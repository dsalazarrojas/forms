# Parent School Program Preference Poll Form - Help Guide
## Purpose
The "Parent School Program Preference Poll Form" is used to gather input from parents on their program preferences for their child. This form is designed to help us understand what programs parents are interested in, and how they would like to be involved in the school programs.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Review the form and ensure you are familiar with the options presented.
2. Read the field explanations below for further clarification on each field.
3. Complete each field as instructed, and submit the form when finished.

## Field-by-Field Explanation
* **School Programs** (`parent_school_program_preference_poll_form_1`, text, not required): Please select the programs you are interested in or that you think would be beneficial for your child. You can choose as many or as few programs as you like.
* **School Program Priority** (`parent_school_program_preference_poll_form_2`, text, not required): If you selected programs in the "School Programs" field, please rank them in order of priority (e.g., most important, second most important, etc.).
* **New Program Suggestions** (`parent_school_program_preference_poll_form_3`, text, not required): If you have a suggestion for a new program that you think would be beneficial for the school, please share it with us.
* **Parent Involvement** (`parent_school_program_preference_poll_form_4`, text, not required): If you would like to be involved in the programs your child is participating in, please describe how you would like to be involved (e.g., volunteering, event planning, etc.).
* **Email Notification** (`parent_school_program_preference_poll_form_5`, select one, not required): Would you like to receive emails about upcoming events and programs? Choose "Yes" if yes, "No" if no.
* **Phone Number** (`parent_school_program_preference_poll_form_6`, text, not required): Please provide your phone number if you would like to be reached by the school for program updates or events.
* **Parent Contact Information** (`parent_school_program_preference_poll_form_7`, email, not required): If you have an email address or phone number where you can be reached by the school for program updates or events, please provide it.
* **Additional Comments** (`parent_school_program_preference_poll_form_8`, note, not required): If there is any additional information you would like to share with us, please use this field to add your comments.

## Tips
- Please be as specific and detailed as possible when filling out the form.
- If you have any questions or concerns, please contact us and we will be happy to help.
- Thank you for taking the time to complete this form!
