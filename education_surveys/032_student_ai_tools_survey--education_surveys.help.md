# Student AI Tools Survey - Help Guide
## Purpose
This form is designed to gather information about students' experiences and perceptions of AI tools in their educational settings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select your current school year from the dropdown menu.
2. Choose all AI tools you have used from the list provided.
3. Indicate your level of satisfaction with the AI tools you have used.
4. Let us know if you are interested in using AI tools in the future.
5. If you have used other AI tools not listed, please specify them in the text field.
6. Provide any additional comments or feedback about AI tools for students.
7. Enter your email address so we can get back to you (optional).

## Field-by-Field Explanation
* **School Year** (`school_year`, select_one, required): Please select the school year you are currently in.
* **AI Tools Used** (`ai_tools_used`, select_multiple, required): Please choose all AI tools you have used. These include:
	+ AI Assistant
	+ Chatbot
	+ Language Model
	+ Virtual Assistant
* **Satisfaction** (`satisfaction`, select_one, required): Indicate your level of satisfaction with the AI tools you have used:
	+ Very satisfied
	+ Somewhat satisfied
	+ Neither satisfied nor dissatisfied
	+ Somewhat dissatisfied
	+ Very dissatisfied
* **Future Interest** (`future_interest`, select_one, required): Let us know if you are interested in using AI tools in the future:
	+ Yes
	+ No
	+ Not sure
* **Other AI Tools Used** (`other_ai_tools_used`, text, optional): If you have used other AI tools not listed, please specify them here.
* **Comments** (`comments`, text, optional): Provide any additional comments or feedback about AI tools for students.
* **Email** (`email`, email, optional): Enter your email address so we can get back to you (optional).
