# Academic Virtual Lab Satisfaction Survey - Help Guide
## Purpose
This survey is designed to assess your experience and satisfaction with the Academic Virtual Lab. Your input will help us understand your needs and identify areas for improvement to enhance your virtual lab experience.

## How To Complete This Form
To complete this form, please navigate through each section and answer the questions accordingly. Fill in all required fields, marked as "Required", and provide any additional feedback in the text fields.

## Field-by-Field Explanation
* **Primary Role** (`user_category`, required): This is your current position within the university or institution.
  - If you are a student, select "Student".
  - If you are a faculty member, select "Faculty Member".
  - If you are a researcher, select "Researcher".
  - If you are IT staff, select "IT Staff".
* **Virtual Lab Used** (`lab_name`, required): Enter the name of the virtual environment or software suite you used.
* **How easy was it to access the virtual lab?** (`ease_of_access`, required): Rate your experience with accessing the virtual lab.
  - If it was easy, select "Very Easy" or "Easy".
  - If it was neutral or average, select "Neutral".
  - If it was difficult, select "Difficult" or "Very Difficult".
* **Rate the performance or speed of the virtual environment** (`system_performance`, required): Assess the virtual lab's performance and speed.
  - If it was excellent, select "Excellent".
  - If it was good, select "Good".
  - If it was fair, select "Fair".
  - If it was poor, select "Poor".
* **How Intuitive is the user interface?** (`interface_intuitiveness`, required): Rate the ease of navigation and use of the virtual lab's interface.
  - If it was very intuitive, select "Very Intuitive".
  - If it was somewhat intuitive, select "Somewhat Intuitive".
  - If it was neutral, select "Neutral".
  - If it was not intuitive, select "Not Intuitive".
* **Select any issues you faced** (`issues_encountered`, optional): List any technical difficulties you experienced while using the virtual lab.
  - Select all that apply.
* **Did the lab have all the software tools you needed?** (`software_availability`, required): Assess the software inventory and availability within the virtual lab.
  - If all software tools were available, select "Yes - All".
  - If most software tools were available, select "Most of them".
  - If only some software tools were available, select "Only some".
  - If no software tools were available, select "None".
* **Rate the quality of technical support provided** (`technical_support_quality`, optional): Assess the quality of technical support you received.
  - If the support was excellent, select "High".
  - If the support was moderate, select "Moderate".
  - If the support was low, select "Low".
  - If no support was sought, select "No support sought".
* **How likely are you to use this virtual lab again?** (`likely_to_use_again`, required): Rate your future intent to use the virtual lab.
  - If you are very likely to use it again, select "Very Likely".
  - If you are likely to use it again, select "Likely".
  - If you are unlikely to use it again, select "Unlikely".
  - If you are very unlikely to use it again, select "Very Unlikely".
* **List 3 improvements you would like to see** (`improvement_suggestions`, optional): Provide specific suggestions for improvement.
* **Overall Rating** (`overall_satisfaction_rating`, required): Enter a number between 1 and 10 to rate your overall satisfaction with the virtual lab.

## Tips
* Please be honest and objective in your feedback.
* Select all that apply in the "Select any issues you faced" field.
* Enter a specific number for the "Overall Rating".
