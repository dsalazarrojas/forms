# Academic Software Needs Survey - Help Guide
## Purpose

This form is designed to collect information from academic users about their current software usage, satisfaction with existing tools, and identification of new software needs.

## How To Complete This Form

1. **Section 1: Current Software Usage**
	* Answer questions about your current software usage, including the tools you use regularly and how satisfied you are with them.
2. **Section 2: Identifying New Needs**
	* If you need new software, describe it and specify how often you would use it and how critical it is to your success.
3. **Section 3: Accessibility and Training**
	* Indicate where you primarily access academic software and if you require training to use new software.

## Field-by-Field Explanation

* **Which software tools do you currently use for your academic work?** (`current_tools`)
	* Select all the tools you regularly use for your academic work.
* **How satisfied are you with the current tools provided by the institution?** (`satisfaction_current_tools`)
	* Choose your level of satisfaction with the current tools provided by the institution.
* **Describe any limitations you encounter with current software** (`software_limitations`)
	* Describe any bugs, missing features, or slow performance issues you experience with current software.
* **Is there a specific software tool you need that is not currently provided?** (`requested_software`)
	* Enter the name of the software tool you need.
* **How often would you use this software?** (`frequency_of_need`)
	* Estimate how often you would use the new software.
* **How critical is this software to your academic success?** (`importance_of_software`)
	* Choose the level of necessity for the new software.
* **Primary use case for requested software** (`primary_use_case`)
	* Select the main task or activity you would use the new software for.
* **Where do you primarily need to access academic software?** (`access_device`)
	* Choose the primary hardware device you use to access academic software.
* **Would you require training to use this new software?** (`training_required`)
	* Indicate if you need training to use the new software.
* **Any other feedback for the IT department?** (`additional_it_comments`)
	* Provide any additional suggestions or comments for the IT department.
