# Yearbook Survey - Help Guide

## Purpose
The Yearbook Survey is a tool used by teachers to gather information about their students in a specific grade level. This form is designed to collect data on students' details such as their first and last names, student ID, grade level, teacher's name, and teacher's email. This data will be used to create a yearbook for the students.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have all the necessary information about the students you are submitting.
2. Enter the student's first name in the "First Name" field.
3. Enter the student's last name in the "Last Name" field.
4. Enter the student's ID number in the "Student ID" field.
5. Select the correct grade level of the student from the "Grade Level" dropdown menu.
6. Enter the teacher's name in the "Teacher's Name" field.
7. Enter the teacher's email in the "Teacher's Email" field.

## Field-by-Field Explanation

* **First Name**: Enter the student's first name (e.g., John, Jane).
* **Last Name**: Enter the student's last name (e.g., Doe, Smith).
* **Student ID**: Enter the student's ID number.
* **Grade Level**: Select the student's grade level from the dropdown menu. Choose from 5th, 6th, 7th, 8th, 9th, 10th, 11th, 12th, 13th, 14th, 15th, 16th.
* **Teacher's Name**: Enter the teacher's name.
* **Teacher's Email**: Enter the teacher's email address.

## Tips

- Make sure to double-check the accuracy of the student's details before submitting the form.
- If you're unsure about a student's grade level, check with the school's administration for clarification.
- Fill out the form as thoroughly as possible to ensure the yearbook is accurate and complete.
