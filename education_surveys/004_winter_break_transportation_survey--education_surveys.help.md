# Winter Break Transportation Survey - Help Guide

## Purpose
The "Winter Break Transportation Survey" is designed to gather information about your transportation plans during winter break. This survey will help us understand your needs and preferences for transportation services during this time.

## How To Complete This Form
1.  Read each field carefully and select the correct options for your transportation plans.
2.  Ensure that all required fields are completed.
3.  Review your answers to ensure accuracy and consistency.
4.  If you have any questions or concerns, please ask your administrator for assistance.

## Field-by-Field Explanation

* **What type of transportation do you plan to use?** (`winter_break_transportation_survey`, select_multiple, required): This question helps us understand your preferred mode of transportation during winter break. Please select all the types of transportation that apply to you.
	+ If you plan to use public transportation (e.g., buses, trains, or subways), select "Yes".
	+ If you plan to use private transportation (e.g., car, bike, or walking), select "Yes".
* **Trip duration (in days)** (`trip_duration_days`, number, optional): This field helps us understand how many days you will be traveling. Please enter the number of days accurately.
* **Travel dates** (`travel_date`, date, required): This field requires you to select the travel dates for your winter break. Please ensure that you enter the correct dates.
* **Start time** (`start_time`, time, required): This field helps us understand when you plan to start your trip. Please select the correct start time.
* **End date** (`end_date`, date, optional): This field is optional, but if you have an end date for your trip, please enter it accurately.
* **Mode of transportation** (`mode_of_transportation`, select_one, required): This question helps us understand your preferred mode of transportation. Please select one of the options:
	+ If you plan to use public transportation, select "Yes".
	+ If you plan to use private transportation, select "Yes".
* **Trip purpose** (`trip_purpose`, select_one, required): This question helps us understand the purpose of your trip. Please select one of the options:
	+ If you are traveling for leisure, select "Yes".
	+ If you are traveling for business or academic purposes, select "Yes".
* **Parking information** (`trip_parking`, note, optional): This field is for additional parking information. Please use this field if you have any specific parking requirements.
* **Housing information** (`trip_housing`, note, optional): This field is for additional housing information. Please use this field if you have any specific housing requirements.
* **Meal and accommodation information** (`trip_meal_accommodation`, note, optional): This field is for additional meal and accommodation information. Please use this field if you have any specific requirements.
* **Other travel arrangements** (`trip_other_arrangements`, note, optional): This field is for any other travel arrangements you may have. Please use this field if you have any additional information.
* **Student transportation availability** (`student_transportation_availability`, select_one, required): This question helps us understand if you are a student and have transportation availability. Please select one of the options:
	+ If you are a student and have transportation availability, select "Yes".
	+ If you are not a student or do not have transportation availability, select "Yes".
* **Student transportation availability** (`student_transportation_availability_hint`, text, optional): This field is for additional information about your student transportation availability. Please use this field if you have any additional comments or questions.
* **When students are available for transportation** (`student_availability_time`, select_multiple, required): This question helps us understand when you are available for transportation. Please select all the times you are available.
* **Day of the week students are available** (`student_availability_day_of_week`, select_multiple, required): This question helps us understand which days of the week you are available for transportation. Please select all the days you are available.
* **Time of day students are available** (`student_availability_time_of_day`, select_multiple, required): This question helps us understand the time of day you are available for transportation. Please select all the times you are available.

By following these instructions, you should be able to complete the "Winter Break Transportation Survey" accurately and effectively. If you have any questions or concerns, please don't hesitate to ask your administrator for assistance.
