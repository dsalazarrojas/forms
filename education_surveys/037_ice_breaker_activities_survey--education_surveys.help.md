# Ice Breaker Activities Survey - Help Guide
## Purpose
This form is designed to gather information about your preferences regarding ice breaker activities, which are social exercises intended to facilitate team building and engagement in educational settings.

## How To Complete This Form
To complete this form, please follow these steps:

* Select a page: You will see a list of pages, each with a unique number and a label. Please select the page that you would like to complete.
* Answer the questions: Each page contains a set of questions. Answer these questions by selecting the options that best suit your preferences.

## Field-by-Field Explanation
### Page 1: Ice Breaker Preferences

* **Ice Breaker Preferences** (`Yes,No`, optional):
	+ This question asks if you would like to participate in ice breaker activities. Please select 'Yes' if you are interested, and 'No' if you are not.
### Page 2: Preferred Ice Breaker Activities

* **Preferred Ice Breaker** (`Yes,No`, optional):
	+ This question asks about the type of ice breaker activity you would prefer. You can select multiple options that best suit your interests.
### Page 3: Ice Breaker Groups

* **Ice Breaker Groups** (`Yes,No`, optional):
	+ This question asks if you would like to participate in ice breaker groups. Please select 'Yes' if you are interested, and 'No' if you are not.

## Tips
* Please be honest and accurate when answering the questions.
* If you are unsure about any of the options, please select the one that best suits your preferences.
* This form is designed to be completed by educators and students currently involved in the educational process.
* If you have completed this form before, please do not submit it again.
