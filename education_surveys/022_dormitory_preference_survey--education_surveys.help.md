# Dormitory Preference Survey - Help Guide

## Purpose
This survey is designed to collect information about your preferences for living in the dormitory. Your input will help us understand what matters most to you in your living arrangement.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select your response for each question by choosing from the available options.
2. You can select multiple options for select_multiple questions.
3. For text input questions, provide a brief answer in the required text box.

## Field-by-Field Explanation

* **Dormitory Presentation** (`dormitory_presentation`, text, optional): Please describe what you want your dormitory presentation to be like (e.g., modern, classic, minimalist).
* **Dormitory Location** (`dormitory_location`, text, optional): Enter the location you would like your dormitory to be (e.g., campus center, near town center, beach).
* **Room Type** (`room_type`, select_one, optional):
	+ **Private Room**: A single room with a private bathroom and no shared space.
	+ **Shared Room**: A room shared with other students.
* **Roommate Preferences** (`roommate_preferences`, select_multiple, optional):
	+ **Male**: You would like to live with male roommates.
	+ **Female**: You would like to live with female roommates.
	+ **Non-Binary**: You would like to live with non-binary roommates.
* **Gender Identity** (`gender_identity`, text, optional): Please describe your gender identity.
* **Language** (`language`, select_one, optional):
	+ **English**: You would like to communicate in English.
	+ **Mandarin**: You would like to communicate in Mandarin.
	+ **Spanish**: You would like to communicate in Spanish.
* **Meal Preference** (`meal_preference`, select_multiple, optional):
	+ **Omnivore**: You would like to have a mix of meat and plant-based dishes.
	+ **Vegetarian**: You would like to have vegetarian dishes only.
	+ **Vegan**: You would like to have plant-based dishes only.
* **Housing Type** (`housing_type`, text, optional): Please describe the type of housing you prefer (e.g., single room, shared room, apartment).
* **Dormitory Size** (`dormitory_size`, text, optional): Please describe the size of the dormitory you prefer.
* **Room Size** (`room_size`, text, optional): Please describe the size of the room you prefer.
* **Amenities** (`amenities`, select_multiple, optional):
	+ **Air Conditioning**: You would like the dormitory to have air conditioning.
	+ **Balcony**: You would like the dormitory to have a balcony.
	+ **Microwave**: You would like the dormitory to have a microwave.
	+ **TV**: You would like the dormitory to have a TV.
* **Floor** (`floor`, select_one, optional):
	+ **Ground Floor**: You would like to live on the ground floor.
	+ **First Floor**: You would like to live on the first floor.
	+ **Second Floor**: You would like to live on the second floor.
	+ **Third Floor**: You would like to live on the third floor.
	+ **Fourth Floor**: You would like to live on the fourth floor.
* **Building Type** (`building_type`, text, optional): Please describe the type of building you prefer.
* **Building Age** (`building_age`, text, optional): Please describe the age of the building you prefer.
* **Floor Age** (`floor_age`, text, optional): Please describe the age of the floor you prefer.
* **Room Orientation** (`room_orientation`, select_one, optional):
	+ **North**: You would like the room to face north.
	+ **South**: You would like the room to face south.
	+ **East**: You would like the room to face east.
	+ **West**: You would like the room to face west.
* **Accessibility** (`accessibility`, select_multiple, optional):
	+ **Wheelchair**: You would like the dormitory to be accessible for people with wheelchairs.
	+ **Hearing**: You would like the dormitory to have hearing accessibility.
	+ **Blindness**: You would like the dormitory to have blindness accessibility.
	+ **Vision**: You would like the dormitory to have vision accessibility.
* **Building Height** (`building_height`, text, optional): Please describe the height of the building you prefer.
* **Dormitory Name** (`dormitory_name`, text, optional): Please enter the name of the dormitory you prefer.
* **Floor Height** (`floor_height`, text, optional): Please describe the height of the floor you prefer.
