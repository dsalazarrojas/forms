# Key Concepts In Evolution - Help Guide
## Purpose
This form is designed to collect feedback from students on the key concepts in evolution that they find challenging or unclear. Instructors will use this feedback to identify areas where they can provide additional support or clarification to help students better understand the subject.

## How To Complete This Form
1. The form is divided into several sections, each corresponding to a different concept in evolution. 
2. Please select the options that apply to your feedback for each concept.
3. You can choose one option for "select_one" type fields, while for "select_multiple" type fields, you can choose multiple options.
4. For "date" and "time" type fields, please select a specific date or time according to the format provided.
5. You can add any additional comments or thoughts in the "note" field.
6. Once you have selected all the necessary options, click the submit button to send your feedback.

## Field-by-Field Explanation
* **Key Concepts In Evolution** (`key_concepts_in_evolution`, text, optional): This is a text field where you can add any general comments or thoughts about the key concepts in evolution.
* **Natural Selection** (`natural_selection`, number, optional): Please enter a number that corresponds to the level of difficulty you are experiencing with this concept. 
* **Evolution Principles** (`evolution_principles`, select_multiple, optional): Select all the evolution principles that you are having trouble understanding. 
* **Student Understanding** (`student_understanding`, select_one, optional): Please select which option best describes your level of understanding for this concept. 
* **Classrooms Tutoring Course Evaluations** (`classrooms_tutoring_course_evaluations`, date, optional): Select the specific date of the class session or tutoring course you attended. 
* **Fast Online Data Collection** (`fast_online_data_collection`, time, optional): This field is not applicable for this form. However, please note that it is intended for collecting feedback on the pace or difficulty of online data collection. 
* **Natural Selection and Core Evolution Principles** (`natural_selection_and_core_evolution_principles`, note, optional): Please add any additional thoughts or comments about the natural selection and core evolution principles. 

## Tips
* Please be as specific as possible when providing feedback. 
* If you have already provided feedback on the same topic, please do not fill out this form. 
* Please select all the options that apply to your feedback, even if it's just one. 
* If you are having trouble with a particular concept, please make sure to select all the corresponding options. 
* Thank you for taking the time to provide your feedback!
