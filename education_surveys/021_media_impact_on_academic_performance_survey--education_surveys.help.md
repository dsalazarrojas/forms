# Media Impact On Academic Performance Survey - Help Guide
## Purpose
The Media Impact On Academic Performance Survey is designed to collect information about the impact of media consumption on academic performance of students. It is intended for students who have been identified as needing to complete it.

## How To Complete This Form
1. Read the instructions carefully before starting to complete the form.
2. Answer each question thoroughly and accurately.
3. Use the provided options to select the correct answer for each question.

## Field-by-Field Explanation
* **Introduction** (Page 1, required): This is a brief introduction to the survey. Please read it carefully to understand the purpose of the form and what information it is asking for.
* **Demographic** (Page 2, optional): This field is for you to provide some basic information about yourself. You can type in any relevant details.
* **Student Demographics** (Page 3, optional): This field is for you to provide more specific information about your demographic details. Please type in any relevant details.
* **Media Use** (Page 4, required): This question asks about how often you use media. Please select the option that best describes your media use frequency.
* **Grade** (Page 5, optional): This field is for you to select your current grade.
* **Grade Point** (Page 6, required): This field is for you to enter your current grade point.
* **Other Media Sources** (Page 7, required): This field is for you to list any other media sources you use besides the ones mentioned in the form.
* **Average Hours Spent** (Page 8, required): This field is for you to enter how many hours you spend on media per day.

## Tips
* Please answer each question thoroughly and accurately.
* If you are not sure about any question, please consult with a teacher or administrator before submitting the form.
* Make sure to enter your correct grade point in the "Grade Point" field.
* This form is a critical part of the data collection process and should be completed thoroughly and accurately.
* If you have any questions or concerns, please contact the administrator or teacher responsible for the survey.
