This help guide is for the Juvenile Spacing Survey form. The form is used to collect information from end users, specifically to gather data on juveniles' spacing, which is an important aspect of their overall well-being. This form is designed to be completed by parents or guardians of the juveniles.

The purpose of this form is to collect demographic information, spacing habits, and other relevant details that can help in understanding the juveniles' spacing patterns.

Before completing this form, please note that it is designed for juveniles' spacing habits, so please only fill out the form for the relevant pages.

**Juvenile Spacing Survey - Help Guide**

**Purpose**

The Juvenile Spacing Survey is a form used to gather information on juveniles' spacing habits. It is designed to collect demographic information, spacing habits, and other relevant details that can help in understanding the juveniles' spacing patterns.

**How To Complete This Form**

1. The form is divided into 25 pages, each with a specific set of questions.
2. Each page has a unique label (Page 1-25) and can be navigated using the next and previous buttons at the top.
3. Please complete each page carefully and accurately.
4. If you are unsure about a question or option, please ask for assistance from a supervisor or administrator.

**Field-by-Field Explanation**

* **Page 1**:
    * **Page 1** (Page 1, text, required/optional): This field is for the juvenile's name.
* **Page 2**:
    * **Page 2** (Page 2, select_multiple, required/optional): Select all options that apply to the juvenile's spacing habits.
* **Page 3**:
    * **Page 3** (Page 3, text, required/optional): Please provide a brief description of the juvenile's spacing habits.
* **Page 4**:
    * **Page 4** (Page 4, number, required/optional): Enter the number of hours spent on spacing activities yesterday.
* **Page 5**:
    * **Page 5** (Page 5, select_one, required/optional): Select the most common spacing activity of the juvenile yesterday.
* **Page 6**:
    * **Page 6** (Page 6, date, required/optional): Enter the date the juvenile last had a spacing session.
* **Page 7**:
    * **Page 7** (Page 7, time, required/optional): Enter the time the juvenile usually has spacing in the morning.
* **Page 8**:
    * **Page 8** (Page 8, number, required/optional): Enter the number of minutes spent on spacing in the last session.
* **Page 9**:
    * **Page 9** (Page 9, text, required/optional): Briefly describe the juvenile's favorite spacing activity.
* **Page 10**:
    * **Page 10** (Page 10, number, required/optional): Enter the average minutes spent on spacing per session.
* **Page 11**:
    * **Page 11** (Page 11, select_one, required/optional): Select the most common time of day for spacing activities.
* **Page 12**:
    * **Page 12** (Page 12, text, required/optional): Briefly describe the juvenile's spacing environment.
* **Page 13**:
    * **Page 13** (Page 13, date, required/optional): Enter the date the juvenile started spacing activities.
* **Page 14**:
    * **Page 14** (Page 14, time, required/optional): Enter the time of day when the juvenile usually starts spacing activities.
* **Page 15**:
    * **Page 15** (Page 15, number, required/optional): Enter the total spacing activity time yesterday.
* **Page 16**:
    * **Page 16** (Page 16, text, required/optional): Describe the juvenile's spacing habits when they feel stressed.
* **Page 17**:
    * **Page 17** (Page 17, number, required/optional): Enter the spacing frequency (number of times per week).
* **Page 18**:
    * **Page 18** (Page 18, select_one, required/optional): Select the most common spacing activity when feeling stressed.
* **Page 19**:
    * **Page 19** (Page 19, text, required/optional): Briefly describe the juvenile's favorite spacing location.
* **Page 20**:
    * **Page 20** (Page 20, number, required/optional): Enter the total spacing time per week.
* **Page 21**:
    * **Page 21** (Page 21, select_one, required/optional): Select the most common spacing activity with friends or family.
* **Page 22**:
    * **Page 22** (Page 22, text, required/optional): Briefly describe the juvenile's spacing habits when they feel bored.
* **Page 23**:
    * **Page 23** (Page 23, date, required/optional): Enter the date the juvenile started spacing activities.
* **Page 24**:
    * **Page 24** (Page 24, time, required/optional): Enter the time of day when the juvenile usually takes a break for spacing activities.
* **Page 25**:
    * **Page 25** (Page 25, number, required/optional): Enter the average minutes spent on spacing in the last 30 days.

**Tips**

* Please complete each page carefully and accurately.
* If you are unsure about a question or option, please ask for assistance from a supervisor or administrator.
* You can navigate through the pages using the next and previous buttons at the top.
* If you need help or have questions, please don't hesitate to contact the administrator.
