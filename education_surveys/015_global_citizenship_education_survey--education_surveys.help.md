# Global_Citizenship_Education_Survey - Help Guide
## Purpose
This form is designed to collect information from users about their education system, level of education, familiarity with certain concepts, and feedback on their experience with the program.

## How To Complete This Form
To complete this form, simply navigate through the pages and fill out the fields as follows:

*   On the "introduction" page, please provide a brief background about yourself.
*   On the "education system" page, select the option that best describes your education system.
*   On the "education level" page, select all the options that apply to your education level.
*   On the "familiarity" page, select a date to indicate how familiar you are with the program.
*   On the "feedback" page, provide any additional feedback or comments about your experience with the program.
*   On the "improvement" page, select all the options that you think would improve the program.
*   On the "program finance" page, select all the options that apply to your experience with the program's finance.
*   On the "program location" page, select the option that best describes the location of the program.
*   On the "program participant characteristics" page, select all the options that apply to your characteristics.
*   On the "program participant differences" page, select all the options that differ from other participants.
*   On the "program characteristics" page, select all the options that apply to the program's characteristics.
*   On the "program characteristics differences" page, select all the options that differ from other programs.
*   On the "program finance characteristics" page, select all the options that apply to the program's finance.
*   On the "program finance differences" page, select all the options that differ from other programs.
*   On the "program outcome characteristics" page, select all the options that apply to the program's outcome.
*   On the "program outcome differences" page, select all the options that differ from other programs.
*   On the "program partners" page, select all the options that apply to the partners of the program.
*   On the "program partners differences" page, select all the options that differ from other programs.
