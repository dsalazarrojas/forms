# Physics Exercises Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback on student work in a physics context, allowing teachers to provide detailed and constructive comments. The form will help teachers assess student performance and help students improve their understanding of physics concepts.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the teacher's name in the "Teacher Name" field.
2. Select the course ID from the "Course ID" dropdown list.
3. Enter the assignment name in the "Assignment Name" field.
4. Enter the problem ID from the "Problem ID" dropdown list.
5. Choose the type of feedback in the "Feedback Type" dropdown list (Positive, Negative, or Neutral).
6. Provide detailed feedback in the "Feedback" field.
7. If necessary, offer suggestions for improvement in the "Suggestion" field.
8. Describe the problem statement in the "Problem Statement" field.
9. Upload the student's work in the "Student Work" field, if applicable.
10. Upload the teacher's work in the "Teacher Work" field, if applicable.
11. Provide the student's comment in the "Student Comment" field, if applicable.
12. Enter the teacher's comment in the "Teacher Comment" field, if applicable.
13. Enter the student's score, if applicable, in the "Student Score" field.
14. Enter the teacher's score, if applicable, in the "Teacher Score" field.
15. Select the feedback status in the "Feedback Status" dropdown list (In Progress, Completed, or Pending).
16. Select the completion status in the "Completion Status" dropdown list (Incomplete, Complete, or No Answer).
17. Enter the submission date and time in the "Submission Date" and "Submission Time" fields, respectively.
18. Set the submission deadline in the "Submission Deadline" field.
19. Set the due date and time in the "Due Date" and "Due Time" fields, respectively.
20. Enter the date and time the form was created and last updated in the "Created At" and "Updated At" fields, respectively.
21. Note: Some fields are optional, and you should only fill them out if relevant to your feedback.

## Field-by-Field Explanation

* **Teacher Name** (`teacher_name`, text, required): Enter your name as a teacher.
* **Course ID** (`course_id`, number, optional): Select the course ID from the list to associate your feedback with the correct course.
* **Assignment Name** (`assignment_name`, text, optional): Enter the name of the assignment.
* **Problem ID** (`problem_id`, number, optional): Select the problem ID from the list to associate your feedback with the specific problem.
* **Feedback Type** (`feedback_type`, select_one, optional): Choose the type of feedback (Positive, Negative, or Neutral).
* **Feedback** (`feedback`, text, optional): Provide detailed feedback on the student's work.
* **Suggestion** (`suggestion`, text, optional): Offer suggestions for improvement.
* **Problem Statement** (`problem_statement`, text, optional): Describe the problem statement.
* **Student Work** (`student_work`, text, optional): Upload the student's work, if applicable.
* **Teacher Work** (`teacher_work`, text, optional): Upload the teacher's work, if applicable.
* **Student Comment** (`student_comment`, text, optional): Provide a comment from the student.
* **Teacher Comment** (`teacher_comment`, text, optional): Provide a comment from the teacher.
* **Student Score** (`student_score`, number, optional): Enter the student's score, if applicable.
* **Teacher Score** (`teacher_score`, number, optional): Enter the teacher's score, if applicable.
* **Feedback Status** (`feedback_status`, select_multiple, optional): Select the feedback status (In Progress, Completed, or Pending).
* **Completion Status** (`completion_status`, select_multiple, optional): Select the completion status (Incomplete, Complete, or No Answer).
* **Submission Date** (`submission_date`, date, optional): Enter the submission date in YYYY-MM-DD format.
* **Submission Time** (`submission_time`, time, optional): Enter the submission time in HH:MM:SS format.
* **Submission Deadline** (`submission_deadline`, date, optional): Set the submission deadline in YYYY-MM-DD format.
* **Due Date** (`due_date`, date, optional): Set the due date in YYYY-MM-DD format.
* **Due Time** (`due_time`, time, optional): Set the due time in HH:MM:SS format.
* **Created At** (`created_at`, date, optional): Displays the date and time the form was created.
* **Updated At** (`updated_at`, date, optional): Displays the date and time the form was last updated.
* **Deleted At** (`deleted_at`, date, optional): Displays the date and time the form was deleted.
