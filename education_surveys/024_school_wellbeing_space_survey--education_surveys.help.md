# School Wellbeing Space Survey - Help Guide
## Purpose
This form is designed to gather feedback and input from staff, students, and other stakeholders on the school's wellbeing spaces.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form to ensure you understand the questions and fields.
2. Fill out the form in a clear and concise manner, providing as much detail as possible.
3. For fields marked as "Other" or "Text," provide a brief description of your answer.
4. Ensure you select the correct options from the list provided for each field.
5. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **School Wellbeing Space Survey (survey_title)** (`survey_title`, Text, Not Required):
	+ This is the title of the survey, which should match the current title of the wellbeing spaces being surveyed.
* **Category (category)** (Category, Select One, Not Required):
	+ Select the category that best describes the wellbeing spaces you are evaluating (e.g., Education, Administration).
* **Staff (staff)** (Staff, Select Multiple, Not Required):
	+ Choose all the staff members who use or have access to the wellbeing spaces.
* **Wellbeing Spaces (wellbeing_spaces)** (Wellbeing Spaces, Select Multiple, Not Required):
	+ Select all the wellbeing spaces you are evaluating (e.g., School Wellbeing Space, Outdoor Wellbeing Space, Other).
* **Other (wellbeing_spaces_other)** (Other (please specify), Text, Not Required):
	+ If you selected "Other" in the previous field, describe the wellbeing space you are referring to.
* **Usage Frequency (usage_frequency)** (Usage Frequency, Select One, Not Required):
	+ Indicate how frequently you use or have access to the wellbeing spaces (e.g., Daily, Weekly, Rarely).
* **Satisfaction (satisfaction)** (Satisfaction, Select One, Not Required):
	+ Rate your satisfaction with the wellbeing spaces (e.g., Very Satisfied, Somewhat Satisfied, Not Satisfied).
* **Support Programs (support_programs)** (Support Programs, Select Multiple, Not Required):
	+ Choose all the support programs you think are relevant or useful for the wellbeing spaces.
* **Other (support_programs_other)** (Other (please specify), Text, Not Required):
	+ If you selected "Other" in the previous field, describe the support program you are referring to.
* **Comments (comments)** (Comments, Note, Not Required):
	+ Provide any additional comments or suggestions you may have.
* **Email (email)** (Email, Email, Not Required):
	+ If you have any contact information or email address you'd like to be reached out to, please provide it.
* **Phone (phone)** (Phone, Text, Not Required):
	+ If you have a phone number you'd like to be reached out to, please provide it.

## Tips
- Please answer all fields that apply to you or the wellbeing spaces you are evaluating.
- Be as detailed and specific as possible in your answers.
- If you're unsure about any field, please don't hesitate to ask for clarification.
