# Educational Sector Indicator Evaluation - Help Guide
## Purpose
This form is designed to collect data on the educational sector, including its progress and performance. The data collected will help in evaluating the sector's performance and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant sector from the available options.
2. Enter the relevant indicator (e.g., student enrollment, graduation rate, etc.).
3. Enter the value of the indicator.
4. Choose the evaluation method used to measure the indicator (e.g., survey, assessment, etc.).
5. Select the evaluation method if it's not one of the provided options.
6. Enter the date of the evaluation.
7. Select the evaluation period (e.g., semester, year, etc.).
8. Choose the type of form (e.g., quarterly, annual, etc.).
9. Enter any additional comments about the evaluation.
10. Select the user assigned to evaluate the sector.
11. Enter the date when the form was submitted.
12. Select the user who submitted the form.
13. Choose the type of submission (e.g., manual, automated, etc.).
14. Select the status of the submission (e.g., pending, approved, etc.).

## Field-by-Field Explanation

* **education survey sector id** (`education_survey_sector_id`, text, optional): This field is used to enter the ID of the educational sector.
* **Sector** (`sector`, select_one, optional): This field is used to select the relevant sector from the available options.
* **Indicator** (`indicator`, text, optional): This field is used to enter the relevant indicator (e.g., student enrollment, graduation rate, etc.).
* **Value** (`value`, number, optional): This field is used to enter the value of the indicator.
* **Evaluation Method** (`evaluation_method`, select_one, optional): This field is used to select the evaluation method used to measure the indicator (e.g., survey, assessment, etc.).
* **Evaluation Method Other** (`evaluation_method_other`, text, optional): This field is used to enter the evaluation method if it's not one of the provided options.
* **Evaluation Date** (`evaluation_date`, date, optional): This field is used to enter the date of the evaluation.
* **Evaluation Period** (`evaluation_period`, number, optional): This field is used to select the evaluation period (e.g., semester, year, etc.).
* **Form Type** (`form_type`, select_multiple, optional): This field is used to choose the type of form (e.g., quarterly, annual, etc.).
* **Evaluation Comment** (`evaluation_comment`, note, optional): This field is used to enter any additional comments about the evaluation.
* **Assigned User** (`assigned_user`, select_one, optional): This field is used to select the user assigned to evaluate the sector.
* **Submitted Date** (`submitted_date`, date, optional): This field is used to enter the date when the form was submitted.
* **Submitted By** (`submitted_by`, select_one, optional): This field is used to select the user who submitted the form.
* **Submission Type** (`submission_type`, select_multiple, optional): This field is used to choose the type of submission (e.g., manual, automated, etc.).
* **Submission Status** (`submission_status`, select_multiple, optional): This field is used to select the status of the submission (e.g., pending, approved, etc.).

## Tips

* Please fill out the form accurately and completely.
* If you're unsure about any field, refer to the form's purpose and instructions above.
* If you need help with any field, contact the relevant authorities.
* This form is meant to be filled out only once you have understood its intended use.
