# Global Economic Empowerment Survey - Help Guide
## Purpose
The Global Economic Empowerment Survey is designed to collect data on household characteristics and socio-economic factors to inform research on global economic empowerment.

## How To Complete This Form
1. Please answer each question to the best of your ability.
2. Select the most accurate option for each field.
3. If you are unsure about any question, please ask for clarification.

## Field-by-Field Explanation

* **Household Income** (`household_income`, number, required: false): This question asks for the household income, which is a measure of the total income earned by all members of the household. Please enter a numerical value for household income.
* **Employment Status** (`employment_status`, select_one, required: false): This question asks about the current employment status of the household head or the person who manages the household finances. Please select one of the following options:
	+ Employed
	+ Unemployed
	+ Other (please specify)
* **Employment Sector** (`employment_sector`, select_multiple, required: false): This question asks about the sector in which the household head or the person who manages the household finances is employed. Please select all that apply:
	+ Government
	+ Private Sector
	+ Self Employment
	+ Other (please specify)
* **Financial Institutions** (`financial_institutions`, select_multiple, required: false): This question asks about the financial institutions used by the household. Please select all that apply:
	+ Bank
	+ Credit Union
	+ Microfinance Institution
	+ Other (please specify)
* **Financial Inclusion** (`financial_inclusion`, select_one, required: false): This question asks about the household's access to financial services. Please select one of the following options:
	+ Included
	+ Not Included
	+ Prefer not to say
* **Perceived Control Over Financial** (`perceived_control_over_financial`, select_multiple, required: false): This question asks about the household's perceived control over financial decisions. Please select all that apply:
	+ High
	+ Medium
	+ Low
* **Region** (`region`, select_one, required: false): This question asks about the geographic region of the household. Please select one of the following options:
	+ Region 1
	+ Region 2
	+ Region 3
* **Education Level** (`education_level`, select_one, required: false): This question asks about the highest level of education attained by the household head or the person who manages the household finances. Please select one of the following options:
	+ High School
	+ College/University
	+ Other (please specify)
* **Gender** (`gender`, select_one, required: false): This question asks about the gender of the household head or the person who manages the household finances. Please select one of the following options:
	+ Male
	+ Female
	+ Other
* **Marital Status** (`marital_status`, select_multiple, required: false): This question asks about the marital status of the household head or the person who manages the household finances. Please select all that apply:
	+ Single
	+ Married
	+ Other (please specify)
* **Household Size** (`household_size`, select_one, required: false): This question asks about the number of household members. Please select one of the following options:
	+ Less than 5
	+ 5 or more
* **Age** (`age`, number, required: false): This question asks for the age of the household head or the person who manages the household finances. Please enter a numerical value.
* **Employment Type** (`employment_type`, select_multiple, required: false): This question asks about the type of employment of the household head or the person who manages the household finances. Please select all that apply:
	+ Formal
	+ Informal
	+ Other (please specify)
* **Financial Support** (`financial_support`, select_multiple, required: false): This question asks about the household's access to financial support. Please select all that apply:
	+ True
	+ False
* **Income** (`income`, number, required: false): This question asks for the household income. Please enter a numerical value.

## Tips
* Please answer the questions honestly and accurately.
* If you are unsure about any question, please ask for clarification.
* This form is for the purpose of research on global economic empowerment. All responses will be kept confidential.
