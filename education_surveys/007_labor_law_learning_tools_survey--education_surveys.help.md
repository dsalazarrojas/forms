# Labor Law Learning Tools Survey - Help Guide
## Purpose
The Labor Law Learning Tools Survey is a form designed to collect information on the learning tools and resources used by employees related to labor law. This information will help us better understand how employees learn and utilize these tools, allowing us to improve our resources and support.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the title of the learning tool or resource being used.
2.  Select the category of the learning tool or resource, which is currently limited to "Labor Law" or "Education Surveys".
3.  Provide a brief description of the learning tool or resource. You can choose from the options "None" or "Other" and provide a description if you select "Other".
4.  Enter any IDs or codes associated with the learning tool or resource.
5.  If the learning tool or resource has an output file or report, enter the file name or location.
6.  Enter any additional information or notes about the learning tool or resource.
7.  Finally, enter any relevant categories or tags for the learning tool or resource.

## Field-by-Field Explanation

*   **Form Title** (`form_title`, Text, Optional): Enter a clear and descriptive title for the learning tool or resource.
*   **Form Category** (`form_category`, Select One, Optional): Select whether the learning tool or resource falls under the category of "Labor Law" or "Education Surveys" based on the provided options.
*   **Form Description** (`form_description`, Select Multiple, Optional): If the learning tool or resource is of type "Other", select "None" and add a short description of the resource.
*   **IDs/Code** (`form_ids`, Text, Optional): Enter any IDs or codes associated with the learning tool or resource, if applicable.
*   **Output File** (`output_file`, Text, Optional): Enter the name of the output file or report generated by the learning tool or resource, if applicable.
*   **Category** (`category`, Text, Optional): Enter any relevant categories or tags for the learning tool or resource.
*   **Description** (`description`, Text, Optional): Enter a brief description of the learning tool or resource, if applicable.
