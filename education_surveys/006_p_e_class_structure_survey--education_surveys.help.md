# P.E. Class Structure Survey - Help Guide
## Purpose
The P.E. Class Structure Survey is designed to collect opinions and suggestions from students, teachers, or other stakeholders about the Physical Education class structure, size, type, and overall safety and engagement level.

## How To Complete This Form
1. Read each question carefully and answer honestly.
2. For numerical questions, choose the most accurate option from the provided list.
3. For text fields, provide clear and concise answers.
4. If you have any additional improvement ideas, use the "Improvement Ideas" or "Other Improvement Ideas" text fields.
5. If you have any suggestions or concerns about class safety, choose the most accurate option from the provided list.

## Field-by-Field Explanation

* **Class Size (2)**: This question asks about the ideal class size. Choose the range that best suits your needs. Please select from:
	+ 1-10 students
	+ 11-20 students
	+ 21-30 students
	+ 31-40 students
	+ 41-50 students
	+ 51 or more students
* **Class Type (3)**: What type of class do you think would be most beneficial? Please select from:
	+ Physical Education Class
	+ Dance Class
	+ Gym Class
	+ Sports Class
	+ Other (please specify)
* **Class Structure (4)**: Describe your ideal class structure. Please provide a clear and concise answer.
* **Class Engagement (5)**: How engaged do you feel in class? Please select from:
	+ High
	+ Medium
	+ Low
	+ Very Low
* **Improvement Ideas (6)**: Share any ideas or suggestions you have to improve the class structure and overall experience.
* **Other Improvement Ideas (7)**: If you have any additional ideas or suggestions, please share them here.
* **Class Safety (8)**: How safe do you feel in class? Please select from:
	+ Very Safe
	+ Somewhat Safe
	+ Not Very Safe
	+ Not Safe At All
* **Teacher Support (9)**: How much support do you feel from your teachers? Please select from:
	+ Strongly Agree
	+ Somewhat Agree
	+ Neutral
	+ Somewhat Disagree
	+ Strongly Disagree
* **Student Support (10)**: How much support do you feel from your peers? Please select from:
	+ Strongly Agree
	+ Somewhat Agree
	+ Neutral
	+ Somewhat Disagree
	+ Strongly Disagree

## Tips

* Be honest and sincere in your answers.
* Provide clear and concise answers.
* If you have any concerns or suggestions, feel free to share them.
* If you have any additional questions or need clarification, contact <form@gic.mx>.
