# VET Course Preparation Survey - Help Guide
## Purpose
This guide will help you complete the VET Course Preparation Survey, which is designed to gather information about your interests and preferences for the VET course.

## How To Complete This Form
To complete this form, simply select the answers that best match your interests and preferences. You can skip questions that are not relevant to your situation.

## Field-by-Field Explanation
* **Course Interests** (`Course Interests`, Select Multiple, Optional): Choose the topics that you are most interested in learning more about in the VET course.
	+ Options: Dental, Healthcare
* **Course Duration** (`Course Duration`, Number, Optional): If you have a specific duration in mind for the course, please select it.
* **Course Frequency** (`Course Frequency`, Select One, Optional): Indicate how often you would like the course to meet.
	+ Options: 1, 2, 3, 4, 5
* **Course Start Date** (`Course Start Date`, Date, Optional): If you have a specific start date in mind for the course, please select it.
* **Course Start Time** (`Course Start Time`, Time, Optional): If you have a specific start time in mind for the course, please select it.
* **Course Delivery Location** (`Course Delivery Location`, Select One, Optional): Choose where you would like the course to be delivered.
	+ Options: Online, Offline
* **Course Participants** (`Course Participants`, Select Multiple, Optional): If you would like to participate with a small group or a large group, please select your preference.
	+ Options: Small Group, Large Group
* **Delivery Preference** (`Delivery Preference`, Select One, Optional): Choose how you would like to receive the course material.
	+ Options: Flexible, Structured
* **Delivery Method** (`Delivery Method`, Select One, Optional): Choose how you would like to receive the course.
	+ Options: Online, Offline
* **Participant Details** (`Participant Details`, Note, Optional): If you have any additional comments or details about your participation, please enter them here.
* **Participant Email** (`Participant Email`, Email, Optional): Enter your email address.
* **Participant Phone** (`Participant Phone`, Text, Optional): Enter your phone number.
* **Participant Address** (`Participant Address`, Text, Optional): Enter your address.
* **Notes** (`Notes`, Note, Optional): If you have any additional comments, please enter them here.
* **Comments** (`Comments`, Text, Optional): If you have any additional comments, please enter them here.
* **Participant Name** (`Participant Name`, Text, Optional): Enter your name.
* **Participant Age** (`Participant Age`, Number, Optional): Enter your age.
* **Participant Gender** (`Participant Gender`, Select One, Optional): Choose your gender.
	+ Options: Male, Female
* **Participant Interests** (`Participant Interests`, Select Multiple, Optional): Choose your interests.
	+ Options: Sports, Music, Travel
* **Participant Education** (`Participant Education`, Select One, Optional): Choose your level of education.
	+ Options: High School, College/University
