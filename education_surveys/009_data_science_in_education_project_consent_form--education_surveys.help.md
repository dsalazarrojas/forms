# data_science_in_education_project_consent_form - Help Guide

## Purpose
This form is designed to collect information from participants in the Data Science in Education Project. It aims to obtain consent for the project and gather relevant details about the participants and their involvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by reviewing the form header, which contains a note about the project.
2. Fill in your Participant Information, including any relevant details about yourself.
3. Provide Project Information, describing the project you are participating in.
4. Indicate whether you are willing to provide consent for the project by selecting 'Yes' or 'No' in the Consent Statement field.
5. If you are giving consent, specify the specific aspects you are consenting to in the Participant Consent field.
6. Enter your contact details, including any relevant contact information.
7. Select 'Yes' or 'No' in the Submit field to finalize your response.

## Field-by-Field Explanation

* **Form Header** (`form_header`, note, required: false): This is an informational header that provides context about the project.
* **Participant Information** (`participant_info`, text, required: false): Please enter your name, affiliation, and any other relevant details about yourself.
* **Project Information** (`project_info`, text, required: false): Describe the project you are participating in, including its goals and objectives.
* **Consent Statement** (`consent_statement`, select_one, required: false): Select 'Yes' if you are willing to provide consent for the project, or 'No' otherwise.
* **Participant Consent** (`participant_consent`, select_multiple, required: false): If you are giving consent, select all the aspects you are willing to consent to. Please note that this field is only visible if you selected 'Yes' in the previous field.
* **Contact Details** (`contact_details`, text, required: false): Enter any contact information you want to provide for the project team.
* **Contact Info** (`contact_info`, text, required: false): Enter any additional contact information you want to provide for the project team.
* **Submit** (`submit`, select_one, required: false): Select 'Yes' to finalize your response and submit your information to the project team.

## Tips
Please take a few minutes to thoroughly review each field before submitting your response. If you have any questions or concerns, feel free to reach out to the project team.
