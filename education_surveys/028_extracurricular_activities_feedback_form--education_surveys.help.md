# Extracurricular Activities Feedback Form - Help Guide
## Purpose
The Extracurricular Activities Feedback Form is designed to collect feedback from participants in extracurricular activities or programs. This form helps the institution to evaluate the quality and engagement of the programs and make necessary improvements.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer all questions carefully and honestly.
2. Select the relevant options for each question.
3. Provide as much detail as possible in the text fields.
4. Ensure that you have filled out all required fields.

## Field-by-Field Explanation

* **Name** (`name_page`, text, required): Please enter your name.
* **School** (`school_page`, text, required): Please enter your school name.
* **Program** (`program_page`, text, optional): If you attended an extracurricular program, please enter the name of the program.
* **Event** (`event_page`, text, optional): If you attended an event, please enter the name of the event.
* **Event Type** (`event_type_page`, select_one, required): Please select the type of event you attended (Enrichment, Club, or Workshop).
* **Date** (`date_page`, date, optional): If you attended an event or program, please enter the date it took place.
* **Time** (`time_page`, time, optional): If you attended an event, please enter the time it took place.
* **Duration** (`duration_page`, text, optional): If you attended an event, please enter the duration of the event.
* **Staff** (`staff_page`, text, optional): If you interacted with staff during the event, please enter their name.
* **Title** (`staff_title_page`, text, optional): If you interacted with staff, please enter their title.
* **Rating** (`staff_rating_page`, number, optional): If you rated the staff member, please enter their rating (e.g., 1-5).
* **Participant** (`participant_page`, text, optional): If you participated in the event, please enter your name.
* **Comments** (`comments_page`, text, optional): Please provide any additional comments or feedback about the event or program.
* **Comments 2** (`submission_comments2_page`, text, optional): Please provide any additional comments or feedback about the submission process.
* **Submission Email** (`submission_email_page`, email, optional): If you have a preferred email address for follow-up, please enter it.
* **Submission Phone** (`submission_phone_page`, text, optional): If you have a preferred phone number for follow-up, please enter it.
* **Submission Name** (`submission_name_page`, text, optional): If you have a preferred name for follow-up, please enter it.

Note: All fields marked as "required" are mandatory and must be filled out. Optional fields can be left blank if not applicable.
