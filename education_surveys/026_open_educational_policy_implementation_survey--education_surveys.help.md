# Open Educational Policy Implementation Survey - Help Guide
## Purpose
The Open Educational Policy Implementation Survey aims to gather information on the current implementation of Open Educational Policy in educational institutions. This information will help institutions to better understand their strengths and weaknesses and make necessary adjustments to improve the implementation of the policy.

## How To Complete This Form
- Fill out the form completely and accurately.
- Review each field carefully and make sure you understand the purpose of each question.
- For the multiple-choice questions, select only one option that best describes your response.
- For text fields, provide a clear and concise description.
- If you have any comments or additional information, use the "policy_comments" field.
- Select the "Submit" button to submit your response or "Save for Later" to save your progress and continue later.

## Field-by-Field Explanation
* **Introduction** (`1`, `note`, required: false): This is a note field where you can provide any necessary introduction or background information.
* **Stakeholder Groups** (`2`, `select_multiple`, required: false): Choose one or more of the following stakeholder groups:
	+ Stakeholder A
	+ Stakeholder B
	+ Stakeholder C
* **Policy Awareness** (`3`, `number`, required: false): On a scale from 1-5, rate how aware you are of the Open Educational Policy implementation in your institution:
	+ 1 (not at all)
	+ 2 (a little)
	+ 3 (somewhat)
	+ 4 (very)
	+ 5 (extremely)
* **Policy Challenges** (`4`, `note`, required: false): Describe the challenges you are facing in implementing the Open Educational Policy.
* **Policy Effectiveness** (`5`, `select_one`, required: false): Choose the option that best describes your current level of effectiveness:
	+ Option A
	+ Option B
	+ Option C
* **Policy Feedback** (`6`, `text`, required: false): Provide any additional feedback about the Open Educational Policy.
* **Policy Comments** (`7`, `note`, required: false): Is there anything else you would like to add about the Open Educational Policy?
* **Contact Information** (`8`, `email`, required: false): Enter your contact information to be kept in the loop and allow for further discussion.
* **Contact Information 2** (`9`, `text`, required: false): Provide any additional contact information you would like to share.
* **Contact Information 3** (`10`, `text`, required: false): This is another contact information field for any further details.
* **Submit** (`11`, `select_multiple`, required: false): Choose how you want to proceed:
	+ Submit
	+ Save for Later
	+ Continue Later
