# After School Program Preferences Questionnaire - Help Guide
## Purpose
The After School Program Preferences Questionnaire is a tool designed to collect information from parents or guardians about their child's interests, preferences, and requirements for an after-school program. This information will help the program administrators create a program that meets the needs of all participants.

## How To Complete This Form
1. Please answer all questions accurately and honestly.
2. Select the options that best fit your child's characteristics and preferences.
3. For numerical questions (e.g., Importance of Academic Support), please enter a number between 1 and 5, where 1 means "not important at all" and 5 means "very important".
4. For multiple-select questions (e.g., Academic Interests), please select all that apply.
5. If you have any additional comments or questions, please use the "Additional Comments" field.

## Field-by-Field Explanation

* **Parent/Guardian Name** (id: 2, type: text, required: true)
	+ Enter your full name as a parent or guardian.
* **Email Address** (id: 3, type: email, required: true)
	+ Enter your email address for program updates and communication.
* **Phone Number** (id: 4, type: text, required: true)
	+ Enter your phone number for contact purposes.
* **Household Income Bracket** (id: 5, type: select_one, required: false)
	+ Select your approximate household income bracket.
* **Student Name** (id: 7, type: text, required: true)
	+ Enter the student's full name.
* **Student Grade Level** (id: 8, type: select_one, required: true)
	+ Select the student's current grade level.
* **School Attended** (id: 9, type: text, required: true)
	+ Enter the name of the school the student attends.
* **Student Interests** (id: 11, type: select_multiple, required: true)
	+ Select all academic subjects your child enjoys (Mathematics, Science, Reading/Language Arts, Social Studies, Foreign Languages, History, None of these).
* **Creative Interests** (id: 12, type: select_multiple, required: true)
	+ Select all creative activities your child enjoys (Art, Music, Drama/Theater, Creative Writing, Dance, Photography, None of these).
* **Physical Activities** (id: 13, type: select_multiple, required: true)
	+ Select all physical activities your child enjoys (Team Sports, Individual Sports, Martial Arts, Dance, Swimming, Outdoor Activities, None of these).
* **Technology Interests** (id: 14, type: select_multiple, required: true)
	+ Select all technology-related activities your child is interested in (Video Production, Game Design, Programming/Coding, Digital Art, Robotics, Web Design, None of these).
* **Preferred Program Type** (id: 16, type: select_one, required: true)
	+ Select the type of program that interests you most (Academic Support, Creative Arts, STEM Activities, Sports and Recreation, Leadership Development, Community Service, Mixed Activities).
* **Preferred Schedule Days** (id: 17, type: select_multiple, required: true)
	+ Select the days of the week that work best for your family.
* **Preferred Time Slot** (id: 18, type: select_one, required: true)
	+ Select the time slot that works best for your schedule (3:00 PM - 4:00 PM, 3:00 PM - 5:00 PM, 3:30 PM - 5:30 PM, 4:00 PM - 6:00 PM, 4:30 PM - 6:30 PM, Flexible schedule).
* **Program Duration Preference** (id: 19, type: select_one, required: true)
	+ Select the duration of the program that you prefer (8 weeks, 12 weeks, 16 weeks, Semester-long, Year-round).
* **Transportation Availability** (id: 20, type: select_one, required: true)
	+ Select how your child will get to and from the program (School bus, Parent/guardian pickup, Walk, Public transportation, Other arrangement).
* **Maximum Program Cost** (id: 22, type: select_one, required: true)
	+ Select the maximum you would pay for a 12-week program (Free (need scholarship), Under $50, $50-$100, $100-$200, $200-$300, Over $300).
* **Financial Assistance Need** (id: 23, type: select_one, required: true)
	+ Select whether you would need financial assistance to participate (True, False, Maybe).
* **Importance of Academic Support** (id: 25, type: number, required: true)
	+ Enter a number between 1 and 5 to indicate how important academic support/enrichment is to you (1-5).
* **Importance of Creative Development** (id: 26, type: number, required: true)
	+ Enter a number between 1 and 5 to indicate how important creative development is to you (1-5).
* **Importance of Physical Activity** (id: 27, type: number, required: true)
	+ Enter a number between 1 and 5 to indicate how important physical activity is to you (1-5).
* **Importance of Social Development** (id: 28, type: number, required: true)
	+ Enter a number between 1 and 5 to indicate how important social development is to you (1-5).
* **Special Needs or Accommodations** (id: 29, type: text, required: false)
	+ Enter any special needs or accommodations your child may have.
* **Ideal Program Size** (id: 31, type: select_one, required: true)
	+ Select the ideal program size that would work best for your child (Small (under 10 students), Medium (10-20 students), Large (over 20 students), No preference).
* **Preferred Program Location** (id: 32, type: select_one, required: true)
	+ Select where you would prefer the program to be held (At school campus, Community center, Library, Local park/recreation center, Online/virtual, No preference).
* **Additional Comments** (id: 33, type: text, required: false)
	+ Enter any other information about your preferences for the after-school program.
