# Course Structure Survey - Help Guide
## Purpose
The purpose of this form is to collect information about a course, including its structure, format, and instructor's details.

## How To Complete This Form

1. Please ensure that you have all the required information about the course.
2. Select the relevant options for each field from the provided list.
3. Enter the course title and description in the first two fields: **Course Organizer** and **Course Description**.
4. Enter the course length in weeks for **Course Length**.
5. Choose the course level: **Beginner**, **Intermediate**, or **Advanced** for **Course Level**.
6. Select the relevant topics for the course: **topic1**, **topic2**, or **topic3** for **Course Topics**.
7. Enter the course format in the **Course Format** field.
8. Enter the instructor's name in the **Instructor Name** field.
9. Enter the course start and end dates for **Course Start Date** and **Course End Date** respectively.
10. Enter the course image URL in the **Course Image URL** field.
11. Enter the course video URL in the **Course Video URL** field (if applicable).
12. Select the evaluation options: **evaluation1**, **evaluation2**, or **evaluation3** for **Evaluations List**.
13. Enter any additional notes or comments about the course in the **Course Outlines** field.
14. Finally, enter the course email and address if required.

## Field-by-Field Explanation

* **Course Organizer** (<id: 1>): Enter the course title.
* **Course Description** (<id: 2>): Enter a brief description of the course.
* **Instructor Name** (<id: 3>): Enter the instructor's name.
* **Course Length** (<id: 4>): Enter the course length in weeks.
* **Course Level** (<id: 5>): Choose the course level: **Beginner**, **Intermediate**, or **Advanced**.
* **Course Topics** (<id: 6>): Select the relevant topics for the course.
* **Course Format** (<id: 7>): Enter the course format.
* **Instructor Availability** (<id: 8>): This field is optional. If applicable, enter the instructor's availability.
* **Course Start Date** (<id: 9>): Enter the course start date.
* **Course End Date** (<id: 10>): Enter the course end date.
* **Instructor Bio** (<id: 11>): This field is optional. Enter the instructor's bio if applicable.
* **Course Image URL** (<id: 12>): Enter the course image URL.
* **Course Video URL** (<id: 13>): Enter the course video URL if applicable.
* **Course File URL** (<id: 14>): This field is optional. Enter the course file URL if applicable.
* **Course Survey Comments** (<id: 15>): This field is optional. Enter any additional comments about the course.
* **Course Survey Feedback** (<id: 16>): Enter any feedback about the course.
* **Instructor Contact** (<id: 17>): Enter the instructor's contact information.
* **Course Venue** (<id: 18>): This field is optional. Enter the course venue if applicable.
* **Course E-mail** (<id: 19>): Enter the course email.
* **Course Address** (<id: 20>): This field is optional. Enter the course address if applicable.
* **Additional Notes** (<id: 21>): This field is optional. Enter any additional notes about the course.
