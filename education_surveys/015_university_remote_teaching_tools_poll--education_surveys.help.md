# University Remote Teaching Tools Poll - Help Guide
## Purpose
This form is designed to gather information from university staff about their usage and preferences of remote teaching platforms. The goal is to inform decisions on which platforms to prioritize for further development and support.

## How To Complete This Form
To complete this form, please follow the instructions below:

1.  Review each question carefully and answer all questions truthfully.
2.  Select the remote teaching platforms you are using or considering using on page 1.
3.  On page 2, indicate on which platforms you are using.
4.  On page 3, identify any improvement priorities you have for remote teaching platforms.
5.  On page 4, select the Jisc survey tools you are familiar with or would like to use.
6.  On page 5, provide feedback on the current remote teaching platforms.
7.  On page 6, suggest improvements on the platforms you are familiar with.
8.  On page 7, provide additional feedback and comments.

## Field-by-Field Explanation

* **What remote teaching platforms are you using or considering using?** (`remote_teaching_platforms`, select_multiple, required: false): This question is asking about the platforms you are using or considering using for remote teaching. Please select all platforms that apply.
* **On which remote teaching platforms are you using?** (`usage_patterns`, select_multiple, required: false): This question is asking about the specific platforms you are using for remote teaching. Please select all platforms that apply.
* **What improvement priorities do you have for remote teaching platforms?** (`improvement_priorities`, select_multiple, required: false): This question is asking about areas for improvement in remote teaching platforms. Please select all priorities that apply.
* **Jisc survey tools?** (`jisc_survey_tools`, select_one, required: false): This question is asking about the Jisc survey tools you are familiar with or would like to use. Please select one of the options.
* **What do you think about the current remote teaching platforms?** (`feedback_on_platforms`, text, required: false): This question is asking for your opinion on the current remote teaching platforms. Please provide a clear and concise answer.
* **On what platforms do you think we should improve?** (`feedback_on_patterns`, text, required: false): This question is asking for suggestions on which platforms should be improved. Please provide a clear and concise answer.
* **Additional feedback** (`additional_feedback`, note, required: false): This question is asking for any additional thoughts or comments you have about remote teaching platforms. Please provide a clear and concise answer.
* **Email** (`email`, email, required: false): This question is for your contact information. Please enter your university email address.
