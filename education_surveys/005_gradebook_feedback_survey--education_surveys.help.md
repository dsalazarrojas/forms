# Gradebook Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback from teachers and staff on the performance of a teacher in a specific term. The feedback is used to provide constructive guidance and support to the teacher to help them improve their teaching skills.

## How To Complete This Form

1. The form has multiple sections with different fields that need to be filled in. Please select the appropriate options and enter the required information in each field.
2. The form is divided into several pages, each representing a different section of the feedback form.
3. Please fill in all the required fields marked with *.

## Field-by-Field Explanation

* **Teacher Feedback** (1): This field is used to capture the teacher's feedback on their performance. Please enter any comments or suggestions you have for the teacher.
* **Gradebook URL** (2): Enter the URL of the gradebook used to access the teacher's gradebook.
* **Teacher Name** (3): Enter the name of the teacher you are providing feedback on.
* **Teacher Rating** (4): Select one of the options to rate the teacher's performance (Excellent, Good, Fair, Poor).
* **Comments** (5): This field is optional and can be used to add any additional comments you have for the teacher.
* **Staff Feedback** (6): Select multiple options to rate the staff member's performance (Excellent, Good, Fair, Poor).
* **Staff Rating** (7): Select multiple options to rate the staff member's performance (Excellent, Good, Fair, Poor).
* **Follow-up Action** (8): Select one of the options to decide on the follow-up action (Send reminders, Follow-up email, Schedule a call).
* **Follow-up Date** (9): Enter the date for the follow-up action.
* **Follow-up Time** (10): Enter the time for the follow-up action.
* **Follow-up Frequency** (11): Select one of the options to decide on the follow-up frequency (After 1 week, After 2 weeks, After 1 month).
* **Term End Date** (12): Select the end of term date (YYYY-MM) for the teacher's performance evaluation.
* **Term End Time** (13): Enter the time for the teacher's performance evaluation.
* **Term End Frequency** (14): Select one of the options to decide on the evaluation frequency (Daily, Weekly, Monthly).
* **Update Frequency** (15): Select one of the options to decide on the update frequency (Daily, Weekly, Monthly).
* **Update Date** (16): Select the date for the update (YYYY-MM).
* **Update Time** (17): Enter the time for the update.
* **Staff E-mail** (18): If you have feedback for the staff member's email address, enter it here.
* **Staff Name** (19): Enter the name of the staff member.
* **Staff Phone** (20): If you have feedback for the staff member's phone number, enter it here.
* **Staff Comments** (21): This field is optional and can be used to add any additional comments for the staff member.
* **Teacher E-mail** (22): If you have feedback for the teacher's email address, enter it here.
* **Teacher Phone** (23): If you have feedback for the teacher's phone number, enter it here.
* **Teacher Comments** (24): This field is optional and can be used to add any additional comments for the teacher.
* **Review Status** (25): Select one of the options to decide on the review status (Review pending, Approved, Rejected).

## Tips

* Please ensure that you fill in all required fields marked with *.
* If a field is not required, you can leave it blank.
* Please select the appropriate options for each field based on your feedback and guidance.
* If you have any additional comments or feedback, please use the comments field.
