# Student Perception Survey - Help Guide
## Purpose
The Student Perception Survey is a tool designed to gather feedback from students about their experiences with their classes and teachers. This survey is used to collect information about how students perceive their classes, teachers, and learning environment.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Enter your Student ID in the "Student Id" field.
2.  Enter your teacher's ID in the "Teacher Id" field.
3.  Enter your class ID in the "Class Id" field.
4.  Enter your course ID in the "Course Id" field.
5.  Answer the questions in the following format:
    *   For questions 1, 3, 5, and 7, select one option from the provided list.
    *   For questions 2, 4, and 6, select multiple options from the provided list.

## Field-by-Field Explanation
*   **Student Id (Student Id, number, required: false):** Enter your student ID.
*   **Teacher Id (Teacher Id, number, required: false):** Enter your teacher's ID.
*   **Class Id (Class Id, number, required: false):** Enter your class ID.
*   **Course Id (Course Id, number, required: false):** Enter your course ID.
*   **How often do you think the teacher asks for feedback? (How often do you think the teacher asks for feedback?, select_one, required: false):** Select one option from the list to describe how often you think the teacher asks for feedback.
*   **How do you rate the class work environment? (How do you rate the class work environment?, select_multiple, required: false):** Select multiple options from the list to describe how you rate the class work environment.
*   **How would you rate the teacher's teaching style? (How would you rate the teacher's teaching style?, select_one, required: false):** Select one option from the list to describe how you rate the teacher's teaching style.
*   **How do you feel about the class work schedule? (How do you feel about the class work schedule?, select_multiple, required: false):** Select multiple options from the list to describe how you feel about the class work schedule.
*   **Do you like the class size? (Do you like the class size?, select_one, required: false):** Select one option from the list to describe how you like the class size.
*   **Would you recommend this class to other students? (Would you recommend this class to other students?, select_one, required: false):** Select one option from the list to describe whether you would recommend this class to other students.
