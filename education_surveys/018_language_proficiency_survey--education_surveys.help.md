# Language Proficiency Survey - Help Guide
## Purpose
The Language Proficiency Survey is a form designed to evaluate an individual's language proficiency in various language skills. This survey is used to assess a person's ability to communicate effectively in each of the language skills listed below.

## How To Complete This Form
To complete this form, follow these steps:

1. Carefully read each question carefully and answer accordingly.
2. For multiple-choice questions, select the correct option that best describes your language proficiency level.
3. For text questions, provide a clear and concise answer.
4. Make sure to answer all questions as accurately as possible.
