# Text Interpretation Survey - Help Guide

## Purpose
The Text Interpretation Survey is designed to gather feedback on the interpretability of text passages provided to users. This form helps us understand how users interact with and understand the text, including whether they can easily interpret its meaning and purpose. Your input will help us improve our text-based content.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review the survey passage provided to you.
2.  For each question, select the option that best answers the question or provide a note if you have any further comments.
3.  Make sure to fill in any required fields.
4.  Submit your response once you have completed all questions.

## Field-by-Field Explanation

* **survey_passage** (Select Multiple, Not Required): Select all that apply when the provided passage is interpretable, not interpretable, or if you would like more information.
	+ Select 'Yes' if you can easily understand the passage and its meaning.
	+ Select 'No' if you have trouble understanding the passage and its meaning.
* **interpretation** (Text, Not Required): Share your understanding of the passage, or how you think others might interpret it.
* **passage_text** (Text, Not Required): If you feel there is any information missing or if you have additional comments about the passage, please include them here.
* **researcher** (Text, Not Required): If you are a researcher, please share any relevant background or credentials that might help us better understand your response.
* **study** (Text, Not Required): If you are taking part in a study, please provide the study details that might be relevant to our analysis.
* **language** (Select One, Not Required): Select whether the language used in the passage was clear and interpretable to you.
	+ Select 'Yes' if the language was clear and easy to understand.
	+ Select 'No' if the language was not clear or confusing.
* **learning** (Select Multiple, Not Required): Select all that apply when you learned new things from the passage or would like to see more examples like it.
	+ Select 'Yes' if you learned something new from the passage.
	+ Select 'No' if you did not learn anything new.
* **ux** (Text, Not Required): Share any additional comments or observations you have about the user experience with the passage.
* **notes** (Note, Not Required): If you have any further comments or observations, please include them in the box below.
* **email** (Email, Not Required): If you want to be contacted for further discussion or clarification, please provide your email address.
* **phone** (Text, Not Required): If you want to be contacted by phone for further discussion or clarification, please provide your phone number.
