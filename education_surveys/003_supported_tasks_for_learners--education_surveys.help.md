# Supported Tasks For Learners - Help Guide
## Purpose
This form is designed to collect information about the types of tasks that learners feel they need support with and their levels of satisfaction with these supports. The collected data will be used to understand areas where learners need improvement and inform support systems.

## How To Complete This Form
1. Select all the tasks from the "Supported Tasks" drop-down menu that apply to you.
2. Indicate whether you need support with any of the tasks listed.
3. Choose one option from the "Learner Support Needs" drop-down menu that best describes your level of support needs.
4. Choose one option from the "Help Methods" drop-down menu that describes the primary method(s) you use to get help when you need it.
5. If you have chosen "No" for "Learner Support Needs", you can provide more information about your support needs in the "Learner Support Needs (Other)" text field.
6. Select one option from the "Satisfaction Levels" drop-down menu that describes your level of satisfaction with the support you receive.
7. If you have chosen "No" for "Help Methods", you can provide more information about the methods you use in the "Other Methods" text field.
8. If you have chosen "Dissatisfied" for "Satisfaction Levels", you can provide more information about why you are dissatisfied with the support in the "Satisfaction Levels (Other)" text field.

## Field-by-Field Explanation

* **Supported Tasks** (`Supported Tasks`, Select Multiple, Required):
	+ Use this field to select all the tasks that you need support with while learning. You can select one or more options from the drop-down menu.
* **Learner Support Needs** (`Learner Support Needs`, Select One, Required):
	+ This field describes your level of support needs. Choose one option that best fits your needs.
* **Help Methods** (`Help Methods`, Select One, Required):
	+ This field describes the primary method(s) you use to get help when you need it. Choose one option that best fits your needs.
* **Other Help Methods** (`Other Help Methods`, Select Multiple, Required):
	+ If you selected "No" for "Help Methods", use this field to provide more information about the methods you use to get help.
* **Learner Support Needs (Other)** (`Learner Support Needs (Other)`, Select Multiple, Required):
	+ If you selected "No" for "Learner Support Needs", use this field to provide more information about your support needs.
* **Learner Feedback** (`Learner Feedback`, Note, Required):
	+ This field is for you to provide any additional feedback about your experience with the support systems.
* **Satisfaction Levels** (`Satisfaction Levels`, Select One, Required):
	+ This field describes your level of satisfaction with the support you receive. Choose one option that best fits your experience.
* **Satisfaction Levels (Other)** (`Satisfaction Levels (Other)`, Select One, Required):
	+ If you selected "Dissatisfied" for "Satisfaction Levels", use this field to provide more information about why you are dissatisfied with the support.
* **Other Methods** (`Other Methods`, Select Multiple, Required):
	+ If you selected "No" for "Help Methods", use this field to provide more information about the methods you use to get help.
* **Help Methods (Other)** (`Help Methods (Other)`, Select Multiple, Required):
	+ If you selected "No" for "Help Methods", use this field to provide more information about the methods you use to get help.
