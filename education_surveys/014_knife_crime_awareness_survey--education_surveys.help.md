# Knife Crime Awareness Survey - Help Guide
## Purpose
The Knife Crime Awareness Survey is designed to gather information on the community's perceptions of safety, knowledge levels, and willingness to report crimes. The survey aims to inform the development of initiatives to improve safety and reduce crime in the community.

## How To Complete This Form
To complete this form, please follow these steps:

* Carefully read each question and its corresponding explanation to ensure you understand what is being asked.
* Complete each section one by one, starting with the first page.
* Use the provided options to answer each question, and if you have any additional comments or feedback, please use the designated text fields.
* Make sure to submit the form once you have completed all the necessary questions.

## Field-by-Field Explanation

### Page 1: Introduction
* **Introduction** (`introduction`, `note`, not required): This is a brief introduction to the survey. Please read it carefully before proceeding to the next section.

### Page 2: Safety Perceptions
* **Safety Perceptions** (`safety_perceptions`, `select_multiple`, not required): Please select all the options that best describe your safety perceptions in the community.
    + Yes
    + No

### Page 3: Knowledge Level
* **Knowledge Level** (`knowledge_level`, `text`, not required): Please provide a brief description of your knowledge level regarding knife crime in the community.

### Page 4: Crime Reporting
* **Crime Reporting** (`crime_reporting`, `number`, not required): Please indicate how often you report crimes in the community.
    + 1 (very often)
    + 2 (often)
    + 3 (rarely)
    + 4 (never)

### Page 5: Reporting Crime
* **Reporting Crime** (`reporting_crime`, `number`, not required): Similar to the previous question, please indicate how often you report crimes in the community.
    + 1 (very often)
    + 2 (often)
    + 3 (rarely)
    + 4 (never)

### Page 6: Support Services
* **Support Services** (`support_services`, `text`, not required): If you need any support or services in the community, please provide your suggestions.

### Page 7: Prevention Efforts
* **Prevention Efforts** (`prevention_efforts`, `select_one`, not required): Please select all the options that best describe your perceptions of prevention efforts in the community.
    + Yes
    + No

### Page 8: Community Feedback
* **Community Feedback** (`community_feedback`, `text`, not required): If you have any suggestions or feedback on how to improve the community's safety and reduce crime, please provide them.

### Page 9: Contact Us
* **Contact Us** (`contact_us`, `email`, not required): If you need to contact us for any reason, please provide your email address.

### Page 10-16: Comments
* **Comments** (`comments`, `text`, not required): Please provide any additional comments or feedback you may have.

Note: All fields are optional, but please make sure to complete all the necessary questions to ensure that your feedback is as comprehensive as possible.
