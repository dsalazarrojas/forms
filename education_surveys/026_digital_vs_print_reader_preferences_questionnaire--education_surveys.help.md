# Digital Vs. Print Reader Preferences Questionnaire - Help Guide

## Purpose
The purpose of this form is to collect information about an individual's reading habits, format preferences, and device usage to help inform decisions on content creation and distribution.

## How To Complete This Form
To complete this form, simply follow the instructions below for each field.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `note`, not required): This is a brief introduction to the questionnaire. Please read it carefully before proceeding.
* **Demographic Information** (`demographic_info`, `select_multiple`, not required):
	+ This section is about your personal demographic information, such as your gender. Please select all that apply.
* **Preferred Format** (`preferred_format`, `select_one`, not required): 
	+ This is asking about your preferred way of consuming information: do you prefer digital or print, or a mix of both?
* **How Often Do You Read** (`reading_frequency`, `select_one`, not required):
	+ This question is asking about how often you read. Please select the frequency that best describes your reading habits.
* **Device Usage** (`device_usage`, `select_multiple`, not required):
	+ This section is about the devices you use to read. Please select all that apply.
* **Where Do You Read?** (`reading_location`, `select_multiple`, not required):
	+ This question is asking about where you usually read. Please select all that apply.
* **How Long Do You Spend Reading?** (`reading_length`, `select_one`, not required):
	+ This question is asking about how long you spend reading. Please select the time frame that best describes your reading habits.
* **Preferred Format for Reading Materials** (`preferred_format_for_reading_materials`, `select_multiple`, not required):
	+ This section is asking about your preferred format for reading materials. Please select all that apply.
* **Format of Materials Purchased** (`format_purchasing`, `select_multiple`, not required):
	+ This question is asking about the format of materials you purchase. Please select all that apply.
* **Format of Materials Shared** (`format_shared`, `select_multiple`, not required):
	+ This section is about the format of materials you share. Please select all that apply.
* **Format of Materials Retained** (`format_retained`, `select_multiple`, not required):
	+ This question is asking about the format of materials you retain. Please select all that apply.
* **Format of Materials Discarded** (`format_discarded`, `select_multiple`, not required):
	+ This section is about the format of materials you discard. Please select all that apply.
* **Reading Habits** (`reading_habits`, `note`, not required):
	+ This is a free-text field for you to describe your reading habits in more detail.
* **Additional Comments** (`additional_comments`, `note`, not required):
	+ This is a free-text field for any additional information you would like to provide.

## Tips
* Please answer each question honestly and to the best of your ability.
* You can select all that apply for each question.
* If you are unsure about any question, please feel free to ask for clarification.
* Your responses will be used to inform decisions on content creation and distribution.
