# Practice Test Creation Survey - Help Guide

## Purpose

This form is designed to gather feedback on the creation of practice tests. It has eight pages, and you will be asked to answer a series of questions to help us understand your thoughts on creating practice tests. Please answer the questions to the best of your ability and provide as much detail as possible.

**Check:**

- Are you an educator, a tutor, or someone responsible for creating practice tests?
- Do you have any existing practice tests that you'd like to share with us?

## How To Complete This Form

1. Please review each page of the form and answer the questions according to your experience and knowledge.
2. For questions with multiple options, select all that apply.
3. You can skip questions that do not apply to you.
4. Please be as detailed as possible in your answers.

## Field-by-Field Explanation

* **Introduction** (`practice_test_creation_survey_page_1`, note, not required): This page serves as an introduction to the practice test creation process. Please provide any general comments or thoughts on creating practice tests.
* **Challenges** (`practice_test_challenges`, select_one, not required): We are interested in hearing about any challenges you have faced while creating practice tests. Please select all challenges that apply.
	+ Yes: I have faced challenges while creating practice tests.
	+ No: I have not faced challenges while creating practice tests.
* **Creation Insights** (`practice_test_creation_insights`, select_multiple, not required): Please provide us with any insights you have gained while creating practice tests. Select all that apply.
	+ Yes: I have gained insights while creating practice tests.
	+ No: I have not gained insights while creating practice tests.
* **Prioritization** (`practice_test_prioritization`, select_one, not required): We are interested in how you prioritize the creation of practice tests. Please select one of the following.
	+ Yes: I prioritize creating practice tests based on student needs.
	+ No: I prioritize creating practice tests based on other factors.
* **Description** (`education_surveys_description`, text, not required): Please provide a brief description of your experience with creating practice tests.
* **Educators** (`education_surveys_educators`, select_multiple, not required): We are interested in how you work with educators. Please select all that apply.
	+ Yes: I work with educators.
	+ No: I do not work with educators.
* **Tutors** (`education_surveys_tutors`, select_one, not required): We are interested in how you collaborate with tutors. Please select one of the following.
	+ Yes: I work with tutors.
	+ No: I do not work with tutors.
* **Training Teams** (`education_surveys_training_teams`, select_multiple, not required): We are interested in how you work with training teams. Please select all that apply.
	+ Yes: I work with training teams.
	+ No: I do not work with training teams.
