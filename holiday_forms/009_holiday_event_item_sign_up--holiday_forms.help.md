# Holiday Event Item Sign Up - Help Guide
## Purpose
This form is designed to collect information about holiday events, allowing hosts to manage and coordinate their gatherings more efficiently.

## How To Complete This Form
1. Fill in the "Host Details" field with the name and any other relevant information about the host.
2. Enter the name and email of the first guest in the "Guest 1" fields.
3. Enter the name and email of the second guest in the "Guest 2" fields, if applicable.
4. Select any dietary restrictions for each guest in the "Dietary Restrictions" fields, using the provided options (e.g., Vegetarian, Vegan, Gluten Free).
5. Choose the type of food items that will be available at the event in the "Food Items" fields, using the provided options (e.g., Fruits, Vegetables, Dairy, Meats, Desserts).
6. Select the type of contribution each guest can make (Host, Guest, Both) in the "Contribution Type" fields.
7. Add any additional notes or comments about the event or guest in the "Notes" field.
8. Finally, submit the form to complete the holiday event information.

## Field-by-Field Explanation
* **Host Details**: Enter the name and any other relevant information about the host.
* **Guest 1**: Enter the name and email of the first guest.
* **Guest 2**: Enter the name and email of the second guest, if applicable.
* **Host Email**: Enter the host's email address, which will be used for communication.
* **Dietary Restrictions**: Select any dietary restrictions for each guest, using the provided options.
* **Food Items**: Choose the type of food items that will be available at the event.
* **Contribution Type**: Select the type of contribution each guest can make.
* **Notes**: Add any additional comments or notes about the event or guest.
* **Submit**: Review and submit the form to complete the holiday event information.
