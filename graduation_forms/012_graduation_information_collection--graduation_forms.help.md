## Graduation Information Collection - Help Guide

### Purpose
This form is used to collect graduation information from students. It is intended to help staff members efficiently and accurately gather the necessary details for graduation ceremonies.

### How to Complete This Form
To complete this form, please follow these steps:

1. Ensure you have the necessary permissions and clearance to access and complete this form.
2. Read each field carefully and enter the required information accurately.
3. Select the relevant options for each field as required.
4. Enter all required fields before proceeding to the next step.
5. Review your submissions before finalizing them.

### Field-by-Field Explanation

* **Graduation Information Collection Form** (Required)
	+ A brief note to explain the purpose of the form.
* **Commencement Date** (Required)
	+ Please enter the date of the student's commencement.
* **Ceremony Participation** (Required)
	+ Select whether the student will participate in the ceremony.
* **Graduation Time** (Optional)
	+ Select the time of the student's graduation.
* **Student Data Submission** (Required)
	+ Please provide student name, email, and other contact information.
* **Graduation Date Subscribed** (Required)
	+ A numerical value indicating the graduation date status.
* **Student Name** (Required)
	+ Please enter the student's name.
* **Email Address** (Required)
	+ Please enter the student's email address.
* **Confirm Email Address** (Required)
	+ Confirm the student's email address.
* **Student Phone Number** (Optional)
	+ Please enter the student's phone number.
* **Confirm Student Phone Number** (Optional)
	+ Confirm the student's phone number.
* **Ceremony Participation Subscribed** (Required)
	+ A numerical value indicating the ceremony participation status.
* **Ceremony Details Subscribed** (Required)
	+ A numerical value indicating the ceremony details status.
* **Student Data Submission Submitted** (Required)
	+ A numerical value indicating the student data submission status.
* **Ceremony Participation Status** (Optional)
	+ Select whether the student participates in the ceremony.
* **Graduation Ceremony Date Subscribed** (Required)
	+ Please enter the graduation ceremony date.
* **Graduation Ceremony Time Submitted** (Required)
	+ Please enter the graduation ceremony time.
* **Submission Confirmation** (Required)
	+ Confirm whether the submission is true or false.
* **Submitted By** (Required)
	+ Please enter the staff member's name who submitted the form.
* **Date Submitted** (Required)
	+ A date indicating the form was submitted.
* **Time Submitted** (Required)
	+ A time indicating the form was submitted.
* **Submission ID** (Required)
	+ Please enter the submission ID.
* **Submission Time Submitted** (Required)
	+ A numerical value indicating the submission time status.
* **Student Data Collection Details** (Required)
	+ A note for staff members to record collection details.
* **Submission Status** (Optional)
	+ Select whether the submission is submitted, in progress, or not started.
