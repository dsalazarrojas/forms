# University Valedictorian Selection Voting Form - Help Guide
## Purpose
This form is for voting on the valedictorian for the current university graduation ceremony. Please select the candidate you want to see as valedictorian.

## How To Complete This Form
1. Fill out the form completely, making sure to select one candidate for each selection.
2. If a field is not required, you can leave it empty.
3. Enter your email address and phone number (if applicable) so we can contact you with the results.
4. Enter any additional comments or notes if you have any.
