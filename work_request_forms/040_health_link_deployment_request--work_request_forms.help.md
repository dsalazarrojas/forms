# health link deployment request - Help Guide
## Purpose
This form is used to collect information about the deployment of health links in a deployment request.

## How To Complete This Form

To complete this form, follow these steps:

1. **Deployment Request**: Fill in the Deployment Request field with a brief description of the health link deployment.
2. **Scheduled Start Date**: Enter the date you plan to start the health link deployment.
3. **Scheduled End Date**: Enter the date you plan to complete the health link deployment.
4. **Planned Duration**: Enter the number of days the health link deployment will take.

## Field-by-Field Explanation
* **Deployment Request**: A brief description of the health link deployment request.
* **Scheduled Start Date**: The date on which you plan to start the health link deployment. 
* **Scheduled End Date**: The date on which you plan to complete the health link deployment.
* **Planned Duration**: The number of days the health link deployment will take.

## Tips

- Make sure to enter accurate and relevant information in each field.
- Double-check that all fields are filled out before submitting the form.
- If you have any questions or need further clarification, please don't hesitate to reach out to our support team.
