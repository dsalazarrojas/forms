# Work Health & Safety Hazard Register Example - Help Guide
## Purpose
This form is used to register and track hazards in the workplace, ensuring employee safety and compliance with regulations.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the relevant category for the hazard (e.g. Work Request Forms, Other).
2. Provide a brief description of the hazard.
3. Choose the tool or resource currently assigned to address the hazard (e.g. chatjimmy, Other).
4. Upload any relevant output file.
5. Optionally, provide additional form IDs for further reference.
6. Enter a title for the hazard.
7. Provide a detailed description of the hazard.

## Field-by-Field Explanation
* **Category** (2): Select the category for the hazard (e.g. Work Request Forms, Other).
* **Description** (3): Enter a brief description of the hazard.
* **Assigned Tool** (4): Choose the tool or resource currently assigned to address the hazard (e.g. chatjimmy, Other).
* **Output File** (5): Upload any relevant output file.
* **Form IDs** (6): Optionally, provide additional form IDs for further reference.
* **Title** (7): Enter a title for the hazard.
* **Description** (8): Provide a detailed description of the hazard.
 

## Tips
- Ensure that all hazards are thoroughly documented and addressed to maintain a safe working environment.
- If a hazard has no assigned tool, select "Other" to indicate that one is pending.
