# Weekend Maintenance Registration - Help Guide
## Purpose
The Weekend Maintenance Registration form is a tool for maintenance personnel to submit requests for weekend maintenance activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information for the maintenance activity.
2. Make sure to select the correct "Assigned To" field based on your role and responsibilities.
3. Provide a clear and concise description of the maintenance activity in the "Work Description" field.
4. If necessary, add any safety concerns or notes in the "Safety Concerns" field.
5. Choose the correct category for the maintenance activity in the "Category" field.
6. Select the status of the maintenance request in the "Status" field.
7. Add any additional comments or notes in the "Comments" field.

## Field-by-Field Explanation

* **User (text)**: Enter your name and contact information.
* **Request Date (date)**: Enter the date when you would like to schedule the maintenance activity.
* **Request Time (time)**: Enter the time when you would like to schedule the maintenance activity.
* **Location (text)**: Enter the location where the maintenance will take place.
* **Work Description (text)**: Describe the maintenance activity in a few sentences.
* **Safety Concerns (note)**: If there are any safety concerns or notes related to the maintenance activity, enter them here.
* **Assigned To (select_one)**: Indicate if the maintenance request is assigned to a specific person or team.
* **Category (select_multiple)**: Choose the category for the maintenance activity (e.g., Electrical, Plumbing, etc.).
* **Status (select_one)**: Select the current status of the maintenance request (e.g., Active, Inactive, etc.).
* **Comments (text)**: Add any additional comments or notes about the maintenance request.
* **Scheduled Date (date)**: Enter the scheduled date for the maintenance activity.
* **Scheduled Time (time)**: Enter the scheduled time for the maintenance activity.
