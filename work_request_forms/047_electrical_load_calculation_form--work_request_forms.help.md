# Electrical Load Calculation Form - Help Guide
## Purpose
This form is designed to calculate electrical load requirements for various electrical equipment and systems. It will help you determine the electrical load calculation based on the provided information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the **User Input** section with your name and any other relevant details.
2.  In the **Electrical Equipment** section, enter the type and size of the electrical equipment you're working with.
3.  In the **Calculating Value** section, select the relevant options from the drop-down menus and fill out the numerical values as required.
4.  Review and confirm your input before submitting the form.

* **Device Rating (11)**: Select the device rating from the drop-down menu.
* **Power Factor (12)**: Select the power factor from the drop-down menu.
