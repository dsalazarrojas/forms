# Floodlight Maintenance Request Form - Help Guide

## Purpose
This form is designed to help users submit a request for floodlight maintenance to the facility management team.

## How To Complete This Form

To submit a maintenance request for a floodlight, please complete the following steps:

1. Fill in the `Facility ID` field with the correct ID number.
2. Enter a brief description of the issue you are experiencing with the floodlight in the `Issue description` field.
3. Select the `Priority` of the issue from the dropdown list (Low, Medium, or High).
4. Enter the name of the person or team requesting the service in the `Service requestor` field.
5. Optionally, provide any additional comments about the issue in the `Comments` field.
6. Click submit to send the request to the facility management team for processing.

## Field-by-Field Explanation

### Facility ID
* **Facility ID** (`facility_id`, `select_one`, required): Enter the ID number of the facility where the floodlight is located. This will help the management team identify the correct location for maintenance.

### Issue description
* **Issue description** (`issue_description`, `text`, required): Briefly describe the problem you are experiencing with the floodlight. This will help the management team understand the nature of the issue.

### Priority
* **Priority** (`priority`, `select_one`, required): Select the level of urgency for the maintenance request. This will help the management team prioritize the request accordingly.

### Service requestor
* **Service requestor** (`service_requestor`, `text`, required): Enter the name of the person or team requesting the service. This will help the management team track who submitted the request.

### Comments
* **Comments** (`comments`, `text`, optional): Provide any additional information about the issue in this field. This can be useful for the management team to have a better understanding of the problem.

### Scheduled service
* **Scheduled service** (`scheduled_service`, `date`, optional): If a specific date for the service is desired, enter the date here. This will help the management team schedule the maintenance accordingly.

Note: If you are unsure about any of the fields, please do not hesitate to contact the facility management team for assistance.
