# Work Ticket Form - Help Guide
## Purpose
The Work Ticket Form is a tool used to collect information from requesters for various tasks and requests.

## How To Complete This Form
To complete this form, follow these steps:
* Fill in the requested information, including requester name, email, phone number, and any additional details.
* Provide a note or comment if necessary.
* Choose a department and location for the request, if applicable.
* Select a time slot for the request, if necessary.
* Mark if the request is urgent or not.
* Choose who to assign the request to (e.g. chatjimmy or other).

## Field-by-Field Explanation
* **Request Form** (`request_form`, text, optional): A short description of the request.
* **Request Details** (`request_details`, text, optional): Additional details about the request.
* **Requester Name** (`requester_name`, text, optional): The name of the person requesting the task.
* **Requester Email** (`requester_email`, email, optional): The email address of the person requesting the task.
* **Requester Phone** (`requester_phone`, text, optional): The phone number of the person requesting the task.
* **Requester Note** (`requester_note`, note, optional): A note for the person requesting the task.
* **Requester Comment** (`requester_comment`, text, optional): A comment for the person requesting the task.
* **Requester Department** (`requester_department`, text, optional): The department of the person requesting the task.
* **Requester Location** (`requester_location`, text, optional): The location of the person requesting the task.
* **Requester Date** (`requester_date`, date, optional): The date of the request.
* **Requester Time** (`requester_time`, time, optional): The time of the request.
* **Requester Urgent** (`requester_urgent`, text, optional): A flag indicating whether the request is urgent or not.
* **Requester Assign** (`requester_assign`, select one, optional): Choose who to assign the request to (e.g. chatjimmy or other).
