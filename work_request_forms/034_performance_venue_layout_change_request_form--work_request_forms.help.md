# Performance Venue Layout Change Request Form - Help Guide
## Purpose
The purpose of this form is to submit a request to make changes to the performance venue layout. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "category" field to indicate whether this is a 'Yes' or 'No' request.
2. Provide a detailed description of the changes you wish to make to the performance venue layout in the "description" field.
3. Enter the date of the change in the "date_of_change" field in the format MM/DD/YY.
4. Enter the time of the change in the "time_of_change" field in the format HH:MM:SS AM/PM.
5. Enter your contact name in the "contact_name" field.
6. Enter your contact phone number in the "contact_phone" field.
7. Enter your contact email in the "contact_email" field.
8. Provide any additional comments about the request in the "comments" field.
9. If applicable, select the tool used for the change in the "assigned_tool" field.
10. Enter the venue in the "venue" field.
11. Enter the area in the "area" field.
12. Enter the floor in the "floor" field.
13. Enter the room in the "room" field.
14. Enter the section in the "section" field.
15. Provide any additional comments about the request in the "comments" field.
16. Enter the details of the change request in the "change_request_details" field.
17. If applicable, enter the name of the person who approved the request in the "approved_by" field.
18. If applicable, enter the date the request was approved in the "approved_on" field.
19. If the request was rejected, enter the reason for rejection in the "rejected_reason" field.
20. Enter any additional notes about the request in the "notes" field.
21. Select the status of the request in the "status" field.
22. Enter the name of the person who submitted the request in the "created_by" field.

## Field-by-Field Explanation
* **category** (`category`, Select One, required/optional): 
  Indicates whether this is a 'Yes' or 'No' request.
* **description** (`description`, Note, required/optional): 
  Provide a detailed description of the changes you wish to make to the performance venue layout.
* **date_of_change** (`date_of_change`, Date, required/optional): 
  Enter the date of the change in the format MM/DD/YY.
* **time_of_change** (`time_of_change`, Time, required/optional): 
  Enter the time of the change in the format HH:MM:SS AM/PM.
* **contact_name** (`contact_name`, Text, required/optional): 
  Enter your name.
* **contact_phone** (`contact_phone`, Text, required/optional): 
  Enter your contact phone number.
* **contact_email** (`contact_email`, Email, required/optional): 
  Enter your contact email.
* **comments** (`comments`, Note, required/optional): 
  Provide any additional comments about the request.
* **submitted_by** (`submitted_by`, Text, required/optional): 
  Enter the name of the person who submitted the request.
* **assigned_tool** (`assigned_tool`, Select One, required/optional): 
  If applicable, select the tool used for the change.
* **submitted_for** (`submitted_for`, Text, required/optional): 
  Enter the reason for the request.
* **venue** (`venue`, Text, required/optional): 
  Enter the venue in question.
* **area** (`area`, Text, required/optional): 
  Enter the area in the venue.
* **floor** (`floor`, Text, required/optional): 
  Enter the floor in the venue.
* **room** (`room`, Text, required/optional): 
  Enter the room in the venue.
* **section** (`section`, Text, required/optional): 
  Enter the section in the room.
* **comments** (`comments`, Note, required/optional): 
  Provide any additional comments about the request.
* **change_request_details** (`change_request_details`, Text, required/optional): 
  Enter the details of the change request.
* **approved_by** (`approved_by`, Text, required/optional): 
  If applicable, enter the name of the person who approved the request.
* **approved_on** (`approved_on`, Date, required/optional): 
  If applicable, enter the date the request was approved.
* **rejected_reason** (`rejected_reason`, Note, required/optional): 
  If the request was rejected, enter the reason for rejection.
* **notes** (`notes`, Note, required/optional): 
  Enter any additional notes about the request.
* **status** (`status`, Select One, required/optional): 
  Select the status of the request.
* **created_by** (`created_by`, Text, required/optional): 
  Enter the name of the person who submitted the request.

## Tips
- Please ensure that you have not already submitted a similar request.
- Fill out the form accurately and thoroughly to ensure that your request is processed efficiently.
- If you have any questions or need help, contact the performance venue management team.
- The status of your request can be one of the following: Active, Inactive.
