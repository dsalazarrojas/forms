# Maintenance Work Order Form - Help Guide

## Purpose
The Maintenance Work Order Form is a tool used to collect and track information for maintenance work orders. This form gathers details such as equipment type, maintenance type, work requestor, and schedule information to ensure efficient and effective maintenance processes.

## How To Complete This Form
1. **Fill out the form completely and accurately**. The form is divided into two pages.
2. **Page 1: Maintenance Information**
	* Enter a brief description of the maintenance work order in the text field.
3. **Page 2: Equipment and Schedule Information**
	* Select the **Equipment Type** and **Equipment Model** that need maintenance.
	* Choose the **Maintenance Work Order Type** from the options provided.
	* Select the **Work Requestor** responsible for the maintenance work order.
	* Choose the **Shift** during which the maintenance will take place.
	* Enter the **Start Date** and **Start Time** of the maintenance work order.
	* Enter the **End Date** and **End Time** of the maintenance work order.
4. **Submit the form** once you have filled out all required fields.

## Field-by-Field Explanation

* **Maintenance Information**
	+ **Equipment Model**: Enter the model of the equipment that requires maintenance.
	+ **Equipment Type**: Select the type of equipment that needs maintenance.
	+ **Maintenance Work Order Type**: Choose the type of maintenance work order from the options provided.
* **Equipment and Schedule Information**
	+ **Equipment Description**: Enter a brief description of the equipment that requires maintenance.
	+ **Equipment Type**: Select the type of equipment that needs maintenance.
	+ **Equipment Serial Number**: Enter the serial number of the equipment.
	+ **Location**: Enter the location of the equipment.
	+ **Maintenance Cost**: Enter the estimated cost of the maintenance work order.
	+ **Work Status**: Enter the current status of the maintenance work order.
	+ **Work Status Notes**: Enter any additional notes about the work status.
	+ **Reason for Maintenance**: Enter a brief reason for the maintenance work order.
* **Work Requestor and Schedule Information**
	+ **Work Requestor**: Select the person responsible for the maintenance work order.
	+ **Shift**: Select the shift during which the maintenance will take place.
	+ **Start Date**: Enter the start date of the maintenance work order.
	+ **Start Time**: Enter the start time of the maintenance work order.
	+ **End Date**: Enter the end date of the maintenance work order.
	+ **End Time**: Enter the end time of the maintenance work order.
* **Assignment and Status Information**
	+ **Assigned To**: Select the person or team responsible for the maintenance work order.
	+ **Assigned Tool**: Enter the tool assigned to the maintenance work order.
	+ **Assigned Jimmy**: Enter the name of the person assigned to the maintenance work order.
	+ **Assigned Tommy**: Enter the name of the person assigned to the maintenance work order.
	+ **Assigned Bob**: Enter the name of the person assigned to the maintenance work order.
* **Additional Information**
	+ **Work Order Status**: Select the current status of the maintenance work order.
	+ **Assigned**: Select whether the maintenance work order is assigned to someone.
