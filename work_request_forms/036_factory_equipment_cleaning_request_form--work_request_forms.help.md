# Factory Equipment Cleaning Request Form - Help Guide
## Purpose
This form is used to request cleaning for factory equipment. Fill out this form to submit a request for cleaning, providing details about the equipment and the desired cleaning schedule.

## How To Complete This Form
1. Select "Yes" or "No" for the equipment's current cleaning status.
2. Enter the details of the equipment that needs cleaning.
3. Select the priority level for the cleaning (if applicable).
4. Select the frequency of cleaning (if applicable).
5. Enter the method of cleaning (if applicable).
6. Provide any additional comments about the equipment or cleaning process.
7. Enter the name of the person responsible for the cleaning contact.
8. If applicable, select who the request is assigned to.
9. Choose the current status of the request.
10. Select "Yes" or "No" for whether the request is active or not.
11. Enter the date and time when the request was created.
12. Enter the date and time when the request was modified.
13. Enter the date and time when the request was last updated.
14. Enter the date and time for when the request is due (if applicable).
15. Select the date and time when the request is due (if applicable).
16. Enter the date and time when the request was created (again, for consistency).
17. Enter the date and time when the request was modified (again, for consistency).
18. Enter the date and time when the request was last updated (again, for consistency).
19. Enter the date and time when the request was created (a third iteration).
20. Enter the date and time when the request was modified (a third iteration).
21. Enter the date and time when the request was last updated (a third iteration).
22. Enter any additional comments about the request.

## Field-by-Field Explanation
* **Submit Request (1)** (`factory_equipment_cleaning_request_form_page_1`, select_multiple, required): Select "Yes" or "No" to indicate whether the request is for a new cleaning or not.
* **Equipment Details (2)** (`equipment_details`, text, required): Enter a description of the equipment that needs cleaning.
* **Cleaning Priority (3)** (`cleaning_priority`, select_one, required): Select the priority level for the cleaning (if applicable).
* **Cleaning Frequency (4)** (`cleaning_frequency`, select_one, required): Select the frequency of cleaning (if applicable).
* **Cleaning Method (5)** (`cleaning_method`, text, required): Enter the method of cleaning (if applicable).
* **Comments (6)** (`comments`, note, required): Provide any additional comments or information about the cleaning process.
* **Contact Person (7)** (`contact_person`, text, required): Enter the name of the person responsible for the cleaning contact.
* **Assign to (8)** (`assigned_to`, select_one, required): Select who the request is assigned to.
* **Status (9)** (`status`, select_one, required): Choose the current status of the request.
* **Created By (10)** (`created_by`, text, required): Enter the name of the person who created the request.
* **Created At (11)** (`created_at`, time, required): Enter the date and time when the request was created.
* **Modified By (12)** (`modified_by`, text, required): Enter the name of the person who modified the request.
* **Modified At (13)** (`modified_at`, time, required): Enter the date and time when the request was modified.
* **Updated By (14)** (`updated_by`, text, required): Enter the name of the person who last updated the request.
* **Updated At (15)** (`updated_at`, time, required): Enter the date and time when the request was last updated.
* **Due By (16)** (`due_by`, date, required): Enter the date when the request is due (if applicable).
* **Due Date (17)** (`due_date`, date, required): Select the date and time when the request is due (if applicable).
* **Due Time (18)** (`due_time`, time, required): Select the time when the request is due (if applicable).
* **Created (19)** (`created_at_2`, date, required): Enter the date when the request was created (for consistency).
* **Modified (20)** (`modified_at_2`, date, required): Enter the date when the request was modified (for consistency).
* **Updated (21)** (`updated_at_2`, date, required): Enter the date when the request was last updated (for consistency).
* **Created At 3 (22)** (`created_at_3`, time, required): Enter the date and time when the request was created (a third iteration).
* **Modified At 3 (23)** (`modified_at_3`, time, required): Enter the date and time when the request was modified (a third iteration).
* **Updated At 3 (24)** (`updated_at_3`, time, required): Enter the date and time when the request was last updated (a third iteration).
* **Comments 2 (25)** (`comments_2`, note, required): Enter any additional comments about the request.
