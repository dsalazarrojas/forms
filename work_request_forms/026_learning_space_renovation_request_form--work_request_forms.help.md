# Learning Space Renovation Request Form - Help Guide
## Purpose
The Learning Space Renovation Request Form is designed to collect information about a school's learning space renovation needs. This form is used by school administrators to submit requests for renovations to the learning spaces within their school. 

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your school's name in the "School Name" field.
2. Select the type of space you are requesting to be renovated (e.g., Classrooms, Labs, Other).
3. Provide a brief description of the space to be renovated.
4. List the specific renovation needs for the space.
5. Enter your email address in the "Email" field.
6. Enter your phone number in the "Phone" field.
7. Assign the request to a staff member or administrator.
8. If desired, assign a specific tool or resource to the request (this is optional).
9. Select a category for the request (e.g., Work Request Forms, Other, Unknown).
10. If applicable, upload an output file related to the request.

## Field-by-Field Explanation

* **School Name** (Text, Required): Enter your school's name.
* **Space Type** (Select One, Optional): Select the type of space to be renovated (e.g., Classrooms, Labs, Other).
* **Space Description** (Text, Required): Provide a brief description of the space to be renovated.
* **Renovation Needs** (Text, Required): List the specific renovation needs for the space.
* **Email** (Email, Required): Enter a valid email address associated with your school.
* **Phone** (Text, Required): Enter a valid phone number associated with your school.
* **Assigned To** (Text, Required): Assign the request to a staff member or administrator.
* **Assigned Tool** (Text, Optional): If desired, enter a specific tool or resource to be assigned to the request.
* **Category** (Select One, Optional): Select a category for the request (e.g., Work Request Forms, Other, Unknown).
* **Output File** (Text, Optional): If applicable, upload an output file related to the request.

## Tips

* Make sure to fill out all required fields.
* Enter a clear and concise description of the space to be renovated.
* Ensure the email and phone fields are accurate and up-to-date.
* If assigned to someone, ensure it is a valid staff member or administrator.

Please note that this guide is a basic help document and might not cover all possible scenarios or edge cases. If you need further assistance, please contact the school administration.
