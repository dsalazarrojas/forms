# Upholstery Service Request - Help Guide

## Purpose
This form is used to request upholstery services, such as repairs or replacement of upholstery fabric. The form captures essential information from the customer, including their contact details and the specifics of the service needed.

## How To Complete This Form
To submit a request for upholstery services, follow these steps:

1. Fill in the required fields with your contact information, including name, email, phone number, and signature.
2. Choose the type of service required, which can be Upholstery Repair, Fabric Repair, or Re Upholstery.
3. Select the service date and time you would like the service to be performed.
4. Enter a detailed description of the service required.
5. Optionally, provide follow-up information if you would like to be contacted after the service is complete.
6. Finally, submit the form to send your request to the upholstery team.

## Field-by-Field Explanation
- **Form Title** (1, form_title, Required): A brief description of the service request.
- **Customer Name** (2, customer_name, Required): The full name of the customer submitting the request.
- **Customer Email** (3, customer_email, Required): The email address of the customer.
- **Customer Phone** (4, customer_phone, Required): The phone number of the customer.
- **Service Type** (5, service_type, Required): The type of service required, which can be Upholstery Repair, Fabric Repair, or Re Upholstery.
- **Service Date** (6, service_date, Required): The date you would like the service to be performed.
- **Service Time** (7, service_time, Required): The time of day you would like the service to be performed.
- **Service Description** (8, service_description, Required): A detailed description of the service required.
- **Form Comments** (9, form_comments, Required): Any additional comments or information you would like to provide about the service.
- **Customer Follow-up** (10, customer_follow_up, Optional): If you would like to be contacted after the service is complete, provide a date for follow-up.
- **Follow-up Note** (11, follow_up_note, Optional): A brief note about the follow-up, if desired.
- **Follow-up Time** (12, follow_up_time, Optional): If you would like to be contacted at a specific time for follow-up.
- **Service Team** (13, service_team, Required): The team that will perform the service, which can be Furniture Repair, Upholstery Team, or Other.
- **Schedule Date** (14, schedule_date, Required): The date you would like the service to be scheduled.
- **Schedule Time** (15, schedule_time, Required): The time of day you would like the service to be scheduled.
- **Schedule Notes** (16, schedule_notes, Optional): Any additional notes about the scheduling.
- **Customer Signature** (17, customer_signature, Required): Your signature, verifying the information provided.
- **Customer Signature Date** (18, customer_signature_date, Required): The date you sign the form.
- **Customer Signature Time** (19, customer_signature_time, Required): The time you sign the form.
- **Customer Address** (20, customer_address, Optional): The address of the customer, if different from your current location.
- **Customer City** (21, customer_city, Optional): The city of the customer, if different from your current city.
- **Customer State** (22, customer_state, Optional): The state or region of the customer, if different from your current location.
- **Customer Zip** (23, customer_zip, Optional): The zip code of the customer, if different from your current location.
- **Customer Notes** (24, customer_notes, Optional): Any additional comments or information about the customer.
- **Form Notes** (25, form_notes, Optional): Additional notes about the form submission, if desired.
