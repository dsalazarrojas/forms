# work_schedule_change_request_form - Help Guide
## Purpose
The purpose of this form is to request changes to an employee's work schedule, allowing employees to submit their requests in a structured and organized manner.

## How To Complete This Form

1. Fill out the form with the required information:
	* Ensure you have all necessary permissions and discussions before submitting the form.
	* Verify that the information you provide is accurate and up-to-date.
2. Select the correct options for each field:
	* **Employee ID** (`employee_id`, required): Enter the employee's ID to associate the schedule change request with their profile.
	* **Date** (`date`, required): Select the date of the shift change in the format mm/dd/yy.
	* **Time In** (`time_in`, required): Enter the time the employee is scheduled to start work.
	* **Time Out** (`time_out`, required): Enter the time the employee is scheduled to finish work.
	* **Old Shift** (`old_shift`, required): Select the current shift the employee is scheduled to work (morning, afternoon, or evening).
	* **New Shift** (`new_shift`, required): Select all applicable new shifts the employee is requesting (morning, afternoon, or evening).
	* **Reason** (`reason`, required): Enter a brief reason for the schedule change request.
3. Review the form for accuracy and completeness before submitting it.

## Field-by-Field Explanation
* **Employee ID**: Enter the employee's ID to associate the schedule change request with their profile.
* **Date**: Select the date of the shift change in the format mm/dd/yy.
* **Time In**: Enter the time the employee is scheduled to start work.
* **Time Out**: Enter the time the employee is scheduled to finish work.
* **Old Shift**: Select the current shift the employee is scheduled to work (morning, afternoon, or evening).
* **New Shift**: Select all applicable new shifts the employee is requesting (morning, afternoon, or evening).
* **Reason**: Enter a brief reason for the schedule change request.
* **Manager Note**: This field is optional and allows the manager to add any additional notes or comments.
* **Employee Note**: This field is optional and allows the employee to add any additional notes or comments.

## Tips
* Ensure that you have all necessary permissions and discussions before submitting the form.
* Verify that the information you provide is accurate and up-to-date.
* Review the form for accuracy and completeness before submitting it.
