# Lift Truck Work Order Information Form - Help Guide

## Purpose
The Lift Truck Work Order Information Form is used to capture and document essential information related to lift truck work orders. This form helps in providing a structured and organized way of gathering relevant details to efficiently process and manage work orders.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the "Lift Truck Work Order ID" field with the specific ID of the work order you are referencing.
2.  Enter the date of the lift truck work order in the "Lift Truck Work Order Date" field.
3.  Select the current status of the work order from the "Status" field. You can choose from "Open", "Closed", or "In Progress".
4.  Choose the type of work order from the "Type" field. You can select "Lift Truck", "Other", or "Specialized".
5.  If applicable, enter the equipment make in the "Equipment Make" field to specify the type of equipment associated with the work order.

## Field-by-Field Explanation

*   **Lift Truck Work Order ID (Lift Truck Work Order ID)** (`lift_truck_work_order_id`, `number`, required: false):
    *   This field captures the unique identifier for the lift truck work order, which can be used for tracking and referencing.
*   **Lift Truck Work Order Date (lift_truck_work_order_date, date, required: false):**
    *   Enter the date the lift truck work order was created or initiated.
*   **Status (work_order_status, select_one, required: false):**
    *   Choose the current status of the work order from the available options: "Open", "Closed", or "In Progress".
*   **Type (work_order_type, select_multiple, required: false):**
    *   Select the type of work order from the options: "Lift Truck", "Other", or "Specialized".
*   **Equipment Make (equipment_make, text, required: false):**
    *   If applicable, enter the make of the equipment associated with the work order.

## Tips
*   Please ensure that the date entered is in the correct format to avoid any formatting issues.
*   Be precise when selecting the status and type of work order to ensure accurate tracking and reporting.
*   Only enter the equipment make if it is relevant to the specific work order.
