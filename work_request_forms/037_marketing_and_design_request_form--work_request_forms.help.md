# Marketing And Design Request Form - Help Guide
## Purpose
The Marketing And Design Request Form is used to capture marketing and design requests from end-users, providing the necessary information for the design team to complete projects efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **Project Name** field with a brief and clear description of the project.
2. Select the **Design Request Type** that best matches the project requirements from the provided options.
3. In the **Description** field, provide a detailed description of the project, including any specific requirements or constraints.
4. Choose a **Due Date** for the project, ensuring that it is feasible and realistic.
5. Enter your **Designer Email** to receive updates and notifications about the project.
6. Provide your **Contact Number** for any further inquiries or clarifications.
7. Select the **Assigned Designer** who will be working on the project.
8. Choose the **Assigned Tool** that will be used for the project.
9. Set the **Priority** of the project as High, Medium, or Low based on its urgency and importance.

## Field-by-Field Explanation

* **Project Name** (id: 1, text, required): Enter a brief and clear description of the project.
* **Design Request Type** (id: 2, select_one, required): Choose the type of design request that best matches the project requirements.
* **Description** (id: 3, text, optional): Provide a detailed description of the project, including any specific requirements or constraints.
* **Due Date** (id: 4, date, required): Choose a feasible and realistic due date for the project.
* **Designer Email** (id: 5, email, required): Enter the email address of the designer assigned to the project.
* **Contact Number** (id: 6, text, required): Provide your contact number for any further inquiries or clarifications.
* **Assigned Designer** (id: 7, select_one, required): Select the designer who will be working on the project.
* **Assigned Tool** (id: 8, select_multiple, required): Choose the tools that will be used for the project.
* **Priority** (id: 9, select_one, required): Set the priority of the project as High, Medium, or Low based on its urgency and importance.
