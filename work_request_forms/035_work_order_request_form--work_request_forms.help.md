# Work Order Request Form - Help Guide
## Purpose
The Work Order Request Form is used to submit requests for work tasks and projects that require specific tools or resources. This form is intended for authorized personnel only.

## How To Complete This Form

1. Fill out the form completely, providing accurate and detailed information for each field.
2. Double-check your information for accuracy before submitting.
3. Make sure to select the correct category and assigned tool, if applicable.
4. Enter a brief description of the work task or project.

## Field-by-Field Explanation

* **First Name** (Text, Optional): Enter your first name as it appears on your official ID.
* **Last Name** (Text, Optional): Enter your last name as it appears on your official ID.
* **Email** (Email, Optional): Enter your work email address or a valid contact email.
* **Phone** (Text, Optional): Enter a valid phone number where you can be reached.
* **Address** (Text, Optional): Enter the address or location related to your request.
* **Date** (Date, Optional): Enter the date for the work task or project if applicable.
* **Time** (Time, Optional): Enter the time for the work task or project if applicable.
* **Note** (Note, Optional): Enter any additional comments or notes about your request.
* **Category** (Text, Optional): Select the category of the work task or project (e.g., Maintenance, Repair, etc.).
* **Description** (Text, Optional): Enter a brief description of the work task or project.
* **Assigned Tool** (Text, Optional): Select the specific tool or resource required for the work task or project if applicable.
* **Submitted By** (Text, Optional): Enter your name or title for reporting purposes.

## Tips
* Make sure to submit the form only for new work orders, and not updates to existing ones.
* Double-check your information before submitting the form.
* If you're unsure about any field, refer back to this help guide for clarification.
* For more information about work orders, please contact your supervisor or team lead.
* If you need to submit a work order that requires special permission, please ensure you have the necessary approvals before submitting this form.
