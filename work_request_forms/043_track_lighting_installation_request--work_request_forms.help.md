# Track Lighting Installation Request - Help Guide

## Purpose
The purpose of this form is to request the installation of lighting equipment at a facility. It collects information necessary for the installation process, including customer contact details, installation preferences, and facility equipment requirements.

## How To Complete This Form
1. Fill out all required fields (indicated by an asterisk \*).
2. Provide accurate and clear information for each field.
3. If a field is not applicable or not relevant, please indicate this in the corresponding field.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
* **Customer Details**: Please provide your name and contact information to ensure we can reach you for further discussion or follow-up questions.
* **Installation Details**: Describe the installation location, type of equipment, and any specific requirements or requests you have for the installation.
* **Scheduling Preferences**: Indicate your preferred scheduling dates and times for the installation.
* **Notes**: Provide any additional comments or information regarding the installation.
* **Customer Signature**: Please add your digital signature to confirm your request.
* **Assigned To**: Select the person responsible for handling your request (e.g., Jimmy or another option).
* **Facility Details**: Provide a brief description of the facility where the installation will take place.
* **Facility Equipment**: Select all applicable options to specify the type of equipment to be installed (e.g., Option 1, Option 2, and Option 3).
* **Follow-up**: If you would like to be contacted for updates or follow-up questions, please provide your contact information here.
