# Rental Property Maintenance Log - Help Guide

## Purpose
The Rental Property Maintenance Log is used to track and record maintenance requests for rental properties owned or managed by the organization. This form helps to keep a record of what needs to be done, what has been completed, and the status of ongoing work.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the date of the maintenance request from the calendar.
2. Choose the property ID from the list of available properties.
3. Choose the type of maintenance needed (Maintenance, Repair, or Inspection).
4. Describe the issue or task to be completed.
5. Choose the current status of the maintenance request (Completed, In Progress, or Not Started).
6. Indicate the priority level of the maintenance request (High, Medium, or Low).
7. Choose whether a specific tool is assigned to complete the task.
8. Submit the form for review and approval.

## Field-by-Field Explanation

* **Rental Property Maintenance Log** (`rental_property_maintenance_log`): Enter a brief description of the maintenance request.
* **Work Request Date** (`work_request_date`): Select the date the maintenance request was made.
* **Property ID** (`property_id`): Choose the ID of the property that requires maintenance.
* **Maintenance Type** (`maintenance_type`): Select the type of maintenance needed (Maintenance, Repair, or Inspection).
* **Description** (`description`): Provide a detailed description of the issue or task to be completed.
* **Maintenance Status** (`maintenance_status`): Choose the current status of the maintenance request (Completed, In Progress, or Not Started).
* **Priority** (`priority`): Indicate the priority level of the maintenance request (High, Medium, or Low).
* **Assigned Tool** (`assigned_tool`): Choose whether a specific tool is assigned to complete the task.
