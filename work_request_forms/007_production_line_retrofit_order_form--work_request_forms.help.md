# Production Line Retrofit Order Form - Help Guide
## Purpose
The Production Line Retrofit Order Form is a tool for production line managers or authorized personnel to submit orders for retrofits on specific production lines. This form ensures that all necessary information is provided to process and fulfill these requests efficiently.

## How To Complete This Form
1. Select the relevant production line from the dropdown menu that corresponds to the production line you would like to retrofit.
2. Enter the current date in the format YYYY-MM-DD.
3. Enter the start time of the retrofit if applicable.
4. Enter the duration of the retrofit if applicable.
5. Provide a brief description of the retrofit request.
6. Check the box if you consent to the terms and conditions.
7. If necessary, provide any additional information regarding the retrofit.
8. Enter the name of the production line manager responsible.
9. Enter the production line manager's email.
10. Enter the production line manager's phone number.

## Field-by-Field Explanation

* **Production Line** (`production_line`): Select the production line that needs to be retrofitted.
* **Date** (`date`): Enter the current date in the format YYYY-MM-DD.
* **Start Time** (`start_time`): Enter the start time of the retrofit, if applicable.
* **Duration** (`duration`): Enter the duration of the retrofit, if applicable.
* **Description** (`description`): Provide a brief description of the retrofit request.
* **Consent** (`consent`): Check the box if you consent to the terms and conditions.
* **Additional Info** (`additional_info`): If necessary, provide any additional information regarding the retrofit.
* **Production Line Manager Name** (`production_line_manager_name`): Enter the name of the production line manager responsible.
* **Production Line Manager Email** (`production_line_manager_email`): Enter the production line manager's email.
* **Production Line Manager Phone** (`production_line_manager_phone`): Enter the production line manager's phone number.

## Tips
* Please fill out the form accurately and completely to ensure that the retrofit request is processed efficiently.
* If you are unsure about any of the fields, contact the relevant production line manager or the team responsible for processing the retrofits.
