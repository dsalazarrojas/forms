# Tooling Design Update Request Form - Help Guide
## Purpose
This form is used to submit requests for tooling design updates to the tooling team. It allows you to specify the category, description, date, and time of the update request, as well as other relevant details.

## How To Complete This Form
1. Select the category of the tooling design update request from the available options: Tooling, Machining, or Welding.
2. Provide a detailed description of the tooling design update request in the "description" field.
3. Enter the date and time of the request in the "request_date" and "time" fields.
4. Specify the name of the tooling design that you are requesting an update for in the "tooling_name" field.
5. Enter the name of the tool that you are requesting an update for in the "assigned_tool" field.
6. Specify the type of update request (Major, Minor, or Major/Minor) in the "change_type" field.
7. Enter the current status of the tooling design update request in the "change_status" field.
8. If applicable, provide any comments or additional information about the update request in the "comment" fields.
9. Enter your email address in the "email" field for contact information.
10. Enter your phone number in the "phone" field for contact information.
11. Enter the name of the department responsible for the tooling design update request in the "department" field.
12. Enter the location where the tooling design update request is located in the "location" field.
13. Enter the name of the manager responsible for the tooling design update request in the "manager" field.
14. Enter the email address of the manager responsible for the tooling design update request in the "manager_email" field.
15. Enter the phone number of the manager responsible for the tooling design update request in the "manager_phone" field.
16. Select the action to take with the form submission: "submit" or "save for later".
17. If you have additional comments or information about the tooling design update request, you can enter them in the "tooling_design_update_request_form_comments" fields.

## Field-by-Field Explanation

* **Category** (`category`, `select_one`, required): Select the category of the tooling design update request from the available options: Tooling, Machining, or Welding.
* **Description** (`description`, `text`, required): Provide a detailed description of the tooling design update request.
* **Request Date** (`request_date`, `date`, required): Enter the date of the request.
* **Tooling Name** (`tooling_name`, `text`, required): Enter the name of the tooling design that you are requesting an update for.
* **Assigned Tool** (`assigned_tool`, `text`, required): Enter the name of the tool that you are requesting an update for.
* **Change Type** (`change_type`, `select_one`, required): Specify the type of update request: Major, Minor, or Major/Minor.
* **Change Status** (`change_status`, `select_one`, required): Enter the current status of the tooling design update request.
* **Comment** (`comment`, `text`, optional): Provide any additional comments or information about the update request.
* **Email** (`email`, `email`, optional): Enter your email address for contact information.
* **Phone** (`phone`, `text`, optional): Enter your phone number for contact information.
* **Submitter** (`submittter`, `text`, required): Enter your name for submitter information.
* **Department** (`department`, `text`, required): Enter the department responsible for the tooling design update request.
* **Location** (`location`, `text`, required): Enter the location where the tooling design update request is located.
* **Manager** (`manager`, `text`, required): Enter the name of the manager responsible for the tooling design update request.
* **Manager Email** (`manager_email`, `text`, required): Enter the email address of the manager responsible for the tooling design update request.
* **Manager Phone** (`manager_phone`, `text`, optional): Enter the phone number of the manager responsible for the tooling design update request.
* **Date** (`date`, `date`, required): Enter the date of the request.
* **Time** (`time`, `time`, required): Enter the time of the request.
* **Submit** (`tooling_design_update_request_form_submit`, `select_one`, required): Select the action to take with the form submission: "submit" or "save for later".
* **Comments** (`tooling_design_update_request_form_comments`, `text`, optional): Enter any additional comments or information about the tooling design update request.

## Tips

* Make sure to complete all required fields to ensure that your request is properly reviewed.
* If you are unsure about any of the fields, please contact the tooling team for guidance.
