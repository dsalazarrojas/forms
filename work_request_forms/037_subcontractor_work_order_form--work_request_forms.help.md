# subcontractor-work-order-form - Help Guide
## Purpose
This form is used to collect information about work orders for subcontractors. Its purpose is to provide a structured way to input details about a work order, such as contractor information, work order status, and other relevant data.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Enter the necessary information in each field, as explained below.
2.  Ensure that the required fields are filled out correctly.
3.  Review your entries for accuracy before submitting the form.

## Field-by-Field Explanation
### **Contractor-Info** (contrator-info, text, required)
Enter the contractor's name, address, phone number, or other relevant contact information.

### **Work-Order-Info** (work_order_info, note, not required)
Please provide any relevant comments or details about the work order.

### **Work-Order-Status** (work_order_status, select_one, required)
Select the status of the work order from the options: "pending", "active", or "cancelled".

### **Work-Order-Date-Created** (work_order_date_created, date, not required)
Enter the date when the work order was created (if known).

### **Work-Order-Date-Created-By** (work_order_created_by, text, required)
Enter the name of the user who created the work order.

### **Work-Order-Last-Updated** (work_order_last_updated, time, not required)
Enter the date and time when the work order was last updated (if known).

### **Work-Order-Last-Updated-By** (work_order_last_updated_by, text, not required)
Enter the name of the user who last updated the work order (if known).

## Tips
*   Ensure that all required fields are completed before submitting the form.
*   Review your entries carefully to avoid errors or inconsistencies.
*   If you need to make changes to a work order, update the status and other relevant fields accordingly.
*   If you need to track changes or history on a work order, use the "Work-Order-Last-Updated" and "Work-Order-Last-Updated-By" fields.
*   This form is designed to be user-friendly and easy to use; if you have any issues or need assistance, please contact [form@gic.mx](mailto:form@gic.mx).
