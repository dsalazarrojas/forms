# Vehicle Inspection Form - Help Guide
## Purpose
This form is designed to collect information for vehicle inspections, which is used to track and document vehicle condition, maintenance, and servicing activities.

## How To Complete This Form

1. To complete this form, follow the instructions on each page.
2. Review the form carefully before submitting to ensure all required fields are filled out.

## Field-by-Field Explanation

* **Vehicle Inspection Form** (`vehicle_inspection_form`, text, not required): Enter a brief description of the vehicle inspection, such as the date and time of the inspection, or a summary of the findings.
* **Work Request Forms** (`work_request_forms`, select_multiple, not required): Check 'Yes' if you have any work request forms related to the vehicle inspection. 
* **Checklist Forms** (`checklist_forms`, select_multiple, not required): Check 'Yes' if you want to include checklist forms with the vehicle inspection.
* **Vehicle Inspection Form Description** (`vehicle_inspection_form_description`, text, not required): Enter a detailed description of the vehicle inspection, including any issues found, repairs made, or recommendations.

## Tips

* Please ensure all fields are accurate and relevant to the vehicle inspection.
* If a field is not applicable, mark 'No' in the corresponding select_multiple field.
* Review the form carefully before submitting to ensure all required fields are filled out.
* If you need to attach additional documents or files, you can do so in the designated upload section of the form (not shown in this guide).
