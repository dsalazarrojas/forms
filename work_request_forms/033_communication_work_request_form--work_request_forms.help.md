# Communication Work Request Form - Help Guide

## Purpose
This form is used to request communication work support from various teams and departments within the organization. It helps to gather all necessary information for fulfilling the request efficiently and effectively.

## How To Complete This Form
To complete this form, please follow the steps below:
1. Fill in the required fields marked as "required" in the form.
2. Provide as much detail as possible in the optional fields to ensure that your request is processed correctly.
3. Review your answers for accuracy before submitting the form.

## Field-by-Field Explanation

* **Request Date** (`Request Date`, date, required): This field is used to capture the date of the request. Please select the date on which you submitted this request.
* **Request ID** (`Request ID`, text, required): This field is for a unique reference number for your request. Please enter a unique ID for easy tracking and reference.
* **Requester Name** (`Requester Name`, text, required): This field is for your full name, which will help us contact you directly if needed.
* **Requester Email** (`Requester Email`, email, required): This field is for your email address, which will be used for communication and follow-up.
* **Requester Phone** (`Requester Phone`, text, optional): This field is for your phone number, which will be used for urgent communication if needed.
* **Department** (`Department`, select_one, required): This field helps us understand which department this request is related to. Please select the relevant department from the options provided.
* **Project Information** (`Project Information`, note, optional): This field is for additional details about the project. You can provide as much information as you need to ensure we understand the project requirements.
* **Project Name** (`Project Name`, text, required): This field is for the name of the project or initiative you are working on.
* **Project Description** (`Project Description`, text, required): This field is for a brief description of the project.
* **Request Type** (`Request Type`, select_multiple, required): This field helps us understand what type of communication support you need. Select all applicable options from the list.
* **Target Audience** (`Target Audience`, select_multiple, required): This field helps us understand who the intended audience is for this communication. Select all applicable options from the list.
* **Key Message** (`Key Message`, text, required): This field is for the main message you want to communicate. Please make sure it is clear and concise.
* **Deadline** (`Deadline`, date, required): This field is for the date by which you need this communication work completed.
* **Launch Date** (`Launch Date`, date, optional): This field is for the date on which you want this communication work to be published or launched.
* **Priority Level** (`Priority Level`, select_one, required): This field helps us understand the urgency of your request. Select the level of priority from the options provided.
* **Budget Information** (`Budget Information`, note, optional): This field is for any budget details related to this request. You can provide as much information as needed.
* **Budget Available** (`Budget Available`, select_one, required): This field helps us understand if there is a budget allocated for this request. Select 'Yes', 'No', or 'Not Sure' from the options provided.
* **Budget Amount** (`Budget Amount`, number, optional): This field is for the available budget amount in USD. Please provide the exact amount if known.
* **Deliverables** (`Deliverables`, text, required): This field is for any specific deliverables you need for this communication work. Be as detailed as possible.
* **Brand Guidelines** (`Brand Guidelines`, select_one, required): This field helps us understand if there are specific brand guidelines to follow. Select 'Yes - Will Provide', 'Yes - Standard Guidelines', or 'No - New Guidelines Needed' from the options provided.
* **Stakeholders** (`Stakeholders`, text, optional): This field is for any stakeholders who need to review or approve this work. Provide their names and contact details.
* **Success Metrics** (`Success Metrics`, text, optional): This field is for how success will be measured for this communication work. Be as specific as possible.
* **Additional Requirements** (`Additional Requirements`, text, optional): This field is for any other requirements or considerations you may have. Be as detailed as possible.
* **Supporting Materials** (`Supporting Materials`, select_one, required): This field helps us understand if you have any supporting materials to share. Select 'Yes - Will Attach', 'Yes - Will Share Later', or 'No' from the options provided.
