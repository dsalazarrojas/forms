# Workspace Modification Request Form - Help Guide
## Purpose
The Workspace Modification Request Form is designed to collect information regarding modifications to a workspace. This form is used by users to submit their requests for modifications with optional attachments and details on priority, status, facility request, and assigned information.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Workspace Info** section with any relevant details about the workspace you wish to modify.
2. Provide **Request Details** in the text area, describing the modifications you are requesting.
3. If applicable, choose your **Priority** (Yes/No) to indicate the level of urgency for the modification.
4. Select the current **Status** (Active/Inactive) of the workspace.
5. Choose whether the modification is related to a **Facility Request** (Yes/No).
6. Upload any additional **Attachments** if necessary, such as images or documents.
7. Indicate if the modification is **Assigned** (Yes/No).
8. Select the **Assigned Date** and **Completed Date** (if completed) for the modification.

## Field-by-Field Explanation

* **Workspace Info**: Enter a brief description of the workspace you are modifying.
* **Request Details**: Describe the modification(s) you are requesting in this text area. Be as detailed as possible to help the team process your request.
* **Priority**: Select "Yes" if this modification is urgent or time-sensitive. Select "No" otherwise.
* **Status**: Choose the current status of the workspace (Active or Inactive).
* **Facility Request**: Choose "Yes" if the modification is related to a facility request. Select "No" otherwise.
* **Attachment 1**: Upload a file or image related to the modification (optional).
* **Attachment 2**: Upload another file or image related to the modification (optional).
* **Attachment 3**: Upload a third file or image related to the modification (optional).
* **Assigned**: Select "Yes" if the modification is assigned to a specific user. Select "No" otherwise.
* **Assigned Date**: Enter the date the modification was assigned to a user (if applicable).
* **Completed Date**: Enter the date the modification was completed (if applicable).
