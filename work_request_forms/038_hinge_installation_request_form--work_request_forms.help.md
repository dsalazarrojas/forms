# Hinge Installation Request Form - Help Guide
## Purpose
The Hinge Installation Request Form is a tool used to collect and track information for hinge installation requests from end users.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the request date to indicate when the hinge installation request was made.
2. Choose the type of hinge installation required.
3. Select the size of the hinge that needs to be installed.
4. Enter the location of the hinge installation.
5. Provide any additional hinge details.
6. If applicable, enter the contractor's name and contact number.
7. Enter the email address and address of the location where the hinge will be installed.
8. Schedule the installation date and time.
9. Enter any schedule notes or additional comments.
10. Enter any notes or comments regarding the installation.
11. Select the status of the hinge installation.
12. Enter any comments regarding the hinge installation.
13. Enter the date of the hinge installation.
14. Enter the cost of the hinge installation.
15. Enter any additional notes or comments regarding the hinge installation.

## Field-by-Field Explanation
- **request_date**: The date when the hinge installation request was made.
  * Type: date
  * Required: false
- **type**: The type of hinge installation required. Please select from the options provided.
  * Type: select_one
  * Required: true
- **hinge_size**: The size of the hinge that needs to be installed. Please select all applicable options.
  * Type: select_multiple
  * Required: true
- **hinge_location**: Enter the location where the hinge will be installed.
  * Type: text
  * Required: true
- **hinge_details**: Provide any additional details regarding the hinge installation.
  * Type: note
  * Required: true
- **contractor_name**: If applicable, enter the name of the contractor.
  * Type: text
  * Required: false
- **contact_number**: If applicable, enter the contact number of the contractor.
  * Type: text
  * Required: false
- **email**: If applicable, enter the email address of the location where the hinge will be installed.
  * Type: email
  * Required: false
- **address**: Enter the address of the location where the hinge will be installed. Please select from the options provided.
  * Type: select_one
  * Required: false
- **schedule_date**: Schedule the date for the hinge installation.
  * Type: date
  * Required: true
- **schedule_time**: Schedule the time for the hinge installation.
  * Type: time
  * Required: true
- **schedule_note**: Enter any schedule notes or additional comments.
  * Type: note
  * Required: false
- **notes**: Enter any notes or comments regarding the hinge installation.
  * Type: note
  * Required: false
- **hinge_installation_status**: Select the status of the hinge installation.
  * Type: select_one
  * Required: true
- **hinge_installation_comments**: Enter any comments regarding the hinge installation.
  * Type: note
  * Required: false
- **hinge_installation_date**: Enter the date of the hinge installation.
  * Type: date
  * Required: true
- **hinge_installation_cost**: Enter the cost of the hinge installation. Note: This field is optional.
  * Type: number
  * Required: false
- **hinge_installation_notes**: Enter any additional notes or comments regarding the hinge installation.
  * Type: note
  * Required: false
- **hinge_installation_requester**: Enter the name of the person requesting the hinge installation.
  * Type: text
  * Required: false
- **hinge_remarks**: Enter any remarks regarding the hinge installation.
  * Type: note
  * Required: false
- **hinge_comments**: Enter any comments regarding the hinge installation.
  * Type: note
  * Required: false
- **hinge_requester**: Enter the name of the person requesting the hinge installation.
  * Type: text
  * Required: false
- **hinge_requester_comments**: Enter any comments regarding the hinge installation.
  * Type: note
  * Required: false
- **hinge_contractors**: Enter the name of the contractor.
  * Type: text
  * Required: false
- **hinge_contractors_comments**: Enter any comments regarding the hinge installation.
  * Type: note
  * Required: false
