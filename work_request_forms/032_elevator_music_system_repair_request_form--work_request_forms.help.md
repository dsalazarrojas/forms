# Elevator Music System Repair Request Form - Help Guide
## Purpose
This form is used to submit a request for repair or maintenance of a facility's elevator music system. This could include issues such as a malfunctioning or no sound at all.

## How To Complete This Form
To submit a request, please fill out this form with the required information and submit it. You can fill out the form as follows:

1. Select the "Status" field and choose "Active" if the music system is currently working or "Inactive" if it is not.
2. Describe the issue in detail in the "Comments" field.
3. If relevant, select the "Music Source" field to specify if the music is from Local, Satellite, or Streaming.
4. If you have additional information, provide it in the "Comments" field.
5. Enter any additional comments or notes in the "Comments" field.
6. If you are the contact person, enter your name, phone number, and email in the respective fields.
7. If you are the facility manager, enter the facility's name, address, and manager's name in the respective fields.
8. Select the "Status 2" field and choose "In Progress" if the request is being worked on, "Completed" if it is fixed, or "Cancelled" if it is no longer needed.
9. Enter any additional comments or notes for the facility in the "Comments 2" field.
