# Sewer Issues And Pest Control Request - Help Guide
## Purpose
This form is designed to report and track sewer or pest issues in your area. Use this form to inform maintenance crew members of problems such as clogs, blockages, or pest sightings.

## How To Complete This Form
1.  Click on the "Start Filling Out" button to begin.
2.  Fill out all the required fields (indicated as "required: true") and any additional fields that you think will be helpful in resolving the issue.
3.  Click on "Submit" to finish and send the form.

## Field-by-Field Explanation

*   **Report Sewer Pest Problem** (report_sewer_pest_problem): Please describe the problem you've encountered in the sewer (e.g., clogged drains, pest sightings).
*   **Report Problem Photo** (report_problem_photo): If you have a photo of the issue, please attach it here to help maintenance crew members better understand the problem.
*   **Report Problem Priority** (report_problem_priority): Use this dropdown menu to select the level of urgency you think the issue requires (Low, Medium, High).
*   **Report Problem Description** (report_problem_description): Describe the issue in more detail, including any steps you've taken to address it.
*   **Report Location** (report_location): Provide the address or location where the issue is happening.
*   **Report Problem Type** (report_problem_type): Select the type of problem you're reporting (Pest Control, Sewer Issue, Other).
*   **Report Problem Status** (report_problem_status): If you know the current status of the problem, select it from the dropdown menu (New, In Progress, Done).
*   **Report Attachment** (report_attachment): If you have any additional documentation or files that can help resolve the issue, attach them here.
*   **Request Follow Up** (report_request_follow_up): Select the date and time you'd like to be followed up on.
*   **Request Follow Up Time** (report_request_follow_up_time): Enter the specific time you'd like to be followed up on.
*   **Report Requesting Unit** (report_requesting_unit): Select who is requesting the follow-up (Residents, Property Managers, Maintenance Crew).
*   **Report Requester Email** (report_requester_email): Enter your contact email for communication purposes.
*   **Report Requester Phone** (report_requester_phone): Enter your contact phone number for communication purposes.
*   **Report Requester Name** (report_requester_name): Enter your name.
*   **Report Notes** (report_notes): Add any additional information that might be helpful in resolving the issue.
*   **Sewer Photo Attachment** (report_sewer_photo_attachment): If you have a photo of the sewer issue, attach it here.
*   **Pest Photo Attachment** (report_pest_photo_attachment): If you have a photo of the pest issue, attach it here.
*   **Report Requester Address** (report_requester_address): Enter your contact address.
*   **Report Requester City** (report_requester_city): Enter your city.
*   **Report Requester State** (report_requester_state): Enter your state or province.
*   **Report Requester Country** (report_requester_country): Enter your country.
*   **Report Requester Zip** (report_requester_zip): Enter your zip or postal code.
