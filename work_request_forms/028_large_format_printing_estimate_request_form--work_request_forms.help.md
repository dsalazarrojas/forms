# Large Format Printing Estimate Request Form - Help Guide
## Purpose
This form is used to request a large format printing estimate from a customer. It is intended for customers to provide information about their project and receive a quote for the printing services.

## How To Complete This Form
1. Fill in the customer name and contact number to ensure that the customer's order is assigned correctly.
2. Provide a brief description of the project to give the customer's representative a clear understanding of what needs to be printed.
3. If available, upload a relevant file to aid in the estimation process.
4. If a file is not available, provide a URL to the file online.
5. Estimate the size of the print job in terms of A3, A4, or A4+ formats.
6. Select the paper type for the print job.
7. Enter the estimated quantity of prints required.
8. Enter the estimated cost of the print job.
9. Choose the delivery method (in-house or in-house and out-of-house).
10. Enter the delivery address for the print job (if in-house delivery is selected).
11. Add any special instructions or notes for the printing representative.
12. Add any customer notes or requests.

## Field-by-Field Explanation

* **Customer Name**: Enter the name of the customer who is requesting the print estimate.
* **Contact Number**: Enter the contact number of the customer or representative.
* **Project Description**: Provide a brief description of the project to give the customer's representative a clear understanding of what needs to be printed.
* **File Upload**: Upload a relevant file to aid in the estimation process. Alternatively, you can enter a URL to the file online.
* **File URL**: If you are not uploading a file, enter the URL to the file online.
* **Estimated Size**: Estimate the size of the print job in terms of A3, A4, or A4+ formats.
* **Print Format**: Select the paper type for the print job from the available options.
* **Quantity**: Enter the estimated quantity of prints required.
* **Estimated Cost**: Enter the estimated cost of the print job.
* **Delivery Method**: Choose the delivery method for the print job (in-house or in-house and out-of-house).
* **Delivery Address**: Enter the delivery address for the print job (if in-house delivery is selected).
* **Special Instructions**: Add any special instructions or notes for the printing representative.
* **Customer Notes**: Add any customer notes or requests.
* **Internal Notes**: Add any internal notes or comments for the printing representative.
