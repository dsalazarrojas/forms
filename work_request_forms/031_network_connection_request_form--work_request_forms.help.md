# Network Connection Request Form - Help Guide
## Purpose
The Network Connection Request Form is designed to facilitate the process of requesting network connections for various purposes. This form ensures that all necessary information is collected and documented for efficient management of network connections.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Network Connection Request** field with a brief description of the request.
2. Select **Connection Type** to indicate the type of connection required (Yes/No).
3. Choose **Network Access** (Yes/No) to determine the level of network access needed.
4. Enter the **Request Date** when the request was initiated.
5. Enter the **End Date** (optional) for any specific date the request should be ended.
6. Provide a detailed **Description** of the request.
7. Select **Priority** (Yes/No) to indicate the urgency of the request.
8. Choose **Status** (Active/Inactive) to determine the current status of the request.
9. Enter your **Submitted By** name and **Submitted Date** when the request was submitted.
10. Enter the **Assigned To** name for the person or team responsible for handling the request.
11. Add any **Notes** (optional) for further clarification or comments.
12. Enter your **Email** address (optional).
13. Enter your **Phone** number (optional).
14. Enter the **Location** (optional) where the request is being made.
15. Enter the **Team** (optional) related to the request.
16. Enter the **Contact** (optional) name and number.
17. Enter the **Requestor** (optional) name.
18. Enter the **Manager** (optional) name.
19. Enter the **Department** (optional) related to the request.
20. Enter your **Role** (optional).
21. Enter the **Supervisor** (optional) name.
22. Enter your **Employee ID** (optional).
23. Enter your **Employee Name** (optional).

## Field-by-Field Explanation
* **Network Connection Request** (1): A brief description of the request.
* **Request Details** (2): A more detailed description of the request (optional).
* **Connection Type** (3): Select Yes for a connection is required, No otherwise.
* **Network Access** (4): Select Yes for full access, No for restricted access.
* **Request Date** (5): The date when the request was initiated.
* **End Date** (6): The date when the request should end (optional).
* **Description** (7): A detailed description of the request.
* **Priority** (8): Select Yes for urgent, No otherwise.
* **Status** (9): Active or Inactive to determine the current status.
* **Submitted By** (10): Your name for tracking purposes.
* **Submitted Date** (11): The date when the request was submitted.
* **Assigned To** (12): The person or team responsible for handling the request.
* **Notes** (13): Additional information or comments.
* **Email** (14): Your email address (optional).
* **Phone** (15): Your phone number (optional).
* **Location** (16): The location where the request is being made (optional).
* **Team** (17): The team related to the request (optional).
* **Contact** (18): The contact name and number (optional).
* **Requestor** (19): The person submitting the request (optional).
* **Manager** (20): The manager's name (optional).
* **Department** (21): The department related to the request (optional).
* **Role** (22): Your role or position (optional).
* **Supervisor** (23): The supervisor's name (optional).
* **Employee ID** (24): Your employee ID (optional).
* **Employee Name** (25): Your name (optional).

## Tips
* Be sure to fill in all required fields.
* Use clear and concise language to describe your request.
* Double-check your information for accuracy before submitting the form.
