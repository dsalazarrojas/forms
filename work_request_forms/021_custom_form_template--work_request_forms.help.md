# Custom Form Template - Help Guide
## Purpose
This custom form template is designed to capture and track essential details about work requests from customers. It's meant to be used for internal processes within an organization.

## How To Complete This Form
To fill out this form, follow these steps:

1. **Work Request (1)**: This is the main section where you'll provide an overview of the customer's request. Please enter a brief description of the work request.
2. **Customer Info (2)**: Enter any relevant details about the customer, such as their name, contact information, or other identifying characteristics.
3. **Order Details (3)**: Describe the specifics of the order or request, including any relevant details about the service or product requested.
4. **Order Status (4)**: Select the current status of the order from the provided options: pending, shipped, or cancelled.
5. **Order Date (5)**: Enter the date when the order was placed.
6. **Order Time (6)**: Enter the time when the order was placed.
7. **Order Total (7)**: Enter the total amount associated with the order.
8. **Order Notes (8)**: Add any additional comments or notes about the order.

## Field-by-Field Explanation

* **Work Request (1)**: A text field where you'll provide a brief description of the customer's request.
* **Customer Info (2)**: A text field for capturing customer details, such as name, contact information, or other relevant characteristics.
* **Order Details (3)**: A text field for describing the specifics of the order or request.
* **Order Status (4)**: A dropdown menu to select the current status of the order (pending, shipped, or cancelled).
* **Order Date (5)**: A date field to enter the date when the order was placed.
* **Order Time (6)**: A time field to enter the time when the order was placed.
* **Order Total (7)**: A numeric field to enter the total amount associated with the order.
* **Order Notes (8)**: A text area for adding any additional comments or notes about the order.

## Tips
- Make sure to provide clear and concise answers to each field to ensure accurate tracking and processing of the work request.
- Use the "Order Status" field to keep the order's progress up to date.
- Keep the "Order Notes" field for any additional information that may be needed for reference or follow-up.
