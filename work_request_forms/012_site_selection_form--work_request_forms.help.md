# Site Selection Form - Help Guide

## Purpose
The Site Selection Form is used for selecting a site for a project, gathering relevant information, and providing space for additional comments and attachments.

## How To Complete This Form
1. Select the site(s) you wish to use for your project by choosing from the available options under "Select Site".
2. Choose the type of project you are working on by selecting from the options under "Project Type".
3. Enter the date and time of the event you are planning using the "Date of Event" and "Time of Event" fields.
4. Enter the contact information for the project, including the "Contact Name", "Contact Email", and "Contact Phone".
5. Enter a brief description of the project in the "Project Description" field.
6. Enter any additional site details in the "Site Details" field.
7. Enter the address of the site in the "Address" field.
8. Enter any site selection criteria in the "Site Selection Criteria" field.
9. Choose a selected site for the project from the options under "Selected Site".
10. Enter any additional comments in the "Comments" field.
11. Attach any relevant documents or files to the form using the "Attachments" field.
12. Enter any internal or external notes about the project in the "Internal Notes" and "External Notes" fields.
13. Enter any additional comments or information about the site selection process in the "Additional Comments" field.

## Field-by-Field Explanation
* **Select Site** (Select Multiple, Required): Choose the site(s) you wish to use for your project.
* **Project Type** (Select One, Required): Choose the type of project you are working on.
* **Date of Event** (Date, Required): Enter the date of the event you are planning.
* **Time of Event** (Time, Required): Enter the time of the event you are planning.
* **Contact Name** (Text, Required): Enter the name of the contact person for the project.
* **Contact Email** (Email, Required): Enter the email of the contact person for the project.
* **Contact Phone** (Text, Required): Enter the phone number of the contact person for the project.
* **Project Description** (Text, Required): Enter a brief description of the project.
* **Site Details** (Text, Required): Enter any additional site details.
* **Address** (Text, Required): Enter the address of the site.
* **Site Selection Criteria** (Text, Required): Enter any site selection criteria.
* **Selected Site** (Select One, Optional): Choose a selected site for the project.
* **Comments** (Note, Optional): Enter any additional comments about the project.
* **Attachments** (Text, Optional): Attach any relevant documents or files to the form.
* **Internal Notes** (Text, Optional): Enter any internal notes about the project.
* **External Notes** (Text, Optional): Enter any external notes about the project.
* **Additional Comments** (Text, Optional): Enter any additional comments or information about the site selection process.
* **Project Manager ID** (Text, Optional): Enter the ID of the project manager.
* **Client ID** (Text, Optional): Enter the ID of the client.
* **Site Selection Form Report** (Text, Optional): Enter a report of the site selection form.
