# Warehouse Lighting Maintenance Request Form - Help Guide
## Purpose
The Warehouse Lighting Maintenance Request Form is used to report and track issues with the warehouse lighting. This form ensures that the problems with the lighting are documented and assigned to the correct person for maintenance.

## How To Complete This Form
To complete this form, follow these steps:

* Select the specific issue with the warehouse lighting by filling in the "Warehouse Lighting Problem" field.
* Provide a detailed description of the problem in the "Issue Description" field.
* Select a photo of the issue from the "Photos" field, if applicable.
* Assign the request to a person from the "Assigned To" field.
* Set a priority level for the request in the "Priority" field.
* Track the status of the request in the "Status" field.
* Optionally, set a due date for the request in the "Due Date" field.

## Field-by-Field Explanation

* **Warehouse Lighting Problem** (`Warehouse Lighting Problem`, `text`, required): Briefly describe the specific issue with the warehouse lighting.
* **Issue Description** (`issue_details`, `note`, required): Provide a detailed description of the problem.
* **Photos** (`photos`, `select_multiple`, required): Attach a photo of the issue to help with diagnosis.
* **Assigned To** (`assigned_to`, `select_one`, required): Select the person to be assigned to for maintenance.
* **Priority** (`priority`, `select_one`, required): Set a priority level for the request, either High, Low, or Medium.
* **Status** (`status`, `select_one`, required): Track the status of the request, either Pending, In Progress, or Done.
* **Issue Date** (`issue_date`, `date`, optional): Optionally, record the date the issue occurred.
* **Due Date** (`due_date`, `date`, optional): Optionally, set a due date for the completion of the request.

## Tips
* Ensure you select the correct issue with the lighting.
* Attach a photo to support your request if possible.
* Set a priority level based on the severity of the issue.
* Keep the status up to date to ensure timely resolution.
* Use the due date to ensure the request is completed within a reasonable timeframe.
