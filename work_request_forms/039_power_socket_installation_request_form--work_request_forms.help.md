# Power Socket Installation Request Form - Help Guide
## Purpose
This form is used to collect information from customers for power socket installation requests.

## How To Complete This Form
Follow the steps below to complete the form:

1. Fill out the form completely.
2. Review all fields carefully.
3. Make sure all required fields are filled.

## Field-by-Field Explanation

* **Customer Info** (`customer_info`, `text`, required: false): This field is for the customer's name and any other relevant contact information.
* **Appointment Time** (`appointment_time`, `select_one`, required: true): Select a time for the installation appointment. Options are 8:00 AM, 9:00 AM, and 10:00 AM.
* **Job Details** (`job_details`, `text`, required: false): Enter any relevant details about the job.
* **Installation Date** (`installation_date`, `date`, required: false): Enter the desired date for the installation.
* **Notes** (`notes`, `note`, required: false): Leave any additional comments for the electrician.
* **Email** (`email`, `email`, required: false): Enter your email address for communication purposes.
* **Phone** (`phone`, `text`, required: false): Enter your phone number for communication purposes.
* **Address** (`address`, `text`, required: false): Enter your property address.
* **Property Manager Info** (`property_manager_info`, `text`, required: false): If applicable, provide contact information for the property manager.
* **Electrician Contact Info** (`electrician_contact_info`, `text`, required: false): If applicable, provide contact information for the electrician.
* **Customer Signature** (`customer_signature`, `note`, required: false): Sign this form to confirm your request.

## Tips
Make sure to fill out all the necessary fields and follow the guidelines above to ensure your request is processed efficiently.
