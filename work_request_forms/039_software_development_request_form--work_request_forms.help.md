# Software Development Request Form - Help Guide
## Purpose
This form is designed to gather project details, priority, and other relevant information for efficient project management and tracking.

## How To Complete This Form
1. Fill in the project information (project name, description, and tags).
2. Determine if the project has priority status.
3. List multiple project managers and development team members.
4. Populate the deadline field with a date in the correct format (YYYY-MM-DD).
5. Fill in the description field with a brief summary of the project.
6. Select the status of the project.
7. List the assigned personnel.
8. Add any additional comments or notes about the project.
9. Optionally, add custom text fields for project-specific information.

## Field-by-Field Explanation

* **Project Info** (`project_info`, text): Enter a brief project title and description.
* **Project Requirements** (`project_requirements`, text): Add any project-specific requirements or details.
* **Priority** (`priority`, select_one): Select 'Yes' if the project has priority status, 'No' otherwise.
* **Project Manager** (`project_manager`, select_multiple): Select multiple project managers (e.g., multiple team leads).
* **Development Team** (`development_team`, select_multiple): Select multiple development team members.
* **Description** (`description`, text): Enter a brief summary of the project.
* **Deadline** (`deadline`, date): Enter the project deadline in the format YYYY-MM-DD.
* **Status** (`status`, select_one): Select the current status of the project.
* **Assigned To** (`assigned_to`, select_multiple): Select the personnel assigned to the project.
* **Comments** (`comments`, text): Add any additional comments or notes about the project.
* **Tags** (`tags`, text): Add any relevant tags for project search and filtering.
* **Files** (`files`, text): Attach any relevant files for project documentation.
* **URL** (`url`, text): Enter a URL for project documentation or resources.
* **Phone** (`phone`, text): Enter a contact phone number for project communication.
* **Email** (`email`, email): Enter the contact email address for project communication.
* **Date Created** (`date_created`, date): This field is automatically populated with the date the form was created.
* **Date Modified** (`date_modified`, date): This field is automatically populated with the date the form was last modified.
* **User Created** (`user_created`, select_multiple): Select the user who created the project (if applicable).
* **User Modified** (`user_modified`, select_multiple): Select the user who last modified the project (if applicable).
* **Created By** (`created_by`, select_multiple): Select the user(s) who created the form (if applicable).
* **Modified By** (`modified_by`, select_multiple): Select the user(s) who modified the form (if applicable).
* **Custom Text 1** (`custom_text1`, text): Enter a custom text field for project-specific information.
* **Custom Text 2** (`custom_text2`, text): Enter a custom text field for project-specific information.
* **Custom Text 3** (`custom_text3`, text): Enter a custom text field for project-specific information.
* **Custom Text 4** (`custom_text4`, text): Enter a custom text field for project-specific information.

Note to the developer: This form has been designed to capture a wide range of project data. Please ensure that each field is populated accurately and consistently to maintain data integrity.
