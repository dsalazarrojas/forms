# public_works_service_request_form - Help Guide
## Purpose
The Public Works Service Request Form is designed to collect information for work requests in various contexts. This form aims to gather data from users, enabling efficient management and processing of these requests.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required and optional fields as needed.
2. Ensure you've provided all necessary information for a proper evaluation or handling of your request.
3. Review your submission to guarantee it's accurate and complete.

## Field-by-Field Explanation
* **Work Request** (`work_request`, text, required/optional): Enter a clear and concise description of the work or service request.
* **Category** (`category`, select one, optional): Select the type of request (e.g., Service Request, Work Order, Other) that best describes your requirement.
* **Description** (`description`, text, required/optional): Provide a detailed explanation of the request, including any specific requirements or constraints.
* **Resident Information** (`resident_info`, text, required/optional): Enter any relevant information about the resident or individual related to this request.
* **Contact Information** (`contact_info`, text, required/optional): Enter your or the resident's contact details for follow-up and further communication.
* **Location** (`location`, text, required/optional): Specify the location or relevant geographical context related to the request.
* **Service Requested** (`service_requested`, text, required/optional): Clearly state the specific service required to fulfill this request.
* **Request Priority** (`request_priority`, select one, optional): Select a priority level for your request, with options: High, Medium, Low.
* **Request Date** (`request_date`, date, required/optional): Enter the date when the request was made, if applicable.
* **Assigned To** (`assigned_to`, select multiple, required/optional): Choose the personnel or team members responsible for handling this request.

Note: Ensure that you only select options that apply to your specific context. If a field is not relevant, you may leave it blank or skip it.
