# Facilities Work Order Request - Help Guide
## Purpose
The purpose of this form is to request facility-related services from the maintenance team. It is used to submit work orders for various maintenance tasks, repairs, or upgrades.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the main page with the main page label.
2. On the location page, enter the location where the maintenance task is required.
3. In the request details page, provide a detailed description of the maintenance task, including any specific issues or concerns.
4. If applicable, upload attachments related to the request, such as images or documents.
5. Review and submit the form to send the request to the maintenance team.

## Field-by-Field Explanation
* **Location Page**: Enter the location where the maintenance task is required. This could be a specific room, building, or area within the facility.
* **Request Details**: Provide a detailed description of the maintenance task, including any specific issues or concerns. Be as clear and concise as possible to ensure the maintenance team understands the task.
* **Attachments**: If you have any relevant images, documents, or other files related to the request, upload them here to support your submission. This could include photos of the issue or relevant diagrams.
 
## Tips
* Be sure to provide clear and concise information in the request details field to ensure the maintenance team can quickly understand the task.
* If possible, include any relevant images or documents to support your request.
* Make sure to review and submit the form carefully before sending it to the maintenance team.
