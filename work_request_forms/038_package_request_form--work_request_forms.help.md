# Package Request Form - Help Guide
## Purpose
The Package Request Form is used to collect information from users about their package requests. This form is typically used by package requesters to submit their requests for new packages.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each section of the form, starting from the first page.
2. Ensure all required fields are filled out before proceeding to the next page.
3. Review your answers before submitting the form to ensure accuracy and completeness.

## Field-by-Field Explanation
- **Package Type** (`Package Type`, select_one, required): Select 'Yes' or 'No' to indicate if this is a new package request or a renewal.
  - If you select 'Yes', you will be asked to provide more information about the package.
  - If you select 'No', you will be asked to provide more details about the renewal.
- **Request Details** (`Request Details`, select_multiple, required): Choose all applicable options to describe your package request.
  - This field is used to provide more information about your package request.
- **Date Requested** (`Date Requested`, date, required): Enter the date when you would like to start using the package.
  - Please format the date in the correct format (e.g., MM/DD/YYYY).
- **Time Requested** (`Time Requested`, time, required): Select the time you would like to start using the package.
  - Please select from the available time slots.
- **Package Requester Name** (`Package Requester Name`, text, required): Enter the name of the person requesting the package.
  - Please use the full name of the person making the request.
- **Package Requester Contact** (`Package Requester Contact`, text, optional): If you'd like to provide your contact information for follow-up, enter your contact information here.
  - If this field is left blank, our team will need to contact you separately.
- **Package Requester Email** (`Package Requester Email`, email, required): Enter the email address associated with the package requester.
  - Please ensure the email address is correct and valid.
- **Package Requester Phone** (`Package Requester Phone`, text, required): Enter the phone number of the person requesting the package.
  - Please use the correct format for phone numbers (e.g., 123-456-7890).
- **Additional Notes** (`Additional Notes`, text, optional): If you'd like to add any additional information about your package request, use this field.
  - This can be used to provide more context or details about your request.
