# Well Water System Maintenance Request Form - Help Guide
## Purpose
This form is used to request maintenance for the well water system. It collects information about the maintenance request, such as the type of maintenance needed, the location where it will be performed, and the person responsible for submitting the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of maintenance required for the well water system (Water System, Electrical System, Pump, Drain, Pipe, or Valve).
2. Enter the location where the maintenance will take place.
3. Enter a brief description of the maintenance request.
4. Select the person assigned to perform the maintenance.
5. Set the priority of the maintenance request (not required but recommended).
6. Set the status of the request (required but not visible to the user).
7. Select the person who submitted the request.
8. (Optional) Attach any supporting files or notes related to the request.

## Field-by-Field Explanation

* **Well ID** (`well_id`): The unique ID of the well that requires maintenance. 
* **Location ID** (`location_id`): The location where the maintenance will take place.
* **Maintenance Request** (`maintenance_request`): A brief description of the maintenance request.
* **Description** (`description`): Additional details about the maintenance request.
* **Maintenance Type** (`maintenance_type`): The type of maintenance required for the well water system (Water System, Electrical System, Pump, Drain, Pipe, or Valve).
* **Maintenance Date** (`maintenance_date`): The date when the maintenance will be performed. (Note: This field is not required but recommended).
* **Maintenance Time** (`maintenance_time`): The time when the maintenance will be performed. (Note: This field is not required but recommended).
* **Maintenance Location** (`maintenance_location`): The location where the maintenance will be performed.
* **Contact Name** (`contact_name`): The name of the contact person.
* **Contact Email** (`contact_email`): The email address of the contact person.
* **Contact Phone** (`contact_phone`): The phone number of the contact person.
* **Priority** (`maintenance_priority`): A numerical value to set the priority of the maintenance request. (Note: Not required but recommended).
* **Assigned To** (`assigned_to`): The person assigned to perform the maintenance.
* **Comments** (`comments`): Additional comments about the maintenance request.
* **Attachment** (`attachment`): A file or note that can be attached to the request.
* **Notes** (`notes`): Additional notes about the maintenance request.
* **Status** (`status`): The status of the maintenance request.
* **Submitted By** (`submitted_by`): The person who submitted the request.
* **Submitted Time** (`submitted_time`): The time when the request was submitted. (Note: This field is not required but recommended).
* **Submitted Date** (`submitted_date`): The date when the request was submitted. (Note: This field is not required but recommended).
* **Submitted Location** (`submitted_location`): The location where the request was submitted.
* **Form Footer** (`form_footer`): The footer of the form.
* **Form Comments** (`form_comments`): Additional comments about the form.
