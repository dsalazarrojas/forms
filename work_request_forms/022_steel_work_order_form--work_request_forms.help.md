# Steel Work Order Form - Help Guide
## Purpose
The Steel Work Order Form is a digital submission tool used by customers to place new steel work orders. This form helps the customer provide essential information about their request, including client details, work order type, material type, quantity, unit price, and any additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your Client ID, which is a unique identifier assigned to you by our company for tracking purposes.
2. Select the correct Order Date for when your work order is needed.
3. Choose the Work Order Type from the available options: Fabricated, Non-Fabricated, or Custom.
4. Select the Material Type from the available options: Aluminum, Steel, Stainless Steel, Copper, or Brass.
5. Enter the quantity of the steel work order required.
6. Enter the Unit Price for the work order.
7. Optionally, enter a Discount if applicable.
8. Add any additional Notes about your work order.
