# smart_power_outlet_installation_request_form - Help Guide
## Purpose
The smart power outlet installation request form is a request for a smart power outlet installation in a residential or commercial building. It is used to collect information from the end-user about the installation requirements, contact information, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your user input in the first field.
2. Provide detailed installation information in the second field.
3. Choose the installation date and time in the third field.
4. Select the installation time in the fourth field.
5. Enter your contact number in the fifth field.
6. Enter your email in the sixth field.
7. Enter your address in the seventh field.
8. Add any additional comments in the eighth field.
9. Select the assigned user for the installation from the dropdown list in the ninth field.

## Field-by-Field Explanation

* **User Input (1)**: This field is for entering any additional information about the user or the request.
* **Installation Details (2)**: This field is for providing detailed information about the installation requirements.
* **Installation Date (3)**: This field is for selecting the date of the installation.
* **Installation Time (4)**: This field is for selecting the time of the installation.
* **Contact Number (5)**: This field is for entering your contact number in case of any questions or concerns.
* **Email (6)**: This field is for entering your email address in case of any questions or concerns.
* **Address (7)**: This field is for entering your address where the installation will take place.
* **Additional Comments (8)**: This field is for adding any additional information or comments about the installation.
* **Assigned User (9)**: This field is for selecting the technician who will be assigned to perform the installation.
