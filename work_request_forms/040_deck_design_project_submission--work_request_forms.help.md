# Deck Design Project Submission - Help Guide
## Purpose
This form is for project stakeholders to submit project information for a deck design project.

## How To Complete This Form
- Fill out the form with all relevant project details.
- Ensure you have all necessary attachments (files) ready.
- Provide accurate measurements for the project.
- Add any required images.
- Specify the project manager, designer, and contractor details.
- Choose the project start and end dates.
- Select the project status (Active, In Progress, Completed, On Hold, or Cancelled).
- Add any additional notes if needed.
- Provide contact information (email, phone, address, city, state, and zip code).

## Field-by-Field Explanation

* **Project Details**: A short description of the project. This will help project stakeholders understand the project scope.
* **Files**: Attach any necessary files related to the project, such as project specifications or designs.
* **Measurements**: Provide accurate measurements for the project, including length, width, and height.
* **Deck Images**: Add any images related to the project, such as floor plans or elevation drawings.
* **Project Manager**: Enter the name and contact information of the project manager.
* **Designer**: Enter the name and contact information of the designer.
* **Contractor**: Enter the name and contact information of the contractor.
* **Project Start Date**: Enter the date the project is expected to start.
* **Project End Date**: Enter the date the project is expected to end.
* **Project Status**: Select the current status of the project (Active, In Progress, Completed, On Hold, or Cancelled).
* **Notes**: Add any additional notes or comments about the project.
* **Email**: Enter the email address of the project contact.
* **Phone**: Enter the phone number of the project contact.
* **Address**: Enter the address of the project contact.
* **City**: Enter the city of the project contact.
* **State**: Enter the state of the project contact.
* **Zip Code**: Enter the zip code of the project contact.

Note: Please ensure that all fields are filled out correctly and accurately. If you are unsure about any field, please reach out to the project manager or designer for clarification.
