# Assisted Living Work Order Request - Help Guide

## Purpose
The Assisted Living Work Order Request form is used to report maintenance issues within the assisted living facility. This form allows residents, family members, and staff to submit requests for repairs, maintenance, or other services. The form provides a standardized way to document the issue, including details about the location, priority level, and any potential safety hazards. The submitted request will be reviewed and addressed by the maintenance team.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the date and time of the request in the **Request Date** and **Request Time** fields.
2.  Provide your name and role in the **Requester Name** and **Requester Role** fields.
3.  If the request is related to a specific resident, enter their name in the **Resident Name** field.
4.  Indicate the location of the issue by entering the **Room or Unit Number** and **Building or Wing** fields.
5.  Select the **Issue Category** that best describes the problem (e.g., Plumbing, Electrical, etc.).
6.  Describe the issue in detail in the **Issue Description** field.
7.  Specify the exact location of the issue in the **Specific Location** field.
8.  Choose the priority level of the issue (e.g., Emergency - Immediate, High - Within 4 Hours, etc.).
9.  Indicate if the issue is a safety hazard and provide additional details if necessary.
10. Confirm if the issue affects resident care and specify the level of impact.
11. Select the best time to contact you for updates or questions.
12. If applicable, provide a preferred completion date for the repair.
13. Attach any photos or documentation related to the issue.
14. Confirm if this issue has been reported before and the date of the previous report.
15. Specify any special requirements for the repair.
16. Identify who the issue was assigned to for resolution.
17. Enter the estimated completion date for the repair.
18. Indicate if parts are required and if they are in stock.
19. Provide a date for when the repair was completed.
20. Describe the work performed to resolve the issue.
21. Enter the name of the technician who performed the work.
22. Rate your satisfaction with the service provided.
23. Confirm if follow-up is needed to ensure the issue is resolved.
24. Sign the form to confirm your request.

## Field-by-Field Explanation

*   **Request Date** (id: 1, type: date, required: true): Enter the date of the request.
*   **Request Time** (id: 2, type: time, required: true): Enter the time of the request.
*   **Requester Name** (id: 3, type: text, required: true): Enter your name as the requester.
*   **Requester Role** (id: 4, type: select_one, required: true): Choose your role (e.g., Resident, Family Member, Nurse, etc.).
*   **Resident Name** (id: 5, type: text, required: false): If the request is related to a specific resident, enter their name.
*   **Room or Unit Number** (id: 6, type: text, required: true): Enter the room or unit number where the issue is located.
*   **Building or Wing** (id: 7, type: text, required: false): Enter the building or wing where the issue is located.
*   **Issue Category** (id: 8, type: select_one, required: true): Choose the best description of the issue (e.g., Plumbing, Electrical, etc.).
*   **Issue Description** (id: 9, type: text, required: true): Describe the issue in detail.
*   **Specific Location** (id: 10, type: text, required: true): Specify the exact location of the issue.
*   **Priority Level** (id: 11, type: select_one, required: true): Choose the priority level of the issue (e.g., Emergency - Immediate, High - Within 4 Hours, etc.).
*   **Is This a Safety Hazard** (id: 12, type: select_one, required: true): Indicate if the issue is a safety hazard.
*   **Safety Details** (id: 13, type: text, required: false): Provide additional details about the safety hazard if applicable.
*   **Does This Affect Resident Care** (id: 14, type: select_one, required: true): Confirm if the issue affects resident care.
*   **Impact on Care** (id: 15, type: text, required: false): Specify the level of impact on resident care.
*   **Best Time to Contact** (id: 16, type: select_one, required: true): Choose the best time to contact you for updates or questions.
*   **Preferred Completion Date** (id: 17, type: date, required: false): Enter a preferred completion date for the repair if applicable.
*   **Number of Photos Attached** (id: 18, type: number, required: false): If applicable, enter the number of photos attached as documentation.
*   **Has This Been Reported Before** (id: 19, type: select_one, required: true): Confirm if the issue has been reported before.
*   **Previous Report Date** (id: 20, type: date, required: false): Enter the date of the previous report if applicable.
*   **Special Requirements** (id: 21, type: text, required: false): Specify any special requirements for the repair if applicable.
*   **Assigned To** (id: 22, type: text, required: false): Identify who the issue was assigned to for resolution.
*   **Estimated Completion** (id: 23, type: date, required: false): Enter the estimated completion date for the repair.
*   **Are Parts Needed** (id: 24, type: select_one, required: false): Indicate if parts are required for the repair and if they are in stock.
*   **Work Completed Date** (id: 25, type: date, required: false): Enter the date the repair was completed.
*   **Work Performed Description** (id: 26, type: text, required: false): Describe the work performed to resolve the issue.
*   **Technician Name** (id: 27, type: text, required: false): Enter the name of the technician who performed the work.
*   **Resident Satisfaction** (id: 28, type: select_one, required: false): Rate your satisfaction with the service provided.
*   **Is Follow-up Needed** (id: 29, type: select_one, required: false): Confirm if follow-up is needed to ensure the issue is resolved.
*   **Requester Signature** (id: 30, type: text, required: true): Sign the form to confirm your request.

## Tips
*   Attach photos or documentation related to the issue to aid in the resolution process.
*   Be as detailed as possible in describing the issue to ensure accurate resolution.
