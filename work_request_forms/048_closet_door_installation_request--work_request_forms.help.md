# Closet Door Installation Request - Help Guide
## Purpose
The purpose of this form is to gather information from customers who are requesting installation services for closet doors. It is designed to collect relevant details about the customer's closet space, preferences, and needs.

## How To Complete This Form

1. Please fill out the form completely and honestly. Incomplete or inaccurate information may delay the process of creating an estimate for your closet door installation services.
2. Please use the following format as a guide:
	* First name and last name in the format "First Name Last Name".
	* Enter your email address in the format "example@example.com" or "123 Main St".
	* Enter your phone number in the format "(123) 123-1234".
	* Enter your property address in the format "123 Main St, Anytown, USA 12345".
	* Select the correct property type from the options provided (e.g. Single Family Home, Apartment, etc.)
	* Select "Yes, Owner" if you own the property, "No Renter" if you rent, or "Property Manager" if you are a property manager.
	* If you are a renter, please select "Yes, Renting" for the "Landlord Approval Obtained" field.
	* Select how many closets need installation services.
	* List the locations where the closets need installation services.
	* Select the type of doors you want to install.
	* Select the preferred material for the doors.
	* Select the preferred style for the doors.
	* Enter the preferred color or finish for the doors.
	* Enter the closet opening width, height, and depth in inches.
	* Select whether existing doors need to be removed.
	* Select whether existing hardware will be reused.
	* Select any additional features you want to include.
	* Enter your estimated budget range.
	* Select your desired completion timeline.
	* Select your preferred installation date.
	* If necessary, please provide any access considerations (e.g. stairs, elevator, narrow hallways).
	* Select how you heard about us.
	* Select whether you need an in-home consultation.
	* Enter any additional comments or special requests.
	* Finally, please indicate your agreement to receive an estimate.

## Field-by-Field Explanation

* **Request Date**: Enter the date you are requesting the closet door installation services.
* **First Name**: Enter your first name.
* **Last Name**: Enter your last name.
* **Email Address**: Enter your email address in the format "example@example.com" or "123 Main St".
* **Phone Number**: Enter your phone number in the format "(123) 123-1234".
* **Property Address**: Enter your property address in the format "123 Main St, Anytown, USA 12345".
* **Property Type**: Select the correct property type from the options provided (e.g. Single Family Home, Apartment, etc.).
* **Do You Own the Property**: Select "Yes Owner" if you own the property, "No Renter" if you rent, or "Property Manager" if you are a property manager.
* **Landlord Approval Obtained**: If you are a renter, select "Yes, Renting" for this field.
* **How Many Closet Doors Need Installation**: Select the number of closets that need installation services.
* **Closet Locations**: List the locations where the closets need installation services (e.g. Master bedroom, hallway, etc.).
* **Type of Doors Desired**: Select the type of doors you want to install (e.g. Sliding Doors, Bifold Doors, etc.).
* **Preferred Door Material**: Select the preferred material for the doors (e.g. Wood, MDF, Glass, etc.).
* **Preferred Door Style**: Select the preferred style for the doors (e.g. Modern, Traditional, Rustic, etc.).
* **Preferred Color or Finish**: Enter the preferred color or finish for the doors.
* **Closet Opening Width**: Enter the width of the closet opening in inches.
* **Closet Opening Height**: Enter the height of the closet opening in inches.
* **Closet Opening Depth**: Enter the depth of the closet opening in inches (optional).
* **Are There Existing Doors to Remove**: Select whether existing doors need to be removed.
* **Will Existing Hardware Be Reused**: Select whether existing hardware will be reused.
* **Additional Features Desired**: Select any additional features you want to include (e.g. Soft-Close Mechanism, Magnetic Catches, etc.).
* **Estimated Budget Range**: Select your estimated budget range.
* **Desired Completion Timeline**: Select your desired completion timeline.
* **Preferred Installation Date**: Enter your preferred installation date.
* **Any Access Considerations**: Enter any access considerations (e.g. stairs, elevator, narrow hallways).
* **How Did You Hear About Us**: Select how you heard about us (e.g. Referral, Online Search, Social Media, etc.).
* **Do You Need an In-Home Consultation**: Select whether you need an in-home consultation.
* **Additional Comments or Special Requests**: Enter any additional comments or special requests.
* **I Agree to Receive an Estimate**: Finally, please indicate your agreement to receive an estimate.

## Tips

* Please fill out the form completely and honestly.
* If you are unsure about any of the fields, please feel free to ask us for clarification.
* We will contact you with any additional questions or concerns we may have after reviewing your form submission.
* We will provide you with an estimate based on the information you provide.
