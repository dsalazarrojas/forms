# Theater Prop Maintenance Request Form - Help Guide
## Purpose
The Theater Prop Maintenance Request Form is used to submit requests for theater prop maintenance, including repairs, replacements, or new prop acquisitions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Request Type" that best describes the nature of your request.
2. Enter the name of the prop that requires maintenance.
3. Provide a brief description of the prop and the nature of the maintenance request.
4. Select the location where the prop is currently being stored or used.
5. Assign the request to a specific team member or individual.
6. Enter the date you originally requested the maintenance.
7. Select the status of the request (Open, In Progress, Closed).
8. Provide any additional comments or notes as needed.

## Field-by-Field Explanation

* **Request Type** (Select One): Select a category for your request (General Maintenance, Repair, Request for new prop).
* **Prop Name**: Enter the name of the prop that requires maintenance.
* **Description**: Provide a brief description of the prop and the nature of the maintenance request.
* **Location**: Enter the location where the prop is currently being stored or used.
* **Assigned To**: Select a team member or individual who will handle the request.
* **Request Date**: Enter the date you originally requested the maintenance.
* **Status**: Select the current status of the request (Open, In Progress, Closed).
* **Comments**: Provide any additional comments or notes as needed.
* **Attachments**: Upload any relevant files or images to support your request.
* **Related Work Orders**: Select any existing work orders related to this request.
* **Priority**: Select the priority level of the request (High, Medium, Low).
* **Estimated Duration**: Select whether the maintenance will require a specific duration.
* **Estimated Cost**: Enter an estimated cost for the maintenance.
* **Status Comments**: Provide any comments on the status of the request.
* **Request Type Comments**: Provide any comments on the request type.
* **Prop Name Comments**: Provide any comments on the prop name.
* **Description Comments**: Provide any comments on the description of the request.
* **Attachments**: Upload any additional files or images to support your request.

Note: All fields are optional unless specified as required. Please fill out as much information as possible to ensure efficient handling of your request.
