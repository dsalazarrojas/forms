# project_charter_form - Help Guide
## Purpose
The project charter form is used to collect and document essential information about a project. This form helps stakeholders, team members, and sponsors to understand the project's objectives, scope, and key performance indicators (KPIs).

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the "Project Info" page with the basic details of the project.
2. Move on to the "Financial Details" page and provide the necessary financial information.
3. On the "Targeted KPI" page, specify the Key Performance Indicators (KPIs) that will measure the project's success.
4. The "Budget" page requires input on the allocated budget for the project.
5. In "Milestones", list the important milestones and deadlines for the project.
6. "Risks" should be filled with potential risks and challenges that may hinder the project's progress.
7. The "Impact" page is for describing the potential impact of the project on the organization or stakeholders.
8. Finally, specify the "Assigned Tool" used for project management.

## Field-by-Field Explanation

* **Project Info** (Project Info, Text, Required): Enter a brief description of the project, including its name, objectives, and scope.
* **Financial Details** (Financial Details, Text, Optional): Provide financial information about the project, such as the allocated budget and funding sources.
* **Targeted KPI** (Targeted KPI, Text, Optional): Specify the Key Performance Indicators (KPIs) that will measure the project's success.
* **Budget** (Budget, Text, Optional): Enter the allocated budget for the project.
* **Milestones** (Milestones, Text, Optional): List important milestones and deadlines for the project.
* **Risks** (Risks, Text, Optional): Identify potential risks and challenges that may hinder the project's progress.
* **Impact** (Impact, Text, Optional): Describe the potential impact of the project on the organization or stakeholders.
* **Assigned Tool** (Assigned Tool, Text, Optional): Specify the project management tool assigned to the project.

## Tips
* Be as detailed as possible when filling out the form to ensure that all stakeholders are informed about the project.
* Review and update the form regularly to ensure that it accurately reflects the project's current status.
* Use the project charter as a guide for project planning, execution, and monitoring.
