# Job Estimate Request Form - Help Guide
## Purpose
The Job Estimate Request Form is a tool for gathering essential information from clients to generate an estimate for a job. This form is designed to be as brief as possible while still collecting the necessary details needed for the estimate.

## How To Complete This Form
1. Fill out the form with the requested information about the client.
2. Ensure that all required fields are filled out, if any.
3. Provide the completed form to the relevant team members for the next steps in the job process.

## Field-by-Field Explanation
* **Estimate Request (estimate_request)**: This is a text field that will be used to generate the job estimate. Provide a brief description of the job or the specific requirements.
* **Client Name (client_name)**: Enter the full name of the client.
* **Client Address (client_address)**: Enter the client's address, including the street address or postal/physical address.
* **Client City (client_city)**: Enter the city where the client is located.
* **Client State (client_state)**: Enter the state or province where the client is located.
* **Client Zip (client_zip)**: Enter the client's zip or postal code.
* **Client Phone (client_phone)**: Enter the client's phone number for contact purposes.
* **Client Email (client_email)**: Enter the client's email for contact purposes.

## Tips
- If you need to collect more information, please create an additional form for the specific job estimate.
- If you need to add more fields to this form, please do not hesitate to reach out to form@gic.mx for further assistance.
