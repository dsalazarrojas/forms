# Parental Leave Absence Form - Help Guide
## Purpose
The Parental Leave Absence Form is used to request and process parental leave for employees, ensuring a fair and efficient process for both the employee and management.

## How To Complete This Form
To complete this form, follow these steps:

1. **Employee Request**: Enter a brief description of the reason for the leave in the "Employee Request" field.
2. **Start Date**: Select the start date of the leave from the calendar.
3. **End Date**: Select the end date of the leave from the calendar.
4. **Reason**: Provide a detailed explanation of the reason for the leave.
5. **Manager Approval**: Select "Yes" or "No" to indicate if the manager approves the leave request.
6. **Employee Name**: Enter the employee's name.
7. **Employee ID**: Enter the employee's ID number.
8. **Start Time**: Enter the start time of the leave.
9. **End Time**: Enter the end time of the leave.
10. **Manager Note**: Add any additional notes or comments from the manager.
11. **Manager Approval Status**: Select "Active" or "Inactive" to indicate the status of the manager's approval.
12. **Company Note**: Add any additional comments or notes from the company.
13. **Employee Response**: Enter any response or comments from the employee.

## Field-by-Field Explanation
### Employee Request (1)
* **Employee Request (Text)**: This field is used to enter a brief description of the reason for the leave.

### Start Date (2)
* **Start Date**: Select the date from the calendar when the leave starts.

### End Date (3)
* **End Date**: Select the date from the calendar when the leave ends.

### Reason (4)
* **Reason**: Provide a detailed explanation of the reason for the leave.

### Manager Approval (5)
* **Manager Approval (Select One)**: Select "Yes" to indicate approval or "No" to decline the leave request.

### Employee Name (6)
* **Employee Name**: Enter the name of the employee requesting the leave.

### Employee ID (7)
* **Employee ID**: Enter the ID number of the employee requesting the leave.

### Start Time (8)
* **Start Time**: Enter the time when the leave starts.

### End Time (9)
* **End Time**: Enter the time when the leave ends.

### Manager Note (10)
* **Manager Note**: Add any additional notes or comments from the manager.

### Manager Approval Status (11)
* **Manager Approval Status (Select Multiple)**: Select "Active" to indicate approval or "Inactive" to decline the leave request.

### Company Note (12)
* **Company Note**: Add any additional comments or notes from the company.

### Employee Response (13)
* **Employee Response**: Enter any response or comments from the employee.
