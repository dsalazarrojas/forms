# Zoological Conservation Leave Of Absence Form - Help Guide
## Purpose
The purpose of this form is to request a leave of absence for an employee. It captures various details about the employee's status, team, shift, and manager information.

## How To Complete This Form
* Fill out the form carefully and accurately.
* Complete all required fields.
* Ensure that you have obtained necessary manager approvals or signatures before submitting the form.

* **End Date (#3)**: The date the leave is expected to end. Use the date format (YYYY-MM-DD) to ensure accurate processing.
* **Reason (#4)**: A brief description of the reason for the leave request. This is optional but helps provide context.
* **Manager Approval (#5)**: Select 'Yes' if the manager has approved the leave request.
* **Employee Status (#6)**: Select 'Active' if the employee is currently working, or 'Inactive' if they are not.
* **Department (#7)**: Select which department the employee belongs to. This helps with internal resource allocation.
* **Location (#8)**: Optional field to provide any specific location information.
* **Shift Coverage (#9)**: Optional field for additional shift details. If the employee has shift coverage, indicate here.
* **Coverage Requested (#10)**: The number of shifts or hours to be covered.
* **Approval Note (#11)**: Optional notes for the manager to comment on the request.
* **Leave Start (#12)**: The number of days before the leave starts.
* **Leave End (#13)**: The number of days after the leave starts.
* **Approval Status (#14)**: Select 'Active' or 'Inactive' to indicate the approval status.
* **Manager Email (#15)**: The manager's email address. This is required for communication purposes.

* **Manager Name (#17)**: The manager's name. This is optional but helps with communication.

* **Team Member (#19)**: Select if the employee is a team member.
