# Library Archival Research Leave Of Absence Form - Help Guide
## Purpose
The Library Archival Research Leave Of Absence Form is used to document and track employee absences related to research or other activities in a library or archival setting. This form helps to ensure that employees are aware of their absence and its impact on the team, and that necessary arrangements are made to minimize disruption to work.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a title for the form, e.g., "Research Leave Request: John Doe, 3 days".
2. Select the category for the form from the list provided. This will help us understand the type of form you are creating.
3. Enter a brief description of the reason for the absence.
4. Enter the form ID if applicable.
5. Select the tool or system that this form will be used with, if applicable.
6. Enter the output file if required.
7. Enter the name of the person creating this form.
8. Click submit to complete the form.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, required/optional): Enter a brief title that describes the reason for the form.
* **Category** (`category`, select_multiple, required/false): Select the type of form you are creating, e.g., Leave of Absence Forms, Request Forms, or Other.
* **Description** (`description`, text, required/false): Enter a brief description of the reason for the absence.
* **Form ID** (`form_id`, number, required/false): Enter the ID number for the form if applicable.
* **Assigned Tool** (`assigned_tool`, text, required/false): Select the tool or system that this form will be used with, if applicable.
* **Output File** (`output_file`, text, required/false): Enter the output file if required.
* **Created By** (`created_by`, text, required/false): Enter the name of the person creating this form.
