# leave_cancellation_form - Help Guide
## Purpose
The purpose of this form is to facilitate the cancellation of leave requests. It ensures that all relevant information is recorded and verified to maintain an accurate and up-to-date record of employee leave.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the details of the leave request you are cancelling.
2. Enter the reason for cancellation (Field 1: Cancellation Reason).
3. Enter the date of cancellation (Field 2: Date of Cancellation).
4. Enter the Employee ID (Field 3: Employee ID).
5. Confirm whether the manager has acknowledged the cancellation (Field 4: Manager Confirmation).
6. Enter any manager comments, if necessary (Field 5: Manager Comment).
7. Confirm whether the employee has acknowledged the cancellation (Field 6: Employee Confirmation).
8. Enter any employee comment (Field 7: Employee Acknowledgement).
9. Select the status of the cancellation (Field 8: Manager Approval).
10. Submit the form once you have reviewed and confirmed all the information.

## Field-by-Field Explanation

* **Cancellation Reason** (Field 1, text, optional): Enter a brief description of the reason for cancelling the leave request.
* **Reason for Cancellation** (Field 2, text, optional): Enter a detailed explanation for the cancellation reason, if necessary.
* **Date of Cancellation** (Field 3, date, optional): Enter the date on which the leave request is being cancelled.
* **Employee ID** (Field 4, number, optional): Enter the unique identifier for the employee whose leave request is being cancelled.
* **Manager Confirmation** (Field 5, select_one, optional): Check Yes if the manager acknowledges the cancellation.
* **Manager Comment** (Field 6, text, optional): Enter any comments from the manager regarding the cancellation.
* **Employee Confirmation** (Field 7, select_one, optional): Check Yes if the employee acknowledges the cancellation.
* **Employee Acknowledgement** (Field 8, select_one, optional): Enter Yes if the employee has acknowledged the cancellation.
* **Manager Approval** (Field 9, select_one, optional): Select the status of the cancellation as Pending, Approved, or Denied.
* **Employee Acknowledgement** (Field 10, select_one, optional): Check Yes if the employee has acknowledged the cancellation. 

**Tips**: Make sure to carefully review all fields before submitting the form to ensure accuracy and completeness. If any field is not applicable, simply leave it blank.
