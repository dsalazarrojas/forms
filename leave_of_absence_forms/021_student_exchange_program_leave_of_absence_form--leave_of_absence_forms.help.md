# Student Exchange Program Leave Of Absence Form - Help Guide
## Purpose
This form is designed to be used by students participating in an exchange program to request a leave of absence. It is used to gather information about the student's leave of absence, including the start and end dates, reason for leave, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's details in the "student_details" field.
2. Enter the start and end dates of the absence in the "leave_start_date" and "leave_end_date" fields, respectively.
3. Provide a reason for the leave in the "reason_for_leave" field.
4. Enter the expected return date in the "expected_return_date" field.
5. Add any additional comments in the "comments" field.
6. Enter the name of the person submitting the request in the "submitted_by" field.
7. Select the status of the request in the "status" field.
8. Enter the university and department information in the "university" and "department" fields, respectively.
9. Enter the name of the contact person in the "contact_person" field.

## Field-by-Field Explanation

* **Student Details** (`student_details`, text, optional): Enter the student's name, ID number, or other relevant student information.
* **Leave Start Date** (`leave_start_date`, date, optional): Enter the start date of the absence.
* **Leave End Date** (`leave_end_date`, date, optional): Enter the end date of the absence.
* **Reason for Leave** (`reason_for_leave`, text, optional): Provide a brief reason for the leave of absence.
* **Expected Return Date** (`expected_return_date`, text, optional): Enter the expected return date.
* **Comments** (`comments`, text, optional): Add any additional comments or explanations.
* **Submitted By** (`submitted_by`, text, optional): Enter the name of the person submitting the request.
* **Status** (`status`, select_one, required): Select the status of the request (Awaiting review, Approved, or Rejected).
* **University** (`university`, text, optional): Enter the name of the university.
* **Department** (`department`, text, optional): Enter the department name.
* **Contact Person** (`contact_person`, text, optional): Enter the name of the contact person.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Use clear and concise language when filling out the form.
* If you have any questions or concerns, please do not hesitate to contact the form submitter's contact person.
