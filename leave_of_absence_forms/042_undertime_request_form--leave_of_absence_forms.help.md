# Untime request form - Help Guide
## Purpose
This form is used to request an unavailability or leave of absence. Fill out the required fields to submit your request and it will be evaluated by your manager for approval.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the required fields:
	* Employee ID (employee_id): A unique identifier for the employee submitting the request.
	* Start Date (start_date): The date from which the employee wishes to start their unavailability.
	* End Date (end_date): The date on which the employee expects to return to work.
	* Status (status): A brief description of the reason for the unavailability.
	* Request Date (request_date): The date on which the request was made.
	* Request Time (request_time): The time of day when the request was made.
2. Provide optional fields:
	* Job Title (job_title): The title of the job position held by the employee.
	* Reason for Leave (reason): A more detailed explanation of the reason for the unavailability.
	* Manager ID (manager_id): A unique identifier for the manager responsible for the employee's work.
	* Manager Name (manager_name): The name of the manager.
	* Manager Email (manager_email): The email address of the manager.
3. Submit the request.

## Field-by-Field Explanation
- **Employee ID (employee_id)**: A unique identifier for the employee submitting the request.
- **Start Date (start_date)**: The date from which the employee wishes to start their unavailability.
- **End Date (end_date)**: The date on which the employee expects to return to work.
- **Job Title (job_title)**: The title of the job position held by the employee.
- **Reason for Leave (reason)**: A more detailed explanation of the reason for the unavailability.
- **Manager ID (manager_id)**: A unique identifier for the manager responsible for the employee's work.
- **Manager Name (manager_name)**: The name of the manager.
- **Manager Email (manager_email)**: The email address of the manager.
- **Status (status)**: A brief description of the reason for the unavailability.
- **Request Date (request_date)**: The date on which the request was made.
- **Request Time (request_time)**: The time of day when the request was made.
- **Comments (comments)**: An optional field to provide additional information.
- **Approved Status (approved_status)**: A select option to indicate the status of the request.
- **Approved By (approved_by)**: A select option to indicate who approved or rejected the request.
- **Approved Date (approved_date)**: The date on which the request was approved or rejected.
- **Assigned Tool (assigned_tool)**: A select option to indicate if a tool has been assigned to the employee for the unavailability.

Note: The form will ask for approval from the manager, and they will select the approved status and date. The approved status and date will be filled in automatically once the request is approved.
