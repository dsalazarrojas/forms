# IT Industry Crisis Leave Of Absence Form - Help Guide
## Purpose
This form is designed to collect information from IT industry employees who are requesting a crisis leave of absence. It is used to gather essential details about the employee's request, including their name, job title, start and end dates of the leave, reason for the leave, and status of the request.

## How To Complete This Form
To complete this form, follow these steps:

1.  Please ensure that you are using this form for a valid reason, such as a personal or family crisis.
2.  Fill in the required fields, including:
	*   Employee Name
	*   Job Title
	*   Start Date
	*   End Date
	*   Reason
3.  If applicable, fill in the optional fields, including:
	*   Manager Name (if you are a manager or representative)
	*   Manager Note (if you have additional comments or instructions for the manager)
4.  Select the status of the request from the dropdown menu:
	*   In Progress
	*   Approved
	*   Rejected
	*   On Hold

## Field-by-Field Explanation
* **Employee Name** (required): Enter the name of the employee requesting leave.
* **Job Title** (required): Enter the title of the employee's job in the IT industry.
* **Manager Name** (optional): If you are a manager or representative, enter your name.
* **Start Date** (required): Enter the start date of the crisis leave.
* **End Date** (required): Enter the end date of the crisis leave.
* **Reason** (required): Enter a brief description of the reason for the crisis leave.
* **Manager Note** (optional): If you have additional comments or instructions for the manager, enter them here.
* **Status** (optional): Select the status of the request from the dropdown menu:
	+ In Progress: The request is being processed.
	+ Approved: The request is approved.
	+ Rejected: The request is denied.
	+ On Hold: The request is pending further review or information.
