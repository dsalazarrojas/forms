# Performance Review Absence Form - Help Guide
## Purpose

This form is used to document and track employee absences from performance reviews. It helps to ensure that absences are properly documented and approved by relevant parties, ensuring continuity and accuracy in performance review processes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields, which are indicated by a red asterisk (*).
2. Select the correct options for each field as needed.
3. Ensure that the form is accurately and thoroughly completed before submitting it.

## Field-by-Field Explanation

### **Title** (`performance_review_absence_form`, text, optional)

This is the title of the form. It is not a required field, but it is a good idea to fill it in for reference purposes.

### **Absence Date** (`absence_date`, date, optional)

This field should be used to enter the date of the absence, if known. If the absence date is not known, leave this field blank.

### **Absence Hours** (`absence_hours`, number, optional)

This field should be used to enter the duration of the absence in hours. If the absence duration is not known, leave this field blank.

### **Absence Description** (`absence_description`, text, optional)

This field should be used to enter a brief description of the absence, if applicable. If the absence does not have a description, leave this field blank.

### **Absence Start Time** (`absence_start_time`, time, optional)

This field should be used to enter the start time of the absence, if applicable. If the absence start time is not known, leave this field blank.

### **Absence End Time** (`absence_end_time`, time, optional)

This field should be used to enter the end time of the absence, if applicable. If the absence end time is not known, leave this field blank.

### **Absence Start Date** (`absence_start_date`, date, optional)

This field should be used to enter the start date of the absence, if applicable. If the absence start date is not known, leave this field blank.

### **Absence End Date** (`absence_end_date`, date, optional)

This field should be used to enter the end date of the absence, if applicable. If the absence end date is not known, leave this field blank.

### **Absence Length** (`absence_length`, number, optional)

This field should be used to enter the duration of the absence, if applicable. If the absence duration is not known, leave this field blank.

### **Absence Type** (`absence_type`, select_one, optional)

This field should be used to select the type of absence. The options are:

* Yes
* No

Select "Yes" if the absence is applicable, "No" otherwise.

### **Absence Reason** (`absence_reason`, text, optional)

This field should be used to enter a brief reason for the absence, if applicable. If the absence reason is not known, leave this field blank.

### **Supervisor Approval** (`supervisor_approval`, select_one, optional)

This field should be used to select the supervisor or approver for the absence. The options are:

* Manager
* Director
* HR

Select the appropriate supervisor or approver from the list.
