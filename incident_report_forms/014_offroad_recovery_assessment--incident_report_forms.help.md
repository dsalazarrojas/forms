# Offroad Recovery Assessment - Help Guide
## Purpose
This form is used to document incidents where vehicles have gone off-road. It helps us gather essential information to assess the recovery process and provide guidance on how to handle such situations.

## How To Complete This Form
To complete this form, fill out the fields below. Please ensure that you answer each field accurately and fully.

## Field-by-Field Explanation
* **Incident Location**: Please enter a detailed description of the location where the incident occurred.
* **Vehicle Details**: Provide a description of the vehicle involved in the incident.
* **Hazards**: Indicate if any hazards were present during the incident. Select 'Yes' if hazards were present and 'No' if not.
* **Photos**: Attach any relevant photos of the incident location or vehicle.
* **Incident Date**: Enter the date of the incident in the format 'YYYY-MM-DD'.
* **Incident Time**: Enter the time of the incident in the format 'HH:MM:SS'.
* **Recovery Services**: Indicate if any recovery services were used. Select 'Yes' if services were used and 'No' if not.
* **Event Organiser**: Enter the name of the person or organisation responsible for the event that led to the off-road incident.

Tips:
* Ensure that all fields are filled out accurately and thoroughly.
* Attach clear and relevant photos to support your answers.
* If you are unsure about any field, please ask for clarification or assistance.
* If you have any further questions or concerns, please contact us for help.
