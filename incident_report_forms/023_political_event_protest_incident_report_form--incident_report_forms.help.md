# Political Event Protest Incident Report Form - Help Guide
## Purpose
The Political Event Protest Incident Report Form is designed to collect detailed information about a political event protest incident. This form will help in gathering a comprehensive report of the incident, including its date, location, and any injuries or police involvement.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the details of the protest event in the "protest event details" field.
2. Select the date of the event in the "protest event date" field.
3. Choose the time of the event in the "protest event time" field.
4. Enter a summary of the incident in the "incident summary" field.
5. Choose the type of incident from the options provided in the "protest event type" field.
6. If applicable, upload photos of the incident in the "incident photos" field.
7. Enter the location where the event occurred in the "protest event location" field.
8. Select the date and time of the report in the "report date" and "report time" fields, respectively.
9. Choose if there was a large crowd present in the "protest event participants" field.
10. Select if any participants were injured in the "injured participants" field.
11. Choose if police were involved in the "police involvement" field.
12. Select the status of the incident resolution in the "incident resolution" field.
13. Add any additional notes about the incident in the "notes" field.

## Field-by-Field Explanation

* **protest event details**: Enter a brief description of the event.
* **protest event date**: Enter the date of the event in the format MM/DD/YYYY.
* **protest event time**: Enter the time of the event in the format 12:00 PM.
* **incident summary**: Enter a summary of what happened during the event.
* **incident photos**: Upload photos of the incident to help provide a better understanding.
* **protest event location**: Enter the address or location where the event occurred.
* **report date**: Enter the date of the report.
* **report time**: Enter the time of the report.
* **protest event participants**: Select 'Yes' if there was a large crowd present, 'No' otherwise.
* **injured participants**: Select 'Yes' if any participants were injured, 'No' otherwise.
* **protest event type**: Choose the type of protest from the options provided.
* **police involvement**: Select 'Yes' if police were involved, 'No' otherwise.
* **incident resolution**: Select the status of the incident resolution from the options provided.
* **notes**: Add any additional notes about the incident.

## Tips

* Make sure to fill out all required fields.
* Be as detailed as possible when filling out the form.
* Use the "incident photos" field to upload relevant photos of the incident.
* If there were injuries, provide a brief description of the injuries.
* If police involvement is selected, provide a brief description of the police involvement.
