# Medication Incident Report Form - Help Guide

## Purpose
The Medication Incident Report Form is used to report medication incidents that have occurred within your institution. This form is a crucial tool for identifying and mitigating potential risks and improving patient safety. Please only fill out this form when a medication incident has occurred.

## How To Complete This Form

1. To begin, click on the "Medication Incident Report Form" link to access the form.
2. Fill out the required fields with the relevant information:
   - **Medication Incident Report Form**: Enter a brief description of the incident.
   - **Patient Name**: Enter the name of the patient involved in the incident.
   - **Date of Incident**: Enter the date the incident occurred.
   - **Time of Incident**: Enter the time the incident occurred.
3. If applicable, select the relevant options for:
   - **Medication Error Type**:
     - Select all applicable options (e.g., "Yes" for error).
   - **Action Taken**: Describe the actions taken to address the incident.
   - **Medication Administered**: If not applicable, indicate "N/A" to prevent unnecessary questions.
   - **Patient Condition**: Describe the patient's condition at the time of the incident.
   - **Staff Involved**:
     - Select the staff members involved in the incident (e.g., "Nurse", "Doctor", "Other").
   - **Incident Location**:
     - Select the location where the incident occurred (e.g., "Ward", "Clinic", "Other").
   - **Incident Nature**:
     - Select all applicable options (e.g., "Error", "Near-Miss").
   - **Incident Cause**:
     - Select all applicable options (e.g., "System", "Human", "Equipment").
   - **Incident Outcome**:
     - Select all applicable options (e.g., "Harm to Patient", "Harm to Staff", "No Harm").

## Field-by-Field Explanation

* **Medication Incident Report Form**:
    Enter a brief description of the incident.
* **Patient Name**:
    Enter the name of the patient involved in the incident.
* **Date of Incident**:
    Enter the date the incident occurred.
* **Time of Incident**:
    Enter the time the incident occurred.
* **Medication Error Type**:
    Indicate if the medication error was a result of a system issue (e.g., "Yes" for error), or if the error was human-related (e.g., "No" for error).
* **Action Taken**:
    Describe the actions taken to address the incident.
* **Medication Administered**:
    If the medication was administered, enter the name or type of medication. If not applicable, indicate "N/A".
* **Patient Condition**:
    Describe the patient's condition at the time of the incident.
* **Staff Involved**:
    Select the staff members involved in the incident (e.g., "Nurse", "Doctor", "Other").
* **Incident Location**:
    Select the location where the incident occurred (e.g., "Ward", "Clinic", "Other").
* **Incident Nature**:
    Indicate if the incident was a result of a near-miss or an actual error.
* **Incident Cause**:
    Select the underlying cause of the incident (e.g., "System", "Human", "Equipment").
* **Incident Outcome**:
    Select the outcome of the incident (e.g., "Harm to Patient", "Harm to Staff", "No Harm").
