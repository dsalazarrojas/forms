# first_aid_incident_report_therapy_matters - Help Guide
## Purpose
This form is used to collect information about incidents that require first aid and therapy.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "First Aid Date" field with the date of the incident.
2. Provide a brief description of the incident in the "Incident Description" field.
3. If therapy was provided, fill in the "Therapy Date" field with the date of the therapy.
4. If any therapy matters were discussed during therapy, type them in the "Therapy Matters" field.
5. If you have any additional notes about the therapy, write them in the "Therapy Notes" field.
6. Fill in the "Therapist" field with the name of the therapist who provided therapy.

## Field-by-Field Explanation
### First Aid Date (1)
* **First Aid Date** (`incident_date`, date, required: false): Enter the date of the incident.
### Incident Description (2)
* **Incident Description** (`incident_description`, text, required: false): Provide a brief description of what happened during the incident.
### Therapy Date (3)
* **Therapy Date** (`incident_therapy_date`, date, required: false): Enter the date of the therapy provided.
### Therapy Matters (4)
* **Therapy Matters** (`incident_therapy_matters`, text, required: false): If therapy was discussed, type any relevant therapy matters here.
### Therapy Notes (5)
* **Therapy Notes** (`incident_therapy_notes`, text, required: false): If you have any additional notes about the therapy, write them here.
### Therapist (6)
* **Therapist** (`therapist_name`, text, required: false): Fill in the name of the therapist who provided therapy.

## Tips
* Be as detailed as possible when filling out the "Incident Description" and "Therapy Matters" fields.
* If you are unsure about any information, it is better to ask for clarification before filling out the form.
* If the form is filled out incorrectly, please contact the relevant staff member for assistance.
* Please note that this form is for internal use and the information collected may be used for administrative purposes.
