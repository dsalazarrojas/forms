# material_trace_error_report_form - Help Guide
## Purpose
The material trace error report form is used to report incidents that occur during the material trace process. This form helps to identify and track errors in a structured and systematic way, ensuring that issues are documented and addressed to prevent their recurrence.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for the batch number of the incident.
2. Enter the date and time of the incident, if known.
3. Specify the location where the incident occurred.
4. Choose the correct error code for the incident.
5. Provide a detailed description of the error.
6. Select the relevant error codes for the batch and material errors.
7. Review and submit the form for verification and approval.

## Field-by-Field Explanation
* **Batch Number** (`batch_number`, Number, Optional): Enter the batch number associated with the incident.
* **Date** (`date`, Date, Optional): Enter the date of the incident, if known.
* **Time** (`time`, Time, Optional): Enter the time of the incident, if known.
* **Location** (`location`, Text, Optional): Specify the location where the incident occurred.
* **Error Code** (`error_code`, Select One, Optional): Choose the correct error code for the incident from the list:
	+ Batch error
	+ Material error
	+ Process error
	+ Material handling error
	+ Machine error
* **Error Description** (`error_description`, Text, Optional): Provide a detailed description of the error.
* **Batch Error Code** (`batch_error_code`, Select Multiple, Optional): Select one or more error codes for batch errors from the list:
	+ Error 1
	+ Error 2
	+ Error 3
	+ Error 4
	+ Error 5
* **Material Error Code** (`material_error_code`, Select Multiple, Optional): Select one or more error codes for material errors from the list:
	+ Error 1
	+ Error 2
	+ Error 3
	+ Error 4
	+ Error 5

## Tips
* If you are unsure about the correct error code or description, please consult with your supervisor or team leader for guidance.
* Ensure that the information provided is accurate and relevant to the incident being reported.
* Please review the form carefully before submitting it for verification and approval.
