# Security Breach Incident Report - Help Guide
## Purpose
This form is designed to collect information about security breaches or incidents that have occurred within an organization.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the details about the incident that occurred.
2.  Select the level of security involved.
3.  Provide the date and time of the incident.
4.  Enter the location where the incident occurred.
5.  Select the team that is handling the incident.
6.  Add any evidence related to the incident.
7.  Describe the actions taken to address the incident.
8.  Select the status of the actions taken.
9.  Specify if follow-up is required.
10.  Enter any additional notes about the incident.

## Field-by-Field Explanation

*  **Incident Details**: Enter a brief description of the security breach or incident that occurred.
*  **Security Level**: Select the level of security involved in the incident. Options include:
	+   Low
	+   High
	+   Medium
	+   None
*  **Incident Date**: Enter the date of the incident in the format `MM/DD/YYYY`.
*  **Incident Time**: Enter the time of the incident in the format `HH:MM:SS` or `HH:MM` for 12-hour format.
*  **Incident Location**: Enter the location where the incident occurred.
*  **Security Team**: Select the team that is handling the incident. Options include:
	+   Operations
	+   Security
	+   Management
*  **Evidence**: Add any evidence related to the incident, such as screenshots, logs, or videos.
*  **Action Taken**: Describe the actions taken to address the incident.
*  **Action Status**: Select the status of the actions taken. Options include:
	+   Completed
	+   In Progress
	+   Not Started
*  **Follow-up Required**: Specify if follow-up is required after the incident. Options include:
	+   Yes
	+   No
*  **Notes**: Enter any additional notes about the incident that may be helpful for further investigation or action. 

## Tips
*   Make sure to fill out the form as accurately and thoroughly as possible to provide the necessary information for incident reporting and follow-up activities.
*   If you are unsure about any part of the form, please contact the relevant team for guidance.
*   This form is intended for internal use only and should not be shared with unauthorized personnel.
