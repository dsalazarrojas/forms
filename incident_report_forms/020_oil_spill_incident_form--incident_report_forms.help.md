# Oil Spill Incident Form - Help Guide
## Purpose
The Oil Spill Incident Form is designed to collect information about oil spills. This form helps in tracking and analyzing oil spills to facilitate effective response and recovery efforts.

## How To Complete This Form
To complete this form, follow the instructions below:

1.  Fill out each field as necessary and with accuracy.
2.  Ensure that you've chosen the correct type of spill.
3.  Enter the correct responders involved in the spill response.
4.  Select the correct containment method used.
5.  Describe the cause and impacts of the spill.
6.  Provide a detailed description of the spill response.
7.  Add any additional notes regarding the spill.

## Field-by-Field Explanation

*   **Spill Name** (`spill_name`, text, optional): Enter a brief name to identify the spill incident.
*   **Spill Date** (`spill_date`, date, optional): Enter the date of the spill, if known.
*   **Spill Location** (`spill_location`, text, optional): Specify the exact location of the spill.
*   **Spill Description** (`spill_description`, text, optional): Provide a detailed description of the spill incident.
*   **Spill Type** (`spill_type`, select_one, optional): Choose the correct type of spill from the provided options.
*   **Responders** (`spill_responders`, select_multiple, optional): Select all responders involved in the spill response.
*   **Containment** (`spill_containment`, select_one, optional): Select the containment method used for the spill.
*   **Spill Cause** (`spill_cause`, text, optional): Provide a detailed description of the cause of the spill.
*   **Spill Impacts** (`spill_impacts`, text, optional): Describe the impacts of the spill.
*   **Spill Response** (`spill_response`, text, optional): Detail the spill response actions taken.
*   **Spill Notes** (`spill_notes`, text, optional): Add any additional notes about the spill incident.
