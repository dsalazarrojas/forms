# Pediatrics Schedule Error Reporting - Help Guide
## Purpose
The Pediatrics Schedule Error Reporting form is used to report scheduling errors that occur in the Pediatrics department. This form helps to document and track incidents that affect the schedule, enabling us to identify patterns and areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the error report page with as much detail as possible.
2. Select the correct date and time of the event from the calendar or type in the correct date and time in the format `MM/DD/YY HH:MM AM/PM`.
3. Choose the correct location where the error occurred.
4. Provide a detailed description of what happened.
5. Select the type of incident that occurred (select all that apply).
6. Choose the impact of the incident (select one).
7. Select the actions taken to resolve the incident (select all that apply).
8. Choose whether this incident was already reported (select one).

## Field-by-Field Explanation
* **Error Report**: This is the main section where you can describe the error that occurred. Please be as detailed as possible.
* **Date of Event**: Enter the date and time the incident occurred. You can select it from the calendar or type it in manually in the format `MM/DD/YY HH:MM AM/PM`.
* **Time of Event**: Enter the time the incident occurred. Please use 24-hour format (HH:MM).
* **Location**: Describe the location where the incident occurred.
* **Description**: Provide a detailed explanation of what happened.
* **Incident Type**: Select all the types of incidents that apply to the error reported. This will help us better understand the nature of the incident.
* **Incident Impact**: Choose the impact of the incident. This will help us assess the severity of the issue.
* **Action Taken**: Select all the actions taken to resolve the incident. This will help us evaluate the effectiveness of our response.
* **Incident Reported**: Choose whether this incident was already reported. This will help us prevent duplicate reporting.
* **Root Cause**: Select all the root causes of the incident. This will help us understand the underlying reasons for the incident and make necessary adjustments to prevent it in the future.
