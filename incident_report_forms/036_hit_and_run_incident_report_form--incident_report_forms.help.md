# Hit And Run Incident Report Form - Help Guide
## Purpose
The Hit And Run Incident Report Form is used to collect information about incidents where a vehicle has been involved in a hit-and-run incident. This form helps to gather details about the incident, the vehicle involved, and any witnesses that may have seen what happened.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the fields as completely and accurately as possible.
2. Review each field carefully to ensure that you have provided all necessary information.
3. If you are unsure about any field, please refer to the explanations below for help.

## Field-by-Field Explanation

* **Incident Report Form** (`incident_report_form_1`): This is the main section of the form where you can describe the incident in detail. Please provide as much information as possible about what happened.
* **Vehicle Details** (`vehicle_details_1`): If the incident involved a vehicle, please provide details about the vehicle, such as its color, type, and license plate number.
* **Driver Details** (`driver_details_1`): If there was a driver involved in the incident, please provide their details, such as their name, description, and any other identifying information.
* **Witness Details** (`witness_details_1`): If there were witnesses to the incident, please provide their details, such as their name, description, and any other identifying information.
* **Suspect Details** (`suspect_details_1`): If the incident involved a suspect, please provide their details, such as their description and any other identifying information.
* **Vehicle Information** (`vehicle_info_1`): This field is used to provide more information about the vehicle involved in the incident.
* **Damage Information** (`damage_info_1`): If there was damage to property or persons as a result of the incident, please describe the extent of the damage.
* **Witness Information** (`witness_info_1`): If there were witnesses to the incident, please provide their information, such as their vehicle details and description.
* **Incident Time** (`incident_time_1`): If you know the time of the incident, please provide it in the format `HH:MM:SS`.
* **Incident Date** (`incident_date_1`): If you know the date of the incident, please provide it in the format `YYYY-MM-DD`.
* **Location** (`location_1`): Please provide the location where the incident occurred.
* **Suspect Vehicle** (`suspect_vehicle_1`): If the suspect vehicle was involved in the incident, please indicate whether it was a yes or no.
* **Vehicle Color** (`suspect_vehicle_color_1`): If you know the color of the suspect vehicle, please select it from the options provided.
* **Vehicle Type** (`suspect_vehicle_type_1`): If you know the type of the suspect vehicle, please select it from the options provided.
* **License Plate** (`suspect_vehicle_license_1`): If you know the license plate number of the suspect vehicle, please provide it.
* **Witness Vehicle** (`witness_vehicle_1`): If the witness vehicle was involved in the incident, please indicate whether it was a yes or no.
* **Witness Vehicle Color** (`witness_vehicle_color_1`): If you know the color of the witness vehicle, please select it from the options provided.
* **Witness Vehicle Type** (`witness_vehicle_type_1`): If you know the type of the witness vehicle, please select it from the options provided.
* **Witness Vehicle License** (`witness_vehicle_license_1`): If you know the license plate number of the witness vehicle, please provide it.
* **Witness Description** (`witness_description_1`): If there were witnesses to the incident, please provide a description of what they saw.
* **Suspect Description** (`suspect_description_1`): If there is a suspect involved in the incident, please provide a description of them.
* **Vehicle Make** (`suspect_vehicle_make_1`): If you know the make of the suspect vehicle, please select it from the options provided.
* **Vehicle Model** (`suspect_vehicle_model_1`): If you know the model of the suspect vehicle, please select it from the options provided.
* **Vehicle Year** (`suspect_vehicle_year_1`): If you know the year of the suspect vehicle, please provide it as a number.
* **License Number** (`suspect_vehicle_license_number_1`): If you know the license plate number of the suspect vehicle, please provide it.
