# incident_review_form_template - Help Guide
## Purpose
The Incident Review Form Template is a standardized form used to document and review incidents that occur in the workplace. It helps ensure that relevant information is collected and stored in a centralized location for easy access and reference.

## How To Complete This Form
1. To complete this form, follow the instructions below.
2. Review each page carefully and ensure that all required fields are filled out.
3. Enter relevant information for each field as prompted.

## Field-by-Field Explanation
### **incident_review_form_page** (Page 1, Required: No)
This page serves as the initial contact information section of the form.

* **first name**: Enter the first name of the individual(s) involved in the incident.
* **last name**: Enter the last name of the individual(s) involved in the incident.
* **email**: Enter the email address of the individual(s) involved in the incident.
* **phone number**: Enter the phone number of the individual(s) involved in the incident.

### **contact_details** (Page 2, Required: No)
This page allows you to provide contact information for multiple parties involved in the incident.

* **Select a contact type**: Choose one of the options to select a contact type (First Name, Last Name, Email, Phone Number)
*   Select one or multiple contact types to display on the form.

### **incident_details_page** (Page 3, Required: No)
This page is used to enter details about the incident.

* **Enter incident details**: Enter a brief description of the incident.

### **review_form_section** (Page 4, Required: No)
This page is used for the reviewer to add any additional notes.

* **Enter review notes**: Enter any comments or observations about the incident.

### **review_notes** (Page 5, Required: No)
This page is used to store any additional notes about the incident.

*   Enter any additional notes or comments about the incident.

### **submit_form** (Page 6, Required: No)
This page is used to submit the completed form.

*   Click the submit button to save and submit the form.
