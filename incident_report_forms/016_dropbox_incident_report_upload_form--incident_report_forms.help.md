# dropbox_incident_report_upload_form - Help Guide
## Purpose
This form is used to submit incident reports related to issues that occurred with Dropbox.

## How To Complete This Form
1. Fill out each field with the relevant information about the incident.
2. Make sure to enter the correct date and time of the incident.
3. Provide a clear and detailed description of what happened.
4. Specify if the affected user is you or if it's someone else.
5. Choose whether the affected location, device, and system were affected.
6. Enter the resolution to the incident.
7. If applicable, specify the date and time of the resolution.
8. If you have an uploaded file related to the incident, select it.
9. Enter the email address of the affected user.

## Field-by-Field Explanation

* **Incident Report Date** (id: 2, date, required: false): Enter the date and time of the incident.
* **Incident Report Description** (id: 3, text, required: false): Provide a detailed description of what happened.
* **Affected User** (id: 4, text, required: false): Enter the name of the user who was affected by the incident.
* **Affected Location** (id: 5, text, required: false): Enter the location where the incident occurred.
* **Affected Device** (id: 6, select_multiple, required: false): Select whether the incident affected your device.
* **Affected System** (id: 7, select_multiple, required: false): Select whether the incident affected a system or network.
* **Resolution** (id: 8, text, required: false): Enter the resolution or outcome of the incident.
* **Resolution Date** (id: 9, date, required: false): Enter the date and time the issue was resolved.
* **Incident Report Upload File** (id: 10, text, required: false): Select a file related to the incident to upload.
* **Affected User E-mail** (id: 11, email, required: false): Enter the email address of the affected user.

## Tips
* Please make sure to fill out each field as accurately and completely as possible.
* If you are unsure about any of the fields, you can ask for help from the Dropbox support team.
* Please do not submit duplicate reports for the same incident.
