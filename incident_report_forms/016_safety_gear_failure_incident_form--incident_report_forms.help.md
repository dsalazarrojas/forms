# Safety Gear Failure Incident Form - Help Guide
## Purpose
This form is used to report and document safety gear failures, which is crucial for maintaining a safe working environment.

## How To Complete This Form
1. Fill in the required fields with accurate and clear information.
2. Select the relevant options for each field, if available.
3. Provide detailed descriptions for text fields.

## Field-by-Field Explanation
* **Incident Report** (`safety_gear_failure_incident`):
	+ This field is the main incident report, which should include a brief description of the incident.
* **Location** (`location`):
	+ This field should be filled with the exact location where the incident occurred.
* **Safety Gear Failure Type** (`safety_gear_failure_type`):
	+ This field should be selected from the available options (Safety Harnesses, Hard Hat, Harness, Fall Protection).
* **Description of Safety Gear Failure** (`safety_gear_failure_description`):
	+ This field is for a detailed description of the safety gear failure.
* **Safety Gear Serial Number** (`safety_gear_serial_number`):
	+ This field should be filled with the serial number of the failed safety gear.
* **Date of Safety Gear Failure** (`safety_gear_failure_date`):
	+ This field should be filled with the date of the safety gear failure.
* **Last Inspection Date** (`safety_gear_last_inspection_date`):
	+ This field should be filled with the last inspection date of the safety gear.
* **Safety Equipment Used During Incident** (`safety_equipment_used`):
	+ This field should be selected from the available options (None, Hard Hat, Safety Harness, Fall Protection, Helmet, Vest).
	+ If no safety equipment was used, select "None".
* **Personnel Injured** (`personnel_injured`):
	+ This field should be filled with the number of personnel injured in the incident.
* **Personnel Involved** (`personnel_involved`):
	+ This field should be selected from the available options (None, Safety Officer, Supervisor, Employee).
	+ If no personnel were involved, select "None".
* **Reporting Officer** (`reporting_officer`):
	+ This field should be selected from the available options (None, Employee, Supervisor, Safety Officer).
* **Incident Status** (`incident_status`):
	+ This field should be selected from the available options (Not Reported, Under Investigation, Completed, In Progress).
* **Incident Closed Date** (`incident_closed_date`):
	+ This field should be filled with the date the incident was closed.
* **Incident Reopened Date** (`incident_reopened_date`):
	+ This field should be filled with the date the incident was reopened.
* **Incident Reported Date** (`incident_reported_date`):
	+ This field should be filled with the date the incident was reported.
* **Incident Cause** (`incident_cause`):
	+ This field should be a detailed description of the incident cause.
* **Incident Narrative** (`incident_narrative`):
	+ This field should be a detailed description of the incident.
* **Action Plan** (`action_plan`):
	+ This field should be a detailed description of the actions to be taken to prevent future incidents.
* **Corrective Action Status** (`corrective_action_status`):
	+ This field should be selected from the available options (Not Started, In Progress, Completed).
* **Corrective Action Due Date** (`corrective_action_due_date`):
	+ This field should be filled with the date the corrective action is due.
* **Corrective Actions Completed** (`corrective_actions_completed`):
	+ This field should be selected from the available options (None, 'True').
* **Corrective Action Closed Date** (`corrective_action_closed_date`):
	+ This field should be filled with the date the corrective action was closed.
* **Incident Cause Analysis** (`incident_cause_analysis`):
	+ This field should be a detailed description of the analysis of the incident cause.
* **Incident Cause Determination** (`incident_cause_determination`):
	+ This field should be a detailed description of the determination of the incident cause.
* **Incident Cause Conclusion** (`incident_cause_conclusion`):
	+ This field should be a detailed description of the conclusion of the incident cause analysis.

## Tips
* Please fill out the form carefully and accurately.
* Make sure to select the correct options for each field.
* If you are unsure about any field, please consult with your supervisor or safety officer.
* This form is subject to change, please check for updates regularly.
