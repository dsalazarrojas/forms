# Incident Report - Help Guide
## Purpose
This form is used to report incidents and collect relevant details to aid in the incident investigation and follow-up process.

## How To Complete This Form
1. Please enter the date and time of the incident in the "Incident Date" field.
2. Provide the location where the incident occurred in the "Incident Location" field.
3. Describe the incident in detail in the "Incident Description" field.
4. Select the cause of the incident from the provided options, or provide an "Other" option if the cause is not listed.
5. If you selected "Other" as the incident cause, provide a detailed description of the cause in the "Incident Cause Other Value" field.
6. Enter the name of the person injured in the "Injured Person" field.
7. Select who reported the incident from the provided options, or provide an "Other" option if the person is not listed.
8. If you selected "Other" as the incident reporter, provide a detailed description of the reporter in the "Incident Reported By Other" field.
9. Select the status of the incident from the provided options, or provide an "Other" option if the status is not listed.
10. If you selected "Other" as the incident status, provide a detailed description of the status in the "Incident Status Other" field.
11. Select any follow-up actions required for the incident from the provided options, or provide an "Other" option if additional follow-up is needed.
12. Enter any additional comments or notes about the incident in the "Note" field.
13. Upload any attachments or files related to the incident in the "Attachments" field.
14. Enter any other attachments not listed in the "Other (attach)" field.
15. Select the current investigation status of the incident from the provided options, or provide an "Other" option if the investigation status is not listed.
16. If you selected "Other" as the investigation status, provide a detailed description of the status in the "Incident Investigation Other" field.
