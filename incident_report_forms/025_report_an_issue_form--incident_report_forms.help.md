# Report An Issue Form - Help Guide
## Purpose
The "Report An Issue Form" is a tool used to collect information about incidents or issues that need to be reported. It's designed to help users provide a structured and detailed account of what happened.

## How To Complete This Form
1. Fill in the required fields marked with an asterisk (\*). These are:
	* User
	* Issue
	* Incident
	* Issue Type
	* Issue Priority
	* Issue Status
	* Issue Resolution
	* Issue Resolution Status
	* Submit
2. Provide as much detail as possible in the optional fields, such as incident details, report date and time, and issue resolution comments.

## Field-by-Field Explanation
* **User**: Enter your name or username, so we can contact you for further questions or follow-ups.
* **Issue**: Describe the issue or incident you're reporting.
* **Incident**: Choose the type of incident from the dropdown menu. This helps us categorize and track the issue more effectively.
* **Incident Details**: Provide additional details about the incident, if any.
* **Report Details**: Add any additional information about your report.
* **Report Date**: Enter the date you're reporting the issue.
* **Report Time**: Enter the time you're reporting the issue.
* **Report Location**: Add the location where the issue occurred.
* **Issue Type**: Choose all applicable types of issues from the dropdown menu.
* **Issue Priority**: Set the priority of the issue, with higher values indicating a greater urgency.
* **Issue Status**: Choose the status of the issue from the dropdown menu.
* **Issue Resolution**: Choose the resolution of the issue from the dropdown menu.
* **Issue Resolution Date**: Enter the date the issue was resolved.
* **Issue Resolution Time**: Enter the time the issue was resolved.
* **Issue Resolution Status**: Choose the status of the issue resolution from the dropdown menu.
* **Issue Resolution Comments**: Add any additional comments about the resolution.
* **Issue Attachment**: Attach any relevant files or documentation.
* **Issue Notes**: Add any additional notes about the issue.
* **Submit**: Click to submit the report and complete the process.

Note: All fields with an asterisk (\*) are required. Make sure to fill them in accurately and thoroughly.
