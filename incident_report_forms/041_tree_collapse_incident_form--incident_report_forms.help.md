# Tree Collapse Incident Form - Help Guide
## Purpose
The Tree Collapse Incident Form is designed to collect information about tree collapses that occur within a forest or tree farm. This form will help incident responders quickly and accurately report on tree collapses, allowing for effective resource allocation and risk management.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Enter a brief description of the incident** in the "Incident Description" field. This should include as much detail as possible about what happened, such as the extent of the damage and any notable events or circumstances.
2. **Select the date and time of the incident** using the date and time fields. This will help incident responders determine the timing of the event and allocate resources accordingly.
3. **Choose the type of tree collapse that occurred** from the list of options. This will help incident responders identify the root cause of the problem and determine the most effective course of action.
4. **Enter the height and age of the tree** if applicable. This will help incident responders understand the size and age of the tree and plan for future maintenance and mitigation.
5. **Provide the location of the incident** in the "Incident Location" field. This will help incident responders pinpoint the exact location of the event and allocate resources efficiently.
6. **Enter your name and contact information** as the incident reporter. This will ensure that incident responders can follow up with you for further questions or information.
7. **Record the response time** of the incident response team. This will help incident responders track their response times and optimize their response efforts.

## Field-by-Field Explanation

* **Incident Description**:
	+ A brief description of the incident.
* **Incident Date**:
	+ The date on which the incident occurred.
* **Incident Time**:
	+ The time at which the incident occurred.
* **Incident Type**:
	+ The type of tree collapse that occurred. (Select one of the following options: "Tree collapse", "Root failure", "Branch failure", "Trunk failure")
* **Tree Height**:
	+ The height of the tree that collapsed (if known).
* **Tree Age**:
	+ The age of the tree that collapsed (if known).
* **Incident Location**:
	+ The location of the incident (e.g. forest name, section, or exact coordinates).
* **Incident Reporter**:
	+ Your name and contact information as the person reporting the incident.
* **Incident Response Time**:
	+ The time it took for the incident response team to respond to the incident.

## Tips
* Be as detailed and accurate as possible when completing this form.
* If you are unsure about any of the fields, please do not hesitate to ask for help.
* This form is not intended for emergency reporting. In the event of an emergency, please call the emergency number immediately.
