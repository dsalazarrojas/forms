The purpose of this form is to collect information about an injury incident that has occurred within an organization, gathering details about the incident, the injured party, and any subsequent medical attention received. This form will help ensure that incidents are reported in a standardized and thorough manner, reducing the likelihood of duplication or miscommunication.

To complete this form, please follow the instructions below:

## Injury Incident Form - Help Guide

## Purpose
The Injury Incident Form is a tool used to record and report information about incidents that have occurred within an organization. This form helps in the collection of accurate and relevant details about the injury, enabling swift and effective reporting and follow-up.

## How To Complete This Form

1.  Ensure that you are completing this form for an actual incident; if it's a hypothetical or test scenario, kindly use a test form.
2.  Please complete all required fields, as indicated by the label. Some fields may be marked as optional; feel free to fill them out if relevant to your situation.
3.  Enter your answers in the spaces provided, using the format suggested in each field.
4.  Once completed, review your form to ensure all fields are filled and correct before submitting it for review and processing.

## Field-by-Field Explanation

*   **Incident Date** (1): The date on which the incident occurred.
    *   Type: date
    *   Required: false
    *   Hint: Use the format MM/DD/YYYY for month, day, and year.
*   **Incident Time** (2): The time of the incident.
    *   Type: time
    *   Required: false
    *   Hint: Enter in 24-hour format (HH:MM).
*   **Incident Location** (3): The specific location where the incident happened.
    *   Type: text
    *   Required: false
    *   Hint: Enter the exact location, including building or department names if applicable.
*   **Incident Description** (4): A brief description of what happened during the incident.
    *   Type: text
    *   Required: false
    *   Hint: Be as detailed as possible while keeping it concise.
*   **Injury Type** (5): Was there an injury? Yes/No.
    *   Type: select_one
    *   Required: false
*   **Injury Severity** (6): What was the severity of the injury? Yes/No.
    *   Type: select_one
    *   Required: false
*   **Injured Party Name** (7): The name of the person injured.
    *   Type: text
    *   Required: false
    *   Hint: Enter the full name of the individual involved in the incident.
*   **Injured Party Job Title** (8): The job title of the injured party.
    *   Type: text
    *   Required: false
*   **Employer Name** (9): The name of the employer where the injury occurred.
    *   Type: text
    *   Required: false
*   **Supervisor Name** (10): The supervisor or manager involved.
    *   Type: text
    *   Required: false
*   **Witness Details** (11): Details about any witnesses.
    *   Type: text
    *   Required: false
*   **Medical Attention Received** (12): Did the injured party receive medical attention? Yes/No.
    *   Type: select_one
    *   Required: false
*   **Hospitalization Length** (13): The duration of hospitalization.
    *   Type: number
    *   Required: false
*   **Medical Bill Cost** (14): The cost of any medical bills.
    *   Type: number
    *   Required: false
*   **Time Off Work** (15): The number of days off work due to the injury.
    *   Type: number
    *   Required: false
*   **Days Off Work** (16): The number of days off work due to the injury.
    *   Type: number
    *   Required: false
*   **Wage Concession** (17): Was a wage concession made? Yes/No.
    *   Type: select_one
    *   Required: false
*   **Medical Provider** (18): Name of the medical provider.
    *   Type: text
    *   Required: false
*   **Injury Description Part** (19): Additional description if applicable.
    *   Type: text
    *   Required: false
*   **Injury Description Details** (20): Further details about the injury.
    *   Type: text
    *   Required: false
*   **Injury Cause** (21): The cause of the injury.
    *   Type: text
    *   Required: false
*   **Injury Cause Description** (22): Description of the cause.
    *   Type: text
    *   Required: false
*   **Prevention Measures** (23): Measures to prevent such incidents.
    *   Type: text
    *   Required: false
*   **Reporting Person** (24): Person reporting the incident.
    *   Type: text
    *   Required: false
*   **Reporting Person Title** (25): Title of the reporter.
    *   Type: text
    *   Required: false

## Tips

*   Always review your form before submission for accuracy and completeness.
*   Ensure all fields are filled according to their requirements.
*   If you have any questions or concerns, contact your supervisor or support team for assistance.
*   This form is designed to help in the collection and processing of incident reports; any issues or concerns should be addressed promptly.
