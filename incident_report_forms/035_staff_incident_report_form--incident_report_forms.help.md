# Staff Incident Report Form - Help Guide
## Purpose
The purpose of this form is to collect information about incidents or near-misses experienced by staff members during their work. This data will be used to improve workplace safety and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date the incident occurred in the "Incident Date" field.
2. Enter your name as the reporter in the "reporter_name" field.
3. Provide a detailed description of the incident in the "incident_description" field.
4. Select the type of incident from the options provided in the "Incident Type" field.
5. Enter the location where the incident occurred in the "Incident Location" field.

## Field-by-Field Explanation

* **Incident Date (id: 1)** (Required: False, Label: Incident Date, Hint: null, Type: date)
	+ This is the date the incident occurred.
* **reporter_name (id: 2)** (Required: False, Label: reporter_name, Hint: null, Type: text)
	+ This is the name of the person submitting the incident report.
* **incident_description (id: 3)** (Required: False, Label: incident_description, Hint: null, Type: text)
	+ Provide a detailed description of what happened during the incident.
* **Incident Type (id: 4)** (Required: False, Label: Incident Type, Hint: null, Type: select_one)
	+ Choose the type of incident from the options provided:
		- Accident
		- Near Miss
* **Incident Location (id: 5)** (Required: False, Label: Incident Location, Hint: null, Type: text)
	+ Enter the location where the incident occurred.

## Tips
- Make sure to complete all required fields.
- Double-check your entries for accuracy.
- If you have any questions or concerns, please contact the relevant department or person responsible for incident reporting.
