# Shoplifting Incident Form - Help Guide
## Purpose
The Shoplifting Incident Form is a document used to report and document shoplifting incidents that have occurred within a store or establishment.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Shoplifting Incident**: Briefly describe the shoplifting incident that occurred, including the events leading up to and following the incident.
2. **Date of Incident**: Enter the date the shoplifting occurred. This can be done using the format `mm/dd/yyyy`.
3. **Time of Incident**: Enter the time the shoplifting occurred. This can be done using the format `hh:mm AM/PM`.
4. **Location of Incident**: Provide a brief description of where the shoplifting occurred within the store or establishment.
5. **Suspect Description**: Describe the suspect's appearance, clothing, and any other distinguishing features that can help identify them.
6. **Suspect Name**: If you know the name of the suspect, please enter it here.
7. **Suspect Distinguishing Features**: If the suspect has any distinguishing features that can help identify them, such as a tattoo or scar, describe them here.
8. **Witness Statement**: Briefly describe what you witnessed or know about the incident.
9. **Witness Name**: If you are the witness, enter your name here.
10. **Witness Relationship**: Select the relationship you have to the suspect or the location where the incident occurred, such as "Employee" or "Customer".
11. **Witness Phone**: Enter your phone number so that you can be contacted for further questioning or investigation.

## Field-by-Field Explanation
* **Shoplifting Incident**: Describe the shoplifting incident that occurred, including the events leading up to and following the incident.
* **Date of Incident** (`date_of_incident`, type: `date`): Enter the date the shoplifting occurred.
* **Time of Incident** (`time_of_incident`, type: `time`): Enter the time the shoplifting occurred.
* **Location of Incident** (`location_of_incident`, type: `text`): Provide a brief description of where the shoplifting occurred within the store or establishment.
* **Suspect Description** (`suspect_description`, type: `text`): Describe the suspect's appearance, clothing, and any other distinguishing features that can help identify them.
* **Suspect Name** (`suspect_name`, type: `text`): If you know the name of the suspect, enter it here. (Optional)
* **Suspect Distinguishing Features** (`suspect_distinguishing_features`, type: `text`): If the suspect has any distinguishing features, describe them here.
* **Witness Statement** (`witness_statement`, type: `text`): Briefly describe what you witnessed or know about the incident.
* **Witness Name** (`witness_name`, type: `text`): If you are the witness, enter your name here.
* **Witness Relationship** (`witness_relationship`, type: `select_one`): Select the relationship you have to the suspect or the location where the incident occurred.
* **Witness Phone** (`witness_phone`, type: `text`): Enter your phone number so that you can be contacted for further questioning or investigation.

## Tips
* Make sure to be as detailed and accurate as possible when completing this form.
* If you are the witness, please try to remember as much as you can about the incident and provide as much information as possible.
* If you are unsure of any information, please enter "unknown" or "did not see".
* This form may be used by store staff or security personnel to investigate and document shoplifting incidents.
