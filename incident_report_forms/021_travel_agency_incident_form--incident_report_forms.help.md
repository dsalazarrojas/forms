# travel-agency-incident-form - Help Guide

## Purpose
This form is used to report incidents that occurred during travel agency operations. It helps gather essential details to resolve and prevent future incidents.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Incident Date** field with the date the incident occurred.
2. Select the **Trip Type** from the options provided (Domestic, International, Group Tour, Corporate, or Cruise).
3. Provide a detailed **Description** of the incident in the text field.
4. Enter the **Incident Time** when the incident occurred.
5. Choose the **Incident Location** where the incident occurred (Airport, Hotel, City, Resort, or Other).
6. Select the current **Incident Status** of the incident (Closed, In Progress, or Resolved).
7. If necessary, provide additional information on the **Incident Resolution**.
8. Check if the incident was **Assigned To** someone (Yes or No).
9. Enter the **Travel Agency** name (if applicable).
10. Optionally, add any additional **Incident Notes** regarding the incident.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, Date, Required): Enter the date the incident occurred.
* **Trip Type** (`trip_type`, Select One, Required): Select the type of trip involved in the incident (e.g., Domestic, International, etc.).
* **Description** (`incident_description`, Text, Required): Provide a detailed description of the incident.
* **Incident Time** (`incident_time`, Time, Required): Enter the time the incident occurred.
* **Incident Location** (`incident_location`, Select One, Required): Choose the location where the incident occurred (e.g., Airport, Hotel, etc.).
* **Incident Status** (`incident_status`, Select One, Required): Select the current status of the incident (Closed, In Progress, or Resolved).
* **Incident Resolution** (`incident_resolution`, Text, Required): Add any additional information about the incident resolution.
* **Incident Assigned To** (`incident_assigned_to`, Select One, Required): Check if the incident was assigned to someone (Yes or No).
* **Travel Agency** (`travel_agency`, Text, Optional): Enter the name of the travel agency involved.
* **Incident Notes** (`incident_notes`, Note, Optional): Add any additional notes about the incident.
