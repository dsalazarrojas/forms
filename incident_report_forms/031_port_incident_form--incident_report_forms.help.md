# port_incident_form - Help Guide
## Purpose

This form is used for reporting and tracking incidents in a port or facility. It is intended for staff members to document and report incidents in a standardized format, ensuring that relevant details are captured and easily accessible for review and analysis.

## How To Complete This Form

To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Incident Date**: Select the date of the incident.
* **Incident Time**: Select the time of the incident.
* **Incident Type**: Choose the type of incident that occurred, or select "Other" if not listed.
* **What is the incident type? (Other)**: Provide a detailed description of the incident type if you selected "Other".
* **Incident Details**: Briefly describe what happened during the incident.
* **Witness Count**: Indicate if there were any witnesses.
* **Witness Names**: Indicate if you know the names of the witnesses or not.
* **Witness Contact Information**: Choose "Yes" if witness contact information is available and provide it.
* **Witness Notes**: Record any notes from the witnesses.
* **Incident Investigation**: Briefly describe the incident investigation.
* **Incident Resolution**: Provide a brief description of the resolution or outcome of the incident.
* **Incident Status**: Choose the current status of the incident, or select "Other" if not listed. If selecting "Other", provide a detailed description.
* **What is the incident status? (Other)**: Provide a detailed description of the incident status if you selected "Other".
