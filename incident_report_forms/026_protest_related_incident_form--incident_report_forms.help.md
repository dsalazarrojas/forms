# protest_related_incident_form - Help Guide
## Purpose
The "protest_related_incident_form" is used to report incidents related to protests. This form is intended to gather all necessary information to document and follow up on protests that may occur within the organization.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out the "Incident Details" section with a detailed description of the incident.
2. Provide information about the protest in the "Protest Details" section.
3. Select the "Reporting Person" responsible for reporting the incident.
4. Enter the "Protest Date" in the required format (MM/DD/YYYY).
5. Enter the "Protest Time" in the required format (HH:MM AM/PM).

## Field-by-Field Explanation
- **Incident Details** (1, text, Required): In this section, please provide a detailed description of the incident that occurred.
- **Protest Details** (2, text, Required): Describe the protest in as much detail as possible, including the location, participants, and any notable events.
- **Reporting Person** (3, select_one, Optional): Select the person who is reporting this incident. 
- **Protest Date** (4, date, Required): Enter the date of the protest in the MM/DD/YYYY format (e.g., 01/01/2022).
- **Protest Time** (5, time, Required): Enter the time of the protest in the format 12:00 PM or 12:00 AM.
