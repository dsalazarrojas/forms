# School Incident Report Form - Help Guide
## Purpose
This form is designed to help school staff report incidents that occur within the school premises. It captures information about the student involved, the staff member responding, and details about the incident.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the student involved in the incident from the dropdown list.
2. Choose the staff member responding to the incident from the dropdown list.
3. Enter the date and time of the incident using the date and time fields.
4. Enter the location of the incident in the text field.
5. Provide a brief description of the incident in the text field.
6. Select the date and time the incident was reported using the date and time fields.
7. Fill out the form as completely as possible to ensure accurate reporting.

## Field-by-Field Explanation

* **Student**: Choose the student involved in the incident from the dropdown list (S1, S2, S3, S4, S5, S6).
* **Staff**: Choose the staff member responding to the incident from the dropdown list (S1, S2, S3, S4, S5, S6).
* **Date**: Enter the date of the incident in the date field. Use the standard date format (dd/mm/yyyy).
* **Time**: Enter the time of the incident in the time field. Use the 12-hour clock format (HH:MM AM/PM).
* **Location**: Enter a brief description of where the incident occurred in the text field.
* **Incident**: Provide a brief description of what happened in the text field.
* **Responder**: Choose the staff member responding to the incident from the dropdown list (S1, S2, S3, S4, S5, S6).
* **Description**: Enter a detailed description of the incident in the text field.
* **Date Reported**: Enter the date the incident was reported using the date field. Use the standard date format (dd/mm/yyyy).
* **Time Reported**: Enter the time the incident was reported using the time field. Use the 12-hour clock format (HH:MM AM/PM).

## Tips

* Make sure to fill out all required fields to ensure accurate reporting.
* If you are unsure about any field, please contact the school administration for assistance.
* This form is for reporting incidents that occur within the school premises. If you are reporting an incident that occurred outside of school hours, please contact the school administration for guidance.
