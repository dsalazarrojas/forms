# Zoological Animal Escape Incident Report Form - Help Guide
## Purpose
This form is used for reporting incidents of animals escaping from a zoological institution.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct answer to "animal_escape_incident" (Yes or No) to indicate whether an escape incident occurred.
2. Enter the date on which the incident occurred in the "incident_date" field.
3. Provide the location where the incident occurred in the "location" field.
4. Select the type of animal that escaped (multiple options available).
5. Enter the details of the animal that escaped in the "animal_details" field.
6. Provide a description of the incident in the "incident_description" field.
7. Enter your name and contact information in the "reported_by" fields.
8. Select the date on which you reported the incident in the "report_date" field.
9. Enter your email address if you wish to be contacted for further information in the "reported_by_email" field.
10. Select the correct answers to "incident_reported_by", "animal_escape_incident_reported_by", "incident_reported_to", "incident_reported_to_2", "incident_reported_to_3", "incident_reported_to_4", "incident_reported_to_5", "incident_reported_to_6", "incident_reported_to_7", and "incident_reported_to_8" fields to indicate who reported the incident to.
11. Enter the species of the animal that escaped in the "animal_species" field.
12. Enter the animal number or tag number in the "animal_number" field.
13. Enter a description of the animal that escaped in the "animal_escape_description" field.
14. Select the type of animal that escaped (multiple options available).
15. Enter any additional notes or comments in the "notes" field.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, date, required): Enter the date on which the incident occurred.
* **Animal Escape Incident** (`animal_escape_incident`, select_one, required): Select 'Yes' if an animal escape incident occurred, 'No' otherwise.
* **Location** (`location`, text, optional): Enter the location where the incident occurred.
* **Escaped Animals** (`escaped_animals`, select_multiple, required): Select all the animals that escaped.
* **Animal Details** (`animal_details`, note, optional): Provide a description of the animal that escaped.
* **Incident Description** (`incident_description`, text, required): Describe the incident in as much detail as possible.
* **Reported By** (`reported_by`, text, required): Enter your name.
* **Reported By Contact** (`reported_by_contact`, text, required): Enter your contact information.
* **Report Date** (`report_date`, date, required): Enter the date on which you reported the incident.
* **Reported By Email** (`reported_by_email`, email, optional): Enter your email address if you wish to be contacted for further information.
* **Incident Reported By** (`incident_reported_by`, select_one, required): Select 'Yes' if you reported the incident to someone.
* **Animal Escape Incident Reported By** (`animal_escape_incident_reported_by`, select_one, required): Select 'Yes' if you reported the incident to someone.
* **Incident Reported To** (`incident_reported_to`, select_one, required): Select 'Yes' if the incident was reported to someone.
* **Incident Reported To 2** (`incident_reported_to_2`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Incident Reported To 3** (`incident_reported_to_3`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Incident Reported To 4** (`incident_reported_to_4`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Incident Reported To 5** (`incident_reported_to_5`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Incident Reported To 6** (`incident_reported_to_6`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Incident Reported To 7** (`incident_reported_to_7`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Incident Reported To 8** (`incident_reported_to_8`, select_one, required): Select 'Yes' if the incident was reported to someone else.
* **Animal Species** (`animal_species`, text, required): Enter the species of the animal that escaped.
* **Animal Number** (`animal_number`, text, required): Enter the animal number or tag number.
* **Animal Escape Description** (`animal_escape_description`, text, required): Enter a description of the animal that escaped.
* **Animal Type** (`animal_type`, select_multiple, required): Select the type of animal that escaped.
* **Notes** (`notes`, note, optional): Enter any additional notes or comments about the incident.
