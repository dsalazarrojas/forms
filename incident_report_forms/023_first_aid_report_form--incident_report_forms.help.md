# First Aid Report Form - Help Guide
## Purpose
The First Aid Report Form is a tool used to document incidents that require immediate attention. This form helps to gather essential information about the incident, the patient, and the treatment administered.

## How To Complete This Form
1. Click on the "Submit" button to start the form.
2. Fill out the form fields as instructed, providing accurate and relevant information about the incident.
3. Select the correct options for each field as prompted.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation
* **Incident Date** (`incident_date`, date, required/optional): Enter the date of the incident, in the format mm/dd/yyyy.
* **Incident Time** (`incident_time`, time, required/optional): Enter the time of the incident in the format 12:00 AM or 11:59 PM.
* **Incident Location** (`incident_location`, text, required/optional): Type the location where the incident occurred.
* **Incident Type** (`incident_type`, select one, required/optional): Select 'Yes' if the incident was caused by an external factor, 'No' if it was self-inflicted.
* **Incident Description** (`incident_description`, text, required/optional): Provide a brief description of what happened during the incident.
* **Patient Name** (`patient_name`, text, required/optional): Enter the name of the patient.
* **Treating Doctor** (`treating_doctor`, select multiple, required/optional): Select all doctors who treated the patient during the incident.
* **Treatment Administered** (`treatment_administered`, text, required/optional): Briefly describe the treatment administered to the patient.
* **Incident Outcome** (`incident_outcome`, select one, required/optional): Select 'Yes' if the incident had a favorable outcome, 'No' if it did not.
* **Patient Injury Type** (`patient_injury_type`, select multiple, required/optional): Select all types of injuries sustained by the patient.
* **Patient Injury Severity** (`patient_injury_severity`, select one, required/optional): Select the severity of the patient's injury from the options provided.

## Tips
* Please ensure that you have the necessary information and permissions before filling out this form.
* Double-check your answers for accuracy and completeness before submitting.
* If you're unsure about any field, consult with your supervisor or a relevant authority before proceeding.
