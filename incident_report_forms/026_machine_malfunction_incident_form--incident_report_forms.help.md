# Machine Malfunction Incident Form - Help Guide
## Purpose
This form is used to collect information about machine malfunctions that occurred on site.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select "Yes" if the machine was functioning properly before the incident occurred, and "No" if it was not.
2. Enter the date and time of the incident.
3. Enter the ID of the machine involved.
4. Enter the location where the incident occurred.
5. Provide a brief description of what happened.
6. If known, provide the root cause of the malfunction.
7. Click "Submit" to submit the form.

## Field-by-Field Explanation
* **user_input** (user_input, select_one, required/optional: Yes/No): This field asks whether the machine was functioning properly before the incident occurred. Please select "Yes" if it was, and "No" if it was not.
* **incident_date** (incident_date, date, required/optional: No): Enter the date of the incident.
* **incident_time** (incident_time, time, required/optional: No): Enter the time of the incident.
* **equipment_id** (equipment_id, number, required/optional: No): Enter the ID number of the machine involved.
* **location** (location, text, required/optional: No): Enter a brief description of the location where the incident occurred.
* **description** (description, text, required/optional: No): Provide a detailed description of what happened during the incident.
* **root_cause** (root_cause, text, required/optional: No): If known, enter a brief description of the root cause of the malfunction.

## Tips
* Be as detailed as possible when describing the incident and its root cause.
* Ensure that you are reporting actual incidents and not duplicate or fictional entries.
* If you are unsure about any part of the form, please contact your supervisor for assistance.
