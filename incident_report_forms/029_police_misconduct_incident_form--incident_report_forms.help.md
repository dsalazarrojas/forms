# Police Misconduct Incident Form - Help Guide
## Purpose
The Police Misconduct Incident Form is designed to collect information about police misconduct incidents, enabling effective investigation and resolution.
## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
### Incident Details
* **Incident Details** (`incident_details`, text, optional): Enter a brief description of the incident.
* **Location** (`location`, text, optional): Enter the location where the incident occurred.
* **Date** (`date`, date, optional): Enter the date of the incident.
* **Description** (`description`, text, optional): Enter a detailed description of what happened.
* **Police Officer ID** (`police_officer_id`, text, optional): Enter the police officer's ID number.
* **Police Department** (`police_department`, text, optional): Enter the police department involved.
* **Incident Type** (`incident_type`, select_one, optional): Select the type of incident that occurred.
* **Incident Reporter Details** (`incident_reporter_details`, select_multiple, optional): Select the details of the incident reporter.
* **Witness Details** (`witness_details`, select_multiple, optional): Select the details of the witness.
* **Witness Statement** (`witness_statement`, text, optional): Enter the witness statement or description.
* **Police Response** (`police_response`, select_one, optional): Select the police response to the incident.
* **Incident Follow-Up** (`incident_follow_up`, date, optional): Enter the date for follow-up actions.
* **Incident Reporter ID** (`incident_reporter_id`, number, optional): Enter the incident reporter's ID number.
* **Incident Date** (`incident_date`, date, optional): Enter the date of the incident.
* **Police Officer Date Of Birth** (`police_officer_date_of_birth`, date, optional): Enter the police officer's date of birth.
* **Police Officer Gender** (`police_officer_gender`, select_one, optional): Select the police officer's gender.
* **Police Officer Rank** (`police_officer_rank`, select_one, optional): Select the police officer's rank.
* **Police Officer Shift** (`police_officer_shift`, select_one, optional): Select the police officer's shift.
* **Police Officer Vehicle** (`police_officer_vehicle`, text, optional): Enter the police officer's vehicle number.
* **Incident Location** (`incident_location`, text, optional): Enter the incident location.
* **Incident Description** (`incident_description`, text, optional): Enter a detailed description of the incident.
* **Incident Officer Name** (`incident_officer_name`, text, optional): Enter the police officer's name.
* **Incident Officer Badge Number** (`incident_officerbadgenumber`, text, optional): Enter the police officer's badge number.
* **Witness Statement Text** (`witness_statement_text`, text, optional): Enter the witness statement text.
* **Witness Statement** (`witness_statement`, text, optional): Enter the witness statement or description.

Note that some fields are optional and may not be required for every incident.
