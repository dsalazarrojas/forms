# Crisis Response Framework Request Form - Help Guide

## Purpose
The Crisis Response Framework Request Form is used to document and facilitate emergency response requests. This form helps to streamline the process of requesting support or information during crisis situations.

## How To Complete This Form
1. Review the incident and determine the type of response required.
2. Fill out the form with the following information:
	* Incident Type (e.g., Emergency, Crisis, Other)
	* Date and Time of the incident
	* Location of the incident
	* Brief description of the incident (Incident Details)
	* Type of support or information requested (Request Type)
	* Request Date and Time
	* Contact details (Contact Name, Email, Phone)

## Field-by-Field Explanation

* **Incident Type** (`incident_type`, Select One, Required): Choose the type of incident that occurred (e.g., Emergency, Crisis, Other).
* **Incident Date** (`incident_date`, Date, Required): Enter the date of the incident.
* **Incident Location** (`incident_location`, Text, Required): Provide a brief description of the incident location.
* **Incident Details** (`incident_details`, Note, Required): Describe the incident in as much detail as possible.
* **Request Type** (`request_type`, Select One, Required): Choose the type of support or information requested.
* **Request Date** (`request_date`, Date, Required): Enter the date of the request.
* **Request Time** (`request_time`, Time, Required): Enter the time of the request.
* **Contact Name** (`contact_name`, Text, Required): Enter the contact name.
* **Contact Email** (`contact_email`, Email, Required): Enter the contact email.
* **Contact Phone** (`contact_phone`, Text, Required): Enter the contact phone number.
* **Team ID** (`team_id`, Number, Optional): Enter the team ID (if applicable).
* **Team Name** (`team_name`, Text, Optional): Enter the team name (if applicable).
* **Team Member Name** (`team_member_name`, Text, Optional): Enter the team member name (if applicable).

## Tips
- Be as detailed as possible when filling out the form.
- Double-check your information for accuracy.
- If you're unsure about any field, ask for clarification.
