# Incident Action Plan Form - Help Guide
## Purpose
The Incident Action Plan Form is used to document the actions taken in response to an incident. This form is intended for responders and team members responsible for incident management to record the necessary information to facilitate effective response and resolution.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary information about the incident before starting.
2. Select the correct options for each field based on the incident details.
3. Answer each field accurately and completely.
4. Review the form before submitting to ensure it is complete and accurate.

## Field-by-Field Explanation
### 1. **incident_action_plan_form_page** (Note, optional)
This field is a note field for providing additional information about the incident.

### 2. **contact_details** (Select Multiple, optional)
Select all the parties that are involved in the incident.

*   **Yes** - Select this option if you are aware of the party's involvement.
*   **No** - Select this option if you are not aware of the party's involvement.

### 3. **incident_details** (Number, optional)
Provide a numerical value related to the incident, if applicable.

### 4. **incident_status** (Select One, optional)
Select the current status of the incident.

*   **Active** - Select this option if the incident is ongoing.
*   **Inactive** - Select this option if the incident is closed or resolved.

### 5. **actions_taken** (Text, optional)
Describe the actions taken in response to the incident.

### 6. **incident_status_date** (Date, optional)
Enter the date the incident status was last updated.

### 7. **incident_status_time** (Time, optional)
Enter the time the incident status was last updated.

### 8. **incident_status_time_tz** (Time, optional)
Enter the time zone of the incident status update.

### 9. **incident_location** (Text, optional)
Enter the location where the incident occurred or is occurring.

### 10. **incident_description** (Text, optional)
Provide a detailed description of the incident.

### 11. **incident_responsible_party** (Text, optional)
Enter the party responsible for the incident.

### 12. **incident_reporter** (Text, optional)
Enter your name and contact information for follow-up communication.
