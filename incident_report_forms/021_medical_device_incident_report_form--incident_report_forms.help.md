# Medical Device Incident Report Form - Help Guide
## Purpose

This form is used to report incidents involving medical devices. It captures details about the incident, the device involved, and the reporter's contact information.

## How To Complete This Form

1. **Complete all required fields**: The following fields are marked as required:
	* Medical Device
	* Incident Date
	* Incident Time
	* Incident Description
	* Incident Location
	* Device Serial Number
	* Reporter Name
	* Contact Information
2. Fill in the form as accurately as possible, using the information about the incident.
3. If you are unsure about any field, leave a note or ask for help if necessary.

## Field-by-Field Explanation

* **Medical Device**: Enter the name of the medical device involved in the incident.
* **Incident Date**: Enter the date of the incident in the format MM/DD/YYYY.
* **Incident Time**: Enter the time of the incident in the format HH:MM AM/PM.
* **Incident Description**: Briefly describe what happened during the incident, including any relevant details.
* **Incident Location**: Enter the location where the incident occurred.
* **Device Serial Number**: Enter the serial number of the medical device involved in the incident.
* **Reporter Name**: Enter your name as the person reporting the incident.
* **Contact Information**: Enter your contact information, including your phone number and email address.
* **Category**: If applicable, select the category of the incident.
* **Accident or Injury**: If there was an accident or injury, select 'Yes'.
* **Was the Patient Injured**: If the patient was injured, select 'Yes'.
* **Medical Device Problem Category**: If there was a medical device problem, select 'Yes'.
* **Medical Device Problem Description**: Describe the medical device problem.
* **Medical Device Problem Category Others**: If the category is not listed, enter the custom category.
* **Medical Device Problem Other**: If the problem was not listed, enter the description of the problem.
* **Medical Device Problem Cause**: If there was a medical device problem cause, select 'Yes'.
* **Medical Device Problem Cause Other**: If the cause was not listed, enter the description of the cause.
* **Medical Device Problem Cause Other Description**: If the cause was not listed, enter the description of the cause.

Note: The fields marked as 'select_one' require a selection from the provided options, while 'text' fields require a written description.
