# Report Antisemitism Incident - Help Guide
## Purpose
The Report Antisemitism Incident form is designed to collect incident reports related to antisemitism that occur within the community.

## How To Complete This Form

1. Please fill out the form with as much detail as possible to help us address the incident.
2. Ensure that you answer all required questions truthfully and completely.

## Field-by-Field Explanation

### **Incident Report** (<incident_report>)

*   A text field to describe the incident in detail.

### **Incident Date** (<incident_date>)

*   The date on which the incident occurred.

### **Location** (<location>)

*   Where did the incident occur?
*   Please provide the exact location, including school name, classroom, or specific building.

### **Incident Reporter** (<incident_reporter>)

*   Select the person who reported the incident from the list:
    *   School/Teacher
    *   Parent
    *   Student
*   Please choose the most relevant option from the list.

### **Antisemitism Incident Details** (<antisemitism_incident_details>)

*   A text field to provide more details about the incident.

### **Witness** (<witness>)

*   If there were any witnesses, please provide their information.

### **Incident Reporter Info** (<incident_reporter_info>)

*   Please provide any additional information about the incident reporter, if necessary.

### **Follow-up Information** (<incident_followup>)

*   Select whether follow-up is necessary:
    *   True
    *   False
*   If follow-up is necessary, please indicate the next steps or actions to be taken.

### **Incident Resolution** (<incident_resolution>)

*   A text field to describe the resolution of the incident.
