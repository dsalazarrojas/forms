# public_transport_incident_form - Help Guide
## Purpose
This form is designed to collect information about incidents related to public transport. It is intended for reporting and analysis purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required information about the incident, such as the location and description.
* If you are reporting an incident, select the relevant reporting agency.
* If applicable, provide more details about the incident, including the transport details and incident types.
