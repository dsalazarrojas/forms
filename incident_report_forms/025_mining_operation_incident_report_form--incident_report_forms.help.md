# Mining Operation Incident Report Form - Help Guide
## Purpose
This form is designed to gather information about incidents that occur during mining operations. It is intended to help gather details about what happened, when it happened, and any assistance that may be required or provided. This form is not intended for use in actual emergency response situations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with as much detail as possible.
2. Make sure to include any relevant information about the incident, including the date and location.
3. Select the correct assistance status from the options provided.

## Field-by-Field Explanation

### 1. **incident_details** (incident details, text, required: false)
This field is a text box for you to provide as much detail as possible about the incident. Include all relevant information that might be useful for reference.

### 2. **report_date** (report date, date, required: false)
Fill in the date when you are submitting the report, in YYYY-MM-DD format.

### 3. **location** (location, text, required: false)
Provide the location where the incident occurred.

### 4. **description** (description, text, required: true)
This is a required field to provide a brief description of the incident.

### 5. **supporting_files** (supporting files, text, required: false)
If you have any supporting files or evidence related to the incident, you can provide them here.

### 6. **reporter** (reporter, text, required: false)
Enter your name and title/position in the organization.

### 7. **supervisor** (supervisor, text, required: false)
If applicable, enter the name and title/position of the supervisor who was on site or was informed of the incident.

### 8. **contact** (contact, text, required: false)
Provide your contact information so that the response team can reach you for further questions.

### 9. **assistance_required** (assistance required, text, required: false)
If you are requesting assistance, provide a brief explanation here.

### 10. **assistance_requested_by** (assistance requested by, text, required: false)
Enter the name and title/position of the person requesting assistance.

### 11. **assistance_provided_by** (assistance provided by, text, required: false)
Enter the name and title/position of the person who provided assistance.

### 12. **assistance_status** (assistance status, select one, required: true)
Select one of the options provided to indicate the current status of assistance:

    * No Assistance Needed
    * Assistance Requested
    * Assistance Provided
    * Assistance Denied

### 13. **other_details** (other details, text, required: false)
Enter any additional information about the incident that is not covered in the other fields.

**Tips**:
* Make sure to fill out all required fields.
* If you have any supporting files, upload them as attachments to this form.
* If you are requesting assistance, make sure to include as much detail as possible about the incident and what kind of assistance you need.
