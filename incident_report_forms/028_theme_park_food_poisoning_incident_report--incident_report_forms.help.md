# Theme Park Food Poisoning Incident Report - Help Guide
## Purpose
This guide will walk you through the process of completing the Theme Park Food Poisoning Incident Report form, a crucial tool for reporting incidents of food poisoning that have occurred at the theme park.

## How To Complete This Form
1. Fill in the **Incident Date** field with the date the incident occurred.
2. Enter the **Park ID** number, which can be found on the park's website or brochure.
3. Provide a detailed description of the food that was consumed, including any relevant details.
4. Select the **Symptoms** experienced by the customer from the drop-down menu.
5. Fill in the **Contact Email** and **Contact Phone** fields with the customer's contact information.
6. Choose the **Incident Status** from the drop-down menu, which indicates the current status of the incident.
7. Select the **Route Team** from the drop-down menu, which is the team responsible for handling the incident.
8. Enter any additional **Incident Notes** regarding the incident.
9. Provide any additional details about the **Food Consumed Details**.
10. If necessary, fill in the **Follow Up Date**, **Follow Up Time**, and **Follow Up Status** fields for any follow-up actions.
11. Enter any notes for the **Follow Up Notes**.
12. Add an **Incident Image** if relevant to the incident.
13. Provide the customer's **Customer Address**, **Customer City**, **Customer Province**, **Customer Country**, and **Customer Postal Code** if necessary.
14. Enter the customer's **Customer Phone** number.
15. Select the customer's **Customer Relationship** from the drop-down menu (e.g., Self-identified, Family Member, Staff, Guest, or Other).
16. Finally, enter the **Incident ID** if you have one.

## Field-by-Field Explanation

* **Incident Date**: The date the incident occurred.
* **Park ID**: The ID number for the park where the incident occurred.
* **Food Consumed**: A detailed description of the food that was consumed by the customer.
* **Symptoms**: Select the symptoms experienced by the customer from the drop-down menu.
* **Description**: A detailed description of the incident.
* **Customer ID**: The ID number for the customer (not to be confused with the **Incident ID**).
* **Contact Email**: The email address of the customer.
* **Contact Phone**: The phone number of the customer.
* **Incident Status**: The current status of the incident (e.g., Pending, Resolved, Follow-up, or Closed).
* **Route Team**: The team responsible for handling the incident.
* **Incident Notes**: Any additional notes regarding the incident.
* **Food Consumed Details**: Additional details about the food consumed.
* **Follow Up Date**: The date for any follow-up actions.
* **Follow Up Time**: The time for any follow-up actions.
* **Follow Up Status**: The status of any follow-up actions (e.g., Scheduled, Completed, Not Scheduled, or Pending).
* **Follow Up Notes**: Any additional notes for follow-up actions.
* **Incident Image**: An image related to the incident.
* **Customer Address**: The customer's address.
* **Customer City**: The customer's city.
* **Customer Province**: The customer's province.
* **Customer Country**: The customer's country.
* **Customer Postal Code**: The customer's postal code.
* **Customer Phone**: The customer's phone number.
* **Customer Relationship**: The customer's relationship with the park (e.g., Self-identified, Family Member, Staff, Guest, or Other).
* **Incident ID**: The unique ID for the incident.

Note that some fields are optional and are only required if necessary.
