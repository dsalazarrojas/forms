# Server Failure Report Form - Help Guide

## Purpose
This form is designed to collect information about server failures, allowing IT teams to report and track issues with server availability. The form is intended to gather relevant details about the server failure, including the category, server ID, and specific details about the problem. This information will help the support team to identify and address the root cause of the failure.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the server failure (e.g., Network, Hardware, Software).
2. Provide the server ID.
3. Describe the problem in the "Problem Description" field.
4. If relevant, specify the server starting and ending times.
5. Report the server downtime duration.
6. Select the current status of the server (e.g., Active, Inactive, Unknown).
7. If applicable, choose the team members who are assigned to address the issue (e.g., "Yes" or "No").
8. Provide the date of the report.
9. Add any additional comments or notes in the "Notes" field.

## Field-by-Field Explanation

* **Server Failure Report** (1): Enter a brief title for the report.
* **Category** (2): Select the category of the server failure from the options provided (e.g., Network, Hardware, Software).
* **Server ID** (3): Enter the unique ID of the server that experienced the failure.
* **Problem Description** (4): Provide a detailed description of the problem that occurred.
* **Server Starting Time** (5): If the server was running at the time of the failure, enter the time it started running. Leave blank if not applicable.
* **Server Ending Time** (6): If the server was running at the time of the failure, enter the time it stopped running. Leave blank if not applicable.
* **Server Downtime** (7): Report the duration of the server downtime in hours and minutes (e.g., 2 hours, 30 minutes).
* **Server Status** (8): Select the current status of the server (e.g., Active, Inactive, Unknown).
* **Assigned To** (9): Check "Yes" if team members are assigned to address the issue, or "No" if not.
* **Report Date** (10): Enter the date you are submitting the report.
* **Notes** (11): Add any additional comments or notes about the server failure.

**Tips**

* Be as detailed as possible in describing the problem to help the support team better understand the issue.
* Ensure that the server ID is accurate to help the support team quickly identify the affected server.
* Use the "Assigned To" field to ensure that team members are aware of their involvement in addressing the issue.
* Use the "Notes" field to add any additional information that may be relevant to the server failure.
