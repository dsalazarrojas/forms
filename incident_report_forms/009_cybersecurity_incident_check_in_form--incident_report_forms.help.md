# Cybersecurity Incident Check In Form - Help Guide
## Purpose
This form is designed to collect information about cybersecurity incidents, ensuring that critical information is captured in a standardized way.

## How To Complete This Form
1. Select the correct reporter (e.g., "Reported By") from the options provided.
2. Enter the date and time of the incident report using the "Report Date" and "Report Time" fields.
3. Select the type(s) of incident using the "Incident Type" field.
4. Provide a brief description of the incident in the "Report Description" field.
5. If necessary, provide additional incident details in the "Incident Details" field.
6. Select the impact of the incident using the "Incident Impact" field.
7. Select the status of the incident using the "Incident Status" field.

## Field-by-Field Explanation

* **Incident Report Form** (`incident_report_form`, text, optional): This is the title of the form that is being submitted.
* **Reported By** (`reported_by`, select one, required): Select who reported the incident (e.g., "Option 1").
* **Report Date** (`report_date`, date, optional): Enter the date of the report. 
* **Report Time** (`report_time`, time, optional): Enter the time of the report.
* **Incident Type** (`incident_type`, select multiple, required): Select the type(s) of incident (e.g., "Option 1", "Option 2").
* **Report Description** (`report_description`, text, optional): Provide a brief description of the incident.
* **Incident Summary** (`incident_summary`, text, optional): Provide a brief summary of the incident.
* **Report Date 2** (`report_date2`, date, optional): Enter the date of the report.
* **Report Time 2** (`report_time2`, time, optional): Enter the time of the report.
* **Incident Type 2** (`incident_type2`, select multiple, required): Select the type(s) of incident (e.g., "Option 1", "Option 2").
* **Report Description 2** (`report_description2`, text, optional): Provide a brief description of the incident.
* **Incident Details** (`incident_details`, text, optional): Provide additional incident details.
* **Incident Impact** (`incident_impact`, select one, required): Select the impact of the incident (e.g., "Option 1").
* **Incident Status** (`incident_status`, select one, required): Select the status of the incident (e.g., "Option 1").
