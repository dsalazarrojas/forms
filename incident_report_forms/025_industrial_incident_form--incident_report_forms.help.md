# industrial_incident_form - Help Guide
## Purpose
The industrial incident form is used to collect information about incidents that occurred during industrial activities. This form will help you report and document incidents in a structured manner, ensuring that all relevant details are captured.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the relevant options for each field.
3. Be thorough in providing details about the incident.
4. Review your answers before submitting the form to ensure accuracy.

## Field-by-Field Explanation

- **Incident Report Form**:
    * A text field to input any information you want to include about the incident.
    * This is a free-text field where you can type in as much or as little information as you need.
    * It's a good idea to keep your answer concise but still provide enough details about the incident.

- **industrial_location**:
    * A field to select the location where the incident occurred.
    * Choose the correct location from the list of options provided.

- **Incident Date**:
    * A field to input the date the incident happened.
    * Use the format MM/DD/YY to ensure accurate date input.

- **Incident Time**:
    * A field to input the time the incident happened.
    * Use the 24-hour format HH:MM to ensure accurate time input.

- **Incident Description**:
    * A text field to provide a detailed description of the incident.
    * This is where you should include as many details as possible about what happened, including circumstances, causes, and effects.

- **Industrial Incident Type**:
    * A field to select the type of incident that occurred.
    * Choose all the types that apply from the list of options provided.

- **Incident Status**:
    * A field to select the status of the incident.
    * Choose the correct status from the list of options provided.

- **Incident Location**:
    * A field to input the location where the incident occurred.
    * Be as specific as possible when providing the location.

- **Incident Date Reported**:
    * A field to input the date you reported the incident.
    * Use the format MM/DD/YY to ensure accurate date input.

- **Incident Time Reported**:
    * A field to input the time you reported the incident.
    * Use the 24-hour format HH:MM to ensure accurate time input.

- **Incident Cause**:
    * A text field to input the cause of the incident.
    * This is where you should provide as much detail as possible about the factors that led to the incident.

- **Incident Effect**:
    * A text field to input the effect of the incident.
    * This is where you should provide as much detail as possible about the impact of the incident.

- **Incident Investigation**:
    * A text field to input any further details about the investigation.
    * This is where you can provide any additional information gathered during the investigation process.

## Tips
* Always be as accurate and thorough as possible when filling out this form.
* Review your answers before submitting to ensure you have provided all relevant information.
* If you are unsure about any of the fields, don't hesitate to ask for help.
* This form is a tool to aid in incident reporting, please use it consistently and follow instructions to get the best results.
