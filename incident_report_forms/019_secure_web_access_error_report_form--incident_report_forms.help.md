# Secure Web Access Error Report Form - Help Guide
## Purpose
This form is used to report any Secure Web Access errors or issues that you are experiencing. Please provide as much detail as possible to help the technical team resolve the problem.

## How To Complete This Form
1. Fill in the required fields: **form_id**, **date**, **ip_address**, **url**, **error_message**, **error_details**, **operating_system**, **form_submitting_device**, **form_submitting_browser**, **form_submitting_ip**, **report_urgent**, **submitter_name**, and **submitter_email**.
2. If possible, provide the **form_submitting_os**, **form_submitting_postal_code**, **form_submitting_city**, **form_submitting_region**.
3. If you have any additional comments or observations, enter them in the **report_comments**.
4. Finally, indicate whether the issue is urgent by selecting **report_urgent**.

## Field-by-Field Explanation
* **form_id** (Number): A unique identifier for this error report.
* **Date** (Date): The date you are reporting the error.
* **ip_address** (Text): The IP address associated with the error.
* **url** (Text): The URL you were trying to access when the error occurred.
* **error_message** (Text): A description of the error message you received.
* **error_details** (Text): Any additional details about the error.
* **operating_system** (Text): The operating system you are using.
* **form_submitting_device** (Text): The device you are using to submit this form.
* **form_submitting_browser** (Text): The browser you are using.
* **form_submitting_ip** (Text): The IP address of the device submitting this form.
* **form_submitting_os** (Text): The operating system of the device submitting this form.
* **report_urgent** (Select One): Whether the issue is urgent and needs immediate attention.
* **submitter_name** (Text): Your name or identity.
* **submitter_email** (Email): Your email address.
* **submitter_ip** (Text): The IP address associated with your submitter account.
* **submitter_browser** (Text): The browser you are using to submit this form.
* **submitter_country** (Text): The country where you are submitting this form from.
* **submitter_city** (Text): The city where you are submitting this form from.
* **submitter_region** (Text): The region where you are submitting this form from.
* **form_submitting_postal_code** (Text): The postal code where you are submitting this form from.
* **form_submitting_comments** (Text): Any additional comments or observations.
* **submitter_browser** is actually a duplicate field and is not included in this list, so we will ignore it.
*   **report_comments** (Text): Any comments you may have about the issue.
* **report_urgent** (Select One): Whether the issue is urgent and needs immediate attention.
