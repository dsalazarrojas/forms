# cultural_event_incident_form - Help Guide
## Purpose
This form is used to report and document cultural events that have occurred within the organization.

## How To Complete This Form
- Read through the form carefully and fill out each field according to the instructions provided.
- If the event is new, create a new form.
- Do not create new forms for events that are already reported.
- Do not update the form unless the incident status has changed.

## Field-by-Field Explanation
- **Event Details** (`1`): Enter a brief description of the cultural event.
	* This field is used to capture any additional information about the event that doesn't fit in other fields.
- **Event Name** (`2`): Enter the name of the cultural event.
	* This field is used to give the event a unique title.
- **Event Date** (`3`): Select the date of the cultural event.
	* This field is used to record the date the event occurred.
- **Event Time** (`4`): Select the time of the cultural event.
	* This field is used to record the time the event occurred.
- **Location** (`5`): Enter the location where the cultural event occurred.
	* This field is used to record where the event took place.
- **Incident Description** (`6`): Enter a detailed description of what happened during the cultural event.
	* This field is used to capture the main details of the event.
- **Incident Image** (`7`): Upload any relevant images or attachments related to the cultural event.
	* This field is used to store images or attachments that support the event report.
- **Witness Statement** (`8`): Enter any witness statements or observations related to the cultural event.
	* This field is used to capture any statements from witnesses or observers.
- **Incident Status** (`9`): Select the current status of the cultural event.
	* This field is used to record whether the event is ongoing, resolved, or dismissed.
- **Incident Cause** (`10`): Select all causes that apply to the cultural event.
	* This field is used to capture the reasons for the incident.
- **Incident Outcome** (`11`): Select all outcomes that apply to the cultural event.
	* This field is used to record the impact of the incident.
- **Incident Category** (`12`): Select all categories that apply to the cultural event.
	* This field is used to classify the type of incident.
- **Incident Severity** (`13`): Select the level of severity for the cultural event.
	* This field is used to record the level of impact or seriousness of the incident.
- **Incident Priority** (`14`): Select whether the cultural event is a high or low priority.
	* This field is used to classify the event's importance.
- **Incident Investigator** (`15`): Select whether an investigator was assigned to the cultural event.
	* This field is used to indicate if an expert has reviewed the report.

## Tips
- Double-check each field to ensure accuracy and completeness.
- Use the "Incident Status" field to mark when the event is resolved or dismissed.
- The "Incident Image" field can be used to store evidence or supporting documentation.
