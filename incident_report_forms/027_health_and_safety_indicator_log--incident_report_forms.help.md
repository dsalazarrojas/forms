# Health And Safety Indicator Log - Help Guide
## Purpose
This form is used to record and track incidents that occur on site, including the incident type, date and time it occurred, and follow-up status.

## How To Complete This Form
- To begin, select the date and time the incident occurred in the "Date Incident Occurred" and "Time Incident Occurred" fields.
- Select the type of incident that occurred, such as a "Hazard" or "Near Miss", using the "Incident Type" dropdown menu.
- Choose the hazard categories that apply, such as "Physical" or "Chemical", from the "Hazard Category" dropdown menu.
- Provide a brief description of the hazard and the incident in the "Hazard Description" and "Incident Description" fields.
- Describe the actions taken in response to the incident in the "Actions Taken" field.
- Select the status of the follow-up activities, such as "Follow-up completed" or "Follow-up in progress", using the "Follow-up Status" dropdown menu.
- If applicable, assign the incident to a specific person using the "Assigned to" field.
- Finally, indicate who reviewed the incident report using the "Reviewed by" field.

## Field-by-Field Explanation
- **Site Address**: Enter the site address where the incident occurred.
  - (Required: False)
- **Site Location**: Enter the site location where the incident occurred.
  - (Required: False)
- **Date Incident Occurred**: Enter the date the incident occurred, in the format mm/dd/yyyy.
  - (Required: True)
- **Time Incident Occurred**: Enter the time the incident occurred, in the format 12:00 PM.
  - (Required: True)
- **Incident Type**: Select the type of incident that occurred.
  - (Required: True)
  - Options: Hazard, Near Miss, Incident, Other
- **Hazard Category**: Select one or multiple categories that apply to the hazard.
  - (Required: True)
  - Options: Physical, Chemical, Biological, Ergonomic, Other
- **Hazard Description**: Provide a brief description of the hazard that occurred.
  - (Required: False)
- **Incident Description**: Provide a brief description of the incident that occurred.
  - (Required: False)
- **Actions Taken**: Describe the actions taken in response to the incident.
  - (Required: False)
- **Follow-up Status**: Select the status of follow-up activities.
  - (Required: True)
  - Options: Follow-up completed, Follow-up in progress, No follow-up
- **Assigned to**: Assign the incident to a specific person, if applicable.
  - (Required: False)
- **Reviewed by**: Indicate who reviewed the incident report, if applicable.
  - (Required: False)
