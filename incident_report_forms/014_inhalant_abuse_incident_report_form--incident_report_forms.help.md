# Inhalant Abuse Incident Report Form - Help Guide
## Purpose
This form is designed to collect information about incidents of abuse, which can be reported by staff members or other authorized personnel. The goal is to gather accurate and detailed information about the incident, including its nature, location, and any other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select "Yes" or "No" to indicate whether the incident was reported (incident_report_form_1).
2.  Provide a brief report of the incident (incident_report_form_2).
3.  Enter the date of the incident using the date field (incident_report_form_3).
4.  Enter the time of the incident using the time field (incident_report_form_4).
5.  Provide the location of the incident (incident_report_form_5).
6.  Enter a detailed description of the incident (incident_report_form_6).
7.  Enter any available suspect ID information (incident_report_form_7).
8.  Enter the name of the suspect (incident_report_form_8).
9.  Select the relationship between the suspect and the victim or incident (incident_report_form_9).

## Field-by-Field Explanation
* **Incident Report Form** (incident_report_form_1, Select One, Optional): Check if an incident was reported. If yes, continue to the next field.
* **Report** (incident_report_form_2, Text, Optional): Provide a brief report of the incident.
* **Date** (incident_report_form_3, Date, Optional): Enter the date of the incident using the date field.
* **Time** (incident_report_form_4, Time, Optional): Enter the time of the incident using the time field.
* **Location** (incident_report_form_5, Text, Optional): Provide the location of the incident.
* **Description** (incident_report_form_6, Text, Optional): Enter a detailed description of the incident.
* **Suspect ID** (incident_report_form_7, Text, Optional): Enter any available suspect ID information.
* **Suspect Name** (incident_report_form_8, Text, Optional): Enter the name of the suspect.
* **Relationship** (incident_report_form_9, Text, Optional): Select the relationship between the suspect and the incident, such as "staff member" or "client".

## Tips
* Please make sure to report only incidents that you have personally witnessed or have been reported to you.
* If unsure about any information, please do not hesitate to ask for help.
* Make sure to fill out each field as accurately as possible.
* If you need to submit multiple incidents, you can submit each one separately, but please note that duplicate reports may not be necessary.
