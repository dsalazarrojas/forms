# Mail Service Disruption Report Form - Help Guide

## Purpose
The Mail Service Disruption Report Form is designed to collect information about disruptions to mail services. This form is used to report issues such as delays, outages, or other problems with mail services.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the form title, "Mail Service Disruption Report Form", to begin.
2. Fill in the form sections as instructed:
	* **Mail Service Disruption Report**: This is the main report section where you can describe the disruption.
	* **Location**: Enter the location where the disruption occurred.
	* **Date**: Enter the date when the disruption started.
	* **Time**: Enter the time when the disruption started.
	* **Service ID**: Enter the ID of the service affected by the disruption.
	* **Problem**: Describe the problem that occurred.
	* **Impact**: Describe the effect of the disruption.
	* **Status**: Select the status of the disruption from the available options (Available, Pending, Delayed, Disrupted).
	* **Follow-up**: If necessary, provide additional information for follow-up actions.
	* **Additional Info**: Enter any other relevant information about the disruption.
3. Click the "Submit" button to send the report.

## Tips
* Please be as detailed as possible when describing the disruption.
* If the problem is already resolved, please select "Available" as the status.
* If the status is "Disrupted", please provide any additional information that may help in follow-up actions.
* You can use the "Follow-up" section to provide any additional information that may be necessary for follow-up actions.
* If you have any other relevant information, please use the "Additional Info" section.
