# University Sports Event Incident Report Form - Help Guide
## Purpose
This form collects incident information during university sports events for prompt investigation and resolution.

## How To Complete This Form
1. Fill in the required information as accurately as possible.
2. Review the form carefully before submitting.
3. Ensure you have all the necessary details before proceeding.
4. If you need to fill in this form multiple times, save the unique URL that appears after submitting the current entry.

## Field-by-Field Explanation
* **General Information (id: 1)**: Enter a brief description of the incident.
* **Event Details (id: 2)**: Provide details about the event, such as event type (e.g., game, practice, or match).
* **Incident Summary (id: 3)**: Summarize the incident in a few sentences.
* **Location (id: 4)**: Specify the location of the incident (e.g., field, court, or sports facility).
* **Incident Date (id: 5)**: Enter the date of the incident.
* **Incident Time (id: 6)**: Enter the time of the incident.
* **Incident Reporter (id: 7)**: Enter your name and contact information.
* **Witness Details (id: 8)**: If there were witnesses, provide their details.
* **Incident Details (id: 9)**: Describe the incident in detail, including any injuries or damage.
* **Witness Statement (id: 10)**: If a witness statement is provided, enter it here.
* **Witness Signature (id: 11)**: If a witness is providing a statement, sign and date it.
* **Reporter Signature (id: 12)**: Sign and date your entry.
* **University Officer Signature (id: 13)**: If applicable, sign and date the entry of a university officer.
* **Incident Location (id: 14)**: Specify the location of the incident.
* **Incident Vehicles (id: 15)**: If vehicles were involved, describe them.
* **Incident Equipment (id: 16)**: If equipment was involved, describe it.
* **Incident Injuries (id: 17)**: Describe any injuries sustained.
* **Incident Damage (id: 18)**: Describe any damage caused.
* **Incident Weather (id: 19)**: If the incident was weather-related, describe the conditions.
* **Other Details (id: 20)**: Enter any additional details not covered by the other fields.
* **Event Type (id: 21)**: Select the type of event (e.g., football, soccer, basketball, or volleyball).
* **Sports Facility (id: 22)**: Select the sports facility where the incident occurred (e.g., gym, field, pool, or track).
* **Incident Type (id: 23)**: Select the type of incident (e.g., injury, medical emergency, fire, weather-related, or other).
* **Status (id: 24)**: Enter the status of the incident (e.g., resolved, ongoing, or pending).
* **Additional Comments (id: 25)**: Enter any additional comments about the incident.
* **Reporting Officer Info (id: 26)**: If applicable, enter information about the reporting officer.
