# Security Surveillance Review Request - Help Guide
## Purpose
This form is designed to report and request a video review of a security incident that has occurred or is ongoing. Please only submit one report per incident to avoid duplicating data.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide detailed information about the incident, including date, time, and location.
2. Decide whether or not to attach supporting files related to the incident.
3. Select the date and time you would like the video review to be performed.

## Field-by-Field Explanation

* **Incident Details** (`incident_details`, text, required/optional): Please provide a detailed description of the incident, including date, time, and location.
* **Supporting Files** (`supporting_files`, select_multiple, required/optional): Attach any relevant supporting files (e.g., screenshots, videos, or photos) related to the incident. Choose 'Yes' if you have supporting files to attach.
* **Requested Video Review** (`requested_video_review`, date, required/optional): Select the date and time you would like the video review to be performed. This will help the review team plan the review accordingly.

## Tips

* Make sure to provide accurate and detailed information about the incident.
* Only attach relevant supporting files that are directly related to the incident.
* If the video review date and time is not specified, it will be reviewed as soon as possible.
