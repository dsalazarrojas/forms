# Fire Alarm Incident Form - Help Guide
## Purpose
## How To Complete This Form
To complete this form, please follow the steps outlined above.

## Field-by-Field Explanation
* **Incident Date**: Enter the date the incident occurred.
* **Incident Time**: Enter the time the incident occurred.
* **Alarm Type**: Select the type of alarm system that was involved (e.g., smoke detector, fire alarm panel, etc.).
* **Description**: Enter a brief description of what happened.
* **Location**: Enter the location where the incident occurred.
* **Alarm Level**: Select the level of alarm that was activated (e.g., low, medium, high).
* **Alarm Source**: Select the source of the alarm (e.g., panel, exit, etc.).
* **Response Time**: Enter the time it took to respond to the incident.
* **Fire Fighting Method**: Select the method used to combat the fire (e.g., fire extinguisher, foam, etc.).
* **Cause of Incident**: Select the cause of the incident (e.g., system test, human error, etc.).
* **Number of Floors**: Enter the number of floors involved in the incident.
* **Number of Floors Evacuated**: Enter the number of floors evacuated.
* **Total People Evacuated**: Enter the total number of people involved in the incident.
* **Fire Extinguisher Location**: Select the location of the fire extinguisher used.
* **Evacuation Procedure**: Select the procedure used to evacuate the building (e.g., elevator, stairs, etc.).
* **Number of Fire Fighting Equipment**: Enter the number of fire fighting equipment used.
* **Number of Fire Extinguishers**: Enter the number of fire extinguishers used.
* **Total Floors**: Enter the total number of floors in the building.
* **Total People Present**: Enter the total number of people present in the building.
* **Number of Floors in Evacuation Zone**: Enter the number of floors in the evacuation zone.
* **Evacuation Procedure Effectiveness**: Evaluate the effectiveness of the evacuation procedure.
* **Incident Status**: Mark the status of the incident (e.g., open, closed, in progress).
* **Incident Type**: Select the type of incident that occurred (e.g., fire alarm, fire extinguisher, etc.).
* **Incident Description**: Enter a detailed description of the incident.
* **Incident Comments**: Enter any comments about the incident.

## Tips
* Be as detailed and accurate as possible when completing this form.
* If you are unsure about any field, please ask for clarification.
* This form is designed to gather information to help prevent future incidents and improve response times.
* Please report all incidents, even if they are minor.
* If you have any questions or concerns, please reach out to the relevant authorities.
