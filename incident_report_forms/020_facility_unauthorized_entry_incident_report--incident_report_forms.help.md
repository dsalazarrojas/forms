# Facility Unauthorized Entry Incident Report - Help Guide
## Purpose
This form is used to report incidents of unauthorized entry into a facility. It's an essential tool for documenting and tracking incidents for facilities with security protocols in place.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the facility where the incident occurred.
2. Select the date and time of the unauthorized entry.
3. Describe the incident in detail, including any relevant details about what happened.
4. Identify any prophets or security officers involved.
5. Choose the outcome of the incident.
6. If applicable, enter the date and time the incident was reported.

## Field-by-Field Explanation

* **Facility Name** (Facility Name): Enter the name of the facility where the incident occurred.
* **Unauthorized Entry Date** (Unauthorized-date): Select the date the incident took place.
* **Unauthorized Time** (Unauthorized-time): Select the time the incident occurred.
* **Incident Description** (Incident-description): Describe the details of the incident in a clear and concise manner.
* **Prophets and Security Officers Involved** (Prophets-and-security-officers-involved): Identify any prophets or security officers that were involved in the incident. Select all who were involved.
* **Incident Location** (Incident-location): Enter the location of the incident.
* **Description of Incident** (Description-of-incident): Provide a detailed description of the incident, if not already provided.
* **Incident Outcome** (Incident-outcome): Select the outcome of the incident from the provided options (Completed, Closed, Pending).
* **Incident Date Completed** (Incident-date-completed): Enter the date the incident was completed, if applicable.
* **Incident Date Reported** (Incident-date-reported): Enter the date the incident was reported.
* **Incident Time Reported** (Incident-time-reported): Select the time the incident was reported.
* **Facility Phone** (Facility-phone): Enter the phone number of the facility, if available.
