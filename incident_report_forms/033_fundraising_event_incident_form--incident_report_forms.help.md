## Fundraising Event Incident Form - Help Guide
## Purpose
The Fundraising Event Incident Form is designed to collect information about incidents that occurred during fundraising events. This form helps to gather accurate details about the incident, which enables prompt and effective handling of the situation.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the name of the event that occurred.
2. Provide the date and time of the incident.
3. Describe what happened, including any details about the incident type (e.g., bullying, conflicts, etc.).
4. If relevant, provide the date and time of the incident.
5. Describe the actions taken in response to the incident.
6. Add any additional information about the incident.

## Field-by-Field Explanation
- **Event Name** (`event_name`, text, required): Enter the name of the event that occurred.
- **Event Date** (`event_date`, date, required): Enter the date when the incident happened.
- **Event Time** (`event_time`, time, required): Enter the time when the incident occurred.
- **Incident Description** (`incident_description`, text, required): Provide a detailed description of what happened, including the incident type.
- **Incident Type** (`incident_type`, select_one, optional): Choose the type of incident from the options provided (e.g., bullying, conflicts, etc.).
  - Select one of the provided options (e.g., Bullying/Hazing, Conflicts between event staff and attendees, etc.).
- **Incident Date** (`incident_date`, date, optional): If not provided in the event date field, enter the date of the incident.
- **Incident Time** (`incident_time`, time, optional): If not provided in the event time field, enter the time of the incident.
- **Response Actions Taken** (`response_action_taken`, text, optional): Describe the actions taken in response to the incident.
- **Response Details** (`response_details`, text, optional): Add any additional details about the response.
- **Additional Information** (`additional_information`, text, optional): Add any other relevant information about the incident.
- **Submit** (`submit_form`, note, required): Click this button to submit the form.
