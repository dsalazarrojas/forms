# security_incident_response_service_request - Help Guide
## Purpose
This form is used to report and respond to security incidents within the organization. It is designed to gather essential information to help the security team address the issue effectively.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill in the required fields (indicated by *) with the relevant information about the incident.
2. Select the appropriate incident type, severity, and incident status from the provided options.
3. Provide a detailed description of the incident in the incident description field.
4. Specify the action required to resolve the incident in the request for action field.
5. If necessary, add any additional information in the incident reporter field.

## Field-by-Field Explanation
* **Incident Details**:
	+ **Incident Type**: Select the type of incident that has occurred (e.g., Option 1 or Option 2).
	+ **Incident Status**: Choose the status of the incident (e.g., Option 1, Option 2, or Option 3).
	+ **Incident Description**: Provide a detailed description of what happened, including dates and times where relevant.
* **Incident Type**: Select the type of incident that occurred (e.g., Option 1 or Option 2).
* **Severity**: Choose the level of severity associated with the incident (e.g., Option 1 or Option 2).
* **Incident Status**: Select the status of the incident (e.g., Option 1, Option 2, or Option 3).
* **Request for Action**: Choose the actions required to resolve the incident (e.g., Option 1 or Option 2).
* **Incident Reporter**: Provide your name and contact information, so the security team can reach out to you for further information.
* **Incident Responder**: Identify who or which team should respond to the incident (if necessary).
* **Resolution Date**: Provide the date by which you expect the incident to be resolved.
* **Resolution Time**: Provide the time by which you expect the incident to be resolved.

## Tips
* Make sure to provide as much detail as possible about the incident.
* If you are unsure about any of the options, select the one that best fits your situation.
* If you have any additional information or supporting documentation, attach it to the form.
