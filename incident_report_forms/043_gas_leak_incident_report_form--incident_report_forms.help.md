# gas_leak_incident_report_form - Help Guide

## Purpose
The gas leak incident report form is used to report any incidents involving gas leaks. This form helps collect information on the date of the incident, type of gas leak, location, description, and size of the leak. The form is designed to assist in documenting and investigating gas leak incidents in a systematic way.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Incident Date field with the date of the incident.
2. Select the type of gas leak from the options provided (Natural Gas, Liquefied Petroleum Gas, or Other).
3. Enter the location where the leak occurred in the Leak Location field.
4. Provide a detailed description of the leak in the Leak Description field.
5. Estimate the size of the leak in the Leak Size field.

## Field-by-Field Explanation

* **Incident Date** (Required: false, Type: date)
	+ Enter the date of the incident, in the format MM/DD/YYYY.
* **Leak Type** (Required: false, Type: select_one)
	+ Select the type of gas leak that occurred (Natural Gas, Liquefied Petroleum Gas, or Other).
* **Leak Location** (Required: false, Type: text)
	+ Enter the specific location where the leak occurred, including any relevant details (e.g., building, floor, room).
* **Leak Description** (Required: false, Type: text)
	+ Provide a detailed description of the leak, including any observations, symptoms, or effects observed.
* **Leak Size** (Required: false, Type: number)
	+ Estimate the approximate size of the leak, in cubic feet or another unit of measurement if applicable.
