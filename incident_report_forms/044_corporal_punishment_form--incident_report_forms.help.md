# Corporal Punishment Form - Help Guide
## Purpose
The corporal punishment form is used to document incidents of corporal punishment within an organization. This form is intended to collect information about the incident, including the user involved, date, location, and type of punishment. The form also tracks the status of each incident and the outcome of any investigation.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the user field with the name of the individual who was involved in the corporal punishment.
2. Enter the date of the incident in the date field.
3. Describe what happened in the description field.
4. Provide the location where the incident occurred in the location field.
5. Select the type of corporal punishment that occurred from the options provided.
6. List any witnesses to the incident in the witnesses field.
7. Select the status of the incident from the options provided.
8. Indicate the outcome of any investigation related to the incident.
9. Add any private notes from the user in the user notes field.
10. Add any private system notes in the system notes field.

## Field-by-Field Explanation

- **User**: Enter the name of the individual involved in the corporal punishment.
  - Type: `text`
  - Required: `false`

- **Date**: Enter the date of the incident.
  - Type: `date`
  - Required: `false`

- **Description**: Describe what happened in detail.
  - Type: `note`
  - Required: `false`

- **Location**: Provide the location where the incident occurred.
  - Type: `text`
  - Required: `false`

- **Type of Corporal Punishment**: Select the type of corporal punishment that occurred from the options provided.
  - Type: `select_one`
  - Required: `false`

- **Witnesses**: List any witnesses to the incident.
  - Type: `text`
  - Required: `false`

- **Status**: Select the status of the incident from the options provided.
  - Type: `select_one`
  - Required: `false`

- **Investigation Result**: Indicate the outcome of any investigation related to the incident.
  - Type: `select_one`
  - Required: `false`

- **User Notes**: Enter any private notes from the user.
  - Type: `note`
  - Required: `false`

- **System Notes**: Enter any private system notes.
  - Type: `note`
  - Required: `false`

## Tips
* Please ensure that you only complete this form for events where corporal punishment has actually occurred or is suspected.
* Be accurate and concise when filling in the fields.
* Private notes fields are intended for internal use only and should not be shared with others.
* If you are unsure about the correct information to fill in, please contact a relevant authority figure.
