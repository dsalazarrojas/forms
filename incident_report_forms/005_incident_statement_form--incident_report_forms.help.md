# incident-statement-form - Help Guide
## Purpose

This form is a general template for collecting information from witnesses and others involved in a vehicle incident. It includes fields for contact details, witness statements, vehicle information, and police reports.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each section carefully and provide accurate and honest information.
2. Ensure you have permission to submit this form and that it is relevant to your situation.
3. Answer each question truthfully and to the best of your ability.

## Field-by-Field Explanation

* **Incident Report (1)**: A brief description of the incident or what happened.
	+ Type: text
	+ Required: false
* **Contact Information (2)**: Your contact details, such as name and address, for follow-up purposes.
	+ Type: text
	+ Required: false
* **Witness Information (3)**: Details about the witness, including their name and contact information.
	+ Type: text
	+ Required: false
* **Vehicle Information (4)**: Description of the vehicle involved in the incident.
	+ Type: text
	+ Required: false
* **Witness Statement (5)**: A detailed account of what you saw or know about the incident.
	+ Type: text
	+ Required: false
* **Police Report (6)**: Details from a police report or incident report, if applicable.
	+ Type: text
	+ Required: false
* **Vehicle Incident (7)**: Description of the vehicle's involvement in the incident.
	+ Type: text
	+ Required: false
* **Witness Statement Date (8)**: Date of the witness statement.
	+ Type: date
	+ Required: false
* **Witness Statement Time (9)**: Time of the witness statement.
	+ Type: time
	+ Required: false
* **Witness Statement Location (10)**: Location of the witness statement.
	+ Type: text
	+ Required: false
* **Police Report Date (11)**: Date of the police report.
	+ Type: date
	+ Required: false
* **Police Report Time (12)**: Time of the police report.
	+ Type: time
	+ Required: false
* **Vehicle Incident Description (13)**: Description of the vehicle's involvement in the incident.
	+ Type: text
	+ Required: false
* **Witness Statement Email (14)**: Email address of the witness, if applicable.
	+ Type: email
	+ Required: false
* **Police Report Email (15)**: Email address of the police report, if applicable.
	+ Type: email
	+ Required: false

## Tips

* Be honest and thorough in your responses.
* Ensure you have permission to submit this form and that it is relevant to your situation.
* If you have already submitted a similar form, please do not duplicate your efforts.
* If you have any questions or concerns, please contact the form author at form@gic.mx.
