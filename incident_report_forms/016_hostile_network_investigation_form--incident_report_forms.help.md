# Hostile Network Investigation Form - Help Guide
## Purpose
The purpose of this form is to collect information about hostile network incidents and guide the incident response team's efforts to address the issue effectively.
## How To Complete This Form
To complete this form, follow these steps:
1. Start by filling in the required fields, which are marked with an asterisk (\*).
2. Provide a clear and concise description of the incident in the "Incident Description" field.
3. Indicate whether the network was involved in the incident by selecting "Yes" or "No" in the "Hostile Network Involvement" field.
4. Identify the affected hosts by selecting the correct option from the list.
5. Provide the time the incident occurred in the "Incident Time" field.
6. Specify the date the incident occurred in the "Incident Date" field.
7. Identify the location where the incident occurred in the "Incident Location" field.
8. Select the type of incident from the list (Network, System, or Application).
9. Provide a brief summary of the incident in the "Incident Summary" field.
10. Select the status of the incident (Open, Closed, or In Progress).
11. Indicate whether the incident is a priority (Yes or No).
12. Add any additional comments or details about the incident in the "Incident Comments" field.
13. Attach any relevant files or documents related to the incident in the "Incident Attachments" field.

## Field-by-Field Explanation
### Incident Report Form 
* `incident_report_form`: A free-text field for any additional information about the incident.
### Incident Description 
* `incident_description`: A text field for providing a clear and concise description of the incident.
### Hostile Network Involvement 
* `hostile_network_involvement`: Select "Yes" if the network was involved in the incident, otherwise select "No".
### Affected Hosts 
* `affected_hosts`: Select the hosts affected by the incident from the list.
### Incident Time 
* `incident_time`: The time the incident occurred.
### Incident Date 
* `incident_date`: The date the incident occurred.
### Incident Location 
* `incident_location`: The location where the incident occurred.
### Incident Type 
* `incident_type`: Select the type of incident from the list (Network, System, or Application).
### Incident Summary 
* `incident_summary`: A brief summary of the incident.
### Incident Status 
* `incident_status`: Select the status of the incident from the list (Open, Closed, or In Progress).
### Incident Priority 
* `incident_priority`: Indicate whether the incident is a priority (Yes or No).
### Incident Escalation 
* `incident_escalation`: Add any additional comments or details about the incident.
### Incident Comments 
* `incident_comments`: Attach any relevant files or documents related to the incident.
