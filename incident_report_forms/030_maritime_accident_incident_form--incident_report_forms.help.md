# Maritime Accident Incident Form - Help Guide
## Purpose
The Maritime Accident Incident Form is designed to collect information about maritime accidents or incidents that have occurred during various maritime activities. It helps ensure that all relevant data is gathered accurately and consistently, which is essential for thorough analysis and investigation of the incident.

## How To Complete This Form
To fill out the Maritime Accident Incident Form, follow these steps:

1.  Select the type of incident (e.g., Collision, Sinking, Fire, or Storm) from the `incident_type` field.
2.  Enter the location where the incident occurred in the `incident_location` field.
3.  Provide the date of the incident in the `incident_date` field. Ensure it's formatted in the correct date format (YYYY-MM-DD).
4.  Enter the time of the incident in the `incident_time` field. Please use the 24-hour clock format (HH:MM:SS).
5.  Select the nature of the incident from the list provided in the `incident_nature` field. You can choose more than one option if necessary.
6.  Type a description of the incident in the `incident_description` field. Be as detailed as possible without exceeding the space provided.
7.  Enter the number of damages or losses incurred during the incident in the `incident_damages` field.
8.  If any crew members were injured or missing, report the number in the `incident_injuries` and `incident_deaths` fields respectively.
9.  Provide the location of the incident again for confirmation in the `incident_location` field.
10. Enter any weather conditions that may have contributed to the incident in the `incident_weather` field.
11.  Report the status of the crew after the incident in the `incident_crew` field. This includes selecting if all crew members were accounted for.
12.  If applicable, enter the type of vessel involved in the `incident_vessel` field.
13.  Choose the type of vessel (e.g., Ship, Boat, Vessel) from the `incident_vessel_type` field.
14.  Select the size of the vessel from the options provided in the `incident_vessel_size` field.
15.  If the vessel flies a flag, select its type from the `incident_vessel_flag` field.
16.  Provide a detailed description of the incident cause in the `incident_cause` field.
17.  If an investigation has been or will be conducted, mark the `incident_investigation` field accordingly.

## Field-by-Field Explanation

* **incident_type**: Select the category the incident falls under (e.g., Collision, Sinking, etc.). This helps in categorizing the incident for easier reference and analysis.
* **incident_location**: Enter the exact location where the incident occurred. This is crucial for identifying the incident's geographical context.
* **incident_date**: Enter the date of the incident in the YYYY-MM-DD format. This ensures that the date is clearly readable and understandable.
* **incident_time**: Provide the time of the incident in the 24-hour clock format (HH:MM:SS). This helps in understanding the timing of the incident.
* **incident_nature**: Select all the relevant options that apply to the incident's nature (e.g., Collision, Fire, Storm, etc.). This provides a detailed description of the incident's characteristics.
* **incident_description**: Type a clear and concise description of the incident. This provides essential context for further analysis.
* **incident_damages**: Report any physical damages or losses suffered during the incident. This includes monetary, material, or environmental damages.
* **incident_injuries**: If any crew members were injured, enter the total number here. This helps in assessing the incident's impact on crew safety.
* **incident_deaths**: If there were any fatalities, enter the number here. This is critical for assessing the incident's severity.
* **incident_location**: Confirm the location of the incident for accuracy.
* **incident_weather**: If weather conditions contributed to the incident, provide a brief description here.
* **incident_crew**: Report the status of the crew after the incident (e.g., all accounted for, some missing or injured, etc.).
* **incident_vessel**: If applicable, enter the type of vessel involved in the incident.
* **incident_vessel_type**: Choose the type of vessel that was involved (e.g., Ship, Boat, Vessel).
* **incident_vessel_size**: Select the size of the vessel from the options provided.
* **incident_vessel_flag**: If the vessel flies a flag, select its type (e.g., National, International, None).
* **incident_cause**: Provide a detailed description of the incident's cause.
* **incident_investigation**: Indicate if an investigation has been or will be conducted into the incident.

## Tips
- Always fill out the form accurately and truthfully to ensure reliable data.
- If you are unsure about any field, refer to the provided options or contact the relevant authorities for clarification.
- Use the 24-hour clock for the `incident_time` field.
- For `incident_date`, use the YYYY-MM-DD format.
- Be as detailed as possible for the `incident_description` and `incident_cause` fields.
