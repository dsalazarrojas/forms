# Construction Zone Collapse Incident Form - Help Guide
## Purpose
The Construction Zone Collapse Incident Form is a crucial document used to report and document construction zone collapses. It is used to record details about the incident, including the date, time, project name, location, and other relevant information.

## How To Complete This Form
1. Fill out the form with the relevant details about the incident.
2. Provide accurate and clear information to ensure a comprehensive report.
3. Use the provided options for fields where applicable.
4. Submit the form once completed.

## Field-by-Field Explanation

* **Incident Report Number** (`incident_report_number`, text, required): Enter the auto-generated or manual report ID.
* **Date of Incident** (`incident_date`, date, required): Enter the date the incident occurred.
* **Time of Incident** (`incident_time`, time, required): Enter the exact time the incident occurred.
* **Project Name** (`project_name`, text, required): Enter the name of the construction project.
* **Project Location** (`project_location`, text, required): Enter the full address of the construction site.
* **Specific Zone of Collapse** (`specific_zone`, text, required): Enter the area or section where the collapse occurred.
* **Reporter Name** (`reporter_name`, text, required): Enter the name of the person reporting the incident.
* **Reporter Position** (`reporter_position`, text, required): Enter the job title or role of the person reporting the incident.
* **Reporter Contact Information** (`reporter_contact`, text, required): Enter the phone and email of the person reporting the incident.
* **Type of Collapse** (`collapse_type`, select_one, required): Select the type of structural collapse that occurred.
	+ Partial Structural Collapse
	+ Complete Structural Collapse
	+ Scaffolding Collapse
	+ Trench Collapse
	+ Roof Collapse
	+ Wall Collapse
	+ Floor Collapse
	+ Other
* **Were There Any Injuries** (`injuries_reported`, select_one, required): Select 'True' if anyone was injured.
* **Injury Details** (`injury_details`, text, required if selected): Enter a description of the injuries sustained.
* **Were There Any Fatalities** (`fatalities`, select_one, required): Select 'True' if there were any deaths.
* **Number of People Affected** (`number_of_people_affected`, number, required): Enter the total number of workers or others affected.
* **Weather Conditions at Time of Incident** (`weather_conditions`, select_one, optional): Select the conditions at the time of the incident.
	+ Clear/Sunny
	+ Cloudy
	+ Rainy
	+ Stormy
	+ Windy
	+ Snowy
	+ Foggy
	+ Not Applicable - Indoor Site
* **Potential Causes of Collapse** (`potential_causes`, select_multiple, required): Select all the potential causes of the collapse that may apply.
	+ Structural Design Flaw
	+ Material Failure
	+ Overloading
	+ Excavation Issues
	+ Weather Related
	+ Equipment Failure
	+ Human Error
	+ Sabotage
	+ Unknown
* **Immediate Actions Taken** (`immediate_actions_taken`, text, required): Enter a description of the emergency response and immediate actions taken.
* **Were Emergency Services Notified** (`emergency_services_notified`, select_one, required): Select 'True' if emergency services were called.
* **Was the Area Evacuated** (`area_evacuated`, select_one, required): Select 'True' if the area was evacuated.
* **Photos or Videos Attached** (`photos_attached`, select_one, optional): Select 'True' if visual documentation is available.
* **Witness Names** (`witness_names`, text, optional): Enter the names of any witnesses.
* **Additional Comments** (`additional_comments`, text, optional): Enter any other relevant information.

Note: If unsure about any field, please consult with a member of the safety team or refer to the relevant company procedures.
