# First Aid Incident Report Form - Help Guide
## Purpose
The First Aid Incident Report Form is designed to collect information about incidents that require first aid attention. This form helps gather essential details to provide the necessary support and care for the affected individual. Please fill out this form as accurately and thoroughly as possible to ensure the best possible outcome.

## How To Complete This Form
To complete this form, follow these steps:

1. **Incident Report Form**: This is the main section of the form where you can describe the incident that occurred. Please provide as much detail as possible.
2. **Incident Date**: If you're reporting an incident that happened in the past, fill in the date it occurred. If the incident is ongoing, select the start date of the incident.
3. **Incident Time**: Report the time the incident occurred or when the first aid was provided.
4. **Incident Location**: Describe the location where the incident took place.
5. **Incident Description**: Provide a detailed description of what happened, including any circumstances that led to the incident.
6. **Incident Injuries**: If injuries were sustained, describe the type and extent of the injuries.
7. **First Aid Provider**: If first aid was provided, enter the name of the person or organization who provided assistance.
8. **Provider Name**: This is the name of the person or organization that provided first aid.
9. **Provider Company**: If the provider is from a company or organization, enter their name.
10. **Provider Contact**: Enter the contact information of the provider.
11. **Provider E-Signature**: If possible, include an electronic signature from the provider. This is a unique identifier that confirms they provided first aid.
12. **Provider E-Signature Base64**: This is an optional field for providers to attach an electronic signature in base64 format.

## Field-by-Field Explanation
* **Incident Report Form**: This field is the main section where you can describe the incident.
* **Incident Date**: Enter the date the incident occurred, if applicable.
* **Incident Time**: Report the time the incident took place.
* **Incident Location**: Describe the location of the incident.
* **Incident Description**: Provide a detailed account of what happened.
* **Incident Injuries**: Describe the type and extent of any injuries sustained.
* **First Aid Provider**: If first aid was provided, enter the name of the person or organization that assisted.
* **Provider Name**: Enter the name of the individual or organization that provided first aid.
* **Provider Company**: If the provider is from a company or organization, enter their name.
* **Provider Contact**: Enter the contact information of the provider.
* **Provider E-Signature**: If possible, include an electronic signature from the provider, confirming they provided first aid.
* **Provider E-Signature Base64**: This field is optional for providers to attach an electronic signature in base64 format.

## Tips
* Please fill out this form as accurately and completely as possible to ensure the best possible outcome.
* If you're unsure about any part of this form, don't hesitate to ask for guidance.
* If you're a provider, make sure to attach an electronic signature if possible, to confirm you provided first aid.
