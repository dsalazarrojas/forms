# process_failure_detection_report_form - Help Guide
## Purpose
The process_failure_detection_report_form is designed to collect information about process failures that have occurred within the organization. This form is used to document and analyze specific, concrete events or incidents, and should not be used for general or speculative reporting.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the **Severity** of the process failure from the options provided.
2. Enter the **Start Date** and **End Date** of the failure incident.
3. Provide a detailed **Description** of the failure incident.
4. If applicable, include supporting **Evidence Attachment**.
5. If relevant, provide additional **Incident ID 1** and **Incident ID 2** for related incidents.

## Field-by-Field Explanation

* **Incident ID** (1): Enter the ID of the process failure incident, if applicable.
* **Severity** (2): Select the level of severity of the process failure, from Minor, Major, or Critical.
* **Start Date** (3): Enter the date and time when the process failure started.
* **End Date** (4): Enter the date and time when the process failure ended.
* **Description** (5): Provide a detailed description of the process failure incident, including any relevant details.
* **Details** (6): Enter any additional details about the process failure incident.
* **Evidence Attachment** (7): If applicable, attach supporting evidence or documentation related to the process failure incident.
* **Incident ID 1** (8): If relevant, enter the ID of another related incident.
* **Incident ID 2** (9): If relevant, enter the ID of another related incident.

## Tips
* Make sure to provide accurate and detailed information about the process failure incident.
* Ensure that the start and end dates are correctly entered.
* If you are unsure about any aspect of the form, please contact the form creator or the process owner for guidance.
