# Wellness Center Treatment Reaction Incident Report - Help Guide
## Purpose
This form is used to report incidents that occur at the wellness center, including allergic reactions, injuries, and other types of incidents.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the date and time of the incident.
2. Enter the name of the staff member involved in the incident.
3. Enter the name of the client involved in the incident.
4. Select the type of incident that occurred.
5. Enter a description of the incident.
6. Select the date and time for any follow-up actions.
7. Select the status of the follow-up actions (Complete, Incomplete, or None).
8. Select "Yes" or "No" for follow-up images.
9. Enter any comments about the follow-up actions.

## Field-by-Field Explanation
* **Incident Date**: 
    - The date field is where you can select the date of the incident. 
    - The date is the date the incident occurred.
* **Incident Time**:
    - Enter the start time of the incident. 
* **Incident End Time**:
    - Enter the end time of the incident.
* **Staff Member**:
    - Enter the name of the staff member involved in the incident.
* **Client Name**:
    - Enter the name of the client involved in the incident.
* **Incident Description**:
    - Enter a description of the incident. 
* **Incident Type**:
    - Select the type of incident that occurred (Allergic Reaction, Injury, etc.).
* **Follow-up Date**:
    - Select the date of any follow-up actions. 
* **Follow-up Time**:
    - Select the time of any follow-up actions. 
* **Follow-up Status**:
    - Select the status of the follow-up actions (Complete, Incomplete, or None).
* **Incident Image**:
    - Select "Yes" or "No" if an image was taken of the incident.
* **Follow-up Image**:
    - Select "Yes" or "No" if follow-up images were taken.
* **Follow-up Comment**:
    - Enter any comments about the follow-up actions.
* **Staff Comment**:
    - Enter any comments from the staff member about the incident.
