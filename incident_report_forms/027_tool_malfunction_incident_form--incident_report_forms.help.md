# Tool Malfunction Incident Form - Help Guide
## Purpose
The Tool Malfunction Incident Form is used to report issues with tools within the organization, providing a structured way to document and track malfunctions.

## How To Complete This Form
1.  To report a tool malfunction, start by filling out this form.
2.  Enter the tool ID, which helps identify the specific tool in question.
3.  Specify whether the tool type is malfunctioning.
4.  Provide a detailed description of the issue you are experiencing.
5.  Enter the date and time of the incident for accurate tracking.
6.  State the current tool condition, which could be working or not.
7.  Mention the location where the tool is being used.
8.  List the users affected by the malfunction.
9.  Report who reported the incident.
10. Lastly, enter the date when the incident was reported.

## Field-by-Field Explanation
* **Tool Malfunction** (`tool_malfunction_incident_form`): This is the main title of the form that summarizes the reported issue.
* **Tool ID** (`tool_id`): Enter the unique identifier for the specific tool experiencing the malfunction.
* **Tool Type** (`tool_type`): Choose whether the tool is malfunctioning or not. This helps in prioritizing and classifying issues.
* **Description** (`description`): Describe the problem you are experiencing with the tool in as much detail as possible.
* **Incident Date** (`incident_date`): Enter the date when the malfunction occurred.
* **Incident Time** (`incident_time`): Provide the time of the incident for accurate tracking and reporting.
* **Tool Condition** (`tool_condition`): Specify the current state of the tool, whether it's functioning or not.
* **Location** (`location`): Mention the place where the tool is being used.
* **Affected Users** (`affected_users`): List the users impacted by the tool malfunction.
* **Incident Reported By** (`incident_reported_by`): Identify who reported the incident.
* **Incident Reporting Date** (`incident_reporting_date`): Enter the date when the incident was reported.

## Tips
- Make sure to fill out the form accurately and thoroughly to ensure that the issue is properly understood and addressed.
- If you are unsure about any of the fields, refer to the help guide or ask your supervisor for clarification.
- Duplicate reports can cause confusion and slow down the resolution process, so please ensure that your report is original.
