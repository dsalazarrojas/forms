# parking_lot_incident_form - Help Guide
## Purpose
The parking_lot_incident_form is designed to document and record incidents that occur within a parking lot, including incidents involving vehicles. Its primary function is to collect essential details such as the date of the incident, location, and description, as well as the type of vehicle involved, if applicable.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the incident details page and enter the incident date, location, and description in the corresponding fields.
2. If applicable, select the incident type, vehicle type, and parking area involved in the incident.
3. If relevant, provide witness statements and the URL of any photos or videos related to the incident.
4. Assign a user to the incident.
5. Enter the incident number, reported by name, and incident status.
6. If the incident has been closed, enter the date of closure, reason for closure, the user who closed the incident, and any closure comments.

## Field-by-Field Explanation
* **Incident Details**: This field is used to enter the essential details of the incident, including the date, location, and description.
* **Incident Date**: Enter the date on which the incident occurred.
* **Location**: Provide the location where the incident occurred.
* **Description**: Enter a brief description of what happened during the incident.
* **Incident Type**: Select the type of incident (Yes/No).
* **Vehicle Type**: If applicable, select the type of vehicle involved in the incident (Yes/No).
* **Parking Area**: If applicable, select the parking area where the incident occurred (Yes/No).
* **Vehicle Color**: If applicable, select the color of the vehicle involved in the incident (Yes/No).
* **Witness Statements**: Enter any witness statements or comments related to the incident.
* **Photo Url**: Enter the URL of any photos or videos related to the incident.
* **Assigned To**: Assign a user to the incident.
* **Incident Number**: Enter a unique number for the incident.
* **Incident Reported By**: Enter the name of the person who reported the incident.
* **Incident Status**: Select the current status of the incident (Active/Inactive).
* **Incident Closed**: If the incident has been closed, enter the date of closure.
* **Incident Closed Reason**: Enter the reason for closing the incident.
* **Incident Closed By**: Enter the user who closed the incident.
* **Incident Closed Comments**: Enter any comments related to the incident closure.
* **Closed By User**: Select if the incident was closed by a user (Yes/No).
* **Incident Status Comments**: Enter any comments about the incident status.
* **Status History**: Select the history of the incident status (Active/Inactive).
