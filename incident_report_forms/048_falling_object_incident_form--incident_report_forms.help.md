# Falling Object Incident Form - Help Guide
## Purpose
This form is a tool used to document and report incidents involving falling objects.

## How To Complete This Form
To fill out this form, follow these steps:

* Date: Select the date of the incident.
* Object Falling: Enter a brief description of the object that fell.
* Object Description: Provide a detailed description of the object that fell.
* Location Where Object Fell: Enter the location where the object fell.
* Object Mass: If you know the mass of the object, enter it here (in kg or pounds).
* Object Velocity: If you know the velocity of the object, enter it here.
* Incident Type: Choose the type of incident that occurred (e.g. Object falling to ground, Object falling on floor, Other).
* Witness: Check if there was a witness to the incident.
* Witness Description: Provide a brief description of the witness's account.
* Witness Phone Number: If the witness is available, enter their phone number for follow-up.
* Incident Reporter's Phone Number: Enter your phone number so we can contact you about the incident.
* Incident Reporter's Name: Enter your name as the incident reporter.
* Incident Reporter's Title: Enter your title or position.
* Incident Reporter's Department: Select the department you belong to.
* Incident Reporter's Email: Enter your email address.
* Incident Reporter's Phone Number: Enter your phone number.
* Incident Reporter's Notes: Add any additional notes or comments about the incident.
* Incident Reported By: Select who reported the incident (e.g. Operations, Maintenance, Management).
* Incident Location: Choose the location where the incident occurred (e.g. Ground, Air, Other).
* Incident Description: Provide a brief description of the incident.
* Incident Cause: Enter any known cause of the incident.
* Incident Effect: Describe the effect of the incident (e.g. damage, injury, etc.).
* Incident Injuries: Check if anyone was injured during the incident.
* Incident Reported On: Enter the date the incident was reported.
* Incident Status: Select the status of the incident (e.g. Pending, Resolved, Closed).
