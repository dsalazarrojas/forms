# Tunnel Accident Incident Form - Help Guide
## Purpose
The Tunnel Accident Incident Form is a tool for collecting information about tunnel-related incidents, such as accidents or near-misses. This data is used to improve tunnel safety.
## How To Complete This Form
To complete the form, follow these steps:

1.  Click on the form and fill out the required fields.
2.  If you're unsure about any field, you can always ask for help or clarification.
## Field-by-Field Explanation

*   **Incident Date** (`incident_date`, date, required: false): Enter the date the incident occurred.
*   **Incident Time** (`incident_time`, time, required: false): Enter the time the incident occurred.
*   **Incident Location** (`incident_location`, text, required: false): Enter the location of the incident, including the tunnel name or reference number.
*   **Incident Nature** (`incident_nature`, text, required: false): Briefly describe the nature of the incident.
*   **Incident Description** (`incident_description`, text, required: false): Provide a detailed description of the incident, including what happened and any relevant details.
*   **Vehicle Involved** (`vehicle_involved`, select_one, required: false): If a vehicle was involved, select 'Yes' to indicate that. Otherwise, select 'No'.
*   **Tunnel Section** (`tunnel_section`, select_multiple, required: false): If the incident occurred on a specific tunnel section, select 'Yes'.  Note that you can select multiple sections.
*   **Incident Reporter** (`incident_reporter`, select_multiple, required: false): If the incident was reported by someone, select 'Yes'.  Note that you can select multiple reporters.
*   **Witness Statements** (`witness_statements`, note, required: false): If there are witness statements, provide them here, along with any relevant details.
*   **Incident Photo** (`incident_photo`, text, required: false): If a photo is available, enter the file location or link here.
*   **Incident Video** (`incident_video`, text, required: false): If a video is available, enter the file location or link here.
*   **Incident Audio** (`incident_audio`, text, required: false): If audio is available, enter the file location or link here.
*   **Incident Document** (`incident_document`, text, required: false): If any supporting documents are available, enter the file location or link here.
*   **Other** (`incident_other`, text, required: false): If there's anything else you'd like to add about the incident, enter it here.

## Tips

*   If you're unsure about any of the fields, don't worry! Just ask for help, and we'll do our best to clarify.
*   The more information you provide, the more helpful it is to us!
