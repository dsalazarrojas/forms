# Maladministration Reporting Form - Help Guide
## Purpose
The Maladministration Reporting Form is used to collect information about maladministration incidents from the reporting unit. This form is a required field for reporting units to submit incident reports to the administration team.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Incident Report" page, which includes fields for incident details, reporting unit, and incident date and time.
2. On the "Attachment" page, select the type of attachment (File, URL, Video, or Audio), and upload your attachment and provide a description.
3. Fill out the "Tags" page, which includes fields for tags, tags description, and organisation details.
4. Review and submit your completed form.

## Field-by-Field Explanation

* **Incident Report (1)**: This is the main section for submitting the incident report. Enter a brief description of the incident.
* **Reporting Unit (2)**: Enter the name of the reporting unit submitting the incident report.
* **Incident Location (3)**: Enter the location where the incident occurred.
* **Incident Date (4)**: Enter the date of the incident.
* **Incident Time (5)**: Enter the time of the incident.
* **Incident Details (6)**: Enter a detailed description of the incident.
* **Incident Status (7)**: Select the status of the incident (Pending, In Progress, Resolved, or Closed).
* **Incident Reporter (8)**: Enter the name of the person reporting the incident.
* **Incident Assignee (9)**: Enter the name of the person assigned to the incident.
* **Incident Priority (10)**: Select the priority level of the incident (Low, Medium, High).
* **Incident Category (11)**: Select the category of the incident (General, Security, Technical).
* **Incident Comments (12)**: Enter any additional comments about the incident.
* **Reporting Unit Name (13)**: Enter the name of the reporting unit submitting the incident report.
* **Reporting Unit Email (14)**: Enter the email address of the reporting unit.
* **Reporting Unit Phone (15)**: Enter the phone number of the reporting unit.
* **Incident Attachment (16)**: Upload your attachment to provide additional evidence or documentation of the incident.
* **Incident Attachment Description (17)**: Enter a description of the attachment.
* **Upload File (18)**: Upload a file to attach to the incident report.
* **File Name (19)**: Enter the name of the file.
* **Description (20)**: Enter a brief description of the file.
* **URL (21)**: Enter a URL link to the incident attachment.
* **Attachment Type (22)**: Select the type of attachment (File, URL, Video, Audio).
* **Tags (23)**: Select the tags associated with the incident attachment.
* **Tags Description (24)**: Enter a description of the tags.
* **Tags (25)**: Select the organisation associated with the tags.
* **Reporting Unit Organisation (26)**: Enter the name of the organisation submitting the incident report.
* **Incident Attachment Tags Organisation (27)**: Enter the organisation details associated with the tags.
* **Tags Organisation Description (28)**: Enter a description of the organisation.
* **Tags Organisation Email (29)**: Enter the email address of the organisation.
* **Tags Organisation Phone (30)**: Enter the phone number of the organisation.
