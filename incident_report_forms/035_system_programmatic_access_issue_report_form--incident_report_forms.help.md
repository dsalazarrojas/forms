# System Programmatic Access Issue Report Form - Help Guide

## Purpose
This form is for reporting incidents of programmatic access issues in the system. It helps us to understand and track these issues to prevent future occurrences.

## How To Complete This Form
To complete this form, follow these steps:

1. **Incident Report Form** (`incident_report_form`, text, required: false): This is the main section of the form where you report the incident.
2. **System ID** (`system_id`, text, required: false): Provide a unique identifier for the system where the issue occurred.
3. **Description** (`description`, text, required: false): Describe the issue in detail. Be as specific as possible.
4. **Issue Type** (`issue_type`, select_one, required: false): Select the type of issue that occurred:
	* Technical Issue
	* Access Issue
	* Other
5. **Impact Level** (`impact_level`, select_multiple, required: false): Choose the impact level of the issue:
	* High
	* Medium
	* Low
6. **Report Date** (`report_date`, date, required: false): Enter the date you are reporting the issue.
7. **Report Time** (`report_time`, time, required: false): Enter the time you are reporting the issue.
8. **Assigned Tool** (`assigned_tool`, select_one, required: false): Select the tool that helped you resolve the issue:
	* chatjimmy
	* Other
9. **Issue Description** (`issue_description`, text, required: false): Give more details about the issue that occurred.
10. **Environment** (`environment`, text, required: false): Describe the environment where the issue occurred.

## Field-by-Field Explanation

* **Incident Report Form** (`incident_report_form`):
	+ This section is the main section of the form where you describe the incident.
	+ Be as specific as possible when writing this section.
* **System ID** (`system_id`):
	+ This field is for providing a unique identifier for the system where the issue occurred.
* **Description** (`description`):
	+ In this section, provide detailed information about the issue you are reporting.
* **Issue Type** (`issue_type`):
	+ Choose the type of issue that best describes what happened.
* **Impact Level** (`impact_level`):
	+ Choose the impact level based on how severe the issue was.
* **Report Date** (`report_date`):
	+ Enter the date you are reporting the issue.
* **Report Time** (`report_time`):
	+ Enter the time you are reporting the issue.
* **Assigned Tool** (`assigned_tool`):
	+ If you used a tool to help you resolve the issue, choose it here.
* **Issue Description** (`issue_description`):
	+ This section is for providing more details about the issue.
* **Environment** (`environment`):
	+ Describe the environment where the issue occurred.

## Tips
- Please be as specific as possible when reporting the issue.
- Do not submit duplicate reports for the same issue.
- If the issue is not resolved, report it immediately to prevent future occurrences.
