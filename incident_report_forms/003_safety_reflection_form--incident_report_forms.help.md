# Safety Reflection Form - Help Guide
## Purpose
This form is used for documenting and analyzing incidents to identify root causes and implement prevention measures.

## How To Complete This Form
To complete this form, please follow these steps:
1. Provide a brief description of the incident that occurred.
2. Indicate whether the root cause of the incident was identified (Yes or No).
3. Describe the near miss or incident that occurred.
4. Indicate whether action was taken as a result of the incident (Yes or No).
5. Select the actions that were taken as a result of the incident.
6. Review and update the form as necessary to ensure that it accurately reflects the incident and any subsequent actions taken.

## Field-by-Field Explanation
* **Incident Summary** (`incident_summary`, text, Optional): A brief description of the incident that occurred.
* **Root Cause** (`root_cause`, select_multiple, Optional): Select all options that apply to the root cause of the incident (e.g., "Yes", "No").
* **Prevention Steps** (`prevention_steps`, text, Optional): A description of the steps that can be taken to prevent similar incidents in the future.
* **Near Miss Description** (`near_miss_description`, text, Optional): A description of the near miss or incident that occurred.
* **Root Cause Identified** (`root_cause_identified`, select_one, Optional): Indicate whether the root cause of the incident was identified (Yes or No).
* **Action Planned** (`action_planned`, select_one, Optional): Indicate whether action was planned as a result of the incident (Yes or No).
* **Action Taken** (`action_taken`, select_multiple, Optional): Select all options that apply to the actions that were taken as a result of the incident (e.g., "Yes", "No").
