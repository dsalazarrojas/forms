# health_and_safety_incident_form - Help Guide
## Purpose
The Health and Safety Incident Form is a tool used to record and report incidents that occur within the workplace. This form helps to gather accurate and detailed information about each incident, which is essential for maintaining a safe and healthy work environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide detailed information about the incident, including the date, time, location, and description.
2. Indicate if there were any injuries or deaths related to the incident.
3. Select the type of incident that occurred.
4. Identify the person reporting the incident and (if applicable) the supervisor who was present.
5. Describe the actions taken to address the incident.

## Field-by-Field Explanation

* **Incident Details** (1, Text, Required):
	+ Enter a brief description of the incident, including any relevant details.
* **Incident Date** (2, Date, Required):
	+ Enter the date on which the incident occurred.
* **Incident Time** (3, Time, Required):
	+ Enter the time at which the incident occurred.
* **Incident Location** (4, Text, Required):
	+ Enter the location where the incident occurred.
* **Incident Description** (5, Text, Required):
	+ Provide a detailed description of what happened.
* **Were There Injuries** (6, Select One, Required):
	+ Select 'True' if there were injuries and 'False' otherwise.
* **Were There Deaths** (7, Select One, Required):
	+ Select 'True' if there were deaths and 'False' otherwise.
* **Incident Type** (8, Select Multiple, Required):
	+ Select all applicable types of incidents that occurred (e.g., slip, fall, cut, burn, vehicle collision, other).
* **Incident Reporter** (9, Text, Required):
	+ Enter the name of the person reporting the incident.
* **Incident Supervisor** (10, Text, Optional):
	+ Enter the name of the supervisor who was present during the incident.
* **Actions Taken** (11, Text, Optional):
	+ Describe any actions taken to address the incident.
* **Incident ID** (12, Text, Optional):
	+ Enter a unique ID for the incident.

## Tips

* Be as detailed and accurate as possible when providing information about the incident.
* If you're unsure about any information, please contact the designated authority for assistance.
* Remember to fill out this form for every incident, no matter how minor it may seem.
