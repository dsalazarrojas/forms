# Crowd Control Incident Form - Help Guide
## Purpose
The Crowd Control Incident Form is used to report and document incidents that occur within the crowd or community. This form is used to gather information about the incident, including the event details, type of incident, location, and status. The information collected will help in understanding the incident and taking appropriate actions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information for each field as prompted.
2. Enter the required information for each field.
3. Ensure that all required fields are filled in before submitting the form.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, required/optional): Enter a brief description of the incident, including any relevant details about what happened.
* **Incident Type** (`incident_type`, select_one, required/optional): Choose the type of incident from the provided options:
	+ Event-related
	+ Medical Emergency
	+ Suspicious Activity
	+ Security Issue
* **Description** (`description`, text, required/optional): Provide more detailed information about the incident, including any relevant context or background.
* **Incident Date and Time** (`incident_datetime`, date/time, required/optional): Enter the date and time of the incident.
* **Incident Location** (`incident_location`, text, required/optional): Specify the location where the incident occurred.
* **Incident Time** (`incident_time`, time, required/optional): Enter the time the incident occurred.
* **Incident Status** (`incident_status`, select_one, required/optional): Choose the current status of the incident from the provided options:
	+ Reported
	+ Unresolved
	+ Resolved
	+ In Progress
* **Incident Image** (`incident_image`, text, required/optional): If available, attach an image or video related to the incident.
* **Incident Details** (`incident_details`, text, required/optional): Provide any additional information about the incident that may be helpful in understanding its context.

## Tips
* Make sure to provide as much detail as possible for each field to ensure a thorough understanding of the incident.
* Use the provided options for selecting incident type and status to help speed up the submission process.
* If you're unsure about any field, refer to the form's purpose and available options to guide your input.
