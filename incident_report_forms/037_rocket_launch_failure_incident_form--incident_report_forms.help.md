# Rocket Launch Failure Incident Form - Help Guide
## Purpose
The Rocket Launch Failure Incident Form is a tool to document and report rocket launch failures, providing essential information for analysis and corrective actions.

## How To Complete This Form
1. Enter the **Rocket Launch Failure** text field to describe the incident briefly.
2. Provide the **Launch site** where the rocket launch occurred.
3. Specify the **Rocket Vehicle** that experienced the failure.
4. Enter the **Launch Date and Time** of the incident.
5. Choose the **Cause of Failure** from the list of options, or select "Unknown" if it's unclear.
6. Enter a detailed **Incident Description** of what happened.

## Field-by-Field Explanation
* **Rocket Launch Failure**: A brief description of the incident (Required: **yes**, type: text).
* **Launch site**: The location where the rocket launch occurred (Required: **no**, type: text).
* **Rocket Vehicle**: The name or identifier of the rocket that failed (Required: **no**, type: text).
* **Launch Date and Time**: The date and time when the launch occurred (Required: **no**, type: date).
* **Launch Time**: The time when the launch occurred (Required: **no**, type: time).
* **Cause of Failure**: The reason for the rocket launch failure, choose from:
	+ Engine failure
	+ Software failure
	+ Human error
	+ Unknown
* **Incident Description**: A detailed description of what happened during the incident (Required: **no**, type: text).

## Tips
* Be as specific and accurate as possible when filling out the form.
* If unsure about the cause of failure, select "Unknown" and provide a brief explanation in the incident description.
* If you need to report multiple incidents, create a new form for each separate incident.
