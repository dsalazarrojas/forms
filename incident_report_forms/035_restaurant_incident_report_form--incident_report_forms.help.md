# Restaurant Incident Report Form - Help Guide
## Purpose
The Restaurant Incident Report Form is a tool used to report incidents or accidents that have occurred within a restaurant setting. This form helps to document the details of the incident, which can aid in investigations, risk management, and staff training.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the incident date and time fields to record the exact time and date of the incident.
2. Describe the location where the incident occurred.
3. Indicate if there were any witnesses present.
4. If there were witnesses, provide their details in the Witness 1 and Witness 2 fields.
5. Check if supporting documents are attached to the report.

## Field-by-Field Explanation
* **Incident Date** (`incident_date`, Date, Optional): Enter the date of the incident.
* **Incident Time** (`incident_time`, Time, Optional): Enter the time of the day when the incident occurred.
* **Incident Location** (`incident_location`, Text, Optional): Describe the location where the incident happened.
* **Witnesses** (`witnesses`, Select Multiple, Optional): Check if there were any witnesses. Select 'Yes' or 'No'.
* **Witness 1** (`witness_1`, Text, Optional): If there were witnesses, enter their details here.
* **Witness 2** (`witness_2`, Text, Optional): If there were witnesses, enter their details here.
* **Supporting Documents** (`supporting_documents`, Select Multiple, Optional): Check if supporting documents are attached to the report. Select 'Yes' or 'No'.
