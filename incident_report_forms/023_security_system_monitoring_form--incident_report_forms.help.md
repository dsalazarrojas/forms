# Security System Monitoring Form - Help Guide
## Purpose
The **Security System Monitoring Form** is used to report and monitor incidents within the security system. 

## How To Complete This Form
To complete this form, please follow these steps:

1.  **Report an Incident**: Provide a brief description of the incident in the **Report an Incident** field. This will help us understand the situation.
2.  **Describe the Incident**: In the **Describe the Incident** field, provide a detailed explanation of what happened. Be as specific as possible about the incident, including the circumstances surrounding it.
3.  **Location**: Enter the location of the incident in the **Location** field. This is crucial for identifying where the incident occurred.
4.  **Choose a Category**: Select a category for the incident from the options provided in the **Choose a Category** field. This helps us better understand the type of incident that occurred.
5.  **Date**: Enter the date of the incident in the **Date** field. This is essential for logging and record-keeping purposes.
6.  **Monitor System Performance**: In the **Monitor System Performance** field, add any relevant notes about system performance related to the incident. This will aid in troubleshooting and understanding system behavior.
7.  **Submit a Maintenance Request**: Select one or more options for the **Submit a Maintenance Request** field if applicable. This will help us prioritize and address any maintenance needs.
8.  **Time of Incident**: Enter the time of the incident in the **Time of Incident** field. This is necessary for precise logging.
9.  **Security Clearance**: Select **Yes** or **No** in the **Security Clearance** field. This will aid in determining the level of security clearance required for future access.

## Tips

*   Only submit this form once per incident, unless instructed otherwise.
*   Be as detailed as possible when describing the incident.
*   Ensure you select the correct category for the incident.
*   Enter the exact date and time of the incident. 
*   Only select **Yes** or **No** for security clearance.
*   If a maintenance request is applicable, select all options that apply. 
*   Be specific with any notes about system performance.
