# software_issue_reporting_intake_form - Help Guide

## Purpose
The software issue reporting intake form is designed to collect information about software issues reported by users. This form helps our team to identify and address the issues quickly and effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Software Issue field with a brief description of the problem you are experiencing.
2. Select the user-reported date from the calendar.
3. Specify the software version affected by the issue.
4. Describe the issue in the Issue Description field.
5. Identify the affected users in the Affected Users field.
6. Specify the groups affected by the issue in the Affected Groups field.
7. Enter the issue-reported time in the Issue Reported Time field.
8. Choose the issue resolution time, if applicable.
9. Describe the cause of the issue in the Issue Cause field.
10. Specify the effect of the issue in the Issue Effect field.
11. Describe how the issue was resolved in the Issue Resolution field.
12. Enter any additional comments about the issue in the Issue Comments field.
13. Provide a brief history of software version related to the issue in the Software Version History field.
14. Enter the email address of the user who reported the issue in the Issue Reported By Email field.
15. Enter the phone number of the user who reported the issue in the Issue Reported By Phone field.
16. Choose whether the issue is assigned to a technician in the Assigned Technician field.
17. Enter any comments from the assigned technician in the Technician Comments field.
18. Choose the issue status in the Issue Status field.
19. Choose the issue category in the Issue Category field.
20. Specify the type of incident in the Incident Type field.
21. Enter a unique incident number in the Incident Number field.
22. Enter a prefix for the incident number in the Incident Number Prefix field.

## Field-by-Field Explanation

* **Software Issue** (`id: 1`, text, required): Enter a brief description of the problem you are experiencing.
* **User Reported Date** (`id: 2`, date, required): Select the date when the issue was reported.
* **Software Version** (`id: 3`, text, required): Specify the software version affected by the issue.
* **Issue Description** (`id: 4`, text, required): Describe the issue in detail.
* **Affected Users** (`id: 5`, text, required): Identify the users affected by the issue.
* **Affected Groups** (`id: 6`, text, required): Specify the groups affected by the issue.
* **Issue Reported Time** (`id: 7`, time, required): Enter the time when the issue was reported.
* **Issue Reported Date Time** (`id: 8`, date, required): Select the date and time when the issue was reported.
* **Issue Resolved Time** (`id: 10`, time, required): Choose the issue resolution time.
* **Issue Cause** (`id: 11`, text, required): Describe the cause of the issue.
* **Issue Effect** (`id: 12`, text, required): Specify the effect of the issue.
* **Issue Resolution** (`id: 13`, text, required): Describe how the issue was resolved.
* **Issue Comments** (`id: 14`, text, required): Enter any additional comments about the issue.
* **Software Version History** (`id: 15`, text, required): Provide a brief history of software version related to the issue.
* **Issue Reported By** (`id: 16`, text, required): Enter the name of the user who reported the issue.
* **Issue Reported By Email** (`id: 17`, email, required): Enter the email address of the user who reported the issue.
* **Issue Reported By Phone** (`id: 18`, text, required): Enter the phone number of the user who reported the issue.
* **Assigned Technician** (`id: 19`, select one, required): Choose whether the issue is assigned to a technician.
* **Technician Comments** (`id: 20`, text, required): Enter any comments from the assigned technician.
* **Issue Status** (`id: 21`, select one, required): Choose the issue status.
* **Issue Category** (`id: 22`, select one, required): Choose the issue category.
* **Incident Type** (`id: 23`, text, required): Specify the type of incident.
* **Incident Number** (`id: 24`, text, required): Enter a unique incident number.
* **Incident Number Prefix** (`id: 25`, text, required): Enter a prefix for the incident number.
