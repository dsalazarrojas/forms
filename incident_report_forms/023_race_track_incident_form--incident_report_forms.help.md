# Race Track Incident Form - Help Guide
## Purpose
The Race Track Incident Form is a tool used to collect and document information about incidents that occur on the race track. This form helps race track officials gather details about the incident, including the date and time it occurred, the location, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary information about the incident, including the date and time it occurred, the location, and any other relevant details.
2. Choose the correct options for each field based on the information you have about the incident.
3. Fill in the fields as prompted, using the following fields:

## Field-by-Field Explanation
* **Incident Date**: Date of the incident (e.g., 02/01/2022)
* **Incident Time**: Time of the incident (e.g., 14:30)
* **Incident Location**: Location where the incident occurred (e.g., Main Straight, Pit Lane, etc.)
* **Incident Type**:
	+ Select "Yes" if the incident involved an accident, injury, or near miss. 
	+ Select "No" if the incident did not involve an accident, injury, or near miss.
* **Race Track Name**: Name of the race track where the incident occurred
* **Race Track Officials**:
	+ Select "Yes" if race track officials were involved in the incident or responded to it.
	+ Select "No" if race track officials were not involved in the incident or responded to it.
* **Vehicle Involved**: Description of the vehicle involved in the incident (e.g., make, model, and license plate number)
* **Vehicle License State**: State where the vehicle is registered
* **Vehicle Year**: Year of the vehicle
* **Incident Narrative**: Detailed description of what happened during the incident, including any relevant details and context.

## Tips
* Make sure to fill out the form accurately and thoroughly, as the information will be used to determine the course of action to take in response to the incident.
* If you are unsure about any field or option, please contact the race track officials for assistance.
