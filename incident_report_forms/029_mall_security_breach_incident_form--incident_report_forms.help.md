# Mall Security Breach Incident Form - Help Guide
## Purpose
This form is designed to collect information about a security breach incident that occurred in a mall. It helps to gather details about the incident, including the date, time, location, and descriptions of the suspect(s) and their vehicle(s).

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the **Incident Summary** field, which is a brief description of what happened.
2. Then, provide the **Date** and **Time** of the incident.
3. Next, enter the **Location** where the incident occurred.
4. Describe the incident in more detail in the **Incident Details** field.
5. If there is an **Incident Image**, upload it to help with the investigation.
6. Provide a **Witness Statement** to help gather more information about what happened.
7. If there are multiple witnesses, you can add **Witness Statement 1**, **Witness Statement 2**, and **Witness Statement 3** fields as needed.
8. If a suspect was involved, describe them in the **Suspect Description**, **Suspect Details**, and **Suspect Vehicle** fields.
9. If you have information about the suspect's vehicle, you can provide additional details in the **Suspect Vehicle Details**, **Suspect License Number**, and **Suspect License State** fields.
10. Finally, upload a **Suspect Photo** to help identify the suspect.

## Field-by-Field Explanation
- **Incident Summary**: A brief description of what happened in the mall.
  - Type: note
  - Required: Optional
- **Date**: The date of the incident.
  - Type: date
  - Required: Optional
- **Time**: The time of the incident.
  - Type: time
  - Required: Optional
- **Location**: The location where the incident occurred.
  - Type: text
  - Required: Optional
- **Incident Details**: A more detailed description of what happened.
  - Type: text
  - Required: Optional
- **Incident Image**: An image that can help with the investigation.
  - Type: text
  - Required: Optional
- **Witness Statement**: A statement from a witness that can help gather more information.
  - Type: text
  - Required: Optional
- **Witness Statement 1**: A statement from the first witness.
  - Type: text
  - Required: Optional
- **Witness Statement 2**: A statement from the second witness.
  - Type: text
  - Required: Optional
- **Witness Statement 3**: A statement from the third witness.
  - Type: text
  - Required: Optional
- **Suspect Description**: A description of the suspect.
  - Type: text
  - Required: Optional
- **Suspect Details**: Additional details about the suspect.
  - Type: text
  - Required: Optional
- **Suspect Vehicle**: The vehicle associated with the suspect.
  - Type: text
  - Required: Optional
- **Suspect Vehicle Details**: More details about the suspect's vehicle.
  - Type: text
  - Required: Optional
- **Suspect License Number**: The license plate number of the suspect's vehicle.
  - Type: text
  - Required: Optional
- **Suspect License State**: The state where the suspect's license was issued.
  - Type: text
  - Required: Optional
- **Suspect Photo**: A photo of the suspect.
  - Type: text
  - Required: Optional

## Tips
* Fill out as much information as possible to help with the investigation.
* If you have any doubts or questions, contact the relevant authorities or the form creators.
* Please be as accurate as possible when filling out the form.
