# Incident Severity Classification Form - Help Guide
## Purpose
The Incident Severity Classification Form is a tool used to categorize incidents based on their severity and gather relevant information for follow-up purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the incident severity level from the dropdown menu:
	* Critical: Severe incidents that require immediate attention.
	* High: Incidents that are serious but not critical.
	* Medium: Incidents that are noticeable but not severe.
	* Low: Incidents that are minor and not time-sensitive.
2. Choose the follow-up method for the incident:
	* Phone: Receive a call to discuss the incident.
	* Email: Receive an email to discuss the incident.
	* Chat: Use chat to discuss the incident.
3. Enter the date and time the incident occurred.
4. Enter the location where the incident occurred.
5. Provide a brief description of the incident.
6. Select the follow-up status:
	* Completed: The follow-up has been completed.
	* In Progress: The follow-up is still in progress.
	* Not Started: The follow-up has not started yet.

## Field-by-Field Explanation

* **Incident Severity Classification** (`incident_severity_classification_form`, Select One, Required):
	+ Select the level of severity of the incident.
* **Follow-up Details** (`follow_up_details`, Select Multiple, Required):
	+ Choose one or more methods to follow up on the incident (e.g., Email, Phone, Chat).
* **Incident Date** (`incident_date`, Date, Required):
	+ Enter the date the incident occurred.
* **Incident Time** (`incident_time`, Time, Required):
	+ Enter the time the incident occurred.
* **Incident Location** (`incident_location`, Text, Required):
	+ Enter the location where the incident occurred.
* **Incident Description** (`incident_description`, Text, Required):
	+ Provide a brief description of the incident.
* **Follow-up Method** (`follow_up_method`, Select One, Required):
	+ Choose the method to use for follow-up (e.g., Phone, Email, Chat).
* **Follow-up Status** (`follow_up_status`, Select One, Required):
	+ Select the status of the follow-up (e.g., Completed, In Progress, Not Started).
