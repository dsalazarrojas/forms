# Library Patron Incident Report Form - Help Guide

## Purpose

The Library Patron Incident Report Form is designed to help library staff report and document incidents involving library patrons in a standardized way. This form provides a comprehensive layout to collect relevant details about the incident, allowing library management to track and address these incidents efficiently.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form and identify the type of incident you are reporting (e.g., accident, security concern, etc.).
2. Select the relevant options for the "select_one" field (e.g., choose the type of incident from the list).
3. Fill out any applicable fields, such as dates, times, and notes, as relevant to the incident.
4. If required, upload relevant files to support your report.
5. Review the form before submitting it for accuracy and completeness.

## Field-by-Field Explanation

### 1. **library_patron_incident_report_form**
 * This field is the main text area for reporting the incident. Provide a clear and concise description of what happened.

### 2. **select_one**
 * Select the type of incident from the list (e.g., accident, security concern, etc.).

### 3. **select_multiple**
 * Select any additional options that apply to the incident (e.g., location, time of day, etc.).

### 4. **date**
 * Enter the date of the incident in the format MM/DD/YYYY (e.g., 02/16/2023).

### 5. **time**
 * Enter the time of the incident in the format 12:00 PM (e.g., 02:00 PM).

### 6. **note**
 * Provide a brief note about the incident to provide additional context.

### 7. **email**
 * Enter the email address of the person involved or responsible for the incident.

### 8. **phone**
 * Enter the phone number of the person involved or responsible for the incident.

### 9. **file_upload**, **file_upload_2**, **file_upload_3**, **file_upload_4**
 * If applicable, upload files related to the incident to support your report.

### 10-11. **file_uploads**, **file_uploads_2**, **file_uploads_3**
 * These fields are similar to file_upload, but with different labels. They can be used to upload additional files related to the incident.

## Tips

* Make sure to review the form carefully before submitting it to ensure accuracy and completeness.
* If you're unsure about any field or option, consult with library management or staff for guidance.
* Remember to keep sensitive information confidential and handle it according to library policies.
