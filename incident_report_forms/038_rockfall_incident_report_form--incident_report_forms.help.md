# rockfall_incident_report_form - Help Guide
## Purpose
This form is designed to collect information about rockfall incidents, including their location, date, and time, as well as details about witnesses, injuries, or fatalities.

## How To Complete This Form
1. Please fill out the form in its entirety, ensuring all required fields are completed.
2. Enter accurate and detailed information for each field, as requested.
3. If unsure about any field, please refer to the Field-by-Field Explanation section for clarification.

## Field-by-Field Explanation
* **Incident Description** (`rockfall_incident_description`, `text`, required): Briefly describe the incident.
* **Incident Location** (`location`, `text`, required): Provide the exact location of the incident.
* **Incident Date** (`rockfall_incident_date`, `date`, required): Enter the date of the incident.
* **Time of Day** (`time_of_day`, `time`, required): Record the time when the incident occurred.
* **Rockfall Type** (`rockfall_type`, `select_one`, required): Select 'Yes' if the incident was a rockfall, 'No' otherwise.
* **Witness Count** (`witness`, `number`, required): Enter the number of witnesses present during the incident.
* **Rockfall Size Range** (`rockfall_size_range`, `select_multiple`, required): Select the size range of the rockfall.
* **Rockfall Size Range Size Units** (`rockfall_size_range_size_units`, `select_multiple`, required): Select the units for the rockfall size range.
* **Witness Description** (`witness_description`, `text`, required): Describe the witness's account of the incident.
* **Rockfall Description** (`rockfall_description`, `text`, required): Provide a detailed description of the rockfall.
* **Photos** (`photos`, `select_multiple`, required): If available, attach photos of the incident.
* **Videos** (`videos`, `select_multiple`, required): If available, attach videos of the incident.
* **Report Date** (`report_date`, `date`, required): Enter the date when the report was submitted.
* **Assigned To** (`assigned_to`, `select_one`, required): Select the person or department assigned to handle the report.
* **Report Status** (`report_status`, `select_one`, required): Select the status of the report (Active or Inactive).
* **Rockfall Area** (`rockfall_area`, `text`, optional): Enter the affected area of the rockfall.
* **Rockfall Affected Area** (`rockfall_affected_area`, `text`, optional): Describe the area affected by the rockfall.
* **Rockfall Affected People** (`rockfall_affected_people`, `text`, optional): List the people affected by the rockfall.
* **Rockfall Description Affected People** (`rockfall_description_affected_people`, `text`, optional): Describe the injuries or fatalities among the affected people.
* **Rockfall Injuries** (`rockfall_injuries`, `text`, optional): Enter details about injuries sustained during the incident.
* **Rockfall Injury Description** (`rockfall_injury_description`, `text`, optional): Describe the injuries sustained.
* **Rockfall Deaths** (`rockfall_deaths`, `text`, optional): Enter the number of fatalities.
* **Rockfall Deceased Description** (`rockfall_deceased_description`, `text`, optional): Describe the fatalities.
* **Rockfall Status** (`rockfall_status`, `text`, optional): Enter the current status of the rockfall.
* **Rockfall Comment** (`rockfall_comment`, `text`, optional): Enter any additional comments about the incident.
