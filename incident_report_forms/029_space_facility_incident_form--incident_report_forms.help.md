# space_facility_incident_form - Help Guide
## Purpose
The purpose of this form is to gather incident information for internal tracking and resolution purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the location of the facility where the incident occurred in the "Facility Location" field.
2.  Enter the date when the incident occurred in the "Date Incident Occurred" field.
3.  Select the type of incident that occurred from the "Incident Type" dropdown menu.
4.  Enter any additional details about the incident in the "Incident Details" field.
5.  Select the current status of the incident from the "Incident Status" dropdown menu.
6.  Enter the contact person's email address in the "Contact Person" field.
7.  Enter the contact person's phone number in the "Phone Number" field.

## Field-by-Field Explanation

*   **Facility Location (Text)**: This field is used to input the location of the facility where the incident occurred.
*   **Date Incident Occurred (Date)**: This field is used to input the date when the incident happened.
*   **Incident Type (Select One)**: This field is used to select the type of incident that occurred from the dropdown menu.
    +   Options: Fire, Security Breach, Environmental Hazard
*   **Incident Details (Note)**: This field is used to input any additional details about the incident.
*   **Incident Status (Select One)**: This field is used to select the current status of the incident from the dropdown menu.
    +   Options: In Progress, Resolved
*   **Contact Person (Email)**: This field is used to input the contact person's email address.
*   **Phone Number (Text)**: This field is used to input the contact person's phone number.
