# Disease Outbreak Incident Form - Help Guide
## Purpose
The Disease Outbreak Incident Form is used to report and document disease outbreaks, providing a standardized way to collect and analyze information on disease cases, case reports, and outbreak types.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form pages to ensure you have all the necessary information before proceeding.
2. Answer each field accurately and thoroughly, using the provided options or text input fields as necessary.
3. If an option is not provided, use the text input field to provide additional information.
4. Review your submission before submitting it to ensure accuracy and completeness.

## Field-by-Field Explanation
- **Page 1** (`first_page`, `text`, required: false): This is the first page of the form. You can review the form's purpose and instructions here.
- **Case Identification** (`case_identification`, `select_one`, required: false): Select the correct case identification option from the provided list to accurately categorize the outbreak.
- **Case Description** (`case_description`, `text`, required: false): Provide a clear and concise description of the disease outbreak case.
- **Date of Outbreak** (`case_date`, `date`, required: false): Enter the date the outbreak was reported or occurred.
- **Case Type** (`case_type`, `select_multiple`, required: false): Select all types that apply to the outbreak from the provided list.
- **Case Location** (`case_location`, `text`, required: false): Enter the location where the outbreak occurred.
- **Other Case Location** (`case_location_other`, `text`, required: false): If the location is not among the provided options, enter the location in this text field.
- **Location Description** (`case_location_other_input`, `text`, required: false): Provide additional information about the location.
- **Location Type** (`case_location_type`, `select_one`, required: false): Select the type of location from the provided list.
- **Contact** (`contact`, `text`, required: false): Enter the name or contact information of the person or organization involved in the outbreak.
- **Other Contact** (`other_contact`, `text`, required: false): If the contact is not among the provided options, enter the contact information in this text field.
- **Contact Description** (`other_contact_input`, `text`, required: false): Provide additional information about the contact.
- **Case Reported By** (`case_reported_by`, `text`, required: false): Enter the name or title of the person reporting the outbreak.
- **Date Reported** (`case_reported_date`, `date`, required: false): Enter the date the outbreak was reported.
- **Case Confirmed** (`case_confirmed`, `text`, required: false): Check yes or no if the case has been confirmed.
- **Confirmed Date** (`case_confirmed_date`, `date`, required: false): Enter the date the case was confirmed.
- **Case Closed** (`case_closed`, `text`, required: false): Check yes or no if the case has been closed.
- **Closed Date** (`case_closed_date`, `date`, required: false): Enter the date the case was closed.
- **Case Cause** (`case_cause`, `text`, required: false): Enter the cause of the outbreak.
- **Case Symptoms** (`case_symptoms`, `text`, required: false): Enter the symptoms of the outbreak.
- **Other Symptoms** (`case_symptoms_other`, `text`, required: false): If the symptoms are not among the provided options, enter the symptoms in this text field.
- **Symptoms Description** (`case_symptoms_other_input`, `text`, required: false): Provide additional information about the symptoms.
- **Outbreak Type** (`case_outbreak_type`, `select_multiple`, required: false): Select all types that apply to the outbreak from the provided list.
- **Other Outbreak Type** (`case_outbreak_type_other`, `select_multiple`, required: false): Select yes or no if the outbreak type is not among the provided options.
- **Outbreak Type Description** (`case_outbreak_type_other_input`, `text`, required: false): If the outbreak type is not among the provided options, enter the type in this text field.
