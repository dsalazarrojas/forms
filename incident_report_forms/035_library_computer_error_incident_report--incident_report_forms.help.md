# Library Computer Error Incident Report - Help Guide
## Purpose
This form is designed to report technical issues that have occurred on library computers. Please fill out this form to report new incidents and provide essential details about the issue.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Report Details section.
2. Select the Report Date and Report Time of the incident.
3. Choose the Incident Type from the options provided.
4. Provide a detailed Description of the incident.
5. Enter the Location where the incident occurred.
6. Select the priority level of the incident from Low to Critical.
7. Enter the Contact Name and Contact Email of the person involved.
8. Enter the Contact Phone number of the person involved.
9. Select the current Incident Status from Open, In Progress, Resolved, or Closed.
10. If applicable, select the personnel who should be notified (Assigned To) and enter any Comments about the incident.

## Field-by-Field Explanation

* **Report Details (1)**: A short description of the incident, including any relevant details about the issue.
* **Report Date (2)**: The date the incident occurred.
* **Report Time (3)**: The time the incident occurred.
* **Incident Type (4)**: The type of incident that occurred, such as Hardware, Software, Network, or Power.
* **Description (5)**: A detailed description of what happened.
* **Location (6)**: The exact location where the incident occurred.
* **Priority (7)**: The level of priority for the incident, with Low being less severe and Critical being the most severe.
* **Contact Name (8)**: The name of the person involved in the incident.
* **Contact Email (9)**: The email of the person involved in the incident.
* **Contact Phone (10)**: The phone number of the person involved in the incident.
* **Incident Status (11)**: The current status of the incident, with Open being new, In Progress for ongoing issues, Resolved for issues that have been fixed, and Closed for issues that are no longer active.
* **Assigned To (12)**: A list of personnel that should be notified about this incident.
* **Comments (13)**: Any additional notes or comments about the incident.
