# Mobile Food Vendor Incident Report Form - Help Guide
## Purpose
The Mobile Food Vendor Incident Report Form is a document used to report incidents that occurred at or in relation to a mobile food vendor's location or services.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill in the required information for each field. Required fields are marked with an asterisk (\*).
* Start by filling in the Incident Report page (page 1).
* Enter a brief description of the incident in the Incident Report field.
* On the next page, fill in the vendor's name and vendor's license number if applicable.
* Enter the date and time of the incident in the date and time fields.
* Finally, enter the location where the incident occurred in the incident location field.

## Field-by-Field Explanation
### Incident Report
* Incident Report (Page 1, <type:text>): Enter a brief description of the incident that occurred.
### Vendor Name
* Vendor Name (Page 2, <type:text>): Enter the name of the mobile food vendor involved in the incident.
### Vendor License
* Vendor License (Page 2, <type:text>): Enter the vendor's license number if applicable.
### Incident Date
* Incident Date (Page 2, <type:date>): Enter the date the incident occurred in MM/DD/YYYY format.
### Incident Time
* Incident Time (Page 2, <type:time>): Enter the time of the incident in 24-hour format (HH:MM).
### Incident Location
* Incident Location (Page 2, <type:text>): Enter the location where the incident occurred.

## Tips
* Please be as detailed and accurate as possible when filling out this form.
* If you need help or have questions, contact our support team.
* Make sure to report each incident only once using this form.
