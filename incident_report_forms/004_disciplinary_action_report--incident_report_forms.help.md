# Disciplinary Action Report - Help Guide

## Purpose
The Disciplinary Action Report form is designed to document and report incidents that occurred within the organization. This form is used to record and manage employee incidents, including details of the incident, action taken, and follow-up information. It is essential to provide accurate and comprehensive information about the incident to ensure proper handling and resolution.

## How To Complete This Form
To complete this form, follow these steps:

1.  Ensure you have all the necessary information and documentation about the incident before starting to fill out the form.
2.  Enter the **incident_date** and **incident_time** fields, which are used to record the date and time when the incident occurred.
3.  Enter the employee's name in the **employee** field, as this is the individual involved in the incident.
4.  Provide a detailed description of the incident in the **details** field.
5.  Specify the action taken to address the incident in the **action_taken** field.
6.  Select the person who reported the incident from the **incident_reported_by** field.
7.  Choose the escalation level from the **incident_escalation** field, if applicable.
8.  Enter the resolution of the incident, if known, in the **incident_resolution** field.
9.  Add any follow-up information about the incident in the **incident_follow_up** field, if necessary.
10.  Add any comments about the incident in the **incident_comments** field.
11.  Attach any relevant files or documentation to the **incident_attachments** field, if needed.

## Field-by-Field Explanation
* **Incident Date** (`incident_date`, date, required): Enter the date when the incident occurred in the format mm/dd/yyyy.
* **Incident Time** (`incident_time`, time, required): Enter the time when the incident occurred in the 24-hour format, e.g., 14:30.
* **Employee** (`employee`, text, required): Enter the name of the employee involved in the incident.
* **Details** (`details`, text, required): Provide a detailed description of the incident.
* **Action Taken** (`action_taken`, text, required): Specify the action taken to address the incident.
* **Incident Reported By** (`incident_reported_by`, select_one, optional): Select the person who reported the incident from the provided options.
* **Incident Escalation** (`incident_escalation`, select_multiple, optional): Choose the escalation level from the options provided, if applicable.
* **Incident Resolution** (`incident_resolution`, text, optional): Enter the resolution of the incident, if known.
* **Incident Follow Up** (`incident_follow_up`, note, optional): Add any follow-up information about the incident, if necessary.
* **Incident Comments** (`incident_comments`, note, optional): Add any comments about the incident.
* **Incident Attachments** (`incident_attachments`, note, optional): Attach any relevant files or documentation about the incident.
