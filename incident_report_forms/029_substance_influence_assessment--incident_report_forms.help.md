# Substance Influence Assessment - Help Guide
## Purpose
The Substance Influence Assessment form is used to collect information on incidents involving substances, such as substance abuse or misuse. This form helps to assess the influence of substances on individuals or groups and provides a systematic way to document and track incidents.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date and time of the incident from the calendar or clock.
2. Provide a brief description of the incident, including the context and circumstances.
3. Identify the observer and their role, if applicable.
4. Specify the substance suspected of influencing the incident, including its type and description.
5. Determine the route or method of substance use, if applicable.
6. Specify the frequency and amount of substance use, if applicable.
7. Select the incident type and category, if applicable.
8. Provide any additional details regarding the incident.
9. Specify if follow-up actions are required.
10. Sign and date the form, if required.

## Field-by-Field Explanation
* **Incident Date**: Select the date and time of the incident from the calendar or clock.
* **Incident Time**: Select the time of the incident from the clock.
* **Description**: Provide a brief description of the incident, including the context and circumstances.
* **Observer**: Identify the person who observed the incident, if applicable.
* **Observer Role**: Specify the role of the observer, if applicable.
* **Suspected Substance**: Specify the substance suspected of influencing the incident, including its type and description.
* **Type**: Select the type of substance (Alcohol, Other, Chemical, Medical).
* **Amount**: Specify the amount of substance used, if applicable.
* **Route**: Specify the route or method of substance use, if applicable.
* **Other**: If the route is not among the provided options, specify the other route or method of substance use.
* **Frequency**: Specify the frequency of substance use, if applicable.
* **Other**: If the frequency is not among the provided options, specify the other frequency of substance use.
* **Incident Type**: Select the type of incident, if applicable.
* **Category**: Select the category of incident, if applicable.
* **Details**: Provide any additional details regarding the incident.
* **Action Plan**: Create a plan for follow-up actions, if applicable.
* **Follow up**: Select whether follow-up actions are required.
* **Signature**: Sign and date the form, if required.
