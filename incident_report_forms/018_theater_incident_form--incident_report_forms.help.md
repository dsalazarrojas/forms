# Theater Incident Form - Help Guide
## Purpose
The Theater Incident Form is used to report and document incidents that occurred in a theater setting, helping to identify trends and patterns in incidents.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of report you want to submit (Safety, Satisfaction, or Stage).
2. Enter the date on which the incident occurred.
3. Enter the time on which the incident occurred.
4. Enter the location where the incident occurred.
5. Provide detailed information about the incident.
6. Set the status of your report to either Pending, Reviewing, or Approved.
7. If applicable, enter the name of the reviewer.
8. Provide any additional notes about the incident.
9. Enter the image (if available).
10. If applicable, enter the assignee's name.
11. Enter the category, sub-category, and description of the incident.
12. Enter the incident date and time.
13. Enter the type of incident.
14. Enter the theater, seat, row, and seat number details.
15. Enter the seat type and row details.
16. Finally, click the "Submit" button to complete and save your report.

## Field-by-Field Explanation
* **Report Type** (`report_type`, select_one, required): Select the type of report you want to submit. This will help categorize and analyze the incident.
* **Date** (`date`, date, required): Enter the date on which the incident occurred.
* **Time** (`time`, time, required): Enter the time on which the incident occurred.
* **Location** (`location`, text, required): Enter the location where the incident occurred.
* **Details** (`details`, text, required): Provide detailed information about the incident.
* **Cause** (`cause`, text, required): Enter the cause of the incident.
* **Report Status** (`report_status`, select_one, required): Set the status of your report to either Pending, Reviewing, or Approved.
* **Reviewer** (`reviewer_name`, text, required): Enter the name of the reviewer (if applicable).
* **Notes** (`notes`, text, required): Provide any additional notes about the incident.
* **Incident Image** (`incident_image`, text, required): Enter the image of the incident (if available).
* **Assignee** (`assignee`, text, required): Enter the name of the assignee (if applicable).
* **Category** (`category`, text, required): Enter the category of the incident.
* **Sub Category** (`sub_category`, text, required): Enter the sub-category of the incident.
* **Description** (`description`, text, required): Provide a description of the incident.
* **Incident Date** (`incident_date`, date, required): Enter the date on which the incident occurred.
* **Incident Time** (`incident_time`, time, required): Enter the time on which the incident occurred.
* **Incident Type** (`incident_type`, text, required): Enter the type of incident.
* **Theater** (`theater`, text, required): Enter the theater where the incident occurred.
* **Seat** (`seat`, text, required): Enter the seat details.
* **Row** (`row`, text, required): Enter the row details.
* **Section** (`section`, text, required): Enter the section details.
* **Seat Number** (`seat_number`, text, required): Enter the seat number details.
* **Seat Type** (`seat_type`, text, required): Enter the seat type details.
* **Seat Row** (`seat_row`, text, required): Enter the seat row details.

Please note that the fields marked as "required" must be filled in for the form to be complete.
