# Wall Cracking Incident Form - Help Guide
## Purpose
This form is used to report wall cracking incidents. It helps gather information about the incident, such as the type of wall, height, crack type, location, and other relevant details. The form is essential for documenting and tracking wall cracking incidents in our system.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the relevant fields with the required information. Make sure to select the correct options for each field.
2. Review your submission before submitting the form to ensure accuracy.
3. Submit the form when you have completed all the required fields.

## Field-by-Field Explanation
- **Wall Cracking Incident Form** (`wall_cracking_incident_form`, text, optional): Enter a brief description of the incident.
- **Wall Type** (`wall_type`, select_one, optional): Select the type of wall that cracked (e.g., concrete, brick, etc.).
- **Wall Height** (`wall_height`, number, optional): Enter the height of the wall where the crack occurred.
- **Wall Crack Type** (`wall_crack_type`, select_multiple, optional): Select all types of cracks that occurred on the wall (e.g., hairline crack, horizontal crack, etc.).
- **Crack Location** (`crack_location`, select_one, optional): Specify the location of the crack on the wall (e.g., top, middle, bottom, etc.).
- **Wall Surface** (`wall_surface`, text, optional): Describe the surface of the wall where the crack occurred (e.g., painted, rough, etc.).
- **Crack Date** (`crack_date`, date, optional): Enter the date the crack occurred.
- **Crack Time** (`crack_time`, time, optional): Enter the time the crack occurred.
- **Crack Description** (`crack_description`, note, optional): Provide a detailed description of the crack.
- **Property Owner** (`property_owner`, select_one, optional): Select the property owner's name (if known).
- **Contact Name** (`contact_name`, text, optional): Enter the name of the contact person or organization (if known).
- **Contact Email** (`contact_email`, email, optional): Enter the email address of the contact person or organization (if known).
- **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the contact person or organization (if known).
- **Report Date** (`report_date`, date, optional): Enter the date you are reporting the incident.
- **Submitted by** (`submitted_by`, select_one, optional): Select the name of the person submitting the form (if known).
- **Notes** (`notes`, note, optional): Add any additional notes about the incident.

Tips:

* Make sure to fill in all the required fields before submitting the form.
* Use clear and concise language when describing the incident.
* If you are unsure about any field, you can leave it blank or ask for help.
* Please review your submission before submitting the form to ensure accuracy.
