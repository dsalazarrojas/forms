# Paramedic Call Log Submission - Help Guide
## Purpose
This form is used to document paramedic calls, including incident date, unit number, patient information, and call outcome. It ensures that relevant information is recorded accurately and thoroughly.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date of the incident.
2. Enter the unit number.
3. Enter the patient's name.
4. Select the type of call (Cardiac, Medical, or Trauma).
5. Enter any additional information about the patient's age.
6. Select the patient's gender.
7. Enter the patient's weight.
8. Enter the patient's height.
9. Add any vital signs information in the notes field.
10. Enter the patient's condition.
11. Check if any medication was administered.
12. Add any medical history information in the notes field.
13. Enter the incident location.
14. Enter the unit's location.
15. Select the call outcome.
16. Add any outcome comments.
17. Enter the paramedic's name.
18. Enter the paramedic's number.
19. Enter the supervisor's name.
20. Enter the supervisor's number.
21. Enter the unit number (alternative).
22. Enter the unit ID (alternative).

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, date, required): Enter the date of the incident.
* **Unit Number** (`unit_number`, text, required): Enter the unit number.
* **Patient Name** (`patient_name`, text, required): Enter the patient's name.
* **Call Type** (`call_type`, select_one, required): Select the type of call (Cardiac, Medical, or Trauma).
* **Unit ID** (`unit_id`, text, required): Enter the unit ID.
* **Call Status** (`call_status`, select_multiple, required): Select the current call status (Active, Completed, or Held).
* **Patient Age** (`patient_age`, number, required): Enter the patient's age.
* **Patient Gender** (`patient_gender`, select_one, required): Select the patient's gender.
* **Patient Weight** (`patient_weight`, number, required): Enter the patient's weight.
* **Patient Height** (`patient_height`, number, required): Enter the patient's height.
* **Vital Signs** (`vital_signs`, note, required): Add any vital signs information in the notes field.
* **Patient Condition** (`patient_condition`, text, required): Enter the patient's condition.
* **Medication Administered** (`medication_administered`, select_multiple, required): Check if any medication was administered.
* **Medical History** (`medical_history`, note, required): Add any medical history information in the notes field.
* **Incident Location** (`incident_location`, text, required): Enter the incident location.
* **Unit Location** (`unit_location`, text, required): Enter the unit's location.
* **Call Outcome** (`call_outcome`, select_one, required): Select the call outcome.
* **Outcome Comments** (`outcome_comments`, text, required): Add any outcome comments.
* **Paramedic Name** (`paramedic_name`, text, required): Enter the paramedic's name.
* **Paramedic Number** (`paramedic_number`, text, required): Enter the paramedic's number.
* **Supervisor Name** (`supervisor_name`, text, required): Enter the supervisor's name.
* **Supervisor Number** (`supervisor_number`, text, required): Enter the supervisor's number.
* **Unit Number (Alternative)** (`unit_number_alt`, text, required): Enter the unit number (alternative).
* **Unit ID (Alternative)** (`unit_id_alt`, text, required): Enter the unit ID (alternative).
