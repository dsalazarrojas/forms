# Basketball Incident Form - Help Guide
## Purpose
The Basketball Incident Form is a tool used by the athletic department to report and document incidents that have occurred during a basketball game or practice. This form is used to gather information about the incident, including the date and time it occurred, the location, and the details of what happened. The information collected will be used to make informed decisions about how to handle the incident and ensure the safety and well-being of all individuals involved.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the date and time of the incident in the "Incident date" and "Incident time" fields.
2. Enter the location where the incident occurred in the "Location of incident" field.
3. Choose the type of incident that occurred from the "Type of incident" dropdown menu.
4. Select the severity level of the incident from the "Severity level" dropdown menu.
5. Enter the name of the person involved in the "Name of person involved" field.
6. If applicable, enter the player number for the person involved.
7. If applicable, enter the team name and the number of witnesses present.
8. Provide a detailed description of what happened in the "Detailed description of incident" field.
9. If necessary, indicate if medical attention was required and describe the medical response taken.
10. If applicable, indicate if the person was transported to the hospital and provide additional details.
11. If necessary, describe any action taken or recommended.
12. If applicable, describe any coaching decision or disciplinary action taken.
13. Enter the name of the person reporting the incident in the "Person reporting incident" field.
14. Select the role of the person reporting the incident from the "Reporter role" dropdown menu.
15. Confirm that the report is accurate by selecting "I Confirm".

## Field-by-Field Explanation
* **Incident date**: The date of the incident. This should be entered in the format MM/DD/YYYY.
* **Incident time**: The time of the incident. This should be entered in the 24-hour clock format (e.g., 12:00 or 14:30).
* **Location of incident**: The location where the incident occurred (e.g., court, hallway, etc.).
* **Type of incident**: The type of incident that occurred (e.g., injury, misconduct, equipment damage, etc.). Select from the options: Injury, Misconduct, Equipment Damage, Safety Violation, Other.
* **Severity level**: The severity level of the incident, which is critical in determining how to handle the situation. Select from the options: Minor, Moderate, Severe.
* **Name of person involved**: The name of the person involved in the incident.
* **Player number (if applicable)**: If the person involved is a basketball player, enter their player number.
* **Team name (if applicable)**: If the incident occurred during a team practice or game, enter the team name.
* **Witnesses present**: If there were any witnesses to the incident, enter their names.
* **Detailed description of incident**: A detailed description of what happened during the incident. This should include as much information as possible, including the context of the incident and any contributing factors.
* **Contributing factors**: If there were any contributing factors to the incident, describe them here.
* **Medical attention required?**: If medical attention was required after the incident, select "True". If not, select "False".
* **Medical response taken**: If medical attention was required, describe the medical response taken.
* **Transported to hospital?**: If the person was transported to the hospital, select "True". If not, select "False".
* **Action taken or recommended**: If any action was taken or recommended as a result of the incident, describe it here.
* **Coaching decision or disciplinary action**: If any coaching decision or disciplinary action was taken as a result of the incident, describe it here.
* **Person reporting incident**: The name of the person reporting the incident.
* **Reporter role**: The role of the person reporting the incident. Select from the options: Coach, Player, Official, Athletic Trainer, Parent, Spectator, Other.
* **I confirm this report is accurate**: Select "I Confirm" to confirm that the report is accurate. If you need to review the report before confirming, select "I Need to Review".
