# Model Release Form - Help Guide

## Purpose
The Model Release Form is a document designed to capture the model's consent and permission to use their photograph or image. It is used to protect the model's rights and ensure they are aware of how their image will be used.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the model's First Name and Last Name in the first and second fields, respectively.
2. Enter the model's Email address in the third field.
3. Enter the model's Phone number in the fourth field.
4. Select the correct answer for "Release Permission" in the fifth field, which indicates whether the model grants permission for their image to be used.
5. If a date is applicable, fill in the Date Taken and Date Used fields, as per your specific situation.
6. Fill in the Photo Location and Other Image Location fields, as required.
7. If necessary, fill in the Other Image Description and Other Image Model Description fields.
8. Select the correct answer for the Other Image Model Release Permission and Other Image Model Other Image Model Release fields, as applicable.
