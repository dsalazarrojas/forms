# Media Release Form - Help Guide
## Purpose
The Media Release Form is a document that confirms the individual's or organization's consent to the use of their name, image, or likeness in public relations, marketing, or other purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields: **Name**, **Email**, **Date of Event**, and **Release Date**. These fields are marked as "required" and must be filled in to submit the form.
2. If applicable, fill in the optional fields: **Phone**, **Location**, **Release Time**, and **Contact Person**.
3. Select the type of media that you are releasing: **Media Type** (Image, Video, Audio, or Other).
4. Provide a brief description of the event or project, if necessary.
5. Review the form carefully before submitting to ensure all required fields are filled in.

## Field-by-Field Explanation

* **Name**: Enter the individual's or organization's name as it should appear on the media release.
* **Email**: Enter the individual's or organization's email address.
* **Phone**: Enter the individual's or organization's phone number (optional).
* **Date of Event**: Enter the date of the event or project for which the media release is required.
* **Location**: Enter the location of the event or project (optional).
* **Release Date**: Enter the date when the media release will be valid.
* **Release Time**: Enter the time when the media release will be valid (optional).
* **Contact Person**: Enter the name and contact information of the person responsible for the event or project (optional).
* **Media Type**: Select the type of media that you are releasing (Image, Video, Audio, or Other).
* **Description**: Enter a brief description of the event or project, if necessary.

## Tips

* Make sure to include the correct contact information for the individual or organization.
* Ensure that the media release is valid for the correct date and time.
* If you are unsure about any part of the form, please contact the relevant authority for clarification.
