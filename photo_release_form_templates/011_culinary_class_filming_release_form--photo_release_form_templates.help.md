# Culinary Class Filming Release Form - Help Guide

## Purpose
The "Culinary Class Filming Release Form" is used to document the filming of a culinary class in order to obtain releases and permissions from participants, chefs, and event organizers. This form is used to inform and obtain consent from those involved in the filming process, ensuring that their rights and interests are respected. The form is usually filled out by participants, instructors, and event organizers in advance of filming.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each section carefully and answer all required fields.
2. Enter your name and contact information to ensure we can contact you if needed.
3. Check the "Photo Release" box to indicate that you give your permission for your photo/video/live stream to be filmed and shared.
4. Select the type(s) of filming you are consenting to, such as Class Photographs, Class Videos, or Class Live Streams.
5. Sign and date your name in the "Participant Signature" or "Instructor Signature" field as applicable.
6. Return the completed form to us prior to filming.

## Field-by-Field Explanation

* **Participant Information** (`participant_information`, `text`, required: false):
	+ A brief description of the participant or event being filmed.
* **Participant Name** (`participant_name`, `text`, required: false):
	+ The name of the participant who is being filmed.
* **Participant Email** (`participant_email`, `email`, required: false):
	+ The email address of the participant or person being filmed.
* **Participant Phone** (`participant_phone`, `text`, required: false):
	+ The phone number of the participant or person being filmed.
* **Filming Information** (`filming_information`, `text`, required: false):
	+ A description of the filming details, such as date, time, and location.
* **Filming Location** (`filming_location`, `text`, required: false):
	+ The location where the filming will take place.
* **Culinary Class Name** (`culinary_class_name`, `text`, required: false):
	+ The name of the culinary class being filmed.
* **Photo Release** (`photo_release`, `select_one`, required: false):
	+ Check "Yes" to indicate that you give permission for your photo to be filmed and shared.
* **Filming Consent** (`filming_consent`, `select_multiple`, required: false):
	+ Select the type(s) of filming you are consenting to, such as Class Photographs, Class Videos, or Class Live Streams.
* **Participant Signature** (`participant_signature`, `note`, required: false):
	+ Sign and date your name to indicate your consent.
* **Instructor Name** (`instructor_name`, `text`, required: false):
	+ The name of the instructor or person leading the culinary class.
* **Instructor Phone** (`instructor_phone`, `text`, required: false):
	+ The phone number of the instructor or person leading the culinary class.
* **Chef Name** (`chef_name`, `text`, required: false):
	+ The name of the chef or person responsible for the culinary class.
* **Culinary Event Organizer** (`culinary_event_organizer`, `text`, required: false):
	+ The name of the person or organization responsible for organizing the culinary event.
* **Culinary Event Manager** (`culinary_event_manager`, `text`, required: false):
	+ The name of the person or organization responsible for managing the culinary event.
* **Contact Information** (`contact_information`, `text`, required: false):
	+ Additional contact information for the participant or person being filmed.
* **Event Dates** (`event_dates`, `date`, required: false):
	+ The dates of the culinary event or class.
* **Event Time** (`event_time`, `time`, required: false):
	+ The start and end time of the culinary event or class.
* **Class Start Date** (`class_start_date`, `date`, required: false):
	+ The start date of the culinary class.
* **Class End Date** (`class_end_date`, `date`, required: false):
	+ The end date of the culinary class.
* **Filming Duration** (`filming_duration`, `text`, required: false):
	+ The duration of the filming.
* **Filming Location 2** (`filming_location_2`, `text`, required: false):
	+ Additional filming location information.
* **Participant Signature 2** (`participant_signature_2`, `note`, required: false):
	+ Another signature from the participant or person being filmed.
* **Instructor Signature** (`instructor_signature`, `note`, required: false):
	+ Another signature from the instructor or person leading the culinary class.
* **Culinary Class Organizer** (`culinary_class_organizer`, `text`, required: false):
	+ The name of the person or organization responsible for organizing the culinary class.
