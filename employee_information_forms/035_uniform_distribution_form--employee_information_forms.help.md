# Uniform Distribution Form - Help Guide
## Purpose
The Uniform Distribution Form is used to track the distribution of uniforms to employees within an organization.

## How To Complete This Form

1. Please fill out the form accurately and thoroughly.
2. Enter the first and last name of the employee receiving the uniform.
3. Select the department where the employee works.
4. Enter the quantity of uniforms distributed.
5. Choose the size of the uniform(s) distributed.
6. Select the color of the uniform(s) distributed.
7. Enter the date the uniform was distributed (mm/dd/yyyy).
8. Choose the type of distribution (in-store pickup, mail-out, or both).
9. Select the status of the uniform distribution (pending, delivered, or replied).
10. Enter the staff name and ID number.
11. Select the department where the staff member works (Finance, Operations, or HR).
12. Repeat the steps for the second employee if necessary.

## Field-by-Field Explanation

* **First and Last Name (user_name)**: Enter the employee's first and last name (e.g., John Smith).
* **Distribution Date (date)**: Enter the date the uniform was distributed in the format mm/dd/yyyy.
* **Staff ID (staff_id)**: Enter the staff ID number.
* **Department (department)**: Select the department where the employee works (ID, Finance, Operations, or HR).
* **Quantity (quantity)**: Enter the number of uniforms distributed.
* **Size (size)**: Select the size of the uniform distributed (Small, Medium, Large).
* **Color (color)**: Enter the color of the uniform distributed.
* **Notes (notes)**: This field is available for any additional comments.
* **Email (email)**: Enter the employee's email address.
* **Phone (phone)**: Enter the employee's phone number.
* **Date In (date_in)**: Enter the date the uniform was distributed in the format mm/dd/yyyy.
* **Distribution Type (distribution_type)**: Select the type of distribution (in-store pickup, mail-out, or both).
* **Status (status)**: Select the status of the uniform distribution (pending, delivered, or replied).
* **Staff Name (staff_name)**: Enter the staff member's name.
* **Employee Name (employee_name)**: Enter the name of the employee receiving the uniform.
* **Staff ID Number (staff_id_number)**: Enter the staff ID number.
* **Distribution Date In (distribution_date_in)**: Enter the date the uniform was distributed in the format mm/dd/yyyy.
* **Staff ID Type (staff_id_type)**: Select the type of staff ID (Staff ID, ID Card, or Badge Number).
* **Employee Name 2 (employee_name_2)**: Enter the name of the second employee receiving the uniform.
* **Employee ID Number (employee_id_number)**: Enter the ID number of the second employee.
* **Department 2 (department_2)**: Select the department where the second employee works (ID, Finance, Operations, or HR).
* **Departmental (departmental)**: Select the department where the second employee works (Finance, Operations, or HR).
* **Distribution Type 2 (distribution_type_2)**: Select the type of distribution for the second employee (in-store pickup, mail-out, or both).
* **Status 2 (status_2)**: Select the status of the uniform distribution for the second employee (pending, delivered, or replied).
