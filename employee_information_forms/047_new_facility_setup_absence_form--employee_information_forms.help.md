# new_facility_setup_absence_form - Help Guide
## Purpose
The new_facility_setup_absence_form is used to collect information from employees and facility managers for setting up absences for a new facility.

## How To Complete This Form

To complete this form, follow the steps below:
1. Fill out each page carefully and accurately.
2. Ensure that all required fields are completed.
3. Review each page for completeness before proceeding to the next page.

## Field-by-Field Explanation

* **employee_absence_form_details** (`employee_absence_form_details`, text, optional): This page is used to capture the general information about the employee's absence.
* **employee_absence_form_details_2** (`employee_absence_form_details_2`, text, optional): This page is used to capture additional comments from the employee.
* **facility_setup_details** (`facility_setup_details`, text, optional): This page is used to capture details about the facility where the employee will be absent.
* **absence_duration** (`absence_duration`, date, optional): This field is used to specify the duration of the absence.
* **facility_manager_approval** (`facility_manager_approval`, select one, optional): This field is used to obtain approval from the facility manager for the absence.
* **facility_location** (`facility_location`, select one, optional): This field is used to determine if the facility is located within a certain area.
* **manager_name** (`manager_name`, text, optional): This field is used to capture the name of the manager approving the absence.
* **manager_contact** (`manager_contact`, text, optional): This field is used to capture the contact information of the manager approving the absence.
* **notes** (`notes`, note, optional): This field is used to capture additional comments or notes from the employee.
* **notes_2** (`notes_2`, note, optional): This field is used to capture additional comments or notes from the employee.
