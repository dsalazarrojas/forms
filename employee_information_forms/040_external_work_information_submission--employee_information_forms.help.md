# External Work Information Submission - Help Guide
## Purpose
The External Work Information Submission form is used to collect external work information from employees for projects or tasks performed outside of the company. This form provides a structured way to gather relevant details about the external work.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the company name where the external work was performed.
2. Provide the job title of the external work.
3. Enter the location of the external work.
4. Select the start and end dates of the external work.
5. Enter any additional details about the external work.
6. Specify whether the external work required manager and client approvals.
7. Select the department responsible for the external work.
8. Choose the category of the external work.
9. Enter any relevant tags related to the external work.
10. Add any additional notes about the external work.
11. Enter the employee's contact email for external communication.
12. Enter the phone number associated with the external work.

## Field-by-Field Explanation
* **Company**: Enter the name of the company where the external work was performed.
* **Job Title**: Enter the title of the job or task performed for the external work.
* **Location**: Enter the location where the external work was performed.
* **Start Date**: Enter the start date of the external work.
* **End Date**: Enter the end date of the external work.
* **Work Details**: Enter any additional details about the external work.
* **External Work**: Enter any external work specifics.
* **Manager Approval**: Check whether manager approval is required for the external work. You can select multiple options.
* **Client Approval**: Check whether client approval is required for the external work. You can select multiple options.
* **Department**: Select the department responsible for the external work from the given options.
* **Category**: Select the category of the external work from the given options.
* **Tags**: Enter any relevant tags related to the external work.
* **Notes**: Add any additional notes about the external work.
* **Email**: Enter the employee's contact email for external communication.
* **Phone**: Enter the phone number associated with the external work.
