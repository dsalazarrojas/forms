# new_team_member_goals_form - Help Guide
## Purpose
The new_team_member_goals_form is designed to gather information about new team members, helping team leads and managers track their progress and performance.
## How To Complete This Form
To complete this form, follow these steps:
1. Enter the team member's name in the "team_member_name" field.
2. Write down the team member's goals in the "goals" field.
3. Specify the start and end dates for the goals in the "start_date" and "end_date" fields.
4. Set the review frequency in the "review_frequency" field.
5. Enter the review date in the "review_date" field.
6. Optionally, enter the manager's name in the "manager_name" field.
7. Enter the team name in the "team_name" field, if applicable.
8. Optionally, enter the project name in the "project_name" field.
9. Enter any goal achievements, descriptions, and targets in the "goal_achievements", "goal_description", and "goal_target" fields, as needed.
10. Set the goal status in the "goal_status" field.
11. Enter any comments about the goal in the "goal_comments" field.
12. Enter the team lead's name in the "team_lead_name" field, if applicable.
13. Enter the team member's status in the "team_member_status" field, if applicable.
14. Enter the manager's comments about the team member in the "manager_comments" field, if applicable.
15. Select the goals for the team member in the "goals_1", "goals_2", and "goals_3" fields.
16. Set the review status in the "review_status" field.
17. Enter any comments for the manager's review in the "manager_review" field.
18. Enter any comments for the team lead's review in the "team_lead_review" field.
19. Select the review status in the "review_status" field.

## Field-by-Field Explanation

* **team_member_name**: Enter the team member's name.
* **goals**: Write a brief description of the team member's goals.
* **start_date**: Specify the start date for the goals.
* **end_date**: Specify the end date for the goals.
* **review_frequency**: Choose how often the team member's progress will be reviewed (First, Second, Third, or Fourth).
* **review_date**: Enter the review date for the team member's progress.
* **manager_name**: Enter the manager's name, if applicable.
* **team_name**: Enter the team name, if applicable.
* **project_name**: Enter the project name, if applicable.
* **goal_achievements**: Enter any achievements or accomplishments related to the goal.
* **goal_description**: Enter a detailed description of the goal.
* **goal_target**: Enter the target or objective for the goal.
* **goal_status**: Select the status of the goal (On Track, Off Track, or Completed).
* **goal_comments**: Enter any comments about the goal.
* **team_lead_name**: Enter the team lead's name, if applicable.
* **team_member_status**: Enter the team member's status, if applicable.
* **manager_comments**: Enter the manager's comments, if applicable.
* **goals_1**: Select the first set of goals for the team member.
* **goals_2**: Select the second set of goals for the team member.
* **goals_3**: Select the third set of goals for the team member, if applicable.
* **review_status**: Set the review status for the team member (On Track, Off Track, or Completed).
* **manager_review**: Enter the manager's review comments, if applicable.
* **team_lead_review**: Enter the team lead's review comments, if applicable.
* **team_lead_name**: Enter the team lead's name, if applicable.
