# Counseling Session Time Off Form - Help Guide

## Purpose
This form is used to document an employee's time off for a counseling session. It captures relevant information such as employee details, session dates and times, and reasons for visit. This form also allows for input of notes and email and phone numbers. The goal of this form is to track and record accurate information about employee's counseling sessions.


## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have an active internet connection.
2. Select the correct options for the required and optional fields based on the information available.
3. Fill out all the required fields marked as **Required**. If a field is not required, you can skip it.
4. Ensure that you fill out each field correctly, according to its type. For instance, the `Session Date` field requires a date format.
5. If any field is not understood, refer back to this help guide for clarification.

## Field-by-Field Explanation

* **Employee Id**: Enter your employee ID number. This number is a unique identifier for the employee.
* **Session Date**: Enter the date of the counseling session. Use a date format.
* **End Date**: Enter the end date of the counseling session. Use a date format.
* **Session Time**: Enter the time of the session.
* **Reason For Visit**: Enter a short description of the reason for the visit.
* **Requested Duration**: Enter the duration of the session.
* **Approved Duration**: Enter the duration of the session approved by the management.
* **Counselor**: Select 'Yes' or 'No' whether the session is with a counselor.
* **Notes**: Enter any additional notes about the session.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Category**: Select the category of the session from the options (Counselor, Medical, Wellness, Personal, Others).
* **Status**: Select the status of the session from the options (Active, Inactive).
* **Assigned Tool**: Select the tool used for the session from the options (chatjimmy, Other).
* **Submitted By**: Select who submitted the session, either 'user' or 'Other'.
* **Assigned To**: Select whether the session is assigned to someone or not.

Note: This form is designed to be completed by employees and management to accurately track and record information about counseling sessions. The fields are self-explanatory, but if you are unsure, please refer back to this help guide for clarification.
