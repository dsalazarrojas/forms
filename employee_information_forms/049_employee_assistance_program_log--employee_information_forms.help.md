# Employee Assistance Program Log - Help Guide

## Purpose
The "Employee Assistance Program Log" is a form used to record and track employee sessions with program providers, such as counselors or coaches, to support employee well-being and productivity.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Employee ID** to associate the session with the specific employee.
2. Provide the **Employee Name**, ensuring it matches the employee's official name.
3. Select the **Employee Department** where the session occurred.
4. Enter the **Session Start Date**, the date the session began.
5. Enter the **Session End Date**, the date the session ended.
6. Describe the **Session Topic**, the main theme or subject of the session.
7. Add any relevant **Session Notes**, providing a summary or details about the session.

## Field-by-Field Explanation

* **Employee ID (1)**: A unique identifier for the employee, used to associate the session with the correct employee record.
* **Employee name (2)**: The employee's official name, used to identify and verify the employee's identity.
* **Employee department (3)**: The department or team where the session occurred, to provide context about the work environment.
* **Session Start Date (4)**: The date the session began, in the standard date format (MM/DD/YYYY).
* **Session End Date (5)**: The date the session ended, in the standard date format (MM/DD/YYYY).
* **Session Topic (6)**: A brief description of the main theme or subject of the session, to help with categorization and future reference.
* **Session Notes (7)**: A free-text field to capture any additional information about the session, such as takeaways, action items, or next steps.

## Tips

* Ensure that all required fields are filled in accurately and completely.
* Double-check dates and names for correctness and consistency.
* Use the "Session Topic" field to help with data analysis and reporting.
* Keep "Session Notes" concise and focused on the essential details of the session.
* If you have any questions or need assistance, contact the HR department for support.
