# Coaching Log Template - Help Guide

## Purpose
This Coaching Log Template is a document used to record and track coaching sessions with clients. It helps coaches to provide high-quality coaching services by ensuring that all necessary information is captured and documented after each session. The template ensures that coaches and clients have a clear and structured format to record session details, goals, and outcomes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked as "Required" in the form.
2. Leave the non-required fields blank or fill them in as needed.
3. Use the available space in the "Session Notes" and "Client Action Items" sections to record any additional information or details that need to be captured.

## Field-by-Field Explanation

### 1. Coach Name (`Coach Name`, text, Required)
Your name as the coach providing the coaching services to the client.

### 2. Coach ID Number (`Coach ID Number`, text, Optional)
Your identification number or code as a coach, if applicable.

### 3. Session Date (`Session Date`, date, Required)
The date of the coaching session.

### 4. Session Start Time (`Session Start Time`, time, Required)
The start time of the coaching session.

### 5. Session End Time (`Session End Time`, time, Required)
The end time of the coaching session.

### 6. Session Duration (minutes) (`Session Duration (minutes)`, number, Optional)
The total length of the session in minutes.

### 7. Client Name (`Client Name`, text, Required)
The name of the person being coached.

### 8. Primary Topic or Focus Area (`Primary Topic or Focus Area`, text, Required)
The main subject or focus area of the session.

### 9. Coaching Areas Covered (`Coaching Areas Covered`, select_multiple, Required)
Select all the areas you covered during the session, such as Goal setting, Performance improvement, etc.

### 10. Session Summary (`Session Summary`, text, Required)
A brief summary of the session, including key points discussed and outcomes.

### 11. Client Progress and Achievements (`Client Progress and Achievements`, text, Optional)
Any progress or achievements reported by the client.

### 12. Challenges or Obstacles Discussed (`Challenges or Obstacles Discussed`, text, Optional)
Any challenges or obstacles discussed during the session.

### 13. Client Action Items (`Client Action Items`, text, Required)
What the client plans to work on as a result of the coaching session.

### 14. Coach Action Items (`Coach Action Items`, text, Optional)
Any action items or tasks you as the coach plan to work on as a result of the session.

### 15. Scheduled Follow-up Date (`Scheduled Follow-up Date`, date, Optional)
The date and time for the next coaching session.

### 16. Session Effectiveness Rating (`Session Effectiveness Rating`, select_one, Required)
How effective was the session? Highly effective, Effective, Somewhat effective, or Not effective.

### 17. Client Engagement Level (`Client Engagement Level`, select_one, Required)
How engaged was the client? Highly engaged, Engaged, Somewhat engaged, or Not engaged.
