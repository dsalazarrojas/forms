# Task Entry Form - Help Guide
## Purpose
The Task Entry Form is a simple form used to create new task entries with details such as title, description, objectives, deadline, and other related attributes. This form is essential for maintaining accurate task records and helping team members stay organized.

## How To Complete This Form
To complete this form effectively:

1. Start by entering the **Task Name** in the "task_name" field. This should be a brief but descriptive title for the task.
2. In the "task_description" field, provide a detailed description of the task, outlining its main objectives and requirements.
3. For "task_objective", type the specific goals and outcomes you aim to achieve with the task.
4. If applicable, set the "task_goal" to indicate any relevant goals or milestones related to the task.
5. Choose the current status of the task from "task_status" - Active or Inactive.
6. If a deadline is relevant for the task, select the date from "task_due_date".
7. Optionally, mark if the task has been completed on the specified "task_completed_date".
8. Enter the name of the task creator in the "task_creator" field.
9. If assigned to someone, enter the name of the task assignee in the "task_assigned_to" field.
10. For "task_priority", choose whether the task is a priority task ("Yes") or not ("No").

## Field-by-Field Explanation

* **Task Name (task_name)**: A brief title for the task, summarizing its purpose.
* **Task Description (task_description)**: A detailed explanation of the task's objectives and requirements.
* **Task Objective (task_objective)**: The specific goals or outcomes you aim to achieve with the task.
* **Task Goal (task_goal)**: Additional goal or milestone information related to the task, if needed.
* **Task Status (task_status)**: Choose the status of the task (Active or Inactive).
* **Task Due Date (task_due_date)**: Select the date by which the task should be completed.
* **Task Completed Date (task_completed_date)**: If the task has been completed, mark the date it was finished.
* **Task Creator (task_creator)**: Enter the name of the person creating the task.
* **Task Assigned To (task_assigned_to)**: If assigned, enter the name of the person responsible for the task.
* **Task Priority (task_priority)**: Indicate whether the task is a priority task or not.
