# Employee Earnings Overview - Help Guide
## Purpose
This form is used to provide an overview of employee earnings, categorize them, and select relevant information for output. It's intended for administrative or HR purposes.

## How To Complete This Form
1. Select the category for the employee earnings (e.g., "Employee Information Forms").
2. Provide a brief description of the earnings.
3. Choose the assigned tool for this earnings category (e.g., "chatjimmy").
4. Select the output file format for this earnings category (e.g., "027 employee earnings overview--employee information forms").
5. Optionally, enter a form ID number.

## Field-by-Field Explanation

* **category**: Choose the category for this earnings category (e.g., "Employee Information Forms").
* **description**: Enter a brief description of the earnings (e.g., "This form is used for employee earnings overview").
* **assigned_tool**: Select the tool assigned to this category (e.g., "chatjimmy").
* **output_file**: Select the output file format for this category (e.g., "027 employee earnings overview--employee information forms").
* **form_id**: This field is optional and appears to be for tracking purposes. Enter a number if required.
