# independent_contractor_information_form - Help Guide
## Purpose
The purpose of this form is to collect and store information about independent contractors who work with the organization on various projects. This form helps ensure that all relevant details about each contractor are accurately and efficiently recorded and communicated within the organization.
## How To Complete This Form

To complete this form, follow these steps:

- Start by filling out the **Contract Info** page, which includes details such as contract start and end dates.
- Then move on to the **Contact Info** page, where you will provide your contact information including phone and email. 
- On the **Payment Terms** page, select your preferred payment method, frequency, and terms (e.g., weekly, bi-weekly, bi-monthly, etc.).
- Fill out the **Tax ID** section with your social security number or EIN.
- In the **Contract Notes** section, add any relevant details about the contract.
- On the **Address** page, enter your address including city and state.
- Finally, review and submit the form to save your information.

## Field-by-Field Explanation

* **Contract Info**: This section collects details about the contract start and end dates.
* **Contractor Name**: This is a text field for the contractor's name.
* **Contractor Address**: This is a text field for the contractor's address.
* **Contractor City**: This is a text field for the contractor's city.
* **Contractor State**: This is a text field for the contractor’s state.
* **Contractor Zip**: This is a number field for the contractor's zip code.
* **Contractor Phone**: This is a select_one field for the contractor's phone number.
* **Contractor Email**: This is a text field for the contractor's email.
* **Contract Start Date**: This is a date field for the contract start date.
* **Contract End Date**: This is a date field for the contract end date.
* **Contract Duration**: This is a number field for the contract duration.
* **Payment Terms**: This is a select_one field for payment terms (e.g., weekly, bi-weekly, etc.).
* **Payment Method**: This is a select_one field for the payment method (e.g., check, direct deposit, etc.).
* **Payment Terms Amount**: This is a number field for the payment terms amount.
* **Payment Terms Note**: This is a text field for any additional payment terms notes.
* **Tax ID Type**: This is a select_one field for tax ID type (e.g., social security, EIN, etc.).
* **Tax ID Number**: This is a number field for tax ID number.
* **Contract Notes**: This is a text field for any additional contract notes.
* **Contractor Notes**: This is a text field for any additional contractor notes.

## Tips

- Please ensure that all fields are filled out accurately to avoid any errors or issues.
- You can update your information at any time by revisiting this form.
- If you have any questions or concerns, please reach out to the organization's contact person.
