# s_r_c_s_s_administration_application - Help Guide
## Purpose
This form is designed to collect employee information for administration purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have access to the form.
2. Click on the form link to access it.
3. Fill out the fields as instructed below.

## Field-by-Field Explanation

* **User Name**: This is a text field where you can enter the employee's name. 
* **Email**: Enter the employee's email address. (Required)
* **Phone**: This is a text field for the employee's phone number. (Not Required)
* **Date of Birth**: Enter the employee's date of birth in the standard date format (YYYY-MM-DD). (Required)
* **Time of Hiring**: Enter the time of hiring in 24-hour format (HH:MM). (Not Required)
* **Notes**: This is a text area where you can add any additional notes about the employee. (Not Required)
* **Category**: Select the category for the employee from the provided options. (Required)
* **Select Multiple**: Select one or more options from the provided list. (Not Required)

## Tips

* Ensure all required fields are filled before submission.
* Use the format specified for date of birth and time of hiring.
