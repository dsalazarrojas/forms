# Machine Operator Offboarding Form - Help Guide
## Purpose
This form is used to document the offboarding process for employees who are leaving the organization. It helps to maintain accurate records and ensures a smooth transition.

## How To Complete This Form
1. Fill in the employee's ID.
2. Enter the employee's name, email, and phone number.
3. Provide the machine ID and type if applicable.
4. Enter the name of the machine operator.
5. Select the last day the employee worked.
6. Select the termination date.
