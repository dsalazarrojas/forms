# Employee Records Update Form - Help Guide
## Purpose
The purpose of this form is to update existing employee records.

## How To Complete This Form
To complete this form, follow the steps below:

- Review the form carefully and ensure you have all necessary information before starting.
- Fill in the required and optional fields as needed.
- Double-check your input for accuracy before submitting the form.

## Field-by-Field Explanation

* **employee_name**: 
  Enter the updated name of the employee.
  Type: text, Required: false
* **employee_id**: 
  Enter the unique identifier of the employee.
  Type: number, Required: false
* **email**: 
  Enter the updated email address of the employee.
  Type: email, Required: false
* **department**: 
  Select the department the employee belongs to.
  Type: select_one, Required: false, Options: [Sales, IT, Marketing]
* **phone**: 
  Enter the updated phone number of the employee.
  Type: text, Required: false
* **date_of_birth**: 
  Enter the date of birth of the employee.
  Type: date, Required: false
* **time_of_birth**: 
  Enter the time of birth of the employee (in 24-hour format).
  Type: time, Required: false
* **notes**: 
  Add any additional comments or notes about the employee.
  Type: note, Required: false
* **job_title**: 
  Enter the updated job title of the employee.
  Type: text, Required: false
* **employee_status**: 
  Select the status of the employee (Active, Inactive, On leave).
  Type: select_one, Required: false, Options: [Active, Inactive, On leave]
* **assigned_tool**: 
  Select the tool assigned to the employee.
  Type: select_one, Required: false, Options: [chatjimmy, Tool 2, Tool 3]
* **created_by**: 
  Select who created the original employee record (admin or user).
  Type: select_one, Required: false, Options: [admin, user]
* **updated_by**: 
  Select who updated the employee record (admin or user).
  Type: select_one, Required: false, Options: [admin, user]
* **updated_date**: 
  Enter the date the record was last updated.
  Type: date, Required: false
* **updated_time**: 
  Enter the time the record was last updated (in 24-hour format).
  Type: time, Required: false
* **created_date**: 
  Enter the date the original employee record was created.
  Type: date, Required: false
* **created_time**: 
  Enter the time the original employee record was created (in 24-hour format).
  Type: time, Required: false
* **department_id**: 
  Enter the unique identifier of the employee's department.
  Type: number, Required: false
* **role**: 
  Enter the updated role of the employee.
  Type: text, Required: false

## Tips

- Double-check the form for accuracy before submitting it.
- If unsure about any field, consult with your supervisor or HR representative.
- Ensure you have the necessary permissions and access to the employee's record before accessing and updating it.
