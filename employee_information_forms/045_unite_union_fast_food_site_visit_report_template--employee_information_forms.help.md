# Unite Union Fast Food Site Visit Report Template - Help Guide
## Purpose
This form is used to document the details of a site visit by union officials.

## How To Complete This Form
1. **Enter the site name**: Type in the name of the site that was visited.
2. **Enter the site address**: Type in the address of the site that was visited.
3. **Select whether union officials attended**: Select 'Yes' if union officials attended the site visit, otherwise select 'No'.
4. **Enter site manager name (if available)**: If the site manager's name is available, enter it in this field.
5. **Enter site manager title (if available)**: If the site manager's title is available, enter it in this field.
6. **Enter site manager contact (if available)**: If the site manager's contact information is available, enter it in this field.
7. **Enter union officials' notes**: This is a space for union officials to record any notes about the site visit.
8. **Enter union officials' signature**: Type in the union officials' signature.
9. **Enter site visit date**: Select the date of the site visit using the date picker.
10. **Enter site visit time**: Select the time of the site visit using the time picker.
11. **Enter site visit comment (if available)**: If any additional comments are needed, enter them in this field.

## Field-by-Field Explanation
* **Site Name** (`site_name`, text, required): Type in the name of the site that was visited.
* **Site address** (`site_address`, text, required): Type in the address of the site that was visited.
* **Union officials attending** (`union_officials_attending`, select_multiple, required): Select 'Yes' if union officials attended the site visit, otherwise select 'No'.
* **Site manager name** (`site_manager_name`, text, optional): If the site manager's name is available, enter it in this field. This field is optional.
* **Site manager title** (`site_manager_title`, text, optional): If the site manager's title is available, enter it in this field. This field is optional.
* **Site manager contact** (`site_manager_contact`, text, optional): If the site manager's contact information is available, enter it in this field. This field is optional.
* **Union officials notes** (`union_officials_notes`, note, optional): This is a space for union officials to record any notes about the site visit.
* **Union officials signature** (`union_officials_signature`, text, required): Type in the union officials' signature.
* **Site visit date** (`site_visit_date`, date, required): Select the date of the site visit using the date picker.
* **Site visit time** (`site_visit_time`, time, required): Select the time of the site visit using the time picker.
* **Site visit comment** (`site_visit_comment`, text, optional): If any additional comments are needed, enter them in this field. This field is optional.
