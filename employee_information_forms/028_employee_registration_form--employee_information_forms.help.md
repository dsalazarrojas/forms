# Employee Registration Form - Help Guide
## Purpose
The Employee Registration Form is used to collect and store employee information for internal administrative and HR purposes. This form helps us keep track of new and existing employees, their job details, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the required information (marked as "required" below) and optional information for the employee.
2. Fill in the form with the following details:
   - First Name: Enter the employee's first name.
   - Last Name: Enter the employee's last name.
   - Email: Enter the employee's email address.
   - Phone: Enter the employee's phone number.
   - Job Title: Enter the employee's job title.
   - Job Description: Enter a brief description of the job position.
   - Job Status: Select the employee's job status (New Hire, Existing Employee, or Contract).
   - Department: Select the employee's department (HR, Management, or Operations).
   - Location: Select the location (New York, Los Angeles, or Chicago).
   - Job Start Date: Enter the date the employee started their job.
   - Job End Date: Enter the date the employee's job ended (if applicable).
   - Job Type: Select the type of job (Full-time, Part-time, or Contract).
   - Job Level: Select the level of the job (Entry-Level, Mid-level, or Senior-Level).

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter the employee's first name.
* **Last Name** (`last_name`, text, optional): Enter the employee's last name.
* **Email** (`email`, email, optional): Enter the employee's email address.
* **Phone** (`phone`, text, optional): Enter the employee's phone number.
* **Job Title** (`job_title`, text, optional): Enter the employee's job title.
* **Job Description** (`job_description`, text, optional): Enter a brief description of the job position.
* **Job Status** (`job_status`, select multiple, optional):
  - Select "New Hire" for new employees.
  - Select "Existing Employee" for existing employees with an updated status.
  - Select "Contract" for contract workers.
* **Department** (`department`, select multiple, optional):
  - Select "HR" for Human Resources department.
  - Select "Management" for management roles.
  - Select "Operations" for operational roles.
* **Location** (`location`, select one, optional):
  - Select "New York" for employees based in New York.
  - Select "Los Angeles" for employees based in Los Angeles.
  - Select "Chicago" for employees based in Chicago.
* **Job Start Date** (`job_start_date`, date, optional): Enter the date the employee started their job.
* **Job End Date** (`job_end_date`, date, optional): Enter the date the employee's job ended (if applicable).
* **Job Type** (`job_type`, select one, optional):
  - Select "Full-time" for full-time employees.
  - Select "Part-time" for part-time employees.
  - Select "Contract" for contract workers.
* **Job Level** (`job_level`, select one, optional):
  - Select "Entry-Level" for entry-level jobs.
  - Select "Mid-level" for mid-level jobs.
  - Select "Senior-Level" for senior-level jobs.

## Tips
* Ensure that all required fields are filled in before submission.
* Double-check the information for accuracy before saving the form.
* If you are unsure about any field, contact your HR department for guidance.
