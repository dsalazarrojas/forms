# Substitute Form - Help Guide

## Purpose
This form is used to document employee absences for HR or administrative purposes.

## How To Complete This Form
1. Fill out all the required fields to ensure the form is properly processed.
2. Make sure you have permission to document this absence before filling out the form.
3. Be aware of your company's absence policies.

## Field-by-Field Explanation

* **Substitute Form** (`substitute_form`, text, required/optional): Enter a brief description of the absence.
* **Employee Name** (`employee_name`, text, required): The name of the employee requesting a substitute.
* **Employee Email** (`employee_email`, email, required): The employee's email address.
* **Reason For Absence** (`reason_for_absence`, text, required): A detailed explanation for the absence.
* **Start Date** (`start_date`, date, optional): The start date of the absence.
* **End Date** (`end_date`, date, optional): The end date of the absence.
* **Contact Phone** (`contact_phone`, text, optional): The contact phone number for the employee's replacement.
* **Contact Email** (`contact_email`, email, optional): The contact email address for the employee's replacement.
* **Contact Name** (`contact_name`, text, optional): The name of the employee's replacement.
* **Start Time** (`start_time`, time, optional): The start time of the absence.
* **End Time** (`end_time`, time, optional): The end time of the absence.
