# Faculty Remote Work Productivity Survey - Help Guide
## Purpose
This form is designed to gather feedback from faculty members on their experiences with remote work, focusing on work status, productivity, challenges faced, and satisfaction with remote work. Your input will help us better understand the remote work experience and make informed decisions to improve it.

## How To Complete This Form
1. Please fill in your **First Name** and **Last Name** in the corresponding fields.
2. Enter your **Email** to help us contact you for further clarification or follow-up questions.
3. Select your current **Work Status** from the dropdown menu.
4. Describe the **Challenges Faced** you have encountered while working remotely.
5. For **Productivity Level**, select all categories that apply to your current work situation.
6. Rate your **Satisfaction with Remote Work** on a scale from 0 to 10.
7. Report the **Time Spent Working Offsite** and specify the units (e.g., days, hours).
8. Report the **Time Spent Communicating with Teams** and specify the units (e.g., minutes, hours).
9. Report the **Time Spent Working from Home** and specify the units (e.g., days, hours).
10. Report the **Time Spent Traveling for Work** and specify the units (e.g., days, hours).
11. Report the **Time Spent Attending Meetings** and specify the units (e.g., days, hours).
12. Provide a brief description of the **Challenges Faculty** you have faced.
13. Describe the **Challenges Support** you require.
14. For **Satisfaction Faculty**, select the option that best represents your current satisfaction level.
15. For **Satisfaction Supervisor**, select the option that best represents your current satisfaction level.
16. For **Satisfaction Collegiality**, select the option that best represents your current satisfaction level.
17. For **Satisfaction Technology**, select the option that best represents your current satisfaction level.
18. Select all areas of **Support Faculty** that you currently receive.
19. Select all areas of **Support Supervisor** that you currently receive.
20. Select all areas of **Support Technology** that you currently receive.
21. Describe the **Challenges Communication** you have faced.
22. Describe the **Challenges Scheduling** you have faced.
23. Provide any **Suggestions** on how to improve the remote work experience.

## Field-by-Field Explanation

* **First Name**: Your first name.
* **Last Name**: Your last name.
* **Email**: Your email address for contact purposes.
* **Work Status**: Select your current work status (e.g., full-time remote, part-time remote, on-campus).
* **Challenges Faced**: Describe any challenges you have faced while working remotely.
* **Productivity Level**: Select all categories that apply to your current productivity level (e.g., high, moderate, low).
* **Satisfaction with Remote Work**: Rate your satisfaction with remote work on a scale from 0 to 10.
* **Time Spent Working Offsite**: Report the time spent working offsite and specify the units.
* **Time Spent Communicating with Teams**: Report the time spent communicating with teams and specify the units.
* **Time Spent Working from Home**: Report the time spent working from home and specify the units.
* **Time Spent Traveling for Work**: Report the time spent traveling for work and specify the units.
* **Time Spent Attending Meetings**: Report the time spent attending meetings and specify the units.
* **Challenges Faculty**: Describe any challenges you have faced regarding faculty support.
* **Challenges Support**: Describe any challenges you have faced regarding support.
* **Satisfaction Faculty**: Select the option that best represents your current satisfaction level with faculty support.
* **Satisfaction Supervisor**: Select the option that best represents your current satisfaction level with supervisor support.
* **Satisfaction Collegiality**: Select the option that best represents your current satisfaction level with collegiality.
* **Satisfaction Technology**: Select the option that best represents your current satisfaction level with technology.
* **Support Faculty**: Select all areas of support you currently receive from faculty.
* **Support Supervisor**: Select all areas of support you currently receive from your supervisor.
* **Support Technology**: Select all areas of support you currently receive from technology.
* **Challenges Communication**: Describe any challenges you have faced regarding communication.
* **Challenges Scheduling**: Describe any challenges you have faced regarding scheduling.
* **Suggestions**: Provide any suggestions on how to improve the remote work experience.
