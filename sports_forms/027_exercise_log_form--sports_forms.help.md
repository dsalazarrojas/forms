# Exercise Log Form - Help Guide
## Purpose
The Exercise Log Form is a tool for tracking individual workout sessions. It helps users document their exercise history, allowing them to review and analyze their progress over time.

## How To Complete This Form
To complete the Exercise Log Form, follow these steps:

1. Determine if you worked out during the session.
2. Select the date of the workout session.
3. Add any notes about the session.
4. Choose the type of exercise you completed.
5. Enter the number of sets you completed.
6. Enter the number of repetitions.
7. Enter the rest time.
8. Confirm if you completed all exercises.

## Field-by-Field Explanation

* **workout_session** (select multiple):
	+ Select "Yes" if you worked out during this session, "No" otherwise.
* **date** (date):
	+ Enter the date of the workout session.
* **notes** (text):
	+ Add any notes or comments about the session.
* **session_duration** (number):
	+ Enter the duration of the session in units of minutes.
* **exercise** (text):
	+ Enter the type of exercise you completed.
* **sets** (number):
	+ Enter the number of sets you completed.
* **reps** (number):
	+ Enter the number of repetitions completed.
* **rest_time** (number):
	+ Enter the rest time between sets.
* **exercises_completed** (select one):
	+ Select "Yes" if you completed all exercises, "No" otherwise.

## Tips
* Be sure to complete all required fields accurately to ensure correct tracking.
* Use one form per workout session to maintain accurate records.
* Review and update your exercise log regularly to track progress over time.
