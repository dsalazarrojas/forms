# Toddler Jiu Jitsu Trial Class Request - Help Guide
## Purpose
This form is designed to be completed by parents or guardians to request a trial class for their toddler to experience Jiu Jitsu for the first time. The information collected will help the Jiu Jitsu school to plan a trial class that suits the child's needs and schedule.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide your child's details in the "Trial Class Details" field.
2. Choose a date for the trial class that works for you and your child.
3. Select a time for the trial class that fits your schedule.

## Field-by-Field Explanation
* **Trial Class Details** (optional):
	+ Enter your child's name, age, and any other relevant information about your child that you would like to share with the Jiu Jitsu school.
* **Trial Class Date** (optional):
	+ Choose a date for the trial class that you think would work best for your child. This can be a specific date or a date range.
* **Trial Class Time** (optional):
	+ Select a time for the trial class that fits your schedule. You can choose from the available options or provide a custom time.

## Tips
* Please make sure to provide accurate and relevant information about your child and your availability.
* If you have any questions or need help with completing this form, please contact us at [form@gic.mx](mailto:form@gic.mx).
