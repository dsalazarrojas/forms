# race_bib_clips_collection_form - Help Guide
## Purpose
This form is designed to collect and record information about race bib clips returns. It helps staff track the status of bib clips, including whether they have been shipped or lost.

## How To Complete This Form
To complete this form, simply fill out the required fields and submit the form. Ensure you have the following information ready:
- Date of Return
- Event Name
- Bib Number
- Race ID
- Return Status (if not required, you can skip this field)

## Field-by-Field Explanation
- **Date of Return** (`date`, required): Enter the date you are returning the race bib clips.
- **Event Name** (`text`, required): Enter the name of the event where the race bib clips were obtained.
- **Bib Number** (`number`, required): Enter the number of the race bib clips being returned.
- **Race ID** (`number`, required): Enter the ID of the race event.
- **Return Status** (`select_one`, optional): If you are not required to select a status, you can leave this field blank. Otherwise, select one of the following options:
  - **Pending**: The return is pending review.
  - **Shipped**: The return has been shipped.
  - **Lost**: The return has been lost or not located.

## Tips
- Make sure to double-check your entries for accuracy.
- If you are unsure about any field, please contact staff for assistance.
- This form is designed to be completed in a timely manner, so please try to submit it as soon as possible after the return.
