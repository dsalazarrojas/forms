## Fitness Class Live Streaming Consent Form - Help Guide

### Purpose
This form is used to collect information about a fitness class live streaming session. It includes details such as class duration, location, streaming type, and schedule. The form also requires consent from the user before streaming can be done.

### How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields with the following information:
	* **Name**: Enter your name.
	* **Email**: Enter your email address.
	* **Date and Time**: Select the date and time of the fitness class.
	* **Location**: Choose the location where the class will be held (studio, at home, or outdoor).
	* **Stream Type**: Select the type of streaming (live, video, or recording).
	* **Streaming Schedule**: Select the schedule for the stream.
	* **Consent**: Check "True" to give consent for the streaming.
2. Optionally, fill out the following fields:
	* **Phone**: Enter your phone number (optional).
	* **Class Duration**: Enter the duration of the class.
	* **Description**: Provide a brief description of the class.
	* **Comments**: Add any additional comments about the class.

### Field-by-Field Explanation
* **Name** (`user_info`, text, optional): Enter your name for reference purposes.
* **Email** (`email`, email, optional): Enter your email address for contact purposes.
* **Phone** (`phone`, text, optional): Enter your phone number for communication.
* **Date and Time** (`date_time`, date, optional): Select the date and time of the fitness class.
* **Location** (`location`, select_one, optional): Choose the location where the class will be held (studio, at home, or outdoor).
* **Stream Type** (`streaming_type`, select_multiple, optional): Select the type of streaming (live, video, or recording).
* **Stream Type** (`stream_type`, text, optional): Enter the type of stream (optional).
* **Streaming Schedule** (`streaming_schedule`, date, optional): Select the schedule for the stream.
* **Class Duration** (`class_duration`, text, optional): Enter the duration of the class.
* **Description** (`description`, note, optional): Provide a brief description of the class.
* **Consent** (`consent`, select_one, required): Check "True" to give consent for the streaming.
* **Comments** (`comments`, note, optional): Add any additional comments about the class.
* **Submission Date** (`submission_date`, date, optional): Enter the date of submission.

### Tips
* Please ensure you provide accurate information to enable successful streaming.
* If you have any questions or need further clarification, please contact us.
