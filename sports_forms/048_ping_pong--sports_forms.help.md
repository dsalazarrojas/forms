# Ping Pong - Help Guide
## Purpose
The "Ping Pong" form is used to track sports scores and matches. This form is suitable for both casual and professional ping-pong games, allowing users to record player names, scores, and match details.

## How To Complete This Form

To get started, fill in the required fields as described in the "Field-by-Field Explanation" section below.

## Field-by-Field Explanation

* **Table Tennis Scores** (`score_form`): Enter the scores for the match.
* **Player One** (`player_one`): Enter the name of the first player.
* **Player Two** (`player_two`): Enter the name of the second player.
* **Player One Score** (`player_one_score`): Enter the score of Player One.
* **Player Two Score** (`player_two_score`): Enter the score of Player Two.
* **Player Three** (`player_three`): Enter the name of the third player (if applicable).
* **Player Four** (`player_four`): Enter the name of the fourth player (if applicable).
* **Date Played** (`date_played`): Enter the date the match was played (YYYY-MM-DD format).
* **Time Played** (`time_played`): Enter the time the match was played (HH:MM:SS format).
* **Match Winner** (`match_winner`): Select the winner of the match from the dropdown menu.
* **Match Winner Reason** (`match_winner_reason`): Enter the reason for the match winner (if applicable).
* **Notes** (`notes`): Add any additional notes about the match.
* **Assigned To** (`assigned_to`): Select the user or team responsible for the match result.
* **Created By** (`created_by`): Enter the name of the user who created the match record.
* **Updated By** (`updated_by`): Enter the name of the user who last updated the match record.
* **Created At** (`created_at`): Display the timestamp when the match record was created.
* **Updated At** (`updated_at`): Display the timestamp when the match record was last updated.
* **Deleted At** (`deleted_at`): Display the timestamp when the match record was deleted.
* **Deleted By** (`deleted_by`): Display the name of the user who deleted the match record.
* **Notes Deleted** (`notes_deleted`): Enter a reason for deleting the match record.
* **Deleted Reason** (`deleted_reason`): Enter a brief reason for deleting the match record.
* **Deleted At Time** (`deleted_at_time`): Display the time when the match record was deleted.
* **Version** (`version`): Display the version of the match record.
* **Deleted By User** (`deleted_by_user`): Display the user who deleted the match record.
* **Deleted At User** (`deleted_at_user`): Display the user who last deleted the match record.

**Tips:**

- Make sure to fill in all required fields marked with `*` (asterisk) symbol.
- Enter scores and dates in the correct formats.
- Use the dropdown menu for selecting match winner when applicable.
- Use this form for both casual and professional ping-pong game tracking.
