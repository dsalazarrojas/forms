# COVID 19 AttendanceChecklist - Help Guide
## Purpose
This form is designed to collect information about a student's class attendance during the COVID-19 pandemic.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the relevant information for the class being reported on.
2.  Fill out the fields for class information, including the class date, class time, instructor name, and class type.
3.  Enter the student's name and ID number (if applicable).
4.  Select the student's membership status and health screening status.
5.  Check the student's vaccination status and temperature screening status.
6.  Determine the student's attendance status.
7.  Enter any additional notes about the student's attendance.

## Field-by-Field Explanation
- **Class Information** (`class_date`, `class_time`, `instructor_name`, `class_type`): These fields collect information about the class being reported on. Select the relevant date and time for the class, and enter the instructor's name and class type (e.g., Beginner, Intermediate, Advanced, etc.).
- **Student Information** (`student_name`, `student_id`): Enter the student's name and ID number (if applicable).
- **Membership Status** (`membership_status`): Select the student's current membership status (Active, Trial, Suspended, Expired).
- **Health Screening** (`health_check`): Select whether the student's health screening has been completed (True, False).
- **COVID-19 Vaccination Status** (`vaccination_confirmed`): Select the student's vaccination status (Vaccinated, Partially Vaccinated, Not Vaccinated, Unknown).
- **Temperature Screening** (`temperature_check`): Select whether the student's temperature screening has been passed (Passed, Failed, Not Checked).
- **Attendance Status** (`attendance_status`): Select the student's attendance status (Present, Excused Absence, Unexcused Absence, Cancelled).
- **Additional Notes** (`notes`): Enter any additional notes about the student's attendance.

## Tips
- Make sure to fill out all required fields.
- Be accurate and consistent in your reporting.
- If a student has a unique situation or circumstance, include additional notes to explain the student's attendance status.
