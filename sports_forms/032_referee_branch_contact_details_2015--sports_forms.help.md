# Referee Branch Contact Details 2015 - Help Guide
## Purpose
The Referee Branch Contact Details 2015 form is used to collect contact information for a referee branch. This form helps in updating or adding contact details for a specific referee branch within a sports organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked as "required" in the form.
2. Make sure to enter a valid email address for the "Email" and "Contact Email" fields.
3. Enter a valid address for the "Address" field.
4. Enter the "Contact Position", "Department", "Contact Phone", and "Contact Fax" fields for the contact person.
5. Optionally, fill in the "Fax", "Mobile", and "Branch Website" fields if applicable.

## Field-by-Field Explanation
* **Contact Name** (`Contact Name`, text, required): Enter the name of the contact person for the referee branch.
* **Email** (`Email`, email, required): Enter a valid email address for the referee branch.
* **Address** (`Address`, text, required): Enter the address of the referee branch.
* **Branch Name** (`Branch Name`, text, required): Enter the name of the referee branch.
* **Contact Position** (`Contact Position`, text, required): Enter the position of the contact person.
* **Phone** (`Phone`, text, required): Enter the phone number of the referee branch.
* **Fax** (`Fax`, text, optional): Enter the fax number of the referee branch if applicable.
* **Mobile** (`Mobile`, text, optional): Enter the mobile number of the contact person if applicable.
* **Department** (`Department`, text, required): Enter the department of the referee branch.
* **Branch Website** (`Branch Website`, text, optional): Enter the website of the referee branch if applicable.
* **Contact Email** (`Contact Email`, email, required): Enter a valid email address for the contact person.
* **Contact Phone** (`Contact Phone`, text, required): Enter the phone number of the contact person.
* **Contact Fax** (`Contact Fax`, text, optional): Enter the fax number of the contact person if applicable.
* **Contact Mobile** (`Contact Mobile`, text, optional): Enter the mobile number of the contact person if applicable.

## Tips
* Make sure to double-check the information entered for accuracy and completeness.
* If you are unsure about any field, please contact the relevant authorities for clarification.
* This form is designed to be used for updating or adding contact details for a specific referee branch within a sports organization.
