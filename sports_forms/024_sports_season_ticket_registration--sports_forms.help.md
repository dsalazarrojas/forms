# Sports Season Ticket Registration - Help Guide

## Purpose

The Sports Season Ticket Registration form is designed to collect information from fans interested in purchasing season tickets for a particular team's events or games.

## How To Complete This Form

1.  Ensure you have a valid email address and phone number, as these fields are required for communication purposes.
2.  Review each field carefully to provide accurate and complete information.
3.  Select the correct options for each field based on your specific needs and requirements.
4.  Double-check your information for accuracy before submitting the form.

## Field-by-Field Explanation

*   **Season Ticket Order (`season_ticket_order`, text, required):** This field is used to enter the specific season ticket order you're interested in. Please enter the desired ticket package or package type.
*   **Attendee Details (`attendee_details`, select_one, required: false):** This field asks if the user will be attending with others. If you answer 'Yes', please specify the number of attendees and any additional information you'd like to provide.
*   **Season Tickets (`season_tickets`, select_multiple, required: false):** Select all the season ticket options you're interested in purchasing. This might include different types of tickets or packages.
*   **Game Dates (`game_dates`, date, required: false):** Enter the specific dates you're interested in attending. You can select multiple dates if necessary.
*   **Game Times (`game_times`, time, required: false):** Enter the specific times you're interested in attending. You can select multiple times if necessary.
*   **Season Ticket Prices (`season_ticket_prices`, number, required: false):** Enter the price you're willing to pay for the season tickets.
*   **Notes (`notes`, note, required: false):** If you have any specific notes or concerns, please enter them here.
*   **Email (`email`, email, required: false):** Enter your email address for communication purposes.
*   **Phone (`phone`, text, required: false):** Enter your phone number for communication purposes.
*   **Team (`team`, select_one, required: false):** Select the team you're interested in attending.
*   **Event Organizer (`event_organizer`, select_one, required: false):** Select if you're interested in attending an event organized by the team or a third-party company.
*   **Event Name (`event_name`, text, required: false):** Enter the name of the event you're interested in attending.
*   **Event Date (`event_date`, date, required: false):** Enter the date of the event you're interested in attending.
*   **Event Time (`event_time`, time, required: false):** Enter the time of the event you're interested in attending.

## Tips

*   Please ensure accuracy when entering your email and phone number, as these will be used for communication purposes.
*   If you're unsure about any of the options or fields, refer back to this guide for clarification.
*   Double-check your information before submitting the form to avoid errors.
*   If you have any issues or concerns, please don't hesitate to contact the event organizers or team management.
*   Be sure to review the terms and conditions before submitting the form.
