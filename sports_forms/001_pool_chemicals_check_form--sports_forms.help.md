# Pool Chemicals Check Form - Help Guide
## Purpose
The Pool Chemicals Check Form is designed to help pool staff and operators keep track of the pool maintenance chemicals being used and ensure that they are up-to-date and safe to use.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current maintenance chemical being used from the list:
	* What is the current chemical used for pool maintenance? (pool_maintenance_chemicals)
	* Select one of the options:
		+ Algaecide
		+ Stabilizer
		+ Clarifier
2. If you selected Algaecide, Stabilizer, or Clarifier, you will be asked to confirm that you are using the correct chemical by selecting "True" or "False" next to the corresponding label.
3. If you selected other chemicals, please describe what they are in the "Other chemicals" field.
4. Record the brand name of the pool chemicals being used in the "Chemical" field.
5. If you are using Algaecide, Stabilizer, or Clarifier, enter the expiration date of the chemical.
6. Finally, confirm that you have checked all the chemicals by selecting "True" or "False" in the "Pool Check" field.

## Field-by-Field Explanation
* **Pool Maintenance Chemicals (pool_maintenance_chemicals)**: Select the current maintenance chemical being used.
* **Algaecide (algaecide)**: Confirm that Algaecide is being used. Select "True" if you are using Algaecide, select "False" otherwise.
* **Stabilizer (stabilizer)**: Confirm that Stabilizer is being used. Select "True" if you are using Stabilizer, select "False" otherwise.
* **Clarifier (clarifier)**: Confirm that Clarifier is being used. Select "True" if you are using Clarifier, select "False" otherwise.
* **Other Chemicals (other_chemicals)**: Select "True" if you are using other chemicals, select "False" otherwise.
* **What are these other chemicals? (other_chemicals_used)**: If you selected "Other Chemicals", describe what these chemicals are.
* **Chemical (chemical_1)**: Record the brand name of the pool chemicals being used.
* **Algaecide Expiration (algaecide_expiration)**: Enter the expiration date of Algaecide if it is being used.
* **Stabilizer Expiration (stabilizer_expiration)**: Enter the expiration date of Stabilizer if it is being used.
* **Clarifier Expiration (clarifier_expiration)**: Enter the expiration date of Clarifier if it is being used.
* **Pool Check (pool_check)**: Confirm that you have checked all the chemicals by selecting "True".
