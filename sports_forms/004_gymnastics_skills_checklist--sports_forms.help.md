# Gymnastics Skills Checklist - Help Guide

## Purpose
This form is designed to assess a gymnast's skills and techniques in various categories, including handstands, round-offs, cartwheels, and somersaults. It's intended for coaches, instructors, or evaluators to quickly identify areas where an athlete excels or needs improvement.

## How To Complete This Form

1. Review each page carefully, as each category assesses different skills.
2. For each field, select the correct answer according to your knowledge of the gymnast's abilities.
3. Enter a "Yes" for skills the gymnast has mastered or can perform with ease.
4. Enter a "No" for skills they have not yet mastered or need practice with.
5. For text fields like "front" and "jumpback," enter the specific skill's name or description if possible.
6. Save your assessment to track progress over time.
