# Sports Event Hosting Application - Help Guide
## Purpose
The Sports Event Hosting Application form is designed to help sports event hosts submit information about upcoming events. This form collects essential details about the event, allowing us to manage and track sports events in our system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked as *required*.
2. Ensure you enter a valid date for the *Event Date* field.
3. Select the correct *Event Type* from the options provided.
4. Choose the appropriate *Event Capacity* from the options provided.
5. Check the *Event Status* and select *Available* if your event has not yet reached capacity.
6. Enter a valid *Event Address* and *Event Phone* number for your event venue.
7. Enter a valid *Event Email* address for contact purposes.

## Field-by-Field Explanation
* **Event Name**: Enter the name of your sports event.
* **School Club Name**: Enter the name of the school club hosting the event.
* **Venue Name**: Enter the name of the venue where the event will take place.
* **Event Date**: Enter a valid date for the event in the format MM/DD/YY.
* **Event Time**: Enter the start time of the event in the format HH:MM.
* **Event Duration**: Enter the expected duration of the event.
* **Event Type**: Select the type of sport being hosted (Soccer, Tennis, Basketball, or Other).
* **Event Capacity**: Choose the number of attendees expected (Less than 50, 50-100, 100-200, More than 200).
* **Event Status**: Indicate if the event is available or not available for registration.
* **Event Address**: Enter the address of the event venue.
* **Event Phone**: Enter the phone number for the event venue.
* **Event Email**: Enter a valid email address for contact purposes.

## Tips
* Make sure to double-check your entries for accuracy and completeness before submitting the form.
* Use a valid format for dates and times to avoid errors.
* If you need help or have questions, contact us using the provided email address.
