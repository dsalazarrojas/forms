# <title> - Help Guide

## Purpose
This is a class preference form designed to help instructors and clients understand individual preferences for group fitness classes. The goal is to gather information on preferred class type, time, frequency, and location to create a more personalized and inclusive class environment.

## How To Complete This Form

1.  Please answer all questions thoroughly, ensuring you accurately represent your preferences.
2.  Select one or multiple options for each field as applicable.
3.  If you have a preferred class type that is not listed, please use the "Other" option and describe it in the "preferred_class_type_other" field.
4.  If you have any additional comments or concerns, please use the "additional_comments" field.

## Field-by-Field Explanation

*   **Introduction** (`introduction`, `note`, required/optional): A brief introduction to this form.
*   **Preferred Class Type** (`preferred_class_type`, `select_one`, required/optional): Please select one of the listed class types, such as "Running", "Strength Training", or "Cardio Kickboxing".
*   **Available Days** (`available_days`, `select_multiple`, required/optional): Select all the days of the week you are available to attend classes. For example, "Monday, Wednesday, Friday".
*   **Available Times** (`available_times`, `select_multiple`, required/optional): Select all the time slots you prefer for your classes. For example, "Morning, Afternoon".
*   **Preferred Duration** (`preferred_duration`, `select_one`, required/optional): Select one of the listed time durations for your classes, such as "30-45 minutes" or "45-60 minutes".
*   **Preferred Frequency** (`preferred_frequency`, `select_one`, required/optional): Select how often you would like to attend classes, such as "Daily" or "1 time a week".
*   **Preferred Class Time** (`preferred_class_time`, `time`, required/optional): If you have a specific time for your classes, please enter it. Note: This field is not currently supported, please contact your instructor for further assistance.
*   **Email** (`email`, `email`, required/optional): Please enter your email address for further contact.
*   **Phone** (`phone`, `text`, required/optional): Enter your phone number for further contact.
*   **Name** (`name`, `text`, required/optional): Enter your name for further reference.
*   **Age Group** (`age_group`, `select_one`, required/optional): Select your age group from "Young Adult (19-30)", "Adult (31-59)", or "Senior (60-)".
*   **Contact Number** (`contact_number`, `text`, required/optional): Enter your contact number for further reference.
*   **Contact Email** (`contact_email`, `text`, required/optional): Enter your contact email for further reference.
*   **Preferred Class Location** (`preferred_class_location`, `select_one`, required/optional): Select one of the listed locations, such as "Downtown", "Near Home", or "In Studio".
*   **Preferred Class Type (Outdoor)** (`preferred_class_type_outdoor`, `select_one`, required/optional): Select one of the listed outdoor activities, such as "Yoga", "Walking/Running", or "Cycling".
*   **Preferred Class Type (Indoor)** (`preferred_class_type_indoor`, `select_one`, required/optional): Select one of the listed indoor activities, such as "Strength Training", "Cardio", or "Other".
*   **Preferred Class Equipment** (`preferred_class_equipment`, `select_one`, required/optional): Select one of the listed equipment types, such as "Weights", "Resistance Bands", or "Mats".
*   **Preferred Class Intensity** (`preferred_class_intensity`, `select_one`, required/optional): Select one of the listed intensity levels, such as "Low", "Medium", or "High".
*   **Preferred Class Type Other** (`preferred_class_type_other`, `text`, required/optional): If you have a different class type in mind that is not listed, describe it here.
*   **Preferred Class Time Day** (`preferred_class_time_weekday`, `select_one`, required/optional): Select a specific day of the week for your classes. For example, "Monday".
*   **Preferred Class Time** (`preferred_class_time_weekday_time`, `time`, required/optional): If you have a specific time for your classes on the selected day, enter it.
*   **Additional Comments** (`additional_comments`, `text`, required/optional): Leave any additional comments or concerns you have.
*   **Email Conflict** (`email_conflict`, `select_one`, required/optional): Select "Yes" if you are available at the email address entered. 
*   **Phone Number Conflict** (`phone_number_conflict`, `select_one`, required/optional): Select "Yes" if you are available at your phone number.

## Tips
*   Please note that some fields are not supported in this form (e.g., "Preferred Class Time" and "Preferred Class Time Day"). Please contact your instructor for further assistance.
*   For any additional questions or concerns, please contact your instructor.
