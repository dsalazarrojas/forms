# Swimming Assessment Form - Help Guide
## Purpose
The Swimming Assessment Form is used to gather information about a swimmer's performance during a swim test. This form helps coaches and trainers evaluate the swimmer's abilities, identify areas for improvement, and create a plan for their development.

## How To Complete This Form
To complete the Swimming Assessment Form, follow these steps:

1. Enter the Athlete ID, which is the unique identifier for the swimmer.
2. Select the swim test that the swimmer took, using the drop-down menu.
3. Enter the date and time of the swim test.
4. Choose the stroke type, selecting all applicable strokes (e.g., Freestyle, Backstroke, Butterfly, etc.).
5. Enter the swim distance.
6. Add any relevant notes about the swim test.
7. Enter the swim score.
8. Enter any comments about the swim test.
9. Upload any relevant files (e.g., images, videos, etc.).
10. Enter the URL of any files uploaded.
11. Select the swim category, selecting all applicable categories (e.g., Sprint, Endurance, etc.).
12. Select the swim subcategory, choosing all applicable subcategories (e.g., Yes, No, etc.).
13. Choose the swim level, selecting all applicable levels (e.g., Beginner, Intermediate, Advanced, etc.).
14. Select the swim coach, choosing all applicable coaches (e.g., Coach, Assistant Coach, etc.).
15. Enter the swim location.
16. Enter any swim equipment used.
17. Select the swim water temperature.
18. Choose the swim pool type.
19. Select the swim squad size.
20. Select the swimmer's age group.
21. Select the swimmer's gender.
22. Select the swim language.
23. Enter any additional comments about the swim test.

## Field-by-Field Explanation
- **Athlete ID** (`athlete_id`, `number`, required): Enter the swimmer's unique identifier.
- **Swim Test** (`swim_test`, `select_one`, required): Select the swim test that the swimmer took.
- **Swim Test Date** (`swim_test_date`, `date`, required): Enter the date of the swim test.
- **Swim Test Time** (`swim_test_time`, `time`, required): Enter the time of the swim test.
- **Stroke** (`swim_stroke`, `select_multiple`, required): Choose all applicable strokes (e.g., Freestyle, Backstroke, etc.).
- **Swim Distance** (`swim_dist`, `number`, required): Enter the swim distance.
- **Swim Notes** (`swim_notes`, `note`, optional): Add any relevant notes about the swim test.
- **Swim Score** (`swim_score`, `number`, required): Enter the swim score.
- **Swim Comments** (`swim_comments`, `text`, optional): Enter any comments about the swim test.
- **Swim File Upload** (`swim_file_upload`, `text`, required): Upload any relevant files (e.g., images, videos, etc.).
- **Swim File Url** (`swim_file_url`, `text`, optional): Enter the URL of any files uploaded.
- **Swim Category** (`swim_category`, `select_multiple`, required): Select all applicable categories (e.g., Sprint, Endurance, etc.).
- **Swim Subcategory** (`swim_subcategory`, `select_multiple`, optional): Choose all applicable subcategories (e.g., Yes, No, etc.).
- **Swim Level** (`swim_level`, `select_multiple`, required): Choose all applicable levels (e.g., Beginner, Intermediate, Advanced, etc.).
- **Swim Coach** (`swim_coach`, `select_multiple`, required): Choose all applicable coaches (e.g., Coach, Assistant Coach, etc.).
- **Swim Location** (`swim_location`, `text`, required): Enter the swim location.
- **Swim Equipment** (`swim_equipment`, `text`, optional): Enter any swim equipment used.
- **Swim Water Temp** (`swim_water_temp`, `select_one`, required): Select the swim water temperature.
- **Swim Pool** (`swim_pool`, `select_multiple`, required): Choose all applicable pool types (e.g., Lap Pool, Wave Pool, etc.).
- **Swim Squad Size** (`swim_squad_size`, `select_multiple`, required): Choose all applicable squad sizes (e.g., 1-5, 6-10, 11-15, etc.).
- **Swim Age Group** (`swim_age_group`, `select_multiple`, required): Select the swimmer's age group.
- **Swim Gender** (`swim_gender`, `select_one`, required): Select the swimmer's gender.
- **Swim Language** (`swim_language`, `select_multiple`, optional): Choose the swim language.
- **Swim Additional Comments** (`swim_additional_comments`, `text`, optional): Enter any additional comments about the swim test.

Note: The fields marked as "optional" may be filled out or left blank, but it's recommended to fill them out if possible to provide more information about the swim test.
