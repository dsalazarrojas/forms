# University Sports Event Incident Report Form - Help Guide
## Purpose
The University Sports Event Incident Report Form is a tool used by university sports event attendees to report incidents that occurred during events. This form is meant to gather information on the incident's details, the people involved, and the response from the staff.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all the required fields accurately and completely.
2. If you are reporting an incident that you witnessed, ensure that you are reporting on the facts as you know them.
3. If you experienced the incident, please be as detailed as possible about what happened.
4. Ensure that you select the correct incident type from the list provided.
5. If medical attention was received, please provide the name of the medical provider who provided it.
6. If first aid was administered, please describe it in detail.
7. Select the correct incident status.
8. Fill out the staff contact information if you are reporting the incident to staff.

## Field-by-Field Explanation

### 1. **Incident** (`incident_details`)
* This field is a place to write a detailed description of the incident that occurred.
* Please be as accurate and detailed as possible.

### 2. **Incident Location** (`incident_location`)
* This field is for the location where the incident occurred.
* If you were not sure of the location, please describe the area or the event's location.

### 3. **Date** (`date`)
* This field is for the date of the incident.
* Please ensure that you select the correct date.

### 4. **Time** (`time`)
* This field is for the time of the incident.
* Please ensure that you select the correct time.

### 5. **Type** (`incident_type`)
* This field is to select the type of incident that occurred.
* Please select the correct type from the list provided.

### 6. **Description** (`incident_description`)
* This field is a place to write a detailed description of the incident that occurred.
* Please be as accurate and detailed as possible.

### 7. **Witness List** (`witness_list`)
* This field is to select the witness of the incident.
* If you witnessed the incident, you will be able to select yourself as a witness.
* If you were not able to witness the incident, please select 'None' from the list.

### 8. **Staff Responded** (`staff_responded`)
* This field is a place to write the details of what staff did to respond to the incident.
* Please be as detailed as possible.

### 9. **Medical Attention Received** (`medical_attention_received`)
* This field is for the medical provider who gave you attention.
* If no medical attention was received, please type 'No'.

### 10. **First Aid Administered** (`first_aid_administered`)
* This field is to describe in detail the first aid administered.
* Please be as detailed as possible.

### 11. **Incident Status** (`incident_status`)
* This field is to select the status of the incident.
* Please select the correct status from the list provided.

### 12. **Incident Date** (`incident_date`)
* This field is for the date of the incident.
* Please ensure that you select the correct date.

### 13. **Staff Contact Name** (`staff_contact_name`)
* This field is for the name of the staff contact.
* Please ensure that you fill out this field if you are reporting the incident to staff.

### 14. **Staff Contact Phone** (`staff_contact_phone`)
* This field is for the phone number of the staff contact.
* Please ensure that you fill out this field if you are reporting the incident to staff.

### 15. **Staff Contact Email** (`staff_contact_email`)
* This field is for the email of the staff contact.
* Please ensure that you fill out this field if you are reporting the incident to staff.

### 16. **Incident Reported By** (`incident_reported_by`)
* This field is a place to write who reported the incident.
* Please ensure that you fill out this field accurately.

### 17. **Staff** (`incident_reported_by_name`)
* This field is to select the category of the person who reported the incident.
* Please select the correct category from the list provided.

## Tips
* Please ensure that you have filled out all the required fields before submitting the form.
* If you have any doubts or issues, please contact the staff for assistance.
* You can submit the form multiple times if the incident status changes or if you have more information to add.
