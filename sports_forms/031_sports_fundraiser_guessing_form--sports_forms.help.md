# Sports Fundraiser Guessing Form - Help Guide
## Purpose
The sports fundraiser guessing form is used to submit entries with donor information and team manager details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Entry Donor fields with the relevant information.
2. Enter the amount and points for the entry.
3. Add any comments for the entry.
4. Provide the team manager's information.
5. Enter the team points and comments.
6. Set the score entry.
7. Select the donation type.
8. Set the donation amount.
9. Set the date and time submitted.

## Field-by-Field Explanation
* **Entry Donor** (`entry_donor`, `text`, optional): Enter the name of the donor who submitted the entry.
* **Entry Amount** (`entry_amount`, `number`, optional): Enter the amount of the donation.
* **Entry Points** (`entry_points`, `number`, optional): Enter the points scored by the entry.
* **Entry Comments** (`entry_comments`, `text`, optional): Add any comments for the entry.
* **Team Manager** (`team_manager`, `text`, optional): Enter the name of the team manager.
* **Team Manager Email** (`team_manager_email`, `email`, optional): Enter the email of the team manager.
* **Team Manager Phone** (`team_manager_phone`, `text`, optional): Enter the phone number of the team manager.
* **Donation Type** (`donation_type`, `select_one`, optional): Select the type of donation (Cash, Check, Other).
* **Donation Amount** (`donation_amount`, `number`, optional): Enter the amount of the donation.
* **Date Submitted** (`date_submitted`, `date`, optional): Set the date the entry was submitted.
* **Time Submitted** (`time_submitted`, `time`, optional): Set the time the entry was submitted.
* **Entry Donor Organisation** (`entry_donor_organisation`, `text`, optional): Enter the organisation of the donor.
* **Score Entry** (`score_entry`, `number`, optional): Set the score entry.
* **Prediction Score** (`prediction_score`, `number`, optional): Set the prediction score.
* **Team Points Score** (`team_points_score`, `number`, optional): Set the team points score.
