# Football Pick Submission Form - Help Guide
## Purpose
The Football Pick Submission Form is designed for users to submit their football picks, including game IDs, pick types, and scores for both home and away teams.

## How To Complete This Form
To complete this form, follow these steps:

1. **Game ID**: Enter the unique identifier for the game you're submitting a pick for.
2. Choose the **Pick Type**: Select "Home" or "Away" to indicate which team you're choosing.
3. **Points Home** and **Points Away**: Enter the scores for both the home and away teams.
4. **Score Home** and **Score Away**: Enter the final scores for both the home and away teams.
5. **Pick ID**: Enter the unique identifier for your pick.
6. **Submitter ID**: Enter the unique identifier for the user submitting the pick.
7. **Submitter IP**: Optional field for tracking the submitter's IP address.
8. **Submitter User Agent**: Optional field for tracking the submitter's user agent string.
9. **Submitter OS**: Optional field for tracking the submitter's operating system.
10. **Submitter Browser**: Optional field for tracking the submitter's browser type.
11. **Submitter Time Zone**: Optional field for tracking the submitter's time zone.
12. **Submitter Language**: Optional field for tracking the submitter's language.
13. **Submitter Country**: Optional field for tracking the submitter's country.
14. **Submitter IP Location**: Optional field for tracking the submitter's IP location.
15. **Submitter IP Organization**: Optional field for tracking the submitter's IP organization.
16. **Submitter IP ISP**: Optional field for tracking the submitter's IP ISP.
17. **Submitter IP Area**: Optional field for tracking the submitter's IP area.
18. **Submitter IP City**: Optional field for tracking the submitter's IP city.
19. **Submitter IP Region**: Optional field for tracking the submitter's IP region.

## Field-by-Field Explanation
* **Game ID**: A unique identifier for the game you're submitting a pick for.
* **Pick Type**: Choose "Home" or "Away" to indicate which team you're choosing.
* **Points Home**: Enter the score for the home team.
* **Points Away**: Enter the score for the away team.
* **Score Home**: Enter the final score for the home team.
* **Score Away**: Enter the final score for the away team.
* **Pick ID**: A unique identifier for your pick.
* **Submitter ID**: A unique identifier for the user submitting the pick.
* **Created At**: The date and time the pick was submitted.
* **Updated At**: The date and time the pick was last updated.
* **Deleted At**: The date and time the pick was deleted (if applicable).
* **Deleted By**: The user ID of the user who deleted the pick (if applicable).
* **Submitter IP**: Optional field for tracking the submitter's IP address.
