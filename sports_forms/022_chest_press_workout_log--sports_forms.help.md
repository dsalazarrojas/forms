# Chest Press Workout Log - Help Guide
## Purpose
The Chest Press Workout Log is a form designed to help athletes track their chest press workouts, including exercise variations, body position, weight used, number of reps, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the athlete's name and ID (if applicable).
2. Select the workout date and time.
3. Choose the exercise variation and body position used during the workout.
4. Enter the weight used for each set and the number of reps completed.
5. Rate the perceived difficulty of the workout and assess the muscle soreness or fatigue experienced.
6. Evaluate the form quality of the workout.
7. Add any additional notes or observations about the workout.

## Field-by-Field Explanation

* **-- Chest Press Workout Log -- (workout_intro)**: This field is a placeholder for the form title. You can ignore it or leave it blank.
* **Athlete name (athlete_name)**: Enter the name of the athlete performing the workout.
* **Athlete ID (athlete_id)**: Enter the athlete's ID (if applicable).
* **Workout date (workout_date)**: Select the date of the workout.
* **Workout time (workout_time)**: Select the time of the workout.
* **Coach or trainer name (coach_name)**: Enter the name of the coach or trainer (if applicable).
* **Workout duration (workout_duration)**: Enter the duration of the workout in minutes.
* **Chest press variation (exercise_variation)**: Select the type of exercise variation used during the workout (e.g., barbell, dumbbell, machine press, etc.).
* **Body position (body_position)**: Select the body position used during the workout (e.g., flat bench, incline bench, decline bench, etc.).
* **Set 1 - Weight used (set_1_weight)**: Enter the weight used for the first set of the workout.
* **Set 1 - Number of reps (set_1_reps)**: Enter the number of reps completed for the first set of the workout.
* **Set 2 - Weight used (set_2_weight)**: Enter the weight used for the second set of the workout.
* **Set 2 - Number of reps (set_2_reps)**: Enter the number of reps completed for the second set of the workout.
* **Set 3 - Weight used (set_3_weight)**: Enter the weight used for the third set of the workout.
* **Set 3 - Number of reps (set_3_reps)**: Enter the number of reps completed for the third set of the workout.
* **Set 4 - Weight used (set_4_weight)**: Enter the weight used for the fourth set of the workout (if applicable).
* **Set 4 - Number of reps (set_4_reps)**: Enter the number of reps completed for the fourth set of the workout (if applicable).
* **Set 5 - Weight used (set_5_weight)**: Enter the weight used for the fifth set of the workout (if applicable).
* **Set 5 - Number of reps (set_5_reps)**: Enter the number of reps completed for the fifth set of the workout (if applicable).
* **Weight unit (weight_unit)**: Select the unit of weight measurement used (e.g., pounds, kilograms, etc.).
* **Perceived difficulty of workout (perceived_difficulty)**: Rate the perceived difficulty of the workout on a scale from 1 to 10.
* **Muscle soreness or fatigue (muscle_soreness)**: Rate the muscle soreness or fatigue experienced after the workout.
* **Form quality assessment (form_quality)**: Evaluate the form quality of the workout.
* **Additional notes or observations (notes_observations)**: Enter any additional notes or observations about the workout.
