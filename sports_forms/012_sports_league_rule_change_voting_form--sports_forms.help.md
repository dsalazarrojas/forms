# Sports League Rule Change Voting Form - Help Guide
## Purpose
The Sports League Rule Change Voting Form is designed to gather feedback and votes from participants on proposed rule changes. This form will help the Sports League collect data and feedback, ensuring that any future changes are well-informed and beneficial to all.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the proposed Rule Change Proposals.
2. Select all that apply under Proposal Details by choosing from the dropdown menu.
3. Select one option for Proposal Votes and Participant Details.
4. Provide feedback in the text field if you wish.

## Field-by-Field Explanation
- **Title (Main Page)**: This field displays the form's title and instructions.
- **Proposal Details (Proposal Details)**: This field allows you to choose all that apply from the list of proposed rule change proposals. Select all that apply.
  - This is a multi-select field, so you can choose multiple options.
  - You can select from the list of options provided.
  - If you don't see an option, please let us know and we'll add it to the list!
- **Proposal Votes (Proposal Votes)**: This field is for voting on the proposals.
  - Choose one option: Yes or No.
  - This is a single-select field, so you can only choose one option.
- **Participant Details (Participant Details)**: This field is for voting on participation.
  - Choose one option: Yes or No.
  - This is a single-select field, so you can only choose one option.
- **Feedback (Feedback)**: This field is for providing any additional feedback or comments.
  - Enter your thoughts, suggestions, or concerns.
  - We value your feedback and look forward to hearing from you!
- **Submit Feedback (Submit Feedback)**: This is a text box for you to write your feedback.

## Tips
- Please provide your honest feedback and opinions on proposed rule changes.
- You can select all or none of the options under Proposal Details.
- Make sure to choose only one option for Proposal Votes and Participant Details.
- Your feedback is confidential and will be used to improve the Sports League.
