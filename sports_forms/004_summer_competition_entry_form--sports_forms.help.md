# Summer Competition Entry Form - Help Guide
## Purpose
This form is used to register users and their teams for a summer competition. It collects necessary information about the competition, events, and user details.

## How To Complete This Form

1. Fill out all the required fields.
2. Choose your events from the provided options.
3. Provide your competition date.
4. Agree to the terms and conditions.

## Field-by-Field Explanation

* **Competition Details**:
	+ Type: Text
	+ This field is where you can enter any additional information about the competition that is not covered by the other fields.
* **Event 1**:
	+ Type: Select One
	+ Choose the first event you would like to participate in.
* **Event 2**:
	+ Type: Select One
	+ Choose the second event you would like to participate in.
* **Competition Date**:
	+ Type: Date
	+ Enter the date of the competition.
* **Consent to Terms and Conditions**:
	+ Type: Text
	+ Please enter 'yes' to agree to the terms and conditions.
* **Terms and Conditions**:
	+ Type: Note
	+ This field is a copy of the terms and conditions, please read and review before proceeding.

## Tips
* Make sure to fill out all required fields correctly.
* Ensure you have the correct information for each event.
* Review the terms and conditions carefully before agreeing.
