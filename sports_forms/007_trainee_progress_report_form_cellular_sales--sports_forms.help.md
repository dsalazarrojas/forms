# Trainee Progress Report Form Cellular Sales - Help Guide
## Purpose
This form is used to collect feedback on trainees' progress in cellular sales, focusing on soft skills and behavioral aspects.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each section carefully and answer each question honestly.
2. Select the most appropriate option for each field.
3. Provide detailed comments in the 'Form Comments' section if you have any additional feedback.

## Field-by-Field Explanation
* **Trainee Progress Report Form Cellular Sales** (`form_title`, text, optional): Enter a brief description or reference number for the trainee's progress report.
* **Communication** (`communication`, select_one, optional): Rate the trainee's communication skills as:
	+ Excellent
	+ Good
	+ Average
	+ Poor
* **Time Management** (`time_management`, select_one, optional): Rate the trainee's time management skills as:
	+ Good
	+ Average
	+ Poor
	+ No Answer
* **Skills Set** (`skills_set`, select_one, optional): Rate the trainee's skills set as:
	+ Good
	+ Average
	+ Poor
	+ No Answer
* **Attitude** (`attitude`, select_one, optional): Rate the trainee's attitude as:
	+ Positive
	+ Neutral
	+ Negative
	+ No Answer
* **Work Knowledge** (`work_knowledge`, select_one, optional): Rate the trainee's work knowledge as:
	+ Good
	+ Average
	+ Poor
	+ No Answer
* **Overall Performance** (`overall_performance`, text, optional): Provide a brief summary of the trainee's overall performance.
* **Form Comments** (`form_comments`, text, optional): Enter any additional comments or feedback for the trainee.

## Tips
* Please answer each question honestly and accurately.
* Use the options provided to select the most appropriate rating for each field.
* Provide specific examples or anecdotes to support your feedback in the 'Form Comments' section.
* This form is intended for soft skills and behavioral assessment, not technical skills evaluation.
