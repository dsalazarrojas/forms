# icc_cricket_world_cup_legacy_facilities_fund - Help Guide
## Purpose
The icc_cricket_world_cup_legacy_facilities_fund form is used to gather information and data about legacy cricket facilities. This information helps in preserving and promoting the history of cricket.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the name of the facility.
2.  Enter the location of the facility.
3.  Enter the capacity of the facility.
4.  Enter a brief description of the facility.
5.  Upload an image of the facility (if available).
6.  Upload a supporting file (if applicable).
7.  Select the status of the facility (approved, rejected, or pending).

## Field-by-Field Explanation

* **Facilities Name (Facilities name)**: Enter the name of the facility, e.g., "Lord's Cricket Ground".
* **Facilities Location (Facilities location)**: Enter the location of the facility, e.g., "St John's Wood, London, England".
* **Facilities Capacity (Facilities capacity)**: Enter the capacity of the facility, e.g., "25,000".
* **Facilities Description (Facilities description)**: Enter a brief description of the facility, e.g., "Historic cricket ground with a rich history".
* **Facilities Image (Facilities image)**: Upload a relevant image of the facility, if available.
* **Facilities File (Facilities file)**: Upload a supporting file, if applicable (e.g., a scanned document).
* **Facilities Status (Facilities status)**: Select the status of the facility from the options: Facilities approved, Facilities rejected, or Facilities pending.
