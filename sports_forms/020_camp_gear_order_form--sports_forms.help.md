# Camp Gear Order Form - Help Guide
## Purpose
This form is used to collect information for a camp gear order. The form is completed by the requester or on their behalf by a staff member.

## How To Complete This Form
1. Fill out the form with the following information:
	* Requester Name: Enter the name of the person placing the order.
	* Organization Name: Enter the name of the organization placing the order (if applicable).
	* Item SKU or Description: Enter the specific item to be ordered.
	* Quantity: Enter the number of units to be ordered.
	* Size Options: Select the size of the item if it is applicable (e.g. Small, Medium, Large, XL).
	* Delivery Address: Enter the address where the order should be shipped.
	* Billing Information: Enter the PO number or billing account (if applicable).
	* Required By Date: Enter the date the gear is needed by.
	* Approval Status: Select the internal approval status for the order (Pending, Approved, Denied).
	* Special Instructions: Enter any additional instructions for fulfillment.

## Field-by-Field Explanation
* **Requester Name** (required): The name of the person placing the order.
* **Organization Name** (optional): The name of the organization placing the order (if applicable).
* **Item SKU or Description** (required): The specific item to be ordered, or a descriptive title if the SKU is not known.
* **Quantity** (required): The number of units to be ordered.
* **Size Options** (optional): Select the size of the item if it is applicable (e.g. Small, Medium, Large, XL).
* **Delivery Address** (required): The address where the order should be shipped.
* **Billing Information** (optional): The PO number or billing account (if applicable).
* **Required By Date** (optional): The date the gear is needed by.
* **Approval Status** (required): Select the internal approval status for the order (Pending, Approved, Denied).
* **Special Instructions** (optional): Enter any additional instructions for fulfillment.
