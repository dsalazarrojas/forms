# League Event Credential Printing Order Form - Help Guide
## Purpose
This form is used to order printed credentials for a league event.

## How To Complete This Form

To complete this form, follow these steps:

1.  Select the type of credential you want to print by choosing from the dropdown menu.
2.  Enter the quantity of credentials you need to print.
3.  If you have any additional artwork you want to be printed on the credential, enter it in the "Artwork" field.
4.  If you have an artwork file to upload for printing, select it in the "Artwork File" field.
5.  Enter any additional information about the delivery of the credential in the "Delivery Details" field.
6.  Enter the address where the credential is to be delivered in the "Delivery Details Address" field.
7.  Enter the city where the credential is to be delivered in the "Delivery Details City" field.
8.  Enter the postal code where the credential is to be delivered in the "Delivery Details Postal Code" field.
9.  Enter the phone number where the credential can be contacted for delivery in the "Delivery Details Phone" field.

## Field-by-Field Explanation

*   **Credential Type**: This field is used to select the type of credential that needs to be printed. Choose from the dropdown menu the type of credential you want to print.
    *   **Credential Type Options**:
        +   Badge
        +   Pass
*   **Quantity**: This field is used to specify the number of credentials that needs to be printed.
*   **Artwork**: This field is used to enter any additional artwork that needs to be printed on the credential.
*   **Artwork File**: This field is used to upload any artwork that needs to be printed on the credential.
*   **Delivery Details**: This field is used to enter any additional information about the delivery of the credential.
*   **Delivery Details Address**: This field is used to enter the address where the credential is to be delivered.
*   **Delivery Details City**: This field is used to enter the city where the credential is to be delivered.
*   **Delivery Details Postal Code**: This field is used to enter the postal code where the credential is to be delivered.
*   **Delivery Details Phone**: This field is used to enter the phone number where the credential can be contacted for delivery.
