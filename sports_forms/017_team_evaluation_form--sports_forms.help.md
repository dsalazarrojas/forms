# Team Evaluation Form - Help Guide
## Purpose
The Team Evaluation Form is used to collect feedback and ratings from evaluators about a team's performance, player ratings, and overall team evaluation score.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information for the team, such as team name and team coach name.
2. Rate the coach and team using the numerical rating fields (e.g., Coach Rating, Team Evaluation Score).
3. Provide feedback on the player's performance, attitude, and communication using the text fields (e.g., Coach Comments, Player Comments).
4. Calculate the team's average score using the numerical fields (e.g., Team Total Score, Team Average Score).

## Field-by-Field Explanation

* **Team Name**: Enter the name of the team being evaluated.
	+ Type: text
	+ Required: false
* **Team Coach Name**: Enter the name of the team coach.
	+ Type: text
	+ Required: false
* **Team Coach Phone**: Enter the phone number of the team coach.
	+ Type: text
	+ Required: false
* **Team Coach Email**: Enter the email address of the team coach.
	+ Type: email
	+ Required: false
* **Coach Rating**: Rate the team coach's performance on a scale of 1-10.
	+ Type: number
	+ Required: false
* **Player Performance**: Provide feedback on the player's performance.
	+ Type: text
	+ Required: false
* **Player Attitude**: Provide feedback on the player's attitude.
	+ Type: text
	+ Required: false
* **Communication**: Provide feedback on the team's communication.
	+ Type: text
	+ Required: false
* **Teamwork**: Provide feedback on the team's teamwork.
	+ Type: text
	+ Required: false
* **Player Rating**: Rate the player's performance on a scale of 1-10.
	+ Type: number
	+ Required: false
* **Player Coach Rating**: Rate the player's coach rating on a scale of 1-10.
	+ Type: number
	+ Required: false
* **Player Rating Averange**: Calculate the average player rating.
	+ Type: number
	+ Required: false
* **Team Comments**: Provide additional comments about the team.
	+ Type: text
	+ Required: false
* **Player Comments**: Provide additional comments about the player.
	+ Type: text
	+ Required: false
* **Team Evaluation Score**: Rate the team's overall performance on a scale of 1-10.
	+ Type: number
	+ Required: false
* **Team Total Score**: Calculate the team's total score.
	+ Type: number
	+ Required: false
* **Team Average Score**: Calculate the team's average score.
	+ Type: number
	+ Required: false

Note: The team and player ratings can be calculated using the numerical fields provided. The coach and player comments can be used to provide additional feedback.
