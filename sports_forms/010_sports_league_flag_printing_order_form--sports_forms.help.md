# Sports League Flag Printing Order Form - Help Guide
## Purpose
This form is designed to help you place an order for printed flags for your sports league. Please provide the required information to ensure that your order is processed accurately and efficiently.

## How To Complete This Form
1. Read through each field carefully and fill in the required information.
2. Select the correct options from the dropdown menus where applicable.
3. Double-check your answers for accuracy before submitting the form.

## Field-by-Field Explanation

* **Order** (`order`, required): Select the type of order you would like to place. Choose from the options provided.
* **Flag Orders** (`flag_orders`, optional): Enter any additional flag orders you would like to make, if any.
* **Team** (`team`, required): Select the name of your sports team from the options provided.
* **Flag Design** (`flag_design`, optional): Describe the design you would like to have on your flag, if any.
* **Artwork** (`artwork`, optional): Provide any additional artwork or design information you would like to have on your flag.
* **Payments** (`payments`, optional): Enter any payment details, if applicable.
* **Custom Flag Orders** (`custom_flag_orders`, optional): Enter any custom flag orders you would like to make, if any.
* **Artwork Details** (`artwork_details`, optional): Describe any additional details about the artwork you would like to have on your flag.
* **Flag Color** (`flag_color`, required): Select the color(s) you would like to have on your flag. Choose from the options provided.
* **Flag Size** (`flag_size`, required): Select the size of your flag from the options provided.
* **Flag Material** (`flag_material`, required): Select the material you would like to use for your flag. Choose from the options provided.
* **Quantity** (`quantity`, required): Enter the number of flags you would like to order.
* **Artwork Size** (`artwork_size`, optional): Enter any additional size information for the artwork, if any.
* **Quantity** (`quantity-2`, required): Enter the number of flags with the selected artwork size.
* **Flag Color 2** (`flag_color2`, optional): Select the additional color(s) you would like to have on your flag. Choose from the options provided.
* **Team Color** (`team_color`, optional): Select the color(s) you would like to have on your team's flag. Choose from the options provided.
* **Team Flag Color** (`team-flag-color`, required): Select the color(s) you would like to have on your team's flag. Choose from the options provided.
* **Flag Size 2** (`flag_size2`, optional): Select the size of your flag from the options provided.
* **Artwork Flag Type** (`artwork_flag_type`, required): Select the type of artwork you would like to have on your flag. Choose from the options provided.
* **Team** (`team-name`, required): Select the name of your sports team from the options provided.
* **Artwork Type** (`artwork_type`, optional): Select the type of artwork you would like to have on your flag, if any.
* **Artwork Color** (`artwork_color`, optional): Select the color(s) you would like to have on your artwork. Choose from the options provided.
* **Flag Type** (`flag_type`, required): Select the type of flag you would like to order. Choose from the options provided.
* **Notes** (`notes`, optional): Enter any additional notes or comments about your order, if any.
