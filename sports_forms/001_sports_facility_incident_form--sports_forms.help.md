# sports_facility_incident_form - Help Guide

## Purpose
This form is designed to report and track incidents that occur within sports facilities. It helps facility staff to quickly gather information about each incident, which can then be used for incident management and improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Click on the "Incident Report" tab to begin filling out the form.
2. Fill out the required fields, marked with an asterisk (\*).
3. Provide as much detail as possible in each field to ensure accurate information is recorded.

## Field-by-Field Explanation

* **Incident Report (1)** (`note`, required/optional): This is the main section where you can describe the incident in detail.
* **Incident Date (2)** (`date`, required/optional): Enter the date the incident occurred.
* **Incident Time (3)** (`time`, required/optional): Enter the time the incident occurred.
* **Incident Location (4)** (`text`, required/optional): Enter the location where the incident occurred.
* **Incident Type (5)** (`select_one`, required/optional): Select the type of incident that occurred. Options: 'Yes', 'No'
* **Incident Description (6)** (`text`, required/optional): Describe the incident in as much detail as possible.
* **Injuries Reported (7)** (`select_multiple`, required/optional): Indicate if injuries were reported during the incident. Options: 'Yes', 'No'
* **Incident Cause (8)** (`text`, required/optional): Provide a brief explanation of the cause of the incident.
* **Incident Outcome (9)** (`select_one`, required/optional): Select the outcome of the incident. Options: 'Yes', 'No'
* **Incident Notes (10)** (`note`, required/optional): Add any additional notes about the incident.
* **Has the incident been responded to? (11)** (`select_one`, required/optional): Indicate if the incident has been responded to. Options: 'Yes', 'No'
* **Incident Status (12)** (`select_one`, required/optional): Select the status of the incident. Options: Active, Inactive
* **Incident Resolution (13)** (`select_one`, required/optional): Select if the incident has been resolved. Options: 'Yes', 'No'
