# zumba_in_the_park_registration_form - Help Guide
## Purpose
The purpose of this form is to collect information from participants for a Zumba event in the park.

## How To Complete This Form
1. Ensure you have all the required information ready before starting the form.
2. Fill out the form by following the explanations for each field below.

## Field-by-Field Explanation

* **Participant Name (Participant Name)** (`participant_name`, text, optional): Please enter your name as you would like to be referred to during the event.
* **Email Address (Email Address)** (`email_address`, email, optional): Enter your email address for communication and event updates.
* **Contact Number (Contact Number)** (`contact_number`, text, optional): Provide your contact number for any last-minute updates or coordination.
* **Event Date (Event Date)** (`event_date`, date, optional): Select the date of the event you'd like to participate in.
* **Event Time (Event Time)** (`event_time`, time, optional): Choose the time slot for the event you'd like to attend.
* **Event Location (Event Location)** (`event_location`, text, optional): Specify the desired event location, if different from the main park area.
* **Organization Name (Organization Name)** (`organization_name`, text, optional): If applicable, mention the organization you're representing or affiliated with.
* **Participant Notes (Participant Notes)** (`participant_notes`, note, optional): Add any additional comments or notes about your participation or preferences.

## Tips
* Please make sure to fill out all the required information accurately.
* Use the correct format for date and time fields.
* If you're unable to attend or need to change your preferences, kindly update your registration by revising the form.
