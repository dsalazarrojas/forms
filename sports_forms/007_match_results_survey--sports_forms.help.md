# Match Results Survey - Help Guide

## Purpose
The Match Results Survey form is designed to collect information about the outcome of a game or match. This form is intended for users to input details about the match, including the outcome, scores, and other relevant information.

## How To Complete This Form

To complete this form, follow these steps:

1.  Go to the Match Results Survey form.
2.  Select the correct match outcome (Win, Loss, or Tie) from the Match Score field.
3.  Input the game date in the Game Date field.
4.  Select the home and away teams from the Home Team and Away Team fields, respectively.
5.  Input the scores in the Match Score, Home Score, and Away Score fields.
6.  Select the match winner from the Winner field.
7.  Input the number of goals scored by each team in the Home Goals Scored and Away Goals Scored fields.
8.  Input the referee's name in the Referee field.
9.  Input the match venue in the Match Venue field.
10.  Select the match duration in the Match Duration field.
11.  Select the match type from the Match Type field.
12.  Input the game ID in the Game ID field.
13.  Select the creator of the match from the Created By field.
14.  Input any comments about the match in the Comments field.
15.  Input the updated-by information in the Updated By field.
16.  Input the creation date and time of the match in the Created At and Game Time fields, respectively.
17.  Input the match round in the Match Round field.
18.  Input any match outcome details in the Match Outcome Details field.

## Field-by-Field Explanation

*   **Match Outcome**: Select the outcome of the match (Win, Loss, or Tie).
*   **Game Date**: Input the date of the game or match.
*   **Home Team**: Select the team that played at home.
*   **Away Team**: Select the team that played away.
*   **Match Score**: Input the score of the match.
*   **Match Score**: Select the winner of the match (Home team, Away team, or Tie).
*   **Home Goals Scored**: Input the number of goals scored by the home team.
*   **Away Goals Scored**: Input the number of goals scored by the away team.
*   **Referee**: Input the name of the referee.
*   **Match Venue**: Input the location of the match.
*   **Match Duration**: Select the duration of the match.
*   **Match Type**: Select the type of match (Regular, Tiebreaker, or Overtime).
*   **Game ID**: Input the unique ID of the game.
*   **Created By**: Select the creator of the match.
*   **Comments**: Input any comments about the match.
*   **Updated By**: Select the person who updated the match information.
*   **Created At**: Input the date and time the match was created.
*   **Updated At**: Input the date and time the match was updated.
*   **Game Time**: Input the time of the match.
*   **Match Round**: Input the round of the match.
*   **Match Outcome Details**: Input any additional details about the match outcome.

## Tips

*   Make sure to input accurate and correct information to ensure that the match results are recorded correctly.
*   If you are unsure about any field, refer to your match notes or records for clarification.
*   Double-check your inputs before submitting the form to avoid errors.
*   If you need help or clarification, contact your administrator or support team.
