# sports_photography_pass_registration - Help Guide
## Purpose
This form is for registering sports photography events and capturing relevant details about them. The goal is to collect and organize necessary information to properly manage these events.

## How To Complete This Form

1. Fill out the form with the required information about the event.
2. Select the type of media used by the photographer.
3. Register or request a pass for the event.
4. Provide any additional event details or notes.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter a name for the event.
* **Event Description** (`event_description`, text, required): Briefly describe the event.
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Event Time** (`event_time`, time, required): Enter the time of the event.
* **Photographer Name** (`photographer_name`, text, required): Enter the name of the photographer.
* **Photographer Email** (`photographer_email`, email, required): Enter the email address of the photographer.
* **Organization Name** (`organization_name`, text, required): Enter the name of the organization hosting the event.
* **Contact Phone** (`contact_phone`, text, required): Enter the contact phone number of the event.
* **Photographer Media Type** (`photographer_media_type`, select_multiple, required): Select one or more types of media used by the photographer (still, action, video, social media, or none).
* **Photographer Pass** (`photographer_media_pass`, select_one, required): Select whether the photographer requires a pass for the event (true, false, or pending).
* **Event Details** (`event_details`, note, required): Enter any additional details about the event.
* **Event Notes** (`event_notes`, note, required): Enter any additional notes about the event.
* **Pass Request Reason** (`pass_request_reason`, text, required): Enter the reason for the pass request.
* **Pass Request Date** (`pass_request_date`, date, required): Enter the date of the pass request.
* **Pass Request Time** (`pass_request_time`, time, required): Enter the time of the pass request.
* **Pass Request Details** (`pass_request_details`, text, required): Enter any additional details about the pass request.
* **Pass Requestor Notes** (`pass_requestor_notes`, note, required): Enter any additional notes about the pass request.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter any information about the assigned tool (not required but useful for tracking purposes).

This guide explains the purpose and requirements of the sports_photography_pass_registration form.
