# Game Schedule Submission Form - Help Guide

## Purpose
The Game Schedule Submission Form is designed for users to submit schedules for games, events, or activities. This form helps to collect relevant information about the game, including the event date and time.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Game Schedule Form section with a detailed description of the game or event.
2. Select the Event Date for the game or event.
3. Choose the Event Time for the scheduled time of the event.

## Field-by-Field Explanation

* **Game Schedule Form (<code>schedule_form</code>, Text, Optional):** Enter a brief description of the game or event. This field is not required but helps provide additional context.
* **Event Date (<code>event_date</code>, Date, Optional):** Choose the date of the game or event.
* **Event Time (<code>event_time</code>, Time, Optional):** Select the scheduled time of the event.

## Tips
* Please ensure that you fill out all required fields to avoid errors.
* You can use the Game Schedule Form field to provide any necessary details about the game or event.
* If you have any issues or concerns while filling out this form, contact us at <form@gic.mx>.
