# Sports League Game Ball Supply Order Form - Help Guide
## Purpose
The Sports League Game Ball Supply Order Form is designed to collect information from end users for the order of sports league game balls. This form helps ensure that the correct quantity of balls is ordered and delivered on time to the right team or location.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the **Team Name** of the team requesting the ball supply.
2. Select the **Order Date** when the order should be fulfilled.
3. Input the **Number Ordered**, the quantity of balls needed.
4. If the order is for a **Team**, select "Yes". Otherwise, select "No".
5. If the order is for a **Specific Location**, select "Yes". Otherwise, select "No".

## Field-by-Field Explanation

* **Team Name** (`sports_league_game_ball_supply_form_team_name`, text, required/optional): Enter the name of the team requesting the ball supply.
* **Order Date** (`sports_league_game_ball_supply_form_order_date`, date, required/optional): Select the date when the order should be fulfilled.
* **Number Ordered** (`sports_league_game_ball_supply_form_number_ordered`, number, required/optional): Input the quantity of balls needed.
* **Team** (`sports_league_game_ball_supply_form_team`, select_one, required/optional): Select "Yes" if the order is for a team, otherwise select "No".
* **Location** (`sports_league_game_ball_supply_form_location`, select_one, required/optional): Select "Yes" if the order is for a specific location, otherwise select "No".

## Tips
* Please double-check the team name and location to ensure accuracy.
* Make sure to select the correct date and number of balls required.
* If you are unsure of any field, please contact the relevant team or authority for clarification.
