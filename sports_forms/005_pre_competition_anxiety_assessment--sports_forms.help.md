# Pre Competition Anxiety Assessment - Help Guide
## Purpose
The Pre-Competition Anxiety Assessment form helps athletes evaluate their mental state before an event. By completing this form, athletes can gain a better understanding of their anxiety levels and the factors contributing to them.

## How To Complete This Form
To complete this form, follow these steps:

1. For each question, select the most accurate response or provide the necessary information.
2. Make sure to fill out all required fields, denoted by an asterisk (\*).

## Field-by-Field Explanation
### Pre-Competition Anxiety Assessment
* **Pre-Competition Anxiety Assessment** (`pre_competition_anxiety_assessment`, `select_one`, required): Check if you are feeling anxious before the competition. Select 'Yes' if you are feeling anxious, and 'No' if you are not.

### Athlete Name
* **Athlete Name** (`athlete_name`, `text`, required): Enter your name as it appears on your athlete ID.

### Athlete ID
* **Athlete ID** (`athlete_id`, `number`, required): Enter your athlete ID number.

### Event Name
* **Event Name** (`event_name`, `select_multiple`, not required): If this event is part of a series, select all the events you will be competing in. If this is a one-off event, select 'Yes'.

### Event Description
* **Event Description** (`event_description`, `text`, not required): Provide a brief description of the event, if applicable.

### Date and Time of Event
* **Date and Time of Event** (`date_and_time_of_event`, `date`, required): Enter the date and start time of the competition.

### Score
* **Score** (`score`, `number`, required): Enter your current competition score.

### Pre-Game Anxiety Level
* **Pre-Game Anxiety Level** (`pre_game_anxiety_level`, `select_one`, not required): Select your level of anxiety before the game. Choose from High, Low, or Medium.

### Anxiety Level Reasons
* **Anxiety Level Reasons** (`anxiety_level_reasons`, `select_multiple`, not required): If you selected 'High' for Pre-Game Anxiety Level, list the reasons for your anxiety.

## Tips
* Make sure to complete the form honestly and accurately, as this will help you and your team better understand your mental state.
* If you're feeling anxious, take steps to address these concerns to improve your performance.
