# What Sport Brings You Passion? What Sports Do You Preffer/ Like To Do - Help Guide
## Purpose
This form is designed to help us understand your interests and preferences in sports. Please answer the questions honestly, and let us know if you have any other sports that you're passionate about that are not listed.

## How To Complete This Form
To complete this form, simply fill out each section with your answers. You can type in your responses for the "what_sports_do_you_prefer" field, and select the sports that apply to you in the "which_sports_do_you_prefer" and "which_sports_do_you_like_to_do" fields.

## Field-by-Field Explanation

* **What Sports Do You Prefer** (`what_sports_do_you_prefer`, text, optional): This is a text field where you can type in the sports that bring you passion. You can type as many sports as you'd like, one per line. For example, you can type "Soccer", "Basketball", and "Tennis" if those are the sports that bring you the most passion.
* **Which Sports Do You Prefer?** (`which_sports_do_you_prefer`, select_multiple, optional): In this field, you can select all the sports that bring you passion. You can select multiple sports, but please avoid selecting the same sport multiple times. You can select from the following options: Soccer, Football, Basketball, and Baseball.
* **Which Sports Do You Like To Do?** (`which_sports_do_you_like_to_do`, select_one, optional): In this field, you can select only one sport that you like to do. You can select from the following options: Soccer, Football, Basketball, Baseball, and Tennis.
* **Other Sports** (`other_sports`, text, optional): If there's a sport that you're passionate about that's not listed, please type it in here.
* **Other** (`other`, select_multiple, optional): If you don't like any of the sports listed, or have any other preferences, please select "Yes" if you have other preferences. Otherwise, select "No".
