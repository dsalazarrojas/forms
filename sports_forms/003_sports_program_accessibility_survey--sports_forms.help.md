# Sports Program Accessibility Survey - Help Guide
## Purpose
The Sports Program Accessibility Survey is a form designed to gather information on accessibility features and tools for sports programs, including clubs, schools, and community recreation teams.

## How To Complete This Form
To complete this form, follow the steps below:
1. Enter the title of the survey in the text field.
2. Select the relevant category for your sports program (sports clubs, schools, or community recreation teams).
3. Provide a brief description of your sports program.
4. Choose the tools assigned to your program (chatjimmy or jotform).
5. Select the file path where you would like to save the output.
6. Select the IDs of any other forms you would like to associate with your program (optional).
7. Enter any additional description (optional).

## Field-by-Field Explanation
* **Title**: `sports_program_accessibility_survey` (text)
	+ Enter the title of your sports program survey.
* **Category**: `sports_forms` (select_one)
	+ Select the category that best describes your sports program (sports clubs, schools, or community recreation teams).
* **Description**: `description` (text)
	+ Enter a brief description of your sports program.
* **Assigned Tool**: `assigned_tool` (select_one)
	+ Choose the tool assigned to your sports program (chatjimmy or jotform).
* **Output File Path**: `output_file_path` (text)
	+ Enter the file path where you would like to save the output.
* **Form IDs**: `form_ids` (select_multiple)
	+ Select the IDs of any other forms you would like to associate with your program (optional).
* **Additional Description**: `description` (text)
	+ Enter any additional description for your sports program (optional).
* **Category**: `category` (text)
	+ Enter the category for your sports program (this is not the same as the category in step 2, this is an additional category field).
 
## Tips
* Please ensure that all fields are filled in accurately to ensure the information gathered is correct and useful.
* If you are unsure of any field, please reach out to the relevant authority for clarification.
