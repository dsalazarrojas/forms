# ski_lesson_sign_in_form - Help Guide

## Purpose
This form is used to sign children up for ski lessons, collecting information from parents or guardians, and instructor details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required information in each field.
2. Make sure to complete all required fields.
3. Review your input carefully before submitting the form.

## Field-by-Field Explanation

* **lesson_details**:
	+ Label: lesson_details
	+ Type: text
	+ Required: false
	+ Explain: Please provide a brief description of the lessons the child will be taking.
* **parent_info**:
	+ Label: parent_info
	+ Type: text
	+ Required: true
	+ Explain: Enter the parent or guardian's name.
* **first_name**:
	+ Label: first_name
	+ Type: text
	+ Required: true
	+ Explain: Enter the parent or guardian's first name.
* **last_name**:
	+ Label: last_name
	+ Type: text
	+ Required: true
	+ Explain: Enter the parent or guardian's last name.
* **email**:
	+ Label: email
	+ Type: email
	+ Required: true
	+ Explain: Enter the parent or guardian's email address.
* **ski_date**:
	+ Label: ski_date
	+ Type: date
	+ Required: true
	+ Explain: Select the date of the lesson.
* **rental_info**:
	+ Label: rental_info
	+ Type: text
	+ Required: false
	+ Explain: If the child requires rental equipment, provide the type and size.
* **equipment**:
	+ Label: equipment
	+ Type: select_multiple
	+ Required: true
	+ Explain: Select the equipment the child will be using: skis, boots, or helmet.
* **instructor_info**:
	+ Label: instructor_info
	+ Type: text
	+ Required: true
	+ Explain: Enter the instructor's name.
* **lesson_time**:
	+ Label: lesson_time
	+ Type: time
	+ Required: true
	+ Explain: Select the time of the lesson.
* **lesson_duration**:
	+ Label: lesson_duration

* **lesson_cost**:
	+ Label: lesson_cost

* **lesson_notes**:
	+ Label: lesson_notes
	+ Type: note

* **submitter_info**:
	+ Label: submitter_info
	+ Type: text
	+ Required: true

	+ Required: true

* **submitter_email**:
	+ Label: submitter_email
	+ Type: email
	+ Required: true

* **submitter_notes**:
	+ Label: submitter_notes
	+ Type: note
