# Sports Event Preparation Checklist Form - Help Guide
## Purpose
This form is designed to gather essential information from event staff before a sports event. Please complete this form to ensure that all necessary arrangements have been made and that the event runs smoothly.

## How To Complete This Form
1. The form consists of multiple pages. Please select the first page "Event Details" and start by providing a brief description of the event.
2. Proceed to the second page "Event Staff" and list all the people responsible for the event, including their names, positions, and contact numbers.
3. In the third and final page "Additional Information", include any other details not covered in the first two pages.

## Field-by-Field Explanation

### Event Details
* **Event Description** (`_name_`, `text`, optional): Briefly describe the event, including its type, date, time, and location.
* **Event Date and Time** (`_type_`, `text`, optional): Provide the event date and time in the format "YYYY-MM-DD HH:MM:SS".
* **Event Location** (`_type_`, `text`, optional): Specify the event location, including the venue and address.

### Event Staff
* **Staff Name** (`_name_`, `text`, required): List the names of all event staff, including event managers, security personnel, and other essential personnel.
* **Staff Position** (`_type_`, `text`, optional): Specify the position or role of each staff member.
* **Contact Number** (`_type_`, `text`, optional): Provide a contact number for each staff member.

### Additional Information
* **Any Other Information** (`_name_`, `text`, optional): Include any additional details not covered in the previous pages, such as weather conditions or special equipment needed.

## Tips
* Please make sure to fill in all required fields (indicated by `required: true` in each field).
* If a field is optional, you can leave it blank or provide additional information if needed.
* This form is not affiliated with any particular platform, so the data collected will not be linked to any external account or database.
