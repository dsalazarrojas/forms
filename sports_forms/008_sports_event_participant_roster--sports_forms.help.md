# sports-event-participant-roster - Help Guide
## Purpose
This form is used to collect information about a sports event participant.

## How To Complete This Form
1. Enter the participant's name in the **Participant Name** field.
2. Enter the participant's email address in the **Participant Email** field.
3. Enter the participant's phone number in the **Participant Phone** field.
4. Enter the participant's date of birth in the **Date of Birth** field using the MM/DD/YY format.
5. Select the participant's country of origin from the **Participant Country** drop-down menu.
6. Choose the participant's relationship to the event from the **Participant Relationship** multi-select menu (e.g., Team Player, Team Staff, Spectator).
7. Enter the name of the event in the **Event Name** field.
8. Enter the start date of the event in the **Start Date** field using the MM/DD/YY format.
9. Enter the start time of the event in the **Start Time** field using the HH:MM format.
10. Select the type of event from the **Event Type** drop-down menu (e.g., Football, Baseball, Basketball, Soccer).
11. Enter the location of the event in the **Event Location** field.
12. (Optional) Enter a brief description of the event in the **Event Description** field.
13. Choose who submitted the participant information from the **Participant Submitter** drop-down menu (e.g., Submitter, Participant, Organizer).
14. (Optional) Enter the date the participant's information was submitted in the **Submission Date** field.

## Field-by-Field Explanation
* **Participant Name**: Enter the name of the participant (e.g., John Doe).
* **Participant Email**: Enter the participant's email address (e.g., johndoe@example.com).
* **Participant Phone**: Enter the participant's phone number (e.g., 123-456-7890).
* **Date of Birth**: Enter the participant's date of birth in the MM/DD/YY format (e.g., 01/01/1990).
* **Participant Country**: Select the participant's country of origin from the drop-down menu.
* **Participant Relationship**: Choose the participant's relationship to the event from the multi-select menu (e.g., Team Player, Team Staff, Spectator).
* **Event Name**: Enter the name of the event (e.g., Super Bowl 2023).
* **Start Date**: Enter the start date of the event in the MM/DD/YY format (e.g., 01/01/2023).
* **Start Time**: Enter the start time of the event in the HH:MM format (e.g., 13:00).
* **Event Type**: Select the type of event from the drop-down menu (e.g., Football, Baseball, Basketball, Soccer).
* **Event Location**: Enter the location of the event (e.g., MetLife Stadium).
* **Event Description**: (Optional) Enter a brief description of the event.
* **Participant Submitter**: Choose who submitted the participant information from the drop-down menu (e.g., Submitter, Participant, Organizer).
* **Submission Date**: (Optional) Enter the date the participant's information was submitted.

## Tips
- Double-check that all required fields are completed before submitting the form.
- Ensure that the participant's date of birth is entered in the correct format (MM/DD/YY).
- If you are unsure about any of the fields, refer back to this help guide for clarification.
