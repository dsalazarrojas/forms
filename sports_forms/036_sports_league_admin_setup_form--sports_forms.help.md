# sports_league_admin_setup_form - Help Guide
## Purpose
This form is used to set up a new sports league on the platform. It collects essential information to create a league with the correct settings and rules.
## How To Complete This Form
### Step 1: Select the League Type
Fill out the "league_type" field by selecting one of the following options:
* Soccer
* Basketball
* Football

### Step 2: Define the League Settings
- Select the scoring system by choosing between "Default" and "Custom".
- Set the game duration (if required).
- Set the game start time (if required).
- Set the game end time (if required).

### Field-by-Field Explanation
- **league_name** (`league_name`, text, required/optional): Enter the name of the league. This will be the title of your sports league.
- **league_type** (`league_type`, select_multiple, required): Choose one of the following options: Soccer, Basketball, or Football. This will determine the type of sports league you are setting up.
- **league_address** (`league_address`, text, required/optional): Enter the address of the league. This can be a physical address or a website URL.
- **contact_email** (`contact_email`, email, required/optional): Enter the email address of the contact person for the league. This will be used for communication and support purposes.
- **contact_phone** (`contact_phone`, text, required/optional): Enter the phone number of the contact person for the league. This will be used for emergency contact purposes.
- **league_rules** (`league_rules`, text, required/optional): Enter any specific rules or regulations for the league. This will help other users understand how to play and participate.
- **scoring_system** (`scoring_system`, select_one, required): Choose between "Default" and "Custom" to select the scoring system for the league.
- **game_duration** (`game_duration`, time, required/optional): Enter the duration of each game in the league. This will help with scheduling and game length.
- **game_start_time** (`game_start_time`, date, required/optional): Enter the start date of the first game in the league. This will help with scheduling and game planning.
- **game_end_time** (`game_end_time`, time, required/optional): Enter the end date of each game in the league. This will help with game duration and scheduling.

## Tips
* Make sure to fill out all required fields accurately and completely.
* Double-check the scoring system and game settings before submitting the form.
* If you need help or have questions, contact the support team for assistance.
