# Virtual Class Attendance Form - Help Guide
## Purpose
The Virtual Class Attendance Form is used by students to report their attendance for virtual classes. This form helps maintain accurate and up-to-date records of student attendance.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Fill in the student's name.
2. Provide the date of attendance.
3. Choose a relevant status (Present, Absent, Late, Leave).
4. Optionally, specify the location where the student attended from (e.g., home, library, etc.).
5. Add any additional comments about the student's attendance.
6. Optionally, enter the teacher's name, which can be useful for teacher verification.
7. Enter the form ID for internal reference, if provided.

## Field-by-Field Explanation
* **Student Name** (`student_name`, text, optional): Enter your name as a student.
* **Attendance Date** (`attendance_date`, date, optional): The date of attendance.
* **Attendance Time** (`attendance_time`, time, optional): The time of attendance.
* **Student Status** (`student_status`, select_one, required): Choose whether you were Present, Absent, Late, or took Leave.
* **Attendance Location** (`attendance_location`, text, optional): Specify the location where you attended the class, if applicable.
* **Comments** (`comments`, text, optional): Add any additional comments about your attendance.
* **Teacher Name** (`teacher_name`, text, optional): Enter the name of the teacher, which can be verified for accuracy.
* **Form ID** (`form_id`, number, optional): The unique ID for this form entry, if provided.

## Tips
* Be sure to fill in the student status accurately to ensure that attendance records are accurate.
* If you're unsure about the attendance location, it's okay to leave it blank.
* If you have any comments about your attendance, use this field to provide more context.
* The teacher name field is optional, but it can be helpful to ensure that the teacher verifies the form entry.
