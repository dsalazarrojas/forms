# Homework Record Form - Help Guide
## Purpose
The purpose of this form is to record and track students' homework submissions.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form with your student ID and other relevant details.
* If you have submitted an assignment, select "Yes" or "No" for the "Submitted" field.
* If you have submitted an assignment, select the "Active" or "Inactive" status for your current homework record.
* Fill out any other required or optional fields as needed.

## Field-by-Field Explanation
* **Student Id (1)**: Enter your unique student ID number.
* **Assignment Id (2)**: Enter the ID of the assignment you are submitting.
* **Grade (3)**: Enter your grade for the assignment, if applicable.
* **Due Date (4)**: Enter the due date of the assignment.
* **Submitted Date (5)**: Enter the date you submitted the assignment.
* **Note (6)**: Add any relevant notes about your submission.
* **Submitted By (7)**: Enter the time you submitted the assignment.
* **Submitted User Id (8)**: Enter your ID as the user who submitted the assignment.
* **Submitted By User (9)**: Enter your email address as the user who submitted the assignment.
* **Status (10)**: Select "Active" if you are currently working on the assignment, or "Inactive" if you are not.
* **Submitted (11)**: Select "Yes" if you have submitted the assignment, or "No" if you have not.
