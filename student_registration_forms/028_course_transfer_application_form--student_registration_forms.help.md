# Course Transfer Application Form - Help Guide
## Purpose
This form is for students who wish to transfer from one course to another. It is used to gather information necessary for departmental and academic approval of the transfer request.

## How To Complete This Form
1. Fill out each page of the form carefully and completely.
2. Ensure all required fields are filled out.
3. Review each field explanation below for specific instructions on how to complete the form.

## Field-by-Field Explanation

* **Personal Details** (`personal_details`, text, optional): This section is used to gather personal contact information for the student.
* **Student Information** (`student_details`, number, required): This is a numerical value that represents the student's student number.
* **Course Information** (`course_info`, select_multiple, required): Select all courses you wish to transfer to. Please select each course that applies.
* **Reason for Transfer** (`reason_for_transfer`, text, required): Please explain why you are requesting a course transfer.
* **Contact Information** (`contact_info`, email, optional): This is the email address of the student or advisor.
* **Signature** (`signature`, note, optional): This is an optional signature line for advisors or students.
* **Student Signature** (`student_signature`, date, optional): This is an optional date field for the student's signature.
* **Advisor Signature** (`advisor_signature`, time, optional): This is an optional time field for advisor's signature.
* **Department** (`department`, select_one, required): Select the department for which you are applying for course transfer.
* **Program** (`program`, select_one, required): Select the program under which you are transferring.
* **Academic Level** (`academic_level`, select_one, required): Select the academic level at which you are transferring.
* **Academic Program** (`academic_program`, select_one, required): Select the academic program you are transferring into.
* **Date of Transfer** (`date_of_transfer`, date, required): Enter the date you wish to start the transfer.
* **Time of Transfer** (`time_of_transfer`, time, required): Enter the time you wish to start the transfer.
* **Course Transfer Status** (`course_transfer_status`, text, optional): This is an optional field for course transfer status.
* **Transfer Comments** (`transfer_comments`, text, optional): This is an optional field for transfer comments.
* **Transfer Recommendations** (`transfer_recommendations`, text, optional): This is an optional field for transfer recommendations.
* **Department Approval** (`department_approval`, select_one, required): Select departmental approval for your transfer request.
* **Academic Approval** (`academic_approval`, select_one, required): Select academic approval for your transfer request.
* **Transfer Confirmation** (`course_transfer_confirmation`, text, optional): This is an optional field for transfer confirmation.
* **Advisor Approval Comment** (`advisor_approval_comment`, text, optional): This is an optional field for advisor approval comment.
* **Departmental Transfer Request** (`departmental_transfer_request`, text, optional): This is an optional field for departmental transfer request.
* **Transfer Request Reason** (`transfer_request_reason`, text, optional): This is an optional field for transfer reason.
* **Student Acknowledgement** (`student_acknowledgement`, text, optional): This is an optional field for student acknowledgement.
* **Final Transfer Decision** (`final_transfer_decision`, select_one, required): Select final transfer decision.
