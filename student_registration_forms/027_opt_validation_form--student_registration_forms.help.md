# Opt Validation Form - Help Guide

## Purpose
The Opt Validation Form is used to collect and validate student information for various purposes, such as student registration, course enrollment, or other academic-related tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all required fields with accurate and complete information.
2. For fields with select_one type, select the relevant option from the dropdown menu.
3. For date fields, enter the date in the correct format (YYYY-MM-DD).
4. For fields with no specific instructions, fill in the information as accurately as possible.
5. Double-check for duplicate entries and ensure all fields are filled in correctly.

## Field-by-Field Explanation
- **Student Information**: This field is a text box where you can fill in any relevant student information not covered by other fields.
  - Student Information (`student_information`, text, optional): Enter any relevant student information not covered by other fields.
- **Student ID**: This field is for entering a unique student ID number.
  - Student ID (`student_id`, number, optional): A unique student ID number.
- **Date of Birth**: Enter the student's date of birth in the correct format (YYYY-MM-DD).
  - Date of Birth (`date_of_birth`, date, optional): The student's date of birth.
- **Passport Number**: Enter the student's passport number.
  - Passport Number (`passport_number`, text, optional): The student's passport number.
- **Nationality**: Select the student's nationality from the dropdown menu.
  - Nationality (`nationality`, select_one, optional): The student's nationality (e.g., Australia, China, Germany, Japan, etc.).
- **Passport Expiration Date**: Enter the expiration date of the student's passport in the correct format (YYYY-MM-DD).
  - Passport Expiration Date (`passport_expiration_date`, date, optional): The expiration date of the student's passport.
- **Visa Expiration Date**: Enter the expiration date of the student's visa in the correct format (YYYY-MM-DD).
  - Visa Expiration Date (`visa_expiration_date`, date, optional): The expiration date of the student's visa.
- **Student Status**: Select the student's status from the dropdown menu.
  - Student Status (`student_status`, select_one, optional): The student's status (e.g., Active, Active with restrictions, Suspended, Inactive).
- **Email**: Enter the student's email address.
  - Email (`email`, email, optional): The student's email address.
- **Phone Number**: Enter the student's phone number.
  - Phone Number (`phone_number`, text, optional): The student's phone number.
- **Address**: Enter the student's address.
  - Address (`address`, text, optional): The student's address.
- **Study Duration**: Enter the duration of the student's study in years.
  - Study Duration (`study_duration`, number, optional): The duration of the student's study.
- **Course Details**: Enter any additional course details.
  - Course Details (`course_details`, text, optional): Additional course details.
- **Institution**: Enter the institution where the student is studying.
  - Institution (`institution`, text, optional): The institution where the student is studying.
- **Study Location**: Enter the location where the student is studying.
  - Study Location (`study_location`, text, optional): The location where the student is studying.
- **Study Level**: Select the student's study level from the dropdown menu.
  - Study Level (`study_level`, select_one, optional): The student's study level (e.g., Undergraduate, Postgraduate).
- **Program Name**: Enter the name of the program the student is enrolled in.
  - Program Name (`program_name`, text, optional): The name of the program the student is enrolled in.
- **Department**: Enter the department the student is studying in.
  - Department (`department`, text, optional): The department the student is studying in.
- **Faculty**: Enter the faculty the student is studying in.
  - Faculty (`faculty`, text, optional): The faculty the student is studying in.
- **Student Status Details**: Enter any additional student status details.
  - Student Status Details (`student_status_details`, text, optional): Additional student status details.
- **Date Graduated**: Enter the date the student graduated in the correct format (YYYY-MM-DD).
  - Date Graduated (`date_graduated`, date, optional): The date the student graduated.
- **Graduation Date**: Enter the date the student graduated in the correct format (YYYY-MM-DD).
  - Graduation Date (`graduation_date`, date, optional): The date the student graduated.
- **Degree Awarded**: Select whether the student was awarded a degree.
  - Degree Awarded (`degree_awarded`, select_one, optional): Whether the student was awarded a degree (True or False).
- **Opt Start Date**: Enter the start date of the student's opt in the correct format (YYYY-MM-DD).
  - Opt Start Date (`opt_start_date`, date, optional): The start date of the student's opt.
- **Opt End Date**: Enter the end date of the student's opt in the correct format (YYYY-MM-DD).
  - Opt End Date (`opt_end_date`, date, optional): The end date of the student's opt.

Note: This help guide is for informational and reference purposes only, and is subject to change as needed. Please double-check all fields for accuracy and relevance before submission.
