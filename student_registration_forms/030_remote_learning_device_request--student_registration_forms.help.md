# Remote Learning Device Request - Help Guide

## Purpose
The Remote Learning Device Request form is used to gather information from students, teachers, and schools to determine the need for devices in a remote learning setting.

## How To Complete This Form
To fill out this form, follow these steps:

1. Start on the first page, "Student Registration Form".
	* Fill out the "Student Registration Form" page with the necessary information.
2. Select the school ID from the dropdown list.
3. Choose the grade level of the student.
4. Select the type of device needed.
5. Enter the student's name.
6. Enter the student's email address.
7. Enter the student's phone number.
8. Choose the date the device is needed.
9. Enter the date the device should be returned.
10. Provide teacher contact information (name, email, phone number).
11. Provide school contact information (email, phone number).

## Field-by-Field Explanation

* **Student Registration Form (Page 1)** (`student_registration_form`, text, required/optional): This is the first page of the form where you can enter student information.
* **school_id** (`school_id`, number, required/optional): Select the school ID from the dropdown list to associate the request with the school.
* **grade_level** (`grade_level`, select_one, required/optional): Choose the grade level of the student (K-5, 6-8, 9-12).
* **device_type** (`device_type`, select_multiple, required/optional): Select the type of device needed (laptop, tablet, chromebook).
* **student_name** (`student_name`, text, required/optional): Enter the student's name.
* **student_email** (`student_email`, email, required/optional): Enter the student's email address.
* **student_phone** (`student_phone`, text, required/optional): Enter the student's phone number.
* **Device Needed Date** (`device_needed_date`, date, required/optional): Choose the date the device is needed.
* **Device Return Date** (`device_return_date`, date, required/optional): Choose the date the device should be returned.
* **teacher_name** (`teacher_name`, text, required/optional): Enter the teacher's name.
* **teacher_email** (`teacher_email`, text, required/optional): Enter the teacher's email address.
* **teacher_phone** (`teacher_phone`, text, required/optional): Enter the teacher's phone number.
* **school_phone** (`school_phone`, text, required/optional): Enter the school's phone number.
* **school_email** (`school_email`, text, required/optional): Enter the school's email address.

## Tips
* Please fill out each field accurately and thoroughly.
* Ensure you've chosen the correct school ID and grade level.
* Be realistic when choosing the device type and dates.
* Enter correct contact information for teachers and schools.
* If you're unsure about any field, feel free to ask for assistance.
