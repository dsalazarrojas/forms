# Exam Grade Entry Form - Help Guide
## Purpose
The Exam Grade Entry Form is designed to collect and record grades for exams, enabling teachers to track student performance accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Student ID of the student whose grade you wish to record.
2. Select the Assignment Type for which the grade is being recorded.
3. Enter the numerical grade for the assignment.
4. Choose the grade type (e.g., Letter Grade, Percent).
5. If applicable, enter the date on which the grade was recorded.
6. Provide any relevant teacher comments about the student's performance.
7. Enter the name of the teacher who recorded the grade.
8. Enter the name of the student whose grade is being recorded (if different from the teacher).
9. Enter the name of the course for which the grade is being recorded.
10. Choose the school year in which the grade was recorded.
11. Enter the subject of the course for which the grade is being recorded.
12. Select the grade scale (e.g., A+, A, B, C, D, F).
13. Provide any additional comments about the student's performance.

## Field-by-Field Explanation
* **Student Id (2)**: A numeric ID for the student. This is a required field to identify the student accurately.
* **Assignment Type (3)**: Select the type of assignment for which the grade is being recorded. This will help in tracking progress and identifying areas of improvement.
* **Grade (4)**: Enter the numerical grade for the assignment.
* **Grade Type (5)**: Choose the type of grade being recorded (e.g., Letter Grade, Percent).
* **Grade Date (6)**: If applicable, enter the date on which the grade was recorded. This helps in tracking the progress over time.
* **Teacher Comments (7)**: Provide any comments or feedback from the teacher about the student's performance.
* **Teacher Name (8)**: Enter the name of the teacher who recorded the grade.
* **Student Name (9)**: Enter the name of the student whose grade is being recorded. This is optional but recommended for identification purposes.
* **Course Name (10)**: Enter the name of the course for which the grade is being recorded.
* **School Year (11)**: Choose the school year in which the grade was recorded.
* **Subject (12)**: Enter the subject of the course for which the grade is being recorded.
* **Grade Scale (13)**: Select the grade scale used for the recording (e.g., A+, A, B, C, D, F).
* **Comments (14)**: Provide any additional comments about the student's performance. This is an optional field for further insights.
