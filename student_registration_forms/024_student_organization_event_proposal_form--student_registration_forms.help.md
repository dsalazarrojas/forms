# Student Organization Event Proposal Form - Help Guide
## Purpose
The Student Organization Event Proposal Form is designed to collect information from students to propose an event for their student organization. This form helps the student organization to plan and coordinate events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information about the event, including the start and end dates and times, the location, and any other details.
2. Review each field carefully to ensure that you are providing accurate information.
3. Submit the form once you have filled it out completely.

## Field-by-Field Explanation
* **Event Details** (`student_organization_event_details`, text, required/optional): A brief description of the event, including its purpose and any other relevant details.
* **Start Date** (`student_organization_event_start_date`, date, required/optional): The date on which the event will start.
* **Start Time** (`student_organization_event_start_time`, time, required/optional): The time at which the event will start.
* **End Date** (`student_organization_event_end_date`, date, required/optional): The date on which the event will end.
* **End Time** (`student_organization_event_end_time`, time, required/optional): The time at which the event will end.
* **Event Location** (`student_organization_event_location`, text, required/optional): The location where the event will take place.
* **Event Venue** (`student_organization_event_venue`, text, required/optional): The venue where the event will take place.

## Tips
* Make sure to double-check the dates and times you enter to ensure they are correct.
* If you need help with event planning, contact your student organization advisor.
* If you have any questions or concerns about the form, contact [form@gic.mx](mailto:form@gic.mx).
