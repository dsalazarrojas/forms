# Extracurricular Activities Declaration Form - Help Guide
## Purpose
This form is used to collect information from students about their extracurricular activities, which can include clubs, sports, leadership roles, and other activities that students participate in or are involved with.

## How To Complete This Form
1. Read each question carefully and answer truthfully about your extracurricular activities.
2. Select the correct options from the dropdown menus, if applicable.
3. If there's a text field, provide a brief description or elaboration of your answer.
4. Make sure to review your answers before submitting the form.

## Field-by-Field Explanation
* **Student Participation** (`student_participation`, text, optional): A brief description of your participation in extracurricular activities. Please provide a short paragraph describing your involvement, including any specific activities or clubs you're part of.
* **Club Affiliations** (`club_affiliations`, select_multiple, optional): If you're affiliated with any clubs, select all the clubs that apply.
* **Sports Participation** (`sports_participation`, select_one, optional): Indicate if you're currently participating in sports. If yes, please select the corresponding option.
* **Sports Coaches** (`sports_coaches`, select_one, optional): Indicate if you have a sports coach. If yes, please select the corresponding option.
* **Student Leadership** (`student_leaderships`, select_multiple, optional): If you're in a leadership role in any club or organization, select all that apply.
* **Student Clubs** (`student_clubs`, select_one, optional): Indicate if you're a part of a student club. If yes, please select the corresponding option.
* **Other Extracurricular** (`other_extracurricular`, text, optional): If you have any other extracurricular activities not listed above, provide a brief description.
* **Additional Information** (`additional_info`, note, optional): If you have any other information to share about your extracurricular activities, provide it here. 

## Tips
* Please answer honestly and accurately.
* Make sure to review your answers before submitting the form.
* If you have any questions or concerns, contact [your contact person/department].
