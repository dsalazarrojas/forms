# Registration Form English Learning Programs - Help Guide
## Purpose
The purpose of this form is to register students for various English learning programs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form header.
2. Enter your student name.
3. Enter your student email.
4. Enter your student phone number.
5. Select your program interest.
6. Select a program start date.
7. Select a program end date.
8. Enter the program duration.
9. Select the program status.
10. Add any program notes (optional).
11. Select the submission status.
12. Select a submission date.

## Field-by-Field Explanation
* **Form** (1):
	+ This is the form header. Please fill out this section with your name and other identifying information.
* **Student Name** (2):
	+ Enter your student name in this field.
* **Student Email** (3):
	+ Enter your student email address to be contacted.
* **Student Phone** (4):
	+ Enter your student phone number to be contacted.
* **Program Interest** (5):
	+ Select the English learning program you are interested in (English Language Arts, English Language and Culture, English Language and Literature, or English Language and Linguistics).
* **Program Start Date** (6):
	+ Select the date you plan to start the program.
* **Program End Date** (7):
	+ Select the date you plan to end the program.
* **Program Duration** (8):
	+ Enter the duration of the program in months or years.
* **Program Status** (9):
	+ Select the status of your program (Active, Inactive, or Pending).
* **Program Notes** (10):
	+ Add any additional notes about your program (optional).
* **Submission Status** (11):
	+ Select the submission status of your form (Submitted, Saved, or Not Submitted).
* **Submission Date** (12):
	+ Select the date you submitted your form.

## Tips
* Ensure you fill out the form accurately and completely.
* Review each field before submitting the form.
* If you need help, contact your program administrator.
