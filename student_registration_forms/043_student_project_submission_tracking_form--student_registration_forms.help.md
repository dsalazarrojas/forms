# Student Project Submission Tracking Form - Help Guide
## Purpose
This form is used by students to submit and track their projects. It collects information about the submission process, including due dates, status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the appropriate submission status from the options provided.
2.  Fill in the submission comments, if applicable.
3.  Upload the submission file(s), if required.
4.  Select the tags for the submission, if applicable.
5.  Enter the student's ID and name.
6.  Fill in the submission date and assignment due date.
7.  Select the submission reviewed status.
8.  Fill in the reviewed date and time, if applicable.

## Field-by-Field Explanation

*  **Submission Due Date** (id: 2, type: date, required: false): Enter the date when the submission is due.
*  **Submission Status** (id: 3, type: select_one, required: false): Choose the status of the submission, which can be either Active or Inactive.
*  **Submission Comments** (id: 4, type: text, required: false): Fill in any comments related to the submission, if applicable.
*  **Submission File** (id: 5, type: text, required: false): Upload the submission file, if required.
*  **Submission Files** (id: 6, type: text, required: false): Upload multiple submission files, if required.
*  **Submission Tags** (id: 7, type: select_multiple, required: false): Select the relevant tags for the submission, from the options provided.
*  **Student ID** (id: 8, type: number, required: false): Enter the student's ID number.
*  **Student Name** (id: 9, type: text, required: false): Enter the student's name.
*  **Submission Date** (id: 10, type: date, required: false): Fill in the date of submission.
*  **Assignment Due Date** (id: 11, type: date, required: false): Fill in the assignment due date.
*  **Submission Reviewed** (id: 12, type: select_one, required: false): Choose whether the submission has been reviewed or not.
*  **Reviewed At** (id: 13, type: time, required: false): Fill in the date and time the submission was reviewed, if applicable.

## Tips
*  Please ensure that all required fields are filled in before submitting the form.
*  Multiple files can be uploaded at once, but each file must be in a compatible format.
*  The submission status and due dates can be updated as necessary.
*  If a student's submission has been reviewed, fill in the reviewed date and time for accurate tracking.
