# gutter_cleaning_checklist_form - Help Guide
## Purpose
The gutter cleaning checklist form is designed to collect data on the status of gutters on a building, including cleaning tasks, clogging, damage, debris collection, and the date and time of completion.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the sections below and answer the questions carefully.
2. Select the correct options for each field.
3. Enter any additional notes or comments in the "Notes" field.
4. Choose the correct date and time of completion.

## Field-by-Field Explanation

* **Gutter Cleaning Tasks** (`gutter_cleaning_tasks`): This field is a multiple-choice question that asks about the status of gutter cleaning. Choose one or more of the following options:
	+ Cleaned
	+ Partially cleaned
	+ Not cleaned
* **Gutter Clogged** (`gutter_clogged`): This field is a single-choice question that asks whether the gutter is clogged or not. Choose one of the following options:
	+ True
	+ False
* **Gutter Damaged** (`gutter_damaged`): This field is a multiple-choice question that asks about the status of gutter damage. Choose one or more of the following options:
	+ Damaged section found
	+ Partially damaged
	+ No damage
* **Debris Collected** (`debris_collected`): This field is a multiple-choice question that asks whether debris was collected or not. Choose one or more of the following options:
	+ True
	+ False
* **Notes** (`notes`): This field is for adding any additional comments or notes about the gutter cleaning process. Enter your comments here.
* **Date Completed** (`date_completed`): This field is a date field where you can enter the date when the gutter cleaning was completed.
* **Time Completed** (`time_completed`): This field is a time field where you can enter the time when the gutter cleaning was completed.

## Tips
- Answer each question carefully and honestly.
- Make sure to select only the options that apply to your situation.
- If you have any additional comments or notes, use the "Notes" field to add them.
- Enter the correct date and time of completion in the respective fields.
