# High Rise Window Cleaning Quote Request - Help Guide
## Purpose
This form is a quote request for high rise window cleaning services.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the project location and description in the "Project Location" and "Project Description" fields, respectively.
2. Select the type of window(s) to be cleaned (Single Pane, Double Pane, or Insulated Pane) in the "Window Type" field.
3. Enter the number of units that will be cleaned in the "Number of Units" field.
4. If applicable, select the service provider(s) from the "Service Provider" dropdown list.
5. Enter the contact email and contact phone number of the person submitting the quote request.
6. If known, provide the date the project is expected to start on.
7. Add any special requests or notes about the project in the "Special Requests" field.
8. Select the user who submitted the quote request from the "Submitted By" dropdown list.

## Field-by-Field Explanation
* **Project Location** (Project Location, text, required): Enter the address or location of the building where the project will take place.
* **Project Description** (Project Description, text, required): Describe your project in detail, including any specific requirements or concerns.
* **Window Type** (Window Type, select_one, required): Select the type of window(s) to be cleaned (Single Pane, Double Pane, or Insulated Pane).
* **Number of Units** (Number of Units, number, required): Enter the number of units that will be cleaned.
* **Service Provider** (Service Provider, select_multiple, optional): Select the service provider(s) that will be performing the work.
* **Contact Email** (Contact Email, email, required): Enter the email address of the person submitting the quote request.
* **Contact Phone** (Contact Phone, text, required): Enter the phone number of the person submitting the quote request.
* **Estimated Date** (Estimated Date, date, optional): If known, enter the date the project is expected to start on.
* **Special Requests** (Special Requests, note, optional): Add any special requests or notes about the project.
* **Submitted By** (Submitted By, select_one, optional): Select the user who submitted the quote request.
