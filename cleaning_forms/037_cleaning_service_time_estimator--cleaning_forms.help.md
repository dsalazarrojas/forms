# Cleaning Service Time Estimator - Help Guide

## Purpose

This form helps cleaning service providers or property management companies estimate the time and resources needed for a specific cleaning job.

## How To Complete This Form

1. Start by providing the basic property information:
	* Select the type of property you are dealing with (e.g., Single Family Home, Apartment, etc.).
	* Enter the approximate square footage of the property.
	* If the property is residential, provide the number of bedrooms and bathrooms.
2. Describe the current condition of the property:
	* Choose how dirty the property currently is (e.g., Clean, Moderately Dirty, etc.).
	* Select the time since the last professional cleaning (e.g., Never been professionally cleaned, 1-3 months ago, etc.).
3. Specify the areas to be cleaned:
	* Indicate if full or partial kitchen cleaning is needed.
	* Specify if full or partial bathroom cleaning is needed.
	* Choose if full or partial floor cleaning is required.
	* Specify if carpet/rug cleaning is needed.
	* Select if window cleaning is required (interior, exterior, or both).
4. Consider any additional factors:
	* Specify if pets are present in the property.
	* Choose the level of clutter (minimal, moderate, heavy, or extreme).
	* If applicable, mention any accessibility issues or special cleaning requirements.
5. Calculate the estimate:
	* Enter the base time estimate for the standard cleaning job (if applicable).
	* Provide any additional time adjustment factors (if applicable).
	* Calculate the total estimated time in hours.
6. Specify the recommended crew size:
	* Enter the number of cleaners needed for the job.
7. Add any scheduling notes:
	* Enter any special scheduling considerations or requests.
