# Cleaning Routine Tracking Form - Help Guide
## Purpose
This form is a tool for tracking and monitoring the cleaning routine of your facility. It helps you to gather information on different aspects of cleaning, including tasks, supplies, and maintenance.

## How To Complete This Form
1. Fill in the required fields: Facility Name, Facility Address, Tracking Period Start Date, and Supervising Staff Name.
2. Select the completion status for each daily cleaning task: Daily - Floor Cleaning (Sweep or Vacuum), Daily - Floor Mopping, Daily - Dusting Surfaces, Daily - Trash Removal, Daily - Restroom Cleaning, and Daily - Kitchen or Break Room Cleaning.
3. Mark the completion status for each weekly task: Weekly - Interior Window Cleaning, Weekly - Baseboard Cleaning, Weekly - Appliance Cleaning, Weekly - Detailed Furniture Dusting, Weekly - Light Fixture Cleaning, Weekly - Deep Disinfection.
4. Check the completion status for each monthly task: Monthly - Carpet Deep Cleaning, Monthly - Floor Stripping and Waxing, Monthly - Wall Washing, Monthly - Air Vent Cleaning, Monthly - Upholstery Cleaning.
5. Select the supply inventory status: Fully Stocked, Adequate Supply, Running Low, Need Reorder, Critical - Out of Stock.
6. Fill in the supplies ordered for the tracking period.
7. Select the overall condition of your cleaning equipment: Excellent, Good, Fair, or Poor.
8. Fill in any equipment maintenance required.
9. Fill in any problems or challenges you encountered during the tracking period.
10. Select which areas need additional attention.
11. Fill in any notes or comments from your staff.
12. Select the overall compliance status with cleaning standards: Fully Compliant, Mostly Compliant, Partially Compliant, or Non-Compliant.
13. Fill in any corrective actions you plan or have taken.
14. Select the review status by your supervisor: Reviewed and Approved, Reviewed with Comments, or Pending Review.
15. Fill in your supervisor's electronic signature.
16. Select the date of the supervisor's review.
17. Fill in the date of the supervisor's review.

## Field-by-Field Explanation

* **Facility Name** (1, text, required): Enter the name of the facility or building.
* **Facility Address** (2, text, required): Fill in the full address of the facility or building.
* **Tracking Period Start Date** (3, date, required): Enter the start date for the tracking period.
* **Tracking Period End Date** (4, date, required): Enter the end date for the tracking period.
* **Supervisor Name** (5, text, required): Enter the name of the supervising staff member.
* **-- Daily Cleaning Tasks --** (6, note, required): Select the daily cleaning tasks to be completed:
	+ **Daily - Floor Cleaning (Sweep or Vacuum)** (7, select_one, required): Select the completion status for this task: Completed All Days, Completed Most Days, Completed Some Days, Not Completed, or Not Applicable.
	+ **Daily - Floor Mopping** (8, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Daily - Dusting Surfaces** (9, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Daily - Trash Removal** (10, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Daily - Restroom Cleaning** (11, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Daily - Kitchen or Break Room Cleaning** (12, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
* **-- Weekly Cleaning Tasks --** (13, note, required): Select the weekly tasks to be completed:
	+ **Weekly - Interior Window Cleaning** (14, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Weekly - Baseboard Cleaning** (15, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Weekly - Appliance Cleaning** (16, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Weekly - Detailed Furniture Dusting** (17, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Weekly - Light Fixture Cleaning** (18, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
	+ **Weekly - Deep Disinfection** (19, select_one, required): Select the completion status for this task: Completed, Partially Completed, Not Completed, or Not Applicable.
* **-- Monthly Cleaning Tasks --** (20, note, required): Select the monthly tasks to be completed:
	+ **Monthly - Carpet Deep Cleaning** (21, select_one, required): Select the completion status for this task: Completed, In Progress, Not Started, or Not Applicable.
	+ **Monthly - Floor Stripping and Waxing** (22, select_one, required): Select the completion status for this task: Completed, In Progress, Not Started, or Not Applicable.
	+ **Monthly - Wall Washing** (23, select_one, required): Select the completion status for this task: Completed, In Progress, Not Started, or Not Applicable.
	+ **Monthly - Air Vent Cleaning** (24, select_one, required): Select the completion status for this task: Completed, In Progress, Not Started, or Not Applicable.
	+ **Monthly - Upholstery Cleaning** (25, select_one, required): Select the completion status for this task: Completed, In Progress, Not Started, or Not Applicable.
* **-- Supply Inventory --** (26, note, required): Select the supply inventory status: Fully Stocked, Adequate Supply, Running Low, Need Reorder, or Critical - Out of Stock.
* **Cleaning Supplies Stock Level** (27, select_one, required): Select the current supply inventory status.
* **Supplies Ordered This Period** (28, text, required): Fill in the list of supplies ordered for the tracking period.
* **Cleaning Equipment Condition** (29, select_one, required): Select the overall condition of your cleaning equipment: Excellent, Good, Fair, or Poor.
* **Equipment Maintenance Needed** (30, text, required): Fill in any equipment maintenance required.
* **-- Issues and Notes --** (31, note, required): Select any problems or challenges you encountered during the tracking period.
* **Issues Encountered During Period** (32, text, required): List any problems or challenges you encountered.
* **Areas Needing Additional Attention** (33, text, required): Select which areas need additional attention.
* **Staff Notes or Comments** (34, text, required): Fill in any notes or comments from your staff.
* **Overall Compliance Status** (35, select_one, required): Select the overall compliance status with cleaning standards: Fully Compliant, Mostly Compliant, Partially Compliant, or Non-Compliant.
* **Corrective Actions Taken or Planned** (36, text, required): Fill in any corrective actions you plan or have taken.
* **Supervisor Review Status** (37, select_one, required): Select the review status by your supervisor: Reviewed and Approved, Reviewed with Comments, or Pending Review.
* **Supervisor Signature** (38, text, required): Fill in your supervisor's electronic signature.
* **Review Date** (39, date, required): Fill in the date of the supervisor's review.

## Tips
* Use the same tracking period for all cleaning tasks.
* Fill in all required fields.
* Be as detailed as possible when providing information.
* Ensure that your supervisor reviews and signs off on the form.
* Store the completed form for future reference.
