# hotel_room_cleaning_checklist_form - Help Guide

## Purpose
This form is used to check the condition of a hotel room's bathroom after cleaning. It helps hotel staff assess the quality of the cleaning process by evaluating the presence or absence of various elements such as bathroom facilities, sinks, toilets, showers, mirrors, flooring, walls, ceilings, doors, and furniture.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the hotel room's bathroom and determine the condition of each listed item.
2. Select the corresponding option for each field, marking "Yes" if the item is present or in good condition, and "No" if it is not.

## Field-by-Field Explanation

* **Bathroom** (`hotel_room_cleaning_checklist`, select_multiple): 
	+ Check each item listed under "Bathroom" and select "Yes" if it is present, "No" if it is not.
* **bathroom_facilities** (`bathroom_facilities`, text): 
	+ Enter any comments or notes about the state of the bathroom facilities.
* **bathroom_sinks** (`bathroom_sinks`, select_one): 
	+ Select "Yes" if there is a sink, "No" if there is no sink or it is not clean.
* **bathroom_toilets** (`bathroom_toilets`, select_one): 
	+ Select "Yes" if there is a toilet, "No" if there is no toilet or it is not clean.
* **bathroom_shower** (`bathroom_shower`, text): 
	+ Enter any comments or notes about the condition of the shower.
* **mirrors** (`mirrors`, select_multiple): 
	+ Select "Yes" if there are mirrors, "No" if there are no mirrors or they are not clean.
* **bathroom_flooring** (`bathroom_flooring`, text): 
	+ Enter any comments or notes about the state of the bathroom flooring.
* **bathroom_walls** (`bathroom_walls`, select_multiple): 
	+ Select "Yes" if the walls are clean, "No" if they are not clean or damaged.
* **bathroom_ceiling** (`bathroom_ceiling`, text): 
	+ Enter any comments or notes about the condition of the bathroom ceiling.
* **bathroom_doors** (`bathroom_doors`, select_one): 
	+ Select "Yes" if the doors are present and clean, "No" if they are not present or not clean.
* **bathroom_furniture** (`bathroom_furniture`, select_multiple): 
	+ Select "Yes" if the bathroom furniture is present and clean, "No" if it is not present or not clean.

## Tips
- Make sure to complete the form carefully and accurately to ensure that the cleaning process is evaluated thoroughly.
- If any issues are found during the assessment, note them in the respective fields to help the cleaning staff improve their performance.
- This form is an essential tool for hotel staff to provide consistent and high-quality cleaning services to guests.
