# home_cleaning_service_referral_form - Help Guide
## Purpose
The purpose of this form is to collect information for a home cleaning service referral.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Select a service option from the list.
2. Enter your first name in the "first name" field.
3. Enter your last name in the "last name" field.
4. Enter your email address in the "email" field.
5. Enter your phone number in the "phone" field.
6. Enter your address in the "address" field.
7. Select the city from the list.
8. Select the state from the list.
9. Select the country from the list.
10. Enter your zip code in the "zip" field.
11. Select the date and time of the referral.
12. Select the medium for the referral (e.g. "utm medium 1" or "utm medium 2").
13. Select the term for the referral (e.g. "utm source 1" or "utm source 2").

## Field-by-Field Explanation

* **Service Option** (`service_option`, select_one): Select a service option that you are referring a friend or family member for.
* **First Name** (`first_name`, text, required): Enter your first name.
* **Last Name** (`last_name`, text, required): Enter your last name.
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`phone`, text, required): Enter your phone number.
* **Address** (`address`, text, required): Enter your address.
* **City** (`city`, text, required): Select the city from the list.
* **State** (`state`, text, required): Select the state from the list.
* **Country** (`country`, text, required): Select the country from the list.
* **Zip** (`zip`, text, required): Enter your zip code.
* **Date** (`date`, date, required): Select the date of the referral.
* **Time** (`time`, time, required): Select the time of the referral.
* **Note** (`note`, note, optional): Enter any additional notes or comments.
* **Note 2** (`note_2`, note, optional): Enter any additional notes or comments.
* **Utm Medium** (`utm_medium`, select_one, required): Select the medium for the referral (e.g. "utm medium 1" or "utm medium 2").
* **Utm Source** (`utm_source`, select_multiple, optional): Select the source for the referral (e.g. "utm source 1" or "utm source 2").
* **Utm Term** (`utm_term`, text, required): Enter the term for the referral.
* **Utm Content** (`utm_content`, text, required): Enter the content for the referral.
* **Utm Campaign** (`utm_campaign`, text, required): Enter the campaign for the referral.
* **Utm Content Id** (`utm_content_id`, text, required): Enter the content id for the referral.
* **Utm Term Id** (`utm_term_id`, text, required): Enter the term id for the referral.
* **Utm Content Domain** (`utm_content_domain`, text, required): Enter the content domain for the referral.
* **Utm Medium Id** (`utm_medium_id`, text, required): Enter the medium id for the referral.
* **Utm Source Id** (`utm_source_id`, text, required): Enter the source id for the referral.
* **Utm Term Id 2** (`utm_term_id_2`, text, required): Enter the term id 2 for the referral.
* **Utm Medium 2** (`utm_medium_2`, select_one, required): Select the medium 2 for the referral.

## Tips

* Make sure to select the correct service option and medium for the referral.
* Double-check the date and time of the referral.
* Enter any additional notes or comments in the "Note" or "Note 2" fields if needed.
* Select the correct term for the referral.
