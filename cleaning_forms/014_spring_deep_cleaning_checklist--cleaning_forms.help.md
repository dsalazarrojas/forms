# Spring Deep Cleaning Checklist - Help Guide
## Purpose
The Spring Deep Cleaning Checklist is a form designed to gather information on the status of seasonal cleaning tasks. It is intended to be used for users to input their feedback and input on the seasonal cleaning form.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the Seasonal Cleaning Form to ensure you have all the necessary information.
2. Select "Yes" or "No" for the "Tasks Completed" field if you have completed all the tasks listed in the seasonal cleaning form.
3. Provide feedback on the "Seasonal Cleaning Form Feedback" field if needed.
4. Select a date for the "Date" field for the spring deep cleaning.
5. Select a time for the "Time" field for the spring deep cleaning.
6. Select "Yes" or "No" for the "Season" field if it is the spring season.
7. Enter any additional notes in the "Notes" field if needed.
8. Select a status for the "Status" field to indicate the current status of the spring deep cleaning.
9. Select a completion status for the "Completed" field to indicate if the spring deep cleaning is complete, not complete, or in progress.
10. Select who completed the spring deep cleaning if applicable in the "Completed By" field.

## Field-by-Field Explanation
* **Seasonal Cleaning Form** (`seasonal_cleaning_form`, note, required: false): This field is used to provide feedback on the seasonal cleaning form.
* **Tasks Completed** (`tasks_completed`, select_multiple, required: false): Select "Yes" if all tasks listed in the seasonal cleaning form are completed.
* **Seasonal Cleaning Form Feedback** (`seasonal_cleaning_form_feedback`, text, required: false): Provide feedback on the seasonal cleaning form if needed.
* **Date** (`spring_deep_cleaning_date`, date, required: false): Select a date for the spring deep cleaning.
* **Time** (`spring_deep_cleaning_time`, time, required: false): Select a time for the spring deep cleaning.
* **Season** (`season`, select_one, required: false): Select "Yes" if it is the spring season.
* **Notes** (`notes`, text, required: false): Enter any additional notes if needed.
* **Status** (`spring_deep_cleaning_status`, select_one, required: false): Select a status for the spring deep cleaning.
* **Completed** (`season_cleaning_form_completed`, select_one, required: false): Select a completion status for the spring deep cleaning.
* **Completed By** (`season_cleaning_form_completed_by`, select_one, required: false): Select who completed the spring deep cleaning if applicable.
