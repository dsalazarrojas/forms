# Cleaning Report Form - Help Guide

## Purpose
The purpose of this form is to collect information about the cleaning service provided to a client, including details about the service, tasks completed, supplies used, and any issues that arose during the process.

## How To Complete This Form

1. **Client Name**: Enter the name of the client who received the cleaning service.
2. **Service Address**: Enter the address where the cleaning service was provided.
3. **Service Date**: Enter the date of the cleaning service.
4. **Service Start Time**: Enter the time the cleaning service began.
5. **Service End Time**: Enter the time the cleaning service ended.
6. **Cleaner Name**: Enter the name of the cleaner or team that provided the service.
7. **Service Type**: Select the type of cleaning service provided from the options listed.
8. **Rooms Cleaned**: Select all rooms that were cleaned from the list provided.
9. **Tasks Completed**: Select all tasks that were completed from the list provided.
10. **Cleaning Supplies Used**: List any supplies or products used during the service.
11. **Supplies Running Low**: List any supplies that need restocking.
12. **Client Supplies Used**: Select whether you used client-provided supplies or company-provided supplies.
13. **Areas of Focus**: List any areas that needed special focus or attention.
14. **Issues Encountered**: Describe any problems or challenges that arose during the cleaning service.
15. **Damage Reported**: List any damage discovered or caused during the service.
16. **Items Not Cleaned**: List any items or areas that were not cleaned and a brief explanation as to why.
17. **Special Client Requests Completed**: List any special requests made by the client.
18. **Follow-Up Recommendations**: Provide suggestions for next time or services recommended for future visits.
19. **Client Satisfaction Level**: Rate the client's satisfaction level after the service.
20. **Client Comments or Feedback**: Allow the client to provide feedback or comments about the service.
21. **Client Requested Follow-Up**: Select whether the client requested any follow-up services.
22. **Report Submitted By**: Enter the name of the person submitting this report.
23. **Report Date**: Enter the date this report is submitted.
