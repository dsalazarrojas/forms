# Bathroom Cleaning Checklist - Help Guide
## Purpose
The Bathroom Cleaning Checklist form is used to document the cleaning tasks and status for bathroom areas. This form helps to ensure that cleaning tasks are completed and reported accurately, and it's used in a maintenance or cleaning context.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide location and staff information:
	* Enter the "Bathroom/Room ID" to identify the specific bathroom area being cleaned.
	* Enter the "Cleaner Name" to associate the cleaning staff member responsible for the task.
	* Select the "Date" of completion using the date field.
2. Check the status of cleaning tasks:
	* Select "True" or "False" or "N/A" for the following tasks:
		+ Mirrors cleaned and polished
		+ Sinks and countertops disinfected
		+ Toilets scrubbed and disinfected
		+ Floors swept and mopped
		+ Trash bins emptied and liners replaced
		+ Paper towels replenished
		+ Soap dispensers refilled
3. Report any maintenance issues:
	* If there are any issues that need attention (e.g., leaky faucet, broken light), enter them in the "Maintenance Issues" text field.

## Field-by-Field Explanation
### Location and Staff Information:
* **Bathroom/Room ID** (`id: 2`): This field is used to identify the specific bathroom area being cleaned. Enter the room number or name.
* **Cleaner Name** (`id: 3`): Enter the name of the person responsible for cleaning the bathroom.
* **Date** (`id: 4`): Select the date when the cleaning tasks were completed using the date field.

### Cleaning Tasks:
* **Mirrors cleaned and polished** (`id: 6`): Check "True" if the mirrors are cleaned and polished, otherwise select "False" or "N/A" if not applicable.
* **Sinks and countertops disinfected** (`id: 7`): Check "True" if the sinks and countertops are disinfected, otherwise select "False" if not applicable.
* **Toilets scrubbed and disinfected** (`id: 8`): Check "True" if the toilets are scrubbed and disinfected, otherwise select "False" if not applicable.
* **Floors swept and mopped** (`id: 9`): Check "True" if the floors are swept and mopped, otherwise select "False" if not applicable.
* **Trash bins emptied and liners replaced** (`id: 11`): Check "True" if the trash bins are emptied and liners replaced, otherwise select "False" if not applicable.
* **Paper towels replenished** (`id: 13`): Check "True" if the paper towels are replenished, otherwise select "False" if not applicable.
* **Soap dispensers refilled** (`id: 14`): Check "True" if the soap dispensers are refilled, otherwise select "False" if not applicable.

### Maintenance and Completion:
* **Maintenance Issues** (`id: 15`): If there are any issues that need attention (e.g., leaky faucet, broken light), enter them in this text field.
* **Time of Completion** (`id: 16`): Select the time of completion using the time field.

This guide should help the user understand the purpose and use of each field in the "Bathroom Cleaning Checklist" form.
