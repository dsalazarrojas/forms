# Functional Communication IEP Goal Tracking Form - Help Guide
## Purpose
The purpose of this form is to track the progress of students with special needs in achieving their functional communication goals.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill in the required information on each page.
* Select the correct options for each field.
* Make sure to save your progress and submit the form when complete.

## Field-by-Field Explanation

### Session Date (1)
* **Session Date**: Enter the date of the session, in the format MM/DD/YYYY.
* This field is used to track the date of the session.
* Example: 02/12/2023

### Student ID (2)
* **Student ID**: Enter the student's unique identifier number.
* This field is used to identify the student.
* Example: 1234

### Session Notes (3)
* **Session Notes**: Enter any notes from the session, if needed.
* This field is optional and can be used for additional information.
* Example: "Student made progress in using verbal communication skills."

### Goal Area (4)
* **Goal Area**: Select the relevant goal area from the list.
* This field helps to categorize the goal.
* Examples:
	+ Goal Area 1
	+ Goal Area 2
	+ Goal Area 3

### Objective (5)
* **Objective**: Enter a clear and specific objective for the student, if needed.
* This field is optional and can be used to provide additional context.
* Example: "Student will use verbal communication to initiate interactions with peers."

### Progress Level (6)
* **Progress Level**: Select the relevant progress level from the list.
* This field helps to evaluate the student's progress.
* Examples:
	+ Level 1
	+ Level 2
	+ Level 3

### Target Date (7)
* **Target Date**: Enter the date when the goal is expected to be achieved.
* This field is used to set a target date for the goal.
* Example: 05/01/2024

### Notes (8)
* **Notes**: Enter any additional notes, if needed.
* This field is optional and can be used for additional information.
* Example: "Student made significant progress in using verbal communication, but still needs practice."
