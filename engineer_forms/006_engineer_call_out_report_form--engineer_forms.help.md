# Engineer Call Out Report Form - Help Guide

## Purpose
This form is used to report call out events, which is when an engineer is called out to a site or location. The form is used to document the details of the call out event, including the site manager's presence, the date and time of the call out, the work order number, and any other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" to indicate whether the site manager was present.
2. Enter the date and time of the call out event using the date field.
3. Enter the start time of the call out event using the start time field.
4. Enter the work order number associated with the call out event.
5. Enter the customer's name and any other relevant information in the customer field.
6. Enter the job number and any other relevant information in the job number field.
7. Enter the type of job associated with the call out event in the job type field.
8. Enter a brief description of the reason for the call out in the call out reason field.
9. Enter the engineer's name and any other relevant information in the field labeled "engineer".
10. Enter the site manager's name in the site manager name field.
11. Check the box to indicate whether the site is a repeat call out in the site field (select multiple options).
12. Enter any additional comments about the call out event in the comments field.

## Field-by-Field Explanation

* **site_manager (select_one)**: Select "Yes" if the site manager was present during the call out event, and "No" otherwise.
* **call_out_date (date)**: Enter the date of the call out event.
* **start_time (time)**: Enter the start time of the call out event.
* **work_order_number (text)**: Enter the work order number associated with the call out event.
* **customer (text)**: Enter the customer's name and any other relevant information.
* **job_number (text)**: Enter the job number and any other relevant information.
* **job_type (text)**: Enter the type of job associated with the call out event.
* **call_out_reason (text)**: Enter a brief description of the reason for the call out event.
* **engineer (text)**: Enter the engineer's name and any other relevant information.
* **site_manager_name (text)**: Enter the site manager's name.
* **site (select_multiple)**: Check the boxes for any sites that were involved in the call out event.
* **comments (text)**: Enter any additional comments about the call out event.

## Tips
* Make sure to select "No" for site manager presence if the site manager is not present.
* Use the date format MM/DD/YYYY to ensure accurate date entry.
* Be as detailed as possible when filling out the engineer and customer fields.
* Use the job type field to document the type of job associated with the call out event.
* Use the comments field to document any additional information about the call out event.
