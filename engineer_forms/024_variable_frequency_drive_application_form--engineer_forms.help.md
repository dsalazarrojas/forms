# Variable Frequency Drive Application Form - Help Guide
## Purpose
This form is used to collect information related to variable frequency drive (VFD) applications for motor control.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the project type from the given options.
2. Choose the VFD type, motor type, and application from the respective options.
3. Enter the motor power rating and speed as required.
4. Select the VFD connection and motor connection types from the options.
5. Provide the VFD and motor sizes as text entries.
6. Enter any additional VFD and motor notes or comments.
7. Select the project status and manager from the options.
8. If needed, enter the project date and user input.

## Field-by-Field Explanation

* **Project Type** (`project_type`, Select One, required): Select the type of project, e.g., VFD, Motor.
* **VFD Type** (`vfd_type`, Select One, required): Choose the type of VFD, e.g., Vector, Induction, Squirrel Cage.
* **Motor Type** (`motor_type`, Select One, required): Select the type of motor, e.g., 3-Phase, Single Phase, AC, DC.
* **Application** (`vfd_application`, Select Multiple, not required): Choose the VFD application, e.g., General, Special, High.
* **VFD Connection Type** (`vfd_connection_type`, Select Multiple, not required): Select the type of VFD connection, e.g., 3-phase 400V, 3-phase 200V, Single Phase 3-wire.
* **Motor Connections** (`motor_connections`, Select Multiple, not required): Choose the motor connection type, e.g., Terminal box, Socket 3-phase, Terminal box and socket 3-phase.
* **Motor Size** (`motor_size`, Text, not required): Enter the motor size as text.
* **VFD Size** (`vfd_size`, Text, not required): Enter the VFD size as text.
* **Motor Power Rating** (`motor_power_rating`, Number, not required): Enter the motor power rating.
* **Motor Speed** (`motor_speed`, Number, not required): Enter the motor speed.
* **VFD Rating** (`vfd_rating`, Number, not required): Enter the VFD rating.
* **Motor Voltages** (`motor_voltages`, Select Multiple, not required): Select the motor voltages, e.g., 3-Phase, Single Phase.
* **VFD Voltages** (`vfd_voltages`, Select Multiple, not required): Choose the VFD voltages, e.g., AC, DC.
* **VFD Notes** (`vfd_notes`, Note, not required): Enter any additional notes or comments about the VFD.
* **Motor Notes** (`motor_notes`, Note, not required): Enter any additional notes or comments about the motor.
* **Additional Notes** (`additional_notes`, Note, not required): Enter any other additional notes or comments.
* **Project Status** (`project_status`, Select One, not required): Select the project status, e.g., Active, Complete, Cancelled.
* **Project Manager** (`project_manager`, Select One, not required): Choose the project manager, e.g., Engineer, Maintenance, Supplier.
* **Project Date** (`project_date`, Date, not required): Enter the project date.
* **User Input** (`user_input`, Text, not required): Enter any additional user input or comments.

## Tips
* Make sure to select the correct project type and VFD type.
* For fields with multiple options, select all that apply.
* Enter accurate information for motor and VFD ratings, sizes, and speeds.
* Be sure to enter any additional notes or comments for VFD and motor.
* Double-check the project status and manager before submitting the form.
