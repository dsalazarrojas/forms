# Engineering Project Status Submission Form - Help Guide
## Purpose
The Engineering Project Status Submission Form is a tool for engineers to submit updates on their project status. It is essential to complete this form accurately and truthfully to ensure that the project is progressing according to plan.

## How To Complete This Form

1.  Fill in the Project Name field with the name of the current project.
2.  Select "Yes" or "No" for Team Members if the project currently has team members assigned or not.
3.  Provide a brief Status Update on the project's current status.
4.  Choose the Risk Visibility level for the project (Risky, Low, or High).
5.  Select "Yes" or "No" for Team Coordination if the project requires coordination with other teams.
6.  Choose the Risk Management approach for the project (e.g., "Yes" or "No" for specific risk management strategies).
7.  Write a brief description of the next steps planned for the project.
8.  Add any additional Comments related to the project.
9.  Select the user who submitted the form (User1, User2, or User3).
10.  Choose the submission date and time using the calendar picker.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, optional): Enter the name of the current project.
* **Team Members** (`team_members`, select_multiple, optional): Check if the project currently has team members assigned.
* **Status Update** (`status_update`, text, optional): Write a brief description of the project's current status.
* **Risk Visibility** (`risk_visibility`, select_one, optional): Choose the risk level for the project (Risky, Low, or High).
* **Team Coordination** (`team_coordination`, select_multiple, optional): Select if the project requires coordination with other teams.
* **Risk Management** (`risk_management`, select_multiple, optional): Choose the risk management strategy for the project (e.g., "Yes" or "No").
* **Next Steps** (`next_steps`, text, optional): Describe the next steps planned for the project.
* **Comments** (`comments`, note, optional): Add any additional comments related to the project.
* **Submitted By** (`submitted_by`, select_one, optional): Choose the user who submitted the form (User1, User2, or User3).
* **Submitted At** (`submitted_at`, date, optional): Choose the submission date and time using the calendar picker.
* **Submission Form** (`submission_form`, text, optional): Enter any additional submission-related information.

## Tips

*   Always fill out the form accurately and truthfully.
*   Make sure to select the correct submission date and time.
*   Use the available options for Team Members and Risk Management to ensure accurate project status.
*   Keep the Status Update and Next Steps fields concise for easy review.
