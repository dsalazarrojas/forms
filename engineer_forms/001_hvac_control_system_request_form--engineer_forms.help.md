# HVAC Control System Request Form - Help Guide
## Purpose

The HVAC Control System Request Form is a tool to help facilities staff report issues with the HVAC control system. It provides the engineering team with the necessary information to efficiently address and resolve these issues.

## How To Complete This Form

1. Select the facility where the issue occurred.
2. Provide a detailed description of the issue.
3. Select the category and priority of the issue.
4. Select the current status of the issue.
5. Check if an engineer has been assigned to the issue.
6. Input the date and time the issue was detected.
7. Provide any additional comments or attachments.
8. Fill out the submitter's contact information for follow-up.

## Field-by-Field Explanation

* **Facility Address** (facility_address): Please input the address of the facility where the issue occurred.
* **Issue Description** (issue_description): Provide a detailed description of the issue you are experiencing.
* **Issue Category** (issue_category): Choose the category of the issue (Heating, Cooling, Water, or Electrical).
* **Issue Priority** (issue_priority): Select the priority of the issue (High, Medium, or Low).
* **Issue Status** (issue_status): Choose the current status of the issue (Open, Closed, or In Progress).
* **Assigned Engineer** (assigned_engineer): Check if an engineer has been assigned to the issue.
* **Issue Date** (issue_date): Input the date the issue was detected.
* **Issue Time** (issue_time): Input the time the issue was detected (optional).
* **Comments** (issue_comments): Provide any additional comments or information about the issue.
* **Facility Phone** (facility_phone): Input the facility's phone number.
* **Facility Email** (facility_email): Input the facility's email address.
* **Submitted By** (submitted_by): Fill out the submitter's name.
* **Submitted By Name** (submitted_by_name): Fill out the submitter's name.
* **Submitted Phone** (submitter_phone): Input the submitter's phone number.
* **Submitted Email** (submitter_email): Input the submitter's email address.
* **Submitted Location** (submitter_location): Input the submitter's location.
* **Submitter Department** (submitter_department): Input the submitter's department.
* **Form Comments** (form_comments): Provide any additional comments about the form.
* **Facility Address 2** (facility_address_2): Please input the address of the facility where the issue occurred (if necessary).
* **Form Header 2** (form_header_2): This is a duplicate header field. Please ignore it.
* **Submitted By** (submitted_by_name): This field is a duplicate of the submitted_by field. Please ignore it.
* **Comments** (form_comments): Provide any additional comments about the form.
