# Building Airflow Analysis Application Form - Help Guide
## Purpose
This form is used to collect information about a building's air flow analysis application. It will help identify the building's characteristics, HVAC system details, and analysis objectives.

## How To Complete This Form

1. Fill in the form with the required information, starting from the first field "Applicant Name" and moving down to the last field "Additional Comments".
2. Be thorough and accurate when filling in the form, as the information collected will be used to determine the building's air flow analysis needs.
3. Make sure to select the correct options for each field, especially for fields with multiple options.

## Field-by-Field Explanation

* **Applicant Name**: <i>Full name of the person completing the form</i>
* **Company Name**: <i>Name of the engineering firm or organization</i>
* **Job Title**: <i>Your position within the company</i>
* **Email Address**: <i>Contact email for follow-up questions or issues</i>
* **Phone Number**: <i>Contact number for follow-up questions or issues</i>
* **Application Date**: <i>Date the application was submitted</i>
* **Building Name**: <i>Name of the building being analyzed</i>
* **Building Address**: <i>Full address of the building</i>
* **Building Type**: <i>Classification of the building (e.g. Office, Residential, Hospital, etc.)</i>
* **Total Square Footage**: <i>Size of the building in square feet</i>
* **Number of Floors**: <i>Total number of floors in the building</i>
* **Year Constructed**: <i>Year the building was built</i>
* **HVAC System Type**: <i>Type of HVAC system installed in the building</i>
* **HVAC System Age**: <i>Approximate age of the HVAC system</i>
* **Airflow Issues Reported**: <i>Select all issues that have been reported in the building (e.g. Uneven Temperature, Poor Ventilation, etc.)</i>
* **Affected Areas**: <i>List all areas where issues have been reported</i>
* **Analysis Objectives**: <i>Objectives for the air flow analysis (e.g. Improve Air Quality, Balance Temperature, etc.)</i>
* **Occupancy Type**: <i>Type of building use (e.g. Office, Residential, etc.)</i>
* **Typical Occupancy**: <i>Number of occupants in the building</i>
* **Operating Hours**: <i>Hours of operation for the building</i>
* **Special Requirements**: <i>SPECIAL requirements for the building (e.g. Clean rooms, labs, etc.)</i>
* **Preferred Analysis Date**: <i>Date when analysis should be performed</i>
* **Access Availability**: <i>When the building is accessible for analysis</i>
* **Documentation Provided**: <i>List any documentation provided for the analysis (e.g. Floor Plans, HVAC Drawings, etc.)</i>
* **Budget Range**: <i>Estimated budget for the analysis</i>
* **Additional Comments**: <i>Any other information relevant to the analysis</i>

Note: The fields marked as "required" are mandatory and must be completed. The fields marked as "optional" are not mandatory and can be left blank if not relevant.
