# Digital Blueprint Submission Application Form - Help Guide
## Purpose
This form is designed for engineers and architects to submit digital projects, providing detailed information about their work.

## How To Complete This Form
1. Ensure you have only one project to submit.
2. Select the project architect and contractor (if applicable).
3. Add any necessary digital files (e.g., images, documents).
4. Provide a detailed description of the project.
5. Choose a submit date and time (if applicable).
6. Select the submission status (if applicable).
7. Add any comments or notes about the project.

## Field-by-Field Explanation

* **Project Details (Project Details)** (`project_details`, text, optional)
	+ This field is for providing a brief description of the project.
* **Project Architect (Project Architect)** (`architect`, select_one, optional)
	+ Select the name of the person responsible for the project.
* **Project Contractor (Project Contractor)** (`contractor`, select_multiple, optional)
	+ Select the names of people involved in the project (if applicable).
* **Digital Files (Digital Files)** (`digital_files`, note, optional)
	+ Attach any digital files relevant to the project.
* **Project Description (Project Description)** (`project_description`, text, optional)
	+ Provide a detailed description of the project.
* **Submit Date (Submit Date)** (`submit_date`, date, optional)
	+ Enter the date you are submitting the project.
* **Submit Time (Submit Time)** (`submit_time`, time, optional)
	+ Enter the time you are submitting the project.
* **Submission Status (Submission Status)** (`submission_status`, select_one, optional)
	+ Select the status of the project's submission (e.g., Draft, Published, Archived).
* **Engineer Comments (Engineer Comments)** (`engineer_comments`, text, optional)
	+ Add any additional comments or notes about the project.
