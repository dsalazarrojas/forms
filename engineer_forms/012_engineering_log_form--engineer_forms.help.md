# Engineering Log Form - Help Guide

## Purpose
This form is designed to collect information about engineering activities and events that occur during a project or task. It is intended to be used for documentation and reference purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your **first name** in the first name field.
2. Enter your **last name** in the last name field.
3. Enter the **date** of the event or activity in the date field.
4. Enter the **time** of the event or activity in the time field.
5. Select the **discipline** related to the activity (e.g., Civil, Mechanical, Electrical, Computer).
6. Enter a brief description of the **activity** in the activity field.
7. Enter a detailed description of the **activity description** in the activity description field.
8. Enter any additional **comments** about the activity in the comments field.

## Field-by-Field Explanation
* **First name** (`first_name`, text, optional): Enter your first name.
* **Last name** (`last_name`, text, optional): Enter your last name.
* **Date** (`date`, date, optional): Enter the date of the event or activity.
* **Time** (`time`, time, optional): Enter the time of the event or activity.
* **Discipline** (`discipline`, select_one, optional): Select the discipline related to the activity (e.g., Civil, Mechanical, Electrical, Computer).
* **Activity** (`activity`, text, optional): Enter a brief description of the activity.
* **Activity description** (`activity_description`, text, optional): Enter a detailed description of the activity.
* **Comments** (`comments`, text, optional): Enter any additional comments about the activity.

## Tips
* Make sure to fill out all required fields (none in this case).
* Use proper date and time formats when entering the date and time fields.
* Select only one discipline option.
* Enter as much detail as needed in the activity description field.
* Use this form for documentation and reference purposes only.
