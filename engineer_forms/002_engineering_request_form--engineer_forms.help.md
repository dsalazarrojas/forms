# Engineering Request Form - Help Guide
## Purpose
This form is designed to capture and track requests related to engineering projects or tasks. It allows users to provide necessary information for project assignment or support.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `Project Name` field with a brief title for the project.
2. Provide a brief description of the project in the `Project Description` field.
3. Enter the `Start Date` and `End Date` of the project if applicable.
4. Select the `Request Type` that best describes the request (e.g., Option 1, Option 2, or Option 3).
5. Select the `Request Category` that best fits the request (e.g., Engineering, Architecture, or Construction).
6. Set the `Priority` of the request (e.g., High, Medium, or Low).
7. Select the `Assignee` who will be handling the request (e.g., John, Jane, or James).
8. Select the `Request Status` of the request (e.g., Approved, Rejected, or Pending).
9. Add any necessary comments in the `Comment` field.
10. If applicable, attach any relevant files or documents in the `Attachment` field.
11. Enter your name and email address in the `Submitter` fields.
12. Enter the email address and phone number of the person to be assigned in the `Assignee` fields.
13. Enter your location in the `Submitter Location` and `Assignee Location` fields.

## Field-by-Field Explanation

* **Project Name** (`1`, `text`, optional): A brief title for the project.
* **Project Description** (`2`, `text`, optional): A brief description of the project. (e.g., "This is a description of the project.")
* **Start Date** (`4`, `date`, optional): The date the project is expected to start.
* **End Date** (`5`, `date`, optional): The date the project is expected to end.
* **Request Type** (`6`, `select_multiple`, optional): Select the type of request (e.g., Option 1, Option 2, or Option 3).
* **Request Category** (`7`, `select_one`, optional): Select the category that best fits the request (e.g., Engineering, Architecture, or Construction).
* **Priority** (`8`, `select_one`, optional): Set the priority of the request (e.g., High, Medium, or Low).
* **Assignee** (`9`, `select_one`, optional): Select the person to be assigned the request (e.g., John, Jane, or James).
* **Request Status** (`10`, `select_one`, optional): Set the status of the request (e.g., Approved, Rejected, or Pending).
* **Comment** (`11`, `text`, optional): Add any necessary comments or notes.
* **Attachment** (`12`, `text`, optional): Attach any relevant files or documents.
* **Submitter** (`13`, `select_one`, optional): Select who submitted the request (e.g., John, Jane, or James).
* **Submitter Email** (`14`, `email`, optional): Enter the email address of the person who submitted the request.
* **Submitter Phone** (`15`, `text`, optional): Enter the phone number of the person who submitted the request.
* **Submitter Location** (`16`, `text`, optional): Enter the location of the person who submitted the request.
* **Assignee Email** (`17`, `email`, optional): Enter the email address of the person to be assigned.
* **Assignee Phone** (`18`, `text`, optional): Enter the phone number of the person to be assigned.
* **Assignee Location** (`19`, `text`, optional): Enter the location of the person to be assigned.
