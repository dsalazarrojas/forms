# Engineering Drawing Request Form - Help Guide
## Purpose

This form is designed to gather information from users for an engineering drawing request. The form is intended for users to provide details about their project, including location, type, size, and other relevant information to ensure the request is properly fulfilled.

## How To Complete This Form

To complete this form, follow these steps:

1. Provide your project location.
2. Select the type of drawing you need (2D or 3D).
3. Choose the size of the drawing (A3, A1, A0).
4. Enter the date you need the drawing by (YYYY-MM-DD format).
5. Enter the time you need the drawing by (HH:MM:SS format).
6. Provide a brief description of the drawing details.
7. Enter your contact information for follow-up purposes.
8. Select the tool you would like to use for the drawing (Chatjimmy or Other).
9. Click the "Submit" button to send the request.

## Field-by-Field Explanation

* **Request Form**: This is the main text field where you can enter a brief description of your drawing request.
* **Project Location**: Enter the location of your project.
* **Drawing Type**: Select the type of drawing you need (2D or 3D).
* **Drawing Size**: Choose the size of the drawing (A3, A1, A0).
* **Date**: Enter the date you need the drawing by (YYYY-MM-DD format).
* **Time**: Enter the time you need the drawing by (HH:MM:SS format).
* **Drawing Details**: Provide a brief description of the drawing details.
* **Contact Information**: Enter your contact information for follow-up purposes.
* **Assigned Tool**: Select the tool you would like to use for the drawing (Chatjimmy or Other).
* **Submit**: Click this button to send the request.

## Tips

* Be as detailed as possible when filling out the form to ensure the request is properly fulfilled.
* Check your project location to ensure it is accurate.
* If you have any questions or concerns, do not hesitate to reach out.
* This form is for internal use only and should not be shared with external parties.
