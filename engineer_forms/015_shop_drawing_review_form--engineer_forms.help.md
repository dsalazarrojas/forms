# Shop Drawing Review Form - Help Guide
## Purpose
This form is used for reviewing shop drawings and tracking progress in construction projects.

## How To Complete This Form
1. Fill out the form with the correct information for the shop drawing review.
2. Provide accurate comments and contact details for the architect and contractor.
3. Enter the completion dates for the shop drawing and review.
4. Enter the review dates for the shop drawing and review.
5. Fill out the form with the required information.

## Field-by-Field Explanation
* **Shop Drawing Review Form** (`shop_drawing_review_form`, Text, Required): Enter a brief description of the shop drawing being reviewed.
* **Review Form Comments** (`review_form_comments`, Note, Optional): Add any relevant comments or observations about the shop drawing.
* **Architect Review Form** (`architect_review_form`, Number, Required): Enter the ID number for the architect's review form, if applicable.
* **Contractor Review Form** (`contractor_review_form`, Number, Required): Enter the ID number for the contractor's review form, if applicable.
* **Date Completed** (`date_completed`, Date, Required): Enter the date the shop drawing was completed, in the format of MM/DD/YYYY.
* **Date Reviewed** (`date_reviewed`, Date, Optional): Enter the date the shop drawing was reviewed, in the format of MM/DD/YYYY.
* **Review Date Completed** (`review_date_completed`, Time, Optional): Enter the time the shop drawing review was completed, if applicable.
* **Review Date Reviewed** (`review_date_reviewed`, Time, Optional): Enter the time the shop drawing was reviewed, if applicable.
* **Review Form Email** (`review_form_email`, Email, Required): Enter the email address associated with the review form.
* **Review Form Phone** (`review_form_phone`, Text, Optional): Enter the phone number associated with the review form.
* **Review Form Comments** (`review_form_comments`, Text, Optional): Add any additional comments about the review form.

Note: Required fields are marked with an asterisk (\*). Ensure that all required fields are filled out before submitting the form.
