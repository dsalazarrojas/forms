# Cable Hauling Safety Assessment - Help Guide
## Purpose
This guide provides step-by-step instructions and explanations for completing the Cable Hauling Safety Assessment form.

## How To Complete This Form
1. Select the project information tab.
2. Enter the project name and location in the designated fields.
3. Set the assessment date and ensure it aligns with the actual date of the assessment.
4. Enter the inspector's name.
5. Enter the contractor's name.
6. Select the cable conditions under the 'Cable Condition Assessment' option.
7. Indicate the equipment type used and select the inspection status for each piece of equipment.
8. Select if a rigging plan is in place.
9. Determine if all personnel are using proper PPE.
10. Enter the number of workers on site.
11. Confirm if a safety briefing was conducted.
12. Select the overall compliance status.
13. Provide any necessary corrective actions.
14. Enter a reassessment date (if needed).
14. Sign off with your inspector's signature.

## Field-by-Field Explanation
* **Project Name (Project Name)**: Enter the actual project name to provide context to the assessment.
* **Project Location (Project Location)**: Enter the location where the cable hauling operation took place.
* **Assessment Date (Assessment Date)**: Enter the date the assessment was conducted.
* **Inspector Name (Inspector Name)**: Enter your name as the inspector conducting the assessment.
* **Contractor Name (Contractor Name)**: Enter the name of the contractor performing the cable hauling operation.
* **Cable Condition Assessment (Cable Condition)**: Select the condition of the cable used for the operation, taking into account any wear and tear or damage.
* **Equipment Type Used (Equipment Type Used)**: Select all the equipment used for the cable hauling operation, such as winch, pulley system, crane, etc.
* **Equipment Inspection Status (Equipment Inspection Status)**: Select the inspection status for each piece of equipment, indicating if it has been inspected and certified, needs inspection, or failed inspection.
* **Rigging Plan (Rigging Plan in Place?)**: Indicate if a proper rigging plan was in place during the operation.
* **All Personnel Using Proper PPE (ppe_compliance)**: Confirm if all personnel involved in the operation were using proper personal protective equipment.
* **Number of Workers on Site (Number of Workers on Site)**: Enter the number of workers involved in the operation.
* **Safety Briefing Conducted (Safety Briefing Conducted?)**: Confirm if a safety briefing was conducted before the operation.
* **Overall Compliance Status (Compliance Status)**: Select the overall compliance status of the operation, taking into account all factors.
* **Required Corrective Actions (Required Corrective Actions)**: Provide any necessary corrective actions to improve the compliance status.
* **Reassessment Date (Reassessment Date (if needed))**: Enter a date for the next assessment, if needed.
* **Inspector Signature (Inspector Signature)**: Sign off with your inspector's name to confirm the assessment.
