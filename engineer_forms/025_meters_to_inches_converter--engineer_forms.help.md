# meters_to_inches_converter - Help Guide
## Purpose
The meters to inches converter form is a tool used to convert measurements from meters to inches or vice versa.

## How To Complete This Form
1. Enter a value in meters or inches in the corresponding input fields.
2. Optionally, select the units you'd like to convert from and to.
3. Press enter or submit the form to see the converted value.

## Field-by-Field Explanation
* **enter_meters** (number, required): Enter a value in meters to convert to inches.
* **enter_inches** (number, optional): Enter a value in inches to convert to meters.
* **convert_meters** (text, optional): Displayed value in meters after conversion (if converted from inches).
* **convert_inches** (text, optional): Displayed value in inches after conversion (if converted from meters).
* **additional_info** (note, optional): A field for entering any additional information or comments.
* **units** (select multiple, optional): Select the units to convert from and to.

## Tips
* Make sure to enter a numeric value in the input fields.
* Be aware that the conversion is two-way, meaning you can convert both meters to inches and inches to meters.
* The converted value is displayed in the corresponding result fields.
