# Audio Engineer Assistance Request Form - Help Guide
## Purpose
This form is used to request assistance from an audio engineer for issues related to audio equipment, software, or technical problems.

## How To Complete This Form
1. Fill in your full name and contact information.
2. Choose the department or team you belong to.
3. Select the type of assistance you require.
4. Describe the issue in detail.
5. Specify any affected equipment or systems.
6. Indicate which software is involved (if any).
7. If applicable, provide any error messages you've received.
8. Choose the urgency level of your request (Critical, High, Medium, or Low).
9. If you have a specific deadline for assistance, select it.
10. Indicate your preferred time for assistance (if any).
11. Specify the location where assistance is needed.
12. Provide any special access requirements.
13. If you've tried anything to fix the issue, describe it.
14. If you have a preference for which engineer assists you, specify it.
15. Finally, choose your preferred method of follow-up (email, phone call, text message, or in-person).

## Field-by-Field Explanation

* **Requester Full Name** (`requester_full_name`, text, required)
  This is the name of the person requesting assistance.
* **Email Address** (`requester_email`, email, required)
  This is the contact email for follow-up purposes.
* **Phone Number** (`requester_phone`, text, required)
  This is the contact phone number for follow-up purposes.
* **Department** (`department`, select_one, required)
  Please select the department or team you belong to.
* **Request Date** (`request_date`, date, required)
  This is the date of this assistance request.
* **Assistance Type** (`assistance_type`, select_one, required)
  Please select the type of assistance you require.
* **Issue Description** (`issue_description`, text, required)
  Describe the issue or problem you are experiencing.
* **Affected Equipment** (`affected_equipment`, text, required)
  List the equipment or systems affected by the issue.
* **Equipment Brand** (`equipment_brand`, text, optional)
  If applicable, provide the primary brand of affected equipment.
* **Equipment Model** (`equipment_model`, text, optional)
  If applicable, provide the model number of affected equipment.
* **Software Involved** (`software_involved`, text, optional)
  If applicable, list any software related to the issue.
* **Error Messages** (`error_messages`, text, optional)
  If applicable, provide any error messages received.
* **Urgency Level** (`urgency_level`, select_one, required)
  Select the urgency level of your request (Critical, High, Medium, or Low).
* **Deadline** (`deadline`, date, optional)
  If you have a specific deadline for assistance, select it.
* **Preferred Time** (`preferred_time`, time, optional)
  If you have a preferred time for assistance, select it.
* **Location** (`location`, text, required)
  Specify the location where assistance is needed.
* **Access Instructions** (`access_instructions`, text, optional)
  If applicable, provide any special access requirements.
* **Previous Attempts** (`previous_attempts`, text, optional)
  If applicable, describe any previous attempts to fix the issue.
* **Preferred Engineer** (`preferred_engineer`, text, optional)
  If you have a preference for which engineer assists you, specify it.
* **Follow-Up Preference** (`follow_up_preference`, select_one, required)
  Choose how you'd like us to follow up with you (Email, Phone call, Text message, or In-person).

Note: Fields marked as required must be filled out for the form to be valid.
