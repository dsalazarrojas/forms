# Engineering Drawing Extension Line Reference Form - Help Guide
## Purpose
The Engineering Drawing Extension Line Reference Form is a tool for documenting and tracking changes to engineering drawings. It helps to maintain a reference system for engineers to keep track of drawing changes, revisions, and updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Form Information" page with any relevant details.
2. Enter the "Drawing Reference ID" number to reference the original drawing.
3. Select the type of drawing from the provided options.
4. Enter the "Drawing Name" as it is known in the reference system.
5. Enter the revision date of the drawing.
6. Provide a description of the changes made to the drawing.
7. Attach any relevant supporting files that relate to the changes.
8. Identify the author of the changes made to the drawing.
9. Select the current status of the drawing from the provided options.

## Field-by-Field Explanation

* **Form Information (form_info)** (`text`, optional): This is the general information page for the drawing reference form.
* **Drawing Reference ID (drawing_ref_id)** (`text`, optional): Enter the ID number for the drawing being referenced.
* **Drawing Type (drawing_type)** (`select_one`, optional): Choose the type of drawing from the options provided.
	+ Options: ID1, ID2, ID3
* **Drawing Name (drawing_name)** (`text`, optional): Enter the name of the drawing as it is known in the reference system.
* **Revision Date (revision_date)** (`date`, optional): Enter the date of the last revision of the drawing.
* **Change Description (change_description)** (`text`, optional): Provide a description of the changes made to the drawing.
* **Supporting Files (supporting_files)** (`text`, optional): Attach any files that support the changes made to the drawing.
* **Change Author (change_author)** (`text`, optional): Identify the author of the changes made to the drawing.
* **Status (status)** (`select_one`, optional): Select the current status of the drawing from the provided options.
	+ Options: Approved, Pending, Rejected, In Progress

## Tips
- Make sure to fill out the form accurately and completely to maintain a reliable reference system.
- Use this form for all engineering drawing revisions, updates, or modifications.
- Collaborate with other engineers to ensure consistency and accuracy in the reference system.
