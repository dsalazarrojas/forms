# Gift Return Authorization Contact Form - Help Guide
## Purpose
This form is used to obtain authorization for gift returns. It's designed to gather information required for processing returns, ensuring that all relevant details are captured accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **Customer Name** in the first field. This is a required field and should match the name of the customer associated with the order.
2. Enter the **Order Number** in the next field. This is also a required field and should match the actual order number.
3. Select the **Order Date** when the order was received by the customer. This helps track the order's history.
4. Provide a clear **Reason for Return** if applicable. This helps us understand the reason for the return and process it accordingly.
5. Optionally, provide any **Return Preferences** if there are specific requirements for handling the return.
6. Choose the **Shipping Method** used for the original delivery, which is typically the same method used for the return. This ensures that the return is handled according to the chosen shipping method.
7. Enter the **Shipping Address** used for the original delivery, which should match the shipping address associated with the order.
8. Enter the **Product Name** of the item being returned. This should match the actual product name on the order.
9. Provide a detailed **Product Description** of the item being returned.
10. Enter the **Product Price** of the item being returned. This should match the actual price of the item on the order.
11. Enter the **Customer Phone** number for communication and contact.
12. Enter the **Customer Email** for communication and updates.
13. Enter the **Customer Address** for any additional contact or shipping information.

## Field-by-Field Explanation
* **Customer Name**: The name of the customer associated with the order.
* **Order Number**: A unique identifier for the order, which should match the actual order number.
* **Order Date**: The date the order was received by the customer.
* **Reason for Return**: An optional field for providing a clear reason for the return.
* **Return Preferences**: Optional field for specifying any special preferences for handling the return.
* **Shipping Method**: The method used for the original delivery, which may be the same method used for the return.
* **Shipping Address**: The address used for the original delivery, which should match the actual shipping address.
* **Product Name**: The name of the item being returned, which should match the actual product name on the order.
* **Product Description**: A detailed description of the item being returned, which helps in processing the return.
* **Product Price**: The price of the item being returned, which should match the actual price on the order.
* **Customer Phone**: The phone number of the customer for contact and communication.
* **Customer Email**: The email address of the customer for contact and updates.
* **Customer Address**: The address of the customer for any additional contact or shipping information.
