# restocking_fee_refund_form - Help Guide
## Purpose
This form is used to initiate a restocking fee refund for a customer. It is essential to use this form only when a customer has a genuine reason for requesting a refund.

## How To Complete This Form
To complete this form, please follow the steps below:
1. Enter the customer's information in the **customer_info** field.
2. Select the reason for the refund from the **reason_for_refund** field.
3. Enter the exact amount to be refunded in the **refund_amount** field.
4. Choose the refund method from the **refund_method** field.

## Field-by-Field Explanation
* **customer_info**: A text field to enter the customer's information.
* **reason_for_refund**: A select multiple field with the following options: option 1, option 2, option 3.
* **refund_amount**: A number field to enter the exact amount to be refunded.
* **refund_method**: A select multiple field with the following options: option 1, option 2, option 3.

## Tips
* Make sure to use this form only once for each customer to avoid duplication of work.
* Review the form carefully before submitting it to ensure all necessary information is provided.
* If you are unsure about any field, please contact your supervisor or support team for guidance.
