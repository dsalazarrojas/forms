# Crowdfunding Refund Form - Help Guide

## Purpose
This form is used to request a refund for a successfully funded crowdfunding project.

## How To Complete This Form

1. Please fill out all the required fields to ensure your refund request is processed smoothly.
2. If you are unsure about any field, please refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **Project Creator** (`project_creator`, text, optional): Enter the name of the person or organization responsible for creating the project.
* **Project Name** (`project_name`, text, optional): Enter the name of the project for which you are requesting a refund.
* **Project ID** (`project_id`, number, optional): Enter the ID number associated with the project.
* **Order ID** (`order_id`, text, optional): Enter the ID number associated with the order related to the refund request.
* **Reason for Refund** (`reason_for_refund`, text, optional): Choose the reason for the refund from the list below, or provide a custom explanation. 
* **Refund Amount** (`refund_amount`, number, optional): Enter the amount to be refunded.
* **Payment Method** (`payment_method`, select_one, optional): Choose the payment method used for the original payment (Credit card, PayPal, or Stripe).
* **Refund Method** (`refund_method`, select_one, optional): Choose the method for the refund to be processed (Manual Refund or Automated Refund).

## Tips

* Make sure to fill out all the required fields accurately and completely to ensure your refund request is processed fairly.
* If you are unsure about the reason for the refund or the refund amount, please contact the platform's support team for guidance.
* The platform's administrators will review your refund request and contact you with further questions or instructions.
