# Program Cancellation Request Form - Help Guide
## Purpose

The Program Cancellation Request Form is used to request the cancellation of a program in the system. This form helps program managers to initiate the cancellation process and gather necessary information for efficient program management.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Program ID of the program you want to cancel.
2. Enter the name of the program you want to cancel.
3. Provide the reason for cancellation.
4. Enter the date of cancellation and the effective date of cancellation (if applicable).
5. Select the refund method for the participant.
6. Enter the participant's email and other contact information (if applicable).
7. Enter the program manager's email and other contact information (if applicable).

## Field-by-Field Explanation

* **Program Information**: Enter the name and ID of the program you want to cancel. This information will help identify the program in the system.
* **Program ID**: Enter a valid program ID to identify the program in the system.
* **Program Name**: Enter the name of the program you want to cancel.
* **Reason for Cancellation**: Provide a brief explanation for the cancellation of the program.
* **Date of Cancellation**: Enter the date of cancellation in mm/dd/yyyy format.
* **Effective Date of Cancellation**: Enter the effective date of cancellation (if applicable) in mm/dd/yyyy format.
* **Refund Method**: Select the refund method for the participant, which can be Full Refund, Partial Refund, or No Refund.
* **Participant Email**: Enter the participant's email address.
* **Participant Name**: Enter the participant's name (if applicable).
* **Participant Phone**: Enter the participant's phone number (if applicable).
* **Participant Address**: Enter the participant's address (if applicable).
* **Program Manager Email**: Enter the program manager's email address.
* **Program Manager Name**: Enter the program manager's name.
* **Program Manager Phone**: Enter the program manager's phone number.
* **Program Manager Address**: Enter the program manager's address.
* **Notes**: Enter any additional comments or notes about the cancellation.

## Tips

* Make sure to enter valid program ID and name to ensure accurate identification of the program.
* Provide a clear and concise reason for cancellation.
* Select the correct refund method for the participant.
* Enter accurate participant and program manager contact information (if applicable).
* Use this form for program cancellations only, and ensure that a request is not already in process.
