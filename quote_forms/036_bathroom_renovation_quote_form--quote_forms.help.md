# Bathroom Renovation Quote Form - Help Guide
## Purpose
The purpose of this form is to collect information for a bathroom renovation quote from a client, allowing the quote provider to gather the necessary details to create an accurate quote for the project.
## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the client's full name in the **Client Full Name** field.
2. Enter the property's address in the **Property Address** field.
3. Enter the client's primary phone number in the **Primary Phone Number** field.
4. Select the type of property from the **Property Type** dropdown menu.
5. Describe the project scope in the **Tell us about the bathroom(s) you want to renovate** field.
6. Select the type of bathroom to be renovated in the **Type of Bathroom to Renovate** dropdown menu.
7. Indicate if the plumbing layout will need to be moved in the **Will the plumbing layout need to be moved?** field.
8. Select if electrical updates or new lighting are required in the **Do you require electrical updates or new lighting?** field.
9. Select interested flooring material(s) from the **Interested Flooring Material** dropdown menu (optional).
10. Select the target budget for the project in the **Target Budget for this Project** dropdown menu.
11. Choose the desired project start date in the **Desired Project Start Date** dropdown menu.
12. Provide any necessary site access or parking instructions in the **Site Access or Parking Instructions** field (optional).
13. Indicate if the site is ready for an initial walkthrough inspection in the **Is the site ready for an initial walkthrough inspection?** field.
14. Enter the date of request submission in the **Request Submission Date** field.
## Field-by-Field Explanation

* **Client Full Name**: Enter the client's full name as it appears on their official documents.
* **Property Address**: Enter the property's address where the project will take place.
* **Primary Phone Number**: Enter the client's primary phone number for contact purposes.
* **Property Type**: Select the type of property where the project will take place (Single Family Home, Condominium/Apartment, Commercial Building, or Other).
* **Type of Bathroom to Renovate**: Select the type of bathroom to be renovated (Master Bathroom, Full Guest Bathroom, Powder Room (Half-Bath), or En-suite Bathroom).
* **Will the plumbing layout need to be moved?**: Indicate if the plumbing layout will need to be moved or rearranged.
* **Do you require electrical updates or new lighting?**: Select if electrical updates or new lighting are required for the project.
* **Interested Flooring Material**: Select interested flooring material(s) for the project (Ceramic/Porcelain Tile, Natural Stone, Luxury Vinyl Plank (LVP), Heated Flooring, or Polished Concrete).
* **Target Budget for this Project**: Select the target budget for the project (Under $10,000, $10,000-$20,000, $20,000-$35,000, or $35,000+).
* **Desired Project Start Date**: Choose the desired project start date (Immediately (Within 2 weeks), Within 1 Month, 2-3 Months, or Flexible / Next Year).
* **Site Access or Parking Instructions**: Enter any necessary site access or parking instructions for the project (optional).
* **Is the site ready for an initial walkthrough inspection?**: Indicate if the site is ready for an initial walkthrough inspection.
* **Request Submission Date**: Enter the date of the request submission.
