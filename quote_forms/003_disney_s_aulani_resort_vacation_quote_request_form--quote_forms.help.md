# disney_s_aulani_resort_vacation_quote_request_form - Help Guide
## Purpose
This form is for requesting a quote from Disney's Aulani Resort for a vacation.

## How To Complete This Form
To complete this form, simply fill out the required fields with the requested information.

## Field-by-Field Explanation
- **First Name** (`first_name`, `text`, optional): Enter the first name of the person requesting the quote.
- **Last Name** (`last_name`, `text`, required): Enter the last name of the person requesting the quote.
- **Email** (`email`, `email`, required): Enter the email address of the person requesting the quote.
- **Phone** (`phone`, `text`, required): Enter the phone number of the person requesting the quote.
- **Arrival Date** (`arrival_date`, `date`, required): Enter the date the person is arriving at the resort.
- **Departure Date** (`departure_date`, `date`, required): Enter the date the person is departing the resort.
- **Room Type** (`room_type`, `select_one`, required): Select the type of room the person would like to book.
  - Select 'Yes' for a specific type of room.
  - Select 'No' if you do not want a specific type of room.
- **Room Quantity** (`room_quantity`, `select_multiple`, required): Select the number of rooms the person would like to book.
  - Select 'Yes' for each room you want to book.
  - Select 'No' if you do not want to book a room.
- **Adults** (`adults`, `number`, required): Enter the number of adults traveling with the person.
- **Children** (`children`, `number`, required): Enter the number of children traveling with the person.
- **Infants** (`infants`, `number`, required): Enter the number of infants (under 2 years old) traveling with the person.
- **Special Requests** (`special_requests`, `text`, optional): Enter any special requests or requirements for the person booking the room.
- **Arrival Time** (`arrival_time`, `time`, optional): Enter the estimated arrival time of the person at the resort.
- **Checkin Date** (`checkin_date`, `date`, required): Enter the date the person is checking in at the resort.
- **Checkout Date** (`checkout_date`, `date`, required): Enter the date the person is checking out at the resort.
- **Meal Plan** (`meal_plan`, `select_one`, required): Select the meal plan the person would like to book.
  - Select 'Yes' for a meal plan.
  - Select 'No' if you do not want a meal plan.
- **Parking** (`parking`, `select_one`, optional): Select whether the person wants parking.
  - Select 'Yes' for parking.
  - Select 'No' if you do not want parking.
- **Other Request 1** (`other_request`, `text`, optional): Enter any other requests or requirements for the person booking the room.
- **Other Request 2** (`other_request_2`, `text`, optional): Enter any other requests or requirements for the person booking the room.
- **Other Request 3** (`other_request_3`, `text`, optional): Enter any other requests or requirements for the person booking the room.
- **Other Request 4** (`other_request_4`, `text`, optional): Enter any other requests or requirements for the person booking the room.
- **Other Request 5** (`other_request_5`, `text`, optional): Enter any other requests or requirements for the person booking the room.
