# Coring and Cutting Project Proposal - Help Guide
## Purpose
The Coring and Cutting Project Proposal form is a tool used to gather information for a project that involves coring and cutting activities. This form will guide you through the process of providing detailed information about your project, which will help us assess your project requirements and prepare for its execution.

## How To Complete This Form
To complete this form, please follow these steps:

* Read through each section carefully and fill in the required information.
* Enter project details, such as client name, contact person, project description, and start and end dates.
* Provide necessary project details like job number, location, equipment needed, and special instructions.
* Ensure that you fill in all required fields to avoid form submission issues.

## Field-by-Field Explanation
- **Project Description** (project_description): A short description of the project that will help us understand the scope of work involved.
- **Client Name** (client_name): The name of the client or company involved in the project.
- **Contact Person** (contact_person): The person we should contact for any questions or concerns related to the project. Please select from the available options: John or Jane.
- **Job Number** (job_number): A unique identifier for the project. You can enter any number.
- **Project Details** (project_details): Choose one or multiple options from the dropdown menu that best describes the project requirements. Please select one or more options.
- **Start Date** (start_date): The date when the project is expected to start.
- **End Date** (end_date): The date when the project is expected to end.
- **Location** (location): The location where the project will take place.
- **Equipment Needed** (equipment_needed): The number of equipment needed for the project.
- **Special Instructions** (special_instructions): Any special instructions or notes that we should consider during the project execution.

## Tips
- Ensure that all required fields are filled in to avoid form submission issues.
- If you have any questions or concerns, please don't hesitate to contact us at [insert contact information].
