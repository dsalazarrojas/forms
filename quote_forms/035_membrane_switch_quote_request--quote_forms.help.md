# Membrane Switch Quote Request - Help Guide
## Purpose
The Membrane Switch Quote Request form is designed to gather information from users about their specific requirements and needs for a custom membrane switch. This information will be used to provide a quote for the custom product.

## How To Complete This Form
To complete this form, please follow these steps:
- Please fill out the form with as much detail as possible.
- Make sure to provide accurate and clear information about your requirements.
- If you have any additional information or attachments, you can attach them to the form.

## Field-by-Field Explanation

* **Membrane Switch Quote Request** (`quote_request`, text, optional):
	+ This field is where you can provide any additional information about your quote request.
* **Contact Us** (`contact_us`, text, optional):
	+ This field is not currently in use, but you can provide any additional contact information if needed.
* **Quote Request** (`quote_request`, text, optional):
	+ This field is currently a duplicate of the first field. Please only fill out one of these fields.

Please note that the second and third fields are currently duplicates and should not be filled out. The first field is the only field that should be filled out.
