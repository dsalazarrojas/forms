# Get A Quote - Help Guide
## Purpose
The "Get A Quote" form is designed to allow users to create a quote for a project, gathering essential information about the project details, payment terms, and client contact information. This guide will walk you through each field and its purpose to ensure you fill out the form accurately and efficiently.

## How To Complete This Form
To complete the form, follow these steps:

1. Start by filling out the user input field, which is a numerical field.
2. Move on to fill out the project details, including the project type (if applicable).
3. Choose the payment terms, which determine the payment conditions for the quote.
4. Enter the client details, including the client name, address, and contact information.
5. Set the project start and end dates.
6. Choose the quote validity, which determines the duration of the quote.
7. Enter the estimated cost and hours required for the project.
8. Add project manager, client, and quote notes, if needed.
9. Finally, review and submit the quote.

## Field-by-Field Explanation

* **User Input** (`1`, number, required): A numerical field where users input any information they see fit to describe the user's input for the project.
* **Project Details** (`2`, text, required): Enter the project details, including its type, if applicable.
* **Quote Amount** (`3`, text, required): Enter the estimated cost for the project, including any additional information or notes.
* **Payment Terms** (`4`, select_one, required): Choose from the provided payment options to determine the payment conditions for the quote.
* **Client Details** (`5`, text, required): Enter the client's name, address, and contact information.
* **Client Address** (`6`, select_multiple, required): Select from the options to enter the client's address information.
* **Project Manager** (`7`, select_one, required): Choose the project manager from the provided options.
* **Client Contact** (`8`, text, required): Enter the client's contact information.
* **Project Start Date** (`9`, date, required): Enter the start date of the project.
* **Project End Date** (`10`, date, required): Enter the end date of the project.
* **Quote Validity** (`11`, select_one, required): Choose from the options to determine the duration of the quote.
* **Payment Terms 2** (`12`, text, required): Enter any additional payment terms or conditions.
* **Total Hours** (`13`, number, required): Enter the total hours required for the project.
* **Rate** (`14`, text, required): Enter the rate for the project.
* **Estimated Cost** (`15`, number, required): Enter the estimated cost for the project, using the rate and total hours.
* **Project Notes** (`16`, note, required): Enter any project-specific notes.
* **Client Notes** (`17`, select_multiple, required): Select from the options to enter the client's notes.
* **Quote Notes** (`18`, text, required): Enter any quote-specific notes.
* **Project Manager Notes** (`19`, select_multiple, required): Select from the options to enter the project manager's notes.
* **Total Cost** (`20`, number, required): Enter the total cost for the project.
* **Project Status** (`21`, select_one, required): Choose the current project status.
* **Quote Status** (`22`, text, required): Enter the quote status.
* **Payment Status** (`23`, select_one, required): Choose from the options to determine the payment status.
* **Project Type** (`24`, text, required): Enter the project type.
* **Assigned Tool** (`25`, select_one, required): Choose from the options to assign a tool to the project.
