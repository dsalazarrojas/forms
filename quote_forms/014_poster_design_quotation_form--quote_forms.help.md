# Poster Design Quotation Form - Help Guide
## Purpose
The Poster Design Quotation Form is a tool used to gather information from clients about their poster design requirements, helping the design team provide an accurate quote for the design work.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Quote Request Form" field with a brief description of the project.
2. Select whether the quote is for a new project ("Yes") or a revision of an existing project ("No").
3. Enter the value of the quote in the "Quote Value" field.
4. If applicable, specify the client's requirements in the "Client Requirements" field.
5. Select the deadline for the quote in the "Quote Deadline" field.

## Field-by-Field Explanation
### **Quote Request Form** 
(required: false)
This field is where you should provide a brief description of your project.

### **Quote Type**
(required: false)
Select "Yes" if this is a new project, "No" if this is a revision of an existing project.

### **Quote Value** 
(required: false)
Enter the value of the quote.

### **Client Requirements**
(required: false)
If you have any specific requirements or constraints for the project, please list them here.

### **Quote Deadline** 
(required: false)
Select the deadline for the quote.

### Tips
* Make sure to fill in all the required fields to ensure that the design team can provide an accurate quote.
* If you have any questions or need clarification on any of the fields, contact the design team.
* This form should only be used for new poster design projects, not for existing project revisions or other types of projects.
