# Digital Transformation Quotation Form - Help Guide
## Purpose

This form is designed to collect information for digital transformation projects, helping project managers and sales teams gather requirements for quoting and project planning.

## How To Complete This Form

1. Fill out the form with all required fields marked as required.
2. Ensure accuracy and completeness of information to avoid duplication of efforts and ensure accurate quotations.
3. Review your input before submission to ensure it is correct.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, not required):
	+ Enter the name of the project.
* **Project Description** (`project_description`, text, not required):
	+ Briefly describe the project.
* **Customer Name** (`customer_name`, text, not required):
	+ Enter the name of the customer.
* **Customer Email** (`customer_email`, email, not required):
	+ Enter the customer's email address.
* **Customer Phone** (`customer_phone`, text, not required):
	+ Enter the customer's phone number.
* **Project Manager** (`project_manager`, text, not required):
	+ Enter the project manager's name.
* **Transformation Type** (`transformation_type`, select_multiple, required):
	+ Select all applicable transformation types (Digital Transformation, Process Automation, Data Analytics).
* **Project Location** (`project_location`, text, not required):
	+ Enter the project location.
* **Start Date** (`start_date`, date, not required):
	+ Enter the start date of the project.
* **End Date** (`end_date`, date, not required):
	+ Enter the end date of the project.
* **Budget Amount** (`budget_amount`, number, not required):
	+ Enter the budget amount.
* **Project Status** (`project_status`, select_one, required):
	+ Select the current project status (Open, Closed, In Progress).
* **Notes** (`notes`, text, not required):
	+ Add any additional comments or notes about the project.
* **Assigned To** (`assigned_to`, text, not required):
	+ Enter the name of the person assigned to the project.
* **Assigned At** (`assigned_at`, date, not required):
	+ Enter the date assigned.
* **Due Date** (`due_date`, date, not required):
	+ Enter the due date.
* **Project Deadline** (`project_deadline`, date, not required):
	+ Enter the project deadline.
* **Transformation Scope** (`transformation_scope`, text, not required):
	+ Describe the transformation scope.
* **Project Scope** (`project_scope`, text, not required):
	+ Describe the project scope.
* **Business Process** (`business_process`, text, not required):
	+ Describe the business process.
* **Process Flow** (`process_flow`, text, not required):
	+ Describe the process flow.
* **Process Flow Status** (`process_flow_status`, select_one, required):
	+ Select the current process flow status (Not Started, In Progress, Completed).
* **Transformation Technology** (`transformation_technology`, text, not required):
	+ Describe the transformation technology used.
* **Customer Comments** (`customer_comments`, text, not required):
	+ Enter customer comments.
* **Internal Comments** (`internal_comments`, text, not required):
	+ Enter internal comments.

Note: Please fill out all fields marked as required. Ensure the information is accurate and complete to avoid duplication of efforts. Review your input before submission.
