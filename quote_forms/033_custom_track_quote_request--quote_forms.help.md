# Custom Track Quote Request - Help Guide
## Purpose
The Custom Track Quote Request form is used to gather information from clients about their project requirements, allowing us to provide tailored quotes and bids for custom projects.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the project details section:
	* Enter a brief description of the project in the "Project Description" field.
	* If applicable, specify the "Project Deadline" and "Project Budget" fields accordingly.
2. Provide project contact information:
	* Enter your "Contact Number" and "Email" for the project lead and/or contact person.
3. Complete the project lead and contact information:
	* Enter the "Project Lead", "Contact Name", "Contact Title", and "Contact Company" fields for the project lead and contact person.
4. Specify the project type:
	* Select the correct "Project Type" from the dropdown menu.
5. Add any additional comments:
	* Use the "Additional Comments" field to provide any other details about the project.

## Field-by-Field Explanation
* **Project Details**
	+ `Project Description` (text): A brief description of the project.
* **Project Lead**
	+ `Project Lead` (text): The person responsible for the project.
* **Project Location**
	+ `Project Location` (text): The location associated with the project.
* **Project Type**
	+ `Project Type` (select_one): The type of project (e.g. Option 1, Option 2, Option 3, or Option 4).
* **Project Description**
	+ `Project Description` (text): A detailed description of the project.
* **Project Budget**
	+ `Project Budget` (number): The budget for the project.
* **Project Deadline**
	+ `Project Deadline` (date): The project deadline, if applicable.
* **Additional Comments**
	+ `Additional Comments` (note): Any other details about the project.
* **Contact Information**
	+ `Contact Number` (text): The phone number of the contact person.
	+ `Email` (email): The email address of the contact person.
	+ `Contact Name` (text): The name of the contact person.
	+ `Contact Title` (text): The title of the contact person.
	+ `Contact Company` (text): The company name of the contact person.
* **Quote Requestor**
	+ `Quote Requestor` (text): The person requesting the quote.
