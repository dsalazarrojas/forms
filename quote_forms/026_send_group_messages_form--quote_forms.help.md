# send_group_messages_form - Help Guide
## Purpose
The send_group_messages_form is a simple form designed to help you send messages to groups of users. This form has 4 fields to gather necessary information for sending group messages.

## How To Complete This Form
To use this form, follow these steps:
1. Click on the "send_messages" field on page 1 and enter a brief description of the group message you want to send.
2. On page 2, select the recipient from the options provided.
3. Enter the subject of the message in the "subject" field on page 3.
4. In the "message" field on page 4, type the content of the message you want to send.

## Field-by-Field Explanation
- **send_messages** (`send_messages`, text, Optional): Enter a brief description of the group message you want to send. This field is used to quickly describe the purpose of the message.
- **Recipient** (`recipient_id`, select_one, Optional): Select "Yes" or "No" to indicate whether you want to send the message to the recipient or not.
- **Subject** (`subject`, text, Optional): Enter the subject of the message that will be sent to the recipient.
- **Message** (`message`, text, Optional): Type the content of the message you want to send to the recipient.
