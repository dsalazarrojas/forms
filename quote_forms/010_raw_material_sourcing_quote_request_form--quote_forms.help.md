## Raw Material Sourcing Quote Request Form - Help Guide

## Purpose
This form is designed to assist users in requesting quotes for raw materials from various suppliers. It captures essential information to facilitate the quote request process and helps to ensure that the necessary details are provided to the suppliers for a smooth and efficient communication.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information on the "Quote Request" page.
2. Provide detailed quote request details on the "Quote Details" page.
3. Enter your contact information on the "Contact Information" page.
4. Select one or more suppliers from the "Suppliers" page.
5. Enter a detailed description of the raw material on the "Raw Material Description" page.
6. Specify the quantity needed and unit price on the "Quantity Needed" and "Unit Price" pages.
7. Add any additional notes for the supplier on the "Supplier Notes" page.
8. Select the status of the quote from the options provided on the "Quote Status" page.
9. Finally, submit the quote using the "Submit Quote" button.

## Field-by-Field Explanation

* **Quote Request** (`raw_material_sourcing_quote_request_form`, text, **not required**): This is the main page for the form where you can enter a brief description of the raw material you are requesting.
* **Quote Details** (`quote_request_details`, text, **not required**): Please enter a detailed description of the quote request, including any specific requirements or specifications.
* **Contact Information** (`contact_information`, text, **not required**): Enter your contact information, including your name, email address, and phone number, so the supplier can easily get in touch with you.
* **Suppliers** (`supplier_selection`, select multiple, **not required**): Select one or more suppliers from the list of available options. You can select multiple suppliers to receive quotes from different suppliers.
* **Raw Material Description** (`raw_material_description`, text, **not required**): Enter a detailed description of the raw material, including its characteristics, specifications, and any other relevant information.
* **Quantity Needed** (`quantity_needed`, number, **not required**): Enter the quantity of the raw material you need to purchase.
* **Unit Price** (`unit_price`, number, **not required**): Enter the unit price of the raw material, if available.
* **Supplier Notes** (`supplier_notes`, text, **not required**): Add any additional notes or information for the supplier, such as special requirements or delivery instructions.
* **Submit Quote** (`submit_quote`, text, **not required**): This is not a field for user input, but rather a button to submit the quote request to the selected suppliers.
* **Supplier Quote** (`supplier_quote`, select one, **not required**): Select the supplier that submitted the quote you are responding to.
* **Supplier Name** (`supplier_name`, text, **not required**): Enter the name of the selected supplier.
* **Quote Status** (`quote_status`, select one, **not required**): Select the status of the quote from the options provided, such as Open, Accepted, Rejected, or Waiting.
