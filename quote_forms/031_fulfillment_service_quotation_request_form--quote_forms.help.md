# Fulfillment Service Quotation Request Form - Help Guide
## Purpose
This form is intended to help customers request quotations for fulfillment services from service providers. It captures relevant information about the service provider, customer, and service details to facilitate efficient quotation preparation.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing an introduction to the quotation request, if needed.
2. Fill in the provider and customer information fields.
3. Specify the fulfillment requirements, including any specific services needed.
4. Enter the pricing information for the requested services.
5. Add any additional fulfillment requirements.
6. Finally, select the submission options to specify the relevant details for the service provider.

## Field-by-Field Explanation
* **Introduction**:
	+ This is a note field where you can provide an optional introduction to the quotation request.
* **Provider info**:
	+ Provide the name and relevant details about the service provider.
* **Customer info**:
	+ Enter the name and relevant information about the customer making the request.
* **Fulfillment requirements**:
	+ Describe the services required for the quotation request, including any specific details or constraints.
* **Pricing info**:
	+ Enter the price details for the requested services, including any discounts or promotions.
* **Additional fulfillment requirements**:
	+ Add any further details or constraints related to the services needed.
* **Submission**:
	+ Select one or more submission options for the service provider to consider, such as Service Provider, Service Type, Service Description, and Service Price.
* **Service provider**:
	+ Select the service provider that will handle the requested services.
* **Service type**:
	+ Choose the type of service needed for the quotation request.
* **Service description**:
	+ Briefly describe the service requested, including any specific details.
* **Service price**:
	+ Select the price for the requested service.
* **Submission options**:
	+ Select one or more options to specify the details for the service provider, such as Service Provider, Service Type, Service Description, and Service Price.
