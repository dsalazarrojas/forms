# Hbcdjs Packages Enquiry - Help Guide

## Purpose
This form is used to inquire about packages related to events and activities. It is intended for clients who are interested in booking a package for a specific event or activity.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with the relevant information.
2. Select the correct options for the event type and accommodation type.
3. Enter any special requests or comments in the text fields.
4. Make sure to select the correct quote type.

## Field-by-Field Explanation

* **First Name** (Text, Required): Enter your first name as it is written on your official identification.
* **Last Name** (Text, Required): Enter your last name as it is written on your official identification.
* **Email** (Email, Optional): If you would like to be contacted via email, enter your email address here. This will not be shared with any third-party.
* **Phone** (Text, Optional): Enter your phone number if you would like to be contacted via phone. This will not be shared with any third-party.
* **Event Type** (Select One, Required): Select the type of event you are inquiring about, which could be a Holiday, Event, or Party.
* **Event Date** (Date, Optional): If you have a specific date in mind for your event, enter it here. If not, you can leave this field blank.
* **Event Time** (Time, Optional): If you have a specific time in mind for your event, enter it here. If not, you can leave this field blank.
* **Number of Guests** (Text, Required): Enter the number of guests attending your event.
* **Accommodation Type** (Select One, Required): Select the type of accommodation you are interested in, which could be Hotel, Resort, Cottage, or Other.
* **Special Requests** (Text, Optional): If you have any special requests or requirements, enter them here.
* **Comments** (Text, Optional): If you have any additional comments or questions, enter them here.
* **Quote Type** (Select One, Required): Select the type of quote you are interested in, which could be a Request Quote or Order Package.
* **Message** (Text, Optional): If you have any additional information or messages, enter them here.

## Tips

* Make sure to fill out all the required fields before submitting the form.
* If you are unsure about any of the fields, please ask our customer support team for assistance.
