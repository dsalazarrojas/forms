# website_design_quotes - Help Guide
## Purpose
The website design quotes form is used to capture project details and quote information for website design projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Quote Request field with a brief description of the project.
2. Provide project details in the Project Details field.
3. Add design details in the Design Details field.
4. Enter a quote price in the Quote Price field.
5. Select the delivery method for the quote in the Quote Delivery field.
6. Confirm if the quote terms are true in the Quote Terms field.
7. Set the project deadline in the Project Deadline field.
8. Set the quote validity in the Quote Validity field.
9. Add any additional quote notes in the Quote Notes field.
10. Enter the quote email and phone number in the Quote Email and Quote Phone fields.
11. Enter the website URL in the Quote Website field.
12. Provide comment information in the Quote Comments field.
13. Set the quote status in the Quote Status field.

## Field-by-Field Explanation
- **Quote Request** (quote_request): Enter a brief description of the project.
- **Project Details** (project_details): Enter project details.
- **Design Details** (design_details): Enter design details.
- **Quote Price** (quote_price): Enter a quote price.
- **Quote Delivery** (quote_delivery): Select how the quote will be delivered. Options: Website, Email, Phone.
- **Quote Terms** (quote_terms): Confirm if the quote terms are true. Options: True, False.
- **Project Deadline** (project_deadline): Set the project deadline.
- **Quote Validity** (quote_validity): Set the quote validity.
- **Quote Notes** (quote_notes): Enter any additional quote notes.
- **Quote Email** (quote_email): Enter the quote email.
- **Quote Phone** (quote_phone): Enter the quote phone number.
- **Quote Website** (quote_website): Enter the quote website URL.
- **Quote Comments** (quote_comments): Confirm if the quote comments are true. Options: True, False.
- **Quote Status** (quote_status): Set the quote status. Options: In Progress, Completed, Cancelled.
