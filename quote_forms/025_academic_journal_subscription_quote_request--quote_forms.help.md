# Academic Journal Subscription Quote Request - Help Guide
## Purpose
This form is used to provide a quote request for academic journal subscriptions. Fill in the required information to get a quote for the desired subscription model.

## How To Complete This Form
To complete this form, simply fill in the requested fields, and we will contact you with the quote. Make sure to fill in all required fields (*) for accurate quote generation.

## Field-by-Field Explanation
* **Requester name** (`requester_name`, Text, *): Your full name for quote contact.
* **Institution name** (`institution_name`, Text, *): The institution requesting the quote.
* **Contact email** (`contact_email`, Email, *): The email for sending the quote.
* **Subscription type** (`subscription_type`, Select one, *): Choose the subscription model requested.
  *   Options: Individual, Departmental, Institutional
* **Number of users or seats** (`number_of_users`, Number, ): Estimated count for pricing purposes.
* **Desired subscription start date** (`desired_start_date`, Date, ): Preferred start date for access.
* **Billing address for invoice** (`billing_address`, Text, ): Address and billing contact details.
* **Additional requirements** (`additional_requirements`, Text, ): Custom access or integration needs.
* **Budget reference or PO number** (`budget_reference`, Text, ): Provide purchase order if available.

## Tips
* Make sure to fill in all required fields (*) for accurate quote generation.
* If you have any custom or special requirements, please specify them in the "Additional requirements" field.
* We will contact you with the quote and answer any questions you may have.
* Please note that the "Desired subscription start date" field is not required for quote generation, but it will be taken into consideration for the quote.
