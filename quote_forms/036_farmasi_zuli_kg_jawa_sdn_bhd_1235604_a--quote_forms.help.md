# Farmasi Zuli Kg Jawa Sdn Bhd 1235604 A - Help Guide
## Purpose
This form is a quote collection tool for Farmasi Zuli Kg Jawa Sdn Bhd 1235604 A, allowing users to submit quotes from different categories, primarily for internal use.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter a title for the quote in the "Form Title" field.
2. Select the category from the "Category" dropdown menu.
3. Add a brief description of the quote in the "Description" field.
4. Optionally, provide a longer description of the quote in the "Description" field.
5. Select the tool assigned to handle the quote from the "Assigned Tool" dropdown menu.

## Field-by-Field Explanation
### Form Title (farmasi_zuli_kg_jawa_sdn_bhd_1235604_a_title)
* **Form Title** (text, required): Enter a title for the quote that will be used as a reference.

### Category (form_category)
* **Category** (select_one, optional): Select the category for the quote, either "Quote Forms" or "Other".

### Description (description)
* **Description** (text, optional): Add a brief description of the quote.

### Description (form_description)
* **Description** (text, optional): Provide a longer description of the quote, if necessary.

### Assigned Tool (form_assigned_tool)
* **Assigned Tool** (select_one, optional): Select the tool assigned to handle the quote, either "chatjimmy" or "Other".
