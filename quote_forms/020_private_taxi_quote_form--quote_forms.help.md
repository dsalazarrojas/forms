# private_taxi_quote_form - Help Guide
## Purpose
This form is used to provide details for a private taxi quote.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Quote Request" note with a brief description of your private taxi needs.
2. Select the pickup and drop off times using the "pickup_datetime" and "travel_datetime" fields.
3. Enter the travel distance in kilometers, if applicable.
4. Provide the pickup and drop off locations.
5. Select the assigned taxi driver from the available options.
6. Enter the estimated duration of the trip.
7. Enter the fare estimate for the trip.
8. Add any additional notes regarding the trip.

## Field-by-Field Explanation
* **Quote Request (Required)**: A brief description of your private taxi needs.
* **pickup_datetime (Required)**: Select the time of pickup.
* **travel_distance (Optional)**: If applicable, enter the travel distance in kilometers.
* **pickup_location (Optional)**: Enter the pickup location.
* **destination (Required)**: Enter the drop off location.
* **travel_datetime (Required)**: Select the time of drop off.
* **estimated_duration (Optional)**: Enter the estimated duration of the trip in minutes.
* **fare (Required)**: Enter the estimated fare for the trip.
* **assigned_driver (Required)**: Select the assigned taxi driver from the available options.
* **notes (Optional)**: Any additional notes regarding the trip.
