# Parkland Development Quote Request - Help Guide
## Purpose
The Parkland Development Quote Request form is designed to collect project information for the purpose of generating a quote. This form is used to gather details about a project, including its location, description, budget, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project details in the "Project Details" section.
2. Provide client information in the "Client Info" section.
3. Select the project location from the "Project Location" dropdown menu.
4. Enter a detailed description of the project in the "Project Description" field.
5. Enter the project budget in the "Project Budget" field.
6. Enter the project contact information in the "Project Contact" field.
7. Enter the project start and completion dates in the "Project Start Date" and "Project Completion Date" fields, respectively.
8. Select the project status from the "Project Status" dropdown menu.
9. Enter any relevant project notes in the "Project Notes" field.
10. Enter the contract value in the "Contract Value" field.

## Field-by-Field Explanation

* **Project Details** (`project_details`): This is the first section of the form, where you will enter the project title and description.
* **Client Info** (`client_info`): Here, you will enter the client's name, contact information, and any other relevant details.
* **Project Location** (`project_location`): Select the location of the project from the dropdown menu.
* **Project Description** (`project_description`): A detailed description of the project.
* **Project Budget** (`project_budget`): Enter the project budget.
* **Project Contact** (`project_contact`): Enter the contact information for the project.
* **Project Start Date** (`project_start_date`): Enter the start date of the project.
* **Project Completion Date** (`project_completion_date`): Enter the completion date of the project.
* **Project Manager** (`project_manager`): Enter the project manager's name and contact information.
* **Project Status** (`project_status`): Select the current status of the project.
* **Project Notes** (`project_notes`): Enter any relevant project notes.
* **Contract Value** (`contract_value`): Enter the contract value.

## Tips
* Make sure to fill in all required fields.
* Double-check the accuracy of the information provided.
* If you have any questions or need further clarification, contact the project team.
* This form is for internal use only, and the information collected will be used to generate a quote for the project.
