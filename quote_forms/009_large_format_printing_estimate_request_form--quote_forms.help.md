# large_format_printing_estimate_request_form - Help Guide
## Purpose

This form is used to request estimates for large format printing projects. It gathers information about the project's description, requirements, and contact details to facilitate the estimation process.

## How To Complete This Form

1. Start by providing a brief description of the project in the "Project Description" field.
2. Select the desired "Print Size" from the options provided (e.g., 11x17, 18x22, etc.).
3. Choose the "Material Type" that best suits your project's needs (e.g., Gloss Brochure, Matte Brochure, etc.).
4. Enter the quantity of prints required for your project.
5. If applicable, set a deadline for the project by selecting a date in the "Deadline" field.
6. Choose the production method for your project (e.g., Standard, Rush).
7. Add any additional information or details about the project in the "Notes" field.
8. Enter the contact email of the person responsible for the project.
9. Provide the contact phone number of the project manager or contact person.
10. If you have a project manager assigned, select the correct name from the list.

## Field-by-Field Explanation

* **Project Description** (`project_description`, text, required: false): A brief description of the project.
* **Print Size** (`print_size`, select_one, required: false): The size of the printed material (e.g., 11x17, 18x22, etc.).
* **Material Type** (`material_type`, select_one, required: false): The type of material to be used (e.g., Gloss Brochure, Matte Brochure, etc.).
* **Quantity** (`quantity`, number, required: false): The number of prints required.
* **Deadline** (`deadline`, date, required: false): The date by which the project needs to be completed.
* **Production Method** (`production_method`, select_one, required: false): The production method for the project (e.g., Standard, Rush).
* **File Upload** (`file_upload`, text, required: false): An optional field for uploading additional files related to the project.
* **Notes** (`notes`, note, required: false): Additional information about the project.
* **Contact Email** (`contact_email`, email, required: false): The email of the contact person.
* **Contact Phone** (`contact_phone`, text, required: false): The contact phone number of the project manager or contact person.
* **Project Manager** (`project_manager`, select_one, required: false): The project manager assigned to the project.

## Tips

* Make sure to fill out all required fields (though most are optional, they are still important for accurate estimation).
* If you're unsure about any field, please consult with your project manager or contact person.
* Be as specific as possible when providing information to ensure accurate estimation and timely completion of the project.
