# Smart Home Budget Calculator - Help Guide
## Purpose
The Smart Home Budget Calculator form is designed to help users estimate and plan their smart home budgets and setups. It collects information related to project details, smart home devices, and project management.

## How To Complete This Form
1. Select the correct answers for each field to provide a complete picture of your smart home project.
2. Answer each question to the best of your ability, providing accurate and truthful information.
3. Ensure all required fields are filled in for the form to be considered complete.

## Field-by-Field Explanation

### Project Details (Page 1)

* **Project Details**: Enter a brief description or name of your project.
	+ Purpose: Provide a clear and concise title for your project.
	+ Type: Text
	+ Required: No
* **Project Start Date**: Enter the start date of your project.
	+ Purpose: Record the start date of your project for planning and reference.
	+ Type: Date
	+ Required: No
* **Project End Date**: Enter the end date of your project.
	+ Purpose: Record the end date of your project for planning and reference.
	+ Type: Date
	+ Required: No

### Device and Budget

* **Smart Home Device**: Indicate if your project involves smart home devices.
	+ Purpose: Determine if you need to estimate costs for smart home devices.
	+ Type: Select One
	+ Options: Yes/No
	+ Required: No
* **Number of Devices**: If you selected yes, estimate the number of devices involved.
	+ Purpose: Provide a rough estimate of the number of devices to be installed.
	+ Type: Number
	+ Required: No
* **Device Price Range**: If you selected yes, estimate the price range of the devices.
	+ Purpose: Provide a rough estimate of the device costs.
	+ Type: Number
	+ Required: No
* **Smart Home Budget**: Estimate your total smart home budget.
	+ Purpose: Provide a rough estimate of your smart home budget.
	+ Type: Number
	+ Required: No

### Project Management

* **Installation Location**: Enter the location where the devices will be installed.
	+ Purpose: Record where the devices will be installed for reference.
	+ Type: Text
	+ Required: No
* **Project Status**: Indicate the current status of your project.
	+ Purpose: Record the status of your project for tracking progress.
	+ Type: Select One
	+ Options: Active/Inactive
	+ Required: No
* **Project Smart Home Pros**: Indicate if the project involves smart home pros.
	+ Purpose: Determine if you need to involve experts in the project.
	+ Type: Select One
	+ Options: Yes/No
	+ Required: No
* **Contact Person**: Indicate if you need to contact a person about the project.
	+ Purpose: Determine if you need to involve someone in the project.
	+ Type: Select One
	+ Options: Yes/No
	+ Required: No
* **Phone Number**: Enter the contact person's phone number.
	+ Purpose: Provide the contact information for the project contact person.
	+ Type: Text
	+ Required: No
* **Email**: Enter the contact person's email.
	+ Purpose: Provide the contact information for the project contact person.
	+ Type: Email
	+ Required: No
* **Message**: Enter any additional information about the project.
	+ Purpose: Provide any relevant details about the project.
	+ Type: Text
	+ Required: No
