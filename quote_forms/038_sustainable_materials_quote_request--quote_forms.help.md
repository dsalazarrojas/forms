# Sustainable Materials Quote Request - Help Guide
## Purpose
This form is used to collect information from clients about their sustainable materials quote request. It includes fields for project details, contact information, material requests, and submission status.

## How To Complete This Form
To complete this form, please fill out the following fields:
- Project Details: Provide a brief description of the project.
- Project Location: Enter the location of the project.
- Project Contacts: List the contacts involved in the project.
- Project Address: Enter the address of the project location.
- Client Name: Enter the name of the client.
- Contact Email: Enter the email address of the contact person.
- Project Type: Select the type of project (e.g., Option 1, Option 2, or Option 3).
- Material Requests: Select the materials requested (e.g., Option 1, Option 2, or Option 3).
- Supplier Name: Enter the name of the supplier.
- Supplier Contact Email: Enter the email address of the supplier contact.
- Supplier Phone: Enter the phone number of the supplier contact.
- Supplier Notes: Add any additional notes about the supplier.
- Submission Date: Enter the date the quote was submitted.
- Submission Time: Enter the time the quote was submitted.
- Delivery Date: Enter the expected delivery date for the materials.
- Delivery Time: Enter the expected delivery time for the materials.
- Delivery Status: Select the status of the delivery (e.g., Option 1, Option 2, or Option 3).
- Client Signature: Add the client's signature.
- Supplier Signature: Add the supplier's signature.
- Reported Date: Enter the date the issue was reported.
- Submitter: Enter the name of the person who submitted the form.
- Submitter Time: Enter the time the form was submitted.
- Submitted To: Select the person or department that the form was submitted to (e.g., Option 1, Option 2, or Option 3).
