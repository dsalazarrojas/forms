# Software Development Quote Request - Help Guide
## Purpose
This form is used to submit a quote request for a software development project. It will guide you through the necessary information needed to provide a comprehensive quote.

## How To Complete This Form
1. Fill out the form completely.
2. Click the "Submit" button when you have finished entering all required fields.
3. Review and confirm the submitted form to ensure it is accurate and complete before finalizing.

## Field-by-Field Explanation
* **Project Details** (page 1):
	+ **Project Details** (text): Briefly describe the project in a few sentences.
* **Project Lead** (page 1):
	+ **Project Lead** (text): Enter the name of the project lead or contact person.
	+ **Project Lead Email** (text/email): Enter the email address of the project lead or contact person.
* **Project Manager** (page 1):
	+ **Project Manager** (select-one):
		- Select "True" if the project has a manager.
	+ **Project Manager Name** (text): If the project has a manager, enter their name.
* **Project Deadline** (page 2):
	+ **Project Deadline** (date): Enter the expected project deadline.
* **Project Start Date** (page 2):
	+ **Project Start Date** (date): Enter the expected project start date.
* **Project Description** (page 2):
	+ **Project Description** (text): Briefly describe the project in 1-2 paragraphs.
* **Project Notes** (page 2):
	+ **Project Notes** (text): Add any additional notes or comments about the project.
* **Project Requirements** (page 3):
	+ **Project Requirements** (text): List the key deliverables and requirements for this project.
* **Project Estimated Cost** (page 3):
	+ **Project Estimated Cost** (number): Enter the estimated cost of the project.
* **Project Estimated Duration** (page 3):
	+ **Project Estimated Duration** (text): Estimate the project duration in terms of weeks or months.
* **Project Status** (page 3):
	+ **Project Status** (select-multiple):
		- Select all that apply: Open, In Progress, Closed, Cancelled.
	+ **Other Project Status** (text): If other, please describe the status.
* **Project Status Comment** (page 3):
	+ **Project Status Comment** (text): Add any comments about the project status.
* **Project Priority** (page 4):
	+ **Project Priority** (select-one):
		- Select Low, Medium, High.
	+ **Other Project Priority** (text): If other, please describe the priority.
* **Project Priority Comment** (page 4):
	+ **Project Priority Comment** (text): Add any comments about the project priority.
* **Project Technology** (page 4):
	+ **Project Technology** (select-one):
		- Select .net, java, javascript, other.
	+ **Other Project Technology** (text): If other, please describe the technology.
* **Project Technology Comment** (page 4):
	+ **Project Technology Comment** (text): Add any comments about the project technology.
* **Project Technology Details** (page 4):
	+ **Project Technology Details** (text): Add any additional technology-specific details.
* **Project Budget** (page 4):
	+ **Project Budget** (number): Enter the estimated budget of the project.
* **Other Project Budget** (page 4):
	+ **Other Project Budget** (text): If other, please describe the budget.
* **Project Budget Comment** (page 4):
	+ **Project Budget Comment** (text): Add any comments about the budget.

## Tips
- Be as detailed as possible when providing project information to ensure we can provide an accurate quote.
- If you are unsure about any field, please ask and we will guide you through the process.
- Please review and confirm your submitted form before finalizing to ensure accuracy and completeness.
