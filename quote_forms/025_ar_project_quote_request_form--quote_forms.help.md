# AR Project Quote Request Form - Help Guide
## Purpose

<Thinking>Before proceeding, please ensure you understand the purpose of this form. This form is used to request a quote for an Augmented Reality (AR) project. Please fill out this form carefully and thoroughly to help us provide an accurate quote. If you have any questions or concerns, feel free to contact us.

This form is used internally to gather project requirements and provide a quote for AR projects. Please do not submit this form if you are a reseller or have already spoken with us about this project. In such cases, please contact your sales representative for further instructions.

</Thinking>

## How To Complete This Form

To complete this form, simply fill out each field as follows:

1. **Client Full Name**: Enter your complete legal name.
2. **Client Email**: Enter your professional email for project communications.
3. **Client Company**: Enter the name of your company or organization.
4. **Client Phone**: Enter your contact number for project discussions.
5. **Project Name**: Enter a name for your AR project.
6. **Project Description**: Enter a detailed description of your AR project requirements.
7. **AR Application Type**: Select the type of AR application you need (e.g. Mobile App, Web-based AR, etc.).
8. **Target Platform**: Select the platforms you would like the AR application to support (e.g. iOS, Android, Web, etc.).
9. **Target Audience**: Enter who the intended audience is for this AR application.
10. **Desired Project Timeline**: Enter the date by which you would like the project to be completed.
11. **Project Budget Range**: Select the budget range you are looking to spend on this project.
12. **Required Features**: List the essential features you need in the AR application.
13. **Reference Examples**: Provide links or descriptions of AR applications you like.
14. **Special Requirements**: Enter any special technical or design requirements.
15. **Preferred Start Date**: Enter the date by which you would like the project to begin.

* **Desired Project Timeline** (`project_timeline`, text, required): Enter the date by which you would like the project to be completed.

* **Required Features** (`required_features`, text, required): List the essential features you need in the AR application.
