# Project Estimate And Policy Overview Form - Help Guide
## Purpose
This form is designed to collect and document project details, estimate, and policy information for project administrators and stakeholders. It's essential to fill out this form accurately to ensure that all project stakeholders are on the same page and can track project progress.

## How To Complete This Form

1.  Scroll through the form pages and select the "Project Estimate" page.
2.  In the "Project Estimate" page, fill out the project estimate-related fields:
   *   **Project Estimate**: This field is used to enter the project estimate, which is the estimated duration of the project.
   *   **Project Details**: Enter project-specific details to provide context to the project estimate.
   *   **Project Status**: Select the current project status from the dropdown options.
   *   **Policy Terms**: Enter any policy terms related to the project.
3.  Scroll through the remaining pages for additional fields related to project status, notes, locations, and more.

## Field-by-Field Explanation

*   **Project Estimate** (`project_estimate`, text, required): Enter the project estimate.
*   **Project Details** (`project_details`, text, required): Enter additional project details.
*   **Project Status** (`project_status`, select_one, required): Select the project status from the provided options.
*   **Project Approval** (`project_approval`, select_multiple, optional): Select the approval status of the project.
*   **Project Notes** (`project_notes`, text, required): Enter project notes.
*   **Project Hours** (`project_hours`, number, optional): Enter project hours.
*   **Project Location** (`project_location`, text, optional): Enter project location.
*   **Project Estimate Date** (`project_estimate_date`, date, optional): Enter the project estimate date.
*   **Project Status Notes** (`project_status_notes`, text, optional): Enter project status notes.
*   **Project Status Date** (`project_status_date`, date, optional): Enter the project status date.
*   **Project Status Time** (`project_status_time`, time, optional): Enter project status time.
*   **Project Status Location** (`project_status_location`, text, optional): Enter project status location.
*   **Project Approval Note** (`project_approval_note`, text, optional): Enter project approval note.
*   **Project Hours Note** (`project_hours_note`, text, optional): Enter project hours note.
*   **Project Status Note** (`project_status_note`, text, optional): Enter project status note.
*   **Project Note** (`project_note`, text, optional): Enter project note.
*   **Project Note Date** (`project_note_date`, date, optional): Enter project note date.
*   **Project Estimate Note** (`project_estimate_note`, text, optional): Enter project estimate note.
*   **Project Estimate Note 2** (`project_estimate_note_2`, text, optional): Enter additional project estimate note.
*   **Project Location Note** (`project_location_note`, text, optional): Enter project location note.
*   **Project Hours Note 2** (`project_hours_note_2`, text, optional): Enter project hours note 2.
*   **Project Status Note 2** (`project_status_note_2`, text, optional): Enter project status note 2.
*   **Project Estimate Date 2** (`project_estimate_date_2`, date, optional): Enter project estimate date 2.
*   **Project Estimate Date Time** (`project_estimate_date_time`, date, optional): Enter project estimate date time.

## Tips

*   Make sure to fill out all required fields accurately.
*   Review and double-check your entries for consistency and accuracy.
*   Use this form to document and track project progress.
*   Share the completed form with project stakeholders for transparency and collaboration.
*   Regularly update this form to reflect project changes and progress.
