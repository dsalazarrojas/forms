# Hardscape Project Estimate Request - Help Guide
## Purpose
The Hardscape Project Estimate Request form is used to collect project information for estimating the scope and feasibility of a project.

## How To Complete This Form
To complete this form, follow these steps:

1. **Project Details**: Provide a brief description of the project, including any relevant details that will help us better understand your request.
2. **Site Location**: Select the site location of the project from the available options.
3. **Preferred Date**: Choose a preferred start date for the project.
4. **Project Type**: Select the type of project you are requesting.
5. **Project Status**: Select the current status of the project from the available options.
6. **Project Description**: Provide a brief description of the project.
7. **Site Contact**: Enter the name of the contact person associated with the project site.
8. **Contact Name**: Enter your name.
9. **Project Notes**: Add any additional notes or comments about the project.
10. **Site Address**: Enter the address of the project site.
11. **Site City**: Enter the city of the project site.
12. **Site Postal**: Enter the postal code of the project site.
13. **Site State**: Select the state of the project site from the available options.
14. **Site Country**: Select the country of the project site from the available options.
15. **Project Budget**: Enter the estimated budget for the project.
16. **Project Start Date**: Enter the start date of the project.
17. **Project End Date**: Enter the end date of the project.
18. **Project Hours**: Enter the estimated hours required for the project.
19. **Project Duration**: Enter the estimated duration of the project.
20. **Project Status Update**: Add any updates or changes to the project status.
21. **Project Status**: Select the current status of the project from the available options.
22. **Project Priority**: Select the priority of the project from the available options.
23. **Project Tags**: Add any relevant tags or keywords associated with the project.
24. **Project Category**: Enter the category of the project.
25. **Project Comments**: Add any additional comments or information about the project.
