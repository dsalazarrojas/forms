# Translation Quote Request Form - Help Guide
## Purpose
This form is used to collect information from clients who are requesting translations. It gathers essential details such as project requirements, quote details, and client contact information to ensure accurate translation services can be provided.

## How To Complete This Form

1.  To complete this form, start by providing a brief overview of the project under "Project Details" (ID: 1).
2.  Next, fill in the "Client Info" (ID: 2) section with the client's name, phone number, and email.
3.  Move on to "Translation Requirements" (ID: 3) and provide a brief explanation of what needs to be translated.
4.  Fill in the "Quote Details" (ID: 4) section with the quote details, including date and price.
5.  In the "Contact Info" (ID: 5) section, provide the client's contact information.
6.  If required, attach a file under "File Attachment" (ID: 6).
7.  Finally, select the "Submission Status" (ID: 25) as "Pending", "Approved", or "Rejected" depending on the submission status.

## Field-by-Field Explanation
*   **Project Details (ID: 1)**: A brief overview of the project.
*   **Client Info (ID: 2)**: Essential contact information for the client, including name, phone number, and email.
*   **Translation Requirements (ID: 3)**: A brief explanation of what needs to be translated.
*   **Quote Details (ID: 4)**: Information about the quote, including date and price.
*   **Contact Info (ID: 5)**: The client's contact information.
*   **File Attachment (ID: 6)**: An optional field for attaching a file.
*   **Submission Status (ID: 25)**: Select the status of the submission as "Pending", "Approved", or "Rejected".
*   **Project Type (ID: 20)**: The type of project being requested.
*   **Language (ID: 21)**: The language for which the translation is requested.
*   **File Type (ID: 22)**: The type of file attached for translation (e.g., PDF, DOCX, JPG, PNG, or ZIP).
*   **Submission Status (ID: 25)**: Select the status of the submission as "Pending", "Approved", or "Rejected".
*   **Attachment (ID: 23)**: Optional field to attach a file.
*   **File Name (ID: 24)**: The name of the attached file.
*   **Quote Request (ID: 9)**: Details about the quote request.
*   **Quote Request Details (ID: 11)**: Detailed information about the quote request.
*   **Quote Request Date (ID: 12)**: The date of the quote request.
*   **Quote Request Time (ID: 13)**: The time of the quote request.
*   **Quote Request Price (ID: 14)**: The price of the quote request.
*   **Project Status (ID: 15)**: The status of the project.
*   **Client Name (ID: 16)**: The name of the client.
*   **Client Phone (ID: 17)**: The phone number of the client.
*   **Client Email (ID: 18)**: The email of the client.
*   **Project Deadline (ID: 19)**: The deadline for the project.
*   **Client Phone (ID: 17)**: The phone number of the client.
*   **Client Email (ID: 18)**: The email of the client.

## Tips
1.  Make sure to fill out all required fields as indicated by the asterisk (\*) in each field's label.
2.  If a file is attached, make sure it is in a supported format (PDF, DOCX, JPG, PNG, or ZIP).
