# Template Weekly - Help Guide
## Purpose
This form is used to collect information from customers for quote requests related to a service.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form to understand the required and optional fields.
2. Fill out the required fields (none are required, but it's assumed the customer has provided all relevant information):
	* `customer_name`
	* `phone`
	* `email`
	* `start_date`
3. If applicable, select the service type:
	* Service type: 
		+ `Yes`
		+ `No`
4. If the service type is `No` and you need to provide more information, use the `other` field to describe the service.

## Field-by-Field Explanation
### 1. Quote Form (`quote_form`):
	* **quote_form** (text, optional): Enter any additional comments or information about the service requested.

### 2. Service Type (`service_type`):
	* **Service Type** (select one, optional): Select `Yes` if the service requested is a standard service, `No` if it's not, or enter a description in the `other` field if it's not a standard service.

### 3. Other (Service Type) (`other`):
	* **Other** (text, optional): If you selected `No` for service type, describe the service requested in this field.

### 4. Customer Name (`customer_name`):
	* **Customer Name** (text, optional): Enter the customer's name.

### 5. Phone (`phone`):
	* **Phone** (text, optional): Enter the customer's phone number.

### 6. Email (`email`):
	* **Email** (email, optional): Enter the customer's email address.

### 7. Address (`address`):
	* **Address** (text, optional): Enter the customer's address.

### 8. Service Hours (`service_hours`):
	* **Service Hours** (time, optional): Enter the service hours requested.

### 9. Start Date (`start_date`):
	* **Start Date** (date, optional): Enter the start date of the service.

## Tips

* Make sure to complete all fields relevant to your service request.
* Be as descriptive as possible when providing information.
* If you need help or have questions, contact the sales or customer service team for assistance.
