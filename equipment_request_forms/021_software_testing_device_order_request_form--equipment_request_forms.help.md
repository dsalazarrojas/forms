# Software Testing Device Order Request Form - Help Guide
## Purpose
The Software Testing Device Order Request Form is a tool used to request the use of software testing devices from the company's inventory. This form is designed to gather necessary information for the proper processing of your request.

## How To Complete This Form
- Fill out the form completely and accurately.
- Double-check your information before submitting the form.
- If you have any questions or concerns, please contact the relevant department.

## Field-by-Field Explanation

* **Requested Device Id** (`requested_device_id`, text, required): Enter the unique identifier of the device you are requesting.
* **Device Name** (`device_name`, text, required): Provide the name of the device you are requesting.
* **Order Reason** (`order_reason`, text, required): Describe the purpose of your request, including any relevant details about the project or task.
* **Priority** (`priority`, select_one, true): Indicate the priority level of your request (Yes or No).
* **Shipping Date** (`shipping_date`, date, required): Enter the desired shipping date for the device.
* **Shipping Method** (`shipping_method`, select_one, required): Select Yes or No to indicate whether you want to receive the device by email or in-person.
* **Select Shipping Method** (`shipping_method_option_label`, text, false): This field is not required and should only be used to provide additional information if the shipping method selected in the previous field is by email.
* **Shipping Address** (`shipping_address`, text, false): This field is not required and should only be used if you selected in-person shipping method.
* **Order Notes** (`order_notes`, text, false): Provide any additional information about your request, such as special instructions or requirements.
* **Contact Person** (`contact_person`, text, false): Enter the name of the person to contact if needed.
* **Contact E-mail** (`contact_email`, email, false): Enter the email address of the person to contact if needed.
* **Contact Phone** (`contact_phone`, text, false): Enter the phone number of the person to contact if needed.
* **Additional Info** (`additional_info`, text, false): Provide any additional information that may be helpful for your request.
* **Testing Environment** (`testing_environment`, text, false): Describe the environment where the device will be used for testing.
* **Testing Setup** (`testing_setup`, text, false): Describe the setup you plan to use for testing with the device.
* **Testing Duration** (`testing_duration`, text, false): Estimate the duration of the testing process.
* **Priority** (`priority`, select_one, true): Note: This field appears twice, please ignore the second instance.

Note: The form requires the fields "Requested Device Id", "Device Name", "Order Reason", "Priority", and "Shipping Date" to be completed accurately. The other fields are optional and can be used to provide additional information if needed.
