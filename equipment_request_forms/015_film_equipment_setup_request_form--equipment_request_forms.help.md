# Film Equipment Setup Request Form - Help Guide
## Purpose
This form is designed to collect information from film crew members to request film equipment for a shoot.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out all the required fields (marked as "Required").
* Enter your information in the relevant fields as requested.
* If you need to request additional equipment not listed on this form, please use the "additional_equipment" field.
* Make sure to submit the form accurately and completely.

## Field-by-Field Explanation
* **Film Location** (`film_location`, text, Required):
	+ Enter the location where the shoot will take place.
* **Equipment Setup Details** (`equipment_setup_details`, text, Required):
	+ Briefly describe the equipment you need for the shoot.
* **Shooting Dates** (`shooting_dates`, date, Required):
	+ Enter the dates of the shoot.
* **Shooting Time** (`shooting_time`, time, Required):
	+ Enter the start and end time of the shoot.
* **Gear Needs** (`gear_needs`, select_multiple, Optional):
	+ Select the equipment you need for the shoot. Please select "Yes" for all necessary equipment.
* **Notes** (`notes`, note, Optional):
	+ Add any additional information or notes about the shoot.
* **Additional Equipment** (`additional_equipment`, select_one, Required):
	+ Select the additional equipment you need that is not listed on this form.
* **Team Name** (`team_name`, text, Required):
	+ Enter the name of the team or production company.
* **Contact Name** (`contact_name`, text, Required):
	+ Enter the name of the person in charge of the shoot.
* **Contact Email** (`contact_email`, email, Required):
	+ Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`, text, Required):
	+ Enter the phone number of the contact person.
* **Contact Notes** (`contact_notes`, note, Optional):
	+ Add any additional information or notes about the contact person.
* **Location Details** (`location_details`, text, Optional):
	+ Enter any additional details about the location.
* **Additional Equipment Notes** (`contact_notes`, note, Optional):
	+ Add any additional information or notes about the equipment needed.

Note: Please make sure to fill out the form accurately and completely, as this information will be used to coordinate the equipment for the shoot.
