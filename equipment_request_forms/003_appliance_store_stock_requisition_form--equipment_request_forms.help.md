# Appliance Store Stock Requisition Form - Help Guide
## Purpose
The Appliance Store Stock Requisition Form is used to request stock from the Appliance Store for business purposes. This form helps in tracking and managing stock requests, ensuring that the correct items are delivered to the right locations and in the right quantities.

## How To Complete This Form
1. Fill in the Requisition Date: This is the date when the stock requisition is submitted. Make sure to fill in the correct date in the correct format (DD/MM/YYYY).
2. Enter Requester Information: Provide your full name, email address, and contact phone number (optional). This information will be used for contact and verification purposes.
3. Select Department: Choose the department that is submitting the requisition. This will help in tracking and managing stock requests within the store.
4. Select Store Location: Choose the store location or branch where the stock will be used.
5. Select Item Category and Name: Choose the category and specific name of the item being requested.
6. Enter Quantity Requested: Enter the number of units being requested.
7. Enter Optional Information (if known): If you know the current stock level and unit cost, provide this information to help with stock management and ordering.
8. Select Urgency Level and Reason for Request: Choose the urgency level and provide a reason for the request (e.g., Low Inventory Replenishment, Customer Order, etc.).
9. Choose Delivery Method: Select how the stock should be delivered (Internal Transfer, Vendor Direct Delivery, Warehouse Pickup, etc.).
10. Add Special Instructions: If there are any special handling or delivery instructions, provide them here.
11. Approve or Request Manager Approval: If this requisition has already been approved, select "Approved". Otherwise, select "Pending Approval" and provide the name of the approving manager.
12. Enter Expected Delivery Date (if known): If the expected delivery date is known, provide it here.
13. Add Additional Comments: Enter any other relevant information about the request.

## Field-by-Field Explanation
* **Requisition Date (id: 1)**: Date when the stock requisition is submitted.
* **Requester Name (id: 2)**: Full name of the person requesting stock.
* **Requester Email (id: 3)**: Email address of the requester.
* **Requester Phone (id: 4)**: Contact phone number of the requester.
* **Department (id: 5)**: Department submitting the requisition.
* **Store Location (id: 6)**: Store location or branch name.
* **Item Category (id: 7)**: Category of appliances being requested.
* **Item Name (id: 8)**: Specific name or description of the item requested.
* **Model Number (id: 9)**: Manufacturer model number (if known).
* **Quantity Requested (id: 10)**: Number of units being requested.
* **Quantity in Stock (id: 11)**: Current stock level (if known).
* **Unit Cost (id: 12)**: Cost per unit (if known).
* **Total Estimated Cost (id: 13)**: Total estimated cost for this requisition (if known).
* **Urgency Level (id: 14)**: How urgently is this stock needed.
* **Reason for Request (id: 15)**: Why is this stock being requested.
* **Reason Details (id: 16)**: Additional details about the request reason.
* **Delivery Method (id: 17)**: How should the stock be delivered.
* **Special Instructions (id: 18)**: Any special handling or delivery instructions.
* **Manager Approval (id: 19)**: Has this request been approved by a manager.
* **Approving Manager (id: 20)**: Name of the approving manager.
* **Expected Delivery Date (id: 21)**: When is the stock expected to arrive.
* **Additional Comments (id: 22)**: Any other relevant information about the request.
