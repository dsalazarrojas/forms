# Environmental Cleanup Equipment Request Form - Help Guide
## Purpose
This form is used to request equipment for environmental cleanup projects. Fill out this form to submit your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project location where the equipment will be used.
2. Select the date you would like to receive the equipment.
3. Provide your contact details, including your name and phone number.
4. Enter your email address so we can contact you.
5. Indicate if you need a list of equipment to be delivered or not.
6. If necessary, include any delivery instructions to ensure smooth delivery of the equipment.
7. Submit the form.

## Field-by-Field Explanation

* **Project Location**: Enter the location of the project where the equipment will be used. This is a text field where you can type in a brief description of the project location.
* **Request Date**: Select the date you would like to receive the equipment. Please use the date format mm/dd/yyyy. This field is not required but helps us plan ahead.
* **Delivery Date**: Select a date for the delivery of the equipment. Please use the date format mm/dd/yyyy. This field is not required but helps us plan ahead.
* **Contact Details**: Enter your name and any other relevant contact information. This will help us contact you directly if we need more information.
* **Contact Email**: Enter your email address so we can contact you via email.
* **Contact Phone**: Enter your phone number so we can contact you via phone.
* **Equipment List**: Indicate if you need a list of equipment to be delivered or not. Please select one of the two options provided.
* **Delivery Instructions**: Enter any additional information to help us ensure smooth delivery of the equipment. This can include parking instructions, loading dock details, or any other information relevant to the delivery process.

## Tips

* If you need any special instructions for the delivery, please include them in the "Delivery Instructions" field.
* If you are unsure about any of the fields, please ask your supervisor for guidance.
* If you need to submit multiple requests, please ensure that only one request is submitted per project.
