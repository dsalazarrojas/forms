# Healthcare Surgical Equipment Order Request Form - Help Guide
## Purpose
This form is used to manage equipment requests in a healthcare setting, including tracking their status updates.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your contact information on the Contact Form page.
2. Provide facility information on the Facility Form page.
3. Specify the equipment status on the Equipment Form page.
4. Update the submission status and select the correct option from the options available.
5. Add any additional information in the Additional Information Form page.

## Field-by-Field Explanation
* **Request Form** (1, text, required): This field is used to describe the equipment request.
* **Facility Form** (2, text, false): This field is used to provide information about the facility where the equipment will be used.
* **Contact Form** (3, text, required): This field is used to provide contact information about who requested the equipment.
* **Additional Information** (4, text, false): This field can be used to provide any additional information about the equipment request.
* **Submission** (5, select_one, required): Select the status of the submission.
* **Equipment Status** (6, select_multiple, false): This field is used to describe the status of the equipment.
* **Equipment Return** (7, select_multiple, false): This field is used to indicate whether the equipment is available for return.
* **Submission Status** (8, select_one, required): Select the current status of the submission.
* **Notes Form** (9, text, false): This field can be used for any notes related to the submission.
* **Contact Form (2)** (10, text, false): This field is used to provide contact information about who requested the equipment.
* **Submission Form** (11, text, false): This field can be used for any additional information about the submission.
* **Additional Info Form** (12, text, false): This field can be used to provide any additional information about the submission.
* **Equipment Form** (13, text, false): This field is used to describe the equipment requested.
* **Form Page** (14, text, false): This field can be used for any notes or comments about the submission.
* **Contact Form Page** (15, text, false): This field can be used to provide contact information about who requested the equipment.
* **Facility Form (2)** (16, text, false): This field is used to provide information about the facility where the equipment will be used.
* **Submission Form (2)** (17, text, false): This field can be used to provide any additional information about the submission.
* **Equipment Ordered Form** (18, text, false): This field is used to indicate that the equipment has been ordered.
* **Contact Ordered Form** (19, text, false): This field is used to provide contact information about who ordered the equipment.
* **Equipment Return Form** (20, text, false): This field is used to indicate whether the equipment is available for return.
* **Facility Return** (21, text, false): This field can be used to provide information about the facility where the equipment is being returned.
* **Submission Return** (22, text, false): This field can be used to indicate the current status of the submission return.
* **Notes Return** (23, text, false): This field can be used to provide any notes related to the equipment return.
* **Form Return** (24, text, false): This field can be used to provide any additional information about the equipment return.
* **Contact Return** (25, text, false): This field can be used to provide contact information about who is responsible for the equipment return.
