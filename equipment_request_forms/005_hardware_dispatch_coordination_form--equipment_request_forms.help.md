# Hardware Dispatch Coordination Form - Help Guide

## Purpose
The **Hardware Dispatch Coordination Form** is used to gather information from users to coordinate the dispatch of hardware equipment. It is designed to ensure that all necessary details are provided to dispatchers for efficient and effective coordination.

## How To Complete This Form
To complete this form, follow these steps:
1. Review and select the **Request Information** page.
2. Indicate whether the request is for **Yes** or **No**.
3. Move to the **Equipment Information** page.
4. Provide a detailed description of the equipment being requested.
5. Move to the **Dispatch Timing** page.
6. Select the date and time for dispatch.
7. Move to the **Status Updates** page.
8. Add any relevant status updates or notes.

## Field-by-Field Explanation

* **Request Information** (`Yes/No`, `Select Multiple`, required: false): Indicate if the request is for equipment dispatch. Selecting **Yes** indicates that the request is for dispatch, while **No** indicates that it is not.
* **Equipment Information** (`Equipment Information`, `Text`, required: false): Describe the equipment being requested in detail, including make, model, and any other relevant specifications.
* **Dispatch Timing** (`Dispatch Timing`, `Date`, required: false): Enter the date and time for dispatch. Ensure the selected date and time align with the dispatch schedule.
* **Status Updates** (`Status Updates`, `Text`, required: false): Provide any relevant status updates or notes to aid in the dispatch process.
