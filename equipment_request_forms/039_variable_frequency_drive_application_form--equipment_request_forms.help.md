# Variable Frequency Drive Application Form - Help Guide
## Purpose
The Variable Frequency Drive Application Form is a tool used to collect necessary information for a VFD application. This form helps ensure that all required details are captured accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide user information on the first page.
2. Enter site-specific details on the second page.
3. Specify VFD details on the third page.
4. Enter motor details on the fourth page.
5. Select the frequency range and other specific drive details on the following pages.

## Field-by-Field Explanation

### 1. User Information
* **User Information** (`user_info`, `text`, required/optional): Enter your name and contact information as a required field for any form submission.

### 2. Site Information
* **Site Information** (`site_info`, `text`, required/optional): Enter the relevant site-specific details, such as site location or unique site identifiers.

### 3. VFD Details
* **VFD Details** (`vfd_details`, `text`, required/optional): Enter a brief description of the VFD system, including the model or type if applicable.

### 4. VFD Size And Config
* **VFD Size And Config** (`vfd_size_and_config`, `text`, required/optional): Enter the size and configuration details of the VFD, such as the number of phases or poles.

### 5. Motor Details
* **Motor Details** (`motor_details`, `text`, required/optional): Enter a description of the motor, including its size, model, or type.

### 6. Drive Details
* **Drive Details** (`drive_details`, `text`, required/optional): Enter a brief description of the drive system, including its application and environment.

### 7. Frequency Range
* **Frequency Range** (`frequency_range`, `text`, required/true): Enter the expected frequency range for the drive system. Ensure it is within the acceptable range as specified elsewhere in the documentation.

### 8. Motor Rating Power
* **Motor Rating Power** (`motor_rating_power`, `number`, required/optional): Enter the motor rating power, if applicable.

### 9. Drive Winding Type
* **Drive Winding Type** (`drive_winding_type`, `select_multiple`, required/optional): Select the drive winding type from the available options, as applicable.

### 10. Drive Winding
* **Drive Winding** (`drive_winding`, `select_multiple`, required/optional): Select the drive winding type from the available options, as applicable.

### 11. Motor Rating
* **Motor Rating** (`motor_rating`, `select_one`, required/optional): Select the motor rating from the available options, as applicable.

### 12. Frequency Range 2
* **Frequency Range 2** (`frequency_range_2`, `number`, required/optional): Enter the expected frequency range for the drive system (second instance).

### 13. Drive Size
* **Drive Size** (`drive_size`, `number`, required/optional): Enter the drive size, if applicable.

### 14. Motor Winding
* **Motor Winding** (`motor_winding`, `select_multiple`, required/optional): Select the motor winding type from the available options, as applicable.

### 15. Motor Winding Type
* **Motor Winding Type** (`motor_winding_type`, `select_multiple`, required/optional): Select the motor winding type from the available options, as applicable.

### 16. Motor Size
* **Motor Size** (`motor_size`, `number`, required/optional): Enter the motor size, if applicable.

### 17. Drive Winding Type 2
* **Drive Winding Type 2** (`drive_winding_type_2`, `select_multiple`, required/optional): Select the drive winding type from the available options, as applicable.

### 18. Drive Winding 2
* **Drive Winding 2** (`drive_winding_2`, `select_multiple`, required/optional): Select the drive winding type from the available options, as applicable.

### 19. Drive Rating
* **Drive Rating** (`drive_rating`, `number`, required/optional): Enter the drive rating, if applicable.

## Tips
* Please double-check your entries for accuracy, as incorrect information may lead to installation, commissioning, or maintenance issues.
* Ensure you have access to the necessary documentation or specifications for the motor and drive systems.
* If you are unsure about any field or requirement, please contact the designated contact person or refer to the relevant documentation.
