# Golf Course Equipment Order Request - Help Guide
## Purpose
The Golf Course Equipment Order Request form is a tool for golf course staff to request equipment for use on the course. This form is used to gather information about the equipment being requested, the preferred date for delivery, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Equipment Request Form" page, providing a detailed description of the equipment being requested.
2. Select the "Preferred Date" for delivery of the equipment.
3. Choose whether the equipment should be "Pickup" or "Delivery".
4. If applicable, enter the name of the "Pro Shop" where the equipment will be used or stored.
5. Enter the name of the "Course Manager" who will be using the equipment.
6. Add any additional "Notes" about the request.

## Field-by-Field Explanation
* **Equipment Request Form** (`equipment_request_form`, text, required): A detailed description of the equipment being requested. Please provide as much information as possible, including the type and quantity of equipment needed.
* **Preferred Date** (`preferred_date`, date, required): The date when the staff member would like to receive the equipment. Please use the date format MM/DD/YY.
* **Pickup or Delivery** (`pickup_delivery`, select_one, required): Choose whether you would like to pick up the equipment from the depot or have it delivered to the course.
* **Pro Shop** (`pro_shop`, text, optional): If applicable, enter the name of the pro shop where the equipment will be used or stored. This will help staff locate the equipment when it is returned.
* **Course Manager** (`course_manager`, text, optional): Enter the name of the course manager who will be using the equipment. This will help ensure the course manager is aware of who is using which equipment.
* **Notes** (`notes`, note, optional): Add any additional comments or information about the request, such as special instructions for handling or installation.

## Tips
* Please ensure that the equipment requested is not already available for use on the course.
* If requesting equipment for a specific event or tournament, please indicate this in the "Notes" field.
* If you are unsure about any of the fields, please ask your supervisor or the equipment manager for guidance.
