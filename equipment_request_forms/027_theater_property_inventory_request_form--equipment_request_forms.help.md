# Theater Property Inventory Request Form - Help Guide
## Purpose
This form is used to request new properties for use in events or productions at the theater.
## How To Complete This Form
To complete this form, follow the steps below:
1. Select the type of property you are requesting (e.g. Set Piece, Stage Set).
2. Enter the name of the property you are requesting.
3. Provide a description of the property.
4. Enter the location where the property will be used.
5. Specify the date and time you need the property by.
6. Enter your contact information, including your name, email, and phone number.
7. Select who the property is to be assigned to.
8. Add any additional notes about the property request.
9. Click "Submit" to submit your request.

## Field-by-Field Explanation
* **Prop Type** (Select One): Select the type of property you are requesting. This could be a Set Piece, Stage Set, etc.
* **Prop Name** (Text): Enter the name of the property you are requesting.
* **Prop Description** (Text): Provide a brief description of the property, including its size, material, and any other relevant details.
* **Location** (Text): Enter the location where the property will be used.
* **Date Needed** (Date): Specify the date you need the property by.
* **Time Needed** (Time): Specify the time you need the property by.
* **Contact Name** (Text): Enter your name.
* **Contact E-mail** (Email): Enter your email address.
* **Contact Phone** (Text): Enter your phone number.
* **Assigned To** (Select One): Select who the property is to be assigned to (e.g. chatjimmy, Other).
* **Notes** (Note): Add any additional notes about the property request.
* **Submit** (Text): Click this button to submit your request. 

## Tips
* Make sure to select the correct property type to ensure that the correct properties are ordered.
* Double-check your contact information to ensure that it is accurate.
* Add any additional notes if you have any specific requests or requirements.
* Review your submission carefully before clicking "Submit" to ensure that all information is accurate and complete.
