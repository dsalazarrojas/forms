# Mining Excavation Tools Requisition Form - Help Guide

## Purpose
This form is used to create a requisition for mining excavation tools. It helps in tracking the required tools, their status, and other relevant details. This form is usually filled out by team members to request for new tools or to report the status of existing tools.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Team Name in the "Team Name" field, which is the name of the team that will be using the tool.
2. Select the type of tool you need from the "Tool Type" dropdown menu.
3. Enter the date you want the tool to be delivered in the "Delivery Date" field.
4. Select the time you want the tool to be delivered in the "Delivery Time" field.
5. Enter the site location where the tool will be used in the "Site Location" field.
6. Enter a brief description of the tool you need in the "Tool Description" field.
7. Specify the priority of the tool request (High, Low, or Medium) in the "Priority" field.
8. If the tool has already been assigned, enter the assigned tool number in the "Assigned Tool" field.
9. Optionally, attach a file with the tool request details in the "Output File" field.
10. Enter any additional comments or notes about the tool request in the "Additional Comments" field.
11. Enter your contact information (email, phone number, etc.) in the "Contact Info" fields.
12. Enter your email address in the "Email" field.
13. Enter your phone number in the "Phone" field.
14. Enter your name in the "Submitted By" field.
15. Enter the date you submitted the form in the "Submitted On" field.
16. If a tool has already been submitted, enter the tool number in the "Submitted By Tool" field.
17. Select the status of the tool (Available, In Use, Out of Order, or Maintenance) in the "Tool Status" field.
18. Enter your name in the "Submitted By User" field.
19. Enter the location of the tool in the "Tool Location" field.
20. Enter a unique ID for the tool request in the "Tool Request ID" field.
21. Enter the category of the tool in the "Tool Category" field.
22. Enter your name in the "Created By" field.
23. Enter the date the form was created in the "Created On" field.

## Field-by-Field Explanation

* **Team Name**: The name of the team that will be using the tool. (text, required)
* **Tool Type**: The type of tool you need. (select_one, optional)
* **Delivery Date**: The date you want the tool to be delivered. (date, optional)
* **Delivery Time**: The time you want the tool to be delivered. (time, optional)
* **Site Location**: The location where the tool will be used. (text, optional)
* **Tool Description**: A brief description of the tool you need. (text, optional)
* **Priority**: The priority of the tool request (High, Low, or Medium). (select_one, optional)
* **Assigned Tool**: If the tool has already been assigned, enter the assigned tool number. (text, optional)
* **Output File**: Optionally, attach a file with the tool request details. (text, optional)
* **Additional Comments**: Any additional comments or notes about the tool request. (text, optional)
* **Contact Info**: Your contact information (email, phone number, etc.). (text, optional)
* **Email**: Your email address. (email, optional)
* **Phone**: Your phone number. (text, optional)
* **Submitted By**: Your name. (text, optional)
* **Submitted On**: The date you submitted the form. (date, optional)
* **Submitted By Tool**: If a tool has already been submitted, enter the tool number. (text, optional)
* **Tool Status**: The status of the tool (Available, In Use, Out of Order, or Maintenance). (select_multiple, optional)
* **Tool Location**: The location of the tool. (text, optional)
* **Tool Request Id**: A unique ID for the tool request. (text, optional)
* **Tool Category**: The category of the tool. (text, optional)
* **Created By**: Your name. (text, optional)
* **Created On**: The date the form was created. (date, optional)

Note: All fields are optional unless specified as required.
