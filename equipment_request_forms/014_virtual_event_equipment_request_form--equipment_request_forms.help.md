# Virtual Event Equipment Request Form - Help Guide
## Purpose
This form is used to request equipment for virtual events. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Select the equipment needed for the event from the drop-down menu.
3. Choose the delivery and return details for the requested equipment.
4. Enter the event team and IT team contact information.

## Field-by-Field Explanation
* **Event Details**: Enter a brief description of the event, including the event name and type.
* **Equipment Needed**: Select the equipment required for the event, such as "Yes" or "No".
* **Delivery Details**: Enter the delivery details, including the date and time of the delivery and the name of the person picking up the equipment.
* **Equipment Return**: Enter the return details, including the date and time of the return and the name of the person returning the equipment.
* **Delivery Option 1/2**: Choose the delivery option for the equipment. This will include options such as "Option a", "Option b", "Option c", and "Option d".
* **Return Details**: Enter any additional details about the return of the equipment.
* **Event Team Name**: Enter the name of the event team responsible for the event.
* **Event Team Email**: Enter the email address of the event team responsible for the event.
* **IT Team Name**: Enter the name of the IT team responsible for the equipment.
* **IT Team Email**: Enter the email address of the IT team responsible for the equipment.
* **AV Team Name**: Enter the name of the AV team responsible for the equipment.
* **AV Team Email**: Enter the email address of the AV team responsible for the equipment.
* **Schedule Start Date**: Enter the start date of the event.
* **Schedule End Date**: Enter the end date of the event.

## Tips
* Make sure to provide accurate and complete information to ensure timely delivery and return of the equipment.
* If you have any questions or need help with the form, contact the event support team.
* Double-check the event calendar to avoid duplicating events.
