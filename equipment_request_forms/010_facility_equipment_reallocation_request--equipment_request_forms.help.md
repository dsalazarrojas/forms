# Facility Equipment Reallocation Request - Help Guide

## Purpose
This form is used to request the reallocation of facility equipment from one location to another. It is intended for authorized personnel to use when equipment needs to be moved from one facility to another due to various reasons.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the form completely and accurately, providing all required information.
2.  Ensure that you are authorized to submit this form.
3.  Review and approve the form before submitting it for review.
4.  Attach any supporting documentation or evidence required for the reallocation request.
5.  Submit the form for review and approval by authorized personnel.

## Field-by-Field Explanation

* **Equipment Type** (Equipment Type, select_one, Required): Choose the type of equipment being reallocated (e.g. "A", "B", "C").
* **Move From** (Move From, select_one, Required): Select the current location of the equipment (e.g. "Location 1", "Location 2", "Location 3").
* **Move To** (Move To, select_one, Required): Select the desired location of the equipment (e.g. "Location 1", "Location 2", "Location 3").
* **Move Date** (Move Date, date, Required): Enter the date the equipment needs to be moved.
* **Reason for move** (Reason for move, text, Required): Provide a brief explanation of why the equipment needs to be reallocated.
* **Additional comments** (Additional comments, text, Optional): If there are any additional comments or information that support the reallocation request, you can provide them here.
* **Submitter details** (Submitter details, text, Optional): If you are submitting this form on behalf of someone else, please provide their name and title/position.
* **Reviewer details** (Reviewer details, text, Optional): If you are reviewing this form, please provide your name and title/position.
* **Approver details** (Approver details, text, Optional): If you are approving this form, please provide your name and title/position.

Note: The "Equipment Type", "Move From", "Move To", and "Move Date" fields are required fields and must be filled out accurately. The "Reason for move" field is also required but can be filled out briefly. The "Additional comments", "Submitter details", "Reviewer details", and "Approver details" fields are optional and can be filled out if relevant.
