# Toy Production Molds Requisition Form - Help Guide
## Purpose
This form is used to collect information about toy production molds requests from internal personnel. It is meant to be used to document requests for new or existing toy production molds, and should only be completed by those with relevant permissions and access.

## How To Complete This Form
To complete this form, follow these steps:

*   Ensure you have the necessary permissions and access to complete this form.
*   Fill out the form with accurate and relevant information about the toy production molds request.
*   Be thorough in your completion, as this form will be used to document and track requests.

## Field-by-Field Explanation
*   **toy_production_molds_request** (text, not required):
    *   This field is where you enter the detailed description of the toy production molds request, including the specific molds being requested and any relevant notes or comments.
*   **production_date** (date, not required):
    *   Enter the date the production molds were produced or the desired production start date for the request.
*   **production_shift** (select_one, not required):
    *   Select 'Yes' if this production mold is currently in use or 'No' if it is not.
*   **production_site** (text, not required):
    *   Enter the specific site where the production molds will be used or produced.
*   **production_type** (select_multiple, not required):
    *   Select all applicable types of production this mold is used for (e.g. 'Yes' for each type).
*   **production_status** (select_one, not required):
    *   Select 'Active' if the production mold is currently in production or 'Inactive' if it is not.
*   **assigned_tool** (text, not required):
    *   Enter the name of the assigned tool or equipment related to this production mold.

## Tips
*   Double-check your information for accuracy before submitting the form.
*   If you are unsure about any field or information required, contact your supervisor or relevant personnel for guidance.
