## Purpose
The Florist Sales Order Form is a form designed to collect relevant information from customers for sales orders for flowers and other floristry services. The form is intended to be used by sales teams to quickly and efficiently capture the details of customer orders.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the customer's details: 
   - Enter the **customer name**, if available.
   - Enter the **customer phone number**, if available.
   - Enter the **customer email**, if available.
2. Select the **order type**: 
   - Choose from the options provided for the type of order (e.g. birthday, valentines, anniversary).
3. Choose a **delivery date** and **delivery time**: 
   - Select a date for the order to be delivered.
   - Select a time for the order to be delivered.
4. Add any additional information in the **message** box.
5. If you need to add any notes for the order, type them in the **order note** box.

## Field-by-Field Explanation
### Form Data
*   **Form Data**: A text field to capture any additional information you need to complete the form. 

### Customer Details
*   **Customer Name**: Enter the customer's name, if provided.
*   **Customer Phone Number**: Enter the customer's phone number, if provided.
*   **Customer Email**: Enter the customer's email address, if provided.

### Order Details
*   **Order Type**: Select the type of order from the provided options (e.g. birthday, valentines, anniversary).
*   **Delivery Date**: Select a date for the order to be delivered.
*   **Delivery Time**: Select a time for the order to be delivered.

### Additional Information
*   **Message**: Add any additional information related to the order.
*   **Order Note**: Add any notes for the order, if needed.
