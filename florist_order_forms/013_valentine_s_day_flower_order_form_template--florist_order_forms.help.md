# Valentine's Day Flower Order Form - Help Guide
## Purpose

This form is designed to collect information from customers ordering flowers for Valentine's Day. It is used to capture essential details such as recipient's name, order details, delivery address, payment method, special requests, order status, delivery details, delivery time, delivery date, delivery status, and customer information. 

The form is intended for internal use and will be used to process the orders efficiently and ensure timely delivery.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the recipient's name in the "Recipient's Name" field.
2. Enter a brief description of the order in the "Order Details" field.
3. Enter the recipient's delivery address in the "Delivery Address" field.
4. Select a payment method from the "Payment Method" dropdown menu.
5. If necessary, enter any special requests in the "Special Request" field.
6. Select the order status from the "Order Status" dropdown menu.
7. Enter the delivery details in the "Delivery Details" field.
8. Enter the delivery time in the "Delivery Time" field.
9. Enter the delivery date in the "Delivery Date" field.
10. Select the delivery status from the "Delivery Status" dropdown menu.
11. Enter customer information in the "Customer Information" field.
12. If necessary, enter any additional notes in the "Additional Notes" field.

## Field-by-Field Explanation

* **Recipient's Name** (`recipient_name`, text, required): Enter the name of the person to whom the order is being placed.
* **Order Details** (`order_details`, text, required): Enter a brief description of the order.
* **Delivery Address** (`delivery_address`, text, required): Enter the recipient's address where the order will be delivered.
* **Payment Method** (`payment_method`, select_one, required): Select a payment method (Visa, Mastercard, Amex, Discover) to complete the payment.
* **Special Request** (`special_request`, text, optional): If you have any special requests for the order, enter them here.
* **Order Status** (`order_status`, select_one, required): Select the status of the order (Confirmed, Pending, Cancelled).
* **Delivery Details** (`delivery_details`, text, required): Enter the details of the delivery.
* **Delivery Time** (`delivery_time`, time, required): Enter the time for delivery.
* **Delivery Date** (`delivery_date`, date, required): Enter the date of the delivery.
* **Delivery Status** (`delivery_status`, select_one, required): Select the status of the delivery (Delivered, Pending, Cancelled).
* **Customer Information** (`customer_info`, text, required): Enter any additional customer information.
* **Additional Notes** (`additional_notes`, text, optional): If you have any additional notes or comments, enter them here.
