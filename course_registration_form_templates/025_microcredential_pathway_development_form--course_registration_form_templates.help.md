# Microcredential Pathway Development Form - Help Guide
## Purpose
This form is used to collect information about your use of microcredential pathway development forms. The purpose of this form is to gather data that will help us improve our services and provide better support for your use cases.
## How To Complete This Form
1. Review each question carefully and answer truthfully.
2. Select the correct options for each question.
3. Fill out all required fields.
## Field-by-Field Explanation

* **Are you using the course registration form?**: This question asks whether you are currently using the course registration form. Please select 'Yes' if you are using it for your microcredential development purposes.
* **What education teams are you working with?**: This field is for you to list the education teams you are working with. You can enter as many teams as necessary.
* **Do you have a microcredential program?**: This question asks whether you have a microcredential program in place. Please select 'Yes' if you have a program.
* **How do you collect structured data?**: This field is for you to describe how you collect structured data for your microcredential development.
* **Are you using JotForm form builder templates?**: This question asks whether you are using JotForm form builder templates for your microcredential development purposes. Please select 'Yes' if you are using them.
* **Are you using education teams with JotForm form builder templates?**: This question asks whether you are using education teams with JotForm form builder templates. Please select 'Yes' if you are using them.
* **Do you have a plan to approve education teams?**: This field is for you to describe your plan to approve education teams.
* **Do you have a plan to approve microcredential programs?**: This field is for you to describe your plan to approve microcredential programs.
* **Are you using JotForm form builder for microcredential pathway development forms?**: This question asks whether you are using JotForm form builder for microcredential pathway development forms. Please select 'Yes' if you are using them.
* **Do you have any help for microcredential pathway development forms?**: This field is for you to describe any help you have for microcredential pathway development forms.
* **Are you using education teams for planning and approving?**: This question asks whether you are using education teams for planning and approving. Please select 'Yes' if you are using them.
* **Are you using education teams with JotForm form builder templates?**: This question asks whether you are using education teams with JotForm form builder templates. Please select 'Yes' if you are using them.
Note: All fields are required unless otherwise stated. Please fill out all required fields to ensure that the data collected will be accurate.
