# Drama Academy Class Registration Form - Help Guide
## Purpose
The Drama Academy Class Registration Form is designed to help users register for a drama class. The form gathers user information such as name, contact information, course selection, and class scheduling.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your new student information, if applicable.
2. Enter your first and last name in the "First Name" and "Last Name" fields.
3. Enter your valid email address in the "Email" field.
4. Enter your birth date in the "Birth Date" field in the format MM/DD/YYYY.
5. Enter your contact number in the "Contact Number" field.
6. Select the drama course you want to enroll in from the "Drama Course" dropdown menu.
7. Choose your class level from the "Class Level" dropdown menu.
8. If you're registering for more than one class, select the corresponding number of classes from the "Total Classes" dropdown menu.
9. Enter the start and end dates of your classes in the "Class Start" and "Class End" fields in the format MM/DD/YYYY.

# Drama Academy Class Registration Form - Help Guide
## Field-by-Field Explanation

* **New Student Information** (`id: 1`): This section is for new students to provide additional information.
* **First Name** (`id: 2`): Enter your first name, e.g., John.
* **Last Name** (`id: 3`): Enter your last name, e.g., Doe.
* **Email** (`id: 4`): Enter a valid email address.
* **Birth Date** (`id: 5`): Enter your birth date in the format MM/DD/YYYY.
* **Contact Number** (`id: 6`): Enter your contact number. Please note that this field is not required.
* **Drama Course** (`id: 7`): Select the drama course you want to enroll in. The options are:
	+ Course A
	+ Course B
	+ Course C
* **Class Level** (`id: 8`): Choose your class level. The options are:
	+ Beginner
	+ Intermediate
	+ Advanced
* **Class Start** (`id: 9`): Enter the start date of your class in the format MM/DD/YYYY.
* **Class End** (`id: 10`): Enter the end date of your class in the format MM/DD/YYYY.
* **Total Classes** (`id: 11`): If you're registering for more than one class, select the corresponding number of classes. The options are:
	+ One
	+ Two
	+ Three
	+ Four
	+ Five
