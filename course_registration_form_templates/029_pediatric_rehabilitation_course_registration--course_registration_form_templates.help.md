# Pediatric Rehabilitation Course Registration - Help Guide
## Purpose
This form is designed for parents to register their children for pediatric rehabilitation courses.

## How To Complete This Form
1. Select one or more sessions for the course from the provided options.
2. Enter the parent's name as it appears on the government ID.
3. Provide the parent's date of birth.
4. Enter the parent's phone number.
5. Enter the parent's email.
6. Select one or more session dates.
7. Enter the parent's consent.
8. Provide any additional notes about the registration.
9. Select who submitted the registration (parent or another person).
10. If applicable, select the session time.
11. Select the session date.
12. Select the session duration.
13. Select the course price.
14. Select the payment status.
15. Select the course status.
16. Enter the user ID.
17. Enter the date created.
18. Enter the date updated.
19. Enter the date deleted.
20. Select who deleted the registration (user or system).
## Field-by-Field Explanation
* **Course Selection** (`course_selection`, `select_multiple`, required: false): Select one or more sessions for the course from the provided options.
* **Parent Name** (`parent_name`, `text`, required: false): Enter the parent's name as it appears on the government ID.
* **Birth Date** (`birth_date`, `date`, required: false): Provide the parent's date of birth.
* **Contact Number** (`contact_number`, `text`, required: false): Enter the parent's phone number.
* **Email** (`email`, `email`, required: false): Enter the parent's email.
* **Session Dates** (`session_dates`, `select_multiple`, required: false): Select one or more session dates.
* **Consents** (`consents`, `note`, required: false): Enter the parent's consent.
* **Notes** (`notes`, `note`, required: false): Provide any additional notes about the registration.
* **Submitted By** (`submitted_by`, `select_one`, required: false): Select who submitted the registration (parent or another person).
* **Submitted On** (`submitted_on`, `date`, required: false): Enter the date the registration was submitted.
* **Submitted On Time** (`submitted_on_time`, `time`, required: false): Enter the time the registration was submitted.
* **Session Time** (`session_time`, `time`, required: false): Select the session time.
* **Session Date** (`session_date`, `date`, required: false): Select the session date.
* **Session Duration** (`session_duration`, `number`, required: false): Select the session duration.
* **Course Price** (`course_price`, `number`, required: false): Select the course price.
* **Payment Status** (`payment_status`, `select_one`, required: false): Select the payment status.
* **Course ID** (`course_id`, `number`, required: false): Enter the course ID.
* **Submitted At** (`submitted_at`, `date`, required: false): Enter the date the registration was submitted.
* **Session Status** (`session_status`, `select_one`, required: false): Select the session status.
* **Course Status** (`course_status`, `select_one`, required: false): Select the course status.
* **User ID** (`user_id`, `number`, required: false): Enter the user ID.
* **Created At** (`created_at`, `date`, required: false): Enter the date the registration was created.
* **Updated At** (`updated_at`, `date`, required: false): Enter the date the registration was updated.
* **Deleted At** (`deleted_at`, `date`, required: false): Enter the date the registration was deleted.
* **Deleted By** (`deleted_by`, `select_one`, required: false): Select who deleted the registration (user or system).
