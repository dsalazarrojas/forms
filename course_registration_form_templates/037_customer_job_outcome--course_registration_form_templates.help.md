# Customer Job Outcome - Help Guide
## Purpose
This form is used to collect information about the outcome of a job for a customer.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's name in the "customer_name" field.
2. Enter the company name (if applicable) in the "company_name" field.
3. Enter the customer's job title in the "job_title" field.
4. Enter the number of hours the customer worked in the "weekly_hours" field.
5. Select the employment type (active or non-active) using the "employment_type" dropdown menu.
6. Enter the start date of the job using the calendar icon or by typing in the "start_date" field.
7. Enter the end date of the job using the calendar icon or by typing in the "end_date" field.
8. Select the customers the customer is working with using the "customer_id" field.

## Field-by-Field Explanation
* **Customer Name (customer_name)**: Enter the customer's full name.
* **Company Name (company_name)**: Enter the company name (if applicable) for which the customer works.
* **Job Title (job_title)**: Enter a brief description of the customer's job title.
* **Weekly Hours (weekly_hours)**: Enter the number of hours the customer worked on the job.
* **Employment Type (employment_type)**: Select the type of employment (active or non-active) to categorize the job outcome.
* **Start Date (start_date)**: Enter the start date of the job using the calendar icon or by typing in the date.
* **End Date (end_date)**: Enter the end date of the job using the calendar icon or by typing in the date.
* **Customer ID (customer_id)**: Select the customer(s) the customer is working with.

## Tips
* Make sure to select a customer ID from the list only if the customer is registered in the system.
* If the job has ended, ensure to select the "non-active" employment type.
* Double-check the entered dates for accuracy to avoid errors.
