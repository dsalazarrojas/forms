# ESL And Computer Skills Registration - Help Guide
## Purpose
This form is for learners who want to register for the ESL and Computer Skills course. It will help the course organizers understand your preferences and schedule to create a suitable course plan.

## How To Complete This Form
1. Review the form carefully and answer all the questions honestly.
2. Select the correct answers for each field based on your preferences and availability.
3. Make sure to check your answers before submitting the form.

## Field-by-Field Explanation
* **Enroll Learner**: Please select whether you are ready to enroll in the course.
* **Course Preferences**: Choose if you have any course preferences (e.g., yes or no).
* **Schedule**: Indicate if you have any schedule constraints (e.g., yes or no).
* **Learner Preferences**: Select any preferences you have as a learner (e.g., yes or no).
* **Class Roster**: Indicate if you are willing to be part of a class roster (e.g., yes or no).
* **Course Schedule**: Select any schedule preferences you have for the course (e.g., yes or no).
* **Proficiency Levels**: Indicate your current proficiency levels in languages and computer skills (e.g., high or low).
* **Learner Contact Info**: Indicate if you are willing to share your contact information (e.g., yes or no).
* **Course Preferences** (again): This is a confirmation question to make sure you are not missing any essential course preferences.

## Tips
* Please answer each question carefully, as it will help the course organizers create a tailored course plan for you.
* If you have any doubts or questions, do not hesitate to contact the course organizers.
* Make sure to submit the form only once, as it may create duplicate registration attempts.
