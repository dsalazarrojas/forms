# Watercolor Course Registration - Help Guide
## Purpose
The Watercolor Course Registration form is used to register students for a watercolor course. This form is intended to collect student information for course registration purposes, ensuring that each student is only registered once.

## How To Complete This Form
To complete this form, simply fill out the fields as instructed below. All fields are optional, but providing accurate and complete information is recommended for a smooth registration process.

## Field-by-Field Explanation
* **Student Name** (`student_name`, text, required: no): Please enter your full name as it appears on your student ID.
* **Email** (`email`, email, required: no): Enter your official university email address for communication purposes.
* **Start Date** (`start_date`, date, required: no): If you have a preferred start date for the course, you can enter it here. Leave blank if you do not have a specific start date.
* **Phone** (`phone`, text, required: no): Enter your phone number if you would like to be contacted for any course-related updates or reminders.
* **Instructor** (`instructor`, select_one, required: no): Indicate if you have a preferred instructor for the course (Yes/No).
* **Course** (`course`, select_multiple, required: no): Select all courses you would like to be registered for (Yes/No).
* **Registration Type** (`registration_type`, select_one, required: no): Indicate the type of course registration you are applying for (Yes/No).
* **Student ID** (`student_id`, number, required: no): If you have a student ID number, please enter it here for identification purposes.

## Tips
* Double-check your information for accuracy before submitting the form.
* If you are unsure about any field, please contact the course administrators for clarification.
* Only fill out the form once per student to avoid duplication of registrations.
