# Class And Teacher Filter Form - Help Guide
## Purpose
This form is designed to gather information from parents or guardians to help filter and match students to suitable classes within the school system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Select your preferred options for each field as accurately as possible.
3. Provide additional comments or requests in the "Additional Comments or Requests" field if needed.

## Field-by-Field Explanation
- **Parent or Guardian Name** (id: 1, text, required): Enter the full name of the parent or guardian who is completing this form.
- **Student Name** (id: 2, text, required): Enter the full name of the student who will be enrolled in the class.
- **Email Address** (id: 3, email, required): Enter the email address of the parent or guardian for correspondence.
- **Phone Number** (id: 4, text, required): Enter the best contact number of the parent or guardian.
- **Grade Level** (id: 5, select_one, required): Select the grade level of the student (Kindergarten to Grade 12).
- **Academic Year** (id: 6, select_one, required): Select the academic year for which the student will be enrolling (2025-2026, 2026-2027, etc.).
- **Semester or Term** (id: 7, select_one, required): Select the term or semester in which the student will be enrolling (Fall, Spring, etc.).
- **Subject Area of Interest** (id: 8, select_one, required): Select the subject area of interest for the class (Math, English, Science, etc.).
- **Class Level Preference** (id: 9, select_one, required): Select the preferred difficulty level of the class (Remedial or Support, Standard, Advanced or Honors, etc.).
- **Preferred Class Format** (id: 10, select_one, required): Select the preferred format of the class (In-person, Online, Hybrid or Blended, etc.).
- **Preferred Class Schedule** (id: 11, select_multiple, not required): Select the preferred time of day for the class (Morning, Afternoon, Evening, etc.).
- **Do You Have a Teacher Preference?** (id: 12, select_one, required): Indicate if you have a preferred teacher.
- **Preferred Teacher Name** (id: 13, text, not required): If you have a preferred teacher, enter their name.
- **Reason for Teacher Preference** (id: 14, text, not required): Explain why you prefer this teacher.
- **Preferred Class Size** (id: 15, select_one, required): Select the preferred class size (Small, Medium, Large, etc.).
- **Student Learning Style** (id: 16, select_one, required): Select the learning style of the student (Visual, Auditory, Kinesthetic, etc.).
- **Does Your Child Have Special Needs?** (id: 17, select_one, required): Indicate if the student has special needs.
- **Please Describe Special Needs** (id: 18, text, not required): If the student has special needs, provide a description.
- **Has Your Child Taken This Class Before?** (id: 19, select_one, required): Indicate if the student has taken this class before.
- **Enrollment Priority** (id: 20, select_one, required): Select the main factor in selecting the class (Teacher quality, Class schedule convenience, Class level and rigor, etc.).
- **Additional Comments or Requests** (id: 21, text, not required): Enter any additional comments or requests.

## Tips
- Please answer each field as accurately as possible to ensure the best possible match for your child's needs.
- If you have any questions or concerns, do not hesitate to contact the school administration.
- The more information you provide, the better we can understand your child's needs and preferences.
