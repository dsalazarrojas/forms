# Woodworking Class Proposal Form - Help Guide
## Purpose
The Woodworking Class Proposal Form is designed to collect and organize information for class proposals in a woodworking course. This form serves as a template for instructors to submit their class proposals, which will be reviewed and evaluated for approval.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the class details section (Class Proposal Form 1) with relevant information about the class, such as the class title, description, and objectives.
2. Provide instructor information in the Instructor Information section (Instructor Information).
3. Review and submit your proposal using the Review and Submit sections (Review, Submit).
4. If necessary, additional class proposal forms can be filled out for further details (Class Proposal Form 2-21).

## Field-by-Field Explanation
* **Class Proposal Form 1**: A text field for entering class title, description, or objectives.
* **Class Details**: A text field for providing additional class details.
* **Submit**: A text field for submitting your proposal.
* **Review**: A text field for reviewers to leave feedback or comments.
* **Instructor Information**: A text field for providing instructor's name, contact information, or bio.
* **Class Proposal Form 2-21**: Additional text fields for providing more details about the class.

## Tips
* Make sure to fill out each field accurately and thoroughly.
* Review your proposal carefully before submitting to ensure all necessary information is included.
* If you have any questions or need help, contact [form@gic.mx](mailto:form@gic.mx).
