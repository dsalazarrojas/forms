# Technology Mediated Learning Cohort Registration - Help Guide
## Purpose
This form is for registering a participant for the Technology Mediated Learning Cohort program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your First Name in the First Name field.
2. Fill in your Last Name in the Last Name field.
3. Enter your Email address in the Email field. Please ensure that your Email address is valid and up-to-date.
4. Enter your Phone Number in the Phone Number field. This can be a local or international number.
5. Select your Experience Level from the dropdown menu. If you don't see your experience level listed, please use the "Other Experience Level" field to provide a detailed description.
6. If you have an experience level that is not listed, please describe it in the "Other Experience Level" field.
7. Indicate whether you have a Learning Goal by selecting "Yes" or "No" from the dropdown menu. If you don't see your learning goal listed, please use the "Other Learning Goal" field to describe it.
8. If you have a learning goal that is not listed, please describe it in the "Other Learning Goal" field.

## Field-by-Field Explanation
* **First Name**: This is your name, as you want to be identified.
	+ Type: Text
	+ Required: Optional
* **Last Name**: This is your surname.
	+ Type: Text
	+ Required: Optional
* **Email**: This is your contact email address.
	+ Type: Email
	+ Required: Optional
* **Phone Number**: This is your contact phone number.
	+ Type: Text
	+ Required: Optional
* **Experience Level**: This is your level of experience in the Technology Mediated Learning Cohort program.
	+ Type: Select One
	+ Required: Optional
* **Other Experience Level**: If your experience level is not listed, please use this field to provide a detailed description.
	+ Type: Text
	+ Required: Optional
* **Learning Goal**: This is a learning goal you want to achieve in the Technology Mediated Learning Cohort program.
	+ Type: Select One
	+ Required: Optional
* **Other Learning Goal**: If your learning goal is not listed, please use this field to describe it.
	+ Type: Text
	+ Required: Optional

## Tips
- Make sure to provide accurate and up-to-date information.
- Use the "Other Experience Level" and "Other Learning Goal" fields only if your experience level or learning goal is not listed.
- If you are unsure about any field, feel free to contact the support team for assistance.
