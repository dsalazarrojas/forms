# Course Add Permission Request Form - Help Guide
## Purpose
The Course Add Permission Request Form is used to request permission to add a course that is currently restricted or closed. This form helps to collect and track student requests in a structured way.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the category of the course that you want to add from the dropdown list.
2. Provide a brief description of the request, including the reason why you need to add the course.
3. Submit the form to send your request to the approval team.

## Field-by-Field Explanation
* **Category** (`form_category`, select_one, required: false): Choose the category for the course you are requesting to add. The options are:
	+ Course Registration Form Templates
	+ Other
* **Description** (`form_description`, text, required: false): Enter a brief description of the request, including the reason why you need to add the course.
