# Theology Class Registration Form - Help Guide

## Purpose
This form is used to register new students for a theology class. Please fill out the form with your information to get started.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field with your information.
2. Review your selections carefully before submitting the form.

## Field-by-Field Explanation

* **Student Info** (student_info, text, optional): Please enter your name and any other relevant student information.
* **Course Preferences** (course_preferences, select_multiple, optional): Select the courses you are interested in registering for. You can choose multiple courses if applicable.
* **Date** (date, date, optional): Enter the date you would like to register for the class. Use the format mm/dd/yy.
* **Time** (time, time, optional): Enter the time you would like to attend the class. Use the 24-hour clock format (e.g., 14:00 for 2:00 PM).
* **Note** (note, note, optional): If you have any special requests or comments, please enter them here.
* **Email** (email, email, optional): Enter your email address so we can contact you about the class.
* **Phone** (phone, text, optional): Enter your phone number so we can reach you if needed.
* **Course** (course, select_one, optional): Choose the specific course you would like to register for from the list.
* **Theology Class** (theology_class, text, optional): Enter any additional information about the class you would like to register for.
* **Student Details** (student_details, text, optional): If you have any further details about yourself, please enter them here.

## Tips
- Make sure to select the correct courses and dates for your registrations.
- Double-check your information before submitting the form.
- If you have any issues or questions, contact us at your email or phone number.
