# CrowdStrike Issue Form - Help Guide
## Purpose
This guide will walk you through the steps to complete the CrowdStrike Issue Form. The form is designed to collect information about new issues reported by users.

## How To Complete This Form

1. Fill out the form with the required fields (if any). Required fields are marked with an asterisk (\*).
2. Ensure that all fields are accurate and up-to-date.
3. Review your input before submitting the form.

## Field-by-Field Explanation

* **Report Details**: Enter a brief description of the report, if necessary. (Text)
* **Issue Description**: Provide a detailed description of the issue being reported. (Text)
* **Issue Category**:
	+ Select one of the following options: Critical, High, or Low, to indicate the severity of the issue.
* **Issue Priority**:
	+ Select one of the following options: Critical, High, or Medium, to indicate the priority of the issue.
* **Assignee**:
	+ Select one or more individuals to be assigned to the issue. You can choose from: chatjimmy, Other.
* **Issue Tags**:
	+ Select one or more tags to help identify the issue type. You can choose from: bug, feature.
* **Issue Reported By**:
	+ Select one of the following options: Customer, Internal Team, to indicate who reported the issue.
* **Issue Reported Date**: Enter the date the issue was reported. (Date)
* **Issue Reported Time**: Enter the time the issue was reported. (Time)
* **Issue Status**:
	+ Select one of the following options: Open, Closed, to indicate the status of the issue.

## Tips
* Double-check your input for accuracy before submitting the form.
* Ensure that all fields are filled out correctly and that the issue is properly categorized and tagged.
* If you are unsure about any field or require assistance, please contact your team or administrator for help.
* If you have already submitted an issue report for the same problem, do not submit another report. This will help prevent duplicate reports and ensure that issues are properly tracked and resolved.
