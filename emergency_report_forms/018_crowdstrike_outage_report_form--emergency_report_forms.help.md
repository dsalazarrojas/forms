# Crowdstrike Outage Report Form - Help Guide

## Purpose

The Crowdstrike Outage Report Form is designed to report outages or incidents that have affected Crowdstrike services. This form is used to collect relevant information about the outage, including the services impacted, start and end times, and duration.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the incident details in the `Incident Details` field.
2. Select the affected services from the `Affected Services` dropdown menu.
3. Enter the start and end times of the outage using the `Outage Start Time` and `Outage End Time` fields, respectively.
4. Enter the duration of the outage in the `Duration` field.
5. Provide a description of the outage in the `Description` field.

## Field-by-Field Explanation

* **Incident Details** (incident_details): 
  Enter a brief description of the incident, including any relevant background information.
* **Affected Services** (affected_services): 
  Select the services that were affected by the outage.
* **Outage Start Time** (outage_start_time): 
  Enter the time when the outage started.
* **Outage End Time** (outage_end_time): 
  Enter the time when the outage ended.
* **Duration** (duration): 
  Enter the length of time the outage lasted.
* **Description** (description): 
  Provide a detailed description of the outage, including any necessary context or explanation.
