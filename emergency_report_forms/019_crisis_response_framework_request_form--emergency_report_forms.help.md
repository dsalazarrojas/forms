# Crisis Response Framework Request Form - Help Guide

## Purpose
The Crisis Response Framework Request Form is used to collect information for crisis response efforts. This form helps us understand the situation, gather relevant details, and provide support as needed.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the **Request Info** section by providing a brief description of the crisis or issue at hand.
2. Enter your **Contact Info** details, including your name and any other relevant contact information.
3. Provide **Incident Details** in the corresponding field.
4. Share **Support Info** if you have any supporting information or resources to aid in the response.
5. If applicable, upload **Request Attachment** and **Submission Attachment** to provide additional context.
6. Leave **Request Comments** and **Submission Comments** fields for any additional information you'd like to convey.
7. Enter your **Email** address so we can get in touch with you.
8. Add your **Phone** number for quick contact.
9. Choose a date and time for the crisis or issue (if applicable).
10. Select from the provided options in **Select One**, **Select Multiple**, and **Select Multiple Required** fields as instructed.
11. Ensure you select the correct options in **Select One Required** field.
12. Enter numerical values in **Decimal** and **Integer** fields as needed.
13. Select the correct options in **Select One 2** and **Select Multiple 2** fields as instructed.
14. Enter a date and time in the **Date Time Required** field.
15. Select the required options in **Select Multiple Required** field.
16. Finally, enter your **Phone Required** number.
