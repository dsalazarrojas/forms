# Public Event Visitor Injury Incident Report Form - Help Guide
## Purpose

This form is designed to collect information about incidents or injuries that occurred during public events. This form helps event organizers and first aid responders gather details about the incidents, including the event location, date, and time, as well as the severity of the injury and the treatment provided. The information collected will help in case of any follow-up actions or medical attention needed.

## How To Complete This Form

1. Fill in the required fields with accurate and clear information.
2. Make sure to provide as much detail as possible for each field.
3. If a field is not applicable, please leave it blank.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, required): Enter a brief description of the event where the incident occurred.
* **Injury Summary** (`injury_summary`, text, required): Summarize the injury or incident that occurred.
* **Visitor Details** (`visitor_details`, text, required): Provide the full name and contact information of the visitor involved.
* **Injury Description** (`injury_description`, text, required): Describe the details of the injury or incident.
* **Injury Severity** (`injury_severity`, text, required): Assess the severity of the injury.
* **Injury Treatment** (`injury_treatment`, text, required): Describe the treatment provided to the visitor.
* **Medical Attention** (`medical_attention`, text, required): Indicate if medical attention was provided.
* **Witness** (`witness`, text, optional): If there was a witness, enter their name or 'None' if there was no witness.
* **Witness Details** (`witness_details`, text, optional): Provide more information about the witness, if applicable.
* **First Aid** (`first_aids`, text, required): Describe the first aid provided.
* **Medical Report** (`medical_report`, text, required): Attach a medical report, if available.
* **Incident Reported To** (`incident_reported_to`, text, required): Specify to whom the incident was reported.
* **Follow Up** (`follow_up`, text, required): Provide any follow-up actions taken or recommended.
* **Incident Reported By** (`incident_reported_by`, text, required): Specify who reported the incident.
* **Incident Date** (`incident_date`, date, required): Enter the date the incident occurred.
* **Incident Time** (`incident_time`, time, required): Enter the time the incident occurred.
* **First Aider** (`first_aider`, text, required): Specify the name of the first aider.
* **First Aider's Role** (`first_aider_role`, text, required): Specify the role of the first aider.
* **First Aider's Location** (`first_aider_location`, text, required): Specify the location where the first aider was present.
* **First Aider's Contact Info** (`first_aider_contact_info`, text, required): Enter the contact information of the first aider.
* **Incident Location** (`incident_location`, text, required): Specify the location of the incident.
* **Incident Location Other** (`incident_location_other`, text, required): If the incident location is not among the options, choose 'Other' and provide the location.
* **Incident Type** (`incident_type`, text, required): Specify the type of incident.
* **Incident Type Other** (`incident_type_other`, text, required): If the incident type is not among the options, choose 'Other' and specify the type.
