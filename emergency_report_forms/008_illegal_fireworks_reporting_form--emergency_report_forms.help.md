# illegal_fireworks_reporting_form - Help Guide
## Purpose
This form is designed to gather information about illegal fireworks incidents. The purpose of this form is to help gather data on the location, time, and description of the incident, as well as any witnesses who may have seen the incident.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the location where the incident occurred.
2.  Enter the date and time of the incident.
3.  Check if fireworks were used and choose the appropriate option from the dropdown list.
4.  If applicable, enter the number of fireworks used.
5.  Indicate the noise level of the incident.
6.  Check if you called 911 and reported the incident to the police.
7.  Indicate if you or others witnessed the incident and can provide a description of what was seen.
8.  Enter a description of the incident.
9.  Enter any witness statements.
10.  Describe the suspect, including their age, gender, height, and weight (if applicable).
11.  Enter any other relevant information about the incident.

## Field-by-Field Explanation

* **Location** (Text): Enter the location where the incident occurred.
* **Date of Incident** (Date): Enter the date of the incident in MM/DD/YYYY format.
* **Time of Incident** (Time): Enter the time of the incident in 12-hour format.
* **Type of Fireworks** (Select One): Check the box that best describes the type of fireworks used. Options:
	+ Yes
	+ No
* **Color of Fireworks** (Select Multiple): Check all that apply:
	+ Yes
	+ No
* **Number of Fireworks** (Number): Enter the number of fireworks used (if applicable).
* **Noise Level** (Number): Enter the level of noise made during the incident (on a scale of 1-10).
* **Did you call 911?** (Select One): Check if you called 911 after the incident. Options:
	+ True
	+ False
* **Did you report to police?** (Select One): Check if you reported the incident to the police. Options:
	+ True
	+ False
* **Witness Statements** (Text): Enter any witness statements about the incident.
* **Description of Incident** (Text): Enter a detailed description of the incident.
* **Suspect Description** (Text): Enter a description of the suspect, including any distinctive features or clothing.
* **Suspect Age** (Number): Enter the suspect's age (if known).
* **Suspect Gender** (Select One): Check the suspect's gender. Options:
	+ Yes
	+ No
* **Suspect Height** (Number): Enter the suspect's height (if known).
* **Suspect Weight** (Number): Enter the suspect's weight (if known).
