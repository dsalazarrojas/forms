# Fire Call Report Sheet Form - Help Guide
## Purpose
The "Fire Call Report Sheet Form" is used to gather information about incidents, including fire response efforts, and is a crucial tool in the incident reporting process.

## How To Complete This Form
- Ensure you have all necessary information about the incident before starting the form.
- Carefully review each field to ensure accuracy and completeness.
- Enter the correct information in each field as instructed.

## Field-by-Field Explanation

* **Fire Call Date** (`fire_call_date`, date, required/optional): Enter the date of the fire call, using the standard date format (MM/DD/YY).
* **Fire Station** (`fire_station`, select_one, required/optional): Select the name of the fire station that responded to the incident.
* **Engine Company** (`engine_company`, select_multiple, required/optional): Choose all relevant engine companies that responded to the incident.
* **Fire Department** (`fire_department`, select_one, required/optional): Select the name of the fire department that responded to the incident.
* **Incident Type** (`incident_type`, select_one, required/optional): Choose the type of incident that occurred (e.g., fire, rescue, medical).
* **Incident Status** (`incident_status`, select_one, required/optional): Select the status of the incident (e.g., active, inactive).
* **Incident Details** (`incident_details`, note, required/optional): Enter any additional notes or details about the incident.
* **Incident Location** (`incident_location`, select_one, required/optional): Select the location of the incident.
* **Reporting Officer Name** (`reporting_officer_name`, text, required/optional): Enter your name as the person reporting the incident.
* **Reporting Officer Number** (`reporting_officer_number`, number, required/optional): Enter your reporting officer number.
* **Reporting Date** (`reporting_date`, date, required/optional): Enter the date of the report.
* **Reporting Time** (`reporting_time`, time, required/optional): Enter the time of the report.
* **Incident Time** (`incident_time`, time, required/optional): Enter the time of the incident.
* **Reporting Unit** (`reporting_unit`, select_one, required/optional): Choose the unit that responded to the incident.
* **Reporting Officer Notes** (`reporting_officer_notes`, note, required/optional): Enter any additional notes from the reporting officer.
* **Incident Notes** (`incident_notes`, note, required/optional): Enter any additional notes about the incident.
* **Fire Call Sheet Number** (`fire_callsheet_number`, text, required/optional): Enter the fire call sheet number.
* **Unit Status** (`unit_status`, select_one, required/optional): Select the status of the unit responding to the incident.
* **Officer in Charge** (`officer_in_charge`, select_one, required/optional): Select the officer in charge of the incident response.
* **Unit Location** (`unit_location`, select_one, required/optional): Select the location of the responding unit.
* **Incident Date** (`incident_date`, date, required/optional): Enter the date of the incident.
* **Incident Reported** (`incident_reported`, select_one, required/optional): Select whether the incident was reported (true/false).
* **Incident Status** (`incident_status`, select_one, required/optional): Select the status of the incident (e.g., active, resolved).
* **Incident Reported By** (`incident_reported_by`, text, required/optional): Enter the person who reported the incident.
