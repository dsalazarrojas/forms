# Disaster Resource Access Request Form - Help Guide
## Purpose

This form is used to request resources in response to a disaster. This form is a crucial part of the disaster response process, and it helps to ensure that aid is delivered efficiently and effectively.

## How To Complete This Form

1.  Start by filling out the "Emergency Report Form" section, which provides a brief overview of the disaster event.
2.  In the "Disaster Name" field, enter the name of the disaster event.
3.  Select the resource type(s) required from the list provided.
4.  Enter the quantity of resources needed.
5.  If applicable, select the resource unit(s) in which the resources should be delivered.
6.  Enter any additional contact information, such as phone numbers and email addresses.
7.  Briefly describe the location where the resources are needed.
8.  Enter a description of the situation.
9.  Select the status of the resource(s) being requested.
10. If applicable, select the aid offered.
11.  Enter the date on which aid was requested.
12.  Enter the date on which aid was received.
13.  Enter the quantity of aid delivered.
14.  If applicable, select the aid delivered unit(s).
15.  Enter the resource availability.
16.  Select the aid status.
17.  Select the disaster status.
18.  Enter the name of the aid officer.
19.  Enter any additional notes.
20.  Select the type of disaster.
21.  Enter the contact person's name.
22.  Enter the contact person's phone number.
