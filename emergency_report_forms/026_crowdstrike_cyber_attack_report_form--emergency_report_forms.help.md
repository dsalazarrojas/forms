# CrowdStrike Cyber Attack Report Form - Help Guide

## Purpose
The CrowdStrike Cyber Attack Report Form is used to report and document cyber attacks that have occurred on the system. This form helps gather relevant information about the attack, including the user's ID, date and time of the attack, and details about the attacker's IP address, browser, and operating system.

## How To Complete This Form

1. **User ID**: Enter your internal User ID, if applicable.
2. **Date Of Attack**: Select the date of the cyber attack.
3. **Time Of Attack**: Select the time of the cyber attack.
4. **Impact**: Choose the impact level of the attack (Low, Medium, High, or Critical).
5. **Response**: Provide a brief description of your response to the attack.
6. **Resolution**: Indicate if the attack has been resolved (None, In Progress, Completed, or Unknown).
7. **Notes**: Add any additional comments or notes about the attack.
8. **User Comments**: Enter any additional comments about the attack.
9. **Attacker IP**: Enter the IP address of the attacker.
10. **Country**: Select the country of the attacker (US or Other).
11. **Attacker Location**: Select the location of the attacker (US or Other).
12. **Attacker OS**: Select the operating system used by the attacker (Windows, Mac, Linux, or Unknown).
13. **Attacker Browser**: Select the browser used by the attacker (IE, Chrome, Firefox, or Other).
14. **Ip Address**: Enter any additional IP addresses related to the attack.
15. **User Agent**: Enter the user agent string associated with the attack.
16. **Referer**: Enter the referer string associated with the attack.
17. **User Agent String**: Enter any additional user agent string information.
18. **Http User Agent**: Enter the HTTP user agent string.
19. **X Forwarded For**: Enter the X-Forwarded-For string.
20. **Http Referer**: Enter the HTTP referer string.
21. **Http Accept**: Enter any additional HTTP Accept headers associated with the attack.
22. **Http Accept Language**: Enter the HTTP accept language string.
23. **Http User Agent String**: Enter any additional HTTP user agent string information.
24. **Attacker Name**: Enter the attacker's name (if known).
25. **Attacker Email**: Enter the attacker's email address (if known).

## Field-by-Field Explanation

* **User ID** (1, number, required): Enter your internal User ID.
* **Date Of Attack** (2, date, required): Select the date of the cyber attack.
* **Time Of Attack** (3, time, required): Select the time of the cyber attack.
* **Impact** (4, select_one, optional): Choose the impact level of the attack (Low, Medium, High, or Critical).
* **Response** (5, note, optional): Provide a brief description of your response to the attack.
* **Resolution** (6, select_multiple, optional): Indicate if the attack has been resolved (None, In Progress, Completed, or Unknown).
* **Notes** (7, note, optional): Add any additional comments or notes about the attack.
* **User Comments** (8, note, optional): Enter any additional comments about the attack.
* **Attacker IP** (9, number, optional): Enter the IP address of the attacker.
* **Country** (10, select_one, optional): Select the country of the attacker (US or Other).
* **Attacker Location** (11, select_multiple, optional): Select the location of the attacker (US or Other).
* **Attacker OS** (12, select_multiple, optional): Select the operating system used by the attacker (Windows, Mac, Linux, or Unknown).
* **Attacker Browser** (13, select_multiple, optional): Select the browser used by the attacker (IE, Chrome, Firefox, or Other).
* **Ip Address** (14, text, optional): Enter any additional IP addresses related to the attack.
* **User Agent** (15, text, optional): Enter the user agent string associated with the attack.
* **Referer** (16, text, optional): Enter the referer string associated with the attack.
* **User Agent String** (17, text, optional): Enter any additional user agent string information.
* **Http User Agent** (18, text, optional): Enter the HTTP user agent string.
* **X Forwarded For** (19, text, optional): Enter the X-Forwarded-For string.
* **Http Referer** (20, text, optional): Enter the HTTP referer string.
* **Http Accept** (21, text, optional): Enter any additional HTTP Accept headers associated with the attack.
* **Http Accept Language** (22, text, optional): Enter the HTTP accept language string.
* **Http User Agent String** (23, text, optional): Enter any additional HTTP user agent string information.
* **Attacker Name** (24, text, optional): Enter the attacker's name (if known).
* **Attacker Email** (25, email, optional): Enter the attacker's email address (if known).

Note: This form is used to document and report cyber attacks, and is intended to provide detailed information about the attack and its resolution.
