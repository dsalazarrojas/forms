# flood_incident_form - Help Guide

## Purpose
The flood incident form is a crucial tool for emergency responders and other stakeholders to collect and report information about flood incidents. This form helps to gather essential details about the incident, including location, time, and description, as well as potential impacts on the affected area, population, and infrastructure.

## How To Complete This Form
To complete the flood incident form, follow these steps:

1. Enter the location where the incident occurred (e.g., street address, city, state).
2. Select the date and time of the incident.
3. Provide a brief description of the incident.
4. Select the type of flood incident (e.g., flood, landslide, storm surge, tsunami).
5. If necessary, provide additional details about the affected area, population, and infrastructure.
