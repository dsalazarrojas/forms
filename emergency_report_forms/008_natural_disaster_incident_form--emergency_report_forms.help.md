# natural-disaster-incident-form - Help Guide
## Purpose
The "natural-disaster-incident-form" is designed to collect information about incidents or events related to natural disasters. This form helps to gather details about the incident, including location, damage description, affected people, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the required fields (you can check the "required" label in each field to see if it's mandatory).
2. Provide as much detail as possible for each field, as this information will help us understand the incident better.
3. Double-check your answers for accuracy and completeness before submitting the form.

## Field-by-Field Explanation
### Incident Information
* **Incident Information**: This is the main section of the form. Provide a brief description of the incident.
* **Damage Description**: Describe the damage caused by the incident in as much detail as possible.
* **Incident Location**: Select one or multiple locations affected by the incident. This will help us understand where the incident occurred.
* **Affected People**: Enter the number of people affected by the incident.
* **Damage Amount**: Enter the estimated damage amount (in the local currency).
* **Incident Date**: Select the date when the incident occurred.
* **Incident Time**: Select the time when the incident occurred.
* **Time Zone**: Select the time zone where the incident occurred.
* **Incident Description**: Provide a more detailed description of the incident.
* **Incident Type**: Select the type of incident (e.g., earthquake, hurricane, flood, etc.).
* **Incident Severity**: Select the severity level of the incident (e.g., minor, moderate, severe, etc.).
* **Time Zone**: Select the time zone where the incident occurred (if not specified in the incident location).

## Tips
* Please be as accurate as possible when filling out the form.
* If you're unsure about any field, feel free to ask for clarification.
* The more information you provide, the better we'll be able to understand the incident.
