# Crisis Communication Form - Help Guide
## Purpose
The Crisis Communication Form is a tool used to report emergencies or incidents, providing essential details for swift response and resolution.

## How To Complete This Form
1. Please fill out the form completely and accurately, providing as much detail as possible.
2. For fields with options, select only one option that best describes the incident.
3. If you are unsure about a field, please do not leave it blank and contact the reporting team for assistance.

## Field-by-Field Explanation

* **Emergency Report Form** (`emergency_report_form`, text, optional): This field is not required, but it can be used to provide any additional information that may be relevant to the incident.
* **Report Details** (`report_details`, text, optional): Use this field to provide any additional details about the incident, such as the location and any relevant facts.
* **Incident Date** (`incident_date`, date, optional): Please select the date of the incident, using the standard date format (DD/MM/YYYY).
* **Incident Time** (`incident_time`, time, optional): Choose the time of the incident, using the 24-hour clock (HH:MM).
* **Location** (`location`, text, optional): Provide the exact location of the incident.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person filing this report.
* **Contact Email** (`contact_email`, email, optional): Enter the email address of the person filing this report.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person filing this report.
* **Report Description** (`report_description`, text, optional): Describe the incident as briefly and accurately as possible.
* **Report Status** (`report_status`, select_one, optional): Select the current status of the report from the options:
	+ In Progress
	+ Completed
	+ Closed
* **Report Type** (`report_type`, select_multiple, optional): Choose one or more of the following report types:
	+ Critical
	+ Non-Critical
	+ Other (please specify)
* **Report Category** (`report_category`, select_one, optional): Select one of the following report categories:
	+ Fire
	+ Police
	+ Medical
	+ Environmental
	+ Other (please specify)
* **Report Comments** (`report_comments`, text, optional): Add any additional comments or observations about the incident.
* **Additional Comments** (`report_comments_additional`, text, optional): Provide any further information about the incident that may be relevant.
* **Incident Photo Upload** (`incident_photo_upload`, text, optional): Please note that this field is not currently supported.
