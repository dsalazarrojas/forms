# Flood Incident Report - Help Guide
## Purpose
The Flood Incident Report form is designed to gather critical information about flood-related incidents, enabling authorities to quickly respond and mitigate the situation.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the location of the flood incident in the **Location** field.
2. Provide a detailed description of the incident in the **Description** field.
3. Enter the date and time the incident occurred in the **Date Occurred** and **Time Occurred** fields.
4. Enter the latitude and longitude of the affected area in the **Latitude** and **Longitude** fields.
5. Specify the elevation of the affected area in the **Elevation** field.
6. Select the type of flood incident that occurred from the **Flood Type** dropdown menu.
7. Enter the affected areas and population in the **Affected Areas** and **Affected Population** fields.
8. Report any emergency services that were called in the **Emergency Services** field.
9. Estimate the damage amount and economic impact of the incident in the **Damage Amount** and **Economic Impact** fields.
10. Provide an update on the response status in the **Response Status** field.

## Field-by-Field Explanation
- **Location**: Enter the exact location where the flood incident occurred, including city, state, or region.
  - Type: text
  - Required: false
- **Description**: Provide a detailed description of the incident, including any notable features or characteristics.
  - Type: text
  - Required: false
- **Date Occurred**: Enter the date the incident occurred in MM/DD/YY format.
  - Type: date
  - Required: false
- **Time Occurred**: Enter the time the incident occurred in 24-hour format (HH:MM).

  - Required: false
- **Latitude**: Enter the latitude of the affected area.
  - Type: number
  - Required: false
- **Longitude**: Enter the longitude of the affected area.
  - Type: number
  - Required: false

  - Type: number
  - Required: false

  - Type: select_multiple

  - Type: text

  - Type: text
  - Required: false

  - Type: text
  - Required: false

  - Type: number
