# Marine Wildlife Sighting Report - Help Guide
## Purpose
This form is used to report marine wildlife sightings, allowing users to collect and record information about marine species occurrences.

## How To Complete This Form

1. Fill in the required fields with accurate and detailed information about the sighting.
2. Select the correct species type from the options provided.
3. Provide as much detail as possible in the sighting details field.
4. Upload a photo of the sighting (if available).
5. Enter the latitude and longitude of the sighting location.
6. Enter the number of photos taken.
7. Add a comment for the photo (if applicable).
8. Indicate if the sighting has conservation interest.
9. If the sighting has conservation interest, select the relevant conservation group.
10. Add any additional comments about the conservation group (if applicable).
11. Enter any comments from the researcher (if applicable).
12. Enter the photo credit information (if applicable).
13. Add a comment about the photo credit (if applicable).

## Field-by-Field Explanation

* **Report Date** (report_date): Enter the date the sighting was made.
* **Location** (location): Enter the location where the sighting occurred.
* **Species** (species): Enter the common name of the species observed.
* **Species Type** (species_type): Select the type of species (Common Name, Scientific Name, or Common Name/Scientific Name).
* **Common Name** (common_name): Enter the common name of the species (if species type is Common Name).
* **Scientific Name** (scientific_name): Enter the scientific name of the species (if species type is Scientific Name).
* **Sighting Details** (sighting_details): Describe the sighting in as much detail as possible.
* **Photo URL** (photo): Enter the URL of the photo (if applicable).
* **Latitude** (latitude): Enter the latitude of the sighting location.
* **Longitude** (longitude): Enter the longitude of the sighting location.
* **Number of Photos** (photo_count): Enter the number of photos taken.
* **Photo Comment** (photo_comment): Add a comment for the photo (if applicable).
* **Conservation Interest** (conservation_interest): Indicate if the sighting has conservation interest.
* **Conservation Group** (conservation_group): Select the relevant conservation group (if conservation interest is selected).
* **Other Conservation Group** (other_conservation_group): Enter any additional conservation group information (if applicable).
* **Other Conservation Group Comment** (other_conservation_group_comment): Add a comment about the other conservation group (if applicable).
* **Researcher Comments** (researcher_comments): Enter any comments from the researcher (if applicable).
* **Photo Credit** (photo_credit): Enter the photo credit information (if applicable).
* **Photo Credit Comment** (photo_credit_comment): Add a comment about the photo credit (if applicable).

Note: All fields are optional unless marked as required. The fields are designed to be completed in a specific order to ensure consistency and accuracy in the collected data.
