# Military Operations Incident Report Form - Help Guide
## Purpose
The Military Operations Incident Report Form is used to report and document incidents that occur during military operations. This form helps to gather detailed information about the incident, including the incident date, unit involved, incident location, and incident status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the incident date from the calendar picker.
2. Enter the name of the unit involved in the incident.
3. Provide a brief description of the incident.
4. Select the time zone in which the incident occurred.
5. Select the military unit from the list of available units.
6. Choose the type of incident that occurred.
7. Select the category of the incident.
8. Select the personnel involved in the incident reporting.
9. Select the incident level and status.
10. Select the incident nature and severity.
11. Select the incident priority.
12. Enter the name and email of the incident reporter and unit commander.
13. Enter the name and email of the reporting officer and incident reporting officer.
14. Select the submitter.

* **Incident Time**: This field is used to select the time of the incident.

* **Military Unit**: This field is used to select the military unit from the list of available units.

* **Incident Category**: This field is used to select the category of the incident.
* **Report By**: This field is used to select the personnel involved in reporting the incident.

* **Incident Level**: This field is used to select the incident level.
* **Incident Status**: This field is used to select the incident status.

* **Incident Priority**: This field is used to select the incident priority.
