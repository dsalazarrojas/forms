# CrowdStrike Global Threat Report Form - Help Guide
## Purpose
This form is used to report and track potential threats to your systems and networks. It helps gather information about the nature, location, and impact of these threats, and provides a platform to share solutions and recommendations for mitigating them.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of threat you are reporting (Threat Type).
2.  Choose the location where the threat is occurring (Threat Location).
3.  Provide a detailed description of the threat (Threat Description).
4.  Indicate the severity of the threat (Threat Severity).
5.  Specify how frequently the threat occurs (Threat Frequency).
6.  Describe the potential impact of the threat (Potential Impact).
7.  Share recommended solutions for mitigating the threat (Threat Solutions).
8.  Add any additional comments about the threat (Comments).

## Field-by-Field Explanation
*   **Threat Type**: Select the type of threat you are reporting from the options provided.
    *   Threat Actor: Select this option if the threat is caused by a human or group.
    *   Malware: Select this option if the threat is caused by a malicious software or code.
    *   Phishing: Select this option if the threat is related to social engineering or deception.
    *   Ransomware: Select this option if the threat is related to ransom demands.
    *   Other: Select this option if none of the above apply.
*   **Threat Location**: Choose all applicable locations where the threat is occurring.
    *   North America: Select this option if the threat is occurring in North America.
    *   South America: Select this option if the threat is occurring in South America.
    *   Europe: Select this option if the threat is occurring in Europe.
    *   Africa: Select this option if the threat is occurring in Africa.
    *   Asia: Select this option if the threat is occurring in Asia.
    *   Other: Select this option if none of the above apply.
*   **Threat Description**: Provide a detailed description of the threat.
*   **Threat Severity**: Indicate how severe you consider this threat to be.
    *   High: Select this option if the threat is severe and should be prioritized.
    *   Medium: Select this option if the threat is moderate and should be addressed.
    *   Low: Select this option if the threat is minimal and can be monitored.
*   **Threat Frequency**: Specify how frequently the threat occurs.
    *   Daily: Select this option if the threat occurs daily.
    *   Weekly: Select this option if the threat occurs weekly.
    *   Monthly: Select this option if the threat occurs monthly.
    *   Quarterly: Select this option if the threat occurs quarterly.
    *   Less than monthly: Select this option if the threat occurs less than monthly.
*   **Potential Impact**: Describe the potential risks of this threat.
*   **Threat Solutions**: Share recommended solutions for mitigating the threat.
*   **Comments**: Add any additional comments about the threat.

## Tips
*   Make sure to fill out each field accurately and thoroughly.
*   If you are unsure about the threat type, select "Other" and provide a detailed description.
*   If you are unsure about the threat location, select all applicable locations.
*   If you are unsure about the threat severity, frequency, or potential impact, provide a detailed description.
*   Make sure to review the form carefully before submitting it.
*   If you need help with this form, contact form@gic.mx.
