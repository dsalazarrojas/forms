# Clinical Study Data Collection - Help Guide

## Purpose
The Clinical Study Data Collection form is a crucial tool for healthcare professionals to gather accurate and comprehensive information about each participant in clinical research studies.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form carefully and ensure you understand the purpose and each field's requirements.
2. Fill in all required fields with accurate and complete information.
3. Double-check your entries for accuracy and completeness.

## Field-by-Field Explanation

* **Study ID** (`id: 2`, `type: text`, `required: true`): Enter the unique identifier for the study.
* **Study Title** (`id: 3`, `type: text`, `required: true`): Enter the title of the study.
* **Study Site ID** (`id: 4`, `type: text`, `required: true`): Enter the ID of the study site.
* **Study Site Name** (`id: 5`, `type: text`, `required: true`): Enter the name of the study site.
* **Participant Study ID** (`id: 6`, `type: text`, `required: true`): Enter the unique identifier for the participant.
* **Visit Number** (`id: 7`, `type: text`, `required: true`): Enter the visit number, e.g., "Visit 1 Screening Visit 2 etc."
* **Visit Date** (`id: 8`, `type: date`, `required: true`): Enter the date of the visit.
* **Data Collector Name** (`id: 9`, `type: text`, `required: true`): Enter the name of the data collector.
* **Data Collector Role** (`id: 10`, `type: select_one`, `required: true`): Select the role of the data collector from the dropdown menu.
* **Participant Age** (`id: 11`, `type: number`, `required: true`): Enter the participant's age.
* **Participant Gender** (`id: 12`, `type: select_one`, `required: true`): Select the participant's gender from the dropdown menu.
* **Participant Race** (`id: 13`, `type: select_one`, `required: false`): Select the participant's race from the dropdown menu.
* **Participant Ethnicity** (`id: 14`, `type: select_one`, `required: false`): Select the participant's ethnicity from the dropdown menu.
* **Height in cm** (`id: 15`, `type: number`, `required: false`): Enter the participant's height in cm.
* **Weight in kg** (`id: 16`, `type: number`, `required: false`): Enter the participant's weight in kg.
* **BMI** (`id: 17`, `type: number`, `required: false`): Enter the participant's BMI.
* **Blood Pressure Systolic** (`id: 18`, `type: number`, `required: false`): Enter the participant's blood pressure systolic.
* **Blood Pressure Diastolic** (`id: 19`, `type: number`, `required: false`): Enter the participant's blood pressure diastolic.
* **Heart Rate** (`id: 20`, `type: number`, `required: false`): Enter the participant's heart rate.
* **Temperature** (`id: 21`, `type: number`, `required: false`): Enter the participant's temperature.
* **Respiratory Rate** (`id: 22`, `type: number`, `required: false`): Enter the participant's respiratory rate.
* **Oxygen Saturation** (`id: 23`, `type: number`, `required: false`): Enter the participant's oxygen saturation.
* **Primary Diagnosis** (`id: 24`, `type: text`, `required: true`): Enter the primary diagnosis.
* **Diagnosis Code ICD-10** (`id: 25`, `type: text`, `required: false`): Enter the diagnosis code ICD-10 if applicable.
* **Relevant Medical History** (`id: 26`, `type: text`, `required: true`): Enter any significant medical history.
* **Current Medications** (`id: 27`, `type: text`, `required: true`): Enter any current medications.
* **Concomitant Medications** (`id: 28`, `type: text`, `required: false`): Enter any concomitant medications.
* **Allergies** (`id: 29`, `type: text`, `required: true`): Enter any allergies.
* **Smoking Status** (`id: 30`, `type: select_one`, `required: false`): Select the participant's smoking status from the dropdown menu.
* **Alcohol Use** (`id: 31`, `type: select_one`, `required: false`): Select the participant's alcohol use from the dropdown menu.
* **Recreational Substance Use** (`id: 32`, `type: select_one`, `required: false`): Select the participant's recreational substance use from the dropdown menu.
* **Laboratory Tests Performed** (`id: 33`, `type: select_multiple`, `required: false`): Select all laboratory tests performed for the participant.
* **Laboratory Results Summary** (`id: 34`, `type: text`, `required: false`): Enter a summary of the laboratory results.
* **Any Adverse Events Since Last Visit** (`id: 35`, `type: select_one`, `required: true`): Select if there have been any adverse events since the last visit.
* **Adverse Events Details** (`id: 36`, `type: text`, `required: false`): Enter details about any adverse events.
* **Any Serious Adverse Events** (`id: 37`, `type: select_one`, `required: true`): Select if there have been any serious adverse events.
* **New Concomitant Illnesses** (`id: 38`, `type: text`, `required: false`): Enter any new concomitant illnesses since the last visit.
* **Any Protocol Deviations** (`id: 39`, `type: select_one`, `required: true`): Select if there have been any protocol deviations.
* **Protocol Deviations Details** (`id: 40`, `type: text`, `required: false`): Enter details about any protocol deviations.
* **Study Intervention Administered** (`id: 41`, `type: select_one`, `required: true`): Select if the study intervention was administered.
* **Intervention Details** (`id: 42`, `type: text`, `required: false`): Enter details about the study intervention.
* **Participant Compliance** (`id: 43`, `type: select_one`, `required: false`): Select the participant's compliance from the dropdown menu.
* **Primary Outcome Measures** (`id: 44`, `type: text`, `required: false`): Enter any primary outcome measures.
* **Secondary Outcome Measures** (`id: 45`, `type: text`, `required: false`): Enter any secondary outcome measures if applicable.
* **Assessment Comments** (`id: 46`, `type: text`, `required: false`): Enter any relevant assessment comments.
* **Data Quality Verified** (`id: 47`, `type: select_one`, `required: true`): Select if data quality is verified.
* **Data Entry Complete** (`id: 48`, `type: select_one`, `required: true`): Select if data entry is complete.
* **Data Reviewer Name** (`id: 49`, `type: text`, `required: false`): Enter the name of the data reviewer.
* **Review Date** (`id: 50`, `type: date`, `required: false`): Enter the review date.

## Tips

* Please double-check all entries for accuracy and completeness before submitting the form.
* Ensure you have the necessary permissions and approvals to complete this form.
* If you are unsure about any of the questions or require clarification, please consult with the study team or relevant healthcare professionals.
* Complete the form for each participant separately, and ensure that all data is up-to-date and accurate.
