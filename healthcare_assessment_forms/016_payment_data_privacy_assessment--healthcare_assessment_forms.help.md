# Payment Data Privacy Assessment - Help Guide

## Purpose
The Payment Data Privacy Assessment form is designed to collect detailed information about the payment data that has been collected, stored, and shared within an organization. This form helps to ensure that sensitive data is protected and handled in accordance with relevant laws and regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all required fields. The fields marked as "Required" in the legend below are mandatory and must be completed before submitting the form.
2. Select the correct options for the "Collected From", "Shared With", and "Data Type" fields as per the options provided.
3. Enter the dates "Date Collected" and "Date Shared" using the date picker or manually, if available.
4. Enter the names of individuals or departments who collected and stored the data.
5. Enter the names of individuals or departments who shared the data.
6. Select the correct options for the "Prophets" field, if applicable.
7. Enter any additional comments about the data protection measures taken.

## Field-by-Field Explanation

* **Payment Data Privacy Assessment**: This is the title of the form.
* **Collected From**: Select where the data was collected from, e.g., "Customer", "Bank", "Online Payment System", etc.
* **Prophets**: Select if the data was collected from a prophetic source.
* **Shared**: Enter the number of people that the data was shared with.
* **Date Collected**: Enter the date the data was collected.
* **Date Shared**: Enter the date the data was shared.
* **Collected By**: Enter the name of the individual or department that collected the data.
* **Stored By**: Enter the name of the individual or department that stored the data.
* **Shared With**: Select who the data was shared with, e.g., "Internal Team", "External Partner", "Contractor", etc.
* **Shared To**: Select where the data was shared to, e.g., "Internal Department", "External Partner", "Public Database", etc.
* **Payment Data**: Enter the actual payment data collected.
* **Data Type**: Select the type of data collected, e.g., "Credit Card Number", "Bank Account Number", "Personal Identification Number", etc.
* **Sensitive Data**: Enter any sensitive information about the data, e.g., "PCI Compliant", "Regulated Data", etc.
* **Data Protection**: Enter any data protection measures taken, e.g., "Encryption", "Access Control", etc.
* **Stored**: Enter where the data is stored.
* **Sharing**: Enter where the data was shared.

Note: This guide is based on the provided YAML fields. The explanation of each field is an attempt to understand the best-effort intent without inventing unsupported business logic.
