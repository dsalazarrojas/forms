# Implementation Science Check In - Help Guide
## Purpose
The Implementation Science Check In form is a tool for project team members to report on their progress, challenges, and needs related to a specific project in the implementation science context.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the appropriate project status from the text field.
2. Provide an update on the barriers you're experiencing, if any.
3. Share any strategies that have been implemented or planned to address these barriers.
4. Specify any support needs you have.
5. Enter the project ID number.
6. Fill in the team name and researcher name, if applicable.
7. Enter the start and end dates and times of the project phase, if applicable.
8. Specify the duration of the project phase.
9. Enter the location where the project is being implemented.
10. Add any additional notes or comments about the project.

## Field-by-Field Explanation

* **Project Status** (Project Status):
	+ Enter a brief description of the current project status.
* **Barriers** (Barriers):
	+ Provide an update on any challenges or obstacles you're experiencing with the project.
* **Strategies** (Strategies):
	+ Share any plans or actions taken to address the barriers you've identified.
* **Support Needs** (Support Needs):
	+ Specify any help or resources you require from the project team or stakeholders.
* **Project ID** (Project ID):
	+ Enter the unique identifier for the project.
* **Team Name** (Team Name):
	+ Enter the name of the team working on the project, if applicable.
* **Researcher Name** (Researcher Name):
	+ Enter the name of the researcher leading the project, if applicable.
* **Start Date** (Start Date):
	+ Enter the date when the project started.
* **End Date** (End Date):
	+ Enter the date when the project is expected to end.
* **Start Time** (Start Time):
	+ Enter the time when the project started.
* **End Time** (End Time):
	+ Enter the time when the project is expected to end.
* **Duration** (Duration):
	+ Specify the length of time the project is expected to take.
* **Location** (Location):
	+ Enter the location where the project is being implemented.
* **Notes** (Notes):
	+ Add any additional comments or notes about the project.

This form is designed to be a living document that captures the progress and challenges of your project. By regularly filling out this form, you'll be able to:

* Identify and address potential issues promptly
* Share knowledge and expertise among team members
* Improve the overall project outcome
