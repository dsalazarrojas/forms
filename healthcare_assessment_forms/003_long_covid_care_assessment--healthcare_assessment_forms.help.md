# long_covid_care_assessment - Help Guide
## Purpose
The Long COVID Care Assessment form is designed to gather information about patients who have been diagnosed with Long COVID. This form is used to document a patient's symptoms, care needs, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the patient's information on page 1 (Patient Info).
2. On page 2 (Symptoms), select all the symptoms that the patient is experiencing.
3. On page 3 (Care Needs), select the type of care the patient requires.
4. On page 4 (Other Care Needs), enter any other care needs that are not listed in the provided options.
5. On page 5 (Patient Support Services), enter any additional support services the patient requires.

## Field-by-Field Explanation
* **Patient info** (Patient info, number, required): Enter the patient's ID number.
* **Symptoms** (Symptoms, select multiple, required): Select all symptoms that the patient is experiencing. The options include: Fever, Fatigue, Loss of taste and smell, Loss of appetite, Muscle and joint pain, Confusion or disorientation, Difficulty concentrating or memory problems, Headache, Sore throat, Cough, Difficulty breathing, Chest pain or pressure.
* **Care needs** (Care needs, select one, required): Select the type of care the patient requires. Options include: Clinic, Rehabilitation program, Patient support services.
* **Other care needs** (Other care needs, text, optional): Enter any other care needs not listed in the provided options.
* **Patient support services** (Patient support services, text, optional): Enter any additional support services the patient requires.

## Tips
* Make sure to select all applicable symptoms for the patient.
* If the patient has no care needs, select "None" in the Care Needs field.
* Use the "Other care needs" field for any additional care needs not listed in the provided options.
