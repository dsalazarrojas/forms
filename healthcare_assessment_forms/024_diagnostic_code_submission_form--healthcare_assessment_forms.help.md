# Diagnostic Code Submission Form - Help Guide
## Purpose
This form is used to submit diagnostic codes for patients in a healthcare setting. It collects necessary information from both the patient and provider sides, ensuring accurate and comprehensive data entry.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the **Diagnostic Code Section**, which requires entering the diagnostic codes relevant to the patient's condition.
2. Next, move on to the **Patient Section**, where you will enter the patient's information, including name, age, gender, and other contact details.
3. The **Provider Section** is optional, but if filled out, it will provide additional context about the provider who submitted the code.
4. In the **Context Section**, select the relevant healthcare codes that apply to the patient's situation.
5. In the **Documentation Section**, enter any additional documentation or comments about the patient's case.
6. Finally, review your entries in the **Submit Section** and ensure everything is accurate and complete before submitting the form.

## Field-by-Field Explanation

* **Diagnostic Code Section (1)**: Enter the diagnostic codes related to the patient's condition. This field is required.
* **Patient Section (2)**:
	+ **Patient Name**: Enter the patient's full name.
	+ **Patient Age**: Enter the patient's age (if applicable).
	+ **Patient Gender**: Select the patient's gender (male, female, or other).
* **Provider Section (3)**:
	+ **Provider Name**: Enter the name of the provider who submitted the code (if applicable).
	+ **Provider Title**: Enter the title of the provider who submitted the code (if applicable).
* **Context Section (4)**:
	+ **Healthcare Codes**: Select the relevant healthcare codes that apply to the patient's situation.
	+ **Context Details**: Select the additional context details that apply to the patient's situation.
* **Documentation Section (5)**: Enter any additional documentation or comments about the patient's case.
* **Submit Section (6)**: Review and submit your entries to complete the form.

Note: Some fields are optional and only need to be filled out if they are relevant to the patient's case.
