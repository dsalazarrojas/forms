# Finger Windows Assessment - Help Guide
## Purpose
The Finger Windows Assessment form is designed to collect information about participants, focusing on their performance, demographics, and compatibility with different versions of the "Finger Windows" software. This form will help gather essential data for research, assessment, or evaluation purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the participant's ID from the drop-down menu under "Participant ID" to identify the participant.
2. Choose the participant's gender from the drop-down menu under "Participant gender."
3. Select all the versions of "Finger Windows" that the participant is compatible with, if applicable.
4. Enter any additional information or notes about the participant in the "Evaluator notes" field, if necessary.
5. If the participant's performance is being assessed, provide a brief description of their performance in the "Participant performance" field.

## Field-by-Field Explanation

* **Participant ID**: This is a required field where you select the participant's unique ID from the drop-down menu.
* **Participant gender**: Choose the participant's gender from the options provided (Male or Female).
* **Participant performance**: This field is for describing the participant's performance, if being assessed.
* **Evaluator notes**: Enter any additional information or notes about the participant's evaluation or assessment.
* **Evaluator name**: This field is for entering the name of the person performing the evaluation or assessment.
* **Participant DOB**: This field is for entering the participant's date of birth, if applicable.
* **Participant Windows**: Select all the versions of "Finger Windows" that the participant is compatible with, if applicable.
* **Finger Windows 10**: Select this option if the participant is compatible with "Windows 10."
* **Finger Windows 11**: Select this option if the participant is compatible with "Windows 11."
* **Finger Windows 12**: Select this option if the participant is compatible with "Windows 12."
