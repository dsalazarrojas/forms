# Insulin Pump Settings Worksheet - Help Guide

## Purpose
The Insulin Pump Settings Worksheet is a form used to collect data on insulin pump settings for patients.

## How To Complete This Form
1. Select the type of insulin pump model used by the patient from the dropdown menu.
2. If applicable, enter the basal settings and basal rate settings for the patient.
3. If applicable, select the frequency and amount for basal insulin delivery.
4. Enter any bolus settings or dosing information.
5. Add any additional provider notes regarding the patient's care plan.

## Field-by-Field Explanation

* **Insulin Pump Model** (insulin_pump_model): Select the type of insulin pump used by the patient.
* **Basal Settings** (basal_settings): Enter the basal settings for the patient, if applicable.
* **Basal Rate** (basal_rate): Enter the basal rate for the patient, if applicable.
* **Basal Rate Unit** (basal_rate_unit): Select the unit of measurement for the patient's basal rate.
* **Bolus Settings** (bolus_settings): Check if the patient has bolus settings or dosing information.
* **Bolus Dose** (bolus_dose): Enter the bolus dose for the patient, if applicable.
* **Bolus Frequency** (bolus_frequency): Select the frequency of bolus dosing for the patient.
* **Bolus Amount** (bolus_amount): Enter the amount of bolus dosing for the patient, if applicable.
* **Bolus Duration** (bolus_duration): Enter the duration of bolus dosing, if applicable.
* **Provider Notes** (provider_notes): Add any additional notes or comments regarding the patient's care plan.
* **Basal Insulin Delivery** (basal_insulin_delivery): Check if the patient has basal insulin delivery.
* **Basal Insulin Delivery Time** (basal_insulin_delivery_time): Enter the time of basal insulin delivery, if applicable.
* **Basal Insulin Delivery Frequency** (basal_insulin_delivery_frequency): Select the frequency of basal insulin delivery for the patient.
* **Basal Insulin Delivery Amount** (basal_insulin_delivery_amount): Enter the amount of basal insulin delivery for the patient, if applicable.

## Tips
* Please ensure that you have the necessary permissions and authorization before completing this form.
* If you are unsure about any of the fields, please consult with the patient's healthcare provider.
* If you have any further questions or concerns, please reach out to the healthcare provider for guidance.
