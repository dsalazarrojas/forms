## Purpose
The Healthcare Necessities Analysis Form is a tool used to assess the health status and needs of patients, focusing on access to necessary care and follow-up on treatment plans. It helps healthcare providers identify areas where patients may require additional support or attention.

## How To Complete This Form
To complete this form, follow these steps:

1. Begin on the Main Page (page 1).
2. Enter a brief description of the patient's current health status in the text field.
3. On the Health Context page (page 2), provide additional details about the patient's health situation, if necessary.
4. On the Access Challenges page (page 3), select one or more of the access challenges listed that apply to the patient's situation.
5. Use the Follow Up page (page 4) to note any specific follow-up instructions or concerns that need to be addressed.
6. Finally, on the Submit page (page 5), choose whether to submit or decline the form for further review.

## Field-by-Field Explanation
* **Main Page (1)** (`title`, `text`, not required): Enter a brief description of the patient's current health status. This field is a text-based field where you can type in a few sentences or paragraphs to describe the patient's health situation.
* **Health Context (2)** (`health_context`, `text`, not required): Provide additional details about the patient's health situation, if necessary. Like the main page, this is a text-based field for further context.
* **Access Challenges (3)** (`access_challenges`, `select_one`, not required): Select one or more of the challenges listed that apply to the patient's situation. The options are:
	+ No challenges
	+ Access to medication
	+ Access to medical devices
	+ Access to healthcare services
	+ Other (use this option to describe the specific challenge not listed)
* **Follow Up (4)** (`follow_up`, `note`, not required): Use this field to note any specific follow-up instructions or concerns that need to be addressed. This field is for additional comments or guidance.
* **Submit (5)** (`submit`, `select_one`, not required): Choose whether to submit or decline the form for further review. Options are:
	+ Submit
	+ Decline

## Tips
- Be as detailed as possible when describing the patient's health status and context.
- If the patient has multiple access challenges, select all that apply.
- Use the follow-up section for specific guidance or comments that require further action.
- Select submit to send the form for review, or decline if further information is needed.
