# VOC Control Assessment Form - Help Guide
## Purpose
The "VOC Control Assessment Form" is a tool for evaluating and documenting Volatile Organic Compounds (VOCs) in a given location or process. The form aims to gather data on the types of VOCs present, their sources, and the associated control measures in place to mitigate their impact.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the types of VOCs present in the location or process being assessed from the options provided.
2. Choose the sources from which the VOCs are derived.
3. Indicate the types of controls measures in place to manage the VOCs.
4. Describe the current compliance status of the VOCs in the location or process.
5. Provide a brief description of the VOCs being assessed.
6. Identify the types of risks associated with the VOCs being assessed.

## Field-by-Field Explanation

### VOC Types (<label> VOC Types)

* **VOC Types** (`voc_types`, select_one): Choose the types of VOCs present in the location or process being assessed. Select from the options provided.

### Sources (<label> Sources)

* **Sources** (`sources`, select_multiple): Identify the sources from which the VOCs are derived. Select all applicable options from the list.

### Controls (<label> Controls)

* **Controls** (`controls`, select_one): Indicate the types of control measures in place to manage the VOCs. Select from the options provided.

### Compliance Status (<label> Compliance Status)

* **Compliance Status** (`compliance_status`, select_one): Describe the current compliance status of the VOCs in the location or process. Select from the options provided.

### VOC Description (<label> VOC Description)

* **VOC Description** (`voc_description`, text): Provide a brief description of the VOCs being assessed.

### Risk Assessed (<label> Risk Assessed)

* **Risk Assessed** (`risk_assessed`, select_multiple): Identify the types of risks associated with the VOCs being assessed. Select all applicable options from the list.
