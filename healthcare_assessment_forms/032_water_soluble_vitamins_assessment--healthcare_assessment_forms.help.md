# Water Soluble Vitamins Assessment - Help Guide
## Purpose

This form is used to assess an individual's consumption of water-soluble vitamins, which are essential nutrients that dissolve in water and are often found in fruits, vegetables, and other foods.

## How To Complete This Form

1.  Answer each question to the best of your ability, and select all that apply.
2.  For questions with a "Select One" type, choose only one option.
3.  For questions with a "Select Multiple" type, choose all that apply.
4.  Enter any relevant details in the text fields.

## Field-by-Field Explanation

*   **What do you take?** (`water_soluble_vitamins_assessment`, Select Multiple, required: false):
    *   List the water-soluble vitamins you consume regularly, such as Vitamin A, Vitamin D, Vitamin E, and Vitamin K.
*   **Vitamins** (`vitamins_consumed`, Select One, required: false):
    *   Indicate which water-soluble vitamin you take.
*   **Vitamin A** (`vitamin_a_consumption`, Select Multiple, required: false):
    *   Answer whether you take Vitamin A.
*   **Vitamin D** (`vitamin_d_consumption`, Select Multiple, required: false):
    *   Answer whether you take Vitamin D.
*   **Vitamin E** (`vitamin_e_consumption`, Select Multiple, required: false):
    *   Answer whether you take Vitamin E.
*   **Vitamin K** (`vitamin_k_consumption`, Select Multiple, required: false):
    *   Answer whether you take Vitamin K.
*   **Symptoms** (`water_soluble_vitamins_symptoms`, Text, required: false):
    *   Describe any symptoms you are experiencing.
*   **Supplements** (`water_soluble_vitamins_supplements`, Select One, required: false):
    *   Indicate whether you take multivitamins or specific water-soluble vitamin supplements.
*   **Frequency** (`water_soluble_vitamins_frequency`, Text, required: false):
    *   Report how often you consume water-soluble vitamins.
*   **Dose** (`water_soluble_vitamins_dose`, Text, required: false):
    *   Provide the amount of water-soluble vitamins you consume.
*   **Side effects** (`water_soluble_vitamins_side_effects`, Text, required: false):
    *   List any side effects you experience.
*   **Recommendations** (`water_soluble_vitamins_recommendation`, Select Multiple, required: false):
    *   Indicate whether you need any recommendations for your water-soluble vitamin intake.

## Tips

*   Be honest and accurate when answering each question.
*   If unsure, try your best to estimate or provide approximate values.
*   If you experience any side effects, discuss them with a healthcare professional.
