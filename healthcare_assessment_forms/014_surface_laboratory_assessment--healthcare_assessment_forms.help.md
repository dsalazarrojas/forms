# Surface Laboratory Assessment - Help Guide
## Purpose
The Surface Laboratory Assessment form is designed to collect information from patients to help medical professionals in a laboratory setting. This form is used to gather data on the patient's medical history, allergies, and test results.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the patient's information on page 1, including their name, date of birth, and contact details.
2. Provide information on the patient's medical history, including any relevant allergies or medical conditions.
3. List any medications the patient is currently taking.
4. Specify the type of test being performed.
5. Enter any test results.
6. Review and update any additional test results or lab information as needed.
7. Enter any medical history notes.

## Field-by-Field Explanation
### Patient Information (Page 1)
* **Patient Information** (`patient_info`, text, required/optional): Enter the patient's name, date of birth, and contact details to ensure we have accurate information about the patient.

### Medical History
* **Medical History** (`medical_history`, note, required/optional): Provide a brief description of the patient's medical history, including any relevant allergies or medical conditions.

### Medication List
* **Medication List** (`medication_list`, text, required/optional): List any medications the patient is currently taking.

### Allergies
* **Allergies** (`allergies`, text, required/optional): Specify any known allergies the patient has.

### Test Type
* **Test Type** (`test_type`, select one, required): Select the type of test being performed.

### Test Results
* **Test Results** (`test_results`, text, required/optional): Enter any test results.

### Test Results Graph
* **Test Results Graph** (`test_results_graph`, text, required/optional): Enter any test results in graph format.

### Test Results Table
* **Test Results Table** (`test_results_table`, text, required/optional): Enter any test results in table format.

### Lab Information
* **Lab Information** (`lab_info`, text, required/optional): Enter any relevant lab information.

### Test Results Table 2
* **Test Results Table 2** (`test_results_table_2`, text, required/optional): Enter any additional test results in table format.

### Medical History Notes
* **Medical History Notes** (`medical_history_notes`, note, required/optional): Enter any additional notes about the patient's medical history.

### Test Type 2
* **Test Type 2** (`test_type_2`, select one, required/optional): Select the type of test being performed, if applicable.

## Tips
* Be as thorough as possible when completing this form, as it will help medical professionals make informed decisions about the patient's care.
* If you have any concerns or questions about a specific field, consult with the laboratory staff before completing the form.
* Double-check your entries for accuracy to ensure the patient's data is up-to-date and reliable.
