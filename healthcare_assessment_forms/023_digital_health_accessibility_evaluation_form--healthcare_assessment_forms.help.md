# digitalHealthAccessibilityEvaluationForm - Help Guide
## Purpose
The digitalHealthAccessibilityEvaluationForm is designed to assess the accessibility of digital platforms for users with health conditions. It collects information on user experience and platform accessibility to help evaluate and improve digital health resources.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all applicable options for User Information.
2. Enter the relevant information about the digital platform you are accessing.
3. Choose the correct answer for Accessibility Checklist.
4. Add any additional comments about your experience, if applicable.
5. Select all applicable feedback options, if any.

## Field-by-Field Explanation
* **User Information** (select_multiple, optional): Select all the health conditions that apply to you. Options: 'Yes', 'No'.
* **Platform Information** (text, required): Enter a brief description of the digital platform you are accessing.
* **Accessibility Checklist** (select_one, required): Evaluate the accessibility of the platform. Options: 'Yes', 'No', 'N/A'
* **Comments** (note, optional): If you'd like to share any additional information about your experience with the platform, add it here.
* **Feedback** (select_multiple, optional): Provide feedback on how we can improve the digital health resource. Options: 'Yes', 'No'
