# sustainable_health_care_design_project_evaluation_form - Help Guide
## Purpose
This form is designed to evaluate the sustainability of a healthcare design project.

## How To Complete This Form
To complete this form, follow the instructions below:
1. Review the project's features, goals, and challenges.
2. Select the sustainable features, stakeholder engagement, overall performance, project goals, project benefits, and project challenges that apply to the project.
3. Evaluate the project's overall score out of a certain score (e.g., 100).

## Field-by-Field Explanation

* **Sustainable Features**: Choose all the features that are sustainable and relevant to the project (e.g., Option 1, Option 2, Option 3).
* **Stakeholder Engagement**: Select the type of stakeholder engagement that applies to the project (e.g., Option 1, Option 2, Option 3).
* **Overall Performance**: Evaluate the project's overall performance (e.g., a text description).
* **Project Goals**: Choose all the goals that apply to the project (e.g., Option 1, Option 2, Option 3).
* **Project Benefits**: Choose all the benefits that apply to the project (e.g., Option 1, Option 2, Option 3).
* **Project Challenges**: Describe the project's challenges and obstacles (e.g., text description).
* **Evaluation Score**: Enter a numerical score out of a certain score (e.g., 100).
* **Form Footer**: Additional comments or notes about the project.
