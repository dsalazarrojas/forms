# Digital Care Coordination Project Application Form - Help Guide

## Purpose
The Digital Care Coordination Project Application Form is a tool used to gather information about proposed projects that aim to improve patient care and outcomes within healthcare organizations. This form will help project teams provide a clear and comprehensive overview of their project, ensuring that all necessary details are captured and evaluated.

## How To Complete This Form

To complete this form, follow these steps:

* Fill in your organization's name and title of the project.
* Describe the objectives and goals of the project.
* Specify the expected impact of the project.
* Provide details about the project's contact person.
* Fill in the project title if it's different from the organization name.
* Provide a description of the project.
* Identify the target audience and project location (if applicable).
* Specify the project duration, start date, end date, and project lead.
* Confirm if the project is funded.
* Select the current project status (active or inactive).
* Add any additional notes on the project status.
* Review and add any comments.

## Field-by-Field Explanation

* **Organization Name (1)** (`text`, required): Enter the name of your organization.
* **Project Title (2)** (`text`, required): Enter the title of your project.
* **Objectives (3)** (`text`, required): Describe the main goals and objectives of your project.
* **Goals (4)** (`text`, required): Specify the specific goals and outcomes you expect to achieve.
* **Expected Impact (5)** (`text`, required): Describe the expected outcomes or benefits of your project.
* **Contact Person (6)** (`select_one`, required): Please select "Yes" if you are the project's contact person.
* **Project Title (7)** (`text`, optional): If your project's title is different from the organization's name, enter it here.
* **Project Description (8)** (`text`, required): Provide a detailed description of your project.
* **Target Audience (9)** (`select_multiple`, required): Identify the target audience for your project.
* **Project Location (10)** (`text`, optional): If applicable, enter the location of your project.
* **Project Duration (11)** (`number`, required): Specify the duration of your project in months.
* **Start Date (12)** (`date`, required): Enter the start date of your project.
* **End Date (13)** (`date`, required): Enter the end date of your project.
* **Project Lead (14)** (`text`, required): Enter the name of the project lead.
* **Project Funded (15)** (`select_one`, required): Please select "Yes" if your project is funded.
* **Project Status (16)** (`select_one`, required): Select the current status of your project (Active or Inactive).
* **Project Status Notes (17)** (`text`, required): Add any additional notes about the project status.
* **Review Comments (18)** (`text`, required): Add any comments or feedback from project reviewers.
