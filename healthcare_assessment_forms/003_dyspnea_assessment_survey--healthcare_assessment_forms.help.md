# Dyspnea Assessment Survey - Help Guide
## Purpose
This form is used to assess a patient's dyspnea symptoms, including respiratory, cardiovascular, and neurological systems, to guide clinicians in evaluating and managing patients with dyspnea.

## How To Complete This Form

### Page 1: Dyspnea Assessment

- **Dyspnea Assessment** (`page1`, text, required): This is a free-text field where you can record your assessment of the patient's dyspnea symptoms. Please provide a brief description of the patient's symptoms, including any relevant medical history or previous diagnoses.

### Page 2: Shortness of Breath Severity

- **Shortness of Breath Severity** (`shortness_of_breath_severity`, number, required): This field is used to quantify the severity of the patient's shortness of breath symptoms. Please select the number that best describes the patient's symptoms:

    0: No symptoms
    1: Mild symptoms
    2: Moderate symptoms
    3: Severe symptoms

### Page 2: Triggers

- **Triggers** (`triggers`, select multiple, required): This field is used to identify the triggers of the patient's shortness of breath symptoms. Please select all that apply:

    * No triggers
    * All the time
    * Only during exercise
    * Only at rest
    * Variable

### Page 2: History

- **History** (`history`, note, required): This field is used to record any relevant medical history, including previous diagnoses or treatments. Please provide a brief description of the patient's medical history.

### Page 2: Respiratory System Symptoms

- **Respiratory System Symptoms** (`respiratory_system_symptoms`, text, required): This field is used to record any respiratory system symptoms the patient is experiencing, such as coughing or wheezing. Please provide a brief description of the symptoms.

### Page 2: Cardiovascular System Symptoms

- **Cardiovascular System Symptoms** (`cardiovascular_system_symptoms`, text, required): This field is used to record any cardiovascular system symptoms the patient is experiencing, such as chest pain or palpitations. Please provide a brief description of the symptoms.

### Page 2: Neurological System Symptoms

- **Neurological System Symptoms** (`neurological_system_symptoms`, text, required): This field is used to record any neurological system symptoms the patient is experiencing, such as dizziness or confusion. Please provide a brief description of the symptoms.

### Page 2: Other Respiratory System Symptoms

- **Other Respiratory System Symptoms** (`respiratory_system_symptoms2`, text, required): This field is used to record any other respiratory system symptoms the patient is experiencing, such as shortness of breath with specific activities. Please provide a brief description of the symptoms.

### Page 2: Other Cardiovascular System Symptoms

- **Other Cardiovascular System Symptoms** (`cardiovascular_system_symptoms2`, text, required): This field is used to record any other cardiovascular system symptoms the patient is experiencing, such as palpitations with specific activities. Please provide a brief description of the symptoms.

### Page 2: Other Neurological System Symptoms

- **Other Neurological System Symptoms** (`neurological_system_symptoms2`, text, required): This field is used to record any other neurological system symptoms the patient is experiencing, such as weakness or numbness. Please provide a brief description of the symptoms.

### Page 2: Dyspnea Assessment - Additional Information

- **Dyspnea Assessment - Additional Information** (`page2`, text, required): This field is used to record any additional information that may be relevant to the patient's dyspnea symptoms, such as medication or treatment plans. Please provide a brief description of any additional information.

### Page 3: Date of Last Event

- **Date of Last Event** (`date_of_last_event`, date, required): This field is used to record the date of the patient's last dyspnea event. Please enter the date in the correct format (mm/dd/yyyy).

### Page 3: Symptoms Since Last Event

- **Symptoms Since Last Event** (`symptoms_since_last_event`, text, required): This field is used to record any symptoms the patient has experienced since the last dyspnea event. Please provide a brief description of the symptoms.

### Page 3: Respiratory System Symptoms Since Last Event

- **Respiratory System Symptoms Since Last Event** (`respiratory_system_symptoms_since_last_event`, text, required): This field is used to record any respiratory system symptoms the patient has experienced since the last dyspnea event, such as coughing or wheezing. Please provide a brief description of the symptoms.

### Page 3: Cardiovascular System Symptoms Since Last Event

- **Cardiovascular System Symptoms Since Last Event** (`cardiovascular_system_symptoms_since_last_event`, text, required): This field is used to record any cardiovascular system symptoms the patient has experienced since the last dyspnea event, such as chest pain or palpitations. Please provide a brief description of the symptoms.

### Page 3: Neurological System Symptoms Since Last Event

- **Neurological System Symptoms Since Last Event** (`neurological_system_symptoms_since_last_event`, text, required): This field is used to record any neurological system symptoms the patient has experienced since the last dyspnea event, such as dizziness or confusion. Please provide a brief description of the symptoms.

## Tips

* Please ensure that all required fields are completed before submitting the form.
* Please provide as much detail as possible in each field to ensure accurate assessment and treatment.
* If you are unsure about any of the fields, please consult with the patient's healthcare provider or medical staff.
