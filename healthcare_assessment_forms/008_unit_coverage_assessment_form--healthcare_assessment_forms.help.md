# Unit Coverage Assessment Form - Help Guide
## Purpose
The Unit Coverage Assessment Form is a tool used to assess the coverage status of units in facilities or networks.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter the unit number, which is a unique identifier for the unit.
2. Enter the unit address, which is the physical or virtual location of the unit.
3. Select the coverage status of the unit, which indicates whether the unit is currently covered or not.
4. Provide any optional notes on the unit.
5. Upload any supporting files for the unit, if required.

## Field-by-Field Explanation

* **Unit Number** (`unit_number`, text, required): Enter the unique identifier for the unit.
* **Unit Address** (`unit_address`, text, required): Enter the physical or virtual location of the unit.
* **Coverage Status** (`coverage_status`, select_one, required): Select 'True' (yes), 'False' (no), or 'Partial' (partially covered) to indicate the unit's coverage status.
* **Notes** (`notes`, text, optional): Provide any additional information or explanations for the unit.
* **File 1** (`file_1`, text, optional): Upload any supporting evidence or documentation for the unit, if required.
* **File 2** (`file_2`, text, optional): Upload any additional supporting evidence or documentation for the unit, if required.
* **File 3** (`file_3`, text, optional): Upload any other supporting evidence or documentation for the unit, if required.
