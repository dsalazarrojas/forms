# x_ray_testing_log - Help Guide
## Purpose
The x-ray testing log form is used to collect data on x-ray testing procedures.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Test Date** (`test_date`, `date`, required/optional): Select the date on which the x-ray test was performed.
* **Equipment Used** (`equipment_used`, `text`, required/optional): Select the type of equipment used during the testing process.
* **Test Results** (`test_results`, `select_multiple`, required): Select all that apply from the list of test results.
* **Notes** (`notes`, `note`, required): Add any additional comments or notes about the test.
* **Images/Documents** (`images_documents`, `select_multiple`, optional): Select all that apply from the list of images/documents related to the test.
* **Test Date 1** (`test_date_1`, `date`, optional): Select the date of the first additional test (if applicable).
* **Equipment Used 1** (`equipment_used_1`, `text`, optional): Select the type of equipment used for the first additional test (if applicable).
* **Test Results 1** (`test_results_1`, `select_multiple`, required): Select all that apply from the list of test results for the first additional test.
* **Notes 1** (`notes_1`, `note`, optional): Add any additional comments or notes about the first additional test.
* **Images/Documents 1** (`images_documents_1`, `select_multiple`, optional): Select all that apply from the list of images/documents related to the first additional test.
* **Test Date 2** (`test_date_2`, `date`, optional): Select the date of the second additional test (if applicable).
* **Equipment Used 2** (`equipment_used_2`, `text`, optional): Select the type of equipment used for the second additional test (if applicable).
* **Test Results 2** (`test_results_2`, `select_multiple`, optional): Select all that apply from the list of test results for the second additional test.
* **Notes 2** (`notes_2`, `note`, optional): Add any additional comments or notes about the second additional test.
* **Images/Documents 2** (`images_documents_2`, `select_multiple`, optional): Select all that apply from the list of images/documents related to the second additional test.
* **Test Date 3** (`test_date_3`, `date`, optional): Select the date of the third additional test (if applicable).
* **Equipment Used 3** (`equipment_used_3`, `text`, optional): Select the type of equipment used for the third additional test (if applicable).
* **Test Results 3** (`test_results_3`, `select_multiple`, optional): Select all that apply from the list of test results for the third additional test.
* **Notes 3** (`notes_3`, `note`, optional): Add any additional comments or notes about the third additional test.
* **Images/Documents 3** (`images_documents_3`, `select_multiple`, optional): Select all that apply from the list of images/documents related to the third additional test.

## Tips
* Be sure to fill in all required fields, including "Test Date", "Test Results", and "Notes", as they are necessary for a complete and accurate x-ray testing log.
* If additional test dates, equipment, or results are required, be sure to fill in the corresponding fields to provide a comprehensive record of the testing process.
* If you have any additional images or documents related to the test, be sure to select them in the corresponding "Images/Documents" field.
