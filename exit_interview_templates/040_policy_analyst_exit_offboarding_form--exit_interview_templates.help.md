# policy_analyst_exit_offboarding_form - Help Guide

## Purpose
The policy analyst exit offboarding form is designed to collect information from employees who are leaving the company. This form helps to gather valuable insights and feedback from departing employees, which can be used to improve employee retention and the overall work environment.

## How To Complete This Form

1. **Exit Offboarding Form Data**: This is the main section of the form where you will provide your basic information.
2. **Offboarding Date**: Please enter the date you are leaving the company.
3. **Exit Interview Questions**: Select all the reasons why you are leaving the company from the list provided.
4. **Feedback and Comments**: Share any feedback or comments you have about your experience with the company.
5. **New Role Details**: If you have a new role, select the category that best describes your new position.
6. **Next Steps**: Provide any next steps or action items for your manager or team.
7. **Manager Name**: Enter the name of your manager.
8. **Manager Title**: Enter your manager's title.
9. **Last Updated**: This field is auto-generated and shows the last time the form was updated.
10. **Assigned Tool**: Enter the tool assigned to you for this form.
11. **Form ID**: Enter a unique ID for this form, if required.
12. **Output File**: Provide a file output for this form.
13. **Category**: Enter the category of this form, if required.
14. **Description**: Enter a description of this form, if required.
15. **Form IDs**: Enter any other form IDs related to this form, if required.
16. **Output File 2**: Provide another file output for this form.
17. **Assigned Tool 2**: Enter the tool assigned to you for this form.
18. **Title**: Enter a title for this form, if required.
19. **Category 2**: Enter the category of this form, if required.
20. **Description 2**: Enter a description of this form, if required.
21. **Form Ids 2**: Enter any other form IDs related to this form, if required.
22. **Category 3**: Enter the category of this form, if required.
23. **Assigned Tool 3**: Enter the tool assigned to you for this form.
24. **Title 2**: Enter a title for this form, if required.
25. **Title 3**: This field is likely a duplicate of the "Title" field (21), and can be ignored.
