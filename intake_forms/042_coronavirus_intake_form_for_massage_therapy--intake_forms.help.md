# Coronavirus Intake Form for Massage Therapy - Help Guide
## Purpose
The purpose of this form is to collect essential information from clients seeking massage therapy services, especially in the context of COVID-19 concerns.

## How To Complete This Form
To complete this form, please follow these steps:

* Answer all required fields marked as "required".
* For select multiple fields (e.g., Medical Conditions, Medications, Allergies), select all applicable options.
* For select one fields (e.g., Recent Exposure, Temperature, Insurance), select only one option from the list.
* For text fields (e.g., Client Information, Emergency Contact), enter your answer in the provided field.
* For date fields (e.g., Date), use the date format: MM/DD/YYYY.
* For time fields (e.g., Time), use the time format: HH:MM AM/PM.
* For note fields (e.g., Symptoms, Medical Record, Emergency Contact Other), enter your answer in the provided field.

## Field-by-Field Explanation

* **Client Information** (Client Information, text, required): Please enter the client's name and any other identifying information.
* **Health Status** (Health Status, text, optional): Describe the client's current health status.
* **Medical Conditions** (Medical Conditions, select multiple, required): Select all medical conditions that apply to the client, such as Fever, Cough, Sore Throat, etc.
* **Travel History** (Travel History, date, optional): Enter the client's travel history, including dates of travel.
* **Recent Exposure** (Recent Exposure, select one, required): Select whether there has been recent exposure to COVID-19 or someone who has it.
* **Temperature** (Temperature, select one, required): Select the client's current temperature, either Normal, Elevated, or No Temperature Taken.
* **Symptoms** (Symptoms, note, optional): Describe any current symptoms the client is experiencing.
* **Medical Record** (Medical Record, note, optional): Enter any relevant medical history or record information.
* **Medications** (Medications, select multiple, required): Select all medications the client is taking, including Prescription Medication, Non-Prescription Medication, and Supplements.
* **Allergies** (Allergies, select multiple, required): Select all known allergies the client has, such as Allergies.
* **Insurance** (Insurance, select one, required): Select whether the client is using insurance.
* **Emergency Contact** (Emergency Contact, text, optional): Enter the name and relationship of the client's emergency contact.
* **Emergency Contact Relationship** (Emergency Contact Relationship, text, optional): Describe the relationship between the client and their emergency contact.
* **Emergency Contact Phone** (Emergency Contact Phone, text, optional): Enter the phone number of the client's emergency contact.
* **Emergency Contact Other** (Emergency Contact Other, note, optional): Enter any additional information about the client's emergency contact.
* **Emergency Contact Other Name** (Emergency Contact Other Name, text, optional): Enter the name of the emergency contact.
* **Client Signature** (Client Signature, text, required): Sign the form to indicate that you've reviewed and agreed to the information provided.
* **Date** (Date, date, optional): Enter the date of the form completion.
* **Time** (Time, time, optional): Enter the time of the form completion.
* **Additional Notes** (Additional Notes, text, optional): Enter any additional information or notes about the client.

Note: Some fields have specific formats or instructions to ensure accurate and complete information collection. Please follow these guidelines to provide the best possible service to your clients.
