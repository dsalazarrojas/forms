# website_intake_form - Help Guide
## Purpose
The website_intake_form is designed to collect information about a website. It appears to be a standard template for gathering essential details about a website. 

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Website URL** field with the website's actual URL.
2. Answer **Website Design** as 'Yes' or 'No', indicating whether the website is designed or not.
3. Select the **Website Development** options as 'Yes' or 'No' for each corresponding category.
4. Choose the **Development Stack** as 'Yes' or 'No' if applicable.
5. Answer **Website Launch** as 'Yes' or 'No' to indicate the website's launch status.
6. If the website is launched, fill in the **Website Launch Date** field with the actual launch date.
7. If applicable, select the **Website Launch Time** in the format 'HH:MM' (e.g., 14:30).
8. Enter the **Website Description** with a brief description of the website.
9. Add **Website Tags** by selecting 'Yes' or 'No' for each tag.
10. Optionally, fill in **Website Keywords** with a comma-separated list of relevant keywords.
11. Enter the **Website Owner**'s name.
12. If applicable, fill in the **Website Email** and **Website Phone** fields with the actual contact information.

## Field-by-Field Explanation

* **Website URL** (text): Enter the website's actual URL.
* **Website Design** (select_one): Answer 'Yes' if the website has been designed, 'No' otherwise.
* **Website Development** (select_one/select_multiple): Answer 'Yes' or 'No' for each category, indicating the level of development.
* **Development Stack** (select_one): Choose 'Yes' or 'No' if the website uses a specific development stack.
* **Website Launch** (select_one): Answer 'Yes' if the website is launched, 'No' otherwise.
* **Website Launch Date** (date): Fill in the actual launch date if the website is launched.
* **Website Launch Time** (time): Enter the actual launch time in 'HH:MM' format.
* **Website Description** (text): Provide a brief description of the website.
* **Website Tags** (select_multiple): Select 'Yes' or 'No' for each tag.
* **Website Keywords** (text): Enter a comma-separated list of relevant keywords.
* **Website Owner** (text): Enter the website owner's name.
* **Website Email** (email): Fill in the website owner's email address.
* **Website Phone** (text): Enter the website's phone number.
