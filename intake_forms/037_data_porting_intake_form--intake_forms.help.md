# Data Porting Intake Form - Help Guide
## Purpose
The Data Porting Intake Form is a tool used to collect and store data from users. This form will be used to create a data porting record, which can then be used for further processing and analysis.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you are filling out this form for the correct purpose and that the information provided is accurate and up-to-date.
2. Carefully review the form to ensure you haven't missed any required fields.
3. Complete each field accurately and concisely.
4. Review your responses before submitting the form to ensure accuracy and completeness.
