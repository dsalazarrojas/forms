# Parent Education Program Intake Form - Help Guide

## Purpose
The Parent Education Program Intake Form is used to gather information from parents and schools about a student's participation in a parent education program.

## How To Complete This Form
1. Enter the name of the school the student is attending.
2. Enter the name of the parent education program the student is participating in.
3. Enter the details of the program, such as the start and end dates.
4. Choose the type of participation the student has in the program (Parent, Student, or Both).
5. Enter the student's name.
6. Enter the student's birthdate.
7. Enter the contact phone number for the school.
8. Enter the contact email for the school.
9. Add any notes about the program or school (optional).
10. Add any additional notes about the program or school (optional).
11. If applicable, enter the time the program started and ended.
12. Enter the ID of the school where the student is attending (if applicable).
13. Enter the name of the assigned counselor (if applicable).

## Field-by-Field Explanation
* **School Name** (`school_name`, text, optional): Enter the name of the school the student is attending.
* **Program Name** (`program_name`, text, optional): Enter the name of the parent education program the student is participating in.
* **Program Details** (`program_details`, text, optional): Enter the details of the program, such as the start and end dates.
* **Parent Participation** (`parent_participation`, select_one, optional): Choose the type of participation the student has in the program (Parent, Student, or Both).
* **Student Name** (`student_name`, text, optional): Enter the name of the student.
* **Student Birthdate** (`student_birthdate`, date, optional): Enter the student's birthdate.
* **Program Start Date** (`program_start_date`, date, optional): Enter the start date of the program.
* **Program End Date** (`program_end_date`, date, optional): Enter the end date of the program.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact phone number for the school.
* **Contact Email** (`contact_email`, email, optional): Enter the contact email for the school.
* **Program Notes** (`program_notes`, note, optional): Add any notes about the program.
* **School Notes** (`school_notes`, note, optional): Add any additional notes about the school.
* **Program Status** (`program_status`, select_multiple, optional): Choose the status of the program (Active, Inactive, or Completed).
* **Notes** (`notes`, note, optional): Add any additional notes about the program.
* **Program Start Time** (`program_start_time`, time, optional): Enter the time the program started (if applicable).
* **Program End Time** (`program_end_time`, time, optional): Enter the time the program ended (if applicable).
* **School ID** (`school_id`, text, optional): Enter the ID of the school where the student is attending (if applicable).
* **Assigned Counselor** (`assigned_counselor`, text, optional): Enter the name of the assigned counselor (if applicable).
