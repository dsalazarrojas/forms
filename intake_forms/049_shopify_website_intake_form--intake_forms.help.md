# shopify_website_intake_form - Help Guide
## Purpose
The shopify_website_intake_form is a form designed to collect information from shopify store owners or administrators to create or manage their shopify store. 

## How To Complete This Form

1. Select the website domain from the dropdown menu.
2. Enter the website name.
3. Select the website category from the dropdown menu.
4. Enter a brief description of the store.
5. Enter the store address.
6. Enter the store phone number.
7. Enter the store email.
8. Enter the store image URL.
9. Enter a caption for the store image.
10. Enter the website URL.
11. Select the store tags (e.g. fashion, home, beauty, sport).
12. Select the social media platforms where the store is present (e.g. Facebook, Instagram, Twitter, Youtube, Pinterest, Tiktok).
13. Select the shopify product types (e.g. dropshipping, print-on-demand, physical, digital, service).
14. Select the shopify payment gateway (e.g. PayPal, Stripe, Square).
15. Select the shopify currency (e.g. USD, EUR, JPY, CNY).
16. Select the shopify currency symbol position (e.g. left, right, none).
17. Select the shopify website type (e.g. standard, advanced, custom).

## Field-by-Field Explanation

* **Website Domain**: <code>www.example.com</code> (Enter the domain name of the shopify website).
* **Website Name**: (Enter the name of the shopify website).
* **Website Category**: <code>eCommerce</code>, <code>Marketplace</code>, <code>Online Store</code>, <code>Blog</code>, <code>Portfolio</code> (Select the category of the shopify website).
* **Store Description**: (Enter a brief description of the store).
* **Store Address**: (Enter the address of the store).
* **Store Phone**: (Enter the phone number of the store).
* **Store Email**: <code>example@example.com</code> (Enter the email of the store).
* **Store Image URL**: <code>https://example.com/image.jpg</code> (Enter the URL of the store image).
* **Store Image Caption**: (Enter a caption for the store image).
* **Website URL**: <code>https://example.com</code> (Enter the URL of the website).
* **Store Tags**: <code>fashion</code>, <code>home</code>, <code>beauty</code>, <code>sport</code> (Select the tags for the store).
* **Store Facebook**: <code>True</code>, <code>False</code> (Select whether the store has a Facebook presence).
* **Store Instagram**: <code>True</code>, <code>False</code> (Select whether the store has an Instagram presence).
* **Store Twitter**: <code>True</code>, <code>False</code> (Select whether the store has a Twitter presence).
* **Store Youtube**: <code>True</code>, <code>False</code> (Select whether the store has a Youtube presence).
* **Store Pinterest**: <code>True</code>, <code>False</code> (Select whether the store has a Pinterest presence).
* **Store Tiktok**: <code>True</code>, <code>False</code> (Select whether the store has a Tiktok presence).
* **Store Other Social**: (Enter any other social media platforms the store is present on).
* **Store Other Social URLs**: (Enter the URL of other social media platforms the store is present on).
* **Shopify Product Types**: <code>dropshipping</code>, <code>print-on-demand</code>, <code>physical</code>, <code>digital</code>, <code>service</code> (Select the shopify product types).
* **Shopify Payment Gateway**: <code>PayPal</code>, <code>Stripe</code>, <code>Square</code> (Select the shopify payment gateway).
* **Shopify Currency**: <code>USD</code>, <code>EUR</code>, <code>JPY</code>, <code>CNY</code> (Select the shopify currency).
* **Shopify Currency Symbol**: (Enter the shopify currency symbol).
* **Shopify Currency Symbol Position**: <code>left</code>, <code>right</code>, <code>none</code> (Select the shopify currency symbol position).
* **Shopify Website Type**: <code>standard</code>, <code>advanced</code>, <code>custom</code> (Select the shopify website type).
