# Bed Bug Case Evaluation Form - Help Guide
## Purpose
The Bed Bug Case Evaluation Form is used to gather information about your bed bug infestation so that we can provide accurate and effective solutions to eradicate the issue.

## How To Complete This Form

To complete this form accurately and efficiently, please fill it out in the following order:

1. Please answer all the required questions. If a question does not apply to your situation, you may leave it blank.
2. Select the relevant answers for the drop-down menus.
3. Enter your preferred dates and times for inspection and treatment.
4. If you have pets or children in the home, please specify the number.
5. Review your answers for accuracy before submitting the form.

## Field-by-Field Explanation

* **Client Name** (`client_name`, `text`, required): Enter your full name or your business name.
* **Email Address** (`client_email`, `email`, required): Enter your primary contact email address.
* **Phone Number** (`client_phone`, `text`, required): Enter your best contact phone number.
* **Property Address** (`property_address`, `text`, required): Enter the full address of the affected property.
* **Property Type** (`property_type`, `select_one`, required): Select the type of property affected:
	+ Single Family Home
	+ Apartment or Condo
	+ Townhouse
	+ Hotel or Motel
	+ Dormitory
	+ Office Building
	+ Retail Store
	+ Other
* **Number of Units or Rooms** (`number_of_units`, `number`, optional): Enter the total number of units in the property, if applicable.
* **Affected Areas** (`affected_areas`, `select_multiple`, required): Select all areas where bed bugs were found:
	+ Bedrooms
	+ Living Room
	+ Kitchen
	+ Bathroom
	+ Basement
	+ Attic
	+ Garage
	+ Multiple Rooms
	+ Entire Property
* **Infestation Severity** (`infestation_severity`, `select_one`, required): Select the severity of the infestation:
	+ Light (1-5 bugs seen)
	+ Moderate (5-20 bugs seen)
	+ Heavy (20+ bugs seen)
	+ Severe (Daily sightings multiple rooms)
	+ Unsure
* **Date of First Sighting** (`first_sighting_date`, `date`, required): Enter the date you first noticed bed bugs.
* **Evidence Found** (`evidence_found`, `select_multiple`, required): Select all evidence you have observed:
	+ Live Bugs
	+ Dead Bugs
	+ Shed Skins
	+ Eggs or Egg Shells
	+ Blood Stains on Bedding
	+ Dark Fecal Spots
	+ Bites on Skin
	+ Musty Odor
	+ None Visible
* **Bite Symptoms** (`bite_symptoms`, `select_one`, required): Select the bite symptoms experienced:
	+ No Bites
	+ Minor Itching
	+ Moderate Itching and Redness
	+ Severe Reactions
	+ Allergic Reaction Requiring Medical Attention
* **Previous Treatment** (`previous_treatment`, `select_one`, required): Select your previous treatment experience:
	+ No First Time
	+ Yes DIY Treatment
	+ Yes Professional Treatment
	+ Yes Multiple Treatments
* **Previous Treatment Date** (`previous_treatment_date`, `date`, optional): If you had previous treatment, enter the date of the last treatment.
* **Previous Treatment Company** (`treatment_company`, `text`, optional): If you had previous treatment, enter the name of the company that treated your property.
* **Pets in Home** (`pets_in_home`, `select_one`, required): Select the number of pets in the home:
	+ No Pets
	+ Yes 1 Pet
	+ Yes 2-3 Pets
	+ Yes 4 or more Pets
* **Children in Home** (`children_in_home`, `select_one`, required): Select the number of children in the home:
	+ No Children
	+ Yes 1-2 Children
	+ Yes 3-4 Children
	+ Yes 5 or more Children
* **Preferred Inspection Date** (`preferred_inspection_date`, `date`, required): Enter your preferred inspection date.
* **Preferred Inspection Time** (`preferred_inspection_time`, `time`, required): Enter your preferred inspection time.
* **Access Instructions** (`access_instructions`, `text`, optional): If there are any special instructions for accessing the property, please enter them here.
* **Urgency Level** (`urgency_level`, `select_one`, required): Select the urgency level:
	+ Routine (within 1-2 weeks)
	+ Soon (within 1 week)
	+ Urgent (within 48 hours)
	+ Emergency (within 24 hours)
* **Estimated Budget Range** (`budget_range`, `select_one`, required): Select your estimated budget for treatment:
	+ Under $500
	+ $500-$1000
	+ $1000-$2500
	+ $2500-$5000
	+ Over $5000
	+ Need Quote
* **Additional Comments** (`additional_comments`, `text`, optional): If you have any other information about your situation, please enter it here.
* **Referral Source** (`referral_source`, `select_one`, optional): How did you find our services:
	+ Google Search
	+ Facebook
	+ Yelp or Review Site
	+ Friend or Family Referral
	+ Property Manager
	+ Previous Customer
	+ Other

## Tips

* Please answer all questions accurately and truthfully.
* Select only the areas affected by bed bugs.
* If you have pets or children, please specify the number.
* If you have previous treatment experience, please select the correct option.
* If you have any further questions or concerns, contact us at [insert contact information].

Note: This is a general help guide and may not cover every possible scenario. If you are unsure about any part of the form, please reach out to us for clarification.
