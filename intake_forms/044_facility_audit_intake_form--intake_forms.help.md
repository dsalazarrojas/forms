# Facility Audit Intake Form - Help Guide

## Purpose
The Facility Audit Intake Form is used to request an audit for a facility. This form will guide you through the process of submitting your request and collecting necessary information for the audit.

## How To Complete This Form

To complete this form, please follow these steps:

1. Provide the title of the facility being audited.
2. Choose the correct answers for each section, taking care to answer all required and optional questions.
3. Review and submit the form when finished.

## Field-by-Field Explanation

* **Facility Audit Intake Form** (1, text, required): Enter the title of the facility being audited.
* **Section 1** (2, select_one, optional): Choose 'Yes' if the facility audit is necessary. 
* **Audit Date** (3, date, optional): Enter the date of the audit, if known. 
* **Auditor's Name** (4, text, optional): Enter the name of the auditor, if known. 
* **Facility ID** (5, text, optional): Enter the facility ID, if known. 
* **Section 2** (6, select_multiple, optional): Choose 'Yes' if the audited areas are necessary. 
* **Audited Areas** (7, select_multiple, optional): Choose 'Yes' for each area that needs to be audited. 
* **Deficiencies** (8, select_multiple, optional): Choose 'Yes' for each deficiency that needs to be addressed. 
* **Comments** (9, note, optional): Enter any comments about the facility audit.
* **Section 3** (10, select_one, optional): Choose 'Yes' if the audit type is necessary. 
* **Audit Type** (11, select_one, optional): Choose 'Yes' for the audit type. 
* **Audit Status** (12, select_one, optional): Choose the current audit status. 
* **Date Completed** (13, date, optional): Enter the date the audit was completed, if known. 
* **Section 4** (14, select_multiple, optional): Choose 'Yes' if the facility details are necessary. 
* **Facility Type** (15, select_one, optional): Choose 'Yes' for the facility type. 
* **Facility Description** (16, text, optional): Enter a description of the facility, if known. 
* **Location** (17, text, optional): Enter the location of the facility, if known. 
* **Submit** (18, note, optional): This section is for submitting the form.
* **Facility Audit Intake Form Section 5 1** (19, note, optional): This section is for additional comments.
* **Facility Audit Intake Form Section 5 2** (20, text, optional): Enter any additional comments about the facility audit.
* **Date Submitted** (21, date, optional): Enter the date the form was submitted, if known. 
* **Facility Audit Intake Form Section 5 4** (22, date, optional): Enter the date the audit is due, if known. 
* **Date Due** (23, date, optional): Enter the date the audit is due, if known. 
* **Status** (24, select_one, optional): Choose the current status of the audit. 
* **Facility Audit Intake Form Section 5 7** (25, text, optional): Enter any additional comments about the facility audit.
