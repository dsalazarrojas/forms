# Healthcare Provider Referral Form - Help Guide
## Purpose
The Healthcare Provider Referral Form is designed for healthcare providers to share information about a patient's care requirements and preferences with other healthcare organizations or services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the provider's name and contact information in the "Provider Name" field.
2. Enter the patient's name in the "Patient Name" field.
3. Enter the patient's contact number in the "Contact Number" field.
4. Provide a brief reason for the referral in the "Referral Reason" field.
5. Select the referral type from the options provided (e.g., "New patient", "Follow-up", "Transfer", "Urgent").
6. Select the referral source from the options provided (e.g., "Provider", "Patient", "Referral Service", "Other").
7. Enter the patient's age in the "Patient Age" field.
8. Select the referral date and time using the calendar and clock tools.
9. Enter any additional notes about the referral in the "Referral Note" field.
10. Enter the provider's email address in the "Email" field.
11. Enter the provider's phone number in the "Phone" field.

## Field-by-Field Explanation

* **Provider Name (text)**: Enter your name and title (e.g., Dr., Nurse, etc.).
* **Patient Name (text)**: Enter the patient's name.
* **Contact Number (text)**: Enter the patient's contact number.
* **Referral Reason (text)**: Provide a brief reason for the referral (e.g., specialist consultation, procedure, or transfer).
* **Referral Type (select_one)**: Select the type of referral:
	+ New patient
	+ Follow-up
	+ Transfer
	+ Urgent
	+ Other (please select from options provided)
* **Referral Source (select_one)**: Select the source of the referral:
	+ Provider
	+ Patient
	+ Referral Service
	+ Other (please select from options provided)
* **Patient Age (text)**: Enter the patient's age.
* **Referral Date (date)**: Select the date of the referral.
* **Referral Time (time)**: Select the time of the referral.
* **Referral Note (note)**: Enter any additional notes about the referral.
* **Email (email)**: Enter your email address.
* **Phone (text)**: Enter your phone number.
