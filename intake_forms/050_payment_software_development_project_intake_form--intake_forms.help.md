# Payment Software Development Project Intake Form - Help Guide
## Purpose
This form is designed to collect project details and information for the payment software development project team. The goal is to ensure accurate and comprehensive data entry for project management and development purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields for each section, marked as "required" in the form.
2. Be accurate and concise in your entries for project details and information.
3. Select the correct technology stack and project status that apply to your project.
4. Ensure that you have filled in all necessary fields and clicked the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Project Details** (`project_details`, `text`, required): Enter a brief description of the project.
* **Software Development Team** (`software_development_team`, `text`, required): List the names of team members involved in the project.
* **Project Manager** (`project_manager`, `text`, required): Enter the name of the project manager.
* **Project Lead** (`project_lead`, `text`, required): Enter the name of the project lead.
* **Project Deadline** (`project_deadline`, `date`, required): Enter the project deadline date.
* **Development Cost** (`development_cost`, `number`, required): Enter the development cost of the project.
* **Technology Stack** (`technology_stack`, `select_multiple`, required): Select the technology stack that applies to your project from the options provided.
* **Project Description** (`project_description`, `text`, required): Enter a brief description of the project.
* **Submit** (`submit_button`, `note`, required): Click this button to complete and submit the form.
* **Email** (`email`, `email`, not required): Enter your contact email address.
* **Phone** (`phone`, `text`, not required): Enter your contact phone number.
* **Address** (`address`, `text`, not required): Enter your work or project location address.
* **Project Status** (`project_status`, `select_one`, required): Select the current project status from the options provided.
* **Payment Terms** (`payment_terms`, `select_one`, required): Select the payment terms that apply to your project.
* **Additional Terms** (`payment_terms_2`, `text`, not required): Enter any additional payment terms or conditions.
* **Project Notes** (`project_notes`, `text`, not required): Enter any project notes or comments.
* **Project Tags** (`project_tags`, `text`, not required): Enter any project tags or keywords.
* **Additional Project Tags** (`project_tags_2`, `text`, not required): Enter any additional project tags or keywords.
* **Project Files** (`project_files`, `text`, not required): Upload or enter any project files or documents.
* **Additional Project Files** (`project_files_2`, `text`, not required): Enter any additional project files or documents.
* **Project File URL** (`project_file_url`, `text`, not required): Enter any project files or documents URLs.
* **Additional Project File URL** (`project_file_url_2`, `text`, not required): Enter any additional project file URLs.
* **Project URL** (`project_url`, `text`, not required): Enter the project URL.
* **Additional Project URL** (`project_url_2`, `text`, not required): Enter any additional project URLs.
* **Assigned Tool** (`assigned_tool`, `select_one`, required): Select whether the project is assigned to a tool or not.
* **Assigned Tool** (`project_url_2`, `text`, not required): Enter any additional information about the assigned tool.
