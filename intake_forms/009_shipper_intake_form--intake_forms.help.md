# Shipper Intake Form - Help Guide
## Purpose
The Shipper Intake Form is a crucial part of the shipping process, and it's essential to complete it accurately.

## How To Complete This Form
To complete the Shipper Intake Form, follow these steps:

1. Fill out the Pickup Details section with all required information.
2. Choose the correct Shipper Type and Status from the drop-down menus.
3. Enter the Shipper's contact information, including email, phone number, and address.
4. Assign a user to the shipper if necessary.
5. Add any additional notes or comments about the shipper.

## Field-by-Field Explanation
* **Pickup Details** (`pickup_details`, `note`, required): Enter a brief description of the pickup details.
* **Delivery Details** (`delivery_details`, `text`, required): Enter a description of the delivery details.
* **Shipper Type** (`shipper_type`, `select_one`): Select the correct shipper type from the dropdown menu.
* **Shipper Status** (`shipper_status`, `select_multiple`): Select the correct status of the shipper from the dropdown menu.
* **Shipper Notes** (`shipper_notes`, `text`, required): Enter any additional notes or comments about the shipper.
* **Shipper Email** (`shipper_email`, `email`, required): Enter the shipper's email address.
* **Shipper Phone** (`shipper_phone`, `text`, required): Enter the shipper's phone number.
* **Shipper Address** (`shipper_address`, `text`, optional): Enter the shipper's address.
* **Shipper City** (`shipper_city`, `text`, optional): Enter the shipper's city.
* **Shipper State** (`shipper_state`, `text`, optional): Enter the shipper's state.
* **Shipper Zip** (`shipper_zip`, `number`, optional): Enter the shipper's zip code.
* **Shipper Country** (`shipper_country`, `text`, optional): Enter the shipper's country.
* **Assigned User** (`assigned_user`, `text`, optional): Assign a user to the shipper if necessary.
* **Assigned Date** (`assigned_date`, `date`, optional): Enter the date the shipper was assigned to.
* **Shipper Comments** (`shipper_comments`, `text`, optional): Enter any additional comments about the shipper.
* **Shipper Signature** (`shipper_signature`, `text`, optional): Enter the shipper's signature.
* **Shipper Company** (`shipper_company`, `text`, optional): Enter the shipper's company name.
* **Shipper Title** (`shipper_title`, `text`, optional): Enter the shipper's title.
* **Shipper Image** (`shipper_image`, `text`, optional): Upload an image of the shipper.
* **Report Type** (`report_type`, `select_one`, optional): Select the type of report to be generated.
* **Shipper Type** (`shipper_type`, `select_one`, optional): Select the type of shipper.
* **Shipper Report** (`shipper_report`, `text`, optional): Enter the shipper's report.
* **Shipper Report Date** (`shipper_report_date`, `date`, optional): Enter the date of the shipper's report.
* **Shipper Report Time** (`shipper_report_time`, `time`, optional): Enter the time of the shipper's report.

## Tips
* Make sure to fill out all required fields before submitting the form.
* Double-check the shipper's contact information for accuracy.
* Use the drop-down menus to select the correct shipper type and status.
* Upload any relevant images or reports for the shipper.
* Review the form carefully before submitting to ensure all information is accurate.
