# emdr_client_intake_form - Help Guide
## Purpose
The emdr_client_intake_form is designed to collect essential information about clients for the purpose of scheduling sessions and facilitating effective communication. This form is intended to gather data on client identification, contact information, session specifics, and consent.

## How To Complete This Form
1. Fill in the form with accurate and complete information about the client.
2. Ensure that all required fields are filled in, which are marked with an asterisk (\*). If a field is not required, you can skip it.
3. Select relevant options for the fields where possible, such as the consent and uploaded documents.
4. Review the form carefully before submitting it to ensure that all information is accurate and complete.

## Field-by-Field Explanation
* **Client ID** (`client_id`, number, required): Enter the client's ID number.
* **Client Name** (`client_name`, text, required): Enter the client's full name.
* **Email** (`email`, email, optional): If available, enter the client's email address.
* **Phone** (`phone`, text, optional): If available, enter the client's phone number.
* **Session Date** (`session_date`, date, required): Enter the date of the scheduled session.
* **Session Time** (`session_time`, time, required): Enter the time of the scheduled session.
* **Session Location** (`session_location`, text, required): Enter the location of the scheduled session.
* **Consent** (`consent`, select_multiple, required): Select the relevant consent options for the session.
* **Note** (`note`, note, optional): Enter any additional notes about the session.
* **Uploaded Documents** (`uploaded_documents`, select_multiple, optional): Select any relevant documents that have been uploaded for the session.

## Tips
* Ensure that all required fields are filled in before submitting the form.
* Double-check the form for accuracy and completeness before submitting it.
* If you are unsure about any field, refer to your supervisor or the provided guidelines for clarification.
