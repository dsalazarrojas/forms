# Entry Questionnaire - Help Guide
## Purpose
The Entry Questionnaire form collects data about a program's entry details. This data is used to help manage and track program-related activities.

## How To Complete This Form
1. **Program Name**: Enter the name of the program, if any.
2. **Program Type**: Select the type of program from the provided options.
3. **Entry Reason**: Explain the reason for the program's entry.
4. **Entry Date**: Select the date of the program's entry.
5. **Entry Time**: Select the time of the program's entry.
6. **Submission Status**: Select the current status of the program's submission.
7. **Additional Comments**: Add any additional comments about the program.
8. **Program Manager**: Enter the name of the program's manager.
9. **Intake Date**: Select the date the program was received for intake.
10. **Program Status**: Select the current status of the program.

## Field-by-Field Explanation
* **Program Name** (text, optional): Enter a brief name for the program.
* **Program Type** (select_one, optional): Choose one of the provided options for the program type.
* **Entry Reason** (text, optional): Explain the reason for the program's entry.
* **Entry Date** (date, optional): Select a date for the program's entry.
* **Entry Time** (time, optional): Select a time for the program's entry.
* **Submission Status** (select_one, optional): Choose one of the provided options for the submission status.
* **Additional Comments** (note, optional): Add any additional comments or notes about the program.
* **Program Manager** (text, optional): Enter the name of the program's manager.
* **Intake Date** (date, optional): Select the date the program was received for intake.
* **Program Status** (select_multiple, optional): Choose multiple statuses for the program's status.
  * Note: This field allows for multiple selections.
