# esthetician_client_intake_form - Help Guide
## Purpose
This form is designed for esthetician-client intake, used for scheduling and organizing appointments and client information.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Provide the required fields (marked as required).
3. If you need help or clarification on a field, please ask your esthetician.

## Field-by-Field Explanation
* **medical_history** (`medical_history`, text, not required): Please provide a brief medical history, including any relevant medical conditions or allergies.
* **allergies** (`allergies`, text, not required): If you have any allergies, please list them here.
* **skincare_concerns** (`skincare_concerns`, text, required): Please list any skincare concerns you have, such as acne, sensitive skin, etc.
* **skin_type** (`skin_type`, text, not required): Please select your skin type (normal, oily, combination, dry, etc.).
* **skin_condition** (`skin_condition`, text, not required): If you have any skin conditions, please describe them here.
* **medical_conditions** (`medical_conditions`, text, not required): If you have any medical conditions, please list them here.
* **skincare_products** (`skincare_products`, text, not required): If you use any skincare products, please list them here.
* **medical_supplement** (`medical_supplement`, text, not required): If you take any medical supplements, please list them here.
* **medications** (`medications`, text, not required): If you take any medications, please list them here.
* **contact_info** (`contact_info`, text, not required): Please provide your contact information, including phone number and email.
* **consent** (`consent`, text, required): Please indicate your consent to the esthetician performing the services.
* **notes** (`notes`, text, not required): Any additional information or notes about your appointment.
* **esthetician_name** (`esthetician_name`, text, required): Enter the name of the esthetician performing the services.
* **esthetician_contact** (`esthetician_contact`, text, not required): Please provide the esthetician's contact information, including phone number and email.
* **esthetician_email** (`esthetician_email`, text, not required): Enter the esthetician's email address.
* **esthetician_phone** (`estician_phone`, text, not required): Enter the esthetician's phone number.
* **date** (`date`, date, required): Select the appointment date.
* **time** (`time`, time, required): Select the appointment time.
* **appointment_id** (`appointment_id`, text, required): Enter a unique appointment ID.
* **client_id** (`client_id`, text, required): Enter a unique client ID.
* **skin_tone** (`skin_tone`, text, not required): Please select your skin tone (light, medium, dark, etc.).
* **client_name** (`client_name`, text, required): Enter your name.
* **service** (`service`, text, not required): If you are having a specific service, please select it here.
* **technician** (`technician`, text, not required): Enter the name of the technician performing the service.
* **notes2** (`notes2`, text, not required): Any additional information or notes about your appointment.

## Tips
* Please be as accurate and thorough as possible when filling out the form.
* If you have any questions or concerns, please don't hesitate to ask your esthetician.
* The form is meant to be used for intake purposes only, not for other uses.
