# Spa Client Intake Form - Help Guide
## Purpose

This form is designed to collect essential information from clients before scheduling a session. The data collected will help us provide a safe and effective therapeutic experience.

## How To Complete This Form

To complete this form, please follow these steps:

1. Provide your personal details, including your name and any other relevant contact information.
2. Answer the questions regarding your medical history, including any allergies or medications.
3. Specify your preferred schedule for the session, including the date and time.
4. If applicable, provide any necessary medical notes or emergency contact information.

## Field-by-Field Explanation

* **Client Information**: This field is for you to provide your personal details.
	+ Type: Text
	+ Required: False
* **Contact Information**: This field is for you to provide your contact details.
	+ Type: Text
	+ Required: False
* **Contact Phone**: This field is to specify if you have a contact phone number.
	+ Type: Select One (Yes/No)
	+ Required: False
* **Contact E mail**: This field is to specify if you have a contact email address.
	+ Type: Select Multiple (Yes/No)
	+ Required: False
* **Schedule Session**: This field is to schedule a session with us.
	+ Type: Date
	+ Required: False
* **Session Start**: This field is to specify the start time for your session.
	+ Type: Time
	+ Required: False
* **Therapy Type**: This field is to specify the type of therapy you need.
	+ Type: Select One (Yes/No)
	+ Required: False
* **Notes**: This field is for any necessary medical notes or information.
	+ Type: Note
	+ Required: False
* **Medical Notes**: This field is for any medical notes or information.
	+ Type: Note
	+ Required: False
* **Allergies**: This field is for you to list any allergies you may have.
	+ Type: Note
	+ Required: False
* **Medications**: This field is for you to list any medications you are currently taking.
	+ Type: Note
	+ Required: False
* **Medical History**: This field is for you to provide your medical history.
	+ Type: Note
	+ Required: False
* **Emergency Contact**: This field is for you to provide an emergency contact's name and phone number.
	+ Type: Note
	+ Required: False
* **Emergency Contact Relationship**: This field is for you to specify your relationship with the emergency contact.
	+ Type: Note
	+ Required: False
* **Emergency Phone**: This field is for the emergency contact's phone number.
	+ Type: Note
	+ Required: False
* **Emergency E mail**: This field is for the emergency contact's email address.
	+ Type: Note
	+ Required: False
* **Payment Information**: This field is for you to provide any payment information.
	+ Type: Note
	+ Required: False
