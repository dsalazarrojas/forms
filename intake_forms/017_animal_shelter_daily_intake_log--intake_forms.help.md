# Animal Shelter Daily Intake Log - Help Guide
## Purpose
The Animal Shelter Daily Intake Log is designed to provide essential information on animal intakes, aiding in the efficient and effective care and housing of the animals. The form should be completed for every animal that enters the shelter, ensuring accurate and up-to-date records are kept.
## How To Complete This Form
To complete this form, follow these steps:
- Enter the Intake Date in the format MM/DD/YY or MM/DD.
- Enter the Staff Member Name responsible for the intake.
- Enter the staff ID number (if applicable).
- Fill out each field with the relevant information:
	+ Daily Intake Number: Enter a sequence number for the animal.
	+ Animal ID: Enter the shelter-assigned identifier.
	+ Animal Name: If known, enter the animal's name.
	+ Species: Choose the correct species from the drop-down options.
	+ Breed: If known or apparent, enter the breed.
	+ Color and Markings: Enter a physical description of the animal.
	+ Sex: Select the correct sex from the drop-down options.
	+ Estimated Age: Enter the animal's age in years or months.
	+ Weight: Enter the animal's weight in pounds.
	+ Intake Type: Choose how the animal arrived at the shelter.
	+ Intake Source: Enter the person or organization that brought the animal.
	+ Source Contact Information: Enter the contact information for the source.
	+ Reason for Intake: Enter why the animal was brought to the shelter.
	+ Intake Location: Enter where the animal was found or from.
	+ Microchip Status: Choose if the animal is microchipped or not.
	+ Microchip Number: If applicable, enter the microchip number.
	+ Initial Health Assessment: Select the animal's health status.
	+ Health Observations: Enter any injuries, symptoms, or concerns.
	+ Initial Behavior Assessment: Enter any temperament observations.
	+ Quarantine Required: Select if quarantine is needed.
	+ Housing Assignment: Choose the housing for the animal.
	+ Photos Taken: Select if photos were taken during intake.
	+ Additional Notes: Enter any other relevant information.
## Field-by-Field Explanation
- **Intake Date**: Enter the date the animal was brought into the shelter.
 	* Type: date
 	* Required: true
 	* Explanation: The date of animal intake.
- **Staff Member Name**: Enter the name of the person completing the intake.
 	* Type: text
 	* Required: true
 	* Explanation: The person responsible for the intake process.
- **Staff ID Number**: Enter the ID number of the staff member if applicable.
 	* Type: text
 	* Required: false
 	* Explanation: Staff ID number, if available.
- **Daily Intake Number**: Enter a sequence number for the animal.
 	* Type: number
 	* Required: true
 	* Explanation: Unique sequence number for the animal for that day.
- **Animal ID or Tag Number**: Enter the shelter-assigned identifier.
 	* Type: text
 	* Required: true
 	* Explanation: The animal's identifier within the shelter.
- **Animal Name**: Enter the animal's name if known.
 	* Type: text
 	* Required: false
 	* Explanation: The animal's name if known to the shelter staff.
- **Species**: Choose the correct species from the drop-down options.
 	* Type: select_one
 	* Required: true
 	* Explanation: The animal's species (e.g., dog, cat, rabbit).
- **Breed**: Enter the breed if known or apparent.
 	* Type: text
 	* Required: false
 	* Explanation: The animal's breed, if known or obvious.
- **Color and Markings**: Enter the animal's physical description.
 	* Type: text
 	* Required: true
 	* Explanation: A detailed description of the animal's coat color and any markings.
- **Sex**: Choose the correct sex from the drop-down options.
 	* Type: select_one
 	* Required: true
 	* Explanation: The animal's sex (male, female, unknown).
- **Estimated Age**: Enter the animal's age in years or months.
 	* Type: text
 	* Required: true
 	* Explanation: The animal's age, in years or months.
- **Weight**: Enter the animal's weight in pounds.
 	* Type: number
 	* Required: true
 	* Explanation: The animal's weight.
- **Intake Type**: Choose how the animal arrived at the shelter.
 	* Type: select_one
 	* Required: true
 	* Explanation: How the animal was brought to the shelter (e.g., owner surrender, found animal).
- **Intake Source**: Enter the person or organization that brought the animal.
 	* Type: text
 	* Required: false
 	* Explanation: The name of the person or organization responsible for bringing the animal in.
- **Source Contact Information**: Enter the contact information for the source.
 	* Type: text
 	* Required: false
 	* Explanation: The contact information for the person or organization that brought the animal in.
- **Reason for Intake**: Enter why the animal was brought to the shelter.
 	* Type: text
 	* Required: true
 	* Explanation: The reason for the animal's presence at the shelter.
- **Intake Location**: Enter where the animal was found or from.
 	* Type: text
 	* Required: false
 	* Explanation: The location where the animal was found or from.
- **Microchip Status**: Choose if the animal is microchipped or not.
 	* Type: select_one
 	* Required: true
 	* Explanation: Whether the animal has a microchip or not.
- **Microchip Number**: If applicable, enter the microchip number.
 	* Type: text
 	* Required: false
 	* Explanation: The microchip number, if found.
- **Initial Health Assessment**: Select the animal's health status.
 	* Type: select_one
 	* Required: true
 	* Explanation: The animal's current health status (e.g., healthy, minor issues, critical).
- **Health Observations**: Enter any injuries, symptoms, or concerns.
 	* Type: text
 	* Required: false
 	* Explanation: A description of any health issues or concerns for the animal.
- **Initial Behavior Assessment**: Enter any temperament observations.
 	* Type: text
 	* Required: true
 	* Explanation: A description of the animal's behavior or temperament.
- **Is Quarantine Required**: Select if quarantine is needed.
 	* Type: select_one
 	* Required: true
 * Explanation: Whether quarantine is necessary for the animal.
- **Housing Assignment**: Choose the housing for the animal.
 	* Type: text
 	* Required: true
 	* Explanation: Where the animal will be housed (e.g., standard enclosure, separate room).
- **Photos Taken**: Select if photos were taken during intake.
 	* Type: select_one
 	* Required: true
 	* Explanation: Whether photos were taken of the animal during intake.
- **Additional Notes**: Enter any other relevant information.
 	* Type: text
 	* Required: false
 	* Explanation: Any additional information that may be helpful for the animal's care.

Please ensure you complete the form accurately and thoroughly to provide the best possible care for each animal. If you are unsure about any field or have further questions, consult with a supervisor or seek additional guidance.
