# Social Media Marketing Client Intake Form - Help Guide
## Purpose
This form is used to collect information about new social media marketing clients.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the first name and last name fields with the client's personal details.
2. Enter the client's email address in the "email" field.
3. Enter the client's phone number in the "phone_number" field.
4. Select the social media platforms the client uses in the "social_media_platforms" field.
5. Choose the social media goals for the client in the "social_media_goals" field.
6. Enter the client's budget for the campaign.
7. Select the expected launch date and time for the campaign.
8. Add any additional notes about the client in the "notes" field.

## Field-by-Field Explanation

* **First Name** (`first_name`, `text`, required: false): Enter the client's first name.
* **Last Name** (`last_name`, `text`, required: false): Enter the client's last name.
* **Email** (`email`, `email`, required: false): Enter the client's email address.
* **Phone Number** (`phone`, `text`, required: false): Enter the client's phone number.
* **Social Media Platforms** (`social_media_platforms`, `select_one`, required: false): Select all social media platforms the client uses (Facebook, Instagram, Twitter, YouTube, TikTok).
* **Social Media Goals** (`social_media_goals`, `select_multiple`, required: false): Choose the social media goals for the client (Brand Awareness, Engagement, Conversions, Lead Generation, Sales).
* **Budget** (`budget`, `number`, required: false): Enter the client's budget for the campaign.
* **Expected Launch Date** (`expected_launch_date`, `date`, required: false): Select the expected launch date for the campaign.
* **Expected Launch Time** (`expected_launch_time`, `time`, required: false): Select the expected launch time for the campaign.
* **Notes** (`notes`, `note`, required: false): Add any additional notes about the client.
