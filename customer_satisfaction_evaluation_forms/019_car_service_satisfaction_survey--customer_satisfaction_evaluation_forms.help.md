# Car Service Satisfaction Survey - Help Guide
## Purpose

This form is designed to collect your feedback about your recent car service experience. Your responses will help us understand what we did well and where we can improve. Please answer the questions honestly, and feel free to provide any specific comments or suggestions you might have.

## How To Complete This Form

1. Please fill out the form in sections, starting with the respondent information section (1-4).
2. Answer the questions in the satisfaction and feedback sections (5-10) with the option that best describes your experience.
3. In the free text fields (11, 12, 23, 24), provide any additional comments or feedback you might have.
4. Review the questions and make sure to answer all required fields (marked with *) before submitting the form.

## Field-by-Field Explanation

* **Your name** (`your_name`, text, required): Please provide your name as it appears on your identification.
* **Email address** (`your_email`, email, required): Please enter your email address so we can follow up with you.
* **Phone number** (`your_phone`, text, optional): If you have a phone number, please enter it so we can contact you if needed.
* **Date of service visit** (`service_visit_date`, date, required): Please select the date of your service visit.
* **Service location visited** (`service_location`, text, optional): Please enter the name or address of the service location you visited.
* **Type of service received** (`service_type_received`, select one, required): Please select the type of service you received during your visit.
* **Vehicle year, make, model** (`vehicle_year_make_model`, text, optional): Please enter the year, make, and model of your vehicle.
* **Overall satisfaction** (`overall_satisfaction`, select one, required): Please select how satisfied you are with your service experience.
* **Quality of work performed** (`work_quality_rating`, select one, required): Please select the quality of work performed during your service visit.
* **Staff professionalism and courtesy** (`staff_courtesy_rating`, select one, required): Please select the level of professionalism and courtesy shown by our staff.
* **Quality of communication** (`communication_rating`, select one, required): Please select the quality of communication you received during your visit.
* **Was service completed on time?** (`timeliness_rating`, select one, required): Please select if the service was completed on time.
* **Satisfaction with service cost** (`cost_satisfaction`, select one, optional): If you feel that the service cost was reasonable, please select the corresponding option.
* **Facility cleanliness and comfort** (`facility_rating`, select one, optional): If you visited a service location, please select how clean and comfortable it was.
* **Overall value for money** (`value_rating`, select one, required): Please select how you feel about the overall value for money.
* **Would you return for future service?** (`would_return`, select one, required): If you would return for future service, please select the corresponding option.
* **Would you recommend to others?** (`would_recommend`, select one, required): If you would recommend our service to others, please select the corresponding option.
* **What did we do well?** (`strengths`, text, optional): If you have any specific strengths that you want to highlight, please type them in.
* **What could be improved?** (`improvement_areas`, text, optional): If you have any suggestions or areas for improvement, please type them in.
* **Any specific feedback or suggestions?** (`specific_feedback`, text, optional): If you have any additional comments or suggestions, please type them in.
* **May we contact you for follow-up?** (`follow_up_contact`, select one, optional): If you would like us to contact you for follow-up, please select the corresponding option.
