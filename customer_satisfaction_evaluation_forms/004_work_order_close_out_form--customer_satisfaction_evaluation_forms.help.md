# Work Order Close Out Form - Help Guide
## Purpose
The Work Order Close Out Form is used to document the completion of a work order. It ensures that all tasks associated with the work order have been completed and that the customer is satisfied with the work done.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the customer type from the "Customer" field. This field is used to specify who the work order is for (Customer, Manager, or Engineer).
2. Select the work order number from the "Work Order" field. This field is used to specify which work order is being closed out. Make sure to select the correct number from the dropdown list.
3. Enter the hours worked on the job in decimal format in the "Hours Worked" field.
4. Enter the labor costs for the job in the "Labor Costs" field.
5. Enter the material costs for the job in the "Material Costs" field.
6. Enter the total costs for the job in the "Total Costs" field.
7. Enter the date the work was completed in the "Completed Date" field.
8. Enter the time the work was completed in the "Completed Time" field.
9. Enter any comments about the job in the "Comments" field.
10. Specify the customer's satisfaction level with the work done using the "Customer Satisfaction" field.
11. If applicable, enter any notes about the labor costs in the "Labor Costs Notes" field.
12. If applicable, enter any notes about the material costs in the "Material Costs Notes" field.
13. If applicable, enter any notes about the total costs in the "Total Costs Notes" field.
14. Enter any comments from the customer about the job in the "Customer Comments" field.
15. Enter any comments from the manager about the job in the "Manager Comments" field.
16. Enter any comments from the engineer about the job in the "Engineer Comments" field.
17. Enter any notes about the assigned tool in the "Assigned Tool" field.
18. Enter any additional comments about the job in the "Comments" field.
19. Enter any additional notes about the work order in the "Work Order Notes" field.

## Field-by-Field Explanation

* **Customer** (`Customer`, select_one): Select the customer type from the dropdown list (Customer, Manager, or Engineer).
* **Work Order** (`Work Order`, select_multiple): Select the work order number from the dropdown list. Make sure to select the correct number from the list.
* **Hours Worked** (`Hours Worked`, number): Enter the hours worked on the job in decimal format.
* **Labor Costs** (`Labor Costs`, number): Enter the labor costs for the job.
* **Material Costs** (`Material Costs`, number): Enter the material costs for the job.
* **Total Costs** (`Total Costs`, number): Enter the total costs for the job.
* **Completed Date** (`Completed Date`, date): Enter the date the work was completed.
* **Completed Time** (`Completed Time`, time): Enter the time the work was completed.
* **Comments** (`Comments`, note): Enter any comments about the job.
* **Customer Satisfaction** (`Customer Satisfaction`, select_one): Specify the customer's satisfaction level with the work done.
* **Assigned Tool** (`Assigned Tool`, text): Enter any notes about the assigned tool.
* **Comments** (`Comments`, note): Enter any additional comments about the job.
* **Work Order Notes** (`Work Order Notes`, note): Enter any additional notes about the work order.
* **Customer Comments** (`Customer Comments`, note): Enter any comments from the customer.
* **Manager Comments** (`Manager Comments`, note): Enter any comments from the manager.
* **Engineer Comments** (`Engineer Comments`, note): Enter any comments from the engineer.
* **Labor Costs Notes** (`Labor Costs Notes`, note): Enter any notes about the labor costs.
* **Material Costs Notes** (`Material Costs Notes`, note): Enter any notes about the material costs.
* **Total Costs Notes** (`Total Costs Notes`, note): Enter any notes about the total costs.
* **Closed Out By** (`Closed Out By`, text): Enter the name of the person who closed out the work order.
* **Closed Out Date** (`Closed Out Date`, date): Enter the date the work order was closed out.
* **Closed Out Time** (`Closed Out Time`, time): Enter the time the work order was closed out.
* **Completed By** (`Completed By`, text): Enter the name of the person who completed the work.
* **Completed Date** (`Completed Date`, date): Enter the date the work was completed.

## Tips

* Make sure to review the work order for completeness before filling out this form.
* Ensure that all tasks associated with the work order have been completed.
* Enter accurate and complete information in all fields.
* Use the "Customer Satisfaction" field to document the customer's satisfaction level with the work done.
* Use the "Comments" field to enter any additional comments about the job.
* Use the "Notes" fields to enter any additional notes about the job.
