# store_layout_satisfaction_poll - Help Guide
## Purpose
The store layout evaluation form aims to collect feedback on the store's layout, overall satisfaction, and suggestions for improvement.

## How To Complete This Form
1. Start by selecting the page with the store layout question.
2. Answer the "store layout" question by selecting one of the provided options or adding a text-based response.
3. Move on to the "overall satisfaction" page and select one of the options that best describes your overall satisfaction with the store layout.
4. On the "layout improve" page, select all that apply to indicate areas of the store layout that need improvement.
5. If you have specific suggestions for improvement, type in the "section improvement" field.
6. If you have feedback on the navigation, select all that apply on the "navigation improvement" page.
7. If you have experienced a store layout change, answer the "layout change" page by entering a numeric value.
8. If you have suggestions on store layout change, enter the time it took for you to make this change on the "layout change time" page.
9. If you have a reason for the store layout change, type it in the "reason for layout change" field.
10. On the "suggest improvement" page, select all that apply to provide suggestions on what could improve the store layout.
11. On the "store improvement" page, select all that apply to suggest what could improve the store.
12. On the "overall satisfaction improvement" page, select all that apply to suggest what could improve overall satisfaction.
13. If you have any additional feedback, type it in the "feedback" field.
14. Finally, provide your email address and phone number if you would like to be contacted for further discussion.

## Field-by-Field Explanation
* **store layout** (`store_layout_satisfaction`, text, optional): Describe your experience with the store's layout.
* **overall satisfaction** (`overall_satisfaction`, select_one, optional): Select one of the options that best describes your overall satisfaction with the store layout.
	+ Very Dissatisfied
	+ Somewhat Dissatisfied
	+ Neutral
	+ Somewhat Satisfied
	+ Very Satisfied
* **layout improve** (`layout_improve`, select_multiple, optional): Select all that apply to indicate areas of the store layout that need improvement.
	+ too small
	+ too big
	+ too cluttered
	+ label: reported
* **section improvement** (`section_improvement`, text, optional): Provide a specific suggestion for improvement.
* **navigation improvement** (`navigation_improvement`, select_multiple, optional): Select all that apply to indicate areas of navigation that need improvement.
	+ too slow
	+ too fast
	+ too hard to navigate
	+ too easy to navigate
* **layout change** (`layout_change`, number, optional): If you have experienced a store layout change, enter the numeric value of the change.
* **layout change time** (`layout_change_time`, number, optional): If you have experienced a store layout change, enter the time it took for you to make this change.
* **reason for layout change** (`reason_for_layout_change`, text, optional): Describe the reason for the store layout change.
* **suggest improvement** (`suggest_improvement`, select_multiple, optional): Select all that apply to suggest what could improve the store layout.
	+ less clutter
	+ more organized
	+ more space
	+ more appealing
* **store improvement** (`store_improvement`, select_multiple, optional): Select all that apply to suggest what could improve the store.
	+ more products
	+ more promotions
	+ more events
	+ more sales associate help
* **overall satisfaction improvement** (`overall_satisfaction_improvement`, select_multiple, optional): Select all that apply to suggest what could improve overall satisfaction.
	+ more appealing
	+ more organized
	+ more space
	+ better product variety
* **feedback** (`feedback`, text, optional): Provide any additional feedback about the store.
* **email** (`email`, email, optional): Enter your email address if you would like to be contacted for further discussion.
* **phone** (`phone`, text, optional): Enter your phone number if you would like to be contacted for further discussion.
