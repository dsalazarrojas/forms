# Returns Process Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback from customers regarding their return process experiences. It will help us understand their satisfaction, preferences, and pain points related to returning products.

## How To Complete This Form
- To complete this form, simply fill in the required and optional fields as requested.
- Please provide honest and detailed feedback to help us improve the return process.
- You can submit the form multiple times if you have had multiple return experiences.

## Field-by-Field Explanation
* **Return Process** (`return_process`, text, optional): Describe your return experience. What happened during the return process that you would like to share with us?
* **Overall Satisfaction** (`overall_satisfaction`, select_one, optional): How would you rate your overall satisfaction with the return process? Choose from:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Return Date** (`return_date`, date, optional): If you returned a product, please enter the date of the return.
* **Return Time** (`return_time`, time, optional): If you returned a product, please enter the time of the return.
* **Return Channel** (`return_channel`, select_one, optional): Through which channel did you return your product? Choose from:
	+ In-store
	+ Online
	+ Phone
	+ In-app
* **Return Reason** (`return_reason`, text, optional): Please describe why you returned the product.
* **Customer Service** (`customer_service`, text, optional): Share any interactions you had with our customer service team.
* **Return Process Improve** (`return_process_improve`, text, optional): What changes would you like to see in the return process?
* **Return Frequency** (`return_frequency`, number, optional): How often do you typically return products?
* **Return Satisfaction Frequency** (`return_satisfaction_frequency`, number, optional): On average, how often do you return products due to dissatisfaction?
* **Return Suggestion** (`return_suggestion`, text, optional): Do you have any suggestions for improving the return process?
