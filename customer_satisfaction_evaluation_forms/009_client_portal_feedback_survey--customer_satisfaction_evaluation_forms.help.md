# Client Portal Feedback Survey - Help Guide
## Purpose
This form is designed to collect feedback from clients about their experience with the Client Portal. Your input will help us identify areas for improvement and make informed decisions on future enhancements.

## How To Complete This Form

1.  The form is divided into multiple sections. Please answer each question to the best of your ability.
2.  For questions with multiple options, select all that apply.
3.  When providing text input, be as specific as possible.

## Field-by-Field Explanation

*  **Client Portal Feedback Survey**
	+ A brief introduction to the survey.
*  **Client ID or Account Number** (`client_id`)
	+ This is an optional field for identifying the client. If you have an account with us, you can provide your client ID or Account Number.
*  **How Often Do You Use the Client Portal** (`usage_frequency`)
	+ This question helps us understand how frequently you use the Client Portal. Select the option that best describes your usage frequency.
*  **What Do You Primarily Use the Portal For** (`primary_use_case`)
	+ This question helps us understand your primary use cases. Select all that apply to the features you use most often.
*  **How Easy Is It to Log In to the Portal** (`ease_of_login`)
	+ This question helps us understand the ease of access you experience when logging into the Client Portal. Select the option that best describes your experience.
*  **How Easy Is It to Navigate the Portal** (`navigation_ease`)
	+ This question helps us understand how easy or difficult you find it to navigate the Client Portal. Select the option that best describes your experience.
*  **How Would You Rate Page Load Speed** (`page_load_speed`)
	+ This question helps us understand your experience with page load speed. Select the option that best describes your experience.
*  **How Would You Rate the Mobile Experience** (`mobile_experience`)
	+ This question is only visible if you have used mobile. Select the option that best describes your experience.
*  **How Satisfied Are You with Available Features** (`feature_satisfaction`)
	+ This question helps us understand your satisfaction with the features available on the Client Portal. Select the option that best describes your experience.
*  **Which Feature Do You Use Most** (`most_used_feature`)
	+ This question helps us understand which feature you use most often. Select the feature that you use most often.
*  **Which Feature Do You Use Least** (`least_used_feature`)
	+ This question helps us understand which feature you use least often. Select the feature that you use least often.
*  **What Features Are Missing That You Would Like** (`missing_features`)
	+ This question helps us understand which features you would like to see added. Select all that apply.
*  **How Confident Are You in the Portal Security** (`security_confidence`)
	+ This question helps us understand your confidence in the security of the Client Portal. Select the option that best describes your experience.
*  **How Easy Is It to Find Information You Need** (`information_findability`)
	+ This question helps us understand how easy or difficult you find it to find the information you need on the Client Portal. Select the option that best describes your experience.
*  **How Would You Rate Support Responsiveness** (`support_responsiveness`)
	+ This question is only visible if you have contacted support. Select the option that best describes your experience.
*  **Overall How Satisfied Are You with the Client Portal** (`overall_satisfaction`)
	+ This question helps us understand your overall satisfaction with the Client Portal. Select the option that best describes your experience.
*  **How Likely Are You to Recommend This Portal to Others** (`net_promoter_score`)
	+ This question helps us understand how likely you are to recommend the Client Portal to others. Select the option that best describes your experience.
*  **What Is Your Biggest Frustration with the Portal** (`biggest_frustration`)
	+ This question helps us understand your biggest frustration with the Client Portal. Please provide a specific reason.
*  **What Do You Like Most About the Portal** (`biggest_strength`)
	+ This question helps us understand what you like most about the Client Portal. Please provide a specific reason.
*  **What Improvements Would You Suggest** (`improvement_suggestions`)
	+ This question helps us understand your suggestions for improvements. Please provide specific reasons.
*  **Additional Comments or Feedback** (`additional_feedback`)
	+ This is an open-ended question for any additional comments or feedback you may have.
*  **May We Contact You for Follow-up Questions** (`follow_up_permission`)
	+ This question is to determine if you are willing to be contacted for follow-up questions. Select the option that best describes your preference.
*  **Email for Follow-up**
	+ If you answered "yes" to the previous question, provide your email address so we can contact you for follow-up questions.
