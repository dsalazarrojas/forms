# Customer Loyalty Program Feedback Poll - Help Guide
## Purpose
This form is designed to collect feedback from customers on their experience with our customer loyalty program. It includes questions and ratings that will help us understand customer satisfaction, expectations, and preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each page of the form carefully before proceeding.
2. Answer each question to the best of your ability.
3. For select_multiple and select_one fields, select one or more options that apply to you.
4. For text fields, provide a brief explanation or comment.

## Field-by-Field Explanation
- **customer_loyalty_program_feedback** (`text`, optional): A text field where you can provide any comments or feedback about the customer loyalty program.
- **prophets** (`select_multiple`, optional): Select all that apply regarding your satisfaction with the loyalty program.
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
- **rewards** (`select_multiple`, optional): Select all that apply regarding the rewards you would like to see in the program.
	+ More rewards options
	+ Rewards updates
	+ Reward updates
	+ More rewards
- **program_updates** (`select_one`, optional): Select an option regarding the type of program updates you would like to see.
	+ Program updates
	+ Reward updates
	+ Reward prophets
- **satisfaction** (`text`, optional): A text field where you can provide any comments or feedback about your overall satisfaction with the program.
- **satisfaction_level** (`select_one`, optional): Select an option to rate your overall satisfaction with the program.
	+ Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
- **suggestions** (`text`, optional): A text field where you can provide any suggestions you have for improving the program.
- **comments** (`text`, optional): A text field where you can provide any additional comments or feedback.
- **contact_info** (`select_multiple`, optional): Select all that apply regarding how you would like to be contacted.
	+ Email
	+ Phone
	+ Mail
- **reward** (`select_one`, optional): Select an option regarding the reward you would like to see.
	+ More rewards
	+ Other
- **reward_updates** (`select_multiple`, optional): Select all that apply regarding the reward updates you would like to see.
	+ Reward updates
	+ Program updates

Note: All fields are optional, so please feel free to skip questions that do not apply to you.
