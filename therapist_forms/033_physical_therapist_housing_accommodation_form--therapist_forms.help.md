# Physical Therapist Housing Accommodation Form - Help Guide
## Purpose
This form is used to collect information about the housing accommodation for a physical therapist, including accommodation type, duration, start and end dates, and other relevant details.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Fill in all the required fields as accurately as possible.
2. Review each field carefully to ensure that you have provided the correct information.

## Field-by-Field Explanation
### 1. Form Information (ID: 1)
• **Form Information** (`Form Information`, text, not required): This field is a brief description of the form's purpose and requirements. Please refer to this section for an explanation of the form's purpose.

### 2. Patient Name (ID: 2)
• **Patient Name** (`patient_name`, text, not required): Enter the name of the patient for whom the accommodation is being arranged.

### 3. Patient Phone Number (ID: 3)
• **Patient Phone Number** (`patient_phone_number`, text, not required): Please provide a valid 10-digit phone number for the patient.

### 4. Patient Email (ID: 4)
• **Patient Email** (`patient_email`, email, not required): Enter the patient's email address if available.

### 5. Patient Address (ID: 5)
• **Patient Address** (`patient_address`, text, not required): Enter the patient's address for accommodation purposes.

### 6. Therapist Name (ID: 6)
• **Therapist Name** (`therapist_name`, text, not required): Enter your name as the physical therapist arranging the accommodation.

### 7. Therapist Phone Number (ID: 7)
• **Therapist Phone Number** (`therapist_phone_number`, text, not required): Please provide a valid 10-digit phone number for yourself.

### 8. Accommodation Type (ID: 8)
• **Accommodation Type** (`accommodation_type`, select_one, not required): Select the type of accommodation being arranged:
	+ Inpatient
	+ Outpatient
	+ Both

### 9. Accommodation Duration (ID: 9)
• **Accommodation Duration** (`accommodation_duration`, select_multiple, not required): Select the duration of the accommodation:
	+ Short-term
	+ Long-term
	+ Variable

### 10. Accommodation Start Date (ID: 10)
• **Accommodation Start Date** (`accommodation_start_date`, date, not required): Enter the date the accommodation is expected to start.

### 11. Accommodation End Date (ID: 11)
• **Accommodation End Date** (`accommodation_end_date`, date, not required): Enter the date the accommodation is expected to end.

### 12. Accommodation Notes (ID: 12)
• **Accommodation Notes** (`accommodation_notes`, text, not required): Provide any additional notes about the accommodation.

## Tips

* Please ensure that the information provided is accurate and up-to-date.
* If you are unsure about any of the fields, please refer to the form's purpose and this help guide.
* If you need help with completing the form, please reach out to the relevant authorities or support teams.
* This form is for the sole purpose of recording information about the physical therapist's housing accommodation. Any other purpose or use of this form is not authorized.
