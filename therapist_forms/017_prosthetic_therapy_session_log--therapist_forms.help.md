# Prosthetic Therapy Session Log - Help Guide
## Purpose
The Prosthetic Therapy Session Log form is designed to track and document details of prosthetic therapy sessions. This form ensures consistency and accuracy in recording session information, which is crucial for providing quality care and services.

## How To Complete This Form
1. Start by filling out the session date in the format required (YYYY-MM-DD). This date should reflect the date of the therapy session.
2. Enter your first name in the "Therapist First Name" field. This field is intended to capture your personal name.
3. Enter your last name in the "Therapist Last Name" field. This field is meant to capture your surname.
4. Specify the session length in minutes in the "Session Length" field. This value should reflect the duration of the therapy session.
5. Provide a brief description of the session in the "Session Notes" field. This field is meant to capture any notable comments or discussions that occurred during the session.

## Field-by-Field Explanation
### Session Date (session_date)
* **Session Date** (`session_date`, `date`, required/optional: false): Enter the date of the therapy session in the format YYYY-MM-DD.

### Therapist First Name (therapist_first_name)
* **Therapist First Name** (`therapist_first_name`, `text`, required/optional: false): Enter your personal name in this field.

### Therapist Last Name (therapist_last_name)
* **Therapist Last Name** (`therapist_last_name`, `text`, required/optional: false): Enter your surname in this field.

### Session Length (session_length)
* **Session Length** (`session_length`, `number`, required/optional: false): Enter the duration of the therapy session in minutes.

### Session Notes (session_notes)
* **Session Notes** (`session_notes`, `note`, required/optional: false): Provide a brief description of the session in this field, including any notable comments or discussions.
