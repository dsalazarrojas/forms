# Physical Therapy Time Off Request - Help Guide
## Purpose
This form is used to request time off for physical therapy sessions. Please fill out the form to submit your request and ensure that your manager receives it for approval.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Select the correct employee ID from the drop-down menu (this may be a unique code assigned to each employee).
2. Choose the desired time period when you plan to be off for physical therapy.
3. Enter your start and end dates for the physical therapy sessions, if applicable.
4. Provide a brief explanation or reason for your request (e.g., injury, recovery, etc.).
5. If necessary, select your manager's approval status (Approved, Denied, or Pending).
6. Add any comments for your manager's reference (optional).

## Field-by-Field Explanation
* **Employee Id** (`employee_id`, `number`, required: false): Enter the ID number assigned to you by the organization.
* **Time Period** (`time_period`, `select_one`, required: false): Choose a specific day of the week when you plan to be off for physical therapy.
* **Start Date** (`start_date`, `date`, required: false): Enter the date when you plan to start the physical therapy sessions, if applicable.
* **End Date** (`end_date`, `date`, required: false): Enter the date when you plan to end the physical therapy sessions, if applicable.
* **Reason** (`reason`, `text`, required: false): Briefly explain the reason for your physical therapy time off request (e.g., injury, recovery, etc.).
* **Manager Approval** (`manager_approval`, `select_multiple`, required: false): Select the status of your manager's approval (Approved, Denied, or Pending).
* **Comments** (`comments`, `text`, required: false): Add any additional comments or details for your manager's reference.
