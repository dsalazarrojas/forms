# Family Coaching Session Log - Help Guide
## Purpose
The Family Coaching Session Log form is a tool to record and track family coaching sessions. It captures key details about each session to provide a clear picture of progress and facilitate future planning.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the family's name in the "family_name" field.
2. Enter the coach's name in the "coach" field.
3. Select the date of the session in the "session_date" field.
4. Enter the duration of the session in the "session_duration" field.
5. In the "focus_areas" field, select all the areas you addressed during the session (e.g., "Yes" for each applicable area).
6. Enter any notable "notes" from the session.
7. For "action_items," select all the tasks you assigned to the family.
8. Provide feedback about the session in the "feedback" field.
9. If necessary, indicate who submitted the form in the "form_submitted_by" field.

## Field-by-Field Explanation

* **Family Name** (`family_name`, text, required): Enter the family's name as it appears in your records or as they have provided it to you.
* **Coach** (`coach`, text, required): Enter your name or the name of the coach who conducted the session.
* **Session Date** (`session_date`, date, required): Select the date of the coaching session.
* **Session Duration** (`session_duration`, number, required): Enter the duration of the coaching session in minutes.
* **Focus Areas** (`focus_areas`, select_multiple, required): Select all the areas you addressed during the session (e.g., "Yes" for each applicable area).
	+ Select "Yes" for each area you addressed.
* **Notes** (`notes`, text, optional): Enter any notable details from the session.
* **Action Items** (`action_items`, select_multiple, optional): Select all the tasks you assigned to the family.
	+ Select "Yes" for each action item.
* **Feedback** (`feedback`, text, optional): Provide your feedback about the session.
* **Form Submitted By** (`form_submitted_by`, text, optional): If necessary, indicate who submitted the form.

## Tips
- Make sure to accurately and completely fill out each field to ensure accurate records.
- If you need to update an existing entry, use the edit function instead of creating a new one.
- This form is intended to be a concise and clear record of each family coaching session.
- If you have any questions or concerns, contact your supervisor or the system administrator.
