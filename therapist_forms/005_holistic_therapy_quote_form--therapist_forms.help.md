# Holistic Therapy Quote Form - Help Guide
## Purpose
The Holistic Therapy Quote Form is designed to collect information from clients interested in scheduling a holistic therapy session. This form will be used to generate a quote for the desired session and facilitate the internal processing and handling of requests.

## How To Complete This Form
To complete this form successfully, follow these steps:

1. Fill out the "Quote Request" field with a clear and concise description of your request.
2. Choose the type of session you are interested in (Massage, Chiropractic, Acupuncture, or Other) from the "Session Type" field.
3. Enter your name in the "Client Name" field.
4. Provide your email address in the "Email" field.
5. Enter your phone number in the "Phone" field.
6. Optionally, if you have any specific address for the session, enter it in the "Address" field.
7. Select the desired session length in the "Session Length" field.
8. Provide pricing details for your session in the "Pricing Details" field.
9. If you would like to schedule a follow-up session, select "True" or "Maybe" in the "Follow up" field. If you choose "Maybe", please also provide the desired follow-up time in the "Follow up Time" field.
10. If you have any other session type or details not listed, enter them in the "Other Session Type" and "Other Session Details" fields.
11. Finally, provide the name of the practitioner you would like to work with in the "Therapist Name" field and any additional information about the practitioner in the "Practitioner Info" field.

## Field-by-Field Explanation

* **Quote Request** (ID 1, text, required):
	+ Please enter a clear and concise description of your session request.
* **Session Type** (ID 2, select_one, required):
	+ Choose the type of session you are interested in (Massage, Chiropractic, Acupuncture, or Other).
* **Client Name** (ID 3, text, required):
	+ Enter your full name.
* **Email** (ID 4, email, required):
	+ Enter a valid email address.
* **Phone** (ID 5, text, required):
	+ Enter your phone number.
* **Address** (ID 6, text, optional):
	+ If you have a specific address for the session, enter it here.
* **Session Length** (ID 7, number, required):
	+ Select the desired session length.
* **Pricing Details** (ID 8, text, required):
	+ Provide details about your pricing preferences or requirements.
* **Follow up** (ID 9, select_multiple, optional):
	+ If you would like to schedule a follow-up session, select "True". If you're unsure, select "Maybe" and provide your desired follow-up time.
* **Follow up Time** (ID 10, date, optional):
	+ If you selected "Maybe" for follow-up, enter the desired time for the follow-up session.
* **Follow up Details** (ID 11, text, optional):
	+ If you have any additional details about your follow-up session, enter them here.
* **Other Session Type** (ID 12, text, optional):
	+ If you have any other session type not listed, enter it here.
* **Other Session Details** (ID 13, text, optional):
	+ If you have any other session details not listed, enter them here.
* **Therapist Name** (ID 14, text, required):
	+ Enter the name of the practitioner you would like to work with.
* **Practitioner Info** (ID 15, text, required):
	+ Provide any additional information about the practitioner you have chosen.
