# pharmacy_weekend_work_checklist - Help Guide
## Purpose
This form is designed to help pharmacists manage their weekend work schedules, medication inventories, and communication details during the weekend.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct page by clicking on the page number.
2. Fill out each field with the requested information.

## Field-by-Field Explanation

* **Weekend Work Checklist Page 1** (`weekend_work_checklist_page_1`, number, optional): This is the first page of the form. You can navigate through the pages by clicking on the page number.
* **Pharmacist Name** (`pharmacist_name`, text, optional): Please enter your name as it appears on your ID or badge.
* **Workshift Start Time** (`workshift_start_time`, time, optional): Enter the start time of your work shift.
* **Workshift End Time** (`workshift_end_time`, time, optional): Enter the end time of your work shift.
* **Medication Inventory** (`medication_inventory`, select_one, optional): Select the current medication inventory level. Please choose from the available options: Medication A, Medication B, or Medication C.
* **Medication Levels** (`medication_levels`, select_multiple, optional): Select multiple medication levels that need to be managed.
* **Notes** (`notes`, note, optional): If you have any additional comments or concerns, please include them here.
* **Email** (`email`, email, optional): If you want to be contacted via email, please enter your email address.
* **Phone** (`phone`, text, optional): If you want to be contacted via phone, please enter your phone number.

## Tips
* Please ensure that you have the necessary information and permissions before completing this form.
* If you are unsure about any of the fields, please don't hesitate to contact the administrator.
* This form is intended to aid in the efficient management of weekend work, but it's not a replacement for actual work schedules and inventory management systems.
* Please update your work schedule and inventory levels accurately to ensure the efficient management of the pharmacy.
