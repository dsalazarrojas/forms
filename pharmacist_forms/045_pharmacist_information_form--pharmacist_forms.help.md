# pharmacist_information_form - Help Guide
## Purpose
This form is used to record pharmacist information for the purpose of maintaining a database of available pharmacists in the system.

## How To Complete This Form

1. Fill out the **Form Id** field with the unique ID for this form. This is a required field and must be completed.
2. Enter a brief **Description** of the pharmacist's services in the provided text field. This field is also required.
3. Select the **Category** for the pharmacist from the available options. This field is required.
4. Enter the name of the **Assigned User** who will handle this pharmacist's work. This field is required.
5. Enter the **Title** of the pharmacist in the provided text field. This field is required.
6. Enter the name of the **Assigned To** user who will receive updates or notifications about this pharmacist. This field is required.
7. If desired, enter the name of the **User** associated with this form in the provided text field. This field is optional.

## Field-by-Field Explanation
* **Form Id** (1): A unique identifier for this form.
* **Description** (2): Enter a brief description of the pharmacist's services.
* **Category** (3): Select the category for the pharmacist's services.
* **Assigned User** (4): Enter the name of the user assigned to handle this pharmacist's work.
* **Title** (5): Enter the title of the pharmacist.
* **Assigned To** (6): Enter the name of the user to whom the pharmacist is assigned.
* **User** (7): Enter the name of the user associated with this form (if desired).
