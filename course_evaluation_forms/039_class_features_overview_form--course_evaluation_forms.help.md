# Class Features Overview Form - Help Guide

## Purpose
The Class Features Overview Form is a comprehensive tool used by staff, instructors, and administrators to provide a detailed overview of a class or course. This form helps to gather essential information that can be used for promotional purposes, course planning, and student registration decisions.

## How To Complete This Form

1. Fill in the required fields with accurate and concise information about the class or course.
2. Review each field carefully and ensure that the provided options match the actual characteristics of the class.
3. Use the hint text as a guide to fill in the fields correctly.
4. Do not leave any field blank, as required fields are essential for the form's purpose.
5. If a field does not apply to the class, select "Other" as the option.

## Field-by-Field Explanation

* **Class or Course Name (`class_name`, Text, Required)**: Enter the official name of the class or course.
* **Course Code (`class_code`, Text, Required)**: Enter the course code (e.g., CS101).
* **Department (`department`, Select One, Required)**: Choose the academic department associated with the class (e.g., Mathematics, Science, etc.).
* **Instructor Name (`instructor_name`, Text, Required)**: Enter the name of the primary instructor.
* **Instructor Credentials (`instructor_credentials`, Text, Optional)**: Provide the instructor's degrees, certifications, etc.
* **Class Description (`class_description`, Text, Required)**: Enter a brief overview of the class, including its objectives, goals, and content.
* **Learning Objectives (`learning_objectives`, Text, Required)**: Describe what students will learn throughout the class.
* **Credit Hours (`credit_hours`, Select One, Required)**: Choose the number of credits associated with the class.
* **Class Level (`class_level`, Select One, Required)**: Select the difficulty level of the class (Introductory, Intermediate, Advanced, Graduate level, All levels welcome).
* **Prerequisites (`prerequisites`, Text, Optional)**: List any required prior knowledge or classes.
* **Class Format (`class_format`, Select One, Required)**: Choose how the class is delivered (In-person lecture, Online synchronous, Online asynchronous, Hybrid or blended, Lab-based, Seminar or discussion).
* **Class Schedule (`class_schedule`, Select Multiple, Required)**: Select the days and time slots when the class is offered.
* **Class Duration (`class_duration`, Select One, Required)**: Choose the length of each session.
* **Total Weeks (`total_weeks`, Select One, Required)**: Select the total number of weeks the class will last.
* **Maximum Class Size (`class_size`, Select One, Required)**: Choose the maximum number of students allowed in the class.
* **Assessment Methods (`assessment_methods`, Select Multiple, Required)**: Select how students are evaluated (Exams, Quizzes, Projects, Papers or essays, Presentations, Participation, Lab work, Portfolio).
* **Required Materials (`materials_required`, Text, Optional)**: List any textbooks, supplies, etc. required for the class.
* **Technology Requirements (`technology_requirements`, Text, Optional)**: List any computer, software, or other technology requirements for the class.
* **Special Features (`special_features`, Select Multiple, Optional)**: Select any unique aspects of the class (Guest speakers, Field trips, Hands-on projects, Industry partnerships, Research opportunities, Internship component, Study abroad option, Certification included).
* **Career Relevance (`career_relevance`, Text, Optional)**: Describe how this class helps with career development.
* **Student Testimonials (`student_testimonials`, Text, Optional)**: Provide quotes from past students.
* **Additional Information (`additional_information`, Text, Optional)**: Add any other relevant details about the class.
