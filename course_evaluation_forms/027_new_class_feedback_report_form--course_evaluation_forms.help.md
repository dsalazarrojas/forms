# New Class Feedback Report Form - Help Guide
## Purpose
The New Class Feedback Report Form is used to gather feedback from students on their experience in a class. It helps the institution to evaluate the quality and effectiveness of the class in meeting the needs of students.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the Class ID of the class you are providing feedback on.
2. Enter the Class Name of the class you are providing feedback on.
3. Enter the Instructor ID of the instructor who taught the class.
4. Enter the Instructor Name of the instructor who taught the class.
5. Enter the Student ID of the student who took the class.
6. Enter the Student Name of the student who took the class.
7. Enter the Feedback Date of when you took the class.
8. Select a value for the Evaluation Scale.
9. Enter any additional Comments about your experience.
10. Select a value for the Course Feedback.
11. Select a value for the Communication.
12. Select a value for the Organization.
13. Select a value for the Relevance.
14. Select a value for the Overall Satisfaction.
15. Select a value for the Instructor Performance.
16. Select a value for the Material.
17. Enter any additional Feedback.
18. Enter the Class Time of the class.
19. Enter the Class Location of the class.
20. Enter the Class Length of the class.
21. Select a value for the Class Attendance.
22. Select values for the Class Evaluations.
23. Enter any additional Class Comments.
24. Enter any Student Comments.
25. Enter any Additional Comments.

## Field-by-Field Explanation

* **Class ID (1)**: Enter the ID of the class you are providing feedback on.
* **Class Name (2)**: Enter the name of the class you are providing feedback on.
* **Instructor ID (3)**: Enter the ID of the instructor who taught the class.
* **Instructor Name (4)**: Enter the name of the instructor who taught the class.
* **Student ID (5)**: Enter the ID of the student who took the class.
* **Student Name (6)**: Enter the name of the student who took the class.
* **Feedback Date (7)**: Enter the date when you took the class.
* **Evaluation Scale (8)**: Select a value for the evaluation scale. This scale helps us to measure your overall satisfaction with the class.
* **Comments (9)**: Enter any additional comments about your experience.
* **Course Feedback (10)**: Select a value for the course feedback. This scale helps us to measure your overall satisfaction with the course.
* **Communication (11)**: Select a value for the communication. This scale helps us to measure how well the instructor communicated with you.
* **Organization (12)**: Select a value for the organization. This scale helps us to measure how well the class was organized.
* **Relevance (13)**: Select a value for the relevance. This scale helps us to measure how relevant the class was to your needs.
* **Overall Satisfaction (14)**: Select a value for the overall satisfaction. This scale helps us to measure your overall satisfaction with the class.
* **Instructor Performance (15)**: Select a value for the instructor performance. This scale helps us to measure how well the instructor performed.
* **Material (16)**: Select a value for the material. This scale helps us to measure how well the class material was covered.
* **Feedback (17)**: Enter any additional feedback about your experience.
* **Class Time (18)**: Enter the time of the class.
* **Class Location (19)**: Enter the location of the class.
* **Class Length (20)**: Enter the length of the class.
* **Class Attendance (21)**: Select a value for the class attendance. This scale helps us to measure how well the class was attended.
* **Class Evaluations (22)**: Select values for the class evaluations. This scale helps us to measure how well the class was evaluated.
* **Class Comments (23)**: Enter any additional comments about the class.
* **Student Comments (24)**: Enter any comments from other students.
* **Additional Comments (25)**: Enter any additional comments about your experience.

## Tips
* Please ensure that you have not already completed this form before.
* If you are unsure, you can check with the instructor or administration to see if the form has been completed before.
* Please be honest and provide detailed feedback to help us improve our classes.
