# MultiPage Course Evaluation Form - Help Guide
## Purpose
The MultiPage Course Evaluation Form is designed to collect feedback and evaluations from course participants on a multi-page format. This form will help instructors, administrators, and other stakeholders assess the effectiveness of the course and identify areas for improvement.

## How To Complete This Form

1. Please complete all the required pages (pages 2, 3, and 4). You can skip page 1 if it's not required.
2. For each page, provide clear and concise answers to the questions and prompts.
3. Make sure to answer all the questions truthfully and accurately.

## Field-by-Field Explanation

* **Course Title** (`page_1`, `number`, required: false)
	+ Please provide the title of the course you're evaluating.
* **Page 1** (`page_2`, `number`, required: false)
	+ Please select the page number you're currently on.
* **Page 2** (`page_3`, `number`, required: false)
	+ Please select the page number you're currently on.
* **Page 3** (`page_4`, `number`, required: false)
	+ Please select the page number you're currently on.

## Tips

* Make sure to answer all the questions truthfully and accurately.
* If you have any questions or concerns about the form, please contact the course administrator.
* Please complete the form in a quiet and comfortable environment to ensure accurate answers.
