# Grady Evaluation Form Template - Help Guide
## Purpose
This form is designed to collect course evaluation information for the purpose of assessing the quality of courses.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field accurately and thoroughly.
2. Make sure to provide the required information for each field.

## Field-by-Field Explanation
### 1. **Course Name** (`course_name`, text, optional)
Enter the name of the course you are evaluating.

### 2. **Evaluation Date** (`evaluation_date`, date, optional)
Provide the date of the evaluation.

### 3. **Course Level** (`course_level`, select one, optional)
Select the level of the course using the following options: 1, 2, 3, 4, 5.

### 4. **Course Instructor** (`course_instructor`, text, optional)
Enter the name of the course instructor.

### 5. **Comments** (`comments`, text, optional)
Provide any additional comments or feedback about the course.

## Tips
- Make sure to fill out each field accurately and thoroughly.
- If you are unsure about any field, please refer to the form purpose and instructions above.
- Review your answers before submitting the form to ensure accuracy and completeness.
