# Gameplay Recording Upload Form - Help Guide

## Purpose
This form is used for submitting gameplay recordings for contests. It requires specific details about the recording, including its video URL, description, and file name. The form also asks for the ID of the game and file being uploaded, as well as the upload server and port used to access the file. All required fields must be filled out in order to successfully submit the form.

## How To Complete This Form

1. Ensure you have all required information and files ready before proceeding.
2. Fill out the **Title** and **Description** fields with the relevant details about your submission.
3. Enter the **Video ID**, which can be obtained from the video URL.
4. Upload the file by clicking on the **Upload File** button and selecting the relevant file.
5. Ensure that the **File Name**, **Video ID**, and **Upload URL** fields are filled out correctly to ensure accurate submission.
6. If you are uploading from a specific server, fill out the **Server**, **Port**, and **Upload Server** fields with the correct information.
7. Fill out the **Username** and **Password** fields with the credentials required to access the file on the upload server.
8. Add any additional notes about your submission in the **Notes** field, if desired.
9. Once all fields are filled out, click the submit button to complete the form.

## Field-by-Field Explanation

* **Contest Entry Form**: This field is not a field that requires input, but rather a form header.
* **Video URL**: Enter the URL of the video being uploaded.
* **Title**: Enter a brief title for your submission.
* **Description**: Enter a detailed description of your submission.
* **Upload File**: Upload the file containing the gameplay recording.
* **Tags**: Select any relevant tags for your submission.
* **Categories**: Select any relevant categories for your submission.
* **Date/Time**: Enter the date and time the gameplay recording was taken.
* **File Type**: Select the type of file being uploaded.
* **File Size**: Enter the size of the file being uploaded.
* **Author**: Enter your name or username.
* **Game Title**: Enter the title of the game being uploaded.
* **Game Version**: Enter the version of the game being uploaded.
* **Game System**: Enter the system or platform the game was played on.
* **Game Type**: Enter the type of game being uploaded.
* **Game ID**: Enter the ID of the game being uploaded.
* **File Name**: Enter the name of the file being uploaded.
* **Video ID**: Enter the ID of the video being uploaded.
* **Upload URL**: Enter the URL to upload the file to.
* **Server**: Enter the server hosting the file.
* **Port**: Enter the port used to access the file.
* **Username**: Enter the username required to access the file on the upload server.
* **Password**: Enter the password required to access the file on the upload server.
* **Upload Server**: Enter the server used to upload the file.
* **Notes**: Add any additional notes about your submission.
