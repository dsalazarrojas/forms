## Purpose
This form is designed to allow users to submit fitness memes for approval and publication on a platform. The form collects information about the meme's title, description, image, and creator's contact details. 

To prevent duplication, the system checks if a user has already submitted a meme with the same name. If a user has submitted a meme with the same name, they will be alerted and won't be able to submit it again. 

Only users with proper access rights can submit and manage submissions. 

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the Meme Name field with the title of the meme.
2. Enter the Meme Description in the Description field.
3. Upload the Meme Image (if required).
4. Enter the Meme URL (if the image is hosted elsewhere).
5. Fill in the Creator Name and Creator Email fields with the name and contact information of the meme's creator.
6. Enter the Creator Phone number.
7. Submit the form.

## Field-by-Field Explanation
### User Input (Text)
* **User Input** (`user_input`, text, optional): This field is reserved for any additional information or comments from the user. It's not required but can be useful for providing context or extra details about the meme.

### Meme Name (Text)
* **Meme Name** (`meme_name`, text, optional): Enter a unique and descriptive title for the meme.

### Meme Description (Text)
* **Meme Description** (`meme_description`, text, optional): Provide a brief description of the meme to help explain its meaning and context.

### Meme Image (Text)
* **Meme Image** (`meme_image`, text, optional): Upload an image of the meme or provide the URL where it's hosted. If you're uploading, make sure it's a valid image file type.

### Meme URL (Text)
* **Meme URL** (`meme_url`, text, optional): If the meme image is hosted elsewhere, enter the URL where it's located.

### Creator Name (Text)
* **Creator Name** (`creator_name`, text, optional): Enter the name of the meme's creator.

### Creator Email (Text)
* **Creator Email** (`creator_email`, text, optional): Enter the email address of the meme's creator. This will be used for communication and verification purposes.

### Creator Phone (Text)
* **Creator Phone** (`creator_phone`, text, optional): Enter the phone number of the meme's creator. This will be used for communication and verification purposes.

The form is designed to ensure that only valid and non-duplicate submissions are allowed, making it a user-friendly and organized platform for submitting and managing fitness memes.
