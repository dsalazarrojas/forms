# Song Relay Competition Results - Help Guide
## Purpose
The Song Relay Competition Results form is used to capture the results of a song relay competition, including judges' scores, rankings, and comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Song Title
	* Song Name
	* Artist Name
	* Judge Name
	* Judge Score
	* Song Name 2 (if applicable)
	* Judge Name 2 (if applicable)
	* Song Name 2 (if applicable)
	* Submitter
	* Judge Name 2 (if applicable)
2. Provide any additional information in the optional fields:
	* Artist Name 2
	* Judge Comments
	* Judge Rank
	* Judge Notes
	* Submitter Notes 2
3. Select the correct options for:
	* Ranking 2
	* Judge Rank
	* Song Relay Competition Results Score
4. Enter the submission date and time in the format YYYY-MM-DD HH:MM:SS.

## Field-by-Field Explanation

* **Song Title** (`title`, `text`, required): Enter the title of the song.
* **Artist Name** (`artist_name`, `text`, required): Enter the name of the artist.
* **Judge Name** (`judges_name`, `text`, required): Enter the name of the judge.
* **Score** (`judge_score`, `number`, required): Enter the score given by the judge.
* **Ranking 2** (`ranking_2`, `select_one`, required): Select 'Yes' or 'No' to indicate whether this entry meets the criteria.
* **Judges Name 2** (`judge_name_2`, `text`, required): Enter the name of the second judge.
* **Song Name** (`song_name`, `text`, required): Enter the name of the song.
* **Submission Date** (`submission_date`, `date`, required): Enter the date and time of submission in the format YYYY-MM-DD HH:MM:SS.
* **Song Name 2** (`song_name_2`, `text`, optional): If applicable, enter the name of a second song.
* **Artist 2** (`artist_name_2`, `text`, optional): If applicable, enter the name of a second artist.
* **Judge Name 3** (`judge_name`, `text`, optional): If applicable, enter the name of the third judge.
* **Judge Rank** (`song_relay_competition_results_judge_rank`, `select_multiple`, optional): Select 'Yes' or 'No' to indicate whether this entry meets the criteria.
* **Song Relay Competition Results Score** (`song_relay_competition_results_score`, `select_one`, optional): Select 'Yes' or 'No' to indicate whether this entry meets the criteria.
* **Judge Comments** (`song_relay_competition_results_judge_comments`, `text`, optional): Enter any additional comments from the judge.
* **Judge Notes** (`song_relay_competition_results_judge_notes`, `text`, optional): Enter any additional notes from the judge.
* **Judge Rank 2** (`song_relay_competition_results_judge_rank`, `select_multiple`, optional): Select 'Yes' or 'No' to indicate whether this entry meets the criteria.
* **Submission Notes** (`submission_notes`, `text`, optional): Enter any additional notes about the submission.
* **Submission Date 2** (`submission_date_2`, `date`, optional): If applicable, enter the date and time of a second submission.
* **Submitted By** (`song_relay_competition_results_submitted_by`, `text`, optional): If applicable, enter the name of the person who submitted.
* **Judge Name 2** (`judge_name_2`, `text`, optional): If applicable, enter the name of the second judge.
* **Judge Comments 2** (`song_relay_competition_results_judge_comments_2`, `text`, optional): Enter any additional comments from the second judge.
* **Judge Rank 2** (`song_relay_competition_results_judge_rank_2`, `select_multiple`, optional): Select 'Yes' or 'No' to indicate whether this entry meets the criteria.
