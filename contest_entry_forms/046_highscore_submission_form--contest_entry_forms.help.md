# Highscore Submission Form - Help Guide
## Purpose
The purpose of this form is to gather highscore submission information for a specific game. Users are required to provide accurate and complete data to ensure the submission's integrity and authenticity.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the highscore submissions option.
2. Provide the proof URL (if applicable) to prevent duplicate submissions.
3. Enter the username of the player who achieved the highscore.
4. Select the game version associated with the highscore.
5. Enter the highscore score.
6. Enter the ranking of the highscore.
7. Provide a brief description of the proof upload (if applicable).
8. Choose the proof upload type (if applicable).
9. Select the proof upload format (if applicable).
10. Enter the proof upload size (if applicable).
11. Choose the proof upload size type (if applicable).
12. Enter the proof upload date and time (if applicable).
13. Enter any additional proof upload description (if applicable).
14. Enter any submitter notes (if applicable).
15. Agree to the submitter agreement.

## Field-by-Field Explanation

* **Highscore Submissions** (Select Multiple):
	+ Select the option that indicates whether the submission is highscore or not.
* **Proof URL** (Text):
	+ Enter the URL of the proof that verifies the highscore submission (if applicable).
* **Username** (Select One):
	+ Enter the name of the player who achieved the highscore.
	+ This field is required to ensure the authenticity of the highscore submission.
* **Game Name** (Text):
	+ Enter the name of the game associated with the highscore.
* **Game Version** (Select One):
	+ Select the version of the game associated with the highscore.
* **Score** (Number):
	+ Enter the highscore score.
* **Ranking** (Number):
	+ Enter the ranking of the highscore.
* **Leaderboard Proof** (Text):
	+ Provide a brief description of the proof that verifies the highscore submission (if applicable).
* **Proof Upload Description** (Text):
	+ Enter any additional description of the proof upload (if applicable).
* **Proof URL** (Text):
	+ Enter the URL of the proof that verifies the highscore submission (if applicable).
* **Game Platform** (Text):
	+ Enter the platform on which the game was played.
* **Submitter** (Select One):
	+ Select the option that indicates whether the submitter is the highscore achiever or not.
* **Submitter Email** (Email):
	+ Enter the email address of the submitter.
* **Submitter Phone** (Text):
	+ Enter the phone number of the submitter.
* **Submitter Location** (Text):
	+ Enter the location of the submitter.
* **Proof Upload Type** (Select One):
	+ Choose the type of proof upload (if applicable).
* **Proof Upload Format** (Select One):
	+ Select the format of the proof upload (if applicable).
* **Proof Upload Size** (Number):
	+ Enter the size of the proof upload (if applicable).
* **Proof Upload Size Type** (Select One):
	+ Choose the type of proof upload size (if applicable).
* **Proof Upload Date** (Date):
	+ Enter the date of the proof upload (if applicable).
* **Proof Upload Time** (Time):
	+ Enter the time of the proof upload (if applicable).
* **Submitter Notes** (Text):
	+ Enter any additional notes from the submitter (if applicable).
* **Submitter Agreement** (Select One):
	+ Agree to the terms of submission.
