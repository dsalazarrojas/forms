# tailoring_contest_entry_form - Help Guide

## Purpose
The "tailoring_contest_entry_form" is a form used to collect information from users for a tailoring contest. It is used to gather details about the garment type, fabric type, pattern type, size, color, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to start the form.
2. Fill out each field with the required and optional information.
3. Select the appropriate options from the select_one and select_multiple fields.
4. Enter any additional notes or comments in the "Notes" field.
5. Submit the form when complete.

## Field-by-Field Explanation
### User Input (`User Input`, text, optional): 
Enter any additional information you would like to provide about yourself.

### Garment Type (`Garment Type`, select_one, optional): 
Select the type of garment you are entering into the contest, such as Garment 1, Garment 2, or Garment 3.

### Fabric Type (`Fabric Type`, select_one, optional): 
Select the type of fabric you are using for the garment, such as Fabric 1, Fabric 2, or Fabric 3.

### Pattern Type (`Pattern Type`, select_multiple, optional): 
Select multiple pattern types for the garment, such as Option 1, Option 2, or Option 3.

### Size (`Size`, number, optional): 
Enter the size of the garment in numerical form.

### Color (`Color`, select_one, optional): 
Select the color of the garment, such as Black, White, or Blue.

### Measurement (`Measurement`, number, optional): 
Enter the measurement of the garment in numerical form.

### Notes (`Notes`, text, optional): 
Enter any additional notes or comments about the garment.

### Email (`Email`, email, optional): 
Enter your email address.

### Phone (`Phone`, text, optional): 
Enter your phone number.

### Date (`Date`, date, optional): 
Enter the date in the format MM/DD/YYYY.

### Time (`Time`, time, optional): 
Enter the time in the format 12:00 AM - 11:59 PM.

### Assigned To (`Assigned To`, select_one, optional): 
Select the user assigned to the garment, such as User 1, User 2, or User 3.

### Assigned By (`Assigned By`, select_one, optional): 
Select the user who assigned the garment, such as User 1, User 2, or User 3.

### Created At (`Created At`, date, optional): 
The date and time the garment was created.

### Updated At (`Updated At`, date, optional): 
The date and time the garment was last updated.

### Created By (`Created By`, select_one, optional): 
Select the user who created the garment, such as User 1, User 2, or User 3.

### Updated By (`Updated By`, select_one, optional): 
Select the user who last updated the garment, such as User 1, User 2, or User 3.

### Deleted At (`Deleted At`, date, optional): 
The date and time the garment was deleted.

### Deleted By (`Deleted By`, select_one, optional): 
Select the user who deleted the garment, such as User 1, User 2, or User 3.

### deleted_at (`deleted_at`, date, optional): 
This field is not used.

### Category (`Category`, select_one, optional): 
Select the category of the garment, such as Cat 1, Cat 2, or Cat 3.

### Subcategory (`Subcategory`, select_one, optional): 
Select the subcategory of the garment, such as Subcat 1, Subcat 2, or Subcat 3.

### Tags (`Tags`, select_multiple, optional): 
Select multiple tags for the garment, such as Tag 1, Tag 2, or Tag 3.

### Description (`Description`, text, optional): 
Enter a description of the garment.

## Tips
* Make sure to fill out all required fields.
* Select the appropriate options for each select fields.
* Enter accurate and complete information in the text fields.
* Use the correct format for date and time fields.
* Review your information before submitting the form.
