# halloween_dinner_table_contest_entry_form - Help Guide
## Purpose
This form is used to collect information about a user's Halloween dinner table creation. Users are encouraged to submit their own unique and creative dinner table ideas, including their name, contact information, and a description of their project.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your name in the "Name" field.
2. Enter your email address in the "email" field.
3. Provide your phone number in the "phone" field.
4. Enter the date you plan to submit your dinner table creation.
5. Choose a time for your project.
6. If desired, provide a description of your project in the "description" field.
7. If desired, mention who is assigned to for this project in the "assigned_to" field.
8. If desired, mention a tool used for this project in the "assigned_tool" field.
9. If desired, mention who submitted this project in the "submitted_by" field.
10. If desired, select a date for when this project was submitted.
11. If desired, enter the email of who submitted this project in the "submitted_by_email" field.
12. If desired, select an ID assigned to this project in the "assigned_id" field.

## Field-by-Field Explanation

* **Name (text, required)**: Enter your name to be associated with your Halloween dinner table creation.
* **email (email, required)**: Enter your email address so we can contact you about your project.
* **phone (text, required)**: Enter your phone number in case we need to contact you.
* **date (date, required)**: Enter the date you plan to submit your project.
* **time (time, required)**: Choose a time for your project.
* **description (text, optional)**: Provide a description of your project if you want to share more details.
* **assigned_to (text, optional)**: If this project is assigned to someone else, enter their name.
* **assigned_tool (text, optional)**: If a tool was used for this project, enter its name.
* **submitted_by (text, optional)**: If someone else submitted this project, enter their name.
* **submitted_on (date, optional)**: If this project was submitted at a specific date, enter it.
* **submitted_by_email (email, optional)**: If this project was submitted by someone with an email address, enter it.
* **assigned_id (number, optional)**: If this project has an ID assigned to it, enter it.

## Tips
Please ensure you provide accurate and up-to-date information about your project. This will help us in reviewing and featuring your project.
