# radio_jingle_tournament_entry_form - Help Guide
## Purpose
The radio jingle tournament entry form is designed for users to submit their entries for a radio jingle competition. The form collects metadata about the submission, such as category, description, and other contest-specific details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for your jingle entry.
2. Select the category your jingle entry belongs to.
3. Briefly describe your jingle entry.
4. If necessary, mark if this is a required entry form.
5. Enter your email address.
6. Enter your phone number (optional).
7. Upload an output file (if applicable).
8. Select the tool assigned to your jingle entry (if applicable).
9. Enter a name for the output file (if applicable).
10. Enter the name of the person who created the jingle entry.

## Field-by-Field Explanation
* **Radio Jingle Title** (text, required: false): Enter a title for your jingle entry.
* **Category** (select_one, required: false): Select the category your jingle entry belongs to. Options include:
	+ Contest Entry Forms
	+ Other
* **Description** (text, required: false): Briefly describe your jingle entry.
* **Is this a required entry form?** (select_one, required: false): If this is a required entry form, select 'True', otherwise select 'False'.
* **Email** (email, required: false): Enter your email address.
* **Phone** (text, required: false): Enter your phone number (optional).
* **Output File** (text, required: false): Upload an output file (if applicable).
* **Assigned Tool** (select_one, required: false): Select the tool assigned to your jingle entry. Options include:
	+ chatjimmy
	+ Other
* **Output File Name** (text, required: false): Enter a name for the output file (if applicable).
* **Created By** (text, required: false): Enter the name of the person who created the jingle entry.
