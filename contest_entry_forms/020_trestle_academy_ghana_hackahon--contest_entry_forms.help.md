# trestle-academy-ghana-hackahon-contest-entry-form - Help Guide

## Purpose
This form is for contest entries submitted to Trestle Academy Ghana Hackahon. Please ensure your entries are accurate and complete to increase your chances of success. Duplicate entries will be automatically rejected.

## How To Complete This Form
To complete this form, fill out the required fields and ensure your entry is submitted before the deadline. The form is self-explanatory, so you can navigate it page by page to provide your information.

## Field-by-Field Explanation

* **First and Last Name (General Info 1)** (`First and Last Name`, text, required): Enter your first and last name for identification purposes.
* **Email (General Info 2)** (`Email`, email, required): Enter your email address for communication purposes. Make sure it is a valid email address.
* **Project Name (General Info 3)** (`Project Name`, text, optional): Provide a name for your project if you like.
* **Team Name (General Info 4)** (`Team Name`, text, optional): If you are working with a team, enter their name.
* **GitHub Link (General Info 5)** (`GitHub Link`, text, required): Paste your GitHub link to prove ownership of the project.
* **Project Description (General Info 6)** (`Project Description`, text, required): Describe your project in a few sentences.
* **Category (General Info 7)** (`Category`, text, optional): Choose a category that best fits your project.
* **Submission URL (General Info 8)** (`Submission URL`, text, required): Provide the URL of your submission.
* **Submission Date (General Info 9)** (`Submission Date`, date, optional): If applicable, enter the date of your submission.
* **Submission Time (General Info 10)** (`Submission Time`, time, optional): If applicable, enter the time of your submission.
* **Submission Duration (General Info 11)** (`Submission Duration`, number, optional): If applicable, enter the duration of your submission.
* **Submission Location (General Info 12)** (`Submission Location`, text, optional): If applicable, enter the location of your submission.

## Tips
* Please ensure your email address is valid and up-to-date.
* Double-check your GitHub link to ensure it points to your actual project.
* Be as specific as possible with your project description and submission details. This will increase the chances of your entry being considered.
* Ensure all required fields are filled out correctly.
* Do not submit duplicate entries. This will result in automatic rejection.
* Check your form for any errors before submission.
