# Senior Superlatives Form - Help Guide
## Purpose
The Senior Superlatives Form is designed to collect votes for outstanding seniors who have made significant contributions to their school or institution. This form is used to gather input from various stakeholders to identify and honor exceptional seniors.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a superlative from the list of options provided in the "Select a superlative" field.
2. Enter the first name of the person you are voting for in the "first name" field.
3. Enter the last name of the person you are voting for in the "last name" field.
4. Enter the email address of the person you are voting for in the "email" field.
5. Indicate whether you vote for the first name ("Yes" or "No") in the "vote for first name" field.
6. Indicate whether you vote for the last name ("Yes" or "No") in the "vote for last name" field.
7. Enter your vote submission in the "Submit votes" field.
8. Select "Yes" or "No" for the first name in the "vote for first name 1" field.

## Field-by-Field Explanation
* **Select a superlative**: 
    * (id: 1, label: Select a superlative, type: select_multiple)
        + This field allows you to select one or multiple superlatives from the provided options. The options are "Yes" and "No". You can select one or both options.
* **first name**: 
    * (id: 2, label: first name, type: text)
        + Enter the first name of the person you are voting for.
* **last name**: 
    * (id: 3, label: last name, type: text)
        + Enter the last name of the person you are voting for.
* **email**: 
    * (id: 4, label: email, type: email)
        + Enter the email address of the person you are voting for. Please ensure the email format is correct and active.
* **vote for first name**: 
    * (id: 5, label: vote for first name, type: select_one)
        + Indicate whether you vote for the first name ("Yes" or "No").
* **vote for last name**: 
    * (id: 6, label: vote for last name, type: select_one)
        + Indicate whether you vote for the last name ("Yes" or "No").
* **Submit votes**: 
    * (id: 7, label: Submit votes, type: text)
        + Enter any additional comments or reasons for your vote submission.
* **vote for first name 1**: 
    * (id: 8, label: vote for first name 1, type: select_one)
        + Select "Yes" or "No" for this field as well. 

## Tips
* Make sure to select a superlative that aligns with the person you are voting for.
* Enter accurate information for the first name, last name, and email fields.
* Be honest when indicating your vote for first name and last name.
