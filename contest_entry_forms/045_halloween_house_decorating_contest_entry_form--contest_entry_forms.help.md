# Halloween House Decorating Contest Entry Form - Help Guide
## Purpose
The Halloween House Decorating Contest Entry Form is designed for users to submit their house decoration information for a Halloween-themed contest. Users will be able to showcase their house's decorations by providing details like address, decoration types, and the entry's details.

## How To Complete This Form
1. Fill in the required fields, if any.
2. Choose the correct options for address, city, and state.
3. Select the types of decorations used in your house.
4. Upload any necessary images or provide a link to them.
5. Fill out the entry's details, including submitter information.
6. Review and submit the form.

## Field-by-Field Explanation
* **House Address** (`house_address`): This is where your house is located, and it's the address of your house that you'd like to submit for the contest.
* **House Name** (`house_name`): This is the name of your house, which can be as simple or as creative as you'd like.
* **House Number** (`house_number`): This is the house number or address number of your house.
* **City** (`city`): This is where your house is located, select from the options: New York, Los Angeles, Chicago, Dallas.
* **State** (`state`): This is the state where your house is located, select from the options: CA, TX, IL, NY.
* **Zip** (`zip`): This is the zip code of your house.
* **Phone** (`phone`): This is the phone number where you can be reached.
* **Email** (`email`): This is the email address where you can be reached.
* **Contest Entry Type** (`contest_entry_type`): Select the type of entry this is, yard, front door, front porch, back door, back porch.
* **House Decorating Type** (`house_decorating_type`): Select the type of decorations used in your house, spider web, jack o' lantern, ghost, skeleton, graveyard, other.
* **Description** (`house_description`): This is a brief description of the decoration and why you're entering the contest.
* **Image** (`house_image`): This is where you can upload an image of your house's decoration.
* **Entry Rules** (`entry_rules`): This is where you can agree to the contest's entry rules.
* **Entry Terms** (`entry_terms`): This is where you can agree to the contest's terms and conditions.
* **Entry Date** (`entry_date`): This is the date when you're submitting this entry.
* **Entry Time** (`entry_time`): This is the time when you're submitting this entry.
* **Entry Submitter** (`entry_submitter`): This is who's submitting this entry, owner, resident, friend, family.
* **Entry Submitter Role** (`entry_submitter_role`): This is the role of the person submitting this entry, homeowner, resident, family member.
* **Entry Submitter Phone** (`entry_submitter_phone`): This is the phone number of the person submitting this entry.
* **Entry Submitter Email** (`entry_submitter_email`): This is the email address of the person submitting this entry.
* **Entry Submitter Address** (`entry_submitter_address`): This is the address of the person submitting this entry.
* **Entry Submitter City** (`entry_submitter_city`): This is the city of the person submitting this entry.
* **Entry Submitter State** (`entry_submitter_state`): This is the state of the person submitting this entry.
* **Entry Submitter Zip** (`entry_submitter_zip`): This is the zip code of the person submitting this entry.
* **Entry Submitter Image** (`entry_submitter_image`): This is where you can upload an image of the person submitting this entry.
