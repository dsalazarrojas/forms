# hedging_match_entry_form - Help Guide
## Purpose
This form is used to capture details about a hedging match, including the type of hedging, underlying asset, match timing, risk level, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of hedging from the "hedge_type" field.
2. Choose whether the underlying asset is "Yes" or "No" in the "underlying_asset" field.
3. Select the match timing from the "match_timing" field.
4. Choose the risk level from the "risk_level" field.
5. Enter the entry name in the "entry_name" field.
6. Select the type of entry from the "entry_type" field.
7. Enter the asset allocation in the "asset_allocation" field.
8. Enter the entry date in the "entry_date" field.
9. Enter the entry time in the "entry_time" field.
10. Select the entry status from the "entry_status" field.
11. Enter the match ID in the "match_id" field.
12. Enter the user ID in the "user_id" field.
13. Enter the created at date in the "created_at" field.
14. Enter the updated at date in the "updated_at" field.
15. Enter the entry ID in the "entry_id" field.
16. Enter the entry notes in the "entry_notes" field.
17. Enter the asset ID in the "asset_id" field.
18. Enter the asset value in the "asset_value" field.
19. Enter the match duration in the "match_duration" field.
20. Enter the entry fee in the "entry_fee" field.
21. Enter the entry type ID in the "entry_type_id" field.
22. Enter the asset type ID in the "asset_type_id" field.
23. Enter the risk level ID in the "risk_level_id" field.
24. Enter the entry status ID in the "entry_status_id" field.
25. Enter the user name in the "user_name" field.

## Field-by-Field Explanation

* **hedge_type**: The type of hedging (e.g., type 1, type 2, etc.). This field is required.
* **underlying_asset**: Whether the underlying asset is Yes or No. This field is optional.
* **match_timing**: The timing of the match (e.g., time 1, time 2, etc.). This field is optional.
* **risk_level**: The risk level of the match (e.g., risk 1, risk 2, etc.). This field is optional.
* **entry_name**: The name of the entry. This field is optional.
* **entry_type**: The type of entry (e.g., entry type 1, entry type 2, etc.). This field is optional.
* **asset_allocation**: The allocation of assets for the entry. This field is optional.
* **entry_date**: The date of the entry. This field is optional.
* **entry_time**: The time of the entry. This field is optional.
* **entry_status**: The status of the entry (e.g., status 1, status 2, etc.). This field is optional.
* **match_id**: The ID of the match. This field is optional.
* **user_id**: The ID of the user. This field is optional.
* **created_at**: The date the entry was created. This field is optional.
* **updated_at**: The last time the entry was updated. This field is optional.
* **entry_id**: The ID of the entry. This field is optional.
* **entry_notes**: Notes about the entry. This field is optional.
* **asset_id**: The ID of the asset. This field is optional.
* **asset_value**: The value of the asset. This field is optional.
* **match_duration**: The duration of the match. This field is optional.
* **entry_fee**: The fee for the entry. This field is optional.
* **entry_type_id**: The ID of the entry type. This field is optional.
* **asset_type_id**: The ID of the asset type. This field is optional.
* **risk_level_id**: The ID of the risk level. This field is optional.
* **entry_status_id**: The ID of the entry status. This field is optional.
* **user_name**: The name of the user who made the entry. This field is optional.
