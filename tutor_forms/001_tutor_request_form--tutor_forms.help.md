# Tutor Request Form - Help Guide
## Purpose
This form is designed to be completed by students seeking tutoring services. It provides a structured way for students to request help from a tutor, specifying the subject, date, and other relevant details.

## How To Complete This Form
1. Fill out each field with the required information.
2. Enter a brief description of your request in the "Request Details" field.
3. Choose the subjects you need help with.
4. Select a preferred date and time for your tutoring session.
5. Enter your email address (not required but recommended for communication).
6. Optional: enter your phone number for easier communication.
7. Specify your location (optional).
8. Choose a preferred tool for the tutoring session (e.g., chat or other).
9. Add any additional notes or comments in the "Notes" field (optional).

## Field-by-Field Explanation

* **Student Name**: Enter your name as it appears on your identification documents.
* **Request Details**: Briefly describe the areas you need help with or the topics you need clarification on.
* **Request Date**: Choose the date and time you would like to have your tutoring session.
* **Tutor Subjects**: Select all the subjects you would like the tutor to focus on. You can choose multiple subjects by holding the "Shift" key while selecting.
* **Email**: Enter your email address so the tutor can contact you for more information or to confirm the session details.
* **Phone**: Enter your phone number if you would like to be contacted by the tutor via phone.
* **Location**: Specify the location where you would like to have the tutoring session (e.g., on-campus, off-campus, online).
* **Assigned Tool**: Choose the tool you would like to use for the tutoring session (e.g., chat, other).
* **Notes**: Add any additional comments or questions you have about the tutoring session.
