# Peer Tutoring Program Impact Assessment - Help Guide
## Purpose
The Peer Tutoring Program Impact Assessment is a form used to collect data on the impact of the peer tutoring program on students. This data will help administrators and instructors to evaluate the effectiveness and efficiency of the program.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Answer each question carefully and honestly, providing as much detail as possible.
2. Make sure to select the most accurate options from the drop-down menus.
3. If a question does not apply, please select "N/A" (Not Applicable) as the answer.

## Field-by-Field Explanation

* **What is the purpose of the peer tutoring program?** (`program_purpose`): This question asks for a brief description of the program's purpose. Please provide a clear and concise answer in the text field.
* **How often do you meet with students for peer tutoring?** (`meeting_frequency`): This question asks for the frequency of meetings between the tutor and students. Please select one of the following options: 
  * Daily
  * Weekly
  * Monthly
  * Bi-Monthly
* **What is the average number of students per session?** (`session_duration`): This question asks for the number of students typically involved in each session. Please enter a number.
* **Select the primary goal of the peer tutoring program** (`primary_goal`): This question asks for the main objective of the program. Please select one of the following options:
  * Improve academic performance
  * Enhance social skills
  * Increase student engagement
* **Select the secondary goals of the peer tutoring program** (`secondary_goals`): This question asks for additional objectives of the program. Please select all applicable options from the list.
* **What is the average time per session?** (`session_time`): This question asks for the duration of each session. Please enter a time in the format HH:MM.
* **What is the primary method of communication with students?** (`communication_methods`): This question asks for the main method of communication with students. Please select all applicable options from the list.
* **What is the method of data collection for the peer tutoring program?** (`data_collection`): This question asks for the method of collecting data on the program. Please select all applicable options from the list.
* **How often do staff members meet with students?** (`meeting_frequency_staff`): This question asks for the frequency of meetings between staff members and students. Please select all applicable options from the list.
* **What is the average number of students in each group?** (`student_group_size`): This question asks for the average number of students in each group. Please enter a number.
* **How often do staff members meet with each other?** (`staff_meeting_frequency`): This question asks for the frequency of meetings between staff members. Please select all applicable options from the list.
* **What is the average time of day for staff meetings?** (`staff_meeting_time`): This question asks for the time of day for staff meetings. Please enter a time in the format HH:MM.
* **How often do students meet with each other?** (`student_meeting_frequency`): This question asks for the frequency of meetings between students. Please select all applicable options from the list.
* **What is the primary method of communication with staff members?** (`communication_staff`): This question asks for the main method of communication with staff members. Please select all applicable options from the list.
* **What is the average time of day for sessions?** (`session_time_2`): This question asks for the time of day for sessions. Please enter a time in the format HH:MM.
* **What is the method of data collection for staff members?** (`data_collection_staff`): This question asks for the method of collecting data on staff members. Please select all applicable options from the list.
* **Staff Meeting Frequency 2** (`staff_meeting_frequency_2`): This question asks for the frequency of meetings between staff members. Please select all applicable options from the list.
* **How often do students meet with staff members?** (`student_meeting_frequency_staff`): This question asks for the frequency of meetings between students and staff members. Please select all applicable options from the list.
* **Group Size** (`group_size`): This question asks for the average number of students in each group. Please enter a number.
* **What is the average time of day for staff-student meetings?** (`meeting_time`): This question asks for the time of day for staff-student meetings. Please enter a time in the format HH:MM.
