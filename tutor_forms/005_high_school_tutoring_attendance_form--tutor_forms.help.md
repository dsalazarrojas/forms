# High School Tutoring Attendance Form - Help Guide
## Purpose
This form is used to track student attendance for high school tutoring sessions.

## How To Complete This Form
To complete this form, simply fill out each section as prompted. Make sure to enter the required fields (indicated by *) and any other fields you feel are relevant for the session.

## Field-by-Field Explanation
- **Session Date** (`1`, date, *): Enter the date of the tutoring session.
- **Student Name** (`2`, text, *): Enter the student's name.
- **Student ID** (`3`, number, ): Enter the student's ID number.
- **Session Type** (`4`, select_one, ): Select the type of session (Regular, Makeup, Test Prep, or Extra Help).
- **Session Topic** (`5`, text, ): Enter the topic of the session.
- **Attendance Status** (`6`, select_multiple, ): Select the student's attendance status for the session (Present, Absent, or Late).
- **Session Notes** (`7`, note, ): Enter any additional notes about the session.
- **Session Start Time** (`8`, time, ): Enter the start time of the session.
- **Session End Time** (`9`, time, ): Enter the end time of the session.
- **Student Signature** (`10`, text, ): Enter your signature as the student.

## Tips
- Make sure to fill out each field accurately and completely.
- If a field is not required, you can still enter information if you feel it is relevant for the session.
- If you have any questions, please don't hesitate to reach out to the administration.
