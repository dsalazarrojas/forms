# Tool Request Form - Help Guide
## Purpose

This form is used to submit requests for tools and equipment.

## How To Complete This Form

* Ensure all required fields are filled out accurately and thoroughly.
* Fill out the form completely before submitting it.
* Double-check your submissions to prevent duplicates.

## Field-by-Field Explanation
* **Tool Request Form** (Text, Required/Optional): This is the main form title.
* **Assigned Tool** (Select One, Optional): Select the tool you would like to be assigned, if applicable.
* **Job Number** (Number, Optional): Enter the job number associated with the tool request, if applicable.
* **Quantity** (Number, Optional): Enter the quantity of the tool you are requesting.
* **Location** (Text, Optional): Enter the location where the tool will be used or stored.
* **Notes** (Note, Optional): Add any additional comments or information about the request.
* **Tool Type** (Select Multiple, Optional): Select the type of tool you are requesting (e.g., Option 1, Option 2, Option 3).
* **Tool Description** (Text, Optional): Provide a brief description of the tool you are requesting.
* **Tool Request Date** (Date, Optional): Date of when you need the tool by.
* **Tool** (Select Multiple, Optional): Select the type of tool you would like to be assigned, if applicable. 

Note: Since Tool Type is a required field in your YAML, I've included it with the label in the Field-by-Field Explanation for clarity. If you'd like to change the label to just "Tool Type" instead, I'd be happy to do so.
