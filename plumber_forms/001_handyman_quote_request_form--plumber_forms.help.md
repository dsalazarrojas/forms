# Handyman Quote Request Form - Help Guide
## Purpose
The Handyman Quote Request Form is used to gather information from clients for handyman services.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter your client's **Client Name** in the first field.
2. Provide **Job Details** in the second field, describing the work to be done.
3. Check if you have **Service Type** available (yes/no).
4. Enter your **Contact Number** and **Email Address** for communication purposes.
5. Mention your **Job Location** where the work is required.
6. Specify the **Requested Date** if it's different from the current date.
7. Update **Job Status** as active or inactive (if necessary).
8. Indicate if the job has **Job Priority** (yes/no).
9. Check if a **Tool is Assigned** (yes/no).
10. Add any additional **Job Notes** if necessary.
11. Sign with your **Client Signature** and **Handyman Signature**.

## Field-by-Field Explanation

* **Client Name (1)**: Enter your full name or the name of your representative.
* **Job Details (2)**: Describe the work to be done, including any specific requirements.
* **Service Type (3)**: Check if you have the required service type available.
* **Contact Number (4)**: Enter your phone number for communication purposes.
* **Email Address (5)**: Enter your email address for communication purposes.
* **Job Location (6)**: Enter the address or location of the job site.
* **Requested Date (7)**: If different from the current date, specify the date you'd like the work done.
* **Job Description (8)**: Describe the job in more detail, if necessary.
* **Job Status (9)**: Update the job status as active or inactive if needed.
* **Job Priority (10)**: Indicate if the job has high or low priority.
* **Tool (11)**: Check if a tool is assigned to the job.
* **Job Notes (12)**: Add any additional notes or comments about the job.
* **Client Signature (13)**: Sign your name to confirm the details.
* **Handyman Signature (14)**: Sign with your name to confirm you've reviewed the details.
* **Job Completed Date (15)**: Record the date the job is completed.
* **Job Completed Time (16)**: Record the time the job is completed.
* **Job Status Update (17)**: Update the job status if it has changed.
* **Service Type Update (18)**: Check if you have updated service type available.
* **Job Priority Update (19)**: Indicate if the job priority has been updated.
* **Tool Update (20)**: Check if a tool is assigned to the job.
* **Job Notes Update (21)**: Add any additional notes or comments about the job.
* **Job Completed Date Update (22)**: Record the updated date the job is completed.
* **Job Completed Time Update (23)**: Record the updated time the job is completed.
* **Job Status Update Update (24)**: Update the job status if it has changed.
* **Client Signature Update (25)**: Sign with your name to confirm you've reviewed the updates.
