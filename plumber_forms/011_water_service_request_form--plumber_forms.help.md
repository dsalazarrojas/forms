# Water Service Request Form - Help Guide
## Purpose
This form is designed to gather information from end-users for a water service request. The system will use this information to process and prioritize the request.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the required fields: "Service Address", "Contact Person", and "Phone Number" or "Email".
* Select the type of service requested from the dropdown menu.
* Provide additional details in the "Message" field.
* Confirm that you are making a service request.

## Field-by-Field Explanation
* **What's The Issue** (water_service_request_form)
	+ This is the main description of the problem.
	+ Please enter a clear and concise description of the issue.
* **Which Service** (service_type)
	+ Choose the type of water service you are requesting, such as "Water Shut-off", "Leaking Water Heater", "Leaking Water Pipe", or "Leaking Faucet".
	+ If none of the options match, select "Other" to provide a custom description.
* **Service Address** (service_address)
	+ Enter the address where the issue is located.
* **Contact Person** (contact_person)
	+ Enter the name and title of the person responsible for the request.
* **Phone Number** (phone_number)
	+ Enter the contact phone number of the person responsible.
* **Email** (email_address)
	+ Enter the email address of the person responsible.
* **Message** (message)
	+ Provide any additional details or comments about the request.
* **Confirm Service Request** (confirm_service_request)
	+ Please confirm that this is a genuine service request.
	+ Select "Cancel" to cancel the request or "Confirm" to continue.
* **Submit** (submit)
	+ Once you have filled out the necessary fields, click "Submit" to send the request.
	+ You may also choose "Other" if you prefer to submit the request without completing all the fields.

## Tips
* Be sure to fill out all the required fields to ensure your request is processed correctly.
* If you select "Other" for the service type, please provide a clear description of the issue in the "Message" field.
* If you are not sure which service type to select, choose "Other" and add a description to help our team better understand your request.
