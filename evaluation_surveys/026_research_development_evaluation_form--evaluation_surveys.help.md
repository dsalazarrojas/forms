# research_development_evaluation_form - Help Guide
## Purpose
This form is used for evaluating research and development projects.

## How To Complete This Form

1. **Project Review**: Enter a brief summary of the project's status and any notable events or milestones.
2. **Strengths**: Select the strengths of the project by choosing from High, Low, or Other (if applicable).
3. **Weaknesses**: Select the weaknesses of the project by choosing from High, Low, or Other (if applicable).
4. **Opportunities**: Select the opportunities of the project by choosing from High, Low, or Other (if applicable).
5. **Next Steps and Recommendations**: Enter any next steps or recommendations for the project.
6. **Project Rating**: Enter a rating of the project on a scale of 0-90.
7. **Rating Scale**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
8. **Date**: Enter the date of the evaluation.
9. **Time**: Enter the time of the evaluation.
10. **Contact Email**: Enter the email address of the project contact.
11. **Contact Phone**: Enter the phone number of the project contact.
12. **Evaluation Comment**: Enter any additional comments or feedback on the project.
13. **Other Comments**: Enter any other comments or feedback on the project.
14. **Prophets**: Enter the number of project prophets.
15. **Project Reporter**: Enter the number of project reporters.
16. **Reviewer**: Enter the number of project reviewers.
17. **Rating Scale 2**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
18. **Rating Scale 3**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
19. **Rating Scale 4**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
20. **Rating Scale 5**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
21. **Rating Scale 6**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
22. **Rating Scale 7**: Select a rating scale for the project from 0-30, 30-60, or 60-90.
23. **Rating Scale 8**: Select a rating scale for the project from Other or 0-30, 30-60, or 60-90.

## Tips

* Please be as concise as possible when filling out the form.
* If you are unsure about any field, please ask your project manager or team lead for clarification.
* Make sure to enter the correct ratings and scales for the project.
* This form is meant to be completed by project reporters and reviewers, please only complete this form if you have been assigned to do so.
* Please be honest and accurate when filling out the form.
