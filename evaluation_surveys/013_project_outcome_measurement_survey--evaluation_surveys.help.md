# Project Outcome Measurement Survey - Help Guide
## Purpose
This form is used to measure the outcome of a project, assessing its likelihood of having a positive or negative impact, the type of outcome expected, and various other aspects such as resources used, project goal, main output, and expected changes in health, well-being, and productivity.

## How To Complete This Form
To complete this form, simply go through each section and select the relevant options that apply to your project.

## Field-by-Field Explanation
### 1. How likely is this project likely to have a positive impact? 
**Likelihood of Positive Impact** (Optional): This question assesses how likely the project is to have a positive impact. Choose a number between 1 (Not at all likely) and 4 (Extremely likely).

### 2. How likely is this project likely to have a negative impact? 
**Likelihood of Negative Impact** (Optional): This question assesses how likely the project is to have a negative impact. Choose a number between 1 (Not at all likely) and 4 (Extremely likely).

### 3. What type of outcome is expected? 
**Type of Outcome** (Optional): This question asks about the type of outcome expected from the project. Choose from Financial, Social, Environmental, Health, or None.

### 4. Expected outcome 
**Expected Outcome** (Optional): This question is asking for a brief description of the expected outcome.

### 5. How satisfied are you with this project? 
**Satisfaction Level** (Optional): This question asks about your level of satisfaction with the project. Choose from Very satisfied, Somewhat satisfied, or Not satisfied.

### 6. What are some areas that need improvement? 
**Areas for Improvement** (Optional): This question asks for specific areas where the project could be improved.

### 7. How likely are you to recommend this project? 
**Recommendation Level** (Optional): This question assesses how likely you are to recommend the project. Choose a number between 1 (Not at all likely) and 4 (Extremely likely).

### 8. How long did this project take to finish? 
**Project Duration** (Optional): This question asks about the duration of the project. Choose from Less than 1 month, 1-2 months, 3-6 months, 7-12 months, or More than 1 year.

### 9. What resources were available for this project? 
**Resources Used** (Optional): This question asks about the resources used for the project. Choose from Budget, Personnel, Facilities, Equipment, Software, or Other.

### 10. What was the project goal? 
**Project Goal** (Optional): This question asks about the main goal of the project. Choose from Improve existing program or service, Increase awareness and education, Increase access, Reduce costs, Increase efficiency, or Other.

### 11. What is the main output of this project? 
**Main Output** (Optional): This question asks about the main output of the project. Choose from Product or service, Training or capacity building, Policy or guidelines, Research or study, or Other.

### 12. What is the main output of this project? 
**Main Output** (Optional): This question is identical to the previous one, but it's possible it was duplicated.

### 13. Who is the main recipient of the project outcome? 
**Recipient of Project Outcome** (Optional): This question asks about the main recipient of the project outcome. Choose from Project team members, Community or public, or Other.

### 14. What is the expected impact on this project? 
**Expected Impact** (Optional): This question asks about the expected impact on the project. Choose from Increase awareness, Increase behavior, Increase knowledge, Increase skills, or Other.

### 15. What is the expected outcome for the main recipient(s)? 
**Expected Outcome for Main Recipient** (Optional): This question asks about the expected outcome for the main recipient. Choose from Positive change in behavior, Positive change in knowledge, Positive change in attitude, Positive change in health, or Positive change in well-being.

### 16. What is the expected benefit for the main recipient(s)? 
**Expected Benefit** (Optional): This question asks about the expected benefit for the main recipient. Choose from Financial benefits, Social benefits, Environmental benefits, Health benefits, or Other benefits.

### 17. What is the expected change in health for the main recipient(s)? 
**Expected Change in Health** (Optional): This question asks about the expected change in health for the main recipient. Choose from Increase, Decrease, or No change.

### 18. What is the expected change in well-being for the main recipient(s)? 
**Expected Change in Well-being** (Optional): This question asks about the expected change in well-being for the main recipient. Choose from Increase, Decrease, or No change.

### 19. What is the expected change in productivity for the main recipient(s)? 
**Expected Change in Productivity** (Optional): This question asks about the expected change in productivity for the main recipient. Choose from Increase, Decrease, or No change.

### 20. What is the expected change in quality of life for the main recipient(s)? 
**Expected Change in Quality of Life** (Optional): This question asks about the expected change in quality of life for the main recipient. Choose from Increase, Decrease, or No change.

### 21. What is the expected duration of the project outcome for the main recipient(s)? 
**Expected Duration of Project Outcome** (Optional): This question asks about the expected duration of the project outcome. Enter a number.

### 22. What is the expected frequency of the project outcome for the main recipient(s)? 
**Expected Frequency of Project Outcome** (Optional): This question asks about the expected frequency of the project outcome. Enter a number.

### 23. How long will the project outcome last for the main recipient(s)? 
**Expected Lasting Time of Project Outcome** (Optional): This question asks about the expected time for the project outcome to last. Choose from Less than 1 month, 1-2 months, 3-6 months, 7-12 months, or More than 1 year.

Please note that some fields are optional and only required if you have relevant information to provide. Also, some questions may have identical labels, but they are meant to be different fields. Please choose the correct options according to your project's specifics.
