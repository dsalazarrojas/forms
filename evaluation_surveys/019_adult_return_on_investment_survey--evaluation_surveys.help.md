# Adult Return On Investment Survey - Help Guide
## Purpose
This form is designed to help us evaluate the effectiveness of adult programs and courses. Your input will help us assess the return on investment (ROI) and identify areas for improvement.

## How To Complete This Form
1. To begin, please select the program or course you are evaluating.
2. Answer the questions in this form as honestly and thoroughly as possible.
3. If you're unsure about any question, please don't hesitate to add additional comments.
4. Select all that apply for "Benefits realized from participation" and "Measurable outcomes achieved".
5. Rate the overall value of the program in the "Cost versus benefit rating" field.
6. For "Would you recommend this program", select "True" if you believe the program has a high return on investment.
7. Finally, add any additional comments or suggestions for improving ROI in the "Additional comments" field.

## Field-by-Field Explanation
* **Program or course name** (Program or course name, text, required): 
  Please enter the name of the program or course you are evaluating.
* **Respondent name** (Respondent name, text, optional): 
  If you'd like to remain anonymous, you can leave this field blank. Otherwise, please enter your name.
* **Program or course name** (Program or course name, text, required): 
  Select the program or course that you have participated in.
* **Benefits realized from participation** (Benefits realized from participation, select_multiple, optional): 
  Select all that apply from the list below:
  • Improved skills
  • Increased income
  • Career advancement
  • Networking
  • Personal growth
* **Cost versus benefit rating** (Cost versus benefit rating, select_one, required): 
  Rate the overall value of the program:
  • Very poor
  • Poor
  • Fair
  • Good
  • Excellent
* **Measurable outcomes achieved** (Measurable outcomes achieved, text, optional): 
  Describe any metrics or KPIs that you've seen improvement in.
* **Would you recommend this program** (Would you recommend this program, select_one, required): 
  Select "True" if you believe the program has a high return on investment:
  • True
  • False
* **Additional comments** (Additional comments, text, optional): 
  Provide any additional comments or suggestions for improving ROI.
