# Advance Achievement Survey - Help Guide
## Purpose
The Advance Achievement Survey is designed to gather feedback from participants about their experience with a specific program or course. Your input will help us understand what worked well and what can be improved to better serve future participants.

## How To Complete This Form
To complete this survey, follow these steps:

1. Select the "Program or course name" field to provide the name of the program or course you are evaluating.
2. Choose one of the options for "Achievement level attained" that best describes your experience.
3. Select "Yes" or "No" for "Were learning resources helpful?".
4. If you would like, describe the most valuable component of the program or course.
5. Provide any recommendations for improvement.
6. Rate your "Overall satisfaction" with the program or course from 1 (low) to 5 (high).
7. Choose "Yes" or "No" for "May we contact you for follow-up?".

## Field-by-Field Explanation
* **Respondent name**: Your name as the participant, which will help us understand who is providing feedback.
	+ Type: Text
	+ Required: No
* **Program or course name**: Select the name of the program or course you are evaluating.
	+ Type: Text
	+ Required: Yes
* **Achievement level attained**: Choose one of the following options to best describe your experience:
	+ Type: Select One
	+ Required: Yes
	+ Options:
		- Below expectations
		- Meets expectations
		- Exceeds expectations
* **Were learning resources helpful?**: Select "Yes" or "No" to indicate whether the learning resources were helpful.
	+ Type: Select One
	+ Required: Yes
* **Most valuable program component**: Describe the part of the program or course that you found most valuable.
	+ Type: Text
	+ Required: No
* **Recommendations for improvement**: Provide any suggestions you have for improving the program or course.
	+ Type: Text
	+ Required: No
* **Overall satisfaction**: Rate your satisfaction with the program or course from 1 (low) to 5 (high).
	+ Type: Select One
	+ Required: Yes
	+ Options: 1, 2, 3, 4, 5
* **May we contact you for follow-up?**: Select "Yes" or "No" to allow or decline further contact.
	+ Type: Select One
	+ Required: No
