# Transformation Success Factors Survey - Help Guide
## Purpose
The Transformation Success Factors Survey is a form used to collect information about transformation projects, including contact details, project status, start and end dates, and other relevant factors.

## How To Complete This Form

- **First Page**: Please fill out this form as instructed.
- **Fill out the form in sequential order**:
  1. **First Page**: Complete the fields with the required information.
  2. **Save and Continue**: Click Save and Continue to move on to the next page.

## Field-by-Field Explanation
- **Contact Name**: <contact_name> (<required/optional>): Enter the name of the person in charge of the transformation project.
  - Type: text, <required/optional>: true/false
- **Project Name**: <project_name> (<required/optional>): Enter the name of the transformation project.
  - Type: text, <required/optional>: true/false
- **Department**: <department> (<required/optional>): Enter the department responsible for the transformation project.
  - Type: text, <required/optional>: true/false
- **Contact Email**: <contact_email> (<required/optional>): Enter the email address of the person in charge of the transformation project.
  - Type: email, <required/optional>: true/false
- **Contact Phone**: <contact_phone> (<required/optional>): Enter the phone number of the person in charge of the transformation project.
  - Type: text, <required/optional>: true/false
- **Project Status**: <project_status> (<required/optional>): Select the current status of the transformation project.
  - Type: select_one, <required/optional>: true/false
  - Options: Active, Inactive, Pending
- **Start Date**: <start_date> (<required/optional>): Enter the start date of the transformation project.
  - Type: date, <required/optional>: true/false
- **End Date**: <end_date> (<required/optional>): Enter the end date of the transformation project.
  - Type: date, <required/optional>: true/false
- **Comments**: <comments> (<required/optional>): Enter any additional comments or notes about the transformation project.
  - Type: text, <required/optional>: true/false
- **Transformation Type**: <transformation_type> (<required/optional>): Select the type of transformation project.
  - Type: select_multiple, <required/optional>: true/false
  - Options: Business Process, Organization, Technology
- **Transformation Status**: <transformation_status> (<required/optional>): Select the current status of the transformation project.
  - Type: select_one, <required/optional>: true/false
  - Options: Not Started, In Progress, Completed
- **Additional Comments**: <comments_2> (<required/optional>): Enter any additional comments or notes about the transformation project.
  - Type: text, <required/optional>: true/false
- **Contact**: <contact> (<required/optional>): Enter any additional contact information.
  - Type: text, <required/optional>: true/false

## Tips
- Please ensure you have all the necessary information before completing this form.
- If you are unsure about any field, please contact the project manager or team member for assistance.
- The form will be reviewed and evaluated on the completeness and accuracy of the information provided.
