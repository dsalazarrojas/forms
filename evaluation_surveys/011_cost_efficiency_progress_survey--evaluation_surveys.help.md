- If the project is active, select "Active" for the project status. If it is inactive, choose "Inactive".
- Provide the actual cost of the project, as reported.

- Calculate the cost variance, which is the difference between the actual and budgeted cost. 
- Select the cost center that the project belongs to, if applicable. 
- Add any comments about the project's progress, if necessary. 
- Finally, choose the current status of the survey as either "Active" or "Inactive".
