# Public Health Partnership Effectiveness Evaluation - Help Guide
## Purpose
The purpose of this form is to evaluate the effectiveness of public health partnerships.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct options for each question, taking into account the level of collaboration, communication, and challenges faced by partners in the public health partnership.
2. Fill in the text fields with a brief description of any challenges or next steps.

## Field-by-Field Explanation

- **coalition_name** (`coalition_name`, text, required): Enter the name of the public health coalition or partnership.
- **collaboration_level** (`collaboration_level`, select_one, required): Select one of the following:
	* High: The partnership has achieved high level of collaboration.
	* Low: The partnership has achieved low level of collaboration.
- **communication_level** (`communication_level`, select_multiple, required): Select all that apply:
	* High: Partners have regular and effective communication.
	* Low: Partners have infrequent or ineffective communication.
- **outcomes** (`outcomes`, text, required): Describe the outcomes achieved by the partnership.
- **challenges** (`challenges`, text, required): Describe any challenges you have experienced.
- **communication** (`communication`, select_multiple, required): Select all that apply:
	* Yes: Partners have effective communication.
	* No: Partners do not have effective communication.
- **collaboration** (`collaboration`, select_multiple, required): Select all that apply:
	* Yes: Partners have collaboration.
	* No: Partners do not have collaboration.
- **partner_involvement** (`partner_involvement`, select_one, required): Select one of the following:
	* Yes: Partners are involved in the decision-making process.
	* No: Partners are not involved in the decision-making process.
- **partner_capacity** (`partner_capacity`, select_one, required): Select one of the following:
	* Yes: Partners have sufficient capacity to contribute.
	* No: Partners do not have sufficient capacity to contribute.
- **ongoing_improvement** (`ongoing_improvement`, select_multiple, required): Select all that apply:
	* Yes: The partnership is always improving.
	* No: The partnership is not improving.
- **future_focus** (`future_focus`, select_multiple, required): Select all that apply:
	* Yes: The partnership has a future focus.
	* No: The partnership does not have a future focus.
- **communication_strategies** (`communication_strategies`, select_multiple, required): Select all that apply:
	* Good: The partnership has effective communication strategies.
	* Fair: The partnership has fair communication strategies.
- **collaboration_strategies** (`collaboration_strategies`, select_multiple, required): Select all that apply:
	* Good: The partnership has effective collaboration strategies.
	* Fair: The partnership has fair collaboration strategies.
- **evaluation_process** (`evaluation_process`, select_one, required): Select one of the following:
	* Yes: The partnership has a regular evaluation process.
	* No: The partnership does not have a regular evaluation process.
- **next_steps** (`next_steps`, select_multiple, required): Select all that apply:
	* Yes: The partnership has next steps.
	* No: The partnership does not have next steps.
- **evaluation_frequency** (`evaluation_frequency`, select_multiple, required): Select all that apply:
	* Yes: The partnership evaluates regularly.
	* No: The partnership does not evaluate regularly.
- **data_reporting** (`data_reporting`, select_multiple, required): Select all that apply:
	* Yes: The partnership reports data regularly.
	* No: The partnership does not report data regularly.
- **communication_frequency** (`communication_frequency`, select_multiple, required): Select all that apply:
	* Yes: The partnership communicates regularly.
	* No: The partnership does not communicate regularly.
- **collaboration_frequency** (`collaboration_frequency`, select_multiple, required): Select all that apply:
	* Yes: The partnership collaborates regularly.
	* No: The partnership does not collaborate regularly.
- **evaluation_method** (`evaluation_method`, select_multiple, required): Select all that apply:
	* Yes: The partnership evaluates regularly.
	* No: The partnership does not evaluate regularly.
- **challenges_frequency** (`challenges_frequency`, select_multiple, required): Select all that apply:
	* Yes: The partnership faces challenges regularly.
	* No: The partnership does not face challenges regularly.
- **next_steps_frequency** (`next_steps_frequency`, select_multiple, required): Select all that apply:
	* Yes: The partnership takes next steps regularly.
	* No: The partnership does not take next steps regularly.
- **challenges_description** (`challenges_description`, text, required): Describe the challenges faced by the partnership.
- **next_steps_description** (`next_steps_description`, text, required): Describe any next steps the partnership plans to take.
- **evaluation_summary** (`evaluation_summary`, text, required): Summarize your evaluation of the partnership.
