# Donor Data Protection Awareness Survey - Help Guide
## Purpose
This form is designed to assess the current state of donor data protection practices within an organization. It aims to gather information on the types of data collected, used, and shared, as well as the methods used for data security, retention, and deletion. The survey helps to identify areas of improvement and potential vulnerabilities in data protection policies and procedures.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question thoroughly and honestly to the best of your ability.
2. Review the options carefully to ensure you select the correct answers.
3. Make sure to fill in all required fields, marked as "required" below.
4. If a question is not applicable or does not apply to your situation, select "Not Applicable".

## Field-by-Field Explanation

* **Introduction** (page 1): This is a note page that provides an introduction to the survey. Please read it carefully before proceeding.
* **Donor Consent** (page 2):
	+ **Consent Given**: This option is selected if you have obtained the donor's consent for data collection and use.
	+ **No Consent Given**: This option is selected if you have not obtained the donor's consent for data collection and use.
* **Privacy Practices** (page 3):
	+ **Data Collection**: This option is selected if you collect data directly from the donor.
	+ **Data Use**: This option is selected if you use data for specific purposes (e.g., marketing, research).
	+ **Data Sharing**: This option is selected if you share data with third parties (e.g., partners, vendors).
* **Data Collection** (page 4):
	+ **Direct**: This option is selected if you collect data directly from the donor.
	+ **Indirect**: This option is selected if you collect data indirectly (e.g., from public sources, third parties).
	+ **Not Applicable**: This option is selected if you do not collect data.
* **Data Use** (page 5):
	+ **Direct**: This option is selected if you use data for specific purposes.
	+ **Indirect**: This option is selected if you use data indirectly (e.g., for analytics, profiling).
	+ **Not Applicable**: This option is selected if you do not use data.
* **Data Sharing** (page 6):
	+ **Public**: This option is selected if you share data publicly (e.g., on social media, website).
	+ **Private**: This option is selected if you share data privately (e.g., with internal teams, partners).
	+ **Not Applicable**: This option is selected if you do not share data.
* **Data Security** (page 7):
	+ **Secure**: This option is selected if you implement security measures to protect data (e.g., encryption, access controls).
	+ **Insecure**: This option is selected if you do not implement security measures.
	+ **Not Applicable**: This option is selected if you do not collect or use data.
* **Data Retention** (page 8):
	+ **Long-term**: This option is selected if you retain data for an extended period.
	+ **Short-term**: This option is selected if you retain data for a short period.
	+ **Not Applicable**: This option is selected if you do not collect or use data.
* **Data Deletion** (page 9):
	+ **Delete**: This option is selected if you delete data upon request or when no longer needed.
	+ **Not Delete**: This option is selected if you do not delete data upon request or when no longer needed.
	+ **Not Applicable**: This option is selected if you do not collect or use data.
* **Data Access** (page 10):
	+ **Access**: This option is selected if you allow access to data for internal teams, partners, or third parties.
	+ **No Access**: This option is selected if you do not allow access to data.
	+ **Not Applicable**: This option is selected if you do not collect or use data.
* **Form Completion** (page 11):
	+ **True**: This option is selected if you complete this survey honestly and accurately.
	+ **False**: This option is selected if you do not complete the survey honestly and accurately.
	+ **Not Applicable**: This option is selected if you do not have the ability or authority to complete this survey.
* **Contact Information** (page 12):
	+ **Public**: This option is selected if you share your contact information publicly (e.g., email, phone number).
	+ **Private**: This option is selected if you share your contact information privately (e.g., internally within the organization).
	+ **Not Applicable**: This option is selected if you do not share contact information.

## Tips
* Make sure to answer all required fields, marked as "required" in the form.
* If you are unsure about any question, please ask for clarification or assistance.
* The survey is designed to be completed honestly and accurately. Please do not falsify information.
