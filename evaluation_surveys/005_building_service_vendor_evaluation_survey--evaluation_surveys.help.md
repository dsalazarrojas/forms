# Building Service Vendor Evaluation Survey - Help Guide
## Purpose
This form is used to evaluate the performance of a vendor providing building services. It assesses the vendor's timeliness, quality, communication, and overall satisfaction with the work performed.

## How To Complete This Form
This form is divided into two main sections: contact and service evaluation. To complete this form, please select the vendor you are evaluating and follow the instructions below.

## Field-by-Field Explanation

*   **Vendor Name** (`vendor_name`, text): Please enter the name of the vendor being evaluated. This is a required field and should be filled with the exact name of the vendor.
*   **Type of Service Provided** (`service_type`, text): Describe the type of service delivered by the vendor, such as construction services, maintenance, or design services.
*   **Contract Reference or PO** (`contract_reference`, text): If applicable, please enter the contract number or purchase order number related to the service provided. This is an optional field.
*   **Timeliness of Service** (`timeliness_rating`, select_one): Rate the timeliness of the service provided using the following options: Excellent, Good, Fair, Poor.
*   **Quality of Work** (`quality_rating`, select_one): Rate the quality of the work performed using the following options: Excellent, Good, Fair, Poor.
*   **Communication and Responsiveness** (`communication_rating`, select_one): Rate the vendor on communication clarity and responsiveness using the following options: Excellent, Good, Fair, Poor.
*   **Safety Compliance** (`safety_compliance`, select_one): Rate the vendor's adherence to safety protocols using the following options: Compliant, Minor issues, Major issues, Non-compliant.
*   **Overall Satisfaction** (`overall_satisfaction`, select_one): Rate your overall satisfaction with the service provided using the following options: Very satisfied, Satisfied, Neutral, Dissatisfied, Very dissatisfied.
*   **Improvement Recommendations** (`improvement_recommendations`, text): Provide any suggestions to improve vendor performance or contract terms. This is an optional field.
*   **Is Follow Up Required?** (`follow_up_required`, select_one): Indicate if the procurement or contract manager should follow up with the vendor using the following options: True, False.

Tips:
Please rate the vendor performance as accurately as possible based on your experience. Use this form to provide constructive feedback that will help the vendor improve their services.
