# Family Supervision Practice Survey - Help Guide
## Purpose
This form is designed to gather feedback on family supervision practices, including their effectiveness, frequency, satisfaction, and safety. This will help inform improvements to these practices.

## How To Complete This Form
1. Please start by reading the introduction and answering the initial questions about the practice type and frequency. 
2. For practices that are not listed, please provide a detailed description in the corresponding text fields.
3. For the remaining questions, select one of the options or provide a detailed description in the text fields.
4. Finally, submit the form to provide your feedback.

## Field-by-Field Explanation

* **Introduction** (Page 1, required: false): This is a brief introduction to the form.
* **Practice Type** (Page 2, required: false): Select 'Yes' if you use this type of practice, 'No' otherwise.
* **Practice Type Other** (Page 3, required: true): If you have a practice not listed, provide a detailed description.
* **Frequency of Practices** (Page 4, required: false): Select 'Yes' if you use this practice frequently, 'No' otherwise.
* **Frequency of Practices Other** (Page 5, required: true): If you have a practice not listed, provide a detailed description.
* **Practice Effectiveness** (Page 6, required: false): Select 'Yes' if the practice is effective, 'No' otherwise.
* **Practice Effectiveness Other** (Page 7, required: true): If the practice is not effective, provide a detailed description.
* **Supervisor Support** (Page 8, required: false): Select 'Yes' if you receive supervisor support, 'No' otherwise.
* **Supervisor Support Other** (Page 9, required: true): If you don't receive supervisor support, please provide a detailed description.
* **Practice Satisfaction** (Page 10, required: false): Select 'Satisfied' if you are satisfied with the practice, 'Dissatisfied' otherwise.
* **Practice Satisfaction Other** (Page 11, required: true): If you are not satisfied, provide a detailed description.
* **Practice Usefulness** (Page 12, required: false): Select 'Yes' if the practice is useful, 'No' otherwise.
* **Practice Usefulness Other** (Page 13, required: true): If the practice is not useful, provide a detailed description.
* **Practice Safety** (Page 14, required: false): Select 'Yes' if the practice is safe, 'No' otherwise.
* **Practice Safety Other** (Page 15, required: true): If the practice is not safe, provide a detailed description.
* **Practice Safety Fear** (Page 16, required: true): If you fear a practice, please describe it.
* **Practice Safety Precautions** (Page 17, required: true): If you have any safety precautions, please describe them.
* **Supervision Model** (Page 18, required: false): Select 'Yes' if you use a supervision model, 'No' otherwise.
* **Supervision Model Other** (Page 19, required: true): If you don't use a supervision model, provide a detailed description.
* **Supervision Frequency** (Page 20, required: false): Select 'Yes' if you use the supervision model frequently, 'No' otherwise.
* **Supervision Frequency Other** (Page 21, required: true): If you don't use the supervision model frequently, please describe your frequency.
* **Supervision Frequency Duration** (Page 22, required: true): If you use the supervision model, please describe the duration.
* **Supervision Frequency Duration Other** (Page 23, required: true): If you don't use the supervision model, please provide a detailed description.
* **Supervision Frequency Fear** (Page 24, required: true): If you fear the supervision model, please describe it.
* **Practice Satisfaction Fear** (Page 25, required: true): If you fear a practice, please describe it.

## Tips
- Please answer each question honestly and thoroughly.
- If you have any questions or concerns, please contact the survey administrators.
