# Plan Filter Survey - Help Guide
## Purpose
The "Plan Filter Survey" form is a tool used to collect information from users about their plans and preferences. This information will help the organization make informed decisions about marketing strategies or product development.

## How To Complete This Form
To complete the form, please follow these steps:

1. Select the options for each field as instructed below.
2. Make sure to answer all required fields, as indicated by the "required" label.

## Field-by-Field Explanation

* **Plan Filter Survey** (`page_one`): This is the title of the form, but it does not require input from the user.
* **Segment Users** (`page_two`): Enter the number of users that will be segmented for the plan.
* **Recommend Plans** (`page_three`): Indicate if you would recommend plans to the users you segmented.
* **Get Started** (`page_four`): Indicate if you think users can get started with the plans.
* **Right Plans** (`page_five`): Enter the plans that you think are right for the users.
* **Guided Questions** (`page_six`): This is a note field for any additional information or questions that may be required.
* **Drag and Drop** (`page_seven`): Select one option to indicate if drag and drop functionality is a requirement.
* **Right Plans** (`page_eight`): Enter the plans that you think are right for the users.
* **Streamlined Data** (`page_nine`): Enter any additional information or comments about the streamlined data.

## Tips
* Make sure to read each question carefully before answering.
* If you are unsure about a question, please ask for clarification before proceeding.
* If you have any additional questions or concerns, feel free to contact the administrator for assistance.
