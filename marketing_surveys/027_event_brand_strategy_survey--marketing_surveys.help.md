# Event Brand Strategy Survey - Help Guide

## Purpose
The Event Brand Strategy Survey is a tool used to assess and improve the branding of an event. It is designed to gather information about the event's brand image and overall feeling.

## How To Complete This Form
1. Fill out the form completely and honestly.
2. Select the correct options for each field that best describe your experience with the event's brand.
3. Take your time to carefully review each field before proceeding.

## Field-by-Field Explanation
### Event Brand Name (`event_brand_name`)
* **Event Brand Name**: A text field where you can enter the name of the event's brand.
* This field is optional but helps to provide a clear and concise name for the event's brand.
* Please enter the event's brand name as you know it.

### Event Colors (`event_color_schemes`)
* **Event Colors**: A select multiple field where you can choose how well the event's brand colors are represented.
* Options: 
 + Event Brand is the best thing in the world
 + Very Good
 + Average
 + Very Poor
* Choose one or multiple options that best describe your experience with the event's brand colors.

### Event Logo (`event_logo`)
* **Event Logo**: A text field where you can enter the name of the event's logo.
* This field is optional but helps to provide a clear and concise logo name for the event's brand.
* Please enter the event's logo as you know it.

### Brand Message (`brand_message`)
* **Brand Message**: A text field where you can enter any message or slogan associated with the event's brand.
* This field is optional but helps to provide more context about the event's brand.
* Please enter any brand message you are aware of.

### Target Audience (`target_audience`)
* **Target Audience**: A text field where you can describe the target audience for the event's brand.
* This field is optional but helps to provide more information about the event's brand.
* Please describe the target audience for the event's brand.

### Event Theme (`event_theme`)
* **Event Theme**: A text field where you can enter any theme associated with the event's brand.
* This field is optional but helps to provide more context about the event's brand.
* Please enter any event theme you are aware of.

### Overall Feeling (`overall_feeling`)
* **Overall Feeling**: A select one field where you can choose how you generally feel about the event's brand.
* Options: 
 + Positive
 + Negative
 + Neutral
* Choose one option that best describes your overall feeling about the event's brand.

### Event Colors Name (`event_color_name`)
* **Event Colors Name**: A select one field where you can choose how well the event's brand colors are represented.
* Options: 
 + Yes
 + No
* Choose one option that best describes your experience with the event's brand colors.

## Tips
* Take your time to carefully review each field before proceeding.
* If you're unsure about any field, ask for help or clarification.
* This form is for internal use only, so please do not share it with anyone outside the organization.
