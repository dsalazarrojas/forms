# Media Project Planning Survey - Help Guide
## Purpose
The Media Project Planning Survey form is designed to gather key information about media projects. This form helps project managers, coordinators, and team leads to efficiently plan and track project progress.

## How To Complete This Form
To complete the form, follow these steps:
1. Review and select "Yes" or "No" for:
	* Project Objectives: Describe the project objectives.
	* Timeline: Confirm if the project timeline is feasible.
	* Production Studio: Indicate if the production studio will be involved in the project.
	* Production Team: Select the composition of the production team.
2. Enter the following information:
	* Project Resources: Provide details about the resources required for the project.
	* Contact Details: Enter contact information for project communication.
	* Project Deadline: Select the deadline for the project completion.
	* Project Notes: Add any additional notes or comments about the project.
3. Select one of the following options for:
	* Project Status: Choose whether the project is active or inactive.
	* Project Budget: Enter the estimated budget for the project.
	* Project Manager: Enter the name of the project manager.

## Field-by-Field Explanation

* **Project Objectives** (`project_objectives`): Briefly describe the project's main objectives. This will help the project team understand the project's scope and focus.
* **Timeline** (`project_timeline`): Confirm if the project timeline is feasible and realistic. This will help in determining project feasibility and resource allocation.
* **Production Studio** (`production_studio`): Indicate if you will be working with a production studio. This will help in determining studio involvement and resource allocation.
* **Production Team** (`production_team`): Select the composition of the production team, such as crew members, equipment, or services required.
* **Project Resources** (`project_resources`): Provide details about the resources required for the project, including personnel, equipment, or services needed.
* **Contact Details** (`contact_details`): Enter contact information for project communication, including name, email, and phone number.
* **Project Deadline** (`project_deadline`): Select the deadline for the project completion.
* **Production Studio Notes** (`production_studio_notes`): Add any additional notes or comments about the production studio's involvement.
* **Project Status** (`project_status`): Choose whether the project is active or inactive.
* **Project Budget** (`project_budget`): Enter the estimated budget for the project.
* **Project Manager** (`project_manager`): Enter the name of the project manager.
* **Project Notes** (`project_notes`): Add any additional notes or comments about the project.

## Tips
- Double-check the accuracy of the information provided before submitting the form.
- If you're unsure about any field, please contact your project coordinator or manager.
- Ensure that you're submitting relevant and up-to-date information to help the project team plan and track the project progress accurately.
