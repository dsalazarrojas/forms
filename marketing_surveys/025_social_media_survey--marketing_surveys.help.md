# Social Media Survey - Help Guide
## Purpose
This form is designed to collect information about the company's social media presence and usage. It helps us understand how we are doing on different social media platforms, and what we need to improve.

## How To Complete This Form

* Please fill out this form carefully, providing honest answers to each question.
* You can select all that apply for the multi-select fields.
* If you're unsure about a particular question, try to provide the best answer you can.

## Field-by-Field Explanation

* **Introduction** (Note): This field is a brief introduction to the survey. Read it carefully to understand the context and purpose of the survey.
* **Social Media Platforms** (Select Multiple): Check all the social media platforms that you use. This will help us understand which platforms are most popular among our audience.
* **Frequency of Use** (Select One): Indicate how often you use social media:
	+ Yes: You use social media frequently (daily or weekly).
	+ No: You don't use social media or use it rarely.
* **Social Media Goals** (Select Multiple): Check all the goals you have for using social media:
	+ Yes: You use social media for [goal 1], [goal 2], etc.
* **Social Media Channels** (Select Multiple): Check all the social media channels you use:
	+ Yes: You use [channel 1], [channel 2], etc.
* **Time Spent on Social Media** (Number): If you use social media, estimate the average amount of time you spend on it per week.
* **Most Used Platforms** (Select One): Indicate the platform you use most frequently:
	+ Yes: [platform 1]
	+ No: Not applicable
* **Least Used Platforms** (Select One): Indicate the platform you use least frequently:
	+ Yes: [platform 1]
	+ No: Not applicable
* **Social Media Influencers** (Select Multiple): Check all the social media influencers you follow:
	+ Yes: [influencer 1], [influencer 2], etc.
* **Social Media Ads** (Select Multiple): Check all the types of social media ads you've seen or used:
	+ Yes: [ad type 1], [ad type 2], etc.
* **Social Media Budget** (Select Multiple): Check all the aspects of your social media budget:
	+ Yes: [budget aspect 1], [budget aspect 2], etc.
* **Social Media Measurement** (Select Multiple): Check all the metrics you use to measure social media performance:
	+ Yes: [metric 1], [metric 2], etc.
