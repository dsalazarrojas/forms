# Event Attendee Interest Survey - Help Guide
## Purpose
This form is designed to collect information about attendees interested in an upcoming event. It will help event organizers understand who's coming and what they're interested in, allowing them to tailor their event experience accordingly.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide the name of the event you are interested in.
2. Enter the date of the event you are interested in.
3. Input your email address so we can keep you updated.
4. Provide your phone number (optional).

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required/optional): Enter the name of the event you are interested in attending.
* **Event Date** (`event_date`, date, required/optional): Enter the date of the event you are interested in attending. Please use the format `YYYY-MM-DD` for the date.
* **Attendee Email** (`attendee_email`, email, required/optional): Enter your email address so we can keep you updated about event details and changes.
* **Attendee Phone** (`attendee_phone`, text, required/optional): If you'd like to be reached by phone, please enter your phone number. This is not required, and you can leave it blank if you prefer not to be contacted by phone.

## Tips
- Double-check your event name and date to ensure accuracy.
- Make sure to double-check your email address for correct formatting.
- Phone number is not required, but if you enter one, we'll use it to contact you if needed.
