# Retail Seasonal Promotion Impact Assessment Form - Help Guide
## Purpose
This form is used to assess the impact of retail seasonal promotions on sales. It will help us to evaluate the effectiveness of these promotions in different regions, product types, and channels. Please ensure that each question is answered accurately and completely to get a comprehensive view of the promotion's performance.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select the relevant options from the dropdown menus for each question.
2. Enter any required text answers in the text fields.
3. Make sure to fill out all fields marked as "required".
4. Review the form carefully before submitting it.

## Field-by-Field Explanation
* **Retail Seasonal Promotion Impact Assessment** (`retail_seasonal_promotion_impact_assessment`, note, optional): This is a brief description of the form. You can add any additional information about the promotion if needed.
* **Location** (`location`, select_one, optional): Please select "Yes" if the promotion was run at your store or location, or "No" if it was not.
* **Store ID** (`store_id`, text, optional): Enter the ID of the store where the promotion was run. This will help us to track the promotion's performance by store.
* **Product ID** (`product_id`, select_one, optional): Please select "Yes" if the product was part of the promotion, or "No" if it was not.
* **Product Type ID** (`product_type_id`, select_one, optional): Select the type of product that was part of the promotion.
* **Promotion Type** (`promotion_type`, select_multiple, optional): Multiple selections are possible, e.g., "Yes" for a "Discount" and "Yes" for a "Giveaway". This will help us to analyze the types of promotion strategies used.
* **Promotion Start Date** (`promotion_start_date`, date, optional): Enter the date when the promotion started. Please use the standard date format (YYYY-MM-DD).
* **Promotion End Date** (`promotion_end_date`, date, optional): Enter the date when the promotion ended. Please use the standard date format (YYYY-MM-DD).
* **Sales Increase** (`sales_increase`, number, optional): Enter the percentage increase in sales due to the promotion. If there was no increase, enter 0.
* **Customer Feedback** (`customer_feedback`, text, optional): Share any comments or feedback from customers related to the promotion.
* **Store Manager ID** (`store_manager_id`, text, optional): Enter the ID of the store manager who oversaw the promotion.
* **Regional Manager ID** (`regional_manager_id`, text, optional): Enter the ID of the regional manager who coordinated the promotion.
* **Sales Channel ID** (`sales_channel_id`, text, optional): Enter the ID of the sales channel used for the promotion.
* **Sales Region ID** (`sales_region_id`, text, optional): Enter the ID of the sales region where the promotion was run.
* **Store Name** (`store_name`, text, optional): Enter the name of the store where the promotion was run.
* **Product Name** (`product_name`, text, optional): Enter the name of the product that was promoted.
* **Promotion Budget** (`promotion_budget`, number, optional): Enter the budget allocated for the promotion.
