# T Shirt Survey - Help Guide
## Purpose
This form is designed to gather information from customers about their preferences and opinions on T-Shirts. The collected data will help marketing teams understand customer behavior and preferences.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Read the instructions and questions carefully.
2. Answer each question to the best of your ability.
3. Provide as much detail as possible in the text fields.

## Field-by-Field Explanation

* **Welcome to T-Shirt Survey**: This is a note field that welcomes the customer and provides instructions on how to complete the form.
* **T-Shirt Size**: This field is a select multiple field where you can select one or more sizes that you prefer.
	+ This field is required: No
* **T-Shirt Color**: This field is a select one field where you can select your preferred color.
	+ Options: Black, White, Red, Blue, Green, Yellow, Gray, Purple, Orange
	+ This field is required: No
* **T-Shirt Style**: This field is a select multiple field where you can select one or more styles you prefer.
	+ Options: Yes, No
	+ This field is required: No
* **T-Shirt Length**: This field is a select one field where you can select your preferred length.
	+ Options: Yes, No
	+ This field is required: No
* **T-Shirt Material**: This field is a select multiple field where you can select one or more materials you prefer.
	+ Options: Yes, No
	+ This field is required: No
* **Preferred T-Shirts**: This field is a select multiple field where you can select one or more designers you prefer.
	+ Options: Yes, No
	+ This field is required: No
* **T-Shirt Price**: This field is a number field where you can select your preferred price range.
	+ Options: $5-$10, $11-$15, $16-$20, $21-$25, $26-$30
	+ This field is required: No
* **T-Shirt Designer**: This field is a select one field where you can select your preferred designer.
	+ Options: Yes, No
	+ This field is required: No
* **Favorite T-Shirt Designer**: This field is a select multiple field where you can select one or more designers you prefer.
	+ Options: Yes, No
	+ This field is required: No
* **Customer Interest**: This field is a note field where you can provide any additional information about your interests.
* **Would you buy this t-shirt?**: This field is a select one field where you can answer yes or no to whether you would buy a T-Shirt based on the information provided.
	+ Options: True, False
	+ This field is required: No
* **Why no?**: This field is a text field where you can provide a brief explanation if you answered "no" to the previous question.
* **Customer Comments**: This field is a text field where you can provide any comments or feedback about the T-Shirt survey.
* **T-Shirt Suggestions**: This field is a text field where you can provide any suggestions you have for improving the T-Shirt survey.
* **Customer Interest 1**: This field is a select multiple field where you can select one or more interests.
	+ Options: Yes, No
	+ This field is required: No
* **Customer Interest 2**: This field is a select multiple field where you can select one or more interests.
	+ Options: Yes, No
	+ This field is required: No
* **T-Shirt Price 1**: This field is a select one field where you can select one price range.
	+ Options: $5-$10, $11-$15, $16-$20, $21-$25, $26-$30
	+ This field is required: No
* **T-Shirt Designer 1**: This field is a select one field where you can select one designer.
	+ Options: Yes, No
	+ This field is required: No
* **T-Shirt Survey Suggestions**: This field is a text field where you can provide any suggestions for the T-Shirt survey.
* **Assigned Tool ID**: This field is a text field where you can provide the ID of the assigned tool.
* **Assigned Tool Name**: This field is a text field where you can provide the name of the assigned tool.
* **Assigned Tool Email**: This field is a text field where you can provide the email of the assigned tool.
* **Assigned Tool Phone**: This field is a text field where you can provide the phone number of the assigned tool.

## Tips
* Please answer each question to the best of your ability.
* If you have any comments or feedback, please provide them in the "Customer Comments" field.
* If you have any suggestions for improving the T-Shirt survey, please provide them in the "T-Shirt Suggestions" field.
