# Item Definition For Market Analysis - Help Guide
## Purpose
This form is used to define items for market analysis, providing details such as title, type, description, status, and competitors.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "New Item" page to begin creating a new item.
2. Fill in the "Item Type" field with the appropriate type of item (Product, Service, or Other).
3. Enter a brief description of the item in the "Item Description" field.
4. Select the "Item Status" from the options provided (In Development, In Production, or Retired).
5. If applicable, list any competitors for the item.
6. Review and submit the form to create a new item.

## Field-by-Field Explanation

* **New Item** (`new_item`, text, required/optional): Enter a title for the new item that will be used for reference.
* **Item Type** (`item_type`, select_one, required): Select the type of item, which can be Product, Service, or Other.
* **Item Description** (`item_description`, text, required): Enter a brief description of the item, e.g., its features, uses, etc.
* **Item Status** (`item_status`, select_one, required): Select the status of the item, which can be In Development, In Production, or Retired.
* **Competitor** (`competitor`, select_multiple, optional): List any competitors for the item, if applicable.

## Tips
* Make sure to review and submit the form carefully to avoid missing any required information.
* Use the "Item Type" field to differentiate between products and services.
* Be concise in the "Item Description" field, only providing essential details about the item.
* If listing competitors, be thorough and accurate to provide a comprehensive market analysis.
