# Survey Distribution Timing Questionnaire - Help Guide

## Purpose
This form is designed to determine the optimal timing for distributing surveys to recipients. It will help us understand when and how best to send our surveys to maximize engagement and response rates.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select all the applicable options for each field to determine your preferences for survey distribution.

## Field-by-Field Explanation

* **Days of the week** (`days_of_week`, select multiple, required: false): Choose the days of the week when you would like to distribute the survey. Select as many or as few as apply.
    * Monday
    * Tuesday
    * Wednesday
    * Thursday
    * Friday
    * Saturday
    * Sunday
* **Hours of the day** (`hours_of_day`, select multiple, required: false): Choose the hours of the day when you would like to distribute the survey. Select as many or as few as apply.
    * 8am-12pm
    * 12pm-4pm
    * 4pm-8pm
    * 8pm-12am
* **Time of day** (`time_of_day`, select multiple, required: false): This field is not currently implemented in the form. However, if it was implemented, it would allow you to choose specific time slots for survey distribution.
* **Channels** (`channels`, select multiple, required: false): Select all the channels through which you would like to send the survey. This may include email, phone, etc.
    * Yes: Select "Yes" to enable email distribution.
    * No: Select "No" to disable email distribution.
* **Send time** (`send_time`, time, required: false): This field is currently not applicable as there are no available options to select from. However, if the form was completed in the future, you would select a specific time for sending the survey.
* **Send day of week** (`send_day_of_week`, select one, required: false): Choose the day of the week when you would like to send the survey.
    * Yes
    * No
* **Send hours of day** (`send_hours_of_day`, select one, required: false): Choose the hours of the day when you would like to send the survey.
    * 8am-12pm
    * 12pm-4pm
    * 4pm-8pm
    * 8pm-12am
* **Email notification** (`email_notification`, select multiple, required: false): Select "Yes" to enable email notifications for the survey.
    * Yes: Select "Yes" to enable email notifications.
    * No: Select "No" to disable email notifications.
* **Reminder notification** (`reminder_notification`, select multiple, required: false): Select "Yes" to enable reminder notifications for the survey.
    * Yes: Select "Yes" to enable reminder notifications.
    * No: Select "No" to disable reminder notifications.
* **Phone number** (`phone_number`, text, required: false): Enter your phone number for receiving survey notifications.
* **Email/phone notification** (`email_phone_notification`, select multiple, required: false): Select "Yes" to enable both email and phone notifications for the survey.
    * Yes: Select "Yes" to enable both email and phone notifications.
    * No: Select "No" to disable both email and phone notifications.
* **Send channel** (`send_channel`, select multiple, required: false): This field is currently not applicable as there are no available options to select from. However, if the form was completed in the future, you would select the channel for sending the survey.
* **Survey frequency** (`survey_frequency`, select multiple, required: false): This field is currently not applicable as there are no available options to select from. However, if the form was completed in the future, you would select the frequency of the survey.
* **Send frequency** (`send_frequency`, select multiple, required: false): This field is currently not applicable as there are no available options to select from. However, if the form was completed in the future, you would select the frequency of sending the survey.

## Tips
* Make sure to select all the options that apply to you to ensure that the survey is distributed according to your preferences.
* If you are unsure about any field, refer to this help guide for more information.
* If you need help with any aspect of survey distribution, please contact your administrator for assistance.
