# Pricing And Package Options Survey - Help Guide
## Purpose
This form is used to collect information about your pricing and package options preferences. Please answer the questions honestly to help us provide you with the best possible experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select the page that best represents your current pricing and package options needs.
2. For the second page, select your preferred option for pricing and package options.
3. For the third page, select the plan value that best suits your needs.

## Field-by-Field Explanation
- **Pricing and Package Options Survey**: This field is a placeholder page that allows us to group other questions together.
	+ Type: `note`
	+ Required: `false`
	+ Hint: `null`
- **Pricing and Package Options Survey**: This field is a select multiple option that asks you to choose one or more of the following options:
	+ Type: `select_multiple`
	+ Required: `false`
	+ Options: `Free Trial`, `Paid Subscription`, `Enterprise`
- **Plan Value**: This field is a select one option that asks you to choose one plan value:
	+ Type: `select_one`
	+ Required: `false`
	+ Options: `High`, `Medium`, `Low`
Note: The form has 3 pages, but only page 2 and 3 have actual questions, page 1 is a placeholder page.
