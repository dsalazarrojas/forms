# Bachelor Program Evaluation Form - Help Guide
## Purpose
This form is designed to collect feedback and evaluations from students about their experience in a Bachelor's program.

## How To Complete This Form
1. Answer all the required fields, indicated by an asterisk (\*).
2. For select_one and select_one_with_options fields, choose one of the available options.
3. For text fields, provide a brief description or answer.
4. Make sure to submit the form once you have completed all the required fields.
