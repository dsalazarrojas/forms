# Preschool Graduation Questionnaire - Help Guide

## Purpose
The Preschool Graduation Questionnaire is designed to collect information about a child's preschool graduation, including the presence and years of experience of teachers and parents, as well as the child's graduation status and date.

## How To Complete This Form

To complete the Preschool Graduation Questionnaire, follow the steps below:

1. Please answer each question honestly and accurately.
2. If a question does not apply to your situation, please select the corresponding option (e.g., "No" or "Not applicable").
3. Make sure to complete all required fields, denoted by the word "required".

## Field-by-Field Explanation

* **Teachers** (`2`, `select_one`, required: false): This question asks about the presence of teachers in the preschool. Please select "Yes" if teachers are involved, and "No" if not.
* **Teachers Name** (`3`, `text`, required: false): This question asks for the name of the teacher(s) involved with the preschool graduation. Please enter the full name of the teacher(s).
* **Teachers Years** (`4`, `number`, required: false): This question asks about the number of years the teacher has been with the preschool. Please enter the number of years.
* **Parents** (`5`, `select_multiple`, required: false): This question asks about the involvement of parents in the preschool graduation. Please select all applicable options (e.g., "Yes" for both parents, or "No" for one or both).
* **Parents Name** (`6`, `text`, required: false): This question asks for the name of the parent(s) involved with the preschool graduation. Please enter the full name of the parent(s).
* **Parents Years** (`7`, `number`, required: false): This question asks about the number of years the parent has been with the preschool. Please enter the number of years.
* **Graduation Date** (`8`, `date`, required: false): This question asks for the date of the preschool graduation. Please enter the date in a standard format (e.g., MM/DD/YYYY).
* **Graduation Status** (`9`, `select_one`, required: false): This question asks about the current status of the preschool graduation. Please select either "Active" or "Inactive".
* **Graduation Comments** (`10`, `note`, required: false): This question asks for any additional comments or notes about the preschool graduation. Please enter any relevant comments or observations.

## Tips

* Make sure to answer each question carefully and accurately.
* If you need help or have questions, don't hesitate to contact us.
