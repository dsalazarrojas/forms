## Purpose

The Student Innovation Project Evaluation Form is used to assess student projects that aim to bring about innovation and creativity in a school setting.

## How To Complete This Form

1.  **Start by filling out the form page by page**. Each page has a specific set of fields that need to be completed.
2.  **Complete all required fields**. These fields are marked as required and are essential for a complete evaluation.
3.  **If a field is not required, you can leave it blank**. However, providing information in these fields can help provide a more comprehensive evaluation.
4.  **Make sure to review and submit your evaluation**. Once you've completed the form, make sure to review your answers for accuracy and completeness before submitting.

## Field-by-Field Explanation

*   **Project Name (Project Name, text, required: false)**: Enter the name of the student project.
    This field is used to identify the project and provide a brief title that summarizes the project's main theme or focus.
*   **Student Name (Student Name, text, required: false)**: Enter the name of the student who submitted the project.
    This field helps to identify the student who submitted the project and provide context for the evaluation.
*   **Project Category (Project Category, text, required: false)**: Select a category that best describes the project's focus or theme.
    This field helps to classify the project into different categories for easier evaluation and comparison.
*   **Project Description (Project Description, text, required: false)**: Enter a brief description of the project.
    This field provides an overview of the project's main goals, objectives, and key features.
*   **Project Duration (Project Duration, text, required: false)**: Enter the duration of the project in a format that makes sense for the project.
    This field helps to understand the scope and scale of the project.
*   **Outcome 1 (Outcome 1, select_one, required: false)**: Evaluate whether the project had a positive outcome.
    This field assesses the project's impact or results and determines whether it had a positive outcome.
*   **Outcome 2 (Outcome 2, text, required: false)**: Enter any additional information or comments about the project's outcome.
    This field provides space for any additional comments or feedback about the project's outcome.

**Tips**

*   Make sure to answer all required fields and provide as much information as possible for a comprehensive evaluation.
*   If you're unsure about any field, you can always ask the student or project coordinator for clarification.
*   Remember that the evaluation is meant to be fair and constructive, so try to provide constructive feedback that can help the student improve their project.
