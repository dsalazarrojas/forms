## Self Appraisal Form - Help Guide
## Purpose
The Self Appraisal Form is a tool used to evaluate an employee's performance and identify areas of improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please fill in your name and title, as they are required fields.
2. Answer the questions truthfully, using the options provided for each question.
3. For fields that are marked as required, please ensure that you provide an answer.

## Field-by-Field Explanation
* **Employee Name** (text): Please enter your name as it appears on your official documents.
* **Employee Title** (select_one, required): Please select either 'Yes' or 'No' to indicate whether you are an employee of the company.
* **Performance Level** (select_multiple, optional): Please select one or more options to describe your current performance level (High, Low).
* **Evaluation Date** (date, optional): If required, please enter the date of evaluation.
* **Section 1** (text, optional): This section is for you to describe your current performance and goals.
* **Areas of Growth** (note, optional): This section is for you to list any areas you would like to work on and improve.
* **Action Items** (select_multiple, optional): Please select one or more options to indicate whether you have any action items to complete.
* **Next Steps** (select_multiple, optional): Please select one or more options to describe what you will do next.
* **Final Rating** (select_one, optional): Please select a rating for your performance (Good, Fair).
* **Final Comment** (text, optional): This section is for any additional comments you would like to add.

## Tips
* Please be honest in your answers to ensure accurate evaluations.
* If a field is required, please fill it in completely.
* If you're unsure about any question, please reach out to your manager for guidance.
