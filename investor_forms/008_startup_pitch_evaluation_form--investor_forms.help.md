# Startup Pitch Evaluation Form - Help Guide
## Purpose
This guide is designed to help users understand the purpose and proper completion of the Startup Pitch Evaluation Form. This form is used to evaluate the strength of a startup's pitch, covering various aspects of the business.
## How To Complete This Form
To complete this form, follow these steps:
1. Begin with the Introduction section, where you can briefly describe the startup's name.
2. In the Team section, select whether the startup has a strong team.
3. For each of the subsequent sections (Product, Market, Business Model, Competition, Financials, Pitch, and Management), enter a brief description of the startup's current status.
4. For the Sales, Operations, and Risk sections, select whether the startup has these capabilities.
5. In the Conclusion section, summarize your overall impression of the startup.
6. In the Additional Comments section, provide any additional feedback or comments you have about the startup.
## Field-by-Field Explanation

* **Introduction** (1, note, required: false): A brief description of the startup's name.
* **Start Up Name** (2, text, required: false): Enter the name of the startup.
* **Team** (3, select_one, required: false): Check if the startup has a strong team.
* **Product** (4, text, required: false): A description of the product or service offered by the startup.
* **Market** (5, text, required: false): A brief description of the market the startup is targeting.
* **Business Model** (6, text, required: false): A description of the startup's business model.
* **Competition** (7, text, required: false): A description of the competition in the market.
* **Financials** (8, text, required: false): A brief overview of the startup's financials.
* **Pitch** (9, text, required: false): A summary of the startup's overall pitch.
* **Management** (10, select_multiple, required: false): Check which management capabilities the startup has.
* **Marketing** (11, select_multiple, required: false): Check which marketing capabilities the startup has.
* **Sales Reporting** (12, select_multiple, required: false): Check which sales reporting capabilities the startup has.
* **Operations** (13, select_multiple, required: false): Check which operations capabilities the startup has.
* **Risk** (14, select_multiple, required: false): Check which risk management capabilities the startup has.
* **Scalability** (15, text, required: false): A description of the startup's scalability.
* **Conclusion** (16, text, required: false): A summary of your overall impression of the startup.
* **Additional Comments** (17, text, required: false): Any additional feedback or comments about the startup.
* **Startup Name 2** (18, text, required: false): Enter the name of the second startup.
* **Team 2** (19, select_one, required: false): Check if the second startup has a strong team.
* **Product 2** (20, text, required: false): A description of the product or service offered by the second startup.
* **Market 2** (21, text, required: false): A brief description of the market the second startup is targeting.
* **Business Model 2** (22, text, required: false): A description of the second startup's business model.
* **Competition 2** (23, text, required: false): A description of the competition in the market for the second startup.
* **Financials 2** (24, text, required: false): A brief overview of the second startup's financials.
* **Management 2** (25, select_multiple, required: false): Check which management capabilities the second startup has.
