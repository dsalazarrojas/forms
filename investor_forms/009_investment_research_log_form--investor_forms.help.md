# Investment Research Log Form - Help Guide
## Purpose
The Investment Research Log Form is a tool used to track and document investment research and analysis activities. It is intended to provide a clear and concise record of your investment decisions and progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the Research Topic field with a brief description of the investment research topic you are working on.
2. Select the Current Status field to indicate the current state of the research, using the options provided (Opportunity, Risk, In Progress, Complete).
3. If required, enter the Investment Amount, Target Return, and Expected Return fields with numerical values representing the relevant investment details.
4. Add any Research Notes related to the investment research activity.
5. If required, select the Submit Date and enter the Analyst Name and Company Name fields with the relevant information.

## Field-by-Field Explanation
* **Research Topic**: (`research_topic`, text, not required): A brief description of the investment research topic being tracked.
* **Current Status**: (`current_status`, select_one, not required): The current state of the research, with options Opportunity, Risk, In Progress, Complete.
* **Investment Amount**: (`investment_amount`, number, not required): The numerical value representing the investment amount.
* **Target Return**: (`target_return`, number, not required): The numerical value representing the target return on the investment.
* **Expected Return**: (`expected_return`, number, not required): The numerical value representing the expected return on the investment.
* **Research Notes**: (`research_notes`, text, not required): Any notes related to the investment research activity.
* **Submit Date**: (`submit_date`, date, not required): The date the form was submitted.
* **Analyst Name**: (`analyst_name`, text, not required): The name of the analyst conducting the research.
* **Company Name**: (`company_name`, text, not required): The name of the company being researched.
