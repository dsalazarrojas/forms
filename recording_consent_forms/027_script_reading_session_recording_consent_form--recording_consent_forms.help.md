# Script Reading Session Recording Consent Form - Help Guide
## Purpose
This form is designed to collect participant consent for recording a script reading session. It is intended to ensure that participants understand and agree to the terms of the recording, which helps maintain trust and clarity in the data collection process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the participant information section with your details.
2. Check the box indicating that you agree to participate in the script reading session.
3. Provide any additional script details if necessary.
4. Sign your name to confirm your participation.
5. Indicate your approval for the recording by selecting "Approved" from the dropdown menu.
6. Add any additional notes about the script reading session.
7. Repeat the process for any additional participants.

## Field-by-Field Explanation

* **Participant Information**: This field is where you'll provide your personal details such as your name, title, and contact information. This is a required field as it helps us identify you as a participant.
* **I Agree to Participate in Script Reading Session**: Check this box to indicate that you consent to participate in the script reading session and understand the terms of the recording.
* **Script Details**: This field is where you can provide any additional information about the script you'll be reading. This is an optional field, but it can be helpful for us to understand more about the script.
* **Participant Signature**: Sign your name to confirm your participation and consent to the recording.
* **Participant Approval**: Indicate your approval for the recording by selecting "Approved" from the dropdown menu. This is a required field to ensure that you've given your consent.
* **Script Reading Session Notes**: Add any additional notes or comments about the script reading session. This is an optional field, and it's up to you to decide what information to provide.
* **Participant Information (Repeat)**: This field is the same as the first participant information field, but it's repeated for any additional participants. This is an optional field, and you can skip it if you're the only participant.
* **Script Details (Repeat)**: This field is the same as the first script details field, but it's repeated for any additional participants. This is an optional field, and you can skip it if you're the only participant.
* **Participant Signature (Repeat)**: This field is the same as the first participant signature field, but it's repeated for any additional participants. This is an optional field, and you can skip it if you're the only participant.
* **Participant Approval (Repeat)**: This field is the same as the first participant approval field, but it's repeated for any additional participants. This is an optional field, and you can skip it if you're the only participant.
* **Script Reading Session Notes (Repeat)**: This field is the same as the first script reading session notes field, but it's repeated for any additional participants. This is an optional field, and you can skip it if you're the only participant.
* **Form End**: This is the final step to complete the form. It's not a field that requires any information, it's just a way to mark the end of the form.

## Tips

* Make sure to fill in all the required fields, especially the participant information, participant signature, and participant approval fields.
* If you're an additional participant, make sure to fill in the participant information (repeat), participant signature (repeat), and participant approval (repeat) fields.
* Double-check your participant approval to ensure that you've given your consent to the recording.
* You can add any additional notes or comments about the script reading session, but it's up to you to decide what information to provide.
* This form is designed to be completed by participants, so make sure to fill it in honestly and accurately.
