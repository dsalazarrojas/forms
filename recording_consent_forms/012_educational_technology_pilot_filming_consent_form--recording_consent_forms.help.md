# educational-technology-pilot-filming-consent-form - Help Guide
## Purpose
This form is used to collect information and consent for the filming of an educational technology pilot. It's a necessary step to ensure that participants or users are aware of the project's goals, methods, and expectations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form description to understand the purpose and goals of the pilot.
2. Select the correct category for your response (if applicable).
3. Fill out all required fields, including the form title, description, and form ID.
4. Provide additional descriptions for the category as needed.
5. Optionally, provide an assigned tool and category label, name, description, keywords, image, and status.

## Field-by-Field Explanation

* **Category** (`Category`, `select_one`, required): Select the category that this educational technology pilot falls under. This is an important field as it helps us to categorize and track the progress of the pilot.
* **Form Title** (`Form Title`, `text`, required): Enter a brief title for this educational technology pilot. This title should accurately reflect the project's goals and objectives.
* **Description** (`Description`, `text`, required): Provide a detailed description of the educational technology pilot, including its goals, methods, and expected outcomes.
* **Form ID** (`Form ID`, `number`, required): Enter a unique ID for this form, which will be used to identify and track the pilot.
* **Assigned Tool** (`Assigned Tool`, `text`, optional): If applicable, provide the name of the tool or technology being piloted.
* **Category Label** (`Category Label`, `text`, optional): Enter a label for the category this pilot falls under.
* **Category Name** (`Category Name`, `text`, optional): Enter the name of the category this pilot falls under.
* **Category Description** (`Category Description`, `text`, optional): Provide a brief description of the category this pilot falls under.
* **Category Keywords** (`Category Keywords`, `text`, optional): Enter keywords related to this category for better searchability.
* **Category Image** (`Category Image`, `text`, optional): Provide an image for the category this pilot falls under.
* **Category URL** (`Category URL`, `text`, optional): Enter a URL related to this category.
* **Category External URL** (`Category External URL`, `text`, optional): Provide an external URL related to this category.
* **Category Status** (`Category Status`, `text`, optional): Enter the status of the category this pilot falls under.
* **Category Featured Image** (`Category Featured Image`, `text`, optional): Upload an image for the category this pilot falls under.
* **Category Featured Image Alt** (`Category Featured Image Alt`, `text`, optional): Enter a short description for the category's featured image.
* **Category Featured Image Position** (`Category Featured Image Position`, `select_one`, optional): Choose where the category's featured image should be displayed.
* **Description 1** (`Description 1`, `text`, optional): Provide an additional description for the category as needed.
* **Description 2** (`Description 2`, `text`, optional): Enter another description for the category as needed.
* **Description 3** (`Description 3`, `text`, optional): Provide a third description for the category as needed.
* **Description 4** (`Description 4`, `text`, optional): Enter a fourth description for the category as needed.
* **Description 5** (`Description 5`, `text`, optional): Provide a fifth description for the category as needed.
* **Description 6** (`Description 6`, `text`, optional): Enter a sixth description for the category as needed.
* **Description 7** (`Description 7`, `text`, optional): Provide a seventh description for the category as needed.
* **Description 8** (`Description 8`, `text`, optional): Enter an eighth description for the category as needed.
