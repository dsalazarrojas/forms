# Single Release Form - Help Guide
## Purpose
The Single Release Form is used to record permission and other necessary information for a project release.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine the contributor's permission status by selecting one of the three options:
	* Contributor Permission: Contributor has given permission
	* Contributor Permission: Contributor has not given permission
	* Contributor Permission: Permission pending
2. Enter the contributor's name in the text field.
3. Enter the contributor's email address in the email field.
4. Select the project owner's name from the text field.
5. Enter the project owner's email address in the email field.
6. Enter the project owner's phone number in the text field.
7. Enter the project owner's signature in the text field.
8. Enter any additional comments from the contributor in the text field.
9. Enter any additional comments from the project owner in the text field.

## Field-by-Field Explanation

* **Contributor Permission** (`contributor_permission`, select_one, required: false):
	+ This field requires you to select the contributor's permission status.
* **Contributor Name** (`contributor_name`, text, required: false):
	+ Enter the contributor's name.
* **Contributor Email** (`contributor_email`, email, required: false):
	+ Enter the contributor's email address.
* **Project Owner Name** (`project_owner_name`, text, required: false):
	+ Enter the project owner's name.
* **Project Owner Email** (`project_owner_email`, email, required: false):
	+ Enter the project owner's email address.
* **Project Owner Phone** (`project_owner_phone`, text, required: false):
	+ Enter the project owner's phone number.
* **Project Owner Signature** (`project_owner_signature`, text, required: false):
	+ Enter the project owner's signature.
* **Contributor Permission Comment** (`contributor_permission_comment`, text, required: false):
	+ Enter any additional comments from the contributor.
* **Project Owner Permission Comment** (`project_owner_permission_comment`, text, required: false):
	+ Enter any additional comments from the project owner.

## Tips

* Please ensure that you select the correct contributor permission status and enter accurate contact information for both the contributor and project owner.
* If a contributor has not given permission, please include a note explaining the reason for their permission status.
* This form is for recording permission and information only, and should not be used for other purposes.
