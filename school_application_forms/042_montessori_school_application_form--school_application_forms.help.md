# Montessori School Application Form - Help Guide
## Purpose
This form is designed to collect necessary information from prospective students' parents or guardians to facilitate their enrollment into the Montessori School.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out the required fields with accurate information.
2. Review each field carefully and ensure you are providing the correct information.
3. If you need help with any field, please refer to the Field-by-Field Explanation section below.

## Field-by-Field Explanation

* **First Name (required)**: Please enter your child's first name. This is a required field.
* **Last Name (required)**: Please enter your child's last name. This is a required field.
* **Date of Birth (required)**: Enter the child's date of birth. This is a required field.
* **Address (optional)**: If you want to provide your home address, please enter it here. This field is not required.
* **Contact Number (optional)**: If you want to provide your contact number, please enter it here. This field is not required.
* **Email Address (required)**: Enter your email address. This is a required field.
* **Parental Consent (required)**: Please select one of the options: "I give my consent for my child to attend this school" or "I do not give my consent for my child to attend this school." This is a required field.
* **Emergency Contact Name (optional)**: If you want to provide the name of an emergency contact person, please enter it here. This field is not required.
* **Emergency Contact Relationship (optional)**: If you want to specify the relationship between the emergency contact and your child, please enter it here. This field is not required.
* **Emergency Contact Number (optional)**: If you want to provide the contact number of the emergency contact, please enter it here. This field is not required.
* **Medical Conditions (optional)**: If your child has any medical conditions, such as Diabetes, Asthma, or Allergies, please select all applicable conditions. This field is not required.
* **School Attended (required)**: Please select the name of the school your child is currently attending or has attended. This is a required field.
* **Contact Method (optional)**: If you have a preferred contact method (e.g., phone, email, or in-person), please select it. This field is not required.
* **Notes (optional)**: If you have any additional comments or information about your child, please enter it here. This field is not required.
