# school_admission_form - Help Guide
## Purpose
The school admission form is a crucial document used for student registration and admission to a school. It is used to gather essential information about the student, such as their personal details, contact information, and demographic data. This form is typically filled out by students or their parents/guardians and is a necessary step in the admission process.

## How To Complete This Form

To complete the school admission form successfully, please follow these steps:

1. Fill out the form in the following order: New School, Student Name, Email, Phone, Date Of Birth, Parent Name, Student Address, Guardian Name, Guardian Phone, Student School Name, Student Class, Student Level, Student Gender, Parent Signature, Student Signature, Parent Email, Student Date Of Admission, Student Start Date, Student Grade, Student Language, Student Nationality, Student Height, Student Weight, Student Height Unit, Student Document ID, Guardian Document ID, Student Parent Guardian Name, Student Parent Guardian Phone, Student Parent Guardian Email, and Student Remarks.
2. Enter the correct information in each field as per your knowledge and availability.
3. Review your form carefully before submitting it to ensure that all required fields are filled out correctly.

## Field-by-Field Explanation

* **New School** (`text`, required: false): Enter the name of the new school the student is applying to.
* **Student Name** (`text`, required: true): Enter the student's full name as it appears on their official documents.
* **Email** (`email`, required: false): Enter the student's email address, if applicable.
* **Phone** (`text`, required: false): Enter the student's phone number, if applicable.
* **Date Of Birth** (`date`, required: true): Enter the student's date of birth in the format dd/mm/yyyy.
* **Parent Name** (`text`, required: false): Enter the name of the student's parent/guardian.
* **Student Address** (`text`, required: false): Enter the student's home address.
* **Guardian Name** (`text`, required: false): Enter the name of the student's parent/guardian.
* **Guardian Phone** (`text`, required: false): Enter the phone number of the student's parent/guardian.
* **Student School Name** (`text`, required: false): Enter the name of the school the student is currently attending or has attended.
* **Student Class** (`select_one`, required: true): Select the student's class (e.g., Class 1, Class 2).
* **Student Level** (`select_one`, required: true): Select the student's level (e.g., 5, 6).
* **Student Gender** (`select_one`, required: true): Select the student's gender (e.g., Male, Female).
* **Parent Signature** (`note`, required: true): Sign with the parent's/guardian's signature to confirm their consent.
* **Student Signature** (`note`, required: true): Sign with the student's signature to confirm their consent.
* **Parent Email** (`email`, required: false): Enter the parent's/guardian's email address, if applicable.
* **Student Date Of Admission** (`date`, required: true): Enter the date the student will start attending the school in the format dd/mm/yyyy.
* **Student Start Date** (`date`, required: true): Enter the date the student will start attending the school in the format dd/mm/yyyy.
* **Student Grade** (`select_one`, required: true): Select the student's grade (e.g., Grade 1, Grade 2, Grade 3).
* **Student Language** (`select_one`, required: true): Select the student's native language (e.g., English, Spanish, French).
* **Student Nationality** (`select_one`, required: true): Select the student's nationality (e.g., American, Chinese, Indian).
* **Student Height** (`number`, required: true): Enter the student's height in centimeters (e.g., 150, 160).
* **Student Weight** (`number`, required: true): Enter the student's weight in kilograms (e.g., 40, 50).
* **Student Height Unit** (`select_one`, required: true): Select the unit of measurement for the student's height (e.g., feet, inches).
* **Student Document ID** (`text`, required: true): Enter the student's ID number or any other identification number assigned by the school or government.
* **Guardian Document ID** (`text`, required: true): Enter the guardian's ID number or any other identification number assigned by the school or government.
* **Student Parent Guardian Name** (`text`, required: true): Enter the name of the student's parent/guardian.
* **Student Parent Guardian Phone** (`text`, required: true): Enter the phone number of the student's parent/guardian.
* **Student Parent Guardian Email** (`email`, required: true): Enter the email address of the student's parent/guardian.
* **Student Remarks** (`text`, required: true): Enter any additional remarks or comments about the student.
* **Student Parent Signature** (`note`, required: true): Sign with the parent's/guardian's signature to confirm their consent.
* **Student Signature** (`note`, required: false): Sign with the student's signature, if required by the school.
* **Student DOB** (`date`, required: true): Enter the student's date of birth in the format dd/mm/yyyy.
* **Student Start Date** (`date`, required: true): Enter the date the student will start attending the school in the format dd/mm/yyyy.

Note: Please ensure that all fields are filled out correctly and accurately before submitting the form.
