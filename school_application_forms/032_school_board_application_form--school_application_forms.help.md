# School Board Application Form - Help Guide
## Purpose
The School Board Application Form is used to collect and store information about a school's board of directors application. This form is typically used by the school staff to submit applications for the school board's review.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **School Board Form Data** field (ID 1) with the relevant information.
2. Upload any necessary documents in the **School Board Form Uploads** field (ID 2).
3. Add your signature in the **School Board Form Signature** field (ID 3) and select the date in the **School Board Form Date** field (ID 10).
4. Provide any additional information or notes in the **School Board Form Notes** field (ID 4).
5. Enter your email address in the **School Board Form Email** field (ID 5).
6. Provide your phone number in the **School Board Form Phone** field (ID 6).
7. Enter your address in the **School Board Form Address** field (ID 7).
8. Select the category for the application (ID 12).
9. Select whether you were served by the board (ID 16).
10. Select whether you have any notes to add for the board (ID 17, 18, and 19).
11. Finally, submit the form.

## Field-by-Field Explanation

* **School Board Form Data** (ID 1, text, required: false): Enter a brief description of the application or any relevant information about the school board.
* **School Board Form Uplods** (ID 2, text, required: false): Upload any supporting documents for your application.
* **School Board Form Signature** (ID 3, date, required: false): Add your signature to the application.
* **School Board Form Notes** (ID 4, note, required: false): Add any additional information or notes for the board.
* **School Board Form Email** (ID 5, email, required: false): Enter your email address.
* **School Board Form Phone** (ID 6, text, required: false): Enter your phone number.
* **School Board Form Address** (ID 7, text, required: false): Enter your address.
* **School Board Form Teacher 1 Name** (ID 8, text, required: false): Enter the name of the teacher 1.
* **School Board Form Teacher 2 Name** (ID 9, text, required: false): Enter the name of the teacher 2.
* **School Board Form Date** (ID 10, date, required: false): Select the date for the application.
* **School Board Form Time** (ID 11, time, required: false): Select the time for the application.
* **School Board Form Category** (ID 12, select multiple, required: false): Select one or more categories for the application.
* **School Board Form Submtitted By** (ID 13, select one, required: false): Select whether you were served by the board.
* **School Board Form Status** (ID 14, select one, required: false): Select the status of the application.
* **School Board Form School Board** (ID 15, select one, required: false): Select whether you are part of the school board.
* **School Board Form Served By** (ID 16, select one, required: false): Select whether you were served by the board.
* **School Board Form Notes 1** (ID 17, select one, required: false): Select whether you have any notes to add.
* **School Board Form Notes 2** (ID 18, select one, required: false): Select whether you have any notes to add.
* **School Board Form Notes 3** (ID 19, select one, required: false): Select whether you have any notes to add.
