# Private School Referral Form - Help Guide
## Purpose
This guide will walk you through the private school referral form to ensure you complete it accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the student's first name, last name, and email address.
2. Provide the student's grade level.
3. Enter the student's ID number and the school's ID number.
4. Fill in the referrer's name, phone number, email address, and any additional contact information (address, city, state, and zip code) if available.
5. Briefly describe the reason for the referral.
6. If you know the school, provide the school's name, address, city, state, and zip code.
7. Finally, add any follow-up message or additional comments.

## Field-by-Field Explanation

* **First name** (First name, text, required): Enter the student's first name.
* **Last name** (Last name, text, required): Enter the student's last name.
* **Email** (Email, email, required): Enter the student's email address.
* **Phone** (Phone, text, required): Enter the student's phone number.
* **Grade Level** (Grade Level, number, required): Enter the student's grade level.
* **Student ID** (Student ID, text, required): Enter the student's ID number.
* **School ID** (School ID, text, required): Enter the school's ID number.
* **Referrer Name** (Referrer Name, text, required): Enter the name of the individual referring the student.
* **Referrer Phone** (Referrer Phone, text, required): Enter the referrer's phone number.
* **Referrer Email** (Referrer Email, email, required): Enter the referrer's email address.
* **Referrer Address** (Referrer Address, text, optional): Enter the referrer's address if available.
* **Referrer City** (Referrer City, text, optional): Enter the referrer's city if available.
* **Referrer State** (Referrer State, text, optional): Enter the referrer's state if available.
* **Referrer Postal Code** (Referrer Zip, text, optional): Enter the referrer's zip code if available.
* **School Name** (School Name, text, required): Enter the name of the school being referred.
* **School Address** (School Address, text, required): Enter the school's address.
* **School City** (School City, text, required): Enter the school's city.
* **School State** (School State, text, required): Enter the school's state.
* **School Postal Code** (School Zip, text, required): Enter the school's zip code.
* **Reason for Referral** (Reason for Referral, text, required): Briefly describe the reason for the referral.
* **How did you know school** (How did you know school, text, optional): If you have any additional information about how you know the school, please provide it.
* **School Website** (School Website, text, optional): Enter the school's website if available.
* **School Contact Person** (School Contact Person, text, optional): Enter the name of the school contact person if available.
* **Follow up Message** (Follow up Message, text, optional): Provide any follow-up comments or questions.
* **Referrer Signature** (Referrer Signature, text, optional): Enter your name and signature.

Note: The referrer's name, phone, and email are required fields. If you are unsure about any of the fields, contact us for clarification.
