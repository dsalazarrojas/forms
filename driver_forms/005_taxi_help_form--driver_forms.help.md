# Taxi Help Form - Help Guide
## Purpose
The Taxi Help Form is designed to gather essential details about taxi-related requests, issues, and resolution processes. It helps taxi service providers, customer support, and technical teams stay organized and on the same page.

## How To Complete This Form
- Read the form carefully and ensure you have all the necessary information before starting to fill it out.
- If you're unsure about any field, refer to the Field-by-Field Explanation section for clarification.
- Complete each section thoroughly and accurately, providing details that support issue resolution.

## Field-by-Field Explanation

* **Form Submission** (`form_submission`): A text box where you can enter your taxi-related query, issue, or feedback. Provide a clear and concise description of the problem or request.
* **Service Issue** (`service_issue`): Enter a brief description of the specific service issue or problem you're experiencing.
* **Problem Description** (`problem_description`): Provide an in-depth explanation of the problem or issue, including any relevant details that may help in resolving it.
* **Service Request** (`service_request`): Enter a brief description of the service request or action required.
* **Service Request Description** (`service_request_description`): Explain the specific service request or action, including any supporting details.
* **Assigned Rep** (`assigned_rep`): Select 'Yes' if you've assigned a representative to handle the issue, or 'No' otherwise.
* **Issue Resolution Status** (`issue_resolution_status`): Select the current status of the issue resolution, whether it's 'Active', 'Inactive', or another status.
* **Follow-up Status** (`follow_up_status`): Select the follow-up status, whether it's 'Active' or 'Inactive'.
* **Follow-up Comment** (`follow_up_comment`): Enter any additional comments or updates regarding the follow-up.
* **Follow-up Action** (`follow_up_action`): Select 'Yes' if follow-up actions are required or 'No' otherwise.
* **Assigned Tool** (`assigned_tool`): Enter any specific tool or resource assigned to handle the issue.
* **Created By** (`created_by`): Select 'Yes' if you're the creator of the form submission, or 'No' otherwise.
* **Submitted By** (`submitted_by`): Select 'Yes' if the issue was submitted by someone else, or 'No' otherwise.
* **Created Date** (`created_date`): The date when the form was created.
* **Submitted Date** (`submitted_date`): The date when the issue was submitted.
* **Service Level** (`service_level`): Select the service level, whether it's 'High' or 'Low'.
* **Issue Status** (`issue_status`): Select the current status of the issue, whether it's 'Active' or 'Inactive'.
* **Submitted Time** (`submitted_time`): The time when the issue was submitted.
* **Follow-up Time** (`follow_up_time`): The time when follow-up actions are scheduled.
* **Submitted Hour** (`submitted_hour`): Select 'Yes' if the issue was submitted during a specific hour.
* **Submitted Day** (`submitted_day`): Select 'Yes' if the issue was submitted on a specific day.
* **Submitted Month** (`submitted_month`): Select 'Yes' if the issue was submitted on a specific month.
* **Submitted Year** (`submitted_year`): Select 'Yes' if the issue was submitted on a specific year.
