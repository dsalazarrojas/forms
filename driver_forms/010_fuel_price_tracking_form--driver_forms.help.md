# Fuel Price Tracking Form - Help Guide
## Purpose
This form is intended to collect user input for tracking fuel prices.

## How To Complete This Form
1. Fill out the **Fuel Type** field by selecting the type of fuel from the available options (Diesel, Petrol, or Hydrogen).
2. Input the **Date** of the price collection using the date field. This field is a calendar-based input field for ease of use.
3. Enter the **Price** of the fuel in the designated field.

## Field-by-Field Explanation
* **Fuel Type (Diesel, Petrol, or Hydrogen)**: Select the type of fuel for which you are tracking the price.
* **Date**: Enter the date for which you are tracking the price. This is a date picker field for selecting the date of price collection.
* **Price**: Enter the price of the fuel.

## Tips
- Please input the price in the correct format to avoid errors.
- Make sure to select the correct fuel type for accurate tracking.
