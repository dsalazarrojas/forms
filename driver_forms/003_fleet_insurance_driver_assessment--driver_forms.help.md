# Fleet Insurance Driver Assessment - Help Guide
## Purpose
The Fleet Insurance Driver Assessment form is designed to collect information from drivers to assess their eligibility for fleet insurance coverage.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing your driver details.
2. Select your driving experience and any relevant incident history.
3. Specify your vehicle type.

## Field-by-Field Explanation
### Driver Details (Required: Optional)
* **Driver Details**: This field is for your name and any other identifying information.

### Driving Experience (Optional)
* **Driving License**: If you're a new driver or have a restricted license, this is where you can indicate you have a valid license.
* **Fleet Driver**: If you drive for a fleet, this option is applicable to you.
* **Commercial Driver**: If you drive for a commercial fleet, such as a delivery or moving company, choose this option.
* **Private Driver**: If you drive a private vehicle for personal use, select this option.
* **Delivery Driver**: If you drive for a delivery service, choose this option.

### Incident History (Optional)
* **Accident**: If you've been involved in an accident while driving, choose this option.
* **Injury**: If you've been injured while driving, choose this option.
* **Fatality**: If you've been involved in a fatal incident while driving, choose this option.

### Vehicle Details (Optional)
* **Car**: If you drive an ordinary car, choose this option.
* **Truck**: If you drive a truck, select this option.
* **Motorcycle**: If you drive a motorcycle, choose this option.
