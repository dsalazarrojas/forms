**Purpose**
----------

The Driver Performance Quarterly Report Form is used to record and document the performance of drivers during a specific quarter. This form is used to collect information about the driver's performance, including their performance score, review date, and comments from both the driver and their supervisor. The form is an essential tool for evaluating and improving driver performance.

**How To Complete This Form**

To complete the form, follow these steps:

1.  Fill in the driver's name in the "Driver Name" field.
2.  Select the relevant quarter from the "Performance Quarter" dropdown menu.
3.  Enter the review date in the "Review Date" field.
4.  Enter the driver's performance score in the "Performance Score" field.
5.  Provide a brief description of the driver's performance in the "Performance Comments" field.
6.  Enter the supervisor's name in the "Supervisor Name" field.
7.  Enter the supervisor's comments in the "Supervisor Comments" field.

**Field-by-Field Explanation**

* **Driver Name** (`driver_name`, text, required): Enter the name of the driver being reviewed.
* **Performance Quarter** (`performance_quarter`, select_one, required): Select the quarter in which the performance review is taking place (1, 2, 3, or 4).
* **Review Date** (`review_date`, date, optional): Enter the date of the performance review.
* **Performance Score** (`performance_score`, number, required): Enter the performance score, which is a numerical value that represents the driver's performance.
* **Performance Comments** (`performance_comments`, text, optional): Enter a brief description of the driver's performance.
* **Supervisor Name** (`supervisor_name`, text, required): Enter the name of the supervisor conducting the performance review.
* **Supervisor Comments** (`supervisor_comments`, text, optional): Enter the supervisor's comments about the driver's performance.
