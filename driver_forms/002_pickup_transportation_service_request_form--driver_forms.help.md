# pickup_transportation_service_request_form - Help Guide
## Purpose
The pickup transportation service request form is used for arranging transportation services, and is intended for both drivers and riders to be able to use it easily without needing to know how to code.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category that best describes your role in the transportation service (Driver or Rider).
2. Enter a brief description of the service you need to arrange, such as "pick up from home" or "drop off at airport".
3. If you are a driver, select the tools you are using to fulfill the ride request (chatjimmy, chatjim, or other).
4. Review your entries for accuracy and submit the form.

## Field-by-Field Explanation
* **Category** (required, Driver Forms/Rider Forms):
	+ This field asks you to select whether you are a driver or rider, so that the system can direct your request to the right person or service.
* **Description** (optional, text):
	+ This field is where you enter a brief description of the transportation service you need to arrange, such as "pick up from home" or "drop off at airport".
* **Assigned Tool** (optional, chatjimmy, chatjim, other):
	+ If you are a driver, select the tools you will be using to fulfill the ride request.
* **Pickup Transportation Service Request Form** (required, text):
	+ This field is not actually a field, but is the form name, so it's not something to fill in as it's just a label, however it's worth mentioning as it's the main title of the form.

## Tips
- Please make sure to select the correct category for your role.
- Enter a clear and concise description of your transportation needs.
- Select the correct tools if you are a driver.
- Review your entries before submitting the form to ensure accuracy. 

Please note that the "Pickup Transportation Service Request Form" is not a field, but the form's title, and should not be filled in.

Note: The form's description is not actually used as it's not a field in the form, but rather a hint to guide users through the form's purpose.
