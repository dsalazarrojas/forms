# Female Cab Driver Survey - Help Guide
## Purpose
The Female Cab Driver Survey is designed to collect information from female cab drivers to gather insights on their experiences and characteristics.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read through each question carefully and answer all required fields.
2. Select the options that best apply to your situation.
3. If you have any additional comments or information, please use the "Comments" field.

## Field-by-Field Explanation

* **Introduction** (`introduction`, note, optional): This is a brief introduction to the survey. Please read through it carefully before proceeding.
* **Demographics** (`demographics`, select_one, optional): Please select whether you identify as Male, Female, or Other.
* **Driver Information** (`driver_info`, text, optional): Please provide some information about yourself as a cab driver.
* **Driving History** (`driving_history`, time, optional): Please select the number of years you have been driving.
* **Vehicle Information** (`vehicle_info`, select_multiple, optional): Please select the type(s) of vehicles you drive.
* **Hours Worked** (`work_hours`, select_one, optional): Please select the range of hours you typically work.
* **Income** (`income`, number, optional): Please enter your monthly income.
* **Tips** (`tips`, number, optional): Please enter any tips you receive.
* **Vehicle Type** (`vehicle_type`, select_one, optional): Please select the type of vehicle you drive.
* **Comments** (`comments`, note, optional): This is a field for any additional comments or information.
* **Gender** (`gender`, select_one, optional): Please select whether you identify as Male, Female, or Other.

Note: All fields are optional unless marked as required.
