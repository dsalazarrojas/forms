# D1_Driver_Application_Form - Help Guide
## Purpose
The D1_Driver_Application_Form is used to input information related to a driver's application, including their license number, address, and phone number.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the "Driver Application" field, which is the main description of the driver's application.
2. Next, select the correct D1 license number from the options provided.
3. Enter the driver's address in the "address" field.
4. Finally, input the driver's phone number in the "Phone Number" field.

## Field-by-Field Explanation
* **Driver Application** (`driver_application`, text, required/optional): A brief description of the driver's application. Please enter a short explanation of why the driver is applying.
* **D1 License Number** (`d1_license`, select_one, required/optional): Select the correct D1 license number from the options provided.
* **Address** (`address`, text, required/optional): Enter the driver's address.
* **Phone Number** (`phone_number`, text, required/optional): Input the driver's phone number.
