# Template Troop Initial Cookie Orders - Help Guide
## Purpose
The Template Troop Initial Cookie Orders form is used to collect information for the troop's annual event preparations. This includes basic contact details and scheduling requirements for the event.

## How To Complete This Form
To fill out this form, please follow these steps:

1. Fill in the following fields:
   - First Name
   - Last Name
   - Email
   - Phone (optional)

Note: Email is required to ensure accurate communication and notifications for event updates.

2. Select a date and time for your event. The date field is designed to select a date in the format of YYYY-MM-DD.
3. Add any additional notes or comments you'd like to share with the event organizers.
4. If applicable, choose your preferred options for "Select One" and "Select Multiple" by clicking the respective radio buttons. These fields are designed to be optional.

## Field-by-Field Explanation
* **First Name** (`user_input_1`, text, optional): Enter your first name as you would like it to be displayed for communication purposes.
* **Last Name** (`user_input_2`, text, optional): Enter your last name as you would like it to be displayed for communication purposes.
* **Email** (`user_input_3`, email, required): A valid email address is necessary for the event organizers to contact you with updates and information.
* **Phone** (`user_input_4`, text, optional): Provide your phone number for additional contact methods.
* **Date** (`user_input_5`, date, optional): Enter the date for the event, in the format YYYY-MM-DD.
* **Time** (`user_input_6`, time, optional): Select the time for the event. Note that this field is a separate entity from the date, as the event organizers will consider these fields separately.
* **Note** (`user_input_7`, note, optional): Add any additional notes or comments for the event organizers to consider.
* **Select One** (`user_input_8`, select one, optional): Select 'Yes' if you have a preference for this option.
* **Select Multiple** (`user_input_9`, select multiple, optional): Select multiple options if you have multiple preferences for these options.
