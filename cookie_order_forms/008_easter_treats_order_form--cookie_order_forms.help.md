# easter_treats_order_form - Help Guide
## Purpose
The easter_treats_order_form is designed to collect information for event or party planning purposes, specifically for ordering Easter treats.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the desired text for the Easter treats order form.
2. Select the date on which the event is scheduled to take place.
3. Choose the time for the event.

## Field-by-Field Explanation

* **easter_treats_order_form** (`title`, `text`, optional): This is the main text field where you can enter any relevant information about the Easter treats order form.
* **easter_treats_order_form_date** (`label`, `date`, optional): Enter the date on which the Easter treats event is scheduled to take place.
* **easter_treats_order_form_time** (`label`, `time`, optional): Choose the time for the Easter treats event.

## Tips

- Make sure to enter the correct date and time to ensure accurate planning.
- Double-check the text field for any specific instructions or details about the order.
