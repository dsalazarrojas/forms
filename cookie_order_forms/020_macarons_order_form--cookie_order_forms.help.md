# Macarons Order Form - Help Guide
## Purpose
The Macarons Order Form is designed to collect customer information and order details for macaron orders.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter your customer name in the "Customer Name" field.
2. Select the desired macaron size from the options provided in the "Macaron Size" field.
3. Select the type of macaron you would like to order (e.g., Vanilla, Chocolate, Fruit) in the "Macaron Type" field.
4. Enter the quantity of macarons you would like to order in the "Macarons Quantity" field.
5. If you have a valid email address, enter it in the "Email" field.
6. Enter your phone number in the "Phone" field.
7. If you have a specific date for the order, enter it in the "Order Date" field.
8. If you have a specific time for the order, enter it in the "Order Time" field.
9. Enter any special instructions for your order in the "Macarons Special Instructions" field.

## Field-by-Field Explanation

* **Customer Name (Customer Name, text, required: false)**: Enter your name to help us identify you in our records.
* **Macaron Size (Macaron Size, select_one, required: false)**: Choose the size of macaron you would like to order. Options: 4, 6, 8, 10.
* **Macaron Type (Macaron Type, select_multiple, required: false)**: Select the type of macaron you would like to order. Options: Vanilla, Chocolate, Fruit.
* **Macarons Quantity (Macarons Quantity, number, required: false)**: Enter the number of macarons you would like to order.
* **Email (Email, email, required: false)**: If you have a valid email address, enter it to help us contact you.
* **Phone (Phone, text, required: false)**: Enter your phone number to help us contact you.
* **Order Date (Order Date, date, required: false)**: If you have a specific date for the order, enter it.
* **Order Time (Order Time, time, required: false)**: If you have a specific time for the order, enter it.
* **Note (Note, note, required: false)**: Enter any special comments or requests for your order.
* **Macarons Special Instructions (Macarons Special Instructions, text, required: false)**: Enter any special instructions for your order.
