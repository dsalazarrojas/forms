# Villa La Nuvola - Help Guide
## Purpose
The Villa La Nuvola form is a tool designed to help users manage and track information related to the "Villa La Nuvola" entity. It allows users to input and store data in a structured way.

## How To Complete This Form
To complete this form, follow these steps:

1.  Navigate through the form pages to input data in the required fields.
2.  For each page, fill in the requested information.
3.  Click "Submit" to save and complete the form.

## Field-by-Field Explanation
- **First Page (form_1_page)**: This page is the initial step in the form, providing a space to input general information.
- **Customer Information (form_2_page)**: Select the customer for which the data is being entered. Choose one of the three available options: "Customer 1", "Customer 2", or "Customer 3".
- **Shipping Address (form_3_page)**: Enter the shipping address associated with the selected customer. This should include the full address information.
- **Order Date (form_4_page)**: Enter the date for the order. This field is designed to capture a date in a standard format (YYYY-MM-DD).
- **Total Price (form_5_page)**: Input the total price for the order. This field is for numerical data, such as prices or quantities.
