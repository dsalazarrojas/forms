# School Play Costumes Pre Order Form - Help Guide
## Purpose
The School Play Costumes Pre Order Form is used to gather information from students and parents for school play costumes. Fill out this form if you have been assigned a role in the school play and would like to pre-order your costume.

## How To Complete This Form
- Click on the "Submit" button to save your entries
- Fill out the form with accurate and complete information

## Field-by-Field Explanation
- **School Play Costumes** (`school_play_costumes_pre_order_form_first_page`): This field is the title of the form. Please do not change it.
- **Student Name** (`student_name`): Enter the student's name as it appears on their student ID or in the school records.
- **Name Hint** (`student_name_hint`): This field is optional and can be used to provide more information about the student's name.
- **Parent Name** (`parent_name`): Enter the parent's name and contact information.
- **Parent Email** (`parent_email`): Enter the parent's email address.
- **Student Email** (`student_email`): Enter the student's email address.
- **Costume Type** (`school_play_costume_type`): Select the type of costume you would like to order.
- **Delivery Preference** (`delivery_preference`): Select your preferred delivery method (if applicable).
- **Special Requests** (`special_requests`): Enter any special requests or messages you would like to share with the costume team.
- **Student Grade** (`student_grade`): If applicable, enter the student's grade level.
- **Class** (`student_class`): Enter the student's class.
- **Section** (`student_section`): If applicable, select the student's section.
- **T-Shirt Size** (`student_tshirt_size`): Select the size of the T-shirt you would like to order.
- **Can Speak** (`student_speech`): If applicable, select whether the student can speak on stage.
- **Payment Method** (`payment_method`): Select the payment method you would like to use (e.g., Cash, Card).
- **Payment Amount** (`payment_amount`): Enter the payment amount.
- **Payment Date** (`payment_date`): Enter the payment date.
- **Notes** (`notes`): Enter any notes or comments for the costume team.
- **Notes Hint** (`notes_hint`): This field is optional and can be used to provide more information about the notes.
- **Tutor** (`student_tutor`): If applicable, select whether the student has a tutor.
- **Language** (`student_language`): If applicable, select the student's language.
- **Costume Type Hint** (`school_play_costume_type_hint`): This field is optional and can be used to provide more information about the costume type.
- **Costume Type 2 Hint** (`school_play_costume_type_2_hint`): This field is optional and can be used to provide more information about the costume type 2.
- **Costume Type 3 Hint** (`school_play_costume_type_3_hint`): This field is optional and can be used to provide more information about the costume type 3.
- **Costume Type 4 Hint** (`school_play_costume_type_4_hint`): This field is optional and can be used to provide more information about the costume type 4.

## Tips
- Please fill out the form accurately and completely to ensure that the costume is delivered correctly and on time.
- Review your entries before submitting the form to avoid mistakes.
- If you have any questions or concerns, contact the costume team directly.
