# Good Hart By Matilda Jane February Pre Order - Help Guide

## Purpose
The Good Hart By Matilda Jane February Pre Order form is designed to collect user information for the pre-order event. It is used to gather details such as name, email, phone number, and other specifics to prepare for the event.

## How To Complete This Form

To complete this form, follow the steps below:

1. Enter your name in the `Name` field.
2. Enter your email address in the `Email` field. Please use a format similar to `john@example.com`.
3. Enter your phone number in the `Phone` field.
4. Select the date you would like to pick up your pre-ordered product in the `Date` field.
5. Select the time you would like to pick up your pre-ordered product in the `Time` field.
6. Select one option from the `Select One` dropdown menu.
7. Enter a decimal value in the `Decimal` field, if applicable.
8. Enter an integer value in the `Integer` field, if applicable.
9. Enter text in the `Text` field, if applicable.
10. Select a date range, if applicable, in the `Date Range` field.

## Field-by-Field Explanation
* **February Pre Order** (`preorder_form`, note, not required): This is the title of the form.
* **Name** (`name`, text, not required): Enter your name to help us prepare for the event.
* **Email** (`email`, email, not required): Enter your email address in the format `john@example.com`.
* **Phone** (`phone`, text, not required): Enter your phone number.
* **Date** (`date`, date, not required): Select the date you would like to pick up your pre-ordered product.
* **Time** (`time`, time, not required): Select the time you would like to pick up your pre-ordered product.
* **Select Multiple** (`select_multiple`, select multiple, not required): Select all the applicable options to help us prepare for the event.
* **Select One** (`select_one`, select one, required): Select one option from the dropdown menu.
* **Decimal** (`decimal`, number, not required): Enter a decimal value if applicable.
* **Integer** (`integer`, number, not required): Enter an integer value if applicable.
* **Text** (`text`, text, not required): Enter text in this field if applicable.
* **Date Range** (`date_range`, text, not required): Enter a date range if applicable.
