# scentsy-nightmare-before-christmas-and-disney-villain-pre-order - Help Guide
## Purpose
The purpose of this form is to collect information from customers to place pre-orders for Christmas-themed items or Disney-themed items with a horror or villainous twist, such as figurines or collectibles.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the options that apply to your order:
	* Nightmare Before Christmas: Select 'Yes' if you want to order Christmas items with a horror or dark twist.
	* Disney Villains: Select 'Yes' if you want to order Disney-themed items with a villainous twist.
2. Fill in your contact information:
	* First Name: Type in your first name as it appears on your identification.
	* Last Name: Type in your last name as it appears on your identification.
3. Enter your contact information:
	* Email: Type in your valid email address.
	* Phone: Type in your phone number.
4. Choose a date and time for delivery:
	* Date: Select a date for delivery.
	* Time: Select a time for delivery.
5. Add any additional notes:
	* Notes: Provide any additional information about your order, such as special requests or instructions.

## Field-by-Field Explanation
* **Nightmare Before Christmas** (nmbf, Select Multiple)
	+ This field allows you to select all Christmas items with a horror or dark twist.
* **Disney Villains** (disney_villains, Select One)
	+ This field allows you to select Disney-themed items with a villainous twist.
* **First Name** (first_name, Text)
	+ This is a field to type in your first name.
* **Last Name** (last_name, Text)
	+ This is a field to type in your last name.
* **Email** (email, Email)
	+ This is a field to type in a valid email address.
* **Phone** (phone, Text)
	+ This is a field to type in your phone number.
* **Date** (date, Date)
	+ This is a field to select a date for delivery.
* **Time** (time, Time)
	+ This is a field to select a time for delivery.
* **Notes** (note, Note)
	+ This is a field for additional information or instructions about your order.
* **Shipping Cost** (shipping_cost, Number)
	+ This is a field to type in the shipping cost for your order.
