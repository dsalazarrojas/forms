# Lunch Menu Pre Order Form - Help Guide

## Purpose
This form is used to allow users to pre-order from the lunch menu. Please use it to select the items you would like to order and provide any additional information such as quantity, name, and contact details. You can select multiple menu items and also add a note if needed.

## How To Complete This Form
To complete this form, simply select the menu items you would like to order, enter the quantity, and provide any additional information such as your name, email, phone number, and a note if necessary. You can also specify a date and time for your order.

## Field-by-Field Explanation
- **Select Menu Item** (`menu_item`, select_multiple, required): Select one or more items from the menu to pre-order. You can choose from the list of options provided.
- **Quantity** (`quantity`, number, optional): Enter the quantity of each selected menu item.
- **Name** (`name`, text, optional): Enter your name so we can address you with your order.
- **Email** (`email`, email, optional): Enter your email address so we can contact you with your order details.
- **Phone** (`phone`, text, optional): Enter your phone number so we can contact you with any last-minute updates.
- **Note** (`note`, note, optional): Add any special requests or comments about your order here.
- **Date** (`date`, date, optional): Specify a date for your order.
- **Time** (`time`, time, optional): Specify a time for your order.
- **Submit** (`submit`, text, required): Click this button to submit your order.
- **Cancel** (`cancel`, text, required): Click this button to cancel your order.

## Tips
* Please make sure to select the menu items you would like to order and complete all required fields (Name and Submit) to submit your order successfully.
* If you need to cancel your order, click the Cancel button and we will be able to assist you with any changes or cancellations.
* You can add a note to your order if you have any special requests or comments.
* You can select multiple menu items, but please be mindful of the quantity of each item.
