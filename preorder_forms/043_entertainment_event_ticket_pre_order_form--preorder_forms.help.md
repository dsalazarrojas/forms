# Entertainment Event Ticket Pre Order Form - Help Guide
## Purpose
This form is designed for customers to pre-order tickets for an entertainment event.

## How To Complete This Form
To complete this form, simply fill out the required fields and submit the form. Please note that all fields marked as "required" are necessary for processing your pre-order.

## Field-by-Field Explanation
* **Event Details** (`event_details`, text, required): This field is where you can provide any additional information about the event you would like to attend. Please be as detailed as possible.
* **Show Time** (`showtime`, time, optional): If this event has multiple showtimes, please select the time you would like to attend. If not specified, the event will start at the default time.
* **Event Name** (`event_name`, text, required): Please enter the name of the event you would like to attend.
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Event Venue** (`event_venue`, text, required): Enter the name of the venue where the event will take place.
* **Event Time** (`event_time`, text, optional): If this is a recurring event, please indicate if it will happen on multiple days.
* **Number of Tickets** (`number_tickets`, number, required): Enter the number of tickets you would like to reserve.
* **Ticket Price** (`ticket_price`, number, required): Enter the ticket price.
* **Customer Email** (`customer_email`, email, required): Enter your email address so we can contact you about your ticket order and any updates.
* **Customer Phone** (`customer_phone`, text, optional): If you would like to be contacted by phone, please enter your phone number.
