# Perfume Box - Help Guide
## Purpose
This form is used to collect information for both preorder and contest registration purposes. It helps in tracking and managing the process of preorders and contest registrations.

## How To Complete This Form
1. Select the relevant category for your form by choosing between "Preorder Forms" and "Contest Registration Forms" in the "Category" field.
2. Provide a brief description of the form in the "Description" field.
3. If necessary, fill in "Form IDs" and "Form IDs 2" with numerical values for tracking purposes.
4. If you have a specific output requirement, specify it in the "Output File" field.
5. Optionally, select the tool associated with this form in the "Assigned Tool" field.

## Field-by-Field Explanation
* **Category**: Select one of the following options:
 	+ Preorder Forms
 	+ Contest Registration Forms
* **Description**: A brief description of the form.
* **Form IDs**: A numerical value for form tracking.
* **Form IDs 2**: Another numerical value for form tracking.
* **Output File**: Specify any additional output file requirements (e.g., CSV, PDF).
* **Assigned Tool**: The tool associated with this form.
