# t-shirt-pre-order-form-template - Help Guide
## Purpose
The pre-order form is used to collect information from customers before ordering t-shirts. This form helps to ensure that all necessary details are provided, making the order process smoother and more efficient.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the t-shirt color and size you are interested in from the respective dropdown menus.
2. Choose how many t-shirts you would like to order.
3. Indicate if you have a preferred color for your t-shirt.
4. Select the style of t-shirt you would like to order.
5. Enter your name and email address.
6. Enter your phone number (optional).
7. Choose the date you would like to order the t-shirt.

## Field-by-Field Explanation
* **t-shirt-color** (`t_shirt_color`, Select One): Choose the color of the t-shirt you are interested in.
* **Quantity** (`quantity`, Number): Enter the number of t-shirts you would like to order.
* **Size** (`size`, Select One): Select the size of the t-shirt you would like to order (small, medium, or large).
* **Color** (`color`, Select Multiple): If you have a preferred color, please select it.
* **Shirt-style** (`shirt-style`, Select One): Choose the style of t-shirt you would like to order.
* **Name** (`name`, Text): Enter your name for the order.
* **Email** (`email`, Email): Enter your email address for communication purposes.
* **Phone** (`phone`, Text): Enter your phone number (optional).
* **Order Date** (`order_date`, Date): Choose the date you would like to order the t-shirt.

## Tips
Please ensure that all required fields are filled out accurately. If you have any issues or questions, please contact our support team.
