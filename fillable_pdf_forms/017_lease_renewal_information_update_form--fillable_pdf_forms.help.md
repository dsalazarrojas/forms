# Lease Renewal Information Update Form - Help Guide
## Purpose
This form is designed to gather updates on lease renewal information, ensuring that all relevant details are captured accurately.

## How To Complete This Form

1. Review the form carefully and ensure all fields are accurate.
2. Enter your lease details in the corresponding fields, such as Lease Date, Lease Amount, Rent Start, and Lease End.
3. Select the correct options for Lease Status, Lease Type, and other relevant fields as per your lease agreement.
4. Provide notes for any discrepancies or additional information about the lease terms, rent, utilities, and other aspects.
5. Double-check your entries for accuracy before submitting the form.

## Field-by-Field Explanation

* **Tenant Info**: Enter the current tenant's name and contact information.
* **Lease Date**: Enter the current lease start and end dates.
* **Lease Amount**: Enter the total lease amount.
* **Lease Terms**: Select the terms of the lease that apply to you.
* **Rent Start**: Enter the start date of the rent period.
* **Lease End**: Enter the end date of the lease.
* **Lease Status**: Select the current status of the lease (e.g., 'Active', 'Suspended', etc.).
* **Lease Duration**: Enter the duration of the lease.
* **Lease Type**: Select the type of lease (e.g., 'Yes' for a standard lease, 'No' for an extension).
* **Lease Terms Agreement**: Enter any special terms agreed upon with the tenant.
* **Lease Agreement**: Enter any additional agreements or clauses in the lease.
* **Lease Extension**: Enter any lease extensions or amendments.
* **Lease Cancellation**: Enter the reason for lease cancellation (if applicable).
* **Lease Amendment**: Enter any lease amendments or modifications.
* **Lease Renewal**: Enter the date for lease renewal.
* **Lease Transfer**: Enter any lease transfer information.
* **End Date**: Enter the end date of the lease.
* **Start Date**: Enter the start date of the lease.
* **End Date Note**: Enter any notes or comments about the end date.
* **Start Date Note**: Enter any notes or comments about the start date.
* **Renewal Date**: Enter the date for lease renewal.
* **Renewal Date Note**: Enter any notes or comments about the renewal date.
* **Lease Terms**: Select the terms of the lease that apply (e.g., 'Yes', 'No', etc.).
* **Rent**: Select the rent terms that apply (e.g., 'Yes', 'No', etc.).
* **Utilities**: Select the utilities included in the lease (e.g., 'Yes', 'No', etc.).
