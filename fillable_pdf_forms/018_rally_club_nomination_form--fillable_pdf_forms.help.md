# Rally Club Nomination Form - Help Guide
## Purpose
This form is used to nominate a user to the Rally Club. The form gathers information about the nominated user, including their role, award details, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the User Name field with the full name of the user you are nominating.
2. Select the role of the user from the Role dropdown menu.
3. For the Award section:
	* Select whether the user has received an award from the Yes/No dropdown menu.
	* If they have received an award, enter the award description in the Award Description field.
	* Enter the date and time of the award in the Award Date and Award Time fields, respectively.
4. Enter the nominated user's email and phone number in the User Email and User Phone fields, respectively.
5. Enter the team name and subcategory (if applicable) in the Team Name and Sub Category fields, respectively.
6. Provide any additional notes about the nomination in the Note field.

## Field-by-Field Explanation
* **User Name** (`user_name`, text, required): Enter the full name of the user you are nominating.
* **Role** (`role`, select_one, optional): Select the role of the user from the dropdown menu.
* **Award** (`award`, select_multiple, optional): Select whether the user has received an award from the Yes/No dropdown menu.
* **Reason** (`reason`, text, optional): Enter any additional reason for nominating the user.
* **Date** (`date`, date, optional): Enter the date of the award in YYYY-MM-DD format.
* **Time** (`time`, time, optional): Enter the time of the award in 24-hour format (HH:MM).
* **Email** (`email`, email, optional): Enter the nominated user's email address.
* **Phone** (`phone`, text, optional): Enter the nominated user's phone number.
* **Note** (`note`, note, optional): Enter any additional notes about the nomination.
* **Category** (`category`, select_one, optional): Select whether the user belongs to a category from the Yes/No dropdown menu.
* **Sub Category** (`sub_category`, select_multiple, optional): Select the subcategory of the user from the Yes/No dropdown menu.
* **Team Name** (`team_name`, text, optional): Enter the team name associated with the nomination.
* **User Email** (`user_email`, email, optional): Enter the email address of the user being nominated.
* **User Phone** (`user_phone`, text, optional): Enter the phone number of the user being nominated.
* **Award Name** (`award_name`, text, optional): Enter the name of the award received by the user.
* **Award Description** (`award_description`, text, optional): Enter a description of the award received by the user.
* **Award Date** (`award_date`, date, optional): Enter the date of the award in YYYY-MM-DD format.
* **Award Time** (`award_time`, time, optional): Enter the time of the award in 24-hour format (HH:MM).
