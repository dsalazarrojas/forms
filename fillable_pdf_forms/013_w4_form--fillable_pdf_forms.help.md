# W4 Form - Help Guide
## Purpose

The W4 Form is used to collect information about an employee's tax status, employer's information, and other relevant details.

## How To Complete This Form

1. Fill out all the required fields with the correct information.
2. Select the correct options for select fields as per the hints provided.
3. Ensure to use the correct date and address formats as specified in the hints or field descriptions.
4. Enter the correct information in text fields as per the hints or field descriptions.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, required): Enter the employee's full name.
* **Employee Address** (`employee_address`, text, required): Enter the employee's address in the required format.
* **W-4 Form** (`w4_form`, select_one, optional): Select 'Yes' if the employee has a W-4 form.
* **W-4 Options** (`w4_form_options`, select_multiple, optional): Select the options as per the provided options.
* **Employee Tax ID** (`employee_tax_id`, text, optional): Enter the employee's tax ID number.
* **Tax ID Type** (`employee_tax_id_type`, select_one, optional): Select the type of tax ID.
* **Date of Birth** (`date_of_birth`, date, optional): Enter the employee's date of birth in the required format.
* **Employee Start Date** (`employee_start_date`, date, optional): Enter the employee's start date with the employer in the required format.
* **Employee End Date** (`employee_end_date`, date, optional): Enter the employee's end date with the employer in the required format.
* **Employee Employer** (`employee_employer`, select_one, optional): Select 'Yes' if the employee has a job with a employer.
* **Employee Occupation** (`employee_occupation`, text, optional): Enter the employee's occupation.
* **Address Line 2** (`employee_address_2`, text, optional): Enter the address line 2 in the required format.
* **City** (`employee_city`, text, optional): Enter the city name.
* **State** (`employee_state`, select_one, optional): Select the state.
* **Zip** (`employee_zip`, text, optional): Enter the zip code.
* **Phone** (`employee_phone`, text, optional): Enter the employee's phone number.
* **Email** (`employee_email`, text, optional): Enter the employee's email.
* **Notes** (`employee_notes`, text, optional): Enter any additional notes about the employee.
* **Employee W-4 Certificate** (`employee_w4_certificate`, select_one, optional): Select 'Yes' if the employee has a W-4 certificate.
* **Employer Name** (`employer_name`, text, optional): Enter the employer's name.
* **Employer Address** (`employer_address`, text, optional): Enter the employer's address in the required format.
* **Employer State** (`employer_state`, text, optional): Enter the employer's state.
* **Zip** (`employer_zip`, text, optional): Enter the employer's zip code.
* **Employer Occupation** (`employer_occupation`, text, optional): Enter the employer's occupation.
* **Filing Status** (`employee_filing_status`, select_one, optional): Select the employee's filing status.

## Tips

* Please ensure to fill out all required fields correctly before submission.
* Use the correct date and address formats as specified in the hints or field descriptions.
* Select the correct options for select fields as per the hints provided.
* Enter the correct information in text fields as per the hints or field descriptions.
