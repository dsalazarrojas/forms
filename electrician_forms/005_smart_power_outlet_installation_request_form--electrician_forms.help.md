# Smart Power Outlet Installation Request Form - Help Guide
## Purpose
This form is a request form for electricians to request access to a smart power outlet installation project. It is used by the maintenance team to track and manage the installation process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely, ensuring all required fields are filled in.
2. Select the correct power outlet type from the options provided.
3. Choose the correct electrician assigned to the installation.
4. Select the current status of the installation.
5. Enter any additional information about the installation, if applicable.
6. Enter the submission date of the installation request.
7. Enter the date of the planned installation.
8. Finally, submit the form to complete the request.

## Field-by-Field Explanation
### First Name
* **First Name** (`first_name`, `text`, `required`): Please enter your first name as it appears on your official identification.

### Last Name
* **Last Name** (`last_name`, `text`, `required`): Please enter your last name as it appears on your official identification.

### Email
* **Email** (`email`, `email`, `required`): Please enter your business email address.

### Phone Number
* **Phone Number** (`phone_number`, `text`, `required`): Please enter a contact phone number where you can be reached.

### Address
* **Address** (`address`, `text`, `optional`): Please enter the address where the smart power outlet will be installed.

### Installation Date
* **Installation Date** (`installation_date`, `date`, `optional`): Please enter the date you plan to have the smart power outlet installed.

### Power Outlet Type
* **Power Outlet Type** (`power_outlet_type`, `text`, `required`): Please select the type of power outlet you are requesting, such as 15A or 30A.

### Additional Info
* **Additional Info** (`additional_info`, `text`, `optional`): Please enter any additional information you feel is necessary for the installation, such as a specific location or any other details.

### Assigned Electrician
* **Assigned Electrician** (`assigned_electrician`, `select_one`, `required`): Please select the electrician assigned to this installation from the list of options.

### Submission Date
* **Submission Date** (`submission_date`, `date`, `optional`): Please enter the date you submitted this request for the smart power outlet installation.

### Installation Status
* **Installation Status** (`installation_status`, `select_multiple`, `required`): Please select the current status of the installation from the options: Not Started, In Progress, or Completed.

### Comments
* **Comments** (`comments`, `text`, `optional`): Please enter any additional comments or information about the installation.

Please ensure all fields are filled out completely and accurately to ensure the proper processing of your request.
