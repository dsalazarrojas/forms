# Underground Insulation Resistance Testing Form - Help Guide

## Purpose
This form is used to collect data on underground insulation resistance testing for electrical safety and integrity evaluations.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the title of the form, which should be a brief description of the testing process.
2. Provide general information about the insulation being tested, including its type.
3. Enter the resistance value of the insulation, including the unit of measurement.
4. Enter the test number, date, and time of the testing process.
5. Specify the type of insulation being tested, or provide additional details if it's not listed.
6. Enter any additional test results, including the resistance value and unit of measurement.
7. Select the person assigned to the testing process.
8. Select the person submitting the form.
9. Enter the date and time of submission.
10. Optionally, upload any relevant files or attachments.
11. Confirm whether any uploads were made.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a brief description of the testing process.
* **Insulation Type** (`general_info_insulation_type`, select_one, required): Select the type of insulation being tested (Air, Cable, Pipe, or Wire).
* **Insulation Resistance Value** (`general_info_insulation_resistance_value`, number, required): Enter the resistance value of the insulation.
* **Insulation Resistance Unit** (`general_info_insulation_resistance_unit`, select_one, required): Select the unit of measurement for the resistance value (Ohm, KOhm, MOhm).
* **Test Number** (`test_info_test_number`, number, required): Enter the test number or identifier.
* **Test Date** (`test_info_test_date`, date, required): Enter the date of the testing process.
* **Test Time** (`test_info_test_time`, time, required): Enter the time of the testing process.
* **Insulation Type** (`test_info_insulation_type`, select_one, required): Select the type of insulation being tested (Air, Cable, Pipe, Wire).
* **Other Insulation Type** (`test_info_insulation_type_other`, text, optional): Provide additional details if the insulation type is not listed.
* **Insulation Resistance Value 2** (`test_results_insulation_resistance_value_2`, number, required): Enter the resistance value of the insulation for the second test.
* **Insulation Resistance Unit 2** (`test_results_insulation_resistance_unit_2`, select_one, required): Select the unit of measurement for the resistance value 2 (Ohm, KOhm, MOhm).
* **Insulation Temperature** (`test_results_insulation_temperature`, select_one, required): Select the temperature of the insulation (Room, Ambient, Unknown).
* **Other Insulation Temperature** (`test_results_other_insulation_temperature`, text, optional): Provide additional details if the insulation temperature is not listed.
* **Notes** (`notes`, text, optional): Enter any additional notes or comments about the testing process.
* **Assigned To** (`assigned_to`, select_one, optional): Select the person assigned to the testing process (Jimmy, Jane).
