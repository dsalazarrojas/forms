# Secret Santa Gift Exchange Form - Help Guide
## Purpose
This form is designed for participants in a Secret Santa gift exchange to submit their gift ideas and preferences. It collects information about the recipient's name, a suggested gift, and gift exchange date and budget details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Recipient field and enter the name of the person you wish to gift.
2. Type in a suggested gift idea in the Suggest a Gift field.
3. Choose the Gift Exchange Date on which the gift will be exchanged.
4. Enter the Gift Budget, selecting the currency you would like to use (e.g., dollars, pounds, etc.).
5. Enter the Gift Budget Currency Symbol to display with the budget amount.
6. Write a Santa Message to include with the gift.

## Field-by-Field Explanation

* **What's Your Gift Idea?** (`gift_santa_exchange_form`, text, optional): This field is where you can write down any gift ideas you have for the recipient. Be creative!
* **Recipient** (`recipient_name`, text, required): Enter the name of the person to whom you are gifting.
* **Suggest A Gift** (`gift_suggestions`, text, optional): Type in a specific gift idea you think would be suitable for the recipient.
* **Gift Exchange Date** (`gift_exchange_date`, date, required): Select the date on which the gift will be exchanged.
* **Gift Budget** (`gift_budget`, number, required): Enter the budget for the gift. Please be honest about your budget to avoid over- or under-gifting!
* **Gift Budget Currency** (`gift_budget_currency`, text, required): Choose the currency you would like to use for the gift budget (e.g., dollars, pounds, etc.).
* **Gift Budget Currency Symbol** (`gift_budget_currency_symbol`, text, required): Select the symbol to display with the budget amount (e.g., $, €, etc.).
* **Santa Message** (`gift_santa_message`, text, required): Include a personal message to go along with your gift!
