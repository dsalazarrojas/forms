# secret_santa_form - Help Guide
## Purpose
This is the Secret Santa form, designed for the company's Christmas gift-giving activity. Please fill out this form to participate and let us know your preferences and details.

## How To Complete This Form
1. Fill out the form completely, providing all required information (Recipient, Budget, Email, Phone).
2. Select the recipient from the options provided.
3. Provide gift ideas in the Gift Ideas field.
4. Enter a budget for the gift.
5. Write a personal message in the Message field.
6. Enter a valid email address in the Email field.
7. Enter the participant's phone number in the Phone field.
8. (Optional) Enter a unique Form ID or select an option from the Form ID dropdown list.
9. If assigned a tool (e.g., chatjimmy, chatfrank, or chatjess), select it in the Assigned Tool field.

## Field-by-Field Explanation
* **Christmas Form**: Enter a brief description of your favorite Christmas-related item or activity (e.g., "I love Christmas cookies").
* **Recipient**: Select "Yes" if you want to be the recipient of the Secret Santa gift, or "No" if you're happy to be the giver.
* **Gift Ideas**: Suggest some gift ideas that you would like to receive or that you think would be nice for others.
* **Budget**: Enter the maximum amount you would like to spend on the gift.
* **Message**: Write a personal message for the recipient, if desired.
* **Email**: Enter a valid email address to which the gift information will be sent.
* **Phone**: Enter your phone number for contact purposes.
* **Address**: (Optional) Enter your address for delivery purposes.
* **Form ID**: Enter a unique ID for this form, or select one from the dropdown list.
* **Assigned Tool**: If assigned a tool, select it to indicate which tool you'll be using for this Secret Santa activity.

## Tips
* Please fill out the form accurately and honestly to ensure the Secret Santa activity runs smoothly.
* Make sure to provide a valid email address and phone number for easy communication.
* The more specific and helpful information you provide, the better the Secret Santa activity will be.
