# Santa Breakfast Participation Survey - Help Guide
## Purpose
The Santa Breakfast Participation Survey is designed to collect information from participants about their experiences at a Christmas-related event. This form will help us understand your opinions and feedback about the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name in the "What is your name?" field.
2. Select the school you attended from the "Which school did you attend?" dropdown list.
3. Enter the date of the event you attended.
4. Enter the time you attended the event.
5. Select your level of satisfaction with the event from the "How satisfied were you with the event?" dropdown list.
6. Optionally, add any additional comments or suggestions in the "Do you have any additional comments or suggestions?" field.
7. If applicable, list the tools assigned to you during the event in the "What tools were assigned to you during the event?" field.
8. If you want to specify a file name for the output, enter it in the "What is the name of the output file?" field.
9. Enter a number to identify the form in the "Form Id Number" field.
10. Indicate if you were attending the event with someone else.
11. Rate the event from the "How would you rate the event?" dropdown list.
12. Add any additional comments about the event.

## Field-by-Field Explanation
* **What is your name?** (Text, Required): Enter your name as it appears on your official documents.
* **Which school did you attend?** (Select One, Required): Select the school you attended from the list.
* **When was the event held?** (Date, Required): Enter the date of the event you attended.
* **What time did you attend the event?** (Time, Required): Enter the time you attended the event.
* **How satisfied were you with the event?** (Select One, Required): Select your level of satisfaction with the event.
* **Do you have any additional comments or suggestions?** (Text, Optional): Add any comments or suggestions you may have.
* **What tools were assigned to you during the event?** (Text, Optional): If applicable, list any tools assigned to you during the event.
* **What is the name of the output file?** (Text, Optional): If you want to specify a file name for the output, enter it here.
* **What is the form ID?** (Number, Optional): Enter a number to identify the form.
* **What is the category of this form?** (Select One, Required): Select the category for this form.
* **What is the description of this form?** (Text, Optional): Enter a description of the form.
* **Who created this form?** (Text, Optional): Enter the name of the form creator.
* **What is the output file?** (Text, Optional): If you want to specify a file name for the output, enter it here.
* **What is the input schema for this form?** (Text, Optional): Enter the input schema for this form.
* **Form Id Number** (Number, Optional): Enter a number to identify the form.
* **Were you attending the event with someone else?** (Select One, Required): Indicate if you were attending the event with someone else.
* **How would you rate the event?** (Select One, Required): Select the rating for the event.
* **Do you have any additional comments about the event?** (Text, Optional): Add any additional comments about the event.
