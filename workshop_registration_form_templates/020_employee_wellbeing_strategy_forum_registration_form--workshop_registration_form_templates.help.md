# Employee Wellbeing Strategy Forum Registration Form - Help Guide

## Purpose

This form is used to register and manage wellbeing events for employees. It is a crucial tool for tracking and organizing employee wellbeing initiatives. Please ensure that you have the necessary permissions to complete this form accurately.

## How To Complete This Form

1. Fill in the required fields (marked with *) as follows:
   - **Event Type**: Select the type of event you are registering (e.g., Type 1, Type 2, Type 3, Type 4).
   - **Wellbeing Category**: Choose the category of wellbeing event (e.g., Category 1, Category 2, Category 3, Category 4).
   - **Wellbeing Topic**: Select the topic of the event (e.g., Topic 1, Topic 2, Topic 3, Topic 4).
   - **Wellbeing Facilitator**: Choose the facilitator of the event (e.g., Facilitator 1, Facilitator 2).
   - **Event Participants**: Select all participants involved in the event.
   - **Event Description**: Provide a brief description of the event.

## Field-by-Field Explanation

* **Employee Data**: Enter employee data for registration purposes.
* **Wellbeing Strategy**: Briefly describe the wellbeing strategy for the event.
* **Event Details**: Provide details about the event such as date, time, and duration.
* **Time Spent At Event**: Enter the time spent at the event.
* **Wellbeing Event Name**: Enter the name of the wellbeing event.
* **Event Participants**: Select all participants involved in the event.
* **Comments**: Add any additional comments about the event.
* **Contact Email**: Enter the contact email for further communication.
* **Contact Phone**: Enter the contact phone number for further communication.
* **Wellbeing Facilitator**: Select the wellbeing facilitator for the event.
* **Wellbeing Facilitator Phone**: Enter the wellbeing facilitator's phone number (optional).
* **Wellbeing Facilitator Email**: Enter the wellbeing facilitator's email (optional).
* **Wellbeing Facilitator Website**: Enter the wellbeing facilitator's website (optional).
* **Wellbeing Facilitator Additional Info**: Enter any additional information about the wellbeing facilitator.
* **Wellbeing Event Description**: Enter a brief description of the event.

Note: All fields marked as required are mandatory and must be filled in to proceed with the registration.
