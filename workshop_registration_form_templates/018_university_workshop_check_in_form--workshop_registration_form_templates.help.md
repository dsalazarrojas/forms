# University Workshop Check In Form - Help Guide
## Purpose
The University Workshop Check In Form is designed to collect essential information from attendees, such as their arrival time, event details, and follow-up status. This form is used for internal organization and management of workshop events.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure you complete all required fields, marked as 'required'.
3. Enter your arrival time and follow-up information in the correct format (e.g., 10:00 AM).

## Field-by-Field Explanation

* **check_in** (`workshop_check_in_form`, text, optional): Enter your check-in information, if any.
* **arrival_time** (`arrival_time`, time, optional): Enter your expected arrival time at the workshop location.
* **event_name** (`event_name`, text, optional): Enter the name of the workshop event you are attending.
* **arrival_location** (`arrival_location`, text, optional): Enter the address or location where you are arriving at.
* **arrival_mode** (`arrival_mode`, select_one, optional): Select the mode of transportation used to arrive at the workshop location (e.g., Arrival by Car).
* **follow_up_time** (`follow_up_time`, time, optional): Enter the follow-up time for the workshop event (if applicable).
* **follow_up_details** (`follow_up_details`, text, optional): Enter any follow-up details for the workshop event (if applicable).
* **workshop_location** (`workshop_location`, text, optional): Enter the location of the workshop event.
* **event_date** (`event_date`, date, optional): Enter the date of the workshop event.
* **notes** (`notes`, text, optional): Enter any additional comments or notes for the workshop event.
* **attendee_info** (`attendee_info`, text, optional): Enter information about the attendees or participants (if applicable).
* **follow_up_status** (`follow_up_status`, select_one, optional): Select the follow-up status for the workshop event (e.g., Active).
* **follow_up_status_note** (`follow_up_status_note`, text, optional): Enter a note about the follow-up status.
* **follow_up_follow_up** (`follow_up_follow_up`, date, optional): Enter the follow-up date for the workshop event (if applicable).
* **follow_up_follow_up_time** (`follow_up_follow_up_time`, time, optional): Enter the follow-up time for the workshop event (if applicable).
* **follow_up_follow_up_status** (`follow_up_follow_up_status`, select_one, optional): Select the follow-up status for the workshop event (e.g., Active).
* **follow_up_follow_up_note** (`follow_up_follow_up_note`, text, optional): Enter a note about the follow-up status.
* **notes_2** (`notes_2`, text, optional): Enter any additional comments or notes for the workshop event.
* **event_id** (`event_id`, text, optional): Enter the event ID for the workshop event.
* **event_type** (`event_type`, text, optional): Enter the type of workshop event.
* **event_name** (`event_name`, text, optional): Enter the name of the workshop event.
* **event_date** (`event_date`, date, optional): Enter the date of the workshop event.
* **start_time** (`start_time`, time, optional): Enter the start time of the workshop event.
* **end_time** (`end_time`, time, optional): Enter the end time of the workshop event.
