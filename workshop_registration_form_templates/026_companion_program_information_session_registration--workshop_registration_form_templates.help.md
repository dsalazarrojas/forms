# Companion Program Information Session Registration - Help Guide
## Purpose
This form is for attendees who want to register for the Companion Program Information Session. It's an optional or preparatory program for the main event. Fill out this form to let us know your interest in attending, provide your contact details, and specify your session preferences.

## How To Complete This Form
1. Fill out the form with your personal details, such as your name and email address.
2. Select a preferred session date from the provided options.
3. If you plan to bring guests, enter the number of guests you'll be bringing.
4. Choose the topics you are interested in learning more about by selecting all that apply.
5. If you have any accessibility needs, let us know so we can accommodate you.

## Field-by-Field Explanation
* **Attendee full name** (`attendee_name`, text, required): Enter your full name as it appears on your official identification.
* **Attendee email** (`attendee_email`, email, required): Enter your email address so we can send you session details and reminders.
* **Session date** (`session_date`, date, required): Select the date you'd like to attend the information session. Please choose from the available dates listed.
* **Number of guests** (`number_of_guests`, number, optional): If you'll be bringing guests, indicate the number of guests you'll be bringing. This will help us plan for seating and arrangements.
* **Topics of interest** (`topics_of_interest`, select_multiple, required): Select all the topics you'd like to cover during the session by choosing from the list provided:
	+ Program overview
	+ Volunteer roles
	+ Support services
	+ Enrollment process
* **Accessibility needs** (`accessibility_needs`, text, optional): If you have any accessibility needs, please describe them so we can accommodate you properly.

## Tips
* Make sure to fill out the form accurately and completely to ensure we have the correct information.
* If you have any questions or need help with the form, contact us.
* The information you provide will only be used for session attendance tracking and communication purposes.
