# Yoga Retreat Participant Profile - Help Guide
## Purpose
This form is designed to help us understand your preferences and needs so we can tailor your yoga retreat experience.

## How To Complete This Form

1. Fill out this form completely and accurately, providing all required fields.
2. Make sure to select the correct options for each field.
3. Provide additional information in the "Additional Info" field if you have any special requests or needs.

## Field-by-Field Explanation

* **Name** (`full_name`, text, required): Please enter your full name as you would like to be referred to during the retreat.
* **Email** (`email`, email, required): Enter your email address so we can contact you.
* **Phone** (`phone`, text, required): Enter your phone number for emergency contact purposes.
* **Conditions** (`conditions`, select_multiple, required): Do you have any medical conditions that may affect your ability to participate? Select all that apply.
	+ Yes
	+ No
* **Allergies** (`allergies`, select_multiple, required): Do you have any allergies or sensitivities that we should be aware of? Select all that apply.
	+ Yes
	+ No
* **Medical Devices** (`medical_devices`, select_multiple, required): Do you have any medical devices that you use regularly? Select all that apply.
	+ Yes
	+ No
* **Preferred Time** (`preferred_time`, select_one, required): What time of day do you prefer to practice yoga?
	+ Yes (morning)
	+ No (afternoon)
	+ No (evening)
* **Preferred Instructor** (`preferred_instructor`, select_one, required): Who is your preferred instructor?
	+ Yes (instructor A)
	+ Yes (instructor B)
* **Preferred Class Type** (`preferred_class_type`, select_one, required): What type of class do you prefer?
	+ Yes (Hatha)
	+ Yes (Vinyasa)
	+ Yes (Kundalini)
* **Yoga Style** (`yoga_style`, select_one, required): What style of yoga do you practice or prefer?
	+ High
	+ Low
* **Dietary Restrictions** (`dietary_restrictions`, select_multiple, required): Do you have any dietary restrictions we should be aware of? Select all that apply.
	+ Yes
	+ No
* **Emergency Contact** (`emergency_contact`, text, optional): Provide the name and contact information of an emergency contact.
* **Additional Info** (`additional_info`, note, optional): If you have any special requests or needs, please let us know here.

Please fill out this form completely and accurately, and let us know if you have any questions or need further clarification.
