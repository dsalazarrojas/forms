# Pottery Session Reservation Form - Help Guide
## Purpose
The Pottery Session Reservation Form is designed to collect participant information and session preferences for a pottery session reservation.

## How To Complete This Form
1. Fill out the participant details section with your first name, last name, email address, phone number, and instructor preference.
2. Select your preferred date and time for the session.
3. Choose your preference for the class you wish to attend.
4. Indicate whether you are booking the session.
5. Provide any additional notes or comments in the notes field.

## Field-by-Field Explanation

* **First Name** (`pottery_session_reservation_form`): This is the participant's first name.
* **Last Name** (`pottery_session_reservation_form_first_name`): This is the participant’s last name.
* **Email** (`pottery_session_reservation_form_email`): This is the participant's email address. Please ensure it is up-to-date and accurate.
* **Phone** (`pottery_session_reservation_form_phone`): This is the participant's phone number.
* **Date** (`pottery_session_reservation_form_date`): Select a date for the session you would like to attend. Please note that the date selected will be used to schedule the session.
* **Time** (`pottery_session_reservation_form_time`): Select a time for the session you would like to attend.
* **Class** (`pottery_session_reservation_form_class`): Choose which class you would like to attend.
* **Session** (`pottery_session_reservation_form_session`): Select whether you are booking the session or not.
* **Instructor** (`pottery_session_reservation_form_instructor`): Select whether you would like to be instructed by a specific teacher or not.
* **Notes** (`pottery_session_reservation_form_notes`): Provide any additional comments or notes about the session.
* **Submission** (`pottery_session_reservation_form_submission`): This is an additional field for any further notes or comments about the session submission.

## Tips
* Ensure all required fields are filled out before submitting the form.
* Be as specific as possible when filling out the session preferences.
* If you have any additional questions or concerns, please don't hesitate to contact us.
