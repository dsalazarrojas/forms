# Stage Props Workshop Booking Form - Help Guide
## Purpose
The Stage Props Workshop Booking Form is a tool for managing workshop registrations. It gathers essential participant and workshop details to ensure smooth and efficient scheduling and coordination.

## How To Complete This Form
1.  First, fill out the required fields for the participant's personal details: First Name, Last Name, Email, Phone, and Workshop Date, Time, and Workshop Time Length.
2.  For optional fields, enter the Participant Name, Participant Email, and Comments if necessary.
3.  Select the Workshop Id and Studio Id as appropriate (Yes or No).
4.  Set the Participant Status and Payment Status as appropriate (Active or Inactive).
5.  Finally, set the Submission Date and click the submit button to complete the form.

## Field-by-Field Explanation

*   **First Name** (`First Name`, `text`, required): Enter the first name of the participant.
*   **Last Name** (`Last Name`, `text`, required): Enter the last name of the participant.
*   **Email** (`Email`, `email`, required): Enter the email address of the participant.
*   **Phone** (`Phone`, `text`, required): Enter the phone number of the participant.
*   **Participant Name** (`Participant Name`, `text`, optional): Enter the name of the participant if different from the first and last name.
*   **Participant Email** (`Participant Email`, `email`, optional): Enter the email address of the participant if different from the main participant email.
*   **Workshop Date** (`Workshop Date`, `date`, required): Select the date of the workshop the participant will be attending.
*   **Time** (`Time`, `time`, required): Select the time of the workshop the participant will be attending.
*   **Workshop Time Length** (`Workshop Time Length`, `number`, required): Enter the duration of the workshop in hours and minutes.
*   **Booking Date** (`Booking Date`, `date`, optional): Set the date of the booking.
*   **Comments** (`Comments`, `note`, optional): Enter any additional comments or notes about the participant.
*   **Workshop Id** (`Workshop Id`, `select_one`, required): Select Yes if the participant will be attending the workshop.
*   **Studio Id** (`Studio Id`, `select_one`, required): Select Yes if the participant will be attending the studio.
*   **Participant Status** (`Participant Status`, `select_multiple`, required): Set the participant status as Active or Inactive.
*   **Payment Status** (`Payment Status`, `select_multiple`, required): Set the payment status as Active or Inactive.
*   **Submission Date** (`Submission Date`, `date`, required): Set the date of the submission.

## Tips
*   Please fill out the form accurately and completely to ensure efficient processing and scheduling.
*   If you're unsure about any field, refer back to this help guide for clarification.
