# outdoor-recreation-expo-registration-form - Help Guide
## Purpose
The outdoor-recreation-expo-registration-form is a data collection form used to register individuals interested in attending an outdoor recreation expo. 

## How To Complete This Form

To complete the form, follow these steps:

- Fill out all the required fields, which are currently empty for this form, except for the "General Info" section. 
- For the multiple-choice fields like "Preferred Days" and "Interests", select the options that apply to you.
- For the "Note" fields, use them to provide any additional information or remarks you'd like to share with the expo organizers.

## Field-by-Field Explanation

### General Info (id: 1)
* **General Info** (text): This is a free-text field where you can provide any general information about yourself.

### Preferred Days (id: 2)
* **Preferred Days** (select multiple, options: 'Yes', 'No'): Select the days you prefer to attend the expo.

### Interests (id: 3)
* **Interests** (select multiple, options: 'Yes', 'No'): Select the interests you have that align with the expo.

### Requirements (id: 4)
* **Requirements** (select multiple, options: 'Yes', 'No'): Select any requirements you have that the expo organizers should be aware of.

### Date (id: 6)
* **Date** (date): This field is not currently required but can be filled out if you know the date you plan to attend.

### Time (id: 7)
* **Time** (time): This field is not currently required but can be filled out if you know the time you plan to attend.

### Note 1-18 (id: 8-25)
* **Note 1-18** (note): These note fields are optional and can be used to provide any additional information you'd like to share with the expo organizers.

Please ensure to review each field carefully and fill out the form according to your needs. If you have any questions or concerns, don't hesitate to reach out to the expo organizers.
