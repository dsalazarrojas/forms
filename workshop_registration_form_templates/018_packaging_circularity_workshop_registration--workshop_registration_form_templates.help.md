# Packaging Circularity Workshop Registration - Help Guide
## Purpose
This form is used to register a workshop. Please fill out the form with the required information to ensure accurate and complete registration.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Workshop Name" field with the name of the workshop you are trying to register.
2. Enter the "Prophet's Email" field with the email address of the workshop contact.
3. Enter the "Contact Phone" field with the phone number of the workshop contact.
4. Select the "Workshop Date" and "Workshop Time" fields with the date and time of the workshop.
5. Choose a "Circular Reporting" option that best describes the type of reporting you will be doing.
6. Select any "Attendee Preferences" that apply to the workshop.
7. Enter any "Attendee Requirements" and "Goals" fields if necessary.
8. Choose "Follow-up" options that apply to the workshop.
9. Enter the "Workshop Venue" and "Workshop Notes" fields if necessary.
10. Enter any "Follow-up Notes" and "Follow-up Frequency" fields if necessary.
11. Select "Follow-up Method" and "Follow-up Status" fields if necessary.
12. Enter the "Workshop Location" field if necessary.
13. Enter the "Workshop Duration" and "Workshop Capacity" fields with the expected duration and capacity of the workshop.
14. Select the "Workshop Start Date" and "Workshop End Date" fields with the start and end dates of the workshop.
15. Select the "Workshop Start Time" and "Workshop End Time" fields with the start and end times of the workshop.
