# Strategic Workforce Planning Program Registration - Help Guide
## Purpose
This form is used to register for the Strategic Workforce Planning Program.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the program you are registering for.
2. Select the type of program that best describes your interests.
3. If applicable, enter the dates and time of the program.
4. Enter your name and email address to identify you as a participant.
5. Enter your phone number so we can contact you if needed.
6. Select the sessions that you are interested in attending.
7. If you have any specific needs or requirements, please let us know in the text field below.
8. Enter any additional session preferences in the text field.
9. Enter your team name and email address if you are registering as a team.
10. Review and submit your application carefully.

## Field-by-Field Explanation
### Program Name
* **Program Name** (`program_name`, text, required): Enter the name of the program you are registering for. This is a required field and should be filled out accurately.

### Program Type
* **Program Type** (`program_type`, select_one, optional): Select the type of program that best describes your interests. This field is optional, but it helps us understand your preferences.

### Program Dates
* **Program Dates** (`program_dates`, date, optional): If the program has specific dates, enter them here. This field is optional and only required if the program has fixed dates.

### Program Time
* **Program Time** (`program_time`, time, optional): If the program has specific time slots, enter them here. This field is optional and only required if the program has fixed time slots.

### Attendee Name
* **Attendee Name** (`attendee_name`, text, required): Enter your name as a participant in the program. This is a required field and should be filled out accurately.

### Attendee Email
* **Attendee Email** (`attendee_email`, email, optional): Enter your email address so we can contact you if needed. This field is optional, but it helps us reach out to you.

### Attendee Phone
* **Attendee Phone** (`attendee_phone`, text, required): Enter your phone number so we can contact you if needed. This is a required field and should be filled out accurately.

### Session Selection
* **Session Selection** (`session_selection`, select_multiple, optional): Select the sessions that you are interested in attending. This field is optional, but it helps us tailor the program to your interests.

### Attendee Needs
* **Attendee Needs** (`attendee_needs`, text, optional): If you have any specific needs or requirements, please let us know in this text field. This field is optional and only required if you have special needs.

### Session Preferences
* **Session Preferences** (`session_preferences`, text, optional): Enter any additional session preferences in this text field. This field is optional and only required if you have specific preferences.

### Team Name
* **Team Name** (`team_name`, text, required): Enter the name of the team you are registering as. This is a required field and should be filled out accurately.

### Team Email
* **Team Email** (`team_email`, email, optional): Enter the email address of your team. This field is optional, but it helps us reach out to your team.

## Tips
* Please fill out the form accurately and carefully.
* If you need to make any changes, please let us know as soon as possible.
* To avoid duplication, please do not register for the same program and session multiple times.
* If you have any questions or concerns, do not hesitate to contact us.
