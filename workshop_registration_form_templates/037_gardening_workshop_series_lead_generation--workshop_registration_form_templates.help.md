# Gardening Workshop Series Lead Generation - Help Guide
## Purpose
This form is designed to generate leads for a gardening workshop series. It captures essential details about the workshop, including its title, category, description, contact information, and output file.

## How To Complete This Form
1. **Gardening Workshop Series Lead Generation**: Enter the title of the workshop series.
2. **Category**: Select the category of the workshop series (e.g., Garden Centers, Educators, Community Groups).
3. **Description**: Provide a brief description of the workshop series.
4. **Email**: Enter the email address of the person or organization associated with the workshop series.
5. **Phone**: Enter the phone number of the person or organization associated with the workshop series.
6. **Output File**: Enter the name of the output file associated with the workshop series.
7. **Assigned Tool**: (Optional) Select the tool assigned to this workshop series.
8. **Assigned User**: (Optional) Select the user assigned to this workshop series.

## Field-by-Field Explanation
* **Gardening Workshop Series Lead Generation** (Text, Required): The title of the workshop series.
* **Category** (Select One, Required): The category of the workshop series (e.g., Garden Centers, Educators, Community Groups).
* **Description** (Text, Required): A brief description of the workshop series.
* **Email** (Email, Required): The email address of the person or organization associated with the workshop series.
* **Phone** (Text, Required): The phone number of the person or organization associated with the workshop series.
* **Output File** (Text, Required): The name of the output file associated with the workshop series.
* **Assigned Tool** (Text, Optional): The tool assigned to this workshop series.
* **Assigned User** (Text, Optional): The user assigned to this workshop series.
* **Form Title** (Text, Optional): The title of the form.
* **Description Description** (Text, Optional): A brief description of the form.
* **Description 2** (Text, Optional): A second description of the workshop series.
* **Category 2** (Text, Optional): The category of the workshop series (e.g., Garden Centers, Educators, Community Groups).
* **Form Category** (Text, Optional): The category of the form.
* **Form Description 2** (Text, Optional): A description of the form.
* **Form Ids 2** (Text, Optional): The IDs of the form.
* **Assigned User ID** (Text, Optional): The ID of the user assigned to this workshop series.
* **Form Title 2** (Text, Optional): The title of the second form.
* **Form Description 2** (Text, Optional): A second description of the form.
* **Form Category 2** (Text, Optional): The category of the second form.
* **Form Ids 2** (Text, Optional): The IDs of the second form.

Note: The fields with "(Optional)" are not required fields and can be completed if additional information is desired.
