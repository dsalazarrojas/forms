# Errorcode Record - Help Guide

## Purpose

The Errorcode Record form is used to document and track error codes in the system. This form helps users to quickly and easily record and manage error codes, their descriptions, and associated priorities. It is essential for the maintenance and development teams to have an accurate and up-to-date record of error codes for efficient troubleshooting and resolution.

## How To Complete This Form

1. To complete the form, navigate to the desired page and click the "Errorcode Record" form.
2. Start by filling out the "Error Code Record" (page 1) with the relevant error code. Select the corresponding value from the available options or fill it in manually.
3. Proceed to page 2 and enter the error code description in the designated text field.
4. If the priority of the error code has been optimized, fill out the "Optimized Priority" field with the corresponding value.

## Field-by-Field Explanation

* **Error Code Record** (Page 1, `errorcode_record_form`, required):
This field is used to input the error code, which is a unique identifier for the error.
* **Error Code Description** (Page 2, `errorcode_description`, optional):
This field provides more detailed information about the error code, allowing users to quickly understand the context.
* **Optimized Priority** (Page 3, `optimized_priority`, optional):
This field indicates the optimized priority level of the error code, which helps in prioritizing error resolution activities.
