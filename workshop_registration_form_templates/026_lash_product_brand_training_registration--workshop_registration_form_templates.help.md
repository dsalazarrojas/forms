# Lash Product Brand Training Registration - Help Guide
## Purpose
This form is used to register attendees for the Lash Product Brand training sessions. It is essential to complete this form accurately to ensure that the trainers can plan their sessions effectively.

## How To Complete This Form

1. Fill in your First Name and Last Name in the respective fields. These fields are required to ensure that each attendee has a unique identity.
2. Enter your email address in the Email field. This will help us contact you with any updates or changes to the training schedule.
3. Enter your phone number in the Phone field. This is optional but helps us to contact you in case of any last-minute updates.
4. Select the sessions you wish to attend from the Session Preferences field. You can select multiple sessions.
5. Provide your consent to participate in the training. This is not required but is necessary for us to proceed with your registration.
6. Select the date and time you would like to attend the training in the Date and Time field.
7. If applicable, assign any tools you need during the training in the Assigned Tool field.
8. If applicable, provide the output file you would like to create in the Output File field.
9. Enter the category you would like to attend in the Category field. This is a required field.
10. Provide a description of your preferences and requirements in the Description field. This is also a required field.
11. If applicable, provide the form IDs you have been assigned in the Form IDs field.
12. If applicable, provide the name of the output file you would like to create in the Output File Name field.
13. If applicable, provide the type of output file you would like to create in the Output File Type field.
14. If applicable, provide the size of the output file you would like to create in the Output File Size field.
15. If applicable, assign any additional tools you need during the training in the Assigned Tool 2 field.
16. If applicable, provide the form filename you have been assigned in the Form Filename field.
17. If applicable, provide the category you would like to attend in the Category 2 field. This is a required field.
18. Provide a description of your preferences and requirements in the Description 2 field. This is also a required field.
19. If applicable, provide the filename of the output file you would like to create in the Form Filename 2 field.
20. If applicable, assign any additional tools you need during the training in the Assigned Tool 3 field.
