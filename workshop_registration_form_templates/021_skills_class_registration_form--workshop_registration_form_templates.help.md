# skills_class_registration_form - Help Guide
## Purpose
The skills class registration form is designed to collect user information, class preferences, and other relevant details to facilitate the registration process for a workshop or training session.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your user details in the "User Details" section.
2. Select the classes you are interested in from the "Class Selections" section.
3. Provide any additional information about yourself in the "User Info" section.
4. Enter your email address in the "Email" field.
5. Enter your phone number in the "Phone" field.
6. Add any relevant notes in the "Notes" section.
7. Provide information about the instructor in the "Instructor Info" section.
8. Select the training provider in the "Training Provider" section.
9. Choose the class status and preferred dates in the "Class Status" and "Preferred Dates" sections.
10. Select the class type and start/end dates in the "Class Type" and "Class Start Date" and "Class End Date" sections.
11. Choose the class time zone and duration in the "Class Time Zone" and "Class Duration" sections.
12. Add any class notes in the "Class Notes" section.

## Field-by-Field Explanation

* **User Details** (1): Enter your name, email, and any other relevant user information.
* **Class Selections** (2): Select the classes you are interested in taking.
* **Class Dates** (3): Select the dates you are available to attend the class.
* **User Info** (4): Provide any additional information about yourself that is relevant to the class.
* **Email** (5): Enter a valid email address for correspondence.
* **Phone** (6): Enter your phone number for contact purposes.
* **Notes** (7): Add any notes about the class or your availability.
* **Instructor Info** (8): Provide information about the instructor leading the class.
* **Training Provider** (9): Select the training provider offering the class.
* **Class Status** (10): Choose the status of the class (e.g. available, full, cancelled).
* **Preferred Dates** (11): Select the dates you prefer to attend the class.
* **Class Type** (12): Select the type of class you are interested in (e.g. beginner, advanced).
* **Class Start Date** (13): Enter the start date of the class.
* **Class End Date** (14): Enter the end date of the class.
* **Class Start Time** (15): Select the start time of the class.
* **Class End Time** (16): Select the end time of the class.
* **Class Time Zone** (17): Choose the time zone of the class.
* **Class Duration** (18): Select the duration of the class.
* **Class Status** (19): Choose the status of the class again (e.g. available, full, cancelled).
* **Class Location** (20): Enter the location of the class.
* **Course ID** (21): Enter a unique ID for the class.
* **Training Provider ID** (22): Enter a unique ID for the training provider.
* **Instructor ID** (23): Enter a unique ID for the instructor.
* **Class Notes** (24): Add any notes about the class.
* **Class Comments** (25): Add any comments about the class.
