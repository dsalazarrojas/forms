# Program Kit Prophetsorm - Help Guide
## Purpose
This form is designed to collect information about program kits and their participants. It is used to register new program kits and gather essential details for their successful implementation.

## How To Complete This Form
1.  Ensure you are filling out this form for a new program kit.
2.  Review the form fields carefully to ensure you have all the necessary information.
3.  Enter the required fields (marked as required).
4.  Double-check your answers before submitting the form.

## Field-by-Field Explanation
* **Program Kit Selections** (`program_kit_selections`, select_multiple, required: false): Select all applicable program kit options from the provided list. This field allows you to choose multiple program kits for registration.
* **Participant Details** (`participant_details`, text, required: false): Enter the participant's name, address, and any other relevant details as applicable.
* **Shipping Details** (`shipping_details`, text, required: false): Provide shipping details such as the shipping address and any special instructions.
* **Program Date** (`program_date`, date, required: false): Enter the date of the program kit's scheduled implementation or distribution.
* **Kit Dosage** (`kit_dosage`, text, required: false): Enter the dosage information for the program kit, if applicable.
* **Participant Signature** (`participant_signature`, text, required: false): Enter the participant's signature, if required.
* **School Name** (`school_name`, text, required: false): Enter the name of the school or institution associated with the program kit.
* **Program ID** (`program_id`, number, required: false): Enter the unique identifier for the program kit.
* **Shipping Notes** (`shipping_notes`, text, required: false): Enter any special shipping instructions or notes.
* **Kit Selection** (`kit_selection`, select_one, required: false): Select the applicable kit selection from the provided list.
* **Participant Email** (`participant_email`, email, required: false): Enter the participant's email address.
* **Participant Phone** (`participant_phone`, text, required: false): Enter the participant's phone number.
* **Shipping Method** (`shipping_method`, select_multiple, required: false): Select all applicable shipping methods from the provided list.
* **Shipping Method Note** (`shipping_method_note`, text, required: false): Enter any special shipping method notes.
* **Kit Selection 2** (`kit_selection_2`, select_one, required: false): Select the applicable kit selection from the provided list.

## Tips
* Please ensure that all required fields are filled out correctly.
* Double-check your answers for accuracy before submitting the form.
* If you are unsure about any field, feel free to ask for clarification.
