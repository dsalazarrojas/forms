# Rally Class Registration Form - Help Guide
## Purpose
The Rally Class Registration Form is designed to collect information from participants for the purpose of organizing and managing a workshop or event related to rally classes.

## How To Complete This Form
1. Fill out the form completely and accurately with your personal details.
2. For emergency contact information, provide the relevant phone numbers and email addresses, if applicable.
3. Select the correct vehicle class and type from the options provided.
4. Choose the correct event type and class type.
5. Add any additional class details, if necessary.
6. Provide any relevant medical certification, if required.

## Field-by-Field Explanation

* **First Name** (`1`, `text`, required: `false`): Please enter your first name.
* **Last Name** (`2`, `text`, required: `false`): Please enter your last name.
* **Date of Birth** (`3`, `date`, required: `false`): Please enter your date of birth in the format `mm/dd/yyyy`.
* **Phone Number** (`4`, `text`, required: `false`): Please enter your phone number.
* **Email** (`5`, `email`, required: `false`): Please enter your email address.
* **Emergency Contact** (`6`, `text`, required: `false`): Please enter the name of the emergency contact.
* **Emergency Phone** (`7`, `text`, required: `false`): Please enter the phone number of the emergency contact.
* **Emergency Email** (`8`, `email`, required: `false`): Please enter the email address of the emergency contact.
* **Course Level** (`9`, `select_one`, required: `false`): Please select your course level:
	+ Beginner
	+ Intermediate
	+ Advanced
	+ Expert
* **Participant Type** (`10`, `select_multiple`, required: `false`): Please select your participant type:
	+ Rider
	+ Rider Support
	+ Spectator
* **Vehicle Class** (`11`, `select_one`, required: `false`): Please select the class of your vehicle:
	+ Group A
	+ Group B
	+ Group C
* **Vehicle Type** (`12`, `select_multiple`, required: `false`): Please select the type of your vehicle:
	+ Rallycross
	+ Rally Raid
	+ SRT
	+ Rally Buggy
	+ Safari Car
	+ Modified 4WD
* **Event Type** (`13`, `select_one`, required: `false`): Please select the type of event:
	+ Rallycross
	+ Rally Raid
	+ SRT
* **Class Type** (`14`, `select_one`, required: `false`): Please select the class type:
	+ Rally 1 (Rallycross)
	+ Rally 2 (Modified 4WD)
	+ Rally 3 (Rally Raid)
* **Class Details** (`15`, `note`, required: `false`): Please enter any additional class details.
* **Emergency Details** (`16`, `text`, required: `false`): Please provide any medical conditions or special instructions for event staff.
* **Medical Certification** (`17`, `select_one`, required: `false`): Please select 'Yes' if you have medical certification.
	+ 'Yes'
	+ 'No'

## Tips

* Please ensure all fields are filled in correctly to avoid any issues with event registration.
