# Translation Session Registration - Help Guide
## Purpose
The Translation Session Registration form is used to collect information from coordinators and participants for translation sessions. This form helps in ensuring that all necessary details are captured to facilitate a smooth and productive session.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Enter the Coordinator Information, including any relevant details about the session.
2. Enter the Participant Information, including any relevant details about the participant.
3. Provide the schedule for the session.
4. Select the language pair for the session.
5. Choose your availability for the session.
6. Enter the participant's email address.
7. Enter the participant's phone number.
8. Add any notes from the coordinator.

## Field-by-Field Explanation
* **Coordinator Information**: This field is used to enter the coordinator's information, including any relevant details about the session.
	+ Type: Text
	+ Required: No
* **Participant Information**: This field is used to enter the participant's information, including any relevant details about the participant.
	+ Type: Text
	+ Required: No
* **Schedule**: This field is used to enter the schedule for the session.
	+ Type: Text
	+ Required: No
* **Language Pair**: This field is used to select the language pair for the session.
	+ Type: Select Multiple
	+ Required: No
	+ Options: ENGLISH, SPANISH, CHINESE, JAPANESE
* **Availability**: This field is used to select your availability for the session.
	+ Type: Select Multiple
	+ Required: No
	+ Options: 09:00-10:00, 10:00-11:00, 11:00-12:00, 12:00-13:00, 13:00-14:00
* **Participant Email**: This field is used to enter the participant's email address.
	+ Type: Email
	+ Required: No
* **Participant Phone**: This field is used to enter the participant's phone number.
	+ Type: Number
	+ Required: No
* **Coordinator Note**: This field is used to add any notes from the coordinator.
	+ Type: Note
	+ Required: No

## Tips
Please fill out the form accurately and completely to ensure that all necessary details are captured. If you have any questions or concerns, please reach out to the session coordinator.
