# Veterinary Innovation Bootcamp Registration Form - Help Guide

## Purpose

This form is designed to collect information from participants who want to register for the Veterinary Innovation Bootcamp. It is essential to provide accurate and complete information to ensure a smooth registration process.

## How To Complete This Form

1.  To complete this form, please follow the instructions below:
    *   Fill in the required fields with accurate information.
    *   Use the available options for select_one fields.
    *   Enter dates and times using the correct format (yyyy-mm-dd for dates, hh:mm for times).

## Field-by-Field Explanation

*   **Participant Details**
    *   (`participant_details`, text, required)
        This field is for your personal details, providing your name, address, city, country, email, phone, and zip.
*   **Motivation**
    *   (`motivation`, text, required)
        Please provide a brief statement explaining why you want to participate in the Veterinary Innovation Bootcamp.
*   **Special Needs**
    *   (`special_needs`, text, optional)
        If you have any special needs or requirements, please mention them here.
*   **Participant Type**
    *   (`participant_type`, select_one, required)
        Please select your type of participation:
            Participant/Researcher/Clinic
*   **Event Type**
    *   (`event_type`, select_one, required)
        Please select the type of event you are interested in:
            Bootcamp/Seminar
*   **Date**
    *   (`date`, date, required)
        Enter the date you are planning to participate in the Veterinary Innovation Bootcamp (yyyy-mm-dd).
*   **Time**
    *   (`time`, time, required)
        Enter the time you are planning to participate in the Veterinary Innovation Bootcamp (hh:mm).
*   **Notes**
    *   (`notes`, text, optional)
        If you have any additional comments or remarks, please enter them here.
*   **Participant ID**
    *   (`participant_id`, text, optional)
        If you want to provide a unique participant ID, please enter it here.
*   **Event ID**
    *   (`event_id`, text, optional)
        If you have an Event ID, please enter it here.
*   **Event Name**
    *   (`event_name`, text, optional)
        If you want to provide the name of the event you are participating in, please enter it here.
*   **Event Date**
    *   (`event_date`, date, optional)
        If you want to provide the date of the event you are participating in, please enter it here.
*   **Event Time**
    *   (`event_time`, time, optional)
        If you want to provide the time of the event you are participating in, please enter it here.
*   **Payment Method**
    *   (`payment_method`, select_one, optional)
        Please select the payment method you are using:
            Card/Bank
*   **Payment Status**
    *   (`payment_status`, select_one, optional)
        Please select your payment status:
            Paid/Pending/Not Paid
*   **Payment Date**
    *   (`payment_date`, date, optional)
        If you want to provide the date of payment, please enter it here.
*   **Additional Comments**
    *   (`additional_comments`, text, optional)
        If you have any additional comments or remarks, please enter them here.
*   **Additional Needs**
    *   (`additional_needs`, text, optional)
        If you have any additional needs or requirements, please mention them here.
*   **Participant Email**
