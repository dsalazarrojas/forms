# Learning Design Certification Pathway Registration Form - Help Guide

## Purpose
This form is used to register users in a learning design certification pathway. It collects information on the user's basic details, learning objective, certification pathway, course details, and submitter's information. 

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your First Name and Last Name in the respective fields. 
2. Provide your Email address and Phone Number. 
3. Enter your Date of Birth if required. 
4. Select your Learning Objective from the dropdown menu. 
5. Choose your Certification Pathway from the dropdown menu. 
6. Enter the name of your Course and Course Start and End Dates if applicable. 
7. Enter the name of your Program and Program Start and End Dates if applicable. 
8. Provide your Registration Date. 
9. Enter your User ID if applicable. 
10. Select your User Role from the dropdown menu. 
11. Add any Additional Information about your learning pathway. 
12. Enter information about the person submitting this form (Submitter's Name, Email, Phone Number, Relationship, Organization, Title).

## Field-by-Field Explanation

* **First Name**: Enter your first name. This is a required field if you want to proceed with registration.
* **Last Name**: Enter your last name. This is a required field if you want to proceed with registration.
* **Email**: Enter your email address. This is a required field for communication purposes.
* **Phone Number**: Enter your phone number. This is optional but recommended for communication.
* **Date of Birth**: Enter your date of birth. This is optional but required for certain programs.
* **Learning Objective**: Select your learning objective from the dropdown menu. This is a required field.
* **Certification Pathway**: Select your certification pathway from the dropdown menu. This is a required field.
* **Course Name**: Enter the name of your course. This is optional.
* **Course Start Date**: Enter the start date of your course. This is optional but required if you have selected a course.
* **Course End Date**: Enter the end date of your course. This is optional but required if you have selected a course.
* **Certification Date**: Enter the certification date. This is optional but required if you have selected a certification pathway.
* **Program Name**: Enter the name of your program. This is optional.
* **Program Start Date**: Enter the start date of your program. This is optional but required if you have selected a program.
* **Program End Date**: Enter the end date of your program. This is optional but required if you have selected a program.
* **Registration Date**: Enter the registration date. This is a required field.
* **User ID**: Enter your user ID. This is optional but required for certain programs.
* **User Role**: Select your user role from the dropdown menu. This is optional.
* **Learning Outcome**: Enter any learning outcome or achievement from your program. This is optional.
* **Additional Info**: Enter any additional information about your learning pathway. This is optional.
* **Submitter's Name**: Enter the name of the person submitting this form. This is optional.
* **Submitter Email**: Enter the email address of the person submitting this form. This is optional but required if you are submitting on behalf of someone else.
* **Submitter Phone Number**: Enter the phone number of the person submitting this form. This is optional.
* **Submitter Relationship**: Select the relationship of the person submitting this form to you. This is optional.
* **Submitter Organization**: Enter the organization of the person submitting this form. This is optional.
* **Submitter Title**: Enter the title of the person submitting this form. This is optional. 

Note: Some fields are optional and will not be visible on the form if not selected.
