# Supply Chain Innovation Bootcamp Registration Form - Help Guide
## Purpose
This form is used to register for the Supply Chain Innovation Bootcamp, capturing essential information about the attendee and their team.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First Name in the "First Name" field.
2. Enter your Last Name in the "Last Name" field.
3. Enter your Email in the "Email" field, using a valid email format.
4. Select a Date for the event from the calendar.
5. Choose a Time slot for the event.
6. Enter your Phone Number in the "Phone" field.
7. Enter the name of your Company.
8. Select your current Role from the list of options (e.g. Innovation Manager, Supply Chain Manager, Logistics Manager).
9. Enter the size of your Team attending the workshop.
10. Enter any additional Message you'd like to share with the event organizers.
11. Select one or more Categories that this workshop registration form template is relevant to (e.g. Workshop Registration Form Templates, Event Registration Forms).
12. Select one option for the Assigned tool from the list (e.g. chatjimmy, Other).
13. Enter the name of the Output File (e.g. PDF, CSV, Excel).
14. Select one or more Workshop Types from the list (e.g. Bootcamp, Workshop, Training).
15. Select one or more Event Types from the list (e.g. Online, Offline).
16. Enter a unique identifier for this form (Form ID).
17. Provide a brief Description of the event or workshop.

## Field-by-Field Explanation

* **First Name** (`1`, `text`, required): Enter your first name as you would like it to appear on the registration list and event materials.
* **Last Name** (`2`, `text`, required): Enter your last name as you would like it to appear on the registration list and event materials.
* **Email** (`3`, `email`, required): Enter a valid email address to receive updates and notifications about the workshop.
* **Date** (`4`, `date`, required): Select the date you plan to attend the workshop.
* **Time** (`5`, `time`, required): Select the time slot for your workshop session.
* **Phone** (`6`, `text`, required): Enter your phone number for contact purposes.
* **Company** (`7`, `text`, required): Enter the name of your company or organization.
* **Role** (`8`, `select_one`, required): Select your current role in your organization (e.g. Innovation Manager, Supply Chain Manager, Logistics Manager).
* **Team Size** (`9`, `number`, required): Enter the number of people attending the workshop from your team.
* **Message** (`10`, `note`, required): Add any additional comments or messages you'd like to share with the event organizers.
* **Category** (`11`, `select_multiple`, required): Select one or more categories that this workshop registration form is relevant to.
* **Assigned** (`12`, `select_one`, required): Select the tool assigned to you for the workshop.
* **Output File** (`13`, `text`, required): Enter the name of the output file for the workshop.
* **Workshop** (`14`, `select_multiple`, required): Select one or more workshop types (e.g. Bootcamp, Workshop, Training).
* **Type** (`15`, `select_multiple`, required): Select one or more event types (e.g. Online, Offline).
* **Form ID** (`16`, `text`, required): Enter a unique identifier for this form.
* **Description** (`17`, `text`, required): Enter a brief description of the event or workshop.
