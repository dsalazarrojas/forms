# Teacher Student Partnership Forum Registration - Help Guide
## Purpose
The purpose of this form is to register teachers and students for a workshop or event. This form gathers essential details about the event, participants, and their institutions.

## How To Complete This Form

1. Fill out the required fields:
	* Event Name
	* Event Organizer
	* Expected Outcomes
	* Follow up
	* School District
	* School Address
	* School City
	* School State
	* School Zip
	* Student Grade
	* School Level
	* Teacher Subjects
	* Student Subjects
	* Student Institution
2. Optional fields:
	* Event Date
	* Expected Participants
	* Event Description
	* School State (this field is not entirely necessary as it will default to a state based on the school district)

## Field-by-Field Explanation

* **Event Name**: The name of the event you are registering for. This is a required field.
* **Event Date** (optional): The date of the event. This field is not required but helps in organizing the schedule.
* **Event Organizer**: The person in charge of organizing the event. This is a required field.
* **Expected Outcomes**: The expected outcomes or goals of the event. This is a required field.
* **Follow up**: Any additional follow-up information or contact details. This is a required field.
* **School District**: The district of the school where the event will take place. This is a required field.
* **School Address**: The address of the school where the event will take place. This is a required field.
* **School City**: The city of the school where the event will take place. This is a required field.
* **School State**: The state of the school where the event will take place. This is a required field.
* **School Zip**: The zip code of the school where the event will take place. This is a required field.
* **Student Grade**: The grade of the student. This is a required field.
* **School Level**: The level of the school. This is a required field.
* **Teacher Subjects**: The subjects taught by the teacher. This is a required field.
* **Student Subjects**: The subjects studied by the student. This is a required field.
* **Student Institution**: The school or institution attended by the student. This is a required field.
* **Student Name**: The name of the student. This is a required field.
* **Teacher Name**: The name of the teacher. This is a required field.
* **Role**: The role of the teacher or student. This is a required field.
* **Email**: The email address of the teacher or student. This is a required field.
* **Phone**: The phone number of the teacher or student. This is a required field.
* **Expected Participants**: Any additional participants in the event. This is an optional field.
* **Event Description** (optional): A brief description of the event. This field is not required but helps in getting a clear picture of the event.
* **Phone** (optional): An additional contact phone number. This field is not required but can be useful for follow-up purposes.

Note: Please ensure you complete all the required fields to ensure a smooth and accurate registration process.
