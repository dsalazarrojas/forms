# Digital Empowerment For Educators Registration Form - Help Guide
## Purpose
The purpose of this form is to collect information from teachers to register for the Digital Empowerment for Educators program. This program aims to provide teachers with resources and support to enhance their teaching practices and stay updated with the latest technology.

## How To Complete This Form
1. Please fill out the form completely and accurately with your personal and professional information.
2. Select your interests from the drop-down menu to indicate your areas of interest.
3. If you have previously registered for this program, please do not proceed.
4. If you are unsure about any information, please contact the administration team for clarification.

## Field-by-Field Explanation

* **First name** (`first_name`, text, required/optional): Enter your first name.
* **Last name** (`last_name`, text, required/optional): Enter your last name.
* **Email** (`email`, email, required/optional): Enter a valid email address that you use to receive updates about the program.
* **Phone** (`phone`, text, required/optional): Enter a phone number that we can use to contact you.
* **Institution** (`institution`, text, required/optional): Enter the name of the institution where you work.
* **Grade level** (`grade_level`, number, required/optional): Select the grade level you currently teach.
* **District** (`district`, text, required/optional): Enter the name of the district where you work.
* **School name** (`school_name`, text, required/optional): Enter the name of the school where you teach.
* **Interests** (`interests`, select_multiple, required/optional): Select all the areas of interest that apply to you.
	+ AI
	+ Data Science
	+ Cybersecurity
	+ Digital Literacy
	+ Game Development
	+ Game Theory
	+ Human-Computer Interaction
	+ Information Systems
	+ Machine Learning
	+ Mathematics
	+ Natural Language Processing
	+ Network Security
	+ Software Development
	+ User Experience (UX)
	+ Web Development
	+ Web Design
* **Motivations** (`motivations`, select_one, required/optional): Select the reason why you are registering for this program.
	+ I want to develop new skills
	+ I want to stay up-to-date with the latest technology
	+ I want to improve my current skills
	+ Other
	+ I want to start a new career path
	+ I want to enhance my current role
	+ I want to teach others
	+ I want to learn new technologies
	+ I want to solve real-world problems
* **Number of sign-ups** (`num_teacher_sign_ups`, number, required/optional): Enter the number of teachers you plan to register.
* **Teacher sign-up date** (`teacher_sign_up_date`, date, required/optional): Select the date you plan to sign up more teachers.
* **Teacher notes** (`teacher_sign_up_teacher_notes`, note, required/optional): Enter any additional notes about your teacher sign-ups.
* **Teacher email** (`teacher_sign_up_email`, email, required/optional): Enter the email address of the teacher you will be contacting.
* **Teacher phone** (`teacher_sign_up_phone`, text, required/optional): Enter the phone number of the teacher you will be contacting.
* **Program name** (`program_name`, text, required/optional): Enter the name of the program you are registering for.
* **Program start date** (`program_start_date`, date, required/optional): Select the start date of the program.
