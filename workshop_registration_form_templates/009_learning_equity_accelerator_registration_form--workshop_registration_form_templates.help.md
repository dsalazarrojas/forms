# learning_equity_accelerator_registration_form - Help Guide
## Purpose
The "Learning Equity Accelerator Registration Form" is a tool used to collect data related to the learning equity programs, funding, and other relevant activities.

## How To Complete This Form
1. Fill out the form with your First name.
2. Fill out the form with your Last name.
3. Enter a valid Email address.
4. Enter a valid Phone number.
5. Select a Workshop date from the provided options.
6. Select a Workshop time from the provided options.
7. Enter a Workshop location (optional).
8. Enter any additional Workshop details (optional).
9. Select whether you are part of a Learning equity program.
10. Select the Learning equity funding options as required.
11. Enter Learning equity objectives (optional).
12. Enter Learning equity outcomes (optional).
13. Enter Learning equity partners (optional).
14. Select the Learning equity funding status.
15. Select the Learning equity funding currency.
16. Select whether the Learning equity funding frequency applies.
17. Select the Learning equity funding source.
18. Enter the Learning equity funding destination (optional).
19. Enter the Learning equity funding start date.
20. Enter the Learning equity funding end date.
21. Select whether the Learning equity funding amount is in currency.
22. Select whether the Learning equity funding amount frequency applies.
23. Enter the Learning equity funding amount.
24. Enter the Learning equity funding source.
25. Enter the Learning equity funding destination (optional).

* **First name** (First name, text, Required): Enter your first name.
* **Last name** (Last name, text, Required): Enter your last name.

* **Phone number** (Phone number, number, Optional): Enter your phone number.

* **Learning equity funding** (Learning equity funding, select_multiple, Required): Select the learning equity funding options as required.
* **Learning equity objectives** (Learning equity objectives, text, Optional): Enter learning equity objectives.
* **Learning equity outcomes** (Learning equity outcomes, text, Optional): Enter learning equity outcomes.
* **Learning equity partners** (Learning equity partners, text, Optional): Enter learning equity partners.
* **Learning equity funding status** (Learning equity funding status, select_one, Optional): Select the learning equity funding status.
* **Learning equity funding currency** (Learning equity funding currency, select_one, Required): Select the learning equity funding currency.
* **Learning equity funding frequency** (Learning equity funding frequency, select_one, Required): Select whether the learning equity funding frequency applies.
* **Learning equity funding source** (Learning equity funding source, text, Optional): Enter the learning equity funding source.
* **Learning equity funding destination** (Learning equity funding destination, text, Optional): Enter the learning equity funding destination.
* **Learning equity funding start date** (Learning equity funding start date, date, Required): Enter the learning equity funding start date.
* **Learning equity funding end date** (Learning equity funding end date, date, Required): Enter the learning equity funding end date.

* **Learning equity funding destination** (Learning equity funding destination, text, Optional): Enter the learning equity funding destination.
