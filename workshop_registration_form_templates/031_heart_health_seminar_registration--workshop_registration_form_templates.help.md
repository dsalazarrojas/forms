# heart_health_seminar_registration - Help Guide
## Purpose
This form is for workshop registration for the heart health seminar. Please fill out this form to provide necessary information for a smooth and enjoyable experience at the event.

## How To Complete This Form
To complete this form, simply follow the instructions below for each field.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): This field is for your name. Please enter your name as you would like it to appear on any event materials.
* **Last Name** (`last_name`, text, optional): This field is for your last name. Similar to the first name field, enter your last name as you would like it to appear on event materials.
* **Email** (`email`, email, optional): Enter your email address. This is where we will contact you with important event details and updates.
* **Phone Number** (`phone_number`, text, optional): If you would like to be contacted by phone, enter your phone number here.
* **Consent** (`consent`, select one, required): Please indicate your consent to receive event updates and information via email.
* **Preferred Language** (`preferred_language`, select one, optional): If you would like to receive event information in a specific language, select that language here.
* **Preferred Time** (`preferred_time`, time, optional): If you would like to arrive at the event early or late, let us know your preferred time here.
* **Note** (`note`, text, optional): If you have any additional information or requests, enter them here.
* **Event Details** (`event_details`, text, optional): If you have any comments or requests regarding the event, enter them here.
* **Event Preferences** (`event_preferences`, select multiple, optional): Select any preferences you have for the event, such as wanting lunch or snacks.
* **Workshop Preferences** (`workshop_preferences`, select multiple, optional): Select any preferences you have for the workshop, such as topics like Heart Health, Nutrition, or Fitness.
* **Additional Information** (`additional_information`, text, optional): If you would like to provide any additional information, enter it here.
* **Clinic Name** (`clinic_name`, text, optional): If your event is hosted at a specific clinic, enter the name here.
* **Nonprofit Name** (`nonprofit_name`, text, optional): If your event is associated with a nonprofit organization, enter the name here.
* **Address** (`address`, text, optional): If you would like to provide an address for event information, enter it here.
* **Zip** (`zip`, text, optional): Enter your zip code for event information purposes.

Please note that some fields are optional, but it's always a good idea to fill them out if possible to ensure we can provide the best experience for you.
