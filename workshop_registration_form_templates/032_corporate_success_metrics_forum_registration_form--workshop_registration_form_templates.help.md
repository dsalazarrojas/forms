# Corporate Success Metrics Forum Registration Form - Help Guide
## Purpose
The Corporate Success Metrics Forum Registration Form is a template for creating form templates to register users for a Corporate Success Metrics Forum. It is designed to capture event preferences and manage data collection for attendees.

## How To Complete This Form
To complete this form, simply fill in the required fields, which are marked as "required". You can leave optional fields blank if not applicable.

## Field-by-Field Explanation

* **Corporate Success Metrics Forum Registration Form** (`form_title`, text, required: false): Enter the title of the form template, which should be the same as the form's name.
* **Category** (`category`, select_one, required: false): Select the category of the form template, which is currently limited to "Workshop Registration Form Templates" and "Meeting Registration Form Templates".
* **Description** (`description`, note, required: false): This field is a note field where you can enter a brief description of the form template.
* **Form ID** (`form_id`, number, required: false): Enter a unique ID for the form template.
* **Assigned Tool** (`assigned_tool`, text, required: false): Enter the tool assigned to the form template.
* **Output File** (`output_file`, text, required: false): Enter the output file for the form template.

## Tips
* Ensure that you fill in all required fields to ensure accurate form creation.
* Use this form template as intended for Corporate Success Metrics Forum registration, and avoid duplicating or using it for other purposes.
