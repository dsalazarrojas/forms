# Nursing Program Workshop Registration Form - Help Guide

## Purpose
This form is used to register for a Nursing Program Workshop. It collects information from applicants, including their contact details, attendance date and time, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the number of applicants attending the workshop in the "Applicant Count" field.
2. Fill in the "Full Name" field with the name of the applicant.
3. Provide the applicant's "Contact Information" in the "Contact Information" field, including their email address and phone number.
4. Enter the applicant's "Email" address.
5. Enter the applicant's phone number in the "Phone" field.
6. Select the correct "Attendance Date" from the calendar or manually input it.
7. Choose the "Attendance Time" for the workshop from the dropdown.
8. Select "True" or "False" for "Select One" as required.
9. Select multiple options from the "Select Multiple" field as required.
10. Enter any additional notes or comments in the "Notes" field.
11. If applicable, enter the assigned tool or equipment in the "Assigned Tool" field.
12. If applicable, enter the output file or document in the "Output File" field.
13. Fill in the "Form ID" field with the provided ID.
14. Provide a brief description in the "Description" field (optional).

## Field-by-Field Explanation
* **Applicant Count**: Enter the number of applicants attending the workshop.
* **Full Name**: Enter the applicant's full name.
* **Contact Information**: Enter the applicant's email address and phone number.
* **Email**: Enter the applicant's email address.
* **Phone**: Enter the applicant's phone number.
* **Attendance Date**: Select the date the applicant will attend the workshop or manually input it.
* **Attendance Time**: Select the time the applicant will attend the workshop from the dropdown options.
* **Select One**: Select "True" or "False" as required.
* **Select Multiple**: Select multiple options as required.
* **Notes**: Enter any additional notes or comments about the applicant.
* **Assigned Tool**: If applicable, enter the assigned tool or equipment.
* **Output File**: If applicable, enter the output file or document.
* **Form ID**: Fill in the provided form ID.
* **Category**: Enter the category or topic of the workshop.
* **Description**: Enter a brief description of the workshop (optional).
