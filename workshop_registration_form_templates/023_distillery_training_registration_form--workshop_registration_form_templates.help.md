# Distillery Training Registration Form - Help Guide
## Purpose
This form is intended for registering participants in a workshop or training event hosted by the distillery. To ensure accurate registration, please complete the form carefully and thoroughly.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your class details in the "Class Details" section.
2. Enter the participant's details in the "Participant Details" section.
3. Select the class status as "Active" or "Inactive" in the "Class Status" section.
4. (Optional) Add any additional payment details if applicable in the "Payment Details" section.
5. Add any additional information in the "Additional Information" section.
6. List the participants in attendance for the class in the "Participants List" section.
7. Briefly describe the submission workflow in the "Submission Workflow" section.

## Field-by-Field Explanation

* **Class Details** (id: 1, text, required: false):
	+ Enter the name of the class or workshop you are registering for.
* **Participant Details** (id: 2, text, required: false):
	+ Enter the name, email, and any other relevant details of the participant.
* **Class Status** (id: 3, select_one, required: false):
	+ Select "Active" if the class is currently active or has not been cancelled, "Inactive" if it has been cancelled.
* **Payment Details** (id: 4, text, required: false):
	+ If you have paid or have any payment-related information, enter it here (e.g., invoice number, payment method).
* **Additional Information** (id: 5, note, required: false):
	+ Add any additional comments or information about the participant or class that may be helpful for organizers.
* **Participants List** (id: 6, text, required: false):
	+ List the names of the participants attending the class, separated by commas or on separate lines.
* **Submission Workflow** (id: 7, text, required: false):
	+ Describe the submission process for the workshop, including any specific requirements or deadlines.

Please note that each field is optional unless marked as "required", but it's recommended to fill in as much information as possible for accurate registration.
