# event_planning_survey_template - Help Guide
## Purpose
This form is designed to collect feedback from event attendees to help improve future event planning and enhance the overall attendee experience.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Answer each question honestly, taking care to select the most accurate response for each prompt.
2. For questions with multiple options, select all that apply.
3. For open-ended questions, provide as much detail as possible to help event planners understand your thoughts and suggestions.

## Field-by-Field Explanation

* **Overall Satisfaction** (`overall_satisfaction`, `single`, required): This question asks about your overall satisfaction with the event. Please select how satisfied you were with the event, with options ranging from "Very satisfied" to "Very dissatisfied".
* **Most Valuable Sessions or Activities** (`most_valuable_sessions`, `multiple`, required): This question asks which sessions or activities you found most valuable. Select all that apply from the options provided: Keynote speeches, Breakout sessions, Workshops, Networking activities, and Panel discussions.
* **Event Organization** (`event_organization`, `single`, required): This question asks about your perception of how well the event was organized and executed. Please select your response from the options: "Very likely", "Somewhat likely", "Neutral", "Unlikely", or "Very unlikely".
* **Likelihood of Attending Similar Events** (`likelihood_attending_similar_events`, `single`, required): This question asks about your likelihood of attending similar events in the future. Select your response from the options: "Very likely", "Somewhat likely", "Neutral", "Unlikely", or "Very unlikely".
* **Expectations Met or Exceeded** (`expectations_met`, `text`, optional): This question allows you to specify what aspects of the event met or exceeded your expectations. Please provide as much detail as possible.
* **Suggestions for Improvement** (`suggestions`, `text`, optional): This question invites you to share any suggestions you have for improving future events. Please provide specific, actionable ideas to help event planners make informed decisions.
