# T Shirt Order Form - Help Guide
## Purpose
The T Shirt Order Form is used to collect information for t-shirt orders, including retail, wholesale, and custom orders.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the t-shirt details.
2. Enter the price of the t-shirt.
3. Specify the quantity of the t-shirt(s).
4. Select the color of the t-shirt.
5. Select the size of the t-shirt (if applicable).
6. Indicate the order type (Retail, Wholesale, or Custom).
7. Enter the customer's name.
8. Enter the customer's phone number.
9. Enter the customer's email.
10. Set the shipping date.
11. Set the shipping time.
12. Add any additional notes or order comments (optional).

## Field-by-Field Explanation

* **T-Shirt Details** (required): This field is for entering the details of the t-shirt being ordered.
* **Price** (required): Enter the price of the t-shirt.
* **Quantity** (required): Enter the quantity of the t-shirt(s) being ordered.
* **Color** (optional): Select the color of the t-shirt from the dropdown menu.
* **Size** (optional): Select the size of the t-shirt from the dropdown menu.
* **Order Type** (required): Select the type of order (Retail, Wholesale, or Custom).
* **Customer Name** (required): Enter the customer's name.
* **Customer Phone** (required): Enter the customer's phone number.
* **Customer Email** (required): Enter the customer's email address.
* **Shipping Date** (required): Set the date for shipping the order.
* **Shipping Time** (required): Set the time for shipping the order.
* **Notes/Order Comments** (optional): Add any additional information or notes about the order.
* **Order Comments** (optional): Add any additional comments about the order.
