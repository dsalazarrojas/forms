# Sports T Shirt Order Form - Help Guide
## Purpose
The Sports T Shirt Order Form is designed to capture information for internal sales purposes, specifically for salesmen to take orders for T shirts from teams. The form is used to gather data about the team name, quantity, size, order date, delivery date, order total, order status, and customer name.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the team name in the "Team Name" field. This field is used to identify the team for whom the T shirts are being ordered.
2. Select the quantity of T shirts to be ordered from the "Quantity" field.
3. Choose the T shirt size from the "T Shirt Size" dropdown menu.
4. Enter the order date in the "Order Date" field. This date should be the date the order was placed.
5. Enter the delivery date in the "Delivery Date" field. This date should be the date the order is expected to be delivered.
6. Enter the total value of the order in the "Order Total" field.
7. Select the current status of the order from the "Order Status" dropdown menu.
8. Enter the customer's name in the "Customer Name" field.

## Field-by-Field Explanation

* **Team Name (text, required: false)**: Enter the name of the team for whom the T shirts are being ordered.
* **Quantity (number, required: false)**: Enter the quantity of T shirts to be ordered.
* **T Shirt Size (select_one, required: false)**: Choose the size of the T shirt from the dropdown menu:
	+ Large
	+ X-Large
	+ Small
	+ Medium
* **Order Date (date, required: false)**: Enter the date the order was placed.
* **Delivery Date (date, required: false)**: Enter the date the order is expected to be delivered.
* **Order Total (number, required: false)**: Enter the total value of the order.
* **Order Status (select_one, required: false)**: Select the current status of the order from the dropdown menu:
	+ New
	+ In Progress
	+ On Hold
	+ Completed
	+ Cancelled
* **Customer Name (text, required: false)**: Enter the name of the customer.
