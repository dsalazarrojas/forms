# School T Shirt Purchase Form - Help Guide
## Purpose
This form is used to collect information from customers about their school t-shirt purchase preferences.

## How To Complete This Form
To complete this form, follow the steps below:

1. **Check if you want to purchase a school t-shirt**:
   - If you're interested in purchasing a school t-shirt, select "Yes" in the **school_t_shirt_class** field.
   - If not, select "No".

2. **Choose your class**:
   - If you've selected "Yes" in the **school_t_shirt_class** field, select the relevant class from the dropdown menu in the **class** field.

3. **Enter the fee associated with the purchase**:
   - If you've selected "Yes" in the **school_t_shirt_class** field, enter the fee associated with the purchase in the **school_t_shirt_fee** field. This field is a numerical input field.

4. **Enter the students' names**:
   - If you've selected "Yes" in the **school_t_shirt_class** field, enter the students' names in the **student_name** field. This field is a multiple-choice input field.

5. **Choose the students' sizes**:
   - If you've selected "Yes" in the **school_t_shirt_class** field, choose the students' sizes from the dropdown menu in the **student_size** field.

6. **Choose the t-shirt color**:
   - If you've selected "Yes" in the **school_t_shirt_class** field, choose the t-shirt color from the dropdown menu in the **school_t_shirt_color** field.

7. **Enter the quantity of t-shirts**:
   - If you've selected "Yes" in the **school_t_shirt_class** field, enter the quantity of t-shirts in the **school_t_shirt_quantity** field. This field is a numerical input field.

## Field-by-Field Explanation
- **school_t_shirt_class** (Select One): Check if you want to purchase a school t-shirt. If yes, continue with the form.
- **school_t_shirt_fee** (Number): Enter the fee associated with the purchase if you've selected "Yes" in the **school_t_shirt_class** field.
- **student_name** (Select Multiple): Enter the students' names if you've selected "Yes" in the **school_t_shirt_class** field.
- **student_size** (Select One): Choose the students' sizes from the dropdown menu if you've selected "Yes" in the **school_t_shirt_class** field.
- **school_t_shirt_color** (Select One): Choose the t-shirt color from the dropdown menu if you've selected "Yes" in the **school_t_shirt_class** field.
- **school_t_shirt_quantity** (Number): Enter the quantity of t-shirts if you've selected "Yes" in the **school_t_shirt_class** field.

## Tips
* Make sure to fill in all the required fields (indicated by *).
* Review the form before submitting to ensure all the required fields are filled in correctly.
* If you're unsure about any field, refer to the guidelines above for clarification.
