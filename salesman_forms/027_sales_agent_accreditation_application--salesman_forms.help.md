# Sales Agent Accreditation Application - Help Guide
## Purpose
The Sales Agent Accreditation Application form is used to submit an application for sales agent accreditation. This form helps us to gather essential information from the sales agent and their agency to evaluate their application.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Review each field carefully to ensure you provide the correct details.
3. Submit the form when you have completed it.

## Field-by-Field Explanation

* **Sales Agent Info** (`sales_agent_info`, `text`, required: false): Please enter your name as a sales agent.
* **Sales Agent Documents** (`sales_agent_documents`, `text`, required: false): Please attach any relevant documents, such as ID or certifications.
* **Sales Agent Agency Name** (`sales_agent_agency_name`, `text`, required: false): Enter the name of your agency.
* **Sales Agent Agency Address** (`sales_agent_agency_address`, `text`, required: false): Enter your agency's address.
* **Sales Agent Agency Phone** (`sales_agent_agency_phone`, `text`, required: false): Enter your agency's contact phone number.
* **Sales Agent Agency Email** (`sales_agent_agency_email`, `email`, required: false): Enter your agency's email address.
* **Sales Agent Manager Name** (`sales_agent_manager_name`, `text`, required: false): Enter the name of your manager.
* **Sales Agent Manager Phone** (`sales_agent_manager_phone`, `text`, required: false): Enter your manager's contact phone number.
* **Sales Agent Manager Email** (`sales_agent_manager_email`, `email`, required: false): Enter your manager's email address.
* **Sales Agent Manager Relationship** (`sales_agent_manager_relationship`, `select_one`, required: false): Select the type of relationship between you and your manager. Options are Sales, Manager, and Owner.
* **Sales Agent Manager Title** (`sales_agent_manager_title`, `text`, required: false): Enter your manager's title.
* **Sales Agent Accreditation Status** (`sales_agent_accreditation_status`, `select_one`, required: false): Select the status of your accreditation. Options are Pending, Accredited, and Denied.
* **Reason Denied** (`sales_agent_reason_denied`, `text`, required: false): If your accreditation is denied, enter the reason for denial.

Note: Fields marked as "required: false" are optional and can be left blank if not applicable.
