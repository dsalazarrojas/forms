# Book Restoration Quote Request - Help Guide
## Purpose
This form is for requesting a quote for book restoration services. Fill it out to provide us with information about your book, the type of restoration you need, and your contact information.

## How To Complete This Form

To complete this form, follow the steps below:

1. Fill in your contact information: Provide your full name, email address, and phone number so we can get in touch with you.
2. Add book details: Enter the book's title, author, and publication year.
3. Describe the damage: Select the types of damage on the book and provide a detailed description.
4. Choose the type of restoration: Select the type of restoration you require, such as stabilizing the condition or making it readable.
5. Set a desired completion date: If you have a specific deadline, let us know when you'd like the work completed.
6. Choose a quote delivery method: Select how you'd like to receive your quote.

## Field-by-Field Explanation

* **Full Name** (Required, Text): Enter your first and last name for communication purposes.
* **Email Address** (Required, Email): Enter the email address where you'd like to receive the quote.
* **Phone Number** (Required, Text): Provide your phone number for discussion or follow-up questions.
* **Organization Name** (Optional, Text): If you're representing a library or museum, enter the name here.
* **Book Title** (Required, Text): Enter the full title of the book.
* **Book Author** (Optional, Text): Enter the author's name if you know it.
* **Publication Year** (Optional, Number): Enter the year the book was published.
* **Estimated Age of Book** (Required, Select One): Select the age of the book (Less than 25 years, 25-50 years, 50-100 years, 100-150 years, Over 150 years, or Unknown).
* **Type of Book** (Required, Select One): Select the type of book (Hardcover, Paperback, Leather Bound, Manuscript, Rare Book, Religious Text, or Other).
* **Book Dimensions** (Optional, Text): Provide the approximate height and width of the book.
* **Type of Damage** (Required, Select Multiple): Select all types of damage that apply (Torn Pages, Water Damage, Fire Damage, Mold or Mildew, Insect Damage, Spine Damage, Cover Detached, Loose Pages, Writing or Marks, Faded Text).
* **Detailed Damage Description** (Required, Text): Describe the damage in detail.
* **Damage Severity** (Required, Select One): Select the severity of the damage (Minor, Moderate, Severe, Critical).
* **Estimated Book Value** (Optional, Select One): If you know the value of the book, approximate it here (Under $100, $100-$500, $500-$1000, $1000-$5000, Over $5000, Sentimental Value Only, or Unknown).
* **Restoration Photos** (Optional, Text): Upload photos of the book's damage, if possible.
* **Urgency Level** (Required, Select One): Select how urgent you need the restoration (Not Urgent, Somewhat Urgent, Urgent, Very Urgent).
* **Desired Completion Date** (Optional, Date): Enter the date you'd like the work completed.
* **Estimated Budget Range** (Optional, Select One): Select your expected budget range (Under $100, $100-$250, $250-$500, $500-$1000, Over $1000, No Budget Limit).
* **Restoration Goals** (Required, Select Multiple): Select the restoration goals you have (Stabilize Condition, Improve Appearance, Make Readable, Preserve for Display, Increase Value, Full Restoration).
* **Has This Book Been Restored Before** (Optional, Select One): Select if this book has been restored before (True, False, Not Sure).
* **Previous Restoration Notes** (Optional, Text): Describe any previous restoration work done on the book.
* **How Did You Hear About Us** (Optional, Select One): Select how you found our services (Search Engine, Social Media, Referral, Library Recommendation, Website, Other).
* **Additional Comments** (Optional, Text): Any other information you'd like to share with us.
* **Quote Delivery Preference** (Required, Select One): Select how you'd like to receive the quote (Email, Phone Call, Video Consultation, In Person).
