# Promotional-Email-Authorization-Form - Help Guide
## Purpose
The promotional-email-authorization-form is a form used to collect data from customers for email marketing purposes. It is intended to be used to obtain explicit consent from customers to send promotional emails to them.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your name in the "Customer Name" field.
2. Enter your email address in the "Email" field.
3. If applicable, enter your company name in the "Company" field.
4. Select your preferred email frequency from the "Preferred Email Frequency" dropdown menu.
5. Check the box next to "Consent for Email Marketing" if you agree to receive promotional emails.
6. Add any additional comments or questions in the "Additional Comments" field (optional).
7. Briefly describe the purpose of the form in the "Description of Form Purpose" field (optional).
8. Select a category for your entry from the "Category" dropdown menu.
9. Enter a unique Form ID in the "Form ID" field.
10. Optionally, upload a file to the "Output File" field.
11. Enter a name for the output file in the "Output File Name" field.
12. Enter the path to save the output file in the "Output File Path" field.

## Field-by-Field Explanation

* **Customer Name** (`Customer Name`, text, required): Enter your name as it appears on your official identification.
* **Email** (`Email`, email, required): Enter your email address that you want us to use to send you promotional emails.
* **Company** (`Company`, text, optional): If you are filling out this form on behalf of a company, please enter the company name.
* **Preferred Email Frequency** (`Preferred Email Frequency`, select_multiple, required): Select how often you would like to receive emails from us.
	+ Daily
	+ Weekly
	+ Monthly
* **Consent for Email Marketing** (`Consent for Email Marketing`, checkbox, required): Check this box if you agree to receive promotional emails from us.
* **Additional Comments** (`Additional Comments`, text, optional): Add any additional comments or questions you have.
* **Description of Form Purpose** (`Description of Form Purpose`, text, optional): Briefly describe the purpose of this form.
* **Category** (`Category`, select_one, required): Select a category for your entry.
	+ Email Marketing Forms
	+ Other
* **Form ID** (`Form ID`, number, required): Enter a unique identifier for this form entry.
* **Output File** (`Output File`, text, optional): Upload a file to be used in conjunction with this form entry.
* **Output File Name** (`Output File Name`, text, optional): Enter a name for the output file.
* **Output File Path** (`Output File Path`, text, optional): Enter the path to save the output file.
