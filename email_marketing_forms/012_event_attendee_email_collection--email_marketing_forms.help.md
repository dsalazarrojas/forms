# Event Attendee Email Collection - Help Guide
## Purpose
This form is designed to collect essential information about attendees for event organization and communication.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Conference Name** (Page 1) - This is the name of the event or conference that the attendee is attending.
2. Enter the **Attendee First Name** and **Attendee Last Name** (Page 2) - These fields are for the first and last names of the event attendee.
3. Enter the **Attendee Email** (Page 2) - This is the email address of the event attendee.
4. Enter the **Attendee Phone** (Page 2) - This is the phone number of the event attendee (optional).
5. Select the **Preferred Communication Channel** (Page 3) - Choose how the attendee wants to receive updates and notifications, either via **Email**, **Phone**, or **Mail**.
6. If applicable, select whether the attendee **Attended the Conference** (Page 3) - This indicates whether the attendee attended the conference or not.
7. Confirm **Consent to Conference Data** (Page 3) - Check the box to indicate if you consent to share your contact information with the conference organizer.
8. Optionally, provide **Additional Information** (Page 4) - If there is any other relevant information about the attendee, you can provide it here.
9. Add any **Notes** (Page 4) - Use this field to make any general comments about the attendee.

## Field-by-Field Explanation

* **Conference Name**: Enter the name of the event or conference that the attendee is attending.
* **Attendee First Name**: Enter the first name of the attendee.
* **Attendee Last Name**: Enter the last name of the attendee.
* **Attendee Email**: Enter the email address of the attendee.
* **Attendee Phone**: Enter the phone number of the attendee (if applicable).
* **Preferred Communication Channel**: Choose how the attendee wants to receive updates and notifications. Select one of the following options:
	+ **Email**: Send updates and notifications to the attendee via email.
	+ **Phone**: Send updates and notifications to the attendee via phone.
	+ **Mail**: Send updates and notifications to the attendee via mail.
* **Attended Conference**: If applicable, select whether the attendee attended the conference or not.
* **Consent to Conference Data**: Confirm whether you consent to share your contact information with the conference organizer.
* **Additional Information**: Provide any additional information about the attendee (if applicable).
* **Notes**: Add any general comments about the attendee.
