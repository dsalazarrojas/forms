# rotational_grazing_feedback_survey - Help Guide
## Purpose
This form is designed to collect feedback from end-users on their experience with the rotational grazing feedback surveys in a specific research program.

## How To Complete This Form
1. The form consists of 12 fields, each with different types of questions.
2. Please fill out as many or as few fields as you need, depending on your experience and willingness to provide feedback.
3. Be as specific as possible when answering each question to help us better understand your experience.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `text`, optional): Briefly describe your experience with the rotational grazing feedback surveys.
* **Benefits** (`benefits`, `text`, optional): Please list the benefits you found from using the surveys, if any.
* **Challenges** (`challenges`, `text`, optional): Share any challenges you faced while using the surveys.
* **Satisfaction** (`satisfaction`, `select_multiple`, optional): Select all the options that apply to your satisfaction level with the program:
	+ Option 1
	+ Option 2
	+ Option 3
* **Comments** (`comments`, `note`, optional): If you have any general comments or suggestions, please provide them here.
* **Additional Comments** (`additional_comments`, `note`, optional): If you have any additional comments or suggestions, please provide them here.
* **Program Benefits** (`program_benefits`, `text`, optional): Describe any benefits you found from the program.
* **Research Areas** (`research_areas`, `text`, optional): Share any specific research areas you think the program covered.
* **Contact Information** (`contact_info`, `select_one`, optional): Select the best option that describes your contact information:
	+ Option 1
	+ Option 2
	+ Option 3
* **Email** (`email`, `email`, optional): If you provided an email address, please enter it here.
* **Phone** (`phone`, `text`, optional): If you have a phone number, please enter it here.
* **Assigned Tool** (`assigned_tool`, `text`, optional): If you have any additional information about the tool you were assigned, please provide it here.

## Tips
- Please be honest and as specific as possible when answering each question.
- You can skip any fields you don't feel comfortable filling out.
- If you have any questions or concerns, please contact us through the contact information provided above.
