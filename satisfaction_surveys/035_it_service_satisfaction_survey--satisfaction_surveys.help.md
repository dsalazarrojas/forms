# IT Service Satisfaction Survey - Help Guide
## Purpose
The IT Service Satisfaction Survey is designed to gather end-user feedback on the quality of the IT service. This survey aims to understand your satisfaction levels, how often you contact the IT service, and your preferences for improvement.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Read each question carefully and select the most appropriate answer.
2. Answer each question truthfully, providing as much detail as possible.
3. If you have any comments or suggestions, please feel free to share them in the designated fields.

## Field-by-Field Explanation
* **IT Service Satisfaction Survey** (`title`, optional): This field is the title of the survey, which is meant to be left blank.
* **Overall Satisfaction** (`overall_satisfaction`, optional): Rate your overall satisfaction with the IT service. You can select from the following options:
	+ Not Satisfied
	+ Slightly Satisfied
	+ Neutral
	+ Slightly Dissatisfied
	+ Dissatisfied
* **Rating Scale** (`rating_scale`, optional): This is a scale to rate your overall satisfaction. Select from:
	+ Not Satisfied
	+ Slightly Satisfied
	+ Neutral
	+ Slightly Dissatisfied
	+ Dissatisfied
* **What is your primary function?** (`question1`, optional): Please select the function that you primarily use the IT service for. You can select one or more of the following options:
	+ Help Desk
	+ Project Management
	+ Service Management
	+ Other (please specify)
* **How often do you contact IT?** (`question2`, optional): Rate how often you contact the IT service. You can select one or more of the following options:
	+ Frequently
	+ Occasionally
	+ Rarely
	+ Never
* **What is your primary IT service channel?** (`question3`, optional): Please select the channel you use most frequently to contact the IT service. You can select one of the following options:
	+ Email
	+ Phone
	+ Online Portal
	+ Other (please specify)
* **What would you suggest to improve the IT service?** (`question4`, optional): If you have any suggestions for improvement, please type them in this field.
* **Do you prefer to contact IT?** (`question5`, optional): Please select the method you prefer to contact the IT service. You can select one or more of the following options:
	+ Phone
	+ Email
	+ Online Chat
	+ Visit Office
* **How can we improve the IT service?** (`question6`, optional): If you have any suggestions for improvement, please select one or more of the following options:
	+ Faster Response Time
	+ Easier Access to Information
	+ Better Communication
	+ Other (please specify)
* **Overall Experience** (`question7`, optional): Rate your overall experience with the IT service. You can select one or more of the following options:
	+ Very Good
	+ Good
	+ Average
	+ Very Poor
* **Comments** (`question8`, optional): If you have any comments or feedback, please type them in this field.
* **Do you have other comments?** (`question9`, optional): If you have any additional comments, please type them in this field.
* **Feedback** (`question11`, optional): If you have any feedback or suggestions, please type them in this field.
