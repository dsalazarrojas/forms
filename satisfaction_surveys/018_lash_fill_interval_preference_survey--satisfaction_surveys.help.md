# Lash Fill Interval Preference Survey - Help Guide

**Purpose**
This form is designed to gather data on the frequency and satisfaction of lash fills, as well as the factors that influence these aspects. This data will help us better understand customer preferences and behavior related to lash fills.

**How To Complete This Form**
To complete this form, please follow these steps:

1. Go through each section and answer the questions accordingly.
2. Select multiple options for most questions by holding down the Ctrl key (or Command key on a Mac) and clicking on each option.
3. If a question is optional, you can skip it if you're not sure or don't have an answer.
4. Once you've filled out all the questions, submit the form.
