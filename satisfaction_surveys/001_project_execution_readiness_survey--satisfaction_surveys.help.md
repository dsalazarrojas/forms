## Project Execution Readiness Survey - Help Guide

## Purpose
The Project Execution Readiness Survey is a tool used to evaluate the project execution readiness of projects. It aims to collect information about the project's status, team lead's contact information, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the status of your project by choosing from the dropdown options.
2. Enter the name and email address of your project team lead.
3. Enter the name and email address of your project manager.
4. Select the project deadline.
5. Provide a brief description of the project status.

## Field-by-Field Explanation

* **Project Execution Readiness**: Select "Yes" if your project is ready to be executed, "No" otherwise.
* **project_team_lead** (text): Enter the name of your project team lead.
* **project_team_lead_email** (email): Enter the email address of your project team lead.
* **project_manager** (text): Enter the name of your project manager.
* **project_manager_email** (email): Enter the email address of your project manager.
* **project_status** (select_one): Select the status of your project from the dropdown options "Active" or "Inactive".
* **project_status_description** (text): Provide a brief description of the project status.
* **project_deadline** (date): Select the deadline of your project.

## Tips

* Make sure to fill in all required fields.
* If you are unsure about any field, please ask your project manager or team lead for clarification.
* Please note that this form is not a comprehensive project management tool, but rather a tool to help project teams assess their readiness for project execution.

Note: The fields are designed to be self-explanatory, but if you are still unsure about any field, please refer to the field's label for a brief explanation.
