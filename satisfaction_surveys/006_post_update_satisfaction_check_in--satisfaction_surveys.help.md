# Post Update Satisfaction Check In - Help Guide
## Purpose
The Post Update Satisfaction Check In form is a survey designed to gather feedback about the update's success and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your answer to "Page 1: Post Update Satisfaction Check In" from the options:
	* Yes
	* No
2. Enter your player feedback in the "Player Feedback" field. This is an optional field for players to share their thoughts about the update.
3. Rate the update on a scale of 1-5 in the "Rating" field.
4. Choose whether the update was "Satisfied" or "Dissatisfied" in the "Satisfaction Trend" field.
5. Set the "Fix Priority" for any issues that need to be fixed, with options: "Yes" (high priority) or "No" (low priority).

## Field-by-Field Explanation

* **Page 1: Post Update Satisfaction Check In**: 
	+ Select "Yes" if you think the update was successful, "No" otherwise.
* **Player Feedback**: 
	+ Enter player feedback in this text field. This is an optional field for players to share their thoughts about the update.
* **Rating**: 
	+ Rate the update on a scale of 1-5. A higher rating indicates a more satisfactory update.
* **Satisfaction Trend**: 
	+ Choose whether the update was "Satisfied" or "Dissatisfied" based on your experience.
* **Fix Priority**: 
	+ Set the "Fix Priority" for any issues that need to be fixed, with options: "Yes" (high priority) or "No" (low priority).
* **Release Notes**: 
	+ This is an optional field for developers to add release notes about the update.
* **Player Notes**: 
	+ This is an optional field for players to add notes about the update.

## Tips
* Please be as specific as possible when providing feedback or ratings.
* If you have any issues with the update, use the "Fix Priority" field to set the priority of the fix.
* The "Release Notes" field is for developers to add context about the update, so you can ignore it if you're not a developer.
* The "Player Notes" field is for players to add any additional thoughts or notes about the update.
