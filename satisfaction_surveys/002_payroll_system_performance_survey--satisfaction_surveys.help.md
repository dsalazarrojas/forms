# Payroll System Performance Survey - Help Guide
## Purpose
The "Payroll System Performance Survey" form is designed to gather feedback on the usability and performance of the payroll system. This form helps us understand how often you access payroll data, how you use the payroll system, and which features are most important to you. Your feedback is essential in helping us improve the payroll system for better performance and user experience.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer the questions on each page according to your experience and interaction with the payroll system.
2. Make sure to select the correct options for each question, as indicated by the labels (e.g., "How often do you access payroll data").
3. If you need help or clarification on any question, please refer to the field-by-field explanation below.

## Field-by-Field Explanation
- **How often do you access payroll data** (`how_often_do_you_access_payroll_data`, number, required): This question asks about your frequency of interaction with payroll data. Please select the number that best represents how often you access payroll data.
  - 1: Never
  - 2: Rarely
  - 3: Occasionally
  - 4: Frequently
  - 5: Almost Always
- **What process do you use to access payroll data** (`what_process_do_you_use_to_access_payroll_data`, text, optional): Describe the process you use to access payroll data. This could be a manual process, a specific tool, or a combination of both.
- **How often do you use payroll system** (`how_often_do_you_use_payroll_system`, number, required): This question asks about your frequency of use of the payroll system. Please select the number that best represents how often you use the system.
  - 1: Never
  - 2: Rarely
  - 3: Occasionally
  - 4: Frequently
  - 5: Almost Always
- **What features do you find most important in payroll system** (`what_features_do_you_find_most_important_in_payroll_system`, select_multiple, optional): Select all the features that are most important to you in the payroll system.
  - Important
  - Not Important
  - Neutral
- **Overall satisfaction with current payroll system** (`overall_satisfaction_with_current_payroll_system`, number, required): This question asks about your overall satisfaction with the current payroll system. Please select the number that best represents your satisfaction level.
  - 1: Very Dissatisfied
  - 2: Somewhat Dissatisfied
  - 3: Neutral
  - 4: Somewhat Satisfied
  - 5: Very Satisfied

## Tips
- Be honest and accurate in your responses.
- If you're unsure about any question, please don't hesitate to ask for clarification.
- Your feedback is essential in helping us improve the payroll system.
