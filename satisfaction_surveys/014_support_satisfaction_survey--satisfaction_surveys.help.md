# Support Satisfaction Survey - Help Guide
## Purpose
The Support Satisfaction Survey form is designed to collect feedback from customers about their experience with the support team. This feedback helps us understand what we're doing well and where we need to improve.

## How To Complete This Form
1. **Start by filling out the form title, which is already filled out for you** (Support Satisfaction Survey). This form has multiple pages, and each page contains a field that you need to fill out.
2. **Go through each page, filling out the fields as needed**. Each page will have one or multiple fields that you need to complete.
3. **When you're finished, click the submission button to complete the form**.

## Field-by-Field Explanation

* **Support Survey**: 
	+ Type: text
	+ (no specific instructions available)
* **Customer Name**: 
	+ Type: text
	+ This is the name of the customer who is filling out the form.
* **Support Survey Date**:
	+ Type: date
	+ Enter the date when you received support services.
* **Support Survey Time**:
	+ Type: time
	+ Enter the time when you received support services.
* **Support Agent**:
	+ Type: text
	+ Enter the name or ID of the support agent who assisted you.
* **Support Agent Comment**:
	+ Type: text
	+ Add any comments or feedback about the support agent who helped you.
* **Support Agent Rating**:
	+ Type: number
	+ Rate the support agent from 0 to 5, where 0 is not satisfied and 5 is highly satisfied.
* **Support Satisfaction Level**:
	+ Type: select multiple
	+ Select one or more levels to describe your satisfaction with the support services:
		+ 0: Very dissatisfied
		+ 1: Somewhat dissatisfied
		+ 2: Neutral
		+ 3: Somewhat satisfied
		+ 4: Satisfied
		+ 5: Very satisfied
* **Support Survey Comments**:
	+ Type: text
	+ Add any additional comments about your experience with the support team.
* **Additional Comments**:
	+ Type: text
	+ Add any other comments or suggestions you have for the support team.
* **Support Survey Type**:
	+ Type: text
	+ Please select the type of support survey you are filling out.
* **Support Survey Status**:
	+ Type: text
	+ Select the status of the support survey you are filling out.
