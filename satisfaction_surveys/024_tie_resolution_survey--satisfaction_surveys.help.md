# Tie Resolution Survey - Help Guide

## Purpose
This form is used to collect feedback and satisfaction ratings from users after a competition or tie resolution. The goal is to gauge the effectiveness of the resolution process and identify areas for improvement.

## How To Complete This Form

1. Fill in the required information:
	* Competition Id: This is the unique identifier for the competition that was resolved.
	* tieBreakingMethod: Select the method used to resolve the tie. Options are: 1, 2, 3.
	* satisfactionLevel: Rate your satisfaction with the resolution. Options are: Very Satisfied, Somewhat Satisfied, Somewhat Dissatisfied, Very Dissatisfied.
2. Optional information:
	* improvementIdeas: If you have any suggestions for improvement, please provide them in this text field.

## Field-by-Field Explanation

* **Competition Id** (`competition_id`, number, required): Enter the unique identifier for the competition that was resolved.
* **tieBreakingMethod** (`tieBreakingMethod`, select one, optional): Select the method used to resolve the tie from the options provided.
	+ If you select "1", this means the tie was resolved using method 1.
	+ If you select "2", this means the tie was resolved using method 2.
	+ If you select "3", this means the tie was resolved using method 3.
* **satisfactionLevel** (`satisfactionLevel`, select one, optional): Rate your satisfaction with the resolution.
	+ Very Satisfied: You were very satisfied with the resolution.
	+ Somewhat Satisfied: You were somewhat satisfied with the resolution.
	+ Somewhat Dissatisfied: You were somewhat dissatisfied with the resolution.
	+ Very Dissatisfied: You were very dissatisfied with the resolution.
* **improvementIdeas** (`improvementIdeas`, text, optional): Provide any suggestions you have for improving the resolution process.
