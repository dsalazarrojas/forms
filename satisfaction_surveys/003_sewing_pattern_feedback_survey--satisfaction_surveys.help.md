# Sewing Pattern Feedback Survey - Help Guide

## Purpose
This form is designed to collect feedback from users on our sewing patterns. The purpose of this form is to help us understand what you think about our patterns, what you liked or disliked, and how we can improve them. We value your feedback and use it to refine our pattern designs to better meet your needs.

## How To Complete This Form

1.  Fill out the form completely and accurately. This will help us get a clear understanding of your thoughts and feelings about our patterns.
2.  Select the category of the pattern you are providing feedback on.
3.  Choose the type of pattern that best fits your experience with the pattern.
4.  Select all the features that apply to the pattern.
5.  Provide any comments you may have about the pattern.
6.  Rate your overall experience with the pattern (if applicable).
7.  Enter your email address and phone number (if you would like to be contacted for follow-up questions).
8.  Enter your name, so we can address you personally.

## Field-by-Field Explanation
### Pattern Category
* **Pattern Category** (`pattern_category`, select_one, required): Select the category of the pattern you are providing feedback on. This will help us understand what type of pattern you are commenting on.

### Pattern Type
* **Pattern Type** (`pattern_type`, select_multiple, required): Choose the type that best fits your experience with the pattern. This is a multiple-choice field, select all the types that apply.

### Pattern Size
* **Pattern Size** (`pattern_size`, select_multiple, required): Choose the size range that fits your experience with the pattern. This is a multiple-choice field, select all the sizes that apply.

### Pattern Features
* **Pattern Features** (`pattern_features`, select_multiple, required): Choose all the features that apply to the pattern. This is a multiple-choice field, select all the features that apply.

### Comments
* **Comments** (`comments`, note, required): Provide any comments or suggestions you may have about the pattern. This is a free-text field where you can write your thoughts and opinions.

### Rating
* **Rating** (`rating`, number, required): Rate your overall experience with the pattern (if applicable).

### Email
* **Email** (`email`, email, required): Enter your email address if you would like to be contacted for follow-up questions.

### Phone
* **Phone** (`phone`, text, optional): Enter your phone number if you would like to be contacted for follow-up questions.

### Name
* **Name** (`name`, text, required): Enter your name, so we can address you personally.

Note: This help guide is designed to be user-friendly and easy to follow. If you have any questions or need further clarification, please don't hesitate to contact us.
