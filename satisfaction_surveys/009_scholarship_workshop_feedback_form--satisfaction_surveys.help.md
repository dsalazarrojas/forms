# Scholarship Workshop Feedback Form - Help Guide
## Purpose
The Scholarship Workshop Feedback Form is a tool designed to collect feedback from participants in the scholarship workshop. This form helps to gauge overall satisfaction and gather valuable insights to improve future workshops.

## How To Complete This Form
To complete the form, please follow these steps:

1. Select your overall satisfaction level with the workshop. Choose from the following options: Very Good, Good, Neutral, Bad, or Very Bad.
2. Provide any additional feedback about your experience.
3. Enter any relevant participant information, such as name and affiliation.
4. Share any additional comments or suggestions.
5. If you'd like to provide more feedback, you can enter it in the "More Feedback" field.
6. If you'd like to add more comments, you can do so in the "More Comments" field.
7. If you'd like to provide more suggestions, you can enter them in the "More Suggestions" field.
8. If you'd like to provide the submission time for this form, you can do so in the "Submission Time" field. You can also add a second submission time in the "Submission Time 2" field.
9. If you'd like to provide the submission date for this form, you can do so in the "Submission Date" field.
10. Add any additional note or information that you'd like to share.

## Field-by-Field Explanation

* **Overall Satisfaction** (`Overall Satisfaction`, select_one, **required**): Choose your overall satisfaction with the workshop from the options: Very Good, Good, Neutral, Bad, or Very Bad.
* **Feedback** (`Feedback`, text, optional): Provide any additional feedback about your experience.
* **Participant Info** (`Participant Info`, text, optional): Enter any relevant participant information, such as name and affiliation.
* **Comments** (`Comments`, text, optional): Share any additional comments.
* **Suggestions** (`Suggestions`, text, optional): Provide any suggestions for improvement.
* **Submission Time** (`Submission Time`, time, optional): Enter the submission time.
* **Submission Time 2** (`Submission Time 2`, time, optional): Enter a second submission time.
* **Submission Date** (`Submission Date`, date, optional): Enter the submission date.
* **Note** (`Note`, text, optional): Add any additional note or information.
* **Repeat Participant Info** (`Repeat Participant Info`, text, optional): Enter any repeat participant information.
* **More Feedback** (`More Feedback`, text, optional): Provide more feedback.
* **More Comments** (`More Comments`, text, optional): Add more comments.
* **More Suggestions** (`More Suggestions`, text, optional): Provide more suggestions.

## Tips

* Please be as detailed and specific as possible when filling out the form to help us improve the workshop.
* You can save and come back to your responses later if needed.
* If you have any technical issues or concerns, please contact us at `form@gic.mx`.
