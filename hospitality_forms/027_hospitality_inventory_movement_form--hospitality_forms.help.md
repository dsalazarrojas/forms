# hospitality_inventory_movement_form - Help Guide
## Purpose
The hospitality_inventory_movement_form is designed to facilitate the movement of hospitality items within the organization. It helps to track item transfers, including internal and external transfers.

## How To Complete This Form

1. Select the type of transfer: Choose between Internal Transfer and External Transfer.
2. Select the department from which the item is being transferred.
3. Enter the item name and description.
4. Enter the item quantity.
5. Select the department to which the item is being transferred.
6. Specify whether the item has a serial number.
7. Choose the item status.
8. Add any additional notes.
9. Select the option to create a file.
10. Enter the goals for the transfer.
11. Enter the form ID.
12. Select the option to create a file.
13. Enter the category for the form.
14. Select the type of the form.
15. Enter the name and details of the person assigned to.
16. Select the option to create a file.

## Field-by-Field Explanation

* **Transfer Type (id: 1)**: Select the type of transfer (Internal or External).
* **Department From (id: 2)**: Choose the department where the item is being transferred from.
* **Item Name (id: 3)**: Enter the name of the item being transferred.
* **Item Description (id: 4)**: Enter a brief description of the item being transferred.
* **Item Quantity (id: 5)**: Enter the quantity of the item being transferred.
* **Department To (id: 6)**: Choose the department to which the item is being transferred.
* **Item Serial (id: 7)**: Specify whether the item has a serial number (Yes or No).
* **Item Status (id: 8)**: Choose the item status (Available or Other).
* **Notes (id: 9)**: Add any additional notes about the transfer.
* **Created By (id: 10)**: Select the option to create a file for the transfer.
* **Date (id: 11)**: Enter the date of the transfer.
* **Time (id: 12)**: Enter the time of the transfer.
* **Form ID (id: 13)**: Enter the form ID for the transfer.
* **Assigned To (id: 14)**: Enter the name and details of the person assigned to.
* **Assigned By (id: 15)**: Select the option to create a file for the assigned person.
* **Category (id: 16)**: Enter the category for the form.
* **Form Type (id: 17)**: Select the type of the form.
