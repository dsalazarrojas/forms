# RFID Hotel Connection Form - Help Guide
## Purpose
The "RFID Hotel Connection Form" is designed to gather information from guests in a hotel setting, primarily for check-in or guest registration purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the "Guest Name" field with the guest's name as it appears on their identification documents.
2. Enter the guest's email address in the "Email" field.
3. If available, enter the guest's phone number in the "Phone" field.
4. If the guest is presenting a RFID key card, enter the key card number in the "RFID Key Card Number" field.
5. Select the check-in and check-out times using the time selectors for "Check In Time" and "Check Out Time" fields, respectively.
6. Enter the date of arrival using the date selector for the "Check In Date" field.
7. Select the room number from the available options.
8. Enter the floor number and building name, if applicable.
9. If the guest is staying in multiple rooms, enter the room numbers for each room in the corresponding fields (Room 1 to Room 13).

## Field-by-Field Explanation

* **Guest Name** (`guest_name`, text, optional): Enter the guest's name as it appears on their identification documents.
* **Email** (`guest_email`, text, optional): Enter the guest's email address.
* **Phone** (`guest_phone`, text, optional): Enter the guest's phone number, if available.

* **Check In Time** (`check_in_time`, time, optional): Select the check-in time using the time selector.
* **Check Out Time** (`check_out_time`, time, optional): Select the check-out time using the time selector.
* **Check In Date** (`check_in_date`, date, optional): Enter the date of arrival using the date selector.
* **Room Number** (`room_number`, text, optional): Select the room number from the available options.
* **Floor** (`floor`, text, optional): Enter the floor number where the guest is staying.
* **Building** (`building`, text, optional): Enter the building name, if applicable.
