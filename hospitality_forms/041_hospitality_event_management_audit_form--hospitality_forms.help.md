# Hospitality Event Management Audit Form - Help Guide
## Purpose
The Hospitality Event Management Audit Form is a tool used to gather information about hospitality events. It helps event managers assess various aspects of an event and provides valuable data for future improvements.
## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the required fields with accurate information about the event.
2. Ensure that all fields are completed as thoroughly and accurately as possible.
3. Review your responses before submitting the form to ensure you have provided all necessary information.

## Field-by-Field Explanation
* **Event Name**: Enter the name of the event being audited.
* **Event Start Date**: Enter the date the event started.
* **Event End Date**: Enter the date the event ended.
* **Venue Name**: Enter the name of the venue where the event took place.
* **Event Category**: Select the category of the event (e.g., Hotels, Conference, Wedding, Meeting, Event).
* **Event Type**: Enter a brief description of the event type.
* **Event Location**: Enter the location of the event.
* **Event Planner**: Enter the name of the person or organization planning the event.
* **Event Notes**: Enter any additional notes about the event that may be relevant to the audit.
* **Event Score**: Enter the event score, if applicable.
* **Event Rating**: Enter the event rating, if applicable.
* **Event Feedback**: Enter feedback about the event, if applicable.
* **Event Phone Numbers**: Enter any phone numbers associated with the event.
* **Event Emails**: Enter any contact emails associated with the event.
* **Event Website**: Enter the website of the event.

## Tips
- Please ensure that all fields are completed accurately and thoroughly.
- If you are unsure about any field, refer to the event's documentation or contact the event planner for clarification.
- If you have already completed this form for the same event, please do not submit again to avoid duplication of effort.
