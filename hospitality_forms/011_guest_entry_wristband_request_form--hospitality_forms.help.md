# Guest Entry Wristband Request Form - Help Guide

## Purpose
This form is designed to collect information for the guest entry wristband request process. It ensures that the correct details are captured for wristband distribution during events.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the guest's details in the "Guest Details" field.
2. Enter event information, including the event name, date, and time, in the corresponding fields.
3. Select the type of wristband the guest requires (Standard, VIP, or Kids).
4. Specify the control type and approval status for the entry.
5. Enter the guest's contact information (phone and email).
6. Add any additional comments or notes if required.

## Field-by-Field Explanation

* **Guest Details**: Enter the guest's name, contact number (if applicable), or other identifying information.
* **Event Info**: Provide a brief description of the event, including the name and date.
* **Wristband Request**: Specify the type of wristband needed (Standard, VIP, or Kids).
* **Entry Control**: Select the type of control required for the entry (Standard, VIP, or Kids).
* **Approval Status**: Choose the status of the approval for the entry.
* **Email**: Enter the guest's email address.
* **Phone**: Enter the guest's phone number.
* **Event Name**: Enter the name of the event.
* **Event Date**: Enter the date of the event.
* **Event Time**: Enter the time of the event.
* **Wristband Type**: Select the type of wristband required (Standard, VIP, or Kids).
* **Wristband Color**: If applicable, specify the color of the wristband.
* **Event Organizer**: Enter the name of the event organizer.
* **Approval Comment**: Add any additional comments or information for the approval process.
* **Entry Control Type**: Select the type of entry control required (Standard, VIP, or Kids).
* **Notes**: Add any additional notes or comments.
* **Event Organizer Email**: Enter the email of the event organizer.
* **Event Organizer Phone**: Enter the phone number of the event organizer.
