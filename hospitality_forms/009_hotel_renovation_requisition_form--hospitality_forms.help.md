# Hotel Renovation Requisition Form - Help Guide
## Purpose
The purpose of this form is to collect information and track hotel renovation requests.

## How To Complete This Form
To complete this form, follow the instructions below.

## Field-by-Field Explanation

* **Form Description** (`form_description`, text, not required): Enter a brief description of the renovation request.
* **Category** (`category`, select one, not required): Select the category for the renovation request.
* **Form ID** (`form_id`, number, not required): Enter the ID number for the form.
* **Priority** (`priority`, select one, not required): Select the priority level for the renovation request.
* **Status** (`status`, select one, not required): Select the status of the renovation request.
* **Created By** (`created_by`, select one, required): Select the person who created the request.
* **Updated By** (`updated_by`, select one, not required): Select the person who last updated the request.
* **Created At** (`created_at`, date, not required): Enter the date when the request was created.
* **Updated At** (`updated_at`, date, not required): Enter the date when the request was last updated.
* **Comments** (`comments`, text, not required): Enter any additional comments about the renovation request.
* **Attachments** (`attachments`, select multiple, not required): Select any attachments related to the renovation request.
* **Assigned To** (`assigned_to`, select one, not required): Select the person assigned to handle the request.
* **Due By** (`due_by`, date, not required): Enter the date by which the request is due.
* **Hotel ID** (`hotel_id`, number, not required): Enter the hotel's ID number.
* **Room ID** (`room_id`, number, not required): Enter the room's ID number.
* **Building ID** (`building_id`, number, not required): Enter the building's ID number.
* **Property ID** (`property_id`, number, not required): Enter the property's ID number.
* **Status ID** (`status_id`, select one, not required): Select the status ID for the request.
* **Assigned to ID** (`assigned_to_id`, select one, not required): Select the ID of the person assigned to handle the request.
* **Created by ID** (`created_by_id`, select one, not required): Select the ID of the person who created the request.
* **Updated by ID** (`updated_by_id`, select one, not required): Select the ID of the person who last updated the request.
* **Comments ID** (`comments_id`, select one, not required): Select the ID for comments about the request.
* **Due by ID** (`due_by_id`, select one, not required): Select the ID of the due date for the request.
