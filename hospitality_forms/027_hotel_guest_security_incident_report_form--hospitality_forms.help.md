# Hotel Guest Security Incident Report Form - Help Guide
## Purpose
This form is used for reporting security incidents involving hotel guests. It helps to document and track incidents that require follow-up action or investigation.

## How To Complete This Form

1. Fill out the form with the necessary information, ensuring that all required fields are completed.
2. Be as detailed as possible when describing the incident.
3. Select the correct category and subcategory for the incident from the options provided.
4. If follow-up action is required, enter the relevant details.

## Field-by-Field Explanation

* **Incident Date**: The date the incident occurred.
* **Incident Reporter Name**: The name of the person reporting the incident.
* **Guest Name**: The name of the guest involved in the incident.
* **Incident Description**: A detailed description of what happened.
* **Incident Location**: The location where the incident occurred.
* **Incident Outcome**: The outcome of the incident (Good, Bad, or Unknown).
* **Incident Reporter Phone**: The contact phone number of the incident reporter.
* **Follow-up Required**: Whether follow-up action is required.
* **Follow-up Details**: Additional details about the follow-up action required.
* **Hotel Security Officer**: The name of the person handling the incident follow-up.
* **Incident Type**: A category for the incident (e.g., lost and found, theft, etc.).
* **Incident Status**: The current status of the incident.
* **Comments**: Any additional comments or remarks about the incident.
* **Incident Number**: A unique number assigned to the incident.
* **Incident Category**: A category for the incident (e.g., theft, lost and found, etc.).
* **Incident Category Other**: For incidents that do not fit into the standard categories.
* **Incident Category Other Details**: Additional details about the incident category.
* **Incident Category Other Subcategory**: A subcategory for incidents that do not fit into standard categories.
* **Incident Category Other Subcategory Other**: Additional details about the subcategory.
* **Follow-up Date**: The date for the follow-up action.
* **Follow-up Time**: The time for the follow-up action.
* **Follow-up Contact Name**: The name of the person to contact for follow-up.
* **Follow-up Contact Phone**: The contact phone number for follow-up.
* **Follow-up Contact Email**: The contact email for follow-up.

Please note that some fields may not be required, depending on the specific incident. If you're unsure about a field, it's best to consult with the hotel security team for guidance.
