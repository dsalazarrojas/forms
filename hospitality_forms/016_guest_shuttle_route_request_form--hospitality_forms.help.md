# Guest Shuttle Route Request Form - Help Guide
## Purpose
The Guest Shuttle Route Request Form is designed to help staff and guests plan for a smooth and efficient transportation experience. The form gathers essential information about the guest shuttle route, which will be used by the transportation team to provide an excellent service.

## How To Complete This Form
1. Review the form carefully to ensure you have all the necessary information before submitting it.
2. Fill out the form in a single session to avoid duplicate entries.

## Field-by-Field Explanation

### **Form**
This is the main form section, which serves as a container for the other fields.

### **date**
* Type: Date
* Required: No
* Description: Enter the date of the requested shuttle route.

### **start_time**
* Type: Time
* Required: No
* Description: Enter the start time of the requested shuttle route.

### **end_time**
* Type: Time
* Required: No
* Description: Enter the end time of the requested shuttle route.

### **pick_up_location**
* Type: Text
* Required: No
* Description: Enter the pick-up location for the shuttle route.

### **drop_off_location**
* Type: Text
* Required: No
* Description: Enter the drop-off location for the shuttle route.

### **number_of_guests**
* Type: Number
* Required: No
* Description: Enter the number of guests traveling on the shuttle route.

### **name**
* Type: Text
* Required: No
* Description: Enter your name and/or the name of the guest group.

### **phone**
* Type: Text
* Required: No
* Description: Enter your phone number or the contact phone number of the guest group.

### **email**
* Type: Email
* Required: No
* Description: Enter your email address or the email address of the guest group.

## Tips
* Please ensure that all required fields are filled out accurately to avoid errors.
* If you have any special requests or requirements, please include them in the "name" field.
* If you have any questions or concerns, please contact the transportation team.
