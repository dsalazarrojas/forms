# Media Audio Feed Booking Form - Help Guide
## Purpose
This form is used to collect information for booking media audio feeds.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "User" field with your name and contact information.
2. Enter the "Event" field with the name of the event you are booking the media audio feed for.
3. Select the dates for the booking in the "Dates" field.
4. Choose the start and end dates for the booking in the "Start date" and "End date" fields.
5. Select the time for the booking in the "Time" field.
6. Enter the venue for the event in the "Venue" field.
7. Choose the media audio feed preferences in the "Audio feed" field.
8. Select the production team for the event in the "Production team" field.
9. Select any additional event details in the "Event details" field.
10. Choose the broadcast information in the "Broadcast information" field.
11. Select the schedule for the event in the "Schedule" field.
12. Choose the broadcast options in the "Broadcast" field.
13. Select the audio preferences in the "Audio" field.
14. Select the video preferences in the "Video" field.
15. Select the image preferences in the "Image" field.
16. Select the file preferences in the "File" field.
17. Select the broadcast information in the "Broadcast info" field.
18. Select the audio file preferences in the "Audio file" field.
19. Select the video file preferences in the "Video file" field.
20. Select the image file preferences in the "Image file" field.
21. Select any other information in the "Other info" field.
22. Finally, enter any additional notes in the "Notes" field and click the "Submit" button to complete the form.
