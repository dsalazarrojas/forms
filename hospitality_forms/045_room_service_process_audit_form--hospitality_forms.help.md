# room_service_process_audit_form - Help Guide
## Purpose

This form aims to assess and document the room service process for each shift, focusing on key performance indicators such as quality checks, manager reviews, and team member involvement.

## How To Complete This Form

1.  Complete the form after each shift.
2.  Ensure that each section is filled in accurately and thoroughly.
3.  Be honest when evaluating the quality of service and performance of each shift.

## Field-by-Field Explanation

*   **Room Service Process** (`1`): This field is a brief description of the room service process, which is meant to be a free-form text that summarizes the events of the service period. It should provide a general overview of how each shift was performed.
*   **Quality Checks** (`2`): This is a multiple-choice field where you choose whether quality checks were performed or not for each shift. This field helps in assessing if quality standards were maintained during the service period.
*   **Performance by Shift** (`3`): This field is used to select which shift this audit applies to. Select `Yes` if it applies to one or both shifts, `No` if it does not apply to either.
*   **Date** (`4`): This is the date on which the audit was performed, ensuring that each entry is dated accurately.
*   **Time** (`5`): This is the time at which the audit was completed.
*   **Team Member** (`6`): Select `Yes` if the team member was involved in the room service process, `No` otherwise.
*   **Manager Signature** (`7`): A unique identifier for the manager who performed the audit, allowing for accountability and tracking of who completed the form.
*   **Manager Name** (`8`): The name of the manager who completed the form, which helps identify who was involved in the evaluation process.
*   **Manager Email** (`9`): Contact information for the manager, facilitating follow-up and feedback.
*   **Manager Phone** (`10`): Additional contact information for the manager.
*   **Manager Note** (`11`): An optional free-form text field for any further comments or observations by the manager.
*   **Manager Date** (`12`): The date on which the manager completed the form.
*   **Manager Time** (`13`): The time at which the manager completed the form.
*   **Manager Comments** (`14`): Another optional free-form text field for any additional comments or feedback.
*   **Shift 1 Start** (`15`): The start time of the first shift, if applicable.
*   **Shift 1 End** (`16`): The end time of the first shift, if applicable.
*   **Shift 2 Start** (`17`): The start time of the second shift, if applicable.
*   **Shift 2 End** (`18`): The end time of the second shift, if applicable.
*   **Manager Review Shift 1** (`19`): Select `Yes` if the manager reviewed the first shift, `No` otherwise.
*   **Manager Review Shift 2** (`20`): Select `Yes` if the manager reviewed the second shift, `No` otherwise.

This form is a valuable tool for hospitality establishments to monitor, evaluate, and improve their room service process, ensuring that every interaction with guests is of the highest quality and meets the standards expected by the establishment.
