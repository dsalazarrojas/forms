# Retreat Extra Nightly Rates Survey - Help Guide

## Purpose
The Retreat Extra Nightly Rates Survey is used to provide information about extra nightly rates for retreats. Extra nightly rates are additional charges applied to the base nightly rate for retreats.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information for your retreat extra nightly rates.

## Field-by-Field Explanation
* **Extra Nightly Rates**: This field is for the extra nightly rates applied to the base nightly rate.
	+ Type: Text
	+ Description: Enter the extra nightly rates for the retreat.
* **Retreat Length**: This field is for the length of the retreat.
	+ Type: Number
	+ Description: Enter the number of days of the retreat.
* **Extra Nightly Rates Frequency**: This field is for how often the extra nightly rates are applied.
	+ Type: Select One
	+ Description: Select when the extra nightly rates are applied (Daily, Weekly, Monthly, Quarterly, Bi-Yearly, Yearly).
* **Pricing Model**: This field is for how the extra nightly rates are priced.
	+ Type: Select Multiple
	+ Description: Select how the extra nightly rates are priced (Room Type, Rate per Night, Room Type and Rate per Night, Other).
* **Rate Range**: This field is for the rate range of the extra nightly rates.
	+ Type: Number
	+ Description: Enter the rate range of the extra nightly rates.
* **Rate Range Unit**: This field is for the unit of the rate range.
	+ Type: Select One
	+ Description: Select the unit of the rate range (USD, Other).
* **Minimum Stay Length**: This field is for the minimum stay length of the extra nightly rates.
	+ Type: Number
	+ Description: Enter the minimum stay length of the extra nightly rates.
* **Additional Nightly Rate**: This field is for the additional nightly rate.
	+ Type: Number
	+ Description: Enter the additional nightly rate.
* **Extra Nightly Rates Amenity**: This field is for the amenities included in the extra nightly rates.
	+ Type: Select Multiple
	+ Description: Select the amenities included in the extra nightly rates (Internet, TV, Parking, Pool).
* **Other Amenity**: This field is for any other amenities not included in the previous options.
	+ Type: Text
	+ Description: Enter any other amenities not included in the previous options.
* **Extra Nightly Rates Comment**: This field is for any comments about the extra nightly rates.
	+ Type: Text
	+ Description: Enter any comments about the extra nightly rates.
* **Extra Nightly Rates Comment 2**: This field is for any additional comments about the extra nightly rates.
	+ Type: Text
	+ Description: Enter any additional comments about the extra nightly rates.
* **Extra Nightly Rates Comment 3**: This field is for any further comments about the extra nightly rates.
	+ Type: Text
	+ Description: Enter any further comments about the extra nightly rates.

## Tips
* Be as detailed and accurate as possible when filling out the form.
* If you are unsure about any of the fields, please contact the hospitality team for assistance.
* Please note that the extra nightly rates will be reviewed and approved by the hospitality team before they are applied.
* If you have any additional information or comments, please include them in the extra nightly rates comment fields.
