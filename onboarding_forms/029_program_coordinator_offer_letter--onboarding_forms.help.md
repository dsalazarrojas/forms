# program_coordinator_offer_letter - Help Guide
## Purpose
The Program Coordinator Offer Letter is a document used to communicate job offers to program coordinators.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the basic information section, which includes the job title, company, and offer amount.
2. Select the offer type from the dropdown menu.
3. Fill out the dates section, which includes the offer date, program start date, and program end date.
4. Fill out the reason for leaving section, if applicable.
5. Fill out the job description, job summary, location, and job status.
6. Add any additional notes if needed.
7. Enter the contact information for the program coordinator and manager.
8. Fill out the team lead and team lead contact information.
9. Select the job title and manager contact from the dropdown menu.
10. Fill out the phone number and email of the program coordinator.

## Field-by-Field Explanation

* **Basic Info** (`1`, `text`, required): Enter the basic information about the job offer, including the job title, company, and offer amount.
* **Job Title** (`2`, `text`, required): Enter the job title.
* **Company** (`3`, `text`, required): Enter the company name.
* **Offer Amount** (`4`, `number`, required): Enter the offer amount.
* **Offer Date** (`5`, `date`, required): Select the offer date.
* **Program Start Date** (`6`, `date`, required): Select the program start date.
* **Program End Date** (`7`, `date`, required): Select the program end date.
* **Reason for Leaving** (`8`, `text`, optional): Enter the reason for leaving, if applicable.
* **Offer Type** (`9`, `select_one`, required): Select the offer type from the dropdown menu.
* **Manager Name** (`10`, `text`, required): Enter the manager name.
* **Department** (`11`, `select_multiple`, required): Select the department from the dropdown menu.
* **Job Description** (`12`, `text`, required): Enter a brief description of the job.
* **Job Summary** (`13`, `text`, required): Enter a brief summary of the job.
* **Location** (`14`, `text`, required): Enter the location.
* **Job Status** (`15`, `select_one`, required): Select the job status from the dropdown menu.
* **Notes** (`16`, `text`, optional): Add any additional notes.
* **Email** (`17`, `email`, required): Enter the email of the program coordinator.
* **Phone** (`18`, `text`, required): Enter the phone number of the program coordinator.
* **Program Coordinator Contact** (`19`, `text`, required): Enter the contact information for the program coordinator.
* **Job Title 1** (`20`, `select_multiple`, required): Select the job title from the dropdown menu.
* **Manager Contact** (`21`, `text`, required): Enter the contact information for the manager.
* **Team Lead** (`22`, `text`, required): Enter the team lead name.
* **Team Lead Contact** (`23`, `text`, required): Enter the contact information for the team lead.
* **Job Title 2** (`24`, `text`, required): Enter the second job title.

Please note that all fields with an asterisk (\*) are required fields.
