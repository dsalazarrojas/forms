# template_of_realtormlo_onboarding - Help Guide
## Purpose
This form is designed to help track the onboarding progress of realtors with their MLO agreements. It captures information about the realtor's status, training completion, and access to assigned tools.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the relevant information for each field, as indicated by the label.
2. Select the correct option for each field, as shown in the Field-by-Field Explanation section.

## Field-by-Field Explanation

* **Onboarding Form Page** (`onboarding_form_page`, `note`, required: false):
	+ This field is not required but provides additional information about the form.
* **Realtor MLO Onboarding** (`realtor_mlo_onboarding`, `text`, required: false):
	+ Enter a brief description or notes about the realtor's MLO onboarding.
* **Realtor MLO Onboarding Agreement** (`realtor_mlo_onboarding_agreement`, `select_multiple`, required: false):
	+ Select whether the realtor has accepted or declined the MLO agreement.
	+ Options: 'Yes', 'No'
* **Date Onboarded** (`date_onboarded`, `date`, required: false):
	+ Enter the date the realtor was onboarded.
* **Time Onboarded** (`time_onboarded`, `time`, required: false):
	+ Enter the time the realtor was onboarded.
* **Training Completed** (`training_completed`, `select_one`, required: false):
	+ Select whether the realtor has completed training.
	+ Options: 'Yes', 'No'
* **Realtor MLO Agreement** (`relocator_mlo_agreement`, `select_one`, required: false):
	+ Select whether the realtor has agreed to the MLO agreement.
	+ Options: 'Yes', 'No'
* **Onboarding Status** (`onboarding_status`, `select_one`, required: false):
	+ Select the onboarding status of the realtor.
	+ Options: Active, Inactive
* **Assigned Tool** (`assigned_tool`, `select_one`, required: false):
	+ Select whether the realtor has been assigned a tool.
	+ Options: 'Yes', 'No'
* **Assigned Tool** (`assigned_tool`, `select_multiple`, required: false):
	+ Select which tool(s) the realtor has been assigned.
* **Onboarding Form Submitted** (`onboarding_form_submitted`, `text`, required: false):
	+ Enter any additional information or comments about the onboarding form submission.

## Tips
- Make sure to fill in all required fields.
- Use the correct format for date and time entries (MM/DD/YYYY, 12:00 PM).
- If you are unsure about any field, please ask your supervisor for assistance.
