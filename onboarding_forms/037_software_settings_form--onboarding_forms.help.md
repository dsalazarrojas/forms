# software_settings_form - Help Guide
## Purpose
This form is designed to gather information from users about their software-related requests and settings to ensure that our support team can provide efficient and effective assistance.

## How To Complete This Form

1. Click on "Start" to begin completing the form.
2. On the first page, select "onboarding_forms_request" to confirm that this is a software-related request.
3. On the second page, choose "Yes" or "No" for "request_type" to indicate whether the user has a software-related request or not.
4. If the user has a software-related request, proceed to the third page to select "Yes" or "No" for "software_type" to indicate the type of software involved.
5. On the fourth page, provide a text description of the software setting request in "software_setting_request".
6. Enter the value for the software setting in "software_setting_value".
7. Optionally, add any additional notes or details about the software setting in "software_setting_description".
8. On the final page, select "Yes" or "No" for "software_category" to indicate the category of the software.
9. Finally, enter the name of the software in "software_name".

## Field-by-Field Explanation
* **onboarding_forms_request** (text, optional): This field is used to confirm that this is a software-related request.
* **request_type** (select_one, optional): Choose "Yes" if you have a software-related request, "No" otherwise.
* **software_type** (select_multiple, optional): Select "Yes" if the software-related request involves a specific type of software, "No" otherwise.
* **software_setting_request** (text, optional): Enter a brief description of the software setting request.
* **software_setting_value** (text, optional): Enter the value for the software setting.
* **software_setting_description** (note, optional): Provide any additional notes or details about the software setting.
* **software_category** (select_one, optional): Select "Yes" if the software-related request involves a specific category of software, "No" otherwise.
* **software_name** (text, optional): Enter the name of the software.
