# logo_creation_onboarding_form - Help Guide
## Purpose
The **Logo Creation Onboarding Form** is used to collect information about a company's visual identity for the purpose of creating a logo.

## How To Complete This Form
To complete this form, please follow the following steps:
1. Enter the company name and formation details.
2. Provide a tagline that captures the company's purpose and message.
3. Specify the placement of the tagline (left, right, top, or bottom).
4. Select the primary and secondary branding colors for the logo.
5. Indicate whether the logo will be used online or not.
6. Choose the font for the logo.
7. Select the font color for the logo.
8. Select the online font setting.

## Field-by-Field Explanation
- **company_name** (`text`, optional): Enter the name of the company.
- **company_formation** (`text`, optional): Enter the formation of the company.
- **tagline** (`text`, optional): Enter a short phrase that describes the company's purpose and message.
- **tagline_placement** (`select_one`, optional): Choose where the tagline will be placed on the logo (left, right, top, or bottom).
- **primary_branding_color** (`number`, optional): Select the primary branding color for the logo (e.g., red, blue, etc.).
- **secondary_branding_color** (`number`, optional): Select the secondary branding color for the logo (e.g., black, white, etc.).
- **online_color_selection** (`select_multiple`, optional): Indicate whether the logo will be used online (Yes or No).
- **font** (`select_one`, optional): Choose the font for the logo (Arial, Times New Roman, Calibri, or Courier).
- **font_color** (`number`, optional): Select the font color for the logo (e.g., red, blue, etc.).
- **online_font_selector** (`select_one`, optional): Select the online font setting for the logo (font 1, font 2, or font 3).
