# SEO Onboarding Form - Help Guide
## Purpose
This form is designed to collect information from clients and consultants for onboarding new projects. It helps to gather essential details about the project, client, and consultant, ensuring a smooth and efficient onboarding process.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill in the required fields with accurate and up-to-date information.
2.  Review each field for correct formatting and completeness.
3.  Submit the form when all fields are filled in.

## Field-by-Field Explanation

* **client_info** (Text): Enter the client's information, such as name and any relevant contact details.
* **project_details** (Text): Provide a brief description of the project, including its scope and objectives.
* **consultant_info** (Text): Enter the consultant's information, such as name and contact details.
* **project_budget** (Number): Enter the project budget in the currency specified in **project_budget_currency**.
* **expected_start_date** (Date): Enter the expected start date of the project.
* **expected_start_time** (Time): Enter the expected start time of the project.
* **client_phone** (Text): Enter the client's phone number.
* **client_email** (Email): Enter the client's email address.
* **project_notes** (Text): Enter any additional notes about the project.
* **consultant_phone** (Text): Enter the consultant's phone number.
* **consultant_email** (Email): Enter the consultant's email address.
* **project_status** (Select One): Select the current status of the project (Active or Inactive).
* **project_status_other** (Text): If the project status is not one of the pre-defined options, enter the reason here.
* **project_status_options** (Select Multiple): Select all applicable statuses for the project (Active and Inactive).
* **onboarding_steps** (Text): Enter the onboarding steps to be taken for the project.
* **project_status_reason** (Text): Enter the reason for the project's status if it's not one of the pre-defined options.
* **client_address** (Text): Enter the client's address.
* **consultant_address** (Text): Enter the consultant's address.
* **onboarding_notes** (Text): Enter any onboarding-related notes.
* **consultant_notes** (Text): Enter the consultant's notes.
* **project_budget_currency** (Text): Enter the currency for the project budget.
* **consultant_rate** (Number): Enter the consultant's rate.
* **project_rate** (Number): Enter the project rate.
* **consultant_currency** (Text): Enter the currency for the consultant's rate.
* **project_currency** (Text): Enter the currency for the project rate.
