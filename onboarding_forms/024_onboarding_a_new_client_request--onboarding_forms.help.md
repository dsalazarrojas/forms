# onboarding_a_new_client_request - Help Guide
## Purpose
The onboarding_a_new_client_request form is used to collect information about a new client for onboarding purposes.

## How To Complete This Form
1. Fill in the client's first name in the First Name field.
2. Enter the client's last name in the Last Name field.
3. Type the client's email address in the Email field.
4. Enter the client's phone number in the Phone field.
5. Provide the client's address in the Address field.
6. Enter the client's date of birth in the Date of Birth field (in the format mm/dd/yyyy).
7. Enter the client's onboarding time in the Onboarding Time field (in the format 24-hour clock, HH:MM).
8. Select the onboarding status of the client from the Onboarding Form Status dropdown menu.
9. Choose whether the client has been assigned a tool or not in the Assigned Tool field.
10. If the client has been assigned a tool, select the assigned tool user in the Assigned Tool User field.
11. Enter the date the client was assigned the tool in the Assigned Date field (in the format mm/dd/yyyy).
12. Enter the assigned time for the client in the Assigned Time field (in the format 24-hour clock, HH:MM).
13. Add any additional notes about the client in the Notes field.

## Field-by-Field Explanation

* **First Name (Text, Required: No)**: Enter the client's first name.
* **Last Name (Text, Required: No)**: Enter the client's last name.
* **Email (Email, Required: No)**: Type the client's email address.
* **Phone (Text, Required: No)**: Enter the client's phone number.
* **Address (Text, Required: No)**: Provide the client's address.
* **Date of Birth (Date, Required: No)**: Enter the client's date of birth in the format mm/dd/yyyy.
* **Time (Time, Required: No)**: Enter the client's onboarding time in the format HH:MM.
* **Onboarding Date (Date, Required: No)**: Enter the onboarding date in the format mm/dd/yyyy.
* **Onboarding Time (Time, Required: No)**: Enter the onboarding time in the format HH:MM.
* **Onboarding Form Status (Select Multiple, Required: No)**: Select the onboarding status of the client (Active, Inactive, Pending).
* **Assigned Tool (Select One, Required: No)**: Choose whether the client has been assigned a tool or not.
* **Assigned Date (Date, Required: No)**: Enter the date the client was assigned the tool in the format mm/dd/yyyy.
* **Assigned Time (Time, Required: No)**: Enter the assigned time in the format HH:MM.
* **Assigned Tool User (Text, Required: No)**: If the client has been assigned a tool, enter the name of the tool user.
* **Notes (Text, Required: No)**: Add any additional notes about the client.
