# onboarding_document_submission_form - Help Guide
## Purpose
The onboarding document submission form is used to collect necessary documents and information from new hires during the onboarding process.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have gathered all the required documents and information for the new hire.
2. Fill out the new hire's information, including their name and hire date.
3. Select the type of document submitted (e.g. resume, ID, passport, etc.).
4. Choose the status of the document (e.g. pending, approved, expired, etc.).
5. Add any comments or notes about the document.
6. Get manager approval for the document.

## Field-by-Field Explanation
### New Hire Documents (Page 1)
* **New Hire Documents**: This is a note field where you can add any additional information about the new hire's documents.

### New Hire Name (Page 2)
* **New Hire Name**: Enter the new hire's full name.

### Hire Date (Page 3)
* **Hire Date**: Enter the date the new hire was hired.

### Manager Approval (Page 4)
* **Manager Approval**: Select whether the document is approved, pending, or denied by the manager.

### Document Type (Page 5)
* **Document Type**: Select the type of document submitted, such as resume, ID, passport, or other.

### Document Date (Page 6)
* **Document Date**: Enter the date the document was submitted.

### Document Status (Page 7)
* **Document Status**: Select the status of the document, such as pending, approved, or expired.

### Document Comments (Page 8)
* **Document Comments**: Add any comments or notes about the document.
