# Property Onboarding Analysis Form - Help Guide
## Purpose
The Property Onboarding Analysis Form is designed to collect and analyze property information in a structured and standardized format. It helps ensure that properties are properly documented and assessed, streamlining the onboarding process.

## How To Complete This Form
1. Fill out the form with the requested information about the property.
2. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation
* **Property Address**: Enter the address of the property, including the number, street name, and any additional information such as "Unit" or "Suite".
* **Property Type**: Select 'Yes' if the property is a type of property that is being onboarded (e.g., office, residential, etc.). Select 'No' if it's not. 
* **Property Owner**: Enter the name of the property owner, including their title if applicable (e.g., 'Mr.', 'Ms.', 'Dr.', etc.). 
* **Property Status**: Select 'Active' if the property is active, i.e., it's being onboarded or has been onboarded successfully. Select 'Inactive' if it's not active or has failed to onboard. 
* **Property Use**: Select all applicable uses of the property (e.g., 'Yes' for office, 'Yes' for residential, etc.).
* **Property Size**: Enter the size of the property in square feet or square meters.
* **Property Location**: Enter the location of the property, including city, state, or province, and postal code.
* **Property Year Built**: Enter the year the property was built.
* **Property Year Renovated**: Enter the year the property was renovated, if applicable.
* **Property Condition**: Enter the condition of the property, e.g., 'Excellent', 'Fair', etc.
* **Property Notes**: Enter any additional information about the property.
* **Second Property Address**: Enter the address of the second property, if there are multiple properties.
* **Property Phone**: Enter the phone number of the property.
* **Property Email**: Enter the email of the property.

Note: This form is designed to be completed by the property owner or their representative, ensuring accurate and up-to-date information.
