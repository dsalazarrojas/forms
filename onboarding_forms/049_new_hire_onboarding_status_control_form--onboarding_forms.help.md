# New Hire Onboarding Status Control Form - Help Guide
## Purpose
This form is designed to provide essential information about new hires, helping them get started with their onboarding process. It's a crucial tool for our organization to track and manage new hires' progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the new hire onboarding process.
2. Select the category for the new hire (e.g., Onboarding Forms, Other).
3. Enter a description of the new hire.
4. Choose the tool assigned to the new hire (e.g., chatjimmy, Other).
5. Enter the output file name for the new hire.
6. Enter any additional IDs for the form.
7. Enter the title of the output.
8. Provide a description of the output.

## Field-by-Field Explanation

* **New Hire Onboarding Status Control Form** (`form_title`, text, not required): Enter a title for the new hire onboarding process that will be displayed on the form.
* **CATEGORY** (`form_category`, select_one, not required): Select the category for the new hire (e.g., Onboarding Forms, Other). This will help categorize the form for easy searching and sorting.
* **DESCRIPTION** (`form_description`, text, not required): Enter a brief description of the new hire.
* **ASSIGNED TOOL** (`form_assigned_tool`, select_one, not required): Choose the tool assigned to the new hire (e.g., chatjimmy, Other). This will help track which tool is being used for the new hire.
* **OUTPUT FILE** (`form_output_file`, text, not required): Enter the name of the output file for the new hire.
* **FORM IDS** (`form_id`, text, not required): Enter any additional IDs for the form.
* **TITLE** (`form_title`, text, not required): Enter the title of the output.
* **DESCRIPTION** (`form_description`, text, not required): Enter a description of the output.
