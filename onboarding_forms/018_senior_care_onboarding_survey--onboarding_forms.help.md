# Senior Care Onboarding Survey - Help Guide
## Purpose
This form is used to collect information about new residents in the care facility, including their emergency contact, medical information, and any relevant medical conditions.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the fields as prompted, providing as much detail as possible.
2. Review and update any existing information as necessary.
3. Submit the form when finished.

## Field-by-Field Explanation

* **New Residency Information** (newResidentInfo): 
  * Type: Text field
  * Required: No
  * Description: Please enter the new resident's information in this field.
* **Emergency Contact** (emergencyContact): 
  * Type: Select One field
  * Options: Primary, Secondary Contact, Address, Relationship, Phone, Emergency Contact Name
  * Required: No
  * Description: Please select the type of emergency contact the new resident has.
* **Medical Information** (medicalInfo): 
  * Type: Text field
  * Required: No
  * Description: Please enter any relevant medical information about the new resident.
* **Medical Conditions** (medicalConditions): 
  * Type: Select Multiple field
  * Options: Alzheimer's disease, Arthritis, Heart failure, Stroke, Other
  * Required: No
  * Description: Please select any relevant medical conditions the new resident has.
* **Medication** (medication): 
  * Type: Select Multiple field
  * Options: Aspirin, Blood thinner, Other
  * Required: No
  * Description: Please select any medication the new resident is taking.
* **Medical Procedures** (medicalProcedures): 
  * Type: Select Multiple field
  * Options: Knee replacement surgery, Hip replacement surgery, Other
  * Required: No
  * Description: Please select any medical procedures the new resident has had.
* **Allergies** (allergies): 
  * Type: Select Multiple field
  * Options: Allergies, Other
  * Required: No
  * Description: Please select any allergies the new resident has.
* **Special Needs** (specialNeeds): 
  * Type: Text field
  * Required: No
  * Description: Please enter any special needs the new resident has.
* **Notes** (notes): 
  * Type: Note field
  * Required: No
  * Description: Please enter any additional notes about the new resident.
* **Additional Information** (additionalInfo): 
  * Type: Text field
  * Required: No
  * Description: Please enter any additional information about the new resident.
