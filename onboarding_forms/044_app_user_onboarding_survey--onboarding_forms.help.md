# App User Onboarding Survey - Help Guide
## Purpose
This form is designed to gather feedback on your onboarding experience in our application.

## How To Complete This Form
To complete this form, select the most accurate response for each question and provide any additional comments or suggestions you may have.

## Field-by-Field Explanation
* **User role**: Select your role in the application (e.g. Admin, Power user, End user).
	+ Select the option that best describes your user role.
* **Time to first success**: Estimate the time it took you to complete the initial setup.
	+ Enter the number of minutes it took you to complete the onboarding flow.
* **Onboarding clarity rating**: Rate how clear the instructions were during onboarding.
	+ Select one of the following options: Very unclear, Somewhat unclear, Neutral, Clear, Very clear.
* **Obstacles encountered during onboarding**: Select any obstacles you experienced during onboarding.
	+ Choose all that apply from the list of options provided.
* **Did you use support resources?**: Indicate if you used any support resources during onboarding.
	+ Select True if you used resources, False otherwise.
* **Suggested improvements**: Provide any suggestions you have for improving the onboarding process.
	+ Enter your suggestions in the text field.
