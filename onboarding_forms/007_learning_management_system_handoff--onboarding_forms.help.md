# Learning Management System Handoff - Help Guide
## Purpose
This form is used to collect information for the Learning Management System Handoff process.

## How To Complete This Form

1. Fill out the form in its entirety, ensuring all required fields are completed.
2. Select the correct options for each field as they apply to your situation.
3. Review your entries carefully before submitting the form.

## Field-by-Field Explanation

* **Education Transfer** (`education_transfer`, `note`, optional): This field is used to provide details about the education transfer.
* **Training Transfer** (`training_transfer`, `select_multiple`, required): Select all applicable training transfers related to the handoff.
* **Data Collection** (`data_collection`, `text`, optional): Centralize data collection in Jotform.
* **Administrator Change** (`admin_change`, `select_one`, optional): Select the administrator responsible for the handoff.
* **Date** (`date`, `date`, required): Enter the date of the transfer.
* **Time** (`time`, `time`, required): Enter the time of the transfer.
* **Description** (`description`, `select_multiple`, optional): Select a brief description of the transfer.
* **Email** (`email`, `email`, required): Enter the email address of the person handling the handoff.
* **Phone** (`phone`, `text`, required): Enter the phone number of the person handling the handoff.
* **Note** (`note`, `note`, optional): Add any additional notes about the handoff.
* **Category** (`category`, `select_one`, required): Select the category of the handoff (e.g., Onboarding Forms, IT Forms, Security Forms).
* **Form Type** (`form_type`, `select_one`, required): Select the type of form (e.g., Onboarding Form, IT Form, Security Form).
* **Form ID** (`form_id`, `text`, optional): Enter the form ID for the handoff.
* **Form Category** (`form_category`, `select_multiple`, required): Select the category of the form.
* **Form Title** (`form_title`, `text`, required): Enter a title for the handoff form.
* **Form Description** (`form_description`, `text`, required): Enter a detailed description of the handoff form.
* **Created By** (`created_by`, `select_one`, required): Select the user who created the handoff form.
* **Updated By** (`updated_by`, `select_one`, required): Select the user who updated the handoff form.
* **Created At** (`created_at`, `text`, required): Enter the date and time the handoff form was created.
* **Updated At** (`updated_at`, `text`, required): Enter the date and time the handoff form was last updated.
* **Status** (`status`, `select_one`, required): Select the status of the handoff (e.g., Active, Inactive, Completed).
* **Version** (`version`, `select_one`, required): Select the version of the handoff form.
* **Custom** (`custom`, `text`, required): Enter any custom information about the handoff.
* **Output File** (`output_file`, `text`, required): Enter the name of the output file for the handoff.
* **Assigned Tool** (`assigned_tool`, `select_one`, required): Select the tool assigned to the handoff.
