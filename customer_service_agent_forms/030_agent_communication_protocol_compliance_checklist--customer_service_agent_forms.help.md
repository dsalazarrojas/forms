# Agent Communication Protocol Compliance Checklist - Help Guide
## Purpose
The purpose of this form is to evaluate an agent's adherence to the communication protocol, ensuring consistency and quality in customer interactions. It assesses their performance in key areas such as greetings, tone, call closings, data handling, and script adherence.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with accurate and honest information about the agent's performance.
2. Make sure to select the correct ratings for each field.
3. Provide any additional feedback or coaching suggestions in the `Action items` field.
4. Add any additional comments or notes in the `Reviewer notes` field.

## Field-by-Field Explanation

* **Agent name** (`agent_name`, text, required): Enter the name of the agent under review.
* **Evaluation date** (`evaluation_date`, date, required): Enter the date of the compliance check.
* **Greeting protocol followed** (`greeting_protocol`, select_one, required): Select 'True' if the agent used the standard greeting, 'False' if they did not, and 'Partially' if their greeting was not entirely correct.
* **Tone and professionalism** (`tone_and_professionalism`, select_one, required): Rate the agent's communication tone (Excellent, Good, Fair, Poor) and indicate their level of professionalism.
* **Call closing protocol followed** (`call_closing_protocol`, select_one, required): Select 'True' if the agent closed the call per the script, 'False' if they did not, and 'Partially' if their closing was not entirely correct.
* **Data privacy compliance** (`data_privacy_compliance`, select_one, required): Select 'Compliant' if the agent handled customer data correctly, 'Non-compliant' if they did not.
* **Script adherence** (`script_adherence`, select_one, required): Rate the agent's script adherence (High, Moderate, Low).
* **Action items** (`action_items`, text, optional): List any coaching or remedial steps required for the agent.
* **Reviewer notes** (`reviewer_notes`, text, optional): Add any additional comments or feedback for the agent.

## Tips

* Make sure to complete the form accurately and honestly.
* Provide specific examples or details when selecting ratings or writing feedback.
* Review the form carefully before submitting to ensure all required fields are filled.
