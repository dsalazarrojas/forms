# Health Advisory Communication Form - Help Guide
## Purpose
The Health Advisory Communication Form is used to capture updates on a patient's health status, medication allergies, medical history, and other relevant information.

## How To Complete This Form
1. Please fill out the form completely and accurately, including all relevant fields.
2. If you are unsure about any field, please ask the healthcare provider for guidance.
3. Make sure to save your work regularly to avoid losing any changes.

## Field-by-Field Explanation

* **Patient Feedback Form** (`patient_feedback_form`, text, required: false): 
Enter a brief summary of the patient's current health status.
* **Patient Name** (`patient_name`, text, required: false): 
Enter the patient's name as it appears in their medical record.
* **Medical Record Number** (`medical_record_number`, text, required: false): 
Enter the patient's medical record number as it appears in their medical record.
* **Medical Record Type** (`medical_record_type`, text, required: false): 
Enter the type of medical record (e.g., "Emergency Department", "Primary Care").
* **Health Condition** (`patient_health_condition`, text, required: false): 
Enter a brief description of the patient's health condition.
* **Medication Allergies** (`patient_medication_allergies`, select multiple, required: false): 
Select "Yes" or "No" for any known medication allergies.
* **Medication Allergies List** (`patient_medication_allergies_list`, select multiple, required: false): 
Select "Yes" or "No" for any known medication allergies.
* **Medication Comments** (`patient_medication`, text, required: false): 
Enter any comments or notes about the patient's medication regimen.
* **Medication List** (`patient_medication_list`, select multiple, required: false): 
Select "Yes" or "No" for any known medications.
* **Medication Comments** (`patient_medication_comments`, text, required: false): 
Enter any comments or notes about the patient's medication regimen.
* **Medication Comments List** (`patient_medication_comments_list`, select multiple, required: false): 
Select "Yes" or "No" for any known medication comments.
* **Family History** (`patient_family_history`, text, required: false): 
Enter a brief description of the patient's family history.
* **Family History Allergies** (`patient_family_history_allergies`, select multiple, required: false): 
Select "Yes" or "No" for any known family history allergies.
* **Family History Comments** (`patient_family_history_comments`, text, required: false): 
Enter any comments or notes about the patient's family history.
* **Family History Comments List** (`patient_family_history_comments_list`, select multiple, required: false): 
Select "Yes" or "No" for any known family history comments.
* **Family History Comments Other** (`patient_family_history_comments_other`, text, required: false): 
Enter any additional comments or notes about the patient's family history.
* **Healthcare Provider Name** (`healthcare_provider_name`, text, required: false): 
Enter the name of the healthcare provider who is submitting this form.
* **Healthcare Provider Note** (`healthcare_provider_note`, text, required: false): 
Enter any comments or notes from the healthcare provider.
* **Other (Name)** (`patient_name_other`, text, required: false): 
Enter any other name that needs to be documented.
* **Other (Text)** (`patient_name_other_text`, text, required: false): 
Enter any additional text about the other name.
* **Other (Comments)** (`patient_name_other_comments`, text, required: false): 
Enter any comments or notes about the other name.
* **Other (Comments List)** (`patient_name_other_comments_list`, select multiple, required: false): 
Select "Yes" or "No" for any known other comments.
