# Wound Healing Progress Evaluation Form - Help Guide
## Purpose
This form is used to evaluate the progress of a patient's wound healing process.

## How To Complete This Form
1. Fill out the form by providing patient information and wound status updates.
2. Ensure you have the necessary permissions to access or modify this form.
3. Review each field carefully, as some fields have specific options.

## Field-by-Field Explanation

* **Patient Id** (`patient_id`, number, required: false): Enter the patient's ID number.
* **Wound Location** (`wound_location`, text, required: false): Describe the location of the wound.
* **Wound Size At Initial Assessment** (`wound_size_at_initial_assessment`, number, required: false): Enter the initial size of the wound.
* **Wound Size Currently** (`wound_size_currently`, number, required: false): Enter the current size of the wound.
* **Wound Depth** (`wound_depth`, number, required: false): Enter the depth of the wound.
* **Pain Level** (`pain_level`, number, required: false): Rate the patient's pain level from 1-5.
* **Wound Tissue Type** (`wound_tissue_type`, select_multiple, required: false): Select all applicable wound tissue types.
* **Wound Infection Status** (`wound_infection_status`, select_one, required: false): Select the current infection status.
* **Wound Smoking Status** (`wound_smoking_status`, select_one, required: false): Select the smoking status.
* **Wound Cleansing Frequency** (`wound_cleansing_frequency`, number, required: false): Enter the frequency of wound cleansing.
* **Wound Dressing Type** (`wound_dressing_type`, select_one, required: false): Select the type of wound dressing used.
* **Wound Drainage** (`wound_drainage`, select_multiple, required: false): Select all applicable wound drainage types.
* **Wound Pain Management** (`wound_pain_management`, select_multiple, required: false): Select all applicable wound pain management types.
* **Wound Complication Status** (`wound_complication_status`, select_multiple, required: false): Select all applicable wound complication status types.
* **Wound Vital Status** (`wound_vital_status`, select_multiple, required: false): Select all applicable wound vital status types.
* **Wound Closure Status** (`wound_closure_status`, select_multiple, required: false): Select all applicable wound closure status types.
* **Patient Feedback** (`patient_feedback`, text, required: false): Enter any comments or feedback from the patient.
* **Wound Healing Progress** (`wound_healing_progress`, select_one, required: false): Select the progress of wound healing.
* **Provider Comments** (`provider_comments`, text, required: false): Enter any comments from the provider.
* **Follow Up Date** (`follow_up_date`, date, required: false): Enter the follow-up date.
* **Follow Up Provider** (`follow_up_provider`, text, required: false): Enter the follow-up provider.
* **Follow Up Status** (`follow_up_status`, select_one, required: false): Select the follow-up status.
* **Next Follow Up Date** (`next_follow_up_date`, date, required: false): Enter the next follow-up date.
* **Next Follow Up Provider** (`next_follow_up_provider`, text, required: false): Enter the next follow-up provider.
* **Last Updated** (`last_updated`, time, required: false): Display the last updated timestamp.

Note: This guide is based on the provided YAML fields and assumes that all fields are self-explanatory.
