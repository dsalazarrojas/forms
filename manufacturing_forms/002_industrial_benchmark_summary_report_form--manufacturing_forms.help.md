# Industrial Benchmark Summary Report Form - Help Guide
## Purpose
This form is used to collect and summarize key performance metrics for industrial benchmarks. It helps to standardize the collection of data across different facilities and provides a quick reference for tracking progress and comparing results.

## How To Complete This Form
1. Enter the facility name in the "Facility" field, which is a required field.
2. Enter the production date in the "Production Date" field. Please use the format `YYYY-MM-DD`.
3. Select the applicable benchmark values in the "Benchmark Values" dropdown menus. You should select all relevant options.
4. Enter the values for "Benchmark Value 1" to "Benchmark Value 3". These fields are numbers and should not be left blank if possible.
5. Add any additional information or notes about your facility's performance in the "Additional Information" field.
6. Enter your name and contact information for the "Contact Person" and "Contact Email" fields. These fields are required.
7. Optionally, enter your contact phone number for "Contact Phone" field.

## Field-by-Field Explanation

* **Facility** (`Facility`, text, required): Enter the name of the facility for which you are submitting the report.
* **Production Date** (`Production Date`, date, required): Enter the date of production.
* **Region** (`Region`, text, optional): Enter the region of the facility.
* **Benchmark Values** (`Benchmark Values`, select multiple, required): Select all applicable benchmark values that apply to your facility.
* **Benchmark Values** (`Benchmark Values`, select one, required): Select the primary benchmark value that best represents your facility's performance.
* **Benchmark Value 1** (`Benchmark Value 1`, number, required): Enter the value for this benchmark metric.
* **Benchmark Value 2** (`Benchmark Value 2`, number, optional): Enter the value for this optional metric if applicable.
* **Benchmark Value 3** (`Benchmark Value 3`, number, optional): Enter the value for this optional metric if applicable.
* **Additional Information** (`Additional Information`, note, optional): Add any additional notes or information about your facility's performance.
* **Contact Person** (`Contact Person`, text, required): Enter your name or title.
* **Contact Email** (`Contact Email`, email, required): Enter your email address.
* **Contact Phone** (`Contact Phone`, text, optional): Enter your phone number.

## Tips

* Please fill out the form accurately and thoroughly.
* Make sure to select all relevant benchmark values for your facility.
* If you need help or have questions, please don't hesitate to reach out to us.
* This form is designed to be completed once per facility per production date. If you have any updates or changes, please submit a new form with the latest information.
