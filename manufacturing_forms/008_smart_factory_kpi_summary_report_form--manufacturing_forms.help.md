# Smart Factory KPI Summary Report Form - Help Guide
## Purpose
The Smart Factory KPI Summary Report Form is designed to collect data for the production planning and control processes, allowing for a comprehensive overview of the factory's performance.

## How To Complete This Form
1. Fill out the form with the required information, which includes:
	* Manufacturing businesses (page 1)
	* Production planners (page 2)
	* Quality control measures (page 6)
	* Production planning and control process status (page 23)
	* Production planning and control process start and end dates (pages 24 and 25)
2. Select the relevant options for each field, as required:
	* Manufacturing businesses (page 1)
	* Production planners (page 2)
	* Quality control measures (page 6)
	* Production planning and control process status (page 23)
3. Fill out any other fields that apply to your specific production planning and control process:
	* Inventory levels (page 7)
	* Production lead time (page 8)
	* Production cycle time (page 9)
	* Defect rate (page 10)
	* Manufacturing processes (page 11)
	* Production costs (page 13)
	* Production times (page 14)
	* Quality control standards (page 15)
	* Production planning and control process description, type, and notes (pages 17, 18, and 20)
	* Production planning and control process schedule and deadline (pages 21 and 22)

## Field-by-Field Explanation
* **Manufacturing Businesses** (Page 1, Required: False): Enter the name(s) of the manufacturing businesses relevant to this report.
* **Production Planners** (Page 2, Required: True): Select all production planners responsible for this process.
* **Inventory Levels** (Page 7, Required: True): Select the current inventory levels for the relevant products.
* **Production Lead Time** (Page 8, Required: False): Enter the production lead time for this process.
* **Production Cycle Time** (Page 9, Required: False): Enter the production cycle time for this process.
* **Defect Rate** (Page 10, Required: False): Enter the defect rate for this process.
* **Manufacturing Processes** (Page 11, Required: True): Select the manufacturing process relevant to this report.
* **Production Planners** (Page 12, Required: True): Select all production planners responsible for this process.
* **Production Costs** (Page 13, Required: False): Enter the production costs for this process.
* **Production Times** (Page 14, Required: False): Enter the production times for this process.
* **Quality Control Measures** (Page 6, Required: False): Select the quality control measures relevant to this report.
* **Quality Control Standards** (Page 15, Required: True): Select the quality control standards relevant to this report.
* **Production Planning and Control Process Status** (Page 23, Required: True): Select the status of this production planning and control process.
* **Production Planning and Control Process Description** (Page 17, Required: False): Enter a description of this production planning and control process.
* **Production Planning and Control Process Type** (Page 18, Required: False): Enter the type of this production planning and control process.
* **Production Planning and Control Process Notes** (Page 20, Required: False): Enter any additional notes for this production planning and control process.
* **Production Planning and Control Process Schedule** (Page 21, Required: False): Enter the schedule for this production planning and control process.
* **Production Planning and Control Process Deadline** (Page 22, Required: False): Enter the deadline for this production planning and control process.
* **Production Planning and Control Process Start Date** (Page 24, Required: False): Enter the start date of this production planning and control process.
* **Production Planning and Control Process End Date** (Page 25, Required: False): Enter the end date of this production planning and control process.

## Tips
* Please ensure that all required fields are completed accurately and thoroughly.
* If you are unsure about any field, please consult with the relevant production team members or management.
* This form will be used to generate a report, so please enter all relevant information to ensure an accurate representation of the factory's performance.
