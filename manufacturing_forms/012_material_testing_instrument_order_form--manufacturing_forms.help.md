# Material Testing Instrument Order Form - Help Guide

## Purpose
The Material Testing Instrument Order Form is designed to help users order material testing instruments, such as equipment or tools, that are required for testing and inspection processes in the manufacturing industry. The form is intended for internal use only and is not suitable for external customers.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all necessary information and approvals before proceeding.
2. Fill in the instrument type (Instrument Type) field with "Yes" if the instrument is required.
3. Select the specific instruments that you need (Instrument Options) from the available options.
4. Enter the date when the material testing is scheduled (Material Testing Date).
5. Enter the quantity of the instrument required (Instrument Quantity).
6. Enter the price of the instrument (Instrument Price).

## Field-by-Field Explanation

* **Instrument Type** (Instrument Type, required/optional: required): This field indicates whether the instrument is required for material testing. If "Yes" is selected, you will be able to select the specific instrument options below.
* **Instrument Options** (Instrument Options, required/optional: false): Select all the instruments that you need from the available options. This field is optional if Instrument Type is "No".
* **Material Testing Date** (Material Testing Date, required/optional: required): Enter the date when the material testing is scheduled. This field is required.
* **Instrument Quantity** (Instrument Quantity, required/optional: required): Enter the quantity of the instrument required. This field is required.
* **Instrument Price** (Instrument Price, required/optional: required): Enter the price of the instrument. This field is required.
