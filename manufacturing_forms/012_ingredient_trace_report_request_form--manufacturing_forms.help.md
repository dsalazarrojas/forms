# Ingredient Trace Report Request Form - Help Guide

## Purpose
The Ingredient Trace Report Request Form is used to request an ingredient trace report from a manufacturer. This report provides information about the origin, production, and processing of a specific ingredient. To ensure accurate and efficient processing, please ensure that you are submitting a legitimate request and not duplicating an existing one.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the product name in the product_name field.
2. Provide the batch number for the ingredient in the batch_number field.
3. Enter the date of the incident in the incident_date field.
4. Specify the name of the ingredient in the ingredient_name field.

## Field-by-Field Explanation
### product_name (text)
* A required field to specify the name of the product related to the trace request.
### batch_number (number)
* Enter the batch number associated with the specific ingredient.
### incident_date (date)
* Specify the date of the incident or event related to the ingredient trace.
### ingredient_name (text)
* A required field to specify the name of the ingredient for which you are requesting a trace report.

## Tips
* Please ensure that you have all relevant information before submitting the form to avoid delays.
* If you have any questions or concerns, do not hesitate to contact our support team.
* Duplicate requests may be rejected, so please verify that you are not submitting a duplicate request.
