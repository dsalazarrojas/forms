# Product Co Development Registration Form - Help Guide
## Purpose
The "Product Co Development Registration Form" is a tool used to register and track product co-development projects. This form is designed to collect essential information about the project, including team lead, company, collaboration partners, project name, and more.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Product Team Lead" field with the name and contact information of the team lead.
2. Enter the name of the company or organization involved in the project.
3. If applicable, select "Yes" or "No" for "Collaboration Partners" to indicate if the project involves collaboration.
4. List the names and details of the collaboration partners in the "Collaboration Partners List" field.
5. Enter the project name and description in the "Project Name" and "Project Description" fields, respectively.
6. Select the stage of co-development for the project in the "Co-Development Stage" field.
7. Enter the start and end dates of the project in the "Project Start Date" and "Project End Date" fields, respectively.
8. Select the project status (Active, Inactive, or Cancelled) in the "Project Status" field.
9. Enter the location of the project in the "Project Location" field.
10. Select the stage of collaboration for the project in the "Collaboration Stage" field.
11. Select the status of collaboration (Active, Inactive, or Cancelled) in the "Collaboration Status" field.
12. Select "Yes" or "No" for "Collaboration Stage 2" to indicate if the project involves collaboration.
13. Select the type of collaboration (Co-development, Co-licensing, or Joint Venture) in the "Collaboration Type" field.
14. Select the co-lending, co-equity, and co-investment options for the project in the "Co-Lending", "Co-Equity", and "Co-Investment" fields, respectively.
15. Select the co-maintenance and submission options for the project in the "Co-Maintenance" and "Submission" fields, respectively.

## Field-by-Field Explanation

* **Product Team Lead** (`product_team_lead`, text, required): Enter the name and contact information of the team lead.
* **Company** (`company`, text, required): Enter the name of the company or organization involved in the project.
* **Collaboration Partners** (`collaboration_partners`, select_multiple, optional): If the project involves collaboration, select "Yes" or "No" to indicate the type of collaboration.
* **Collaboration Partners List** (`collaboration_partners_list`, note, optional): List the names and details of the collaboration partners.
* **Project Name** (`project_name`, text, required): Enter the name of the project.
* **Project Description** (`project_description`, text, required): Enter a brief description of the project.
* **Co-Development Stage** (`co_development_stage`, select_one, optional): Select the stage of co-development for the project.
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of the project.
* **Project Status** (`project_status`, select_one, optional): Select the status of the project (Active, Inactive, or Cancelled).
* **Project Location** (`project_location`, text, optional): Enter the location of the project.
* **Collaboration Stage** (`collaboration_stage`, select_one, optional): Select the stage of collaboration for the project.
* **Collaboration Status** (`collaboration_status`, select_one, optional): Select the status of collaboration (Active, Inactive, or Cancelled).
* **Collaboration Stage 2** (`collaboration_stage_2`, select_multiple, optional): Select "Yes" or "No" to indicate if the project involves collaboration.
* **Collaboration Type** (`collaboration_type`, select_one, optional): Select the type of collaboration (Co-development, Co-licensing, or Joint Venture).
* **Co-Lending** (`co_lending`, select_one, optional): Select the co-lending option for the project (Lending, Non-Lending, or None).
* **Co-Equity** (`co_equity`, select_one, optional): Select the co-equity option for the project (Equity, None, or Joint).
* **Co-Investment** (`co_investment`, select_one, optional): Select the co-investment option for the project (Investment, None, or Joint).
* **Co-Maintenance** (`co_maintenance`, select_one, optional): Select the co-maintenance option for the project (Maintenance, None, or Joint).
* **Submission** (`submission`, select_one, optional): Select the submission option for the project (Submission, None, or Joint).

## Tips
* Please ensure that you have all the necessary information before submitting the form.
* If you are unsure about any of the fields, feel free to ask for clarification.
* Double-check the form for errors before submitting it.
* If you need to make changes to the form, contact the form administrator for assistance.
