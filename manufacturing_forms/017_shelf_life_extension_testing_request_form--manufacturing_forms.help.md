# Shelf Life Extension Testing Request Form - Help Guide
## Purpose
The purpose of this form is to request an extension of the shelf life of a product, providing the necessary details and justification for the extension.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the product's manufacturer name in the "Manufacturer" field.
2. Enter the product's name in the "Product" field.
3. Select the date of the product's expiry from the calendar or select it from the dropdown list in the "Expiry" field.
4. Enter the justification for requesting the shelf life extension in the "Justification" field.
5. Upload any supporting documents for the request in the "Supporting Documents" field.
6. If a laboratory has been assigned to perform the testing, select "Yes" in the "Assigned Laboratory" field and enter their contact information in the "Assigned Laboratory Contact Info" field.
7. If you are submitting the request, select "Yes" in the "Submitted By" field and enter your contact information in the "Submitted By Contact Info" and "Submitted By" fields.
8. If a tool has been assigned to the request, select "Yes" in the "Assigned Tool" field.
9. Select "Yes" in the "Assigned User" field to assign a user to the request.
10. Enter the submission date and time in the "Submission Date" and "Submission Time" fields.

## Field-by-Field Explanation

* **Manufacturer** (`manufacturer`, text, optional): Enter the name of the product's manufacturer.
* **Product** (`product`, text, optional): Enter the name of the product being requested.
* **Expiry** (`expiry`, date, optional): Select the date of the product's expiry from the calendar or select it from the dropdown list.
* **Justification** (`justification`, text, optional): Enter a brief explanation for why the shelf life extension is necessary.
* **Supporting Documents** (`documents`, note, optional): Upload any files or documents that support the request.
* **Assigned Laboratory** (`assigned_laboratory`, select_one, optional): Select "Yes" if a laboratory has been assigned to perform the testing.
* **Assigned Laboratory Contact Info** (`assigned_laboratory_email`, email, optional): Enter the contact information of the assigned laboratory.
* **Assigned Laboratory Contact** (`assigned_laboratory_phone`, text, optional): Enter the phone number of the assigned laboratory.
* **Submitted By** (`submitted_by`, select_one, optional): Select "Yes" if you are submitting the request.
* **Submitted By Contact Info** (`submitted_by_email`, email, optional): Enter your contact information.
* **Submitted By** (`submitted_by_phone`, text, optional): Enter your phone number.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select "Yes" if a tool has been assigned to the request.
* **Assigned User** (`assigned_user`, select_one, optional): Select "Yes" if you want to assign a user to the request.
* **Form ID** (`form_id`, text, optional): Enter a unique identifier for the form (if required).
* **Submission Date** (`submitted_date`, date, optional): Enter the date you are submitting the request.
* **Submission Time** (`submitted_time`, time, optional): Enter the time you are submitting the request.
* **Submitted By User** (`submitted_by_user`, select_one, optional): Select "Yes" if you are submitting the request on behalf of someone else.
