# Production Machinery Quote Request - Help Guide

## Purpose
This form is used to request a quote from suppliers for production machinery. It is designed to gather essential information from the production team, including contact details, production schedule, and equipment requirements.

## How To Complete This Form

1. Fill out all required fields marked with an asterisk (\*) with accurate and up-to-date information.
2. For select_one and select_multiple fields, choose the relevant options that best match your needs.
3. For date fields, enter the dates in the format MM/DD/YYYY.
4. For text fields, enter a brief description of the equipment or requirements.
5. For note fields, provide any additional information that may be helpful for the supplier.

## Field-by-Field Explanation

* **Contact Person** (`contact_person`, Text, Optional): Enter the name of the person to contact for this quote request.
* **Customer Name** (`customer_name`, Text, Required): Enter the name of the customer for this quote request.
* **Contact Email** (`contact_email`, Email, Required): Enter the email address of the person to contact for this quote request.
* **Contact Phone** (`contact_phone`, Text, Optional): Enter the phone number of the person to contact for this quote request.
* **Production Site** (`production_site`, Text, Required): Enter the production site where the machinery will be used.
* **Production Site Location** (`production_site_location`, Text, Optional): Enter the location of the production site (e.g. city, state, country).
* **Machinery Suppliers** (`machinery_suppliers`, Select One, Required): Choose "Yes" if you are requesting quote from a specific supplier.
* **Equipment Type** (`equipment_type`, Select Multiple, Required): Choose all relevant equipment types that you are requesting a quote for.
* **Production Quantity** (`production_quantity`, Number, Required): Enter the expected production quantity.
* **Production Frequency** (`production_frequency`, Select Multiple, Required): Choose all relevant production frequencies that apply.
* **Production Start Date** (`production_start_date`, Date, Required): Enter the start date of production.
* **Production End Date** (`production_end_date`, Select Multiple, Optional): Choose "Yes" if you know the end date of production.
* **Quote Due Date** (`quote_due_date`, Date, Required): Enter the due date for the quote.
* **Requested Equipment List** (`requested_equipment_list`, Text, Required): Enter a list of required equipment.
* **Equipment Note** (`equipment_note`, Note, Optional): Provide any additional information about the equipment or requirements.
* **Production Requirements** (`production_requirements`, Text, Required): Enter any additional production requirements.
* **Production Lead Time** (`production_lead_time`, Number, Optional): Enter the expected lead time for production.
* **Production Capacity** (`production_capacity`, Text, Optional): Enter any relevant production capacity information.
* **Customer Reference** (`customer_reference`, Text, Optional): Enter any relevant customer reference information.
* **Machinery Suppliers Additional Info 1** (`machinery_suppliers_additional_info`, Text, Optional): Enter any additional information about the supplier.
* **Machinery Suppliers Phone** (`machinery_suppliers_phone`, Text, Optional): Enter the phone number of the supplier.
* **Machinery Suppliers Email** (`machinery_suppliers_email`, Email, Optional): Enter the email address of the supplier.
* **Machinery Suppliers Additional Info 2** (`machinery_suppliers_additional_info_2`, Text, Optional): Enter any additional information about the supplier.
* **Machinery Suppliers Additional Info 3** (`machinery_suppliers_additional_info_3`, Text, Optional): Enter any additional information about the supplier.
