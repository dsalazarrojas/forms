# Material Hardness Assessment - Help Guide
## Purpose
The Material Hardness Assessment form is used to record and document the results of material testing, including the test method, test value, and test result. This form helps to ensure consistency and accuracy in material testing processes.

## How To Complete This Form
1. Select the appropriate test method for the material being tested.
2. Enter the test value(s) obtained from the testing process.
3. Enter any relevant observations made during the testing process.
4. Record the date and location of the hardness test.
5. Provide contact information for the person conducting the test.
6. Enter a brief description of the hardness scale used.
7. Select the test result(s) obtained from the testing process.
8. Enter any notes or comments related to the test.
9. Enter any additional information about the test setup and location.
10. Enter any additional notes or comments about the test.

## Field-by-Field Explanation

* **Test Method** (`test_method`, text, required): Enter the method used to test the material (e.g., Rockwell 1, Rockwell 2, etc.).
* **Test Value** (`test_value`, number, required): Enter the test value obtained from the testing process.
* **Observation** (`observation`, text, required): Enter any relevant observations made during the testing process.
* **Hardness Test Date** (`hardness_test_date`, date, required): Enter the date the hardness test was performed.
* **Tester Name** (`tester_name`, text, required): Enter the name of the person conducting the test.
* **Tester Role** (`tester_role`, text, required): Enter the role of the person conducting the test (e.g., quality control engineer, materials scientist, etc.).
* **Test Location** (`test_location`, text, required): Enter the location where the hardness test was performed.
* **Hardness Scale Used** (`hardness_scale_used`, select_one, required): Select the hardness scale used for the test (e.g., Rockwell 1, Rockwell 2, etc.).
* **Test Result** (`test_result`, select_multiple, required): Select the test result(s) obtained from the testing process (e.g., Pass, Fail, Pending, etc.).
* **Notes** (`notes`, text, required): Enter any additional notes or comments about the test.
* **Contact Info** (`contact_info`, text, required): Enter the contact information for the person conducting the test (e.g., email, phone number, etc.).
* **Hardness Scale Description** (`hardness_scale_description`, text, optional): Enter a brief description of the hardness scale used.
* **Test Frequency** (`test_frequency`, number, optional): Enter the frequency of the test (e.g., how often the test is performed).
* **Tester Notes** (`tester_notes`, text, optional): Enter any additional notes or comments from the person conducting the test.
* **Hardness Scale Reference** (`hardness_scale_reference`, text, optional): Enter any reference or documentation for the hardness scale used.
* **Hardness Scale Certification** (`hardness_scale_certification`, text, optional): Enter any certification or authentication for the hardness scale used.
* **Test Method Certification** (`test_method_certification`, text, optional): Enter any certification or authentication for the test method used.
* **Test Equipment** (`test_equipment`, text, optional): Enter any equipment used during the test.
* **Test Setup** (`test_setup`, text, optional): Enter any additional information about the test setup.
* **Test Location Setup** (`test_location_setup`, text, optional): Enter any additional information about the test location.
* **Hardness Scale Notes** (`hardness_scale_notes`, text, optional): Enter any additional notes or comments about the hardness scale used.
* **Test Result Notes** (`test_result_notes`, text, optional): Enter any additional notes or comments about the test result.
* **Test Location** (`test_location`, text, optional): Enter the test location (e.g., where the test was performed).
* **Test Date** (`test_date`, date, optional): Enter the date the test was performed.
* **Tester Signature** (`tester_signature`, text, optional): Enter the signature of the person conducting the test.

Note: The optional fields are only required if the field is relevant to the specific test or process.
