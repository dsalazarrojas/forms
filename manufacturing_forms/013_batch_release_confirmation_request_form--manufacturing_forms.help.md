# Batch Release Confirmation Request Form - Help Guide

## Purpose
The Batch Release Confirmation Request Form is designed to collect and verify essential information for the release of a batch of products. This form ensures that all required checks and approvals are in place before the batch is released from the facility. The form is used to gather data on batch details, production history, and quality assurance, making it an essential tool for streamlining the release process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Unique Request ID to associate the batch release with the initial request.
2. Select the Date of the initial request.
3. Enter the Batch ID, which is the unique identifier for the batch.
4. Provide the Product Name and Product Code for the product being released.
5. Enter the batch size, which is the quantity in the batch.
6. Specify the Manufacturing Date, which is when the batch was produced.
7. Enter the Name of the Requester.
8. Choose the Department responsible for the request (Production, Quality Assurance, Warehouse, Supply Chain, or Other).
9. Confirm whether all quality tests have been completed (Yes - All Passed, Yes - With Minor Deviations, or No - Pending Tests).
10. Confirm whether all documentation is complete (Yes - Complete, Partially Complete, or No - Missing Items).
11. Confirm the regulatory compliance status (Fully Compliant, Compliant with Notes, or Non-Compliant).
12. Enter the Current Storage Location of the batch.
13. Enter the Expiry Date of the product.
14. Choose the release urgency (Standard, Priority, Urgent, or Emergency).
15. Enter the destination for the batch release.
16. (Optional) Add any Special Handling Requirements.
17. Confirm the Quality Assurance Approval Status (Approved, Pending Review, or Not Approved).
18. If applicable, enter the name of the Quality Assurance Approver.
19. Add any Additional Comments or information.

## Field-by-Field Explanation
*   **Request ID** (`request_id`): Enter the unique identifier for the batch release.
*   **Request Date** (`request_date`): Enter the date the batch release was requested.
*   **Batch ID** (`batch_id`): Enter the batch ID for the product being released.
*   **Product Name** (`product_name`): Enter the name of the product being released.
*   **Product Code** (`product_code`): Enter the product code or SKU for the product being released.
*   **Batch Size** (`batch_size`): Enter the quantity in the batch.
*   **Manufacturing Date** (`manufacturing_date`): Enter the date the batch was produced.
*   **Requested By** (`requested_by`): Enter the name of the person who requested the batch release.
*   **Department** (`department`): Select the department responsible for the request.
*   **All Quality Tests Completed** (`quality_tests_completed`): Confirm whether all quality tests have been completed.
*   **Documentation Complete** (`documentation_complete`): Confirm whether all documentation is complete.
*   **Compliance Status** (`compliance_status`): Confirm the regulatory compliance status.
*   **Current Storage Location** (`storage_location`): Enter the current storage location of the batch.
*   **Expiry Date** (`expiry_date`): Enter the product's expiry date.
*   **Release Urgency** (`release_urgency`): Choose the release urgency level.
*   **Release Destination** (`destination`): Enter the destination for the batch release.
*   **Special Handling Requirements** (`special_handling`): Add any special handling requirements for the batch release.
*   **QA Approval Status** (`qa_approval`): Confirm the Quality Assurance approval status.
*   **QA Approver Name** (`qa_approver`): Enter the name of the Quality Assurance approver.
*   **Additional Comments** (`additional_comments`): Add any additional comments or information for the batch release.
