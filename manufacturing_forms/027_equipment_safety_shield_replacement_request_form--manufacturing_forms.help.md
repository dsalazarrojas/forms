The Equipment Safety Shield Replacement Request Form is used to request replacement of equipment that is broken, malfunctioning, or otherwise unusable. To ensure that the correct equipment is prioritized for repair or replacement, please only submit a form if the issue is not minor or temporary, and if you have already tried troubleshooting or contacted the manufacturer for assistance.

Before submitting a form, please check our database to see if the issue has already been reported. Duplicate submissions will be ignored.

**Equipment Safety Shield Replacement Request Form - Help Guide**
## Purpose
The purpose of this form is to request replacement of equipment that is broken, malfunctioning, or otherwise unusable.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the issue with the equipment.
2. Enter the Equipment ID number of the equipment in question.
3. Enter the name of the equipment that is experiencing the issue.
4. Select the current status of the equipment (Available, Maintenance, Missing, or Offline).
5. Select the status of the issue (New, Under Investigation, Resolved, or Waiting for Maintenance).
6. Select the status of the maintenance (Pending, In Progress, or Completed).
7. Optionally, provide a date and time when the issue first occurred.
8. Optionally, provide any relevant images of the issue.
9. Provide the reason for the issue, if available.
10. Provide any additional comments or notes about the issue.
11. Select the name of the person assigned to resolve the issue, if applicable.
12. Provide any additional comments or notes about the issue, if necessary.

## Field-by-Field Explanation

* **Header**: This field is not required, but provides a general description of the form and its purpose.
* **Issue Description**: Provide a brief description of the issue with the equipment. This could include symptoms, error messages, or any other relevant information.
* **Equipment ID**: Enter the unique identifier number for the equipment in question.
* **Equipment Name**: Enter the name of the equipment experiencing the issue.
* **Equipment Status**: Select the current status of the equipment from the following options:
	+ Available: The equipment is currently available for use.
	+ Maintenance: The equipment is currently undergoing maintenance.
	+ Missing: The equipment is not currently available.
	+ Offline: The equipment is currently offline.
* **Issue Date**: Provide the date when the issue first occurred. This is optional, but helps track the history of the issue.
* **Issue Time**: Provide the time when the issue first occurred. This is optional, but helps track the history of the issue.
* **Issue Description**: Provide a more detailed description of the issue, if available.
* **Issue Reason**: Provide the reason for the issue, if available.
* **Issue Image**: Provide any relevant images of the issue, if available.
* **Issue Status**: Select the status of the issue from the following options:
	+ New: The issue is new and has not been reported before.
	+ Under Investigation: The issue is currently being investigated.
	+ Resolved: The issue has been resolved.
	+ Waiting for Maintenance: The issue is waiting for maintenance to be completed.
* **Maintenance Status**: Select the status of the maintenance from the following options:
	+ Pending: The maintenance is pending.
	+ In Progress: The maintenance is currently in progress.
	+ Completed: The maintenance is complete.
* **Maintenance Date**: Provide the date when the maintenance is scheduled to be completed. This is optional, but helps track the history of the maintenance.
* **Maintenance Time**: Provide the time when the maintenance is scheduled to be completed. This is optional, but helps track the history of the maintenance.
* **Assigned to**: Enter the name of the person assigned to resolve the issue, if applicable.
* **Comments**: Provide any additional comments or notes about the issue, if necessary.

Note: Please submit the form only once for each issue, and avoid submitting duplicate forms for the same issue.
