# factory_cybersecurity_contact_form - Help Guide

## Purpose
The "factory_cybersecurity_contact_form" is designed for users to report security issues within the factory's network or systems.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the specific security issues you are experiencing.
2. Provide a detailed description of each issue.
3. Attach any supporting files that can help with the investigation.
4. Select the category and priority of the incident.
5. Click the "submit" button to send your report.

## Field-by-Field Explanation

* **security_issues** (`security_issues`, select_multiple, required): Select the specific security issues you are experiencing.
* **issue_description** (`issue_description`, text, required): Provide a detailed description of each issue.
* **supporting_files** (`supporting_files`, text, optional): Attach any supporting files that can help with the investigation.
* **submit_to** (`submit_to`, select_multiple, required): Select the specific team that will handle your report.
* **incident_id** (`incident_id`, number, optional): Please enter your incident ID if you have one.
* **issue_priority** (`issue_priority`, select_one, required): Select the priority of the incident.
* **issue_category** (`issue_category`, select_one, required): Select the category of the incident.
* **issue_description_2**, **issue_description_3**, ..., **issue_description_16** (`issue_description_2`, `issue_description_3`, ..., `issue_description_16`, text, optional): Provide additional detailed descriptions of each issue.
* **submit** (`submit`, text, required): Click the "submit" button to send your report.

## Tips

* Please ensure that you provide detailed descriptions of each issue.
* Attach any supporting files that can help with the investigation.
* Select the specific team that will handle your report.
* Enter your incident ID if you have one.
* Select the category and priority of the incident correctly.
