# Production Yield Data Request Form - Help Guide
## Purpose
This form is used to request production yield data for the manufacturing process. It helps to gather information on various aspects of production, including production data, yield rate, production rate, performance metrics, and other relevant details.

## How To Complete This Form
1. Select the correct category for your production data request.
2. Choose whether you want to request data for 'Yes' or 'No' for the selected category.
3. Enter the production data (e.g., quantity, quality).
4. Enter the yield rate (a numerical value).
5. Enter the production rate (a numerical value).
6. Select the performance metrics you want to include with your data request.
7. Provide any additional comments or observations.
8. Select the sub-category for your data request (optional).
9. Choose the manufacturing process (e.g., 'Yes' or 'No').
10. Enter the production yield (a numerical value).
11. Select the product related to your data request (e.g., 'Yes' or 'No').

## Field-by-Field Explanation
* **Manufacturing Forms** (`production_yield_data_request_form`, select_multiple, required: false): Select the category for your production data request from the options provided.
* **Category** (`category_form`, select_one, required: false): Select the category for which you want to request production data.
* **Production Data** (`production_data_form`, text, required: false): Enter relevant production data such as quantity, quality, or other relevant details.
* **Yield Rate** (`yield_rate_form`, number, required: false): Enter the yield rate as a numerical value.
* **Production Rate** (`production_rate_form`, number, required: false): Enter the production rate as a numerical value.
* **Performance Metrics** (`performance_metrics_form`, select_multiple, required: false): Select the performance metrics you want to include with your data request.
* **Additional Comments** (`additional_comments_form`, text, required: false): Provide any additional comments or observations that might be relevant to your data request.
* **Sub Category** (`category_form_1`, select_one, required: false): Select the sub-category for your data request (if applicable).
* **Manufacturing Process** (`manufacturing_process_form`, select_multiple, required: false): Choose the manufacturing process related to your data request (e.g., 'Yes' or 'No').
* **Production Yield** (`production_yield_form`, text, required: false): Enter the production yield as a numerical value.
* **Product** (`product_form`, select_one, required: false): Select the product related to your data request (e.g., 'Yes' or 'No').
