# Warehouse Robotics Trial Registration Form - Help Guide
## Purpose
The Warehouse Robotics Trial Registration Form is a tool for warehouse staff to register and track warehouse robotics trials. 

## How To Complete This Form
1. **Fill out the form completely and accurately**: Ensure all required fields have valid information. 
2. **Submit the form once**: To avoid duplication of trials, submit the form only once per trial. 

## Field-by-Field Explanation
* **Trial Request**: Enter a brief description of the trial being submitted.
* **Site Details**: Select the location or site where the trial is taking place. (Please select one option: Site 1, Site 2, Site 3)
	+ Hint: This field is crucial for identifying where the trial is happening.
* **Trial Details**: Enter the trial's specific details (a numeric value) 
	+ Hint: This field should not be left blank.
* **Start Date**: Enter the date the trial will start.
	+ Hint: This field is used for scheduling purposes.
* **End Date**: Enter the date the trial is scheduled to end.
	+ Hint: This field is used for scheduling purposes.
* **Trial Status**: Select the current status of the trial. (Select multiple options: In Progress, Completed, Cancelled)
	+ Hint: This field helps keep track of trial progress and status.
* **Follow Up Status**: Select the follow-up status of the trial. (Select multiple options: Scheduled, In Progress, Completed)
	+ Hint: This field helps with trial follow-up scheduling and progress.
* **Trial Site**: Select the location or site for the trial. (Select one option: Site 1, Site 2, Site 3)
	+ Hint: This field ensures the trial's location is accurately recorded.
