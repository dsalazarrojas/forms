# Machine Efficiency Tracker Order Form - Help Guide
## Purpose
This form is designed to track the efficiency of machines in the manufacturing process. It helps to collect data on various aspects of machine performance, allowing for better monitoring and improvement of machine efficiency.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the machine model from the options provided.
2. Choose the machine size from the options provided.
3. Select the machine type from the options provided.
4. Enter the number of machines being monitored.
5. Choose the machine condition from the options provided.
6. Select the monitoring tools used from the options provided.
7. Choose the monitoring period from the options provided.
8. Select the monitoring frequency from the options provided.
9. Choose the monitoring duration from the options provided.
10. Enter the cost of monitoring tools.
11. Enter the quantity of monitoring tools.
12. Enter the date of machine installation.
13. Select the location of machine installation from the options provided.
14. Choose the installation status from the options provided.
15. Enter the name of the contact person.
16. Enter the phone number of the contact person.
17. Enter the email of the contact person.
18. Choose the machine monitoring status from the options provided.
