# Quality Alert Form - Help Guide
## Purpose
This form is used to report quality issues and track the progress of actions taken to address them.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate quality level and production status for the issue.
2. Choose the action taken or status of the action taken by.
3. Enter the date and time of the action taken.
4. Provide your contact information for follow-up.
5. Enter a detailed description of the issue.
6. Enter any other relevant details.

## Field-by-Field Explanation

* **1. Quality Alert Form** (`quality_alert_form_1`, Select Multiple, Required): Select the quality level (Good or Poor) and production status (Active or Inactive) for the issue.
* **2. Production Line ID** (`production_line_id`, Number, Required): Enter the unique identifier for the production line where the issue occurred.
* **3. Quality Level ID** (`quality_level_id`, Select One, Required): Select the quality level (Good or Poor) for the issue.
* **4. Quality Level** (`quality_level`, Text, Optional): Enter a detailed description of the quality level for the issue.
* **5. Production Status ID** (`production_status_id`, Select One, Required): Select the production status (Active or Inactive) for the issue.
* **6. Production Status** (`production_status`, Text, Optional): Enter a detailed description of the production status for the issue.
* **7. Date** (`date`, Date, Optional): Enter the date of the issue.
* **8. Time** (`time`, Time, Optional): Enter the time of the issue.
* **9. Contact Name** (`contact_name`, Text, Optional): Enter your name for follow-up purposes.
* **10. Contact Phone** (`contact_phone`, Text, Optional): Enter your phone number for follow-up purposes.
* **11. Contact Email** (`contact_email`, Email, Optional): Enter your email address for follow-up purposes.
* **12. Issue Description** (`issue_description`, Text, Optional): Enter a detailed description of the issue.
* **13. Action Taken** (`action_taken`, Text, Optional): Enter the action taken to address the issue.
* **14. Action Taken By** (`action_taken_by`, Text, Optional): Enter the name of the person who took the action.
* **15. Action Date** (`action_date`, Date, Optional): Enter the date the action was taken.
* **16. Action Status** (`action_status`, Select One, Optional): Select the status of the action taken (Active or Inactive).
* **17. Action Taken By Email** (`action_taken_by_email`, Email, Optional): Enter the email address of the person who took the action.
* **18. Quality Level ID 2** (`quality_level_id2`, Select One, Optional): Select the quality level (Good or Poor) for the issue.
* **19. Production Status ID 2** (`production_status_id2`, Select One, Optional): Select the production status (Active or Inactive) for the issue.
* **20. Quality Level ID 3** (`quality_level_id3`, Select One, Optional): Select the quality level (Good or Poor) for the issue.
* **21. Production Status ID 3** (`production_status_id3`, Select One, Optional): Select the production status (Active or Inactive) for the issue.
* **22. Contact Name 2** (`contact_name2`, Text, Optional): Enter your name for follow-up purposes.
* **23. Contact Phone 2** (`contact_phone2`, Text, Optional): Enter your phone number for follow-up purposes.
* **24. Contact Email 2** (`contact_email2`, Email, Optional): Enter your email address for follow-up purposes.
* **25. Issue Description 2** (`issue_description2`, Text, Optional): Enter a detailed description of the issue.

## Tips

* Make sure to select the correct quality level and production status for each issue.
* Enter accurate contact information for follow-up purposes.
* Enter detailed descriptions of each issue.
* Review your entries carefully before submitting the form.
