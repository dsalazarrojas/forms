# Material Property Data Collection - Help Guide

## Purpose
The Material Property Data Collection form is used to gather and store data about materials used in the manufacturing process. It's essential to only use this form for materials that are relevant to the process, and to avoid duplicate entries.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the `material_name` field with the name of the material.
2. Select `Yes` or `No` in the `material_type` field to indicate whether the material is a specific type.
3. Enter a brief description of the material in the `material_description` field.
4. For each property of the material, fill in the corresponding field (e.g. `material_property_1`, `material_property_2`, etc.) with the relevant information.

## Field-by-Field Explanation

* **material_name** (`material_name`, text, required): Enter the name of the material.
* **material_type** (`material_type`, select_one, required): Indicate whether the material is a specific type (`Yes` or `No`).
* **material_description** (`material_description`, text, required): Enter a brief description of the material.
* **material_property_1** (`material_property_1`, text, optional): Enter the value of the first material property.
* **material_property_2** (`material_property_2`, text, optional): Enter the value of the second material property.
* **material_property_3** (`material_property_3`, text, optional): Enter the value of the third material property.
* **material_property_4** (`material_property_4`, text, optional): Enter the value of the fourth material property.
* **material_property_5** (`material_property_5`, text, optional): Enter the value of the fifth material property.
* **material_property_6** (`material_property_6`, text, optional): Enter the value of the sixth material property.
* **material_property_7** (`material_property_7`, text, optional): Enter the value of the seventh material property.
* **material_property_8** (`material_property_8`, text, optional): Enter the value of the eighth material property.

## Tips

* Make sure to only enter information for materials that are relevant to the manufacturing process.
* Avoid duplicate entries to prevent errors in the data collection process.
