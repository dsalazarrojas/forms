# Ingredient Declaration Update Request Form - Help Guide
## Purpose
The Ingredient Declaration Update Request Form is a tool for requesting updates to existing ingredient declarations. Use this form to provide accurate and detailed information about the changes required for a product or material.

## How To Complete This Form
1. Please ensure you have the necessary permissions to submit this form.
2. Review the form carefully and fill in the relevant fields with accurate information.
3. If you're updating multiple fields, make sure to fill in all relevant fields.
4. Once you're satisfied that the form is complete, submit the form for processing.

## Field-by-Field Explanation
* **Ingredient Declaration Update Request** (`ingredient_declaration_update_request`): This field is for the main reason or description of the update request.
	+ Please enter a brief description of the change needed for the ingredient declaration.
* **Reasons For Update** (`reasons_for_update`): This field is for additional information about the update request.
	+ Use this field to provide more details about the update request, if necessary.
* **Documentation** (`documentation`): This field is for attaching any supporting documentation or evidence for the update request.
	+ Upload relevant documents, such as test results or technical reports, to help support your request.
* **Contact Details** (`contact_details`): This field is for providing contact information for the person submitting the update request.
	+ Enter the name and contact information of the person submitting the form.
* **Submitted By** (`submitted_by`): This field is for specifying who submitted the update request.
	+ Select the name of the person or department that submitted the form.
* **Submitted On** (`submitted_on`): This field is for recording the date and time the form was submitted.
	+ This field is automatically populated and cannot be edited by the user.
* **Assigned To** (`assigned_to`): This field is for assigning the update request to a team or department.
	+ Select the team or department responsible for processing the update request.
* **Assigned Tool** (`assigned_tool`): This field is for specifying the tool or software used to process the update request.
	+ Select the tool or software used for processing the update request.
* **Status** (`status`): This field is for tracking the progress of the update request.
	+ Select the status of the form, such as Draft, In Progress, or Completed.
* **Notes** (`notes`): This field is for adding any additional comments or notes about the update request.
	+ Use this field to provide further information or clarification about the update request.
* **Form ID** (`form_id`): This field is for tracking the unique identifier of the update request form.
	+ This field is automatically populated and cannot be edited by the user.
* **Category ID** (`category_id`): This field is for specifying the category of the update request.
	+ Select or enter the category ID of the product or material being updated.
* **Assigned To ID** (`assigned_to_id`): This field is for tracking the ID of the person or team assigned to process the update request.
	+ This field is automatically populated and cannot be edited by the user.
