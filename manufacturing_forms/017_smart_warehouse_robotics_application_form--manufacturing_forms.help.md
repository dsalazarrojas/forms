# Smart Warehouse Robotics Application Form - Help Guide

## Purpose
This form is designed for users to provide information about a robotic application for their warehouse.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields marked with an asterisk (\*). These fields include:
	* name
	* robot_capacity
	* robot_price
	* robot_warranty_duration
	* terms_and_conditions
2. Fill in the optional fields as needed. These fields include:
	* form_title
	* email
	* address
	* company
	* contact_number
	* robot_type
	* robot_model
	* robot_description
	* robot_image
	* robot_video
	* robot_document
	* robot_file
	* robot_installation
	* robot_maintenance
	* robot_support
	* robot_training
	* robot_customization
	* robot_return_policy
	* additional_comments

## Field-by-Field Explanation

* **form_title**: The title of the robotic application. This is an optional field.
* **name**: Your name. This is a required field.
* **email**: Your email address. This is an optional field.
* **address**: The address of your warehouse. This is an optional field.
* **company**: The name of your company. This is an optional field.
* **contact_number**: The contact number of your warehouse. This is an optional field.
* **robot_type**: A multiple-choice field to select the type of robot. Options include 'Yes' and 'No'.
* **robot_model**: The model of the robot. This is an optional field.
* **robot_capacity**: A multiple-choice field to select the capacity of the robot. Options include 'Yes' and 'No'. This is a required field.
* **robot_description**: A description of the robot. This is an optional field.
* **robot_image**: A link to an image of the robot. This is an optional field.
* **robot_video**: A link to a video of the robot. This is an optional field.
* **robot_document**: A link to a document about the robot. This is an optional field.
* **robot_file**: A file about the robot. This is an optional field.
* **robot_installation**: A multiple-choice field to select the installation of the robot. Options include 'Yes' and 'No'. This is a required field.
* **robot_maintenance**: A multiple-choice field to select the maintenance of the robot. Options include 'Yes' and 'No'. This is an optional field.
* **robot_support**: A multiple-choice field to select the support of the robot. Options include 'Yes' and 'No'. This is an optional field.
* **robot_training**: A multiple-choice field to select the training of the robot. Options include 'Yes' and 'No'. This is an optional field.
* **robot_customization**: A multiple-choice field to select the customization of the robot. Options include 'Yes' and 'No'. This is an optional field.
* **robot_warranty_duration**: A multiple-choice field to select the warranty duration of the robot. Options include 'Yes' and 'No'. This is a required field.
* **robot_return_policy**: A multiple-choice field to select the return policy of the robot. Options include 'Yes' and 'No'. This is an optional field.
* **terms_and_conditions**: A text field to agree to the terms and conditions. This is a required field.
* **additional_comments**: A field for any additional comments. This is an optional field.
* **robot_price**: The price of the robot. This is a required field.
* **robot_warranty**: A multiple-choice field to select the warranty of the robot. Options include 'Yes' and 'No'. This is an optional field.

## Tips
Please ensure that you have filled in all required fields before submitting the form. If you need further assistance, please contact our support team.
