# Production Closure Checklist - Help Guide

## Purpose
This form is used to document the closure of a production line, capturing essential details for accurate record-keeping and future reference.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the current production line.
2. Indicate whether the production line is closed.
3. Enter the production date and time.
4. Enter the length of the shift.
5. Confirm if the shift length is in hours.
6. Enter the production manager's name.
7. Enter the production manager's email address.
8. Enter the production manager's phone number.
9. Enter the production location.
10. Indicate if any production resources are available or unavailable for the next shift.

## Field-by-Field Explanation

* **Production Line** (`production_line`, text, required): Enter the current production line being closed.
* **Is the production line closed?** (`is_production_line_closed`, select_one, required): Select "Yes" or "No" to indicate the status of the production line.
* **Production Date** (`production_date`, date, required): Enter the date of the production closure.
* **Production Time** (`production_time`, time, required): Enter the time of the production closure.
* **Shift Length** (`shift_length`, number, required): Enter the length of the shift.
* **Is the shift length in hours?** (`is_shift_length_hours`, select_one, required): Select "Yes" or "No" to indicate if the shift length is in hours.
* **Production Manager** (`production_manager_name`, text, required): Enter the name of the production manager responsible for the production line.
* **Production Manager Email** (`production_manager_email`, email, required): Enter the production manager's email address.
* **Production Manager Phone** (`production_manager_phone`, text, required): Enter the production manager's phone number.
* **Location** (`location`, text, required): Enter the production location.
* **Are any production resources available for next shift?** (`is_production_resources_available_next_shift`, select_one, required): Select "Yes" or "No" to indicate if any production resources are available for the next shift.
* **Are any production resources unavailable for next shift?** (`is_production_resources_unavailable_next_shift`, select_one, required): Select "Yes" or "No" to indicate if any production resources are unavailable for the next shift.

## Tips
* Make sure to accurately fill out each field as it relates to the specific production line and shift.
* Double-check the production date and time to ensure accuracy.
* Enter the production manager's contact information accurately.
* Confirm the availability or unavailability of production resources for the next shift.
* Review the form carefully before submission to ensure all required fields are completed.
