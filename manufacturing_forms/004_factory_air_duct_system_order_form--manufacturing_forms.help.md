# Factory Air Duct System Order Form - Help Guide
## Purpose
The Factory Air Duct System Order Form is designed to collect essential information for the production and installation of air duct systems in a factory setting. This form helps suppliers and manufacturers confirm the type of system needed, material used, expected delivery date, and other vital details for the successful completion of the project.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter Customer Information**: Fill in the relevant details about the customer, including name, contact information, and factory address.
2. Select the **Type of Factory Air Duct System** that best fits the needs of the project.
3. Specify the **Expected Delivery Date** when the system is required.
4. Estimate the **Quantity** of the system needed.
5. Select the **Price Range** for the order.
6. Choose the preferred **HVAC Supplier** for the project.
7. Decide on the **Order Tracking Method** for the project.
8. **Describe the System Technical Specifications** in detail.
9. Indicate whether **Factory Details** are provided or required.
10. Confirm the **Material Used** in the system.
11. **Specify the Expected Installation Date** for the system.
12. Enter any **Special Requests or Notes** for the project.
13. Select the **System Details** relevant to the project.
14. Enter the **Factory Address** for the project.
15. Provide **Contact Information** for the customer.
16. Enter the **Shipping Information** for the project.

## Field-by-Field Explanation

* **Customer Information** (`customer_info`, text, required): Enter the customer's name and contact information.
* **Type of Factory Air Duct System** (`system_type`, select_one, required): Choose the type of system that best fits the project's needs.
* **Expected Delivery Date** (`delivery_date`, date, required): Specify the date when the system is required.
* **Estimated Quantity** (`quantity`, number, required): Estimate the number of systems needed.
* **Price Range** (`price_range`, number, required): Select the price range for the order.
* **HVAC Supplier Details** (`supplier_info`, select_multiple, required): Choose one or multiple suppliers for the project.
* **Order Tracking Method** (`tracking_method`, select_one, required): Decide on the order tracking method for the project.
* **System Technical Specifications** (`system_specs`, text, required): Describe the system's technical specifications in detail.
* **Factory Details** (`factory_info`, select_one, required): Indicate whether factory details are provided or required.
* **Material Used** (`material_used`, select_one, required): Confirm the material used in the system.
* **Expected Installation Date** (`installation_date`, date, required): Specify the date when the system is expected to be installed.
* **Special Requests or Notes** (`special_requests`, note, optional): Enter any special requests or notes for the project.
* **System Details** (`system_details`, select_multiple, required): Select the system details relevant to the project.
* **Factory Address** (`factory_address`, text, required): Enter the factory address for the project.
* **Contact Information** (`contact_info`, text, required): Provide the contact information for the customer.
* **Shipping Information** (`shipping_info`, text, required): Enter the shipping information for the project.
