# robotics_end_effector_custom_order_form - Help Guide
## Purpose
The purpose of this form is to place custom orders for end effectors in the robotics department. It captures essential information from the user, including their contact details, the type of tool required, quantity, delivery date and time, and any additional comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your User Name.
2. Enter your Contact E-mail and Contact Phone numbers.
3. Select the type of tool you require (Custom or Standard).
4. Provide a brief description of the custom tool, if applicable.
5. Specify the quantity of the required tool.
6. Choose a delivery date and delivery time.
7. Add any custom order comments (optional).

## Field-by-Field Explanation
### User Name (User Name, text, required)
Enter your full name as it appears on your official documentation or business card.

### Contact E-mail (Contact E-mail, email, required)
Enter your email address that you'd like us to contact you on.

### Contact Phone (Contact Phone, text, required)
Enter your phone number that we can reach you at.

### Tool Type (Tool Type, select_one, required)
Select the type of tool you require: Custom or Standard.

### Custom Tool Description (Custom Tool Description, text, optional)
If you're ordering a custom tool, provide a brief description of the custom tool.

### Quantity (Quantity, number, required)
Specify the quantity of the required tool.

### Delivery Date (Delivery Date, date, required)
Choose a date for delivery of the tool.

### Delivery Time (Delivery Time, time, required)
Choose a time for delivery of the tool.

### Custom Order Comments (Custom Order Comments, note, optional)
Add any additional comments or notes about your custom order (if applicable).

### Assigned Tool (Assigned Tool, select_one, required)
Select a tool from the options: chatjimmy or other.
