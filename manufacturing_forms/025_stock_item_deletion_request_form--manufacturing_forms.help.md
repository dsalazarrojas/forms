# Stock Item Deletion Request Form - Help Guide
## Purpose
The "Stock Item Deletion Request Form" is used to request the deletion of a stock item. This form helps authorized personnel to initiate the process for removing a stock item from the inventory. It's essential to use this form to ensure that stock items are correctly updated and maintained in the inventory system.

## How To Complete This Form

1.  To complete this form, start on "Stock Item Deletion Request Form Page 1".
2.  Select the "Stock Item ID" and enter the ID of the stock item you want to delete.
3.  Enter the "Stock Item Quantity" if the item has multiple units or variations that you want to delete.
4.  Describe the "Reason for Removal" to provide context for the deletion request.

## Field-by-Field Explanation

*   **Stock Item ID** (`stock_item_id`, Number, Required): Enter the unique ID of the stock item you want to delete.
*   **Stock Item Quantity** (`stock_item_quantity`, Number, Optional): If the stock item has multiple units or variations, enter the quantity of the item you want to delete. Leave this field blank if you are deleting the entire stock item.
*   **Reason for Removal** (`reason_for_removal`, Text, Required): Provide a brief explanation for removing the stock item. This helps others understand the reason behind the deletion request.
