# Product Shelf Test Request Form prophets - Help Guide
## Purpose
This form is used to request a product to be placed on a shelf for testing purposes. Please read the form carefully to ensure that you are providing accurate and clear information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the product you want to test from the "Product id" field.
2. Provide a brief description of the product in the "Product description" field.
3. Indicate whether the product is on a shelf by selecting "Yes" or "No" in the "Shelf id" field.
4. Choose the type of test you want to perform in the "Test type" field.
5. Set the date and time for the test in the "Date" and "Time" fields.
6. Enter the name of the product in the "Product name" field.
7. Indicate the location of the shelf where the product will be tested in the "Shelf location" field.

## Field-by-Field Explanation
* **Product id**: Please select the product you want to test from the available options. This field is required.
* **Product description**: Please provide a brief description of the product you are testing. This field is not required, but it will help us to better understand the product.
* **Shelf id**: Indicate whether the product is on a shelf by selecting "Yes" or "No". This field is not required.
* **Test type**: Choose the type of test you want to perform. Please select "Yes" or "No" from the available options.
* **Date**: Please set the date for the test. This field is not required.
* **Time**: Please set the time for the test. This field is not required.
* **Product name**: Please enter the name of the product you are testing. This field is not required.
* **Shelf location**: Please indicate the location of the shelf where the product will be tested. Please select "Yes" or "No" from the available options. This field is not required.
