# Production Batch Update Request Form - Help Guide
## Purpose
The Production Batch Update Request Form is used to update production batch information. This form helps production team members to submit requests for updates to production batches. It ensures that all necessary information is documented and reviewed before proceeding with updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide production information for the batch you want to update.
2. Describe the reason for the update.
3. Attach any relevant documents or supporting materials.
4. Select the reason for the update.
5. Choose the production status and update type.
6. Select the update status and date of the update.
7. Enter the reviewer's notes for the review.

## Field-by-Field Explanation

* **Production Information** (`production_batch_update_request_form_production_info`, text, optional): Enter the production information for the batch being updated.
* **Reason** (`production_batch_update_request_form_reason`, text, optional): Enter the reason for the update.
* **Document** (`production_batch_update_request_form_document`, text, optional): Attach any relevant documents or supporting materials.
* **Reason for Update** (`production_batch_update_request_form_reason_for_update`, text, optional): Enter the reason for the update.
* **Requested By** (`production_batch_update_request_form_requested_by`, select_one, optional): Select the person responsible for requesting the update.
* **Requested Date** (`production_batch_update_request_form_requested_date`, date, optional): Enter the date when the update was requested.
* **Production Status** (`production_batch_update_request_form_production_status`, select_multiple, optional): Select the production status for the batch.
* **Update Type** (`production_batch_update_request_form_update_type`, select_one, optional): Select the type of update being requested.
* **Update Status** (`production_batch_update_request_form_update_status`, select_one, optional): Select the status of the update.
* **Update Date** (`production_batch_update_request_form_update_date`, date, optional): Enter the date of the update.
* **Reviewer Notes** (`production_batch_update_request_form_reviewer_notes`, note, optional): Enter any notes from the reviewer for the update.

## Tips
* Please ensure that all fields are completed accurately and thoroughly.
* Attach any relevant documents or supporting materials to support the update request.
* Review the form carefully before submitting it to ensure that all necessary information is provided.
