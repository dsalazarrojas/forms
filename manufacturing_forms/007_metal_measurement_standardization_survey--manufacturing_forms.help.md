# Metal Measurement Standardization Survey - Help Guide
## Purpose
This form is designed to collect information about standardization needs and practices in the manufacturing industry. It is intended to gather data about metal analysis, standardization practices, analysis techniques, data collection, and other relevant factors.

## How To Complete This Form
1. Review the form carefully to understand the questions and fields.
2. Answer each question accurately and thoroughly.
3. Select the relevant options for each field, if applicable.
4. Submit the form to ensure your responses are recorded.

## Field-by-Field Explanation

### 1. Introduction
* **Introduction** (`intro`, `note`, required: false`): This is a brief note to introduce the survey and provide context. Please read it carefully to understand the purpose and scope of the survey.

### 2. Metal Analysis Practices
* **Metal Analysis Practices** (`metal-analysis-practices`, `text`, required: false`): Describe your current metal analysis practices.

### 3. Standardization Needs
* **Standardization Needs** (`standardization-needs`, `text`, required: false`): List the standardization needs you currently face.

### 4. Scale
* **Scale** (`scale`, `select_one`, required: false`): Select one of the following scales:
	+ smaller
	+ medium
	+ large

### 5. Standardization Practices
* **Standardization Practices** (`standardization-practices`, `select_one`, required: false`): Select one of the following standardization practices:
	+ lab1
	+ lab2
	+ lab3
	+ lab4
	+ lab5

### 6. Analysis Techniques
* **Analysis Techniques** (`analysis-techniques`, `select_multiple`, required: false`): Select all the analysis techniques you use:
	+ technique1
	+ technique2
	+ technique3
	+ technique4

### 7. Data Collection
* **Data Collection** (`data-collection`, `text`, required: false`): Describe your data collection methods.

### 8-19. Standardization Needs 1-15
* **Standardization Needs 1-15** (`standardization-needs-1`, `text`, required: false`): List the standardization needs you currently face (16-21).

### 20-25. 
* **Data Collectors** (`data-collectors`, `text`, required: false`): Describe your data collectors.
* **Data Analysis Tools** (`data-analysis-tools`, `text`, required: false`): Describe your data analysis tools.
* **Data Analysis Methods** (`data-analysis-methods`, `text`, required: false`): Describe your data analysis methods.

## Tips
- Please answer all questions thoroughly and accurately.
- Select the relevant options for each field.
- If you are unsure about any question, contact the form administrators for clarification.
