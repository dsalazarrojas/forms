# Manufacturing Process Audit Form - Help Guide
## Purpose
The Manufacturing Process Audit Form is designed to evaluate the production process, identify areas of improvement, and take corrective actions to maintain a smooth and efficient production process.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form sections and fields carefully.
2. Answer each field accurately and thoroughly, providing as much detail as possible.
3. Choose the correct options for each field from the provided select options.

## Field-by-Field Explanation
### 1. **Production Process** (`production_process`, `text`, required: false)
Enter a brief description of the production process being audited.

### 2. **Inspection Frequency** (`inspection_frequency`, `select_one`, required: false)
Choose the frequency of inspections from the options:
*   Daily
*   Weekly
*   Monthly

### 3. **Production Capacity** (`production_capacity`, `number`, required: false)
Enter the current production capacity, if applicable.

### 4. **Production Capacity Value** (`production_capacity_value`, `text`, required: false)
Enter a description or notes on production capacity, if applicable.

### 5. **Inspection Item** (`inspection_item`, `text`, required: false)
Enter a description or notes on the inspection item, if applicable.

### 6. **Inspection Item Value** (`inspection_item_value`, `text`, required: false)
Enter a description or notes on the inspection item value, if applicable.

### 7. **Inspection Frequency Value** (`inspection_frequency_value`, `text`, required: false)
Enter a description or notes on the inspection frequency value, if applicable.

### 8. **Production Process Description** (`production_process_description`, `note`, required: false)
Enter a detailed description of the production process, if applicable.

### 9. **Critical Control Points** (`critical_control_points`, `select_multiple`, required: false)
Choose the critical control points from the options:
*   Critical Control Points 1
*   Critical Control Points 2

### 10. **Corrective Action** (`corrective_action`, `select_one`, required: false)
Choose the corrective action from the options:
*   Corrective Action 1
*   Corrective Action 2
*   Corrective Action 3

### Tips
*   Be accurate and thorough when filling out the form.
*   If you're unsure about any field, refer to your manufacturing process documentation or consult with a production specialist.
*   This form is not intended to replace your current process documentation or procedures; rather, it's a tool to aid in process improvements and corrective actions.
