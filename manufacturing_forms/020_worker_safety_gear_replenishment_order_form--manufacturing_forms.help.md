# Worker Safety Gear Replenishment Order Form - Help Guide
## Purpose
This form is used to create a new hire order, manage replacement orders, and track damaged equipment for worker safety gear replenishment.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the new hire information, including the new hire ID, name, and any required safety equipment.
2. Indicate if any personal protective equipment (PPE) is needed for the new hire.
3. List any required safety equipment that needs to be replaced or replenished.
4. Identify any damaged equipment that needs to be replaced.
5. Provide the supervisor's name for verification and approval.
6. Specify the workplace where the order will be used (if applicable).
7. Add any comments or notes for the order (optional).
8. Enter the worker's email address and phone number (if applicable).
9. Select 'Submit' to send the order for processing.

## Field-by-Field Explanation

* **New Hire Order**: Please enter the order for a new hire, including a unique ID number.
	+ Required: Yes
	+ Type: Text
* **New Hire ID**: Please enter the ID number for the new hire.
	+ Required: Yes
	+ Type: Number
* **New Hire Name**: Enter the name of the new hire.
	+ Required: Yes
	+ Type: Text
* **PPE Needed**: Indicate if any PPE is required for the new hire.
	+ Required: Yes
	+ Type: Select one option (Yes, No)
* **Safety Equipment Needed**: Select any required safety equipment for the new hire.
	+ Required: Yes
	+ Type: Select multiple options (Yes, No)
* **Replacement Order**: Enter the reason for the replacement order.
	+ Required: Yes
	+ Type: Text
* **Replacement ID**: Enter the ID number for the replacement order.
	+ Required: Yes
	+ Type: Number
* **Replacement Name**: Enter the name of the item being replaced.
	+ Required: Yes
	+ Type: Text
* **Replacement Equipment**: Select any equipment to be replaced.
	+ Required: Yes
	+ Type: Select multiple options (Yes, No)
* **Damaged Equipment**: Indicate if any equipment has been damaged.
	+ Required: Yes
	+ Type: Select multiple options (Yes, No)
* **Supervisor Name**: Enter the supervisor's name for verification.
	+ Required: Yes
	+ Type: Text
* **Worksits**: Specify if the order will be used at a worksite.
	+ Required: Yes
	+ Type: Select one option (Yes, No)
* **Order Comments**: Add any comments or notes for the order (optional).
	+ Required: No
	+ Type: Note
* **Email**: Enter the worker's email address (if applicable).
	+ Required: No
	+ Type: Email
* **Phone**: Enter the worker's phone number (if applicable).
	+ Required: No
	+ Type: Text
* **Submit**: Select to send the order for processing.
	+ Required: Yes
	+ Type: Select one option (Yes, No)

## Tips
* Double-check the information entered to ensure accuracy.
* Make sure to follow the proper procedures for new hire and replacement orders.
* If you are unsure about any information, please contact the supervisor or the relevant department for assistance.
