# Digital Manufacturing Efficiency Report Form - Help Guide
## Purpose
This form is designed to collect data on the efficiency of manufacturing processes, including production shifts, machines, operators, and products. It helps to gather information on production metrics such as efficiency, production rates, and quality control.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the production shift from the options provided.
2. Enter the machine ID, if applicable.
3. Enter the operator ID, if applicable.
4. Select the product type(s) produced.
5. Enter the production date.
6. Enter the production time, if applicable.
7. Enter the efficiency percentage, if applicable.
8. Provide any additional notes, if necessary.
9. Enter your email and phone number for contact purposes.
10. Select the production rate from the options provided.
11. Select the comments, if applicable.
12. Enter the total parts produced.
13. Select the defective parts produced.
14. Check if quality control checks were performed.
15. Enter the production time elapsed.
16. Select the production line(s).
17. Enter the product ID.
18. Select the shift ID.
19. Enter the operator ID.
20. Select the production product type ID.
21. Enter the production production date.
22. Enter the production production time.
23. Enter the production efficiency percentage.
24. Provide any additional production notes.

## Field-by-Field Explanation
* **Production Shift** (`production_shift`, select_one): Select the production shift that occurred during the production process.
* **Machine ID** (`machine_id`, number): Enter the ID of the machine used during production, if applicable.
* **Operator ID** (`operator_id`, number): Enter the ID of the operator responsible for the production process, if applicable.
* **Product Type** (`product_type`, select_multiple): Select the type of product(s) produced during the production process.
* **Production Date** (`production_date`, date): Enter the date on which the production occurred.
* **Production Time** (`production_time`, time): Enter the time at which the production occurred, if applicable.
* **Efficiency Percentage** (`efficiency_percentage`, number): Enter the efficiency percentage achieved during the production process, if applicable.
* **Notes** (`notes`, note): Provide any additional notes or comments about the production process, if necessary.
* **Email** (`email`, email): Enter your email address for contact purposes.
* **Phone** (`phone`, text): Enter your phone number for contact purposes.
* **Production Rate** (`production_rate`, select_one): Select the production rate achieved during the production process.
* **Comments** (`comments`, select_multiple): Select any comments or issues that occurred during the production process, if applicable.
* **Total Parts Produced** (`total_parts_produced`, number): Enter the total number of parts produced during the production process.
* **Defective Parts Produced** (`defective_parts_produced`, select_one): Select the number of defective parts produced during the production process.
* **Quality Control Check** (`quality_control_check`, select_one): Check if quality control checks were performed during the production process.
* **Production Time Elapsed** (`production_time_elapsed`, time): Enter the time elapsed during the production process, if applicable.
* **Production Line** (`production_line`, select_multiple): Select the production line(s) involved in the production process.
* **Product ID** (`product_id`, number): Enter the ID of the product produced during the production process.
* **Shift** (`production_shift_id`, number): Enter the ID of the shift during which the production occurred.
* **Operator** (`production_operator_id`, number): Enter the ID of the operator responsible for the production process.
* **Production Product Type Id** (`production_product_type_id`, select_multiple): Select the type of product ID produced during the production process.
* **Production Production Date** (`production_production_date`, date): Enter the date on which the production occurred.
* **Production Production Time** (`production_production_time`, time): Enter the time at which the production occurred.
* **Production Efficiency Percentage** (`production_efficiency_percentage`, number): Enter the efficiency percentage achieved during the production process, if applicable.
* **Production Notes** (`production_notes`, note): Provide any additional production notes or comments, if necessary.
