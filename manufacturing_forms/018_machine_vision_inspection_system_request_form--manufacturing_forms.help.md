# Machine Vision Inspection System Request Form - Help Guide
## Purpose
This form is used to request the use of the Machine Vision Inspection System. It is intended to collect information about new projects that require access to this system. Please use this form to provide accurate and comprehensive details about your project.

## How To Complete This Form
Before starting to fill out this form, please make sure you have all the necessary information required to complete the form. Here's a step-by-step guide:
1. Start by filling out the `machine_vision_inspection_system_request_form` form title with a brief and descriptive title of your request.
2. Select the type of project you are requesting, such as Machine Vision Inspection, Automated Vision Inspection, or Vision Inspection.
3. Enter a name for your project if it has one.
4. If your project has a start date, enter it in the `start_date` field.
5. If your project has a duration, enter it in the `project_duration` field.
6. If your project has a budget, enter it in the `project_budget` field.
7. Choose the status of your project, selecting all that apply from Active, Inactive, or both.
8. Describe your project in the `form_description` field.
9. If assigned to a user, enter their name in the `assigned_user` field.
10. If assigned to a form, enter the ID number of that form.
11. (Note: `created_date` and `updated_date` fields are auto-populated by the system)

## Field-by-Field Explanation
- **Machine Vision Inspection System Request Form** (Page 1, `machine_vision_inspection_system_request_form`): Enter a brief and descriptive title of your request.
- **Project Type** (Page 2, `project_type`): Select the type of project you are requesting, such as Machine Vision Inspection, Automated Vision Inspection, or Vision Inspection.
- **Project Name** (Page 2, `project_name`): Enter a name for your project if it has one.
- **Start Date** (Page 3, `project_start_date`): Enter the start date of your project if it has one.
- **Project Duration** (Page 3, `project_duration`): Enter the duration of your project if it has one.
- **Project Budget** (Page 3, `project_budget`): Enter the budget of your project if it has one.
- **Project Status** (Page 4, `project_status`): Choose the status of your project, selecting all that apply from Active, Inactive, or both.
- **Form Description** (Page 4, `form_description`): Describe your project in this field, providing as much detail as possible.
- **Assigned User** (Page 4, `assigned_user`): If assigned to a user, enter their name in this field.
- **Form ID** (Page 5, `form_id`): If assigned to a form, enter the ID number of that form.
- **Created Date** (Page 5, `created_date`): This field is auto-populated by the system and should not be edited.
- **Updated Date** (Page 5, `updated_date`): This field is auto-populated by the system and should not be edited.
