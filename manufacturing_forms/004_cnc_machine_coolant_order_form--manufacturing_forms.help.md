# CNC Machine Coolant Order Form - Help Guide

## Purpose
The CNC Machine Coolant Order Form is a document used to request and track the ordering of coolants for CNC machines. It ensures that all necessary information is captured and communicated to the procurement team for order fulfillment.

## How To Complete This Form
To fill out the form, please follow these steps:

1.  Enter your name and title to indicate who is submitting the request.
2.  Select the department responsible for the CNC machine, such as Manufacturing, Production, Maintenance, Quality Control, Operations, or Other.
3.  Enter the order date for the requested coolant.
4.  Enter the required delivery date for the coolant.
5.  Choose the type of coolant needed, such as Oil-based, Water-soluble, Synthetic, Semi-synthetic, Straight oil, or Other.
6.  Specify the quantity of coolant required in liters.
7.  Choose the preferred container size for the ordered coolant, such as 5 liters, 10 liters, 20 liters, 50 liters, 200 liters, or 1000 liters.
8.  List the CNC machine models that will be using the ordered coolant.
9.  Enter the current coolant supplier, if applicable.
10.  Enter the cost center code for the machine(s) that will be using the coolant.
11.  Confirm that budget approval has been received.
12.  Enter any special requirements or notes for the order.
13.  Specify how the previous coolant was disposed of, if applicable.
14.  Enter the name of the manager who approved the order.
15.  Enter your contact phone number for follow-up.

## Field-by-Field Explanation

*   **Requester Name** (`requester_name`, text, required): Enter your name and title to indicate who is submitting the request.
*   **Department** (`department`, select_one, required): Select the department responsible for the CNC machine, such as Manufacturing, Production, Maintenance, Quality Control, Operations, or Other.
*   **Order Date** (`order_date`, date, required): Enter the order date for the requested coolant.
*   **Required Delivery Date** (`required_delivery_date`, date, required): Enter the required delivery date for the coolant.
*   **Coolant Type** (`coolant_type`, select_one, required): Choose the type of coolant needed, such as Oil-based, Water-soluble, Synthetic, Semi-synthetic, Straight oil, or Other.
*   **Coolant Viscosity Grade** (`coolant_viscosity`, text, optional): This field is optional, but if you have specific requirements for the viscosity grade, please enter them here.
*   **Quantity Needed (liters)** (`quantity_liters`, number, required): Specify the quantity of coolant required in liters.
*   **Container Size Preference** (`container_size`, select_one, required): Choose the preferred container size for the ordered coolant, such as 5 liters, 10 liters, 20 liters, 50 liters, 200 liters, or 1000 liters.
*   **CNC Machine Model(s)** (`machine_model`, text, optional): List the CNC machine models that will be using the ordered coolant, if applicable.
*   **Current Coolant Supplier** (`current_coolant_supplier`, text, optional): Enter the current coolant supplier, if applicable.
*   **Cost Center Code** (`cost_center`, text, required): Enter the cost center code for the machine(s) that will be using the coolant.
*   **Budget approval received** (`budget_approval`, select_one, required): Confirm that budget approval has been received, such as 'Yes', 'No', or 'Pending'.
*   **Special Requirements or Notes** (`special_requirements`, text, optional): Enter any special requirements or notes for the order, if applicable.
*   **Previous Coolant Disposal Method** (`disposal_considerations`, select_one, optional): Specify how the previous coolant was disposed of, if applicable, such as Recycling program, Waste management company, On-site storage, or Other.
*   **Manager Approval Name** (`approval_manager`, text, required): Enter the name of the manager who approved the order.
*   **Contact Phone Number** (`contact_phone`, text, required): Enter your contact phone number for follow-up.
