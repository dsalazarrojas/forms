# Factory Waste Segregation Report Request Form - Help Guide
## Purpose
The Factory Waste Segregation Report Request Form is used to collect information about waste segregation in the factory. It helps identify areas where waste is not being properly segregated, and what can be done to improve waste management.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" from the "User Information" field to indicate if you are the person submitting the report.
2. Enter the factory's information in the "Factory Information" field.
3. If necessary, provide additional information about the report in the "Report Information" field.
4. Indicate if the factory is segregating waste properly by selecting "Yes" or "No" in the "Factory Waste Segregation" field.
5. Select "Yes" or "No" from the "Report Type" field to indicate the type of report.
6. Enter your full name and email address in the "Full Name" and "Email" fields.
7. Enter the factory's waste code in the "Factory Waste Code" field.
8. Select "Yes" or "No" from the "Department" field to indicate which department is responsible for the waste segregation.
9. Enter the name of the supervisor responsible for the area where the waste is not being properly segregated.
10. Enter the date you submitted the report in the "Date Submitted" field.
11. Enter the date the report was requested in the "Date Requested" field.
12. Enter any additional comments or notes about the situation in the "Notes" field.

* **Factory Waste Segregation** (`select_one`, required: false): Select "Yes" or "No" to indicate if the factory is segregating waste properly.
