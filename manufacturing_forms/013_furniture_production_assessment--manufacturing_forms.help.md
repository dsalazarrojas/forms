# Furniture Production Assessment - Help Guide
## Purpose
The Furniture Production Assessment form is used to collect and record information about specific production projects in the manufacturing process. It is used to gather data on project details, production benefits, and quality control.

## How To Complete This Form
To complete this form, follow the instructions above.

## Field-by-Field Explanation
* **Production Project** (`production_project`, text, optional): Enter the name or code of the production project.
* **Project Type** (`project_type`, select_one, optional): Select the type of project, which can be either "Wooden Furniture" or "Metal Furniture".
* **Production Benefits** (`production_benefits`, select_multiple, optional): Check any applicable production benefits that have been realized, such as "Improved Quality", "Reduced Labor Costs", or "Enhanced Safety".
* **Production Location** (`production_location`, number, optional): Enter the production location, which is a numerical value representing the facility or plant number.
* **Production Date** (`production_date`, date, optional): Enter the production date in the format of "YYYY-MM-DD".
* **Production Shift** (`production_shift`, time, optional): Select the production shift from the format "HH:MM".
* **Production Notes** (`production_notes`, note, optional): Optionally, provide additional production notes, if needed.
* **Inspector Name** (`inspector_name`, text, optional): Enter the name of the inspector who conducted the quality control inspection.
