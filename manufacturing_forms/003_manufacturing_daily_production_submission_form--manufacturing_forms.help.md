# Manufacturing Daily Production Submission Form - Help Guide

## Purpose
The purpose of this form is to report the daily production output and defects on the manufacturing floor. It's essential to fill out this form accurately and consistently to support production analysis and improvement efforts.

## How To Complete This Form
1. Click on the "Submit" button to begin filling out the form.
2. Select the correct production shift from the options available.
3. Enter the start and end times for the production shift.
4. Report the total parts made, total parts scrap, total defective parts, total defects, total parts in process, and total parts completed for the shift.
5. Provide details about any defects encountered during the shift, including the cause, location, and description.
6. Verify the information entered before submitting the form.

## Field-by-Field Explanation

- **Production Shift**: Enter the production shift for which you are reporting. This field is required.
- **Start Time**: Enter the start time of the production shift. This field is required. Please use the correct format, e.g., 08:00 or 12:00.
- **End Time**: Enter the end time of the production shift. This field is required. Please use the correct format, e.g., 12:00 or 16:00.
- **Production Output**: Report the total parts produced during the shift. This field is required.
- **Defects**: Report any defects encountered during the shift. This field is optional.
- **Downtime**: Report any downtime experienced during the shift. This field is optional.
- **Production Shift ID**: Enter the production shift ID number. This field is required.
- **Line ID**: Enter the production line ID number. This field is required.
- **Defect Cause**: Report the cause of any defects encountered during the shift. This field is required.
- **Defect Location**: Report the location where defects were found. This field is required.
- **Defect Description**: Provide a detailed description of any defects. This field is required.
- **Total Parts Made**: Report the total number of parts produced during the shift. This field is optional.
- **Total Parts Scrap**: Report the total number of parts scrap during the shift. This field is required.
- **Total Defective Parts**: Report the total number of defective parts. This field is optional.
- **Total Defects**: Report the total number of defects encountered during the shift. This field is optional.
- **Total Parts In Process**: Report the total number of parts still in process at the end of the shift. This field is optional.
- **Total Parts Completed**: Report the total number of parts completed during the shift. This field is optional.
