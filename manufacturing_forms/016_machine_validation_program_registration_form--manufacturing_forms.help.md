# Machine Validation Program Registration Form - Help Guide
## Purpose
The Machine Validation Program Registration Form is designed to collect information from machine validation programs registered with the program. It serves as a comprehensive guide to provide the necessary details about the program, its features, and the contact information of the person or organization responsible for it.

## How To Complete This Form
To complete the form, follow these steps:

1. Start with the "Registration Information" page (Page 1) and fill out the required fields.
2. Proceed to the "Additional Information" page (Page 2) and provide any additional details about the program.
3. Move on to the "Contact Information" page (Page 3) and fill out the required fields.
4. Continue to the "Machine Details" page (Page 4) and provide the necessary information about the machine.
5. The next page will ask you to "Submit" your application.
6. After submission, you will be able to review your submission on the "Review Submission" page (Page 7).
7. Once you have reviewed your submission, click "Submit Confirmation" on the "Submission Confirmation" page (Page 8) to finalize your submission.
8. Finally, you will be directed to the "Submission Complete" page (Page 9) to acknowledge that you have completed the form.

## Field-by-Field Explanation
- **Name** (`Registration Information`, `title`, required): This field requires the name of the machine validation program.
- **Description** (`Registration Information`, `description`, required): Describe the machine validation program in a brief manner.
- **Type** (`Registration Information`, `type`, required): Select the type of machine validation program you are registering.
- **Industry** (`Registration Information`, `industry`, required): Choose the industry related to the machine validation program.
- **Features** (`Additional Information`, `features`, optional): List any notable features of the machine validation program.
- **Contact Person** (`Contact Information`, `name`, required): Enter the name of the contact person.
- **Email Address** (`Contact Information`, `email`, required): Enter the email address of the contact person.
- **Phone Number** (`Contact Information`, `phone`, required): Enter the phone number of the contact person.
- **Machine Type** (`Machine Details`, `machine_type`, required): Specify the type of machine related to the machine validation program.
- **Machine Model** (`Machine Details`, `machine_model`, required): Enter the machine model number.
- **Upload Attachments** (`Upload Attachments`, `file`, optional): Attach any supporting documents or files related to the machine validation program.
- **Review Submission** (`Review Submission`, `review`, required): Review your submission on this page.
- **Confirm Submission** (`Submission Confirmation`, `confirm`, required): Confirm that you have submitted the form correctly.
- **Complete Submission** (`Submission Complete`, `complete`, required): Acknowledge that you have completed the form successfully.

Note: The page numbers mentioned above refer to the page ID in the provided YAML schema.
