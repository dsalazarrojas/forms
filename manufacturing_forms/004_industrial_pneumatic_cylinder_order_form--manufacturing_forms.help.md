# industrial_pneumatic_cylinder_order_form - Help Guide
## Purpose
The industrial_pneumatic_cylinder_order_form is used for ordering industrial pneumatic cylinders. This form collects relevant details about the customer, order, and product specifications.

## How To Complete This Form
To complete this form, please follow these steps:

1. Begin by providing customer information on page 1.
2. Move on to page 2 for order details.
3. On page 3, enter the quantity of the product.
4. On page 4, specify the pressure rating of the product.
5. Move on to page 5 for the description of the product.
6. Select the type of cylinder from page 6.
7. On page 8, enter any additional quantity details if required.
8. Select the order status on page 9.
9. Enter contact information on page 10.
10. Finally, on page 11, enter the order date.
11. If necessary, add the name of the customer on page 12.

## Field-by-Field Explanation
### 1. Customer Information (Customer Info Page, Page 1)
* **Customer Name**: Enter the name of the customer.
* **Customer Contact Information**: Enter any relevant contact details of the customer.

### 2. Order Details (Order Details Page, Page 2)
* This is where you can add any additional details about the order.

### 3. Quantity (Quantity Page, Page 3)
* **Quantity**: Enter the quantity of the product ordered.

### 4. Pressure Rating (Pressure Page, Page 4)
* **Pressure Rating**: Enter the pressure rating of the product.

### 5. Description (Description Page, Page 5)
* **Description**: Enter a description of the product ordered.

### 6. Cylinder Type (Cylinder Type Page, Page 6)
* **Cylinder Type**: Select the type of cylinder from the options available.

### 7. Quantity2 Page (Quantity2 Page, Page 7)
* **Quantity2**: This field is likely for any additional quantity details, such as variations or special requests.

### 8. Address (Address Page, Page 8)
* **Address**: Enter the address where the order is to be delivered or processed.

### 9. Order Status (Order Status Page, Page 9)
* **Order Status**: Select the current status of the order from the options provided.

### 10. Contact Information (Contact Information Page, Page 10)
* **Contact Information**: Enter any relevant contact information for the customer.

### 11. Order Date (Order Date Page, Page 11)
* **Order Date**: Enter the date of the order.

### 12. Name (Name Page, Page 12)
* **Name**: Enter the name of the person associated with the order, if required.
