# Ethanol Production Process Survey - Help Guide
## Purpose
This form collects information on the production process of ethanol, which includes details on production capacity, operational hours, and production shifts. The gathered data will help in understanding the ethanol production process better.

## How To Complete This Form
To complete this form, follow these steps:
- Select the relevant options for each field based on your production data.
- Enter numerical values where required for production capacity, operational hours, and batch size.
- Choose the correct options for personnel on site and production shifts.
- Ensure that all required fields (marked as 'Yes' and 'No' for select_one and select_multiple fields) are filled correctly.

## Field-by-Field Explanation
### 1. Production Plant (select_one)
* **Production Plant**: This field is used to indicate whether the production plant is operational or not.
  + Options: 'Yes', 'No'

### 2. Production Type (select_one)
* **Production Type**: This field is used to indicate the type of production (likely referring to the type of ethanol produced or a similar concept).
  + Options: 'Yes', 'No'

### 3. Equipment Type (select_multiple)
* **Equipment Type**: This field is used to select multiple types of equipment used in the production process.
  + Options: 'Yes', 'No'

### 4. Ethanol Produced (number)
* **Ethanol Produced**: Enter the total amount of ethanol produced in gallons.

### 5. Production Capacity (number)
* **Production Capacity**: Enter the total production capacity of the plant in gallons.

### 6. Operational Hours (time)
* **Operational Hours**: This field is used to input the hours of operation for the production plant.

### 7. Operational Days (number)
* **Operational Days**: Enter the number of days the production plant operates.

### 8. Batch Size (number)
* **Batch Size**: Enter the size of each batch produced in the production process.

### 9. Production Shift (select_one)
* **Production Shift**: This field is used to indicate whether the production plant operates on shifts or not.
  + Options: 'Yes', 'No'

### 10. Production Shift Start Time (time)
* **Production Shift Start Time**: If production shifts are used, enter the start time of each shift.

### 11. Production Shift End Time (time)
* **Production Shift End Time**: If production shifts are used, enter the end time of each shift.

### 12. Personnel on Site (select_multiple)
* **Personnel on Site**: This field is used to select multiple categories of personnel present on site during production.
  + Options: 'Yes', 'No'
