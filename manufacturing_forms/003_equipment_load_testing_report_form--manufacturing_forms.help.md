# Equipment Load Testing Report Form - Help Guide
## Purpose
The Equipment Load Testing Report Form is used to document the results of a load testing event on a piece of equipment. This form helps to ensure that all relevant information about the test is recorded accurately and consistently.

## How To Complete This Form
1. Fill in the required fields with the necessary information about the load testing event.
2. Use the provided options for the "test_result" field to indicate the outcome of the test.
3. Ensure that you have completed all the fields before submitting the form.

## Field-by-Field Explanation
* **Equipment Name** (`equipment-name`, `text`, required: false): Enter the name of the equipment being tested.
* **Test Date** (`test-date`, `date`, required: false): Enter the date the test was conducted.
* **Test Time** (`test-time`, `time`, required: false): Enter the time the test was conducted.
* **Test Duration** (`test-duration`, `number`, required: false): Enter the duration of the test (in minutes or hours).
* **Test Location** (`test-location`, `text`, required: false): Enter the location where the test was conducted.
* **Notes** (`notes`, `note`, required: false): Enter any observations or comments made during or after the test.
* **Assigned Tool** (`assigned-tool`, `select_one`, required: false): Select the tool used for the test from the provided options.
* **Test Result** (`test-result`, `select_multiple`, required: false): Select all outcomes that apply from the provided options.
* **Submission Date** (`submission-date`, `date`, required: false): Enter the date the test results were submitted.

## Tips
- Fill out all fields as accurately and thoroughly as possible to ensure a comprehensive record of the load testing event.
- If you are unsure about any field, please do not hesitate to contact the relevant personnel for clarification.
