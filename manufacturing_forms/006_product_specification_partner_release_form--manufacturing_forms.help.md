# Product Specification Partner Release Form - Help Guide

## Purpose
The purpose of this form is to collect information about the product specification, partner names, release date, and other relevant details for managing the release of products to partners in the manufacturing process.

## How To Complete This Form

1.  Enter a brief title for this release.
2.  Provide a brief description of this release.
3.  Select whether this release is intended for internal use or not.
4.  Enter the names of all partners involved in this release.
5.  Select the release date and time for this product.
6.  Upload any additional files or documentation related to this release.
7.  Enter the contact email address of the partner or person responsible for this release.
8.  Enter the contact phone number of the partner or person responsible for this release.
9.  Enter the address of the partner or person responsible for this release.
10. Enter any additional notes related to this release.
11. Enter the name and title of the person reviewing this release.
12. Enter the date and time the release was reviewed.
13. Enter any notes from the review process.
14. Select whether this release has been approved or rejected.
15. Enter the name of the person who approved or rejected this release.
16. Enter the date and time of the approval or rejection.
17. Enter any notes from the approval or rejection process.
18. Select whether this product is released or not.
19. Enter the name of the person who released this product.
20. Enter the date and time of the release.
21. Enter any notes from the release process.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a brief title for this release.
* **Form Description** (`form_description`, text, optional): Provide a brief description of this release.
* **Form Category** (`form_category`, select_one, optional):
	+ If this release is intended for internal use, select 'Yes'. If not, select 'No'. 
* **Partner Names** (`form_specification_partners`, text, required): Enter the names of all partners involved in this release.
* **Category Options** (`form_specification_category_options`, text, optional): Select the category options for this release.
* **Product Title** (`form_specification_title`, text, required): Enter the title of the product being released.
* **Product Description** (`form_specification_description`, text, optional): Enter the description of the product being released.
* **Release Date** (`form_specification_date`, date, required): Select the release date for this product.
