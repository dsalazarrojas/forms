# Factory LED Display Board Order Form - Help Guide
## Purpose
This form is designed to help us understand your requirements for a custom Factory LED Display Board. Please take a few minutes to fill out this form, and we will get back to you with a quote and any further questions we may have.

## How To Complete This Form
To complete this form, please fill out the following fields:

* Please make sure to provide accurate and up-to-date information to ensure a smooth ordering process.
* If you need to add any additional comments or information not covered by this form, please use the "Additional Comments" section at the end of the form.

## Field-by-Field Explanation
* **Customer Name (`customer_name`, Text, Optional):**
	+ This field is where you can enter your name, which will be used to address our communication with you.
* **Customer Email (`customer_email`, Email, Optional):**
	+ This is your email address where we will send you any follow-up questions or quotes.
* **Customer Phone (`customer_phone`, Text, Optional):**
	+ This is your phone number where we can contact you if needed.

## Tips
* Please make sure to fill out all required fields (although they are not marked as "required" in this form, we still need all the information provided to ensure accurate quoting and delivery).
* If you need to add any additional comments or information not covered by this form, please use the "Additional Comments" section.
* If you are unsure about any of the fields, please don't hesitate to ask us for clarification.
