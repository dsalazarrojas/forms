# Factory Asset Tag Supply Order Form - Help Guide

## Purpose
The Factory Asset Tag Supply Order Form is used to track and verify the stock of factory assets. This form helps in identifying which factory assets are available and which ones need to be replenished. It ensures that the correct quantities and types of assets are ordered to maintain inventory balance.

## How To Complete This Form
1. Select the correct answer to the first question on the form, which is a simple "yes" or "no" question about whether you need to place an order.
2. If you choose "yes", proceed to the second question where you will enter the specific asset type or description in the text field.
3. Enter the required information in the text field, describing the type or quantity of the asset you need to order.
4. If you need to specify a time constraint for the order, enter the date and time in the time field on the third question.

## Field-by-Field Explanation

* **form_1** (Select One, Required): This question determines whether you need to place an order. Select "yes" if you need to order assets.
* **form_2** (Text, Optional): Enter a brief description of the asset type or quantity you need to order. This will help the supply team understand what to order.
* **form_3** (Time, Optional): If you have a specific time constraint for the order, enter it here. This could be a deadline for the order to be fulfilled or a time frame when the assets are needed.

## Tips
* Make sure to clearly describe the asset type or quantity you need to ensure accurate ordering.
* Enter specific dates and times for any orders that have time-sensitive requirements.
* If you select "no" on the first question, you will not be able to proceed with the order, but you can always reach out to the supply team for further assistance.
