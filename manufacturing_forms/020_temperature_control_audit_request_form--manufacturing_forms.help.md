# Temperature Control Audit Request Form - Help Guide
## Purpose
The Temperature Control Audit Request Form is used to collect information related to the temperature control of a manufacturing process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select "Yes" or "No" for each question to indicate whether the specified temperature control measures are in place within your facility or process.
2. Fill in the numbers for the critical temperature limits if they are applicable.
3. Select the acceptable temperature range if it is applicable.
4. Enter the inspection frequency if it is applicable.
5. Enter the temperature control inspection interval if it is applicable.
6. Add any additional comments about the temperature control measures in place.
