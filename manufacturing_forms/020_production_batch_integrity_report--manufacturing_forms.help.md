# Production Batch Integrity Report - Help Guide
## Purpose
The Production Batch Integrity Report is a form used to collect and document information about the integrity of a production batch.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct batch from the options provided.
2. Fill in the batch details section with the relevant information.
3. Select the inspection results for the batch.
4. If any issues were encountered during production, describe them in the issues section.
5. Choose the corrective actions taken to address any issues.
6. Select the batch status.
7. Enter the production date and time for the batch.
8. Enter the production location for the batch.
9. Select the production shift.
10. Choose the quality inspector who reviewed the batch.
11. Select the production manager who oversaw the batch.
12. Enter any additional comments about the batch integrity.
13. Rate the production batch integrity using the provided scale.

## Field-by-Field Explanation
* **Batch Details** (`batch_details`): Enter the batch details such as batch ID, production number, or any other relevant information.
* **Inspection Results** (`inspection_results`): Select the inspection results that apply to the batch. You can choose multiple options.
* **Issues** (`issues`): If any issues were encountered during production, describe them in this section.
* **Corrective Actions** (`corrective_actions`): Choose the corrective actions taken to address any issues.
* **Batch Status** (`batch_status`): Select the status of the batch.
* **Production Date** (`production_date`): Enter the production date for the batch.
* **Production Time** (`production_time`): Enter the production time for the batch.
* **Production Location** (`production_location`): Enter the production location for the batch.
* **Production Shift** (`production_shift`): Select the production shift.
* **Quality Inspector** (`quality_inspector`): Choose the quality inspector who reviewed the batch.
* **Production Manager** (`production_manager`): Choose the production manager who oversaw the batch.
* **Batch Integrity Comment** (`batch_integrity_comment`): Enter any additional comments about the batch integrity.
* **Production Batch Integrity Rating** (`production_batch_integrity_rating`): Rate the production batch integrity using the provided scale.
