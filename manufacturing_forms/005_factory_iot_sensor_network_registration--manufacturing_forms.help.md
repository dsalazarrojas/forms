# Factory IoT Sensor Network Registration - Help Guide

## Purpose
The "Factory IoT Sensor Network Registration" form is used to collect information about the locations of IoT sensors within a factory. This form helps to track and manage the deployment and status of these sensors, ensuring that they are properly assigned and maintained. It is essential to fill out this form accurately to ensure that your factory's IoT sensor network is up-to-date and running smoothly.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Locations" tab to start entering information about the locations of your IoT sensors.
2. Enter the "Network Identifier" to uniquely identify your factory's IoT network.
3. Choose whether you want to deploy or not deploy a sensor.
4. Enter the "Sensor Deployment Date" if applicable.
5. Enter the "Installation Date" for each sensor.
6. Select the current status of each sensor (Active or Inactive).
7. Add any additional "Sensor Notes" regarding the sensor's status or issues.
8. If applicable, choose whether a technician is assigned to each sensor (Yes or No).
9. Enter the "Assigned Tool" for the technician, if applicable.
10. Enter the "Location" of each sensor.
11. Add any additional "Notes" regarding the sensor's status or issues.

## Field-by-Field Explanation
### Locations
* **Locations**: Enter a descriptive title for this form submission, ideally including the floor/zone number and location name (e.g., "Floor 3, Zone A").

### Network Identifier
* **Network Identifier**: Enter a unique identifier for your factory's IoT network.

### Sensor Type
* **Sensor Type**: Choose whether you want to deploy a sensor (Yes) or not (No).

### Sensor Deployment Date
* **Sensor Deployment Date**: Enter the date the sensor was deployed if it was deployed.

### Installation Date
* **Installation Date**: Enter the date the sensor was installed.

### Sensor Status
* **Sensor Status**: Select the status of the sensor (Active or Inactive).

### Sensor Notes
* **Sensor Notes**: Enter any additional comments about the sensor, such as its functionality or any issues.

### Assigned Technician
* **Assigned Technician**: Choose whether a technician is assigned to this sensor (Yes or No).

### Assigned Tool
* **Assigned Tool**: Enter the tool assigned to the technician, if applicable.

### Location
* **Location**: Enter the specific location of the sensor, such as a building number or room.

### Notes
* **Notes**: Add any additional comments about the sensor, such as its functionality or any issues.

## Tips
* Please ensure that you fill out each field accurately to ensure that your factory's IoT sensor network is up-to-date and running smoothly.
* If you're unsure about any of the fields, refer to your factory's IoT sensor network documentation for more information.
