# daily_work_report - Help Guide
## Purpose
The daily work report is a form used by employees to report their working hours, breaks, and work activities during the shift. It is a tool for management to track and analyze employee work patterns.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your employee name in the "Employee Name" field.
2. Select the start and end times of your work shift using the "Work Start Time" and "Work End Time" fields, respectively.
3. Briefly describe your work activities in the "Work Description" field.
4. If you take breaks during the shift, select all applicable options in the "Breaks Taken" field.
5. If you take breaks, also indicate the start and end times of your breaks using the "Break Start Time" and "Break End Time" fields, respectively.

## Field-by-Field Explanation
* **Employee Name** (`employee_name`, text, required): Enter your name as it appears on your employee ID or payroll record.
* **Work Start Time** (`work_start_time`, time, required): Select the time you started your work shift.
* **Work End Time** (`work_end_time`, time, required): Select the time you ended your work shift.
* **Work Description** (`work_description`, text, optional): Briefly describe your work activities during the shift.
* **Break Start Time** (`break_start_time`, time, optional): If you take a break, select the start time of your break.
* **Break End Time** (`break_end_time`, time, optional): If you take a break, select the end time of your break.
* **Breaks Taken** (`breaks_taken`, select multiple, optional): Select all types of breaks you took during the shift (e.g., Morning Break, Lunch Break, Afternoon Break, Other).

## Tips
* Make sure to fill in all required fields (Employee Name, Work Start Time, Work End Time).
* Use the "Work Description" field to provide a brief summary of your work activities.
* If you take breaks, fill in the corresponding fields for break start and end times.
* Select all applicable breaks taken in the "Breaks Taken" field.
* Be concise in your answers and avoid repeating information already provided in other fields.
