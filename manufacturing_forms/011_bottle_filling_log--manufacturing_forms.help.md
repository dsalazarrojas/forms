# Bottle Filling Log - Help Guide
## Purpose
The Bottle Filling Log form is used to record and track the bottle filling process, capturing various parameters such as date, time, equipment status, and quality control data.

## How To Complete This Form

1. Ensure you have all necessary information and equipment ready before starting the filling process.
2. Select the correct shift, operator, and production line from the respective dropdown menus.
3. Enter the date and batch number for the filling operation.
4. Enter the product name and code, and select the bottle type.
5. Record the start and end times for the filling process.
6. Enter the target fill volume and number of bottles started and completed.
7. Record the number of bottles rejected and the primary rejection reason.
8. Check the fill accuracy and quality control status.
9. Report any equipment status and downtime minutes (if applicable).
10. Provide additional notes and comments (if necessary).
11. Get supervisor approval for the completed log entry.

## Field-by-Field Explanation

* **Log Date**: Enter the date of the filling operation.
* **Shift**: Select the shift during which the filling took place.
* **Operator Name**: Enter the name of the machine operator performing the filling.
* **Operator ID**: Enter the employee identification number of the machine operator.
* **Production Line**: Select the production line on which the filling took place.
* **Batch Number**: Enter the unique batch identifier for the filled bottles.
* **Product Name**: Enter the name of the product being filled.
* **Product Code**: Enter the product identification code or SKU.
* **Bottle Type**: Select the type and size of bottles used.
* **Fill Start Time**: Record the time filling began.
* **Fill End Time**: Record the time filling completed.
* **Target Fill Volume**: Enter the target volume per bottle in milliliters.
* **Number of Bottles Started**: Enter the total number of bottles entering the filling line.
* **Number of Bottles Completed**: Enter the total number of bottles successfully filled.
* **Number of Bottles Rejected**: Enter the number of bottles rejected during quality check.
* **Primary Rejection Reason**: Select the main reason for bottle rejection.
* **Fill Accuracy Check**: Check if the fill volume was within tolerance.
* **Equipment Status**: Report the condition of the filling equipment.
* **Downtime Minutes**: Record the total unplanned downtime.
* **Quality Control Status**: Report the quality control status (Passed, Failed, or Pending review).
* **QC Inspector Name**: Enter the name of the quality control inspector.
* **Cleaning Performed**: Report if the equipment was cleaned after the run.
* **Additional Notes**: Provide any observations or comments.
* **Supervisor Approval**: Enter the supervisor's name for approval.
