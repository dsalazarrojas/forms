# Factory Operations Support Contact Form - Help Guide
## Purpose
The Factory Operations Support Contact Form is used to report issues or concerns related to factory operations, including machineries, supplies, or production.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your company name in the "Company Name" field.
2. Provide your email address in the "Email" field.
3. Enter your phone number in the "Phone" field.
4. Describe the issue in the "Issue Description" field.
5. Select the category of the issue from the "Category" field.
6. If applicable, select the type of issue from the "Issue Type" field.
7. If you have an attachment related to the issue, upload it in the "Attachment" field.
8. Fill in the "First Name", "Last Name", and "Factory Location" fields with your relevant information.
9. Select the "Shift" and "Date" fields, if applicable.
10. Optionally, provide more details about the issue in the "Issue Description 2", "Issue Description 3", "Issue Description 4", "Issue Description 5", "Issue Description 6", "Issue Description 7", "Issue Description 8", "Issue Description 9", and "Issue Description 10" fields.
11. Click the "Submit" button to send the form.

## Field-by-Field Explanation

* **Company Name (`company_name`, required):** Enter the name of your company.
* **Email (`email`, required):** Enter your email address.
* **Phone (`phone`, required):** Enter your phone number.
* **Issue Description (`issue_description`, required):** Describe the issue you are experiencing.
* **Category (`category`, required):** Select the category of the issue (issue with machineries, issue with supplies, or issue with production).
* **Issue Type (`issue_type`, required):** If applicable, select the type of issue (Mechanical, Quality, or Maintenance).
* **Attachment (`attachment`, optional):** If you have a file related to the issue, upload it here.
* **First Name (`first_name`, required):** Enter your first name.
* **Last Name (`last_name`, required):** Enter your last name.
* **Factory Location (`factory_location`, required):** Enter the location of the factory where the issue is occurring.
* **Shift (`shift`, optional):** Select your shift if you are reporting the issue during your shift.
* **Date (`date`, required):** Select the date the issue is occurring or has occurred.
* **Issue Description 2-12 (`issue_description2`, `issue_description3`, `issue_description4`, `issue_description5`, `issue_description6`, `issue_description7`, `issue_description8`, `issue_description9`, `issue_description10`, `issue_description11`, `issue_description12`, optional):** Provide more details about the issue if necessary.
* **Submit (`submit`, optional):** Click the "Submit" button to send the form.
