# Packaging Return Coordination Contact Form - Help Guide
## Purpose
This form is used for packaging return coordination purposes, typically for items that are still under warranty or need to be returned to the supplier for repair or replacement.

## How To Complete This Form

1. Choose whether you want to be contacted about the return.
2. Provide details about the return.
3. Choose whether you want to be contacted about the shipping details.
4. Enter your return shipping address.

## Field-by-Field Explanation

* **Packaging Return Contact** (packaging_return_contact_page, select_multiple, optional):
	+ Select "Yes" if you want to be contacted about the return.
	+ Select "No" if you don't want to be contacted.
* **Return Details** (return_details_page, note, optional):
	+ Please provide any additional details about the return.
	+ This field is for you to include any notes or comments about the return.
* **Contact Info** (contact_info_page, select_one, optional):
	+ Select "Yes" if you want to be contacted about the return.
	+ Select "No" if you don't want to be contacted.
* **Shipping Details** (shipping_details_page, select_one, optional):
	+ Select "Yes" if you want to be contacted about the shipping details.
	+ Select "No" if you don't want to be contacted.
* **Return Address** (return_address_page, text, optional):
	+ Enter your return shipping address if you want to be contacted about the shipping details.
	+ Please include your full address, including street address, city, state, and zip code.
