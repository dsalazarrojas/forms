# Spray Batch Production Log - Help Guide
## Purpose
This form is designed to record and track the production details of batches, including production dates, production numbers, production line, and quality inspection status. It helps manufacturing teams monitor and document their work for future reference.

## How To Complete This Form
1. Enter the **Production Date** in the format `YYYY-MM-DD`.
2. Input the **Production Number**, a unique identifier for this batch.
3. Select the **Production Line** from the available options (if any).
4. Enter the **Operator** who performed the production run.
5. Enter the **Supervisor** responsible for the production line.
6. Enter the **Quality Inspector** who inspected the batch.
7. Enter the **Batch ID**, a unique identifier for this batch (if applicable).
8. Select the **Production Status**:
	* **New**: The batch is new and production has not started.
	* **In-Process**: The batch is currently being produced.
	* **Finished**: The batch is complete and production is finished.
	* **Aborted**: The batch production was stopped due to some reason.
9. If the batch was **Aborted**, enter a brief reason for why it was stopped.
10. Add any additional **Comments** about the production run, if necessary.

## Field-by-Field Explanation
* **Production Date**: The date the production run occurred.
	+ Required: No
	+ Type: Date
* **Production Number**: A unique identifier for this batch.
	+ Required: No
	+ Type: Text
* **Production Line**: The production line responsible for this batch.
	+ Required: No
	+ Type: Text
* **Operator**: The person responsible for performing the production run.
	+ Required: No
	+ Type: Text
* **Supervisor**: The person responsible for overseeing the production line.
	+ Required: No
	+ Type: Text
* **Quality Inspector**: The person responsible for inspecting the batch.
	+ Required: No
	+ Type: Text
* **Batch ID**: A unique identifier for this batch (if applicable).
	+ Required: No
	+ Type: Text
* **Production Status**: The current status of the batch.
	+ Required: No
	+ Type: Select One, options: New, In-Process, Finished, Aborted
* **Reason for Aborted**: If the batch was aborted, enter a brief reason for why it was stopped.
	+ Required: No
	+ Type: Text
* **Comments**: Add any additional comments about the production run.
	+ Required: No
	+ Type: Note

## Tips
* Be sure to enter accurate and complete information to ensure accurate tracking and monitoring of production progress.
* If the batch was aborted, include a brief reason to help others understand the reason for stopping production.
* Use this form to document and track production runs, and refer back to it for future production planning and decision-making.
