# Employee Engagement Program Claim Form - Help Guide
## Purpose
The Employee Engagement Program Claim Form is designed to collect information from employees about their participation in the Employee Engagement Program. This form helps to track and record employee claims, ensuring accurate and up-to-date data for management and decision-making purposes.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the **Category** field to indicate that this form is related to "Employee Surveys".
2. Provide a brief **Description** of the claim you are submitting.
3. If necessary, specify the **Assigned Tool** used to complete the form.
4. Optionally, provide the **Form Ids** for reference.

## Field-by-Field Explanation
* **Category** (Employee Surveys, required/optional): Select the category that best describes the type of claim you are submitting.
* **Description** (text, required/optional): Enter a brief description of your claim, including any relevant details.
* **Output File** (text, required/optional): If applicable, specify the output file related to your claim.
* **Assigned Tool** (text, required/optional): If a specific tool was used to complete the form, please indicate it.
* **Form Ids** (text, required/optional): Provide any relevant form IDs for reference.
* **Form Ids** (text, required/optional): This field is identical to the previous one; please disregard.

### Tips
* Make sure to select the correct category to ensure accurate tracking and reporting.
* Keep the description concise and clear for easy reference.
* If applicable, provide the output file for further analysis or review.
* If a specific tool was used, please specify it for future reference.
* Form IDs are optional but can be helpful for tracking and linking related forms.
