# Recognition Frequency Analysis Survey - Help Guide
## Purpose
This form is designed to collect information about the frequency of recognition practices within an organization. It consists of various sections that ask you to select or input information about different aspects of recognition, such as employee surveys, manager surveys, and barriers.

## How To Complete This Form
1. Select all the options that apply to your current recognition practices. For each option, you can select one or multiple answers depending on the type of question.
2. Answer all sections thoroughly, and provide as much detail as possible.
3. If you're unsure about any of the options, please contact the person who provided you with this form for clarification.

## Field-by-Field Explanation
* **Employee Survey** (`employee_survey`, select_multiple): This section asks you to select all the options that apply to your current recognition practices for employees. For example, if you frequently recognize employees for their contributions, select all the options that apply.
* **Barriers** (`barriers`, text): Please describe any barriers that prevent you from recognizing your employees more frequently.
* **Manager Survey** (`manager_survey`, select_one): This section asks you to select the option that best describes your manager's recognition practices. For example, if your manager frequently recognizes you for your contributions, select the option that best describes this practice.
* **Recognition Practices** (`recognition_practices`, text): Describe any recognition practices that you don't see listed in this form but that you feel are important to recognizing your employees.
* **Frequency Analysis** (`frequency_analysis`, select_multiple): This section asks you to select all the options that best describe the frequency of recognition practices. For example, if you are recognized occasionally, select all the options that apply.
* **Team Survey** (`team_survey`, select_one): This section asks you to select the option that best describes your team's recognition practices. For example, if your team frequently recognizes each other's contributions, select the option that best describes this practice.
* **Ideas** (`ideas`, text): Please describe any ideas you have for improving recognition practices within your team or organization.
* **Manager Frequency Analysis** (`manager_frequency_analysis`, select_multiple): This section asks you to select all the options that best describe the frequency of your manager's recognition practices. For example, if your manager frequently recognizes you, select all the options that apply.
* **Employee Frequency Analysis** (`employee_survey_frequency`, select_multiple): This section asks you to select all the options that describe the frequency of recognition practices for employees. For example, if employees are frequently recognized for their contributions, select all the options that apply.
* **Manager Barriers** (`manager_survey_barriers`, text): Please describe any barriers that prevent your manager from recognizing employees more frequently.
