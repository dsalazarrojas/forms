# Employee Recognition Panel Application Form - Help Guide
## Purpose
The Employee Recognition Panel Application Form is used to submit applications for inclusion in the employee recognition panel, which consists of two types: Employee Surveys and Human Resources Forms.
## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of panel you wish to apply for from the category and employee surveys fields.
2. Check the box next to Human Resources Forms if you want to be included in that section.
3. Enter a brief description of why you wish to be included in the panel.
## Field-by-Field Explanation
### Category
*   **category**: 
    Select the type of panel you wish to be included in. This field is optional, but selecting "Yes" will automatically populate the employee surveys field.
### Employee Surveys
*   **Employee Surveys**: 
    Select "Yes" to be included in the employee surveys panel, or "No" to be excluded.
### Human Resources Forms
*   **Human Resources Forms**: 
    Select "Yes" to be included in the Human Resources Forms panel, or "No" to be excluded.
### Description
*   **description**: 
    Enter a brief description of why you wish to be included in the panel. This field is optional but recommended for consideration.
### Tips
*   Please be as specific as possible with your description.
*   If you have any questions, contact your supervisor or HR representative.
