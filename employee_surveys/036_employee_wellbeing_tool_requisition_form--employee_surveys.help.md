# employee_wellbeing_tool_requisition_form - Help Guide
## Purpose
The employee wellbeing tool requisition form is a tool used to request access to wellbeing tools for employees. It is designed to help employees request wellbeing tools that they need to improve their physical and mental health. This form is meant to be completed by employees who require access to wellbeing tools such as exercise equipment, meditation rooms, or mental health services.

## How To Complete This Form
To complete this form, follow these steps:
1. Click on the "wellbeing tool request" text field. This is where you can enter a brief description of the wellbeing tool you are requesting access to.
2. Enter your name in the "assigned to" text field. This is where you can specify who the wellbeing tool will be assigned to (e.g., yourself, a team member, or a department).
3. Enter the name of the assigned tool in the "assigned tool" text field. This is where you can specify the wellbeing tool you are requesting access to.
4. Once you have completed all the fields, click the "submit" button to submit your request.

## Field-by-Field Explanation
* **wellbeing tool request** (`wellbeing_tool_request`, `text`, required: false): This field is where you can enter a brief description of the wellbeing tool you are requesting access to. For example, you can enter "I need access to a yoga mat for meditation sessions."
* **assigned tool** (`assigned_tool`, `text`, required: false): This field is where you can specify the wellbeing tool you are requesting access to. For example, you can enter "yoga mat", " meditation room", etc.
* **assigned to** (`assigned_to`, `text`, required: false): This field is where you can specify who the wellbeing tool will be assigned to. For example, you can enter your name, a team member's name, or a department's name.
