# Employee Sentiment Summary Request Form - Help Guide
## Purpose
This form is used to request a sentiment summary for an employee from their manager.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Employee ID of the employee you wish to request a sentiment summary for.
2. Enter the Employee Name.
3. Enter the Reporting Line Manager ID.
4. Enter the Reporting Line Manager Name.
5. Select a Sentiment Summary Request Date.
6. Select a Sentiment Summary Request Time.
7. Enter the Manager Sentiment Score.
8. Enter the Manager Sentiment Comment.
9. Enter the Employee Sentiment Score.
10. Enter the Employee Sentiment Comment.
11. Enter the Manager Sentiment Impact Score.
12. Enter the Manager Sentiment Impact Comment.
13. Enter the Employee Sentiment Impact Score.
14. Enter the Employee Sentiment Impact Comment.
15. Select the submitted by manager option (Manager, Department, HR).
16. Enter the submitted by date.
17. Enter the submitted to manager name.
18. Enter the submitted to manager name.
19. Enter the email of the person submitting the request.
20. Enter the phone number of the person submitting the request.
21. Add any additional notes about the request.
22. Enter the name of the person submitting the request.

## Field-by-Field Explanation
* **Employee Sentiment Summary Request Form** (`employee_sentiment_summary_request_form`, text, required/optional): This is the title of the form.
* **Employee ID** (`employee_id`, number, required/optional): Enter the ID of the employee you wish to request a sentiment summary for.
* **Employee Name** (`employee_name`, text, required/optional): Enter the name of the employee.
* **Reporting Line Manager ID** (`reporting_line_manager_id`, number, required/optional): Enter the ID of the employee's reporting line manager.
* **Reporting Line Manager Name** (`reporting_line_manager_name`, text, required/optional): Enter the name of the employee's reporting line manager.
* **Sentiment Summary Request Date** (`sentiment_summary_request_date`, date, required/optional): Select the date of the sentiment summary request.
* **Sentiment Summary Request Time** (`sentiment_summary_request_time`, time, required/optional): Select the time of the sentiment summary request.
* **Manager Sentiment Score** (`manager_sentiment_score`, number, required/optional): Enter the sentiment score of the manager.
* **Manager Sentiment Comment** (`manager_sentiment_comment`, text, required/optional): Enter the comment of the manager's sentiment.
* **Employee Sentiment Score** (`employee_sentiment_score`, number, required/optional): Enter the sentiment score of the employee.
* **Employee Sentiment Comment** (`employee_sentiment_comment`, text, required/optional): Enter the comment of the employee's sentiment.
* **Manager Sentiment Impact Score** (`manager_sentiment_impact_score`, number, required/optional): Enter the impact score of the manager's sentiment.
* **Manager Sentiment Impact Comment** (`manager_sentiment_impact_comment`, text, required/optional): Enter the comment of the manager's sentiment impact.
* **Employee Sentiment Impact Score** (`employee_sentiment_impact_score`, number, required/optional): Enter the impact score of the employee's sentiment.
* **Employee Sentiment Impact Comment** (`employee_sentiment_impact_comment`, text, required/optional): Enter the comment of the employee's sentiment impact.
* **Submitted By** (`submitted_by_manager`, text, required/optional): Select the submitted by manager option (Manager, Department, HR).
* **Submitted By Date** (`submitted_by_date`, date, required/optional): Enter the submitted by date.
* **Submitted To** (`submitted_to_manager`, select_one, required/optional): Select the submitted to manager option (Manager, Department, HR).
* **Submitted To Date** (`submitted_to_date`, date, required/optional): Enter the submitted to manager date.
* **Email** (`email`, email, required/optional): Enter the email of the person submitting the request.
* **Phone** (`phone`, text, required/optional): Enter the phone number of the person submitting the request.
* **Notes** (`notes`, note, required/optional): Add any additional notes about the request.
* **Submitted By Manager Name** (`submitted_by_manager_name`, text, required/optional): Enter the name of the person submitting the request.
* **Submitted To Manager Name** (`submitted_to_manager_name`, text, required/optional): Enter the name of the submitted to manager.
* **Submitted By Department** (`submitted_by_department`, text, required/optional): Enter the department of the person submitting the request.
