# employee_engagement_tool_requisition_form - Help Guide
## Purpose
This form is designed to collect information about employee engagement tools requested by employees, which will be reviewed and processed by internal stakeholders for approval and resource allocation.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of tool you are requesting (yes/no).
2. Provide a brief description of the tool you are requesting.
3. Specify the budget allocated for the tool.
4. Indicate who requested the tool (yes/no).
5. If applicable, specify who the tool is assigned to.
6. Select the status of the tool (active/inactive).
7. Enter the date the tool was received.
8. Add any comments or notes about the tool.
9. Specify which tool you are requesting (chatjimmy/other).

## Field-by-Field Explanation
* **tool_type** (select_one, required): Select the type of tool you are requesting (yes/no).
* **tool_description** (text, optional): Provide a brief description of the tool you are requesting.
* **budget** (number, optional): Specify the budget allocated for the tool.
* **requested_by** (select_multiple, optional): Indicate who requested the tool (yes/no).
* **assigned_to** (text, optional): Specify who the tool is assigned to.
* **tool_status** (select_one, optional): Select the status of the tool (active/inactive).
* **date_received** (date, optional): Enter the date the tool was received.
* **comments** (note, optional): Add any comments or notes about the tool.
* **assigned_tool** (select_one, optional): Specify which tool you are requesting (chatjimmy/other).

## Tips

* Please ensure that you have explicit approval to submit a tool request before filling out this form.
* If you are requesting a tool for personal purposes or non-work-related, please use a different submission channel.
