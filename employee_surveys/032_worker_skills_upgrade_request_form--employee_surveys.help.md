# Worker Skills Upgrade Request Form - Help Guide
## Purpose
The Worker Skills Upgrade Request Form is a tool for employees to request a manager's approval for skills upgrade for a specific worker. This form helps to facilitate the process of upgrading the worker's skills and knowledge, and ensures that the manager is informed and involved in the decision-making process.

## How To Complete This Form

To complete this form, follow these steps:

1. **Manager Approval** (`manager_approval`): Select the desired manager approval status for the request.
	* Approved: Manager approves the request.
	* Rejected: Manager rejects the request.
	* Pending: Manager is still considering the request.
2. **Employee Name** (`employee_name`): Enter the name of the employee whose skills you want to upgrade.
3. **Training Requests** (`training_requests`): List the specific training or skills you want to upgrade.
4. **Preferred Format** (`preferred_format`): Choose the preferred format for the upgrade (e.g., Online Course, Instructor-led Course, or Other).
5. **Manager Email** (`manager_email`): Enter the email address of the manager responsible for the employee.
6. **Manager Name** (`manager_name`): Enter the name of the manager responsible for the employee.
7. **Manager Phone** (`manager_phone`): Enter the phone number of the manager responsible for the employee.
8. **Manager Comments** (`manager_approval_comments`): Provide any additional feedback or comments for the manager.

## Field-by-Field Explanation

* **Manager Approval**: Select the desired manager approval status for the request. This will help the manager make an informed decision.
* **Employee Name**: Enter the name of the employee whose skills you want to upgrade. This is necessary for the manager to identify the employee.
* **Training Requests**: List the specific training or skills you want to upgrade. This will help the manager understand the request.
* **Preferred Format**: Choose the preferred format for the upgrade. This will help the manager consider the logistics of the upgrade.
* **Manager Email**: Enter the email address of the manager responsible for the employee. This is necessary for the manager to receive the request.
* **Manager Name**: Enter the name of the manager responsible for the employee. This is necessary for the manager to identify the employee.
* **Manager Phone**: Enter the phone number of the manager responsible for the employee. This is optional but recommended.
* **Manager Comments**: Provide any additional feedback or comments for the manager. This will help the manager make an informed decision.

## Tips

* Before submitting the form, please ensure that you have discussed the request with the manager and that they are aware of the request.
* If the request is approved, please follow up with the manager to confirm their availability and schedule for the upgrade.
* If the request is rejected, please discuss the reason with the manager and provide any necessary feedback or corrections.
