# performance-metrics-clarity-survey - Help Guide
## Purpose
This form is designed to help employees evaluate the clarity and understanding of performance metrics and targets set by their supervisors. The results will be used to inform improvements to the performance management process.

## How To Complete This Form
1. Please answer all questions truthfully and to the best of your abilities.
2. Select all that apply for each question.
3. If you have any trouble completing a question, please ask your supervisor for clarification.

## Field-by-Field Explanation
- **Employee-Survey** (page_1): This question asks if you have a clear understanding of what you are being measured on. Select 'Yes' if you have a clear understanding of the performance metrics.
- **Performance-Metrics** (page_2): This question asks you to describe a performance metric you are familiar with. Please provide a specific example from your job or work area.
- **Metrics-Targets** (page_3): This question asks you to select a date when you first started to understand what the performance metric means or when you became clear. This will help us determine the effectiveness of our training and communication processes.
- **Targets-Description** (page_4): This question asks you to describe the performance target and how you have understood it. Please provide a clear and concise description.
- **Targets-Clarification** (page_5): This question is optional and allows you to provide any additional comments or clarifications about the targets.
- **Performance-Metrics-Clarity** (page_6): This question asks if you have a clear understanding of performance metrics. Select 'Yes' if you have a clear understanding.
- **Metrics-And-Targets-Understanding** (page_7): This question asks you to select all the performance metrics and targets you have a clear understanding of. Select all that apply.
- **Metrics-Understanding** (page_8): This question asks if you have a clear understanding of the metrics and targets you selected in the previous question. Select 'Yes' for each metric and target.
- **Performance-Metrics-Targets** (page_9): This question asks if you have a clear understanding of performance metrics and targets. Select 'Yes' if you have a clear understanding.
- **Prophets-And-Priesthood** (page_10): This question allows you to provide any additional comments or thoughts on the performance metrics and targets.
- **Metrics-And-Targets-Satisfaction** (page_11): This question asks you to select how satisfied you are with the clarity of performance metrics and targets. Select 'Satisfied' if you are satisfied.
- **Performance-Metrics-Clarification** (page_12): This question asks if you have any suggestions or requests for improvements to the performance metrics and targets. Select 'Yes' if you have any suggestions or requests.

## Tips
* Please answer all questions truthfully and to the best of your abilities.
* If you have any trouble completing a question, please ask your supervisor for clarification.
* All answers will be kept anonymous.
