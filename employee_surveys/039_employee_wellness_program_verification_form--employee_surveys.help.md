# employee_wellness_program_verification_form - Help Guide

## Purpose
The purpose of this form is to verify the participation status of employees in the employee wellness program.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the employee's name in the "employee_name" field.
2. Enter the employee's ID in the "employee_id" field.
3. Choose the correct date of program participation from the "program_date" field.
4. Select all relevant programs the employee is participating in from the "wellness_programs" field.
5. Indicate the employee's current participation status in the "participation_status" field.
6. Check the employee's current status (Active or Inactive) in the "employee_status" field.

## Field-by-Field Explanation

* **employee_name**: Enter the name of the employee whose participation is being verified.
* **employee_id**: Enter the employee's unique ID number.
* **program_date**: Select the date on which the employee started participating in the wellness program.
* **wellness_programs**: Choose all programs the employee is currently participating in:
	+ Employee Assistance Program
	+ Employee Wellness Program
	+ Wellness Program
* **participation_status**: Indicate the employee's current participation status:
	+ Yes
	+ No
* **employee_status**: Check the employee's current status:
	+ Active
	+ Inactive
