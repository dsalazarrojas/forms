# Family Leave Benefits Survey - Help Guide
## Purpose
The Family Leave Benefits Survey is designed to gather information about employee benefits related to family leave. This form will help us understand which benefits are available to employees, their satisfaction with these benefits, and any feedback or comments about the leave policies in place.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the answer that best matches your response to each question.
2. If a question is not applicable to you, please select 'No' or leave the field blank.
3. Provide any additional feedback or comments in the 'Feedback' field.

## Field-by-Field Explanation

* **Family Leave Benefits** (`1`, `select_one`, required: false): Please select 'Yes' if you have access to family leave benefits, such as paid time off, parental leave, or other types of leave. Select 'No' if you do not have access to such benefits.
* **Employee Leave Benefits** (`2`, `text`, required: false): Provide a brief description of the leave benefits you have.
* **Leave Benefits Satisfaction** (`3`, `select_multiple`, required: false): Indicate how satisfied you are with the leave benefits you have. You can select 'Satisfied' if you are satisfied, 'Dissatisfied' if you are not, or 'Neutral' if you are indifferent.
* **Workplace Policies** (`4`, `text`, required: false): Describe any policies related to leave benefits that you would like to see changed or implemented.
* **Feedback** (`5`, `note`, required: false): Share any comments or suggestions you have about leave benefits or policies. This is a free-text field where you can write your thoughts.
* **Email** (`6`, `email`, required: false): Please enter your email address if you would like to be contacted about this survey or if you have any follow-up questions.
* **Phone** (`7`, `text`, required: false): If you have a phone number where you can be reached, please enter it.
* **Date** (`8`, `date`, required: false): Enter the date you completed this survey.
* **Time** (`9`, `time`, required: false): Enter the time you completed this survey.
* **Category** (`10`, `select_one`, required: false): Select 'Yes' if you believe your category is relevant to this survey, such as 'Parental Leave' or 'Other'.
* **Category Value** (`11`, `select_one`, required: false): Select 'Yes' if your category is relevant to this survey.
* **Description** (`12`, `text`, required: false): Provide a brief description of why this category is relevant to you.
* **Output File** (`13`, `text`, required: false): If you would like to attach a file with your responses, please enter the name of the file.
* **Assigned Tool** (`14`, `select_one`, required: false): Select 'Yes' if you have been assigned to use a specific tool or resource related to leave benefits.
* **Assigned Tool Value** (`15`, `select_one`, required: false): Select 'Yes' if you have been assigned to use a specific tool or resource related to leave benefits.
* **Form IDs** (`16`, `number`, required: false): Enter the ID of this form, if applicable.
* **Form IDs Value** (`17`, `select_one`, required: false): Select 'Yes' if this form is relevant to you, if applicable.

Please note that some fields are not required, and you can leave them blank if you don't have any information to report.
