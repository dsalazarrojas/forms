# Nap Pod Usage Interest Survey - Help Guide
## Purpose
The purpose of this form is to gather information from employees about their interest in using nap pods.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Read each question carefully and answer accordingly.
2. Select the options that best fit your preferences.
3. Use the "Additional Comments" field for any further information you would like to provide.

## Field-by-Field Explanation

* **Introduction**: This is a non-mandatory note to introduce the form and its purpose.
* **Interested in Nap Pods**: Select all the options that apply to you. For example, if you are interested in using nap pods both on campus and in your office, select both options.
* **Preferred Usage Time**: Select your preferred time of day to use a nap pod. You can choose one or multiple options.
* **Nap Pod Frequency**: Select how often you would like to use nap pods.
* **Nap Pod Duration**: Note the length of time you would like to use nap pods for.
* **Nap Pod Location**: Select all the locations where you would like to use nap pods. For example, if you would like to use nap pods on campus and in your office, select both options.
* **Nap Pod Frequency Comments**: If you would like to provide more information about your preferred frequency, you can do so in this field.
* **Comments**: Use this field to provide any additional comments or information you would like to share.
* **Additional Comments**: Use this field to provide any further comments or information you would like to share.
* **Interested in Nap Pods Frequency**: Select how often you would like to use nap pods. 
* **Nap Pod Type**: Select the type of nap pod you are interested in (e.g., nap pod, other).
* **Nap Pod Features**: Select the features you would like to have in a nap pod (e.g., temperature control, white noise, quiet, nap mat).
* **Nap Pod Features Comments**: If you would like to provide more information about the features you are interested in, you can do so in this field.
* **Nap Pod Features Frequency**: Select how often you would like to use nap pods with the selected features.
* **Nap Pod Features Reason**: Use this field to explain why you would like to have a nap pod with selected features.
* **Nap Pod Features Reason Comments**: If you would like to provide more information about why you would like to have a nap pod with selected features, you can do so in this field.
* **Nap Pod Favourite Time**: Select your favorite time to use a nap pod.
* **Nap Pod Favourite Time Comments**: If you would like to provide more information about your favorite time, you can do so in this field.
* **Nap Pod Favourite Frequency**: Select how often you would like to use a nap pod during your favorite time.
* **Nap Pod Favourite Frequency Comments**: If you would like to provide more information about your favorite frequency, you can do so in this field.
* **Nap Pod Favourite Location**: Select the location where you would like to use a nap pod during your favorite time.
* **Nap Pod Favourite Location Comments**: If you would like to provide more information about your favorite location, you can do so in this field.
