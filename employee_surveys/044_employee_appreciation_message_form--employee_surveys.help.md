# Employee Appreciation Message Form - Help Guide
## Purpose

The Employee Appreciation Message Form is a tool for employees to express their appreciation and gratitude for their colleagues, team members, or other employees. It's designed to help foster a positive and supportive work environment.

## How To Complete This Form

To complete this form, simply select the recipient and message type, and fill out any other required or optional fields. The form will help guide you through each step.

## Field-by-Field Explanation

### Employee Appreciation Message

- **Employee Appreciation Message** (`id: 1`, text, optional): Please take a moment to write a message to express your appreciation for your colleague's hard work and dedication.
    * Keep it concise and sincere, e.g., "Thanks for your help on the project!"
    * You can also mention specific projects or tasks you're grateful for.

### Recipient

- **Recipient** (`id: 2`, select_one, optional): Choose the person you want to send the appreciation message to.
    * Select 'Yes' if you want to send the message to the specified recipient.
    * Select 'No' if you don't want to send the message to anyone.

### Message Type

- **Message Type** (`id: 10`, select_one, optional): Choose how you want to send the appreciation message.
    * Select 'Yes' for a public message visible to all team members.
    * Select 'No' for a private message only visible to the recipient.

### Department

- **Department** (`id: 4`, select_one, optional): Choose the department the recipient belongs to.
    * This will help the recipient receive the message in their departmental email list.

### Date

- **Date** (`id: 5`, date, optional): Select a date to send the appreciation message on.
    * This will schedule the message to be sent on the specified date.

### Time

- **Time** (`id: 6`, time, optional): Select a time to send the appreciation message on.
    * This will schedule the message to be sent at the specified time.

### Employee Name

- **Employee Name** (`id: 7`, text, optional): Enter the name of the employee sending the appreciation message.
    * Make sure to use the employee's name as per company records.

### Email

- **Email** (`id: 8`, email, optional): Enter the email address of the recipient.
    * Ensure you use the correct email address of the recipient, or their departmental email.

### Phone

- **Phone** (`id: 9`, text, optional): Enter the phone number of the recipient.
    * Only enter if you have the recipient's phone number, otherwise, leave blank.

### Team

- **Team** (`id: 11`, select_multiple, optional): Choose the team members to receive the appreciation message.
    * Select 'Yes' for all team members to receive the message.
    * Select 'No' if you only want to send the message to the specified recipient.

### Submit

- **Submit** (`id: 12`, select_one, optional): Finalize and send the appreciation message.
    * Once you've filled out all the fields, select 'Yes' to submit the form.
    * Select 'No' to cancel the form without submitting.

Please remember to be sincere and specific with your appreciation messages to make them more impactful.
