# Reception Shift Interest Survey - Help Guide
## Purpose
This form is designed to collect information from employees about their availability and interest in different shifts. Your responses will help management create more optimal shift schedules that take into account your preferences and availability.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the "Form Start" page, which is just a placeholder page with no fields to fill out.
2. Proceed to the "Employee Details" page, where you will provide your employee details, which includes a text field where you can enter your name and any other relevant information.
3. On the "Availability" page, select the date for which you are available to work.
4. On the "Shift Interest" page, select all the shifts for which you are interested in working. You can select multiple shifts.
5. Finally, on the "Form End" page, enter any comments or additional information you want to provide.

## Field-by-Field Explanation

* **Form Start** (`text`, not required): A placeholder page to get you started.
* **Employee Details** (`text`, not required): Enter your name and any other relevant information about yourself.
* **Availability** (`date`, not required): Select the date for which you are available to work. Please enter the date in the correct format (e.g., YYYY-MM-DD).
* **Shift Interest** (`select_multiple`, not required): Select all the shifts for which you are interested in working. You can select multiple shifts by checking multiple boxes.
	+ Shift 1: Select this option if you are interested in working Shift 1.
	+ Shift 2: Select this option if you are interested in working Shift 2.
	+ Shift 3: Select this option if you are interested in working Shift 3.
	+ Shift 4: Select this option if you are interested in working Shift 4.
	+ Shift 5: Select this option if you are interested in working Shift 5.
	+ Shift 6: Select this option if you are interested in working Shift 6.
* **Form End** (`text`, not required): Enter any additional comments or information you want to provide.

## Tips
- Be honest and accurate when filling out this form to help management create a schedule that takes into account your needs and preferences.
- If you have any questions or concerns, please contact your supervisor or HR representative.
- Please do not submit duplicate responses, as this can cause confusion and make it harder for management to understand your needs and preferences.
