# Support Leadership Continuity Form - Help Guide
## Purpose
## How To Complete This Form
## Field-by-Field Explanation

* **Current Succession Status (`current_succession_status`):**
	+ Select one of the following options:
		- Active
		- Inactive
* **Identified Successors (`identified_successors`):**
	+ Select all successors who have been identified for key roles. You can choose 'Yes' for each applicable person.
* **Succession Planning Resources (`succession_planning_resources`):**
	+ Select all resources that are available to support succession planning, such as training programs, mentorship, or development plans.
* **Resource Needs (`resource_needs`):**
	+ Select 'Yes' if there are specific resource needs for succession planning, such as additional training or budget allocations.
* **Frequency of Resource Needs (`resource_needs_frequency`):**
	+ Enter a numerical value (e.g., 1-5) to indicate how frequently resource needs arise for succession planning.
* **Succession Status Comments (`succession_status_comments`):**
	+ Provide any additional comments or observations about the current succession status.
* **Resource Needs Comments (`resource_needs_comments`):**
	+ Provide any additional comments or observations about resource needs.
* **Resource Needs Frequency Comments (`resource_needs_frequency_comments`):**
	+ Provide any additional comments or observations about resource needs frequency.
