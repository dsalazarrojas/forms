# Organizational Feedback Maturity Survey - Help Guide

## Purpose
This form is designed to help organizations assess their current status and progress in various areas of organizational feedback, action items, and focused actions.

## How To Complete This Form
To complete this form, please answer the questions on each page as accurately and thoroughly as possible. For each question, select the option that best describes your current status or practice. Make sure to provide clear and detailed answers in the text fields.

## Field-by-Field Explanation

### Page 1: Introduction
* **Introduction** (`intro_page`, note, optional): This page provides an introduction to the survey and its purpose.

### Page 2: Current Status
* **What is the current status?** (`question_2_1`, select_multiple, required): Please select all the options that describe the current status of your organization's feedback system. Options are:
	+ Not Implemented
	+ Somewhat Implemented
	+ Fully Implemented
* **What is the current status implementation details?** (`question_3_1`, text, required): Please provide a brief description of the current implementation details of your organization's feedback system.
* **What is the current status effectiveness?** (`question_4_1`, select_one, required): Please select the option that best describes the current effectiveness of your organization's feedback system. Options are:
	+ Not Effective
	+ Somewhat Effective
	+ Very Effective
* **What are the most common reasons for not being very effective?** (`question_5_1`, text, required): Please provide a detailed list of the most common reasons why your organization's feedback system is not very effective.
