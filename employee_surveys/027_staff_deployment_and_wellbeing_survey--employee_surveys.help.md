# Staff Deployment And Wellbeing Survey - Help Guide
## Purpose

This form is designed to gather information on the current deployment status and overall wellbeing level of employees.

## How To Complete This Form

1. Select the relevant response for each question based on your current situation.
2. Answer all required fields, marked with an asterisk (\*).
3. Provide any additional comments or notes if desired in the text fields.

## Field-by-Field Explanation

* **What is your current deployment status** (`staff_deployment_status`, select_one, required):
	+ Select "Active" if you are currently deployed and actively working on projects.
	+ Select "Inactive" if you are not actively deployed and not working on projects.
* **Overall wellbeing level** (`overall_wellbeing_level`, select_one, required):
	+ Select "High" if you are feeling well and happy in your current role.
	+ Select "Low" if you are not feeling well and happy in your current role.
* **Job satisfaction** (`job_satisfaction`, number, required):
	+ Enter a number between 1-10 to indicate your current level of job satisfaction.
* **Job satisfaction note** (`job_satisfaction_note`, text, optional):
	+ Provide any additional comments on your job satisfaction.
* **Deployment wellbeing issues** (`deployment_wellbeing_issues`, select_multiple, required):
	+ Select "Yes" if you are experiencing any deployment-related wellbeing issues.
	+ Select "No" if you are not experiencing any deployment-related wellbeing issues.
* **Deployment status** (`deployment_status`, select_one, required):
	+ Select "Active" if you are currently deployed and actively working on projects.
	+ Select "Inactive" if you are not actively deployed and not working on projects.
* **Overall wellbeing issues** (`overall_wellbeing_issues`, select_multiple, required):
	+ Select "Yes" if you are experiencing any overall wellbeing issues.
	+ Select "No" if you are not experiencing any overall wellbeing issues.
* **Wellbeing focus area** (`wellbeing_focus_area`, select_one, required):
	+ Select "Yes" if you are currently focusing on wellbeing.
	+ Select "No" if you are not focusing on wellbeing.
* **Wellbeing support** (`wellbeing_support`, select_multiple, required):
	+ Select "Yes" if you are receiving wellbeing support.
	+ Select "No" if you are not receiving wellbeing support.
* **Deployment status note** (`deployment_status_note`, text, optional):
	+ Provide any additional comments on your deployment status.

## Tips

* Please answer honestly and to the best of your ability.
* You can provide additional comments or notes in the text fields to elaborate on your responses.
* If you have any questions or concerns, please reach out to your management team.
