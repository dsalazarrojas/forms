# media_operations_coordinator_survey - Help Guide
## Purpose
This form aims to gather feedback from media operations coordinators, enabling the improvement and development of media operations processes.

## How To Complete This Form
To complete this form, please answer each question to the best of your ability. Make sure to choose the correct options for your work experience, challenges, and tool usage.

## Field-by-Field Explanation
### **work_experience** (Yes/No)
(`work_experience`, `select_multiple`, required/optional)
This field asks about your work experience as a media operations coordinator. Please select all the options that apply to your situation.

### **challenges** (text)
(`challenges`, `text`, required/optional)
Enter any challenges you are currently facing or have faced in your role as a media operations coordinator.

### **tools** (Yes/No)
(`tools`, `select_one`, required/optional)
This field asks about your use of specific tools in your work. Please select all that apply.

### **improvements** (text)
(`improvements`, `text`, required/optional)
Share any suggestions or ideas you have to improve media operations processes.

### **feedback** (text)
(`feedback`, `note`, required/optional)
Provide any feedback or comments you'd like to share about media operations.

### **assigned_tool** (Yes/No)
(`assigned_tool`, `select_one`, required/optional)
This field asks about the assigned tool usage in your role. Please select all that apply.

### **tools_used** (Yes/No)
(`tools_used`, `select_multiple`, required/optional)
Select all the tools you use regularly in your work.

### **tools_not_used** (Yes/No)
(`tools_not_used`, `select_multiple`, required/optional)
Select all the tools you do not use regularly.
