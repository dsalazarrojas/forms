# Remote Work Readiness Assessment - Help Guide

## Purpose
This form is designed to assess an employee's readiness for remote work arrangements. It will help managers and HR personnel understand whether an employee is suitable for remote work, based on their personal preferences, skills, and circumstances.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate employee surveys category from the list of options.
2. Enter a brief description of the current situation or the purpose of the assessment.
3. Choose the output format for the assessment results (JSON, CSV, or Excel).
4. Specify which apps to sync data with (if any).
5. Indicate if no coding is required for remote work.
6. Enter any additional comments or details about the assessment.
7. Enter any other relevant details about the assessment.

## Field-by-Field Explanation

* **Employee Surveys** (`employee_surveys`, `select_one`, required: `false`): Select the type of employee surveys that best fit your situation. Choose from the options of Employee Surveys or Other.
* **Description** (`description`, `text`, required: `false`): Enter a brief description of the current situation or the purpose of the assessment.
* **Output Format** (`output_format`, `select_multiple`, required: `false`): Choose the output format for the assessment results. Options include JSON, CSV, and Excel.
* **Sync Apps** (`sync_apps`, `text`, required: `false`): Specify which apps to sync data with (if any).
* **No Coding Required** (`no_coding_required`, `select_one`, required: `false`): Indicate if no coding is required for remote work.
* **Description** (`description`, `text`, required: `false`): Enter any additional comments or details about the assessment.
* **Description** (`description_2`, `text`, required: `false`): Enter any other relevant details about the assessment.
