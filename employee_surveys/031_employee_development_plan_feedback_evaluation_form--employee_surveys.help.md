**Employee Development Plan Feedback Evaluation Form - Help Guide**

## Purpose
This form is used to gather feedback on the effectiveness of employee development plans for employees in the organization. It is meant to be completed by managers or supervisors who will evaluate the progress of employee development plans and provide insights on areas of improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the employee development plans you are responsible for and identify areas where the employees need improvement.
2. Select the relevant options for each field that best describe the employee's performance and progress.
3. Provide specific feedback in the text field for the employee and action items.
4. Select the correct performance level and status for the employee.
5. Date and time of the evaluation should be accurate.

## Field-by-Field Explanation

* **Employee Development Plan** (`employee_development_plan`, Note, Optional):
	+ This field is a brief description of the employee's development plan.
* **Performance** (`performance`, Select Multiple, Optional):
	+ This field is used to evaluate the employee's performance level. Select "Yes" if the employee is meeting or exceeding expectations, "No" if not.
* **Goals** (`goals`, Select One, Optional):
	+ This field is used to evaluate if the employee's goals are being achieved. Select "Yes" if the employee is making progress, "No" if not.
* **Feedback** (`feedback`, Text, Optional):
	+ This field is for providing specific feedback on areas of improvement for the employee.
* **Action Items** (`action_items`, Select Multiple, Optional):
	+ This field is used to identify specific action items that need to be addressed by the employee.
* **Employee Development Plan Goals** (`employee_development_plan_goals`, Text, Optional):
	+ This field is for providing specific goals and objectives that need to be achieved by the employee.
* **Performance Level** (`performance_level`, Select One, Optional):
	+ This field is used to evaluate the employee's performance level. Select "High" for excellent performance, "Low" for below-expectations performance.
* **Employee Development Plan Status** (`employee_development_plan_status`, Select One, Optional):
	+ This field is used to evaluate the status of the employee's development plan. Select "Active" for ongoing plans, "Inactive" for plans that have been completed.
* **Evaluation Date** (`evaluation_date`, Date, Optional):
	+ This field is for recording the date of the evaluation.
* **Evaluation Time** (`evaluation_time`, Time, Optional):
	+ This field is for recording the time of the evaluation.

## Tips

* Be specific and concrete when providing feedback and action items for the employee.
* Ensure that the performance level and status fields accurately reflect the employee's current state.
* Date and time fields should be accurate and up-to-date.
* This form is meant to be a tool to help employees grow and improve, so be constructive and helpful in your feedback.
