# Hair Extension Consultation Form - Help Guide

## Purpose

This form is designed to collect information about your hair for a hair extension consultation. It will help our hairdresser understand your hair's current condition, needs, and preferences to provide personalized recommendations for your hair extension.

## How To Complete This Form

*   To complete this form, please answer the questions honestly and thoroughly. If you have any previous hair problems or products, please select 'Yes' or 'No' accordingly.
*   For fields like 'hair_type', 'hair_length', 'hair_condition', 'hair_color', 'hair_thickness', 'hair_texture', 'hair_porosity', 'hair_diameter', 'scalp_condition', 'hair_follicle', 'hair_problems', and 'previous_hair_products', please select all applicable options.
*   For 'hair_problems_other' and 'recommended_products_other' fields, please provide a brief description of your issue or recommended product.

## Field-by-Field Explanation

*   **hair_extension_consultation** (`hair_extension_consultation_form_1`, text, required): This is the main consultation question where you can describe your hair concerns or preferences.
*   **hair_type** (`hair_type`, select_one, required: false): Please select all your hair types (e.g., 'Yes' for curly, 'Yes' for straight, 'Yes' for wavy, etc.).
*   **hair_length** (`hair_length`, select_multiple, required: false): Please select all hair lengths you have experience with (e.g., 'Yes' for short, 'Yes' for long, etc.).
*   **hair_condition** (`hair_condition`, select_multiple, required: false): Please select all hair conditions you have (e.g., 'Yes' for oily, 'Yes' for dry, etc.).
*   **hair_color** (`hair_color`, select_multiple, required: false): Please select all hair colors you have (e.g., 'Yes' for black, 'Yes' for blonde, etc.).
*   **hair_thickness** (`hair_thickness`, select_multiple, required: false): Please select all hair thicknesses you have (e.g., 'Yes' for thin, 'Yes' for thick, etc.).
*   **hair_texture** (`hair_texture`, select_multiple, required: false): Please select all hair textures you have (e.g., 'Yes' for fine, 'Yes' for coarse, etc.).
*   **hair_porosity** (`hair_porosity`, select_multiple, required: false): Please select all hair porosities (e.g., 'Yes' for porous, 'Yes' for non-porous, etc.).
*   **hair_diameter** (`hair_diameter`, select_multiple, required: false): Please select all hair diameters you have (e.g., 'Yes' for fine, 'Yes' for coarse, etc.).
*   **scalp_condition** (`scalp_condition`, select_multiple, required: false): Please select all scalp conditions you have (e.g., 'Yes' for flaky, 'Yes' for oily, etc.).
*   **hair_follicle** (`hair_follicle`, select_multiple, required: false): Please select all hair follicle conditions you have (e.g., 'Yes' for dandruff, 'Yes' for itchiness, etc.).
*   **hair_problems** (`hair_problems`, select_multiple, required: false): Please select all hair problems you have (e.g., 'Yes' for breakage, 'Yes' for tangles, etc.).
*   **hair_problems_other** (`hair_problems_other`, note, required: false): If you have any other hair problems not listed above, please describe them here.
*   **previous_hair_products** (`previous_hair_products`, select_multiple, required: false): Please select all previous hair products you've used (e.g., 'Yes' for conditioner, 'Yes' for serum, etc.).
*   **previous_hair_products_other** (`previous_hair_products_other`, note, required: false): If you've used any other hair product not listed above, please describe them here.
*   **recommended_products** (`recommended_products`, select_multiple, required: false): If you're open to product recommendations, please select the ones you'd like to try.
*   **recommended_products_other** (`recommended_products_other`, note, required: false): If you have any other product recommendations, please describe them here.
*   **other_comments** (`other_comments`, text, required: false): Please provide any additional comments or concerns you have about your hair.

## Tips

*   Please answer all questions thoroughly and honestly to help our hairdresser provide the best advice for your hair.
*   If you have any questions or concerns, feel free to ask us!
