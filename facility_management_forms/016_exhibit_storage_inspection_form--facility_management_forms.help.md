# Exhibit Storage Inspection Form - Help Guide
## Purpose
The Exhibit Storage Inspection Form is used to inspect and report on the storage conditions of exhibits stored in various locations within the facility.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form pages and ensure you understand what each page is asking you to report on.
2. Answer each question honestly and accurately, using the options provided.
3. Select the correct answer for each question from the options available.
4. Provide any additional comments or observations in the space provided.
5. Ensure you have answered all required questions.

## Field-by-Field Explanation

* **Storage Location** (`storage_location`): Select the location where the exhibit is stored. Choose from the list of options provided.
* **Storage Conditions** (`storage_conditions`): Select all storage conditions that apply to the exhibit. Choose from the list of options provided.
* **Storage Status** (`storage_status`): Select all storage statuses that apply to the exhibit. Choose from the list of options provided.
* **Last Check** (`last_check`): Enter the date and time of the last inspection of the exhibit.
* **Storage Capacity** (`storage_capacity`): Enter the current storage capacity of the exhibit.
* **Storage Capacity Comments** (`storage_capacity_comments`): Provide any additional comments about the storage capacity of the exhibit.
* **Facility Storage** (`facility_storage`): Provide any additional comments or observations about the facility's storage.
* **Next Check Date** (`next_check_date`): Enter the date of the next scheduled check or inspection of the exhibit. 
* **Maintenance Plan** (`maintenance_plan`): This field is optional and should be used to note any ongoing or upcoming maintenance activities for the exhibit.
