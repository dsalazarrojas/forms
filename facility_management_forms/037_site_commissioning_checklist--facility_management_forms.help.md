# Site Commissioning Checklist - Help Guide
## Purpose
The Site Commissioning Checklist is a form designed to facilitate the commissioning process for a site, ensuring that all relevant teams have reviewed and signed off on the project and that all required information is captured.

## How To Complete This Form

1. Select the relevant teams that have reviewed the site (Construction, Facilities, and/or Operations).
2. Choose the options that best describe the status of the site commissioning process for each team.
3. Enter the site contact information (name, address, phone, email, etc.).
4. Enter the client contact information (name, contact, phone, email, etc.).
5. Select the site type and status from the available options.
6. Add any comments or additional comments as necessary.

## Field-by-Field Explanation

* **Construction Team Review** (`Construction Team Review`, `select_multiple`): Please select the options that best describe the status of the construction team review process.
* **Facilities Team Review** (`Facilities Team Review`, `select_one`): Please select the option that best describes the status of the facilities team review process.
* **Operations Team Review** (`Operations Team Review`, `select_multiple`): Please select the options that best describe the status of the operations team review process.
* **Review** (`Review`, `select_multiple`): Please select the options that best describe the status of the review process.
* **Comments** (`Comments`, `note`): Please enter any additional comments or notes about the site commissioning process.
* **Date** (`Date`, `date`): Please enter the date of the site commissioning completion.
* **Time** (`Time`, `time`): Please enter the time of the site commissioning completion.
* **Status** (`Status`, `select_one`): Please select the option that best describes the current status of the site commissioning process.
* **Site Name** (`Site Name`, `text`): Please enter the name of the site.
* **Site Address** (`Site Address`, `text`): Please enter the address of the site.
* **Site Contact** (`Site Contact`, `text`): Please enter the contact information for the site.
* **Site Phone** (`Site Phone`, `text`): Please enter the phone number for the site.
* **Site Email** (`Site Email`, `text`): Please enter the email address for the site.
* **Site Manager** (`Site Manager`, `text`): Please enter the name of the site manager.
* **Site Manager Phone** (`Site Manager Phone`, `text`): Please enter the phone number for the site manager.
* **Site Manager Email** (`Site Manager Email`, `text`): Please enter the email address for the site manager.
* **Client Name** (`Client Name`, `text`): Please enter the name of the client.
* **Client Contact** (`Client Contact`, `text`): Please enter the contact information for the client.
* **Client Phone** (`Client Phone`, `text`): Please enter the phone number for the client.
* **Client Email** (`Client Email`, `text`): Please enter the email address for the client.
* **Site Type** (`Site Type`, `select_one`): Please select the type of site (e.g., residential, commercial, industrial, etc.).
* **Site Status** (`Site Status`, `select_one`): Please select the status of the site (e.g., active, inactive, under construction, etc.).
* **Comments** (`Comments`, `note`): Please enter any additional comments about the site commissioning process.
* **Additional Comments** (`Additional Comments`, `note`): Please enter any additional comments or notes about the site commissioning process.

## Tips

* Please review each field carefully and ensure that it is relevant to your specific site commissioning process.
* Use the options provided to select the most accurate status for each team's review process.
* Ensure that all required information is captured to avoid missing critical data.
* Use the form as a guide to streamline the commissioning process, but do not rely solely on this form as a substitute for actual commissioning activities, such as site visits, inspections, and testing.
