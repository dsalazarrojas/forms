# idle_resource_assessment - Help Guide
## Purpose
The idle_resource_assessment form is used by facility management personnel to track and assess the status of idle resources, such as equipment, assets, or facilities. The form helps identify opportunities for improvement and optimization, and provides a clear and consistent approach to tracking and follow-up actions.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the list of idle resources provided in the form.
2. Select the resources that are currently idle from the list.
3. Input the relevant information for each selected resource, such as its type, location, and status.
4. Determine the next action to be taken for each resource, if any.
5. Set a follow-up date and time, if necessary.
6. Add any additional follow-up notes or comments.
7. Identify the responsible person for follow-up actions.
8. Review and submit the form.

## Field-by-Field Explanation
- **Resource List** (select multiple): Select the idle resources that you want to assess.
- **Resourcetype** (text): Enter the type of resource, such as equipment, asset, or facility.
- **Loaction** (text): Enter the location of the resource.
- **Descript** (text): Enter a brief description of the resource.
- **Statu** (text): Enter the current status of the resource.
- **Nextaction** (select one): Determine the next action to be taken for the resource, if any.
- **Prioriti** (select one): Determine if the resource is a priority for follow-up action.
- **Followupdate** (date): Set a follow-up date for the resource, if necessary.
- **Followuptime** (time): Set a follow-up time for the resource, if necessary.
- **Followupnotes** (note): Add any additional follow-up notes or comments.
- **Assetlocation** (text): Enter the location of the asset.
- **Assettag** (text): Enter any asset tags or identification numbers.
- **Assetstatus** (select one): Determine the current status of the asset.
- **Followupfrequency** (select one): Determine the follow-up frequency for the asset, if any.
- **Followupreminder** (select one): Determine if a reminder is needed for follow-up actions.
- **Followupmethod** (select one): Determine the method for follow-up actions.
- **Followupdetails** (text): Enter any additional follow-up details.
- **Followupcomments** (note): Add any additional follow-up comments.
- **Followupresponsible** (select one): Identify the responsible person for follow-up actions.
- **Nextactiondate** (date): Set a follow-up date for the next action.
- **Nextactiontime** (time): Set a follow-up time for the next action.
- **Assetcategory** (text): Enter the category of the asset.
- **Assetsubcategory** (text): Enter the subcategory of the asset.
- **Assettagdescription** (text): Enter a brief description of the asset tag.
- **Assettagstatus** (select one): Determine the current status of the asset tag.
- **Assettagstatus** (select one): Determine the current status of the asset.

## Tips
- Make sure to select only relevant resources that are currently idle.
- Enter accurate and detailed information for each resource.
- Set follow-up dates and times, if necessary.
- Identify responsible persons for follow-up actions.
- Review and update the form regularly to track progress.
