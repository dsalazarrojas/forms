# Maintenance Record Verification Request - Help Guide
## Purpose
The purpose of this form is to request the verification of a maintenance record, ensuring that all necessary information is accurate and up-to-date.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the correct information about the work order you are requesting verification for.
2. Make sure to fill out all required fields, marked with a red asterisk (*) symbol.
3. If a field is optional, fill it out if you have the necessary information.
4. Double-check your information before submitting the form.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, not required): Enter a brief description of the reason for the verification request.
* **Work Order** (`work_order`, text, required*): Enter the name or ID of the work order you are requesting verification for.
* **Start Date** (`start_date`, date, required*): Enter the start date of the work order.
* **Completion Date** (`completion_date`, date, required*): Enter the completion date of the work order.
* **Equipment ID** (`equipment_id`, number, required*): Enter the ID of the equipment being maintained.
* **Location** (`location`, text, required*): Enter the location where the maintenance was performed.
* **Description** (`description`, text, required*): Enter a brief description of the maintenance performed.
* **Supporting Documents** (`supporting_documents`, text, not required): If you have any supporting documents related to the maintenance, enter them here.
