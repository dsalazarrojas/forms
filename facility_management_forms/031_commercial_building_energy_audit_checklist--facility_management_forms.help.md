# Commercial Building Energy Audit Checklist - Help Guide
## Purpose
This form is designed to help commercial building owners and operators conduct a comprehensive energy audit to assess the building's energy efficiency, identify areas for improvement, and estimate potential savings. It will help gather information about the building's energy usage, HVAC system, lighting and insulation, water heating, and overall energy efficiency.
## How To Complete This Form
To complete this form, please follow these steps:

*   Fill in the required fields with accurate information about the commercial building.
*   Select the relevant options for each field, taking care to select one or more options when required.
*   Enter the estimated annual savings from the suggested improvements in the 'Estimated Annual Savings' field (if applicable).
## Field-by-Field Explanation

*   **1. Auditor Name** (`auditor_name`, Text, Required): This field is for the name of the energy auditor who conducted the audit.
*   **2. Audit Date** (`audit_date`, Date, Required): Enter the date on which the energy audit was conducted.
*   **3. Building Name** (`building_name`, Text, Required): Enter the name or identifier of the commercial building.
*   **4. Building Address** (`building_address`, Text, Required): Enter the complete address of the building.
*   **5. Building Type** (`building_type`, Select One, Required): Select the type of commercial building (e.g., Office Building, Retail Store, Warehouse, etc.).
*   **6. Total Square Footage** (`total_square_footage`, Number, Required): Enter the building size in square feet.
*   **7. Year Built** (`year_built`, Number, Required): Enter the construction year of the building.
*   **8. HVAC System Age** (`hvac_age`, Select One, Required): Select the age of the HVAC system (e.g., Less than 5 years, 5-10 years, etc.).
*   **9. HVAC Condition** (`hvac_condition`, Select One, Required): Select the current condition of the HVAC system (e.g., Excellent, Good, Fair, etc.).
*   **10. Regular Maintenance** (`hvac_maintenance`, Select One, Required): Select whether regular maintenance is performed on the HVAC system (e.g., Yes Regular, Sometimes, No Rarely).
*   **11. Thermostat Type** (`thermostat_type`, Select One, Required): Select the type of thermostat control (e.g., Manual, Programmable, Smart Thermostat, etc.).
*   **12. Lighting Type** (`primary_lighting_type`, Select One, Required): Select the main lighting technology used in the building (e.g., LED, Fluorescent, etc.).
*   **13. Lighting Controls** (`lighting_controls`, Select Multiple, Required): Select the controls in place for lighting (e.g., Manual Switches, Occupancy Sensors, Daylight Sensors, etc.).
*   **14. Natural Light Usage** (`natural_light_usage`, Select One, Required): Select the extent of natural light usage in the building (e.g., Extensive, Moderate, Minimal, etc.).
*   **15. Insulation Quality** (`insulation_quality`, Select One, Required): Select the effectiveness of insulation in the building (e.g., Excellent, Good, Fair, etc.).
*   **16. Window Type** (`window_type`, Select One, Required): Select the type of windows installed in the building (e.g., Single Pane, Double Pane, etc.).
*   **17. Air Leakage** (`air_leakage`, Select One, Required): Select the observed air leakage in the building (e.g., None, Minimal, Moderate, etc.).
*   **18. Water Heater Type** (`water_heater_type`, Select One, Required): Select the type of water heating system used (e.g., Electric, Gas, Tankless, etc.).
*   **19. Water Heater Age** (`water_heater_age`, Select One, Required): Select the age of the water heating system (e.g., Less than 5 years, 5-10 years, etc.).
*   **20. Energy Star Equipment** (`equipment_energy_star`, Select One, Required): Select the percentage of Energy Star rated equipment in the building (e.g., 0-25%, 26-50%, etc.).
*   **21. Overall Energy Efficiency Rating** (`energy_efficiency_rating`, Select One, Required): Select the current energy efficiency rating of the building (e.g., A - Excellent, B - Good, etc.).
*   **22. Recommended Improvements** (`recommended_improvements`, Text, Required): Enter any recommended improvements or suggestions for energy efficiency.
*   **23. Estimated Annual Savings** (`estimated_savings`, Number, Optional): Enter the estimated annual savings from the suggested improvements (if applicable).
*   **24. Additional Notes** (`additional_notes`, Text, Optional): Enter any other observations or comments.

This form is designed to collect information about the commercial building's energy efficiency, and provide a comprehensive report on areas for improvement to reduce energy consumption. Please fill out this form accurately and thoroughly to get the most out of the energy audit.
