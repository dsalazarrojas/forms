# Smart Building Alert Setup Request Form - Help Guide
## Purpose

This form is used to collect information for setting up smart building alerts for facility management tasks. It helps in gathering necessary details for sending notifications and alerts to the relevant parties.

## How To Complete This Form

Before filling out this form, make sure you have the necessary information ready. Each field is important for the correct setup of the smart building alert.

## Field-by-Field Explanation

* **Request Details (1)**: Enter a brief description of your facility management request.
* **Trigger Settings (2)**: Select the trigger types that should initiate the smart building alert. You can select multiple options.
* **Notification Preferences (3)**: Enter your preferred notification method and schedule. 
* **Alert Settings (4)**: Enter any specific alert settings if required.
* **Requestor Email (5)**: Enter the email address of the person submitting the request.
* **Request Description (6)**: Enter a brief description of your request.
* **Building Location (7)**: Enter the building's location in city and state format.
* **Requestor Phone (8)**: Enter the contact phone number of the person making the request.
* **Requestor Department (9)**: Select the department associated with the request. Although not required, it's recommended for proper tracking and follow-up.
* **Requestor Name (10)**: Enter the name of the person submitting the request.
* **Trigger Type (11)**: Select the type of trigger that should initiate the alert.
* **Trigger Frequency (12)**: Enter the frequency at which the alert should be sent.
* **Trigger Interval (13)**: Enter the interval at which the alert should be sent.
* **Trigger Duration (14)**: Enter the duration for which the alert should be active.
* **Trigger Status (15)**: Select the status of the trigger. This field is optional but helps in tracking the trigger's state.

**Tips**

* Please ensure that the email address and phone number entered are correct and up-to-date.
* For trigger settings, make sure to select the correct frequency and interval for sending the alerts.
* Double-check all fields before submitting the form to avoid any errors.
