# Shared Workspace Configuration Request - Help Guide
## Purpose
The Shared Workspace Configuration Request form is used to configure workspace settings for shared workspaces. This form is designed to collect information about the needs and preferences of the workspace administrators to ensure that workspaces are properly equipped and configured to meet their requirements.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form to understand what information you need to provide.
2. Select the workspace needs that apply to your request.
3. Choose the workspace that you want to configure.
4. Select the amenities you want to request for the workspace.
5. Add any additional comments or information about the request.
6. Enter the email and phone number of the person you want to be assigned to handle your request.
7. Submit the form.

## Field-by-Field Explanation
* **Workspace Needs**: 
  * Select one or more of the provided options to describe the needs of the workspace.
* **Workspaces**: 
  * Choose the workspace for which you want to configure settings.
* **Amenities**: 
  * Select one or more of the provided options to specify what amenities you want for the workspace.
* **Dates**: 
  * Input the date you want the workspace to be configured (format: YYYY-MM-DD).
* **Work Hours**: 
  * Input the work hours for the workspace (format: HH:MM AM/PM).
* **Comments**: 
  * Add any additional comments or information about the request.
* **Email**: 
  * Enter the email of the person you want to be assigned to handle your request.
* **Phone**: 
  * Enter the phone number of the person you want to be assigned to handle your request.
* **Assigned User**: 
  * Choose the person you want to be assigned to handle your request.
