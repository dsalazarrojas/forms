# Control Room Data Collection - Help Guide
## Purpose
The Control Room Data Collection form is used to gather information about the status of control room systems, environmental conditions, and incidents that occurred during a specific shift. This information is essential for shift-to-shift handovers and for tracking system status and incident resolution.

## How To Complete This Form
1. Fill in your name and ID
2. Select the shift type and date
3. Record the start and end times of the shift
4. Report the status of primary systems, power systems, network, and security systems
5. Report environmental conditions (temperature, humidity)
6. Record any reported incidents, their severity, and resolution status
7. Indicate if maintenance was performed and describe the activities
8. Record important calls made or received
9. Log any pending actions for next shift and ongoing issues to monitor
10. Record any additional notes

## Field-by-Field Explanation
### 1. **Operator Name**: Operator Name - <name>
* A text box where you can enter your name
### 2. **Operator ID**: Operator ID - <id>
* A text box where you can enter your employee identification number
### 3. **Shift Type**: Shift Type - <shift_type>
* A dropdown menu to select the shift type (Morning, Afternoon, Night, or Rotating)
### 4. **Shift Date**: Shift Date - <shift_date>
* A date field where you can enter the date of the shift
### 5. **Shift Start Time**: Shift Start Time - <shift_start_time>
* A time field where you can enter the start time of the shift
### 6. **Shift End Time**: Shift End Time - <shift_end_time>
* A time field where you can enter the end time of the shift
### 7. **Primary Systems Status**: Primary Systems Status - <primary_systems_status>
* A dropdown menu to select the overall status of main systems (All Normal, Minor Issues, Major Issues, or Critical)
### 8. **Power Systems Status**: Power Systems Status - <power_status>
* A dropdown menu to select the status of power systems (Normal, Backup Active, Fluctuating, or Outage)
### 9. **Network Status**: Network Status - <network_status>
* A dropdown menu to select the status of network systems (Normal, Degraded, Partial Outage, or Complete Outage)
### 10. **Security Systems Status**: Security Systems Status - <security_systems_status>
* A dropdown menu to select the status of security systems (All Active, Partial Active, Maintenance Mode, or Offline)
### 11. **Temperature**: Control Room Temperature - <temperature>
* A field where you can enter the temperature in degrees
### 12. **Humidity Level**: Humidity Level - <humidity>
* A field where you can enter humidity levels as a percentage
### 13. **HVAC System Status**: HVAC System Status - <hvac_status>
* A dropdown menu to select the status of the HVAC system (Normal, Warning, Fault, or Offline)
### 14. **Were any incidents reported?**: Were any incidents reported - <incidents_occurred>
* A dropdown menu to select if any incidents were reported (True or False)
### 15. **Incident Details**: Incident Details - <incident_details>
* A text field where you can describe any incidents
### 16. **Incident Severity**: Incident Severity - <incident_severity>
* A dropdown menu to select the severity of incidents (Low, Medium, High, or Critical)
### 17. **Incident Resolution Status**: Incident Resolution Status - <incident_resolution>
* A dropdown menu to select the resolution status of incidents (Resolved, In Progress, Escalated, or Pending)
### 18. **Maintenance Performed**: Maintenance Performed - <maintenance_performed>
* A dropdown menu to select if maintenance was performed (True or False)
### 19. **Maintenance Details**: Maintenance Details - <maintenance_details>
* A text field where you can describe maintenance activities
### 20. **Systems Affected by Maintenance**: Systems Affected by Maintenance - <systems_affected>
* A text field where you can list the systems affected by maintenance
### 21. **Important Calls Made or Received**: Important Calls Made or Received - <important_calls>
* A text field where you can log important calls
### 22. **Escalations Made**: Escalations Made - <escalations>
* A text field where you can list any escalations
### 23. **Handover Notes**: Handover Notes - <handover_notes>
* A text field where you can record any notes for the next shift
### 24. **Pending Actions for Next Shift**: Pending Actions for Next Shift - <pending_actions>
* A text field where you can log any pending actions for the next shift
### 25. **Ongoing Issues to Monitor**: Ongoing Issues to Monitor - <ongoing_issues>
* A text field where you can list any ongoing issues to monitor
### 26. **Special Instructions**: Special Instructions - <special_instructions>
* A text field where you can enter any special instructions for the next shift
### 27. **Next Shift Operator Name**: Next Shift Operator Name - <next_shift_operator>
* A text field where you can enter the name of the next shift operator
### 28. **Handover Completed**: Handover Completed - <handover_completed>
* A dropdown menu to select if handover was completed (True or False)
### 29. **Additional Notes**: Additional Notes - <additional_notes>
* A text field where you can enter any other relevant information

## Tips
* Please be as detailed as possible when filling in each field, especially when describing incidents and maintenance activities.
* Use the dropdown menus to select the most accurate status for each system.
* If unsure about any field, please consult with your supervisor or a colleague.
* Ensure that you log all important calls made or received and any escalations made.
* Be thorough when recording handover notes and pending actions for next shift.
* Enter all relevant information in the additional notes field.
