# Room Entry Inspection Report - Help Guide
## Purpose
The Room Entry Inspection Report form is used to document the condition and status of a room after an inspection. It helps facility managers and maintenance teams to keep track of room maintenance, repairs, and other relevant information.

## How To Complete This Form

1. Start by selecting the room's condition using the "room_condition" field. Choose the correct option from the dropdown list to accurately describe the room's condition.
2. Upload photos of the room using the "photos" field. This will help provide visual evidence of the room's condition.
3. Enter the room number in the "room_number" field.
4. Select the date of inspection using the "date_of_inspection" field.
5. Select the time of inspection using the "time_of_inspection" field.
6. Choose the room's status using the "room_status" field.
7. Enter any additional notes or comments about the room's condition using the "notes" field.
8. Provide detailed description of the room's condition using the "room_condition_details" field.
9. Describe the uploaded photos using the "photos_description" field.
10. Enter any status details using the "room_status_details" field.
11. Write a detailed report about the room inspection using the "room_entry_inspection_report_details" field.
12. Select the date of the room inspection report using the "room_entry_inspection_report_date" field.
13. Select the time of the room inspection report using the "room_entry_inspection_report_time" field.
14. Choose the status of the room inspection report using the "room_entry_inspection_report_status" field.
15. Enter any additional notes or comments about the room inspection report using the "room_entry_inspection_report_notes" field.
16. Upload photos of the room inspection report using the "room_entry_inspection_report_photos" field.
17. Enter any status notes about the room inspection report using the "room_entry_inspection_report_status_notes" field.
18. Enter any comments about the room inspection report using the "room_entry_inspection_report_comments" field.
19. Enter any notes about the uploaded photos using the "room_entry_inspection_report_photos_notes" field.
20. Enter the room inspection report ID using the "room_entry_inspection_report_id" field.
21. Enter the assigned user using the "assigned_user" field.

## Field-by-Field Explanation

* **room_condition** (`room_condition`, select_one, required): Select the condition of the room, such as "Option 1", "Option 2", or "Option 3".
* **photos** (`photos`, select_multiple, required): Upload photos of the room to provide visual evidence of its condition.
* **room_number** (`room_number`, text, required): Enter the room number to accurately identify the room.
* **date_of_inspection** (`date_of_inspection`, date, required): Select the date of the room inspection.
* **time_of_inspection** (`time_of_inspection`, time, required): Select the time of the room inspection.
* **room_status** (`room_status`, select_one, required): Choose the room's status, such as "Available", "Occupied", or "Locked".
* **notes** (`notes`, note, required): Enter any additional notes or comments about the room's condition.
* **room_condition_details** (`room_condition_details`, text, required): Provide a detailed description of the room's condition.
* **photos_description** (`photos_description`, text, required): Describe the uploaded photos.
* **room_status_details** (`room_status_details`, text, required): Enter any status details about the room.
* **room_entry_inspection_report_details** (`room_entry_inspection_report_details`, text, required): Write a detailed report about the room inspection.
* **room_entry_inspection_report_date** (`room_entry_inspection_report_date`, date, required): Select the date of the room inspection report.
* **room_entry_inspection_report_time** (`room_entry_inspection_report_time`, time, required): Select the time of the room inspection report.
* **room_entry_inspection_report_status** (`room_entry_inspection_report_status`, select_one, required): Choose the status of the room inspection report, such as "Done", "Pending", or "Cancelled".
* **room_entry_inspection_report_notes** (`room_entry_inspection_report_notes`, note, required): Enter any additional notes or comments about the room inspection report.
* **room_entry_inspection_report_photos** (`room_entry_inspection_report_photos`, select_multiple, required): Upload photos of the room inspection report.
* **room_entry_inspection_report_status_notes** (`room_entry_inspection_report_status_notes`, text, required): Enter any status notes about the room inspection report.
* **room_entry_inspection_report_comments** (`room_entry_inspection_report_comments`, text, required): Enter any comments about the room inspection report.
* **room_entry_inspection_report_photos_notes** (`room_entry_inspection_report_photos_notes`, text, required): Enter any notes about the uploaded photos.
* **room_entry_inspection_report_id** (`room_entry_inspection_report_id`, text, required): Enter the room inspection report ID.
* **assigned_user** (`assigned_user`, text, required): Enter the assigned user for the room inspection report.
