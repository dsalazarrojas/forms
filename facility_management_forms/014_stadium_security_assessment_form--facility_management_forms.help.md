# Stadium Security Assessment Form - Help Guide
## Purpose

The Stadium Security Assessment Form is designed to assess the security readiness of a stadium. This form helps to gather information about the current state of stadium security, including the category, location, and time of assessment, and the readiness level of security measures such as emergency exit routes, emergency contact numbers, and emergency response plans. The form will be used by facility management staff to identify areas for improvement and to create a plan to increase security readiness.

## How To Complete This Form

1. Fill in the **Stadium Security Assessment Form** title.
2. Enter a **Description** of the assessment, explaining the purpose and scope of the assessment.
3. Select the **Category** (Facility Management Forms or Other).
4. Select the **Form Category** (Facility Management Forms).
5. Enter a **Form Id** (optional).
6. Enter the **Date** of the assessment.
7. Enter the **Time** of the assessment.
8. Enter the **Location** of the assessment.
9. Select the **Security Readiness** level (High, Medium, or Low).
10. Select the **Security Readiness 2** level (High, Medium, or Low).
11. Select the **Previous Assessment** status ('True' or 'False').
12. Select the **Next Assessment** status ('True' or 'False').
13. Select the **Previous Assessment 2** status ('True' or 'False').
14. Select the **Next Assessment 2** status ('True' or 'False').
15. Select the **Security Readiness 3** level (High, Medium, or Low).
16. Select the **Security Readiness 4** level (High, Medium, or Low).
17. Select the **Security Readiness 5** level (High, Medium, or Low).
18. Select the **Previous Assessment 3** status ('True' or 'False').
19. Select the **Next Assessment 3** status ('True' or 'False').
20. Select the **Security Readiness 6** level (High, Medium, or Low).
21. Select the **Security Readiness 7** level (High, Medium, or Low).
22. Select the **Next Assessment 4** status ('True' or 'False').
23. Select the **Security Readiness 8** level (High, Medium, or Low).
24. Enter any **Comments** about the assessment.

## Field-by-Field Explanation

* **Stadium Security Assessment Form** (Text, Required): Enter the title of the assessment.
* **Description** (Text, Required): Provide a brief description of the assessment.
* **Category** (Text, Required): Select the category of the assessment (Facility Management Forms or Other).
* **Form Category** (Select One, Required): Select the form category (Facility Management Forms).
* **Form Id** (Number, Optional): Enter a unique identifier for the assessment (optional).
* **Date** (Date, Required): Enter the date of the assessment.
* **Time** (Time, Required): Enter the time of the assessment.
* **Location** (Text, Required): Enter the location of the assessment.
* **Security Readiness** (Select One, Required): Select the security readiness level (High, Medium, or Low).
* **Security Readiness 2** (Select Multiple, Required): Select the security readiness levels for multiple areas (High, Medium, or Low).
* **Previous Assessment** (Select One, Optional): Select the status of the previous assessment ('True' or 'False').
* **Next Assessment** (Select One, Optional): Select the status of the next assessment ('True' or 'False').
* **Previous Assessment 2** (Select One, Optional): Select the status of the previous assessment 2 ('True' or 'False').
* **Next Assessment 2** (Select One, Optional): Select the status of the next assessment 2 ('True' or 'False').
* **Security Readiness 3** (Select One, Required): Select the security readiness level 3 (High, Medium, or Low).
* **Security Readiness 4** (Select Multiple, Required): Select the security readiness levels 4 (High, Medium, or Low).
* **Security Readiness 5** (Select One, Required): Select the security readiness level 5 (High, Medium, or Low).
* **Previous Assessment 3** (Select One, Optional): Select the status of the previous assessment 3 ('True' or 'False').
* **Next Assessment 3** (Select One, Optional): Select the status of the next assessment 3 ('True' or 'False').
* **Security Readiness 6** (Select One, Required): Select the security readiness level 6 (High, Medium, or Low).
* **Security Readiness 7** (Select One, Required): Select the security readiness level 7 (High, Medium, or Low).
* **Next Assessment 4** (Select One, Optional): Select the status of the next assessment 4 ('True' or 'False').
* **Security Readiness 8** (Select One, Optional): Select the security readiness level 8 (High, Medium, or Low).
* **Comments** (Text, Optional): Enter any comments about the assessment.
