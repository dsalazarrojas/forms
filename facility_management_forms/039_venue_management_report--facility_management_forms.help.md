This form is designed to collect information about venues that require management. The form is meant for facilities managers to report on the status of events at their venues, including any incidents that have occurred, maintenance needs, and any comments or notes they may have. This form is likely to be used for reporting and tracking purposes, and the information collected will be used to inform decisions about venue management. It's recommended that users only complete this form if they are authorized to do so and have access to the relevant information.

# Venue Management Report - Help Guide
## Purpose
The Venue Management Report form is used to collect information about events at venues and report on any incidents, maintenance needs, and comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the status of the event using the "event status" dropdown menu.
2. If there were any incidents, provide a brief description of what happened in the "incident details" text field.
3. If the venue requires maintenance, type in the necessary information in the "maintenance needs" text field.
4. Add any comments or notes about the event in the "comments" text field.
5. Enter the facility ID number if it's required or relevant to the report.

## Field-by-Field Explanation
* **Event status**: Choose from the options provided to report the current status of the event (Event Open, Event Closed, or Event Canceled).
* **Incident details**: If an incident occurred during the event, provide a brief description in this text field.
* **Maintenance needs**: If the venue requires any maintenance, type in the necessary information here.
* **Comments**: Add any additional comments or notes about the event.
* **Facility ID**: Enter the facility's ID number (this field is not required but may be necessary for tracking purposes).

## Tips
* Make sure to report accurate information to ensure that the venue is properly managed.
* If unsure about any part of the form, contact the facilities team for clarification.
* Review the form carefully before submission to ensure completeness and accuracy.
