# Access Control Unit Setup Form - Help Guide
## Purpose
This form is used to collect information about Access Control Units to ensure proper setup and configuration.

## How To Complete This Form
1. Select the relevant sections and pages that apply to your specific Access Control Unit.
2. Fill in the required fields with accurate and up-to-date information.

## Field-by-Field Explanation

### Installation Project Details
* **Site Name or Building**: Enter the location of the new unit (e.g., Building A, Floor 1).
* **Installation Contractor Name**: Enter the name of the external or internal team performing the installation.
* **Setup or Installation Date**: Enter the official completion date of the installation.

### Hardware Configuration
* **Control Unit Model Number**: Enter the unique hardware identifier of the Access Control Unit.
* **Number of Readers Connected**: Enter the total number of readers connected to the unit.
* **Unit Communication Type**: Select the type of network protocol used by the unit (e.g., Ethernet or IP, PoE, Wi-Fi, or RS-485).
* **Installed Firmware Version**: Enter the firmware version installed on the unit (e.g., v3.4.5).

### Programming and Logic
* **Access Groups Programmed**: Select all enabled access groups on the unit (e.g., General Staff, Management, Security, Cleaning or Maintenance, Emergency Services).
* **Door Logic Configuration**: Select the security vs. safety setting for the unit (e.g., Fail-Safe or Fail-Secure).

### Testing and Verification
* **Was a successful test swipe performed on all readers?**: Indicate if a functional validation was performed on all readers.
* **Did the unit sync successfully with the central server?**: Indicate if the unit successfully synchronized with the central server.

### Approvals
* **Authorized Technician Name**: Enter the name of the person performing the setup.
* **I approve the installation and configuration as documented**: Select "Approved" to indicate official site acceptance.

Note: This form is a comprehensive guide to ensure accurate and complete setup of the Access Control Unit. Please fill in all fields as required and ensure all sections are completed before moving forward.
