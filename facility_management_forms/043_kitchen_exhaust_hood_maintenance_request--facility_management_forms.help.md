# Kitchen Exhaust Hood Maintenance Request - Help Guide
## Purpose
This form is designed to collect information about the maintenance requests for kitchen exhaust hoods.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the date you would like to schedule the maintenance request.
2. Choose the type of hood that requires maintenance.
3. Indicate the status of the hood.
4. Provide a detailed description of the issue with the hood.
5. Determine if the issue is a priority.
6. Select the team member(s) you would like to be assigned to the maintenance task.
7. Select the date the hood was assigned to a team member.
8. Select the date the maintenance was completed.
9. Indicate if the maintenance was completed by the assigned team member.
10. Add any comments or notes about the maintenance request.

## Field-by-Field Explanation

* **Date** (`request_date`, date): Enter the date you would like to schedule the maintenance request.
* **Hood Type** (`hood_type`, select_one): Select the type of hood that requires maintenance (e.g., exhaust hood, ventilation system).
* **Hood Status** (`hood_status`, select_one): Indicate the status of the hood (e.g., active, inactive).
* **Issue Description** (`issue_description`, note): Provide a detailed description of the issue with the hood.
* **Priority** (`priority`, select_one): Determine if the issue is a priority (e.g., yes, no).
* **Assigned Team Member** (`assigned_team_member`, select_multiple): Select the team member(s) you would like to be assigned to the maintenance task.
* **Assigned Date** (`assigned_date`, date): Select the date the hood was assigned to a team member.
* **Completed Date** (`completed_date`, date): Select the date the maintenance was completed.
* **Completed By** (`completed_by`, select_multiple): Indicate if the maintenance was completed by the assigned team member.
* **Comments** (`comments`, note): Add any comments or notes about the maintenance request.
* **Status** (`status`, select_one): Indicate the status of the maintenance request (e.g., active, inactive).
