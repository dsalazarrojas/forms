# Facility Equipment Reallocation Request - Help Guide
## Purpose
This form is used to submit a request for equipment reallocation. Please provide the necessary information to ensure a smooth and efficient process.

## How To Complete This Form
1. Select the facility for which the equipment is currently allocated.
2. Select the new facility for which the equipment will be allocated.
3. Provide the reason for the reallocation.
4. Describe the equipment being reallocated.
5. Enter the date the reallocation is requested for.
6. Confirm which tool is assigned for the reallocation.
7. Add any additional comments about the reallocation.

## Field-by-Field Explanation

* **Facility 1 (Reallocation Request)** (`facility_1`, Select one, required): Select the current facility for which you are requesting to reallocate equipment.
* **Facility 2 (Facility Name)** (`facility_2`, Text, not required): This is the name of the new facility to which the equipment will be reallocated.
* **Reason for Reallocation (Reason for Reallocation)** (`reason_for_reallocation`, Text, not required): Explain the reason for the equipment reallocation.
* **Equipment Description (Equipment Description)** (`equipment_description`, Text, not required): Provide a brief description of the equipment being reallocated.
* **New Facility (New Facility)** (`new_facility`, Select one, not required): Select the new facility to which the equipment will be reallocated.
* **New Equipment Location (New Equipment Location)** (`new_equipment_location`, Text, not required): Enter the new location within the new facility where the equipment will be placed.
* **Date Requested (Date Requested)** (`date_requested`, Date, not required): Enter the date the reallocation is requested for.
* **Assigned Tool (Assigned Tool)** (`assigned_tool`, Text, not required): Confirm which tool is assigned for the reallocation.
* **Comments (Comments)** (`comments`, Text, not required): Add any additional comments or notes for the reallocation request.
