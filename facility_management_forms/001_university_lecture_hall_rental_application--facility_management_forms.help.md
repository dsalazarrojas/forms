# university_lecture_hall_rental_application - Help Guide

## Purpose
This form is used to request the rental of the university's lecture hall for events, meetings, or other activities. The form should only be used for internal purposes within the university community. The event organizer will need to provide details about the event to ensure that the hall is available and suitable for the event.

## How To Complete This Form
To complete this form, please fill in the necessary details about your event. The form should take only a few minutes to complete.

## Field-by-Field Explanation
* **Rental Date** (`rental_date`, date, required: false): Enter the date of the event (optional).
* **Event Name** (`event_name`, text, required: false): Enter a brief description of the event (e.g., "Lecture on AI" or "University Conference").
* **Start Time** (`start_time`, time, required: false): Enter the start time of the event. Please use the 24-hour format (e.g., 09:00 for 9am).
* **End Time** (`end_time`, time, required: false): Enter the end time of the event. Please use the 24-hour format (e.g., 17:00 for 5pm).
* **Organizer** (`organizer`, text, required: false): Enter your name and contact information.
* **Organization** (`organization`, text, required: false): Enter the name of the organization or department sponsoring the event.
* **Purpose** (`purpose`, text, required: false): Enter a brief description of the purpose of the event.
* **Rental Duration** (`rental_duration`, number, required: false): Enter the expected duration of the event in hours (e.g., 2 for 2 hours). If your event is all-day, simply enter "0".

## Tips
Please ensure that you have checked with the event coordinator or facilities manager to ensure that the hall is available on the requested date and time before submitting this form.
