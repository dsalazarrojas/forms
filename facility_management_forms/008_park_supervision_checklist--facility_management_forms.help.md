# Park Supervision Checklist - Help Guide
## Purpose
This form is designed for park supervisors to document the details of a park inspection, including the current state of the park, any hazards or issues that need to be addressed, and the names of staff or contractors present during the inspection.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant option from the "Park Inspection Details" field (field 1) that corresponds to the current state of the park.
2. Enter a photo description in the "Photo" field (field 2).
3. Enter a brief hazard report in the "Hazard Report" field (field 3).
4. Enter any notes or observations in the "Notes" field (field 4).
5. Enter the date of the inspection in the "Date" field (field 5).
6. Enter the time of the inspection in the "Time" field (field 6).
7. Select the names of staff or contractors present during the inspection in the "Staff or Contractors" field (field 7), and repeat this process in fields 8, 13, 14, 17.
8. Enter a photo description in each of the "Photo 2", "Photo 3", "Photo 4", and "Photo 5" fields (fields 9-12).
9. Select the names of staff or contractors present during the inspection in the "Staff or Contractors 2", "Staff or Contractors 3", "Staff or Contractors 4", and "Staff or Contractors 5" fields (fields 8, 13, 14, 17).

	+ Option 18: Park is in a state of emergency.

- **Photo 9 (field 19)**: Enter a brief description of the ninth photo taken during the inspection.
## Tips

* Make sure to fill out all relevant fields to ensure accurate documentation of the park inspection.
* If you are unsure about the current state of the park, select the option that best describes it.
* If you have taken multiple photos during the inspection, make sure to describe each one in the corresponding field.
* If you need to select multiple staff or contractors, make sure to select all relevant names in the corresponding field.
