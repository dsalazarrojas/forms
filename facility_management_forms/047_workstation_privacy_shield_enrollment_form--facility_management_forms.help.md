# workstation_privacy_shield_enrollment_form - Help Guide
## Purpose
The workstation privacy shield enrollment form is used to record and track information about workstations, including their status, location, and employee association. This form ensures the privacy and security of sensitive data stored on or accessed from these workstations.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the workstation(s) you want to enroll in the privacy shield by choosing from the list of available options on the first page.
2. Enter the employee workstation ID (if applicable) for the workstation(s) selected.
3. Choose the current status of the workstation(s) from the list of options.
4. Select the location of the workstation(s) from the list of options.
5. If applicable, enter the name of the employee associated with the workstation.
6. Enter the email address of the employee associated with the workstation.
7. Enter the name of the manager associated with the workstation.
8. Add any additional notes about the workstation.
9. Indicate whether the form has been submitted or not.
10. Select the person who submitted the form from the list of options.
11. Finally, enter the date the form was submitted.

## Field-by-Field Explanation
* **workstation_privacy_shield_enrollment_form**: This is the list of workstations to be enrolled in the privacy shield.
	+ This field is a select multiple field that allows you to choose the workstations you want to enroll in the privacy shield.
* **employee_workstation_id**: This field is used to enter the employee ID associated with the workstation.
	+ This field is a number field where you can enter the employee ID.
* **workstation_status**: This field is used to select the current status of the workstation.
	+ This field is a select one field with options: Active, Passive, Dormant.
* **workstation_location**: This field is used to select the location of the workstation.
	+ This field is a select one field with options: Office 1, Office 2, Office 3.
* **employee_name**: This field is used to enter the name of the employee associated with the workstation.
	+ This field is a text field where you can enter the employee's name.
* **employee_email**: This field is used to enter the email address of the employee associated with the workstation.
	+ This field is an email field where you can enter the employee's email address.
* **manager_name**: This field is used to enter the name of the manager associated with the workstation.
	+ This field is a text field where you can enter the manager's name.
* **workstation_notes**: This field is used to add any additional notes about the workstation.
	+ This field is a note field where you can enter any notes or comments about the workstation.
* **form_submitted**: This field is used to indicate whether the form has been submitted or not.
	+ This field is a select one field with options: 'True', 'False'.
* **submitted_by**: This field is used to select the person who submitted the form.
	+ This field is a select one field with options: Jimmy, Jane, John.
* **date_submitted**: This field is used to enter the date the form was submitted.
	+ This field is a date field where you can enter the date in the required format.
