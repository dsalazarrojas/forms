# Facility AI Analytics Consent Form - Help Guide

## Purpose
This form is a consent form for facility management personnel to provide their consent for the use of AI-generated data. It is meant to be a simple and straightforward way to track and record consent for AI analytics in facility management.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the form you are completing (e.g., "Facility Management Forms").
2. Describe the purpose of the form you are completing.
3. Choose an output file for the form data to be saved to.
4. Assign a tool to be used for the form data analysis (not required).
5. Provide a brief description of the form.
6. Select a category for the form (Facility AI Analytics Consent Form Category).
7. Provide a brief description of the form for the category (Facility AI Analytics Consent Form Description).
8. Select a file for the form data to be output (Facility AI Analytics Consent Form Output File).

## Field-by-Field Explanation

* **Facility Management Form Category** (`category`, `select_one`):
	+ Select the category of the form you are completing (e.g., "Facility Management Forms").
* **Facility AI Analytics Consent Form Description** (`description`, `text`):
	+ Describe the purpose of the form you are completing.
* **Output File** (`output_file`, `text`):
	+ Choose an output file for the form data to be saved to.
* **Assigned Tool** (`assigned_tool`, `text`):
	+ (Optional) Choose a tool to be used for analysis of the form data.
* **Facility AI Analytics Consent Form Category** (`facility_ai_analytics_consent_form_category`, `text`):
	+ Select a category for the form (Facility AI Analytics Consent Form Category).
* **Facility AI Analytics Consent Form Description** (`facility_ai_analytics_consent_form_description`, `text`):
	+ Provide a brief description of the form for the category.
* **Facility AI Analytics Consent Form Output File** (`facility_ai_analytics_consent_form_output_file`, `text`):
	+ Choose a file for the form data to be output (Facility AI Analytics Consent Form Output File).

## Tips
* Make sure to select the correct category and output file for your form data.
* If you are unsure about any of the fields, please contact form@gic.mx for assistance.
