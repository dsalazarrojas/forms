# HR Issue Tracking Form - Help Guide

## Purpose
The HR Issue Tracking Form is used to record, track, and monitor HR-related issues, incidents, or concerns raised by employees. This form ensures that all relevant information is gathered and documented accurately, allowing HR staff to address these issues effectively.

## How To Complete This Form
To complete the form correctly:

1. Select the employee(s) affected by the issue from the dropdown menu.
2. Choose the type of contact (Phone, Email, In Person) through which the issue was reported.
3. Select the division or department involved in the issue (HR, Marketing, Finance).
4. Identify the type(s) of issue(s) faced by the employee(s) (Issue 1, Issue 2, Issue 3).
5. Provide a brief description of the issue in the text field.
6. Enter the date the issue occurred.
7. Select the time the issue occurred (if applicable).
8. Update the issue status (Open, Closed, In Progress).
9. Enter the employee(s) assigned to resolve the issue (if applicable).
10. Add any additional notes or comments about the issue.

## Field-by-Field Explanation
- **Employee** (`Employee 1`, `Employee 2`, `Employee 3`, <type>: `select_multiple`): Select the employee(s) affected by the issue from the dropdown menu.
- **Contact Type** (`contact_type`, <type>: `select_one`): Choose how the issue was reported (Phone, Email, In Person).
- **Division** (`division`, <type>: `select_one`): Select the division or department involved in the issue (HR, Marketing, Finance).
- **Problem Type** (`problem_type`, <type>: `select_multiple`): Identify the type(s) of issue faced by the employee(s) (Issue 1, Issue 2, Issue 3).
- **Issue Description** (`issue_description`, <type>: `text`): Provide a brief description of the issue.
- **Issue Date** (`issue_date`, <type>: `date`): Enter the date the issue occurred.
- **Issue Time** (`issue_time`, <type>: `time`): Select the time the issue occurred (if applicable).
- **Issue Status** (`issue_status`, <type>: `select_one`): Update the issue status (Open, Closed, In Progress).
- **Issue Assigned** (`issue_assigned`, <type>: `text`): Enter the employee(s) assigned to resolve the issue (if applicable).
- **Notes** (`notes`, <type>: `note`): Add any additional comments or notes about the issue.
