# Recruiter Recommendation Form - Help Guide
## Purpose
The Recruiter Recommendation Form is a tool designed to collect feedback from recruiters on a candidate's performance, communication style, and collaboration skills. This form will help you provide a comprehensive assessment of the candidate's strengths and weaknesses, allowing for informed decisions and future growth opportunities.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the General Info section: Provide a brief description of the candidate.
2. Enter the Candidate Details section: Share any additional information about the candidate.
3. Complete the Communication Style, Collaboration Skills, Work Style, Work Performance, Communication Quality, and Collaboration Quality sections: Rate the candidate's skills and qualities using the provided scales (Excellent, Good, Fair, Poor).
4. Provide Feedback Comments: Share any specific comments or feedback about the candidate.
5. Enter a Feedback Score (optional): Provide an additional score to support your feedback.

## Field-by-Field Explanation

* **General Info (1)**: A brief description of the candidate. This field is required.
* **Candidate Details (2)**: Share any additional information about the candidate, such as job title, department, or work environment.
* **Communication Style (3)**: Rate the candidate's communication style using the scale: Excellent, Good, Fair, Poor. This field is optional.
* **Collaboration Skills (4)**: Rate the candidate's collaboration skills using the scale: Excellent, Good, Fair, Poor. This field is optional.
* **Work Style (5)**: Rate the candidate's work style using the scale: Excellent, Good, Fair, Poor. This field is optional.
* **Work Performance (6)**: Rate the candidate's work performance using the scale: Excellent, Good, Fair, Poor. This field is optional.
* **Communication Quality (7)**: Rate the candidate's communication quality using the scale: Excellent, Good, Fair, Poor. This field is optional.
* **Collaboration Quality (8)**: Rate the candidate's collaboration quality using the scale: Excellent, Good, Fair, Poor. This field is optional.
* **Feedback Comments (9)**: Share specific comments or feedback about the candidate. This field is optional.
* **Feedback Score (10)**: Enter a score to support your feedback. This field is optional.
