# Recruitment Process Checklist - Help Guide
## Purpose
The Recruitment Process Checklist is used to track and manage candidate applications throughout the recruitment process.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form, ensuring you have access to all the required information.
2. Fill in the required fields with accurate and relevant information for the candidate.
3. Ensure you are aware of the status of each candidate as you progress through the form.

## Field-by-Field Explanation
- **Applicant Details** (`applicant_details`, `text`, required: false): Enter any relevant details about the candidate.
- **Application Stage** (`application_stage`, `number`, required: false): Select the current stage of the application process.
- **Interview Date** (`interview_date`, `date`, required: false): Enter the date of the interview.
- **Decision Made** (`decision_made`, `select_one`, required: false): Select whether a decision has been made regarding the candidate.
  - If selected 'Yes', you are indicating that a decision has been made.
- **Candidate Status** (`candidate_status`, `select_multiple`, required: false): Select the current status of the candidate in the application process.
  - Select 'Active' or 'Inactive' to indicate the candidate's status.
- **Recruiter Comments** (`recruiter_comments`, `note`, required: false): Add any relevant comments about the candidate.
- **Contact Details** (`contact_details`, `text`, required: false): Enter any relevant contact information for the candidate.
- **Additional Information** (`additional_info`, `note`, required: false): Add any additional information about the candidate.
- **Created At** (`created_at`, `date`, required: false): Automatically populated with the date the form was created.
- **Updated At** (`updated_at`, `date`, required: false): Automatically populated with the date the form was last updated.
- **Recruiter Comments** (`recruiter_comments`, `note`, required: false): Add any additional comments from the recruiter.
- **Assigned User** (`assigned_user`, `number`, required: false): Select the user responsible for the candidate.
- **Application Type** (`application_type`, `select_multiple`, required: false): Select the type of application.
  - Select 'Yes' or 'No' to indicate the application type.
- **Interview Type** (`interview_type`, `select_multiple`, required: false): Select the type of interview.
  - Select 'Yes' or 'No' to indicate the interview type.
- **Interview Location** (`interview_location`, `select_multiple`, required: false): Select the location of the interview.
  - Select 'Yes' or 'No' to indicate the interview location.
- **Interview Time** (`interview_time`, `time`, required: false): Enter the time of the interview.
- **Interview Status** (`interview_status`, `select_one`, required: false): Select the current status of the interview.
  - Select 'Active' or 'Inactive' to indicate the interview status.
- **Candidate ID** (`candidate_id`, `number`, required: false): Enter the candidate's ID number.
- **User ID** (`user_id`, `number`, required: false): Enter the ID of the user responsible for the candidate.
- **Created By ID** (`created_by_id`, `number`, required: false): Automatically populated with the ID of the user who created the form.
- **Updated By ID** (`updated_by_id`, `number`, required: false): Automatically populated with the ID of the user who last updated the form.
- **Assigned User ID** (`assigned_user_id`, `number`, required: false): Select the ID of the user assigned to the candidate.
- **Status** (`status`, `number`, required: false): Enter the status of the candidate.
- **Application Source** (`application_source`, `select_multiple`, required: false): Select the source of the application.
  - Select 'Yes' or 'No' to indicate the application source.
- **Application Stage ID** (`application_stage_id`, `select_multiple`, required: false): Select the stage of the application.
  - Select 'Yes' or 'No' to indicate the stage of the application.

## Tips

- Select the correct options for each field as it applies to the candidate.
