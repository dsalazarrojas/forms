# Intern Performance Scorecard - Help Guide
## Purpose
The Intern Performance Scorecard is a form used to track and evaluate intern performance over a specific evaluation period. It captures key information about an intern's progress, strengths, and areas for improvement, helping managers and HR teams to assess their performance and make informed decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields for the evaluation period you are tracking (Score Type, Evaluation Frequency, Evaluation Period, and Evaluation Status).
2. Enter the required fields:
	* Employee Name
	* Manager Name
	* Completed By
	* Completed Date
	* Completed Status
	* Score Value
	* Score Date
3. Provide optional comments and descriptions for each score, if needed.
4. Submit the form to record the intern's performance scorecard.

## Field-by-Field Explanation
* **Employee ID** (`employee_id`, text, required): Unique ID assigned to the intern.
* **Manager Comments** (`manager_comments`, text, optional): Additional comments from the manager on the intern's performance.
* **Date Completed** (`date_completed`, date, optional): Date when the performance scorecard was completed.
* **Performance Score** (`performance_score`, number, required): Score assigned to the intern based on their performance.
* **Completed Date** (`completed_date`, date, required): Date when the scorecard was completed.
* **Completed Time** (`completed_time`, time, optional): Time when the scorecard was completed.
* **Evaluation Date** (`evaluation_date`, date, required): Date of the evaluation period.
* **Evaluation Time** (`evaluation_time`, time, optional): Time of the evaluation period.
* **Completed By** (`completed_by`, text, required): Name of the person who completed the scorecard.
* **Manager Name** (`manager_name`, text, required): Name of the manager evaluating the intern.
* **Employee Name** (`employee_name`, text, required): Name of the intern being evaluated.
* **Score Type** (`score_type`, select_one, required): Type of scorecard (Scorecard, Progress Report, Evaluation Report).
* **Score Description** (`score_description`, text, optional): Brief description of the score.
* **Score Date** (`score_date`, date, required): Date the scorecard was scored.
* **Score Value** (`score_value`, number, required): Value of the score assigned.
* **Evaluation Frequency** (`evaluation_frequency`, select_multiple, optional): Frequency of evaluations (Weekly, Bi-Weekly, Monthly, Quarterly, Yearly).
* **Evaluation Period** (`evaluation_period`, select_multiple, optional): Period of the evaluation (First, Second, Third).
* **Evaluation Status** (`evaluation_status`, select_multiple, optional): Status of the evaluation (Active, Not Active).
* **Evaluation Comment** (`evaluation_comment`, text, optional): Additional comments on the evaluation.
* **Completed Status** (`completed_status`, select_multiple, optional): Status of the scorecard (Completed, Not Completed).
* **Evaluation Frequency 2** (`evaluation_frequency_2`, select_multiple, optional): Second evaluation frequency.
* **Evaluation Status 2** (`evaluation_status_2`, select_multiple, optional): Second evaluation status.
* **Evaluation Date 2** (`evaluation_date_2`, date, optional): Second evaluation date.
* **Completed By 2** (`completed_by_2`, text, optional): Name of the person who completed the second evaluation.
* **Evaluation Comment 2** (`evaluation_comment_2`, text, optional): Additional comments on the second evaluation.

## Tips
- Make sure to fill out all required fields to ensure accurate and complete evaluation.
- Use the Score Type field to distinguish between different types of scorecards.
- Select the correct Evaluation Frequency, Evaluation Period, and Evaluation Status to reflect the intern's progress during the evaluation period.
- Use the Evaluation Comment fields to provide additional context and feedback on the evaluation.
