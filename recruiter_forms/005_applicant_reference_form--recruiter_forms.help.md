# Applicant Reference Form - Help Guide
## Purpose
This form is used to collect professional references from individuals who have worked with or supervised the applicant. The form is designed to assess the applicant's skills, abilities, and character.

## How To Complete This Form

To complete this form, simply follow these steps:

1. Select the type of relationship you have with the applicant.
2. Provide the reference date when you completed this form.
3. Fill out the required fields, including:
   * Reference Name
   * Reference Title
   * Reference Company
   * Reference Email
   * Relationship to Applicant
   * Relationship Duration
   * Work Context
   * Applicant Strengths
   * Technical Skills Rating
   * Communication Skills Rating
   * Teamwork Rating
   * Leadership Rating
   * Work Ethic Rating
   * Reliability Rating
   * Would Rehire
   * Recommendation Level
4. If desired, add any additional comments or notable achievements.

## Field-by-Field Explanation

* **Reference Date**: The date when this reference form is completed. This is a required field.
* **Reference Name**: Full name of the person providing the reference. This is a required field.
* **Reference Title**: Job title or position of the person providing the reference. This is a required field.
* **Reference Company**: Name of the company or organization where you worked with or supervised the applicant. This is a required field.
* **Reference Email**: Professional email address of the person providing the reference. This is a required field.
* **Reference Phone**: Contact phone number of the person providing the reference. This is not a required field.
* **Applicant Name**: Full name of the applicant being referenced. This is a required field.
* **Relationship to Applicant**: Select the type of relationship you have with the applicant. Options include:
	+ Direct Supervisor
	+ Manager
	+ Colleague
	+ Subordinate
	+ Client or Customer
	+ Professor or Instructor
	+ Other Professional Contact
* **Relationship Duration**: How long you have known or worked with the applicant. Options include:
	+ Less than 6 months
	+ 6 months to 1 year
	+ 1 to 2 years
	+ 2 to 5 years
	+ More than 5 years
* **Work Context**: Briefly describe the work context you worked with the applicant in. For example, a team project or a specific job function.
* **Applicant Strengths**: List the applicant's greatest strengths, such as communication skills or technical skills.
* **Technical Skills Rating**: Rate the applicant's technical skills. Options include:
	+ Excellent
	+ Above Average
	+ Average
	+ Below Average
	+ Poor
* **Communication Skills Rating**: Rate the applicant's communication skills. Options include:
	+ Excellent
	+ Above Average
	+ Average
	+ Below Average
	+ Poor
* **Teamwork Rating**: Rate the applicant's ability to work in a team. Options include:
	+ Excellent
	+ Above Average
	+ Average
	+ Below Average
	+ Poor
* **Leadership Rating**: Rate the applicant's leadership abilities. Options include:
	+ Excellent
	+ Above Average
	+ Average
	+ Below Average
	+ Poor
	+ Not Observed
* **Work Ethic Rating**: Rate the applicant's work ethic. Options include:
	+ Excellent
	+ Above Average
	+ Average
	+ Below Average
	+ Poor
* **Reliability Rating**: Rate the applicant's reliability. Options include:
	+ Excellent
	+ Above Average
	+ Average
	+ Below Average
	+ Poor
* **Would Rehire**: Would you rehire or work with the applicant again? Options include:
	+ Definitely Yes
	+ Probably Yes
	+ Unsure
	+ Probably No
	+ Definitely No
	+ Not Applicable
* **Notable Achievements**: If desired, describe any notable achievements or contributions of the applicant.
* **Additional Comments**: If desired, add any additional comments about the applicant.
* **Recommendation Level**: How strongly do you recommend this applicant? Options include:
	+ Highly Recommend
	+ Recommend
	+ Recommend with Reservations
	+ Cannot Recommend
* **Consent to Contact**: May we contact you for follow-up questions? Options include:
	+ True
	+ False

By filling out this form, you will be providing valuable feedback to help the applicant and our organization make informed decisions about their potential for employment or further development. Please take the time to complete this form as accurately and thoroughly as possible.
