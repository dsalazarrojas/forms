# Courier Check Out Form - Help Guide

## Purpose
The Courier Check Out Form is designed to gather critical information about deliveries, including customer details, delivery specifics, and payment status. This form will help us keep track of your deliveries efficiently and ensure that all necessary information is captured accurately.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the relevant fields with accurate information, ensuring that all required fields are completed.
2. For fields with options, select the most appropriate choice from the provided list.
3. Double-check your entries for errors before submitting the form.

## Field-by-Field Explanation

* **delivery_order_templates_form** (`delivery_order_templates_form`, note, optional): This is a note field where you can add any relevant details about the delivery order templates.
* **customer_info_form** (`customer_info_form`, text, optional): Enter the customer's information, such as their name, address, and contact number.
* **delivery_details_form** (`delivery_details_form`, text, optional): Provide a description of the delivery, including any relevant details about the package or item being delivered.
* **signature_form** (`signature_form`, text, optional): This is a field for capturing the customer's signature, which can be useful for verification purposes.
* **package_details_form** (`package_details_form`, text, optional): Enter a description of the package being delivered, including its contents and any other relevant details.
* **payment_info_form** (`payment_info_form`, text, optional): Record any payment-related information for the delivery, such as payment method or amount due.
* **delivery_address_form** (`delivery_address_form`, text, optional): Enter the delivery address, including street address, city, state, or zip code.
* **package_tracking_form** (`package_tracking_form`, text, optional): Use this field to track the package's status, such as "Delivered", "Delayed", or "Lost".
* **package_status_form** (`package_status_form`, select_one, optional): Select the current status of the package from the options: "Delivered", "Delayed", or "Lost".
* **package_notes_form** (`package_notes_form`, text, optional): Add any notes or comments about the package, if needed.
* **delivery_date_form** (`delivery_date_form`, date, optional): Enter the delivery date for the package.
* **delivery_time_form** (`delivery_time_form`, time, optional): Enter the delivery time for the package.
* **delivery_person_form** (`delivery_person_form`, text, optional): Identify the person delivering the package, if applicable.
* **delivery_phone_number_form** (`delivery_phone_number_form`, text, optional): Enter the phone number of the person delivering the package.
* **delivery_email_address_form** (`delivery_email_address_form`, email, optional): Enter the email address of the person delivering the package.
* **delivery_notes_form** (`delivery_notes_form`, note, optional): Add any additional comments or notes about the delivery.
* **delivery_terms_condition_form** (`delivery_terms_condition_form`, text, optional): Enter any terms or conditions related to the delivery, if applicable.
* **delivery_additional_info_form** (`delivery_additional_info_form`, text, optional): Provide any extra information about the delivery that may be useful to record.
* **delivery_signature_form** (`delivery_signature_form`, text, optional): Capture the signature of the delivery person, if needed.
* **delivery_payment_form** (`delivery_payment_form`, text, optional): Record any payment-related information, if applicable.
* **delivery_payment_status_form** (`delivery_payment_status_form`, select_one, optional): Select the current payment status from the options: "Paid", "Unpaid", or "Partially Paid".
* **delivery_payment_method_form** (`delivery_payment_method_form`, select_multiple, required): Select one or more payment methods from the options: "Bank", "Credit Card", or "PayPal".
* **assigned_user_form** (`assigned_user_form`, select_one, required): Select the assigned user from the options: "chatjimmy" or "Other".
* **delivery_status_form** (`delivery_status_form`, select_one, optional): Select the current status of the delivery from the options: "In Progress", "Completed", or "Delayed".
