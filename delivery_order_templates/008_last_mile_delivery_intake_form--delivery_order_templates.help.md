# Last Mile Delivery Intake Form - Help Guide

## Purpose
The Last Mile Delivery Intake Form is designed to collect information about last-mile delivery orders. This form helps in capturing key details about the order, which are essential for efficient and accurate delivery processing.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Order Template ID, if available.
2. Provide the Customer Name.
3. Enter the Contact Number of the customer.
4. Enter the customer's Email.
5. Enter the Shipping Address of the customer.
6. Select the Delivery Date for the order.
7. Choose the Delivery Time for the order.
8. Select the Delivery Time Zone for the order.
9. Enter the Delivery Location.

## Field-by-Field Explanation

* **Order Template ID** (`delivery_order_template_id`, text, optional):
	+ Enter the unique identifier for the order template, if provided.
* **Customer Name** (`customer_name`, text, optional):
	+ Enter the name of the customer.
* **Contact Number** (`contact_number`, text, optional):
	+ Enter the contact number of the customer.
* **Email** (`email`, email, optional):
	+ Enter the email address of the customer.
* **Shipping Address** (`shipping_address`, text, optional):
	+ Enter the shipping address of the customer.
* **Delivery Date** (`delivery_date`, date, optional):
	+ Select the date for the delivery.
* **Delivery Time** (`delivery_time`, time, optional):
	+ Choose the time for the delivery.
* **Delivery Time Zone** (`delivery_time_zone`, time, optional):
	+ Select the time zone for the delivery.
* **Delivery Location** (`delivery_location`, text, optional):
	+ Enter the location for the delivery.
