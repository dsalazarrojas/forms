# prophets - Help Guide
## Purpose
This guide explains how to fill out the "prophets" form for delivery information and preferences. It's crucial for ensuring that your delivery details are correctly recorded and accurately processed.

## How To Complete This Form
1. Ensure you have all the necessary details about the delivery.
2. Start with the "pickup_date" field, selecting the date of the delivery from the calendar or entering the date manually.
3. Fill in the "pickup_time" field with the planned time for pickup.
4. Provide the full address for delivery in the "delivery_address" field.
5. Enter the phone number for delivery contact in the "delivery_phone" field.
6. Optionally, if applicable, add any additional delivery instructions in the "delivery_instructions" field.
7. If you have any other delivery instructions, type them in the "delivery_instructions_other" field.
8. Enter the delivery email for contact in the "delivery_instructions_email" field.
9. If assigned, type the tool or equipment assigned for the delivery in the "assigned_tool" field.
10. Add any other pickup instructions in the "pickup_instructions" field.
11. Enter the estimated delivery time in hours in the "estimated_delivery_time" field.
12. Select 'Yes' or 'No' for the delivery method in the "delivery_method" field.
13. Select 'Yes' or 'No' for the delivery instructions select in the "delivery_instructions_select" field.
14. Optionally, enter the pickup location in the "pickup_location" field.
15. For deliveries with a different pickup time, enter that in the "pickup_time_other" field.
16. If the delivery date is different, enter it in the "pickup_date_other" field.
17. Add any delivery notes in the "notes" field.
18. If applicable, select 'Yes' or 'No' for the assigned to options in the "assigned_to" field.
19. Add any other notes in the "notes_other" field.

## Field-by-Field Explanation
- **Pickup Date (1)**: Select the date of the delivery from this field.
- **Pickup Time (2)**: Enter the planned pickup time for the delivery.
- **Delivery Address (3)**: Type or paste the full address where the delivery needs to take place.
- **Delivery Phone (4)**: Enter the contact phone number for the delivery.
- **Delivery Instructions (5)**: Provide any specific instructions for the delivery that the customer has given.
- **Other Delivery Instructions (6)**: Enter any additional delivery instructions that do not fit into the main delivery instructions field.
- **Delivery Email (7)**: Enter the email for delivery contact.
- **Assigned Tool (8)**: If the delivery is assigned a specific tool or equipment, enter it here.
- **Other Pickup Instructions (9)**: Enter any additional pickup instructions not listed in the main pickup instructions field.
- **Estimated Delivery Time (10)**: Enter the estimated delivery time in hours.
- **Delivery Method (11)**: Select 'Yes' if the delivery method is applicable or 'No' if not.
- **Delivery Instructions Select (12)**: Select 'Yes' if the delivery instructions need to be selected or 'No' if not.
- **Pickup Location (13)**: Type or paste the location of where the delivery needs to be picked up.
- **Other Pickup Time (14)**: If the delivery time is different, enter it here.
- **Other Pickup Date (15)**: If the delivery date is different, enter it here.
- **Delivery Notes (16)**: Type any additional delivery notes that you want to record.
- **Assigned to (17)**: Select 'Yes' if the delivery is assigned to someone or 'No' if not.
- **Other Notes (18)**: Type any other notes about the delivery that are not listed here.
- **Assigned To (19)**: Select who the delivery is assigned to, if applicable.
