# Mail Delivery Form - Help Guide
## Purpose
The Mail Delivery Form is designed to track mail delivery information for your organization. Use this form to record details about each mail delivery, including recipient and sender details, delivery dates and times, and any additional notes or status updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the recipient's name and any other relevant information in the "Enter recipient name" field.
2. Select the delivery date using the date picker.
3. Select the delivery time using the time picker.
4. Enter the sender's name and any other relevant information in the corresponding fields.
5. Describe the package contents in the "Package contents" field.
6. Enter the package tracking number for easy tracking.
7. Select the current delivery status from the options provided.
8. Add any additional notes about the delivery in the "Additional notes" field.
9. Enter the sender's phone number and email address.

## Field-by-Field Explanation

### Enter recipient name
* **Enter recipient name**: This field is used to record the recipient's name. Enter the name of the person or organization receiving the mail delivery.

### Delivery date
* **Delivery date**: This field is used to record the date of the mail delivery. Select a date using the calendar picker.

### Delivery time
* **Delivery time**: This field is used to record the time of the mail delivery. Select a time using the time picker.

### Enter sender name
* **Enter sender name**: This field is used to record the sender's name. Enter the name of the person or organization sending the mail delivery.

### Sender company
* **Sender company**: This field is used to record the sender's company name. Enter any additional company information about the sender.

### Sender address
* **Sender address**: This field is used to record the sender's address. Enter any additional address information about the sender.

### Package contents
* **Package contents**: This field is used to record a brief description of the package contents. Enter any relevant details about the package.

### Package tracking number
* **Package tracking number**: This field is used to record the package tracking number for easy tracking.

### Delivery status
* **Delivery status**: This field is used to record the current status of the mail delivery. Select from the options: "Pending", "In Progress", or "Delivered".

### Additional notes
* **Additional notes**: This field is used to record any additional notes or comments about the mail delivery. Enter any relevant information that may be useful to the staff.

### Phone number
* **Phone number**: This field is used to record the sender's phone number. Enter the phone number of the person or organization sending the mail delivery.

### Email
* **Email**: This field is used to record the sender's email address. Enter the email address of the person or organization sending the mail delivery.

## Tips
* Be sure to fill out all required fields to ensure accurate tracking and reporting.
* Use the calendar and time pickers to ensure accurate dates and times.
* Keep the "Package contents" field concise for easy reference.
* Use the "Delivery status" options to provide a clear status update.
* Keep "Additional notes" field brief for easy reference.
