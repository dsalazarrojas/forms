# Security System Delivery Form - Help Guide
## Purpose
This form is used to record security information for delivery purposes, including delivery orders, client company details, security product information, delivery dates and times, contact details, and special instructions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the delivery order template as required.
2. Enter the client company name and any other relevant details.
3. Specify the security product to be delivered.
4. Select a delivery date and time.
5. Provide a contact email and phone number for the client.
6. Enter the delivery address.
7. Select special delivery instructions, if any.
8. Assign a security guard to the delivery.

## Field-by-Field Explanation
### <img src="image" alt="Delivery Order Template">
* **Delivery Order Template** (`delivery_order_template`, text, optional): A template for the delivery order.
* **Client Company** (`client_company`, text, optional): Enter the client company name.
* **Security Product** (`security_product`, text, optional): Specify the security product to be delivered.
* **Delivery Date** (`delivery_date`, date, optional): Select the date of delivery.
* **Delivery Time** (`delivery_time`, time, optional): Select the time of delivery.
* **Contact Email** (`contact_email`, email, optional): Enter the client's contact email address.
* **Contact Phone** (`contact_phone`, text, optional): Enter the client's contact phone number.
* **Delivery Address** (`delivery_address`, text, optional): Enter the delivery address.
* **Special Instructs** (`special_instructs`, select_multiple, optional): Select special delivery instructions, if any.
* **Assigned Security Guard** (`assigned_security_guard`, select_one, optional): Assign a security guard to the delivery.

## Tips
* Make sure to fill out the form accurately and thoroughly.
* Double-check the delivery date and time.
* Ensure the contact email and phone number are correct.
* Enter special instructions carefully, if any.
* Assign a suitable security guard for the delivery.
