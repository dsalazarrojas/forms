# Staff Use Mobile Food Delivery Intake Form - Help Guide
## Purpose
This form is designed for staff to collect and process orders from customers. Selecting the correct template, entering customer details, choosing a pickup location, specifying the order date and time, and providing any additional order notes are all essential steps in the order processing workflow.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct delivery order template from the "Delivery Order Templates" field.
2. Choose the customer's details from the "Customer Details" field.
3. Enter the pickup location in the "Pickup Location" field.
4. Select the date and time for the order in the "Order Date Time" field.
5. Add any additional order notes in the "Order Notes" field.

## Field-by-Field Explanation

### Delivery Order Templates
* **Delivery Order Templates** (`delivery_order_templates_page`, `select_one`): Select the desired delivery order template from the dropdown menu. This template will serve as a guide for processing the order.

### Customer Details
* **Customer Details** (`customer_details`, `select_multiple`): Choose the customer's details from the options provided. This ensures that the correct customer information is associated with the order.

### Pickup Location
* **Pickup Location** (`pickup_location`, `text`): Enter the location where the order will be picked up by the customer. This will help with logistics and delivery scheduling.

### Order Date Time
* **Order Date Time** (`order_date_time`, `date`): Select the date and time for the order. This is crucial for scheduling and ensuring timely delivery.

### Order Notes
* **Order Notes** (`order_notes`, `text`): Add any additional comments or notes related to the order. This can include special requests, allergies, or other relevant information.

## Tips
* Make sure to select the correct delivery order template to ensure accurate processing.
* Double-check customer details to avoid errors.
* Enter the correct pickup location to avoid delays.
* Be precise when selecting the date and time for the order.
* Use the "Order Notes" field to capture any special requests or requirements.
