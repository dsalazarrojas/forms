# Sandwich Order Form Template - Help Guide
## Purpose
This form is designed to gather information from users about their sandwich order preferences for delivery purposes.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the type of bread you would like for your sandwich.
2. If you have any dietary restrictions (e.g., vegetarian, vegan, gluten-free), select them from the list.
3. If you have any special requests, type them in the text field.
4. Select any extra items you would like to add to your sandwich (e.g., extra cheese, extra sauce).
5. Choose how you would like your sandwich to be prepared (toasted, grilled, panini).
6. Select any toppings you would like to add to your sandwich.
7. If you would like to order extra pickles, olives, or jalapenos, select the options.
8. If you would like to order a side dish, select the option.

## Field-by-Field Explanation

* **What type of bread would you like?**: This field allows you to select the type of bread you prefer for your sandwich.
* **Do you have any dietary restrictions?**: This field allows you to select any dietary restrictions you have (e.g., vegetarian, vegan, gluten-free).
* **Would you like to order extra?**: This field allows you to type any special requests you may have for your sandwich.
* **Would you like extra cheese?**: This field is a checkbox that allows you to select if you want extra cheese on your sandwich.
* **Would you like extra sauce?**: This field is a checkbox that allows you to select if you want extra sauce on your sandwich.
* **What is your preferred delivery time?**: This field allows you to select the time you would like your sandwich delivered.
* **How would you like your sandwich to be prepared?**: This field allows you to select how you would like your sandwich to be prepared (toasted, grilled, panini).
* **Do you want to add any toppings?**: This field allows you to select any toppings you would like to add to your sandwich.
* **Would you like to order extra pickles?**: This field is a checkbox that allows you to select if you want extra pickles on your sandwich.
* **Would you like to order extra olives?**: This field is a checkbox that allows you to select if you want extra olives on your sandwich.
* **Would you like to order extra jalapenos?**: This field is a checkbox that allows you to select if you want extra jalapenos on your sandwich.
* **Would you like to order a side dish?**: This field is a checkbox that allows you to select if you want to order a side dish with your sandwich.
