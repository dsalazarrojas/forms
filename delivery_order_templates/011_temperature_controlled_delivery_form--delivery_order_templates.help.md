# temperature-controlled-delivery-form - Help Guide
## Purpose
The temperature-controlled delivery form is designed to collect information about deliveries that require temperature control during shipping. This form is intended for use with food or pharmaceutical products that need to be kept at a specific temperature range to ensure safety and quality.

## How To Complete This Form

1. Please fill out this form to create a new record for a temperature-controlled delivery.
2. Ensure that you provide accurate and complete information for each field.
3. If you need to make any changes to a existing record, please use the edit functionality to update the relevant fields.

## Field-by-Field Explanation

* **delivery_details** (Text, Optional): Enter a brief description of the delivery, including any relevant details about the products being shipped.
* **delivery_type** (Select, Optional): Select the type of delivery method (Air, Ground, etc.).
* **shipping_temperature** (Number, Optional): Enter the temperature at which the products are being shipped (e.g. 5-15°C).
* **temperature_range** (Text, Optional): Enter a specific temperature range for the products being shipped (e.g. 2-8°C).
* **package_type** (Select Multiple, Optional): Select the type of packages being shipped (Box, Package, Pallet, etc.).
* **packaging_details** (Text, Optional): Enter any special details about the packaging (e.g. insulated box).
* **delivery_time** (Date, Optional): Enter the expected delivery date and time.
* **temperature_controlled** (Select, Optional): Confirm if the delivery is temperature-controlled.
* **customer_details** (Text, Optional): Enter any customer-specific details, such as their contact information or order number.
* **notes** (Note, Optional): Enter any additional notes or comments about the delivery.

## Tips

* Please ensure that you provide accurate and complete information for each field to avoid errors or delays in processing the delivery.
* If you are unsure about any field, please contact your supervisor or the relevant department for guidance.
* This form is designed to be used for temperature-controlled deliveries, but if you need to create a non-temperature-controlled delivery record, please use the standard delivery form.
