This form template is designed to help videographers create a storyboard for a video project. The purpose of this form is to collect information about a video project, including its title, start date, end date, assigned tool, and output file name. This form is intended to be used by videographers to provide a clear and concise summary of their project.

## videoStoryboardTemplate - Help Guide

## Purpose
The videoStoryboardTemplate form is used to collect project information for video projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Form ID** (optional): This is a unique identifier for the form.
2. Enter the **Project Name**: A descriptive name for the video project.
3. Enter the **Video Title**: A brief title for the video.
4. Select the **Story Board Type**: Choose from options "Type 1" or "Type 2" to describe the story board type.
5. Enter the **Start Date**: The date the project is scheduled to start.
6. Enter the **End Date**: The date the project is scheduled to end.
7. Select the **Assigned Tool**: Choose from options "chatjimmy" or "tool2".
8. Enter the **Output File Name**: The name of the output file for the video project.

## Field-by-Field Explanation
* **Form ID** (`form_id`, number, optional):
	+ A unique identifier for the form.
* **Project Name** (`project_name`, text, optional):
	+ A descriptive name for the video project.
* **Video Title** (`video_title`, text, optional):
	+ A brief title for the video.
* **Story Board Type** (`story_board_type`, select_one, required):
	+ Choose from options "Type 1" or "Type 2" to describe the story board type.
* **Start Date** (`start_date`, date, optional):
	+ The date the project is scheduled to start.
* **End Date** (`end_date`, date, optional):
	+ The date the project is scheduled to end.
* **Assigned Tool** (`assigned_tool`, select_one, optional):
	+ Choose from options "chatjimmy" or "tool2".
* **Output File Name** (`output_file`, text, optional):
	+ The name of the output file for the video project.

## Tips
* Ensure that all required fields (Story Board Type) are completed.
* Use clear and concise labels for each field to ensure accurate information is entered.
* Review your form carefully before submission to ensure all information is correct.
