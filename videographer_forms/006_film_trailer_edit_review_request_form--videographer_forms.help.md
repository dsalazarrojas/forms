# Film Trailer Edit Review Request Form - Help Guide
## Purpose
The Film Trailer Edit Review Request Form is a document used to gather feedback and requests for edits on a film trailer. It is designed to be filled out by editors or production teams to communicate with the client or stakeholders about the status of the film trailer's edit process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Edit Status" field with the current status of the edit process. This can be "Approved", "In Progress", or "Rejected".
2. Write a brief description of the edit process in the "Edit Description" field.
3. If you have any additional notes, you can include them in the "Edit Notes" field.
4. If you have any links or files that are relevant to the edit process, you can add them in the "Edit Links" and "Edit Files" fields.
5. Make sure to repeat steps 1-4 for any additional edits or reviews you need to request.

## Field-by-Field Explanation

* **Edit Status** (`Edit Status 2`, `Edit Status 3`, etc.): This field is used to indicate the current status of the edit process. Please select one of the following options:
	+ **Approved**: The edit has been approved and is ready for release.
	+ **In Progress**: The edit is still in progress and not yet complete.
	+ **Rejected**: The edit has been rejected and needs to be revised.
* **Edit Description** (`Edit Description 2`, `Edit Description 3`, etc.): This is a brief description of the edit process. Please write a short paragraph explaining the current status and any issues or concerns.
* **Edit Notes** (`Edit Notes 2`, `Edit Notes 3`, etc.): This is an optional field for you to include any additional notes or comments about the edit process.
* **Edit Links** (`Edit Links 2`, `Edit Links 3`, etc.): This field is used to include any relevant links that are related to the edit process.
* **Edit Files** (`Edit Files 2`, `Edit Files 3`, etc.): This field is used to include any relevant files that are related to the edit process.
* **Edit Deadlines** (`Edit Deadlines 2`, `Edit Deadlines 3`, etc.): This field is used to indicate any deadlines or due dates for the edit process.

## Tips

* Make sure to keep your notes and descriptions concise and clear.
* Use the correct status and deadline to ensure accurate tracking and follow-up.
* If you have any additional requests or concerns, include them in the notes field.
* If you have any questions or need further clarification, reach out to the client or stakeholders directly.
