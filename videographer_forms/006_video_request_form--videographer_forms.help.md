# Video Request Form - Help Guide
## Purpose
The video request form is a crucial tool that helps us understand the project details and requirements before creating a video.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the project type from the provided options.
2.  Select the client from the list of available clients.
3.  Choose the video format.
4.  If applicable, enter the budget for the project.
5.  Choose the start and end dates for the project.
6.  Enter the duration of the project.
7.  Provide a detailed description of the project.
8.  Enter the name and contact information for the contact person.
9.  Enter the assigned team member to handle the project.
10.  Choose the status of the project.
11.  Select the person who created and updated the project.
12.  Enter the project URL.
13.  Enter the form URL.

## Field-by-Field Explanation
### Project Type (`project_type`)
*   **Project Type** (`Select the project type`): This field is a selection field that allows you to choose the type of project you want to create.
### Client (`client`)
*   **Client** (`Select the client`): This is a selection field that allows you to select the client that the project is for.
### Video Format (`video_format`)
*   **Video Format** (`Select the video format`): This field is used to select the video format of the project.
### Budget (`budget`)
*   **Budget** (`Optional, enter budget for the project`): This field is optional and allows you to enter the budget for the project.
### Start Date (`start_date`)
*   **Start Date** (`Select start date for the project`): This field is a date field that allows you to select the start date for the project.
### End Date (`end_date`)
*   **End Date** (`Select end date for the project`): This field is a date field that allows you to select the end date for the project.
### Duration (`duration`)
*   **Duration** (`Enter duration of the project`): This field is a number field that allows you to enter the duration of the project.
### Description (`description`)
*   **Description** (`Enter detailed description of the project`): This field is a text field where you can enter a detailed description of the project.
### Contact Name (`contact_name`)
*   **Contact Name** (`Enter contact name for the project`): This field is a text field where you can enter the name of the contact person for the project.
### Email (`email`)
*   **Email** (`Enter contact email for the project`): This field is an email field that allows you to enter the contact email for the project.
### Phone (`phone`)
*   **Phone** (`Enter contact phone number for the project`): This field is a text field that allows you to enter the contact phone number for the project.
### Assigned To (`assigned_to`)
*   **Assigned To** (`Select assigned team member for the project`): This field is a selection field that allows you to select the team member assigned to handle the project.
### Status (`status`)
*   **Status** (`Select status of the project`): This field is a selection field that allows you to select the status of the project.
### Created By (`created_by`)
*   **Created By** (`Select creator of the project`): This field is a selection field that allows you to select the person who created the project.
### Updated By (`updated_by`)
*   **Updated By** (`Select person who updated the project`): This field is a selection field that allows you to select the person who updated the project.
### Project URL (`project_url`)
*   **Project Url** (`Enter project URL`): This field is a text field where you can enter the URL for the project.
### Form Url (`form_url`)
*   **Form Url** (`Enter form URL here`): This field is a text field where you can enter the URL of the form.

**Tips**

*   Please ensure that all required fields are filled out before submitting the form.
*   Make sure to enter accurate and complete information to help us better assist you with the project.
*   If you're unsure about any field, please contact the project coordinator for guidance.
