# Videographer Training Course Selection - Help Guide
## Purpose
This form is used to select a training course for a videographer. The form asks questions related to the applicant's qualifications, interests, and availability. The goal is to determine the most suitable training course for the applicant based on their answers.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for each field. Some fields are select_one, select_multiple, or text fields.
2. Fill in the text fields (e.g., "applicant_details", "course_type_2", "course_duration", "course_level_2", "training_location", "training_availability_4") with your answers.
3. Make sure to review and submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation
* **Yes/No (1)**: Select "Yes" if you are interested in a videographer training course. This field is required.
* **Applicant Details (2)**: Enter your details (name, email, contact number, etc.) in this text field. This field is optional.
* **Videography Interest (3)**: Enter a brief description of your interest in videography. This field is required.
* **Training Availability (4)**: Select "Yes" if you are available for training. This field is required.
* **Training Availability 2 (5)**: Enter the specific dates or periods when you are available for training. This field is required.
* **Course Type (6)**: Select "Yes" if you are interested in a specific course type (e.g., basic, advanced, etc.). This field is optional.
* **Course Type 2 (7)**: Enter a specific course type (e.g., documentary, fiction, etc.). This field is required.
* **Course Duration (8)**: Enter the duration of the course (e.g., full-time, part-time, etc.). This field is required.
* **Course Level (9)**: Select "High" if you have prior experience with videography, "Low" otherwise. This field is optional.
* **Course Level 2 (10)**: Enter your current level of experience with videography. This field is required.
* **Training Availability 3 (11)**: Select "Yes" if you have access to the training location. This field is required.
* **Training Location (12)**: Enter the location where you want to receive the training. This field is required.
* **Training Availability 4 (13)**: Enter specific details about your training availability (e.g., online, in-person, etc.). This field is required.

Note: Make sure to review and submit the form once you have completed all the necessary fields.
