## Halloween Trunk Or Treat Event Interest Survey - Help Guide
## Purpose
The purpose of this survey is to gauge interest in hosting a Halloween Trunk or Treat event at our organization. This event is a fun and safe way for kids to collect candy and participate in Halloween festivities.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and fill out the information as accurately as possible.
2. Answer each question truthfully, as your response will help us plan the event accordingly.
3. Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Halloween Trunk or Treat Event Interest Survey** (`halloween_trunk_or_treat_event_interest_survey`, text, required: false):
	+ This is the title of the form, and you are already here.
* **Event Category** (`category`, select_multiple, required: false):
	+ Please select one or more categories that best describe your interest in participating in a Halloween Trunk or Treat event. This can be one or multiple of:
		- Yes, I am interested
		- No, I am not interested
* **Parent Contact Name** (`contact_name`, text, required: true):
	+ Please enter your name as the parent or guardian of the child participating in the event.
* **Parent Email** (`contact_email`, email, required: true):
	+ Please enter your email address so we can contact you with event details and updates.
* **Parent Phone Number** (`contact_phone`, text, required: true):
	+ Please enter a phone number where we can reach you with event updates and information.
* **Parent Phone Number** (`contact_phone_number`, text, required: false):
	+ This field is optional and can be used for additional contact information. If you provide it, please ensure it is accurate.
* **Event Details** (`event_details`, note, required: false):
	+ If you have any specific ideas or requests for the event, please include them here. This can be a note-taking field.
* **Event Date** (`event_date`, date, required: true):
	+ Please select a date for the event. If you have a preferred date, please provide it.
* **Event Time** (`event_time`, time, required: false):
	+ This field is optional. If you provide a time for the event, please ensure it is accurate.
* **Event Location** (`event_location`, text, required: false):
	+ If you have a preferred location for the event, please provide it.
 
## Tips
