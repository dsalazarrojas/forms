# Customer Information Form - Help Guide
## Purpose
This form is designed to collect information about customers who are planning or have planned a trip.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the fields as instructed in the sections below.
2. Provide accurate and clear information to ensure that we can effectively assist you.

## Field-by-Field Explanation

* **First Name (1)**: Enter the customer's first name. This is a text input field that requires only letters and spaces.
* **Last Name (2)**: Enter the customer's last name. This is a text input field that requires only letters and spaces.
* **Email (3)**: Enter the customer's email address. This is a field that should be in the format of `username@domain.com`.
* **Phone Number (4)**: Enter the customer's phone number. This can be a 10-digit number without any special characters.
* **Travel Dates (5)**: Select the dates of the customer's trip. You can use the date picker to select a specific start and end date for the trip.
* **Arrival Date (6)**: Select the date of arrival. This is similar to the **Travel Dates** field and allows you to specify a date of arrival for the customer.
* **Travel Type (7)**: Select the type of travel the customer will be taking, such as Air, Land, Sea, or Train.
* **Travel Agent (8)**: Choose one or multiple travel agents who will be assisting the customer. You can select from the options provided.
