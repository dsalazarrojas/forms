# Travel Package Extension Form - Help Guide
## Purpose
The Travel Package Extension Form is used to request an extension of a travel package. This form allows customers to submit their requests and additional information for package extension.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the customer's request in the "Customer request" field.
2.  Select the "Travel package id" field to choose the relevant package for extension.
3.  Provide the new end date for the package extension.
4.  Enter the customer's name in the "Customer name" field.
5.  Enter the customer's email address in the "Customer email" field.
6.  If required, enter the customer's phone number in the "Customer phone" field.

## Field-by-Field Explanation
*   **Customer request** (`customer_request`, `text`, required): Enter a brief description of the customer's request for package extension. This field is mandatory to ensure we understand their request accurately.
*   **Travel package id** (`travel_package_id`, `select_one`, optional): Select the id of the travel package you want to extend. You can choose from the options provided.
*   **New end date** (`new_end_date`, `date`, optional): Enter the new end date for the travel package extension. Please use the date format mm/dd/yyyy.
*   **Customer name** (`customer_name`, `text`, required): Enter the customer's name to whom the package extension is being requested.
*   **Customer email** (`customer_email`, `email`, required): Enter the customer's email address for communication purposes.
*   **Customer phone** (`customer_phone`, `text`, optional): If you wish to provide additional contact information for the customer, enter their phone number here.
