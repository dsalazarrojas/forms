# hajj_preparation_checklist - Help Guide
## Purpose
The Hajj Preperation Checklist is designed to help users input travel and pilgrims details for a Hajj trip. 

## How To Complete This Form
To complete this form, follow the instructions below:

1. Start by filling out the travel details.
2. Answer the questions regarding pilgrims list.
3. Add any additional pilgrims details.
4. Provide flight details and accommodation information.
5. Check if travel insurance is needed.
6. Input flight numbers and travel agency information.
7. Check if a travel agent is available.
8. Enter emergency contact information.
9. Fill out travel date and group details.
10. Input flight numbers and travel agency information for the second flight.
11. Check if a travel agent is available for the second flight.

## Field-by-Field Explanation

* **Travel Details** (`travel_details`, `text`, optional): This field is for entering general travel details, if any.
* **Pilgrims List** (`pilgrims_list`, `select_multiple`, optional): Check if there are any pilgrims traveling with you.
* **Pilgrims Details** (`pilgrims_details`, `note`, optional): Provide any additional details regarding the pilgrims.
* **Flight Details** (`flight_details`, `text`, optional): Enter any additional flight information.
* **Accommodation** (`accommodation`, `text`, optional): Enter your accommodation details.
* **Travel Insurance** (`travel_insurance`, `select_one`, optional): Check if travel insurance is needed.
* **Flight Number** (`flight_number`, `number`, optional): Enter the flight number for the first flight.
* **Travel Agency** (`travel_agency`, `select_one`, optional): Check if you are traveling with an agency.
* **Travel Agent** (`travel_agent`, `select_one`, optional): Check if you have a travel agent.
* **Emergency Contact** (`emergency_contact`, `text`, optional): Enter your emergency contact information.
* **Travel Date** (`travel_date`, `date`, optional): Enter your travel date.
* **Group Details** (`group_details`, `text`, optional): Enter any group details.
* **Flight Number 2** (`flight_number2`, `number`, optional): Enter the flight number for the second flight.
* **Travel Agency 2** (`travel_agency2`, `select_one`, optional): Check if you are traveling with an agency for the second flight.
* **Travel Agent 2** (`travel_agent2`, `select_one`, optional): Check if you have a travel agent for the second flight.

## Tips

- Please make sure to fill out all required fields.
- Double-check your information before submitting the form.
- Make sure to enter accurate information to avoid any issues during your Hajj trip.
