# cruise_registration_form - Help Guide
## Purpose

The cruise_registration_form is used to register a passenger for a cruise. It collects information about the passenger and their travel details.

## How To Complete This Form

1. Enter the passenger's name in the Passenger Name field.
2. Enter the passenger's email address in the Passenger Email field.
3. Enter the passenger's phone number in the Passenger Phone field.
4. Select the cabin type from the Cabin Type field.
5. Enter the travel date in the Travel Date field.
6. Select the arrival time in the Arrival Time field.
7. Select the departure date in the Departure Date field.
8. Select the departure time in the Departure Time field.
9. Select the cruise type from the Cruise Type field.
10. Enter the ship name in the Ship Name field.
11. Enter the passenger's address in the Passenger Address field.
12. Enter the passenger's city in the Passenger City field.
13. Enter the passenger's state in the Passenger State field.
14. Enter the passenger's zip code in the Passenger Zip field.

## Field-by-Field Explanation

* **Passenger Name**: Enter the name of the passenger.
* **Passenger Email**: Enter the email address of the passenger.
* **Passenger Phone**: Enter the phone number of the passenger.
* **Cabin Type**: Select the type of cabin the passenger will be staying in.
* **Travel Date**: Enter the date of the travel.
* **Arrival Time**: Select the arrival time of the passenger.
* **Departure Date**: Select the departure date of the passenger.
* **Departure Time**: Select the departure time of the passenger.
* **Cruise Type**: Select the type of cruise the passenger will be taking.
* **Ship Name**: Enter the name of the ship the passenger will be on.
* **Passenger Address**: Enter the address of the passenger.
* **Passenger City**: Enter the city of the passenger's address.
* **Passenger State**: Enter the state of the passenger's address.
* **Passenger Zip**: Enter the zip code of the passenger's address.

## Tips

* Ensure that all fields are properly completed before submitting the form.
* If you're unsure about any field, please ask for assistance. 
* Double-check the fields for accuracy before submitting the form.
* Make sure to enter the correct type of cabin and cruise for the passenger.
