# Skin Analysis Questionnaire - Help Guide
## Purpose
The Skin Analysis Questionnaire is a tool used to gather information about your skin type, sensitivities, habits, and products used. This data will help professionals in the beauty industry provide personalized advice and recommendations to help you achieve your desired skin care goals.

## How To Complete This Form
1. Read each question carefully and select the answer that best describes your skin.
2. Fill out the form completely, but do not worry if you're unsure about any of the options.
3. If you have any questions or concerns, feel free to ask a professional for guidance.

## Field-by-Field Explanation

### Skin Type
*   **Skin Type** (`skin_type`, select_one, required: false): This question asks about the general type of skin you have. Choose the option that best describes your skin type from the following options: Normal, Acne-prone, Aging-prone, Sensitive, Dry, or Oily.

### Skin Sensitivities
*   **Skin Sensitivities** (`skin_sensitivities`, select_one, required: false): This question asks whether you experience any skin sensitivities. Select "True" if you experience any sensitivities, and "False" if you do not.

### Skin Habits
*   **Skin Habits** (`skin_habits`, select_one, required: false): This question asks about your skin habits. Choose the option that best describes your skin habits from the following options: Morning and Night, Only morning, Only night, or Never.

### Skin Products Used
*   **Skin Products Used** (`skin_products_used`, select_multiple, required: false): This question asks about the skin products you use. Select all the products that apply to you from the following options: Moisturizer, Sunscreen, Cleanser, Mask, Exfoliant.

### Treatment Goals
*   **Treatment Goals** (`treatment_goals`, select_multiple, required: false): This question asks about your treatment goals. Select all the goals that apply to you from the following options: Acne treatment, Anti-aging, Hydration, Sun protection, Other, None.

## Tips
*   Be honest and accurate when answering the questions.
*   If you experience any skin sensitivities, be sure to mention them.
*   If you have any questions or concerns, feel free to ask a professional for guidance.
