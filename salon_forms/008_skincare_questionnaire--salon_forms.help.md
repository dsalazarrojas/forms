# Skincare Questionnaire - Help Guide
## Purpose
This form is intended to gather information about your skin type, concerns, and skincare habits to provide personalized skincare recommendations.

## How To Complete This Form
To complete this form, simply select the options that apply to you from the dropdown menus. You can select multiple options for each field by holding down the Ctrl key (or Command key on a Mac) and clicking on the options.
