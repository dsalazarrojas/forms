# Beauty Color Match Form - Help Guide

## Purpose
This form is designed to help beauty salons match clients with the best possible hair or makeup color recommendations based on their individual characteristics.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the client's name.
2. Select a visit date for the client.
3. Choose the type of service desired (Makeup Color Match or Hair Color Match).
4. Provide information about the client's skin tone, undertone, eye color, and hair color.
5. Answer questions about the client's hair condition, previous color or chemical treatments, and hair texture.
6. Indicate the client's sun exposure level, color maintenance commitment, and any product allergies.
7. Provide any additional comments or notes for the colorist.
8. Review and approve the recommended color.

## Field-by-Field Explanation

* **Client Name** (`Client Name`, text, required): Enter the client's name.
* **Visit Date** (`Visit Date`, date, required): Select a date for the visit.
* **Service Type** (`Service Type`, select_one, required): Choose the type of service desired (Makeup Color Match or Hair Color Match).
* **Skin Tone** (`Skin Tone`, select_one, required): Select the client's skin tone (Fair, Light, Medium, Olive, Tan, Deep).
* **Skin Undertone** (`Skin Undertone`, select_one, required): Select the client's skin undertone (Warm, Cool, Neutral, Mixed).
* **Eye Color** (`Eye Color`, select_one, required): Select the client's eye color (Blue, Green, Brown, Hazel, Amber, Gray).
* **Hair Color** (`Hair Color`, select_one, required): Select the client's current hair color (Black, Dark Brown, Brown, Light Brown, Blonde, Red, Gray, Multi-colored).
* **Desired Hair Color** (`Desired Hair Color`, text, required): Enter the client's desired hair color.
* **How Drastic is the Color Change** (`How Drastic is the Color Change`, select_one, required): Select how drastic the color change should be (Same Family - Slight Shift, Same Family - Noticeable Change, Major Shift, Complete Transformation).
* **Hair Condition** (`Hair Condition`, select_one, required): Select the client's hair condition (Damaged, Weak, Fair, Healthy, Excellent).
* **Previous Color or Chemical Treatments** (`Previous Color or Chemical Treatments`, text, required): Enter any previous color or chemical treatments.
* **Hair Texture** (`Hair Texture`, select_one, required): Select the client's hair texture (Straight, Wavy, Curly, Coily).
* **Color Maintenance Commitment** (`Color Maintenance Commitment`, select_one, required): Select how often the client is willing to return for touch-ups (Monthly, Every 6 Weeks, Every 2 Months, Every 3 Months, Minimal).
* **Sun Exposure Level** (`Sun Exposure Level`, select_one, required): Select the client's sun exposure level (Minimal, Moderate, High).
* **Product Allergies** (`Product Allergies`, text, optional): Enter any product allergies.
* **Colorist Notes and Recommendations** (`Colorist Notes and Recommendations`, text, optional): Enter any professional assessment or recommendations from the colorist.
* **Client Approves Recommended Color** (`Client Approves Recommended Color`, select_one, required): Select whether the client approves the recommended color (Yes, No, Want to Consult Further).

## Tips
* Make sure to select the correct service type (Makeup Color Match or Hair Color Match).
* Enter accurate and detailed information about the client's characteristics and preferences.
* Review and approve the recommended color to ensure it meets the client's needs.
