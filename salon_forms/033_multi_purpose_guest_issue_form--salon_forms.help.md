# Multi Purpose Guest Issue Form - Help Guide

## Purpose
The Multi Purpose Guest Issue Form is a tool used to collect feedback from guests who have had an issue with their visit to the salon. This form is designed to be multi-purpose, allowing guests to report issues with the associate, service, or facility.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have visited the salon and are reporting an actual issue.
2. Select the relevant issue(s) that you experienced during your visit.
3. Provide a clear description of the issue(s) you experienced.
4. If you were charged incorrectly, specify how you were charged.
5. If you've already taken any action to resolve the issue, describe what you did.

## Field-by-Field Explanation

* **Unsatisfied With Associate** (`unsatisfied_with_associate`, text, optional):
    This field is used to report any issues with the associate who served you. If you were not satisfied with the service you received, please describe what specifically was not to your liking.
* **Service Issue** (`service_issue`, select_one, optional):
    Please select 'Yes' if you experienced an issue with the service provided. This could include any issues with the service itself, the quality of service, or communication.
* **Unsatisfied With Service** (`unsatisfied_with_service`, text, optional):
    This field is used to provide a clear description of any service issues you experienced.
* **Facility Issue** (`facility_issue`, select_multiple, optional):
    Please select all issues that apply to the facility (e.g. ambiance, cleanliness, availability).
* **Other Guest Issue** (`other_guest_issue`, text, optional):
    If there were any issues not listed above, please describe them here.
* **Issues Resolved/Action Taken** (`issues_resolved_action_taken`, text, optional):
    If you've already taken any action to resolve the issue, please describe what you did.
* **Guest Charged Incorrectly** (`guest_charged_incorrectly`, select_one, optional):
    Please select 'Yes' if you were charged incorrectly. If you were charged incorrectly, please provide details on how you were charged.
* **Unsatisfied With Facility** (`unsatisfied_with_facility`, text, optional):
    This field is used to report any issues with the facility itself. If you were not satisfied with the facility, describe what specifically was not to your liking.
* **Touch Up Form** (`touch_up_form`, text, optional):
    If you would like to provide a touch-up form for your next visit, please provide your desired services and dates.

## Tips

* Be as specific as possible when describing the issue(s) you experienced.
* If you've already taken any action to resolve the issue, please provide a clear description of what you did.
* If you were charged incorrectly, please provide details on how you were charged.
