# Skin Client Record Form - Help Guide
## Purpose
The "Skin Client Record Form" is a tool designed to collect and store information about skin-related clients. This form captures various details about the client's skin condition, visits, services, and recommendations. It aims to create a comprehensive record for skin care professionals, ensuring accurate and up-to-date information about each client.

## How To Complete This Form
To complete the "Skin Client Record Form", follow these steps:

1. Ensure you have all the necessary permissions and access to use this form.
2. Review the form's fields and understand their significance.
3. Enter the client's personal details in the following fields:
	* **Client Name**: Enter the client's full name.
	* **Date Of Visit**: Record the date of the client's visit.
	* **Client Number**: Enter a unique number to identify the client.
	* **Service Provider**: Select the service provider from the provided list.
4. Provide the client's contact information:
	* **Contact Number**: Enter the client's phone number.
	* **Client EMail**: Enter the client's email address.
5. Add notes and recommendations:
	* **Notes**: Provide any additional comments about the client's skin condition and visit.
	* **Recommended Products**: Select and list recommended products for the client.
	* **Recommended Services**: Select and list recommended services for the client.
	* **Recommended Providers**: Select and list recommended providers for the client.
	* **Recommended Appointments**: Select and list recommended appointments for the client.
	* **Recommended Reviews**: Select and list recommended reviews for the client.
	* **Recommended Articles**: Select and list recommended articles for the client.
	* **Recommended Videos**: Select and list recommended videos for the client.
	* **Recommended Websites**: Select and list recommended websites for the client.
	* **Recommended Books**: Select and list recommended books for the client.
	* **Recommended Blogs**: Select and list recommended blogs for the client.
