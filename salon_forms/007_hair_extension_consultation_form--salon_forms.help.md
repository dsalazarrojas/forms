# Hair Extension Consultation Form - Help Guide
## Purpose
The Hair Extension Consultation Form is designed to gather information about your hair extension needs, preferences, and details. This information will help our stylists understand your requirements and provide the best possible experience for you.

## How To Complete This Form

1. Read each question carefully and answer honestly.
2. Select the relevant answers for each question.
3. Fill in the required fields (marked as "required") with accurate and complete information.
4. Leave optional fields blank if not applicable.

## Field-by-Field Explanation

* **Hair type** (`hair_extension_consultation_form_1`, Select One, required)
	+ Please select the type of hair you have. This will help us understand your natural hair texture.
* **Desired hair length** (`hair_extension_consultation_form_2`, Select Multiple, optional)
	+ If you have a preference for your hair length, please select the options that apply to you.
* **Color** (`hair_extension_consultation_form_3`, Text, required)
	+ Enter your natural hair color.
* **Previous hair treatments** (`hair_extension_consultation_form_4`, Text, optional)
	+ If you have undergone any previous hair treatments, please describe them briefly.
* **Previous hair procedures** (`hair_extension_consultation_form_5`, Select One, required)
	+ Please select "Yes" if you have undergone any previous hair procedures.
* **Allergies** (`hair_extension_consultation_form_6`, Select Multiple, optional)
	+ If you have any allergies, please select the relevant options.
* **Notes** (`hair_extension_consultation_form_7`, Note, optional)
	+ If you have any additional comments or information you'd like to share, please use this field.
* **Phone** (`hair_extension_consultation_form_8`, Text, required)
	+ Enter your phone number so we can contact you.
* **Email** (`hair_extension_consultation_form_9`, Email, required)
	+ Enter your email address so we can communicate with you.
* **Date** (`hair_extension_consultation_form_10`, Date, optional)
	+ If you have a preferred date for your consultation, please select it.
* **Time** (`hair_extension_consultation_form_11`, Time, optional)
	+ If you have a preferred time for your consultation, please select it.
* **Hair extension type** (`hair_extension_consultation_form_12`, Select One, optional)
	+ Please select the type of hair extension you're interested in.
* **Additional info** (`hair_extension_consultation_form_13`, Note, optional)
	+ If you have any additional information you'd like to share, please use this field.
* **Hair** (`hair_extension_consultation_form_14`, Text, required)
	+ Enter your hair type (e.g., curly, straight, etc.).
* **Consultation** (`hair_extension_consultation_form_15`, Text, required)
	+ Briefly describe your consultation preferences.
* **Extension style** (`hair_extension_consultation_form_16`, Text, optional)
	+ If you have a preferred style for your hair extension, please describe it.
* **Extension type** (`hair_extension_consultation_form_17`, Text, optional)
	+ If you have a preferred type of hair extension, please describe it.
* **Additional comments** (`hair_extension_consultation_form_18`, Note, optional)
	+ If you have any additional comments or information, please use this field.
* **Client** (`hair_extension_consultation_form_19`, Text, required)
	+ Enter your name and contact information.
* **Salon** (`hair_extension_consultation_form_20`, Text, optional)
	+ If you have a preferred salon, please enter the name.
* **Address** (`hair_extension_consultation_form_21`, Text, optional)
	+ If you have a preferred address for your consultation, please enter it.
* **City** (`hair_extension_consultation_form_22`, Text, optional)
	+ If you have a preferred city for your consultation, please enter it.
* **State** (`hair_extension_consultation_form_23`, Text, optional)
	+ If you have a preferred state for your consultation, please enter it.
* **Zip** (`hair_extension_consultation_form_24`, Text, optional)
	+ If you have a preferred zip code for your consultation, please enter it.
* **Country** (`hair_extension_consultation_form_25`, Text, optional)
	+ If you have a preferred country for your consultation, please enter it.

Note: The fields marked as required are mandatory and must be filled in. If you're unsure about any of the fields, please feel free to ask our stylists for guidance.
