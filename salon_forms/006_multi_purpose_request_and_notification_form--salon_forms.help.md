# multi_purpose_request_and_notification_form - Help Guide
## Purpose
This form is designed to collect information about various requests and notifications from users. It's intended to be a multi-purpose form, allowing users to input different types of requests such as multi-purpose requests, wax supply requests, facility maintenance requests, and in-center delivery notifications.

## How To Complete This Form
To complete this form, simply fill in the relevant fields with the required information. You can input information in any or all of the fields as needed.

## Field-by-Field Explanation
### Multi-Purpose Request (1)
* **Multi-Purpose Request**: This field is for users to describe their multi-purpose requests in detail.
### Waxer Supply Request (2)
* **Waxer Supply Request**: This field is for users to specify their waxer supply requests, if any.
### Facility Maintenance Request (3)
* **Facility Maintenance Request**: This field is for users to describe their facility maintenance requests.
### Wax Room Maintenance Request (4)
* **Wax Room Maintenance Request**: This field is for users to specify their wax room maintenance requests, if any.
### In-Center Delivery Notification (5)
* **In-Center Delivery Notification**: This field is for users to provide any in-center delivery notifications.

## Tips
* Please provide as much detail as possible in each field to ensure accurate tracking and management of requests.
* If you have any questions or concerns, you can contact the form creator at form@gic.mx.
