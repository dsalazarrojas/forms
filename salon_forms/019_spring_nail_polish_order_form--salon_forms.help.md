# Spring Nail Polish Order Form - Help Guide
## Purpose
The Spring Nail Polish Order Form is used to collect information for a spring nail polish order.
## How To Complete This Form
To complete this form, follow the instructions below:

1.  Fill out the required fields with accurate and relevant information.
2.  Select the correct options for the "Order Details", "Nail Polish Size", and "Nail Type" fields.
3.  Enter the correct date and time for the "Date" and "Time" fields.
4.  Ensure that you sign off on your submission with your name in the "Customer Signature" field.
5.  Review all information for accuracy before submission.

## Field-by-Field Explanation

*   **User Details**: This field is optional and is meant to store any additional details you may want to provide about the user who is ordering the spring nail polish.
    *   **Contact Information**: This field is required and is meant to store the customer's contact information, including email and phone number.
    *   **Order Details**: This field is required and is a select multiple option field where you can select the color of the nail polish you want to order.
    *   **Nail Polish Size**: This field is required and is a select one option field where you can select the size of the nail polish you want to order.
    *   **Nail Type**: This field is required and is a select multiple option field where you can select the type of nail polish you want to order.
    *   **Order Notes**: This field is optional and is meant to store any additional notes about the order.
    *   **Special Instructions**: This field is optional and is meant to store any special instructions for the order.
    *   **Total Cost**: This field is required and is a number field where you can enter the total cost of the order.
    *   **Customer Signature**: This field is optional and is required for the customer to sign off on their order.
    *   **Technician Signature**: This field is required and is where the technician signs off on their completion of the order.
    *   **Date**: This field is required and is a date field where you can enter the date you submitted the form.
    *   **Time**: This field is required and is a time field where you can enter the time you submitted the form.
    *   **Form ID**: This field is required and is a unique ID for the form submission.
    *   **Category**: This field is optional and is a select one option field where you can select the category of the order.
    *   **Description**: This field is optional and is meant to store a description of the order.
    *   **Assigned Tool**: This field is optional and is meant to store the tool used to complete the order.
    *   **Assigned User**: This field is optional and is meant to store the user who was assigned to complete the order.
    *   **Created By**: This field is optional and is meant to store the user who created the order.
    *   **Created Date**: This field is optional and is a date field where you can enter the date the order was created.
    *   **Updated By**: This field is optional and is meant to store the user who updated the order.
    *   **Updated Date**: This field is optional and is a date field where you can enter the date the order was updated.
    *   **Submitted At**: This field is optional and is a date field where you can enter the date the order was submitted.
    *   **Submitted By**: This field is optional and is meant to store the user who submitted the form.
    *   **Submitted User**: This field is optional and is meant to store the user who submitted the form.
    *   **Submitted Tool**: This field is optional and is meant to store the tool used to submit the form.
## Tips

*   Please review all information for accuracy before submission.
*   Please sign the form with your name after completing the fields.
*   Ensure that you complete all required fields.

This help guide should be followed to ensure accurate and complete submission of the Spring Nail Polish Order Form. Please take your time and fill out the form carefully, making sure to review all fields before submission. If you have any questions or concerns, please feel free to contact us.
