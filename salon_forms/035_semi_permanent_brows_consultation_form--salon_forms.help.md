# semi-permanent_brows_consultation_form - Help Guide
## Purpose
This form is used to collect information from clients for semi-permanent brow consultations.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the basic information in the "Salon Forms" field.
2. Enter your intake information in the "Intake Forms" field.
3. Provide details specific to the semi-permanent brow consultation in the "Semi Permanent Brows Consultation Form" field.
4. If applicable, select the assigned tool for the consultation.
5. Enter the form ID(s) in the "Form IDs" field.
6. Upload the output file in the "Output File" field.

## Field-by-Field Explanation
- **Salon Forms** (`salon_forms`, text, required: false): This field is for basic information about the salon, such as location and contact number.
- **Intake Forms** (`intake_forms`, text, required: false): Please enter any relevant intake information, such as medical conditions or allergies.
- **Semi Permanent Brows Consultation Form** (`semi_permanent_brows_consultation_form`, text, required: false): This field is for details specific to the semi-permanent brow consultation, such as desired brow shape and color.
- **Assigned Tool** (`assigned_tool`, text, required: false): If applicable, select the assigned tool for the consultation.
- **Form IDs** (`form_ids`, number, required: false): Enter the relevant form ID(s) for the consultation.
- **Output File** (`output_file`, text, required: false): Upload the output file for the consultation.
