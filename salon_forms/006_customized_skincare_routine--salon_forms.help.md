# Customized Skincare Routine - Help Guide
## Purpose
The "Customized Skincare Routine" form is designed to collect information from clients about their individual skincare preferences, skin type, and any allergies or medical conditions that may affect their skincare routine. This information will be used to provide personalized skincare recommendations for the client.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions on this form to the best of your ability.
2. If you have any allergies or medical conditions, please provide as much detail as possible in the "Allergies" and "Medical History" sections.
3. If you have any previous skincare routines, please provide information about them in the "Current Skincare" section.
4. Answer the other questions on the form to the best of your ability, using the options provided.

## Field-by-Field Explanation

* **Client Preferences (1)**: Please provide a brief description of your preferences, such as any skincare concerns or issues you are experiencing.
* **Skin Type (2)**: Please select your skin type from the options provided: Acne, Combination, Dry, Oily.
* **Product Use (3)**: Indicate how often you use skincare products, choosing from: True, False, Rarely, Never.
* **Skin Condition (4)**: Please select any conditions you are experiencing, such as Acne, Aging, Eczema, Hyperpigmentation.
* **Allergies (5)**: If you have any allergies, please list them here.
* **Medical History (6)**: If you have any medical conditions, please provide a brief description.
* **Current Skincare (7)**: If you have any current skincare routines, please provide a brief description.
* **Custom Recommendations (8)**: If you would like customized recommendations for your skincare routine, please select this option.
* **Skin Sensitivities (9)**: If you experience any skin sensitivities, please select the options that apply.
* **Client Concerns (10)**: If you have any concerns about your skincare routine, please select the options that apply.

## Tips
- Please answer the questions honestly and to the best of your ability.
- If you are unsure about any of the options, please ask your skincare professional for guidance.
- If you have any further questions or concerns, please do not hesitate to contact us.
