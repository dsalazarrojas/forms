## HR Case Note Submission - Help Guide

## Purpose
This form is used to submit a Human Resources (HR) case note for an employee incident. It provides a platform for recording and tracking incidents, allowing HR to efficiently manage and follow up on cases.

### How To Complete This Form

1. Fill out the form with the required and optional information for the incident.
2. Ensure you fill in all necessary fields as indicated by the required label (e.g., "required: true").
3. Select attachments and case manager from the provided options.

### Field-by-Field Explanation

* **Employee ID (`employee_id`, text, required: false):**
	+ Enter the employee's unique identification number to associate the case with the correct employee.
* **Employee Name (`employee_name`, text, required: false):**
	+ Enter the name of the employee involved in the incident.
* **Incident Description (`incident_description`, text, required: false):**
	+ Provide a detailed description of what occurred, including any relevant facts and circumstances.
* **Actions Taken (`actions_taken`, text, required: false):**
	+ Describe the actions taken to address the incident, including any steps or resolutions implemented.
* **Attachments (`attachments`, select_multiple, required: false):**
	+ Check if attachments are related to the case, such as photos or documents.
* **Case Manager (`case_manager`, select_one, required: false):**
	+ Select the manager responsible for handling the case.
* **Case Status (`case_status`, select_one, required: false):**
	+ Choose the current status of the case, either "Open" or "Closed".
* **Case Notes (`case_notes`, text, required: false):**
	+ Add any additional comments or notes about the case.
* **Case Date (`case_date`, date, required: false):**
	+ Enter the date the case was recorded or last updated.
* **Case Time (`case_time`, time, required: false):**
	+ Enter the time the case was recorded or last updated.

## Tips

* Ensure all required fields are filled in before submitting the form.
* Double-check your answers for accuracy and completeness.
* Use the "Attachments" field to include any relevant supporting documents.
* Select the correct case manager to ensure proper handling of the case.

This guide is intended to assist you in understanding how to complete the HR Case Note Submission form efficiently. If you have any further questions or concerns, please contact the HR department.
