# Employee Conflict Mediation Program Application Form - Help Guide
## Purpose
This form is used to submit an application for the conflict mediation program. The program aims to resolve conflicts between employees in a fair and constructive manner.

## How To Complete This Form
To complete this form, follow these steps:

1. **Complete each section carefully and accurately**. Make sure to provide all required information.
2. Ensure you have your manager's consent before submitting this form (questions 8 and 9).

## Field-by-Field Explanation
### **Conflict Details** (`conflict_details`, text, required: false)
* This section is optional, but if you choose to use it, please provide a brief description of the conflict you are experiencing.

### **Employee Name** (`employeeName`, text, required: true)
* Enter your full name as it appears on your personnel record.

### **Manager Name** (`managerName`, text, required: true)
* Enter your manager's name as it appears on their personnel record.

### **Conflict Start Date** (`conflictStart`, date, required: true)
* Enter the date when the conflict started.

### **Conflict End Date** (`conflictEnd`, date, required: false)
* If the conflict is ongoing, you can leave this field blank. Otherwise, enter the date when the conflict ended.

### **Mediation Outcome** (`meditationOutcome`, select_one, required: true)
* Select the outcome of the conflict mediation session from the options below:
	+ Conflict Resolved
	+ Conflict Ongoing
	+ Other
	+ Not Applicable

### **Mediation Description** (`conflictDescription`, text, required: false)
* This field is optional, but if you choose to use it, please provide a brief description of the conflict resolution process.

### **Manager Consent** (`managerConsent`, select_multiple, required: true)
* Select 'True' if you have obtained your manager's consent for conflict mediation. Select 'False' otherwise.

### **Employee Consent** (`employeeConsent`, select_multiple, required: true)
* Select 'True' if you consent to participate in a conflict mediation session. Select 'False' otherwise.

## Tips
* Ensure that both you and your manager consent to conflict mediation before submitting this form.
* If you have any questions or concerns, please reach out to your supervisor or HR representative.
* Conflict mediation is a confidential process.
