# Hospital Needle Stick Injury Incident Report Form - Help Guide
## Purpose
The purpose of this form is to document and report incidents involving needle stick injuries in a hospital setting.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the date of the incident using the calendar icon.
2. Enter the location where the incident occurred.
3. Select the type of injury that occurred (e.g. Nerve, Tendons/Muscles, etc.).
4. Enter a brief description of the incident.
5. If applicable, enter the number of needles involved.
6. If applicable, enter the total number of needles involved.
7. Check if immediate safety precautions were taken.
8. If immediate safety precautions were taken, enter a brief description.
9. If long-term safety precautions are required, enter a brief description.
10. Select the location of the injury (e.g. Left, Right, etc.).
11. If not required, enter the date of the injury.
12. If not required, enter the time of the injury.
13. Enter a brief description of the injury location.
14. Enter a brief description of any necessary safety precautions.
15. If necessary, enter any additional safety precautions taken.
16. Enter a brief description of any additional safety precautions taken.
17. Enter any additional comments or information about the incident.

## Field-by-Field Explanation

* **Incident Date**: The date on which the needle stick injury occurred.
* **Incident Location**: The location where the needle stick injury occurred.
* **Sharps Injury Type**: The type of injury that occurred (e.g. Nerve, Tendons/Muscles, etc.).
* **Sharps Injury Description**: A brief description of the incident.
* **Sharps Number**: The number of needles involved (if applicable).
* **Sharps Total Number**: The total number of needles involved (if applicable).
* **Sharps Safety Precautions**: Check if immediate safety precautions were taken.
* **Sharps Safety Precautions Immediate Action**: If immediate safety precautions were taken, enter a brief description.
* **Sharps Safety Precautions Long Term Action**: If long-term safety precautions are required, enter a brief description.
* **Sharps Injury Location**: The location of the injury (e.g. Left, Right, etc.).
* **Sharps Injury Date**: The date of the injury (if not required).
* **Sharps Injury Time**: The time of the injury (if not required).
* **Sharps Injury Location Description**: A brief description of the injury location.
* **Sharps Safety Precautions Description**: A brief description of any necessary safety precautions.
* **Sharps Safety Precautions Other**: Additional comments or information about the incident.
* **Sharps Safety Precautions Immediate Description**: A brief description of any immediate safety precautions taken.
* **Sharps Safety Precautions Long Description**: A brief description of any long-term safety precautions taken.
