# Harassment Incident Form - Help Guide

## Purpose
The purpose of this form is to report incidents of harassment that occur within the workplace. This will help maintain a safe and respectful work environment.

## How To Complete This Form
1. Fill out this form for each incident you would like to report.
2. Answer each question as thoroughly as possible.
3. Make sure to include all necessary details to describe the incident.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, date, required: false): Enter the date when the incident occurred.
* **Incident Description** (`description`, text, required: false): Describe the incident as accurately as possible, including the actions that were taken by the harasser and any witness statements.
* **Reporter** (`reporter`, select_one, required: false): Select the person who reported the incident.
* **Harasser** (`harasser`, select_one, required: false): Select the person who was harassing.
* **Witness** (`witness`, select_multiple, required: false): Select all witnesses to the incident.
* **Location** (`location`, text, required: false): Enter the location where the incident occurred.
* **Incident Type** (`incident_type`, select_one, required: false): Select the type of harassment that occurred (verbal, physical, emotional).
* **Incident Details** (`incident_details`, text, required: false): Provide any additional details about the incident.
* **Witness Statement** (`witness_statement`, text, required: false): If a witness was present, describe their statement.
* **Witness Statement 2** (`witness_statement_2`, text, required: false): If a second witness was present, describe their statement.
* **Witness Statement 3** (`witness_statement_3`, text, required: false): If a third witness was present, describe their statement.
* **Witness Statement 4** (`witness_statement_4`, text, required: false): If a fourth witness was present, describe their statement.

## Tips
* Be thorough and accurate when filling out this form.
* If you have any additional questions or concerns, please contact your HR representative.
* This form is confidential and only accessible to authorized personnel.
