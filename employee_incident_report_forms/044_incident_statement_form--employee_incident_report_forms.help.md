# incident-statement-form - Help Guide

## Purpose
This form is for reporting incidents that require a detailed statement from employees, providing a structured and organized framework for submitting information and details about the incident. This form helps ensure that all relevant information is collected and documented consistently, making it easier to analyze and respond to incidents.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter general information about the incident in the **General Information** field.
2. Select the type of incident (e.g., Police Report, Accident, Other) from the **Incident Type** field.
3. Provide the location of the incident in the **Incident Location** field.
4. Enter the date and time of the incident in the **Incident Date** and **Incident Time** fields, respectively.

## Field-by-Field Explanation

### General Information
* **General Information** (`title`, `text`, required: **false**): Enter a brief description of the incident, including any relevant details.

### Incident Type
* **Incident Type** (`select_one`, required: **false**): Select the type of incident from the options provided. Options include:
	+ Police Report
	+ Accident
	+ Other

### Incident Location
* **Incident Location** (`text`, required: **false**): Provide the location where the incident occurred, including the city, state, or country if applicable.

### Incident Date
* **Incident Date** (`date`, required: **false**): Enter the date of the incident using the YYYY-MM-DD format.

### Incident Time
* **Incident Time** (`time`, required: **false**): Enter the time of the incident using the 24-hour clock format (HH:MM).
