Fraud Report Form Template - Help Guide
====================================

## Purpose
This form is designed to capture information about potential fraud incidents in the workplace. It helps to report fraudulent activities, gather details, and take appropriate actions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the fields as instructed.
2. Select the relevant options for each field.
3. Make sure to provide as much detail as possible in the "Description" field.
4. Select the "Submit" option to send the report to the relevant authorities, or choose "Save Draft" to save your report as a draft for future reference.

## Field-by-Field Explanation

* **Fraud Report** (Page 1, id: 1):
	+ This field is the main title of the report. Enter a brief description of the incident.
* **Contact Info** (Page 1, id: 2):
	+ Enter your contact information, including your phone number.
* **Fraud Information** (Page 1, id: 3):
	+ Select one or more of the provided options to describe the nature of the fraud.
* **Date** (Page 1, id: 4):
	+ Enter the date of the incident in the format MM/DD/YYYY.
* **Time** (Page 1, id: 5):
	+ Enter the time of the incident in the format HH:MM AM/PM.
* **Description** (Page 1, id: 6):
	+ Provide a detailed description of the incident, including as much information as possible.
* **Submit** (Page 1, id: 7):
	+ Select this option to send the report to the relevant authorities.
* **Contact Person** (Page 1, id: 8):
	+ Enter the name of the contact person, if any.
* **Phone** (Page 1, id: 9):
	+ Enter the contact person's phone number.
* **Email** (Page 1, id: 10):
	+ Enter the contact person's email address.

## Tips

* Please provide as much detail as possible in the "Description" field to help investigate the incident effectively.
* Make sure to enter accurate and up-to-date contact information.
* If you are unsure about any field, please consult with your supervisor or HR representative.
