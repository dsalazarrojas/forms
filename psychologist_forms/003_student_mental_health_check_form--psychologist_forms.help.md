# Student Mental Health Check Form - Help Guide

## Purpose
This form is designed to help students assess their mental health and well-being, providing an opportunity to identify potential concerns that may require support or follow-up.

## How To Complete This Form

1. Please review the form carefully before beginning.
2. Answer each question honestly and to the best of your ability.
3. If you have any concerns or questions, please don't hesitate to reach out to a school administrator or counselor.

## Field-by-Field Explanation

* **Intro Page (Page 1)** (intro-page, note, optional): This page is an introduction to the form and provides an overview of what the form is for.
* **Student Mental Health Page (Page 2)** (student-mental-health-page, text, optional): This page is where you can write about your current mental health status. Please be as honest and detailed as possible.
* **Student Mental Status Page (Page 3)** (student-mental-status-page, select_one, optional): Please select one of the following options that best describes your current mental health status:
	+ Normal
	+ Anxious
	+ Depressed
	+ Other
* **Student Mental Support Page (Page 4)** (student-mental-support-page, select_multiple, optional): If you have a support system, please select all that apply:
	+ Parent
	+ Teacher
	+ Other
* **Student Mental Symptom Page (Page 5)** (student-mental-symptom-page, select_multiple, optional): If you are experiencing any of the following symptoms, please select all that apply:
	+ Sleep Disturbances
	+ Appetite Disturbances
	+ Concentration Issues
	+ Social Withdrawal
	+ Other
* **Student Mental Status Date Page (Page 6)** (student-mental-status-date-page, date, optional): If you would like to specify a date for your mental status, please enter it here.
* **Student Mental Status Time Page (Page 7)** (student-mental-status-time-page, time, optional): If you would like to specify a time for your mental status, please enter it here.
* **Student Mental Status Note Page (Page 8)** (student-mental-status-note-page, note, optional): If you have any additional comments or concerns, please write them here.
* **Student Mental Status Action Page (Page 9)** (student-mental-status-action-page, select_one, optional): Please select one of the following options for your mental status:
	+ Follow-up
	+ Counseling
	+ No Action
* **Student Mental Status Signature Page (Page 10)** (student-mental-status-signature-page, select_one, optional): If you would like to sign and confirm your mental status, please select 'True'.
* **Student Mental Status Email Page (Page 11)** (student-mental-status-email-page, email, optional): If you would like to provide your email address, please enter it here.
* **Student Mental Status Phone Page (Page 12)** (student-mental-status-phone-page, text, optional): If you would like to provide your phone number, please enter it here.
* **Student Mental Status Date Page (Page 13)** (student-mental-status-date-page, date, optional): If you would like to specify a date for your mental status, please enter it here.
* **Student Mental Status Signature 2 Page (Page 14)** (student-mental-status-signature-2-page, select_one, optional): If you would like to sign and confirm your mental status again, please select 'True'.

## Tips

* Please answer each question honestly and to the best of your ability.
* If you have any concerns or questions, please don't hesitate to reach out to a school administrator or counselor.
* This form is not a comprehensive mental health assessment. If you are experiencing severe mental health concerns, please seek help from a mental health professional.
