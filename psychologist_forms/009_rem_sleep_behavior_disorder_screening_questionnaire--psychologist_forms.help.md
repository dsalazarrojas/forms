# Rem Sleep Behavior Disorder Screening Questionnaire - Help Guide

## Purpose
The Rem Sleep Behavior Disorder Screening Questionnaire is a tool used to identify potential risks for sleep behavior disorder in individuals. The form collects information on various aspects of sleep behavior and history to aid in the assessment and diagnosis of this condition.

## How To Complete This Form
To complete this form, please follow these steps:

* Answer each question carefully and honestly to provide accurate information.
* Be as detailed as possible when providing answers to text-based fields.
* Select all that apply for multiple-choice fields.
* Enter numerical values for numerical fields.
* Enter date and time values in standard format (MM/DD/YYYY HH:MM AM/PM)

## Field-by-Field Explanation

* **Rem sleep behavior disorder screening questionnaire form 1**: This text field is intended to capture any additional comments or information about the individual's sleep behavior.
* **Rem sdb q1 1**: This field asks if the individual has experienced excessive daytime sleepiness. Answer "Yes" if you have experienced excessive daytime sleepiness, which is a common symptom of sleep behavior disorder.
* **Rem sdb q1 2**: This field asks about sleep duration. Select all that apply if you have experienced the following sleep behaviors: 
  • Sleeping more than 10 hours per day.
  • Sleeping less than 6 hours per night.
  • Sleeping only 6-8 hours per night.
  • Napping for more than 1 hour at a time.
* **Rem sdb q2 1**: This text field is for the individual to describe their sleep quality, including any difficulties falling asleep, staying asleep, or waking up.
* **Rem sdb q2 2**: This text field is for the individual to describe any sleep-related behaviors, such as binge eating before bed or watching TV before sleep.
* **Rem sdb q3 1**: This field asks if the individual has experienced sleep paralysis. Answer "Yes" if you have experienced sleep paralysis.
* **Rem sdb q3 2**: This field asks about sleep-related anxiety or fear. Select all that apply if you have experienced the following: 
  • Fear of sleep
  • Anxiety about sleep quality
  • Difficulty falling or staying asleep due to fear or anxiety
* **Rem sdb q4 1**: This numerical field asks about average sleep duration in hours.
* **Rem sdb q4 2**: This numerical field asks about average wake-up time in 24-hour format.
* **Rem sdb q5 1**: This numerical field asks about average bedtime in 24-hour format.
* **Rem sdb q5 2**: This numerical field asks about number of hours slept at night.
* **Rem sdb q6 1**: This date field asks for the date of the last full night's sleep.
* **Rem sdb q6 2**: This time field asks for the time of wake-up in 24-hour format.
* **Rem sdb q7 1**: This text field is for the individual to describe any sleep-related pain or discomfort.
* **Rem sdb q7 2**: This text field is for the individual to describe any other sleep-related concerns.
* **Rem sdb q8 1**: This field asks if the individual has experienced sleep attacks. Answer "Yes" if you have experienced sleep attacks.
* **Rem sdb q8 2**: This field asks about sleep-related anxiety or fear. Select all that apply if you have experienced the following: 
  • Fear of sleep
  • Anxiety about sleep quality
  • Difficulty falling or staying asleep due to fear or anxiety
* **Rem sdb q9 1**: This numerical field asks about number of hours spent in bed.
* **Rem sdb q9 2**: This numerical field asks about total sleep time in hours.
* **Rem sdb q10 1**: This numerical field asks about number of hours spent awake at night.
* **Rem sdb q10 2**: This numerical field asks about number of awakenings per night.
* **Rem sdb q11 1**: This date field asks for the date of last night's sleep.
* **Rem sdb q11 2**: This time field asks for the time of wake-up in 24-hour format.
* **Rem sdb q12 1**: This text field is for the individual to describe any sleep-related behaviors, such as sleep talking or sleepwalking.
