# psychology_informed_consent_form - Help Guide
## Purpose
This form is designed to obtain informed consent from research participants in a psychology study. It gathers information about the study's purpose, design, and participant's rights and responsibilities.

## How To Complete This Form
1. Read the introduction to understand the study's purpose and requirements.
2. Provide a brief description of the research purpose (if applicable).
3. Describe the study's design (if applicable).
4. Select one of the options for informed consent (Option 1, Option 2, or Option 3).
5. Fill in your participant details, if required.
6. Provide the date and time you signed the form, if required.

## Field-by-Field Explanation

* **Introduction** (`1`, `note`, required: `false`): This is a brief note that provides an overview of the study's purpose and requirements.
* **Research Purpose** (`2`, `text`, required: `false`): If you have a specific research purpose, provide a brief description. This is an optional field.
* **Study Design** (`3`, `text`, required: `false`): If you have a specific study design, provide a brief description. This is an optional field.
* **Informed Consent** (`4`, `select_one`, required: `false`): Select one of the options for informed consent. Please review the options carefully and choose the one that best suits your understanding of the study.
* **Participant Details** (`5`, `text`, required: `false`): If required, please provide your participant details, such as your name and contact information.
* **Informed Consent Date** (`6`, `date`, required: `false`): If required, please provide the date you signed this form.
* **Psychologist Info** (`7`, `text`, required: `false`): If applicable, provide information about the psychologist conducting the study.
* **Study Location** (`8`, `text`, required: `false`): If applicable, provide the location where the study will take place.
* **Study Instruments** (`9`, `text`, required: `false`): If applicable, provide information about the study's tools and equipment.
* **Participant Agreement** (`10`, `select_multiple`, required: `false`): Select all applicable participant agreements (Option 4, Option 5, or Option 6).
* **Study Informed Consent Form** (`11`, `select_one`, required: `false`): Select one of the options for the study's informed consent form (Option 7, Option 8, or Option 9).
* **Participant Signature** (`12`, `select_one`, required: `false`): Select one of the options for your participant signature (Option 10, Option 11, or Option 12).
* **Psychologist Signature** (`13`, `select_one`, required: `false`): Select one of the options for the psychologist's signature (Option 13, Option 14, or Option 15).
* **Date Signed** (`14`, `date`, required: `false`): If required, please provide the date you signed this form.
* **Time Signed** (`15`, `time`, required: `false`): If required, please provide the time you signed this form.
