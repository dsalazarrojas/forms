# Sanitary Survey Checklist - Help Guide
## Purpose
The Sanitary Survey Checklist is a form used to inspect facilities and gather information about their systems, construction materials, and inspection details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you have all the necessary information.
2. Fill in the required fields, marked as "required".
3. For fields not marked as "required", provide as much detail as possible to help facilitate the inspection process.
4. Ensure that you have answered all questions truthfully and accurately.

## Field-by-Field Explanation
* **facility_id** (Number): Enter the facility's ID number, if applicable.
* **system_type** (Select One): Select 'Yes' or 'No' to indicate whether the facility has a system type (e.g., water treatment system, waste management system).
* **system_capacity** (Select One): Select 'Yes' or 'No' to indicate whether the facility's system has been properly constructed (e.g., sufficient capacity, well-maintained).
* **construction_materials** (Select Multiple): Select all applicable options to describe the construction materials used in the facility's systems (e.g., steel, concrete, wood).
* **operation_and_maintenance** (Text): Describe the facility's operation and maintenance procedures, if applicable.
* **physical_condition** (Select Multiple): Select all applicable options to describe the physical condition of the facility's systems (e.g., clean, well-maintained, adequate drainage).
* **capability_and_capacity** (Note): Provide a brief note about the facility's capability and capacity.
* **notes** (Text): Provide any additional comments or observations about the facility's sanitary conditions.
* **facility_address** (Text): Enter the facility's address, if applicable.
* **facility_contacts** (Text): Enter the facility's contacts information, if applicable.
* **facility_inspection_notes** (Text): Provide any additional comments or observations about the inspection, if applicable.
* **facility_inspection_date** (Date): Enter the date of the facility's inspection, if applicable.
* **facility_inspection_time** (Time): Enter the time of the facility's inspection, if applicable.
* **assigned_tool** (Text): Enter the tool or equipment used during the inspection, if applicable.
* **output_file** (Text): Specify the output file for the inspection report, if applicable.
