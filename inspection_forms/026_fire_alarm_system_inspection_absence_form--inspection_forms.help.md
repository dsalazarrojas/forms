# fire_alarm_system_inspection_absence_form - Help Guide
## Purpose
The "fire_alarm_system_inspection_absence_form" is used to report the absence of a fire alarm system inspection and provide details for the missed inspection.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the inspection date on which the absence was noticed.
2. Check the "Absence Notification" field to specify whether a notification was sent to anyone about the absence.
3. Select the notification method used (email, phone, or text).
4. Specify the time of the absence.
5. Provide a reason for the absence in the "Reason for Absence" field.
6. Enter the location where the inspection was missed.
7. Add any additional comments about the situation.

## Field-by-Field Explanation

* **Inspection Date**: Enter the date on which the inspection absence was noticed.
* **Absence Notification**: Check the box if you sent a notification about the absence to anyone.
	+ Select 'Yes' if a notification was sent.
	+ Select 'No' if no notification was sent.
* **Notification Recipients**: Select who received the notification.
	+ Select all applicable options (Yes, No)
* **Notification Method**: Choose how the notification was sent.
	+ Select email.
	+ Select phone.
	+ Select text.
* **Notification Time**: Enter the time of the absence.
* **Reason for Absence**: Enter a brief reason for the missed inspection.
* **Location**: Enter the location where the inspection was missed.
* **Comments**: Add any additional comments about the situation.

## Tips
- Make sure to fill out this form for every instance of absence or missed inspection.
- Be as specific as possible when providing the reason for absence and location.
