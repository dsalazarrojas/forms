# Rental Property Self Inspection Form - Help Guide
## Purpose
This form is used by property managers or inspectors to record information about the current status and condition of rental properties.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the status of the property (Active or Inactive).
2. List any features that are present at the property (e.g., air conditioning, pool, etc.).
3. Note any existing damage at the property (e.g., broken appliances, leaky faucets, etc.).
4. Select the date and time of the inspection.
5. Add any comments or notes about the inspection.
6. Enter the contact number of the property's owner or manager.
7. Enter the property address.
8. Select the status of the inspection (Active or Inactive).

## Field-by-Field Explanation
- **Property Status** (`property_status`, select_one, required: false): Select the current status of the property (Active or Inactive).
- **Property Features** (`property_features`, select_multiple, required: false): List any features that are present at the property (e.g., air conditioning, pool, etc.).
- **Property Damage** (`property_damage`, select_multiple, required: false): Note any existing damage at the property (e.g., broken appliances, leaky faucets, etc.).
- **Inspection Date** (`inspection_date`, date, required: false): Select the date of the inspection.
  - Please use the standard date format (MM/DD/YYYY).
- **Inspection Time** (`inspection_time`, time, required: false): Select the time of the inspection.
  - Please use the 12-hour clock format (e.g., 10:00 AM, 2:00 PM, etc.).
- **Comments** (`comments`, note, required: false): Add any comments or notes about the inspection.
- **Contact Number** (`contact_number`, text, required: false): Enter the contact number of the property's owner or manager.
- **Property Address** (`property_address`, text, required: false): Enter the property address.
- **Inspection Status** (`inspection_status`, select_one, required: false): Select the status of the inspection (Active or Inactive).

## Tips

* Make sure to fill out all required fields.
* Use clear and concise language when filling out the comments field.
* If a property has multiple features or damage, list them all.
