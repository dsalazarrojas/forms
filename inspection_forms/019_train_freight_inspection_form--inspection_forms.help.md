# Train Freight Inspection Form - Help Guide
## Purpose
The Train Freight Inspection Form is used to document the inspection status and findings of freight trains. This form helps ensure that trains are safe for operation and comply with relevant regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if the train is of type 'Yes' or 'No' using the "Train Type" field.
2. Select if the train length is 'Yes' or 'No' using the "Train Length" field.
3. Check if the train weight is 'Yes' or 'No' using the "Train Weight" field.
4. Select if the train speed is 'Yes' or 'No' using the "Train Speed" field.
5. Confirm if the driver license is 'Yes' or 'No' using the "Driver License" field.
6. Confirm if the train license is 'Yes' or 'No' using the "Train License" field.
7. Select the current inspection status of the train ('Active' or 'Inactive') using the "Train Inspection Status" field.
8. Check if the train carries hazardous materials ('Yes' or 'No') using the "Hazardous Materials" field.
9. Select the inspection location using the "Inspection Location" field.
10. Date and time of the inspection using the "Inspection Date" and "Inspection Time" fields.
11. Provide any additional comments or notes using the "Inspection Comments" field.

## Field-by-Field Explanation

* **Train Type** (select_one): Select 'Yes' or 'No' to indicate if the train is of freight type.
* **Train Length** (select_multiple): Select 'Yes' or 'No' to indicate if the train length is within the specified limits.
* **Train Weight** (select_multiple): Select 'Yes' or 'No' to indicate if the train weight is within the specified limits.
* **Train Speed** (select_one): Select 'Yes' or 'No' to indicate if the train speed is within the specified limits.
* **Driver License** (select_one): Confirm if the driver license is valid.
* **Train License** (select_one): Confirm if the train license is valid.
* **Train Inspection Status** (select_one): Select 'Active' or 'Inactive' to indicate the current inspection status.
* **Hazardous Materials** (select_multiple): Select 'Yes' or 'No' to indicate if the train carries hazardous materials.
* **Inspection Location** (select_one): Select the location of the inspection.
* **Inspection Date** (date): Enter the date of the inspection.
* **Inspection Time** (time): Enter the time of the inspection.
* **Inspection Comments** (note): Provide any additional comments or notes regarding the inspection.
