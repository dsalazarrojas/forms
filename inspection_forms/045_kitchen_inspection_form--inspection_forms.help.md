# Kitchen Inspection Form - Help Guide
## Purpose
The kitchen inspection form is designed to collect information on the condition of a kitchen facility. The form assesses the cleanliness, safety, and condition of the kitchen.

## How To Complete This Form
1. Review each field carefully to understand what it represents.
2. Answer each question based on your observations or knowledge of the facility.
3. Select the appropriate options for each field, taking note of any additional comments or notes.

## Field-by-Field Explanation

* **Facility Rating** (Facility Rating, select_one):
  This field is used to rate the overall facility condition.
  Select "Good" if the facility meets your expectations, or "Fair" if it needs improvement.
* **Food Handling** (Food Handling, text):
  This field is used to note any observations or concerns about food handling practices in the facility.
  Please provide any relevant details or concerns you may have.
* **Cleanliness** (Cleanliness, select_multiple):
  This field is used to indicate if the facility is clean or dirty.
  Select "Yes" if the facility is clean or "No" if it is not.
* **Food Temperature** (Food Temperature, select_multiple):
  This field is used to note if food is stored at the correct temperature.
  Select "Yes" if the temperature is adequate or "No" if it is not.
* **Pest Control** (Pest Control, select_one):
  This field is used to indicate if the facility has a pest control program in place.
  Select "Yes" if the facility has a program or "No" if it does not.
* **Waste Disposal** (Waste Disposal, select_one):

  Select "Yes" if waste is disposed of properly or "No" if it is not.
* **Facility Condition** (Facility Condition, select_one):
