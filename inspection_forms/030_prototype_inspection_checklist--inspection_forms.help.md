# Prototype Inspection Checklist - Help Guide
## Purpose
This form is used to assess and evaluate prototypes, gathering essential information about the prototype, its description, and the results of its inspection.

## How To Complete This Form
1. Start by filling in the **Prototype ID** (Field 1) if it is provided.
2. Enter the **Reviewer Name** (Field 2) and their **Email** (Field 3) for identification purposes.
3. Provide a brief **Prototype Description** (Field 4) about the inspected prototype.
4. Select the **Inspection Outcomes** (Field 6) that apply to the prototype, choosing one or more options from the dropdown list.
5. If necessary, add additional **Comments** (Field 7) about the prototype inspection.
6. Indicate if the **Review is Completed** (Field 8) or not.
7. Select the **Review Status** (Field 9) from the options provided, indicating the state of the review.
8. Choose the **Assigned To** (Field 10) who will be responsible for the review.
9. Record the **Review Completed Date** (Field 11) if the review has been finished.
10. Set the **Review Due Date** (Field 12) for the review, if applicable.
11. Finally, enter any **Review Notes** (Field 13) that are relevant to the review.

## Field-by-Field Explanation
* **Prototype ID (1)**: Enter the unique identifier for the prototype being inspected.
* **Reviewer Name (2)**: Enter your name for identification purposes.
* **Reviewer Email (3)**: Enter your email address for identification and contact purposes.
* **Prototype Description (4)**: Provide a brief description of the prototype being inspected.
* **Inspection Outcomes (6)**: Select one or more outcomes that apply to the prototype inspection:
	+ Option 1: Select this option if the prototype meets the required criteria.
	+ Option 2: Select this option if the prototype does not meet the required criteria.
	+ Option 3: Select this option if the prototype needs further evaluation.
* **Comments (7)**: Add any additional comments about the prototype inspection, if necessary.
* **Review is Completed (8)**: Indicate if the review has been completed.
* **Review Status (9)**: Choose the status of the review from the provided options.
	+ Option 1: Select this option if the review is pending.
	+ Option 2: Select this option if the review is completed.
* **Assigned To (10)**: Choose the person assigned to conduct the review.
* **Review Completed Date (11)**: Enter the date on which the review was completed.
* **Review Due Date (12)**: Set the date by which the review is expected to be completed.
* **Review Notes (13)**: Enter any notes related to the review.
