# Ingredient Shelf Verification Report Form - Help Guide
## Purpose
The Ingredient Shelf Verification Report Form is used to record the status of ingredients on a shelf, ensuring accuracy, safety, and compliance with regulations.

## How To Complete This Form
1. Review the form carefully and ensure you're not duplicating work by referring to previous inspections or reports.
2. Enter the required information for each field, following the explanations below.

## Field-by-Field Explanation
* **Ingredient Shelf Verification Form** (`ingredient_shelf_verification_form`, select_one, required: false): Select "Yes" or "No" to indicate whether the ingredients on the shelf meet the verification criteria.
* **Ingredient Shelf Status** (`ingredient_shelf_status`, text, required: false): Enter a brief description of the current shelf status (e.g., "clean", "unclean", "needs repair", etc.).
* **Corrective Action** (`corrective_action`, text, required: false): Describe any actions taken or recommended to address any issues or defects observed during the inspection.
* **Inspection Date** (`inspection_date`, date, required: false): Record the date of the inspection.
* **Shelf Location** (`shelf_location`, text, required: false): Specify the location of the shelf (e.g., "rack 3, aisle 2", etc.).
* **Shelf Condition** (`shelf_condition`, select_multiple, required: false): Select all that apply from the list:
	+ "Yes" (e.g., clean, organized, etc.)
	+ "No" (e.g., unclean, disorganized, etc.)
* **Storage Area** (`storage_area`, text, required: false): Enter the storage area where the shelf is located.
* **Storage Type** (`storage_type`, select_one, required: false): Select whether the shelf is:
	+ "Yes" (e.g., refrigerated, etc.)
	+ "No" (e.g., non-refrigerated, etc.)

## Tips
* Be thorough and accurate when completing the form.
* If unsure, refer to relevant documentation or consult with your supervisor.
* Save and file the completed form for future reference.
* Ensure you're aware of any changes or updates to the shelf or storage conditions.
