# Stormwater Discharge Quality Report - Help Guide
## Purpose
The Stormwater Discharge Quality Report is a form designed to collect data on stormwater discharges and overflows from facilities, providing essential information for environmental monitoring and regulation.

## How To Complete This Form

### Step 1: Event Date
* Select the date of the stormwater event you are reporting.
* This date is the date of the event itself, not the date of the report.

### Step 2: Site Location
* Provide the location where the stormwater event occurred.
* This could be the name of the facility, a nearby landmark, or a specific address.

### Step 3: Facility ID
* Enter the identification number of the facility where the event occurred.
* If not applicable, leave this field blank.

### Step 4: Facility Name
* Enter the name of the facility where the event occurred.
* If you are not affiliated with the facility, try to obtain the name from publicly available records.

### Step 5: Stormwater Event Type
* Select the type of stormwater event that occurred.
* Options are:
	+ Discharge: water flowing out of a pipe or structure.
	+ Overflow: water exceeding capacity of a storage or drainage system.
	+ Spill: uncontrolled release of pollutants or contaminated water.
	+ Other: describe the type of event in the comments section.

### Step 6: Discharge Characteristics
* Describe the characteristics of the discharge, such as quantity, rate, and quality.

### Step 7: Photo Description
* Provide a description of any photos taken during the event.
* This will help in documenting the event and providing visual evidence.

### Step 8: Facility Contact
* Provide the name and contact information of the facility representative.
* This will facilitate communication and follow-up actions.

### Step 9: Inspector Comments
* Provide any additional comments or concerns about the event.
* This is an opportunity to highlight any issues that may require further investigation.

### Step 10: Facility Surveyor
* If applicable, provide the name of the facility surveyor or inspector.
* This helps in tracking accountability and ensuring accuracy.

## Tips

* Be as specific as possible when describing the event and its characteristics.
* Attach photos or other visual evidence to support your report.
* Use standard formats and units for measurements and descriptions.
* If you have any questions or concerns about the form, contact us at form@gic.mx.
