# monthly_retail_inspection_form_template - Help Guide
## Purpose
The monthly retail inspection form template is designed to collect data from retailers about their store's condition, layout, equipment, and facilities. This data will be used to identify areas of improvement and monitor changes over time.

## How To Complete This Form

1. Please fill out the form accurately and thoroughly.
2. Make sure to answer all questions on each page.
3. If a question is not applicable, select "No" or leave the field blank.

## Field-by-Field Explanation
### **Main Page** (page 1)

* **Store Layout** (`store_layout`, select_one): Select "Yes" if the store's layout meets your requirements, or "No" otherwise.
* **Store Condition** (`store_condition`, select_multiple): Select all that apply if the store's condition meets your requirements, or "No" otherwise.
* **Store Condition Score** (`store_condition_score`, select_one): Select "Yes" if the store's condition meets your requirements, or "No" otherwise.
* **Store Equipment** (`store_equipment`, select_multiple): Select all that apply if the store's equipment meets your requirements, or "No" otherwise.
* **Store Layout Equipment** (`store_layout_equipment`, select_multiple): Select all that apply if the store's layout meets your requirements, or "No" otherwise.
* **Store Facilities** (`store_facilities`, select_multiple): Select all that apply if the store's facilities meet your requirements, or "No" otherwise.
* **Store Staff** (`store_staff`, select_multiple): Select all that apply if the store's staff meets your requirements, or "No" otherwise.

## Tips
* Make sure to answer all questions accurately and thoroughly.
* If a question is not applicable, select "No" or leave the field blank.
* This form is designed to be completed once a month. Please complete it at the same time each month to ensure consistent data collection.
