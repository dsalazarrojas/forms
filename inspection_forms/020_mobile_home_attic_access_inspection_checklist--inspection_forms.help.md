# Mobile Home Attic Access Inspection Checklist - Help Guide
## Purpose
This form is designed to collect information about mobile home attic access inspections. It's intended to be used by inspectors or other personnel who need to conduct and store data about these inspections.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the Category field to select the category that this inspection belongs to.
* Enter a brief Description of the inspection.
* Choose whether the inspection was performed with an Assigned Tool (Yes/No).
* Enter the Form ID to identify the form.
* Select the Output File type (e.g. PDF, Excel).
* Select whether the Submission Status is Active or Inactive.
* Enter the Submission Date and Submission Time (optional).
* Choose whether the Submission was made with an Assigned Tool (Yes/No).
* Select whether the Submission Output File is available (Yes/No).
* Enter the Submission User ID and Submission User Name.
* Fill in the Form Title and Form Description (optional).
* Select the Submission Submission Notes (optional).

## Field-by-Field Explanation

* **Category** (`category`, `select_one`, required: false): Select the category for this inspection.
* **Description** (`description`, `text`, required: false): Enter a brief description of the inspection.
* **Description** (`description_description`, `note`, required: false): This is a note field for additional description information.
* **Assigned Tool** (`assigned_tool`, `select_multiple`, required: true): Choose whether the inspection was performed with an assigned tool.
* **Form ID** (`form_ids`, `number`, required: true): Enter the form ID to identify the form.
* **Output File** (`output_file`, `select_one`, required: true): Select the output file type (e.g. PDF, Excel).
* **Submitted By** (`submitted_by`, `select_multiple`, required: true): Choose whether the submission was made by a user (Yes/No).
* **Output Path** (`output_path`, `text`, required: false): Enter the output path (optional).
* **Submitted Date** (`submitted_date`, `date`, required: false): Enter the date the submission was made (optional).
* **Submission ID** (`submission_id`, `text`, required: false): Enter the submission ID (optional).
* **Submitted Time** (`submitted_time`, `time`, required: false): Enter the time the submission was made (optional).
* **User ID** (`user_id`, `number`, required: false): Enter the user ID (optional).
* **User Name** (`user_name`, `text`, required: false): Enter the user name (optional).
* **Form Title** (`form_title`, `text`, required: true): Enter the title of the form.
* **Form Description** (`form_description`, `text`, required: false): Enter the description of the form (optional).
* **Submission Status** (`submission_status`, `select_multiple`, required: true): Choose whether the submission status is Active or Inactive.
* **Submission Date** (`submission_date`, `date`, required: false): Enter the submission date (optional).
* **Submission Time** (`submission_time`, `time`, required: false): Enter the submission time (optional).
* **Submission Notes** (`submission_notes`, `note`, required: false): Enter additional notes about the submission.
* **Submission User ID** (`submission_user_id`, `number`, required: true): Enter the submission user ID.
* **Submission User Name** (`submission_user_name`, `text`, required: true): Enter the submission user name.
* **Submission Assigned Tool** (`submission_assigned_tool`, `select_one`, required: false): Choose whether the submission was made with an assigned tool.
* **Submission Output File** (`submission_output_file`, `select_one`, required: false): Select whether the submission output file is available (Yes/No).

## Tips
* Make sure to select the correct category for the inspection.
* Enter a clear and concise description of the inspection.
* Make sure to select the correct output file type.
* Ensure that the submission status is accurate.
* Enter the correct submission date and time (if applicable).
* Enter the correct submission user ID and user name.
* Enter the correct submission notes (if applicable).
* Make sure to select the correct submission assigned tool and output file availability.
