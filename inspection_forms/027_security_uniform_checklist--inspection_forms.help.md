# Security Uniform Checklist - Help Guide

## Purpose
The Security Uniform Checklist is a form designed to help facility managers and security teams assess and report on the security status of a facility. This form is intended to be completed after a security inspection to provide an accurate and standardized record of the facility's security measures.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form and ensure you have all the necessary information.
2. Enter the inspection date and time in the `inspection_date` field.
3. Select the correct response for each question by filling in the corresponding field.
4. Enter any additional comments or observations in the `facility_location` field.
5. Submit the form once complete.

## Field-by-Field Explanation

* **Security Teams** (`facility_managers`, select_multiple, Required: false):
	+ Check if your facility has a security team. If yes, please select all applicable teams.
	+ If no, select 'No'.
* **Inspection Date** (`inspection_date`, date, Required: false):
	+ Enter the date of the security inspection.
* **Inspection Time** (`inspection_time`, time, Required: false):
	+ Enter the time of the security inspection.
* **Security Teams** (`security_teams`, select_one, Required: false):
	+ Select one of the security teams: Security, Facility, or Management.
* **Facility Location** (`facility_location`, text, Required: false):
	+ Enter the address or location of the facility.
* **Facility Contact** (`facility_contact`, text, Required: false):
	+ Enter the contact information for the facility manager or security team.
* **Fast Data Collection** (`fast_data_collection`, text, Required: false):
	+ Enter any information related to fast data collection.
* **Standardize Appearance Checks** (`standardize_appearance_checks`, text, Required: false):
	+ Enter any information related to standardized appearance checks.
* **Facility Managers** (`facility_managers`, select_multiple, Required: false):
	+ Check if your facility has a facilities manager. If yes, please select all applicable teams.
	+ If no, select 'No'.

## Tips

* Complete the form thoroughly and accurately to ensure a reliable and standardized report.
* If you are unsure about any field, please ask for clarification or assistance from the security team or facility manager.
* Remember to enter all relevant information to ensure a comprehensive report.
