# Solar Assessment Form - Help Guide
## Purpose
The Solar Assessment Form is used to collect information about a property's solar features, which can be used to inform decisions or actions related to the property.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the `Property Address` field with the address of the property being assessed.
* Select the appropriate `Property Type` from the dropdown menu:
	+ Office
	+ Residential
	+ Commercial
* Select the current `Property Status` from the dropdown menu:
	+ Active
	+ Inactive
	+ Pending
* Enter the `Contact Name` of the person to contact.
* Enter the `Contact Phone` number of the person to contact.

## Field-by-Field Explanation
* **Property Address** (`property_address`, text, required): Enter the address of the property being assessed. This is the main address where the property is located.
* **Property Type** (`property_type`, select_one, optional): Select the type of property from the dropdown menu. This information will help identify the property's characteristics.
* **Property Status** (`property_status`, select_one, optional): Select the current status of the property from the dropdown menu. This information will help identify any issues or concerns related to the property.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person to contact. This can be the property owner, manager, or other relevant individual.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person to contact. This can be used for follow-up or additional information.

## Tips
* Ensure that you have the necessary permissions and that the property is not already being assessed before proceeding.
* If you have previously completed this form for the same property, please do not submit duplicate requests.
* If you are unsure about any of the fields, please contact your supervisor or a colleague for guidance.
