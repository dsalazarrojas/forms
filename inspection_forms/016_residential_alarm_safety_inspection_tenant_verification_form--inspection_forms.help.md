# Residential Alarm Safety Inspection Tenant Verification Form - Help Guide
## Purpose
This form is used to gather information about the residential alarm system's functionality, safety status, and other relevant details from the tenant's perspective.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form carefully and fill in the necessary information.
2. Select the correct options from the drop-down menus (e.g., Alarm System, Safety Status).
3. Enter your name and contact information (if applicable).
4. Provide any additional comments or notes about the system's condition.

## Field-by-Field Explanation

* **Tenant Info**: Enter your name and contact information so that we can follow up with you if needed.
	+ **Tenant Info** (`tenant_info`, `text`, required: `false`): Enter your name and contact information (email and phone number).
* **Alarm System**: Select the type of alarm system you are using (e.g., System 1, System 2, System 3).
	+ **Alarm System** (`alarm_system`, `select_multiple`, options: `["System 1", "System 2", "System 3"]`): Select the correct alarm system type.
* **Safety Status**: Indicate the current safety status of the alarm system.
	+ **Safety Status** (`safety_status`, `select_one`, options: `["Functional", "Non-Functional", "Unknown"]`): Select the safety status of the alarm system.
* **Functionality**: Enter a numerical value to indicate the system's functionality level (optional).
	+ **Functionality** (`functionality`, `number`, required: `false`): Enter a numerical value to indicate the system's functionality level.
* **Notes**: Provide any additional comments or notes about the system's condition.
	+ **Notes** (`notes`, `note`, required: `false`): Enter any additional comments or notes about the system's condition.
* **Email**: Enter your email address for follow-up communication.
	+ **Email** (`email`, `email`, required: `false`): Enter your email address for follow-up communication.
* **Phone**: Enter your phone number for follow-up communication.
	+ **Phone** (`phone`, `text`, required: `false`): Enter your phone number for follow-up communication.
* **Date Completed**: Indicate when the inspection was completed.
	+ **Date Completed** (`date_completed`, `date`, required: `false`): Enter the date the inspection was completed.
* **Time Completed**: Indicate when the inspection was completed.
	+ **Time Completed** (`time_completed`, `time`, required: `false`): Enter the time the inspection was completed.

* **Assigned Tool**: Enter the tool or device used during the inspection.
	+ **Assigned Tool** (`assigned_tool`, `text`, required: `false`): Enter the tool or device used during the inspection.
* **Form ID**: Enter a unique ID for the form.
	+ **Form ID** (`form_id`, `text`, required: `false`): Enter a unique ID for the form.
* **Category**: Enter the category for the form.
	+ **Category** (`category`, `text`, required: `false`): Enter the category for the form.
