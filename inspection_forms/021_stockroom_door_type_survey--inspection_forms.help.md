# Stockroom Door Type Survey - Help Guide
## Purpose
This form is used to collect information about stockroom doors in a warehouse or stockroom setting.

## How To Complete This Form

1. Review the stockroom door and determine its type.
2. Choose the correct type for the stockroom door from the options provided.
3. Describe the door, if necessary, using the text field for additional comments.
4. Report the door's condition and size as accurately as possible.
5. Indicate the priority level of maintenance required for the door.
6. Confirm the current maintenance status of the door.
7. If necessary, provide comments or feedback for the door.
8. Assign a person responsible for maintaining or inspecting the door.

## Field-by-Field Explanation

* **Stockroom Door Type** (`stockroom_door_type_id`): Choose the correct type of stockroom door from the options provided. This field is required.
* **What type of stockroom door is it?** (`stockroom_door_type`): Describe the type of stockroom door, such as a fire door, security door, or regular door. This field is required.
* **Description** (`stockroom_door_description`): If necessary, provide a brief description of the door, such as its purpose or location. This field is optional.
* **Door Condition** (`door_condition_id`): Report the condition of the door, such as 'Yes' if it's in good condition or 'No' if it's not. This field is required.
* **What condition is the door in?** (`door_condition`): Choose the correct condition of the door from the options provided. This field is required.
* **Stockroom Door Size** (`stockroom_door_size_id`): Report the size of the door, such as small, medium, or large. This field is required.
* **What size is the stockroom door?** (`stockroom_door_size`): Choose the correct size for the door from the options provided. This field is required.
* **Maintenance Priority** (`maintenance_priority_id`): Indicate the priority level of maintenance needed for the door, such as 'Yes' if it's urgent or 'No' if not. This field is required.
* **How quickly does maintenance need to be done?** (`maintenance_priority`): Choose the correct priority level from the options provided. This field is required.
* **Maintenance Status** (`maintenance_status_id`): Report the current maintenance status of the door, such as 'Active' or 'Inactive'. This field is optional.
* **Is the door currently maintained?** (`maintenance_status`): Choose the correct status from the options provided. This field is optional.
* **Additional Comments** (`stockroom_door_comments`): Provide any additional comments or feedback about the door. This field is optional.
* **Assigned To** (`assigned_to_id`): Report who is currently assigned to maintain or inspect the door, such as 'Yes' if someone is assigned or 'No' if not. This field is optional.
* **Who is assigned to it?** (`assigned_to`): Choose the correct person or team assigned to the door from the options provided. This field is optional.
* **Additional Comments** (`stockroom_door_type_survey_form_comments`): Provide any additional comments or feedback about the door. This field is optional.
