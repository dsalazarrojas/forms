# Retaining Wall Inspection Checklist - Help Guide

## Purpose
The purpose of this form is to help you inspect and evaluate the condition of a retaining wall. This checklist is used to identify potential issues with the wall's foundation, drainage system, and overall structural integrity.

## How To Complete This Form

1. Select the pages and questions that apply to your inspection.
2. For each question, select the relevant options or enter your observations in the text fields.
3. Review your answers to ensure you have addressed all the required fields.
4. Submit the form to document your findings.

## Field-by-Field Explanation

* **Inspect Wall Base** (`inspect_wall_base`, text, required: false): This field is used to document any issues or observations you have regarding the wall's base or foundation.
* **Check Drainage System** (`check_drainage_system`, select_one, required: false): This field is used to indicate if the drainage system is working properly. Select "Yes" if the system is functioning as expected, or "No" if it is not.
* **Check For Structural Damage** (`check_for_structural_damage`, text, required: false): This field is used to document any signs of structural damage or defects in the wall.
* **Inspect Pavers or Slab** (`inspect_pavers_or_slab`, select_multiple, required: false): This field is used to select any issues or observations you have regarding the pavers or slab surrounding the wall.
* **Inspect Wall Face** (`inspect_wall_face`, text, required: false): This field is used to document any issues or observations you have regarding the wall's face or surface.
* **Inspect Back Fill Area** (`inspect_back_fill_area`, select_one, required: false): This field is used to indicate if the back fill area is level, compacted, and properly drained. Select "Option 1" if it is level, "Option 2" if it is not.
* **Inspect Drains** (`inspect_drains`, text, required: false): This field is used to document any issues or observations you have regarding the wall's drainage system.
* **Inspect Carrying Cables** (`inspect_carrying_cables`, text, required: false): This field is used to document any issues or observations you have regarding the wall's carrying cables.
* **Inspect Wall Anchors** (`inspect_wall_anchors`, select_one, required: false): This field is used to indicate if the wall anchors are secure and properly installed. Select "Option 1" if they are secure, "Option 2" if they are not.
* **Inspect Back Fill Cement** (`inspect_back_fill_cement`, select_multiple, required: false): This field is used to select any issues or observations you have regarding the back fill cement.
* **Inspect Wall Ties** (`inspect_wall_ties`, text, required: false): This field is used to document any issues or observations you have regarding the wall ties.
* **Inspect Wall Cuts** (`inspect_wall_cuts`, text, required: false): This field is used to document any issues or observations you have regarding the wall cuts.
* **Inspect Drainage System Connection** (`inspect_drainage_system_connection`, text, required: false): This field is used to document any issues or observations you have regarding the connection of the drainage system.
* **Inspect Wall Anchoring System** (`inspect_wall_anchoring_system`, select_one, required: false): This field is used to indicate if the wall anchoring system is secure and properly installed. Select "Option 1" if it is secure, "Option 2" if it is not.
* **Inspect Back Fill Material** (`inspect_back_fill_material`, select_multiple, required: false): This field is used to select any issues or observations you have regarding the back fill material.
* **Inspect Anchoring System Connection** (`inspect_anchoring_system_connection`, text, required: false): This field is used to document any issues or observations you have regarding the connection of the anchoring system.
* **Inspect Structural Foundation** (`inspect_structural_foundation`, text, required: false): This field is used to document any issues or observations you have regarding the structural foundation of the wall.
* **Inspect Back Fill Compaction** (`inspect_back_fill_compaction`, select_one, required: false): This field is used to indicate if the back fill compaction is proper and meets code. Select "Option 1" if it is, "Option 2" if it is not.
* **Inspect Cement Condition** (`inspect_cement_condition`, text, required: false): This field is used to document any issues or observations you have regarding the condition of the cement used in the wall.
* **Inspect Wall Condition** (`inspect_wall_condition`, text, required: false): This field is used to document any issues or observations you have regarding the overall condition of the wall.
* **Inspect Drains Clearance** (`inspect_drains_clearance`, text, required: false): This field is used to document any issues or observations you have regarding the clearance of the drains.
* **Inspect Wall Structural Integrity** (`inspect_wall_structural_integrity`, select_one, required: false): This field is used to indicate if the wall's structural integrity is maintained. Select "Option 1" if it is, "Option 2" if it is not.
