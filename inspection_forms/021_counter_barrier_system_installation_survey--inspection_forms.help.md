# Counter Barrier System Installation Survey - Help Guide
## Purpose

The Counter Barrier System Installation Survey is a form designed to collect information about the counter barrier system installations across the organization. This form helps ensure that the barriers are properly documented, and their status is up-to-date.

## How To Complete This Form

1.  Review each page of the form carefully.
2.  Answer each question accurately and thoroughly.
3.  Use the provided options for select questions.
4.  Attach relevant site photos if required.
5.  Submit the form once complete.

## Field-by-Field Explanation

* **Site Details**: This field is used to capture general site information. Please provide a brief description of the site, including its name, address, and any other relevant details.
* **Barrier Requirements**: Select all the barriers that apply to this site. Choose from the options 'Yes' or 'No' for each barrier requirement. If a barrier is not listed, please add a comment in the **Access Notes** field.
* **Access Notes**: Use this field to provide additional notes or comments about access to the site or its barriers. If you're unsure about a barrier requirement, please provide a brief explanation.
* **Site Photos**: Attach relevant photos of the site or its barriers. This will help the team better understand the site's configuration.
* **Barrier Design**: Provide a brief description of the barrier's design, including its type, material, and any other relevant details.

## Tips

* Double-check your answers to ensure accuracy.
* Use clear and concise language when providing information.
* If you're unsure about any field, ask for clarification before proceeding.
* Ensure you've selected all relevant barriers for each site.
