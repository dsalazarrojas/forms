# Tool Inspection Declaration Form - Help Guide
## Purpose
The Tool Inspection Declaration Form is a document used to declare the state of tools after inspection. It provides a clear and concise way to record inspection results, categorize tools, and document any necessary actions or descriptions.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have access to the tool being inspected.
2. Select the correct category for the tool from the options provided.
3. Choose whether the tool is currently assigned to someone.
4. Enter any additional comments or descriptions about the tool.
5. Select the date of the tool's inspection.

## Field-by-Field Explanation

### 1. **Assigned Tool**
Assigned Tool (Yes/No)

* This field indicates whether the tool is currently assigned to someone. Select 'Yes' if the tool is assigned to someone, and 'No' if it is not assigned.

### 2. **Category**
Category (Select One)

* This field categorizes the tool in a specific way (e.g., by type, function, or location).

### 3. **Description**
Description (Note)

* This field provides a free-form text field for any additional comments or notes about the tool.

### 4. **Date of Inspection**
Date of Inspection (Date)

* This field captures the date of the tool's inspection.

### 5. **Tips**

* Make sure to select the correct category for the tool to ensure accurate categorization.
* Enter any relevant comments or descriptions about the tool in the description field.
* Ensure to select the correct date of inspection to track the tool's history accurately.
