# Cannabis Dispensary Inspection Checklist - Help Guide
## Purpose
The purpose of this form is to inspect a cannabis dispensary's adherence to regulations and industry standards.

## How To Complete This Form

1.  Review the form carefully and ensure you understand the questions and fields before starting.
2.  Complete each field accurately and thoroughly, paying attention to any required fields marked as "required".
3.  Use the select_one fields to rate the dispensary's compliance with the relevant regulations or standards.
4.  Use the text fields for additional comments or observations.
5.  Ensure that you sign and date the form at the end, indicating that the inspection was performed.

## Field-by-Field Explanation

*   **Inspection Date** (`inspection_date`): The date of the inspection.
    *   This field should be filled out in the format YYYY-MM-DD.
    *   This field is required.
*   **Inspector Name** (`inspector_name`): The name of the inspector performing the inspection.
    *   This field is required.
*   **Dispensary Name** (`dispensary_name`): The name of the dispensary being inspected.
    *   This field is required.
*   **License Number** (`license_number`): The state or local license number of the dispensary.
    *   This field is required.
*   **Address** (`address`): The address of the dispensary.
    *   This field is required.
*   **Floor Cleanliness** (`floor_cleanliness`): The condition of the dispensary's floor area.
    *   This field uses a select_one format with the following options:
        +   Pass - Clean and well maintained
        +   Pass with conditions
        +   Fail - Dirty or hazardous
*   **Counter and Display Cleanliness** (`counter_cleanliness`): The condition of the dispensary's counter and display areas.
    *   This field uses a select_one format with the following options:
        +   Pass - Clean and organized
        +   Pass with conditions
        +   Fail - Dirty or disorganized
*   **Restroom Cleanliness** (`restroom_cleanliness`): The condition of the dispensary's restrooms.
    *   This field uses a select_one format with the following options:
        +   Pass - Clean and stocked
        +   Pass with conditions
        +   Fail - Dirty or poorly maintained
*   **Trash and Waste Management** (`trash_management`): The condition of the dispensary's trash and waste management.
    *   This field uses a select_one format with the following options:
        +   Pass - Properly managed
        +   Pass with conditions
        +   Fail - Overflowing or hazardous
*   **Product Storage and Handling** (`product_storage`): The condition of the dispensary's product storage and handling.
    *   This field uses a select_one format with the following options:
        +   Pass - Secure and properly stored
        +   Pass with conditions
        +   Fail - Improper storage
*   **Temperature and Humidity Control** (`temperature_control`): The condition of the dispensary's temperature and humidity control.
    *   This field uses a select_one format with the following options:
        +   Pass - Appropriate levels maintained
        +   Pass with conditions
        +   Fail - Out of range
*   **Inventory Tracking System** (`inventory_tracking`): The condition of the dispensary's inventory tracking system.
    *   This field uses a select_one format with the following options:
        +   Pass - System in place and accurate
        +   Pass with conditions
        +   Fail - Missing or inaccurate
*   **Expiration Date Compliance** (`expiration_dates`): The condition of the dispensary's product expiration date compliance.
    *   This field uses a select_one format with the following options:
        +   Pass - All products within expiration
        +   Pass with conditions
        +   Fail - Expired products found
*   **Security Surveillance System** (`surveillance_system`): The condition of the dispensary's security surveillance system.
    *   This field uses a select_one format with the following options:
        +   Pass - Functional and recording
        +   Pass with conditions
        +   Fail - Non-functional or missing
*   **Entry Control and Alarms** (`entry_control`): The condition of the dispensary's entry control and alarms.
    *   This field uses a select_one format with the following options:
        +   Pass - Secure and functioning
        +   Pass with conditions
        +   Fail - Inadequate security
*   **Employee ID and Access Logs** (`employee_id`): The condition of the dispensary's employee ID and access logs.
    *   This field uses a select_one format with the following options:
        +   Pass - System in place
        +   Pass with conditions
        +   Fail - Missing or incomplete
*   **Safe and Vault Security** (`safe_security`): The condition of the dispensary's safe and vault security.
    *   This field uses a select_one format with the following options:
        +   Pass - Secure and functional
        +   Pass with conditions
        +   Fail - Inadequate security
*   **Staff Licenses and Credentials** (`staff_credentials`): The condition of the dispensary's staff licenses and credentials.
    *   This field uses a select_one format with the following options:
        +   Pass - All staff properly credentialed
        +   Pass with conditions
        +   Fail - Missing credentials
*   **Training Records** (`training_records`): The condition of the dispensary's training records.
    *   This field uses a select_one format with the following options:
        +   Pass - Complete records available
        +   Pass with conditions
        +   Fail - Missing or incomplete
*   **License Display** (`license_display`): The condition of the dispensary's license display.
    *   This field uses a select_one format with the following options:
        +   Pass - License visible and current
        +   Pass with conditions
        +   Fail - Not displayed or expired
*   **Age Verification System** (`age_verification`): The condition of the dispensary's age verification system.
    *   This field uses a select_one format with the following options:
        +   Pass - System in place and functional
        +   Pass with conditions
        +   Fail - Missing or not functioning
*   **Additional Notes or Observations** (`additional_notes`): Additional comments or observations about the dispensary.
    *   This field is optional.
*   **Violations Found** (`violations_found`): List any violations found during the inspection.
    *   This field is optional.
*   **Corrective Actions Required** (`corrective_actions`): Actions required to address any found violations.
    *   This field is optional.

Please use this form to ensure that the dispensary is operating in a safe and compliant manner. Please complete the form accurately and thoroughly, and do not hesitate to contact us if you have any questions or concerns.
