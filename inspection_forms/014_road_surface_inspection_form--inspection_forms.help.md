# Road Surface Inspection Form - Help Guide
## Purpose
The Road Surface Inspection Form is used to collect data on the condition of road surfaces, allowing us to identify areas for improvement and maintain the integrity of our road networks.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the inspection date in the `Inspection Date` field.
2. Enter the inspection time in the `Inspection Time` field.
3. Enter the inspector's name in the `Inspector Name` field.
4. Select the location of the inspection from the list of options in the `Location` field.
5. For each option in the `Surface Condition` field, select all that apply.
6. Select the overall road condition from the list of options in the `Road Condition` field.
7. Add any relevant comments in the `Comments` field.
8. If applicable, select relevant photos and videos from the `Photos` and `Videos` fields.
9. Select the road surface inspector from the list of options in the `Road Surface Inspector` field.
10. Select the assigned tool user from the list of options in the `Assigned Tool User` field.
11. Enter the name of the assigned tool in the `Assigned Tool` field.
12. Enter the form ID in the `Form ID` field.
13. Select the created at date and time from the `Created At` field.
14. Select the updated at date and time from the `Updated At` field.
15. Select the deleted at date and time from the `Deleted At` field.
16. Enter the comments count in the `Comments Count` field.
17. Select the created by user from the list of options in the `Created By` field.
18. Select the updated by user from the list of options in the `Updated By` field.
19. Select the deleted by user from the list of options in the `Deleted By` field.
20. Select relevant comments from the `Comments` field.
21. Enter the photo count in the `Photo Count` field.
22. Enter the video count in the `Video Count` field.
23. Enter the tool count in the `Tool Count` field.

## Field-by-Field Explanation

* **Inspection Date** (`inspection_date`, `date`, required: false): Enter the date of the inspection.
* **Inspection Time** (`inspection_time`, `time`, required: false): Enter the time of the inspection.
* **Inspector Name** (`inspector_name`, `text`, required: false): Enter the name of the inspector.
* **Location** (`location`, `select_one`, required: false): Select the location of the inspection from the list of options.
* **Surface Condition** (`surface_condition`, `select_multiple`, required: false): Select all that apply for the surface condition.
* **Road Condition** (`road_condition`, `select_one`, required: false): Select the overall road condition from the list of options.
* **Comments** (`comments`, `note`, required: false): Add any relevant comments.
* **Photos** (`photos`, `select_multiple`, required: false): If applicable, select relevant photos.
* **Videos** (`videos`, `select_multiple`, required: false): If applicable, select relevant videos.
* **Road Surface Inspector** (`road_surface_inspector`, `select_one`, required: false): Select the road surface inspector from the list of options.
* **Assigned Tool User** (`assigned_tool_user`, `select_one`, required: false): Select the assigned tool user from the list of options.
* **Assigned Tool** (`assigned_tool`, `text`, required: false): Enter the name of the assigned tool.
* **Form ID** (`form_id`, `number`, required: false): Enter the form ID.
* **Created At** (`created_at`, `date`, required: false): Select the created at date and time.
* **Updated At** (`updated_at`, `date`, required: false): Select the updated at date and time.
* **Deleted At** (`deleted_at`, `date`, required: false): Select the deleted at date and time.
* **Comments Count** (`comments_count`, `number`, required: false): Enter the comments count.
* **Created By** (`created_by`, `select_one`, required: false): Select the created by user from the list of options.
* **Updated By** (`updated_by`, `select_one`, required: false): Select the updated by user from the list of options.
* **Deleted By** (`deleted_by`, `select_one`, required: false): Select the deleted by user from the list of options.
* **Comments** (`comments`, `select_multiple`, required: false): Select relevant comments.
* **Photo Count** (`photo_count`, `number`, required: false): Enter the photo count.
* **Video Count** (`video_count`, `number`, required: false): Enter the video count.
* **Tool Count** (`tool_count`, `number`, required: false): Enter the tool count.

## Tips

* Make sure to fill out the form accurately and thoroughly.
* Use the correct options for each field.
* If you are unsure about any field, consult with the inspector or the relevant authorities.
* Take clear and high-quality photos and videos to provide additional context.
* Keep the comments field concise and relevant.
