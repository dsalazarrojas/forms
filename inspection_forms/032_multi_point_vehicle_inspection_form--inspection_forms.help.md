# Multi Point Vehicle Inspection Form - Help Guide
## Purpose
The Multi Point Vehicle Inspection Form is designed to help inspect a vehicle's state in multiple aspects, such as exterior and interior conditions, engine condition, safety features, vehicle history, and inspection date.

## How To Complete This Form
1. Start by filling in the "Vehicle Info" section with the vehicle's details.
2. Evaluate and select the condition of the vehicle's exterior using the "Exterior Condition" dropdown menu.
3. Assess and select the condition of the vehicle's interior using the "Interior Condition" text field.
4. Evaluate and select the condition of the vehicle's engine using the "Engine Condition" dropdown menu.
5. List the safety features present or absent in the vehicle using the "Safety Features" multi-select menu.
6. Check if the vehicle has a history of previous issues or accidents using the "Vehicle History" dropdown menu.
7. Enter the date of the inspection using the "Inspection Date" date field.
8. Finally, add your signature as the inspector.

## Field-by-Field Explanation
* **Vehicle Info**: This field collects the basic information about the vehicle. Please enter the vehicle's make, model, and year.
* **Exterior Condition**: This field assesses the overall condition of the vehicle's exterior, such as body paint, tires, and overall appearance. Select one of the options:
	+ Excellent: No noticeable flaws
	+ Fair: Minor flaws or scratches
	+ Poor: Major flaws or damage
	+ Not Present: No exterior
* **Interior Condition**: This field evaluates the overall condition of the vehicle's interior, such as cleanliness, wear, and tear. Please enter your findings in the text field.
* **Engine Condition**: This field assesses the overall condition of the vehicle's engine, such as performance, leaks, and unusual noises. Select one of the options:
	+ Excellent: No noticeable issues
	+ Fair: Minor issues or performance decrease
	+ Poor: Major issues or performance loss
	+ Not Present: No engine or no engine available for inspection
* **Safety Features**: This field identifies safety features present or absent on the vehicle, such as airbags, seatbelts, or anti-lock brakes. Select all applicable options:
	+ Excellent: All safety features functioning as expected
	+ Fair: Some safety features not functioning or damaged
	+ Poor: No safety features or damaged/missing
	+ Not Present: No safety features or no vehicle
* **Vehicle History**: This field checks if the vehicle has a history of previous issues or accidents. Select one of the options:
	+ True: Vehicle has a history
	+ False: Vehicle has no history
* **Inspection Date**: This field records the date of the inspection. Please enter the date in the format YYYY-MM-DD.
* **Inspector Signature**: This field is for the inspector's signature, confirming that the inspection was performed.
