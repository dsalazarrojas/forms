# Data Center Security Inspection Form - Help Guide
## Purpose
This form is used to collect information for data center security inspections.

## How To Complete This Form
1. Please select the "Data Center Location" field to enter the address or name of the data center.
2. Enter the date of the security check in the "Security Check Date" field in the format YYYY-MM-DD.
3. Enter the time of the security check in the "Security Check Time" field in the format HH:MM AM/PM.
4. In the "Checked By" field, enter the name of the team or person responsible for conducting the security inspection.

## Field-by-Field Explanation
* **Data Center Location** (`data_center_location`, `text`, optional): Enter the address or name of the data center being inspected.
* **Security Check Date** (`security_check_date`, `date`, optional): Enter the date of the security check in the format YYYY-MM-DD.
* **Security Check Time** (`security_check_time`, `time`, optional): Enter the time of the security check in the format HH:MM AM/PM.
* **Checked By** (`checked_by`, `text`, optional): Enter the name of the team or person responsible for conducting the security inspection.

## Tips
* Make sure to enter accurate and complete information to ensure that the security inspection is thorough and effective.
* If you are unsure about any information, do not hesitate to consult with relevant personnel or authorities.
* This form is intended for data center security inspections only.
