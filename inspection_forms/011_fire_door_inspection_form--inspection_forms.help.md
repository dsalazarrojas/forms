# Fire Door Inspection Form - Help Guide
## Purpose
The Fire Door Inspection Form is used to inspect and record the condition of fire doors and fire exits in a building.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all fire doors and fire exits to be inspected from the list provided.
2. Evaluate the condition of each selected fire door or fire exit.
3. Choose the condition of each fire door or fire exit (Good, Fair, or Poor) based on the evaluation.
4. Record the date of the last inspection and the date of the next scheduled inspection.
5. Enter the inspection frequency for each fire door or fire exit.
6. Provide any comments or notes about the condition or inspection of each fire door or fire exit.
7. Select the action to take for each fire door or fire exit (Submit, Skip, or Cancel).

## Field-by-Field Explanation

* **Fire Doors** (`fire_doors`): Select all fire doors to be inspected from the list provided. This is a multiple-choice field with the following options: Fire Door 1, Fire Door 2, Fire Door 3, etc.
* **Fire Door Condition** (`fire_door_condition`): Choose the condition of each selected fire door (Good, Fair, or Poor) based on the evaluation. This is a single-choice field with the following options: Good, Fair, Poor.
* **Fire Door Last Inspection** (`fire_door_last_inspection`): Record the date of the last inspection for each fire door. Enter the date in the format YYYY-MM-DD.
* **Fire Door Next Inspection** (`fire_door_next_inspection`): Record the date of the next scheduled inspection for each fire door. Enter the date in the format YYYY-MM-DD.
* **Fire Door Inspection Frequency** (`fire_door_inspection_frequency`): Enter the frequency of inspections for each fire door, e.g., 1, 2, 3, etc.
* **Fire Door Comments** (`fire_door_comments`): Provide any comments or notes about the condition or inspection of each fire door.
* **Fire Exit Doors** (`fire_exits`): Select all fire exits to be inspected from the list provided. This is a multiple-choice field with the following options: Fire Exit 1, Fire Exit 2, Fire Exit 3, etc.
* **Fire Exit Condition** (`fire_exit_condition`): Choose the condition of each selected fire exit (Good, Fair, or Poor) based on the evaluation. This is a single-choice field with the following options: Good, Fair, Poor.
* **Fire Exit Last Inspection** (`fire_exit_last_inspection`): Record the date of the last inspection for each fire exit. Enter the date in the format YYYY-MM-DD.
* **Fire Exit Next Inspection** (`fire_exit_next_inspection`): Record the date of the next scheduled inspection for each fire exit. Enter the date in the format YYYY-MM-DD.
* **Fire Exit Inspection Frequency** (`fire_exit_inspection_frequency`): Enter the frequency of inspections for each fire exit, e.g., 1, 2, 3, etc.
* **Fire Exit Comments** (`fire_exit_comments`): Provide any comments or notes about the condition or inspection of each fire exit.
* **Submit** (`submit`): Select this option to submit the form. This is a single-choice field with the following options: Submit, Other. This field is required.
* **Skip** (`skip`): Select this option to skip the form. This is a single-choice field with the following options: Skip, Other. This field is optional.
* **Cancel** (`cancel`): Select this option to cancel the form. This is a single-choice field with the following options: Cancel, Other. This field is optional.
