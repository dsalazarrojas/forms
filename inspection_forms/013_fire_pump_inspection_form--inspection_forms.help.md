# fire_pump_inspection_form - Help Guide
## Purpose
The fire_pump_inspection_form is designed to gather information about the condition, location, type, maintenance status, last inspection date, Fire Station ID, and any notes related to the pump being inspected.

## How To Complete This Form

### Step 1: Determine the Pump Condition
Please select all the conditions that apply to the pump by clicking on the options below. 

* **Pump Condition** (`Pump Condition`, `select_multiple`, required): Select all the conditions that apply to the pump.
	+ Choose all that apply.

### Step 2: Identify the Pump Location
Enter the location of the pump.

* **Pump Location** (`Pump Location`, `text`, required): Enter the pump's location.
	+ Use the exact address of the pump location.

### Step 3: Specify the Pump Type
Select the type of pump.

* **Pump Type** (`Pump Type`, `select_one`, required): Select the pump type.
	+ Choose the type of pump being inspected.

### Step 4: Document Pump Maintenance
Enter the date of the most recent maintenance.

* **Pump Maintenance** (`Pump Maintenance`, `date`, required): Enter the date of the most recent maintenance.
	+ Use the format: MM/dd/yyyy.

### Step 5: Record Last Inspection
Enter the date of the last inspection.

* **Last Inspection** (`Last Inspection`, `date`, required): Enter the date of the last inspection.
	+ Use the format: MM/dd/yyyy.

### Step 6: Provide Fire Station ID
Enter the ID of the fire station.

* **Fire Station ID** (`Fire Station ID`, `text`, required): Enter the ID of the fire station.
	+ Use the exact ID assigned to the station.

### Step 7: Add Notes (Optional)
Record any additional notes about the pump inspection.

* **Notes** (`Notes`, `note`, required): Provide any additional notes or comments.
	+ Type them in the text field below. 

## Tips

* Please ensure to fill in all required fields.
* The format of dates should be in MM/dd/yyyy.
* If you're unsure about the condition or type of pump, it's best to check the relevant documentation or consult the fire station's records.
* If you're unable to find the pump, do not fill in the form. 
* Please save the form before submission to ensure no changes are lost during the submission process. 

Please use this form for actual pump inspections or other non-mandatory, optional, or information-gathering purposes.
