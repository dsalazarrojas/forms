# Tire Contact Patch Measurement Form - Help Guide
## Purpose
The Tire Contact Patch Measurement Form is designed for inspecting tire contact patches for wear. It is an essential tool for ensuring accurate and thorough reporting during tire inspections.

## How To Complete This Form
To complete this form, follow these steps:
- Start by checking the contact patch for any signs of wear.
  - If you find wear, select "Yes" for the corresponding field.
  - If there is no wear, select "No".
- Record the date and time of the inspection by selecting a valid date and time.
  - Use the date picker to choose the correct date.
  - Use the time picker to choose the correct time.
- If you need to leave a note about the inspection, use the note field.
  - This is for any additional information that might be relevant to the inspection.
- If you need to be contacted for further clarification or next steps, provide your email or phone number in the contact fields.
  - This information will be used for follow-up communication.
