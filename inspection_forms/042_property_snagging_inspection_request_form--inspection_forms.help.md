# Property Snagging Inspection Request Form - Help Guide
## Purpose

This form is used to request a property snagging inspection from the inspection team. 

## How To Complete This Form

1. **Step 1: Property Details**
	* **Property ID (property_id)** (`<text>`, **required**): Enter the ID number of the property that requires inspection.
2. **Step 2: Inspection Details**
	* **Property Type (property_type)** (`<select one>`, **required**): Select the type of property that requires inspection (Residential, Commercial, or Other).
	* **Inspection Type (inspection_type)** (`<select multiple>`, **required**): Select the type of inspection required (Snagging, Walk Through, or Other).
3. **Step 3: Additional Details**
	* **Inspection Date (inspection_date)** (`<date>`, **optional**): Enter the date of the inspection (optional).
	* **Inspection Time (inspection_time)** (`<time>`, **optional**): Enter the time of the inspection (optional).
4. **Step 4: Request Details**
	* **Property Address (property_address)** (`<text>`, **required**): Enter the address of the property that requires inspection.
	* **Inspection Requester (inspection_requester)** (`<text>`, **required**): Enter the name and contact information of the person requesting the inspection.
	* **Request Details (request_details)** (`<text>`, **required**): Enter any additional details about the inspection request.
5. **Step 5: Inspection Schedule**
	* **Inspection Schedule (inspection_schedule)** (`<select one>`, **required**): Select the schedule for the inspection (Immediate, Within 24 hours, Within 48 hours, or Custom).
6. **Step 6: Follow-up Inspection**
	* **Follow-up Inspection (follow_up_inspection)** (`<select one>`, **optional**): Select whether a follow-up inspection is required (True or False).

## Tips

* Please ensure that all required fields are filled in correctly and accurately.
* If you have any special requests or requirements, please provide additional details in the Request Details field.
* If you need a custom inspection schedule, please select "Custom" in the Inspection Schedule field and provide further details in the Request Details field.
* If a follow-up inspection is required, please select "True" in the Follow-up Inspection field.
