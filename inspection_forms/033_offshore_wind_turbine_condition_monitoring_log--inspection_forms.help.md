# offshore_wind_turbine_condition_monitoring_log - Help Guide
## Purpose
The offshore wind turbine condition monitoring log is used to gather information about the status of offshore wind turbines. This includes their condition, monitoring systems, and other relevant details.

## How To Complete This Form

1. **General Info**: This field is not required, but it's where you can enter any general information about the turbine.
2. **Turbine Details**: Enter a brief description of the turbine, including its status (active/inactive), monitoring system, and other relevant details.
3. **Condition Status**: Select the current status of the turbine (active or inactive).
4. **Monitoring System**: Select whether a monitoring system is in place.
5. **Monitoring System Type**: Select the type of monitoring system used.
6. **Issues Reported**: Select any issues that have been reported about the turbine.
7. **Condition Status Description**: Enter a brief description of the turbine's condition.
8. **Condition Status Comments**: Add any additional comments about the turbine's condition.
9. **Turbine Inspection**: Enter the date of the last turbine inspection.
10. **Monitoring Frequency**: Select the frequency of monitoring.
11. **Monitoring Start Date**: Enter the date when monitoring started.
12. **Monitoring End Date**: Enter the date when monitoring ended.
13. **Comments**: Add any additional comments about the form.
14. **Signature**: Sign and date this form to confirm that it's been completed.
15. **Email**: Enter your contact email.
16. **Phone**: Enter your contact phone number.
17. **Address**: Select whether the turbine is located at your address.
18. **Location**: Select the location of the turbine.
19. **Contact Person**: Select the contact person for the turbine.
20. **Department**: Select the department responsible for the turbine.
21. **Team Lead**: Select the team lead for the turbine.
22. **Team Members**: Select any team members involved with the turbine.
23. **Issue Description**: Enter a brief description of any issues reported about the turbine.
24. **Action Taken**: Enter a brief description of any actions taken on the turbine.
25. **Follow-up**: Enter any follow-up information about the turbine.
