# Ingredient Contaminant Alert Report Form - Help Guide
## Purpose
The purpose of this form is to report potential contaminants in ingredients to ensure their safety and quality.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the ingredient name in the "Ingredient" field.
2. Select the contaminant type from the list in the "Contaminant Type" field.
3. Choose the severity of the contaminant from the list in the "Severity" field.
4. Select the location where the contaminant was found from the list in the "Location" field.
5. If available, upload photos of the contaminant in the "Photos" field.
6. Add any additional notes or comments about the contaminant in the "Notes" field.

## Field-by-Field Explanation
* **Ingredient** (1, text, required): Enter the name of the ingredient that may be contaminated.
* **Contaminant Type** (2, select_one, optional): Select the type of contaminant found from the list (Type A, Type B, Type C).
* **Severity** (3, select_multiple, optional): Select all relevant severity levels from the list (Low, Moderate, High).
* **Location** (4, select_one, optional): Select the location where the contaminant was found from the list (Room A, Room B, Room C).
* **Photos** (5, text, optional): If available, upload photos of the contaminant as evidence.
* **Notes** (6, text, optional): Add any additional comments or notes about the contaminant.

## Tips
* Be as detailed as possible when completing the form to ensure accurate reporting.
* Use the correct format for uploading photos.
* Only report contaminants that have been identified during the inspection process.
* If unsure, seek guidance from the relevant authorities or our support team.
