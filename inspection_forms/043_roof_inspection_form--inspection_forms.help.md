# Roof Inspection Form - Help Guide
## Purpose
The Roof Inspection Form is designed to gather information about a roof inspection. It's intended for roofing inspectors to document their findings and provide relevant details about the roof's condition, type, area, and inspection date. The form also allows for photos and notes to be included.

## How To Complete This Form

To complete the form, follow these steps:

1. Select the general roof condition from the options provided. If none of the options match your assessment, feel free to add a description in the "Description" field.
2. Choose the type of roof from the available options. If none of the options match your assessment, select "Other" and describe the roof type in the "Roof Type Description" field.
3. Enter the roof area, either using the number or text input field.
4. Select the inspection date.
5. Add any relevant photos or descriptions.
6. Enter the contact information, including email and phone numbers.
7. Add any additional notes or photos.

## Field-by-Field Explanation

* **General Roof Condition**: Select the overall condition of the roof. Options include Good, Fair, Poor, and Critical.
* **Roof Type**: Choose the type of roof, which includes Asphalt, Clay, Metal, Slate, and Tile.
* **Roof Area**: Enter the area of the roof using the number input field.
* **Inspection Date**: Select the date of the inspection.
* **Description**: Add any additional description about the roof.
* **Roof Type Description**: Add any further description about the roof type.
* **Photos**: Attach any photos that support your findings.
* **Contact Email**: Enter the email address to contact you.
* **Contact Phone**: Enter a phone number to contact you.
* **Contact Phone 2**: Enter a secondary phone number to contact you.
* **Contact Email 2**: Enter a secondary email address to contact you.
* **Notes**: Add any additional notes or comments.
* **Roof Condition 2**: Select the condition of the second roof.
* **Roof Type 2**: Choose the type of second roof.
* **Roof Area 2**: Enter the area of the second roof.
* **Inspection Date 2**: Select the inspection date for the second roof.
* **Photos 2**: Attach any photos related to the second roof.
* **Notes 2**: Add any additional notes or comments for the second roof.
* **General Roof Condition 2**: Select the condition of the second roof.
* **Roof Type 2**: Choose the type of second roof.
* **Roof Area 2**: Enter the area of the second roof.
* **Inspection Date 2**: Select the inspection date for the second roof.
* **Photos 3**: Attach any photos related to the third roof.
* **Notes 3**: Add any additional notes or comments for the third roof.

Note: Some fields might not be applicable for certain types of roofs or have redundant information.
