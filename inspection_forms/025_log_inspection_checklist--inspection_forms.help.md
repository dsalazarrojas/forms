# Log Inspection Checklist - Help Guide
## Purpose
The Log Inspection Checklist is a form used to document the results of a log inspection. It is designed to gather information about the inspection process, location, and any findings or issues that arose during the inspection.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reviewing the introduction page and familiarize yourself with the form's purpose and objectives.
2. Select the date the inspection was completed.
3. Enter your name and title as the inspector.
4. Provide a brief description of the location inspected.
5. List any equipment that was inspected.
6. Document any findings or issues that arose during the inspection.
7. Check the boxes to confirm if safety procedures and standards were followed.
8. Provide a brief description of any actions taken to address any issues.
9. Enter any additional comments or notes about the inspection.
10. Date and sign the form to confirm completion.

## Field-by-Field Explanation

* **Introduction** (`introduction`, note, required: false): The introduction page provides a brief overview of the form and its purpose.
* **Date Completed** (`date_completed`, date, required: false): Enter the date the inspection was completed.
* **Inspector Name** (`inspector_name`, text, required: false): Enter your name and title as the inspector.
* **Location Inspected** (`location_inspected`, text, required: false): Provide a brief description of the location inspected.
* **Equipment Inspected** (`equipment_inspected`, text, required: false): List any equipment that was inspected.
* **Inspection Findings** (`inspection_findings`, text, required: false): Document any findings or issues that arose during the inspection.
* **Safety Procedures** (`safety_procedures`, select multiple, required: false): Check the box to confirm if safety procedures were followed during the inspection.
* **Safety Standards** (`safety_standards`, select multiple, required: false): Check the box to confirm if safety standards were followed during the inspection.
* **Action Taken** (`action_taken`, text, required: false): Provide a brief description of any actions taken to address any issues.
* **Comments** (`comments`, text, required: false): Enter any additional comments or notes about the inspection.
* **Signature** (`signature`, date, required: false): Date and sign the form to confirm completion.
