# Mobile Home Inspection Form - Help Guide
## Purpose
This form is used to collect information about a mobile home's address, condition, and features during an inspection.

## How To Complete This Form
To complete this form, please answer the questions accurately and completely. Start by filling out the required fields, and then add any additional comments or notes as needed.

## Field-by-Field Explanation

* **Home Address** (`home_address`, text, required): Enter the address of the mobile home you're inspecting.
* **Mobile Type** (`mobile_type`, select_one, optional): Answer 'Yes' if the mobile home is a type that requires a specific type of inspection (e.g. double-wide, single-wide). Answer 'No' otherwise.
* **Year Built** (`year_built`, text, optional): Enter the year the mobile home was built.
* **Location** (`location`, text, required): Enter the location where the mobile home is situated.
* **Home Features** (`home_features`, text, required): Describe any notable features of the mobile home, such as the number of bedrooms or bathrooms.
* **Property Condition** (`property_condition`, select_one, optional): Answer 'Yes' if the property condition is satisfactory. Answer 'No' otherwise.
* **Electrical Systems** (`electrical_systems`, select_multiple, optional): Select all applicable electrical systems (e.g. 100Amp, 200Amp, Other).
* **Plumbing Systems** (`plumbing_systems`, select_multiple, optional): Select all applicable plumbing systems (e.g. Copper, Pex, Other).
* **Heating Systems** (`heating_systems`, select_multiple, optional): Select all applicable heating systems (e.g. Gas, Electric, Other).
* **Cooling Systems** (`cooling_systems`, select_multiple, optional): Select all applicable cooling systems (e.g. Air Conditioning, Other).
* **Roof Condition** (`roof_condition`, select_one, optional): Answer 'Yes' if the roof condition is satisfactory. Answer 'No' otherwise.
* **Foundation Condition** (`foundation_condition`, select_one, optional): Answer 'Yes' if the foundation condition is satisfactory. Answer 'No' otherwise.
* **Exterior Condition** (`exteriror_condition`, select_one, optional): Answer 'Yes' if the exterior condition is satisfactory. Answer 'No' otherwise.
* **Basement Condition** (`basement_condition`, select_one, optional): Answer 'Yes' if the basement condition is satisfactory. Answer 'No' otherwise.
* **Crawl Space Condition** (`crawl_space_condition`, select_one, optional): Answer 'Yes' if the crawl space condition is satisfactory. Answer 'No' otherwise.
* **Electrical Systems Notes** (`electrical_systems_notes`, text, optional): Enter any notes about the electrical systems.
* **Plumbing Systems Notes** (`plumbing_systems_notes`, text, optional): Enter any notes about the plumbing systems.
* **Heating Systems Notes** (`heating_systems_notes`, text, optional): Enter any notes about the heating systems.
* **Cooling Systems Notes** (`cooling_systems_notes`, text, optional): Enter any notes about the cooling systems.
* **Roof Notes** (`roof_notes`, text, optional): Enter any notes about the roof.
* **Foundation Notes** (`foundation_notes`, text, optional): Enter any notes about the foundation.
* **Exterior Notes** (`exteriror_notes`, text, optional): Enter any notes about the exterior.
* **Basement Notes** (`basement_notes`, text, optional): Enter any notes about the basement.
* **Crawl Space Notes** (`crawl_space_notes`, text, optional): Enter any notes about the crawl space.
* **Additional Notes** (`additional_notes`, text, optional): Enter any additional comments or notes about the mobile home.
