# Sky Rider Template - Help Guide
## Purpose
The Sky Rider Template is a simple form designed to collect user input and inspection details. It is intended for use in controlled environments, such as factories, warehouses, or laboratories, where users need to provide their personal information and inspection notes.

## How To Complete This Form
To complete the Sky Rider Template, follow these steps:

1. On the "User Input Page", enter your name as required.
2. On the "Inspection Details" page, enter any relevant inspection notes or comments.
3. On the "Date and Time" page, select the date and time of the inspection.
4. Review your input before submitting the form.

## Field-by-Field Explanation

* **User Input Page (Text)**: Enter your name as prompted. This field is required.
* **Inspection Details (Text)**: Enter any relevant inspection notes or comments. This field is optional.
* **Date and Time (Date)**: Select the date and time of the inspection. This field is required.
  (Note: The date field is expected to be a standard date format, i.e., MM/DD/YYYY.)
