# highway_safety_inspection_form - Help Guide
## Purpose
This form is intended to collect data on highway safety inspection information for personal or educational purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing general inspection information on the first page.
2. On the second page, enter details about the vehicle being inspected.
3. On the third page, select the safety features of the vehicle.
4. On the fourth page, choose the road surface conditions.
5. On the fifth page, select the road geometry.
6. On the sixth page, select the road visibility.
7. On the seventh page, select the traffic signals.
8. On the eighth page, select the traffic signs.

## Field-by-Field Explanation
* **General Inspection Info** (`general_inspection_info`, text, required: false): This field is for entering the general inspection information.
* **vehicle_inspectee_info** (`vehicle_inspectee_info`, text, required: false): This field is for entering details about the vehicle being inspected.
* **Vehicle Info** (`vehicle_info`, text, required: false): This field is for entering information about the vehicle.
* **Safety Features** (`safety_features`, select_multiple, required: false): Select all safety features that apply:
	+ Safety Feature 1
	+ Safety Feature 2
	+ Safety Feature 3
* **Road Surface Conditions** (`road_surface_conditions`, select_one, required: false): Choose the condition of the road surface:
	+ Good
	+ Fair
	+ Poor
* **Road Geometry** (`road_geometry`, select_one, required: false): Choose the geometry of the road:
	+ Straight
	+ Curved
	+ Slight Curve
* **Road Visibility** (`road_visibility`, select_one, required: false): Choose the visibility of the road:
	+ Good
	+ Fair
	+ Poor
* **Traffic Signals** (`traffic_signals`, select_multiple, required: false): Select all traffic signals that apply:
	+ Traffic Signal 1
	+ Traffic Signal 2
	+ Traffic Signal 3
* **Traffic Signs** (`traffic_signs`, select_multiple, required: false): Select all traffic signs that apply:
	+ Traffic Sign 1
	+ Traffic Sign 2
	+ Traffic Sign 3

## Tips
* Please fill out the form carefully and accurately.
* If you're unsure about any field, refer to the field's label for clarification.
* This form is intended for personal or educational use only.
