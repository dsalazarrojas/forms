# Library Facility Inspection Form - Help Guide
## Purpose
This form is used to inspect the library facilities for safety and emergency equipment, ensuring that all equipment is in good working condition and that regular maintenance is performed.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information about the facility being inspected.
2. Select the appropriate options for each field, taking into account the condition of the equipment.
3. Date fields are in the format MM/DD/YYYY.

## Field-by-Field Explanation

* **Facility Name** (1, text, required): Enter the name of the library facility being inspected.
* **Location** (2, text, required): Enter the location of the library facility being inspected.
* **Date Completed** (3, date, required): Enter the date the inspection was completed.
* **Safety Equipment in Good Working Condition** (4, select multiple, optional): Check the boxes to indicate which safety equipment is in good working condition.
* **Safety Equipment in Need of Repair** (5, select multiple, optional): Check the boxes to indicate which safety equipment is in need of repair.
* **Fire Drill Last Conducted** (6, date, optional): Enter the date the last fire drill was conducted.
* **Fire Drill Last Conducted Date** (7, date, optional): Enter the date of the last fire drill.
* **Fire Extinguishing Equipment in Good Working Condition** (8, select multiple, optional): Check the boxes to indicate which fire extinguishing equipment is in good working condition.
* **Fire Extinguishing Equipment in Need of Repair** (9, select multiple, optional): Check the boxes to indicate which fire extinguishing equipment is in need of repair.
* **Fire Extinguishing Equipment Last Service Date** (10, date, optional): Enter the date the last fire extinguishing equipment was serviced.
* **Fire Safety Plan** (11, text, optional): Enter a brief description of the fire safety plan.
* **Exit Signs** (12, text, optional): Enter the condition of exit signs.
* **Emergency Exit Signs Last Serviced** (13, date, optional): Enter the date the last emergency exit signs were serviced.
* **Emergency Exit Signs Last Serviced Date** (14, date, optional): Enter the date the last emergency exit signs were serviced.
* **Safety Signs** (15, text, optional): Enter a brief description of safety signs.
* **Emergency Exit Lamps Last Serviced** (16, date, optional): Enter the date the last emergency exit lamps were serviced.
* **Emergency Exit Lamps Last Serviced Date** (17, date, optional): Enter the date the last emergency exit lamps were serviced.
* **Electrical Equipment in Good Working Condition** (18, select multiple, optional): Check the boxes to indicate which electrical equipment is in good working condition.
* **Electrical Equipment in Need of Repair** (19, select multiple, optional): Check the boxes to indicate which electrical equipment is in need of repair.
* **Electrical Equipment Last Serviced** (20, date, optional): Enter the date the last electrical equipment was serviced.
* **Electrical Equipment Last Serviced Date** (21, date, optional): Enter the date the last electrical equipment was serviced.
* **Electrical Outlets** (22, text, optional): Enter a brief description of electrical outlets.
* **Emergency Exit Doors in Good Working Condition** (23, select multiple, optional): Check the boxes to indicate which emergency exit doors are in good working condition.
* **Emergency Exit Doors in Need of Repair** (24, select multiple, optional): Check the boxes to indicate which emergency exit doors are in need of repair.
* **Emergency Exit Doors Last Serviced** (25, date, optional): Enter the date the last emergency exit doors were serviced.

## Tips
* Take a moment to review each field carefully before submitting the form.
* If a field is required, make sure to fill it in with accurate information.
* Select the correct options for each field based on the actual condition of the equipment.
