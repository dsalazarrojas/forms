# Underground Insulation Resistance Testing Form - Help Guide
## Purpose
The Underground Insulation Resistance Testing Form is designed to collect and record data related to underground insulation resistance testing. This form is used for documenting test data and results, including the type of insulation used, resistance readings, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Inspection Date** in the corresponding field. This is the date on which the insulation resistance test was conducted.
2.  Enter the **Test Conducted By** field with the name of the person or organization conducting the test.
3.  Enter the **Test Location** where the test was performed.
4.  Enter a numeric value in the **Temperature** field, as this is likely the temperature at which the test was conducted.
5.  Enter two numeric values for **Resistance Reading 1** and **Resistance Reading 2**. These readings are likely the results of the insulation resistance tests.
6.  Select the **Insulation Type** from the provided options: Fiberglass, XPS, EPS, or Other.
7.  Enter any additional notes in the **Notes** field about the test or any relevant details.
8.  Enter any submission notes or comments in the **Submission Notes** field, if necessary.

## Field-by-Field Explanation

*  **Inspection Date**: Enter the date on which the insulation resistance test was conducted.
*  **Test Conducted By**: Enter the name of the person or organization conducting the test.
*  **Test Location**: Enter the location where the test was performed.
*  **Temperature**: Enter a numeric value representing the temperature at which the test was conducted.
*  **Resistance Reading 1** and **Resistance Reading 2**: Enter two numeric values representing the results of the insulation resistance tests.
*  **Insulation Type**: Select the type of insulation used from the provided options.
*  **Notes**: Enter any additional notes or comments about the test.
*  **Submission Notes**: Enter any submission notes or comments, if necessary.

## Tips
- Make sure to fill out all required and optional fields as accurately and completely as possible.
- Double-check the **Insulation Type** to ensure it reflects the correct type of insulation used.
- Review all fields before submitting the form to ensure accuracy and completeness of the data entered.
