# UVA MLR Project Management Review Form - Help Guide
## Purpose
The form is designed to collect information about a UVA MLR project, allowing project stakeholders to track and evaluate project progress, identify potential issues, and plan future actions.

## How To Complete This Form
To complete this form, please follow these steps:

*   Fill in the project name and description.
*   Choose the current status of the project (Active, On Hold, or Completed).
*   Select the next steps to be taken (Continue project as is, Change project scope, Put on hold, or Terminate project).
*   If necessary, add any issues or concerns with the project.
*   Describe the plans for moving forward.
*   Enter the follow-up date and location (if applicable).
*   Add any follow-up notes or comments.
*   Identify the project manager and lead.
*   List the team members involved in the project.
*   Specify the roles of each team member (Project Manager, Team Lead, Team Member, or Other).
*   Enter the review date.

## Field-by-Field Explanation

*   **Project Name** (project\_name, text, required): Enter the name of the project being reviewed.
*   **Project Description** (project\_description, text, optional): Provide a brief description of the project.
*   **Current Status** (current\_status, select\_one, optional): Select the current status of the project from the options:
    *   Active
    *   On Hold
    *   Completed
*   **Next Steps** (next\_steps, select\_multiple, optional): Select the next steps to be taken for the project from the options:
    *   Continue project as is
    *   Change project scope
    *   Put on hold
    *   Terminate project
*   **Issues** (issues, text, optional): If there are any issues or concerns with the project, describe them here.
*   **Plans** (plans, text, optional): Describe the plans for moving forward with the project.
*   **Follow-up** (follow\_up, date, optional): Enter the follow-up date (if applicable).
*   **Follow-up Location** (follow-up\_location, text, optional): Enter the location for the follow-up (if applicable).
*   **Follow-up Notes** (follow-up\_notes, text, optional): Add any follow-up notes or comments.
*   **Project Manager** (project\_manager, text, optional): Identify the project manager.
*   **Project Lead** (project\_lead, text, optional): Identify the project lead.
*   **Team Members** (team\_members, select\_multiple, optional): List the team members involved in the project from the options:
    *   John
    *   Jane
    *   Joe
*   **Team Members Roles** (team\_members\_roles, select\_multiple, optional): Specify the roles of each team member from the options:
    *   Project Manager
    *   Team Lead
    *   Team Member
    *   Other
*   **Review Date** (review\_date, date, optional): Enter the review date.

## Tips
*   Be sure to fill out all applicable fields to ensure a comprehensive review of the project.
