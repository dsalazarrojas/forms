# Mobile Inspection Form - Help Guide
## Purpose
The Mobile Inspection Form is designed to collect data about the inspection process for mobile inspections. This form can be used to record details about the category, description, assigned tool, and date of the inspection.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the category of the inspection from the list provided in the "Category" field.
2. Provide a brief description of the inspection in the "Description" field.
3. Choose the assigned tool used for the inspection from the list provided in the "Assigned Tool" field.
4. Input the date of the inspection in the "Date" field.

## Field-by-Field Explanation
### Category
* **Category** (`Category`, `select_one`, optional): Select the category of the inspection from the list provided. This will help to group inspections by type.

### Description
* **Description** (`Description`, `text`, optional): Enter a brief description of the inspection, including any relevant details about the process, results, or findings.

### Assigned Tool
* **Assigned Tool** (`Assigned Tool`, `select_one`, optional): Choose the tool used for the inspection from the list provided. This can be a critical piece of equipment or a software tool used for the inspection.

### Date
* **Date** (`Date`, `date`, optional): Input the date of the inspection in the standard date format (DD/MM/YYYY).

## Tips
* Ensure that you select the correct category and description to ensure accurate grouping and understanding of the inspection results.
* If you are unsure about the assigned tool, you can choose "other" and provide additional information in the description field.
* Make sure to input the correct date of the inspection to ensure accurate record-keeping and future reference.
