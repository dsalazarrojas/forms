# Location Scan Request Form - Help Guide

## Purpose

This form is used to collect information for location scan requests. It gathers details such as scan dates, times, durations, types, and status updates to track the scan process.

## How To Complete This Form

1. Fill in the required fields:
	* `scan_date`
	* `scan_time`
	* `scan_type`
	* `scan_status`
2. You can optionally provide additional information in the fields:
	* `location_details`
	* `scan_duration`
	* `authorization_details`
	* `on_site_visit` 
	* `on_site_visit_date`
	* `on_site_visit_time`
	* `on_site_visit_duration`
	* `on_site_visit_comments`
	* `scan_comments`
	* `scan_date2`
	* `scan_time2`
	* `scan_duration2`
	* `scan_type2`
	* `scan_status2`
	* `comments2`
	* `authorization_details2`
	* `on_site_visit2`
	* `on_site_visit2_date`
	* `on_site_visit2_time`
	* `on_site_visit2_duration`
	* `on_site_visit2_comments`
	* `on_site_visit2_status`
	* `on_site_visit2_notes`
	* `on_site_visit2_scan_comments`

## Field-by-Field Explanation

* **location_details (1)**: Enter a brief description of the location to be scanned.
* **scan_date (2)**: Select the date of the scan.
* **scan_time (3)**: Select the time of the scan.
* **scan_duration (4)**: Enter the duration of the scan in minutes.
* **scan_type (5)**: Select the type of scan:
	+ `walk through`
	+ `visual inspection`
	+ `audit`
	+ `audit with video`
* **scan_status (6)**: Select the current status of the scan:
	+ `suggested`
	+ `declined`
	+ `pending`
	+ `approved`
* **comments (7)**: Add any additional comments about the scan.
* **authorization_details (8)**: Enter any relevant authorization details.
* **on_site_visit (9)**: Select if the scan will be conducted on-site:
	+ `yes`
	+ `no`
* **on_site_visit_date (10)**: Select the date of the on-site visit.
* **on_site_visit_time (11)**: Select the time of the on-site visit.
* **on_site_visit_duration (12)**: Enter the duration of the on-site visit in minutes.
* **on_site_visit_comments (13)**: Add any additional comments about the on-site visit.
* **on_site_visit_status (14)**: Select the current status of the on-site visit:
	+ `suggested`
	+ `declined`
	+ `pending`
	+ `approved`
* **on_site_visit_notes (15)**: Enter any additional notes about the on-site visit.
* **on_site_visit2 (16)**: Select if the second on-site visit will be conducted:
	+ `yes`
	+ `no`
* **on_site_visit2_date (17)**: Select the date of the second on-site visit.
* **on_site_visit2_time (18)**: Select the time of the second on-site visit.
* **on_site_visit2_duration (19)**: Enter the duration of the second on-site visit in minutes.
* **on_site_visit2_status (20)**: Select the current status of the second on-site visit:
	+ `suggested`
	+ `declined`
	+ `pending`
	+ `approved`
* **on_site_visit2_comments (21)**: Add any additional comments about the second on-site visit.
* **scan_type2 (22)**: Select the type of scan for the second on-site visit:
	+ `walk through`
	+ `visual inspection`
	+ `audit`
	+ `audit with video`
* **scan_date2 (23)**: Select the date of the second scan.
* **scan_time2 (24)**: Select the time of the second scan.
* **scan_duration2 (25)**: Enter the duration of the second scan in minutes.
* **scan_status2 (26)**: Select the current status of the second scan:
	+ `suggested`
	+ `declined`
	+ `pending`
	+ `approved`
* **comments2 (27)**: Add any additional comments about the second scan.
* **authorization_details2 (28)**: Enter any relevant authorization details for the second scan.
* **on_site_visit2_scan_comments (29)**: Add any additional comments about the second on-site visit.
* **scan_comments (30)**: Add any additional comments about the scan.

## Tips

* Make sure to fill out all required fields before submitting the form.
* You can add comments for both the main scan and on-site visit.
* If you are conducting multiple on-site visits, fill out the corresponding fields for each visit.
* If you have any additional comments, use the `comments` and `comments2` fields for the main scan and second on-site visit respectively.
