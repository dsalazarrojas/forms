# Tech Software Quality Assurance Inspection Form - Help Guide
## Purpose
This form is designed to help quality assurance teams track and document the progress of software releases and builds, including findings and actions taken.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the release date from the list of options (Release 1, Release 2, Release 3) in the "Release" field (id: 2).
2. Choose all relevant builds for the selected release in the "Build" field (id: 3).
3. Enter the date of the inspection in the "Date" field (id: 4) if required.
4. Enter the time of the inspection in the "Time" field (id: 5) if required.
5. In the "Findings" field (id: 6), describe any issues or defects found during the inspection.
6. In the "Actions Taken" field (id: 7), describe any corrective actions taken or planned to address the findings.
7. Optionally, provide release notes in the "Release Notes" field (id: 8) if necessary.
8. Optionally, provide build notes in the "Build Notes" field (id: 9) if necessary.
9. In the "QA Review" field (id: 10), provide any additional comments or feedback on the inspection.

## Field-by-Field Explanation
* **Software Inspection Form** (id: 1): Enter a title or description for the inspection.
* **Release** (id: 2): Select the release date for which the inspection is being performed.
	+ Options: Release 1, Release 2, Release 3
* **Build** (id: 3): Choose all relevant builds for the selected release.
	+ Options: Build 1, Build 2, Build 3
* **Date** (id: 4): Enter the date of the inspection if required.
* **Time** (id: 5): Enter the time of the inspection if required.
* **Findings** (id: 6): Describe any issues or defects found during the inspection.
* **Actions Taken** (id: 7): Describe any corrective actions taken or planned to address the findings.
* **Release Notes** (id: 8): Provide release-specific notes if necessary.
* **Build Notes** (id: 9): Provide build-specific notes if necessary.
* **QA Review** (id: 10): Provide any additional comments or feedback on the inspection.
