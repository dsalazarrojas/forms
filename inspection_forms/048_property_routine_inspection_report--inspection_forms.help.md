# property_routine_inspection_report - Help Guide
## Purpose
This form is used to report on the results of a routine property inspection, which is a regular check-up to evaluate the condition and state of a property. The form collects information about the property's inspection status, size, age, condition, and other details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the inspection status of the property from the options on page 1.
2. Enter the property address on page 2.
3. Enter the property size on page 3.
4. Select the age of the property on page 4.
5. Check the condition of the property on page 5.
6. Indicate whether rooms were photographed during the inspection on page 6.
7. (Optional) Add any additional photographs or comments in the note field on page 7.
8. (Optional) Add any additional notes or comments in the note field on page 8.

## Field-by-Field Explanation

* **property_inspection** (`property_inspection`, select_multiple, required/optional): Select the current inspection status of the property. This field helps the user understand the property's current state.
* **property_address** (`property_address`, text, required/optional): Enter the address of the property being inspected. This field is used to identify the property.
* **property_size** (`property_size`, number, required/optional): Enter the size of the property. This field helps the user understand the property's size and space.
* **property_age** (`property_age`, select_one, required/optional): Select the age of the property. This field helps the user understand how old the property is.
* **property_condition** (`property_condition`, select_multiple, required/optional): Check the condition of the property. This field helps the user understand the property's current state of repair and maintenance.
* **rooms_photographed** (`rooms_photographed`, select_multiple, required/optional): Check whether rooms were photographed during the inspection. This field helps the user understand if the inspection included photographs.
* **photographs** (`photographs`, note, required/optional): Add any additional photographs or comments about the property. This field is used for any extra information that doesn't fit in other fields.
* **notes** (`notes`, note, required/optional): Add any additional comments or information about the inspection. This field is used for any extra information that doesn't fit in other fields.
