# Flooring Inspection Checklist - Help Guide
## Purpose
The Flooring Inspection Checklist is used to assess the condition and type of flooring in a property. It helps to identify the flooring type, condition, and any additional notes or comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of property from the select options.
2. Select the type of flooring from the select options.
3. Enter the square footage of the property.
4. Enter the number of rooms in the property.
5. Enter any additional notes or comments about the property.

## Field-by-Field Explanation

* **Form Header** (`inspection_form_header`, note, optional): This is a header section that provides a brief overview of the form.
* **property_type** (`property_type`, select_one, optional): Select the type of property (e.g. living room, kitchen, bedroom, etc.). This field helps to identify the specific area of the property being inspected.
* **square_footage** (`square_footage`, number, optional): Enter the total square footage of the property. This field is used to calculate the total area of the property.
* **room_count** (`room_count`, number, optional): Enter the number of rooms in the property. This field helps to calculate the total number of rooms in the property.
* **room_type** (`room_type`, select_one, required): Select the type of room (e.g. living room, kitchen, bedroom, etc.). This field is used to identify the specific type of room being inspected.
* **flooring_type** (`flooring_type`, select_one, required): Select the type of flooring (e.g. hardwood, tile, laminate, etc.). This field is used to identify the type of flooring in the property.
* **condition** (`condition`, select_one, required): Select the condition of the flooring (e.g. excellent, good, fair, poor). This field helps to identify any issues or concerns with the flooring.
* **notes** (`notes`, note, optional): Enter any additional notes or comments about the property. This field is used to provide further information about the property.
* **additional_notes** (`additional_notes`, note, optional): Enter any additional notes or comments about the property. This field is used to provide further information about the property.

## Tips
* Make sure to select the correct property type and room type to ensure accurate results.
* Enter accurate and complete information in the square footage and room count fields to ensure accurate calculations.
* Use the condition field to identify any issues or concerns with the flooring.
* Use the notes and additional notes fields to provide further information about the property.
