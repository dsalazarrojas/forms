# Electrical Infrastructure - Help Guide
## Purpose
This form is designed to gather and track information about the electrical infrastructure in a facility, including status, condition, and other relevant details.

## How To Complete This Form

1. Fill out the form in a new browser tab or window to avoid losing your progress.
2. Start by entering the **Facility Name**, which should match the name of the facility being inspected.
3. Select the **Inspection Date** for the relevant inspection or audit.
4. Enter the **Inspection Time**, if applicable.
5. Enter the current **Electrical Grid Status** and **Electrical Grid Description** for the facility.
6. Provide the current **Electrical Distribution Status** and **Electrical Distribution Description**.
7. Enter the **Electrical Panel Status** and **Electrical Panel Description**.
8. Enter any **Safety Concerns** related to the electrical infrastructure.
9. Provide a detailed **Electrical Infrastructure Comments** section, including any relevant notes or observations.
10. Specify the **Electrical Grid Condition** and **Electrical Grid Type** for the facility.
11. Enter the **Electrical Grid Location** and **Electrical Panel Location**.
12. Enter the **Electrical System Location** and the **Electrical Grid Size**.
13. Enter the **Electrical Grid Capacity**.
14. Enter any additional information about the **Electrical System Status 2**, **Electrical System Description 2**, **Electrical Grid Status 2**, **Electrical Panel Status 2**, and **Electrical Grid Condition 2**.
