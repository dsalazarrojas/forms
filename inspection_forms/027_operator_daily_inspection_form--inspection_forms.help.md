# Operator-Daily-Inspection-Form - Help Guide
## Purpose
This form is designed to gather information on the daily condition of a vehicle being inspected.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
* **Vehicle Number (1)** (`Vehicle Number`, `number`, Required: false): Enter the vehicle's identification number.
* **Date (2)** (`Date`, `date`, Required: false): Select the date of the inspection.
* **Operator Name (3)** (`Operator Name`, `text`, Required: false): Enter the operator's name responsible for the inspection.
* **Vehicle Type (4)** (`Vehicle Type`, `select_one`, Required: false): Select the type of vehicle being inspected.
* **Engine Noise (5)** (`Engine Noise`, `select_one`, Required: false): Answer if there is any engine noise.
* **Fuel Leaks (6)** (`Fuel Leaks`, `select_multiple`, Required: false): Answer if there are any fuel leaks.
* **Oil Leaks (7)** (`Oil Leaks`, `select_multiple`, Required: false): Answer if there are any oil leaks.
* **Brake Leaks (8)** (`Brake Leaks`, `select_multiple`, Required: false): Answer if there are any brake leaks.
* **Suspension (9)** (`Suspension`, `select_multiple`, Required: false): Select if the suspension is in good condition.
* **Steering Grease (10)** (`Steering Grease`, `select_multiple`, Required: false): Select if the steering grease is in good condition.
* **Tire Condition (11)** (`Tire Condition`, `select_multiple`, Required: false): Select if the tire condition is good.
* **Tire Pressure (12)** (`Tire Pressure`, `select_multiple`, Required: false): Select if the tire pressure is adequate.
* **Brakes (13)** (`Brakes`, `select_multiple`, Required: false): Select if the brakes are in good condition.
* **Lights (14)** (`Lights`, `select_multiple`, Required: false): Select if the lights are in good condition.
* **Signals (15)** (`Signals`, `select_multiple`, Required: false): Select if the signals are in good condition.
* **Horn (16)** (`Horn`, `select_one`, Required: false): Answer if the horn is functioning properly.
* **Windshield Wipers (17)** (`Windshield Wipers`, `select_one`, Required: false): Answer if the windshield wipers are in good condition.
* **Windshield Condition (18)** (`Windshield Condition`, `select_multiple`, Required: false): Select if the windshield is in good condition.
* **Mirrors (19)** (`Mirrors`, `select_multiple`, Required: false): Select if the mirrors are in good condition.
* **Seats (20)** (`Seats`, `select_multiple`, Required: false): Select if the seats are in good condition.
* **Doors and Locks (21)** (`Doors and Locks`, `select_multiple`, Required: false): Select if the doors and locks are in good condition.
* **Wheels (22)** (`Wheels`, `select_multiple`, Required: false): Select if the wheels are in good condition.
* **Glass and Reflective Materials (23)** (`Glass and Reflective Materials`, `select_multiple`, Required: false): Select if the glass and reflective materials are in good condition.
* **Body Condition (24)** (`Body Condition`, `select_multiple`, Required: false): Select if the body condition is good.
* **Vehicle Status (25)** (`Vehicle Status`, `select_one`, Required: false): Select the current status of the vehicle.
