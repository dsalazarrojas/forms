# Sports Stadium Security Inspection Form - Help Guide
## Purpose
The Sports Stadium Security Inspection Form is designed to ensure that sports stadiums are secure and safe for events. This form helps identify potential risks and threats that may be present in the stadium and provides a report of the findings.

## How To Complete This Form
1. Select the event date for which the inspection is being conducted.
2. Enter the event name.
3. Choose the security team responsible for the inspection.
4. Select the access points in the venue where security is required.
5. Describe the safety plan in place for the event.
6. Choose the emergency services available in the venue.
7. Select the fire safety procedures in place.
8. Enter the details of first aid procedures.
9. Select the exit routes from the venue.
10. Describe the emergency procedures in place.
11. Select the emergency equipment available in the venue.
12. Select the safety signs in place in the venue.
13. Select the security clearances required for the event.
14. Describe the exit procedure in place.
15. Select the first aid kits available in the venue.
16. Select the fire drills conducted in the venue.
17. Select the safety meetings conducted in the venue.
18. Select the inspection results.
19. Enter any additional notes about the inspection.
20. Enter the name of the person who completed the form.
21. Enter the date and time the form was completed.
22. Enter the name of the person assigned to the inspection.
23. Enter the name of the person who submitted the form.
24. Enter the date and time the form was submitted.
25. Enter the name of the person who received the submitted form.

## Field-by-Field Explanation

* **Event Date**: Enter the date of the event that is being inspected. (Required: false, Type: date)
* **Event Name**: Enter the name of the event. (Required: false, Type: text)
* **Security Team**: Select the security team responsible for the inspection. (Required: false, Type: select_one)
* **Venue Access Points**: Select the access points in the venue where security is required. (Required: false, Type: select_multiple)
* **Safety Plan**: Describe the safety plan in place for the event. (Required: false, Type: text)
* **Emergency Services**: Choose the emergency services available in the venue. (Required: false, Type: select_one)
* **Fire Safety**: Select the fire safety procedures in place. (Required: false, Type: select_one)
* **First Aid**: Enter the details of first aid procedures. (Required: false, Type: text)
* **Exit Routes**: Select the exit routes from the venue. (Required: false, Type: select_one)
* **Emergency Procedures**: Describe the emergency procedures in place. (Required: false, Type: text)
* **Emergency Equipment**: Select the emergency equipment available in the venue. (Required: false, Type: select_multiple)
* **Safety Signs**: Select the safety signs in place in the venue. (Required: false, Type: select_multiple)
* **Security Clearance**: Select the security clearances required for the event. (Required: false, Type: select_multiple)
* **Exit Procedure**: Describe the exit procedure in place. (Required: false, Type: text)
* **First Aid Kit**: Select the first aid kits available in the venue. (Required: false, Type: select_multiple)
* **Fire Drill**: Select the fire drills conducted in the venue. (Required: false, Type: select_multiple)
* **Safety Meeting**: Select the safety meetings conducted in the venue. (Required: false, Type: select_multiple)
* **Inspection Result**: Select the inspection results. (Required: false, Type: select_multiple)
* **Notes**: Enter any additional notes about the inspection. (Required: false, Type: text)
* **Completed By**: Enter the name of the person who completed the form. (Required: false, Type: text)
* **Completed At**: Enter the date and time the form was completed. (Required: false, Type: date)
* **Assigned To**: Enter the name of the person assigned to the inspection. (Required: false, Type: text)
* **Submitted By**: Enter the name of the person who submitted the form. (Required: false, Type: text)
* **Submitted At**: Enter the date and time the form was submitted. (Required: false, Type: date)
* **Submitted To**: Enter the name of the person who received the submitted form. (Required: false, Type: text)
