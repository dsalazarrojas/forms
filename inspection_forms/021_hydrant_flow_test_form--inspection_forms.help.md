## Field-by-Field Explanation

* **Hydrant Flow Test** (`hydrant_flow_test_form`, text, required/optional): This field is the main title of the form and is not editable.
* **Hydrant Flow Rate** (`hydrant_flow_rate`, number, required/optional): Enter the rate of the hydrant flow test. This field is optional.
* **Test Result** (`flow_test_result`, select_one, required/optional): Choose whether the test result is 'Yes' or 'No'. This field is optional.
* **Building Name** (`building_name`, text, required/optional): Enter the name of the building where the hydrant is located. This field is optional.
* **Inspector Name** (`inspector_name`, text, required/optional): Enter your name as the inspector or the person completing the form. This field is optional.
* **Assigned Tool** (`assigned_tool`, select_one, required/optional): Choose whether the tool is 'Yes' or 'No'. This field is optional.
* **Assigned Tool Id** (`assigned_tool_id`, text, required/optional): Enter the tool's identifier if applicable. This field is optional.
* **Assigned Tool Name** (`assigned_tool_name`, text, required/optional): Enter the tool's name if applicable. This field is optional.
* **Assigned Tool Type** (`assigned_tool_type`, select_one, required/optional): Choose whether the tool type is 'Yes' or 'No'. This field is optional.
* **Assigned Tool Model** (`assigned_tool_model`, text, required/optional): Enter the tool's model if applicable. This field is optional.
* **Assigned Tool Serial Number** (`assigned_tool_serial_number`, text, required/optional): Enter the tool's serial number if applicable. This field is optional.
* **Assigned Tool Notes** (`assigned_tool_notes`, text, required/optional): Add any notes about the assigned tool if applicable. This field is optional.
* **Hydrant Flow Test Form Notes** (`hydrant_flow_test_form_notes`, text, required/optional): Add any notes about the form if applicable. This field is optional.
* **Hydrant Flow Test Form Date** (`hydrant_flow_test_form_date`, date, required/optional): Enter the date of the form. This field is optional.
* **Hydrant Flow Test Form Time** (`hydrant_flow_test_form_time`, time, required/optional): Enter the time of the form. This field is optional.
* **Inspector** (`inspector`, text, required/optional): Enter your name as the inspector or the person completing the form. This field is optional.
* **Inspector Email** (`inspector_email`, email, required/optional): Enter your email if applicable. This field is optional.
* **Inspector Phone** (`inspector_phone`, text, required/optional): Enter your phone number if applicable. This field is optional.
* **Form Notes** (`form_notes`, text, required/optional): Add any notes about the form if applicable. This field is optional.
* **Building Inspector** (`building_inspector`, text, required/optional): Enter the name of the building inspector if applicable. This field is optional.
* **Building Inspector Phone** (`building_inspector_phone`, text, required/optional): Enter the building inspector's phone number if applicable. This field is optional.
* **Building Inspector Email** (`building_inspector_email`, email, required/optional): Enter the building inspector's email if applicable. This field is optional.
* **Building Inspector Notes** (`building_inspector_notes`, text, required/optional): Add any notes about the building inspector if applicable. This field is optional.
* **Form Status** (`form_status`, select_one, required/optional): Choose whether the form status is 'Active' or 'Inactive'. This field is optional.
* **Form Status Notes** (`form_status_notes`, text, required/optional): Add any notes about the form status if applicable. This field is optional.
