# Compactor Inspection Checklist - Help Guide
## Purpose
This form is designed to collect information about the condition of compactors during regular inspections. The goal is to ensure that the machinery is in good working order and identify any potential issues before they become major problems.

## How To Complete This Form

1. Start by filling out your name as the inspector. This is a required field for record-keeping purposes.
2. Enter the date of the inspection. This will help track the timeline of your inspections.
3. Enter the compactor's identifier, which could be its serial number or a location code.
4. For the "Visual condition check" field, select "Pass" if the unit appears to be in good visible condition, "Fail" if there are visual issues, or "Needs maintenance" if it's not clear.
5. For the "Safety features operational" field, select "True" if all safety features are functioning correctly, and "False" if there are any issues.
6. For the "Hydraulic system condition" field, select "Good" if the system is functioning correctly, "Attention required" if there are minor issues, or "Critical" if the system is severely malfunctioning.
7. If you have any recommended next steps for maintenance, enter them in the "Recommended actions" field. This is an optional field, so only enter information if there are specific actions required.
8. If maintenance has been scheduled, enter the date in the "Maintenance scheduled" field. This field is optional and only required if maintenance has been scheduled.

## Field-by-Field Explanation

* **Inspector name** (`inspector_name`, text, required): Enter your name as the person conducting the inspection.
* **Inspection date** (`inspection_date`, date, required): Enter the date of the inspection.
* **Compactor identifier** (`compactor_id`, text, required): Enter the compactor's serial number or location code.
* **Visual condition check** (`visual_check`, select_one, required): Select "Pass" if the unit appears to be in good visible condition, "Fail" if there are visual issues, or "Needs maintenance" if it's not clear.
* **Safety features operational** (`safety_features`, select_one, required): Select "True" if all safety features are functioning correctly, and "False" if there are any issues.
* **Hydraulic system condition** (`hydraulic_checks`, select_one, required): Select "Good" if the system is functioning correctly, "Attention required" if there are minor issues, or "Critical" if the system is severely malfunctioning.
* **Recommended actions** (`recommended_actions`, text, optional): Enter any recommended next steps for maintenance.
* **Maintenance scheduled** (`maintenance_scheduled`, date, optional): Enter the date if maintenance has been scheduled.

## Tips

* Ensure you have access to the compactor before completing this form.
* If you're unsure about any field, refer to the equipment manual or manufacturer's guidelines.
* Double-check your answers to ensure accuracy and completeness.
