# Hotel Fire Escape Inspection Form - Help Guide
## Purpose
The Hotel Fire Escape Inspection Form is designed to collect information about the condition of fire escape routes in a hotel and ensure that they are safe for guests to use in case of an emergency.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the correct information:
	* **Facility Name**: Enter the name of the hotel or building being inspected.
	* **Inspection Date**: Enter the date the inspection was conducted.
	* **Inspector Name**: Enter the name of the inspector who conducted the inspection.
	* **Fire Escape Doors**: Enter the number of fire escape doors in the facility.
	* **Fire Escape Stairways**: Enter the number of fire escape stairways in the facility.
	* **Issues**: Check "Yes" if there are any issues with the fire escape routes.
	* **Form ID**: Enter a unique identifier for the form.

2. Optional fields:
	* **Fire Escape Hallways**: Enter the number of fire escape hallways in the facility (if applicable).
	* **Notes**: Enter any additional comments or notes about the inspection.
	* **Facility Manager Signature**: Check "Yes" if the facility manager has reviewed and signed off the inspection (if applicable).
	* **Submission Date**: Enter the date the form was submitted.
	* **Inspector Submission**: Check "Yes" if the inspector has reviewed and signed off the form (if applicable).

## Field-by-Field Explanation

* **Facility Name**: Enter the name of the hotel or building being inspected.
* **Inspection Date**: Enter the date the inspection was conducted using the standard date format (MM/DD/YYYY).
* **Inspector Name**: Enter the name of the inspector who conducted the inspection.
* **Fire Escape Doors**: Enter the number of fire escape doors in the facility.
* **Fire Escape Stairways**: Enter the number of fire escape stairways in the facility.
* **Fire Escape Hallways**: Enter the number of fire escape hallways in the facility (if applicable).
* **Issues**: Check "Yes" if there are any issues with the fire escape routes, or "No" if there are no issues.
* **Notes**: Enter any additional comments or notes about the inspection.
* **Facility Manager Signature**: Check "Yes" if the facility manager has reviewed and signed off the inspection (if applicable).
* **Submission Date**: Enter the date the form was submitted using the standard date format (MM/DD/YYYY).
* **Inspector Submission**: Check "Yes" if the inspector has reviewed and signed off the form (if applicable).
* **Form ID**: Enter a unique identifier for the form.
* **Inspector Signature**: Enter the signature of the inspector who completed the form.
