# Rental History Verification Form - Help Guide
## Purpose
The Rental History Verification Form is used to gather information about a tenant's rental history, including their previous leases, rental property addresses, and rental status. This information helps rental property owners or managers assess a tenant's creditworthiness or eligibility to rent a property.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the option for "Application Submitted" to indicate whether the applicant has submitted an application for a rental property.
2. Enter the date range for the rental history, if applicable.
3. Enter the start and end dates for any previous leases, if applicable.
4. Enter the address of the current property the tenant resides in and the address of any previous rental properties, if applicable.
5. Select the type of rental property (e.g., studio, 1-bedroom, 2-bedroom, 3-bedroom, or other) and the rental status (e.g., vacant or occupied).
6. Enter any relevant information about the property owner, manager, and tenant.
7. Enter any additional details about the rent amount, lease start and end dates, and other relevant information.

## Field-by-Field Explanation

* **Application Submitted** (1, Select One, Required): Select "Yes" if the application has been submitted, "No" if it has not, or "Maybe" if it's uncertain.
* **Rental History Date Range** (2, Date, Optional): Enter the date range for the rental history, if applicable.
* **Previous Lease End Date** (3, Date, Optional): Enter the end date of the previous lease.
* **Current Property Address** (4, Text, Optional): Enter a street address for the property the tenant currently resides in.
* **Previous Lease Length** (5, Number, Optional): Enter the length of the previous lease.
* **Previous Lease Start Date** (6, Date, Optional): Enter the start date of the previous lease.
* **Previous Lease End Date 2** (7, Date, Optional): Enter the end date of a second previous lease.
* **Previous Property Address** (8, Text, Optional): Enter the address of a previous rental property.
* **Rental Type** (9, Select One, Optional): Select the type of rental property (e.g., studio, 1-bedroom, 2-bedroom, 3-bedroom, or other).
* **Rental Status** (10, Select One, Optional): Select the rental status (e.g., vacant or occupied).
* **Property Owner** (11, Text, Optional): Enter the property owner's name.
* **Property Manager** (12, Text, Optional): Enter the property manager's name.
* **Property Address** (13, Text, Optional): Enter the address of the rental property.
* **Tenant Name** (14, Text, Optional): Enter the tenant's name.
* **Lease Start Date** (15, Date, Optional): Enter the start date of the lease.
* **Lease End Date** (16, Date, Optional): Enter the end date of the lease.
* **Rent** (17, Number, Optional): Enter the amount of rent.
* **Previous Owner Name** (18, Text, Optional): Enter the previous owner's name.
* **Property Type** (19, Select One, Optional): Select the type of property (e.g., single family, multi-family, rental apt, or other).
* **Previous Property Address 2** (20, Text, Optional): Enter the address of a second previous rental property.
* **Previous Lease Length 2** (21, Number, Optional): Enter the length of a second previous lease.
* **Rent Amount** (22, Number, Optional): Enter the rent amount.
* **Lease Start Date/Time** (23, Date, Optional): Enter the start date and time of the lease.
* **Lease End Date/Time** (24, Date, Optional): Enter the end date and time of the lease.
* **Tenant Relationship** (25, Select One, Optional): Select the tenant's relationship with the property owner or manager (e.g., renter, owner, or broker).

## Tips
* Make sure to fill out all required fields before submitting the form.
* Enter accurate and up-to-date information for each field.
* If you're unsure about a particular field, use the "Maybe" or "Other" option as a placeholder until you can obtain more information.
* Review the form carefully before submitting it to ensure all required fields are filled out correctly.
