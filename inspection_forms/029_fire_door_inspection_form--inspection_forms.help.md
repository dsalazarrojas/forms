# fire_door_inspection_form - Help Guide
## Purpose
The fire door inspection form is used to record information about fire doors, including their inspection history, condition, and next scheduled inspection date.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by identifying the fire door you wish to inspect.
2. Complete each page of the form in the following order:
	* Page 1: Fire Door Information
	* Page 2: Inspection Results
	* Page 3: Fire Door Type and Condition
	* Page 4: Defects and Next Inspection Date
	* Page 5: Fire Exit Information (if applicable)

## Field-by-Field Explanation

* **Fire Door ID** (1, number, required: false): Enter the unique identifier for the fire door.
* **Inspection Results** (2, select_multiple, required: false): Indicate if the fire door has been inspected and if there were any issues found. Choose one or more from the options 'Yes' or 'No'.
* **Fire Door Type** (3, select_one, required: false): Select the type of fire door from the options 'Fire Door' or 'Fire Exit'.
* **Fire Door Condition** (4, text, required: false): Describe the overall condition of the fire door.
* **Last Inspection Date** (5, date, required: false): Enter the date of the last inspection.
* **Next Inspection Date** (6, date, required: false): Enter the date of the next scheduled inspection.
* **Defect Description** (7, text, required: false): If a defect was found during inspection, describe it in this field.
* **Fire Exit ID** (8, number, required: false): Enter the ID of the fire exit associated with this fire door, if applicable.

Note: The form will only be complete if all fields have a valid entry.
