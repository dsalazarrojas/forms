# post-renovation-inspection-form - Help Guide
## Purpose
The post-renovation-inspection-form is used to inspect and verify that a renovation has been completed safely and to the expected standards.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the general questions section with any relevant information about the renovation, such as the date of completion and any notable changes or issues.
2. In the "Photos" section, upload photos of the work area to provide visual evidence of the renovation.
3. In the "Safety Checklist" section, review the safety checks and select the correct answers for each item.
4. For each item in the "Safety Checklist", select the corresponding "Yes" or "No" answer based on the actual state of the work area.

## Field-by-Field Explanation
### General Questions
* **General Questions** (`general_questions`, text, required: false): This section is for any relevant information about the renovation, such as the date of completion and any notable changes or issues.

* **Photos** (`photos`, text, required: false): Upload photos of the work area to provide visual evidence of the renovation.

* **Safety Checklist** (`safety_checklist`, select_multiple, required: false):
	+ **Is the work area clean and free from debris?** (`safety_checklist_item_1`, select_one, required: false): Select "Yes" if the work area is clean and free from debris, otherwise select "No".
	+ **Are all electrical and gas connections safely secured?** (`safety_checklist_item_2`, select_one, required: false): Select "Yes" if the electrical and gas connections are safely secured, otherwise select "No".
	+ **Are all exit doors and emergency exits clear?** (`safety_checklist_item_3`, select_one, required: false): Select "Yes" if the exit doors and emergency exits are clear, otherwise select "No".
	+ **Are all fire alarms and fire suppression systems tested?** (`safety_checklist_item_4`, select_one, required: false): Select "Yes" if the fire alarms and fire suppression systems have been tested, otherwise select "No".
	+ **Are all windows and doors secure?** (`safety_checklist_item_5`, select_one, required: false): Select "Yes" if the windows and doors are secure, otherwise select "No".
	+ **Is the work area well ventilated?** (`safety_checklist_item_6`, select_one, required: false): Select "Yes" if the work area is well ventilated, otherwise select "No".
	+ **Are all electrical and gas systems tested and approved?** (`safety_checklist_item_7`, select_one, required: false): Select "Yes" if the electrical and gas systems have been tested and approved, otherwise select "No".

## Tips
- Make sure to carefully review each question and select the correct answer based on the actual state of the work area.
- Take clear and legible photos of the work area to provide visual evidence of the renovation.
- If you are unsure about any of the safety checks, do not hesitate to consult with a supervisor or expert before completing the form.
