# shipping_container_inspection_form - Help Guide
## Purpose
The shipping container inspection form is used to record the type and condition of shipping containers, ensuring accurate and consistent reporting.

## How To Complete This Form
1. Choose the type of shipping container you are inspecting from the options provided.
2. Describe the condition of the container, providing as much detail as possible.
3. Select any damage or issues found on the container.

## Field-by-Field Explanation

* **Container Type** (`container_type`, select_one, required: false):
	+ Choose the type of container from the options provided (20ft, 40ft, 20ft with palletized pallet).
* **Container Condition** (`container_condition`, text, required: false):
	+ Describe the overall condition of the container, providing as much detail as possible.
* **Damage** (`damage`, select_multiple, required: false):
	+ Check any applicable issues with the container, such as dented corner, dented side, leaking, or other.
	+ Select all that apply to accurately report the condition of the container.

## Tips
* Be thorough when describing the condition of the container to ensure accurate reporting.
* If the container's condition does not fit into any of the provided options, select "Other" and provide a description.
* This form is for reporting on shipping containers, if you're unsure about the type or condition of a container, consult with a supervisor or reference materials for guidance.
