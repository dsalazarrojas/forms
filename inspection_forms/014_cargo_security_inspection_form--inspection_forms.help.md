# Cargo Security Inspection Form - Help Guide
## Purpose
The Cargo Security Inspection Form is designed to ensure that goods are properly secured and meet safety standards during transport. This form will help inspectors assess the condition of cargo containers and report any discrepancies or issues. It is essential to complete this form thoroughly and accurately to maintain the integrity of the goods and ensure compliance with regulations.

## How To Complete This Form
1. **Inspection ID**: Enter the internal tracking number for this inspection.
2. **Date of Inspection**: Enter the date and time of the inspection.
3. **Inspector Name**: Enter your full name as the authorized inspector.
4. **Facility or Warehouse Location**: Enter the specific building or terminal where the inspection took place.
5. **Shipment or Container Number**: Enter the main identifier for the goods being inspected.
6. **Carrier Company**: Enter the name of the company that is responsible for transporting the goods (optional).
7. **Driver Name**: Enter the name of the driver responsible for transporting the goods (optional).
8. **Vehicle License Plate**: Enter the license plate number of the vehicle used for transport (optional).
9. **Container Seal Intact?**: Select 'True' if the container seal is intact, 'False' if it is broken or missing, or 'N/A' if it is not applicable.
10. **Seal Number**: Enter the ID of the new or verified seal (optional).
11. **Container Walls, Roof, and Floor Sound?**: Select 'True' if the container walls, roof, and floor are in good condition, 'False' if they are damaged, or 'Needs Maintenance' if they require repair or maintenance.
12. **Hidden Compartments?**: Select 'True' if there are hidden compartments, 'False' if there are not, or 'N/A' if not applicable.
13. **Locks and Doors Functional and Secure?**: Select 'True' if all locks and doors are functioning and secure, 'False' if they are not.
14. **Cargo Properly Secured?**: Select 'True' if the cargo is properly lashed or blocked, 'False' if it is not.
15. **Unauthorized Items or Discrepancies?**: Select 'True' if there are any unauthorized items or discrepancies based on the manifest comparison.
16. **Signs of Package Tampering or Damage?**: Select 'True' if there are signs of package tampering or damage, 'False' if there are not.
17. **Hazardous Materials Properly Labeled?**: Select 'True' if all hazardous materials are properly labeled according to shipping regulations, 'False' if they are not.
18. **Overall Inspection Result**: Select the overall result of the inspection: Pass, Fail, or Provisional Pass.
19. **List Any Corrective Actions**: Enter any necessary corrective actions to be taken before releasing the goods.
20. **Confirmation of Inspection**: Enter your full name as acknowledgment of the inspection.
