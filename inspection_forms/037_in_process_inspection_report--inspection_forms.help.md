# In Process Inspection Report - Help Guide
## Purpose
The In Process Inspection Report is a form designed to collect information about ongoing or completed inspections within an organization. This form helps to record details about the inspection date, time, location, inspector's name, and any findings or corrective actions taken.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Start" button to begin filling out the form.
2. Provide the inspection date in the format `YYYY-MM-DD`.
3. Enter the inspection time in the format `HH:MM:SS`.
4. Enter the location of the inspection, such as a room or area name.
5. Enter the name of the inspector performing the inspection.
6. If any findings were made during the inspection, provide a description in the text field.
7. If any corrective actions were taken as a result of the inspection, provide a description in the text field.

## Field-by-Field Explanation

* **inspection_date**: Enter the date of the inspection in the format `YYYY-MM-DD`.
* **inspection_time**: Enter the time of the inspection in the format `HH:MM:SS`.
* **inspection_location**: Enter the location of the inspection, such as a room or area name.
* **inspector_name**: Enter the name of the inspector performing the inspection.
* **finding_description**: If any findings were made during the inspection, provide a description of what was observed or detected.
* **corrective_action**: If any corrective actions were taken as a result of the inspection, provide a description of the action taken to address the finding.
* **supporting_evidence**: If supporting evidence for the inspection or finding, such as photos or documentation, can be uploaded or linked, enter the file location or URL here.
  (Note: This field may not be enabled for every use case, please verify if it's applicable)

## Tips

* Be as detailed as possible when filling out the inspection date and time.
* Ensure the location is accurately described so that it can be easily located.
* If findings or corrective actions were taken, be thorough in your descriptions.
* If supporting evidence is required, ensure it is properly uploaded or linked to provide additional context.
