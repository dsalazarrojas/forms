# Cleaning Checklist Form - Help Guide
## Purpose

The Cleaning Checklist Form is a comprehensive cleaning report used to document the completion of various cleaning tasks across different areas of a property. The form is designed to be used by cleaning staff or inspectors to report on the status of each task, ensuring quality control and future reference.

## How To Complete This Form

1.  Select the Property Type and enter the Property Name or Address.
2.  Choose the Cleaning Date and enter the Cleaner's Name.
3.  Select the Cleaning Type and report on the status of each task across different areas.
4.  For each task, choose one of the three options: Completed, Not Applicable, or Needs Attention.
5.  Enter the Additional Tasks performed, if any.
6.  List any Issues or Damage Noted.
7.  List any Supplies that need Restocking.
8.  Report the Cleaning Start and End Times.
9.  Sign the Supervisor's Signature, if applicable.

## Field-by-Field Explanation

*   **Property Name or Address**: Enter the name of the property or address being cleaned.
*   **Property Type**: Select the type of property (e.g., Residential Home, Apartment or Condo, Office Building, etc.).
*   **Cleaning Date**: Enter the date of the cleaning service.
*   **Cleaner Name**: Enter the name of the cleaner or team member.
*   **Cleaning Type**: Select the type of cleaning service (e.g., Regular Cleaning, Deep Cleaning, Move-In or Move-Out, etc.).
*   **Living Room - Dust All Surfaces**: Report the status of dusting living room surfaces.
*   **Living Room - Vacuum or Sweep Floors**: Report the status of vacuuming or sweeping living room floors.
*   **Bedrooms - Dust All Surfaces**: Report the status of dusting bedroom surfaces.
*   **Bedrooms - Vacuum or Sweep Floors**: Report the status of vacuuming or sweeping bedroom floors.
*   **Bedrooms - Make Beds**: Report the status of making beds.
*   **Kitchen - Clean and Disinfect Counters**: Report the status of cleaning and disinfecting kitchen counters.
*   **Kitchen - Clean Appliances (Exterior)**: Report the status of cleaning kitchen appliances.
*   **Kitchen - Clean and Sanitize Sink**: Report the status of cleaning and sanitizing the kitchen sink.
*   **Kitchen - Sweep and Mop Floors**: Report the status of sweeping and mopping kitchen floors.
*   **Kitchen - Wipe Cabinet Fronts**: Report the status of wiping kitchen cabinet fronts.
*   **Bathroom - Clean and Disinfect Toilet**: Report the status of cleaning and disinfecting the toilet.
*   **Bathroom - Clean Shower or Tub**: Report the status of cleaning the shower or tub.
*   **Bathroom - Clean and Polish Sink**: Report the status of cleaning and polishing the bathroom sink.
*   **Bathroom - Clean Mirrors**: Report the status of cleaning mirrors.
*   **Bathroom - Sweep and Mop Floors**: Report the status of sweeping and mopping bathroom floors.
*   **Windows - Clean Interior Glass**: Report the status of cleaning interior window glass.
*   **Baseboards - Dust and Wipe**: Report the status of dusting and wiping baseboards.
*   **Light Switches and Door Handles - Disinfect**: Report the status of disinfecting light switches and door handles.
*   **Trash - Empty All Bins and Replace Liners**: Report the status of emptying all trash bins and replacing liners.
*   **All Floors - Vacuum Carpets**: Report the status of vacuuming all carpets.
*   **All Hard Floors - Sweep and Mop**: Report the status of sweeping and mopping all hard floors.
*   **Additional Tasks Completed**: List any extra tasks performed.
*   **Issues or Damage Noted**: Report any pre-existing damage or concerns.
*   **Supplies Running Low or Needed**: List any supplies that need restocking.
*   **Cleaning Start Time**: Report the start time of the cleaning service.
*   **Cleaning End Time**: Report the end time of the cleaning service.
*   **Supervisor Signature (Type Full Name)**: Sign the supervisor's name, if applicable.

## Tips

*   Be thorough when completing the form to ensure accurate reporting.
*   Report each task as accurately as possible.
*   Document any issues or concerns for future reference.
*   Sign the supervisor's signature if required.
