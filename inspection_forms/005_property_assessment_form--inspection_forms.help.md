# Property Assessment Form - Help Guide
## Purpose
This form is designed to collect property information for assessment purposes, such as appraisals or valuations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, if any.
2. Select the appropriate options for each field from the list provided.
3. Enter any additional information or details about the property as needed.

## Field-by-Field Explanation
* **Property Address** (1, text, required): Enter the property's address, including the street number and name, city, state, and zip code.
* **Property Type** (2, select_one, required): Choose the type of property from the list:
	+ Single-family
	+ Multi-family
	+ Other
* **Property Value** (3, number, required): Enter the property's value.
* **Property Year Built** (4, number, required): Enter the year the property was built.
* **Property Square Footage** (5, text, required): Enter the property's square footage.
* **Property Bedrooms** (6, number, required): Enter the number of bedrooms in the property.
* **Property Lot Size** (7, number, required): Enter the property's lot size in square footage.
* **Property Condition** (8, select_multiple, required): Choose the property's condition from the list:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Neighboring Units** (9, select_multiple, required): Check if there are neighboring units:
	+ False
	+ True
* **Property Views** (10, select_one, required): Choose the property's viewability:
	+ Unobstructed
	+ Obstructed
	+ Unknown
* **Property Accessibility** (11, select_multiple, required): Choose the property's accessibility:
	+ Walk
	+ Drive
	+ Unknown

## Tips
- Make sure to fill in all required fields.
- Double-check the options for each field to ensure you're selecting the correct information.
- If you're unsure about any field, ask for help or clarification.
