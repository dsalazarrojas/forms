# Receptacle Testing Survey - Help Guide

## Purpose
This form is designed to collect information about the testing of receptacles, which are containers or containers used to store or transport liquids, gases, or other substances.

## How To Complete This Form
1. **Page 1**: Start by filling out the basic information about the receptacle being tested:
	* Location name: Enter the name of the location where the receptacle is being tested.
	* Address 1: Enter the first part of the address where the receptacle is located.
	* Address 2: Enter the second part of the address where the receptacle is located.
	* Receptacle Identifiers: Enter any identifiers or codes related to the receptacle being tested.
	* Test Date: Enter the date when the testing was performed.
	* Test Time: Enter the time when the testing was performed.
	* Test Results: Enter the results of the testing.
	* Issues Found: Enter any issues or defects found during the testing.
2. **Page 2**: If necessary, provide additional information about any issues:
	* Issue Description: Describe the issue found.
	* Issue Type: Identify the type of issue found.
	* Issue Location: Specify where the issue was located.
	* Issue Priority: Determine the priority of the issue.
	* Issue Comments: Enter any comments or notes about the issue.
3. **Page 3-9**: These pages are intended for additional comments or information. You can use them to provide any additional details about the testing process or the receptacle being tested.
4. **Page 10**: Finally, enter any electrical inspection certification:
	* Electrical Inspection Cert.: Enter the electrical inspection certificate number.
	* Electrical Inspection Cert. Date: Enter the date of the electrical inspection certification.
4. **Submit**: Once all required fields have been filled out, click the "Submit" button to complete the form.
