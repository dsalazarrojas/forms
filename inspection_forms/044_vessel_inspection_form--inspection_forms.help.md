# Vessel Inspection Form - Help Guide
## Purpose
The Vessel Inspection Form is used to record the results of an inspection of a vessel, including its safety equipment, inspection result, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct category for the vessel inspection.
2. Provide a brief description of the vessel inspection.
3. Indicate whether the vessel's safety equipment is in good working order (Safety Equipment).
4. Report the result of the vessel inspection (Vessel Inspection Result).
5. Choose the date and time of the inspection (Inspection Date, Inspection Time).
6. Enter the start and end times of the inspection (Inspection Start Time, Inspection End Time).
7. Enter the name and ID of the inspector conducting the inspection (Inspector Name, Inspector ID).
8. Enter the vessel's MMSI (Maritime Mobile Safety Information) number.
9. Select whether the ship type is present (Ship Type, Ship Type List).
10. Provide any additional ship type information (Ship Type 2, Ship Type List).

## Field-by-Field Explanation
* **Category**: Select the category for the vessel inspection.
* **Description**: Provide a brief description of the vessel inspection.
* **Safety Equipment**: Check if the vessel's safety equipment is in good working order.
* **Vessel Inspection Form Description**: Enter any additional information about the form.
* **Safety Equipment**: Check if the vessel's safety equipment is in good working order.
* **Vessel Inspection Result**: Report the result of the vessel inspection (e.g., "Yes", "No").
* **Inspection Date**: Select the date of the inspection.
* **Inspection Time**: Select the time of the inspection.
* **Inspection Start Time**: Enter the start time of the inspection.
* **Inspection End Time**: Enter the end time of the inspection.
* **Inspector Name**: Enter the name of the inspector conducting the inspection.
* **Inspector ID**: Enter the ID of the inspector conducting the inspection.
* **Vessel MMSI**: Enter the vessel's MMSI number.
* **Ship Type**: Select whether the ship type is present.
* **Ship Type List**: Enter any additional ship type information.
* **Ship Type 2**: Select whether the ship type is present.
* **Ship Type 2 List**: Enter any additional ship type information.

## Tips
* Make sure to accurately select the category and ship type to ensure the correct inspection is recorded.
* Double-check the accuracy of the inspection result and safety equipment.
* Ensure that the date and time are entered correctly.
* Verify the inspector's name and ID are correct.
* Double-check the vessel's MMSI number for accuracy.
* Enter any additional ship type information if necessary.
* Review the form for completeness before submitting.
