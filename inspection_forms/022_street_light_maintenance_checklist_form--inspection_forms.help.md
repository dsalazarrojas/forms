# Street Light Maintenance Checklist Form - Help Guide
## Purpose
The Street Light Maintenance Checklist Form is used to collect data on the condition and status of a street light. This information is used to identify maintenance needs and plan repairs and replacements.

## How To Complete This Form
1. Fill out this form while inspecting the street light.
2. Answer each question carefully, following the instructions provided below.
3. Make sure to save the form once completed, as it will be used as a reference for future maintenance work.

## Field-by-Field Explanation
* **Street Light Maintenance Checklist Form (1)**: Enter a brief description of the condition of the street light, if applicable.
* **Power Sources (2)**: Check if the street light is powered by electricity or not.
	+ Select "Yes" if the street light is powered by an electrical power source.
	+ Select "No" if the street light is not powered by an electrical power source.
* **Is Power On (3)**: Enter the current status of the street light's power source, if applicable.
* **Street Light Maintenance Checklist (4)**: Enter a brief description of the condition of the street light, if applicable.
* **Utilities (5)**: Check if the street light has utilities such as water or gas.
	+ Select "Yes" if the street light has utilities.
	+ Select "No" if the street light does not have utilities.
* **Is Utility On (6)**: Enter the current status of the street light's utilities, if applicable.
* **Foundations (7)**: Enter a brief description of the condition of the street light's foundation, if applicable.
* **Is Foundation Stable (8)**: Enter the current stability of the street light's foundation, if applicable.
* **Poles (9)**: Enter a brief description of the condition of the street light pole, if applicable.
* **Is Pole Stable (10)**: Enter the current stability of the street light pole, if applicable.
* **Comments (11)**: Add any additional comments or notes about the street light, if applicable.
* **Assigned Tool (12)**: Enter the tool used to inspect the street light, if applicable.
* **Category (13)**: Enter a category or classification for the street light, if applicable.
* **Form ID (14)**: Enter a unique ID for this form, if applicable.
* **Created By (15)**: Enter the name of the person who created this form, if applicable.
* **Date Created (16)**: Enter the date and time this form was created, if applicable.
* **Modified By (17)**: Enter the name of the person who modified this form, if applicable.

## Tips
* Make sure to answer each question carefully and to the best of your ability.
* If you are unsure about a particular aspect of the street light, please add notes or comments to explain the situation.
* This form is a tool to help you collect data, not to replace your own professional judgment.
* If you have any questions or concerns about this form, please reach out to your supervisor or the maintenance team.
