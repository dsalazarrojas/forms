# Incomplete Work Items Report Form - Help Guide

## Purpose
This form is designed to collect information about incomplete work items that need to be reworked or addressed. It helps to identify items that require attention and provides a structured format for inspectors to report them.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the inspectors who have inspected the incomplete work items (field "inspectors").
2. Enter the title of the incomplete work items report (field "title").
3. On each page, enter any relevant comments or details about the incomplete work items (field "incomplete_work_items").
4. Select a date when the report was submitted (field "date_submitted").
5. Select a date when the report was due (field "date_due").
6. Optional: enter the count and percentage of incomplete work items (fields "incomplete_work_items_count" and "incomplete_work_items_percentage").

## Field-by-Field Explanation

* **inspectors** (<label>: Select the inspectors who inspected the incomplete work items. This field is required.)
* **Incomplete Work Items** (note): Enter any comments or details about the incomplete work items. This field is required.
* **Date Submitted** (date): Select the date when this report was submitted. This field is required.)
* **Date Due** (date): Select the date when this report was due. This field is required.)
* **Prophets** (select_multiple): This field seems to be a placeholder or has an unclear label, but it appears to be a list of options related to the report. Enter any relevant information.
* **Date Completed** (date): Optional field to enter the date when the report was completed.
* **Incomplete Work Items Count** (number): Optional field to enter the count of incomplete work items.
* **Incomplete Work Items Percentage** (number): Optional field to enter the percentage of incomplete work items.
* **Incomplete Work Items Average** (number): Optional field to enter the average of incomplete work items, but its purpose is unclear.
