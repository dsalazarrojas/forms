# Refrigeration Compliance Inspection Checklist - Help Guide
## Purpose
This form is used to record and report the results of a refrigeration compliance inspection at a specific location. It captures details about the location, inspection, and refrigeration systems present, as well as any supporting evidence such as photos, videos, and documents.

## How To Complete This Form
1. Fill in the **Location Name**, which should be the name of the facility being inspected.
2. Enter the **Inspection Name**, which can be a unique identifier or description for the inspection.
3. Select the start and end times for the inspection using the time input fields.
4. Optionally, add any **Notes** to provide additional context or details about the inspection.
5. For the **Refrigeration Systems** field, select all systems present at the location.
6. Choose the **Refrigeration Status** to indicate the status of the systems (Active, Inactive, Maintenance, or Other).
7. Select the **Refrigeration System Status** to indicate the condition of the systems (Active, Inactive, Maintenance, or Other).
8. For the **Facility Type**, enter the type of facility being inspected (e.g., warehouse, office building, etc.).
9. Select the **Refrigeration Systems** checked during the inspection.
10. Choose the **Refrigeration System Criticality** for each selected system (Critical, Non-Critical, Not Rated).
11. Enter the **Refrigeration Systems Condition** to provide a detailed description of the condition of the systems.
12. If necessary, add **Comments** and **Photos**, **Videos**, or **Documents** as supporting evidence.

## Field-by-Field Explanation

* **Location Name**: Enter the name of the facility or location being inspected.
* **Inspection Name**: Enter a unique identifier or description for the inspection.
* **start_time**: Enter the start time for the inspection.
* **end_time**: Enter the end time for the inspection.
* **Notes**: Add any additional context or details about the inspection.
* **Refrigeration Systems**: Select all systems present at the location.
* **Refrigeration Status**: Choose the status of the systems (Active, Inactive, Maintenance, or Other).
* **Refrigeration System Status**: Indicate the condition of the systems (Active, Inactive, Maintenance, or Other).
* **Facility Type**: Enter the type of facility being inspected.
* **Refrigeration Systems Checked**: Select the systems inspected or checked.
* **Refrigeration System Criticality**: Choose the criticality of each system (Critical, Non-Critical, Not Rated).
* **Refrigeration Systems Condition**: Enter a description of the condition of the systems.
* **Photos**: Upload photos as supporting evidence.
* **Videos**: Upload videos as supporting evidence.
* **Documents**: Upload documents as supporting evidence.
* **Location Address**: Enter the address of the facility location.
* **Location City**: Enter the city of the facility location.
* **Location Postal Code**: Enter the postal code of the facility location.
* **Location State**: Enter the state of the facility location.
* **Location Country**: Enter the country of the facility location.
