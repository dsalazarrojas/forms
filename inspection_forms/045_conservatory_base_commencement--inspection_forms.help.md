# Conservatory Base Commencement - Help Guide

## Purpose
This form is used to document the inspection and completion of conservatory base work, ensuring that all necessary information and data are collected and recorded for the construction project's compliance and safety.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields and fill in the required information.
2. Ensure all required fields are completed before submitting the form.
3. Enter accurate and relevant information for each field.
4. Review and verify the information before submitting the form.

## Field-by-Field Explanation

* **Inspection Date** (`inspection_date`, date, required): Enter the date of the inspection, following the format `MM/DD/YY`.
* **Inspection Time** (`inspection_time`, time, required): Enter the time of the inspection, following the format `HH:MM AM/PM`.
* **Inspector Name** (`inspector_name`, text, required): Enter the name of the inspector conducting the inspection.
* **Inspection Company** (`inspector_company`, text, required): Enter the name of the company conducting the inspection.
* **Project Name** (`project_name`, text, required): Enter the name of the construction project being inspected.
* **Project Number** (`project_number`, text, required): Enter the project identifier.
* **Site Address** (`site_address`, text, required): Enter the physical location of the construction site.
* **City** (`site_city`, text, required): Enter the city location of the site.
* **State** (`site_state`, text, required): Enter the state or province location of the site.
* **Building Type** (`building_type`, select_one, required): Select the type of structure being inspected (e.g., Residential, Commercial, etc.).
* **Conservatory Type** (`conservatory_type`, select_one, required): Select the type of conservatory structure being inspected (e.g., Glass house, Greenhouse, etc.).
* **Foundation Type** (`foundation_type`, select_one, required): Select the type of foundation being inspected (e.g., Slab on grade, Crawl space, etc.).
* **Soil Type** (`soil_type`, text, required): Enter the soil classification.
* **Soil Report Date** (`soil_report_date`, date, required): Enter the date the soil was tested.
* **Excavation Complete** (`excavation_complete`, select_one, required): Indicate whether the excavation is complete.
* **Excavation Depth** (`excavation_depth`, text, required): Enter the depth of the excavation in feet or meters.
* **Excavation Dimensions** (`excavation_dimensions`, text, required): Enter the length and width of the excavation.
* **Groundwater Observed** (`groundwater_observed`, select_one, required): Indicate whether water was observed during the inspection.
* **Groundwater Depth** (`groundwater_depth`, text, optional): Enter the depth to the water table.
* **Dewatering Required** (`dewatering_required`, select_one, required): Indicate whether water removal is needed.
* **Base Preparation** (`base_preparation`, select_one, required): Rate the condition of the base preparation (e.g., Excellent, Good, etc.).
* **Compaction Test Completed** (`compaction_test`, select_one, required): Indicate whether the soil has been tested for compaction.
* **Compaction Percentage** (`compaction_percentage`, text, optional): Enter the percentage of maximum density.
* **Vapor Barrier Installed** (`vapor_barrier`, select_one, required): Indicate whether a vapor barrier is installed.
* **Reinforcement Type** (`reinforcement`, select_one, required): Select the type of reinforcement used (e.g., Rebar grid, Wire mesh, etc.).
* **Rebar Size** (`rebar_size`, text, optional): Enter the size and spacing of the rebar.
* **Forms Inspection** (`forms_inspection`, select_one, required): Rate the condition of formwork (e.g., Approved, Approved with notes, etc.).
* **Forms Notes** (`forms_notes`, text, optional): Enter any issues with forms.
* **Utilities Located** (`utilities_location`, select_one, required): Indicate whether utilities are marked.
* **Utility Types Present** (`utilities_types`, select_multiple, required): Select all utilities present (e.g., Water, Sewer, etc.).
* **Drainage System** (`drainage_system`, text, optional): Enter the type of drainage system.
* **Weather Conditions** (`weather_conditions`, text, required): Enter the current weather conditions.
* **Temperature** (`temperature`, text, required): Enter the ambient temperature.
* **Site Access** (`site_access`, select_one, required): Rate the condition of access routes (e.g., Good, Fair, etc.).
* **Safety Measures in Place** (`safety_measures`, select_one, required): Indicate whether safety protocols are followed.
* **Safety Deficiencies** (`safety_deficiencies`, text, optional): List any safety issues.
* **Photographs Taken** (`photographs_taken`, number, optional): Enter the number of photos taken.
* **Compliance Status** (`compliance_status`, select_one, required): Rate the overall compliance status (e.g., Compliant, Non-compliant, etc.).
* **Deficiencies Found** (`deficiencies`, text, optional): List any issues found.
* **Corrective Actions Required** (`corrective_actions`, text, optional): Enter what needs to be fixed.
* **Approval Status** (`approval_status`, select_one, required): Indicate the approval status (e.g., Approved, Not approved, etc.).
* **Next Inspection Required** (`next_inspection`, text, optional): Enter when the next inspection is scheduled.
* **Inspector Signature** (`inspector_signature`, text, required): Type your signature as the inspector.
* **Contractor Signature** (`contractor_signature`, text, optional): Enter the contractor's acknowledgement.

Note: Please review and verify all information before submitting the form.
