# Wood Destroying Insect Inspection Form - Help Guide
## Purpose
This form is used to document the results of a wood destroying insect inspection. It is intended to collect information on the type of pest observed, the location and description of the infestation, and the method of control used.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter the property address in the `Property Address` field.
2. Select the type of pest observed from the `Pest Type` dropdown menu.
3. Describe the location of the infestation in the `Location` field.
4. Provide a detailed description of the pest in the `Pest Description` field.
5. Select the method of control used from the `Control Method` field (you can select multiple options).
6. Enter the name of the inspector who completed the form in the `Inspector Name` field.
7. Enter the date and time the inspection was completed in the `Date Completed` and `Completed Time` fields, respectively.
8. Select the tool used for the inspection from the `Assigned Tool` dropdown menu.
9. Enter a unique identifier for the form in the `Form ID` field.

## Field-by-Field Explanation

* **Property Address**: Enter the address of the property that was inspected.
	+ Type: `text`
	+ Required: `false`
* **Pest Type**: Select the type of pest observed from the list.
	+ Options: `Ants`, `Cockroaches`, `Flies`, `Rodents`, `Termites`, `Wasps`, `Yellowjackets`
	+ Required: `false`
* **Location**: Describe the location of the infestation in detail.
	+ Type: `note`
	+ Required: `false`
* **Pest Description**: Provide a detailed description of the pest observed.
	+ Type: `text`
	+ Required: `false`
* **Control Method**: Select the method(s) used to control the pest.
	+ Options: `Trapping`, `Exclusion`, `Elimination`, `Monitoring`, `Prevention`
	+ Required: `false`
* **Inspector Name**: Enter the name of the inspector who completed the form.
	+ Type: `text`
	+ Required: `false`
* **Date Completed**: Enter the date the inspection was completed.
	+ Type: `date`
	+ Required: `false`
* **Completed Time**: Enter the time the inspection was completed.
	+ Type: `time`
	+ Required: `false`
* **Assigned Tool**: Select the tool used for the inspection from the list.
	+ Options: `chatjimmy`, `Other`
	+ Required: `false`
* **Form ID**: Enter a unique identifier for the form.
	+ Type: `number`
	+ Required: `false`
