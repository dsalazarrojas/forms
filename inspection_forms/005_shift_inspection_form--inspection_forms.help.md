# Shift Inspection Form - Help Guide
## Purpose
This form is used to inspect shifts and gather information about an employee's performance during their shift.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the necessary fields, such as the employee's name, attendance, and performance.
2. Answer the "Performance" section questions, selecting "Yes" or "No" for each question.
3. Provide any additional comments or notes in the "Comments" section.
4. Sign the form with the employee's and manager's signature.

## Field-by-Field Explanation
* **Shift Inspection Form (Page 1)**: This is the title of the form.
* **Employee**: This is where you select whether the employee was present or not.
* **Attendance**: This is a multiple-choice option for whether the employee was on time or late.
* **On Time**: This is a multiple-choice option for whether the employee was on time.
* **Late**: This is a multiple-choice option for whether the employee was late.
* **On Time and ready to work**: This is a multiple-choice option for whether the employee was on time and ready to work.
* **Shift Inspection Form Page 2**: This is the title of the second page of the form.
* **Performance**: This is where you select whether the employee performed well or not.
* **Attentive**: This is a multiple-choice option for whether the employee was attentive.
* **Well-organized**: This is a multiple-choice option for whether the employee was well-organized.
* **Team player**: This is a multiple-choice option for whether the employee was a team player.
* **Willingness to Learn**: This is a multiple-choice option for whether the employee was willing to learn.
* **Shift Inspection Form Page 3**: This is the title of the third page of the form.
* **Notes**: This is a text field for any additional comments or notes.
* **Notes (2)**: This is another text field for any additional comments or notes.
* **Shift Inspection Form Page 4**: This is the title of the fourth page of the form.
* **Comments**: This is a text field for any additional comments or notes.
* **Comments (2)**: This is another text field for any additional comments or notes.
* **Shift Inspection Form Page 5**: This is the title of the fifth page of the form.
* **Employee Signature**: This is where you select whether the employee has signed the form.
* **Employee Signature (2)**: This is another text field for the employee to sign.
* **Manager Signature**: This is a text field for the manager or supervisor to sign.
* **Manager**: This is where you select whether the manager has signed the form.
* **Employee 2**: This is where you select whether there is an employee 2 present or not.
* **Date**: This is a date field for the date of the inspection.
* **Employee 2**: This is a multiple-choice option for whether the employee 2 was present.
* **Employee Signature**: This is where you select whether the employee 2 has signed the form.
* **Employee 2 Signature**: This is another text field for the employee 2 to sign.
