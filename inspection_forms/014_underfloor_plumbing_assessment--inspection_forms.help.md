# Underfloor Plumbing Assessment - Help Guide
## Purpose
This form is used to gather information about underfloor plumbing conditions and issues in facilities or buildings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to ensure you have all the required information.
2. Answer each field as accurately and thoroughly as possible.
3. For fields with multiple options, select only one or more that apply to your situation.

## Field-by-Field Explanation
* **Underfloor Plumbing Conditions** (Underfloor Plumbing Conditions, Text, Optional): Describe the overall condition of the underfloor plumbing in the facility or building.
* **Issues Encountered** (Issues Encountered, Select One, Optional):
	+ Select "Yes" if you have noticed any issues with underfloor plumbing.
	+ Select "No" otherwise.
* **Issue Description** (Issue Description, Text, Optional): Provide a detailed description of any issues you have encountered with underfloor plumbing.
* **Photo Evidence** (Photo Evidence, Note, Optional): Attach any relevant photographs or images that support your assessment.
* **Assessment Report** (Assessment Report, Text, Optional): Write a detailed report on your findings and observations regarding the underfloor plumbing conditions.
* **Underfloor Plumbing Issues** (Underfloor Plumbing Issues, Select One, Optional):
	+ Select "Yes" if underfloor plumbing issues are present.
	+ Select "No" otherwise.
* **Issue Priority** (Issue Priority, Select One, Optional):
	+ Select "Low" if the issue is minor and does not require immediate attention.
	+ Select "Medium" or "High" if the issue is significant and requires immediate attention.
* **Issue Remediating Status** (Issue Remediating Status, Select One, Optional):
	+ Select "Open" if the issue is still pending resolution.
	+ Select "Closed" if the issue has been resolved.
	+ Select "In Progress" if the issue is being addressed but not yet resolved.

## Tips
- Be thorough in your responses, as accurate information will help in addressing potential issues.
- Use the "Issues Encountered" field to identify any issues that are present.
- The "Issue Description" field can be used to provide more details about the issue.
- Attach relevant photographs or images to support your assessment using the "Photo Evidence" field.
- Provide a comprehensive report on your findings using the "Assessment Report" field.
- Select the correct option for "Underfloor Plumbing Issues" based on the presence or absence of issues.
- Select the appropriate priority for "Issue Priority" based on the significance of the issue.
- Select the correct status for "Issue Remediating Status" based on the current state of issue resolution.
