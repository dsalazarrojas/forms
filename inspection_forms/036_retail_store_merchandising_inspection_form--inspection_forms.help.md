# retail_store_merchandising_inspection_form - Help Guide
## Purpose
This form is used to collect information about a retail store during an inspection.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the store's address in the "store_address" field.
2. Enter the store's name in the "store_name" field.
3. Select the region where the store is located from the "region" dropdown menu.
4. Choose the type of store from the "store_type" dropdown menu.
5. Enter the name and contact information of the person responsible for the store in the "contact_person" field.
6. If applicable, fill out the store's operating hours in the "store_hours" field.
7. If applicable, specify the date and time of the inspection in the "date_of_inspection" and "time_of_inspection" fields.

## Field-by-Field Explanation
* **store_address** (text): The store's address, including house number, street, and city.
* **store_name** (text): The name of the store, as it is known to the public.
* **region** (select_one): The region where the store is located, which can be East, West, or South.
* **store_type** (select_multiple): The type of store, which can be Retail, Wholesale, or Other.
* **contact_person** (text): The name and contact information of the person responsible for the store.
* **store_hours** (time): The store's operating hours, if applicable.
* **date_of_inspection** (date): The date of the inspection, if applicable.
* **time_of_inspection** (time): The time of the inspection, if applicable.
* **store_type**: If any other store type is selected, please describe the other store type in the additional information box.
