# Line Length Input Form - Help Guide
## Purpose
The Line Length Input Form is used to collect and track information related to line length measurements for various projects, including construction, engineering, and surveying.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure that you have the relevant information and supporting documentation ready for input.
2. Choose the correct measurement unit for the line length (inches, feet, or meters).
3. Enter the project name accurately.
4. Enter the line length measurement in the provided field.
5. Add any relevant notes or comments for the project.
6. Upload supporting documentation (e.g., photos, videos).
7. Verify the project status with the relevant personnel and enter the verification date.
8. Select the project type (construction, engineering, surveying, or other).
9. Choose the project status (in progress, completed, pending).
10. If needed, enter an alternative measurement unit.

## Field-by-Field Explanation

* **Line Length Input** (`measurement_length`, number, required): Enter the line length measurement in the selected unit (inches, feet, or meters).
* **Project Name** (`project_name`, text, required): Enter the name of the project accurately.
* **Measurement Unit** (`measurement_unit`, select_one, required): Choose the correct measurement unit for the line length (inches, feet, or meters).
* **Notes** (`notes`, text, optional): Enter any additional comments or notes related to the project.
* **Supporting Documents** (`supporting_documents`, text, optional): Upload supporting documentation, such as photos or videos, to further verify the project status.
* **Verification Notes** (`verification_notes`, text, optional): Enter any comments or notes related to verification.
* **Project Start Date** (`project_start_date`, date, optional): Enter the project start date, if applicable.
* **Project Finish Date** (`project_finish_date`, date, optional): Enter the project finish date, if applicable.
* **Verification By** (`verification_by`, select_one, required): Choose the personnel responsible for verifying the project status.
* **Verified Date** (`verified_date`, date, optional): Enter the date the project was verified.
* **Project Type** (`project_type`, select_one, required): Choose the type of project (construction, engineering, surveying, or other).
* **Project Status** (`project_status`, select_multiple, required): Choose the current project status (in progress, completed, pending).
* **Other Measurement Unit** (`measurement_unit_other`, text, optional): If the project requires an alternative measurement unit, enter it here.
