# Room Condition Form - Help Guide
## Purpose
The Room Condition Form is designed to assess the state of a room, allowing users to record and report on various aspects of the room's condition. This form is useful for rental or property inspection purposes.

## How To Complete This Form
1. Fill out the form page by page, starting from the first page.
2. For each page, read the label and hint provided for each field.
3. Fill in the required fields, and use your discretion for optional fields.
4. Be as detailed as possible when answering questions.

## Field-by-Field Explanation
* **Room Condition Form Page 1: Room Condition Form** (`room_condition_form_page`, text, required: false)
	+ This is the first page of the form, which appears to be the introduction to the room condition assessment.
* **Room Condition Form Inventory** (`room_condition_form_inventory`, text, required: false)
	+ This field is for recording the inventory of the room, such as furniture, fixtures, and appliances.
* **Room Condition Form Pictures** (`room_condition_form_pictures`, text, required: false)
	+ This field is for uploading or referencing pictures of the room's condition, such as before-and-after shots or damage.
* **Room Condition Form Marks** (`room_condition_form_marks`, select_multiple, required: false)
	+ This field is for marking any marks, scratches, or stains on the walls or floors. Select multiple options as needed.
	+ Options: scratches, stains, holes, dents, nicks, gouges, other
* **Room Condition Form Damages** (`room_condition_form_damages`, select_multiple, required: false)
	+ This field is for identifying any damages or issues found in the room. Select multiple options as needed.
	+ Options: small, medium, large
* **Room Condition Form Issues** (`room_condition_form_issues`, text, required: false)
	+ This field is for checking the doors and windows for any damage or issues.
* **Room Condition Form Issues Description** (`room_condition_form_issues_description`, text, required: false)
	+ This field is for providing more information about any issues found in the room.
* **Room Condition Form Signs of Wear** (`room_condition_form_signs_of_wear`, select_one, required: false)
	+ This field is for identifying the signs of wear on the room's condition, such as peeling paint or worn-out furniture.
	+ Options: none, slight, moderate, severe
* **Room Condition Form Signs of Wear Description** (`room_condition_form_signs_of_wear_description`, text, required: false)
	+ This field is for providing more information about any signs of wear found in the room.
* **Room Condition Form Priorities** (`room_condition_form_priorities`, select_multiple, required: false)
	+ This field is for identifying the priorities for repairs or actions needed for the room's condition.
	+ Options: low, medium, high

## Tips
- Be thorough and detailed when filling out the form.
- Use your best judgment when selecting options for each field.
- If you're unsure about an option, use the "other" option for marks or damages.
- If you need to upload pictures, use a high-quality image with a clear description.
- If you need to provide more information, use the description field for each field.
