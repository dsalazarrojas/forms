# Doha Drilling Daily Report Master تقرير الحفر اليومي - Help Guide
## Purpose
This form is designed to collect daily drilling data from the field, providing a structured and standardized way to document and report on drilling activities. It is a critical tool for drilling operations teams to ensure accurate and reliable data collection.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name in the "Project" field.
2. Select the correct date of the drilling operation in the "Date" field.
3. Enter the location of the drilling operation in the "Location" field.
4. Choose the type of drilling mud used from the "Drilling Mud" field.
5. Select the specific drilling rig used from the "Drilling Rig" field.
6. Enter the measured values for the following fields:
	* Drillpipe (in meters)
	* Depth (in meters)
	* Drilling Mud Density (in g/cm³)
	* Drilling Mud Viscosity (in cp)
	* Temperature (in °C)
	* Water Depth (in meters)
	* Drilling RPM (in RPM)
	* Drilling Rate (in meters/hour)
	* Drillpipe Inner Diameter (in meters)
	* Drillpipe Length (in meters)
7. Enter the weight of the drilling rig in the "Drilling Rig Weight" field, using either kg or ton as the unit.
8. Select the unit for the drilling rig weight from the options.
9. Enter the weight of the drilling mud in the "Drilling Mud Weight" field, using either kg or ton as the unit.
10. Select the unit for the drilling mud weight from the options.
11. Select the type of drilling rig from the "Drilling Rig Type" field.
12. Enter the name of the rig operator in the "Rig Operator" field.
13. Enter the start and end dates of the drilling operation in the "Drilling Date" field.
14. Enter the duration of the drilling operation in the "Drilling Time" field.

## Field-by-Field Explanation

* **Project** (1): Enter the name of the project being drilled.
* **Date** (2): Select the date of the drilling operation (not required but recommended for tracking purposes).
* **Location** (3): Enter the location of the drilling site.
* **Drilling Mud** (6): Select the type of drilling mud used (e.g., "Mud with water", "Mud with diesel", etc.).
* **Drilling Rig** (7): Select the specific drilling rig used.
* **Drillpipe** (8): Enter the measured value of the drillpipe (in meters).
* **Depth** (9): Enter the measured value of the depth (in meters).
* **Drilling Mud Density** (10): Enter the measured value of the drilling mud density (in g/cm³).
* **Drilling Mud Viscosity** (11): Enter the measured value of the drilling mud viscosity (in cp).
* **Temperature** (12): Enter the measured value of the temperature (in °C).
* **Water Depth** (13): Enter the measured value of the water depth (in meters).
* **Drilling RPM** (14): Enter the measured value of the drilling RPM (in RPM).
* **Drilling Rate** (15): Enter the measured value of the drilling rate (in meters/hour).
* **Drillpipe Inner Diameter** (16): Enter the measured value of the drillpipe inner diameter (in meters).
* **Drillpipe Length** (17): Enter the measured value of the drillpipe length (in meters).
* **Drilling Rig Weight** (18): Enter the weight of the drilling rig, using either kg or ton as the unit.
* **Drilling Rig Weight Unit** (19): Select the unit used for the drilling rig weight (kg or ton).
* **Drilling Mud Weight** (20): Enter the weight of the drilling mud, using either kg or ton as the unit.
* **Drilling Mud Weight Unit** (21): Select the unit used for the drilling mud weight (kg or ton).
* **Drilling Rig Type** (22): Select the type of drilling rig used (e.g., "PDC", "Tricky", etc.).
* **Rig Operator** (23): Enter the name of the rig operator.
* **Drilling Date** (24): Enter the start and end dates of the drilling operation.
* **Drilling Time** (25): Enter the duration of the drilling operation in hours.

Note: Please ensure that all required fields are completed accurately and thoroughly to maintain data integrity.
