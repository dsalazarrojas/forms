# School Bus Pre Trip Inspection Report Form - Help Guide
## Purpose
The School Bus Pre Trip Inspection Report Form is used to record the pre-trip inspection of a school bus. This form helps identify any potential issues with the vehicle before it departs, ensuring a safe and efficient trip.

## How To Complete This Form
1. Enter the bus number, driver name, and vehicle number.
2. Select the date and time of the inspection.
3. Check the pre-trip items, such as the fire extinguisher, mirrors, tires, brakes, lights, horn, parking brakes, steering, suspension, brakes clearance, tire pressure, and vehicle condition.
4. Add any comments or concerns about the vehicle.
5. Sign the form to confirm completion.

## Field-by-Field Explanation
* **Bus Number** (bus_number): Enter the bus number for identification purposes.
* **Driver Name** (driver_name): Enter your name as the driver performing the inspection.
* **Vehicle Number** (vehicle_number): Enter the vehicle number for identification purposes.
* **Date Inspected** (date_inspected): Select the date of the inspection using the date field.
* **Time Inspected** (time_inspected): Select the time of the inspection using the time field.
* **Pre-Trip Items Checked** (pre_trip_items): Check the pre-trip items that were inspected, such as fire extinguishers, mirrors, tires, and brakes. Select 'Yes' for checked and 'No' for not checked.
* **Fire Extinguisher** (fire_extinguisher): Check if the fire extinguisher is fully charged or not fully charged.
* **Mirrors** (mirrors): Check if the mirrors are clean or streaked.
* **Tires** (tires): Select the condition of the tires: in good condition, less than 1/2 inch tread, or less than 1/4 inch tread.
* **Brakes** (brakes): Select the function of the brakes: they function well, function badly, or badly.
* **Lights** (lights): Select if the lights function well or badly.
* **Horn** (horn): Select if the horn sounds good or badly.
* **Parking Brakes** (parking_brakes): Select if the parking brakes function well or badly.
* **Steering** (steering): Select if the steering function well or badly.
* **Suspension** (suspension): Select if the suspension is well or badly.
* **Brakes Clearance** (brakes_clearance): Select if the brake clearance is proper or badly.
* **Tire Pressure** (tire_pressure): Select if the tire pressure is correct or low.
* **Vehicle Condition** (vehicle_condition): Describe the overall condition of the vehicle.
* **Driver Signature** (driver_signature): Sign your name as the driver performing the inspection.
* **Vehicle Condition** (vehicle_condition): Add any comments or concerns about the vehicle.
* **Inspector Signature** (inspector_signature): Sign your name as the inspector (if different from the driver).
* **Inspection Completed** (inspection_completed): Select if the inspection is completed correctly or not.
* **Date Completed** (date_completed): Select the date of completion using the date field.
* **Time Completed** (time_completed): Select the time of completion using the time field.
* **Comments Completed** (comments_completed): Add any comments or concerns about the completion of the inspection.
