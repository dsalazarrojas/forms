# Irrigation Audit Form - Help Guide
## Purpose
The Irrigation Audit Form is used to assess the status of irrigation systems. It helps in tracking and comparing the condition of these systems over time.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form sections and questions carefully.
2. Answer each question accurately based on your inspection.
3. Make sure to fill out all required fields.

## Field-by-Field Explanation
* **Irrigation Systems**: This is a text field where you can describe the irrigation systems in detail. Be as specific as possible.
* **Main Valve**: Select "Yes" if the main valve is present and functioning correctly, or "No" if it is not.
* **Pump Valve**: Select all the pump valves that are present and functioning correctly.
* **Controller**: Select "Yes" if the controller is present and functioning correctly, or "No" if it is not.
* **Meter**: Select "Yes" if the meter is present and functioning correctly, or "No" if it is not.
* **Irrigation Schedule**: Select all schedules that are currently in effect.
* **Maintenance Schedule**: Select all schedules for maintenance that are currently in effect.
* **Maintenance Frequency**: Select "Yes" if maintenance is performed regularly, or "No" if it is not.
* **Inspection Frequency**: Select "Yes" if regular inspections are performed, or "No" if they are not.
* **System Type**: Select the type of irrigation system present (e.g., "Yes" for a specific type).
* **Irrigation System Status**: Select the current status of the system (Active or Inactive).
