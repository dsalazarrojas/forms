# Sweet Corn Quality Assessment Form - Help Guide

## Purpose
The purpose of this form is to assess the quality of sweet corn. It is designed to be used by sweet corn producers, farmers, or quality assurance staff to evaluate the quality of sweet corn in various aspects.

## How To Complete This Form

To complete this form, follow these steps:

1. Start by selecting the relevant page based on the specific type of quality assessment being conducted (first page for initial assessment, second page for advanced assessment, third page for final assessment).
2. Fill in the required fields with accurate information about the sweet corn.
3. Select the relevant options for each field according to the assessment.
4. Enter dates and times accurately for fields that require them.

## Field-by-Field Explanation

* **First_page_fields_1**: This is the title of the sweet corn being assessed. Please enter the name of the sweet corn.
* **First_page_fields_2**: This field is for assessing the appearance of the sweet corn. Please select "Yes" if the sweet corn has the following: 
  + No visible signs of damage
  + No mold or mildew
  + No insect or animal damage
  + No visible rot
  + No signs of mold or mildew
  + No other defects
  Select "No" otherwise.
* **First_page_fields_3**: This field is for assessing the maturity of the sweet corn. Please enter a number between 1 and 5, where 1 is immature and 5 is mature.
* **First_page_fields_4**: This field is for assessing the taste of the sweet corn. Please enter a number between 1 and 5, where 1 is bad taste and 5 is excellent taste.
* **First_page_fields_5**: This field is for entering the date the sweet corn was harvested. Please enter the date in the format YYYY-MM-DD.
* **First_page_fields_6**: This field is for entering the time the sweet corn was harvested. Please enter the time in 24-hour format.
* **First_page_fields_7**: This field is for assessing if the sweet corn was stored properly. Please select "Yes" if the sweet corn was stored:
  + In a dry place
  + With proper ventilation
  + At a consistent temperature
  + Away from insects and animals
  Select "No" otherwise.
* **First_page_fields_8**: This field is for entering the email of the person conducting the assessment.
* **First_page_fields_9**: This field is for any additional notes or comments about the sweet corn.
* **Second_page_fields_1**: This field is for assessing the size of the sweet corn. Please enter a number between 1 and 10, where 1 is small and 10 is large.
* **Second_page_fields_2**: This field is for assessing the color of the sweet corn. Please select "Yes" if the sweet corn has the following:
  + No visible signs of browning
  + No visible signs of green spots
  + No other defects
  Select "No" otherwise.
* **Second_page_fields_3**: This field is for assessing if the sweet corn was handled properly. Please select "Yes" if the sweet corn was handled:
  + With care
  + In a clean environment
  + With proper equipment
  Select "No" otherwise.
* **Second_page_fields_4**: This field is for entering the weight of the sweet corn. Please enter the weight in kg.
* **Second_page_fields_5**: This field is for entering the number of sweet corn pieces evaluated. Please enter a number.
* **Second_page_fields_6**: This field is for entering the date the sweet corn was evaluated. Please enter the date in the format YYYY-MM-DD.
* **Second_page_fields_7**: This field is for entering the time the sweet corn was evaluated. Please enter the time in 24-hour format.
* **Second_page_fields_8**: This field is for assessing if the sweet corn was graded properly. Please select "Yes" if the sweet corn was graded:
  + In a clean environment
  + With proper equipment
  + With proper grading standards
  Select "No" otherwise.
* **Second_page_fields_9**: This field is for any additional notes or comments about the sweet corn.
* **Third_page_fields_1**: This field is for assessing if the sweet corn was packed properly. Please select "Yes" if the sweet corn was packed:
  + In a clean box
  + With proper packaging material
  + Properly sealed
  Select "No" otherwise.
* **Third_page_fields_2**: This field is for assessing if the sweet corn was transported properly. Please select "Yes" if the sweet corn was transported:
  + In a clean vehicle
  + With proper safety measures
  + Properly secured
  Select "No" otherwise.
* **Third_page_fields_3**: This field is for entering the date the sweet corn was packed. Please enter the date in the format YYYY-MM-DD.
* **Third_page_fields_4**: This field is for entering the time the sweet corn was packed. Please enter the time in 24-hour format.
