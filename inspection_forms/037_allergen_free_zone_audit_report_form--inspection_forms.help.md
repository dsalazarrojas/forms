# Allergen Free Zone Audit Report Form - Help Guide
## Purpose
The purpose of this form is to assess the compliance of a facility with allergen-free zone regulations, ensuring a safe environment for individuals with food allergies.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and answer truthfully based on your inspection findings.
2. For each field, select the corresponding answer that best reflects your observations.
3. If a field requires a description or additional information, provide as much detail as possible.
4. Review the form carefully before submitting it to ensure accuracy and completeness.

## Field-by-Field Explanation
* **1. Audit ID**: Unique audit identifier.
	+ Enter a unique code or number assigned to the audit.
* **2. Audit Date**: Date of audit.
	+ Enter the date the audit was conducted.
* **3. Audit Start Time**: Start time of audit.
	+ Enter the start time of the audit.
* **4. Audit End Time**: End time of audit.
	+ Enter the end time of the audit.
* **5. Auditor Name**: Who conducted the audit.
	+ Enter the name of the auditor who conducted the audit.
* **6. Auditor Title**: Position/role of the auditor.
	+ Enter the title or position of the auditor.
* **7. Facility Name**: Name of facility.
	+ Enter the name of the facility being audited.
* **8. Facility Address**: Full address of facility.
	+ Enter the full address of the facility.
* **9. Zone Audited**: Specific area.
	+ Enter the specific area or zone that was audited.
* **10. Zone Type**: Type of area.
	+ Select the type of area that was audited (e.g., kitchen, food prep area, storage area, etc.).
* **11. Allergens Covered**: Select all that apply.
	+ Select all the allergens that were covered in the audit (e.g., peanuts, tree nuts, milk, eggs, etc.).
* **12. Allergen-Free Signage Present**: Are signs posted?
	+ Select "Yes, adequate" if signs are present and adequate; "Yes, but inadequate" if signs are present but not adequate; "No signage" if no signs are present.
* **13. Signage Condition**: State of signs.
	+ Select the condition of the signs posted (e.g., excellent, good, fair, poor, not applicable).
* **14. Physical Barriers**: Separation measures.
	+ Select if physical barriers are in place, adequate or inadequate.
* **15. Dedicated Equipment**: Separate utensils/equipment.
	+ Select if equipment is dedicated for specific tasks or not.
* **16. Equipment Labeling**: Is equipment labeled?
	+ Select if equipment is labeled for specific tasks or not.
* **17. Cleaning Procedures**: Are procedures followed?
	+ Select if cleaning procedures are followed, documented, or not.
* **18. Cleaning Supplies**: Dedicated supplies?
	+ Select if dedicated cleaning supplies are provided.
* **19. Staff Training Status**: Are staff trained?
	+ Select if staff are trained on allergen-free zone procedures.
* **20. Training Documentation**: Is training documented?
	+ Select if training is documented.
* **21. Cross-Contamination Risk**: Risk level observed.
	+ Select the risk level observed (e.g., no risk, low, moderate, high, critical).
* **22. Storage Practices**: How are allergen-free items stored?
	+ Select how allergen-free items are stored (e.g., properly segregated, somewhat segregated, not segregated).
* **23. Ingredient Verification**: Are ingredients verified?
	+ Select if ingredients are verified for allergen-free status.
* **24. Violations Found**: Any violations?
	+ Select any observed violations (e.g., none, minor, major, critical).
* **25. Violation Details**: Describe any observed violations.
	+ Provide a brief description of any observed violations.
* **26. Corrective Actions Needed**: List required actions.
	+ Provide a list of corrective actions needed to address any observed violations.
* **27. Corrective Action Deadline**: Due date for fixes.
	+ Enter the due date for any corrective actions.
* **28. Follow-Up Audit Required**: Is re-audit needed?
	+ Select if a re-audit is required within a specific timeframe.
* **29. Overall Compliance**: Rate compliance.
	+ Rate the overall compliance of the facility with allergen-free zone regulations.
* **30. Auditor Signature**: Auditor confirmation.
	+ Select to confirm the accuracy of the audit.
* **31. Manager Acknowledgment**: Manager review.
	+ Enter a brief acknowledgment from the manager.
* **32. Additional Notes**: Any other observations.
	+ Provide any additional notes or observations from the audit.

## Tips
* Answer all questions truthfully and accurately based on your inspection findings.
* Use the fields to provide clear and concise answers.
* Review each field carefully before moving on to the next.
* Ensure that all fields are complete and accurate before submitting the form.
