# Nut Tree Compliance Checklist - Help Guide
## Purpose

This form is used to record the findings and details of a nut tree inspection. It is intended to be used for orchard inspections, and its completion will help ensure accurate and consistent data collection.

## How To Complete This Form

1. Select the "Orchard Inspection" page and provide a brief description of the inspection.
2. Enter the date of the inspection using the "Inspection Date" field. This date should match the actual date of the inspection.
3. Complete the "Species Compliance Check" field by selecting all relevant species that were inspected.
4. Add any additional notes about the inspection in the "Notes" field.
5. If you have inspected multiple species, you can provide your email address in the "Email Inspector" field so that you can be contacted directly about any issues that arise from this inspection.

## Field-by-Field Explanation

* **Orchard Inspection** (`orchard_inspection`, text, optional): A brief description of the inspection, including the location and any notable findings.
* **Inspection Date** (`inspection_date`, date, optional): The date of the inspection.
* **Species Compliance Check** (`species_compliance_check`, select_multiple, optional): Select all relevant species that were inspected during the orchard inspection.
* **Notes** (`notes`, note, optional): Additional notes about the inspection, including any areas of concern or recommendations for improvement.
* **Email Inspector** (`email_inspector`, email, optional): If you would like to be contacted directly about any issues that arise from this inspection, provide your email address here.
