# Transportation Infrastructure Condition Report - Help Guide
## Purpose
This form is used to report the condition of transportation infrastructure, such as roads, bridges, and assets.

## How To Complete This Form
Before starting, please make sure you have a clear understanding of the infrastructure asset's current condition. The form is divided into sections, each with its own purpose. Please complete the form from top to bottom.

## Field-by-Field Explanation

* **Road Condition** (`road_condition`, `select_one`, required: false): Select the current condition of the road from the options provided: Good, Fair, Poor. This field helps assess the overall condition of the road.
* **Bridge Condition** (`bridge_condition`, `select_one`, required: false): Select the current condition of the bridge from the options provided: Good, Fair, Poor. This field assesses the overall condition of the bridge.
* **Asset Condition** (`asset_condition`, `select_one`, required: false): Select the current condition of the asset from the options provided: Good, Fair, Poor. This field helps assess the overall condition of the asset.
* **Condition Date** (`condition_date`, `date`, required: false): Enter the date on which the condition was assessed. This field helps track when the condition was last reported.
* **Condition Time** (`condition_time`, `time`, required: false): Enter the time of day when the condition was assessed. This field helps track when the condition was last reported.
* **Condition Description** (`condition_description`, `text`, required: false): Enter a brief description of the condition of the asset. This field provides additional details to support the condition assessment.
* **Road Type** (`road_type`, `select_one`, required: false): Select the type of road from the options provided: Highway, Street, Alley, Other. This field helps identify the specific type of road.
* **Asset Type** (`asset_type`, `select_one`, required: false): Select the type of asset from the options provided: Bridge, Road, Other. This field helps identify the specific type of asset.
* **Condition Status** (`condition_status`, `select_one`, required: false): Select the status of the condition from the options provided: Complete, Incomplete, Unknown. This field indicates the completeness of the condition assessment.
* **Inspection Type** (`inspection_type`, `select_multiple`, required: false): Select the types of inspections that were conducted, from the options provided: Visual, Physical, Other. This field helps identify the methods used to assess the condition.
* **Notes** (`notes`, `note`, required: false): Enter any additional notes or comments about the condition. This field provides space for any extra information.
* **Email** (`email`, `email`, required: false): Enter a contact email for further information or clarification. This field helps facilitate communication.
* **Phone** (`phone`, `text`, required: false): Enter a contact phone number for further information or clarification. This field helps facilitate communication.
* **Asset Location** (`asset_location`, `text`, required: false): Enter a brief description of the location of the asset. This field helps identify where the asset is located.
* **Asset Location Notes** (`asset_location_notes`, `text`, required: false): Enter any additional notes or comments about the location. This field provides extra information about the location.
* **Asset Location Coordinates** (`asset_location_coordinates`, `text`, required: false): Enter the coordinates of the location (e.g., GPS coordinates). This field helps pinpoint the exact location of the asset.
* **Asset Location Coordinates Lat** (`asset_location_coordinates_lat`, `number`, required: false): Enter the latitude of the location. This field helps identify the geographical location of the asset.
* **Asset Location Coordinates Lon** (`asset_location_coordinates_lon`, `number`, required: false): Enter the longitude of the location. This field helps identify the geographical location of the asset.

Please complete the form carefully and accurately, and do not hesitate to contact if you have any questions or need further clarification.
