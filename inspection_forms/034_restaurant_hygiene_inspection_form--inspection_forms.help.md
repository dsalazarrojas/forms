# Restaurant Hygiene Inspection Form - Help Guide
## Purpose
The Restaurant Hygiene Inspection Form is designed to collect information on the cleanliness and safety of a restaurant during an on-site inspection.

## How To Complete This Form
To complete this form, follow these steps:

* Select 'Yes' or 'No' for each of the following:
	+ Is Inspection Required
	+ Fire Extinguisher
	+ Temperature Control
	+ Personal Hygiene
	+ Hand Washing
	+ Food Storage
	+ Cleaning Sinks
	+ Toilets Facilities
	+ Food Temperature Control
	+ Food Allergens
	+ Food Handling
	+ Food Presentation
	+ Food Labeling
	+ Personal PPE
	+ Food Prevention
	+ Food Allergens Control
* Enter the following required information:
	+ Date of Inspection (in mm/dd/yyyy format)
	+ Time of Inspection
	+ Inspector's Name
	+ Restaurant Name
	+ Address
	+ Contact Number
	+ Food Safety Certificate
	+ Inspector's Comments (optional)
* Select 'Yes' or 'No' for the following:
	+ Food Allergens Control

## Field-by-Field Explanation

* **Is Inspection Required**: Select 'Yes' if an inspection is required, 'No' otherwise.
* **Date of Inspection**: Enter the date of the inspection in mm/dd/yyyy format.
* **Time of Inspection**: Enter the time of the inspection.
* **Inspector's Name**: Enter the name of the inspector.
* **Restaurant Name**: Enter the name of the restaurant.
* **Address**: Enter the address of the restaurant.
* **Contact Number**: Enter the contact number of the restaurant.
* **Food Safety Certificate**: Scan or attach a copy of the food safety certificate.
* **Fire Extinguisher**: Select 'Yes' if a fire extinguisher is available, 'No' otherwise.
* **Temperature Control**: Select 'Yes' if temperature control is available, 'No' otherwise.
* **Personal Hygiene**: Select 'Yes' if personal hygiene is available, 'No' otherwise.
* **Hand Washing**: Select 'Yes' if hand washing facilities are available, 'No' otherwise.
* **Food Storage**: Select 'Yes' if food storage facilities are available, 'No' otherwise.
* **Cleaning Sinks**: Select 'Yes' if cleaning sinks are available, 'No' otherwise.
* **Toilets Facilities**: Select 'Yes' if toilets facilities are available, 'No' otherwise.
* **Food Temperature Control**: Select 'Yes' if food temperature control is available, 'No' otherwise.
* **Food Allergens**: Select 'Yes' if food allergens are controlled, 'No' otherwise.
* **Food Handling**: Select 'Yes' if food handling practices are safe, 'No' otherwise.
* **Food Presentation**: Select 'Yes' if food presentation is safe, 'No' otherwise.
* **Food Labeling**: Select 'Yes' if food labeling is safe, 'No' otherwise.
* **Personal PPE**: Select 'Yes' if personal protective equipment is available, 'No' otherwise.
* **Food Prevention**: Select 'Yes' if food prevention practices are safe, 'No' otherwise.
* **Food Allergens Control**: Select 'Yes' if food allergens are controlled, 'No' otherwise.
* **Inspector's Comments**: Enter any additional comments or feedback from the inspector.
