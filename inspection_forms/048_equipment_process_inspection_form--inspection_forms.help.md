# Equipment Process Inspection Form - Help Guide
## Purpose
This form collects information about equipment process inspections to maintain equipment health and safety, ensure regulatory compliance, and optimize operational efficiency.

## How To Complete This Form
1. Provide a brief description of the general information about the inspection.
2. Select all equipment used during the inspection.
3. Specify the location where the inspection was conducted.
4. Rate the condition of the equipment.
5. Indicate the current maintenance status of the equipment.
6. Add any additional notes about the inspection.
7. Enter the date the inspection was completed.
8. Provide the name and information of the person who completed the inspection.
9. Enter any relevant information about the machine being inspected.
10. Provide any additional information about the inspector.

## Field-by-Field Explanation
* **General Information**
	+ Label: General Information (`title`, `text`, not required)
	+ Explanation: This field is for entering a brief description of the inspection.
* **Equipment Used**
	+ Label: Equipment Used (`equipment_used`, `select_multiple`, not required)
	+ Explanation: Select all equipment used during the inspection.
* **Location Used**
	+ Label: Location Used (`location_used`, `text`, not required)
	+ Explanation: Specify the location where the inspection was conducted.
* **Condition Rating**
	+ Label: Condition Rating (`condition_rating`, `select_one`, not required)
	+ Explanation: Rate the condition of the equipment as Good, Fair, or Poor.
* **Maintenance Status**
	+ Label: Maintenance Status (`maintenance_status`, `select_one`, not required)
	+ Explanation: Indicate the current maintenance status of the equipment as True or False.
* **Notes**
	+ Label: Notes (`notes`, `note`, not required)
	+ Explanation: Add any additional notes about the inspection.
* **Date Completed**
	+ Label: Date Completed (`date_completed`, `date`, not required)
	+ Explanation: Enter the date the inspection was completed.
* **Completed By**
	+ Label: Completed By (`completed_by`, `text`, not required)
	+ Explanation: Provide the name and information of the person who completed the inspection.
* **Inspector Information**
	+ Label: Inspector Information (`inspector_info`, `text`, not required)
	+ Explanation: Enter any relevant information about the inspector.
* **Machine Name**
	+ Label: Machine Name (`machine_name`, `text`, not required)
	+ Explanation: Enter any relevant information about the machine being inspected.
