# Sprinkler System Inspection Form - Help Guide
## Purpose
The Sprinkler System Inspection Form is a tool for inspecting and reporting on the condition and status of a sprinkler system. It's used by maintenance staff or inspectors to collect and document information on the status of each component of the sprinkler system and identify any potential issues or areas for improvement.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out the "Inspection Form" section (page 1) with any identifying information about the inspection.
2. Select the current condition of the sprinkler system from the "system_condition" dropdown menu on page 1.
3. For each component of the system, select the status from the "system_component_status" field on page 1. This field allows for multiple selections.
4. Check whether the system complies with safety standards in the "safety_standard_compliance" field on page 1.
5. Provide any additional comments or observations about the inspection in the "notes" field on page 2.
6. Enter the name and contact information of the staff member conducting the inspection in the "assigned_inspector" fields on page 2.

* **safety_standard_compliance** (page 1):
