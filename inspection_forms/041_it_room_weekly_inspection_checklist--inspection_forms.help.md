# IT Room Weekly Inspection Checklist - Help Guide
## Purpose
The IT Room Weekly Inspection Checklist is used to evaluate the state of the IT room on a weekly basis. This form helps identify any potential issues that may affect the proper functioning of the equipment and overall environment.

## How To Complete This Form
1. Please select the "inspector_name" field and enter your name as the person completing the inspection.
2. Select the "inspector_date" field and choose the date of the inspection.
3. Evaluate each condition by selecting the corresponding rating (Good, Fair, Poor) for Conditions 1-3.
4. In the "Cleanliness 1-2" fields, describe the observed cleanliness state of the room.
5. Enter a numeric value in the "Temperature" field to check if the room temperature meets the required level.
6. In the "Security 1-2" fields, describe any security concerns or issues observed.
7. Use the "Comments" field to add any relevant comments or recommendations.

## Field-by-Field Explanation

* **inspector_name** (text): Enter your name as the person completing the inspection.
* **inspector_date** (date): Select the date of the inspection.
* **Condition 1** (select_multiple): Evaluate the condition of the room in terms of overall condition, using the options Good, Fair, Poor.
* **Condition 2** (select_multiple): Evaluate the condition of the room in terms of overall condition, using the options Good, Fair, Poor.
* **Condition 3** (select_multiple): Evaluate the condition of the room in terms of overall condition, using the options Good, Fair, Poor.
* **Cleanliness 1** (text): Describe the cleanliness state of the room.
* **Cleanliness 2** (text): Describe the cleanliness state of the room.
* **Temperature** (number): Enter a numeric value to check if the room temperature meets the required level.
* **Security 1** (text): Describe any security concerns or issues observed.
* **Security 2** (text): Describe any security concerns or issues observed.
* **Comments** (text): Add any relevant comments or recommendations.

## Tips
- Make sure to complete the form accurately and honestly.
- If any issues are found, make sure to document them in the "Comments" field.
- If you are unable to determine the condition of any aspect, please leave it blank.
- If there are any additional comments or recommendations, please add them in the "Comments" field.
