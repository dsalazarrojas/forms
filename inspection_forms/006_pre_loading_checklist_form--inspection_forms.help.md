# Pre Loading Checklist Form - Help Guide

## Purpose
This form is used to collect information about the status of a pre-loading checklist, including event details, completion status, and completion dates.

## How To Complete This Form
1. Enter the event details in the `Event Details` field.
2. Select the date of the event in the `Event Date` field.
3. Choose the current loading status in the `Loading Status` field.
4. Select the type of loading tasks performed in the `Loading Tasks` field.
5. Enter any additional comments related to the event in the `Comments (Event)` field.
6. Enter any general comments about the event in the `Comments (Overall)` field.
7. Enter any additional comments in the `Additional Comments` field.
8. Select the completion status of the pre-loading checklist in the `Pre-Loading Checklist Completion Status` field.
9. Enter the date the pre-loading checklist was completed in the `Pre-Loading Checklist Completion Date` field.
10. Enter the date of the next review in the `Review Date` field.
11. Select the current review status in the `Review Status` field.
12. Enter any additional comments from the review in the `Additional Review Comments` field.

## Field-by-Field Explanation
* **Event Details** (`event_details`): Enter a brief description of the event.
* **Event Date** (`event_date`): Enter the date of the event using the date format `YYYY-MM-DD`.
* **Loading Status** (`loading_status`): Select one of the following:
	+ Complete: The loading process is complete.
	+ Incomplete: The loading process is not complete.
	+ No Load: There is no loading process.
* **Loading Tasks** (`loading_tasks`): Select one or more of the following:
	+ Preventive Maintenance: Maintenance activities performed to prevent equipment failure.
	+ Corrective Maintenance: Maintenance activities performed to correct equipment issues.
	+ Pre Loading Checklist Tasks: Tasks performed as part of the pre-loading checklist.
* **Comments (Event)** (`comments_event`): Enter any additional comments related to the event.
* **Comments (Overall)** (`comments_overall`): Enter any general comments about the event.
* **Additional Comments** (`additional_comments`): Enter any additional information that is not covered in the other fields.
* **Pre-Loading Checklist Completion Status** (`pre_loading_checklist_completion_status`): Select one of the following:
	+ Complete: The pre-loading checklist is complete.
	+ Incomplete: The pre-loading checklist is not complete.
* **Pre-Loading Checklist Completion Date** (`pre_loading_checklist_completion_date`): Enter the date the pre-loading checklist was completed using the date format `YYYY-MM-DD`.
* **Review Date** (`review_date`): Enter the date of the next review using the date format `YYYY-MM-DD`.
* **Review Status** (`review_status`): Select one of the following:
	+ Complete: The review process is complete.
	+ Incomplete: The review process is not complete.
* **Additional Review Comments** (`additional_review_comments`): Enter any additional comments from the review.
