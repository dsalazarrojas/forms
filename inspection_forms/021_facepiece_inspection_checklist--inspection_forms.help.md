# Facepiece Inspection Checklist - Help Guide
## Purpose
The Facepiece Inspection Checklist is a form used to track the inspection and maintenance of facepieces, a critical component of a respirator or air-purifying system. This form helps ensure that all necessary checks and corrective actions are completed to maintain the facepiece's integrity and functionality.

## How To Complete This Form
1. **Select all applicable checks** from the "Equipment Checks" page.
	* Ensure you check all equipment that requires inspection, including filters, valves, and regulators.
2. **Choose corrective actions** from the "Corrective Actions" page.
	* Select all actions that need to be taken to address any issues found during the inspection.
3. **Provide comments** on the "Comments" page.
	* Add any additional information or notes about the inspection, such as any issues encountered or actions taken.
4. **Record follow-ups** on the "Follow-ups" page.
	* Select any follow-up checks that are required after the initial inspection.

## Field-by-Field Explanation

* **Equipment Checks** (`equipment_checks`, select_multiple, not required):
	+ This page lists all necessary equipment checks, such as inspecting filters, valves, and regulators.
	+ Select "Yes" for each check that applies to the facepiece.
* **Corrective Actions** (`corrective_actions`, select_multiple, not required):
	+ This page lists all necessary corrective actions, such as replacing filters or repairing valves.
	+ Select "Yes" for each action that applies to the facepiece.
* **Follow-ups** (`follow_ups`, select_multiple, not required):
	+ This page lists all follow-up checks that are required after the initial inspection.
	+ Select "Yes" for each follow-up check that applies to the facepiece.
* **Comments** (`comments`, text, not required):
	+ Add any additional information or notes about the inspection, such as any issues encountered or actions taken.
