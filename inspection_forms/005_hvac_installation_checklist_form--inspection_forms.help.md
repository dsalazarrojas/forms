# HVAC Installation Checklist Form - Help Guide
## Purpose
This form is used to collect data on the status of various aspects of HVAC installations, including general safety checks, furnace information, electrical checks, venting, cooling, and heating. It serves as a reference for quality control, compliance, or auditing purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page to ensure you understand the questions and options.
2. Select the relevant answers for each page based on your specific situation.
3. Fill out the form accordingly, taking note of any necessary explanations or comments.

## Field-by-Field Explanation

* **General** (`General`, `select_multiple`, `No`, `No`): Select 'Yes' if the installation has completed all general safety checks, and 'No' if not. This page is used to verify that all general safety checks have been performed correctly.
* **Furnace Info** (`Furnace Info`, `select_one`, `Yes`, `No`): Select 'Yes' if the furnace has been installed and functioning correctly, and 'No' if not. This page is used to confirm that the furnace is working as expected.
* **Safety Checks** (`Safety Checks`, `select_multiple`, `Yes`, `No`): Select 'Yes' for each safety check that has been performed correctly, and 'No' for each check that has not been performed correctly. This page is used to verify that all safety checks have been conducted properly.
* **Electrical Checks** (`Electrical Checks`, `select_multiple`, `Yes`, `No`): Select 'Yes' for each electrical check that has been performed correctly, and 'No' for each check that has not been performed correctly. This page is used to confirm that all electrical checks have been conducted properly.
* **Venting Info** (`Venting Info`, `select_one`, `Yes`, `No`): Select 'Yes' if the venting system is working correctly, and 'No' if not. This page is used to verify that the venting system is functioning as expected.
* **Cooling Info** (`Cooling Info`, `select_one`, `Yes`, `No`): Select 'Yes' if the cooling system is working correctly, and 'No' if not. This page is used to confirm that the cooling system is functioning as expected.
* **Heating Info** (`Heating Info`, `select_one`, `Yes`, `No`): Select 'Yes' if the heating system is working correctly, and 'No' if not. This page is used to verify that the heating system is functioning as expected.
* **Other Notes** (`Other Notes`, `note`, `No`): Provide any additional comments or notes about the installation that are not covered by the other questions. 
* **Second Page** (`Second Page`, `text`, `No`): Provide any additional comments or information that you would like to include about the installation. This is a free-text field for any notes that don't fit in the other fields above.

Note: This form is not intended to be filled out by end-users; it is a guide for those who will be filling out the form, typically those with expertise in the HVAC industry.
