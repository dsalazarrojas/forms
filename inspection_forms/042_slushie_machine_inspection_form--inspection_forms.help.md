# Slushie Machine Inspection Form - Help Guide
## Purpose
The Slushie Machine Inspection Form is designed to inspect the Slushie machine's general information, machine status, temperature, water level, potential leaks, safety gloves usage, maintenance status, and comments. This form ensures the machine's condition is accurately reported, allowing for efficient maintenance and upkeep.

## How To Complete This Form
1. Review the form carefully to understand each field's purpose and requirements.
2. Gather all necessary information and tools before starting.
3. Complete all fields accurately and thoroughly, including non-mandatory fields.
4. If unsure about any field, ask your supervisor or colleague for guidance.

## Field-by-Field Explanation

* **General Info**: Provide a brief description of the machine's current status, including any recent changes or updates.
* **Machine Status**: Select the current status of the Slushie machine:
	+ Slushie Machine On
	+ Slushie Machine Off
* **Temperature**: Enter the machine's current temperature in numbers (e.g., 25.5).
* **Water Level**: Select the current water level:
	+ High
	+ Low
	+ Normal
* **Machine Leaking**: Identify any potential leaks:
	+ Water Leaking
	+ Ice Cream Leaking
* **Safety Gloves**: Confirm if safety gloves are being used:
	+ True
	+ False
* **Machine Cleaning**: Record the date and time for the last machine cleaning:
	+ (Date Format: YYYY-MM-DD)
* **Machine Maintenance**: Select the type of maintenance performed:
	+ Oil Check
	+ Filter Check
	+ Belt Check
* **Comments**: Provide any additional comments or observations.
* **Assigned Tool**: Enter the name of any assigned tool or equipment used during the inspection.
* **Comments**: Provide any additional comments or observations regarding the machine's condition or maintenance history.

## Tips
* Complete the form accurately and thoroughly to ensure efficient maintenance and upkeep.
* Review the form carefully before submitting to avoid errors or omissions.
* Ask your supervisor or colleague if unsure about any field.
* Store the form in a secure location, as it contains sensitive information about the machine's condition.
