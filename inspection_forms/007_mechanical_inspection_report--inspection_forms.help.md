# Mechanical Inspection Report - Help Guide
## Purpose
The Mechanical Inspection Report form is used to document and report on the condition of a vehicle after an inspection. It provides a standardized way to record and communicate inspection results.

## How To Complete This Form
To complete this form, follow these steps:

* Select the vehicle information page and fill in the necessary details about the vehicle being inspected.
* Move to the vehicle condition page and rate the condition of the vehicle using the provided scale.
* Enter the inspection date and time in the correct format.
* Add any notes about the inspection in the notes field, if necessary.

## Field-by-Field Explanation
* **Vehicle Info** (`vehicle_info`, text, optional): Enter the vehicle's make, model, and any other relevant details.
* **Vehicle Condition** (`vehicle_condition`, number, optional): Rate the vehicle's condition using the provided scale (e.g., 1-10).
* **Inspection Date** (`inspection_date`, date, optional): Enter the date and time of the inspection.
* **Notes** (`notes`, note, optional): Provide any additional comments or observations about the inspection.
