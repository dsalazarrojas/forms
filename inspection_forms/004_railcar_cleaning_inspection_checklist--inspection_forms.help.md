# Railcar Cleaning Inspection Checklist - Help Guide
## Purpose
This form is used to collect information for the cleaning inspection of railcars.

## How To Complete This Form

To complete the form, follow these steps:

* Enter the title of the railcar (Train Number) in field 2.
* Enter the date of the cleaning inspection in field 3 (Cleaning Inspecton Date).
* Enter the name of the crew leader or inspector in field 4 (crew_leader_name).
* Enter the number of the train in field 5 (Train Number).
* Enter the length and width of the railcar in fields 6 and 7 (Railcar Length and Railcar Width).
* Select the correct option for the condition of the railcar (field 8: Cleaning Inspection Type).
* Select all the applicable options for the crew check (field 9: Crew Check).
* Enter any comments or observations in field 11 (Comments).
* Enter any additional notes or comments in field 12 (Notes).
* Select the options for supporting documentation, including photos, videos, and other documents (fields 13-15: Photos, Videos, and Other Documents).

## Field-by-Field Explanation

* **Railcar Number (2)**: Enter the title of the railcar to be inspected.
* **Cleaning Inspecton Date (3)**: Enter the date of the cleaning inspection.
* **Crew Leader Name (4)**: Enter the name of the crew leader or inspector conducting the inspection.
* **Train Number (5)**: Enter the number of the train.
* **Railcar Length (6)**: Enter the length of the railcar.
* **Railcar Width (7)**: Enter the width of the railcar.
* **Cleaning Inspection Type (8)**: Select the correct option for the condition of the railcar (Clean or Dirty).
* **Crew Check (9)**: Select all applicable options for the crew check.
* **Railcar Condition (10)**: Enter any comments or observations about the railcar's condition.
* **Comments (11)**: Enter any comments or notes about the inspection process.
* **Notes (12)**: Enter any additional comments or notes about the inspection.
* **Photos (13)**: Select the option if supporting photos are available.
* **Videos (14)**: Select the option if supporting videos are available.
* **Other Documents (15)**: Select the option if other supporting documents are available.

## Tips

* Make sure to fill out all fields accurately and completely.
* Enter the correct options for the crew check and inspection type.
* Use supporting documentation to aid in the inspection process.
* Review the form before submitting to ensure all fields are filled out correctly.
