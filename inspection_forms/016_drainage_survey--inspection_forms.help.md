# Drainage Survey - Help Guide
## Purpose
The "Drainage Survey" form is a tool used to assess the status and conditions of drainage systems in various settings. It helps identify issues and provide recommendations for improvement, ensuring public health and safety, and environmental sustainability.

## How To Complete This Form
To complete this form, follow these steps:

* Review each page carefully and ensure that all required fields are completed.
* Answer all questions honestly and accurately based on your observations and knowledge.
* Select the correct options for each question using the provided drop-down menu.
* Enter any relevant comments or notes in the "Drainage system inspection notes" field.
* Record the date and time of the inspection in the "Drainage system inspection date" and "Drainage system inspection time" fields.

## Field-by-Field Explanation
* **Drainage System Status** (`drainage_survey_1`, select_one, required): Select the current status of the drainage system, which can be either "Active" or "Inactive".
* **Is there a leak in the drainage system?** (`drainage_survey_2`, select_multiple, required): Check "Yes" if you have observed a leak in the drainage system, or "No" if there is no leak.
* **Is there an obstruction in the drainage system?** (`drainage_survey_3`, select_multiple, required): Check "Yes" if you have observed an obstruction in the drainage system, or "No" if there is no obstruction.
* **Current status of the drainage system** (`drainage_survey_4`, text, required): Enter a brief description of the current status of the drainage system.
* **Type of drainage system used** (`drainage_survey_5`, text, required): Enter the type of drainage system used, e.g. "Sewer", "Pipe", etc.
* **Drainage system inspection notes** (`drainage_survey_6`, note, required): Enter any relevant comments or notes about the drainage system, e.g. observations, recommendations, or concerns.
* **Drainage system inspection date** (`drainage_survey_7`, date, required): Record the date of the inspection.
* **Drainage system inspection time** (`drainage_survey_8`, time, required): Record the time of the inspection.
* **Is there any other issue with the drainage system?** (`drainage_survey_9`, select_one, required): Check "Yes" if you have observed any other issue with the drainage system, or "No" if there is no issue.
* **Any other comments about the drainage system?** (`drainage_survey_10`, text, required): Enter any other comments or concerns about the drainage system.
* **Is the drainage system properly maintained?** (`drainage_survey_11`, select_one, required): Check "Yes" if the drainage system is properly maintained, or "No" if it's not.
