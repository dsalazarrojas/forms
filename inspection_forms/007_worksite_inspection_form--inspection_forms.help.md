# worksite_inspection_form - Help Guide

## Purpose
The worksite_inspection_form is a standardized form for collecting site-related inspection data. It consists of several fields that require input to ensure a thorough and efficient inspection process.

## How To Complete This Form
To complete this form, please follow these steps:
1. Start by filling in the Site Address field, which requires a detailed description of the site's location.
2. If you have the Site ID, please input it in the Site ID field.
3. In the Site Manager field, enter the name of the person responsible for the site.
4. In the Manager Phone field, provide the contact number of the site manager.
5. If you have any additional comments or observations, use the Notes field for a brief description.

## Field-by-Field Explanation
* **Site Address** (`site_address`, text, required): Enter the full address of the site to be inspected.
* **Site ID** (`site_id`, number, optional): Enter the unique identifier for the site (if applicable).
* **Site Manager** (`site_manager`, text, required): Provide the name of the person responsible for the site.
* **Manager Phone** (`manager_phone`, text, required): Enter the contact number of the site manager.
* **Notes** (`notes`, note, optional): Enter any additional comments or observations about the site inspection.
