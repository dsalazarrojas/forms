# prophets_inspection_form - Help Guide

## Purpose
The purpose of this form is to collect information about a vehicle's condition and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the vehicle's basic information on page 1.
2. Select the applicable systems for each section.
3. Choose the vehicle's overall condition and status.

## Field-by-Field Explanation

* **Vehicle Information** (`vehicle_info`, text, optional): Enter the vehicle's make, model, and year.
* **Vehicle Engine Systems** (`engine_systems`, select_one, optional): Select the type of engine system installed in the vehicle.
* **Vehicle Transmission Systems** (`transmission_systems`, select_multiple, optional): Select all applicable transmission systems.
* **Vehicle Brake Systems** (`brake_systems`, select_multiple, optional): Select all applicable brake systems.
* **Vehicle Suspension Systems** (`suspension_systems`, select_multiple, optional): Select all applicable suspension systems.
* **Vehicle Steering Systems** (`steering_systems`, select_multiple, optional): Select all applicable steering systems.
* **Vehicle Electrical Systems** (`electrical_systems`, select_multiple, optional): Select all applicable electrical systems.
* **Vehicle Condition** (`vehicle_condition`, select_multiple, optional): Select the vehicle's overall condition.
* **Notes** (`notes`, note, optional): Enter any additional comments or notes about the vehicle.
* **Vehicle Status** (`vehicle_status`, select_one, optional): Select the vehicle's overall status.

## Tips

* Make sure to select all applicable systems for each section.
* Use the notes field to provide more detailed information about the vehicle.
* Choose the vehicle's condition and status accurately based on the inspection results.
