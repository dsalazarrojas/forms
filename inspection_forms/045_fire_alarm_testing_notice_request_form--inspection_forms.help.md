# Fire Alarm Testing Notice Request Form - Help Guide
## Purpose
The Fire Alarm Testing Notice Request Form is used to request testing services for fire alarm systems in your property. Please use this form to provide essential information for scheduling and performing fire alarm system testing.

## How To Complete This Form
1. Fill out the form accurately and thoroughly, providing all required information.
2. Review each field carefully before submitting.
3. Ensure all required fields are completed before proceeding to the next page.

## Field-by-Field Explanation
- **Name** (`Name`, required/True): Enter the name of the person or entity requesting the testing service.
- **Contact** (`Contact`, required/True): Enter the contact name and information for the person responsible for the property or facility.
- **Email** (`Email`, required/True): Enter the email address for the contact person, which will be used for communication and confirmation.
- **Phone** (`Phone`, required/True): Enter the phone number for the contact person, which will be used for scheduling and confirmation purposes.
- **Property Address** (`Property Address`, required/True): Enter the property address where the fire alarm system will be tested.
- **Fire Alarm System** (`Fire Alarm System`, required/True): Enter a brief description of the fire alarm system, including any specific features or components.
- **Testing Date** (`Testing Date`, required/True): Select the date for the testing service, which will be used to schedule the testing appointment.
- **Testing Time** (`Testing Time`, required/True): Select the time for the testing service, which will be used to schedule the testing appointment.
- **Duration** (`Duration`, required/True): Enter the estimated duration of the testing service.
- **Confirm** (`Confirm`, required/True): Select one of the options to confirm the testing date, time, or duration.
- **Comments** (`Comments`, required/False): Enter any additional comments or notes about the property or fire alarm system.
- **Submit** (`Submit`, required/False): This is the final step to submit the request for testing services. Ensure all required fields are completed before proceeding.
