# Energy Sector Environmental Compliance Audit Form - Help Guide
## Purpose
This form is designed to assess and document an energy sector facility's compliance status with environmental regulations and guidelines.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct facility location from the list of options.
2. Enter the facility's name in the text field provided.
3. Choose the correct sector from the list of options.
4. Select the correct audit date from the calendar.
5. Specify the audit time in the format HH:MM AM/PM.
6. Identify the facility type from the list of options.
7. Select the correct environmental compliance level from the list of options.
8. Provide comments on the audit process, if any.
9. Enter any additional notes or observations about the facility's status.
10. Specify the output file name and file path, if desired.
11. Confirm the facility's status from the list of options.
12. Enter the name of the assigned user, if applicable.

## Field-by-Field Explanation

* **Facility Location** (`facility_location`, text, required/optional): Enter the physical location of the facility.
* **Facility Name** (`facility_name`, text, required/optional): Enter the name of the facility being audited.
* **Sector** (`sector`, select_one, required): Choose the sector in which the facility operates (e.g., Oil and Gas, Renewable Energy, etc.).
* **Audit Date** (`audit_date`, date, required/optional): Select the date of the audit, following the calendar format.
* **Audit Time** (`audit_time`, time, required/optional): Enter the time of the audit in the format HH:MM AM/PM.
* **Facility Type** (`facility_type`, select_multiple, required): Choose the type of facility from the list of options.
* **Environmental Compliance Level** (`environmental_compliancy_level`, select_one, required): Select the level of compliance with environmental regulations.
* **Comments** (`comments`, text, required/optional): Provide any relevant comments on the audit process.
* **Notes** (`notes`, text, required/optional): Enter any additional notes or observations about the facility's status.
* **Output File** (`output_file`, text, required/optional): Specify the name and location of the file to be generated from the audit data.
* **Facility Status** (`facility_status`, select_one, required): Confirm the facility's status from the list of options.
* **Assigned User** (`assigned_user`, text, required/optional): Enter the name of the user assigned to the facility, if applicable.
