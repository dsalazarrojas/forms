# Key Fob Battery Check Form - Help Guide
## Purpose
The "Key Fob Battery Check Form" is used to inspect and document the condition and status of a vehicle's key fob batteries.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the options for "Key Fob Batteries" on Page 1 of the form. Select whether the batteries are:
	* Yes: The batteries are functioning correctly.
	* No: The batteries are not functioning correctly.
2. On Page 2, select the type of vehicle that the key fob is intended for:
	* Car
	* Truck
	* Van
	* Bus
3. Determine the battery capacity of the key fob:
	* 12
	* 36
	* 48
	* 96
4. Select the type of battery:
	* Standard
	* Extended
5. Assess the condition of the batteries:
	* Normal
	* Bad
6. For "Follow Up Recommendations", select the preferred method of follow-up:
	* Call
	* Email
	* Letter
	* None
7. In the "Comments" field, enter any additional information about the inspection, such as any issues found or actions taken.
8. On Page 9, select any actions taken to address the battery condition:
	* Replace
	* Refill
	* Inspect
	* None
9. For "Follow Up Actions Taken", select the method of follow-up for any actions taken:
	* Call
	* Email
	* Letter
	* None

## Field-by-Field Explanation

* **Key Fob Batteries**: (`key_fob_batteries`, select_multiple, required: false)
	+ This field asks you to indicate whether the key fob batteries are functioning correctly or not.
* **Vehicle Type**: (`vehicle_type`, select_one, required: false)
	+ This field asks you to select the type of vehicle that the key fob is intended for (e.g. Car, Truck, Van, Bus).
* **Battery Capacity**: (`battery_capacity`, select_multiple, required: false)
	+ This field asks you to select the battery capacity of the key fob (e.g. 12, 36, 48, 96).
* **Battery Type**: (`battery_type`, select_one, required: false)
	+ This field asks you to select the type of battery used in the key fob (e.g. Standard, Extended).
* **Condition Of Batteries**: (`condition_of_batteries`, select_multiple, required: false)
	+ This field asks you to assess the condition of the key fob batteries (e.g. Normal, Bad).
* **Follow Up Recommendations**: (`follow_up_recommendations`, select_multiple, required: false)
	+ This field asks you to select the method of follow-up for any issues found with the batteries.
* **Results**: (`results`, note, required: false)
	+ This field is for entering any results or notes about the inspection.
* **Comments**: (`comments`, text, required: false)
	+ This field is for entering any additional comments or information about the inspection.
* **Actions Taken**: (`actions_taken`, select_multiple, required: false)
	+ This field asks you to select any actions taken to address the battery condition (e.g. Replace, Refill, Inspect).
* **Follow Up Actions Taken**: (`follow_up_actions_taken`, select_multiple, required: false)
	+ This field asks you to select the method of follow-up for any actions taken.
