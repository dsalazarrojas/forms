# Property Inspection Scheduling Form - Help Guide
## Purpose
The Property Inspection Scheduling Form is used to schedule property inspections for active properties.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Property ID of the property you wish to schedule an inspection for.
2. Enter the Property Inspection Date and Scheduled Time for the inspection.
3. Select whether the inspection team member is available for the inspection (if applicable).
4. Enter any additional notes or comments regarding the inspection.
5. Select the Property Status and Property Status Update for the property.
6. Enter the contact information for the property (name, email, and phone number).

	+ A date field where you can select the date of the inspection.

## Tips
* Make sure to fill out all required fields before submitting the form.
* Double-check the scheduled date and time to ensure they align with the inspection team's availability.
* If the inspection is not applicable for a particular property, select 'No' for the inspection team member fields.
* If there are any issues or questions regarding the form, please contact the property management team.
