# Fire Safety Equipment Test Request Form - Help Guide
## Purpose
The Fire Safety Equipment Test Request Form is used to request a fire safety equipment test. It gathers information about the equipment to be tested, including the type of test, date, and time of the test, as well as contact details of the person requesting the test.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a unique Test Request ID to identify the request.
2. Select the Date for the test from the calendar.
3. Enter the Time for the test.
4. Choose the Test Type from the list of options (Alarms, Sprinklers, or Extinguishers).
5. Enter any relevant information about the Equipment to be tested.
6. Enter the name of the Contact Person who requested the test.
7. Enter the Contact Email of the person requesting the test.
8. Enter the Contact Phone Number of the person requesting the test.
9. Provide a brief description of the Report Details.
10. Select the Report Date from the calendar.

## Field-by-Field Explanation
* **Test Request ID**: Enter a unique identifier for this test request. This will help us track your request.
* **Date**: Select the date on which the test is scheduled to take place.
* **Time**: Enter the time of the test.
* **Test Type**: Choose the type of test you need to perform on the equipment (Alarms, Sprinklers, or Extinguishers).
* **Equipment**: Enter any relevant information about the equipment to be tested.
* **Contact Name**: Enter the name of the person requesting the test.
* **Email**: Enter the email address of the person requesting the test.
* **Phone**: Enter the phone number of the person requesting the test.
* **Address**: You can optionally enter the address of the person requesting the test.
* **Report Details**: Enter a brief description of the test results and any issues found.
* **Report Date**: Select the date the test results will be available.

## Tips
* Make sure to provide accurate and complete information to ensure that the test is properly scheduled and executed.
* If you have any special requests or requirements for the test, please include them in the Report Details field.
