# hvac_commissioning_checklist - Help Guide
## Purpose
The HVAC Commissioning Checklist is a tool for documenting and tracking the commissioning process of HVAC systems. It ensures that all relevant details are captured and that systems are properly tested and certified to function correctly.

## How To Complete This Form
1. Select the "System Testing" page and enter a brief description of the system being commissioned.
2. Enter the details of the commissioning process, including any testing equipment used.
3. Update the "Commissioning Status" field to indicate whether the system is active or inactive.
4. Add any additional details or comments as necessary in the "Commissioning Comments" field.
5. Review the form for completeness and accuracy before submitting.

## Field-by-Field Explanation
* **System Description** (`system_description`, `text`, required: false): Enter a brief description of the system being commissioned.
* **Commissioning Process** (`commissioning_process`, `text`, required: false): Enter the details of the commissioning process, including any testing equipment used.
* **Commissioning Status** (`commissioning_status`, `select_one`, required: false): Select whether the system is active or inactive.
* **Testing Equipment** (`testing_equipment`, `text`, required: false): Enter any testing equipment used during the commissioning process.
* **Testing Results** (`testing_results`, `text`, required: false): Enter any testing results or observations from the commissioning process.
* **Certification Documents** (`certification_documents`, `text`, required: false): Enter any relevant certification documents or paperwork required for commissioning.
* **System Performance** (`system_performance`, `text`, required: false): Enter any details about the system's performance during the commissioning process.
* **System Acceptance** (`system_acceptance`, `text`, required: false): Enter any details about system acceptance, such as any issues or concerns.
* **Certification** (`certification`, `text`, required: false): Enter any relevant certification information, such as dates or serial numbers.
* **Commissioning Comments** (`commissioning_comments`, `text`, required: false): Enter any additional comments or details about the commissioning process.
* **Notes** (`notes`, `note`, required: false): Enter any miscellaneous notes or comments about the system or commissioning process.

## Tips
* Ensure that each system is only commissioned once to avoid duplication.
* Update existing entries instead of creating new ones if a system has been previously commissioned.
* Review the form carefully before submitting to ensure accuracy and completeness.
