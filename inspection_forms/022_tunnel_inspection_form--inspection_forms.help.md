# Tunnel Inspection Form - Help Guide
## Purpose
The Tunnel Inspection Form is designed to collect information about the condition of tunnels. This form is intended for tunnel inspectors and maintenance personnel to report their findings and observations.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the current status of the tunnel from the options provided in the "Tunnel Status" field.
2. In the "Comments" field, type any relevant comments or observations you have about the tunnel's condition.
3. Ensure that you complete the form as accurately and thoroughly as possible, as this information will help in assessing and maintaining the tunnel's condition.

## Field-by-Field Explanation

* **Tunnel Status** (`tunnel_status`, select_one, required: false): Select the current status of the tunnel from the available options.
* **Comments** (`inspection_comments`, text, required: false): Type any comments or observations you have about the tunnel's condition. This field is optional but provides valuable context for the inspection report.
* **Tunnel Inspection** (`tunnel_inspection_form`, note, required: false): This is a note field for providing any additional information or comments about the tunnel inspection. It is optional but can be used to store any notes or observations that are not captured in the "Comments" field.
