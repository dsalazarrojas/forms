# Defect Type Selection Survey - Help Guide
## Purpose
The Defect Type Selection Survey is a form used to collect information about defects that need to be addressed. This form is not meant to be used for emergency or high-priority defects. It is intended for regular defect tracking and selection of defect types for further analysis and action.

## How To Complete This Form
To complete this form, follow these steps:

* Select the defect type from the dropdown menus.
* Optionally, provide a description of the defect in the Defect Description field.
* Optionally, specify the location where the defect is or was found in the Defect Location field.
* Optionally, select the date the defect occurred or will occur in the Defect Date field.
* If the defect is recurring, select all applicable defect recurring patterns in the Defect Recurring Patterns field.
* If the defect is frequent, select all applicable defect frequency options in the Defect Frequency field.
* Select the current status of the defect in the Defect Status field.
* If necessary, select a high or low priority for the defect in the Defect Priority field.
* If necessary, select all applicable defect categories and subcategories in the Defect Category and Defect Subcategory fields.
* Finally, select the department that the defect belongs to in the Defect Department field and the location where the defect is or was found in the Defect Location field.

## Field-by-Field Explanation
* **Introduction** (Optional): This field is a note field where you can add any additional information about the defect.
* **Defect Type** (Required): Select the type of defect from the dropdown menu.
* **Defect Description** (Optional): This field is for providing additional details about the defect.
* **Defect Location** (Optional): Provide the location where the defect is or was found.
* **Defect Date** (Optional): Select the date the defect occurred or will occur.
* **Defect Recurring Patterns** (Optional): Select all applicable defect recurring patterns.
* **Defect Frequency** (Optional): Select all applicable defect frequency options.
* **Defect Status** (Required): Select the current status of the defect.
* **Defect Priority** (Optional): Select a high or low priority for the defect.
* **Defect Category** (Optional): Select all applicable defect categories.
* **Defect Subcategory** (Optional): Select all applicable defect subcategories.
* **Defect Department** (Optional): Select the department that the defect belongs to.
* **Defect Location** (Optional): Provide the location where the defect is or was found.

* Please only select all applicable fields that apply to your defect type.
