# Inspection Checklist Submission Acknowledgement Form - Help Guide
## Purpose
This form is intended for use by inspectors to acknowledge the completion of inspections, providing information about the submitter and inspector involved, as well as details about the inspection itself. It aims to collect relevant data for administrative and auditing purposes, ensuring that all necessary steps are taken care of inspection completion.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the submitter's company from the list.
2. Choose whether the submitter has a job title, and if so, select from the given options or type in your own title.
3. Choose the submitter's department from the list.
4. Select the submitter's job function from the list.
5. Provide any comments or additional information from the submitter.
6. Select the inspector's organisation from the list.
7. Choose the inspector's function from the list.
8. Provide any comments or additional information from the inspector.
9. Enter the inspection date and time.
10. Select the inspection location.
11. Choose the inspection type from the list, and if necessary, type in a custom description.
12. Provide any additional notes about the inspection.

## Field-by-Field Explanation

* **Submitter Information (1)** (`text`, required/optional): Enter the submitter's name and other relevant details. Please note that this field is not actually visible in the form as per the provided YAML.
* **Submitter Company (3)** (`select_multiple`, required): Select the submitter's company from the list.
* **Submitter Job Title (4)** (`select_one`, required): Choose whether the submitter has a job title, and if so, select from the given options or type in your own title.
* **Submitter Job Title Other (5)** (`text`, required/optional): If the submitter has a job title other than the given options, type it in here.
* **Submitter Department (6)** (`select_multiple`, required): Select the submitter's department from the list.
* **Submitter Job Function (7)** (`select_multiple`, required): Select the submitter's job function from the list.
* **Inspector Information (11)** (`text`, required/optional): Enter the inspector's name and other relevant details.
* **Inspector Information (12)** (`time`, required/optional): Enter the time of the inspection, or leave blank if not applicable.
* **Inspector Organisation (13)** (`select_multiple`, required): Select the inspector's organisation from the list.
* **Inspector Function (14)** (`select_multiple`, required): Choose the inspector's function from the list.
* **Inspector Comments (15)** (`text`, required/optional): Provide any comments or additional information from the inspector.
* **Inspector Comments Other (16)** (`text`, required/optional): If necessary, provide additional comments from the inspector.
* **Inspection Date/Time (18)** (`date`, required/optional): Enter the inspection date and time, or leave blank if not applicable.
* **Inspection Location (19)** (`text`, required): Enter the inspection location.
* **Inspection Type (20)** (`select_multiple`, required): Select the inspection type from the list, and if necessary, type in a custom description.
* **Inspection Type Other (21)** (`text`, required/optional): If the inspection type is other than the given options, type it in here.
* **Inspection Type Other Description (22)** (`text`, required/optional): If the inspection type is other than the given options, provide a description.
* **Inspection Notes (23)** (`text`, required/optional): Provide any additional notes about the inspection.
* **Inspection Notes Other (24)** (`text`, required/optional): If necessary, provide additional notes about the inspection.
* **Inspection Notes Other Description (25)** (`text`, required/optional): If the inspection notes are other than the given options, provide a description.
