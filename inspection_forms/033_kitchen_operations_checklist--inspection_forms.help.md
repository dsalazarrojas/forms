# Kitchen Operations Checklist - Help Guide
## Purpose
The Kitchen Operations Checklist is a form used by kitchen staff to report the status of kitchen operations. The form is designed to ensure all necessary information is recorded to monitor and improve kitchen operations.

## How To Complete This Form
To complete this form, please review each field carefully and select the correct options. The form consists of several fields, each with its own set of options. If a field is marked as "required", please ensure it is filled out. If you are unsure about any field, please refer to the field-by-field explanations below.

## Field-by-Field Explanation

### 1. **All Tools Available** (required: true)
All tools available: Check if all tools are available for use.
*   Select "All tools are available" if all tools are in good working condition and ready for use.
*   Select "Some tools are not available" if some tools are missing or not functioning properly.
*   Select "Tools not known" if the kitchen staff is unsure about the availability of tools.

### 2. **Kitchen Staff** (required: false)
Kitchen staff: Check the status of kitchen staff.
*   Select "Head Chef" if the head chef is on duty.
*   Select "Kitchen Manager" if the kitchen manager is on duty.
*   Select "Line Cook" if a line cook is on duty.

### 3. **Equipment Cleaned** (required: true)
Equipment cleaned: Check the cleanliness status of kitchen equipment.
*   Select "Cleaned" if all equipment is clean and ready for use.
*   Select "Not Cleaned" if some equipment is not clean.
*   Select "Unknown" if the kitchen staff is unsure about the cleanliness of equipment.

### 4. **Kitchen Closed** (required: false)
Kitchen closed: Check if the kitchen is closed for the day.
*   Select a time if the kitchen is closed.
*   Leave blank if the kitchen is not closed.

### 5. **Kitchen Opened** (required: false)
Kitchen opened: Check if the kitchen is opened for the day.
*   Select a time if the kitchen is opened.
*   Leave blank if the kitchen is not opened.

### 6. **Kitchen Closed Time** (required: false)
Kitchen closed time: If the kitchen is closed, select the time it was closed.
*   Enter the time the kitchen was closed.

### 7. **Kitchen Opened Time** (required: false)
Kitchen opened time: If the kitchen is opened, select the time it was opened.
*   Enter the time the kitchen was opened.

### 8. **Tools Damaged** (required: false)
Tools damaged: Check if any tools are damaged.
*   Select "Yes" if any tools are damaged.
*   Select "No" if all tools are in good condition.

### 9. **Tools Malfunctioning** (required: false)
Tools malfunctioning: Check if any tools are not functioning properly.
*   Select "Yes" if any tools are not functioning properly.
*   Select "No" if all tools are functioning properly.
