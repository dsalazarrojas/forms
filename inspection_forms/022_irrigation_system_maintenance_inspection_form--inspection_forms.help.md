# irrigation_system_maintenance_inspection_form - Help Guide
## Purpose

This form is used to track and report the maintenance status of irrigation systems, including the current status of maintenance activities, equipment availability, and upcoming schedule for the next maintenance.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Fill out the **maintenance_section** field with a brief description of the current maintenance activities or issues that are being addressed.
2.  Select the **maintenance_status** field with one of the following options:
    *   **Not started**: If the maintenance activity is yet to begin.
    *   **In Progress**: If the maintenance activity is currently underway.
    *   **Completed**: If the maintenance activity has been completed.
3.  Check the **equipment_status** field to report the status of the equipment in the irrigation system:
    *   **Not available**: If the equipment is not currently available for use.
    *   **Available**: If the equipment is available and functioning properly.
    *   **Not functioning**: If the equipment is not currently functioning.
    *   **Functioning**: If the equipment is functioning properly.
4.  Enter the next **schedule_next** date for the maintenance activity using the date picker field.
5.  If there are any additional comments or details related to the maintenance activity, enter them in the **notes** field.
6.  Finally, enter your **email** address and **phone** number for contact purposes (optional).

## Field-by-Field Explanation

*   **maintenance_section**: A text field where you can enter a brief description of the current maintenance activities or issues being addressed.
*   **maintenance_status**: A field with three options to report the status of the maintenance activity. Please select one of the options based on the current status.
*   **equipment_status**: A field with four options to report the status of the equipment in the irrigation system. Please select all applicable options based on the current status.
*   **schedule_next**: A date field where you can enter the next scheduled date for the maintenance activity using the date picker tool.
*   **notes**: A text field where you can enter any additional comments or details related to the maintenance activity.
*   **email**: A field where you can enter your email address for contact purposes.
*   **phone**: A field where you can enter your phone number for contact purposes (optional).

## Tips

*   Please make sure to fill out all required fields before submitting the form.
*   Double-check your responses to ensure accuracy and completeness.
*   Use the date picker tool to select the correct date for the next scheduled maintenance activity.
*   If you need to report multiple equipment statuses, you can select multiple options in the **equipment_status** field.
