# Work Method Statement Form - Help Guide
## Purpose
The Work Method Statement Form is a document used to record the detailed description of the work method to be followed during a task or project, including hazards identified and controls implemented to mitigate them, as well as the roles and responsibilities of supervisors and reviewers.

## How To Complete This Form
1. Review the task or project details and site-specific safety procedures to ensure this form is relevant and not duplicating information already available.
2. Fill out the form by providing the following information:
	* **Work Method Statement**: Describe the step-by-step process to be followed during the task or project.
	* **Contractor Information**: Enter the name, title, and company of the contractor performing the work.
	* **Task Name**: Enter the name of the task or project.
	* **Task Description**: Provide a brief description of the task or project.
	* **Hazards Identified**: List any hazards identified during the task or project.
	* **Hazard Statement**: Describe the hazards identified.
	* **Controls Mitigated**: List any controls implemented to mitigate the hazards.
	* **Control Statement**: Describe the controls implemented.
	* **Supervisor Name**: Enter the name of the supervisor responsible for the task or project.
	* **Reviewer's Signature**: Sign and date the form to indicate approval.
	* **Reviewer's Name**: Enter the name and title of the reviewer.
	* **Reviewer's Company**: Enter the name of the reviewer's company.

## Field-by-Field Explanation
* **Work Method Statement (1)**: A detailed description of the step-by-step process to be followed during the task or project.
* **Contractor Information (2)**: Enter the name, title, and company of the contractor performing the work.
* **Task Name (3)**: Enter the name of the task or project.
* **Task Description (4)**: A brief description of the task or project.
* **Hazards Identified (5)**: List any hazards identified during the task or project.
* **Hazard Statement (6)**: Describe the hazards identified.
* **Controls Mitigated (7)**: List any controls implemented to mitigate the hazards.
* **Control Statement (8)**: Describe the controls implemented.
* **Supervisor Name (9)**: Enter the name of the supervisor responsible for the task or project.
* **Reviewer's Signature (10)**: Sign and date the form to indicate approval.
* **Reviewer's Name (11)**: Enter the name and title of the reviewer.
* **Reviewer's Company (13)**: Enter the name of the reviewer's company.

## Tips
* Make sure to review and update this form regularly to reflect any changes in the task or project details.
* Ensure that the form is completed accurately and thoroughly, as it is a critical document for maintaining a safe and healthy work environment.
* If you are unsure about any information or have questions, please seek guidance from a supervisor or reviewer.
