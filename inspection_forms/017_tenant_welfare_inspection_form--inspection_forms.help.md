# Tenant Welfare Inspection Form - Help Guide
## Purpose
This form is used to record and track the welfare and conditions of rental properties during regular inspections. It helps property management teams ensure that properties are well-maintained and address any issues promptly.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the relevant options for each field, using the following fields as guidance.
2. Ensure that all required fields are completed, as indicated by the asterisk (\*) symbol.
3. Enter the required information accurately and thoroughly.

## Field-by-Field Explanation

* **Rental Unit Conditions** (`tenant_welfare_inspection_form_page_1`, select_multiple):
	+ Select one or multiple options from the list to indicate the overall condition of the rental unit.
* **Tenant Welfare Visits** (tenant_welfare_visits, number):
	+ Enter the number of welfare visits made during the inspection.
* **Date of Last Inspection** (date_of_last_inspection, date):
	+ Enter the date of the last inspection conducted.
* **Findings** (findings, text):
	+ Describe any notable findings or issues observed during the inspection.
* **Action Planned** (action_planned, select_one):
	+ Select whether an action is planned or not.
* **Comments** (comments, text):
	+ Add any additional comments or notes about the inspection.
* **Next Inspection Date** (next_inspection_date, date):
	+ Enter the date of the next scheduled inspection.
* **Completed** (completed, text):
	+ Add any relevant information about the inspection's completion.
* **Follow-up Actions** (follow_up_actions, text):
	+ List any follow-up actions or tasks assigned to maintenance teams.
* **Follow-up Date** (follow_up_date, date):
	+ Enter the date of the next follow-up inspection.
* **Follow-up Status** (follow_up_status, select_one):
	+ Select the status of the follow-up actions (Active or Inactive).
* **Next Follow-up Date** (next_follow_up_date, date):
	+ Enter the date of the next follow-up inspection.
* **Next Follow-up Status** (next_follow_up_status, select_one):
	+ Select the status of the next follow-up actions (Active or Inactive).
* **Follow-up Comments** (follow_up_comments, text):
	+ Add any comments or notes about the follow-up inspection.
* **Follow-up Completed** (follow_up_completed, text):
	+ Indicate whether the follow-up inspection is complete.
* **Follow-up Comments 2** (follow_up_comments2, text):
	+ Add any additional comments or notes about the follow-up inspection.
* **Follow-up Status Comments** (follow_up_status_comments, text):
	+ Add any comments or notes about the follow-up status.
* **Tenant ID** (tenant_id, select_one):
	+ Select whether the tenant is identified as a high-risk or low-risk tenant.
* **Property ID** (property_id, text):
	+ Enter any relevant property identification information.
* **Completed By** (completed_by, text):
	+ Identify the person completing the form.
* **Date Completed** (date_completed, date):
	+ Enter the date the form was completed.
* **Comments 3** (comments3, text):
	+ Add any additional comments or notes.
* **Next Visit Status** (next_visit_status, select_one):
	+ Select the status of the next visit (Active or Inactive).
* **Next Visit Comments** (next_visit_comments, text):
	+ Add any comments or notes about the next visit.

Note: Fields may have different requirements based on the selected options and other fields. Always ensure that all required fields are completed and that information is accurate and complete.
