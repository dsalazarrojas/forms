# Shop Drawing Review Form - Help Guide
## Purpose
The Shop Drawing Review Form is used to gather information from reviewers to review and provide feedback on shop drawings.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the "Submit" button to start the form.
* Select the reviewer's identity from the "Reviewer Name" dropdown menu.
* Enter the reviewer's email address in the "Reviewer Email" field.
* Enter the reviewer's phone number in the "Reviewer Phone" field.
* Select the current project status from the "Project Status" dropdown menu.
* Select the project type from the "Project Type" dropdown menu.
* Enter any additional comments in the "Reviewer Comments" field.
* Provide your signature in the "Architect's Signature" field (only if you are an architect).

## Field-by-Field Explanation
* **Shop Drawing Review Form** (Page 1): This is the title of the form.
* **Reviewer Name** (id: 2, Select One, Required: False): Select the reviewer's name from the dropdown menu (Architects, Contractors, Project Managers).
* **Reviewer Email** (id: 3, Email, Required: False): Enter the reviewer's email address.
* **Reviewer Phone** (id: 4, Text, Required: False): Enter the reviewer's phone number.
* **Project Status** (id: 5, Select One, Required: False): Select the project status (In Progress, Done, Not Started).
* **Project Type** (id: 6, Select One, Required: False): Select the project type (Structural, Mechanical, Electrical).
* **Reviewer Comments** (id: 7, Note, Required: False): Enter any additional comments about the project.
* **Architect's Signature** (id: 8, Date, Required: False): Provide your signature as an architect.
* **Architect's Signature** (id: 8, Date, Required: False): Only architects are required to provide their signature.
 
Note: The required fields are marked as "Required: False" which means they are not mandatory to complete the form. However, providing accurate and complete information will help ensure that the reviewer's comments and feedback are taken seriously.
