# Excavation Safety Checklist - Help Guide
## Purpose
This form is used to assess the safety of an excavation site before starting or continuing with excavation work. It checks for various safety protocols such as trench safety barriers, personal protective equipment, clearance around excavated areas, and site access control measures.

## How To Complete This Form
To complete this form, please select "Yes" or "No" to answer the questions, or enter a number or a text as required for each field. Make sure to answer carefully to ensure that all necessary safety protocols are met.

## Field-by-Field Explanation
* **1. Excavation Safety Checklist** (`excavation_safety_checklist`, text, optional): Enter a brief description of the safety measures taken for the excavation site.
* **2. Trench Safety Barrier** (`trench_safety_barrier`, select_one, optional): Check if a trench safety barrier is present to prevent accidents.
*   * If "Yes", indicate that a trench safety barrier is in place.
*   * If "No", indicate that no barrier is present or specify why not.
* **3. Personal Protective Equipment** (`personal_protective_equipment`, select_multiple, optional): Check if all necessary personal protective equipment is available and being used.
*   * If "Yes", indicate that all necessary equipment is present and being used.
*   * If "No", specify which equipment is missing or not being used.
* **4. Excavated Area Clearance** (`excavated_area_clearance`, number, optional): Enter the clearance around the excavated area, measured in meters.
*   * Enter the distance around the excavated area that is clear from obstacles.
* **5. Trench Depth** (`trench_depth`, number, optional): Enter the depth of the trench, measured in meters.
*   * Enter the depth of the trench.
* **6. Safety Hatch Protection** (`safety_hatch_protection`, date, optional): Enter the date when the safety hatch was last inspected or updated.
*   * Enter the date when the safety hatch was last inspected or updated, or indicate if it has never been inspected.
* **7. Trench Barricading Materials** (`trench_barricading_materials`, select_one, optional): Check if the trench is barricaded with the required materials.
*   * If "Yes", indicate that the trench is barricaded with the required materials.
*   * If "No", indicate that the trench is not barricaded or specify why not.
* **8. Trench Barricade Height** (`trench_barricade_height`, number, optional): Enter the height of the barricade, measured in meters.
*   * Enter the height of the barricade.
* **9. Trench Barricade Type** (`trench_barricade_type`, select_one, optional): Check if the trench is barricaded with the required type of material.
*   * If "Yes", indicate that the trench is barricaded with the required type of material.
*   * If "No", indicate that the trench is not barricaded or specify why not.
* **10. Trench Barricade Material** (`trench_barricade_material`, select_one, optional): Check if the trench is barricaded with the required material.
*   * If "Yes", indicate that the trench is barricaded with the required material.
*   * If "No", indicate that the trench is not barricaded or specify why not.
* **11. Trench Barricade Depth** (`trench_barricade_depth`, number, optional): Enter the depth of the barricade, measured in meters.
*   * Enter the depth of the barricade.
* **12. Site Access Control** (`site_access_control`, select_one, optional): Check if site access control measures are in place.
*   * If "Yes", indicate that site access control measures are in place.
*   * If "No", indicate that site access control measures are not in place or specify why not.
* **13. Site Access Control Description** (`site_access_control_description`, text, optional): Provide a brief description of the site access control measures.
*   * Enter a brief description of the site access control measures taken.
* **14. Site Access Control Location** (`site_access_control_location`, text, optional): Enter the location where site access control measures are implemented.
*   * Enter the location where site access control measures are implemented.

Note: This form requires careful completion to ensure that all necessary safety protocols are met before starting or continuing with excavation work.
