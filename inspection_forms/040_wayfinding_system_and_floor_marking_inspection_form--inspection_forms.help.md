# Wayfinding System And Floor Marking Inspection Form - Help Guide
## Purpose
This form is designed to collect information about the wayfinding system and floor marking in a building or facility. It's intended to help you inspect and verify the wayfinding system and floor marking to ensure compliance with relevant standards and regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields with accurate and truthful information.
2. Ensure that you have access to the relevant documents and information about the building or facility before starting the inspection.
3. Be thorough in your inspection and provide detailed comments and explanations for each field.

## Field-by-Field Explanation
### 1. **Wayfinding System Name** (required)
	* Enter the name of the wayfinding system you are inspecting.
	* Ensure that it is accurate and up-to-date.

### 2. **Building Name** (required)
	* Enter the name of the building or facility being inspected.
	* This field is used to identify the location of the inspection.

### 3. **Floor Number** (required)
	* Enter the floor number you are inspecting.
	* Ensure that it is accurate and up-to-date.

### 4. **Wayfinding System Type** (required)
	* Select the type of wayfinding system used in the building or facility.
	* Choose from the available options: Option 1, Option 2, Option 3.

### 5. **Floor Marking Type** (required)
	* Select the type of floor marking used in the building or facility.
	* Choose from the available options: Option 1, Option 2, Option 3.

### 6. **Wayfinding System Color** (required)
	* Select the color(s) of the wayfinding system used in the building or facility.
	* Choose multiple options from: Option 1, Option 2, Option 3.

### 7. **Floor Marking Color** (required)
	* Select the color(s) of the floor marking used in the building or facility.
	* Choose multiple options from: Option 1, Option 2, Option 3.

### 8. **Additional Comments** (optional)
	* Provide any additional comments or observations about the wayfinding system and floor marking.
	* This field is not required but can be helpful for further clarification.

### 9. **Inspector Email** (required)
	* Enter your contact email address.
	* Ensure that it is accurate and up-to-date.

### 10. **Inspector Phone** (required)

### 14. **Building Inspector Name** (required)
