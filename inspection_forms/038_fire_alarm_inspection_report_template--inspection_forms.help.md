# Fire Alarm Inspection Report Template - Help Guide
## Purpose
The Fire Alarm Inspection Report Template is used to document the inspection of fire alarm systems in a building or facility. The form helps identify any issues or non-compliances and guides the necessary actions to correct them.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing the system description and type.
2. Enter the alarm status, indicating whether the system is active or inactive.
3. Specify the panel type and panel location.
4. Choose the zone status and describe the zone status.
5. Enter the system inspected date and time.
6. Provide the system inspected by field for the person performing the inspection.
7. Enter the system inspection timestamp.
8. Check if the system has been repaired and who performed the repair.
9. Enter the system repair timestamp.
10. Add any additional comments.
11. Select the system status (Active or Inactive) and provide a description.
12. Enter the system inspection date and the panel inspection date.
13. Add any system inspection notes.
14. Enter the system repaired notes (if applicable).

## Field-by-Field Explanation

* **system_description**: A brief description of the fire alarm system.
* **alarm_status**: Choose "Active" if the system is currently functioning correctly, "Inactive" if it's not.
* **panel_type**: Select the type of panel being inspected.
* **panel_location**: Enter the location of the panel being inspected.
* **zone_status**: Choose "Active" if the zone is currently functioning correctly, "Inactive" if it's not.
* **zone_status_description**: Provide a description of the zone status.
* **system_inspected**: Enter the date the system was inspected.
* **system_inspected_by**: Enter the name of the person performing the inspection.
* **system_inspected_timestamp**: Enter the timestamp of the inspection.
* **system_repaired**: Check if the system has been repaired.
* **system_repaired_by**: Enter the name of the person who performed the repair.
* **system_repaired_timestamp**: Enter the timestamp of the repair.
* **system_status_description**: Provide a description of the system status (Active or Inactive).
* **system_status_description_2**: Enter any additional description for the system status.
* **inspection_date**: Enter the inspection date.
* **system_status**: Select the status of the system (Active or Inactive).
* **panel_inspection_date**: Enter the date of the panel inspection.
* **system_inspection_date**: Enter the date of the system inspection.
* **system_inspection_notes**: Enter any notes about the inspection.
* **system_repaired_notes**: Enter any notes about the repair.
* **fire_alarm_system**: Enter any additional information about the fire alarm system.
* **system_type**: Enter the type of system being inspected.
* **system_description_1**: Enter any additional description of the system.
* **additional_comments**: Enter any additional comments or observations about the system.
