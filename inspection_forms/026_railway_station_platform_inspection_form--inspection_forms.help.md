# Railway Station Platform Inspection Form - Help Guide
## Purpose
The Railway Station Platform Inspection Form is used to collect data on the condition, safety, and status of a railway station platform. This form helps ensure that the platform is properly maintained and meets the required standards.

## How To Complete This Form
1. Review the form carefully before starting the inspection.
2. Complete each field accurately and thoroughly.
3. Use the options provided for each field to choose the correct response.
4. Make sure to include any additional comments or notes as needed.
5. Submit the form once completed.

## Field-by-Field Explanation
* **Platform Condition** (`platform_condition`): A text field for describing the general condition of the platform.
	+ Enter a brief description of the platform's condition, e.g., "Clean and clear", "Dirty and cluttered", etc.
* **Safety Inspection** (`safety_inspection`): A select multiple field for checking if the platform meets the safety standards.
	+ Select "Yes" if the platform meets the safety standards, "No" otherwise.
* **Platform Status** (`platform_status`): A select one field for indicating the platform's status.
	+ Select "Active" if the platform is currently in use, "Inactive" otherwise.
* **Platform Elevation** (`platform_elevation`): A number field for recording the platform's elevation.
	+ Enter the platform's elevation in meters or feet.
* **Inspection Date** (`inspection_date`): A date field for recording the date of the inspection.
	+ Enter the date in the format YYYY-MM-DD.
* **Inspection Time** (`inspection_time`): A time field for recording the time of the inspection.
	+ Enter the time in the format HH:MM.
* **Notes** (`notes`): A text field for recording any additional comments or notes.
	+ Enter any relevant comments or observations about the platform's condition.
* **Assigned Inspector** (`assigned_inspector`): A text field for recording the assigned inspector's name.
	+ Enter the name of the assigned inspector.
* **Comments** (`comments`): A text field for recording any comments or feedback.
	+ Enter any additional comments or feedback about the platform's condition.
* **Platform Condition 1** (`platform_condition_1`): A select multiple field for checking the platform's condition 1.
	+ Select "Yes" if the platform condition 1 is met, "No" otherwise.
* **Platform Condition 2** (`platform_condition_2`): A select multiple field for checking the platform's condition 2.
	+ Select "Yes" if the platform condition 2 is met, "No" otherwise.
* **Platform Condition 3** (`platform_condition_3`): A select multiple field for checking the platform's condition 3.
	+ Select "Yes" if the platform condition 3 is met, "No" otherwise.
