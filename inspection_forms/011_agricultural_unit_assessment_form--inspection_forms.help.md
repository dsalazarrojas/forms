# Agricultural Unit Assessment Form - Help Guide

## Purpose

The Agricultural Unit Assessment Form is used to collect data on the condition and status of a specific agricultural unit, providing valuable information for decision-making and resource allocation.

## How To Complete This Form

1.  Answer each question in the form accurately and thoroughly.
2.  Please provide as much detail as possible for each question.
3.  Proceed to the next section only after completing all questions in the current section.

## Field-by-Field Explanation

*   **Assessor Name** (1, text, required): The name of the person conducting the assessment.
*   **Assessment Date** (2, date, required): The date the assessment was conducted.
*   **Farm Name** (3, text, required): The name of the farm or agricultural unit being assessed.
*   **Unit Identifier** (4, text, required): A specific identifier for the unit or field being assessed.
*   **Unit Size (acres)** (5, number, required): The size of the agricultural unit.
*   **Current Land Use** (6, select_one, required): Select the primary use of the unit (e.g. Crop production, Pasture, etc.).
*   **Infrastructure Condition** (7, select_one, required): Rate the overall condition of the unit's infrastructure.
*   **Fencing Status** (8, select_one, required): Evaluate the condition of the perimeter fencing.
*   **Water Access** (9, select_one, required): Assess the availability of water sources.
*   **Water Sources** (10, select_multiple, optional): Select all available water sources for the unit.
*   **Soil Quality Assessment** (11, select_one, required): Rate the overall soil quality of the unit.
*   **Drainage Condition** (12, select_one, required): Assess how well the unit drains.
*   **Erosion Present** (13, select_one, required): Determine if there is evidence of soil erosion.
*   **Vegetation Cover Percentage** (14, select_one, required): Estimate the percentage of ground covered by vegetation.
*   **Pest Pressure Level** (15, select_one, required): Evaluate the current pest pressure level.
*   **Weed Infestation Level** (16, select_one, required): Assess the level of weed problems.
*   **Equipment Access** (17, select_one, required): Rate the access to farm equipment for the unit.
*   **Road Condition** (18, select_one, required): Assess the condition of access roads.
*   **Environmental Concerns** (19, select_multiple, optional): Select any environmental issues affecting the unit.
*   **Productivity Rating** (20, select_one, required): Evaluate the overall productivity potential of the unit.
*   **Recommended Improvements** (21, text, required): Suggest improvements for the unit.
*   **Estimated Investment Needed (USD)** (22, number, optional): Provide an approximate cost for suggested improvements.
*   **Assessor Signature** (23, text, required): A digital signature from the assessor.
*   **Follow-up Assessment Required** (24, select_one, required): Determine if a follow-up assessment is needed.

## Tips

*   Answer each question carefully and thoroughly.
*   Provide as much detail as possible for each question.
*   Proceed to the next section only after completing all questions in the current section.
*   Ensure the assessor signs the form digitally.
