# Land Inspection And Risk Assessment Form - Help Guide

## Purpose
The Land Inspection And Risk Assessment Form is a tool used to collect information about a property's condition and potential risks associated with it. This form is intended to aid in the assessment of a property's condition and provide a framework for identifying potential risks that require attention.

## How To Complete This Form
1. Start by providing Property Inspection Details, including a brief description of the property's current state.
2. Indicate whether there are any Property Inspection Risks present, selecting all that apply.
3. Conduct a Risk Assessment and select a date for the assessment.
4. Describe the current Land Conditions, if any.
5. Identify any Risk Factors that exist, selecting only one as the most relevant.
6. Provide the date and time of the inspection.
7. Add any additional Notes and Comments regarding the inspection.

## Field-by-Field Explanation

* **Property Inspection Details (property_inspection_details, text, optional)**: Describe the current state of the property, including any notable features or issues.
* **Property Inspection Risks (property_inspection_risks, select_multiple, required)**: Identify any risks present at the property, selecting all that apply (e.g., 'Yes' for each risk present).
	+ These risks are used to determine the severity of the property's condition.
* **Risk Assessment (risk_assessment, date, required)**: Choose a date for the risk assessment, which will serve as a reference point for further evaluation.
* **Land Conditions (land_conditions, text, optional)**: Describe the current state of the land, if any notable features or issues exist.
* **Risk Factors (risk_factors, select_one, required)**: Identify the most relevant risk factor present at the property.
* **Inspection Date (inspection_date, time, required)**: Provide the date and time of the inspection, ensuring accuracy.
* **Notes and Comments (notes_and_comments, text, optional)**: Add any additional comments or observations regarding the inspection, serving as a reference for future evaluations.
