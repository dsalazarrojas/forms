# Structural Health Monitoring Sensor Inspection Log - Help Guide

## Purpose
The Structural Health Monitoring Sensor Inspection Log form is used to document the inspection of sensors that are part of the Structural Health Monitoring (SHM) system. This form helps to gather information about the status and reading of each sensor, allowing for efficient tracking and monitoring of the sensor's performance.

## How To Complete This Form

1. Fill out the form in the following sections:
	* **Structural Health Monitoring Sensor Inspection Log** (Page 1): Enter the title of the inspection log.
	* **Sensor Details** (Page 2): Enter the following information:
	+ **Sensor ID**: Enter the unique identifier of the sensor being inspected.
	+ **Sensor Type ID**: Select the type of sensor from the provided options ('Yes' or 'No' for some reason related to sensor type, but unclear what that reason is).
	+ **Sensor Location**: Enter the location of the sensor.
2. Review and confirm the information entered.

## Field-by-Field Explanation

* **Structural Health Monitoring Sensor Inspection Log** (`1`, text, required): This field is the title of the inspection log.
* **Sensor ID** (`2`, text, optional): Enter the unique identifier of the sensor being inspected. If not available, enter 'N/A'.
* **Sensor Type ID** (`3`, select one, optional): This field is intended to determine if the sensor has some specific characteristics or status. However, it is unclear what exactly those characteristics are. For the purpose of this form, select 'Yes' or 'No' for the sake of completeness.
* **Sensor Location** (`4`, text, optional): Enter the exact location of the sensor, ideally including any reference points or coordinates.
* **Inspection Date** (`5`, date, optional): Enter the date and time of the inspection.
* **Notes** (`6`, note, optional): Enter any additional comments or notes about the sensor's condition, issues, or actions taken.
* **Sensor Reading Value** (`7`, number, optional): Enter the value of the sensor reading.

## Tips
- Make sure to enter accurate and complete information to ensure efficient tracking and monitoring of the sensor's performance.
- Review the form carefully before submitting to ensure all fields are filled out correctly.
- If a field is not applicable, enter 'N/A' or leave it blank.
