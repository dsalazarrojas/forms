# Yard Security Assessment Form - Help Guide
## Purpose
The Yard Security Assessment Form is used to evaluate the security features and risks associated with a given yard. It is designed to gather information on the yard's security measures and any potential risks that need to be addressed.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form in its entirety, ensuring that all required fields are completed.
2. Answer each question to the best of your ability, using the options provided.

## Field-by-Field Explanation

* **Yard Details** (`yard_details`, text, required): This field is used to collect information about the yard, including any relevant details or comments that need to be considered when evaluating the security features.
* **Yard Address** (`yard_address`, text, required): This field is used to collect the address of the yard, which is essential for locating the site and evaluating the security features.
* **Yard Size** (`yard_size`, number, required): This field is used to collect the size of the yard, which can affect the security features and measures that need to be implemented.
* **Security Risks** (`security_risks`, select_multiple, required): This field is used to select any potential security risks associated with the yard, such as a drowning pool or loose wire. Select all risks that apply.
* **Risk Rating** (`risk_rating`, number, required): This field is used to rate the level of risk associated with each selected risk. A higher number indicates a higher level of risk.
* **Recommended Actions** (`recommended_actions`, select_multiple, required): This field is used to select any recommended actions to address the security risks, such as securing a pool cover or installing a fence.
* **Inspector Comments** (`inspector_comments`, note, required): This field is used to provide any additional comments or notes from the inspector.
* **Inspector Signature** (`inspector_signature`, time, required): This field is used to collect the signature of the inspector, which is essential for official documentation.
* **Date Completed** (`date_completed`, date, required): This field is used to collect the date the form was completed.
* **Inspector Name** (`inspector_name`, text, required): This field is used to collect the name of the inspector.
* **Inspector Company** (`inspector_company`, text, required): This field is used to collect the name of the inspector's company.
* **Contact Number** (`contact_number`, text, required): This field is used to collect the contact number of the inspector.
* **Email** (`email`, email, required): This field is used to collect the email of the inspector.
* **Assigned Tool** (`assigned_tool`, text, required): This field is used to collect the tool used by the inspector.
* **Assigned Inspector** (`assigned_inspector`, text, required): This field is used to collect the name of the inspector assigned to the job.
* **Completed By** (`completed_by`, select_one, required): This field is used to indicate whether the form has been completed.
* **Completed Date** (`completed_date`, date, required): This field is used to collect the date the form was completed.
* **Inspector Designation** (`inspector_designation`, text, required): This field is used to collect the designation of the inspector.
* **Certification Number** (`certification_number`, number, required): This field is used to collect the certification number of the inspector.
* **Assigned Tool Type** (`assigned_tool_type`, text, required): This field is used to collect the type of tool used by the inspector.
* **Notes** (`notes`, note, required): This field is used to provide any additional notes or comments from the inspector.
* **Inspector Designation Number** (`inspector_designation_number`, number, required): This field is used to collect the designation number of the inspector.

Note: All fields marked as "required" must be completed in order to submit the form.
