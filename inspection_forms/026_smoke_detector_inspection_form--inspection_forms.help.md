# Smoke Detector Inspection Form - Help Guide
## Purpose
The Smoke Detector Inspection Form is designed to collect information about the status of smoke detectors in a building. This form helps building inspectors conduct thorough checks on the presence, functionality, and placement of smoke detectors, as well as the status of fire extinguishers and fire alarm panels. The data collected through this form can be used to ensure that the smoke detectors and fire safety systems are functioning properly, identifying any potential issues that need to be addressed.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the required fields, which are marked as `required` in the form.
2. Select the correct options for each field, based on your observations.
3. Double-check your answers to ensure accuracy.

## Field-by-Field Explanation

* **Smoke Detector Inspection Form** (`smoke_detector_inspection_form`, text, not required): This field is not required, but it's a good idea to leave a note or description about the inspection process.
* **Building ID** (`building_id`, number, not required): Enter the building's ID number, if available.
* **Floor Level** (`floor_level`, select_one, not required): Select the floor level where the smoke detector is located. Common options are:
	+ ground floor
	+ first floor
	+ second floor
* **Fire Alarm System** (`fire_alarm_system`, select_multiple, not required): Check the status of the fire alarm system. Options are:
	+ installed
	+ not installed
	+ not applicable
* **Smoke Detector Location** (`smoke_detector_location`, select_multiple, not required): Identify the location of the smoke detector. Options are:
	+ near stairwell
	+ near window
	+ near door
* **Smoke Detector Status** (`smoke_detector_status`, select_one, not required): Check the functionality of the smoke detector. Options are:
	+ functional
	+ non-functional
* **Fire Extinguisher Type** (`fire_extinguisher_type`, select_one, not required): Identify the type of fire extinguisher. Options are:
	+ water chemical
	+ dry chemical
	+ clean agent
* **Fire Extinguisher Location** (`fire_extinguisher_location`, select_multiple, not required): Identify the location of the fire extinguisher. Options are:
	+ near entrance
	+ near fire alarm panel
	+ near stairwell
* **Fire Extinguisher Status** (`fire_extinguisher_status`, select_one, not required): Check the functionality of the fire extinguisher. Options are:
	+ functional
	+ non-functional
* **Fire Alarm Panel** (`fire_alarm_panel`, select_one, not required): Check the status of the fire alarm panel. Options are:
	+ present
	+ absent
	+ non-applicable
* **Fire Extinguisher Tag** (`fire_extinguisher_tag`, text, not required): Enter any tag or label on the fire extinguisher, if applicable. 

## Tips
* Be thorough and accurate when completing this form.
* If you're unsure about any of the fields, refer to the building's documentation or consult with the building's maintenance team.
* Make sure to save your completed form for future reference.
