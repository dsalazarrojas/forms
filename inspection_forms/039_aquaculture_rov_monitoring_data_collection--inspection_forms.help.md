# Aquaculture ROV Monitoring Data Collection - Help Guide

## Purpose
This form is used to collect data on the monitoring and inspection of aquaculture environments using remotely operated vehicles (ROVs). The data collected will help aquaculture professionals to evaluate the effectiveness of their operations, identify potential issues, and take necessary actions to improve the health of the aquaculture environment.

## How To Complete This Form

1. Please fill in the mission details, including the date and start time of the monitoring mission.
2. Enter the facility name and pond ID where the monitoring was conducted.
3. Specify the name of the ROV operator who conducted the monitoring mission.
4. Provide any monitoring data collected during the mission in the "Monitoring Data" field.
5. Report on the water visibility and depth during the mission.
6. Assess the bottom condition using the provided scale (Excellent, Good, Fair, or Poor).
7. Record any fish behavior observations during the mission.
8. Describe the condition of equipment and infrastructure used during the mission.
9. Report any anomalies or concerns encountered during the mission.
10. Indicate if any media files were captured during the mission.
10. If necessary, suggest recommended actions to improve the aquaculture environment.

## Field-by-Field Explanation

* **Mission Information**: This field is used to record the details of the monitoring mission, including the date and start time.
* **Mission Date**: This field is used to select the date of the monitoring mission.
* **Mission Start Time**: This field is used to select the start time of the monitoring mission.
* **Facility Name**: This field is used to enter the name of the facility where the monitoring was conducted.
* **Pond ID**: This field is used to enter the pond ID where the monitoring was conducted.
* **ROV Operator Name**: This field is used to enter the name of the ROV operator who conducted the monitoring mission.
* **Monitoring Data**: This field is used to enter any additional monitoring data collected during the mission.
* **Water Visibility (feet)**: This field is used to report on the water visibility during the mission.
* **Water Depth (feet)**: This field is used to report on the water depth during the mission.
* **Bottom Condition Assessment**: This field is used to assess the bottom condition using the provided scale (Excellent, Good, Fair, or Poor).
* **Fish Behavior Observation**: This field is used to record any fish behavior observations during the mission.
* **Equipment and Infrastructure Condition**: This field is used to describe the condition of equipment and infrastructure used during the mission.
* **Any Anomalies or Concerns**: This field is used to report any anomalies or concerns encountered during the mission.
* **Media Files Captured**: This field is used to indicate if any media files were captured during the mission.
* **Recommended Actions**: This field is used to suggest any recommended actions to improve the aquaculture environment.
