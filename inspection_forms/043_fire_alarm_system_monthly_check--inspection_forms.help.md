# Fire Alarm System Monthly Check - Help Guide
## Purpose
The purpose of this form is to gather information about the current state of the fire alarm system on a monthly basis. This information will be used to track the system's status, identify potential issues, and ensure that the system is functioning correctly.

## How To Complete This Form
To complete this form, simply select the relevant options for each field and provide the required information. The form is divided into several sections, each with its own specific fields and instructions.

## Field-by-Field Explanation
* **Monthly Check** (`monthly_check`, select_one, required: false): Please select "Yes" if you have completed a monthly check of the fire alarm system, or "No" if you have not.
* **System Inspected** (`system_inspected`, select_multiple, required: false): Please select "Yes" if the system was inspected, or "No" if it was not.
* **Alarm System Status** (`alarm_system_status`, text, required: false): Please enter a brief description of the current status of the alarm system.
* **Fire Alarm System Description** (`fire_alarm_system_description`, text, required: false): Please enter a brief description of the fire alarm system.
* **Electrical Inspection** (`electrical_inspection`, select_one, required: false): Please select "Yes" if an electrical inspection was performed, or "No" if it was not.
* **Fire Alarm System Monthly Check 7** (`fire_alarm_system_monthly_check_7`, select_multiple, required: false): Please select "Yes" if this specific check was completed, or "No" if it was not.
* **Fire Alarm System Monthly Check 9** (`fire_alarm_system_monthly_check_9`, text, required: false): Please enter a brief description of this specific check.
* **Fire Alarm System Monthly Check 10** (`fire_alarm_system_monthly_check_10`, number, required: false): Please enter a numerical value for this field.
* **Fire Alarm System Monthly Check 13** (`fire_alarm_system_monthly_check_13`, select_one, required: false): Please select "Yes" if this specific check was completed, or "No" if it was not.
* **Fire Alarm System Monthly Check 15** (`fire_alarm_system_monthly_check_15`, number, required: false): Please enter a numerical value for this field.
* **Fire Alarm System Monthly Check 16** (`fire_alarm_system_monthly_check_16`, select_multiple, required: false): Please select "Yes" if this specific check was completed, or "No" if it was not.
* **Fire Alarm System Monthly Check 19** (`fire_alarm_system_monthly_check_19`, select_one, required: false): Please select "Yes" if this specific check was completed, or "No" if it was not.

## Tips
* Make sure to carefully read each field label and description carefully before selecting an option.
* If you are unsure about any of the questions or fields, please contact the relevant authorities or personnel for clarification.
* The information gathered from this form will be used to ensure that the fire alarm system is functioning correctly and to identify any potential issues.
