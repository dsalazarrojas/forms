# Medical Supplies Usage Report Form - Help Guide

## Purpose
The Medical Supplies Usage Report Form is used to collect data on the usage of medical supplies across the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the report date for which you are reporting on the usage of medical supplies.
2. Choose whether the report period is a specific date or a general period (e.g., week, month, etc.).
3. Enter the truck number for the vehicle that delivered the medical supplies.
4. Select which products were used during the report period (Yes or No).
5. Select which products are still in stock (Yes or No).
6. Enter your name as the person submitting the report.
7. Add any additional comments about the report.

## Field-by-Field Explanation

* **Report Date** (1): Enter the date for which you are submitting this report. This is the date on which you are reporting the usage of medical supplies.
* **Report Period** (2): Select the time frame for which you are reporting on the usage of medical supplies. This could be a specific date or a general period (e.g., week, month, etc.).
* **Truck Number** (3): Enter the truck number for the vehicle that delivered the medical supplies.
* **Truck Number** (4): This field is a duplicate of the Truck Number field. Please only enter the truck number once.
* **Products Used** (5): Select which products were used during the report period (Yes or No).
* **Products Still In Stock** (6): Select which products are still in stock (Yes or No).
* **Submitter Name** (7): Enter your name as the person submitting this report.
* **Submitter Comments** (8): Add any additional comments about the report.
* **Products Reorder Date** (9): Enter the date on which products will be reordered if necessary.
