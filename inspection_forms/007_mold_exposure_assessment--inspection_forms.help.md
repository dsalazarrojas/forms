# mold_exposure_assessment - Help Guide
## Purpose
This form is used to collect information about mold exposure in properties, including occupant concerns, property details, and follow-up instructions. It will help assess and address mold-related issues in a property.

## How To Complete This Form
1. Answer all required fields marked with an asterisk (\*).
2. Select the correct options for each field from the provided choices.
3. Fill out the form in the following pages: Property Details, Occupant Concerns, and Follow-up.

## Field-by-Field Explanation

* **Property Details** (`property_details`, text, optional): Describe the property's type (residential or commercial), location, and general condition.
* **Occupant Concerns** (`occupant_concerns`, select_one, optional): Report the level of mold exposure concern experienced by the property's occupant(s) (None, Mild, Moderate, Severe).
* **Property Type** (`property_type`, select_one, optional): Select the type of property (Residential, Commercial).
* **Property Location** (`property_location`, text, optional): Enter the property's address or location.
* **Occupant Name** (`occupant_name`, text, optional): Enter the name(s) of the occupant(s) concerned about mold exposure.
* **Contact Info** (`contact_info`, text, optional): Enter contact information, such as phone number or email address, for follow-up purposes.
* **Property Condition** (`property_condition`, select_one, optional): Report the property's condition (Well-maintained, Poor, Needs Improvement).
* **Follow-up** (`follow_up`, select_one, optional): Determine if a follow-up is required (True, False).
* **Notes** (`notes`, text, optional): Add any additional comments or notes about the property's mold exposure condition.
* **Mold Type** (`mold_type`, select_one, optional): Select the type of mold (Black, Green).
* **Email** (`email`, email, optional): Enter your email address for follow-up communication.
* **Phone** (`phone`, text, optional): Enter your phone number for follow-up communication.
* **Follow-up Date** (`follow_up_date`, date, optional): Set a follow-up date if required.
* **Follow-up Time** (`follow_up_time`, time, optional): Set a follow-up time if required.
* **Follow-up Location** (`follow_up_location`, text, optional): Enter the location for follow-up.
* **Follow-up Notes** (`follow_up_notes`, text, optional): Add any additional notes about the follow-up.
* **Mold Location** (`mold_location`, text, optional): Describe the location of the mold growth.
* **Mold Area** (`mold_area`, text, optional): Estimate the size of the mold area affected.
* **Mold Size** (`mold_size`, text, optional): Describe the size of the mold growth.
* **Mold Description** (`mold_description`, text, optional): Add any additional comments about the mold exposure condition.

**Tips**

* Be as accurate as possible when providing information.
* If you are unsure about any field, please do not leave it blank.
* If you have any questions or concerns, contact [insert contact information].
