# Softgel Capsule Quality Inspection Checklist - Help Guide
## Purpose

This form is used to inspect softgel capsules for quality issues, such as color, weight, size, and shape inconsistencies.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the **Batch Number** field with the number of the batch being inspected.
2. Select the **Shift** field and choose the correct shift from the available options.
3. For each field after this, select the options that apply to the inspected capsules.

## Field-by-Field Explanation

* **Batch Number** (`batch_number`, text, required: false): Enter the batch number of the inspected capsules.
* **Shift** (`shift`, select_multiple, required: false): Select the shift that the capsules were inspected during.
* **Color** (`color`, text, required: false): Enter any observations about the color of the capsules.
* **Weight** (`weight`, number, required: false): Enter any observations about the weight of the capsules.
* **Size** (`size`, text, required: false): Enter any observations about the size of the capsules.
* **Shape** (`shape`, text, required: false): Enter any observations about the shape of the capsules.
* **Consistent Color** (`color_consistent`, select_one, required: false): Select 'True' if the color of all capsules is consistent, 'False' if it is not.
* **Consistent Weight** (`weight_consistent`, select_one, required: false): Select 'True' if the weight of all capsules is consistent, 'False' if it is not.
* **Consistent Size** (`size_consistent`, select_one, required: false): Select 'True' if the size of all capsules is consistent, 'False' if it is not.
* **Consistent Shape** (`shape_consistent`, select_one, required: false): Select 'True' if the shape of all capsules is consistent, 'False' if it is not.
* **Uneven Color** (`color_uneven`, select_multiple, required: false): Select any observations where the color of the capsules is uneven.
* **Uneven Weight** (`weight_uneven`, select_multiple, required: false): Select any observations where the weight of the capsules is uneven.
* **Uneven Size** (`size_uneven`, select_multiple, required: false): Select any observations where the size of the capsules is uneven.
* **Uneven Shape** (`shape_uneven`, select_multiple, required: false): Select any observations where the shape of the capsules is uneven.
* **Color Missing** (`color_missing`, select_multiple, required: false): Select any observations where the color of the capsules is missing.
* **Weight Missing** (`weight_missing`, select_multiple, required: false): Select any observations where the weight of the capsules is missing.
* **Size Missing** (`size_missing`, select_multiple, required: false): Select any observations where the size of the capsules is missing.
* **Shape Missing** (`shape_missing`, select_multiple, required: false): Select any observations where the shape of the capsules is missing.
* **Color Outside** (`color_outside`, text, required: false): Enter any observations about the color of the capsules that is not within the accepted range.
* **Weight Outside** (`weight_outside`, text, required: false): Enter any observations about the weight of the capsules that is not within the accepted range.
* **Size Outside** (`size_outside`, text, required: false): Enter any observations about the size of the capsules that is not within the accepted range.
* **Shape Outside** (`shape_outside`, text, required: false): Enter any observations about the shape of the capsules that is not within the accepted range.

## Tips

* Make sure to select all fields that apply to the inspected capsules.
* If you are unsure about any field, consult with a quality control specialist.
* This form is meant to be used for quality inspections only, do not use for other purposes.
