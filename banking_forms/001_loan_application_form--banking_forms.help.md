# Loan Application Form - Help Guide
## Purpose
This loan application form is designed to collect information about the applicant and loan specifics. It will help us assess your loan eligibility or provide relevant loan options.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields with accurate and up-to-date information.
2. Review each field carefully, and make sure to select the correct option for each select field.
3. Double-check that all fields are filled out correctly before submitting the form.

## Field-by-Field Explanation

* **Loan Application Form** (`loan_application_form_header`, note, required: false)
	+ This field is just a header, so please ignore it.
* **Applicant Info** (`applicant_info_form`, text, required: false)
	+ Enter your name, address, and other identifying details.
* **Loan Amount** (`loan_amount_form`, number, required: false)
	+ Enter the total loan amount you are requesting.
* **Loan Term** (`loan_term_form`, number, required: false)
	+ Enter the loan term or repayment period.
* **Interest Rate** (`interest_rate_form`, number, required: false)
	+ Enter the interest rate of the loan.
* **Loan Term Month** (`loan_term_month_form`, time, required: false)
	+ Select the loan term in months.
* **Loan Start Date** (`loan_start_date_form`, date, required: false)
	+ Select the start date of the loan.
* **Loan End Date** (`loan_end_date_form`, date, required: false)
	+ Select the end date of the loan.
* **Applicant Income** (`applicant_income_form`, select_one, required: false)
	+ Select your annual income range.
* **Applicant Employment** (`applicant_employment_form`, select_multiple, required: false)
	+ Select all the employment options that apply to you.
* **Loan Status** (`loan_status_form`, select_one, required: false)
	+ Select the status of the loan (Active, Inactive, Closed, or Pending).
* **Loan Type** (`loan_type_form`, select_one, required: false)
	+ Select the type of loan (Personal, Business, Real Estate).
* **Loan Purpose** (`loan_purpose_form`, select_one, required: false)
	+ Select the purpose of the loan (Auto, Home Improvement, Education, Other).
* **Address** (`applicant_address_form`, text, required: false)
	+ Enter your address.
* **City** (`applicant_city_form`, text, required: false)
	+ Enter your city.
* **State** (`applicant_state_form`, text, required: false)
	+ Enter your state.
* **Zip** (`applicant_zip_form`, text, required: false)
	+ Enter your zip code.
* **Phone** (`applicant_phone_form`, text, required: false)
	+ Enter your phone number.
* **Email** (`applicant_email_form`, email, required: false)
	+ Enter your email address.
* **Submit** (`submit_form`, select_one, required: false)
	+ Click the "Submit" button to complete and submit the form.
