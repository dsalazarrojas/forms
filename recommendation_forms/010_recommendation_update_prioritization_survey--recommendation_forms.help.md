# Recommendation Update Prioritization Survey - Help Guide
## Purpose
The "Recommendation Update Prioritization Survey" form is designed to gather information on team involvement and recommendation updates from team members. It helps prioritize recommendations based on stakeholder input and status updates.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
* **Team Name (team_name)**:
    Team name is a required field to help identify the team that submitted the recommendation.
* **Team Lead (team_lead)**:
    Team lead is the person responsible for the recommendation, which is also required.
* **Recommendation ID (recommendation_id)**:
    This is a unique identifier for the recommendation.
* **Update Status (update_status)**:
    Select the current status of the recommendation as Active or Inactive.
* **Update Priority (update_priority)**:
    Choose whether the update is prioritized (Yes) or not (No).
* **Update Comments (update_comments)**:
    Provide additional comments for the update.
* **Stakeholders (stakeholders)**:
    List all relevant stakeholders involved in the recommendation.
* **Stakeholder Comments (stakeholder_comments)**:
    Enter comments from stakeholders.
* **Recommendation Text (recommendation_text)**:
    Enter the text of the recommendation.
* **Stakeholder Rating (stakeholder_rating)**:
    Rate the recommendation (1-10).
* **Stakeholder Rating Pros (stakeholder_rating_pros)**:
    Enter additional pros for the stakeholder rating.
* **Stakeholder Rating Cons (stakeholder_rating_cons)**:
    Enter additional cons for the stakeholder rating.
