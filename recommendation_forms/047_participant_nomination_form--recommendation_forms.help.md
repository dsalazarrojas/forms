# Participant Nomination Form - Help Guide
## Purpose
The Participant Nomination Form is used to recommend a participant for an award. This form gathers information about the participant, the recommender, and the award to be nominated for. The form ensures that all necessary details are provided to support a successful nomination.

## How To Complete This Form

*   To start, fill in the required fields with the participant's information and the nomination details.
*   Enter the participant's name and their institution in the respective fields.
*   Provide a brief explanation for the nomination reason.
*   Select the committee that will review the nomination.
*   Enter the award name and year for the nomination.
*   Fill in the participant's category.
*   Provide the recommender's name, title, institution, email, and phone number.
*   Enter a message from the recommender to support the nomination.
*   Ensure the recommender has signed and agreed to the nomination.
*   Finally, select the submission options to indicate how the nomination was submitted.

## Field-by-Field Explanation

*   **Participant Nomination Form**: This is the form title, and it cannot be edited.
*   **Nominee Info**: This field should be filled with the participant's name and information.
*   **Recommender Info**: This field should be filled with the recommender's name, title, and institution.
*   **Recommender Info 2**: This field is optional and can be left blank if not applicable.
*   **Nomination Reason**: This field should be filled with a brief explanation for the nomination.
*   **Nomination Committee**: Select the committee that will review the nomination.
*   **Award Info**: Fill in the award name and year to be nominated.
*   **Award Year**: This field should be filled with the award year.
*   **Nominee Info 2**: This field should be filled with the nominee's additional information.
*   **Recommender Name**: This field should be filled with the recommender's name.
*   **Recommender Title**: This field should be filled with the recommender's title.
*   **Recommender Institution**: This field should be filled with the recommender's institution.
*   **Recommender Email**: This field should be filled with the recommender's email address.
*   **Recommender Phone**: This field should be filled with the recommender's phone number.
*   **Nominee Name**: This field should be filled with the participant's name.
*   **Nominee Institution**: This field should be filled with the participant's institution.
*   **Award Name**: This field should be filled with the award name.
*   **Award Year 2**: This field should be filled with the award year.
*   **Nominee Category**: This field should be filled with the participant's category.
*   **Recommender Message**: This field should be filled with a message from the recommender supporting the nomination.
*   **Nominee Message**: This field should be filled with a message from the participant supporting the nomination.
*   **Recommender Signature**: This field should be filled with the recommender's signature.
*   **Agree**: Ensure the recommender has agreed to the nomination.
*   **Agree**: Ensure the participant has agreed to the nomination.
*   **Form Submission**: Select the submission options to indicate how the nomination was submitted.
