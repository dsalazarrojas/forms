# Recommendation Request Form - Help Guide
## Purpose
The purpose of this form is to request a recommendation from a recommender for a student.

## How To Complete This Form

1.  To complete this form, start by filling out the student information section.
2.  Fill out the student's name, school, degree, and major.
3.  Enter the student's email address and phone number.
4.  If you are a recommender, fill out your own contact information.
5.  Enter your email address and phone number.
6.  If you are requesting a recommendation for someone else, please provide the student's name and other relevant information.
7.  Set the submission deadline for the recommendation.
8.  Finally, enter the recommended submission time for the letter.

## Field-by-Field Explanation

*   **Student Name** (`student_name`, text, not required): Please enter the student's full name.
*   **Student School** (`student_school`, text, not required): Please enter the name of the student's school or university.
*   **Student Degree** (`student_degree`, select_one, not required): Please select the student's degree (e.g., Bachelor, Master, PhD).
*   **Student Major** (`student_major`, text, not required): Please enter the student's major or field of study.
*   **Recommender Name** (`recommender_name`, text, not required): If you are a recommender, please enter your name. If you are the student, please enter the name of the person recommending you.
*   **Recommender Contact** (`recommender_contact`, text, not required): If you are a recommender, please enter your contact information.
*   **Student Email** (`student_email`, email, not required): Please enter the student's email address.
*   **Student Phone** (`student_phone`, text, not required): Please enter the student's phone number.
*   **Recommender Email** (`recommender_email`, email, not required): If you are a recommender, please enter your email address.
*   **Recommender Phone** (`recommender_phone`, text, not required): If you are a recommender, please enter your phone number.
*   **Deadline** (`deadline`, date, not required): Please select a date by which you would like the recommendation submitted.
*   **Submission Time** (`submission_time`, time, not required): Please select a time of day for the submission of the letter.
*   **Recommendation Letter** (`recommendation_letter`, text, not required): Please provide a brief letter of recommendation.

## Tips

*   Please ensure that you have filled out all required fields before submitting the form.
*   If you are a recommender, please make sure to proofread your recommendation letter carefully before submitting.
*   If you are requesting a recommendation, please ensure that you have provided all necessary information for the recommender.
