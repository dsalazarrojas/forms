# Recommendation Letter Adjectives Reference Form - Help Guide
## Purpose
The Recommendation Letter Adjectives Reference Form is a standardized form used to capture evaluator's feedback and recommendation for a candidate. It provides a structured way of evaluating a candidate's performance and providing a clear assessment of their strengths and weaknesses.

## How To Complete This Form

1. **Candidate Information**: Enter the candidate's name in the "Candidate Name" field. This will help identify the candidate being evaluated.
2. **Evaluator Information**: Enter your name, position, and department in their respective fields. This will help establish your credibility as an evaluator.
3. **Evaluation Date**: Enter the date when you evaluated the candidate. This will help track the timeline of the evaluation process.
4. **Evaluation Score**: Select the evaluation score that best describes the candidate's performance. You can choose from four options: Excellent, Good, Fair, or Poor.
5. **Evaluation Comments**: Provide a brief description of the candidate's strengths and weaknesses. This section should include specific examples and details about the candidate's performance.
6. **Recommendation Letter**: If you have a formal recommendation letter for the candidate, you can upload it in this section. This is optional.
7. **Evaluator Signature**: Sign your name to confirm that the evaluation is genuine.
8. **Submit**: Review and submit the form to complete the evaluation process.

## Field-by-Field Explanation

* **Candidate Name**: The name of the candidate being evaluated.
* **Suggest a name for the candidate**: A suggested name for the candidate. This can be used as an alternative to the candidate's actual name.
* **Evaluator Name**: Your name as the evaluator.
* **Evaluator Position**: Your position or title in the organization.
* **Evaluator Position Hint**: If you need help with your position or title, use this field for additional information.
* **Letter Date**: The date when you evaluated the candidate.
* **Date Hint**: If you need help with the evaluation date, use this field for additional information.
* **Evaluation Score**: A score that best describes the candidate's performance. You can choose from four options: Excellent, Good, Fair, or Poor.
* **Evaluation Scale**: A hint to help you understand the evaluation scale options.
* **Evaluation Score Hint**: If you need help with the evaluation score, use this field for additional information.
* **Evaluation Comments**: A description of the candidate's strengths and weaknesses.
* **Evaluation Comments Hint**: If you need help with evaluation comments, use this field for additional information.
* **Evaluator Department**: The department you belong to.
* **Evaluator Department Hint**: If you need help with your department, use this field for additional information.
* **Recommendation Letter**: A formal recommendation letter for the candidate. This is optional.
* **Recommendation Letter Hint**: If you need help with the recommendation letter, use this field for additional information.
* **Evaluator Signature**: Your signature to confirm that the evaluation is genuine.
* **Evaluator Signature Hint**: If you need help with your signature, use this field for additional information.
* **Submit**: Review and submit the form to complete the evaluation process.

## Tips

* Make sure to evaluate the candidate fairly and honestly.
* Provide specific examples and details about the candidate's performance.
* Use the evaluation scale options to provide a clear assessment of the candidate's strengths and weaknesses.
* Review the form carefully before submission to ensure accuracy and completeness.
