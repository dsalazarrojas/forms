# Strategic Recommendation Success Assessment Form - Help Guide
## Purpose
The Strategic Recommendation Success Assessment Form is designed to evaluate the success of strategic recommendations made to organizations or teams. It helps identify areas of improvement and measures the effectiveness of recommended initiatives.

## How To Complete This Form
To complete this form, please go through each page and fill in the required information. The form has several pages with different sections to assess various aspects of the recommendation. Please fill in the fields as accurately and thoroughly as possible.

## Field-by-Field Explanation
### Page 1: Initiative Outcomes
* **Initiative Outcomes** (`initiative_outcomes`, text, optional): This field is used to describe the expected outcomes of the recommended initiative. Please provide a brief description of the anticipated results.

### Page 2: Adoption Rates
* **Adoption Rates** (`adoption_rates`, number, optional): This field is used to assess the rate at which the recommended initiative was adopted by the organization or team. Please provide a numerical value between 0 and 100.

### Page 3: Implementation Dates
* **Implementation Dates** (`implementation_dates`, date, optional): This field is used to record the dates when the recommended initiative was implemented. Please provide the start and end dates of the implementation.

### Page 4: Recommended By
* **Recommended By** (`recommended_by`, text, optional): This field is used to identify the person or team that recommended the initiative. Please provide the name and title of the person or team.

### Page 5: Success Metrics
* **Success Metrics** (`success_metrics`, number, optional): This field is used to measure the success of the recommended initiative. Please provide a numerical value between 0 and 100.

### Page 6: Feedback
* **Feedback** (`feedback`, text, optional): This field is used to gather feedback on the recommended initiative. Please provide any comments or suggestions.

### Page 7: Implementation Status
* **Implementation Status** (`implementation_status`, select, optional): This field is used to record the current implementation status of the recommended initiative. Please select from the following options:
	+ Implemented
	+ On Hold
	+ Not Implemented

### Page 8: Implementation Comments
* **Implementation Comments** (`implementation_comments`, text, optional): This field is used to provide any additional comments on the implementation status. Please provide any details that may be helpful for future reference.

## Tips
* Please answer all fields as accurately and thoroughly as possible.
* If you are unsure about any field, please consult with the person who recommended the initiative.
* This form is designed to be completed by the person who implemented the recommended initiative.
