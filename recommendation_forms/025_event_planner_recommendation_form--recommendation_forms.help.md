# event_planner_recommendation_form - Help Guide
## Purpose

The event planner recommendation form is used to provide details about a recommended event, including its name, location, date, and time. Additionally, the form captures information about the event planner, such as their name, contact information, and job description.

The purpose of this form is to help event planners recommend events to others, providing a clear and concise way to share event details and planner contact information.

## How To Complete This Form

To complete the form, follow these steps:

1. Fill out the `event_name` field with the name of the event.
2. Enter the `event_details` field with a brief description of the event.
3. Select the `recommendation_type` field to indicate whether the event is recommended or not.
4. Enter a description of the event in the `recommendation_description` field.
5. Fill out the `event_planner_name` field with the name of the event planner.
6. Enter the event planner's contact information in the `event_planner_email`, `event_planner_phone`, `event_planner_company`, `event_planner_title`, `event_planner_organization`, `event_planner_job_title`, and `event_planner_job_description` fields.
7. Enter the event details in the `event_date`, `event_time`, `event_location`, and `event_notes` fields.
8. Enter the name of the person recommending the event in the `recommended_by` field.
9. Enter the contact information of the person recommending the event in the `recommended_by_email`, `recommended_by_phone`, `recommended_by_company`, `recommended_by_title`, `recommended_by_job_description` fields.

## Field-by-Field Explanation

* **event_name** (Required): Enter the name of the event.
* **event_details** (Required): Enter a brief description of the event.
* **recommendation_type** (Required): Select "Yes" to indicate that the event is recommended, or "No" to indicate that it is not recommended.
* **recommendation_description** (Required): Enter a description of why you are recommending the event.
* **event_planner_name** (Required): Enter the name of the event planner.
* **event_planner_email** (Required): Enter the event planner's email address.
* **event_planner_phone** (Required): Enter the event planner's phone number.
* **event_planner_company** (Required): Enter the event planner's company name.
* **event_planner_title** (Required): Enter the event planner's title.
* **event_planner_organization** (Required): Enter the event planner's organization name.
* **event_planner_job_title** (Required): Enter the event planner's job title.
* **event_planner_job_description** (Required): Enter a brief description of the event planner's job.
* **event_date** (Required): Enter the date of the event.
* **event_time** (Required): Enter the time of the event.
* **event_location** (Required): Enter the location of the event.
* **event_notes** (Required): Enter any additional notes about the event.
* **recommended_by** (Required): Enter the name of the person recommending the event.
* **recommended_by_email** (Required): Enter the email address of the person recommending the event.
* **recommended_by_phone** (Required): Enter the phone number of the person recommending the event.
* **recommended_by_company** (Required): Enter the company name of the person recommending the event.
* **recommended_by_title** (Required): Enter the title of the person recommending the event.
* **recommended_by_job_description** (Required): Enter a brief description of the person recommending the event's job.
