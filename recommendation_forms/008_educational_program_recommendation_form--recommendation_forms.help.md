# educational_program_recommendation_form - Help Guide
## Purpose
This form is designed to gather user-specific recommendations for educational programs. It is a supplementary tool to help users provide feedback and recommendations for students, parents, or faculty members.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary information ready.
2. Select the type of recommendation you are providing (Student, Parent, or Faculty Member).
3. Enter the user's Program Name and Institution Name.
4. Enter your Recommendation.
5. Click on the Submit button to submit your recommendation.

## Field-by-Field Explanation
* **User ID** (`user_id`, number, optional): Your unique user ID number. If you don't have a user ID, please contact the institution's administration team for assistance.
* **Program Name** (`program_name`, text, optional): Enter the name of the program for which you are providing a recommendation.
* **Program ID** (`program_id`, number, optional): Enter the ID number of the program for which you are providing a recommendation.
* **Institution Name** (`institution_name`, text, optional): Enter the name of the institution offering the program.
* **Recommendation Type** (`recommendation_type`, select_one, optional): Choose the type of recommendation you are providing (Student, Parent, or Faculty Member).
* **Feedback** (`feedback`, text, optional): Enter any additional feedback or comments you have.
* **Recommendation** (`recommendation`, text, optional): Enter your written recommendation for the user.
* **Submit** (`submit_button`, note, optional): Click the submit button to send your recommendation.

## Tips
* Please ensure your recommendation is specific and relevant to the user's abilities and qualifications.
* If you need help or have questions, contact the institution's administration team.
* This form is meant for one-time submission, so please only submit your recommendation once.
