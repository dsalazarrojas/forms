# Study Abroad Recommendation Form - Help Guide
## Purpose
The Study Abroad Recommendation Form is a tool used to collect information about students participating in study abroad programs. This form helps us better understand the programs and provide support to students, faculty, and staff members involved in these programs. To ensure you provide accurate and complete information, please make sure to fill out this form carefully and only submit it for programs you are familiar with.

## How To Complete This Form
To complete this form, please follow these steps:

* Review the program details carefully to ensure you are recommending a legitimate study abroad program.
* Fill out the required fields as accurately as possible.
* Make sure to enter a valid email address in the `Student Email` field.
* Enter a valid phone number in the `Student Phone` field.
* Review your responses to ensure they are accurate and complete before submitting the form.

## Field-by-Field Explanation
- **Program Name** (`program_name`, text, required): The name of the study abroad program you are recommending.
- **Program Type** (`program_type`, select_one, required): The type of program you are recommending (e.g., internship, language exchange, etc.).
- **Name** (`name`, text, required): Your name and title.
- **Department** (`department`, text, required): The department or faculty you are representing.
- **Program Length** (`program_length`, number, required): The length of the program in months.
- **Program Start Date** (`program_start_date`, date, required): The start date of the program in MM/DD/YYYY format.
- **Program End Date** (`program_end_date`, date, required): The end date of the program in MM/DD/YYYY format.
- **Name of Prophet** (`name_of_prophet`, text, optional): Not clear what this field is intended for. Please enter your name as it appears on your business card or a brief description of your role.
- **Role in Program** (`role_in_program`, text, required): A description of your role in the program.
- **Contact Information** (`contact_info`, text, optional): A contact method for follow-up questions.
- **Email** (`email`, email, optional): An alternative contact email address.
- **Report ID** (`report_id`, text, required): A unique identifier for the program report.
- **Student ID** (`student_id`, text, required): The ID number of the student in the program.
- **Student Name** (`student_name`, text, required): The name of the student in the program.
- **Student Grade** (`student_grade`, number, required): The grade level of the student (e.g., freshman, sophomore, etc.).
- **Student Class** (`student_class`, text, required): The class or level of the student.
- **Program Status** (`program_status`, text, required): The current status of the program (e.g., active, inactive, etc.).
- **Comment** (`comment`, text, optional): Additional comments about the program or student.
- **Student Email** (`student_email`, email, required): The email address of the student.
- **Student Phone** (`student_phone`, text, required): The phone number of the student.
- **Program Address** (`program_address`, text, required): The address of the program location.
- **Program Website** (`program_website`, text, optional): The website of the program.
- **Program Institution** (`program_institution`, text, required): The institution or university where the program is held.
- **Program Instructor** (`program_instructor`, text, required): The instructor or person running the program.
