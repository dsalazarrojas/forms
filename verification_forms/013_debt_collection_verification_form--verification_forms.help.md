# Debt Collection Verification Form - Help Guide
## Purpose
The Debt Collection Verification Form is a tool used to gather and store information about debt collection activities. Its purpose is to ensure that all necessary details are collected and accurately recorded for future reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Debtor's First Name in the field labeled "Debtor First Name".
2. Enter the Debtor's Last Name in the field labeled "Debtor Last Name".
3. Provide a brief description of the debt in the field labeled "Debt Description".
4. Enter the debtor's address in the field labeled "Debt Address".
5. Enter the debtor's contact email in the field labeled "Debtor Contact Email".
6. Enter the debtor's phone number in the field labeled "Debtor Phone Number".
7. Enter the date of the debt in the field labeled "Debt Date".
8. Enter the total debt amount in the field labeled "Debt Amount".
9. Select the method of verification from the options provided in the field labeled "Verification Method".
10. If the verification method is "Other", enter a brief description of the method in the field labeled "Other Verification Method".
11. Add any additional comments about the debt in the field labeled "Additional Comments".
12. Enter the tool assigned to the debt collection activity in the field labeled "Assigned Tool".
13. Select the user responsible for submitting the form in the field labeled "Submitted By".

## Field-by-Field Explanation
* **Debtor First Name** (Text, Optional): This field is used to capture the first name of the debtor.
* **Debtor Last Name** (Text, Optional): This field is used to capture the last name of the debtor.
* **Debtor Description** (Text, Optional): This field provides a brief description of the debt.
* **Debtor Address** (Text, Optional): This field is used to capture the debtor's address.
* **Debtor Contact Email** (Email, Optional): This field is used to capture the debtor's contact email.
* **Debtor Phone Number** (Text, Optional): This field is used to capture the debtor's phone number.
* **Debt Date** (Date, Optional): This field is used to capture the date of the debt.
* **Debt Amount** (Number, Optional): This field is used to capture the total debt amount.
* **Verification Method** (Select One, Optional): This field allows you to select the method of verification (Online, Offline, or Other).
* **Other Verification Method** (Text, Optional): If the verification method is "Other", this field is used to provide a brief description of the method.
* **Additional Comments** (Note, Optional): This field allows you to add any additional comments or notes about the debt.
* **Assigned Tool** (Text, Optional): This field is used to capture the tool assigned to the debt collection activity.
* **Submitted By** (Select One, Optional): This field is used to select the user responsible for submitting the form.

## Tips
* Please ensure that all fields are filled in accurately and completely.
* If the verification method is "Other", please provide a brief description of the method.
* If you are unsure about any of the fields, please contact the authorized personnel for assistance.
