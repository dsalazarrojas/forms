# Agent Credentials Verification Form - Help Guide
## Purpose
This form is designed to collect detailed information about an individual's credentials, including type, issuing authority, number, and status, to facilitate efficient verification processes.

## How To Complete This Form
1. Fill in the required fields:
	* Agent full name
	* Credential type
	* Issuing authority
	* Credential number
	* Verification status
2. Select the credential type (e.g., license, certification, ID) and select the correct issuing authority and number.
3. Choose whether the credential has an issue date and expiry date.
4. If necessary, describe any supporting documents attached.
5. Select the verification status (e.g., Verified, Pending, Rejected).
6. Enter the name of the staff member who completed the verification.

## Field-by-Field Explanation
* **Agent full name**: Enter the full name as it appears on the credential.
* **Credential type**: Select the type of credential, such as Professional license, Certification, Government ID, or Other.
* **Issuing authority**: Enter the organization that issued the credential.
* **Credential number**: Enter the number on the credential document.
* **Issue date**: Enter the date the credential was issued, if applicable.
* **Expiry date**: Enter the date the credential expires, if applicable.
* **Supporting documents description**: Describe any documents attached to support the verification process.
* **Verification status**: Select the result of the verification process, such as Verified, Pending, or Rejected.
* **Verifier name**: Enter the name of the staff member who completed the verification process.

## Tips
* Double-check the information entered to ensure accuracy and completeness.
* If the credential type is not listed, select "Other" and enter a custom description.
* If the credential has an issue date, ensure it is accurate and relevant to the verification process.
* If the verification status is "Pending", provide a clear explanation for the delay in verification.
* If the verification status is "Rejected", provide a brief reason for the rejection.
