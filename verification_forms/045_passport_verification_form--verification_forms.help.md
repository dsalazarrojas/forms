# Passport Verification Form - Help Guide
## Purpose
This form is designed to collect comprehensive information about a passport for verification purposes. Please fill out the form accurately and thoroughly to ensure proper verification.

## How To Complete This Form
Before starting, make sure you have all the necessary documents and information ready. The form is divided into two parts: Client Information and Passport Details. Please fill out each section accordingly.

## Field-by-Field Explanation

* **Client Info** (`client_info`, text, required/optional): Enter the client's name and other identifying information.
* **Passport Number** (`passport_number`, text, required/optional): Enter the passport number as it appears on the passport.
* **Date of Issue** (`date_of_issue`, date, required/optional): Enter the date the passport was issued.
* **Date of Expiry** (`date_of_expiry`, date, required/optional): Enter the date the passport is due to expire.
* **Place of Issue** (`place_of_issue`, text, required/optional): Enter the country where the passport was issued.
* **Issued By** (`issued_by`, text, required/optional): Enter the authority that issued the passport.
* **Passport Photo** (`passport_photo`, text, required/optional): Enter a brief description of the passport's photo.
* **Photo Front** (`photo_front`, text, required/optional): Enter a brief description of the passport's front page.
* **Photo Back** (`photo_back`, text, required/optional): Enter a brief description of the passport's back page.
* **Client** (`client`, select_one, required/optional): Select the client from the list provided.
* **Address** (`address`, text, required/optional): Enter the client's address.
* **Postal Address** (`postal_address`, text, required/optional): Enter the client's postal address.
* **Nationality** (`nationality`, text, required/optional): Enter the client's nationality.
* **Passport Country** (`passport_country`, text, required/optional): Enter the country of passport issue.
* **Passport Number 2** (`passport_number_2`, text, required/optional): Enter the second passport number.
* **Passport Photo ID** (`passport_photo_id`, text, required/optional): Enter the ID number of the passport photo.
* **Client 2** (`client_2`, select_multiple, required/optional): Select the second client from the list provided.
* **Photo Front 2** (`photo_front_2`, text, required/optional): Enter a brief description of the second client's passport photo front page.
* **Photo Back 2** (`photo_back_2`, text, required/optional): Enter a brief description of the second client's passport photo back page.
* **Passport Front** (`passport_front`, text, required/optional): Enter a brief description of the passport's front page.
* **Passport Back** (`passport_back`, text, required/optional): Enter a brief description of the passport's back page.
* **Signature** (`signature`, text, required/optional): Enter the client's signature.
* **ID Number** (`id_number`, text, required/optional): Enter the ID number of the client.
* **Date of Birth** (`date_of_birth`, date, required/optional): Enter the client's date of birth.
* **Date Of Issue 2** (`date_of_issue_2`, date, required/optional): Enter the date the second passport was issued.

## Tips
Please fill out each field accurately and thoroughly. If you're unsure about any field, consult the relevant authority or contact the relevant department for assistance.
