# Customer ID Upload Form - Help Guide
## Purpose
This form is designed to help customers upload their ID documents for verification purposes. This may include age verification, onboarding, or other identity verification processes.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the required fields as per the instructions below.
2. Upload your ID document using the "Upload" button.
3. A file upload notification will be displayed after uploading your ID document.

## Field-by-Field Explanation

* **Customer ID** (`customer_id`, text, optional): Enter your customer ID number or any other identifying information you have been provided with.
* **Upload** (`upload_button`, text, optional): Click this button to upload your ID document. Make sure to upload a valid document such as a passport, driver's license, or government-issued ID card.
* **File uploaded** (`file_uploaded`, text, optional): This is a read-only field that shows the uploaded file details, including the file name and size.
* **Verify ID** (`verify_id`, note, optional): This field is intended for any additional comments or notes about the uploaded ID document. Use this to confirm that the uploaded document is valid or to provide further details about the customer's identity.

## Tips

* Make sure to upload a valid ID document to ensure successful verification.
* Ensure the uploaded document is clear and readable for verification purposes.
* If the verification process fails, re-upload your ID document and try again.
* If you have any issues or concerns about the verification process, contact the support team for assistance.
