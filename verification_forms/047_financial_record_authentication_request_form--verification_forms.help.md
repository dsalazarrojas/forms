# Financial Record Authentication Request Form - Help Guide
## Purpose
The Financial Record Authentication Request Form is a tool used to verify the authenticity of financial records for customers. Fill out this form to request authentication of a specific account or transaction.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of financial record you are requesting to be authenticated (Account Number, Account Holder, etc.).
2. Choose the correct account number from the options provided.
3. Select the type of account or individual/business owner.
4. Choose the financial institution and branch location (if applicable).
5. Select the type of account (Checking, Savings, Investment, etc.).
6. Specify the type of transaction (Deposit, Withdrawal, Transfer, etc.).
7. Enter the date and time of the transaction (if applicable).
8. Enter the amount of the transaction (if applicable).
9. Provide any additional transaction details (if applicable).
10. Choose the authentication method (Document, Phone Call, Video Call, In-Person, etc.).
11. Provide any additional authentication details (if applicable).
12. Add any additional information relevant to the request.
13. Finally, submit the form to initiate the authentication request.

## Field-by-Field Explanation
* **Financial Record Authentication Request Form**: Select the type of financial record you are requesting to be authenticated.
* **Account Number**: Enter the account number associated with the financial record you are requesting to be authenticated.
* **Account Holder**: Select whether the account is held by an individual or a business.
* **Individual or Business**: Confirm the type of account holder (Individual or Business).
* **Financial Institution**: Choose the financial institution (Bank, Brokerage, Other) associated with the account.
* **Branch Location**: Select the branch location (Branch, Branch Office, Branch Office Location) where the account is held.
* **Account Type**: Choose the type of account (Checking, Savings, Investment, Other).
* **Transaction Type**: Select the type of transaction (Deposit, Withdrawal, Transfer, Other).
* **Date of Transaction**: Enter the date of the transaction (if applicable).
* **Time of Transaction**: Enter the time of the transaction (if applicable).
* **Amount of Transaction**: Enter the amount of the transaction (if applicable).
* **Transaction Details**: Provide any additional details about the transaction (if applicable).
* **Authentication Method**: Choose the method to authenticate the financial record (Document, Phone Call, Video Call, In-Person, etc.).
* **Authentication Details**: Provide any additional details about the authentication method (if applicable).
* **Additional Information**: Enter any other relevant information about the request.
* **Submit**: Select this option to submit the authentication request.
