# Business Listing Verification Status Check - Help Guide
## Purpose
The purpose of this form is to collect information about the status of business listings. It is used to track and manage the verification status of these listings.

## How To Complete This Form

1. **Enter Business name**: Please type the name of the business listing being verified. This is the name used on the platform where the listing is found.
2. **Platform**: Select the platform where the listing is located from the options provided.
3. **Claimed Status**: Select whether the listing has been claimed or remains unclaimed.
4. **Verification Method**: (Optional) Select the method used to verify the listing (e.g., Phone, Email, Postcard, Third party).
5. **Verification Date**: (Optional) Enter the date when the listing was verified.
6. **Verification Notes**: (Optional) Enter any additional notes about the verification process.

## Field-by-Field Explanation

* **Business name** (`business_name`, text, required): The name of the business listing being verified.
* **Platform** (`platform`, text, required): The platform where the listing is located.
* **Claimed Status** (`claimed_status`, select_one, required): Select whether the listing has been claimed or remains unclaimed.
* **Verification Method** (`verification_method`, select_one, optional): The method used to verify the listing (e.g., Phone, Email, Postcard, Third party).
* **Verification Date** (`verification_date`, date, optional): The date when the listing was verified.
* **Verification Notes** (`verification_notes`, text, optional): Additional notes about the verification process.

## Tips
* Make sure to fill in all required fields before submitting the form.
* If a field is optional, provide the information only if it's relevant to your submission.
* Ensure that the business listing information is accurate to the best of your knowledge.
