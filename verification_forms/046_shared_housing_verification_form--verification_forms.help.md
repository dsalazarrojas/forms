# Shared Housing Verification Form - Help Guide

## Purpose

This form is used to verify the details of shared housing arrangements, including start and end dates, roommate information, and other relevant details.

## How To Complete This Form

1. Fill out the form completely and accurately to ensure that all necessary information is included.
2. Enter the landlord's name in the "landlord name" field.
3. Enter the address of the shared housing location.
4. Select the start and end dates of the shared housing arrangement.
5. Enter the name and contact information of the roommates.
6. Select the type of shared housing agreement and term of the agreement.
7. Enter the date the roommates moved in and out, if applicable.
8. Provide a reason for moving out, if applicable.
9. Add any additional notes about the shared housing agreement.
10. Select the verification method used to complete the form.

## Field-by-Field Explanation

* **Landlord Name** (landlord_name, text, required): Enter the name of the landlord or property manager.
* **Address** (address, text, required): Enter the address of the shared housing location.
* **Start Date** (start_date, date, required): Enter the date the shared housing arrangement began.
* **End Date** (end_date, date, required): Enter the date the shared housing arrangement ended.
* **Roommates Name** (room_mates_name, text, required): Enter the names of the roommates.
* **Roommates Phone** (room_mates_phone, text, required): Enter the phone numbers of the roommates.
* **Roommates Email** (room_mates_email, email, required): Enter the email addresses of the roommates.
* **Shared Housing Agreement Type** (shared_housing_agreement_type, select_one, required): Select the type of shared housing agreement.
* **Agreement Term** (agreement_term, select_multiple, required): Select the terms of the shared housing agreement.
* **Move In Date** (move_in_date, date): Enter the date the roommates moved in, if applicable.
* **Move Out Date** (move_out_date, date): Enter the date the roommates moved out, if applicable.
* **Reason for Move Out** (reason_for_move_out, text): Provide a reason for moving out, if applicable.
* **Roommates Note** (room_mates_note, note, required): Add any additional notes about the roommates.
* **Shared Housing Agreement Note** (shared_housing_agreement_note, note, required): Add any additional notes about the shared housing agreement.
* **Verification By** (verification_by, select_one, required): Select the method used to verify the form.
