# property_lease_verification_form - Help Guide
## Purpose
This form is used to gather information for property lease verification.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Tenant Info page:
	* Enter the tenant's information in the provided text field.
2. Move on to the Lease Details page:
	* Select the relevant lease details from the dropdown menu.
3. Continue to the Tenant Experience page:
	* Select the relevant tenant experience from the dropdown menu.
4. Complete the Property Info page:
	* Enter the property's information in the provided text field.
5. Proceed to the Tenant References page:
	* Select the relevant tenant references from the dropdown menu.
6. Finish with the Lease End page:
	* Enter the lease end date in the provided date field.

## Field-by-Field Explanation

* **Tenant Info (Tenant Info, text, required: false)**: 
	+ Enter the tenant's name, address, and contact information.
* **Lease Details (Lease Details, select_multiple, required: false)**: 
	+ Choose one or more of the following options:
		- Lease Status: current or past
		- Lease Type: commercial or residential
		- Lease Length: short-term or long-term
		- Lease Terms: month-to-month or fixed-term
* **Tenant Experience (Tenant Experience, select_multiple, required: false)**: 
	+ Select one or more of the following options:
		- Rental History: past rental experience
		- Employment Status: employed or self-employed
		- Income Verification: verified or unverified
* **Property Info (Property Info, text, required: false)**: 
	+ Enter the property's address and details.
* **Tenant References (Tenant References, select_multiple, required: false)**: 
	+ Choose one or more of the following options:
		- Landlord Reference: reference from the landlord
		- Property Manager Reference: reference from the property manager
* **Lease End (Lease End, date, required: false)**: 
	+ Enter the lease end date in the YYYY-MM-DD format.
