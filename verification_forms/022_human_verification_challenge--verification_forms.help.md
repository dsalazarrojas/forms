# Human Verification Challenge - Help Guide
## Purpose
The Human Verification Challenge is a form designed to evaluate human users' ability to complete a series of challenges that verify their humanity. This form is used to assess the user's cognitive abilities and provide a way to verify that the user is not a bot. 

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the verification question on the first page, which asks "What is 1 + 1?". 
2. On the second page, select the correct answer to the challenge "I am not a bot" from the options provided.
3. On the last page, type your answer to the verification question "What is the color of your shirt".

## Field-by-Field Explanation
* **What is 1 + 1?** (`verification_challenge`, `text`, required/optional): Answer this question as you would any arithmetic question. For example, you can type "2" in the answer box.
* **I am not a bot** (`captcha_challenge`, `select_one`, required/optional): Select "I am human" to answer this challenge, as you are not a bot.
* **What is the color of your shirt** (`verification_question`, `text`, required/optional): Answer this question by typing the color of the shirt you are wearing. Please answer this question as accurately as possible.

## Tips
* Please note that this form is intended for human users only. If you are not human, please do not attempt to complete this form. 
* If you are having trouble completing any of the questions, please contact form@gic.mx for assistance.
