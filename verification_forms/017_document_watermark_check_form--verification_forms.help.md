# Document Watermark Check Form - Help Guide
## Purpose
The purpose of this form is to verify whether a document has a digital watermark.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Select the type of document you are checking for a watermark from the options provided.
2. If the document has a watermark, fill in the date of the document.
3. If the document has a watermark, fill in the name of the requester.
4. If the document has a watermark, fill in the review request.
5. You are not required to fill in any fields if the document does not have a watermark.

## Field-by-Field Explanation
- **Document with Watermark** (`document_watermark_check_form_1`, `select_one`, required/optional): Select this option if the document you are checking has a digital watermark.
  - Document with Watermark: This field is used to verify if the document has a watermark.
  - Document without Watermark: This is a default option to select if the document does not have a watermark.
- **Date** (`document_watermark_check_date`, `date`, required/optional): If you selected "Document with Watermark" in the previous field, please fill in the date of the document.
  - Enter the date the document was created or modified.
- **Requester** (`document_watermark_check_requester`, `text`, required/optional): If you selected "Document with Watermark" in the previous field, please fill in the name of the requester.
  - Enter the name of the person or organization that requested the document.
- **Reviewer** (`document_watermark_check_reviewer`, `text`, required/optional): This field is for the reviewer to fill in their name.
  - Enter your name as the reviewer.
- **Review Request** (`document_watermark_check_review`, `text`, required/optional): If you selected "Document with Watermark" in the previous field, please fill in any review request or comments.
  - Enter any additional comments or review requests.

## Tips
- Please fill in the fields only if the document has a digital watermark.
- If you are unsure about any field, simply select "Document without Watermark" and submit the form.
- This form is meant to be a quick and simple way to verify documents for watermarks.
