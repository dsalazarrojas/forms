# Product Certification Renewal Application Form - Help Guide
## Purpose
This form is used to renew the certification of a product, ensuring that all relevant information is up-to-date and accurate. Please complete this form if your product requires certification renewal.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct status of your product from the "Product Details" page.
2. Choose the correct "Prophet" from the "Prophet" page.
3. Enter the product's details, such as name and type, in the "Product Info", "Address", and "Product Type" pages.
4. Enter the product's expiration date in the "Expiration Date" page.
5. Provide a description of the product's purpose and goals in the "Description" page.
6. Enter the contact information for the product's owner or representative in the "Contact Info" page.

## Field-by-Field Explanation
* **Form Submission**: This page is used to submit the completed form. Please review your answers carefully before submitting the form.
* **Product Details**: This page asks you to select the status of your product, whether it is Certified, Non-Certified, or Pending. Please choose the correct status.
* **Prophet**: This page asks you to choose the correct "Prophet" for the product. Please select one of the options: John, Jane, or Doe.
* **Product Info**: This page asks for the product's name and other relevant details. Please enter the correct information.
* **Address**: This page asks for the product's address. Please enter a valid address.
* **Product Type**: This page asks for the product's type. Please enter a valid type.
* **Certification Type**: This page asks for the type of certification the product requires. Please enter a valid type.
* **Expiration Date**: This page asks for the product's expiration date. Please enter a valid date.
* **Description**: This page asks for a description of the product's purpose and goals. Please enter a clear and concise description.
* **Contact Info**: This page asks for the contact information for the product's owner or representative. Please enter a valid address and contact details.
* **Address**: This page asks for the product's address. Please enter a valid address.
* **Product Name**: This page asks for the product's name. Please enter a valid name.
