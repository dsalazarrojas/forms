# Practitioner Signature Verification - Help Guide

## Purpose
This form is used to verify the signature of a practitioner as part of the onboarding process or when the practitioner's status changes.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the practitioner's information:
   * First Name: Enter the first name of the practitioner.
   * Last Name: Enter the last name of the practitioner (required).
   * Title: Enter the practitioner's title.
   * Date Of Birth: Enter the date of birth of the practitioner (required).
   * Date Of Verification: Enter the date of the verification (required).
   * Signature Type: Select the type of signature the practitioner is verifying (required).
   * Other signature type fields are optional and can be left blank.
2. Upload relevant files:
   * Photo: Upload a photo of the practitioner's identification.
   * Verification File: Upload a file verifying the practitioner's identification.
   * Signature File: Upload a file of the practitioner's signature.
   * Medical License Number: Upload a file containing the practitioner's medical license number.
   * Medical License Type: Upload a file containing the practitioner's medical license type.
   * Date of Renewal: Upload a file containing the date of the practitioner's medical license renewal.
   * Signature File Type: Select the type of signature file uploaded.
   * Medical License Status: Select the status of the practitioner's medical license.
   * Signature Verification Status: Select the status of the practitioner's signature verification.
   * Verification Record ID: Upload a file containing the verification record ID.
   * Verification Status: Select the status of the verification record.
   * Verification Date: Upload a file containing the verification date.
   * Verified By: Upload a file containing the name of the person who verified the practitioner.
   * Uploaded By: Upload a file containing the name of the person who uploaded the file.
   * Notes: Add any additional notes about the verification process.
   * Medical License Type: Select the type of medical license the practitioner holds.
   * Signature File Type: Select the type of signature file uploaded.
   * Medical License Status: Select the status of the practitioner's medical license.
   * Signature Verification Status: Select the status of the practitioner's signature verification.
