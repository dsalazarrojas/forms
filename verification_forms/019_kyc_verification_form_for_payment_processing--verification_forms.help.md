# KYC Verification Form For Payment Processing - Help Guide
## Purpose
This form is used to collect merchant verification information for payment processing. 

## How To Complete This Form
1. Fill out the merchant name field with the name of the merchant.
2. Enter the merchant's address in the merchant address field.
3. Provide the merchant's phone number in the merchant phone field.
4. Enter the merchant's email address in the merchant email field.
5. Select the type of document required for verification in the document type field. For example, Merchant ID, Business License, Proof of Address, etc.
6. Upload the document file in the document file field.
7. If required, enter the date of birth in the date of birth field.

## Field-by-Field Explanation

* **Merchant Name (merchant_name, text, required)**: Enter the name of your merchant in this field.
* **Merchant Address (merchant_address, text, required)**: Enter your merchant's address in this field.
* **Merchant Phone (merchant_phone, text, required)**: Enter your merchant's phone number in this field.
* **Merchant Email (merchant_email, email, required)**: Enter your merchant's email address in this field. Please note that this field requires a valid email format.
* **Document Type (doc_type, select_one, required)**: Select the type of document required for verification. This field is used to indicate what type of document you are uploading in the document file field. Examples include Merchant ID, Business License, Proof of Address, etc.
* **Document File (doc_file, text, required)**: Upload the document file that corresponds to the selected document type. Please note that the file type and size may be restricted.
* **Date of Birth (date_of_birth, date, optional)**: If applicable, enter the date of birth of the merchant or the representative who is submitting this form. This field is optional but may be required for certain verification purposes. 

## Tips
* Ensure that you have the necessary authority to submit this form on behalf of the merchant. 
* Make sure to upload a valid document that corresponds to the selected document type.
* Double-check that all fields are completed correctly before submitting the form.
