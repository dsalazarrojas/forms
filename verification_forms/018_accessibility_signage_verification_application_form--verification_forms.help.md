# Accessibility Signage Verification Application Form - Help Guide
## Purpose
This form is designed to ensure that facilities meet accessibility standards and provide a safe and accessible environment for individuals with disabilities.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with the requested information.
2. For fields with multiple options, select the relevant choices that apply to your facility.
3. For fields that require dates, use the format MM/DD/YYYY.
4. Please ensure that all fields are filled out accurately and completely to avoid any delays in the verification process.

## Field-by-Field Explanation
- **Applicant Name** (1, text, required): Full name of the person applying for verification.
- **Applicant Title** (2, text, required): Job title or role of the person applying for verification.
- **Organization Name** (3, text, required): Name of the organization requesting verification.
- **Organization Address** (4, text, required): Complete address of the organization.
- **Contact Email** (5, email, required): Email address for correspondence.
- **Contact Phone** (6, text, required): Phone number for correspondence.
- **Facility Name** (7, text, required): Name of the facility requiring signage verification.
- **Facility Address** (8, text, required): Complete address of the facility to be verified.
- **Facility Type** (9, select_one, required): What type of facility is being verified? (e.g. Commercial Building, Educational Institution, etc.)
- **Verification Scope** (10, select_multiple, required): What areas of the facility require signage verification? (e.g. Main entrances, interior pathways, etc.)
- **Signage Types Included** (11, select_multiple, required): What types of signage are included in this verification? (e.g. Directional signs, Room identification, etc.)
- **Accessibility Standards Applied** (12, select_multiple, required): Which accessibility standards are being verified against? (e.g. ADA Standards, ICC A117.1, etc.)
- **Verification Reason** (13, select_one, required): Why is this verification being requested? (e.g. New construction, Renovation, etc.)
- **Verification Timeline** (14, select_one, required): When is the verification needed? (e.g. Immediately, Within 1 week, etc.)
- **Current Signage Assessment** (15, select_one, required): How would you rate the current state of accessibility signage? (e.g. Excellent, Good, etc.)
- **Previous Verification Date** (16, date, optional): When was the last accessibility signage verification performed? (format MM/DD/YYYY)
- **Known Deficiencies** (17, text, optional): Are there any known deficiencies in current signage?
- **Budget Allocation** (18, select_one, required): What budget has been allocated for signage improvements? (e.g. Under $5,000, $15,000-$30,000, etc.)
- **Special Considerations** (19, text, optional): Are there any special considerations for this verification?
- **Applicant Signature** (20, text, required): Electronic signature of the applicant.
- **Signature Date** (21, date, required): Date of application submission.

## Tips
- Please ensure that all fields are filled out accurately and completely.
- If you are unsure about any field, please ask for clarification.
- Please note that this form is for informational purposes only and should not be used for any other purpose.
