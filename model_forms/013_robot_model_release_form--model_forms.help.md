# Robot Model Release Form - Help Guide
## Purpose
The Robot Model Release Form is a document that captures the essential information needed for the release of a robot model. This form helps ensure that all relevant details are recorded for reproducibility, accountability, and compliance purposes.

## How To Complete This Form
1. Enter the title of the robot model in the `Robot Model Name` field.
2. Choose the appropriate category for the project, event, or media that the model is associated with from the `Project/Event/Media` field.
3. Provide a brief description of the robot model in the `Robot Model Description` field.
4. Enter the project location, event location, or media location associated with the model in the respective `Project Location`, `Event Location`, and `Media Location` fields.
5. Enter the date of approval for the model in the `Approvals` field.
6. Attach a relevant image of the model in the `Robot Model Image` field.
7. Enter the email and phone number of the approver in the `Approval Email` and `Approval Phone` fields.
8. Add any additional notes or comments about the model in the `Robot Model Notes` field.
9. Select whether the project, event, or media approvals are required for the model.
10. Fill in any additional fields only if necessary or if the model requires special approvals.

## Field-by-Field Explanation

* **Robot Model Name** (`robot_model_name`, text, required): Enter the name of the robot model.
* **Project/Event/Media** (`project_event_media`, select_multiple, required): Choose the category that the model is associated with (project, event, or media).
* **Robot Model Description** (`robot_model_description`, text, required): Briefly describe the robot model.
* **Project Location** (`project_location`, text, required): Enter the location associated with the project.
* **Event Location** (`event_location`, text, required): Enter the location associated with the event.
* **Media Location** (`media_location`, text, required): Enter the location associated with the media.
* **Approvals** (`approvals`, date, required): Enter the date of approval for the model.
* **Robot Model Image** (`robot_model_image`, note, required): Attach a relevant image of the model.
* **Approval Email** (`approval_email`, email, required): Enter the email of the approver.
* **Approval Phone** (`approval_phone`, text, required): Enter the phone number of the approver.
* **Robot Model Notes** (`robot_model_notes`, text, optional): Add any additional notes about the model.
* **Project Approvals** (`project_approvals`, select_multiple, optional): Select whether project approvals are required for the model.
* **Event Approvals** (`event_approvals`, select_multiple, optional): Select whether event approvals are required for the model.
* **Media Approvals** (`media_approvals`, select_multiple, optional): Select whether media approvals are required for the model.

## Tips
- Make sure to enter accurate and detailed information about the model.
- Ensure that you have the approver's email and phone number correct.
- Attach an image that clearly shows the model.
- Review this form carefully before submitting it to ensure all required and optional fields are filled out correctly.
