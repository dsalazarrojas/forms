# Model Search Form - Help Guide
## Purpose
The Model Search Form is designed to collect information from users for the purpose of searching models. Fill out the form with the necessary details to get an accurate and relevant search result.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: "Fashion Designer", "Production Company", "Clothing Shop", and "Email", and "Phone" fields.
2. For non-required fields, you can optionally fill in any information you have about the model.
3. Make sure to select the correct options for each field as instructed in the "Field-by-Field Explanation" section.

## Field-by-Field Explanation
### 1. Fashion Designer (Required)
* **Fashion Designer**: Enter the name of the fashion designer you are looking for.
*   Enter the name of the designer, e.g., "John Doe".

### 2. Production Company (Required)
* **Production Company**: Enter the name of the production company associated with the model.
*   Enter the name of the production company, e.g., "ABC Corporation".

### 3. Clothing Shop (Optional)
* **Clothing Shop**: Enter the name of the clothing shop associated with the model.
*   Enter the name of the clothing shop, e.g., "Shop XYZ".

### 4. Clothing Type (Optional)
* **Clothing Type**: Select "Yes" if the model is a clothing type that you are interested in.
*   Select "No" if the model is not a clothing type that you are interested in.

### 5. Model Height (Optional)
* **Model Height**: Enter the model's height in inches or centimeters.
*   Enter a numerical value for the model's height, e.g., "60" (60 inches) or "150" (150 centimeters).

### 6. Model Weight (Optional)
* **Model Weight**: Enter the model's weight in pounds or kilograms.
*   Enter a numerical value for the model's weight, e.g., "120" (120 pounds) or "50" (50 kilograms).

### 7. Date of Birth (Optional)
* **Date of Birth**: Enter the model's date of birth.
*   Enter a date in the format "mm/dd/yyyy", e.g., "01/01/1990".

### 8. Time of Day (Optional)
* **Time of Day**: Enter the time of day the model was photographed.
*   Enter a time in the format "HH:MM AM/PM", e.g., "02:15 PM".

### 9. Notes (Optional)
* **Notes**: Enter any additional information about the model.
*   Enter a brief description of the model, e.g., "Model with great smile".

### 10. Email (Required)
* **Email**: Enter the model's email address.
*   Enter the email address, e.g., "john.doe@example.com".

### 11. Phone (Required)
* **Phone**: Enter the model's phone number.
*   Enter a numerical value for the model's phone number, e.g., "123-456-7890".

### 12. Select Multiple (Required)
* **Select Multiple**: Select all the options that apply to the model.
*   Select "Yes" for each option that applies to the model.

### 13. Time of Shoot (Optional)
* **Time of Shoot**: Enter the time of the photoshoot.
*   Enter a date in the format "mm/dd/yyyy", e.g., "01/01/2020".

### 14. Select One (Optional)
* **Select One**: Select one option for the model.
*   Select "Yes" or "No" for the model.

### 15. Select Date (Optional)
* **Select Date**: Enter the date for the model.
*   Enter a date in the format "mm/dd/yyyy", e.g., "01/01/2020".

### 16. Select Time (Optional)
* **Select Time**: Enter the time for the model.
*   Enter a time in the format "HH:MM AM/PM", e.g., "02:15 PM".

## Tips
* Make sure to fill out all the required fields.
* Be as specific as possible when filling out the non-required fields.
* If you are unsure about any field, refer to the explanations above.
