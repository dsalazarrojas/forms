# Model And Production Liability Release Form - Help Guide
## Purpose
This form is designed to collect information about participants and models involved in a project, including their consent to release models for production use.

## How To Complete This Form

1. **Fill out each section thoroughly and accurately**. Ensure that you provide all required and optional information.
2. **Review the form carefully before submitting**. If you are unsure about any part of the form, don't hesitate to ask.
3. **Be truthful and honest in your responses**. Providing inaccurate information can lead to delays or issues with the release process.

## Field-by-Field Explanation

* **Participant Info**: This section is for providing basic information about the participant, including their name, project ID, and other relevant details.
* **Project Info**: This section is for providing information about the project, including its title, description, and other relevant details.
* **Participant Consent**: This question asks if you are willing to release your model for production use. Please answer "I am willing" or "I am not willing" accordingly.
* **Model Info**: This section is for providing information about the model, including its name, version, and other relevant details.
* **Signature**: This section is for selecting one or more models that you are releasing.
* **Date of Capture**: This is the date when the model was captured or created.
* **Time of Capture**: This is the time when the model was captured or created.
* **Location**: This is the location where the model was captured or created.
* **Model Release Info**: This section is for providing any additional information about the model's release.
* **Participant Release Info**: This section is for providing any additional information about the participant's release.
* **Release Date**: This is the date when the model is expected to be released for production use.
* **Release Time**: This is the time when the model is expected to be released for production use.
* **Project Release Info**: This section is for providing any additional information about the project's release.
* **Production Release Info**: This section is for providing any additional information about the production release.
* **Project Manager Release Info**: This section is for providing any additional information about the project manager's release.
* **Participant Signature**: This is a text field for the participant to sign their name.
* **Model Release Signature**: This is a text field for the model to sign their name.
* **Participant Consent Date**: This is the date when the participant gave their consent to release the model.
* **Production Consent Date**: This is the date when the production team gave their consent to release the model.
* **Project Manager Consent Date**: This is the date when the project manager gave their consent to release the model.
* **Participant Consent**: This question asks if you are willing to release your model for production use. Please answer "I am willing" or "I am not willing" accordingly.
* **Production Consent**: This question asks if the production team is willing to release the model for production use. Please answer "I am willing" or "I am not willing" accordingly.
