# Model Casting Form - Help Guide
## Purpose
This form is designed to collect and manage information about models for casting purposes. It is used to gather details about a model's availability, skills, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Model Casting Form" from the available forms.
2. Fill out each page of the form, which includes fields for casting agency, model information, contact number, contact email, and more.
3. Make sure to fill out all required fields.
4. Review your completed form before submitting it for casting purposes.

## Field-by-Field Explanation

* **Casting Agency**: Enter the name of the agency handling the model casting. This field is required.
* **Model Information**: Provide a brief description of the model. This field is optional.
* **Contact Number**: Enter the model's contact phone number. This field is required.
* **Contact Email**: Enter the model's email address. This field is optional.
* **Contact Person**: Enter the name of the person to contact. This field is required.
* **Project Info**: Provide a brief description of the project. This field is required.
* **Project Details**: Add any additional project details if necessary. This field is optional.
* **Shoot Date**: Enter the date of the shoot. This field is optional.
* **Shoot Time**: Enter the time of the shoot. This field is optional.
* **Shoot Location**: Enter the location of the shoot. This field is optional.
* **Project Budget**: Enter the budget for the project. This field is required.
* **Project Type**: Select the type of project from the available options. This field is required.
* **Shoot Duration**: Enter the duration of the shoot. This field is required.
* **Shoot Notes**: Add any notes about the shoot. This field is required.
* **Model Requirements**: List any requirements for the model. This field is optional.
* **Model Description**: Describe the model. This field is optional.
* **Casting Agent**: Identify the agent handling the model casting. This field is optional.
* **Agency Phone**: Enter the agency's phone number. This field is optional.
* **Agency Email**: Enter the agency's email address. This field is required.
* **Agency Address**: Enter the agency's address. This field is optional.
* **Agency Notes**: Add any agency notes. This field is optional.
* **Model Name**: Enter the model's name. This field is required.
* **Model Contact Info**: Enter the model's contact information. This field is required.
* **Model Availability**: List the model's availability. This field is optional.
* **Model Education**: List the model's education. This field is optional.

## Tips
* Make sure to fill out all required fields.
* Double-check your completed form before submitting it.
* If you have any questions or concerns, contact the relevant agency or casting team.
