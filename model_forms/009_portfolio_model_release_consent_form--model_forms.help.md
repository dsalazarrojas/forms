# Portfolio Model Release Consent Form - Help Guide
## Purpose
This form is designed to collect the necessary information for a model release consent from a photographer to a model.

## How To Complete This Form
1. Fill in the model's name in the **model_name** field.
2. Select whether the **portfolio_release** field is "Yes" or "No" to indicate the release status.
3. Enter the **photographer_name** field with the photographer's name.
4. Enter the **photographer_contact** field with the photographer's contact information.
5. Enter the **model_contact** field with the model's contact information.
6. Enter the **photographer_address** field with the photographer's address.
7. Enter the **photographer_city** field with the city where the photographer is located.
8. Enter the **photographer_state** field with the state where the photographer is located.
9. Enter the **photographer_country** field with the country where the photographer is located.
10. Enter the **photographer_postal** field with the photographer's postal code.
11. Enter the **model_address** field with the model's address.
12. Enter the **model_city** field with the city where the model is located.
13. Enter the **model_state** field with the state where the model is located.
14. Enter the **model_country** field with the country where the model is located.
15. Enter the **model_postal** field with the model's postal code.
16. Select the **signed_date** field to indicate the date the consent was signed.
17. Enter the **photographer_signature** field with the photographer's signature.
18. Enter the **model_signature** field with the model's signature.
19. Enter the **release_statement** field to describe the release statement.
20. Select whether the **photographer_agreement** field is "Yes" or "No" to indicate the agreement status.
21. Select whether the **model_agreement** field is "Yes" or "No" to indicate the agreement status.
22. Enter the **date_signed** field to indicate the date the agreement was signed.

## Field-by-Field Explanation

* **model_name**: Enter the model's name.
* **portfolio_release**: Select whether the portfolio release is "Yes" or "No".
* **photographer_name**: Enter the photographer's name.
* **photographer_contact**: Enter the photographer's contact information.
* **model_contact**: Enter the model's contact information.
* **photographer_address**: Enter the photographer's address.
* **photographer_city**: Enter the city where the photographer is located.
* **photographer_state**: Enter the state where the photographer is located.
* **photographer_country**: Enter the country where the photographer is located.
* **photographer_postal**: Enter the photographer's postal code.
* **model_address**: Enter the model's address.
* **model_city**: Enter the city where the model is located.
* **model_state**: Enter the state where the model is located.
* **model_country**: Enter the country where the model is located.
* **model_postal**: Enter the model's postal code.
* **signed_date**: Select the date the consent was signed.
* **photographer_signature**: Enter the photographer's signature.
* **model_signature**: Enter the model's signature.
* **release_statement**: Enter a description of the release statement.
* **photographer_agreement**: Select whether the photographer's agreement status is "Yes" or "No".
* **model_agreement**: Select whether the model's agreement status is "Yes" or "No".
* **date_signed**: Select the date the agreement was signed.

## Tips

* Make sure to fill in all required fields to ensure accurate documentation.
* Review the fields carefully before submission to avoid errors.
* Ensure that the model and photographer have read and agreed to the release statement.
* Store the form securely to protect sensitive information.
