# Photography Spokesmodel Application - Help Guide
## Purpose
The Photography Spokesmodel Application form is designed to collect essential information from users who wish to apply for modeling opportunities. This form will help us to understand your physical characteristics, experience, and qualifications.

## How To Complete This Form
1. Please fill out each field accurately and completely.
2. Make sure to select the correct options for your physical characteristics and qualifications.
3. Upload your photo, resume, and profile picture as required.
4. Submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation

* **title** (`text`, required/optional): Please enter a brief title for your application, such as "Photography Model Application."
* **contact_info** (`text`, required/optional): Enter your contact information, including your name, email address, and phone number.
* **photo_info** (`text`, required/optional): Provide a brief description of your experience and qualifications as a model.
* **model_info** (`text`, required/optional): Enter any additional information about yourself as a model.
* **email** (`email`, required/optional): Enter your email address.
* **phone** (`text`, required/optional): Enter your phone number.
* **address** (`text`, required/optional): Enter your address.
* **upload_photo** (`text`, required/optional): Upload a photo of yourself.
* **upload_resume** (`text`, required/optional): Upload your resume.
* **upload_profile_pic** (`text`, required/optional): Upload a profile picture.
* **date** (`date`, required/optional): Enter the date you are available to work.
* **time** (`time`, required/optional): Enter the time you are available to work.
* **select_model_type** (`select_one`, required): Select "Yes" if you are a model and "No" if you are not.
* **select_model_height** (`select_one`, required): Select "Yes" if you have a certain height and "No" if you do not.
* **select_model_ethnicity** (`select_one`, required): Select "Yes" if you belong to a certain ethnicity and "No" if you do not.
* **select_model_age** (`select_one`, required): Select "Yes" if you are of a certain age and "No" if you are not.
* **select_model_hair_color** (`select_one`, required): Select "Yes" if you have a certain hair color and "No" if you do not.
* **select_model_eye_color** (`select_one`, required): Select "Yes" if you have a certain eye color and "No" if you do not.
* **select_model_hair_style** (`select_one`, required): Select "Yes" if you have a certain hair style and "No" if you do not.
* **select_model_height** (`select_one`, required): Select "Yes" if you have a certain height and "No" if you do not.
* **select_model_weight** (`select_one`, required): Select "Yes" if you have a certain weight and "No" if you do not.
* **select_model_shoe_size** (`select_one`, required): Select "Yes" if you wear a certain shoe size and "No" if you do not.
* **select_model_gender** (`select_one`, required): Select "Yes" if you are a certain gender and "No" if you are not.
* **select_model_special_skills** (`select_multiple`, required): Select "Yes" if you have a certain special skill and "No" if you do not.

Note: All fields marked as "optional" are still required to be filled out to ensure a complete application.
