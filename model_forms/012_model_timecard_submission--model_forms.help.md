# model_timecard_submission - Help Guide
## Purpose
This form is used for submitting timecard information for your work hours, job details, agency, and production team.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the timecard you are submitting.
2. Enter the number of hours you worked on the selected date.
3. Provide a brief description of the job details, including any relevant information about the project or task.
4. Enter the name of the agency associated with your work.
5. Enter the name of the production team you worked with.

## Field-by-Field Explanation
* **Work Date** (`work_date`, date, **optional**): Select the date for which you are submitting your timecard information.
* **Hours Worked** (`hours_worked`, number, **optional**): Enter the total number of hours you worked on the selected date.
* **Job Details** (`job_details`, text, **optional**): Provide a brief description of the job details, including any relevant information about the project or task.
* **Agency** (`agency`, text, **optional**): Enter the name of the agency associated with your work.
* **Production Team** (`production_team`, text, **optional**): Enter the name of the production team you worked with.

## Tips
- Make sure to select the correct date for the timecard you are submitting.
- Double-check that the hours you enter are accurate.
- Provide as much detail as possible for job details and agency fields.
- If you need to submit multiple timecards, please use the same form to submit each one, making sure to select the correct date for each submission.
