# Charity Run Volunteer Application Form - Help Guide
## Purpose
The Charity Run Volunteer Application Form is designed to collect information from potential volunteers for a specific charity run event. By completing this form, you can express your interest in participating in the event and help make it a success.

## How To Complete This Form
- Please fill out the form completely and accurately.
- Ensure that all required fields are filled out.
- If you have any questions or concerns, feel free to reach out to us.

## Field-by-Field Explanation
### 1. First Name
* **First Name**: Your first name.
*   Type: text, required: true

### 2. Last Name
* **Last Name**: Your last name.
*   Type: text, required: true

### 3. Email Address
* **Email Address**: For volunteer communications. Please provide a valid email address.
*   Type: email, required: true

### 4. Phone Number
* **Phone Number**: Best contact number. Please provide a valid phone number.
*   Type: text, required: true

### 5. Date of Birth
* **Date of Birth**: MM/DD/YYYY. If you don't know your date of birth, please leave it blank.
*   Type: date, required: false

### 6. Charity Run Event Name
* **Charity Run Event Name**: Which charity run are you volunteering for.
*   Type: text, required: true

### 7. Event Date
* **Event Date**: When is the charity run.
*   Type: date, required: true

### 8. Hours Available
* **Hours Available**: How many hours can you volunteer.
*   Type: number, required: true

### 9. Time Preferences
* **Time Preferences**: Early morning, afternoon, evening, or flexible.
*   Type: select_one, required: true

### 10. Can You Work Specific Shifts
* **Can You Work Specific Shifts**: Yes, full day, yes, specific shifts, or no, just one shift.
*   Type: select_one, required: true

### 11. Preferred Volunteer Role
* **Preferred Volunteer Role**: Course monitor, water station staff, registration, parking, finish line, or general support.
*   Type: select_one, required: true

### 12. Experience with This Type of Role
* **Experience with This Type of Role**: Yes, extensive, yes, some, no, but willing to learn, or no.
*   Type: select_one, required: false

### 13. Special Skills or Certifications
* **Special Skills or Certifications**: CPR, medical, language, etc.
*   Type: text, required: false

### 14. Able to Handle Physical Demands
* **Able to Handle Physical Demands**: Yes, fully able, yes, with limitations, or no.
*   Type: select_one, required: true

### 15. Do You Need Transportation
* **Do You Need Transportation**: No, own transportation, or yes, need transportation.
*   Type: select_one, required: true

### 16. Dietary Restrictions or Allergies
* **Dietary Restrictions or Allergies**: For volunteer meals.
*   Type: text, required: false

### 17. Date of Application
* **Date of Application**: Today's date.
*   Type: date, required: true

## Tips
- Please ensure that all required fields are filled out.
- If you have any questions or concerns, feel free to reach out to us.
- We will review your application and get back to you soon.
