# Volunteer Sports Official Application - Help Guide
## Purpose
This form is designed for individuals who wish to apply to become a volunteer sports official. It gathers basic contact information, personal details, experience in various sports, emergency contact details, and a space for relevant skills and certifications.

## How To Complete This Form
1. Fill out the form carefully and accurately, providing all the required information.
2. Ensure you only submit one application per person.

## Field-by-Field Explanation

* **Contact Information** (Contact Information, text, required/optional): This section collects basic contact information, including your name and contact details.
* **Personal Details** (Personal Details, text, required/optional): This section is for you to provide a brief description of yourself and any relevant personal details.
* **Address** (Address, text, required/optional): Enter your address for contact and communication purposes.
* **Experience** (Experience, select_multiple, true): Select the sports in which you have experience, from the provided list.
* **Emergency Contact** (Emergency Contact, text, required/optional): Provide the contact information for a person who can be reached in case of an emergency.
* **Volunteer Info** (Volunteer Info, text, required/optional): Briefly describe why you want to volunteer as a sports official.
* **Skills & Certifications** (Skills & Certifications, text, required/optional): List any relevant skills and certifications you hold that would be beneficial as a sports official.
* **Referee Code of Conduct** (Referee Code of Conduct, note, true): Read and acknowledge the sports official's code of conduct, a set of principles that guides your behavior as a sports official.
