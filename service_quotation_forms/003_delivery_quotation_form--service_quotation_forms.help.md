# Delivery Quotation Form - Help Guide
## Purpose
The "Delivery Quotation Form" is designed to capture information about deliveries, allowing administrators to efficiently manage delivery requests from customers. This form collects relevant data such as customer details, delivery date, product details, and more.

## How To Complete This Form
To complete the "Delivery Quotation Form", follow these steps:

1. Fill in the **Customer Name** field with the customer's name.
2. Enter the **Customer Address** in the respective field.
3. Add the customer's **Phone Number** in the **Customer Phone** field.
4. Select the **Delivery Date** from the calendar or select a date from the provided options.
5. Choose the **Delivery Time** from the clock or select a time from the provided options.
6. Select the **Product** required (e.g., "Yes" or "No").
7. Enter the desired **Quantity** in the field.
8. Enter the **Price** of the delivery.
9. Add any **Notes** about the delivery in the text area.
10. Enter the **Email** address of the customer.
11. Add any **Customer Message** to the customer.
12. Select the **Assigned User** responsible for the delivery.
13. Select the **Delivery Status** (e.g., "Active" or "Inactive").
14. Choose the **Delivery Status Options** (e.g., "Option 1" or "Option 2").
15. Select the **Customer Status** (e.g., "Active" or "Inactive").
16. Choose the **Customer Status Options** (e.g., "Option 1" or "Option 2").
17. Enter the **Assigned Tool** used for the delivery.
18. Select the **Created At** date and time of the delivery request.
19. Select the **Updated At** date and time of the last update.
20. Enter the **Assigned By** user.
21. Enter the **Assigned To** user.
22. Select the **Assigned At** date and time of assignment.
23. Select the **Status** of the delivery (e.g., "Active" or "Inactive").
24. Choose the **Status Options** (e.g., "Option 1" or "Option 2").

## Field-by-Field Explanation
* **Customer Name**: Enter the customer's name.
* **Customer Address**: Enter the customer's address.
* **Customer Phone**: Enter the customer's phone number.
* **Delivery Date**: Select the date of the delivery.
* **Delivery Time**: Select the time of the delivery.
* **Product**: Select if the product is required ("Yes" or "No").
* **Quantity**: Enter the quantity of the delivery.
* **Price**: Enter the price of the delivery.
* **Notes**: Add any notes about the delivery.
* **Email**: Enter the customer's email address.
* **Customer Message**: Add a message to the customer.
* **Assigned User**: Select the user responsible for the delivery.
* **Delivery Status**: Select the status of the delivery (e.g., "Active" or "Inactive").
* **Delivery Status Options**: Select the status options for the delivery.
* **Customer Status**: Select the status of the customer (e.g., "Active" or "Inactive").
* **Customer Status Options**: Select the status options for the customer.
* **Assigned Tool**: Enter the tool used for the delivery.
* **Created At**: Select the date and time of the delivery request.
* **Updated At**: Select the date and time of the last update.
* **Assigned By**: Enter the user who assigned the delivery.
* **Assigned To**: Enter the user assigned to the delivery.
* **Assigned At**: Select the date and time of assignment.
* **Status**: Select the status of the delivery (e.g., "Active" or "Inactive").
* **Status Options**: Select the status options for the delivery.
