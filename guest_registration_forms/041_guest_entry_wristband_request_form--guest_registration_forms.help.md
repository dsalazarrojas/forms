# Guest Entry Wristband Request Form - Help Guide
## Purpose
This form is used to request a guest entry wristband for a specified event. The form is used by event staff to request wristbands for guests who are attending the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the relevant information for the guest.
2. Select the correct options for the wristband type and entry status.
3. Add any additional comments in the notes field.
4. Submit the form.

## Field-by-Field Explanation
* **FirstName** (Required): Enter the first name of the guest.
* **LastName** (Required): Enter the last name of the guest.
* **Email** (Required): Enter the email address of the guest.
* **EventName** (Required): Enter the name of the event.
* **WristbandType** (Optional): Select the type of wristband required for the guest. This field will appear only if the event is enabled to issue more than one type of wristband.
* **EventDate** (Required): Select the start date of the event.
* **EventEnd** (Required): Select the end date of the event.
* **EventStart** (Required): This field is used to track the start date of the event for internal use.
* **EventEnd** (Required): This field is used to track the end date of the event for internal use.
* **Approval** (Optional): Select the approval status for the guest entry wristband request. Options are Approve, Deny, and Review.
* **ApprovalNote** (Optional): Add any comments for the approval status.
* **FormId** (Optional): This field is for internal use and tracks the form ID.
* **CreatedAt** (Optional): This field is for internal use and tracks the created at timestamp.
* **UpdatedAt** (Required): This field is for internal use and tracks the updated at timestamp.
* **DeletedAt** (Optional): This field is for internal use and tracks the deleted at timestamp.
* **CreatedBy** (Required): Enter the ID of the user who created the form.
* **UpdatedBy** (Required): Enter the ID of the user who updated the form.
* **EntryStatus** (Optional): Select the status of the guest entry wristband request. Options are Approved, Waiting, and Denied.
* **EntryStatusNote** (Optional): Add any comments for the entry status.
* **Notes** (Optional): Add any additional notes for the guest entry wristband request.
* **WristbandQuantity** (Optional): Enter the number of wristbands required for the guest.
* **WristbandTypeApproved** (Optional, Note): This field is for internal use and is used to track the approved wristband type.
* **AssignedToolId** (Required): Enter the ID of the tool assigned to the guest.
* **GuestMessage** (Optional): Add any additional comments for the guest.
* **EventLocation** (Optional): Enter the location of the event.
* **EventTime** (Optional): Select the start time of the event.
