## Purpose

The Guest Communication System Pilot Registration Form is a critical tool for property owners and managers to provide accurate and up-to-date information about their properties, allowing for more efficient and personalized guest communication.

## How To Complete This Form

1. Please ensure you are registering your property only once. If you need to update any information, contact the system administrators for assistance.
2. Fill in the required fields carefully and accurately.
3. For properties with multiple team members, list each member under the 'Team Members' field.
4. Be cautious when selecting your submission confirmation method, as this determines how you'll receive updates about guest interactions.

## Field-by-Field Explanation

* **Property Name** (2, text, **required**): Enter the name of the property you are registering.
* **Property Type** (3, select_one, **required**): Select the type of property (e.g., Apartment, Condo, Hotel, House, Other).
* **Address** (4, text, **required**): Enter the property's street address.
* **City** (5, text, **required**): Enter the city where the property is located.
* **State** (6, text, **required**): Enter the state where the property is located.
* **Zip** (7, number, **required**): Enter the property's zip code.
* **Team Members** (8, select_multiple, **required**): List each team member at the property, including John, Jane, and None.
* **Notes** (9, note, **optional**): Leave notes about the property or any specific requests.
* **Email** (10, email, **required**): Enter the email address where you'd like to receive communications.
* **Phone** (11, text, **optional**): Enter the phone number where you can be reached.
* **Submission Confirmation** (12, select_one, **required**): Select whether you'd like to receive submission confirmations (True or False).
* **Submission Confirmation Method** (13, select_one, **required**): Select how you'd like to receive submission confirmations (Phone, Email, In-person).
* **Follow-up Method** (14, select_multiple, **required**): Select how you'd like to follow up with guests (True, False, None).

Please complete the form with accurate and up-to-date information to ensure seamless communication with your guests. If you have any questions or need assistance, don't hesitate to contact the system administrators.
