# Security Support Request Form - Help Guide
## Purpose
This form is designed to collect information about security incidents or issues that you would like the security team to be aware of.

## How To Complete This Form
1. Click on the "Submit" button at the bottom of the page to submit your request.
2. Fill out each section according to the instructions below.

## Field-by-Field Explanation

* **Incident Details (Required: No)**: Please provide a brief description of the incident or issue you would like to report. This will help the security team understand the context and take appropriate action.
* **Security Team (Required: No)**: If you would like to escalate the incident to a specific member of the security team, select their name from the list. If not, the incident will be reviewed by the team as a whole.
* **Type (Required: No)**: Please indicate whether the incident is related to a "Yes", "No", or if you are unsure. The security team will use this information to determine the urgency and priority of the incident.
* **Description (Required: No)**: If you would like to provide more information about the incident, please include any relevant details in this field.
* **Status (Required: No)**: Please select the current status of the incident (Active/Inactive) so the security team can prioritize and track it accordingly.
* **Priority (Required: No)**: Please indicate the level of priority for the incident (High/Medium/Low) so the security team can prioritize accordingly.
* **Date and Time (Required: No)**: Please select a date and time for the incident. The format for this field is MM/DD/YY HH:MM.
* **Incident Location (Required: No)**: If you would like to report an incident that occurred at a specific location, please provide the address or location name.
