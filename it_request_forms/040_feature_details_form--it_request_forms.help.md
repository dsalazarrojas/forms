# feature_details_form - Help Guide
## Purpose
The feature_details_form is used to collect information about features being worked on in your project.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the title of the feature in the **feature_details** field.
2. Select whether the feature is a **Yes** or **No** request type in the **request_type** field.
3. Add a brief description of the feature in the **description** field.
4. Select the current **status** of the feature from the options New, In Progress, or Completed.
5. Set the **priority** level of the feature using a number (e.g. 1-5).

## Field-by-Field Explanation
* **feature_details** (`feature_details`, text, optional): Enter a brief description of the feature.
* **request_type** (`request_type`, select_multiple, optional): Select whether the feature is a **Yes** or **No** request type.
* **description** (`description`, text, optional): Add a brief description of the feature.
* **status** (`status`, select_one, optional): Select the current status of the feature from the options New, In Progress, or Completed.
* **priority** (`priority`, number, optional): Set the priority level of the feature using a number (e.g. 1-5).

## Tips
* Ensure you only fill out this form once per feature to avoid duplication.
* Be as concise as possible when entering the description field to make it easier for others to read.
* If you are unsure about the status or priority of a feature, you can always ask the project manager for guidance.
