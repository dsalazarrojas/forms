# Request For Tags And Controls - Help Guide
## Purpose
The purpose of this form is to request additional tags and controls related to a specific item. It gathers information such as relevant tags, required controls, and comments about the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Request For Tags" field with a brief description of the item you are requesting tags for.
2. Select relevant tags from the list provided in the "Tags" field.
3. If necessary, select specific controls from the list provided in the "Controls" field.
4. Add any additional comments about the request in the "Comments" field.
5. Select the department responsible for the request from the list provided in the "Department" field.
6. Select the status of the request from the list provided in the "Status" field.
7. If applicable, select the tool assigned to the request from the list provided in the "Assigned Tool" field.
8. If desired, upload an output file in the "Output File" field.

## Field-by-Field Explanation

* **Request For Tags** (`request_for_tags`, text, required: false): This field is where you can type in a brief description of the item you are requesting tags for. 
* **Tags** (`tags`, select_multiple, required: false): Select the tags that are relevant to the item you are requesting. You can select multiple tags from the options provided.
* **Request For Controls** (`request_for_controls`, text, required: false): If you are requesting specific controls for the item, enter them here. 
* **Controls** (`controls`, select_one, required: false): Select the controls that are required for the item from the options provided.
* **Comments** (`comments`, text, required: false): Add any additional comments about the request here. 
* **Department** (`department`, select_one, required: false): Select the department that is responsible for the request from the options provided. 
* **Status** (`status`, select_one, required: false): Select the status of the request from the options provided. 
* **Assigned Tool** (`assigned_tool`, select_one, required: false): If applicable, select the tool that is assigned to the request from the options provided. 
* **Output File** (`output_file`, text, required: false): If desired, upload an output file related to the request.

## Tips
* Make sure to fill in all required fields, if any, to ensure your request is complete.
* Select only relevant tags and controls to avoid unnecessary information.
* Double-check the department and status fields to ensure accuracy.
* If you are unsure about any field, feel free to ask for clarification or guidance.
