# e_commerce_platform_api_request_form - Help Guide

## Purpose
This form is used to request access to the e-commerce platform's API (Application Programming Interface) and provide necessary contact information to the IT department. It is crucial to ensure that you have the necessary permissions and approvals within your organization before filling out this form.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your business integration details in the "business_integration_details" field.
2. Check "Yes" or "No" for each requested endpoint in the "requested_endpoints" field.
3. Check "Yes" or "No" for API access consent in the "consent" field.
4. Fill out the "api_access_info" field with notes or information about your API access request.
5. Provide your contact information in the "contact_info" field.
6. Check "Yes" or "No" for API access consent in the "api_access_consent" field.
7. Select the type of integration you are requesting in the "integration_type" field.
8. Choose the type of platform you are integrating with in the "platform_type" field.
9. Select any requested features in the "requested_features" field.
10. Fill out the "technical_contact", "business_contact", "it_contact", "product_contact", and "partnership_contact" fields with relevant contact information.
11. If applicable, fill out the "api_version" field with the API version you are requesting.
12. Choose the current status of your API in the "api_status" field.
13. Check "Yes" or "No" for API version information in the "api_version_info" field.

## Field-by-Field Explanation

* **Business Integration Details**: Enter a brief description of your business integration details.
* **Requested Endpoints**: Check "Yes" or "No" for each endpoint you are requesting access to. This field is optional.
* **Consent**: Check "Yes" or "No" to grant or deny API access consent.
* **API Access Info**: Enter notes or information about your API access request.
* **Contact Info**: Enter your contact information (email).
* **API Access Consent**: Check "Yes" or "No" to grant or deny API access consent.
* **Integration Type**: Select the type of integration you are requesting.
* **Platform Type**: Select the type of platform you are integrating with.
* **Requested Features**: Select any features you are requesting.
* **Technical Contact**: Enter your technical contact information.
* **Business Contact**: Enter your business contact information.
* **IT Contact**: Enter your IT contact information.
* **Product Contact**: Enter your product contact information.
* **Partnership Contact**: Enter your partnership contact information.
* **API Version**: Enter the API version you are requesting (if applicable).
* **API Status**: Choose the current status of your API.
* **API Version Info**: Check "Yes" or "No" for API version information.
