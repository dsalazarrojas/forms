# Systems Request Form - Help Guide
## Purpose
The Systems Request Form is a tool for users to submit requests for information or services related to systems. This form gathers necessary information about the system, customer, and request, as well as contact details of the person making the request.

## How To Complete This Form
1. To complete this form, please select the relevant pages for your request.
2. Fill in the form fields with the required information:
	* **System Information (Page 1)**: Enter a brief description of the system you are requesting information for.
	* **Request Information (Page 2)**: Provide a detailed description of the request you are making.
	* **Customer Information (Page 3)**: Enter the customer's information, if applicable.
	* **Request Details (Page 4)**: Add any additional details about the request.
	* **Requestor (Page 5)**: Enter your name and role related to the request.
	* **Requestor Email (Page 6)**: Enter your email address.
	* **Requestor Phone (Page 7)**: Enter your phone number.
	* **System Description (Page 8)**: Add any additional information about the system.
	* **Request Description (Page 9)**: Provide a detailed description of the request.
3. Click submit to send your request for further processing.
