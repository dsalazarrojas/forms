# video_game_workstation_requisition_form - Help Guide
## Purpose
The video game workstation requisition form is used to collect requests for computing systems used for gaming purposes. This form is for internal use only and should not be used for external purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the request details (page 1).
2. Select the department and type of workstation you require (page 2).
3. Specify the workstation details (page 3).
4. Fill in any additional information required, such as budget and approval comments (page 4).

## Field-by-Field Explanation

* **Request Details**:
	+ <page1_request_details> (text): Briefly describe your request.
* **User**:
	+ <page1_user> (text): Enter your username or name.
* **Department**:
	+ <page1_department> (select multiple):
		- IT: Information Technology department.
		- Management: Management department.
		- Finance: Finance department.
* **Workstation Details**:
	+ <page2_workstation_details> (text): Describe the workstation you are requesting.
* **Type**:
	+ <page2_type> (select one):
		- Gaming PC: A gaming PC workstation.
		- Mobile: A mobile workstation.
		- Laptop: A laptop workstation.
* **Operating System**:
	+ <page2_operating_system> (select multiple):
		- Windows: A Windows-based operating system.
		- Mac: A Mac-based operating system.
		- Linux: A Linux-based operating system.
* **RAM**:
	+ <page2_ram> (number): Specify the amount of RAM you require.
* **Storage**:
	+ <page2_storage> (number): Specify the amount of storage you require.
* **Processor**:
	+ <page3_processor> (text): Describe the processor you are requesting.
* **Budget**:
	+ <page3_budget> (number): Specify the budget for the workstation.
* **Departmental Approval**:
	+ <page4_departmental_approval> (text): Request departmental approval.
* **Manager Approval**:
	+ <page4_manager_approval> (text): Request manager approval.
* **Approval Comment**:
	+ <page4_approval_comment> (text): Add any additional comments.
* **Request Status**:
	+ <page4_request_status> (select one):
		- Approved: The request is approved.
		- Rejected: The request is rejected.
		- In Progress: The request is being reviewed.
* **Notes**:
	+ <page4_notes> (text): Add any additional information.
* **Submit**:
	+ <page4_submit> (text): Submit the form.
* **Email**:
	+ <page4_email> (email): Enter your email address.
* **Phone**:
	+ <page4_phone> (text): Enter your phone number.
* **Date Request Sent**:
	+ <page5_date_request_sent> (date): Date the request was sent.
* **Time Request Sent**:
	+ <page5_time_request_sent> (time): Time the request was sent.
* **Date Received**:
	+ <page5_date_received> (date): Date the request was received.
* **Time Received**:
	+ <page5_time_received> (time): Time the request was received.
* **Date Approved**:
	+ <page5_date_approved> (date): Date the request was approved.
* **Time Approved**:
	+ <page5_time_approved> (time): Time the request was approved.
* **Comments**:
	+ <page5_comments> (text): Add any additional comments.

## Tips

* Make sure to fill out all required fields correctly.
* Double-check the details you provide to ensure accuracy.
* Use a valid email address and phone number for communication.
* Be clear and concise in your request and approval comments.
* Review the request status regularly for updates.

Please note that this form is designed to be used internally and should not be shared with external parties.
