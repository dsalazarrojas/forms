# Employee Equipment Agreement - Help Guide
## Purpose
This form is used to document the agreement for employee equipment usage, ensuring that employees understand their responsibilities and the organization's expectations.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the category under which the equipment falls (e.g., IT Request Forms, Other).
2. Provide a description of the equipment being used.
3. Choose the employee tool you are agreeing to use.
4. Input the ID number associated with this form.
5. Add a description for tracking and reference purposes.
6. Select the employee responsible for creating this equipment agreement.
7. Note the form version number.
8. Select the categories under which this form will be filed (e.g., IT Request Forms, Other).
9. Enter the date the agreement is assigned to the employee.

## Field-by-Field Explanation
* **Category** (`category`, `select_one`, optional): Select the category under which the equipment falls (e.g., IT Request Forms, Other).
* **Description** (`description`, `text`, optional): Provide a description of the equipment being used.
* **Assigned Tool** (`assigned_tool`, `select_one`, optional): Choose the employee tool you are agreeing to use.
* **Form ID** (`form_id`, `number`, optional): Input the ID number associated with this form.
* **Description** (`description`, `text`, optional): Add a description for tracking and reference purposes.
* **Created By** (`created_by`, `note`, optional): Select the employee responsible for creating this equipment agreement.
* **Form Version** (`form_version`, `number`, optional): Note the form version number.
* **Category** (`form_category`, `select_multiple`, optional): Select the categories under which this form will be filed (e.g., IT Request Forms, Other).
* **Assigned Date** (`assigned_date`, `date`, optional): Enter the date the agreement is assigned to the employee.

## Tips
- Make sure to review and understand the expectations and responsibilities outlined in the agreement.
- Ensure that the information entered is accurate and up-to-date.
- Review and update the form as necessary to reflect any changes to the equipment or agreement terms.
