# Unmute Permission Request Form - Help Guide
## Purpose
The Unmute Permission Request Form is used to request permission to unmute a user account. This form is typically filled out by a requestor, who is the person requesting to unmute another user's account, or by a moderator, who is responsible for granting or denying the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select 'Yes' or 'No' for "unmute_request" to indicate if you are requesting to unmute the account.
2. Enter the "channel" where the unmute request is being made.
3. Provide a clear "reason" for the request.
4. Select "Yes" or "No" for "approvals" to indicate if the request is approved or denied.
5. Enter any additional "comments" to support your request.
6. Select "Yes" or "No" for "moderator_approvals" to indicate if the request is approved or denied by a moderator.
7. Select "Yes" or "No" for "requestor" to indicate if you are the requestor.
8. Enter the "email" of the requestor.
9. Enter the "phone" number of the requestor (optional).
10. Select "Yes" or "No" for "channel" to indicate if the channel is involved in the request.
11. Select "Yes" or "No" for "requestor" to indicate if you are the requestor (this field should not be selected if step 7 is selected).
12. Enter the "requestee" who is the user whose account is being unmuted.
13. Enter the "requestee_id" of the user whose account is being unmuted (optional).
14. Select "Yes" or "No" for "moderators" to indicate if the moderators are involved in the request.
15. Enter the "moderator" name (optional).
16. Enter the "moderator_id" number (optional).
17. Enter the "moderator_group" name (optional).
18. Enter the "moderator_group_id" number (optional).
19. Enter the "moderator_group_name" name (optional).
20. Enter the "requestor_group" name (optional).
21. Enter the "requestor_group_id" number (optional).
22. Enter the "requestor_group_name" name (optional).
23. Select "Yes" or "No" for "moderator_requestor" to indicate if the moderator is requesting to unmute the account.
24. Select "Yes" or "No" for "requestee_type" to indicate the type of requestee.
