# systems_support_log_form - Help Guide
## Purpose
The systems_support_log_form is used to report system issues that require support.

## How To Complete This Form
To fill out this form, follow these steps:

1. Click on the "Report System Issue" field and enter a brief description of the problem you are experiencing.
2. In the "System Description" field, provide more details about the system or application that is not functioning correctly.
3. Enter any relevant "Issue Details" in the "Issue Details" field.
4. Select the "Report Date" field and choose the date the issue started or was discovered.
5. For "Report Time", select the time the issue started or was observed.
6. In the "Reported By" field, enter your name or the name of the person reporting the issue.
7. If you would like to be contacted for further clarification, enter a "Contact Number" in the "Contact Number" field.

## Field-by-Field Explanation
* **Report System Issue** (report_system_issue, text, required/optional): This field is used to enter a brief description of the system issue.
* **System Description** (system_description, text, required/optional): Enter a detailed description of the system or application that is not functioning correctly.
* **Issue Details** (issue_details, text, required/optional): This field is used to provide more information about the issue, such as steps to reproduce or error messages.
* **Report Date** (report_date, date, required/optional): Select the date the issue started or was discovered.
* **Report Time** (report_time, time, required/optional): Select the time the issue started or was observed.
* **Reported By** (reported_by, text, required/optional): Enter your name or the name of the person reporting the issue.
* **Contact Number** (contact_number, text, required/optional): If you would like to be contacted for further clarification, enter your phone number or email address.
