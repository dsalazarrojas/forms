# CrowdStrike Fix Request Form - Help Guide

## Purpose
This form is for users to report issues that require attention from the CrowdStrike team. Please only submit new, unique issues.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Provide a detailed description of the issue in the "Issue Description" field.
3. Select the appropriate "Issue Priority" based on the urgency and impact of the issue.
4. Choose all relevant categories and tags for the issue.
5. Enter your contact information and email address so that we can follow up with you.
6. Select which team or tool you would like the issue to be assigned to.
7. Confirm that you have not submitted a similar issue before.

## Field-by-Field Explanation

* **Submit Request** (Note): 
  - This is a space for you to enter a detailed description of the issue you are experiencing.
  - Please be as specific as possible so we can understand the problem clearly.
 
* **Issue Description**:
  - This is where you should provide a detailed description of the issue you are experiencing.
  - Please be as detailed as possible so we can understand the problem clearly.
 
* **Issue Priority**:
  - Low: The issue is not critical and can be resolved in the background.
  - Medium: The issue is moderately important and requires immediate attention.
  - High: The issue is critical and requires urgent resolution.
 
* **Category**:
  - Please select all relevant categories for the issue (e.g., Hardware, Software, Security).
 
* **Tags**:
  - Please select all relevant tags for the issue (e.g., 'Yes', 'No').
 
* **Issue Reporter**:
  - This is where you should enter your name or title for reference.
 
* **Contact Information**:
  - This is where you should enter your contact information for follow-up.
 
* **Contact Email**:
  - This is where you should enter your email address for follow-up.
 
* **Assigned Group**:
  - Please select which team you would like to be assigned to resolve the issue.
 
* **Assigned Tool**:
  - Please select which tool you would like the issue to be assigned to for resolution.
 
* **Confirm Not a Duplicate**:
  - Confirm that this issue is not a duplicate of a previously reported issue.
