# Publishing Authoring Tools Requisition Form - Help Guide

## Purpose

This form is used to submit requests for publishing tools and authoring resources for the content team. 

Before completing this form, please ensure that your request is not a duplicate of a previously submitted request and that it aligns with your team's publishing schedule and goals.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the form title with a clear and concise title that accurately describes your request.
2. Select the category that best fits your request from the provided options (e.g., IT Request Forms, Other).
3. Provide a detailed description of your software request in the description field.
4. Choose the priority level of your request from the available options (High, Low, Medium).
5. Select the team that should be assigned to your project from the provided options (Publishing, Content, Both).
6. Indicate whether the tool should be assigned to the user ('Yes' or 'No').
7. Indicate who submitted the request ('Yes' or 'No').
8. If applicable, enter the name of the output file for the requested tool.
9. Add any additional notes regarding your request.
10. Optionally, select the date and time the request was submitted.

## Field-by-Field Explanation

* **Publishing Authoring Tools Requisition Form** (`form_title`, `text`, **required**): Enter a clear and concise title that accurately describes your request.
* **Category** (`category`, `select_one`, **required**): Select the category that best fits your request from the provided options (e.g., IT Request Forms, Other).
* **Description** (`description`, `text`, **required**): Provide a detailed description of your software request. This should include all necessary information for the assigned team to understand your needs.
* **Priority Level** (`priority`, `select_one`, **required**): Choose the priority level of your request from the available options (High, Low, Medium). This will help the assigned team understand the urgency of your request.
* **Team** (`team`, `select_one`, **required**): Select the team that should be assigned to your project from the provided options (Publishing, Content, Both).
* **Assigned Tool** (`assigned_tool`, `select_one`, **optional**): Indicate whether the tool should be assigned to the user ('Yes' or 'No').
* **Submitted By** (`submitted_by`, `select_one`, **required**): Indicate who submitted the request ('Yes' or 'No').
* **Output File** (`output_file`, `text`, **optional**): If applicable, enter the name of the output file for the requested tool.
* **Notes** (`notes`, `text`, **optional**): Add any additional notes regarding your request.
* **Date Submitted** (`date_submitted`, `date`, **optional**): Optionally, select the date and time the request was submitted. If not selected, the current date and time will be used.
* **Time Submitted** (`time_submitted`, `time`, **optional**): Optionally, select the time the request was submitted. If not selected, the current time will be used.
