# Device Keyboard Haptic Feedback Settings Request Form - Help Guide

## Purpose

This form is designed to collect user preferences for adjusting haptic feedback settings on their device keyboard. If you're experiencing any issues with your device's haptic feedback, this form is the right place to submit your request for adjustments.

## How To Complete This Form

1. Fill out the form by providing your email address in the "User Email" field.
2. Answer the question about haptic feedback in the "Device Haptic Feedback Type" field. Select "Yes" if you want haptic feedback, "No" if you don't.
3. If applicable, select the models of keyboards you use in the "Keyboard Model" field.
4. Choose the desired level of haptic feedback in the "Haptic Feedback Level" field. Note that this field is not applicable for all users.
5. Provide a brief description of your request in the "Description" field (optional).

## Field-by-Field Explanation

* **User Email (user_email, email, Optional):** Enter your email address where you'd like to receive updates on your request.
* **Haptic Feedback Type (device_haptic_feedback_type, select_one, Required):** Select "Yes" to enable haptic feedback, "No" to disable it.
* **Keyboard Model (keyboard_model, select_multiple, Optional):** If you use multiple keyboard models, select all that apply. Note: This field is not applicable for all users.
* **Haptic Feedback Level (keyboard_haptic_feedback_level, number, Optional):** If you're interested in adjusting the haptic feedback level, select a number from the options provided. This field is not required.
* **Description (description, text, Optional):** Add any additional context or details about your request, if applicable.
