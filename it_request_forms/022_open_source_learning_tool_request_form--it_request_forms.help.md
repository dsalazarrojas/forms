# Open Source Learning Tool Request Form - Help Guide
## Purpose
This form is designed to gather information from stakeholders and developers to support the education of various groups within the organization by requesting open-source learning tools.

## How To Complete This Form
- Please fill out this form in a clear and concise manner, providing as much detail as possible in each field.
- Make sure to answer all required fields (indicated by *).

## Field-by-Field Explanation
- **Form Title** (`1`, `text`, required/optional: true): The title of the learning tool being requested.
  - A clear and descriptive title is crucial for the tool's identification and management.
  - Please provide a title that accurately represents the tool's purpose and functionality.
- **Request Category** (`2`, `select_one`, required/true): Is this a high-priority or low-priority request?
  - Select 'Yes' if this request is urgent and should be prioritized quickly.
  - Select 'No' if it's not urgent, but still a valid request.
- **Description** (`3`, `text`, required/false): A brief description of the learning tool and its intended use.
  - Please provide a concise yet detailed description of the tool and its purpose.
- **Organization** (`4`, `text`, required/false): The department or team requesting the learning tool.
  - Provide the name of the department or team requesting the tool.
- **Email** (`5`, `email`, required/true): The contact email for the person submitting the request.
  - This will serve as the primary contact point for further communication and questions.
- **Phone** (`6`, `text`, required/false): The contact phone number for further communication and questions.
  - Provide a valid phone number that can be reached for further clarification or discussions.
- **Assigned Tool** (`7`, `text`, required/true): The learning tool name or code name (if known).
  - Please provide the name or code name of the requested learning tool (if known).
- **Educational Level** (`8`, `select_multiple`, required/false): Select the level of education this tool will support (if applicable).
  - Choose all that apply (High, Low).
- **Additional Comments** (`9`, `text`, required/false): Any additional comments or details about the learning tool request.
  - Please provide any further information or context that will aid in the processing and management of the request.

## Tips
- Double-check each field for accuracy before submitting the form.
- Use clear and concise language to ensure easy understanding of the request.
- If you're unsure about any field, contact the designated contact person for clarification.
- This form is intended to support efficient and accurate communication, so please fill it out as thoroughly as possible.
