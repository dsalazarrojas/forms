# Library Online Resource Access Report Form - Help Guide
## Purpose

This form is designed to collect information about your experience accessing online library resources. The information collected will help us improve our online resource collection and services.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your name and email address.
2. Select the name of the online resource you were trying to access.
3. Select the type of resource you were trying to access.
4. Describe the problem you encountered while accessing the resource.
5. Explain how the library could have helped solve the problem.
6. If you were assisted by a library staff member, please provide their name.
7. Click the "Submit" button to send your report.

## Field-by-Field Explanation

* **Patron Name** (`patron_name`, text, optional): This is your name.
* **Patron Email** (`patron_email`, email, optional): This is your email address.
* **Resource Name** (`resource_name`, text, optional): This is the name of the online resource you were trying to access.
* **Resource Type** (`resource_type`, select_one, optional):
	+ Database
	+ E-book
	+ DVD/Video
	+ Electronic Journal
	+ Electronic Reserve
	+ Journal
	+ Journal Article
	+ Journal Article Collection
	+ Media
	+ Newspaper
	+ Patron Service
	+ Serials
* **Problem Description** (`problem_description`, text, optional): Describe the problem you encountered while accessing the resource.
* **Library Solution** (`library_solution`, text, optional): Explain how the library could have helped solve the problem.
* **Staff Name** (`staff_name`, text, optional): If you were assisted by a library staff member, please provide their name.
