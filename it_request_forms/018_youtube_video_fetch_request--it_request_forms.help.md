# YouTube Video Fetch Request - Help Guide
## Purpose
The YouTube Video Fetch Request form is a tool used to collect information for the creation, modification, or removal of YouTube videos. This form is used by various departments, including Marketing and Creative, to ensure that the support team has all the necessary details for a successful video fetch operation.

## How To Complete This Form
1. Fill in the YouTube URL of the video you'd like to fetch.
2. Specify the purpose of the request, such as creating a new video, modifying an existing one, or removing a video.
3. Set a deadline for when you'd like the request to be completed.
4. Clearly list any specific requirements or instructions for the fetch process.
5. Select the relevant support team that will handle your request (Marketing, Creative, or Support).
6. Optionally, add any additional details or instructions in the Submit Request field.
7. Enter the date you'd like to submit the request by.

## Field-by-Field Explanation

### Enter YouTube URL (id: 1)
• **Enter YouTube URL** (`text`, required/optional): Enter the URL of the YouTube video you'd like to fetch. This field is used to identify the specific video for which you're requesting a fetch operation.

### Purpose (id: 2)
• **Purpose** (`text`, required/optional): Describe the purpose of your request, such as creating a new video, modifying an existing one, or removing a video. This helps the support team understand the context and priority of your request.

### Deadline (id: 3)
• **Deadline** (`date`, required/optional): Set a specific date by which you'd like the request to be completed. This helps the support team plan and schedule their tasks accordingly.

### Requirements (id: 4)
• **Requirements** (`text`, required/optional): List any specific requirements or instructions for the fetch process. This ensures that the support team can accurately and efficiently complete the task.

### Support Team (id: 5)
• **Support Team** (`select_one`, required): Select the support team that will handle your request. This ensures that your request is assigned to the relevant team and handled promptly.

### Submit Request (id: 6)
• **Submit Request** (`note`, optional): Add any additional details or instructions for the support team to consider when handling your request.

### Submit Date (id: 7)
• **Submit Date** (`date`, optional): Enter the date by which you'd like to submit the request. This helps the support team plan and schedule their tasks accordingly.

## Tips
- Ensure that all fields are filled out accurately and completely.
- Be specific when listing requirements and deadlines to avoid misunderstandings.
- Select the relevant support team to ensure that your request is handled promptly.
- Use the Submit Request field for any additional details or instructions.
- Enter the correct Submit Date to ensure that your request is scheduled accordingly.
