# internet_speed_research_survey_0608 - Help Guide
## Purpose
This form is used to report the results of internet speed tests. Please fill out the form to help us collect data on your internet speed test results.

## How To Complete This Form

1. **Form Title**: Enter a title for your internet speed test report. This can be a brief description of your test results.
2. Fill out the rest of the form based on your actual test results.

## Field-by-Field Explanation
- **Form Title**: (`form_title`, text, required: false)
	* This is a text field where you can enter a title for your internet speed test report.
	* Enter a brief description of your test results.
- **Form Description**: (`form_description`, text, required: false)
	* This is a text field where you can provide a detailed description of your internet speed test.
	* You can enter any additional information that might be helpful for us to know.
- **Form Category**: (`form_category`, select one, required: false)
	* Select the category that best describes your internet speed test location.
	* Options:
		+ IT Request Forms
		+ Other Forms
- **Form Environment**: (`form_environment`, select one, required: false)
	* Select the environment where you took your internet speed test.
	* Options:
		+ Home
		+ Work
		+ School
		+ Other
- **Form Speed Test Speed**: (`form_speed_test_speed`, number, required: false)
	* Enter the speed of your internet connection in Mbps.
- **Form Speed Test Location**: (`form_speed_test_location`, text, required: false)
	* Enter the location where you took your internet speed test.
- **Form Speed Test Time**: (`form_speed_test_time`, date, required: false)
	* Enter the date and time when you took your internet speed test.
- **Form Speed Test Device**: (`form_speed_test_device`, select one, required: false)
	* Select the device you used for your internet speed test.
	* Options:
		+ PC
		+ Mobile
		+ Other
- **Form Speed Test Internet Provider**: (`form_speed_test_internet_provider`, select one, required: false)
	* Select your internet service provider.
	* Options:
		+ Provider 1
		+ Provider 2
		+ Provider 3
		+ Provider 4
- **Form Speed Test Internet Speed Test**: (`form_speed_test_internet_speed_test`, number, required: false)
	* Enter the actual internet speed test results.
- **Tips**
* If you have any questions or concerns about this form, please contact us.
* Make sure to fill out the form accurately and completely to help us better understand your internet speed test results.
