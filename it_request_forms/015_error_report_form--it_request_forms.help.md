# Error Report Form - Help Guide
## Purpose
This form is designed to collect information about errors that have occurred on the system. It is used to help identify and resolve issues in a timely and effective manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the error from the dropdown menu. You can choose from "IT Request Forms", "Software Issues", "Hardware Issues", or "Option 4".
2. Describe the issue that occurred in the "Description" field.
3. Enter the date and time the issue occurred in the "Issue Date" and "Issue Time" fields, respectively.
4. Provide a detailed description of the issue in the "Issue Details" field.
5. If applicable, specify the tool used to reproduce the issue in the "Assigned Tool" field.
6. Enter the date you are reporting the issue in the "Report Date" field.

## Field-by-Field Explanation
- **Error Report Form** (Text, required): This is the title of your error report.
- **Category** (Select one, required): Select the category of the error from the dropdown menu. Choose from "IT Request Forms", "Software Issues", "Hardware Issues", or "Option 4".
- **Description** (Text, required): Describe the error that occurred in detail.
- **Issue Date** (Date, required): Enter the date the issue occurred.
- **Issue Time** (Time, required): Enter the time the issue occurred.
- **Issue Details** (Text, required): Provide a detailed description of the issue.
- **Assigned Tool** (Select one, optional): If applicable, specify the tool used to reproduce the issue.
- **Report Date** (Date, required): Enter the date you are reporting the issue.

## Tips
- Be as detailed as possible when describing the issue in the "Description" and "Issue Details" fields.
- Ensure that you select the correct category for the error.
- Check to make sure you have not already submitted a report for the same issue on the same day.
- If you are unsure about which category to choose, contact your supervisor for guidance.
