# Smart Building Alert Setup Request Form - Help Guide

## Purpose
The Smart Building Alert Setup Request Form is designed to help you set up custom alerts for your smart building. This form allows you to choose specific alert options and preferences to tailor the alerts to your needs. 

## How To Complete This Form

1. Select whether you need building alerts or not.
2. Choose your notification preferences for the alerts.
3. Provide the contact person, email, and phone number for alerts to be sent to.
4. Determine the triggers for the alerts (e.g., building status, type, location, etc.).
5. Select the type, priority, and frequency of the alerts.
6. Provide any additional comments or information about the building and its status.
