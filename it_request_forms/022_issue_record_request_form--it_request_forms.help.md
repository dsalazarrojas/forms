# issue_record_request_form - Help Guide
## Purpose
The issue_record_request_form is used to request an issue record from the IT department. This form is used to report problems that need to be addressed, and to gather information about the issue, such as when it occurred, what category it falls under, and other relevant details.

## How To Complete This Form
To complete the issue_record_request_form, follow these steps:

1. Fill in the **form name** field with a brief description of the issue or problem.
2. Select the **form category** from the dropdown menu, which could be "IT Request Forms" or "IT Forms".
3. Enter the **form date** when the issue occurred.
4. Provide a detailed description of the issue in the **form description** field.
5. Enter your **form ID** number, which is a unique identifier.
6. Fill in your **form version**, which is the version of the form you are submitting.
7. Select the **form status**, which could be "Active" or "Inactive", depending on the current status of the issue.
8. Enter any additional comments or information about the issue in the **form comments** field.
9. Enter your **issuer name** and **issuer email**, which will be used to contact you about the issue.

## Field-by-Field Explanation
- **Form Name** (`form_name`, text, required): This field is optional, but it's a good idea to fill it in to provide a brief description of the issue. It will help identify the issue more easily.
- **Form Date** (`form_date`, date, required): This field is required. Enter the date when the issue occurred.
- **Form Category** (`form_category`, select_one, required): This field is required. Select the relevant category for the issue from the dropdown menu.
- **Form Description** (`form_description`, text, required): This field is required. Provide a detailed description of the issue.
- **Form ID** (`form_id`, number, optional): This field is not required, but it's a unique identifier for the issue.
- **Form Version** (`form_version`, text, optional): This field is not required. Enter the version of the form you are submitting.
- **Form Status** (`form_status`, select_one, optional): This field is not required. Select the current status of the issue from the dropdown menu.
- **Form Comments** (`form_comments`, text, optional): This field is not required. Enter any additional comments or information about the issue.
- **Issuer Name** (`form_issuer_name`, text, optional): This field is not required. Enter your name.
- **Issuer Email** (`form_issuer_email`, email, optional): This field is not required. Enter your email address.
