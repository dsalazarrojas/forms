# Remote Workforce Monitoring Dashboard Request - Help Guide
## Purpose
The purpose of this form is to collect information for a custom remote workforce monitoring dashboard request. It will guide the IT department in configuring the dashboard according to your requirements.

## How To Complete This Form
To submit a new request for a remote workforce monitoring dashboard:

1. Select the relevant category for your request (e.g., "IT Request Forms").
2. Enter a detailed description of your requirements and needs in the description field.
3. Choose the required fields for your dashboard from the list of options provided.
4. Enter any additional details or notes that you would like to be included in the dashboard configuration.
5. Enter your email address so that we can contact you with updates or questions.
6. Enter your phone number if you would like to be contacted via phone.
7. Optionally, specify the tool that you would like to be assigned to work on your dashboard.

## Field-by-Field Explanation

* **Category**: Select the category that best describes your request. This will help us prioritize and filter requests.
* **Description**: Please provide a clear and detailed description of your requirements and needs. The more information you provide, the better we can meet your expectations.
* **Required Fields**: Select the fields you would like to be included in your dashboard. Choose from the available options provided.
* **Dashboard Overview**: Enter a brief summary of your dashboard requirements. This will be used as the main page title.
* **Data Collection**: Enter any specific data collection requirements you need for your dashboard.
* **Data Visualization**: Enter any specific data visualization requirements you need for your dashboard.
* **Data Export**: Enter any specific data export requirements you need for your dashboard.
* **Data Security**: Enter any specific data security requirements you need for your dashboard.
* **Notes**: Enter any additional details or comments that would help us understand your requirements better.
* **Email**: Enter your email address so that we can contact you with updates or questions.
* **Phone**: Enter your phone number if you would like to be contacted via phone.
* **Assigned Tool**: Optionally, specify the tool that you would like to be assigned to work on your dashboard.

## Tips
* Please fill in the form accurately and thoroughly, as the information will be used to configure the dashboard according to your specifications.
* If you have any questions or concerns, please don't hesitate to contact the support team.
