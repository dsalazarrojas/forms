# Gaming Equipment Calibration Request Form - Help Guide

## Purpose
The purpose of this form is to submit a request for calibration of gaming equipment. It is used to request calibration for devices, consoles, or chairs, and it is essential to provide accurate and up-to-date information for calibration purposes.

## How To Complete This Form
To complete this form, follow the steps below:

* Fill in your name, email, and phone number in the required fields.
* Select the type of gaming equipment that needs calibration from the options provided.
* Choose the location of the gaming equipment.
* Specify the date you would like the calibration to take place.
* Select the status of the calibration request (if you don't know, you can leave it as 'Pending').
* If you want to assign the calibration request to someone, you can do so by specifying their name.

## Field-by-Field Explanation
* **Title** (`title`, text, required/optional): This is a short title for your calibration request.
* **Name** (`name`, text, required): Enter your name to associate with this calibration request.
* **Email** (`email`, email, required): Enter your email address for communication purposes.
* **Phone** (`phone`, text, optional): Enter your phone number for further contact.
* **Date** (`date`, date, required): Select the date you would like the calibration to take place.
* **Gaming Equipment Type** (`gaming_equipment_type`, select_one, required): Choose the type of gaming equipment that needs calibration (e.g., Gaming Device, Gaming Console, Gaming Chair).
* **Location** (`gaming_equipment_location`, select_one, required): Choose the location of the gaming equipment (e.g., Gaming Room, Gaming Room 2, Gaming Room 3, Other).
* **Description** (`description`, text, optional): Provide a brief description of the calibration request if necessary.
* **Calibration Request Date** (`calibration_request_date`, date, required): Select the date you would like the calibration to take place.
* **Calibration Status** (`calibration_status`, select_one, optional): Select the status of the calibration request (if you don't know, you can leave it as 'Pending').
* **Assigned to** (`assigned_to`, text, required): Specify the name of the person you want to be assigned to this calibration request.
* **Assigned by** (`assigned_by`, text, required): Specify the name of the person making this calibration request.
* **Calibration Status** (`calibration_status`, select_one, optional): Select the status of the calibration request (if you don't know, you can leave it as 'Pending').
