# Signage Direction Update Request Form - Help Guide
## Purpose
The purpose of this form is to update the direction signage for facilities or locations. It is used to submit a request to update the signage direction.

## How To Complete This Form
1. Fill in the **Signage Direction Update Request** field with a brief description of the update.
2. Select the **Urgency Level** field to indicate the level of urgency for the update (e.g., High, Low).
3. If required, provide a **Photo** of the signage for reference.
4. In the **Description** field, add any additional information about the update.
5. If needed, provide more **Update Details** about the update.
6. Enter the **Facility ID** number.
7. Check the box in the **Submit** field to confirm that the information is accurate.
8. Enter the **Facility Name** of the location.
9. Enter the **Location** of the facility.
10. Enter the **Sign ID** number.
11. Select **Yes** or **No** in the **Update Priority** field to indicate if the update has priority.
12. In the **Update Type** field, provide a brief description of the update type.
13. Enter the **Update Frequency** field to indicate how often the update should be performed.

## Field-by-Field Explanation
* **Signage Direction Update Request** (`signage_direction_update_request`, text, optional): A brief description of the update.
* **Urgency Level** (`urgency_level`, select_one, optional): Indicates the level of urgency for the update (e.g., High, Low).
* **Photo** (`photo`, text, optional): A photo of the signage for reference (if required).
* **Description** (`description`, text, optional): Additional information about the update.
* **Update Details** (`update_details`, text, optional): More details about the update.
* **Facility ID** (`facility_id`, number, optional): Facility ID number.
* **Submit** (`submit`, select_multiple, optional): Confirm that the information is accurate (check the box).
* **Facility Name** (`facility_name`, text, optional): The name of the facility.
* **Location** (`location`, text, optional): The location of the facility.
* **Sign ID** (`signage_id`, number, optional): Sign ID number.
* **Update Priority** (`update_priority`, select_one, optional): Indicates if the update has priority (Yes, No).
* **Update Type** (`update_type`, text, optional): A brief description of the update type.
* **Update Frequency** (`update_frequency`, text, optional): How often the update should be performed.
