# Smart Monitoring Access Request Form - Help Guide
## Purpose
The Smart Monitoring Access Request Form is used to request access to monitoring tools. This form allows users to specify the level of monitoring access required and other relevant details to support their request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Monitoring Access Level** that best suits your needs. Choose between **High** or **Low** to indicate the level of access required.
2. If applicable, enter the **Start Date** and **End Date** when you expect to need monitoring access.
3. Enter the **Duration** for which you need monitoring access.
4. Provide a clear **Reason for Request** explaining why you need monitoring access.
5. Add any additional **User Comments** if needed.
6. Indicate who **Submitted By** this request.

## Field-by-Field Explanation
* **Monitoring Access Level** (`Monitoring Access Level`, select_one, required): Choose the level of access you require. Select **High** for sensitive or critical monitoring needs, or **Low** for less sensitive or less time-sensitive monitoring needs.
* **Start Date** (`Start Date`, date, optional): If you know the date you want to start monitoring, enter it here.
* **End Date** (`End Date`, date, optional): If you know the date you want to end monitoring, enter it here.
* **Duration** (`Duration`, number, required): Enter the number of days for which you need monitoring access.
* **Reason for Request** (`Reason for Request`, text, required): Give a clear and concise explanation for why you need monitoring access.
* **User Comments** (`User Comments`, text, optional): Add any additional comments or notes that support your request.
* **IT Approvals** (`IT Approvals`, select_multiple, optional): Indicate if you require IT approvals for your request.
* **Security Approvals** (`Security Approvals`, select_multiple, optional): Indicate if you require security approvals for your request.
* **Ops Approvals** (`Ops Approvals`, select_multiple, optional): Indicate if you require operations approvals for your request.
* **Submitted By** (`Submitted By`, select_one, required): Choose who submitted this request.
