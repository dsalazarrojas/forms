# IT Service Request Form - Help Guide
## Purpose
The IT Service Request Form is a tool used to submit and track IT requests. This form helps the IT team to understand the user's request and provide timely support.

## How To Complete This Form
To complete this form, simply fill out the required fields:

1. Select the category of your request from the "IT Request Type" dropdown menu.
2. Enter your name, email, and phone number in the "User Input", "User Email", and "User Phone" fields respectively.
3. Fill out the "IT Request Description" field with a detailed description of your request.
4. Set the "Status" field to "Pending", "In Progress", "Resolved", or "Closed" to track the request's progress.
5. Select one or multiple team members to assign your request to from the "Assignee" dropdown menu.
6. Fill out the "Assigned Date" field with the date when the request was assigned to a team member.
7. Optionally, enter the "Created Date" with the date when the request was created.

## Field-by-Field Explanation
### User Input
* **User Input**: Required, text
Enter your name to help our IT team to provide personalized support.

### User Email
* **User Email**: Required, email
Enter your email address so we can contact you about your request.

### User Phone
* **User Phone**: Optional, text
Enter your phone number to be contacted quickly about your request.

### IT Request Type
* **IT Request Type**: Required, select one
Select the category of your request from the dropdown menu:
	+ Request for IT Support
	+ Request for IT Service
	+ Request for IT Equipment
	+ Request for IT Training
	+ Request for IT Consulting

### IT Request Description
* **IT Request Description**: Optional, text
Fill out this field with a detailed description of your request.

### IT Request Priority
* **IT Request Priority**: Optional, number
This field is not currently used, but we recommend leaving it blank.

### Status
* **Status**: Required, select one
Set the "Status" field to:
	+ Pending
	+ In Progress
	+ Resolved
	+ Closed

### Assignee
* **Assignee**: Required, select multiple
Select one or multiple team members to assign your request to from the dropdown menu.

### Assigned Date
* **Assigned Date**: Optional, date
Enter the date when the request was assigned to a team member.

### Created Date
* **Created Date**: Optional, date
Enter the date when the request was created.

## Tips
- Make sure to fill out all required fields to ensure that your request is properly processed.
- If you are unsure about any field, please contact our IT team for assistance.
- Please be as detailed as possible in the "IT Request Description" field to help our team provide accurate support.
