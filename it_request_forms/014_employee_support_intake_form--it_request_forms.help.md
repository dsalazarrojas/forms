# employee_support_intake_form - Help Guide
## Purpose
The employee_support_intake_form is a form designed to collect employee support requests. It is intended to be used when an employee requires assistance with a specific issue or concern.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to ensure you have filled in all necessary information.
2. Select the relevant options from the dropdown menus where applicable.
3. Enter any relevant details in the text fields.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

* **Employee Support Form 1** (`employee_support_intake_form_1`, text, optional): Please provide a brief description of the issue you are experiencing. This can be a problem you are having or a request for assistance.
* **Select One Employee** (`select_one_employees`, select one, optional): Choose the employee who is experiencing the issue or requesting support.
* **Select Multiple Employees** (`select_multiple_employees`, select multiple, optional): Select all employees who are experiencing the issue or requesting support.
* **Date** (`date`, date, optional): Please enter the date when the issue occurred or when you are requesting support.
* **Time** (`time`, time, optional): Please enter the time when the issue occurred or when you are requesting support.
* **Select One Request Type** (`select_one_request_type`, select one, optional): Choose the type of request you are submitting (e.g., help, bug, feature request).
* **Select Multiple Request Types** (`select_multiple_request_types`, select multiple, optional): Select all relevant request types.
* **Email** (`email`, email, optional): Enter your email address for follow-up communication.
* **Phone** (`phone`, text, optional): Enter your phone number if you would like to be contacted by phone.
Note: If you have any further questions or concerns not addressed by the form, please don't hesitate to reach out.
