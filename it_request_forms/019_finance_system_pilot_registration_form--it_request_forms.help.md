# finance-system-pilot-registration-form - Help Guide
## Purpose
The Finance-System-Pilot-Registration-Form is designed to collect participant information and pilot objectives for the finance system pilot program. This form ensures that participants provide necessary details for a smooth and successful pilot registration process.

## How To Complete This Form
1. Fill out the form completely, especially the required fields.
2. Ensure you provide accurate information about yourself and your pilot objectives.
3. Double-check your answers for accuracy before submitting the form.

## Field-by-Field Explanation
### Participant ID (`form-id`, Number, Required: False)
This field is used to uniquely identify the participant in the finance system pilot program. Enter your participant ID if you have one; otherwise, leave it blank.

### Participant Name (`participant-name`, Text, Required: False)
Enter your name as it appears on your official identification.

### Pilot Objectives (`pilot-objectives`, Text, Required: False)
Describe your pilot objectives and goals for participating in the finance system pilot program.

### Finance Systems Used (`finance-systems-used`, Select Multiple, Required: False)
Select all finance systems you are using for the pilot program.

### Consent Given (`consent-given`, Select One, Required: True)
Indicate whether you have given your consent to participate in the finance system pilot program. Please select 'True' if you have given your consent.

### Email (`email`, Email, Required: False)
Enter your email address if you would like to be contacted regarding the pilot program.

### Phone Number (`phone-number`, Text, Required: False)
Enter your phone number if you would like to be contacted regarding the pilot program.

### Notes (`notes`, Note, Required: False)
Provide any additional information you believe is necessary for the pilot program.

### Date Created (`date-created`, Date, Required: False)
This field is automatically populated upon form submission.

### Time Created (`time-created`, Time, Required: False)
This field is automatically populated upon form submission.

## Tips
- Fill out the form carefully and accurately.
- Ensure you have given your consent to participate in the finance system pilot program.
- If you have any questions or concerns, contact the finance system support team.
