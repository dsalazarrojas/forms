# Power Backup System Check Request Form - Help Guide

## Purpose
This form is used to request power backup system checks for facilities, generators, and UPS systems. The purpose of this form is to gather necessary information for technicians to perform the checks and ensure that the power systems are functioning correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the facility IDs and generator/UPS IDs for each facility you want the power backup system checked.
2. Select the date and time when you want the check to be performed.
3. Add any additional notes or supporting files as necessary.
4. Choose the status of the check (Requested, Scheduled, or Complete).
5. Enter the scheduled date and time if the check has already been scheduled.
6. Enter the contact information (name, email, phone number, and notes) of the person requesting the check.
7. Repeat the above steps for any additional facilities, generators, or UPS systems.

## Field-by-Field Explanation

* **Facility ID** (`facility_id`): Enter the ID of the facility where the power backup system is located.
* **Generator ID** (`generator_id`): Enter the ID of the generator that powers the facility.
* **UPS ID** (`ups_id`): Enter the ID of the UPS system that provides backup power.
* **Date Requested** (`date_requested`): Select the date when you want the power backup system check to be performed.
* **Start Time** (`start_time`): Select the start time of the check.
* **End Time** (`end_time`): Select the end time of the check.
* **Notes** (`notes`): Add any additional comments or information about the check.
* **Supporting Files** (`supporting_files`): Attach any files that support your request (e.g. photos, videos).
* **Preferred Date** (`preferred_date`): Select the preferred date for the check, if different from the requested date.
* **Preferred Time** (`preferred_time`): Select the preferred time for the check, if different from the requested time.
* **Contact Name** (`contact_name`): Enter the name of the person requesting the check.
* **Contact Email** (`contact_email`): Enter the email of the person requesting the check.
* **Contact Phone** (`contact_phone`): Enter the phone number of the person requesting the check.
* **Contact Notes** (`contact_notes`): Add any additional notes or comments about the contact person.
* **Facility Notes** (`facility_notes`): Add any additional notes or comments about the facility.
* **Status** (`status`): Select the status of the check (Requested, Scheduled, or Complete).
* **Scheduled Date** (`scheduled_date`): Select the date when the check is scheduled.
* **Scheduled Time** (`scheduled_time`): Select the time when the check is scheduled.
* **Facility 2 ID** (`facility_id_2`), **Generator 2 ID** (`generator_id_2`), **UPS 2 ID** (`ups_id_2`), and others: Repeat the above steps for any additional facilities, generators, or UPS systems.

## Tips
- Make sure to enter accurate and complete information to ensure that the power backup system check can be performed efficiently.
- Attach any supporting files that demonstrate the issue or concern with the power backup system.
- Clearly select the status of the check to keep track of its progress.
- If you have any questions or concerns, contact the person listed as the contact.
- If you have any additional facilities or systems to add to the form, repeat the above steps.
- Make sure to submit the form to initiate the power backup system check.
