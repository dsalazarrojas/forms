## Smart Machine Diagnostics Request Form - Help Guide
## Purpose
This form is designed to help users report issues with their smart machines. It guides users through the process of describing the problems they're experiencing and providing relevant supporting details for a thorough diagnostic investigation.

## How To Complete This Form
Please fill out this form with the required information and any additional details that might be helpful. Ensure that you've answered all questions and uploaded any necessary supporting files. If you're unsure about any part of the form, please contact the support team for guidance.

## Field-by-Field Explanation

* **Submit Request Form (1)**: This is the first step in the process, where you confirm that you're submitting a new request and haven't already submitted a similar one.
* **Machine ID (2)**: Enter the ID number of the machine you're experiencing issues with.
* **Issue Description (3)**: Briefly describe the problem you're facing with your machine. This will help the technician understand the issue better.
* **Diagnostic Visit Date (4)**: If you have a preferred date for the diagnostic visit, enter it here. If not, leave this field blank.
* **Preferred Visit Date (5)**: If you have a preferred date for the visit, enter it here. If not, leave this field blank.
* **Diagnostic Visit Time (6)**: If you have a preferred time for the diagnostic visit, enter it here. This field is currently not required.
* **Diagnostic Visit Duration (7)**: Estimate the time needed for the diagnostic visit.
* **Supporting Details (8)**: Provide any additional information about the issue that might help the technician understand the problem better.
* **Supporting Files (9)**: Attach any files that might aid in the diagnostic process.
* **Assigned Technician (10)**: If you have a preferred technician for the job, you can select 'Yes' here. If not, the system will automatically assign a technician.
* **Scheduled Visit Time (11)**: Enter the preferred time for the diagnostic visit.
* **Scheduled Visit Date (12)**: Enter the preferred date for the diagnostic visit.
* **Notes (13)**: Any additional comments or questions you have about the visit.
