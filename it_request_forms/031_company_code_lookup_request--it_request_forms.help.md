# Company Code Lookup Request - Help Guide

## Purpose
The Company Code Lookup Request form is used to request a new company code for various business purposes, such as vendor setup, transactions, and reporting. This form is intended for employees of the company and requires accurate and complete information to ensure the correct assignment and use of the code in the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your full name and email address as the requester.
2. Provide your employee ID.
3. Select your department from the list of options.
4. Enter the name of the manager who will be using this code.
5. Choose the type of code you are requesting (e.g., Vendor Code, Customer Code, etc.).
6. Enter the company name to look up.
7. (Optional) Provide any additional identifying information such as the company address, Tax ID or EIN, DUNS Number, etc.
8. If you have searched for this code before and couldn't find it, select the corresponding option and provide any similar codes you found.
9. Provide a brief explanation for the business purpose of the code lookup.
10. Indicate the urgency level of the request (e.g., Low, Medium, High, Critical).
11. Enter the deadline for the code to be assigned and used.
12. If this code is related to a specific transaction, provide the transaction details.
13. Check if this is a new vendor setup and select the type of vendor.
14. (Optional) Select the expected payment terms and payment currency.
15. Provide any additional comments or information.
16. Sign the form electronically with your signature.
17. Check the "For IT/Finance Use Only" box for internal use only.
18. Review and submit the form.

## Field-by-Field Explanation

* **Full Name**: Enter your full name as the requester.
* **Email Address**: Enter your company email address.
* **Employee ID**: Enter your employee ID as a validation of your identity.
* **Department**: Select your department from the list of options.
* **Manager Name**: Enter the name of your manager who will be using this code.
* **Code Type**: Choose the type of code you are requesting (e.g., Vendor Code, Customer Code, etc.).
* **Company Name**: Enter the name of the company to look up.
* **Company Address**: (Optional) Provide any additional identifying information about the company address (if known).
* **Tax ID or EIN**: (Optional) Provide any additional identifying information about the Tax ID or EIN (if available).
* **DUNS Number**: (Optional) Provide any additional identifying information about the DUNS Number (if available).
* **Additional Identifiers**: (Optional) Provide any other identifying information.
* **Have You Searched Previous Records?**: If you have searched for this code before and couldn't find it, select the corresponding option and provide any similar codes you found.
* **Similar Codes Found**: If you selected "Yes", provide any similar codes you found.
* **Business Purpose**: Provide a brief explanation for the business purpose of the code lookup.
* **Urgency Level**: Indicate the urgency level of the request (e.g., Low, Medium, High, Critical).
* **Deadline**: Enter the deadline for the code to be assigned and used.
* **Is This Related to a Specific Transaction?**: If this code is related to a specific transaction, select the corresponding option and provide transaction details.
* **Transaction Details**: If you selected "Yes", provide the transaction details (e.g., PO number, invoice number, etc.).
* **Is This for a New Vendor Setup?**: Check if this is a new vendor setup and select the type of vendor.
* **Vendor Type**: If you selected "Yes", select the type of vendor.
* **Expected Payment Terms**: (Optional) Select the expected payment terms.
* **Currency for Transactions**: (Optional) Select the payment currency.
* **Any Additional Comments or Information?**: Provide any additional comments or information.
* **Requester Signature**: Sign the form electronically with your signature.
* **For IT/Finance Use Only**: Check the box for internal use only.
* **Lookup Result**: This field will display the code found or assigned.
* **Processed By**: The name of the staff member who processed the request.
* **Processed Date**: The date the request was processed.
