# Virtual Desktop Access License Request Form - Help Guide
## Purpose
This form is used to request access to the virtual desktop environment. It gathers information from the user regarding their request, license details, supporting information, approval status, and submitter's information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with accurate and concise information.
2. Review each field carefully to ensure you have provided the correct information.
3. If you have any supporting information, such as documents or references, you can attach them in the "Supporting Information" field.

## Field-by-Field Explanation
* **Request Information** (`request_info`, text, optional): This field is where you provide a brief description of your request for virtual desktop access. Please be clear and concise about your needs and requirements.
* **License Information** (`license_info`, text, optional): In this field, provide details about the license you are requesting, including any specific terms or conditions.
* **Supporting Information** (`supporting_info`, note, optional): If you have any supporting documents or references that can help process your request, you can attach them here.
* **Approval Status** (`approval_status`, select_one, required): Please select the status of your approval from the options provided. This is a required field.
* **Comments** (`comments`, text, optional): If you have any additional comments or feedback, you can include them here.
* **Submitter Information** (`submitter_info`, text, optional): This field is where you provide your name and contact information, so we can get back to you about your request.

## Tips
* Please review each field carefully before submitting the form to ensure you have provided accurate and complete information.
* If you have any doubts or questions, please don't hesitate to contact us for help.
* We will review your request and get back to you as soon as possible.
