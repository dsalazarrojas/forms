# graphic_design_request_template - Help Guide
## Purpose
This form is for requesting graphic design services for a project. It provides a simple and standardized way to submit a request with necessary details.

## How To Complete This Form
To complete this form, follow these steps:

1. Decide if you want to submit a request (`submit_request` field) and select the appropriate option (Yes or No).
2. Specify the project name and description in the `project_name` and `project_description` fields, respectively.
3. If applicable, select the relevant client details from the `client_details` field.
4. Set the deadline for the project in the `deadline` field, if necessary.

## Field-by-Field Explanation

* **Submit Request** (`submit_request`, select_one, required: false):
	+ This field is used to flag the request as submitted or not.
* **Client Details** (`client_details`, select_multiple, required: false):
	+ This field is used to specify whether the client has agreed to the terms of the project or has other specific requirements.
* **Project Name** (`project_name`, text, required: false):
	+ Enter the name of the project.
* **Project Description** (`project_description`, text, required: false):
	+ Enter a brief description of the project.
* **Deadline** (`deadline`, date, required: false):
	+ Enter the deadline for the project, if applicable.

## Tips
* Make sure to fill in all relevant fields to ensure a complete and accurate request.
* If you're unsure about any field, ask your supervisor or the design team for clarification.
* This form is for internal use, so feel free to modify or add fields as needed for your project's specific requirements.
