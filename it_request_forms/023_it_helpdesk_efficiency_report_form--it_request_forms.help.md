# IT Helpdesk Efficiency Report Form - Help Guide
## Purpose
The IT Helpdesk Efficiency Report Form is used to monitor and evaluate the efficiency of the IT helpdesk process.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form fields below to ensure you have a good understanding of what each field represents.
2. Select the corresponding values for each field based on the data you have access to.
3. Make sure you only fill out fields for tickets that are currently open or not yet resolved.

## Field-by-Field Explanation
### Page 1: Ticket Metrics
* **User Response Time** (`User Response Time`, `text`, optional): Enter the average time (in minutes) it takes for users to receive a response from the helpdesk team.
* **Resolution Rate** (`Resolution Rate`, `number`, required): Enter the percentage of resolved issues out of the total number of issues.
* **Response Time** (`Response Time`, `text`, optional): Enter the average time (in minutes) it takes for the helpdesk team to respond to tickets.
* **Resolved Issues** (`Resolved Issues`, `number`, required): Enter the total number of issues resolved.
* **Unresolved Issues** (`Unresolved Issues`, `number`, required): Enter the total number of issues that remain pending.

### Page 2: User Feedback
* **Feedback** (`Feedback`, `text`, optional): Enter any comments or suggestions you have on how to improve the helpdesk service.
* **User Satisfaction** (`User Satisfaction`, `select_one`, required): Select the level of satisfaction from `very dissatisfied` to `very satisfied`.
* **Page 2** (`Page 2`, `note`, optional): This is just a note field for any additional comments or information.
