# Server Transfer Request Form - Help Guide
## Purpose
The Server Transfer Request Form is used to request a server transfer from one location to another.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the source server information in the "Transfer Source" field.
* Enter the new location where the server will be transferred in the "New Location" field.
* Select the date and time when you would like the transfer to take place in the "Transfer Date" and "Transfer Time" fields.
* Provide a brief reason for the transfer in the "Reasons" field.
* If there are any additional reasons for the transfer, select the relevant options in the "Additional Reasons" field.

## Field-by-Field Explanation
* **Transfer Source** (`transfer_source`, text, optional): Enter the name or description of the server you wish to transfer.
* **New Location** (`new_location`, text, optional): Enter the name or description of the location where the server will be transferred.
* **Transfer Date** (`transfer_date`, date, optional): Select the date when you would like the transfer to take place.
* **Transfer Time** (`transfer_time`, time, optional): Select the time when you would like the transfer to take place.
* **Reasons** (`reasons`, text, optional): Provide a brief reason for the transfer. This will help the server transfer team understand the justification for the request.
* **Additional Reasons** (`reasons_list`, select_multiple, optional): Select any additional reasons for the transfer that are not included in the main "Reasons" field. Options include:
	+ Reason 1
	+ Reason 2
	+ Reason 3

## Tips
* Please ensure that the transfer request is legitimate and not a duplicate request.
* If you are unsure about any information or have any questions, contact the server transfer team for assistance.
* Fill out as much information as possible to help the server transfer team process your request efficiently.
