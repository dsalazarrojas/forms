# tech-marketing-tools-requisition-form - Help Guide

## Purpose

This form is used to request and track the procurement of tech-marketing tools. It allows marketing teams to submit requests for new tools, software, or services, and track the status of these requests with their respective managers and teams.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of tool you are requesting (Tools and Software or Services).
2. Enter the name of the marketing tool you need.
3. Provide the URL of the tool if applicable.
4. Choose the marketing team who will be using the tool.
5. Select the manager who will be handling the approval process.
6. Add a brief description of the tool and its intended use.
7. Set the status of the tool request (Approved, Pending, or Rejected).
8. If necessary, add comments regarding the tool or its request.
9. Fill in the form ID and other additional fields as required.

## Field-by-Field Explanation

* **Form Control** (`form_control`, text, optional): 
	+ Enter any additional information that you think would be helpful in managing this request.
* **Marketing Tool Name** (`marketing_tool_name`, text, optional): 
	+ Enter the name of the marketing tool you are requesting.
* **Tool Type** (`tool_type`, select_one, optional): 
	+ Select the type of tool you are requesting (Tools and Software or Services).
* **Tool URL** (`tool_url`, text, optional): 
	+ Enter the URL of the tool if applicable.
* **Marketing Team** (`marketing_team`, select_multiple, optional): 
	+ Select the marketing team who will be using the tool.
* **Manager** (`manager`, select_one, optional): 
	+ Select the manager who will be handling the approval process.
* **Description** (`description`, text, optional): 
	+ Add a brief description of the tool and its intended use.
* **Status** (`status`, select_one, optional): 
	+ Set the status of the tool request (Approved, Pending, or Rejected).
* **Created By** (`created_by`, text, optional): 
	+ Fill in the name of the person creating the request.
* **Created Date** (`created_date`, date, optional): 
	+ The date the form was created.
* **Updated By** (`updated_by`, text, optional): 
	+ Fill in the name of the person updating the request.
* **Updated Date** (`updated_date`, date, optional): 
	+ The date the form was last updated.
* **Tool Approval** (`tool_approval`, select_one, optional): 
	+ Approve or reject the tool request.
* **Comments** (`comments`, text, optional): 
	+ Add any additional comments regarding the tool or its request.
* **Form ID** (`form_id`, text, optional): 
	+ Enter the form ID for reference.
* **Assigned Tool** (`assigned_tool`, select_one, optional): 
	+ Select the tool that has been assigned for this request.
* **Form Owner** (`form_owner`, text, optional): 
	+ Fill in the name of the form owner.
* **Form Category** (`form_category`, text, optional): 
	+ Select the category of the form.
* **Form Description** (`form_description`, text, optional): 
	+ Add a brief description of the form.
* **Form Output File** (`form_output_file`, text, optional): 
	+ Enter the output file for this form.
* **Form Version** (`form_version`, text, optional): 
	+ Fill in the version of the form.
* **Form Created Date** (`form_created_date`, date, optional): 
	+ The date the form was created.
* **Form Updated Date** (`form_updated_date`, date, optional): 
	+ The date the form was last updated.
* **Form Created By** (`form_created_by`, text, optional): 
	+ Fill in the name of the person creating the form.
* **Form Updated By** (`form_updated_by`, text, optional): 
	+ Fill in the name of the person updating the form.

**Tips**

* Make sure to provide accurate and clear information when filling out this form to ensure smooth processing of your tool request.
* If you are unsure about any field, please feel free to ask your manager or team lead for clarification.
* This form is meant to be used for internal tool requests only. If you are looking for external resources, please use the [other form].
