# IT Change Management Request Form - Help Guide

## Purpose
The IT Change Management Request Form is a tool to help the IT team in tracking and managing changes to the IT infrastructure, systems, or processes. This form will help to ensure that all changes are properly analyzed, documented, and implemented.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select a request type**: Choose the type of request you are submitting (e.g., software update, hardware replacement, configuration change).
2. **Add a description**: Enter a brief description of the request.
3. **Choose categories**: Select the relevant categories that apply to your request.
4. **Provide date of request**: Enter the date you are requesting the change.
5. **Provide detailed description**: Add any further details about the request.
6. **Describe the impact**: Explain the potential impact of the change.
7. **Describe the changes**: Provide a detailed description of the changes you are requesting.

## Field-by-Field Explanation
- **it_change_management_request_form** (`it_change_management_request_form_label`, note, optional): This is the main label for the form.
- **description** (`description_label`, text, optional): A brief description of the request.
- **request_type** (`request_type_label`, select_one, optional): Select the type of request you are submitting (e.g., software update, hardware replacement).
- **category** (`category_label`, select_multiple, optional): Choose the relevant categories that apply to your request.
- **request_date** (`request_date_label`, date, optional): The date you are requesting the change.
- **description_details** (`description_details_label`, text, optional): Add any further details about the request.
- **impact_description** (`impact_description_label`, text, optional): Explain the potential impact of the change.
- **description_of_changes** (`description_of_changes_label`, text, optional): Provide a detailed description of the changes you are requesting.
 
## Tips
- Make sure to provide as much detail as possible to ensure the request is handled correctly.
- Check that you have not already submitted a similar request.
- If you are unsure about any field, please contact the IT team for clarification.
