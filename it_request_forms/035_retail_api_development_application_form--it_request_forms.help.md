# Retail API Development Application Form - Help Guide
## Purpose
This form is for individuals or businesses to apply for API access and development. It helps us gather necessary information about you and your company to review and approve your API access request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name, email address, and company name in the respective fields.
2. Select your role within the company.
3. Provide a brief description of your API development needs.
4. Choose the type of API access you require (Retail API or Non-Retail API).
5. Select the duration for which you need API access.
6. Enter the date you plan to submit your request.
7. Enter a brief note about yourself, if you'd like to share more about your submission.
8. Select the status of your review (Review, Pending, or Approved).
9. Add any comments or feedback you'd like to share with us.
10. Finally, specify how much API access you are requesting.

## Field-by-Field Explanation

* **Name** (`Name`, text, required): Enter your name as it appears on official documents.
* **Email** (`Email`, email, required): Enter a valid email address associated with your company or organization.
* **Company** (`Company`, text, required): Enter your company name as it appears on official documents.
* **Role** (`Role`, text, required): Select your role within your company (e.g., Developer, Manager, etc.).
* **Description** (`Description`, text, required): Provide a brief explanation of your API development needs.
* **API Access Type** (`API Access Type`, select multiple, required): Select whether you are requesting Retail API or Non-Retail API access.
* **API Access Duration** (`API Access Duration`, date, required): Specify the duration for which you need API access (in date format).
* **Submission Date** (`Submission Date`, date, required): Enter the date you plan to submit your request.
* **Submitter** (`Submitter`, text, required): Enter a brief note about yourself, if you'd like to share more about your submission.
* **Review Status** (`Review Status`, select one, required): Select the status of your review (Review, Pending, or Approved).
* **Comments** (`Comments`, note, optional): Add any comments or feedback you'd like to share with us.
* **API Access Requested** (`API Access Requested`, time, required): Specify how much API access you are requesting (in time format).
