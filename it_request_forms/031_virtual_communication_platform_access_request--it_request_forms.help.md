# Virtual Communication Platform Access Request - Help Guide
## Purpose
The Virtual Communication Platform Access Request form is a tool used to submit requests for access to the Virtual Communication Platform. It helps in organizing and tracking access requests in a structured way.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the form by providing the required and optional information in the fields provided.
2. Select "Yes" or "No" in the "Requested User" field to indicate if the access request is for the user or if it's not a user request.
3. For "Team" field, select one or multiple teams that the user wants to have access to.
4. In "Purpose" field, enter a clear and concise explanation for the access request.
5. For "Tool" field, select "Yes" if the access is requested for a specific tool, or "No" otherwise.
6. Enter the expected "Start Date" and "End Date" for the access period.
7. In "Reason" field, enter a brief description for the request.
8. If the request is made by a manager, select "Yes" in the "Manager Request" field.
9. Select the status of the request in the "Status" field, either "Active" or "Inactive".
10. In "Tool Status" field, select the status of the tool, either "Active" or "Inactive".
11. If the manager has any comments, enter them in the "Manager Comments" field.
12. Finally, enter any additional comments in the "Comments" field.

## Field-by-Field Explanation
* **Request From**: The name of the user submitting the request.
* **Requested User**: A yes/no field indicating if the access request is for the user or not.
* **Team**: Select one or multiple teams to grant access to.
* **Purpose**: A brief description of the purpose of the access request.
* **Tool**: A yes/no field indicating if the access request is for a specific tool.
* **Start Date**: The expected start date for the access period.
* **End Date**: The expected end date for the access period.
* **Reason**: A brief description for the request.
* **Manager Request**: A yes/no field indicating if the request is made by a manager.
* **Status**: The status of the request, either "Active" or "Inactive".
* **Tool Status**: The status of the tool, either "Active" or "Inactive".
* **Manager Comments**: Comments from the manager on the request.
* **Comments**: Additional comments or feedback on the request.
