# Employee File Access Request Form - Help Guide

## Purpose
This form is used to request access to employee files. It gathers information about the employee requesting access, the type of access they are requesting, and the level of access required. Please ensure that you have a valid reason for requesting access and that you are authorized to access employee files.

## How To Complete This Form

*   Please answer each question honestly and accurately.
*   Select "Yes" or "No" for each question where applicable.
*   Enter your name in the "Employee Name" field.
*   Choose the correct answer for the "File Type" and "Access Level" questions.
*   Enter a valid reason in the "Request Reason" field.
*   Set the "Manager Approvals" date field to a future date when your manager has approved the request.

## Field-by-Field Explanation

*   <b>Employee Request</b> (Yes / No):
    *   Select "Yes" to request access to employee files.
    *   Select "No" to not request access to employee files.
*   <b>Employee Name</b> (Text):
    *   Enter the name of the employee requesting access.
*   <b>File Type</b> (Select Multiple):
    *   Choose "Yes" for each type of file access you require.
*   <b>Access Level</b> (High / Low):
    *   Choose "High" for full access.
    *   Choose "Low" for restricted access.
*   <b>Request Reason</b> (Text):
    *   Enter a valid reason for requesting access.
*   <b>Manager Approvals</b> (Date):
    *   Set the date when your manager has approved the request.
*   <b>Employee Manager</b> (Yes / No):
    *   Select "Yes" if you are an employee manager.
    *   Select "No" if you are not an employee manager.
*   <b>Department</b> (Text):
    *   Enter the department of the employee requesting access.
*   <b>Team</b> (Select Multiple):
    *   Choose "Yes" for each team you require access for.
*   <b>File Share</b> (Number):
    *   Enter the number of files to share.
