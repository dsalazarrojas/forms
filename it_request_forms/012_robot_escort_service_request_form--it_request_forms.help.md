# Robot Escort Service Request Form - Help Guide
## Purpose
The Robot Escort Service Request Form is designed to collect basic information about a robot escort service request. Fill out this form to submit a request for robotic assistance.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the requested fields with the required information:
   - **Robot Escort Service Request** (id: 1): Type in a brief description of your robot escort service request.
   - **Organization** (id: 2): Enter the name or identifier of the organization involved, if applicable.
   - **Description** (id: 3): Provide a detailed description of the service you need from the robot.
   - **Contact Name** (id: 4): Enter your name or the name of the person submitting the request.
   - **Contact E-mail** (id: 5): Type in your email address or the email address associated with the organization.
   - **Escort Date** (id: 6): Choose the date for the robot escort service.
   - **Escort Time** (id: 7): Select the time for the robot escort service.
