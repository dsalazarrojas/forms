# Air Filtration Upgrade Request Form - Help Guide

## Purpose
The Air Filtration Upgrade Request Form is a tool for internal staff to submit requests for upgrading or modifying the air filtration system within their department or unit. This form helps the relevant personnel to understand the requirements and plan the necessary upgrades effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you're using the correct department and are the authorized submitter.
2. Fill in your name as the person requesting the upgrade.
3. Provide a brief description of the current filtration system.
4. Specify the desired improvements for the upgrade.
5. Indicate the urgency level for the upgrade (Low, Medium, or High).
6. If applicable, provide an approximate budget for the upgrade.
7. Suggest a preferred timeline for the completion of the upgrade.
8. Enter your contact email address for follow-up communication.
9. Add any additional context or details that might be helpful for the upgrade.

## Field-by-Field Explanation
* **Requester name**: This field is for your name as the person requesting the upgrade. It will be used for communication and tracking purposes.
* **Department or unit**: This field is for selecting the department or unit where the air filtration system is located. If you're not sure which department to select, please reach out to the relevant department manager.
* **Current system description**: This is where you describe the existing filtration setup, including the current state and any issues you're experiencing.
* **Desired improvements**: This field is for specifying the changes you'd like to make to the filtration system. Be as detailed as possible to ensure we understand your requirements.
* **Urgency level**: This is a measure of how quickly you need the upgrade to be completed. Select Low if the upgrade is not time-sensitive, Medium if you have some flexibility, and High if it's essential for the upgrade to be completed urgently.
* **Budget estimate**: This field is optional, but if you have an approximate budget for the upgrade, please provide it. This will help us plan and budget for the upgrade more effectively.
* **Preferred timeline**: This field is for suggesting when you'd like the upgrade to be completed. Be as specific as possible, including start and end dates.
* **Contact email**: This field is for entering your email address where we can reach you for follow-up communication.
* **Additional notes**: This field is for any additional context or details that might be helpful for the upgrade, such as technical specifications or specific requirements.

## Tips
* Ensure that you're using the correct department and are the authorized submitter to avoid delays and confusion.
* Be as specific as possible when describing the current system and desired improvements.
* If you have any doubts or questions, please don't hesitate to reach out for clarification.
