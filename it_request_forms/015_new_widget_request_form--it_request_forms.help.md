# New Widget Request Form - Help Guide
## Purpose
The New Widget Request Form is used to gather information from customers regarding their requests for new widgets.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter a brief description of the widget you are requesting in the **Widget Description** field.
2.  Enter your contact information in the **Email** and **Phone** fields.
3.  If this is on behalf of another customer, provide the contact information in the **Customer Rep Name**, **Customer Rep Email**, and **Customer Rep Phone** fields.
4.  If a sales representative is involved, provide their contact information in the **Sales Rep Name**, **Sales Rep Email**, and **Sales Rep Phone** fields.
5.  Choose the **Widget Type** from the options provided.
6.  Select the **Widget Status** as either **Active** or **Inactive**.
7.  Answer the question about whether this is a **Customer Request** or not.
8.  Enter any additional notes or comments in the **Widget Notes** and **Sales Manager Notes** fields.
9.  If the widget is being rejected, enter a reason and any additional notes in the **Widget Rejection Reason** and **Widget Rejection Notes** fields.

## Field-by-Field Explanation
- **New Widget Request Form** (`new_widget_request_form`, text, optional): Enter a brief description of the widget you are requesting.
- **Customer Organization** (`customer_organization`, text, optional): Enter the name of the customer organization.
- **Widget Type** (`widget_type`, text, optional): Select the type of widget you are requesting.
- **Widget Description** (`widget_description`, text, optional): Enter a brief description of the widget you are requesting.
- **Requested By** (`requested_by`, text, optional): Enter your name.
- **Email** (`email`, email, optional): Enter your email address.
- **Phone** (`phone`, text, optional): Enter your phone number.
- **Widget Request Details** (`widget_request_details`, text, optional): Enter any additional details about the widget request.
- **Customer Rep Name** (`customer_rep_name`, text, optional): Enter the name of the customer representative.
- **Customer Rep Email** (`customer_rep_email`, email, optional): Enter the email address of the customer representative.
- **Customer Rep Phone** (`customer_rep_phone`, text, optional): Enter the phone number of the customer representative.
- **Sales Rep Name** (`sales_rep_name`, text, optional): Enter the name of the sales representative.
- **Sales Rep Email** (`sales_rep_email`, email, optional): Enter the email address of the sales representative.
- **Sales Rep Phone** (`sales_rep_phone`, text, optional): Enter the phone number of the sales representative.
- **Request Date** (`request_date`, date, optional): Enter the date the request was made.
- **Request Time** (`request_time`, time, optional): Enter the time the request was made.
- **Widget Price** (`widget_price`, number, optional): Enter the price of the widget.
- **Widget Status** (`widget_status`, select_one, optional): Select whether the widget is Active or Inactive.
- **Widget Status Notes** (`widget_status_notes`, text, optional): Enter any additional notes about the widget status.
- **Customer Request Type** (`customer_request_type`, select_multiple, optional): Select whether this is a Customer Request or not.
- **Widget Notes** (`widget_notes`, text, optional): Enter any additional notes about the widget.
- **Sales Manager Notes** (`sales_manager_notes`, text, optional): Enter any additional notes for the sales manager.
- **Widget Approval Date** (`widget_approval_date`, date, optional): Enter the date the widget was approved.
- **Widget Rejection Reason** (`widget_rejection_reason`, text, optional): Enter the reason the widget was rejected.
- **Widget Rejection Notes** (`widget_rejection_notes`, text, optional): Enter any additional notes about the widget rejection.
