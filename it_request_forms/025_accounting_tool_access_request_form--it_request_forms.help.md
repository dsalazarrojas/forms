# Accounting Tool Access Request Form - Help Guide

## Purpose
The purpose of this form is to request access to accounting tools for employees, ensuring compliance with security policies and efficient management of tool access.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Provide a valid justification for the requested access level.
3. Enter a start date for access, and optionally a date for access expiry.
4. Get approval from your manager.
5. Review and agree to the IT Security Policy.

## Field-by-Field Explanation

* **Requester Full Name**: Enter your full name as it appears on your official documentation.
* **Employee ID**: Enter your Employee ID as it appears in the HR system.
* **Work Email**: Enter your work email address associated with the company.
* **Tool Requested**: Select the specific tool you need access to (e.g., NetSuite, QuickBooks Online, etc.).
* **Access Type**: Choose the reason for access request (New Account, Change Permissions, Password Reset, Deactivate Account).
* **Requested Access Level**: Choose the level of access you require (Standard User, Power User, Read-Only, Admin).
* **Business Justification for Access**: Provide a clear and concise explanation of why this access is required.
* **Access Start Date**: Enter the date when access is needed to start.
* **Access Expiry Date**: Leave blank for permanent access, or specify the date when access is no longer needed.
* **Manager Approval Name**: Enter the name of your manager who is authorizing this access request.
* **-- IT Security Policy --**: Review and acknowledge compliance with internal IT Security Policy.
* **I agree to use the tool in compliance with security policies**: Select "I agree" to confirm you will use the tool responsibly.

## Tips
* Ensure accurate and detailed information when filling out the form.
* Be mindful of deadlines and plan accordingly.
* Review and follow internal guidelines for tool access requests.
* Get approval from management prior to submission.
* Use the tool responsibly and abide by internal security policies.
