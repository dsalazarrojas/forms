# Document Conversion Request Form - Help Guide

## Purpose
This form is designed to collect information for document conversion requests. You can use it to submit requests for converting scans, emails, or files into other formats.

## How To Complete This Form
1. Select the type of document you want to convert:
   - Scan: Convert a physical document into a digital format.
   - Email: Convert an email message into a document format.
   - File: Convert a file into another format.
2. Decide if you need conversion of your document:
   - Yes: You need conversion of your document.
   - No: You do not need conversion of your document.
3. Provide the name of the document:
   - Enter the name of the document you want to convert.
4. Provide the name of the conversion:
   - Enter the name of the conversion you want to perform.
5. Describe your document and the conversion:
   - Enter a brief description of the document and the conversion you need.
6. Upload a file (if applicable):
   - If you selected "File" as your document type, you will need to upload the file.

## Field-by-Field Explanation
- **conversion_request** (Select Multiple, required/optional): This field is used to indicate whether you want to perform conversion on your document.
  - Please select "Yes" if you need conversion, "No" otherwise.
- **Document Type** (Select One, required/optional): This field is used to select the type of document you want to convert:
  - Scan: Convert a physical document into a digital format.
  - Email: Convert an email message into a document format.
  - File: Convert a file into another format.
- **conversion_type** (Select Multiple, required/optional): This field is used to indicate whether you want to convert your document into multiple formats:
  - "Yes": You want to convert your document into multiple formats.
  - "No": You do not want to convert your document into multiple formats.
- **Document Name** (Text, required/optional): This field is used to enter the name of the document:
  - Enter the name of the document you want to convert.
- **Conversion Name** (Text, required/optional): This field is used to enter the name of the conversion:
  - Enter the name of the conversion you want to perform.
- **Description** (Text, required/optional): This field is used to enter a brief description of the document and the conversion:
  - Enter a brief description of the document and the conversion you need.
- **Conversion Description** (Text, required/optional): This field is used to enter a more detailed description of the conversion:
  - Enter a more detailed description of the conversion you need.
- **Upload File** (Text, required/optional): This field is used to upload a file for conversion:
  - If you selected "File" as your document type, you will need to upload the file.

## Tips
* Ensure that you only submit one request per form.
* Please ensure that you have all the necessary information before submitting the form.
* If you have any questions or need help, please contact our support team.
