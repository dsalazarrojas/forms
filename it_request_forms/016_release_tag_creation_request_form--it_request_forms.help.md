# Release Tag Creation Request Form - Help Guide
## Purpose
This form is used to create a release tag for a specific release version in a specified environment. It's intended for requesting access to a release tag for testing or other purposes.

## How To Complete This Form
1. Click on the "Submit" button to initiate the request.
2. Fill out the form with the following information:
	* Request Details: Provide a brief description of the request.
	* Environment: Select the environment where the release is located (e.g., Test, Preprod, Production).
	* Release Version: Enter the release version number.
	* Release Tag: Enter a name for the release tag (e.g., "release-1.0").
	* Requestor: Enter the name of the person or team requesting the release tag.

## Field-by-Field Explanation

* **Request Details** (1): Enter a brief description of the request.
* **Environment** (2): Select the environment where the release is located. This is typically where the release will be deployed or tested.
* **Release Version** (3): Enter the version number of the release you're requesting access to.
* **Release Tag** (4): Enter a name for the release tag (e.g., "release-1.0"). This is the name of the tag that will be created.
* **Requestor** (5): Enter the name of the person or team requesting the release tag. This is useful for tracking and communication purposes.

## Tips

* Be clear and concise in the Request Details field to ensure the request is processed efficiently.
* Choose the correct environment where the release will be deployed or tested.
* Make sure to enter the correct release version number.
* Enter a unique and descriptive name for the release tag.
* Enter your actual name or the team's name as the requestor to ensure proper tracking and communication.
