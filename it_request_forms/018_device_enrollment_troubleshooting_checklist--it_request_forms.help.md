# Device Enrollment Troubleshooting Checklist - Help Guide
## Purpose
This form is used to collect information about device enrollment issues that require technical support. It is intended for use by IT personnel to help diagnose and resolve problems with device enrollment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Device Serial Number** of the device experiencing the issue.
2. Select the **Troubleshooting Steps** that apply to your issue.
3. Enter a brief description of the **Issue Description**.
4. Select the **Date** when the issue occurred.
5. Enter the name and contact information of the **IT Contact** who will be working on the issue.
6. Enter the **Device Enrollment Date**, when the device was last enrolled.
7. (Optional) Enter any additional comments in the **Comments** field.
8. Select whether the device is a **Mobile Device** (yes/no).
9. Select whether the device has a **Serial Number Issue** (yes/no).
10. (Optional) Enter any **Device Information**.
11. (Optional) Select the **Device Type** (yes/no).
12. Enter the **Issue Resolution** (yes/no).
13. Select the **Resolution Status** for all steps (yes/no).
14. (Optional) Enter any **Additional Comments**.
15. Finally, select the **Resolution Status** for all steps (yes/no).

## Field-by-Field Explanation

* **Device Serial Number**: Enter the serial number of the device experiencing the issue.
* **Troubleshooting Steps 1**: Select the troubleshooting steps that apply to your issue.
* **Troubleshooting Steps 2**: Select the troubleshooting steps that apply to your issue.
* **Issue Description**: Enter a brief description of the issue.
* **Date**: Enter the date when the issue occurred.
* **IT Contact**: Enter the name and contact information of the staff member who will be working on the issue.
* **Device Enrollment Date**: Enter the date when the device was last enrolled.
* **Comments**: Enter any additional comments about the issue.
* **Additional Comments**: Enter any additional comments about the issue.
* **Device Type**: Select whether the device is a mobile device (yes/no).
* **Serial Number Issue**: Select whether the device has a serial number issue (yes/no).
* **Device Information**: Enter any additional information about the device.
* **Resolution Status**: Select the resolution status for all steps (yes/no).
* **Issue Resolution**: Enter whether the issue has been resolved (yes/no).
* **Resolution Status**: Select whether the resolution has been achieved (yes/no).

* **user_input_24**: (Optional) Enter any additional comments about the issue.
* **user_input_25**: (Optional) Enter any information about the issue.

Note: Some fields in this form are not required and can be left blank, but it's recommended to fill them out if possible.
