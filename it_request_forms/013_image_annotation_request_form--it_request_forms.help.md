# Image Annotation Request Form - Help Guide
## Purpose
The Image Annotation Request Form is designed to collect all necessary information from users for image annotation requests in an efficient and organized manner.

## How To Complete This Form
1.  Fill in the required fields with the relevant details such as image URL, ID, and annotation requirements.
2.  Upload the image or enter the image URL.
3.  Select the annotation requirements and deadline.
4.  Fill in the submitter and vendor information.
5.  Review and submit the form.

## Field-by-Field Explanation

*   **Enter Image URL**: Enter the URL of the image that needs to be annotated.
*   **Image ID**: Enter the ID of the image that needs to be annotated.
*   **Deadline**: Enter the deadline for annotating the image (if required).
*   **Requirement**: Select the annotation requirements for the image.
*   **Upload Image**: Upload an image file for annotation.
*   **Notes**: Add any additional notes about the image annotation process.
*   **Email**: Enter the email address of the submitter.
*   **Phone**: Enter the phone number of the submitter.
*   **Submit**: Select the option for submission.
*   **Upload File**: Upload a file for the image annotation process.
*   **Annotation Requirements**: Select the annotation requirements for the image.
*   **Annotation Deadline**: Enter the deadline for the annotation process.
*   **Submitter Name**: Enter the name of the submitter.
*   **Submitter Email**: Enter the email address of the submitter.
*   **Submitter Phone**: Enter the phone number of the submitter.
*   **Submitter Department**: Select the department of the submitter.
*   **Submitter Designation**: Enter additional designation details of the submitter.
*   **Submitter Title**: Enter the title of the submitter.
*   **Submitter Notes**: Add any additional notes from the submitter.
*   **Vendor Name**: Enter the name of the vendor.
*   **Vendor URL**: Enter the URL of the vendor.
*   **Vendor Email**: Enter the email address of the vendor.
*   **Vendor Phone**: Enter the phone number of the vendor.
*   **Submitter Agreement**: Select the submitter agreement.
*   **Submitter Comments**: Add any additional comments from the submitter.
