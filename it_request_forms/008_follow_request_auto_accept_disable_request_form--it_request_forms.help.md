# Follow Request Auto Accept Disable Request Form - Help Guide
## Purpose
This form is designed to be filled out by support teams when a follow-up action is required on a ticket. The form helps to track and manage follow-up requests, and its primary purpose is to disable auto-accept functionality for specific requests.

## How To Complete This Form
1. Fill out the form with the required information.
2. Select the follow-up reason, priority, and follow-up by options as needed.
3. Enter any additional notes or comments if necessary.
4. Submit the form to update the status of the request.

## Field-by-Field Explanation

* **Follow Request Form** (<name>): This is the main field where you'll enter a brief description of the follow-up request.
* **Reason** (<label> reason): This field is optional and is used to enter a short explanation of the reason for the follow-up request. If you're unsure about the reason, you can leave this field blank.
* **Priority** (<label> priority): This field is used to set the priority of the follow-up request. Select the highest priority level that best describes the urgency and importance of the follow-up.
* **Priority Order** (<label> priority_order): This field is optional and is used to set the order of the priority level selected in the previous field. If you're unsure, you can leave this field blank.
* **Auto Accept** (<label> auto_accept): This field is used to select whether the auto-accept functionality should be disabled for this request. Choose "Auto" to disable auto-accept, or "Manual" to keep it enabled.
* **Status** (<label> status): This field is used to set the status of the follow-up request. Enter the current status of the request, such as "open", "closed", or "pending".
* **Follow-up Date** (<label> follow_up_date): This field is used to set the date when you plan to follow up on the request. Select the date from the calendar or enter it manually.
* **Follow-up Time** (<label> follow_up_time): This field is used to set the time when you plan to follow up on the request. Select the time from the dropdown list or enter it manually.
* **Follow-up Note** (<label> follow_up_note): This field is used to enter any additional notes or comments about the follow-up request.
* **Email** (<label> email): This field is optional and is used to enter the email address of the person you'll be following up with.
* **Phone** (<label> phone): This field is optional and is used to enter the phone number of the person you'll be following up with.
* **Follow-up by** (<label> follow_up_by): This field is used to select who will be following up on the request. Choose "Support Team" or "Moderator".
* **Follow-up by Note** (<label> follow_up_by_note): This field is optional and is used to enter any additional notes or comments about who will be following up.
* **Requester Note** (<label> requester_note): This field is optional and is used to enter any additional notes or comments from the requestor.
* **Status** (<label> status): This field is used to set the final status of the follow-up request, ensuring it matches the original request status.
