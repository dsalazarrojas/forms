# System Access Code Request Form - Help Guide
## Purpose
This form is used to request access codes for various system accesses. It helps employees to provide necessary information for the access request evaluation process.

## How To Complete This Form
1. Fill in your employee name in the "Employee Name" field.
2. Enter your job title in the "Job Title" field.
3. Select your department from the list of options in the "Department" field.
4. Choose a date for your access request in the "Request Date" field.
5. If you need to request access at a specific time, enter it in the "Request Time" field.
6. Enter your access code in the "Access Code" field.
7. Select the access level you require from the list of options in the "Access Level" field.
8. Optionally, provide a description of your access request in the "Description" field.
9. Enter your email address in the "Email" field.
10. Enter your phone number in the "Phone" field.
11. Add any additional notes about your access request in the "Note" field.

## Field-by-Field Explanation

* **Employee Name (employee_name, text, required)**: Enter your full name to identify yourself as the requestor of the access code.
* **Job Title (job_title, text, required)**: Enter your job title to ensure the request is properly evaluated and approved.
* **Department (department, select_one, required)**: Select your department from the list of options to ensure the request is directed to the correct team.
* **Request Date (request_date, date, required)**: Enter a date for your access request to be properly evaluated and approved.
* **Request Time (request_time, time, optional)**: If you need to request access at a specific time, enter it here.
* **Access Code (access_code, text, required)**: Enter your access code to be used for system access evaluation.
* **Access Level (access_level, select_multiple, optional)**: Select the access level you require to ensure the correct evaluation and approval process.
* **Description (description, text, optional)**: Provide any additional information about your access request for better evaluation.
* **Email (email, email, optional)**: Enter your email address for communication about your access request.
* **Phone (phone, text, optional)**: Enter your phone number for additional communication about your access request.
* **Note (note, note, optional)**: Add any additional notes about your access request to help with the evaluation process.
