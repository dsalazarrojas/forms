# Archived Website Request - Help Guide
## Purpose
This form is used to request assistance with finding a specific page on an archived website.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your contact information (name and email address).
2. Provide the title of the page you are trying to find (or the URL if you know it).
3. Describe the type of content you were looking for (e.g., product information, documentation, etc.).
4. Give us an estimate of when you last visited the page.
5. Choose how you found the page (e.g., search engine, direct link, etc.).
6. Let us know if you have any other relevant information or comments.

## Field-by-Field Explanation
### 1. **Your Name** (`visitor_name`, text, required)
Your name is required so we can contact you for more information or to provide assistance.

### 2. **Email Address** (`visitor_email`, email, required)
This is the email address we will use to contact you for more information or to provide assistance.

### 3. **Phone Number** (`visitor_phone`, text, optional)
If you would like to be contacted by phone, please provide your phone number here.

### 4. **What page were you looking for** (`original_page_title`, text, required)
Provide the title of the page you are trying to find, or the URL if you know it.

### 5. **Type of Content** (`page_content_type`, select_one, optional)
Choose the type of content you were looking for (e.g., product information, documentation, etc.).

### 6. **Describe the content you were looking for** (`content_description`, text, required)
Give us a brief description of the content you were looking for, so we can better understand your request.

### 7. **Approximately when did you last visit this page** (`approximate_visit_date`, date, optional)
If you can remember when you last visited the page, please provide the approximate date and time.

### 8. **How did you find this page** (`how_did_you_find_us`, select_one, optional)
Choose how you found the page (e.g., search engine, direct link, etc.).

### 9. **Do you know if this content exists on the new site?** (`current_location_known`, select_one, required)
Let us know if you have found the content on the new site or not.

### 10. **URL of current page on new site** (`current_page_url`, text, optional)
If you have found the content on the new site, please provide the URL of the current page.

### 11. **How urgent is this request** (`priority_level`, select_one, optional)
Choose the level of urgency for your request (e.g., low, medium, high).

### 12. **Additional comments or notes** (`additional_comments`, text, optional)
If you have any other information that might help us locate the content you are looking for, please provide it here.

### 13. **Preferred contact method** (`contact_preference`, select_one, required)
Choose how you would like to be contacted (e.g., email, phone, etc.).
