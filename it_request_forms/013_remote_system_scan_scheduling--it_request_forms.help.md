# Remote System Scan Scheduling - Help Guide
## Purpose
This form is used to schedule remote system scans for IT systems. It allows users to select a time slot and provide any necessary details for the scan request.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a time slot for the scan from the options provided.
2. Fill in any necessary details for the scan request, if applicable.
3. Enter the name of the person requesting the scan.
4. Provide the email or phone number of the person requesting the scan.
5. Specify the date and time of the scan, if necessary.
6. Click "Submit" to send the scan request.

## Field-by-Field Explanation

* **Select Time Slot 1** (`select_time_slot_1`, `select_one`, required: false): Choose the first time slot for the scan from the provided options.
* **Select Time Slot 2** (`select_time_slot_2`, `select_one`, required: false): Choose the second time slot for the scan from the provided options.
* **Select Time Slot 3** (`select_time_slot_3`, `select_one`, required: false): Choose the third time slot for the scan from the provided options.
* **Scan Request Details** (`scan_request_details`, `text`, required: false): Provide any additional details or instructions for the scan request.
* **Scan Requestor Name** (`scan_requestor_name`, `text`, required: false): Enter the name of the person requesting the scan.
* **Email or Phone** (`email_or_phone`, `text`, required: false): Enter the email or phone number of the person requesting the scan.
* **Date of Scan** (`date_of_scan`, `date`, required: false): Specify the date of the scan, if necessary.
* **Time of Scan** (`time_of_scan`, `time`, required: false): Specify the time of the scan, if necessary.
* **Scan Request Details 2** (`scan_request_details_2`, `text`, required: false): Provide any additional details or instructions for the scan request.

## Tips
- Please select a specific time slot for each time slot, as this will help the scan requestor plan for the scan.
- If you have any further details or instructions for the scan, please enter them in the "Scan Request Details" and "Scan Request Details 2" fields.
- If you have any questions or concerns, please contact the scan facilitator for assistance.
