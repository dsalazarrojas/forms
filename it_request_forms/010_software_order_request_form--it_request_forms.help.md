# software_order_request_form - Help Guide

## Purpose
The software order request form is used to collect information about software orders from requestors and submitters. This includes software name, version, category, and contact details of the requestor and submitter.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure that all required fields are filled out.
3. Check the form for any errors or inconsistencies before submitting.

## Field-by-Field Explanation

* **Software Order Request Form** (`1`, `text`, required): This field is the title of the form and is automatically generated.
* **Requestor Name** (`2`, `text`, required): Enter the name of the person requesting the software.
* **Requestor Email** (`3`, `email`, required): Enter the email address of the person requesting the software.
* **Requestor Phone** (`4`, `text`, required): Enter the phone number of the person requesting the software.
* **Software Name** (`5`, `text`, required): Enter the name of the software being requested.
* **Software Category** (`6`, `text`, required): Enter the category of the software being requested.
* **Software Version** (`7`, `text`, required): Enter the version of the software being requested.
* **Reason for Request** (`8`, `text`, required): Enter a brief explanation of why the software is being requested.
* **Requestor Department** (`9`, `text`, required): Enter the department of the person requesting the software.
* **Budgeted Cost** (`10`, `text`, required): Enter the budgeted cost of the software.
* **Actual Cost** (`11`, `text`, required): Enter the actual cost of the software.
* **Approval Status** (`12`, `select_one`, required): Choose the current approval status of the software order request. Options: pending, approved, declined.
* **Comments** (`13`, `text`, optional): Enter any additional comments or remarks about the software order request.
* **Submitter Name** (`14`, `text`, required): Enter the name of the person submitting the software order request.
* **Submitter Email** (`15`, `email`, required): Enter the email address of the person submitting the software order request.
* **Submitter Phone** (`16`, `text`, required): Enter the phone number of the person submitting the software order request.
* **Departmental Approval** (`17`, `select_one`, required): Choose the department that needs to approve the software order request. Options: it, operations, procurement.
* **Technical Approval** (`18`, `select_one`, required): Choose the technical approval status of the software order request. Options: pending, approved, declined.
* **Request Date** (`19`, `date`, required): Enter the date when the software order request was made.
* **Request Time** (`20`, `time`, required): Enter the time when the software order request was made.
* **Form Submitter** (`21`, `select_one`, required): Choose who submitted the software order request. Options: chatjimmy, another option.
* **Comments Awaiting Approval** (`22`, `text`, required): Enter comments awaiting approval from the submitter.
* **Approval Date** (`23`, `date`, required): Enter the date when the software order request was approved.
* **Comments After Approval** (`24`, `text`, required): Enter comments after approval from the submitter.
* **Submitted By** (`25`, `text`, required): Enter the name of the person who submitted the software order request.
