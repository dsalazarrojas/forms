# Software Engineer Technical Interview Q&A Guide Request Form - Help Guide
## Purpose
This form is designed to collect information from users who request a technical interview Q&A guide for software engineers.

## How To Complete This Form
To complete this form, simply follow the instructions below:

## Field-by-Field Explanation
* **Form Title** (form_title, text, required): A concise title for the guide.
* **Description** (description, text, required): Brief description of the request.
* **Email** (email, email, required): Please enter a valid email address.
* **Phone** (phone, text, optional): A phone number for the submitter (optional).
* **Submitted By** (submitted_by, text, required): Name of the submitter.
* **Assigned Tool** (assigned_tool, select_one, required): Choose the tool you would like to use for the guide.
* **Form ID** (form_id, number, required): A unique identifier for the form.
* **Submitted At** (submitted_at, date, optional): Date and time of submission (will be auto-filled).
* **Submitted To** (submitted_to, text, optional): Name of the person submitted to.
* **Category** (form_category, select_one, required): Choose the category for the guide.
* **Output File** (output_file, text, required): A file generated for the submission.
* **Output Name** (output_name, text, required): Name of the output file.
* **Output Path** (output_path, text, optional): Path where the output file is located.

## Tips
Please make sure to fill out all the required fields carefully, and provide as much information as possible to ensure that your guide request is processed correctly.
