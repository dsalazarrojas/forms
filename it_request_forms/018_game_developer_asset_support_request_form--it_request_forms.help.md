# Game Developer Asset Support Request Form - Help Guide
## Purpose
The Game Developer Asset Support Request Form is designed to help game developers get assistance with their game assets, including textures, 3D models, and audio files.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of asset you are requesting help with from the "asset_type" dropdown menu.
2. Enter the name of the asset you are requesting help with in the "asset_name" field.
3. If you have an asset ID, enter it in the "asset_id" field.
4. Describe the issue you are experiencing with the asset in the "issue_description" field.
5. Select the platform on which you are experiencing the issue from the "platform" dropdown menu.
6. Indicate the status of the asset by selecting "New", "In Progress", "Complete", or "Not Found" from the "asset_status" dropdown menu.
7. Enter your email address in the "game_dev_email" field.
8. (Optional) Attach any supporting files or images related to the issue in the "game_dev_attachment" fields.
9. Enter any additional comments about the issue in the "game_dev_comment" and "game_dev_message" fields.
10. Review your form submission for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **Asset Type (asset_type)**: Select the type of asset you are requesting help with. This can be a Texture, 3D Model, or Audio File.
* **Asset Name (asset_name)**: Enter the name of the asset you are requesting help with.
* **Asset ID (asset_id)**: If you have an asset ID, enter it here.
* **Issue Description (issue_description)**: Describe the issue you are experiencing with the asset.
* **Platform (platform)**: Select the platform on which you are experiencing the issue. This can be PC, Console, Mobile, or Browser.
* **Asset Status (asset_status)**: Indicate the status of the asset by selecting "New", "In Progress", "Complete", or "Not Found".
* **Game Title (game_title)**: Enter the title of the game associated with the asset.
* **Game Version (game_version)**: Enter the version of the game associated with the asset.
* **Game Developer Email (game_dev_email)**: Enter your email address.
* **Game Developer Phone (game_dev_phone)**: Enter your phone number (optional).
* **Game Developer Name (game_dev_name)**: Enter your name.
* **Game Developer Platform (game_dev_platform)**: Enter your platform or company name (optional).
* **Asset File (asset_file)**: If you have a file related to the issue, upload it here.
* **Game Developer Comment (game_dev_comment)**: Enter any additional comments about the issue.
* **Game Developer Message (game_dev_message)**: Enter any additional information or context about the issue.
* **Game Developer Attachment (game_dev_attachment)**: If you have a file or image related to the issue, upload it here.
* **Game Developer Attachment 2 (game_dev_attachment_2)**: If you have another file or image related to the issue, upload it here.
* **Game Developer Attachment 3 (game_dev_attachment_3)**: If you have another file or image related to the issue, upload it here.
* **Game Developer Attachment 4 (game_dev_attachment_4)**: If you have another file or image related to the issue, upload it here.
* **Game Developer Attachment 5 (game_dev_attachment_5)**: If you have another file or image related to the issue, upload it here.
