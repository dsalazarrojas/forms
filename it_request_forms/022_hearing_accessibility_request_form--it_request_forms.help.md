# Hearing Accessibility Request Form - Help Guide
## Purpose
The Hearing Accessibility Request Form is designed to collect information about your accessibility needs and preferences for a specific event. This form helps us ensure a comfortable and inclusive experience for all attendees, including those with disabilities.

## How To Complete This Form
1. Fill out the form with as much information as possible.
2. Be as detailed as you can, especially for fields like "Accessibility Request" and "Additional Comments".
3. If you have any specific requests or needs, make sure to specify them clearly.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event you are attending.
* **Event Date** (`event_date`, date, required): Enter the date of the event in the format YYYY-MM-DD.
* **Session Time** (`session_time`, time, required): Enter the time of the session you are attending.
* **Session Duration** (`session_duration`, number, optional): If you know the session duration, please enter it here. If not, you can leave it blank.
* **Start Time** (`start_time`, time, required): Enter the start time of the event.
* **End Time** (`end_time`, time, required): Enter the end time of the event.
* **Venue** (`venue`, text, required): Enter the location of the event.
* **Request Type** (`request_type`, select_one, required): Please select "Yes" if you require any accommodations or "No" if you do not.
* **Requester Name** (`requester_name`, text, optional): If you are requesting accommodations on behalf of someone else, please enter their name.
* **Requester Email** (`requester_email`, email, required): Enter the email address of the person making the request or the person being requested to accommodate.
* **Requester Phone** (`requester_phone`, text, required): Enter the phone number of the person making the request or the person being requested to accommodate.
* **Accessibility Request** (`accessibility_request`, text, optional): Please specify any specific accessibility requests you may have.
* **Accessibility Request Note** (`accessibility_request_note`, note, optional): If you have any additional information about your accessibility request, please enter it here.
* **Follow Up** (`follow_up`, text, required): Please check if you would like to be followed up after the event.
* **Follow Up Note** (`follow_up_note`, note, optional): If you have any additional comments about follow-up, please enter them here.
* **School Name** (`school_name`, text, optional): If you are an attendee of an educational institution, please enter the name of the school you attend.
* **Event Organizer** (`event_organizer`, text, optional): If you have a point of contact for the event, please enter their name and email.
* **Event Description** (`event_description`, text, optional): If you would like to provide more information about the event, please enter it here.
* **Accessibility Equipment** (`accessibility_equipment`, text, optional): If you have specific accessibility equipment needs, please specify them here.
* **Additional Comments** (`additional_comments`, text, optional): If you have any additional comments or information, please enter them here.
* **Event Location** (`event_location`, text, optional): If you would like to provide more information about the event location, please enter it here.
* **Event Type** (`event_type`, select_one, required): Please select "Yes" if the event is an in-person event or "No" if it is online.
* **Event Size** (`event_size`, select_multiple, required): Please select all that apply from the list of event sizes.
* **Event Presentation** (`event_presentation`, text, optional): If you would like to provide more information about the event presentation, please enter it here.
* **Follow Up Email** (`follow_up_email`, email, optional): If you would like to be contacted via email after the event, please enter your email address.

## Tips
- Please fill out the form as completely as possible to ensure we can provide the best possible experience for you.
- If you have any questions or concerns, please don't hesitate to contact us.
- We will follow up with you after the event to ensure that everything went well.
