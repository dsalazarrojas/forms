# Smart Building App Support Request Form - Help Guide
## Purpose

This form is designed to collect information from users who are experiencing issues with the Smart Building App. The support team uses this form to understand the problem and provide a resolution.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter a clear and concise description of the issue you are experiencing with the Smart Building App.
2. If you are reporting an issue with a specific version of the app, please select the correct version from the dropdown menu.
3. Enter your email address so we can contact you for further information or to provide an update on the issue.
4. If you have a screenshot or attachment that can help us understand the issue, please upload it.
5. Enter any additional details or comments about the issue.
6. Click the "Submit" button to send the form to the support team.

## Field-by-Field Explanation

* **Support Request Form** (`support_request_form`): Enter a brief description of the issue you are experiencing with the Smart Building App.
* **Building App Info** (`building_app_info`): Enter any additional information about the app that may help us understand the issue.
* **Description** (`description`): Enter a detailed description of the issue you are experiencing with the app.
* **Issue Details** (`issue_details`): Enter any specific details about the issue, such as steps you took or errors you encountered.
* **Email Address** (`email_address`): Enter your email address so we can contact you for further information or to provide an update on the issue.
* **Phone Number** (`phone_number`): Enter your phone number in case we need to contact you directly.
* **Building App Version** (`building_app_version`): Select the version of the Smart Building App you are using to help us understand which version is affected by the issue.
* **Screenshot** (`screenshot`): If you have a screenshot that can help us understand the issue, please upload it.
* **Attachment** (`attachment`): If you have a file that can help us understand the issue, please upload it.
* **Building App Support Request Form** (`building_app_support_request_form`): Enter any additional comments or details about the issue.

Note: All fields are optional except for the Building App Version, which is required to ensure we understand which version of the app is affected by the issue.
