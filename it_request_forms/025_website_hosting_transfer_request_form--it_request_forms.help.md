# Website Hosting Transfer Request Form - Help Guide
## Purpose
This form is designed to request website hosting transfer services. Please fill out the form carefully to provide necessary information for a smooth transfer process.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the new host provider from the provided options.
2. Choose the desired transfer type (Full Transfer, Partial Transfer, Cutover).
3. Enter the new website URL.
4. Enter the current website URL (for reference only).
5. Choose the transfer date and time.
6. Select the transfer status (In Progress, Complete, Cancelled).
7. Add any additional notes or comments (optional).
8. Enter the contact email address.
9. Enter the contact phone number.

## Field-by-Field Explanation
* **New Host Provider (Host 1, Host 2, Host 3)**: Choose the new host provider from the list.
* **Transfer Type (Full Transfer, Partial Transfer, Cutover)**: Select the desired transfer type.
* **New URL**: Enter the new website URL.
* **Current URL**: This field is for reference only. Please enter the current website URL to help our team locate the correct website.
* **Transfer Date**: Choose the desired transfer date.
* **Transfer Time**: Choose the desired transfer time.
* **Transfer Status (In Progress, Complete, Cancelled)**: Select the current status of the transfer.
* **Notes**: Add any additional notes or comments about the transfer.
* **Contact Email**: Enter the email address of the person requesting the transfer.
* **Contact Phone**: Enter the phone number of the person requesting the transfer.
