# Multi Store Account Merge Request Form - Help Guide
## Purpose
This form is used to request a merge between multiple store accounts. Please use this form to provide the necessary information for a smooth and efficient merge process.

## How To Complete This Form
1. Fill in the required fields with accurate and up-to-date information.
2. Ensure you have the necessary permissions and follow the correct procedures to avoid any account restrictions.
3. Submit the form for review and approval.

## Field-by-Field Explanation
* **Account Name** (account_name): This is the name of the account you want to merge.
* **Account Email** (account_email): This is the email address associated with the account you want to merge.
* **Store Code** (store_code): This is the code associated with the store you want to merge.
* **Username** (username): This is the username of the user associated with the account.
* **User Email** (user_email): This is the email address associated with the user.
* **User Name** (user_name): This field is optional and is used to provide additional information about the user.
* **User Phone** (user_phone): This field is optional and is used to provide additional information about the user.
* **Reason for Merge** (reason_for_merge): Provide the reason why you want to merge the accounts.
* **Merge Store Details** (merge_store_details): Provide detailed information about the store you want to merge.
* **Request Date** (request_date): This is the date you are making the request.
* **Review Date** (review_date): This is the date the request was reviewed by the administrator.
* **Review By** (review_by): This field is optional and is used to indicate who reviewed the request.
* **Comments** (comments): This field is optional and is used to provide additional comments about the request.
* **Upload Files** (upload_files): This field allows you to upload multiple files to support your request.
  Note: You can select up to 5 files to upload.

# Tips
* Make sure to check the accuracy of the information you provide to avoid any delays in the review process.
* Please be patient and allow sufficient time for the review and approval process.
