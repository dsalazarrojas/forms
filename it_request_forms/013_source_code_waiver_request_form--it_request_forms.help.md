# Source Code Waiver Request Form - Help Guide
## Purpose
The Source Code Waiver Request Form is designed to allow employees to request waivers for source code use, providing a standardized process for submission and review of such requests. This form helps track and manage the waiver request process, ensuring that necessary information is collected and reviewed efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Request Information page with the required details about the request.
	* Enter the request date when you submitted the request.
	* Provide a detailed description of the request.
2. On the second page, enter the relevant information:
	* Enter the employee requesting the waiver.
	* Enter the manager's email address who will be reviewing the request.
	* Select the person responsible for security review (e.g., Security Team, Compliance Officer, or Manager).
	* Choose the current approval status of your request (Pending, Approved, or Denied).
	* Enter any comments or feedback related to the request.

## Field-by-Field Explanation

* **Request Information** (`source_code_waiver_request_form_1`, Note, Not Required): A brief summary of your waiver request.
	+ This is where you can provide any additional information about your request.
* **Request Date** (`request_date`, Date, Not Required): The date when you submitted your request.
	+ Enter the date you submitted this request in the format MM/DD/YYYY.
* **Request Description** (`request_description`, Text, Not Required): A detailed description of your waiver request.
	+ Use this field to provide as much context as possible about the request.
* **Employee Requesting** (`employee_requesting`, Text, Not Required): The name of the employee who is requesting the waiver.
	+ Enter the full name of the employee requesting the waiver.
* **Manager Approval** (`manager_approval`, Email, Not Required): The email address of the manager who will be reviewing your request.
	+ Enter the manager's email address for them to review and respond to your request.
* **Security Review** (`security_review`, Select One, Not Required): The person responsible for security review (e.g., Security Team, Compliance Officer, or Manager).
	+ Select the person responsible for reviewing your request for security concerns.
* **Approval Status** (`approval_status`, Select One, Not Required): The current status of your request (Pending, Approved, or Denied).
	+ Choose the current status of your request.
* **Comments** (`comments`, Note, Not Required): Any comments or feedback related to your request.
	+ Use this field to provide any additional feedback or context for the reviewer.

## Tips
- Make sure to fill in all relevant fields to ensure the reviewer has sufficient information to make an informed decision.
- If your request is approved, please be mindful of any obligations or conditions that come with the waiver.
- If your request is denied, use the comments field to understand the reasons for the denial and address any concerns or questions.
