# it_support_request_form - Help Guide
## Purpose
The it_support_request_form is designed to assist IT support staff in quickly gathering essential information from users to provide effective support. This form helps to identify the issue, its severity, and the user's operating environment, enabling support staff to troubleshoot and resolve the problem promptly.

## How To Complete This Form
To fill out this form, follow these steps:

1.  Select one or multiple internet connection options that apply to your issue. These options include DSL, Fiber, and Wireless. If your connection type is not listed, please provide a brief explanation in the Problem Details field.
2.  Choose your operating system from the options provided (Windows, macOS, or Linux). If you're unsure or have multiple operating systems installed, select the one most relevant to the issue.
3.  Provide a detailed description of the problem you're experiencing in the Problem Details field. This could include error messages, symptoms, or steps you've taken to troubleshoot the issue.
4.  Enter your phone number, which will be used for follow-up if needed.

## Field-by-Field Explanation
### Internet Connection
*   **Internet Connection** (`id: 1`, `type: select_multiple`): Select one or multiple internet connection types that apply to your issue. These options include DSL, Fiber, and Wireless. If your connection type is not listed, please provide a brief explanation in the Problem Details field.
*   **Problem Details** (`id: 3`, `type: text`): Enter a detailed description of the problem you're experiencing, including any error messages, symptoms, or steps you've taken to troubleshoot the issue.
*   **Phone Number** (`id: 4`, `type: text`): Enter your phone number, which will be used for follow-up if needed.
*   **Operating System** (`id: 2`, `type: select_one`): Choose your operating system from the options provided (Windows, macOS, or Linux). If you're unsure or have multiple operating systems installed, select the one most relevant to the issue.
