# Hospital Information System Diagram Request Form - Help Guide
## Purpose
This form is designed to gather necessary information for diagram requests made by hospital staff to the IT department. It is used to ensure that the IT department has the necessary data to process and fulfill the requests accurately and efficiently.

## How To Complete This Form
To complete this form, simply fill in the required and optional fields as follows:
- Enter your name, department, and contact information in the "User Information" section.
- Provide the name of the IT department involved in the request in the "IT Department" section.
- Briefly describe your diagram request in the "Request Details" section.
- Specify the name of the system and server related to the request in the "System Name" and "Server Name" sections.
- Indicate the location of the request in the "Location" section.
- Fill in the date and time of the request in the "Request Date" and "Request Time" sections.
- Specify your contact information for the IT department in the "IT Contact" section.

## Field-by-Field Explanation
- **User Information** (`user_info`, text, optional): This field is for you to enter your name and department. You can provide any additional contact information if necessary.
  - Enter your name as it appears on your hospital ID badge or personnel file.
  - If you're requesting on behalf of another staff member, indicate their name and department as well.
- **IT Department** (`it_department`, text, optional): This field is for you to specify which IT department is involved in the request.
  - If you're unsure which IT department is responsible, you can contact the IT department's general email or phone number to confirm.
- **Request Details** (`request_details`, text, optional): This field is for you to describe the specific diagram request you are making.
  - Please be as detailed as possible so that the IT team can understand your needs.
- **System Name** (`system_name`, text, optional): This field is for you to enter the name of the system related to the request.
  - Typically, this is the name of the software or system you are using.
- **Server Name** (`server_name`, text, optional): This field is for you to specify the name or IP address of the server involved.
  - If you're unsure of the server name, you can check the system settings or contact the IT department.
- **Location** (`location`, text, optional): This field is for you to indicate the location where the diagram will be used or installed.
  - This can include the room number, floor, or building where the system will be used.
- **Request Date** (`request_date`, date, optional): This field is for you to enter the date you are submitting the request.
  - Format the date as mm/dd/yyyy.
- **Request Time** (`request_time`, time, optional): This field is for you to specify the time you are submitting the request.
  - Format the time as 12:00 PM or 3:00 AM.
- **IT Contact** (`it_contact`, text, optional): This field is for you to specify your contact information for the IT department.
  - This can include a phone number, email address, or other contact details.

## Tips
- Make sure to provide as much detail as possible for your diagram request.
- If you're unsure about any of the fields, contact the IT department for guidance.
- Double-check your entry before submitting the form to ensure accuracy.
- If you have any additional questions or concerns, contact the IT department for assistance.
