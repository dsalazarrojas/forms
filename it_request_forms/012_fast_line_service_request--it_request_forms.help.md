# Fast Line Service Request - Help Guide
## Purpose
The purpose of this form is to provide a clear and concise way to submit service requests to the team. This form gathers essential information about your service request, including the issue, report details, contact information, service category, priority, and any additional comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of your service request in the "Issue Summary" field.
2. Provide more details about the issue in the "Report Details" field.
3. Ensure you have accurate contact information in the "Contact Information" field.
4. Select the relevant "Service Category" for your request.
5. Indicate the priority level of your request in the "Service Priority" field.
6. If applicable, choose the "Requested By" options that best fit your situation.
7. Enter any additional comments about your service request in the "Service Request Comments" field.
8. Select the team member(s) responsible for handling your service request in the "Assigned To" field.

## Field-by-Field Explanation
* **Service Request**: A brief description of your service request.
  * Type: text
  * Required: Optional
* **Issue Summary**: A concise summary of the issue or problem you are experiencing.
  * Type: text
  * Required: Optional
* **Report Details**: More details about the issue, including any supporting information.
  * Type: text
  * Required: Optional
* **Contact Information**: Your name, department, and contact email or phone number.
  * Type: text
  * Required: Optional
* **Service Category**: Select the category that best fits your service request.
  * Type: select_one
  * Required: Optional
* **Service Priority**: Choose the priority level of your request (e.g., high, medium, low).
  * Type: select_one
  * Required: Optional
* **Requested By**: If you are requesting on behalf of someone else, indicate who.
  * Type: select_multiple
  * Required: Optional
* **Service Request Comments**: Additional comments or context about your request.
  * Type: text
  * Required: Optional
* **Assigned To**: Select the team member(s) you would like to handle your request.
  * Type: select_multiple
  * Required: Optional
