# virtual_event_equipment_request_form - Help Guide
## Purpose
The purpose of this form is to request virtual event equipment for an event. This form helps the event planner to gather necessary information for the event's logistics.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Details page with the relevant information about the event.
2. Provide the start and end times of the event in the Start Time and End Time fields.
3. If necessary, fill in the Delivery Details page with information about equipment delivery and pick-up.
4. On the Equipment Requested page, select 'Yes' to indicate that equipment is required for the event.
5. If applicable, provide a preferred delivery date on the Preferred Delivery Date field.
6. Fill in the delivery address, return instructions, and any special instructions on their respective pages.
7. Enter the contact person's name, email, and phone number on the Contact Information page.
8. Finally, fill in any additional event details on the Additional Event Details pages.

## Field-by-Field Explanation

* **Event Details**: This page is where you can enter general information about the event, such as its name and location.
* **Start Time**: Enter the start time of the event in 24-hour format (e.g., 14:00 for 2 PM).
* **End Time**: Enter the end time of the event in 24-hour format (e.g., 17:00 for 5 PM).
* **Delivery Details**: If equipment will be delivered to the event location, fill in this page with the delivery details.
* **Equipment Requested**: Select 'Yes' if equipment is required for the event. This is necessary for the event planner to know whether to provide equipment or not.
* **Preferred Delivery Date**: If you have a preferred delivery date, enter it in this field.
* **Delivery Address**: Enter the address where the equipment will be delivered.
* **Return Instructions**: Provide instructions on how the equipment will be returned after the event.
* **Special Instructions**: If there are any special instructions for the event, fill them in this field.
* **Contact Person**: Enter the name of the person responsible for the event.
* **Contact Email**: Enter the email of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.
* **Additional Event Details**: Fill in any additional information about the event that might be useful for the event planner.
