# Create New Object Form - Help Guide

## Purpose
This form is used to create a new object, which can be used to store and manage various types of data.

## How To Complete This Form
To complete this form, fill in the required and optional fields as follows:

## Field-by-Field Explanation
* **Create New Object** (`create_new_object_form_1`, text, required/optional): This is the main field to fill in the name of the new object.
* **Object Type** (`object_type`, select_multiple, optional): Choose one or more types of objects to associate with the new object.
* **Description 1** (`description_1`, text, optional): Provide a brief description of the new object.
* **Description 2** (`description_2`, text, optional): Provide additional information about the new object.
* **Date** (`date`, date, optional): Enter the date of the new object.
* **Time** (`time`, time, optional): Enter the time of the new object.
* **Email** (`email`, email, optional): Enter the email address associated with the new object.
* **Phone** (`phone`, text, optional): Enter the phone number associated with the new object.
* **Note** (`note`, note, optional): Enter any additional notes about the new object.
* **Select One 1** (`select_one_1`, select_one, optional): Choose one option from the dropdown list.
* **Select One 2** (`select_one_2`, select_one, optional): Choose one option from the dropdown list.
* **Select Multiple 1** (`select_multiple_1`, select_multiple, optional): Choose one or more options from the dropdown list.
* **Select Multiple 2** (`select_multiple_2`, select_multiple, optional): Choose one or more options from the dropdown list.
* **Decimal 1** (`decimal_1`, number, optional): Enter a decimal value.
* **Decimal 2** (`decimal_2`, number, optional): Enter a decimal value.
* **Integer 1** (`integer_1`, number, optional): Enter an integer value.
* **Integer 2** (`integer_2`, number, optional): Enter an integer value.
* **Time 1** (`time_1`, time, optional): Enter the time of the new object.
* **Time 2** (`time_2`, time, optional): Enter the time of the new object.
* **Date 1** (`date_1`, date, optional): Enter the date of the new object.
* **Date 2** (`date_2`, date, optional): Enter the date of the new object.
* **Phone 1** (`phone_1`, text, optional): Enter the phone number associated with the new object.
* **Phone 2** (`phone_2`, text, optional): Enter the phone number associated with the new object.
* **Note 1** (`note_1`, note, optional): Enter any additional notes about the new object.
* **Select One 3** (`select_one_3`, select_one, optional): Choose one option from the dropdown list.
