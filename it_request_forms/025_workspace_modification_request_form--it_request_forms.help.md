# Workspace Modification Request Form - Help Guide
## Purpose

This form is used to request modifications to a workspace. Please use this form to make an official request for changes to a workspace, ensuring that all necessary information is provided to facilitate the process.

## How To Complete This Form

1.  Fill in the required fields to the best of your ability.
2.  If a field is marked as "required", make sure to fill it in accurately and completely.
3.  If a field is optional, feel free to provide as much or as little information as you need to.
4.  If you have an attachment, please attach it to support your request.

## Field-by-Field Explanation
* **Employee Request** (`employee_request`, text, required/optional): Enter a brief description of the modification you are requesting.
* **Modification Details** (`modification_details`, text, required/optional): Provide additional information about the modification, such as what type of change is being requested.
* **Expected Date** (`expected_date`, date, required/optional): Specify the date you expect the modification to be completed. If left blank, it will be assumed to be as soon as possible.
* **Comment** (`comment`, text, required/optional): Add any additional comments or information about the request.
* **Assigned Tool** (`assigned_tool`, text, required/optional): If the modification requires the use of a specific tool, enter the name of the tool.
* **Facility Request** (`facility_request`, text, required/optional): Specify if there is a facility or resource that needs to be modified.
* **Attachment** (`attachment`, note, required/optional): If you have an additional document or file that supports your request, attach it here.
* **Email** (`email`, email, required/optional): Enter a contact email address for the person making the request.
* **Phone** (`phone`, text, required/optional): Enter a contact phone number for the person making the request.
* **Employee Request 2** (`employee_request_2`, text, required/optional): This field is a duplicate of the "Employee Request" field and is likely an error. Please only fill in this field if you are certain it should be different from the original.
