# feature_request_form - Help Guide
## Purpose
The feature request form is designed for submitting feature requests for products or features.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the **Title** of the feature you are requesting in the "Feature Request Form" field.
2. Check the box next to "Company" to indicate if the company is the requesting party.
3. Enter a brief **Description** of the feature you are requesting in the "Description" field.
4. Choose the relevant options for "Company", "Product", "Category", "Team", "Product Version", "Priority", and "Status" as they apply to your request.
5. Enter your **Email** and **Phone** in the respective fields.
6. Select the **Date Submitted** and **Time Submitted** of when you submitted the request.
7. Enter any additional **Comments** about your request.

## Field-by-Field Explanation
* **Feature Request Form** (`form_title`, text, required): Enter a brief title of the feature you are requesting.
* **Company** (`company`, checkbox, required): Check this box if the company is the requesting party.
* **Description** (`form_description`, text, required): Enter a brief description of the feature you are requesting.
* **Company** (`company`, select_multiple, optional): Select the company that is requesting the feature.
* **Product** (`product`, select_multiple, optional): Select the product that the feature is related to.
* **Category** (`category`, select_one, optional): Select the category that the feature belongs to.
* **Team** (`team`, select_multiple, optional): Select the team that the feature is related to.
* **Product Version** (`product_version`, select_one, optional): Select the product version that the feature is related to.
* **Priority** (`priority`, select_one, optional): Select the priority of the feature.
* **Status** (`status`, select_multiple, optional): Select the status of the feature.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Date Submitted** (`date_submitted`, date, optional): Select the date when you submitted the request.
* **Time Submitted** (`time_submitted`, time, optional): Select the time when you submitted the request.
* **Comments** (`comments`, text, optional): Enter any additional comments about your request.
* **Date Required** (`date_required`, date, optional): Select the date by when the feature is required.
* **Active/Inactive** (`status`, select_multiple, optional): Select the status of the feature.
