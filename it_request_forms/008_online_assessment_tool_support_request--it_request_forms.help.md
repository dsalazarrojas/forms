# Online Assessment Tool Support Request - Help Guide
## Purpose
The form is intended to collect information about issues or problems you're facing while using the online assessment tool, allowing our support team to better understand and resolve these problems.

## How To Complete This Form
Complete this form by entering the required and optional fields. Each field has been designed to help us understand the issue you're experiencing, so please fill in each field as accurately and concisely as possible. You can save and submit your request at any time.

## Field-by-Field Explanation

* **User Name (text, required)**: Enter the name of the user (you) submitting this form. This will help our support team identify and address the issue correctly.
* **Email (email, required)**: Enter your official email address. This will allow us to contact you directly and keep you updated on the progress of your issue.
* **Phone (text, optional)**: If you prefer to be contacted via phone, you can enter a valid phone number here. Please note that this is not a mandatory field.
* **Issue (text, optional)**: Describe the problem you're experiencing with the online assessment tool. Try to be as detailed and concise as possible so we can better understand the issue.
* **Issue Description (text, optional)**: Provide a more detailed description of the issue. This will help our support team better understand your concerns.
* **Urgency (select_one, optional)**: Choose whether your issue is urgent or not. Select "Yes" if you need immediate attention, and "No" if it's not time-sensitive.
* **Selected Urgency (select_multiple, optional)**: Choose all that apply to your issue. For example, if you selected "Yes" for Urgency, select "Yes" here as well.
* **Comments (text, optional)**: Share any additional information you think would be helpful for us to resolve your issue.
* **Attachments (note, optional)**: Attach any files or screenshots that can help our support team better understand your issue.

## Tips
- Be as detailed and concise as possible when filling out each field.
- If you're unsure about any field, don't hesitate to ask our support team for clarification.
- Please note that all fields are optional, but providing as much information as possible will help us resolve your issue more efficiently.
