# HVAC Control System Request Form - Help Guide
## Purpose
The HVAC Control System Request Form is used to report any issues or problems with the HVAC control system. This form allows users to provide information about the facility, issue, and desired outcome.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the facility from the "Facility" dropdown list.
2. Provide a brief problem description in the "Problem Description" field.
3. Indicate whether the issue is a problem with the HVAC control system ("Issue Category").
4. Enter the room number where the issue is located.
5. Enter the equipment ID or any other relevant information.
6. Provide the issue date.
7. Describe the issue in more detail.
8. If necessary, provide an adjustment request.
9. Enter the contact person's name and email address.
10. Enter the phone number of the contact person.
11. Provide any additional comments or comments.
12. If necessary, upload attachments.
13. Select the facility status.
14. Select the issue status.
15. Select whether the issue has been assigned to someone.
16. Select the priority of the issue.
17. Enter the due date for the issue resolution.
18. Enter the date the issue was closed.
19. Select whether the issue was closed by someone.
20. Select whether the issue was resolved.
21. Upload any additional attachments.

## Field-by-Field Explanation

* **Facility**: Select the facility where the issue is located.
* **Problem Description**: Provide a brief description of the problem.
* **Issue Category**: Indicate whether the issue is a problem with the HVAC control system.
* **Room Number**: Enter the room number where the issue is located.
* **Equipment ID**: Enter the equipment ID or any other relevant information.
* **Issue Date**: Enter the date the issue started.
* **Issue Description**: Provide a detailed description of the issue.
* **Adjustment Request**: If necessary, describe the adjustment request.
* **Contact Person**: Enter the name and email address of the contact person.
* **Phone Number**: Enter the phone number of the contact person.
* **Comment**: Provide any additional comments or comments.
* **Attachment**: If necessary, upload attachments to support the issue.
* **Facility Status**: Select the status of the facility.
* **Issue Status**: Select the status of the issue.
* **Assigned To**: Select whether the issue has been assigned to someone.
* **Priority**: Select the priority of the issue.
* **Due Date**: Enter the date the issue is due to be resolved.
* **Closed Date**: Enter the date the issue was closed.
* **Closed By**: Select whether the issue was closed by someone.
* **Resolved**: Select whether the issue was resolved.
* **Attachment 1**: If necessary, upload attachment 1.
