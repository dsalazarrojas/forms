# Managed Security Services Pricing Request Form - Help Guide
## Purpose
This form is for customers to request managed security services from the company. Please fill out this form to provide information about your security needs and preferences.

## How To Complete This Form
- Fill out the form completely and accurately with your information and preferences.
- Select one or more services you are interested in from the "Services Requested" field.
- Choose the "Security Level" that best describes your security needs.
- If applicable, input your budget for the services.
- Add any additional information or context in the "Description" field.

## Field-by-Field Explanation
* **Managed Security Services Pricing Request** (page 1): This is the title of the form.
* **Customer Name** (Customer Name, text, optional): Enter your name as you would like to be referred to by the company.
* **Company** (Company, text, optional): Enter your company name (if applicable).
* **Email** (Email, email, optional): Enter a valid email address where you can be reached by the company.
* **Phone** (Phone, text, optional): Enter your phone number (if applicable).
* **Services Requested** (Services Requested, select multiple, optional):
	+ Penetration Testing: Select this option if you are interested in simulating cyber attacks on your network or system.
	+ Vulnerability Assessment: Select this option if you would like to identify vulnerabilities in your network or system.
	+ Compliance Audit: Select this option if you are looking for a comprehensive audit of your security practices and policies.
	+ Security Consulting: Select this option if you need professional advice on how to improve your security posture.
* **Security Level** (Security Level, select one, optional):
	+ Basic: Select this option if you are looking for a basic level of security service.
	+ Premium: Select this option if you are looking for a higher level of security service.
	+ Enterprise: Select this option if you are looking for a comprehensive, high-end security service.
* **Budget** (Budget, number, optional): Enter your budget for the services you are requesting.
* **Description** (Description, text, optional): Add any additional information or context about your security needs and preferences.
