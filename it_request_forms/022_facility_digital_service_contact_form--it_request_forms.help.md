# Facility Digital Service Contact Form - Help Guide
## Purpose
This form is designed to help facilities contact digital service support when they experience issues. It helps the support team to quickly identify the location and priority of the issue, making it easier to allocate resources and provide timely assistance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the location where you are experiencing the issue from the list of options.
2. Choose the priority for this issue (High, Medium, or Low).
3. Enter your contact email address so that the support team can reach out to you.
4. If you have a phone number, please enter it so that we can contact you if needed.
5. Provide more details about the issue in the comments field.
6. Select the facility that is experiencing the issue from the list of options.
7. If you have any comments or additional information, please provide them in the comments field.

## Field-by-Field Explanation

* **What is the location where you are experiencing the issue?** (Select One, Required)
	+ This field allows you to select the location where you are experiencing the issue. Choose the option that best describes your location.
* **What is your priority for this issue?** (Select Multiple, Required)
	+ This field helps us understand the urgency of the issue. Select the priority that best describes the situation.
* **What is your contact email?** (Email, Required)
	+ This field is where you enter your contact email address so that we can reach out to you for further information or to provide assistance.
* **Do you have a phone number to contact you?** (Text, Not Required)
	+ If you have a phone number, please enter it so that we can contact you if needed.
* **Please provide more details about the issue** (Text, Not Required)
	+ This field is where you can provide more information about the issue you are experiencing.
* **What facility is experiencing the issue?** (Select Multiple, Required)
	+ This field allows you to select the facility that is experiencing the issue.
* **Do you have any comments?** (Text, Not Required)
	+ If you have any additional comments or information, please provide them here.
* **How do you want to be contacted?** (Text, Not Required)
	+ This field is where you can specify how you want to be contacted (e.g., phone, email, or in-person).
* **Facility Digital Service Contact Form Comments 3** (Text, Not Required)
	+ This field is for additional comments or information.
