# Time Flow Diagram Improvement Request - Help Guide
## Purpose
This form is used to submit requests for improvement suggestions on existing Time Flow Diagrams. The form is intended for users to provide detailed feedback on what needs to be improved or fixed on the Time Flow Diagram, allowing the team to make adjustments and enhancements as needed. 

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your **User Name** and **Email** in the respective text fields. These are mandatory fields and are used to identify you as the submitter of the request.
2. Fill in your **Phone** (optional) if you have a preferred contact number.
3. Enter a detailed **Description** of the improvement suggestions you have for the Time Flow Diagram. This is a mandatory field and is used to explain the changes you want to see made.
4. Select the **Category** of the improvement request, which could be **Operations**, **Engineering**, or **Quality**.
5. Choose the **Teams** involved in the improvement request. You can select multiple teams, such as **Operations**, **Engineering**, or **Quality**.
6. Set the **Status** of the improvement request, which can be **Active**, **On Hold**, or **Closed**.
7. Choose the **Priority** of the improvement request, which can be **High**, **Medium**, or **Low**.
8. Select whether the improvement request is to be **Assigned To** someone, which can be either **Yes** or **No**.
9. Fill in the **Date** when you want the improvement request to be implemented, using the date picker.

## Field-by-Field Explanation
- **User Name**: Your name, which is mandatory and will be used to identify you as the submitter of the request.
  * Type: Text
  * Required: Yes
- **Email**: Your email address, which is mandatory and is used to contact you about the improvement request.
  * Type: Email
  * Required: Yes
- **Phone**: Your preferred phone number, which is optional and can be used for further clarification or discussion.
  * Type: Text
  * Required: No
- **Description**: A detailed description of the improvement suggestions you have for the Time Flow Diagram.
  * Type: Text
  * Required: Yes
- **Category**: The category of the improvement request, which can be **Operations**, **Engineering**, or **Quality**.
  * Type: Select One
  * Required: Yes
- **Team(s)**: The teams involved in the improvement request.
  * Type: Select Multiple
  * Required: Yes
- **Status**: The status of the improvement request, which can be **Active**, **On Hold**, or **Closed**.
  * Type: Select One
  * Required: Yes
- **Priority**: The priority of the improvement request, which can be **High**, **Medium**, or **Low**.
  * Type: Select One
  * Required: Yes
- **Assigned To**: Whether the improvement request is assigned to someone, which can be **Yes** or **No**.
  * Type: Select One
  * Required: Yes
- **Date**: The date when you want the improvement request to be implemented.
  * Type: Date
  * Required: Yes
