# it_support_authorization_form - Help Guide
## Purpose
The it_support_authorization_form is used to request access to IT systems and resources on behalf of employees. This form is essential for documenting and tracking access levels.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if the requesting person is an employee. If they are not, do not fill out the other fields.
2. Fill out the Employee Name field with the name of the requesting person.
3. Select the Department of the requesting person from the available options.
4. Enter the Job Title of the requesting person.
5. If the requesting person is currently not allowed access, select 'No' for Employee, and fill out the Access Date and Access Time fields to denote the start of access.
6. Select the Access Type of the requesting person's access level.
7. Select the Access Level of the requesting person's access level.

## Field-by-Field Explanation

- **Employee** (id: 1, label: Employee, required: false): 
  Check this box if the requesting person is an employee. If not, do not check it.
  
- **Employee Name** (id: 2, label: Employee Name, required: false): 
  Enter the name of the requesting person.
  
- **Department** (id: 3, label: Department, required: false): 
  Select the department of the requesting person from the available options.
  
- **Job Title** (id: 4, label: Job Title, required: false): 
  Enter the job title of the requesting person.
  
- **Access Date** (id: 5, label: Access Date, required: false): 
  If the requesting person's access is not currently active, enter the date when access will start.
  
- **Access Time** (id: 6, label: Access Time, required: false): 
  If the requesting person's access is not currently active, enter the time when access will start.
  
- **Access Type** (id: 7, label: Access Type, required: false): 
  Select the type of access the requesting person will have (Yes/No).
  
- **Access Level** (id: 8, label: Access Level, required: false): 
  Select the level of access the requesting person will have.
