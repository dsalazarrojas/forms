# hr_system_login_assistance_request - Help Guide
## Purpose
This form is designed to help IT and HR teams resolve login issues for employees. It is used to collect information about the employee's login problems and provide assistance.
## How To Complete This Form
To complete this form, follow these steps:
1. Enter the employee's details, including their ID and name.
2. Describe the issue they are experiencing.
3. Choose the urgency level of the issue.
4. Select the department the employee belongs to.
5. Identify the type of issue (e.g. login, password reset, etc.).

## Field-by-Field Explanation
- **Employee Details** (Employee ID, optional, text): Enter the employee's ID.
- **Issue Description** (Issue Description, optional, text): Describe the issue the employee is experiencing.
- **Urgency Level** (Urgency Level, optional, number): Choose a value to indicate the level of urgency for the issue.
- **Department** (Department, optional, select_one): Select the department the employee belongs to (e.g. HR, IT, Finance, etc.).
- **Employee Name** (Employee Name, optional, text): Enter the employee's name.
- **Issue Type** (Issue Type, optional, select_multiple): Select the type of issue (e.g. login, password reset, etc.).
 
## Tips
* Make sure to fill out all required fields.
* Be as specific as possible when describing the issue.
* Choose the correct department and issue type to ensure accurate assistance.
