# Hybrid Learning Support Desk Request Form - Help Guide
## Purpose

This form is used to submit requests for assistance with hybrid learning-related issues. If you are experiencing problems with online or blended learning, please fill out this form to report your concerns.

## How To Complete This Form

1. To complete this form, please fill in the required fields with your personal details and issue descriptions.
2. Enter your First Name, Last Name, and Email in the respective fields.
3. Enter your phone number in the Phone field.
4. Provide a detailed description of your issue in the Description field.
5. Enter the date and time you experienced the issue in the Issue Date and Issue Time fields.
6. Select the relevant Category for your issue from the provided options.
7. Choose the personnel you would like to be assigned to from the provided options in the Assigned to field.
8. Add any additional comments or notes in the Note field (optional).
9. If you would like to have an email sent to the support staff, please select the recipient in the Email Sent field (optional).

## Tips

* Please ensure that you have not already submitted a request for the same issue before filling out this form.
* Double-check your input fields for accuracy before submitting the form.
* If you have any questions or concerns, please reach out to support staff directly.
