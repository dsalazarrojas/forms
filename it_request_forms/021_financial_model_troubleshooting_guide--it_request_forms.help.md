# Financial Model Troubleshooting Guide - Help Guide
## Purpose
This form is used to report, track, and resolve issues with financial models used for decision-making and analysis.

## How To Complete This Form
1. Fill out the required fields with as much detail as possible.
2. Select the correct urgency level for the issue.
3. Describe the issue in the issue description field.
4. Specify the issue date and time.
5. Choose the relevant issue category.
6. Select the priority level of the issue.
7. Provide comments on the issue.
8. Indicate whether the issue has been resolved or closed.
9. If applicable, upload any supporting files.
10. Review and submit your form.

## Field-by-Field Explanation
- **Financial Model Issues** (`financial_model_issues`, text, optional): Briefly describe the issue with the financial model you are experiencing. This could include errors, unexpected outputs, or other problems that are affecting the model's performance.
- **Urgency** (`urgency`, select_one, optional): Indicate the urgency level for the issue, with options including Yes and No.
- **Model Version** (`model_version`, text, optional): If the issue relates to a specific version of the financial model, please specify which version.
- **Supporting Files** (`supporting_files`, text, optional): Provide any files that may be helpful in troubleshooting, such as log files or screenshots.
- **Consultant Name** (`consultant_name`, text, optional): If you are working with a consultant or expert, enter their name here.
- **Issue Description** (`issue_description`, note, optional): Describe the issue in as much detail as possible, including any error messages or symptoms.
- **Issue Date** (`issue_date`, date, optional): Enter the date the issue started or occurred.
- **Issue Time** (`issue_time`, time, optional): Enter the time the issue started or occurred.
- **Issue Category** (`issue_category`, select_multiple, optional): Select all relevant categories for the issue, such as data, model, or other.
- **Issue Priority** (`issue_priority`, number, optional): Choose a priority level for the issue, with options to be determined (e.g., 1-5).
- **Issue Status** (`issue_status`, select_one, optional): Indicate whether the issue is Active or Inactive.
- **Issue Comments** (`issue_comments`, text, optional): Add any additional comments or context about the issue.
- **Issue Resolved** (`issue_resolved`, select_one, optional): Indicate whether the issue has been resolved or not.
- **Issue Closed** (`issue_closed`, select_one, optional): Indicate whether the issue is closed or not.
- **File Uploads** (`file_uploads`, select_multiple, optional): Select whether files are uploaded as part of the issue.
- **Submit** (`submit`, text, optional): Enter any final comments or notes about the issue.
- **Email** (`email`, email, optional): Enter your contact email address.
- **Phone** (`phone`, text, optional): Enter your contact phone number.

Note: The fields marked as `optional` are not required but can be filled out if applicable and relevant to the issue.
