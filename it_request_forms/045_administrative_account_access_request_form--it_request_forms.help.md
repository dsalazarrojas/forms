# Administrative Account Access Request Form - Help Guide
## Purpose
This form is used to request access to administrative accounts within the organization. It captures essential information to facilitate the review and approval process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Ensure all required fields are filled out.
3. Provide a clear and concise business justification for the access request.
4. Enter the correct manager approval name and requested by date.
5. Specify the desired access level and account duration (if temporary or permanent).
6. Add any additional notes for the IT team.
7. Submit the form.

## Field-by-Field Explanation
* **Requester details**: This field is not used in the actual form, but it's an optional note for the form filler.
* **Requester name**: This field is a required text input where you should enter your full name.
* **Requester email**: This field is also required and should contain your work email address for follow-ups and approvals.
* **Account required**: Enter the name of the system or application you need access to.
* **Access level requested**: Select the level of access you need (Read, Write, or Admin).
* **Business justification**: Provide a clear explanation of why you need this access.
* **Manager approval name**: Enter the name of your manager approving this request.
* **Requested by date**: Enter the date you're requesting access.
* **Account duration**: If the access is temporary, specify how long you need it for.
* **Additional notes**: This is an optional field for any further details for the IT team.
