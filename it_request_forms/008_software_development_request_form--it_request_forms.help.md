# Software Development Request Form - Help Guide
## Purpose
This form is designed to collect requests from users for software development projects, such as bug fixes, new feature additions, or updates to existing applications. It will guide you through the necessary information for a project request.

## How To Complete This Form
1. Fill in the required information, including the project title, team name, project lead, project description, deadline, priority, budget, project status, project manager, and contact email.
2. Choose the project priority and status from the options provided.
3. Add any additional project notes if necessary.
4. Select the project manager from the provided options.
5. Complete the form and submit it for review.

## Field-by-Field Explanation
* **Project Request** (Project Request, text, optional): A brief title or description of the project.
* **Team Name** (Team Name, text, optional): The name of the team or department associated with the project.
* **Project Lead** (Project Lead, text, optional): The name of the project lead or contact person.
* **Project Description** (Project Description, text, optional): A brief description of the project, including its goals and objectives.
* **Project Deadline** (Project Deadline, date, optional): The deadline for the project completion.
* **Project Priority** (Project Priority, select_one, optional): The priority level of the project, which can be Low, Medium, or High.
* **Project Budget** (Project Budget, number, optional): The budget allocated for the project.
* **Project Status** (Project Status, select_one, optional): The current status of the project, which can be Active, On Hold, or Inactive.
* **Project Notes** (Project Notes, note, optional): Additional notes about the project.
* **Contact Email** (Contact Email, email, optional): The contact email of the person submitting the request.
* **Contact Phone** (Contact Phone, text, optional): The contact phone number of the person submitting the request.
* **Project Manager** (Project Manager, select_one, optional): The name of the project manager, which can be Jimmy, Jane, or Bob.

## Tips
* Use clear and concise language when filling in the project description and project notes.
* Ensure that the project title and deadline are accurate and realistic.
* Review and update the project status regularly to reflect the current progress.
* Respond to the project manager and team promptly to ensure that your project request is being addressed.
