# Studio Access Security Request Form - Help Guide
## Purpose
The Studio Access Security Request Form is used to submit a request for temporary access to a studio. It is intended for team members or external collaborators who need access to specific resources or services within the studio for a short period of time.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the required information for the request.
2. Choose the correct access duration from the dropdown menu.
3. Enter any additional contact information if necessary.
4. Add any relevant comments or details about the request.
5. Review your submission before clicking the 'Submit' button to ensure all required fields are complete.

## Field-by-Field Explanation
- **Studio Request Form** (`studio_request_form`, text, optional): This field is for a brief description of your request.
  Enter a short description of why you need access to the studio.
  This field is optional, but it's a good opportunity to provide context for your request.
- **Contact Information** (`contact_information`, text, optional): This field is for any additional contact information you'd like to provide.
  If you have any contact information, enter it here so that studio administrators can get in touch with you.
  This field is optional, but it can help speed up the response time.
- **Contact Email** (`contact_email`, text, optional): This field is for your email address.
  Enter your email address so that studio administrators can contact you about your request.
  This field is optional, but it's recommended for communication purposes.
- **Request Date** (`request_date`, date, optional): This field is for the date you're requesting access.
  Enter the date when you'd like to start your access period.
  This field is optional, but it helps studio administrators plan and schedule access accordingly.
- **Request Duration** (`access_duration`, select_one, required): This field is for selecting the length of time you need access.
  Choose how long you need access to the studio, from 15 minutes to 1 hour.
  This field is required, as it helps studio administrators plan and schedule access accordingly.
- **Contact Phone** (`contact_phone`, text, optional): This field is for your phone number.
  Enter your phone number so that studio administrators can contact you about your request.
  This field is optional, but it can help with communication and scheduling.
- **Requesters Details** (`requesters_details`, text, optional): This field is for any additional details or comments.
  Enter any information that might be helpful for studio administrators to consider when reviewing your request.
  This field is optional, but it can provide context for your request.
- **Comments** (`studio_access_request_form_comments`, text, optional): This field is for any additional comments or questions.
  Enter any comments or questions you have about your request.
  This field is optional, but it can help studio administrators understand your needs.
- **Submit** (`request_form_submit`, text, optional): This field is not really a field, but rather a button.
  Click this button to submit your request once all required fields are complete.

## Tips
* Ensure all required fields are complete before clicking the 'Submit' button.
* Be as detailed as possible in the 'Requesters Details' field to help studio administrators understand your needs.
* If you have any questions or concerns, contact studio administrators before submitting the form.
* This form is for temporary access requests, so don't submit duplicate requests if your needs haven't changed.
