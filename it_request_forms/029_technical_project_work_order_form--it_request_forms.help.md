Technical Project Work Order Form - Help Guide
===========================================

## Purpose
This form is designed to create and manage technical project work orders for IT projects. It captures essential details about the project, including the requestor, request type, priority, and expected completion date.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (\*).
2. Select the correct priority level and request type from the drop-down menus.
3. Enter the requestor's name and any additional comments.
4. Choose the expected completion date.
5. Select the owner and status of the project.

## Field-by-Field Explanation
### Request Form 
* **Request Form** (`request_form`, text, optional): Enter a brief description of the project request.
* **Priority** (`priority`, select_one, optional): Select the priority level: Low, Medium, or High.
* **Request Type** (`request_type`, select_one, optional): Choose from Bug Fix, New Feature, or Enhancement.
* **Requestor** (`requestor`, text, optional): Enter the name of the person making the request.
* **Description** (`description`, text, optional): Enter a detailed description of the project.
* **Priority Date** (`priority_date`, date, optional): Enter the expected priority date for the project.
* **Completion Date** (`completion_date`, date, optional): Enter the expected completion date for the project.
* **Owner** (`owner`, select_one, optional): Choose from IT, Engineering, or Operations.
* **Comments** (`comments`, text, optional): Enter any additional comments about the project.
* **Assigned To** (`assigned_to`, text, optional): Enter the name of the person assigned to work on the project.
* **Status** (`status`, select_one, optional): Select the current status: Open, In Progress, or Closed.

## Tips
* Make sure to fill in all required fields (\*) to avoid errors.
* Select the correct priority and request type to ensure timely completion.
* Enter accurate and detailed descriptions to facilitate project management.
