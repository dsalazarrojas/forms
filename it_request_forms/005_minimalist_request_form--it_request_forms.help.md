# Minimalist Request Form - Help Guide
## Purpose
The Minimalist Request Form is a simple tool for requesting tasks, resources, or services. Fill out this form to submit your request and provide as much information as possible.

## How To Complete This Form
1. Fill out all required fields: First Name, Last Name, Phone Number, Department, Description, and Priority.
2. If you have a due date or time for the request, please enter it. This is not required.
3. Add any additional notes that are relevant to the request.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Please enter your first name as it is written on your official identification.
* **Last Name** (`last_name`, text, required): Please enter your last name as it is written on your official identification.
* **Email** (`email`, email, optional): If you have an email address that you would like to be contacted at, please enter it here.
* **Phone Number** (`phone_number`, text, required): Please enter your phone number that can be used to contact you.
* **Department** (`department`, text, required): Please select the department or team that your request is related to.
* **Description** (`description`, text, required): Please describe your request in a clear and concise manner.
* **Priority** (`priority`, select_one, required): Please select the priority level for your request (Normal, High, or Low).
* **Due Date** (`due_date`, date, optional): If you have a specific due date for your request, please enter it here.
* **Time** (`time`, time, optional): If you have a specific time for your request, please enter it here.
* **Note** (`note`, note, required): Please add any additional notes that are relevant to your request.

## Tips
* Make sure to fill out all required fields to ensure your request is processed correctly.
* If you have any trouble filling out this form, please contact the support team.
* Please be as detailed as possible in your description to help us understand your request.
