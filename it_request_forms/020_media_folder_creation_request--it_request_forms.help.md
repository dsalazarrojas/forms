# Media Folder Creation Request - Help Guide
## Purpose
The "Media Folder Creation Request" form is used to collect information about a media folder creation request from a user.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields (Priority, Type, Status).
2. Provide more information about the media folder you are requesting (Media Folder Details).
3. Identify the user requesting the media folder (Media Folder Requester).
4. Add any additional comments or information you feel is necessary (Media Folder Notes).
5. If applicable, provide the email and phone number of the media folder owner (Media Folder Email and Media Folder Phone).
6. Specify the location of the media folder (Media Folder Location).
7. Date and time when the media folder will be used or created (Media Folder Date and Time).

## Field-by-Field Explanation

* **Media Folder Creation Request**: This field is not visible to the user and is used for internal purposes.
* **Media Folder Details**: Provide more information about the media folder, such as its purpose or intended use. (text, optional)
* **Media Folder Requester**: Identify the person or department requesting the media folder. (text, optional)
* **Media Folder Description**: Describe the media folder in more detail. (text, optional)
* **Media Folder Priority**: Select the priority level of the media folder creation request (High, Low, Medium). (select_one, required)
* **Media Folder Type**: Choose the type of media folder you need (Image, Video, Audio). (select_multiple, required)
* **Media Folder Size**: Specify the expected size of the media folder. (number, optional)
* **Media Folder Status**: Select the status of the media folder creation request (Active, Inactive, Pending). (select_one, required)
* **Media Folder Notes**: Add any additional comments or information about the media folder creation request. (note, optional)
* **Media Folder Email**: Provide the email address of the media folder owner. (email, optional)
* **Media Folder Phone**: Provide the phone number of the media folder owner. (text, optional)
* **Media Folder Location**: Specify the location of the media folder. (text, optional)
* **Media Folder Date**: Specify the date when the media folder will be used or created. (date, optional)
* **Media Folder Time**: Specify the time when the media folder will be used or created. (time, optional)

## Tips
Please ensure that you fill out all required fields accurately and completely to avoid delays in the processing of your request. If you have any doubts or concerns, feel free to reach out to the relevant authorities for clarification.
