# on_call_consultant_request_form - Help Guide

## Purpose
The on_call_consultant_request_form is designed to gather information from on-call consultants who are available to provide support or assistance. This form will help ensure that the consultant is correctly matched with the request based on their availability and expertise.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of request you are submitting (Option 1, Option 2, or Option 3)
2. Enter your first name
3. Provide a description of the request
4. Select one or more on-call consultants who are available to provide support
5. Enter your contact email
6. Enter your contact phone number
7. Choose a date and time for the request
8. Enter the location of the request
9. Choose the type of request (Type 1, Type 2, or Type 3)
10. Enter any additional information

## Field-by-Field Explanation
* **on_call_request** (`select_one`, required: false): Select the type of request you are submitting. This will help match you with the correct on-call consultant.
* **name** (`text`, required: false): Enter your first name. Please keep this brief and only include your first name.
* **description** (`text`, required: false): Provide a description of the request.
* **on_call_consultant** (`select_multiple`, required: false): Select one or more on-call consultants who are available to provide support. Please make sure to select at least one consultant.
* **email** (`email`, required: false): Enter your contact email. Please ensure that this is a valid email address.
* **phone** (`text`, required: false): Enter your contact phone number.
* **date** (`date`, required: false): Choose a date for the request.
* **time** (`time`, required: false): Choose a time for the request.
* **location** (`text`, required: false): Enter the location of the request.
* **request_type** (`select_one`, required: false): Choose the type of request (Type 1, Type 2, or Type 3).
* **additional_info** (`text`, required: false): Enter any additional information related to the request.
* **submit** (`text`, required: false): Click submit to send the form.
