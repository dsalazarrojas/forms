# Guest Access Restriction Request Form - Help Guide

This form is used to request access for guests to restricted areas or resources within an organization. It captures essential information from the user and approver sides to ensure a smooth access request process.

### Form Fields:
#### 1. Guest Access Restriction Request:
   *   Description: This field is the main request section of the form.
   *   Type: Text.
   *   Mandatory: No.
   *   Note: This section captures the main reason for the access request.
#### 2. User Requester:
   *   Description: Enter your name as the person requesting access for the guest.
   *   Type: Text.
   *   Mandatory: No.
   *   Note: This field is for your reference and identification.
#### 3. User Requester Email:
   *   Description: Enter your email address.
   *   Type: Email.
   *   Mandatory: No.
   *   Note: This field is for approvers to contact you for further clarification.
#### 4. Guest Name:
   *   Description: Enter the name of the guest you want to grant access to.
   *   Type: Text.
   *   Mandatory: No.
   *   Note: This is an optional field, but helps to identify the person for whom the access is requested.
#### 5. Guest Phone:
   *   Description: Enter the phone number of the guest, if you want to grant them phone access.
   *   Type: Text.
   *   Mandatory: No.
   *   Note: This field is optional and only applicable for phone-based access.
#### 6. Department ID:
   *   Description: Enter the department ID associated with the access you want to grant.
   *   Type: Number.
   *   Mandatory: No.
   *   Note: This field is optional and only applicable for department-specific access.
#### 7. Department:
   *   Description: Select the department you want to grant access to.
   *   Type: Select Multiple.
   *   Mandatory: Yes.
   *   Note: You must select at least one department for access to be granted.
#### 8. Reason for Access:
   *   Description: Provide a clear explanation for why the guest needs access.
   *   Type: Text.
   *   Mandatory: No.
   *   Note: This field ensures that requests are specific and valid.
#### 9. Start Date:
   *   Description: Select the start date of the access, if applicable.
   *   Type: Date.
   *   Mandatory: No.
   *   Note: This field is optional and only for specific access duration.
#### 10. End Date:
   *   Description: Select the end date of the access, if applicable.
   *   Type: Date.
   *   Mandatory: No.
   *   Note: This field is optional and only for specific access duration.
#### 11. Status:
   *   Description: Indicate the status of the request.
   *   Type: Select One.
   *   Mandatory: Yes.
   *   Note: This field indicates whether the request is pending, approved, or rejected.
#### 12. Approver:
   *   Description: Indicate whether the department approver should be notified.
   *   Type: Select One.
   *   Mandatory: No.
   *   Note: This field indicates whether the approver needs to be notified.
#### 13. Approver Email:
   *   Description: Enter the approver's email address for notification.
   *   Type: Email.
   *   Mandatory: No.
   *   Note: This field is for sending a notification to the approver.
#### 14. Approver Phone:
   *   Description: Enter the approver's phone number for phone-based notification.
   *   Type: Text.
   *   Mandatory: No.
   *   Note: This field is optional and only for phone-based notification.
#### 15. Department Approver:
   *   Description: Indicate whether the department approver is responsible.
   *   Type: Select One.
   *   Mandatory: No.
   *   Note: This field indicates whether the approver is responsible.
#### 16. Notes:
   *   Description: Add any additional comments for further reference.
   *   Type: Note.
   *   Mandatory: No.
   *   Note: This field is for additional information or references.
## Tips:

*   Ensure that you are requesting access for a valid reason.
*   Provide specific details about the access request, such as start and end dates.
*   Make sure to indicate whether the department approver should be notified.
*   Enter the approver's contact information if necessary.
*   Check the status of your request regularly to ensure it is processed correctly.
