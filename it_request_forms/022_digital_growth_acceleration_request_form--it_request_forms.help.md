# Digital Growth Acceleration Request Form - Help Guide
## Purpose
The Digital Growth Acceleration Request Form is a tool for project teams and individuals to submit requests for new or ongoing projects aimed at driving digital growth within the organization. This form helps the IT department to track and prioritize these projects, ensuring that they are properly assessed, planned, and executed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct category for your project (IT Request Forms) and provide a brief title for your submission.
2. Indicate whether your project is a Growth Project.
3. Choose the status of your project.
4. Select the priority level of your project (if applicable).
5. Provide the project deadline (if applicable).
6. Enter your Project Manager, Owner, and Sponsor's names.
7. Fill out any other project details you deem relevant.

## Field-by-Field Explanation
* **IT Request Forms** (`it_request_forms`, text, required/optional): Enter a brief description of your project's category or type (e.g., 'New Project', 'Upgrade Project', etc.).
* **Growth Projects** (`growth_projects`, select multiple, optional): Check the box if your project contributes to growth acceleration (if not checked, you may want to consider not filling out this form).
* **Project Status** (`project_status`, select one, required): Choose the status of your project from the available options (New, In Progress, Completed, Cancelled).
* **Project Priority** (`project_priority`, select one, optional): Select the priority level of your project (if applicable) to help with planning and scheduling. Options: Low, Medium, High.
* **Project Deadline** (`project_deadline`, date, optional): Enter the project deadline or expected completion date, if applicable.
* **Project Manager** (`project_manager`, text, optional): Enter the name of the person responsible for managing the project.
* **Project Owner** (`project_owner`, text, optional): Enter the name of the person or team owning the project.
* **Project Sponsor** (`project_sponsor`, text, optional): Enter the name of the person or organization sponsoring the project.
* **Project Funding** (`project_funding`, text, optional): Enter any relevant project funding information.
* **Project Details** (`project_details`, text, optional): Enter any other relevant project details or notes.
* **Project Description** (`project_description`, text, optional): Enter a brief description of your project.
