# MAG Troubleshooting Request - Help Guide
## Purpose
The MAG Troubleshooting Request form is a tool used by the support team to gather information about issues with the MAG system. By providing detailed information, you can help the support team to quickly identify and resolve the problem.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Issue Category" that best describes the problem you are experiencing with the MAG system.
2. Choose the "Urgency Level" that best describes the severity of the issue.
3. If you have any relevant file attachments, such as screenshots or error logs, please upload them as a "File Attachments".
4. Enter any additional "Device Details" that might be relevant to the issue.
5. Finally, click the "Submit" button to send the form to the support team.

## Field-by-Field Explanation
- **Issue Category** (device_details, select_one): Select the category that best describes the problem you are experiencing with the MAG system.
  This field helps the support team to quickly identify the type of issue and guide further troubleshooting steps.
- **Urgency Level** (urgency_level, select_one): Choose the level of urgency that best describes the severity of the issue.
  This field helps the support team to prioritize the issue and guide further troubleshooting steps accordingly.
- **File Attachments** (file_attach, text): If you have any relevant file attachments, such as screenshots or error logs, please upload them here.
  This field allows you to share additional information that might be relevant to the issue.
- **Device Details** (page_1, text): Enter any additional details about the device or system you are experiencing the issue with.
  This field helps the support team to understand the context and guide further troubleshooting steps.
- **File Attachments** (file_attach, text): If you have any relevant file attachments, such as screenshots or error logs, please upload them here.
  This field is similar to the "File Attachments" field above, but is placed on the second page of the form for better separation.

# Tips
* Please be as detailed and informative as possible when filling out this form.
* Attach any relevant file attachments to help the support team to quickly identify and resolve the issue.
* If you are unsure about any of the fields, please let the support team know so we can guide you through the process.
* Do not fill out multiple forms for the same issue. If you have already submitted a form for a specific problem, please do not submit another one. If you have a new issue that requires attention, please fill out a new form.
