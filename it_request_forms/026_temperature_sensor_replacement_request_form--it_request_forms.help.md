# Temperature Sensor Replacement Request Form - Help Guide
## Purpose
This form is designed to gather information for a temperature sensor replacement request. Please fill it out carefully to ensure the correct replacement is processed.

## How To Complete This Form
1. Fill in your customer information, including your name and contact details.
2. Enter the serial number of the temperature sensor that needs replacement.
3. Provide the date of failure for the sensor.
4. Describe the reason for the failure of the sensor.
5. Select the status of the replacement request (if applicable).
6. If you're unsure about the replacement status, provide a reason for it.
7. Add any additional notes about the request.

## Field-by-Field Explanation
* **Customer Information** (Customer Information, Text, Required): Enter your name, company, and contact information for communication about the replacement request.
* **Serial Number** (Serial Number, Text, Required): Type in the unique serial number of the sensor that needs replacement.
* **Date of Failure** (Date of Failure, Date, Required): Enter the date when the sensor failed or stopped working properly.
* **Description of Failure** (Description of Failure, Text, Required): Briefly describe the issue with the sensor, including symptoms or error messages you experienced.
* **Replacement Status** (Replacement Status, Select One, Optional): Select the status of the replacement request (Awaiting Approval, Awaiting Replacement, Approved, or Denied).
* **Reason for Replacement Status** (Reason for Replacement Status, Text, Required): If the replacement status is not Approved, select a reason for it (e.g., 'Sensor not found', 'Order cancelled', etc.).
* **Notes** (Notes, Note, Required): Add any additional comments or information about the request, like the cause of failure or any other relevant details.

## Tips
- Be accurate when entering the serial number and date of failure to ensure the correct sensor is replaced.
- Use clear and concise language when describing the failure of the sensor.
- If you're unsure about the replacement status, provide a reason to help with the process.
