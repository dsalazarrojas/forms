# IT Service Ticket Form - Help Guide
## Purpose
The IT Service Ticket Form is a tool for submitting IT service tickets to report issues or requests for technical assistance.

## How To Complete This Form
To complete this form, follow these steps:
1. Choose the category of the issue or request (e.g., IT Request Forms, Other).
2. Enter a brief description of the issue or request.
3. Select the status of the issue or request (e.g., Open, In Progress, Closed).
4. Select the priority level of the issue or request (e.g., High, Medium, Low).
5. Choose the tool assigned to handle the issue or request (e.g., chatjimmy, other).
6. Enter the due date for the issue or request.
7. Enter the created and updated timestamps for the issue or request.
8. Enter the created and updated by information for the issue or request.
9. Enter the form ID for the issue or request.
10. Enter the output file for the issue or request.

## Field-by-Field Explanation
* **Category** (`Category 2`, `select_multiple`): Choose a category for the issue or request (e.g., IT Request Forms, Other).
* **Description** (`Description 2`, `text`): Enter a brief description of the issue or request.
* **Status** (`Status 2`, `select_one`): Select the status of the issue or request (e.g., Open, In Progress, Closed).
* **Priority** (`Priority 2`, `select_one`): Select the priority level of the issue or request (e.g., High, Medium, Low).
* **Assigned Tool** (`Assigned Tool 2`, `select_one`): Choose the tool assigned to handle the issue or request (e.g., chatjimmy, other).
* **Due Date** (`Due Date 2`, `date`): Enter the due date for the issue or request.
* **Created At** (`Created At 2`, `time`): Enter the created timestamp for the issue or request.
* **Updated At** (`Updated At 2`, `time`): Enter the updated timestamp for the issue or request.
* **Created By** (`Created By 2`, `text`): Enter the created by information for the issue or request.
* **Updated By** (`Updated By 2`, `text`): Enter the updated by information for the issue or request.
* **Form ID** (`Form ID 2`, `text`): Enter the form ID for the issue or request.
* **Output File** (`Output File 2`, `text`): Enter the output file for the issue or request.
