# shared_workspace_configuration_request - Help Guide
## Purpose
The shared workspace configuration request form is used to collect information for planning and setting up shared workspaces. This form helps the planning team to accurately determine the workspace requirements and make informed decisions about the workspace setup.

## How To Complete This Form
1. Fill out the form in its entirety, paying attention to the required fields marked with an asterisk (\*).
2. Ensure that the office location is accurately specified, as this will determine the availability of resources and services.
3. Select the correct coworking space for the requested period.
4. Indicate the facility team members responsible for the workspace.
5. Specify if the workspace is required for the selected period.
6. Enter the start and end dates for the requested workspace.
7. Enter the time required for the workspace setup.
8. Specify any special workspace needs (e.g., furniture, equipment).
9. Mention any additional amenities required for the workspace.
10. Add any additional notes about the workspace setup.

## Field-by-Field Explanation
* **Office Location** (required): Specify the exact location of the office where the shared workspace will be set up.
* **Coworking Space** (optional): Select the coworking space for the requested period. This field is optional but provides valuable information for planning purposes.
* **Facility Team** (optional): List the members of the facility team responsible for the workspace setup. This helps ensure that the team is aware of their responsibilities.
* **Needs** (required): Specify if the workspace is required for the selected period. Choose 'Yes' or 'No' accordingly.
* **Date Start** (required): Enter the start date for the requested workspace (yyyy-mm-dd format).
* **Date End** (required): Enter the end date for the requested workspace (yyyy-mm-dd format).
* **Time Required** (required): Enter the time required for the workspace setup (hh:mm format).
* **Workspace Needs** (optional): Specify any special requirements for the workspace setup (e.g., furniture, equipment).
* **Amenities** (optional): Mention any additional amenities required for the workspace.
* **Notes** (optional): Add any additional notes or comments about the workspace setup.

## Tips
* Double-check all fields for accuracy before submitting the form.
* If you're unsure about any field, do not hesitate to ask for clarification.
* Ensure that all required fields are filled out before submitting the form.
* This form will help the planning team to make informed decisions about the workspace setup. Please provide as much detail as possible to ensure the best possible outcome.
