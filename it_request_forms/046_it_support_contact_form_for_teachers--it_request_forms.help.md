# it_support_contact_form_for_teachers - Help Guide
## Purpose
This form is for teachers to report issues or seek support from the IT department.

## How To Complete This Form
To complete this form, follow these steps:

* Select whether you are seeking support or not.
* If you are seeking support, describe the issue you are facing in the "Issue" field.
* If you have any further details or description about the issue, you can add them in the "Message" field.
* If you have a specific question or need help with something, you can add more details in the "Description" field.
* You can categorize your issue as "Yes" or "No" depending on whether it's related to the category you are selecting.
* Finally, submit your request for support.

## Field-by-Field Explanation

* **Teacher** (Teacher, select_one, required):
	+ Select whether you are a teacher or not.
* **Issue** (Issue, text, required):
	+ Describe the issue you are facing.
* **Email** (Email, email, optional):
	+ Enter your email address if you want to be contacted about your issue.
* **Phone** (Phone, text, optional):
	+ Enter your phone number if you want to be contacted about your issue.
* **Message** (Message, text, optional):
	+ Add any additional information or details about your issue.
* **Description** (Description, text, optional):
	+ Provide more details about the problem you are facing.
* **Category** (Category, select_one, optional):
	+ Categorize your issue as related to the category you are selecting.
* **Submit** (Submit, text, optional):
	+ Click this button to submit your request for support.
