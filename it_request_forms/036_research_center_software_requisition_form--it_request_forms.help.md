# research_center_software_requisition_form - Help Guide
## Purpose
This form is used to request software and equipment from the research center.

## How To Complete This Form
To complete this form, follow these steps:
- Click on the form's name to open it.
- Fill in the required information for each field.
- Make sure to submit the form once you have filled in all required fields.

## Field-by-Field Explanation
### Research Center Software Request
- **Research Center Software Request** (`research_center_software_request`, text, required): This field is the main request for the software or equipment.
### Request Date
- **Request Date** (`request_date`, date, required): This field is used to record the date the request was made.
### Due Date
- **Due Date** (`due_date`, date, required): This field is used to specify when the requested software or equipment is needed by.
### Requestor
- **Requestor** (`requestor`, text, required): This field is used to identify the person making the request.
### Requestor Email
- **Requestor Email** (`requestor_email`, email, optional): This field is used to specify the email address of the person making the request (if available).
### Requestor Phone
- **Requestor Phone** (`requestor_phone`, text, optional): This field is used to specify the phone number of the person making the request (if available).
### Lab Location
- **Lab Location** (`lab_location`, text, required): This field is used to specify the location of the laboratory where the software or equipment will be used.
### Request Details
- **Request Details** (`request_details`, text, required): This field is used to provide additional information about the request, such as specific software requirements or equipment specifications.
### Supporting Materials
- **Supporting Materials** (`supporting_materials`, text, optional): This field is used to attach any relevant documentation or materials that support the request.
### Route To
- **Route To** (`route_to`, select, required): This field is used to specify where the software or equipment will be used, such as the Research Center Software and Equipment or an IT Request.
### Notes
- **Notes** (`notes`, note, optional): This field is used to add any additional notes or comments about the request.

## Tips
- Make sure to fill in all required fields.
- Review the form carefully before submitting it.
- Be specific about the software or equipment being requested.
- Attach any relevant documentation or supporting materials if possible.
