# Data Integrity Validation Request Form - Help Guide
## Purpose
The Data Integrity Validation Request Form is used to request validation for data that may be inconsistent or incorrect. It's a way to identify potential issues with data and get them resolved in a structured and organized way.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" to confirm that you need data integrity validation.
2. Choose the category of data that needs validation.
3. Provide a brief description of the data that needs validation.
4. Enter the requestor's name or contact information (email and phone number).
5. Specify if any requests for validation have been submitted before.
6. Select "Yes" or "No" to confirm if the request has been submitted before.
7. Enter the date and time when the request was submitted (if known).
8. Select the status of the request (Active or Inactive).
9. Add any additional notes about the request.
10. Select the assignee who will be responsible for validating the data.

## Field-by-Field Explanation

* **Form Data Integrity Validation** (form-data-integrity-validation): A yes/no field to confirm that you need data integrity validation.
* **Data Integrity Validation Request Category** (data_integrity_validation_request_form_it_category): Select the category of data that needs validation.
* **Data Integrity Validation Request Description** (data_integrity_validation_request_form_it_description): A text field to describe the data that needs validation.
* **Requester's Contact Information** (data_integrity_validation_request_form_it_requester): A field to enter the requestor's name, email, and phone number.
* **Requests Submitted Before** (data_integrity_validation_request_form_it_requests_submitted): A yes/no field to confirm if any requests have been submitted before.
* **Requests Submitted Count** (data_integrity_validation_request_form_it_requests_submitted_count): A yes/no field to confirm if the request has been submitted before.
* **Date Submitter** (data_integrity_validation_request_form_it_date_submitted): A date field to enter the date when the request was submitted (if known).
* **Time Submitter** (data_integrity_validation_request_form_it_time_submitted): A time field to enter the time when the request was submitted (if known).
* **Status** (data_integrity_validation_request_form_it_status): A select field to choose the status of the request (Active or Inactive).
* **Notes** (data_integrity_validation_request_form_it_notes): A text field for additional notes about the request.
* **Assignee** (data_integrity_validation_request_form_it_assignee): A select field to choose the assignee who will be responsible for validating the data.

## Tips
* Make sure to double-check the data before requesting validation.
* If you're unsure about any field, feel free to ask for help.
* Requests will be processed in the order they are received.
* The assignee will be notified about the request and will follow up with the validation results.
