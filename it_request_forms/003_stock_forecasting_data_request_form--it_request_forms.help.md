# Stock Forecasting Data Request Form - Help Guide
## Purpose
This form is designed to collect information from users related to stock forecasting data requests. It gathers details about stock symbols, forecast periods, and the intended use of the data.

## How To Complete This Form

1. To complete this form, select the stock symbol you are interested in.
2. Choose the forecast period for which you are requesting data.
3. Indicate the urgency of your data request (Low, Medium, or High).
4. Select the intended use of the data (Investment Decision Making, Data Analysis, or Other).
5. If necessary, provide additional comments about your data request.
6. If you have multiple stocks of interest, repeat steps 1-5 for each stock.

## Field-by-Field Explanation

* **Stock Symbol** (`stock_symbol`, `text`, required): Enter the stock symbol (e.g., `AAPL` for Apple Inc.).
* **Forecast Period** (`forecast_period`, `select_one`, true): Select the forecast period for which you are requesting data. Options are: One Day, Three Days, One Week, Two Weeks, or One Month.
* **Urgency** (`urgency`, `select_one`, true): Indicate the urgency of your data request. Options are: Low, Medium, or High.
* **Intended Use** (`intended_use`, `select_multiple`, false): Select the intended use of the data. Options are: Investment Decision Making, Data Analysis, or Other.
* **Stock Forecast Data Request Comments** (`stock_forecast_data_request_form_comments`, `note`, false): Provide any additional comments about your data request.
* **Stock 2** (`stock_symbol_2`, `text`, false): Enter the stock symbol for the second stock (if applicable).
* **Intended Use 2** (`intended_use_2`, `select_multiple`, false): Select the intended use of the data for the second stock (if applicable).
* **Stock Forecast Data Request Comments 2** (`stock_forecast_data_request_form_comments_2`, `note`, false): Provide any additional comments about the data request for the second stock (if applicable).
* ... (similar fields for each stock)
