# Uniform Style Guide Submission - Help Guide
## Purpose
This form is used to submit a uniform style guide for a school or company team. The guide outlines the uniform style for the team, including the type of uniform, colors, and other specific details.

## How To Complete This Form
Please fill out each field carefully, and make sure to review the field explanations below for clarification on each field.

## Field-by-Field Explanation
* **Uniform Purpose** (uniform_purpose): A brief description of the purpose of the uniform style guide.
* **Uniform Style** (uniform_style): Select the type of uniform that the guide outlines (e.g. Option 1, Option 2, or Option 3).
* **Uniform Colors** (uniform_colors): Select multiple colors that are part of the uniform style guide (e.g. Option 1, Option 2, and Option 3).
* **Uniform Branding** (uniform_branding): A brief description of the uniform's branding.
* **Uniform Sizing** (uniform_sizing and uniform_sizing_2): Enter the size of the uniform, or add additional sizing details if necessary.
* **School Company Team** (school_company_team): Select the school or company team that this uniform style guide applies to (e.g. Option 1, Option 2, or Option 3).
* **Additional Comments** (additional_comments): Use this field to add any additional comments or information related to the uniform style guide.
* **Email** (email): Enter your email address, which will be used for communication related to the uniform style guide.
* **Phone** (phone): Enter your phone number, which will be used for communication related to the uniform style guide.
* **Submit** (submit_button): This field is not actually used in the form, it seems there's a duplicate field. Please ignore it.
* **Additional Sizing** (uniform_sizing_2) and **Additional Sizing 2** (uniform_sizing_3): These fields can be used to add additional sizing details if necessary, such as sleeve length or pant length.
