# Doggie Meet & Greet Info Form - Help Guide
## Purpose
The "Doggie Meet & Greet Info Form" is used to collect information from pet owners about their pets and owners for meet and greet sessions or other pet-related purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Please fill in the pet's first name in the "First Name" field.
2. Enter the pet's last name in the "Last Name" field.
3. Input the pet's birthdate in the "Birthdate" field using the correct date format (e.g., YYYY-MM-DD).
4. Select the pet's type from the options provided in the "Type" field.
5. Enter your first name in the "Owner First Name" field.
6. Enter your last name in the "Owner Last Name" field.
7. Enter your contact email in the "Owner Email" field, following the standard email format (e.g., johndoe@example.com).
8. Enter your phone number in the "Owner Phone" field.

## Field-by-Field Explanation
- **First Name (pet_name)**: This field is for the pet's first name.
  - Type: text
  - Required: false
- **Last Name (pet_last_name)**: This field is for the pet's last name.
  - Type: text
  - Required: false
- **Birthdate (pet_birthday)**: This field is for the pet's birthdate.
  - Type: date
  - Required: false
- **Type (pet_type)**: Select the type of pet from the options provided.
  - Type: select_one
  - Required: false
  - Options: Labrador, Golden, Beagle, Poodle, Other
- **Owner First Name (owner_first_name)**: This field is for the owner's first name.
  - Type: text
  - Required: false
- **Owner Last Name (owner_last_name)**: This field is for the owner's last name.
  - Type: text
  - Required: false
- **Owner Email (owner_email)**: This field is for the owner's contact email.
  - Type: email
  - Required: false
  - Format: standard email format (e.g., johndoe@example.com)
- **Owner Phone (owner_phone)**: This field is for the owner's phone number.
  - Type: text
  - Required: false

## Tips
- Please ensure that all fields are filled in accurately and completely.
- Use the correct date format for the birthdate field.
- Select a valid pet type from the options provided.
- Enter a standard email format for the owner's email address.
- Enter a valid phone number for the owner's phone field.
