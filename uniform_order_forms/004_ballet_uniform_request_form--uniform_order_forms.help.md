# Ballet Uniform Request Form - Help Guide
## Purpose
The Ballet Uniform Request Form is designed to collect information for ballet uniform orders. This form guides you through the required details to ensure accurate and complete requests.

## How To Complete This Form
To complete this form, simply fill out the following fields:

1. Enter the student's full name in the "Student full name" field.
2. Select the class level the student attends from the options provided in the "Class level" field.
3. Choose the type of uniform item to order in the "Uniform item requested" field.
4. Select the size that best fits the student in the "Size" field.
5. Enter the quantity of items to order in the "Quantity" field.
6. Enter the name on the billing account if different from the student's name in the "Billing contact name" field (optional).
7. Add any special instructions or tailoring requests in the "Special instructions" field (optional).

## Field-by-Field Explanation

* **Student full name** (`student_name`, text, required): Enter the full name of the student as it appears on their student account.
* **Student age** (`student_age`, number, optional): This field helps determine proper sizing recommendations for the uniform.
* **Class level** (`class_level`, select_one, required): Select the class level the student is currently attending.
* **Uniform item requested** (`uniform_item`, select_one, required): Choose the type of uniform to order (Leotard, Tutu, Tights, Warm-up jacket).
* **Size** (`size`, select_one, required): Select the size that best fits the student. Options include XS, S, M, L, XL.
* **Chest measurement cm** (`chest_measure_cm`, number, optional): Enter the student's chest measurement in centimeters if you have this information.
* **Waist measurement cm** (`waist_measure_cm`, number, optional): Enter the student's waist measurement in centimeters if you have this information.
* **Preferred color** (`preferred_color`, text, optional): Enter a preferred color or the school-approved color for the uniform.
* **Quantity** (`quantity`, number, required): Enter the number of uniform items to order.
* **Billing contact name** (`billing_contact`, text, optional): Enter the name on the billing account if different from the student's name.
* **Special instructions** (`special_instructions`, text, optional): Add any special instructions or tailoring requests in this field.
