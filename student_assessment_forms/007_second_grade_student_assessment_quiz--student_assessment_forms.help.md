# second_grade_student_assessment_quiz - Help Guide
## Purpose
This form is a student assessment quiz used to evaluate the performance of a student in various subjects.
## How To Complete This Form
To complete this form, please follow the instructions above.
## Field-by-Field Explanation
* **Student Name** (`Student Name`, `text`, required): Enter the student's name as they are known in the class.
* **Math Score** (`math_score`, `number`, required): Enter the student's math score, which should be a numerical value between 1 and 10.
* **Reading Score** (`reading_score`, `number`, optional): Enter the student's reading score, which should be a numerical value between 1 and 10.
* **Writing Score** (`writing_score`, `number`, optional): Enter the student's writing score, which should be a numerical value between 1 and 10.
* **Science Score** (`science_score`, `number`, optional): Enter the student's science score, which should be a numerical value between 1 and 10.
* **Student ID** (`student_id`, `text`, optional): Enter the student's ID, if applicable.
* **Teacher Comments** (`teacher_comments`, `text`, optional): Enter any comments or feedback from the teacher.
* **Parent Comments** (`parent_comments`, `text`, optional): Enter any comments or feedback from the parent.
* **Student Survey** (`student_survey`, `select_one`, required): Select one of the options to indicate whether the student is:
	+ On task: The student is completing the assigned work and staying focused.
	+ Not on task: The student is not completing the assigned work or is frequently distracted.
* **Teacher Survey** (`teacher_survey`, `select_multiple`, optional): Select all that apply to indicate the teacher's level of agreement with the following statements:
	+ Always on task
	+ Sometimes on task
	+ Rarely on task
* **Math Comments** (`math_comments`, `text`, optional): Enter any comments or feedback specific to math.
* **Reading Comments** (`reading_comments`, `text`, optional): Enter any comments or feedback specific to reading.
* **Writing Comments** (`writing_comments`, `text`, optional): Enter any comments or feedback specific to writing.
* **Science Comments** (`science_comments`, `text`, optional): Enter any comments or feedback specific to science.
* **Class Notes** (`class_notes`, `text`, optional): Enter any additional notes or comments about the class.
* **Student Survey 2** (`student_survey_2`, `select_one`, optional): Select one of the options to indicate whether the student is:
	+ On task: The student is completing the assigned work and staying focused.
	+ Not on task: The student is not completing the assigned work or is frequently distracted.
* **Teacher Survey 2** (`teacher_survey_2`, `select_multiple`, optional): Select all that apply to indicate the teacher's level of agreement with the following statements:
	+ Always on task
	+ Sometimes on task
	+ Rarely on task
* **Math Survey** (`math_survey`, `select_one`, required): Select one of the options to indicate the student's math performance:
	+ Strong
	+ Weak
* **Reading Survey** (`reading_survey`, `select_one`, required): Select one of the options to indicate the student's reading performance:
	+ Strong
	+ Weak
* **Writing Survey** (`writing_survey`, `select_one`, required): Select one of the options to indicate the student's writing performance:
	+ Strong
	+ Weak
* **Science Survey** (`science_survey`, `select_one`, required): Select one of the options to indicate the student's science performance:
	+ Strong
	+ Weak
* **Teacher Comments 2** (`teacher_comments_2`, `text`, optional): Enter any comments or feedback from the teacher.
* **Parent Comments 2** (`parent_comments_2`, `text`, optional): Enter any comments or feedback from the parent.
* **Student Comments** (`student_comments`, `text`, optional): Enter any comments or feedback from the student.
* **Class Survey** (`class_survey`, `select_multiple`, optional): Select all that apply to indicate the class's performance:
	+ Strong
	+ Weak

## Tips
* Please enter accurate and detailed comments where possible.
* Please use the options provided for the surveys to ensure consistency in assessment.
* This form is designed to help track student performance and provide feedback for improvement.
