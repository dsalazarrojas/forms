# Mark Lesson As Completed - Help Guide

## Purpose
The "Mark Lesson As Completed" form is used to update the status of a lesson to mark it as completed or not. This form helps to keep the lesson database up-to-date and reflects the lesson completion status accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the options for each field to ensure you are selecting the correct status for the lesson.
2. Select the status of the lesson using the select_one options.
3. Provide any additional notes if necessary using the notes field.
4. Submit the form to update the lesson status.

## Field-by-Field Explanation

* **lesson_one**: 
  Select the status of the lesson as either "Yes" or "No".

* **lesson_one_date**:
  Enter the date when the lesson was completed or last updated.

* **lesson_one_status**:
  Select the current status of the lesson as either "Active" or "Inactive".

* **lesson_one_notes**:
  Provide any additional comments or notes about the lesson.

* **lesson_one_completed**:
  Select "Yes" if the lesson is completed, and "No" otherwise.

Note: All fields are optional unless marked as required in the form schema. 

## Tips
- Ensure that you are filling out the form for the correct lesson.
- Double-check the options before selecting the correct status for the lesson.
- Use the notes field to provide any additional context about the lesson.
