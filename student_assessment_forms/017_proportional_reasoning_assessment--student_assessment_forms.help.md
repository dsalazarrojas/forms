# Proportional Reasoning Assessment - Help Guide

## Purpose
The Proportional Reasoning Assessment is a tool for formative or summative evaluations of a student's proportional reasoning ability. It is used to assess the student's understanding, concept, application, performance, growth, and other attributes in relation to the mathematical concept of proportionality.

## How To Complete This Form

1. Select the options that best describe the student's proportional reasoning ability for each question.
2. Provide detailed comments and suggestions in the teacher comment and teacher suggestion fields.
3. Indicate whether or not the student has demonstrated proportional reasoning in each section.
4. Review and adjust your answers accordingly, as the student's ability may change over time.

## Field-by-Field Explanation

* **Proportional Reasoning Assessment** (`student_assessment_forms`, select_multiple, optional): Select all options that apply to the student's proportional reasoning ability.
	+ Select one or more of the options: Yes or No.
* **Student Understanding** (`student_understanding`, select_one, optional): Choose the option that best describes the student's understanding of proportional relationships.
	+ Select one of the options: Yes or No.
* **Student Concept** (`student_concept`, select_multiple, optional): Select all options that apply to the student's concept of proportional relationships.
	+ Select one or more of the options: Yes or No.
* **Student Application** (`student_application`, select_one, optional): Choose the option that best describes the student's ability to apply proportional relationships.
	+ Select one of the options: Yes or No.
* **Student Performance** (`student_performance`, select_one, optional): Choose the option that best describes the student's performance in proportional reasoning tasks.
	+ Select one of the options: Yes or No.
* **Student Growth** (`student_growth`, select_multiple, optional): Select all options that apply to the student's growth in proportional reasoning ability.
	+ Select one or more of the options: Yes or No.
* **Teacher Assessment** (`teacher_assessment`, select_multiple, optional): Select all options that apply to the teacher's assessment of the student's proportional reasoning ability.
	+ Select one or more of the options: Yes or No.
* **Student Feedback** (`student_feedback`, select_multiple, optional): Select all options that apply to the student's feedback about their proportional reasoning ability.
	+ Select one or more of the options: Yes or No.
* **Teacher Comment** (`teacher_comment`, note, optional): Provide a comment about the student's proportional reasoning ability.
* **Teacher Suggestion** (`teacher_suggestion`, note, optional): Provide a suggestion for the student to improve their proportional reasoning ability.

## Tips

* Please answer each question based on your assessment of the student's ability.
* Use the teacher comment and teacher suggestion fields to provide more detailed feedback and guidance.
* Review and adjust your answers accordingly, as the student's ability may change over time.
