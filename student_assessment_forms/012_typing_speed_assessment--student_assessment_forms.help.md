# Typing Speed Assessment - Help Guide
## Purpose

This form is designed to evaluate a user's typing speed and accuracy over multiple tests. It's essential to complete this form accurately to obtain a comprehensive assessment of your typing performance.

## How To Complete This Form

1. Select the appropriate speed test from the options provided. You can choose one or multiple tests to assess your typing speed.
2. For each selected test, enter your accuracy results and speed results as prompted.
3. Enter the time taken to complete each test and the average time per key.
4. Review all results to ensure accuracy.

## Field-by-Field Explanation

* **Speed Test 1 (Select)**: Choose one or multiple speed tests to assess your typing speed.
	+ Type: Select Multiple
	+ Required: No
* **Accuracy Results 1**: Enter your accuracy results for the selected speed test.
	+ Type: Number
	+ Required: No
* **Speed Results 1**: Enter your speed results for the selected speed test.
	+ Type: Number
	+ Required: No
* **Speed Test Results 2-10** (Select): Select speed tests to enter additional accuracy and speed results.
	+ Type: Number
	+ Required: No
* **Time to Complete** (Select): Enter the time taken to complete each selected speed test.
	+ Type: Number
	+ Required: No
* **Average Time per Key** (Select): Enter the average time per key for each selected speed test.
	+ Type: Number
	+ Required: No
* **Accuracy Results 2-6** (Select): Enter accuracy results for selected speed tests.
	+ Type: Number
	+ Required: No
* **Speed Test Results 2-10** (Select): Enter speed results for selected speed tests.
	+ Type: Number
	+ Required: No

**Tips:**

* Please ensure accurate completion of each field to obtain a comprehensive assessment of your typing performance.
* Review each field carefully to avoid errors.
* You can select multiple speed tests to assess your typing speed and accuracy comprehensively.
