# Math Multiplication Skills Assessment Quiz - Help Guide
## Purpose
The Math Multiplication Skills Assessment Quiz is a tool to evaluate students' multiplication skills by providing a set of math problems to solve.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Review the instructions and read each math problem carefully.
2. For each math problem, input the correct answer in the corresponding field.
3. When you have finished solving all math problems, select the number of problems you completed correctly from the options below.

## Field-by-Field Explanation
* **Introduction** (`introduction`, `note`, no): This page introduces the assessment quiz and provides some background information on the math problems you will be solving.
* **math_problem_1** (`math_problem_1`, `number`, no): Please input the correct answer to the first math problem.
* **math_problem_2** (`math_problem_2`, `number`, no): Please input the correct answer to the second math problem.
* **math_problem_3** (`math_problem_3`, `number`, no): Please input the correct answer to the third math problem.
* **math_problem_4** (`math_problem_4`, `number`, no): Please input the correct answer to the fourth math problem.
* **math_problem_5** (`math_problem_5`, `number`, no): Please input the correct answer to the fifth math problem.
* **Submit** (`submit`, `select_one`, yes): After solving all math problems, select the number of problems you completed correctly from the options.
