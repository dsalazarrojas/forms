# Final Assessment For Early Education - Help Guide
## Purpose
The Final Assessment For Early Education form is used to collect feedback and information from educators, instructors, or anyone who has interacted with the student. This form helps to assess a student's progress in early education, focusing on their child development, social interaction, and cognitive development.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the student you want to assess by choosing from the dropdown menu for the "Category" field.
2. Answer the multiple-choice question for the "Child Development" page, selecting one or more options from the list.
3. Provide a short description in the text field for "Comments".
4. Optionally, provide overall recommendations in the text field for "Overall Recommendations".
5. If you have a rating to give, enter a numerical value between 1 and 5 in the "Rating" field.
6. If you have a specific date, enter it in the "Date" field.
7. Enter a time in the format "HH:MM AM/PM" in the "Time" field.
8. If you need to contact the student, enter their email address in the "Email" field.
9. If you need to contact the student by phone, enter their phone number in the "Phone" field.
10. Optionally, select a tool that has been assigned to the student in the "Assigned Tool" dropdown menu.
11. Optionally, provide a description of the student's category in the "Category" field.

## Field-by-Field Explanation

* **Category (Student Assessment Forms)**: Select the student you want to assess from the dropdown menu.
* **Child Development (Select Multiple)**: Answer the multiple-choice question by selecting one or more options from the list.
* **Comments**: Provide a short description of the student's progress.
* **Overall Recommendations**: Provide overall recommendations for the student's progress.
* **Rating**: Enter a numerical value between 1 and 5 to rate the student's progress.
* **Date**: Enter a specific date in the format "MM/DD/YYYY" or "MM/DD/YY".
* **Time**: Enter a time in the format "HH:MM AM/PM".
* **Email**: Enter the student's email address if you need to contact them.
* **Phone**: Enter the student's phone number if you need to contact them.
* **Assigned Tool (chatjimmy)**: Select a tool that has been assigned to the student from the dropdown menu.
* **Category (Student Assessment Forms)**: Provide a description of the student's category.
* **Description**: This field is currently not used, it's a note field for any additional information.
