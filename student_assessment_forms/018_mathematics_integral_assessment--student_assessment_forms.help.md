# Mathematics Integral Assessment - Help Guide
## Purpose
The Mathematics Integral Assessment form is designed to collect information from students for assessment purposes in the field of mathematics.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. If applicable, enter the student's ID in the "Student ID" field.
3. Input the date and time of the assessment in the "Assessment Date" and "Assessment Time" fields, respectively.
4. Select the teacher's name in the "Teacher Name" field, if applicable.
5. Add any relevant notes about the student in the "Notes" field.
6. Input the student's email address in the "Email" field.
7. Enter the student's phone number in the "Phone" field.
8. Select one option from the "Select One" field.
9. Select multiple options from the "Select Multiple" field.

## Field-by-Field Explanation

* **Student Name**: <label> (`student_name`, `text`, required/optional): Enter the student's name.
* **Student ID**: <label> (`student_id`, `number`, optional): Enter the student's ID, if available.
* **Assessment Date**: <label> (`assessment_date`, `date`, required): Input the date of the assessment.
* **Assessment Time**: <label> (`assessment_time`, `time`, optional): Input the time of the assessment.
* **Teacher Name**: <label> (`teacher_name`, `text`, optional): Select the teacher's name, if applicable.
* **Notes**: <label> (`notes`, `note`, optional): Add any relevant notes about the student.
* **Email**: <label> (`email`, `email`, optional): Input the student's email address.
* **Phone**: <label> (`phone`, `text`, optional): Enter the student's phone number.
* **Select One**: <label> (`select_one`, `select_one`, required): Select one option from the list.
* **Select Multiple**: <label> (`select_multiple`, `select_multiple`, required): Select multiple options from the list.

## Tips
- Make sure to fill in all required fields.
- Select only one option in the "Select One" field.
- Select multiple relevant options in the "Select Multiple" field.
