# Polymer Properties Assessment - Help Guide
## Purpose
The Polymer Properties Assessment form is used to collect information about a polymer sample's properties, condition, and behavior. This form is designed to provide a structured and organized way of assessing the properties of a polymer sample.

## How To Complete This Form
1.  To complete this form, please select the correct options for each field based on the information about the polymer sample you are assessing.
2.  You are required to fill out the form in its entirety.

## Field-by-Field Explanation
* **Polymer Sample ID** (1, number, required/optional): This field is for entering the sample's unique identifier.
* **Test Condition** (2, select_one, required/optional): Please select the test condition from the provided options.
	+ 1
	+ 2
	+ 3
	+ 4
	+ 5
* **Test Temperature** (3, number, required/optional): Enter the test temperature in relevant units.
* **Polymer Type** (4, select_one, required/optional): Choose the type of polymer from the options.
	+ Polypropylene
	+ Polycarbonate
	+ Polyester
* **Test Duration** (5, number, required/optional): Enter the duration of the test.
* **Physical Characteristics** (6, select_multiple, required/optional): Select the physical characteristics of the polymer.
	+ Flexibility
	+ Strength
	+ Elasticity
	+ Hardness
* **Mechanical Behavior** (7, select_multiple, required/optional): Choose the mechanical behavior of the polymer.
	+ Damping
	+ Stiffness
	+ Hardness
	+ Toughness
* **Chemical Behavior** (8, select_multiple, required/optional): Select the chemical behavior of the polymer.
	+ Solubility
	+ Reactivity
	+ Conductivity
	+ Absorption
* **Comments** (9, note, required/optional): Provide any additional comments about the polymer sample.

## Tips
- Please ensure that you have all relevant information about the polymer sample before filling out the form.
- If you are unsure about any of the fields, please consult the relevant documentation or seek guidance from a qualified professional.
