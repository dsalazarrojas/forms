# Chinese Language Proficiency Assessment - Help Guide
## Purpose
The Chinese Language Proficiency Assessment is designed to evaluate a student's language skills, knowledge, and experience with the Chinese language. It helps to gauge their level of proficiency, identify areas of strength and weakness, and provide a basis for further language instruction and assessment. The test is used to determine eligibility for language learning programs, academic placement, and other language-related evaluations.

## How To Complete This Form
To complete the Chinese Language Proficiency Assessment, please follow the steps below:

1. Fill in all required information (indicated by a red asterisk *) for each field.
2. Answer all questions truthfully and accurately.
3. Use the provided options for select fields (e.g., select_one, select_multiple).
4. For text fields (e.g., Student Full Name, Writing Sample), provide clear and concise answers.
5. For notes fields (e.g., Background Information, Learning Goals), use the space provided to write your thoughts and responses.

## Field-by-Field Explanation

* **Student Information**: This field provides basic details about the student. Please fill in all required information.
* *Student Full Name*: Enter the student's full name in both English and Chinese characters, if applicable.
* *Chinese Name*: Enter the student's Chinese name in characters, if applicable.
* *Date of Birth*: Enter the student's date of birth.
* *Current Age*: Enter the student's current age.
* *Grade Level*: Select the student's current grade level (e.g., Elementary, Middle School, High School, College, Adult learner).
* *School or Organization*: Enter the name of the school or organization the student is associated with, if applicable.
* *Email Address*: Enter the student or parent's email address.
* *Language Background*: Write a brief description of the student's language experience and background.
* *Do you have Chinese Heritage*: Select the student's heritage background.
* *Is Chinese Spoken at Home*: Select how often Chinese is spoken at home.
* *How many years have you studied Chinese*: Select how many years the student has studied Chinese.
* *Where have you studied Chinese*: Select all applicable places where the student has studied Chinese.
* *Have you lived in a Chinese-speaking country*: Select how long the student has lived in a Chinese-speaking country.
* *Self-Assessment*: Rate the student's self-assessment level (e.g., Beginner, Elementary, Intermediate, Advanced, Fluent, Native).
* *Listening Skill*: Rate the student's listening skill level.
* *Speaking Skill*: Rate the student's speaking skill level.
* *Reading Skill*: Rate the student's reading skill level.
* *Writing Skill*: Rate the student's writing skill level.
* *Character Recognition*: Estimate the number of Chinese characters the student can recognize.
* *Pinyin Knowledge*: Rate the student's Pinyin knowledge level.
* *Tones Knowledge*: Rate the student's tones knowledge level.
* *Learning Goals*: Write a brief description of the student's learning goals.
* *Primary Goal*: Select the student's primary goal for studying Chinese.
* *Target Skills*: Select all applicable skills the student wants to improve.
* *Assessment Reason*: Select the reason for the assessment (e.g., Course placement, Program admission, Scholarship application, Employment, Personal evaluation).
* *Preferred Dialect*: Select the Chinese dialect the student is studying.
* *Simplified or Traditional Characters*: Select the character system the student prefers.
* *Additional Comments or Questions*: Write any other relevant information or questions.

Note: This help guide is a general guide and may not cover every specific question or field. Please refer to the form instructions for specific guidance.
