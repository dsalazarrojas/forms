# Scratch Knowledge Assessment - Help Guide
## Purpose
The Scratch Knowledge Assessment form is designed to evaluate a student's knowledge and skills in various areas, including coding, problem-solving, project management, and more. This form helps assessors to evaluate a student's performance and provide feedback.

## How To Complete This Form
To complete this form, follow these steps:

1.  **Student Name**: Enter the student's name.
2.  **Project Name**: Enter the name of the project being assessed.
3.  **Confidence Level**: Assess the student's confidence level regarding the project.
4.  **Skill Level**: Assess the student's skill level regarding the project.
5.  **Project Experience**: Assess the student's project experience level.
6.  **Skills**: Select all relevant skills the student possesses.
7.  **Project Expressiveness**: Assess the student's project expressiveness.
8.  **Quiz**: Select the student's confidence level regarding the quiz.
9.  **Project Expressiveness Score**: Enter a score for the student's project expressiveness.
10. **Project Experience Score**: Enter a score for the student's project experience.
11.  **Skills Score**: Enter a score for the student's skills.
12.  **Quiz Score**: Enter a score for the student's quiz.
13.  **Comments**: Provide any comments for the student.
14.  **Teacher Name**: Enter the teacher's name (optional).
15.  **Student ID**: Enter the student's ID (optional).
16.  **Student SSN**: Enter the student's SSN (optional).
17.  **Student Email**: Enter the student's email (optional).
18.  **Project ID**: Enter the project ID (optional).
19.  **Teacher ID**: Enter the teacher's ID (optional).
20.  **Assessment Date**: Select the assessment date.
21.  **Assessment Time**: Select the assessment time.
22.  **Assessment Duration**: Enter the assessment duration (optional).
23.  **Teacher Comment**: Provide any comments from the teacher (optional).
24.  **Student Comments**: Provide any comments from the student (optional).
25.  **Assessment Completed**: Mark the assessment as completed (optional).
