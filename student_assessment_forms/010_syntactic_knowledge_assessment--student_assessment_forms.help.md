# Syntactic Knowledge Assessment - Help Guide
## Purpose
The Syntactic Knowledge Assessment form is designed to gather information about language learners' knowledge and usage of sentence structure, built-for-educators, and other related aspects of language learning.

## How To Complete This Form
1. Please answer the questions based on your general knowledge and understanding of language learning.
2. Fill in the form completely and accurately, and select the correct options where applicable.
3. If you are unsure about any question, please refer to the field-by-field explanation below for clarification.

## Field-by-Field Explanation

* **Language Learners Sentence Structure** (`language_learners_sentence_structure`, text, optional):
	+ This question is asking about the structure of sentences used by language learners.
	+ Please describe a typical sentence structure used by language learners.
* **Built For** (`built_for_educators`, select_multiple, optional):
	+ This question is asking about whether the form is built for educators.
	+ Select 'Yes' if the form is designed for educators, 'No' otherwise.
* **Training Teams Data Collection** (`training_teams_data_collection`, text, optional):
	+ This question is asking about how training teams collect data.
	+ Please describe how training teams collect data, if applicable.
* **Fast Data Collection** (`fast_data_collection`, number, optional):
	+ This question is asking about how fast data collection is needed.
	+ Please enter a numerical value to indicate the speed of data collection.
* **Organized Form Submissions** (`organized_form_submissions`, select_one, optional):
	+ This question is asking about how organized form submissions are.
	+ Select 'Jotform', 'Google Forms', or 'Other' to indicate the method used.
* **Educators And Training Teams** (`educators_and_training_teams`, text, optional):
	+ This question is asking about the educators and training teams involved.
	+ Please describe the educators and training teams, if applicable.
* **Need Organized Data** (`need_organized_data`, date, optional):
	+ This question is asking about when organized data is needed.
	+ Please enter a date for when organized data is needed.
* **Language Learning** (`language_learning`, time, optional):
	+ This question is asking about language learning duration.
	+ Please enter a duration for language learning, if applicable.

## Tips
* Please answer the questions carefully and accurately.
* If you are unsure about any question, please refer to this help guide for clarification.
* If you have any further questions or need assistance, please contact us.
