# Physical Quantities Assessment - Help Guide
## Purpose
This form is used to assess physical quantities for various purposes such as quality control, inventory management, and more.

## How To Complete This Form
1. Fill out the required fields marked as `required: true`.
2. Select the appropriate unit conversions as needed.
3. Enter accurate and complete data for all fields.
4. Double-check your entries for accuracy and consistency.

## Field-by-Field Explanation

* **General Knowledge** (`general_knowledge`, text, optional): A text field for any additional information or comments.
* **Si Units** (`si_units`, select_multiple, optional): Select up to 3 units to be assessed (e.g., meter, gram, liter).
* **Unit Conversion** (`unit_conversion`, select_one, optional): Select one unit conversion (e.g., Kilogram to Gram).
* **Mass Conversion** (`mass_conversion`, select_multiple, required): Select up to 2 mass conversions (e.g., kilogram, gram).
* **Length Conversion** (`length_conversion`, select_multiple, required): Select up to 2 length conversions (e.g., Meter to Kilometer).
* **Density Conversions** (`density_conversions`, select_multiple, optional): Select up to 2 density conversions (e.g., kg/m3 to g/L).
* **Volume Conversions** (`volume_conversions`, select_multiple, optional): Select up to 2 volume conversions (e.g., L to m3).
* **Time Conversions** (`time_conversions`, select_multiple, optional): Select up to 2 time conversions (e.g., sec to min).
* **Temperature Conversions** (`temperature_conversions`, select_multiple, optional): Select up to 2 temperature conversions (e.g., C to F).
* **Pressure Conversions** (`pressure_conversions`, select_multiple, optional): Select up to 2 pressure conversions (e.g., Pa to N).
* **Energy Conversions** (`energy_conversions`, select_multiple, optional): Select up to 2 energy conversions (e.g., J to kJ).
* **Other Conversions** (`other_conversions`, select_multiple, optional): Select up to 2 other conversions (e.g., m2 to L).
* **Time** (`time`, time, required): Enter the time in the format HH:MM:SS.
* **Mass** (`mass`, number, required): Enter the mass in the format 0.#### (e.g., 1.5).
* **Length** (`length`, number, optional): Enter the length in the format 0.#### (e.g., 1.5).
* **Density** (`density`, number, required): Enter the density in the format 0.#### (e.g., 1.5).
* **Volume** (`volume`, number, optional): Enter the volume in the format 0.#### (e.g., 1.5).
* **Temperature** (`temperature`, number, required): Enter the temperature in the format 0.## (e.g., 25.5).
* **Pressure** (`pressure`, number, optional): Enter the pressure in the format 0.#### (e.g., 1.5).
* **Energy** (`energy`, number, required): Enter the energy in the format 0.#### (e.g., 1.5).
* **Additional Notes** (`note`, note, optional): Enter any additional notes or comments.
* **Email** (`email`, email, optional): Enter the email address.
* **Phone** (`phone`, text, optional): Enter the phone number.
* **Comments** (`comments`, text, optional): Enter any comments or remarks.
