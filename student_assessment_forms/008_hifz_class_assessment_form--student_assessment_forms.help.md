# Hifz Class Assessment Form - Help Guide
## Purpose
The Hifz Class Assessment Form is used to assess the performance of a class, collecting information from teachers, parents, and students to evaluate progress and identify areas of improvement.

## How To Complete This Form
1. Select the class type from the options provided: Class Teacher, Class Student, or Class Parent.
2. Enter the Hifz class name.
3. If necessary, provide an alternative Hifz class name.
4. Select the assessment date using the date picker.
5. Enter the time allocated for the assessment.
6. Enter the student ID.
7. Enter the student name.
8. If necessary, provide an alternative student name.
9. Select the assessment level: Excellent, Good, Fair, or Poor.
10. Enter notes about the assessment.
11. Enter the student email address.
12. Enter the student phone number.
13. Enter the school name.
14. Enter the school address.
15. Enter the school phone number.
16. Enter the teacher's name.
17. Enter the teacher's phone number.
18. Enter the teacher's email address.
19. Enter the school email address.
20. Select the student's level: Excellent, Good, Fair, or Poor.
21. If necessary, select additional student levels.
22. Select the student's status: Excellent, Good, Fair, or Poor.
23. If necessary, select additional student statuses.
24. Enter the number of times the student has read the Hifz Quran in a week.
25. If necessary, enter alternative times the student has read the Hifz Quran in a week.
