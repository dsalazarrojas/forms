# Special Needs Student Progress Assessment - Help Guide
## Purpose
This form is used to track the progress of students with special needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the student's file to ensure you have all necessary information.
2. Select the student's current level of needs using the "student_needs" field.
3. Choose the student's current outcomes using the "student_outcomes" field.
4. Enter the date of the last progress assessment in the "progress_start_date" field, if applicable.
5. Select the frequency of progress assessments in the "progress_frequency" field.
6. Enter any comments or notes in the "educator_comments" field.
7. Enter a progress rating, if applicable, in the "progress_rating" field.
8. Upload any relevant student progress graphs or notes in the "student_progress_graph" field.
9. Enter the date when progress assessments will next occur in the "progress_end_date" field, if applicable.
10. Enter the time period of the progress assessment in the "progress_time_period" field, if applicable.

## Field-by-Field Explanation
* **Student Needs**: This field allows you to select the student's current level of needs.
	+ Needs 1
	+ Needs 2
	+ Needs 3
* **Student Outcomes**: Select all the outcomes that apply to the student.
	+ Outcomes 1
	+ Outcomes 2
	+ Outcomes 3
* **Student Growth**: Enter the date of the last progress assessment, if applicable.
* **Next Steps**: Enter any additional comments or notes about the student's progress.
* **Progress Frequency**: Select the frequency of progress assessments.
	+ Weekly
	+ Biweekly
	+ Monthly
* **Progress Start Date**: Enter the date when progress assessments began.
* **Progress End Date**: Enter the date when progress assessments will next occur.
* **Progress Time Period**: Enter the time period of the progress assessment, if applicable.
* **Progress Rating**: Enter a progress rating, if applicable.
* **Educator Comments**: Enter any comments or notes about the student's progress.
* **Student Progress Graph**: Upload any relevant student progress graphs or notes.
* **Progress Rating**: Enter a progress rating, if applicable.
