# Learning Design Case Publication Consent Form - Help Guide

## Purpose
This form is used to obtain consent for the sharing of a Learning Design Case Study. It captures information about the case study, including its title, category, description, output file (if applicable), assigned tool, and sharing consent.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Title of the Case Study** in the "Title of the Case Study" field. This is the title that will be used to identify the case study.
2. Select the **Category of the Case Study** from the dropdown menu. Choose the category that best represents the case study.
3. Enter a brief description of the case study in the "Description of the Case Study" field. This should be a concise explanation of the case study.
4. If an output file is available, enter the path to the file in the "Output File (optional)" field. This is an optional field, so you can leave it blank if no output file is available.
5. If an assigned tool is applicable, select the tool from the "Assigned Tool" dropdown menu. This is an optional field, so you can leave it blank if no tool is assigned.
6. In the "Category of the Sharing Consent Form" field, select "Category of the Sharing Consent Form".

## Field-by-Field Explanation

* **Title of the Case Study (text)**: Enter the title of the case study.
* **Category of the Case Study (select_one)**: Choose the category that best represents the case study.
* **Description of the Case Study (text)**: Enter a brief description of the case study.
* **Output File (optional) (text)**: If an output file is available, enter the path to the file. Leave blank if no output file is available.
* **Assigned Tool (select_one)**: If an assigned tool is applicable, select the tool from the dropdown menu. Leave blank if no tool is assigned.
* **Category of the Sharing Consent Form (text)**: Select "Category of the Sharing Consent Form". This field is required and should be left as is.
