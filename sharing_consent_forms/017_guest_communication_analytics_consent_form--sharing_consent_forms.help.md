# Guest Communication Analytics Consent Form - Help Guide
## Purpose
This form is used to capture the guest's communication analytics consent, ensuring they are informed and aware of the data being collected.

## How To Complete This Form
To complete this form, follow these steps:

1. Scroll through each page to review the provided information carefully.
2. Select the "Allow tracking" option if you are willing to be tracked for analytics purposes.
3. Select the "Decline tracking" option if you are not willing to be tracked.
4. Select the "Do not track" option if you don't want to be tracked.
5. Enter your contact details, phone number, and email address (if applicable).
6. Provide any additional information you feel necessary.
7. Click the submit button to save your consent status.

## Field-by-Field Explanation

* **Guest Communication Analytics** (`communication_analytics_consent`): This is a note section to inform you about the data collected and used for analytics purposes.
* **Contact Details** (`contact_details`): Enter your name, address, and any other relevant contact information if you want to be contacted.
* **Phone Number** (`phone`): Enter your phone number if you want to be contacted by phone.
* **E-mail** (`email`): Enter your email address if you want to be contacted by email.
* **Consent** (`consent`): Select one of the options to indicate your consent status:
	+ **Allow tracking**: You are willing to be tracked for analytics purposes.
	+ **Decline tracking**: You are not willing to be tracked for analytics purposes.
	+ **Do not track**: You don't want to be tracked.
* **Additional Information** (`additional_info`): Provide any additional comments or information you feel necessary.
