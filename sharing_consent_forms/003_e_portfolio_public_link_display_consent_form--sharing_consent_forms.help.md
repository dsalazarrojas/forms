# e-portfolio-public-link-display-consent-form - Help Guide
## Purpose
This form is designed to obtain consent from users for displaying their e-portfolio in a public link.

## How To Complete This Form

To complete this form, please follow these steps:

1. Ensure that you have reviewed and understood the purpose of this form.
2. Fill in the required fields marked with an asterisk (\*). The fields that are marked with an asterisk are:
   * participant info
   * public link info
   * portfolio link url
   * assigned portfolio id
   * assigned tool id
   * assigned tool type

## Field-by-Field Explanation

* **participant info** (`participant_info`, text, required): Enter a brief description of the participant.
* **public link info** (`public_link_info`, select_one, required): Select 'yes' to agree to display your e-portfolio in a public link.
* **portfolio link url** (`portfolio_link_url`, text, required): Enter the URL of your e-portfolio.
* **consent date** (`consent_date`, date, optional): If you wish to record the date of your consent.
* **assigned portfolio id** (`assigned_portfolio_id`, number, required): Enter your portfolio ID.
* **assigned tool id** (`assigned_tool_id`, select_one, required): Select 'chatjimmy' or 'other' as the tool ID.
* **user email** (`user_email`, email, optional): Enter your email address (optional).
* **user phone** (`user_phone`, text, optional): Enter your phone number (optional).
* **user name** (`user_name`, text, optional): Enter your name (optional).
* **user title** (`user_title`, text, optional): Enter your title (optional).
* **school name** (`school_name`, text, optional): Enter your school name (optional).
* **school url** (`school_url`, text, optional): Enter your school URL (optional).
* **user password** (`user_password`, text, optional): Enter your password (optional).
* **notes** (`notes`, note, optional): Add any additional comments or notes.
* **assigned school id** (`assigned_school_id`, select_one, required): Select 'yes' to agree to display your school's information in the public link.
* **assigned school name** (`assigned_school_name`, text, optional): Enter your school name (optional).
* **assigned school url** (`assigned_school_url`, text, optional): Enter your school URL (optional).
* **assigned tool name** (`assigned_tool_name`, text, optional): Enter your tool name (optional).
* **assigned tool url** (`assigned_tool_url`, text, optional): Enter your tool URL (optional).
* **assigned tool id** (`assigned_tool_id`, select_one, required): Select 'yes' to agree to display your tool in the public link.
* **assigned tool type** (`assigned_tool_type`, text, optional): Enter your tool type (optional).
* **assigned tool version** (`assigned_tool_version`, text, optional): Enter your tool version (optional).
* **assigned tool domain** (`assigned_tool_domain`, text, optional): Enter your tool domain (optional).
