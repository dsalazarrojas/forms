# Property Management System API Consent Form - Help Guide
## Purpose
This form is used to obtain consent from property management system users to access and manage properties through the Property Management System API.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the title of the Property Management System API Consent Form.
2. Select the relevant category for your properties.
3. Enter a brief description of your properties.
4. Provide the URL of the Property Management System API.
5. Enter your API key.
6. Enter your email address.
7. Enter your phone number.
8. Choose a date for your consent.

## Field-by-Field Explanation
* **Property Management System API Consent Form** (`form_title`, text, required: false):
	+ This field is the title of the form, which is used to identify the purpose of the form.
* **Category** (`category`, text, required: false):
	+ Select the category for your properties. This will help us to filter and manage your properties more efficiently.
* **Description** (`description`, text, required: false):
	+ Enter a brief description of your properties. This will help us to understand your requirements better.
* **API URL** (`api_url`, text, required: false):
	+ Enter the URL of the Property Management System API.
* **API Key** (`api_key`, text, required: false):
	+ Enter your API key, which is used to access the Property Management System API.
* **Email** (`email`, email, required: false):
	+ Enter your email address, which will be used for communication and updates.
* **Phone** (`phone`, text, required: false):
	+ Enter your phone number, which will be used for emergency contact.
* **Date** (`date`, date, required: false):
	+ Choose a date for your consent, which is the date when you are granting permission to access your properties.
 
## Tips
- Make sure to complete all the required fields accurately to ensure a smooth submission process.
- If you're unsure about any field or have questions, please contact our support team before completing the form.
- Ensure that you have read and understood the terms and conditions before granting consent.
