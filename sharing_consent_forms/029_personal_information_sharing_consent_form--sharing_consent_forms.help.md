# Personal Information Sharing Consent Form - Help Guide
## Purpose
This guide is meant to walk you through the Personal Information Sharing Consent Form to help you understand its purpose and requirements.

## How To Complete This Form
Please follow the instructions below to complete the form:

1. Select the options that apply to you for each field.

## Field-by-Field Explanation
- **Personal Information Sharing Consent Form Data** (`personal_information_sharing_consent_form_data`, number, not required): This field is not required and will be used to gather more information.
- **Sharing Consent** (`sharing_consent`, select_one, not required): Select 'Yes' if you consent to share your personal information. Select 'No' if you do not.
- **Data Collection** (`data_collection`, select_multiple, not required): Select 'Yes' if you consent to data collection, multiple selections are allowed.
- **Information Sharing** (`information_sharing`, select_one, not required): Select 'Yes' if you consent to share your personal information. Select 'No' if you do not.
- **How would you like to share your data?** (`how_would_you_like_to_share`, select_multiple, not required): Select 'Yes' if you want to share your personal information through one of the selected methods. Select 'No' if you do not.
- **Sharing Method** (`sharing_method`, select_one, not required): Select one of the sharing methods you prefer.
- **Sharing With** (`sharing_with`, select_multiple, not required): Select who you want to share your personal information with. Select multiple options if applicable.
- **Sharing Consent Details** (`sharing_consent_details`, text, not required): Enter any additional details regarding your consent.
- **Sharing Consent Details 2-18** (`sharing_consent_details2-17`, text, not required): These fields are for any additional details regarding your consent, feel free to use as many as you like.
  Note that all the extra "Sharing Consent Details" fields can be ignored, as they are not necessary for the form's functionality.
