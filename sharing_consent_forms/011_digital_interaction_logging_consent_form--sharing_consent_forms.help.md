# Digital Interaction Logging Consent Form - Help Guide
## Purpose
This form is used to collect your consent and preferences for data logging for digital interactions. It's essential to complete this form accurately to ensure that you're comfortable with the data collection and usage.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each field carefully and make sure to understand what's being asked.
2. Answer each question truthfully, taking into account your personal preferences and requirements.

## Field-by-Field Explanation

* **User Consent (id: 1)**: Check if you agree to the digital interaction logging.
* **Monitoring Frequency (id: 2)**: Select the frequency at which you're comfortable with monitoring:
	+ Daily: Monitoring will occur every day.
	+ Weekly: Monitoring will occur every week.
* **Monitoring Method (id: 3)**: Select the methods you're comfortable with monitoring:
	+ Browser: Monitoring through the browser.
	+ Mobile App: Monitoring through the mobile app.
	+ Desktop Application: Monitoring through the desktop application.
* **Recording Frequency (id: 4)**: Select the frequency of recording:
	+ Always: Record all interactions.
	+ Sometimes: Record some interactions, not all.
	+ Never: Record no interactions.
* **Data Retention (id: 5)**: Please note, this field is not currently used for this form. You can skip this field.
* **Monitoring Location (id: 6)**: Select where you're comfortable with monitoring:
	+ Office: Monitoring will only occur in the office.
	+ Home: Monitoring will only occur at home.
	+ Both: Monitoring will occur in both the office and home.
* **Monitoring Period (id: 7)**: This field is not currently in use. You can skip this field.
* **Monitoring Method Detail (id: 8)**: Provide a detailed explanation of your preferred monitoring method(s).
* **Interaction Type (id: 9)**: Select the type of interaction you're comfortable with:
	+ Email: Monitoring through email.
	+ Chat: Monitoring through chat.
	+ Voice: Monitoring through voice.
* **Interaction Details (id: 10)**: Provide any additional details about your interaction preferences.

Note: Fields with "This field is not currently in use" are currently not implemented for this form and can be skipped.
