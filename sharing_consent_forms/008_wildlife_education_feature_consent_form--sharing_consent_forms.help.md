# Wildlife Education Feature Consent Form - Help Guide
## Purpose
This form is used to gather information about the type of media that will be used in educational content, the purpose of the content, and whether or not consent has been given for its use.

## How To Complete This Form
To complete this form, you will need to follow these steps:

1. Choose the type of media that will be used in the educational content from the options provided.
2. Select the purpose of the content from the options provided (e.g., for education, promotion, or entertainment).
3. Enter the name of the contact person responsible for the content.
4. Enter a valid email address for the contact person.
5. Enter a valid phone number for the contact person.
6. Check the box to indicate that consent has been given for the use of the media.

## Field-by-Field Explanation

* **media Type** (`media_type`, select_one, required/optional): Select the type of media that will be used in the educational content. This could be an image, video, or audio file.
* **purpose** (`purpose`, select_multiple, required/optional): Indicate the purpose of the content. This could be for education, promotion, or entertainment.
* **Contact Person** (`contact_person`, text, required/optional): Provide the name of the contact person responsible for the content.
* **email** (`email`, email, required/optional): Enter a valid email address for the contact person.
* **phone number** (`phone_number`, text, required/optional): Enter a valid phone number for the contact person.
* **consent Given** (`consent_given`, select_one, required/optional): Check this box to indicate that consent has been given for the use of the media. If the media being shared does not contain any sensitive or protected information, this box should be checked.

## Tips

* Make sure to select the correct type of media and purpose of the content to ensure accurate and relevant information is gathered.
* Ensure that the contact person's email and phone number are valid and up-to-date.
* If the media being shared does not contain any sensitive or protected information, check the "consent Given" box to indicate that consent has been granted.
