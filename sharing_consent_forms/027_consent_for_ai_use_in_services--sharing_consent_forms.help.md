# Consent For AI Use In Services - Help Guide
## Purpose
This form is designed to obtain informed consent for the use of AI technology in your services or products. Please fill this form to provide explicit consent and understanding of how your data will be handled.

## How To Complete This Form
1. Fill out each field accurately and completely.
2. If you are unsure about a field, use the available options or ask your provider for clarification.
3. Review each field carefully to ensure you understand the implications of your consent.

## Field-by-Field Explanation
* **Consent Date** (`consent_date`, Date, required): The date you are providing consent for AI use in your service or product.
* **Client Name** (`client_name`, Text, required): Your full name as the client or service recipient.
* **Email Address** (`client_email`, Email, required): Your contact email address.
* **Phone Number** (`client_phone`, Text, optional): Your contact phone number (not required but recommended).
* **Client ID Number** (`client_id`, Text, optional): A unique identifier for your account or service (not required but recommended).
* **Type of Service** (`service_type`, Select One, required): Select the type of service utilizing AI.
	+ Healthcare Consultation
	+ Legal Services
	+ Financial Advisory
	+ Educational Services
	+ Customer Support
	+ Content Creation
	+ Data Analysis
	+ Other
* **AI Technology Description** (`ai_description`, Text, required): Describe the AI technology to be used.
* **Purpose of AI Use** (`ai_purpose`, Text, required): Explain why AI will be used in your service or product.
* **Data That Will Be Processed** (`data_collected`, Select Multiple, required): Select the types of data that will be processed.
	+ Personal Information
	+ Health Information
	+ Financial Information
	+ Communication Records
	+ Behavioral Data
	+ Biometric Data
	+ None
* **Level of AI Involvement** (`ai_involvement_level`, Select One, required): Select how AI will be used.
	+ Full AI Analysis
	+ AI-Assisted Human Decision
	+ AI for Administrative Tasks Only
	+ AI for Initial Screening
	+ AI for Ongoing Monitoring
* **Human Oversight Description** (`human_oversight`, Text, required): Describe how humans will supervise AI decisions.
* **Benefits of AI Use Explained** (`benefits_explained`, Select One, required): Select whether benefits of AI use have been explained to you.
	+ Yes - Fully Understood
	+ Yes - Partially Understood
	+ False
* **Risks and Limitations Explained** (`risks_explained`, Select One, required): Select whether risks and limitations of AI use have been explained to you.
	+ Yes - Fully Understood
	+ Yes - Partially Understood
	+ False
* **Data Storage Information Provided** (`data_storage`, Select One, required): Select whether you know how data will be stored.
	+ True
	+ False
* **Data Retention Period** (`data_retention`, Text, required): Specify the period for which data will be kept.
* **Will Data Be Shared with Third Parties?** (`data_sharing`, Select One, required): Select whether data will be shared with third parties.
	+ Yes - With Named Partners
	+ Yes - With Anonymous Partners
	+ False
	+ Unsure
* **Third Party Details** (`third_party_details`, Text, optional): Provide names of third parties if data is shared.
* **Security Measures Explained** (`security_measures`, Select One, required): Select whether you understand security measures.
	+ True
	+ False
* **Right to Withdraw Understood** (`right_to_withdraw`, Select One, required): Select whether you know you can withdraw consent.
	+ Yes - Fully Understood
	+ Yes - Partially Understood
	+ False
* **Withdrawal Process Explained** (`withdrawal_process`, Select One, required): Select whether you know the withdrawal process.
	+ True
	+ False
* **Alternative Options Available** (`alternative_options`, Select One, required): Select whether alternative options are available.
	+ Yes - Full Alternative Available
	+ Yes - Partial Alternative
	+ No - AI Required for Service
* **Were Your Questions Answered?** (`questions_answered`, Select One, required): Select whether your questions were answered.
	+ Yes - All Questions Answered
	+ Yes - Some Questions Answered
	+ No - No Questions Asked
* **Your Consent Decision** (`consent_decision`, Select One, required): Select whether you consent to AI use.
	+ Yes - I Consent
	+ No - I Do Not Consent
	+ I Need More Information
* **Scope of Consent** (`consent_scope`, Select One, optional): Select what your consent covers if you select "Specific Uses Only".
	+ All AI Uses Described
	+ Specific Uses Only
	+ One-Time Use Only
	+ Ongoing Until Withdrawn
* **Client Signature** (`client_signature`, Text, required): Type your full name as a signature.
* **Witness Name** (`witness_name`, Text, optional): Provide name of witness if required.
* **Service Provider Name** (`provider_name`, Text, required): Provide name of service provider explaining consent.
* **Provider Signature** (`provider_signature`, Text, required): Provide name of provider giving consent.

## Tips
- Review and understand all fields before signing the form.
- Ask questions if unsure about any field.
- Ensure you understand the scope and implications of your consent.
