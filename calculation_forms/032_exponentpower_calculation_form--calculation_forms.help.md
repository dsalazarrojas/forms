# ExponentPower Calculation Form - Help Guide
## Purpose
The ExponentPower Calculation Form is a tool used to calculate the power of a base number raised to an exponent number. It is designed to provide a simple and straightforward way to perform this basic mathematical operation.

## How To Complete This Form
To use this form, follow these steps:

1. Enter the base number in the "base" field. This is the number you want to raise to the power.
2. Enter the exponent number in the "exponent" field. This is the power to which you want to raise the base number.
3. Click the "Calculate" button to perform the calculation.

## Field-by-Field Explanation
### Base (number)
* **Base (number)** (`base`, `number`, required): Enter the base number you want to raise to the power.
### Exponent (number)
* **Exponent (number)** (`exponent`, `number`, required): Enter the exponent number to which you want to raise the base number.
### Result (result)
* **Result** (`result`, `note`, required): This field displays the result of the calculation. Note that this field is read-only and can only be updated by the form's "Calculate" button.
