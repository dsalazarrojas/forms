# Form Calculation: Math Function Reference Avg() - Help Guide
## Purpose
The Form Calculation: Math Function Reference Avg() is a tool used to calculate the average of multiple numbers. This form is designed to guide users in understanding how to use the Math Function Reference Avg() formula correctly.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Yes" or "No" option from the "Math Function Reference Avg" dropdown menu.
2. Enter the first number you want to include in the calculation in the "num1" field.
3. Enter the second number you want to include in the calculation in the "num2" field.
4. Enter the third number you want to include in the calculation in the "num3" field.
5. Click on the "Result" field to see the calculated average.

## Field-by-Field Explanation
### Math Function Reference Avg
• **Math Function Reference Avg** (`math_function_reference_avg`, `select_one`, required/optional): This field is a dropdown menu with two options: "Yes" or "No". It is not required, and you can select either option depending on your preference. However, if you select "Yes", the form will guide you through the calculation process.
### num1
• **num1** (`num1`, `number`, required/optional): This field is for entering the first number you want to include in the calculation.
### num2
• **num2** (`num2`, `number`, required/optional): This field is for entering the second number you want to include in the calculation.
### num3
• **num3** (`num3`, `number`, required/optional): This field is for entering the third number you want to include in the calculation.
### Result
• **Result** (`result`, `note`, required/optional): This is a read-only field that displays the calculated average of the numbers you entered in the previous fields.

## Tips
* Make sure to enter numbers in the correct format (e.g., 1, 2, 3).
* If you select "Yes" in the Math Function Reference Avg field, the form will guide you through the calculation process.
* The calculated average is displayed in the Result field.
