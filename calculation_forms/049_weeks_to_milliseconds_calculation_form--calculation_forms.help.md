# Weeks To Milliseconds Calculation Form - Help Guide
## Purpose
The Weeks To Milliseconds Calculation Form is designed to convert a given number of weeks into milliseconds and vice versa.

## How To Complete This Form
To complete this form, follow these steps:
1.  Provide the number of milliseconds to convert into weeks in the "milliseconds_input_form" field.
2.  Provide the total milliseconds to be calculated from the input in the "weeks_to_milliseconds" field.
3.  Leave the "total_milliseconds" field to be calculated automatically.

## Field-by-Field Explanation
* **milliseconds_input_form** (`weeks_input_form`, number, optional): This is where you input the number of milliseconds to convert into weeks.
* **milliseconds_input_form** (`milliseconds_input_form`, number, optional): This is where you input the total milliseconds to convert into weeks.
* **result_form** (`result_form`, number, note, optional): This field will display the calculated total milliseconds.
* **milliseconds_per_week** (`milliseconds_per_week`, number, optional): This field is not used in the current form configuration and can be ignored.
* **weeks_to_milliseconds** (`weeks_to_milliseconds`, number, optional): This is where you input the number of weeks to convert into milliseconds.
* **total_milliseconds** (`total_milliseconds`, number, required): This is the calculated total milliseconds from the input.
