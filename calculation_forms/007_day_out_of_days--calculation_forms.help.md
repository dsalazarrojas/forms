# Day Out Of Days - Help Guide

## Purpose
The "Day Out Of Days" form is used to calculate the time difference between two dates. It helps to determine the number of days between the two dates and allows users to specify the unit of the result (e.g., days, weeks, months, or years).

## How To Complete This Form

1.  Select the start date of the period you want to calculate.
2.  Select the end date of the period you want to calculate.
3.  Choose the unit for the result from the dropdown menu (e.g., days, weeks, months, or years).
4.  Optionally, provide a label for the result to describe the calculation.

## Field-by-Field Explanation

*   **Start Date** (`date1`, date, optional): Enter the start date of the period you want to calculate.
*   **End Date** (`date2`, date, optional): Enter the end date of the period you want to calculate.
*   **Days Difference** (`calculation_result`, number, required): This field will be automatically calculated as the difference in days between the two dates.
*   **Unit** (`unit`, select_one, required): Choose the unit for the result (e.g., days, weeks, months, or years).
*   **Label** (`result_label`, text, optional): Provide a label to describe the result.
