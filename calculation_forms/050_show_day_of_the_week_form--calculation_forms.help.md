# Show Day Of The Week Form - Help Guide
## Purpose
This form is designed to help users convert a given date into its corresponding day of the week.

## How To Complete This Form
To use this form, simply enter a date in the `date_input` field, and select the days of the week you are interested in from the `calculate_day_of_week` field. You can select multiple days by holding down the Ctrl (or Command) key while clicking on the options.

## Field-by-Field Explanation
* **Date Input** (`date_input`, `date`, required): Enter a date in the format MM/DD/YYYY (e.g., 07/04/2022). This field allows you to specify the date for which you want to determine the day of the week.
* **Calculate Day Of The Week** (`calculate_day_of_week`, `select_multiple`, required): Select the day(s) of the week you are interested in learning about. This field allows you to specify which day(s) you want to know the corresponding date falls on.
* **Result** (`result`, `text`, required): This field will display the day of the week for the specified date.
* **Error Message** (`error_message`, `text`, required): This field will display an error message if the entered date is invalid or if the selected day(s) of the week are not within the valid range (Monday to Sunday).

## Tips
* Make sure to enter a valid date in the `date_input` field. If the date is invalid, an error message will be displayed in the `error_message` field.
* You can select multiple days of the week by holding down the Ctrl (or Command) key while clicking on the options in the `calculate_day_of_week` field.
