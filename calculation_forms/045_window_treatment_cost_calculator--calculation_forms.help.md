# Window Treatment Cost Calculator - Help Guide
## Purpose
The Window Treatment Cost Calculator is a tool that helps customers estimate the cost of window treatments for their windows. It collects information about the window's dimensions, room type, fabric type, and delivery preferences to provide an estimated cost.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the window length, width, and height measurements to provide accurate information about the window's dimensions.
2. Select the room type from the options provided (e.g., Bedroom, Living Room, etc.).
3. Choose the fabric type for your window treatment from the options (e.g., Roller Blind, Vertical Blind, etc.).
4. Select the window treatment type from the options (e.g., Window Treatment 1, Window Treatment 2, etc.).
5. Enter the quantity of window treatments needed.
6. Enter the estimated cost of the window treatment.
7. Select the lead time for delivery (if applicable).
8. Choose the delivery method (Standard, Express, or Next Day).
9. Select the delivery location (Home, Office, or Warehouse).
10. Add any special instructions or notes (optional).
11. Enter your email address (if you want to receive updates or notifications).
12. Enter your phone number (if you want to receive calls or SMS notifications).
13. Finally, submit the form by selecting the 'Submit Form' option.

## Field-by-Field Explanation
* **Window Length**: Enter the length of the window in inches.
* **Window Width**: Enter the width of the window in inches.
* **Window Height**: Enter the height of the window in inches.
* **Room Type**: Select the type of room where the window treatment will be installed (e.g., Bedroom, Living Room, etc.).
* **Fabric Type**: Choose the type of fabric or material for your window treatment (e.g., Roller Blind, Vertical Blind, etc.).
* **Window Treatment Type**: Select the type of window treatment you need (e.g., Window Treatment 1, Window Treatment 2, etc.).
* **Quantity**: Enter the number of window treatments needed.
* **Cost**: Enter the estimated cost of the window treatment.
* **Lead Time**: Select the lead time for delivery (e.g., standard, express, etc.). This field is optional.
* **Delivery Method**: Choose the delivery method (e.g., Standard, Express, Next Day).
* **Delivery Location**: Select the location where you want the delivery to be made (e.g., Home, Office, Warehouse).
* **Special Instructions**: Add any special instructions or notes about your order.
* **Email**: Enter your email address to receive updates or notifications.
* **Phone**: Enter your phone number to receive calls or SMS notifications.
* **Submit**: Select this option to submit the form and get an estimated cost quote.
* **Email Label**: If you want to receive emails, select 'Yes' in this field. If not, select 'No'.
