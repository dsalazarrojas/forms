# Square Root Calculator Form Template - Help Guide
## Purpose
The Square Root Calculator Form Template is a simple tool designed to calculate the square root of a given number.

## How To Complete This Form
1. Click on the "Square Root Form" tab on the page.
2. Enter the number for which you want to calculate the square root in the "Number" field.
3. Click the "Submit" button to get the square root result.

## Field-by-Field Explanation
* **Number (Number)**: Enter the numerical value of the number for which you want to calculate the square root. For example, if you enter "16", the form will display the square root of 16, which is 4.
* **Result (Result)**: This field will display the calculated square root of the number you entered in the "Number" field.
