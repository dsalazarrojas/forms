# Apply A Percentage To A Calculation Total - Help Guide
## Purpose
This form is designed to calculate the total amount of an item after applying a percentage, allowing users to easily apply discounts, taxes, or fees to a base amount.

## How To Complete This Form
1. Select the calculation date for the transaction.
2. Enter the item name or description.
3. Enter the original base amount.
4. Choose the type of percentage to apply (e.g., discount, tax, fee, etc.).
5. Select the percentage value to apply.
6. If the percentage type is "Custom", enter the custom percentage value.
7. Choose whether the percentage should be added or subtracted from the base amount.
8. Select the currency type for the calculation.
9. Enter the quantity of items (if applicable).
10. Enter the unit price per item (if applicable).
11. Enter any additional discount (if applicable).
12. Enter any notes about the calculation (if applicable).
13. Enter the name of the person performing the calculation (if applicable).
## Field-by-Field Explanation
* **Calculation Date** (id: 1): Enter the date of the calculation.
* **Item Name** (id: 2): Enter the name or description of the item.
* **Base Amount** (id: 3): Enter the original amount before percentage application.
* **Percentage Type** (id: 4): Select the type of percentage to apply (e.g., discount, tax, fee, etc.).
* **Percentage Value** (id: 5): Select the percentage value to apply.
* **Custom Percentage** (id: 6): If the percentage type is "Custom", enter the custom percentage value.
* **Apply Percentage** (id: 7): Choose whether the percentage should be added or subtracted from the base amount.
* **Calculation Method** (id: 8): Select how the percentage should be calculated (e.g., add to base amount, subtract from base amount, etc.).
* **Calculated Amount** (id: 9): The calculated amount after percentage application (result of the calculation).
* **Final Total** (id: 10): The final amount after all calculations have been performed (result of the calculation).
* **Currency Type** (id: 11): Select the currency type for the calculation.
* **Quantity** (id: 12): Enter the number of items (if applicable).
* **Unit Price** (id: 13): Enter the price per unit (if applicable).
* **Subtotal** (id: 14): The quantity multiplied by the unit price (if applicable).
* **Additional Discount** (id: 15): Enter any additional discount to apply (if applicable).
* **Notes** (id: 16): Enter any notes about the calculation (if applicable).
* **Calculated By** (id: 17): Enter the name of the person performing the calculation (if applicable).

## Tips
* Make sure to select the correct percentage type and value for the calculation.
* If the percentage type is "Custom", enter the custom percentage value accurately.
* Choose the correct calculation method to perform the percentage calculation.
* Enter all required fields accurately to get the correct calculated amount.
* Use the calculated amount as needed for further calculations or reporting.
