# Get Arccosine (acos) Form - Help Guide

## Purpose
The "Get Arccosine (acos) Form" is a mathematical form that calculates the arccos function for a given input angle. It takes an angle as input and provides the arccos result as output.

## How To Complete This Form
To get the arccos result, follow these steps:
1. Enter the input angle (in radians) in the "Input Angle" field.
2. Select the desired output value from the "Result Acos" dropdown menu.
3. Click the "Submit" button to calculate and display the arccos result.

## Field-by-Field Explanation

* **Input Value** (`input_value`, number, optional): Enter the input angle in radians. This field is not required, but it is recommended to enter the angle to get accurate results.
* **Result Acos** (`result_acos`, select_one, optional): Select the desired output value from the dropdown menu. The options are:
	+ 1
	+ 2
	+ 3
* **Input Angle** (`input_angle`, number, optional): Enter the input angle in radians. This field is not required, but it is recommended to enter the angle to get accurate results.
* **Result Acos Angle** (`result_acos_angle`, select_one, optional): Select the desired output angle from the dropdown menu. The options are:
	+ 1
	+ 2
