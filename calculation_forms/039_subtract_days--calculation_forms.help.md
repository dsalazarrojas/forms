# Subtract Days - Help Guide
## Purpose
The "Subtract Days" form is a simple tool used to calculate a date that falls a certain number of days before or after a selected date.

## How To Complete This Form
To use this form, follow these steps:

1. Select a date using the date picker.
2. Enter the number of days to subtract.
3. Click "Calculate" to get the resulting date.

## Field-by-Field Explanation

- **date_picker** (date_picker, date): Enter the date from which you want to subtract the days. Use the date picker to select a date in the format MM/DD/YYYY.
- **days_to_subtract** (days_to_subtract, number, optional): Enter the number of days to subtract from the selected date. If not filled in, the form will default to 0.
- **result** (result, text): This field will display the calculated date after subtracting the specified number of days.

## Tips
- Make sure to select a valid date in the date picker to get accurate results.
- The number of days to subtract can be a positive or negative number, depending on the desired direction of the calculation.
- The calculated date will be displayed in the same format as the selected date.
