# Date Calculation Form - Help Guide
## Purpose
The Date Calculation Form is used to input start and end dates and choose a calculation type to calculate the number of days between the two dates.

## How To Complete This Form
1. Select a start date from the input field.
2. Select an end date from the input field.
3. Choose a calculation type from the options provided (Between, Add, or Subtract).
4. If "Between" is selected, enter the number of days between the start and end dates.
5. If "Add" or "Subtract" is selected, enter a number of days to add or subtract from the start or end date.
6. Click the "Submit" button to get the result.

## Field-by-Field Explanation
- **Start Date (`start_date`, date, optional):** Input the start date for the calculation.
- **End Date (`end_date`, date, optional):** Input the end date for the calculation.
- **Calculation Type (`calculation_type`, select_one, optional):** Choose the calculation type: Between, Add, or Subtract.
  - **Between:** Input the number of days between the start and end dates.
  - **Add:** Input a number of days to add to the start date.
  - **Subtract:** Input a number of days to subtract from the start date.
- **Days Between (`days_between`, number, optional):** Input the number of days between the start and end dates if the "Between" calculation type is selected.
- **Result (`result`, text, optional):** The result of the calculation will be displayed here.

## Tips
- Make sure to select the correct calculation type before entering the number of days between the start and end dates.
- If "Between" is selected, ensure that the start date is before the end date.
- If "Add" or "Subtract" is selected, ensure that the number of days is a whole number.
