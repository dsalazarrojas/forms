# Find The Lowest Value - Help Guide
## Purpose
This form is designed to find the lowest value from a list of numbers. You will be prompted to enter a list of numbers and select whether you want to find the lowest or highest value. The form will then display the result as a date in the format `YYYY-MM-DD HH:MM:SS`.

## How To Complete This Form
1. Start by entering a list of numbers in the "Enter numbers" field (form_1).
2. In the "Select lowest" field (form_2), choose "lowest" to find the lowest value from the entered numbers or "highest" to find the highest value.
3. Click "Submit" to generate the result.

## Field-by-Field Explanation
* **Enter numbers** (`form_1`, text, optional): Enter a list of numbers separated by commas, for example: `1, 2, 3, 4, 5`.
* **Select lowest** (`form_2`, select_one, optional): Select "lowest" to find the lowest value from the entered numbers or "highest" to find the highest value.
* **Numbers** (`form_3`, text, optional): Enter another list of numbers if the first list is not enough.
* **Result** (`form_4`, date, optional): This field will be automatically populated with the result of the calculation, displayed as a date in the format `YYYY-MM-DD HH:MM:SS`.

## Tips
- Make sure to enter the numbers separated by commas for the "Enter numbers" field.
- You can enter multiple pages of numbers by clicking "Add page" or entering additional numbers in the "Numbers" field.
- If you select "highest" in the "Select lowest" field, the form will display the highest value instead of the lowest.
