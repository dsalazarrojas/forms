# PI (π) Calculation Form - Help Guide

## Purpose
The PI (π) Calculation Form is a simple form designed to calculate the value of pi (π) based on a given input number. The form is intended to demonstrate the calculation of the mathematical constant pi, which is approximately 3.14159. The form is not meant to be used for complex mathematical operations, but rather for educational or basic calculations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a positive number in the "Enter a number" field on the first page.
2. Press the submit button to calculate the result.
3. The calculated pi value will be displayed in the "Result" field.

## Field-by-Field Explanation

* **Enter a number** (`entry_number`, `number`, required): Enter a positive number for which you want to calculate the value of pi. Ensure that you enter a whole number (e.g., 1, 2, 3, etc.) for accurate results.
* **Result** (`result`, `number`, optional): This field displays the calculated value of pi based on the input number. You can ignore this field if you don't need to see the result.
* **pi** (`pi`, `number`, required): This field is not used in the calculation. It is intended for internal use, and you should not modify it.
