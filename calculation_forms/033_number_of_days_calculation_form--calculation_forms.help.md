# Number of Days Calculation Form - Help Guide

## Purpose
This form is designed to calculate the number of days between two dates and times. It helps users compute the duration between two time points for various purposes, such as calculating working hours, travel time, or any other time-based metric.

## How To Complete This Form

1.  Enter the start date in the "start_date" field.
2.  Enter the end date in the "end_date" field.
3.  (Optional) Enter the start time in the "start_time" field.
4.  (Optional) Enter the end time in the "end_time" field.
5.  Click "Submit" to calculate the number of days.

## Field-by-Field Explanation

*   **start_date** (Date, Required): Enter the starting date for the calculation.
*   **end_date** (Date, Required): Enter the ending date for the calculation.
*   **start_time** (Time, Optional): Enter the starting time for the calculation.
*   **end_time** (Time, Optional): Enter the ending time for the calculation.

## Tips

*   Make sure to enter the start and end dates in the correct format (MM/DD/YYYY).
*   Enter the start and end dates in the same time zone to avoid confusion.
*   If you enter start and end times, ensure they are within the correct time range to produce accurate results.
*   The calculated result will be in days, and you can further convert it to other units (e.g., hours, minutes) if needed.
