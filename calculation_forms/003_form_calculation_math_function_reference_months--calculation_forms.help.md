# Form Calculation: Math Function Reference Months() - Help Guide
## Purpose
This form is designed to allow users to reference months for use in mathematical calculations.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the relevant months you want to include in your calculation using the "months" field.
2. Choose the function you want to apply to your selected months from the "function_name" field.
3. Enter the value to be used with the selected function in the "value" field.
4. Optionally, select the number of milliseconds to apply to your calculation in the "milliseconds" field, if applicable.

## Field-by-Field Explanation
* **months** (`months`, select_multiple, required): Select the months you want to include in your calculation. This field allows you to choose one or more months from the list of options provided.
* **function_name** (`year`, select_one, required): Choose the function you want to apply to your selected months. Options include "months" to get the total number of months, "year" to get the total number of years, and "week" to get the total number of weeks.
* **value** (`value`, text, required): Enter the value to be used with the selected function.
* **milliseconds** (`milliseconds`, number, optional): If applicable, select the number of milliseconds to apply to your calculation. This field is used to apply a time-based calculation.

## Tips
* Make sure to select the correct months and function for your calculation.
* Ensure the value entered in the "value" field is accurate for the selected function.
* If applicable, select the correct number of milliseconds for your calculation.
