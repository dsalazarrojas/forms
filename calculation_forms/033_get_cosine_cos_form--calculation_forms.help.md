# get_cosine_form - Help Guide

## Purpose
The get_cosine_form is designed to calculate the cosine similarity between two input angles. This form takes in two input angles and outputs their cosine value.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Enter the first input angle.
2. Enter the second input angle.
3. Click the submit button to perform the calculation.

## Field-by-Field Explanation

* **calculate cosine** (calculate_cosine, number, optional): Enter the first input angle. The user is expected to enter a decimal number in degrees.
* **input angle** (angle, number, optional): Enter the second input angle. The user is expected to enter a decimal number in degrees.
* **cos value** (cos_value, number, optional): This field will display the cosine similarity value calculated from the input angles. The result is a decimal number between -1 and 1.

## Tips
* Make sure to enter decimal numbers in degrees for both input angles.
* If you are unsure about the input angles, please consult a mathematics reference or a vector calculator.
* The results are not stored or reused, so feel free to fill out the form as many times as needed to test different scenarios.
