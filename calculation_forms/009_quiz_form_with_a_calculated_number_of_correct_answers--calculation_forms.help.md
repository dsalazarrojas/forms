# Quiz Form With A Calculated Number Of Correct Answers - Help Guide
## Purpose
This form is designed to collect user feedback on a quiz by presenting three questions with single selections and calculating the number of correct answers.

## How To Complete This Form
To complete this form, follow these steps:

1. Select one option for each question (first_question, second_question, third_question) by choosing the correct answer for each.
2. Fill out any additional feedback in the "thankyou" field if you have any comments or questions.

## Field-by-Field Explanation
### first_question (Select One)
Select one option for the first question. Make sure to choose the correct answer from the given options (correct answer1, incorrect answer2, incorrect answer3).

### second_question (Select One)
Select one option for the second question. Make sure to choose the correct answer from the given options (correct answer2, incorrect answer1).

### third_question (Select One)
Select one option for the third question. Make sure to choose the correct answer from the given options (correct answer3, incorrect answer4).

### thankyou (Note)
Fill out any additional feedback or questions you have regarding the quiz.

### number_correct_answers (Number)
This field will automatically display the calculated number of correct answers after you have completed the first three questions. It is for display purposes only and does not require input.
