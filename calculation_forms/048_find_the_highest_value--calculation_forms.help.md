# Find The Highest Value - Help Guide
## Purpose
This form is designed to find the highest value among two or three input numbers.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the first number in the first field.
2. Enter the second number in the second field.
3. If you have a third number, enter it in the third field.
4. Click on the form to submit your input.

## Field-by-Field Explanation
* **Entered Number 1** (`entered_number_1`, number, optional): Enter the first number you want to compare.
* **Entered Number 2** (`entered_number_2`, number, optional): Enter the second number you want to compare.
* **Highest Value** (`highest_value`, number, optional): This field will display the highest value among the numbers you entered.

## Tips
* Make sure to enter numbers only.
* If a field is not filled, it will not affect the result, as the form will only display the highest value among the numbers entered.
* You can enter up to three numbers in this form.
