# Find Sine - Help Guide
## Purpose
This form is designed to calculate the sine of an angle given its opposite and hypotenuse values. It helps users quickly and easily find the sine of an angle using the fundamental principles of trigonometry.

## How To Complete This Form
1. Fill in the opposite and hypotenuse angle values in the first page of the form.
2. Select the calculation type from the "calculate" dropdown menu on the second page of the form.

## Field-by-Field Explanation
* **Enter the opposite and hypotenuse angle values** (`opposite_and_hypotenuse`, `text`, required/optional): This page is where you input the opposite and hypotenuse angle values for the calculation. You can type in the values in the provided text field.
* **Sine value** (`sine_value`, `number`, required/optional): This is where the calculated sine value will be displayed.
* **Calculate** (`calculate_button`, `select_one`, required): This dropdown menu offers three options: Sine, Cosine, and Tangent. Select the type of calculation you want to perform, and the sine value will be calculated and displayed in the "Sine value" field.
