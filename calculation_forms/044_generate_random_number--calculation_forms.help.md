# Generate Random Number - Help Guide
## Purpose
The Generate Random Number form is a simple tool for generating a unique random number for a specific use case or scenario.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a unique formula in the "Formula" field to generate the random number. This formula will be used to create a unique value.
2. Click the "Generate" button to create a new random number based on the formula entered.

## Field-by-Field Explanation

* **Random Number**: (`random_number`, number, required: false)
	+ The randomly generated number is displayed after clicking the "Generate" button.
* **Formula**: (`formula`, text, required: false)
	+ Enter a formula to generate the random number. This can be any valid mathematical expression, such as a simple addition or multiplication problem. 
* **Generate**: (`generate`, text, required: false)
	+ Click this button to execute the formula and generate a new random number.
