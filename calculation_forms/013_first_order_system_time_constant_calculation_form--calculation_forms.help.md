# First Order System Time Constant Calculation Form - Help Guide
## Purpose
This form is for calculating the time constant of a first order system. The time constant is an essential parameter used to describe how the system responds to inputs or stimuli.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter system details on page 1, including System Response Details, System Damping Ratio A, and System Mass Ratio B. These values are crucial for the time constant calculation.
2. On page 2, input the System Frequency. This parameter helps the system's response behavior.
3. Review the calculated System Time Constant generated by the form.

## Field-by-Field Explanation
* **System Response Details**: This field is for you to describe the system's response to inputs or stimuli. Enter a brief description to help identify the system's behavior.
* **System Damping Ratio A**: This field is for the first-order system damping ratio A. Enter a numerical value to represent the damping effect on the system's response.
* **System Mass Ratio B**: Enter the mass ratio B for the system, which influences the system's mass distribution.
* **System Frequency**: This parameter determines the frequency at which the system responds to inputs or stimuli.
* **Calculate Time Constant**: This field is not editable; it's for the calculated result of the input system details.
* **Calculated Time Constant**: The calculated time constant is automatically generated based on your input system details.
* **Assigned Tool**: If applicable, assign a tool to the calculated time constant for further reference or actioning.

## Tips
* Make sure to input correct values for the system details, as incorrect inputs can affect the accuracy of the calculated time constant.
* Ensure that you understand the context and units of each parameter to provide accurate inputs.
