This form is a simple text concatenation form that allows users to input text values on three pages. The purpose of this form is to collect three text values that will be concatenated together to produce a final output text result.

## Text Concatenation With Form Calculation Widget - Help Guide

## Purpose
This form is designed to collect three text values and concatenate them together to produce a final output text result.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to begin.
2. On each page, enter the corresponding text value in the text field.
3. Click "Next" to proceed to the next page.
4. On the final page, click "Submit" to generate the concatenated text result.

## Field-by-Field Explanation
- **Text 1** (`text_1`, `text`, optional): Enter the first text value you want to concatenate.
- **Text 2** (`text_2`, `text`, required): Enter the second text value you want to concatenate.
- **Text Result** (`text_result`, `text`, required): This is the final concatenated text result that will be displayed after submitting the form.

## Tips
- Make sure to enter valid text values in all fields.
- Click "Next" carefully, as navigating back to previous pages is not supported.
- The final text result will be generated after submitting the form.

Note: The form does not save or store any data, and the result is only visible on the form submission page.
