# City Year Event Proposal Form - Help Guide
## Purpose
The "City Year Event Proposal Form" is a tool for submitting community engagement events for consideration. It helps event organizers provide detailed proposals, including event title, description, target audience, date, time, venue, budget, and resource requirements.

## How To Complete This Form

Before starting, review the form carefully to ensure you understand each field's purpose and requirements. The form is divided into several sections, each with specific fields and instructions.

## Field-by-Field Explanation

### -- Event Proposal Details --
* **Proposer Full Name** (Proposer Full Name, text, required): Enter your full name as the event proposer. This is a required field and should be filled with your real name.
* **Proposer Email** (Proposer Email, email, required): Enter your email address associated with the event proposal. This is a required field and should be a valid email address.
* **Proposed Event Title** (Proposed Event Title, text, required): Enter a brief title of the event you are proposing. This is a required field and should be descriptive but concise.
* **Event Category** (Event Category, select_one, required): Choose the category of the event from the options provided (Community Service, Youth Education, Cultural Celebration, Health and Wellness, Career Development, Fundraising).
* **Event Description and Overview** (Event Description and Overview, text, required): Describe the main purpose and objectives of the event in a clear and concise manner. This is a required field.
* **Target Audience** (Target Audience, select_multiple, required): Select the target audience for the event from the options provided (Students (K-12), Parents and Families, Local Educators, Corporate Partners, Community Residents).
* **Proposed Event Date** (Proposed Event Date, date, required): Enter the date of the proposed event in the format mm/dd/yyyy.
* **Start Time** (Start Time, time, required): Enter the start time of the proposed event in the format hh:mm AM/PM.
* **End Time** (End Time, time, required): Enter the end time of the proposed event in the format hh:mm AM/PM.
* **Proposed Venue or Location** (Proposed Venue or Location, text, required): Enter the venue or location of the proposed event.
* **Expected Number of Attendees** (Expected Number of Attendees, number, required): Estimate the expected number of attendees for the event.
* **Estimated Total Budget Required** (Estimated Total Budget Required, number, optional): If applicable, enter an estimated budget for the event.
* **Key Resources Needed** (Key Resources Needed, text, optional): If applicable, list any key resources required for the event, such as equipment or volunteers.
* **How will success be measured?** (How will success be measured?, text, required): Describe how you will measure the success of the event.
* **Date of Proposal** (Date of Proposal, date, required): Enter the date you are submitting the proposal.

## Tips

- Double-check that all required fields are filled accurately and thoroughly.
- Be as detailed as possible when describing the event proposal.
- Review the form carefully before submitting to avoid non-duplication.
- Ensure the event proposal meets City Year event planning guidelines and requirements.
