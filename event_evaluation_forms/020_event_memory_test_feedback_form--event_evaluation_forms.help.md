# Event Memory Test Feedback Form - Help Guide
## Purpose
The Event Memory Test Feedback Form is designed to collect feedback on the event memory test, used to gauge an individual's memory abilities.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the questions and options provided.
2. Answer the questions honestly and to the best of your ability.
3. Ensure that you have not already completed this form for the same test.

## Field-by-Field Explanation
### **Event Memory Test Feedback Form (event_memory_test_feedback_form)**
* This field is the main question for this form, where you can provide any feedback on the event memory test.

### **Test Difficulty (test_difficulty)**
* This field is used to rate the difficulty level of the test.
* Select a level that best describes your experience: Hard, Medium, or Easy.

### **Memory Test Format (memory_test_format)**
* Select which of the following options best describes the test format:
	+ Yes: The test was in a yes/no format.
	+ No: The test was not in a yes/no format.

### **Memory Test Length (memory_test_length)**
* This field is used to rate how long the test lasted.
* Select a number from 1-10 that best describes the test length.

### **Difficulty Level (difficulty_level)**
* This field is used to rate the difficulty level of the test.
* Select a level that best describes your experience: Hard, Medium, or Easy.

### **Recall Level (recall_level)**
* This field is used to rate how well you remembered the test.
* Select a level that best describes your experience: Very High, High, Medium, Low, or Very Low.

### **Tips**
* Please ensure that you complete the form honestly and accurately.
* If you have any questions or concerns, contact the administrator for assistance.
