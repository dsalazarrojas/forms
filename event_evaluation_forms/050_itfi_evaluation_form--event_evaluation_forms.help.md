# itfi_evaluation_form - Help Guide
## Purpose
The itfi_evaluation_form is a tool used to collect information and evaluations from users about events. It collects data on event name, date, time, evaluation date, evaluation note, ITFI rating, SDCPC rating, assigned tool, and evaluation comment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Name** in the "Event Name" field. This is the title of the event being evaluated.
2. Select the **Event Date** in the "Event Date" field. This should be the date the event took place.
3. Enter the **Event Time** in the "Event Time" field. This is the time the event occurred.
4. Select the **Evaluation Date** in the "Evaluation Date" field. This should be the date the evaluation is being made.
5. (Optional) Add any additional **Evaluation Note** in the "Evaluation Note" field. This is a field for any notes or comments about the event.
6. Enter the **ITFI Rating** in the "ITFI Rating" field. This is a rating for the event.
7. Enter the **SDCPC Rating** in the "SDCPC Rating" field. This is another rating for the event.
8. Select the **Assigned Tool** from the dropdown menu. This is the tool or resource used during the event.
9. (Optional) Add any **Evaluation Comment** in the "Evaluation Comment" field. This is a field for any comments or feedback about the event.

## Field-by-Field Explanation
* **Event Name (text, required)**: Enter the title of the event being evaluated.
* **Event Date (date, required)**: Select the date the event took place.
* **Event Time (time, required)**: Enter the time the event occurred.
* **Evaluation Date (date, required)**: Select the date the evaluation is being made.
* **Evaluation Note (note, optional)**: Add any additional notes or comments about the event.
* **ITFI Rating (text, required)**: Enter a rating for the event.
* **SDCPC Rating (text, required)**: Enter another rating for the event.
* **Assigned Tool (select_one, required)**: Select the tool or resource used during the event.
* **Evaluation Comment (text, optional)**: Add any comments or feedback about the event.
