# Unique Experience Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback and ratings on unique experiences, allowing us to assess the effectiveness and enjoyment of specific events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the event you are providing feedback on.
2. Enter your name and email address if you are providing feedback.
3. Provide your feedback on the event in the notes field.
4. Rate your satisfaction with the event using the numerical scale.
5. Select which experiences you had during the event from the list of options.
6. Share any additional comments or suggestions you have.

## Field-by-Field Explanation
* **Event Name**: Enter the name of the event you are providing feedback on. This is required information and should match the name of the event you are referencing.
* **Name**: Enter your name. This will be used to identify you as the person providing feedback.
* **Email**: Enter a valid email address to help us contact you for more information.
* **Feedback**: Provide as much detail as possible about your experience with the event.
* **Event Date**: If you know the date of the event, please enter it. This can be used to reference the event in our records.
* **Event Time**: If you know the time of the event, please enter it. This can be used to reference the time of the event in our records.
* **Participant Satisfaction**: Rate your satisfaction with the event using the provided numerical scale.
* **Rating**: Select your rating for the event from the list of options. Please be honest and accurate in your rating.
* **Participant Experience**: Select which experiences you had during the event. You can select more than one option.
* **Suggestions**: If you have any suggestions on how we can improve the event, please enter them here.
* **Additional Comments**: Enter any additional comments or notes about your experience with the event.

Note: The form is best completed when you are providing feedback on a specific event that you have attended. If you have any questions or concerns, please don't hesitate to reach out.
