# Fundraising Event Effectiveness Audit Form - Help Guide
## Purpose
The Fundraising Event Effectiveness Audit Form is used to gather information about the success and effectiveness of a fundraising event.

## How To Complete This Form

To complete this form, follow these steps:

1.  Ensure that you have access to the event information you are being asked for.
2.  Fill out the form with as much detail as you can.
3.  Review each section carefully before submitting the form.

## Field-by-Field Explanation

*  **Event Name**: This is the name of the fundraising event, such as "Spring Charity Run".
*  **Event Date**: The date on which the event took place.
*  **Event Time**: The time of day when the event occurred.
*  **Event Type**: Indicate if this was a one-time event or if it was part of a series.
*  **Target Goal**: Indicate if the event met its target goal.
*  **Total Donations**: Enter the total amount of money raised during the event.
*  **Average Donation**: Enter the average amount donated per participant.
*  **Event Location**: The location where the event took place.
*  **Event Notes**: Any additional comments or observations about the event.
*  **Event Feedback**: Indicate if the event was a success.
*  **Lessons Learned**: Note any lessons or observations from the event that could be used to improve future events.
*  **Event Evaluation Form Version**: Indicate if this is the current version of the form being used.
*  **Assigned to**: The person(s) to whom the form should be sent to for review or action.
*  **Created At**: The date and time the form was created (not editable).

## Tips

*  Be as detailed as possible when filling out the form to ensure accurate results.
*  If an event was not a success, try to provide feedback and suggestions for how to improve future events.
*  If the form is to be filled out by multiple people, ensure that all have access to the same information.
*  Use this form for past events only.
