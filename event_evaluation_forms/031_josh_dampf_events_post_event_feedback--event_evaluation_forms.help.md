# josh_dampf_events_post_event_feedback - Help Guide
## Purpose
The "josh_dampf_events_post_event_feedback" form is designed to collect feedback and ratings from attendees after an event. It helps us evaluate the success of events and make improvements for future events.

## How To Complete This Form
1. Review the form carefully to ensure you're providing accurate and relevant feedback.
2. Fill in the required fields as accurately as possible.
3. For optional fields, feel free to provide any additional comments or information you think would be helpful.
4. Submit the form to submit your feedback.

## Field-by-Field Explanation

* **Event Details (event_details)**: A field where you can describe the event you attended.
* **Event Attendance (event_attendance)**: Please enter the number of attendees present at the event.
* **Comments (feedback_comments)**: Share any comments or thoughts you have about the event.
* **Overall Rating (overall_rating)**: Rate your overall experience at the event. You can choose from "Very Poor" to "Excellent".
* **Email (email)**: If you have any questions or need to be contacted, please provide your email address.
* **Phone (phone)**: If you have a contact number where we can reach you, please provide it.
* **Event Date (event_date)**: If you're able to recall the date of the event, please enter it.
* **Event Time (event_time)**: If you're able to recall the time of the event, please enter it.
* **Assigned Tool (assigned_tool)**: Please select the tool that was assigned to the event.
* **Category (category)**: A field where you can describe the category of the event (optional).
* **Description (description)**: A field where you can provide a more detailed description of the event (optional).
* **Form ID (form_id)**: This field is not required, but in case you need to reference the form for internal use, you can fill it in.
* **Form Category (form_category)**: This field is not required, but it's a way to categorize the form for internal use.
* **Assigned Tool (assigned_tool)**: Please note that "Other" is an option in case the assigned tool was not among the provided choices.
