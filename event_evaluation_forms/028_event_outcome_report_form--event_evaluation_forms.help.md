# Event Outcome Report Form - Help Guide

## Purpose
The Event Outcome Report Form is designed to gather information about the outcome of an event. It is used to report the success or failure of an event, including any notable achievements or areas for improvement.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the relevant details about the event, including the date it occurred and the time it took place.
2. Choose the outcome of the event from the provided options (Excellent, Good, Fair, or Poor).
3. Enter any comments about the event's outcome.
4. If applicable, provide information about the event organizer and attendees.
5. Enter a numerical score for the event's outcome.
6. Add any additional comments you have about the event.

## Field-by-Field Explanation

* **Event Outcome Report Form** (1): This is the main title of the form.
* **Event Outcome** (6): Choose the outcome of the event from the options below.
	+ Excellent: The event was highly successful and achieved its objectives.
	+ Good: The event was successful, but had some minor issues.
	+ Fair: The event was average and did not meet expectations.
	+ Poor: The event was unsuccessful and had significant issues.
* **Date of Event** (3): Enter the date the event took place.
* **Time of Event** (4): Enter the time the event took place.
* **Event Venue** (5): If applicable, enter the location where the event occurred.
* **Event Organizer** (8): If applicable, enter the name of the event organizer.
* **Event Attendees** (9): If applicable, enter the names of the attendees or participants.
* **Event Outcome Score** (10): Enter a numerical score to rate the event's outcome (e.g., 1-10).
* **Additional Comments** (11): Enter any additional comments or observations about the event.
* **Event Evaluation Form Comments** (12): Enter any comments or feedback about the form itself.
* **Evaluation Form Comments** (13): Enter any comments or feedback about the form's design or functionality.
* **Evaluation Form** (14): Choose multiple options from the list to indicate what aspects of the event were evaluated (e.g., content, organization, etc.).

Note: The fields marked as "required: false" are optional and can be filled in or left blank.
