# event_sponsorship_roi_assessment_form - Help Guide

## Purpose
The event sponsorship ROI assessment form is used to evaluate the return on investment (ROI) of a sponsorship for an event. It helps event organizers and sponsors to understand the benefits and costs associated with the sponsorship and make informed decisions for future events.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Please select the relevant page and field for the information you are providing.
2. Fill in the required fields as accurately as possible.
3. Use the hints and labels as guides to ensure that you fill in the correct information.
4. Review your answers carefully to ensure that they are complete and accurate.

## Field-by-Field Explanation

### Page 1

* **Event Sponsorship ROI Assessment Event** (`event_sponsorship_roi_assessment_event`): This is the name of the event being sponsored. Please provide the exact name of the event.
* **Sponsor Name** (`sponsor_name`): Please provide the name of the sponsor or organization that provided the sponsorship.
* **Sponsorship Fees** (`sponsorship_fees`): This is the amount of money or resources provided by the sponsor. If no fees were provided, please enter 0.
* **Return on Investment (ROI) Percentage** (`roi_percentage`): This is the percentage of benefits received from the sponsorship compared to the costs incurred. Please provide a numerical value between 0 and 100.
* **Sponsor Feedback** (`sponsor_feedback`): This field is for any additional comments or feedback from the sponsor about the event and the sponsorship.
* **Investment Outcomes** (`investment_outcomes`): Please describe the outcomes or results achieved as a result of the sponsorship.
* **ROI Calculation Method** (`roi_calculation_method`): Please describe the method used to calculate the ROI for this sponsorship.

### Page 2

* **Event Attendance** (`event_attendance`): This is the number of attendees at the event. If the event was not attended, please enter 0.
* **Engagement Level** (`engagement_level`): This is a subjective measure of the engagement level of the attendees with the event. Please provide a brief description of the level of engagement, e.g., low, medium, high.

Please note that some fields are not required, but they are included in case you have additional information to provide.
