# Event Environmental Impact Assessment Form - Help Guide
## Purpose
This form is designed to be used for assessing the potential environmental impact of an event. It's intended to be used by event organizers to provide information about the event, including its title, category, date, location, and other relevant details.

## How To Complete This Form

1. Fill out the form with accurate and truthful information about the event.
2. Make sure to answer all required fields.
3. For select fields, choose the most relevant option that applies to the event.

## Field-by-Field Explanation
* **Event Title** (`event_title`): Enter a brief title of the event.
* **Event Category** (`event_category`): Select the category of the event from the list of options.
* **Event Date** (`event_date`): Enter the date of the event in the correct format.
* **Start Time** (`start_time`): Enter the start time of the event in the correct format.
* **End Time** (`end_time`): Enter the end time of the event in the correct format.
* **Location** (`location`): Enter a brief description of the event location.
* **Event Status** (`event_status`): Select the status of the event from the list of options.
* **Event Capacity** (`event_capacity`): Enter the number of people attending the event.
* **Event Participants** (`event_participants`): Enter the number of people participating in the event.
* **Energy Consumption** (`energy_consumption`): Enter the estimated energy consumption of the event.
* **Water Usage** (`water_usage`): Enter the estimated water usage of the event.
* **Waste Production** (`waste_production`): Enter the estimated waste production of the event.
* **Carbon Footprint** (`carbon_footprint`): Enter the estimated carbon footprint of the event.
* **Transportation Emissions** (`transportation_emissions`): Enter the estimated transportation emissions of the event.
* **Food And Beverage Usage** (`food_and_beverage_usage`): Enter the estimated food and beverage usage of the event.
* **Other Impact** (`other_impact`): Enter any other environmental impact of the event.
* **Sustainability Measures** (`sustainability_measures`): Select any sustainability measures that will be implemented during the event.
* **Notes** (`notes`): Enter any additional notes about the event.
* **Submit** (`submit`): This is not a field to be filled out.
* **Email** (`email`): Enter the email address of the event contact person.
* **Phone Number** (`phone_number`): Enter the phone number of the event contact person.
* **Website** (`website`): Enter the website of the event.
* **Event Organizer** (`event_organizer`): Enter the name of the event organizer.
* **Event Location** (`event_location`): Enter a brief description of the event location.
* **Event Date 2** (`event_date_2`): Enter the date of the event (second field).

## Tips

* Make sure to answer all required fields accurately and truthfully.
* For select fields, choose the most relevant option that applies to the event.
* If you are unsure about any field, ask for help or clarification.
* Review the form carefully before submitting it to ensure that it is completed correctly.
