# Event Logistics Assessment Questionnaire - Help Guide
## Purpose
This form is used to collect and document event logistics information for assessments and evaluations.

## How To Complete This Form
- To complete this form, please fill out each section as instructed.
- Start by providing the event title, start and end dates, and location.
- Next, provide the number of attendees, event budget, and select the event type.
- Then, choose the status of the event and provide a brief description of the venue.
- After that, outline the communication plan and evaluation criteria.
- Finally, review and submit the form.

## Field-by-Field Explanation

### Event Details
- **Event Title**: Provide the title of the event.
### Event Start Date
- **Event Start Date**: Enter the date when the event started or is scheduled to start.
### Event End Date
- **Event End Date**: Enter the date when the event ended or is scheduled to end.
### Event Location
- **Event Location**: Enter the location where the event was or will be held.
### Number of Attendees
- **Number of Attendees**: Enter the number of people who attended or are expected to attend the event.
### Event Budget
- **Event Budget**: Enter the budget allocated for the event.
### Event Type
- **Event Type**: Select the type of event (e.g., Conference, Workshop, Festival, Meeting).
### Event Status
- **Event Status**: Select all applicable statuses (e.g., Planned, In Progress, Completed).
### Venue Description
- **Venue Description**: Provide a brief description of the venue where the event was or will be held.
### Communication Plan
- **Communication Plan**: Outline the communication plan for the event, including how you will keep attendees informed.
### Evaluation Criteria
- **Evaluation Criteria**: Describe the criteria used to evaluate the event's success.
### Review and Recommendations
- **Review and Recommendations**: Provide a review and recommendations of the event, including which options you chose from the provided checkboxes (Option A and Option B).
