# Event Planner Offboarding Form - Help Guide
## Purpose
The Event Planner Offboarding Form is used to document the offboarding process of events, ensuring that all necessary information is captured and communicated effectively. This form helps event planners, project managers, and other stakeholders stay organized and up-to-date during the offboarding process.

## How To Complete This Form
To complete the form, follow these steps:

1. Ensure you have all the required information about the event.
2. Start by filling out the `Event ID` field with the unique identifier for the event.
3. Enter the `Event Name` in the corresponding field.
4. Select the `Event Start Date` and `Event End Date` fields to specify the event's timeline.
5. Fill out the `Event Planner Notes` field with any relevant details about the event.
6. If applicable, select the event planners responsible for the event from the `Event Planner Name` field.
7. Choose the current `Event Status` from the dropdown menu.
8. If needed, add any comments from the project manager in the `Project Manager Comments` field.

## Field-by-Field Explanation

* **Event ID** (`event_id`, required): Enter the unique identifier for the event. This helps track and identify the event within the system.
* **Event Name** (`event_name`, required): Enter the name of the event. This should be a clear and concise description of the event.
* **Event Start Date** (`event_start_date`, required): Select the start date of the event. This helps establish the timeline for the event.
* **Event End Date** (`event_end_date`, required): Select the end date of the event. This completes the timeline for the event.
* **Event Planner Notes** (`event_planner_notes`, required): Add any notes or comments about the event. This provides additional context for the event planners and project managers.
* **Event Planner Name** (`event_planner_name`, optional): If applicable, select the event planners responsible for this event. This helps track who was involved in the event.
* **Event Status** (`event_status`, required): Select the current status of the event (Completed, In Progress, or Pending). This helps project managers and stakeholders understand the event's current state.
* **Project Manager Comments** (`project_manager_comments`, optional): Add any comments or feedback from the project manager. This helps event planners and stakeholders understand the project manager's perspective.
