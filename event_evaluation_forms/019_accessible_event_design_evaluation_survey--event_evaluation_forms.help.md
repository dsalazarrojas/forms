# Accessible Event Design Evaluation Survey - Help Guide
## Purpose
The Accessible Event Design Evaluation Survey is designed to collect information about the accessibility of events. This form will help event organizers identify areas of improvement and make their events more accessible for all attendees.

## How To Complete This Form
- Please answer all the questions in this form as accurately as possible, based on your personal experience.
- If you have any difficulty filling out this form, do not hesitate to contact us.
- Please be honest and specific about any accessibility issues you encountered.
- You can fill out the form even if you do not have a disability or did not encounter any accessibility issues.

## Field-by-Field Explanation

* **Attendee Disability Status** (Page 1, Question 1)
	+ This question helps us understand if you have a disability that affects your participation in events.
	+ Answer: "Yes" if you have a disability.
	+ Answer: "No" if you do not have a disability.
	+ Answer: "Prefer not to say" if you do not want to disclose your disability status.
* **Age Group** (Page 1, Question 2)
	+ This question helps us understand the demographics of our attendees.
	+ Please select the age range that best describes you.
* **Event Type Attended** (Page 1, Question 3)
	+ This question helps us understand the type of events you attend.
	+ Please select the type of event you attended (e.g. conference, workshop, seminar).
* **Event Name** (Page 1, Question 4)
	+ This question helps us understand which event you are evaluating.
	+ Please enter the name of the event you attended.
* **Event Date** (Page 1, Question 5)
	+ This question helps us understand when the event took place.
	+ Please select the date of the event.
* **Venue Name** (Page 1, Question 6)
	+ This question helps us understand where the event took place.
	+ Please enter the name of the venue where the event was held.
* **Mobility Accessibility Rating** (Page 2, Question 7)
	+ This question helps us understand how accessible the venue's mobility features were.
	+ Please select the rating that best describes your experience.
* **Visual Accessibility Rating** (Page 2, Question 8)
	+ This question helps us understand how accessible the venue's visual features were.
	+ Please select the rating that best describes your experience.
* **Auditory Accessibility Rating** (Page 2, Question 9)
	+ This question helps us understand how accessible the venue's auditory features were.
	+ Please select the rating that best describes your experience.
* **Communication Accessibility Rating** (Page 2, Question 10)
	+ This question helps us understand how accessible the venue's communication features were.
	+ Please select the rating that best describes your experience.
* **Seating Arrangement Satisfaction** (Page 3, Question 11)
	+ This question helps us understand how satisfied you were with the seating arrangements.
	+ Please select the rating that best describes your experience.
* **Accessible Restroom Availability** (Page 3, Question 12)
	+ This question helps us understand how accessible the restrooms were.
	+ Please select the rating that best describes your experience.
* **Parking Accessibility** (Page 3, Question 13)
	+ This question helps us understand how accessible the parking was.
	+ Please select the rating that best describes your experience.
* **Staff Assistance Quality** (Page 4, Question 14)
	+ This question helps us understand how helpful the event staff were with accessibility needs.
	+ Please select the rating that best describes your experience.
* **Assistive Technology Availability** (Page 4, Question 15)
	+ This question helps us understand how available and functional assistive technologies were.
	+ Please select the rating that best describes your experience.
* **Registration Accommodation Process** (Page 4, Question 16)
	+ This question helps us understand how easy it was to request accommodations during registration.
	+ Please select the rating that best describes your experience.
* **Most Significant Barrier** (Page 5, Question 17)
	+ This question helps us understand what was the most significant accessibility barrier you encountered.
	+ Please select the barrier that best describes your experience.
* **Likelihood to Attend Similar Event** (Page 5, Question 18)
	+ This question helps us understand how likely you are to attend a similar event at this venue.
	+ Please select the rating that best describes your experience.
* **Accessibility Improvement Suggestions** (Page 5, Question 19)
	+ This question helps us understand any accessibility improvements you would recommend.
	+ Please enter any suggestions you may have.
* **Additional Comments** (Page 5, Question 20)
	+ This question helps us understand any other comments you may have about the event's accessibility.
	+ Please enter any comments you may have.

## Tips
- Answer honestly and accurately based on your personal experience.
- If you have any difficulty filling out this form, do not hesitate to contact us.
- Your responses will be kept anonymous and used to improve future events.
