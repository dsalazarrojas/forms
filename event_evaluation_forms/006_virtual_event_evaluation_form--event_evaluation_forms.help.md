# Virtual Event Evaluation Form - Help Guide
## Purpose
This form is designed to collect feedback and evaluation of virtual events from attendees to help event organizers improve the quality and satisfaction of their events.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please ensure that you have attended the virtual event and are filling this form as a genuine attendee.
2. Fill in the required fields, which are indicated by an asterisk (\*).
3. Answer the questions honestly and to the best of your ability.
4. You can submit your evaluation form at any time, but please do not submit it multiple times.

## Field-by-Field Explanation

* **Virtual Event Evaluation** (`virtual_event_evaluation_form`, text, optional): Please provide a brief statement about your overall experience with the virtual event.
* **Event Title** (`event_title`, text, optional): Please provide the title of the virtual event you attended.
* **Event Description** (`event_description`, text, optional): Please provide a short description of the virtual event you attended.
* **Overall Satisfaction** (`overall_satisfaction`, select_one, optional): Choose one of the options below to indicate your overall satisfaction with the virtual event.
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Not Satisfied
	+ Very Unsatisfied
* **Event Value** (`event_value`, number, optional): Please provide a numerical value between 1 and 5 to rate the quality and value of the virtual event.
* **Event Quality** (`event_quality`, text, optional): Please provide a brief statement about the quality of the virtual event.
* **Tip**: You can provide additional comments or suggestions about the virtual event in this field.
