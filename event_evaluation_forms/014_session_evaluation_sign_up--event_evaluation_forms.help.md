# Session Evaluation Sign Up - Help Guide
## Purpose
This form is designed to collect evaluation feedback from session evaluators. It helps the session organizers to understand the effectiveness of the session, identify areas of improvement, and provide valuable insights to attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Sign Up" page to access the form.
2. Fill out the required fields (marked as `required` in the form):
	* Date of the session you evaluated
	* Start and end times of the session
3. Fill out the optional fields:
	* Event name (if applicable)
	* Evaluator's name and email (for contact purposes)
	* Evaluator's phone number (if you'd like to be contacted)

## Field-by-Field Explanation
* **Sign Up** (`session_evaluation_sign_up`, text, required): This is the title of the form. You can leave it as is or add any additional context about the session you evaluated.
* **Date** (`session_date`, date, required): Please select the date of the session you evaluated.
* **Start Time** (`session_start_time`, time, required): Choose the start time of the session. This is crucial for accurate evaluation.
* **End Time** (`session_end_time`, time, required): Select the end time of the session. This will help the session organizers understand the full duration of the session.
* **Event Name** (`event_name`, text, optional): If the session had a name or a specific title, enter it here. If not, you can leave it blank.
* **Evaluator Name** (`evaluator_name`, text, optional): Enter your name as the evaluator. This is for identification purposes.
* **Evaluator Email** (`evaluator_email`, email, optional): Enter your email address. This will help the session organizers contact you for any follow-up questions or discussions.
* **Evaluator Phone** (`evaluator_phone`, text, optional): If you'd like to be contacted via phone, enter your phone number here. Otherwise, you can leave it blank.
* **Comments** (`comments`, text, optional): Add any additional comments or feedback about the session. This is an open-ended field for you to share your thoughts.

## Tips
* Make sure to fill out the required fields accurately and honestly.
* If you've already filled out this form for the same session, please don't duplicate your evaluation.
* If you're unsure about any field, you can always reach out to the session organizer for clarification.
