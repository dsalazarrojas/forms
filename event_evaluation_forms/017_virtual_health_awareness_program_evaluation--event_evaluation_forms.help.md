# Virtual Health Awareness Program Evaluation - Help Guide
## Purpose
This form is intended to gather feedback from participants about their experience with the virtual health awareness program. It will help program organizers understand the program's effectiveness and identify areas for improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read through each page carefully and answer all the questions that apply to you.
2. For each field, provide as much detail as you can.
3. Make sure to complete all required fields.

## Field-by-Field Explanation

* **Introduction** (`text`, optional): Please provide a brief introduction about yourself and your experience with the virtual health awareness program.
* **Background information about the virtual session** (`text`, optional): Please share some background information about the virtual session you attended. What made it memorable? What did you find interesting?
* **Session Attendance** (`select_one`, optional):
	+ Select one of the options that best describe your session attendance:
		- Value 1
		- Value 2
		- Value 3
		- Value 4
		- Value 5
* **Session outcomes and takeaways** (`text`, optional): Please list the key outcomes and takeaways you got from the session.
* **Knowledge gain** (`number`, optional): If you have a specific number of hours or percentage of knowledge gained from the session, please enter it here.
* **Session satisfaction** (`select_multiple`, optional):
	+ Select all the options that describe your session satisfaction:
		- Value 1
		- Value 2
		- Value 3
		- Value 4
		- Value 5
* **Future programs** (`text`, optional): If you are interested in attending future health awareness programs, please mention them here.
* **Comments** (`note`, optional): Do you have any comments or suggestions about the program? Share them here.
* **E-mail** (`email`, optional): If you'd like to receive updates from the program, please provide your email address here.

## Tips
* Please be as specific and detailed as possible when answering the questions.
* If you have any questions or concerns, feel free to ask us.
* Thank you for taking the time to complete this form. Your feedback is valuable to us!
