# International Trade Certification Exam Form - Help Guide
## Purpose
The International Trade Certification Exam Form is designed to collect information about certification exams. It includes fields to capture exam details such as exam date, time, location, and scores.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the exam date and time using the calendar picker or text input.
2. Enter your First Name and Last Name.
3. Provide your contact information using the Email and Contact Number fields.
4. Select the exam location from the available options.
5. Choose the exam type and category from the respective select menus.
6. Enter the exam duration (optional).
7. Select the exam start and end dates.
8. Choose the exam status and language from the respective select menus.
9. Enter any additional comments or notes about the exam.
10. Select relevant exam attachments (optional).

## Field-by-Field Explanation

* **Exam Form**: This is the main heading for the exam form.
* **First Name** (`First Name`, `text`, required): Enter your first name.
* **Last Name** (`Last Name`, `text`, required): Enter your last name.
* **Email** (`Email`, `email`, required): Enter your email address.
* **Contact Number** (`Contact Number`, `text`, required): Enter your contact number.
* **Exam Date** (`Exam Date`, `date`, required): Select the exam date using the calendar picker.
* **Exam Time** (`Exam Time`, `time`, required): Select the exam time.
* **Exam Location** (`Exam Location`, `select_one`, required): Select the exam location from the available options.
* **Goals** (`Goals`, `note`, optional): Enter any additional goals or objectives for the exam.
* **Exam Type** (`Exam Type`, `select_multiple`, required): Choose the type of exam.
* **Exam Level** (`Exam Level`, `select_one`, required): Choose the level of the exam.
* **Exam Category** (`Exam Category`, `select_multiple`, required): Choose the category of the exam.
* **Exam Duration** (`Exam Duration`, `number`, optional): Enter the exam duration (optional).
* **Exam Start Date** (`Exam Start Date`, `date`, optional): Select the exam start date.
* **Exam End Date** (`Exam End Date`, `date`, optional): Select the exam end date.
* **Exam Status** (`Exam Status`, `select_one`, required): Choose the exam status.
* **Exam Score** (`Exam Score`, `number`, optional): Enter the exam score (optional).
* **Exam Language** (`Exam Language`, `select_one`, required): Choose the exam language.
* **Exam Comments** (`Exam Comments`, `note`, optional): Enter any additional comments or notes about the exam.
* **Exam Attachment** (`Exam Attachment`, `text`, optional): Select any relevant exam attachments.
* **Exam Notes** (`Exam Notes`, `note`, optional): Enter any additional exam notes.
* **Exam Result** (`Exam Result`, `select_one`, required): Choose the exam result.
* **Exam Result Date** (`Exam Result Date`, `date`, optional): Select the exam result date (optional).
* **Exam Notes** (`Exam Notes`, `note`, optional): Enter any additional exam notes.
* **Exam Agreement** (`Exam Agreement`, `select_multiple`, optional): Choose any additional exam agreements.
* **Exam Agreement Options**: Option 1, Option 2, Option 3, Option 4, Option 5.
