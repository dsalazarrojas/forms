# Children Histogram Quiz - Help Guide
## Purpose
The purpose of this form is to collect data about students' understanding and application of histograms, specifically in an educational setting.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Student Name field with the full name of the student.
2. If applicable, select the class or grade level of the student.
3. Answer the three questions about histograms, selecting the correct option for each question.
	* Which chart shows frequency of scores?
	* A histogram groups data by...
	* Histograms are useful for...
4. Optionally, provide feedback on the student's performance in the Teacher Comments field.
5. Enter a numeric score for the student's quiz performance.

## Field-by-Field Explanation

* **Student Name** (student_name, text, required): Enter the full name of the student.
* **Class or Grade** (class_grade, text, optional): If applicable, enter the class or grade level of the student.
* **Which chart shows frequency of scores?** (question_1, select_one, required):
	+ Select one of the options: Bar chart, Histogram, Pie chart, Line chart.
* **A histogram groups data by** (question_2, select_one, required):
	+ Select one of the options: Categories, Ranges of values, Individual names.
* **Histograms are useful for** (question_3, select_one, required):
	+ Select one of the options: Showing distribution, Comparing proportions, Showing trends over time.
* **Teacher Comments** (teacher_comments, text, optional): Optionally provide feedback on the student's performance.
* **Score** (score, number, optional): Enter a numeric score for the student's quiz performance.
