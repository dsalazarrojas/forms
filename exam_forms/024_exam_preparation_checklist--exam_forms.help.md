# Exam Preperation Checklist - Help Guide
## Purpose
This form is designed to help you prepare for an exam by checking off items on a checklist.

## How To Complete This Form
To complete this form, simply select the options that apply to your exam preparation needs. For each field, choose the option that best fits your situation. Make sure to review each field carefully and select the correct options.

## Field-by-Field Explanation
### Exam Preparation Questions
* **Exam Preparation Questions** (`exam_preperation_checklist_questions`, `select_multiple`, required/optional): Select 'Yes' if you have exam preparation questions that you need help with. Select 'No' if you do not have exam preparation questions.
### Exam Preparation Materials
* **Exam Preparation Materials** (`exam_preperation_checklist_materials`, `select_multiple`, required/optional): Select 'Yes' if you need exam preparation materials such as textbooks, notes, or online resources. Select 'No' if you do not need exam preparation materials.
### Exam Schedule
* **Exam Schedule** (`exam_preperation_checklist_schedule`, `date`, required/optional): Select the date of your exam, if known.
### Exam Deadlines
* **Exam Deadlines** (`exam_preperation_checklist_deadlines`, `select_one`, required/optional): Select 'Yes' if you have exam deadlines to meet. Select 'No' if you do not have exam deadlines.
### Exam Preparation Resources
* **Exam Preparation Resources** (`exam_preperation_checklist_resources`, `select_multiple`, required/optional): Select 'Yes' if you need access to exam preparation resources such as online courses or tutoring. Select 'No' if you do not need exam preparation resources.
### Exam Notes
* **Exam Notes** (`exam_preparation_checklist_notes`, `note`, required/optional): Add any additional notes about your exam preparation.
### Contact Information
* **Contact Information** (`exam_preperation_checklist_phone`, `text`, required/optional): Enter your contact information, if needed.
* **Email** (`exam_preperation_checklist_email`, `email`, required/optional): Enter your email address, if needed.
