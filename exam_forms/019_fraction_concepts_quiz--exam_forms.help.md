# Fraction Concepts Quiz - Help Guide
## Purpose
This form is designed to evaluate students' knowledge of fraction concepts, covering essential skills such as solving problems and identifying equivalent ratios.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of problem you are attempting to solve. This will help the system understand the context of your answer.
2. Enter the numerator value of the fraction you are working with.
3. Enter the denominator value of the fraction you are working with.
4. Identify an equivalent ratio for the given fraction.
5. Choose the correct answer for the comparison question.
6. Select the type of solution you are providing.
7. If you have a word problem, describe it in the text field.
8. Enter your score for the question.
9. Provide any comments or feedback about the question.
10. Enter your student ID for identification purposes.
11. Enter your teacher ID for identification purposes.
12. Enter the date and time you completed the quiz.
13. Finally, select any assigned students who should receive this assessment.

## Field-by-Field Explanation
* **concept** (`concept`, text, optional): Enter a brief description of the fraction concept you are working with.
* **problem type** (`problem_type`, select one, optional): Choose the type of problem you are attempting to solve (e.g., 1, 2, 3, or 4).
* **numerator value** (`numerator_value`, number, optional): Enter the numerator value of the fraction.
* **denominator value** (`denominator_value`, number, optional): Enter the denominator value of the fraction.
* **equivalent ratio** (`equivalent_ratio`, select multiple, optional): Identify multiple equivalent ratios for the given fraction.
* **comparison question** (`comparison_question`, select one, optional): Choose the correct answer for the comparison question.
* **solution type** (`solution_type`, select one, optional): Select the type of solution you are providing.
* **word problem** (`word_problem`, text, optional): Describe any word problem you are attempting to solve.
* **score** (`score`, number, optional): Enter your score for the question.
* **result** (`result`, text, optional): Provide any comments or feedback about the question.
* **student id** (`student_id`, number, optional): Enter your student ID for identification purposes.
* **teacher id** (`teacher_id`, number, optional): Enter your teacher ID for identification purposes.
* **date** (`date`, date, optional): Enter the date and time you completed the quiz.
* **form id** (`form_id`, number, optional): This field is likely used for tracking purposes.
* **assigned to** (`assigned_to`, select multiple, optional): Select students who are assigned this assessment.

Please fill out the form according to your understanding of the fraction concepts, and remember to provide accurate information for the fields that are not marked as optional.
