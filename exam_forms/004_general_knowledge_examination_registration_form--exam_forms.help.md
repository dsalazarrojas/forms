# general_knowledge_examination_registration_form - Help Guide
## Purpose
The "general_knowledge_examination_registration_form" is used to collect information from participants regarding their examination details. This includes exam dates, participant information, and examination settings.

## How To Complete This Form
To complete this form, follow these steps: 
1. Select the exam date from the given options.
2. Enter the participant's name and contact number.
3. Provide a valid email address for communication purposes.
4. Specify the location for the examination.
5. Choose the examination type.
6. Select the examination locations where the exam will take place.
7. Enter the exam time.
8. Specify the examination duration.
9. Provide the start date for the examination.
10. Select the examination level.
11. Choose the examination status.
12. Select the examination result.

## Field-by-Field Explanation

* **Exam Date (#1)**: Select a date for the examination. This field is optional.
* **Participant Name (#2)**: Enter the name of the participant. This field is optional.
* **Contact Number (#3)**: Enter a contact number for the participant. This field is optional.
* **Email (#4)**: Enter a valid email address for communication purposes. This field is optional.
* **Location (#5)**: Enter the location for the examination. This field is optional.
* **Exam Type (#7)**: Select the type of examination. This field is optional.
* **Exam Location (#8)**: Select the locations where the exam will take place. This field is optional.
* **Exam Time (#9)**: Enter the time for the examination. This field is optional.
* **Exam Duration (#10)**: Enter the duration of the examination in number format. This field is optional.
* **Start Date (#11)**: Enter the start date for the examination. This field is optional.
* **Exam Level (#12)**: Select the level of the examination. This field is optional.
* **Exam Status (#13)**: Select the status of the examination. This field is optional.
* **Exam Result (#14)**: Select the result of the examination. This field is optional.
