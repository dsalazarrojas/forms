# Data Models Knowledge Quiz - Help Guide
## Purpose
This form is designed to collect data on question types, correct answers, and other relevant information. Please use it to gather data on a specific subject area.

## How To Complete This Form
1. Review the form carefully to ensure you're filling out all required fields.
2. Select a question type from the dropdown menu for each question.
3. Choose the correct answer for each question.
4. Enter the time it took to answer each question.
5. Provide additional notes or comments if needed.
6. Enter the email address and phone number of the person answering the questions.

## Field-by-Field Explanation
* **What is your question type** (`question_type`, select_one, required: false): Select a question type from the dropdown menu. This will help us understand the type of question being asked.
* **What is your answer type** (`answer_type`, select_one, required: false): Choose the type of answer corresponding to the question type.
* **What is the time** (`time`, time, required: false): Enter the time it took to answer the question. Note that this field only accepts time values in 24-hour format (HH:MM).
* **Question number** (`question_number`, number, required: false): Enter the question number or identifier.
* **Correct answer** (`correct_answer`, select_one, required: false): Select the correct answer for the question.
* **Correct answer type** (`correct_answer_type`, select_one, required: false): Choose the type of correct answer.
* **Additional notes** (`note`, note, required: false): Provide any additional comments or notes about the question or answer.
* **Email address** (`email`, email, required: false): Enter the email address of the person answering the questions.
* **Phone number** (`phone_number`, text, required: false): Enter the phone number of the person answering the questions.
* **Another question type** (`question_type_2`, select_one, required: false): Select another question type from the dropdown menu.
* **Another correct answer** (`correct_answer_2`, select_one, required: false): Select the correct answer for the next question.
* **Another time** (`time_2`, time, required: false): Enter the time it took to answer the next question.
* **Another question number** (`question_number_2`, number, required: false): Enter the question number or identifier for the next question.
* **Another correct answer type** (`correct_answer_type_2`, select_one, required: false): Choose the type of correct answer for the next question.
* **Another note** (`note_2`, note, required: false): Provide additional comments or notes about the next question or answer.
* **Another email address** (`email_2`, email, required: false): Enter the email address of the person answering the next question.
* **Another phone number** (`phone_number_2`, text, required: false): Enter the phone number of the person answering the next question.
