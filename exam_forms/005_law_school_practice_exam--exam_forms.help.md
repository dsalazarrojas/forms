# Law School Practice Exam - Help Guide
## Purpose
The Law School Practice Exam is a test designed to evaluate your understanding of various legal concepts and principles. This form is meant to help you assess your knowledge and prepare for actual exams or assessments.

## How To Complete This Form
- To start, read the instructions on each page carefully.
- For multiple-choice questions (questions 2 and 3), select the correct answer(s) from the available options.
- For date and time questions (questions 4 and 5), enter the date and time in the correct format (e.g., MM/DD/YYYY or HH:MM AM/PM).
- For the email field (question 6), enter a valid email address.
- For the phone number field (question 7), enter a valid phone number.
- For the note field (question 8), type any additional comments or notes you'd like to provide.

## Field-by-Field Explanation
* **Written (Page 1)** (`law_school_practice_exam_1`, text, not required): This field is a free-text section where you can answer questions that require a written response.
* **Multiple-Choice Question 1 (Page 2)** (`law_school_practice_exam_2`, select_one, not required): Select the correct answer to the question presented. For example, if the question asks "Is this statement true?", select "Yes" or "No".
* **Multiple-Choice Question 2 (Page 3)** (`law_school_practice_exam_3`, select_multiple, not required): Select all the correct answers to the question presented.
* **Date Question (Page 4)** (`law_school_practice_exam_4`, date, not required): Enter the date in the format MM/DD/YYYY.
* **Time Question (Page 5)** (`law_school_practice_exam_5`, time, not required): Enter the time in the format HH:MM AM/PM.
* **Email (Page 6)** (`law_school_practice_exam_6`, email, not required): Enter a valid email address.
* **Phone Number (Page 7)** (`law_school_practice_exam_7`, text, not required): Enter a valid phone number.
* **Note (Page 8)** (`law_school_practice_exam_8`, note, not required): Type any additional comments or notes you'd like to provide.
