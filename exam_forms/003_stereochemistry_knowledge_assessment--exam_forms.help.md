# Stereochemistry Knowledge Assessment - Help Guide
## Purpose
The Stereochemistry Knowledge Assessment form is designed to evaluate a user's knowledge of stereochemistry, a branch of chemistry that deals with the three-dimensional arrangement of atoms in molecules. The form helps to gauge a user's understanding of the concepts and principles that govern the spatial arrangement of atoms and molecules.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of question you want to answer from the "Question Type" dropdown menu.
2. Type your answer in the text field labeled "Question Text" and provide any additional information or clarification as needed.
3. If multiple options are available, select the correct answer from the list of options.
4. Optionally, provide a hint to help clarify your answer if needed.
5. If applicable, assign a point value to your answer.
6. Choose whether to submit your response immediately or select "Other" for review.
7. Optionally, set a time limit for the response.
8. Note: This section is for internal use only and not required for user completion.

## Field-by-Field Explanation
### Question Type
* **Question Type** (`question_type`, `select_one`, required/optional: required): Select the type of question you want to answer: Multiple Choice, Short Answer, Checkboxes, or Radio Buttons.

### Question Text
* **Question Text** (`question_text`, `text`, required/optional: required/optional): Type your answer to the question in the text field provided.

### Answer Options
* **Answer Options** (`question_answer`, `select_multiple`, required/optional: required/optional): Choose one or multiple options that best answer your question. Select the options by checking the corresponding checkboxes.

### Hint
* **Hint** (`question_hint`, `note`, required/optional: required/optional): Provide a hint or additional information to help clarify your answer if needed.

### Point Value
* **Point Value** (`question_points`, `number`, required/optional: required/optional): Assign a point value to your answer if applicable. This will help in determining the scoring of your assessment.

### Submit
* **Submit** (`submit_button`, `select_one`, required/optional: required/optional): Choose whether to submit your response immediately or select "Other" for review.

### Time Limit
* **Time Limit** (`time_limit`, `time`, required/optional: required/optional): Set a time limit for your response if you want to complete the assessment within a specific timeframe.

### Form ID
* **Form ID** (`form_id`, `number`, required/optional: required/optional): This field is for internal use only and not required for user completion.

### Created At
* **Created At** (`created_at`, `date`, required/optional: required/optional): This field displays the date and time when the form was created and is not required for user completion.

Note: The fields marked "required/optional: required" are mandatory fields and must be filled out. The fields marked "required/optional: optional" are not mandatory and can be left blank.
