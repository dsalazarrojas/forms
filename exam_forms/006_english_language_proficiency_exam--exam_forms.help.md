# English Language Proficiency Exam - Help Guide
## Purpose
This form is designed to assess a student's language proficiency in the English language, covering various aspects such as listening, speaking, reading, and writing skills. It's intended to be used by teachers, educators, or language proficiency evaluators to evaluate a student's language abilities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the "Student Name" field.
2. Provide the student's email address in the "Student Email" field.
3. Select the student's native language from the "Native Language" dropdown menu.
4. Choose the student's language proficiency level from the "Student Language Proficiency" dropdown menu.
5. Add any additional notes or comments in the "Student Notes" field.

## Field-by-Field Explanation
* **Student Name**: Enter the student's name.
* **Student Email**: Enter the student's email address.
* **Native Language**: Select the student's native language, such as English, French, Spanish, Chinese, or Other.
* **Student Language Level**: Select the student's language level, such as Basic, Intermediate, or Advanced.
* **Student Language Proficiency**: Select the student's language proficiency skills, such as Listening, Speaking, Reading, Writing, or Other.
* **Student Notes**: Add any additional notes or comments about the student.
* **Examiner Notes**: Add any notes or comments from the evaluator.
* **Student Language Proficiency Hint**: This field is intended to provide additional information or context about the student's language proficiency, but it is not required.

## Tips
* Make sure to enter accurate and detailed information for each field to provide a comprehensive assessment of the student's language proficiency.
* If you're unsure about a student's language proficiency level or native language, you can select "Other" as an option to provide more specific information.
