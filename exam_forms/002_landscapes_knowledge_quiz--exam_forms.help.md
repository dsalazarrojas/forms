# Landscapes Knowledge Quiz - Help Guide
## Purpose
This form is a knowledge quiz about landscapes. It is meant to test the user's understanding of different types of landscapes.

## How To Complete This Form
To complete this form, simply fill in the required fields, and provide the necessary information. The form is split into the following sections:
1. Landscapes Knowledge Quiz
2. Category
3. Description
4. Form ID
5. Output File
6. Assigned Tool

## Field-by-Field Explanation
* **Landscapes Knowledge Quiz (1)**: This is the main title of the quiz.
* **Category (2)**: Select a category that best describes the type of landscape being tested.
* **Description (3)**: Provide a brief description of the quiz.
* **Form ID (4)**: Enter a unique identifier for this form.
* **Output File (5)**: Specify the output file for this form.
* **Assigned Tool (6)**: Specify the tool assigned to this form.
