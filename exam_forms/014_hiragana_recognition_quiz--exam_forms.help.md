# Hiragana Recognition Quiz - Help Guide
## Purpose
This form is designed to test your knowledge of Hiragana characters. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct answer to the Hiragana question on page 1.
2. Choose all the correct answer options on page 2.
3. Enter your name on page 3.
4. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Hiragana Image (Page 1)** (`hiragana_image`, number, not required): This is where you will see the Hiragana character to be recognized. Please take a close look at the character and select the correct answer from the options below.
* **Correct Answer (Page 2)** (`correct_answer`, select_one, not required): Choose the correct answer from the options 1, 2, 3, 4, 5, or 6.
* **Answer Choices (Page 2)** (`answer_choices`, select_multiple, not required): Choose all the correct answers that match the image.
* **Student Name (Page 3)** (`student_name`, text, not required): This is where you enter your name. Please enter your name as it appears on your identification.

## Tips

* Take your time to accurately and carefully examine the Hiragana image.
* Select the correct answer options that match the image.
* Ensure all selected answer options are accurate and match the image.
* If you are unsure or have questions, please contact the form administrator.
