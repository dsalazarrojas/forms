# Color Theory Knowledge Quiz - Help Guide
## Purpose

This form is a quiz designed to assess your knowledge of color theory concepts. It consists of five questions that test your understanding of primary colors, complementary colors, color temperature, and color mixing. Please take the quiz seriously and answer the questions to the best of your ability.

## How To Complete This Form

To complete the quiz, follow these steps:

1. Fill in your participant name in the "Participant name" field if you wish to be recorded as a participant.
2. Answer the five questions, choosing the correct options for each question.
3. Estimate the time taken to complete the quiz in the "Time taken in minutes" field.
4. If you know your score, enter it in the "Estimated score" field.
5. Provide any additional feedback in the "Additional feedback" field.

## Field-by-Field Explanation

* **-- Color Theory Quiz --** (`header`, `note`, required: `false`): This is the title of the quiz.
* **Participant name** (`participant_name`, `text`, required: `false`): Enter your name if you wish to be recorded as a participant.
* **Question 1 - Primary colors** (`question_1`, `select_multiple`, required: `true`): Select the primary colors. Please choose one or more of the following options:
	+ Red
	+ Blue
	+ Green
	+ Yellow
* **Question 2 - Complementary of blue** (`question_2`, `select_one`, required: `true`): Select the complementary color of blue. Please choose one of the following options:
	+ Orange
	+ Green
	+ Red
	+ Purple
* **Question 3 - Color temperature refers to** (`question_3`, `select_one`, required: `true`): Choose the best answer. Please select one of the following options:
	+ Warm vs cool
	+ Saturation levels
	+ Hue shifts
* **Question 4 - Mixing red and blue produces** (`question_4`, `select_one`, required: `true`): Choose the result. Please select one of the following options:
	+ Purple
	+ Green
	+ Orange
* **Question 5 - Neutralizing a color means** (`question_5`, `select_one`, required: `true`): Select the best description. Please choose one of the following options:
	+ Reducing intensity
	+ Adding complementary
	+ Changing hue
* **Time taken in minutes** (`time_taken`, `number`, required: `false`): Estimate the time taken to complete the quiz.
* **Estimated score** (`score_estimate`, `number`, required: `false`): Enter your self-reported score if known.
* **Additional feedback** (`additional_feedback`, `text`, required: `false`): Provide any additional feedback about the quiz.
