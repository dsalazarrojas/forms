# Notation Knowledge Quiz - Help Guide

## Purpose
This form is designed to collect information about musical notation knowledge for the purpose of assessing or creating musical scores or pieces.

## How To Complete This Form

1.  Read each question carefully and choose the correct answer for each field.
2.  Ensure that each field has been filled out correctly before proceeding to the next question.
3.  If you're unsure about any of the fields, refer to the Field-by-Field Explanation section for clarification.
4.  Fill out the form in the required order, starting from the first page (notation_type) to the last page (score).

## Field-by-Field Explanation

*   **Notation Type (notation_type)** (`select_one`, optional): Choose the type of musical notation you are familiar with (e.g., A, B, C, D).
*   **Time Signature (time_signature)** (`number`, optional): Enter the time signature of the musical piece (e.g., 3/4, 4/4, etc.).
*   **Beat Pattern (beat_pattern)** (`select_multiple`, optional): Select the beat pattern used in the musical piece (e.g., 1, 2, 3).
*   **Note Value (note_value)** (`number`, optional): Enter the note value used in the musical piece (e.g., 1, 2, 3, etc.).
*   **Staff Size (staff_size)** (`select_one`, optional): Choose the staff size used in the musical piece (e.g., 4, 5, 6, 7).
*   **Note Position (note_position)** (`select_multiple`, optional): Select the note position used in the musical piece (e.g., top, middle, bottom).
*   **Clef Sign (clef_sign)** (`select_multiple`, optional): Select the clef sign used in the musical piece (e.g., left, right).
*   **Key Signature (key_signature)** (`select_one`, optional): Choose the key signature used in the musical piece (e.g., 3/4, 6/8, 4/4, 3/8).
*   **Time Signature 2 (time_signature_2)** (`number`, optional): Enter the time signature 2 used in the musical piece (e.g., 3/4, 4/4, etc.).
*   **Note Value 2 (note_value_2)** (`number`, optional): Enter the note value 2 used in the musical piece (e.g., 1, 2, 3, etc.).
*   **Staff Size 2 (staff_size_2)** (`select_one`, optional): Choose the staff size 2 used in the musical piece (e.g., 4, 5, 6, 7).
*   **Note Position 2 (note_position_2)** (`select_multiple`, optional): Select the note position 2 used in the musical piece (e.g., top, middle, bottom).
*   **Clef Sign 2 (clef_sign_2)** (`select_multiple`, optional): Select the clef sign 2 used in the musical piece (e.g., left, right).
*   **Key Signature 2 (key_signature_2)** (`select_one`, optional): Choose the key signature 2 used in the musical piece (e.g., 3/4, 6/8, 4/4, 3/8).
*   **Score (score)** (`select_one`, optional): Choose whether the musical piece is a score or not (True or False).

## Tips

*   If you're unsure about any of the fields, refer to the Field-by-Field Explanation section for clarification.
*   Ensure that each field has been filled out correctly before proceeding to the next question.
*   If you need to ask for help or clarification, contact the support team.
