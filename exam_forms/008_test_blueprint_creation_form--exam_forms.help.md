# Test Blueprint Creation Form - Help Guide
## Purpose
This form is used to create test blueprints for exams or assessments.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter a title for your test blueprint in the **Form Title** field.
2. Select a category for your test blueprint from the dropdown menu (**Category**).
3. Input a description for your test blueprint in the **Form Description** field.
4. If your test blueprint has any specific requirements, enter them in the **Form Requirements** field.
5. If you have any additional information for the requirements, you can add it in the **Form Requirements Note** field.
6. Determine if your test blueprint will have data fields (**Form Data Fields**).
7. If so, you can add individual data fields in the **Form Data Fields 1** and **Form Data Fields 2** fields.

## Field-by-Field Explanation

* **Form Title** (form_title, text, required: false):
	+ A brief title for your test blueprint.
* **Category** (form_category, select_one, required: false):
	+ Choose a category for your test blueprint from the dropdown menu:
		- Exam Forms
		- Training Forms
		- Assessment Forms
* **Form Description** (form_description, note, required: false):
	+ A detailed description of your test blueprint.
* **Form Requirements** (form_requirements, text, required: false):
	+ Enter any specific requirements for your test blueprint.
* **Form Requirements Note** (form_requirements_note, note, required: false):
	+ Additional information for the requirements.
* **Form Data Fields** (form_data_fields, select_multiple, required: false):
	+ Determine if your test blueprint will have data fields.
* **Form Data Fields 1** (form_data_fields_1, text, required: false):
	+ If you selected yes for data fields, you can add individual data fields here.
* **Form Data Fields 2** (form_data_fields_2, text, required: false):
	+ Add more individual data fields if needed.

## Tips
- Make sure to keep your form title concise and descriptive.
- Choose the most relevant category for your test blueprint.
- Keep the form description detailed and clear.
- Enter specific requirements and notes to provide additional context.
- Be realistic about the data fields your test blueprint will require.
