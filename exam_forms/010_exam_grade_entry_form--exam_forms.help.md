# Exam Grade Entry Form - Help Guide
## Purpose
This form is used to record student grades for exams. It allows administrators to input student names, IDs, assignment IDs, scores, grades, categories, exam dates, and any additional comments.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the student's name in the `Student Name` field.
2. Enter the student's ID number in the `Student ID` field.
3. Enter the assignment ID number in the `Assignment ID` field.
4. Enter the score obtained by the student for the exam.
5. Enter the grade for the exam, which is usually a letter grade (e.g., A, B, C, etc.).
6. Select the category for the exam from the dropdown list (e.g., Math, English, Science, Social Studies).
7. Enter the date of the exam.
8. (Optional) Provide any additional comments about the exam.

## Field-by-Field Explanation

### 1. **Student Name** (`Student Name`, text, required)
Enter the student's full name.

### 2. **Student ID** (`Student ID`, number, required)
Enter the student's ID number as assigned by the school or institution.

### 3. **Assignment ID** (`Assignment ID`, number, required)
Enter the ID number of the assignment taken by the student.

### 4. **Score** (`Score`, number, required)
Enter the score obtained by the student for the exam.

### 5. **Grade** (`Grade`, number, required)
Enter the grade for the exam, usually a letter grade (e.g., A, B, C, etc.).

### 6. **Category** (`Category`, select_one, required)
Select the category for the exam from the dropdown list:
*   Math
*   English
*   Science
*   Social Studies

### 7. **Exam Date** (`Exam Date`, date, required)
Enter the date of the exam.

### 8. **Comments** (`Comments`, note, optional)
(No specific format or requirements specified, but this is an optional field for additional comments or notes about the exam.)

Tips: Make sure to enter accurate and accurate information for each field to ensure accurate record-keeping and data tracking.
