# statistics_exam_quiz - Help Guide
## Purpose
The statistics_exam_quiz form is designed to collect information from students on their performance on a set of questions. This form is used to record and analyze the students' responses to these questions.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your Student ID in the `student_id` field.
2. Enter your name in the `student_name` field.
3. Answer each of the question fields (`question1`, `question2`, `question3`, `question4`, `question5`) with your response. For each question, type the corresponding number from 1 to 5.
## Tips
- Make sure to fill in all required fields to ensure accurate data collection.
- If you have any issues or concerns while filling out this form, please contact your administrator.

## Field-by-Field Explanation
* **Student ID**: 
    Enter your unique student ID number.
* **Student Name**: 
    Enter your full name as it is recorded in the school records.
* **Question 1**: 
    Type the number corresponding to the answer you selected for Question 1.
* **Question 2**: 
    Type the number corresponding to the answer you selected for Question 2.
* **Question 3**: 
    Type the number corresponding to the answer you selected for Question 3.
* **Question 4**: 
    Type the number corresponding to the answer you selected for Question 4.
* **Question 5**: 
    Type the number corresponding to the answer you selected for Question 5.
