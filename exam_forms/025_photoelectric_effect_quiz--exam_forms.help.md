# Photoelectric Effect Quiz - Help Guide

## Purpose
This form is designed to collect user input for the Photoelectric Effect Quiz. The form consists of four sections: Introduction, Physics Question, Physics Answer, and Note. The form is used to assess the user's understanding of the photoelectric effect in physics.

## How To Complete This Form
To complete this form, follow the steps below:
1. Begin by reading the Introduction section, which provides background information about the photoelectric effect.
2. In the Physics Question section, select all the relevant answers by clicking on the "Yes" buttons for each option that applies to your understanding of the photoelectric effect.
3. In the Physics Answer section, select the single correct answer that best describes your understanding of the photoelectric effect.
4. Optionally, add any additional notes or comments in the Note section.

## Field-by-Field Explanation
### Introduction
• **Introduction** (`1`, `text`, optional): This is a text field where you can provide background information or context about your understanding of the photoelectric effect. You can type any relevant details or thoughts you have about the topic.

### Physics Question
• **Physics Question** (`2`, `select_multiple`, optional): In this section, select all the options that apply to your understanding of the photoelectric effect. You can choose from "Yes" for each option that you believe is correct.

### Physics Answer
• **Physics Answer** (`3`, `select_one`, optional): Select the single answer that best describes your understanding of the photoelectric effect. Choose from the options: Answer A, Answer B, Answer C, or Answer D.

### Note
• **Note** (`4`, `note`, optional): This is a free-text field where you can add any additional notes or comments about your understanding of the photoelectric effect.
