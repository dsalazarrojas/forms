# International Health Certificate Exam Application Form - Help Guide
## Purpose
This form is used to collect information for the international health certificate exam application process.

## How To Complete This Form
1. Fill out the form in a step-by-step manner, page by page.
2. Answer each field carefully, as they are all important for the exam application process.
3. Ensure you have all necessary information before submitting the form.

## Field-by-Field Explanation

* **Medical History** (`1`, `text`, required: `false`): Please provide a brief description of your medical history, including any health conditions, medications, or allergies.
* **Passport Details** (`2`, `select_multiple`, required: `false`): Please select 'Yes' if you hold a passport, and 'No' otherwise.
* **Nationality** (`3`, `text`, required: `false`): Please state your nationality or the nationality of the country you represent.
* **Travel Dates** (`4`, `date`, required: `false`): If you are planning to travel, please enter the dates of your travel.
* **Contact Details** (`5`, `select_one`, required: `false`): Please select 'Yes' if you wish to receive contact information for follow-up communication.
* **Phone Numbers** (`6`, `text`, required: `false`): If you have a phone number, please enter it.
* **Email Addresses** (`7`, `email`, required: `false`): If you have an email address, please enter it.
* **Nationality Issued By** (`8`, `select_multiple`, required: `false`): Please select if you were issued a nationality by another country or institution.
* **Medical Examiner** (`9`, `select_one`, required: `false`): Please select 'Yes' if you have been examined by a medical professional.
* **Medical Certification** (`10`, `select_multiple`, required: `false`): Please select if you have received medical certification.
* **Exam Location** (`11`, `select_one`, required: `false`): Please select 'Yes' if you are taking the exam at a specific location.
* **Travel History** (`12`, `text`, required: `false`): Please provide a brief description of your travel history.
* **Medical Certification Issue Date** (`13`, `date`, required: `false`): If you have received medical certification, please enter the date it was issued.
* **Medical Certification Number** (`14`, `number`, required: `false`): If you have received medical certification, please enter the number assigned to you.
* **Exam Fee** (`15`, `number`, required: `false`): If you have paid an exam fee, please enter the amount.
* **Exam Prophets** (`16`, `text`, required: `false`): Please provide a brief description of the exam's prophets.
* **Exam Prophets Issued By** (`17`, `text`, required: `false`): Please enter the name of the institution that issued the examination certificate.
* **Exam Prophets Date** (`18`, `date`, required: `false`): If you received an exam prophets, please enter the date it was issued.
