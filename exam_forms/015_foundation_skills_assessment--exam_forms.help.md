# Foundation Skills Assessment - Help Guide
## Purpose
The Foundation Skills Assessment is a tool used to evaluate users' foundation skills, which are essential abilities or knowledge required for a particular job or task.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form instructions and ensure you understand the purpose and scope of the assessment.
2. Answer each question on the separate pages, providing as much detail as possible about your foundation skills.
3. Submit your answers to complete the assessment.

## Field-by-Field Explanation
### **First Page - User Input 1**
* **User Input 1** (`text`, **not required**): This is the first text input field, where you can describe your foundation skills or experiences.

### **Second Page - User Input 2**
* **User Input 2** (`text`, **not required**): This is the second text input field, where you can elaborate on your foundation skills or experiences.

### **Third Page - User Input 3**
* **User Input 3** (`text`, **not required**): This is the third text input field, where you can provide more details about your foundation skills or experiences.

## Tips
* Please answer each question as thoroughly as possible to provide a comprehensive assessment of your foundation skills.
