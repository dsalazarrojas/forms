# Ethics Knowledge Assessment - Help Guide
## Purpose
The Ethics Knowledge Assessment form is designed to test the respondent's knowledge on various ethical matters.

## How To Complete This Form
To complete this form, follow these steps:

1. Start on the first page and read the introductory text carefully.
2. Answer each question according to your best knowledge.
3. Make sure to complete all questions, but check that none are duplicated.
4. Once you've completed all the questions, submit the form.
