# Smile Assessment Form Template - Help Guide
## Purpose
The Smile Assessment Form Template is designed to collect information about a patient's smile and overall oral health. This form is intended for use in dental and orthodontic clinics to assess the patient's smile aesthetics, functionality, and satisfaction. It is not a medical diagnostic tool and should not be used to diagnose any conditions.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully and answer the questions accurately.
2. For each page, select the correct answer based on the patient's response.
3. Make sure to fill in all required fields.
4. If you are unsure about any question, please ask your doctor or dentist for guidance.

## Field-by-Field Explanation

### Page 1: Smile Assessment
* **Smile Assessment** (smile_assessment_form_template_page_1, text, required): This is the main question of the form, where you can type in your answer to the question "What is your overall smile assessment?"
* **Smile Assessment** (smile_assessment_form_template_page_2, date, not required): This is the date of the assessment.

### Page 2: Smile Assessment
* **Smile Assessment** (smile_assessment_form_template_page_3, select_one, not required): This question asks you to select one of the following options: "Yes" or "No". If you answer "Yes", it means the patient has a good smile aesthetics. If you answer "No", it means the patient does not have a good smile aesthetics.
* **Smile Assessment** (smile_assessment_form_template_page_4, select_multiple, not required): This question asks you to select all that apply regarding the patient's smile assessment. For example, if you select "Yes" for "Good smile aesthetics" and "Yes" for "Good smile functionality", it means the patient has both good smile aesthetics and functionality.

### Page 3: Smile Assessment
* **Smile Assessment** (smile_assessment_form_template_page_5, time, not required): This is the time of the assessment. 

### Tips
* Be thorough and honest when answering each question.
* Please note that the smile assessment is a subjective evaluation, so be careful when answering based on the patient's subjective feeling.
* If you need to make any changes or corrections to the form, please let your doctor or dentist know.
* This form is for internal use only and is not for external sharing or publication.
