# Coronavirus Case Report Template - Help Guide
## Purpose
This form is used to report cases of the coronavirus, gathering essential information to aid in tracking and managing the spread of the virus.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your report location (e.g., workplace, community, etc.)
2. Enter the name and contact information of the person reporting the case
3. Select the type of case reported (e.g., confirmed, suspected, etc.)
4. Choose the type of location where the case was reported (e.g., office, school, etc.)
5. Select the subcategory of the location where the case was reported (e.g., office building, school campus, etc.)
6. Select the severity of the case reported (e.g., mild, severe, etc.)
7. Choose the reported user type (e.g., employee, visitor, etc.)
8. Select the source of the case reported (e.g., internal, external, etc.)

## Field-by-Field Explanation

* **Report Location** (`report_location`, text, optional): Enter the location where the case was reported (e.g., workplace, community, etc.). This is where the case occurred.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person reporting the case.
* **Case Reported** (`case_reported`, number, optional): Enter the number of cases reported.
* **Case Confirmed** (`case_confirmed`, number, optional): Enter the number of cases confirmed.
* **Workplace Location** (`workplace_location`, text, optional): Enter the location where the case was reported if applicable.
* **Contact Email** (`contact_email`, email, optional): Enter the email address of the person reporting the case.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person reporting the case.
* **Date Reported** (`date_reported`, date, optional): Enter the date when the case was reported.
* **Time Reported** (`time_reported`, time, optional): Enter the time when the case was reported.
* **Symptoms** (`symptoms`, text, optional): List any symptoms experienced by the person reporting the case.
* **Reported By** (`reported_by`, select_one, required): Select the type of user reporting the case (e.g., employee, visitor, etc.).
* **Workplace Size** (`workplace_size`, number, optional): Enter the size of the workplace or community where the case was reported.
* **Number of Employees** (`number_of_employees`, number, optional): Enter the number of employees in the workplace or community where the case was reported.
* **Case Type** (`case_type`, select_multiple, required): Select the type of case reported (e.g., confirmed, suspected, etc.).
* **Location Type** (`location_type`, select_multiple, required): Select the type of location where the case was reported (e.g., office, school, etc.).
* **Location Subcategory** (`location_subcategory`, select_multiple, required): Select the subcategory of the location where the case was reported (e.g., office building, school campus, etc.).
* **Case Severity** (`case_severity`, select_one, required): Select the severity of the case reported (e.g., mild, severe, etc.).
* **Reported By User** (`reported_by_user`, select_one, required): Select the type of user reporting the case (e.g., employee, visitor, etc.).
* **Case Source** (`case_source`, select_one, required): Select the source of the case reported (e.g., internal, external, etc.).
* **Workplace Address** (`workplace_address`, text, optional): Enter the address of the workplace where the case was reported if applicable.
* **Case Source** (`case_source`, select_one, required): Select the source of the case reported (e.g., internal, external, etc.).
* **Workplace Name** (`workplace_name`, text, optional): Enter the name of the workplace where the case was reported if applicable.
* **Location Details** (`location_details`, text, optional): Enter any additional details about the location where the case was reported.
* **Contact Name Other** (`contact_name_other`, text, optional): Enter the name of the person reporting the case if not using the provided contact name field.
* **Contact Email Other** (`contact_email_other`, text, optional): Enter the email address of the person reporting the case if not using the provided contact email field.
* **Contact Phone Other** (`contact_phone_other`, text, optional): Enter the phone number of the person reporting the case if not using the provided contact phone field.
