# Visual Cognitive Ability Assessment - Help Guide
## Purpose
The Visual Cognitive Ability Assessment form is designed to evaluate an individual's visual cognitive abilities, including visual processing, memory, learning, attention, and other related aspects. This form is intended to help assessors or clinicians understand a person's visual cognitive strengths and weaknesses.

## How To Complete This Form
To complete this form, follow these steps:

* Review the questions carefully and answer them honestly.
* For text fields, enter your response in the provided text boxes.
* For select_multiple fields, select all the options that apply to you.
* For select_one fields, choose the option that best describes your response.
* For number fields, enter a numerical value as prompted.

## Field-by-Field Explanation

* **General Info** (`general_info`): Enter any general information about yourself that may be relevant to the assessment.
* **Visual Processing** (`visual_processing`): Indicate if you have difficulty with visual processing. Select 'Yes' if you experience difficulties such as difficulty with recognizing patterns or difficulty with visualizing information.
* **Visual Memory** (`visual_memory`): Enter any information about your visual memory, such as difficulty with remembering visual details or visualizing mental images.
* **Visual Learning** (`visual_learning`): Indicate if you have difficulty with visual learning. Select 'Yes' if you experience difficulties such as difficulty with understanding visual instructions or difficulty with learning from visual aids.
* **Visual Maintenance** (`visual_maintenance`): Enter a numerical value indicating your visual maintenance skills, such as your ability to maintain visual focus or attention.
