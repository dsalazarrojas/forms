# Covid 19 Screening Survey And Waiver - Help Guide
## Purpose
The Covid 19 Screening Survey And Waiver form is designed to collect information related to COVID-19 screening and waiver, which will help healthcare providers make informed decisions about patient care.

## How To Complete This Form
Before starting the form, please ensure that you have read and understand the questions below. This form has multiple pages, each with its own set of questions. Please complete each page thoroughly and accurately to provide the necessary information.

## Field-by-Field Explanation
* **Introduction** (`introduction`, Note, Not Required): This page serves as an introduction to the form and provides some background information.
* **Patient Information** (`patient_information`, Text, Not Required):
	+ This field is for entering patient information.
* **Medical Conditions** (`medical_conditions`, Select Multiple, Not Required):
	+ This field is for selecting any pre-existing medical conditions.
	+ Please select all applicable conditions from the options provided.
* **Vaccination Status** (`vaccination_status`, Select One, Not Required):
	+ This field is for indicating vaccination status.
	+ Select the option that best describes the current vaccination status.
* **Vaccination Interest** (`vaccination_interest`, Select One, Not Required):
	+ This field is for indicating interest in vaccination.
	+ Select the option that best describes the interest in vaccination.
* **Emergency Contact** (`emergency_contact`, Select One, Not Required):
	+ This field is for selecting an emergency contact.
	+ Choose the person who will be contacted in case of an emergency.
* **Emergency Contact Relationship** (`emergency_contact_relationship`, Select Multiple, Not Required):
	+ This field is for indicating the relationship between the patient and the emergency contact.
	+ Select all applicable relationships.
* **Medical History** (`medical_history`, Select Multiple, Not Required):
	+ This field is for selecting medical history.
	+ Please choose all relevant medical history options.

This form is designed to be completed by patients or their representatives. Please ensure that the information is accurate and up-to-date. If you have any questions or concerns, please don't hesitate to reach out to your healthcare provider.
