# Premature Retinopathy Assessment Form - Help Guide
## Purpose
This form is used to assess and document a patient's premature retinopathy condition.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Medical History section with the patient's relevant medical information.
2. Select the appropriate options for the Maternal Data and Infant Data sections.
3. Enter the date of the eye exam results in the Date section.
4. Assess the patient's retinopathy condition in the Retinopathy Assessment section.
5. Write a treatment plan for the patient in the Treatment Plan section.
6. Provide your consent as a healthcare professional in the Consent section.
7. Add any additional submission information in the Submission Information section.

## Field-by-Field Explanation

* **Medical History (1)**: A text field to document the patient's medical history. Please provide a brief description of the patient's medical history.
* **Maternal Data (2)**: A select multiple field to ask if the patient's mother had any complications during pregnancy.
	+ Select 'Yes' if the patient's mother had any complications during pregnancy.
	+ Select 'No' otherwise.
* **Infant Data (3)**: A select multiple field to ask if the patient had any issues during development.
	+ Select 'Yes' if the patient had any issues during development.
	+ Select 'No' otherwise.
* **Eye Exam Results (4)**: A date field to document the date of the eye exam results.
* **Retinopathy Assessment (5)**: A select one field to assess the patient's retinopathy condition.
	+ Select 'Yes' if the patient has a severe retinopathy condition.
	+ Select 'No' if the patient's retinopathy condition is not severe.
* **Treatment Plan (6)**: A text field to document the patient's treatment plan.
* **Consent (7)**: A text field to document your consent as a healthcare professional.
* **Submission Information (8)**: A note field to add any additional submission information.

## Tips
* Please fill out the form accurately and thoroughly to ensure that the patient receives the best possible treatment.
* If you need to update or change any of the patient's data, refer back to the original form and fill it out again in its entirety.
