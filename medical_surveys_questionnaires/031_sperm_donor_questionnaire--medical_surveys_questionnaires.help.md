# Sperm Donor Questionnaire - Help Guide
## Purpose
This form is designed to collect information from individuals who are interested in or have experience with sperm donation. The form is used to gather details about the donor's medical history, contact information, and medical clearances, as well as any additional medical certifications or qualifications they may have.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and answer the questions honestly.
2. Select the correct answers from the options provided for each question.
3. Make sure to answer all required fields (marked as required).
4. If you have any medical conditions or certifications not listed, use the "Other (Specify)" option to provide more information.

## Field-by-Field Explanation
### 1. Sperm Donor Questionnaire
*   **Sperm Donor Questionnaire** (`select_one`, `title`): This is the main question for the form. Please select "Yes" if you are a sperm donor or have experience with sperm donation, or "No" if you are not.

### 2. Donor Id
*   **Donor Id** (`number`, `donor_id`): This field is for your identifier or ID number. Please enter a valid number if applicable.

### 3. Medical History
*   **Medical History** (`select_multiple`, `medical_history`): Please select all medical conditions that apply to you from the list provided. You can also specify any additional medical conditions not listed using the "Other (Specify): []" option.

### 4. Contact Info
*   **Contact Info** (`select_multiple`, `contact_info`): Please select all contact information you are willing to share (Phone, Email, or Other).

### 5. Medical Clearance
*   **Medical Clearance** (`select_one`, `medical_clearance`): Please select "Yes" if you have been medically cleared to be a sperm donor, or "No" if not.

### 6. Medical Certifications
*   **Medical Certifications** (`select_multiple`, `medical_certifications`): Please select all medical certifications you hold (Certified Doctor, Certified Nurse, or Other).

### 7. Donor Info
*   **Donor Info** (`text`, `donor_info`): This field is for any additional information about your experience as a sperm donor. Please enter your response in the text box.

### 8. Medical History Other
*   **Medical History Other** (`text`, `medical_history_other`): If you have any medical conditions not listed, please provide more information in this field.

### 9. Contact Info Other
*   **Contact Info Other** (`text`, `contact_info_other`): If you have any contact information not listed, please provide more information in this field.

### 10. Medical Clearance Other
*   **Medical Clearance Other** (`text`, `medical_clearance_other`): If you have any medical clearance information not listed, please provide more information in this field.

### 11. Medical Certifications Other
*   **Medical Certifications Other** (`text`, `medical_certifications_other`): If you have any medical certifications not listed, please provide more information in this field.

### 12. Medical Clearance 2
*   **Medical Clearance 2** (`select_multiple`, `medical_clearance_2`): Please select all medical clearances you have.

### 13. Medical Clearance 2 Other
*   **Medical Clearance 2 Other** (`text`, `medical_clearance_2_other`): If you have any medical clearance information not listed, please provide more information in this field.

### 14. Medical Certifications 2
*   **Medical Certifications 2** (`select_multiple`, `medical_certifications_2`): Please select all medical certifications you hold.

### 15. Medical Certifications 2 Other
*   **Medical Certifications 2 Other** (`text`, `medical_certifications_2_other`): If you have any medical certifications not listed, please provide more information in this field.

## Tips
*   Please answer all questions honestly and accurately.
*   Make sure to use the "Other (Specify)" options for any medical conditions, contact information, or medical certifications that are not listed.
*   If you are unsure about any question, please ask for clarification before submitting the form.
