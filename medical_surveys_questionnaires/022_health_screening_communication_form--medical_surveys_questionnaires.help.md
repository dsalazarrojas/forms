# Health Screening Communication Form - Help Guide
## Purpose
This form is used to collect information about a patient's screening status, vaccination status, and other relevant details after a screening process. It is intended for use by medical professionals to facilitate communication and record-keeping within a healthcare setting.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant answers to each question based on the patient's screening status.
2. Enter the actual test result values in the screening results field.
3. Provide a brief note or comment regarding the patient's contact information if applicable.
4. Enter any relevant medical notes about the patient.
5. Provide follow-up recommendations for the patient.
6. Enter any next steps or actions for the patient.
7. Select the type of screening performed (e.g., 'Yes' or 'No').
8. Date the screening form.

## Field-by-Field Explanation

* **Screening Questions** (`screening_questions`, `select_multiple`): Select the relevant answers based on the patient's screening status.
* **Status of Screening** (`screening_status`, `select_one`): Choose the current status of the screening process (Active or Inactive).
* **Screening Results** (`screening_results`, `select_one`): Enter the actual test result values.
* **Vaccination Status** (`vaccination_status`, `select_one`): Choose the current vaccination status (Active or Inactive).
* **Screening Comments** (`screening_comments`, `text`): Provide any additional comments or notes regarding the patient's contact information.
* **Contact** (`patient_contact`, `note`): Enter a brief note or comment regarding the patient's contact information.
* **Medical Notes** (`medical_notes`, `note`): Enter any relevant medical notes about the patient.
* **Follow Up Recommendations** (`follow_up_recommendations`, `text`): Provide follow-up recommendations for the patient.
* **Next Steps** (`next_steps`, `text`): Enter any next steps or actions for the patient.
* **Screening Type** (`screening_type`, `select_one`): Select the type of screening performed (e.g., 'Yes' or 'No').
* **Screening Form Date** (`screening_form_date`, `date`): Date the screening form.

Note: This help guide assumes the form will be used in a context where the patient's screening status and vaccination status can be accurately determined and recorded. If the form is being used in a context where this is not possible, additional instructions or clarifications may be necessary.
