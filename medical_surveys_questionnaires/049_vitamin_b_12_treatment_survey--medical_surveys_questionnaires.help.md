# Vitamin B12 Treatment Survey - Help Guide
## Purpose
This form is used to collect data on patient experiences and outcomes related to Vitamin B12 treatment.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the form title in the text field.
2. Select the category (not applicable in this form).
3. Enter a brief description of the patient's experience with the treatment.
4. Select any effective side effects (if applicable).
5. Select any ineffective side effects (if applicable).
6. Report the patient's treatment experience (if applicable).
7. Select any follow-up care required.
8. Select whether the patient has provided informed consent (if applicable).
9. Select any medical safety risks associated with the treatment (if applicable).
10. Enter the patient's medical conditions (if applicable).
11. Enter the medical professional's qualifications (if applicable).

## Field-by-Field Explanation
- **Form Title** (`form_id`, text, required): Enter the title of the form, which will be used as the title of the survey.
  - This field should be a brief and descriptive title of the form.
- **Category** (`category`, text, optional): Select a category for the form (not applicable in this form).
  - This field is not currently used in the form.
- **Description** (`description`, text, optional): Enter a brief description of the patient's experience with the treatment.
  - This field allows the patient to provide a description of their experience with the treatment.
- **Effective Side Effects** (`effective_side_effects`, select_one, optional): Select any effective side effects experienced by the patient.
  - Select one or more of the options provided to report any effective side effects.
- **Ineffective Side Effects** (`ineffective_side_effects`, select_multiple, optional): Select any ineffective side effects experienced by the patient.
  - Select one or more of the options provided to report any ineffective side effects.
- **Treatment Experience** (`treatment_experience`, select_one, optional): Report the patient's treatment experience (if applicable).
  - Select one or more of the options provided to report the patient's treatment experience.
- **Follow-up Care** (`follow_up_care`, select_multiple, optional): Select any follow-up care required for the patient.
  - Select one or more of the options provided to report any follow-up care required.
