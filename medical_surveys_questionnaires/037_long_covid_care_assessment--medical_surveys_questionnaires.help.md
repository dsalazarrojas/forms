# long_covid_care_assessment - Help Guide
## Purpose
This form is designed to help healthcare providers assess the needs and care requirements of individuals who have experienced long COVID.

## How To Complete This Form

1. Please answer the questions honestly and accurately to the best of your ability.
2. If you are unsure about any question, please do not hesitate to ask for clarification.
3. Complete all required fields, marked with an asterisk (\*).

## Field-by-Field Explanation

* **long_covid_care_needs** (Yes, No): This question asks whether the individual requires care or support due to long COVID. Please answer "Yes" if the individual has identified a need for care.
* **long_covid_care_providers** (Yes, No): This question asks whether the individual has a preferred care provider or has identified a need for a care provider. Please answer "Yes" if the individual has a preferred provider or needs a care provider.
* **long_covid_symptoms_duration** (Number): This question asks for the duration of the individual's long COVID symptoms. Please enter the number of days or weeks since the symptoms began.
* **long_covid_symptoms_description** (Text): This question asks for a description of the individual's symptoms. Please enter a brief description of the symptoms, including any frequency or severity.
* **long_covid_care_goals** (Text): This question asks about the individual's care goals and preferences. Please enter a brief description of the care goals and preferences.
* **long_covid_care_support_services** (Yes, No): This question asks whether the individual requires support services due to long COVID. Please answer "Yes" if the individual has identified a need for support services.
* **long_covid_symptoms_frequency** (Yes, No): This question asks about the frequency of the individual's symptoms. Please answer "Yes" if the symptoms occur frequently.
* **long_covid_care_referral** (Yes, No): This question asks whether the individual has been referred for care due to long COVID. Please answer "Yes" if the individual has been referred.
* **long_covid_care_additional_info** (Text): This question asks for any additional information about the individual's care needs. Please enter any relevant information.
* **long_covid_care_additional_comments** (Text): This question asks for any additional comments about the individual's care needs. Please enter any relevant comments.
* **long_covid_care_additional_notes** (Text): This question asks for any additional notes about the individual's care needs. Please enter any relevant notes.
* **long_covid_care_provider_specialty** (Yes, No): This question asks whether the individual's care provider has a specific specialty or expertise. Please answer "Yes" if the provider has a specialty.
* **long_covid_care_provider_location** (Text): This question asks for the location of the care provider. Please enter the location of the care provider.
* **long_covid_care_provider_phone** (Text): This question asks for the contact phone number of the care provider. Please enter the phone number of the care provider.
* **long_covid_care_provider_email** (Email): This question asks for the email address of the care provider. Please enter the email address of the care provider.
* **long_covid_care_provider_notes** (Text): This question asks for any additional notes about the care provider. Please enter any relevant notes.
* **long_covid_care_assessment_date** (Date): This question asks for the date of the care assessment. Please enter the date of the assessment.
* **long_covid_care_assessment_time** (Time): This question asks for the time of the care assessment. Please enter the time of the assessment.
* **long_covid_care_assessment_by** (Yes, No): This question asks whether the care assessment was completed by a healthcare professional. Please answer "Yes" if the assessment was completed.
* **long_covid_care_assessment_completed** (Yes, No): This question asks whether the care assessment was completed. Please answer "Yes" if the assessment was completed.

## Tips

* Please be honest and accurate when completing this form.
* If you are unsure about any question, please do not hesitate to ask for clarification.
* Complete all required fields to ensure that the individual's care needs are fully assessed.
