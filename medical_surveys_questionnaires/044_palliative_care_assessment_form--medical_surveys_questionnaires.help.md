# Palliative Care Assessment Form - Help Guide
## Purpose
This form is designed to gather information about patients' palliative care needs and circumstances. The purpose of this form is to assess the level of care required for patients who are nearing the end of their life or have a serious illness. The form collects data on various aspects of the patient's health, medical team, and care requirements.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each page carefully and answer all required questions.
2. Enter your response to each question in the designated fields.
3. If you are unsure about any question, refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **Home Address** (page 1): Enter the patient's home address.
* **Medical Survey** (page 1): Describe the patient's current medical condition and any recent medical events.
* **Care Type** (page 2): Select the type of palliative care the patient requires:
	+ Option 1: Terminal illness
	+ Option 2: Chronic condition
	+ Option 3: Other (please specify)
	+ Option 4: End-of-life care
	+ Option 5: Other (please specify)
* **Other Care** (page 2): If the patient requires care not listed above, describe the type of care.
* **Medical Condition** (page 3): Describe the patient's current medical condition.
* **Doctor** (page 3): Enter the name of the patient's doctor.
* **Nurse** (page 3): Enter the name of the patient's nurse.
* **Home Care Services** (page 4): Select any home care services the patient requires:
	+ Option 1: Nursing care
	+ Option 2: Home visits
	+ Option 3: Medical equipment
	+ Option 4: Transportation
	+ Option 5: Other (please specify)
* **Other Services** (page 4): If the patient requires services not listed above, describe the type of service.
* **Doctor Visit** (page 5): Enter the date of the last doctor visit.
* **Medication** (page 5): Enter any medications the patient is currently taking.
* **Medical Team** (page 5): Enter the names of any members of the patient's medical team.
* **Patient Status** (page 6): Select the patient's current status:
	+ Option 1: Stable
	+ Option 2: Unstable
	+ Option 3: Critical
	+ Option 4: Other (please specify)
	+ Option 5: Other (please specify)
* **Other Medical Info** (page 6): If there is any additional medical information, enter it here.
* **Care Location** (page 7): Enter the location where the patient receives care.
* **Patient Family** (page 7): Enter any relevant information about the patient's family.
* **Medical History** (page 8): Enter the patient's medical history.
* **Patient Status 2** (page 8): Select the patient's current status:
	+ Option 1: Stable
	+ Option 2: Unstable
	+ Option 3: Critical
	+ Option 4: Other (please specify)
	+ Option 5: Other (please specify)
* **Medical Team Members** (page 8): Enter any relevant information about the patient's medical team members.
* **Doctor Visit Frequency** (page 9): Enter the frequency of the patient's doctor visits.
* **Patient Medication** (page 9): Enter any medications the patient is currently taking.
* **Medical History 2** (page 9): Enter the patient's medical history.
* **Patient Status 3** (page 10): Select the patient's current status:
	+ Option 1: Stable
	+ Option 2: Unstable
	+ Option 3: Critical
	+ Option 4: Other (please specify)
	+ Option 5: Other (please specify)
* **Hospitalization** (page 11): Enter any hospitalization information.
* **Medical History 3** (page 11): Enter the patient's medical history.

## Tips

* Please answer all questions honestly and accurately.
* If you are unsure about any question, refer to this guide for clarification.
* If you have any difficulty completing this form, contact the palliative care team for assistance.
