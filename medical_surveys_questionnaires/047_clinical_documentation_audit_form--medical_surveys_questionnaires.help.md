# Clinical Documentation Audit Form - Help Guide
## Purpose
This form is designed to evaluate the clinical documentation of patient records. It assesses the accuracy, completeness, and timeliness of documentation, as well as any compliance issues or areas for improvement. The form is used to identify strengths and weaknesses of the documentation process and provide recommendations for improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields:
	* Audit Date
	* Auditor Name
	* Facility Name
	* Department Audited
	* Medical Record Number (MRN)
	* Provider Name
	* Date of Record
	* History of Present Illness documented (select from "Not documented", "Incomplete", "Complete", or "Comprehensive")
	* Review of Systems documented (select from "Not documented", "Incomplete", "Complete", or "Comprehensive")
	* Physical Examination documented (select from "Not documented", "Incomplete", "Complete", or "Comprehensive")
	* Assessment and Plan documented (select from "Not documented", "Incomplete", "Complete", or "Comprehensive")
	* Diagnostic and procedure coding accuracy (select from "Multiple errors", "Some errors", "Mostly accurate", or "Fully accurate")
	* Documentation accuracy (select from "Inaccurate", "Mostly accurate", "Accurate", or "Highly accurate")
	* Clarity of documentation (select from "Unclear", "Somewhat unclear", "Clear", or "Very clear")
	* Organization and structure (select from "Disorganized", "Somewhat organized", "Well organized", or "Excellently organized")
	* Documentation timeliness (select from "Late", "Delayed", "Timely", or "Immediate")
2. Answer the optional fields:
	* Compliance violations noted
	* Areas for improvement

## Field-by-Field Explanation
### Audit Information
* **-- Audit Information --**: This section is a brief introduction to the audit.
* **Audit Date**: The date of the audit.
* **Auditor Name**: The name of the person performing the audit.
* **Facility Name**: The name of the facility being audited.
* **Department Audited**: The department being audited (e.g. Emergency Department, Primary Care, etc.).
### Record Information
* **Medical Record Number (MRN)**: The unique identifier for the patient's medical record.
* **Provider Name**: The name of the healthcare provider who documented the patient's record.
* **Date of Record**: The date the medical record was created or last updated.
### Documentation Completeness
* **History of Present Illness documented**: This question assesses the completeness of the patient's history of present illness in the medical record.
*   Select "Not documented" if the history was not documented at all.
*   Select "Incomplete" if the history was only partially documented.
*   Select "Complete" if the entire history was documented.
*   Select "Comprehensive" if the history was well-structured and detailed.
* **Review of Systems documented**: This question assesses the completeness of the patient's review of systems in the medical record.
*   Select "Not documented" if the review was not documented at all.
*   Select "Incomplete" if the review was only partially documented.
*   Select "Complete" if the entire review was documented.
*   Select "Comprehensive" if the review was well-structured and detailed.
* **Physical Examination documented**: This question assesses the completeness of the patient's physical examination in the medical record.
*   Select "Not documented" if the examination was not documented at all.
*   Select "Incomplete" if the examination was only partially documented.
*   Select "Complete" if the entire examination was documented.
*   Select "Comprehensive" if the examination was well-structured and detailed.
* **Assessment and Plan documented**: This question assesses the completeness of the patient's assessment and plan in the medical record.
*   Select "Not documented" if the assessment and plan were not documented at all.
*   Select "Incomplete" if the assessment and plan were only partially documented.
*   Select "Complete" if the entire assessment and plan were documented.
*   Select "Comprehensive" if the assessment and plan were well-structured and detailed.
### Documentation Quality
* **Documentation accuracy**: This question assesses the accuracy of the medical record documentation.
*   Select "Inaccurate" if the documentation contained errors or inaccuracies.
*   Select "Mostly accurate" if the majority of the documentation was accurate but some errors were found.
*   Select "Accurate" if the documentation was largely accurate.
*   Select "Highly accurate" if the documentation was almost entirely accurate.
* **Clarity of documentation**: This question assesses the clarity of the medical record documentation.
*   Select "Unclear" if the documentation was confusing or difficult to understand.
*   Select "Somewhat unclear" if the documentation was somewhat clear but could be improved.
*   Select "Clear" if the documentation was easy to understand.
*   Select "Very clear" if the documentation was well-structured and easy to understand.
* **Organization and structure**: This question assesses the organization and structure of the medical record documentation.
*   Select "Disorganized" if the documentation was poorly organized or difficult to follow.
*   Select "Somewhat organized" if the documentation was somewhat organized but could be improved.
*   Select "Well organized" if the documentation was well-structured and easy to follow.
*   Select "Excellently organized" if the documentation was extremely well-organized and easy to follow.
* **Documentation timeliness**: This question assesses the timeliness of the medical record documentation.
*   Select "Late" if the documentation was delayed or not up-to-date.
*   Select "Delayed" if the documentation was not timely but not late.
*   Select "Timely" if the documentation was completed on time.
*   Select "Immediate" if the documentation was completed as soon as possible.
### Compliance Issues
* **Compliance violations noted**: List any compliance issues or violations found during the audit.
### Recommendations
* **Areas for improvement**: List any areas where the documentation process could be improved.
* **Documentation strengths**: List any strengths or areas of excellent documentation practices.
* **Diagnostic and procedure coding accuracy**: This question assesses the accuracy of diagnostic and procedure coding in the medical record.
*   Select "Multiple errors" if the coding contained multiple errors.
*   Select "Some errors" if the coding contained some errors.
*   Select "Mostly accurate" if the majority of the coding was accurate.
*   Select "Fully accurate" if the coding was almost entirely accurate.
