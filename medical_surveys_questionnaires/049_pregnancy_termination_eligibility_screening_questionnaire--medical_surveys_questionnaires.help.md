# Pregnancy Termination Eligibility Screening Questionnaire - Help Guide

## Purpose
This form is intended to gather information about your medical history, social determinants, current medications, medical providers, and medical conditions to determine your eligibility for certain medical treatments or procedures related to pregnancy termination.

## How To Complete This Form

1. Carefully read the form instructions and questions.
2. Answer each question truthfully and thoroughly.
3. Select the correct options from the provided choices.
4. If you have any additional comments or questions, use the "Medical History Notes" field at the end of the form.

## Field-by-Field Explanation

* **Introduction** (`Introduction`, `note`, not required): This section provides an overview of the form's purpose and importance of completing it accurately.
* **Medical History** (`Medical History`, `select_multiple`, not required):
	+ **High Blood Pressure**: Select this option if you have been diagnosed with high blood pressure.
	+ **Diabetes**: Select this option if you have been diagnosed with diabetes.
	+ **Heart Disease**: Select this option if you have been diagnosed with heart disease.
	+ **Kidney Disease**: Select this option if you have been diagnosed with kidney disease.
	+ **Option 5**: Select this option if you have other medical conditions not listed.
* **Social Determinants** (`Social Determinants`, `text`, not required): This field is for you to describe the social factors that may impact your health or pregnancy termination eligibility.
* **Family History** (`Family History`, `select_one`, not required):
	+ **High Blood Pressure**: Select this option if a family member has high blood pressure.
	+ **Diabetes**: Select this option if a family member has diabetes.
	+ **Cancer**: Select this option if a family member has cancer.
	+ **Other**: Select this option if a family member has other medical conditions not listed.
* **Current Medication** (`Current Medication`, `text`, not required): List your current medications and dosages in this field.
* **Medical Provider** (`Medical Provider`, `select_multiple`, not required):
	+ **Family Doctor**: Select this option if your primary medical provider is a family doctor.
	+ **Specialist**: Select this option if your primary medical provider is a specialist.
	+ **Other**: Select this option if your primary medical provider is not listed.
* **Medical History Condition** (`Medical History Condition`, `text`, not required): List all medical conditions you have or have had in the past.
* **Medical History Description** (`Medical History Description`, `text`, not required): Describe each medical condition and treatment details in this field.
* **Medical Provider Contact** (`Medical Provider Contact`, `select_multiple`, not required):
	+ **Family Doctor**: Select this option if you have contact information for your family doctor.
	+ **Specialist**: Select this option if you have contact information for a specialist.
	+ **Other**: Select this option if you have contact information for another medical provider.
* **Medical Provider Address** (`Medical Provider Address`, `select_multiple`, not required):
	+ **Address 1**: Select this option if your medical provider's address is Address 1.
	+ **Address 2**: Select this option if your medical provider's address is Address 2.
	+ **Address 3**: Select this option if your medical provider's address is Address 3.
	+ **Other**: Select this option if your medical provider's address is not listed.
* **Medical History Notes** (`Medical History Notes`, `note`, not required): Use this field to add any additional comments or questions you have about your medical history.

## Tips

* Be honest and thorough when answering each question.
* If you're unsure about a question, ask your medical provider for guidance.
* This form is for informational purposes only and does not replace a medical consultation or diagnosis.
