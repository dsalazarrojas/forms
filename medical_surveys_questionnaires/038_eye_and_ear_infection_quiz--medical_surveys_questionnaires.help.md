# Eye And Ear Infection Quiz - Help Guide
## Purpose
This form is designed to help identify potential ear and ear related issues you are experiencing. Please answer the questions thoroughly and honestly to help us better understand your situation.

## How To Complete This Form
To complete this form, please answer each question on each page as accurately as possible. You can select all applicable options from the dropdown menus. If you need more space for a field, you can use the "Additional Information" section at the end of each page.

## Field-by-Field Explanation

* **How long have you been experiencing symptoms?** (`first_page`, `text`, required)
	+ Please answer this question as specifically as you can, including approximate dates and duration of symptoms.
* **Symptoms** (`first_page_symptoms`, `select_multiple`, required)
	+ Choose all the symptoms that you are experiencing from the list.
* **Additional symptoms** (`first_page_additional_symptoms`, `note`, optional)
	+ If you have any additional symptoms not listed, please describe them here.
* **Ear infection symptoms** (`ear_infection_symptoms`, `number`, required)
	+ Please select the number of ear infection symptoms you are experiencing.
* **Have you visited a doctor for any of these issues?** (`doctor_visits`, `select_one`, required)
	+ If you have visited a doctor, select "Yes" and describe the visit in the "Medication Details" field below.
* **Have you been taking any medications for these symptoms?** (`ear_infection_medication`, `select_one`, required)
	+ If you have been taking medication, select "Yes" and describe the medication in the "Medication Details" field below.
* **Please provide details about the medication(s) you are taking** (`medication_details`, `text`, required)
	+ Describe the medication(s) you are taking, including dosage and frequency.
* **Have you experienced any of the following?** (`second_page`, `select_multiple`, required)
	+ Choose all the symptoms you are experiencing from the list.
* **Additional information** (`additional_info`, `note`, optional)
	+ If you have any additional information related to your symptoms or condition, please describe it here.
* **Have you received treatment for any of these ear infections?** (`ear_infection_treatment`, `select_multiple`, required)
	+ If you have received treatment, select all the treatment options you have received.
* **Please provide details about treatment received** (`treatment_details`, `text`, required)
	+ Describe the treatment you have received, including any medications or procedures.
* **Have you had any previous medical conditions?** (`previous_medical_conditions`, `select_one`, required)
	+ If you have had any previous medical conditions, select "Yes" and describe them in the "Previous Medical Conditions Details" field below.
* **Please provide details about previous medical conditions** (`previous_medical_conditions_details`, `text`, required)
	+ Describe your previous medical conditions, including any treatments or medications.
* **Additional questions** (`additional_questions`, `select_one`, optional)
	+ If you have any additional questions or concerns, select "Yes" and describe them below.
* **Have you had a flu vaccine recently?** (`recent_vaccination`, `select_one`, optional)
	+ If you have had a flu vaccine recently, select "Yes".
* **Have you taken any medication during the past 2 weeks for symptoms?** (`medication_exposure`, `select_one`, optional)
	+ If you have taken any medication, select "Yes".
* **Have you been tested for allergies or intolerances recently?** (`allergies_or_intolerances`, `select_one`, optional)
	+ If you have been tested for allergies or intolerances, select "Yes".
* **Have you had any recent travel history?** (`travel_history`, `select_one`, optional)
	+ If you have had any recent travel history, select "Yes".
* **Have you had any recent exposure to pets or animals?** (`exposure_to_animals`, `select_one`, optional)
	+ If you have had any recent exposure to pets or animals, select "Yes".
* **Have you had any recent exposure to chemicals or toxins?** (`exposure_to_chemicals`, `select_one`, optional)
	+ If you have had any recent exposure to chemicals or toxins, select "Yes".
* **Have you had any recent exposure to smoke or pollution?** (`exposure_to_pollutants`, `select_one`, optional)
	+ If you have had any recent exposure to smoke or pollution, select "Yes".
* **Have you had any recent exposure to mold or fungi?** (`exposure_to_mold`, `select_one`, optional)
	+ If you have had any recent exposure to mold or fungi, select "Yes".
* **Have you had any recent exposure to dust?** (`exposure_to_dust`, `select_one`, optional)
	+ If you have had any recent exposure to dust, select "Yes".
* **Have you had any recent exposure to viruses?** (`exposure_to_viruses`, `select_one`, optional)
	+ If you have had any recent exposure to viruses, select "Yes".
