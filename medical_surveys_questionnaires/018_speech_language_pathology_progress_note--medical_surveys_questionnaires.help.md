# Speech/Language Pathology Progress Note - Help Guide
## Purpose
This form is used to document progress and notes from speech and language pathology sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's name in the "Client Name" field.
2. Select the date of the session using the calendar icon.
3. Enter the therapist's name in the "Therapist Name" field.
4. Enter the client's ID number in the "Client ID" field.
5. Write a brief summary of the session in the "Session Notes" field.
6. Select the relevant diagnosis from the "Diagnosis" dropdown list.
7. Enter the client's current speech level in the "Current Level" field, selecting all applicable options.
8. Set the target date for achieving the speech goal in the "Speech Goal Target Date" field.
9. Enter a brief description of the speech goal in the "Speech Goal" field.

## Field-by-Field Explanation

* **Client Name** (Text, Required: False): Enter the client's name as per the client's preference or as per the facility's documentation policy.
* **Date Of Session** (Date, Required: False): Enter the date of the session using the calendar icon to select the date.
* **Therapist Name** (Text, Required: False): Enter the name of the SLP who conducted the session.
* **Client ID** (Number, Required: False): Enter the client's ID number as per the facility's documentation policy.
* **Session Notes** (Note, Required: False): Write a brief summary of what happened during the session, including any relevant observations, interventions, and outcomes.
* **Diagnosis** (Select One, Required: False): Select the relevant diagnosis from the dropdown list:
	+ Normal: No speech or language disorders were observed.
	+ Delayed speech development: The client exhibits delayed speech development.
	+ Language disorder: The client has a language disorder.
	+ Speech impairment: The client has a speech impairment.
	+ Other: Select this option if the client's diagnosis is not listed above.
* **Speech Goal** (Text, Required: False): Enter a brief description of the speech goal or area of focus for the client.
* **Current Level** (Select Multiple, Required: False): Select the relevant level from the dropdown list:
	+ None: The client's speech level is unknown or not applicable.
	+ Emerging: The client is emerging or just beginning to exhibit speech skills.
	+ Developing: The client is developing speech skills but requires further work.
	+ Proficient: The client's speech skills are proficient but may require maintenance.
	+ Fluency: The client's speech is fluent.
	+ Articulation: The client's articulation is clear and accurate.
	+ Other: Select this option if the client's current level does not fit the above categories.
* **Speech Goal Target Date** (Date, Required: False): Enter the target date for achieving the speech goal.
	+ Note: This field is used to track progress towards the speech goal.
* **Tips**

+ Make sure to accurately document the client's name and ID to ensure accurate tracking and billing.
+ Use the "Session Notes" field to provide a concise and detailed summary of the session.
+ Select "Other" for diagnosis if the client's condition is not listed above.
+ Use "None" for current level if the client's speech level is unknown or not applicable.
+ Use the "Articulation" option for current level if the client has difficulty articulating words or sounds.
