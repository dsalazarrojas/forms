# NDIS Access Request Form - Help Guide
## Purpose
The NDIS Access Request Form is used by eligible individuals to request access to National Disability Insurance services.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have read and understood the form's purpose and requirements.
2. Fill out the form accurately and thoroughly.
3. Check for any existing requests before submitting the form to avoid duplication.

## Field-by-Field Explanation
* **User Information** (`user_info`, text, optional): This section is used to capture your personal details, such as name, address, and other relevant information. Please provide your name and any other relevant information as required.
* **Service Information** (`service_info`, text, optional): In this section, describe the specific NDIS service you are requesting access to. Please provide a clear and concise description of the service you require.
* **Email** (`user_email`, email, optional): If you have an email address, please provide it so that we can contact you regarding your request. Please ensure the email address is correctly formatted (e.g., example@example.com).
* **Phone** (`user_phone`, text, optional): If you have a phone number, please provide it so that we can contact you regarding your request. Please ensure the phone number is correctly formatted (e.g., 01234 567890).
