# Bristol Stool Assessment Form - Help Guide

## Purpose
This form is designed to assess the Bristol Stool Scale (BSS) for patients, which is a standardized tool used to evaluate the quality of stool and identify potential gastrointestinal issues.

## How To Complete This Form
To complete this form, follow these steps:

* Enter the patient's full name in the field "Patient Name".
* Enter the patient's identification number or medical record number in the field "Patient ID or Medical Record Number".
* Select the patient's date of birth from the calendar.
* Choose the patient's gender from the dropdown list.
* Select the date of the assessment from the calendar.
* Choose the corresponding Bristol Stool Scale type for the patient's stool from the dropdown list, using the following descriptions:
	+ Type 1 - Separate hard lumps
	+ Type 2 - Lumpy sausage shape
	+ Type 3 - Sausage with cracks
	+ Type 4 - Smooth soft sausage
	+ Type 5 - Soft blobs with clear edges
	+ Type 6 - Fluffy ragged pieces
	+ Type 7 - Watery no solid pieces
* Describe the consistency of the patient's stool in the "Consistency Description" field.
* Select the observed stool color from the dropdown list:
	+ Brown
	+ Light Brown
	+ Dark Brown
	+ Black
	+ Red
	+ Green
	+ Yellow
	+ Clay Colored
* Describe any notable odor characteristics in the "Odor Description" field.
* Indicate if blood is visible in the "Presence of Blood" field:
	+ None
	+ Bright Red Blood
	+ Dark Blood
	+ Occult Blood
* Indicate if mucus is present in the "Presence of Mucus" field:
	+ None
	+ Small Amount
	+ Moderate Amount
	+ Large Amount
* Select how often bowel movements occur in the "Bowel Movement Frequency" field:
	+ Multiple times per day
	+ Once daily
	+ Every 2-3 days
	+ Less than 3 times per week
* Select all associated symptoms in the "Associated Symptoms" field:
	+ Abdominal Pain
	+ Bloating
	+ Nausea
	+ Vomiting
	+ Constipation
	+ Diarrhea
	+ Urgency
	+ Incontinence
* Describe any relevant dietary factors that may affect bowel function in the "Relevant Dietary Factors" field.
* List any medications that may affect bowel function in the "Medications" field.
* Provide clinical interpretation of findings in the "Clinical Interpretation" field, using the following options:
	+ Normal
	+ Constipation Indicated
	+ Diarrhea Indicated
	+ Possible Malabsorption
	+ Requires Further Investigation
* Describe recommended follow-up or treatment in the "Recommended Actions" field.
* Enter the name of the healthcare provider who conducted the assessment in the "Examiner Name" field.
* Enter any additional clinical notes in the "Additional Clinical Notes" field.

* **Patient Name**: Enter the full name of the patient.

* **Bristol Stool Type**: Choose the corresponding Bristol Stool Scale type for the patient's stool.
* **Consistency Description**: Describe the consistency of the patient's stool.
* **Stool Color**: Select the observed stool color.
* **Odor Description**: Describe any notable odor characteristics.
* **Presence of Blood**: Indicate if blood is visible.
* **Presence of Mucus**: Indicate if mucus is present.
* **Bowel Movement Frequency**: Select how often bowel movements occur.
* **Associated Symptoms**: Select all associated symptoms.
* **Relevant Dietary Factors**: Describe any relevant dietary factors that may affect bowel function.
* **Medications**: List any medications that may affect bowel function.
* **Clinical Interpretation**: Provide clinical interpretation of findings.
* **Recommended Actions**: Describe recommended follow-up or treatment.
* **Examiner Name**: Enter the name of the healthcare provider who conducted the assessment.
* **Additional Clinical Notes**: Enter any additional clinical notes.

## Tips

* Ensure you have all necessary information before completing this form.
* Be as specific as possible when describing the patient's symptoms and stool characteristics.
* Use the clinical interpretation options to guide your assessment and recommended actions.
* Enter all required fields to ensure a complete and accurate assessment.
* Review and update any previous assessments to track changes in the patient's condition.
