# Shelter Verification Form - Help Guide
## Purpose
The Shelter Verification Form is used by social workers to verify the information of a shelter. It helps in confirming the existence of a shelter, the services it has provided, and the contact details of the shelter.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the client information in the first page.
	* Please provide the correct name of the client (Client Name).
2. Enter the shelter's information in the second page.
	* Please select whether the shelter provides the services (Services Provided).
	* Please select whether the shelter requests the services (Services Requested).
3. Confirm the case manager and shelter manager's details in the third page.
	* Please enter the name of the case manager.
	* Please enter the name of the shelter manager.
4. Fill out the shelter's address and contact details in the fourth page.
	* Please select whether the shelter has an address (Shelter Address).
	* Please select whether the shelter has contact (Shelter Contact).
5. Add any additional services notes in the last page.
	* Please provide any additional comments or information about the services provided by the shelter.

## Field-by-Field Explanation

* **Client Info (Client Name)** (`text`, required/optional): Enter the correct name of the client to be verified.
* **Shelter Info (Shelter Info)** (`text`, required/optional): Enter a brief description of the shelter's information.
* **Services Provided** (`select_multiple`, optional): Select whether the shelter provides the services (Yes/No).
* **Services Requested** (`select_multiple`, optional): Select whether the shelter requests the services (Yes/No).
* **Case Manager** (`text`, optional): Enter the name of the case manager for the shelter.
* **Shelter Manager** (`text`, optional): Enter the name of the shelter manager.
* **Shelter Address** (`select_multiple`, optional): Select whether the shelter has an address (Yes/No).
* **Shelter Contact** (`select_multiple`, optional): Select whether the shelter has contact (Yes/No).
* **Services Notes** (`text`, optional): Enter any additional comments or information about the services provided by the shelter.
* **Services Notes** (`text`, required/optional): Please provide any additional information about the shelter.
