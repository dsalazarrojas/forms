# COVID 19 Essentials Delivery For The Elderly - Help Guide
## Purpose
This form is designed to collect information about an elderly individual's needs and preferences for COVID-19 essentials delivery.

## How To Complete This Form
1. Answer each field accurately and thoroughly.
2. Make sure to provide clear and concise information.
3. Use the provided formatting instructions for each field.
4. Double-check your submission before submitting it.

## Field-by-Field Explanation

* **Recipient Full Name** (`recipient_name`, text, required): Please enter the full name of the elderly individual.
* **Phone Number** (`recipient_phone`, text, required): Enter the phone number of the elderly individual.
* **Email Address** (`recipient_email`, email, optional): If the elderly individual has an email address, please enter it. This will help us contact them for delivery confirmation and any updates.
* **Delivery Address** (`address`, text, required): Enter the delivery address where the elderly individual resides.
* **City** (`city`, text, required): Enter the city where the elderly individual resides.
* **State and Zip Code** (`state_zip`, text, required): Enter the state and zip code where the elderly individual resides.
* **Age 65 or older** (`age_confirmation`, select_one, required): Please confirm if the elderly individual is 65 or older.
* **Number of household members** (`household_members`, number, required): Please enter the number of household members.
* **Emergency Contact Name** (`contact_person`, text, required): Enter the name of the emergency contact person.
* **Emergency Contact Phone** (`contact_phone`, text, required): Enter the phone number of the emergency contact person.
* **Types of essentials needed** (`essentials_type`, select_multiple, required): Select all the types of essentials needed, such as groceries, medications, medical supplies, etc.
* **Specific grocery items needed** (`grocery_items`, text, optional): If there are any specific grocery items required, please list them.
* **Medications or medical supplies** (`medications_needed`, text, optional): If there are any medications or medical supplies required, please list them.
* **Dietary restrictions or allergies** (`dietary_restrictions`, text, optional): If the elderly individual has any dietary restrictions or allergies, please list them.
* **Any COVID-19 symptoms or health concerns** (`health_concerns`, select_one, required): Please confirm if the elderly individual has any COVID-19 symptoms or health concerns.
* **Describe health concerns if applicable** (`concern_details`, text, optional): If the elderly individual has any health concerns, please describe them.
* **Vaccination Status** (`vaccination_status`, select_one, required): Please select the vaccination status of the elderly individual.
* **Preferred Delivery Method** (`delivery_method`, select_one, required): Select the preferred delivery method, such as contactless doorstep delivery, hand-to-hand delivery, etc.
* **Preferred Delivery Date** (`delivery_date`, date, required): Select the preferred delivery date.
* **Preferred Delivery Time** (`delivery_time`, time, required): Select the preferred delivery time.
* **Special Instructions for Delivery** (`special_instructions`, text, optional): If there are any special instructions for delivery, please provide them.
