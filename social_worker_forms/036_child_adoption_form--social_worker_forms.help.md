# Child Adoption Form - Help Guide
## Purpose
The Child Adoption Form is used to document the finalization of child adoption proceedings. This form captures information about the adoptive parents, the child, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure all required fields are filled out.
2. Enter the adoption case number.
3. Enter the date of form completion.
4. Enter the name and date of birth of the first adoptive parent.
5. Enter the address of the first adoptive parent.
6. Enter the name and date of birth of the second adoptive parent (if applicable).
7. Enter the address of the second adoptive parent (if applicable).
8. Enter the child's legal name (if changed).
9. Enter the child's birth date.
10. Select the child's gender.
11. Enter the child's place of birth.
12. Enter the name of the biological parent 1 (if applicable).
13. Enter the name of the biological parent 2 (if applicable).
14. Confirm if consent from biological parents has been obtained.
15. Enter the date the child was placed with the adoptive parents.
16. Confirm if prior custody or guardianship was established.
17. Enter the name of the adoption agency or organization (if applicable).
18. Enter the name of the social worker.
19. Confirm if the court has approved the adoption.
20. Enter the date of adoption finalization.
21. Confirm if the child has all inheritance and succession rights.
22. Confirm if post-adoption support services were discussed.
23. Confirm if the adoption records should be sealed.

## Field-by-Field Explanation
- **Adoption case number**: Enter the unique identifier for the adoption case. This is a required field.
- **Form completion date**: Enter the date this form was completed. This is a required field.
- **First adoptive parent name**: Enter the name of the first adoptive parent. This is a required field.
- **First adoptive parent DOB**: Enter the date of birth of the first adoptive parent. This is a required field.
- **First adoptive parent address**: Enter the address of the first adoptive parent. This is a required field.
- **Second adoptive parent name**: Enter the name of the second adoptive parent (if applicable). This is an optional field.
- **Second adoptive parent DOB**: Enter the date of birth of the second adoptive parent (if applicable). This is an optional field.
- **Second adoptive parent address**: Enter the address of the second adoptive parent (if applicable). This is an optional field.
- **Child's legal name**: Enter the child's legal name (if changed). This is a required field.
- **Child's date of birth**: Enter the child's date of birth. This is a required field.
- **Child's gender**: Select the child's gender. This is a required field.
- **Child's place of birth**: Enter the child's place of birth. This is a required field.
- **Biological parent 1 name**: Enter the name of the biological parent 1 (if applicable). This is an optional field.
- **Biological parent 2 name**: Enter the name of the biological parent 2 (if applicable). This is an optional field.
- **Consent from biological parents obtained**: Confirm if consent from biological parents has been obtained. This is a required field.
- **Date child placed with adoptive parents**: Enter the date the child was placed with the adoptive parents. This is a required field.
- **Prior custody or guardianship**: Confirm if prior custody or guardianship was established. This is an optional field.
- **Adoption agency or organization**: Enter the name of the adoption agency or organization (if applicable). This is an optional field.
- **Social worker name**: Enter the name of the social worker. This is a required field.
- **Has court approved the adoption**: Confirm if the court has approved the adoption. This is a required field.
- **Adoption finalization date**: Enter the date of adoption finalization. This is a required field.
- **Child has all inheritance and succession rights**: Confirm if the child has all inheritance and succession rights. This is a required field.
