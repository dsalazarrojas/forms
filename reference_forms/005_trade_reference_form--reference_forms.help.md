# Trade Reference Form - Help Guide
## Purpose
The Trade Reference Form is used to collect and store detailed information about a trade, including its name, description, and reference details. This form helps to create a comprehensive record of the trade, ensuring that all necessary information is accurate and up-to-date.

## How To Complete This Form
1. To complete this form, start by selecting the "Trade" field and enter the name of the trade you want to create a record for.
2. In the "Reference" field, enter any relevant details about the trade.
3. If you have a Trade ID or Reference ID, please enter it in the corresponding fields.
4. Provide a brief description of the trade in the "Trade Description" field.
5. Enter any relevant details about the reference in the "Reference Description" field.
6. Select the "Publish Date" field to enter the date you want the trade to be published.
7. Once you have filled out all the fields, review your entries to ensure accuracy and completeness.
8. Click the submit button to create a new record of the trade.

## Field-by-Field Explanation
* **Trade** (text): Enter the name of the trade you want to create a record for.
* **Trade Description** (text): Provide a brief description of the trade.
* **Trade ID** (number): Enter the Trade ID (if applicable).
* **Reference** (text): Enter any relevant details about the trade.
* **Reference Description** (text): Enter any relevant details about the reference.
* **Reference ID** (number): Enter the Reference ID (if applicable).
* **Reference Name** (text): Enter the name of the reference.
* **Publish Date** (date): Select the date you want the trade to be published.
* **Trade Name** (text): Enter the name of the trade (this field can be used if you don't have a Trade ID).
* **Trade ID** (number): Enter the Trade ID (if applicable).
* **Reference ID** (number): Enter the Reference ID (if applicable).

## Tips
* If you are unsure about any of the fields, you can always contact your administrator for clarification.
* Make sure to review your entries carefully before submitting the form to avoid errors and inaccuracies in the data entered.
* If you need to create multiple trades, you can fill out this form multiple times, but be aware of potential duplication of records.
* If you find a trade already exists, please do not create a new record for the same trade.
