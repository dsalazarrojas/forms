# Employee Reference Request Form - Help Guide
## Purpose
The Employee Reference Request Form is designed to collect detailed information about an employee's work history, circumstances, and circumstances surrounding their employment. This form is intended for use by HR or other personnel to make informed decisions about employees.

## How To Complete This Form
To fill out the form, simply complete each field with accurate and clear information. Ensure you've reviewed the form carefully before submitting it, especially if submitting multiple requests for the same employee.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, optional): Provide the name of the employee in question.
* **Job Title** (`job_title`, text, optional): If applicable, provide the job title of the employee during their tenure.
* **Start Date** (`start_date`, date, optional): Enter the start date of the employee's tenure with the company.
* **End Date** (`end_date`, date, optional): Enter the end date of the employee's tenure with the company.
* **Company Name** (`company_name`, text, optional): The name of the company the employee was employed by.
* **Contact Number** (`contact_number`, text, optional): Provide a valid contact number for the employee or their representative.
* **Email** (`email`, email, optional): Enter the employee's or their representative's email address.
* **Reason for Request** (`reason_for_request`, text, optional): Briefly describe the reason for the reference request.
* **Employee Status** (`employee_status`, text, optional): Provide a brief description of the employee's current status (e.g. 'Employed', 'Terminated', 'Resigned', etc.).
* **Employee Termination Date** (`employee_termination_date`, date, optional): If applicable, enter the date the employee's employment was terminated.
* **Supervisor Status** (`supervisor_status`, text, optional): Describe the current status of the employee's supervisor.
* **Supervisor Name** (`supervisor_name`, text, optional): If applicable, provide the name of the employee's supervisor.
* **Supervisor Title** (`supervisor_title`, text, optional): If applicable, enter the title of the employee's supervisor.
* **Contact Details** (`contact_details`, text, optional): Provide any additional contact details for the employee or their representative.

Note: All fields are optional unless specified as required.
