# Reference Check Authorization - Help Guide

## Purpose
This form is used for reference checks to gather information about a candidate's professional relationships.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the reference name if it is different from the applicant's name.
2. Enter the reference email address if it is available.
3. Enter the reference phone number if it is available.
4. Select the type of relationship you have with the reference.
5. Enter the length of time you have known the reference.
6. Enter the time you have known the reference.
7. If necessary, enter any additional comments or notes about the reference.

## Field-by-Field Explanation

* **Reference Name** (`reference_name`, text, optional): Enter the name of the reference if it is different from the applicant's name.
* **Reference Email** (`reference_email`, email, optional): Enter the reference email address if it is available.
* **Reference Phone** (`reference_phone`, text, optional): Enter the reference phone number if it is available.
* **Relationship** (`reference_relationship`, select_one, optional): Select the type of relationship you have with the reference:
	+ Colleague
	+ Supervisor
	+ Manager
	+ Friend
	+ Family Member
* **Reference Time** (`reference_time`, time, optional): Enter the time you have known the reference.
* **Reference Since** (`reference_since`, date, optional): Enter the length of time you have known the reference.
* **Reference Note** (`reference_note`, note, optional): Enter any additional comments or notes about the reference.

## Tips
Please ensure that the information you enter is accurate and up-to-date. If the reference is a professional reference (such as a supervisor or manager), it is recommended to enter their title or position for better context.
