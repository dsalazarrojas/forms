# Reference Order Request Form - Help Guide
## Purpose
The Reference Order Request Form is designed to collect information from university administrators for reference orders.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with the necessary information.
2. Review and submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation

* **University Information** (`general_info`, text, optional): Enter a brief description of the university's information.
* **Delivery Preferences** (`delivery_preferences`, text, optional): Enter the delivery preferences of the university.
* **Clear Authorization** (`clear_authorization`, select multiple, optional): Select one or more options for clear authorization.
* **University Name** (`university_name`, text, optional): Enter the name of the university.
* **University Email** (`university_email`, email, optional): Enter the email of the university.
* **University Phone** (`university_phone`, text, optional): Enter the phone number of the university.
* **Research Center** (`research_center`, text, optional): Enter the research center of the university.
* **Committee** (`committee`, text, optional): Enter the committee of the university.
* **Reference Request** (`reference_request`, text, optional): Enter the reference request of the university.

## Tips
* Make sure to fill in all the required fields accurately.
* If you are unsure about any field, please contact the reference department for assistance.
