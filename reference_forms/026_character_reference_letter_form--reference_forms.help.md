# Character Reference Letter Form - Help Guide
## Purpose
The Character Reference Letter Form is used to collect structured information for writing a character reference letter, which is a personal endorsement of an individual's character and qualifications.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the requester's name and email address in the respective fields.
2. Enter the subject's name.
3. Specify the purpose of the letter (e.g., employment, tenancy, academic).
4. List key points to include in the letter, such as the subject's qualifications, achievements, and personal qualities.
5. Indicate how long you have known the subject.
6. If the letter should be confidential, select 'True'.
7. Choose how the letter should be delivered: Email, Hard copy, or Upload to portal.
8. If you know the submission deadline, select it. If not, leave it blank.

## Field-by-Field Explanation
- **-- Reference Letter Request --** (header, note, required: false): This is a brief introduction to the form.
- **requester name** (requester_name, text, required: true): Enter the name of the person requesting the letter.
- **requester email** (requester_email, email, required: true): Enter the contact email of the person requesting the letter.
- **subject name** (subject_name, text, required: true): Enter the name of the subject being referenced.
- **purpose of letter** (purpose_of_letter, text, required: true): Specify the purpose of the letter (e.g., employment, tenancy, academic).
- **key points to include** (key_points_to_include, text, required: false): List key points to include in the letter, such as the subject's qualifications, achievements, and personal qualities.
- **relationship length** (relationship_length, text, required: false): Indicate how long you have known the subject.
- **confidentiality** (confidentiality, select_one, required: false): Check if the letter should be confidential.
- **delivery method** (delivery_method, select_one, required: true): Choose how the letter should be delivered: Email, Hard copy, or Upload to portal.
- **submission deadline** (submission_deadline, date, required: false): Enter the date by which the letter is needed.
