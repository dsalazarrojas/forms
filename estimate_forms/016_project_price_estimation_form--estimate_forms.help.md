# project_price_estimation_form - Help Guide
## Purpose
The project price estimation form is a tool to help project managers and team members estimate project costs and timelines for future planning and budgeting.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Start Date" field and select the date when the project is expected to start.
2. Click on the "End Date" field and select the date when the project is expected to end.
3. In the "Estimated Budget" field, enter the estimated cost for the project.
4. In the "Actual Price" field, leave blank as this field will be used to record the actual project price after it's completion.

## Field-by-Field Explanation
* **Project Start Date** (`project_start_date`, date, required): The date when the project is expected to start.
* **Project End Date** (`project_end_date`, date, required): The date when the project is expected to end.
* **Estimated Budget** (`estimated_budget`, number, required): The estimated cost for the project.
* **Actual Price** (`actual_price`, number, optional): Leave blank, this field will be used to record the actual project price after it's completion.
