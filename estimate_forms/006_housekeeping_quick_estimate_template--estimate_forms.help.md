# Housekeeping Quick Estimate Template - Help Guide
## Purpose
The "Housekeeping Quick Estimate Template" form is used to estimate the time required for a housekeeping service at a site. This form is meant to be used by staff members to gather information about the services needed and generate an estimate for the time required.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the housekeeping quick estimate template. This will help identify the template in the system.
2. Provide additional information about the housekeeping quick estimate template if needed.
3. Indicate if you would like to request a site visit.
4. Enter the estimated value for the housekeeping quick estimate.

## Field-by-Field Explanation
- **Title** (`title`, `text`, required/optional: required): Enter a title for the housekeeping quick estimate template.
  This will help in identifying the template in the system.
- **Additional Info** (`housekeeping_quick_estimate_template_form_additional_info`, `text`, required/optional: optional): Provide any additional information that may be relevant to the housekeeping quick estimate template.
- **Request Site Visit** (`housekeeping_quick_estimate_template_form_request_site_visit`, `select_one`, required/optional: optional): Indicate if you would like to request a site visit by selecting "Yes" or "No" from the options provided.
- **Estimate Value** (`housekeeping_quick_estimate_template_form_estimate_value`, `number`, required/optional: optional): Enter the estimated value for the housekeeping quick estimate.
