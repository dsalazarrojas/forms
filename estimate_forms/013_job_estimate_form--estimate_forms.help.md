# Job Estimate Form - Help Guide
## Purpose
The Job Estimate Form is a document used to estimate the cost and duration of a project or service. It is designed to be completed by clients or customers to communicate their project requirements and expectations to service providers or vendors.

## How To Complete This Form
To complete the Job Estimate Form, follow these steps:

* Answer the questions on the first page regarding the overall project status.
* For each service provided, answer the questions on the second page, including selecting the services, providing a list of services, and entering the corresponding details and costs.

## Field-by-Field Explanation
* **First Page:** "job_estimate_form_first_page" (First Page)
	+ This is where you can enter a brief description of the project or service.
* **services (Job Estimate Form - Services):** (Yes/No)
	+ Select "Yes" if you are requesting services for this project, "No" otherwise.
* **services_list (Job Estimate Form - Services List):** (text)
	+ Enter a list of services to be provided for this project.
* **services_list_item (Job Estimate Form - Services List Item):** (Yes/No)
	+ Select "Yes" for each service that will be provided for this project.
* **services_list_item_type (Job Estimate Form - Services List Item Type):** (Yes/No)
	+ Select "Yes" or "No" to indicate whether this service is active or inactive.
* **services_list_item_description (Job Estimate Form - Services List Item Description):** (text)
	+ Enter a description of this service.
* **services_list_item_cost (Job Estimate Form - Job Estimate Form - Services List Item Cost):** (number)
	+ Enter the cost of this service.
* **services_list_item_start_date (Job Estimate Form - Services List Item Start Date):** (date)
	+ Enter the start date of this service.
* **services_list_item_end_date (Job Estimate Form - Services List Item End Date):** (date)
	+ Enter the end date of this service.
* **services_list_item_status (Job Estimate Form - Services List Item Status):** (Active/Inactive)
	+ Select "Active" or "Inactive" to indicate the status of this service.
* **services_list_item_notes (Job Estimate Form - Services List Item Notes):** (text)
	+ Enter any additional notes about this service.
* **services_list_item_email (Job Estimate Form - Services List Item Email):** (email)
	+ Enter the email address of the service provider.
* **services_list_item_phone (Job Estimate Form - Services List Item Phone):** (text)
	+ Enter the phone number of the service provider.
* **second_page (Job Estimate Form - Second Page):** (text)
	+ This is where you can enter any additional information about the project or service.

## Tips
* Ensure that you select "Yes" for each service that will be provided.
* Enter accurate and up-to-date information for each service.
* Double-check that you have entered all required fields before submitting the form.
