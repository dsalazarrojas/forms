# Roll Shutter Estimation Form - Help Guide
## Purpose
The Roll Shutter Estimation Form is designed to collect information about roll shutter projects for estimation purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the project details, including project lead, project type, and project status.
2. Enter contact information, including contact number, email address, and address.
3. Provide project description, client name, and project manager information.
4. Enter roll shutter specifications, including roll shutter size, type, material, color, gauge, and thickness.
5. Set the project start and end dates, as well as project status update frequency.
6. Review and submit the form once all required fields are completed.
