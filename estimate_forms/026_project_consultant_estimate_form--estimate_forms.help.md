# Project Consultant Estimate Form - Help Guide

## Purpose

This form is used to gather information from project consultants to estimate project details and ensure that all necessary information is collected for project planning and execution.

## How To Complete This Form

1.  Review the form carefully and ensure you understand each field before completing it.
2.  Enter your project scope and details in the "Project Scope" field.
3.  Indicate whether the project provides services in the "Services Provided" field.
4.  Enter the anticipated costs for the project in the "Anticipated Costs" field.
5.  Specify the consultants involved in the project in the "Consultants" field.
6.  Enter the consultant's contact information in the "Contact Information" field.
7.  Add any additional notes for the consultant in the "Consultant Notes" field.
8.  Enter the consultant's email in the "Consultant Email" field.
9.  Enter the consultant's phone number in the "Consultant Phone" field.
10. Enter the client's name in the "Client Name" field.
11.  Enter the project start date in the "Project Start Date" field.
12.  Enter the project end date in the "Project End Date" field.
13.  Enter the project duration in the "Project Duration" field.
14.  Enter the billing rate for the project in the "Billing Rate" field.
15.  Add any additional notes for the billing rate in the "Billing Rate Note" field.
16.  Add any additional notes for the consultant in the "Consultant Notes Note" field.
17.  Enter the project status in the "Project Status" field.
18.  Add any additional notes for the project status in the "Project Status Note" field.
19.  Indicate whether the project manager is assigned to the project in the "Assigned Project Manager" field.
20.  Add any additional notes for the project manager in the "Assigned Project Manager Note" field.
21.  Enter the project review comments in the "Project Review Comments" field.
22.  Enter the client review comments in the "Client Review Comments" field.
23.  Add any additional notes for the review comments in the "Review Comments Note" field.

## Field-by-Field Explanation

*   **General Information** (1) (text, optional)
    This field is used to gather any additional general information about the project.
*   **Project Scope** (2) (text, required)
    This field is used to enter the project scope and details.
*   **Services Provided** (3) (select one, required)
    This field is used to indicate whether the project provides services.
*   **Anticipated Costs** (4) (number, required)
    This field is used to enter the anticipated costs for the project.
*   **Consultants** (5) (select multiple, required)
    This field is used to specify the consultants involved in the project.
*   **Contact Information** (6) (text, required)
    This field is used to enter the consultant's contact information.
*   **Consultant Notes** (7) (note, optional)
    This field is used to add any additional notes for the consultant.
*   **Consultant Email** (8) (email, required)
    This field is used to enter the consultant's email.
*   **Consultant Phone** (9) (text, required)
    This field is used to enter the consultant's phone number.
*   **Client Name** (10) (text, required)
    This field is used to enter the client's name.
*   **Project Start Date** (11) (date, required)
    This field is used to enter the project start date.
*   **Project End Date** (12) (date, required)
    This field is used to enter the project end date.
*   **Project Duration** (13) (number, required)
    This field is used to enter the project duration.
*   **Billing Rate** (14) (number, required)
    This field is used to enter the billing rate for the project.
*   **Billing Rate Note** (15) (note, optional)
    This field is used to add any additional notes for the billing rate.
*   **Consultant Notes Note** (16) (note, optional)
    This field is used to add any additional notes for the consultant.
*   **Client Notes** (17) (note, optional)
    This field is used to add any additional notes for the client.
*   **Project Status** (18) (select one, required)
    This field is used to enter the project status.
*   **Project Status Note** (19) (note, optional)
    This field is used to add any additional notes for the project status.
*   **Assigned Project Manager** (20) (select one, required)
    This field is used to indicate whether the project manager is assigned to the project.
*   **Assigned Project Manager Note** (21) (note, optional)
    This field is used to add any additional notes for the project manager.
*   **Project Review Comments** (22) (text, required)
    This field is used to enter the project review comments.
*   **Client Review Comments** (23) (text, required)
    This field is used to enter the client review comments.
*   **Review Comments Note** (24) (note, optional)
    This field is used to add any additional notes for the review comments.
*   **Submit** (25) (select one, required)
    This field is used to submit the form.

## Tips

*   Make sure to review the form carefully before submitting it.
*   Enter accurate and complete information in each field.
*   Use the "Consultant Notes", "Billing Rate Note", "Project Status Note", "Assigned Project Manager Note", and "Review Comments Note" fields to add any additional notes or comments as needed.
*   Ensure that all required fields are completed before submitting the form.
