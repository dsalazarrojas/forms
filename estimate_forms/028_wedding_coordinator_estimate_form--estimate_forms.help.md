# Wedding Coordinator Estimate Form - Help Guide
## Purpose
The Wedding Coordinator Estimate Form is a tool to gather essential information for wedding planning and budgeting. This form helps the wedding coordinator to provide accurate estimates for the wedding services by collecting details such as date, location, guest count, and vendor requirements.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the wedding date using the date field.
2. Enter the location of the wedding in the text field.
3. Enter the number of guests attending the wedding.
4. Select the type of ceremony to be held (Civil, Ceremony, or Ceremonies).
5. Indicate if a rehearsal dress rehearsal is required.
6. Enter any accommodations required for the vendors.
7. Enter any travel information for the vendors.
8. Enter any specific vendor requirements.
9. Enter any vendor preferences.
10. Select any vendor services required (Yes/No).
11. Select if the vendor will send invoices (Yes/No).

## Field-by-Field Explanation
* **Wedding Date** (`wedding_date`, date, not required): Enter the date of the wedding in a standard date format (MM/DD/YYYY).
* **Wedding Location** (`wedding_location`, text, not required): Enter the address or venue of the wedding event.
* **Number of Guests** (`number_of_guests`, number, not required): Enter the estimated number of guests attending the wedding.
* **Wedding Time** (`wedding_time`, time, not required): Select the time of the wedding event.
* **Ceremony Type** (`ceremony_type`, select_one, not required): Select the type of ceremony to be held (Civil, Ceremony, or Ceremonies).
* **Rehearsal Dress Rehearsal** (`rehearsal_dress_rehearsal`, select_one, not required): Indicate if a rehearsal dress rehearsal is required.
* **Accommodations** (`accommodations`, text, not required): Enter any specific accommodations required for the vendors.
* **Travel Info** (`travel_info`, text, not required): Enter any travel information for the vendors.
* **Vendor Requirements** (`vendor_requirements`, text, not required): Enter any specific requirements for the vendors.
* **Vendor Preferences** (`vendor_preferences`, text, not required): Enter any specific preferences for the vendors.
* **Vendor Services** (`vendor_services`, select_multiple, not required): Select any vendor services required (Yes/No).
* **Vendor Invoices** (`vendor_invoices`, select_multiple, not required): Select if the vendor will send invoices (Yes/No).

## Tips
* Please ensure to enter accurate and up-to-date information for the wedding event.
* Double-check the fields for completeness and consistency.
* If unsure about any field, please refer to the wedding coordinator for assistance.
