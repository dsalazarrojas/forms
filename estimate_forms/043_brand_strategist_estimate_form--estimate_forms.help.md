# Brand Strategist Estimate Form - Help Guide
## Purpose
The Brand Strategist Estimate Form is used to provide a structured and accurate estimate of the time and resources required for a project. The form helps in capturing the essential details of a project, including its scope, timeline, and financial aspects. The goal is to ensure that both the client and the brand strategist have a clear understanding of the project's scope and costs, preventing misunderstandings and miscommunication during project execution.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by entering the **Client Name** (field 2) and **Project Name** (field 3) accurately. These are mandatory fields that identify the client and the project, respectively.
2. Enter the **Estimate Date** (field 4), which is the date on which the estimate is being submitted.
3. Click on the **Services Included in Estimate** (field 6) and select all the services that apply to the project. This will ensure that you're including all necessary services in your estimate.
4. Provide a detailed **Detailed Scope Description** (field 7) of the project, explaining the scope of work, deliverables, and any other relevant details.
5. If applicable, enter the **Total Estimated Hours** (field 8) and **Hourly Rate** (field 10) to calculate the **Total Estimated Project Fee** (field 11).
6. Enter the **Estimated Project Start Date** (field 13), which represents the project's start date.
7. Specify the **Proposed Payment Schedule** (field 14), e.g., 50 percent upfront.
8. Finally, enter the **Estimate Valid Until** (field 15), which is the date by which the estimate is valid.

## Field-by-Field Explanation
* **Client Name (2)**: Enter the name of the client for whom the project is being estimated.
* **Project Name (3)**: Enter the name of the project being estimated.
* **Estimate Date (4)**: Enter the date on which the estimate is being submitted.
* **Services Included in Estimate (6)**: Select all services applicable to the project from the provided options.
* **Detailed Scope Description (7)**: Provide a detailed explanation of the project's scope, including deliverables and any other relevant details.
* **Total Estimated Hours (8)**: Enter the total estimated hours for the project, if applicable.
* **Hourly Rate (10)**: Enter the hourly rate for the project, if applicable.
* **Total Estimated Project Fee (11)**: This is calculated automatically based on **Total Estimated Hours** and **Hourly Rate**.
* **Estimated Project Start Date (13)**: Enter the project's estimated start date.
* **Proposed Payment Schedule (14)**: Enter the proposed payment schedule for the project, e.g., 50 percent upfront.
* **Estimate Valid Until (15)**: Enter the date by which the estimate is valid.
* **Brand Strategist Name (17)**: Enter the name of the brand strategist responsible for the project.
* **Client Approval - Type Full Name to Accept (18)**: This is a confirmation field for the client to accept the estimate by typing their full name.
