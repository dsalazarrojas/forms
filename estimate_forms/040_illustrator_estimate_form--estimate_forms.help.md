# Illustrator Estimate Form - Help Guide
## Purpose
The Illustrator Estimate Form is a project management tool designed to track and manage ongoing or upcoming projects. It gathers necessary information for project leaders and administrators to understand project scope, client details, and project status.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the project details, including a brief description.
2. Provide information about the project lead, including their name and contact details.
3. Fill out the client information, including their contact details and address.
4. Select the services offered for the project.
5. Enter the project start and end dates, if applicable.
6. Choose the project status (Active or Inactive).
7. Enter the project budget, if applicable.
8. Add any project notes or comments.
9. Enter the client phone number, email, and address.

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required: false): Enter a brief description of the project.
* **Project Lead** (`project_lead`, text, required: false): Enter the name and contact details of the project lead.
* **Client Information** (`client_info`, text, required: false): Enter the client's name, contact details, and address.
* **Services Offered** (`services_offered`, select_multiple, required: false): Select the services provided for the project from the available options (Yes, No).
* **Project Start Date** (`project_start_date`, date, required: false): Enter the start date of the project, if applicable.
* **Project End Date** (`project_end_date`, date, required: false): Enter the end date of the project, if applicable.
* **Project Status** (`project_status`, select_one, required: false): Choose the project status (Active, Inactive).
* **Project Budget** (`project_budget`, number, required: false): Enter the project budget, if applicable.
* **Project Notes** (`project_notes`, note, required: false): Add any project notes or comments.
* **Client Phone** (`client_phone`, text, required: false): Enter the client's phone number.
* **Client Email** (`client_email`, email, required: false): Enter the client's email address.
* **Client Address** (`client_address`, text, required: false): Enter the client's address.

## Tips
* Ensure each field is completed accurately and completely.
* Use the available options for select fields (Services Offered, Project Status) to avoid errors.
* If a field is marked as required (e.g., Project Details), ensure it is filled out accordingly.
* Use the project notes field for any additional comments or information.
