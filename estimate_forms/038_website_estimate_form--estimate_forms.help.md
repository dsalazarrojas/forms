# Website Estimate Form - Help Guide
## Purpose
The Website Estimate Form is used to gather information required to create a detailed estimate for a website project.

## How To Complete This Form
1. Click on the "Form Submit" button to start the form.
2. Enter the project name and project description in the respective fields.
3. Provide the project URL if it's a live website.
4. Select the project type from the dropdown menu.
5. Choose the project status from the dropdown menu.
6. Enter the estimated hours and estimated cost if applicable.
7. Provide a breakdown of the estimated cost in the notes section.
8. Enter your name, email address, job title, company, and department in the submitter section.

## Field-by-Field Explanation

* **Form Submit** (`form_submit`, note, not required): This is the first page of the form. Click on this button to start filling in the form.
* **Project Name** (`project_name`, text, not required): Enter a short name for the project.
* **Project Description** (`project_description`, text, not required): Enter a brief description of the project.
* **Project URL** (`project_url`, text, not required): If the project has a live website, enter the URL here.
* **Project Type** (`project_type`, select_one, required): Select the type of project (Website, E-commerce, Blog).
* **Project Status** (`project_status`, select_multiple, required): Select the status of the project (Active, Inactive).
* **Estimated Hours** (`estimated_hours`, number, not required): Enter the estimated hours required for the project.
* **Estimated Cost** (`estimated_cost`, number, not required): Enter the estimated cost for the project.
* **Estimated Cost Breakdown** (`estimated_cost_breakdown`, note, not required): Provide a breakdown of the estimated cost.
* **Submitter** (`submitter`, text, not required): Enter the submitter's name.
* **Submitter Email** (`submitter_email`, email, not required): Enter the submitter's email address.
* **Submitter Phone** (`submitter_phone`, text, not required): Enter the submitter's phone number.
* **Submitter Job Title** (`submitter_jobtitle`, text, not required): Enter the submitter's job title.
* **Submitter Company** (`submitter_company`, text, not required): Enter the submitter's company.
* **Submitter Department** (`submitter_department`, text, not required): Enter the submitter's department.
