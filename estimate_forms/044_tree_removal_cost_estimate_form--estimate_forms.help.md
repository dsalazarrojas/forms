# Tree Removal Cost Estimate Form - Help Guide

## Purpose
This form is used to provide information about a tree that needs to be removed and any additional services needed. This information will be used to create an estimate for the tree removal service.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the type of tree that needs to be removed.
2. Choose the size of the tree, if applicable.
3. Provide the height of the tree.
4. Decide if a retaining wall is needed.
5. Choose the location of the tree.
6. Select the services needed for the removal.
7. Enter the estimated cost of the service.
8. Add any additional notes about the tree removal.
9. Enter your contact information, such as email and phone number.
10. Assign a tool (e.g. foreman, arborist, etc.) to handle the service.
11. Assign a tool's email and phone number.
12. Add any notes about the tool assigned.

## Field-by-Field Explanation

* **Tree Species**: This field is used to select the type of tree that needs to be removed. Please choose the most accurate option from the list:
	+ Spruce
	+ Oak
	+ Maple
	+ Pine
	+ Other
* **Tree Size**: If the tree has multiple sizes, please select all that apply:
	+ Small
	+ Medium
	+ Large
* **Tree Height**: Enter the height of the tree in numbers only.
* **Stump Size**: Enter the size of the stump in numbers only.
* **Retaining Wall**: Check this box if a retaining wall is needed around the tree area.
* **Tree Location**: Describe the location of the tree, including the address, neighborhood, or landmark.
* **Removal Services**: Select all services needed for the removal:
	+ Tree Removal
	+ Stump Removal
	+ Branching
	+ Other
* **Estimated Cost**: Enter the estimated cost of the service in numbers only.
* **Notes**: Add any additional information about the tree removal service.
* **Email**: Enter your email address so we can contact you about the service.
* **Phone**: Enter your phone number so we can contact you about the service.
* **Assigned Tool**: Assign a tool (e.g. foreman, arborist, etc.) to handle the service.
* **Assigned Tool Email**: Enter the tool's email address.
* **Assigned Tool Phone**: Enter the tool's phone number.
* **Assigned Tool Notes**: Add any notes about the tool assigned.
* **Assigned Tool Comments**: Add any comments about the tool assigned.
* **Submit**: Once you've completed all fields, click the "Submit" button to send the form to us.
