# Proofreader Estimate Form - Help Guide
## Purpose
The Proofreader Estimate Form is a tool used to gather information from clients about their project proofreading needs. This form helps the proofreader understand the project requirements and create an accurate estimate for the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the client's name in the **Client Name** field.
2. Enter the project name in the **Project Name** field.
3. Briefly describe the project in the **Project Description** field.
4. If applicable, specify the proofreader's rate in the **Proofreader Rate** field.
5. Enter the project deadline in the **Project Deadline** field.
6. Enter the project start date in the **Project Start Date** field.
7. Specify the total cost for the project in the **Total Cost** field.
8. Enter the cost per page for the project in the **Cost Per Page** field.
9. Enter the number of pages in the **Project Pages** field.
10. Select the project status from the **Project Status** dropdown menu.
11. Choose the tool assigned to the project from the **Assigned Tool** dropdown menu.
12. Enter a unique identifier for the project in the **Form ID** field.
13. Select the category for the project from the **Category** multi-select menu.
14. If applicable, upload a file to the **Output File** field.
15. Enter any additional notes about the project in the **Notes** field.
16. Enter the client's email address in the **Email** field.
17. Enter the client's phone number in the **Phone** field.
18. Finally, enter the date the form was created in the **Created At** field.

## Field-by-Field Explanation

* **Client Name**: Enter the name of the client.
* **Project Name**: Enter the name of the project.
* **Project Description**: Briefly describe the project.
* **Proofreader Rate**: If applicable, specify the proofreader's rate.
* **Project Deadline**: Enter the project deadline.
* **Project Start Date**: Enter the project start date.
* **Total Cost**: Specify the total cost for the project.
* **Cost Per Page**: Enter the cost per page for the project.
* **Project Pages**: Enter the number of pages in the project.
* **Project Status**: Select the project status from the dropdown menu.
* **Assigned Tool**: Choose the tool assigned to the project from the dropdown menu.
* **Form ID**: Enter a unique identifier for the project.
* **Category**: Select the category for the project from the multi-select menu.
* **Output File**: If applicable, upload a file for the project.
* **Notes**: Enter any additional notes about the project.
* **Email**: Enter the client's email address.
* **Phone**: Enter the client's phone number.
* **Created At**: Enter the date the form was created.
