# Nail Artist Pricing Transparency Survey Form - Help Guide
## Purpose
This form is designed to collect information from nail artists about their pricing practices and policies. It will help you understand your current pricing strategies and how they compare to industry standards.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Answer each question to the best of your ability.
2. Select all that apply for multiple select fields (e.g., Price Range, Service Prices).
3. Select only one option for single select fields (e.g., Pricing Strategy, Pricing Structure).

## Field-by-Field Explanation

* **Salons Info** (`salon_info`, `note`): This section is a note field where you can provide any additional information about your salon.
* **Artist Info** (`artist_info`, `note`): This section is also a note field where you can provide any additional information about yourself as a nail artist.
* **Pricing Info** (`pricing_info`, `select_multiple`): This field allows you to select all that apply to your pricing practices. You can choose from the following options:
	+ Price Range: This is a range of prices you offer for your services.
	+ Pricing Strategy: This is the way you determine your prices (e.g., Price List, Menu Pricing).
	+ Price List: This is a list of prices for your services.
	+ Pricing Structure: This is the format in which you price your services (e.g., Menu Pricing, Tiered Pricing).
* **Pricing Strategy** (`pricing_strategy`, `select_one`): This field allows you to select one of the following pricing strategies:
	+ Price List: This is a fixed price list for all services.
	+ Menu Pricing: This is a pricing system where prices are based on a menu of services.
	+ Tiered Pricing: This is a pricing system where prices vary based on the level of service or complexity.
* **Price List** (`price_list`, `select_multiple`): This field allows you to select all that apply for your price list. You can choose from the following options:
	+ Price per Service: This is a fixed price for each service.
	+ Flat Rate: This is a fixed price for all services.
	+ Tiered Pricing: This is a pricing system where prices vary based on the level of service or complexity.
* **Pricing Structure** (`pricing_structure`, `select_one`): This field allows you to select one of the following pricing structures:
	+ Menu Pricing: This is a pricing system where prices are based on a menu of services.
	+ Tiered Pricing: This is a pricing system where prices vary based on the level of service or complexity.
* **Pricing Range** (`pricing_range`, `number`): This field allows you to select a range of prices you offer for your services.
* **Satisfaction Level** (`satisfaction_level`, `select_one`): This field allows you to select one of the following satisfaction levels:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neutral
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Highest Satisfied** (`satisfaction_level_highest_satisfied`, `select_one`): This field allows you to select the highest level of satisfaction you've received from a client.
* **Least Satisfied** (`satisfaction_level_least_satisfied`, `select_one`): This field allows you to select the lowest level of satisfaction you've received from a client.
* **Pricing Decisions** (`pricing_decisions`, `select_one`): This field allows you to select how you make pricing decisions:
	+ Price per Service
	+ Flat Rate
	+ Tiered Pricing
	+ Menu Pricing
	+ Menu Pricing with Discounts
* **Service Prices** (`service_prices`, `select_multiple`): This field allows you to select all that apply for your service prices. You can choose from the following options:
	+ Nail Polish Change
	+ Nail Art Services
	+ Nail Shape and Design
	+ Other Services
* **Discount Pricing** (`discount_pricing`, `select_one`): This field allows you to select one of the following options:
	+ Discounts Available
	+ Discounts Not Available
* **Pricing Transparency** (`pricing_transparency`, `select_one`): This field allows you to select one of the following options:
	+ Transparent
	+ Not Transparent

## Tips

- Answer each question honestly and to the best of your ability.
- Select all that apply for multiple select fields.
- Select only one option for single select fields.
- If you have any questions or concerns, contact us for assistance.
