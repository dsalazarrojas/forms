# Software Development Assessment - Help Guide
## Purpose
The Software Development Assessment form is designed to collect feedback and information on software development projects. It helps project team members, stakeholders, and clients to provide valuable insights on the development process, progress, and outcomes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Form Title to describe the project briefly.
2. Select the Software Development Assessment to provide your feedback or assessment of the project.
3. Enter the Fitness for Purpose to describe how the project meets its intended goals and objectives.
4. Choose the Assigned Tool to select the tool used for the project.
5. Enter the Category and Subcategory to classify the project.
6. Select the Assigned To team members or stakeholders involved in the project.
7. Choose the Status to update the project's status.
8. Enter the Start and End Dates to track the project's timeline.
9. Enter the Creation and Update Dates to track when the record was created and last updated.
10. Select the Submitted Date to mark when the form was submitted.
11. Enter Additional Notes to provide any further comments or remarks on the project.
12. Indicate whether Notes have been Read.
13. Enter the Email Address and Phone Number for contact information.
14. Select whether Email has been Sent and Read.
15. Select whether Created By and Updated By team members or stakeholders.
16. Select whether the record has been Deleted and Deleted By.
17. Enter the Deleted Date if the record has been deleted.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, optional): Enter a brief description of the project.
* **Software Development Assessment** (`software_development_assessment`, text, optional): Provide your feedback or assessment of the project.
* **Fitness for Purpose** (`fitness_for_purpose`, text, optional): Describe how the project meets its intended goals and objectives.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select the tool used for the project from the available options.
* **Category** (`category`, text, optional): Classify the project into a category.
* **Subcategory** (`sub_category`, text, optional): Further classify the project into a subcategory.
* **Assigned To** (`assigned_to`, select_one, optional): Select the team members or stakeholders involved in the project.
* **Status** (`status`, select_one, optional): Update the project's status.
* **Start Date** (`start_date`, date, optional): Enter the start date of the project.
* **End Date** (`end_date`, date, optional): Enter the end date of the project.
* **Created** (`created`, date, optional): Track when the record was created.
* **Updated** (`updated`, date, optional): Track when the record was last updated.
* **Submitted** (`submitted`, date, optional): Mark when the form was submitted.
* **Additional Notes** (`notes`, text, optional): Provide any further comments or remarks on the project.
* **Notes Read** (`notes_read`, select_one, optional): Indicate whether notes have been read.
* **Email** (`email`, email, optional): Enter the email address of the project contact.
* **Phone** (`phone`, text, optional): Enter the phone number of the project contact.
* **Email Sent** (`email_sent`, select_one, optional): Select whether email has been sent.
* **Email Read** (`email_read`, select_one, optional): Select whether email has been read.
* **Created By** (`created_by`, select_one, optional): Select the team member or stakeholder who created the record.
* **Updated By** (`updated_by`, select_one, optional): Select the team member or stakeholder who updated the record.
* **Deleted** (`deleted`, select_one, optional): Select whether the record has been deleted.
* **Deleted By** (`deleted_by`, select_one, optional): Select the team member or stakeholder who deleted the record.
* **Deleted Date** (`deleted_date`, date, optional): Enter the date when the record was deleted.
