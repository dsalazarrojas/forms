# feedback_session_glss - Help Guide
## Purpose
This form is used to provide feedback on a session.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select Multiple**: Choose the relevant options for "Feedback" from the list.
2. Fill out "Assigned Tool" with the name of the tool used during the session.
3. **Select One**: Choose the category of the session from the list (Peer Feedback Forms or Other).
4. In "Description", briefly describe your feedback for the session.
5. Fill out "Form ID" with a unique number for the session.
6. Enter your "User Name" so that we can know who provided the feedback.

## Field-by-Field Explanation
- **Feedback (Select Multiple)**: Choose the options that best describe the feedback provided for the session (Yes or No).
- **Assigned Tool**: The tool or software used during the session. Enter the name of the tool used.
- **Category**: The category of the session (Peer Feedback Forms or Other).
- **Description**: A brief description of your feedback on the session.
- **Form ID**: A unique number for the session.
- **User Name**: Your name so that we can know who provided the feedback.
