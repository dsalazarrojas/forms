# Peritoneal Dialysis Record Form - Help Guide

## Purpose
This form is designed to collect data about peritoneal dialysis sessions. Completing this form helps healthcare professionals track and analyze vital information about patient treatment, facilitating better patient care.

## How To Complete This Form
1. **Select the Peritoneal Dialysis Machine or Manual Modality**: Choose from the options provided to indicate whether the peritoneal dialysis was performed using a machine or manually.
2. **Enter Machine Modality (if applicable)**: If you chose a machine modality, enter the specific machine used for the treatment.
3. **Enter Machine Modality ID (if applicable)**: If you chose a machine modality, enter the ID number corresponding to the machine used.
4. **Enter Manual Modality Setup (if applicable)**: If you performed the treatment manually, describe the setup used.
5. **Enter Manual Modality ID (if applicable)**: If you performed the treatment manually, enter the ID number corresponding to the setup used.
6. **Session Duration**: Enter the duration of the peritoneal dialysis session.
7. **Session Start Time**: Enter the start time of the peritoneal dialysis session.
8. **Session End Time**: Enter the end time of the peritoneal dialysis session.
9. **Patient Weight**: Enter the patient's weight at the time of the session.
10. **Blood Flow Rate**: Enter the blood flow rate, if applicable.
11. **Ultrafiltration Volume**: Enter the ultrafiltration volume used during the session.
12. **Ultrafiltration Flow Rate**: Enter the ultrafiltration flow rate used during the session.

## Field-by-Field Explanation
* **Peritoneal Dialysis Setup**: Select the modality used for the treatment.
* **Machine Modality**: Enter the name of the machine used for the treatment.
* **Machine Modality ID**: Enter the ID number corresponding to the machine used.
* **Manual Modality Setup**: Describe the manual setup used for the treatment.
* **Manual Modality ID**: Enter the ID number corresponding to the manual setup used.
* **Session Duration**: Enter the duration of the peritoneal dialysis session.
* **Session Start Time**: Enter the start time of the peritoneal dialysis session.
* **Session End Time**: Enter the end time of the peritoneal dialysis session.
* **Patient Weight**: Enter the patient's weight at the time of the session.
* **Blood Flow Rate**: Enter the blood flow rate used during the session.
* **Ultrafiltration Volume**: Enter the ultrafiltration volume used during the session.
* **Ultrafiltration Flow Rate**: Enter the ultrafiltration flow rate used during the session.

## Tips
* Ensure accurate and consistent data entry to maintain accurate patient records.
* Double-check fields for completeness and accuracy before submitting.
* If you're unsure about any field, please review the form purpose and field-by-field explanations above.
