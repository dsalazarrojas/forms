# Patient Weight And Height Log - Help Guide
## Purpose
The Patient Weight And Height Log form is used to record and track a patient's weight and height measurements.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's weight in the Weight field.
2. Enter the patient's height in the Height field.
3. Select the date of the measurement in the Date of Measurement field.

## Field-by-Field Explanation

* **Weight** (`patient_weight`, number, optional): Enter the patient's weight in kilograms (or pounds if you're using a different unit of measurement). This field allows you to track the patient's weight over time.
* **Height** (`patient_height`, number, optional): Enter the patient's height in centimeters (or feet and inches if you're using a different unit of measurement). This field allows you to track the patient's height over time.
* **Date of Measurement** (`date_of_measurement`, date, optional): Select the date the weight and height measurement was taken. This field helps to timestamp the data and provide a reference point for future measurements.

## Tips
* Ensure that you are using a consistent unit of measurement for both weight and height.
* Make sure to update the form regularly to track the patient's progress over time.
* Use the date field to keep track of when each measurement was taken.
