# Patient Treatment Plan Extension Form - Help Guide
## Purpose
This form is designed to collect patient information and treatment plans for medical professionals to review and use in their practices.

## How To Complete This Form
1. Review each field carefully and input the required information.
2. Fill in all fields as accurately as possible.
3. Click submit to save your input.

## Field-by-Field Explanation

* **Form** (`form`, `text`, required: false): This field is a text box where you can input any comments or information related to the patient.
* **Medication Allergies** (`medication_allergies`, `select_multiple`, required: false): Select all medications the patient is allergic to.
* **Medical Conditions** (`medical_conditions`, `text`, required: false): Input any medical conditions the patient has.
* **Medical History** (`medical_history`, `note`, required: false): Input any relevant medical history for the patient.
* **Medical Specialties** (`medical_specialties`, `select_one`, required: false): Select the specialty of the doctor or healthcare provider that treated the patient.
* **Medical Specialty** (`medical_specialty`, `number`, required: false): Input the specialty of the doctor or healthcare provider that treated the patient.
* **Medical Specialty 2** (`medical_specialty_2`, `select_one`, required: false): Select if the patient has any other medical specialties.
* **Medical Specialty 3** (`medical_specialty_3`, `select_one`, required: false): Select if the patient has any other medical specialties.
* **Patient Demographics** (`patient_demographics`, `text`, required: false): Input any demographic information about the patient.
* **Patient Info** (`patient_info`, `text`, required: false): Input any other patient information.
* **Treatment Plan** (`treatment_plan`, `select_multiple`, required: false): Select any treatment plans applied to the patient.
* **Treatment Plan 2** (`treatment_plan_2`, `select_multiple`, required: false): Select any other treatment plans applied to the patient.
* **Treatment Plan 3** (`treatment_plan_3`, `select_multiple`, required: false): Select any other treatment plans applied to the patient.
* **Doctor Info** (`doctor_info`, `text`, required: false): Input any information about the doctor or healthcare provider that treated the patient.
* **Doctor Info 2** (`doctor_info_2`, `text`, required: false): Input any other information about the doctor or healthcare provider that treated the patient.
* **Doctor Info 3** (`doctor_info_3`, `text`, required: false): Input any other information about the doctor or healthcare provider that treated the patient.
* **Doctor Specialties** (`doctor_specialties`, `select_multiple`, required: false): Select any specialties of the doctor or healthcare provider that treated the patient.
* **Doctor Specialties 2** (`doctor_specialties_2`, `select_multiple`, required: false): Select any other specialties of the doctor or healthcare provider that treated the patient.
* **Doctor Specialties 3** (`doctor_specialties_3`, `select_multiple`, required: false): Select any other specialties of the doctor or healthcare provider that treated the patient.
* **Doctor Experience** (`doctor_experience`, `text`, required: false): Input any information about the doctor's experience.
* **Patient Treatment** (`patient_treatment`, `text`, required: false): Input any treatment plans or information related to the patient.
* **Patient History** (`patient_history`, `text`, required: false): Input any other patient information.
* **Patient Treatment Plan** (`patient_treatment_plan`, `text`, required: false): Input any other patient treatment plan information.
* **Patient History 2** (`patient_history_2`, `text`, required: false): Input any other patient information.
* **Patient Medical History** (`patient_medical_history`, `text`, required: false): Input any other patient medical history information.
