# vaccination_status_and_verification_form - Help Guide
## Purpose
This form is designed to collect vaccination status and verification details of patients. It's essential to fill this form out with care to ensure accurate patient records.

## How To Complete This Form
To complete this form, follow these steps:

*   Select the patient's vaccination status from the available options.
*   Record the verification records, which may involve checking with the patient or reviewing medical records.
*   Enter the vaccination date, verification date, and verification time.
*   Select the verification method used (e.g., Immunization Record, Birth Certificate, Medical Records, or Other).
*   Indicate if the verification provider is 'Yes' or 'No'.
*   Add any additional comments or remarks.
*   If applicable, upload a supporting file with details such as file name, size, type, and location.

## Field-by-Field Explanation

*   **Vaccination Status** (select multiple): This field requires selecting the patient's current vaccination status from the available options (Active or Inactive).
*   **Verification Records** (select one): This field is used to record whether verification records are available (Yes or No).
*   **Vaccination Date** (date): Enter the date of the vaccination, if applicable.
*   **Verification Date** (date): Enter the date of the verification, if applicable.
*   **Verification Time** (time): Enter the time of the verification, if applicable.
*   **Verification Method** (select one): Select the method used for verification (e.g., Immunization Record, Birth Certificate, Medical Records, or Other).
*   **Verification Provider** (select one): Indicate if the verification provider is 'Yes' or 'No', indicating their involvement in the verification process.
*   **Comments** (text): Add any additional comments or remarks about the patient's vaccination status or verification process.
*   **Uploaded File** (text): If a file is uploaded, enter the file name.
*   **File Name** (text): Enter the name of the uploaded file.
*   **File Size** (text): Enter the size of the uploaded file.
*   **File Type** (text): Enter the type of the uploaded file.
*   **File Date** (date): Enter the date the file was uploaded.
*   **File Description** (text): Add a description of the uploaded file.
*   **File Tags** (text): Add any relevant tags or keywords to the uploaded file.
*   **File Mimetype** (text): Enter the mime type of the uploaded file.
*   **File Location** (text): Enter the location of the uploaded file.

Please ensure that the data entered is accurate and complete to maintain the highest standard of care.
