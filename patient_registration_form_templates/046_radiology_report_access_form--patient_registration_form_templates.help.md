# radiology_report_access_form - Help Guide
## Purpose
The radiology_report_access_form is used to access and request radiology reports for patients from a centralized database. This form is designed to efficiently and accurately provide radiology reports, and to prevent duplicate requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information to fill out the form.
2. Fill out each field according to your needs.

## Field-by-Field Explanation
- **Patient ID** (`patient_id`, Number, Optional):
    Enter the patient's unique identifier, if you know it. If you don't know the patient's ID, you can leave this field blank and the system will prompt you to select the patient from a list.

- **Access Date** (`access_date`, Date, Optional):
    Enter the date you want to access the radiology report for. If left blank, the system will default to the current date.

- **Radiologist Notes** (`radiologist_notes`, Text, Optional):
    Enter any additional notes or comments from the radiologist about the patient's report.

- **Radiology Report ID** (`radiology_report_id`, Number, Optional):
    Enter the ID of the radiology report you want to access. If you don't know the report ID, you can leave this field blank and the system will prompt you to search for the report.

## Tips
- If you're unsure about any field, you can refer back to this guide for clarification.
- If you need to access multiple reports, repeat the process for each report.
- If you encounter any issues, contact your local support team for assistance.
