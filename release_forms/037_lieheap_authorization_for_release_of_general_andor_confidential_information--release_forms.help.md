# LIEHEAP Authorization For Release Of General Andor Confidential Information - Help Guide
## Purpose
This form is used to request authorization for the release of general andor confidential information. This form should only be used for legitimate purposes and not for duplicate or non-relevant requests.

## How To Complete This Form
- Read the form carefully and ensure that you are filling it out for a legitimate reason.
- Answer all required fields truthfully and accurately.
- If you are unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **Authorized by** (`4`, `text`, optional): The name of the person authorizing the release of the information.
* **Authorized Person** (`3`, `text`, optional): The name of the person or team releasing the information.
* **Comments** (`6`, `note`, optional): Any additional comments or details about the release of the information.
* **Conidential** (`2`, `select_one`, optional): The type of information being released, whether it's Confidential, General, or Both.
* **Date of Release** (`5`, `date`, optional): The date the information will be released.
* **File Upload** (`9`, `text`, optional): A file or document to be uploaded for reference.
* **Release of** (`8`, `select_multiple`, optional): The type of information to be released, whether it's General, Confidential, or Both.
* **Release Type** (`2`, `select_one`, optional): The type of information being released, whether it's Confidential, General, or Both.
* **Signature** (`7`, `text`, optional): The signature of the person authorizing the release.
* **Title** (`title`, `text`, optional): The title of this form.
* **Upload File** (`9`, `text`, optional): Not a valid field. It seems there are two fields with the same label, one is "file_upload" and the other is "file_upload" which is not a valid field. It's possible that this field is not supposed to be used. Please disregard this field.
* **Release_of** (`8`, `select_multiple`, optional): The type of information to be released, whether it's General, Confidential, or Both.

Note that "Release Type" and "Release of" seems to be duplicate fields. Please ensure that only one of them is used.
