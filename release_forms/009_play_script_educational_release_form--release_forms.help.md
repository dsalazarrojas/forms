# Play Script Educational Release Form - Help Guide
## Purpose

The Play Script Educational Release Form is used to request and record script releases for educational purposes. This form is a standard template to ensure consistency and accuracy in the release process.

## How To Complete This Form

1. Fill out the form with the required information and details for the script release.
2. Make sure all required fields are completed before submitting the form.
3. Double-check the form for accuracy before submitting to avoid errors.

## Field-by-Field Explanation
* **User Name** (`user_name`, Text, Optional): Enter your name as a reference or your department's name if you are an administrator. This will help us track and manage releases more effectively.
* **Organization Name** (`organization_name`, Text, Required): Enter your organization's name (school, university, or company) to associate the release with your institution.
* **Permission Type** (`permission_type`, Select, Required): Choose the intended permission type (classroom performance, workshop, or readings) to specify the purpose of the script release.
* **Script Start Date** (`script_start_date`, Date, Required): Enter the start date of the script's usage period, which is from January 1st, 2020, to January 1st, 2023.
* **Script End Date** (`script_end_date`, Date, Required): Enter the end date of the script's usage period, which is December 31st, 2023.
* **Script Title** (`script_title`, Text, Optional): Provide the title of the script for reference and organization.
* **Script Version** (`script_version`, Number, Optional): Enter the version number of the script for consistency and tracking purposes.
* **Performance Location** (`performance_location`, Text, Required): Specify the location where the script will be performed or read.
* **Performance Date** (`performance_date`, Date, Required): Enter the date when the performance or reading will take place.
* **Performance Time** (`performance_time`, Time, Required): Specify the time of the performance or reading.
* **Number of Performances** (`number_of_performances`, Number, Required): Enter how many performances or readings will take place.
* **Release To** (`release_to`, Text, Optional): Enter any additional details or names of who the release is to.
* **Email** (`email`, Email, Optional): Provide your email address for contact and follow-up purposes.
* **Phone** (`phone`, Text, Optional): Enter your phone number for contact and follow-up purposes.
* **Comments** (`comments`, Note, Optional): Leave any additional comments or notes for further reference and clarification.

Note: Ensure all required fields are completed before submitting the form for accurate and efficient processing.
