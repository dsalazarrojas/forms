# magazine_media_release_form - Help Guide
## Purpose
The magazine_media_release_form is used to collect user information from media releases, including details about the type of media and its usage rights.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your **First Name** in the `first_name` field. This is a required field for your identification purposes.
2. Fill in your **Last Name** in the `last_name` field.
3. Enter your **Email** in the `email` field. This is an optional field.
4. If you want to include your contact phone number, enter it in the `phone` field. This is an optional field.
5. If you want to provide your address, enter it in the `address` field. This is an optional field.
6. In the `media_type` field, select all relevant media types that apply to your release (e.g., photo, video, audio, written, other).
7. Choose the usage rights for your media release in the `usage_rights` field. Select one or more options that apply to your release (e.g., publish, distribute, use).
8. If your media release has a specific **Published Date**, enter it in the `published_date` field. This is an optional field.
9. If you want to assign a specific tool or identifier to your media release, enter it in the `assigned_tool` field. This is an optional field.
10. If you want to categorize your media release, enter a brief description in the `category` field. This is an optional field.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Please enter your first name.
* **Last Name** (`last_name`, text, required): Please enter your last name.
* **Email** (`email`, email, optional): Please enter your email address for contact purposes.
* **Phone** (`phone`, text, optional): If you want to provide your contact phone number, enter it here.
* **Address** (`address`, text, optional): Please enter your contact address.
* **Media Type** (`media_type`, select_multiple, optional): Please select all relevant media types for your release (photo, video, audio, written, other).
* **Usage Rights** (`usage_rights`, select_one, optional): Choose one or more usage rights for your media release (publish, distribute, use).
* **Published Date** (`published_date`, date, optional): If your media release has a specific published date, enter it here.
* **Form ID** (`form_id`, number, optional): Please enter a specific identifier for your media release, if required.
* **Assigned Tool** (`assigned_tool`, text, optional): If you want to assign a specific tool or identifier to your media release, enter it here.
* **Category** (`category`, text, optional): Please enter a brief description for your media release category.

Note: All fields are optional unless marked as required.

## Tips

* Make sure to select all applicable media types and usage rights for your release.
* If you're unsure about a field, feel free to ask for clarification.
* This form is meant to provide a general guideline for media releases; some fields are optional, so use your discretion when completing them.
* If you have any further questions, please do not hesitate to contact us.
