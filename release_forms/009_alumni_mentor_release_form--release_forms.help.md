# Alumni Mentor Release Form - Help Guide
## Purpose
This form is used to formally release an alumni mentor from their responsibilities and agreements, typically after a program has ended.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have all the necessary information and approvals before filling out the form.
2. Fill out each field accurately and completely.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation
* **Mentor name** (id: 2, name: mentor_name, type: text, required: true): Enter the full name of the mentor being released.
* **Mentee name** (id: 3, name: mentee_name, type: text, required: false): Enter the full name of the mentee (if applicable).
* **Scope of release** (id: 4, name: release_scope, type: text, required: true): Describe the specific activities or responsibilities covered in the release.
* **Effective date** (id: 5, name: effective_date, type: date, required: true): Enter the date when the release becomes effective.
* **Contact email** (id: 6, name: contact_email, type: email, required: true): Enter the email address for correspondence with the mentor.
* **Printed name for signature** (id: 7, name: signature_name, type: text, required: true): Enter your printed name for signature purposes.
* **Consent acknowledgement** (id: 8, name: consent_signature, type: text, required: true): Type your name to acknowledge your consent to the release.
* **Additional notes** (id: 9, name: additional_notes, type: text, required: false): Enter any additional comments or notes about the release (optional).

## Tips
* Please ensure that all fields are filled out accurately and completely before submitting the form.
* If you are unsure about any field, please contact the relevant authorities for guidance.
* This form is intended to be used for formal releases only. If you are unsure about the purpose or usage of this form, please contact the relevant authorities for guidance.
