# Magazine Model Release Form - Help Guide
## Purpose
This form is used to gather model release information for a magazine or media publication.

## How To Complete This Form
To use this form, please fill in the required fields below. If a field is marked as optional, it is not required but may be necessary for our records or future reference.

## Field-by-Field Explanation
* **Model Information** (`model_information`, `text`, optional): Enter a brief description of the model.
* **First Name** (`first_name`, `text`, optional): Enter the model's first name.
* **Last Name** (`last_name`, `text`, optional): Enter the model's last name.
* **Date of Birth** (`date_of_birth`, `date`, optional): Enter the model's date of birth.
* **Contact Address** (`contact_address`, `text`, optional): Enter the model's contact information.
* **Email Address** (`email_address`, `email`, optional): Enter the model's email address.
* **Phone Number** (`phone_number`, `text`, optional): Enter the model's phone number.
* **Photographer** (`photographer`, `text`, optional): Enter the model's photographer's name.
* **Agency** (`agency`, `text`, optional): Enter the agency the model represents.
* **Published Media** (`published_media`, `text`, optional): Note the media that the model has been published in (e.g., magazine, newspaper, billboard).
* **Release For** (`release_for`, `select_one`, required): Select the type of media this release is for (Magazine, Newspaper, or Billboard).
* **Signed On** (`signed_on`, `date`, optional): Date the model released their rights.
* **Signed By** (`signed_by`, `text`, optional): Enter the person who signed the release.
* **Signed At** (`signed_at`, `date`, optional): Date the release was signed.
* **Notes** (`notes`, `text`, optional): Enter any additional notes or comments regarding the model's release.

## Tips
* Make sure to fill in all required fields, especially "Release For".
* Double-check the model's contact information for accuracy.
* If the model has been released for multiple media types, select all applicable options for "Release For".
