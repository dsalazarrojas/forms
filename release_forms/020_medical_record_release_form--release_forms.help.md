# Medical Record Release Form - Help Guide
## Purpose
This form is used to collect the necessary information for releasing a patient's medical record. It is essential to complete this form accurately to ensure the correct release process and minimize potential issues.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the required information for the patient's identification and medical history.
2. Select the correct release option (Authorized Person or Other) from the dropdown menu.
3. Choose the release date for both the releaser and signer.
4. Select the type of medical record being released (Authorized Person or Other).
5. Review and sign the form.

## Field-by-Field Explanation
### 1. **Patient Info** (Patient Info, Text, Required)
Enter the patient's identifying information, such as their name, date of birth, or any other relevant details.

### 2. **Medical History** (Medical History, Note, Optional)
If necessary, provide any important medical history or background information that may be relevant for the release.

### 3. **Authorization** (Authorization, Select One, Optional)
Select 'Authorized Person' if you are authorized to access and release the medical record on behalf of the patient. Otherwise, choose 'Other' for alternative arrangements.

### 4. **Date of Releaser** (Date Releaser, Date, Optional)
Enter the date on which the medical record is being released.

### 5. **Date of Signer** (Date Signer, Date, Optional)
Enter the date on which the form is signed by the releaser or signer.

### 6. **Release Type** (Release Type, Select One, Optional)
Select 'Authorized Person' if you are the authorized person for the release. Otherwise, choose 'Other' for alternative arrangements.

### 7. **Medical Record Release Form** (Medical Record Release Form, Select Multiple, Optional)
Select the type of medical record being released.

### 8. **Medical Record Release Form Signature** (Medical Record Release Form Signature, Note, Optional)
This is a note field for any additional comments or explanations related to the release.

### 9. **Release Date** (Release Date, Date, Optional)
Enter the date on which the form is released.

### 10. **Medical Record Release Form** (Medical Record Release Form, Select Multiple, Required)
Select the type of medical record being released.
 
### 11. **Medical Record Release Form Signature** (Medical Record Release Form Signature, Note, Required)
Sign the form to confirm the release.
 
### 12. **Release Date** (Release Date, Date, Required)
Enter the date on which the form is released.

Note: This form requires careful completion and verification to ensure accurate and secure release of the medical records. Please review the information carefully before submission.
