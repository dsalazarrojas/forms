# Employee Offboarding Records Release Form - Help Guide
## Purpose
This form is used to document the employee offboarding process, including the release of company records and information. It is intended to be completed by the employee and their manager to ensure a smooth and transparent transition out of the company.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer the questions on each page, taking care to provide accurate and relevant information.
2. For fields with options, select the most appropriate choice for your situation.
3. Sign and date the required fields to confirm that you have read, understand, and agree to the terms.
4. Ensure that you have filled out all required fields before submitting the form.

## Field-by-Field Explanation

* **employee_offboarding_records** (`employee_offboarding_records`, text, optional): This field is used to enter any relevant information about the employee's offboarding records.
* **release_form** (`release_form`, select_one, optional): Select the option that best describes the reason for the employee's offboarding. Options:
	+ Option 1
	+ Option 2
	+ Option 3
* **offboarding_process** (`offboarding_process`, note, optional): This field is for any additional notes or comments about the offboarding process.
* **manager_approval** (`manager_approval`, select_multiple, optional): Check all the boxes that apply to the manager's approval:
	+ Option 1
	+ Option 2
* **employee_signature_date** (`employee_signature_date`, date, optional): Date and signature of the employee, confirming that they have read and understood the terms.
* **release_date** (`release_date`, date, optional): Date on which the employee's records will be released.
* **manager_signature_date** (`manager_signature_date`, date, optional): Date and signature of the manager, confirming that they have read, understood, and agreed to the terms.
* **date_of_departure** (`date_of_departure`, date, optional): Date of the employee's departure from the company.

## Tips

* Please ensure that you have filled out all required fields before submitting the form.
* If you have any questions or concerns, please reach out to the HR department.
* This form is an essential document for the offboarding process, so please take care when filling it out.
