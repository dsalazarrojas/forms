# Design Firm Project Release Form - Help Guide
## Purpose
The Design Firm Project Release Form is a tool used to track and record project release information. It helps gather data about a project's status, progress, and completion.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project name in the "Project Name" field.
2. Enter the client name in the "Client Name" field.
3. Select the project status from the "Project Status" dropdown menu.
4. Provide a brief description of the project in the "Project Description" field.
5. Enter the date the project was closed in the "Date Closed" field.
6. Enter the name of the project manager in the "Project Manager Name" field.
7. Enter the date the client signed off on the project in the "Client Signed Date" field.
8. Enter the date the project manager signed off on the project in the "Project Manager Signed Date" field.
9. Enter the release version number in the "Release Version" field.
10. Enter the date the project was released in the "Release Date" field.
11. Provide any additional status notes about the project in the "Project Status Notes" field.
12. Provide any additional closed notes about the project in the "Project Closed Notes" field.
13. Enter any project status history in the "Project Status History" field.
14. Enter any project release notes in the "Project Release Notes" field.
15. Enter any client notes about the project in the "Client Notes" field.
16. Enter the date the project was signed off on in the "Project Signed Date" field.
17. Enter the date the project manager signed off on in the "Project Manager Signed Date" field.
18. Enter any release version history in the "Release Version History" field.
19. Enter any release status history in the "Release Status History" field.
20. Enter any release date notes in the "Release Date Notes" field.
21. Enter the date the release was signed off on by the release manager in the "Release Manager Signed Date" field.
22. Enter any release version notes in the "Release Version Notes" field.
23. Enter the date the release was signed off on in the "Signed Date" field.
24. Enter the date the manager signed off on in the "Manager Signed Date" field.
25. Enter the date the release manager signed off on in the "Release Manager Signed Date" field.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project that is being released.
* **Client Name** (`client_name`, text, required): Enter the name of the client that the project is for.
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project (Active, Completed, Released).
* **Project Description** (`project_description`, text, required): Provide a brief description of the project.
* **Date Closed** (`date_closed`, date, required): Enter the date the project was closed.
* **Project Manager Name** (`project_manager_name`, text, required): Enter the name of the project manager.
* **Client Signed Date** (`client_signed_date`, date, required): Enter the date the client signed off on the project.
* **Project Manager Signed Date** (`project_manager_signed_date`, date, required): Enter the date the project manager signed off on the project.
* **Release Version** (`release_version`, text, required): Enter the version number of the released project.
* **Release Date** (`release_date`, date, required): Enter the date the project was released.
* **Project Status Notes** (`project_status_notes`, text, required): Enter any additional status notes about the project.
* **Project Closed Notes** (`project_closed_notes`, text, required): Enter any additional closed notes about the project.
* **Project Status History** (`project_status_history`, text, required): Enter any project status history.
* **Project Release Notes** (`project_release_notes`, text, required): Enter any project release notes.
* **Client Notes** (`client_notes`, text, required): Enter any client notes about the project.
* **Project Signed Date** (`project_signed_date`, date, required): Enter the date the project was signed off on.
* **Project Manager Signed Date** (`project_manager_signed_date`, date, required): Enter the date the project manager signed off on.
* **Release Version History** (`release_version_history`, text, required): Enter any release version history.
* **Release Status History** (`release_status_history`, text, required): Enter any release status history.
* **Release Date Notes** (`release_date_notes`, text, required): Enter any release date notes.
* **Release Manager Signed Date** (`release_manager_signed_date`, date, required): Enter the date the release was signed off on by the release manager.
* **Release Version Notes** (`release_version_notes`, text, required): Enter any release version notes.
* **Signed Date** (`signed_date`, date, required): Enter the date the release was signed off on.
* **Manager Signed Date** (`manager_signed_date`, date, required): Enter the date the manager signed off on.
* **Release Manager Signed Date** (`release_manager_signed_date`, date, required): Enter the date the release manager signed off on.
