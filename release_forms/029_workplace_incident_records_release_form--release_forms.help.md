# Workplace Incident Records Release Form - Help Guide
## Purpose
The Workplace Incident Records Release Form is used to document and report workplace incidents, ensuring consistency in the incident management process.

## How To Complete This Form
1. Fill out the form completely and accurately with the requested information about the incident.
2. Be sure to select the correct investigation status and incident type for each incident.
3. If the incident report is completed, attach it to the form or provide a link to the report.

## Field-by-Field Explanation
* **Release Form** (`release_form`): A brief description of the incident, including any relevant details that need to be reported.
* **Incident Date** (`incident_date`): The date on which the incident occurred.
* **Incident Time** (`incident_time`): The time at which the incident occurred.
* **Incident Location** (`incident_location`): The location where the incident occurred.
* **Incident Description** (`incident_description`): A detailed description of the incident, including any injuries or damages sustained.
* **Investigation Status** (`investigation_status`): Select the current status of the investigation (Not Started, Completed, or In Progress).
* **Incident Type** (`incident_type`): Select all types of incidents that apply to the reported incident (Accident, Near Miss, or Other).
* **Incident Report** (`incident_report`): If an incident report has been completed, attach it or provide a link to the report.

## Tips
* Double-check the provided information for accuracy before submitting the form.
* Be thorough in filling out all required and optional fields.
* Use the investigation status and incident type fields carefully to ensure that the incident is classified correctly.
