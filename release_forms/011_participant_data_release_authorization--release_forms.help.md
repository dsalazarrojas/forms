# Participant Data Release Authorization - Help Guide

## Purpose
This form is used to obtain authorization to release participant data to specified recipients. The form collects information about the release purpose, type, and date/time, as well as the recipient's details and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Release Purpose" field with a brief description of why you are requesting data release authorization.
2. Select the type of data to be released (Participant, Program, or Research Team) in the "Release Type" field.
3. Enter the date and time you are requesting data to be released in the "Release Date" and "Release Time" fields, respectively.
4. Enter any additional notes or comments in the "Notes" field.
5. Select whether or not you agree to the terms of data release in the "Agreed" field.
6. Enter the recipient's email address in the "Email Recipient" field.
7. Enter the recipient's phone number in the "Phone Recipient" field.
8. Enter the recipient's address in the "Address Recipient" field.

## Field-by-Field Explanation

* **Release Purpose** (Text, Optional): A brief description of why you are requesting data release authorization.
* **Release Type** (Select Multiple, Optional):
	+ Participant: Data release authorization for a single participant.
	+ Program: Data release authorization for a program or project.
	+ Research Team: Data release authorization for a research team.
* **Release Date** (Date, Optional): The date on which you are requesting data to be released.
* **Release Time** (Time, Optional): The time on which you are requesting data to be released.
* **Notes** (Text, Optional): Additional comments or notes about the data release request.
* **Agreed** (Select Multiple, Optional):
	+ True: You agree to the terms of data release.
	+ False: You do not agree to the terms of data release.
* **Email Recipient** (Email, Optional): The recipient's email address.
* **Phone Recipient** (Text, Optional): The recipient's phone number.
* **Address Recipient** (Text, Optional): The recipient's address.
* **Recipient Details** (Text, Optional): Additional details about the recipient.
* **Form Participant Data Release** (Text, Optional): Additional information about the participant data to be released. 

Please note that some fields are optional and can be left blank if not applicable.
