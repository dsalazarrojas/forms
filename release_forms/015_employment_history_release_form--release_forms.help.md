# Employment History Release Form - Help Guide
## Purpose
The Employment History Release Form is used to collect and document an individual's employment history for official purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the employee's name as it appears on their identification documents.
2. Provide the name of the employee's previous employer(s).
3. Enter the job title(s) held during previous employment.
4. Enter the dates of employment (start and end dates) for each previous job.
5. Specify the duration of each previous job.
6. Provide the reason for leaving each previous job.
7. Indicate the current status of the employee (Active or Non-Active).
8. If applicable, enter the date of last employment and the reason for leaving last employment.

## Field-by-Field Explanation
* **Employee Name**: Enter the individual's name as it appears on their identification documents.
* **Employer Name**: Provide the name of the employee's previous employer(s).
* **Job Title**: Enter the job title(s) held during previous employment.
* **Job Start Date**: Enter the start date of the employee's job.
* **Job End Date**: Enter the end date of the employee's job.
* **Job Duration**: Enter the duration of each previous job.
* **Reason for Leaving**: Provide a brief explanation for why the employee left their previous job.
* **Employee Status**: Indicate the current status of the employee (Active or Non-Active).
* **Employment Start Date**: If the employee has never been employed before, or if the current employment start date is before the last employment end date, enter the date they started their first job.
* **Employer Address**: This field is not applicable for this form.
* **Employment End Date**: If the employee has never been employed before, enter the current date.
* **Reason for Leaving Employer**: This field is not applicable for this form.
* **Last Employment Start Date**: If the employee has never been employed before, enter the date they started their first job.
* **Last Employment End Date**: If the employee has never been employed before, enter the current date.
* **Last Employment Duration**: If the employee has never been employed before, enter 0.
* **Reason for Last Leaving**: This field is not applicable for this form.

## Tips
* Ensure that the information provided is accurate and up-to-date.
* If an employee has never been employed before, please enter the first employment start date and current date for all relevant fields.
* If you are unsure about any field, please ask for clarification or consult with the relevant authorities.
