# Coverage Plan Release Form - Help Guide
## Purpose
The Coverage Plan Release Form is used to document the details of an employee's termination, ensuring a smooth and accurate processing of the release.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all required fields, including employee name, email, phone number, termination date, termination reason, and release authorization date.
2. Select the termination effective period from the provided options.
3. Choose the release status and provide any additional release status notes.
4. Ensure all fields are filled and submitted accurately before submitting the form.

## Field-by-Field Explanation
### First page (First name)
* **First name**: This is the first name of the employee, please fill in their actual first name.
* **Email**: This is the employee's email address, please make sure it is accurate.
* **Phone number**: This is the employee's phone number, please fill in without any special characters or formatting.
* **Termination date**: This is the date when the employee's coverage will end, please select the correct date.
* **Termination reason**: This is the reason for the employee's termination, please fill in a brief description.
* **Termination cause**: This is an optional field for any additional information regarding the termination.
* **Employee name**: This is the full name of the employee, please fill in their actual name.
* **Employee email**: This is the employee's email address, please make sure it is accurate.
* **Employee phone**: This is the employee's phone number, please fill in without any special characters or formatting.

### Second page
* **Termination effective date**: This is the date when the termination will take effect, please select the correct date.
* **Termination effective time**: This is the time when the termination will take effect, please select the correct time.
* **Termination effective period**: This is the duration of the termination, please select one of the provided options.
* **Termination effective period unit**: This is the unit of time for the termination period, please select one of the provided options.
* **Termination effective period value**: This is an optional field for any additional information regarding the termination period.
* **Manager name**: This is the name of the manager or representative who is processing the termination, please fill in their actual name.
* **Manager email**: This is the manager's email address, please make sure it is accurate.
* **Manager phone**: This is the manager's phone number, please fill in without any special characters or formatting.

### Third page
* **Release authorization**: This is the approval or authorization for the termination, please fill in any additional comments.
* **Release notes**: This is an optional field for any additional comments or information regarding the release.
* **Release authorization date**: This is the date when the release was authorized, please select the correct date.
* **Release authorization time**: This is the time when the release was authorized, please select the correct time.
* **Release status**: This is the status of the release, please select one of the provided options.
* **Release status other**: This is an optional field for any additional comments regarding the release status.
* **Release notes**: This is an optional field for any additional comments or information regarding the release.
* **Submitted by**: This is the name of the person who submitted the form, please fill in their actual name.
* **Submitted by employee ID**: This is the ID of the employee who submitted the form, please fill in their actual ID.

Note: Ensure all fields are filled and submitted accurately before submitting the form. If you have any doubts or concerns, please contact your HR representative.
