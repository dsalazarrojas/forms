# Toy Collection Release Form - Help Guide

## Purpose
The Toy Collection Release Form is a document used to release a toy collection to a group of people. It provides necessary information about the collection and the release process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the fields as needed:
	* "What is the name of the toy?" (Field 1: release_form)
	* Choose the group the toy belongs to: (Field 2: release_group)
	* Select the release date and time (Field 3: release_date and Field 4: release_time)
	* Provide the reason for releasing the toy (Field 5: release_reason)
	* Enter the donor's email (Field 6: donor_email)
	* Enter the collector's phone number (Field 7: collector_phone)
	* Add any notes about the release (Field 8: notes)
	* Identify yourself as the submitter (Field 9: submitters)
	* Select any additional groups the toy is a member of (Field 10: collector_group)
2. Review and submit the form to complete the release process.

## Field-by-Field Explanation
* **What is the name of the toy? (Field 1: release_form)**: Enter the name of the toy being released.
* **What group is the toy in? (Field 2: release_group)**: Select the group the toy belongs to, such as Donors, Collectors, Clubs, or Community Groups.
* **Release Date (Field 3: release_date)**: Select the date the toy is to be released.
* **Release Time (Field 4: release_time)**: Select the time the toy is to be released.
* **Reason for Release (Field 5: release_reason)**: Provide a brief explanation for why the toy is being released.
* **Donor Email (Field 6: donor_email)**: Enter the email address of the person or organization providing the toy.
* **Collector Phone (Field 7: collector_phone)**: Enter the phone number of the person or organization adopting the toy.
* **Notes (Field 8: notes)**: Add any additional comments or information about the release.
* **Submitter (Field 9: submitters)**: Identify yourself as the person submitting the form.
* **Collector Group (Field 10: collector_group)**: Select any additional groups the toy is a member of, such as other Donors or Clubs.

## Tips
* Make sure to fill in all required fields to complete the form.
* Double-check the release date and time to ensure accuracy.
* Be sure to provide clear and concise information for the reason for release.
* Review the form carefully before submitting to ensure all information is accurate.
