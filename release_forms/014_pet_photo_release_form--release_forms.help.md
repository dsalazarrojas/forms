# Pet Photo Release Form - Help Guide

## Purpose
The Pet Photo Release Form is used to document the details of each photo taken of a pet, including the pet's owner, photo metadata, and release status.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the pet's owner's name in the `pet_owner_name` field.
2. Enter the pet's name in the `pet_name` field.
3. Enter the pet's owner's email address in the `owner_email` field.
4. Select the date the photo was taken using the `photo_taken` field.
5. Select the date the photo was uploaded using the `photo_uploaded` field.
6. Enter the photo details in the `photographer_info` field.
7. Select the release date for the photo using the `release_date` field.
8. Choose the photo rights using the `photo_rights` field (select one or more options).
9. Choose the person who signed the release using the `signed_by` field (select one option).
10. Add any additional notes about the photo in the `photo_notes` field.

## Field-by-Field Explanation

* **pet_photo_release_form**: This field is not directly editable by the user.
* **pet_owner_name**: Enter the name of the pet's owner.
* **pet_name**: Enter the name of the pet.
* **owner_email**: Enter the email address of the pet's owner.
* **photo_taken**: Select the date the photo was taken.
* **photo_uploaded**: Select the date the photo was uploaded.
* **photographer_info**: Enter information about the photographer who took the photo.
* **release_date**: Select the date the photo was released.
* **photo_rights**: Choose the photo rights (select one or more options):
	+ Pet Photos
	+ Photo Album
	+ Online Use
	+ Reproduction
	+ Other
* **signed_by**: Choose the person who signed the release (select one option):
	+ Owner
	+ Parent
	+ Guardian
	+ Other
* **signature**: This field is not editable by the user.
* **release_version**: Enter the release version number.
* **pet_breed**: Enter the breed of the pet.
* **photo_location**: Enter the location where the photo was taken.
* **photo_taken_at**: Select the time the photo was taken.
* **photo_uploaded_at**: Select the time the photo was uploaded.
* **photo_file_name**: Enter the file name of the photo.
* **photo_size**: Enter the size of the photo in bytes.
* **photo_orientation**: Enter the orientation of the photo.
* **photo_exposure**: Enter the exposure of the photo.
* **photo_camera_model**: Enter the camera model used to take the photo.
* **photo_lens**: Enter the lens used to take the photo.
* **photo_iso**: Enter the ISO setting used to take the photo.
* **photo_flash**: Enter if flash was used to take the photo.
* **photo_notes**: Add any additional notes about the photo.
