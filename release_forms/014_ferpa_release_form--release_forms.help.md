# Ferpa Release Form - Help Guide
## Purpose
The Ferpa Release Form is a form used to collect information for a release or discharge from a service. This form is typically used for administrative purposes, such as releasing a user's account or service.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required and optional fields as prompted.
2. Make sure to review the form carefully to ensure all required fields are completed.
3. Submit the form once you have finished.

## Field-by-Field Explanation

* **Release Form** (`release_form`, select_one, required/optional): Choose the release or discharge option that best applies to your situation. Select "Yes" to confirm the release or discharge.
* **Release Form Name** (`release_form_name`, text, required/optional): Enter the name associated with the release or discharge.
* **Release Form Date** (`release_form_date`, date, required/optional): Enter the date of the release or discharge.
* **Release Form Time** (`release_form_time`, time, required/optional): Enter the time of the release or discharge.
* **Email** (`release_form_email`, email, required/optional): Enter the email address associated with the release or discharge.
* **Phone Number** (`release_form_phone`, text, required/optional): Enter the phone number associated with the release or discharge.
* **Notes** (`release_form_notes`, note, required/optional): Enter any additional information or notes about the release or discharge.
* **Release/Discharge** (`release_form_release`, select_one, required/optional): Confirm the release or discharge by selecting "Yes".
