# document_release_authorization_form - Help Guide
## Purpose
The document release authorization form is used to obtain approval for releasing sensitive or confidential documents to the public or otherwise. This form ensures that only authorized personnel can verify and approve the release of documents to maintain data security and compliance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the document in the `Document Title` field.
2. Fill in your organization's name in the `Organization Name` field.
3. Select the document type from the dropdown list.
4. Provide a brief description of the document in the `Document Description` field.
5. Enter the name of the person authorizing the release in the `Authorized Person` field.
6. Enter the email address of the person authorizing the release in the `Authorized Person Email` field.
7. Choose the release date from the calendar.
8. (Optional) Select the reason for the release in the `Reason for Release` field.
9. Indicate if the client has confirmed the release in the `Client Confirmation` field.
10. Add any optional notes about the release in the `Notes` field.
11. Enter your name in the `Submitted By` field.
12. Enter your title in the `Submitted By Title` field.
13. Enter your email address in the `Submitted By Email` field.
14. Select the category of the document.
15. Choose the status of the document (e.g., Open, Closed, Approved, Rejected).
16. Enter the date the form was submitted.

## Field-by-Field Explanation

* **Document Title** (`form_title`, text, required): Enter the title of the document being released.
* **Organization Name** (`organization_name`, text, required): Enter the name of your organization.
* **Document Type** (`document_type`, select_one, required): Select the type of document (e.g., Confidential, Public).
* **Document Description** (`document_description`, text, required): Briefly describe the document being released.
* **Authorized Person** (`authorized_person`, text, required): Enter the name of the person authorizing the release.
* **Authorized Person Email** (`authorized_person_email`, email, required): Enter the email address of the person authorizing the release.
* **Release Date** (`release_date`, date, required): Choose the date of intended release.
* **Release Time** (`release_time`, time, not specified): Not currently used (optional).
* **Reason for Release** (`reason_for_release`, text, optional): Provide a reason for releasing the document (if applicable).
* **Client Confirmation** (`client_confirmation`, select_multiple, optional): Select whether the client has confirmed the release (e.g., Yes, No).
* **Notes** (`notes`, note, optional): Add any comments or notes about the release.
* **Submitted By** (`submitted_by`, text, required): Enter your name.
* **Submitted By Title** (`submitted_by_title`, text, required): Enter your title.
* **Submitted By Email** (`submitted_by_email`, email, required): Enter your email address.
* **Submitted On** (`submitted_on`, date, required): Enter the date the form was submitted.
* **Document ID** (`document_id`, number, not specified): Not currently used (optional).
* **Category** (`category`, text, not specified): Not currently used (optional).
* **Status** (`status`, select_one, not specified): Select the status of the document (e.g., Open, Closed, Approved, Rejected).
* **Created By** (`created_by`, text, not specified): Not currently used (optional).
* **Updated On** (`updated_on`, date, not specified): Not currently used (optional).
* **Submitted By IP** (`submitted_by_ip`, text, not specified): Not currently used (optional).
* **Submitted By Browser** (`submitted_by_browser`, text, not specified): Not currently used (optional).
* **Document Name** (`document_name`, text, not specified): Not currently used (optional).
* **Form ID** (`form_id`, number, not specified): Not currently used (optional).
* **User** (`user`, text, not specified): Not currently used (optional).
