# shutterslap_model_release - Help Guide
## Purpose
The shutterslap_model_release form is used to collect model release and property release information for shutterstock models. Please fill out the form for each release type accordingly to ensure accurate and complete release data.

## How To Complete This Form
To complete this form, simply follow these steps:

1.  Enter the Release Name in the "Release Name" field. This field is optional and can be used for additional reference or description.
2.  Select the release date from the calendar or enter it manually in the "Release Date" field.
3.  Enter the name of the photographer or model in the "Photographer Credit" field, or type 'n/a' if not applicable.
4.  Enter the location where the photos were taken in the "Location" field.
5.  Enter the name of the contact person in the "Contact Name" field.
6.  Enter the contact email in the "Contact Email" field.
7.  Enter the contact phone number in the "Contact Phone" field.
8.  Select the release type for the model in the "Model Release" field (Model, Property of the Artist, or Artist's Agent).
9.  Select the release type for the property in the "Property Release" field (Property of the Artist or Property of the Client).
10.  Enter the name of the right manager in the "Right Manager" field.
11.  Enter the phone number of the right manager in the "Right Manager Phone" field.
12.  Enter the email of the right manager in the "Right Manager Email" field.
13.  Enter the name of the client in the "Client Name" field.
14.  Enter the client contact person in the "Client Contact" field.

## Field-by-Field Explanation
*   **Release Name**: Enter a brief description or reference for this release. (Optional)
*   **Release Date**: Select the date of the release. This could be the date the release was signed or agreed upon.
*   **Photographer Credit**: Enter the name of the photographer or model, or type 'n/a' if not applicable.
*   **Location**: Enter the location where the photos were taken.
*   **Contact Name**: Enter the name of the contact person.
*   **Contact Email**: Enter the email of the contact person.
*   **Contact Phone**: Enter the phone number of the contact person.
*   **Photographer Credit**: Enter the name of the photographer or model, or type 'n/a' if not applicable.
*   **Location**: Enter the location where the photos were taken.
*   **Model Release**: Select the type of model release:
    *   Model: Release granted by the model.
    *   Property of the Artist: Release granted by the artist for the model's property.
    *   Artist's Agent: Release granted by the model's agent.
*   **Property Release**: Select the type of property release:
    *   Property of the Artist: Release granted by the artist for the property.
    *   Property of the Client: Release granted by the client for the property.
*   **Right Manager**: Enter the name of the right manager.
*   **Right Manager Phone**: Enter the phone number of the right manager.
*   **Right Manager Email**: Enter the email of the right manager.
*   **Client Name**: Enter the name of the client.
*   **Client Contact**: Enter the client contact person.

By following this guide, you should be able to complete the form accurately and efficiently, ensuring that all required information is included. If you have any questions or concerns, please contact support for further assistance.
