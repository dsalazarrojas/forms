# dog_boarding_release_form - Help Guide
## Purpose
The dog_boarding_release_form is a form used to release a dog from boarding. It is a mandatory form for authorized users to provide information about the dog's category, description, output file, form ID, and any additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the dog being released.
2. Provide a brief description of the dog and the reason for release.
3. Indicate whether an assigned tool was used for the boarding.
4. Upload the output file generated during the boarding process.
5. Enter the form ID, which can be obtained from the system or a previous form submission.
6. Add any additional notes about the release process.

## Field-by-Field Explanation
- **Title** (`title`, `text`, required):
  Enter a brief title to identify this dog's release form.
- **Category** (`category`, `select_one`, required):
  Select the category of the dog from the provided options.
- **Description** (`description`, `text`, required):
  Enter a brief description of the dog and the reason for release.
- **Assigned Tool** (`assigned_tool`, `select_one`, required):
  Indicate whether an assigned tool was used during the boarding process.
- **Output File** (`output_file`, `text`, required):
  Upload the output file generated during the boarding process.
- **Form IDs** (`form_ids`, `number`, required):
  Enter the form ID, which can be obtained from the system or a previous form submission.
- **Note** (`note`, `note`, optional):
  Add any additional notes about the release process.

## Tips

* Make sure to select the correct category for the dog being released.
* Ensure that the output file and form ID are accurate and complete.
* Provide clear and concise descriptions to ensure the release process is properly documented.
