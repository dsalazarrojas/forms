# Fashion Brand Footage Release Form - Help Guide
## Purpose
This form is used to collect information about the usage of footage featuring a fashion brand. It is essential to ensure that the model releases their rights and agrees to the terms of use of their image. Please fill out this form to demonstrate that you have obtained the necessary releases and understand the usage terms.

## How To Complete This Form

To complete this form, follow these steps:

*   Start by reviewing the form carefully and make sure you understand the required fields.
*   If any required fields are missing or not applicable, make a note of this in the form and submit it.

## Field-by-Field Explanation

*   *Model Release* (id: 1, required: false):
    + This field is used to determine whether or not you need to obtain a model release.
*   *Usage Agreement* (id: 2, required: false):
    + This field is used to record any additional agreements or stipulations for usage of the model's image.
*   *Project Details* (id: 3, required: true):
    + Select one of the available options to describe the project type. This will help the brand to categorize and process your request.
*   *Usage Purposes* (id: 4, required: true):
    + Select all applicable purposes for which the image will be used.
*   *Usage Duration* (id: 5, required: false):
    + If you're aware of it, please fill out the date the model's image will be used until.
*   *Usage Exposure* (id: 6, required: false):
    + If you're aware of it, please describe where the image will be published or used.
*   *Model's Name* (id: 7, required: false):
    + Please fill out the name of the model featured in the image.
*   *Model's Agreement* (id: 8, required: false):
    + Determine whether or not the model agrees to the terms of use.
*   *Image Description* (id: 9, required: false):
    + Provide a brief description of the image to help the brand process your request.
