This help guide is intended for users who need to submit a Video Release Consent Letter. This form is not intended for editing existing releases, so it's a "create" form. To ensure the correct fields are filled out, review this guide carefully.

## Video Release Consent Letter - Help Guide

## Purpose
The Video Release Consent Letter is a document that captures the essential information needed to release content. It helps in ensuring that the content is released in a way that respects the rights and interests of all parties involved. This form is typically used for creating new releases.

## How To Complete This Form
To complete this form, follow these steps:

1.  In the "Category" field, select the relevant category for the release (e.g., "Release Forms").
2.  In the "Description" field, enter a brief description of the release.
3.  In the "Form ID" field, enter the unique ID of the form (if applicable).
4.  In the "Assigned Tool" field, select the tool that will be used for the release (e.g., "chatjimmy").
5.  In the "Output File" field, enter the file name for the release (if applicable).
6.  In the "Assigned To" field, select the person(s) responsible for the release (e.g., "John", "Jane", "Bob").
7.  In the "Created By" field, enter the name of the person creating the form.
8.  In the "Date Created" field, select the date the form was created.
9.  In the "Date Updated" field, select the date the form was last updated (if applicable).
10. In the "Form Title" field, enter the title of the form (if applicable).
11. In the "Form Description" field, enter a brief description of the form (if applicable).
12. In the "Form Version" field, enter the version of the form (if applicable).

## Field-by-Field Explanation
- **Category** (`Category`, `select_one`, required: false): Select the category for the release (e.g., "Release Forms").
- **Description** (`Description`, `text`, required: false): Enter a brief description of the release.
- **Form ID** (`Form ID`, `number`, required: false): Enter the unique ID of the form (if applicable).
- **Assigned Tool** (`Assigned Tool`, `select_one`, required: true): Select the tool that will be used for the release (e.g., "chatjimmy").
- **Output File** (`Output File`, `text`, required: false): Enter the file name for the release (if applicable).
- **Assigned To** (`Assigned To`, `select_multiple`, required: false): Select the person(s) responsible for the release (e.g., "John", "Jane", "Bob").
- **Created By** (`Created By`, `text`, required: false): Enter the name of the person creating the form.
- **Date Created** (`Date Created`, `date`, required: false): Select the date the form was created.
- **Date Updated** (`Date Updated`, `date`, required: false): Select the date the form was last updated (if applicable).
- **Form Title** (`Form Title`, `text`, required: false): Enter the title of the form (if applicable).
- **Form Description** (`Form Description`, `text`, required: false): Enter a brief description of the form (if applicable).
- **Form Version** (`Form Version`, `text`, required: false): Enter the version of the form (if applicable).
