# playwright_script_reproduction_release_form - Help Guide
## Purpose
This form is used to track and release information about a production or script reproduction.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, which are marked with an asterisk (\*) in the label.
2. For the "Permission Level" field, select one of the options: Basic, Premium, or Custom.
3. For the "Script Reproduction" field, select "Yes" or "No" depending on whether the script reproduction has been completed.
4. For the "Review Required" field, select "Yes" or "No" depending on whether a review is required.
5. For the "Approval Required" field, select "Yes" or "No" depending on whether approval is required.
6. For the "Production Manager" field, enter the name of the production manager.
7. For the "Production Manager Phone", "Production Manager Email", and "Production Manager Notes" fields, enter the production manager's contact information and any additional notes.
8. Review the form for any errors or missing information before submitting.

## Field-by-Field Explanation

* **Playwright Script ID** (1, number, required): Enter the ID of the script reproduction.
* **Production Company** (2, text, required): Enter the name of the production company.
* **Production Title** (3, text, required): Enter the title of the production.
* **Script Version** (4, text, required): Enter the version of the script being reproduced.
* **Permission Level** (5, select_one, required): Select the level of permission required for the script reproduction: Basic, Premium, or Custom.
* **Performance Dates** (6, date, required): Enter the dates of the performance or release of the production.
* **Production Location** (7, text, required): Enter the location of the production.
* **Production Notes** (8, text, required): Enter any additional notes about the production.
* **Email Address** (9, email, required): Enter the email address of the production manager.
* **Phone Number** (10, text, optional): Enter the phone number of the production manager (if applicable).
* **Additional Notes** (11, text, optional): Enter any additional notes about the production.
* **Script Reproduction** (12, select_multiple, required): Select "Yes" or "No" to indicate whether the script reproduction has been completed.
* **Reproduction Notes** (13, text, optional): Enter any notes about the reproduction process.
* **Production Type** (14, select_one, required): Select the type of production: Theater, School, or Production Organization.
* **Production Status** (15, select_one, required): Select the status of the production: Planned, In Progress, or Completed.
* **Review Required** (16, select_one, required): Select "Yes" or "No" to indicate whether a review is required.
* **Review Type** (17, text, required): Enter the type of review required.
* **Review Notes** (18, text, optional): Enter any notes about the review process.
* **Approval Required** (19, select_one, required): Select "Yes" or "No" to indicate whether approval is required.
* **Approval Notes** (20, text, optional): Enter any notes about the approval process.
* **Production Manager** (21, text, required): Enter the name of the production manager.
* **Production Manager Phone** (22, text, optional): Enter the production manager's phone number (if applicable).
* **Production Manager Email** (23, text, optional): Enter the production manager's email address (if applicable).
* **Production Manager Notes** (24, text, optional): Enter any additional notes from the production manager.
* **Created By** (25, text, required): Enter the name or ID of the person who created this form.

Please note that this form is required for script reproductions, and all fields marked as required must be filled in order to complete the form.
