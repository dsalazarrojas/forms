# Webinar Content Release Form - Help Guide
## Purpose
The Webinar Content Release Form is a tool for creators to release their webinar content. It helps gather necessary information and ensure they understand the terms and conditions related to the release.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Release Form Title** in the title field.
2. Select the **Release Date** of your webinar content.
3. Provide a brief **Release Description** of the content being released.
4. List the **Contributors** who contributed to the webinar (comma-separated).
5. Check the **Permission** box to agree to the release form conditions.
6. Check the **Agreement** box to confirm you have read and agree to the release form conditions.
7. If required, attach a Non Disclosure Agreement (NDA) document.

## Field-by-Field Explanation

* **Release Form Title**: Enter a title for the release form.
	+ Type: Text
	+ Required: Not required
* **Release Date**: Select the date the content will be released.
	+ Type: Date
	+ Required: Not required
* **Release Description**: Briefly describe the content being released.
	+ Type: Text
	+ Required: Not required
* **Contributors**: List the contributors to the webinar content (comma-separated).
	+ Type: Text
	+ Required: Not required
* **Permission**: Check to agree to the release form conditions.
	+ Type: Select One
	+ Required: Not required (However, it's likely required for the form to be valid.)
* **Agreement**: Check to confirm you have read and agree to the release form conditions.
	+ Type: Select One
	+ Required: Not required (However, it's likely required for the form to be valid.)
* **Non Disclosure Agreement (NDA)**: Attach an NDA document if required.
	+ Type: Text
	+ Required: Not required
