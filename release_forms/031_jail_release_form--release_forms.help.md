# Jail Release Form - Help Guide

## Purpose
The purpose of this form is to process a jail release request for a specific individual. It is used within a law enforcement or corrections facility to manage releases from jail.

## How To Complete This Form

To fill out this form, please follow these steps:

1. Fill in the release date in the date format (DD/MM/YYYY).
2. Enter the name of the facility where the individual is currently being held.
3. Select a reason for the release from the available options.
4. Fill in the contact name and address of the person or organization responsible for the release.
5. Provide the contact phone number and email address for the release contact.
6. Enter the facility ID number.
7. Fill in the facility code (if applicable).
8. Fill in the release date and time.
9. Enter the contact email address.
10. Sign off with your name (not required but recommended for tracking purposes).
