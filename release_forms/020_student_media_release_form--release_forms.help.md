# Student Media Release Form - Help Guide
## Purpose
The Student Media Release Form is used to obtain consent from students for the use of their image, video, or audio in media production and to collect contact information for schools and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1.  Choose the correct response for each question.
2.  Fill out the form completely and accurately.

## Field-by-Field Explanation

*   **Student** (`student_media_release_form_1`, Select One, required: false): This field asks whether the student has given permission for their media to be released. Please select 'Yes' if you grant permission, and 'No' if you do not.
*   **Parent** (`student_media_release_form_2`, Select Multiple, required: false): This field asks for the contact information of the parent or guardian of the student. Please select all applicable options.
*   **School** (`student_media_release_form_3`, Text, required: false): Please enter the name of the school where the student is enrolled.
*   **Student Images** (`student_media_release_form_4`, Text, required: false): This field is intended for uploading or providing information about images of the student.
*   **Student Names** (`student_media_release_form_5`, Text, required: false): Please enter the name of the student.
*   **School Images** (`student_media_release_form_6`, Text, required: false): This field is intended for uploading or providing information about images of the school.
*   **Student Names** (`student_media_release_form_7`, Text, required: false): This field is intended for the same purpose as `student_media_release_form_5` but seems to be redundant.
*   **School** (`student_media_release_form_8`, Text, required: false): This field is intended for the same purpose as `student_media_release_form_3` but seems to be redundant.
*   **School Website** (`student_media_release_form_9`, Text, required: false): Please enter the website address of the school.
*   **Print** (`student_media_release_form_10`, Text, required: false): Please specify if you would like media to be released in print.
*   **Electronic** (`student_media_release_form_11`, Text, required: false): Please specify if you would like media to be released in electronic format.
*   **Both** (`student_media_release_form_12`, Select One, required: false): Please select 'Yes' if you would like media to be released in both print and electronic formats.
*   **Other** (`student_media_release_form_13`, Text, required: false): Please describe any other specific format or method for releasing media you would like to use.
