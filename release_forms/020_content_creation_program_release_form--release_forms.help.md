# Content Creation Program Release Form - Help Guide
## Purpose
The Content Creation Program Release Form is used to capture participant information and obtain releases and consents for various types of content creation programs.

## How to Complete This Form

To complete this form, you will need to fill out the following fields:

### 1. Participant Full Name
* **Participant Full Name** (`participant_full_name`, text, required)
  * Enter the legal first and last name of the participant.

### 2. Participant Email
* **Participant Email** (`participant_email`, email, required)
  * Enter the email address for contact.

### 3. Participant Phone (optional)
* **Participant Phone** (`participant_phone`, text, optional)
  * Enter the contact phone number.

### 4. Date of Birth
* **Date of Birth** (`date_of_birth`, date, required)
  * Enter the participant's date of birth in MM/DD/YYYY format.

### 5. Program Name
* **Program Name** (`program_name`, text, required)
  * Enter the name of the content creation program.

### 6. Program Dates
* **Program Dates** (`program_dates`, text, required)
  * Enter the dates of participation.

### 7. Organization Name
* **Organization Name** (`organization_name`, text, required)
  * Enter the name of the organizing entity.

### 8. Release Type
* **Release Type** (`release_type`, select_one, required)
  * Select the type of release you are granting, such as Full Media Release, Limited Media Release, or Educational Use Only.

### 9. Photo Consent
* **Photo Consent** (`photo_consent`, select_one, required)
  * If you consent to photographs being taken and used, select "Yes, I Consent".

### 10. Video Consent
* **Video Consent** (`video_consent`, select_one, required)
  * If you consent to video recordings being taken and used, select "Yes, I Consent".

### 11. Audio Consent
* **Audio Consent** (`audio_consent`, select_one, required)
  * If you consent to audio recordings being taken and used, select "Yes, I Consent".

### 12. Name Usage Consent
* **Name Usage Consent** (`name_usage_consent`, select_one, required)
  * If you consent to your name being used in materials, select "Yes, I Consent".

### 13. Testimonial Consent
* **Testimonial Consent** (`testimonial_consent`, select_one, required)
  * If you consent to your testimonials being used, select "Yes, I Consent".

### 14. Usage Channels
* **Usage Channels** (`usage_channels`, select_multiple, required)
  * Select where the content can be used, such as Website, Social Media, Print Materials, etc.

### 15. Usage Duration
* **Usage Duration** (`usage_duration`, select_one, required)
  * Select how long the content can be used, such as 1 Year, 3 Years, etc.

### 16. Geographic Scope
* **Geographic Scope** (`geographic_scope`, select_one, required)
  * Select where the content can be used, such as Local Only, National, International, etc.

### 17. Compensation Received
* **Compensation Received** (`compensation_received`, select_one, required)
  * If you received compensation for participation, select "True". If not, select "False".

### 18. Compensation Details
* **Compensation Details** (`compensation_details`, text, optional)
  * If you received compensation, describe the amount and terms.

### 19. Is Participant a Minor?
* **Is Participant a Minor?** (`minor_participant`, select_one, required)
  * If the participant is under 18, select "True". If not, select "False".

### 20. Parent or Guardian Name
* **Parent or Guardian Name** (`parent_guardian_name`, text, optional)
  * If the participant is a minor, enter the name of the parent or guardian.

### 21. Parent or Guardian Signature Date
* **Parent or Guardian Signature Date** (`parent_guardian_signature_date`, date, optional)
  * If the participant is a minor, enter the date the parent or guardian signed.

### 22. Release Effective Date
* **Release Effective Date** (`release_effective_date`, date, required)
  * Enter the date this release takes effect.

### 23. Additional Permissions
* **Additional Permissions** (`additional_permissions`, text, optional)
  * Enter any additional permissions granted.

### 24. Revocation Terms
* **Revocation Terms** (`revocation_terms`, text, optional)
  * Understand the terms for revoking this release.

### 25. Signature Confirmation
* **Signature Confirmation** (`signature_confirmation`, select_one, required)
  * Confirm that you have read and agree to this release.

## Tips

* Ensure that you are filling out the form for the correct participant.
* Review the form carefully before submitting.
* If the participant is a minor, additional information is required to be filled out.
* Ensure that all required fields are completed.
* If you are unsure about any field, please ask for clarification.
