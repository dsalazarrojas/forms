# Pharmaceutical Drug Release Form - Help Guide
## Purpose
The Pharmaceutical Drug Release Form is a document used to record the release of pharmaceutical products from a pharmacy. This form is used to document the details of the release, including the patient's information, medication information, and release data.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the general information section with the relevant details.
2. Enter the patient's information, including their name, birthdate (if known), and medication list.
3. Provide the medication information, including the medication name and release reason.
4. Enter the prescriber's information, including their name, title, and contact details.
5. Select the release status and release date.
6. Add any release comments or notes.
7. Review and submit the form.

## Field-by-Field Explanation
* **General Info** (Text, Optional): Enter any additional general information about the release.
* **Patient Info** (Text, Optional): Enter the patient's name and birthdate (if known).
* **Medication Info** (Text, Optional): Enter the medication name and release reason.
* **Release Data** (Text, Optional): Enter any additional release data.
* **Prescriber Info** (Text, Optional): Enter the prescriber's name, title, and contact details.
* **Signature** (Text, Optional): Enter the prescriber's signature.
* **Release Date** (Date, Optional): Enter the release date.
* **Release Time** (Time, Optional): Enter the release time.
* **Release Status** (Select One, Optional): Select the release status (Pending, Released, Expired).
* **Release Reason** (Select Multiple, Optional): Select the reason for releasing the medication (Prescription refill, Patient request, Clinical update).
* **Prescriber Name** (Text, Optional): Enter the prescriber's name.
* **Prescriber Title** (Text, Optional): Enter the prescriber's title.
* **Pharmacy Location** (Text, Optional): Enter the pharmacy location.
* **Release By** (Text, Optional): Enter the person or department releasing the medication.
* **Release Notes** (Text, Optional): Enter any release notes or comments.
* **Release Comments** (Text, Optional): Enter any additional release comments.
* **Prescriber Email** (Email, Optional): Enter the prescriber's email address.
* **Prescriber Phone** (Text, Optional): Enter the prescriber's phone number.
* **Patient Name** (Text, Optional): Enter the patient's name.
* **Patient Birthdate** (Date, Optional): Enter the patient's birthdate.
* **Patient Birthdate Optional** (Date, Optional): Enter the patient's birthdate (if not known).
* **Prescriber Address** (Text, Optional): Enter the prescriber's address.
* **Prescriber License Number** (Text, Optional): Enter the prescriber's license number.
* **Patient Medication List** (Select Multiple, Optional): Select whether the patient has a medication list.
* **Release Status Date** (Date, Optional): Enter the release status date.
* **Release Status** (Select One, Optional): Select the release status (Pending, Released, Expired).
