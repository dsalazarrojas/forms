# Parent Guardian Publicity Authorization And Release Form - Help Guide

## Purpose
This form is for parents or guardians to grant permission for the use of their child's image or likeness in a project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the title of the project, which is the name of the project that will be using your child's image or likeness.
2. Select the category of the project (e.g. "Release Forms" or "Other").
3. Provide a brief description of the project, explaining why and how your child's image or likeness will be used.
4. Specify the tool or platform associated with this project (e.g. "chatjimmy" or "Other").
5. If you're using a different tool or platform, select "Other" and specify the name of the tool or platform.
6. Upload the output file, which is the final document that will be used to record the permission.

## Field-by-Field Explanation
* **Parent Guardian Publicity Authorization And Release Form** (`form_title`, text, required): Enter the title of the project that will be using your child's image or likeness.
* **Category** (`category`, select_one, required): Select the category of the project (e.g. "Release Forms" or "Other").
* **Description** (`description`, text, required): Provide a brief description of the project, explaining why and how your child's image or likeness will be used.
* **A parent/guardian publicity authorization and release form is used by producers to get parental or guardian consent on the use of their child in a project.** (`form_description`, text, required): This field is a pre-filled description of the form's purpose. It's not required to be filled out.
* **Assigned Tool** (`assigned_tool`, text, required): Specify the tool or platform associated with this project (e.g. "chatjimmy" or "Other").
* **Assigned Tool** (`assigned_tool`, select_multiple, optional): If you're using a different tool or platform, select "Other" and specify the name of the tool or platform.
* **Output File** (`output_file`, text, required): Upload the output file, which is the final document that will be used to record the permission.

## Tips
* Make sure to fill out the form accurately and completely.
* Ensure that you understand the project's purpose and how your child's image or likeness will be used.
* If you're unsure about any of the fields, contact the production team for assistance.
