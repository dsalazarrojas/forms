# Inked HempQueens Photo Release - Help Guide

## Purpose
The Inked HempQueens Photo Release form is a legal document that grants permission to use an individual's image. This form is used to gather information for the purpose of obtaining a photo release from a model or photographer, and to document the details of the release.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the correct category for the form. If the form is for a photo release, choose "Release Forms". If it is for a different purpose, choose "Other".
2. Enter a brief description of the photograph or image being released.
3. Enter the output filename that will be used for the released file.
4. Enter your name and contact information (email and phone number).
5. Enter the date the photograph was taken.
6. Enter the name of the photographer who captured the image.
7. Enter the photographer's license number (if applicable).
8. Enter the publication title and issue (if it's a series).
9. Enter the publication URL (if applicable).
10. Select the copyright ownership.
11. Enter the publication date.
12. Enter the publication period.
13. Enter any additional notes about the release.
14. Select the type of publication (print or web).
15. If necessary, enter the release version.
16. Enter any additional photographer notes.
17. Enter the photographer's agreement.
18. Enter whether the agreement has been signed.
19. Enter the model's release details.
20. Enter the model's release date.

## Field-by-Field Explanation

* **Category** (`category`, `select_one`, required): Select the correct category for the form. If it's for a photo release, choose "Release Forms". If it's for a different purpose, choose "Other".
* **Form Title** (`form_title`, `text`, optional): Enter a brief title for the form.
* **Description** (`description`, `text`, required): Enter a brief description of the photograph or image being released.
* **Output Filename** (`output_filename`, `text`, required): Enter the filename that will be used for the released file.
* **Author** (`author`, `text`, required): Enter your name and contact information (email and phone number).
* **Email** (`email`, `email`, optional): Enter your email address.
* **Phone** (`phone`, `text`, optional): Enter your phone number.
* **Date Taken** (`date_taken`, `date`, required): Enter the date the photograph was taken.
* **Photographer Credit** (`photographer_credit`, `text`, optional): Enter the name of the photographer who captured the image.
* **Photographer Name** (`photographer_name`, `text`, required): Enter the name of the photographer who captured the image.
* **Photographer License Number** (`photographer_license`, `number`, optional): Enter the photographer's license number (if applicable).
* **Publication Title** (`publication_title`, `text`, required): Enter the title of the publication that will be using the image.
* **Publication Issue** (`publication_issue`, `text`, optional): Enter the issue number of the publication (if it's a series).
* **Publication URL** (`publication_url`, `text`, optional): Enter the URL of the publication.
* **Copyright Ownership** (`copyright_ownership`, `select_one`, required): Select the correct copyright ownership. If it's the photographer, choose "Photographer". If it's the model, choose "Model". If it's another party, choose "Other".
* **Publication Date** (`publication_date`, `date`, optional): Enter the date of the publication.
* **Publication Period** (`publication_period`, `time`, optional): Enter the publication period.
* **Notes** (`notes`, `note`, optional): Enter any additional notes about the release.
* **Publication Type** (`publication_type`, `select_one`, optional): Select the type of publication. If it's print, choose "Print". If it's web, choose "Web".
* **Release Version** (`release_version`, `text`, optional): Enter the release version (if applicable).
* **Photographer Notes** (`photographer_notes`, `text`, optional): Enter any additional notes from the photographer.
* **Photographer's Agreement** (`photographer_agreement`, `text`, optional): Enter the photographer's agreement.
* **Agreement Signed** (`agreement_signed`, `text`, optional): Enter whether the agreement has been signed.
* **Model Release** (`model_release`, `text`, optional): Enter the model's release details.
* **Model Release Date** (`model_release_date`, `date`, optional): Enter the model's release date.

## Tips

* Make sure to select the correct category and copyright ownership to ensure the form is completed correctly.
* Enter accurate and complete information for all required fields.
* Double-check the date and time of the photograph and release dates to ensure they are correct.
* Enter any additional notes or agreements as necessary.
* Review the form carefully before submission to ensure all fields are complete and accurate.
