# Magazine Press Release Form by Asiah Amsterdamm - Help Guide
## Purpose
This form is designed to create a press release for a magazine's latest issue or other publication. Please use it to provide a short, formal announcement to promote your magazine's content.

## How To Complete This Form

To complete this form, follow the steps below:

1.  Determine if this release is indeed a press release (answer "Yes" or "No" in the "Release Forms" field).
2.  Enter a brief description of the press release in the "Description" field, adhering to the provided hint for guidance on what to write.
3.  Upload any relevant supporting files or images in the "File" field, if applicable.

## Field-by-Field Explanation

*   **Release Forms** (`magazine_press_release_form_category`, select_one, required: false): 
    *   This field is used to indicate whether the form is intended as a press release.
    *   Please answer "Yes" if you are creating a press release, and "No" otherwise.
*   **Description** (`magazine_press_release_form_description`, text, required: false): 
    *   Enter a concise and formal description of the press release, ideally between 100-200 words.
    *   Follow the hint provided for guidance on writing a compelling press release.
*   **File** (`magazine_press_release_form_file`, text, required: false): 
    *   If you have any files (such as images, PDFs, or documents) associated with this press release, upload them here.
    *   This can be used to provide additional context or supporting evidence for the press release.
