# Movie Premiere Release Form - Help Guide
## Purpose
The Movie Premiere Release Form is a document used to gather essential information about movie premieres, such as event details, media permissions, and contact information. This form helps in organizing and managing events efficiently and ensures compliance with media and release regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Event Name** in the text field provided.
2. Select the **Event Date** using the date picker tool.
3. Choose the **Event Time** using the time picker tool.
4. Enter the **Event Location** in the text field.
5. Choose whether **Media Permission** is **True**, **False**, or **Not Applicable**.
6. Enter the **Attendee Count** using numbers only.
7. Enter **Attendee Details**, which can include any relevant information about the attendees, such as names, organizations, and contact details.
8. If applicable, enter any **Special Requests** related to the event.
9. Enter any **Comments** about the event.
10. Enter the **Event ID** as provided by the event organizer.
11. Optionally, enter the **Media Release Form Version** for reference.
12. Select the **Event Type** from the options provided (Movie Premiere, Q&A, Panel Discussion, or Press Conference).
13. Enter the **Contact Email** for the event organizers.
14. Enter the **Contact Phone** for the event organizers.
15. Enter the **Contact Name** for the event organizers.
16. Enter the **Contact Title** for the event organizers.
17. Enter the **Contact Department** for the event organizers.
18. Enter the **Contact Organization** for the event organizers.
19. Enter the **Contact Address** for the event organizers.
20. Finally, enter any additional **Contact Note** regarding the event.

## Field-by-Field Explanation
* **Event Name**: A text field to enter the name of the event.
* **Event Date**: A date picker field to select the date of the event.
* **Event Time**: A time picker field to select the time of the event.
* **Event Location**: A text field to enter the location of the event.
* **Media Permission**: A select-one field with three options: True, False, or Not Applicable.
* **Attendee Count**: A number field to enter the number of attendees.
* **Attendee Details**: A text field to enter any details about the attendees.
* **Special Request**: A text field for any special requests related to the event.
* **Comments**: A text field for any additional comments about the event.
* **Event ID**: A text field to enter the event ID provided by the event organizers.
* **Media Release Form Version**: A text field for reference.
* **Event Type**: A select-multiple field to select the type of event (Movie Premiere, Q&A, Panel Discussion, or Press Conference).
* **Contact Email**: An email field to enter the contact email of the event organizers.
* **Contact Phone**: A text field for the contact phone number.
* **Contact Name**: A text field to enter the contact name of the event organizers.
* **Contact Title**: A text field to enter the contact title of the event organizers.
* **Contact Department**: A text field to enter the contact department of the event organizers.
* **Contact Organization**: A text field to enter the contact organization of the event organizers.
* **Contact Address**: A text field to enter the contact address of the event organizers.
* **Contact Note**: A text field for any additional contact notes regarding the event.

By following this guide, you should be able to complete the movie premiere release form accurately and efficiently. If you have any further questions or concerns, please don't hesitate to contact us.
