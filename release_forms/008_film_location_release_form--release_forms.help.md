# film_location_release_form - Help Guide
## Purpose
The "film_location_release_form" is used to gather information for the release of a film location. This form is used by production companies to provide accurate and relevant information for the release process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all required fields (marked as "required").
2. Select multiple items in fields "Cast", "Crew", and "Equipment" as necessary.
3. Ensure that the date of production and release date are accurate.

## Field-by-Field Explanation
* **Production Company** (production_company, text, required): The name of the production company producing the film.
* **Address** (address, text, required): The address of the production location.
* **City** (city, text, required): The city of the production location.
* **State** (state, select_one, optional): The state where the production location is located. Choose one from the options: CA, FL, NY, TX.
* **Zip** (zip, number, required): The zip code of the production location.
* **Date Of Production** (date_of_production, date, required): The date of production of the film.
* **Release Date** (release_date, date, required): The date of release of the film.
* **Cast** (cast, select_multiple, optional): A list of cast members involved in the production. You can select multiple cast members from the options.
* **Crew** (crew, select_multiple, optional): A list of crew members involved in the production. You can select multiple crew members from the options.
* **Equipment** (equipment, select_multiple, optional): A list of equipment used in the production. You can select multiple equipment from the options.
* **Special Equipment** (special_equipment, select_multiple, optional): A list of special equipment used in the production. You can select multiple special equipment from the options.
* **Notes** (notes, text, optional): Any additional notes about the production.
* **Email** (email, email, required): The email address of the contact person.
* **Phone** (phone, text, required): The phone number of the contact person.
* **Signature** (signature, note, required): The signature of the contact person, usually a manager or supervisor.

## Tips
- Ensure all required fields are filled out.
- Double-check the accuracy of the date of production and release date.
- Use the select_multiple fields to add all relevant information.
- If unsure about any field, please ask your supervisor or contact person for clarification.
