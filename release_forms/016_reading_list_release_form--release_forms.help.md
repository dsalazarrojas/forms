# Reading List Release Form - Help Guide

## Purpose

This form is designed to collect information from educators to release copyrighted materials for reading and educational purposes. The purpose of this form is to provide a clear and efficient way to obtain the necessary permissions and authorizations from educators to use copyrighted materials in a reading list.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Enter the release date and release time of the materials.
3. Provide the educator's name and title.
4. Enter the library name and program name (if applicable).
5. Sign the form with your signature as the educator.
6. If applicable, upload an optional file related to the release.
7. Check any necessary release authorizations for the materials.

## Field-by-Field Explanation

* **Release Form** (`release_form`, text, required): Enter a clear and concise description of the materials to be released, such as "All materials" or "Only for educational purposes".
* **Release Date** (`release_date`, date, required): Enter the date of release, in mm/dd/yyyy format.
* **Release Time** (`release_time`, time, required): Enter the time of release, in 24-hour format (e.g., 14:00 for 2:00 PM).
* **Educator Name** (`educator_name`, text, required): Enter your official name as the educator.
* **Educator Title** (`educator_title`, text, required): Enter your official title as the educator.
* **Library Name** (`library_name`, text, optional): Enter the name of the library or institution you are affiliated with.
* **Program Name** (`program_name`, text, optional): Enter the name of the program you are affiliated with (if applicable).
* **Signature** (`signature`, text, required): Sign the form with your official signature as the educator.
* **File Upload** (`file_upload`, text, optional): Upload any optional file related to the release, such as a PDF or image.
* **Release Authorization** (`release_authorization`, select_multiple, required): Check the checkboxes for the release authorizations needed, such as "Only for educational purposes", "Non-commercial use", "Public Domain", or other options.
