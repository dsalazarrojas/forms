# Earnest Money Release Request Form - Help Guide
## Purpose
The earnest money release request form is a tool for capturing information related to the release of earnest money in real estate or financial transactions.

## How To Complete This Form
1. Provide your seller information, including your name and any other relevant details.
2. Enter the buyer's information, including their name and any other relevant details.
3. Select the type of earnest money release request (e.g., Earnest Money Release Request or Earnest Money Release Request with Signature).
4. Specify the date of the release.
5. Choose the delivery method for the release (e.g., Email, In-person, Mail).
6. Select the signature method for the release (e.g., In-person, Email, Mail).
7. Enter the address to deliver the release to.
8. Provide any additional remarks or comments.
9. Enter the date of the release.

## Field-by-Field Explanation
* **Earnest Money Release Form** (`earnestMoneyReleaseForm`): A text field for the seller to provide any additional information related to the release.
* **Seller Info** (`sellerInfo`): A text field for the seller to enter their information.
* **Buyer Info** (`buyerInfo`): A text field for the buyer to enter their information.
* **Release Type** (`releaseType`): A select field with options to choose the type of earnest money release request (e.g., Earnest Money Release Request or Earnest Money Release Request with Signature).
* **Date Released** (`dateReleased`): A date field to specify the date of the release.
* **Time Released** (`timeReleased`): A time field to specify the time of the release.
* **Delivery Method** (`deliveryMethod`): A select field with options to choose the delivery method (e.g., Email, In-person, Mail).
* **Signature Method** (`signatureMethod`): A select field with options to choose the signature method (e.g., In-person, Email, Mail).
* **Delivery To** (`deliveryTo`): A text field for the address to deliver the release to.
* **Remarks** (`remarks`): A text field for any additional comments or remarks.
* **Release Date** (`releaseDate`): A date field to specify the date of the release.
* **Comments** (`comments`): A text field for any additional comments.

## Tips
- Please ensure that all required fields are completed accurately.
- Review your information carefully before submitting the form.
- If you are unsure about any field, please ask your representative for assistance.
