# newsletter-release-form - Help Guide
## Purpose
The newsletter-release-form is a data collection tool designed to gather relevant information about newsletter releases from end users. This form serves as a means to understand the specific needs and requirements of users, which in turn will help improve the newsletter content and overall release process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have the necessary permissions and access rights to use this form.
2. Select the category of the release (e.g., "Release Forms", "Other Category", or "Some Other Category") to specify the type of content you are releasing.
3. Provide a brief description of the release (less than 250 characters).
4. If applicable, enter the name of the output file associated with this release.
5. Assign the tool used for this release from the provided list of options (e.g., "chatjimmy" or "Some Other Tool 2").

## Field-by-Field Explanation
### 1. **Category** (`category`, select_one, optional)
* The category field allows you to specify the type of content you are releasing. Please select the most relevant option from the list provided.

### 2. **Description** (`description`, text, optional)
* The description field is a brief summary of the release content. Keep it concise, ideally under 250 characters.

### 3. **Output File** (`output_file`, text, optional)
* If an output file is associated with this release, please provide the name of the file.

### 4. **Assigned Tool** (`assigned_tool`, select_one, optional)
* Select the tool used for this release from the provided options. This could be a software, platform, or any other tool used for the release process.

### 5. **Newsletter Release Form** (`title`, text, optional)
* This field is not used for any specific functionality but is a required field for the form's metadata.

Tips:
* If you're unsure about any of the fields, please don't hesitate to reach out to us for assistance.
* Make sure to review and submit the form carefully to avoid errors.
* If you need help with completing this form or have any questions, contact [form@gic.mx](mailto:form@gic.mx).
