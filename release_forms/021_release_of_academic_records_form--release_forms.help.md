# Release Of Academic Records Form - Help Guide

## Purpose
The Release Of Academic Records Form is a tool used to request the release of academic records from the system. This form helps to guide the user in providing accurate and complete information, reducing the likelihood of duplication of effort and ensuring that requests are handled efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct category for the records release from the "category" dropdown menu.
2. Provide a clear description of the records you are requesting in the "description" field.
3. Choose the assigned tool for the records release from the "assigned_tool" dropdown menu.
4. If necessary, enter a unique form ID in the "form_id" field.
5. Optionally, provide a name for the output file in the "output_file" field.

## Field-by-Field Explanation

* **Category** (`category`, select_one, required): Select the category for the records release. This field guides the system to process the request appropriately.
* **Description** (`description`, text, required): Enter a clear description of the records you are requesting.
* **Assigned Tool** (`assigned_tool`, select_one, required): Choose the assigned tool for the records release.
* **Form ID** (`form_id`, number, optional): If necessary, enter a unique form ID for the records release.
* **Output File** (`output_file`, text, optional): Optionally, provide a name for the output file.
