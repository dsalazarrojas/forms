# Concert Press Release Form - Help Guide
## Purpose
This form is designed to collect and organize information about a concert or music-related event for public press releases. It provides a centralized platform for event organizers to provide detailed information about the event, including title, date, time, location, artists, and press release content.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked with *.
2. Provide a brief description of the event in the "Concert Event Details" field.
3. Select the correct music genre from the options provided in the "Genre" field.
4. Upload any relevant media assets, if applicable, in the "Media Assets" field.
5. Indicate whether high or low resolution photos are available in the "Photos Available" field.
6. Check if a video trailer or full performance is available in the "Video Available" field.
7. Provide any additional notes or information in the "Additional Notes for Media" field.

## Field-by-Field Explanation

* **Press Release Information** (`release_information`, note, required: false): This field provides a brief description of the event details.
* **Press Release Title** (`release_title`, text, required: true): Enter a catchy and descriptive title for the press release.
* **Release Date** (`release_date`, date, required: true): Select the date for public distribution.
* **Media Contact Name** (`contact_name`, text, required: true): Enter the name of the person responsible for media inquiries.
* **Media Contact Email** (`contact_email`, email, required: true): Enter the email address for press inquiries.
* **Media Contact Phone** (`contact_phone`, text, required: true): Enter the phone number for urgent inquiries.
* **Concert Event Details** (`concert_details`, note, required: false): Provide a brief description of the concert event.
* **Event Name** (`event_name`, text, required: true): Enter the official concert title.
* **Event Date** (`event_date`, date, required: true): Select the date of the concert.
* **Event Time** (`event_time`, time, required: true): Select the start time of the concert.
* **Venue Name** (`venue_name`, text, required: true): Enter the location of the concert.
* **Venue City and State** (`venue_city`, text, required: true): Enter the city and state or province of the concert location.
* **Performing Artists** (`performing_artists`, text, required: true): List all artists performing at the concert.
* **Music Genre** (`genre`, select_one, required: true): Select the primary music genre of the event.
* **Press Release Content** (`press_content`, note, required: false): Provide the main body of the press release.
* **Main Headline** (`headline`, text, required: true): Enter a catchy headline for media consumption.
* **Subheadline** (`subheadline`, text, required: false): Enter a supporting headline text.
* **Press Release Body** (`body_text`, text, required: true): Enter the full press release content.
* **Featured Quote** (`quote`, text, required: false): Enter a quote from the event organizer or artist.
* **Ticket Information** (`ticket_info`, text, required: true): Enter information on how and where to buy tickets.
* **Media Assets** (`media_assets`, note, required: false): Upload any relevant media files.
* **Press Photos Available** (`photos_available`, select_one, required: false): Indicate whether high or low resolution photos are available.
* **Press Video Available** (`video_available`, select_one, required: false): Indicate whether a video trailer or full performance is available.
* **Social Media Links** (`social_media_links`, text, required: false): Enter relevant social media URLs.
* **Additional Notes for Media** (`additional_notes`, text, required: false): Provide any additional information for media consumption.
