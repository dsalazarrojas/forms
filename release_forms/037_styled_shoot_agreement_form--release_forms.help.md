# Styled Shoot Agreement Form - Help Guide
## Purpose
The Styled Shoot Agreement Form is used to capture information and agreements related to the usage of images from a styled shoot. This form is essential to ensure that all parties involved in the shoot understand and agree on the usage of the images produced.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the photographer participating in the shoot.
2. Enter the email address of the photographer.
3. Enter the name of the planner participating in the shoot.
4. Enter the email address of the planner.
5. Select the venue where the shoot will take place.
6. List the vendors involved in the shoot.
7. Specify how the images will be used (e.g., social media, online, marketing materials, etc.).
8. Select the role of each participant (e.g., photographer, planner, venue, etc.).
9. Provide any additional details about the shoot.
10. Note any specific usage agreements for the images produced.
11. Date and sign the agreement.

## Field-by-Field Explanation

* **styled shoot agreement form**: This is the main text field where you can enter any additional information or agreements related to the shoot.
* **photographer name**: Enter the name of the photographer participating in the shoot.
* **photographer email**: Enter the email address of the photographer.
* **planner name**: Enter the name of the planner participating in the shoot.
* **planner email**: Enter the email address of the planner.
* **venue**: Select the location where the shoot will take place.
* **vendors**: List the vendors involved in the shoot.
* **image use**: Specify how the images will be used (e.g., social media, online, marketing materials, etc.).
	+ Select one or more options from the list provided.
* **role**: Select the role of each participant (e.g., photographer, planner, venue, etc.).
	+ Select one option from the list provided.
* **shoot details**: Enter any additional details about the shoot.
* **image usage**: This is a note field where you can enter any specific usage agreements for the images produced.
* **signed on**: Date and sign the agreement.
* **signed by**: Enter the name of the person signing the agreement.
