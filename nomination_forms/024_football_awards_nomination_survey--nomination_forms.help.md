# football_awards_nomination_survey - Help Guide
## Purpose
This form is used to collect information about a sports player's nomination for an award or recognition.

## How To Complete This Form

* To complete this form, select the relevant options for each field as required.
* Make sure to enter accurate and complete information for each field.

## Field-by-Field Explanation

* **Nomination Form**: Select whether the player is being nominated (yes or no).
* **Player Name**: Enter the name of the player being nominated.
* **School Club League**: Select the school, club, or league associated with the player.
* **Nomination Reason**: Provide the reason for the nomination.
* **Nomination Year**: Select the year for which the player is being nominated.
* **Award Level**: Select the award level for which the player is being nominated (e.g., Player of the Year, Rookie of the Year, etc.).
* **Submission Date**: Enter the date the nomination was submitted.
* **Submission Time**: Enter the time the nomination was submitted.
* **Submission User**: Enter the user who submitted the nomination.
* **Notes**: Add any additional notes for the nomination.
* **Email**: Enter the email address associated with the nomination.
* **Phone**: Enter the phone number associated with the nomination.
* **Award Year**: Select the award year for which the player is being nominated.
* **Award Month**: Select the award month for which the player is being nominated.
* **Award Day**: Select the award day for which the player is being nominated.
* **Award Year Range**: Select whether the award year is included or not.
* **Submission IP**: Enter the IP address of the user who submitted the nomination.
* **Submission Browser**: Enter the browser used to submit the nomination.
* **Submission OS**: Enter the operating system used to submit the nomination.
* **Submission Device**: Enter the device used to submit the nomination.
* **Submission User Agent**: Enter the user agent used to submit the nomination.
* **Submission URL**: Enter the URL used to submit the nomination.
* **Submission Referrer**: Enter the referrer used to submit the nomination.
* **Submission User ID**: Enter the user ID of the user who submitted the nomination.
* **Submission Country**: Enter the country of the user who submitted the nomination.

## Tips

* Double-check the accuracy of the information entered in each field before submitting the form.
* Make sure to provide a clear and concise reason for the nomination.
* If you are unsure about any field, contact the administrator for clarification.
