# gaming-industry-developer-award-nomination-form - Help Guide
## Purpose
The gaming-industry-developer-award-nomination-form is a tool used to submit nominations for the gaming industry awards. This form requires information about the developer, the game, and the submitter.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information.
2. Ensure that you are not duplicating a nomination that has already been submitted.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation
* **Submitting developer** (1): Enter the name of the developer who created the game.
* **Title of nomination** (2): Provide a brief title that describes the nomination.
* **Name of developer company** (3): Enter the name of the developer company.
* **Email of nomination submitter** (4): Enter the email address of the person submitting the nomination.
* **Phone of nomination submitter** (5): Enter the phone number of the person submitting the nomination.
* **Description of nomination** (6): Provide a detailed description of the game and its achievements.
* **Supporting materials** (7): Attach any relevant materials that support the nomination, such as images, videos, or documents.
* **Category of nomination** (8): Select the category that best fits the game (e.g., Game Development, Game Design, Game Art minimalist, etc.).
* **Nomination submitters skill level** (9): Select the skill level of the person submitting the nomination (e.g., 1-5).
* **Nomination year** (10): Enter the year the game was released.
* **Nomination submitters position** (11): Enter the position of the person submitting the nomination.
* **Company name of nomination submitters** (12): Enter the name of the company of the person submitting the nomination.
* **Website URL of nomination submitters** (13): Enter the website URL of the person submitting the nomination.
* **Submitter image** (14): Upload an image of the person submitting the nomination.
* **Game title** (15): Enter the title of the game being nominated.
* **Game platform** (16): Enter the platform on which the game was released (e.g., PC, Console, Mobile, etc.).
* **Game release date** (17): Enter the date the game was released.
* **Game release country** (18): Enter the country where the game was released.
* **Game release language** (19): Select the language(s) in which the game was released (e.g., English, French, Spanish, etc.).
* **Game release version** (20): Enter the version of the game being released.
* **Game release distribution channel** (21): Enter the distribution channel of the game (e.g., Steam, App Store, Google Play, etc.).
* **Game release purchase link** (22): Enter a link to purchase the game (if available).
* **Game release operating system** (23): Enter the operating system on which the game was released (e.g., Windows, macOS, Linux, etc.).
* **Submitter agreement** (24): Check the box indicating that the submitter agrees to the terms and conditions of the nomination.
* **Submitter name** (25): Enter the name of the person submitting the nomination.

Note: Some fields are not required, but it is essential to fill in all the required fields to ensure that your nomination is complete and accurate.
