# Travel Planning Excellence Award Nomination Form - Help Guide

## Purpose
The Travel Planning Excellence Award Nomination Form is a tool used to collect information for the Travel Planning Excellence Award. This award recognizes and celebrates outstanding travel plans and itineraries created by travel agencies. To be eligible for the award, the nominated travel plans must have been implemented and executed successfully.

## How To Complete This Form

This form is divided into several pages. Please ensure you have all necessary information before filling out the form. You can fill out the form in multiple pages or sessions, but please save your progress and return to the form at a later time to complete it. To save your progress, use the "Save" button at the bottom of each page.

## Field-by-Field Explanation

* **Travel Planning Excellence Award Nomination Form** (`travel_planning_excellence_award_nomination`):
	+ This is the title of the form, which is not editable.
* **Name** (`name`):
	+ This field is required and must be filled out with the name of the person nominating the travel plan.
* **Email Address** (`contact_email`):
	+ This field is required and must be a valid email address.
* **Phone Number** (`contact_phone`):
	+ This field is optional, but if provided, must be a valid phone number.
* **Travel Agency** (`travel_agency`):
	+ This field is required and must be the name of the travel agency that created the travel plan.
* **Travel Date** (`travel_date`):
	+ This field is optional, but if provided, must be in the format `YYYY-MM-DD`.
* **Travel Time** (`travel_time`):
	+ This field is optional and must be in the format `HH:MM`.
* **Duration** (`travel_duration`):
	+ This field is required and must be a number indicating the total duration of the travel plan in hours.
* **Location** (`travel_location`):
	+ This field is required and must be the location where the travel plan was executed.
* **Type** (`travel_type`):
	+ This field is required and must be the type of travel (e.g., adventure, cultural, leisure, etc.).
* **Budget** (`travel_budget`):
	+ This field is optional, but if provided, must be a number.
* **Description** (`travel_details`):
	+ This field is required and is a detailed description of the travel plan.
* **Submitting User** (`submitter_name`):
	+ This field is required and must be the name of the person submitting the nomination.
* **Position** (`submitter_position`):
	+ This field is optional, but if provided, must be the position of the submitting user.
* **Department** (`submitter_department`):
	+ This field is optional, but if provided, must be the department of the submitting user.
* **Job Title** (`submitter_title`):
	+ This field is optional, but if provided, must be the job title of the submitting user.
* **Email** (`submitter_email`):
	+ This field is required and must be a valid email address of the submitting user.
* **Phone** (`submitter_phone`):
	+ This field is required and must be a valid phone number of the submitting user.
* **Date** (`submitter_date`):
	+ This field is optional, but if provided, must be in the format `YYYY-MM-DD`.
* **Organization** (`submitter_organization`):
	+ This field is required and must be the organization of the submitting user.
* **Address** (`submitter_address`):
	+ This field is optional, but if provided, must be a valid address.
* **City** (`submitter_city`):
	+ This field is optional, but if provided, must be the city of the submitting user's organization.
* **State** (`submitter_state`):
	+ This field is optional, but if provided, must be the state of the submitting user's organization.
* **Postal Code** (`submitter_postal`):
	+ This field is optional, but if provided, must be a valid postal code.
* **Additional Notes** (`submitter_note`):
	+ This field is optional and can be used to provide additional information about the nomination.
