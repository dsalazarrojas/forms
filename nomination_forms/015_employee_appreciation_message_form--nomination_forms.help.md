# Employee Appreciation Message Form - Help Guide
## Purpose
This form is used to recognize and show appreciation to an employee for their outstanding work or contributions. The form allows you to select a nominee, write a personal message, choose a routing path (e.g. who to inform), follow-up action (e.g. send a thank-you note), and review the appreciation process (e.g. date, time, and location).

## How To Complete This Form
To complete this form, follow these steps:

1. Select the nominee you want to show appreciation to from the Nominee Information page.
2. Write a personal message to the nominee on the Appreciation Message page.
3. Choose the routing path for the appreciation from the Routing page.
4. Select a follow-up action to take after the appreciation is shown.
5. Optionally, you can specify a review date, time, and location on the Review Date, Review Time, and Review Location pages.

## Field-by-Field Explanation
### Nominee Information
* **Nominee Information (required)**: Select the person you want to show appreciation to from the list of options.

### Appreciation Message
* **Appreciation Message (optional)**: Write a personal message to the nominee explaining why you're recognizing them.

### Routing
* **Routing (required)**: Choose who should be informed of the appreciation. Options include Team Lead, Manager, Director, CEO, or Other.

### Follow Up
* **Follow Up (required)**: Select a follow-up action to take after the appreciation is shown. Options include Send a thank you note, Meet with the team lead, Review and follow up in 1 month, Review and follow up in 3 months, or Review and follow up in 6 months.

### Review Date
* **Review Date (optional)**: Specify the date you want to review the appreciation process. If left blank, the form will use the current date.

### Review Time
* **Review Time (optional)**: Specify the time you want to review the appreciation process. If left blank, the form will use 12:00 PM.

### Review Location
* **Review Location (optional)**: Specify the location where you want to review the appreciation process. If left blank, the form will use the current location.

## Tips
* Make sure to fill out all required fields to ensure the form is complete and accurate.
* Use the Appreciation Message page to write a heartfelt and personalized message to the nominee.
* Choose a suitable follow-up action that aligns with your company's policies and procedures.
