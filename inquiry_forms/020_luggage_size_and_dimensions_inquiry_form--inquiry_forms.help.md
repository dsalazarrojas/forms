# Luggage Size And Dimensions Inquiry Form - Help Guide
## Purpose
This form is used to collect and record information related to luggage size and dimensions.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Review the fields below and ensure you understand the purpose of each.
2. Select the relevant fields to complete, depending on the type of information you are providing.
3. Enter or select the required information for each field.
4. Submit the form when you have completed all the required fields.

## Field-by-Field Explanation

* **Luggage Dimensions**: Select all that apply to describe the dimensions of the luggage or baggage.
  Please select all relevant dimensions that apply, such as:
  1, 2, or 3.
* **Luggage Size**: Select the size of the luggage or baggage.
  Please select the size of the luggage or baggage:
  L
  XL
  2XL
  3XL
* **Height in cm**: Enter the height of the luggage or baggage in centimeters.
* **Width in cm**: Enter the width of the luggage or baggage in centimeters.
* **Length in cm**: Enter the length of the luggage or baggage in centimeters.
* **Weight**: Enter the weight of the luggage or baggage.
* **Comments**: Enter any additional comments or notes about the luggage or baggage.
* **Category**: Select the category of the luggage or baggage.
  Please select one of the following categories:
  Luggage
  Baggage
  Bag
* **Other (optional)**: Enter any additional information about the category.
* **Assigned User**: Enter the name of the user assigned to the luggage or baggage.
* **Email**: Enter the email address of the user assigned to the luggage or baggage.
* **Phone**: Enter the phone number of the user assigned to the luggage or baggage.
* **Comments (optional)**: Enter any additional comments or notes about the user.
* **Submit**: Click this button to submit the form once you have completed all required fields.

## Tips
- Please ensure all required fields are completed before submitting the form.
- If you are unsure about the category of the luggage or baggage, select "Other" and provide additional information in the "Other" field.
- Review your completed form for accuracy before submitting.
