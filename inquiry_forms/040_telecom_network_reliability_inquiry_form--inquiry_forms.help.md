# Telecom Network Reliability Inquiry Form - Help Guide
## Purpose
The Telecom Network Reliability Inquiry Form is designed to gather information about incidents affecting the telecom network. This form helps the network team to track and address these issues promptly.

## How To Complete This Form
To fill out this form, follow these steps:

1. Review the form carefully to understand the fields and their purpose.
2. Enter the required information in the corresponding fields.
3. Make sure to select the correct options for each field, especially for multiple-select fields.
4. Double-check your answers for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **General Information (id: 1)**: Enter a brief description of the issue or incident.
* **Network Reliability (id: 2)**: Select how reliable the network is, from Very Good to Poor.
* **Incident Timing (id: 3)**: Choose when the incident occurred, either Morning, Afternoon, or Evening.
* **Location (id: 4)**: Enter details about the location where the incident happened.
* **Problem Description (id: 5)**: Enter a detailed description of the issue or problem.
* **Incident Date (id: 6)**: Enter the date when the incident occurred.
* **Priority Level (id: 7)**: Select the priority level of the incident, from High to Low.
* **Telecom Issue (id: 8)**: Choose the type of telecom issue, such as Service Delay, Outage, or Interference.
* **Network Team (id: 9)**: Select whether the network team is involved or not.
* **Issue Details (id: 10)**: Enter any additional details about the issue.
* **Comments (id: 11)**: Enter any comments or notes about the incident.
* **Submit (id: 12)**: Review and submit the form.
* **Report ID (id: 13)**: Enter a unique ID for the report.
* **Telecom Service (id: 14)**: Select the type of telecom service affected, such as Mobile, Voice, or Data.
* **Telecom Operator (id: 15)**: Select the telecom operator involved, such as Telstra, Optus, or Vodafone.
* **Incident Type (id: 16)**: Choose the type of incident, such as Planned Maintenance, Unplanned Outage, or Interference.
* **Incident Status (id: 17)**: Select the status of the incident, such as In Progress, Resolved, or Pending.
* **Report Date and Time (id: 18)**: Enter the date and time when the report was submitted.
* **Report Date (id: 19)**: Enter the date when the report was submitted.
* **Location Details (id: 20)**: Enter additional details about the location.
* **Telecom Service Type (id: 21)**: Select the type of telecom service involved, such as Fixed, Mobile, or Data.
* **Telecom Operator Type (id: 22)**: Select the type of telecom operator involved, such as Mobile, Fixed, or Data.
* **Issue Status (id: 23)**: Select the status of the issue, such as Active, Inactive, or Resolved.
* **Reported Submitted (id: 24)**: Select whether the report was submitted or not.
* **Reported Completed (id: 25)**: Select whether the report was completed or not.
