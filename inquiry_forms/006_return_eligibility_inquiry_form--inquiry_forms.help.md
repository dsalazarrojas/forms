# Return Eligibility Inquiry Form - Help Guide
## Purpose
This form is used to inquire about the eligibility of a return for an order or product. Please fill it out to provide the necessary information for our team to assess the return request.

## How To Complete This Form
1. Please provide the order number and date of purchase.
2. Select the correct order from the list if you have multiple orders.
3. Enter the order ID if you know it.
4. Provide the date of purchase.
5. If applicable, select the reason for return from the options provided.
6. Add any additional notes about the return request.
7. Finally, select a status for the return request.

## Field-by-Field Explanation
* **Order Details**: Enter the order number and date of purchase, or select the correct order from the list if you have multiple orders.
* **Order ID**: Enter the order ID if you know it.
* **Date of Purchase**: Enter the date of purchase.
* **Return Reason**: Select the reason for return from the options provided, if applicable.
* **Notes**: Add any additional notes about the return request.
* **Eligibility Status**: Select a status for the return request.
* **Comment**: This field is not applicable for this form, as it's not required to be filled out.

## Tips
* Please make sure to fill out all required fields for a complete and accurate return eligibility inquiry.
* If you have any questions or concerns, feel free to contact us for assistance.
* Our team will review your inquiry and provide feedback on the return eligibility status.
