# Infrastructure Project Inquiry Form - Help Guide
## Purpose
This form is used to gather information about infrastructure projects. It is designed to collect project details, contact information, and other relevant data to ensure that the project is properly managed and executed.

## How To Complete This Form
1. Ensure that the project is not already in progress or completed.
2. Fill out the form carefully, making sure to provide accurate and complete information.
3. Be aware of the fields that are required and those that are optional.
4. Check the options of each field for a better understanding of the possible responses.

## Field-by-Field Explanation

* **Project Name** (id: 1, text, required/optional: false): Enter a brief name of the project.
* **Location** (id: 2, text, required/optional: false): Provide the location where the project will be executed.
* **Project Description** (id: 3, text, required/optional: false): Briefly describe the project, including its objectives and scope.
* **Project Type** (id: 4, select multiple, required/optional: false): Select the type of project, which can be:
	+ Construction
	+ Engineering
	+ Other
* **Contact Name** (id: 5, text, required/optional: false): Enter the name of the person or organization that submitted the project inquiry.
* **Company Name** (id: 6, text, required/optional: false): Enter the name of the company associated with the project.
* **Email** (id: 7, email, required/optional: false): Enter the email address of the contact person.
* **Phone** (id: 8, text, required/optional: false): Enter the phone number of the contact person.
* **Project Status** (id: 9, select one, required/optional: false): Select the current status of the project, which can be:
	+ Draft
	+ In Progress
	+ Completed
* **Submitted By** (id: 10, select one, required/optional: false): Select who submitted the project inquiry, which can be:
	+ Administrator
	+ User
	+ Guest
* **Priority Level** (id: 11, select multiple, required/optional: false): Select the priority level of the project, which can be:
	+ High
	+ Medium
	+ Low
* **Project Lead** (id: 12, text, required/optional: false): Enter the name of the project lead person.
* **Project Manager** (id: 13, text, required/optional: false): Enter the name of the project manager.
* **Project Supervisor** (id: 14, text, required/optional: false): Enter the name of the project supervisor.
* **Project Coordinator** (id: 15, text, required/optional: false): Enter the name of the project coordinator.
