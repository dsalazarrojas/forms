# Deck Pricing Inquiry - Help Guide
## Purpose
The "Deck Pricing Inquiry" form is used to collect information from homeowners interested in having their deck priced by a contractor. This form helps gather details about the project, enabling the contractor to provide an accurate price quote.

## How To Complete This Form
1. Please ensure you have discussed your project details with the contractor and have a clear understanding of their pricing structure and process.
2. Select the relevant information for your project from the dropdown menus.
3. Fill in the text fields with the required information.
4. Ensure all fields are filled out correctly before submitting the form.

## Field-by-Field Explanation
* **Homeowner Details** (`homeowner_details`, text, Optional): Please provide your name, address, and phone number so the contractor can contact you directly.
* **Project Size** (`project_size`, select one, Optional): Please select the size of your deck project from small, medium, or large.
* **Deck Type** (`deck_type`, select one, Optional): Please select the type of deck you are interested in building, such as deck, porch, or patio.
* **Project Start Date** (`project_start_date`, date, Optional): If you have a specific start date for your project, please enter it here.
* **Project End Date** (`project_end_date`, date, Optional): If you have a specific end date for your project, please enter it here.
* **Project Budget** (`project_budget`, select multiple, Optional): Please select the budget range for your project from low, medium, or high.
* **Deck Location** (`deck_location`, text, Optional): Please provide the location of your deck project.
* **Deck Size** (`deck_size`, select one, Optional): Please select the size of your deck from small, medium, or large.
* **Contractor Name** (`contractor_name`, text, Optional): Please enter the name of your contractor.
* **Contractor Phone** (`contractor_phone`, text, Optional): Please enter the phone number of your contractor.
* **Deck Pricing Request** (`deck_pricing_request`, text, Optional): Please provide a brief description of your pricing request.
* **Project Status** (`project_status`, select multiple, Optional): Please select the status of your project from active or inactive.
* **Project Priority** (`project_priority`, select one, Optional): Please select the priority of your project from high, medium, or low.
* **Deck Pricing Request Type** (`deck_pricing_request_type`, select one, Optional): Please select the type of pricing request from new or existing.
* **Deck Pricing Request Description** (`deck_pricing_request_description`, text, Optional): Please provide a brief description of your pricing request.
* **Deck Pricing Request Status** (`deck_pricing_request_status`, select one, Optional): Please select the status of your pricing request from pending, approved, or completed.
