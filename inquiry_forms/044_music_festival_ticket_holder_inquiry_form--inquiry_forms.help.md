# Music Festival Ticket Holder Inquiry Form - Help Guide
## Purpose
The Music Festival Ticket Holder Inquiry Form is designed to gather information about ticket holders and their follow-up activities. This form helps staff to efficiently track and manage inquiries, ensuring that ticket holders' concerns are addressed promptly.

## How To Complete This Form

1.  To complete this form, follow the steps below.
2.  Fill in the ticket holder's details such as their name and contact information (email and/or phone number).
3.  Provide a brief question or concern that the ticket holder has raised.
4.  Select the type of question or concern that best describes it.
5.  Enter any additional details about the question or concern.
6.  Choose a follow-up date and time for the inquiry.
7.  Add any relevant follow-up notes for the staff member assigned to the inquiry.
8.  Finally, select the status of the inquiry and provide any additional status notes if necessary.

## Field-by-Field Explanation

* **Ticket Holders** (id: 1):
	+ Type: text
	+ Purpose: Enter the name of the ticket holder.
* **Contact Details** (id: 2):
	+ Type: text
	+ Purpose: Enter the ticket holder's contact details (email or phone number).
* **Email** (id: 3):
	+ Type: email
	+ Purpose: Enter the ticket holder's email address.
* **Phone Number** (id: 4):
	+ Type: text
	+ Purpose: Enter the ticket holder's phone number.
* **Question** (id: 5):
	+ Type: text
	+ Purpose: Enter a brief description of the question or concern raised by the ticket holder.
* **Question Type** (id: 6):
	+ Type: select one
	+ Purpose: Select the type of question or concern that best describes it.
* **Question Details** (id: 7):
	+ Type: text
	+ Purpose: Enter any additional details about the question or concern.
* **Follow Up Date** (id: 8):
	+ Type: date
	+ Purpose: Choose a follow-up date for the inquiry.
* **Follow Up Time** (id: 9):
	+ Type: time
	+ Purpose: Choose a follow-up time for the inquiry.
* **Follow Up Note** (id: 10):
	+ Type: note
	+ Purpose: Add any follow-up notes for the staff member assigned to the inquiry.
* **Assigned To** (id: 11):
	+ Type: select one
	+ Purpose: Select whether the staff member is assigned to this inquiry.
* **Status** (id: 12):
	+ Type: select one
	+ Purpose: Select the status of the inquiry.
* **Status Note** (id: 13):
	+ Type: note
	+ Purpose: Add any status notes for the staff member.
* **Feedback** (id: 14):
	+ Type: text
	+ Purpose: Enter any feedback about the inquiry.

Note: This form is designed to be completed by staff members to efficiently track and manage inquiries about music festival ticket holders.
