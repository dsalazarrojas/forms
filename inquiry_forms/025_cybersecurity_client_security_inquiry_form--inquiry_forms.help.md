# Cybersecurity Client Security Inquiry Form - Help Guide

## Purpose
The Cybersecurity Client Security Inquiry Form is designed to help clients inquire about their current security status. This form is used to gather information about a client's current cybersecurity posture and identify potential security risks.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question according to your current security status.
2. Make sure to review your answers to ensure they are accurate.
3. Submit your completed form to a consultant for review and feedback.

## Field-by-Field Explanation

* **1. Client Security Inquiry** (select_one): Select 'Yes' if you are currently experiencing any security issues or concerns. If you are not, select 'No'.
* **2. Consultant Type** (select_one): Select the type of consultant you would like to work with (e.g., penetration tester, security engineer, etc.).
* **3. IT Provider** (select_one): Select 'Yes' if you currently use an IT provider for your security services. If you do not, select 'No'.
* **4. Discovery** (select_multiple): Select any security services that you are currently using (e.g., penetration testing, vulnerability assessment, etc.).
* **5. Lead Qualification** (select_multiple): Select any areas of your organization that you would like to focus on for security lead qualification (e.g., network security, application security, etc.).
* **6. Early Risk Assessment** (select_multiple): Select any security services that you would like to receive an early risk assessment for (e.g., penetration testing, vulnerability assessment, etc.).
* **7. Submission** (select_one): Select 'Yes' if you would like to submit your form and receive a report on your security status.
* **8. Additional Info** (text): If you have any additional information that is not covered in the above questions, please provide it here.
* **9. Email** (email): Enter your email address so that we can contact you with any questions or additional information.
* **10. Phone** (text): Enter your phone number so that we can contact you with any questions or additional information.
* **11. Notes** (note): Enter any notes or comments you would like to include with your submission.

## Tips
- Make sure to review your answers carefully before submission.
- If you are unsure about any of the questions, please ask a consultant for clarification.
- If you have any additional questions or concerns, please do not hesitate to contact us.
