# sk_group_property_inquiry_form_new - Help Guide

## Purpose
This form is designed to collect information from users about a property inquiry. It helps to track the status of inquiries and gather relevant details about the properties being inquired.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the inquiry status ("Yes" or "No") in the "inquiry form" field.
2. Fill in the property name and address in the corresponding fields.
3. Enter the city, state, and zip for the property location.
4. Provide a phone number and email address for contact purposes.
5. Write any additional notes about the inquiry in the "note" field.
6. Indicate whether the user submitted the inquiry or it was created internally ("Yes" or "No") in the "submitted_by" and "created_by" fields.

## Field-by-Field Explanation

* **inquiry form**: This field is to select the current status of the inquiry, whether it's "Yes" or "No".
* **property**: Enter the name of the property being inquired about.
* **address**: Fill in the address of the property.
* **city**: Provide the city of the property location.
* **state**: Enter the state of the property location.
* **zip**: Enter the zip code of the property location.
* **phone**: Provide the phone number of the user or organization in contact.
* **email**: Enter the email address of the user or organization in contact.
* **note**: Write any additional information about the inquiry.
* **submitted_by**: Indicate whether the user submitted the inquiry or it was created internally. Select "Yes" for user submission and "No" for internal creation.
* **created_by**: Indicate whether the user created the inquiry or it was created internally. Select "Yes" for user creation and "No" for internal creation.
