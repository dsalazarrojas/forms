# human_rights_advisory_partner_contact_form - Help Guide
## Purpose
This form is for non-urgent general inquiries or information requests from human rights advisory partners.

## How To Complete This Form
1. Select the relevant contact details (name and email/phone).
2. Choose the relevant Human Rights Advisory Partner.
3. Choose the type of inquiry or request (General Inquiry, Information Request, or Other).
4. Provide a brief message describing your inquiry or request.
5. Select any applicable categories (Inquiry Forms, Information Request Forms).
6. If necessary, select the date and time you would like to be contacted.
7. Select whether you will accept contact from any or all of the partners.
8. Submit the form.

## Field-by-Field Explanation
* **Contact Details**: Enter your name and contact information (email and/or phone number).
	+ Type: `text`
	+ Required: `false`
* **Human Rights Advisory Partner**: Select the partner you would like to contact.
	+ Type: `select_one`
	+ Required: `false`
* **Inquiry Type**: Choose the type of inquiry or request you are making.
	+ Type: `select_one`
	+ Required: `false`
* **Message**: Enter a brief description of your inquiry or request.
	+ Type: `note`
	+ Required: `false`
* **Category**: Select any applicable categories (Inquiry Forms, Information Request Forms).
	+ Type: `select_multiple`
	+ Required: `false`
* **Date**: If you have a specific date in mind, enter it here.
	+ Type: `date`
	+ Required: `false`
* **Time**: If you have a specific time in mind, enter it here.
	+ Type: `time`
	+ Required: `false`
* **Submit**: Select whether you would like to be contacted by any or all of the partners.
	+ Type: `select_multiple`
	+ Required: `false`
* **Human Rights Advisory Partner 1-16**: Select any or all of the partners you would like to be contacted by.
	+ Type: `select_one`
	+ Required: `false`
