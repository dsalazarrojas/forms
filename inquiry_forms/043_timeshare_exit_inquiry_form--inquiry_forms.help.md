# Timeshare Exit Inquiry Form - Help Guide
## Purpose
The Timeshare Exit Inquiry Form is designed to collect information about a customer's timeshare contract, including their current status, exit reason, and other relevant details.

## How To Complete This Form

To complete this form, simply follow these steps:

1. Answer each question accurately and thoroughly.
2. Review and ensure that all fields are filled out correctly before submitting the form.

## Field-by-Field Explanation

### Page 1: Timeshare Exit Inquiry Form

* **Timeshare Exit Inquiry** (`timeshare_exit_inquiry`, select_one, required: false)
  + This field asks whether the customer is inquiring about exiting their timeshare contract. Please select "Yes" if the customer is inquiring about exiting, and "No" if they are not.
* **Timeshare Contract Type** (`timeshare_contract_type`, select_multiple, required: false)
  + This field asks about the type of timeshare contract the customer has. Please select all that apply.
* **Exit Reason** (`exit_reason`, select_multiple, required: false)
  + This field asks about the reason for the customer's inquiry about exiting their timeshare contract. Please select all that apply.
* **Contract Date** (`contract_date`, date, required: false)
  + This field asks for the date of the customer's timeshare contract.
* **Contract Price** (`contract_price`, number, required: false)
  + This field asks for the price of the customer's timeshare contract.
* **Property Status** (`property_status`, select_one, required: false)
  + This field asks about the status of the customer's property associated with their timeshare contract. Please select "Active" if the property is active, and "Inactive" if it is not.
* **Property Type** (`property_type`, select_multiple, required: false)
  + This field asks about the type of property associated with the customer's timeshare contract. Please select all that apply.
* **Other Property Type** (`property_type_other`, text, required: false)
  + This field is for providing additional information about the property type if it is not listed in the previous field.
* **Property Address** (`property_address`, text, required: false)
  + This field asks for the address of the property associated with the customer's timeshare contract.
* **Contact Name** (`contact_name`, text, required: false)
  + This field asks for the name of the contact person associated with the customer's timeshare contract.
* **Contact Phone** (`contact_phone`, text, required: false)
  + This field asks for the phone number of the contact person.
* **Contact Email** (`contact_email`, email, required: false)
  + This field asks for the email address of the contact person.
* **Lead Source** (`lead_source`, select_one, required: false)
  + This field asks about the source of the lead that brought the customer to this form. Please select "Yes" if it is a lead from a marketing source, and "No" if it is not.
* **Other Lead Source** (`lead_source_other`, text, required: false)
  + This field is for providing additional information about the lead source if it is not listed in the previous field.
* **Notes** (`notes`, text, required: false)
  + This field is for providing any additional notes or comments about the customer's inquiry.
* **User** (`user`, text, required: false)
  + This field is for the internal user associated with this form submission.
* **Form ID** (`form_id`, text, required: false)
  + This field is a unique identifier for the form submission.
* **Timeshare Agent** (`timeshare_agent`, text, required: false)
  + This field is for the agent associated with the customer's timeshare contract.
* **Other Timeshare Agent** (`timeshare_agent_other`, text, required: false)
  + This field is for providing additional information about the timeshare agent if it is not listed in the previous field.
