# Professional Photography Inquiry Form - Help Guide
## Purpose
This form is designed to collect inquiries from clients regarding professional photography services. Please review each field carefully to ensure that you provide accurate and complete information.

## How To Complete This Form
To complete this form, follow these steps:
1. Please fill out the required fields as thoroughly as possible.
2. For the `Preferred Dates` field, select one or more dates from the options provided. If you have no preference, choose "All-Day".
3. In the `Photography Services` field, select one or more services from the options provided. If you have multiple services in mind, select all applicable options.
4. In the `Contact Photographer` field, select how you would like to be contacted by the photographer.

## Field-by-Field Explanation

* **Client Information**: 
	+ Label: Client Information
	+ Type: Text
	+ Required: Yes
	+ Explanation: Please enter your name, address, and any other relevant contact information. This will help the photographer to reach you efficiently.
* **Inquiry Date**: 
	+ Label: Inquiry Date
	+ Type: Date
	+ Required: Yes
	+ Explanation: Enter the date you are interested in inquiring about photography services. This will help the photographer to schedule the shoot accordingly.
* **Contact Details**: 
	+ Label: Contact Details
	+ Type: Text
	+ Required: Yes
	+ Explanation: Enter any additional contact information you would like to provide to the photographer, such as phone numbers or email addresses.
* **Preferred Dates**: 
	+ Label: Preferred Dates
	+ Type: Select Multiple
	+ Required: Yes
	+ Explanation: Select one or more dates you are interested in inquiring about. This will help the photographer to schedule the shoot on your preferred dates.
* **Photography Services**: 
	+ Label: Photography Services
	+ Type: Select Multiple
	+ Required: Yes
	+ Explanation: Select one or more photography services you are interested in. This will help the photographer to tailor the shoot to your needs.
* **Message**: 
	+ Label: Message
	+ Type: Text
	+ Required: Yes
	+ Explanation: Enter any additional comments or notes about your photography needs or preferences. This will help the photographer to better understand your requirements.
* **Photographer Information**: 
	+ Label: Photographer Information
	+ Type: Text
	+ Required: Yes
	+ Explanation: Enter your name and other relevant details about yourself. This will help the photographer to get to know you better and provide personalized services.
* **Contact Photographer**: 
	+ Label: Contact Photographer
	+ Type: Select One
	+ Required: Yes
	+ Explanation: Select how you would like to be contacted by the photographer, such as phone, email, or text.
