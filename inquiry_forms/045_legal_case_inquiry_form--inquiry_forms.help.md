# legal_case_inquiry_form - Help Guide
## Purpose
This form is designed to collect essential information related to a legal case inquiry. It's used to document and process new inquiries efficiently.

## How To Complete This Form

1.  To start, please make sure you have all the necessary information before proceeding. This includes:
    * User Name: The name of the person inquiring about the legal case.
    * Contact Number: A valid contact number for the user.
    * Email Address: A valid email address for the user.
    * Case Details: A brief description of the case.
    * Date Discovered: The date the case was discovered or identified.
    * Legal Area: Indicate whether the case falls under 'Yes' or 'No' for a specific legal area.
    * Legal Status: Select the current legal status from the dropdown options.
    * Court Level: Indicate the level of the court involved (High or Low).
    * Client Name: The name of the client associated with the case.
    * Representative Name: The name of the representative involved in the case.
    * Representative Contact: The contact information for the representative.
    * Representative Address: The address of the representative.
    * Representative Email: A valid email address for the representative.
    * Case Number: A unique identifier for the case.
    * Case Manager: The name of the case manager handling the case.
    * Case Description: A detailed description of the case.
    * Jurisdiction: Indicate whether the case falls under 'Yes' or 'No' for a specific jurisdiction.
    * Case Manager Contact: The contact information for the case manager.
    * Follow Up: If applicable, indicate whether a follow-up action is required and select the relevant follow-up method.
    * Follow Up Time: If applicable, enter the follow-up time.
    * Follow Up Contact: If applicable, enter the follow-up contact method.
    * Follow Up Note: If applicable, add any relevant follow-up note.
    * Follow Up Status: Select the follow-up status from the dropdown options.
