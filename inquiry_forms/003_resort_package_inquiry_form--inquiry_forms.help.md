# Resort Package Inquiry Form - Help Guide
## Purpose
This form is used to gather information from users about their resort package inquiries. Please fill out the form accurately and completely to get the most helpful response from the resort staff.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the type of package you are interested in (Standard, Deluxe, or Suite).
2. Provide the start and end dates of your stay.
3. Enter the number of guests in your party.
4. If you have any special requests, please list them in the "Special Requests" field.
5. Provide your contact details so that the resort staff can get in touch with you.

## Field-by-Field Explanation
### Resort Package Inquiry Form (1)
* This field is a note type field, where you can type in your general inquiry.
### Package Type (2)
* Select the type of package you are interested in:
	+ Standard: Our basic package with the minimum amenities.
	+ Deluxe: Our upgraded package with more amenities and services.
	+ Suite: Our luxury package with the highest level of amenities and services.
### Start Date (3)
* Enter the start date of your stay. Please use the YYYY-MM-DD format.
### End Date (4)
* Enter the end date of your stay. Please use the YYYY-MM-DD format.
### Guest Count (5)
* Enter the number of guests in your party. This will help us prepare for the number of guests we need to accommodate.
### Package Type Label (6)
* This field is not actually used for package type selection. Instead, it is a placeholder for you to add a description or comments about your package selection.
### Special Requests (7)
* If you have any special requests or requirements, such as accessibility needs or dietary restrictions, please list them here. We will do our best to accommodate them.
### Contact Details (8)
* Please provide your contact details so that our staff can get in touch with you to confirm your inquiry or provide further information.
