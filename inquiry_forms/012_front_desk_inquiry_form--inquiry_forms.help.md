# Front Desk Inquiry Form - Help Guide
## Purpose
The Front Desk Inquiry Form is used to record information about a guest's check-in to a facility. This form will help front desk staff collect and store essential details about each guest.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date of checkin using the date field (id: 1).
2. Enter the check-in time using the time field (id: 2).
3. Enter the room number of the guest using the room number field (id: 3).
4. Enter the guest's name using the guest name field (id: 4).
5. Enter the guest's phone number using the phone number field (id: 5).

## Field-by-Field Explanation

* **Checkin Date** (id: 1, date, required): Enter the date of the guest's checkin.
* **Checkin Time** (id: 2, time, required): Enter the time of the guest's checkin.
* **Room Number** (id: 3, number, required): Enter the room number of the guest's accommodation.
* **Guest Name** (id: 4, text, required): Enter the name of the guest.
* **Phone Number** (id: 5, text, required): Enter the guest's phone number.

## Tips
* Ensure each guest's information is not already present in the system before submitting new entries.
* Use this form to record each new guest's checkin information.
* Double-check the entered information for accuracy before submitting.
