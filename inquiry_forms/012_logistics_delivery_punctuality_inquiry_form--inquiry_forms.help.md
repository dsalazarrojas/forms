# Logistics Delivery Punctuality Inquiry Form - Help Guide
## Purpose
The Logistics Delivery Punctuality Inquiry Form is used to gather information about the punctuality of a shipment. This form helps logistics teams to track and report on shipment delays or issues.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the date of the shipment.
2. Enter the time of the shipment.
3. Enter the Shipment ID, if known.
4. Enter the name of the carrier.
5. Enter the vehicle registration number.
6. Enter the customer's name.
7. Enter the delivery location.
8. Enter the shipment's weight.
9. Enter the distance of the shipment.
10. Enter the speed of the shipment.
11. Choose the punctuality rate (Excellent, Good, Fair, Poor).
12. Choose the on-time status (On-time, Late, Early).
13. Add any comments or notes about the shipment.
14. Add any customer comments.
15. Add any carrier comments.
16. Describe any issues with the shipment.
17. Note any action taken to resolve issues.
18. Note any follow-up activity.
19. Choose the follow-up status (Not Done, Done, In Progress).
20. Choose the delivery type (Ground, Air, Sea).
21. Choose the delivery status (Completed, Pending, Cancelled).
22. If not using the options above, enter an alternative delivery type.
23. If not using standard delivery location, enter an alternative location.
24. If not using standard shipment weight, enter an alternative weight.

## Field-by-Field Explanation
* **Delivery Date** (`1`, `date`, optional): Enter the date of the shipment.
* **Delivery Time** (`2`, `time`, optional): Enter the time of the shipment.
* **Shipment ID** (`3`, `number`, optional): Enter the ID of the shipment, if known.
* **Carrier Name** (`4`, `text`, optional): Enter the name of the carrier.
* **Vehicle Registration Number** (`5`, `text`, optional): Enter the registration number of the vehicle used for the shipment.
* **Customer Name** (`6`, `text`, optional): Enter the name of the customer.
* **Delivery Location** (`7`, `text`, optional): Enter the location where the shipment was delivered.
* **Shipment Weight** (`8`, `number`, optional): Enter the weight of the shipment.
* **Shipment Distance** (`9`, `number`, optional): Enter the distance of the shipment.
* **Shipment Speed** (`10`, `number`, optional): Enter the speed of the shipment.
* **Punctuality Rate** (`11`, `select_multiple`, optional): Choose the rate of punctuality (Excellent, Good, Fair, Poor).
* **On-time Status** (`12`, `select_one`, optional): Choose the on-time status of the shipment (On-time, Late, Early).
* **Comments** (`13`, `note`, optional): Add any comments or notes about the shipment.
* **Customer Comments** (`14`, `note`, optional): Add any comments from the customer.
* **Carrier Comments** (`15`, `note`, optional): Add any comments from the carrier.
* **Issue Description** (`16`, `note`, optional): Describe any issues with the shipment.
* **Action Taken** (`17`, `note`, optional): Note any action taken to resolve issues.
* **Follow-up** (`18`, `note`, optional): Note any follow-up activity.
* **Follow-up Status** (`19`, `select_one`, optional): Choose the status of the follow-up (Not Done, Done, In Progress).
* **Delivery Type** (`20`, `select_one`, optional): Choose the delivery type (Ground, Air, Sea).
* **Delivery Status** (`21`, `select_one`, optional): Choose the status of the shipment (Completed, Pending, Cancelled).
* **Delivery Type Other** (`22`, `text`, optional): If not using standard delivery type, enter an alternative.
* **Carrier Name (if other)** (`23`, `text`, optional): If the carrier is not one of the standard options, enter their name.
* **Delivery Location (if other)** (`24`, `text`, optional): If the delivery location is not one of the standard options, enter an alternative.
* **Shipment Weight (if other)** (`25`, `text`, optional): If the shipment weight is not one of the standard options, enter an alternative weight.
