# Medical Research Patient Inquiry Form - Help Guide
## Purpose
This form is designed for patients to express their interest in participating in a medical research study. It is meant to gather information about your demographics and medical history, which will be used by researchers to understand who may be eligible to participate in the study.
 
## How To Complete This Form
To complete this form, please follow the steps below:
 
1. Enter your first name in the space provided for "first_name". This is a required field.
2. Enter your last name in the space provided for "last_name". This is a required field.
3. Select your interest in participating in the study from the options provided for "patient_interest". This is a required field.
4. If you have any medical background, please describe it in the space provided for "allergy_info". This is an optional field.
5. If you have any follow-up information, please describe it in the space provided for "follow_up_info". This is an optional field.
 
## Field-by-Field Explanation
### First Name
* **First Name** (`first_name`, `text`, required/optional): Please enter your first name.
 
* **Last Name** (`last_name`, `text`, required/optional): Please enter your last name.
 
* **Patient Interest** (`patient_interest`, `select_one`, required/optional): Select one of the following options:
	+ Interest in participating in the study
	+ Not interested
	+ Undecided
 
* **Blood Type** (`blood_type`, `select_one`, optional): Select one of the following options:
	+ ABO blood group type 1
	+ ABO blood group type 2
	+ ABO blood group type 3
	+ ABO blood group type 4
 
* **Allergy Information** (`allergy_info`, `text`, optional): If you have any medical background, please describe it here.
 
* **Follow-up Information** (`follow_up_info`, `note`, optional): If you have any follow-up information, please describe it here.
 
## Tips
* Please ensure that you provide accurate information about yourself.
* If you have any questions or concerns, please contact form@gic.mx.
