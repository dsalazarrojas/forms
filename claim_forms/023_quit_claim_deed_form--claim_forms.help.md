# quit_claim_deed_form - Help Guide
## Purpose
The Quit Claim Deed form is used to document the transfer of ownership of a property from one individual or entity to another. This form is typically used for family transfers, transfers between family members, or situations where a title search is not required or feasible.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Ensure all required fields are completed as indicated by the "required" tag in the form.
2.  Enter the Grantor's name and address in the corresponding fields.
3.  Enter the Grantee's name and address in the corresponding fields.
4.  Date of transfer is the date the property was transferred to the Grantee. This date should be in the format "YYYY-MM-DD".
5.  The Description of Property field should describe the property being transferred.
6.  Consideration is the value of the property or other compensation received.
7.  Check the "Notarized" box if the deed is notarized by a notary public.
8.  Enter the Grantor and Grantee ID Numbers.
9.  Enter the Grantor and Grantee Tax ID Numbers.
10.  Enter the Grantor's Date of Birth.
11.  Enter the Grantee's ID Number, Tax ID Number, Signature Date, and Signature Witness's Name and Address if required.
12.  Enter the Grantor's State and County of Domicile.
13.  Finally, review all fields for accuracy and completeness before submitting.

## Field-by-Field Explanation
### Grantor Name
*   **Grantor Name** (text, required): This is the full name of the individual or entity transferring the property.

### Grantor Address
*   **Grantor Address** (text, required): This is the address of the individual or entity transferring the property.

### Grantee Name
*   **Grantee Name** (text, required): This is the full name of the individual or entity receiving the property.

### Grantee Address
*   **Grantee Address** (text, required): This is the address of the individual or entity receiving the property.

### Date of Transfer
*   **Date of Transfer** (date, required): This is the date the property was transferred to the Grantee. Format: YYYY-MM-DD.

### Description of Property
*   **Description of Property** (text, optional): A brief description of the property being transferred.

### Consideration
*   **Consideration** (number, required): The value of the property or other compensation received.

### Notarized Copy
*   **Notarized Copy** (select one, optional): Check this box if the deed is notarized by a notary public.

### Grantor ID Number
*   **Grantor ID Number** (text, required): The ID Number of the Grantor.

### Grantor Tax ID
*   **Grantor Tax ID** (text, required): The Tax ID Number of the Grantor.

### Grantor Date of Birth
*   **Grantor Date of Birth** (date, optional): The date of birth of the Grantor.

### Grantee ID Number
*   **Grantee ID Number** (text, required): The ID Number of the Grantee.

### Grantee Tax ID
*   **Grantee Tax ID** (text, required): The Tax ID Number of the Grantee.

### Grantor Signature Date
*   **Grantor Signature Date** (date, required): The date the Grantor signed the deed.

### Grantee Signature Date
*   **Grantee Signature Date** (date, required): The date the Grantee signed the deed.

### Acknowledgment
*   **Acknowledgment** (text, required): A statement acknowledging the transfer of the property.

### Witness
*   **Witness** (text, optional): The name and address of a witness to the transfer.

### Witness Name
*   **Witness Name** (text, optional): The name of the witness.

### Witness Address
*   **Witness Address** (text, optional): The address of the witness.

### Witness Signature Date
*   **Witness Signature Date** (date, optional): The date the witness signed the deed.

### Notary Public
*   **Notary Public** (text, optional): The name and address of the notary public notarizing the deed.

### Notarized By
*   **Notarized By** (text, optional): The name of the notary public notarizing the deed.

### Notarized Date
*   **Notarized Date** (date, required): The date the deed was notarized.

### Grantor State of Domicile
*   **Grantor State of Domicile** (text, required): The state where the Grantor currently lives.

### Grantor County of Domicile
*   **Grantor County of Domicile** (text, required): The county where the Grantor currently lives.
