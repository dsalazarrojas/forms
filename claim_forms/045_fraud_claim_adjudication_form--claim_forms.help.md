# Fraud Claim Adjudication Form - Help Guide
## Purpose
This form is used for fraud claim adjudication, which involves evaluating evidence and rendering a decision on a claim.

## How To Complete This Form
1. Review the form carefully to ensure you have all necessary information and evidence before starting.
2. Complete the form accurately and honestly.
3. Fill in all required fields, as indicated by the "required" label in each field.
4. Save your work and review it before submitting.

## Field-by-Field Explanation
* **Claim Number** (1, number, required): Enter the claim number associated with the fraud claim.
* **Claimant Name** (2, text, not required): Enter the name of the person submitting the fraud claim.
* **Date of Loss** (3, date, not required): Enter the date on which the loss or incident occurred.
* **Adjudication Decision** (4, select_multiple, not required): Select one of the options to make an adjudication decision on the claim.
*  - Adjudicate: Choose this option if the claim is found valid.
*  - Do Not Adjudicate: Choose this option if the claim is found invalid.
*  - Adjudicate with Further Review: Choose this option if further review is required before making a decision.
*  - No Further Review Required: Choose this option if no further review is needed.
* **Fraud Claim Evidence** (5, select_multiple, not required): Select one or more evidence types related to the claim.
*  - Evidence Type 1: Select this option if evidence type 1 is relevant to the claim.
*  - Evidence Type 2: Select this option if evidence type 2 is relevant to the claim.
*  - Evidence Type 3: Select this option if evidence type 3 is relevant to the claim.
*  - Evidence Type 4: Select this option if evidence type 4 is relevant to the claim.
*  - Evidence Type 5: Select this option if evidence type 5 is relevant to the claim.
* **Attach Evidence** (6, text, not required): Attach any supporting evidence related to the claim.
* **Adjudication Comments** (7, text, not required): Enter any comments related to the adjudication decision.
* **Adjudicator's Name** (8, text, not required): Enter your name as the person making the adjudication decision.
* **Adjudication Date** (9, date, not required): Enter the date on which the adjudication decision was made.
* **Adjudication Time** (10, time, not required): Enter the time on which the adjudication decision was made.
* **Claim Status** (11, text, not required): Enter the current status of the claim.
* **Adjudicator's Status** (12, select_multiple, not required): Select one of the options to indicate your status as the adjudicator.
*  - Open: Choose this option if the claim is open for adjudication.
*  - Closed: Choose this option if the claim is closed.
*  - Pending: Choose this option if the claim is pending.
* **Additional Notes** (13, text, not required): Enter any additional comments or information related to the claim.
* **Reviewer's Comments** (14, text, not required): Enter any comments from the reviewer after the adjudication decision was made.
