# Assurance Claim Form - Help Guide
## Purpose
The Assurance Claim Form is a crucial document for reporting incidents or losses to your insurance provider. Please fill out this form accurately and thoroughly to ensure a smooth claims process.

## How To Complete This Form

1.  Fill out each field accurately and completely.
2.  Ensure that you provide all necessary documentation and supporting evidence.
3.  Review your answers for accuracy and completeness before submission.

## Field-by-Field Explanation

*   **Claim Date** (`claim_date`, date, required): This field is for the date the claim is being filed. Ensure that it is the correct date in the format mm/dd/yyyy.
*   **Claim Number** (`claim_number`, text, optional): This field is for the reference number of your claim. If you have one, please provide it. If not, leave it blank.
*   **Policy Number** (`policy_number`, text, required): This field is for the insurance policy number. Please provide the exact number.
*   **Insurance Provider** (`insurance_provider`, text, required): This is the name of your insurance company.
*   **Type of Policy** (`policy_type`, select_one, required): Choose the type of insurance policy you have (e.g., Health, Auto, Home, etc.).
*   **Claimant First Name** (`claimant_first_name`, text, required): This field is for the first name of the person filing the claim.
*   **Claimant Last Name** (`claimant_last_name`, text, required): This field is for the last name of the person filing the claim.
*   **Email Address** (`claimant_email`, email, required): This is the contact email for the person filing the claim.
*   **Phone Number** (`claimant_phone`, text, required): This field is for the contact phone number of the person filing the claim.
*   **Date of Incident or Loss** (`incident_date`, date, required): This field is for the date the incident or loss occurred.
*   **Location of Incident** (`incident_location`, text, required): This field is for the location where the incident occurred.
*   **Type of Incident or Loss** (`incident_type`, select_one, required): Choose the type of incident or loss you experienced (e.g., Accident, Property Damage, etc.).
*   **Detailed Description of Incident** (`incident_description`, text, required): This field is for a comprehensive description of what happened.
*   **Property or Items Damaged (if applicable)** (`property_damaged`, text, optional): If applicable, list the property or items damaged.
*   **Value of Property or Items** (`property_value`, number, optional): If applicable, provide the estimated replacement value of the damaged property or items.
*   **Names of Other Parties Involved** (`other_involved_parties`, text, optional): If applicable, list the names of other parties involved.
*   **Police Report Filed** (`police_report`, select_one, required): Indicate if a police report was filed.
*   **Police Report Number** (`police_report_number`, text, optional): If applicable, provide the police report number.
*   **Medical Treatment Received** (`medical_treatment`, select_one, required): Indicate if medical treatment was received.
*   **Medical Provider Name** (`medical_provider`, text, optional): If applicable, provide the name of the medical provider.
*   **Date of Medical Treatment** (`treatment_date`, date, optional): If applicable, provide the date medical treatment was received.
*   **Claim Amount Requested** (`claim_amount`, number, required): This field is for the amount of the claim.
*   **Supporting Documentation Attached** (`supporting_documentation`, text, optional): If applicable, list any supporting documentation attached.
*   **Prior Claims with This Insurer** (`prior_claims`, select_one, required): Indicate if you have filed prior claims with this insurer.
*   **Form Submission Date** (`claim_submission_date`, date, required): This field is for the date the form was completed.
