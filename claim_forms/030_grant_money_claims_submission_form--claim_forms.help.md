# Grant Money Claims Submission Form - Help Guide
## Purpose
This form is used for submitting claims for grants. It guides users through the process of providing necessary information for a grant application.

## How To Complete This Form
To submit a claim, follow these steps:

* Fill in all required fields. Fields marked as optional can be left blank if not applicable.
* Be accurate and truthful in your responses to ensure a successful submission.

## Field-by-Field Explanation
* **grant_money_claims_submission_form** (Grant Money Claims Submission Form): This is the title of the form.
* **grant_money_claims_form_fields** (Grant Money Claims Form Fields): This section contains fields related to grant claims submission.
* **grant_money_claims_form_files_uploads** (Grant Money Claims Form Files Uploads): This section is for uploading relevant files.
* **form_submission** (Form Submission): Check to confirm that the submission is correct.
* **file_uploads** (File Uploads): Check if files are uploaded.
* **claim_id** (Claim ID): Select 'Yes' if this is a new claim.
* **grant_money** (Grant Money): Enter the grant amount.
* **grant_date** (Grant Date): Enter the date of the grant.
* **submission_date** (Submission Date): Enter the date of submission.
* **status** (Status): Select 'Active' if the claim is active.
* **file_type** (File Type): Select 'Yes' for file upload.
* **file_name** (File Name): Enter the file name.
* **file_size** (File Size): Enter the file size.
* **file_description** (File Description): Enter the file description.
* **file_url** (File URL): Enter the file URL.
* **file_mimetype** (File MIME Type): Enter the file MIME type.
* **file_user** (File User): Enter the file user.
* **file_status** (File Status): Select 'Active' for active file.
* **form_submission_id** (Form Submission ID): Enter the form submission ID.
* **form_submission_date** (Form Submission Date): Enter the form submission date.
* **form_submission_status** (Form Submission Status): Select 'Active' for active submission.
* **file_submission** (File Submission): Check to confirm file submission.
* **claim_form_id** (Claim Form ID): Enter the claim form ID.
* **form_version** (Form Version): Enter the form version.

Note: Please make sure to review and understand the fields before submitting a claim. If you have any doubts, please consult your supervisor or the grant office.
