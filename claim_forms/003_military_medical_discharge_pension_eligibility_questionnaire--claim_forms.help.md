# Military Medical Discharge Pension Eligibility Questionnaire - Help Guide
## Purpose
The Military Medical Discharge Pension Eligibility Questionnaire is used to determine the eligibility of military personnel for a medical discharge pension. This form helps gather information about the military service history, medical discharge status, and pension eligibility of the claimant.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Please review each field carefully and answer the questions according to your military service history.
2. If you are unsure about any of the questions, please contact your military representative or pension officer for guidance.
3. Complete each field with the requested information, taking care to select the correct options from the dropdown lists.
4. Once you have completed all the fields, review your answers carefully to ensure they are accurate and complete.
5. Submit the form for processing.

## Field-by-Field Explanation

* **Military Medical Discharge Pension Eligibility (1)** (`military_medical_discharge_pension_eligibility`): This field is not applicable as it is a title.
* **Military Service (2)** (`military_service`): 
  * Select "Yes" if you have served in the military.
  * Select "No" if you have not served in the military.
* **Military Branch (3)** (`military_branch`): 
  * Select the branch of military service (Army, Marine, Navy, Air Force, or Coast Guard).
* **Military Service Period (4)** (`military_service_period`): 
  * Select the periods of military service (World War 2, Korean War, Vietnam War, Gulf War, Iraq War, or Afghanistan War).
* **Discharge Status (5)** (`discharge_status`): 
  * Select "Active" if you are currently serving in the military.
  * Select "Inactive" if you are not currently serving in the military.
* **Pension Eligibility (6)** (`pension_eligibility`): 
  * Select "Yes" if you are eligible for a pension.
  * Select "No" if you are not eligible for a pension.
* **Pension Type (7)** (`pension_type`): 
  * Select the type of pension you are applying for (Military Pension, VA Pension, Social Security Disability Insurance (SSDI), or Compensation and Pension).
* **Military Medical History (8)** (`military_medical_history`): 
  * Select "Yes" if you have a military medical history.
  * Select "No" if you do not have a military medical history.
* **Dependent Status (9)** (`dependent_status`): 
  * Select "Active" if you have dependents.
  * Select "Inactive" if you do not have dependents.
* **Dependent Relationships (10)** (`dependent_relationships`): 
  * Select "Yes" if you have dependents.
  * Select "No" if you do not have dependents.
* **Service Connection (11)** (`service_connection`): 
  * Select "Yes" if you have a service connection.
  * Select "No" if you do not have a service connection.
* **Veteran Status (12)** (`veteran_status`): 
  * Select "Active" if you are a veteran.
  * Select "Inactive" if you are not a veteran.
* **Military Discharge (13)** (`military_discharge`): 
  * Select "Yes" if you have been medically discharged.
  * Select "No" if you have not been medically discharged.
* **Medical Cause (14)** (`medical_cause`): 
  * Enter the medical cause of your discharge.
* **Disability Determination (15)** (`disability_determination`): 
  * Select "Yes" if you have a disability determination.
  * Select "No" if you do not have a disability determination.
* **Service-Connected Disability (16)** (`service_connected_disability`): 
  * Select "Yes" if your disability is service-connected.
  * Select "No" if your disability is not service-connected.
* **Veteran Service Disability (17)** (`veteran_service_disability`): 
  * Select "Yes" if you have a veteran service disability.
  * Select "No" if you do not have a veteran service disability.
* **Medical Discharge Certification (18)** (`medical_discharge_certification`): 
  * Select "Yes" if you have a medical discharge certification.
  * Select "No" if you do not have a medical discharge certification.
* **Veteran Status Verification (19)** (`veteran_status_verification`): 
  * Select "Active" if you are a verified veteran.
  * Select "Inactive" if you are not a verified veteran.
* **Medical Certification Verification (20)** (`medical_certification_verification`): 
  * Select "Yes" if you have a medical certification.
  * Select "No" if you do not have a medical certification.
* **Claimant Declaration (21)** (`claimant_declaration`): 
  * Select "Yes" if you are declaring as a claimant.
  * Select "No" if you are not declaring as a claimant.
* **Claimant Signature (22)** (`claimant_signature`): 
  * Select "Yes" if you have signed as a claimant.
  * Select "No" if you have not signed as a claimant.
* **Claimant Date (23)** (`claimant_date`): 
  * Enter the date you signed as a claimant.
* **Claimant Time (24)** (`claimant_time`): 
  * Enter the time you signed as a claimant.
* **Claimant Relationship (25)** (`claimant_relationship`): 
  * Select "Yes" if you have a claimant relationship.
  * Select "No" if you do not have a claimant relationship.

## Tips

* Please ensure that you have carefully reviewed each field before submitting the form.
* If you are unsure about any of the questions, please contact your military representative or pension officer for guidance.
* Complete each field accurately and thoroughly to ensure that your application is processed correctly.
