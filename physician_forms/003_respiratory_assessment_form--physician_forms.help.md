# Respiratory Assessment Form - Help Guide
## Purpose
The Respiratory Assessment Form is a medical tool used to evaluate and document the respiratory system and related information of patients. It helps healthcare professionals gather vital data that aids in identifying potential respiratory problems and providing targeted treatment.

## How To Complete This Form
- Please answer all questions honestly and thoroughly. This form is designed to help healthcare professionals make informed decisions about patient care.
- Review each page carefully to ensure all required fields are completed.
- If you're unsure about any question, please seek guidance from the healthcare professional completing the form with you.

## Field-by-Field Explanation

* **Patient Information** (<name>): This field is used to collect essential personal details such as name, date of birth, and contact information.
	+ Required: Yes
	+ Type: Text field
	+ Purpose: To identify the patient correctly and establish contact.
* **Medical History** (<name>): This field is used to collect information about the patient's medical history, including previous respiratory issues and current medical conditions.
	+ Required: Yes
	+ Type: Text field
	+ Purpose: To gather essential background information that may impact respiratory function.
* **Lung Functions** (<name>): This field measures the patient's lung function, typically expressed in numbers (e.g., FEV1, FVC, etc.).
	+ Required: Yes
	+ Type: Number field
	+ Purpose: To assess lung function and identify potential impairments.
* **Oxygen Saturation** (<name>): This field measures the patient's oxygen saturation levels, typically expressed as a percentage (e.g., 92%, 98%).
	+ Required: Yes
	+ Type: Number field
	+ Purpose: To assess the patient's oxygen levels in the blood.
* **Respiratory Rate** (<name>): This field measures the patient's breathing rate, typically expressed in breaths per minute (e.g., 12, 18, etc.).
	+ Required: Yes
	+ Type: Number field
	+ Purpose: To assess the patient's respiratory rate and identify potential problems.
* **Respiratory System** (<name>): This field asks the patient to identify their current respiratory system, such as Oxygen therapy, CPAP/BiPAP, Ventilator, or Non-invasive ventilation.
	+ Required: Yes
	+ Type: Select one field
	+ Purpose: To document the patient's current respiratory system.
* **Oxygen Flow** (<name>): This field measures the patient's oxygen flow, typically expressed in liters per minute (e.g., 2, 10, etc.).
	+ Required: Yes
	+ Type: Number field
	+ Purpose: To assess the patient's oxygen flow and adjust as needed.
* **Respiratory Rate 2** (<name>): This field is used to collect a second measurement of the patient's respiratory rate.
	+ Required: Yes
	+ Type: Number field
	+ Purpose: To verify the patient's respiratory rate.
* **Respiratory System 2** (<name>): This field asks the patient to identify their current respiratory system (same options as above).
	+ Required: Yes
	+ Type: Select one field
	+ Purpose: To document the patient's current respiratory system.
* **Patient Info** (<name>): This field collects additional patient information, such as contact details or next of kin contact information.
	+ Required: Yes
	+ Type: Text field
	+ Purpose: To gather essential contact information for the patient.
* **Respiratory System 3** (<name>): This field asks the patient to identify their current respiratory system (same options as above).
	+ Required: Yes
	+ Type: Select one field
	+ Purpose: To document the patient's current respiratory system.
* **Oxygen Flow 2** (<name>): This field measures the patient's oxygen flow (same unit as above).
	+ Required: Yes
	+ Type: Number field
	+ Purpose: To assess the patient's oxygen flow and adjust as needed.

## Tips
* Please review all fields carefully to ensure accurate completion of the form.
* If you're unsure about any question, please seek guidance from a healthcare professional.
* Complete the form in a clean and quiet environment to minimize errors.
* Please answer honestly and truthfully to provide the best possible care and treatment.
