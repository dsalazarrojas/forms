# Telemedicine E Visit Request Form - Help Guide
## Purpose
This form is used to request a telemedicine E-Visit, a virtual consultation with a physician. It is used to collect information from patients, including their medical history, contact details, and requesting information.

## How To Complete This Form
1. Fill out all required fields, denoted by an asterisk (*). This will ensure that your request is processed accurately and efficiently.
2. Enter your information carefully and accurately, as this will be used to create your telemedicine E-Visit request.
3. If you have any issues or questions while completing the form, please contact your physician or medical office staff for assistance.

## Field-by-Field Explanation
* **Patient Information** (`telemedicine_e_visit_request_form_1`, text, optional):
	+ This field is used to input patient's name, date of birth, or any other identifying information.
* **Medical Information** (`telemedicine_e_visit_request_form_2`, text, optional):
	+ This field is used to input the patient's medical history, including any relevant medical conditions or allergies.
* **Contact Information** (`telemedicine_e_visit_request_form_3`, text, optional):
	+ This field is used to input the patient's contact information, including their phone number and email address.
* **Medical Conditions** (`telemedicine_e_visit_request_form_4`, select multiple, optional):
	+ This field is used to select multiple medical conditions that apply to the patient.
* **Request Reason** (`telemedicine_e_visit_request_form_5`, text, optional):
	+ This field is used to input the reason for the telemedicine E-Visit request.
* **Request Date** (`telemedicine_e_visit_request_form_6`, date, optional):
	+ This field is used to input the date of the requested telemedicine E-Visit.
* **Request Time** (`telemedicine_e_visit_request_form_7`, time, optional):
	+ This field is used to input the time of the requested telemedicine E-Visit.
* **Physician Information** (`telemedicine_e_visit_request_form_8`, text, optional):
	+ This field is used to input the physician's information, including their name and contact details.
* **Requesting Physician** (`telemedicine_e_visit_request_form_9`, select one, optional):
	+ This field is used to select the requesting physician.

* **Request Type** (`telemedicine_e_visit_request_form_11`, select one, optional):
