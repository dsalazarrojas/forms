# Mpox Case Report Form - Help Guide
## Purpose
The Mpox Case Report Form is designed to collect information about MPox cases from healthcare professionals for disease surveillance and outbreak management purposes.

## How To Complete This Form
To complete this form accurately and thoroughly, please follow the steps outlined above.

## Field-by-Field Explanation

* **Mpox Case Report Form (1)**: This field is for a brief summary of the case.
* **patient name (2)**: Enter the name of the patient.
* **patient age (3)**: Enter the age of the patient.
* **gender (4)**: Select the patient's gender from the options provided.
* **symptoms description (5)**: Describe the patient's symptoms in detail.
* **exposure date (6)**: Record the date of exposure to the disease.
* **contact history (7)**: Provide any relevant contact history related to the case.
* **travel history (8)**: If applicable, provide travel history for the patient.
* **vaccination status (9)**: Indicate the patient's vaccination status.
* **contact trace details (10)**: Record any details related to contact tracing.
* **diagnosis confirmed (11)**: Indicate whether the diagnosis has been confirmed or not.
* **test results (12)**: Record any test results related to the case.
* **patient contact trace (13)**: Indicate whether the patient has undergone contact tracing.
* **exposure site (14)**: If applicable, record the exposure site.
* **exposure source (15)**: If applicable, record the exposure source.
* **symptoms start date (16)**: Record the date the symptoms started.
* **symptoms end date (17)**: Record the date the symptoms ended.
* **patient outcome (18)**: Select the patient's outcome (e.g., recovered, deceased, or pending).
* **patient outcome details (19)**: Provide any further details about the patient's outcome.
* **case reported (20)**: Indicate whether the case has been reported.
* **reporter info (21)**: Provide any relevant information about the reporter.
* **case type (22)**: Select the case type (e.g., confirmed, suspected, or probable).
* **contact type (23)**: Select the contact type (e.g., close contact, casual contact, or household contact).
* **exposure type (24)**: Select the exposure type (e.g., close exposure, casual exposure, or household exposure).
* **other details (25)**: Record any other relevant details about the case.

## Tips
Please answer the questions accurately and completely, as the information you provide will be used to inform public health decisions.
