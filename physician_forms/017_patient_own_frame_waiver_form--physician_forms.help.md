# Patient Own Frame Waiver Form - Help Guide
## Purpose
This form is used to gather information from patients about their own frame choices.
## How To Complete This Form
To complete this form, please follow these steps:

* Select the "Patient Own Frame Waiver Form" page.
* Choose one of the options for "Patient Own Frame Information" depending on your preference:
	+ If you prefer "Patient Own", select that option.
	+ If you prefer "Other", select that option and fill in "Other Frame" field.
* Choose the type of frame you would like to use from the options provided:
	+ Single Vision
	+ Progressive
	+ Bifocal
	+ High Index
	+ Aspheric
* Answer the questions:
	+ If you currently use a single vision frame, answer "True" to "Is your current frame a single vision?".
	+ If you do not currently use a single vision frame, answer "False".
	+ Answer "True" if you have other frames you would like to use, and "Other Frame" field will appear.
	+ If you do not have other frames you would like to use, answer "False".
* Fill in the "Other Frame" field if you selected "Other" for "Patient Own Frame Information" and "True" for "Do you have any other frames you'd like to use?". Choose the type of frame you would like to use from the options provided:
	+ High Index
	+ Bifocal
	+ Aspheric

## Field-by-Field Explanation
* **Patient Own Frame Waiver Form** (Required):
	+ This is the title of the form.
* **Patient Own Frame Information** (Select Multiple, Required: False):
	+ Choose one of the options for this field.
* **What type of frame would you like to use** (Select One, Required: False):
	+ Choose the type of frame you would like to use.
* **Is your current frame a single vision?** (Select One, Required: False):
	+ Answer "True" if you currently use a single vision frame, "False" otherwise.
* **Do you have any other frames you'd like to use?** (Select One, Required: False):
	+ Answer "True" if you have other frames you would like to use, "False" otherwise.
* **Other Frame** (Text, Required: False):
	+ If you selected "Other" for "Patient Own Frame Information" and "True" for "Do you have any other frames you'd like to use?", fill in this field.
* **Type of other frame?** (Select One, Required: False):
	+ If you selected "Other" for "Patient Own Frame Information" and "True" for "Do you have any other frames you'd like to use?", choose the type of frame you would like to use from the options provided.
