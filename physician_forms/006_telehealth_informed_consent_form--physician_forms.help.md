# Telehealth Informed Consent Form - Help Guide
## Purpose
The Telehealth Informed Consent Form is a document used to obtain informed consent from patients before starting telehealth services. It ensures that patients understand the terms and conditions of their engagement and provides a clear understanding of the services they will receive.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Category" that best describes the form's purpose (e.g., "Physician Forms" or "Other Forms").
2. Enter a brief "Description" of the form's purpose and content.
3. Select the "Output File" that corresponds to the type of consent form you are creating (e.g., "006 telehealth informed consent form--physician forms.docx").
4. Choose the "Assigned Tool" that will be used to create the form (e.g., "chatjimmy" or "jotform").
5. Fill in the "Form ID" with the unique ID number for the form (e.g., "12345").

## Field-by-Field Explanation
* **Category (id: 2)**: Select the category that best describes the form's purpose. This will help determine the form's type and content.
* **Description (id: 3)**: Enter a brief description of the form's purpose and content. This will help provide context for the form's information.
* **Output File (id: 4)**: Select the output file that corresponds to the type of consent form you are creating. This will determine the form's layout and content.
* **Assigned Tool (id: 5)**: Choose the tool that will be used to create the form. This will affect the form's functionality and features.
* **Form ID (id: 6)**: Fill in the unique ID number for the form. This will identify the form within the system.
