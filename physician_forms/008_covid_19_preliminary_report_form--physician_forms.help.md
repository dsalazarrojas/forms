# Covid 19 Preliminary Report Form - Help Guide
## Purpose
The Covid 19 Preliminary Report Form is used to record patient data for COVID-19 cases.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields with the necessary information.
2. Review each field for any additional guidance or hints provided.

## Field-by-Field Explanation

* **Patient Name** (`patient_name`, text, required): Enter the name of the patient.
* **Vaccine Name** (`vaccine_name`, text, required): Enter the name of the vaccine administered to the patient.
* **Patient ID** (`patient_id`, number, required): Enter the patient's ID number.
* **Date Received** (`date_received`, date, required): Enter the date the patient received the vaccine.
* **Date Reported** (`date_reported`, date, required): Enter the date the patient's test result was reported.
* **Vaccine Dose** (`vaccine_dose`, number, required): Enter the dose of the vaccine administered.
* **Symptoms** (`symptoms`, text, required): Describe any symptoms the patient is experiencing.
* **Test Result** (`test_result`, select_one, required): Select the patient's test result (Positive, Negative, or Indeterminate).
* **Test Date** (`test_date`, date, required): Enter the date the patient's test was performed.
* **Side Effects** (`side_effects`, text, required): Describe any side effects the patient has experienced.
* **Patient Outcome** (`patient_outcome`, text, required): Record the patient's outcome.
* **Medical Notes** (`medical_notes`, text, required): Record any medical notes about the patient.
* **Follow-up Scheduled** (`follow_up_scheduled`, select_one, required): Select if a follow-up is scheduled (True, False, or Not Scheduled).
* **Follow-up Comments** (`follow_up_comments`, text, required): Enter any comments about the follow-up.
* **Vaccine Lot** (`vaccine_lot`, text, required): Enter the vaccine lot number.

## Tips
Please ensure you have all necessary information before submitting the form. If you're unsure about any field, refer back to this guide for guidance.
