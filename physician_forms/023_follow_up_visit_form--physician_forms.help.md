# follow_up_visit_form - Help Guide
## Purpose
This form is designed to capture information for follow-up visits with patients after an initial visit or treatment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the "patient name" field.
2. Enter the patient's age in the "patient age" field.
3. Provide any relevant medical history in the "medical history" field.
4. List any medication allergies in the "medication allergies" field.
5. Describe any medical procedures performed in the "medical procedure" field.
6. Record the patient's vital signs in the "vital signs" field (note: this field is for free-formatted information).
7. Select the patient's status from the "patient status" dropdown menu.
8. Enter any follow-up notes for the patient in the "follow up notes" field.
9. Select the date of the next visit in the "next visit" field.
10. Select the doctor performing the follow-up visit in the "follow up doctor" field.
11. Select the time of the next visit in the "follow up visit time" field.
12. Repeat this process for any additional medical history, medications, contact information, and doctor notes as needed.
13. Enter the date and time of the follow-up visit in the "follow up visit date" and "follow up visit time" fields, respectively.
14. Select the doctor performing the follow-up visit in the "follow up doctor 2" field.
15. Select the doctor performing the follow-up visit in the "follow up doctor 3" field.
16. Select "yes" or "no" to indicate if the follow-up visit is with the same doctor in the "follow up doctor 4" field.
17. Select the doctor performing the follow-up visit in the "follow up doctor 5" fields.
18. Select the doctor performing the follow-up visit in the "follow up doctor 6" field.
19. Select the doctor performing the follow-up visit in the "follow up doctor 7" field.
20. Enter the date of the next visit in the "follow up visit date 2" field.
21. Select the time of the next visit in the "follow up visit time 2" field.
22. Enter the date of the next visit in the "follow up visit date 3" field.

## Field-by-Field Explanation

* **patient name** (`patient_name`, text, required): The patient's name is entered in this field for identification purposes.
* **patient age** (`patient_age`, number, optional): The patient's age is entered in this field.
* **patient condition** (`patient_condition`, text, optional): This field is for any relevant medical conditions affecting the patient.
* **medical history** (`medical_history`, text, optional): Any relevant medical history is entered in this field.
* **medication allergies** (`medication_allergies`, text, optional): List any medication allergies in this field.
* **medical procedure** (`medical_procedure`, text, optional): Describe any medical procedures performed on the patient.
* **vital signs** (`vital_signs`, note, optional): Record any vital signs taken during the visit, such as blood pressure, heart rate, etc.
* **patient status** (`patient_status`, select_one, optional): Select the patient's current status, such as "stable", "stable but requires close monitoring", etc.
* **follow up notes** (`follow_up_notes`, text, optional): Enter any follow-up notes for the patient.
* **next visit** (`next_visit`, date, optional): Enter the date of the next visit.
* **follow up doctor** (`follow_up_doctor`, select_one, optional): Select the doctor performing the follow-up visit.
* **follow up time** (`follow_up_time`, time, optional): Select the time of the next visit.
* **medical history 2** (`medical_history2`, text, optional): Enter any additional medical history.
* **medication 2** (`medication2`, text, optional): List any additional medications taken by the patient.
* **contact** (`contact`, text, optional): Enter any contact information for the patient.
* **physician notes** (`physician_notes`, text, optional): Enter any additional physician notes.
* **follow up visit date** (`follow_up_visit_date`, date, optional): Enter the date of the next visit.

* **follow up doctor 3** (`follow_up_doctor3`, select_one, optional): Select the doctor performing the follow-up visit.
* **follow up doctor 4** (`follow_up_doctor4`, select_one, optional): Select "yes" or "no" to indicate if the follow-up visit is with the same doctor.

## Tips
* Please ensure that all fields are completed accurately and thoroughly.
* Double-check the information entered to prevent any errors or discrepancies.
* If you are unsure about any field or its requirement, please consult with your supervisor or the patient's primary care provider.
* This form is intended to be used in a medical setting, and the information gathered is confidential. Handle the data with care and respect patient privacy.
