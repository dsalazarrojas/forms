# Home Blood Pressure Report Form - Help Guide
## Purpose
This form is designed to collect data on a patient's blood pressure readings, including systolic and diastolic values, pulse rates, and timestamps for each reading. The form is intended for healthcare professionals to record and analyze the patient's blood pressure data.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date of the blood pressure reading using the "Date" field.
2. Enter the time of the reading using the "Time" field in the format "HH:MM".
3. Enter the systolic pressure value(s) using the "Systolic Value 1" and "Systolic Value 2" fields.
4. Enter the diastolic pressure value(s) using the "Diastolic Value 1" and "Diastolic Value 2" fields.
5. Enter the pulse rate value(s) using the "Pulse Value 1" and "Pulse Value 2" fields.
6. Enter the user's name using the "User Name" field.

## Field-by-Field Explanation
* **Systolic**: Enter the first systolic pressure value measured.
* **Systolic Value 2**: Enter the second systolic pressure value measured.
* **Diastolic**: Enter the first diastolic pressure value measured.
* **Diastolic Value 2**: Enter the second diastolic pressure value measured.
* **Pulse**: Enter the pulse rate measured.
* **Pulse Value 2**: Enter the second pulse rate measured.
* **Date**: Enter the date of the blood pressure reading in the format "MM/DD/YY" or "MM/DD/YY".
* **Time**: Enter the time of the reading in the format "HH:MM".
* **User Name**: Enter the patient's name to associate the reading with the correct individual.

## Tips
* Ensure the date and time are accurate to enable precise analysis.
* Enter both systolic and diastolic values to ensure a complete picture of the patient's blood pressure.
* Enter multiple readings for comparison and trend identification.
* Use a valid reason for filling out this form again, to avoid redundancy.
