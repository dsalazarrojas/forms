# Skin Tag Removal Consent Form - Help Guide

## Purpose
This form is designed to gather information from patients for a skin tag removal procedure. It is a consent form that needs to be completed by the client prior to the procedure. 

## How To Complete This Form
1. Please ensure you have read the instructions carefully before starting.
2. Enter the client's information in the field "Client Information".
3. If the client is eligible for the procedure, check the type of skin tag removal in field "Tag Type".
4. Select the date for the skin tag removal procedure in "Skin Tag Removal Date" field.
5. The "Physician Signature" field is for the doctor's confirmation of the form completion.

## Field-by-Field Explanation
### Client Information 
* **Client Information** (`client_info`, text, required: false): This section is for entering the client's details such as their name, contact information, or other relevant data that the practitioner might find useful.

### Tag Type 
* **Tag Type** (`tag_type`, select_multiple, required: false): This option is used to determine which type of skin tag removal the client is interested in, select one or more from the list. This field is not required.

### Skin Tag Removal Date 
* **Skin Tag Removal Date** (`skin_tag_removal_date`, date, required: false): This is the date on which the skin tag removal procedure will take place. It is not required but it's a useful information for scheduling purposes.

### Physician Signature 
* **Physician Signature** (`physician_signature`, note, required: false): This field is for the doctor's confirmation of the form completion. 

### Tips
* Make sure to review the information you enter carefully before submitting the form.
* If you need help with any of the fields, don't hesitate to ask the practitioner.
* Ensure all fields that are required are completed before proceeding with the form submission.
