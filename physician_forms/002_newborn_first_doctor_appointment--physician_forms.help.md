# Newborn First Doctor Appointment - Help Guide
## Purpose
This form is used to collect information from medical professionals during a newborn's first doctor appointment. It is designed to gather data on the baby's vital signs, reflexes, and motor function tests as part of the initial medical evaluation.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the relevant medical evaluations or sections that apply to the newborn's condition. This can include physical examination, reflexes, and motor function tests.
2.  Fill in the relevant form sections with the corresponding information. This can include text-based responses or selections from multiple-choice options.
3.  Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

*   **Newborn Physical Exam** (id: 1, type: select_multiple, required: true): This field allows you to select which parts of the newborn's physical examination apply. Choose all relevant options to provide a comprehensive overview of the baby's condition.
*   **Newborn First Doctor Appointment Form 1** (id: 2, type: text, required: false): This field is a text-based input section for any additional information related to the newborn's first doctor appointment. You can enter any relevant comments or notes about the baby's condition.
*   The remaining fields (id: 3-25, type: text, required: false): These are additional text-based input sections for any other information related to the newborn's medical evaluation. You can enter any relevant comments or notes about the baby's condition in each of these fields.

## Tips

*   Be as detailed as possible when filling in the relevant fields to provide a comprehensive overview of the newborn's condition.
*   Ensure all required fields are completed before submitting the form.
*   If you are unsure about any part of the form, consult with medical staff or the relevant medical professional for guidance.
