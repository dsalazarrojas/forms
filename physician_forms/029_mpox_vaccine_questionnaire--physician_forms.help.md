# Mpox Vaccine Questionnaire - Help Guide
## Purpose
The Mpox Vaccine Questionnaire is designed to collect information about individuals who are being assessed for eligibility for the Mpox vaccine. This form helps healthcare professionals make informed decisions about vaccination.

## How To Complete This Form

To complete this form, please follow these steps:

1. **Introduction**: This is the first page of the form and serves as an introduction to the questionnaire. It will help you understand the purpose of the form.
2.  **Age**: Please enter your age.
3.  **Sex**: Select your sex.
4.  **Medical Condition**: Check all medical conditions that apply.
5.  **Previous Vaccination**: Select all previous vaccinations that apply.
6.  **Vaccination Status**: Select your current vaccination status.
7.  **Symptoms**: Select all symptoms that apply.
8.  **Previous Contact**: Check all previous contacts that apply.
9.  **Contact Status**: Select your contact status.
10. **Exposure Risk**: Select all exposure risks that apply.
11. **Travel History**: Check all travel history that apply.
12. **Sexually Active**: Check if you are sexually active.
13.  **Sexually Active with**: Select all types of sexual activity that apply.
14.  **Mpox Vaccinated**: Select all vaccinations that apply.
15.  **Mpox Tested Positive**: Select if you have tested positive for mpox.
16.  **Contact Type**: Select all contact types that apply.
17.  **Contact Source**: Select all contact sources that apply.
18.  **Exposure Date**: Enter the date of exposure.
19.  **Exposure Start Date**: Enter the start date of exposure.
20.  **Exposure End Date**: Enter the end date of exposure.
21.  **Vaccination Date**: Enter the date of vaccination.
22.  **Vaccination Dosage**: Enter the dosage of the vaccination.
23.  **Vaccination Status 2**: Select your current vaccination status.
24.  **Mpox Vaccination Status**: Select your current vaccination status for mpox.
