# TB Skin Test Results Form - Help Guide
## Purpose
The purpose of this form is to document the results of a TB skin test, including patient information, test site, test results, and follow-up details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the "Patient Name" field.
2. Record the date of the test in the "Test Date" field.
3. Select the test site from the options provided.
4. Choose the test result from the options provided.
5. Enter the physician's name in the "Physician Name" field.
6. Sign the form with the physician's signature.
7. If necessary, enter additional comments or notes about the test site in the "Test Site Notes" field.
8. Enter any additional comments or notes about the test in the "Additional Comments" field.
9. Record the result date in the "Result Date" field, if applicable.
10. Record the follow-up date and comments, if applicable.

## Field-by-Field Explanation
### 1. Patient Name (Required)
* **Patient Name**: Enter the name of the patient who underwent the TB skin test.
### 2. Test Date (Required)
* **Test Date**: Record the date on which the TB skin test was conducted.
### 3. Test Site (Required)
* **Test Site**: Select the location on the body where the TB skin test was applied, such as left forearm, right forearm, left lower arm, or right lower arm.
### 4. Test Result (Required)
* **Test Result**: Choose the result of the test from the options provided, such as negative, positive, or borderline positive.
### 5. Physician Name (Required)
* **Physician Name**: Enter the name of the medical professional who conducted the test.
### 6. Physician Signature (Required)
* **Physician Signature**: Sign the form with the physician's signature to confirm the results.
### 7. Test Site Notes (Optional)
* **Test Site Notes**: Enter any additional comments or notes about the test site, if necessary.
### 8. Additional Comments (Optional)
* **Additional Comments**: Enter any additional comments or notes about the test, if necessary.
### 9. Result Date (Required if applicable)
* **Result Date**: Record the date of the test result, if applicable.
### 10. Follow-up Date (Optional)
* **Follow-up Date**: Record the date of the follow-up, if applicable.
### 11. Follow-up Comments (Optional)
* **Follow-up Comments**: Enter any comments or notes about the follow-up, if applicable.
