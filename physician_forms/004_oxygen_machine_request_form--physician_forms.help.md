# Oxygen Machine Request Form - Help Guide
## Purpose
The Oxygen Machine Request Form is used to report maintenance and repair needs for office oxygen machines. This form helps track the status and history of oxygen machines, ensuring timely and efficient service.

## How To Complete This Form

To fill out this form, please follow these steps:

*   Enter the office location where the machine is located
*   Enter the office number where the machine is located
*   Choose the type of oxygen machine that requires maintenance or repair (e.g., Oxygen Machine, Oxygen Concentrator, Oxygen Generator, or Oxygen Purifier)
*   Enter the model of the oxygen machine
*   Enter the date the machine was purchased
*   Enter the date of the last service or maintenance performed on the machine
*   Enter the serial number of the oxygen machine
*   Enter the asset tag number associated with the machine
*   Select the status of the asset tag (e.g., Available, Lost, Sold, Retired, or Missing)
*   Enter any additional notes about the machine (e.g., maintenance history, issues, or concerns)
*   Enter the provider of the oxygen machine (optional)
*   Enter the supplier of the oxygen machine (optional)
*   Enter the serial number of the oxygen machine (optional)
*   Enter the date the oxygen machine was purchased (optional)

## Field-by-Field Explanation

*   **Oxygen Machine Request Form**
    This is the title of the form.
*   **Office Location**
    Enter the office location where the oxygen machine is currently located.
*   **Office Number**
    Enter the office number where the oxygen machine is located.
*   **Oxygen Machine Type**
    Choose the type of oxygen machine that requires maintenance or repair.
    *   Oxygen Machine: A standard oxygen machine.
    *   Oxygen Concentrator: A machine that concentrates oxygen gas.
    *   Oxygen Generator: A machine that generates oxygen gas.
    *   Oxygen Purifier: A machine that purifies oxygen gas.
*   **Machine Model**
    Enter the model of the oxygen machine.
*   **Purchase Date**
    Enter the date the oxygen machine was purchased.
*   **Last Service**
    Enter the date of the last service or maintenance performed on the machine.
*   **Serial Number**
    Enter the serial number of the oxygen machine.
*   **Asset Tag Number**
    Enter the asset tag number associated with the machine.
*   **Asset Tag Status**
    Select the status of the asset tag.
    *   Available: The asset tag is currently available.
    *   Lost: The asset tag is lost.
    *   Sold: The asset tag is sold.
    *   Retired: The asset tag is retired.
    *   Missing: The asset tag is missing.
*   **Asset Notes**
    Enter any additional notes or comments about the machine (e.g., maintenance history, issues, or concerns).
*   **Oxygen Provider**
    Enter the provider of the oxygen machine (if known).
*   **Oxygen Supplier**
    Enter the supplier of the oxygen machine (if known).
*   **Oxygen Serial Number**
    Enter the serial number of the oxygen machine (if known).
*   **Oxygen Purchase Date**
    Enter the date the oxygen machine was purchased (if known).

## Tips

*   Please ensure that you have the correct information before completing this form.
*   If you are unsure about any of the information, please contact the relevant department or team for guidance.
*   Complete this form accurately and thoroughly to ensure that the maintenance or repair request is processed efficiently.
*   If you have any additional questions or concerns, please contact us for support.
