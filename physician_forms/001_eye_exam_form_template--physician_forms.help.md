# Eye Exam Form Template - Help Guide
## Purpose
This form is designed to collect information from patients for eye exams. It covers various aspects of the exam, including patient details, medical history, and examination results.

## How To Complete This Form

1. Fill in the patient's name on page 1.
2. Enter the doctor's name on page 1.
3. Select the type of exam performed on page 1.
4. Provide the date of the exam on page 1.
5. Choose the patient's gender from the options on page 2.
6. Enter the patient's date of birth on page 2.
7. Select the type of exam performed, if applicable, on page 2.
8. Provide medical history on page 3.
9. Select whether a prescription was issued on page 4.
10. Check if a follow-up is scheduled on page 4.
11. Select whether contact lenses were used on page 5.
12. Choose the type of contact lens used, if applicable, on page 5.
13. Provide the power of the contact lens on page 5.
14. Select the spectacle prescription type on page 6.
15. Provide the power of the spectacle prescription on page 6.
16. Enter the contact lens solution used on page 6.
17. Enter the spectacle frame type on page 6.
18. Enter the eye exam result on page 7.
19. Provide more details about the eye exam result on page 7.
20. Enter the spectacle frame 1-6, if applicable, on page 8-9.

## Field-by-Field Explanation

* **Patient Name (page 1)**: Enter the patient's full name.
* **Doctor Name (page 1)**: Enter the full name of the doctor who performed the exam.
* **Date Exam Performed (page 1)**: Enter the date the exam was performed, using the format MM/DD/YYYY.
* **Patient Gender (page 2)**: Select the patient's gender from the options.
* **Patient DOB (page 2)**: Enter the patient's date of birth, using the format MM/DD/YYYY.
* **Eye Exam Type (page 2)**: Select the type of exam performed, if applicable.
* **Medical History (page 3)**: Provide any relevant medical history for the patient.
* **Medical History 2 (page 3)**: Provide any additional medical history, if necessary.
* **Prescription (page 4)**: Select whether a prescription was issued.
* **Follow Up Scheduled (page 4)**: Check if a follow-up appointment is scheduled.
* **Contact Lenses (page 5)**: Select whether contact lenses were used.
* **Contact Lens Type (page 5)**: Choose the type of contact lens used, if applicable.
* **Contact Lens Power (page 5)**: Enter the power of the contact lens.
* **Spectacle Prescription (page 6)**: Select the spectacle prescription type.
* **Spectacle Prescription Power (page 6)**: Enter the power of the spectacle prescription.
* **Contact Lens Solution (page 6)**: Enter the contact lens solution used.
* **Spectacle Frame 1-6 (page 6-9)**: Enter the type of spectacle frame used, if applicable.
* **Eye Exam Result (page 7)**: Select the result of the eye exam.
* **Eye Exam Result Detail (page 7)**: Provide more details about the eye exam result.
* **Other relevant information (page 8-9)**: Fill in any other relevant information, if necessary. 

Note that this form is a template, you should adjust it according to your needs. 

Note that page 1 to 4 can be filled in by a medical professional, page 5 to 7 can be filled in by the doctor and page 8-9 can be left blank or filled in by a medical professional. 
Please make sure to adjust the form according to the specific eye exam type and your clinic needs. 
You may need to add or remove fields to make the form suitable for your clinic.
