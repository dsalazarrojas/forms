# Telemedicine Patient Information Form - Help Guide
## Purpose
This form is designed to collect medical history information from patients for telemedicine consultations.

## How To Complete This Form
1. Read through the form carefully and ensure you understand each field.
2. Answer each question truthfully and thoroughly.
3. Provide accurate and up-to-date information.
4. Review and submit the form.

## Field-by-Field Explanation
* **Medical History**: 
  • This section is used to record any medical issues you are currently experiencing or have experienced in the past. Please provide a detailed description of your medical history.
* **Insurance Information**:
  • This field is for providing your insurance information, including your insurance provider and policy number.
* **Contact Info**: 
  • Please provide your name, address, phone number, and email address.
* **Medical Contact Information**:
  • Select 'Yes' if you have any medical contact information you would like to share with the healthcare provider.
* **Medical History Allergies**:
  • Check 'Yes' if you have any allergies, and list them in the provided space.
* **Medical History Conditions**:
  • Check 'Yes' if you have any medical conditions, and list them in the provided space.
* **Medication List**:
  • Check 'Yes' if you are currently taking any medications, and list them in the provided space.
* **Contact Info Additional**:
  • If you have any additional contact information you would like to provide, please enter it here.
* **Emergency Contact Info**:
  • Select 'Yes' if you have an emergency contact you would like to share with the healthcare provider.
* **Emergency Contact Relationship**:
  • Please select 'Yes' if you would like the emergency contact to be reached in case of an emergency.
* **Medical History Surgeries**:
  • Check 'Yes' if you have had any surgeries, and list them in the provided space.
* **Medical History Fertility**:
  • Check 'Yes' if you have any concerns regarding fertility, and select 'Yes' if you are trying to become pregnant or are currently pregnant.
* **Medical History Tattoos**:
  • Check 'Yes' if you have any tattoos.
* **Medical History Vaccinations**:
  • Check 'Yes' if you have received any vaccinations, and list them in the provided space.
* **Medical History Vaccinations 2, 3, 4, 5, 6, 7, and 8**:
  • These fields are for additional vaccinations you may have received, and you can check 'Yes' if you have had them and list them in the provided space.
  Please note that these fields are for additional vaccinations and may not be required for every patient.
* **Emergency Contact Relationship**:
  • Select 'Yes' if you have an emergency contact you would like to share with the healthcare provider.
  Please note that this is for emergency situations only.
* **Review and Submit**: 
  • Once you have completed the form, please review it for accuracy and completeness.
