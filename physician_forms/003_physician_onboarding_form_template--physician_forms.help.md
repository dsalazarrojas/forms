# Physician Onboarding Form Template - Help Guide
## Purpose
The Physician Onboarding Form Template is a standard form used to guide new physicians through the onboarding process with our organization. This template provides a structured approach to capturing essential information about physicians, ensuring they are properly vetted and prepared to practice medicine with our organization.

## How To Complete This Form
To complete this form, follow these steps:

1.  **Select Category**: Please choose the "Physician Forms" category from the dropdown menu. This will help categorize and organize the form for efficient searching and use.
2.  **Provide Description**: Briefly describe this form template in the text box provided.
3.  **Assign Tool**: Choose the tool assigned to this form template from the dropdown menu (e.g., "chatjimmy").
4.  **Name Output File**: Give a name to the output file generated by this form template.
5.  **Unique Identifier (Form ID)**: Enter a unique number to identify this form template. 

## Field-by-Field Explanation

* **Category** (`category`, **select_one**, required): Select the category for this form template to help organize and categorize it.
* **Description** (`description`, **text**, optional): Briefly describe this form template in the text box provided.
* **Assigned Tool** (`assigned_tool`, **select_one**, required): Choose the tool assigned to this form template from the dropdown menu.
* **Output File** (`output_file`, **text**, optional): Give a name to the output file generated by this form template.
* **Form ID** (`form_id`, **number**, optional): Enter a unique identifier for this form template. **Note:** You may duplicate this field with a different name, which should have a different label.
* **Form ID 2** (`form_ids_2`, **number**, optional): Enter another unique identifier for this form template. 
* **Output File 2** (`output_file_2`, **text**, optional): Give another name to the output file generated by this form template. 

## Tips
- Please ensure that you fill out all required fields as indicated by the asterisk (\*). 
- If you have any questions, feel free to reach out to the relevant team.
