# sexually_transmitted_infection_report_form - Help Guide
## Purpose
The Sexually Transmitted Infection (STI) Report Form is used to collect information about patient's symptoms and medical history for the purpose of diagnosis and treatment planning.

## How To Complete This Form
To complete this form, follow these steps:

1.  Go to the first page (Patient Details) and enter the patient's information. This page is optional, but it helps us to better understand the patient's context.
2.  Go to the second page (Sti Symptoms) and select all the symptoms that apply to the patient's condition. This page is required.
3.  If applicable, go to the third page (Medical History) and provide any relevant information about the patient's medical history. This page is optional.

## Field-by-Field Explanation

*   **Patient Details**: This is the first page of the form where you can enter the patient's basic information.
    *   **Label**: Patient Details
    *   **Type**: Text
    *   **Required**: Optional
*   **Sti Symptoms**: This page allows you to select all the symptoms that apply to the patient's condition. Please select all that apply.
    *   **Label**: Sti Symptoms
    *   **Type**: Select Multiple
    *   **Required**: True
*   **Medical History**: This page is where you can provide any relevant information about the patient's medical history.
    *   **Label**: Medical History
    *   **Type**: Text
    *   **Required**: Optional
