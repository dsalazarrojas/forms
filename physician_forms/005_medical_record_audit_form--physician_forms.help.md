# Medical Record Audit Form - Help Guide
## Purpose

The Medical Record Audit Form is used to collect information for a medical record audit, which is a process to verify the accuracy and completeness of patient medical records.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Enter the name of the physician performing the audit.
3. Enter the ID number of the medical record being audited.
4. Enter the date of the audit.
5. Select the procedures and tests performed during the audit.
6. Enter the start and end times of the procedures.
7. Enter the name of the healthcare provider who performed the audit.
8. Select the audit level (e.g., Level 1, Level 2, Level 3).
9. Select the current status of the audit (e.g., Complete, Not Started, In Progress).
10. Enter any comments related to the audit.
11. Enter any additional audit comments if necessary.

## Field-by-Field Explanation

* **Physician Name (1)**: Enter the name of the physician performing the audit.
* **Medical Record ID (2)**: Enter the ID number of the medical record being audited.
* **Audit Date (3)**: Enter the date of the audit in the format MM/DD/YY.
* **Prophets and Procedures (4)**: Select all procedures and tests performed during the audit.
* **Procedure Start Time (5)**: Enter the start time of the procedure(s) in 24-hour format (HH:MM).
* **Procedure End Time (6)**: Enter the end time of the procedure(s) in 24-hour format (HH:MM).
* **Provider Name (7)**: Enter the name of the healthcare provider who performed the audit.
* **Audit Level (8)**: Select the audit level (e.g., Level 1, Level 2, Level 3).
* **Audit Status (9)**: Select the current status of the audit (e.g., Complete, Not Started, In Progress).
* **Comments (10)**: Enter any comments related to the audit.
* **Audit Comments (11)**: Enter any additional audit comments if necessary.
* **Audit Completion Date (12)**: Enter the date the audit was completed in the format MM/DD/YY.
