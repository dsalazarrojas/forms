# emergency-medical-form - Help Guide

## Purpose
This form is designed to gather information about patients who have experienced an emergency medical incident. It covers essential details such as patient identification, the circumstances surrounding the incident, and the treatment or condition of the patient. This information helps medical professionals provide accurate diagnosis and care.

## How To Complete This Form

### Page 1: emergency_medical_form_page_1
- **Title**: This is the name of the form, "emergency-medical-form".
  - This field is not editable and serves as a header for the form.

### Page 1: emergency_medical_form_page_1
- **patient_information**: This is the section for entering the patient's information.
  - This field is a text box where you can enter the patient's details.

### Page 1: emergency_medical_form_page_1
- **date_and_time_of_injury**: This is the field for selecting the date and time of the injury.
  - This field is a date input where you can choose the date and time of the incident.

### Page 1: emergency_medical_form_page_1
- **name_of_injured_person**: This is the field for entering the name of the patient.
  - This field is a text box for typing the name of the person injured.

### Page 1: emergency_medical_form_page_1
- **age_of_injured_person**: This is the field for selecting the age of the patient.
  - This field is a numerical input for selecting the patient's age.

### Page 1: emergency_medical_form_page_1
- **location_of_injury**: This is the field for describing the location of the injury.
  - This field is a text box for describing the location where the injury occurred.

### Page 1: emergency_medical_form_page_1
- **medical_condition**: This field allows selection of multiple medical conditions.
  - Select all the medical conditions that apply to the patient's situation.
  - Options include Cardiac arrest, Stroke, and Other.

### Page 1: emergency_medical_form_page_1
- **medical_conditions_list**: This is the field for listing any other medical conditions not listed above.
  - This text box allows you to add any other medical conditions related to the patient's injury.

### Page 1: emergency_medical_form_page_1
- **witness_info**: This field is for gathering any relevant witness information.
  - This text box is for noting any witness information.

### Page 2: patient_information (This page is not displayed as the first page with id 1 is the only displayed page)
- **physician_signature**: This is the field for signing the form.
  - This text box requires a signature from a medical professional.

### Page 2: patient_information
- **physician_license_number**: This is the field for entering the physician's license number.
  - This text box is for inputting the physician's license number.
  
## Tips

* Ensure all fields are completed accurately to provide the best possible care for the patient.
* Verify the information provided matches the patient's actual condition and circumstances.
* If a field is required but not applicable, mark it as such to avoid delays in treatment.
* The form is designed for emergency situations; it is essential to fill it out as soon as possible after the incident.
