# Covid Testing Form - Help Guide
## Purpose
The Covid Testing Form is designed to collect information from healthcare providers about a patient's Covid-19 testing process. This includes details about the testing site, test results, and other relevant patient contact information.

## How To Complete This Form
1. Fill out the form for each patient interaction, ensuring that the information provided is accurate and up-to-date.
2. Complete all the required fields.
3. If the test site is not listed in the "Test Site" dropdown menu, select "Other" and enter the specific test site name in the "Other Test Site" field.

## Field-by-Field Explanation
* **Patient Information**: Enter the patient's basic contact information, including their name, phone number, and email address. This helps healthcare providers track patient interactions and communicate effectively.
* **Consent**: If applicable, describe the patient's consent for testing. This may include details about the patient's understanding of the testing process and any necessary paperwork.
* **Test Date**: Enter the date the test was administered, using the standard date format (MM/DD/YYYY).
* **Test Time**: Record the time of the test, using a 12-hour clock format (e.g., 08:00).
* **Test Results**: Enter the test results, such as positive or negative. This field is a free-form text area for recording results in your own words.
* **Test Site**: If the test was performed at an official testing site, select the relevant site from the dropdown menu. If not, select "Other" and fill out the "Other Test Site" field.
* **Other Test Site**: If "Test Site" is "Other," enter the name and location of the testing site in this field. This helps ensure accurate and detailed recording of testing sites.
* **Physician Note**: Enter any additional notes or comments from the healthcare provider, such as observations or next steps.
* **Patient Phone**: Enter the patient's contact phone number, which can be used for follow-up or communication.
* **Patient Email**: Enter the patient's email address, which can be used for secure communication or follow-up.
* **Physician Note**: Enter any additional notes or comments from the healthcare provider, such as observations or next steps.

## Tips
* Ensure that all fields are filled out accurately and completely.
* If a field is not relevant to the current patient interaction, skip it or mark it as not applicable.
* This guide is a general explanation of the form fields; consult with the relevant healthcare team or documentation for specific guidance on field requirements and usage.
