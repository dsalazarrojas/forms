# Compression Stocking Prescription Form - Help Guide
## Purpose
This form is designed to capture information for compression stocking prescriptions, ensuring that patients receive the appropriate compression stockings for their specific medical needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Prescription ID**, a unique identifier for the prescription.
2. Provide the **Prescription Date**, which should be the date the prescription is issued.
3. Enter the **Physician Name**, who is prescribing the compression stockings.
4. Enter the **Physician NPI Number**, the National Provider Identifier number of the prescribing physician.
5. Enter the **Clinic Name**, where the prescription will be administered.
6. Enter the **Clinic Address**, the complete address of the clinic where the prescription is being issued.
7. Enter the **Clinic Phone Number**, the contact number of the clinic.
8. Enter the **Patient Full Name**, the complete name of the patient.
9. Enter the **Patient Date of Birth**, the patient's birth date.
10. Select the **Patient Gender**, either Male, Female, or Other.
11. Enter the **Patient Height**, the patient's height in feet and inches or centimeters.
12. Enter the **Patient Weight**, the patient's weight in pounds or kilograms.
13. Select the **Medical Condition**, which should be one of the provided options.
14. Select the **Affected Limbs**, which will be one or more of the provided options.
15. Select the **Stocking Type**, which should be one of the provided options.
16. Select the **Compression Level**, which should be one of the provided options.
17. Enter the **Right Leg Measurements**, if required.
18. Enter the **Left Leg Measurements**, if required.
19. Enter the **Leg Length Measurement**, if required.
20. Enter the **Ankle Circumference**, if required.
21. Enter the **Calf Circumference**, if required.
22. Enter the **Thigh Circumference**, if required.
23. Select the **Wearing Schedule**, which should be one of the provided options.
24. Select the **Duration of Therapy**, which should be one of the provided options.
25. Enter the **Quantity Prescribed**, the number of pairs of stockings to be prescribed.
26. Select the **Replacement Frequency**, which should be one of the provided options.
27. Select **Contrainications**, which should be one of the provided options.
28. Enter any **Special Instructions**, if applicable.
29. Sign the form with your **Physician Signature** and enter your full name.
30. Date the **Signature Date** with the current date.

## Field-by-Field Explanation

* **Prescription ID**: Enter a unique identifier for the prescription.
* **Prescription Date**: Enter the date the prescription is issued.
* **Physician Name**: Enter the full name of the prescribing physician.
* **Physician NPI Number**: Enter the National Provider Identifier number of the prescribing physician.
* **Clinic Name**: Enter the name of the medical clinic or practice.
* **Clinic Address**: Enter the complete address of the clinic.
* **Clinic Phone**: Enter the contact phone number of the clinic.
* **Patient Full Name**: Enter the full name of the patient.
* **Patient Date of Birth**: Enter the patient's birth date.
* **Patient Gender**: Select the patient's gender (Male, Female, or Other).
* **Patient Height**: Enter the patient's height in feet and inches or centimeters.
* **Patient Weight**: Enter the patient's weight in pounds or kilograms.
* **Medical Condition**: Select the medical condition being treated.
* **Affected Limbs**: Select the limbs affected by the medical condition.
* **Stocking Type**: Select the type of compression stocking required (Knee High, Thigh High, Waist High, Arm Sleeve, Custom Fit).
* **Compression Level**: Select the compression level required (8-15 mmHg, 15-20 mmHg, 20-30 mmHg, 30-40 mmHg, 40-50 mmHg, Custom mmHg).
* **Right Leg Measurements**: Enter the circumference measurements for the right leg, if required.
* **Left Leg Measurements**: Enter the circumference measurements for the left leg, if required.
* **Leg Length Measurement**: Enter the leg length measurement, if required.
* **Ankle Circumference**: Enter the ankle circumference measurement, if required.
* **Calf Circumference**: Enter the calf circumference measurement, if required.
* **Thigh Circumference**: Enter the thigh circumference measurement, if required.
* **Wearing Schedule**: Select the schedule for wearing the stockings (All Day Daily, Daytime Only, During Travel Only, During Exercise Only, As Needed, Other).
* **Duration of Therapy**: Select the duration of the therapy (3 Months, 6 Months, 1 Year, Indefinitely, Until Further Notice).
* **Quantity Prescribed**: Enter the number of pairs of stockings to be prescribed.
* **Replacement Frequency**: Select the frequency for replacing the stockings (Every 3 Months, Every 6 Months, Every 12 Months, As Needed, When Worn Out).
* **Contrainications**: Select any contraindications (None Known, Peripheral Artery Disease, Severe Neuropathy, Skin Infection, Uncontrolled Heart Failure, Other).
* **Special Instructions**: Enter any special instructions for the patient, if applicable.
* **Physician Signature**: Sign the form with your full name.
* **Signature Date**: Date the signature with the current date.
