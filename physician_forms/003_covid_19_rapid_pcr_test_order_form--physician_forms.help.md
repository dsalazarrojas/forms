# COVID 19 Rapid PCR Test Order Form - Help Guide
## Purpose
The COVID 19 Rapid PCR Test Order Form is a standardized document used to gather necessary information for the COVID-19 rapid PCR test order. It ensures accuracy and consistency in reporting, aiding in the processing and delivery of test kits.

## How To Complete This Form

1. **Order Date**: Select the date on which you are placing the order.
2. **Ordering Provider Name**: Enter your full name and credentials as a healthcare provider.
3. **Provider License Number**: Enter your state medical license number.
4. **Clinic or Practice Name**: Enter the name of the healthcare facility where you are practicing.
5. **Clinic Phone**: Enter the office phone number of the clinic.
6. **Clinic Email**: Enter the email address for order confirmations.
7. **Patient First Name**: Enter the patient's legal first name.
8. **Patient Last Name**: Enter the patient's legal last name.
9. **Patient Date of Birth**: Enter the patient's date of birth in MM/DD/YYYY format.
10. **Patient Sex at Birth**: Select the patient's sex at birth.
11. **Patient Phone**: Enter the patient's best contact number.
12. **Patient Email**: Enter the patient's email address for result notifications.
13. **Patient Race**: Select the patient's race (optional).
14. **Patient Ethnicity**: Select the patient's ethnicity (optional).
15. **Test Type Ordered**: Select the type of COVID-19 test ordered (Rapid PCR, Standard PCR, Antigen, or Antibody).
16. **Quantity Ordered**: Enter the number of tests ordered.
17. **Payment Method**: Select the method of payment (Credit Card, Debit Card, Insurance, HSA/FSA Card, PayPal, or Bank Transfer).
18. **Billing Address**: Enter the street address for billing purposes.
19. **Billing City**: Enter the city for billing purposes.
20. **Billing State**: Enter the state or province for billing purposes.
21. **Billing ZIP Code**: Enter the postal code for billing purposes.
22. **Is Shipping Address the Same as Billing**: Select 'True' if the shipping address is the same as the billing address; otherwise, select 'False'.
23. **Shipping Address**: (Optional) Enter the shipping address if different from the billing address.
24. **Shipping City**: (Optional) Enter the city for shipping purposes if different from the billing city.
25. **Shipping State**: (Optional) Enter the state or province for shipping purposes if different from the billing state.
26. **Shipping ZIP Code**: (Optional) Enter the postal code for shipping purposes if different from the billing ZIP Code.
27. **Special Instructions**: Enter any special delivery or handling instructions.

## Tips

* Please ensure all required fields are completed before submitting the form.
* If you select 'False' for 'Is Shipping Address the Same as Billing', enter the shipping address in the fields below.
* For 'Test Type Ordered', select the most accurate type of test for the patient's needs.
* For 'Payment Method', select a payment method that suits your needs.
* For 'Billing Address', 'Billing City', 'Billing State', and 'Billing ZIP Code', enter the address where payment will be received.
* For 'Shipping Address', 'Shipping City', 'Shipping State', and 'Shipping ZIP Code', enter the address where the test kits will be delivered, if different from the billing address.
* Be accurate and clear in filling in all fields for efficient processing.
