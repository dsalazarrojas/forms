# Spot Status Override Request - Help Guide
## Purpose
This form is used to request a status override for a parking spot.

## How To Complete This Form
1. Fill in the required information in the relevant fields.
2. Ensure you are filling out the correct information to avoid duplication of requests.

## Field-by-Field Explanation
- **Team Name** (`team_name`, text, required/optional): Enter the team name associated with the parking spot.
- **Manager Email** (`manager_email`, email, required/optional): Input the email address of the manager responsible for the parking spot.
- **Manager Phone** (`manager_phone`, text, required/optional): Enter the phone number of the manager responsible for the parking spot.
- **Override Reason** (`override_reason`, select_one, required/optional): Choose the reason for the status override.
    * Reason for override
    * Other
- **Override Type** (`override_type`, select_one, required/optional): Select the type of override.
    * Temporary
    * Permanent
- **Override Effective Date** (`override_effective_date`, date, required/optional): Enter the date the override effective date.
- **Override Effective Time** (`override_effective_time`, time, required/optional): Enter the time the override effective time.
- **Override Effective Date 2** (`override_effective_date_2`, time, required/optional): Enter the time the override effective date 2.
- **Notes** (`notes`, note, required/optional): Add any additional notes regarding the status override.
- **Assigned To** (`assigned_to`, text, required/optional): Input the name of the person assigned to the parking spot.
- **Assigned Tool** (`assigned_tool`, text, required/optional): Input the name of the tool assigned to the parking spot.
- **Assigned User** (`assigned_user`, text, required/optional): Input the name of the user assigned to the parking spot.
- **Facility** (`facility`, text, required/optional): Input the facility name associated with the parking spot.
- **Parking Manager** (`parking_manager`, text, required/optional): Input the name of the parking manager.
- **Operations Manager** (`operations_manager`, text, required/optional): Input the name of the operations manager.
- **Override Status** (`override_status`, select_one, required/optional): Select the override status.
    * Active
    * Expired
- **Override Status Reason** (`override_status_reason`, text, required/optional): Input the reason for the override status.
- **Override Status Effective Date** (`override_status_effective_date`, date, required/optional): Enter the date the override status effective date.
- **Override Status Effective Time** (`override_status_effective_time`, time, required/optional): Enter the time the override status effective time.
- **Override Status Effective Date 2** (`override_status_effective_date_2`, time, required/optional): Enter the time the override status effective date 2.
- **Override Status Effective Date 3** (`override_status_effective_date_3`, time, required/optional): Enter the time the override status effective date 3.
- **Facility Manager** (`facility_manager`, text, required/optional): Input the name of the facility manager.
- **Operations Manager 2** (`operations_manager_2`, text, required/optional): Input the name of the operations manager 2.
- **Override Status Effective Date 4** (`override_status_effective_date_4`, time, required/optional): Enter the time the override status effective date 4.
