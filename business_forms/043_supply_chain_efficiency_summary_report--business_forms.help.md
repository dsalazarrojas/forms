# Supply Chain Efficiency Summary Report - Help Guide

## Purpose
The Supply Chain Efficiency Summary Report is a high-level overview of the supply chain's current efficiency status, used by teams to monitor and report on performance over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Supply Chain Efficiency Summary Report page.
2. Provide a brief summary of the current efficiency status of your supply chain operations.
3. Choose an option for the Supply Chain Efficiency Score.
4. Identify any bottlenecks in the supply chain.
5. Provide any improvement actions that can be taken.
6. Add any comments or notes about the supply chain's efficiency.
7. Select the reporting period for which you are reporting.
8. Enter any relevant Key Performance Indicators (KPIs) for each of the supply chain's metrics (KPI1, KPI2, KPI3, KPI4).

## Field-by-Field Explanation

* **supply_chain_efficiency_summary_report**: Enter a brief summary of the current efficiency status of your supply chain operations. This field is not required.
* **supply_chain_efficiency_score**: Choose an option that represents the current efficiency score of your supply chain (Option 1, Option 2). This field is not required.
* **bottlenecks_identified**: Select all bottlenecks that have been identified in the supply chain (Yes, No). This field is not required.
* **improvement_actions**: Provide any improvement actions that can be taken to improve the supply chain's efficiency. This field is not required.
* **comments**: Add any comments or notes about the supply chain's efficiency. This field is not required.
* **reporting_period**: Select the reporting period for which you are reporting (Option 1, Option 2, ...). This field is not required.
* **kpi1**, **kpi2**, **kpi3**, **kpi4**: Enter relevant Key Performance Indicators (KPIs) for each of the supply chain's metrics. These fields are not required.
