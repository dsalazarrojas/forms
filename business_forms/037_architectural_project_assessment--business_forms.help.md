# Architectural Project Assessment - Help Guide

## Purpose
The Architectural Project Assessment form is used to collect and track information about architectural projects. It is intended to provide a comprehensive overview of project details, including project name, address, scope, budget, timeline, and team composition. This form is used by architects, project managers, and other stakeholders to assess and evaluate architectural projects.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the project name in the "Project Name" field.
2. Enter the project number and reference code in the "Project Number" field.
3. Enter the project address in the "Project Address" field.
4. Select the project type from the drop-down menu in the "Project Type" field.
5. Enter the total project area in square feet in the "Total Project Area (Square Feet)" field.
6. Describe the scope of work in the "Scope of Work Description" field.
7. Enter the estimated project budget in the "Estimated Project Budget" field.
8. Enter the design budget in the "Design Budget" field (if applicable).
9. Enter the construction budget in the "Construction Budget" field (if applicable).
10. Enter the contingency percentage for unexpected costs in the "Contingency Percentage" field (if applicable).
11. Select the project start date from the calendar in the "Project Start Date" field.
12. Select the expected project end date from the calendar in the "Project End Date" field.
13. Enter the design duration in weeks in the "Design Duration (Weeks)" field (if applicable).
14. Enter the construction duration in weeks in the "Construction Duration (Weeks)" field (if applicable).
15. Enter the name of the architect firm in the "Architect Firm Name" field.
16. List any key consultants involved in the project in the "Key Consultants (if any)" field (if applicable).
17. Select the assessment date from the calendar in the "Assessment Date" field.

## Field-by-Field Explanation

* **Project Name** (required): Enter the name of the project.
* **Project Number** (required): Enter the project number and reference code.
* **Project Address** (required): Enter the project address.
* **Project Type** (required): Select the project type from the drop-down menu.
	+ Residential
	+ Commercial
	+ Industrial
	+ Institutional
	+ Mixed-use
	+ Other
* **Total Project Area (Square Feet)** (required): Enter the total project area in square feet.
* **Scope of Work Description** (required): Describe the scope of work involved in the project.
* **Estimated Project Budget** (required): Enter the estimated project budget.
* **Design Budget** (optional): Enter the design budget (if applicable).
* **Construction Budget** (optional): Enter the construction budget (if applicable).
* **Contingency Percentage** (optional): Enter the percentage for unexpected costs (if applicable).
* **Project Start Date** (required): Select the project start date from the calendar.
* **Project End Date** (required): Select the expected project end date from the calendar.
* **Design Duration (Weeks)** (optional): Enter the design duration in weeks (if applicable).
* **Construction Duration (Weeks)** (optional): Enter the construction duration in weeks (if applicable).
* **Architect Firm Name** (required): Enter the name of the architect firm.
* **Key Consultants (if any)** (optional): List any key consultants involved in the project (if applicable).
* **Assessment Date** (required): Select the assessment date from the calendar.

## Tips
* Make sure to enter accurate and complete information for each field.
* If a field is optional, only fill it out if necessary.
* Double-check your entries before submitting the form.
* Use the calendar to select dates accurately.
