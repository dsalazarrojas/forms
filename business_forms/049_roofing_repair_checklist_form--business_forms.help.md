# roofing_repair_checklist_form - Help Guide
## Purpose
The roofing repair checklist form is used to record and assess the condition of a roof, its components, and necessary repairs. It helps to identify potential issues and provide recommendations for rectification.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "roof_condition" page to assess the overall condition of the roof.
2. Answer "damage_type" with a simple "Yes" or "No" to indicate if there is any damage.
3. Provide detailed description in the "repair_description" field to describe the damage or issue.
4. Enter the estimated repair cost in the "repair_cost" field.
5. Choose the status of the repair from the dropdown options for "repair_status".
6. Assess the roof's condition rating by selecting one of the provided options in "roof_condition_rating".
7. Describe the recommended remediation or action to be taken in the "recommended_remediation" field.
8. Document the results of any roof structure inspection in the "roof_structure_inspection" field (if applicable).
9. Provide a detailed description of the roof's structure condition in the "roof_structure_condition" field (if applicable).
10. Report the current leakage status and provide detailed description in the "roof_leakage_status" and "roof_leakage_description" fields.
11. Evaluate the roof's condition rating again by selecting one of the provided options in "roof_condition_rating".
12. Record the recommended repair action in the "repair_recommendation" field.
13. Indicate if the repair is a priority by selecting "Yes" or "No" from the "repair_priority" field.
14. Enter the schedule of the repair in the "repair_schedule" field in the required format.
15. Provide an estimate of the repair cost in the "repair_cost_estimate" field.
16. Document any client communication or discussions in the "client_communication" field.
17. Enter a detailed repair report in the "repair_report" field.

## Field-by-Field Explanation
* **Roof Condition**: A field to assess the overall condition of the roof.
	+ Type: text
	+ Required: yes
* **Damage Type**: A field to indicate if there is any damage on the roof.
	+ Type: select_one
	+ Required: yes
	+ Options: 'Yes', 'No'
* **Location**: A field to specify the location of the damage or issue (if applicable).
	+ Type: text
	+ Required: no
* **Repair Description**: A field to provide a detailed description of the damage or issue.
	+ Type: text
	+ Required: yes
* **Repair Cost**: A field to estimate the cost of the repair.
	+ Type: number
	+ Required: yes
* **Repair Status**: A field to indicate the status of the repair.
	+ Type: select_multiple
	+ Required: yes
	+ Options: Active, Inactive
* **Roof Condition Rating**: A field to evaluate the condition of the roof.
	+ Type: select_one
	+ Required: yes
	+ Options: Good, Fair
* **Recommended Remediation**: A field to provide a description of the recommended remediation or action to be taken.
	+ Type: text
	+ Required: yes
* **Roof Structure Inspection**: A field to document the results of any roof structure inspection (if applicable).
	+ Type: text
	+ Required: no
* **Roof Structure Condition**: A field to describe the condition of the roof structure (if applicable).
	+ Type: text
	+ Required: no
* **Roof Leakage Status**: A field to indicate the current leakage status of the roof.
	+ Type: text
	+ Required: yes
* **Roof Leakage Description**: A field to provide a detailed description of the leakage issue.
	+ Type: text
	+ Required: yes
* **Roof Condition Rating (again)**: A field to re-evaluate the condition of the roof.
	+ Type: select_one
	+ Required: yes
	+ Options: Good, Fair
* **Repair Recommendation**: A field to provide a description of the recommended repair action.
	+ Type: text
	+ Required: yes
* **Repair Priority**: A field to indicate if the repair is a priority.
	+ Type: select_one
	+ Required: yes
	+ Options: 'Yes', 'No'
* **Repair Schedule**: A field to enter the schedule of the repair.
	+ Type: date
	+ Required: yes
* **Repair Cost Estimate**: A field to estimate the cost of the repair.
	+ Type: text
	+ Required: yes
* **Client Communication**: A field to document any client communication or discussions.
	+ Type: text
	+ Required: yes
* **Repair Report**: A field to enter a detailed repair report.
	+ Type: text
	+ Required: yes

This help guide is designed to assist users in understanding the purpose and usage of the roofing repair checklist form. It explains each field's purpose, type, and requirements to ensure accurate and comprehensive completion of the form.
