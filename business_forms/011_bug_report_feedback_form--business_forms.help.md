# Bug Report Feedback Form - Help Guide

## Purpose
This form is used for users to report bugs and provide feedback about issues encountered with an application or software.

## How To Complete This Form
To report a bug, follow these steps:

1. Enter your name and email address for us to contact you.
2. Provide the date when the bug was discovered.
3. Specify the application name and version (if applicable).
4. Choose the category of the issue.
5. Select the severity and priority levels of the bug.
6. Describe the bug in detail, including steps to reproduce it.
7. Provide expected and actual behavior.
8. Specify how often the bug occurs.
9. Attach screenshots or files if applicable.
10. Add any additional comments or information.
11. Choose a contact preference for follow-up.

## Field-by-Field Explanation
* **Your Name**: Enter your full name for us to contact you. (Required)
* **Email Address**: Enter your contact email for follow-up communication. (Required)
* **Report Date**: Enter the date when you discovered the bug. (Required)
* **Application Name**: Enter the name of the software or application where you encountered the issue. (Required)
* **Application Version**: If available, provide the version number of the application. (Optional)
* **Bug Category**: Select the category of the issue (e.g., Functional Error, User Interface Issue). (Required)
* **Severity Level**: Choose the severity level of the bug (e.g., Critical - System Crash, Low - Cosmetic Issue). (Required)
* **Priority Level**: Select the priority level of the bug (e.g., Urgent - Fix Immediately, Lowest - Backlog). (Required)
* **Browser Used**: If applicable, select the browser you were using when the bug occurred. (Optional)
* **Operating System**: If applicable, select the operating system you were using. (Optional)
* **Device Type**: If applicable, select the type of device you were using. (Optional)
* **Bug Title**: Provide a brief summary of the issue. (Required)
* **Detailed Description**: Describe the bug in detail, including any steps you took to reproduce it. (Required)
* **Steps to Reproduce**: List the steps to reproduce the bug. (Required)
* **Expected Behavior**: Describe what you expected to happen. (Required)
* **Actual Behavior**: Describe what actually happened. (Required)
* **Frequency of Occurrence**: Specify how often the bug occurs. (Required)
* **Screenshots or Files Attached**: If applicable, attach screenshots or files to support your report. (Optional)
* **Additional Comments**: Provide any other relevant information about the bug. (Optional)
* **Contact Preference**: Choose how you want us to contact you for follow-up. (Optional)

Note: Fields marked as "Required" must be completed for the form to be submitted.
