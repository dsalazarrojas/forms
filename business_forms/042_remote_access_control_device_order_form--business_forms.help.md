# Remote Access Control Device Order Form - Help Guide

## Purpose
This form is designed to collect information for ordering remote access control devices. It will be used to process and fulfill orders efficiently.

## How To Complete This Form

1.  Select the type of remote access control device you wish to order from the options provided.
2.  Enter the customer's contact information in the "Contact Information" field.
3.  Provide the shipping information in the "Shipping Information" field.
4.  Enter any additional order information in the "Order Information" field.
5.  Select the shipping date for the order.
6.  Enter the address for shipping in the "Address Line 1" field.
7.  If necessary, enter any additional address information in the "Address Line 2" field.
8.  Specify the quantity of devices ordered in the "Quantity" field.
9.  Add any additional notes about the order in the "Notes" field.
10.  Confirm the total cost of the order in the "Total Cost" field.

## Field-by-Field Explanation

*   **Remote Access Control Device** (Select One):
    *   This field allows you to select the type of remote access control device you wish to order.
*   **Contact Information** (Text):
    *   Enter the customer's name, email, and phone number in this field.
*   **Shipping Information** (Text):
    *   Enter the shipping address and any additional information about the shipment.
*   **Order Information** (Text):
    *   Enter any additional details about the order, such as special requests or instructions.
*   **Shipping Date** (Date):
    *   Select the date for shipping the device(s) to the customer.
*   **Address Line 1** (Text):
    *   Enter the first line of the shipping address.
*   **Address Line 2** (Text):
    *   Enter any additional address information, such as apartment or suite numbers.
*   **Quantity** (Number):
    *   Specify the quantity of devices being ordered.
*   **Notes** (Text):
    *   Add any additional notes or comments about the order in this field.
*   **Total Cost** (Number):
    *   Confirm the total cost of the order after calculating it based on the options selected.
