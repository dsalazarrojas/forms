# Working Declaration Form - Help Guide
## Purpose
The Working Declaration Form is used to capture essential details about a worker's job declaration, including their work location, contact information, and work schedule.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Work Location" field with the country where the worker is currently working.
2. Select the "Country" of the worker's location from the dropdown menu.
3. Enter the start and end dates of the worker's job in the "Start Date" and "End Date" fields, respectively.
4. Provide a brief description of the job in the "Description" field, if required (optional).
5. Enter the worker's contact number in the "Contact Number" field.
6. Enter the worker's email address in the "Email Address" field, if required (optional).
7. Fill out the "Work Address" field with the worker's physical address, if required (optional).

## Field-by-Field Explanation
* **Work Location** (`work_declaration_form`, text, required): Enter the country where the worker is currently working.
* **Country** (`work_location`, select_one, required): Select the country where the worker is working.
* **Start Date** (`work_start_date`, date, required): Enter the start date of the worker's job. This is the date when the worker started working in the selected country.
* **End Date** (`work_end_date`, date, required): Enter the end date of the worker's job. This is the date when the worker finished working in the selected country.
* **Description** (`work_description`, text, optional): Enter a brief description of the job. This is an optional field and can be left blank if not applicable.
* **Contact Number** (`contact_number`, text, required): Enter the worker's contact number. This is the number that will be used to contact the worker.
* **Email Address** (`email_address`, email, optional): Enter the worker's email address. This is an optional field and can be left blank if not applicable.
* **Work Address** (`work_address`, text, optional): Enter the worker's physical address. This is an optional field and can be left blank if not applicable.

## Tips
* Ensure that all required fields are filled out accurately and completely.
* Use the correct format for the "Start Date" and "End Date" fields. The correct format is MM/DD/YYYY.
* Double-check the "Country" field to ensure it matches the country where the worker is working.
