# Professional Event Registration Form - Help Guide
## Purpose
This form is used to collect and manage professional event information, including events such as conferences, workshops, or seminars.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the `event_name` field.
2. Select the event date and time in the `event_date` and `event_time` fields, respectively.
3. Provide the event location in the `event_location` field.
4. Choose the event organizers in the `event_organizers` field.
5. Select the attendees in the `event_attendees` field.
6. Enter the registration count in the `event_registrations_count` field.

## Field-by-Field Explanation
* **Event Details** (`event_details`, `text`, required: false): This field is optional and can be used to provide additional notes or details about the event.
* **event_name** (`event_name`, `text`, required: false): Enter the name of the event, e.g. "Conference on Artificial Intelligence".
* **event_date** (`event_date`, `date`, required: false): Select the date of the event, e.g. "2022-09-01".
* **event_time** (`event_time`, `time`, required: false): Select the time of the event, e.g. "09:00 AM".
* **event_location** (`event_location`, `text`, required: false): Enter the location of the event, e.g. "New York City, USA".
* **event_organizers** (`event_organizers`, `select_one`, required: false): Choose one of the provided options for the event organizers, e.g. "Organizer 1".
* **event_attendees** (`event_attendees`, `select_multiple`, required: false): Select multiple attendees for the event, e.g. "Attendee 1, Attendee 2, Attendee 3".
* **event_registrations** (`event_registrations`, `number`, required: false): Enter the number of registrations for the event, e.g. "10".
* **event_registrations_count** (`event_registrations_count`, `select_one`, required: false): Choose the number of registrations count for the event, e.g. "1", "2", or "3".
