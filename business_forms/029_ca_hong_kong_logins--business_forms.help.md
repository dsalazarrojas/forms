# Ca Hong Kong Logins - Help Guide

## Purpose
This form is used to capture and record login management information for internal administrative access to various systems and platforms in Hong Kong. The purpose of this form is to ensure accurate and efficient management of access permissions and to provide a centralized hub for technical access information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as per the instructions below.
2. Select the relevant system or platform name from the "System or Platform Name" dropdown menu.
3. Choose the appropriate environment (Production, Staging, Testing, or Development) for the login management information.
4. Indicate the access method (Web Interface, SSH, RDP, VPN, or API Key) for the login management.
5. Enter the administrative username for the login management.
6. Check if Multi-Factor Authentication (MFA) is enabled for the login management.
7. Identify the primary account owner for the login management.
8. Record the last password reset date for the login management.
9. Add any specific configuration notes or dependencies that are relevant to the login management.
10. Specify any other systems that this login depends on.
11. Enter the contact information for local Hong Kong support.
12. Schedule the next security review date for the login management.

## Field-by-Field Explanation

* **System or Platform Name** (text, required): Enter the name of the system or platform being managed, e.g., "HK Server Alpha" or "Regional CRM".
* **Environment** (select_one, required): Choose from the options: Production, Staging, Testing, or Development.
* **Server IP or URL** (text, required): Enter the IP address or URL of the server.
* **Access Method** (select_one, required): Choose from the options: Web Interface, SSH, RDP, VPN, or API Key.
* **Administrative Username** (text, required): Enter the administrative username for the login management.
* **MFA Enabled** (select_one, required): Choose from the options: True, False, or Pending Setup.
* **Primary Account Owner** (text, required): Identify the primary account owner for the login management.
* **Last Password Reset Date** (date, required): Record the last date the password was reset.
* **Specific Configuration Notes** (text, required): Enter any specific configuration notes or dependencies relevant to the login management.
* **System Dependencies** (text, optional): List any other systems that this login depends on.
* **Local HK Support Contact** (text, required): Enter the contact information for local Hong Kong support.
* **Next Security Review Date** (date, required): Schedule the next security review date for the login management.
* **Administrative Comments** (text, optional): Add any additional administrative comments about the login management.
* **Technical Notes and Documentation** (note, optional): Add any technical notes or documentation relevant to the login management.
* **Dependencies** (text, optional): List any other systems that this login depends on.
