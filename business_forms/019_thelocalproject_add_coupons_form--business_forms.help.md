# thelocalproject_add_coupons_form - Help Guide
## Purpose
The thelocalproject_add_coupons_form is a form used to create and manage coupons for a specific project. It allows users to select the type of coupon they want to add, enter the name of the coupon, and set the discount amount.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of coupon you want to add by clicking on the "Add Coupons" dropdown menu.
2. Enter the name of the coupon in the "Coupon Name" field.
3. Set the discount amount in the "Discount" field.

## Field-by-Field Explanation
* **Add Coupons**: 
    * (select multiple) This field allows you to choose the type of coupon you want to add (Yes/No).
* **Coupon Name** 
    * (text) Enter the name of the coupon you are creating.
* **Discount**: 
    * (number) Enter the discount amount you want to apply to the coupon.
