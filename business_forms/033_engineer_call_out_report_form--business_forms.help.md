# Engineer Call Out Report Form - Help Guide
## Purpose
This form is used for reporting callouts or visits made by engineers to sites.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Site Manager field with the name of the person responsible for the site.
2. Enter the name of the Owning Organization in the Owning Organization field.
3. Provide a brief description of the work done in the Work Description field.
4. Enter the start date of the callout or visit in the Start Date field.
5. Enter the start time of the callout or visit in the Start Time field.
6. Enter the end date of the callout or visit in the End Date field.
7. Enter the end time of the callout or visit in the End Time field.
8. Enter the duration of the callout or visit in the Duration field.
9. Enter the location of the callout or visit in the Location field.
10. Briefly describe the purpose of the callout or visit in the Purpose field.
11. Add any comments from the Site Manager in the Site Manager Comments field.
12. Add any comments from the Engineer in the Engineer Comments field.
13. Select the tool used for the callout or visit from the Assigned Tool field.
14. Add any comments from the Owning Organization in the Owning Organization Comments field.

## Field-by-Field Explanation

* **Site Manager** (`site_manager`, text, required: false): This field is for entering the name of the person responsible for the site.
* **Owning Organization** (`owning_organization`, text, required: false): This field is for entering the name of the owning organization of the site.
* **Work Description** (`work_description`, text, required: false): This field is for providing a brief description of the work done during the callout or visit.
* **Start Date** (`start_date`, date, required: false): This field is for entering the start date of the callout or visit.
* **Start Time** (`start_time`, time, required: false): This field is for entering the start time of the callout or visit.
* **End Date** (`end_date`, date, required: false): This field is for entering the end date of the callout or visit.
* **End Time** (`end_time`, time, required: false): This field is for entering the end time of the callout or visit.
* **Duration** (`duration`, text, required: false): This field is for entering the duration of the callout or visit.
* **Location** (`location`, text, required: false): This field is for entering the location of the callout or visit.
* **Purpose** (`purpose`, text, required: false): This field is for briefly describing the purpose of the callout or visit.
* **Site Manager Comments** (`site_manager_comments`, text, required: false): This field is for entering any comments from the Site Manager.
* **Owning Organization Comments** (`owning_organization_comments`, text, required: false): This field is for entering any comments from the Owning Organization.
* **Assigned Tool** (`assigned_tool`, select_one, required: false): This field is for selecting the tool used for the callout or visit.
* **Engineer Comments** (`engineer_comments`, text, required: false): This field is for entering any comments from the Engineer.

## Tips

* Make sure to fill in all required fields before submitting the form.
* If a field is not required, you can leave it blank if not applicable.
* If you are unsure about any field, refer to the field's label or description for clarification.
