# Product Return Check In Form - Help Guide
## Purpose
The Product Return Check In Form is used to record and process customer returns. Completing this form helps ensure that returned products are checked in accurately and in a timely manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the return date.
2. Provide a detailed description of the product being returned.
3. Select the product(s) being returned by their IDs.
4. Specify the reason for the return.
5. Enter the customer's name and email address (if available).
6. Input the order ID (if applicable).
7. Enter any contact number for the customer (if available).
8. Specify the return status as "Pending", "Approved", or "Rejected".
9. Add any additional notes about the return.
10. Enter the return date and time.
11. Identify the user assigned to handle the return.
12. Enter any additional message from the customer.
13. Enter the product price.
14. Select the product condition (New, Used, or Defective).
15. Specify the product category.
16. Choose the return method (e.g., in-person, mail, etc.).
17. Enter the return address.
18. Enter any shipping details.

## Field-by-Field Explanation

* **Return Date**: Enter the date the return was made.
* **Product Description**: Enter a detailed description of the product being returned.
* **Product ID**: Select the ID of the product being returned.
* **Reason for Return**: Explain why the product is being returned.
* **Customer Name**: Enter the name of the customer who returned the product (if known).
* **Customer Email**: Enter the email address of the customer (if known).
* **Order ID**: Enter the order ID associated with the return (if applicable).
* **Contact Number**: Enter any contact number for the customer (if available).
* **Return Status**: Specify the status of the return as "Pending", "Approved", or "Rejected".
* **Notes**: Add any additional notes about the return.
* **Return Date and Time**: Enter the date and time the return was made.
* **Assigned User**: Identify the user responsible for handling the return.
* **Customer Message**: Enter any additional message from the customer.
* **Product Price**: Enter the price of the product being returned.
* **Product Condition**: Select the condition of the product being returned (New, Used, or Defective).
* **Product Category**: Enter the category of the product being returned.
* **Return Method**: Choose the method of return (e.g., in-person, mail, etc.).
* **Return Address**: Enter the address where the product will be returned.
* **Shipping Details**: Enter any additional shipping information.

Note: Some fields are optional and should be filled in only if applicable.
