# production_process_work_order - Help Guide
## Purpose
This form is used to create a new production process work order, which is a critical part of the production process in the business. It captures essential details about the production process, including tasks, due dates and times, resources, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the production process work order.
2. Select the first step of the production process (Step 1).
3. Enter the task for the production process.
4. Set the due date for the production process.
5. Set the due time for the production process.
6. Select the resources required for the production process (optional).
7. Enter the contact email address for the production process (optional).
8. Enter the contact phone number for the production process (optional).
9. Add any additional comments about the production process (optional).
10. Submit the form to create the production process work order.

## Field-by-Field Explanation
* **production_process_work_order_title** (`title`, required/optional): Enter a brief title for the production process work order.
* **first_step** (`first_step`, required): Select the first step of the production process from the available options.
* **task** (`task`, required): Enter the task for the production process.
* **due_date** (`due_date`, required): Set the due date for the production process in the format YYYY-MM-DD.
* **due_time** (`due_time`, required): Set the due time for the production process in the format HH:MM AM/PM.
* **resources** (`resources`, optional): Select the resources required for the production process from the available options.
* **email** (`email`, optional): Enter the contact email address for the production process.
* **phone** (`phone`, optional): Enter the contact phone number for the production process.
* **comment** (`comment`, optional): Add any additional comments about the production process.
* **submit** (`submit`, required): Enter the number of production process work orders to be submitted.
