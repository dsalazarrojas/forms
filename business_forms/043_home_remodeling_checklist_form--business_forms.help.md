# Home Remodeling Checklist Form - Help Guide
## Purpose
This form is intended to gather essential information about home remodeling projects, including project details, contact information, and project status. It's a comprehensive tool to help project managers and clients track and communicate project progress.

## How To Complete This Form

1. Review the form and ensure you have all the necessary information before starting to fill it out.
2. Fill in the project information, including title, location, start and end dates, budget, and scope.
3. Provide contact information for the project manager and client.
4. Select the project budget type and status.
5. Add any additional project goals or scope of work.

## Field-by-Field Explanation

* **Project Information** (`project_info`, text, required): Enter a brief description or title of the project.
* **Project Location** (`project_location`, text, required): Provide the physical location of the project site.
* **Project Start Date** (`project_start_date`, date, required): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, required): Enter the end date of the project.
* **Project Budget** (`project_budget`, number, required): Enter the estimated project budget.
* **Project Budget Type** (`project_budget_type`, select_multiple, required): Select the type of budget that applies to the project.
* **Project Scope** (`project_scope`, text, required): Describe the project scope or tasks involved.
* **Contact Information** (`contact_info`, text, required): Provide the contact information for the project manager.
* **Project Manager** (`project_manager`, text, required): Enter the name of the project manager.
* **Project Manager Email** (`project_manager_email`, email, required): Enter the email address of the project manager.
* **Project Manager Phone** (`project_manager_phone`, text, required): Enter the phone number of the project manager.
* **Client Name** (`client_name`, text, required): Enter the name of the client.
* **Client Email** (`client_email`, email, required): Enter the email address of the client.
* **Client Phone** (`client_phone`, text, required): Enter the phone number of the client.
* **Project Status** (`project_status`, select_one, required): Select the current status of the project.
