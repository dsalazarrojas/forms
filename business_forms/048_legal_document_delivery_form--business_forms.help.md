# Legal Document Delivery Form - Help Guide
## Purpose
This form is used to deliver legal documents to clients or other stakeholders.

## How To Complete This Form

1. Enter the name of the law firm (Law Firm Name)
2. Choose the type of document being delivered (Document Type)
3. Enter a brief description of the document (Document Description)
4. Enter the client's name (Client Name)
5. Enter the date of delivery (Document Date)
6. Enter the time of delivery (Document Time)
7. Enter the status of the document (Document Status)
8. Enter the delivery address (Delivery Address)
9. Enter the client's phone number (Delivery Phone)
10. Enter the client's IP address (Client IP)
11. (Optional) Enter a file name and file type (File Name, File Type)
12. (Optional) Check the box if you have confirmed the client's email (Email Confirmation)
13. Enter the client's email address (Email)
14. (Optional) Enter a description of the file (File Description)

## Field-by-Field Explanation

* **Law Firm Name** (`law_firm_name`, text, required): Enter the name of your law firm.
* **Document Type** (`document_type`, select_one, required): Choose the type of document being delivered.
* **Document Description** (`document_description`, text, required): Enter a brief description of the document.
* **Client Name** (`client_name`, text, required): Enter the client's name.
* **Document Date** (`document_date`, date, required): Enter the date of delivery.
* **Document Time** (`document_time`, time, required): Enter the time of delivery.
* **Document Status** (`document_status`, select_one, required): Choose the status of the document (Active or Inactive).
* **Delivery Address** (`delivery_address`, text, required): Enter the address where the document will be delivered.
* **Delivery Phone** (`delivery_phone`, text, required): Enter the phone number of the person or organization receiving the document.
* **Client IP** (`client_ip`, text, required): Enter the client's IP address.
* **File Name** (`file_name`, text, optional): Enter a name for the file being delivered.
* **File Type** (`file_type`, select_one, optional): Choose the type of file being delivered.
* **File Size** (`file_size`, select_multiple, optional): Check the box if the file size is relevant.
* **File Description** (`file_description`, select_multiple, optional): Check the box if a description of the file is relevant.
* **Document Date** (`document_date`, date, optional): Enter the date of delivery (if different from the main document date).
* **Email** (`email`, email, required): Enter the client's email address.
* **Email Confirmation** (`email_confirmation`, select_one, optional): Check the box if you have confirmed the client's email.
* **Email Domain** (`email_domain`, text, optional): Enter the domain of the client's email.
* **Confirm Email** (`confirm_email`, select_one, optional): Check the box if you have confirmed the client's email.
* **Document ID** (`document_id`, text, optional): Enter a unique identifier for the document.
* **File Version** (`file_version`, select_multiple, optional): Check the box if you have a version of the file.
* **Document Status** (`document_status`, select_one, optional): Choose the status of the document (Active or Inactive).
* **Confirm Email** (`confirm_email`, select_one, optional): Check the box if you have confirmed the client's email. 

## Tips
Please ensure that all fields are filled out correctly, especially those marked as required. 
This will ensure that the legal documents are delivered correctly and on time. 
You may need to double-check the information with your clients or other stakeholders before submitting the form.
