# Color Street Party Order Form TAB - Help Guide
## Purpose
This form is used to collect information from hosts and their guests about a Color Street party order. It captures details such as party dates, guest names and email addresses, sets ordered from stock and to be ordered, and payment information.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the Hostess Name field with the name of the person hosting the party.
2. Enter the Party Date in the format of MM/DD/YYYY (e.g., 01/15/2023).
3. In the Guest Order Information section, enter the names and email addresses of the guests attending the party.
4. In the Sets Ordered section, list the names of sets ordered from stock, separated by commas (e.g., "Set A, Set B, Set C").
5. Enter the number of sets ordered from stock in the Number of On-Hand Sets field.
6. In the Sets to be Ordered section, list the names of sets that need to be ordered, separated by commas (e.g., "Set D, Set E, Set F").
7. Enter the number of sets to be ordered in the Number of Sets to Order field.
8. In the Payment Tracking section, enter the subtotal amount, which is calculated based on the sets ordered and to be ordered.
9. Enter the amount charged for shipping in the Shipping Charged field.
10. Calculate the total amount collected by subtracting the shipping amount from the subtotal amount.
11. Select the Payment Status from the drop-down menu:
	* "Paid" for completed payments
	* "Pending" for pending payments
	* "Not Billed" for payments not yet processed

## Field-by-Field Explanation

* **Hostess Name**: The name of the person hosting the party, which is a required field.
* **Party Date**: The date of the party, in the format MM/DD/YYYY (e.g., 01/15/2023).
* **Guest Name**: The name of a guest attending the party, which is a required field.
* **Guest Email**: The email address of a guest, which is a required field.
* **Sets Ordered from On-Hand Stock**: List the names of sets ordered from stock, separated by commas (e.g., "Set A, Set B, Set C").
* **Number of On-Hand Sets**: The number of sets ordered from stock.
* **Sets to be Ordered**: List the names of sets that need to be ordered, separated by commas (e.g., "Set D, Set E, Set F").
* **Number of Sets to Order**: The number of sets to be ordered.
* **Subtotal**: The total amount before shipping, calculated based on the sets ordered and to be ordered.
* **Shipping Charged**: The amount charged for shipping.
* **Total Amount Collected**: The total amount collected, which is the subtotal minus the shipping amount.
* **Payment Status**: The status of the payment, which can be:
	+ **Paid**: Completed payment
	+ **Pending**: Payment is pending
	+ **Not Billed**: Payment is not yet processed
