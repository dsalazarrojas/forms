# Project Task Management Form - Help Guide
## Purpose
This form is used to manage and track project tasks within a business context. It allows users to gather and update project information in a centralized location.

## How To Complete This Form
1. **Form title**: Enter a descriptive title for the project.
2. **Project name**: Type the name of the project.
3. **Project manager**: Enter the name of the project manager.
4. **Project status**: Select the current status of the project from the available options ('Active' or 'Inactive').
5. **Project start date**: Enter the date the project started.
6. **Project end date**: Enter the date the project is expected to end.
7. **Project start time**: Enter the time of day the project started.
8. **Project end time**: Enter the time of day the project is expected to end.
9. **Project description**: Provide a brief description of the project.
10. **Project priority**: Select whether the project is a priority ('Yes' or 'No').
11. **Assignee**: Enter the name of the person assigned to the project.

## Field-by-Field Explanation
* **Form title**: A descriptive title for the project.
* **Project name**: The name of the project.
* **Project manager**: The name of the project manager.
* **Project status**: The current status of the project.
* **Project start date**: The date the project started.
* **Project end date**: The date the project is expected to end.
* **Project start time**: The time of day the project started.
* **Project end time**: The time of day the project is expected to end.
* **Project description**: A brief description of the project.
* **Project priority**: Whether the project is a priority ('Yes' or 'No').
* **Assignee**: The name of the person assigned to the project.

## Tips
* Make sure to fill in all required fields to ensure accurate and complete project information.
* If a project is inactive, ensure that its status is updated accordingly.
* Use the project description to briefly summarize the project's objectives and goals.
* Be mindful of project deadlines and start times to ensure timely progress.
