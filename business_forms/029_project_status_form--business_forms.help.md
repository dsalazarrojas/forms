# Project Status Form - Help Guide
## Purpose
This form is used to update and track project status by project administrators. It helps project managers to stay informed about ongoing and past projects.

## How to Complete This Form
1. To get started, select the project from the dropdown list or search for it in the search bar.
2. Fill in the project status in the `Project Status` text field.
3. Update the `Progress` bar to indicate the project's advancement towards the deadline.
4. Enter the `Deadline` date if it has changed or is not yet set.
5. Select the `Priority` level of the project. This helps project managers to allocate resources effectively.
6. Choose the `Status` of the project from the available options (In Progress, Completed, or Cancelled).

## Field-by-Field Explanation
* **Project Status** (`project_status`, text, required/optional): Enter a brief description of the project's status.
* **Progress** (`progress`, number, required/optional): Use a percentage to indicate how much of the project is completed.
* **Deadline** (`deadline`, date, required/optional): Enter the project's deadline, if one has been set.
* **Priority** (`priority`, select_one, required/optional): Choose the project's priority level: Low, Medium, or High.
* **Status** (`status`, select_multiple, required/optional): Select all applicable statuses for the project: In Progress, Completed, or Cancelled.

## Tips
- Use the project status update feature to keep project information up-to-date and organized.
- Ensure that each project has a unique title to avoid confusion.
- If you have any doubts or questions, contact the project administrator for assistance.
- Only fill out the form if you are an authorized project manager.
- Avoid sharing sensitive information through this form.
