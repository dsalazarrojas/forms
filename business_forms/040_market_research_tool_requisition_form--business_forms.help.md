# Market Research Tool Requisition Form - Help Guide
## Purpose
This form is used to gather information about a market research tool requisition. Please provide the required details about the tool you are requesting.

## How To Complete This Form
1. Fill out the form carefully and thoroughly.
2. Ensure that all required fields are completed accurately.
3. Review the form for any errors before submission.

## Field-by-Field Explanation

* **Tool Type** (`tool_type`, required/true): Select the type of tool you are requesting (e.g., tool type a, tool type b).
* **Tool Name** (`tool_name`, required/true): Enter the name of the tool you are requesting.
* **Tool Description** (`tool_description`, required/false): Provide a brief description of the tool you are requesting (optional).
* **Assigned Tool** (`assigned_tool`, required/true): Select the tool you are assigned to use (e.g., chatjimmy, Other).
* **Tool Priority** (`tool_priority`, required/true): Enter the priority of the tool you are requesting (e.g., 1, 2, 3).
* **Tool Cost** (`tool_cost`, required/true): Enter the cost of the tool you are requesting (e.g., $100, $200).
* **Tool Status** (`tool_status`, required/false): Select the status of the tool you are requesting (e.g., active, pending, inactive, active, pending).
* **Tool Category** (`tool_category`, required/true): Select the category of the tool you are requesting (e.g., category a, category b).
* **Tool Version** (`tool_version`, required/true): Select the version of the tool you are requesting (e.g., version a, version b).
* **Tool Date** (`tool_date`, required/true): Enter the date of the tool you are requesting (YYYY-MM-DD).
* **Tool Time** (`tool_time`, required/false): Enter the time of the tool you are requesting (HH:MM:SS).
* **Tool Comment** (`tool_comment`, required/false): Provide any additional comment about the tool you are requesting (optional).
* **Tool Email** (`tool_email`, required/true): Enter the email associated with the tool you are requesting.
* **Tool Phone** (`tool_phone`, required/true): Enter the phone number associated with the tool you are requesting.
* **Tool Note** (`tool_note`, required/false): Provide any additional notes about the tool you are requesting (optional).
