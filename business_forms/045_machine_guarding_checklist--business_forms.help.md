# Machine Guarding Checklist - Help Guide

## Purpose
This form is designed to help you conduct a comprehensive machine guarding checklist, ensuring the safety and efficacy of your machine's guarding system. The form guides you through a series of questions related to equipment installation, maintenance, and inspection to help identify potential risks and take corrective actions to prevent accidents.

## How To Complete This Form
1. Answer each question carefully, providing a "yes" or "no" response for each field.
2. For fields with "yes" or "yes" options, provide a brief description of the situation or reason behind your response.
3. Review all fields and provide a summary of your findings at the end of the form.

## Field-by-Field Explanation
* **Is equipment installed?** (Equipment Installed, text, required: false): Answer "yes" if the machine guarding equipment is in place and installed correctly. Provide a description if there are any issues.
* **Is equipment functioning correctly?** (Equipment Functioning Correctly, text, required: false): Answer "yes" if the machine guarding equipment is working as expected. If not, provide details on any malfunctions or issues.
* **Machine guarding equipment** (Machine Guarding Equipment, text, required: false): Describe the type and condition of the machine guarding equipment, including any necessary documentation or certifications.
* **Is equipment maintained?** (Equipment Maintained, text, required: false): Answer "yes" if the machine guarding equipment is regularly maintained and serviced. Provide details on the maintenance schedule and any outstanding issues.
* **Is equipment in good working condition?** (Equipment in Good Working Condition, text, required: false): Answer "yes" if the equipment is in good working condition, with no visible signs of wear and tear. If not, describe any needed repairs or replacements.
* **Regular cleaning and maintenance** (Regular Cleaning and Maintenance, text, required: false): Answer "yes" if the machine guarding equipment is regularly cleaned and maintained. Provide details on the schedule and any notable issues.
* **Inspection frequency** (Inspection Frequency, text, required: false): Answer "yes" if inspections are conducted regularly, according to the schedule. If not, describe the reasons for non-compliance.
* **Trained guard available?** (Trained Guard Available, text, required: false): Answer "yes" if a trained guard is on site and available to intervene in case of an emergency. Provide details on guard training and certifications.
* **Guarding equipment is in proximity?** (Guarding Equipment in Proximity, text, required: false): Answer "yes" if the machine guarding equipment is in close proximity to the machine or hazardous area. If not, describe the reasons for non-compliance.
* **Alarm system operational?** (Alarm System Operational, text, required: false): Answer "yes" if the alarm system is functioning correctly and alerting as expected. If not, investigate and provide details on any malfunctions or issues.
* **Alarm sound level** (Alarm Sound Level, text, required: false): Answer "yes" if the alarm sound level is audible and effective. If not, describe any adjustments or modifications needed.
* **Warning signals** (Warning Signals, text, required: false): Describe the types and methods of warning signals used for machine guarding, such as lights, horns, or other visual or auditory alerts.
* **Emergency shutdown** (Emergency Shutdown, text, required: false): Answer "yes" if the machine has an emergency shutdown mechanism in place. If not, describe any necessary adjustments or modifications.
* **Lockout tagging** (Lockout Tagging, text, required: false): Answer "yes" if lockout tags or devices are used to identify and prevent unauthorized machine access. If not, describe the reasons for non-compliance.
* **Electrical connections** (Electrical Connections, text, required: false): Describe the electrical connections and any safety measures in place to prevent electrical shock or arc faults.
* **Guarding area signaling** (Guarding Area Signaling, text, required: false): Describe the types and methods of guarding area signaling used, such as flashing lights or alarm systems.
* **Emergency stops** (Emergency Stops, text, required: false): Answer "yes" if emergency stops are in place to quickly shut down the machine in case of an emergency. If not, describe any necessary adjustments or modifications.
* **Lockout device** (Lockout Device, text, required: false): Describe the type and functionality of the lockout device, including any necessary certifications or documentation.
* **Machine access points** (Machine Access Points, text, required: false): Describe the locations and types of machine access points, including any safety barriers or guards.
* **Guarding system** (Guarding System, text, required: false): Describe the overall guarding system in place, including its components and functionalities.
* **Guarding system status** (Guarding System Status, text, required: false): Answer "yes" if the guarding system is in good working condition. If not, describe any issues or malfunctions.
* **Guarding area signaling system** (Guarding Area Signaling System, text, required: false): Describe the types and methods of guarding area signaling systems used.
* **Guarding system test and inspection** (Guarding System Test and Inspection, text, required: false): Answer "yes" if regular tests and inspections are performed on the guarding system. If not, describe any outstanding issues or malfunctions.
* **Guarding system maintenance record** (Guarding System Maintenance Record, text, required: false): Describe the maintenance record and schedule for the guarding system, including any necessary documentation or certifications.
* **Trained guards** (Trained Guards, text, required: false): Answer "yes" if trained guards are present and available to intervene in case of an emergency. Provide details on guard training and certifications.
* **Guarding system test and inspection date** (Guarding System Test and Inspection Date, date, required: false): Record the last date of guarding system testing and inspection.
