# Machine Validation Program Registration Form - Help Guide
## Purpose
This form is used to register a machine validation program with the organization. It collects contact information, machine details, and validation date, and allows the user to submit the form at the current or a later time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the machine validation program in the "Machine Validation Program" field.
2. Select the type of machine from the available options.
3. Enter the contact name, email, and phone number in the "Contact Name", "Email", and "Phone" fields, respectively.
4. Enter the address in the "Address" field.
5. Select a validation date from the calendar.
6. Choose whether to submit the form now or later.
7. Add any additional notes about the machine validation program, if needed.

## Field-by-Field Explanation

* **Machine Validation Program (required)**: Enter the name of the machine validation program.
* **Machine (required)**: Select the type of machine for this validation program.
* **Contact Name (required)**: Enter the name of the contact person responsible for this machine validation program.
* **Email (required)**: Enter the email address of the contact person.
* **Phone (optional)**: Enter the phone number of the contact person.
* **Address (optional)**: Enter the address of the contact person.
* **Validation Date (required)**: Select the date when the validation for this machine is expected to take place.
* **Submit Now/Submit Later (required)**: Choose when you want to submit this form.
* **Notes (optional)**: Add any additional information about this machine validation program, if needed.

## Tips

* Make sure to fill out all required fields to ensure successful submission.
* If you are unsure about any field, check the hint provided or contact the program administrator.
* This form is designed to help you register your machine validation program efficiently and effectively.
