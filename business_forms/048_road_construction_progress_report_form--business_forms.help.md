# Road Construction Progress Report Form - Help Guide
## Purpose
This form is designed to track the progress of road construction projects, allowing project managers and team members to report on work started, progress made, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

* Fill in the required fields with accurate and relevant information about the project.
* Choose the correct options for fields with dropdown or select options.
* Enter detailed descriptions for text fields.
* Select the correct team experience level.
* Ensure that all required fields are filled in for accurate reporting.

## Field-by-Field Explanation

* **Work Started** (`work_started`, `date`, required: false): Report the date on which work started for the project.
* **Progress Percentage** (`progress_percentage`, `select_one`, required: false): Select the percentage of progress made on the project, using the options 0%, 25%, 50%, 75%, 100%.
* **Work Completed** (`work_completed`, `text`, required: false): Describe the work completed on the project.
* **Delay Reason** (`delay_reason`, `text`, required: false): If the project is delayed, provide the reason for the delay.
* **Delay Duration** (`delay_duration`, `time`, required: false): If the project is delayed, report the duration of the delay.
* **Team Size** (`team_size`, `number`, required: false): Report the size of the team working on the project.
* **Team Experience** (`team_experience`, `select_multiple`, required: false): Select the team experience level, using the options Novice, Intermediate, Advanced, Expert.
* **Project Status** (`project_status`, `select_one`, required: false): Select the current project status, using the options Not Started, In Progress, Completed.
* **Completed Activities** (`completed_activities`, `text`, required: false): Describe the activities completed on the project.
* **Project Manager** (`project_manager`, `text`, required: false): Report the name of the project manager.
* **Site Visit Date** (`site_visit_date`, `date`, required: false): Report the date of the site visit.
* **Site Visit Duration** (`site_visit_duration`, `time`, required: false): Report the duration of the site visit.
* **Work Order ID** (`work_order_id`, `select_one`, required: false): Report whether a work order ID is required.
* **Client Contact** (`client_contact`, `text`, required: false): Report the name of the client contact.
* **Site Visit Notes** (`site_visit_notes`, `note`, required: false): Enter any notes about the site visit.
* **Project Start Date** (`project_start_date`, `date`, required: false): Report the date on which the project started.

## Tips

* Be concise and accurate in filling out the form.
* Use the options provided for select fields to ensure correct reporting.
* Ensure that all required fields are filled in.
* Review and edit your submission before saving to ensure accuracy.
