# wholly_owned_subsidiary_incorporation_checklist - Help Guide

## Purpose
This form is designed to collect information about a wholly-owned subsidiary's incorporation status, including details about the entity type, address, and incorporation number.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you have all the necessary information before starting.
2. Fill in the required fields (indicated by an asterisk*) with the accurate information about your wholly-owned subsidiary.
3. Choose the correct options for each select field (such as entity type, tax type, and subsidiary incorporation type).
4. Ensure that you have filled in all the required fields before submitting the form.

## Field-by-Field Explanation

* **Entity Type** (`entity_type`): Select the type of entity (e.g., Entity Type 1, Entity Type 2).
* **Entity Name** (`entity_name`): Enter the name of the entity (e.g., Company Name).
* **Address** (`address`): Enter the address of the entity.
* **City** (`city`): Enter the city of the entity.
* **Country** (`country`): Enter the country of the entity.
* **Postal Code** (`postal_code`): Enter the postal code of the entity.
* **Tax ID** (`tax_id`): Enter the tax ID number of the entity.
* **Tax Type** (`tax_type`): Select the type of tax (e.g., Tax Type 1, Tax Type 2).
* **Tax Resident Status** (`tax_resident_status`): Select the tax resident status (e.g., Resident 1, Resident 2, NonResident).
* **Date of Incorporation** (`date_of_incorporation`): Enter the date of incorporation of the entity.
* **Incorporation Status** (`incorporation_status`): Select the incorporation status (e.g., Active, Suspended, Cancelled).
* **Legal Entity Type** (`legal_entity_type`): Select the type of legal entity (e.g., Type 1, Type 2).
* **Entity Number** (`entity_number`): Enter the entity number.
* **Entity Number Suffix** (`entity_number_suffix`): Enter the entity number suffix.
* **Legal Entity Number** (`legal_entity_number`): Enter the legal entity number.
* **Incorporation Number** (`incorporation_number`): Enter the incorporation number.
* **Subsidiary Incorporation Type** (`subsidiary_incorporation_type`): Select the type of subsidiary incorporation (e.g., Type 1, Type 2).
* **Subsidiary Incorporation Status** (`subsidiary_incorporation_status`): Select the status of the subsidiary incorporation (e.g., Status 1, Status 2, Status 3).

## Tips

* Ensure that you have accurate and up-to-date information about your wholly-owned subsidiary's incorporation status before filling out this form.
* If you are unsure about any of the fields, please consult the relevant authorities or your legal counsel for guidance.
* Once you have filled out the form, review it carefully before submitting it to ensure that all the required fields are filled in accurately.
