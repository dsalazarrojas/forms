## Service Level Agreement Change Request Form - Help Guide

## Purpose
The Service Level Agreement Change Request Form is used to submit a request for changes to the existing Service Level Agreement (SLA) between your company and a third party or vendor.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose the category for your request. Select "Consulting Forms" or "Business Forms" depending on the type of request you are submitting.
2. Provide a clear and concise description of the changes you are requesting to the SLA.
3. If the changes you are requesting are approved, you will have the option to upload an output file.
4. Select the tool that will be responsible for handling the change request.
5. Review and submit the form for processing.

## Field-by-Field Explanation

* **Category** (Category, Select Multiple, Required): This field allows you to select the category for your request. Please choose "Consulting Forms" or "Business Forms" depending on the type of request you are submitting.
* **Description** (Description, Text, Required): In this field, please provide a clear and concise description of the changes you are requesting to the SLA. This will help the reviewer understand the nature of the request.
* **Output File** (Output File, Text, Optional): If the changes you are requesting are approved, you may be required to upload an output file as part of the change request process. This field is not required, but if you need to upload a file, please use this field.
* **Assigned Tool** (Assigned Tool, Select One, Optional): This field allows you to select the tool that will be responsible for handling the change request. Please choose from the available options, or select "Other" if the tool is not listed.
