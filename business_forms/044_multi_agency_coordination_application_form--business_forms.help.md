# multi-agency-coordination-application-form - Help Guide
## Purpose
The multi-agency-coordination-application-form is designed to gather information from individuals or organizations interested in coordinating with multiple agencies on a project.
## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the form completely and accurately, ensuring that all required fields are filled out.
2. Select 'Yes' or 'No' for the participating agencies question, depending on whether the organization is interested in coordinating with multiple agencies.
3. Choose the correct options for the project status, budget, and location fields as per the project details.

## Field-by-Field Explanation
* **Proposed Project** (`proposed_project`, `text`, required: false):
	+ This field is used to enter the title of the proposed project.
* **Participating Organizations** (`participating_organizations`, `select_multiple`, required: false):
	+ Select 'Yes' if the organization is interested in coordinating with multiple agencies. Select 'No' otherwise.
* **Shared Resources** (`shared_resources`, `select_one`, required: false):
	+ Select 'Yes' if the project requires shared resources. Select 'No' otherwise.
* **Contact Info** (`contact_info`, `text`, required: false):
	+ Enter the contact information of the person responsible for the project.
* **Organization Details** (`organization_details`, `note`, required: false):
	+ Enter any additional details about the organization.
* **Project Status** (`project_status`, `date`, required: false):
	+ Enter the project start and end dates.
* **Project Budget** (`project_budget`, `number`, required: false):
	+ Enter the budget for the project.
* **Project Start Date** (`project_start_date`, `date`, required: false):
	+ Enter the project start date.
* **Project End Date** (`project_end_date`, `date`, required: false):
	+ Enter the project end date.
* **Project Location** (`project_location`, `text`, required: false):
	+ Enter the location of the project.
* **Project Description** (`project_description`, `text`, required: false):
	+ Enter a brief description of the project.
## Tips
* Ensure that all required fields are filled out.
* Double-check the entered information for accuracy.
* If you have any questions or concerns, please feel free to contact the relevant agency for clarification.
