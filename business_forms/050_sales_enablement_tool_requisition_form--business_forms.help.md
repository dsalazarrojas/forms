# Sales Enablement Tool Requisition Form - Help Guide
## Purpose
The Sales Enablement Tool Requisition Form is used to request sales tools and resources required by sales team members. This form helps to streamline the process of requesting and managing sales tools, ensuring that team members can focus on their sales activities without distractions.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill in your name and title of the form
* Specify the sales tool name and ID
* Provide a brief description of the tool
* Choose the category and purpose of the tool
* Identify if the sales manager is involved and provide their email address
* Specify the required date for the tool
* Mention who requested the tool
* Explain the purpose of the tool
* Select the type of sales tool (e.g. yes/no)
* Enter a budget for the tool
* Select the status of the tool (e.g. active/inactive)
* Identify if the tool is assigned to someone else
* Provide any additional comments or notes about the tool

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required: false): Enter a brief title for this form to help identify the purpose and scope of the request.
* **Sales Tool Name** (`sales_tool_name`, text, required: false): Enter the name of the sales tool you are requesting.
* **Sales Tool ID** (`sales_tool_id`, number, required: false): Enter the ID of the sales tool, if applicable.
* **Description** (`description`, text, required: false): Provide a brief description of the sales tool and its purpose.
* **Category** (`category`, text, required: false): Choose the category of the sales tool (e.g. software, hardware, etc.).
* **Sales Manager** (`sales_manager`, select_one, required: false): Identify if the sales manager is involved in the tool request.
* **Email** (`sales_manager_email`, email, required: false): Provide the email address of the sales manager, if applicable.
* **Phone** (`manager_phone`, text, required: false): Enter the phone number of the sales manager, if applicable.
* **Required Date** (`required_date`, date, required: false): Specify the date by which the tool is required.
* **Requested By** (`requested_by`, text, required: false): Mention who requested the tool.
* **Purpose** (`purpose`, text, required: false): Explain the purpose of the tool in the sales process.
* **Sales Tool Type** (`sales_tool_type`, select_multiple, required: false): Select the type of sales tool (e.g. yes/no).
* **Budget** (`budget`, number, required: false): Enter a budget for the tool, if applicable.
* **Status** (`status`, select_multiple, required: false): Select the status of the tool (e.g. active/inactive).
* **Assigned To** (`assigned_to`, select_multiple, required: false): Identify if the tool is assigned to someone else.
* **Notes** (`notes`, note, required: false): Provide any additional comments or notes about the tool.
* **Comments** (`comments`, note, required: false): Add any additional comments about the tool.
