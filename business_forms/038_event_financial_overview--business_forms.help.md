# Event Financial Overview - Help Guide
## Purpose
The Event Financial Overview form is used to collect financial information for events with significant financial transactions. This form helps to ensure that event financials are accurately recorded and reported.

## How To Complete This Form
1. Ensure you're using the correct event ID.
2. Review the event's financial transactions, including income and expenses.
3. Fill out the form with accurate financial information.
4. Select the correct tool associated with the event.

## Field-by-Field Explanation

* **Event Income** (`event_income`, number, required): Enter the total income earned from the event.
* **Event Expenses** (`event_expenses`, number, required): Enter the total expenses incurred for the event.
* **Event Expenses Description** (`event_expenses_description`, text, required): Provide a brief description of the event expenses.
* **Event Profit Loss** (`event_profit_loss`, number, required): Enter the total profit or loss from the event.
* **Event Profit Loss Percentage** (`event_profit_loss_percentage`, number, required): Enter the percentage of profit or loss from the event.
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool that was used to manage the event's financials.

Note: If a field is marked as required, it's essential to fill it out for the form to be complete.
