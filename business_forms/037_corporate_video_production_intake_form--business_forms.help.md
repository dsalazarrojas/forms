# corporate_video_production_intake_form - Help Guide
## Purpose
The corporate video production intake form is designed to collect project-related details from clients, project managers, or producers to create a corporate video. This form will help the production team understand the project's scope, timeline, and budget requirements, ensuring that all necessary information is captured for successful project execution.

## How To Complete This Form
To fill out this form, simply follow these steps:

1.  Enter the **Project Description** in the text field provided, describing the project's purpose, goals, and objectives.
2.  Provide the **Client Name**, which is the name of the client or organization related to the project.
3.  Enter the **Project Location**, specifying the location where the project will take place or be produced.
4.  Select a **Project Start Date** and **Project Deadline**, indicating the project's start and end dates in the format specified by your device's calendar options.
5.  For **Project Type**, choose from the available options provided (Option 1, Option 2, or Option 3) to categorize the project.
6.  If applicable, enter the **Number of Days** the project will require for completion.
7.  Provide an estimated **Budget Estimate** for the project, if known.

## Field-by-Field Explanation

*   **Project Description**: A brief description of the project's purpose, goals, and objectives.
*   **Client Name**: The name of the client or organization related to the project.
*   **Project Location**: The location where the project will take place or be produced.
*   **Project Start Date**: The date when the project is expected to start, using your device's calendar options.
*   **Project Deadline**: The date by which the project is expected to be completed, using your device's calendar options.
*   **Project Type**: Select one of the provided options to categorize the project (Option 1, Option 2, or Option 3).
*   **Number of Days**: If known, the number of days the project will require for completion.
*   **Budget Estimate**: An estimated budget for the project, if known.

## Tips

- Ensure that all mandatory fields are filled out before submission.
- For fields with date selections, use your device's calendar options for accurate date representation.
- Double-check all entered information before submitting to ensure it's accurate and complete.
- If unsure about a field or project type, refer to project requirements and specifications for guidance.
