# Data Visualization Input Form - Help Guide
## Purpose
This form is used to collect information for data visualization purposes. The input will help in analyzing and presenting data in a meaningful way.

## How To Complete This Form
- To complete this form, please go through each section carefully and fill in the required fields.
- Enter your details accurately in the text fields (e.g., Name, Date, Time).
- Select the correct options for selection fields (e.g., Select One, Select Multiple).
- Ensure you enter correct email addresses and phone numbers in the respective fields.
- For range fields, enter the start and end values accurately.

## Field-by-Field Explanation
- **Name** (text, required): Enter your name for identification purposes.
- **Email** (email, optional): Enter your email address. This will help in reaching you for further information.
- **Phone** (text, optional): Enter your phone number for contact purposes.
- **Date** (date, optional): Enter a date in the format mm/dd/yyyy.
- **Time** (time, optional): Enter a time in the format 12:00 AM.
- **Note** (note, optional): Enter any additional notes or comments.
- **Select One** (select_one, optional): Select one option from the list.
- **Select Multiple** (select_multiple, optional): Select multiple options from the list.
- **Decimal** (number, optional): Enter a decimal value.
- **Integer** (number, optional): Enter an integer value.
- **Date Range** (text, optional): Enter a date range in the format mm/dd/yyyy - mm/dd/yyyy.
- **Time Range** (text, optional): Enter a time range in the format 12:00 AM - 12:00 PM.
- **Select One Range** (select_one, optional): Select one option from the range.
- **Select Multiple Range** (select_multiple, optional): Select multiple options from the range.
- **Email Range** (text, optional): Enter an email range in the format email1@example.com - email2@example.com.
- **Phone Range** (text, optional): Enter a phone number range in the format 123-456-7890 - 987-654-3210.
- **Form Range** (text, optional): Enter a form range.
- **Note Range** (text, optional): Enter a note range.
- **Date Range Start** (text, optional): Enter the start of the date range.
- **Time Range Start** (text, optional): Enter the start of the time range.
- **Note Range Start** (text, optional): Enter the start of the note range.
- **Date Range End** (text, optional): Enter the end of the date range.
- **Time Range End** (text, optional): Enter the end of the time range.
- **Note Range End** (text, optional): Enter the end of the note range.
