# Supervisor Note Form - Help Guide
## Purpose
The Supervisor Note Form is a document used to record and document important notes from supervisors to employees or workers. This form helps to provide valuable feedback, instructions, or reminders to workers, ensuring they are up-to-date and aware of their tasks and expectations.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Supervisor Note Form" link to access the form.
2. Fill in the "Worker ID" field with the correct ID number of the worker you are addressing.
3. In the "Note" field, type in the relevant feedback, instruction, or reminder for the worker.
4. Select a date for the note in the "Date" field.
5. Optionally, select a time for the note in the "Time" field.
6. Once you have filled out all necessary fields, click the "Submit" button to save the note.

## Field-by-Field Explanation
* **Worker ID**: Enter the unique ID number of the worker you are addressing. This helps the worker know who the note is for.
* **Note**: Type in the feedback, instruction, or reminder you have for the worker. This can be a brief message or a more detailed explanation.
* **Date**: Select the date you want the note to be recorded on. This helps the worker know when the note applies to.
* **Time**: Optionally, select a time for the note to be recorded. If left blank, the time will default to the current time.

## Tips
* Make sure to fill out the "Worker ID" field correctly to ensure the note reaches the intended recipient.
* Keep the "Note" field concise and to the point to avoid confusing the worker.
* Ensure the "Date" field is accurate to reflect the correct time period the note applies to.
* If you need to provide feedback or instructions to the worker, use the "Note" field to do so.
* Use the "Time" field to provide a specific time for the note or leave it blank for a general note.
