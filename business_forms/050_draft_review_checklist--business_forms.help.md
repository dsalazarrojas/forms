# Draft Review Checklist - Help Guide
## Purpose
The "Draft Review Checklist" form is used to collect feedback and information about a project from reviewers within an organization. It helps to ensure that projects are accurately reflected in their status and that feedback is provided in a structured format.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current project status from the dropdown menu.
2. Enter the date of the review.
3. Add any comments about the project.
4. Choose relevant project types from the list.
5. Enter the name and department of the reviewer.
6. Add any additional review comments.
7. Enter the title of the reviewer.

## Field-by-Field Explanation
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project from the dropdown menu.
* **Review Date** (`review_date`, date, optional): Enter the date when the review was conducted.
* **Comments** (`comments`, note, optional): Add any comments about the project.
* **Project Type** (`project_type`, select_multiple, optional): Choose all applicable project types that apply to the project.
* **Reviewer Name** (`reviewer_name`, text, optional): Enter the name of the reviewer.
* **Reviewer Department** (`reviewer_department`, text, optional): Enter the department of the reviewer.
* **Review Comments** (`review_comments`, note, optional): Add any additional review comments.
* **Reviewer Title** (`reviewer_title`, text, optional): Enter the title of the reviewer.

## Tips
* Make sure to choose the correct project status to accurately reflect its current status.
* Enter the review date to help track the progress of reviews.
* Use the comments field to provide constructive feedback.
* Select all applicable project types to ensure that the project is properly categorized.
* Enter the reviewer's name and department for easy identification.
* Use the review comments field to add any additional comments.
