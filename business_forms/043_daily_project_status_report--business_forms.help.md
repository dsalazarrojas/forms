# daily-project-status-report - Help Guide
## Purpose
The daily project status report form is used to update project status on a daily basis, keeping team members and stakeholders informed about project progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current project status from the options provided in the "Project Status" field.
2. Choose any milestones that have been reached in the "Milestones Reached" field.
3. If necessary, describe any challenges or issues that have arisen in the "Challenges" field.
4. Select the overall progress of the project in the "Overall Progress" field.
5. Add any additional comments or notes about the project in the "Additional Comments" field.
6. Identify any contact information for team members or stakeholders in the "Contact Information" field.
7. If applicable, select the date the project was created in the "Date Created" field and the date it is due in the "Date Due" field.

## Field-by-Field Explanation

* **Project Status** (`project_status`, select_one, required): Select the current status of the project. This could be "On Track", "At Risk", "Delayed", or "Completed".
* **Milestones Reached** (`milestones_reached`, select_multiple, required): Choose any milestones that have been completed or met.
* **Challenges** (`challenges`, text, required): Describe any challenges or issues that are currently affecting the project.
* **Overall Progress** (`overall_progress`, select_one, required): Select the overall progress of the project. This could be "Not Started", "In Progress", "Completed", or "Postponed".
* **Additional Comments** (`additional_comments`, text, required): Add any additional comments or notes about the project.
* **Next Steps** (`next_steps`, text, required): Describe the next steps that need to be taken on the project.
* **Contact Information** (`contact_information`, select_multiple, required): Identify any contact information for team members or stakeholders who are working on or involved in the project.
* **Date Created** (`date_created`, date, required): Select the date the project was created.
* **Date Due** (`date_due`, date, required): Select the date the project is due.

Note: The fields marked as required are those that must be completed for the form to be valid.
