# Treasury Report Correction Request Form - Help Guide
## Purpose
The purpose of this form is to request corrections for treasury reports. This form should only be used for corrections, not for general inquiries or other types of requests. 

## How To Complete This Form
To complete this form, follow the steps below:

1. Ensure you have a clear understanding of the issue you are trying to correct.
2. Fill in the form details (form_header_details) briefly describing the correction request.
3. Indicate whether the request is coming from the person who made the original report (form_header_requestor).
4. Select the status of the request (form_header_status) to reflect the current state of the report.
5. Enter the date and time when the form was submitted (form_header_submitting_date).
6. If applicable, indicate whether the report has been approved (form_header_approver).
7. Enter any comments about the request (form_header_comments).
8. Review the form carefully before submitting it to ensure all required fields are filled and the request is clear and concise.

## Field-by-Field Explanation
* **Form Header** (form_header): This is the header section of the form where you can enter a brief description of the correction request.
* **Form Details** (form_header_details): Enter a short description of the correction request. This can include details about the report, the correction needed, and any relevant information.
* **Requestor** (form_header_requestor): Check if the request is coming from the person who made the original report. This helps to ensure that the correct person is making the request.
* **Date** (form_header_date): Enter the date of the original report that needs to be corrected.
* **Status** (form_header_status): Select the status of the request to reflect the current state of the report. This can be 'Pending', 'Processing', or 'Completed'.
* **Submit Date** (form_header_submitting_date): Enter the date and time when you are submitting the form.
* **Approver** (form_header_approver): Check if the report has been approved by someone else. This helps to ensure that the report has been reviewed and approved before the correction request is made.
* **Comments** (form_header_comments): Enter any additional comments about the request.
* **Form Footer** (form_footer): This is the footer section of the form with a note about the form.
