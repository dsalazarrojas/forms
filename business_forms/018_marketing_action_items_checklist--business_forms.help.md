# Marketing Action Items Checklist - Help Guide
## Purpose
The Marketing Action Items Checklist is a form used to track and manage marketing campaigns. It helps you keep track of the status, priority, and other important details of each campaign task.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant campaign status from the "Campaign Status" dropdown menu.
2. Enter the title of the campaign task in the "Campaign Task Title" field.
3. Choose the priority level of the campaign from the "Campaign Priority" dropdown menu.
4. Enter the start date and start time of the task, if applicable.
5. Add any additional notes about the task in the "Task Notes" field.
6. If necessary, specify the priority order of the campaign.

## Field-by-Field Explanation

* **Campaign Status (Campaign Status)** (`campaign_status`, select_one, required: false): Select the current status of the campaign, such as Active, Completed, or Paused.
* **Campaign Task Title (Campaign Task Title)** (`campaign_task_title`, text, required: false): Enter a brief title of the campaign task.
* **Task Start Date (Task Start Date)** (`task_start_date`, date, required: false): Enter the start date of the task, if applicable.
* **Task Start Time (Task Start Time)** (`task_start_time`, time, required: false): Enter the start time of the task, if applicable.
* **Campaign Priority (Campaign Priority)** (`campaign_priority`, select_one, required: false): Choose the priority level of the campaign, such as High, Medium, or Low.
* **Priority Order (Campaign Priority Order)** (`campaign_priority_order`, number, required: false): If necessary, specify the priority order of the campaign.
* **Task Notes (Task Notes)** (`task_notes`, note, required: false): Add any additional notes about the task.
* **Campaign Manager (Campaign Manager)** (`campaign_manager`, text, required: false): Identify the campaign manager assigned to the campaign.

Note: The form is not a required form, and the fields are optional unless specifically marked as required.
