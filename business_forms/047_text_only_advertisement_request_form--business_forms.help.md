# Text Only Advertisement Request Form - Help Guide

## Purpose

The Text Only Advertisement Request Form is used to collect information about text-only advertisements for marketing agencies, agencies, and companies. This form helps to streamline the process of requesting and managing text-only advertisements.

## How To Complete This Form

- Fill out the form with accurate and clear information about your request.
- Review the form carefully before submitting it to ensure that all fields are filled out correctly.

## Field-by-Field Explanation

* **category**: Select the category that best fits your advertisement request from the dropdown options (Marketing Agency, Agency, or Company).
* **name**: Enter the name of the person requesting the advertisement.
* **email**: Enter a valid email address.
* **phone**: Enter a valid phone number.
* **date**: Enter the date of the request in the format MM/DD/YYYY.
* **time**: Enter the time of the request in the format HH:MM AM/PM.
* **note**: Enter a brief note about the request.
* **assigned_tool**: Select all applicable tools that will be used to handle the request (chatjimmy, chatbot, or chatbot2).
* **submitted_by**: Select who submitted the request from the dropdown options (User, Admin, or Agency).
* **submitted_by**: Enter a brief note about the request.

Note: The **name** and **submitted_by** fields are for reference purposes only and will not be visible to the users.
