# Project Task Assignment Form - Help Guide
## Purpose
The Project Task Assignment Form is used to assign project tasks to team members and collect relevant project information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the "Project Lead" field with the name of the project lead responsible for the project.
2. Select the "Start Date" field to enter the start date of the project.
3. Select the "End Date" field to enter the end date of the project.
4. Choose the project status in the "Status" field.
5. Add any status updates in the "Status Update" field.
6. Assign a priority level to the project in the "Priority" field.
7. Assign the project to a team member in the "Assigned To" field.
8. Specify who assigned the project in the "Assigned By" field.
9. Add any notes related to the project in the "Notes" field.
10. Leave comments for the project in the "Comments" field.
11. Specify who the comments are from in the "Comments To" field.
12. Select the date and time of the comments in the "Comments Date" and "Comments Time" fields.
13. Specify the email of the comments author in the "Comments User Email" field.
14. Enter the phone number of the comments author in the "Comments User Phone" field.
15. Add any additional notes for the comments author in the "Comments User Notes" field.
16. Choose an attachment option from the "Attachment" field.
17. Enter the URL of the attachment in the "Attachment URL" field.
18. Specify the size of the attachment in the "Attachment Size" field.
19. Specify the MIME type of the attachment in the "Attachment MIME" field.
20. Enter the date and time of the attachment in the "Attachment Date" and "Attachment Time" fields.

## Field-by-Field Explanation

* **Project Lead**: Enter the name of the project lead responsible for the project.
* **Start Date**: Select the start date of the project.
* **End Date**: Select the end date of the project.
* **Status**: Choose the project status.
* **Status Update**: Add any status updates related to the project.
* **Priority**: Assign a priority level to the project.
* **Assigned To**: Assign the project to a team member.
* **Assigned By**: Specify who assigned the project.
* **Notes**: Add any notes related to the project.
* **Comments**: Leave comments for the project.
* **Comments To**: Specify who the comments are from.
* **Comments Date**: Select the date of the comments.
* **Comments Time**: Select the time of the comments.
* **Comments User**: Specify the name of the comments author.
* **Comments User Email**: Enter the email of the comments author.
* **Comments User Phone**: Enter the phone number of the comments author.
* **Comments User Notes**: Add any additional notes for the comments author.
* **Attachment**: Choose an attachment option.
* **Attachment URL**: Enter the URL of the attachment.
* **Attachment Size**: Specify the size of the attachment.
* **Attachment MIME**: Specify the MIME type of the attachment.
* **Attachment Date**: Select the date of the attachment.
* **Attachment Time**: Select the time of the attachment.

Note: All fields are optional, unless otherwise specified.
