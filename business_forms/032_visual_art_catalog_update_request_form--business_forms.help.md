# Visual Art Catalog Update Request Form - Help Guide
## Purpose
The Visual Art Catalog Update Request Form is used to update information about visual art entries in a catalog. This form should be used when you need to add, modify, or delete information about a visual art piece.

## How To Complete This Form
To fill out this form, follow these steps:

1. Review the form carefully to ensure you are only updating the correct information.
2. Enter the title of the artwork in the "Artwork Title" field.
3. Enter a brief description of the artwork in the "Artwork Description" field.
4. Select the category of the artwork from the list of options in the "Category" field.
5. Select the type of artwork from the list of options in the "Type" field.
6. If you have a file to upload, you can drag and drop it into the "Upload Artwork File" field or browse for it.
7. If you don't have a file, you can enter the URL of the artwork in the "Artwork File URL" field.
8. Finally, click the "Submit" button to send the update request.

## Field-by-Field Explanation

* **Artwork Title** (required): This field is used to enter the title of the artwork.
* **Artwork Description** (optional): This field is used to enter a brief description of the artwork.
* **Category** (optional):
	+ Select "Abstract" for abstract or non-representational art.
	+ Select "Architecture" for works of architecture or buildings.
	+ Select "Conceptual" for conceptual or conceptual art.
	+ Select "Fine Art" for traditional or fine art.
	+ Select "Graphic Art" for graphic design or illustrations.
	+ Select "Illustrations" for illustrations.
	+ Select "Mixed Media" for mixed media or multimedia art.
	+ Select "Photography" for photographs.
	+ Select "Printmaking" for printmaking or prints.
	+ Select "Sculpture" for sculpture or 3D art.
* **Type** (optional):
	+ Select "Painting" for traditional painting.
	+ Select "Print" for printmaking or prints.
	+ Select "Digital" for digital art or digital media.
	+ Select "Mixed Media" for mixed media or multimedia art.
	+ Select "Other" for other or unspecified.
* **Upload Artwork File** (optional): This field is used to upload a file related to the artwork.
* **Artwork File URL** (optional): This field is used to enter the URL of the artwork if you don't have a file.
* **Submit** (required): Click this button to send the update request.
