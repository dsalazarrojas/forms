# Ambulance Rig Check Form - Help Guide
## Purpose
The Ambulance Rig Check Form is a comprehensive checklist used to inspect and verify the readiness of an ambulance for service. This form ensures that all critical systems, vehicle components, and equipment are in good working order, reducing the risk of mechanical failure and ensuring patient safety.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review each section carefully, and select the corresponding answer based on the condition of the vehicle.
2.  Ensure you have checked all areas of the ambulance, including the exterior and interior.
3.  Record your findings in the provided fields, and be specific about any issues or concerns.
4.  Sign and date the form when completed.

## Field-by-Field Explanation

*   **Check Date** (`check_date`, date, required): Enter the date of the inspection.
*   **Check Time** (`check_time`, time, required): Enter the time of the inspection.
*   **Rig/Unit Number** (`rig_unit_number`, text, required): Enter the vehicle's identification number.
*   **Rig Type** (`rig_type`, select_one, required): Select the type of ambulance (e.g., Type I, Type II, Type III, etc.).
*   **Shift** (`shift`, select_one, required): Select the shift you are working (e.g., Day Shift, Evening Shift, Night Shift, etc.).
*   **Crew Member 1 Name** (`crew_member_1`, text, required): Enter the name of the first crew member.
*   **Crew Member 1 Certification** (`crew_member_1_cert`, select_one, required): Select the certification level of the first crew member (e.g., EMT-B, EMT-I, Paramedic, etc.).
*   **Crew Member 2 Name** (`crew_member_2`, text, required): Enter the name of the second crew member.
*   **Crew Member 2 Certification** (`crew_member_2_cert`, select_one, required): Select the certification level of the second crew member (e.g., EMT-B, EMT-I, Paramedic, etc.).
*   **Exterior Body Condition** (`exterior_condition`, select_one, required): Select the condition of the exterior body (e.g., Good - No damage, Fair - Minor damage, etc.).
*   **Emergency Lights** (`lights_emergency`, select_one, required): Select the condition of all emergency lights (e.g., All functional, Some not functional, None functional, etc.).
*   **Headlights** (`lights_head`, select_one, required): Select the condition of headlights (e.g., All functional, Some not functional, None functional, etc.).
*   **Taillights and Brake Lights** (`lights_tail`, select_one, required): Select the condition of taillights and brake lights (e.g., All functional, Some not functional, None functional, etc.).
*   **Siren/Audible Warning** (`siren`, select_one, required): Select the condition of siren/audible warning system (e.g., All modes functional, Some modes not functional, Not functional, etc.).
*   **Tire Condition** (`tires_condition`, select_one, required): Select the condition of tires (e.g., Good, Fair, Poor, etc.).
*   **Tire Pressure** (`tires_pressure`, select_one, required): Select the condition of tire pressure (e.g., All adequate, Some low, All low, etc.).
*   **Spare Tire** (`spare_tire`, select_one, required): Select the condition of the spare tire (e.g., Present and adequate, Present but low, Missing, etc.).
*   **Windows** (`windows`, select_one, required): Select the condition of windows (e.g., Clean and intact, Needs cleaning, Damaged, etc.).
*   **Mirrors** (`mirrors`, select_one, required): Select the condition of mirrors (e.g., All present and adjusted, Needs adjustment, Damaged/missing, etc.).
*   **Cab Interior Cleanliness** (`interior_cleanliness`, select_one, required): Select the condition of the cab interior (e.g., Clean, Acceptable, Needs cleaning, etc.).
*   **Dashboard Gauges** (`dashboard_gauges`, select_one, required): Select the condition of dashboard gauges (e.g., All functional, Some not functional, Many not functional, etc.).
*   **Warning Lights** (`warning_lights`, select_one, required): Select the condition of warning lights (e.g., No warnings, Minor warnings, Major warnings, etc.).
*   **Steering** (`steering`, select_one, required): Select the condition of steering (e.g., Normal, Some play, Excessive play, etc.).
*   **Brakes** (`brakes`, select_one, required): Select the condition of brakes (e.g., Normal, Spongy, Hard, etc.).
*   **Parking Brake** (`parking_brake`, select_one, required): Select the condition of parking brake (e.g., Holds properly, Slips, Not functional, etc.).
*   **Horn** (`horn`, select_one, required): Select the condition of horn (e.g., Functional, Not functional, etc.).
*   **Seatbelts (All Positions)** (`seatbelts`, select_one, required): Select the condition of seatbelts (e.g., All functional, Some not functional, Many not functional, etc.).
*   **Seats** (`seats`, select_one, required): Select the condition of seats (e.g., All secure, Some loose, Damaged, etc.).
*   **Heating and Air Conditioning** (`climate_control`, select_one, optional): Select the condition of heating and air conditioning system (e.g., Both functional, One functional, Neither functional, etc.).
*   **Radio/Communication System** (`radio_communication`, select_one, required): Select the condition of radio/communication system (e.g., Functional, Partially functional, Not functional, etc.).
*   **GPS/Mobile Data Terminal** (`gps_mdt`, select_one, optional): Select the condition of GPS/mobile data terminal (e.g., Functional, Not functional, Not equipped, etc.).
*   **Patient Compartment Cleanliness** (`compartment_cleanliness`, select_one, required): Select the condition of patient compartment (e.g., Clean and sanitized, Acceptable, Needs cleaning, etc.).
*   **Patient Compartment Odor** (`compartment_odour`, select_one, required): Select the condition of patient compartment odor (e.g., No odor, Mild odor, Strong odor, etc.).
*   **Stretcher** (`stretcher`, select_one, required): Select the condition of stretcher (e.g., Fully functional, Partially functional, Not functional, etc.).
*   **Stretcher Mount/Lock** (`stretcher_mount`, select_one, required): Select the condition of stretcher mount/lock (e.g., Secures properly, Loose, Not functional, etc.).
*   **Stretcher Straps** (`stretcher_straps`, select_one, required): Select the condition of stretcher straps (e.g., All present and functional, Some missing, Many missing, etc.).
*   **Oxygen System** (`oxygen_system`, select_one, required): Select the condition of oxygen system (e.g., Full and functional, Partially full, Needs refill, etc.).
*   **Suction Unit** (`suction_unit`, select_one, required): Select the condition of suction unit (e.g., Both functional, One functional, Neither functional, etc.).
*   **Cardiac Monitor/Defibrillator** (`monitor_defibrillator`, select_one, required): Select the condition of cardiac monitor/defibrillator (e.g., Charged and functional, Needs charging, Not functional, etc.).
*   **Fuel Level** (`fuel_level`, select_one, required): Select the condition of fuel level (e.g., Full, 3/4, 1/2, 1/4, Needs fuel, etc.).
*   **Engine Oil** (`engine_oil`, select_one, required): Select the condition of engine oil (e.g., Adequate and clean, Low, Dirty/contaminated, etc.).
*   **Coolant Level** (`coolant`, select_one, required): Select the condition of coolant level (e.g., Adequate, Low, Very low, etc.).
*   **Brake Fluid Level** (`brake_fluid`, select_one, required): Select the condition of brake fluid level (e.g., Adequate, Low, Very low, etc.).
*   **Windshield Washer Fluid** (`windshield_washer`, select_one, required): Select the condition of windshield washer fluid (e.g., Adequate, Low, Empty, etc.).
*   **Odometer Reading** (`odometer_reading`, number, required): Enter the current odometer reading.
*   **Engine Hours** (`hours_meter`, number, optional): Enter the engine hours (if applicable).
*   **Were Any Issues Found?** (`issues_found`, select_one, required): Select the condition of any issues found (e.g., No - All clear, Yes - Minor issues, Yes - Major issues, etc.).
*   **Describe Issues Found** (`issues_description`, text, optional): Describe any issues found (if applicable).
*   **Maintenance Required** (`maintenance_required`, select_one, required): Select the condition of maintenance required (e.g., No maintenance needed, Routine maintenance, Urgent maintenance, Vehicle out of service, etc.).
*   **Describe Maintenance Needed** (`maintenance_description`, text, optional): Describe any maintenance needed (if applicable).
*   **Is Vehicle Ready for Service?** (`vehicle_ready`, select_one, required): Select the condition of the vehicle (e.g., Yes - Fully ready, Yes - With minor issues, No - Needs repair, etc.).
*   **Additional Notes** (`additional_notes`, text, optional): Enter any additional notes or comments.
*   **Rig Check Completed By** (`checked_by`, text, required): Enter the name of the primary crew member completing the form.
*   **Checked By (Partner)** (`checked_by_partner`, text, optional): Enter the name of the partner completing the form (if applicable).
*   **Supervisor Review** (`supervisor_review`, text, optional): Enter the review comments from the supervisor (if applicable).
*   **Supervisor Signature** (`supervisor_signature`, text, optional): Enter the supervisor's signature (if applicable).
