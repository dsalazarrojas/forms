# Schema Creation Form - Help Guide
## Purpose
This form is used to collect the necessary information to create a new schema for your project.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields as they appear on each page. The form will guide you through each step.
2. Ensure that all required fields are filled out before moving on to the next page.
3. Review the form for errors or incomplete fields before submitting.

## Field-by-Field Explanation

* **First Name**: Enter your first name as it appears on official documents.
* **Last Name**: Enter your last name as it appears on official documents.
* **Email**: Enter a valid email address where you can be reached.
* **Phone**: Enter a phone number where you can be reached.
* **Team Lead**: Select the team lead responsible for the schema.
	+ Options: John, Jane, Jim
* **Date**: Enter the date you want the schema to be effective from.
* **Time**: Enter the time you want the schema to be effective from.
* **Note**: Enter any additional notes about the schema.
* **Schema Name**: Enter a name for the new schema.
* **Schema Version**: Enter a version number for the new schema.
	+ Note: This field is not currently used in the schema creation process.
