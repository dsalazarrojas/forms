# quality_metric_adjustment_request_form - Help Guide
## Purpose
This form is used to submit a request for quality metric adjustment. It is intended for submitters to provide additional information about the request, including the submitter's and reviewer's contact details, metric name, and reason for the request. The form also allows for the submission of additional comments and notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Submit Request" option to indicate that you are submitting a request for quality metric adjustment.
2. Choose the date for the request from the calendar or date picker.
3. Enter the name of the metric for which you are requesting an adjustment.
4. Enter the value of the metric being adjusted.
5. Provide a reason for the request in the "Reason" field.
6. Select the department related to the request.
7. Enter your team name if applicable.
8. Enter your comments as the submitter.
9. Enter the reviewer's comments if they have reviewed the request.
10. Enter the submitter's name, title, and organization if applicable.
11. Enter the reviewer's name, title, and organization if applicable.
12. Enter the submitter's phone number and email if applicable.
13. Enter the reviewer's phone number and email if applicable.
14. Select the metric type.
15. Select the adjustment type.
16. Enter any additional comments from the submitter and reviewer.
17. Select the approval status.
18. Enter any submitter notes.

## Field-by-Field Explanation
* **Submit Request**: This field allows you to indicate that you are submitting a request for quality metric adjustment.
* **Date**: Enter the date for the request.
* **Metric Name**: Enter the name of the metric being adjusted.
* **Metric Value**: Enter the value of the metric being adjusted.
* **Reason**: Provide a reason for the request.
* **Department**: Select the department related to the request.
* **Team Name**: Enter your team name if applicable.
* **Submitter Comments**: Enter any comments from the submitter.
* **Reviewer Comments**: Enter any comments from the reviewer.
* **Submitter Name**: Enter your name as the submitter.
* **Submitter Title**: Enter your title as the submitter.
* **Submitter Organization**: Enter your organization if applicable.
* **Reviewer Name**: Enter the name of the reviewer.
* **Reviewer Title**: Enter the title of the reviewer.
* **Reviewer Organization**: Enter the organization of the reviewer if applicable.
* **Submitter Phone**: Enter your phone number as the submitter.
* **Reviewer Phone**: Enter the phone number of the reviewer if applicable.
* **Submitter Email**: Enter your email address as the submitter.
* **Reviewer Email**: Enter the email address of the reviewer if applicable.
* **Metric Type**: Select the metric type.
* **Adjustment Type**: Select the adjustment type.
* **Submitter Comments Other**: Enter any additional comments from the submitter.
* **Reviewer Comments Other**: Enter any additional comments from the reviewer.
* **Approval Status**: Select the approval status.
* **Submitter Note**: Enter any notes from the submitter.
