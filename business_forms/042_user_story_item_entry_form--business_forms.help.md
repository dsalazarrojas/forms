# User Story Item Entry Form - Help Guide
## Purpose
The User Story Item Entry Form is designed to collect and display user story item data for team members and project managers to input and review.

## How To Complete This Form

1. **User Story Item**: Enter a short description of the user story.
2. **Story Points**: Enter the story points for the user story.
3. **Due Date**: Enter the due date for the user story.
4. **Actual Start Date**: Enter the actual start date of the user story.
5. **Actual End Date**: Enter the actual end date of the user story.
6. **Team Lead**: Select the team lead assigned to the user story.
7. **Team**: Select the team assigned to the user story.
8. **Priority**: Select the priority level of the user story.
9. **Status**: Select the status of the user story.
10. **Progress**: Enter the progress of the user story.
11. **Comments**: Enter any comments or notes about the user story.
12. **Email**: Enter the email address for communication.
13. **Phone**: Enter the phone number for communication.
14. **Location**: Enter the location of the user story.
15. **Description**: Enter a detailed description of the user story.
16. **User ID**: Enter the user ID number.
17. **Story ID**: Enter the story ID number.
18. **Project ID**: Enter the project ID number.
19. **Team ID**: Enter the team ID number.
20. **Assigned To**: Select the person assigned to the user story.
21. **Start Date**: Enter the start date of the user story.
22. **End Date**: Enter the end date of the user story.
23. **Comments**: Enter any additional comments about the user story.
24. **Attachments**: Enter any attachments related to the user story.
25. **Files**: Upload any files related to the user story.

## Field-by-Field Explanation

* **User Story Item**: Enter a short description of the user story. (~ 1-2 sentences)
* **Story Points**: Enter the story points for the user story. (~ 0-5)
* **Due Date**: Enter the due date in the format `YYYY-MM-DD`.
* **Actual Start Date**: Enter the actual start date in the format `YYYY-MM-DD`.
* **Actual End Date**: Enter the actual end date in the format `YYYY-MM-DD`.
* **Team Lead**: Select the team lead assigned to the user story.
* **Team**: Select all teams assigned to the user story.
* **Priority**: Select the priority level of the user story.
* **Status**: Select the status of the user story.
* **Progress**: Enter the progress of the user story. (~ 0-100)
* **Comments**: Enter any comments or notes about the user story.
* **Email**: Enter the email address for communication.
* **Phone**: Enter the phone number for communication.
* **Location**: Enter the location of the user story.
* **Description**: Enter a detailed description of the user story.
* **User ID**: Enter the user ID number.
* **Story ID**: Enter the story ID number.
* **Project ID**: Enter the project ID number.
* **Team ID**: Enter the team ID number.
* **Assigned To**: Select the person assigned to the user story.
* **Start Date**: Enter the start date of the user story.
* **End Date**: Enter the end date of the user story.
* **Comments**: Enter any additional comments about the user story.
* **Attachments**: Enter any attachments related to the user story.
* **Files**: Upload any files related to the user story.

Note: Dates should be formatted as `YYYY-MM-DD`.
