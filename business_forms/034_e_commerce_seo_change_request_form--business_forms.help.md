# e_commerce_seo_change_request_form - Help Guide

## Purpose
The e-commerce SEO change request form is used to request changes to e-commerce product pages. This form allows users to submit requests for various updates to product pages, including SEO optimization, content changes, and image updates.

## How To Complete This Form

To complete the form, follow these steps:

1. Fill in the required fields with accurate information.
2. Select the relevant options for the changes you would like to make.
3. Choose the date you would like to implement these changes on.
4. Provide any additional comments or notes as needed.

## Field-by-Field Explanation

* **User** (1): Enter your name and any relevant information about yourself.
* **Request Type** (2): Select the type of request you are making, such as Search Engine Optimization or Product Page Update.
* **Url** (3): Enter the URL of the product page you are requesting changes for.
* **Changes to SEO** (4): Select all the SEO changes you would like to make, such as title tags, description tags, and image tags.
* **Changes to Content** (5): Select all the content changes you would like to make, such as product name, description, headline, and call-to-action button text.
* **Changes to Images** (6): Select all the image changes you would like to make. (Note: This field is not required.)
* **Request Date** (7): Choose the date you would like to implement these changes on.
* **Priority** (8): Select the priority of your request, such as High, Medium, or Low.
* **Notes** (9): Provide any additional comments or notes as needed.
* **Assigned To** (10): Select the person you would like to be assigned to work on your request.
* **Status** (11): Select the status of your request, such as In Progress, Pending, or Completed. (Note: This field is not required.)
* **Comments** (12): Provide any additional comments as needed. (Note: This field is not required.)
* **Assigned Tool** (13): Enter the tool or resource you would like to be used to complete your request. (Note: This field is not required.)
* **Form Comments** (14): Provide any additional comments or notes as needed.
* **Submitted By** (15): Select the person submitting the request.
* **Submitted Date** (16): Enter the date you submitted the request.
* **Last Updated** (17): Enter the last updated date of your request.
* **Assigned To Email** (18): Enter the email of the person assigned to work on your request.
* **Submitted To** (19): Enter the email of the person submitting the request. (Note: This field is not required.)
* **Form Status** (20): Select the status of your form, such as Active or Inactive.
* **Request Type Details** (21): Provide any additional details about your request type.
* **Changes To URL** (22): Enter any changes you would like to make to the URL.
* **Changes To Images URL** (23): Enter any changes you would like to make to the images URL. (Note: This field is not required.)
* **Submitted By Email** (24): Enter the email of the person submitting the request.
* **Form Comments** (25): Provide any additional comments or notes as needed. (Note: This field is not required.)

## Tips

* Make sure to fill in all required fields.
* Select the correct options for the changes you would like to make.
* Double-check your information before submitting the form.
* If you have any questions or need help, contact the assigned person or submit a separate request.
