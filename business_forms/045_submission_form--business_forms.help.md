# Submission Form - Help Guide
## Purpose
The Submission Form is used to collect file submissions from users, gathering information such as file name, description, type, and size for processing or review.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Upload File" button to select a file from your computer or device.
2. Enter the file name in the text field.
3. Provide a brief description of the file in the text field.
4. Select the type of file from the dropdown menu.
5. Optionally, enter the file size in the number field, if applicable.
6. Click the "Submit" button to send the form.

## Field-by-Field Explanation

* **File Upload** (`file_upload`, file upload, required/optional: no): This field is where you select a file from your computer or device to be uploaded. Click on the "Browse" button to browse for your file.
* **File Name** (`file_name`, text, required/optional: no): This field is for entering the name of the file you are uploading. Make sure to enter a clear and concise name that accurately represents the file.
* **File Description** (`file_description`, text, required/optional: no): Provide a brief description of the file, such as its contents or purpose. This helps the reviewer understand the file's context.
* **File Type** (`file_type`, select, required/optional: no): Select the type of file from the dropdown menu to ensure it is correctly identified.
* **File Size** (`file_size`, number, required/optional: no): Enter the file size in kilobytes (KB) or megabytes (MB), if applicable.
