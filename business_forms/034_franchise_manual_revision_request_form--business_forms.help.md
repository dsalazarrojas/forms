# Franchise Manual Revision Request Form - Help Guide
## Purpose
The Franchise Manual Revision Request Form is a document used to request changes to the franchise manual. This form requires the submitter to provide a clear explanation of the reason for the change, a description of the requested change, and supporting information such as the current and previous versions of the manual, and the date when the new version will be effective.

## How To Complete This Form
1.  Fill out the form completely, including all required fields.
2.  Make sure to provide a clear and concise description of the change request.
3.  Enter accurate information about the current and previous versions of the manual.
4.  Enter the date when the new version will be effective.
5.  Choose the correct status of the manual.
6.  Enter your name and contact information for review and follow-up.

## Field-by-Field Explanation

* **What is the reason for the manual change request** (Franchise Manual Change Reason, id 2):
	+ A brief explanation of the reason for the manual change request.
* **Change Request Description** (Change Request Description, id 3):
	+ A clear and concise description of the requested change.
* **Franchise Manual Version** (Franchise Manual Version, id 4):
	+ The current version of the franchise manual.
* **Previous Franchise Manual Version** (Previous Franchise Manual Version, id 5):
	+ The version of the franchise manual before the change.
* **New franchise manual version** (New Franchise Manual Version, id 6):
	+ The new version of the franchise manual.
* **Franchise Manual Effective Date** (Franchise Manual Effective Date, id 7):
	+ The date when the new version will be effective.
* **Franchise Manual Status** (Franchise Manual Status, id 8):
	+ The status of the manual, which can be Active, Inactive, or Pending.
* **Submitter's Name** (Submitter's Name, id 9):
	+ Your name, which will be used for review and follow-up.
* **Submitter's Email** (Submitter's Email, id 10):
	+ Your email address, which will be used for review and follow-up.
* **Submitter's Phone** (Submitter's Phone, id 11):
	+ Your phone number, which will be used for follow-up.
* **Submitter's Department** (Submitter's Department, id 12):
	+ The department you belong to, which can be HQ, Regional, or Local.
