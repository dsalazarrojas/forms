# Project Addendum Submission Form - Help Guide
## Purpose
The purpose of this form is to submit updates or changes to existing projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the necessary information for your project.
2. Provide detailed descriptions for any changes made.
3. Submit the form for review and processing.

## Field-by-Field Explanation
* **Project Manager** (`project_manager`, text, required): The person responsible for the project.
* **Client Name** (`client_name`, text, required): The company or organization the project is for.
* **Date Changed** (`date_changed`, date, required): The date on which the change was made.
* **Time Changed** (`time_changed`, time, required): The time of day when the change was made.
* **Change Description** (`change_description`, text, required): A detailed description of the change, including why it was made and what impact it had.
* **Reason for Change** (`reason_for_change`, text, required): A brief explanation of the reason for the change.

## Tips
* Please make sure to provide as much detail as possible when filling out this form.
* If you are unsure about any of the fields, please contact us for guidance.
