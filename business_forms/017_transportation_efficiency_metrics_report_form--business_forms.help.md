# transportation_efficiency_metrics_report_form - Help Guide
## Purpose

This form is designed to collect data on transportation efficiency metrics for vehicles. The collected data can be used to optimize transportation routes, monitor vehicle performance, and identify areas for improvement.

## How To Complete This Form

1. Fill in the required fields: Vehicle Usage, Fuel Consumption, Route Efficiency, Travel Distance, Fuel Type, Vehicle Capacity, Start Date, End Date, Travel Time, Fuel Level, Vehicle Status, Comments, Notes, Email Address, and Vehicle ID.
2. Select the correct options for Vehicle Type, Location, and Vehicle Model.
3. Fill in the optional fields: Phone Number, Vehicle ID, Assigned User, Route ID, Department ID, Employee ID, Vehicle Driver, and Vehicle Model.

## Field-by-Field Explanation

* **Transportation Efficiency Metrics**: Enter a brief description of the transportation efficiency metrics you want to track.
* **Vehicle Usage**: Enter the number of times the vehicle has been used.
* **Fuel Consumption**: Enter the amount of fuel consumed by the vehicle.
* **Route Efficiency**: Enter a brief description of the route efficiency metrics you want to track.
* **Travel Distance**: Enter the distance traveled by the vehicle.
* **Fuel Type**: Select the type of fuel used by the vehicle (Gasoline, Diesel, Electric).
* **Vehicle Capacity**: Select the capacity of the vehicle (Small, Medium, Large).
* **Start Date**: Enter the start date of the transportation event.
* **End Date**: Enter the end date of the transportation event.
* **Travel Time**: Enter the travel time of the event.
* **Fuel Level**: Enter the fuel level of the vehicle.
* **Vehicle Status**: Select the status of the vehicle (Available, Maintenance, Broken).
* **Comments**: Enter any additional comments about the transportation event.
* **Notes**: Enter any additional notes about the transportation event.
* **Email Address**: Enter the email address of the person submitting the form.
* **Phone Number**: Enter the phone number of the person submitting the form.
* **Vehicle ID**: Enter the ID number of the vehicle.
* **Assigned User**: Enter the name of the user assigned to the vehicle.
* **Route ID**: Enter the ID number of the route.
* **Vehicle Type**: Select the type of vehicle (Truck, Bus, Train).
* **Location**: Select the location of the vehicle (City, Town, Suburbs).
* **Department ID**: Enter the ID number of the department.
* **Employee ID**: Enter the ID number of the employee.
* **Vehicle Driver**: Enter the name of the vehicle driver.
* **Vehicle Model**: Select the model of the vehicle (Toyota, Ford, Chevrolet).
* **Vehicle ID (Optional)**: If you have a vehicle ID, enter it here. If not, leave it blank.
* **Assigned User (Optional)**: If you have an assigned user, enter their name here. If not, leave it blank.
* **Route ID (Optional)**: If you have a route ID, enter it here. If not, leave it blank.
* **Department ID (Optional)**: If you have a department ID, enter it here. If not, leave it blank.
* **Employee ID (Optional)**: If you have an employee ID, enter it here. If not, leave it blank.
* **Vehicle Driver (Optional)**: If you have a vehicle driver, enter their name here. If not, leave it blank.
* **Vehicle Model (Optional)**: If you have a vehicle model, select it here. If not, leave it blank.
