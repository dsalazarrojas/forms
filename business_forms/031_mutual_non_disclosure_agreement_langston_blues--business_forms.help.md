# mutual_non_disclosure_agreement_langston_blues - Help Guide
## Purpose
This form is used to collect mutual non-disclosure agreement information for business purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct category for the mutual non-disclosure agreement.
2. Enter a brief description of the agreement.
3. Select the tool(s) assigned to the agreement.
4. Enter the output file name.
5. Select the correct form ID from the options.

## Field-by-Field Explanation
* **Category** (`category`, select_one, required): Select the category for the mutual non-disclosure agreement.
* **Description** (`description`, text, optional): Enter a brief description of the agreement.
* **Assigned Tool(s)** (`assigned_tool`, select_multiple, optional): Select the tool(s) assigned to the mutual non-disclosure agreement.
* **Output File Name** (`output_file`, text, required): Enter a name for the output file containing the agreement's details.
* **Form ID** (`form_ids`, select_one, required): Select the correct form ID for the mutual non-disclosure agreement.

## Tips
* Ensure that the information you provide is accurate and up-to-date.
* Review the form carefully before submitting to avoid errors.
* If you are unsure about any field, please contact your administrator for assistance.
