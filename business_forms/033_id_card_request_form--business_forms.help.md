# id_card_request_form - Help Guide
## Purpose
This form is used to request an ID card for an employee.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the ID card type you need (e.g., "Yes" or "No").
2. Enter a brief reason for requesting the ID card.
3. Enter your employee name.
4. Enter your employee ID.
5. Enter the department you belong to (optional).
6. Enter the branch you belong to (optional).
7. Enter a description of the reason for requesting the ID card (optional).
8. If you have a current ID card, enter its number (optional).
9. Select the status of your current ID card (e.g., "Active" or "Inactive").
10. Enter your name and email address for submitting the request.
11. Enter your phone number for submitting the request.
12. Select the date and time you submit the request.

## Field-by-Field Explanation

* **ID Card Type** (`id_card_type`, select_one): Select the type of ID card you need.
* **Reason** (`reason`, text): Enter a brief reason for requesting the ID card.
* **Employee Name** (`employee_name`, text): Enter your full name.
* **Employee ID** (`employee_id`, text): Enter your employee ID number.
* **Department** (`department`, text): Enter the department you belong to (if applicable).
* **Branch** (`branch`, text): Enter the branch you belong to (if applicable).
* **Reason Description** (`reason_description`, text): Enter a description of the reason for requesting the ID card (if applicable).
* **New ID Card** (`new_id_card`, text): Enter the ID card number of your new ID card (if applicable).
* **Old ID Card** (`old_id_card`, text): Enter the ID card number of your old ID card (if applicable).
* **ID Card Number** (`id_card_number`, text): Enter the ID card number of your current ID card (if you have one).
* **ID Card Status** (`id_card_status`, select_one): Select the status of your current ID card (e.g., "Active" or "Inactive").
* **Submitter** (`submitter`, text): Enter your name as the submitter of this request.
* **Submitter Email** (`submitter_email`, email): Enter your email address as the submitter of this request.
* **Submitter Phone** (`submitter_phone`, text): Enter your phone number as the submitter of this request.
* **Submitter Date** (`submitter_date`, date): Select the date and time you submit the request.
* **Submitter Time** (`submitter_time`, time): Select the time you submit the request.
