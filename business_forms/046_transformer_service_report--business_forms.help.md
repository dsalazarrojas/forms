# Transformer Service Report - Help Guide
## Purpose
The Transformer Service Report is a form used to document and report maintenance activities related to transformers in power distribution systems. It collects information about the transformer type, location, start and end dates, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for the maintenance activity (e.g., Business Forms).
2. Provide a brief description of the maintenance activity.
3. Choose the type of transformer (e.g., Pole-Mounted, Pad-Mounted, Substation Transformer).
4. Enter the location of the transformer.
5. Choose the start and end dates for the maintenance activity.
6. (Optional) Enter the duration of the maintenance activity.
7. (Optional) Provide any comments or notes about the activity.
8. If applicable, select the tool assigned for the maintenance activity.

## Field-by-Field Explanation
### Category
Select the category for the maintenance activity. This field is required.
*   **Category**: This field is used to classify the type of maintenance activity. Choose "Business Forms" or "Other" depending on the relevant category.

### Transformer Type
Select the type of transformer for the maintenance activity. This field is required.
*   **Transformer Type**: This field is used to identify the type of transformer. Choose from the options: Pole-Mounted Transformer, Pad-Mounted Transformer, or Substation Transformer.

### Description
Provide a brief description of the maintenance activity. This field is optional.
*   **Description**: This field is used to provide a brief description of the maintenance activity. Enter a short paragraph describing the work performed.

### Transformer Location
Enter the location of the transformer. This field is optional.
*   **Transformer Location**: This field is used to identify the location of the transformer. Enter the specific location, such as a street address or a facility name.

### Start Date
Enter the start date for the maintenance activity. This field is optional.
*   **Start Date**: This field is used to record the start date of the maintenance activity. Enter the date in the correct format (e.g., YYYY-MM-DD).

### End Date
Enter the end date for the maintenance activity. This field is optional.
*   **End Date**: This field is used to record the end date of the maintenance activity. Enter the date in the correct format (e.g., YYYY-MM-DD).

### Duration
Enter the duration of the maintenance activity. This field is optional.
*   **Duration**: This field is used to record the length of the maintenance activity. Enter the duration in days or hours.

### Comments
Provide any comments or notes about the maintenance activity. This field is optional.
*   **Comments**: This field is used for any additional comments or notes about the activity. Enter any relevant information that may be helpful for future reference.

### Assigned Tool
If applicable, select the tool assigned for the maintenance activity. This field is optional.
*   **Assigned Tool**: This field is used to identify the tool or equipment used during the maintenance activity. Choose from the available options.

### Other Category
Enter any additional category information if "Other" is selected for Category. This field is optional.
*   **Other Category**: This field is used to provide additional category information if the category is "Other". Enter a brief description of the category.
