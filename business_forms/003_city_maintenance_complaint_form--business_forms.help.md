# City Maintenance Complaint Form - Help Guide
## Purpose
This form is designed to collect information about city maintenance complaints, allowing citizens to report issues such as potholes, broken streetlights, and overgrown vegetation. Your input helps city officials identify and address these problems.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Enter your full name as it appears on your official documents.
2.  Provide your email address for follow-up communications.
3.  Enter your phone number to ensure we can contact you about this issue.
4.  Describe the type of issue you are experiencing (e.g., pothole, broken streetlight).
5.  Provide a detailed description of the location and size of the issue.
6.  Specify the date when you first noticed the problem.
7.  Indicate whether the issue poses a safety risk.
8.  (Optional) Add any supporting information or photos that can help us identify the issue.
9.  If you have reported this issue before, please select "True". If you know the report number, you can enter it.
10.  Finally, you can provide any additional information that will help us address the issue.

## Field-by-Field Explanation

*   **Full Name**: This is your official name as it appears on your documents. Please enter it accurately.
*   **Email Address**: This will be used for follow-up communications about this issue.
*   **Phone Number**: Enter your phone number so we can contact you regarding this complaint.
*   **Type of Issue**: Select the category that best describes the problem you are experiencing.
*   **Location Description**: Provide a detailed description of where the issue is located, including street name, neighborhood, or any distinctive landmarks.
*   **Street Address**: If you know the street address of the issue, please enter it.
*   **Detailed Description of Issue**: Provide as much detail as possible about the problem, including its size and any other relevant information.
*   **Date Issue Was Observed**: Specify when you first noticed the issue.
*   **Does this pose a safety risk?**: If the issue poses a safety risk, select "Yes, high risk" or "Yes, moderate risk". If it is not a safety risk, select "No, minimal risk".
*   **Size of Affected Area**: If the issue is small, select the corresponding size category. If it is not small, select "Not sure" and provide more details in the "Detailed Description of Issue" field.
*   **Supporting Information**: You can attach photos or other documents that will help us identify the issue.
*   **Can you provide a photo of the issue?**: If you have a photo of the issue, please select "True". If not, select "False".
*   **Have you reported this issue before?**: If you have previously reported this issue, select "True". If you are not sure or this is a new report, select "Not sure" or "False".
*   **Previous Report Number**: If you know the report number of the previous report, enter it.
*   **Recommended Priority Level**: Select the urgency level of the issue, based on its severity and safety concerns.
*   **Any additional information**: Provide any other information that will help us address the issue.
