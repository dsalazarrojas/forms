# Custom Flyer Request Form - Help Guide
## Purpose
The Custom Flyer Request Form is designed to collect essential details from clients for a custom flyer project. This form ensures that we have all the necessary information to create a flyer that meets their specific needs and expectations.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the client's name in the `Client Name` field.
2. Enter the project name in the `Project Name` field.
3. Select the project type from the `Project Type` options (Design, Print).
4. Choose the project deadline by entering a date in the `Project Deadline` field.
5. Select the preferred color scheme from the `Color Scheme` options (Blue, Red, Green, Yellow).
6. Select the desired flyer size from the `Flyer Size` options (A3, A4, A5, Letter).
7. Choose the material type from the `Material Type` options (Paper, Vinyl, Plastic, Fabric).
8. Select the design style from the `Design Style` options (Modern, Traditional, Artistic, Minimal).
9. Upload a design file or provide a print file if necessary.
10. Enter the email address for contact purposes.
11. Enter the phone number for contact purposes.

## Field-by-Field Explanation
* **Client Name**: Enter the name of the client or the person requesting the custom flyer.
* **Project Name**: Enter a descriptive name for the project that will be used to create the custom flyer.
* **Project Type**: Select the type of project you require (Design or Print).
* **Project Deadline**: Enter the date by which the project must be completed.
* **Color Scheme**: Choose the preferred color scheme for the flyer (Blue, Red, Green, Yellow).
* **Flyer Size**: Select the size of the flyer (A3, A4, A5, Letter).
* **Material Type**: Choose the material type for the flyer (Paper, Vinyl, Plastic, Fabric).
* **Design Style**: Select the style of the design (Modern, Traditional, Artistic, Minimal).
* **Design File**: If you have a pre-made design file, upload it here.
* **Print File**: If you have a pre-made print file, upload it here.
* **Email**: Enter the email address that we can use to contact you about the project.
* **Phone**: Enter your phone number that we can use to contact you about the project.

## Tips
* Please provide accurate information to ensure that we can create a perfect custom flyer according to your requirements.
* Ensure that you upload all required files before submitting the form.
* If you have any questions or concerns, don't hesitate to reach out to us.
