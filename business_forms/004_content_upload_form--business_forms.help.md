# Content Upload Form - Help Guide
## Purpose
This form is used to collect information about an uploaded content file and its associated metadata.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your name and email address in the "Uploader Name" and "Email Address" fields respectively.
2. Select the category of the content from the "Content Category" dropdown list.
3. Enter the title and description of the content in the "Content Title" and "Content Description" fields respectively.
4. Provide a comma-separated list of keywords associated with the content in the "Content Tags" field.
5. Select the file format from the "File Format" dropdown list.
6. Enter the approximate size of the file in megabytes in the "File Size" field.
7. Specify who owns the rights to the content from the "Content Owner" dropdown list.
8. Select the usage permissions for the content from the "Usage Permissions" dropdown list.
9. Select the target audience for the content from the "Target Audience" dropdown list.
10. If applicable, enter the expiration date for the content in the "Expiration Date" field.
11. If applicable, enter a version number for the content in the "Version Number" field.
12. If applicable, enter a list of associated projects in the "Related Projects" field.
13. Specify the confidentiality level of the content from the "Confidentiality Level" dropdown list.
14. Enter any additional comments about the content in the "Additional Comments" field.

## Field-by-Field Explanation

* **Uploader Name** (text, required): Enter your full name.
* **Email Address** (email, required): Enter your email address.
* **Upload Date** (date, required): Enter the date when you uploaded the content.
* **Content Category** (select_one, required): Select the type of content (e.g. Video, Image, Document, etc.).
* **Content Title** (text, required): Enter a descriptive title for the content.
* **Content Description** (text, required): Enter a brief description of the content.
* **Content Tags** (text, optional): Enter a comma-separated list of keywords associated with the content.
* **File Format** (select_one, required): Select the format of the file (e.g. MP4, JPG, PDF, etc.).
* **File Size** (number, optional): Enter the approximate size of the file in megabytes.
* **Content Owner** (select_one, required): Specify who owns the rights to the content (e.g. I own the rights, My organization, etc.).
* **Usage Permissions** (select_multiple, required): Select the usage permissions for the content (e.g. Internal use only, Public website, etc.).
* **Target Audience** (select_one, optional): Select the target audience for the content (e.g. General Public, Customers, etc.).
* **Expiration Date** (date, optional): Enter the date when the content should expire.
* **Version Number** (text, optional): Enter a version number for the content.
* **Related Projects** (text, optional): Enter a list of associated projects.
* **Confidentiality Level** (select_one, required): Specify the confidentiality level of the content (e.g. Public, Internal, etc.).
* **Additional Comments** (text, optional): Enter any additional comments about the content.
