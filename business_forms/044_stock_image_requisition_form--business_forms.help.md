# Stock Image Requisition Form - Help Guide
## Purpose
The Stock Image Requisition Form is used to create a new stock image requisition request for a project.

## How To Complete This Form
1. Review the form carefully and ensure you have all the necessary project information ready.
2. Complete all required fields, indicated by * (required fields are project_name, project_type, and project_status).
3. Fill in the project information, including the project name, type, status, and deadline.
4. Add a brief description of the required fields, which will help us understand your project better.
5. Select relevant tags for the image requisition.
6. Choose the correct project status and deadline.
7. Finally, fill in any additional information or notes about the project.
8. Click the submit button to create the requisition request.

## Field-by-Field Explanation
* **Project Name** (project_name, text, required): Enter the name of the project for which you are requesting the stock image.
* **Project Type** (project_type, select_one, required): Select the type of project for which you are requesting the stock image. This will help us understand the project's requirements and scope.
* **Project Status** (project_status, select_one, required): Choose the current status of the project, which will help us prioritize the requisition request.
* **Project Deadline** (project_deadline, date, required): Enter the expected deadline for the project, which will help us schedule the image requisition accordingly.
* **Image Description** (image_description, text, optional): Provide a brief description of the image requisition, including any specific requirements or expectations.
* **Tags** (image_tags, select_multiple, optional): Select relevant tags for the image requisition, which will help us narrow down the search results.
* **Required Fields** (required_fields, select_one, optional): Choose which specific fields are required for the project. This will help us understand the project's requirements and scope.
* **Additional Information** (additional_info, text, optional): Fill in any additional information or notes about the project that you think will help us better understand it.
* **Project Budget** (project_budget, number, optional): Enter the project budget, if applicable.
* **Project Type** (project_type, select_one, optional): Note: This field is a duplication of project_type above, but was included to accommodate the original form schema. Please ensure you only fill in one of these fields. 

Note: The project_type and project_type fields are duplicates. Please ensure that one of these fields is filled in, but not both, to avoid confusion.
