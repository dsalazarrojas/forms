# Project Information Form - Help Guide
## Purpose
This form is designed to collect and store project information, including project name, description, status, priority, start and end dates, budget, location, project manager's email and phone number, and team members.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the project name in the "Project Name" field.
2. Provide a brief description of the project in the "Project Description" field.
3. Select the project status from the "Project Status" dropdown menu.
4. Choose the project priority from the "Project Priority" dropdown menu.
5. Enter the project start and end dates in the "Project Start Date" and "Project End Date" fields, respectively.
6. Enter the project deadline in the "Project Deadline" field.
7. Enter the project budget.
8. Enter the project location.
9. Enter the project manager's email in the "Project Manager E-mail" field.
10. Enter the project manager's phone number in the "Project Manager Phone" field.
11. Select the team members from the "Team Members" dropdown menu.

## Field-by-Field Explanation
- **Project Name** (text, required/optional): Enter the name of the project.
- **Project Description** (text, required/optional): Enter a brief description of the project.
- **Project Manager Name** (text, required/optional): Enter the name of the project manager.
- **Project Status** (select one, required/optional): Select the current status of the project from the dropdown menu:
	* New
	* Ongoing
	* Completed
- **Project Priority** (select multiple, required/optional): Select the priority level of the project from the dropdown menu:
	* High
	* Medium
	* Low
- **Project Start Date** (date, required/optional): Enter the start date of the project.
- **Project End Date** (date, required/optional): Enter the end date of the project.
- **Project Deadline** (date, required/optional): Enter the deadline for the project.
- **Project Budget** (number, required/optional): Enter the budget for the project.
- **Project Location** (text, required/optional): Enter the location where the project will be executed.
- **Project Manager E-mail** (email, required/optional): Enter the email address of the project manager.
- **Project Manager Phone** (text, required/optional): Enter the phone number of the project manager.
- **Team Members** (select multiple, required/optional): Select the team members involved in the project from the dropdown menu:
	* Team Member 1
	* Team Member 2
	* Team Member 3

## Tips
- Double-check the project status and priority to ensure accuracy.
- Enter the correct dates and deadlines for the project.
- Ensure that the project budget and location are accurate.
- Make sure that the project manager's email and phone number are up-to-date.
- Select the correct team members involved in the project.
