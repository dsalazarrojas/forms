# File Attachment Form - Help Guide
## Purpose
The File Attachment Form is a simple form designed to collect multiple files from users. It is meant to be a straightforward and easy-to-use form for uploading files related to a specific topic or theme.

## How to Complete This Form
To complete this form, simply follow these steps:

1. Click on the "File 1" field on the first page and select the file you want to upload.
2. Click on the "File 2" field on the second page and select the file you want to upload.
3. Click on the "File 3" field on the third page and select the file you want to upload.
4. Repeat the process for each page until you have uploaded all the files you need to attach.

## Field-by-Field Explanation
### File 1
* **File 1 (Page 1)** (`file_attachment_form_page_1`, text, optional): Attach your first file to this field. This is where you can upload your first file related to the topic or theme.

### File 2
* **File 2 (Page 2)** (`file_attachment_form_page_2`, text, optional): Attach your second file to this field. This is where you can upload your second file related to the topic or theme.

### File 3
* **File 3 (Page 3)** (`file_attachment_form_page_3`, text, optional): Attach your third file to this field. This is where you can upload your last file related to the topic or theme.

## Tips
* Make sure to attach files that are relevant to the topic or theme.
* Only attach files that are not excessively large.
* Ensure that the files are in a format that can be opened by the recipient.
* If you are unsure about any of the files you are attaching, please contact [form@gic.mx](mailto:form@gic.mx) for assistance.
