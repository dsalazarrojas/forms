# Network Development Onboarding Form - Help Guide
## Purpose
This form is designed to collect information about network development projects, including project name, lead, description, start and end dates, and project lead's email. The form is intended to be used for onboarding new projects within a network development context, and to ensure that all necessary details are captured for further analysis and processing.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name in the first field.
2. Provide the name and email address of the project lead in the second and third fields, respectively.
3. Briefly describe the project in the fourth field.
4. Enter the start and end dates of the project in the fifth and sixth fields, respectively.
5. Ensure that all fields are filled in accurately and completely, as this information will be used for further processing and analysis.

## Field-by-Field Explanation
* **Project Name**: Enter the name of the project. This field is optional.
* **Project Lead**: Enter the name of the person leading the project.
* **Project description**: Briefly describe the network development project in this field.
* **Start Date**: Enter the start date of the project in the correct format (dd/mm/yyyy).
* **End Date**: Enter the end date of the project in the correct format (dd/mm/yyyy).
* **Project Lead Email**: Enter the email address of the project lead. This field is optional.
