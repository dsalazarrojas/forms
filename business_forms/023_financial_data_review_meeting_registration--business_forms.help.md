# financial_data_review_meeting_registration - Help Guide
## Purpose
The "financial_data_review_meeting_registration" form is a tool used to register and collect data for financial review meetings. It is designed to provide accurate and detailed information about the meeting, including session topic, meeting date, start time, location, attendees, session duration, and other essential details.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the correct session topic for the meeting from the list of options.
2.  Enter the meeting date in the format `YYYY-MM-DD` (e.g., `2022-01-01`).
3.  Choose the meeting start time using the 24-hour format `HH:MM` (e.g., `13:30`).
4.  Select the correct meeting location from the available options.
5.  Enter a list of attendees with their names and emails separated by commas.
6.  Enter the session duration in minutes.
7.  Select the meeting start time from the options provided.
8.  Enter the end time of the meeting in the format `HH:MM`.

## Field-by-Field Explanation

* **Session Topic** (`Session Topic`, `select_one`, required): Select the topic of the session.
* **Meeting Date** (`Meeting Date`, `date`, required): Enter the date of the meeting in the format `YYYY-MM-DD`.
* **Meeting Start Time** (`Meeting Start Time`, `time`, required): Choose the start time of the meeting using the 24-hour format `HH:MM`.
* **Meeting Location** (`Meeting Location`, `select_multiple`, required): Select the location of the meeting from the options provided.
* **Attendees** (`Attendees`, `text`, required): Enter a list of attendees with their names and emails separated by commas.
* **Session Duration** (`Session Duration`, `number`, required): Enter the duration of the session in minutes.
* **Meeting Start Time** (`Meeting Start Time`, `select_one`, required): Select the start time of the meeting from the provided options.
* **Meeting End** (`Meeting End`, `time`, required): Enter the end time of the meeting in the format `HH:MM`.

## Tips

*   Ensure all fields are filled accurately to prevent errors.
*   Use commas to separate multiple attendees' names and emails.
*   Enter the session duration in minutes.
*   Use the 24-hour format for start and end times.
*   Review the form carefully before submitting to avoid any mistakes.
