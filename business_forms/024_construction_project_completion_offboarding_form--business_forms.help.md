# Construction Project Completion Offboarding Form - Help Guide
## Purpose
The Construction Project Completion Offboarding Form is a comprehensive guide that ensures all necessary steps for offboarding a construction project are properly completed and documented.

## How To Complete This Form
1. Fill out the form carefully, ensuring all required fields are completed.
2. Review each section for completeness and accuracy.
3. Submit the form to the authorized personnel for review and validation.

## Field-by-Field Explanation

* **Full Project Name** (`project_name`): The official name of the project being offboarded.
* **Project ID or Contract Number** (`project_id`): A unique identifier or contract number associated with the project.
* **Official Project/Contract End Date** (`contract_end_date`): The date when the project officially ended.
* **Lead Offboarding Manager (Name and Title)** (`lead_offboarding_manager`): The person responsible for overseeing the offboarding process.
* **Final As-built Drawings Submitted** (`as_built_drawings_submitted`): Confirm if the final as-built drawings have been submitted.
* **Operations and Maintenance (O&M) Manuals Handover** (`warranty_manuals_handover`): Confirm if the O&M manuals have been handed over.
* **Final Lien Waivers Collected** (`lien_waivers_collected`): Confirm if all lien waivers have been collected from subcontractors.
* **Final Certificate of Occupancy (C of O) Obtained** (`certificate_of_occupancy_obtained`): Confirm if the final C of O has been obtained.
* **All Site Waste and Debris Removed** (`site_waste_removed`): Confirm if all site waste and debris have been removed.
* **All Rental Equipment Returned/Off-rented** (`rentals_returned_checklist`): Confirm if all rental equipment has been returned or off-rented.
* **All Site Keys and Access Cards Returned** (`site_keys_handover`): Confirm if all site keys and access cards have been returned.
* **Final Billing/Invoice Submitted** (`final_billing_submitted`): Confirm if the final progress billing/invoice has been submitted.
* **Retainage Release Request Submitted** (`retainage_release_requested`): Confirm if the retainage release request has been submitted.
* **Primary Success Factor for this Project** (`primary_success_factor`): A brief description of what went well during the project.
* **Biggest Lesson Learned for Future Projects** (`biggest_lesson_learned`): A brief reflection on what can be improved for future projects.
* **Interest in the Next Phase or Similar Future Projects** (`next_project_interest`): A confirmation if you're interested in the next phase or similar projects.
* **Date of Offboarding Completion** (`submission_date`): The date when the offboarding process is completed.
* **Authorized By (Name)** (`offboarding_officer_signature_label`): The signature of the authorized person completing the form.
