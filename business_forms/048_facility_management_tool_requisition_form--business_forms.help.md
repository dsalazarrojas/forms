# Facility Management Tool Requisition Form - Help Guide
## Purpose
This form is used to request and manage facility management tools. It is designed to help facility management staff to efficiently process and track tool requests, maintenance, and reviews. To ensure accuracy and completeness, please review the form carefully before submission.

## How To Complete This Form
1. Choose the correct option for "First page fields" to indicate the purpose of the request (Equipment Request, Tool Request Details, or Maintenance Request).
2. Select the tools required from the list for "Tool Requested" field.
3. On the second page, choose the type of review required (Tool Review, Technical Review, or Other Review).
4. Select the specific review options for "Tool Review", "Technical Review", or "Other Review" fields.
5. Enter any additional comments or review notes in the "Review notes" fields.
6. Fill out your submission and review details (name, email, date, and time).
7. Select the submission and review status (Approved, Pending, or Rejected).

## Field-by-Field Explanation

* **Submission**: This is the email address to which the submission will be sent. Please enter a valid email address to which you want to receive updates on the status of your request. (Required)
* **Comments**: A text field for you to enter any additional comments or notes for the reviewer to consider. (Required)
* **Tool Requested**: A list of available tools from which you can select the ones you want to request. Please note that you can select more than one tool. 
* **Tool Review**: A selection of review options for tools. Please note that you can select more than one review option. 
* **Technical Review**: A selection of review options for technical aspects. Please note that you can select more than one review option. 
* **Technical Support**: A selection of support options for technical matters. Please note that you can select more than one support option. 
* **Review notes**: A text field for the reviewer to enter any additional review notes. (Required)
* **Submission date** and **Submission time**: These fields are automatically filled in when you submit the form. You do not need to fill them out.
* **Review date** and **Review time**: These fields are automatically filled in when the review is completed. You do not need to fill them out.
* **Reviewer**: A list of reviewers from which you can select the one who will review your request. Please note that you can select more than one reviewer. 
* **Review notes**: A text field for the reviewer to enter any additional review notes. (Required)
* **Status**: A list of status options (Approved, Pending, or Rejected) to indicate the current status of your request. Please note that you can select more than one status. 
* **Submitter**: A list of submitters from which you can select the one who submitted the request. Please note that you can select more than one submitter. 
* **Tool Review, Technical Review, Other Review**: These are selection fields for the type of review required. Please note that you can select more than one review option. 
* **Review notes**: A text field for the reviewer to enter any additional review notes. (Required)
