# Resource Management Checklist - Help Guide
## Purpose
The Resource Management Checklist is a form used to track and report on resource status and allocation within a project. This form gathers information about project names, status, resource names, types, and other relevant details for resource management purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the project name in the "Project Name" field.
2.  Select the project status from the "Project Status" dropdown menu.
3.  Enter the resource name in the "Resource Name" field.
4.  Select the resource type from the "Resource Type" dropdown menu.
5.  Choose the resource status from the "Resource Status" dropdown menu.
6.  Select the resource level from the "Resource Level" dropdown menu (multiple selections are allowed).
7.  Indicate if the resource has priority by selecting "Yes" or "No" from the "Priority" dropdown menu.
8.  Enter the date the resource was allocated in the "Allocated Date" field.
9.  Enter the time the resource was allocated in the "Allocated Time" field.
10. Enter the resource's availability as a number in the "Resource Availability" field.
11. Enter the resource's utilization as a number in the "Resource Utilization" field.
12. Add any notes about the resource in the "Notes" field.
13. Enter the resource's email address in the "Email" field.
14. Enter the resource's phone number in the "Phone" field.
15. Indicate if the resource is assigned to a user by selecting "Yes" or "No" from the "Assigned User" dropdown menu.
16. Enter the date the resource was assigned to a user in the "Assigned Date" field.
17. Indicate if the resource is managed by a resource manager by selecting "Yes" or "No" from the "Resource Manager" dropdown menu.

## Field-by-Field Explanation

* **Project Name** (1, text, required/optional): Enter the name of the project this resource belongs to.
* **Project Status** (2, select_one, required/optional): Select the current status of the project.
* **Resource Name** (3, text, required/optional): Enter the name of the resource being managed.
* **Resource Type** (4, select_one, required/optional): Select the type of resource being managed.
* **Resource Status** (5, select_one, required/optional): Select the status of the resource.
* **Resource Level** (6, select_multiple, required/optional): Select the level of the resource (multiple selections are allowed).
* **Priority** (7, select_one, required/optional): Indicate if the resource has priority by selecting "Yes" or "No".
* **Allocated Date** (8, date, required/optional): Enter the date the resource was allocated.
* **Allocated Time** (9, time, required/optional): Enter the time the resource was allocated.
* **Resource Availability** (10, number, required/optional): Enter the resource's availability as a number.
* **Resource Utilization** (11, number, required/optional): Enter the resource's utilization as a number.
* **Notes** (12, note, required/optional): Enter any notes about the resource.
* **Email** (13, email, required/optional): Enter the resource's email address.
* **Phone** (14, text, required/optional): Enter the resource's phone number.
* **Assigned User** (15, select_one, required/optional): Indicate if the resource is assigned to a user by selecting "Yes" or "No".
* **Assigned Date** (16, date, required/optional): Enter the date the resource was assigned to a user.
* **Resource Manager** (17, select_one, required/optional): Indicate if the resource is managed by a resource manager by selecting "Yes" or "No".
