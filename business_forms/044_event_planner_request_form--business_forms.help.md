# Event Planner Request Form - Help Guide

## Purpose
This form is designed to collect event-related information from users, helping event planners organize and manage upcoming events. Please review each field carefully to ensure accurate and efficient data collection.

## How To Complete This Form

To complete this form, follow these steps:

1. Start by filling out the form with the requested information.
2. Review each field to ensure you have provided accurate and complete data.
3. Submit the form once you have filled out all the required fields.

## Field-by-Field Explanation

### 1. Event Planner Request Form

* **event name** (`event_name`, text, optional): Enter the name of the event you are planning.
* **event date** (`event_date`, date, optional): Enter the date of the event.
* **event time** (`event_time`, time, optional): Enter the time of the event.
* **event location** (`event_location`, text, optional): Enter the location of the event.
* **event organizer** (`event_organizer`, text, optional): Enter the name of the event organizer.
* **event type** (`event_type`, text, optional): Enter the type of event (e.g., conference, workshop, meeting, etc.).
* **event details** (`event_details`, text, optional): Enter any additional details about the event.
* **vendor name** (`vendor_name`, text, optional): Enter the name of the vendor or company related to the event (if applicable).

## Tips

* Be as accurate and thorough as possible when filling out the form.
* Ensure you have provided all required information for the event planner.
* If you have any questions or concerns, please contact us at form@gic.mx.
* You can modify this form as needed to fit your specific event planning needs.
