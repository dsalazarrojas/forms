# Procurement Vendor Change Request Form - Help Guide
## Purpose
The Procurement Vendor Change Request Form is used to request changes to existing vendors. This form captures necessary information for the procurement team to review and process vendor changes efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your User ID.
2. Provide the current vendor's name and status (active or inactive).
3. Specify the reason for the change.
4. If applicable, enter the proposed new vendor ID and name.
5. Provide the proposed new vendor status (active or inactive).
6. Select the reason for the change date and time (in the format YYYY-MM-DD and HH:MM:SS respectively).
7. Enter any additional comments or notes about the request.
8. Review and submit the form.

## Field-by-Field Explanation
- **User ID** (`user_id`, `number`, required: false): Please enter your User ID to identify you as the requester.
- **Vendor Name** (`vendor_name`, `text`, required: false): Enter the current vendor's name that needs to be changed.
- **Vendor Status** (`vendor_status`, `select_one`, required: false): Select the current status of the vendor (active or inactive).
- **Reason for Change** (`reason_for_change`, `text`, required: false): Specify the reason why the change is necessary.
- **Proposed New Vendor ID** (`proposed_new_vendor_id`, `number`, required: false): If applicable, enter the proposed new vendor ID.
- **Proposed New Vendor Name** (`proposed_new_vendor_name`, `text`, required: false): If applicable, enter the proposed new vendor name.
- **Reason for Change Date** (`reason_for_change_date`, `date`, required: false): Select the date of the reason for the change (in the format YYYY-MM-DD).
- **Reason for Change Time** (`reason_for_change_time`, `time`, required: false): Select the time of the reason for the change (in the format HH:MM:SS).
- **Comment** (`comment`, `text`, required: false): Enter any additional comments or notes about the request.

## Tips
* Ensure that the form is filled out correctly and completely to avoid delays in processing.
* Review your submission before submitting to ensure that all necessary information is provided.
* If you are unsure about any part of the form, please contact the procurement team for assistance.
