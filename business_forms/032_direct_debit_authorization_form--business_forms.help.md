# direct_debit_authorization_form - Help Guide
## Purpose
The direct_debit_authorization_form is a form used to obtain authorization for direct debit transactions on a customer's account.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
* **Company Name** (`1`, `text`, required): Enter the name of your company.
* **Company Address** (`2`, `text`, required): Enter your company's address.
* **Authorized Person** (`3`, `text`, required): Enter the name of the authorized person.
* **Phone Number** (`4`, `text`, required): Enter the authorized person's phone number.
* **Email** (`5`, `email`, required): Enter the authorized person's email.
* **Billing Name** (`6`, `text`, optional): Enter the billing name if different from the company name.
* **Billing Address** (`7`, `text`, required): Enter the billing address if different from the company address.
* **Bank Name** (`8`, `text`, required): Enter the bank name.
* **Bank BIC** (`9`, `text`, required): Enter the BIC of the bank.
* **IBAN** (`10`, `text`, required): Enter the IBAN of the account.
* **Account Number** (`11`, `number`, required): Enter the account number.
* **Sort Code** (`12`, `text`, required): Enter the sort code of the account.
* **Account Holder** (`13`, `text`, required): Enter the name of the account holder.
* **Direct Debit** (`14`, `select_one`, required): Choose the type of direct debit (Direct Debit, Credit, Debit, Cheque).
* **Frequency** (`15`, `select_multiple`, required): Select all frequencies that apply (Daily, Weekly, etc.).
* **Amount** (`16`, `number`, required): Enter the amount to be debited.
* **Start Date** (`17`, `date`, optional): Enter the start date if required.
* **End Date** (`18`, `date`, optional): Enter the end date if required.
* **Frequency Start Date** (`19`, `date`, optional): Enter the frequency start date if required.
* **Frequency End Date** (`20`, `date`, optional): Enter the frequency end date if required.
* **BIC/IBAN** (`21`, `text`, optional): Enter the BIC/IBAN if required.
* **BIC (2)** (`22`, `text`, optional): Enter the BIC if required.
* **Iban 2** (`23`, `text`, optional): Enter the IBAN 2 if required.
* **Account Number 2** (`24`, `number`, optional): Enter the account number 2 if required.
* **Sort Code 2** (`25`, `text`, optional): Enter the sort code 2 if required.
