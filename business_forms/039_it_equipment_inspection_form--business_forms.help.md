# it_equipment_inspection_form - Help Guide
## Purpose
The it_equipment_inspection_form is designed to collect information about the inspection status of equipment within the organization.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the name of the equipment being inspected.
2. Choose the type of equipment being inspected.
3. Specify the location of the equipment being inspected.
4. Select all applicable issues regarding the hardware condition (Good, Fair, Critical, Needs Repair).
5. Choose the software condition (Good, Fair, Critical, Needs Update) if applicable.
6. Provide a description of any issues or problems detected during the inspection.
7. Select the current status of the equipment (Active, Inactive, Decommissioned).
8. Optionally, enter the frequency of maintenance required for the equipment.
9. If necessary, specify the next scheduled maintenance date.
10. Add any additional comments or notes regarding the equipment.

## Field-by-Field Explanation

### 1. Equipment Name (`Equipment Name`, Text, Required)
Enter the name of the equipment being inspected.

### 2. Equipment Type (`Equipment Type`, Text, Required)
Choose the type of equipment being inspected.

### 3. Location (`Location`, Text, Required)
Enter the location of the equipment being inspected.

### 4. Hardware Condition (`Hardware Condition`, Select Multiple, Required)
Select all applicable issues regarding the hardware condition:

* Good: The equipment is in good condition.
* Fair: The equipment has some minor issues but is still functional.
* Critical: The equipment is non-functional or in critical condition.
* Needs Repair: The equipment requires immediate attention and repair.

### 5. Software Condition (`Software Condition`, Select One, Optional)
Choose the software condition if applicable. If not applicable, skip this field.

* Good: The software is up-to-date and functioning properly.
* Fair: The software has some minor issues but is still functional.
* Critical: The software is non-functional or critical.
* Needs Update: The software requires an update or upgrade.

### 6. Issue Description (`Issue Description`, Text, Required)
Provide a detailed description of any issues or problems detected during the inspection.

### 7. Equipment Status (`Equipment Status`, Select One, Required)
Select the current status of the equipment:

* Active: The equipment is currently in use and functional.
* Inactive: The equipment is not currently in use but still maintained.
* Decommissioned: The equipment is no longer in use and not maintained.

### 8. Maintenance Frequency (`Maintenance Frequency`, Number, Optional)
Enter the frequency of maintenance required for the equipment (e.g., weekly, monthly, etc.).

### 9. Next Maintenance (`Next Maintenance`, Date, Optional)
Specify the next scheduled maintenance date if applicable.

### 10. Comments (`Comments`, Text, Optional)
Add any additional comments or notes regarding the equipment.
