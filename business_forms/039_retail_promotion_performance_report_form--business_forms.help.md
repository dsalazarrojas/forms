# Retail Promotion Performance Report Form - Help Guide
## Purpose
This form is used to collect data on the performance of retail promotions, including campaign results, budget, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `Campaign Name` field with the name of the campaign you are reporting on.
2. Enter the `Promotion Name` field with the name of the promotion within the campaign.
3. Select the `Promotion Type` from the available options (e.g., "Discount", "Free Gift", etc.).
4. Enter the `Budget` field with the actual budget spent on the campaign or promotion.
5. Enter the `Actual Budget` field with the actual budget spent on the campaign or promotion.
6. Enter the `Target Budget` field with the target budget set for the campaign or promotion.
7. Select the `Results` field with the overall result of the campaign or promotion (e.g., "Yes", "No").
8. Select the `Result Type` field with the type of result achieved (e.g., "Yes", "No").
9. Select the `Result Value` field with the value of the result achieved (e.g., "Yes", "No").
10. Enter the `Campaign Start Date` field with the start date of the campaign.
11. Enter the `Campaign End Date` field with the end date of the campaign.
12. Enter the `Campaign Duration` field with the duration of the campaign.
13. Select the `Total Budget` field with the total budget classification (e.g., "Low", "Medium", "High").
14. Select the `Promotion Duration` field with the duration of the promotion.

## Field-by-Field Explanation
* **Campaign Results** (`campaign_results`): A text field to enter the overall results of the campaign or promotion.
* **Campaign Name** (`campaign_name`): A text field to enter the name of the campaign.
* **Promotion Name** (`promotion_name`): A text field to enter the name of the promotion within the campaign.
* **Promotion Type** (`promotion_type`): A field to select the type of promotion (e.g., "Discount", "Free Gift", etc.).
* **Budget** (`budget`): A numeric field to enter the actual budget spent on the campaign or promotion.
* **Actual Budget** (`actual_budget`): A numeric field to enter the actual budget spent on the campaign or promotion.
* **Target Budget** (`target_budget`): A numeric field to enter the target budget set for the campaign or promotion.
* **Results** (`results`): A field to select the overall result of the campaign or promotion (e.g., "Yes", "No").
* **Result Type** (`result_type`): A field to select the type of result achieved (e.g., "Yes", "No").
* **Result Value** (`result_value`): A field to select the value of the result achieved (e.g., "Yes", "No").
* **Campaign Start Date** (`campaign_start_date`): A date field to enter the start date of the campaign.
* **Campaign End Date** (`campaign_end_date`): A date field to enter the end date of the campaign.
* **Campaign Duration** (`campaign_duration`): A field to enter the duration of the campaign.
* **Total Budget** (`total_budget`): A field to select the total budget classification (e.g., "Low", "Medium", "High").
* **Promotion Duration** (`promotion_duration`): A field to select the duration of the promotion.
