## How To Complete This Form

### 1. Production Plan
* **production plan** (production plan, text, optional): Provide details about the production process and any relevant information.

### 2. Inspection Schedule
* **inspection schedule** (inspection schedule, date, required): Enter the date of the inspection.

### 3. Inspector Notes
* **inspector notes** (inspector notes, text, optional): Provide any comments or observations about the inspection process.

### 4. Defect List
* **defect list** (defect list, select multiple, required): Select all defects found during the inspection from the dropdown menu.

### 5. Action Plan
* **action plan** (action plan, text, optional): Outline steps to rectify defects or issues found during the inspection.

### 6. Corrective Action Taken
* **corrective action taken** (corrective action taken, select one, required): Select if corrective action has been taken, and no otherwise.

### 7. Production Status
* **production status** (production status, select one, required): Choose whether the production is `Active` or `Inactive`.

### 8. Production Date
* **production date** (production date, date, required): Enter the production date.

### 9. Inspection Frequency
* **inspection frequency** (inspection frequency, select one, required): Select whether the inspection is scheduled to be performed `Yes` or `No`.

### 10. Production Frequency
* **production frequency** (production frequency, select one, required): Choose whether the production is `Yes` or `No`.

### 11. Inspection Interval
* **inspection interval** (inspection interval, text, optional): Provide details about the inspection frequency.

### 12. Production Interval
* **production interval** (production interval, text, optional): Provide details about the production frequency.

### 13. Inspection Status
* **inspection status** (inspection status, select one, required): Select whether the inspection is `Active` or `Inactive`.

### 14. Production Status
* **production status** (production status, select one, required): Choose whether the production is `Active` or `Inactive`.

### 15. Comments
* **comments** (comments, text, optional): Provide any additional comments or feedback.

### 16. Next Inspection Due Date
* **next inspection due date** (next inspection due date, date, optional): Enter the date of the next inspection.

### 17. Next Inspection Due Time
* **next inspection due time** (next inspection due time, time, optional): Enter the time of the next inspection.

### 18. Previous Inspection Results
* **previous inspection results** (previous inspection results, text, optional): Provide any previous inspection results.

### 19. Previous Actions Taken
* **previous actions taken** (previous actions taken, text, optional): Provide any actions taken in the previous inspections.

### 20. Certification Date
* **certification date** (certification date, date, optional): Enter the certification date.

### 21. Production Lot
* **production lot** (production lot, text, optional): Enter the production lot number.

### 22. Inspection Location
* **inspection location** (inspection location, text, optional): Enter the location of the inspection.

### 23. Inspector Name
* **inspector name** (inspector name, text, optional): Enter the name of the inspector.

### 24. Inspector ID
* **inspector id** (inspector id, text, optional): Enter the ID of the inspector.

### 25. Certification Status
* **certification status** (certification status, select one, required): Select whether the certification is `Active` or `Inactive`.

## Tips
* Ensure that all fields are filled in accurately and thoroughly.
* Refer to this help guide for assistance if you are unsure about any field.
* Complete all required fields for a smooth and efficient inspection process.
* Review and revise your answers before submitting the form.
