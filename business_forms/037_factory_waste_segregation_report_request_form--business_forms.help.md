# Factory Waste Segregation Report Request Form - Help Guide
## Purpose
This form is used to report waste segregation incidents that occur during factory shifts. It helps management keep track of and address these incidents, ensuring a clean and efficient working environment.

## How To Complete This Form

1. Fill in your User Email address to receive follow-up notifications about your submitted reports.
2. Provide the Report Date on which the waste segregation incident occurred.
3. Enter the Shift Start and Shift End times to indicate the duration of your shift.
4. Enter the Machine ID number of the machine involved in the incident.
5. Check 'Yes' if the incident resulted in waste segregation; otherwise, select 'No'.
6. Select all relevant Waste Types that were involved in the incident (e.g., Paper, Plastic, Glass).
7. Add any additional Remarks (optional).
8. If you'd like to record the name of the person who submitted this report and the date it was submitted, you can fill in the Submitted By and Submitted On fields, but they are not required.
9. Similarly, if you'd like to add the name of the person who approved this report and the date it was approved, you can fill in the Approved By field but it's not required.

## Field-by-Field Explanation

* **User Email (Email, Required)**: Enter your email address to receive notifications about your submitted reports.
* **Report Date (Date, Required)**: The date on which the waste segregation incident occurred.
* **Shift Start (Time, Required)**: The start time of your shift.
* **Shift End (Time, Required)**: The end time of your shift.
* **Machine ID (Number, Required)**: The ID number of the machine involved in the incident.
* **Waste Code (Select One, Required)**: Check 'Yes' if the incident resulted in waste segregation; otherwise, select 'No'.
* **Waste Type (Select Multiple, Required)**: Select all relevant waste types involved in the incident (e.g., Paper, Plastic, Glass).
* **Remarks (Note, Optional)**: Add any additional comments or details about the incident.
* **Submitted By (Text, Optional)**: If you'd like to record the name of the person who submitted this report.
* **Submitted On (Date, Optional)**: The date you submitted this report.
* **Approved By (Text, Optional)**: If you'd like to add the name of the person who approved this report.
* **Proctor (Text, Optional)**: This field is not currently used in the form; it's likely a placeholder for future development.

# Tips

* Ensure you fill out the form accurately and completely to help management address potential waste management issues promptly.
* If you're unsure about any field, refer to your supervisor or colleague for guidance.
* Review and submit the form carefully before saving it to avoid errors.
