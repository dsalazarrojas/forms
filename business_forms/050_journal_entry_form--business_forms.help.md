# Journal Entry Form - Help Guide
## Purpose
The Journal Entry Form is designed to collect and document patient care information from healthcare providers. It captures essential details about patient visits, including medical practices, billing status, and other relevant information.

## How To Complete This Form

1. Start by selecting the relevant options for the medical practice and insurance provider.
2. Enter the patient's ID, medical record number, and billing status.
3. Record the start and stop dates of the visit.
4. Provide details about the visit, such as the reason for the visit and any visit details.
5. Select the assigned tool used during the visit.
6. Enter any relevant notes, comments, and patient condition information.
7. Select the billing status ID.
8. Enter the patient's name.
9. Add any additional comments or notes.

## Field-by-Field Explanation

* **journal_entry_form** (Text, Optional)
	+ This field is the title of the form and is meant to be filled in with a brief description of the form's purpose.
* **medical_practice** (Text, Optional)
	+ This field is for the medical practice information, which should be filled in with the relevant details.
* **patient_id** (Number, Optional)
	+ This field is for the patient's ID number, which should be entered to identify the patient.
* **medical_record_number** (Text, Optional)
	+ This field is for the patient's medical record number, which should be entered to track the patient's medical history.
* **start_date** (Date, Optional)
	+ This field is for the start date of the visit, which should be entered in the correct date format.
* **stop_date** (Date, Optional)
	+ This field is for the stop date of the visit, which should be entered in the correct date format.
* **reason_for_visit** (Text, Optional)
	+ This field is for the reason for the visit, which should be filled in with a brief description of the visit's purpose.
* **visit_details** (Note, Optional)
	+ This field is for any additional details about the visit, which can be filled in with free text.
* **billing_status** (Select One, Optional)
	+ This field is for the billing status of the visit, which should be selected from the provided options.
* **insurance_provider** (Select Multiple, Optional)
	+ This field is for the insurance provider information, which should be selected from the provided options.
* **assigned_tool** (Select One, Optional)
	+ This field is for the assigned tool used during the visit, which should be selected from the provided options.
* **user_id** (Number, Optional)
	+ This field is for the user's ID number, which should be entered to track the user's activity.
* **journal_entry_date** (Date, Optional)
	+ This field is for the journal entry date, which should be entered in the correct date format.
* **journal_entry_time** (Time, Optional)
	+ This field is for the journal entry time, which should be entered in the correct time format.
* **created_by** (Select Multiple, Optional)
	+ This field is for the created by information, which should be selected from the provided options.
* **created_date** (Date, Optional)
	+ This field is for the created date, which should be entered in the correct date format.
* **last_updated** (Date, Optional)
	+ This field is for the last updated date, which should be entered in the correct date format.
* **journal_entry_id** (Number, Optional)
	+ This field is for the journal entry ID number, which should be entered to track the journal entry.
* **journal_entry_status** (Select One, Optional)
	+ This field is for the journal entry status, which should be selected from the provided options.
* **user_name** (Text, Optional)
	+ This field is for the user's name, which should be filled in with the relevant details.
* **notes** (Note, Optional)
	+ This field is for any additional notes, which can be filled in with free text.
* **comments** (Text, Optional)
	+ This field is for any comments, which should be filled in with relevant information.
* **patient_condition** (Text, Optional)
	+ This field is for the patient's condition, which should be filled in with the relevant details.
* **billing_status_id** (Select One, Optional)
	+ This field is for the billing status ID, which should be selected from the provided options.
* **patient_name** (Text, Optional)
	+ This field is for the patient's name, which should be filled in with the relevant details.

## Tips

* Make sure to fill in all required fields accurately and consistently.
* Use the correct date and time formats for date and time fields.
* Select relevant options for insurance provider and assigned tool fields.
* Double-check the billing status and journal entry status for accuracy.
* Save the form regularly to avoid losing any entered information.
