# Sustaining Capex Expression Of Interest - Help Guide
## Purpose
This form is for submitting project ideas, justifications, and budget information for potential investments within the business. It's a means to propose new projects or initiatives that can benefit the company.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of your project idea in the **project_idea** field.
2. Provide a justification for the project in the **justification** field.
3. Select the relevant department from the **department** field.
4. Choose the business case or reason for the project from the **business_case** field.
5. Select the cost centre or area affected by the project from the **cost_centre** field.
6. Choose the project team or members responsible for the project from the **project_team** field.
7. Select the location where the project will be carried out from the **project_location** field.
8. Choose the status of the project from the **project_status** field.
9. Select the budget category or type for the project from the **budget_category** field.
10. Enter a note for project justification if necessary.
11. Choose the project rationale or reason for the project from the **project_rationale** field.

## Field-by-Field Explanation

* **project_idea** (text): Brief description of the project idea.
* **budget** (number): Proposed budget for the project.
* **justification** (note): Additional justification or explanation for the project.
* **department** (select_one): Select the department responsible for the project.
* **business_case** (select_multiple): Choose the business case or reason for the project.
* **cost_centre** (select_one): Select the cost centre or area affected by the project.
* **justification** (note): Additional justification or explanation for the project.
* **business_case** (select_multiple): Reiterate the business case or reason for the project.
* **project_idea** (text): Repeat the project idea.
* **project_team** (select_one): Select the project team or members responsible for the project.
* **project_location** (select_one): Select the location where the project will be carried out.
* **project_status** (select_one): Select the status of the project.
* **budget_category** (select_multiple): Select the budget category or type for the project.
* **project_justification** (note): Enter any additional project justification.
* **project_rationale** (select_one): Select the project rationale or reason for the project.
* **project_rationale** (select_multiple): Repeat the project rationale or reason for the project.

Note: The fields marked with **note** are meant for users to enter any additional information that may be required for the project proposal.
