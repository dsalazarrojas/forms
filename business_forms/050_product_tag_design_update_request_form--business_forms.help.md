# product_tag_design_update_request_form - Help Guide
## Purpose
The purpose of this form is to collect information for updating the product tags' design. This form is intended for product teams to submit updates on product tags, specifying which tags need changes, the priority of these updates, and any supporting files that may be relevant.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the product tag that needs an update.
2. Specify the priority of the update (high, medium, or low).
3. If necessary, attach a file that supports your request.
4. Select the type of changes needed for the product tag (color, image, text, background, or icon).
5. Enter any additional file information if required.
6. Submit the form.

## Field-by-Field Explanation
- **Product Tag** (`product_tag`, `text`, not required): Enter the product tag that needs an update.
- **Product Name** (`product_name`, `text`, not required): Enter the name of the product associated with the tag.
- **Design Priority** (`design_priority`, `select_one`, not required): Specify the priority of the update (high, medium, or low).
- **File** (`file`, `note`, not required): If you need to attach a file to support your request, upload it here. This field is not required but recommended for clarity.
- **File Description** (`file_description`, `text`, not required): If you attached a file, provide a brief description of what it is and why it's relevant.
- **Tag Changes** (`tag_changes`, `select_multiple`, not required): Select the type of changes needed for the product tag (color, image, text, background, or icon).
- **File Upload** (`file_upload`, `text`, not required): If you attached a file, enter the file's name for easier identification.
- **Priority** (`priority`, `number`, not required): Enter a numeric value to further specify the priority of the update (1, 2, or 3 for low, medium, and high respectively).
