# Strategic Change Analysis Request Form - Help Guide
## Purpose
The Strategic Change Analysis Request Form is used to collect and analyze requests for strategic changes within a project.

## How To Complete This Form
To complete this form, please follow these steps:

* Fill in the required fields with accurate and complete information.
* Ensure that your request is not a duplicate and has been discussed with the project team first.
* The approver will review your request and either approve or deny it.

## Field-by-Field Explanation

* **Strategic Change Analysis Request Form** (`form_title`, text, required: false): The title of the form, which will be used for reference and tracking purposes.
* **Request Date** (`request_date`, date, required: false): The date when the request was made.
* **Request Time** (`request_time`, time, required: false): The time when the request was made.
* **Project Name** (`project_name`, text, required: false): The name of the project affected by the change.
* **Change Description** (`change_description`, text, required: false): A brief description of the change request.
* **Change Impact** (`change_impact`, text, required: false): The impact of the change on the project, including any potential risks or benefits.
* **Project Status** (`project_status`, select_one, required: false): The current status of the project (Active, In Progress, On Hold, Complete).
* **Change Type** (`change_type`, text, required: false): The type of change requested (e.g., feature addition, bug fix, etc.).
* **Submitter Name** (`submitter_name`, text, required: false): The name of the person submitting the request.
* **Submitter Email** (`submitter_email`, email, required: false): The email address of the person submitting the request.
* **Submitter Phone** (`submitter_phone`, text, required: false): The phone number of the person submitting the request.
* **Submitter Department** (`submitter_department`, text, required: false): The department of the person submitting the request.
* **Approver Name** (`approver_name`, text, required: false): The name of the person reviewing and approving the request.
* **Approver Email** (`approver_email`, email, required: false): The email address of the person reviewing and approving the request.
* **Approver Phone** (`approver_phone`, text, required: false): The phone number of the person reviewing and approving the request.
* **Approver Department** (`approver_department`, text, required: false): The department of the person reviewing and approving the request.
* **Review Date** (`review_date`, date, required: false): The date when the request was reviewed.
* **Approver Notes** (`approver_notes`, note, required: false): Any additional notes from the approver.
* **Approver Comments** (`approver_comments`, text, required: false): Any comments from the approver.
* **Approver Status** (`approver_status`, select_one, required: false): The status of the request (Approved, Denied, Pending).
* **Approver Signature** (`approver_signature`, text, required: false): The signature of the person reviewing and approving the request.
* **Submitter Signature** (`submitter_signature`, text, required: false): The signature of the person submitting the request.
* **Approver Title** (`approver_title`, text, required: false): The title of the person reviewing and approving the request.
* **Submitter Title** (`submitter_title`, text, required: false): The title of the person submitting the request.
* **Form Notes** (`form_notes`, text, required: false): Any additional notes about the form or request.

Tips:

* Make sure to fill in all required fields accurately and completely.
* Review the form carefully before submitting it to ensure that all necessary information is included.
* If you have any questions or concerns, please reach out to the project lead or approver.
