# Raw Material Variance Report Form - Help Guide
## Purpose
The purpose of this form is to report variances of raw materials during production. It is used to track and document any discrepancies or deviations from the expected or actual production process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the production team that was involved in the production process.
2. Enter the date of the production.
3. Enter the actual quantity of the raw material produced.
4. Provide a brief description of the root cause of the variance.
5. Select the corrective actions taken.
6. Select the production run ID.
7. Provide a description of the production run.
8. Indicate if the raw material was received or not.
9. Provide a description of the raw material and its unit of measurement.
10. Enter the cost of the raw material.
11. Enter any additional notes about the production process.

## Field-by-Field Explanation
### Production Team
* **Production Team** (`production_team`, Select Multiple, required): Select the production team that was involved in the production process.

### Production Date
* **Production Date** (`production_date`, Date, required): Enter the date of the production.

### Actual Production Quantity
* **Actual Production Quantity** (`actual_production_quantity`, Number, required): Enter the actual quantity of the raw material produced.

### Root Cause Description
* **Root Cause Description** (`root_cause_description`, Text, required): Provide a brief description of the root cause of the variance.

### Corrective Actions
* **Corrective Actions** (`corrective_actions`, Select Multiple, required): Select the corrective actions taken.

### Production Run ID
* **Production Run ID** (`production_run_id`, Select One, required): Select the production run ID.

### Production Run Description
* **Production Run Description** (`production_run_description`, Text, required): Provide a description of the production run.

### Production Lot
* **Production Lot** (`production_lot`, Text, required): Enter the production lot.

### Production Lot Number
* **Production Lot Number** (`production_lot_number`, Text, required): Enter the production lot number.

### Production Lot Description
* **Production Lot Description** (`production_lot_description`, Text, required): Enter the description of the production lot.

### Production Start Date
* **Production Start Date** (`production_start_date`, Date, required): Enter the start date of the production.

### Production End Date
* **Production End Date** (`production_end_date`, Date, required): Enter the end date of the production.

### Production Status
* **Production Status** (`production_status`, Select One, required): Select the production status.

### Raw Material ID
* **Raw Material ID** (`raw_material_id`, Select One, required): Indicate if the raw material was received or not.

### Raw Material Description
* **Raw Material Description** (`raw_material_description`, Text, required): Provide a description of the raw material.

### Raw Material Quantity
* **Raw Material Quantity** (`raw_material_quantity`, Number, required): Enter the quantity of the raw material produced.

### Raw Material Receiving Date
* **Raw Material Receiving Date** (`raw_material_receiving_date`, Date, required): Enter the date the raw material was received.

### Raw Material UOM
* **Raw Material UOM** (`raw_material_uom`, Select One, required): Indicate the unit of measurement of the raw material.

### Raw Material UOM Description
* **Raw Material UOM Description** (`raw_material_uom_description`, Text, required): Provide a description of the unit of measurement of the raw material.

### Raw Material Vendor
* **Raw Material Vendor** (`raw_material_vendor`, Select One, required): Indicate if the raw material was purchased from a vendor or not.

### Raw Material Vendor Description
* **Raw Material Vendor Description** (`raw_material_vendor_description`, Text, required): Provide a description of the vendor.

### Raw Material Cost
* **Raw Material Cost** (`raw_material_cost`, Number, required): Enter the cost of the raw material.

### Raw Material Note
* **Raw Material Note** (`raw_material_note`, Text, required): Enter any additional notes about the production process.
