# Product Lifecycle Management Application - Help Guide
## Purpose
The Product Lifecycle Management Application is used to track and manage product requests, changes, and approvals within an organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: product_name, change_request_description, change_request_stage, change_request_priority, change_request_status, change_request_type, product_category, product_subcategory, change_reason, approval_level, approval_notes, and approval_user.
2. Select the relevant options for change_request_stage, change_request_priority, approval_level, and approval_status.
3. Leave any optional fields (approval_date, phone, email, notes, change_request_due_date) empty unless they are required for your specific use case.
4. Fill in any additional notes in the approval_notes, change_request_notes, and change_request_status_notes fields.

## Field-by-Field Explanation
* **Product Name** (text, required): Enter the name of the product being requested or changed.
* **Change Request Description** (text, required): Describe the change request being made.
* **Change Request Stage** (select_one, required): Select the current stage of the change request.
* **Change Request Priority** (select_one, required): Select the priority level of the change request.
* **Change Request Status** (select_one, required): Select the current status of the change request.
* **Change Request Type** (select_one, required): Select the type of change request.
* **Product Category** (select_one, required): Select the category of the product.
* **Product Subcategory** (select_one, required): Select the subcategory of the product.
* **Change Reason** (text, required): Provide a description of the change reason.
* **Approval Level** (select_one, required): Select the approval level of the change request.
* **Product Name** (text, required): Enter the name of the product.
* **Email** (email, required): Enter the email of the approver.
* **Phone** (text, optional): Enter the phone number of the approver.
* **Change Request Due Date** (date, optional): Select the due date of the change request.
* **Approval User** (select_one, required): Select the user who approved the change request.
* **Approval Notes** (note, optional): Enter any additional notes about the approval.
* **Change Request Description** (text, required): Describe the change request.
* **Change Request Notes** (text, required): Enter any additional notes about the change request.
* **Change Request Status Notes** (text, optional): Enter any additional status notes about the change request.
* **Approval Notes** (note, optional): Enter any additional notes about the approval.
* **Change Request Stage** (select_one, required): Select the stage of the change request.
* **Approval Status** (select_one, required): Select the status of the approval.

Please review each field carefully and provide accurate information to ensure the form is completed correctly.
