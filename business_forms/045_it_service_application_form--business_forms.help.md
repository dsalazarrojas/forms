# IT Service Application Form - Help Guide
## Purpose
The IT Service Application Form is a tool used to gather information about new or ongoing IT services. It helps the IT team to better understand your service needs and provide efficient support.
## How To Complete This Form
To complete this form, please follow these steps:
1. Select the type of service you are applying for.
2. Enter your company name (if applicable).
3. Provide your email address and phone number for further communication.
4. Describe the service you are applying for.
5. Select the start and end dates of the service.
6. Choose the frequency of the service (e.g., one-time, daily, weekly, etc.).
7. Select the current status of the service (e.g., active, inactive, etc.).
8. Select the priority of the service (e.g., high, low, etc.).
9. Choose the category of the service (e.g., network, hardware, software, etc.).
10. If necessary, provide further information about the service frequency.
11. Enter the start and end times of the service, if applicable.
12. Add any additional notes about the service.
13. Finally, add any additional comments about the service.

## Field-by-Field Explanation
* **service_type** (Select one)
	+ Choose 'Yes' if you are applying for a new service, 'No' if you are updating an existing one.
* **company_name** (Text)
	+ Enter your company name, if applicable.
* **email** (Email)
	+ Enter your email address for further communication.
* **phone** (Text)
	+ Enter your phone number for further communication.
* **service_description** (Text)
	+ Describe the service you are applying for.
* **service_start_date** (Date)
	+ Select the start date of the service.
* **service_end_date** (Date)
	+ Select the end date of the service.
* **service_frequency** (Select one)
	+ Choose the frequency of the service (e.g., one-time, daily, weekly, etc.).
* **service_status** (Select multiple)
	+ Select all relevant status (e.g., active, inactive, etc.).
* **service_priority** (Select multiple)
	+ Select the priority of the service (e.g., high, low, etc.).
* **service_category** (Select multiple)
	+ Choose the category of the service (e.g., network, hardware, software, etc.).
* **service_frequency_further_info** (Text)
	+ If necessary, provide further information about the service frequency.
* **service_start_time** (Time)
	+ Enter the start time of the service, if applicable.
* **service_end_time** (Time)
	+ Enter the end time of the service, if applicable.
* **service_notes** (Note)
	+ Add any additional notes about the service.
* **service_comments** (Note)
	+ Add any additional comments about the service.

## Tips
* Be accurate and complete in your responses to ensure the IT team can efficiently provide support.
* If you are unsure about any field, feel free to ask for help or clarification.
