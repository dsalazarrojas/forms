# green_building_certification_approval_form - Help Guide
## Purpose
The green building certification approval form is used to track and report on the progress of green building projects. This form helps to ensure that projects meet the necessary requirements for green building certification.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project name and address.
2. Select the project type (e.g. commercial, residential, etc.).
3. Check the certification status (e.g. pending, approved, etc.).
4. Enter the project specifications.
5. Provide compliance documentation (if applicable).
6. Enter the building code certification (if applicable).
7. Enter energy audit results (if applicable).
8. Enter the energy audit date (if applicable).
9. Enter the energy audit performed by (if applicable).
10. Enter the green building certification date (if applicable).
11. Select the green building certification status (e.g. pending, approved, etc.).
12. Enter the building type (e.g. commercial, residential, etc.).
13. Select the green building certification level (e.g. level 1, level 2, etc.).
14. Enter the building square footage.
15. Enter the project cost.
16. Select the project status (e.g. in progress, completed, etc.).
17. Select whether the project has green building certification points.
18. Enter energy consumption.
19. Enter carbon footprint.
20. Enter water consumption.
21. Enter waste water reduction.
22. Enter energy savings.

## Field-by-Field Explanation
* **Project Name (1)**: Enter the name of the project.
* **Project Address (2)**: Enter the address of the project.
* **Project Location (3)**: Enter the location of the project.
* **Project Type (4)**: Select the type of project (e.g. commercial, residential, etc.).
* **Certification Status (5)**: Check the current status of the project's certification.
* **Compliance Documentation (6)**: Provide any relevant compliance documentation (if applicable).
* **Project Specifications (7)**: Enter a detailed description of the project specifications.
* **Certification Requirements (8)**: Enter any relevant certification requirements.
* **Building Code Certification (9)**: Select the building code certification (if applicable).
* **Energy Audit Results (10)**: Enter any relevant energy audit results (if applicable).
* **Energy Audit Date (11)**: Enter the date of the energy audit (if applicable).
* **Energy Audit Performed By (12)**: Enter the name of the person or organization that performed the energy audit (if applicable).
* **Green Building Certification Date (13)**: Enter the date of green building certification (if applicable).
* **Green Building Certification Status (14)**: Select the current status of green building certification (e.g. pending, approved, etc.).
* **Building Type (15)**: Select the type of building (e.g. commercial, residential, etc.).
* **Green Building Certification Level (16)**: Select the level of green building certification (e.g. level 1, level 2, etc.).
* **Building Square Footage (17)**: Enter the square footage of the building.
* **Project Cost (18)**: Enter the total cost of the project.
* **Project Status (19)**: Select the current status of the project (e.g. in progress, completed, etc.).
* **Green Building Certification Points (20)**: Select whether the project has green building certification points.
* **Energy Consumption (21)**: Enter the energy consumption of the building.
* **Carbon Footprint (22)**: Enter the carbon footprint of the building.
* **Water Consumption (23)**: Enter the water consumption of the building.
* **Waste Water Reduction (24)**: Enter the waste water reduction of the building.
* **Energy Savings (25)**: Enter the energy savings of the building.
