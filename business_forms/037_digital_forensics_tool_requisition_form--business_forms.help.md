# digital_forensics_tool_requisition_form - Help Guide
## Purpose
This form is used to request a digital forensic tool for a specific case.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of tool you need for the case by choosing one of the available options in the "tool_type" field.
2. Enter the name or username of the person requesting the tool in the "tool_requestor" field.
3. Fill out the "phone_number" field with the requestor's contact number.
4. Enter the case details in the "case_number", "case_date" fields.
5. Select the tool(s) that will be assigned to the case in the "assigned_tool" field.
6. Choose the user assigned to the case in the "assigned_user" field (optional).
7. Fill out the "submitted_by" field with the username of the person submitting the form.
8. Select the submission date and time in the "submitted_date" field.

## Field-by-Field Explanation
* **Tool Type (tool_type)**: Select the type of tool needed for the case.
* **Tool Requestor (tool_requestor)**: Enter the name or username of the person requesting the tool.
* **Phone Number (phone_number)**: Enter the contact number of the person requesting the tool.
* **Email (email)**: Enter the email address of the person requesting the tool (not required).
* **Notes (notes)**: Add any additional comments or notes about the case.
* **Assigned Tool (assigned_tool)**: Select the tool(s) that will be assigned to the case.
* **Case Number (case_number)**: Enter the case number or unique identifier.
* **Case Date (case_date)**: Enter the date the case was opened.
* **Assigned User (assigned_user)**: Select the user assigned to work on the case (optional).
* **Submitted By (submitted_by)**: Enter the username of the person submitting the form.
* **Submitted Date (submitted_date)**: Select the date and time the form was submitted.
* **Updated Date (updated_date)**: Select the date and time the form was last updated (not required).
* **Tool Status (tool_status)**: Select the current status of the tool assignment (optional).
* **Notes (notes)**: Add any additional comments or notes about the case.
* **Tool Status (tool_status)**: Select the current status of the tool (optional).

## Tips
* Please make sure to fill out the form accurately and honestly.
* If you're unsure about any of the fields, contact the tool team for guidance.
* Double-check the form for completeness and accuracy before submitting.
