# Storage Unit Billing Form - Help Guide
## Purpose
The Storage Unit Billing Form is used to capture important information related to a storage unit, including facility name, customer details, billing information, and payment status.

## How To Complete This Form
To complete this form, follow the steps below:

1. On the main page, enter the facility name in the "facility_name" field.
2. Indicate the customer account status in the "customer_account" field.
3. Enter the unit number in the "unit_number" field.
4. Enter the total charges and amount charged in the corresponding fields.
5. Select the payment method in the "payment_method" field.
6. Enter the date and time due in the "date_due" and "time_due" fields, respectively.
7. Add any customer notes in the "customer_notes" field.
8. Select the payment status in the "payment_status" field.
9. Go to the second page for additional details.

## Field-by-Field Explanation
* **facility_name** (id: 2): Enter the name of the facility.
* **facility_name** is a text field that requires a descriptive title for the facility.
* **customer_account** (id: 3): Indicate if the customer account is active or inactive.
* **customer_account** is a select_one field that has two options: 'Yes' or 'No'.
* **unit_number** (id: 4): Enter the unit number of the storage unit.
* **unit_number** is a number field that requires a numerical value.
* **total_charges** (id: 5): Enter the total charges for the storage unit.
* **total_charges** is a number field that requires a numerical value.
* **amount_charged** (id: 6): Enter the amount charged for the storage unit.
* **amount_charged** is a number field that requires a numerical value.
* **payment_method** (id: 7): Select the payment method for the storage unit.
* **payment_method** is a select_one field that has two options: 'Yes' or 'No'.
* **date_due** (id: 8): Enter the date the payment is due.
* **date_due** is a date field that requires a date in the format MM/DD/YYYY.
* **time_due** (id: 9): Enter the time the payment is due.
* **time_due** is a time field that requires a time in the format HH:MM AM/PM.
* **customer_notes** (id: 10): Add any customer notes for the storage unit.
* **customer_notes** is a note field that allows for free-text comments.
* **payment_status** (id: 11): Select the payment status of the storage unit.
* **payment_status** is a select_multiple field that has two options: 'Paid' or 'Unpaid'.
* **billing_email** (id: 12): Enter the billing email for the storage unit.
* **billing_email** is an email field that requires a valid email address.
* **billing_phone** (id: 13): Enter the billing phone number for the storage unit.
* **billing_phone** is a text field that requires a numerical phone number.
* **contact_person** (id: 14): Select if there is a contact person for the storage unit.
* **contact_person** is a select_one field that has two options: 'Yes' or 'No'.
* **facility_address** (id: 15): Enter the facility address.
* **facility_address** is a text field that requires a complete address.
* **facility_city** (id: 16): Enter the facility city.
* **facility_city** is a text field that requires a city name.
* **facility_state** (id: 17): Enter the facility state.
* **facility_state** is a text field that requires a state name.
* **facility_zip** (id: 18): Enter the facility zip code.
* **facility_zip** is a text field that requires a zip code.
* **facility_country** (id: 19): Enter the facility country.
* **facility_country** is a text field that requires a country name.
* **contact_number** (id: 20): Enter the contact number for the storage unit.
* **contact_number** is a text field that requires a numerical value.
* **facility_hours** (id: 21): Enter the facility hours of operation.
* **facility_hours** is a text field that requires a set of hours.
* **facility_notes** (id: 22): Add any facility notes for the storage unit.
* **facility_notes** is a note field that allows for free-text comments.
* **facility_fax** (id: 23): Enter the facility fax number.
* **facility_fax** is a text field that requires a numerical value.
* **facility_website** (id: 24): Enter the facility website.
* **facility_website** is a text field that requires a valid website URL.
* **facility_other** (id: 25): Enter any additional information about the facility.
* **facility_other** is a text field that requires a free-text comment.

## Tips
* Ensure all required fields are filled before proceeding.
* Review each field carefully to ensure accurate information is entered.
* Use a valid email address for the billing email field.
* Enter a valid phone number for the billing phone field.
* Enter the correct facility hours of operation.
* Enter a valid zip code for the facility zip field.
