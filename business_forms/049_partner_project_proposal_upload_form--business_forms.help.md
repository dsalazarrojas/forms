# Partner Project Proposal Upload Form - Help Guide
## Purpose
This form is used to upload and maintain project proposals for partnerships. It is essential to accurately and thoroughly provide project details, partner information, and other relevant notes to ensure proper review and approval processes.

## How To Complete This Form
1. Click on the "New Proposal" button to initiate the form.
2. Fill out the form completely and accurately, providing all required information for each field.
3. Ensure you have the necessary permission to upload project documents and files.

## Field-by-Field Explanation
### **Project Title (Required)**
Project Title: Enter a brief but descriptive title for the project, summarizing its scope and objective.

*   This field is required to identify the project and distinguish it from other proposals.

### **Project Description (Required)**
Project Description: Provide a detailed description of the project, including its goals, objectives, and key features.

*   This field is required to provide a comprehensive understanding of the project's scope and requirements.

### **Project Status (Required)**
Project Status: Choose the status of the project from the available options: Active, Inactive, or On Hold.

*   This field helps in tracking the project's current status and progression.

### **Project Start Date (Optional)**
Project Start Date: Enter the date when the project is scheduled to commence, if applicable.

*   This field is used for scheduling and planning purposes.

### **Project End Date (Optional)**
Project End Date: Enter the date when the project is expected to conclude, if applicable.

*   This field is used for scheduling and planning purposes.

### **Uploaded Documents (Optional)**
Uploaded Documents: Attach relevant project documents, such as project plans, reports, or agreements.

*   This field is used to attach supporting documents for project proposal review and approval.

### **Review Note (Optional)**
Review Note: Add any additional comments or notes for the reviewer's reference.

*   This field is used to provide context or clarify any project-related information.

### **Partner Name (Required)**
Partner Name: Enter the name of the partnering organization or individual.

*   This field is essential for identifying the partner and ensuring correct communication.

### **Partner Email (Required)**
Partner Email: Enter the email address of the partnering organization or individual.

*   This field is used for official communication and correspondence with the partner.

### **Partner Phone (Required)**
Partner Phone: Enter the phone number of the partnering organization or individual.

*   This field is used for direct communication and follow-up.

### **Team Members (Required)**
Team Members: List the names and roles of team members involved in the project.

*   This field is used to track team composition and ensure correct communication.

### **Project Manager (Required)**
Project Manager: Enter the name of the project manager responsible for overseeing the project.

*   This field is used for assigning project responsibility and tracking progress.

### **Team Leader (Required)**
Team Leader: Enter the name of the team leader responsible for leading the project.

*   This field is used for assigning project leadership and tracking performance.

### **Upload Date (Optional)**
Upload Date: Enter the date when the project was uploaded for review, if applicable.

*   This field is used for tracking the upload date and ensuring timely review.

### **Review Date (Optional)**
Review Date: Enter the date when the project was reviewed, if applicable.

*   This field is used for tracking review dates and ensuring timely follow-up.

### **Status Change (Required)**
Status Change: Choose the status change from the available options: Changed or Not Changed.

*   This field is used to indicate any changes to the project's status.

### **Document Upload (Optional)**
Document Upload: Attach any supporting documents related to the project.

*   This field is used to attach relevant documents for project proposal review and approval.

### **Project Status Note (Optional)**
Project Status Note: Add any additional notes or comments about the project's status.

*   This field is used to provide context or clarify any project status information.

### **Partner Status Note (Optional)**
Partner Status Note: Add any additional notes or comments about the partner's status.

*   This field is used to provide context or clarify any partner status information.

### **Project Comments (Optional)**
Project Comments: Add any additional comments or notes about the project.

*   This field is used to provide context or clarify any project information.

### **Uploaded File (Optional)**
Uploaded File: Attach any supporting files related to the project.

*   This field is used to attach relevant files for project proposal review and approval.

### **Uploaded Documents Note (Optional)**
Uploaded Documents Note: Add any additional comments or notes about the uploaded documents.

*   This field is used to provide context or clarify any uploaded document information.

### **Partner Comments (Optional)**
Partner Comments: Add any additional comments or notes about the partner.

*   This field is used to provide context or clarify any partner information.

### **Uploaded File 2 (Optional)**
Uploaded File 2: Attach any supporting files related to the project, if applicable.

*   This field is used to attach additional files for project proposal review and approval.

### **Project Notes (Optional)**
Project Notes: Add any additional comments or notes about the project.

*   This field is used to provide context or clarify any project information.

## Tips
*   Ensure all required fields are completed accurately and thoroughly.
*   Attach relevant documents and files to support the project proposal.
*   Provide clear and concise information in all fields to facilitate review and approval processes.
*   Use the provided fields to track project progress and communicate effectively with partners.
