# Assembly Line Rebalance Request Form - Help Guide
## Purpose
This form is designed to collect information for rebalance requests from production or engineering teams, helping to optimize assembly line production efficiency and workflow.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and the name of the engineering or production unit you are representing.
2. Select the primary reason for the rebalance request from the provided options.
3. Enter the current and target cycle times for the assembly line, with the current cycle time representing the current production process and the target cycle time representing the desired outcome.
4. Provide a summary of the proposed task reallocation, describing which tasks will be moved to which stations.
5. If applicable, estimate the impact on station staffing and list any safety and ergonomic risks introduced or mitigated by the rebalance.
6. Indicate any required tooling or jig changes.
7. If the implementation downtime is anticipated, enter the expected duration.
8. Review and acknowledge that this request requires secondary engineering sign-off.

## Field-by-Field Explanation
- **Requester Name** (Requester Name, Text, Required): Enter your name and the name of the engineering or production unit you are representing.
- **Engineering or Production Unit** (Engineering or Production Unit, Text, Required): Enter the name of the production or engineering unit you are submitting this request from.
- **Primary Reason for Rebalance Request** (Primary Reason for Rebalance Request, Select One, Required): Choose the primary reason for the rebalance request from the provided options.
- **Current Cycle Time** (Current Cycle Time, Text, Required): Enter the current cycle time for the assembly line in seconds or minutes.
- **Target Cycle Time** (Target Cycle Time, Text, Required): Enter the target cycle time for the assembly line as the desired outcome post-rebalance.
- **Proposed Task Reallocation Summary** (Proposed Task Reallocation Summary, Text, Required): Describe which tasks will be moved to which stations in the assembly line.
- **Estimated Impact on Station Staffing** (Estimated Impact on Station Staffing, Text, Optional): If applicable, estimate the impact on station staffing, for example, adding 2 operators to station B.
- **Safety and Ergonomic Risk Assessment** (Safety and Ergonomic Risk Assessment, Text, Required): Assess the safety and ergonomic risks introduced or mitigated by the rebalance.
- **Required Tooling or Jig Changes** (Required Tooling or Jig Changes, Text, Optional): List any physical modifications needed for the rebalance.
- **Anticipated Implementation Downtime** (Anticipated Implementation Downtime, Text, Required): Enter the anticipated duration of the implementation, if applicable.
- **Note - This request requires secondary engineering sign-off** (Note - This request requires secondary engineering sign-off, Note, Optional): Acknowledge that this request requires secondary engineering sign-off.
- **Request Date** (Request Date, Date, Required): Enter the date the request was submitted.

## Tips
- Be as specific as possible when providing information to ensure a thorough evaluation.
- Ensure all relevant details are included to facilitate a successful rebalance.
