# Project Handover Form - Help Guide
## Purpose
The Project Handover Form is used for collecting information about a project handover.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review each field carefully and ensure that you have the necessary information to fill it in.
2.  Fill in the required fields, marked with an asterisk (\*), and provide as much detail as possible for the optional fields.
3.  Double-check your input for accuracy and completeness.

## Field-by-Field Explanation

* **Project Details (\*\***: This field is for the project title or name.
* **Project Team (\*\***: Select all team members involved in the project.
* **Project Start Date (\*\***: Enter the date the project started.
* **Project End Date (\*\***: Enter the date the project was completed or is expected to be completed.
* **Project Budget (\*\***: Enter the project budget.
* **Project Status** (optional): Select the project's status, whether Active, Completed, or Closed.
* **Project Notes** (optional): Add any additional notes about the project.
* **Team Responsible** (optional): Select the team responsible for the project.
* **Team Lead** (optional): Select the team lead for the project.
* **Team Members** (optional): Select all team members involved in the project.
* **Resource List** (optional): Enter any additional resources used for the project.
* **Resource Type** (optional): Select the type of resource used for the project.
* **Resource Quantity** (optional): Enter the quantity of resources used for the project.
* **Resource Status** (optional): Select the status of the resources used for the project.

## Tips
* Always ensure that all required fields are filled in before submitting the form.
* Double-check your input for accuracy and completeness.
* If you are unsure about any field or its purpose, please consult with the project manager or team lead.
