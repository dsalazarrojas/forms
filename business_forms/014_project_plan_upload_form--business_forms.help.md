# project_plan_upload_form - Help Guide

## Purpose
The "Project Plan Upload Form" is a tool for project team members or stakeholders to upload project plans, providing essential details such as project descriptions, files, and status updates.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter a brief description of your project in the "Project Description" field.
2. Select the "Yes" or "No" option for "Select Project Plan File" to indicate whether you are uploading a file or not.
3. If you are uploading a file, enter its size in the "File Size (MB)" field.
4. Specify who uploaded the project plan in the "Uploaded By" field, by selecting "Yes" or "No".
5. Enter the date of upload in the "Upload Date" field.
6. Specify the time the project was uploaded in the "Upload Time" field.
7. Provide additional comments about the project plan in the "Project Plan Comments" field.
8. Enter your email address in the "Email" field.
9. Enter your phone number in the "Phone" field.
10. Finally, select the status of the project plan in the "Project Plan Status" field, using "Active" or "Inactive".

## Field-by-Field Explanation
* **Upload Project Plan (1)**: Enter a brief description of your project.
* **Project Description (2)**: Describe your project in a few sentences.
* **Select Project Plan File (3)**: Choose "Yes" if you are uploading a file, "No" otherwise.
* **File Size (MB) (4)**: If you are uploading a file, enter its size in megabytes.
* **Uploaded By (5)**: Specify who uploaded the project plan, by selecting "Yes" or "No".
* **Upload Date (6)**: Enter the date the project plan was uploaded.
* **Upload Time (7)**: Enter the time the project plan was uploaded.
* **Project Plan Comments (8)**: Provide additional comments or notes about the project plan.
* **Email (9)**: Enter your email address for contact purposes.
* **Phone (10)**: Enter your phone number for contact purposes.
* **Project Plan Status (11)**: Choose the status of the project plan, using "Active" or "Inactive".
