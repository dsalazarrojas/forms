# Tool Malfunction Incident Form - Help Guide
## Purpose
The Tool Malfunction Incident Form is designed to collect information about tool malfunctions that occur within the organization. This form helps to identify the tools that are not functioning correctly, which aids in taking corrective actions to prevent future malfunctions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the assigned tool that was not functioning correctly.
2. Enter the date and time when the malfunction occurred.
3. Describe the malfunction in detail.

## Field-by-Field Explanation
* **Tool**: Select from the list of tools provided. Please choose the tool that was not functioning correctly. This will help us identify the specific tool that needs to be addressed.
	+ Type: <select_one> (Select One)
	+ Required: <yes>
* **Incident Date**: Enter the date when the malfunction occurred. This will help us track the malfunctions over time.
	+ Type: <date> (Date)
	+ Required: <no>
* **Incident Time**: Enter the time when the malfunction occurred. This will help us pinpoint the exact time of the malfunction.
	+ Type: <time> (Time)
	+ Required: <no>
* **Incident Description**: Provide a detailed description of the malfunction. This will help us understand the nature of the malfunction and what caused it.
	+ Type: <text> (Text)
	+ Required: <no>

## Tips
* Please ensure that you select the correct tool that was malfunctioning.
* If the time is not available, you can leave it blank.
* Please provide a clear and detailed description of the malfunction to aid in the resolution process.
