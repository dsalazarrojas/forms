# Construction Supply Requisition Form - Help Guide
## Purpose

This form is designed to collect information from construction workers to request materials and supplies for their projects. It's intended for internal use within the organization, and the purpose of this form is to streamline the requisitioning process.

## How To Complete This Form

1.  Fill out the form carefully, providing accurate information for each field as needed.
2.  Start by filling out the first section, "Project Details," which includes:
    *   Requisition Date: The date you are submitting this request.
    *   Requisition Number: A unique reference number for this request.
    *   Project Name: The name of the construction project.
    *   Project Address: The site location of the project.
    *   Requested By: Your name and contact information.
    *   Requester Department: Your department or crew.
3.  In the "Items" section, list each item you need for your project. For each item:
    *   Item Description: A detailed description of the item needed.
    *   Item Specifications: Any specific specifications or details about the item (e.g., size, model).
    *   Quantity: The amount of the item needed.
    *   Unit: The unit of measure for the item (e.g., "Each", "Box", "Bundle").
    *   Unit Cost: The cost per unit if known.
4.  Calculate the total cost for each item by multiplying the quantity by the unit cost.
5.  Enter your urgency level and purpose for the request.
6.  Optionally, you can enter a budget code or account for the request.
7.  Provide any special instructions or requirements for the delivery.
8.  Finally, sign the form with your full name.

## Field-by-Field Explanation

* **Requisition Date**: The date you are submitting this request.
* **Requisition Number**: A unique reference number for this request.
* **Project Name**: The name of the construction project.
	+ This is the name of the project you are working on.
* **Project Address**: The site location of the project.
	+ Enter the exact address where the project is located.
* **Requested By**: Your name and contact information.
	+ Please enter your full name and contact information.
* **Requester Department**: Your department or crew.
	+ Enter the department or crew you belong to.
* **Supplier Name**: The name of the preferred supplier company (optional).
* **Supplier Contact**: The contact person for the supplier (optional).
* **Supplier Phone**: The phone number of the supplier (optional).
* **Delivery Date Needed**: The date when you need the materials delivered.
* **Delivery Location**: The location where you want the materials delivered.
* **Item 1 Description**, **Item 2 Description**, etc.: A detailed description of each item.
* **Item 1 Specifications**, **Item 2 Specifications**, etc.: Any specific specifications or details about each item.
* **Item 1 Quantity**, **Item 2 Quantity**, etc.: The amount of each item needed.
* **Item 1 Unit**, **Item 2 Unit**, etc.: The unit of measure for each item.
* **Item 1 Unit Cost**, **Item 2 Unit Cost**, etc.: The cost per unit if known.
* **Item 1 Total Cost**, **Item 2 Total Cost**, etc.: The cost of each item calculated by multiplying the quantity by the unit cost.
* **Urgency Level**:
	+ Routine: Not urgent, can wait for a standard delivery time.
	+ Standard: Standard delivery time.
	+ Urgent: Requires faster delivery, but can still wait for a reasonable time.
	+ Emergency: Very urgent, requires immediate delivery.
* **Purpose**: A brief description of what the request is for.
* **Budget Code**: The cost code or account for the request (optional).
* **Special Instructions**: Any special requirements or instructions for the delivery.
* **Requester Signature**: Your full name as a signature.
* **Approval Signature**: The full name of the person approving this request (optional).

Note: Please fill out each item carefully, and make sure to submit each request as a separate form if you need to make multiple requests.
