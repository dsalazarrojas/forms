# Temporary Duty Request Form - Help Guide
## Purpose
This form is used to submit a temporary duty request to your supervisor or manager for approval. Please use this form to request temporary duty for yourself or others.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and complete information.
2. Make sure to submit the form with a clear and concise reason for your temporary duty request.
3. If you are requesting temporary duty for someone else, please provide their name and assigned tool.
4. You can add any additional comments if necessary.

## Field-by-Field Explanation
* **User** (`user`, text, required): Enter the name of the person making the temporary duty request.
* **Start Date** (`start_date`, date, required): Enter the start date of the temporary duty.
* **End Date** (`end_date`, date, required): Enter the end date of the temporary duty.
* **Duty Location** (`duty_location`, text, required): Enter the location where the temporary duty will take place.
* **Reason** (`reason`, text, required): Explain why the temporary duty is being requested.
* **Assigned Tool** (`assigned_tool`, text, required): Enter the tool assigned to the temporary duty request.
* **Comments** (`comments`, text, optional): Add any additional comments or details about the temporary duty request.
* **Approval Required** (`approval_required`, select_one, required): Select 'True' if approval is required, or 'False' if not.

## Tips
- Make sure to check with your supervisor or manager before submitting the form to ensure you have permission to request temporary duty.
- If you are unsure about any of the fields, please contact your supervisor or manager for clarification.
- Please keep the reason for the temporary duty request clear and concise.
