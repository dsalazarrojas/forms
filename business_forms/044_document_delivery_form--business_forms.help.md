# Document Delivery Form - Help Guide
## Purpose
The Document Delivery Form is used to document delivery information for various business purposes. It captures essential details about the delivery, including address, contact information, delivery date and time, delivery method, and other relevant comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information in the address fields (Address Line 1, Address Line 2, City, State, Zip Code).
2. Select the Recipient Group from the provided options.
3. Enter the Contact Name, which is the name of the person to receive the document.
4. If applicable, enter the Contact Phone and Contact Email numbers.
5. Choose a Delivery Date and Delivery Time for the document.
6. Select the preferred Delivery Method from the provided options.
7. Provide any Additional Comments or remarks as needed.
8. Enter the Delivery Status, which indicates the current status of the document.
9. Select the person assigned to handle the document delivery.
10. Set the Priority level of the document delivery.
11. If needed, add Follow Up information.
12. Enter the Due Date for any follow-up actions.
13. Enter any additional Comments or remarks as needed.
14. Finally, review the form for accuracy and completeness before submitting it.

## Field-by-Field Explanation
* **Address Line 1**: The first line of the address where the document will be delivered.
* **Address Line 2**: The second line of the address where the document will be delivered.
* **City**: The city where the document will be delivered.
* **State**: The state where the document will be delivered. (Select from options: option 1, option 2, option 3)
* **Zip Code**: The zip code where the document will be delivered.
* **Recipient Group**: The group to which the document will be delivered (Select from options: option 1, option 2, option 3).
* **Contact Name**: The name of the person to receive the document.
* **Contact Phone** (optional): The phone number of the contact person.
* **Contact Email** (optional): The email address of the contact person.
* **Delivery Date**: The date on which the document is to be delivered.
* **Delivery Time**: The time on which the document is to be delivered.
* **Delivery Method**: The method of delivery (Select from options: option 1, option 2, option 3).
* **Signature**: Any additional comments or remarks about the delivery (Not required).
* **Delivery Address**: A note for the delivery address (Not required).
* **Comments**: Any additional comments or remarks about the delivery (Not required).
* **Additional Comments**: Any additional comments or remarks about the delivery (Not required).
* **Delivery Instructions**: Any specific instructions for the delivery (Not required).
* **Delivery Status**: The current status of the document delivery (Select from options: option 1, option 2, option 3).
* **Assigned To**: The person assigned to handle the document delivery (Select from options: option 1, option 2, option 3).
* **Priority**: The level of priority for the document delivery (Select from options: option 1, option 2, option 3).
* **Follow Up**: Any follow-up information (Select from options: option 1, option 2, option 3).
* **Due Date**: The due date for any follow-up actions (Not required).
* **Comments**: Any additional comments or remarks about the delivery (Not required).
* **Delivery Method Note**: A note for the delivery method (Not required).
* **Remarks**: Any additional comments or remarks about the delivery (Not required).
