# Do Not Contact Request Form - Help Guide
## Purpose
The Do Not Contact Request Form is used to document and manage contact requests in a business setting. It helps keep track of contact requests, their status, and the person(s) involved.

## How To Complete This Form
To fill out this form, follow these steps:

1. Review the form fields and ensure you have all the necessary information before proceeding.
2. Select the contact type (e.g., Email, Phone, SMS, or Mail).
3. Enter the email address (if selecting Contact Email) or phone number (if selecting Contact Phone).
4. Add any additional contact notes, if necessary.
5. Choose the person submitting the form (or select 'System').
6. Select the recipient of the contact request (or select multiple recipients if required).
7. Add any notes for the submitter.
8. Update the contact request status (if necessary).

## Field-by-Field Explanation
* **Contact Request**: This text field is used to enter a brief description of the contact request.
* **Contact Type**: Select the type of contact method used for the request (Contact Email, Contact Phone, Contact Mail, or Contact SMS).
* **Email**: Enter the email address associated with the contact request (if selecting Contact Email).
* **Phone**: Enter the phone number associated with the contact request (if selecting Contact Phone).
* **Contact Note**: Add any additional notes or information related to the contact request.
* **Contact Request Date**: Enter the date the contact request was made.
* **Contact Request Time**: Enter the time the contact request was made.
* **Submitted By**: Select the person submitting the form (or select 'System').
* **Submitted To**: Select the recipient(s) of the contact request (or select multiple recipients if required).
* **Notes**: Add any additional notes or comments related to the contact request.
* **Submitter Note**: Add any notes or comments from the person submitting the form.
* **Contact Request Status**: Update the status of the contact request (New, In Progress, Complete, or Cancelled).
