# Cabinet Design Questionnaire - Help Guide
## Purpose
This form is designed to gather information for a cabinet design project, helping our designers create a tailored solution that meets your specific needs and preferences. Please complete this form to provide detailed information about your project, including client and project details, design preferences, and functional requirements.

## How To Complete This Form
To complete this form, simply fill in the required fields and select relevant options for each section. You can refer to the field-by-field explanations below for more information on what each field is asking.

## Field-by-Field Explanation

### 1. Full Name (id: 2)
* **Full Name**: This field is a required text input where you can enter your full name.

### 2. Project Address (id: 3)
* **Project Address**: This field is a required text input where you can enter the address of the project location.

### 3. Contact Phone (id: 4)
* **Contact Phone**: This field is a required text input where you can enter your contact phone number.

### 4. Which rooms require cabinet design (id: 6)
* **Which rooms require cabinet design**: This field is a select multiple input where you can select all applicable rooms that require cabinet design. Options include:
	+ Kitchen
	+ Master Bathroom
	+ Guest Bathroom
	+ Laundry Room
	+ Home Office
	+ Mudroom
	+ Entertainment Center

### 5. Project Type (id: 7)
* **Project Type**: This field is a select one input where you can choose the type of project you are undertaking. Options include:
	+ New Construction
	+ Full Remodel
	+ Partial Update
	+ Cabinet Refacing Only

### 6. Estimated Budget (id: 8)
* **Estimated Budget**: This field is a select one input where you can choose your estimated budget for the cabinet design project, excluding appliances and labor. Options include:
	+ Under $10k
	+ $10k to $25k
	+ $25k to $50k
	+ $50k Plus

### 7. Desired Installation Timeframe (id: 9)
* **Desired Installation Timeframe**: This field is a select one input where you can choose your desired installation timeframe for the cabinet design project. Options include:
	+ Immediate
	+ 1 to 3 Months
	+ 3 to 6 Months
	+ 6 Months Plus

### 8. Key Storage Priorities (id: 11)
* **Key Storage Priorities**: This field is a select multiple input where you can select the storage priorities for your project. Options include:
	+ Pantry Space
	+ Pot and Pan Drawers
	+ Spice Pull-outs
	+ Trash/Recycle Centers
	+ Corner Solutions
	+ Tray Dividers

### 9. Preferred Cabinet Height (id: 12)
* **Preferred Cabinet Height**: This field is a select one input where you can choose the preferred cabinet height for your project. Options include:
	+ To the Ceiling
	+ Standard 30/36 inch
	+ Staggered Heights

### 10. Planned Appliances (id: 13)
* **Planned Appliances**: This field is a text input where you can list the planned appliances for your project.

### 11. Preferred Door Style (id: 15)
* **Preferred Door Style**: This field is a select one input where you can choose your preferred door style for your project. Options include:
	+ Shaker
	+ Raised Panel
	+ Flat/Slab
	+ Inset
	+ Mitered

### 12. Preferred Material/Wood Species (id: 16)
* **Preferred Material/Wood Species**: This field is a select one input where you can choose your preferred material/wood species for your project. Options include:
	+ Maple
	+ Cherry
	+ Oak
	+ Walnut
	+ MDF/Painted
	+ Laminate

### 13. Special Architectural Features (id: 17)
* **Special Architectural Features**: This field is a text input where you can enter special architectural features for your project, e.g. crown molding, glass doors, lighting.

### 14. Specific Questions for our Designer (id: 18)
* **Specific Questions for our Designer**: This field is a text input where you can ask specific questions or provide additional information for our designer.
