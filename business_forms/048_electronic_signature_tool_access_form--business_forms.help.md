# electronic-signature-tool-access-form - Help Guide
## Purpose
This form is used to request access to the Electronic Signature Tool within an organization. It gathers essential user information, selects the tool to be accessed, and tracks dates related to the access request process.

## How To Complete This Form
1. Fill out the required fields:
	* User Name
	* Role
	* Email
	* Assigned Tool (select "chatjimmy" or "other")
	* Organization (select one or multiple organizations)
	* Category (select "Business Forms")
	* Due Date
	* Assigned Date
2. Optionally, provide additional information:
	* Phone (if applicable)
	* Description (if necessary)
	* Form Title (if required by the organization)
	* Form Description (if needed)
	* Form Category (if necessary)
	* Form ID (if required by the organization)
	* Output File (if required)
3. Review and submit the form for review and approval.

## Field-by-Field Explanation

* **User Name** (Text, Required): Enter your name for reference purposes.
* **Role** (Select One, Required): Choose your role within the organization (e.g., Administrator, Manager, User).
* **Email** (Email, Required): Enter your work email address.
* **Phone** (Text, Optional): Enter your work phone number (if applicable).
* **Assigned Tool** (Select One, Required): Choose the tool you want to access (e.g., chatjimmy, other).
* **Description** (Note, Optional): Provide a brief description of your request (if necessary).
* **Organization** (Select Multiple, Required): Select one or multiple organizations you belong to.
* **Category** (Select One, Required): Choose the category for your access request (e.g., Business Forms).
* **Due Date** (Date, Required): Enter the due date for your access request.
* **Assigned Date** (Date, Required): Enter the assigned date for your access request.
* **Form Title** (Text, Optional): Enter a title for your access request (if required).
* **Form Description** (Text, Optional): Enter a description for your access request (if needed).
* **Form Category** (Select One, Required): Choose the category for your access request (e.g., Electronic Signature Tool Access Form).
* **Form ID** (Text, Optional): Enter a unique ID for your access request (if required).
* **Output File** (Text, Optional): Enter the output file required for your access request (if necessary).
* **Tool Name** (Text, Optional): Enter a name for the tool you want to access (if necessary).
* **Submitted Date** (Date, Optional): Enter the submitted date for your access request (if required).

## Tips

* Make sure to fill out all required fields accurately and completely.
* Provide additional information when necessary to ensure your access request is processed correctly.
* Review your form submission carefully before submitting it for review and approval.
* If you encounter any issues or have questions, contact your organization's support team.
