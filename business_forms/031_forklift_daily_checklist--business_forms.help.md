# Forklift Daily Checklist - Help Guide
## Purpose

The Forklift Daily Checklist is a form used by forklift operators to report their daily status on various equipment and safety items. This form helps ensure that forklifts are properly maintained, inspected, and ready for use.

## How To Complete This Form

1. Review each question carefully and answer accordingly.
2. Select the correct option for each question based on the forklift's current status.
3. Ensure that all required fields are filled out.

## Field-by-Field Explanation

* **Pre Start Checklist** (`pre_start_checklist`, `select_one`, required: false): Check if the forklift's pre-start checklist is complete. Select 'Yes' if it is, 'No' otherwise.
* **Engine Oil Level** (`engine_oil_level`, `select_multiple`, required: true): Report the engine oil level. Select 'High' if the level is above the recommended minimum, 'Low' if it is below the recommended minimum.
* **Battery Charge** (`battery_charge`, `select_one`, required: false): Check if the forklift's battery is fully charged. Select 'Yes' if it is, 'No' otherwise.
* **Hydraulic Oil Level** (`hydraulic_oil_level`, `select_multiple`, required: false): Report the hydraulic oil level. Select 'High' if the level is above the recommended minimum, 'Low' if it is below the recommended minimum.
* **Parking Brake** (`parking_brake`, `select_one`, required: false): Check if the parking brake is engaged. Select 'Yes' if it is, 'No' otherwise.
* **Horn** (`horn`, `select_one`, required: false): Check if the horn is functioning properly. Select 'Yes' if it is, 'No' otherwise.
* **Steering Wheel** (`steering_wheel`, `select_one`, required: false): Check if the steering wheel is in good condition. Select 'Yes' if it is, 'No' otherwise.
* **Lights** (`lights`, `select_multiple`, required: false): Report the status of the forklift's lights. Select 'Yes' if they are working, 'No' otherwise.
* **Fire Suppressant** (`fire_suppressant`, `select_one`, required: false): Check if the fire suppressant system is functioning properly. Select 'Yes' if it is, 'No' otherwise.
* **Parking Area Clean** (`parking_area_clean`, `select_multiple`, required: false): Report the parking area's cleanliness. Select 'Yes' if it is clean, 'No' otherwise.
* **Inspection Tag** (`inspection_tag`, `select_multiple`, required: false): Check if the forklift is wearing an inspection tag. Select 'Yes' if it is, 'No' otherwise.
* **Inspection Area** (`inspection_area`, `text`, required: true): Record the area where the forklift was inspected. Enter the correct area here.
* **Pre-operations Checklist** (`pre_operations_checklist`, `select_one`, required: false): Check if the pre-operations checklist is complete. Select 'Yes' if it is, 'No' otherwise.
* **Post-operations Checklist** (`post_operations_checklist`, `select_one`, required: false): Check if the post-operations checklist is complete. Select 'Yes' if it is, 'No' otherwise.
* **Post Start Checklist** (`post_start_checklist`, `select_one`, required: false): Check if the post-start checklist is complete. Select 'Yes' if it is, 'No' otherwise.
* **Fuel** (`fuel`, `select_one`, required: false): Check if the forklift has fuel. Select 'Yes' if it does, 'No' otherwise.
* **Fuel Type** (`fuel_type`, `select_one`, required: false): Report the type of fuel in the forklift. Select the correct type here.
* **Engine** (`engine`, `select_one`, required: false): Check if the engine is functioning properly. Select 'Yes' if it is, 'No' otherwise.
* **Transmission** (`transmission`, `select_one`, required: false): Check if the transmission is functioning properly. Select 'Yes' if it is, 'No' otherwise.
* **Brake** (`brake`, `select_one`, required: false): Check if the forklift's brake is functioning properly. Select 'Yes' if it is, 'No' otherwise.
* **Tire** (`tire`, `select_one`, required: false): Check if the tires are in good condition. Select 'Yes' if they are, 'No' otherwise.
* **Oil** (`oil`, `select_one`, required: false): Check if the oil is at the recommended level. Select 'Yes' if it is, 'No' otherwise.
* **Air** (`air`, `select_one`, required: false): Check if the forklift has air. Select 'Yes' if it does, 'No' otherwise.
* **Electrical** (`electrical`, `select_one`, required: false): Check if the forklift's electrical components are functioning properly. Select 'Yes' if they are, 'No' otherwise.
* **Safety** (`safety`, `select_one`, required: false): Check if the forklift's safety features are functioning properly. Select 'Yes' if they are, 'No' otherwise.
