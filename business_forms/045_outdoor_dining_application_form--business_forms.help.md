# Outdoor Dining Application Form - Help Guide
## Purpose
This form is used to apply for outdoor dining events or reservations at a business or establishment. It collects information about the event, form submitter's details, and other relevant specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Application Information section with any necessary details about the event.
2. Select the Form of Payment for the event.
3. Choose a Reservation Time and Date for the event.
4. Select the Establishment Name and Address where the event will take place.
5. Choose the Event Type (e.g., Wedding, Birthday, Anniversary).
6. Provide any Special Instructions or Requirements for the event.
7. Fill in the Form Submitter's Name, Email, and Phone Number.
8. Provide any Additional Comments about the event.
9. Select the Event Capacity and Event Duration.
10. Choose the Event Start and End Time.
11. Enter any Additional Details about the event.

## Field-by-Field Explanation

* **Application Information**: Please provide all necessary details about the event.
* **Form of Payment**: Select the method of payment (Credit Card, Cash, or Other).
* **Reservation Time**: Please select a time for the event.
* **Reservation Date**: Please select a date for the event.
* **Establishment Name**: Enter the name of the establishment where the event will take place.
* **Establishment Address**: Enter the address of the establishment where the event will take place.
* **Event Type**: Choose the type of event (e.g., Wedding, Birthday, Anniversary).
* **Special Instructions**: Provide any special instructions or requirements for the event.
* **Special Requests**: Enter any special requests or instructions for the event.
* **Event Capacity**: Enter the number of guests attending the event.
* **Event Start Time**: Select the start time of the event.
* **Event End Time**: Select the end time of the event.
* **Event Duration**: Choose the duration of the event (e.g., Half Hour, One Hour, Two Hours).
* **Form Submitter's Name**: Enter your name as the form submitter.
* **Form Submitter's Email**: Enter your email address as the form submitter.
* **Form Submitter's Phone Number**: Enter your phone number as the form submitter.
* **Payment Details**: Enter any payment details (e.g., credit card number).
* **Other Payment Method**: Select any other payment method.
* **Other Payment Method Details**: Enter any additional details about the other payment method.
* **Special Instructions 2**: Provide any special instructions or requirements for the event.
* **Special Requirements**: Choose any special requirements for the event (e.g., Food Allergies, Dietary Restrictions).
* **Special Requests**: Enter any special requests or instructions for the event.
* **Additional Comments**: Enter any additional comments about the event.
