# Project Scope Checklist - Help Guide
## Purpose
The Project Scope Checklist is a tool for project managers and team members to document and review project scope details. It ensures that all stakeholders have a clear understanding of the project's objectives, deliverables, timeline, budget, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the project in the **Project Description** field.
2. List the project's objectives in the **Project Objectives** field.
3. Specify the project's deliverables, if any, in the **Project Deliverables** field.
4. Provide a date for the project's start and end in the **Project Timeline** field.
5. Enter the project's budget, if applicable, in the **Project Budget** field.
6. Indicate whether the project team is involved in the **Project Team** field.
7. Specify the project's location, if applicable, in the **Project Location** field.
8. Choose the current project status from the options provided in the **Project Status** field.
9. Optionally, attach a project scope document in the **Project Scope Document** field.
10. Enter any additional comments about the project scope in the **Project Scope Checklist Comments** field.
11. Specify who reviewed the project scope in the **Project Scope Checklist Reviewer** field.
12. Enter the date the project scope was reviewed in the **Project Scope Checklist Date** field.
13. Choose the format of the project scope document (e.g., Word, PDF) in the **Project Scope Checklist Version** field.

## Field-by-Field Explanation

* **Project Description**: A brief description of the project.
* **Project Objectives**: A list of the project's main goals and objectives.
* **Project Deliverables**: A list of what the project will deliver, e.g., software, report, document.
* **Project Timeline**: The project's start and end dates.
* **Project Budget**: The project's budget, if applicable.
* **Project Team**: A list of team members involved in the project, either "Yes" or "No".
* **Project Location**: The project's location, if applicable.
* **Project Status**: The current project status, either "Active" or "Inactive".
* **Project Scope Document**: An optional attachment of the project scope document.
* **Project Scope Checklist Comments**: Any additional comments about the project scope.
* **Project Scope Checklist Reviewer**: The person who reviewed the project scope.
* **Project Scope Checklist Date**: The date the project scope was reviewed.
* **Project Scope Checklist Version**: The format of the project scope document, e.g., Word, PDF.
