# Home Backup Generator Order Form - Help Guide
## Purpose
This form is used to gather information from customers who are interested in purchasing a backup generator for their home. It is not a real order form, but rather a sample of what a possible order form could look like in the real-world.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in your user information, including your name and any other relevant details.
2. Select the backup generator model you are interested in (Model A, Model B, or Model C).
3. Choose the features you would like to include in your backup generator (Feature 1, Feature 2, or Feature 3).
4. Provide your contact information, including your name, email address, and phone number.
5. Enter your contact address.

## Field-by-Field Explanation
### User Information
* **Name**: This is where you enter your name.
* **Backup Generator Model**: This is where you select the type of backup generator you are interested in.
*  - Model A: This is a backup generator with feature 1.
*  - Model B: This is a backup generator with feature 2.
*  - Model C: This is a backup generator with feature 3.
* **Backup Generator Features**: This is where you select the features you would like to include with your backup generator.
*  - Feature 1: This feature provides [briefly describe feature 1].
*  - Feature 2: This feature provides [briefly describe feature 2].
*  - Feature 3: This feature provides [briefly describe feature 3].
* **Contact Information**: This is where you enter your contact information.
*  - **Name**: This is where you enter your name.
*  - **Email**: This is where you enter your email address.
*  - **Phone**: This is where you enter your phone number.
*  - **Address**: This is where you enter your address.

Note: The exact descriptions for the features will depend on the actual features of the backup generators. For the purpose of this guide, they are left blank.
