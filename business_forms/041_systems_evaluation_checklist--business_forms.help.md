# Systems Evaluation Checklist - Help Guide
## Purpose
The Systems Evaluation Checklist is a form used to evaluate or track project progress. It captures information about project manager details, project status, satisfaction, and risk assessment. This form helps project managers and teams to assess project effectiveness, identify areas for improvement, and make data-driven decisions.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project manager's name in the "Project Manager Name" field.
2. Enter the project manager's email address in the "Project Manager Email" field.
3. Rate the system's effectiveness using the "Systems Effectiveness Rating" field.
4. Rate the project's efficiency using the "Efficiency Rating" field.
5. Select your overall satisfaction level for the project using the "Overall Satisfaction" field.
6. Choose the current project status using the "Project Status" field.
7. Enter the date the project was completed using the "Date Of Completion" field.
8. Enter the time the project took to complete using the "Time Of Completion" field.
9. Describe the project using the "Project Description" field.
10. Enter any additional notes about the project using the "Notes" field.

12. Enter the project lead's name using the "Project Lead Name" field.
13. Enter the project lead's email address using the "Project Lead Email" field.
14. Enter the project lead's phone number using the "Project Lead Phone" field.
15. Enter the project lead's department using the "Project Lead Department" field.
16. Enter the project start date using the "Project Start Date" field.
17. Enter the project end date using the "Project End Date" field.
18. Enter the project budget using the "Project Budget" field.
19. Describe the project scope using the "Project Scope" field.
