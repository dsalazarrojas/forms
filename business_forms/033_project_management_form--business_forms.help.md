# Project Management Form - Help Guide
## Purpose
The Project Management Form is used to collect and track information about projects within the organization. This form helps the project team to have a centralized view of all ongoing and upcoming projects, allowing them to better manage resources, priorities, and deadlines.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the **Project Name** in the first field. This is the title of the project, and it should be a unique identifier for the project.
2. Provide the **Project Start Date** and **Project Deadline** dates if applicable. These dates help track the project timeline.
3. Select the **Project Status** from the available options (Active or Inactive). This helps the project team to know if the project is ongoing or not.
4. Select multiple **Project Resources** from the available options (Yes or No).
5. Enter the **Project Manager's** contact information, including their name and email address.
6. Enter the **Project Manager Phone** number.
7. Add any additional notes in the **Project Manager Note** field for further communication or context.

## Field-by-Field Explanation
- **Project Name** (`project_name`, text, required): Enter the title of the project, which should be a unique identifier for the project.
- **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project.
- **Project Deadline** (`project_deadline`, date, optional): Enter the deadline of the project.
- **Project Status** (`project_status`, select_one, optional): Select the status of the project (Active or Inactive).
- **Status Options** (`project_status_options`, text, optional): This field is currently not used, but it could potentially be used for additional status information.
- **Project Resources** (`project_resources`, select_multiple, optional): Select multiple project resources (Yes or No).
- **Resources Options** (`project_resources_options`, text, optional): This field is currently not used, but it could potentially be used for additional resources information.
- **Project Manager** (`project_manager`, text, optional): Enter the project manager's name.
- **Project Manager Email** (`project_manager_email`, email, optional): Enter the project manager's email address.
- **Project Manager Phone** (`project_manager_phone`, text, optional): Enter the project manager's phone number.
- **Project Manager Note** (`project_manager_note`, note, optional): Add any additional notes for the project manager.
