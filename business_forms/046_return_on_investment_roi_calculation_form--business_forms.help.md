# Return On Investment (ROI) Calculation Form - Help Guide
## Purpose
The Return On Investment (ROI) Calculation Form is a standard tool for project managers and team members to assess the financial efficiency of a project.

## How To Complete This Form
To complete the form, follow these steps:

1. Provide details about the project in the Project Details field.
2. Enter the expected return for the project in the Expected Return field.
3. Enter the actual return for the project in the Actual Return field.
4. Provide the project duration in the Project Duration field.
5. Enter the total investment for the project in the Investment field.
6. Enter the expected investment for the project in the Expected Investment field.
7. Enter the actual investment for the project in the Actual Investment field.
8. Select the project type from the Project Type field.
9. Select any relevant tags from the Tags field.
10. Enter the project date in the Date field (optional).
11. Enter the project time in the Time field (optional).
12. Add any additional notes about the project in the Note field.
13. Enter the project manager's email address in the Email field (optional).
14. Enter the project manager's phone number in the Phone field (optional).
15. Select the project frequency from the Frequency field.
16. Select the departments involved in the project from the Departments field.
17. Select the project's categories from the Categories field.
18. Select the project status from the Status field.
19. Select the project owners from the Owners field (optional).
20. Select any additional tags from the Tags 2 field (optional).

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required): Enter a brief description of the project.
* **Expected Return** (`expected_return`, number, optional): Enter the expected return for the project.
* **Actual Return** (`actual_return`, number, optional): Enter the actual return for the project.
* **Project Duration** (`project_duration`, number, optional): Enter the project duration.
* **Investment** (`investment`, number, optional): Enter the total investment for the project.
* **Expected Investment** (`expected_investment`, number, optional): Enter the expected investment for the project.
* **Actual Investment** (`actual_investment`, number, optional): Enter the actual investment for the project.
* **Project Type** (`select_one_project_type`, select one, optional): Select the project type (e.g., software development, marketing, etc.).
* **Tags** (`select_multiple_tags`, select multiple, optional): Select any relevant tags for the project.
* **Date** (`date`, date, optional): Enter the project date (if applicable).
* **Time** (`time`, time, optional): Enter the project time (if applicable).
* **Note** (`note`, text, optional): Add any additional notes about the project.
* **Email** (`email`, email, optional): Enter the project manager's email address (if applicable).
* **Phone** (`phone`, text, optional): Enter the project manager's phone number (if applicable).
* **Frequency** (`select_one_frequency`, select one, required): Select the project frequency (e.g., daily, weekly, monthly, etc.).
* **Departments** (`select_multiple_departments`, select multiple, required): Select the departments involved in the project.
* **Categories** (`select_multiple_categories`, select multiple, required): Select the project categories.
* **Status** (`select_one_status`, select one, required): Select the project status (e.g., ongoing, completed, pending, etc.).
* **Owners** (`select_multiple_owners`, select multiple, optional): Select the project owners (if applicable).
* **Tags 2** (`select_multiple_tags_2`, select multiple, optional): Select any additional tags for the project.
* **Status 2** (`select_multiple_status_2`, select multiple, optional): Select the project status 2 (if applicable).
