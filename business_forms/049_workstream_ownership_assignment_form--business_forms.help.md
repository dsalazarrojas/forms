# Workstream Ownership Assignment Form - Help Guide
## Purpose
The Workstream Ownership Assignment Form is a tool used to assign ownership and accountability for tasks, projects, or initiatives within a workstream. This form ensures that each project or task has a clear owner and accountability level, facilitating efficient tracking and reporting.

## How To Complete This Form
To complete this form, follow these steps:

1. **Project Name**: Enter the name of the project or task to be assigned.
2. **Project Leader**: Indicate whether the project has a leader assigned.
3. **Team Members**: List the team members involved in the project, if applicable.
4. **Start Date**: Enter the start date of the project or task.
5. **End Date**: Enter the end date of the project or task.
6. **Owner Name**: Enter the name of the person or team assigned as the owner of the project or task.
7. **Accountability Level**: Select the level of accountability for the project or task. You can choose from "High" or "Low".
8. **Other (please specify)**: If you selected "Low" accountability level, provide a brief explanation for why it's low.
9. **Assigned Tool**: Enter the name of the tool assigned to the project or task.
10. **Other (please specify)**: If you selected "Other" for the assigned tool, provide a brief explanation for the selected tool.

## Field-by-Field Explanation

* **Project Name**: Enter the name of the project or task to be assigned, which will help identify and track it within the workstream.
* **Project Leader**: Check "Yes" if the project has a designated leader, indicating clear ownership and leadership. If not applicable, select "No".
* **Team Members**: List all team members involved in the project, if applicable, to ensure everyone is informed and on board.
* **Start Date**: Enter the start date of the project or task, which will help track deadlines and milestones.
* **End Date**: Enter the end date of the project or task, which will help track completion and wrap-up.
* **Owner Name**: Enter the name of the person or team assigned as the owner of the project or task, ensuring clear accountability.
* **Accountability Level**: Choose from "High" or "Low" to indicate the level of responsibility and oversight required. This will influence the frequency and type of reporting and support needed for the project.
* **Other (please specify)**: If you selected "Low" accountability level, provide a brief explanation for why it's low, which will help the owner and stakeholders understand the scope and expectations.
* **Assigned Tool**: Enter the name of the tool assigned to the project or task, which will help ensure proper utilization and tracking.
* **Other (please specify)**: If you selected "Other" for the assigned tool, provide a brief explanation for the selected tool, ensuring clarity and consistency in tooling.
* **Accountabiltiy Level Other Specify**: This field is only visible if "Low" accountability level is selected. Enter a brief description to provide additional context for the low accountability level.
* **Assigned Tool Other**: This field is only visible if "Other" for the assigned tool is selected. Enter a brief description to provide additional context for the assigned tool.

## Tips

* Please ensure to fill out all required fields to avoid incomplete or duplicate records.
* This form should be used only once for each project or task to avoid conflicts and miscommunication.
* If you're unsure about any field, refer to your project manager or team lead for guidance.
