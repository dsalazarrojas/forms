# Franchise Agreement Verification Form - Help Guide
## Purpose
This form is designed for verifying franchise agreements for internal use within a company or organization that deals with franchises.

## How To Complete This Form
1. Select the Agreement Type from the options provided.
2. Enter the Start Date and End Date of the franchise agreement.
3. Fill in the Franchise Owner Name and Address.
4. Select and upload the required documents (Document 1, Document 2, and Document 3).
5. Enter any additional information about the franchise agreement in the Franchise Agreement field.
6. If applicable, enter the Franchise License and Franchise Certification details.
7. If necessary, add any other documents or information about the franchise in the Other Document and Other Notes fields.

## Field-by-Field Explanation

* **Agreement Type**: Select one or multiple types of agreements from the options provided.
* **Start Date**: Enter the start date of the franchise agreement.
* **End Date**: Enter the end date of the franchise agreement.
* **Franchise Owner Name**: Enter the name of the franchise owner.
* **Franchise Owner Address**: Enter the address of the franchise owner.
* **Prophets**: This field is not required and seems to be an optional field for additional information. 
* **Documents Uploaded**: Select the documents that have been uploaded for the franchise agreement.
	+ **Document 1**: Enter any additional information about Document 1.
	+ **Document 2**: Enter any additional information about Document 2.
	+ **Document 3**: Enter any additional information about Document 3.
* **Franchise Agreement**: Enter any additional information about the franchise agreement.
* **Franchise License**: If applicable, enter the details of the franchise license.
* **Franchise Certification**: If applicable, enter the details of the franchise certification.
* **Other Document**: If necessary, enter any other documents related to the franchise.
* **Other Notes**: If necessary, add any additional notes about the franchise.
* **Notes 1**, **Notes 2**, **Notes 3**, **Other Notes 1**, **Other Notes 2**, **Other Notes 3**, **Other Notes 4**, **Other Notes 5**: These fields are for additional notes and information about the franchise.
