# Crime Clearance Rate Report Form - Help Guide
## Purpose
The Crime Clearance Rate Report Form is used to report the clearance status of crimes and the current status of cases related to those crimes.

## How To Complete This Form
To complete this form, follow these steps:
- Fill out each field as accurately and completely as possible.
- If a field is not applicable, leave it blank.
- If you are unsure about a particular field, please contact your supervisor or relevant authorities for guidance.

## Field-by-Field Explanation
* **Crime Clearance Rate Form** (`title`, text, required): This is the title of the form, which is used to identify the form's purpose.
* **Agency** (`agency`, text, optional): This field is used to identify the agency or department that is responsible for the crime.
* **Crime Type** (`crime-type`, text, optional): This field is used to specify the type of crime that was committed.
* **Crime Date** (`crime-date`, date, optional): This field is used to record the date on which the crime was committed.
* **Reporting Period** (`reporting-period`, number, optional): This field is used to specify the reporting period for the crime (e.g. week, month, year).
* **Crime Clearance Rate** (`crime-clearance-rate`, number, optional): This field is used to report the clearance rate of the crime (e.g. 100% if the crime is cleared).
* **Clearance Status** (`clearance-status`, select one, optional): This field is used to report the clearance status of the crime, which can be:
	+ Cleared
	+ Not Cleared
	+ Unknown
* **Case Status** (`case-status`, select multiple, optional): This field is used to report the current status of the case related to the crime, which can be:
	+ Closed
	+ Active
	+ In progress

## Tips
- Please fill out this form accurately and completely.
- If you are unsure about a particular field, please contact your supervisor or relevant authorities for guidance.
- If you need to report multiple crimes, you will need to fill out this form multiple times.
