# Daily Task Checklist Form - Help Guide
## Purpose
The purpose of this form is to create and manage a list of daily tasks. Each task has a brief description, due date, and status. This form helps users stay on top of their tasks and deadlines.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter a brief description of each task under the corresponding "Task" fields.
2. Add a due date for each task under the "Due Date" field.
3. Select the status of each task under the "Status" field.
4. Add any additional notes about each task under the "Notes" field.

* **Due Date** (`task_1_due_date`, date, not required): Enter the due date of the task.
