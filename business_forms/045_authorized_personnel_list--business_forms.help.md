# Authorized Personnel List - Help Guide
## Purpose
The Authorized Personnel List is a document that outlines the personnel authorized to access certain areas, systems, or resources within the organization.

## How To Complete This Form
1.  Click on the "New Authorized Personnel List" button to start creating a new list.
2.  Fill in the "List Date" field with the date of this authorization list.
3.  Select the purpose of this list from the provided options (Building/Facility Access, Equipment Operation, Financial Transactions, Data Access, Admin Privileges, or Multi-Purpose).
4.  Enter the name of the department or division.
5.  Enter the name of the authorizing manager.
6.  Enter the title of the authorizing manager.
7.  Enter the email address of the authorizing manager.
8.  Select the effective date when this list takes effect.
9.  Select the expiration date when this list expires (if applicable).
10. For each authorized personnel, enter their full name, employee ID, job title, access level, and specific permissions (if applicable).

## Field-by-Field Explanation
*   **List Date (1)**: Date of this authorization list.
*   **Department or Division (2)**: Name of department.
*   **Purpose of This List (3)**: Select the purpose of this list.
*   **Authorizing Manager Name (4)**: Manager approving this list.
*   **Manager Title (5)**: Position of authorizing manager.
*   **Manager Email (6)**: Manager contact email.
*   **Effective Date (7)**: When does this list take effect.
*   **Expiration Date (8)**: When does this list expire (if applicable).
*   **Employee 1 - Full Name (9)**: Name of first authorized personnel.
*   **Employee 1 - Employee ID (10)**: Employee identification number.
*   **Employee 1 - Job Title (11)**: Current position.
*   **Employee 1 - Access Level (12)**: What level of access.
*   **Employee 1 - Specific Permissions (13)**: What can they access or do.
*   **Employee 2 - Full Name (14)**: Name of second authorized personnel.
*   **Employee 2 - Job Title (15)**: Current position.
*   **Employee 2 - Access Level (16)**: What level of access.
*   **Employee 3 - Full Name (17)**: Name of third authorized personnel.
*   **Employee 3 - Job Title (18)**: Current position.
*   **Employee 3 - Access Level (19)**: What level of access.
*   **Total Number of Authorized Personnel (20)**: Complete count of all personnel.
*   **Training Completion Required (21)**: Must personnel be trained.
*   **Security Clearance Status (22)**: Have background checks been done.
*   **Audit Trail / Activity Monitoring (23)**: Will activity be monitored.
*   **Additional Notes or Requirements (24)**: Any special conditions.

**Tips:**

*   Make sure to include all necessary information for each authorized personnel.
*   Review and verify the accuracy of the information before submitting.
*   Update the list as necessary to reflect changes in authorized personnel or conditions.
