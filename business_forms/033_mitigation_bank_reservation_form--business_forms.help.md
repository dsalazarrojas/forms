# Mitigation Bank Reservation Form - Help Guide
## Purpose
The Mitigation Bank Reservation Form is a crucial tool for collecting and tracking project information in the mitigation bank. This form helps to ensure that all necessary details are recorded accurately and efficiently.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the correct credit type for the project from the options provided.
2. Enter the start and end dates of the project.
3. Enter the credit amount.
4. Provide any necessary comments from the consultant and developer.
5. Choose the project status from the available options.
6. Select the person who reserved the credit.
7. Choose the tool assigned to the project.
8. Enter the email address of the person responsible for the project.
9. Enter the phone number of the person responsible for the project.
10. Add any additional notes about the project.
11. Select the person who reserved the project.
12. Enter the date and time when the credit was reserved.
13. (Optional) Enter the project ID and credit ID if applicable.
14. (Optional) Enter the creation and deletion dates if applicable.
15. (Optional) Enter the name of the project.
16. (Optional) Select the person assigned to the project.
17. (Optional) Select the person who created the project.
18. Select the Form ID.

## Field-by-Field Explanation

* **Project Name** (`Project Name`, text, required): Enter the name of the project.
* **Credit Type** (`Credit Type`, select_one, required): Choose the type of credit from the available options.
* **Start Date** (`Start Date`, date, required): Enter the start date of the project.
* **End Date** (`End Date`, date, required): Enter the end date of the project.
* **Credit Amount** (`Credit Amount`, number, required): Enter the amount of credit allocated to the project.
* **Consultant Comments** (`Consultant Comments`, note, optional): Enter any comments or remarks from the consultant.
* **Developer Comments** (`Developer Comments`, note, optional): Enter any comments or remarks from the developer.
* **Project Status** (`Project Status`, select_one, required): Choose the status of the project from the available options.
* **Credit Reserved By** (`Credit Reserved By`, select_one, required): Select the person who reserved the credit.
* **Assigned Tool** (`Assigned Tool`, select_one, required): Choose the tool assigned to the project.
* **Email Address** (`Email Address`, email, required): Enter the email address of the person responsible for the project.
* **Phone Number** (`Phone Number`, text, required): Enter the phone number of the person responsible for the project.
* **Notes** (`Notes`, note, optional): Add any additional notes or remarks about the project.
* **Reserved By** (`Reserved By`, select_one, required): Select the person who reserved the project.
* **Reserved Date** (`Reserved Date`, date, optional): Enter the date when the credit was reserved.
* **Reserved Time** (`Reserved Time`, time, optional): Enter the time when the credit was reserved.
* **Project ID** (`Project ID`, number, optional): Enter the project ID if applicable.
* **Credit ID** (`Credit ID`, number, optional): Enter the credit ID if applicable.
* **Created At** (`Created At`, date, optional): Enter the creation date of the project.
* **Updated At** (`Updated At`, date, optional): Enter the update date of the project.
* **Deleted At** (`Deleted At`, date, optional): Enter the deletion date of the project.
* **Assigned to** (`Assigned to`, select_one, required): Select the person assigned to the project.
* **Form ID** (`Form ID`, number, required): Enter the Form ID.
* **Created By** (`Created By`, select_one, optional): Select the person who created the project.
* **Project Name** (`Project Name`, text, required): Enter the name of the project.
* **Reserved By** (`Reserved By`, select_one, required): Select the person who reserved the project.
