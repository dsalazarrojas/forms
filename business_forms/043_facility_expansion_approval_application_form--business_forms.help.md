# Facility Expansion Approval Application Form - Help Guide
## Purpose
This form is for project managers to submit their facility expansion applications to their superiors for approval.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the correct project details, facility type, and project manager information.
2. Choose the correct facility ID and manager email.
3. Enter the project start and end dates, project budget, and submission date.
4. Select the project status and category.
5. Enter any additional notes about the project.
6. Enter the submission date and time.
7. Enter any additional comments or notes about the project.

## Field-by-Field Explanation

* **Project Details**: This field is used to enter a brief description of the project.
* **Facility Type**: Select the type of facility expansion project you are requesting approval for.
* **Project Manager**: Enter the name of the project manager.
* **Project Manager Email**: Enter the email address of the project manager.
* **Facility Address**: Enter the address of the facility.
* **Project Start Date**: Enter the start date of the project.
* **Project End Date**: Enter the end date of the project.
* **Project Budget**: Enter the budget for the project.
* **Project Status**: Select the current status of the project.
* **Notes**: Enter any additional notes about the project.
* **Submission Date**: Enter the date of submission.
* **Submitted By**: Enter the email address of the person submitting the application.
* **Project Location**: Enter the location of the project.
* **Project Description**: Enter a brief description of the project.
* **Project Manager Phone**: Enter the phone number of the project manager.
* **Facility Size**: Enter the size of the facility.
* **Project Manager Name**: Enter the name of the project manager.
* **Submission Time**: Enter the time of submission.
* **Project Category**: Enter the category of the project.
* **Project Notes**: Enter any additional notes about the project.
* **Submitted User ID**: Enter the ID of the person submitting the application.
* **Facility ID**: Select the ID of the facility.
* **Manager Email**: Enter the email address of the manager.
* **Manager Phone**: Enter the phone number of the manager.
* **Phone**: Enter the phone number of the manager. 

Note: The "Manager Phone" field has been duplicated, please use the correct field "Manager Phone" and "Manager Phone" will be removed.
