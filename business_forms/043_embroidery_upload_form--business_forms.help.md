# Embroidery Upload Form - Help Guide
## Purpose
This form is used for uploading embroidery files for various tasks such as creating custom designs, editing customer orders, and managing embroidery production. It ensures correct file categorization, sizing, and customer attribution.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of file you are uploading (PDF, BMP, JPEG, or PNG).
2. Upload the relevant file from your device.
3. Enter the name of the file.
4. Choose an upload date and time for the file.
5. If relevant, provide the customer's name, phone number, and email address.
6. Click the "Submit" button to upload the file.

## Field-by-Field Explanation

* **Upload Your File**: Upload the embroidery file (.PDF, .BMP, .JPEG, or .PNG) to be uploaded.
* **File Name**: Enter the name of the file, which will be used for reference and organization.
* **File Size (MB)**: Enter the size of the uploaded file in megabytes (MB). This helps ensure the file does not exceed system limitations.
* **Upload Type**: Select the type of file you are uploading. This is crucial for proper processing and categorization.
* **Upload Date**: Choose the date you want to upload the file. This helps with tracking and organization.
* **Upload Time**: Choose the time you want to upload the file. This complements the date selection.
* **Customer Name**: If you're uploading a file related to a specific customer, enter their name for accurate tracking and billing purposes.
* **Customer Phone**: If you have the customer's phone number, enter it for further communication and contact.
* **Customer Email**: If you have the customer's email address, enter it for billing and communication purposes.

## Tips
* Please ensure the file size is reasonable to avoid overwhelming the system.
* Make sure to select the correct file type for proper processing.
* If you're unsure about any field, refer to the instructions above or contact your administrator for guidance.
