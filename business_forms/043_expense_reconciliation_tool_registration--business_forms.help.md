# Expense Reconciliation Tool Registration - Help Guide
## Purpose
The Expense Reconciliation Tool Registration form is used to collect and manage information about tools used by employees for expense reporting and reconciliation.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the employee who used the tool.
2. Enter the tool name.
3. Enter the start and end dates of the tool usage.
4. Select the tool type.
5. Select the tool status.
6. Select whether the tool is assigned to an employee.
7. Enter the user ID and form ID for the tool.
8. Repeat steps 4-7 for additional tools if necessary.

## Field-by-Field Explanation
* **Employee**: Select the employee who used the tool. This field helps track which employee is associated with the tool.
* **Email**: Enter the email address of the employee who used the tool. This field is not always required, but it can be useful for further verification.
* **Phone**: Enter the phone number of the employee who used the tool. Like the email field, this is not always required but can be helpful.
* **Tool Name**: Enter the name of the tool used. This is a critical field as it helps identify the tool being reported.
* **Start Date**: Enter the date the tool was first used. This date should be the earliest date the tool was used.
* **End Date**: Enter the date the tool was last used. This date should be the latest date the tool was used.
* **Tool Type**: Select the category or type of tool used (e.g., "Yes" or "No"). This field helps categorize and manage different tools.
* **Tool Status**: Select the current status of the tool (Active or Inactive). This helps track the tool's availability.
* **Assigned Tool**: Select whether the tool is assigned to an employee or not. This field is important for tracking ownership and responsibility.
* **User ID**: Enter a unique identifier for the user who used the tool. This is a unique number assigned to each user.
* **Form ID**: Enter a unique identifier for the form used. This is a unique number assigned to each form.
* **Assigned Tool 2**: Select whether the second tool is assigned to an employee or not.
* **Tool 2 Type**: Select the category or type of second tool used.
* **User ID 2**: Enter a unique identifier for the user who used the second tool.
* **Form ID 2**: Enter a unique identifier for the form used for the second tool.
* **Tool 2 ID**: Enter a unique identifier for the second tool.
* **Tool 3 Type**: Select the category or type of third tool used.
* **Tool 3 Status**: Select the current status of the third tool (Active or Inactive).
* **User ID 3**: Enter a unique identifier for the user who used the third tool.
* **Form ID 3**: Enter a unique identifier for the form used for the third tool.
* **Tool 3 ID**: Enter a unique identifier for the third tool.
* **Tool 3 Type**: Select the category or type of third tool used.
* **Tool 4 ID**: Enter a unique identifier for the fourth tool.
* **User ID 4**: Enter a unique identifier for the user who used the fourth tool.
* **Form ID 4**: Enter a unique identifier for the form used for the fourth tool.
* **Tool 4 ID**: Enter a unique identifier for the fourth tool.

## Tips
- Make sure to select the correct employee, tool, and dates to ensure accurate expense reporting and reconciliation.
- Double-check the tool status and assigned tool fields to ensure correct tracking.
- Enter all required fields to avoid incomplete submissions.
- If unsure about a field, refer to the provided options or contact your supervisor for clarification.
