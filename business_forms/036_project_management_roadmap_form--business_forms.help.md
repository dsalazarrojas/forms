# Project Management Roadmap Form - Help Guide
## Purpose
This form is designed to provide a structured approach to managing and monitoring projects within the organization.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out the project details section:
	* **Project Objectives**: Briefly describe the objectives of the project. This should be a concise and clear statement of what the project aims to achieve.
2. Determine project milestones:
	* **Project Milestones**: Select the milestones that are relevant to the project. This will help in identifying key points in the project timeline.
3. Identify project owners:
	* **Project Owners**: Choose the team members or stakeholders who will be responsible for the project.
4. Assess project risks:
	* **Project Risks**: Document any potential risks or challenges that may impact the project.
5. Set up the project timeline:
	* **Project Timeline**: Input the start and end dates of the project.
6. Establish project deadline:
	* **Project Deadline**: Enter the deadline for the project completion.
7. Check the project status:
	* **Project Status**: Select the current status of the project.
8. Provide contact information for project owners:
	* **Project Owners Email**: Input the email address of the project owner(s).
	* **Project Owners Phone**: Enter the phone number of the project owner(s).
9. Add any additional project notes:
	* **Project Notes**: Enter any relevant notes or comments about the project.

## Field-by-Field Explanation

* **Project Objectives** (`project_objectives`, `text`, required: false): This field is used to describe the main goals and objectives of the project. It should be a clear and concise statement of what the project aims to achieve.
* **Project Milestones** (`project_milestones`, `select_multiple`, required: false):
	+ Select all the relevant milestones for the project. This will help in identifying key points in the project timeline.
* **Project Owners** (`project_owners`, `select_one`, required: false):
	+ Choose the team members or stakeholders who will be responsible for the project.
* **Project Risks** (`project_risks`, `note`, required: false): 
	+ Document any potential risks or challenges that may impact the project.
* **Project Timeline** (`project_timeline`, `date`, required: false): 
	+ Enter the start and end dates of the project.
* **Project Deadline** (`project_deadline`, `time`, required: false):
	+ Enter the deadline for the project completion.
* **Project Status** (`project_status`, `select_one`, required: false):
	+ Select the current status of the project.
* **Project Owners Email** (`project_owners_email`, `email`, required: false):
	+ Input the email address of the project owner(s).
* **Project Owners Phone** (`project_owners_phone`, `text`, required: false):
	+ Enter the phone number of the project owner(s).
* **Project Notes** (`project_notes`, `text`, required: false):
	+ Enter any relevant notes or comments about the project.

## Tips
- Be as specific as possible when filling out the form.
- Review and update the form regularly to reflect changes in the project status.
- If a project is completed, please remove it from this form to maintain accuracy.
