# Landlord Agreement Discharge Form - Help Guide
## Purpose
The Landlord Agreement Discharge Form is designed to document the discharge of a rental agreement between a landlord and a tenant. This form is used to collect information from both parties regarding the agreement, including the reason for discharge, dates of signing, and any notes or comments.

## How To Complete This Form
1. Fill out the form completely and accurately, providing all required and optional information.
2. Review the form carefully to ensure that all fields are filled out correctly.
3. If you have any questions or concerns, contact form@gic.mx for assistance.

## Field-by-Field Explanation
* **Landlord Information**: This field is for the landlord's details, including their name and contact information.
	+ Label: Landlord Information
	+ Type: Text
	+ Required: Optional
* **Tenant Information**: This field is for the tenant's details, including their name and contact information.
	+ Label: Tenant Information
	+ Type: Text
	+ Required: Optional
* **Property Information**: This field is for information about the rental property, such as its address.
	+ Label: Property Information
	+ Type: Text
	+ Required: Optional
* **Discharge Reason**: This field is for the reason why the rental agreement is being discharged.
	+ Label: Discharge Reason
	+ Type: Text
	+ Required: Optional
* **Landlord Sign Date**: This field is for the date when the landlord signed this form.
	+ Label: Landlord Sign Date
	+ Type: Date
	+ Required: Optional
* **Tenant Sign Date**: This field is for the date when the tenant signed this form.
	+ Label: Tenant Sign Date
	+ Type: Date
	+ Required: Optional
* **Landlord Note**: This field is for any additional comments or notes from the landlord.
	+ Label: Landlord Note
	+ Type: Note
	+ Required: Optional
* **Tenant Note**: This field is for any additional comments or notes from the tenant.
	+ Label: Tenant Note
	+ Type: Note
	+ Required: Optional

## Tips
