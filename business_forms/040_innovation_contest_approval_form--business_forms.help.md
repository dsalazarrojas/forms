# Innovation Contest Approval Form - Help Guide
## Purpose
The Innovation Contest Approval Form is used to collect information about an innovation, including its category, description, assigned tool, and approval status. This form helps in the evaluation and approval process of innovations within an organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the innovation from the provided options.
2. Provide a brief description of the innovation.
3. Identify the assigned tool for the innovation.
4. Determine if the innovation is a form or not.
5. If it is a form, enter the Form ID.
6. Specify the type of form it is (Business Forms or Other Forms).
7. Provide a description of the innovation.
8. Identify the tool(s) that would be used to implement this innovation.
9. Determine if the innovation is approved or not.
10. Specify the type of form it is (Form 1 or Form 2).

## Field-by-Field Explanation
### 1. What is the category of the innovation?
* **What is the category of the innovation?** (`form_id`, Select One, **required**): This field is used to select the category of the innovation. Choose the correct category from the provided options (Business Forms or Other Forms).
### 2. Please provide a brief description of the innovation.
* **Please provide a brief description of the innovation.** (`description`, Text, **required**): Type a short description of the innovation.
### 3. What is the assigned tool for the innovation?
* **What is the assigned tool for the innovation?** (`assigned_tool`, Text, **required**): Enter the name of the tool assigned to the innovation.
### 4. Is this innovation a form?
* **Is this innovation a form?** (`form_id_2`, Select One, **required**): Select 'True' if the innovation is a form, 'False' otherwise.
### 5. What is the Form ID?
* **What is the Form ID?** (`form_id_3`, Text, **required**): Enter the ID of the form if it is a form.
### 6. Is this innovation a Business Forms type?
* **Is this innovation a Business Forms type?** (`category`, Select One, **not required**): Select 'Business Forms' if the innovation is related to business forms, 'Other Forms' otherwise.
### 7. What is a description of the innovation?
* **What is a description of the innovation?** (`description_2`, Text, **required**): Type a brief description of the innovation.
### 8. What tool would be used to implement this innovation?
* **What tool would be used to implement this innovation?** (`assigned_tool_2`, Select Multiple, **required**): Select 'Yes' if the tool is to be used, 'No' otherwise, or enter a different tool in the text field.
### 9. Is this innovation approved?
* **Is this innovation approved?** (`form_id_4`, Radio, **required**): Select 'True' if the innovation is approved, 'False' otherwise.
### 10. What type of form is this innovation?
* **What type of form is this innovation?** (`category_2`, Select One, **required**): Select 'Form 1' or 'Form 2' to specify the type of form.
