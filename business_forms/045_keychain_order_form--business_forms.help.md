# Keychain Order Form - Help Guide

## Purpose
The Keychain Order Form is a digital form used to create and track orders for keychain products. It helps gather customer information, order details, and keychain customization options in a structured format.

## How To Complete This Form
To use this form, follow these steps:
1. Start by entering your customer's information on page 1, including name, contact phone number, and email address.
2. On page 2, select the desired keychain model and color from the provided options.
3. Enter any special instructions or text you'd like to appear on the keychain.
4. Select the sales channel for the order.
5. Finally, add any additional customer notes or comments.

## Field-by-Field Explanation
### Page 1
* **Customer Info** (`customer_info`, text): Enter the customer's information.
* **Customer Name** (`customer_name`, text): Enter the customer's name.
* **Email Address** (`email_address`, email): Enter the customer's email address.
* **Contact Phone** (`contact_phone`, number): Enter the customer's contact phone number.
* **Order Info** (`order_info`, text): Enter any additional order information.

### Page 2
* **Keychain Model** (`keychain_model`, select_one): Select the desired keychain model.
* **Keychain Color** (`keychain_color`, select_multiple): Select the desired keychain color.
* **Keychain Text** (`keychain_text`, note): Enter any special instructions or text you'd like to appear on the keychain.
* **Order Date** (`order_date`, date): Select the date for the order.
* **Order Time** (`order_time`, time): Select the time for the order.

### Additional Fields
* **Customer Notes** (`customer_notes`, text): Add any additional customer notes or comments.
* **Sales Channel** (`sales_channel`, select_one): Select the sales channel for the order.

### Tips
* Please ensure that all fields marked as "required" are filled out accurately and completely.
* Double-check your order details before submission to avoid errors.
* If you have any issues or questions, contact our support team for assistance.
