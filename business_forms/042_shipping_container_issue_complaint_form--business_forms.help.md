# Shipping Container Issue Complaint Form - Help Guide
## Purpose
This form collects information about shipping container issues reported by customers.

## How To Complete This Form
1. Fill in the required fields, indicated by an asterisk \*.
2. Enter the shipping container's unique ID.
3. Describe the issue with the shipping container.
4. Select the type and condition of the shipping container.
5. Choose the status of the issue (Open, Closed, or In Progress).
6. Choose the priority of the issue (Low or Medium).
7. Choose how the issue was resolved (Not Resolved or Resolved).
8. Enter the customer's name, email, and phone number.
9. Choose who last updated the issue (Admin or User).
10. If the issue is resolved, enter the date and time it was last updated.

## Field-by-Field Explanation

* **Shipping Container Issue Id**: \* (Required) - Enter the unique ID of the shipping container issue.
* **Description**: (Optional) - Describe the issue with the shipping container.
* **Shipping Container Type**: \* (Required) - Select the type of shipping container (Small, Large, or Other).
* **Condition**: \* (Required) - Select the condition of the shipping container (New or Used).
* **Customer Issue Description**: (Optional) - Add any additional details about the issue.
* **Customer Complaint Status**: \* (Required) - Select the status of the issue (Open, Closed, or In Progress).
* **Priority**: \* (Required) - Select the priority of the issue (Low or Medium).
* **Resolution**: \* (Required) - Select how the issue was resolved (Not Resolved or Resolved).
* **Customer Name**: \* (Required) - Enter the customer's name.
* **Customer Email**: \* (Required) - Enter the customer's email address.
* **Customer Phone**: \* (Required) - Enter the customer's phone number.
* **Shipping Container Issue Date**: (Optional) - Enter the date the issue occurred.
* **Shipping Container Issue Time**: (Optional) - Enter the time the issue occurred.
* **Shipping Container Issue Details**: (Optional) - Add any additional details about the issue.
* **Shipping Container Issue Image**: (Optional) - Upload an image of the shipping container issue.
* **Shipping Container Issue Attachment**: (Optional) - Attach any relevant documents or files to the issue.
* **Shipping Container Issue Notes**: (Optional) - Add any additional notes about the issue.
* **Shipping Container Issue Resolution Notes**: (Optional) - Add any additional resolution notes about the issue.
* **Shipping Container Issue Close Notes**: (Optional) - Add any additional close notes about the issue.
* **Shipping Container Issue Status Update**: (Optional) - Add any status updates about the issue.
* **Shipping Container Issue Last Updated**: (Optional) - Enter the date and time the issue was last updated.
* **Shipping Container Issue Last Updated By**: (Optional) - Choose who last updated the issue (Admin or User).
* **Shipping Container Issue Last Updated By User ID**: \* (Required) - Enter the ID of the user who last updated the issue.
* **Shipping Container Issue Last Updated By User**: \* (Required) - Choose who last updated the issue (Admin or User).

Note: Asterisk \* indicates a required field.
