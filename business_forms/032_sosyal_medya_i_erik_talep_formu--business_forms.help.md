# Sosyal Medya İcerik Talep Formu - Help Guide
## Purpose
This form is used to create and manage social media content requests. Please fill in the required fields to create a new request.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if the platform for the content request is "Yes" or "No".
2. Select the content type (e.g., "Yes", "No") for the content request.
3. Set a valid deadline for the content request.
4. Write a brief description of the content request.
5. Select the current status of the content request ("Open", "In Progress", "Closed").
6. Choose the tool assigned to fulfill the content request (e.g., "chatjimmy" or "Other").
7. Decide if an output file is required for the content request ("Yes", "No").

## Field-by-Field Explanation
- **Platform** (`platform_selection`, Required): Choose "Yes" if the content request is for a social media platform, "No" otherwise.
- **Content Type** (`content_type`, Required): Select the type of content requested (e.g., "Yes", "No").
- **Deadline** (`deadline`, Required): Enter a valid date for the content request.
- **Description** (`description`, Required): Provide a brief description of the content request.
- **Status** (`content_request_status`, Required): Choose the current status of the content request ("Open", "In Progress", "Closed").
- **Assigned Tool** (`assigned_tool`, Required): Select the tool assigned to fulfill the content request (e.g., "chatjimmy" or "Other").
- **Output File** (`output_file`, Required): Choose "Yes" if an output file is required for the content request, "No" otherwise.

## Tips
- Make sure to fill in all required fields to ensure the content request is properly created and managed.
- If you're unsure about any field, ask your team or refer to the relevant documentation for guidance.
