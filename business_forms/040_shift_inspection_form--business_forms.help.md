# shift_inspection_form - Help Guide
## Purpose
The Shift Inspection Form is a tool used to track and document information for employee shifts, including attendance, performance, and other relevant details.

## How To Complete This Form
To complete the Shift Inspection Form, follow these steps:

1. Begin by filling out the employee information, including the employee ID, which is a required field.
2. Answer the questions regarding the employee's attendance on each of the two designated shift dates. You can choose between 'Yes' or 'No' for each date.
3. Provide any additional comments or notes about the employee's performance and attendance, if necessary.
4. Select a date for the inspection, if relevant.
5. Select a time for the inspection, if relevant.
6. Enter the employee's email and phone number, if necessary.
7. Add any additional notes or comments about the employee.
8. Review and submit the form.

## Field-by-Field Explanation
* **Employee** (`shift_inspection_form_page_1`, `text`, required): Enter the employee's ID number. This field is used to identify the employee being inspected.
* **Performance** (`shift_inspection_form_page_2`, `select_one`, required): Answer 'Yes' or 'No' to indicate the employee's performance during the shift.
* **Attendance** (`shift_inspection_form_page_3`, `number`, required): Enter the number of hours the employee was present during the shift. This field is used to track the employee's attendance.
* **Shift** (`shift_inspection_form_page_4`, `select_multiple`, required): Select 'Yes' or 'No' for each shift date to indicate the employee's attendance on that date.
* **Comments** (`shift_inspection_form_page_5`, `text`, optional): Add any additional comments or notes about the employee's performance and attendance, if necessary.
* **Date** (`shift_inspection_form_page_6`, `date`, optional): Select a date for the inspection, if relevant.
* **Time** (`shift_inspection_form_page_7`, `time`, optional): Select a time for the inspection, if relevant.
* **Email** (`shift_inspection_form_page_8`, `email`, optional): Enter the employee's email address, if necessary.
* **Phone** (`shift_inspection_form_page_9`, `text`, optional): Enter the employee's phone number, if necessary.
* **Notes** (`shift_inspection_form_page_10`, `note`, optional): Add any additional notes or comments about the employee.
* **employee_id** (`shift_inspection_form_page_11`, `number`, required): Enter the employee's ID number. This is a required field to identify the employee being inspected.
