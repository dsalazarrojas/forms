# Event Debrief Form - Help Guide
## Purpose
The Event Debrief Form is used to gather information about events, including their dates, locations, status, types, outcomes, and comments. This form is designed to provide detailed insights into each event, which can be used for future reference, analysis, and decision-making.

## How To Complete This Form
To complete the Event Debrief Form, follow these steps:

1. Fill in the required information on each page.
2. On **Page 1: Event Debrief**, enter a brief description of the event.
3. On **Page 2: Event Date**, select the date of the event from the calendar.
4. On **Page 3: Start Time**, enter the start time of the event.
5. On **Page 4: End Time**, enter the end time of the event.
6. On **Page 5: Event Location**, enter the location of the event.
7. On **Page 6: Event Status**, select the status of the event (Active or Inactive).
8. On **Page 7: Event Type**, select the type of event (Yes or No).
9. On **Page 8: Event Outcome**, select the outcome of the event (Yes or No).
10. On **Page 9: Event Comments**, enter any additional comments about the event.
11. On **Page 10: Event Rating**, enter a rating for the event.
12. On **Page 11: Feedback**, enter any feedback or comments about the event.
13. On **Page 12: Feedback Notes**, enter any additional feedback or notes.
14. On **Page 13: Contact Person**, enter the name of the contact person.
15. On **Page 14: Contact Email**, enter the email of the contact person.
16. On **Page 15: Contact Phone**, enter the phone number of the contact person.
17. On **Page 16: Contact Cell**, enter the cell phone number of the contact person.
