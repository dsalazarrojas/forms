# General Work Order Form - Help Guide
## Purpose
The General Work Order Form is used to document and track general work orders for employees and customers. It provides a structured way to capture essential information about a work order, including task details, deadlines, and contact information.

## How To Complete This Form
To complete the General Work Order Form, follow these steps:

1. Fill in the "Work Order Form" section with a brief description of the work order.
2. Provide details about the task, including its status and assigned employee.
3. Specify whether materials are required for the task.
4. Enter the deadline and start date for the task.
5. Add any additional notes or comments.
6. Enter the email and phone number of the customer.
7. Enter the work order number and customer name.

## Field-by-Field Explanation
* **Work Order Form** (required): Enter a brief description of the work order.
* **Task Information** (optional): Provide details about the task, including any relevant information that will help the assigned employee understand what needs to be done.
* **Task Status** (optional): Select the current status of the task from the options: "Available", "In Progress", or "Completed".
* **Assigned Employee** (optional): Indicate whether the task has been assigned to an employee. Select "Yes" if the task has been assigned.
* **Materials** (optional): Specify whether materials are required for the task. Select "Yes" if materials are needed.
* **Deadline** (optional): Enter the deadline for the task.
* **Start Date** (optional): Enter the start date for the task.
* **Notes** (optional): Add any additional notes or comments about the task.
* **Email** (optional): Enter the email address of the customer.
* **Phone Number** (optional): Enter the phone number of the customer.
* **Work Order Number** (optional): Enter a unique work order number.
* **Customer Name** (optional): Enter the name of the customer.
* **Customer Email** (optional): Enter the email address of the customer.

## Tips
* Be sure to complete all required fields before submitting the form.
* Use the "Task Status" field to track the progress of the task.
* Use the "Materials" field to ensure that necessary materials are ordered or obtained for the task.
* Use the "Deadline" and "Start Date" fields to set realistic and achievable goals for the task.
* Use the "Notes" field to leave additional comments or instructions for the assigned employee.
* Use the "Email" and "Phone Number" fields to ensure that the customer can be contacted if needed.
* Use the "Work Order Number" field to reference the work order for future reference.
* Use the "Customer Name" field to keep track of the customer's name and identity.
