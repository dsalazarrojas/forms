# supplier_quality_assessment_form - Help Guide
## Purpose
This form is used to assess the performance and quality of a supplier. It helps to identify areas of improvement and evaluate the overall satisfaction of a supplier. The form is designed to be completed by users to provide an objective evaluation of the supplier's quality and performance.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the form and ensure you have all the necessary information about the supplier before starting.
2. For each section, select the option that best describes your experience with the supplier.
3. If you have any additional comments or observations, you can add them in the comments field (not shown in this guide).
4. Complete each section and submit the form when finished.

## Field-by-Field Explanation

* **Supplier Performance** (`supplier_performance`, select_one, required/optional):
	+ Select "Yes" if you have a positive experience with the supplier's performance.
	+ Select "No" if you have a negative experience with the supplier's performance.
* **Communication** (`communication`, select_multiple, required/optional):
	+ Select all options that apply to your experience with the supplier's communication.
	+ For example, if the supplier has communicated with you clearly and timely, select "Yes" for both "Yes" options.
* **Quality Control** (`quality_control`, select_one, required/optional):
	+ Select "Good" if you have a positive experience with the supplier's quality control processes.
	+ Select "Poor" if you have a negative experience with the supplier's quality control processes.
* **Reliability** (`reliability`, select_one, required/optional):
	+ Select "Yes" if you have a positive experience with the supplier's reliability.
	+ Select "No" if you have a negative experience with the supplier's reliability.
* **Supplier Satisfaction** (`supplier_satisfaction`, select_one, required/optional):
	+ Select "Satisfied" if you are satisfied with the supplier's service.
	+ Select "Dissatisfied" if you are dissatisfied with the supplier's service.

## Tips

* Please be honest and thorough in your assessment.
* Take your time to select the most accurate options for each field.
* If you are unsure about any field, ask a colleague or contact the supplier directly to clarify.
