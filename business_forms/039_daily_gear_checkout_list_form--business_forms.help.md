# Daily Gear Checkout List Form - Help Guide
## Purpose
This form is designed to help you track and manage daily gear checkouts. It's a simple tool to record the type of gear, event details, and other relevant information related to the gear checkout.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the `daily_gear_checkout_list_form` field with the description of the gear to be checked out.
2. Select the type of gear from the `gear_type` field. This field offers options like Microphone, Headphones, Lamps, and Projector.
3. Enter the date of the event in the `date_of_event` field using the date format (YYYY-MM-DD).
4. Enter the time of the event in the `time_of_event` field using the time format (HH:MM).
5. Provide a brief description of the event in the `event_description` field.
6. Enter the name of the person assigned to handle the gear in the `assigned_to` field.
7. Enter the name of the gear tool being checked out in the `assigned_tool` field.
8. Enter the date the gear was checked out in the `checkout_date` field using the date format (YYYY-MM-DD).

## Field-by-Field Explanation
* **daily_gear_checkout_list_form**: Enter a description of the gear to be checked out. This could include the type of gear, number, and condition.
* **gear_type**: This field is used to select the type of gear, such as Microphone, Headphones, Lamps, or Projector. Select the relevant option(s) that matches the gear being checked out.
* **date_of_event**: Enter the date of the event in the format YYYY-MM-DD. This could be the date the gear was checked out or returned.
* **time_of_event**: Enter the time of the event in the format HH:MM. This could be the start or end time of the event.
* **event_description**: Provide a brief description of the event or the purpose of the gear checkout.
* **assigned_to**: Enter the name of the person assigned to handle the gear.
* **assigned_tool**: Enter the specific tool or device being checked out.
* **checkout_date**: Enter the date the gear was checked out.
