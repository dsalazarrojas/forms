# Restaurant Closing Checklist Form - Help Guide
## Purpose
The Restaurant Closing Checklist Form is used to gather information and data for closing procedures at the end of a shift or day at a restaurant. This form helps staff members report on tasks completed, cash handling, and other important details.

## How To Complete This Form
1. Select the relevant options for each field based on your completion of tasks and procedures. For example, select "Yes" or "No" for tasks completed or "Yes" or "No" for action items.
2. Enter numeric values for cash handling fields, such as cash drawers, registers, and cash in/out.
3. Select the corresponding restaurant ID and manager ID from the provided options.
4. Enter the close time and date for the shift or day.
5. Select the restaurant name and manager name from the provided options.
6. Provide any additional notes or comments in the notes fields.
7. Review and submit the form for review and processing.

## Field-by-Field Explanation

* **Tasks Completed** (`tasks_completed`):
	+ Select "Yes" if you completed the required tasks for closing procedures.
	+ Select "No" if you did not complete the tasks.
* **Cash Drawer Count** (`cash_drawer_count`):
	+ Enter the number of cash drawers still open.
* **Cash Register Count** (`cash_register_count`):
	+ Enter the number of cash registers still open.
* **Check Closers Count** (`check_closers_count`):
	+ Enter the number of check closers still open.
* **Check Closers Counted** (`check_closers_counted`):
	+ Enter the number of check closers counted.
* **Shift Leaders Count** (`shift_leaders_count`):
	+ Enter the number of shift leaders still on duty.
* **Shift Leaders Counted** (`shift_leaders_counted`):
	+ Enter the number of shift leaders counted.
* **Cash In** (`cash_in`):
	+ Enter the amount of cash in the register.
* **Cash Out** (`cash_out`):
	+ Enter the amount of cash out of the register.
* **Change** (`change`):
	+ Enter the amount of change remaining in the register.
* **Notes** (`notes`):
	+ Provide any additional comments or notes about the shift or closing procedures.
* **Email** (`prophet_email`):
	+ Enter the email address of the prophet (manager).
* **Phone** (`phone`):
	+ Enter the phone number of the prophet (manager).
* **Action Items** (`action_items`):
	+ Select "Yes" if you have any action items to report.
* **Action Items 2** (`action_items_2`):
	+ Select "Yes" if you have any action items to report for the second shift or day.
* **Notes For Employee** (`notes_for_employee`):
	+ Select "Yes" if you have any notes for the employee.
* **Notes For Manager** (`notes_for_manager`):
	+ Select "Yes" if you have any notes for the manager.
* **Restaurant ID** (`restaurant_id`):
	+ Select the restaurant ID from the provided options.
* **Manager ID** (`manager_id`):
	+ Select the manager ID from the provided options.
* **Close Time** (`close_time`):
	+ Enter the close time of the shift or day.
* **Close Date** (`close_date`):
	+ Enter the close date of the shift or day.
* **Restaurant Name** (`restaurant_name`):
	+ Select the restaurant name from the provided options.
* **Manager Name** (`manager_name`):
	+ Select the manager name from the provided options.

## Tips
- Make sure to review the form carefully before submitting it for accuracy.
- Double-check the numeric values and select options to ensure they are correct.
- Complete the form for the correct shift or day.
- Submit the form for review and processing.
