# Screening App ROI Calculator - Help Guide
## Purpose
The Screening App ROI Calculator is a tool used to evaluate the financial benefits of a screening application by calculating its return on investment (ROI). This form helps users to quickly input relevant metrics, such as screen time savings and implementation expenses, and calculate the expected and actual ROI.

## How To Complete This Form

1. To start, navigate to the first page of the form, "Screen Time Savings".
2. On this page, enter the amount of screen time saved by using the screening application. This field is optional but recommended for accurate results.
3. Click "Submit" to proceed to the next page.
4. On the next page, enter the total implementation expenses for the screening application. This field is also optional but recommended for accurate results.
5. Click "Submit" to proceed to the next page.
6. On the next page, enter the expected savings from using the screening application. This field is optional but recommended for accurate results.
7. Click "Submit" to proceed to the next page.
8. On the next page, enter the ROI percentage calculated by the screening application. This field is optional but recommended for accurate results.
9. Click "Submit" to proceed to the next page.
10. On the last page, view the calculated actual ROI of the screening application.

## Field-by-Field Explanation

* **Screen Time Savings** (`screen_time_savings`, number, optional): Enter the amount of screen time saved by using the screening application. This is the time saved compared to manual screening processes.
* **Implementation Expenses** (`implementation_expenses`, number, optional): Enter the total implementation expenses for the screening application. This includes all costs associated with setting up and configuring the application.
* **ROI Timeline** (`roi_timeline`, date, optional): Enter the date when the ROI was calculated. This is the date when the expected ROI was calculated.
* **Expected Savings** (`expected_savings`, number, optional): Enter the expected savings from using the screening application. This is the total savings expected over the calculated ROI period.
* **ROI Percentage** (`roi_percentage`, number, optional): Enter the ROI percentage calculated by the screening application. This is the percentage of return on investment.
* **Actual ROI** (`actual_roi`, number, optional): This is the actual ROI of the screening application, calculated based on the input values.

## Tips

* Always input accurate values for best results.
* If a field is not relevant, you can skip it.
* Use the calculated actual ROI to compare with expected ROI and make informed decisions.
