# Dispatch Release - Help Guide
## Purpose
This form is designed to document and track the release of goods or materials for logistics and shipping purposes. It captures essential details about the release, including dates, delivery information, and status.

## How To Complete This Form
To complete this form, follow these steps:

* Enter the **Release code**, which is a unique identifier for the release.
* Enter the **Date of issue**, which is the date the release was issued.
* Enter the **Date of expiry**, which is the date the release expires.
* Enter the **Release date**, which is the date the release was made.
* Enter the **Delivery address**, which is the location where the goods or materials are to be delivered.
* Enter the **Delivery contact**, which is the person or entity responsible for delivering the goods or materials.
* Enter the **Delivery method**, which is the mode of transportation used for delivery (e.g., truck, plane, etc.).
* Enter the **Delivery details**, which is a brief description of the delivery process.
* Select the **Release status**, which indicates whether the release is Active, Inactive, or Cancelled.
* Select multiple **Release codes**, which are additional identifiers for the release (e.g., for different types or quantities).
* Enter the **Delivery person**, which is the individual responsible for delivering the goods or materials.
* Enter **Dispatch notes**, which is a field for additional comments or notes about the release.

## Field-by-Field Explanation
* **Date of issue**: Enter the date the release was issued.
* **Date of expiry**: Enter the date the release expires.
* **Release code**: Enter a unique identifier for the release.
* **Release date**: Enter the date the release was made.
* **Delivery address**: Enter the location where the goods or materials are to be delivered.
* **Delivery contact**: Enter the person or entity responsible for delivering the goods or materials.
* **Delivery method**: Enter the mode of transportation used for delivery (e.g., truck, plane, etc.).
* **Delivery details**: Enter a brief description of the delivery process.
* **Release by**: Enter the name of the person or entity responsible for the release.
* **Release date time**: Enter the time the release was made.
* **Dispatch notes**: Enter any additional comments or notes about the release.
* **Release status**: Select whether the release is Active, Inactive, or Cancelled.
* **Release code list**: Select multiple release codes that apply to the release.
* **Delivery person**: Enter the name of the individual responsible for delivering the goods or materials.

## Tips
* Make sure to complete all required fields.
* Double-check dates and release codes for accuracy.
* Use the **Dispatch notes** field for any additional comments or notes about the release.
* If you are unsure about any field, refer to the form's purpose and industry standard practices for guidance.
