# Pre Task Planning Form - Help Guide
## Purpose
The Pre Task Planning Form is a tool used to gather essential project information before the project starts. It helps project managers and team members to plan and prepare for the project's requirements, timeline, and resources.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the title of the project in the "Project Title" field.
2. Provide the name of the client associated with the project in the "Client Name" field.
3. Enter a brief description of the task in the "Task Description" field.
4. Select the start and end dates of the project using the calendars provided.
5. Choose the priority level of the project from the dropdown menu ("High", "Medium", or "Low").
6. Enter the name of the person assigned to the task in the "Assigned To" field (optional).
7. If applicable, enter the tool or resource assigned to the task in the "Assigned Tool" field (optional).

## Field-by-Field Explanation
* **Project Title** (text, required/optional): Enter a short title of the project that describes its scope and purpose.
* **Client Name** (text, required): Enter the name of the client associated with the project.
* **Task Name** (text, optional): Enter a brief title or name for the task being planned.
* **Task Description** (text, optional): Provide a short description of the task, including its objectives and requirements.
* **Start Date** (date, optional): Select the start date of the project using the calendar provided.
* **End Date** (date, optional): Select the end date of the project using the calendar provided.
* **Priority** (select_one, required): Choose the priority level of the project from the dropdown menu: "High", "Medium", or "Low".
* **Assigned To** (text, optional): Enter the name of the person assigned to the task (if applicable).
* **Assigned Tool** (text, optional): Enter the tool or resource assigned to the task (if applicable).

## Tips
* Make sure to fill out the "Client Name" field accurately, as it will help track and report on project progress and results.
* If you are unsure about the start or end dates, use placeholders or "to be determined" to indicate that the dates are subject to change.
* Use the "Assigned To" and "Assigned Tool" fields only when a specific person or tool is assigned to the task.
* Double-check the "Priority" level to ensure it reflects the project's urgency and importance.
