# Social Engineering Incident Form - Help Guide
## Purpose
The Social Engineering Incident Form is used to report and track social engineering incidents that have occurred within the organization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the date and time the incident occurred.
2. Enter the IP address of the attacker.
3. Enter the email address of the attacker.
4. Enter the phone number of the attacker.
5. Enter the name of the victim.
6. Enter the location where the incident occurred.
7. Enter a brief description of the incident.
8. Select the type of incident (e.g., Phishing, Scam, Malware).
9. Select the category of the incident (e.g., Financial, Business, Personal).
10. Select the status of the incident (e.g., Reported, Under Investigation, Resolved).
11. If necessary, enter a resolution or outcome for the incident.
12. If necessary, enter any additional comments about the incident.

## Field-by-Field Explanation
* **Incident Date**: Enter the date the incident occurred in `YYYY-MM-DD` format. This will help us track the timeline of the incident.
* **Incident Time**: Enter the time the incident occurred in `HH:MM:SS` format. This will help us track the timing of the incident.
* **Incident Details**: Enter a brief description of the incident. This can include any relevant details about the attack, such as the method used by the attacker.
* **Attacker IP**: Enter the IP address of the attacker.
* **Attacker Email**: Enter the email address of the attacker.
* **Attacker Phone**: Enter the phone number of the attacker.
* **Victim Name**: Enter the name of the victim.
* **Incident Location**: Enter the location where the incident occurred.
* **Incident Description**: Enter a brief description of the incident.
* **Incident Type**: Select the type of incident from the list (e.g., Phishing, Scam, Malware). This will help us categorize the incident.
* **Incident Category**: Select the category of the incident from the list (e.g., Financial, Business, Personal). This will help us track the scope of the incident.
* **Incident Status**: Select the status of the incident from the list (e.g., Reported, Under Investigation, Resolved). This will help us track the progress of the incident.
* **Incident Resolution**: If the incident has been resolved, enter a brief description of the outcome.
* **Incident Comment**: Enter any additional comments about the incident.
* **Incident Attachment**: If you have any attachments or evidence related to the incident, attach them here.
* **Incident Note**: Enter any additional notes about the incident.
* **Incident Url**: Enter any relevant URLs related to the incident.
* **Incident Tags**: Select any relevant tags from the list (e.g., Security, Finance, IT). This will help us search and filter incidents.
* **Attacker Name**: Enter the name of the attacker.
* **Attacker Location**: Enter the location of the attacker.
* **Incident Date 2**: This field is optional and only necessary if the incident involves multiple dates.
* **Incident Time 2**: This field is optional and only necessary if the incident involves multiple times.
* **Incident Type 2**: This field is optional and only necessary if the incident has multiple types.
* **Incident Category 2**: This field is optional and only necessary if the incident has multiple categories.
* **Incident Status 2**: This field is optional and only necessary if the incident has multiple statuses.
* **Incident Tags 2**: This field is optional and only necessary if you need to add more tags.

Note: The fields marked as "2" are optional and only necessary if the incident is complex or involves multiple incidents.

## Tips
* Make sure to enter all necessary information to ensure accurate documentation of the incident.
* If you are unsure about any of the fields, please consult with the IT security team.
* Please be as detailed as possible when entering information about the incident.
* This form is for reporting and tracking social engineering incidents only. If the incident is not related to social engineering, please use the appropriate incident reporting form.
