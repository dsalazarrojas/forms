# Financial Model Troubleshooting Guide - Help Guide
## Purpose
The Financial Model Troubleshooting Guide is a form used to report and track issues related to financial models. By completing this form, you will provide detailed information about the problem you are experiencing, which will help the team to identify and resolve the issue efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a detailed description of the problem you are experiencing in the "Issue Description" field.
2. Specify the current model version in the "Model Version" field.
3. Choose the type of issue you are experiencing (e.g. data discrepancy, calculation error) in the "Type of Issue" field.
4. If applicable, upload any support files or documents related to the issue in the "Support Files" field.
5. Enter the urgency and priority level of the issue in the "Urgency" and "Priority" fields respectively.
6. Specify who the issue should be assigned to in the "Assigned To" field.
7. Provide the date the issue was discovered in the "Issue Date" field.
8. Enter the status of the resolution in the "Resolution Status" field.

## Field-by-Field Explanation
* **Issue Description (Issue Description, text, required)**: Enter a detailed description of the problem you are experiencing.
* **Model Version (Model Version, number, required)**: Specify the current model version.
* **Urgency (Urgency, text, required)**: Enter the urgency level of the issue (e.g. high, medium, low).
* **Support Files (Support Files, select_multiple, required)**: Add any supporting files or documents related to the issue. Accepted formats are CSV, PDF, Excel, and ZIP.
* **Type of Issue (Type of issue, select_one, required)**: Specify the type of issue (e.g. data discrepancy, calculation error).
* **Priority (issue_priority, text, required)**: Enter the priority level of the issue (e.g. high, medium, low).
* **Assigned To (Assigned To, text, required)**: Specify who the issue should be assigned to.
* **Issue Date (Issue Date, date, required)**: Enter the date the issue was discovered.
* **Resolution Status (Resolution Status, text, required)**: Enter the status of the resolution.
