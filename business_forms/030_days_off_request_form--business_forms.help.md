# Days Off Request Form - Help Guide

## Purpose
The "Days Off Request Form" is used to record and manage employee requests for taking time off from work. It captures relevant details about the request, such as start and end dates, duration, reason, and approval status.

## How To Complete This Form

1. To complete the form, follow the instructions below.
2. On the first page, enter the request details.
   * **Request Details** (`request_details`, text, optional): Enter a brief description of the time off request.
3. On the second page, enter the dates and duration of the time off.
   * **Start Date** (`start_date`, date, optional): Enter the start date of the time off.
   * **End Date** (`end_date`, date, optional): Enter the end date of the time off.
   * **Duration** (`duration`, number, optional): Enter the number of days off.
4. On the next page, enter the reason and approval details.
   * **Reason** (`reason`, text, optional): Enter the reason for the time off request.
   * **Manager's Note** (`manager_note`, text, optional): If applicable, enter any additional notes from your manager.
5. On the last page, enter the approval details.
   * **Approved By** (`approved_by`, select_one, optional): Select whether the request is approved by your manager.
   * **Status** (`status`, select_multiple, optional): Select the status of the request.
   * **Approval Request** (`approval_request`, select_one, optional): Select whether an approval request is needed.
   * **Approval Status** (`approval_status`, select_multiple, optional): Select the approval status.
   * **Approval Date** (`approval_date`, date, optional): Enter the date of the approval.

## Field-by-Field Explanation

* **Request Details**: Enter a brief description of the time off request.
* **Start Date**: Enter the start date of the time off.
* **End Date**: Enter the end date of the time off.
* **Duration**: Enter the number of days off.
* **Reason**: Enter the reason for the time off request.
* **Manager's Note**: If applicable, enter any additional notes from your manager.
* **Approved By**: Select whether the request is approved by your manager.
* **Status**: Select the status of the request.
* **Approval Request**: Select whether an approval request is needed.
* **Approval Status**: Select the approval status.
* **Approval Date**: Enter the date of the approval.

## Tips

* Ensure that you have all necessary information before completing the form.
* Review the form carefully before submitting it.
* If you are unsure about any field, please consult your manager or HR representative.
