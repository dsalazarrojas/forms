# Energy Intelligence Grant Application Form - Help Guide
## Purpose
The Energy Intelligence Grant Application Form is a tool used to collect information for energy intelligence grant applications. It is designed to gather all the necessary details about a project to ensure accurate and complete submission.

## How To Complete This Form
To complete this form, simply fill in the required fields. The form is organized into the following sections:
- Project Details
- Contact Information
- Project Team
- Project Status
- Energy Source
- Project Location
- Project Funding
- Project Notes

## Field-by-Field Explanation
### Project Details
* **Project Title** (`energy_intelligence_grant_application_form`, text, required): Enter a brief description of the project.
* **Project Team** (project_team, text, optional): If applicable, provide details about the project team.
* **Project Status** (project_status, select_one, required): Select the current project status (pending, approved, or rejected).
* **Project Funding** (project_funding, number, required): Enter the project funding amount.
* **Project Start Date** (project_start_date, date, required): Enter the project start date.
* **Project End Date** (project_end_date, date, required): Enter the project end date.
* **Energy Source** (energy_source, select_multiple, optional): Select the energy source (solar, wind, hydro, geothermal, or other).
* **Project Location Type** (project_location_type, select_one, required): Select the project location type (rooftop, ground mount, or other).
* **Energy Production Capacity** (energy_production_capacity, number, required): Enter the energy production capacity.
* **Project Location Notes** (project_location_note, note, optional): Provide any additional notes about the project location.
* **Project Team Notes** (project_team_note, note, optional): Provide any additional notes about the project team.
* **Project Funding Notes** (project_funding_note, note, optional): Provide any additional notes about the project funding.
* **Project Notes** (project_notes, note, optional): Provide any additional notes about the project.
* **Energy Source Notes** (energy_source_note, note, optional): Provide any additional notes about the energy source.
* **Project Location Type Notes** (project_location_type_note, note, optional): Provide any additional notes about the project location type.
* **Project Funding** (project_funding, number, optional): Enter the project funding amount (if not already provided).
* **Project Funding Currency** (project_funding_currency, select_one, required): Select the project funding currency (USD, EUR, AUD, CAD, or other).
* **Project Total Funding** (project_total_funding, number, required): Enter the total project funding amount.
* **Project Start Date Range** (project_start_date_range, date, required): Enter the project start date range.
* **Project End Date Range** (project_end_date_range, date, required): Enter the project end date range.
* **Project Budget** (project_budget, number, optional): Enter the project budget.
* **Project Additional Notes** (project_additional_notes, note, optional): Provide any additional notes about the project.
