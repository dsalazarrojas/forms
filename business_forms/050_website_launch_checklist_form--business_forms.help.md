# website_launch_checklist_form - Help Guide
## Purpose
The website launch checklist form is used to create and manage website launch checklists for different categories and tools.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for your website launch checklist from the dropdown options.
2. Enter a brief description of the launch process.
3. Choose the tool assigned to the launch checklist.
4. Select the output file(s) related to the launch.
5. Enter a title for the launch checklist.
6. Select the category for the launch checklist.
7. Enter a description for the launch checklist.

## Field-by-Field Explanation

* **Category** (`form_category`, select_one): Select the category for your website launch checklist. Choose from "Business Forms" or "Other" options.
* **Description** (`form_description`, text): Enter a brief description of the launch process.
* **Assigned Tool** (`assigned_tool`, select_one): Choose the tool assigned to the launch checklist.
* **Output File(s)** (`output_file`, select_multiple): Select one or more output files related to the launch. Choose from "050 website launch checklist form--business forms" or "Other File".
* **Title** (`title`, text): Enter a title for the launch checklist.
* **Category (2)** (`category`, select_one): Select the category for the launch checklist.
* **Description (2)** (`description_2`, text): Enter a description for the launch checklist.
