# Project Intake Form - Help Guide

## Purpose

This form is used to collect information about new projects, including project name, manager, start and end dates, business case, risk assessment, budget, resource planning, risk factors, and risk level. 

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the project name in the "Project Name" field.
2. Enter the project manager's name in the "Project Manager" field.
3. Enter the project start date in the "Project Start Date" field.
4. Enter the project end date in the "Project End Date" field.
5. Provide a brief description of the business case in the "Business Case" field.
6. Select the risk assessment for the project.
7. Enter the project budget.
8. Describe the resource planning for the project.
9. Indicate whether there are risk factors present (select one or multiple options).
10. Select the project risk level.

## Field-by-Field Explanation

* **Project Name**: Enter the name of the project. This is the title of the project, which will be used to identify and track the project.
* **Project Manager**: Enter the name of the person responsible for managing the project. This will help ensure that the correct person is informed and involved in the project.
* **Project Start Date**: Enter the date when the project will start. This is the date when the project will begin and work will commence.
* **Project End Date**: Enter the date when the project will end. This is the date when the project will be completed and finished.
* **Business Case**: Provide a brief description of the business case for the project. This is an opportunity to explain the reason for the project and its importance to the organization.
* **Business Risk Assessment**: Select whether there is a business risk associated with the project. This helps identify potential risks and issues that may impact the project.
* **Project Budget**: Enter the budget for the project. This is the financial cost of the project and helps to ensure that it is funded correctly.
* **Resource Planning**: Describe the resource planning for the project. This is an opportunity to outline the resources required for the project, including personnel, equipment, and materials.
* **Risk Factors**: Indicate whether there are risk factors present for the project. Select one or multiple options, as applicable.
* **Risk Level**: Select the risk level for the project. This helps to identify and prioritize projects based on their risk level.

## Tips

* Please fill out all required fields accurately and completely.
* Be thorough when describing the business case and resource planning.
* Use the select options to provide clear answers for the risk assessment and risk factors.
