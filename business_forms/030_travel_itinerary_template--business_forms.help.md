# Travel Itinerary Template - Help Guide
## Purpose
The Travel Itinerary Template form is used to create a structured template for travel itineraries, helping travel agencies and planners to gather and organize essential information about trips.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Trip Type" field, selecting either "Business" or "Leisure" as the type of trip.
2. Enter the travel dates in the "Travel Dates" field, using the specified date format.
3. Enter the destination in the "Destination" field.
4. Provide any additional details about the travel agency in the "Travel Agency Details" field, if applicable.
5. Enter any additional information about the traveler in the "Traveler Details" field, if applicable.
6. Select a payment method from the "Payment Method" field, choosing between "Credit Card", "Bank Transfer", or "Check".
7. Enter the agency contact phone number in the "Agency Phone" field.
8. Enter the agency contact email in the "Agency Email" field.

## Field-by-Field Explanation

* **Travel Agency**: This field is optional but allows travel agencies to provide their contact information and details.
	+ Type: text
	+ Required: false
* **Trip Type**: Select the type of trip, either "Business" or "Leisure".
	+ Type: select_one
	+ Required: true
* **Travel Dates**: Enter the travel dates in the specified format from 1-9-2015 to 1-1-2023.
	+ Type: date
	+ Required: false
* **Destination**: Enter the destination of the trip.
	+ Type: text
	+ Required: false
* **Travel Agency Details**: Enter any additional details about the travel agency, if applicable.
	+ Type: text
	+ Required: false
* **Traveler Details**: Enter any additional information about the traveler, if applicable.
	+ Type: text
	+ Required: false
* **Payment Method**: Select one of the payment methods: "Credit Card", "Bank Transfer", or "Check".
	+ Type: select_one
	+ Required: true
* **Agency Phone**: Enter the agency contact phone number.
	+ Type: text
	+ Required: false
* **Agency Email**: Enter the agency contact email.
	+ Type: email
	+ Required: false
