# Server Health Monitoring Check In Form - Help Guide
## Purpose
This form is used for checking in on the server health monitoring system.

## How To Complete This Form
1. Fill out the form by selecting the appropriate option from each of the available fields.
2. Select the status of the server from the "Server Status" field.
3. Enter the server's uptime, if it is available.
4. Enter the server's downtime, if it is available.
5. Enter a note or comment about the server's performance.
6. Click the "Submit" button to submit the form.

## Field-by-Field Explanation
* **Server Status** (`server_status`, select_one, required): Select the current status of the server from the available options.
* **Server Health Monitoring Form** (`server_health_monitoring_form`, select_multiple, required): Select all of the available options if the server is currently experiencing any issues.
* **Server Uptime** (`server_uptime`, number, required): Enter the current uptime of the server in hours.
* **Server Downtime** (`server_downtime`, number, required): Enter the current downtime of the server in hours.
* **Server Performance** (`server_performance`, number, required): Enter a numeric value representing the server's performance.
* **Notes** (`notes`, note, optional): Enter a note or comment about the server's performance.

## Tips
* Make sure to select all relevant options for server issues.
* Enter accurate values for server uptime, downtime, and performance.
* Keep notes clear and concise.
