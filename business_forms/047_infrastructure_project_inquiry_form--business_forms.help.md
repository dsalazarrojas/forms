# Infrastructure Project Inquiry Form - Help Guide
## Purpose
This form is used to inquire about or propose new infrastructure projects, allowing the team to gather essential information to manage and execute projects effectively.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill out the **Project Location** field with the exact location of the project.
2. Describe the **Project Description** in the provided field.
3. Enter the **Project Budget** if applicable.
4. Select a **Project Timeline** (start and end dates).
5. Choose the current **Project Status** from the available options.
6. Assign a **Project Priority** from the available options (high, medium, or low).
7. Select one or multiple **Project Category**(ies) from the available options (infrastructure, building, transportation).
8. Enter your **Project Submitter** email address.
9. If needed, add **Project Notes** for additional context.

## Field-by-Field Explanation

* **Project Location** (Text, Required): Enter the exact location of the project, including city, state, or country.
* **Project Description** (Note, Optional): Briefly describe the project.
* **Project Budget** (Number, Optional): Enter the project budget if applicable.
* **Project Timeline** (Date, Optional): Select the project start and end dates.
* **Project Status** (Select One, Required): Choose the current status of the project from the available options (active, inactive, pending).
* **Project Priority** (Select One, Required): Assign a priority level (high, medium, low) to the project.
* **Project Category** (Select Multiple, Required): Select one or multiple categories for the project (infrastructure, building, transportation).
* **Project Submitter** (Email, Required): Enter your email address to be associated with the project.
* **Project Notes** (Text, Optional): Add any additional notes or context about the project.
