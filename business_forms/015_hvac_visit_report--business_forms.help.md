# hvac_visit_report - Help Guide
## Purpose
The HVAC visit report is used by technicians to document their visits to customers' homes or offices, ensuring thorough and accurate information is recorded.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the tech's name in the "Tech Name" field.
2. Select the date of the visit in the "visit_date" field using the date picker.
3. Select the type of service provided from the available options in the "service_type" field.
4. Add any notes or comments about the service provided in the "service_notes" field.
5. Select the current repair status from the options in the "repair_status" field.
6. If required, sign and date in the "customer_signature" field.
7. If required, sign in the "tech_signature" field.

## Field-by-Field Explanation
- **Tech Name (Tech Name, text, required):**
Enter the name of the technician who visited the customer.
- **Visit Date (visit_date, date, required):**
Select the date of the visit using the date picker.
- **Service Type (service_type, select_one, optional):**
Choose the type of service provided, such as Service1, Service2, or Service3.
- **Service Notes (service_notes, text, optional):**
Add any notes or comments about the service provided.
- **Repair Status (repair_status, select_one, optional):**
Select the current repair status from the options, which are Complete, Not Required, or In Progress.
- **Customer Signature (customer_signature, text, optional):**
If required, sign and date in this field to indicate customer acknowledgment.
- **Technician Signature (tech_signature, text, optional):**
Sign in this field if required to indicate technician acknowledgment.
