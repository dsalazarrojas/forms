# Inventory Rescan Request Form - Help Guide
## Purpose
This form is used to request an inventory rescan for a specific business, staff member, or product. The goal of this form is to facilitate the process of updating inventory information by requesting a rescan of the relevant data. 

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are submitting a valid request by providing necessary information.
2. Fill out the form with the required fields (business ID, staff ID, product ID, reason, and comment).

## Field-by-Field Explanation
* **Business ID** (1, Number, Required/Optional: false)
  * This field is used to select the business for which you want to request an inventory rescan. Enter the business ID number.
* **Staff ID** (2, Number, Required/Optional: false)
  * This field is used to select the staff member responsible for the inventory rescan. Enter the staff ID number.
* **Product ID** (3, Number, Required/Optional: false)
  * This field is used to select the product for which you want to request an inventory rescan. Enter the product ID number.
* **Reason** (4, Text, Required/Optional: false)
  * This field is used to provide a brief explanation for the inventory rescan request. Enter a short description of the reason for the rescan.
* **Comment** (5, Text, Required/Optional: false)
  * This field is used to provide additional information or notes about the inventory rescan request. Enter any additional comments or details about the request.
