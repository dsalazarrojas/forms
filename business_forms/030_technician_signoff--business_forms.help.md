# Technician Signoff - Help Guide
## Purpose
The purpose of this form is to capture information from a technician or engineer regarding the status of a work order or project. This includes selecting the correct work status, providing contact information for on-site visits, confirming whether the technician has signed off on a particular task, recording the date and time of sign off, specifying the method used for signing off (e.g., digitally, with a signature pad, or with ink), and leaving any additional comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct work status for the project from the drop-down menu.
2. Enter the name of the contact person responsible for the on-site visit.
3. Check the box to confirm whether you have signed off on the task.
4. Select the date of sign off using the date picker field.
5. Select the time of sign off using the time picker field.
6. Choose the method used for signing off (e.g., digitally, with a signature pad, or with ink).
7. Leave any additional comments about the task or project in the comments field.

## Field-by-Field Explanation
* **Work Status**: This field is a drop-down menu where you need to select the current status of the work order or project.
  - Options: 100, 200, 300 (Please check the options to determine which status best describes the project's current status.)
* **On Site Contact**: Enter the name of the contact person responsible for the on-site visit. This will help the team know who to contact if they have any questions or need further information.
* **Signed Off**: Check this box to confirm that you have signed off on the task.
* **Signature Date**: Select the date of sign off using the date picker field.
* **Signature Time**: Select the time of sign off using the time picker field.
* **Signature Method**: Choose the method used for signing off the task, such as digitally, with a signature pad, or with ink.
* **Comments**: Leave any additional comments about the task or project in this field.
* **Comments 2**: This field is for any additional comments or information that you may want to provide.
