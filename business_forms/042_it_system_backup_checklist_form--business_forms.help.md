# it_system_backup_checklist_form - Help Guide
## Purpose
The IT System Backup Checklist Form is a tool used to track the backup status and frequency of IT systems. This form helps in ensuring that backups are performed regularly and that the data is safe and secure.

## How To Complete This Form
1. Select the current status of the backup from the "backup_status" dropdown menu.
2. Choose the frequency of the backup from the "backup_frequency" dropdown menu.
3. Select the location where the backup is stored from the "backup_location" dropdown menu.
4. Select the media type used for the backup from the "backup_media" dropdown menu.
5. Enter the last backup date in the "last_backup_date" field.
6. Enter the next backup date in the "next_backup_date" field.
7. Select the last backup status from the "backup_status_last" dropdown menu.
8. Select the last backup location from the "backup_location_last" dropdown menu.
9. Select the last backup media from the "backup_media_last" dropdown menu.
10. Enter the last backup date for the last backup from the "last_backup_date_last" field.
11. Enter the next backup date for the last backup from the "next_backup_date_last" field.
12. Select the backup status for the next backup from the "next_backup_status" dropdown menu.
13. Select the frequency of the backup for the last backup from the "last_backup_frequency" dropdown menu.
14. Select the backup status for the last backup from the "backup_status_frequency" dropdown menu.
15. Select the location for the last backup from the "backup_location_frequency" dropdown menu.
16. Select the media used for the last backup from the "backup_media_last_last" dropdown menu.
17. Select the frequency of the last backup from the "backup_frequency_last_last" dropdown menu.
