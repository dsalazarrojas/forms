# program_pick - Help Guide
## Purpose
The "program_pick" form is designed to collect information about programs. It is used to input and store data for various programs, allowing you to categorize and track them effectively.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the program type from the provided options.
2. Input the name of the program.
3. Enter the start and end dates of the program.
4. Choose the program manager from the options.
5. Add any additional notes or comments for the program.
6. Enter the program's category and status.
7. Input any other relevant information such as email, phone, location, and program notes.

## Field-by-Field Explanation
* **Program Type** (`program_type`): Select the type of program you are inputting data for.
* **Program Name** (`program_name`): Input the name of the program.
* **Start Date** (`program_start_date`): Enter the start date of the program.
* **End Date** (`program_end_date`): Enter the end date of the program.
* **Program Manager** (`program_manager`): Choose the program manager from the provided options.
* **Notes** (`notes`): Add any additional notes or comments for the program.
* **Email** (`email`): Enter the program's email address.
* **Phone** (`phone`): Enter the program's phone number.
* **Category** (`category`): Select the category of the program.
* **Status** (`status`): Choose the status of the program.
* **Comments** (`comments`): Add any additional comments for the program.
* **Program Location** (`program_location`): Input the program's location.
* **Program Status** (`program_status`): Choose the status of the program.
* **Program Type 2** (`program_type_2`): Select the secondary type of the program.
* **Program Status 2** (`program_status_2`): Choose the secondary status of the program.
* **Program Type 3** (`program_type_3`): Select the tertiary type of the program.
* **Program Location 2** (`program_location_2`): Input the secondary location of the program.
* **Program Notes** (`program_notes`): Add any additional notes for the program.
* **Program Notes 2** (`program_notes_2`): Add any additional secondary notes for the program.
* **Program Phone 2** (`program_phone_2`): Enter the secondary phone number of the program.
* **Program Email 2** (`program_email_2`): Enter the secondary email address of the program.
* **Program Phone 3** (`program_phone_3`): Enter the tertiary phone number of the program.
* **Program Email 3** (`program_email_3`): Enter the tertiary email address of the program.
* **Program Comments** (`program_comments`): Add any additional comments for the program.
* **Program Status 3** (`program_status_3`): Choose the tertiary status of the program.
* **Program Status 4** (`program_status_4`): Choose the quaternary status of the program.
* **Program Comments 2** (`program_comments_2`): Add any additional secondary comments for the program.

## Tips
* Make sure to select the correct program type, manager, and status for accurate categorization and tracking.
* Use the notes and comments fields to add any additional information that may not be covered by the other fields.
* Double-check your input for accuracy to ensure that the data is up-to-date and correct.
