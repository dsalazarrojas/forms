# Worker Timesheet And Tracking Form - Help Guide
## Purpose
This form is used to track employee work hours, including start and end times, breaks, and other specific events. It helps to ensure accurate recording of work hours and breaks for payroll purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Employee Id** field with the ID number of the employee who is being clocked in.
2. Enter the **Start Time** and **End Time** fields with the actual times the employee started and ended their workday.
3. If applicable, fill in the **Lunch Break** field with the number of hours taken for lunch.
4. Calculate the total hours worked using the **Total Hours Worked** field.
5. Check if the worker is assigned to a specific **Tool** or **User** by filling in the respective fields.

## Field-by-Field Explanation
- **Employee Id**: Enter the ID number of the employee being clocked in.
- **Start Time**: The start time of the employee's workday.
  - This field is required and should be filled in with the actual start time of the employee's workday.
- **End Time**: The end time of the employee's workday.
  - This field is required and should be filled in with the actual end time of the employee's workday.
- **Lunch Break**: The number of hours taken for lunch.
  - This field is optional and should be filled in if a lunch break is taken.
- **Total Hours Worked**: Calculate the total hours worked for the day.
  - This field is required and should be calculated using the start and end times.
- **Assigned Tool**: Check if the worker is assigned to a specific tool.
  - This field is required and is used to indicate if the worker is assigned to a tool.
- **Assigned User**: Check if the worker is assigned to a specific user.
  - This field is optional and is used to indicate if the worker is assigned to a user.
- **Comments**: Any additional comments about the workday.
  - This field is optional and can be used to add any comments about the workday.
- **Clock In**: The time the worker clocks in for the day.
  - This field is required and should be filled in with the actual clock-in time.
- **Clock Out**: The time the worker clocks out for the day.
  - This field is required and should be filled in with the actual clock-out time.
- **Break Start Time**: The start time of a scheduled break.
  - This field is optional and is used to indicate the start time of a scheduled break.
- **Break End Time**: The end time of a scheduled break.
  - This field is optional and is used to indicate the end time of a scheduled break.
- **Clock In Break Start Time**: The start time of the clock-in break.
  - This field is optional and is used to indicate the start time of a break.
- **Clock In Break End Time**: The end time of the clock-in break.
  - This field is optional and is used to indicate the end time of a clock-in break.
- **Total Break Hours**: The total hours taken for breaks.
  - This field is optional and should be calculated using the break start and end times.
- **Clock Out Break Start Time**: The start time of the clock-out break.
  - This field is optional and is used to indicate the start time of a break.
- **Clock Out Break End Time**: The end time of the clock-out break.
  - This field is optional and is used to indicate the end time of a break.

## Tips
- Double-check the fields for any errors before submitting the form.
- Make sure to calculate the total hours worked and break hours accurately.
- Use the comments field for any additional comments or explanations about the workday.
