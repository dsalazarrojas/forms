# Metro Security Report Form - Help Guide

## Purpose
The Metro Security Report Form is used to report security threats that have occurred within the Metro organization.

## How To Complete This Form
To complete the form, follow these steps:

1. Please ensure you are reporting a single threat. If you have reported multiple threats, please submit a separate form for each incident.
2. Fill out the form completely and accurately, providing as much detail as possible about the threat.
3. Be sure to select the correct options for each field, as indicated in the explanations below.

## Field-by-Field Explanation

* **Threat Description** (Threat Description, text, required):
Provide a detailed description of the threat you are reporting.
* **Location** (Location, number, required):
Enter the location where the threat occurred. Please use a numerical value to represent the specific location (e.g. 123 Main St).
* **Date** (Date, date, required):
Enter the date the threat occurred. Please use the standard date format (e.g. MM/DD/YYYY).
* **Reported By** (Reported By, text, required):
Enter the name of the person who reported the threat.
* **Threat Severity** (Threat Severity, select_multiple, required):
Select all that apply from the following options:
	+ Low
	+ Medium
	+ High
* **Incident Type** (Incident Type, select_one, required):
Select the type of incident (e.g. physical, cyber, etc.):
	+ Physical
	+ Cyber
	+ Other
* **Threat Level** (Threat Level, number, required):
Enter a numerical value to represent the threat level.
* **Reporting Date** (Reporting Date, date, required):
Enter the date the threat was reported. Please use the standard date format (e.g. MM/DD/YYYY).
