# <string> - Help Guide

## Purpose
This form is used to check the status of various systems and components of a drone, including the drone system, battery, flight controller, navigation system, propeller, compass, flight control, avionics, weather condition, pilot, drone, maintenance, safety protocols, emergency equipment, first aid kit, navigation, communication, power, flight plan, and other status fields. It helps in gathering information about the drone's readiness for flight and identifies potential issues that need attention.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current status for each system or component listed in the form. The available options are:
	* For select multiple and select_one fields, choose from the given options.
	* For select_one fields, ensure you select only one option.
	* For text fields, type any additional comments or status information.
2. Make sure to answer all required fields as indicated in the form.
3. Review your answers carefully to ensure accuracy and completeness.
