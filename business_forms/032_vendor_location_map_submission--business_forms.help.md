# Vendor Location Map Submission - Help Guide

## Purpose
This form is designed to collect information about vendor locations and submissions. It is used for submitting vendor locations, including their contact information, maps, and other relevant details.

## How To Complete This Form
To complete this form, follow the instructions below:

*   Fill in the required and optional fields as per your needs.
*   Please fill out each field carefully, as it will help ensure accurate submission.
*   Review your submission before submitting it to make sure all required fields are completed.

## Field-by-Field Explanation

* **event_organizer** (select_one, Required: no): Select the type of event organizer from the list provided.
	+ Options: Event Organizer, Event Coordinator, Event Manager
* **local_directory** (select_multiple, Required: no): Choose one or more local directories from the list.
	+ Options: Public Map, Local Directory, Private Directory
* **business_association** (select_multiple, Required: no): Select one or more associations related to the business.
	+ Options: Event Organization, Business Association, Professional Group
* **consistent_data_collection_online** (text, Required: no): Describe the consistent data collection method used.
* **fast_data_collection_online** (select_one, Required: no): Select the speed of data collection from the list.
	+ Options: Fast, Slow
* **vendor_listing_data** (select_multiple, Required: no): Choose one or more vendor listing data sources.
	+ Options: Accurate, Inaccurate, Unknown
* **submission_form** (select_one, Required: no): Select the submission form type.
	+ Options: Vendor Location Map Submission Form, Vendor Map Submission Form, Submission Form
* **description** (text, Required: no): Provide a description of the vendor location.
* **assigned_tool** (number, Required: no): Provide the number of tools assigned to the submission.
* **business_association_type** (select_multiple, Required: no): Choose the type of business association.
	+ Options: Event Organization, Business Association, Professional Group
* **data_collection_method** (select_multiple, Required: no): Choose the data collection method used.
	+ Options: Online Data Collection, Offline Data Collection, Unknown
* **vendor_listings** (text, Required: no): Describe the vendor listings.
* **vendor_details** (select_multiple, Required: no): Select one or more vendor details.
	+ Options: Vendor Information, Contact Information, Vendor Details
* **submission_status** (select_multiple, Required: no): Select the submission status from the list.
	+ Options: Approved, Rejected, Pending
* **submission_comments** (text, Required: no): Provide comments about the submission.
* **vendor_rating** (number, Required: no): Provide the vendor rating.
* **vendor_rating_description** (text, Required: no): Describe the vendor rating.
* **vendor_contact_info** (text, Required: no): Provide the vendor contact information.
* **vendor_map_url** (text, Required: no): Provide the vendor map URL.
* **vendor_description** (text, Required: no): Describe the vendor location.
* **vendor_email** (email, Required: no): Provide the vendor's email address.
* **vendor_phone** (text, Required: no): Provide the vendor's phone number.
* **submission_date** (date, Required: no): Provide the submission date.
* **assigned_to** (select_one, Required: no): Select the person assigned to the submission.
	+ Options: chatjimmy, Other

## Tips

*   Please review each field carefully before submitting the form.
*   Make sure to fill out all required fields.
*   Double-check the submission form for accuracy before submitting it.
