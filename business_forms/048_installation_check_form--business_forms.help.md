# Installation Check Form - Help Guide
## Purpose
The Installation Check Form is used to record information related to the installation process. This form is not required for any specific business process, but rather for general reporting or record-keeping purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the installation date field with the correct date of the installation in the format YYYY-MM-DD.
2. Select one of the options for the system ID that best describes the system being installed.
3. Type in the name of the equipment installed.
4. Type in the location where the installation took place.
5. Select one or multiple options for the installation status that best describe the current status of the installation.

## Field-by-Field Explanation
* **Installation Check Form** (`installation_check_form`, text, optional): This field is the main title of the form.
* **Installation Date** (`installation_date`, date, optional): Record the date of the installation in the format YYYY-MM-DD.
* **System ID** (`system_id`, select_one, optional): Select one of the options for the system being installed.
* **Equipment Name** (`equipment_name`, text, optional): Type in the name of the equipment installed.
* **Installation Location** (`installation_location`, text, optional): Type in the location where the installation took place.
* **Installation Status** (`installation_status`, select_multiple, optional): Select one or multiple options for the current status of the installation.

## Tips
* Make sure to fill out all the required fields, even if they are optional.
* Use the correct format for the installation date.
* Select only one option for the system ID.
* Be as specific as possible when filling out the equipment name and installation location.
* Select multiple options for the installation status only if necessary.
