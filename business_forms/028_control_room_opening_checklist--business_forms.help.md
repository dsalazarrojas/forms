# Control Room Opening Checklist - Help Guide
## Purpose
The Control Room Opening Checklist is a form used to verify that all critical systems and components are in order before opening the control room for operation. This includes checking physical security, power systems, communication systems, monitoring systems, computer systems, environmental controls, and documentation.

## How To Complete This Form
1. Enter your name and ID number to identify yourself as the operator opening the control room.
2. Select the date of your shift from the calendar.
3. Enter the start time of your shift.
4. Check the status of each system and component, using the options provided.
5. If any issues are found, describe them in the "Issues Found" section.
6. If any actions are taken to address issues, describe them in the "Actions Taken" section.
7. If any escalations are needed, indicate who was notified.
8. Finally, confirm that the control room is ready for operation and that you have notified your supervisor of the status.

## Field-by-Field Explanation

* **Operator Name** (Operator Name, text, required): Your name as the operator opening the control room.
* **Operator ID** (Operator ID, text, required): Your employee identification number.
* **Shift Date** (Shift Date, date, required): The date of your shift.
* **Shift Start Time** (Shift Start Time, time, required): The time you start your shift.
* **-- Physical Security --**
	+ **Door Locks Functional** (Door locks functional, select_one, required): Check if the door locks are functioning properly.
	+ **Access Control System** (Access control system operational, select_one, required): Check if the access control system is operational.
* **-- Power Systems --**
	+ **Main Power Status** (Main power supply normal, select_one, required): Check if the main power supply is normal.
	+ **UPS Systems** (UPS systems operational, select_one, required): Check if the UPS systems are operational.
	+ **Backup Generator** (Backup generator ready, select_one, required): Check if the backup generator is ready.
* **-- Communication Systems --**
	+ **Phone Systems** (Phone systems operational, select_one, required): Check if the phone systems are operational.
	+ **Radio System** (Radio communication working, select_one, required): Check if the radio communication system is working.
	+ **Intercom System** (Intercom system functional, select_one, required): Check if the intercom system is functional.
* **-- Monitoring Systems --**
	+ **Monitoring Screens** (All monitoring screens active, select_one, required): Check if all monitoring screens are active.
	+ **Alarm Systems** (Alarm systems armed and ready, select_one, required): Check if the alarm systems are armed and ready.
	+ **Sensor Status** (All sensors reporting, select_one, required): Check if all sensors are reporting.
* **-- Computer Systems --**
	+ **Workstations** (All workstations operational, select_one, required): Check if all workstations are operational.
	+ **Network Connectivity** (Network connectivity normal, select_one, required): Check if the network connectivity is normal.
	+ **Software Systems** (All required software running, select_one, required): Check if all required software is running.
* **-- Environmental Controls --**
	+ **Temperature Normal** (Temperature within normal range, select_one, required): Check if the temperature is within normal range.
	+ **HVAC System** (HVAC system operational, select_one, required): Check if the HVAC system is operational.
	+ **Fire Suppression System** (Fire suppression system ready, select_one, required): Check if the fire suppression system is ready.
* **-- Documentation --**
	+ **Logbooks Available** (Log books available and current, select_one, required): Check if log books are available and current.
	+ **Emergency Procedures** (Emergency procedures accessible, select_one, required): Check if emergency procedures are accessible.
	+ **Contact Lists** (Emergency contact lists current, select_one, required): Check if emergency contact lists are current.
* **-- Issues Found --**
	+ **Issues Found** (Were any issues found, select_one, required): Check if any issues were found.
	+ **Describe Issues** (Describe issues found, text, required): Describe any issues found.
* **Actions Taken** (Actions taken, text, required): Describe any actions taken to address issues.
* **Escalations Needed** (Escalations needed, text, required): Indicate who was notified of issues.
* **Control Room Ready** (Control room ready for operation, select_one, required): Confirm that the control room is ready for operation.
* **Supervisor Notified** (Supervisor notified of status, select_one, required): Confirm that you have notified your supervisor of the status.
* **Additional Notes** (Additional notes, text, required): Add any additional notes or information.
