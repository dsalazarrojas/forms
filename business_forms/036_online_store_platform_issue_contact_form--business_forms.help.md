# online_store_platform_issue_contact_form - Help Guide
## Purpose
This form is used to report issues with the online store platform. If you are experiencing any problems with the platform, please fill out this form so that our support team can assist you.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a detailed description of your issue in the "Issue Description" field. This will help us understand the root cause of the problem.
2. Select the category of your issue from the list provided in the "Issue Category" field. This will help us prioritize and route your issue to the correct team.
3. If necessary, provide more details about your issue in the "Issue Details" field.
4. Enter your contact information, such as your email or phone number, in the "Contact Information" field. This will allow us to get back to you for further information or to resolve the issue.
5. If you have a screenshot, attachment, or video related to your issue, you can upload it in the "Issue Screenshot", "Issue Attachment", "Issue Video", or "Issue Audio" fields. Please make sure to provide a clear and relevant file.
6. Specify the device, browser, operating system, and platform you are using when experiencing the issue. This will help us to replicate the issue and resolve it efficiently.

## Field-by-Field Explanation
### Issue Description
* **Issue Description (text)**: Enter a detailed description of your issue. Please be as specific as possible so that our support team can better understand the problem.

### Issue Category
* **Issue Category (select multiple)**: Select all the categories that apply to your issue. This will help us to prioritize and route your issue to the correct team.
	+ **Product Issues**: Issues related to products or product listings.
	+ **Account Issues**: Issues related to your account or login.
	+ **Payment Issues**: Issues related to payments or transactions.

### Issue Details
* **Issue Details (text)**: Provide more details about your issue if necessary.

### Contact Information
* **Contact Information (text)**: Enter your contact email or phone number so that we can get back to you for further information or to resolve the issue.

### Issue Screenshot
* **Issue Screenshot (text)**: Upload a screenshot related to your issue. This will help us to visualize the problem.

### Issue Attachment
* **Issue Attachment (text)**: Upload an attachment related to your issue. Please ensure it's relevant to the problem.

### Issue Video
* **Issue Video (text)**: Upload a video related to your issue. This will help us to understand the problem better.

### Issue Audio
* **Issue Audio (text)**: Upload an audio file related to your issue. Please ensure it's relevant to the problem.

### Issue Location
* **Issue Location (text)**: Enter the location where you experienced the issue.

### Issue Device
* **Issue Device (select one)**: Select the device you are using when experiencing the issue.
	+ **Mobile**: Issues experienced on mobile devices.
	+ **Desktop**: Issues experienced on desktop devices.
	+ **Tablet**: Issues experienced on tablet devices.

### Issue Browser
* **Issue Browser (select one)**: Select the browser you are using when experiencing the issue.
	+ **Chrome**: Issues experienced on Chrome browser.
	+ **Firefox**: Issues experienced on Firefox browser.
	+ **Safari**: Issues experienced on Safari browser.

### Issue OS
* **Issue OS (select one)**: Select the operating system you are using when experiencing the issue.
	+ **Windows**: Issues experienced on Windows operating system.
	+ **macOS**: Issues experienced on macOS operating system.
	+ **Linux**: Issues experienced on Linux operating system.

### Issue Version
* **Issue Version (select one)**: Select the version of the platform you are using when experiencing the issue.
	+ **v8.0**: Issues experienced on version 8.0 of the platform.
	+ **v9.1**: Issues experienced on version 9.1 of the platform.
	+ **v10.0**: Issues experienced on version 10.0 of the platform.

### Issue Platform
* **Issue Platform (select one)**: Select the platform you are using when experiencing the issue.
	+ **Android**: Issues experienced on Android platform.
	+ **iOS**: Issues experienced on iOS platform.
	+ **Web**: Issues experienced on web platform.

### Issue Language
* **Issue Language (select one)**: Select the language you are using when experiencing the issue.
	+ **English**: Issues experienced on English language.
	+ **Spanish**: Issues experienced on Spanish language.
	+ **French**: Issues experienced on French language.

### Email
* **Email (email)**: Enter your contact email so that we can get back to you for further information or to resolve the issue.
