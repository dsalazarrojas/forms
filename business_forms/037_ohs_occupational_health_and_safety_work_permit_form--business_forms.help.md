> # ohs_business_forms - Help Guide
## Purpose
This form is designed to conduct site safety checks and assessments to ensure a safe working environment.

## How To Complete This Form
1. Start by filling out the `site_safety_checks` page, which is a mandatory section that requires you to select the necessary safety checks to be conducted on site.
2. Proceed to the `hazard_assessments` page, where you will select the level of hazard (High, Low, or No Hazard) for each assessment.
3. On the `risk_assessment` page, you will conduct a risk assessment, which is optional but recommended.
4. Move on to the `emergency_plan` page, where you will select the appropriate emergency plan for the site.
5. Enter the site security information on the `site_security` page, which is a mandatory date field.
6. On the `site_clearance` page, you will select the site clearance status (Option A, Option B, Option C, or Option D).
7. Enter the site clearance date on the `site_clearance_date` page, which is a mandatory date field.
8. Provide the supervisor's name on the `supervisor_name` page, which is a mandatory selection field.
9. Sign the form with the supervisor's signature on the `supervisor_signature` page, which is a mandatory selection field.
10. Finally, enter the date on the `date` page, which is a mandatory date field.

## Field-by-Field Explanation
* **Site Safety Checks** (`site_safety_checks`, `note`, required): This is the first page of the form, which requires you to select the necessary site safety checks to be conducted on site.
* **Hazard Assessments** (`hazard_assessments`, `select_multiple`, required): Select the level of hazard (High, Low, or No Hazard) for each assessment.
* **Risk Assessment** (`risk_assessment`, `note`, required): This is an optional page where you will conduct a risk assessment.
* **Emergency Plan** (`emergency_plan`, `select_one`, required): Select the appropriate emergency plan for the site.
* **Site Security** (`site_security`, `date`, required): Enter the site security information as a date.
* **Site Clearance** (`site_clearance`, `select_one`, optional): Select the site clearance status (Option A, Option B, Option C, or Option D).
* **Site Clearance Date** (`site_clearance_date`, `date`, required): Enter the site clearance date.
* **Supervisor Name** (`supervisor_name`, `select_one`, required): Enter the supervisor's name.
* **Supervisor Signature** (`supervisor_signature`, `select_one`, required): Sign the form with the supervisor's signature.
* **Date** (`date`, `date`, required): Enter the date.

**Tips**

* Ensure that you complete all mandatory fields (indicated by `required` label).
* Review the form carefully before submission to avoid errors.
* If you are unsure about any field, refer to the form's purpose and instructions for clarification.
