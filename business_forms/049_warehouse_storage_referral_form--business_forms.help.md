# Warehouse Storage Referral Form - Help Guide

## Purpose
The Warehouse Storage Referral Form is used to gather information about potential clients and their storage facility needs. This form helps to efficiently collect and organize data about client preferences, facility characteristics, and other relevant details.

## How To Complete This Form
To complete this form accurately and efficiently, follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Select the correct options for client type, facility type, and other relevant characteristics.
3. Enter the available storage space if it is available for rental.
4. Make sure to include any relevant notes or comments about the facility or client.
5. Review the form carefully before submission to ensure accuracy and completeness.

## Field-by-Field Explanation

* **Client Name (id: 1)**: Enter the name of the client you are referring. This can be a person, company, or organization.
* **Company Name (id: 2)**: Enter the full name of the company or organization being referred.
* **Contact Number (id: 3)**: Enter the phone number of the client or contact person.
* **Email (id: 4)**: Enter the email address of the client or contact person.
* **Date of Contact (id: 5)**: Enter the date of your contact with the client.
* **Facility Name (id: 6)**: Enter the name of the storage facility or warehouse being referred.
* **Facility Address (id: 7)**: Enter the address of the storage facility or warehouse being referred.
* **Client Type (id: 8)**: Select the type of client from the list:
	+ Logistics Company
	+ Storage Facility
	+ Other
* **Storage Capacity (id: 9)**: Enter the total capacity of the storage facility or warehouse.
* **Facility Capacity (id: 10)**: Enter the capacity of the facility or warehouse being referred.
* **Storage Space (id: 11)**: Enter the available storage space of the facility or warehouse.
* **Facility Location (id: 12)**: Select the location of the facility from the list:
	+ New York
	+ Los Angeles
	+ Chicago
* **Facility Status (id: 13)**: Select the status of the facility from the list:
	+ Available
	+ Not Available
	+ Pending
* **Available Storage Space (id: 14)**: Enter the available storage space if it is available for rental. If not available, leave this field blank.
* **Facility Type (id: 15)**: Select the type of facility from the list:
	+ Self Storage
	+ Full Service
	+ Climate Controlled
* **Facility Security (id: 16)**: Select the security level of the facility from the list:
	+ 24/7 Access
	+ Gate Guarded
	+ Self Serve
* **Facility Parking (id: 17)**: Select the parking availability of the facility from the list:
	+ Free Parking
	+ Paid Parking
	+ No Parking
* **Facility Elevator (id: 18)**: Select the elevator availability of the facility from the list:
	+ True
	+ False
	+ Not Applicable
* **Facility Forklift (id: 19)**: Select the fork lift availability of the facility from the list:
	+ Available
	+ Not Available
	+ Not Applicable
* **Facility Liftgate (id: 20)**: Select the lift gate availability of the facility from the list:
	+ Available
	+ Not Available
	+ Not Applicable
* **Facility Rail Capable (id: 21)**: Select the rail capable facility status from the list:
	+ True
	+ False
	+ Not Applicable
* **Facility Liftgate (id: 22)**: Select the lift gate status from the list:
	+ Available
	+ Not Available
	+ Not Applicable
* **Facility Handicap (id: 23)**: Select the handicap accessibility of the facility from the list:
	+ True
	+ False
	+ Not Applicable
* **Facility Wifi (id: 24)**: Select the wifi availability of the facility from the list:
	+ Available
	+ Not Available
	+ Not Applicable
* **Notes (id: 25)**: Enter any additional notes or comments about the facility or client.
