# Process Documentation Access Request - Help Guide
## Purpose
This form is used to request access to process documentation. Fill out this form to specify the document details, reasons for access, intended use, and approval processes.

## How To Complete This Form
1.  Select the **Request Type** as "Access Request", "Update Request", or "Delete Request".
2.  Choose the **Document Category** from the list of available categories.
3.  Specify the **Request Reason** for accessing the document.
4.  Select the **Approver** for the request.
5.  Fill out the **Document Details** section.
6.  Select the **Access Level** as "Read", "Write", "Execute", or "Delete".
7.  Set the **Access Expiration** date, if applicable.
8.  Fill out the **Comments** section, if necessary.
9.  Specify the **Requestor** details.
10. Select the **Requestor ID**.
11. Fill out the **Document Status** field with the current document status.

## Field-by-Field Explanation
*   **Request Type** (Select One, Required): This field determines the type of request being made.
*   **Document Category** (Select One, Required): This field selects the category of the document being accessed.
*   **Request Reason** (Text, Optional): Enter the reason for accessing the document.
*   **Approver** (Select One, Required): This field selects the approver for the request.
*   **Document Details** (Text, Optional): Enter document details.
*   **Intended Use** (Text, Optional): Enter the intended use of the document.
*   **Approval Process** (Select One, Optional): Select the approval process for the request.
*   **Approval Date** (Date, Optional): Enter the date of approval.
*   **Approved By** (Select One, Optional): Select the person who approved the request.
*   **Comments** (Text, Optional): Enter comments for the request.
*   **Approved** (Select One, Required): Select whether the request is approved or not.
*   **Date of Approval** (Date, Optional): Enter the date of approval.
*   **User ID** (Select One, Required): This field selects the user requesting access.
*   **Document ID** (Select One, Required): This field selects the ID of the document being accessed.
*   **Access Level** (Select One, Required): Select the access level for the document (Read, Write, Execute, or Delete).
*   **Access Expiration** (Date, Optional): Enter the access expiration date.
*   **Comments Section** (Text, Optional): Enter comments for the request.
*   **Request Reason** (Text, Optional): Enter reason for accessing the document.
*   **Document Type** (Select One, Optional): Select the type of document being accessed.
*   **Document Status** (Text, Required): Enter the current document status.
*   **Requestor** (Text, Required): Enter requestor details.
*   **Requestor ID** (Select One, Required): This field selects the ID of the requestor.
*   **Request Type** (Select One, Required): Select the request type.
*   **Document Category** (Select One, Required): Select the category of the document being accessed.
*   **Request Status** (Select One, Required): Select the request status (Active or Inactive).
*   **Approver** (Select One, Required): Select the approver.
*   **Approver ID** (Select One, Required): This field selects the approver ID.
