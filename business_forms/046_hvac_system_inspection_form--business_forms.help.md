# hvac_system_inspection_form - Help Guide
## Purpose
This form is used to collect information about an HVAC system's location, type, and inspection date. It is designed to gather data on the system's status and help maintain accurate records.

## How To Complete This Form
1.  Fill out the form completely, making sure to include all required and optional fields.
2.  Ensure the information provided is accurate and relevant to the HVAC system being inspected.
3.  Use the available options in select fields to select the correct information.

## Field-by-Field Explanation
- **System** (`system_info`, note, optional): This is a text field for any additional notes on the system being inspected. Enter any relevant details about the system.
- **Location** (`location`, text, optional): Enter the exact address or location of the HVAC system.
- **System Type** (`system_type`, select_one, optional): Choose the type of HVAC system being inspected (Residential, Commercial, or Industrial).
- **Date Installed** (`date_installed`, date, optional): Enter the date the HVAC system was originally installed.
- **Installation Contractor** (`installation_contractor`, text, optional): Enter the name of the contractor who installed the HVAC system.
- **Inspection Date** (`inspection_date`, date, optional): Enter the date the HVAC system was inspected.
- **System Status** (`system_status`, select_one, optional): Choose the current status of the HVAC system (Functional, Non-Functional, or Not Present).
- **Comments** (`comments`, note, optional): Enter any additional comments or observations about the HVAC system.

## Tips
- Be thorough when filling out the form to ensure accurate information is collected.
- Use the available options in select fields to select the correct information.
- If a field is left blank, it may indicate a problem with the HVAC system.
- Save and submit the form only after ensuring all required and optional fields have been filled out correctly.
- Review and verify the information before saving to prevent duplicate submissions.
