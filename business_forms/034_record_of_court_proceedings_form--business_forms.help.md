# record_of_court_proceedings_form - Help Guide
## Purpose
This form is used to record and track court proceedings, allowing for the collection of data on various aspects of court cases.

## How To Complete This Form
To complete this form, please follow the steps below:

1.  Enter the Case Number, which is a unique identifier for the case.
2.  Enter the Court Number, which is also a unique identifier for the court.
3.  Enter the Judge Name, if applicable.
4.  Enter the Court Date, if applicable.
5.  Enter the Court Time, if applicable.
6.  Select the Witness List from the given options, as this field is required.
7.  Enter the Witness Name and Witness Position, if applicable.
8.  Select the Ruling, which is a required field.
9.  Enter any Testimony, if applicable.
10.  Select whether or not there is Evidence.
11.  Select whether or not the Deposition is involved.
12.  Select the Ruling Type from the given options, as this field is required.

## Field-by-Field Explanation
- **Case Number** (`case_number`, Number, Required): Enter a unique identifier for the case.
- **Court Number** (`court_number`, Number, Required): Enter a unique identifier for the court.
- **Judge Name** (`judge_name`, Text, Optional): Enter the name of the judge, if applicable.
- **Court Date** (`court_date`, Date, Optional): Enter the date of the court proceeding.
- **Court Time** (`court_time`, Time, Optional): Enter the time of the court proceeding.
- **Witness List** (`witness_list`, Select Multiple, Required): Select all applicable witnesses from the given options.
- **Witness Name** (`witness_name`, Text, Optional): Enter the name of the witness.
- **Witness Position** (`witness_position`, Text, Optional): Enter the position of the witness.
- **Ruling** (`ruling`, Select One, Required): Select the ruling outcome.
- **Testimony** (`testimony`, Note, Optional): Enter any relevant testimony.
- **Evidence** (`evidence`, Select One, Required): Select whether or not there is evidence.
- **Deposition** (`deposition`, Select Multiple, Required): Select whether or not the deposition is involved.
- **Ruling Type** (`ruling_type`, Select Multiple, Required): Select the type of ruling from the given options.
