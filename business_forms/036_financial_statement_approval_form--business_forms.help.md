# Financial Statement Approval Form - Help Guide
## Purpose
This form is used for managerial or executive-level approvals of financial documents within an organization. It captures information about financial documents, their periods, and approval levels.

## How To Complete This Form
1. Start by reviewing the financial document attached or provided.
2. Select the correct financial period from the options provided (Financial Q1, Q2, Q3, or Q4).
3. Choose one or more approval levels from the list (Manager, Director, CEO, CFO, or Other).
4. Enter the date of approval using the date field.
5. If needed, select the time of approval using the time field.

## Field-by-Field Explanation
* **Financial Information** (`financial_statement_approval_form`, `note`, not required): This field provides space for a brief description or summary of the financial information being submitted.
* **Financial Document** (`financial_statement_approval_form_financial_document`, `text`, not required): Enter the name or description of the financial document.
* **Financial Period** (`financial_statement_approval_form_financial_period`, `select_one`, not required): Select the correct financial period (Financial Q1, Q2, Q3, or Q4) that the financial document pertains to.
* **Approval Level** (`financial_statement_approval_form_approval_level`, `select_multiple`, not required): Choose one or more approval levels (Manager, Director, CEO, CFO, or Other) to approve the financial document.
* **Approval Date** (`financial_statement_approval_form_approval_date`, `date`, not required): Enter the date of approval using the date field in the format specified by your organization.
* **Approval Time** (`financial_statement_approval_form_approval_time`, `time`, not required): If needed, select the time of approval using the time field in the format specified by your organization.

## Tips
- Please ensure that you have all necessary information and permissions before completing this form.
- Review the financial document carefully before proceeding with approval.
- Use the correct financial period and approval level to accurately represent the document's scope and authority.
- Adjust the "required" settings according to your organization's actual needs and regulations.
