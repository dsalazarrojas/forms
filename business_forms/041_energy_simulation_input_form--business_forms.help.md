# Energy Simulation Input Form - Help Guide
## Purpose
The "Energy Simulation Input Form" is used to input data for energy simulations. This data is likely used to analyze and predict energy consumption, production, or other relevant outcomes for a building or location.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the relevant fields for your simulation by choosing the correct options from the drop-down menus or entering data in the text fields.
2. Ensure all required fields are filled out before submitting the form.

## Field-by-Field Explanation

* **Building Type** (`building_type`, text, optional): This field is used to select the type of building you are simulating. Please select the relevant building type from the provided options.
* **Building Size** (`building_size`, number, optional): This field is used to input the size of the building in square meters.
* **Climate Zone** (`climate_zone`, select_one, optional): This field is used to select the climate zone of the location being simulated. Please choose from the provided options.
* **Energy Use** (`energy_use`, select_multiple, optional): This field is used to select the type(s) of energy use for the simulation. Please choose from the provided options.
* **Simulation Type** (`simulation_type`, select_one, optional): This field is used to select the type of simulation being run. Please choose from the provided options.
* **Location** (`location`, text, optional): This field is used to input the location of the building or simulation.
* **Building Direction** (`building_direction`, number, optional): This field is used to input the direction of the building.
* **Energy Consumption** (`energy_consumption`, number, optional): This field is used to input the energy consumption of the building.
* **Climate Data** (`climate_data`, date, optional): This field is used to input the date for the climate data.
* **Start Time** (`start_time`, time, optional): This field is used to input the start time of the simulation.
* **End Time** (`end_time`, time, optional): This field is used to input the end time of the simulation.
* **Simulation Duration** (`simulation_duration`, number, optional): This field is used to input the duration of the simulation.

## Tips
* Please ensure all fields are filled out accurately and completely before submitting the form.
* If you are unsure about any field, please refer to the relevant documentation or seek guidance from a qualified professional.
