# Machine Maintenance Report Form - Help Guide
## Purpose
The Machine Maintenance Report Form is used to document machine maintenance activities for new machines that have not been previously registered in the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the relevant information.
2. Select the maintenance activities that were performed on the machine.
3. Enter the machine's serial number, model, and other relevant details.
4. Select the priority level of the maintenance activity.
5. Select the status of the maintenance activity.
6. Select the person responsible for the maintenance activity.
7. Select the location where the maintenance activity was performed.
8. Enter any additional notes about the maintenance activity.

## Field-by-Field Explanation

* **Machine Maintenance Report** (`machine_maintenance_form_1`): Enter a brief description of the machine maintenance activity.
* **Maintenance Activities** (`machine_maintenance_form_2`): Select the maintenance activities that were performed on the machine, such as Task 1, Task 2, or Task 3.
* **Schedule Task** (`machine_maintenance_form_3`): Select multiple schedule tasks that were performed on the machine.
* **Machinery ID** (`machine_maintenance_form_4`): Enter the machine's ID number.
* **Serial Number** (`machine_maintenance_form_5`): Enter the machine's serial number.
* **Description** (`machine_maintenance_form_6`): Enter a brief description of the machine.
* **Date** (`machine_maintenance_form_7`): Enter the date the maintenance activity was performed.
* **Time** (`machine_maintenance_form_8`): Enter the time the maintenance activity was performed.
* **Priority** (`machine_maintenance_form_9`): Select the priority level of the maintenance activity, such as High, Low, or Medium.
* **Status** (`machine_maintenance_form_10`): Select the status of the maintenance activity, such as Open, Closed, or Pending.
* **Responsible** (`machine_maintenance_form_11`): Select the person responsible for the maintenance activity, such as John, Jane, or Jim.
* **Location** (`machine_maintenance_form_12`): Select the location where the maintenance activity was performed, such as Office, Warehouse, or Factory.
* **Notes** (`machine_maintenance_form_13`): Enter any additional notes about the maintenance activity.
* **Email** (`machine_maintenance_form_14`): Enter the contact email of the person responsible for the maintenance activity.
* **Phone** (`machine_maintenance_form_15`): Enter the contact phone number of the person responsible for the maintenance activity.
* **Machine Type** (`machine_maintenance_form_16`): Select the type of machine, such as Machine 1, Machine 2, or Machine 3.
* **Machine Model** (`machine_maintenance_form_17`): Enter the machine's model number.
* **Serial Number 2** (`machine_maintenance_form_18`): Enter the machine's serial number.
* **Maintenance Schedule** (`machine_maintenance_form_19`): Enter the maintenance schedule for the machine.
* **Maintenance Date** (`machine_maintenance_form_20`): Enter the date the maintenance activity was scheduled.
* **Maintenance Time** (`machine_maintenance_form_21`): Enter the time the maintenance activity was scheduled.
* **Due Date** (`machine_maintenance_form_22`): Enter the due date of the maintenance activity.
* **Next Action** (`machine_maintenance_form_23`): Enter the next action to be performed on the machine.
* **Next Date** (`machine_maintenance_form_24`): Enter the date the next action is scheduled.
* **Next Time** (`machine_maintenance_form_25`): Enter the time the next action is scheduled.

## Tips
* Make sure to enter accurate and complete information to ensure that the machine's maintenance history is up-to-date.
* If you are unsure about any field, please refer to the machine's profile or contact the maintenance team for clarification.
* This form is for machines that have not been previously registered in the system. If you are updating a machine's maintenance record, please use the machine's profile directly.
