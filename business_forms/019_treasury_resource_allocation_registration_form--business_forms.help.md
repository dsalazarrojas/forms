# treasury Resource Allocation Registration Form - Help Guide
## Purpose
This form is used to register resource allocation for treasury purposes.

## How To Complete This Form
1. Please ensure that you have all the necessary information to complete the form accurately.
2. Review the form pages and sections carefully to avoid any errors.
3. Fill out the form in a logical order, page by page.
4. For each field, read the label and explanation carefully before entering any information.
5. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
* **Page 1 (Page 1)** (`first_page`, text, optional): This page is for general information and can be filled out as needed.
* **Page 2 (Page 2)** (`page_2`, select_multiple, required): On this page, you will select one or more options from the list.
	+ Please choose the relevant options that apply to your resource allocation.
	+ Ensure that you select at least one option.
* **Page 3 (Page 3)** (`page_3`, date, optional): This is a date field, which is used to input a date in the format YYYY-MM-DD.
* **Page 4 (Page 4)** (`page_4`, select_one, optional): On this page, you will select one option from the list.
	+ Please choose the relevant option that applies to your resource allocation.
* **Page 5 (Page 5)** (`page_5`, note, optional): This is a free-text field for any additional information.

Note: The fields on each page are marked as required or optional. Please ensure that you have filled out all required fields before submitting the form.
