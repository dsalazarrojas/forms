# Cost Allocation Change Request Form - Help Guide

## Purpose
The purpose of this form is to submit changes to cost allocations for different business activities. This form helps employees and managers keep track of and manage changes in cost allocations.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your name and employee ID in the respective fields.
2. Enter the name of the manager who will be approving your request.
3. Select the department and account code related to the change.
4. Enter the cost center and cost code associated with the change.
5. Choose the type of change (e.g., addition, deletion, update).
6. Provide a brief description of the change.
7. Enter the effective date of the change.
8. Select the status of the request (e.g., pending, approved, rejected).
9. Once you have completed all the fields, submit the form for review and approval.

## Field-by-Field Explanation

* **Form Title** (page 1): Enter a brief description of the reason for the change.
* **Employee Name** (page 1): Enter your full name as it appears on your personnel record.
* **Employee ID** (page 1): Enter your employee ID number.
* **Manager Name** (page 1): Enter the full name of the manager who will be approving this request.
* **Department** (page 1): Enter the department related to the change.
* **Account Code** (page 1): Enter the account code associated with the change.
* **Cost Center** (page 1): Enter the cost center related to the change.
* **Cost Code** (page 1): Enter the cost code associated with the change.
* **Change Type** (page 1): Choose the type of change (e.g., addition, deletion, update).
	+ Type 1: Addition
	+ Type 2: Deletion
	+ Type 3: Update
	+ Type 4: Other
	+ Type 5: Unknown
* **Description** (page 1): Enter a brief description of the change.
* **Cost Allocation** (page 1): Enter the details of the cost allocation change.
* **Effective Date** (page 1): Enter the date on which the change will be effective.
* **Approved By** (page 1): Enter the name of the manager who approved this request.
* **Manager Approval Date** (page 1): Enter the date on which this request was approved.
* **Manager Approved By** (page 1): Enter the name of the manager who approved this request.
* **Request Status** (page 1): Select the status of the request (e.g., pending, approved, rejected).
	+ Status 1: Pending
	+ Status 2: Approved
	+ Status 3: Rejected
	+ Status 4: In progress
	+ Status 5: Cancelled

Note to self: In this help guide, the term "page" is used to refer to each section or group of fields on the form, rather than an actual printed page.
