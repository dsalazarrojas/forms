# Maintenance Check In Form - Help Guide
## Purpose
The Maintenance Check In Form is used to record and track maintenance activities, ensuring that all relevant information is captured and up-to-date.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter your user input information in the "User Input" field.
2. Select a date for the maintenance check-in.
3. Add a description of the maintenance activity.
4. Choose the users assigned to work on the task.
5. Provide any additional comments about the task.
6. Select the current status of the task (e.g., In Progress, Done, Waiting).
7. Enter the due date for the maintenance check-in.
8. Record the actual start time of the maintenance activity.
9. Record the actual finish time of the maintenance activity.
10. Select a date for the actual finish of the maintenance activity.
11. Enter any additional comments about the task.
12. Select the tool assigned to the maintenance activity (e.g., chatjimmy or Other).

## Field-by-Field Explanation

* **User Input (User Input, text, required/optional)**: Enter any relevant information about the maintenance activity.
* **date (date, required/optional)**: Select the date for the maintenance check-in.
* **description (description, text, required/optional)**: Describe the maintenance activity being performed.
* **assigned_to (assigned_to, select_multiple, required/optional)**: Choose the users assigned to work on the task. (e.g., User 1, User 2, User 3)
* **comments (comments, text, required/optional)**: Enter any additional comments or notes about the task.
* **status (status, select_one, required/optional)**: Select the current status of the task (e.g., In Progress, Done, Waiting).
* **due_date (due_date, required/optional)**: Enter the due date for the maintenance check-in.
* **actual_start_time (actual_start_time, required/optional)**: Record the actual start time of the maintenance activity.
* **actual_finish_time (actual_finish_time, required/optional)**: Record the actual finish time of the maintenance activity.
* **actual_finish_date (actual_finish_date, required/optional)**: Select the actual finish date of the maintenance activity.
* **comments_2 (comments_2, text, required/optional)**: Enter any additional comments about the task.
* **assigned_tool (assigned_tool, select_one, required/optional)**: Select the tool assigned to the maintenance activity (e.g., chatjimmy or Other).
