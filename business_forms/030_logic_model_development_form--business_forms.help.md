Logic Model Development Form - Help Guide

The purpose of this form is to collect information about a specific logic model, a tool used in program planning and evaluation. This form will help you to gather data on the goals, activities, outputs, and outcomes of a project or program. Please note that this form is for the development of a logic model, not for evaluating one.

This form is used to collect data on a single project or program. If you are looking to evaluate or update an existing logic model, please use the "Logic Model Evaluation Form" or "Logic Model Update Form", which have similar fields but slightly different requirements.

## Purpose
The Logic Model Development Form is used to gather information about a specific project or program's goals, activities, outputs, and outcomes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out each page as you progress through the form.
2. Answer each question honestly and thoroughly.
3. Make sure to review your answers for accuracy and clarity before submitting.

## Field-by-Field Explanation
### Goals (Page 1)
* **goals**: A list of the project's or program's specific goals. Select all goals that apply to your project.

### Activities (Page 2)
* **activities**: A list of the activities that will help achieve the project's or program's goals.
	+ Provide a brief description of each activity.

### Outputs (Page 3)

## Tips
