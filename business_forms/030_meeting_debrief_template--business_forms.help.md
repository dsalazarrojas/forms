# Meeting Debrief Template - Help Guide

## Purpose
The Meeting Debrief Template is designed to facilitate post-meeting discussions, review meeting outcomes, and plan next steps.

## How To Complete This Form
1. Fill in the form with the following information:
	* Meeting Organizer
	* Meeting ID
	* Date
	* Start Time
	* Location
	* Prophets (Yes/No)
	* Notes
	* Attendees (Yes/No)
	* Meeting Objectives (Yes/No)
	* Outcomes (Yes/No)
	* Next Steps (Yes/No)
	* Meeting Goals
	* Action Items
	* Follow-up Tasks (Yes/No)
	* Next Steps Date (optional)
	* Follow-up Tasks Status (Active/Inactive)
	* Follow-up Tasks Date (optional)
	* Meeting Outcomes
	* Meeting Notes
	* Meeting Attendance (Yes/No)
	* Follow-up Tasks Notes
	* Meeting Summary
	* Follow-up Status (Active/Inactive)
	* Follow-up Date (optional)
	* Follow-up Followers (Yes/No)
2. Review each field carefully and fill in the necessary information.
3. Save and store the form for future reference.

## Field-by-Field Explanation

* **Meeting Organizer**: The person who organized the meeting.
	+ Type: text
	+ Required: yes
* **Meeting ID**: A unique identifier for the meeting.
	+ Type: number
	+ Required: yes
* **Date**: The date the meeting took place.
	+ Type: date
	+ Required: no
* **Start Time**: The start time of the meeting.
	+ Type: time
	+ Required: yes
* **Location**: The location of the meeting.
	+ Type: text
	+ Required: yes
* **Prophets**: A yes/no field indicating if prophets were present.
	+ Type: select_multiple
	+ Required: yes
* **Notes**: A text area for any additional comments or notes about the meeting.
	+ Type: note
	+ Required: yes
* **Attendees**: A yes/no field indicating if attendees were present.
	+ Type: select_multiple
	+ Required: yes
* **Meeting Objectives**: A yes/no field indicating if meeting objectives were met.
	+ Type: select_multiple
	+ Required: yes
* **Outcomes**: A yes/no field indicating if the meeting outcomes were met.
	+ Type: select_multiple
	+ Required: yes
* **Next Steps**: A yes/no field indicating if next steps are in place.
	+ Type: select_multiple
	+ Required: yes
* **Meeting Goals**: A text field for documenting the meeting goals.
	+ Type: text
	+ Required: yes
* **Action Items**: A text field for documenting action items.
	+ Type: text
	+ Required: yes
* **Follow-up Tasks**: A yes/no field indicating if follow-up tasks are in place.
	+ Type: select_multiple
	+ Required: yes
* **Next Steps Date**: A date field for documenting the next steps date.
	+ Type: date
	+ Required: no
* **Follow-up Tasks Status**: A select_multiple field for documenting the status of follow-up tasks.
	+ Type: select_multiple
	+ Required: yes
* **Follow-up Tasks Date**: A date field for documenting the follow-up tasks date.
	+ Type: date
	+ Required: no
* **Meeting Outcomes**: A text field for documenting meeting outcomes.
	+ Type: text
	+ Required: yes
* **Meeting Notes**: A text field for documenting meeting notes.
	+ Type: note
	+ Required: yes
* **Meeting Attendance**: A yes/no field indicating if attendees were present.
	+ Type: select_multiple
	+ Required: yes
* **Follow-up Tasks Notes**: A text field for documenting follow-up tasks notes.
	+ Type: note
	+ Required: yes
* **Meeting Summary**: A text field for documenting meeting summary.
	+ Type: text
	+ Required: yes
* **Follow-up Status**: A select_multiple field for documenting the follow-up status.
	+ Type: select_multiple
	+ Required: yes
* **Follow-up Date**: A date field for documenting the follow-up date.
	+ Type: date
	+ Required: no
* **Follow-up Followers**: A yes/no field indicating if follow-up followers are present.
	+ Type: select_multiple
	+ Required: yes

## Tips
- Be thorough and accurate when filling out the form.
- Review each field carefully and ensure that you are providing the correct information.
- Store the form in a safe and secure location for future reference. 
- Consider setting reminders for follow-up tasks and next steps to stay on track. 
- Review and update the form regularly to maintain up-to-date information.
