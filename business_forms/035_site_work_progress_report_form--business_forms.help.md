# Site Work Progress Report Form - Help Guide
## Purpose
The Site Work Progress Report Form is a general form designed to track progress on site work projects. This form helps you gather information about site work progress, including site address, project details, contact information, and other relevant data. 

## How To Complete This Form

This form is divided into multiple pages, each containing fields that need to be filled out. Please go through each page carefully and provide the required information. 

## Field-by-Field Explanation

* **Site Progress** (Page 1): Please select whether the site work is in progress or not. You can choose from 'Yes' or 'No'.
* **Site Address** (Page 2): Enter the address of the site where the work is being done.
* **Client** (Page 3): Enter the client's name who commissioned the project.
* **Project Details** (Page 4): Select whether the project is in progress or not.
* **Site Contact** (Page 5): Enter the contact person's name and contact information.
* **Site Manager** (Page 6): Select whether the site manager is available or not.
* **Project Status** (Page 7): Select the status of the project, whether it's Active or Inactive.
* **Site Notes** (Page 8): Enter any additional notes or comments about the site work.
* **Client Signature** (Page 9): Select whether the client has signed the project documents or not.
* **Project Manager Signature** (Page 10): Select whether the project manager has signed the project documents or not.
* **Site Date** (Page 11): Enter the date when the site work started.
* **Site Time** (Page 12): Enter the time when the site work started.
* **Project Start Date** (Page 13): Enter the date when the project started.
* **Project Finish Date** (Page 14): Enter the date when the project is expected to finish.
* **Work Status** (Page 15): Enter a brief description of the work status.
* **Progress Percentage** (Page 16): Select whether the project is progressing or not.
* **Project Manager** (Page 17): Select whether the project manager is available or not.
* **Site Supervisor** (Page 18): Select whether the site supervisor is available or not.
* **Site Work** (Page 19): Enter a brief description of the site work.
* **Site Area** (Page 20): Select whether the site area is available or not.
* **Site Area Size** (Page 21): Enter the site area size.
* **Site Address** (Page 22): Enter the site address.
* **Site Contact** (Page 23): Enter the site contact person's name and contact information.
* **Site Notes** (Page 24): Enter any additional notes or comments about the site work.
