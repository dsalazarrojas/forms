# media_coverage_verification_form - Help Guide
## Purpose
The media_coverage_verification_form is designed to collect and verify information about media coverage of events, issues, or topics. This form helps media outlets, organizations, or researchers gather relevant details from publications, such as publication names, dates, types, and journalists involved.

## How To Complete This Form
1. Fill in the publication's name in the "Publication Name" field.
2. Enter the date of coverage in the "Coverage Date" field (format: MM/DD/YYYY).
3. Select the type of publication (e.g., newspaper, magazine, online) from the "Publication Type" field.
4. Enter the journalist's name in the "Journalist Name" field.
5. Make sure to fill in all required fields, and you can leave optional fields empty if not applicable.

## Field-by-Field Explanation

* **Publication Name** (`publication_name`, text, required): Enter the name of the publication that covered the event or issue.
* **Coverage Date** (`coverage_date`, date, required): Enter the date of coverage in the format MM/DD/YYYY.
* **Publication Type** (`publication_type`, text, required): Select the type of publication (e.g., newspaper, magazine, online).
* **Journalist Name** (`journalist_name`, text, required): Enter the name of the journalist involved in the coverage.

## Tips
* Use clear and accurate information when filling in the publication name and journalist name.
* If the coverage date is not known, leave the "Coverage Date" field empty.
* If the publication type is not applicable, select the closest match from the options.
* You can save the form and come back to it later if needed.
