# Process Failure Analysis Request Form - Help Guide

## Purpose
The Process Failure Analysis Request Form is used to submit a request for process failure analysis to the relevant team or department. This form helps ensure that the issue is properly documented and tracked, and that the right team receives the request in a timely manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Category of the process failure that occurred.
2. Provide a brief Description of the issue.
3. Choose the Assigned Tool that was involved in the failure.
4. Upload any relevant Output File(s) for further analysis.
5. If applicable, enter the Form Id (a unique identifier for the form).
6. Optionally, provide the Date and Time the issue occurred (Created At).

## Field-by-Field Explanation
* **Category** (`Category`, select_one, required): Select the category that best describes the type of process failure that occurred (e.g. Business Forms, General Forms, Technical Forms).
* **Description** (`Description`, text, required): Provide a clear and concise description of the issue that occurred.
* **Assigned Tool** (`Assigned Tool`, select_one, required): Select the tool that was involved in the process failure.
* **Output File** (`Output File`, text, optional): Upload any files related to the issue, such as error logs or screenshots.
* **Form Id** (`Form Id`, number, optional): Enter a unique identifier for the form, if applicable.
* **Created At** (`Created At`, date, optional): Enter the date and time the issue occurred, if known.

## Tips
* Make sure to select the correct Category to ensure that the request is directed to the right team or department.
* Be as detailed as possible when providing the Description to help the analysis team quickly understand the issue.
* If the issue is complex, consider uploading relevant Output Files to support your claim.
* If you have a Form Id, enter it to help the analysis team track the issue.
