# Daily Job Report Form - Help Guide

## Purpose
The Daily Job Report Form is a simple form used by employees to report their work hours and tasks completed on a daily basis. It's a useful tool for time tracking and productivity monitoring.

## How To Complete This Form
1. Fill out the form for the day you're reporting on.
2. Enter the total number of hours you worked in the "work_hours" field.
3. Select "Yes" or "No" for each of the task fields ("task_1", "task_2", "task_3") to indicate if you completed the task.
4. If you completed a task, you can enter more details about it in the "task_3" text field.
5. Enter the date you worked in the "date_worked" field.

## Field-by-Field Explanation

* **work_hours** (number): Enter the total number of hours you worked during the day.
* **task_1** (select_one): Select "Yes" if you completed task 1, "No" otherwise.
* **task_2** (select_multiple): Select "Yes" if you completed task 2, "No" otherwise. You can select "Yes" for multiple tasks if applicable.
* **task_3** (text): Enter any additional details about task 3 if you completed it.
* **date_worked** (date): Enter the date you're reporting on.
