# Document Merge Request Form - Help Guide
## Purpose
The purpose of this form is to request merging of documents for a specific use case. This form is used by users to request merge of documents when they need to combine multiple documents into one.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the document type for which you are requesting merge.
2. Choose the document status.
3. Fill in the document version number.
4. Select whether you are the requester or not.
5. Enter the document owner's name.
6. Enter the document name.
7. Enter the name of the prophet(s) involved.
8. Provide a reason for merge.
9. Select the merge type.
10. Enter any additional comment.
11. Select the merge date and time.

## Field-by-Field Explanation
### 1. **Document Type** (select_one, required)
Choose the type of document you are requesting to merge.

### 2. **Document Status** (select_multiple, optional)
Select the current status of the document.

### 3. **Document Version** (number, optional)
Enter the current version number of the document.

### 4. **Requester** (select_one, optional)
Select whether you are the requester or not.

### 5. **Document Owner** (select_one, optional)
Select the document owner.

### 6. **Document Name** (text, optional)
Enter the name of the document.

### 7. **Prophets Name** (text, optional)
Enter the name of the prophet(s) involved.

### 8. **Reason for Merge** (text, optional)
Provide a reason for merging the document.

### 9. **Merge Type** (select_one, optional)
Select the type of merge.

### 10. **Comment** (note, optional)
Enter any additional comment.

### 11. **Date** (date, optional)
Enter the date of the merge.

### 12. **Time** (time, optional)
Enter the time of the merge.

### 16. **Address** (text, optional)
Enter your address.

### 17. **Document Number** (text, optional)

### 20. **Merge Status** (select_one, optional)
