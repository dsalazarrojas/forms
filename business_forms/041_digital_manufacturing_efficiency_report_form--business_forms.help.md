# Digital Manufacturing Efficiency Report Form - Help Guide
## Purpose
This form is designed to collect data related to the efficiency of digital manufacturing processes. It gathers information on production efficiency, equipment IDs, production dates and times, production hours, start and end times, and comments. The form is not a requirement, and its completion is voluntary.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the production efficiency from the list of options provided.
2. Enter the equipment ID, if applicable.
3. Select the production date from the calendar or enter it manually.
4. Enter the production hours worked.
5. Select the start time from the clock or enter it manually.
6. Select the production start time from the clock or enter it manually.
7. Select the production end time from the clock or enter it manually.
8. Provide comments or notes regarding production, if any.

## Field-by-Field Explanation
* **Production Efficiency** (`production_efficiency`, select_multiple, required: false): Select whether the production was efficient or not. Options are "Yes" and "No".
* **Equipment ID** (`equipment_id`, text, required: false): Enter the ID of the equipment used during production, if applicable.
* **Production Date** (`production_date`, date, required: false): Select the production date from the calendar or enter it manually.
* **Production Hours** (`production_hours`, number, required: false): Enter the number of hours worked during production.
* **Start Time** (`start_time`, time, required: false): Select the start time from the clock or enter it manually.
* **Production Start Time** (`production_start_time`, time, required: false): Select the production start time from the clock or enter it manually.
* **Production End Time** (`production_end_time`, time, required: false): Select the production end time from the clock or enter it manually.
* **Comments** (`comments`, note, required: false): Provide any additional comments or notes regarding production.
* **Department ID** (`department_id`, text, required: false): Enter the ID of the department involved in production, if applicable.
