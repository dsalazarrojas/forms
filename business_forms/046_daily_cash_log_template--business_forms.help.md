# Daily Cash Log Template - Help Guide
## Purpose
The Daily Cash Log Template is used to document and record daily cash transactions, including income and expenses, refunds, transfers, and other cash-related activities.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the **Cash Log Date** field with the date of the transaction.
2. Enter the **Account Code** associated with the transaction.
3. Describe the **Cash Description** of the transaction.
4. Select the **Cash Type** of the transaction from the provided options (e.g. Cash In, Cash Out, Refund, Transfer).
5. Enter the **Cash Amount** of the transaction.
6. Choose the **Cash Currency** of the transaction (e.g. USD, EUR, GBP, AUD).
7. Identify the person who recorded the transaction in the **Recorded By** field.
8. Optionally, include additional **Notes** about the transaction.
9. Select the **Assigned User** who is responsible for the transaction, if applicable.

## Field-by-Field Explanation
* **Cash Log Date**: Date of the transaction
	+ Format: mm/dd/yy
	+ Required: No
* **Account Code**: The account code associated with the transaction
	+ Enter the account code used for accounting and record-keeping purposes
* **Cash Description**: Description of the transaction
	+ Enter a brief description of the transaction
* **Cash Type**: Type of the transaction (e.g. Cash In, Cash Out, Refund, Transfer)
	+ Choose from the provided options
* **Cash Amount**: Amount of the transaction
	+ Enter the monetary amount of the transaction
* **Cash Currency**: Currency of the transaction (e.g. USD, EUR, GBP, AUD)
	+ Choose from the provided options
* **Recorded By**: Person who recorded the transaction
	+ Enter the name of the person who recorded the transaction
* **Notes**: Additional information about the transaction
	+ Enter any additional details about the transaction
* **Assigned User**: Person responsible for the transaction
	+ Choose from the provided options, if applicable
