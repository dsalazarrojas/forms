# Large Format Printing Quote Request Form - Help Guide
## Purpose
The purpose of this form is to collect information from the user about their project details and print requirements for the large format printing services.

## How To Complete This Form
Please follow these steps to complete the form accurately:

* Enter your project details in the "Project Details" field.
* Select the type of printing you need ("Rollup", "Banner", or "Poster").
* Specify the print area you need (enter the number of square inches or feet).
* Choose the paper type you need (Paper A, Paper B, or Paper C).
* Enter the quantity of prints needed.
* Select the finish type (Gloss, Matte, or Semi-gloss).
* Select the materials you need (Paper, Vinyl, or Banner).
* Choose the color(s) you need (Red, Blue, or Yellow).
* Enter the quantity per unit (e.g. 1 per sheet).
* Specify the unit of measure for your print (inches, feet, or yards).
* If necessary, add any special instructions for the printing process.
* If necessary, add any comments or notes about the project.
* If necessary, specify a date and time for submission.
* If necessary, provide your contact information (email, phone, or address).
* If necessary, attach any relevant files or documents.
* If necessary, specify the type and size of any files you need to upload.
* If necessary, add any additional comments or remarks.

## Field-by-Field Explanation

* **Project Details (1)**: Enter a brief description of your project.
* **Print Type (2)**: Select the type of printing you need: "Rollup", "Banner", or "Poster".
* **Print Area (3)**: Enter the print area in square inches or feet.
* **Paper Type (4)**: Choose the paper type you need: Paper A, Paper B, or Paper C.
* **Quantity (5)**: Enter the quantity of prints needed.
* **Finish Type (6)**: Select the finish type: Gloss, Matte, or Semi-gloss.
* **Material (7)**: Select the materials you need: Paper, Vinyl, or Banner.
* **Color (8)**: Choose the color(s) you need: Red, Blue, or Yellow.
* **Quantity Per Unit (9)**: Enter the quantity per unit.
* **Unit of Measure (10)**: Specify the unit of measure for your print (inches, feet, or yards).
* **Special Instructions (11)**: If necessary, add any special instructions for the printing process.
* **Comments (12)**: If necessary, add any comments or notes about the project.
* **Date Needed (13)**: If necessary, specify a date for submission.
* **Time Needed (14)**: If necessary, specify a time for submission.
* **Email (15)**: Enter your email address.
* **Phone (16)**: Enter your phone number.
* **Address (17)**: Enter your address.
* **File (18)**: Attach any relevant files or documents.
* **Attachment (19)**: Attach any other relevant files or documents.
* **Upload (20)**: If necessary, upload any files.
* **File Type (21)**: Specify the type of file(s) you need to upload (e.g. PDF, DOCX, TXT).
* **File Size (22)**: Enter the size of the file(s) you need to upload.
* **File Size Unit (23)**: Specify the unit of measure for the file size (KB, MB, or GB).
* **Comments (24)**: If necessary, add any additional comments or remarks.
* **Submission (25)**: Enter any final comments or remarks before submission.
