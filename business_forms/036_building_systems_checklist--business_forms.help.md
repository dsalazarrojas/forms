# Building Systems Checklist - Help Guide

## Purpose
This form is a comprehensive checklist designed for inspecting and evaluating the status of various building systems, including security cameras, fire extinguishers, doors and locks, gates, lighting, alarm systems, sprinkler systems, HVAC, plumbing, electrical, backup power, and other critical systems. It provides a structured approach to ensure that all necessary checks are performed and issues are documented.

## How To Complete This Form

1. Fill out the form for each building location.
2. Enter the checklist date.
3. Enter the building location.
4. Enter the inspector's name.
5. Select the shift or time of the check (morning, afternoon, evening, or night).
6. Answer all questions about system functionality and status.
7. Enter any notes or details for each system.
8. Check if urgent repairs are needed.

## Field-by-Field Explanation

* **Checklist Date**: The date of the systems check. Please enter the current date in the format 'YYYY-MM-DD'.
* **Building Location**: Enter the name of the facility or location being inspected.
* **Inspector Name**: The name of the person conducting the inspection.
* **Shift or Time of Check**: Select the shift or time of day when the inspection was performed (morning, afternoon, evening, or night).
* **Security Cameras Operational**: Check if all security cameras are working properly.
* **Camera System Notes**: Enter any notes or details about the camera system.
* **Fire Extinguishers Present and Accessible**: Check if all fire extinguishers are present and accessible.
* **Fire Extinguisher Inspection Current**: Check if the fire extinguisher inspection is current.
* **All Doors and Locks Functional**: Check if all doors and locks are functional.
* **Door Contact Sensors Working**: Check if door contact sensors are working properly.
* **Entry and Exit Gates Operational**: Check if entry and exit gates are operational.
* **Gate System Notes**: Enter any notes or details about the gate system.
* **External Sign Lighting Operational**: Check if external sign lighting is operational.
* **Lighting System Details**: Enter any notes or details about the lighting system.
* **Alarm System Operational**: Check if the alarm system is operational.
* **Emergency Lighting Functional**: Check if emergency lighting is functional.
* **Sprinkler System Operational**: Check if the sprinkler system is operational.
* **HVAC System Operating**: Check if the HVAC system is operating properly.
* **Temperature and Humidity Levels**: Check the building climate (comfortable, acceptable, below standard, concerning).
* **Plumbing Systems Working**: Check if the plumbing systems are working properly.
* **Electrical Systems Functional**: Check if the electrical systems are functional.
* **Backup Power System Operational**: Check if the backup power system is operational.
* **Issues or Problems Found**: List any issues or problems found during the inspection.
* **Actions Taken**: Enter any actions taken or repairs made.
* **Urgent Repairs Needed**: Check if urgent repairs are needed.
