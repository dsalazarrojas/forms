# Project Milestone Monitoring Form - Help Guide
## Purpose
This form is used for monitoring project milestone progress.

## How To Complete This Form
1. Fill in the following fields:
   * Project Title: Enter the title of the project.
   * Project Description: Enter a brief description of the project.
   * Project Deadline: Enter the deadline for the project.
   * Responsible Party: Check if the project is the responsibility of the user.
   * Project Status: Select if the project is Active or Inactive.
   * Project Category: Select if the project has a category.
   * Project Tags: Select if the project has tags.
   * Assigned User: Check if the project is assigned to a user.
   * Project Manager: Check if the project is managed by the user.
2. Fill out the remaining fields as relevant.

## Field-by-Field Explanation

* **Project Title**: Enter a brief and descriptive title for the project.
* **Project Description**: Enter a short description of the project.
* **Project Deadline**: Enter the date by which the project is expected to be completed.
* **Project Start Date**: Enter the date on which the project began.
* **Project End Date**: Enter the date on which the project is expected to be completed.
* **Project Manager ID**: Enter the ID of the project manager.
* **Project Manager**: Check if the project is managed by the user.
* **Team Lead ID**: Enter the ID of the team lead.
* **Team Lead**: Check if the project is led by the user.
* **Assigned User ID**: Enter the ID of the assigned user.
* **Assigned User**: Check if the project is assigned to the user.
* **Project Status Updated At**: Enter the date on which the project status was last updated.
* **Project Deadline 2**: Enter the alternative deadline for the project.
* **Project Category**: Select if the project has a category.
* **Project Tags**: Select if the project has tags.
* **Assigned Tool Id**: Enter the ID of the assigned tool.
* **Project Milestone ID**: Enter the ID of the project milestone.
* **Project Milestone**: Check if the project has a milestone.
* **Responsible Party**: Check if the project is the responsibility of the user.
* **Project Status 2**: Select if the project is Active or Inactive.
* **Assigned Tool Id**: Enter the ID of the assigned tool.
