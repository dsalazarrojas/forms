# Project Closeout Checklist - Help Guide
## Purpose
The Project Closeout Checklist is a form used to gather critical information about project closure, ensuring that all necessary steps and tasks are completed before closing out the project.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select "Yes" or "No" for project_closeout_checklist_project**: This field asks you to confirm if the project is closed out. If the project is not fully completed, select "No" and provide further details in the "project_closeout_checklist_notes" field.
2. **Enter project_closeout_checklist_notes**: If you selected "No" in the previous step, please provide a brief description of why the project is not closed out yet.
3. **Enter project_closeout_checklist_phone**: This field is optional, but if you need to contact someone regarding the project, enter their phone number.
4. **Enter project_closeout_checklist_email**: Enter the email address of the person responsible for the project or someone who can be contacted for further information.
5. **Enter project_closeout_checklist_date**: This field is required and asks for the date when the project was closed out. Please use the date format (yyyy-mm-dd).
6. **Enter project_closeout_checklist_time**: This field is optional and asks for the time spent on the project.
7. **Select "Yes" or "No" for project_closeout_checklist_project_9**: This field is optional and asks if the project was completed on time.
8. **Select multiple options for project_closeout_checklist_project_10**: This field is required and asks you to select all relevant projects that were completed in conjunction with this project.
9. **Enter project_closeout_checklist_project_11**: This field is optional, but if you need to provide additional details about the project, enter them here.
10. **Enter project_closeout_checklist_project_12**: This field is required and asks for a detailed description of the project.
11. **Select multiple options for project_closeout_checklist_project_13**: This field is optional and asks if the project's closure had any significant outcomes or impacts.
12. **Enter project_closeout_checklist_date_14**: This field is required and asks for the date the project was initiated.

## Field-by-Field Explanation
- **project_closeout_checklist_project**: Indicates whether the project is closed out.
- **project_closeout_checklist_notes**: A field for entering further details if the project is not closed out yet.
- **project_closeout_checklist_phone**: A field for entering the contact phone number of the project lead or someone responsible for the project.
- **project_closeout_checklist_email**: A field for entering the contact email address of the project lead or someone responsible for the project.
- **project_closeout_checklist_date**: The date when the project was closed out.
- **project_closeout_checklist_time**: The time spent on the project.
- **project_closeout_checklist_project_9**: A field for indicating if the project was completed on time.
- **project_closeout_checklist_project_10**: A field for selecting all relevant projects completed in conjunction with this project.
- **project_closeout_checklist_project_11**: A field for entering additional details about the project.
- **project_closeout_checklist_project_12**: A field for a detailed description of the project.
- **project_closeout_checklist_project_13**: A field for indicating if the project's closure had any significant outcomes or impacts.
- **project_closeout_checklist_date_14**: The date the project was initiated.

Note to the reader: Please complete the form accurately and thoroughly, and do not skip any required fields. If you're unsure about any of the fields, consult with the project team or contact the relevant authority for guidance.
