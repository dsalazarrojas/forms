# event_certificate_printing_request_form - Help Guide
## Purpose
This form is used to request an event certificate, which is a document that confirms an individual's participation in an event.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the "Event Name" of the event you are requesting the certificate for.
2. Enter the "Speaker Name" associated with the event.
3. Select whether you need a "Certificate Type" (Yes/No).
4. List any "Attendees" (Yes/No) attending the event.
5. Provide "Delivery Details" about how you want the certificate to be delivered (e.g. email, mail, etc.).
6. Select your preferred "Delivery Method" (Yes/No, e.g. email, mail, etc.).
7. Enter the "Delivery Date" when you want the certificate to be delivered.
8. Enter the "Delivery Time" when you want the certificate to be delivered.
9. Enter the "Delivery Address" where the certificate should be delivered.
10. Enter the "Delivery City" where the certificate should be delivered.
11. Enter the "Delivery State" where the certificate should be delivered.
12. Enter the "Delivery Zip" for the delivery address.
13. Select whether to include "Delivery Country" information (Yes/No).
14. Enter the "Certificate Number" if required.

## Field-by-Field Explanation
* **Event Name (Text)**: Enter the name of the event for which you are requesting a certificate.
* **Speaker Name (Text)**: Enter the name of the speaker associated with the event.
* **Certificate Type (Select One)**: Select "Yes" if you need a certificate.
* **Attendees (Select Multiple)**: List "Yes" for each attendee associated with the event.
* **Delivery Details (Text)**: Provide a description of how you want the certificate to be delivered (e.g. email, mail, etc.).
* **Delivery Method (Select One)**: Select how you want the certificate to be delivered (e.g. email, mail, etc.).
* **Delivery Date (Date)**: Enter the date when you want the certificate to be delivered.
* **Delivery Time (Time)**: Enter the time when you want the certificate to be delivered.
* **Delivery Address (Text)**: Enter the address where the certificate should be delivered.
* **Delivery City (Text)**: Enter the city where the certificate should be delivered.
* **Delivery State (Text)**: Enter the state where the certificate should be delivered.
* **Delivery Zip (Text)**: Enter the zip code for the delivery address.
* **Delivery Country (Select One)**: Select whether to include country information (Yes/No).
* **Certificate Number (Text)**: Enter the certificate number if required. 

## Tips
* Make sure to fill in all required fields.
* If you are unsure about any field, please contact the administrator for assistance.
* Please note that the "Delivery Details" field is a free text field for you to describe your delivery requirements.
