# tool_request_form - Help Guide
## Purpose
This form is used to request tools or resources from the support team. Please fill it out to provide all necessary information for efficient processing and addressing your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the job number in the **job_number** field. This is a unique identifier for the job related to your request.
2. Select the date you are requesting the tool in the **tool_request_date** field. Use the date format `YYYY-MM-DD`.
3. Provide a brief description of the tool or resource you are requesting in the **tool_description** field.
4. Choose the tool you are requesting from the **assigned_tool** dropdown list.
5. Indicate whether you are the requested resource or not by selecting 'Yes' or 'No' in the **requested_by** field.
6. Select the status of the tool from the **tool_status** dropdown list.
7. If applicable, provide a reason for the request in the **reason_for_request** field.
8. Add any additional comments or context in the **comments** field.

## Field-by-Field Explanation
* **job_number**: Enter a unique identifier for the job related to your request.
	+ Type: `number`
	+ Optional
* **tool_request_date**: Select the date you are requesting the tool.
	+ Type: `date`
	+ Optional
* **tool_description**: Provide a brief description of the tool or resource you are requesting.
	+ Type: `text`
	+ Optional
* **assigned_tool**: Choose the tool you are requesting from the dropdown list.
	+ Type: `select_one`
	+ Optional
* **requested_by**: Indicate whether you are the requested resource or not.
	+ Type: `select_multiple`
	+ Optional
* **tool_status**: Select the status of the tool.
	+ Type: `select_one`
	+ Optional
* **reason_for_request**: If applicable, provide a reason for your request.
	+ Type: `text`
	+ Optional
* **comments**: Add any additional comments or context related to your request.
	+ Type: `text`
	+ Optional
