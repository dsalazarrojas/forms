## Employee Engagement Tool Requisition Form - Help Guide
### Purpose

The purpose of this form is to enable employees to submit requests for tools and resources that they need for their work. We want to streamline the process and ensure that all employees have access to the necessary tools and resources to do their job effectively.

### How To Complete This Form

To complete this form, please follow these steps:

1. Enter the name of the company that is making the request.
2. Enter the name of the employee who is making the request.
3. Describe the tool or resource that you are requesting.
4. Select the category of the tool request from the available options.
5. Select the status of the tool request from the available options.
6. Choose the date when you submitted the request.
7. If someone is assigned to handle the request, select True.

### Field-by-Field Explanation

* **Company Name** (`company_name`, text, required): Please enter the name of the company making the request.
* **Employee Name** (`employee_name`, text, required): Please enter the name of the employee making the request.
* **Tool Request** (`tool_request`, text, required): Please describe the tool or resource being requested.
* **Category** (`category`, select_multiple, required): Please select the category for this tool request from the available options: Business Forms, Other, IT, Marketing, Operations, and Finance.
* **Status** (`status`, select_one, required): Please select the status of the tool request from the available options: Open, In Progress, Done, and Rejected.
* **Submitted Date** (`submitted_date`, date, required): Please enter the date when you submitted the request.
* **Assigned By** (`assigned_by`, select_one, required): Please select if someone is assigned to handle the tool request.

### Tips

- Please ensure that you have the necessary information and approval before submitting the request.
- If you are unsure about the category or status, please consult your team or manager for guidance.
- This form's information will be reviewed and processed by the team assigned to handle tool requests.
- If you have any questions or need help, please don't hesitate to contact us.
