# project_status_report_form - Help Guide
## Purpose
The "project_status_report_form" is used to capture and document project status reports for projects being managed within the organization. This form is essential for tracking and maintaining accurate project progress, challenges, and completion status.

## How To Complete This Form

1. Start by selecting the current status of your project from the options provided in the "Project Status" field.
2. Enter the start date and end date of your project in the corresponding fields.
3. Provide the name of the project manager responsible for the project in the "Project Manager" field.
4. Enter the current progress of your project as a numerical value in the "Project Progress" field.
5. List any challenges faced during the project execution in the "Project Challenges" field.
6. Provide a brief description of the project's progress and challenges in the "Project Comments" field.
7. If applicable, select the tool(s) used for this project from the options provided in the "Assigned Tool" field.
8. Enter the category of the project in the "Project Category" field.
9. Provide a brief description of the project in the "Project Description" field.
10. Attach an output file or document related to the project in the "Output File" field.
11. Enter a unique identifier for the form in the "Form ID" field.
