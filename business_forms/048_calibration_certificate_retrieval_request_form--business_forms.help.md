# Calibration Certificate Retrieval Request Form - Help Guide
## Purpose
This form is used to collect information from users requesting calibration certificates for their equipment. Please fill it out carefully to ensure we can process your request efficiently and accurately.

## How To Complete This Form
1. Enter your information:
	* Your Name: Enter your full name as you'd like it to appear on the certificate.
	* Email Address: Enter your email address where you'd like to receive the certificate.
	* Phone Number: Enter your contact number in case we need to contact you.
2. Enter equipment information:
	* Company Name: Enter your organization's name.
	* Department (optional): Enter your department if you'd like to specify.
	* Request Date: Select the date you'd like to request the calibration certificate for. This date will be used to ensure we have the necessary records.
	* Equipment Name: Enter the name of the equipment you'd like to obtain a certificate for.
	* Equipment ID: Enter the asset or serial number of the equipment.
3. Select equipment type:
	* Equipment Type: Select the type of equipment from the provided options (e.g., Scale, Balance, Pressure gauge, etc.).
4. Specify certificate type and format:
	* Certificate Type Needed: Select the type of certificate you require (e.g., ISO 17025 accredited, NIST traceable, etc.).
	* Certificate Format: Select how you'd like to receive the certificate (e.g., PDF via email, Printed copy by mail, etc.).
5. Provide additional information:
	* Mailing Address (if printed copy): If you've selected to receive a printed copy, enter the address where you'd like it to be mailed.
	* Purpose: Select the reason for your request (e.g., Audit compliance, Quality assurance, etc.).
	* Audit Date (if for audit): If your request is for an audit, enter the date of the audit.
6. Specify urgency and additional details:
	* Urgency: Select how soon you need the certificate (e.g., Routine, Expedited, etc.).
	* Multiple Certificates: If you need certificates for multiple items, select the number of items.
	* Equipment List (if multiple): If you've selected multiple certificates, enter a list of equipment names.
	* Date Range Needed: If you need a date range, enter the start and end dates.
	* Special Requirements or Notes: Enter any special requirements or notes for your request.
7. Finalize your request:
	* Previous Request Number: If this is a follow-up request, enter the previous request number.
	* Cost Center (for billing): Enter the cost center for billing purposes.
	* Authorization Needed: Select if this request requires approval (e.g., manager approval, quality approval, etc.).
	* Additional Comments: Enter any additional information or comments.

## Tips

* If you've previously submitted a request for this equipment, please enter the previous request number to help us track and process your new request efficiently.
* If you need certificates for multiple items, please select the correct number of items and provide a list of equipment names.
* If you need a printed copy of the certificate, please ensure you've entered the correct mailing address.
* If your request requires approval, please select the correct approval type and ensure you've entered the necessary information.
* If you have any special requirements or notes, please enter them in the "Special Requirements or Notes" field to help us process your request accurately.
