# eftpos_information_form - Help Guide
## Purpose
This form collects information about EFTPOS terminals for business operations. It is essential for terminal management and updating.

## How To Complete This Form

1. Fill in the required fields:
	* Terminal ID
	* Bank Name
	* Contact Name
	* Contact Email
	* Branch Code
	* Branch Name
	* Account Number
	* Account Type
	* Terminal Type
	* Terminal Status
2. Optionally, you can add additional information:
	* Terminal Description
	* Terminal Notes
	* Bank Details
	* Payment Provider
	* Finance Details
	* Support Team
	* Onboarding Date
	* Onboarding Time
	* Onboarding Status
	* Onboarding Comments
	* Update Date
	* Update Time
	* Update Status

## Field-by-Field Explanation

* **Terminal ID**: A unique identifier for the EFTPOS terminal. (Required)
* **Bank Name**: The name of the bank associated with the terminal. (Required)
* **Contact Name**: The name of the contact person responsible for the terminal. (Required)
* **Contact Email**: The email address of the contact person. (Required)
* **Contact Phone**: The phone number of the contact person. (Required)
* **Branch Code**: A code for the branch where the terminal is located. (Required)
* **Branch Name**: The name of the branch where the terminal is located. (Required)
* **Account Number**: The account number associated with the terminal. (Required)
* **Account Type**: The type of account (e.g., Account Management, Account Opening, Savings, Loan, Other). (Required)
* **Terminal Type**: The type of terminal (EFTPOS, Other). (Required)
* **Terminal Status**: The status of the terminal (Active, Inactive, Offline, Online). (Required)
* **Terminal Description**: A brief description of the terminal. (Optional)
* **Terminal Notes**: Additional information about the terminal. (Optional)
* **Bank Details**: Whether bank details are selected. (Optional)
* **Payment Provider**: The payment provider associated with the terminal. (Optional)
* **Finance Details**: Whether finance details are selected. (Optional)
* **Support Team**: The support team responsible for the terminal. (Optional)
* **Onboarding Date**: The date of onboarding the terminal. (Optional)
* **Onboarding Time**: The time of onboarding the terminal. (Optional)
* **Onboarding Status**: The status of onboarding the terminal (Onboarding, Not Onboarding). (Optional)
* **Onboarding Comments**: Comments about onboarding the terminal. (Optional)
* **Update Date**: The date of the last update. (Optional)
* **Update Time**: The time of the last update. (Optional)
* **Update Status**: The status of the last update (Update, Not Update). (Optional)
