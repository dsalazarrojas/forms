# oem_weekly_reflection - Help Guide
## Purpose
This form is a weekly reflection tool used to document progress and experiences with assigned tools.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a category that best describes your work (Oem, Other, or None).
2. Provide a brief description of your work and experiences.
3. Choose the tools you're using this week.
4. Submit the form.

## Field-by-Field Explanation

* **Weekly Reflection (Page 1)**: A text field where you provide a brief description of your progress and experiences. Please write a concise and honest account of your work.
* **Category (Page 1)**: Select the category that best describes your work. This could be Oem, Other, or None.
* **Description (Page 1)**: A text field where you can provide more details about your work, if needed. This is optional.
* **Assigned Tool (Page 1)**: Select the tools you're using this week. You can choose one or multiple tools that are relevant to your work. This field is optional.
* **Assigned Tool (Page 2)**: This field is a continuation of the previous one, allowing you to select additional tools if needed.
