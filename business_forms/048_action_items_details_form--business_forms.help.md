# Action Items Details Form - Help Guide
## Purpose
The purpose of this form is to collect details about action items to ensure accurate and up-to-date information about projects and tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* **Action title**: Enter a short description of the action item.
	* **Description**: Enter a detailed description of the task.
	* **Owner**: Identify the person responsible for completing the action item.
	* **Priority**: Select the priority level (Low, Medium, High) for the action item.
	* **Status**: Select the current state of the action item (Open, In progress, Completed).
	* **Status**: Select the current state of the action item (Open, In progress, Completed).
2. Fill in optional fields:
	* **Due date**: Enter the target completion date for the action item (if applicable).
	* **Estimated effort hours**: Enter the estimated time to complete the task in hours (if applicable).
	* **Related project**: Enter the project name or identifier (if applicable).
	* **Dependencies**: List tasks that must be completed before this action item can be done (if applicable).
	* **Tags**: Enter labels for categorization (if applicable).
	* **Progress update**: Enter the latest progress note (if applicable).
	* **Closure notes**: Enter notes recorded when closing the action item (if applicable).
