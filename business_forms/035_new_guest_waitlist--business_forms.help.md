# new_guest_waitlist - Help Guide
## Purpose
The "new_guest_waitlist" form is used to create a new guest waitlist for a business. This form helps users to list guests who are waiting to be assigned a specific tool or resource.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for the guest waitlist from the dropdown menu. You can choose between "business forms" and "other" options.
2. Provide a brief description of the guest waitlist.
3. Choose the assigned tool from the dropdown menu. You can select "chatjimmy" or "other" options.
4. Enter the form IDs for the guest waitlist.
5. Specify the output file for the guest waitlist.
6. Assign a user to manage the guest waitlist.

## Field-by-Field Explanation
- **new guest waitlist** (1, text, required): Enter a title for the new guest waitlist. This field is required and should be a brief description of the waitlist.
- **Category** (2, select_one, optional): Select the category for the guest waitlist from the dropdown menu. This field is optional and has two options: "business forms" and "other".
- **Description** (3, text, optional): Enter a brief description for the guest waitlist. This field is optional.
- **Assigned Tool** (4, select_one, optional): Choose the assigned tool from the dropdown menu. This field is optional and has two options: "chatjimmy" and "other".
- **Form IDs** (5, text, optional): Enter the form IDs for the guest waitlist. This field is optional.
- **Output File** (6, text, optional): Specify the output file for the guest waitlist. This field is optional.
- **Assigned User** (7, select_one, optional): Choose the user to be assigned to manage the guest waitlist from the dropdown menu. This field is optional and has two options: "assigned user" and "other".

## Tips
- Make sure to select the correct category and assigned tool to accurately reflect the guest waitlist purpose.
- Enter a clear and concise description to help users understand the purpose of the waitlist.
- If you need help with assigned tools or users, contact your IT department for assistance.
- Double-check the form IDs and output file to ensure accuracy and compatibility.
- Assign the correct user to manage the waitlist to ensure smooth administration and communication.
