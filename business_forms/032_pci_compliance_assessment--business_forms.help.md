# pci_compliance_assessment - Help Guide
## Purpose
The Payment Card Industry (PCI) compliance form is used to assess whether a business is meeting the required security standards for protecting cardholder data.

## How To Complete This Form
Please follow these steps to complete this form:

1. Answer all the questions carefully and thoroughly.
2. For select_multiple fields, you will be able to choose multiple options.
3. For select_one fields, you will only be able to choose one option.
4. For text fields, provide a detailed response.

## Field-by-Field Explanation

### 1. **Payment Channels**
* **Payment Channels** (`Payment Channels`, `select_multiple`, optional):
This question asks if the business accepts payments through various channels such as mail, phone, or online.
* If you select "Yes" for more than one channel, please specify which channels.

### 2. **it_status**
* **it_status** (`it_status`, `text`, optional):
This field is for any additional information about the business's current IT status.

### 3. **key_security_controls**
* **key_security_controls** (`key_security_controls`, `text`, optional):
This field is for any information about the key security controls that the business has in place.

### 4. **key_security_controls_2**
* **key_security_controls_2** (`key_security_controls_2`, `select_one`, optional):
This question asks if the business has the second part of its key security controls in place. Please select "Yes" or "No".

### 5. **key_security_controls_3**
* **key_security_controls_3** (`key_security_controls_3`, `select_one`, optional):
This question asks if the business has the third part of its key security controls in place. Please select "Yes" or "No".

## Tips
* Answer every question carefully and thoroughly.
* If you're unsure about any question, please ask for clarification before proceeding.
* This form is for internal use only. Please ensure that you have the necessary permissions to access and fill out this form.
