# Dz Reimbursement Request Form - Help Guide

## Purpose
The purpose of this form is to request reimbursement for business expenses incurred by employees.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you are submitting the form for a legitimate business expense and that it has not already been reimbursed.
2. Fill in the form's required fields, including:
	* Category (e.g. "business_forms_request_forms")
	* Description
	* Expense amount
	* Expense date
	* Expense time
	* Business name
	* Employee name
	* Expense type
	* Email (submitter's email)
	* Phone (submitter's phone)
	* Signature (select submitter's role and options from the dropdown list)

## Field-by-Field Explanation
- **Category** (`business_forms_request_forms`): A label to identify the type of expense being claimed. Please select the relevant category from the options provided.
	* Type: text
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Description** (`description`): A detailed description of the expense, including its purpose and nature.
	* Type: text
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Expense Amount** (`expense_amount`): The total cost of the expense, including taxes and any other expenses.
	* Type: number
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Expense Date** (`expense_date`): The date on which the expense was incurred.
	* Type: date
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Expense Time** (`expense_time`): The time at which the expense was incurred.
	* Type: time
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Business Name** (`business_name`): The name of the business or organization that incurred the expense.
	* Type: text
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Employee Name** (`employee_name`): The name of the employee who incurred the expense.
	* Type: text
	* Required: True
	* Hint: This field is required and should be filled in accurately.
- **Expense Type** (`expense_type`): A selection of the type of expense being claimed.
	* Type: select_one
	* Required: True
	* Hint: Select one of the options provided.
- **Submitter Email** (`submitter_email`): The email address of the employee submitting the form.
	* Type: email
	* Required: True
	* Hint: Please enter a valid email address.
- **Submitter Phone** (`submitter_phone`): The phone number of the employee submitting the form.
	* Type: text
	* Required: True
	* Hint: Please enter a valid phone number.
- **Signature** (`submitter_signature`): A selection of the submitter's role and options.
	* Type: select_multiple
	* Required: True
	* Hint: Select one or more options from the dropdown list.
- **Form Submitter** (`form_submitter`): A selection of the form submitter's role.
	* Type: select_one
	* Required: True
	* Hint: Select one of the options provided.
- **Submitter Role** (`submitter_role`): A selection of the submitter's role.
	* Type: select_one
	* Required: True
	* Hint: Select one of the options provided.

## Tips
- Ensure that you double-check all fields before submitting the form.
- If you are unsure about any part of the form, please consult with your supervisor or departmental support team.
- This form is intended for legitimate business expenses only. If you are unsure about the legitimacy of an expense, please do not submit it.
- Please note that incomplete or inaccurate forms may be rejected.
- Please submit the form only once it is complete and accurate.
