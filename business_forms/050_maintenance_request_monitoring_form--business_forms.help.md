# Maintenance Request Monitoring Form - Help Guide

## Purpose
The purpose of this form is to track and manage maintenance requests within an organization or business.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the required fields:
	* **Status**: Select the current status of the maintenance request (New, In Progress, Complete, Cancelled).
	* **Priority**: Choose the priority level of the maintenance request (High, Medium, Low).
	* **Assigned To**: Select the person responsible for completing the maintenance task.
2. Optionally, you can provide the following information:
	* **Date Submitted**: The date the maintenance request was submitted.
	* **Due Date**: The expected completion date of the maintenance request.
	* **Completed Date**: The date the maintenance request was completed.
	* **Completed Time**: The time the maintenance request was completed.
	* **Completed Status**: A brief description of the completion status.
	* **Notes**: Any additional comments or remarks about the maintenance request.
	* **Email**: The contact email for the person responsible for the maintenance request.

## Field-by-Field Explanation

* **Maintenance Request**:
	+ (text field, required: false): Enter a brief description of the maintenance request.
* **Date Submitted**:
	+ (date field, required: false): Enter the date the maintenance request was submitted.
* **Status**:
	+ (select_one, required: true): Select the current status of the maintenance request (New, In Progress, Complete, Cancelled).
	+ Intended to track the progress of the maintenance request.
* **Priority**:
	+ (select_multiple, required: true): Choose the priority level of the maintenance request (High, Medium, Low).
	+ Helps in prioritizing and scheduling maintenance tasks.
* **Assigned To**:
	+ (select_one, required: true): Select the person responsible for completing the maintenance task.
	+ Assigns the maintenance task to a specific person.
* **Due Date**:
	+ (date field, required: false): Enter the expected completion date of the maintenance request.
	+ Helps in planning and scheduling maintenance activities.
* **Completed Date**:
	+ (date field, required: false): Enter the date the maintenance request was completed.
	+ Tracks the completion date of the maintenance request.
* **Completed Time**:
	+ (time field, required: false): Enter the time the maintenance request was completed.
	+ Tracks the completion time of the maintenance request.
* **Completed Status**:
	+ (text field, required: false): Enter a brief description of the completion status.
	+ Provides a detailed status update about the maintenance request.
* **Notes**:
	+ (note field, required: false): Enter any additional comments or remarks about the maintenance request.
	+ Provides additional context or information about the maintenance request.
* **Email**:
	+ (email field, required: false): Enter the contact email for the person responsible for the maintenance request.
	+ Facilitates communication and contact between the person responsible and the maintenance request submitter.

## Tips
* Please ensure that you are submitting new requests only for maintenance tasks that have not been previously submitted.
* Double-check the accuracy of the information you provide to ensure efficient maintenance request monitoring.
* If you have any questions or concerns, please reach out to your team or supervisor for clarification.
