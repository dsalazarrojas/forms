# Duty Manager Daily Checklist - Help Guide
## Purpose
This form is designed to provide a daily record of tasks and activities that need to be performed by the duty manager. It captures relevant metadata such as assigned users, task status, priority, and completion dates.

## How To Complete This Form

*   To complete this form, start by selecting the relevant tasks from the morning, afternoon, and evening checklists. These checklists will help you identify the tasks that need to be performed during each period.
*   Once you have selected the tasks, review the "Assigned To" field to ensure that the correct user is assigned to each task.
*   Update the "Task Status" field to reflect the current status of each task (active or inactive).
*   Use the "Priority" field to record the priority of each task (yes or no).
*   Review the "Completed Tasks" field to ensure that all completed tasks are recorded.
*   Update the "Completed Date" field with the actual completion date of each task.
*   Use the "Created By" field to record the person who created each task.
*   Use the "Updated By" field to record the person who updated each task.
*   Review the "Created At" field to record the date and time each task was created.
*   Review the "Updated At" field to record the date and time each task was updated.
*   Use the "Assigned Tool" field to record the tool assigned to each task.
*   Use the "Category" field to record the category of each task.
*   Review the "Form ID" field to record the unique identifier of the form.
*   Review the "Form Version" field to record the version of the form.
*   Review the "Submitted At" field to record the date and time each task was submitted.
*   Review the "User ID" field to record the user ID of the person who submitted each task.
*   Review the "Status" field to record the status of each task (active or inactive).
*   Review the "Deleted At" field to record the date each task was deleted.
*   Review the "Created At" field to record the date and time each task was created.
