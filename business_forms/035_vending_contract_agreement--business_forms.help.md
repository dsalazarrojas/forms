# vending_contract_agreement - Help Guide
## Purpose
The vending contract agreement form is used to collect and manage data for vending contracts within a business or organization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the machine ID from the provided list.
2. Enter the contract start date.
3. Enter the contract end date.
4. Specify the payment terms.
5. Specify the responsibilities of both parties.
6. Select the vending operator.
7. Specify the location of the vending machine.
8. Enter the contract duration.
9. Select the payment method.
10. Specify the payment frequencies.
11. Enter the payment terms frequency.
12. Enter the payment amount.
13. Specify the payment schedule.
14. Select the contract type.
15. Specify the contract version.
16. Specify any notes about payment terms.
17. Specify any notes about payment frequencies.
18. Specify any notes about payment schedule.
19. Specify any notes about the contract.
20. Select the contract signers.
21. Enter the contract sign date.
22. Specify any notes about the contract end date.
23. Specify any notes about the contract start date.
24. Specify any notes about the contract duration.
25. Specify any notes about payment terms.

## Field-by-Field Explanation

* **Machine ID (1)**: Select the unique ID for the vending machine from the provided list.
* **Contract Start Date (2)**: Enter the date the contract is scheduled to start.
* **Contract End Date (3)**: Enter the date the contract is scheduled to end.
* **Payment Terms (4)**: Specify the payment terms, such as frequency and amount.
* **Responsibilities (5)**: Specify the responsibilities of both parties involved.
* **Vending Operator (6)**: Select the individual or entity managing the vending machine.
* **Location (7)**: Specify the location of the vending machine.
* **Contract Duration (8)**: Enter the length of the contract.
* **Payment Method (9)**: Select the method of payment for the contract.
* **Payment Frequencies (10)**: Specify the payment frequencies, such as weekly or monthly.
* **Payment Terms Frequency (11)**: Specify the frequency of payment terms.
* **Payment Amount (12)**: Enter the payment amount.
* **Payment Schedule (13)**: Specify the payment schedule, such as bi-weekly.
* **Contract Type (14)**: Select the type of contract.
* **Contract Version (15)**: Enter the contract version number.
* **Payment Terms Notes (16)**: Specify any additional notes about payment terms.
* **Payment Frequencies Notes (17)**: Specify any additional notes about payment frequencies.
* **Payment Schedule Notes (18)**: Specify any additional notes about payment schedule.
* **Contract Notes (19)**: Specify any additional notes about the contract.
* **Contract Signers (20)**: Select the individuals or entities signing the contract.
* **Contract Sign Date (21)**: Enter the date the contract is signed.
* **Contract End Notes (22)**: Specify any additional notes about the contract end date.
* **Contract Start Notes (23)**: Specify any additional notes about the contract start date.
* **Contract Duration Notes (24)**: Specify any additional notes about the contract duration.
* **Payment Terms Notes (25)**: Specify any additional notes about payment terms.
