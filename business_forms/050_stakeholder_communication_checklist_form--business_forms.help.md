# Stakeholder communication checklist form - Help Guide
## Purpose
The Stakeholder Communication Checklist Form is designed to facilitate effective communication between project stakeholders. This form collects and organizes information about the project status, stakeholder status, communication frequency, and last updated status, ensuring all parties are informed and on the same page.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the project name and status to provide context for the stakeholder communication history.
2.  Select the project start and end dates to establish the timeline for communication.
3.  Enter the project manager's name to associate the project with the responsible manager.
4.  Provide the stakeholder's name to identify the person communicating with the project team.
5.  Choose the communication type (e.g., email, phone call, in-person, video conferencing, or chat) to specify the method used for communication.
6.  Enter the last communicated date and time to record the most recent interaction.
7.  Select the frequency of communication (daily, weekly, monthly, quarterly, or annually) to establish a schedule.
8.  Update the project status (in progress, on hold, or completed) and stakeholder status to reflect the current project status.
9.  Enter the next communication planned date and time to schedule future interactions.
10.  Record any comments or observations from the project manager and stakeholder to facilitate feedback and discussion.

## Field-by-Field Explanation
* **Stakeholder Communication Checklist Form**: This is the title of the form, providing a clear overview of the purpose and scope.
* **Project Name** (`project_name`): Enter the name of the project to associate it with the stakeholder communication history.
* **Project Status** (`project_status`): Select the current status of the project (in progress, on hold, or completed).
* **Project Start Date** (`project_start_date`): Enter the start date of the project to establish the timeline.
* **Project End Date** (`project_end_date`): Enter the end date of the project to define the project duration.
* **Project Manager Name** (`project_manager_name`): Enter the name of the project manager responsible for the project.
* **Stakeholder Name** (`stakeholder_name`): Enter the name of the stakeholder communicating with the project team.
* **Communication Type** (`communication_type`): Select the method used for communication (email, phone call, in-person, video conferencing, or chat).
* **Last Communicated Date** (`last_communicated_date`): Record the date of the most recent communication.
* **Last Communicated Time** (`last_communicated_time`): Record the time of the most recent communication.
* **Frequency Of Communication** (`frequency_of_communication`): Select the frequency of communication (daily, weekly, monthly, quarterly, or annually).
* **Communication Method** (`communication_method`): Select the method used for communication (email, phone call, in-person, video conferencing, or chat).
* **Next Communication Planned Date** (`next_communication_planned_date`): Enter the date of the next planned communication.
* **Next Communication Planned Time** (`next_communication_planned_time`): Enter the time of the next planned communication.
* **Stakeholder Comments** (`stakeholder_comments`): Record any comments or observations from the stakeholder.
* **Project Manager Comments** (`project_manager_comments`): Record any comments or observations from the project manager.
* **Last Communicated By** (`last_communicated_by`): Record the person who last communicated with the stakeholder.
* **Last Updated By** (`last_updated_by`): Record the person who last updated the communication status.
* **Stakeholder Status Last Updated** (`stakeholder_status_last_updated`): Update the stakeholder status (in progress, on hold, or completed).
* **Project Status Last Updated** (`project_status_last_updated`): Update the project status (in progress, on hold, or completed).
* **Communication Last Updated** (`communication_last_updated`): Record the date of the last updated communication status.
* **Frequency Last Updated** (`frequency_last_updated`): Update the frequency of communication (daily, weekly, monthly, quarterly, or annually).
* **Next Communication Last Updated** (`next_communication_last_updated`): Record the date of the last updated next communication plan.
* **Stakeholder Last Updated** (`stakeholder_last_updated`): Update the stakeholder status last updated.

Note: This guide assumes the form is completed by the project manager and the stakeholder. Ensure to review and discuss any discrepancies or changes with all parties involved before making any updates.
