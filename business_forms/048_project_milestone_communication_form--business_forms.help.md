# Project Milestone Communication Form - Help Guide
## Purpose
The Project Milestone Communication Form is used to record and communicate project milestones, updates, and status changes. This form helps project managers and team members stay informed about project progress and facilitates efficient communication among team members, project managers, and customers.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project Name** in the designated field. This is the name of the project you are updating.
2. Select the **Start Date** and **End Date** of the project milestone.
3. Choose the **Update Status** of the project (Completed, In Progress, On Hold, or Not Started).
4. If applicable, enter any **Update Notes** to provide additional context or information.
5. Select the **Team Members** involved in the project milestone.
6. Choose the **Update Priority** (High, Low, or Medium).
7. Select the **Project Status** (Active, Archived, or Inactive).
8. Enter any **Comments** regarding the project milestone.
9. Enter your **Email** address and **Phone** number for contact purposes.
10. Select the **Project Manager**, **Team Lead**, and **Customer** involved in the project.
11. Choose the **Update Type**.
12. Enter any **Notes** about the project.
13. Select any **Files** and **Attachments** related to the project.
14. Enter the **Update Date** and **Updated By**.
15. Finally, ensure you have filled in all required fields (indicated by an asterisk \*).

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project.
* **Start Date** (`start_date`, date, required): Enter the start date of the project milestone.
* **End Date** (`end_date`, date, required): Enter the end date of the project milestone.
* **Update Status** (`update_status`, select_one, required): Choose the current status of the project (Completed, In Progress, On Hold, Not Started).
* **Update Notes** (`update_notes`, text, optional): Enter any additional comments or information about the project.
* **Team Members** (`team_members`, select_multiple, optional): Select the team members involved in the project.
* **Update Priority** (`update_priority`, select_one, optional): Choose the priority level of the update (High, Low, Medium).
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project (Active, Archived, Inactive).
* **Comments** (`comments`, text, optional): Enter any comments about the project.
* **Email** (`email`, email, required): Enter your email address for contact purposes.
* **Phone** (`phone`, text, required): Enter your phone number for contact purposes.
* **Project Manager** (`project_manager`, select_one, optional): Select the project manager.
* **Team Lead** (`team_lead`, select_one, optional): Select the team lead.
* **Customer** (`customer`, select_one, optional): Select the customer.
* **Update Type** (`update_type`, select_one, optional): Choose the update type.
* **Notes** (`notes`, text, optional): Enter any additional comments or information.
* **Files** (`files`, select_multiple, optional): Select any files related to the project.
* **Attachments** (`attachments`, select_multiple, optional): Select any attachments related to the project.
* **Update Date** (`update_date`, date, required): Enter the date of the update.
* **Updated By** (`updated_by`, select_multiple, required): Select the person who updated the project.
* **Updated At** (`updated_at`, date, required): Enter the date and time of the update.
* **Created By** (`created_by`, select_multiple, optional): Select the person who created the project.
* **Created At** (`created_at`, date, required): Enter the date and time of the project creation.
* **Version** (`version`, text, required): Enter the version of the project.

Note: This help guide is based on the provided YAML fields, and some fields' labels and explanations are best-effort.
