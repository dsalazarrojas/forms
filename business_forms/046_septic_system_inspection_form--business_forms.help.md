# septic_system_inspection_form - Help Guide

## Purpose
This form is for documenting and tracking septic system inspections. It captures information about the system's description, condition, inspection details, and status.

## How To Complete This Form

To complete this form, follow these steps:
1. Enter a brief description of the septic system.
2. Provide information about the system's condition.
3. Enter any notes or comments about the system.
4. Enter your contact information.
5. Record the date and time of the inspection.
6. Select the current status of the system.
7. Enter any additional status information not included in the select option.

## Field-by-Field Explanation

* **septic_system_inspection_form** (1): Enter a brief description of the septic system.
* **system_description** (2): Provide a brief note about the septic system.
* **system_condition** (3): Rate or grade the current condition of the septic system.
* **inspector_notes** (4): Enter any comments or notes about the system during the inspection.
* **inspector_name** (5): Enter your name as the inspector.
* **inspector_phone** (6): Enter your phone number for follow-up.
* **inspector_email** (7): Enter your email address for follow-up.
* **inspection_date** (8): Record the date of the inspection.
* **inspection_time** (9): Record the time of the inspection.
* **system_status** (10): Select the current status of the system (Active, Inactive, Abandoned).
* **system_status_other** (11): Enter any additional status information not included in the select option.

## Tips
- Be as detailed as possible when describing the septic system.
- Use the system condition field to rate or grade the system's current state.
- Use the inspector notes field for any comments or observations during the inspection.
- Make sure to enter accurate contact information for follow-up.
- Record the inspection date and time accurately.
- Select the correct status of the system from the provided options.
- If the system status is not included in the select option, enter it in the system status other field.
