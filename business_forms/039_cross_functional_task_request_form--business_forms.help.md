# Cross Functional Task Request Form - Help Guide
## Purpose
The Cross Functional Task Request Form is a tool used by team members to request tasks that require collaboration across different functional teams. It helps to ensure that tasks are properly assigned and managed, reducing the risk of misunderstandings and miscommunications.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the "Cross Functional Task Request" field with a brief description of the task you wish to request.
2. In the "Task Request" field, provide a detailed description of the task, including any necessary background information.
3. Select "Yes" or "No" from the "Assigned To" dropdown menu to indicate who the task should be assigned to.
4. Choose a priority level (High, Medium, Low) for the task in the "Priority" dropdown menu.
5. Optionally, add any comments or notes about the task in the "Comments" field.
6. If necessary, attach any relevant files or documents to the task in the "Attachment" field.

## Field-by-Field Explanation

* **Cross Functional Task Request** (`cross_functional_task_request_form_page_1`, text, required): A brief description of the task you wish to request.
* **Task Request** (`cross_functional_task_request_form_page_2`, text, required): A detailed description of the task, including any necessary background information.
* **Assigned To** (`assigned_to`, select_multiple, optional): Select "Yes" if the task should be assigned to someone, or "No" if it doesn't require assignment.
* **Due Date** (`due_date`, date, optional): The date by which the task should be completed.
* **Priority** (`priority`, select_one, optional): Choose a priority level for the task (High, Medium, Low).
* **Comments** (`comments`, note, optional): Any comments or notes about the task.
* **Attachment** (`attachment`, text, optional): Attach any relevant files or documents to the task.

## Tips
Please make sure to provide clear and concise descriptions of the tasks, and include all necessary information to ensure that the task can be completed correctly. If you're unsure about any of the fields, please don't hesitate to ask your team lead for clarification.
