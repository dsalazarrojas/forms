# Employee Disciplinary Action Follow Up Form - Help Guide

## Purpose
The Employee Disciplinary Action Follow Up Form is used to track and document the progress of disciplinary actions initiated in the past. It helps supervisors monitor, note, and address the status of these actions and their outcomes.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the employee's name and ID in their respective fields. This information is necessary for tracking and identifying the employee.
2. Enter the date of the disciplinary action and the date for the follow-up action. These dates will help you keep track of the timeline of events.
3. Select the current status of the disciplinary action from the options provided. This will give you an overview of whether the action is complete, incomplete, or needs further attention.
4. Provide a brief description of the action taken or the progress made. This description will help in reviewing the action's outcome.
5. Add any additional comments about the follow-up process. This section is for any notes or observations you'd like to record.

## Field-by-Field Explanation

* **Employee Name** (employee_name, text, optional): Enter the name of the employee involved in the disciplinary action.
* **Employee ID** (employee_id, number, optional): Enter the ID of the employee involved in the disciplinary action.
* **Disciplinary Action Date** (disciplinary_action_date, date, optional): Enter the date when the disciplinary action was initiated.
* **Follow Up Date** (follow_up_date, date, optional): Enter the date of the follow-up action taken.
* **Action Status** (action_status, select_multiple, optional):
	+ **Complete**: The disciplinary action has been completed and finalized.
	+ **Incomplete**: The action is not complete and still ongoing.
	+ **No Action**: No action was taken on the employee.
	+ **Not Started**: The disciplinary action has not begun yet.
* **Action Description** (action_description, text, optional): Give a brief description of the action taken or progress made.
* **Follow Up Comments** (follow_up_comments, text, optional): Add any additional comments about the follow-up process.

## Tips

* Make sure to fill in accurate and detailed information for each field to ensure the tracking process is reliable.
* Use the status options correctly to reflect the true state of the disciplinary action.
* Keep the action description concise and focused on the key points of the action.
* Add any relevant comments that may help in future references or evaluations.
