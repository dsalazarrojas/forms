# Mortgage Complaint Form - Help Guide
## Purpose
The Mortgage Complaint Form is used to collect information from homeowners who have filed a complaint regarding a mortgage issue.

## How To Complete This Form
1. Begin by filling out the form with your personal information, including your name, address, and contact number.
2. Choose the type of complaint you are experiencing (Mortgage, Interest, Property, or Other).
3. Describe the issue in detail and provide the date and time the dispute occurred.
4. If you have any supporting documentation or proof, you can upload it as an attachment.
5. If you have any further requests or requirements regarding your complaint, please indicate this in the "Review Request" field.
6. Finally, select a status for your review request from the options provided.

## Field-by-Field Explanation

* **Homeowner**: Enter your name to identify yourself.
	+ Type: text
	+ Required: true
* **Address**: Enter your address to provide a location for the dispute to occur.
	+ Type: text
	+ Required: true
* **Complaint Type**: Choose the type of complaint you are experiencing (Mortgage, Interest, Property, or Other).
	+ Type: select_multiple
	+ Options: Mortgage, Interest, Property, Other
* **Description**: Describe the issue in detail.
	+ Type: text
	+ Required: true
* **Date Dispute**: Enter the date the dispute occurred.
	+ Type: date
	+ Required: true
* **Time Dispute**: Enter the time the dispute occurred.
	+ Type: time
	+ Required: true
* **Contact Number**: Enter your contact number to ensure we can reach you.
	+ Type: text
	+ Required: true
* **Email**: Enter your email to ensure we can contact you.
	+ Type: email
	+ Required: true
* **Proof**: If you have any supporting documentation or proof, you can upload it here (optional).
	+ Type: text
	+ Required: false
* **Document**: If you have any additional documentation to support your complaint, you can upload it here (optional).
	+ Type: text
	+ Required: false
* **Review Request**: If you have any further requests or requirements regarding your complaint, please indicate this here.
	+ Type: text
	+ Required: false
* **Review Status**: Select a status for your review request from the options provided (Pending, In Review, Resolved, Denied).
	+ Type: select_one
	+ Options: Pending, In Review, Resolved, Denied
	+ Required: false
