# monthly_grant_timesheet - Help Guide
## Purpose
This form is used to track and record grant-funded projects and their corresponding hours worked, project status, and other relevant metrics.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the Grant Funded Projects to which this timesheet applies.
2. Enter the hours worked on each project.
3. Indicate the Project Activity status of each project.
4. Enter the expense amount and description for each project, if applicable.
5. Select the Date Submitted and enter the submitted timestamp.
6. Enter the Notes, if any.
7. Select the Assigned User status for each project.
8. Enter the Email and Phone Number for the project contact person.
9. Enter the Grant Name, Grant ID, Project Name, and Project Start and End Dates.
10. Select the Project Status and provide a brief reason for the status change, if applicable.
11. Select whether this timesheet was submitted, and who submitted it.

## Field-by-Field Explanation

* **Grant Funded Projects** (`grant_funded_projects`, select_multiple): Select all the grant-funded projects you are reporting on. This field is required.
* **Hours Worked** (`hours_worked`, number): Enter the total hours worked on all selected projects. This field is required.
* **Project Activity** (`project_activity`, select_one): Indicate the current activity status of each project (Yes/No). This field is required.
* **Expense Amount** (`expense_amount`, number): Enter the total expense amount for all selected projects. This field is required.
* **Expense Description** (`expense_description`, text): Enter a brief description for each expense, if applicable. This field is optional.
* **Date Submitted** (`date_submitted`, date): Enter the date and time you submitted this timesheet. This field is required.
* **Notes** (`notes`, note): Add any additional notes or comments about the project. This field is optional.
* **Assigned User** (`assigned_user`, select_one): Indicate whether this project is assigned to someone (Yes/No). This field is required.
* **Email** (`email`, email): Enter the contact email of the project manager or lead. This field is optional.
* **Phone Number** (`phone_number`, text): Enter the contact phone number of the project manager or lead. This field is required.
* **Grant Name** (`grant_name`, text): Enter the name of the grant. This field is required.
* **Grant ID** (`grant_id`, text): Enter the unique ID of the grant. This field is required.
* **Project Name** (`project_name`, text): Enter the name of the project. This field is required.
* **Project Start Date** (`project_start_date`, date): Enter the start date of the project. This field is required.
* **Project End Date** (`project_end_date`, date): Enter the end date of the project. This field is required.
* **Project Status** (`project_status`, select_multiple): Select the current project status (Active/Inactive). This field is required.
* **Project Status Reason** (`project_status_reason`, text): Provide a brief reason for the project status change. This field is required.
* **Submitted At** (`submitted_at`, date): Enter the date and time you submitted this timesheet. This field is required.
* **Submitted By** (`submitted_by`, select_one): Indicate whether this timesheet was submitted (Yes/No). This field is required.
* **Assigned To** (`assigned_to`, select_one): Indicate whether this project is assigned to someone (Yes/No). This field is required.
