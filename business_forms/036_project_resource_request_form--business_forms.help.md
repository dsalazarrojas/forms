# Project Resource Request Form - Help Guide

## Purpose
This form is designed to help project managers submit resource requests for their projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project ID and project name in the respective fields.
2. Provide a brief description of the project, including its goals and objectives.
3. Select the type of resource required (e.g., personnel, materials, or financial support).
4. Enter the quantity of resources needed.
5. Choose the start and end dates for the project.
6. Select the project status (active, pending, or completed).
7. Enter the project manager and project lead names.
8. Select the resource manager and resource lead names.
9. Add any additional notes or comments about the project.
10. Specify the priority level of the project (high, medium, or low).
11. Select the individuals assigned to the project.
12. Choose the team members involved in the project.
13. Select the team members responsible for providing the resources.
14. Enter the project budget.
15. Enter the project status date and time.
16. Select the project priority level.
17. Add any project notes.

## Field-by-Field Explanation

* **Project ID** (`project_id`, number, required): Enter the unique ID for the project.
* **Project Name** (`project_name`, text, required): Enter the name of the project.
* **Project Description** (`project_description`, text, optional): Provide a brief description of the project.
* **Resource ID** (`resource_id`, text, optional): Enter the ID of the resource required.
* **Resource Name** (`resource_name`, text, optional): Enter the name of the resource required.
* **Resource Type** (`resource_type`, select_one, optional): Select the type of resource required (e.g., personnel, materials, or financial support).
* **Resource Quantity** (`resource_quantity`, number, optional): Enter the quantity of resources needed.
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of the project.
* **Project Status** (`project_status`, select_one, optional): Select the project status (active, pending, or completed).
* **Project Manager** (`project_manager`, text, optional): Enter the name of the project manager.
* **Project Lead** (`project_lead`, text, optional): Enter the name of the project lead.
* **Resource Manager** (`resource_manager`, text, optional): Enter the name of the resource manager.
* **Resource Lead** (`resource_lead`, text, optional): Enter the name of the resource lead.
* **Notes** (`notes`, text, optional): Add any additional notes or comments about the project.
* **Priority** (`priority`, select_multiple, optional): Select the priority level of the project (high, medium, or low).
* **Assigned To** (`assigned_to`, select_multiple, optional): Select the individuals assigned to the project.
* **Project Team** (`project_team`, select_multiple, optional): Select the team members involved in the project.
* **Resource Team** (`resource_team`, select_multiple, optional): Select the team members responsible for providing the resources.
* **Project Budget** (`project_budget`, number, optional): Enter the project budget.
* **Project Status Date** (`project_status_date`, date, optional): Enter the project status date.
* **Project Status Time** (`project_status_time`, time, optional): Enter the project status time.
* **Project Priority** (`project_priority`, select_multiple, optional): Select the project priority level (high, medium, or low).
* **Project Notes** (`project_notes`, text, optional): Add any additional project notes.
* **Project Manager 2** (`project_manager_2`, text, optional): Enter the name of the project manager 2.
