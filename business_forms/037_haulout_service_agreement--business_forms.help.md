# haulout_service_agreement - Help Guide
## Purpose
The haulout service agreement form is used to record general information about a vessel's haulout service. This form helps in maintaining accurate records and facilitating communication between service providers and vessel operators.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Review each section carefully and ensure you have all the necessary information before proceeding.
2. Fill out the General section with the basic information about the vessel.
3. Provide details about the vessel in the Vessel Details section, including its name and type.
4. Specify the haulout details, including type, date, and time range.
5. Choose the haulout status and vessel status.
6. Select the haulout cost currency and rate.
7. Add any remarks or comments related to the haulout service.
8. Review and verify all the information before submitting the form.

## Field-by-Field Explanation

* **General**: A brief description of the haulout service. (Text input, not required)
* **Vessel Details**: Select the name of the vessel and its type. (Select one, not required)
* **Haulout Details**: Select multiple options for the haulout type, date, and time. (Select multiple, not required)
* **Haulout Cost**: Enter the cost of the haulout service. (Number, not required)
* **Haulout Cost Currency**: Select the currency of the haulout cost. (Select one, not required)
* **Haulout Cost Rate**: Enter the rate of the haulout cost. (Number, not required)
* **Haulout Cost Rate Currency**: Select the currency of the haulout cost rate. (Select one, not required)
* **Vessel Status**: Select the status of the vessel. (Select one, not required)
* **Haulout Status**: Select the status of the haulout service. (Select one, not required)
* **Remarks**: Add any additional comments or remarks about the haulout service. (Note, not required)
* **Vessel Type Options**: Select multiple options for the vessel type. (Select multiple, not required)
* **Haulout Date Range**: Enter the date range for the haulout service. (Date, not required)
* **Haulout Time Range**: Enter the time range for the haulout service. (Time, not required)
* **Vessel Size**: Select the size of the vessel. (Select multiple, not required)
* **Haulout Cost Currency**: Select the currency of the haulout cost. (Select one, not required)

## Tips

* Ensure all fields are filled out accurately and consistently.
* Review each section carefully before proceeding.
* Verify the information against the actual service records.
* Use standard formatting for dates and times.
* If unsure about any field, consult the vessel operator or service provider.
