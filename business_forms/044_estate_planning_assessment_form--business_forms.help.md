# estate_planning_assessment_form - Help Guide
## Purpose
The estate planning assessment form is a tool to help individuals or organizations gather and organize information about their estate planning needs. This form is meant to be a comprehensive assessment of the user's goals, assets, and relationships to determine the best course of action for their estate planning.

## How To Complete This Form
1. **Introduction**: Read the introduction page to understand the purpose and structure of the form.
2. Select the relevant options for each field, and fill in any required information.
3. Review the form to ensure all necessary information is provided.

## Field-by-Field Explanation

* **Estate Planning Goals** (Page 2, label: Estate Planning Goals, type: text, required: false): This field is meant to gather the user's goals and objectives for the estate planning process.
* **Wills** (Page 3, label: Wills, type: select_multiple, required: false): Select all applicable options for the types of wills the user may have.
* **Trusts** (Page 3, label: Trusts, type: select_one, required: false): Choose one option that best describes the user's current trust status.
* **Asset Distribution** (Page 4, label: Asset Distribution, type: select_multiple, required: false): Select all applicable options for the types of assets the user has or wishes to distribute.
* **Beneficiaries** (Page 4, label: Beneficiaries, type: select_multiple, required: false): Select all applicable options for the individuals or organizations the user wishes to benefit from their estate.
* **Asset Values** (Page 5, label: Asset Values, type: number, required: false): Enter the current value of the user's assets.
* **Real Property Ownership** (Page 5, label: Real Property Ownership, type: select_multiple, required: false): Select all applicable options for the types of real property the user owns or wishes to own.
* **Asset Distribution Tips**: Review the asset distribution field for any specific distribution instructions or notes.
* **Beneficiaries Tips**: Review the beneficiaries field for any specific beneficiary instructions or notes.
* **Real Property Ownership Tips**: Review the real property ownership field for any specific property details or notes.
