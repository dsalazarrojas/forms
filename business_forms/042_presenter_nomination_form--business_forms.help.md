# presenter_nomination_form - Help Guide
## Purpose
The presenter_nomination_form is used to collect information for presenting nominations for speakers at an event.

## How To Complete This Form
To complete the form, follow these steps:
- Fill out the Speaker Information page.
- Fill out the Event Details page.
- Select the speaker nominations from the available options on the Nominations page.
- Enter the event date on the Event Date page.

## Field-by-Field Explanation
* **Speaker Information (speaker_information)**: Enter the name of the speaker being nominated. 
* **Event Details (event_details)**: Enter a brief description of the event, including any relevant details such as event type, location, and time. 
* **Nominations (speaker_nominations)**: Select the speakers you wish to nominate from the provided options. 
* **Event Date (event_date)**: Enter the date of the event for which the speaker is being nominated. 

## Tips
- Ensure that the speaker's name is accurate and up-to-date.
- Enter the correct event details to ensure the speaker can be properly prepared.
- Only select speakers who are available to present on the specified date.
- Review all fields carefully before submitting the form to ensure accuracy.
