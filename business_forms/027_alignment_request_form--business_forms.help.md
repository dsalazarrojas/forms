# Alignment Request Form - Help Guide
## Purpose
This form is designed to help project stakeholders request alignment and facilitate the process of ensuring that all relevant parties are on the same page.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information in the "Request ID", "Request Date", "Requester Name", "Requester Email", "Department", "Project Name", "Project Description", "Alignment Type", "Priority Level", "Teams Involved", "Current Status", "Alignment Goal", "Challenges Faced", and "Success Criteria" fields.
2. Select the required "Preferred Meeting Format" and "Preferred Meeting Time" options.
3. Indicate the "Timeline Impact" and "Budget Impact" (if applicable) of the misalignment.
4. Specify the "Requested Support" and any additional "Additional Context".
5. Attach any "Supporting Documents" (if necessary).

## Field-by-Field Explanation

* **Request ID**: (`request_id`, `text`, required) This field is used to provide a unique identifier for the request.
* **Request Date**: (`request_date`, `date`, required) This field is used to record the date the request was made.
* **Requester Name**: (`requester_name`, `text`, required) This field is used to record the full name of the requester.
* **Requester Email**: (`requester_email`, `email`, required) This field is used to record the email address of the requester.
* **Department**: (`department`, `text`, required) This field is used to record the department associated with the request.
* **Project Name**: (`project_name`, `text`, required) This field is used to record the name of the project.
* **Project Description**: (`project_description`, `text`, required) This field is used to record a brief description of the project.
* **Alignment Type**: (`alignment_type`, `select_one`, required) This field is used to indicate the type of alignment needed (e.g., strategic, cross-functional, resource, timeline, goal, process).
* **Priority Level**: (`priority_level`, `select_one`, required) This field is used to indicate the urgency of the request (e.g., critical, high, medium, low).
* **Teams Involved**: (`teams_involved`, `select_multiple`, required) This field is used to select all the teams involved in the project.
* **Current Status**: (`current_status`, `select_one`, required) This field is used to record the current status of the project (e.g., planning, early execution, mid-execution, late execution, facing roadblocks, completed).
* **Alignment Goal**: (`alignment_goal`, `text`, required) This field is used to record what the requester wants to achieve through the alignment process.
* **Challenges Faced**: (`challenges_faced`, `text`, required) This field is used to record any obstacles or challenges faced by the project.
* **Dependencies**: (`dependencies`, `text`, optional) This field is used to record any dependencies the project has.
* **Timeline Impact**: (`timeline_impact`, `select_one`, required) This field is used to indicate the potential impact on the timeline (e.g., no impact, minor delay, moderate delay, significant delay, project at risk).
* **Budget Impact**: (`budget_impact`, `select_one`, optional) This field is used to indicate the potential financial impact (e.g., no impact, under $10,000, $10,000-$50,000, $50,000-$100,000, over $100,000).
* **Requested Support**: (`requested_support`, `select_multiple`, required) This field is used to select the support needed from the project team.
* **Preferred Meeting Format**: (`preferred_meeting_format`, `select_one`, required) This field is used to select the preferred meeting format (e.g., in-person, video conference, phone conference, asynchronous collaboration, hybrid).
* **Availability**: (`availability`, `text`, required) This field is used to record the preferred times for the alignment meeting.
* **Alignment Deadline**: (`alignment_deadline`, `date`, required) This field is used to record the deadline for the alignment meeting.
* **Success Criteria**: (`success_criteria`, `text`, optional) This field is used to record how success will be measured.
* **Additional Context**: (`additional_context`, `text`, optional) This field is used to record any additional relevant information.
* **Supporting Documents**: (`supporting_documents`, `text`, optional) This field is used to attach any supporting documents.
