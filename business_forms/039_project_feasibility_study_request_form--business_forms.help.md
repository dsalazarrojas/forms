# project_feasibility_study_request_form - Help Guide
## Purpose
This form is used to assess the feasibility of a new project by collecting key parameters such as project title, status, priority, start and end dates, estimated cost, and project owner.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the project title in the "Project Title" field.
2. Describe the project in the "Project Description" field.
3. Select the current status of the project from the "Project Status" dropdown menu.
4. Choose the priority level of the project from the "Project Priority" dropdown menu.
5. Enter the start date of the project.
6. Enter the end date of the project.
7. Estimate the cost of the project.
8. Provide the name of the project owner.

## Field-by-Field Explanation

* **Project Title** (text, required: false): Enter a brief title of the project to help identify it for internal review.
* **business_name** (text, required: false): Please enter the name of the business or department related to the project.
* **project_description** (text, required: false): Provide a brief description of the project to help project managers understand its purpose and scope.
* **project_status** (select_one, required: false): Select the current status of the project:
	+ active: The project is currently being worked on.
	+ pending: The project is waiting for further review or resources.
	+ canceled: The project has been canceled or put on hold.
* **project_priority** (select_multiple, required: false): Choose the priority level of the project:
	+ high: The project is high-priority and should be completed quickly.
	+ low: The project is low-priority and can be completed when resources are available.
* **Start Date** (date, required: false): Enter the start date of the project.
* **End Date** (date, required: false): Enter the end date of the project.
* **Estimated Cost** (number, required: false): Provide an estimate of the project's cost.
* **Project Owner** (text, required: false): Enter the name of the person or department responsible for the project.

## Tips

* Please ensure that the information provided is accurate and up-to-date to facilitate informed decision-making.
* If the project status is "canceled", please provide a brief explanation for why the project was canceled.
* If the project priority is "high", please ensure that the project aligns with company goals and objectives.
* Please avoid duplicating effort by ensuring that the project is not already being worked on internally.
