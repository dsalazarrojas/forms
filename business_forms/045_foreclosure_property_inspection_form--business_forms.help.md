# Foreclosure Property Inspection Form - Help Guide
## Purpose
This form is designed to collect information about a property in foreclosure. The information collected will help assess the property's current status and make informed decisions.
## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the property details, including the address and any other relevant information.
2. Select the correct status of the property (Foreclosure, Bank Owned, Pre-foreclosure, or Owned).
3. Choose the type of property (Single Family, Multi Family, Commercial, Industrial, or Vacant).
4. Provide any additional information about the property's location.
5. Enter the property's inspection date.
6. Enter any inspection notes or comments.
7. Enter the property's age (if known).
8. Provide the inspector's name, phone number, and email.
9. Confirm whether the inspection was conducted with a fee (True or False).
10. Enter any notes about the inspection fee (if applicable).
11. Enter the property's price (if known).
12. Enter any additional notes about the property's price (if applicable).
13. Enter any inspection report comments.
14. Select the current status of the inspection (Complete, Incomplete, or Not Started).
14. Add any final comments or notes.

## Field-by-Field Explanation
* **property_details** (Page 1):
	+ A text input field where you can enter any details about the property.
* **property_address** (Page 1):
	+ A text input field where you can enter the property's address.
* **property_status** (Page 2):
	+ A dropdown menu where you can select the current status of the property (Foreclosure, Bank Owned, Pre-foreclosure, or Owned).
* **property_inspection_date** (Page 2):
	+ A date input field where you can enter the date of the inspection.
* **inspector_notes** (Page 3):
	+ A text input field where you can enter any notes or comments from the inspector.
* **property_condition** (Page 3):
	+ A text input field where you can enter any comments about the property's condition.
* **property_location** (Page 4):
	+ A text input field where you can enter any comments about the property's location.
* **property_contact** (Page 4):
	+ An email input field where you can enter the property owner's email address.
* **phone** (Page 4):
	+ A text input field where you can enter the property owner's phone number.
* **property_type** (Page 5):
	+ A dropdown menu where you can select the type of property (Single Family, Multi Family, Commercial, Industrial, or Vacant).
* **property_type_other** (Page 5):
	+ A text input field where you can enter any other type of property not listed in the previous field.
* **property_age** (Page 6):
	+ A number input field where you can enter the age of the property (if known).
* **property_age_other** (Page 6):
	+ A text input field where you can enter any other information about the property's age (if applicable).
