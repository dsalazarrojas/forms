# Receipt Loss Report - Help Guide
## Purpose
The Receipt Loss Report form is used to document instances of lost receipts, allowing businesses to track and manage these occurrences efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Employee Name**, which is the person who last had the lost receipt.
2.  Enter the **Customer Name**, if it's available.
3.  Select the **Date Lost**, when the receipt was last seen.
4.  Select any **Supporting Documents** that are relevant to the lost receipt, such as receipts, invoices, or contracts.
5.  You do not need to enter **Employee Signature**, **Customer Signature**, or **Vendor Signature** as they are not required fields.

## Field-by-Field Explanation

* **Employee Name** (`Employee Name`, text, required): Enter the name of the employee who last had the lost receipt.
* **Customer Name** (`Customer Name`, text, optional): Enter the name of the customer associated with the lost receipt, if available.
* **Date Lost** (`Date Lost`, date, required): Select the date when the receipt was last seen.
* **Supporting Documents** (`Supporting Documents`, select multiple, required): Select any documents that support the lost receipt, such as receipts, invoices, or contracts.
* **Notes** (Notes, note, optional): Add any additional comments or information about the lost receipt, if necessary.
