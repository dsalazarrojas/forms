# Facility Access Log - Help Guide
## Purpose
The Facility Access Log is a form used to record and document access to facilities, such as buildings, rooms, or equipment. This form is intended to help facility administrators, security personnel, and managers track and monitor who has accessed a facility, when they accessed it, and for what reason.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Provide Facility Name**: Type the name of the facility being accessed (e.g., "Main Building", "Lab 1", etc.).
2. **Provide Employee Name**: Enter the name of the employee who accessed the facility.
3. **Enter Access Time**: Select the time of day when the employee accessed the facility (e.g., 08:00, 12:00, etc.).

## Field-by-Field Explanation

* **Facility Name (text)**:
	+ This field is used to identify the facility being accessed.
	+ Please type the name of the facility, such as "Main Building" or "Lab 1".
* **Employee Name (text)**:
	+ This field is used to record the name of the employee who accessed the facility.
	+ Please type the employee's full name, including their first and last names (e.g., "John Doe").
* **Entry Time (time)**:
	+ This field is used to select the time of day when the employee accessed the facility.
	+ Choose the correct time using the hour and minute format (e.g., 08:00 or 12:30).

## Tips

* Please ensure that you have permission to access the facility before completing this form.
* If you need assistance or have questions about accessing a facility, contact the facility administrator or security personnel.
* This form is for recording official access to facilities; please do not use it for other purposes.
