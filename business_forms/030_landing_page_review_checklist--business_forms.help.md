# landing_page_review_checklist - Help Guide
## Purpose
The landing page review checklist is a tool used to evaluate the quality of a landing page. It helps in identifying areas that need improvement and ensures that the landing page meets the required standards.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the landing page and ensure that it has all the necessary components.
2. Select the correct header image size from the options provided.
3. Enter the headline and meta description for the page.
4. Enter the page title and ensure it is relevant to the content.
5. Select the background color for the page.
6. Choose the font size for the headline.
7. Enter the page URL (if applicable).

## Field-by-Field Explanation

* **Header Image** (`header_image`, `number`, required: false): The header image is the main image displayed on the landing page. Select the correct size for the header image from the provided options.
* **Headline** (`headline`, `text`, required: false): Enter the headline for the landing page. This should be a brief yet descriptive title that grabs the user's attention.
* **Headline Length** (`headline_length`, `number`, required: false): Enter the length of the headline in characters.
* **Meta Description** (`meta_description`, `text`, required: false): Enter a brief description of the page's content.
* **Page Title** (`page_title`, `text`, required: false): Enter the title of the page that appears in the browser tab or header.
* **Page URL** (`page_url`, `text`, required: false): Enter the URL of the landing page (if applicable).
* **Header Image Size** (`header_image_size`, `select_multiple`, required: false): Select the size of the header image from the provided options.
* **Headline Font Size** (`headline_font_size`, `select_one`, required: false): Select the font size for the headline from the provided options.
* **Background Color** (`background_color`, `text`, required: false): Enter the background color of the landing page in hexadecimal code (e.g., #ffffff).

**Tips**

* Ensure that all fields are filled out correctly to get accurate feedback.
* Use the provided options for header image size and headline font size to choose the best option for the landing page.
* Enter the page URL if it is a live page.
* Use a consistent background color that complements the header image and headline.
* Review the landing page carefully before submitting the form to ensure it meets the required standards.
