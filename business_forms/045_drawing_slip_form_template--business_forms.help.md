# Drawing Slip Form Template - Help Guide
## Purpose
The Drawing Slip Form Template is a versatile form used to create a drawing or sweepstakes event. It collects essential details such as entry name, draw date, start and end times, and more, helping event administrators efficiently plan and execute their events.

## How To Complete This Form
To complete this form, follow these general steps:

1. Enter the entry name for the event.
2. Select the correct draw date for the event.
3. Fill out the start and end times for the event (if applicable).
4. Choose the type of drawing or sweepstakes (if applicable).
5. Provide any other required or optional details as prompted.

## Field-by-Field Explanation

### Entry Name
* **Entry Name** (`entry_name`, Text, Required: false): Enter a unique and descriptive name for the event.

### Draw Date
* **Draw Date** (`draw_date`, Date, Required: false): Select the date for the event draw.

### Start Time
* **Start Time** (`start_time`, Time, Required: false): Enter the start time for the event (if applicable).

### Prophets
* **Prophets** (`prophets`, Number, Required: false): Enter the number of prophets for the event (if applicable).

### Entry Id
* **Entry Id** (`entry_id`, Number, Required: false): Enter a unique identifier for the entry.

### Draw Type
* **Draw Type** (`draw_type`, Select One: raffle, lottery, sweepstakes, contest, Required: false): Choose the type of drawing event (if applicable).

### Draw Date 2
* **Draw Date 2** (`draw_date_2`, Date, Required: false): Enter the draw date for another event detail (if necessary).

### Start Time 2
* **Start Time 2** (`start_time_2`, Time, Required: false): Enter the start time for another event detail (if necessary).

### End Time
* **End Time** (`end_time`, Time, Required: false): Enter the end time for the event (if applicable).

### Draw Date 3
* **Draw Date 3** (`draw_date_3`, Date, Required: false): Enter the draw date for another event detail (if necessary).

### Start Time 3
* **Start Time 3** (`start_time_3`, Time, Required: false): Enter the start time for another event detail (if necessary).

### End Time 2
* **End Time 2** (`end_time_2`, Time, Required: false): Enter the end time for another event detail (if necessary).

### Location
* **Location** (`location`, Text, Required: false): Enter the location for the event.

### Drawing Type
* **Drawing Type** (`drawing_type`, Select Multiple: raffle, lottery, sweepstakes, contest, Required: false): Choose the type of drawing event (if applicable).

### Number Of Prizes
* **Number Of Prizes** (`number_of_prizes`, Number, Required: false): Enter the number of prizes for the event (if applicable).

### Prize Description
* **Prize Description** (`prize_description`, Text, Required: false): Enter a description of the prize for the event (if applicable).

### Draw Status
* **Draw Status** (`draw_status`, Select One: open, closed, Required: false): Set the status of the draw event (if applicable).

### Draw Date 4
* **Draw Date 4** (`draw_date_4`, Date, Required: false): Enter the draw date for another event detail (if necessary).

Note that this form template is designed to be flexible, allowing event administrators to easily adapt it to their specific needs. Ensure that each entry submitted is unique to prevent errors and confusion. If you're unsure about any of the fields or have additional questions, please refer to the event category guidelines for further assistance.
