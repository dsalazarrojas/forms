# Service Downgrade Request Form - Help Guide

## Purpose
This form is for requesting a service downgrade. Fill out this form to provide details about the service in question and the reason for the downgrade request.

## How To Complete This Form

1. Select the service you are requesting a downgrade for from the "Service Name" field.
2. Enter the date you would like the downgrade to take effect.
3. Provide a brief explanation of the reason for the downgrade request in the "Reason" field.
4. Specify whether your service should be approved or denied by selecting "Yes" or "No" in the "Approval" field.
5. If approved, enter the name of the person approving the request in the "Approved By" field.
6. If approved, provide any additional comments in the "Comments" field.
7. Enter the date the request was approved in the "Approved At" field.
8. Select the current status of the service, either "Active" or "Inactive".
9. Enter a brief explanation for the current service status in the "Service Status Reason" field.
10. Enter the name of the customer requesting the downgrade.
11. Enter the customer's email address.
12. Enter the customer's phone number.
13. Enter any comments from the customer.
14. Select the current customer service status, either "Active" or "Inactive".
15. Enter a brief explanation for the current customer service status.
16. Enter the name of the administrator processing this request.
17. Enter the administrator's email address.
18. Enter the administrator's phone number.
19. Enter any comments from the administrator.
20. Select the current administrator service status, either "Active" or "Inactive".
21. Enter a brief explanation for the current administrator service status.

## Field-by-Field Explanation

* **Service Name** (`service_name`, required): This is the name of the service you are requesting a downgrade for.
* **Service Date** (`service_date`, required): This is the date you would like the downgrade to take effect.
* **Reason** (`reason`, required): This is a brief explanation of the reason for the downgrade request.
* **Approval** (`approval`, required): Select "Yes" to indicate approval of the downgrade request, "No" otherwise.
* **Approved By** (`approved_by`, required): If the request is approved, enter the name of the person approving the request.
* **Comments** (`comments`, required): If the request is approved, enter any additional comments.
* **Approved At** (`approved_at`, required): If the request is approved, enter the date the request was approved.
* **Service Status** (`service_status`, required): Select the current status of the service, either "Active" or "Inactive".
* **Service Status Reason** (`service_status_reason`, required): Enter a brief explanation for the current service status.
* **Customer Name** (`customer_name`, required): Enter the name of the customer requesting the downgrade.
* **Customer Email** (`customer_email`, required): Enter the customer's email address.
* **Customer Phone** (`customer_phone`, required): Enter the customer's phone number.
* **Customer Comments** (`customer_comments`, required): Enter any comments from the customer.
* **Customer Service Status** (`customer_service_status`, required): Select the current customer service status, either "Active" or "Inactive".
* **Customer Service Status Reason** (`customer_service_status_reason`, required): Enter a brief explanation for the current customer service status.
* **Admin Name** (`admin_name`, required): Enter the name of the administrator processing this request.
* **Admin Email** (`admin_email`, required): Enter the administrator's email address.
* **Admin Phone** (`admin_phone`, required): Enter the administrator's phone number.
* **Admin Comments** (`admin_comments`, required): Enter any comments from the administrator.
* **Admin Service Status** (`admin_service_status`, required): Select the current administrator service status, either "Active" or "Inactive".
* **Admin Service Status Reason** (`admin_service_status_reason`, required): Enter a brief explanation for the current administrator service status.
* **Request Type** (`request_type`, required): Select whether the request is a downgrade request ("Yes") or not ("No").
* **Requested Date** (`requested_date`, required): Enter the date the request was made.
* **Service ID** (`service_id`, required): Enter the unique ID of the service being requested for downgrade.
* **Request Type Options** (`request_type`, required): Select whether the request is for a downgrade ("Yes") or not ("No") - this option is for the request type field only.
* **Service ID** (`service_id`, required): Enter the unique ID of the service being requested for downgrade.
