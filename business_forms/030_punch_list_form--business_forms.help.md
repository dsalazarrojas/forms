# Punch List Form - Help Guide
## Purpose
The Punch List Form is used to track and manage tasks and their status within the organization. It allows users to assign tasks to employees, set due dates, and track progress. The form is essential for ensuring tasks are completed efficiently and on time.

## How To Complete This Form
1. Select all applicable tasks from the list of available tasks.
2. Enter the employee's name(s) assigned to the task.
3. Select a valid date when the task was assigned to the employee.
4. Select a valid due date for the task.
5. Choose the task priority (high/low) and status (active/inactive).
6. Add any notes or comments about the task.
7. Enter any additional notes or comments for the task.

## Field-by-Field Explanation

* **Task Assignments** (`task_assignments`, `select_multiple`): Select all applicable tasks from the list to indicate which tasks are assigned to which employees. 
  - This field allows users to choose multiple tasks and assign them to specific employees.

* **Employee Names** (`employee_names`, `text`): Enter the name(s) of the employee(s) assigned to the task.
  - This field requires the name of the employee(s) assigned to the task.

* **Assigned Dates** (`assigned_dates`, `date`): Select a valid date when the task was assigned to the employee.
  - This field requires a valid date to be entered.

* **Due Dates** (`due_dates`, `date`): Select a valid due date for the task.
  - This field requires a valid date to be entered.

* **Priority** (`priority`, `select_one`): Choose the priority level for the task (high or low).
  - This field allows users to choose between a high or low priority level.

* **Status** (`status`, `select_one`): Select the status of the task (active or inactive).
  - This field allows users to choose between an active or inactive status for the task.

* **Task Completed** (`task_completed`, `text`): Check if the task is completed.
  - This field is used to indicate if the task is completed.

* **Task Notes** (`task_notes`, `text`): Add any additional notes or comments for the task.
  - This field allows users to add any comments or notes about the task.

* **Assigned To** (`assigned_to`, `text`): Enter the name of the employee assigned to the task.
  - This field is used to enter the name of the employee assigned to the task.

* **Task ID** (`task_id`, `number`): Enter a unique ID number for the task.
  - This field requires a valid ID number to be entered.

* **Notes** (`notes`, `text`): Add any additional notes or comments for the task.
  - This field allows users to add any comments or notes about the task.
