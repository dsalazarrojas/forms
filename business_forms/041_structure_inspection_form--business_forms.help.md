# structure_inspection_form - Help Guide
## Purpose
This form is used to inspect a structure for its various features and components to ensure they meet specific standards.

## How To Complete This Form
1. Start by filling in the "Structure name" field with the name of the structure being inspected.
2. Enter the "Structure address" field with the address of the structure.
3. For each field that follows, select the response that best describes the condition of the structure's component.

## Field-by-Field Explanation
* **Structure name** (1, text, required): Enter the name of the structure being inspected.
* **Structure address** (2, text, required): Enter the address of the structure being inspected.
* **Structural integrity** (3, select_one, required): Select "Yes" if the structure's integrity is good, "No" if it's not.
* **Structural soundness** (4, select_one, required): Select "soundness" if the structure's soundness is good, "unsoundness" if it's not.
* **Structural fire suppression system** (5, select_multiple, required): Select the options that apply to the structure's fire suppression system, such as "installed" or "not installed".
* **Structural fire drill system** (6, select_multiple, required): Select the options that apply to the structure's fire drill system, such as "installed" or "not installed".
* **Structural stair wells** (7, select_one, required): Select "adequate" if the structure's stair wells are sufficient, "inadequate" if they're not.
* **Structural ramps** (8, select_one, required): Select "adequate" if the structure's ramps are sufficient, "inadequate" if they're not.
* **Structural handrails** (9, select_one, required): Select "adequate" if the structure's handrails are sufficient, "inadequate" if they're not.
* **Structural handrail clearance** (10, select_one, required): Select "adequate" if the structure's handrail clearance is sufficient, "inadequate" if it's not.
* **Structural handrail height** (11, select_multiple, required): Select the options that apply to the structure's handrail height, such as "installed" or "not installed".
* **Structural handrail material** (12, text, required): Enter the material used for the structure's handrails.
* **Structural handrail height required** (13, select_one, required): Select "required" if handrail height is a requirement, "not required" if it's not.
* **Structural handrail clearance required** (14, select_one, required): Select "required" if handrail clearance is a requirement, "not required" if it's not.
* **Structural stair tread** (15, select_one, required): Select "adequate" if the structure's stair tread is sufficient, "inadequate" if it's not.
* **Structural stair riser** (16, select_one, required): Select "adequate" if the structure's stair riser is sufficient, "inadequate" if it's not.
* **Structural handrail height required for handrails** (17, select_one, required): Select "required" if handrail height is a requirement for handrails, "not required" if it's not.
* **Structural stair wells and landings** (18, select_one, required): Select "adequate" if the structure's stair wells and landings are sufficient, "inadequate" if they're not.
* **Structural stair wells and landings clearance** (19, select_one, required): Select "adequate" if the structure's stair wells and landings clearance is sufficient, "inadequate" if it's not.
* **Structural stair railing** (20, select_one, required): Select "adequate" if the structure's stair railing is sufficient, "inadequate" if it's not.
* **Structural railing height** (21, select_multiple, required): Select the options that apply to the structure's railing height, such as "installed" or "not installed".
* **Structural railing material** (22, text, required): Enter the material used for the structure's railing.
* **Structural railing clearance** (23, select_one, required): Select "adequate" if the structure's railing clearance is sufficient, "inadequate" if it's not.
* **Structural hallway railing** (24, select_multiple, required): Select the options that apply to the structure's hallway railing, such as "installed" or "not installed".

## Tips
* Take your time to carefully read each question and select the response that best describes the condition of the structure's component.
* Make sure to review your answers carefully before submitting the form.
* If you're unsure about a particular field, ask for clarification or consult the structure's plans or documentation.

Note: This guide is intended to be a step-by-step walkthrough of the form and its fields, but it's not a comprehensive guide to structural inspection or building codes. It's meant to be a helpful resource for end-users who need to complete the form.
