# Custom Event Logistics Request Form - Help Guide
## Purpose
This form is used to request event logistics information from a vendor. It helps in collecting all the necessary details about a custom event, such as event name, venue, date, time, vendor information, and event description, to efficiently manage events or vendor relationships.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the required information about the event:
	* Event Name: Enter the name of the event.
	* Event Date: Enter the date of the event in the correct format (MM/DD/YYYY).
	* Event Time: Enter the time of the event.
2. Provide the vendor's information:
	* Vendor Name: Enter the name of the vendor or company providing the event services.
	* Vendor Contact: Enter the contact person's name.
	* Vendor Email: Enter the email address of the vendor.
	* Vendor Phone: Enter the phone number of the vendor.
	* Vendor Address: Enter the address of the vendor.
3. Add a brief description of the event: Enter a short description of the event to help with identification and reference.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, optional): Enter the name of the event.
* **venue** (`venue`, text, optional): Enter the location where the event will take place.
* **Event Date** (`event_date`, date, optional): Enter the date of the event in the correct format (MM/DD/YYYY).
* **Event Time** (`event_time`, time, optional): Enter the time of the event.
* **Vendor Name** (`vendor_name`, text, optional): Enter the name of the vendor or company providing the event services.
* **Vendor Contact** (`vendor_contact`, text, optional): Enter the contact person's name.
* **Vendor Email** (`vendor_email`, email, optional): Enter the email address of the vendor.
* **Vendor Phone** (`vendor_phone`, text, optional): Enter the phone number of the vendor.
* **Vendor Address** (`vendor_address`, text, optional): Enter the address of the vendor.
* **Event Description** (`event_description`, text, optional): Enter a short description of the event to help with identification and reference.

## Tips
- Make sure to fill in all required fields to ensure that your event logistics request is complete.
- Be accurate and clear when entering the event details to avoid any confusion or misunderstandings.
- Double-check your entries for any errors before submitting the form.
