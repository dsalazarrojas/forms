# Corporate Strategy Records Release Form - Help Guide

## Purpose
This form is intended for submitting and managing corporate strategy records releases. It's essential to ensure that you understand the purpose of the form and its relevance to your tasks before proceeding. Please use this guide to help you complete the form accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct category for your records release form from the "Category" dropdown menu. If you're unsure, choose "Business Forms".
2. Provide a brief description of the records release form in the "Description" field.
3. Assign a tool from the "Assigned Tool" dropdown menu, such as "chatjimmy" or "other tool".
4. If applicable, upload any relevant output files in the "Output File" field.
5. Add any additional notes in the "Notes" field.
6. Enter your email address in the "Email" field.
7. Enter your phone number in the "Phone" field.
8. If necessary, select the required fields for the records release form from the "Required Fields" dropdown menu. This may include "Corporate Strategy", "Records Release Form", "Records Release Form Version", or "Other Records Release Form".
9. Add any further notes in the "Other Notes" field.

## Field-by-Field Explanation

* **Corporate Strategy Records Release Form (Page 1)** (`corporate_strategy_records_release_form`, text, required): This field is a text input where you can enter the title of your corporate strategy records release form. It's a crucial field that helps identify the form's purpose.

* **Assigned Tool (Assigned Tool, select_one, optional): This field is a dropdown menu where you can assign a tool to your records release form. This helps track which tool is associated with the form.
* **Output File (Output File, text, optional): This field is a text input where you can upload any relevant output files related to your records release form.
* **Notes (Notes, note, optional): This field is a note input where you can add any additional notes about your records release form.
* **Email (Email, email, optional): This field is an email input where you can enter your email address. It's an optional field but helps in case there's a need to communicate further.
* **Phone (Phone, text, optional): This field is a text input where you can enter your phone number. It's an optional field but useful for further communication.
* **Required Fields (Required Fields, select_multiple, optional): This field is a dropdown menu where you can select the required fields for your records release form. This includes "Corporate Strategy", "Records Release Form", "Records Release Form Version", or "Other Records Release Form". It's an optional field, but it's helpful for ensuring completeness.
