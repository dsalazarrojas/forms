# Graphic Design Checklist Form - Help Guide
## Purpose
The Graphic Design Checklist Form is a tool used to collect project details from clients or designers. It helps the design team understand the project's scope, goals, and requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief title for the project.
2. Give a detailed description of the project.
3. Specify if the project requires any specific design elements, such as color scheme or typography.
4. Select the required color type (e.g., RGB or CMYK).
5. If applicable, upload any relevant design files or provide links to them.
6. Set a deadline for the project completion.
7. Optionally, select any required fonts or upload additional project information.

## Field-by-Field Explanation
* **Project Title** (`title`, text, required: false): Enter a brief title for the project.
* **Project Description** (`project_info`, text, required: true): Give a detailed description of the project.
* **Design Requirements** (`design_requirements`, select_one, required: true): Check if the project requires any specific design elements, such as color scheme or typography.
* **Color Scheme** (`color_scheme`, select_one, required: true): Select the required color scheme for the project (e.g., Monochromatic, Complementary, or Analogous).
* **Images** (`images`, text, required: false): If applicable, upload any relevant images or provide links to them.
* **Fonts and Typography** (`fonts`, select_multiple, required: false): Select the required fonts or typography for the project.
* **Project Information** (`project_info_3`, text, required: false): Provide any additional project information.
* **Color Type** (`color_type`, select_one, required: false): Select the required color type (e.g., RGB or CMYK).
* **Design File** (`design_file`, note, required: false): If applicable, upload any relevant design files or provide links to them.
* **Project Deadline** (`deadline`, date, required: true): Set a deadline for the project completion in the format YYYY-MM-DD.

## Tips
* Ensure that you fill out the form accurately and thoroughly to avoid delays or rework.
* If you're unsure about any field, refer to this guide for clarification.
* If you need to upload files, please ensure they are in the required format.
* If you have any additional project requirements or details, please provide them in the "Project Information" field.
