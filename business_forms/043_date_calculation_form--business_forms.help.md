# Date Calculation Form - Help Guide

## Purpose
The Date Calculation Form is designed to help users calculate dates in various ways, such as finding the number of days between two dates or adding/subtracting a specific number of days from a given date.

## How To Complete This Form

1. To start, select two dates from the available fields (`date1` and `date2`).
2. Choose the calculation type from the options provided:
	* `Days between` to find the number of days between two dates.
	* `Plus` to add a specific number of days to a date.
	* `Minus` to subtract a specific number of days from a date.
3. Enter the number of days to be added or subtracted in the `calculate` field.
4. Click "Submit" to perform the calculation and display the result.

## Field-by-Field Explanation

* **Date 1** (`date1`, date, optional): Enter the first date to use in your calculation.
* **Date 2** (`date2`, date, optional): Enter the second date to use in your calculation.
* **Calculation Type** (`calculation_type`, select_one, optional): Choose the type of calculation to perform. The options are `Days between`, `Plus`, and `Minus`.
* **Calculate** (`calculate`, number, optional): Enter the number of days to add or subtract from the date.
* **Result** (`result`, note, optional): The calculated result of the date calculation will be displayed here.
* **Date 1 Label** (`date1_label`, text, optional): This field is intended to be used to label the first date. Currently, it's not used in the calculation.
* **Date 2 Label** (`date2_label`, text, optional): This field is intended to be used to label the second date. Currently, it's not used in the calculation.
* **Result Label** (`result_label`, text, optional): This field is intended to be used to label the result. Currently, it's not used in the calculation.

Note: The "label" fields are not currently used in the calculation. If you need to label your dates or result, please enter a text description in these fields for your own reference.

## Tips

* Make sure to enter valid dates in the date fields.
* The result will be displayed in the "Result" field.
* If you need to perform multiple calculations, you can fill out this form multiple times.
