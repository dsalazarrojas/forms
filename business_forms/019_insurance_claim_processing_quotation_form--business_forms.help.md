# Insurance Claim Processing Quotation Form - Help Guide
## Purpose
This form is designed to collect information for the purpose of processing insurance claims, gathering relevant details from both the claimant and the agent involved in the claim.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form in its entirety, paying attention to the required fields indicated by a asterisk (\*).
2. Enter accurate information for each field, ensuring that you provide the correct details for the claimant and agent involved.
3. If you are unsure about any field, review the instructions and guidelines provided below for clarification.

## Field-by-Field Explanation

* **Client Information** (`client_information`, text, optional): This field is used to collect the client's name, address, and contact information. Please enter the claimant's details accurately.
* **Claim Details** (`claim_details`, text, required): This field is used to describe the nature of the claim, including the date of incident, claimant name, and claimant contact information. Please enter a clear and concise description of the claim.
* **Quote Request** (`quote_request`, text, optional): This field is used to request a quote from the insurance company. If this field is not relevant, you may leave it blank.
* **Insurance Policy** (`insurance_policy`, text, required): This field is used to identify the insurance policy number or details. Please enter the correct policy number or details.
* **Date Of Incident** (`date_of_incident`, date, required): This field is used to record the date of the incident that led to the claim. Please enter the correct date in the correct format (MM/DD/YYYY).
* **Claimant Name** (`claimant_name`, text, required): This field is used to record the name of the claimant. Please enter the claimant's name accurately.
* **Claimant Contact** (`claimant_contact`, text, required): This field is used to record the claimant's contact information (phone, email, etc.). Please enter the claimant's contact details accurately.
* **Claim Details Description** (`claim_details_description`, text, optional): This field is used to provide a brief description of the claim details. If not required, please leave it blank.
* **Claimant Address** (`claimant_address`, text, optional): This field is used to collect the claimant's address. If not required, please leave it blank.
* **Medical Certificate** (`medical_certificate`, text, optional): This field is used to collect medical certificates or supporting documents. If not required, please leave it blank.
* **Proof Of Payment** (`proof_of_payment`, text, optional): This field is used to collect proof of payment for the claim. If not required, please leave it blank.
* **Claimant Document** (`claimant_document`, text, optional): This field is used to collect additional documents supporting the claim. If not required, please leave it blank.
* **Additional Documents** (`additional_documents`, text, optional): This field is used to collect any additional documents that may be relevant to the claim. If not required, please leave it blank.
* **Claimant Statement** (`claimant_statement`, text, optional): This field is used to collect a statement from the claimant. If not required, please leave it blank.
* **Claimant Statement Attachment** (`claimant_statement_attachment`, text, optional): This field is used to attach supporting documents for the claimant's statement. If not required, please leave it blank.
* **Claimant Phone** (`claimant_phone`, text, optional): This field is used to collect the claimant's phone number. If not required, please leave it blank.
* **Claimant Email** (`claimant_email`, email, optional): This field is used to collect the claimant's email address. If not required, please leave it blank.
* **Claimant Notes** (`claimant_notes`, note, optional): This field is used to collect additional notes about the claimant. If not required, please leave it blank.
* **Claimant Signature** (`claimant_signature`, text, optional): This field is used to collect the claimant's signature. If not required, please leave it blank.
* **Claimant Signature Attachment** (`claimant_signature_attachment`, text, optional): This field is used to attach the claimant's signature document. If not required, please leave it blank.
* **Agent Information** (`agent_information`, text, optional): This field is used to collect the agent's contact information. If not required, please leave it blank.
* **Agent Name** (`agent_name`, text, optional): This field is used to record the agent's name. If not required, please leave it blank.
* **Agent Contact** (`agent_contact`, text, optional): This field is used to collect the agent's contact information. If not required, please leave it blank.
* **Agent Signature** (`agent_signature`, text, optional): This field is used to collect the agent's signature. If not required, please leave it blank.
* **Agent Signature Attachment** (`agent_signature_attachment`, text, optional): This field is used to attach the agent's signature document. If not required, please leave it blank.

## Tips

* Please ensure that you fill out the form accurately and honestly, providing all required information.
* If you are unsure about any field, please review the guidelines and instructions provided.
* If you have any questions or concerns, please do not hesitate to reach out to the relevant authorities or support personnel.
* Please attach all necessary documents and supporting materials when required.
