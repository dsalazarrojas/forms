# innovation_lab_referral_form - Help Guide
## Purpose
The innovation lab referral form is used to refer projects to the Innovation Lab for evaluation and potential implementation. This form is used to collect information about the project, including project name, description, URL, and other relevant details.

## How To Complete This Form
1. Select the project stage from the options provided.
2. Select the project category from the options provided.
3. Enter the project name and description in the corresponding fields.
4. Enter the project URL.
5. Select the project owner.
6. Enter the email address of the project owner.
7. Enter the phone number of the project owner.
8. Enter the name of the person referring the project.
9. Enter the role of the person referring the project.
10. Enter the email address of the person referring the project.
11. Select the department of the person referring the project (if applicable).
12. Select the location of the person referring the project (if applicable).
13. Enter the date the project was submitted for review.
14. Enter the date the project is due for review (if applicable).
15. Select the time the project is due for review (if applicable).
16. Enter any additional notes about the project.
17. Select any relevant documents associated with the project.

## Field-by-Field Explanation

* **project_name** (id: 2, <type>: text, required/optional): Enter the name of the project.
* **project_description** (id: 3, <type>: text, required/optional): Enter a brief description of the project.
* **project_url** (id: 4, <type>: text, required/optional): Enter the URL of the project.
* **project_stage** (id: 5, <type>: select_one, required/optional): Select the current stage of the project from the options provided.
* **project_status** (id: 6, <type>: select_one, required/optional): Select the status of the project from the options provided.
* **project_category** (id: 7, <type>: select_one, required/optional): Select the category of the project from the options provided.
* **project_team** (id: 8, <type>: select_multiple, required/optional): Select the teams associated with the project.
* **project_owner** (id: 9, <type>: text, required/optional): Enter the name of the project owner.
* **email** (id: 10, <type>: email, required/optional): Enter the email address of the project owner.
* **phone** (id: 11, <type>: text, required/optional): Enter the phone number of the project owner.
* **submitter_name** (id: 12, <type>: text, required/optional): Enter the name of the person referring the project.
* **submitter_role** (id: 13, <type>: text, required/optional): Enter the role of the person referring the project.
* **submitter_email** (id: 14, <type>: email, required/optional): Enter the email address of the person referring the project.
* **submitter_phone** (id: 15, <type>: text, required/optional): Enter the phone number of the person referring the project.
* **submitter_department** (id: 16, <type>: text, required/optional): Enter the department of the person referring the project (if applicable).
* **submitter_location** (id: 17, <type>: text, required/optional): Enter the location of the person referring the project (if applicable).
* **submitter_date** (id: 18, <type>: date, required/optional): Enter the date the project was submitted for review.
* **review_date** (id: 19, <type>: date, required/optional): Enter the date the project is due for review (if applicable).
* **review_time** (id: 20, <type>: time, required/optional): Enter the time the project is due for review (if applicable).
* **project_tags** (id: 21, <type>: text, required/optional): Enter any additional tags or keywords for the project.
* **project_notes** (id: 22, <type>: text, required/optional): Enter any additional notes about the project.
* **project_employees** (id: 23, <type>: text, required/optional): Enter any employees associated with the project.
* **project_participants** (id: 24, <type>: text, required/optional): Enter any participants associated with the project.
* **project_files** (id: 26, <type>: select_multiple, required/optional): Select any relevant documents associated with the project.
