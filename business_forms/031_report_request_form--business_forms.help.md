# Report Request Form - Help Guide
## Purpose
The Report Request Form is used to gather information for reports from the requester to provide to the submitter. This form helps to standardize the process of creating and submitting reports in the system.

## How To Complete This Form
To complete the Report Request Form, follow these steps:

1. Select the report type that best describes the purpose of the report.
2. Enter your project number if it's required for the report.
3. Choose the report frequency (e.g., Daily, Weekly, Monthly, Quarterly, Annual).
4. Select the report start and end dates for the specified period.
5. Enter your email and phone number for the requestor and submitter details.
6. Choose the submitter's role (e.g., Project Manager, Project Team, Data Manager).
7. Enter any additional comments or instructions for the submitter.

## Field-by-Field Explanation

* **Report Type**: Select the report type from the options (Progress Report, Status Report, Detail Report) to help us understand the purpose of the report.
* **Project Number**: If required for the report, enter the project number for reference purposes.
* **Report Frequency**: Choose the frequency at which the report should be submitted (e.g., Daily, Weekly, Monthly, Quarterly, Annual).
* **Report Start Date**: Enter the start date of the report period.
* **Report End Date**: Enter the end date of the report period.
* **Requester**: Enter your name or title as the person requesting the report.
* **Requester Email**: Enter your email address so we can contact you for any further information.
* **Requester Phone**: Enter your phone number for any additional communication.
* **Requested By**: Choose the role of the submitter (e.g., Project Manager, Project Team, Data Manager).
* **Report Comment**: Enter any additional comments or instructions for the submitter.
* **Submit Date**: Enter the date when the report was submitted.
* **Submit Time**: Enter the time when the report was submitted.
* **Submitter**: Choose the role of the person submitting the report (e.g., Project Manager, Project Team, Data Manager).
* **Submitter Email**: Enter the email address of the person submitting the report.
* **Submitter Phone**: Enter the phone number of the person submitting the report.
* **Submitter Comment 1-7**: Enter any additional comments or instructions for the submitter.

Note: Some fields may not be applicable for all reports, and not all fields are marked as required.
