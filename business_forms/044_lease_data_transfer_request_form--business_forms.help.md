# lease_data_transfer_request_form - Help Guide
## Purpose
This form is used to request the transfer of lease data between teams or departments within the same organization. It helps facilitate the submission of a lease data transfer request, providing the ability to specify the category, description, lease data, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a title for the request.
2. Select the category for the transfer request.
3. Enter a description of the lease data transfer request.
4. Enter the lease data to be transferred.
5. Specify any transfer request details.
6. Select the property team responsible for the lease data.
7. Choose how the submission will be tracked (e.g., using a Jotform Form Builder or another method).
8. Select the submission tracking options.

## Field-by-Field Explanation
- **Form Title** (`form_title`, `text`, required: false): Enter a brief title for the request.
- **Category** (`category`, `select_multiple`, required: false): Select one or more categories relevant to the transfer request.
- **Description** (`description`, `text`, required: true): Enter a detailed description of the lease data transfer request.
- **Lease Data** (`lease_data`, `text`, required: false): Enter the lease data to be transferred.
- **Transfer Request** (`transfer_request`, `text`, required: false): Specify any transfer request details.
- **Property Team** (`property_team`, `select_one`, required: false): Select the property team responsible for the lease data.
- **Jotform Form Builder** (`jotform_form_builder`, `select_one`, required: false): Choose how the submission will be tracked (e.g., using a Jotform Form Builder or another method).
- **Organized Submission Tracking** (`organized_submission_tracking`, `select_multiple`, required: false): Select the submission tracking options.
