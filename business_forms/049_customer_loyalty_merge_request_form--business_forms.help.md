# Customer Loyalty Merge Request Form - Help Guide
## Purpose
This form allows you to request a merge between two customer accounts, which can help eliminate duplicate records and improve data accuracy.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the customer ID of the account you want to merge into.
2.  Enter the existing ID of the account you want to merge.
3.  Select "Merge" or "Do not merge" to confirm or reject the merge request.
4.  Provide any additional comments about the merge request.
5.  Enter any merge notes for the support team to reference.
6.  Select "Submit" to complete the request.

## Field-by-Field Explanation
* **Customer ID** (`customer_id`, number, required): Enter the ID of the customer account you want to merge into.
* **Merge Reason** (`merge_reason`, text, optional): Provide a brief explanation for the merge request (e.g., "Duplicate account created by mistake").
* **Customer Name** (`customer_name`, text, optional): Enter the name of the customer (if not already provided).
* **Account Name** (`account_name`, text, optional): Enter the name of the account (if not already provided).
* **Existing ID** (`existing_id`, number, required): Enter the ID of the existing account you want to merge.
* **Existing Name** (`existing_name`, text, optional): Enter the name of the existing account (if not already provided).
* **Confirm Merge** (`confirm_merge`, select, required): Select "Merge" to confirm the merge request or "Do not merge" to reject.
* **Comments** (`comments`, text, optional): Provide any additional comments about the merge request.
* **Merge Notes** (`merge_notes`, text, optional): Enter any notes for the support team to reference.
* **Submit** (`submit`, select, required): Select "Submit" to complete the request.
