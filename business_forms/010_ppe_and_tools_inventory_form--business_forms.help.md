# ppe_and_tools_inventory_form - Help Guide
## Purpose
This form is used to track the inventory of PPE and tools within an organization.

## How To Complete This Form
To complete this form, please follow the instructions below.

1. Determine which fields are relevant to the information you are tracking and fill out the corresponding fields.
2. Fill out the **form details** field with any additional information about the tool.
3. Select the **PPE category** of the tool from the dropdown menu.
4. Enter the **tool name** in the text field.
5. Enter the **quantity** of the tool.
6. Enter a brief **description** of the tool.
7. Enter the **serial number** of the tool.
8. Enter the **manufacturer** of the tool.
9. Select whether the tool is located at **location** from the dropdown menu.
10. Enter the **asset value** of the tool.
11. Select whether the tool is **assigned to** from the dropdown menu.
12. Enter any additional **notes** about the tool in the free-text field.

## Field-by-Field Explanation
* **Form Details**: A brief description of the form to help you get started.
* **PPE Category**: Select the category of the tool (e.g., safety glasses, gloves, etc.).
* **Tool Name**: Enter the name of the tool.
* **Quantity**: Enter the number of tools you have.
* **Description**: Enter a brief description of the tool.
* **Serial Number**: Enter the serial number of the tool.
* **Manufacturer**: Enter the manufacturer of the tool.
* **Location**: Select where the tool is located (e.g., warehouse, office, etc.).
* **Asset Value**: Enter the value of the tool.
* **Assigned To**: Select whether the tool is assigned to a person or group.
* **Notes**: Enter any additional comments about the tool.
