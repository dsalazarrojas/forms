# Project Closure Report Template - Help Guide
## Purpose
The Project Closure Report Template is a tool for project teams to document key information about a project's status when it is closed or inactive. This form ensures a seamless and efficient project closure process.

## How To Complete This Form
1. Select the project status as "Active" or "Inactive" to indicate the current state of the project.
2. Enter the project manager's name and email address to provide contact information.
3. Enter the closure date when the project was officially closed.
4. Provide any additional comments or notes about the project's closure.
5. Confirm if the project status was changed during the closure process.
6. Select "Yes" or "No" to confirm if the project is closed.

## Field-by-Field Explanation

* **Project Closure Report**: This field allows you to enter a brief description of the project, such as its name or title.
* **Project Status**: Select "Active" if the project is currently ongoing, or "Inactive" if it has been closed.
* **Project Manager**: Enter the name of the person responsible for managing the project.
* **Project Manager Email**: Enter the email address of the project manager, so they can be contacted for further information.
* **Closure Date**: Enter the date when the project was officially closed.
* **Comments**: Provide any additional comments or notes about the project's closure.
* **Project Closure Remarks**: Enter any additional comments or notes about the project's closure.
* **Status updated**: This field is not currently used for any functionality, it's likely a placeholder for a future feature.
* **Is it closed?**: Confirm that the project is indeed closed.
* **Status Changed**: This field was likely intended to store the timestamp of when the status was changed, it's not used as it's always set to the current time when submitted.
* **Project Closure Notes**: Enter any additional comments or notes about the project's closure.

Note: This form is designed to be completed when a project is closed or inactive, and all fields should be filled accordingly.
