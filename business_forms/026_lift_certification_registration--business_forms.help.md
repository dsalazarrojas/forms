# Lift Certification Registration - Help Guide
## Purpose
This form is designed to collect information from individuals or organizations seeking lift certification. The form helps to gather details about the equipment, contact information, and certification status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Select the correct options for the lift type, certification requests, inspection status, and review status.
3. Upload any necessary files or documents.
4. Review your completed form before submitting it.

## Field-by-Field Explanation
* **Equipment Details**: Enter a brief description of the lift equipment being certified.
* **Contact Information**: Enter your name, email, and phone number for communication purposes.
* **Lift Type**: Select 'Yes' if the lift is certified, 'No' if it is not certified, or select 'Other' if it has a non-standard certification status.
* **Certification Date**: Enter the date of the lift's certification.
* **Schedule**: Provide a schedule for the lift's maintenance or certification renewal.
* **Certification Requests**: Select 'Yes' if you are requesting certification, 'No' if you are not, or select 'Other' if you have a special request.
* **Upload Files**: Attach any relevant files or documents to support your certification application.
* **Inspection Status**: Select 'Yes' if the lift is inspected regularly, 'No' if it is not inspected, or select 'Other' if it has a non-standard inspection status.
* **Review Status**: Select 'Yes' if the lift has been reviewed, 'No' if it has not been reviewed, or select 'Other' if it has a non-standard review status.
* **Submit**: Select 'Yes' to submit your completed form, 'No' if you need to revise it, or select 'Other' if you have further questions.

## Tips
- Make sure to complete all required fields accurately and truthfully.
- If you have any doubts or questions, contact the form administrators.
- Review your form carefully before submitting it to avoid errors.
