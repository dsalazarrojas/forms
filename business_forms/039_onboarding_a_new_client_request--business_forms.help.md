# onboarding_a_new_client_request - Help Guide
## Purpose
The "onboarding_a_new_client_request" form is used to onboard a new client to the system. This form collects client information, onboarding details, and assignee details for new client requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to start filling out the form.
2. Select the relevant information in each field as described below.

## Field-by-Field Explanation

* **New Client Request Form** (`new_client_request_form`): Enter a brief description of the new client request.
* **Client Name** (`client_name`): Enter the name of the new client.
* **Client Email** (`client_email`): Enter the email address of the new client.
* **Client Phone** (`client_phone`): Enter the phone number of the new client.
* **Onboarding Date** (`onboarding_date`): Select the date of the new client onboarding.
* **Onboarding Time** (`onboarding_time`): Select the time of the new client onboarding.
* **Onboarding Address** (`onboarding_address`): Enter the onboarding address of the new client.
* **Onboarding Notes** (`onboarding_notes`): Enter any notes related to the new client onboarding.
* **Status** (`onboarding_status`): Select the current status of the new client (Active or Inactive).
* **Status Note** (`onboarding_status_note`): Enter any additional notes for the status selected.
* **Assigned To** (`assigned_to`): Enter the name of the assignee who will handle the new client request.
* **Assigned Tool** (`assigned_tool`): Enter the tool assigned to the new client request.
* **Assigned Date** (`assigned_date`): Select the date when the new client request was assigned.
* **Onboarding User** (`onboarding_user`): Select the user who will be handling the new client onboarding (Chatjimmy or Other).
* **User Note** (`onboarding_user_note`): Enter any notes related to the user handling the new client onboarding.
* **New Client Request Form Note** (`new_client_request_form_note`): Enter any additional notes for the new client request form.
* **Onboarding Form Version** (`onboarding_form_version`): Enter the version of the onboarding form being used.
* **Client Form Data** (`client_form_data`): Enter any additional client form data.
* **Onboarding Form Category** (`onboarding_form_category`): Select the category of the onboarding form (Business Forms or Other).
* **Onboarding Form Description** (`onboarding_form_description`): Enter a description of the onboarding form.
* **Onboarding Form Assigned Tool** (`onboarding_form_assigned_tool`): Enter the tool assigned to the onboarding form.
* **Onboarding Form Output File** (`onboarding_form_output_file`): Enter the output file for the onboarding form.

## Tips

* Make sure to fill in all required fields.
* Use the correct format for dates and times.
* Double-check the status and assigned user information.
* If you're unsure about any field, contact your system administrator for assistance.
