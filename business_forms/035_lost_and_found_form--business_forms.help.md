# lost_and_found_form - Help Guide
## Purpose
The "Lost and Found Form" is used to document and track lost or found items within the organization. This form collects details about the item, its owner, and any contact information for the owner.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the lost or found item in the "Item Description" field.
2. Select the type of item's owner from the "Owner Type" dropdown menu (Business, School, or Organization).
3. Enter the location where the item was found in the "Found Location" field.
4. Select the date and time when the item was found in the "Found Date" and "Found Time" fields.
5. Provide any contact information for the item's owner in the "Contact Info" field.

## Field-by-Field Explanation
* **Item Description** (`item_description`, text, optional): A brief description of the lost or found item.
* **Owner Type** (`owner_type`, select_one, required): The type of entity that owns the item (Business, School, or Organization).
* **Found Location** (`found_location`, text, optional): The location where the item was found.
* **Found Date** (`found_date`, date, optional): The date when the item was found.
* **Found Time** (`found_time`, time, optional): The time of day when the item was found.
* **Contact Info** (`contact_info`, text, optional): Any contact information for the item's owner. 

## Tips
* Be as detailed as possible when describing the item and providing contact information.
* Make sure to select the correct owner type for accuracy.
* Use the date and time fields to accurately report when the item was found.
* If unsure about any field, ask for assistance or clarification from staff.
