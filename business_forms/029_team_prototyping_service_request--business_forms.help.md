# Team Prototyping Service Request - Help Guide

## Purpose
The Team Prototyping Service Request form is used to collect requests for prototyping services from team members.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the services you require from the "Service Type" dropdown menu. You can select multiple services.
2. Provide a brief description of the service you need in the "Description" field.
3. If you need to contact the team about this request, select "Yes" in the "Contact Person" field and provide your email address in the "Contact Email" field.
4. If you need to provide additional contact information, you can add your phone number in the "Contact Phone" field.
5. Provide any other details about the service you need in the "Service Details" field.
6. Set a deadline for the service in the "Deadline" field (if applicable).

## Field-by-Field Explanation

* **Service Type** (`service_type`, select_multiple, required/optional): This field allows you to select the services you require (e.g. 3D Printing, 3D Scanning, Laser Cutting).
* **Required Service** (`service_required`, select_one, required/optional): This field allows you to select one of the three services that you need.
* **Description** (`service_description`, text, required/optional): This field is used to provide a brief description of the service you need.
* **Contact Person** (`contact_person`, select_one, required/optional): If you need to contact the team about this request, select "Yes" here.
* **Contact Email** (`contact_email`, email, required/optional): If you selected "Yes" in the "Contact Person" field, provide your email address here.
* **Contact Phone** (`contact_phone`, text, required/optional): If you need to provide additional contact information, enter your phone number here.
* **Service Details** (`service_details`, text, required/optional): This field is used to provide any other details about the service you need.
* **Deadline** (`service_deadline`, date, required/optional): If you have a deadline for the service, select the date here.

Tips:

* Make sure to complete all required fields.
* Select "Yes" in the "Contact Person" field if you need to contact the team about this request.
* If you're unsure about any of the fields, please ask for clarification from the team.
