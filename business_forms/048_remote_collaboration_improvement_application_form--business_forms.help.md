# Remote Collaboration Improvement Application Form - Help Guide
## Purpose
This form is designed to collect information from users about their remote collaboration improvement needs and preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a category for your application (e.g., Business Forms, General Use Case, or Personal Use Case)
2. Enter a brief description of your needs and preferences
3. Choose the assigned tool you would like to use for remote collaboration (e.g., chatjimmy, chat frank, or chatjimmy2)
4. Upload the output file generated by this form (this will be a text file with your input data)

## Field-by-Field Explanation

* **Category (remote_collaboration_improvement_application_form)** (select_one, optional): Choose a category that best describes your application. This will help us to better understand the context of your collaboration needs.
* **Description (description)** (text, optional): Enter a brief description of your needs and preferences for remote collaboration. This can include things like, "I need to collaborate with colleagues from different departments" or "I need to work with external partners".
* **Assigned Tool (assigned_tool)** (select_one, optional): Select the tool you would like to use for remote collaboration. This can be chatjimmy, chat frank, or chatjimmy2.
* **Remote Collaboration Improvement Application Form Output File (remote_collaboration_improvement_application_form_output)** (text, optional): This is the output file generated by this form. You will need to upload this file to your submission, but you can edit it first to include any additional information you think is relevant.
