# Organizational Capability Enhancement Request Form - Help Guide
## Purpose
The Organizational Capability Enhancement Request Form is used to gather information from submitters about enhancements they would like to request for the organization.

## How To Complete This Form
1. Review the form carefully before submitting it to avoid duplication and ensure you are submitting all required information.
2. Fill out the form with accurate and relevant information about the enhancements you would like to request.
3. Submit the form for review and processing.

## Field-by-Field Explanation

* **main_form (Text)**: This field is the main description of your enhancement request. 
* **general_information (Text)**: Please enter general information about the form.
* **submitter (Text)**: Enter your name as the submitter of this request.
* **submitter_details (Text)**: Enter any additional details about yourself as the submitter.
* **submitter_email (Email)**: Enter your email address for contact purposes.
* **submitter_phone (Text)**: Enter your phone number for contact purposes.
* **process_improvement (Select Multiple)**: Indicate if this enhancement will improve a process.
* **tool_request (Select Multiple)**: Indicate if you are requesting a tool.
* **capability_improvement (Select Multiple)**: Indicate if this enhancement will improve a capability.
* **change_ideas (Note)**: Enter any additional information about the ideas behind this enhancement request.
* **review_date (Date)**: Enter the expected review date for this enhancement request.
* **review_time (Time)**: Enter the expected review time for this enhancement request.
* **priority (Select One)**: Indicate the priority of this enhancement request.
* **status (Select One)**: Indicate the status of this enhancement request.
* **created_by (Select One)**: Indicate if this enhancement request was created by you.
* **updated_by (Select One)**: Indicate if this enhancement request was updated by you.
* **created_at (Date)**: This field is for internal use and shows the creation date of this enhancement request.
* **updated_at (Date)**: This field is for internal use and shows the last update date of this enhancement request.
* **created_at_time (Time)**: This field is for internal use and shows the creation time of this enhancement request.
* **updated_at_time (Time)**: This field is for internal use and shows the last update time of this enhancement request.
* **created_by_team (Select One)**: Indicate if this enhancement request was created by your team.
* **updated_by_team (Select One)**: Indicate if this enhancement request was updated by your team.
* **created_at_date (Date)**: This field is for internal use and shows the creation date of this enhancement request.
* **created_at_time (Time)**: This field is for internal use and shows the creation time of this enhancement request.
* **submitted_by (Select One)**: Indicate if this enhancement request was submitted by you.
