# Weekly Retail Performance Report - Help Guide
## Purpose
The Weekly Retail Performance Report is a tool for retail managers to record and report on the performance of individual retail stores.

## How To Complete This Form

1. Fill out the form for each store on a weekly basis.
2. Enter the Week Ending Date at the top of the form.
3. Enter the Store ID and Store Name.
4. Report the number of sales and transactions for the week.
5. Indicate the current inventory status for each item.
6. Enter any notes or comments about the store's performance.
7. Fill out the employee information for the store, including the Manager's Email and Phone, and Assistant Manager or Store Owner.

## Field-by-Field Explanation

* **Week Ending Date (week_ending_date)**: Enter the last day of the week for which you are reporting sales data. This should be in the format of Month Day, Year.
* **Store ID (store_id)**: Enter the unique ID for this store.
* **Store Name (store_name)**: Enter a brief description of the store's name.
* **Sales Amount (sales_amount)**: Enter the total number of sales made during the week.
* **Transactions (transactions)**: Select from the options (0-10, 11-20, 21-30) that best describes the number of transactions made during the week.
* **Foot Traffic (foot_traffic)**: Enter a numeric value describing the number of customers that visited the store during the week.
* **Inventory Status (inventory_status)**: Select from the options (In Stock, Out of Stock, Backorder, Discontinued) that best describes the current status of the store's inventory.
* **Notes (notes)**: Enter any additional comments or notes about the store's performance.
* **Store Hours (store_hours)**: Enter the hours the store is open during the week.
* **Store Open (store_open)**: Enter the time the store opens.
* **Store Close (store_close)**: Enter the time the store closes.
* **Email (email)**: Enter the email address of the store's manager.
* **Phone (phone)**: Enter the phone number of the store's manager.
* **Manager Name (manager_name)**: Enter the name of the store's manager.
* **Manager Email (store_manager_email)**: Enter the email address of the store's manager.
* **Manager Phone (store_manager_phone)**: Enter the phone number of the store's manager.
* **Store Area (store_area)**: Enter a brief description of the store's location.
* **Region (region)**: Enter a brief description of the region where the store is located.
* **District (district)**: Enter a brief description of the district where the store is located.
* **Store Address (store_address)**: Enter the address of the store.
* **Store City (store_city)**: Enter the city where the store is located.
* **Store State (store_state)**: Enter the state where the store is located.
* **Store Zip (store_zip)**: Enter the zip code of the store's location.
* **Submitted By (submitted_by)**: Select from the options (Manager, Assistant Manager, Store Owner) that best describes who submitted the report.
