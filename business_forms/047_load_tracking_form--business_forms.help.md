# Load Tracking Form - Help Guide
## Purpose
This form is used to track shipments and loads for business operations.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the shipment id in the "shipment_id" field.
2. Choose the truck id by selecting one of the options provided.
3. Enter the weight of the load.
4. Add any additional notes about the load in the "notes" field.

## Field-by-Field Explanation
- **Load Tracking Form**:
	* Label: Load Tracking Form
	* Type: Text field
	* Description: This is the title of the form.
- **shipment_id**:
	* Label: shipment_id
	* Type: Select one option
	* Description: Choose one of the provided shipment id options.
- **truck_id**:
	* Label: truck_id
	* Type: Select one option
	* Description: Choose one of the provided truck id options.
- **weight**:
	* Label: weight
	* Type: Number
	* Description: Enter the weight of the load.
- **notes**:
	* Label: notes
	* Type: Text area
	* Description: Add any additional notes or comments about the load.
