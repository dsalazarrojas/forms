# pre_survey - Help Guide
## Purpose
The pre_survey form is designed to collect general information from users, including their name, contact details, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your First Name in the "First Name" field.
2. Enter your Last Name in the "Last Name" field.
3. Enter your Email address in the "Email" field.
4. Enter your phone number in the "Phone" field.
5. Select a valid Date (YYYY-MM-DD) in the "Date" field.
6. Enter a Time in the "Time" field.
7. Provide any additional Comments if necessary in the "Comments" field.
8. Select the Category from the options provided in the "Category" field.
9. Select one option from the list in the "Select One" field.
10. If applicable, select multiple options in the "Select Multiple" field.
11. Add a Note if necessary in the "Note" field.
12. Enter a valid Date and Time in the "Date/Time" field.
13. Enter a Decimal value in the "Decimal" field.
14. Enter an Integer value in the "Integer" field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter your given name.
* **Last Name** (`last_name`, text, required): Enter your surname.
* **Email** (`email`, email, required): Enter a valid email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Date** (`date`, date, optional): Select a date in the format YYYY-MM-DD.
* **Time** (`time`, time, optional): Select a time.
* **Comments** (`comment`, text, optional): Provide any additional comments if necessary.
* **Category** (`category`, select_one, required): Select a category from the options provided.
* **Select One** (`select_one`, select_one, optional): Select one option from the list.
* **Select Multiple** (`select_multiple`, select_multiple, optional): Select multiple options from the list.
* **Note** (`note`, note, optional): Add a note if necessary.
* **Date/Time** (`date_time`, text, optional): Enter a date and time.
* **Decimal** (`decimal`, number, optional): Enter a decimal value.
* **Integer** (`integer`, number, optional): Enter an integer value.
