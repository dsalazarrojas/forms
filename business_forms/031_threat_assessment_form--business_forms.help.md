# Threat Assessment Form - Help Guide
## Purpose
This form is for threat assessment. It is used to gather information about potential risks to the organization, and to document and track threat assessments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of threat from the threat options.
2. Choose the level of the threat on a scale of 0-10.
3. Describe the threat in the risk description field.
4. Choose the type of risk from the risk type options.
5. Select the prevention strategies for the risk.
6. Select the response strategy for the risk.
7. Enter the recommended risk level for the risk.
8. Enter any additional comments about the risk.
9. Enter the next steps to take on the risk.
10. Enter the date and time you would like to follow up on the risk.
11. Enter the name of the person who reviewed the risk.
12. Enter the date and time the risk was reviewed.
13. Enter any comments made during the review.
14. Select the status of the risk.
15. Enter any additional notes about the risk.
16. Upload any attachments related to the risk.
17. Enter any comments about the attachments.
18. Enter the date and time of the risk recommendation.
19. Enter any comments about the risk recommendation.

## Field-by-Field Explanation

* **Threat Assessment**: This is the main field for selecting the threat being assessed.
	+ Type: Select multiple values.
	+ Options: Option 1, Option 2, Option 3.
* **Risk Type**: This is the field for selecting the type of risk.
	+ Type: Select one value.
	+ Options: Risk 1, Risk 2, Risk 3.
* **Risk Level**: This is the field for entering the level of the risk on a scale of 0-10.
	+ Type: Number.
	+ Hint: 0-10.
* **Threat Level**: This is the field for entering the threat level on a scale of 0.0-10.0.
	+ Type: Number.
	+ Hint: 0.0-10.0.
* **Risk Description**: This is the field for describing the risk.
	+ Type: Note.
	+ Hint: None.
* **Risk Justification**: This is the field for entering any justification for the risk.
	+ Type: Text.
	+ Hint: None.
* **Risk Prevention**: This is the field for selecting the prevention strategy.
	+ Type: Select multiple values.
	+ Options: Prevention 1, Prevention 2, Prevention 3.
* **Risk Response**: This is the field for selecting the response strategy.
	+ Type: Select one value.
	+ Options: Response 1, Response 2, Response 3.
* **Risk Recommendation**: This is the field for entering any recommended risk level.
	+ Type: Text.
	+ Hint: None.
* **Risk Status**: This is the field for selecting the status of the risk.
	+ Type: Select one value.
	+ Options: Status 1, Status 2, Status 3.
* **Risk Comments**: This is the field for entering any comments about the risk.
	+ Type: Text.
	+ Hint: None.
* **Next Steps**: This is the field for entering the next steps to take on the risk.
	+ Type: Select multiple values.
	+ Options: Step 1, Step 2, Step 3.
* **Follow-up**: This is the field for entering the date and time to follow up on the risk.
	+ Type: Date.
	+ Hint: None.
* **Follow-up Time**: This is the field for entering the time to follow up on the risk.
	+ Type: Time.
	+ Hint: None.
* **Reviewed By**: This is the field for entering the name of the person who reviewed the risk.
	+ Type: Text.
	+ Hint: None.
* **Reviewed Date**: This is the field for entering the date the risk was reviewed.
	+ Type: Date.
	+ Hint: None.
* **Reviewed Time**: This is the field for entering the time the risk was reviewed.
	+ Type: Time.
	+ Hint: None.
* **Closed**: This is the field for selecting the status of the risk.
	+ Type: Select one value.
	+ Options: Closed 1, Closed 2, Closed 3.
* **Risk Notes**: This is the field for entering any notes about the risk.
	+ Type: Text.

* **Risk Attachments**: This is the field for uploading any attachments related to the risk.
	+ Type: Text.

* **Risk Attachment Comments**: This is the field for entering any comments about the attachments.
	+ Type: Text.

* **Risk Recommendation Date**: This is the field for entering the date and time of the risk recommendation.
	+ Type: Date.
	+ Hint: None.
