# Finance Task Assignment Form - Help Guide
## Purpose

The Finance Task Assignment Form is used to create and manage tasks assigned to team members. This form will help finance teams track and prioritize tasks efficiently.

## How To Complete This Form

1. Fill out each page completely and accurately.
2. Make sure all required fields are completed.
3. Review each field carefully to ensure you're providing the correct information.

## Field-by-Field Explanation

* **Task Name (1)** (`task_name`, text, required: false): Enter the name of the task, a brief description of what needs to be done.
* **Priority (2)** (`priority`, number, required: false): Set the priority level of the task, where 1 is the highest and 5 is the lowest.
* **Deadline (3)** (`deadline`, date, required: false): Enter the deadline for the task completion.
* **Team Lead (4)** (`team_lead`, select_multiple, required: false): Check if this task is related to a team lead. 
* **Task Type (5)** (`task_type`, select_one, required: false): Choose if the task type is 'Yes' or 'No'. The exact meaning of this field might not be immediately obvious.
* **Task Status (6)** (`task_status`, select_multiple, required: false): Select either Active or Inactive to indicate the status of the task.
* **Assigned To (7)** (`assigned_to`, select_multiple, required: false): Select team members or users to whom the task should be assigned.
* **Due Date (8)** (`due_date`, date, required: false): Enter the actual due date for the task.
* **Task Description (9)** (`task_description`, text, required: false): Enter a detailed description of the task.
* **Assigned To Name (10)** (`assigned_to_name`, text, required: false): Enter the name of the team member assigned to the task.
* **Assigned To Email (11)** (`assigned_to_email`, email, required: false): Enter the email of the team member assigned to the task.
* **Assigned To Phone (12)** (`assigned_to_phone`, text, required: false): Enter the phone number of the team member assigned to the task.
* **Task Priority (13)** (`task_priority`, number, required: false): Set the priority level of the task, where 1 is the highest and 5 is the lowest.
* **Created By (14)** (`created_by`, select_one, required: false): Check if this task was created by you. 

Note: Some fields may have limited options, but all fields are crucial for proper task management. If you're unsure about any field, please ask for clarification before proceeding.
