# RFP Intake Form - Help Guide

## Purpose
The RFP Intake Form is used to collect information about project opportunities and requirements. This form helps to ensure that all relevant project details are captured and communicated efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by filling out the form fields as instructed below.

## Field-by-Field Explanation

* **General Review** (`rfp_bid_no_bid_general_review`, text, required: false): Please provide a brief general review of the project opportunity.
* **Contact Person** (`contact_person`, text, required: false): Enter the name of the contact person responsible for this project opportunity.
* **Contact Phone Number** (`contact_phone_number`, text, required: false): Enter the phone number of the contact person responsible for this project opportunity.
* **RFP Number** (`rfp_number`, number, required: false): Enter the RFP number, if applicable.
* **Project Name** (`project_name`, text, required: false): Enter the name of the project opportunity.
* **Project Description** (`project_description`, text, required: false): Describe the project opportunity in brief.
* **Bid or No Bid** (`bid_or_no_bid`, select_one, required: false):
	+ **No Bid**: Select this option if the project does not require a bid.
	+ **Bid**: Select this option if the project requires a bid.
* **Review Type** (`review_type`, select_one, required: false):
	+ **Review**: Select this option for a review only.
	+ **Bid and Review**: Select this option for both bid and review.
* **Submit Date** (`submit_date`, date, required: false): Enter the date when the project opportunity is submitted.

## Tips
- Please ensure that you're filling out the form with accurate and up-to-date information.
- If you're unsure about any field, please consult with your supervisor or the project sponsor.
- If you have any questions or need help with this form, please reach out to the relevant stakeholders.
