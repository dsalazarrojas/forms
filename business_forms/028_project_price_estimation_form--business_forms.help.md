# project_price_estimation_form - Help Guide
## Purpose
The project_price_estimation_form is a form used for estimating prices for projects. This form helps users provide detailed information about a project, including its budget, scope, duration, price, location, and type.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the Project Details field with a brief description of the project.
2. Enter the Project Budget in the specified format (e.g., 1000.00).
3. Describe the Project Scope, including its objectives and key deliverables.
4. Enter the Project Duration in the specified format (e.g., 1 month, 2 years, etc.).
5. Enter the Project Price, which should be a number.
6. Select the Project Location from the list of options.
7. Select the Project Type from the list of options.

## Field-by-Field Explanation
- **Project Details (Text, Optional)**: Enter a brief description of the project, including its objectives and key deliverables.
- **Project Budget (Number, Optional)**: Enter the budget for the project in the specified format.
- **Project Scope (Text, Optional)**: Describe the project scope, including its objectives and key deliverables.
- **Project Duration (Time, Optional)**: Enter the project duration in the specified format (e.g., 1 month, 2 years, etc.).
- **Project Price (Number, Optional)**: Enter the project price.
- **Project Location (Select One, Optional)**: Select the location of the project from the list of options.
- **Project Type (Select Multiple, Optional)**: Select the project type from the list of options.
