# Contact Form With Upload Function - Help Guide

## Purpose
This form is designed for clients to submit their requests for professional services such as graphic design, copywriting, web development, and consultation. It allows clients to provide their contact information, project details, and preferences for communication.

## How To Complete This Form

1. Click on the "Submit" button to begin the form.
2. Fill out the required fields marked with an asterisk (\*).
3. Choose the service requested from the dropdown menu.
4. Provide a brief description of the project.
5. Indicate whether you have a project brief ready to upload.
6. Select a preferred method of communication.
7. (Optional) Provide a budget estimate and an estimated deadline.
8. Click on the "Submit" button to send your inquiry to us.

## Field-by-Field Explanation

### 1. <a name="service_header" >Online Services Request</a>
* This field is not a form input but a heading that introduces the purpose of the form.

### 2. <a name="client_name" >Your Name</a>
* A text input field where you can enter your name to associate with your inquiry.

### 3. <a name="client_email" >Your Email</a>
* A text input field to enter your email address, which will be used for communication.
* Ensure to enter a valid email address to enable us to contact you.

### 4. <a name="service_type" >Service Requested</a>
* A dropdown menu where you can select the type of service you require:
	+ Graphic Design
	+ Copywriting
	+ Web Development
	+ Consultation

### 5. <a name="project_description" >Project Description</a>
* A text input field where you can enter a brief description of your project.

### 6. <a name="file_upload_ready" >Do you have a project brief to upload?</a>
* A dropdown menu to indicate whether you have a project brief ready to upload.
	+ 'True'
	+ 'False'

### 7. <a name="estimated_deadline" >Requested Deadline</a>
* A date input field to enter an estimated deadline for the project.
* Note: This field is optional.

### 8. <a name="project_budget_limit" >Budget Estimate</a>
* A number input field for an estimated budget for your project.
* Note: This field is optional.

### 9. <a name="preferred_communication" >Preferred Communication</a>
* A dropdown menu to select your preferred method of communication:
	+ Email
	+ Slack
	+ Phone
	+ Video Call

### 10. <a name="referral_info" >How did you find us?</a>
* A text input field for any additional information on how you found our services.
* Note: This field is optional.
