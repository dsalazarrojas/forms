# Business Intelligence Enhancement Request Form - Help Guide
## Purpose
This form is used to collect detailed information about business intelligence enhancements requested by team members, allowing for proper documentation, review, and prioritization before implementation.

## How To Complete This Form
To complete this form, please follow the instructions below.

1. Start by identifying yourself as the requestor.
2. Provide your name as requested by your department.
3. Specify which department you belong to.
4. Choose the BI tool to be enhanced.
5. Determine the type of enhancement needed.
6. Indicate the priority of the enhancement.
7. Provide a detailed description of your request.
8. Estimate the expected business value or benefit from the enhancement.
9. If applicable, share a sample data or mockup link.
10. Confirm the completion date and submission date.
11. Confirm if this request has been approved by your department manager.

## Field-by-Field Explanation
### 1. **Requestor Name** (bi_requestor_full_name)
* Label: Requestor Name
* Type: text
* Required: True
* Explanation: This field is used to capture the name of the person submitting the request. Please enter your name as requested by your department.

### 2. **Department** (bi_requestor_department)
* Label: Department
* Type: text
* Required: True
* Explanation: This field is used to specify which department the requestor belongs to. Enter the department name as e.g., Finance, Sales, or Operations.

### 3. **BI Tool to be Enhanced** (target_bi_tool_selection)
* Label: BI Tool to be Enhanced
* Type: select_one
* Required: True
* Explanation: This field is used to choose which Business Intelligence tool you want to enhance. Select from the options: Power BI, Tableau, Looker, Google Data Studio, or Internal Custom Dashboard.

### 4. **Enhancement Type** (enhancement_category_type)
* Label: Enhancement Type
* Type: select_one
* Required: True
* Explanation: This field is used to determine the type of enhancement needed. Choose from the options: New Report/Dashboard Development, Modification of Existing Report, Data Model Change / New Data Source, Performance Optimization, or Security / Access Level Change.

### 5. **Priority** (bi_enhancement_priority_level)
* Label: Priority
* Type: select_one
* Required: True
* Explanation: This field is used to indicate the priority of the enhancement, relative to other business needs. Choose from the options: Critical (System down / Blocking revenue), High (Significant business impact), Medium (Standard improvement), or Low (Nice-to-have / Aesthetic).

### 6. **Description of Request** (request_detailed_description)
* Label: Description of Request
* Type: text
* Required: True
* Explanation: This field is used to provide a detailed description of your request, including fields, filters, and logic changes. Be specific and clear in your description.

### 7. **Expected Business Value or Benefit** (expected_business_value_benefit)
* Label: Expected Business Value or Benefit
* Type: text
* Required: True
* Explanation: This field is used to estimate the expected business value or benefit from the enhancement. Provide an example as e.g., saves 5 hours/week, improves accuracy by 10%.

### 8. **Sample Data or Mockup Link** (sample_data_mockup_url)
* Label: Sample Data or Mockup Link
* Type: text
* Required: False
* Explanation: This field is used to share a link to a sample data or mockup, if available.

### 9. **Required Completion Date** (required_enhancement_completion_date)
* Label: Required Completion Date
* Type: date
* Required: True
* Explanation: This field is used to set a required completion date for the enhancement.

### 10. **Date of Request** (request_submission_date_bi)
* Label: Date of Request
* Type: date
* Required: True
* Explanation: This field is used to record the date the request was submitted.

### 11. **Has this request been approved by your department manager?** (manager_approval_confirmed_check)
* Label: Has this request been approved by your department manager
* Type: select_one
* Required: True
* Explanation: This field is used to confirm if the request has been approved by your department manager.
Note: If not approved, this may impact resource allocation and further processing.
