# Supplier Benchmarking Program Application Form - Help Guide
## Purpose
The Supplier Benchmarking Program Application Form is a tool used to collect and evaluate data on supplier performance, ratings, and characteristics.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter your supplier's name in the "Supplier Name" field.
2. Provide your supplier's email address in the "Supplier Email" field.
3. Enter your supplier's address in the "Supplier Address" field.
4. Enter your supplier's contact number in the "Contact Number" field.
5. Rate your supplier's performance in each of the 12 fields using the options provided.
6. Choose the category and supplier type of your supplier.
7. Select the supplier's status (Active, Inactive, or Pending).
8. Optionally, add any notes about your supplier.
9. Set the review date and time of your supplier.
10. Set the last update date and time of your supplier.

## Field-by-Field Explanation
- **Supplier Name**: Enter the name of the supplier you are submitting.
	+ Type: text
	+ Required: No
- **Supplier Email**: Enter the email address of the supplier.
	+ Type: email
	+ Required: No
- **Supplier Address**: Enter the address of the supplier.
	+ Type: text
	+ Required: No
- **Contact Number**: Enter the contact number of the supplier.
	+ Type: text
	+ Required: No
- **Supplier Rating 1-12**: Rate the supplier's performance in each of the 12 fields using the options provided (High, Low, Medium).
	+ Type: select_one
	+ Required: No
- **Category**: Choose the category of the supplier.
	+ Type: select_one
	+ Required: No
- **Supplier Type**: Choose the type of the supplier.
	+ Type: select_one
	+ Required: No
- **Supplier Status**: Select the status of the supplier (Active, Inactive, Pending).
	+ Type: select_one
	+ Required: No
- **Notes**: Optionally, add any notes about your supplier.
	+ Type: note
	+ Required: No
- **Review Date**: Set the review date of your supplier.
	+ Type: date
	+ Required: No
- **Review Time**: Set the review time of your supplier.
	+ Type: time
	+ Required: No
- **Last Update Date**: Set the last update date of your supplier.
	+ Type: date
	+ Required: No
- **Last Update Time**: Set the last update time of your supplier.
	+ Type: time
	+ Required: No

Note: This form is designed to collect multiple ratings for each supplier, and you will be asked to rate your supplier 12 times. Please make sure to rate your supplier honestly and accurately in each field.
