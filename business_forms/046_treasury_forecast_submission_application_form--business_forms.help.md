# Treasury Forecast Submission Application Form - Help Guide
## Purpose
The Treasury Forecast Submission Application Form is a tool used to collect and manage Treasury submissions within the organization. It is an essential part of the forecasting process, allowing financial analysts to analyze and predict cash inflows and outflows for the company.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the submission date for the forecast.
2. Indicate whether the submission entity is 'Yes' or 'No' to determine the scope of the submission.
3. Enter the Entity ID, which is a unique identifier for the entity being forecasted.
4. Provide the Department Name and Department ID, which are essential details for the submission.
5. Choose the type of submission, whether it is an Inflow, Outflow, or Both.
6. Enter the expected Cash Inflow and Cash Outflow for the submission.
7. Select the submission status, which can be Draft, Submitted, Approved, or Rejected.
8. Add any relevant Comments about the submission.

## Field-by-Field Explanation
* **Submission Date** (`submission_date`, date, required: false): This field is used to record the date the submission was made.
* **Submission Entity** (`submission_entity`, select_multiple, required: false): This field allows you to specify whether the submission applies to a yes or no scope.
* **Entity ID** (`entity_id`, number, required: false): This field is used to uniquely identify the entity being forecasted.
* **Department Name** (`department_name`, text, required: false): This field allows you to provide the name of the department associated with the submission.
* **Department ID** (`department_id`, number, required: false): This field is used to provide the ID of the department associated with the submission.
* **Submission Type** (`submission_type`, select_one, required: false): This field allows you to choose the type of submission, whether it is Inflow, Outflow, or Both.
* **Cash Inflow** (`cash_inflow`, number, required: false): This field is used to enter the expected cash inflow for the submission.
* **Cash Outflow** (`cash_outflow`, number, required: false): This field is used to enter the expected cash outflow for the submission.
* **Submission Status** (`submission_status`, select_one, required: false): This field allows you to select the status of the submission, whether it is Draft, Submitted, Approved, or Rejected.
* **Comments** (`comments`, note, required: false): This field provides a space for any additional comments about the submission.

## Tips
* Please ensure that all required fields are filled in accurately to avoid any issues with the submission.
* Double-check the submission date and status to prevent any confusion.
* Use the correct submission type to ensure accurate forecasting and analysis.
* Comments can be used to provide further context or explanation about the submission, which may be helpful for reviewers or analysts.
