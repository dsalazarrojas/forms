# Outdoor Service Quote Request - Help Guide
## Purpose
This form is designed to gather information from clients or customers who are interested in requesting a quote for outdoor services. The form will be used to collect project details, contact information, and service provider specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of your project and any relevant details.
2. Enter your name and contact information, so we can get in touch with you.
3. Select the project start and end dates.
4. Choose the location where the outdoor service will take place.
5. Describe the project scope and what work is required.
6. Select the type of service you need.
7. Choose the service provider or providers you would like to consider.
8. If none of the listed service providers are applicable, enter your own service provider.
9. Enter the contact person's name and phone number.

## Field-by-Field Explanation
* **Project Details** (`project_details`): A brief description of your project, including any relevant details.
* **Client Name** (`client_name`): Your name and contact information, so we can get in touch with you.
* **Project Start Date** (`project_start_date`): The date you plan to start the project. 
* **Project End Date** (`project_end_date`): The date you plan to complete the project.
* **Project Location** (`project_location`): The location where the outdoor service will take place.
* **Project Scope** (`project_scope`): A description of the project's scope, including what work is required.
* **Project Type** (`project_type`):
	+ Select from the options to choose the correct project type.
	+ If none of the options fit, enter "Other" and describe the project type in the "Project Type Other" field.
* **Service Provider** (`service_provider`):
	+ Select from the options to choose the service provider.
	+ If none of the listed service providers are applicable, enter "Other" and describe the service provider.
* **Contact Person** (`contact_person`): The name and phone number of the contact person.
* **Phone** (`phone`): The phone number of the contact person.

## Tips
- Please fill out this form as thoroughly and accurately as possible to ensure we have the necessary information to provide you with a proper quote.
- If you have any questions or need clarification on any field, feel free to contact us.
- We'll get back to you as soon as possible with the quote request.
