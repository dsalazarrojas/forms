# Event Inventory Request Form - Help Guide

## Purpose
The Event Inventory Request Form is a tool used to collect essential information about an event, enabling the team to better manage and plan the inventory for the requested period.

## How To Complete This Form
To fill out the Event Inventory Request Form, follow these steps:

1. Enter the Event Date in the format `mm/dd/yyyy` or the date of the event.
2. Select the Event Time for the event.
3. Provide the Venue where the event will take place.
4. Choose the Event Type from the available options.
5. Select the Organizer of the event from the list of options.
6. Enter the Organizer's email address.
7. If applicable, enter the Organizer's phone number.
8. Enter a brief description of the event details.

## Field-by-Field Explanation
- **Event Date** (`event_date`, date, required: false): Enter the date of the event in the format `mm/dd/yyyy`.
- **Event Time** (`event_time`, time, required: false): Select the time of the event.
- **Venue** (`venue`, text, required: false): Provide the location of the event.
- **Event Type** (`event_type`, select_one, required: false): Choose the type of event from the available options: Option 1, Option 2, or Option 3.
- **Organizer** (`organizer`, select_one, required: false): Select the person or organization responsible for the event from the list of options.
- **Organizer Email** (`organizers_email`, email, required: false): Enter the email address of the person or organization hosting the event.
- **Organizer Phone** (`organizers_phone`, text, required: false): If applicable, enter the phone number of the organizer.
- **Event Details** (`event_details`, text, required: false): A brief description of the event, such as its purpose, description, or any other relevant details.

## Tips
* Double-check the event date and time for accuracy to ensure correct scheduling and inventory management.
* Verify that the organizer's email address is current and active.
* Enter a clear and concise event description to provide a comprehensive understanding of the event.
* Ensure the event type aligns with the organization's classification system.
* Use the event details section to add any relevant additional information about the event.

Note: Please review your answers for accuracy and ensure they align with your actual event needs.
