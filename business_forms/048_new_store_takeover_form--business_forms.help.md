# new_store_takeover_form - Help Guide
## Purpose
This form is used to document store takeovers and transfers between owners.

## How To Complete This Form
- Please ensure that all required fields are completed accurately and thoroughly.
- Refer to the "Field-by-Field Explanation" section below for specific guidance on each field.

## Field-by-Field Explanation
* **Store Name** (store_name): Enter the name of the store.
* **New Owner Details** (new_owner_details): Select "Yes" to indicate that this store will be transferred to a new owner. This field is required.
* **New Owner Address** (new_owner_address): Enter the address of the new store owner.
* **New Owner Phone** (new_owner_phone): Enter the phone number of the new store owner. (Note: This field is not required, but it's recommended for communication purposes.)
* **New Owner Email** (new_owner_email): Enter the email address of the new store owner. This field is required.
* **Reason for Transfer** (reason_for_transfer): Enter a brief explanation for the store takeover. This field is required.
* **Owner Details** (owner_details): Select "Yes" to indicate that this store is currently owned by someone. This field is required.
* **New Owner Information** (new_owner_info): Select "Yes" to indicate that the new owner has provided accurate and complete information. This field is required.
