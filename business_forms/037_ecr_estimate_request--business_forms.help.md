# Ecr Estimate Request - Help Guide
## Purpose
The Ecr Estimate Request form is used to collect estimated costs or consumption values for a specific period. Please provide the necessary information to help us generate accurate ECR reports.

## How To Complete This Form
1. Select the Ecr Request Form page.
2. Fill in the required and optional fields as needed.
3. Submit the form.

## Field-by-Field Explanation

* **Ecr Request Form** (Text, Optional): This is the main form section where you can enter any relevant information related to your ECR request.
* **Estimated Date** (Date, Optional): Please enter the estimated date for which you are submitting this request. This will help us associate your request with the correct time period.
* **Start Time** (Time, Optional): If applicable, please enter the start time for which you are submitting this request. This will help us narrow down the time frame.
* **Estimated Value** (Number, Optional): Enter the estimated value for the consumption or cost you are requesting to report.
* **Ecr Number** (Number, Optional): Enter the ECR number, which is a unique identifier for your request.
* **Ecr Status** (Select One, Optional): Select the status of your ECR request: Active, Inactive, or Unknown.
* **Ecr Priority** (Select Multiple, Optional): Select the priority level of your ECR request: Low, Medium, or High.
* **Ecr Priority 2** (Select Multiple, Optional): Select the secondary priority level of your ECR request: Lowest, Medium.

## Tips
* Please make sure to fill in all required fields to ensure accurate ECR report generation.
* If you have any further questions or concerns, please contact your supervisor or administrator.
* This form is intended to be used for estimated consumption reports, so please ensure that the information provided is accurate and reliable.
