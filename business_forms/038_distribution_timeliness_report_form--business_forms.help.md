# Distribution Timeliness Report Form - Help Guide
## Purpose
This form is used to report on the timeliness of deliveries, allowing you to track and update the status of your deliveries.

## How To Complete This Form
To complete this form, follow these steps:
1. Select all applicable options for each field as needed.
2. Enter the requested information in the specified format.
3. Review your entries for accuracy and completeness.
4. Submit the form once complete.

## Field-by-Field Explanation

* **Delivery Performance** (`delivery_performance`):
  This field indicates if the delivery was made in a timely manner. Select "Yes" if the delivery was made on time, "No" otherwise.
* **Delay Reasons** (`delay_reasons`):
  This field allows you to select one reason for the delay if applicable. Choose "Yes" if the delivery was delayed due to one of the listed reasons.
* **Delay Date** (`delay_date`):
  Enter the date on which the delivery was delayed. If not applicable, leave blank.
* **Delay Time** (`delay_time`):
  Enter the time of day when the delivery was delayed. If not applicable, leave blank.
* **Delivery Location** (`delivery_location`):
  Select the location where the delivery was made. If not applicable, leave blank.
* **Reporting Period** (`reporting_period`):
  This field indicates if the delivery is within the current reporting period. Select "Yes" if it applies, "No" otherwise.
* **Delay Days** (`delay_days`):
  Enter the number of days by which the delivery was delayed. If not applicable, leave blank.
* **Distribution Channel** (`distribution_channel`):
  Select the channel through which the delivery was made. If not applicable, leave blank.
