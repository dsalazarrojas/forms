# production_yield_data_request_form - Help Guide
## Purpose
This form is used to collect data related to production yield, performance metrics, and contact information from users.
## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the **Production Data Request** field with a brief description of the production data you want to request.
2. Input your **Production Yield Rate** in the **Production Yield Rate** field.
3. Select one or more **Production Performance Metrics** from the list:
	* Yield Rate
	* Scrap Rate
	* Defect Rate
4. Enter the **Production Date** when the production took place.
5. Input the **Production Time** when the production took place.
6. Add any additional **Production Notes** that might be relevant to the production.
7. Optionally, add your **Email Addresses** if you want to get updates on the production data.
8. Optionally, add your **Phone Numbers** if you want to be contacted for further information.

## Field-by-Field Explanation
- **Production Data Request**: A brief description of the production data you want to request. 
- **Production Yield Rate**: The rate of production yield, usually expressed as a percentage.
- **Production Performance Metrics**: Select one or more performance metrics that you would like to report for this production. 
	+ Yield Rate: The rate at which the production yielded the desired product or service.
	+ Scrap Rate: The rate of waste or defective product during the production process.
	+ Defect Rate: The rate of defect in the production process.
- **Production Date**: The date when the production took place.
- **Production Time**: The time when the production took place.
- **Production Notes**: Any additional information that might be relevant to the production.
- **Email Addresses**: Your email addresses where you can be contacted for further information.
- **Phone Numbers**: Your phone numbers where you can be contacted for further information.

## Tips
- Please ensure that all fields are accurate and complete before submitting the form.
- If you select multiple options in the performance metrics field, all selected options will be recorded.
- If you have any further questions or concerns, please don't hesitate to contact us.
- Please note that all fields are optional except for the email addresses field which is recommended but not required.
