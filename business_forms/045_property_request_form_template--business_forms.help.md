# Property Request Form Template - Help Guide

## Purpose
This form is used to collect detailed information from clients for property requests. It includes a series of fields that cover user details, property specifics, and follow-up information.

## How To Complete This Form
1. Start by filling in your User Name, Email, and Contact Number.
2. Select the appropriate Property Type and Location for the property request.
3. Choose the Requested Features, Preferred Agent, Preferred Contact, and Preferred Method.
4. Select the Property Status and fill in any Additional Request or Property Details.
5. Choose the Follow Up Method and select the Follow Up Contact.
6. Enter any Agent Comments and Next Steps.
7. Fill in the Follow Up Date and Time.
8. Select the Follow Up Comments.

## Field-by-Field Explanation
* **User Name** (`user_name`, `text`, required): Enter your name as the user making the property request.
* **Email** (`email`, `email`, required): Enter your email address for communication purposes.
* **Contact Number** (`contact_number`, `text`, required): Enter your contact number for follow-up purposes.
* **Address** (`address`, `text`, optional): Enter the address related to the property request.
* **Preferred Date** (`preferred_date`, `date`, optional): Select the date you prefer for the follow-up.
* **Property Details** (`property_details`, `text`, optional): Enter any additional information about the property request.
* **Additional Request** (`additional_request`, `note`, optional): Enter any additional requests or information about the property.
* **Property Type** (`property_type`, `select_one`, required): Select the type of property you are requesting (e.g., residential, commercial, etc.).
* **Property Location** (`property_location`, `select_multiple`, required): Select the location of the property (e.g., city, state, etc.).
* **Requested Features** (`requested_features`, `select_multiple`, required): Select the features you are requesting for the property.
* **Preferred Agent** (`preferred_agent`, `select_one`, required): Select the preferred agent handling your request.
* **Preferred Contact** (`preferred_contact`, `select_multiple`, required): Select the preferred contact method (e.g., phone, email, etc.).
* **Preferred Method** (`preferred_method`, `select_multiple`, required): Select the preferred follow-up method (e.g., email, phone, etc.).
* **Property Status** (`property_status`, `select_one`, required): Select the current status of the property.
* **Agent Note** (`agent_note`, `note`, optional): Enter any comments or notes from the agent handling your request.
* **Client Request ID** (`client_request_id`, `text`, optional): Enter any client request ID related to the property request.
* **Agent Comments** (`agent_comments`, `text`, optional): Enter any comments or notes from the agent handling your request.
* **Follow Up Date** (`follow_up_date`, `date`, optional): Select the date for the follow-up.
* **Follow Up Time** (`follow_up_time`, `time`, optional): Select the time for the follow-up.
* **Follow Up Method** (`follow_up_method`, `select_one`, optional): Select the method for the follow-up (e.g., phone, email, etc.).
* **Follow Up Contact** (`follow_up_contact`, `select_multiple`, optional): Select the contact method for the follow-up (e.g., phone, email, etc.).
* **Next Steps** (`next_steps`, `text`, optional): Enter any next steps or actions for the property request.
* **Follow Up Comments** (`follow_up_comments`, `text`, optional): Enter any comments or notes for the follow-up.
* **Property Type 2** (`property_type_2`, `select_multiple`, optional): Select the second type of property (if applicable).
* **Property Type 3** (`property_type_3`, `select_multiple`, optional): Select the third type of property (if applicable).
