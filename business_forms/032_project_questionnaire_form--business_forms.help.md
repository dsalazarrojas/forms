# Project Questionnaire Form - Help Guide

## Purpose
The Project Questionnaire Form is used to manage project questionnaire templates by collecting and updating their information.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the template type: Choose between Single Template or Multiple Templates.
2. Enter a brief description of the template.
3. Choose the status of the template: Select whether it is Active or Inactive.
4. Enter any comments about the template status (optional).
5. Select the date the template was last updated (optional).

## Field-by-Field Explanation

* **Project Questionnaire Template** (`project_questionnaire_template`, text, required): This field allows you to enter a brief description of the template.
* **Project Questionnaire Template Type** (`project_questionnaire_template_type`, select_one, required): Choose between Single Template or Multiple Templates.
* **Project Questionnaire Template Status** (`project_questionnaire_template_status`, select_one, required): Select whether the template is Active or Inactive.
* **Project Questionnaire Template Status Comments** (`project_questionnaire_template_status_comments`, text, optional): Enter any comments about the template status.
* **Project Questionnaire Template Last Updated** (`project_questionnaire_template_last_updated`, date, optional): Select the date the template was last updated.

## Tips
- Make sure to select the correct template type and status to accurately reflect the template's status.
- Enter a brief description of the template to help identify it easily.
- Use the "Project Questionnaire Template Last Updated" field to keep track of the template's updates.
