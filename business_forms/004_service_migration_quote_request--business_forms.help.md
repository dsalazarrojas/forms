# Service Migration Quote Request - Help Guide
## Purpose
The Service Migration Quote Request form is designed to collect relevant information from customers interested in migrating their IT infrastructure. This form helps the sales and technical teams to generate accurate quotes for the migration process.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your customer's name and contact information (phone and email).
2. Enter a brief description of the service you are requesting.
3. Select the type of service you are interested in (e.g., Yes or No).
4. Choose the type of migration you require (e.g., multiple options for this field).
5. If applicable, enter the server model details, current server capacity, and new server capacity.
6. Select the availability date for the service.
7. Choose the start and end dates for the service duration.
8. Specify the service duration in time.
9. If applicable, select the frequency of service (e.g., Yes or No).
10. Select the frequency of migration (e.g., multiple options).
10. Provide any additional comments or notes about your service request.

## Field-by-Field Explanation

* **Customer Name** (Customer Name, Text, Required): Enter your name as the customer representative.
* **Customer Phone** (Customer Phone, Text, Required): Enter your phone number for the customer.
* **Customer Email** (Customer Email, Email, Required): Enter your email address as the customer representative.
* **Description** (Description, Text, Required): Briefly describe the service you are requesting.
* **Service Type** (Service Type, Select One, Required): Select the type of service you are interested in (e.g., Yes or No).
* **Migration Type** (Migration Type, Select Multiple, Optional): Select the type of migration you require (e.g., multiple options).
* **Server Model** (Server Model, Text, Optional): If applicable, enter the server model details.
* **Current Server Capacity** (Current Server Capacity, Text, Optional): If applicable, enter the current server capacity.
* **New Server Capacity** (New Server Capacity, Text, Optional): If applicable, enter the new server capacity.
* **Server Model Details** (Server Model Details, Text, Optional): If applicable, provide additional details about the server model.
* **Service Availability Date** (Service Availability Date, Date, Required): Choose the date when the service is available.
* **Service Start Date** (Service Start Date, Date, Required): Choose the start date of the service duration.
* **Service End Date** (Service End Date, Date, Required): Choose the end date of the service duration.
* **Service Duration** (Service Duration, Time, Required): Specify the duration of the service in time.
* **Service Frequency** (Service Frequency, Select One, Optional): Select the frequency of the service (e.g., Yes or No).
* **Migration Frequency** (Migration Frequency, Select Multiple, Optional): Select the frequency of migration (e.g., multiple options).
* **Client Comments** (Client Comments, Note, Optional): Provide any additional comments or notes about your service request.
