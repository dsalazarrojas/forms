# Financial Dashboard Permission Application Form - Help Guide
## Purpose
The Financial Dashboard Permission Application Form is used to grant permission to access the Financial Dashboard, allowing users to view and interact with financial data. The form is designed to ensure that only authorized personnel have access to sensitive financial information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **User Details** (page 1). This is where you will enter your basic contact information.
2. Choose your **Financial Dashboard Access** (page 1). Select either **Full Access** or **Read-Only Access** to determine your level of permission.
3. Provide a brief explanation for your **Financial Dashboard Access Notes** (page 1).
4. Select your department from the list of **Department** options (page 2). This is where you will determine which data you will have access to.
5. Enter your **Date** (page 2) when you would like to start using the Financial Dashboard.
6. Choose a time for your **Time** (page 2) when you would like to start using the Financial Dashboard.
7. Enter your **Email** (page 3) so that we can contact you with updates.
8. Fill in your **Phone** (page 3) number so that we can contact you with important updates.
9. Write a brief explanation for your **Financial Dashboard Request** (page 3).

## Field-by-Field Explanation

* **User Details** (`user`, `text`): This is where you will enter your basic contact information such as your name and email.
* **Financial Dashboard Access** (`financial_dashboard_access`, `select_one`): Choose either **Full Access** or **Read-Only Access** to determine your level of permission. **Full Access** allows you to edit and view financial data. **Read-Only Access** only allows you to view financial data.
* **Financial Dashboard Access Notes** (`financial_dashboard_access_notes`, `note`): This is a text area where you can add any additional information about your access request.
* **Department** (`department`, `select_multiple`): Select from the list of departments (Marketing, Sales, Product, Finance) that you are a part of to determine which data you will have access to.
* **Date** (`date`, `date`): Enter the date when you would like to start using the Financial Dashboard.
* **Time** (`time`, `time`): Enter the time when you would like to start using the Financial Dashboard.
* **Email** (`email`, `email`): Enter your email so that we can contact you with updates.
* **Phone** (`phone`, `text`): Enter your phone number so that we can contact you with important updates.
* **Financial Dashboard Request** (`financial_dashboard_request`, `note`): This is a text area where you can add any additional information about your request.
