# Heuristic Evaluation Checklist - Help Guide
## Purpose
The Heuristic Evaluation Checklist is a tool for evaluating the user experience of an application, website, or system. It is designed to gather feedback on various aspects of the product, including user experience, navigation, search, and feedback mechanisms.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the provided options for each field and select the one that best describes your experience.
2. Fill out each field with your feedback and ratings.
3. Make sure to provide detailed explanations for each field where possible.

## Field-by-Field Explanation

* **Introduction** (`1`, `text`, required: false): This field is a brief introduction to the form. Please provide a short description of your experience with the application or system.
* **Simple User Goals** (`2`, `select_multiple`, required: false): Select all the simple user goals that best describe your experience.
	+ Option A: Clear and concise instructions for users to achieve their goals
	+ Option B: Intuitive and easy-to-use interface
* **User Characteristics** (`3`, `number`, required: false): Rate how well the application or system accommodates different user characteristics.
* **Simple Task Completion** (`4`, `select_one`, required: false): Select how well the application or system allows you to complete simple tasks.
	+ Option A: Tasks are easy to complete
	+ Option B: Tasks are difficult to complete
* **Error Message** (`5`, `text`, required: false): Describe any error messages you encountered while using the application or system.
* **Navigation** (`6`, `number`, required: false): Rate how well the navigation of the application or system helps you find what you need.
* **Search Box** (`7`, `email`, required: false): Enter your email address if you would like to be notified when your search results are available.
* **Search Results** (`8`, `number`, required: false): Rate how well the search results meet your needs.
* **Feedback Form** (`9`, `select_one`, required: false): Select how well you can provide feedback on the application or system.
	+ Option A: Feedback is easy to provide
	+ Option B: Feedback is difficult to provide
* **User Experience** (`10`, `text`, required: false): Describe your overall user experience with the application or system.
* **Search Box Rating** (`11`, `number`, required: false): Rate how well the search box meets your needs.
* **Prophets** (`12`, `select_multiple`, required: false): Select all the prophets that best describe your experience.
* **User Experience Rating** (`13`, `number`, required: false): Rate your overall experience with the application or system.
* **Navigation Rating** (`14`, `number`, required: false): Rate how well the navigation of the application or system helps you find what you need.
* **Search Box Rating 2** (`15`, `number`, required: false): Rate how well the second search box meets your needs.
* **Error Message 2** (`16`, `text`, required: false): Describe any error messages you encountered while using the application or system.
* **User Characteristics 2** (`17`, `number`, required: false): Rate how well the application or system accommodates different user characteristics.
* **Feedback Form 2** (`18`, `select_one`, required: false): Select how well you can provide feedback on the application or system.
	+ Option A: Feedback is easy to provide
	+ Option B: Feedback is difficult to provide

Please note that you can provide feedback on each field by describing your experience and rating it accordingly. The ratings are on a scale of 1-5, where 5 is the highest rating.
