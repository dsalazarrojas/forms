# Amenity Upgrade Proposal Request Form - Help Guide
## Purpose
This form is designed to help you, as a building maintenance staff or facilities manager, submit a proposal for an amenity upgrade within your building. The form is used to gather all relevant information about the proposed upgrade, including its scope, cost, timeline, and benefits. This information will be reviewed by management to determine the feasibility and priority of the proposed upgrade.

## How To Complete This Form
1. Fill out the form completely, making sure to provide all necessary information.
2. Enter the proposed date for the upgrade, if applicable.
3. Select the amenity type and location for the upgrade.
4. Provide a detailed description of the proposed upgrade, including the expected benefits.
5. Specify the estimated cost and basis of the estimate.
6. Select the expected duration of the project.
7. Specify the expected disruption to users, and provide details on how they will be affected.
8. List any alternative options considered.
9. Describe any supporting documentation attached.
10. Provide any additional comments or recommendations.
11. Sign and date the form, indicating your approval of the proposal.

## Field-by-Field Explanation
* **-- Proposal Information --**: This section provides general information about the proposal.
* **Proposal Date**: Enter the date you plan to complete the proposal.
* **Proposal Title**: Provide a brief descriptive title for the proposal.
* **-- Proposer Information --**: This section is for you to provide your name and title.
* **Proposer First Name**, **Proposer Last Name**: Enter your first and last names.
* **Proposer Title/Position**: Enter your job title or position.
* **Department**: Select the department you belong to.
* **Email Address**: Enter your email address.
* **Phone Number**: Enter your phone number.
* **-- Amenity Information --**: This section provides information about the amenity to be upgraded.
* **Amenity to be Upgraded**: Select the type of amenity to be upgraded.
* **Amenity Type**: Select the type of amenity being upgraded (e.g., fitness center).
* **Amenity Location**: Enter the location of the amenity.
* **Age of Current Amenity**: Enter the age of the current amenity.
* **Current Condition**: Select the condition of the current amenity.
* **-- Upgrade Details --**: This section provides detailed information about the upgrade.
* **Detailed Upgrade Description**: Provide a detailed description of the upgrade.
* **Type of Upgrade**: Select all applicable types of upgrades.
* **Scope of Work**: Provide a detailed description of the scope of work.
* **Materials/Equipment Needed**: List any materials or equipment needed for the upgrade.
* **-- Justification --**: This section provides justification for the upgrade.
* **Primary Reason for Upgrade**: Select the main reason for the upgrade.
* **Detailed Justification**: Provide a detailed explanation for the upgrade.
* **How Will This Affect Users**: Describe how the upgrade will affect users.
* **Urgency Level**: Select the urgency level of the upgrade.
* **-- Cost Estimate --**: This section provides estimated cost information.
* **Estimated Cost**: Enter the estimated cost of the upgrade.
* **Estimated Cost Range - Low**, **Estimated Cost Range - High**: Enter the estimated cost range.
* **Basis of Estimate**: Select the basis of the estimate.
* **Vendor Information**: If a vendor was selected, provide their information.
* **-- Timeline --**: This section provides timeline information.
* **Proposed Start Date**, **Proposed Completion Date**: Enter the proposed start and completion dates.
* **Estimated Project Duration**: Select the expected duration of the project.
* **Disruption Expected**: Select the expected disruption to users.
* **Disruption Details**: Describe how users will be affected.
* **-- Expected Benefits --**: This section provides expected benefits information.
* **Expected Benefits**: Select all applicable benefits.
* **Describe Expected Benefits**: Provide a detailed description of the expected benefits.
* **Expected Return on Investment**: If applicable, enter the expected return on investment.
* **-- Alternatives Considered --**: This section provides alternative options considered.
* **Alternatives Considered**: Enter any alternative options considered.
* **Why This Option Was Selected**: Provide a detailed explanation for why the selected option was chosen.
* **-- Supporting Documentation --**: This section provides supporting documentation information.
* **Documentation Attached**: Select all applicable documents attached.
* **List Attached Documents**: If applicable, list the attached documents.
* **-- Additional Information --**: This section provides additional comments or recommendations.
* **Additional Comments**: Enter any additional comments or recommendations.
* **Recommendations**: Enter any additional recommendations.
* **-- Approval --**: This section is for management review and approval.
* **Proposer Signature**: Sign the form, indicating your approval of the proposal.
* **Date of Signature**: Enter the date of signature.
* **Supervisor Review**: Enter supervisor review and approval information, if applicable.
* **Supervisor Signature**: Enter supervisor signature, if applicable.

## Tips
* Make sure to complete the form thoroughly and accurately.
* Review and proofread the form before submitting.
* Attach all necessary supporting documentation.
* Provide any additional comments or recommendations.
* Get supervisor review and approval, if applicable.
