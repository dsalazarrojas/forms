# Quality Improvement Plan Request Form - Help Guide
## Purpose
This form is used to submit a quality improvement project proposal to the project team and managers. It provides a structured template for project title, description, and other relevant information.

## How To Complete This Form
1. Fill out the form completely and accurately, providing all required and optional information.
2. Enter the project title in the "Project Title" field.
3. Provide a brief description of the project in the "Project Description" field.
4. Select the project category and other relevant details.
5. Fill out the project manager's contact information, including phone number and email.
6. Enter the project start and end dates.
7. Select the project status.
8. Enter the project priority and team size.
9. Fill out the team member information, including name, title, phone number, and email.
10. Provide notes for the team member.
11. Identify the action areas to focus on for the project.
12. Enter the action description and owner information.
13. Set the start and end dates for the action.
14. Select the action status and priority.
15. Enter the action team size and budget.
16. Provide notes for the action.
17. Select "Submit" to submit the form.

## Field-by-Field Explanation
* **Project Title**: A brief title for the project.
* **Project Description**: A brief description of the project.
* **Project Category**: The category of the project, if applicable.
* **Project Start Date**: The date when the project starts.
* **Project End Date**: The date when the project ends.
* **Project Manager**: The contact information for the project manager.
* **Project Manager Email**: The email of the project manager.
* **Project Manager Phone**: The phone number of the project manager.
* **Project Manager External Phone**: The external phone number of the project manager.
* **Project Manager External Email**: The external email of the project manager.
* **Project Status**: The status of the project, such as Active, In Progress, or Completed.
* **Project Priority**: The priority of the project.
* **Project Team Size**: The size of the project team.
* **Project Budget**: The budget for the project, if applicable.
* **Team Member Name**: A team member's name.
* **Team Member Title**: A team member's title.
* **Team Member Phone**: A team member's phone number.
* **Team Member Email**: A team member's email.
* **Team Member External Phone**: A team member's external phone number.
* **Team Member External Email**: A team member's external email.
* **Team Member Notes**: Notes for the team member.
* **Action Areas**: The areas to focus on for the project, such as Quality, Cost, Schedule, Scope, Resources, or Risk.
* **Action Description**: A brief description of the action.
* **Action Owners**: The owner of the action, such as Team, Client, or Other.
* **Action Start Date**: The date when the action starts.
* **Action End Date**: The date when the action ends.
* **Action Status**: The status of the action, such as Active, In Progress, Completed, or Not Started.
* **Action Priority**: The priority of the action.
* **Action Team Size**: The size of the action team.
* **Action Budget**: The budget for the action, if applicable.
* **Action Notes**: Notes for the action.
* **Submit**: Submit the form to send the project proposal.
* **Action Owners Other**: Other action owners, if applicable.
* **Action Budget Other**: Other action budget, if applicable.
* **Team Member Name Other**: Other team member name, if applicable.
* **Team Member Title Other**: Other team member title, if applicable.
* **Team Member Phone Other**: Other team member phone number, if applicable.
* **Team Member Email Other**: Other team member email, if applicable.
* **Team Member External Phone Other**: Other team member external phone number, if applicable.
* **Team Member External Email Other**: Other team member external email, if applicable.
* **Action Areas Other**: Other action areas, if applicable.
