# Digital Shelf Integration Request Form - Help Guide
## Purpose

The "Digital Shelf Integration Request Form" is a tool for requesting integration with digital platforms such as Shopify, Magento, and WooCommerce. This form helps the e-commerce and IT teams to track and manage such requests in a centralized manner. 

## How To Complete This Form

1.  To complete this form, please follow these steps:
    1.  Ensure you have read this guide thoroughly before submitting the form.
    2.  Select the status of your e-commerce team.
    3.  Select the status of your IT team.
    4.  Select the integration platform you wish to use.
    5.  Choose the type of integration you need (e.g., API, FTP, SFTP, or Other).
    6.  Choose the type of product you are integrating (e.g., Digital Product, Physical Product, or Service).
    7.  Select the date for integration.
    8.  Select the time for integration.
    9.  Provide any additional notes about your integration request.
    10. Enter your email address.
    11. Enter your phone number.
    12. If required, select the tool that will be used for this integration.

## Field-by-Field Explanation

- **Ecommerce Team Status** (`ecommerce_team_status`, optional): Indicate the status of your e-commerce team. If you are unsure, please mark as "Unknown".
- **IT Team Status** (`it_team_status`, optional): Indicate the status of your IT team. If you are unsure, please mark as "Unknown".
- **Integration Platform** (`integration_platform`, optional): Select the platform you wish to integrate with (Shopify, Magento, WooCommerce, or Other).
- **Integration Type** (`integration_type`, optional): Choose the type of integration you need (e.g., API, FTP, SFTP, or Other).
- **Product Type** (`product_type`, optional): Indicate the type of product you are integrating (Digital Product, Physical Product, or Service).
- **Integration Date** (`integration_date`, optional): Select the date for integration in the format "YYYY-MM-DD".
- **Integration Time** (`integration_time`, optional): Select the time for integration in 24-hour format (e.g., "14:30" for 2:30 PM).
- **Additional Notes** (`additional_notes`, optional): Enter any further information about your integration request.
- **Email** (`email`, optional): Enter your email address.
- **Phone** (`phone`, optional): Enter your phone number.
- **Assigned Tool** (`assigned_tool`, optional): If required, select the tool that will be used for this integration.
- **Output File** (`output_file`, optional): Enter the file name you wish to save your output.

## Tips

*   Before submitting this form, please ensure that you have read and understood all the fields.
*   Please fill in all required fields to the best of your abilities.
*   If you are unsure about any field, please mark it as "Unknown" and provide a brief explanation in the "Additional Notes" field.
*   If you need to submit a similar request, please check the form first to prevent duplicate efforts.
