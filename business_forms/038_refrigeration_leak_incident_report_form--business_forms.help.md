# Refrigeration Leak Incident Report Form - Help Guide
## Purpose
The Refrigeration Leak Incident Report Form is a standardized tool used to report incidents involving refrigeration leaks. This form helps to gather critical information about the leak, including the date, location, description, and cause. Reporting leaks in a consistent and thorough manner ensures that maintenance and repairs are addressed promptly and effectively.

## How To Complete This Form
1. Fill out the form with the necessary information about the incident, ensuring that all required fields are completed.
2. Select the correct repair status and leak type from the provided options.
3. Indicate the source of the leak using the relevant options.
4. Enter the size of the leak in numerical value.
5. Double-check that all information is accurate and complete before submitting the form.

## Field-by-Field Explanation

* **Incident Date**: The date on which the leak occurred.
* **Leak Location**: The location where the leak was detected.
* **Leak Description**: A detailed description of the leak, including any visible signs or symptoms.
* **Cause Of Leak**: A description of the reason for the leak.
* **Repair Status**: The current status of the repair, which can be "Complete", "In Progress", or "Not Reported".
* **Leak Type**: The type of leak, which can be "Defect", "Failure", "Material Fault", or "Other".
* **Leak Source**: The source of the leak, which can be "Valve", "Pipe", "Equipment", or "Other".
* **Leak Size**: The size of the leak, measured in numerical value.

## Tips

* Make sure to report all leaks, no matter how minor they may seem.
* If the cause of the leak is not immediately apparent, try to gather as much information as possible.
* If the repair status is "Not Reported", be prepared to provide additional information when the status changes.
* If you're unsure about any field, please consult with a supervisor or colleague for guidance.
