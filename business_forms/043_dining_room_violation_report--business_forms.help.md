# Dining Room Violation Report - Help Guide
## Purpose
The Dining Room Violation Report form is used to report any potential issues that have occurred in the dining room, such as food safety concerns or cleanliness issues. This form will help school administrators or restaurant management identify and address these issues in a timely and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date of the incident
2. Enter the time of the incident
3. Provide the location where the issue occurred
4. Describe the issue that was observed
5. Attach a photo of the issue (if possible)
6. Indicate if the issue is active or inactive
7. Select the type of issue that occurred
8. Enter the facility ID (if applicable)
9. Enter the follow-up date (if applicable)
10. Enter the school ID (if applicable)

## Field-by-Field Explanation
### Violation Date
* **Violation Date**: Enter the date of the incident in the format `YYYY-MM-DD`
* This is the date when the issue was observed or occurred.

### Time
* **Time**: Enter the time of the incident in 24-hour format `HH:MM:SS`
* This is the time when the issue was observed or occurred.

### Location
* **Location**: Enter the location where the issue occurred
* This could be a specific room number, a floor, or a section of the dining area.

### Description
* **Description**: Describe the issue that was observed
* Be as detailed as possible to help identify the problem.

### Photo
* **Photo**: Attach a photo of the issue (if possible)
* This can help illustrate the problem and aid in resolving it.

### Issue Type
* **Issue Type**: Select the type of issue that occurred
* This could be a food safety issue, cleanliness concern, or other.

### Follow Up
* **Follow Up**: Enter the date for follow-up on the issue
* This is the date when the issue should be revisited to ensure it is resolved.

### Issue Status
* **Issue Status**: Select whether the issue is active or inactive
* This indicates whether the issue is ongoing or has been resolved.

### Issue Type (Multiple Select)
* **Issue Type**: Select all types of issues that occurred
* This allows for multiple issues to be reported, such as food safety and cleanliness concerns.

### Facility ID
* **Facility ID**: Enter the ID of the facility where the issue occurred
* This is used to track issues across multiple facilities.

### Follow Up Date
* **Follow Up Date**: Enter the date for follow-up on the issue
* This is the date when the issue should be revisited to ensure it is resolved.

### School ID
* **School ID**: Enter the ID of the school where the issue occurred
* This is used to track issues across multiple schools.

## Tips

* Please be as detailed as possible when describing the issue to help resolve it efficiently.
* Attach any supporting evidence, such as photos or videos, to aid in resolving the issue.
* Ensure that the issue status is updated accordingly after the issue has been resolved.
