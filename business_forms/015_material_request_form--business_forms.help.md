# Material Request Form - Help Guide
## Purpose
The Material Request Form is designed to collect information about materials requested by project teams. It is used to gather details about the materials needed for a project, the person who requested them, and the location and person responsible for ordering them.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Material Request Date** field with the date you are requesting materials.
2. Enter the **Material Requestor**'s name and title (e.g., John Doe, Project Manager).
3. Specify the **Project Location** where the materials will be used.
4. Enter the **Material Ordered From** where the materials will be purchased from.
5. Enter the **Material Ordered By** who is responsible for ordering the materials.
6. (Optional) Add any additional **Material Request Details** if needed.
7. (Optional) Add any additional **Material Request Comments** if needed.

## Field-by-Field Explanation
* **Material Request Date**: Enter the date you are requesting materials for. This date should match the project's timeline.
*   **Material Requestor**: Enter the name and title of the person requesting the materials.
*   **Project Location**: Enter the location where the materials will be used.
*   **Material Ordered From**: Enter the name of the company or supplier from which you are ordering materials.
*   **Material Ordered By**: Enter the name of the person responsible for ordering the materials.
*   **Material Request Details**: (Optional) Add any additional information about the materials being requested.
*   **Material Request Comments**: (Optional) Add any additional comments or notes about the material request.

Note: The fields marked as optional can be left blank, but it is recommended to fill them out for more comprehensive information about the material request.
