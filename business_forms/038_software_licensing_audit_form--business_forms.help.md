# software_licensing_audit_form - Help Guide
## Purpose
The software_licensing_audit_form is designed to collect information about a company's software usage, ensuring compliance with regulatory requirements and company policies.

## How To Complete This Form

1.  Start by selecting the company info page. This section is optional but provides additional context about the company being audited.
2.  On the Software Licenses page, select all the software licenses used by the company. For each selected license, list the corresponding license numbers in the License Numbers field.
3.  Indicate the compliance status of each selected software license. If unsure, select "pending" to signify further investigation is needed.
4.  In the Notes field, provide any additional information that may be relevant to the software licenses or compliance status.
5.  On the Email and Phone fields, input contact information for the person completing the form or for additional contact information.
6.  Finally, provide a signature in the Signature field, acknowledging that the information provided is accurate and complete.

## Field-by-Field Explanation

*   **Company Info** (`company_info`, text, optional):
    *   Enter any additional information about the company being audited.
*   **Software Licenses** (`software_licenses`, select_multiple, optional):
    *   Select all the software licenses used by the company (e.g., Microsoft Excel, Adobe Photoshop, Microsoft Word).
*   **License Agreements** (`license_agreements`, select_one, optional):
    *   Indicate whether there is a license agreement associated with each selected software license.
*   **License Numbers** (`license_numbers`, text, optional):
    *   List all license numbers for the selected software licenses.
*   **Compliance Status** (`compliance_status`, select_one, optional):
    *   Indicate the compliance status of each selected software license (compliant, non-compliant, or pending).
*   **Notes** (`notes`, note, optional):
    *   Provide any additional information relevant to the software licenses or compliance status.
*   **Email** (`email`, email, optional):
    *   Input contact information for the person completing the form or additional contact information.
*   **Phone** (`phone`, text, optional):
    *   Input phone number for the person completing the form or additional contact information.
*   **Signature** (`signature`, text, optional):
    *   Provide a digital signature, acknowledging that the information provided is accurate and complete.
