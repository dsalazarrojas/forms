# Team Muse Movement Seint LllD Color Match Form - Help Guide
## Purpose

The Team Muse Movement Seint LllD Color Match Form is designed to help the team understand which type of form to create. This form asks team members about their interest in creating a color match form for Seint LllD and a movement form for Seint LllD.

## How To Complete This Form

To fill out this form, follow these steps:

1. Answer the questions about creating a color match form for Seint LllD.
2. Answer the questions about creating a movement form for Seint LllD.
3. Provide a description for both forms if you would like to have a more in-depth explanation.
4. Select the tool you would like to use for the project.

## Field-by-Field Explanation

* **Team Muse Movement Seint LllD Color Match Form** (`team_muse_movement_seint_llld_color_match_form`, text, optional): A text box where you can briefly describe your interest in creating a color match form for Seint LllD.
* **Seint Artists** (`seint_artists`, select_one, optional): This field asks whether you are interested in creating a form for Seint artists. Please select "Yes" if you are interested and "No" if not.
* **Color Match Form** (`color_match_form`, text, optional): A text box where you can describe your interest in creating a color match form for Seint LllD.
* **Movement Seint Form** (`movement_seint_form`, text, optional): A text box where you can describe your interest in creating a movement form for Seint LllD.
* **Seint LllD Color Match Form Description** (`seint_lll_d_color_match_form`, text, optional): This field is not actually needed as it is identical to the "Color Match Form" field.
* **Seint LllD Movement Form Description** (`seint_lll_d_color_match_form_description`, text, optional): A text box where you can describe your interest in creating a movement form for Seint LllD.
* **Assigned Tool** (`assigned_tool`, select_one, optional): This field asks which tool you would like to use for the project. Please select "chatjimmy" if you want to use chatjimmy, or "other" if you have a different tool in mind.
