# project_funding_request_form - Help Guide
## Purpose
The project funding request form is used to gather information about a project that is being submitted for funding consideration. This form helps project managers and team members to provide accurate and comprehensive information about the project, making it easier for funders to assess the project's potential for support.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the project title and description fields to provide a brief overview of the project.
2. Enter the project's budget and funding goal, if applicable.
3. Provide the project's start and end dates.
4. Enter the project location.
5. Select the project leads and funding sources.
6. Add any relevant contacts for the project.
7. Choose the project status and provide any additional status details, if necessary.
8. Enter the project's email address and phone number, if applicable.
9. For duplicate projects, fill out all relevant fields for each duplicate project.

## Field-by-Field Explanation

* **Project Title** (Text): A brief title for the project.
* **Project Description** (Text): A brief description of the project.
* **Project Budget** (Number): The budget for the project, if applicable.
* **Project Funding Goal** (Number): The funding goal for the project, if applicable.
* **Project Start Date** (Date): The start date of the project.
* **Project End Date** (Date): The end date of the project.
* **Project Location** (Text): The location of the project.
* **Project Leads** (Select Multiple): A list of leads or team members associated with the project.
* **Project Funding Sources** (Select Multiple): A list of funding sources for the project.
* **Project Contacts** (Note): A note field for any additional contacts associated with the project.
* **Project Status** (Select One): The current status of the project (Active or Inactive).
* **Project Status Details** (Select One): Additional details about the project's status (Detailed or Other).
* **Email** (Email): The email address of the project's contact person or team.
* **Phone** (Text): The phone number of the project's contact person or team.
* **Project Leads 2** (Select Multiple): A list of leads or team members associated with the second project.
* **Project Budget 2** (Number): The budget for the second project, if applicable.
* **Project Funding Goal 2** (Number): The funding goal for the second project, if applicable.
* **Project Start Date 2** (Date): The start date of the second project.
* **Project End Date 2** (Date): The end date of the second project.
* **Project Location 2** (Text): The location of the second project.
* **Project Leads 3** (Select Multiple): A list of leads or team members associated with the third project.
* **Project Funding Sources 2** (Select Multiple): A list of funding sources for the third project.
* **Project Contacts 2** (Note): A note field for any additional contacts associated with the third project.
* **Project Status 2** (Select One): The current status of the third project (Active or Inactive).
* **Project Status Details 2** (Select One): Additional details about the third project's status (Detailed or Other).
