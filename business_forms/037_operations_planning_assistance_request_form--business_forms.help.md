# Operations Planning Assistance Request Form - Help Guide
## Purpose
The Operations Planning Assistance Request Form is used to request help with operations planning within an organization. This form helps the operations team plan and execute operations more efficiently.

## How To Complete This Form
To fill out this form, simply select the relevant fields with the required information and click submit. Make sure to provide as much detail as possible in the "Description" field to help the operations team better understand the operation.

## Field-by-Field Explanation
### Operation ID
* **Operation ID** (`operation_id`, text, optional): This is the unique identifier for the operation. If you have the Operation ID, please enter it here.
### Name
* **Name** (`name`, text, optional): Enter the name of the operation being requested.
### Date of Request
* **Date of Request** (`date_of_request`, date, optional): The date when the operation was requested. If not known, leave blank.
### Time of Request
* **Time of Request** (`time_of_request`, time, optional): The time when the operation was requested. If not known, leave blank.
### Email Address
* **Email Address** (`email_address`, email, optional): The email address associated with the operation. If not applicable, leave blank.
### Contact Number
* **Contact Number** (`contact_number`, text, optional): The phone number or contact number for the operation. If not applicable, leave blank.
### Description
* **Description** (`description`, text, optional): A detailed description of the operation, including any relevant details or context.
### Department
* **Department** (`department`, text, optional): The department associated with the operation. If not applicable, leave blank.
### Location
* **Location** (`location`, text, optional): The location associated with the operation. If not applicable, leave blank.
### Request Type
* **Request Type** (`request_type`, select_one, optional, options: Type 1, Type 2, Type 3, Type 4): Select one of the four types of requests listed.
### Assigned Tool
* **Assigned Tool** (`assigned_tool`, text, optional): The tool or resources assigned to the operation. If not applicable, leave blank.
### Notes
* **Notes** (`notes`, note, optional): Any additional information or notes about the operation.
### Submitted By
* **Submitted By** (`submitted_by`, text, optional): The name of the person submitting the operation. If not known, leave blank.
### Submitted Time
* **Submitted Time** (`submitted_time`, time, optional): The time when the operation was submitted. If not known, leave blank.
### Submitted Date
* **Submitted Date** (`submitted_date`, date, optional): The date when the operation was submitted. If not known, leave blank.
### Operation Status
* **Operation Status** (`operation_status`, select_one, optional, options: Status 1, Status 2, Status 3, Status 4): Select one of the four statuses listed.
