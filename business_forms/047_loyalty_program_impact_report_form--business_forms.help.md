# Loyalty Program Impact Report Form - Help Guide
## Purpose
The Loyalty Program Impact Report Form is a tool to collect user feedback on their experience with a specific loyalty program. This form helps program managers understand how well the program is performing and identify areas for improvement.
## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **First Name** in the text field. Your first name will be used to identify your response.
2. Provide your **Email** address. This will help us contact you with any follow-up questions or for further information.
3. Select your **Loyalty Program** from the drop-down menu.
4. If you have any additional comments or feedback about the program, type them in the **Program Details** text field.
5. Enter the **Frequency** with which you participate in the program (e.g., "daily", "weekly", "monthly", etc.).
6. If you have any comments or feedback about the program, type them in the **Comments** text field.
7. Rate your **Program Effectiveness** by selecting one of the options from the drop-down menu.
8. If applicable, rate your **User Experience** by selecting one of the options from the drop-down menu.
9. Choose the **Recommendations** you would make to improve the program by selecting one or more options from the drop-down menu.
10. Select the **Date** and **Time** you completed this form using the calendar and time input fields.
11. Finally, enter the name of your **Program Manager** (this is not a required field, but if you have one, please provide their name).

## Field-by-Field Explanation

* **First Name** (Text, Required): Enter your first name as you would like to be addressed.
* **Email** (Email, Required): Enter your email address so we can contact you for follow-up questions.
* **Loyalty Program** (Select One, Optional): Choose your current loyalty program from the list.
* **Program Details** (Text, Optional): If you have any additional comments or feedback about the program, type them in this field.
* **Frequency** (Number, Optional): Enter the frequency with which you participate in the program (e.g., "daily", "weekly", "monthly", etc.).
* **Comments** (Text, Optional): If you have any comments or feedback about the program, type them in this field.
* **Program Effectiveness** (Select One, Optional): Rate your experience with the program on a scale from Strongly Agree to Strongly Disagree.
* **User Experience** (Select One, Optional): If applicable, rate your user experience with the program on a scale from High to Low.
* **Recommendations** (Select Multiple, Required): Choose one or more options to improve the program.
* **Date** (Date, Required): Select the date you completed this form using the calendar input field.
* **Time** (Time, Required): Select the time you completed this form using the time input field.
* **Program Manager** (Text, Optional): If you have a program manager assigned to you, enter their name.

Note: This form is intended for program managers to track user engagement and satisfaction. Please answer honestly and provide as much detail as you can.
