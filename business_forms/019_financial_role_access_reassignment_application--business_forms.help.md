# Financial Role Access Reassignment Application - Help Guide
## Purpose
The Financial Role Access Reassignment Application form is used to reassign financial roles within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the User Requesting field and enter your name.
2. Enter your Reason For Change in the provided field.
3. Enter your Current Title and New Title in the provided fields.
4. If necessary, select Yes or No for Manager, IT, and HR Approvals.
5. Enter the Manager Approval Date and IT Approval Date if approvals have been obtained.
6. Select Yes or No for IT and HR Approvals.
7. Enter the HR Approval Date if HR approval has been obtained.
8. Enter a brief description of the Role Description.
9. Select the Access Level.
10. Select Access Granted and enter any additional Notes.
11. Enter the Submitted By field with your name.
12. Enter the Submitted To field with the name of the person or department to whom the request is submitted.
13. Enter the Manager Name, IT Name, Finance Name, and HR Name fields with their respective names.
14. Enter the Manager Title, IT Title, and Finance Title fields with their respective titles.
15. Select the Finance Approval Status as Active or Inactive.

## Field-by-Field Explanation
* **User Requesting (1)** (`User Requesting`, `text`, required): Enter your name to initiate the role reassignment process.
* **Reason For Change (2)** (`reason_for_change`, `text`, required): Provide a clear and concise reason for requesting the role change.
* **Current Title (4)** (`current_title`, `text`, required): Enter your current title to facilitate the transition.
* **New Title (5)** (`new_title`, `text`, required): Enter the new title to be assigned.
* **Manager Approvals (6)** (`manager_approvals`, `select_one`, optional): Select Yes or No to indicate if the manager has approved the request.
* **Manager Approval Date (7)** (`manager_approval_date`, `date`, optional): Enter the date the manager approved the request if applicable.
* **IT Approvals (8)** (`it_approvals`, `select_multiple`, optional): Select Yes or No to indicate if IT has approved the request.
* **IT Approval Date (9)** (`it_approval_date`, `date`, optional): Enter the date IT approved the request if applicable.
* **HR Approvals (10)** (`hr_approvals`, `select_one`, optional): Select Yes or No to indicate if HR has approved the request.
* **HR Approval Date (11)** (`hr_approval_date`, `date`, optional): Enter the date HR approved the request if applicable.
* **Role Description (12)** (`role_description`, `text`, required): Provide a brief description of the role being reassigned.
* **Access Level (13)** (`access_level`, `text`, optional): Enter the access level for the reassigned role.
* **Access Granted (14)** (`access_granted`, `text`, required): Select Yes or No to confirm access is granted for the reassigned role.
* **Notes (15)** (`notes`, `note`, optional): Enter any additional notes for the reassignment process.
* **Submitted By (16)** (`submitted_by`, `text`, optional): Enter your name for submission purposes.
* **Submitted To (17)** (`submitted_to`, `text`, required): Enter the name of the person or department to whom the request is submitted.
* **Manager Name (18)** (`manager_name`, `text`, required): Enter the manager's name for approval purposes.
* **IT Name (19)** (`it_name`, `text`, required): Enter the IT representative's name for approval purposes.
* **Finance Name (20)** (`finance_name`, `text`, required): Enter the finance representative's name for approval purposes.
* **HR Name (21)** (`hr_name`, `text`, required): Enter the HR representative's name for approval purposes.
* **Manager Title (22)** (`manager_title`, `text`, required): Enter the manager's title.
* **IT Title (23)** (`it_title`, `text`, optional): Enter the IT representative's title.
* **Finance Title (24)** (`finance_title`, `text`, optional): Enter the finance representative's title.
* **Finance Approval Status (25)** (`finance_approval_status`, `select_one`, optional): Select Active or Inactive to confirm the finance approval status.
