# nonprofit_outreach - Help Guide
## Purpose
The Nonprofit Outreach form is used to gather information about nonprofit organizations' outreach efforts, including categories, descriptions, dates, and contact details. This form is typically used for internal tracking and communication purposes within the organization.

## How To Complete This Form
To complete this form, follow these steps:
1. Start by providing the title of the outreach effort, including any relevant details in the description field.
2. Select the category for this outreach effort from the options provided.
3. Briefly describe the outreach effort, providing any necessary details.
4. If applicable, select additional categories for the short description of the effort.
5. Set a date for this outreach event or project.
6. Enter a time for the outreach event or project (if applicable).
7. Add a phone number for any additional contact information.
8. Provide a contact email address.
9. Leave any additional note for the outreach effort.

## Field-by-Field Explanation
- **Nonprofit Title** (`form_title`, text, optional): Enter a brief title for this outreach effort.
- **Category** (`form_category`, text, optional): Select the main category for this outreach event or project.
- **Description** (`form_description`, text, optional): Provide a detailed description of the outreach effort.
- **Select Category** (`form_category_select`, select_one, optional): Choose additional categories for this outreach effort.
- **Short Description** (`form_description_short`, select_multiple, optional): Select additional categories for a brief short description of this outreach effort.
- **Date** (`form_date`, date, optional): Set the date for this outreach event or project.
- **Time** (`form_time`, time, optional): Set the time for this outreach event or project.
- **Phone** (`form_phone`, text, optional): Enter a phone number for any additional contact information.
- **Email** (`form_email`, email, optional): Enter a contact email address for this outreach effort.
- **Note** (`form_note`, note, optional): Add any additional notes about the outreach effort.
