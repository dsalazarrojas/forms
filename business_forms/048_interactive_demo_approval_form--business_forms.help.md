# interactive_demo_approval_form - Help Guide
## Purpose
The interactive_demo_approval_form is used to process demo requests, enabling users to submit and track the status of demos.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely, making sure to provide necessary information for demo requests.
2. Select relevant options for Product Preferences, Demo Schedule, and Demo Approval Status as per your requirements.
3. Optionally, provide Client Contact Info, Demo Details, Product Notes, and Client Notes if needed.
4. Review your submission carefully before submitting.

## Field-by-Field Explanation

* **Demo Request Form (id: 1)** (`title`, `text`, optional): Enter a brief description of the demo request.
* **Client Contact Info (id: 2)** (`text`, optional): Enter any relevant contact information for the client.
* **Demo Details (id: 3)** (`text`, optional): Provide additional details about the demo request.
* **Product Preferences (id: 4)** (`select_multiple`, optional): Select which products are relevant to this demo request.
	+ Choose one or more products from the options:
		- 'Yes'
		- 'No'
* **Demo Schedule (id: 5)** (`date`, optional): Select a date for the demo.
* **Client Notes (id: 6)** (`note`, optional): Record any important notes related to the client.
* **Product Notes (id: 7)** (`note`, optional): Record any important notes related to the product.
* **Demo Approval Status (id: 8)** (`select_one`, optional): Select the current status of the demo.
	+ Choose one option:
		- Active
		- Inactive
* **Assigned To (id: 9)** (`select_one`, optional): Select whether the demo is assigned to someone.
	+ Choose one option:
		- 'Yes'
		- 'No'
* **Chat ID (id: 10)** (`text`, optional): Enter the chat ID for the demo request.

## Tips
* Be sure to review each field carefully and provide accurate information.
* If you're unsure about any field, please contact your supervisor or refer to the relevant product documentation.
* This form is designed to streamline the demo request process. If you have any issues or concerns, please reach out to us for assistance.
