# Seasonal Maintenance Checklist Form - Help Guide
## Purpose
This form is used to track and manage seasonal maintenance tasks for properties. It helps users keep track of tasks that need to be performed during different seasons and store notes and status updates for each task.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of property you are maintaining (Single Family Home, Duplex, Condo, or Townhouse).
2. Choose the seasonal maintenance tasks that need to be performed (Heating System Check, Gutter Cleaning, Fire Safety Check, etc.).
3. Select the status of each maintenance task (Done, Not Done, Scheduled, In Progress).
4. Enter the seasonal maintenance schedule (date and time).
5. Add any additional comments or notes regarding the maintenance tasks.

## Field-by-Field Explanation
* **Checklist Items**: Select all the maintenance tasks that need to be performed.
	+ Type: Note field
	+ Purpose: Enter a list of tasks that need to be completed during the current season.
* **Seasonal Maintenance Tasks**: Select all the tasks that need to be performed.
	+ Type: Select Multiple
	+ Purpose: Identify which tasks need to be completed during the current season.
* **Property Details**: Select the type of property you are maintaining.
	+ Type: Select One
	+ Purpose: Identify the type of property (Single Family Home, Duplex, Condo, Townhouse).
* **Additional Comments**: Enter any additional comments or notes about the maintenance tasks.
	+ Type: Text Field
	+ Purpose: Add any additional information or context about the maintenance tasks.
* **Seasonal Maintenance Schedule**: Enter the date and time for when the maintenance tasks should be completed.
	+ Type: Date Field
	+ Purpose: Schedule when the maintenance tasks should be completed.
* **Scheduled Date**: Enter the date and time for when the maintenance tasks should be completed.
	+ Type: Time Field
	+ Purpose: Schedule when the maintenance tasks should be completed.
* **Seasonal Maintenance Status**: Select the status of each maintenance task.
	+ Type: Select One
	+ Purpose: Identify the status of each maintenance task (Done, Not Done, Scheduled, In Progress).
* **Notes**: Select all the maintenance tasks that need to be performed.
	+ Type: Select Multiple
	+ Purpose: Identify which tasks need to be completed during the current season.
* **Seasonal Maintenance Due Date**: Enter the date when the maintenance tasks are due.
	+ Type: Date Field
	+ Purpose: Identify when the maintenance tasks are due.
* **Seasonal Maintenance Status**: Select the status of each maintenance task.
	+ Type: Select One
	+ Purpose: Identify the status of each maintenance task (Done, Not Done, Scheduled, In Progress).

## Tips
* Make sure to select all the tasks that need to be completed during the current season.
* Enter the correct date and time for when the maintenance tasks should be completed.
* Use the notes field to add any additional comments or context about the maintenance tasks.
* Update the status of each maintenance task as needed.
* Use this form to track and manage seasonal maintenance tasks for your properties.
