# Unreturned Item Report - Help Guide
## Purpose
The Unreturned Item Report form is used to report items that have not been returned by office employees.

## How To Complete This Form
1. Enter the **Office Name** where the item was borrowed from.
2. Enter the date the item was supposed to be returned.
3. Identify the employee who borrowed the item.
4. Enter the date the item was returned (if applicable).
5. Provide a brief reason for why the item has not been returned.
6. Specify any details about the item that might be helpful.
7. Leave any additional notes.
8. Select the office where the item was supposed to be returned.
9. Specify the status of the item (e.g. Not Returned Yet, Returned, Lost).
10. Select the item that was supposed to be returned (e.g. Item 1, Item 2, Item 3).

## Field-by-Field Explanation
* **Office Name** (Office Name, text, optional): Enter the name of the office where the item was borrowed from.
* **Unreturned Date** (Unreturned Date, date, optional): Enter the date the item was supposed to be returned.
* **Borrowed By** (Borrowed By, text, optional): Identify the employee who borrowed the item.
* **Returned Date** (Returned Date, date, optional): Enter the date the item was returned (if applicable).
* **Reason** (Reason, text, optional): Provide a brief reason for why the item has not been returned.
* **Item Details** (Item Details, text, optional): Specify any details about the item that might be helpful.
* **Notes** (Notes, note, optional): Leave any additional notes.
* **Office** (Office, select_one, optional): Select the office where the item was supposed to be returned.
* **Status** (Status, select_multiple, optional): Specify the status of the item (e.g. Not Returned Yet, Returned, Lost).
* **Item** (Item, select_one, optional): Select the item that was supposed to be returned (e.g. Item 1, Item 2, Item 3).
