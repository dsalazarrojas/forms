# Material Return Form - Help Guide
## Purpose
This form is used to submit material return requests to initiate the return process.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your user email address in the "User Email" field.
2. Enter the name of the item in the "Item Name" field.
3. Provide the quantity of the item being returned.
4. Specify the reason for the return in the "Reason For Return" field.
5. Enter the date you received the item in the "Date Item Received" field.
6. Enter the date you would like to return the item in the "Date Returned" field.
7. Select the reason for the return from the dropdown list in the "Reason For Return" field.
8. Add any additional comments or notes about the return in the "Notes" field (optional).

## Field-by-Field Explanation
* **User Email** (`user_email`, email, required/optional): Please enter your email address to help our team contact you regarding your return request.
* **Item Name** (`item_name`, text, required/optional): Enter the name of the item you would like to return.
* **Item Quantity** (`item_quantity`, number, required/optional): Enter the quantity of the item you would like to return.
* **Reason For Return** (`reason_for_return`, text, required/optional): Specify the reason for returning the item, such as "defective" or "no longer needed".
* **Date Item Received** (`date_item_received`, date, required/optional): Enter the date you received the item.
* **Date Returned** (`date_returned`, date, required/optional): Enter the date you would like to return the item.
* **Reason For Return** (`return_reason`, select_one, required/optional): Select the reason for return from the dropdown list.
* **Notes** (`notes`, note, required/optional): Add any additional comments or notes about the return request.

Please note that all fields are optional unless marked as "required". If a field is marked as required, please fill it in accordingly.
