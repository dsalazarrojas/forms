The "Sustainability Index Evaluation Request" form is a crucial tool used to evaluate and assess various aspects of an organization's sustainability index. This form serves as a framework for collecting and analyzing data related to the request type, context, focus areas, documentation, and submission details. The purpose of this form is to ensure that each aspect of the sustainability index is accurately evaluated and rated to provide a comprehensive picture of an organization's sustainability performance.

## Sustainability Index Evaluation Request - Help Guide

## Purpose
The Sustainability Index Evaluation Request form is used to collect and evaluate data related to an organization's sustainability index. It helps to assess various aspects of sustainability, including focus areas, documentation, and submission details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Organization field with the relevant information about the organization being evaluated.
2. Select the Request Type from the available options.
3. Provide a brief Context to describe the purpose of the sustainability index evaluation.
4. Choose the Focus Areas relevant to the evaluation.
5. Add any additional Documentation required for the evaluation.
6. Enter the Submission Date and Submission Time of the evaluation.
7. Enter the Review Date and Review Time for the reviewer's comments.
8. Select the Reviewer who will be evaluating the sustainability index.
9. Enter the Evaluator Rating of the sustainability index.
10. Enter the Evaluation Result and Evaluation Status.
11. Add any Comments or feedback related to the evaluation.
12. Enter the Form ID for tracking purposes.
13. Select the Category of the evaluation.

## Field-by-Field Explanation

- **Organization (text)**: Enter the name of the organization being evaluated.
  - **Type**: text
  - **Required**: No
- **Request Type (text)**: Select the type of request being made (e.g., evaluation, update, etc.).
  - **Type**: text
  - **Required**: No
- **Context (text)**: Provide a brief description of the purpose of the evaluation.
  - **Type**: text
  - **Required**: No
- **Focus Areas (select_multiple)**: Choose the specific areas of focus for the evaluation (e.g., environmental, social, economic).
  - **Type**: select_multiple
  - **Required**: No
- **Documentation (text)**: Attach any relevant documentation or evidence required for the evaluation.
  - **Type**: text
  - **Required**: No
- **Evaluator Notes (text)**: Enter any additional notes or feedback from the evaluator.
  - **Type**: text
  - **Required**: No
- **Submission Date (date)**: Enter the date the evaluation was submitted.
  - **Type**: date
  - **Required**: No
- **Submission Time (time)**: Enter the time the evaluation was submitted.
  - **Type**: time
  - **Required**: No
- **Review Date (date)**: Enter the date the reviewer commented on the evaluation.
  - **Type**: date
  - **Required**: No
- **Review Time (time)**: Enter the time the reviewer commented on the evaluation.
  - **Type**: time
  - **Required**: No
- **Submitted By (text)**: Enter the name of the person who submitted the evaluation.
  - **Type**: text
  - **Required**: No
- **Submitted On (date)**: Enter the date the evaluation was submitted.
  - **Type**: date
  - **Required**: No
- **Evaluator Rating (number)**: Enter a rating of the sustainability index (e.g., 1-10).
  - **Type**: number
  - **Required**: No
- **Reviewer (text)**: Enter the name of the reviewer.
  - **Type**: text
  - **Required**: No
- **Evaluation Result (text)**: Enter a brief description of the evaluation result.
  - **Type**: text
  - **Required**: No
- **Evaluation Status (select_one)**: Select the status of the evaluation (e.g., Approved, Not Approved, Pending).
  - **Type**: select_one
  - **Required**: No
- **Comments (text)**: Enter any additional comments or feedback related to the evaluation.
  - **Type**: text
  - **Required**: No
- **Form ID (text)**: Enter a unique identifier for the form (for tracking purposes).
  - **Type**: text
  - **Required**: No
- **Category (text)**: Enter the category of the evaluation (e.g., sustainability, environment, etc.).
  - **Type**: text
  - **Required**: No

## Tips

- Make sure to fill in all relevant fields to ensure accurate and comprehensive evaluation.
- Use the provided fields to provide detailed and clear information for the evaluator.
- Double-check your submission for any errors or inaccuracies before submitting.
- Contact the reviewer or evaluator if you have any questions or need further clarification.
