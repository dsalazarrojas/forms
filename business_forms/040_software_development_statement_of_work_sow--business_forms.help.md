# Software Development Statement Of Work SOW - Help Guide
## Purpose
The Software Development Statement Of Work SOW is a form used to document and track project information for software development projects. It captures project details, scope, timeline, and payment terms to ensure that all stakeholders are on the same page.

## How To Complete This Form

*   Start by filling out the project details section, which includes the project title, description, and scope.
*   Next, enter the project timeline, including the start and end dates.
*   Provide payment terms, including payment frequency and terms.
*   Choose the clients involved in the project and enter their contact information.
*   Select the project status and billing cycle.
*   Enter any additional comments or notes about the project.
*   Finally, confirm who created the project and who approved it.

## Field-by-Field Explanation

*   **Project Title** (`project_title`, text, required): Enter a brief title that describes the project.
*   **Project Description** (`project_description`, text, required): Enter a detailed description of the project, including its objectives and goals.
*   **Project Scope** (`project_scope`, text, required): Describe the project scope, including the services or deliverables expected.
*   **Project Deliverables** (`project_deliverables`, text, required): Specify the project deliverables, including software products or services.
*   **Timeline Start Date** (`timeline_start_date`, date, required): Enter the project start date.
*   **Timeline End Date** (`timeline_end_date`, date, required): Enter the project end date.
*   **Payment Terms** (`payment_terms`, text, required): Outline the payment terms and conditions.
*   **Payment Schedule** (`payment_schedule`, text, required): Specify the payment schedule, including the payment frequency and due dates.
*   **Payment Frequency** (`payment_frequency`, text, required): Enter the payment frequency (e.g., weekly, bi-weekly, etc.).
*   **Client** (`client`, select_multiple, optional): Select the clients involved in the project.
*   **Contact E-mail** (`contact_email`, email, required): Enter the contact email for the client.
*   **Project Manager** (`project_manager`, text, required): Identify the project manager.
*   **Team Lead** (`team_lead`, text, required): Identify the team lead.
*   **Billing Cycle** (`billing_cycle`, select_one, required): Choose the billing cycle (e.g., weekly, bi-weekly, etc.).
*   **Project Status** (`project_status`, select_one, required): Select the project status (e.g., active, inactive, etc.).
*   **Payment Terms Notes** (`payment_terms_notes`, text, required): Enter any additional notes about payment terms.
*   **Project Notes** (`project_notes`, text, required): Enter any additional notes about the project.
*   **Project Comments** (`project_comments`, text, required): Enter any comments about the project.
*   **Project Attachments** (`project_attachments`, text, required): Attach any relevant documents or files to the project.
*   **Approval** (`approval`, select_one, required): Confirm who approved the project.
*   **Approved By** (`approved_by`, select_one, required): Confirm who approved the project.
*   **Approved Date** (`approved_date`, date, required): Enter the date of approval.
*   **Created By** (`created_by`, select_one, required): Confirm who created the project.
*   **Modified By** (`modified_by`, select_one, required): Confirm who modified the project.

Note: The following fields are optional and not required for the project: **Client**, **Project Manager**, **Team Lead**.

## Tips

*   This form is designed to be completed by project managers, team leads, or clients.
*   Ensure that you have the necessary authority to access and submit project information.
*   Double-check your entries for accuracy and completeness to prevent errors.
*   Save your progress frequently to avoid losing your work.
*   Use the project attachment field to upload relevant documents or files.
*   Review the form carefully before submitting it for approval.

By following this guide, you will be able to complete the Software Development Statement Of Work SOW form accurately and efficiently. If you have any questions or need further clarification, please contact [form@gic.mx](mailto:form@gic.mx).
