# Construction Project Intake Form - Help Guide
## Purpose
The Construction Project Intake Form is designed to collect essential information about a construction project from the client. This information will help the firm understand the project's scope, budget, and timeline, ensuring a smooth and efficient process.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out the Client and Primary Contact section with accurate information about the client and their primary contact person.
2. Provide details about the project's identification, including the official project name, project site address, and tax parcel number (if applicable).
3. In the Project Scope and Budget section, describe the project's main goals and features, and provide an estimated total budget.
4. Choose the primary project category and select all applicable permits and approvals status.
5. Specify the desired start and completion dates for the project.
6. Check any special site constraints or client requirements.
7. Provide a brief description of how you heard about the firm.
8. Finally, confirm the name of the person completing the form and submit the date of intake.

## Field-by-Field Explanation

* **Client/Business Name**: Enter the name of the client or business associated with this project.
* **Primary Contact Person**: Enter the name of the primary contact person for this project.
* **Primary Email Address**: Enter the primary email address of the contact person.
* **Primary Phone Number**: Enter the primary phone number of the contact person in the format (XXX) XXX-XXXX.
* **Official Project Name**: Enter the official name of the project.
* **Project Site Address**: Enter the address of the project site, including city, state, and zip.
* **Tax Parcel Number (APN)**: Enter the tax parcel number associated with the project site (if applicable).
* **Primary Project Category**: Choose the primary category for this project from the available options.
* **Brief Summary of Project Scope**: Describe the main goals and features of the project.
* **Estimated Total Budget**: Enter the estimated total budget for the project in dollars.
* **Current Funding Status**: Select the current funding status of the project from the available options.
* **Desired Project Start Date**: Enter the desired start date for the project.
* **Desired Project Completion Date**: Enter the desired completion date for the project.
* **Permits and Approvals Status**: Select all applicable permits and approvals statuses that apply to this project.
* **Special Site Constraints or Client Requirements**: Enter any special site constraints or client requirements that apply to this project.
* **How Did You Hear About Our Firm?**: Provide a brief description of how you heard about our firm.
* **Name of Person Completing Intake Form**: Enter the name of the person completing this form.
* **Date of Intake**: Enter the date of intake for this form.
