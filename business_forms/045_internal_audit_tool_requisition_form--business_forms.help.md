# Internal Audit Tool Requisition Form - Help Guide
## Purpose
This form is used to request internal audit tools for business purposes.

## How To Complete This Form

1. Select all the tools that you think are necessary for your internal audit from the dropdown menu.
2. Choose the person or group that should be assigned to use the tools by selecting their name from the dropdown menu. If the person or group is not listed, select "Other" and include their name in the notes field.
3. If you have any additional information or requests about the tools, please include them in the "notes" field.
4. If you have a specific email address or phone number to contact you, please enter them in the corresponding fields.
5. If you have a specific name and version of the tool in mind, please enter them in the corresponding fields.

## Field-by-Field Explanation

* **request_tools** (`request_tools`, select_multiple, required: false): Select all the tools that you think are necessary for your internal audit from the dropdown menu. Please make sure to select only tools that are relevant to your audit and that you have a legitimate business reason for requesting them.
* **tool_requester** (`tool_requester`, select_one, required: false): Choose the person or group that should be assigned to use the tools by selecting their name from the dropdown menu. If the person or group is not listed, select "Other" and include their name in the notes field.
* **notes** (`notes`, text, required: false): If you have any additional information or requests about the tools, please include them in this field.
* **email** (`email`, email, required: false): If you have a specific email address that you'd like to be contacted at, please enter it here.
* **phone** (`phone`, text, required: false): If you have a specific phone number that you'd like to be contacted at, please enter it here.
* **tool_name** (`tool_name`, text, required: false): If you have a specific name of the tool in mind, please enter it here.
* **tool_version** (`tool_version`, text, required: false): If you have a specific version of the tool in mind, please enter it here.
