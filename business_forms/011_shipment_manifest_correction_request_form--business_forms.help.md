# Shipment Manifest Correction Request Form - Help Guide

## Purpose
The Shipment Manifest Correction Request Form is used to report discrepancies or changes in shipment information. This form is designed to help staff members identify and correct issues with shipment manifests, ensuring accurate and up-to-date information.

## How To Complete This Form

To complete this form, follow these steps:

1.  Review the form fields carefully to ensure you understand what information is required and what you need to provide.
2.  Select the relevant shipping party for your submission.
3.  Enter any additional information for the shipping party if it is not listed.
4.  Provide the reason for the correction.
5.  Enter the shipment date and time if applicable.
6.  Enter the shipment number.
7.  Enter the tracking number.
8.  Enter the shipment weight.
9.  Select the current shipment status.
10.  Select the shipment location.
11.  Enter the ship from and ship to information.
12.  Select the ship via method.
13.  Enter any other additional information for the ship via method if not listed.

## Field-by-Field Explanation

### Request Details
* **Request Details** (`Shipment Manifest Correction Request Form`, text, optional): Enter a brief description of the issue you are reporting. Please provide enough information for the staff to understand the context of the correction.

### Shipping Party
* **Shipping Party** (`party a`, `party b`, optional): Select the shipping party responsible for the shipment from the list below.
	+ party a
	+ party b

### Other Shipping Party
* **Other Shipping Party** (text, optional): If the shipping party is not listed, please enter the name of the party.

### Reason for Correction
* **Reason for Correction** (text, optional): Enter a brief explanation for the correction you are requesting. Please provide enough information for the staff to understand why the change is needed.

### Ship Date
* **Ship Date** (date, optional): Enter the date of the shipment if applicable.

### Ship Time
* **Ship Time** (time, optional): Enter the time of the shipment if applicable.

### Shipment Number
* **Shipment Number** (number, optional): Enter the unique number of the shipment.

### Tracking Number
* **Tracking Number** (text, optional): Enter the tracking number for the shipment.

### Shipment Weight
* **Shipment Weight** (number, optional): Enter the weight of the shipment if applicable.

### Shipment Status
* **Shipment Status** (pending, confirmed, delivered, optional): Select the current status of the shipment from the list below.
	+ pending
	+ confirmed
	+ delivered

### Shipment Location
* **Shipment Location** (location a, location b, optional): Select the location of the shipment from the list below.
	+ location a
	+ location b

### Ship From
* **Ship From** (text, optional): Enter the name of the sender.

### Ship To
* **Ship To** (text, optional): Enter the name of the recipient.

### Ship Via
* **Ship Via** (method a, method b, method c, optional): Select the method of shipping from the list below.
	+ method a
	+ method b
	+ method c

### Other Ship Via
* **Other Ship Via** (text, optional): If the shipping method is not listed, please enter the method of shipping.
