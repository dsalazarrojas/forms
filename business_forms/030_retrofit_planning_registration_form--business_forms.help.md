# retrofit_planning_registration_form - Help Guide
## Purpose
This form is designed to collect information about a project's planning and registration.
## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Project Info" section with the project's details.
2. Provide the project manager's contact information, including their name, email, phone number, and address.
3. Select the project status (Active or Inactive).
4. Enter the project's start and end dates.
5. Enter the project's location.
6. Enter the project's budget.
7. Enter the project's status and location on a map.
8. Enter any additional comments or notes for the project manager.
9. Fill out the second project manager's contact information (optional).
10. Review and submit the form to complete the project registration.

## Field-by-Field Explanation

* **Project Info (project_info)**: Enter the project's title, description, or any other relevant details.
* **Project Manager (project_manager)**: Enter the project manager's name.
* **Project Manager Email (project_manager_email)**: Enter the project manager's email address.
* **Project Manager Phone (project_manager_phone)**: Enter the project manager's phone number.
* **Project Manager Address (project_manager_address)**: Enter the project manager's address.
* **Project Manager Contact Number (project_manager_contact_number)**: Enter the project manager's contact number.
* **Project Description (project_description)**: Enter a brief description of the project.
* **Project Status (project_status)**: Select the project status (Active or Inactive).
* **Project Location (project_location)**: Enter the project's location.
* **Project Start Date (project_start_date)**: Enter the project's start date.
* **Project End Date (project_end_date)**: Enter the project's end date.
* **Project Manager Notes (project_manager_notes)**: Enter any additional comments or notes for the project manager.
* **Project Manager Comments (project_manager_comments)**: Enter any additional comments for the project manager.
* **Project Location Map (project_location_map)**: Select whether the project location is on a map.
* **Project Budget (project_budget)**: Enter the project's budget.
* **Project Cost (project_cost)**: Enter the project's cost (optional).
* **Project Currency (project_currency)**: Enter the project's currency (optional).
* **Project Deadline (project_deadline)**: Enter the project's deadline (optional).
* **Second Project Manager (project_manager_2)**: This section is for backup or alternative contact methods for the project manager.
* **Second Project Manager Email (project_manager_email_2)**: Enter the second project manager's email address.
* **Second Project Manager Phone (project_manager_phone_2)**: Enter the second project manager's phone number.
* **Second Project Manager Address (project_manager_address_2)**: Enter the second project manager's address.
* **Second Project Manager Contact Number (project_manager_contact_number_2)**: Enter the second project manager's contact number.
* **Second Project Manager Notes (project_manager_notes_2)**: Enter any additional comments or notes for the second project manager.
* **Second Project Manager Comments (project_manager_comments_2)**: Enter any additional comments for the second project manager.
