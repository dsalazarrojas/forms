# Power Grid Failure Incident Form - Help Guide
## Purpose
This form is used to report and document power grid failures, providing a standardized structure for capturing essential details to improve response and recovery efforts.

## How To Complete This Form
1. Enter the date of the incident in the "Incident Date" field, using the format "YYYY-MM-DD".
2. Provide the location of the failure in the "Location" field.
3. Choose from the options for "Grid Failure Type" to select the type of failure that occurred.
4. If the grid was affected, select all applicable options for "Grid System".
5. Enter the number of customers impacted in the "Affected Customers" field.
6. Enter the estimated duration of downtime in the format "HH:MM:SS" in the "Estimated Downtime" field.
7. Indicate if the failure was reported by a "Yes/No" option.
8. Select the current status of the grid using the "Grid Status" options.
9. Provide a detailed description of the incident in the "Incident Description" field.
10. Explain the cause of the failure in the "Cause of Failure" field.
11. Document any recommended actions to take in the "Recommended Actions" field.
12. Document the resolution of the incident in the "Incident Resolution" field.
13. Indicate the current operational status of the grid using the "Grid Operational Status" options.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`): Enter the date of the incident, using the format "YYYY-MM-DD".
* **Location** (`location`): Enter the location where the power grid failure occurred.
* **Grid Failure Type** (`grid_failure_type`): Select the type of grid failure that occurred, such as "Yes" for a failure that resulted in a grid shutdown or "No" for a failure that did not affect the grid.
* **Grid System** (`grid_system`): If the grid was affected, select all applicable options that describe the system impacted, such as "Yes" for a failure that impacted the primary grid or "No" for a failure that did not affect the primary grid.
* **Affected Customers** (`affected_customers`): Enter the number of customers impacted by the power grid failure.
* **Estimated Downtime** (`estimated_downtime`): Enter the estimated duration of downtime in the format "HH:MM:SS" (e.g., "01:30:00" for one and a half hours).
* **Reported By** (`reported_by`): Indicate if the failure was reported by "Yes" or "No".
* **Grid Status** (`grid_status`): Select the current status of the grid using the options "Active" or "Inactive".
* **Incident Description** (`incident_description`): Provide a detailed description of the incident.
* **Cause of Failure** (`cause_of_failure`): Explain the root cause of the power grid failure.
* **Recommended Actions** (`recommended_actions`): Document any recommended actions to take to mitigate future failures.
* **Incident Resolution** (`incident_resolution`): Document the resolution of the incident.
* **Grid Operational Status** (`grid_operational_status`): Indicate the current operational status of the grid using the options "Active" or "Inactive".
