# Food Defense Assessment Template - Help Guide

## Purpose
The purpose of this form is to assess the food defense programs within your organization, evaluating the strengths and weaknesses, and identifying potential corrective actions.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the "Food Defense Program" field with a brief description of the food defense program you are assessing.
2. Enter the "Assessment Date" of when the assessment was conducted.
3. List the "Strengths" of the food defense program in the designated field.
4. Identify the "Weaknesses" of the food defense program in the designated field.
5. Answer the "Food Defense Measures" question by selecting "Yes" if the program has measures in place, and "No" if it does not.
6. Select all applicable "Control Measures" that the program has implemented.
7. Answer the "Training and Evaluation" question by selecting "Yes" if the program has training and evaluation in place, and "No" if it does not.
8. In the "Corrective Actions" field, describe any actions that the program has taken or plans to take to address the identified weaknesses.
9. In the "Follow-up Actions" field, describe any follow-up actions that the program has taken or plans to take to monitor and address any issues.
10. In the "Recommendations" field, provide any recommendations for improvement to the food defense program.
11. Use the "Additional Comments" field to provide any other relevant information or comments about the assessment.

## Field-by-Field Explanation

* **Food Defense Program**: A brief description of the food defense program being assessed.
	+ Type: text
	+ Required: false
* **Assessment Date**: The date when the assessment was conducted.
	+ Type: date
	+ Required: false
* **Strengths**: List the strengths of the food defense program.
	+ Type: text
	+ Required: false
* **Weaknesses**: Identify the weaknesses of the food defense program.
	+ Type: text
	+ Required: false
* **Food Defense Measures**: Answer "Yes" if the program has measures in place to address food defense, "No" if it does not.
	+ Type: select_one
	+ Required: false
* **Control Measures**: Select all applicable control measures implemented by the program.
	+ Type: select_multiple
	+ Required: false
* **Training and Evaluation**: Answer "Yes" if the program has training and evaluation in place, "No" if it does not.
	+ Type: select_one
	+ Required: false
* **Corrective Actions**: Describe any actions the program has taken or plans to take to address weaknesses.
	+ Type: text
	+ Required: false
* **Follow-up Actions**: Describe any follow-up actions the program has taken or plans to take to monitor and address any issues.
	+ Type: text
	+ Required: false
* **Recommendations**: Provide any recommendations for improvement to the food defense program.
	+ Type: text
	+ Required: false

	+ Type: text

## Tips
* Make sure to be as detailed as possible when describing strengths, weaknesses, corrective actions, follow-up actions, and recommendations.
* Use the "Food Defense Measures" and "Control Measures" fields to provide specific examples or details about what measures are in place.
* Select all applicable "Control Measures" that the program has implemented.
* Answer the "Training and Evaluation" question with a clear "Yes" or "No" to indicate whether the program has training and evaluation in place.
* Use the "Additional Comments" field to provide any additional information that may be relevant to the assessment.
