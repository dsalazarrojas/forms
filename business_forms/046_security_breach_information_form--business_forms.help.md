# security_breach_information_form - Help Guide
## Purpose
This form collects information about security breaches that have occurred within an organization. It is meant to be completed by the person responsible for reporting and managing the incident.

## How To Complete This Form
To complete this form, simply follow the instructions below for each section:

* Read through each section carefully before filling out the form.
* Answer all required fields (marked as "required" in the form).

## Field-by-Field Explanation

* **Introduction** (ID: 1, text, not required):
  This is a brief description of the incident.
* **Breach Details** (ID: 2, text, required):
  Describe the nature of the breach, including any relevant context.
* **Affected Entities** (ID: 3, select one, required):
  Select whether the breach affected entities within the organization, such as employees or customers.
* **Submitter** (ID: 4, select multiple, not required):
  Check who submitted the report, if desired.
* **Incident Date** (ID: 5, date, not required):
  Enter the date the incident occurred.
* **Incident Time** (ID: 6, time, not required):
  Enter the time the incident occurred.
* **Incident Location** (ID: 7, text, not required):
  Describe the location where the incident occurred, if applicable.
* **Breach Type** (ID: 8, select one, required):
  Select the type of breach, such as a data breach or a system breach.
* **Reporter** (ID: 9, select multiple, not required):
  Check who reported the incident, if desired.
* **Incident Impact Assessment** (ID: 10, number, not required):
  Enter an assessment of the impact of the incident, on a scale from 1 to 10.
* **Incident Impact Description** (ID: 11, text, not required):
  Describe the impact of the incident in more detail.
* **Discovered By** (ID: 12, select one, not required):
  Select whether the incident was discovered internally or externally.
* **Discovered By Role** (ID: 13, select one, not required):
  Select the role of the person or entity that discovered the breach.
* **Discovered By Entity** (ID: 14, select multiple, not required):
  Check which entities discovered the incident, if applicable.
* **Discovered Date** (ID: 15, date, not required):
  Enter the date the incident was discovered.
* **Confirmed Date** (ID: 16, date, not required):
  Enter the date the incident was confirmed.
* **Confirmed By** (ID: 17, select multiple, not required):
  Check who confirmed the incident.
* **Confirmed By Role** (ID: 18, select one, not required):
  Select the role of the person or entity that confirmed the incident.
* **Confirmed By Entity** (ID: 19, select multiple, not required):
  Check which entities confirmed the incident, if applicable.
* **Incident Description** (ID: 20, text, required):
  Describe the incident in more detail.
* **Incident Classification** (ID: 21, select one, required):
  Select the classification of the incident.
* **Incident Classification Description** (ID: 22, text, not required):
  Provide a more detailed description of the incident classification.
* **Incident Status** (ID: 23, select one, required):
  Select the status of the incident, such as Active or Inactive.
* **Incident Status Description** (ID: 24, text, not required):
  Provide a description of the incident status.
* **Incident Status Date** (ID: 25, date, not required):
  Enter the date the incident status was last updated.

## Tips

* Make sure to answer all required fields, as indicated by the "required" label.
* Review your answers before submitting the form to ensure accuracy.
* If you're unsure about any field, ask your supervisor or a colleague for guidance.
* Save the form regularly as you complete it to avoid losing progress.
* Submit the form when finished to ensure timely completion of the incident reporting process.
