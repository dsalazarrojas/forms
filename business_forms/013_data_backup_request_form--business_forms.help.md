# data_backup_request_form - Help Guide
## Purpose
The purpose of this form is to request data backup from the data management team. It helps the team determine the priority and scope of the backup request.

## How To Complete This Form

To complete this form, follow these steps:

* Select the correct answer for each field, and the form will guide you through the process.
* Make sure to fill in all the required fields.
* If a field is not required, you can skip it.

* **data_needs** (`data_needs`, select_multiple, required): Select all the data types that need to be backed up (e.g., files, system configurations, etc.). You can choose multiple options.
