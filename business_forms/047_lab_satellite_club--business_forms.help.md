# lab_sattellite_club - Help Guide
## Purpose
This form is used for creating and managing satellite clubs within a business. It allows users to input data related to satellite clubs, which will be used in conjunction with existing business systems.

## How To Complete This Form

1. Fill out the required fields: 
   * lab_satellite_club: Enter a title for the satellite club.
   * juices: Select one or multiple options for juices from the dropdown list.
   * order: Enter a numeric value for the order.
   * mobile_club: Enter a value for mobile_club.
2. Select options for teas from the dropdown list.
3. Review and submit the form for submission.

## Field-by-Field Explanation

* **lab_satellite_club**: `title` (text, required): Enter a title for the satellite club.
* **juices**: `select_multiple` (optional): Select one or multiple options from the dropdown list of juices available.
* **order**: `number` (optional): Enter a numeric value for the order.
* **mobile_club**: `text` (optional): Enter a value for mobile_club.
* **teas**: `select_one` (optional): Select one option from the dropdown list of teas available.
