# NEW Client App - Help Guide

## Purpose
This form is designed to collect information about a new client application. The form is used to gather essential details such as application title, category, description, and other relevant information. The collected data will be used to process and manage client applications effectively.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the title of the new client application in the "Application Title" field.
2. Select the category of the application from the provided options (Business Forms or Personal Forms).
3. Provide a brief description of the application in the "Description" field.
4. Enter any relevant output file information in the "Output File" field.
5. Specify the tool assigned to the application in the "Assigned Tool" field.
6. Enter any additional form IDs if necessary in the "Form IDs" fields.
7. Enter the date of the application in the "Date" field.
8. Enter the time of the application in the "Time" field.
9. Enter the email associated with the application in the "Email" field.
10. Enter the phone number associated with the application in the "Phone Number" field.
11. Provide any additional notes about the application in the "Notes" field.
12. Enter any additional form IDs if necessary in the "Form IDs 2" field.

## Field-by-Field Explanation
* **Application Title** (`application_title`, text, required):
	+ Enter a brief and descriptive title of the new client application.
* **Category** (`application_category`, select_one, required):
	+ Select the category of the application from the provided options (Business Forms or Personal Forms).
* **Description** (`description`, text, required):
	+ Provide a brief description of the application.
* **Output File** (`output_file`, text, required):
	+ Enter any relevant output file information.
* **Assigned Tool** (`assigned_tool`, text, required):
	+ Specify the tool assigned to the application.
* **Form IDs** (`form_ids`, number, required):
	+ Enter any additional form IDs.
* **Date** (`application_date`, date, required):
	+ Enter the date of the application.
* **Time** (`application_time`, time, required):
	+ Enter the time of the application.
* **Email** (`application_email`, email, required):
	+ Enter the email associated with the application.
* **Phone Number** (`application_phone`, text, required):
	+ Enter the phone number associated with the application.
* **Notes** (`notes`, note, required):
	+ Provide any additional notes about the application.
* **Form IDs 2** (`form_ids_2`, number, required):
	+ Enter any additional form IDs.
