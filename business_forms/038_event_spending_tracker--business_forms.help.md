# event_spending_tracker - Help Guide
## Purpose
The event_spending_tracker form is designed to track and record event-related expenses, providing a centralized platform for event organizers, coordinators, and financial managers to gather and manage essential information.

## How To Complete This Form
To complete the event_spending_tracker form, follow these steps:

1. Fill in the Event Title field with a brief and descriptive name of the event.
2. Provide a detailed description of the event in the Event Description field.
3. Record the event date and time using the Event Date and Event Time fields.
4. Enter the budget allocated for the event in the Budget Amount field.
5. Select the type of expense from the Expense Type field (e.g., Food, Travel, or Venue).
6. Enter the date and time of the expense using the Expense Date and Expense Time fields.
7. Enter the amount spent on the expense in the Expense Amount field.
8. Provide any additional information or notes about the expense in the Expense Note field.
9. If required, select the receipts to be attached to the expense in the Receipts field.
10. Finally, select the category of the expense from the Category field (e.g., Amenities, Food and Beverage, Transportation, or Miscellaneous).

## Field-by-Field Explanation
* **Event Title (text)**: Enter a brief and descriptive name for the event.
* **Event Description (text)**: Provide a detailed description of the event.
* **Event Date (date)**: Record the date of the event.
* **Event Time (time)**: Record the time of the event.
* **Budget Amount (number)**: Enter the budget allocated for the event.
* **Expense Type (select_one)**: Select the type of expense (e.g., Food, Travel, or Venue).
* **Expense Date (date)**: Record the date of the expense.
* **Expense Time (time)**: Record the time of the expense.
* **Expense Amount (number)**: Enter the amount spent on the expense.
* **Expense Note (note)**: Provide any additional information or notes about the expense.
* **Receipts (select_multiple)**: If required, select the receipts to be attached to the expense.
* **Category (select_one)**: Select the category of the expense (e.g., Amenities, Food and Beverage, Transportation, or Miscellaneous).
