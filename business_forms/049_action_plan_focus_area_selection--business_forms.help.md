# Action Plan Focus Area Selection - Help Guide
## Purpose
This form is designed to help users select and document a specific focus area and create an action plan for achieving a desired outcome.

## How To Complete This Form
1. Select the primary focus area you want to work on from the provided options.
2. Enter your participant name and job title or team name (optional).
3. Enter a brief objective statement that describes the goal for the selected focus area.
4. List the main actions to be taken to achieve the objective.
5. Enter any additional information on how success will be measured.
6. If applicable, select a target completion date and enter the person accountable for delivering results.
7. If applicable, enter any resources required to complete actions.
8. If applicable, list any stakeholders who should be consulted or informed.
9. Add any additional comments to support the plan.

## Field-by-Field Explanation

* **-- Focus area selection --** (`focus_selection_header`, note, not required): This is the title of the page.
* **Participant name** (`participant_name`, text, not required): Enter your name or a name to represent yourself.
* **Role** (`role`, text, not required): Enter your job title or team name.
* **Focus area** (`focus_area`, select_one, required): Select the primary focus area you want to work on.
* **Objective statement** (`objective_statement`, text, required): Enter a brief statement of the goal for the selected focus area.
* **Key actions** (`key_actions`, text, required): List the main actions to be taken to achieve the objective.
* **Success metrics** (`success_metrics`, text, not required): Enter how success will be measured.
* **Target date** (`target_date`, date, not required): Enter the target completion date for the objective.
* **Owner** (`owner`, text, required): Enter the person accountable for delivering results.
* **Resources required** (`resources_required`, text, not required): Enter any resources required to complete actions.
* **Stakeholder involvement** (`stakeholder_involvement`, text, not required): List stakeholders to be consulted or informed.
* **Additional comments** (`additional_comments`, text, not required): Enter any additional comments to support the plan.
