# Component Order Form For Manufacturers - Help Guide

## Purpose
This form is used to gather detailed information for a new order from a customer to a manufacturer.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the order details: Order ID, Order Date, Customer Name, Customer ID, and Company Name.
2. Enter the component details: Component Category, Component Part Number, and Component Description.
3. Provide shipping information: Shipping Address, City, State/Province, Postal Code, and Country.
4. Add any additional details: Quantity Ordered, Unit of Measure, Unit Price, and Specifications (if required).
5. Select the shipping method and payment terms.
6. Review and submit the form to place the order.

## Field-by-Field Explanation

* **Order ID**: A unique identifier for the order.
* **Order Date**: The date the order was placed.
* **Customer Name**: The name of the customer or organization placing the order.
* **Customer ID**: The customer's account number.
* **Company Name**: The name of the company placing the order.
* **Contact Person**: The primary contact person for this order.
* **Email Address**: The contact email for this order.
* **Phone Number**: The contact phone number for this order.
* **Shipping Address**: The address where the order should be shipped to.
* **City**: The city where the order should be shipped to.
* **State/Province**: The state or province where the order should be shipped to.
* **Postal Code**: The ZIP or postal code where the order should be shipped to.
* **Country**: The country where the order should be shipped to.
* **Component Category**: The category of the component being ordered (e.g., Electronic Components, Mechanical Components).
* **Component Part Number**: The manufacturer's part number for the component.
* **Component Description**: A detailed description of the component being ordered.
* **Quantity Ordered**: The number of units being ordered.
* **Unit of Measure**: The unit type (e.g., Each, Box, Case).
* **Unit Price**: The price per unit of the component.
* **Specifications**: Any technical specifications or requirements for the component (if required).
* **Quality Requirements**: Any special quality requirements for the component (e.g., Standard Quality, Enhanced Quality).
* **Delivery Date Required**: The date by which the order needs to be delivered.
* **Shipping Method**: The preferred shipping method (e.g., Standard Ground, Express 2-Day).
* **Payment Terms**: The payment terms for the order (e.g., Net 30, Net 60).
* **Purchase Order Number**: The customer's purchase order number.
* **Special Instructions**: Any special handling or delivery instructions.
* **Order Status**: The current status of the order (e.g., Pending Approval, Approved, In Production, Ready to Ship, Shipped, Delivered, Cancelled).

Please review the form carefully and ensure all required fields are filled in before submitting it for processing.
