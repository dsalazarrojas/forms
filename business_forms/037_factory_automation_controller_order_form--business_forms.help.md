# factory_automation_controller_order_form - Help Guide
## Purpose
The factory automation controller order form is a crucial tool for factory administrators to order and manage factory automation controllers.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of factory automation controller you need to order.
2. Enter the number of units you require.
3. Provide the serial number of the controller (if known).
4. Choose the shipping location.
5. Enter your contact information: name, phone number, and email address.
6. Add any additional notes for the order.
7. Specify any assigned tools or users for the order.

## Field-by-Field Explanation
* **Factory Automation Controller Type (`controller_type`)**: Select the type of factory automation controller you need to order.
* **Number of Units (`quantity`)**: Enter the total number of units you require.
* **Serial Number (`serial_number`)**: Enter the serial number of the controller (if known).
* **Shipping Location (`shipping_location`)**: Choose the location where the controller should be shipped.
* **Contact Name (`contact_name`)**: Enter your name so we can contact you regarding the order.
* **Contact Phone (`contact_phone`)**: Enter your phone number so we can contact you regarding the order.
* **Contact Email (`contact_email`)**: Enter your email address so we can contact you regarding the order.
* **Notes (`notes`)**: Add any additional information or comments about the order.
* **Assigned Tool (`assigned_tool`)**: Specify any tools or equipment that are assigned to the order.
* **Assigned User (`assigned_user`)**: Specify the user or team member who will be using the controller.
* **Form ID (`form_id`)**: A unique identifier for the form, not to be completed by the user.

## Tips
* Be sure to double-check your answers carefully before submitting the form.
* If you're unsure about any field, please contact the factory automation team for guidance.
* This form is not intended for ordering other non-automation equipment. Use the correct order form for that specific item.
