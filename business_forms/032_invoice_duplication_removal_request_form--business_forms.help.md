# Invoice Duplication Removal Request Form - Help Guide
## Purpose
To report and request removal of duplicate invoices that have been incorrectly processed or mistakenly created.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Click on the "Report Duplicates" field (Page 1) and enter a detailed description of the issue.
2.  If you have supporting documents related to the issue, you can upload them to provide more context.
3.  Select one or more review requests from the "Review Requests" section, depending on the specific situation.
4.  Provide relevant information about the customer and vendor involved.
5.  In case of conflicting information, select the correct option from "Review Request 1", "Review Request 2", and "Review Request 3".
6.  Finally, submit your form.

## Field-by-Field Explanation
- **Report Duplicates** (`invoice_deduction_request`, `text`, optional): Enter a detailed description of the issue, including any relevant details or context about the duplicate invoices.
- **Upload Documents** (`supporting_documents`, `note`, optional): If available, upload documents that support your request for invoice duplication removal.
- **Centralize Review Request** (`review_request`, `select_multiple`, optional): Select one or more review requests that relate to the issue.
- **Review Requests** (`review_requests`, `select_multiple`, optional): Select the specific review requests that need to be reviewed in relation to the duplicate issue.
- **Customer Info** (`customer_info`, `note`, optional): Provide information about the customer involved in the issue.
- **Vendor Info** (`vendor_info`, `note`, optional): Provide information about the vendor involved in the issue.
- **Finance Info** (`finance_info`, `note`, optional): Provide any additional financial information related to the issue.
- **Review Request 1** (`review_request_1`, `select_one`, optional): Select the correct option from the conflicting information related to the issue.
- **Review Request 2** (`review_request_2`, `select_one`, optional): Select the correct option from the conflicting information related to the issue.
- **Review Request 3** (`review_request_3`, `select_one`, optional): Select the correct option from the conflicting information related to the issue.
