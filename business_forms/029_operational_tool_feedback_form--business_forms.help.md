# operational_tool_feedback_form - Help Guide
## Purpose
The operational tool feedback form is used to collect suggestions, questions, and feedback from users about the operational tool.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Select the "What type of feedback" field from the dropdown menu.
2.  Enter your question or feedback in the "Question" field.
3.  Provide a brief description of your feedback in the "Description" field.
4.  Rate your satisfaction with the operational tool using the "Rating" field.
5.  If you have any additional comments, please enter them in the "Comments" field.
6.  Enter your email address in the "Email" field so that we can contact you if needed.

## Field-by-Field Explanation

*   **Operational Tool** (`tool_id`, number, required: false): This field is not currently used in the form.
*   **What type of feedback** (`feedback_type`, select_one, required: false): Please select from the dropdown menu: "Feedback", "Suggestions", or "Questions".
*   **Question** (`question`, text, required: false): Enter a specific question you have about the operational tool.
*   **Description** (`description`, text, required: false): Provide a brief description of your feedback to help us understand your thoughts.
*   **Rating** (`rating`, number, required: false): Rate your satisfaction with the operational tool on a scale of 1-5.
*   **Comments** (`comments`, text, required: false): Enter any additional comments you have about the operational tool.
*   **Email** (`email`, email, required: false): Enter your email address so that we can contact you if needed.

## Tips

*   Please ensure that you have already read the form instructions before submitting your feedback.
*   Be as specific as possible when providing feedback or questions to help us improve the operational tool.
*   If you have already submitted feedback for this tool, please do not submit again.
*   If you are not sure about any of the fields, you can leave them blank or enter a question mark (\?) to indicate that you are unsure.
