# document_archiving_checklist - Help Guide
## Purpose
This form is used to record and verify the archiving of documents according to company standards.

## How To Complete This Form
1. Select the type of document(s) you are archiving (e.g., document-type).
2. Enter the date the document was archived (date_archived).
3. Choose the storage location of the archived document (storage_location).
4. Indicate the period of time the document is to be retained (retention_period) and select the unit of time (retention_period_unit).
5. Specify any access restrictions on the document (access_restrictions) and provide a clear description if selecting 'Other' (access_restrictions_other).
6. Identify the status of the document (document_status).
7. Confirm the start date of the retention period (retention_start_date).

## Field-by-Field Explanation
* **Document Type** (`Document Type`, Select Multiple, Required): Choose the type of document you are archiving (e.g., document-type, Other).
* **Date Archived** (`Date Archived`, Date, Required): Enter the date the document was archived.
* **Storage Location** (`Storage Location`, Select One, Required): Select the location where the document is stored.
* **Retention Period** (`Retention Period`, Number, Required): Specify the number of days, months, or years the document is to be retained.
* **Access Restrictions** (`Access Restrictions`, Select One, Required): Choose the access restrictions applicable to the document (e.g., access-restrictions, Other).
* **Storage Media** (`Storage Media`, Select Multiple, Optional): If necessary, choose the type of storage media used for the document (e.g., storage-media, Other). 
* **Document Status** (`Document Status`, Select One, Required): Identify the current status of the document.
* **Retention Period Unit** (`Retention Period Unit`, Select One, Required): Choose the unit of time for the retention period (e.g., days, months, years).
* **Retention Start Date** (`Retention Start Date`, Date, Required): Enter the start date of the retention period.
* **Other Access Restriction** (`Other Access Restriction`, Note, Required): Provide a clear description of any other access restrictions applicable to the document (if not selecting 'access-restrictions').
