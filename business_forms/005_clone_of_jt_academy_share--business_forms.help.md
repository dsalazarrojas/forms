# Clone Of JT ACADEMY Share - Help Guide
## Purpose
This form is used to request access to materials and courses from JT ACADEMY, ensuring that sharing is done following a set of predefined conditions. It helps the requester provide necessary information about the resource and its intended use.

## How To Complete This Form
To complete this form, please follow the following steps:

* Fill in your name and contact email in the required fields (Requester name and Requester email).
* Provide the full name of the course or document you wish to access (Academy resource).
* Specify the purpose of your request (Purpose of use).
* If applicable, choose the estimated number of expected viewers or participants (Estimated audience size).
* Confirm whether sharing is permitted outside the organization (Permission to share externally).
* Optionally, choose the preferred format for the shared resource (Preferred format).
* Set a date by which the resource is required (Required by date).
* Any additional notes about the request (Additional notes).

## Field-by-Field Explanation
* **Requester name** (`requester_name`, text, required): Fill in the full name of the person requesting access to the material.
* **Requester email** (`requester_email`, email, required): Enter the contact email of the person requesting access to the material.
* **Academy resource** (`academy_resource`, text, required): Provide the full name of the course or document you wish to access.
* **Purpose of use** (`purpose_of_use`, text, optional): Briefly explain the intended use of the requested material.
* **Estimated audience size** (`audience_size`, number, optional): Enter the estimated number of expected viewers or participants.
* **Permission to share externally** (`share_permission`, select_one, required): Select whether sharing is permitted outside the organization.
* **Preferred format** (`preferred_format`, select_one, optional): Choose the desired format for the shared resource (PDF, Slide deck, Video, Other).
* **Required by date** (`required_by_date`, date, optional): Set a date by which the resource is required.
* **Additional notes** (`additional_notes`, text, optional): Include any further information about the request.

## Tips

* If you're unsure about any field, don't hesitate to contact us for assistance.
* Be as detailed as possible when providing information to ensure a smooth evaluation process.
* Ensure you provide the correct format for the requested resource.
* Check if the requested resource is already available or if a similar request has been made before filling this form to avoid duplication.
