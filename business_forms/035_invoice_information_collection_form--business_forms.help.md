# Invoice Information Collection Form - Help Guide
## Purpose
This form is used to collect important information about the customer or client for invoicing purposes. It helps the user to provide necessary details about the client, their billing address, and contact information, as well as any payment terms agreed upon.

## How To Complete This Form
To complete this form, follow these steps:

*   Start by filling out the fields as required and in the order provided.
*   Ensure that all required fields are completed before proceeding.
*   Use the correct format for each field type (e.g., email for the email field).
*   Review the form carefully before submission to avoid any errors.

## Field-by-Field Explanation

*   **Client Name** (`client_name`, text, optional): Enter the name of the client or customer.
*   **Billing Address** (`billing_address`, text, optional): Enter the address of the client's billing location.
*   **Billing City** (`billing_city`, text, optional): Enter the city where the client is located.
*   **Billing State** (`billing_state`, text, optional): Enter the state where the client is located.
*   **Billing Postal Code** (`billing_postal_code`, text, optional): Enter the postal code or zip code of the client's billing address.
*   **Contact Number** (`contact_number`, text, optional): Enter the contact number of the client for communication.
*   **Email** (`email`, email, optional): Enter the email of the client for communication.
*   **Payment Terms** (`payment_terms`, select_multiple, optional): Choose the payment terms agreed upon with the client (e.g., Net 30 days, Net 60 days, Net 90 days).

## Tips

*   Double-check the form for any errors or missing fields before submission.
*   Use the correct format for each field type to avoid any validation errors.
*   If you're unsure about any field or its requirements, refer to the internal documentation for guidance.
