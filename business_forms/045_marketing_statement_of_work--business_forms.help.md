# marketing_statement_of_work - Help Guide
## Purpose
This form is used to create a Marketing Statement of Work for a project.

## How To Complete This Form

1. Start by filling out the **Project Details** field. This field should include a brief description of the project.
2. Next, fill out the **Project Scope** field. This field should describe the specific objectives and deliverables of the project.
3. In the **Deliverables** field, select all the deliverables that apply to your project. A deliverable is a specific item or outcome that will be delivered as a result of the project.
4. Set a **Timeline** for your project by selecting the expected start and end dates.
5. Enter the **Budget** for your project.
6. If your project has a **Team Lead**, indicate this in the field. A Team Lead is responsible for overseeing the project.
7. If your project has a **Project Manager**, enter their contact information.
8. If your project has a **Marketing Manager**, enter their contact information.
9. If your project has a **Sales Manager**, enter their contact information.
10. Finally, fill out the **Customer** field with the name of the customer.
11. Enter the **Customer Email** of the customer.
12. Enter the **Customer Phone** of the customer.
13. If your project has a **Project Manager**, enter their email address and phone number.
14. Finally, fill out the **Project Status** field with a brief description of the current status of your project.

## Field-by-Field Explanation

* **Project Details** (Project Details, text, required): A brief description of the project.
* **Project Scope** (Project Scope, text, required): A description of the specific objectives and deliverables of the project.
* **Deliverables** (Deliverables, select multiple, required): Select all the deliverables that apply to your project.
* **Timeline** (Timeline, date, required): The expected start and end dates of the project.
* **Budget** (Budget, number, required): The budget for your project.
* **Team Lead** (Team Lead, select one, required): Indicate if your project has a Team Lead.
* **Project Manager** (Project Manager, text, optional): Enter the contact information for the Project Manager.
* **Marketing Manager** (Marketing Manager, text, optional): Enter the contact information for the Marketing Manager.
* **Sales Manager** (Sales Manager, text, optional): Enter the contact information for the Sales Manager.
* **Customer** (Customer, text, optional): The name of the customer.
* **Customer Email** (Customer Email, email, required): The email address of the customer.
* **Customer Phone** (Customer Phone, text, optional): The phone number of the customer.
* **Project Manager Email** (Project Manager Email, email, optional): The email address of the Project Manager.
* **Project Manager Phone** (Project Manager Phone, text, optional): The phone number of the Project Manager.
* **Project Status** (Project Status, text, optional): A brief description of the current status of your project.
