# Competency Assessment Form - Help Guide
## Purpose
This form is designed to assess an employee's competencies and identify areas for development. It helps managers evaluate an employee's technical skills, communication, teamwork, problem-solving, leadership, adaptability, time management, customer focus, and overall competency. The assessment results will inform the employee's development plan and help them grow professionally.

## How To Complete This Form

To fill out this form, follow these steps:

1. Select the date of the assessment in the "Assessment Date" field.
2. Enter the employee's name, employee ID, current job title, and department.
3. Choose the type of assessment being conducted (e.g., annual review, promotion consideration, performance improvement, etc.).
4. Rate the employee's technical skills, communication, teamwork, problem-solving, leadership, adaptability, time management, and customer focus using the provided scale.
5. Provide specific comments for each competency, if applicable.
6. Select the overall competency rating and indicate the employee's key strengths and areas for development.
7. Add any recommended development plans or employee comments.

## Field-by-Field Explanation

* **Assessment Date** (`assessment_date`, date, required): Enter the date of the assessment.
* **Employee Name** (`employee_name`, text, required): Enter the full name of the employee being assessed.
* **Employee ID** (`employee_id`, number, required): Enter the employee's identification number.
* **Job Title** (`job_title`, text, required): Enter the employee's current job title.
* **Department** (`department`, select_one, required): Choose the employee's department.
* **Manager Name** (`manager_name`, text, required): Enter the name of the assessing manager.
* **Time in Current Role** (`tenure_in_role`, select_one, required): Select how long the employee has been in their current role.
* **Type of Assessment** (`assessment_type`, select_one, required): Choose the purpose of this assessment (e.g., annual review, promotion consideration, etc.).
* **Technical Skills Rating** (`technical_skills_rating`, select_one, required): Rate the employee's technical skills using the provided scale.
* **Technical Skills Comments** (`technical_skills_comments`, text, optional): Provide specific comments on the employee's technical skills.
* **Communication Rating** (`communication_rating`, select_one, required): Rate the employee's communication skills using the provided scale.
* **Communication Comments** (`communication_comments`, text, optional): Provide specific comments on the employee's communication skills.
* **Teamwork Rating** (`teamwork_rating`, select_one, required): Rate the employee's teamwork and collaboration using the provided scale.
* **Teamwork Comments** (`teamwork_comments`, text, optional): Provide specific comments on the employee's teamwork and collaboration.
* **Problem Solving Rating** (`problem_solving_rating`, select_one, required): Rate the employee's problem-solving and analytical skills using the provided scale.
* **Problem Solving Comments** (`problem_solving_comments`, text, optional): Provide specific comments on the employee's problem-solving and analytical skills.
* **Leadership Rating** (`leadership_rating`, select_one, required): Rate the employee's leadership skills using the provided scale (or select "Not applicable" if not applicable).
* **Leadership Comments** (`leadership_comments`, text, optional): Provide specific comments on the employee's leadership skills.
* **Adaptability Rating** (`adaptability_rating`, select_one, required): Rate the employee's adaptability and flexibility using the provided scale.
* **Adaptability Comments** (`adaptability_comments`, text, optional): Provide specific comments on the employee's adaptability and flexibility.
* **Time Management Rating** (`time_management_rating`, select_one, required): Rate the employee's time management and organization skills using the provided scale.
* **Time Management Comments** (`time_management_comments`, text, optional): Provide specific comments on the employee's time management and organization skills.
* **Customer Focus Rating** (`customer_focus_rating`, select_one, required): Rate the employee's customer service orientation using the provided scale (or select "Not applicable" if not applicable).
* **Customer Focus Comments** (`customer_focus_comments`, text, optional): Provide specific comments on the employee's customer service orientation.
* **Overall Competency Rating** (`overall_competency_rating`, select_one, required): Rate the employee's overall competency using the provided scale.
* **Key Strengths** (`key_strenghts`, text, required): Identify the employee's key strengths demonstrated.
* **Areas for Development** (`development_areas`, text, required): Identify the employee's areas for development.
* **Recommended Development Plan** (`development_plan`, text, optional): Suggest development actions for the employee.
* **Employee Comments** (`employee_comments`, text, optional): Allow the employee to provide comments.
* **Next Review Date** (`next_review_date`, date, optional): Enter the date of the next review.
