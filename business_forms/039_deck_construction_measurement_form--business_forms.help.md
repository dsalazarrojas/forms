# Deck Construction Measurement Form - Help Guide

## Purpose
This form is designed to collect essential information about a deck construction project. It will help us understand the site details, dimensions, material preferences, and other important aspects of the project.

## How To Complete This Form
To complete this form, follow these steps:
1. Start by selecting the site details (Page 1: Site Details).
2. Select the dimensions of the deck (Page 2: Dimensions).
3. Choose your preferred deck material and any additional features you'd like to include (Page 3: Material Preferences).
4. Upload up to three site photos to help us better understand the site (Page 4: Site Photos).
5. Specify the deck's location and orientation (Page 5: Deck Location and Page 6: Deck Orientation).
6. Choose the type of deck you'd like to construct (Page 6: Deck Type).
7. Provide the site address (Page 8: Site Address).
8. Add any additional information about the project (Page 9: Additional Information).
9. If applicable, select any additional features for the deck (Page 10: Deck Features).
10. Specify the deck's size (Page 12: Deck Size).
11. Finally, provide any additional information or comments about the project (Page 13: Additional Info 2 and Page 14: None).

## Field-by-Field Explanation

* **Site Details (Page 1)** (`site_details`, `text`, required): Enter the site details, such as the site address, to help us understand the project context.
* **Dimensions (Page 2)** (`dimensions`, `select_multiple`, required): Select the length and width of the deck in feet to help us calculate the deck's area.
* **Dimensions (Page 2)** (`dimensions`, `select_multiple`, required): Select the height of the deck in feet to help us calculate the deck's volume.
* **Material Preferences (Page 3)** (`material_preferences`, `checkbox`, required): Choose the preferred deck material, such as Wooden Deck or Composite Deck.
* **Site Photos (Page 4)** (`site_photos`, `select_multiple`, required): Upload up to three site photos to help us better understand the site's layout and features.
* **Deck Location (Page 5)** (`deck_location`, `radio`, required): Specify the deck's location, such as North, South, East, or West.
* **Deck Type (Page 6)** (`deck_type`, `select_one`, required): Choose the type of deck you'd like to construct, such as Wooden Deck or Composite Deck.
* **Deck Orientation (Page 6)** (`deck_orientation`, `select_one`, required): Specify the deck's orientation, such as North-South or East-West.
* **Site Address (Page 8)** (`site_address`, `text`, required): Enter the site address to help us understand the project's location.
* **Additional Information (Page 9)** (`additional_info`, `text`, optional): Provide any additional information about the project.
* **Deck Features (Page 10)** (`deck_features`, `select_multiple`, optional): Select any additional features you'd like to include in the deck, such as a built-in bench or planter.
* **Deck Size (Page 12)** (`deck_size`, `select_multiple`, required): Select the length and width of the deck in feet to help us calculate the deck's area.
* **Additional Info 2 (Page 13)** (`additional_info_2`, `text`, optional): Provide any additional information about the project.
* **None (Page 14)** (`none`, `text`, optional): This field is not currently used in the project.

Note: The fields marked as "optional" are not required to be filled out, but providing more information can help us better understand your project needs.
