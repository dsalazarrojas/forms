# Capital Project Request Form - Help Guide
## Purpose
This form is used to request capital projects that align with the organization's strategic goals and objectives.

## How To Complete This Form
1. Fill out the form completely, including all required fields.
2. Provide a clear and concise description of the project and its justification.
3. Ensure that all fields are accurate and up-to-date.

## Field-by-Field Explanation
* **First Name** (`First Name`, text, required): Enter your first name.
* **Last Name** (`Last Name`, text, required): Enter your last name.
* **Email Address** (`Email Address`, email, required): Enter your email address.
* **Phone Number** (`Phone Number`, text, required): Enter your contact phone number.
* **Department** (`Department`, text, required): Enter your department name.
* **Direct Manager** (`Direct Manager`, text, required): Enter your manager's name.
* **Request Date** (`Request Date`, date, required): Enter the date of the request.
* **Project Name** (`Project Name`, text, required): Enter the official project name.
* **Project Description** (`Project Description`, text, required): Enter a detailed description of the project.
* **Project Type** (`Project Type`, select one, required): Select the project type from the dropdown list.
* **Strategic Alignment** (`Strategic Alignment`, text, required): Explain how the project aligns with the organization's goals.
* **Business Justification** (`Business Justification`, text, required): Explain why the project is needed.
* **Expected Benefits** (`Expected Benefits`, text, required): Describe the anticipated benefits of the project.
* **Expected Return on Investment (ROI)** (`Expected Return on Investment (ROI)`, text, required): Enter the percentage or dollar amount of the expected ROI.
* **Payback Period** (`Payback Period`, text, required): Enter the estimated payback period in months or years.
* **Risk Mitigation Strategy** (`Risk Mitigation Strategy`, text, required): Describe how risks will be managed.
* **Capital Cost** (`Capital Cost`, number, required): Enter the dollar amount for assets.
* **Annual Operational Cost** (`Annual Operational Cost`, number, required): Enter the ongoing costs.
* **Total Cost of Ownership** (`Total Cost of Ownership`, number, required): Enter the total cost of ownership over the project life.
* **Cost Breakdown** (`Cost Breakdown`, text, required): Itemize the costs.
* **Contingency Amount** (`Contingency Amount`, number, optional): Enter a buffer for cost overruns.
* **Proposed Funding Source** (`Proposed Funding Source`, select one, required): Select the source of funding for the project.
* **Planned Start Date** (`Planned Start Date`, date, required): Enter the planned start date for the project.
* **Planned End Date** (`Planned End Date`, date, required): Enter the planned end date for the project.
* **Critical Milestones** (`Critical Milestones`, text, optional): Enter key project milestones.
* **Project Urgency Level** (`Project Urgency Level`, select one, required): Select the project's urgency level.
* **Alternatives Evaluated** (`Alternatives Evaluated`, text, required): Explain the alternatives considered.
* **Why Selected Solution is Best** (`Why Selected Solution is Best`, text, required): Compare the selected solution to alternatives.
* **Budget Director Approval Status** (`Budget Director Approval Status`, select one, required): Select the status of budget director approval.
