# design_thinking_toolkit_requisition_form - Help Guide
## Purpose
The design thinking toolkit requisition form is a tool used to request resources and materials for design projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately with the required information.
2. Make sure to select the correct options for each field.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **form_data**: This field is used to enter any additional information about the project.
* **project_title**: Enter the title of the project.
* **team_members**: Select the members of your team that are working on the project.
* **design_tools_requested**: Select all the design tools that you need for the project.
* **tool_quantity**: Enter the quantity of each tool that you need.
* **material_requests**: Enter any material requests that you need for the project.
* **collaboration_platform**: Select the collaboration platform that you will be using for the project.
* **resource_allocation**: Enter any resource allocation that you need for the project.
* **project_manager**: Select the project manager who will be overseeing the project.
* **team_lead**: Select the team lead who will be leading the project.
* **priority**: Select the priority of the project.
* **due_date**: Enter the due date for the project.
* **assigned_to**: Select the person who will be assigned to the project.
* **comments**: Enter any comments or notes about the project.
* **form_completed**: Select whether the form has been completed.
* **project_status**: Select the status of the project.
* **project_description**: Enter a brief description of the project.
* **resource_request**: Enter any resource requests that you need for the project.
* **form_reviewed**: Select whether the form has been reviewed.
* **project_tags**: Enter any tags or keywords that describe the project.
* **project_notes**: Enter any additional notes about the project.
* **collaboration_platform**: Enter the collaboration platform that you will be using for the project.
* **resource_request_date**: Select the date of the resource request.
* **team_lead_notes**: Enter any notes from the team lead.
* **project_status_notes**: Enter any additional notes about the project status.
* **resource_request_date**: Enter the date of the resource request.

Note: Some fields on this form may have more detailed explanations or specific guidance provided by the project manager or team lead. If you are unsure about any field, please reach out to them for further clarification.
