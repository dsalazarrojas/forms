# Workflow Configuration Form - Help Guide
## Purpose
This form is used to create or edit a workflow configuration.
## How To Complete This Form
Please follow the steps below to complete this form:

1.  Select the type of business process being configured using the "Business form" field.
2.  Enter a name for the workflow in the "Workflow name" field.
3.  Add a description for the workflow in the "Description" field.
4.  Specify the start date for the workflow in the "Start date" field.
5.  Specify the end date for the workflow in the "End date" field.
6.  Enter a unique ID for the workflow in the "Form ID" field.
7.  Select the status of the workflow from the options provided in the "Workflow status" field.
8.  (Optional) Select one or more users who will be assigned to the workflow in the "Assignee" field.
9.  (Optional) Add any additional comments or notes about the workflow in the "Notes" field.
10. (Optional) Enter an email address for contact purposes in the "Email address" field.
11. (Optional) Enter a phone number for contact purposes in the "Phone number" field.

*   **Business form** (`business_form`, Number, Required): 
    This field specifies the type of business process being configured.
*   **Workflow name** (`workflow_name`, Text, Required): 
    Enter a name for the workflow.
*   **Description** (`description`, Text, Optional): 
    Add a description for the workflow, providing more information about its purpose and scope.
*   **Start date** (`start_date`, Date, Required): 
    Specify the start date for the workflow.
*   **End date** (`end_date`, Date, Required): 
    Specify the end date for the workflow.
*   **Form ID** (`form_id`, Number, Required): 
    Enter a unique ID for the workflow.
*   **Workflow status** (`workflow_status`, Select One, Required): 
    Select the status of the workflow: Draft, Review, or Published.
*   **Assignee** (`assignee`, Select Multiple, Optional): 
    Select one or more users who will be assigned to the workflow.
*   **Notes** (`notes`, Note, Optional):

*   **Email address** (`email_address`, Email, Optional):

*   **Phone number** (`phone_number`, Text, Optional):
