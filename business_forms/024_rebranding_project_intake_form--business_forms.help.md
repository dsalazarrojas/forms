# rebranding_project_intake_form - Help Guide
## Purpose
The rebranding_project_intake_form is a form used to collect information about a rebranding project. This form gathers essential details about the client, project, and project status to ensure accurate and efficient processing of the rebranding project. Please fill out this form to start the rebranding process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: Project Name, Rebranding Services, Project Status, and Rebranding Status.
2. Enter the client's name and contact information (Client Email and Client Phone) if applicable.
3. Provide a brief description of the project.
4. Select the start and end dates for the project.
5. Specify the budget for the project.
6. Add any relevant notes about the client or project.

## Field-by-Field Explanation
### 1. **Client Name** (text, required: false)
Enter the name of the client.

### 2. **Project Name** (text, required: false)
Enter the name of the project.

### 3. **Description** (text, required: false)
Provide a brief description of the project.

### 4. **Start Date** (date, required: false)
Select the start date for the project.

### 5. **End Date** (date, required: false)
Select the end date for the project.

### 6. **Budget** (number, required: false)
Specify the budget for the project.

### 7. **Client Email** (email, required: false)
Enter the client's email address, if applicable.

### 8. **Client Phone** (text, required: false)
Enter the client's phone number, if applicable.

### 9. **Client Note** (note, required: false)
Add any additional notes about the client.

### 10. **Project Note** (note, required: false)
Add any additional notes about the project.

### 11. **Rebranding Services** (select multiple, required: true)
Select the rebranding services needed for the project:

* Service 1
* Service 2
* Service 3

### 12. **Project Status** (select one, required: true)
Select the current status of the project:

* Active
* Inactive

### 13. **Rebranding Status** (select one, required: true)
Select the current status of the rebranding project:

* In Progress
* Complete
* Cancelled
