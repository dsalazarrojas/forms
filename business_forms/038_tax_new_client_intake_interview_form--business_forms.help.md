# Tax New Client Intake Interview Form - Help Guide
## Purpose
The Tax New Client Intake Interview Form is designed to gather essential information from new clients for tax purposes, ensuring accurate and efficient tax filing. This form is used to verify income, employment status, and other relevant details to facilitate tax processing.

## How To Complete This Form
1. Review the form carefully and understand each section's purpose.
2. Answer all questions honestly and accurately, using the provided options or text fields as necessary.
3. Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **New Client Info**: This field is used to collect basic information about the new client. Please provide a brief description of the client's employment status and any other relevant details.
* **Personal Info**: Enter the client's personal information, such as name, address, and phone number.
* **Contact Info**: Provide the client's contact information, including phone number and email.
* **Employment Info**: Describe the client's employment status, including job title, employer, and employment duration.
* **Benefits Info**: Explain the client's benefits status, such as health insurance, retirement plans, and other relevant benefits.
* **Employment Status**: Select one of the options to indicate the client's current employment status.
* **Income Info**: Enter the client's income details, including salary or wage, and any other relevant income sources.
* **Income Verification**: Verify the client's income using the provided options or upload documentation as required.
* **Tax Filing Status**: Select one of the options to indicate the client's tax filing status.
* **Tax Year**: Enter the tax year related to the client's income or employment.
* **Tax Return**: Describe the tax return related to the client's income or employment status.
* **Tax Return Date**: Enter the date the tax return was filed or is due.
* **Tax Return Status**: Select one of the options to indicate the current tax return status.
* **Tax Return Date Range**: Select the range of dates the tax return applies to.
* **Employment Agreement**: Select one of the options to indicate the client's employment agreement status.
* **Benefit Agreement**: Select one of the options to indicate the client's benefit agreement status.
* **Termination Agreement**: Select one of the options to indicate the client's termination agreement status.
* **Client Interview Info**: Provide a brief description of the client's interview details.
* **Interview Notes**: Enter any additional interview notes or comments.
* **Notes**: Enter any additional notes about the client's information.
* **Tax Return Signed**: Select one of the options to indicate whether the tax return has been signed.
* **Review Status**: Select one of the options to indicate the review status of the client's information.
* **Review Comments**: Enter any review comments or feedback.
* **Reviewer Notes**: Enter any reviewer's notes or comments.
* **Review Date**: Enter the date the review was completed.
* **Notes**: Enter any additional notes or comments about the review process.
