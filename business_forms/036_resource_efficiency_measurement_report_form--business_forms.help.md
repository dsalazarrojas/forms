# Resource Efficiency Measurement Report Form - Help Guide
## Purpose
This form is used to measure the efficiency of resources within an organization. It helps track and document the usage and impact of various resources, allowing for data-driven decisions to be made.

## How To Complete This Form

1. Review the form carefully and ensure you are familiar with each field.
2. Answer each question accurately and truthfully.
3. Ensure all required fields are filled in before submitting the form.

## Field-by-Field Explanation

* **Resource Efficiency Measurement Report**: This is the title of the form, serving as a header for the rest of the form.
* **Resource Use Category**: This field is used to indicate whether the resource was used or not (`Yes` or `No`). It's a quick way to categorize resources.
* **Resource Use Description**: Provide a brief description of how the resource was used. This is a free text field for you to describe the context of the usage.
* **Resource Use Location**: This field is used to indicate where the resource was used (`Yes` or `No`). However, this label could be more specific and clear.
* **Time Spent**: Enter the actual time spent on using the resource, if applicable.
* **Resource Usage Measurement**: This field is used to determine if the resource usage was measured (`Yes` or `No`).
* **Resource Use Efficiency**: Indicate whether the resource usage was efficient (`Yes` or `No`).
* **Resource Use Cost**: Determine if the resource usage resulted in any cost (`Yes` or `No`).
* **Resource Use Savings**: Identify any savings or benefits gained from using the resource (`Yes` or `No`).
* **Resource Use Impact**: Specify the impact of the resource usage on the organization or project (`Yes` or `No`).
* **Resource Use Recommendations**: Provide any suggestions or recommendations for future resource allocation or usage.
* **Resource Use Comments**: Add any additional comments or observations about the resource usage.
* **Date**: Enter the date the report was submitted.
* **Time**: Enter the time the report was submitted.
* **Category**: This field is used to indicate the category of the resource usage (`Yes` or `No`). However, it's unclear what it's referring to.
* **Submitted By**: Indicate who submitted the report (`Yes` or `No`). It would be clearer if this field referred to the person who submitted the report.
* **Submitted To**: Identify who the report was submitted to (`Yes` or `No`). Similar to "submitted By", it would be more specific if it referred to the recipient of the report.
* **Submitted Date**: Enter the date the report was submitted.
* **Submitted Time**: Enter the time the report was submitted.
* **Organisation**: Provide the name of the organization or department related to the resource usage.
* **Department**: Enter the department related to the resource usage.
* **Division**: Enter the division related to the resource usage.
* **Job Function**: Enter the job function related to the resource usage.

Please note that some fields could be more clearly labeled or defined, and some redundancy might be removed for a more streamlined experience. This guide is a starting point to help users understand the form's purpose and usage.
