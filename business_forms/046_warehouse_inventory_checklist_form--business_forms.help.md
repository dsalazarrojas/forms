# Warehouse Inventory Checklist Form - Help Guide
## Purpose
The Warehouse Inventory Checklist Form is used by authorized personnel to quickly assess the current state of the inventory in the warehouse. The form helps in recording whether items are available or not, and if not, suggests a re-order date for replenishment.

## How To Complete This Form
To complete this form, please follow these steps:

* Review the item list to determine the items that need attention.
* Select the items that are currently available or not available.
* Enter the quantity of the items that are not available.
* If an item is not available, select a re-order date for replenishment.
* Enter any additional notes for further explanation.
* Select the current status of the item (Active or Inactive).

## Field-by-Field Explanation
* **Item List (Select Multiple)**: Select all items that need attention from the drop-down menu. This will help in creating a list of items that are not available for use.
* **Quantity (Number)**: Enter the number of items that are not available. This will help in tracking the exact shortage level.
* **Reorder Date (Date)**: Select a date for reordering the item if it is not available. This will help in planning and scheduling the replenishment process.
* **Notes (Text Area)**: Enter any additional comments or notes for the item. This will help in further explanation and discussion about the item's status.
* **Item Status (Select One)**: Select the current status of the item as Active or Inactive. This will help in tracking the item's availability and usage status.

## Tips
* Make sure to review the item list carefully before selecting the items that need attention.
* If an item is not available, select a re-order date as soon as possible to ensure timely replenishment.
* Enter accurate quantity and notes to ensure efficient tracking and communication.
* Select the correct item status to ensure proper inventory management.
* This form is meant for authorized personnel only, please ensure only authorized users access and use this form.
