# design upload form template - Help Guide
## Purpose
The purpose of this form is to collect information about uploaded design files, including project details and file specifications.

## How To Complete This Form
To complete this form, follow these steps:

1. **Upload Design File**: Click the "Upload Design File" field to select a design file to upload.
2. **Enter Project Name and Description**: Fill in the "Project Name" and "Project Description" fields to provide a brief overview of the project.
3. **Select Design Upload Date**: Choose the date for which the design is being uploaded.
4. **Specify Design File Format and Size**: Select the file format and size of the uploaded design file.
5. **Enter Project URL and Tags**: Optionally, enter the project URL and any relevant tags.

## Field-by-Field Explanation

* **Upload Design File**: Upload a design file (.pdf, .jpeg, .png, .svg, .eps, .gif, .bmp, .tiff) to associate with the project.
* **Project Name**: Enter a brief and descriptive title for the project.
* **Project Description**: A short description of the project, explaining its purpose or context.
* **Design Upload Date**: Select a date to associate with the uploaded design file.
* **Design File Name**: Enter a name for the uploaded design file.
* **Design File Format**: Select the format of the uploaded design file from the dropdown menu.
* **Design File Size**: Select the size of the uploaded design file (small, medium, large).
* **Project URL**: Optionally, enter the URL where the project is publicly available.
* **Project Tags**: Add relevant keywords or tags to help identify and categorize the project.
* **Project Tags**: A field where you can add more keywords or tags to help identify and categorize the project.
