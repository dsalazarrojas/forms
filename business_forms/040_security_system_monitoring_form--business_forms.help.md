# Security System Monitoring Form - Help Guide
## Purpose
This form is designed to help businesses report and monitor security system incidents in real-time. It allows users to input relevant details about reported incidents, including type, date, and other necessary information.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the "Report Incidents" page and input a brief description of the incident in the "Report Incidents" field.
2. If the incident is a specific type, choose it from the dropdown menu in the "Incident Type" field.
3. Input the date the incident occurred in the "Date of Incidents" field.
4. If the incident requires maintenance or monitoring, add the request in the "Maintenance Requests" field.
5. Once you have completed all the fields, submit the form to record and monitor the incident.

## Field-by-Field Explanation
### Report Incidents (text, Report Incidents, optional)
* Enter a brief description of the incident, including the key details and circumstances surrounding it.

### Monitor System Performance (text, Monitor System Performance, optional)
* Enter any observations or metrics regarding the performance of your security system, such as uptime, downtime, or other relevant data.

### Maintenance Requests (text, Maintenance Requests, optional)
* If the incident requires maintenance or upkeep, provide a detailed description of the work needed.

### Incident Type (Select Multiple, Incident Type, optional)
* Choose one or more of the following incident types:
	+ Security Breach
	+ System Downtime
	+ Maintenance

### Date of Incidents (date, Date of Incidents, optional)
* Enter the date the incident occurred.
