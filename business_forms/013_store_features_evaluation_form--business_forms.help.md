# Store Features Evaluation Form - Help Guide
## Purpose
The Store Features Evaluation Form is a tool used to evaluate the various features of a store. This form helps business owners or managers assess the availability of different features in the store and make decisions based on the data collected.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each feature listed in the form and indicate whether it is available in your store.
2. Select "Yes" for each feature that is available and "No" for each feature that is not available.
3. For features with a numerical value (e.g. feature1_value), enter the numerical value in the corresponding field.
4. Fill out the form for all the features listed.

## Field-by-Field Explanation

* **Store Features** (`store_features`, select_multiple): Choose all the features that are available in your store, separated by commas. For example, "Yes, Yes, No"
* **Feature 1** (`feature1`, text): Enter a short description of feature 1.
* **Feature 1 Value** (`feature1_value`, number): If feature 1 has a numerical value, enter that value in this field. Otherwise, leave this field blank.
* **Feature 2** (`feature2`, text): Enter a short description of feature 2.
* **Feature 2 Value** (`feature2_value`, select_one): Select "Yes" if feature 2 has a value, "No" otherwise.
* **Feature 3** (`feature3`, text): Enter a short description of feature 3.
* **Feature 3 Value** (`feature3_value`, number): If feature 3 has a numerical value, enter that value in this field. Otherwise, leave this field blank.
* **Feature 4** (`feature4`, text): Enter a short description of feature 4.
* **Feature 4 Value** (`feature4_value`, select_one): Select "Yes" if feature 4 has a value, "No" otherwise.
* **Feature 5** (`feature5`, text): Enter a short description of feature 5.
* **Feature 5 Value** (`feature5_value`, number): If feature 5 has a numerical value, enter that value in this field. Otherwise, leave this field blank.

## Tips

* Make sure to answer all questions carefully and accurately, as the data collected will be used to make decisions about your store.
* If you are unsure about the availability of a feature, leave it blank or select "No".
