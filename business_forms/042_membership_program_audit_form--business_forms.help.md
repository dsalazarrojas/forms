# membership_program_audit_form - Help Guide
## Purpose
This form is designed to gather feedback and survey information from members about their experience with the membership program.

## How To Complete This Form
To complete this form, follow these steps:

* Select the answers to each question based on your experience with the membership program.
* Choose "Yes" or "No" for the Member Survey, Program Evaluation, Member Experience, and Action Plan questions.
* Enter a numerical value for the Member Satisfaction question, if applicable.
* Make sure to fill out all required questions, even if it's to indicate "No" or "Not Applicable".

## Field-by-Field Explanation

* **Member Survey** (`member_survey`, `select_one`, required/optional: false): This question asks whether you are a member of the program or not. Select "Yes" if you are currently a member, "No" if you are not.
* **Program Evaluation** (`program_evaluation`, `note`, required/optional: false): This is a text field for any comments or thoughts you have about the program. You can type any feedback or suggestions you have about the program.
* **Member Experience** (`member_experience`, `select_multiple`, required/optional: false): Select all the experiences you've had with the program. For example, "Yes" for "Good", "Yes" for "Bad", etc.
* **Member Satisfaction** (`member_satisfaction`, `number`, required/optional: false): If you are a member, type a numerical value between 1 and 10, where 1 is very dissatisfied and 10 is very satisfied.
* **Action Plan** (`action_plan`, `select_one`, required/optional: false): This question asks whether you have an action plan for future improvements. Select "Yes" if you do, "No" if you don't.
