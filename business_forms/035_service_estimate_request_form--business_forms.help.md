# Service Estimate Request Form - Help Guide
## Purpose
This form is used to request an estimate for a service. It collects information about your project and the service provider.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields to provide information about your project.
2. Select the service provider for your project.
3. Provide details about your project and the service provider.
4. Enter contact information for your service provider.
5. Submit the form to request an estimate.

## Field-by-Field Explanation

* **Project Details** (1, text, required/optional):
	+ Enter a brief description of your project.
* **Service Provider** (2, select_one, required/optional):
	+ Select 'Yes' if the service provider is a part of the project. Select 'No' otherwise.
* **Project Type** (3, select_one, required/optional):
	+ Select the type of project you are requesting an estimate for (e.g. Option 1, Option 2, Option 3).
* **Project Status** (4, select_multiple, required/optional):
	+ Select all applicable statuses for your project (e.g. Active, Inactive).
* **Start Date** (5, date, required/optional):
	+ Enter the start date for your project.
* **End Date** (6, date, required/optional):
	+ Enter the end date for your project.
* **Project Description** (7, text, required/optional):
	+ Enter a detailed description of your project.
* **Service Provider Details** (8, text, required/optional):
	+ Enter any additional details about the service provider.
* **Contact Number** (9, text, required/optional):
	+ Enter the contact number for the service provider.
* **Email** (10, email, required/optional):
	+ Enter the email address for the service provider.
* **Address** (11, text, required/optional):
	+ Enter the address of the service provider's location.
* **City** (12, text, required/optional):
	+ Enter the city of the service provider's location.
* **State** (13, text, required/optional):
	+ Enter the state of the service provider's location.
* **Zip** (14, text, required/optional):
	+ Enter the zip code of the service provider's location.
* **Service Estimate** (15, number, required/optional):
	+ Enter the estimated cost for the service.
