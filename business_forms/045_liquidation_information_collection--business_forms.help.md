# Liquidation Information Collection - Help Guide
## Purpose
This form collects information about liquidated assets, including the date and reason for liquidation, asset value, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Submit" button to start filling out the form.
2. Select the date of the liquidation from the calendar or enter it manually.
3. Choose the reason for liquidation from the options provided.
4. For each field, enter the required information, making sure to provide accurate details.
5. Review your answers carefully before submitting the form.

## Field-by-Field Explanation
### Liquidation Date
* **Liquidation Date** (`liquidation_date`, date, not required): Enter the date of the liquidation.

### Reason for Liquidation
* **Reason for Liquidation** (`reason_for_liquidation`, text, required): Enter the reason for liquidation, providing a clear explanation.

### Documents
* **Documents** (`documents`, select_multiple, not required): Select 'Yes' if documents are available, or 'No' if not.

### Document 1
* **Document 1** (`document_1`, text, not required): Enter the first document details if 'Yes' is selected for 'Documents'.

### Amount Liquidated
* **Amount Liquidated** (`amount_liquidated`, number, required): Enter the total amount liquidated.

### Amount Liquidated Reasons
* **Amount Liquidated Reasons** (`amount_liquidated_reasons`, text, required): Enter the reasons for the amount liquidated.

### Asset Liquidated
* **Asset Liquidated** (`asset_liquidated`, text, required): Enter the asset being liquidated.

### Asset Type
* **Asset Type** (`asset_type`, select_one, not required): Choose 'Yes' or 'No' to indicate whether the asset is liquidated or not.

### Asset Location
* **Asset Location** (`asset_location`, text, not required): Enter the location of the asset.

### Asset Value
* **Asset Value** (`asset_value`, number, required): Enter the value of the asset.

### Asset Value Reasons
* **Asset Value Reasons** (`asset_value_reasons`, text, required): Enter the reasons for the asset value.

### Asset Use
* **Asset Use** (`asset_use`, text, required): Enter the use of the asset.

### Asset Use Reasons
* **Asset Use Reasons** (`asset_use_reasons`, text, required): Enter the reasons for the asset use.

### Asset Status
* **Asset Status** (`asset_status`, select_one, not required): Choose the status of the asset, either 'Active' or 'Inactive'.

### Asset Status Reasons
* **Asset Status Reasons** (`asset_status_reasons`, text, not required): Enter the reasons for the asset status.

### Asset Status Description
* **Asset Status Description** (`asset_status_description`, text, not required): Enter a description of the asset status.

### Asset Status Code
* **Asset Status Code** (`asset_status_code`, text, not required): Enter the asset status code.

### Asset Status Notes
* **Asset Status Notes** (`asset_status_notes`, text, not required): Enter notes about the asset status.

### Asset Class
* **Asset Class** (`asset_class`, select_one, not required): Choose 'Yes' or 'No' to indicate whether the asset is in a class or not.

### Asset Class Reasons
* **Asset Class Reasons** (`asset_class_reasons`, text, not required): Enter the reasons for the asset class.

### Notes
* **Notes** (`notes`, note, not required): Enter any additional notes about the asset.

### Asset Use Location
* **Asset Use Location** (`asset_use_location`, text, not required): Enter the location of the asset use.

### Asset Value Use
* **Asset Value Use** (`asset_value_use`, text, not required): Enter the use of the asset value.

### Asset Value Use Reasons
* **Asset Value Use Reasons** (`asset_value_use_reasons`, text, not required): Enter the reasons for the asset value use.
