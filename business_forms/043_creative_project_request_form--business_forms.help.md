# Creative Project Request Form - Help Guide

## Purpose
The purpose of this form is to gather information about creative projects, including contact details, project managers, and project-related information.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your contact information, including your name, email, and phone number.
2. Choose a project manager from our team to work on the project.
3. Provide the project manager's contact information, including their name, email, and phone number.
4. Add any additional project details, such as project type, project deadline, budget, and priority.
5. Indicate the project's status, such as active, in progress, or completed.
6. Add any additional project notes or details, if needed.

## Field-by-Field Explanation

* **Contact Information**: Enter your name, email, and phone number to help us get in touch with you about your project.
* **Project Manager**: Choose the project manager you'd like to work with from our team.
* **Name**: Enter the project manager's name.
* **Email**: Enter the project manager's email address.
* **Phone**: Enter the project manager's phone number.
* **Graphics Research**: Enter any relevant graphics research information related to the project.
* **Project Deadline**: Select a deadline for the project.
* **Project Budget**: Enter the project's budget.
* **Project Priority**: Choose the project's priority level (Low, Medium, or High).
* **Project Status**: Select the project's status (Active, In Progress, or Completed).
* **Project Manager Notes 2**: Add any additional notes or details for the project manager.
* **Project Location**: Enter the project's location.
* **Project Description**: Enter a brief description of the project.
* **Project Notes**: Add any additional project notes or details.
* **Project Manager 2**: Enter the name of the secondary project manager.
* **Project Deadline 2**: Select a deadline for the project.
* **Project Status 2**: Select the status of the project.
* **Project Type**: Enter the type of project.
* **Project Type 2**: Select whether this is a yes or no project, or choose other.
* **Project Details 2**: Enter additional project details.
* **Project Description 2** is not present in the original yaml form.
 
Note: Some fields are not required and can be left blank if not applicable. 

Please fill out the form carefully and accurately to help us understand your project requirements better.
