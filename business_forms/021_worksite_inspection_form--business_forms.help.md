# worksite_inspection_form - Help Guide
## Purpose
The worksite inspection form is used to gather information about the site's condition and identify any issues that need to be addressed.

## How To Complete This Form
To complete this form, follow these steps:
1. Go to the first page of the form, "Site Information."
2. Fill out the required fields with accurate and complete information about the site.
3. Move on to the second page, "Checklist."
4. Select all relevant checkboxes for the site's conditions.
5. Add any notable events or issues in the "Notes" field.
6. Review the form for completeness and accuracy before submitting.

## Field-by-Field Explanation
* **Site Information (<type:text>):** Enter the site's name and ID number for reference.
* **Checklist (Select Multiple):** Select all relevant boxes that describe the site's conditions.
	+ 'Yes' for conditions that exist, and 'No' for those that do not.
* **Notes (Text):** Write a brief description of any notable events or issues observed during the inspection.
