# Ensemble Coordinator Contract Form - Help Guide
## Purpose
The Ensemble Coordinator Contract Form is used to establish a contract with an ensemble coordinator for a specific job or project. This form outlines the terms and conditions of the agreement, including the category, dates, compensation, and contact information for both parties involved.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title, which should be a brief description of the job or project.
2. Select the category that best fits the job or project.
3. Provide a description of the job or project.
4. Set the start and end dates for the job or project.
5. Enter the compensation for the job or project.
6. Complete the contact information for both the ensemble coordinator and client, including name, title, organization, address, phone number, and email.

## Field-by-Field Explanation

* **ensemble_coordinator_contract_form** (`form_title`, text, not required): A brief description of the job or project.
* **category** (`category`, select_one, not required): The category that best fits the job or project.
* **description** (`description`, text, not required): A detailed description of the job or project.
* **date_start** (`date_start`, date, not required): The start date of the job or project.
* **date_end** (`date_end`, date, not required): The end date of the job or project.
* **compensation** (`compensation`, number, not required): The compensation for the job or project.
* **signature_1** (`signature_1`, text, not required): The ensemble coordinator's signature.
* **name_1** (`name_1`, text, not required): The ensemble coordinator's name.
* **title_1** (`title_1`, text, not required): The ensemble coordinator's title.
* **organization** (`organization`, text, not required): The ensemble coordinator's organization.
* **address_1** (`address_1`, text, not required): The ensemble coordinator's address.
* **phone_1** (`phone_1`, text, not required): The ensemble coordinator's phone number.
* **email_1** (`email_1`, email, not required): The ensemble coordinator's email.
* **date_signed** (`date_signed`, date, not required): The date the contract was signed.
* **signature_2** (`signature_2`, text, not required): The client's signature.
* **name_2** (`name_2`, text, not required): The client's name.
* **title_2** (`title_2`, text, not required): The client's title.
* **organization_2** (`organization_2`, text, not required): The client's organization.
* **address_2** (`address_2`, text, not required): The client's address.
* **phone_2** (`phone_2`, text, not required): The client's phone number.
* **email_2** (`email_2`, email, not required): The client's email.
* **date_signed_2** (`date_signed_2`, date, not required): The date the contract was signed.
* **note_1** (`note_1`, note, not required): A note for the ensemble coordinator.
* **note_2** (`note_2`, note, not required): A note for the client.
* **submitted_by** (`submitted_by`, text, not required): The person who submitted the form.

Note: Please sign the form when finished and keep a copy for your records.
