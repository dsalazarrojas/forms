# Return Of Property Form - Help Guide
## Purpose
The Return Of Property Form is used to document the return of properties, assets, or items that have been returned to their rightful owners or recovered.

## How To Complete This Form
To fill out this form, please follow these steps:

*   Start by filling in the required fields, indicated by an asterisk \*.
*   Enter the relevant information for each field, and ensure that it's accurate and complete.

## Field-by-Field Explanation
### Return (`return_of_property_form`)

*   **Return** (`return_of_property_form`, text, required: false): Enter a brief description of the return or the reason for returning the property.

### Business Name (`business_name`, text, required: false)

*   **Business Name** (`business_name`, text, required: false): Enter the name of the business or organization related to the return of property.

### Employee ID (`employee_id`, number, required: false)

*   **Employee ID** (`employee_id`, number, required: false): Enter the ID of the employee involved in the return process, if applicable.

### Item Description (`item_description`, text, required: false)

*   **Item Description** (`item_description`, text, required: false): Provide a detailed description of the item being returned.

### Date Returned (`date_returned`, date, required: false)

*   **Date Returned** (`date_returned`, date, required: false): Enter the date when the property was returned.

### Return Date (`return_date_hint`, date, required: false)

*   **Return Date** (`return_date_hint`, date, required: false): Enter the expected return date for the property.

### Status (`status`, select_multiple, required: false)

*   **Status** (`status`, select_multiple, required: false): Select the status of the return process from the options: Returned, Lost, Stolen, or Missing.

### Asset Location (`asset_location`, text, required: false)

*   **Asset Location** (`asset_location`, text, required: false): Enter the location where the property was found or recovered.

### Remarks (`remarks`, text, required: false)

*   **Remarks** (`remarks`, text, required: false): Add any additional comments or remarks related to the return of property.

## Tips
Please ensure that you fill out the form accurately and completely, as it is used for record-keeping and tracking. If you have any questions or concerns about the return of property process, please contact your supervisor or HR department for assistance.
