# Cross Entity Payment Coordination Application Form - Help Guide

## Purpose
This form is designed to facilitate cross-entity payments within a company, ensuring that all parties involved are aware of and agree to the payment terms. It clarifies the payment details, contact information, and other relevant specifics.

## How To Complete This Form
- Please review each page carefully, making sure all required fields are completed accurately.
- Ensure that you have filled out the form for the correct use case and that there are no duplicate submissions.
- Review the fields carefully to ensure you are answering the correct questions for your specific situation.

## Field-by-Field Explanation

* **Company** (`company`, text, required: false): Enter the name of the company making the payment.
* **Company Address** (`company_address`, text, required: false): Enter the address of the company making the payment.
* **Entity** (`entity`, text, required: false): Enter the name of the entity receiving the payment.
* **Entity Address** (`entity_address`, text, required: false): Enter the address of the entity receiving the payment.
* **Contact** (`contact`, select_one, required: false):
  * Select 'Yes' if you are the contact person for this payment coordination.
  * Select 'No' if you are not.
* **Contact Email** (`contact_email`, text, required: false): If you are the contact person, enter their email address.
* **Contact Phone** (`contact_phone`, text, required: false): If you are the contact person, enter their phone number.
* **Payment Method** (`payment_method`, select_multiple, required: false):
  * Select 'Yes' if payment is made using this method.
  * Select 'No' if not.
* **Amount** (`amount`, number, required: false): Enter the exact amount of the payment.
* **Date of Payment** (`date_of_payment`, date, required: false): Enter the date the payment is due or was made.
* **Description** (`description`, text, required: false): Briefly describe the purpose of the payment.
* **File Upload** (`file_upload`, text, required: false): If necessary, attach a file related to the payment.
* **File Type** (`file_type`, select_multiple, required: false):
  * Select 'Yes' if the file is attached.
  * Select 'No' if not.
* **Date** (`date`, time, required: false): Enter the time of the payment or deadline.
* **Submit** (`submit`, select_one, required: false):
  * Select 'Yes' if you have completed the form accurately.
  * Select 'No' if you need to review or correct any fields.
* **Notes** (`notes`, text, required: false): Add any additional comments or notes about the payment.
* **Entity 2** (`entity_2`, select_one, required: false):
  * Select 'Yes' if this entity is involved in the payment.
  * Select 'No' if not.

Please ensure you fill out all required fields and double-check your submission.
