# Tool Issue Form - Help Guide
## Purpose
The Tool Issue Form is a reporting tool used to track and manage tool-related issues within the organization. It helps gather essential information to address problems promptly and maintain up-to-date records.

## How To Complete This Form
1. Choose the correct tool category (e.g., Hardware, Consumables, Tools) from the provided options.
2. Enter a brief description of the tool and the issue you are facing.
3. Specify the tool's status (e.g., Available, Lost, Stolen, Missing, Broken, Damaged, Inactive).
4. Indicate if the issue was reported by someone other than the person filling out the form.
5. Record the date and time the issue occurred.
6. Provide a detailed description of the issue.
7. Enter the date the issue was resolved, if applicable.
8. Enter the time the issue was resolved, if applicable.
9. Specify who resolved the issue, if known.

## Field-by-Field Explanation
* **Tool Category** (`tool_category`): Select the category that best describes the type of tool or consumable involved in the issue.
	+ Hardware: Physical tools and equipment.
	+ Consumables: Materials or supplies used in tooling or production.
	+ Tools: General-purpose tools.
	+ Other: Any other category that doesn't fit the above options.
* **Tool Description** (`tool_description`): Briefly describe the tool or consumable in question.
* **Tool Status** (`tool_status`): Indicate the current state of the tool, such as Available, Lost, Stolen, Missing, Broken, Damaged, or Inactive.
* **Assigned To** (`assigned_to`): Check "Yes" if the issue was reported by someone else, "No" if you're the one reporting the issue.
* **Date Issue** (`date_issue`): Enter the date the issue occurred or was first noticed.
* **Time Issue** (`time_issue`): Enter the time the issue occurred or was first noticed.
* **Issue Reported By** (`issue_reported_by`): Enter the name of the person who reported the issue, if not yourself.
* **Issue Description** (`issue_description`): Provide a detailed description of the problem or issue.
* **Resolution Date** (`resolution_date`): Enter the date the issue was resolved, if applicable.
* **Resolution Time** (`resolution_time`): Enter the time the issue was resolved, if applicable.
* **Issue Closed By** (`issue_closed_by`): Enter the name of the person who closed the issue, if known.
