# Folder Creation Form - Help Guide
## Purpose
This form is used to create a new folder within our project management system. You can use this form to create a folder for storing and organizing related project files, documents, and other resources.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a brief but descriptive name for your folder in the "Folder name" field.
2. Select a category for your folder from the "Folder Category" dropdown list.
3. Add a brief description of your folder in the "Folder Description" field.
4. Optionally, add tags to your folder to help with searching and organization.
5. If you're creating the folder as part of a team project, enter the email address of the folder's owner.
6. If you're creating the folder, select "Created by" from the dropdown list to attribute ownership.
7. Choose the status of your folder from the "Folder Status" dropdown list.
8. Optionally, enter a date and time for when the folder was created.

## Field-by-Field Explanation
* **Folder name** (`form_name`, text, required): This field is where you can enter a descriptive name for your folder. Please try to keep it brief and to the point.
* **Folder Category** (`folder_category`, select_one, optional): This field allows you to select a category for your folder from the provided options. Selecting a category helps with searching and organization.
* **Folder Description** (`folder_description`, text, optional): This field is for adding a brief description of your folder. Use it to provide context and make it easier for others to understand what's inside the folder.
* **Folder Tags** (`folder_tags`, text, optional): Enter a list of tags separated by commas to help others find and filter your folder more easily.
* **Folder Owner** (`folder_owner`, email, optional): If you're creating the folder as part of a team project, enter the email address of the folder's owner.
* **Folder Creator** (`folder_creator`, select_one, optional): If you're creating the folder, select "Created by" from the dropdown list to attribute ownership to yourself.
* **Share with others** (`folder_share`, text, optional): Enter email addresses separated by commas if you want to share the folder with others.
* **Folder Status** (`folder_status`, select_one, optional): Choose the status of your folder from the provided options to indicate its current state.
* **Created at** (`folder_created_at`, date, optional): If you're tracking the creation date of your folder, enter it here.
* **Created by** (`folder_creator`, select_one, optional): If you're creating the folder, select "Created by" from the dropdown list to attribute ownership to yourself.
