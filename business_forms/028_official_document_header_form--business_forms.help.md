# official_document_header_form - Help Guide
## Purpose
The official document header form is used to create and update headers for official documents. This form is necessary for maintaining accurate and up-to-date document information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked as (required).
2. Fill in the optional fields, as needed.
3. Make sure to select the correct document type from the options provided.

## Field-by-Field Explanation
* **Form Header** (`form_header`, text, optional): Enter a brief description of the document header.
* **Document Id** (`document_id`, number, optional): Enter the unique identifier for the document.
* **Document Name** (`document_name`, text, optional): Enter the name of the document.
* **Document Type** (`document_type`, select_one, optional): Select the type of document from the options provided. This will help categorize and manage documents accordingly.
* **Issue Date** (`issue_date`, date, optional): Enter the date the document was issued.
* **Created By** (`created_by`, text, optional): Enter the name of the employee who created the document.
* **Title** (`created_by_title`, text, optional): Enter the title of the employee who created the document.
* **Company Name** (`company_name`, text, optional): Enter the name of the company related to the document.
* **Document Number** (`document_number`, text, optional): Enter the document number.
* **Document Number 2** (`document_number_2`, text, optional): Enter the second document number, if applicable.

## Tips
* Make sure to fill in all the required fields to ensure accurate document information.
* Double-check the document type to ensure it matches the actual document type.
* If you are unsure about any field, contact your supervisor or colleague for clarification.
