# Production Proposal Upload Form - Help Guide

## Purpose
The Production Proposal Upload Form is a tool for uploading and managing production proposals. It provides a structured way to submit and track proposals, from first page to final review status.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the First Page with any initial details about the proposal.
2. On the second page, select the type of proposal you're submitting (Production, Development, Preproduction, or Postproduction).
3. Upload any relevant files related to the proposal by selecting them from the Proposal Files section.
4. Provide production details, including the production schedule and duration.
5. Choose the reviewers who will be reviewing the proposal.
6. Set the proposal status to In Review, Approved, Rejected, or Pending.
7. Add any review notes or comments.
8. Select the files that have been reviewed.
9. Finally, set the review status to In Progress, Complete, Overdue, or Not Started.

## Field-by-Field Explanation

* **First Page**: A free-form text field for entering initial proposal details.
* **Second Page**: Select the type of proposal you're submitting (Production, Development, Preproduction, or Postproduction).
* **Proposal Details**: Upload files related to the proposal (e.g., project plan, budget, etc.).
* **Production Details**: Enter production details, including production schedule and duration.
* **Production Schedule**: Enter the start and end dates of the production process.
* **Production Duration**: Enter the duration of the production process.
* **Reviewers**: Select the reviewers who will be reviewing the proposal.
* **Proposal Status**: Set the proposal status to In Review, Approved, Rejected, or Pending.
* **Review Notes**: Enter any review notes or comments.
* **Files Reviewed**: Select the files that have been reviewed.
* **Review Status**: Set the review status to In Progress, Complete, Overdue, or Not Started.

## Tips
* Make sure to upload all necessary files related to the proposal.
* Double-check the proposal status to ensure it's accurate.
* Review and update the review notes regularly to track progress.
* Set the review status to reflect the current state of the proposal.
* Ensure that all reviewers are aware of their responsibilities and deadlines.
