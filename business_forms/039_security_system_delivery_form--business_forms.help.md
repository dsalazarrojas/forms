# Security System Delivery Form - Help Guide
## Purpose
The Security System Delivery Form is used to collect information for delivering security systems to clients. This form helps gather essential details about the client, product, and delivery schedule, enabling efficient processing and delivery.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the client's name in the Client Name field.
2. Enter the client's address in the Client Address field.
3. Enter the product's name in the Product Name field.
4. Describe the product in the Product Description field.
5. Select the delivery date in the Delivery Date field.
6. Select the delivery time in the Delivery Time field.
7. Choose the security type from the Security Type field.
8. Select the delivery method from the Delivery Method field.
9. Enter the status in the Status field.
10. Enter any delivery notes in the Delivery Notes field.
11. Enter the contact email in the Contact Email field.
12. Enter the contact phone number in the Contact Phone field.
13. Select the assigned user from the Assigned User field.
14. Select the assigned department from the Assigned Department field.
15. Enter any additional notes in the Notes field.
16. Enter the contact name in the Contact Name field.
17. Enter the contact phone number (if applicable) in the Contact Phone 2 field.
18. Enter the security system details in the Security System Details field.

## Field-by-Field Explanation

* **Client Name** (`client_name`): Enter the name of the client receiving the security system.
* **Client Address** (`client_address`): Enter the address where the security system will be delivered.
* **Product Name** (`product_name`): Enter the name of the product being delivered.
* **Product Description** (`product_description`): Briefly describe the product being delivered.
* **Delivery Date** (`delivery_date`): Select the date the security system is to be delivered.
* **Delivery Time** (`delivery_time`): Select the time the security system is to be delivered.
* **Security Type** (`security_type`): Choose the type of security system being delivered (e.g., Fire Alarm, Security Camera, Access Control).
* **Delivery Method** (`delivery_method`): Select the method of delivery (e.g., Option 1, Option 2).
* **Status** (`status`): Enter the current status of the delivery.
* **Delivery Notes** (`delivery_notes`): Enter any additional delivery information or instructions.
* **Contact Email** (`contact_email`): Enter the contact email for the client or delivery contact.
* **Contact Phone** (`contact_phone`): Enter the contact phone number for the client or delivery contact.
* **Assigned User** (`assigned_user`): Select the user assigned to handle the delivery.
* **Assigned Department** (`assigned_department`): Select the department responsible for the delivery.
* **Notes** (`notes`): Enter any additional information or comments.
* **Contact Name** (`contact_name`): Enter the name of the contact person.
* **Contact Phone 2** (`contact_phone_2`): Enter the secondary contact phone number (if applicable).
* **Security System Details** (`security_system_details`): Enter any additional details about the security system being delivered.
