# Operational Sustainability Program Registration Form - Help Guide
## Purpose
This form is designed to collect information about operational sustainability programs. These programs are intended to improve the sustainability and reduce the ecological footprint of a business or organization.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the program details in the first field.
2.  Enter the program name in the second field.
3.  Enter a brief description of the program in the third field.
4.  Enter the start date and end date of the program in the fourth and fifth fields respectively.
5.  Enter the contact person for the program in the sixth field.
6.  Enter the organization running the program in the seventh field.
7.  Enter the email address of the program in the eighth field.
8.  Enter the phone number of the program in the ninth field.
9.  Enter the address of the program in the tenth field.
10. Select the type of the program in the eleventh field.
11. Select the certification level of the program in the twelfth field.
12. Enter the sector of the program in the thirteenth field.
13. Enter the region of the program in the fourteenth field.
14. Enter the country of the program in the fifteenth field.
15. Enter the city of the program in the sixteenth field.
16. Enter the zip code of the program in the seventeenth field.
17. Enter the website of the program in the eighteenth field.

## Field-by-Field Explanation

*   **Program Details** (Program Details, text, required/optional): Enter a brief description of the program.
*   **Program Name** (Program Name, text, required/optional): Enter the name of the program.
*   **Program Description** (Program Description, text, required/optional): Enter a brief description of the program.
*   **Program Start Date** (Program Start Date, date, required/optional): Enter the start date of the program.
*   **Program End Date** (Program End Date, date, required/optional): Enter the end date of the program.
*   **Contact Person** (Contact Person, text, required/optional): Enter the contact person for the program.
*   **Organization** (Organization, text, required/optional): Enter the organization running the program.
*   **Email** (Email, email, required/optional): Enter the email address of the program.
*   **Phone** (Phone, text, required/optional): Enter the phone number of the program.
*   **Address** (Address, text, required/optional): Enter the address of the program.
*   **Program Type** (Program Type, select_one, required/optional): Select the type of the program. Options are Sustainability or Non-Sustainability.
*   **Certification Level** (Certification Level, select_multiple, required/optional): Select the certification level of the program. Options are Basic, Intermediate, or Advanced.
*   **Sector** (Sector, text, required/optional): Enter the sector of the program.
*   **Region** (Region, text, required/optional): Enter the region of the program.
*   **Country** (Country, text, required/optional): Enter the country of the program.
*   **City** (City, text, required/optional): Enter the city of the program.
*   **Zip Code** (Zip Code, text, required/optional): Enter the zip code of the program.
*   **Website** (Website, text, required/optional): Enter the website of the program.
