# Innovation Management Tool Requisition Form - Help Guide
## Purpose
The Innovation Management Tool Requisition Form is designed to collect information about the tools and resources required by project managers and teams within an organization for innovation management purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. **Project Manager**: Enter the name of the person in charge of the project, if applicable.
2. **Team Name**: Enter the name of the team working on the project.
3. **Team Email**: Enter the email address of the team members or the project lead.
4. **Tool Name**: Enter a brief description or name of the tool required.
5. **Tool Description**: Provide a short description of the tool and its purpose.
6. **Business Value**: Briefly describe the value this tool will bring to the organization.
7. **Justification**: Explain why this tool is necessary for the project or team.
8. **Assigned Tool**: Select the tool owner from the list, or enter "Other" to specify a different tool owner.
9. **Tool Owner (if Other)**: If you selected "Other" in the previous field, enter the name of the tool owner.

## Field-by-Field Explanation

* **Project Manager**: Enter the name of the person in charge of the project, if applicable. This field is optional, but it helps the administrators to associate the request with the correct project lead.
* **Team Name**: Enter the name of the team working on the project. This field is optional, but it helps the administrators to track the team responsible for the tool request.
* **Team Email**: Enter the email address of the team members or the project lead. This field is optional but ensures that the team is notified about the tool requisition.
* **Tool Name**: Enter a brief description or name of the tool required. This could be the tool's name, a short description, or its acronym.
* **Tool Description**: Provide a short description of the tool and its purpose. This field should give the administrators an understanding of the tool's function and why it's needed.
* **Business Value**: Briefly describe the value this tool will bring to the organization. This could include benefits, cost savings, or improvements in efficiency.
* **Justification**: Explain why this tool is necessary for the project or team. This field should provide a clear reason for why the tool is needed.
* **Assigned Tool**: Select the tool owner from the list. This ensures that the tool is assigned to the correct person. If "Other" is selected, enter the name of the tool owner in the following field.
* **Tool Owner (if Other)**: If you selected "Other" in the previous field, enter the name of the tool owner. This field is required when "Other" is selected.
