# Work Order Request - Help Guide
## Purpose
This form is used to submit a new work order request. Work orders are used to track and manage tasks and projects within a business organization.

## How To Complete This Form
1. Ensure that you have the necessary permissions to submit a work order request.
2. Fill out the form with the required information, including facility, location, and work order details.
3. Select the correct options for the type of work order and priority level.
4. Provide a description of the work order, if applicable.
5. Select the correct status and due dates for the work order.
6. Review and submit the form for processing.

## Field-by-Field Explanation

* **Facility** (Facility, number, not required): Select the facility related to the work order.
* **Location** (Location, number, not required): Select the location related to the work order.
* **Work Order** (Work Order, number, not required): Select the work order related to the work order.
* **Type** (Type, select one, not required): Select the type of work order.
* **Facility Name** (Facility Name, text, not required): Enter the name of the facility related to the work order.
* **Location Name** (Location Name, text, not required): Enter the name of the location related to the work order.
* **Request Date** (Request Date, date, not required): Enter the date the work order was requested.
* **Request Time** (Request Time, time, not required): Enter the time the work order was requested.
* **Description** (Description, text, not required): Provide a description of the work order.
* **Assigned To** (Assigned To, select one, not required): Select who is assigned to the work order.
* **Category** (Category, select one, not required): Select the category of the work order.
* **Priority** (Priority, select one, not required): Select the priority level of the work order.
* **Status** (Status, select one, not required): Select the status of the work order.
* **Due Date** (Due Date, date, not required): Enter the due date for the work order.
* **Due Time** (Due Time, time, not required): Enter the due time for the work order.
* **Submitted By** (Submitted By, select one, not required): Select who submitted the work order.
* **Submitted Date** (Submitted Date, date, not required): Enter the date the work order was submitted.
* **Facility IDs** (Facility IDs, select multiple, not required): Select the facility IDs related to the work order.
* **Location IDs** (Location IDs, select multiple, not required): Select the location IDs related to the work order.
* **Work Order IDs** (Work Order IDs, select multiple, not required): Select the work order IDs related to the work order.
* **Assigned Tool IDs** (Assigned Tool IDs, select multiple, not required): Select the tool IDs assigned to the work order.
* **Category IDs** (Category IDs, select multiple, not required): Select the category IDs related to the work order.
* **Status IDs** (Status IDs, select multiple, not required): Select the status IDs related to the work order.
* **Priority IDs** (Priority IDs, select multiple, not required): Select the priority IDs related to the work order.
* **Notes** (Notes, text, not required): Enter any additional notes about the work order.
* **Submitted By** (Submitted By, select one, not required): Select who submitted the work order.
* **Work Order IDs** (Work Order IDs, select multiple, not required): Select the work order IDs related to the work order.

## Tips
* Ensure that all fields are filled out completely and accurately.
* Review the form carefully before submitting to ensure that all necessary information is included.
* If you are unsure about any field, refer to the relevant documentation or seek assistance from a supervisor or colleague.
