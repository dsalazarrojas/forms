# manufacturing_process_records_release_form - Help Guide
## Purpose
The manufacturing process records release form is used to record the release of manufacturing process records for various reasons. This form is used to capture essential information such as user name, department, date and time of release, reason for release, and other supporting details.

## How To Complete This Form
1. Fill in your user name in the "User Name" field. This field is required.
2. Enter your department in the "Department" field. This field is not required but recommended for administrative purposes.
3. Select a valid date in the "Date" field. This field is not required but recommended for tracking purposes.
4. Enter the time of release in the "Time" field. This field is required.
5. Select the type of records being released in the "Records Type" field. This field is required.
6. Enter the reason for the release in the "Reason" field. This field is not required but recommended for reference.
7. Enter the name of the person certifying the release in the "Certified By" field. This field is not required but recommended for tracking purposes.
8. Enter the name of the person approving the release in the "Approved By" field. This field is required.
9. Select the status of the records in the "Status" field. This field is not required but recommended for tracking purposes.
10. Enter the date of release in the "Release Date" field. This field is required.
11. Enter the time of release in the "Release Time" field. This field is required.
12. Enter your name in the "Release User Name" field. This field is required.
13. Enter any additional comments in the "Comments" field. This field is not required but recommended for reference.
14. Enter your email address in the "Email" field. This field is required.
15. Enter your phone number in the "Phone" field. This field is required.
16. Enter any additional notes in the "Notes" fields. These fields are not required but recommended for reference.
17. Enter the name of the person releasing the records in the "Release User Name 2" field. This field is required for secondary releases.

## Field-by-Field Explanation

* **User Name** (`user_name`, `text`, required): Enter your user ID or name as it is recorded in the system.
* **Department** (`department`, `text`, optional): Enter your department name or code for easy reference.
* **Date** (`date`, optional): Select a valid date for release.
* **Time** (`time`, required): Enter the release time.
* **Records Type** (`records_type`, `text`, required): Enter the type of records being released.
* **Reason** (`reason`, `text`, optional): Enter the reason for release.
* **Certified By** (`certified_by`, `text`, optional): Enter the name of the person certifying the release.
* **Certified By** (`certified_by`, `text`, optional): Enter the name of the person certifying the release. (Duplicate field of "Certified By" field)
* **Approved By** (`approved_by`, `text`, required): Enter the name of the person approving the release.
* **Approved Date** (`approved_date`, `date`, required): Select a valid date for approval.
* **Approved Time** (`approved_time`, `time`, required): Enter the approval time.
* **Comments** (`comments`, `note`, optional): Enter any comments or remarks for the release.
* **Status** (`status`, `select_one`, optional): Select the status of the records.
* **Release Date** (`release_date`, `date`, required): Select a valid date for release.
* **Release Time** (`release_time`, `time`, required): Enter the release time.
* **Release User Name** (`release_user_name`, `text`, required): Enter your name for the release.
* **Comments 2** (`comments_2`, `note`, optional): Enter any additional comments or remarks.
* **Notes** (`notes`, `note`, optional): Enter any additional notes.
* **Email** (`email`, `email`, required): Enter your email address.
* **Phone** (`phone`, `text`, required): Enter your phone number.
* **Notes 2** (`notes_2`, `note`, optional): Enter any additional notes.
* **Additional Notes** (`additional_notes`, `note`, optional): Enter any additional notes or remarks.
* **Release Date 2** (`release_date_2`, `date`, optional): Select a valid date for release 2.
* **Release Time 2** (`release_time_2`, `time`, optional): Enter the release time 2.
* **Release User Name 2** (`release_user_name_2`, `text`, optional): Enter the name of the person releasing the records 2.
