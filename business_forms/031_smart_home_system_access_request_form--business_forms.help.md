# smart_home_system_access_request_form - Help Guide
## Purpose
The "smart_home_system_access_request_form" is an internal form used to request access to the smart home system. This form is required for all users who need access to the system for various reasons such as troubleshooting, maintenance, or testing.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in your user information (page 1)
2. Select the request date (page 2)
3. Enter your smart home system ID (page 3)
4. Provide a reason for your request (page 4)
5. Add any additional user notes (page 5)
6. Select the security protocol for access (page 6)
7. Confirm your user permission level (page 7)
8. Choose your user access level (page 8)
9. (Optional) Enter your smart home device IP address and MAC address (pages 9-10)

## Field-by-Field Explanation

* **User Information (page 1)**: Please fill in your employee ID, name, and contact information to identify yourself.
* **Request Date (page 2)**: Choose the date you are requesting access to the smart home system.
* **Smart Home Id (page 3)**: Enter the unique ID of your smart home system.
* **Reason for Request (page 4)**: Briefly explain the reason why you need access to the smart home system. For example, you may be performing maintenance or testing on the system.
* **User Note (page 5)**: Add any additional comments or notes relevant to your request.
* **Security Protocol (page 6)**: Select the security protocol that applies to your access request. Choose from Homeowner, Tenant, or Guest.
* **User Permission (page 7)**: Confirm that you have permission to access the smart home system.
* **User Access Level (page 8)**: Choose your user access level. Select from Basic, Intermediate, or Advanced.
* **Smart Home Device IP Address (page 9)**: (Optional) Enter the IP address of the smart home device you are accessing. 
* **Smart Home Device MAC Address (page 10)**: (Optional) Enter the MAC address of the smart home device you are accessing.

## Tips

* Make sure to fill in all required fields accurately and thoroughly.
* If you are unsure about any field, please ask your supervisor or the system administrator for clarification.
* If you need to access the smart home system, please submit this form and we will review your request and respond as soon as possible.
