# Scentsy Action Plan - Help Guide
## Purpose
The Scentsy Action Plan form is a tool for consultants to document and track their actions, providing a single source of truth for project managers and stakeholders to monitor progress and performance.

## How To Complete This Form
To complete the Scentsy Action Plan form, follow these steps:

1. Select the form ID (page 1).
2. Enter your consultant name.
3. Fill in the start date for the action plan.
4. Fill in the end date for the action plan.
5. Choose the status of the action plan from the dropdown menu.

## Field-by-Field Explanation
* **Form ID (Page 1)** (`form_id_1`, Number, Optional): This field is used to select the form ID for the action plan. You can choose a specific ID from the available options.
* **Consultant Name** (`consultant_name`, Text, Optional): Enter your name as a consultant to associate your action plan with your identity.
* **Start Date** (`start_date`, Date, Optional): Fill in the date when the action plan starts.
* **End Date** (`end_date`, Date, Optional): Fill in the date when the action plan ends.
* **Status** (`status_1`, Select, Optional): Choose from the available status options to indicate the current state of the action plan.
