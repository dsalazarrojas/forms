# Project Budget Form - Help Guide
## Purpose
The Project Budget Form is used to track and manage project budgets, including project name, budgeted and actual costs, project type, and status.

## How To Complete This Form
To complete this form, please enter the following information:

1. **Project Name** (`project_name`): Enter the name of the project.
2. **Budget Start Date** (`budget_start_date`): Enter the start date of the project budget period.
3. **Budget End Date** (`budget_end_date`): Enter the end date of the project budget period.
4. **Budgeted Costs** (`budgeted_costs`): Enter the budgeted costs for the project.
5. **Actual Costs** (`actual_costs`): Enter the actual costs for the project.
6. **Project Type** (`project_type`): Select the type of project from the provided options (e.g., "Type 1", "Type 2").
7. **Project Status** (`project_status`): Select the status of the project from the provided options (e.g., "Active", "Archived").
8. **Comments** (`comments`): Enter any additional comments or notes about the project.
9. **Budgeted Costs Breakdown** (`budgeted_costs_breakdown`): Enter a brief breakdown of the budgeted costs.
10. **Actual Costs Breakdown** (`actual_costs_breakdown`): Enter a brief breakdown of the actual costs.
11. **Project Budget Notes** (`project_budget_notes`): Enter any additional notes about the project budget.
12. **Budgeted Personnel Costs** (`budgeted_personnel_costs`): Enter the budgeted personnel costs for the project.
13. **Actual Personnel Costs** (`actual_personnel_costs`): Enter the actual personnel costs for the project.
14. **Budgeted Travel Costs** (`budgeted_travel_costs`): Enter the budgeted travel costs for the project.
15. **Actual Travel Costs** (`actual_travel_costs`): Enter the actual travel costs for the project.
16. **Project Budget ID** (`project_budget_id`): Enter a unique ID for the project budget.
17. **Assigned Tool** (`assigned_tool`): Enter the tool or resource assigned to the project.
18. **Project Budget Form Version** (`project_budget_form_version`): Enter the version of the project budget form.
19. **Project Budget Form Last Updated** (`project_budget_form_last_updated`): Enter the date and time the form was last updated.
20. **Project Budget Form Last Updated By** (`project_budget_form_last_updated_by`): Enter the user who last updated the form.
21. **Project Budget Form Last Updated Date** (`project_budget_form_last_updated_date`): Enter the date the form was last updated.
22. **Project Budget Form Last Updated Time** (`project_budget_form_last_updated_time`): Enter the time the form was last updated.
23. **Form IDs** (`form_ids`): Enter any additional form IDs associated with the project.
24. **Category** (`category`): Enter the category of the project.

Please note that some fields are required and should be filled in accordingly. If you are unsure about any field, please consult with the project manager or administrator for guidance.
