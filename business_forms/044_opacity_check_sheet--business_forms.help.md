# Opacity Check Sheet - Help Guide
## Purpose
The Opacity Check Sheet is used to record and track data related to plant maintenance or inspections, including findings, notes, and results.

## How To Complete This Form

### Step 1: Gather the required information
Enter the plant ID, technician ID, and any relevant data specific to your plant, technician, and ERP systems.

### Step 2: Fill out the form sections
Fill out the form in the following sections:

*   **Plant ID**: Enter the unique identifier for the plant being checked.
*   **Technician ID**: Enter the identification number for the technician performing the check.
*   **Date**: Record the date of the check.
*   **Start Time** and **End Time**: Record the start and end times of the check.
*   **Opacity Data**: Select the opacity levels to be checked (e.g., 0, 1, 2).
*   **ERP Data**: Select the relevant ERP data (e.g., 123, 456).
*   **Plant Data**: Select any relevant data specific to the plant (e.g., XYZ).
*   **Technician Data**: Select the data for the technician performing the check (e.g., ABC).
*   **Stack Check**: Select the stack check data and ERP data (e.g., 1, 2, 3).
*   **Comments**: Record any additional comments or notes.
*   **Email**: Enter a contact email address.
*   **Phone**: Enter a contact phone number.

### Step 3: Review and submit your data
Once you have filled out the form, review your entries to ensure they are accurate and complete. Then, click submit to save your data.

## Field-by-Field Explanation

*   **Plant ID** (`plant_id`, number, required): The unique identifier for the plant being checked.
*   **Technician ID** (`technician_id`, number, required): The identification number for the technician performing the check.
*   **Date** (`date_field`, date, required): The date of the check.
*   **Start Time** and **End Time** (`start_time` and `end_time`, time, optional): Record the start and end times of the check.
*   **Opacity Data** (`opacities_data`, select_multiple, required): Select the opacity levels to be checked (e.g., 0, 1, 2).
*   **ERP Data** (`erp_data`, select_one, optional): Select the relevant ERP data (e.g., 123, 456).
*   **Plant Data** (`plant_data`, select_multiple, optional): Select any relevant data specific to the plant (e.g., XYZ).
*   **Technician Data** (`technician_data`, select_one, optional): Select the data for the technician performing the check (e.g., ABC).
*   **Stack Check** (`stack_check`, select_one, optional): Select the stack check data (e.g., 1, 2, 3).
*   **Stack Check Data** (`stack_check_data`, select_multiple, optional): Select the stack check data (e.g., 1, 2, 3).
*   **Stack Check ERP Data** (`stack_check_erp_data`, select_one, optional): Select the stack check ERP data (e.g., ABC).
*   **Stack Check Plant Data** (`stack_check_plant_data`, select_multiple, optional): Select the stack check plant data (e.g., PQR).
*   **Stack Check Technician Data** (`stack_check_technician_data`, select_one, optional): Select the stack check technician data (e.g., XYZ).
*   **Stack Check Comments** (`stack_check_comments`, text, optional): Record any additional comments or notes specific to the stack check.
*   **Opacities Check** (`opacities_check`, select_one, optional): Select the opacities check data (e.g., 1, 2, 3).
*   **Opacities Monitoring** (`opacities_monitoring`, select_multiple, optional): Select the opacities monitoring data (e.g., 0, 1, 2).
*   **Opacities Data** (`opacities_data`, text, optional): Record any additional opacities data.
*   **Comments** (`comments`, text, optional): Record any general comments or notes.
*   **Email** (`email`, email, optional): Enter a contact email address.
*   **Phone** (`phone`, text, optional): Enter a contact phone number.

### Tips

*   Be sure to fill out all required fields accurately and completely.
*   If a field is not required, it is optional, but it may still be useful to provide additional information.
*   Review your entries before submitting to ensure accuracy and completeness.
*   If you have any questions or need further clarification, refer to the relevant sections in this help guide.
