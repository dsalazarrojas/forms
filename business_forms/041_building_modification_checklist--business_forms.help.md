# Building Modification Checklist - Help Guide
## Purpose
The Building Modification Checklist is a form used to document and verify modifications made to a building. The form ensures that all modifications are properly documented and approved, and that all necessary checks and inspections have been completed.

## How To Complete This Form

### General Guidance

1. Review each section carefully and ensure that you have all the necessary information.
2. Complete each field accurately and thoroughly.
3. If unsure about any part of the process, refer to the project manager or supervisor.

### Step-by-Step Instructions

1. **Project name**: Enter the name of the project.
2. **Modification date**: Enter the date the modification was made.
3. **Inspector or Project Manager name**: Enter the name of the inspector or project manager assigned to the project.
4. **Building address**: Enter the address of the building modified.
5. **Building permit obtained**: Select one of the options to indicate whether a building permit was obtained.
6. **Permit number**: (Optional) Enter the permit number if applicable.
7. **Design plans approved by owner**: Select one of the options to indicate whether design plans have been approved by the owner.
8. **Contractor is properly licensed**: Select one of the options to indicate whether the contractor is properly licensed.
9. **Contractor insurance current and adequate**: Select one of the options to indicate whether the contractor's insurance is current and adequate.
10. **Safety plan approved**: Select one of the options to indicate whether the safety plan has been approved.
11. **Walls removed or modified**: Select one of the options to indicate whether walls were removed or modified.
12. **Structural support modifications**: Select one of the options to indicate whether structural support modifications were made.
13. **Foundation or basement work**: Select one of the options to indicate whether foundation or basement work was completed.
14. **Electrical modifications made**: Select one of the options to indicate whether electrical modifications were made.
15. **Electrical panel upgrades**: Select one of the options to indicate whether electrical panel upgrades were needed or completed.
16. **New circuits or outlets installed**: Select one of the options to indicate whether new circuits or outlets were installed.
17. **Plumbing modifications made**: Select one of the options to indicate whether plumbing modifications were made.
18. **Water line modifications**: Select one of the options to indicate whether water line modifications were made.
19. **Drainage modifications**: Select one of the options to indicate whether drainage modifications were made.
20. **HVAC system modifications**: Select one of the options to indicate whether HVAC system modifications were made.
21. **Ductwork modifications**: Select one of the options to indicate whether ductwork modifications were made.
22. **Structural integrity verification**: (Note) Review and acknowledge the structural integrity of the building.
23. **Structural engineer inspection**: Select one of the options to indicate whether a structural engineer inspection was completed.
24. **Fire safety compliance**: Select one of the options to indicate whether the building meets fire safety compliance standards.
25. **Emergency exits remain accessible**: Select one of the options to indicate whether emergency exits remain accessible.
26. **ADA accessibility compliance**: Select one of the options to indicate whether the building meets ADA accessibility standards.
27. **Code violations identified**: Select one of the options to indicate whether code violations were identified.
28. **Final inspection and closeout**: (Note) Review and acknowledge that all necessary checks and inspections have been completed.
29. **Final walkthrough completed**: Select one of the options to indicate whether a final walkthrough was completed.
30. **Punch list items completed**: Select one of the options to indicate whether all punch list items were completed.
31. **Certificates of completion received**: Select one of the options to indicate whether all necessary certificates of completion were received.
32. **All documentation properly filed**: Select one of the options to indicate whether all documentation is properly filed.
33. **Inspector notes and comments**: (Optional) Enter any notes or comments from the inspector.
34. **Follow-up inspections needed**: Select one of the options to indicate whether follow-up inspections are needed.
