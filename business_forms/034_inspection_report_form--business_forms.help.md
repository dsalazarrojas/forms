# inspection_report_form - Help Guide
## Purpose
The inspection report form is designed to gather information for a comprehensive inspection report, which is used for various purposes such as documenting safety and compliance checks for workplaces or facilities, conducting inspections of construction sites, and recording property condition assessments for real estate transactions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked with an asterisk (\*). These fields are marked as required and must be completed for the form to be valid.
2. Select the relevant options from the dropdown menus for fields such as category, assigned_tool, form_ids, and output_format.
3. Fill in the necessary details for fields such as title, description, assigned_location, and submitted_by.

## Field-by-Field Explanation

* **title** (1, text, required): Enter a brief title for the inspection report.
* **description** (2, text, required): Provide a description of the inspection report, including the purpose and scope of the inspection.
* **category** (3, select_one, required): Select the category of the inspection report from the available options (Business Forms or Inspection Forms).
* **assigned_tool** (4, select_one, required): Select the tool assigned to the inspection report from the available options (chatjimmy or Other).
* **form_ids** (5, select_multiple, required): Select the form IDs that are relevant to the inspection report from the available options.
* **property_condition** (6, date, required): Enter the date of the property condition assessment.
* **safety_and_compliance_checks** (7, select_multiple, required): Select the safety and compliance checks performed during the inspection.
* **construction_site** (8, select_multiple, required): Select the construction site that was inspected.
* **property_condition_assessments** (9, select_multiple, required): Select the property condition assessments performed during the inspection.
* **date_completed** (10, date, required): Enter the date the inspection was completed.
* **time_completed** (11, time, required): Enter the time the inspection was completed.
* **comments** (12, note, optional): Provide any additional comments or observations related to the inspection.
* **email** (13, email, required): Enter the email address of the person completing the form.
* **phone** (14, text, required): Enter the phone number of the person completing the form.
* **output_file** (15, select_one, required): Select the format for the output file (PDF or Other).
* **output_format** (16, select_one, optional): Select the format for the output file (pdf or Other).
* **output_filename** (17, text, optional): Enter a name for the output file.
* **output_path** (18, text, optional): Enter the path where the output file will be saved.
* **assigned_user** (19, select_one, required): Select the user assigned to the inspection report from the available options (chatjimmy or Other).
* **assigned_group** (20, select_multiple, required): Select the group assigned to the inspection report from the available options.
* **assigned_date** (21, date, required): Enter the date assigned to the inspection report.
* **assigned_time** (22, time, required): Enter the time assigned to the inspection report.
* **assigned_location** (23, text, required): Enter the location assigned to the inspection report.
* **submitted_by** (24, select_one, optional): Select the person who submitted the inspection report from the available options (user1 or Other).
* **submitted_date** (25, date, optional): Enter the date the inspection report was submitted.
* **submitted_time** (26, time, optional): Enter the time the inspection report was submitted.

## Tips
* Make sure to review the form carefully before submitting it to ensure all required fields are completed.
* Double-check the information entered in the form for accuracy and completeness.
* If you have any doubts or questions about the form, please seek guidance from an authorized person.
* This form is designed to be used by authorized personnel only.
