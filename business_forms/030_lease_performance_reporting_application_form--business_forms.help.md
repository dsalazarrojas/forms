# lease-performance-reporting-application-form - Help Guide
## Purpose
This form is designed to gather information about lease performance data for landlords or property managers to analyze and make informed decisions about tenant relationships, property management, and potential lease renewals.
## How To Complete This Form
1. Select the lease performance response:
   - If yes, proceed to the next fields.
   - If no, skip to the next step.
2. Select the reporting period:
   - Choose one of the 12 months or seasons.
3. Enter the reporting date (start and end):
   - Fill in the start and end dates for the reporting period.
4. Select the lease type:
   - Choose between residential, commercial, or industrial.
5. Select the lease term:
   - Choose the lease term from 6-12 months, 1-2 years, 2-5 years, or 5+ years.
6. Select the lease status:
   - Choose between active, inactive, or terminated.
7. Enter the lease performance score:
   - Input a numerical value to represent the lease's performance level.
8. Enter any additional comments about the lease performance:
   - Provide any notes or observations about the lease's performance.
9. (Optional) Select the reporting period for the next section:
   - Choose one of the 12 months or seasons.
10. (Optional) Enter the reporting date for the next section:
    - Fill in the start and end dates for the next reporting period.
11. (Optional) Select the lease type for the next section:
    - Choose between residential, commercial, or industrial.
12. (Optional) Select the lease term for the next section:
    - Choose the lease term from 6-12 months, 1-2 years, 2-5 years, or 5+ years.
13. (Optional) Select the lease status for the next section:
    - Choose between active, inactive, or terminated.
14. Enter any comments or observations about the lease performance for the next section:
    - Provide any additional notes or comments about the lease's performance.
14. Submit the form.

## Field-by-Field Explanation

* **lease-performance** (Select Multiple, required): 
    - This field helps to identify if the lease is performing well or poorly.
* **reporting-period** (Select One, required): 
    - This field helps determine when the lease performance data is being reported. Please select one of the 12 months or seasons.
* **lease-type** (Select One, required): 
    - This field helps identify the type of lease (residential, commercial, or industrial).
* **lease-term** (Select One, required): 
    - This field helps determine the length of time of the lease (6-12 months, 1-2 years, 2-5 years, or 5+ years).
* **lease-status** (Select One, required): 
    - This field helps determine the status of the lease (active, inactive, or terminated).
* **lease-performance-score** (Number, required): 
    - This field is used to input the lease's performance level.
* **lease-performance-comment** (Text, required): 
    - Provide any comments or observations about the lease's performance.
* **reporting-date-start** and **reporting-date-end** (Date, required): 
    - Fill in the start and end dates for the reporting period.
* **lease-performance-reporting-period-2** (Select One, optional): 
    - This field is used for the next reporting period's data.
* **lease-type-2** (Select One, optional): 
    - This field is used to select the lease type for the next section.
* **lease-term-2** (Select One, optional): 
    - This field is used to select the lease term for the next section.
* **lease-status-2** (Select One, optional): 
    - This field is used to select the lease status for the next section.
* **lease-performance-score-2** (Number, optional): 
    - This field is used to input the lease's performance level for the next section.
* **lease-performance-comment-2** (Text, optional): 
    - This field is used for additional comments or observations about the lease's performance for the next section.
* **reporting-date-start** and **reporting-date-end** (Date, optional): 
    - This field is used for the start and end dates of the next reporting period.

## Tips
* Ensure that you have filled in all required fields before submitting the form.
* If a field is not applicable or not relevant to your situation, you can leave it blank.
* Double-check your entries for accuracy before submitting the form.
* If you are unsure about any field or have questions, please contact the form's administrator or support team.
