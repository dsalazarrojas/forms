# Environmental Permit Extension Form - Help Guide

## Purpose
The Environmental Permit Extension Form is designed to help you extend the validity of an environmental permit. This form is typically used when you need to renew or update an existing permit to continue operating within the environmental regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your selection from the "Business Type" dropdown menu.
2. Select all relevant permit types from the "Permit Type" multi-select menu.
3. Enter the date you would like to request the permit extension.
4. Choose the contact person responsible for the permit.
5. Enter your phone number and email address.
6. Add any additional comments or notes about your application.

## Field-by-Field Explanation

* **Business Type**: Select the type of business or organization submitting this form (e.g., Company, Organization, Individual). This information helps us identify your business and ensure that the extension is processed correctly.
	+ Type: Select One
	+ Required: Optional
* **Permit Type**: Select all permit types that you need to extend (e.g., Air Permit, Water Permit, Waste Permit). You can choose multiple options by holding down the Shift key while selecting.
	+ Type: Select Multiple
	+ Required: Optional
* **Request Date**: Enter the date you would like the permit to be extended from. This date should be in the format MM/DD/YYYY.
	+ Type: Date
	+ Required: Optional
* **Contact Person**: Choose the person responsible for handling the permit extension (e.g., Manager, Supervisor, Employee).
	+ Type: Select One
	+ Required: Optional
* **Phone**: Enter your phone number where you can be reached regarding this permit extension.
	+ Type: Text
	+ Required: Optional
* **Email**: Enter your email address where you can be reached regarding this permit extension.
	+ Type: Email
	+ Required: Optional
* **Note**: Add any additional comments or notes about your application. This is optional, but can be helpful for us to review your request.
	+ Type: Note
	+ Required: Optional
