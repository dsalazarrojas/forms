# To Do Reminder - Help Guide
## Purpose
The "To Do Reminder" form is used to create a reminder for a task with a specified deadline. It allows you to set a reminder for a task, which will be visible to you and other team members if they have permission to access the related tools.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Title" field with a brief description of the task.
2. Enter a valid "Deadline" date for the task reminder.
3. In the "To Do List" field, select 'True' to mark the task as completed or 'False' to indicate it is not completed.
4. If necessary, add any personal notes in the "Personal Notes" field.
5. If the task is assigned to a specific tool, enter the tool's ID in the "Tool ID" field.
6. Fill out the "Form ID" field with the ID of the form that this reminder belongs to.
7. Enter the title of the related tool in the "Tool Title" field.
8. Select the category of the tool in the "Tool Category" field.
9. Fill out the "Form Title" field with the title of the form that this reminder belongs to.
10. Finally, click the "Submit" button to create the reminder.

## Field-by-Field Explanation
- **Title** (text, required/optional: required): Enter a brief description of the task.
- **Deadline** (date, required/optional: required): Enter a valid date for the task reminder.
- **To Do List** (select multiple, required/optional: required): Select 'True' to mark the task as completed or 'False' to indicate it is not completed.
- **Personal Notes** (text, required/optional: optional): Add any personal notes about the task.
- **Assigned Tool** (text, required/optional: optional): If the task is assigned to a specific tool, enter the tool's ID.
- **Created By** (text, required/optional: optional): Enter the name of the user who created the reminder.
- **Created At** (date, required/optional: required): Enter the date and time the reminder was created.
- **Updated By** (text, required/optional: optional): Enter the name of the user who last updated the reminder.
- **Updated At** (date, required/optional: required): Enter the date and time the reminder was last updated.
- **Deleted By** (text, required/optional: optional): Enter the name of the user who deleted the reminder.
- **Deleted At** (date, required/optional: required): Enter the date and time the reminder was deleted.
- **Description** (text, required/optional: optional): Add a description of the task.
- **Category** (text, required/optional: optional): Select the category of the tool related to the reminder.
- **Tool ID** (text, required/optional: optional): Enter the ID of the tool related to the reminder.
- **Form ID** (text, required/optional: optional): Enter the ID of the form that this reminder belongs to.
- **Tool Title** (text, required/optional: optional): Enter the title of the tool related to the reminder.
- **Tool Category** (text, required/optional: optional): Select the category of the tool related to the reminder.
- **Form Title** (text, required/optional: optional): Enter the title of the form that this reminder belongs to.
