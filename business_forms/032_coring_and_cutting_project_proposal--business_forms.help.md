# coring_and_cutting_project_proposal - Help Guide

## Purpose

This form is used to create a project proposal for coring and cutting projects. It helps to gather all relevant information about the project, including its title, location, start and end dates, budget, and details about the project manager, client, and files associated with the project.

## How To Complete This Form

1. Enter a title for the project.
2. Provide the name of the company or entity involved in the project.
3. Briefly describe the project.
4. Enter the location of the project.
5. Enter the start and end dates of the project.
6. Enter the budget for the project.
7. Select the status of the project.
8. Enter the name of the project manager.
9. Enter the contact phone number of the project manager or contact person.
10. Enter the email of the project manager or contact person.
11. Add any additional project notes.
12. Enter comments about the project.
13. Enter the name of the client.
14. Enter the company of the client.
15. Enter the address of the client.
16. Enter the phone number of the client.
17. Enter the email of the client.
18. Add any notes about the client.
19. Select the files associated with the project from the options provided.
20. Enter a name for the file.
21. Briefly describe the file.
22. Enter the size of the file.
23. Select the type of file (e.g., PDF, DOCX, DOC, JPG, TXT, CSV).
24. Enter a link to the file (optional).

## Field-by-Field Explanation

* **Project Title** (text, required/optional): Enter a brief and descriptive title for the project.
* **Company** (text, required/optional): Provide the name of the company or entity involved in the project.
* **Project Description** (text, required/optional): Briefly describe the project.
* **Project Location** (text, required/optional): Enter the location of the project.
* **Project Start Date** (date, required/optional): Enter the start date of the project.
* **Project End Date** (date, required/optional): Enter the end date of the project.
* **Project Budget** (number, required/optional): Enter the budget for the project.
* **Project Status** (text, required/optional): Select the status of the project.
* **Project Manager** (text, required/optional): Enter the name of the project manager.
* **Contact Phone** (text, required/optional): Enter the contact phone number of the project manager or contact person.
* **Contact Email** (email, required/optional): Enter the email of the project manager or contact person.
* **Project Notes** (note, required/optional): Add any additional project notes.
* **Project Comments** (text, required/optional): Enter comments about the project.
* **Client Name** (text, required/optional): Enter the name of the client.
* **Client Company** (text, required/optional): Enter the company of the client.
* **Client Address** (text, required/optional): Enter the address of the client.
* **Client Phone** (text, required/optional): Enter the phone number of the client.
* **Client Email** (email, required/optional): Enter the email of the client.
* **Client Notes** (note, required/optional): Add any notes about the client.
* **Project File Upload** (select_multiple, required/optional): Select the files associated with the project from the options provided.
* **File Name** (text, required/optional): Enter a name for the file.
* **File Description** (text, required/optional): Briefly describe the file.
* **File Size** (number, required/optional): Enter the size of the file.
* **File Type** (select_one, required/optional): Select the type of file (e.g., PDF, DOCX, DOC, JPG, TXT, CSV).
* **File Link** (text, required/optional): Enter a link to the file (optional).
