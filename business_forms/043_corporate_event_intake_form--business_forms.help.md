# Corporate Event Intake Form - Help Guide
## Purpose
The Corporate Event Intake Form is used to collect information about corporate events, meetings, conferences, or workshops. This form helps gather essential details for event planning, coordination, and registration.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of event (Meeting, Conference, Trade Show, Seminar, or Workshop) that you are submitting.
2. Enter the start and end dates for the event in the format YYYY-MM-DD.
3. Provide a list of attendees, if applicable.
4. Enter the location details and venue where the event will take place.
5. Describe the event in a brief summary.
6. Specify the event time slot.
7. Enter your contact information so we can reach out to you for further coordination.

## Field-by-Field Explanation
* **Event Type**: Select the type of event (Meeting, Conference, Trade Show, Seminar, or Workshop) that you are submitting.
* **Event Details**: Enter the basic details about the event, such as its purpose and focus.
* **Attendees List**: List the attendees, if any, for the event.
* **Start Date**: Enter the start date for the event in the format YYYY-MM-DD.
* **End Date**: Enter the end date for the event in the format YYYY-MM-DD.
* **Location Details**: Enter the address, city, state, and country of the event location.
* **Venue**: Enter the specific venue name where the event will take place.
* **Event Description**: Provide a brief summary of the event.
* **Event Time**: Specify the time slot for the event.
* **Contact Info**: Enter your contact information so we can reach out to you for further coordination.

## Tips
* Make sure to fill out all required fields to ensure we can process your event submission correctly.
* If you have any attachments or supporting documents, please attach them to your submission for reference.
* If you have any questions or concerns, feel free to reach out to us for assistance.
