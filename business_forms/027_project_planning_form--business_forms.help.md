# Project Planning Form - Help Guide
## Purpose
The Project Planning Form is a tool used to collect and document project details for better organization and management. It's essential for project teams, managers, and stakeholders to use this form for accurate and thorough project planning.

## How To Complete This Form
1.  Select "Project" from the "project_manager" field to assign the project manager.
2.  Enter the project title, which will be the name of the project.
3.  Choose the start and end dates of the project.
4.  Select the project's priority level (if applicable).
5.  Enter a brief description of the project.
6.  Select the project status (if applicable).
7.  Choose the project type (if applicable).
8.  Add any additional notes about the project.
9.  Enter the email address of the project lead.
10. Enter the phone number of the project lead.
11. Enter the name of the project lead.
12. Enter the project status update.
13. Enter the team members involved in the project.
14. Select the task status.
15. Enter the type of task (if applicable).
16. Enter the priority of the task.
17. Enter the hours spent on the task.
18. Enter the start and end dates of the task.
19. Enter any task status updates.
20. Enter notes about the task.
21. Enter the email address of the project lead.
22. Enter the phone number of the project lead.

## Field-by-Field Explanation

* **project_name** (Text, Required): Enter the name of the project.
* **project_manager** (Select One, Optional): Choose the project manager from the provided options.
* **start_date** (Date, Required): Enter the start date of the project.
* **end_date** (Date, Required): Enter the end date of the project.
* **priority** (Select Multiple, Optional): Select the priority level of the project (if applicable).
* **description** (Text, Required): Enter a brief description of the project.
* **project_status** (Select One, Optional): Choose the project status (if applicable).
* **project_type** (Select Multiple, Optional): Select the project type (if applicable).
* **notes** (Note, Required): Add any additional notes about the project.
* **email** (Email, Required): Enter the email address of the project lead.
* **phone** (Text, Required): Enter the phone number of the project lead.
* **project_lead** (Text, Required): Enter the name of the project lead.
* **status_update** (Text, Required): Enter the project status update.
* **team_members** (Text, Required): Enter the team members involved in the project.
* **task_status** (Select One, Optional): Select the task status (if applicable).
* **task_type** (Text, Required): Enter the type of task (if applicable).
* **task_priority** (Number, Required): Enter the priority of the task.
* **task_hours** (Number, Required): Enter the hours spent on the task.
* **task_start_date** (Date, Required): Enter the start date of the task.
* **task_end_date** (Date, Required): Enter the end date of the task.
* **task_status_update** (Text, Required): Enter any task status updates.
* **task_notes** (Note, Required): Enter notes about the task.
* **project_lead_email** (Email, Required): Enter the email address of the project lead.
* **project_lead_phone** (Text, Required): Enter the phone number of the project lead.
* **project_lead** (Text, Required): Enter the name of the project lead.
