# User Logon Activity Report - Help Guide
## Purpose
The User Logon Activity Report form is used to collect information about user logon and logoff activities within a system. This form helps system administrators or IT staff to track user activity, troubleshoot issues, and ensure system security.

## How To Complete This Form
1. Fill in the User Details section with the relevant information about the user.
2. Enter the Logon/Logoff Time in date format (e.g., 2022-02-20 14:30).
3. Select the Activity Type (e.g., Login, Log off, Both, or Other).
4. Choose the Device (e.g., PC, Mobile, or Other).
5. Enter the Location where the activity occurred (e.g., Office, Home, or Other).
6. Select the Submitting Party (e.g., IT, Security, or Other).
7. Choose the Submission Status (e.g., Success, Failed, or Partially Successful).
8. Enter the User IP and User Agent information (if available).
9. Enter the User OS and Device Type information (if available).
10. Provide any additional Device Details or Browser information if necessary.
11. Indicate if the form was submitted by a user or not.
