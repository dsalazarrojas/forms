# Order Fulfillment Communication Form - Help Guide
## Purpose
The Order Fulfillment Communication Form is used to communicate with customers regarding their orders. This form provides an update on the status of a customer's order, which can be new, open, cancelled, pending, closed, or on-hold.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the customer's name in the "Customer Name" field.
2. Enter the order number in the "Order Number" field.
3. Select the current order status from the "Order Status" dropdown menu.
4. Provide a brief description of the order details in the "Order Details" field.
5. Choose the shipping method from the "Shipping Method" dropdown menu.
6. Enter the shipping date in the "Shipping Date" field.
7. Enter the shipping time in the "Shipping Time" field.
8. If you have any additional comments or messages for the customer, enter them in the "Customer Message" field.

## Field-by-Field Explanation
* **Customer Name** (`text`, **required: false**): Enter the customer's name as it appears on their order documents.
* **Order Number** (`number`, **required: false**): Enter the number of the customer's order.
* **Order Status** (`select_one`, **required: false**): Select the current status of the customer's order from the options: New, Open, Cancelled, Pending, Closed, or On-Hold.
* **Order Details** (`text`, **required: false**): Provide a brief description of the customer's order.
* **Shipping Method** (`select_one`, **required: false**): Choose the shipping method for the customer's order from the options: DHL, FedEx, UPS, USPS, or On-site Pickup.
* **Shipping Date** (`date`, **required: false**): Enter the date of the customer's shipment.
* **Shipping Time** (`time`, **required: false**): Enter the time of the customer's shipment.
* **Customer Message** (`text`, **required: false`): Enter any additional comments or messages for the customer.

## Tips
* Make sure to enter the customer's name and order number correctly to ensure accurate order tracking.
* If an order status is changed, select the new status from the dropdown menu.
* Be as brief as possible when providing order details, but make sure to include all necessary information.
* Choose the shipping method that best suits the customer's needs.
* Double-check the shipping date and time for accuracy.
