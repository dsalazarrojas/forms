# property_compliance_office_contact_form - Help Guide
## Purpose
This form is used to gather contact information for properties under the office's supervision, allowing for efficient communication and issue resolution.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all relevant options from the "Contact Us" page that apply to you, using the available options ("Yes" or "No").
2. If applicable, upload any necessary documentation for the property.
3. Provide detailed information about any property compliance issue on the "Report Property Compliance Issue" page.
4. Enter the email address of the contact person in the "Contact The Compliance Office" field.
5. Select the relevant property details from the "Property Details" page.

## Field-by-Field Explanation
* **Contact Us** (Select Multiple, Required: False):
	+ Select "Yes" if you are a contact person for this property, or "No" if you are not.
* **Upload Documentation** (Number, Required: False):
	+ Upload any relevant documents or attachments for the property.
* **Report Property Compliance Issue** (Note, Required: False):
	+ Provide a detailed description of the issue related to property compliance.
* **Contact The Compliance Office** (Email, Required: False):
	+ Enter the email address of the contact person for the compliance office.
* **Property Details** (Select One, Required: False):
	+ Select one of the available options: "Address", "Contact Information", or "Lease Agreement".

## Tips
- Make sure to accurately select all relevant options from the "Contact Us" page.
- Ensure that the uploaded documentation is clear and easily accessible.
- Provide a detailed description of the issue on the "Report Property Compliance Issue" page.
- Verify that the email address entered in the "Contact The Compliance Office" field is correct.
- Choose the most relevant property details to ensure efficient communication and issue resolution.
