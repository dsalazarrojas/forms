# Trade Reference Form - Help Guide
## Purpose
The Trade Reference Form is used to collect reference information for a business transaction.

## How To Complete This Form
1. Fill out the form with the required and optional fields as described below.
2. Ensure that all fields are accurately completed to the best of your ability.
3. Submit the form to proceed with the trade.

## Field-by-Field Explanation
* **Trade Reference Form (trade_reference_form)** (`trade_reference_form`, Text, Optional):
	+ A brief description of the trade reference. Please enter a short description of the trade.
* **Trade Reference Form** (`trade_reference_form_business`, Text, Optional):
	+ This field is not currently in use. Please ignore or leave blank.
* **Reference ID (reference_id)** (`reference_id`, Text, Optional):
	+ Enter the reference ID, if applicable.
* **Reference Type (reference_type)** (`Reference Type`, Select One, Optional):
	+ Select "Yes" if the reference is applicable, otherwise select "No".
* **Client Name (client_name)** (`Client Name`, Text, Optional):
	+ Enter the client's name.
* **Client Email (client_email)** (`Client Email`, Email, Optional):
	+ Enter the client's email address.
* **Client Phone (client_phone)** (`Client Phone`, Text, Optional):
	+ Enter the client's phone number.
* **Reference Status (reference_status)** (`Reference Status`, Select One, Optional):
	+ Select "Active" if the reference is active, otherwise select "Inactive".

## Tips
* Ensure that all fields are accurately completed before submitting the form.
* If you're unsure about any field, please contact your supervisor or colleague for guidance.
* This form is for business purposes only; do not use for personal or testing purposes.
