# Project Management Tool Access Form - Help Guide
## Purpose
The Project Management Tool Access Form is used to manage access to tools within the project management toolset. This form allows administrators to grant access to specific tools for team members, project managers, and other users.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields, including project name, tool name, access start date, tool access level, project status, tool status, project type, user type, and assigned user status.
2. Choose the correct options for project manager status, project status, tool access level, and tool access notes.
3. Select the project type and tool access level.
4. Fill in the tool description and project status date if required.

## Field-by-Field Explanation
* **Project Manager** (Select Multiple, required): Choose who has project management access.
* **Team Member** (Text, optional): Enter the team member's name.
* **Team Member Email** (Email, optional): Enter the team member's email address.
* **Tool Name** (Text, required): Enter the tool name.
* **Access Level** (Select One, required): Choose the access level for the tool.
* **Access Start Date** (Date, required): Enter the start date for tool access.
* **Access End Date** (Date, optional): Enter the end date for tool access.
* **Assigned Tool** (Select One, required): Choose if the tool is assigned to a user.
* **Tool Access Level** (Number, required): Enter the access level for the tool.
* **Tool Description** (Text, optional): Enter a description for the tool.
* **Project Name** (Text, required): Enter the project name.
* **Tool Version** (Text, optional): Enter the tool version.
* **User Access Level** (Select Multiple, required): Choose the access level for the users.
* **Notes** (Note, required): Enter any notes about the tool access.
* **Project Status** (Select One, required): Choose the project status.
* **Tool Status** (Select One, required): Choose the tool status.
* **Project Type** (Select Multiple, required): Choose the project type.
* **Assigned User** (Select One, required): Choose if the tool is assigned to a user.
* **User Type** (Select One, required): Choose the user type.
* **Project Status Date** (Date, optional): Enter the project status date.
* **Assigned Date** (Date, optional): Enter the assigned date.
* **Tool Access Notes** (Text, optional): Enter notes about the tool access.
* **Project Manager Status** (Select One, required): Choose the project manager status.
* **Tool Access** (Select Multiple, required): Choose the tool access.
* **Notes** (Note, required): Enter any notes about the tool access.
