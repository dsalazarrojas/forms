# Treasury Training Session Request Form - Help Guide
## Purpose
The Treasury Training Session Request Form is a document used to submit requests for treasury training sessions. This form is intended for employees within an organization to request training on treasury-related topics.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide user information in the **User Info** field.
2.  Enter session request details in the **Session Request Info** field.
3.  Provide session details and any additional information required in the **Session Details** field.
4.  Enter the trainer's information in the **Trainer Info** field.
5.  Specify the session scheduling details in the **Session Scheduling** field.
6.  Select the current status of the session in the **Session Status** field.
7.  Add any comments related to the session in the **Comments** field.
8.  Enter the trainer's phone number in the **Trainer Phone** field.
9.  Enter the trainer's email address in the **Trainer Email** field.
10.  Provide submitter information in the **Submitter Info** field.

## Field-by-Field Explanation

*   **User Info** (User Info, Text, Optional):
    *   A field to input user information.
*   **Session Request Info** (Session Request Info, Text, Optional):
    *   A field to enter session request details.
*   **Session Details** (Session Details, Text, Optional):
    *   A field to provide session details and any additional information required.
*   **Trainer Info** (Trainer Info, Text, Optional):
    *   A field to enter the trainer's information.
*   **Session Scheduling** (Session Scheduling, Text, Optional):
    *   A field to specify session scheduling details.
*   **Session Status** (Session Status, Text, Optional):
    *   A field to select the current status of the session.
*   **Comments** (Comments, Text, Optional):
    *   A field to add any comments related to the session.
*   **Trainer Phone** (Trainer Phone, Text, Optional):
    *   A field to enter the trainer's phone number.
*   **Trainer Email** (Trainer Email, Email, Optional):
    *   A field to enter the trainer's email address.
*   **Submitter Info** (Submitter Info, Text, Optional):
    *   A field to provide submitter information.
