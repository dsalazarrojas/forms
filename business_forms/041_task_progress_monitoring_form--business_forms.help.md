# Task Progress Monitoring Form - Help Guide

## Purpose
This form is designed to help you track the progress of tasks. It's a crucial tool for ensuring that tasks are completed on time and to the best of your abilities. By using this form, you can easily monitor and manage your tasks, helping you stay organized and focused on priority tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all tasks from the list that you have completed or are currently working on.
2. Choose the status of your task (Active or Inactive).
3. Set the priority of your task by providing a brief description of its importance.
4. Enter the start and end dates for your task, if applicable.
5. Indicate the progress you've made on the task, using a numerical value (e.g., 50%).
6. Mark the tasks that you have completed, selecting all that apply.
7. Briefly describe the task's purpose and goals, providing context for others.

## Field-by-Field Explanation
* **Task List** (`task_list`, select_multiple, optional): Select all tasks that you are working on or have completed. This helps track your tasks across multiple pages.
* **Task Status** (`task_status`, select_one, optional): Indicate whether your task is Active (in progress) or Inactive (completed or cancelled).
* **Task Priority** (`task_priority`, text, optional): Provide a brief description of the task's importance or priority level.
* **Start Date** (`start_date`, date, optional): Enter the date when the task started, if applicable.
* **End Date** (`end_date`, date, optional): Enter the date when the task is expected to be completed, if known.
* **Progress** (`progress`, number, optional): Enter a numerical value (0-100) to indicate the progress made on the task.
* **Completed Tasks** (`completed_tasks`, select_multiple, optional): Select all tasks that you have completed, to track your completed work.
* **Task Description** (`task_description`, text, optional): Provide a brief description of the task, including its goals and objectives.
