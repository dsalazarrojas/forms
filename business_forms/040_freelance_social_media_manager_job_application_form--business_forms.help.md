# Freelance Social Media Manager Job Application Form - Help Guide
## Purpose
The purpose of this form is to allow individuals to apply for a Freelance Social Media Manager position. Please fill out this form to submit your application.

## How To Complete This Form
1. Fill out each field as accurately and thoroughly as possible.
2. Ensure you meet the minimum requirements (e.g., job title, skills, job references).

## Field-by-Field Explanation
* **Job Title** (`job_title`, select_one, required): Select the job title that best describes the position you're applying for. Please choose from Social Media Manager, Content Manager, or Marketing Manager.
* **Name** (`name`, text, required): Enter your full name.
* **Email** (`email`, email, required): Enter a valid email address that we can use to contact you.
* **Phone** (`phone`, text, required): Enter your phone number so we can contact you about the application.
* **Experience** (`experience`, text, required): Describe your relevant experience in social media management.
* **Skills** (`skills`, select_multiple, required): Select all the skills you possess that are relevant to the position, such as Social Media, Content, Marketing, and Communication.
* **Availability** (`availability`, date, optional): If you're available to start immediately, leave this field blank. Otherwise, enter the date you can start working.
* **Job References** (`job_references`, select_multiple, required): Indicate whether you have job references. If yes, we'll need to contact them as part of the application process.
* **Portfolio** (`portfolio`, text, optional): If you have a relevant portfolio, attach it or paste a link to it.
* **Expected Salary** (`expected_salary`, number, optional): This field might not be relevant for freelancers, so you can leave it blank.
* **Notice Period** (`notice_period`, time, optional): This field might not be necessary for freelancers, so you can leave it blank.
* **Agreement** (`agreement`, date, optional): This field might not be necessary for freelancers, so you can leave it blank.
* **Agreement Expiration** (`agreement_expiration`, date, optional): This field might not be necessary for freelancers, so you can leave it blank.

## Tips
* Make sure to review your application carefully before submitting it.
* If you have any questions or concerns, don't hesitate to contact us.

Note: As a general rule, it's always better to err on the side of caution and leave fields that are marked as optional empty unless you're certain they're relevant to your application.
