# Content Calendar Tool Requisition Form - Help Guide
## Purpose

The Content Calendar Tool Requisition Form is used to request a tool or resource for content creation, management, or project planning. This form helps ensure that all stakeholders are informed about the tools and resources needed for content creation and management, facilitating more efficient project planning and resource allocation. 

## How To Complete This Form

Before completing the form, please ensure that you have a clear understanding of what you are requesting. Review the form carefully and fill in all required fields. If you are unsure about any information or need clarification, contact the relevant team members or your supervisor.

## Field-by-Field Explanation

* **Requester Full Name** (`requester_name`, text, required): Enter your full name for identification purposes.
* **Requester Identification Number** (`requester_id`, text, required): Enter your identification number (e.g., employee ID or account number).
* **Tool or Resource Name** (`tool_name`, text, required): Clearly specify the name of the tool or resource you are requesting.
* **Description of the Tool or Resource** (`tool_description`, text, required): Provide a short description of the tool or resource, including its key features and functionalities.
* **Tool Category** (`tool_category`, select_one, required): Select the category under which the tool/resource fits (e.g., SEO, Social Media, Content Management, Project Management, Analytics, Design, or Other).
* **Justification for the Requisition** (`reason_for_requisition`, text, required): Clearly explain why you are requesting this tool or resource, including how it will benefit the organization or team.
* **Requested Start Date for Tool Use** (`requested_start_date`, date, required): Enter the date when you plan to start using the tool or resource.
* **Requisition Form Completed?** (`requisition_form_completed`, select_one, required): Confirm that you have completed this form accurately and truthfully, indicating that it is completed or not. 

Note: Fields marked as `required` must be filled out. Non-required fields are optional and can be left blank if not relevant to your request. 

## Tips

* If you are requesting multiple resources or tools, please submit separate forms for each resource.
* Make sure to proofread your form for any errors before submitting.
* If you are unsure about any information, contact the relevant team members or your supervisor.
* This form is used to facilitate project planning and resource allocation, so ensure that all necessary information is provided to facilitate these processes.
