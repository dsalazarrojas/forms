# Vendor Transaction Audit Request Form - Help Guide
## Purpose
The Vendor Transaction Audit Request Form is used to request an audit on a transaction involving a third-party vendor. This form helps ensure that transactions are accurate, compliant, and in line with company policies.

## How To Complete This Form
1. Fill out the form with the details of the transaction you would like to audit.
2. Provide reasons for the requested review in the "Reasons for Review" section.
3. Attach any supporting files or documents that are relevant to the transaction in the "Supporting Files" section.
4. Select the current status of the transaction from the dropdown options.
5. Enter any contact information for the vendor, if necessary.
6. Submit the form to initiate the audit request.

## Field-by-Field Explanation
* **Transaction Details** (Required/Optional): Enter a brief description of the transaction, including the date, amount, and any relevant details.
* **Reasons for Review** (Required/Optional): Explain why you are requesting an audit on this transaction. This could include concerns about accuracy, compliance, or company policy.
* **Supporting Files** (Required/Optional): Attach any relevant documents or files that support your audit request.
* **Transaction Status** (Required/Optional): Select the current status of the transaction from the options:
	+ In Review
	+ Approved
	+ Rejected
* **Contact Vendor** (Required/Optional): If necessary, enter the contact information for the vendor, including their name, email, and phone number.

## Tips
* Make sure to be as detailed as possible when filling out the form.
* Attach any relevant supporting files or documents to ensure that your audit request is well-supported.
* If you are unsure about any field, please reach out to your supervisor for guidance.
