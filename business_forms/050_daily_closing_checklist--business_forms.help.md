# Daily Closing Checklist - Help Guide

## Purpose
The Daily Closing Checklist is a form designed to help users track and report on daily tasks and activities. It's intended to be completed at the end of each day to ensure that all tasks are accounted for and any issues or concerns are documented.

## How To Complete This Form
To complete the Daily Closing Checklist, follow these steps:

1. Review the form's pages and questions to ensure you understand what's being asked.
2. Choose the correct options for each page and question, such as selecting "Yes" or "No" for tasks and "Yes" or "No" for missed tasks.
3. Enter any relevant notes or observations in the "Notes" field.
4. Input the location where the tasks were completed.
5. Select the date when the tasks were completed.

## Field-by-Field Explanation

* **Tasks** (Select Multiple, id: 1): Choose the tasks that were completed during the day.
	+ Select "Yes" for tasks that were completed.
	+ Select "No" for tasks that were not completed.
* **Completed Tasks** (Select Multiple, id: 2): Choose the tasks that were actually completed.
	+ Select "Yes" for tasks that were completed.
	+ Select "No" for tasks that were not completed.
* **Notes** (Note, id: 3): Enter any additional comments or observations about the day's events.
* **Missed Tasks** (Select Multiple, id: 4): Choose the tasks that were missed or not started.
	+ Select "Yes" for tasks that were missed or not started.
	+ Select "No" for tasks that were completed.
* **Location** (Text, id: 5): Enter the location where the tasks were completed.
* **Date** (Date, id: 6): Select the date when the tasks were completed.

## Tips

* Make sure to review the form carefully before submitting it to avoid errors.
* If you're unsure about a particular task or activity, use the "Notes" field to provide more information.
* If you're unable to complete a task, select "Missed Tasks" to notify the relevant teams or managers.
