# To Do Details Form - Help Guide
## Purpose
The To Do Details Form is a crucial form for task management, allowing users to input task-specific details. This form will help you keep track of tasks and ensure their accurate and timely completion.

## How To Complete This Form
1. To fill out the "To Do Details Form," begin with the "Create Task" field where you will provide a brief description of the task.
2. In the "task_name" field, add a concise name for the task to help it get recognized in the system.
3. For tasks with specific deadlines, enter the "due_date" using the date format accepted by the system.
4. Select a user for the task from the "Assigned To" dropdown menu to designate the responsible person.
5. In the "Notes" field, add any additional comments or instructions about the task that may not fit into other fields.

## Field-by-Field Explanation
* **Create Task** (`Create Task`, `text`, required/optional: false): Enter a brief description of the task to create it in the system. This will serve as the starting point for task details.
* **task_name** (`task_name`, `text`, required/optional: false): Type in a concise name for the task. This title will be used to identify the task and distinguish it from others.
* **Due Date** (`due_date`, `date`, required/optional: false): Enter the date by which the task is to be completed. Use the date format accepted by the system.
* **Assigned To** (`assigned_to`, `select_one`, required/optional: false): Choose a user from the list who will be responsible for completing the task.
* **Notes** (`notes`, `note`, required/optional: false): Enter any additional comments or instructions about the task that may not fit into other fields.

## Tips
- Be sure to provide as much detail as necessary in the "Create Task" field to accurately represent the task.
- Use the "task_name" field to ensure the task title is descriptive and unique.
- In the "Assigned To" field, only select a user who is available and able to complete the task.
- In the "Notes" field, be concise and only include the most relevant information.
- Review all fields for completeness before submitting the form to ensure accurate task details.
