**Workflow Instruction Checklist - Help Guide**

## Purpose
The Workflow Instruction Checklist is a form designed to help project teams track and manage tasks, including their completion status, priority, and deadlines. This form allows project managers to assign tasks to team members and project managers, and track the progress of each task.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all relevant tasks from the "Task List" section (page 1).
2. Enter the completion date for each selected task in the "Completion Date" section (page 2).
3. Choose the project manager responsible for each task from the "Project Manager" section (page 3).
4. Select the status of each task from the "Status" section (page 4).
5. Choose the team leader responsible for each task from the "Team Leader" section (page 5).
6. Add any additional notes about the task in the "Notes" section (page 6).
7. Select the priority level of each task from the "Priority" section (page 7).
8. Enter the email of the project manager responsible for each task in the "Project Manager Email" section (page 8).
9. Enter the phone number of the project manager responsible for each task in the "Project Manager Phone" section (page 9).
10. Finally, enter the deadline for each task in the "Deadline" section (page 10).
