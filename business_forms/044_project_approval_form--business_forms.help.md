# project_approval_form - Help Guide
## Purpose

This form is used for project approval. It collects information from project contacts, including project fees, contact name, email, phone number, and other relevant details. It is designed to be completed by project contacts to provide necessary information for project approval processes.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure you have all necessary information about the project before starting the form.
2. Enter the project fees (if applicable).
3. Enter the contact name for the project.
4. Enter the email address associated with the contact.
5. Enter the phone number of the contact.
6. Select the consent options that apply to the project.
7. Select the terms and conditions that apply to the project.

## Field-by-Field Explanation

* **project_fees** (`project_fees`, number, required/optional): Enter the fees associated with the project, if applicable.
* **contact_name** (`contact_name`, text, required/optional): Enter the name of the contact person for the project.
* **email** (`email`, email, required/optional): Enter the email address associated with the contact person.
* **phone_number** (`phone_number`, text, required/optional): Enter the phone number of the contact person.
* **consent** (`consent`, select_multiple, required/optional): Select the consent options that apply to the project. This field allows you to choose from multiple options.
* **terms_and_conditions** (`terms_and_conditions`, select_one, required/optional): Select the terms and conditions that apply to the project. This field allows you to choose one option.

## Tips

* Make sure to fill in all required fields to ensure the form is complete and accurate.
* If you are unsure about any field, contact the project manager or support team for assistance.
* Review and verify the information entered before submitting the form.
* Ensure you have the necessary approvals and permissions before submitting the form.
* The form is designed to be completed by project contacts, so ensure you have the necessary authority to complete it.
