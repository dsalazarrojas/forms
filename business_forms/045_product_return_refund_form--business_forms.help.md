# Product Return Refund Form - Help Guide
## Purpose
This form is designed to collect information for a product return refund. It is used by customers to submit a request for a refund on a product they have purchased from our company.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the customer name, order date, and order number in the corresponding fields.
2. Select the reason for return from the options provided.
3. Enter the return date and any additional return note if necessary.
4. Enter any customer note if necessary.
5. Enter the customer's email address, phone number, shipping address, billing address, and zip code.
6. Enter a brief description of the product and its id.
7. Enter the price of the product and the amount of the refund.
8. Select the payment method used for the original purchase.
9. Select the shipping method used for the original delivery.
10. Select the current shipping status and order status of the product.
11. Select the return status of the product.
12. Select the order status update.
13. Select the customer status update.
14. Enter the product return id if known.
15. Enter the username of the person submitting the form.

## Field-by-Field Explanation

* **Customer Name**: Enter the full name of the customer.
* **Order Date**: Enter the date the order was placed.
* **Order Number**: Enter the number of the order.
* **Reason for Return**: Select the reason for returning the product.
* **Return Date**: Enter the date the return is expected to be processed.
* **Return Note**: Enter any additional information about the return.
* **Customer Note**: Enter any additional information from the customer.
* **Customer Email**: Enter the email address of the customer.
* **Customer Phone**: Enter the phone number of the customer.
* **Customer Shipping Address**: Enter the shipping address of the customer.
* **Customer Billing Address**: Enter the billing address of the customer.
* **Customer Zip**: Enter the zip code of the customer.
* **Product Description**: Enter a brief description of the product.
* **Product Id**: Enter the id of the product.
* **Product Price**: Enter the price of the product.
* **Refund Amount**: Enter the amount of the refund.
* **Payment Method**: Select the payment method used for the original purchase.
* **Shipping Method**: Select the shipping method used for the original delivery.
* **Shipping Status**: Select the current shipping status of the product.
* **Order Status**: Select the current status of the order.
* **Return Status**: Select the status of the product return.
* **Order Status Update**: Select the update on the order status.
* **Customer Status Update**: Select the update on the customer status.
* **Product Return Id**: Enter the id of the product return.
* **Submitted By**: Enter the name of the person submitting the form.
