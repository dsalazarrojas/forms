# Rdc Check List - Help Guide
## Purpose
This form is designed to input metadata for a specific business form, providing a way to store and manage information about a form. The form includes fields for title, category, description, assigned tool, and form ID.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the form in the `form_title` field.
2. Select the category of the form from the `business_forms` dropdown (if available).
3. Add a brief description of the form in the `n_a` field.
4. If applicable, select the tool assigned to the form in the `assigned_tool` field.
5. Enter the ID of the form in the `form_id` field (if required).

## Field-by-Field Explanation
* **Title** (`form_title`, Text, required: false): Enter the title of the form that you want to input metadata for.
* **Category** (`business_forms`, Text, required: false): Select the category of the form from the dropdown list. If no categories are available, leave this field blank.
* **Description** (`n_a`, Note, required: false): Add a brief description of the form. This field is a rich text area, allowing you to enter multiple lines of text.
* **Assigned Tool** (`assigned_tool`, Text, required: false): If a tool is assigned to the form, select it from this field.
* **Form ID** (`form_id`, Number, required: false): Enter the ID of the form. If this field is required, please enter the exact ID of the form.
