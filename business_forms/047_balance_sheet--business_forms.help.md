# Balance Sheet - Help Guide
## Purpose
This form is designed to collect balance sheet information from businesses, including their assets, liabilities, and equity. The data collected will help businesses report their financial situation at a specific date.

## How To Complete This Form

1. Click on the "Submit" button to start filling out the form.
2. Select the "Company Name" field to input the name of the company.
3. Enter the "Reporting Date" in the format of mm/dd/yyyy.
4. Choose the "Fiscal Period" from the dropdown menu (Monthly, Quarterly, Annual, or Other).
5. Enter the values for each asset category (Current Assets, Fixed Assets, etc.) in the respective fields.
6. Enter the values for each liability category (Accounts Payable, Short-Term Debt, etc.) in the respective fields.
7. Enter the value for "Total Current Liabilities" and "Total Liabilities".
8. Enter the value for "Shareholders Equity" in the respective field.

## Field-by-Field Explanation

* **Company Name** (`company_name`, Required): Enter the name of the company.
* **Reporting Date** (`reporting_date`, Required): Enter the date of the financial report (mm/dd/yyyy).
* **Fiscal Period** (`fiscal_period`, Required): Choose the period for which the financial report is being submitted (Monthly, Quarterly, Annual, or Other).
* **Current Assets - Cash** (`current_cash`, Required): Enter the current cash value in dollars.
* **Accounts Receivable** (`accounts_receivable`, Optional): Enter the accounts receivable value in dollars.
* **Inventory** (`inventory`, Optional): Enter the inventory value in dollars.
* **Other Current Assets** (`other_current`, Optional): Enter the other current assets value in dollars.
* **Total Current Assets** (`total_current_assets`, Required): Calculated total value of current assets.
* **Fixed Assets (Property, Equipment)** (`fixed_assets`, Optional): Enter the fixed assets value in dollars.
* **Less Accumulated Depreciation** (`accumulated_depreciation`, Optional): Enter the accumulated depreciation value in dollars.
* **Intangible Assets** (`intangible_assets`, Optional): Enter the intangible assets value in dollars.
* **Total Assets** (`total_assets`, Required): Calculated total value of all assets.
* **Accounts Payable** (`accounts_payable`, Optional): Enter the accounts payable value in dollars.
* **Short-Term Debt** (`short_term_debt`, Optional): Enter the short-term debt value in dollars.
* **Other Current Liabilities** (`other_current_liabilities`, Optional): Enter the other current liabilities value in dollars.
* **Total Current Liabilities** (`total_current_liabilities`, Required): Calculated total value of current liabilities.
* **Long-Term Debt** (`long_term_debt`, Optional): Enter the long-term debt value in dollars.
* **Total Liabilities** (`total_liabilities`, Required): Calculated total value of all liabilities.
* **Common Stock** (`common_stock`, Optional): Enter the common stock value in dollars.
* **Retained Earnings** (`retained_earnings`, Optional): Enter the retained earnings value in dollars.

## Tips
* Make sure to enter accurate and up-to-date information.
* Review the form carefully before submitting to ensure all fields are completed correctly.
* If you have any questions or concerns, contact your financial advisor or accounting team.
