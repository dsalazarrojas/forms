# Vendor Settlement Authorization Application Form - Help Guide

## Purpose
The Vendor Settlement Authorization Application Form is designed to capture essential information required for settling payments with vendors. This form will be used to gather details about the vendor's banking information, settlement dates, and payment terms.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the vendor's settlement form, providing all the required information.
2. Select the vendor's authorization method and payment terms.
3. Enter the vendor's banking details, including their bank account number, branch, and routing number.
4. Fill out the payment schedule and payment method.
5. Provide the vendor's contact information, including their email and phone number.
6. Add any additional notes or comments about the vendor's contact information.
7. Review the form for accuracy before submitting it for processing.

## Field-by-Field Explanation

* **Vendor Settlement Form** (`vendor_settlement_form`, text, optional): This is the first field on the form where you can provide any relevant information about the vendor's settlement details.
* **Vendor Settlement Authorization** (`vendor_settlement_authorization`, select_one, optional): Select the type of authorization required for settlement, which can be Option 1, Option 2, or Option 3.
* **Vendor Details** (`vendor_details`, text, optional): Please provide the vendor's banking details here.
* **Bank Account Details** (`bank_account_details`, text, optional): This is where you can enter any additional banking details about the vendor's account.
* **Vendor Bank Account** (`vendor_bank_account`, number, optional): Enter the vendor's bank account number here.
* **Settlement Details** (`settlement_details`, text, optional): This is where you can provide any additional settlement details required.
* **Date of Settlement** (`date_of_settlement`, date, optional): Select the date of the settlement.
* **Time of Settlement** (`time_of_settlement`, time, optional): Select the time of the settlement.
* **Settlement Amount** (`settlement_amount`, number, optional): Enter the settlement amount here.
* **Payment Terms** (`payment_terms`, select_one, optional): Select the payment terms required for the settlement, which can be Option 1, Option 2, or Option 3.
* **Payment Schedule** (`payment_schedule`, select_multiple, optional): Select multiple payment schedules required for the settlement, which can be Option 1, Option 2, or Option 3.
* **Vendor Contact** (`vendor_contact`, text, optional): Please provide the vendor's contact information here.
* **Vendor Contact Email** (`vendor_contact_email`, email, optional): Enter the vendor's email address here.
* **Vendor Contact Phone** (`vendor_contact_phone`, text, optional): Enter the vendor's phone number here.
* **Vendor Contact Note** (`vendor_contact_note`, note, optional): Add any additional notes about the vendor's contact information.
* **Payment Method** (`payment_method`, select_multiple, optional): Select the payment method required for the settlement, which can be Option 1, Option 2, or Option 3.
* **Bank Account Number** (`bank_account_number`, text, optional): Enter the vendor's bank account number here.
* **Bank Branch** (`bank_branch`, text, optional): Enter the vendor's bank branch here.
* **Bank Routing Number** (`bank_routing_number`, text, optional): Enter the vendor's bank routing number here.
* **Bank Name** (`bank_name`, text, optional): Enter the bank name here.
* **Bank Address** (`bank_address`, text, optional): Enter the bank's address here.
* **Vendor Bank Name** (`vendor_bank_name`, text, optional): Enter the vendor's bank name here.
* **Vendor Tax ID** (`vendor_tax_id`, text, optional): Enter the vendor's tax ID here.
* **Payment Term** (`payment_term`, select_one, optional): Select the payment term required for the settlement, which can be Option 1, Option 2, or Option 3.
* **Payment Term Note** (`payment_term_note`, note, optional): Add any additional notes about the payment term.

## Tips
- Double-check all fields before submitting the form to ensure accuracy.
- If a field is not required, you can leave it blank.
- If you have any questions or concerns, please contact the relevant authorities for assistance.
