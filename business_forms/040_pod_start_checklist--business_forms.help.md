# Pod Start Checklist - Help Guide

## Purpose
The "Pod Start Checklist" form is a crucial tool for project managers to collect essential information about a project before it begins. This form ensures that all necessary details are captured, and project teams get started on the right foot.

## How To Complete This Form

1.  Review the form's sections and fields to understand what information is required.
2.  Start by filling in the "Project Details" section, which includes project title and any additional details.
3.  Move on to the "Team Members" section, where you'll select the team members involved in the project. You can choose from "Yes" or "No" for each team member.
4.  In the "Task Responsibilties" and "Meeting Details" sections, provide any relevant text descriptions for the project's tasks and meeting details.
5.  Set the project and meeting start and end dates and times using the "Start Date" and "End Date" fields.
6.  Determine the project and meeting status by selecting "Active" or "Inactive" from the "Task Status" and "Meeting Status" fields.
7.  Capture project notes and comments in the "Project Notes" and "Comments" fields.
8.  Identify project owners and team leads by selecting "Yes" or "No" from the "Project Owner" and "Team Lead" fields.
9.  For the project and meeting start and end dates and times, select the correct options from the "Pod Start Date" and "Pod End Date" fields.
10. In the "Meeting Location" field, enter the location where the meeting will take place.

## Field-by-Field Explanation

*   **Project Details** (`project_details`, text, required): Enter a brief description of the project.
*   **Team Members** (`team_members`, select_multiple, required): Choose the team members involved in the project by selecting "Yes" or "No".
*   **Task Responsibilties** (`task_responsibilities`, text, optional): Provide any relevant text description for the project's tasks.
*   **Start Date** (`start_date`, date, required): Set the project start date.
*   **End Date** (`end_date`, date, required): Set the project end date.
*   **Meeting Time** (`meeting_time`, time, required): Set the meeting start and end times.
*   **Task Status** (`task_status`, select_one, required): Select "Active" or "Inactive" for the task status.
*   **Task Notes** (`task_notes`, note, optional): Enter any additional notes for the task.
*   **Task Responsibility Status** (`task_responsibility_status`, select_multiple, optional): Choose "Active" or "Inactive" for the task responsibility status.
*   **Comments** (`comments`, text, optional): Enter any additional comments.
*   **Project Owner** (`project_owner`, select_one, required): Select "Yes" or "No" to indicate if the project has a owner.
*   **Pod Start Date** (`pod_start_date`, date, required): Set the project start date.
*   **Pod End Date** (`pod_end_date`, date, required): Set the project end date.
*   **Pod Meeting Time** (`pod_meeting_time`, time, required): Set the project meeting start and end times.
*   **Project Status** (`project_status`, select_one, required): Select "Active" or "Inactive" for the project status.
*   **Project Notes** (`project_notes`, note, optional): Enter any additional project notes.
*   **Team Lead** (`team_lead`, select_one, required): Select "Yes" or "No" to indicate if the team has a lead.
*   **Comments** (`comments`, text, optional): Enter any additional comments.
*   **Meeting Details** (`meeting_details`, text, optional): Enter any relevant text description for the meeting.
*   **Meeting Status** (`meeting_status`, select_one, optional): Choose "Active" or "Inactive" for the meeting status.
*   **Meeting Notes** (`meeting_notes`, note, optional): Enter any additional meeting notes.
*   **Project Manager** (`project_manager`, select_one, required): Select "Yes" or "No" to indicate if the project has a manager.
*   **Pod Lead** (`pod_lead`, select_one, required): Select "Yes" or "No" to indicate if the project has a lead.
*   **Meeting Location** (`meeting_location`, text, optional): Enter the location where the meeting will take place.
*   **Assigned To** (`assigned_to`, select_one, required): Select "Yes" or "No" to indicate if the project is assigned to someone.

## Tips

*   Make sure to fill in all required fields before submitting the form.
*   Double-check all dates and times for accuracy.
*   Use clear and concise language when filling in text fields.
*   Select the correct options for select fields to ensure accurate project and meeting status.
*   Review and proofread the form before submitting to avoid errors.

By following this guide, users will be able to complete the "Pod Start Checklist" form efficiently and accurately, ensuring that all necessary information is captured and project teams get started on the right foot.
