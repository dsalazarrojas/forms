# Work Order Completion Acknowledgement Form - Help Guide
## Purpose
The Work Order Completion Acknowledgement Form is used to confirm the completion of a work order and any related confirmations and comments.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the form carefully to ensure you understand what is being asked.
2. Fill out the form with the relevant information, taking care to select the correct options for each field.

## Field-by-Field Explanation
* **Work Order Completion Acknowledgement** (`work_order_completion_acknowledgement`, note, optional): This field is a free-form text box where you can type any notes or comments related to the completion of the work order.
* **Date Completed** (`date_completed`, date, optional): Enter the date when the work order was completed.
* **Time Completed** (`time_completed`, time, optional): Enter the time when the work order was completed.
* **Client Confirmation** (`client_confirmation`, select one, optional): Select 'Yes' if the client has confirmed the completion of the work order, 'No' otherwise.
* **Business Confirmation** (`business_confirmation`, select multiple, optional): Select one or more options to indicate which parts of the work order were completed.
* **Comments** (`comments`, text, optional): Enter any additional comments or notes related to the completion of the work order.
* **Assigned To** (`assigned_to`, select one, optional): Select 'Yes' if the work order was assigned to someone, 'No' otherwise.
* **Assigned Tool** (`assigned_tool`, select one, optional): Select 'Yes' if a specific tool was used for the work order, 'No' otherwise.
* **Form ID** (`form_id`, number, optional): This field is used for internal tracking purposes and should not be filled out by the user.
