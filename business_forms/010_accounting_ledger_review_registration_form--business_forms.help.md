# Accounting Ledger Review Registration Form - Help Guide
## Purpose
This form is used to register an accounting ledger review. It gathers information about the ledger to be reviewed, the person performing the review, and the specific review details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields:
   * Full Name: Enter the name of the person registering the review.
   * Employee ID: Enter the ID of the employee registering the review.
   * Ledger Name or Number: Enter the name or number of the ledger to be reviewed.
   * Ledger Type: Select the type of ledger (e.g., General Ledger, Subsidiary Ledger - AP, Subsidiary Ledger - AR).
   * Review Cycle: Select the frequency of the review (e.g., Monthly, Quarterly, Semiannually, Annually).
   * Scheduled Review Date: Enter the date the review is scheduled.
   * Contact Phone for Follow-up: Enter a phone number for the reviewer to contact for follow-up.

2. Optionally, fill out the following fields:
   * Preferred Review Time: Enter a preferred time for the review, if desired.
   * Special Instructions for Reviewer: Enter any special instructions or notes for the reviewer.

3. Select the focus areas for the review by choosing from the list of options. You can select multiple areas.

## Field-by-Field Explanation
### Full Name
* **Full Name**: Enter the name of the person registering the review.

### Employee ID
* **Employee ID**: Enter the ID of the employee registering the review.

### Ledger Name or Number
* **Ledger Name or Number**: Specify the name or number of the ledger to be reviewed.

### Ledger Type
* **Ledger Type**: Select the type of ledger (e.g., General Ledger, Subsidiary Ledger - AP, Subsidiary Ledger - AR).

### Review Cycle
* **Review Cycle**: Select the frequency of the review (e.g., Monthly, Quarterly, Semiannually, Annually).

### Scheduled Review Date
* **Scheduled Review Date**: Enter the date the review is scheduled.

### Preferred Review Time
* **Preferred Review Time**: Enter a preferred time for the review, if desired.

### Focus Areas
* **Focus Areas**: Select priority items for this review (e.g., Reconciliation Discrepancies, Large Value Transactions, Duplicate Entries, Aging Analysis).

### Special Instructions for Reviewer
* **Special Instructions for Reviewer**: Enter any special instructions or notes for the reviewer.

### Contact Phone for Follow-up
* **Contact Phone for Follow-up**: Enter a phone number for the reviewer to contact for follow-up.

## Tips

* Make sure to register all required fields accurately and completely.
* If you have any special instructions or notes for the reviewer, enter them in the "Special Instructions for Reviewer" field.
* If you want to specify a preferred time for the review, enter it in the "Preferred Review Time" field.
* You can select multiple focus areas for the review by choosing from the list of options.
