# Peacekeeping Cost Assessment - Help Guide
## Purpose
The Peacekeeping Cost Assessment form is used to record and analyze actual and estimated costs associated with various peacekeeping efforts.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the currency in which the actual cost is denominated. 
2. Select the currency in which the estimated cost is denominated.
3. Enter the actual cost.
4. Enter the estimated cost.
5. Select the type of cost (fixed, variable, or fixed and variable).
6. Select the actual and estimated currency type.
7. Enter any additional notes about the actual and estimated costs.
8. Enter the actual and estimated cost variance.
9. Enter the actual and estimated cost.
10. Select the notes type (fixed, variable, or fixed and variable).
11. Select the actual and estimated currency type.
