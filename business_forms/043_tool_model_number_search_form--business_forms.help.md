# Tool Model Number Search Form - Help Guide
## Purpose
The Tool Model Number Search Form is designed to help you quickly search for tool models based on various criteria, such as model number, supplier, store, date, and time. This form can help you find the desired tool model by providing a simple and straightforward way to input the necessary information.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the desired search criteria from the available options.
2. Enter the required information in the corresponding fields.
3. Click on the "Search" button to execute the search.

## Field-by-Field Explanation

* **Model Number**: Enter the model number of the tool you are searching for.
* **Supplier**: Select the supplier of the tool you are searching for.
* **Store**: Select the store where the tool is available.
* **Date**: Select the date when the tool was purchased or used.
* **Time**: Select the time when the tool was purchased or used.
* **Note**: Enter any additional notes or comments about the tool.
* **Email**: Enter your email address (optional).
* **Phone**: Enter your phone number (optional).
* **Search Results**: This field will display the results of your search.
* **Assigned Tool**: Select the tool that is assigned to you.
* **Tool Model Number**: Enter the model number of the tool you are searching for (repeated from page 1).
* **Tool Number**: Enter the tool number of the tool you are searching for (repeated from page 1).
* **Date2**: Select the date when the tool was purchased or used (repeated from page 1).
* **Time2**: Select the time when the tool was purchased or used (repeated from page 1).
* **Note2**: Enter any additional notes or comments about the tool (repeated from page 1).
* **Email2**: Enter your email address (repeated from page 1).
* **Phone2**: Enter your phone number (repeated from page 1).
* **Supplier2**: Select the supplier of the tool you are searching for (repeated from page 1).
* **Store2**: Select the store where the tool is available (repeated from page 1).
* **Search Button2**: This button will execute the search for the second set of criteria.
* **Search Results2**: This field will display the results of your search for the second set of criteria.

Note: Some fields have the same label and functionality as their counterparts on other pages, but with a "2" suffix. This is due to the form's structure being split into multiple pages, each with a similar set of fields.
