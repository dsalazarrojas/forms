# Checklist For New Items - Help Guide
## Purpose
This form is used to collect information about new items being added to the catalog. It helps ensure that each item meets the required standards and is ready for launch.

## How To Complete This Form
1. Fill in the required fields with the correct information about the new item.
2. Select the corresponding status for each step in the review checklist.
3. Enter any blocker issues that are preventing the item from being ready for launch.
4. Select the overall readiness score for the item.
5. Confirm that all checklist items have been reviewed.

## Field-by-Field Explanation
* **Item Name / Title** (new_item_name_title, text, required): Enter the name and title of the new item.
* **Product / Item Category** (item_category_type, select_one, required): Choose the category for the new item (e.g. Hardware, Software Feature, Marketing Asset, etc.).
* **Project / Item Lead** (project_lead_name, text, required): Enter the name of the project lead responsible for the new item.
* **Target Launch Date** (target_launch_date, date, required): Enter the target launch date for the new item.
* **Initial Design Review Completed** (step_initial_design_review, select_one, required): Select whether the initial design review has been completed (Done, In Progress, N/A).
* **Quality Assurance Testing Passed** (step_quality_assurance_test, select_one, required): Select whether the quality assurance testing has been passed (Done, In Progress, Pending).
* **Pricing and Valuation Finalized** (step_pricing_valuation, select_one, required): Select whether the pricing and valuation has been finalized (Done, Under Review, N/A).
* **Legal and Compliance Approval** (step_legal_compliance_check, select_one, required): Select whether the legal and compliance approval has been received (Approved, Denied, Pending).
* **Marketing Collateral Prepared** (step_marketing_collateral, select_one, required): Select whether the marketing collateral has been prepared (Done, Not Started, N/A).
* **Key Specifications Summary** (item_specifications_summary, text, required): Enter a brief summary of the item's specifications (e.g. dimensions, technical requirements, etc.).
* **Documentation / BOM Link** (bill_of_materials_link, text, required): Enter a link to the internal documentation or bill of materials for the item.
* **Overall Readiness Score** (item_readiness_score, select_one, required): Select the overall readiness score for the item (1 - Needs Significant Work, 2 - Getting There, 3 - Ready for Beta, 4 - Ready for Launch).
* **Major Blocker Issues** (blocker_issues_identified, text, required): Enter any major blocker issues preventing the item from being ready for launch.
* **Date of Next Review Meeting** (next_review_meeting_date, date, required): Enter the date of the next review meeting for the item.
* **I confirm all checklist items have been reviewed** (check_completion_ack, select_one, required): Select whether all checklist items have been reviewed (Confirmed, Other).
