# Customer Product List Setup Form - Help Guide
## Purpose
This form is designed to allow administrators to set up a list of products for customers. This list will be used to display products to customers in the sales process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Product List" page (Page 1).
2. Choose the size of the product(s) you want to add to the list (Page 2).
3. Enter the price of the product(s) (Page 3).
4. Enter the name of the product(s) (Page 4).

## Field-by-Field Explanation

* **Product List** (Page 1): Select the page for the product list.
* **Size** (Page 2): Choose the size of the product you want to add to the list. You can select multiple sizes by holding down the Ctrl key (or Command key on a Mac) while clicking on the sizes.
* **Price** (Page 3): Enter the price of the product. You can enter a numerical value (e.g., 10.99).
* **Product Name** (Page 4): Enter the name of the product. For example, "Apple iPhone 12".

## Tips
Make sure to complete each field as accurately as possible to ensure that your product list is up to date and accurate.
