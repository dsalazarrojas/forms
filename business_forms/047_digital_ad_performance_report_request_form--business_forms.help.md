# Digital Ad Performance Report Request Form - Help Guide
## Purpose
This form is used to request a digital ad performance report for a specific campaign. The report will contain data about the campaign's performance, including metrics such as spend, clicks, impressions, and conversions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Date Range** for which you want to receive the report. Choose from **Last 30 days**, **Last 60 days**, or **Last 90 days**.
2. Choose the **Metrics** you want to include in the report. Select one or more of **Spend**, **Clicks**, **Impressions**, and **Conversions**.
3. Choose the **Campaign Status** of the campaign(s) you want to report on. Select **Active**, **Paused**, or **Finished**.
4. If you have any **Notes** about the campaign, you can include them in the text field.
5. Enter the **Email** address of the contact person for communication purposes.
6. Enter the **Phone** number of the contact person for communication purposes.
7. Enter the **Start Date** and **End Date** of the campaign if known.

## Field-by-Field Explanation
* **Campaign Details** (`campaign_details`, text, optional): This is the title of the campaign for which you are requesting the report.
* **Date Range** (`date_range`, select_one, optional): Select the time period for which you want to receive the report. Choose from **Last 30 days**, **Last 60 days**, or **Last 90 days**.
* **Metrics** (`metrics`, select_multiple, optional): Select one or more of **Spend**, **Clicks**, **Impressions**, and **Conversions** to include in the report.
* **Campaign Status** (`campaign_status`, select_one, optional): Select the status of the campaign for which you are requesting the report. Choose from **Active**, **Paused**, or **Finished**.
* **Notes** (`notes`, text, optional): If you have any information that is important to include in the report, enter them here.
* **Email** (`email`, email, required): Enter the email address of the contact person for communication purposes.
* **Phone** (`phone`, text, optional): Enter the phone number of the contact person for communication purposes.
* **Start Date** (`date_start`, date, optional): Enter the start date of the campaign if known.
* **End Date** (`date_end`, date, optional): Enter the end date of the campaign if known.
