# Fitness Membership Freeze Form - Help Guide
## Purpose
The Fitness Membership Freeze Form is used to freeze a fitness membership for a member of your gym or fitness center.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the reason for freezing the membership (e.g. Fitness, Non-Membership).
2. Enter the freeze date (the date on which the membership will be frozen).
3. Enter any additional reason or comments for freezing the membership (e.g. member is no longer active, member is on hold).
4. Enter the member's ID.
5. Enter the member's name.
6. Choose the freeze status (e.g. Active, Frozen).
7. Enter any freeze notes or additional comments.
8. Enter the member's email (if applicable).
9. Enter the member's phone number (if applicable).
10. Select the freeze by status (e.g. Active, Inactive, Cancelled).
11. Enter any additional notes or comments about the freeze by status.

## Field-by-Field Explanation

* **Freeze Membership** (`id: 1, type: select_one`): Select the reason for freezing the membership. This field will allow you to choose between Fitness and Non-Membership as the reason for freezing.
* **Freeze Date** (`id: 2, type: date`): Enter the date on which the membership will be frozen.
* **Reason** (`id: 3, type: note`): Enter any additional reason or comments for freezing the membership.
* **Comments** (`id: 4, type: note`): Enter any additional comments or notes about the freeze.
* **Member ID** (`id: 5, type: number`): Enter the member's ID number.
* **Member Name** (`id: 6, type: text`): Enter the member's name.
* **Freeze Status** (`id: 7, type: select_one`): Choose the freeze status for the member (e.g. Active, Frozen).
* **Notes** (`id: 8, type: text`): Enter any additional notes or comments about the freeze status.
* **Freeze Date Note** (`id: 9, type: note`): Enter any additional notes or comments about the freeze date.
* **Freeze Status Note** (`id: 10, type: note`): Enter any additional notes or comments about the freeze status.
* **Comments** (`id: 11, type: note`): Enter any additional comments or notes about the freeze.
* **Member Email** (`id: 12, type: email`): Enter the member's email address (if applicable).
* **Member Phone** (`id: 13, type: text`): Enter the member's phone number (if applicable).
* **Frozen By** (`id: 14, type: number`): Enter the ID of the person who froze the membership.
* **Freeze Date Start** (`id: 15, type: date`): Enter the start date of the freeze period.
* **Freeze Date End** (`id: 16, type: date`): Enter the end date of the freeze period.
* **Freeze Notes** (`id: 17, type: text`): Enter any additional notes or comments about the freeze.
* **Freeze Status Notes** (`id: 18, type: note`): Enter any additional notes or comments about the freeze status.
* **Member Status** (`id: 20, type: select_one`): Choose the member status (e.g. Active, Frozen, Cancelled).
* **Member Notes** (`id: 21, type: note`): Enter any additional notes or comments about the member.
