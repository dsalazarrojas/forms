# Retail Compliance Assessment Form - Help Guide
## Purpose
The Retail Compliance Assessment Form is used to evaluate the compliance of stores within a region with specific standards and regulations. It helps ensure that stores are meeting the required guidelines and standards.

## How To Complete This Form
1. Start by selecting the relevant store information from the dropdown options.
2. Complete each page of the form, ensuring that you answer all required fields.
3. Enter any additional comments or feedback in the "Comments" field.
4. Finally, enter the date the assessment was completed.

## Field-by-Field Explanation

### **Store Audit** (1)
* Store Audit: This is a note-taking field where you can record any observations or notes about the store during the assessment.
* Type: Note
* Required: No

### **Store Number** (2)
* Store Number: Enter the unique identifier number for the store being assessed.
* Type: Text
* Required: No

### **Store Name** (3)
* Store Name: Enter the name of the store being assessed.
* Type: Text
* Required: No

### **Region** (4)
* Region: Select the region where the store is located from the dropdown options.
* Type: Select One
* Required: No

### **Store Type** (5)
* Store Type: Indicate whether the store is 'True' (compliant) or 'False' (non-compliant) with the standards and regulations.
* Type: Select One
* Required: No

### **Compliance Standards** (6)
* Compliance Standards: Enter any additional information about the store's compliance with the standards.
* Type: Text
* Required: No

### **Comments** (7)
* Comments: Enter any additional comments or feedback about the store's compliance.
* Type: Text
* Required: No

### **Date Completed** (8)
* Date Completed: Enter the date the assessment was completed.
* Type: Date
* Required: No
