# Report Submission Authorization Form - Help Guide
## Purpose
The Report Submission Authorization Form is used to authorize the submission of a report.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the submitter.
2. Enter the submitter's email address.
3. Enter the report ID (if required by the organization).
4. Enter the date of report submission.

## Field-by-Field Explanation
* **Report Submission Authorization**: This is the main label for the form.
* **Submitter Name**: Enter the name of the person submitting the report. This is a required field.
* **Submitter Email**: Enter the email address of the person submitting the report. This is a required field.
* **Report ID**: Enter a report ID if it's required by the organization. This field is optional.
* **Report Submission Date**: Enter the date the report was submitted. This field is optional.

## Tips
* Make sure to fill out all required fields before submitting the form.
* Double-check your report ID if required, to ensure it's correct.
* Ensure the date of report submission is accurate.
