# Recruiter Phone Screen - Help Guide
## Purpose
The Recruiter Phone Screen form is used by recruiters or hiring managers to gather information about a candidate's screening performance. This form helps to assess a candidate's suitability for a particular position and collect contact details for follow-up communication.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the screen questions that apply to the candidate from the list of options.
2. Enter the candidate's name in the "Candidate Name" field.
3. Enter the contact email address of the candidate in the "Contact Email" field.
4. Enter the candidate's phone number in the "Contact Phone" field.
5. Add any additional notes about the candidate in the "Contact Note" field.

## Field-by-Field Explanation
* **Screen Questions** (`Screen Questions`, `Select Multiple`, required: false):
	+ Select all the screen questions that apply to the candidate from the list of options. This field allows you to choose which questions were asked during the phone screen.
* **Candidate Name** (`Candidate Name`, `text`, required: false):
	+ Enter the full name of the candidate.
* **Contact Email** (`Contact Email`, `email`, required: false):
	+ Enter the email address of the candidate.
* **Contact Phone** (`Contact Phone`, `text`, required: false):
	+ Enter the phone number of the candidate.
* **Contact Note** (`Contact Note`, `note`, required: false):
	+ Add any additional notes or comments about the candidate's performance during the phone screen.

## Tips
* Make sure to select all relevant screen questions that apply to the candidate.
* Double-check the candidate's contact information for accuracy.
* Use the "Contact Note" field to add any additional context or comments about the candidate's performance.
