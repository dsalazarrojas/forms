# Incomplete Work Items Report Form - Help Guide

## Purpose
The "Incomplete Work Items Report Form" is designed to report on incomplete work items that need attention. This form helps to capture relevant details about these items to provide a clear picture of their status and required actions.

## How To Complete This Form

To complete this form, follow these steps:

1. Select all incomplete work items by choosing "Yes" or "No" for "Work Items".
2. Fill in the "Report Date" field with the date the report is being made.
3. If a tool is assigned to fix this item, select "Yes" or "No" for "Assigned Tool".
4. Indicate who reported the item by selecting "Yes" or "No" for "Reported By".
5. Enter any comments or notes about the item in the "Reason" field.
6. Provide any user comments in the "User Comments" field.
7. Select the status of the work item as "Active" or "Inactive" for "Status".
8. If a tool is involved, select "Yes" or "No" for "Tool Comment".
9. Select the tool status as "Active" or "Inactive" for "Tool Status".
10. Indicate the type of tool used by selecting "Yes" or "No" for "Tool Type".
11. Select "Yes" or "No" for "Tool Comment" to indicate if the tool is commented on.
12. Select "Yes" or "No" for "Reported By User" to indicate if the user reported the item.
13. Select "Yes" or "No" for "Last Updated By" to indicate who last updated the item.
14. Enter the date the item was last updated in the "Last Updated Date" field.
15. Select "Yes" or "No" for "Tool Last Updated" to indicate if the tool was last updated.
16. Select "Yes" or "No" for "Tool Status 2" to indicate the tool's status.
17. Select "Yes" or "No" for "Tool Type 2" to indicate the tool's type.
18. Select "Yes" or "No" for "User Last Updated" to indicate if the user was last updated.
19. Select "Yes" or "No" for "Tool Last Updated By" to indicate who last updated the tool.
20. Enter the report ID in the "Report ID" field.
21. Select "Yes" or "No" for "Form Version" to indicate the form version.

* **Work Items** (`work_items`, select_multiple, optional): Select all incomplete work items by choosing "Yes" or "No".

* **Status** (`status`, select_one, optional): Select the status of the work item as "Active" or "Inactive".
* **Tool Comment** (`tool_comment`, select_one, optional): Select "Yes" or "No" for "Tool Comment" to indicate if the tool is commented on.
* **Tool Status** (`tool_status`, select_one, optional): Select the tool status as "Active" or "Inactive".
* **Tool Type** (`tool_type`, select_one, optional): Select "Yes" or "No" for "Tool Type" to indicate if the tool is used.
* **Reported By User** (`reported_by_user`, select_one, optional): Select "Yes" or "No" for "Reported By User" to indicate if the user reported the item.
* **Last Updated** (`last_updated`, date, optional): Enter the date the item was last updated.
* **Tool Last Updated** (`tool_last_updated`, select_one, optional): Select "Yes" or "No" for "Tool Last Updated" to indicate if the tool was last updated.
* **Tool Status 2** (`tool_status_2`, select_one, optional): Select "Yes" or "No" for "Tool Status 2" to indicate the tool's status.
