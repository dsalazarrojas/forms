# Process Efficiency Blueprint Request Form - Help Guide
## Purpose
This form is designed to aid users in submitting a detailed request for a process efficiency blueprint, aimed at identifying and addressing areas of inefficiency in business processes.

## How To Complete This Form
Before filling out this form, please ensure you have a clear understanding of the process you wish to improve and the specific pain points you'd like to address. This will help you provide accurate and relevant information.

1. **Pain Points**: Select all the pain points that you are experiencing in the current process. This will help the requestor understand the areas where improvements are needed.
2. **Process Details**: Provide a brief description of the current process, including its steps and any relevant context.
3. **Business Process**: Choose the correct category for the business process you are requesting improvements for.
4. **Current Process**: Select the current version of the process from the options provided.
5. **Business Process Description**: Describe the business process, including its purpose and how it functions.
6. **Pain Points Description**: Describe the specific pain points you selected earlier in detail.
7. **Requestor's Email**: Enter your email address where you can be reached for further discussion or follow-up questions.
8. **Requested By**: Enter your name or title for reference and accountability.
9. **Date Submitted**: This field is automatically filled in based on the date you submit the form.

## Field-by-Field Explanation
* **Pain Points**: 
  * This field allows you to identify the pain points in the current process.
  + Type: Select Multiple
  + Required: False
* **Process Details**: 
  + Type: Text
  + Required: False
* **Business Process**: 
  + Type: Select One
  + Required: False
* **Current Process**: 
  + Type: Select One
  + Required: False
* **Business Process Description**: 
  + Type: Text
  + Required: False
* **Pain Points Description**: 
  + Type: Text
  + Required: False
* **Requestor's Email**: 
  + Type: Email
  + Required: False
* **Requested By**: 
  + Type: Text
  + Required: False
* **Date Submitted**: 
  + Type: Date
  + Required: False

Note: The date submitted field is automatically filled in when the form is submitted.
