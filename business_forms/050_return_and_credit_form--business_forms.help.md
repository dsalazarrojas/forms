# return_and_credit_form - Help Guide

## Purpose
The return_and_credit_form is used to document the return or credit process for a purchase, including the reason for the return, the amount to be credited, and the method of credit.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of return you wish to initiate, either Refund, Partial Refund, or Store Credit.
2. Enter the reason for the return in the return_reason field.
3. Enter the date of the return in the return_date field.
4. Enter the credit amount in the credit_amount field.
5. Choose the method of credit, either Cash, Check, or Credit Card.
6. Enter any additional comments in the return_comment field.
7. The seller can enter their comments in the seller_comment field.
8. The buyer can enter their response in the buyer_response field.
9. Select the status of the return, either Open or Closed.
10. Enter any additional comments about the status in the status_comment field.
11. Select whether the deleted_at timestamp is included in the return process.
12. Select whether the updated_at timestamp is included in the return process.
13. Select whether the created_at timestamp is included in the return process.

## Field-by-Field Explanation
* **return_page (Required: false)**: Select the type of return you wish to initiate, either Refund, Partial Refund, or Store Credit.
* **return_reason (Required: false)**: Enter the reason for the return.
* **return_date (Required: false)**: Enter the date of the return.
* **credit_amount (Required: false)**: Enter the amount to be credited.
* **credit_method (Required: false)**: Choose the method of credit, either Cash, Check, or Credit Card.
* **return_comment (Required: false)**: Enter any additional comments about the return.
* **seller_comment (Required: false)**: Enter any comments from the seller.
* **buyer_response (Required: false)**: Enter your response as the buyer.
* **return_status (Required: false)**: Select the status of the return, either Open or Closed.
* **status_comment (Required: false)**: Enter any additional comments about the status.
* **form_id (Required: false)**: Enter the ID of the form.
* **assigned_tool (Required: false)**: Enter the tool assigned to the form.
* **created_at (Required: false)**: Enter the time when the form was created.
* **updated_at (Required: false)**: Enter the time when the form was last updated.
* **deleted_at (Required: false)**: Enter the time when the form was deleted.
* **created_by (Required: false)**: Enter the user who created the form.
* **updated_by (Required: false)**: Enter the user who updated the form.
* **deleted_by (Required: false)**: Enter the user who deleted the form.
* **updated_user_id (Required: false)**: Enter the user ID of the form.
* **deleted_user_id (Required: false)**: Enter the user ID of the form.
* **created_user_id (Required: false)**: Enter the user ID of the form.
* **deleted_at_included (Required: false)**: Select whether the deleted_at timestamp is included in the return process.
* **updated_at_included (Required: false)**: Select whether the updated_at timestamp is included in the return process.
* **created_at_included (Required: false)**: Select whether the created_at timestamp is included in the return process.
