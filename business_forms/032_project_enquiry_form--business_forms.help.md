# Project Enquiry Form - Help Guide

## Purpose
The Project Enquiry Form is a tool used to gather information about a project from the customer. This form is used to collect details about the project's title, description, location, timeline, budget, project type, and other relevant information. This form helps the project team to understand the customer's requirements and expectations, and to create a project plan that meets those needs.

## How To Complete This Form

To complete this form, follow these steps:

*   Enter your name and ensure it matches your official name.
*   Provide your email address to ensure you can be contacted about the project.
*   Enter the name of your company.
*   Describe the project in detail, including its purpose and objectives.
*   Provide a description of the project, including any relevant background information.
*   Enter the deadline for the project.
*   Select the type of project you are enquiring about (e.g., "Option a" or "Option b").
*   Enter the location where the project will be carried out.
*   Enter the expected timeline for the project.
*   Enter the budget for the project.
*   Provide the name of the project manager responsible for the project.

## Field-by-Field Explanation

*   **Name** (Required): Enter your official name as it appears on your business cards or identification documents.
*   **Email** (Required): Enter your company email address where you can be contacted about the project.
*   **Company** (Required): Enter the name of your company, including any relevant details such as address or website.
*   **Project Description** (Required): Write a brief description of the project, including its purpose and objectives.
*   **Description of Project** (Required): Provide a detailed description of the project, including any relevant background information.
*   **Deadline** (Required): Enter the date by which the project must be completed.
*   **Project Type** (Required): Select the type of project you are enquiring about (e.g., "Option a" or "Option b").
*   **Location** (Required): Enter the location where the project will be carried out.
*   **Timeline** (Required): Enter the expected timeline for the project.
*   **Budget** (Required): Enter the budget for the project.
*   **Project Manager** (Required): Enter the name of the project manager responsible for the project.

## Tips

*   Before filling out this form, ensure that you have all the necessary information about the project.
*   Double-check your entries for accuracy and completeness.
*   If you have any questions or need help with filling out this form, contact the project team.
