# Design Brief 2 - Help Guide
## Purpose
This form is used to collect project details from clients to facilitate design project management and collaboration.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing a brief description of the project, including the project title (Field 1: What is the project?).
2. Add a detailed description of the project (Field 2: Project Description).
3. Enter the client's name and company (Field 3: Client Name).
4. Identify the contact person responsible for the project (Field 4: Contact Person).
5. Provide the contact person's email address (Field 5: Email).
6. Enter the contact person's phone number (Field 6: Phone).
7. Specify the project deadline (Field 7: Project Deadline).
8. Select the project type (Field 8: Project Type).
9. Indicate the project status (Field 9: Project Status).
10. Add any additional notes or comments for the client (Field 10: Client Notes).

## Field-by-Field Explanation

* **What is the project?** (`business_form`, text, required: false): A brief description of the project, e.g., "Logo redesign for XYZ Corp."
* **Project Description** (`project_description`, text, required: false): A detailed description of the project, including its objectives and scope.
* **Client Name** (`company_name`, text, required: false): The name of the client's company.
* **Contact Person** (`contact_person`, text, required: false): The person responsible for the project at the client's company.
* **Email** (`contact_email`, email, required: false): The contact person's email address.
* **Phone** (`contact_phone`, text, required: false): The contact person's phone number.
* **Project Deadline** (`project_deadline`, date, required: false): The deadline for the project.
* **Project Type** (`project_type`, select_one, required: false): The type of project, e.g., "Logo design", "Web design", "Print design".
* **Project Status** (`project_status`, select_multiple, required: false): The status of the project, e.g., "Active", "On hold", "Completed".
* **Client Notes** (`client_notes`, note, required: false): Any additional comments or notes from the client. 

## Tips
- Make sure to provide accurate and detailed information about the project.
- Ensure that all required fields are completed, but feel free to fill in any additional fields that might be useful for the project.
- Review and submit the form carefully before finalizing it.
