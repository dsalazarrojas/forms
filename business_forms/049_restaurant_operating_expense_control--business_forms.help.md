# Restaurant Operating Expense Control - Help Guide
## Purpose
This form is designed to help restaurants track and manage their operating expenses, including food costs, labor costs, occupancy costs, other operating expenses, and more.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the relevant expenses by checking the boxes for each category.
2. Enter the percentage value for each expense category.
3. Review and submit the form to generate a report.

## Field-by-Field Explanation
* **Food Cost**: (`restaurant_operating_expense_control_food_cost`, select_one): Check this box if the restaurant has a food cost.
* **Labor Cost**: (`restaurant_operating_expense_control_labor_cost`, select_one): Check this box if the restaurant has a labor cost.
* **Occupancy**: (`restaurant_operating_expense_control_occupancy`, select_one): Check this box if the restaurant has an occupancy cost.
* **Other Operating Expense**: (`restaurant_operating_expense_control_other_operating_expense`, select_multiple): Check the boxes for each other operating expense type.
* **Other Income**: (`restaurant_operating_expense_control_other_income`, select_one): Check this box if the restaurant has other income.
* **Other Expense**: (`restaurant_operating_expense_control_other_expense`, select_multiple): Check the boxes for each other expense type.
* **Depreciation**: (`restaurant_operating_expense_control_depreciation`, select_one): Check this box if the restaurant has depreciation.
* **Amortization**: (`restaurant_operating_expense_control_amortization`, select_one): Check this box if the restaurant has amortization.
* **Interest**: (`restaurant_operating_expense_control_interest`, select_one): Check this box if the restaurant has interest.
* **Taxes**: (`restaurant_operating_expense_control_taxes`, select_one): Check this box if the restaurant has taxes.
* **Other**: (`restaurant_operating_expense_control_other`, select_one): Check this box if the restaurant has other expenses.
* **Food Cost Percentage**: (`restaurant_operating_expense_control_food_cost_percentage`, number): Enter the percentage value of food costs as a decimal (e.g., 30.25).
* **Labor Cost Percentage**: (`restaurant_operating_expense_control_labor_cost_percentage`, number): Enter the percentage value of labor costs as a decimal (e.g., 20.50).
* **Occupancy Percentage**: (`restaurant_operating_expense_control_occupancy_percentage`, number): Enter the percentage value of occupancy costs as a decimal (e.g., 12.75).
* **Other Operating Expense Percentage**: (`restaurant_operating_expense_control_other_operating_expense_percentage`, number): Enter the percentage value of other operating expenses as a decimal (e.g., 8.25).
* **Other Income 2**: (`restaurant_operating_expense_control_other_income_2`, select_multiple): Check the boxes for each other income type.
* **Other Expense Percentage**: (`restaurant_operating_expense_control_other_expense_percentage`, number): Enter the percentage value of other expenses as a decimal (e.g., 5.50).
* **Depreciation Percentage**: (`restaurant_operating_expense_control_depreciation_percentage`, number): Enter the percentage value of depreciation as a decimal (e.g., 2.75).
* **Amortization Percentage**: (`restaurant_operating_expense_control_amortization_percentage`, number): Enter the percentage value of amortization as a decimal (e.g., 1.25).
* **Interest 2**: (`restaurant_operating_expense_control_interest_2`, select_multiple): Check the boxes for each interest type.
* **Taxes Percentage**: (`restaurant_operating_expense_control_taxes_percentage`, number): Enter the percentage value of taxes as a decimal (e.g., 10.25).
* **Other Percentage**: (`restaurant_operating_expense_control_other_percentage`, number): Enter the percentage value of other expenses as a decimal (e.g., 8.50).

## Tips
* Be accurate when entering percentage values.
* Review each field carefully to ensure all relevant expenses are selected.
* Use this form to generate a report on the restaurant's operating expenses.
