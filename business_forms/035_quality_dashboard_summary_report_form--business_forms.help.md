# Quality Dashboard Summary Report Form - Help Guide

## Purpose
The Quality Dashboard Summary Report Form is a tool for tracking and analyzing quality metrics and issues. It helps teams and individuals to monitor their quality performance and identify areas for improvement.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the form with the required information, which includes the following fields:
	* **Quality KPI 1-18**: These fields are used to track specific key performance indicators (KPIs) related to quality. You can fill in the relevant information for each field.
	* **Issues Description 1-10**: These fields are used to describe issues that have been reported and resolved. You can fill in the details of each issue.
	* **Quality Status**: Select the status of the quality, whether it's active or inactive.
	* **Quality Score**: Enter the quality score, which represents the overall quality of your work or product.
	* **Quality Target**: Enter the target quality score, which should be higher than the current quality score.
	* **Issues Count**: Enter the total number of issues reported and resolved.
	* **Issues Resolved**: Enter the number of issues resolved.
	* **Issues Unresolved**: Enter the number of issues still pending.
