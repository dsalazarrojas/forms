# Smart Contract Service Inquiry Form - Help Guide
## Purpose
This form is used to submit a request for services related to smart contracts.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Select the correct options for each field as instructed below.
3. Ensure that all fields are filled in correctly before submitting the form.

## Field-by-Field Explanation

* **Smart Contract Service** (`smart_contract_service`, text, required): A short description of the service you are requesting.
* **Contract Type** (`contract_type`, select_one, required): Select the type of smart contract you are inquiring about.
	+ Option 1
	+ Option 2
	+ Option 3
* **Business Type** (`business_type`, select_multiple, required): Select all the types of business related to your smart contract inquiry.
	+ Option 1
	+ Option 2
	+ Option 3
* **Service Request** (`service_request`, text, required): A detailed description of the service you are requesting.
* **Email** (`email`, email, required): The email address of the person submitting the form.
* **Phone** (`phone`, text, required): The phone number of the person submitting the form.
* **Notes** (`notes`, note, required): Any additional notes or comments about your service request.
* **Category** (`category`, select_one, required): Select the category of service you are inquiring about.
	+ Option 1
	+ Option 2
	+ Option 3
* **Subcategory** (`subcategory`, select_multiple, required): Select all the subcategories of service you are inquiring about.
	+ 'Yes'
	+ 'No'
* **Service Request Date** (`service_request_date`, date, required): The date you are requesting the service.
* **Service Request Time** (`service_request_time`, time, required): The time you are requesting the service.
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool assigned to you for the service.
	+ chatjimmy
	+ other
* **Notes2** (`notes2`, note, required): Any additional notes or comments about your service request.
* **Submitted By** (`submitted_by`, text, required): The name of the person submitting the form.
* **Submit Date** (`submit_date`, date, required): The date the form was submitted.
* **Submit Time** (`submit_time`, time, required): The time the form was submitted.
* **Submitter** (`submitter`, text, required): The name of the person submitting the form.
* **Assigned To** (`assigned_to`, text, required): The name of the person assigned to handle the service request.
* **Submitted By Title** (`submitted_by_title`, text, required): The title of the person submitting the form.
* **Submitted By Organization** (`submitted_by_organization`, text, required): The organization of the person submitting the form.
* **Assigned To Title** (`assigned_to_title`, text, required): The title of the person assigned to handle the service request.
* **Assigned To Organization** (`assigned_to_organization`, text, required): The organization of the person assigned to handle the service request.
* **Submitter Organization** (`submitter_organization`, text, required): The organization of the person submitting the form.
* **Submitted By Email** (`submitted_by_email`, email, required): The email address of the person submitting the form.
* **Assigned To Email** (`assigned_to_email`, email, required): The email address of the person assigned to handle the service request.

Note: Ensure that all fields are filled in correctly before submitting the form.
