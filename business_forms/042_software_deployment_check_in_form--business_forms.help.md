# software_deployment_check_in_form - Help Guide
## Purpose
This form is designed for documenting and tracking software deployment information, including current deployment status, onboarding date, user impact, and other relevant details. It helps maintain transparency and organization within your organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current deployment status from the options provided.
2. Enter the onboarding date, if applicable.
3. Add any important software release notes in the provided text field.
4. Assess the user impact using the provided options (High, Medium, Low) and add any comments about the user impact.
5. Evaluate the technical impact using the provided options (High, Medium, Low) and add any comments about the technical impact.
6. Add any release notes that are important for the deployment.
7. Select the relevant team(s) involved in the deployment.
8. Add any comments about the team's involvement.
9. Outline the next steps that need to be taken.
10. Add any notes about the deployment.

## Field-by-Field Explanation

* **What is the current deployment status?** (`deployment_status`, `select_one`):
	+ Select one of the options: Active, In Progress, On Hold, or Not Applicable.
* **Onboarding date** (`onboarding_date`, `date`):
	+ Enter the date the software was onboarded into production.
* **Software release notes** (`software_release_notes`, `text`):
	+ Add any important notes about this release.
* **User Impact** (`user_impact`, `select_one`):
	+ Select one of the options: High, Medium, Low.
* **User Impact Comments** (`user_impact_comments`, `text`):
	+ Add any comments about user impact.
* **Technical Impact** (`technical_impact`, `select_one`):
	+ Select one of the options: High, Medium, Low.
* **Technical Impact Comments** (`technical_impact_comments`, `text`):
	+ Add any comments about technical impact.
* **Release Notes** (`release_notes`, `text`):
	+ Add any important notes about the release.
* **Team name** (`team_name`, `select_multiple`):
	+ Select one or more teams involved in the deployment.
* **Team Comments** (`team_comments`, `text`):
	+ Add any comments about the team.
* **Next Steps** (`next_steps`, `text`):
	+ Outline the next steps that need to be taken.
* **Deployment Notes** (`deployment_notes`, `text`):
	+ Add any notes about the deployment.

## Tips

* Ensure you fill out all required fields according to your business's standard operating procedures.
* Keep the form organized and up-to-date for accurate record-keeping.
* Review and revise the form regularly to reflect changes in the deployment process.
