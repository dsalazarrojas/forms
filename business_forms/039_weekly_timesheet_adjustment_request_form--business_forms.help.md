# Weekly Timesheet Adjustment Request Form - Help Guide
## Purpose
The purpose of this form is to request an adjustment to a weekly timesheet for extra hours worked that were not initially recorded. This form should only be used once for each period's extra hours worked.

## How To Complete This Form
To complete this form:

1. Select the period for which you are requesting an adjustment.
2. Enter the start and end dates of the period.
3. Enter the number of extra hours you worked.
4. Provide any additional comments or notes about your request.
5. Submit the form.

## Field-by-Field Explanation
- **Weekly Timesheet Adjustment Request** (`weekly_timesheet_adjustment_form`, Text): Enter a brief description of the adjustment you are requesting.
- **Select Period** (`timesheet_period`, Select One):
  • Choose the period for which you are requesting an adjustment.
  • Use the dropdown list to select the correct period.
- **Start Date** (`start_date`, Date): Enter the start date of the period for which you are requesting an adjustment.
- **End Date** (`end_date`, Date): Enter the end date of the period for which you are requesting an adjustment.
- **Hours Worked** (`hours_worked`, Number): Enter the number of extra hours you worked that need to be adjusted for.
- **Notes** (`notes`, Note): Add any additional comments or notes about your request.
- **Comments** (`comments`, Note): Add any additional comments or notes about your request.
- **Submit** (`submit`, Text): Click to submit your request.

## Tips
* Only submit this form once for all extra hours worked in a given period.
* Make sure to include accurate start and end dates to ensure the correct adjustment is applied.
* Be as detailed as possible in the comments or notes to help with processing your request.
