# customer_appreciation_event_invitation_form - Help Guide
## Purpose
This form is designed to help users invite customers to appreciate events.

## How To Complete This Form
To complete the form, follow these steps:
1. Enter a brief title for the customer appreciation event in the **customer_appreciation_event** field.
2. Provide more details about the event in the **customer_appreciation_event_details** field.
3. Fill out the **customer_appreciation_event_dates** field with the date of the event.
4. Specify the location of the event in the **customer_appreciation_event_location** field.
5. Indicate if the event is a customer appreciation event by selecting **Yes** or **No** in the **customer_appreciation_event_invitation_details** field.
6. Choose the type of invitation for the event in the **customer_appreciation_event_invitation_type** field.
7. Select the start time of the event in the **customer_appreciation_event_invitation_start_time** field.
8. Select the end time of the event in the **customer_appreciation_event_invitation_end_time** field.
9. Enter the duration of the event in the **customer_appreciation_event_invitation_duration** field.
10. Enter the date of the event in the **customer_appreciation_event_invitation_date** field.
11. Enter the time of the event in the **customer_appreciation_event_invitation_time** field.
12. Add any notes about the event in the **customer_appreciation_event_invitation_note** field.
13. Enter the email address for the invitation in the **customer_appreciation_event_invitation_email** field.
14. Enter the phone number for the invitation in the **customer_appreciation_event_invitation_phone** field.
15. Enter a message for the invitation in the **customer_appreciation_event_invitation_message** field.
