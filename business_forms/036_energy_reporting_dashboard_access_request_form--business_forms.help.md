# <string> - Help Guide
## Purpose
The purpose of this form is to gather information for setting up and maintaining a proper energy reporting dashboard that meets the user's needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a title for the dashboard.
2. Select multiple energy reporting systems that you want to be included in the dashboard.
3. Choose the reporting tools that you want to use for the dashboard.
4. Select the access levels of users who should be able to view the dashboard.
5. Fill in all required fields carefully to ensure accurate data collection.

## Field-by-Field Explanation
- **Title** (`title`, `string`, required): Enter a brief title for the energy reporting dashboard.
- **Energy Reporting Systems** (`energy_reporting_system`, `select_multiple`, required): Select multiple energy reporting systems that you want to include in the dashboard.
- **Reporting Tools** (`reporting_system`, `select_multiple`, optional): Choose the reporting tools that you want to use for the dashboard.
- **System Admin** (`system_admin`, `select_one`, optional): Select whether you want the system admin to have access to the dashboard.
- **Dashboard Admin** (`dashboard_admin`, `select_one`, optional): Select whether you want the dashboard admin to have access to the dashboard.
- **Reporting Admin** (`reporting_admin`, `select_one`, optional): Select whether you want the reporting admin to have access to the dashboard.
- **Reporting User** (`reporting_user`, `select_one`, optional): Select whether you want the reporting user to have access to the dashboard.
- **System User** (`system_user`, `select_one`, optional): Select whether you want the system user to have access to the dashboard.
- **User** (`user`, `select_one`, optional): Select whether you want the user to have access to the dashboard.
- **User Admin** (`user_admin`, `select_one`, optional): Select whether you want the user admin to have access to the dashboard.
- **Reporting System Admin** (`reporting_system_admin`, `select_one`, optional): Select whether you want the reporting system admin to have access to the dashboard.
- **Reporting System User** (`reporting_system_user`, `select_one`, optional): Select whether you want the reporting system user to have access to the dashboard.

Note: Please fill in all required fields carefully to ensure accurate data collection.
