# prophets - Help Guide
## Purpose
The "prophets" form is used to gather information about prophetic events, which can be completed by internal stakeholders. The form is not intended for external use, and multiple submissions from the same user are not allowed.

## How To Complete This Form
To complete the form, follow these steps:
1. Enter the **Company Name** in the designated field.
2. Select the **Start Date** and **End Date** of the prophetic event.
3. Provide the **Auditor**'s name and any other relevant details.
4. Select the **Findings** related to the event (e.g., 1st Quarter, 2nd Quarter, 3rd Quarter, or 4th Quarter).
5. Enter any additional **Comments** about the event.
6. Choose the **Status** of the event (Active or Inactive).
7. Optionally, select the **Assigned Tool** related to the event.

## Field-by-Field Explanation
### Company Name
* **Company Name** (`Company Name`, text, optional): Enter the name of the company related to the prophetic event.

### Start Date
* **Start Date** (`start_date`, date, optional): Select the start date of the prophetic event.

### End Date
* **End Date** (`end_date`, date, optional): Select the end date of the prophetic event.

### Auditor
* **Auditor** (`auditor`, text, optional): Enter the name of the auditor related to the prophetic event.

### Findings
* **Findings** (`findings`, select_multiple, optional): Select the findings related to the event (e.g., 1st Quarter, 2nd Quarter, 3rd Quarter, or 4th Quarter).

### Comments
* **Comments** (`comments`, note, optional): Enter any additional comments about the prophetic event.

### Status
* **Status** (`status`, select_one, optional): Choose the status of the event (Active or Inactive).

### Assigned Tool
* **Assigned Tool** (`assigned_tool`, text, optional): Optionally, select the tool assigned to the prophetic event.

### Tips
* This form is designed for internal use only. Please ensure that all fields are filled out accurately and completely.
* If you need to make changes to an existing submission, please use the correct submission ID for editing purposes.
* If you have any questions or concerns, contact the designated support team.
