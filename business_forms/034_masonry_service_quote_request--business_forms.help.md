# MasonryServiceQuoteRequest - Help Guide
## Purpose
The MasonryServiceQuoteRequest form is a tool for clients to request quotes from service providers for masonry services.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields to provide detailed information about your project, including project details, masonry service details, client details, contact person, project location, and project description.
2. Provide contact information for both the client and the service provider, including phone numbers and email addresses.
3. Specify the project status and start and end dates (if applicable).
4. Add any additional project notes, service provider notes, and project images as needed.
5. Review and submit the form to request a quote from the service provider.

## Field-by-Field Explanation
### Project Details
* **Project Details** (`project_details`, text, optional): Enter a brief description of the project.
### Masonry Service Details
* **Masonry Service Details** (`masonry_service_details`, text, optional): Enter a detailed description of the masonry services required for the project.
### Client Details
* **Client Details** (`client_details`, text, optional): Enter a brief description of the client's needs and requirements.
### Contact Person
* **Contact Person** (`contact_person`, text, optional): Enter the name and title of the person responsible for the project.
### Project Location
* **Project Location** (`project_location`, text, optional): Enter the location of the project site.
### Project Description
* **Project Description** (`project_description`, text, optional): Enter a detailed description of the project, including the scope of work and any specific requirements.
### Service Quote
* **Service Quote** (`service_quote`, text, optional): Enter a brief description of the service quote required (e.g., material costs, labor costs).
### Project Cost
* **Project Cost** (`project_cost`, number, optional): Enter the estimated or actual cost of the project.
### Project Status
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project (New, In Progress, Completed).
### Project Start Date
* **Project Start Date** (`project_start_date`, date, optional): Enter the expected start date of the project.
### Project End Date
* **Project End Date** (`project_end_date`, date, optional): Enter the expected end date of the project.
### Client Phone
* **Client Phone** (`client_phone`, text, optional): Enter the phone number of the client.
### Service Provider
* **Service Provider** (`service_provider`, text, optional): Enter the name of the service provider.
### Service Provider Address
* **Service Provider Address** (`service_provider_address`, text, optional): Enter the address of the service provider.
### Service Provider Phone
* **Service Provider Phone** (`service_provider_phone`, text, optional): Enter the phone number of the service provider.
### Service Provider Email
* **Service Provider Email** (`service_provider_email`, email, optional): Enter the email address of the service provider.
### Project Notes
* **Project Notes** (`project_notes`, text, optional): Enter any additional notes about the project.
### Project Notes Additional
* **Project Notes Additional** (`project_notes_additional`, text, optional): Enter any additional notes about the project.
### Project Image
* **Project Image** (`project_image`, text, optional): Enter a brief description of an image related to the project.
### Project Image Additional
* **Project Image Additional** (`project_image_additional`, text, optional): Enter any additional description of an image related to the project.

## Tips
* Please ensure that all fields are filled in accurately to provide the service provider with the necessary information to quote the project.
* Review the form carefully before submitting it to ensure that it is complete and accurate.
