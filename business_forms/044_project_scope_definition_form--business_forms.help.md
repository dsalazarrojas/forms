# Project Scope Definition Form - Help Guide
## Purpose
The Project Scope Definition Form is designed to provide a structured framework for project managers and team members to define and refine the project scope by capturing the essential information required for project planning and execution.

## How To Complete This Form
To complete this form, follow these steps:

* Review the project objectives and deliverables section, selecting the relevant goals and deliverables for your project.
* In the timelines section, enter the project start and end dates, and any relevant milestones.
* In the stakeholders section, select the relevant stakeholders involved in the project, such as client, team, or manager.
* Determine the current project status by selecting Active, In Progress, or Completed.
* Classify the project type as Internal, External, or Hybrid.
* Finally, provide a brief description of the project in the project description field.

## Field-by-Field Explanation
* **Project Scope** (`project_scope`, text, optional): Enter a short description of the project scope.
* **Objectives** (`objectives`, select_multiple, optional):
	+ Project goals
	+ Project deliverables
	+ Project timelines
* **Deliverables** (`deliverables`, text, optional): List the specific deliverables expected from the project.
* **Timelines** (`timelines`, date, optional): Enter the project start and end dates, and any relevant milestones.
* **Stakeholders** (`stakeholders`, select_one, optional): Select the relevant stakeholders involved in the project.
	+ Client
	+ Team
	+ Manager
* **Project Status** (`project_status`, select_one, optional): Determine the current project status.
	+ Active
	+ In Progress
	+ Completed
* **Project Type** (`project_type`, select_one, optional): Classify the project type.
	+ Internal
	+ External
	+ Hybrid
* **Project Description** (`project_description`, text, optional): Provide a brief description of the project.

## Tips
* Make sure to review and refine the project scope definition regularly to ensure it remains relevant and accurate.
* Ensure that all stakeholders are aware of the project scope and objectives.
* Use this form as a starting point for project planning and execution, and adjust it as needed to suit your project's unique requirements.
