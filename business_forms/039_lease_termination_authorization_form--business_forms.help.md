# Lease Termination Authorization Form - Help Guide
## Purpose
This form is used to formalize the termination of a lease agreement between a tenant and a landlord. It collects necessary information to document the termination of the lease and ensure both parties are in agreement on the terms of the termination.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary documents and information ready before filling out the form.
2. Fill out the required fields, which are marked with an asterisk (\*).
3. For fields with options, select the relevant option that best describes your situation.
4. Double-check the form for any errors or missing information before submitting it.

## Field-by-Field Explanation

* **Tenant Signature** (`tenant_signature`, `text`, required: false): This field is where the tenant signs to confirm their agreement to terminate the lease. If this field is not required, please include a reason why it's not necessary.
* **Landlord Signature** (`landlord_signature`, `text`, required: false): This field is where the landlord signs to confirm their agreement to terminate the lease. If this field is not required, please include a reason why it's not necessary.
* **Lease Date** (`lease_date`, `date`, required: false): This field is for the date the lease began. If this field is not required, please include a reason why it's not necessary.
* **Reason for Termination** (`reason_for_termination`, `select_one`, required: false): Select one of the provided options to describe the reason for the lease termination.
* **Landlord Address** (`landlord_address`, `text`, required: false): This field is for the landlord's address.
* **Tenant Address** (`tenant_address`, `text`, required: false): This field is for the tenant's address.
* **Lease Term** (`lease_term`, `select_one`, required: false): Select one of the provided options to describe the lease term.
* **Termination Date** (`termination_date`, `date`, required: false): This field is for the date the lease is to be terminated.
* **Reason for Termination Details** (`reason_for_termination_details`, `text`, required: false): Provide a detailed explanation for the reason for termination.
* **Lease End Date** (`lease_end_date`, `date`, required: false): This field is for the date the lease is to end.
* **Signed By** (`signed_by`, `text`, required: false): This field is for the person signing the document.
* **Signed Date** (`signed_date`, `date`, required: false): This field is for the date the document was signed.
* **Tenant Name** (`tenant_name`, `text`, required: false): This field is for the tenant's name.
* **Landlord Name** (`landlord_name`, `text`, required: false): This field is for the landlord's name.
* **Tenant Contact Info** (`tenant_contact_info`, `text`, required: false): This field is for the tenant's contact information.
* **Landlord Contact Info** (`landlord_contact_info`, `text`, required: false): This field is for the landlord's contact information.
* **Property Manager** (`property_manager`, `select_one`, required: false): Select one of the provided options to describe the property manager.
* **Property Manager Contact Info** (`property_manager_contact_info`, `text`, required: false): This field is for the property manager's contact information.
* **Termination Fees** (`termination_fees`, `number`, required: false): This field is for the termination fees.
* **Termination Fees Details** (`termination_fees_details`, `text`, required: false): Provide a detailed explanation for the termination fees.
* **Property Type** (`property_type`, `select_one`, required: false): Select one of the provided options to describe the property type.
* **Property Details** (`property_details`, `text`, required: false): This field is for any additional property details.
* **Lease Terms** (`lease_terms`, `text`, required: false): This field is for any lease terms.
* **Lease Terms Details** (`lease_terms_details`, `text`, required: false): Provide a detailed explanation for the lease terms.
* **Comments** (`comments`, `text`, required: false): This field is for any additional comments or notes.

## Tips
* Please ensure all fields are filled out accurately and completely to avoid any errors or misunderstandings.
* If a field is not required, please include a reason why it's not necessary.
* Review the form carefully before submitting it to ensure all necessary information is included.
