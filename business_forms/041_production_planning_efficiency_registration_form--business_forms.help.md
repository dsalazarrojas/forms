# Production Planning Efficiency Registration Form - Help Guide
## Purpose
This form is used to collect production planning efficiency data for a workcenter. It includes fields for workflow description, production capacity, and planning efficiency.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Make sure to enter the correct workflow description, production capacity, and planning efficiency.
3. For production capacity, enter the number and units used for production.
4. Enter the planning efficiency as a number and units.
5. If applicable, enter notes for production capacity, planning efficiency, and workcenter capacity.

## Field-by-Field Explanation

* **Production Planning Efficiency** (`production_planning_efficiency_form`): Enter a brief description of the production planning process.
* **Workflow Description** (`workflow_description`): Describe the workflow used in the production planning process.
* **Workflow Status** (`workflow_status`): Select the current status of the workflow. If not applicable, leave blank.
* **Workcenter ID** (`workcenter_id`): Enter the workcenter's ID, if applicable.
* **Production Capacity** (`production_capacity`): Enter the production capacity number and units used.
* **Production Capacity Units** (`production_capacity_units`): Enter the units used for production capacity.
* **Production Capacity Notes** (`production_capacity_notes`): Add any additional notes about production capacity.
* **Planning Efficiency** (`planning_efficiency`): Enter the planning efficiency as a number.
* **Planning Efficiency Units** (`planning_efficiency_units`): Enter the units used for planning efficiency.
* **Planning Efficiency Notes** (`planning_efficiency_notes`): Add any additional notes about planning efficiency.
* **Workcenter Capacity** (`workcenter_capacity`): Enter the workcenter's capacity number, if applicable.
* **Workcenter Capacity Units** (`workcenter_capacity_units`): Enter the units used for workcenter capacity.
* **Workcenter Capacity Notes** (`workcenter_capacity_notes`): Add any additional notes about workcenter capacity.
* **Planning Cycle Length** (`planning_cycle_length`): Enter the planning cycle length number, if applicable.
* **Cycle Length Notes** (`cycle_length_notes`): Add any additional notes about planning cycle length.
* **Efficiency Score** (`efficiency_score`): Enter the efficiency score number.
* **Efficiency Score Units** (`efficiency_score_units`): Enter the units used for efficiency score.
* **Efficiency Score Notes** (`efficiency_score_notes`): Add any additional notes about efficiency score.
* **Efficiency Score 1** (`efficiency_score_1`): Select 'Yes' or 'No' to indicate if this score is applicable.
* **Efficiency Score 1 Units** (`efficiency_score_1_units`): Enter the units used for efficiency score 1.
* **Efficiency Score 1 Notes** (`efficiency_score_1_notes`): Add any additional notes about efficiency score 1.
* **Efficiency Score 2** (`efficiency_score_2`): Select 'Yes' or 'No' to indicate if this score is applicable.
* **Efficiency Score 2 Units** (`efficiency_score_2_units`): Enter the units used for efficiency score 2.
* **Efficiency Score 2 Notes** (`efficiency_score_2_notes`): Add any additional notes about efficiency score 2.
* **Efficiency Score 3** (`efficiency_score_3`): Select 'Yes' or 'No' to indicate if this score is applicable.
* **Efficiency Score 3 Units** (`efficiency_score_3_units`): Enter the units used for efficiency score 3.
* **Efficiency Score 3 Notes** (`efficiency_score_3_notes`): Add any additional notes about efficiency score 3.
* **Notes** (`notes`): Add any additional notes about the production planning efficiency process.
