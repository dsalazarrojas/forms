# data_backup_infrastructure_inspection_form - Help Guide
## Purpose
This form is designed to assess the data backup infrastructure of an organization, including its frequency, location, method, and media. The goal is to ensure that data is properly backed up and retained for a specified period in case of emergencies or hardware failures.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the following questions about your data backup infrastructure:
	* It Department: Enter the name of your IT department responsible for data backup and recovery.
	* Backup Frequency: Select how often you back up your data (Daily, Weekly, Monthly, Quarterly, Yearly).
	* Data Retention Policy: Choose how long you retain your backed-up data (3 Months, 6 Months, 1 Year, 2 Years).
	* Backup Location: Select where your backups are stored (Onsite, Offsite).
	* Backup Method: Select the method used for data backup (Tape, Disk, Cloud).
	* Backup Media: Choose the type of media used for backup (Hard Disk, Tape, SSD).
	* Backup Schedule: Enter the date and time of the last backup (Note: This field is not currently visible as it's a date input, but users will have to input date in this field).
	* Backup Window: Select the time range during which backups occur (This field is hidden as it's a time input).
	* Backup Prophets: This field is not used as it's a text area for note.
	* Backup Frequency 2, 3, and 4: Repeat the same questions for multiple backup frequency.

## Field-by-Field Explanation
* **It Department** (Text): Enter the name of your IT department.
* **Backup Frequency** (Select Multiple): Frequency of data backup (Daily, Weekly, Monthly, Quarterly, Yearly).
* **Data Retention Policy** (Select Multiple): Choose how long backed-up data is retained (3 Months, 6 Months, 1 Year, 2 Years).
* **Backup Location** (Select One): Where data is backed up (Onsite, Offsite).
* **Backup Method** (Select One): Select the backup method (Tape, Disk, Cloud).
* **Backup Media** (Select One): Choose the backup media (Hard Disk, Tape, SSD).
* **Backup Schedule** (Date): Enter the date of the last backup.
* **Backup Window** (Time): Select the time range during which backups occur.
* **Backup Prophets** (Note): This field is not used.
* **Backup Frequency 2, 3, and 4** (Select One/Select Multiple): Repeat the same questions for multiple backup frequencies.
