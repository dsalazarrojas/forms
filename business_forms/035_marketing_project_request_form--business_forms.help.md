# Marketing Project Request Form - Help Guide
## Purpose
This form is intended for marketing project requests. It is used to collect and manage project details such as title, lead, start and end dates, budget, priority, status, and project manager.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for your marketing project in the "Project Name" field.
2. Select the person responsible for the project from the "Lead" dropdown.
3. Set the project's start and end dates in the "Start Date" and "End Date" fields, respectively.
4. Enter the project's allocated budget in the "Budget" field.
5. Indicate the project's priority from the "Priority" dropdown.
6. Select the current status of your project from the "Status" dropdown.
7. Enter the name of the project manager in the "Project Manager" field.

## Field-by-Field Explanation
* **Project Name**: Enter a title for your marketing project. This will be used to identify and track the project.
* **Lead**: Select the person responsible for the project from the dropdown options. This is likely the person who will be overseeing the project's progress.
* **Start Date**: Set the project's start date. This is the date when the project is expected to begin.
* **End Date**: Set the project's end date. This is the date when the project is expected to finish.
* **Budget**: Enter the allocated budget for the project. This is the financial resources available for the project.
* **Priority**: Indicate the project's level of importance or urgency from the dropdown options. For example, high, medium, or low.
* **Status**: Select the current stage of your project from the dropdown options. This will help track the project's progress.
* **Project Manager**: Enter the name of the person in charge of the project. This is the person who will oversee the project's execution.
