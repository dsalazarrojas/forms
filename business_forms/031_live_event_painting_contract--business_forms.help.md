# Live Event Painting Contract - Help Guide

## Purpose
The Live Event Painting Contract form is designed to capture essential information for a live event painting contract. This form helps event organizers and artists gather necessary details for a successful and enjoyable live painting event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event date in the format `YYYY-MM-DD` (e.g., 2024-01-15).
2. Provide a brief description of the event, including its theme, location, and other relevant details.
3. Fill in any additional details about the event as required.

## Field-by-Field Explanation
* **Event Date** (event_date, date, required): Enter the date of the live event in `YYYY-MM-DD` format (e.g., 2024-01-15).
* **Live Event Painting Contract Description** (live_event_painting_contract_description, text, optional): Provide a brief description of the event, including its theme, location, and other relevant details.
* **Event Details** (event_details, text, optional): Enter any additional details about the event as required.
