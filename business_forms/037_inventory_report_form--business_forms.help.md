# Inventory Report Form - Help Guide
## Purpose
The Inventory Report Form is a document used to gather data about the current state of an organization's inventory. It helps in generating reports that provide insights into stock levels, product status, and other relevant details.

## How To Complete This Form
- Start by selecting the type of report you need (Sales Report, Inventory Report, or Product Report).
- Choose the start date of the report period.
- Select the end date of the report period.
- Enter the inventory level as a numerical value.
- List the stock levels in the text field.
- Provide a brief description of the product(s) being reported on.
- Select the stock units to report on (can be multiple options).
- Choose the current stock status (Active or Inactive).
- Select the user responsible for the stock (or choose "Other" if not applicable).
- Choose the frequency of the report (Monthly, Quarterly, or Yearly).

## Field-by-Field Explanation

* **report_type** (Select One): Choose the type of report you need, which can be Sales Report, Inventory Report, or Product Report.
* **start_date** (Date): Enter the start date of the report period.
* **end_date** (Date): Enter the end date of the report period.
* **inventory_level** (Number): Enter the current inventory level.
* **stock_levels** (Text): List the stock levels for the products being reported on.
* **product_description** (Text): Provide a brief description of the product(s) being reported on.
* **stock_units** (Select Multiple): Select the stock units to report on.
* **stock_status** (Select One): Choose the current stock status (Active or Inactive).
* **assigned_user** (Select One): Select the user responsible for the stock (or choose "Other" if not applicable).
* **report_frequency** (Select One): Choose the frequency of the report (Monthly, Quarterly, or Yearly).
