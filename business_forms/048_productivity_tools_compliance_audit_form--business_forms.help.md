# Productivity Tools Compliance Audit Form - Help Guide
## Purpose
This form is used to evaluate the compliance of productivity tools used within the organization, ensuring they align with the organization's standards and policies.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the relevant information about the productivity tool being audited.
2. Answer the questions according to your knowledge or research about the tool.
3. Provide accurate and honest answers, as incomplete or inaccurate information might lead to inaccurate results.

## Field-by-Field Explanation

* **Form Header** (`form_header`, note, required: false): This is the introduction to the form. It's not a field that requires a specific answer, but rather an informational header.
* **tool name** (`tool_name`, text, required: false): This field is for the name of the productivity tool being audited.
* **Organization** (`organization`, text, required: false): This field is for the organization that owns or uses the tool.
* **tool type** (`tool_type`, select one, required: false): This field is for the type of tool being audited (e.g., software, hardware, or a service).
* **tool url** (`tool_url`, text, required: false): This field is for the URL of the tool, if applicable.
* **tool accessibility** (`tool_accessibility`, select multiple, required: false): This field is for the tool's accessibility features, such as accessibility for people with disabilities or language support.
* **tool security** (`tool_security`, select multiple, required: false): This field is for the tool's security features, such as encryption or authentication.
* **tool data privacy** (`tool_data_privacy`, select multiple, required: false): This field is for the tool's data privacy features, such as data protection or storage.
* **tool compliance** (`tool_compliance`, select multiple, required: false): This field is for the tool's compliance features, such as regulatory adherence or certifications.
* **tool sustainability** (`tool_sustainability`, select multiple, required: false): This field is for the tool's sustainability features, such as energy efficiency or environmental impact.
* **tool security compliance** (`tool_security_compliance`, select multiple, required: false): This field is for the tool's security compliance features, such as compliance with industry standards.
* **tool eudra** (`tool_eudra`, select multiple, required: false): This field is for the tool's EUDRA features, such as data sharing or access control.

Note: This form is for internal use only and not for external tools or services. This form is to be filled by employees or authorized personnel. 

Also, please be aware that this form is for a specific type of tool. If a tool does not fit the description, do not fill this form. Instead, contact the relevant department or team for guidance. 

## Tips

* Always provide accurate and honest answers.
* If unsure about a field, refer to the tool's documentation or contact the relevant department or team.
* If the tool does not fit the description or you are not sure, do not fill this form.
* Review the form before submitting to ensure all fields are filled and accurate.
* Use this form for tools used by employees, not for external tools or services.
