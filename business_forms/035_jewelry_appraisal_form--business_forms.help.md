# Jewelry Appraisal Form - Help Guide
## Purpose
The Jewelry Appraisal Form is a tool used to gather detailed information about a piece of jewelry for appraisal purposes. This form helps appraisers and collectors to accurately identify and value a piece of jewelry.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the item name and type of the jewelry item.
2.  Enter the weight of the item, if applicable.
3.  Specify the material of the jewelry item.
4.  Enter the carat weight of the item, if applicable.
5.  Identify the gemstone used in the jewelry item, if applicable.
6.  Enter the date the item was found, if applicable.
7.  Add any additional comments about the item.
8.  Upload images of the jewelry item (if applicable).
9.  Sign and date the form with the appraiser's signature.
10.  Enter the certificate number, if applicable.
11.  Enter the date the item was certified, if applicable.
12.  Enter the date the item was made, if applicable.
13.  Enter the date the item was issued, if applicable.
14.  Enter the certificate issuer, if applicable.
15.  Enter the name of the certificate holder, if applicable.

## Field-by-Field Explanation

*   **Item Name** (`item_name`, text, optional): Enter the name of the jewelry item.
*   **Item Type** (`item_type`, select_one, optional): Choose the type of jewelry, such as Diamond or Gold.
*   **Weight** (`weight`, number, optional): Enter the weight of the item, if applicable.
*   **Material** (`material`, text, optional): Specify the material used in the jewelry item.
*   **Carat** (`carat`, number, optional): Enter the carat weight of the item, if applicable.
*   **Gemstone** (`gemstone`, text, optional): Identify the gemstone used in the jewelry item, if applicable.
*   **Certificate** (`certificate`, text, optional): Enter any relevant certificates or documents associated with the item.
*   **Appraiser** (`appraiser`, text, optional): Enter the name of the appraiser who conducted the appraisal.
*   **Date Found** (`date_found`, date, optional): Enter the date the item was found, if applicable.
*   **Value** (`value`, number, optional): Enter the estimated value of the item.
*   **Comments** (`comments`, note, optional): Add any additional comments or details about the item.
*   **Image URL 1** (`image_url`, text, optional): Upload an image of the jewelry item.
*   **Image URL 2** (`image_url_url`, text, optional): Upload an additional image of the jewelry item.
*   **Appraiser Signature** (`appraiser_signature`, text, optional): Sign and date the form with the appraiser's signature.
*   **Certificate Number** (`certificate_number`, text, optional): Enter the certificate number, if applicable.
*   **Certificate Date** (`certificate_date`, date, optional): Enter the date the certificate was issued, if applicable.
*   **Date Found** (`certificate_date_found`, date, optional): Enter the date the item was found, if applicable.
*   **Date Made** (`certificate_date_made`, date, optional): Enter the date the item was made, if applicable.
*   **Date Issued** (`certificate_date_issued`, date, optional): Enter the date the item was issued, if applicable.
*   **Certificate Issuer** (`certificate_issuer`, text, optional): Enter the name of the certificate issuer.
*   **Certificate Holder** (`certificate_holder`, text, optional): Enter the name of the certificate holder.

Note: The fields marked as "optional" can be filled in or left blank as per your discretion.
