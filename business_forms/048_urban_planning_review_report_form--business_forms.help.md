# urban_planning_review_report_form - Help Guide
## Purpose
The urban planning review report form is used to document and track reviews of urban planning projects. It is designed to collect information about project details, project location, project status, contact information, and review comments.

## How To Complete This Form
1. Click on the project details page.
2. Enter project details in the text field.
3. Click on the project_location field and enter the project's location.
4. Select the project_type by clicking on the dropdown menu.
5. Select the project_status by clicking on the dropdown menu.
6. Enter contact_details in the text field.
7. Enter contact_email in the email format (e.g., john.doe@example.com).
8. Enter contact_phone in the text field.
9. Enter a description of the project in the project_description field.
10. Add any additional notes about the project in the project_notes field.
11. Enter your review comments in the review_comments field.
12. Enter the date of the review in the review_date field.
13. Enter the time of the review in the time field (HH:MM format).
14. Enter the review_location in the text field.

## Field-by-Field Explanation
* **Project Details** (`project_details`, text, required: false): Enter a brief description of the project.
* **Project Location** (`project_location`, text, required: false): Enter the location of the project.
* **Project Type** (`project_type`, select_one, required: false): Select whether the project is a new project or not.
* **Project Status** (`project_status`, select_one, required: false): Select the status of the project (Active or Inactive).
* **Contact Details** (`contact_details`, text, required: false): Enter contact person's name and/or department.
* **Contact Email** (`contact_email`, email, required: false): Enter the contact email address in the format (e.g., john.doe@example.com).
* **Contact Phone** (`contact_phone`, text, required: false): Enter the contact person's phone number.
* **Project Description** (`project_description`, text, required: false): Enter a description of the project.
* **Project Notes** (`project_notes`, note, required: false): Add any additional notes about the project.
* **Review Comments** (`review_comments`, text, required: false): Enter your review comments about the project.
* **Review Date** (`review_date`, date, required: false): Enter the date of the review.
* **Review Time** (`review_time`, time, required: false): Enter the time of the review (HH:MM format).
* **Review Location** (`review_location`, text, required: false): Enter the location of the review.
