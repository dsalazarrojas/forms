# seo_analysis_report_form - Help Guide
## Purpose
The SEO Analysis Report Form is used to collect data related to search engine optimization (SEO) analysis for a given website or webpage.

## How To Complete This Form

This form consists of multiple pages with various fields to provide a comprehensive analysis. Please complete each page step-by-step:

- Page 1: **Meta Tags**
  * **Meta Tags**: (`Meta Tags`, select_multiple, required: false) Select all meta tags that are present on the website or webpage.
  - **Meta Description**: (`Meta Description`, text, required: false) Enter a brief summary of the website or webpage, ideally 155-160 characters.
  - **Meta Description Length**: (`Meta Description Length`, number, required: false) Enter the length of the meta description.
  - **Keywords**: (`Keywords`, select_multiple, required: false) Select all keywords that are present on the website or webpage.
  - **Keywords Length**: (`Keywords Length`, number, required: false) Enter the length of the keywords.
  - **Header Tags**: (`Header Tags`, select_multiple, required: false) Select all header tags that are present on the website or webpage.
  - **Header Tags Length**: (`Header Tags Length`, number, required: false) Enter the length of the header tags.

- Page 2: **Url**
  * **Url**: (`Url`, text, required: false) Enter the URL of the website or webpage.
  - **Duplicate Meta Tags**: (`Duplicate Meta Tags`, select_multiple, required: false) Check if the meta tags are duplicated.
  - **Meta Tags Count**: (`Meta Tags Count`, number, required: false) Enter the count of meta tags.
  - **Meta Description Count**: (`Meta Description Count`, number, required: false) Enter the count of meta descriptions.
  - **Keywords Count**: (`Keywords Count`, number, required: false) Enter the count of keywords.

## Field-by-Field Explanation

* Meta Tags: This field allows you to select all the meta tags present on the website or webpage. Meta tags are the tags that appear in the `<head>` section of an HTML document and are used for search engine optimization (SEO) purposes.
* Meta Description: This field is used to enter a brief summary of the website or webpage, ideally 155-160 characters. This is the text that appears in the search engine results page (SERP) when a user searches for the website or webpage.
* Meta Description Length: This field is used to enter the length of the meta description.
* Keywords: This field allows you to select all the keywords that are present on the website or webpage. Keywords are the words or phrases that a website or webpage is trying to rank for in search engines.
* Keywords Length: This field is used to enter the length of the keywords.
* Header Tags: This field allows you to select all the header tags that are present on the website or webpage. Header tags are the tags that appear in the `<h1>`, `<h2>`, etc. sections of an HTML document.
* Header Tags Length: This field is used to enter the length of the header tags.
* Url: This field is used to enter the URL of the website or webpage.
* Duplicate Meta Tags: This field allows you to check if the meta tags are duplicated.
* Meta Tags Count: This field is used to enter the count of meta tags.
* Meta Description Count: This field is used to enter the count of meta descriptions.
* Keywords Count: This field is used to enter the count of keywords.
