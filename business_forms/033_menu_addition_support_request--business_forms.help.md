# Menu Addition Support Request - Help Guide
## Purpose
This form is used to submit requests related to menu additions in a business setting. You can use it to add new menu items, modify existing ones, or make requests for changes to menu items.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with a *.
2. Provide detailed information in the optional fields, such as images or notes.
3. Review your submission carefully before submitting.

## Field-by-Field Explanation

* **menu_item_1** (new_menu_item_1, text, required): Enter the name of the new menu item you want to add or modify.
* **item_name** (new_menu_item_2, text, required): Enter the name of the menu item.
* **price** (price_range, number, required): Enter the price of the menu item.
* **category** (category, select_one, required): Select the category that best fits the menu item.
* **description** (description, text, required): Enter a detailed description of the menu item.
* **image_1** (image_attachment_1, text, optional): You can upload an image related to the menu item if needed.
* **image_2** (image_attachment_2, text, optional): You can upload additional images related to the menu item if needed.
* **notes** (notes, text, optional): Enter any additional notes or comments related to the menu item.

## Tips
* Make sure to fill in all required fields carefully and accurately.
* Use clear and concise language in the description field.
* If you're uploading images, make sure they are relevant and clear.
* Review your submission carefully before submitting to ensure accuracy.
