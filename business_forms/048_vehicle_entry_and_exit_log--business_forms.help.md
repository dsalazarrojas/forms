# Vehicle Entry And Exit Log - Help Guide
## Purpose
The "Vehicle Entry And Exit Log" form is used to record the entry and exit of vehicles from the premises, allowing for accurate inventory management, parking management, and security surveillance.
## How To Complete This Form
1. Select the vehicle type from the options provided in the "Vehicle Type" field.
2. Enter the vehicle number in the "Vehicle Number" field.
3. Select the entry date in the "Entry Date" field.
4. Select the entry time in the "Entry Time" field.
5. Select the departure time in the "Departure Time" field.
6. Enter any entry notes in the "Entry Note" field (optional).
7. Enter any exit notes in the "Exit Note" field (optional).
8. Select the departure date in the "Departure Date" field.
9. Select the departure time in the "Exit Time" field.
10. Enter any additional notes in the "Additional Notes" field (optional).
11. Enter the entry user in the "Entry User" field (optional).
12. Enter the exit user in the "Exit User" field (optional).
## Field-by-Field Explanation
* **Vehicle Type (Car, Truck, Motorcycle)**: Select the type of vehicle that entered or exited the premises.
* **Vehicle Number**: Enter the license plate number or any other unique identifier of the vehicle.
* **Entry Date**: Select the date the vehicle entered the premises.
* **Entry Time**: Select the time the vehicle entered the premises.
* **Departure Time**: Select the time the vehicle exited the premises.
* **Entry Note**: Enter any notes about the vehicle's entry, such as reason for entry or special conditions.
* **Exit Note**: Enter any notes about the vehicle's exit, such as reason for exit or special conditions.
* **Departure Date**: Select the date the vehicle exited the premises.
* **Exit Time**: Select the time the vehicle exited the premises.
* **Additional Notes**: Enter any additional notes about the vehicle's entry or exit.
* **Entry User**: Enter the user who entered or updated the vehicle's entry record.
* **Exit User**: Enter the user who exited or updated the vehicle's exit record.
## Tips
* Make sure to select the correct vehicle type and number.
* Ensure that entry and departure dates and times match.
* Use the "Additional Notes" field for any additional information that may be useful for reference.
* Use the "Entry User" and "Exit User" fields only when necessary and accurate.
