# shipment_status_monitoring_form - Help Guide
## Purpose
The form is designed to monitor the status of shipments and facilitate communication between the shipper and the recipient.

## How To Complete This Form
To complete this form, simply input the required and optional fields as applicable to the shipment status you are tracking.

## Field-by-Field Explanation
*   **Shipments Status**: Input the current status of the shipment.
*   **Tracking Number**: Input the tracking number associated with the shipment.
*   **Shipment Date**: Input the date of the shipment.
*   **Shipment Time**: Input the time of the shipment.
*   **Status**: Choose the status of the shipment from the list of options.
*   **Shipper Name**: Input the name of the shipper.
*   **Shipper Phone**: Input the phone number of the shipper.
*   **Shipper Email**: Input the email address of the shipper.
*   **Shipper Address**: Input the address of the shipper.
*   **Consignment Note**: Input any additional notes or messages associated with the shipment.
*   **Shipper Message**: Input any messages or notes from the shipper.
*   **Shipment Status History**: Choose multiple statuses of the shipment from the list of options.

## Tips
*   Make sure to input accurate information to ensure the shipper receives correct updates.
*   Use the shipment status history field to track changes in the shipment status over time.
*   Input as much or as little information as necessary to track the shipment status.
*   Review the form regularly to stay up-to-date with the latest shipment status changes.
