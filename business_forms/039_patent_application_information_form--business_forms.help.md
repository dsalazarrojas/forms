# Patent Application Information Form - Help Guide
## Purpose
This form collects information about patent applications, including details about the applicant, the invention, and the status of the patent application.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields marked with an *asterisk* (*).
2. Ensure that the applicant's name, title, and invention name are accurate and complete.
3. Enter the correct email address and phone number for the applicant.
4. Provide a detailed description of the invention.
5. Select the correct filing status, patent office, and application type.
6. Enter the correct application fee.
7. Choose the correct application status.

## Field-by-Field Explanation
* **Applicant Name** (`applicant_name`, text, required): Enter the name of the applicant who is submitting the patent application.
* **Inventor Name** (`inventor_name`, text, optional): Enter the name of the inventor or innovator behind the invention.
* **Title** (`title`, text, required): Enter a brief title of the patent application.
* **Applicant Email** (`applicant_email`, email, optional): Enter the email address of the applicant.
* **Applicant Phone** (`applicant_phone`, text, optional): Enter the phone number of the applicant.
* **Applicant Address** (`applicant_address`, text, optional): Enter the address of the applicant.
* **Invention Name** (`invention_name`, text, required): Enter the name of the invention.
* **Description** (`description`, text, required): Provide a detailed description of the invention.
* **Date of Publication** (`date_of_publication`, date, optional): Enter the date of publication of the patent application.
* **Patent Number** (`patent_number`, text, optional): Enter the patent number (if applicable).
* **Filing Status** (`filing_status`, select_one, required): Select the current filing status of the patent application (Active or Inactive).
* **Country** (`country`, select_one, optional): Select 'Yes' if the patent application is applicable to the country.
* **Citizenship Status** (`citizenship_status`, select_multiple, optional): Select all applicable citizenship statuses (Active or Inactive).
* **Nationality** (`nationality`, text, optional): Enter the nationality of the applicant.
* **Address** (`address`, text, optional): Enter the address of the applicant.
* **Filing Date** (`filing_date`, date, optional): Enter the date of filing of the patent application.
* **Patent Office** (`patent_office`, select_multiple, optional): Select all applicable patent offices.
* **Application Type** (`application_type`, select_multiple, required): Select all applicable application types (Yes or No).
* **Application Fee** (`application_fee`, number, required): Enter the application fee.
* **Application Status** (`application_status`, select_multiple, required): Select the current application status (Active or Inactive).

## Tips
* Ensure that all required fields are completed accurately and thoroughly.
* Double-check the information before submitting the form.
* If you have any questions or concerns, please contact the relevant business team for guidance.
