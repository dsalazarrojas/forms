# Irrigation System Maintenance Inspection Form - Help Guide

## Purpose
This form is used to record and track information about irrigation system inspections. It helps personnel to monitor and maintain the systems effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the irrigation system's id in the "Irrigation System Id" field.
2. Select the inspector's id from the "Inspector Id" field.
3. Enter the date of the inspection in the "Inspection Date" field.
4. Check the system status in the "System Status" field.
5. Enter the pump's id in the "Pump Id" field.
6. Enter the pump's location in the "Pump Location" field.
7. Enter the pump's capacity in the "Pump Capacity" field.
8. Check the pump's status in the "Pump Status" field.
9. Enter the valve's id in the "Valve Id" field.
10. Enter the valve's location in the "Valve Location" field.
11. Check the valve's status in the "Valve Status" field.
12. Enter the controller's id in the "Controller Id" field.
13. Check the controller's status in the "Controller Status" field.
14. Enter the sprinkler's id in the "Sprinkler Id" field.
15. Enter the sprinkler's location in the "Sprinkler Location" field.
16. Enter the sprinkler's capacity in "Sprinkler Capacity" field.
17. Check the sprinkler's status in "Sprinkler Status" field.
18. Enter the main pump's id in "Main Pump Id" field.
19. Enter the main pump's location in "Main Pump Location" field.
20. Check the main pump's status in "Main Pump Status" field.
21. Enter the check date in "Check Date" field.
22. Enter the check user's id in "Check User Id" field.
23. Enter any additional notes about the inspection in "Check Notes" field.
24. Select the status of the inspection in "Check Status" field.

## Field-by-Field Explanation

* **Irrigation System Id (1)**: Enter the id of the irrigation system being inspected.
* **Inspector Id (2)**: Select the id of the personnel performing the inspection.
* **Inspection Date (3)**: Enter the date of the inspection (optional).
* **System Status (5)**: Select the current status of the system:
	+ Active: The system is functioning normally.
	+ Inactive: The system is not currently in use.
	+ Maintenance Required: The system requires maintenance or repair.
* **Pump Id (6)**: Enter the id of the pump in the irrigation system.
* **Pump Location (7)**: Enter the location of the pump in the irrigation system.
* **Pump Capacity (8)**: Enter the capacity of the pump (optional).
* **Pump Status (9)**: Select the status of the pump:
	+ Active: The pump is functioning normally.
	+ Inactive: The pump is not currently in use.
	+ Maintenance Required: The pump requires maintenance or repair.
* **Valve Id (10)**: Enter the id of the valve in the irrigation system.
* **Valve Location (11)**: Enter the location of the valve in the irrigation system.
* **Valve Status (12)**: Select the status of the valve:
	+ Active: The valve is functioning normally.
	+ Inactive: The valve is not currently in use.
	+ Maintenance Required: The valve requires maintenance or repair.
* **Controller Id (13)**: Enter the id of the controller in the irrigation system.
* **Controller Status (14)**: Select the status of the controller:
	+ Active: The controller is functioning normally.
	+ Inactive: The controller is not currently in use.
	+ Maintenance Required: The controller requires maintenance or repair.
* **Sprinkler Id (15)**: Enter the id of the sprinkler in the irrigation system.
* **Sprinkler Location (16)**: Enter the location of the sprinkler in the irrigation system.
* **Sprinkler Capacity (17)**: Enter the capacity of the sprinkler (optional).
* **Sprinkler Status (18)**: Select the status of the sprinkler:
	+ Active: The sprinkler is functioning normally.
	+ Inactive: The sprinkler is not currently in use.
	+ Maintenance Required: The sprinkler requires maintenance or repair.
* **Main Pump Id (19)**: Enter the id of the main pump in the irrigation system.
* **Main Pump Location (20)**: Enter the location of the main pump in the irrigation system.
* **Main Pump Status (21)**: Select the status of the main pump:
	+ Active: The main pump is functioning normally.
	+ Inactive: The main pump is not currently in use.
	+ Maintenance Required: The main pump requires maintenance or repair.
* **Check Date (22)**: Enter the date of the last check or inspection (optional).
* **Check User Id (23)**: Enter the id of the user performing the last check or inspection (optional).
* **Check Notes (24)**: Enter any additional notes about the inspection (optional).
* **Check Status (25)**: Select the status of the last check or inspection:
	+ Complete: The inspection is complete.
	+ Incomplete: The inspection is incomplete.
	+ Maintenance Required: The inspection requires further action or maintenance.
