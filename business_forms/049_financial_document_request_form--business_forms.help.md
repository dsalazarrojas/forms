# Financial Document Request Form - Help Guide
## Purpose
The Financial Document Request Form is used to request financial documents for business or personal purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of document you are requesting.
2. Enter the name of the employee whose document you are requesting.
3. Enter the name of the company for which the document is being requested.
4. Enter the date of the document you are requesting.
5. Provide a second document type if necessary.
6. Enter the document number if required.
7. Enter the name of the person requesting the document.
8. Enter the phone number of the person requesting the document.

## Field-by-Field Explanation
- **Document Type** (`document_type`, text, optional): Select the type of financial document you are requesting (e.g., invoice, receipt, etc.).
- **Employee Name** (`employee_name`, text, optional): Enter the name of the employee whose document is being requested.
- **Company Name** (`company_name`, text, optional): Enter the name of the company for which the document is being requested.
- **Document Date** (`document_date`, date, optional): Enter the date of the document you are requesting.
- **Document Type 2** (`document_type_2`, text, optional): Provide a second document type if necessary.
- **Document Number** (`document_number`, text, optional): Enter the document number if required.
- **Requestor Name** (`requestor_name`, text, optional): Enter the name of the person requesting the document.
- **Requestor Phone** (`requestor_phone`, text, optional): Enter the phone number of the person requesting the document.
