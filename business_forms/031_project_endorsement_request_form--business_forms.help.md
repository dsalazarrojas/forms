# Project Endorsement Request Form - Help Guide
## Purpose

This form is used to request endorsement from various project stakeholders. Endorsement is a formal approval from a designated stakeholder that indicates that a project is worthy of support.

## How To Complete This Form

1. Fill out all required fields, as indicated by an asterisk (*).
2. Ensure that you have obtained any necessary approval from the project sponsor.
3. Fill out the supporting documents field (if applicable).
4. Select the correct approval options for each field.
5. Enter the enddate and endorsement date fields in the correct format (e.g., MM/DD/YYYY).
6. Enter a brief description of the project in the project description field.
7. Enter the name of the project leader or manager in the project leader/manager fields (if applicable).
8. Enter the status of the project in the project status fields (if applicable).

## Field-by-Field Explanation

* **Project Name** (*): Enter the name of the project you are requesting endorsement for.
* **Project Description** (*): Enter a brief description of the project.
* **Reason for Endorsement**: Enter a brief explanation of why you are requesting endorsement for this project.
* **Supporting Documents**: Attach any relevant supporting documents for the project.
* **Manager Approval**: Select 'Yes' if you have obtained approval from the project manager.
* **Board Approval**: Select 'Yes' if you have obtained approval from the project board.
* **Sponsor Approval**: Select 'Yes' if you have obtained approval from the project sponsor.
* **Project Lead**: Enter the name of the project leader or manager.
* **Project Status**: Enter the current status of the project.
* **Endorsement Date**: Enter the date of the endorsement in the correct format (e.g., MM/DD/YYYY).
* **Formal Endorsement**: Select 'Yes' if you are requesting formal endorsement.
* **Formal Endorsement Date**: Enter the date of the formal endorsement in the correct format (e.g., MM/DD/YYYY).
* **Formal Endorsement By**: Enter the name of the person or group that is providing formal endorsement.
* **Manager Comments**: Enter any comments from the project manager.
* **Project Manager**: Enter the name of the project manager.
* **Project Status 2**: Enter the current status of the project (if applicable).
* **Project Manager Comments**: Enter any comments from the project manager.
* **Project Status 3**: Enter the current status of the project (if applicable).
* **Project Sponsor**: Select 'Yes' if you have obtained approval from the project sponsor.
* **Project Sponsor Comments**: Enter any comments from the project sponsor.
* **Project Sponsor 2**: Select 'Yes' if you have obtained approval from the project sponsor 2.
* **Project Sponsor Comments 2**: Enter any comments from the project sponsor 2.
* **Project Board**: Enter the name of the project board.
* **Project Board Comments**: Enter any comments from the project board.
