# SOW Information Collection - Help Guide

## Purpose
The SOW Information Collection form is used to gather and document essential details about a project or project-related information.

## How To Complete This Form
To complete this form, follow the step-by-step guide below:

1. **Project Scope**: Provide a brief description of the project scope and objectives.
2. **Project Name**: Enter the name of the project.
3. **Deliverables**: Select all the relevant deliverables for this project.
4. **Timeline**: Enter the timeline for the project.
5. **Due Date**: Enter the due date for the project.
6. **Stakeholders**: Select all the stakeholders involved with the project.
7. **Contact Info**: Provide contact information for follow-up purposes.
8. **Project Manager**: Select the project manager assigned to this project.
9. **Project Status**: Select the current status of the project.
10. **Notes**: Add any additional notes or comments about the project.

## Field-by-Field Explanation

* **Project Scope** (`project_scope`, text, optional): A brief description of the project scope and objectives.
* **Project Name** (`project_name`, text, optional): The name of the project.
* **Deliverables** (`deliverables`, select_multiple, optional): Select all the relevant deliverables for this project. 
*   - Select one or more options from the list to indicate the deliverables for the project.
* **Timeline** (`timeline`, date, optional): Enter the timeline for the project.
* **Due Date** (`due_date`, date, optional): Enter the due date for the project.
* **Stakeholders** (`stakeholders`, select_one, optional): Select all the stakeholders involved with the project.
*   - Select one option from the list to indicate the primary stakeholder.
* **Contact Info** (`contact_info`, text, optional): Provide contact information for follow-up purposes.
* **Project Manager** (`project_manager`, select_one, optional): Select the project manager assigned to this project.
*   - Select one option from the list to indicate the project manager.
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project.
*   - Select one option from the list to indicate the project status.
* **Notes** (`notes`, note, optional): Add any additional notes or comments about the project.
