# Va End Of Day Report - Help Guide
## Purpose
The "Va End Of Day Report" form is designed for reporting information about the end of day activities. This form helps in tracking and documenting the daily activities, tasks, and events that occurred during the day. It is used to provide a clear and concise overview of the day's activities, which can be useful for future reference and planning purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have filled in all the required fields (Note: Not all fields are required for this form.)
2. Select the "Report Date" field using the date picker.
3. Choose the "Report Start Time" and "Report End Time" using the time picker.
4. Select the "Report Type" from the provided options.
5. Add any additional comments or notes in the "Comments" field.
6. Select the name of the person submitting the report in the "Submitted By" field.
7. Enter the email address or phone number of the person submitting the report in the "Email or Phone" field.

## Field-by-Field Explanation
- **VA End Of Day Report** (`end_of_day`, Text, Optional): Enter a brief description of the day's activities.
- **Report Date** (`report_date`, Date, Required): Enter the date of the report.
- **Report Start Time** (`report_start_time`, Time, Required): Enter the start time of the report.
- **Report End Time** (`report_end_time`, Time, Required): Enter the end time of the report.
- **Report Start AM/PM** (`report_start_time_am_pm`, Select One, Optional): Select the AM/PM of the report start time.
- **Report Type** (`report_type`, Select Multiple, Optional): Select the type of report.
- **Comments** (`comments`, Note, Optional): Add any additional comments or notes about the report.
- **Submitted By** (`submitted_by`, Select One, Optional): Select the name of the person submitting the report.
- **Submitted By Phone** (`submitted_by_phone`, Email, Optional): Enter the email address or phone number of the person submitting the report.
- **Email** (`email`, Email, Optional): Enter the email address of the person submitting the report.
- **Phone** (`phone`, Text, Optional): Enter the phone number of the person submitting the report.
- **Fax** (`fax`, Text, Optional): Enter the fax number of the person submitting the report.
- **Email or Phone** (`email_phone`, Select Multiple, Optional): Select whether to submit by email or phone.
