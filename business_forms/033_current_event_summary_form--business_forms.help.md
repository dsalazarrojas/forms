# Current Event Summary Form - Help Guide
## Purpose
The Current Event Summary Form is designed to collect concise information about a current event. It includes fields for event type, date, start time, and location.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form fields as instructed in the "Field-by-Field Explanation" section below.
* Answer all required fields (indicated by *) in order to submit the form.
* You may skip optional fields if not applicable.
* Make sure to submit the form once you have completed all required fields.

## Field-by-Field Explanation
* **Current Event Summary** (`current_event_summary_form`, text, *): Enter a brief summary of the current event.
* **Event Type** (`event_type`, select_one, *): Select the type of event (e.g., meeting, conference, etc.).
* **Date Of Event** (`date_of_event`, date, *): Enter the date of the event (mm/dd/yyyy format).
* **Event Start Time** (`event_start_time`, time, *): Enter the start time of the event (hh:mm AM/PM).
* **Event Location** (`event_location`, text, *): Enter the location of the event.

## Tips
* Use the "Event Type" field to categorize the event accurately.
* Ensure the "Date Of Event" and "Event Start Time" fields match the actual event schedule.
* Use a brief and concise summary in the "Current Event Summary" field.
* If you need to provide more information about the event, consider adding an attachment or comment section in your submission.
* Please review this form carefully before submitting to ensure all required fields are filled out correctly.
