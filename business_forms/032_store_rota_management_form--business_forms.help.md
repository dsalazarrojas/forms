# Store Rota Management Form - Help Guide

## Purpose
This form is designed to manage store rotas, including shifts, start and end dates, and other relevant details. It's intended for use by store managers and collectors to track and organize store rotas data.

## How To Complete This Form

1. Fill out the form with the relevant information about the store rota, including shifts, start and end dates, and other details.
2. Choose the correct options for store rota status, employees involved, and other relevant fields.
3. Ensure all required fields are completed, such as store rota employees.
4. Double-check your input for accuracy and completeness.

## Field-by-Field Explanation

* **Store Rota Management Form**: This is the title of the form, which serves as a heading.
* **Store Rota Shifts**: Enter the shifts associated with the store rota.
* **Store Rota Start Date**: Enter the start date of the store rota.
* **Store Rota End Date**: Enter the end date of the store rota.
* **Store Rota Time**: Enter the time of the store rota shift.
* **Store Rota Notes**: Enter any additional notes about the store rota.
* **Store Rota Manager**: Enter the name of the store rota manager.
* **Store Rota Collector**: Enter the name of the store rota collector.
* **Store Rota Status**: Choose the status of the store rota (e.g., In Progress, Completed, Cancelled).
* **Store Rota Manager Note**: Enter any note from the manager about the store rota.
* **Store Rota Collector Note**: Enter any note from the collector about the store rota.
* **Store Shift Start Time**: Enter the start time of the store shift.
* **Store Shift End Time**: Enter the end time of the store shift.
* **Store Rota Email**: Enter the email address associated with the store rota.
* **Store Rota Phone**: Enter the phone number associated with the store rota.
* **Store Rota Availability**: Enter the availability of the store rota.
* **Store Rota Employees**: Select the employees involved in the store rota (Manager, Assistant Manager, Supervisor, Team Member).
* **Store Rota Form Submitted**: Indicate whether the form has been submitted or not (True or False).
