# Facility Maintenance Status Report Form - Help Guide
## Purpose
The Facility Maintenance Status Report Form is used to collect and report on the maintenance status of facilities within an organization.

## How To Complete This Form
1. Select the current status of the facility from the options provided in the "Maintenance Status" field.
2. Optionally, select the category and type of maintenance for the facility.
3. Enter the date the maintenance request was made.
4. Enter any additional comments or status descriptions.
5. Select the priority level of the maintenance request.
6. Select the user assigned to the maintenance task.
7. Attach any relevant documents or images.
8. Select the type of attachment.
9. Select the user who made the original request.
10. Enter the date the request was made.
11. Select the user who last updated the status.
12. Enter any comments about status changes.
13. Select the reason for status changes.
14. Enter the count of attachments.
15. Enter the date of the last status change.
16. Select the previous status of the facility.
17. Enter comments about the status change.
18. Select the user who made the status change.

## Field-by-Field Explanation
* **Maintenance Status** (`Maintenance Status`, `select_one`): Choose the current status of the facility (e.g., Active, Passive, Inactive).
* **facility_maintenance_category** (`facility_category`, `select_one`): Choose the category of the facility (e.g., Category A, Category B, Category C).
* **facility_maintenance_type** (`maintenance_type`, `select_one`): Choose the type of maintenance for the facility (e.g., Type 1, Type 2, Type 3).
* **request_date** (`request_date`, `date`): Enter the date the maintenance request was made.
* **status_description** (`status_description`, `text`): Enter any additional comments or status descriptions.
* **priority** (`priority`, `select_multiple`): Select the priority level of the maintenance request (e.g., High, Medium, Low).
* **assigned_to** (`assigned_to`, `select_one`): Select the user assigned to the maintenance task.
* **attachments** (`attachments`, `text`): Attach any relevant documents or images.
* **attachments_type** (`attachments_type`, `select_one`): Select the type of attachment (e.g., Type 1, Type 2, Type 3).
* **requested_by** (`requested_by`, `select_one`): Select the user who made the original request.
* **requesting_date** (`requesting_date`, `date`): Enter the date the request was made.
* **last_updated_by** (`last_updated_by`, `select_one`): Select the user who last updated the status.
* **status_changed** (`status_changed`, `text`): Enter any comments about status changes.
* **status_reason** (`status_reason`, `text`): Enter the reason for status changes.
* **attachments_count** (`attachments_count`, `number`): Enter the count of attachments.
* **status_change_date** (`status_change_date`, `date`): Enter the date of the last status change.
* **previous_status** (`previous_status`, `select_one`): Select the previous status of the facility.
* **status_change_user** (`status_change_user`, `select_one`): Select the user who made the status change.
* **comments** (`comments`, `text`): Enter comments about the status change.
