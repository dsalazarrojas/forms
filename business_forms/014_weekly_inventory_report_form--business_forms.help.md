# Weekly Inventory Report Form - Help Guide
## Purpose
The Weekly Inventory Report Form is used by warehouse staff to report inventory levels and manage stock. It helps track inventory status and determine if items need to be reordered.

## How To Complete This Form
1. Start by filling out the form header.
2. Enter the date of the inventory count.
3. Enter the name of the item being counted.
4. Enter the current quantity of the item on hand.
5. Enter the reorder point for the item.
6. Select the status of the item (Reorder, In stock, Discontinued, or Pending).
7. Enter any comments about the item, such as any issues with stock or upcoming changes.
7. Review and submit the form.

## Field-by-Field Explanation

* **Header**: This is a note field where you can enter a brief note about the inventory count.
* **inventory_date**: Enter the date of the inventory count. This date will help us track the accuracy of the data over time.
* **item**: Enter the name of the item being counted.
* **quantity**: Enter the current quantity of the item on hand. This will help us determine if the item needs to be reordered.
* **reorder_point**: Enter the reorder point for the item. This is the quantity at which we will need to reorder the item.
* **item_status**: Select the status of the item from the options provided. This will help us track the item's status and decide if it needs to be reordered.
* **item_comments**: Enter any comments or notes about the item, such as any issues with stock or upcoming changes.
* **Footer**: This is a note field where you can enter any final comments or notes about the inventory count.

## Tips
* Make sure to review the inventory levels regularly to ensure that the data is accurate and complete.
* If you are unsure about any item's status or quantity, please contact the warehouse staff for assistance.
* If you need to reorder an item, please make sure to follow the standard reordering process.
