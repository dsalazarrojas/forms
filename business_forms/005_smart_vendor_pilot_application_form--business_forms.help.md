# Smart Vendor Pilot Application Form - Help Guide
## Purpose
The Smart Vendor Pilot Application Form is used to gather information from potential vendors for the Smart Vendor Pilot program. This form ensures that all required details are captured accurately to support the evaluation and approval processes.

## How To Complete This Form
1. Start by filling out the First Page (Page 1). This page is for general information and serves as the introduction to the form.
2. Move on to the Vendor Details page (Page 2), where you will enter the vendor's basic information.
3. On the Business Details page (Page 3), select the relevant options for the vendor's business details.
4. The Pilot Details page (Page 4) is for entering the pilot project dates.
5. Proceed to the Submission Status page (Page 5), where you can select the current status of your submission.
6. Provide notes for the Pilot Notes page (Page 6) if necessary.
7. Enter the vendor's contact information and address on the Vendor Contacts and Vendor Address page (Pages 7 and 8).
8. Fill in the vendor's phone number on the Vendor Phone page (Page 9).
9. Enter the submission date and time on the Submission Date and Time page (Page 10).
10. Select the review status on the Review Status page (Page 11).
11. Add any review comments on the Review Comments page (Page 12).
12. Enter the vendor's notes on the Vendor Notes page (Page 13).
13. Capture the vendor's signature on the Vendor Signature page (Page 14).
14. Enter the reviewer's signature on the Reviewer Signature page (Page 15).
15. Select the review deadline on the Review Deadline page (Page 16).
16. Choose the approval status on the Approval Status page (Page 17).
17. Enter approval comments on the Approval Comments page (Page 18).
18. Select the vendor's status on the Vendor Status page (Page 19).
19. Choose the submission type on the Submission Type page (Page 20).
20. Select the review type on the Review Type page (Page 21).
21. Choose the submission review status on the Submission Review Status page (Page 22).
22. Enter the approval date on the Approval Date page (Page 23).
23. Select the submission status on the Submission Status page (Page 24).

## Field-by-Field Explanation

* **First Page (Page 1)**: This page serves as the introduction to the form and provides general information about the Smart Vendor Pilot program.
* **Vendor Details (Page 2)**: Enter the vendor's basic information such as their name, address, and contact details.
* **Business Details (Page 3)**: Select the relevant options for the vendor's business details, such as whether they are a new or existing vendor.
* **Pilot Details (Page 4)**: Enter the dates for the pilot project, including the start and end dates.
* **Submission Status (Page 5)**: Select the current status of your submission, such as Active or Inactive.
* **Pilot Notes (Page 6)**: Add any additional notes for the pilot project if necessary.
* **Vendor Contacts (Page 7)**: Enter the vendor's contact information, including email and phone number.
* **Vendor Address (Page 8)**: Enter the vendor's address.
* **Vendor Phone (Page 9)**: Enter the vendor's phone number.
* **Submission Date (Page 10)**: Enter the date of your submission.
* **Submission Time (Page 11)**: Enter the time of your submission.
* **Review Status (Page 12)**: Select the current review status, such as Active or Inactive.
* **Review Comments (Page 13)**: Enter any comments for the review process.
* **Vendor Notes (Page 14)**: Enter any additional notes from the vendor.
* **Vendor Signature (Page 15)**: Capture the vendor's signature.
* **Reviewer Signature (Page 16)**: Enter the reviewer's signature.
* **Review Deadline (Page 17)**: Select the review deadline.
* **Approval Status (Page 18)**: Select the current approval status, such as Active or Inactive.
* **Approval Comments (Page 19)**: Enter any comments for the approval process.
* **Vendor Status (Page 19)**: Select the vendor's status, such as Active or Inactive.
* **Submission Type (Page 20)**: Select the type of submission, such as Yes or No.
* **Review Type (Page 21)**: Select the type of review, such as Yes or No.
* **Submission Review Status (Page 22)**: Select the current submission review status, such as Active or Inactive.
* **Approval Date (Page 23)**: Enter the approval date.
* **Submission Status (Page 24)**: Select the current submission status, such as Active or Inactive.
