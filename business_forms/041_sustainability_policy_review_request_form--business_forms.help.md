# sustainability_policy_review_request_form - Help Guide
## Purpose
The sustainability policy review request form is designed to collect information for requesting a review of a sustainability policy. This form helps ensure that all necessary details are captured to facilitate the review process.

## How To Complete This Form

1. Enter the **Organization Name**, which is the name of the organization requesting the review.
2. Select the **Policy Type**, which indicates the type of policy being reviewed (e.g., Green Policy, Sustainability Policy, Carbon Policy, Environmental Policy).
3. Provide the **Document Link**, which is an optional field for uploading or linking the relevant document.
4. Set the **Priority Level**, which indicates the urgency of the review (required field).
5. Select the **Deadline**, which is the date by which the review is expected to be completed (optional field).
6. Enter the **Contact Name**, which is the name of the person contacting us (optional field).
7. Select the **Department**, which is the department responsible for the policy (required field).
8. Choose the **Document Type**, which indicates the type of document being reviewed (e.g., Sustainability Report, Policy Document, Compliance Report).
9. Select the **Policy Status**, which indicates the current status of the policy (required field).
10. Set the **Review Request Type**, which indicates the type of review requested (e.g., Review and Update, New Request, Revision).
11. Enter the **Review Request Reason**, which is an optional field for additional information.
12. Enter the **Document Description**, which is an optional field for further explanation (field).
13. Enter the **Document Link URL**, which is an optional field for uploading or linking the document.
14. Select the **Form Comments**, which is an optional field for adding additional comments (field).

## Field-by-Field Explanation

* **Organization Name** (`Organization Name`, text, required): Enter the name of the organization requesting the review.
* **Policy Type** (`Policy Type`, select one, required): Select the type of policy being reviewed (e.g., Green Policy, Sustainability Policy, Carbon Policy, Environmental Policy).
* **Document Link** (`Document Link`, note, optional): Upload or link the relevant document.
* **Priority** (`Priority`, number, required): Set the priority level of the review (e.g., 1, 2, 3).
* **Deadline** (`Deadline`, date, optional): Enter the date by which the review is expected to be completed.
* **Contact Name** (`Contact Name`, text, optional): Enter the name of the person contacting us.
* **Department** (`Department`, select multiple, required): Select the department responsible for the policy (e.g., Marketing, Finance, Operations, HR).
* **Document Type** (`Document Type`, select one, required): Choose the type of document being reviewed (e.g., Sustainability Report, Policy Document, Compliance Report).
* **Policy Status** (`Policy Status`, select multiple, required): Select the current status of the policy (e.g., Active, Inactive, Pending Review).
* **Review Request Type** (`Review Request Type`, select multiple, required): Select the type of review requested (e.g., Review and Update, New Request, Revision).
* **Review Request Reason** (`Review Request Reason`, text, optional): Enter the reason for the review request.
* **Document Description** (`Document Description`, note, optional): Enter a further explanation of the document.
* **Document Link URL** (`Document Link URL`, note, optional): Upload or link the document.
* **Policy Status** (`Policy Status`, select multiple, required): Select the current status of the policy.
* **Review Request** (`Review Request`, note, optional): Add any additional review requests.
* **Note** (`Note`, select multiple, required): Select whether the review request is true or false.
* **Form Comments** (`Form Comments`, text, optional): Add any additional comments.
