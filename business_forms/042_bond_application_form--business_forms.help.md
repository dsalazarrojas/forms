# Bond Application Form - Help Guide

## Purpose
The Bond Application Form is a tool used to collect information about an individual's bond application, including their personal details, employment status, housing status, family ties, and substance abuse and mental health history. This information is intended for use in a legal or court context.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field according to the instructions provided.
2. Make sure to answer all required questions truthfully and accurately.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Application Date** (`application_date`, date, required): This is the date the bond application was submitted.
* **Defendant Full Name** (`defendant_full_name`, text, required): This is the full name of the individual applying for the bond.
* **Date of Birth** (`defendant_date_of_birth`, date, required): This is the date of birth of the individual applying for the bond.
* **Current Address** (`defendant_address`, text, required): This is the current address of the individual applying for the bond.
* **City - State - Zip** (`defendant_city_state_zip`, text, required): This is the city, state, and zip code of the individual's current address.
* **Phone Number** (`defendant_phone`, text, required): This is the phone number of the individual applying for the bond.
* **Social Security Number** (`defendant_ssn`, text, required): This is the last four digits of the individual's social security number, which is considered acceptable for this field.
* **Case Number** (`case_number`, text, required): This is the case number associated with the bond application.
* **Charges** (`charges`, text, required): This is a description of the charges associated with the bond application.
* **Court Name** (`court_name`, text, required): This is the name of the court associated with the bond application.
* **Assigned Judge** (`judge_assigned`, text, optional): This is the name of the judge assigned to the bond application.
* **Arrest Date** (`arrest_date`, date, required): This is the date of the individual's arrest.
* **Current Employment Status** (`employment_status`, select_one, required): This is the individual's current employment status, which can be Employed - Full Time, Employed - Part Time, Self-Employed, Unemployed, Retired, Student, or Disabled.
* **Current Employer Name** (`employer_name`, text, optional): If the individual is employed, this is the name of their current employer.
* **Annual Income** (`annual_income`, number, optional): This is the approximate annual income of the individual.
* **Housing Status** (`housing_status`, select_one, required): This is the individual's housing status, which can be Own Home, Rent Home, Live with Family, No Fixed Address, or Other.
* **Family Ties in Community** (`family_ties`, text, optional): This is a description of the individual's family ties in the community.
* **Prior Criminal Convictions** (`prior_convictions`, text, optional): This is a description of the individual's prior criminal convictions.
* **Outstanding Warrants** (`outstanding_warrants`, select_one, required): This is a boolean indicating if the individual has outstanding warrants.
* **Substance Abuse History** (`substance_abuse_history`, select_one, required): This is a description of the individual's substance abuse history, which can be No History, Past History, Current Use, In Treatment, or Prefer Not to Answer.
* **Mental Health History** (`mental_health_history`, select_one, required): This is a description of the individual's mental health history, which can be No History, Past History, Current Treatment, Hospitalized, or Prefer Not to Answer.
* **Emergency Contact Name** (`emergency_contact_name`, text, required): This is the name of the individual's emergency contact.
* **Emergency Contact Phone** (`emergency_contact_phone`, text, required): This is the phone number of the individual's emergency contact.
* **Relationship to Contact** (`emergency_contact_relationship`, text, required): This is a description of the relationship between the individual and their emergency contact.
* **I Acknowledge** (`applicant_acknowledgment`, select_one, required): This is a statement of acknowledgment of the accuracy of the provided information, which can be I Acknowledge or I Do Not Acknowledge.
