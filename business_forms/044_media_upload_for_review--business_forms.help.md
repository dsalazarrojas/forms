# Media Upload For Review - Help Guide
## Purpose
This form is used for uploading media and setting up a review process for a project.

## How To Complete This Form
1. Select the category of the media you are uploading (e.g. image, video, document).
2. Add a description of the media file.
3. Upload the media file.
4. Select the reviewers who will review the media (e.g. colleagues, team members).
5. Set the project name where the media will be used.
6. Optionally, set a due date for the review process to be completed.

## Field-by-Field Explanation

* **Category** (`category`, `select_one`, not required): Select the category of the media you are uploading. This will help the review process move forward.
* **Description** (`description`, `note`, not required): Add a brief description of the media file.
* **File** (`file`, `text`, not required): This field is not used in the form, but it's a field named "File". It's likely meant for uploading the actual media file.
* **Reviewers** (`reviewers`, `select_multiple`, not required): Select the reviewers who will review the media. You can select multiple reviewers if needed.
* **Project** (`project`, `text`, not required): Set the project name where the media will be used.
* **Due Date** (`due_date`, `date`, not required): Set a due date for the review process to be completed.

## Tips
* Make sure to select the correct category to ensure the review process moves forward smoothly.
* Be clear and concise in your description.
* Select the correct reviewers to ensure timely and proper feedback.
* Set a due date if you have a specific deadline for the review process.
* Double-check your uploads and review assignments to avoid errors.
