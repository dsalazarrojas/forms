# Project Party - Help Guide
## Purpose
The "Project Party" form is used to collect information about a party or event, including its type, number of guests, menu preferences, and other details.

## How To Complete This Form
To complete the "Project Party" form, follow these steps:

1. Select the type of event you are planning (e.g., Birthday, Wedding, Anniversary).
2. Enter the number of guests attending the event (if applicable).
3. Choose the party theme and menu options (if applicable).
4. Provide setup and design details (if applicable).
5. Enter the date and time of the event.
6. Specify the location of the event.
7. Add any additional notes or comments about the event.

## Field-by-Field Explanation

* **Event Type** (`event_type`, select, required/optional): Select the type of event (e.g., Birthday, Wedding, Anniversary).
	+ Choose from the available options: Birthday, Wedding, Anniversary.
* **Number of Guests** (`number_of_guests`, number, optional): Enter the number of guests attending the event (if applicable).
* **Party Theme** (`party_theme`, text, optional): Choose the party theme, e.g., Finger Foods, BBQ, Hors d'oeuvres.
	+ Enter a theme name or description.
* **Menu Type** (`menu_type`, select_multiple, optional): Select multiple menu options for the event (if applicable).
	+ Choose from the available options: Finger Foods, BBQ, Hors d'oeuvres.
* **Setup Details** (`setup_details`, text, optional): Enter setup details, such as table settings, decorations, etc.
* **Design Details** (`design_details`, text, optional): Enter design details, such as color scheme, decorations, etc.
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Event Time** (`event_time`, time, optional): Enter the time of the event.
* **Location** (`location`, text, optional): Specify the location of the event.
* **Notes** (`notes`, note, optional): Add any additional notes or comments about the event.

## Tips

* Make sure to select the correct event type and menu options to ensure accurate planning and preparation.
* Enter accurate and specific details about the event date, time, and location.
* Use the notes field to add any additional information that may be helpful for the event organizers or planners.
