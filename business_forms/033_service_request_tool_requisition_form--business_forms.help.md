# Service Request Tool Requisition Form - Help Guide
## Purpose
The Service Request Tool Requisition Form is used to request access to specific tools for business operations. This form helps to streamline the process of requesting tools for various departments within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the tools you require from the list of available tools.
2. Provide a brief description of your requirements in the "Description" field.
3. Choose the category that best suits your request from the list of options.
4. Select the assigned tool from the list of options.

## Field-by-Field Explanation

* **Tool Request** (`tool_request`, `select_multiple`, required/optional: optional): 
  This field allows you to select one or more tools from the list. 
  Please choose the tools you need for your business operation.

* **Description** (`description`, `text`, required/optional: optional): 
  Please provide a brief description of the tools you require and their expected use.

* **Category** (`category`, `select_one`, required/optional: optional): 
  Choose the category that best suits your request from the provided options.

* **Assigned Tool** (`assigned_tool`, `select_one`, required/optional: optional): 
  Select the tool that will be assigned to fulfill your request from the provided options.
