# shelf_label_printing_request_form - Help Guide
## Purpose
This form is used to request printing of shelf labels or tags for a specific category.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for which you want to request printing of labels.
2. Enter a description of the labels you want to print.
3. Choose the print size of the labels.
4. Specify the quantity of labels you need.
5. Set the due date for the printing request.
6. Enter any additional content or instructions for the label.
7. If applicable, specify the assigned tool or equipment for the printing.
8. Optionally, enter the output file path for the printing request.

## Field-by-Field Explanation
* **form_category** (Select One):
	+ This field allows you to select the category for which you want to request printing of labels.
* **form_description** (Text):
	+ Enter a brief description of the labels you want to print.
* **print_size** (Number):
	+ Choose the size of the labels you want to print (e.g., 1 inch, 2 inches, etc.).
* **print_quantity** (Number):
	+ Specify the quantity of labels you need.
* **due_date** (Date):
	+ Set the due date for the printing request.
* **content** (Text):
	+ Enter any additional content or instructions for the label.
* **form_ids** (Text):
	+ This field is likely used to track or reference the form's ID for internal purposes.
* **assigned_tool** (Text):
	+ If applicable, specify the assigned tool or equipment for the printing.
* **output_file** (Text):
	+ Optionally, enter the output file path for the printing request.
* **output_file_path** (Text):
	+ If applicable, enter the path where the output file will be saved.
* **category** (Text):
	+ Enter any additional category information for the printing request.

Note: The fields marked as optional may not be required for every use case, but are provided in case you need to include additional information.
