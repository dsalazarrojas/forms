# Financial Analytics Collaboration Application - Help Guide
## Purpose
The Financial Analytics Collaboration Application form is designed to gather and analyze data on team collaboration requests, team member evaluations, and project ideas. This form helps teams evaluate and refine their collaboration processes, identify areas for improvement, and develop effective project ideas.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of collaboration you are requesting or evaluating:
	* Choose from "Requests", "Collaborations", or "Ideas" for the first field.
	* Select one of the four options (Excellent, Good, Fair, or Poor) for the second field, Team Evaluation.
2. Provide a brief description for the Project Idea field (fields 3 and 4). This field is not required.
3. Fill in any other optional fields as needed.

## Field-by-Field Explanation
* **Collaboration Requests** (`financial_analytics_form`, select_multiple): Choose from "Requests", "Collaborations", or "Ideas" to indicate the type of collaboration you are requesting or evaluating.
* **Team Evaluation** (`collaboration_requests_form`, select_one): Select one of the four options (Excellent, Good, Fair, or Poor) to evaluate the team's performance.
* **Project Idea** (`project_idea_form`, text): Provide a brief description of your project idea. This field is not required.
* **Project Idea 2** (`project_idea_form_2`, text): Provide another brief description of your project idea. This field is not required.

## Tips
* Please provide clear and concise descriptions for the Project Idea fields, as they will be used to analyze and evaluate project ideas.
* Make sure to select the correct option for Team Evaluation to ensure accurate and fair assessments.
* If you are unsure about any field, please ask for help or clarification.
