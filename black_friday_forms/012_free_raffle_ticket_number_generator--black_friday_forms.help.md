# Free Raffle Ticket Number Generator - Help Guide
## Purpose
The Free Raffle Ticket Number Generator form is designed to provide a quick and easy way to generate free raffle tickets for a specific raffle event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information for your raffle event.
2. Fill out the required fields with the correct details.
3. Select the options as needed.
4. Click "Generate Tickets" to generate the free raffle ticket numbers.

## Field-by-Field Explanation
### Ticket Number
* **Ticket Number** (`ticket_number`, number, optional): Enter the number of the raffle ticket you would like to generate.
* **Draw Date** (`draw_date`, date, optional): Select the date of the raffle draw.
* **Draw Time** (`draw_time`, time, optional): Select the time of the raffle draw.
* **Winning Tickets** (`winning_tickets`, number, optional): Enter the number of winning tickets.
* **Raffle ID** (`raffle_id`, number, optional): Enter the ID number of your raffle event.
* **Total Tickets** (`total_tickets`, number, optional): Enter the total number of tickets available for the raffle.
* **Winning Number** (`winning_number`, number, optional): Enter the winning ticket number.
* **Ticket Numbers** (`ticket_numbers`, select multiple, optional): Select whether the generated ticket numbers are "Yes", "No", or "Other".
* **Generate Tickets** (`generate_tickets`, select multiple, optional): Select "Yes", "No", or "Other" to indicate whether to generate tickets.
* **Raffle Id 2** (`raffle_id_2`, text, optional): Enter a secondary ID number for your raffle event (e.g. for a second draw).
* **Draw Time 2** (`draw_time_2`, time, optional): Select the time of the second draw.
* **Draw Date 2** (`draw_date_2`, date, optional): Select the date of the second draw.

## Tips
* Make sure to enter the correct details for your raffle event.
* The form will only generate tickets for valid and existing raffle events.
* If you need help with a specific field, refer to the field-by-field explanation above.
