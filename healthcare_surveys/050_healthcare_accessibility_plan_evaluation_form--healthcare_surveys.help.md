> # healthcare_accessibility_plan_evaluation_form - Help Guide
## Purpose
This form is designed to evaluate a healthcare facility's accessibility plan, gathering information on accessibility features and patient feedback.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form and familiarize yourself with the questions and fields.
2. Answer the questions on each page, providing as much detail as possible.
3. Select the options that best answer each question from the dropdown menus.
4. Provide any additional comments or feedback in the free-text fields.

## Field-by-Field Explanation

* **introduction** (Page 1): This is a note field for any introductory information about the facility and its accessibility plan.
* **facility_location** (Page 2): Please provide the physical address of the healthcare facility.
* **accessibility_features** (Page 3): Select all the accessibility features that are available at the facility, using the dropdown menu. These include:
	+ Wheelchair
	+ Wheelchair accessible entrance
	+ Automatic door
	+ Wide doorways
	+ Wide doorways and hallways
	+ Accessible parking
	+ Accessible restrooms
	+ Accessible seating
	+ Accessible waiting area
	+ Accessible examination room
	+ Accessible treatment area
* **feedback** (Page 4): Provide any feedback or comments about the facility's accessibility features and services.
* **contact_information** (Page 5): Please provide your name, title, and contact information (email address and phone number) so that we can follow up with you about your feedback.
* **patient_feedback** (Page 6): Please select how satisfied you are with your experience at the facility, using the dropdown menu. Options include:
	+ Very satisfied
	+ Somewhat satisfied
	+ Neutral
	+ Somewhat dissatisfied
	+ Very dissatisfied
* **patient_satisfaction** (Page 7): Please select how satisfied you are with your experience at the facility, using the dropdown menu. Options include:
	+ Very satisfied
	+ Somewhat satisfied
	+ Neutral
	+ Somewhat dissatisfied
	+ Very dissatisfied
* **additional_comments** (Page 8): If there is anything else you would like to comment on or provide additional feedback, please do so here.

## Tips
- Please answer all questions to the best of your ability.
- If you are unable to complete the form in one sitting, please save your progress and return to it later.
- If you have any questions or concerns, please don't hesitate to contact us.
