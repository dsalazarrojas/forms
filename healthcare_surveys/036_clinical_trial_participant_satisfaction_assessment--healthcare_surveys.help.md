# Clinical Trial Participant Satisfaction Assessment - Help Guide
## Purpose
This guide will walk you through the Clinical Trial Participant Satisfaction Assessment form, which aims to collect feedback from clinical trial participants to improve the trial experience.

## How To Complete This Form
1. Start by reading the introduction page, which provides context and instructions for the survey.
2. Answer the questions on each page according to your experience and perceptions.
3. Be honest and thorough in your responses, as your feedback is valuable to us.
4. If you have any additional comments or suggestions, please use the "Additional Comments" field at the end of the form.

## Field-by-Field Explanation

* **Clinical Trial Participant Satisfaction Assessment (page 1)**: This is the introduction page, providing context and instructions for the survey.
* **Participant ID (page 2)**: Enter your participant ID, if you have one. If not, you can leave this field blank.
	+ Label: Participant ID
	+ Type: Text input
	+ Hint: Optional
* **Study ID (page 2)**: Enter the study ID, if you have one. If not, you can leave this field blank.
	+ Label: Study ID
	+ Type: Text input
	+ Hint: Optional
* **Survey Date (page 3)**: Select the date you completed the clinical trial.
	+ Label: Survey Date
	+ Type: Date picker
	+ Hint: null
* **How Many Visits Have You Completed (page 3)**: Select the number of visits you completed during the clinical trial.
	+ Label: How Many Visits Have You Completed
	+ Type: Select one option
	+ Options: 1-2 visits, 3-5 visits, 6-10 visits, 11+ visits, Study Complete
* **Overall How Satisfied Are You with Your Trial Experience (page 4)**: Rate your overall satisfaction with the trial experience.
	+ Label: Overall How Satisfied Are You with Your Trial Experience
	+ Type: Select one option
	+ Options: Very Satisfied, Satisfied, Neutral, Dissatisfied, Very Dissatisfied
* **How Would You Rate the Informed Consent Process (page 4)**: Rate the informed consent process as part of the trial.
	+ Label: How Would You Rate the Informed Consent Process
	+ Type: Select one option
	+ Options: Excellent, Very Good, Good, Fair, Poor
* **Did You Feel You Understood What You Were Consenting To (page 5)**: Rate how well you understood what you were consenting to.
	+ Label: Did You Feel You Understood What You Were Consenting To
	+ Type: Select one option
	+ Options: Yes Completely, Yes Mostly, Somewhat, Not Really, No Not at All
