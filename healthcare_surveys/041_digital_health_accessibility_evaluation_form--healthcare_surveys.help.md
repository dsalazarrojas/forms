# digital_health_accessibility_evaluation_form - Help Guide

## Purpose
The digital health accessibility evaluation form is used to evaluate the accessibility of digital platforms. It helps to assess how well a platform meets accessibility standards for users with disabilities. This form collects information about the platform type, user group, user experience, accessibility features, accessibility bar, platform accessibility, and feedback.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of platform you are evaluating (e.g., website, mobile app, or other).
2. Indicate the user group that would be using the platform (e.g., healthcare provider, patient, family member, or other).
3. Describe your experience using the platform.
4. List all the accessibility features available on the platform.
5. Rate the platform's accessibility on a scale of 1-5.
6. Choose the overall accessibility level of the platform (e.g., high, medium, low).
7. Provide any additional feedback about the platform.

## Field-by-Field Explanation

* **Platform Type** (1):
	+ A select_one field that asks you to choose the type of digital platform you are evaluating (e.g., website, mobile app, or other).
* **User Group** (2):
	+ A select_multiple field that asks you to indicate which user group would be using the platform (e.g., healthcare provider, patient, family member, or other).
* **User Experience** (3):
	+ A text field where you can describe your experience using the platform.
* **Accessibility Features** (4):
	+ A text field where you can list all the accessibility features available on the platform.
* **Accessibility Bar** (5):
	+ A number field where you can rate the platform's accessibility on a scale of 1-5.
* **Platform Accessibility** (6):
	+ A select_one field that asks you to choose the overall accessibility level of the platform (e.g., high, medium, low).
* **Feedback** (7):
	+ A note field where you can provide any additional feedback about the platform.

## Tips

* Make sure to be as accurate as possible when answering the questions.
* If you are unsure about a particular feature or aspect of the platform, try to describe it as best as you can.
* If you need help or have questions, feel free to contact us.
