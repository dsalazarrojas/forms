# Public Health Data Trust Perception Survey - Help Guide
## Purpose
This survey is designed to gauge the trust and concerns related to data in the public health sector. Your input will help us understand how individuals perceive and interact with public health data, which is crucial for improving data trust and security in the sector.

## How To Complete This Form
1. Review each page carefully and answer all questions to the best of your ability.
2. Select all that apply for each question.
3. Make sure to submit the form only once you have completed all pages.

## Field-by-Field Explanation

* **Public Health Data Trust Survey** (<type:text>): This is the main question, which asks about your general trust in public health data.
* **Healthcare Organization Surveyed** (<type: select_multiple>): Please select all the types of healthcare organizations you have worked with or interacted with in the past (e.g., Public Health Department, Nonprofit Organization, Academic Research Institution).
* **Healthcare Organization Surveyed 1** (<type: select_one>): Please select only one type of healthcare organization you have worked with or interacted with in the past (e.g., Public Health Department, Nonprofit Organization, Academic Research Institution).
* **Surveyed** (<type: select_one>): Please select only one type of public health data that you have interacted with in the past (e.g., Public Health Department, Nonprofit Organization, Academic Research Institution).
* **Concern** (<type: select_multiple>): Select all the concerns you have about public health data, such as Lack of control over data, Data not secure, Data not private, etc.
* **Concern 1** (<type: select_multiple>): Select all the sub-concerns about concern 1 (e.g., Data not secure, Data not private, etc.).
* **Concern 2** (<type: select_multiple>): Select all the sub-concerns about concern 2 (e.g., Unfair bias, Lack of diversity, etc.).
* ...
* **Concern 19** (<type: select_multiple>): Select all the sub-concerns about concern 19 (e.g., Unfair bias, Other, etc.).

## Tips

* Please answer honestly and to the best of your ability.
* If you are unsure about any question, please ask your supervisor or team lead for guidance.
* You should not fill out this survey if you have completed a similar survey in the past.
* Make sure to submit the form only once you have completed all pages.
