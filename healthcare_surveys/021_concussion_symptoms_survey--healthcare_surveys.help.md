# Concussion Symptoms Survey - Help Guide
## Purpose
This form is used to gather information about a patient's symptoms after a concussion. It's essential to complete this form accurately to help healthcare professionals assess the severity of the symptoms and provide proper care.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your patient's initials in the "Patient initials" field, if you're not anonymous.
2. Select the date of the incident from the calendar in the "Date of incident" field.
3. In the "Current symptoms" field, select all the symptoms that apply to the patient.
4. Choose the overall symptom severity in the "Symptom severity overall" field.
5. If necessary, note any changes in sleep patterns in the "Changes in sleep patterns" field.
6. Describe any cognitive changes noticed in the patient in the "Cognitive changes noticed" field.
7. Provide the number of previous concussions, if known.
8. List any current medications the patient is taking in the "Current medications" field.
9. Check if urgent follow-up is required in the "Urgent follow-up required" field.
10. Add any additional notes about the patient's condition in the "Additional notes" field.

## Field-by-Field Explanation

* **Patient initials**: Your patient's initials. This field is optional for anonymous submissions.
* **Date of incident**: When the head injury occurred.
* **Current symptoms**: Select all the symptoms that apply to the patient, such as Headache, Dizziness, Nausea, Sensitivity to light, Sensitivity to noise, and Memory problems.
* **Symptom severity overall**: Choose how severe the symptoms are overall, with options being Mild, Moderate, or Severe.
* **Changes in sleep patterns**: Note any changes in the patient's sleep patterns, such as difficulty sleeping or sleeping more.
* **Cognitive changes noticed**: Describe any cognitive changes noticed in the patient, like concentration or memory issues.
* **Prior concussion history**: Provide the number of previous concussions, if known.
* **Current medications**: List any medications the patient is currently taking, including over-the-counter medications.
* **Urgent follow-up required**: Check if the patient needs urgent follow-up care.
* **Additional notes**: Add any other relevant information about the patient's condition.
