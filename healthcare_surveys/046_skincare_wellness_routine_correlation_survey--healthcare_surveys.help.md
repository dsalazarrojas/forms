# Skincare Wellness Routine Correlation Survey - Help Guide
## Purpose
This survey aims to collect information about your skincare routines, habits, and practices. Your responses will help us better understand how skincare routines relate to overall wellness.
## How To Complete This Form
To complete this form, simply follow the steps below:

1. Answer all questions honestly and accurately.
2. Please select the correct options for each question based on your current practices.
3. You may refer to the field explanations below for further guidance.

## Field-by-Field Explanation
* **General Information** (`general_info`, text, required: false): This field is a text entry for any additional information you'd like to provide.
* **Survey Information** (`survey_info`, text, required: false): If you have any comments or additional information about your skincare routine, please enter it here.
* **Skincare Frequency** (`skincare_frequency`, number, required: false): Please select the number of times you practice a skincare routine per week.
*   *If not applicable, select 0*
* **Skincare Products** (`skincare_products`, select_one, required: false): Do you currently use skincare products? 
    *Yes* if you regularly use them
    *No* if you do not use them
* **Wellness Frequency** (`wellness_frequency`, number, required: false): If you have a regular wellness routine, how often do you practice it?
*   *If not applicable, select 0*
* **Skincare Prospects** (`skincare_prospects`, select_multiple, required: false): What benefits do you think skincare provides? 
    *Yes* if you believe it provides the benefit
    *No* if you do not believe it provides the benefit
* **Survey Participants** (`survey_participants`, text, required: false): Who are you sharing this information with? (e.g., family members, friends, online communities)
*   *If not applicable, leave blank*
*   *If other, please provide details*
* **Other Survey Participants** (`survey_participants_other`, text, required: false): If you are sharing this information with anyone not listed above, please specify their names or details.
*   *If not applicable, leave blank*
*   *If other, please provide details*
* **Healthcare Professionals** (`healthcare_professionals`, select_multiple, required: false): Have you ever consulted with a healthcare professional about your skin health?
    *Yes* if you have
    *No* if you have not
*   *If other, please specify*
* **Wellness Habits** (`wellness_habits`, text, required: false): Please list any wellness habits you practice regularly.
*   *If not applicable, leave blank*
*   *If other, please provide details*
* **Wellness Products** (`wellness_products`, select_multiple, required: false): Do you use any wellness products? 
    *Yes* if you use them
    *No* if you do not use them
* **Skincare Habits** (`skincare_habits`, select_multiple, required: false): Do you practice any of the following skincare habits? 
    *Yes* if you do
    *No* if you do not
*   *If other, please specify*
* **Other Skincare Products** (`skincare_products_other`, text, required: false): If you use any other skincare products, please list them.
*   *If not applicable, leave blank*
*   *If other, please provide details*
