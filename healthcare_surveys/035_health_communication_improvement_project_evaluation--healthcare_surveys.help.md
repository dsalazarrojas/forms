# Health Communication Improvement Project Evaluation - Help Guide
## Purpose
This form is designed to gather feedback on healthcare projects, allowing healthcare professionals to evaluate and improve project performance.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Enter the project title in the "Project Title" field.
2. Provide the project URL in the "Project URL" field.
3. Enter a brief description of the project in the "Project Description" field.
4. Select the evaluation date from the calendar.
5. Rate the project performance using the ratings scale (1-5, 2-8, 4-10).
6. Provide any suggestions or comments about the project.
7. Enter your email address (optional).
8. Enter your phone number (optional).
9. Select the category of the project (Healthcare Surveys, Patient Feedback, Project Evaluation).
10. Select one or more tags related to the project (healthcare, patient feedback, project evaluation).
11. Select who submitted the form (Form Author, Team Member, Guest User).
12. Select your department (Healthcare, Patient Feedback, Project Management).
13. Select your role in the project (Form Author, Team Leader, Guest User).
14. Select the submitter who filled out the form (Form Author, Team Member, Guest User).
15. Select the project status (Completed, In Progress, Not Started).
16. Select the ratings scale for the project performance.
17. Provide any comments or feedback about the project.
