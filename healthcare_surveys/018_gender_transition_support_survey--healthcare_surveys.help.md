# Gender Transition Support Survey - Help Guide
## Purpose
This form is used to collect feedback on an individual's gender transition support from healthcare staff. It is a survey designed to gauge the level of support provided to patients undergoing gender transition.

## How To Complete This Form
1. Please select the correct answer for each question based on your honest feedback.
2. You can select multiple options for each question, as they are designed to be select_multiple types.
3. Please be as specific as possible when answering questions like "Supportive" and "Not Supportive".

## Field-by-Field Explanation
* **Gender Transition Support** (`gender_transition_support`, select_multiple):
	+ This question is about your general level of support for patients undergoing gender transition.
	+ Please select from the following options:
		- Strongly Agree
		- Somewhat Agree
		- Somewhat Disagree
		- Strongly Disagree
		- Neutral
		- Prefer Not to Answer
* **Gender Identity** (`gender_identity`, select_one):
	+ This question is about the individual's self-identified gender.
	+ Please select one of the following options:
		- Male
		- Female
		- Nonbinary
* **Age** (`age`, number):
	+ This question is about the patient's age.
	+ Please enter a numerical value.
