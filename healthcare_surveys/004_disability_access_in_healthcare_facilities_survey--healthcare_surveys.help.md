# Disability Access In Healthcare Facilities Survey - Help Guide
## Purpose

This guide will walk you through the survey questions and help you complete the Disability Access In Healthcare Facilities Survey.

## How To Complete This Form

*   To complete the survey, please select all the pages listed on the following pages: <a href="#pages-1-17" id="pages-1-17">Pages 1-17</a>.



## Field-by-Field Explanation

*   **Survey Title (`survey_title`)**: <span class="label">Survey Title</span> (<span class="type">Text</span>): This field is used to enter a title for the survey. It is not a required field.
*   **Survey Date (`survey_date`)**: <span class="label">Survey Date</span> (<span class="type">Date</span>): This field is used to enter the date of the survey.
*   **Accessibility Facility (`access_facility`)**: <span class="label">Accessibility Facility</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the facility, such as ramps or elevators.
*   **Accessibility Entrance (`access_entrance`)**: <span class="label">Accessibility Entrance</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the entrance, such as automatic doors.
*   **Accessibility Pathway (`access_pathway`)**: <span class="label">Accessibility Pathway</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the pathway, such as clear signage.
*   **Accessibility Elevator (`access_elevator`)**: <span class="label">Accessibility Elevator</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the elevator, such as accessibility buttons.
*   **Accessibility Restroom (`access_restroom`)**: <span class="label">Accessibility Restroom</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the restroom, such as grab bars.
*   **Accessibility Service Animal (`access_serviceanimal`)**: <span class="label">Accessibility Service Animal</span> (<span class="type">Text</span>): This field is used to describe the policies and procedures for service animals in the facility.
*   **Accessibility Wheelchair (`access_wheelchair`)**: <span class="label">Accessibility Wheelchair</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the wheelchair accessibility, such as accessible seating areas.
*   **Accessibility Signage (`access_signage`)**: <span class="label">Accessibility Signage</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the signage, such as clear and large print.
*   **Accessibility Hearing (`access_hearing`)**: <span class="label">Accessibility Hearing</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the hearing accessibility, such as sound amplification systems.
*   **Accessibility Visually (`access_visually`)**: <span class="label">Accessibility Visually</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the visually accessibility, such as audio signals for the visually impaired.
*   **Accessibility Motor (`access_motor`)**: <span class="label">Accessibility Motor</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the motor accessibility, such as accessible parking.
*   **Accessibility Tactile (`access_tactile`)**: <span class="label">Accessibility Tactile</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the tactile accessibility, such as Braille signage.
*   **Accessibility Other (`access_other`)**: <span class="label">Accessibility Other</span> (<span class="type">Text</span>): This field is used to describe any other accessibility features not listed above.
*   **Facility Location (`facility_location`)**: <span class="label">Facility Location</span> (<span class="type">Text</span>): This field is used to describe the location of the facility.
*   **Facility Type (`facility_type`)**: <span class="label">Facility Type</span> (<span class="type">Select One</span>): This field is used to select the type of facility, such as hospital or clinic.
*   **Facility Accessibility (`facility_accessibility`)**: <span class="label">Facility Accessibility</span> (<span class="type">Text</span>): This field is used to describe the accessibility features of the facility.
*   **Contact Name (`contact_name`)**: <span class="label">Contact Name</span> (<span class="type">Text</span>): This field is used to enter the contact person's name.
*   **Contact Email (`contact_email`)**: <span class="label">Contact Email</span> (<span class="type">Email</span>): This field is used to enter the contact person's email address.
*   **Contact Phone (`contact_phone`)**: <span class="label">Contact Phone</span> (<span class="type">Text</span>): This field is used to enter the contact person's phone number.
*   **Accessibility Barriers (`accessibility_barriers`)**: <span class="label">Accessibility Barriers</span> (<span class="type">Text</span>): This field is used to list the accessibility barriers in the facility.
*   **Accessibility Suggestions (`accessibility_suggestions`)**: <span class="label">Accessibility Suggestions</span> (<span class="type">Text</span>): This field is used to enter suggestions for improving accessibility in the facility.
*   **Survey Comments (`survey_comments`)**: <span class="label">Survey Comments</span> (<span class="type">Text</span>): This field is used to enter any comments or observations about the survey.

## Tips

*   Always complete the survey with the utmost care and attention to detail.
*   Make sure to answer all questions accurately and thoroughly.
*   If you have any doubts or concerns, please contact the survey administrator.
*   You can enter suggestions for improving accessibility in the field "Accessibility Suggestions".
*   You can also provide any additional comments or observations about the survey in the field "Survey Comments".
