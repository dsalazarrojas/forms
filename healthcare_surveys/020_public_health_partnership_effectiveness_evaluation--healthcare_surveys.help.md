## Public Health Partnership Effectiveness Evaluation - Help Guide

## Purpose
This form is used to evaluate the effectiveness of public health partnerships. It helps gather information about the partnership's objectives, description, category, output file, assigned tool, and other relevant details.

## How To Complete This Form

1. Enter a title for the partnership in the "Public Health Partnership Effectiveness Evaluation" field.
2. Select the category of the partnership from the dropdown menu.
3. Provide a description of the partnership in the "Description" field.
4. Enter the output file name in the "Output File" field.
5. Select the assigned tool for the partnership from the dropdown menu.
6. Enter a unique ID for the partnership in the "Form ID" field.

## Field-by-Field Explanation

* **Public Health Partnership Effectiveness Evaluation** (`form_title`, text, optional): Enter a brief title for the partnership, e.g., "Public Health Partnership to Improve Vaccination Rates".
* **Category** (`category`, select_one, optional): Select the category of the partnership from the provided options, e.g., "Healthcare Surveys".
* **Description** (`description`, text, optional): Provide a detailed description of the partnership, including its objectives and goals.
* **Description** (`form_description`, text, optional): This is another description field for additional information about the partnership.
* **Output File** (`output_file`, text, optional): Enter the name of the output file related to the partnership, e.g., "Report.docx".
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select the tool assigned to the partnership from the provided options, e.g., "ChatJIMMY".
* **Form ID** (`form_id`, text, optional): Enter a unique ID for the partnership, e.g., "PHPP-001".
* **Title** (`form_title_input`, text, optional): Enter a title for the partnership, this field is similar to the first field "Public Health Partnership Effectiveness Evaluation".
