# Substance Misuse Prevention Evaluation - Help Guide

## Purpose
The Substance Misuse Prevention Evaluation form is designed to collect data on substance misuse prevention programs to help identify areas for improvement and inform program development.

## How To Complete This Form

1. Start by filling out the first page, which includes:
	* Program Title: Enter the title of the program being evaluated.
	* Organization: Enter the name of the organization running the program.
	* Program Name: Enter the name of the program.
	* Program Type: Select the type of program (e.g., School, Nonprofit, Public Health).
	* Target Population: Select the target population of the program (e.g., Students, Parents, Teachers).
	* Evaluation Goals: Enter the evaluation goals of the program.
	* Evaluation Method: Select the method used for evaluation (e.g., Survey, Focus Groups, Interviews).
	* Evaluation Frequency: Select the frequency of evaluation (e.g., Monthly, Quarterly, Bi-Annually).
2. On the second page, provide additional details:
	* Form Submission: Select the method of form submission (e.g., Online, Phone, Email).
	* Email: Enter the email address associated with the program.
	* Phone Number: Enter the phone number associated with the program.
	* Date: Enter the date of form completion.
	* Time: Enter the time of form completion.
	* Note: Enter any additional notes or comments.
3. Finally, confirm the form completion date.

## Field-by-Field Explanation

* **Program Title** (`program_title`, text, optional): Enter the title of the program being evaluated.
* **Organization** (`organization`, text, optional): Enter the name of the organization running the program.
* **Program Name** (`program_name`, text, optional): Enter the name of the program.
* **Program Type** (`program_type`, select_multiple, optional): Select the type of program (e.g., School, Nonprofit, Public Health).
* **Target Population** (`target_population`, select_multiple, optional): Select the target population of the program (e.g., Students, Parents, Teachers).
* **Evaluation Goals** (`evaluation_goals`, text, optional): Enter the evaluation goals of the program.
* **Evaluation Method** (`evaluation_method`, select_one, optional): Select the method used for evaluation (e.g., Survey, Focus Groups, Interviews).
* **Evaluation Frequency** (`evaluation_frequency`, select_one, optional): Select the frequency of evaluation (e.g., Monthly, Quarterly, Bi-Annually).
* **Form Submission** (`form_submission`, select_multiple, optional): Select the method of form submission (e.g., Online, Phone, Email).
* **Email** (`email`, email, optional): Enter the email address associated with the program (Format: johndoe@example.com).
* **Phone Number** (`phone_number`, text, optional): Enter the phone number associated with the program (Format: 123 456 7890).
* **Date** (`date`, date, optional): Enter the date of form completion.
* **Time** (`time`, time, optional): Enter the time of form completion.
* **Note** (`note`, note, optional): Enter any additional notes or comments.
* **Form Completion** (`form_completion`, date, optional): Confirm the form completion date.
