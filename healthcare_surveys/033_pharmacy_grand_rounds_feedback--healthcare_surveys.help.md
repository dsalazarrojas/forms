# Pharmacy Grand Rounds Feedback - Help Guide
## Purpose
This form is designed to collect feedback and evaluation results from healthcare professionals who have attended a pharmacy grand rounds session.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct session ID.
2. Enter the session date in the correct format (e.g., 02/02/2022).
3. Enter the session time in the correct format (e.g., 14:00).
4. Enter the session start and end times in numerical format (e.g., 1400 for 2:00 PM).
5. Enter the session location.
6. Select whether the session was well-attended or not.
7. Select whether any outstanding items were discussed during the session.
8. Enter an evaluation score out of 5 to rate the session's quality.
9. Enter any additional feedback or comments about the session.

## Field-by-Field Explanation
- **Session ID**: This is a unique identifier for the session.
	+ Type: number
	+ Required: No
	+ Hint: Not required but helps the organizers to track sessions.
- **Session Date**: The date on which the session took place.
	+ Type: date
	+ Required: No
	+ Hint: Enter the date in the correct format (e.g., 02/02/2022).
- **Session Time**: The time at which the session took place.
	+ Type: time
	+ Required: No
	+ Hint: Enter the time in the correct format (e.g., 14:00).
- **Session Start Time**: The start time of the session.
	+ Type: number
	+ Required: No
	+ Hint: Enter the start time in numerical format (e.g., 1400 for 2:00 PM).
- **Session End Time**: The end time of the session.
	+ Type: number
	+ Required: No
	+ Hint: Enter the end time in numerical format (e.g., 1500 for 3:00 PM).
- **Session Location**: The location where the session took place.
	+ Type: text
	+ Required: No
	+ Hint: Enter the location where the session was held.
- **Session Attendees**: Whether the session was well-attended or not.
	+ Type: select_multiple
	+ Required: Yes
	+ Hint: Select Yes if the session was well-attended, No otherwise.
- **Session Outstanding Items**: Outstanding items or topics that were discussed during the session.
	+ Type: select_multiple
	+ Required: Yes
	+ Hint: Select Yes if any outstanding items were discussed, No otherwise.
- **Evaluation Score**: An evaluation score out of 5, indicating the session's quality.
	+ Type: number
	+ Required: No
	+ Hint: Rate the session's quality out of 5.
- **Feedback**: Any additional feedback or comments about the session.
	+ Type: text
	+ Required: No
	+ Hint: Enter any additional comments or feedback about the session.
