# Radiotherapy Virtual Assistant Survey - Help Guide
## Purpose
This form collects your feedback and opinions about the virtual assistant, to help us improve its performance and better serve you. Your input is valuable to us, and we appreciate your time and effort in filling out this survey.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in your name in the first field.
2. Select how often you use the virtual assistant in the second field.
3. Choose the feature that you find most useful in the third field.
4. In the fourth field, type your feedback about the virtual assistant's user interface.
5. In the fifth field, type your suggestions for improvements to the virtual assistant.
6. Select how likely you are to recommend the virtual assistant to others in the sixth field.
7. Rate the overall experience with the virtual assistant in the seventh field.
8. Choose how satisfied you are with the virtual assistant's response time in the eighth field.
9. If you have experienced any issues with the virtual assistant, select them in the ninth field. (Note: This field is not required, as we aim to resolve any issues that arise.)
10. In the tenth field, select the type of device you use to access the virtual assistant.
11. Choose how you usually access the virtual assistant in the eleventh field.
12. In the twelfth field, type any additional features you would like to see added to the virtual assistant.
13. Finally, in the thirteenth field, provide any additional comments about the virtual assistant.

## Field-by-Field Explanation

### 1. **What is your name**
(Required) This field collects your name for identification purposes.

### 2. **How often do you use the virtual assistant?**
(Required) Please select how often you use the virtual assistant, whether it's:
	+ Once a day
	+ A few times a week
	+ Less than once a week

### 3. **What is the virtual assistant's feature that you find most useful?**
(Not Required) This field allows you to choose one or multiple features that you find most useful, such as:
	+ Providing information on available treatment options
	+ Suggesting treatment options based on your medical history
	+ Offering appointment reminders and scheduling

### 4. **What is your feedback about the virtual assistant's user interface?**
(Required) Please provide your honest feedback about the virtual assistant's user interface. This will help us identify areas for improvement.

### 5. **What would you like to see improved in our virtual assistant?**
(Not Required) Type any suggestions you have for improving the virtual assistant. This is your opportunity to share your thoughts and ideas.

### 6. **How likely are you to recommend the virtual assistant to others?**
(Required) Please select how likely you are to recommend the virtual assistant, whether it's:
	+ Not at all
	+ Somewhat
	+ Very likely
	+ Extremely likely

### 7. **How would you rate the overall experience with the virtual assistant?**
(Required) Rate your overall experience with the virtual assistant, whether it's:
	+ Very poor
	+ Poor
	+ Neutral
	+ Good
	+ Excellent

### 8. **How satisfied are you with the virtual assistant's response time?**
(Required) Choose how satisfied you are with the virtual assistant's response time, whether it's:
	+ Very dissatisfied
	+ Somewhat dissatisfied
	+ Neutral
	+ Somewhat satisfied
	+ Very satisfied

### 9. **Have you experienced any issues with the virtual assistant?**
(Not Required) If you have experienced any issues with the virtual assistant, select them, such as:
	+ Yes, with technical issues
	+ Yes, with content issues
	+ False (if no issues)

### 10. **What type of device do you use to access the virtual assistant?**
(Required) Please select the type of device you use to access the virtual assistant, whether it's:
	+ Smartphone
	+ Tablet
	+ Desktop or laptop

### 11. **How do you usually access the virtual assistant?**
(Required) Choose how you usually access the virtual assistant, whether it's:
	+ Through a web browser
	+ Through an app
	+ Both

### 12. **What features would you like to see added to the virtual assistant?**
(Not Required) Type any additional features you would like to see added to the virtual assistant.

### 13. **Do you have any additional comments about the virtual assistant?**
(Not Required) Provide any additional comments or feedback about the virtual assistant.

### 14. **How can we contact you if we need more information?**
(Not Required) Please provide your contact information, so we can reach out to you if we need further clarification or details.

Note: The fields marked as "Not Required" are optional and are only for users who want to provide additional feedback or comments.
