# Global Health Equity Awareness Survey - Help Guide
## Purpose
This form is designed to collect data on healthcare access, affordability, and quality in a global context to inform policy and resource allocation decisions.

## How To Complete This Form
1. Start by reading the introduction page to understand the purpose and objectives of the survey.
2. Select your demographic information:
	* Choose whether you are male, female, or other.
	* Please select your age range.
3. Answer questions about your healthcare coverage:
	* Do you have health insurance?
	* If yes, please select all options that apply.
	* If no, please indicate "No".
4. Provide information about your medical history:
	* Please note down any relevant medical history.
5. Answer questions about healthcare access:
	* How do you access healthcare services?
	* Please select one option.
6. Answer questions about healthcare cost:
	* What are the costs associated with accessing healthcare services?
	* Please select all options that apply.
7. Answer questions about healthcare funding:
	* Please select a number that represents your response.
8. Answer questions about medical facilities:
	* Do you have access to medical facilities?
	* If yes, please select all options that apply.
9. Answer questions about healthcare accessibility costs:
	* Do healthcare costs limit your access to care?
	* If yes, please select all options that apply.
10. Answer questions about social services:
	* Do you have access to social services?
	* Please select one option.
11. Answer questions about mental health services:
	* Do you have access to mental health services?
	* If yes, please select all options that apply.
12. Answer questions about healthcare worker satisfaction:
	* How satisfied are you with the healthcare workers' service quality?
	* Please select one option.
13. Answer questions about healthcare access:
	* Do you have access to healthcare services?
	* If yes, please select all options that apply.
14. Answer questions about healthcare worker safety:
	* How safe do you feel the healthcare environment is?
	* Please select one option.
