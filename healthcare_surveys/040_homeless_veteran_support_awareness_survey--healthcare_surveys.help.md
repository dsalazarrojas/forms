# Homeless Veteran Support Awareness Survey - Help Guide
## Purpose
This form is a tool for authorized personnel to collect data on the awareness and support needs of homeless veterans they serve. The purpose of this form is to identify the services and resources that are most effective in supporting homeless veterans.

## How To Complete This Form
To complete this form, please follow these steps:

*   Read each question carefully to ensure you understand the information being requested.
*   Complete each section as thoroughly as possible, but only answer questions that are relevant to your experience with the veterans you serve.
*   Enter your contact information so that we can follow up with you if needed.

## Field-by-Field Explanation
### **Introduction**
*   `contact_info`: This field is not required and should only be filled out if you need to provide additional contact information for the survey.
*   `awareness_needs`: This field asks you to indicate if the veterans you serve have specific awareness needs. Please select all that apply.

### **Awareness Needs**
*   **contact_info**: This field is not required and should only be filled out if you need to provide additional contact information for the survey.
*   **awareness_needs**: This field asks you to select whether the veterans you serve have specific awareness needs.
*   **support_services**: This field asks you to describe the support services you provide or have been provided to the veterans you serve.
*   **demographic_info**: This field is not required and should only be filled out if you have demographic information about the veterans you serve.
*   **veteran_info**: This field is not required and should only be filled out if you have specific information about the veteran(s) you are serving.
*   **contact**: This field is not required and should only be filled out if you need to provide additional contact information for the survey.
*   **organization**: This field is not required and should only be filled out if you are affiliated with an organization providing support services to homeless veterans.
*   **email**: This field is not required and should only be filled out if you have an email address you would like to use for follow-up purposes.
