# Care Continuity Improvement Project Registration Form - Help Guide
## Purpose
The Care Continuity Improvement Project Registration Form is used to gather essential details about a care continuity improvement project. This information will be used by the project team to track and manage the project's progress, goals, and timeline.

## How To Complete This Form
1. Enter the project lead's name and email address on the first page.
2. Provide a clear project title, description, and goals on the second page.
3. Select the primary focus area (project category) on the third page.
4. Enter the anticipated start and end dates on the fourth page.
5. List the project team members on the fifth page.
6. Summarize the anticipated outcomes on the sixth page.
7. Authorize the registration by confirming that you are the project lead on the last page.

## Field-by-Field Explanation

* **Project Lead Name** (`project_lead_full_name`, text, required): Enter the name of the primary contact for the project.
* **Email Address** (`project_lead_email_address`, email, required): Enter the email address of the primary contact for the project.
* **Institution/Organization Name** (`institution_organization_name`, text, required): Enter the name of the institution or organization leading the project.
* **Project Title** (`care_continuity_project_title`, text, required): Give your project a clear, concise name that summarizes its scope.
* **Project Description** (`care_continuity_project_description`, text, required): Briefly describe the project's scope and objectives.
* **Project Goals and Objectives** (`care_continuity_project_goals`, text, required): Clearly state the specific, measurable, achievable, relevant, and time-bound (SMART) goals of the project.
* **Project Category** (`care_continuity_project_category`, select_one, required): Select the primary focus area for the project (e.g., Quality Improvement (QI), Patient Safety, Staff Education/Training, Technology Implementation, Process Optimization).
* **Anticipated Start Date** (`project_start_date_initial`, date, required): Enter the expected start date of the project.
* **Anticipated End Date** (`project_end_date_target`, date, required): Enter the expected end date of the project.
* **Project Team Members (List Names)** (`project_team_members_list`, text, optional): List the names of team members, separated by commas.
* **Anticipated Outcomes** (`anticipated_outcomes_summary`, text, required): Summarize the key milestones and expected impact of the project.
* **I authorize the registration of this care continuity project** (`lead_registration_authorization`, select_one, required): Confirm that you are the project lead and authorize the registration of this project.
