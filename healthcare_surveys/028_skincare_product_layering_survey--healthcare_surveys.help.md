# Skincare Product Layering Survey - Help Guide
## Purpose
This form is designed to gather information about your skincare product layering habits, preferences, and challenges. Your input will help us understand how you currently layer skincare products and what benefits you see from this process.

## How To Complete This Form
1. Please answer each question honestly and to the best of your ability.
2. For questions with multiple options, select all that apply.
3. If you have any additional comments or suggestions, please use the "Additional Comments or Suggestions" field.

## Field-by-Field Explanation

* **Introduction to Skincare Product Layering Survey** (`page_1`, `text`, required): This is the introduction to the survey, and you are expected to read it and acknowledge that you understand the purpose of the form.

* **How Frequently Do You Use Skincare Products?** (`page_2`, `select_one`, required): Please select one of the following options: Never, Rarely, Sometimes, Often, or Always. This question helps us understand how frequently you use skincare products.

* **How Often Do You Apply Skincare Products In A Day?** (`page_3`, `number`, required): Please enter a number that indicates how often you apply skincare products in a day.

* **How Often Do You Layer Different Skincare Products In A Session?** (`page_4`, `number`, required): Please enter a number that indicates how often you layer different skincare products in a session.

* **Do You Mix And Match Products From Different Brands?** (`page_5`, `checkbox`, optional): If you select this option, it means you mix and match products from different brands. If not, you stick to products from the same brand.

* **Do You Use Multiple Products From The Same Brand?** (`page_6`, `checkbox`, optional): If you select this option, it means you use multiple products from the same brand. If not, you use single products from a brand.

* **How Long Have You Been Using Skincare Products?** (`page_7`, `number`, required): Please enter a number that indicates how long you have been using skincare products.

* **What Products Do You Use For Cleansing, Toning, And Moisturizing?** (`page_8`, `select_multiple`, required): Please select all products you use for cleansing, toning, and moisturizing.

* **Which Skincare Products Do You Currently Use?** (`page_9`, `select_multiple`, required): Please select all skincare products you are currently using.

* **How Often Do You Find The Products Deliver Satisfactory Results?** (`page_10`, `number`, required): Please enter a number that indicates how often you find the products deliver satisfactory results.

* **How Important Is It To You To Layer Products For Optimal Results?** (`page_11`, `number`, required): Please enter a number that indicates how important it is to you to layer products for optimal results.

* **Which Benefits Do You See When Layering Skincare Products?** (`page_12`, `select_multiple`, required): Please select all benefits you see when layering skincare products.

* **What Layering Method Do You Prefer?** (`page_13`, `select_one`, required): Please select one of the following options: Option A, Option B.

* **How Many Layers Do You Typically Apply At Once?** (`page_14`, `select_one`, optional): If you select this option, please select the number of layers you typically apply at once.

* **What Challenges Do You Face When Layering Skincare Products?** (`page_15`, `select_multiple`, required): Please select all challenges you face when layering skincare products.

* **Do You Experience Any Skin Irritation Or Reactions?** (`page_16`, `checkbox`, optional): If you select this option, it means you experience skin irritation or reactions when layering skincare products. If not, you do not experience any issues.

* **What Benefits Do You See When Layering Skincare Products?** (`page_17`, `select_multiple`, required): Please select all benefits you see when layering skincare products.

* **Additional Comments Or Suggestions?** (`page_18`, `note`, optional): Please use this field to add any additional comments or suggestions you may have.
