# summer_apprenticeship_application_form - Help Guide
## Purpose
The purpose of this form is for applicants to apply for summer camps, select relevant programs and skills, and provide necessary contact information.

## How To Complete This Form
To complete this form, follow the steps outlined above and make sure to fill out all required fields.

## Field-by-Field Explanation
- **Summer Camp Selection** (`summer_apprenticeship`, Select Multiple, required: false): Select the summer camps for which you would like to apply.
  - Please choose up to 3 summer camps that you are interested in applying to.
  - You can select more than one option if you are interested in multiple camps.
- **Applicant Information** (`summer_apprenticeship_applicant`, Note, required: false): This field is for your personal details as an applicant.
  - Please provide a brief description of yourself, your interests, or any relevant information about your background.
  - This field is a text area where you can type in your information, and is not a form field where you can select options.
- **Name** (`name`, Text, required: false): Enter your name as you would like it to be displayed on any communication from the summer camps.
  - Please enter your name in the format "Full Name".
- **Email** (`email`, Email, required: false): Enter a valid email address that the summer camps can use to contact you.
  - Please make sure to enter a real email address that you can be reached at.
- **Phone** (`phone`, Text, required: false): Enter a valid phone number that the summer camps can use to contact you.
  - Please make sure to enter a real phone number that you can be reached at.
- **Summer Camp Programs** (`summer_apprenticeship_programs`, Select Multiple, required: false): Choose the programs you are interested in participating in.
  - Please select up to 3 programs that you are interested in participating in.
  - You can select more than one option if you are interested in multiple programs.
- **Date** (`date`, Date, required: false): Choose a date for which you would be available to participate in the programs you selected.
  - Please choose a date in the format "MM/DD/YY".
- **Time** (`time`, Time, required: false): Choose a time for which you would be available to participate in the programs you selected.
  - Please choose a time in the format "HH:MM".
- **Skills** (`skills`, Select Multiple, required: false): Choose the skills you have that are relevant to the programs you selected.
  - Please select up to 3 skills that you have.
  - You can select more than one option if you have multiple skills.
- **Resume** (`resume`, Text, required: false): Upload a resume or CV that demonstrates your relevant skills and experience.
  - Please make sure to upload a clear and legible copy of your resume.
