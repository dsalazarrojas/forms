# National Design Award Registration Form - Help Guide
## Purpose
The National Design Award Registration Form is a mandatory form for participants who wish to be considered for the award. The form is used to gather information about the participant's project and their registration details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the registration details section with your name and email address.
2. Answer the award category question by selecting "Yes" or "No" depending on whether your project fits the award criteria.
3. Select all the design categories that apply to your project in the design type section.
4. Enter the date when your project was submitted.
5. Upload a relevant file related to your project, if applicable.
6. Provide a brief description of your project.
7. Upload an image of your project, if applicable.
8. Enter your name as the participant.

## Field-by-Field Explanation

### Registration Details
* **Registration Details** (`registration_details`, `text`, optional): This is the first section of the form where you can enter your name and email address. Please fill out this section completely and accurately.

### Award Category
* **Award Category** (`awardCategory`, `select_one`, optional): This question asks whether your project fits the award criteria. Please select "Yes" if your project fits the criteria and "No" otherwise.

### Design Type
* **Design Type** (`designType`, `select_multiple`, optional): This is where you can select all the design categories that apply to your project. Please choose all that apply.

### Submission Date
* **Submission Date** (`submissionDate`, `date`, optional): Enter the date when your project was submitted. This is an important date for the award process.

### Upload File
* **Upload File** (`uploadFile`, `text`, optional): If you have a file related to your project, you can upload it here. This can be a document, image, or other file format. Please ensure the file is relevant to your project.

### Description
* **Description** (`description`, `text`, optional): Provide a brief description of your project. This will help the award committee understand your project better.

### Design Image
* **Design Image** (`designImage`, `text`, optional): If you have an image related to your project, you can upload it here. This can be a screenshot, diagram, or other visual representation. Please ensure the image is relevant to your project.

### Participant Name
* **Participant Name** (`participantName`, `text`, optional): Enter your name as the participant in this form. This is required for registration purposes.

## Tips
* Please ensure that all required fields are filled out correctly before submitting the form.
* Avoid duplication of registration entries. Each participant can only submit one registration entry per project.
* If you are unsure about any field, please contact the award committee for clarification.
