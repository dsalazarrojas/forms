# Sweepstake Entry Form - Help Guide
## Purpose
This guide will help you fill out the Sweepstake Entry Form correctly.

## How To Complete This Form
To complete the form, please follow these steps:

1. Enter your first name in the First Name field.
2. Enter your last name in the Last Name field.
3. Enter your email address in the Email field.
4. Enter your phone number (if you have one) in the Phone field.
5. Select one option for the How did you hear about us field.
6. Select multiple options for the What would you like to win field.
7. (Optional) Enter a date in the Date field.
8. (Optional) Enter a time in the Time field.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, optional): Enter your first name here.
* **Last Name** (`last_name`, text, optional): Enter your last name here.
* **Email** (`email`, email, optional): Enter your email address here. Please make sure it is a valid email address.
* **Phone** (`phone`, text, optional): Enter your phone number here.
* **How did you hear about us** (`select_one`, required): Select the way you heard about this sweepstakes. You can only select one option.
* **What would you like to win** (`select_multiple`, required): Select the prize options you would like to win. You can select multiple options.
* **Date** (`date`, text, optional): Enter a date you are available to win the prize.
* **Time** (`time`, text, optional): Enter a time you are available to win the prize.
 
## Tips
* Please fill out the form accurately and completely.
* Make sure to select only one option for the How did you hear about us field.
* Make sure to select multiple options for the What would you like to win field.
* If you enter the sweepstakes multiple times, please make sure to fill out the same information each time.
