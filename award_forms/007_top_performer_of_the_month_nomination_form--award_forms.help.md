# top_performer_of_the_month_nomination_form - Help Guide
## Purpose
This form is used to nominate an individual as a top performer of the month.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the information for the Nomination Form page.
2. On the Nomination Form page, select "Yes" if the nominee is a top performer or "No" if not.
3. Enter the Nominee's Email address on the Email field.
4. Enter the Nominee's Phone number on the Phone field.
5. Provide your Name on the Nominator field.
6. Enter your Email on the Nominator Email field.
7. Select the Nominee's Department.
8. Enter any Comments about the nomination.
9. Finally, select the Nomination Date.

## Field-by-Field Explanation
* **Nomination Form** (Page 1, Nomination Form, Label: Nomination Form, Required: False, Type: Text, Options: [], Hint: null)
	+ This is the first page of the form.
* **Nominee** (Page 2, Nominee, Label: Nominee, Required: False, Type: Select Multiple, Options: ['Yes', 'No'], Hint: null)
	+ Select "Yes" if the nominee is a top performer or "No" if not.
* **Email** (Page 3, Nominee Email, Label: Email, Required: False, Type: Email, Options: [], Hint: null)
	+ Enter the email address of the nominee.
* **Phone** (Page 4, Nominee Phone, Label: Phone, Required: False, Type: Text, Options: [], Hint: null)
	+ Enter the phone number of the nominee.
* **Nominator** (Page 5, Nominator Name, Label: Nominator, Required: False, Type: Text, Options: [], Hint: null)
	+ Enter your name.
* **Nominator Email** (Page 6, Nominator Email, Label: Nominator Email, Required: False, Type: Email, Options: [], Hint: null)
	+ Enter your email address.
* **Nomination Date** (Page 7, Nomination Date, Label: Nomination Date, Required: False, Type: Date, Options: [], Hint: null)
	+ Select the date of the nomination.
* **Comments** (Page 8, Comments, Label: Comments, Required: False, Type: Note, Options: [], Hint: null)
	+ Enter any comments about the nomination.
* **Nominee Department** (Page 9, Nominee Department, Label: Nominee Department, Required: False, Type: Text, Options: [], Hint: null)
	+ Select the department of the nominee.
