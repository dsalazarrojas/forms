# Nature Award Nomination Form - Help Guide
## Purpose
The Nature Award Nomination Form is designed to collect information for a Nature Award nomination, which recognizes and celebrates outstanding contributions related to nature, conservation, or environmentalism.
## How To Complete This Form
To complete the form, follow these steps:
1. Provide a title for your submission.
2. Enter a description of your submission.
3. Select up to 5 images associated with your submission.
4. Enter the photographer's name, email, and phone number (if applicable).
5. Add any additional details or credits for the images.
6. Select the submission status and category (if applicable).
7. Add any relevant tags or notes.
8. Optionally, specify the entry date and time of the submission.
9. Click "Submit" to complete the form.

## Field-by-Field Explanation
* **Submission Details**: A brief title summarizing the submission. This will be displayed on the nomination page.
* **Submission Images**: Select up to 5 images related to the submission. These will be displayed as part of the nomination.
* **Photographer Name**: Enter the name of the photographer or individual responsible for the submission.
* **Photographer Email**: Enter the email address of the photographer or individual responsible for the submission.
* **Photographer Phone**: Enter the phone number of the photographer or individual responsible for the submission (if applicable).
* **Entry Title**: Enter a title for the entry image. This will be displayed as a caption for the image.
* **Entry Description**: Enter a description for the entry image. This will be displayed as a description for the image.
* **Entry Image URL**: Enter the URL of the entry image (if applicable).
* **Entry Image Title**: Enter a title for the entry image. This will be displayed as a caption for the image.
* **Entry Image Description**: Enter a description for the entry image. This will be displayed as a description for the image.
* **Entry Image Credit**: Enter credits or information about the entry image. This will be displayed as a credit for the image.
* **Entry Image URL Alt**: Enter an alternative URL for the entry image (if applicable).
* **Entry Date**: Select the date of the submission (if applicable).
* **Entry Time**: Select the time of the submission (if applicable).
* **Submission Status**: Select the current status of the submission (Awaiting review, Under review, or Rejected).
* **Submission Category**: Select the category of the submission (if applicable).
* **Submission Tags**: Select relevant tags or keywords for the submission.
* **Submission Notes**: Enter any additional notes or comments about the submission.

This guide should help you understand what each field is for and how to fill it out correctly. If you are still unsure, contact the support team for further assistance.
