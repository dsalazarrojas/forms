# Zone XV Division II Horticulture - Help Guide
## Purpose
This form is used by competition organizers to manage and track Zone XV Division II Horticulture competition entries and related data.

## How To Complete This Form
1. Navigate through each page of the form, starting from "Entry Phase".
2. Fill out the required fields for each page, using the explanations provided below.
3. Review and submit the form once you have completed all required fields.

## Field-by-Field Explanation
* **Entry Phase** (Required): This field is used to select the phase of the competition that the entry belongs to.
* **Entry Name** (Required): Enter the name of the competition entry.
* **Division** (Required, Select One): Select the division of the competition that this entry belongs to.
* **Entry Number** (Required): Enter the unique number of the competition entry.
* **Passing Phase** (Required): This field is used to select the phase through which the entry passed.
* **Passing Criteria** (Required): Enter the criteria through which the entry passed.
* **Placement Phase** (Required, Select Multiple): Select the phase through which the entry placed.
* **Placement Criteria** (Required): Enter the criteria for the entry's placement.
* **Special Awards Phase** (Optional, Select One): Select the phase for special awards.
* **Special Criteria** (Optional): Enter any special criteria for the entry's award.
* **Email Notification** (Required): Enter the email address for competition organizers to contact.
* **Entry Table** (Optional): This field is used to view and edit the entry data in a table format.
* **Judges Email** (Optional): Enter the email address of the judges for the competition.
* **Entry Phase Table** (Optional): This field is used to view and edit the entry phase data in a table format.
* **Passing Table** (Optional): This field is used to view and edit the passing data in a table format.
* **Placement Table** (Optional): This field is used to view and edit the placement data in a table format.
* **Special Awards Table** (Optional): This field is used to view and edit special awards data in a table format.
