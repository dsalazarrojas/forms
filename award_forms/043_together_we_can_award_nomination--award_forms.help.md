# together_we_can_award_nomination - Help Guide
## Purpose
The "Together We Can Award" form is used to collect nominations for the "Together We Can Award", a recognition given to teams or individuals that demonstrate exceptional collaboration and teamwork.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing a brief title for the nomination.
2. Indicate whether the nominee is a team or an individual.
3. Provide a description of the nominee's work or actions that demonstrate their exceptional collaboration and teamwork.
4. Select the relevant category for the nomination.
5. Optionally, provide a Category ID, Form Title, and Form Description for further context.
6. Provide a filename for the form output.
7. If applicable, identify the tool assigned to the nominee.
8. Provide the form ID and version number.

## Field-by-Field Explanation
- **Together We Can Award Nomination** (`form_title`, text, required): Enter a brief title for the nomination.
- **Category** (`category`, select_one, required): Select the category that best represents the nomination (e.g., "Team" or "Individual").
- **Description** (`description`, text, required): Describe the nominee's work or actions that demonstrate exceptional collaboration and teamwork.
- **Category ID** (`category_id`, number, optional): Enter a unique ID for the category selected.
- **Form Category** (`form_category`, text, optional): Enter a category for the form (e.g., "Award Nomination Form").
- **Form Title** (`form_title`, text, optional): Enter a title for the form (e.g., "Together We Can Award Nomination Form").
- **Form Description** (`form_description`, text, optional): Provide a brief description of the form.
- **Form Output Filename** (`form_output_filename`, text, optional): Enter a filename for the form output.
- **Assigned Tool** (`assigned_tool`, text, optional): If applicable, identify the tool assigned to the nominee.
- **Form ID** (`form_id`, number, optional): Enter the ID of the form.
- **Form Version** (`form_version`, text, optional): Enter the version number of the form.
- **Form Last Modified By** (`form_last_modified_by`, text, optional): Enter the name of the user who last modified the form.

## Tips
- Be concise in your answers and provide clear and specific examples where applicable.
- Ensure that the category selected accurately reflects the nomination.
- If providing a description, be sure to clearly explain the nominee's work or actions.
- Review and proofread your answers carefully before submitting the form.
