# Entry Upload Form - Help Guide
## Purpose
This form is used to confirm and document uploaded entries. It helps us to keep track of uploaded files and their details for future reference.

## How To Complete This Form
1. Select the option that accurately describes the uploaded file as either "Yes" or "No" for "entry_upload_form".
2. In the "upload_file" field, provide the actual name of the file that was uploaded.
3. Provide a brief description of the uploaded file in the "entry_title" field.
4. Add a longer description of the uploaded file in the "entry_description" field if necessary.
5. Specify the category of the uploaded file in the "entry_category" field.
6. Enter the date the file was uploaded in the "upload_date" field.
7. Enter the time the file was uploaded in the "upload_time" field.
8. Enter the name of the user who uploaded the file in the "upload_user" field.
9. Enter the IP address of the user who uploaded the file in the "upload_ip" field.
10. Enter the country where the file was uploaded from in the "upload_country" field.
11. Enter the city where the file was uploaded from in the "upload_city" field.
12. Enter the region where the file was uploaded from in the "upload_region" field.
13. Enter the country code of the location where the file was uploaded from in the "upload_country_code" field.
14. Enter the city code of the location where the file was uploaded from in the "upload_city_code" field.
15. Enter the zip code of the location where the file was uploaded from in the "upload_zip" field.
16. Enter the name of the organisation that uploaded the file in the "upload_organisation" field.
17. Enter the code of the organisation that uploaded the file in the "upload_organisation_code" field.
18. Enter the email address of the user who uploaded the file in the "upload_email" field.
19. Enter the phone number of the user who uploaded the file in the "upload_phone" field.
