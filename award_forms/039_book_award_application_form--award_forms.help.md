# Book Award Application Form - Help Guide
## Purpose
The "Book Award Application Form" is used to gather the necessary information for a book to be considered for an award in the book award application process.

## How To Complete This Form
To fill out this form, follow these steps:
- Carefully read the form instructions and all field descriptions.
- Answer all required fields (marked as required: true).
- Ensure all the fields with options select from a specific list select the correct and accurate choice for your book.

## Field-by-Field Explanation

* **Author name** (2): Please enter the full name of the author of the book.
* **Email address** (3): Provide a valid email address for notification purposes.
* **Book title** (4): Enter the exact title of the book you are applying with.
* **Genre** (5): Select the primary genre of the book.
*   - **Fiction**
   - **Non fiction**
   - **Poetry**
   - **Children**
   - **Young adult**
* **Publication year** (6): Enter the year the book was published.
* **Brief synopsis** (7): Provide a short description of the book (less than 200 characters).
* **Previous awards** (8): List any previous awards or recognitions the book has received.
* **Declaration of originality** (9): Confirm that the book is original work, or select "I do not confirm" if it's not.

## Tips

- Double-check your work before submitting to avoid mistakes.
- Ensure all required fields are filled out completely.
- If you have any questions or concerns, contact the support team.
