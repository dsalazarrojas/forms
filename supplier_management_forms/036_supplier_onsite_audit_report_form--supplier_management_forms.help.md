# Supplier Onsite Audit Report Form - Help Guide

## Purpose
The form is used to record information and ratings from onsite audits of suppliers. This information can be used to evaluate supplier performance and identify areas for improvement.

## How To Complete This Form

1. Enter the visit date in the "visit date" field.
2. Enter the visit start and end times in the "visit start time" and "visit end time" fields, respectively.
3. Select the type of visit in the "visit type" field.
4. Select the location(s) visited in the "visit location" field. If multiple locations are visited, separate them with commas.
5. Enter ratings for different categories in the "rating <number>" fields.
6. Enter any findings in the "findings" field.
7. Record any additional notes in the "notes" field.
8. Save and submit the form.

## Field-by-Field Explanation
- **Visit Date** (`visit_date`, date, required): Enter the date of the visit.
- **Visit Start Time** (`visit_start_time`, time, required): Enter the start time of the visit.
- **Visit End Time** (`visit_end_time`, time, required): Enter the end time of the visit.
- **Visit Type** (`visit_type`, select_one, required): Select the type of visit (Onsite Audit, Other).
- **Visit Location** (`visit_location`, select_multiple, required): Select the location(s) visited (Manufacturing, Warehousing, Offices). If multiple locations are selected, separate them with commas.
- **Findings** (`findings`, note, required): Enter any significant findings from the visit.
- **Notes** (`notes`, note, required): Record any additional information about the visit.
- **Rating 1**, **Rating 2**, **Rating 3**, **Rating 4**, **Rating 5**, **Rating 6** (, number, required): Enter ratings for different categories.
