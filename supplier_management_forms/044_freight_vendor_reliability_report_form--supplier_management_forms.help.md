# Freight Vendor Reliability Report Form - Help Guide
## Purpose

The Freight Vendor Reliability Report Form is used to report on the performance of freight vendors. This form helps identify any issues or trends that may be affecting their reliability.

## How To Complete This Form

1. Answer each question truthfully to the best of your ability.
2. Make sure to fill in all required fields, marked with an asterisk \*.
3. Select only one option per multi-select question.
4. If applicable, provide additional comments to explain your answers.

## Field-by-Field Explanation

* **Shipment Details** (id: 8): The unique number of the shipment. Please enter this as it appears on the vendor's records.
* **Shipment Date** (id: 9, `type: date`): The date the shipment was made. Please enter the date using the standard date format (YYYY-MM-DD).
* **Due Date** (id: 10, `type: date`): The date the shipment was due to be delivered. Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Status** (id: 12, `type: select_one`): The current status of the shipment. Select 'Active' if the shipment is currently active, and 'Inactive' if it is not.
* **Ship Type** (id: 13, `type: select_one`): Select 'Yes' if the shipment is a type that requires special handling or attention, and 'No' otherwise.
* **Freight Cost** (id: 14, `type: number`): The cost of the freight. Please enter this as a numerical value.
* **Freight Weight** (id: 15, `type: number`): The weight of the freight. Please enter this as a numerical value.
* **Shipment Value** (id: 16, `type: number`): The value of the shipment. Please enter this as a numerical value.
* **Ship Date 2** (id: 17, `type: date`): The date the shipment was made (second entry). Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Date 3** (id: 18, `type: date`): The date the shipment was made (third entry). Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Date 4** (id: 19, `type: date`): The date the shipment was made (fourth entry). Please enter the date using the standard date format (YYYY-MM-DD). This field is not required.
* **Ship Date 5** (id: 20, `type: date`): The date the shipment was made (fifth entry). Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Date 6** (id: 21, `type: date`): The date the shipment was made (sixth entry). Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Date 7** (id: 22, `type: date`): The date the shipment was made (seventh entry). Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Date 8** (id: 23, `type: date`): The date the shipment was made (eighth entry). Please enter the date using the standard date format (YYYY-MM-DD).
* **Ship Time 2** (id: 24, `type: time`): The time the shipment was made. Please enter this as a time in the 24-hour format (HH:MM).
* **Ship Time 3** (id: 25, `type: time`): The time the shipment was made (second entry). Please enter this as a time in the 24-hour format (HH:MM).

**Tips**

* Make sure to double-check your entries for accuracy.
* If you are unsure about any information, please leave it blank or enter a question mark (\?) to indicate that you are unsure.
* If you have any additional comments or information to provide, please use the 'Additional Comments' field.
