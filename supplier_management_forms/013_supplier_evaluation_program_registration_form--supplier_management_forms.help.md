# supplier_evaluation_program_registration_form - Help Guide
## Purpose
The supplier evaluation program registration form is used to register suppliers for an evaluation program. This form is necessary to collect information about the supplier and their evaluation program details.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the supplier details section (fields 1-5).
2. Fill out the evaluation program details section (fields 6-10).
3. Choose the evaluation cycle and dates for the program (fields 11-12).
4. Select the evaluation frequency and unit (fields 13-14).
5. Choose the evaluation status and provide a comment (fields 15-16).
6. Provide any necessary documents or notes for the program (fields 17-22).

## Field-by-Field Explanation

* **Supplier Details** (`Supplier Details`, text, required): Enter the supplier's details, such as their name, address, city, country, and zip code.
* **Supplier Name** (`supplier_name`, text, required): Enter the supplier's name.
* **Supplier Address** (`supplier_address`, text, required): Enter the supplier's address.
* **Supplier City** (`supplier_city`, text, required): Enter the supplier's city.
* **Supplier Country** (`supplier_country`, text, required): Enter the supplier's country.
* **Supplier Zip** (`supplier_zip`, text, required): Enter the supplier's zip code.
* **Evaluation Program Details** (`Evaluation Program Details`, text, required): Enter the details of the evaluation program.
* **Evaluation Program Description** (`evaluation_program_description`, text, required): Enter a description of the evaluation program.
* **Evaluation Cycle** (`evaluation_cycle`, select_one, required): Choose the evaluation cycle for the program (Evaluation Cycle 1, 2, or 3).
* **Evaluation Start Date** (`evaluation_start_date`, date, required): Choose the start date of the evaluation.
* **Evaluation End Date** (`evaluation_end_date`, date, required): Choose the end date of the evaluation.
* **Evaluation Frequency** (`evaluation_frequency`, number, required): Enter the evaluation frequency (e.g., 1, 2, 3).
* **Evaluation Frequency Unit** (`evaluation_frequency_unit`, text, required): Enter the unit of the evaluation frequency (e.g., days, weeks, months).
* **Evaluation Start Time** (`evaluation_start_time`, time, required): Choose the start time of the evaluation.
* **Evaluation End Time** (`evaluation_end_time`, time, required): Choose the end time of the evaluation.
* **Evaluation Status** (`evaluation_status`, select_multiple, required): Choose the status of the evaluation (Active or Inactive).
* **Evaluation Comment** (`evaluation_comment`, text, required): Enter a comment for the evaluation.
* **Consent** (`consent`, select_one, required): Choose whether or not to participate in the evaluation program (I consent to participate or I do not consent to participate).
* **Supplier Document** (`supplier_document`, text, required): Enter any necessary documents or notes for the supplier.
* **Evaluation Program Documents** (`evaluation_program_documents`, text, required): Enter any necessary documents or notes for the evaluation program.
* **Evaluation Document** (`evaluation_document`, text, required): Enter any necessary documents or notes for the evaluation.
* **Evaluation Program Notes** (`evaluation_program_notes`, text, required): Enter any notes for the evaluation program.
* **Evaluation Program Agreement** (`evaluation_program_agreement`, text, required): Enter any agreement for the evaluation program.
* **Evaluation Program Disclaimer** (`evaluation_program_disclaimer`, text, required): Enter any disclaimer for the evaluation program.
* **Submitted By** (`submitted_by`, text, required): Enter the person submitting the form.
