# Vendor Credential Update Request Form - Help Guide
## Purpose
This form is used to update vendor credentials in the vendor management system. Vendors can use this form to request changes to their existing credentials, such as updates to their status or categories.
## How To Complete This Form
1. Ensure you have permission to complete this form on behalf of the vendor.
2. Fill in the required fields as instructed below.
3. Review and submit the form for review and approval.

## Field-by-Field Explanation

* **Vendor Name (vendor_name)**: This field is used to identify the vendor whose credentials are being updated.
* **Email (email)**: This field is used to verify the vendor's email address.
* **Vendor Status (vendor_status)**: Select the current status of the vendor from the dropdown menu: Active or Inactive.
* **Update Reason (update_reason)**: Describe the reason for the update request.
* **Supporting Documentation (supporting_documentation)**: Provide any additional documentation or evidence to support the update request.
* **Notes (notes)**: Add any additional comments or information to support the update request.
* **Category (category)**: Select the category for the vendor's credentials from the dropdown menu: Hardware, Software, or Service.
* **Sub-Category (sub_category)**: Select the sub-category for the vendor's credentials from the dropdown menu: Yes or No.
* **Vendor Group (vendor_group)**: Select the vendor group for the vendor's credentials from the dropdown menu: Yes or No.
* **Vendor Type (vendor_type)**: Enter the type of vendor being updated.

Please note that some fields are not required, but filling in all relevant fields will ensure that your update request is processed efficiently.
