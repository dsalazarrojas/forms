## Ingredient Origin Confirmation Request Form - Help Guide

## Purpose
The Ingredient Origin Confirmation Request Form is used to confirm the origin of an ingredient, ensuring that suppliers provide accurate information about the ingredients they supply.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the Category of the ingredient.
2. Provide a Description of the ingredient.
3. Enter the Supplier Name and Supplier Email.
4. Enter the Supplier Phone Number.
5. Select the Origin Country and Origin State.
6. Enter the Origin City.
7. Select the Supplier Documentation (if required).
8. Enter the Supplier Notes (if required).
9. Select the Origin Date and Origin Time (if required).
10. Enter the Origin Notes (if required).
11. Enter the Ingredient Origin Confirmation Code.
12. Enter the Ingredient Description.
13. Select the Certification Type and Certification Date (if required).
14. Enter the Certification Number (if required).
15. Select the Supplier Certification Type and Supplier Certification Number (if required).
16. Enter the Ingredient Specifications (if required).
17. Select the Submit option to send the form.

## Field-by-Field Explanation

* **Category**: Choose the category of the ingredient from the dropdown menu.
* **Description**: Enter a detailed description of the ingredient.
* **Ingredient**: Enter the name of the ingredient.
* **Supplier Name**: Enter the name of the supplier.
* **Supplier Email**: Enter the email address of the supplier.
* **Supplier Phone**: Enter the phone number of the supplier.
* **Origin Country**: Select the country of origin from the dropdown menu.
* **Origin State**: Select the state of origin from the dropdown menu.
* **Origin City**: Enter the city of origin.
* **Supplier Documentation**: Select any additional documentation required from the dropdown menu.
* **Supplier Notes**: Enter any additional notes from the supplier.
* **Origin Date**: Enter the date of origin.
* **Origin Time**: Enter the time of origin.
* **Origin Notes**: Enter any additional notes about the origin.
* **Ingredient Origin Confirmation Code**: Enter a confirmation code for the ingredient origin.
* **Ingredient Description**: Enter a detailed description of the ingredient.
* **Certification**: Select the certification type from the dropdown menu.
* **Certification Date**: Enter the date of certification.
* **Certification Number**: Enter the certification number.
* **Supplier Certification**: Select any additional certifications required from the dropdown menu.
* **Supplier Certification Number**: Enter the supplier certification number.
* **Ingredient Specifications**: Enter any additional specifications about the ingredient.
* **Submit**: Select "Submit" to send the form.

Please note that some fields may be optional, depending on the specific requirements of the supplier management process. Ensure you fill out all required fields accurately to avoid any potential issues or delays.
