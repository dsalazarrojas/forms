# Restaurant Supply Chain Audit Form - Help Guide
## Purpose

The Restaurant Supply Chain Audit Form is designed to help you collect data about suppliers' practices, performance, and other relevant information. This form is a tool for auditing and improving the restaurant supply chain management.

## How To Complete This Form

1.  Start by filling in the "Supplier Name" field with the name of the supplier you are auditing.
2.  In the "Supplier Address" field, enter the contact information of the supplier.
3.  If applicable, select relevant information about the supplier's performance from the "Chat" field.
4.  Finally, enter the current date in the "Date" field.
5.  Optionally, enter any relevant information in the "Comments Additional Info" field if you have any further comments or notes about the supplier.

## Field-by-Field Explanation

*   **Supplier Name** (`restaurant_supply_chain_audit_form`): Enter the name of the supplier.
    *   Type: text
    *   Required: true
*   **Supplier Address** (`restaurant_supply_chain_audit_form_supplier_address`): Enter the contact information of the supplier.
    *   Type: text
    *   Required: true
*   **Performance Date** (`restaurant_supply_chain_audit_form_performance_date`): If you want to track performance over time, enter the date of the performance evaluation.
    *   Type: date
    *   Required: false
*   **Receiving Practices** (`restaurant_supply_chain_audit_form_receiving_practices`): Select from the options to describe the supplier's receiving practices.
    *   Type: text
    *   Required: false
*   **Quality Control Procedures** (`restaurant_supply_chain_audit_form_quality_control_procedures`): Enter information about the supplier's quality control procedures.
    *   Type: text
    *   Required: false
*   **Supplier Performance Data** (`restaurant_supply_chain_audit_form_supplier_performance_data`): Enter relevant information about the supplier's performance.
    *   Type: text
    *   Required: false
*   **Faster Follow-up Across Locations** (`restaurant_supply_chain_audit_form_faster_follow_up_across_locations`): Enter relevant information about the supplier's ability to follow up across locations.
    *   Type: text
    *   Required: false
*   **Comments Additional Info** (`restaurant_supply_chain_audit_form_comments_additional_info`): Enter any further comments or notes about the supplier.
    *   Type: text
    *   Required: false
*   **Date** (`restaurant_supply_chain_audit_form_date`): Enter the current date for the audit.
    *   Type: date
    *   Required: true
*   **Time** (`restaurant_supply_chain_audit_form_time`): Enter the time of the audit.
    *   Type: time
    *   Required: false
*   **Chat** (`restaurant_supply_chain_audit_form_chat`): Select from options to describe the supplier's performance and practices.
    *   Type: select_multiple
    *   Required: false
*   **Username** (`restaurant_supply_chain_audit_form_username`): Enter a username or identifier for the audit.
    *   Type: text
    *   Required: true

## Tips

*   Make sure to fill in the "Supplier Name" and "Supplier Address" fields with accurate information.
*   If you're tracking performance over time, make sure to fill in the "Performance Date" field.
*   Be specific and clear when entering information in the "Comments Additional Info" field.
*   Use the "Chat" field to select multiple relevant options.
*   Enter the current date and time in the "Date" and "Time" fields, respectively.
*   Use a unique username or identifier in the "Username" field to track audits.
