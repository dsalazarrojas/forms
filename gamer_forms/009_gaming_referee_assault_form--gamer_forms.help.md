# Gaming Referee Assault Form - Help Guide
## Purpose
The Gaming Referee Assault Form is used to report incidents that occur during gaming events. This form is intended for referees to provide detailed information about the incident, including the date, time, game ID, player names, and any relevant notes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the **Incident Details** section with a brief description of what happened.
2.  Enter the **Date** of the incident using the date field.
3.  Enter the **Time** of the incident using the time field.
4.  Enter the **Game ID** of the incident using the game id field.
5.  Enter the **Player Name** of the player involved in the incident.
6.  Enter the **Opponent Name** of the player involved in the incident.
7.  Enter the **Referee Name** who reported the incident.
8.  Enter the **Game Type** of the game where the incident occurred.
9.  Enter the **Location** where the incident occurred.
10. Enter any **Notes** about the incident.

## Field-by-Field Explanation
*   **Incident Details**: This field is used to provide a brief description of the incident.
    *   **Label:** Incident Details
    *   **Type:** text
    *   **Required:** false
    *   **Hint:** This field is for providing a brief description of the incident.
*   **Date**: This field is used to specify the date of the incident.
    *   **Label:** Date
    *   **Type:** date
    *   **Required:** false
    *   **Hint:** This field should be in the correct format (dd/mm/yyyy).
*   **Time**: This field is used to specify the time of the incident.
    *   **Label:** Time
    *   **Type:** time
    *   **Required:** false
    *   **Hint:** This field should be in the correct format (hh:mm).
*   **Game ID**: This field is used to identify the game in which the incident occurred.
    *   **Label:** Game ID
    *   **Type:** number
    *   **Required:** false
    *   **Hint:** Enter the game ID number.
*   **Player Name**: This field is used to enter the name of the player involved in the incident.
    *   **Label:** Player Name
    *   **Type:** text
    *   **Required:** false
    *   **Hint:** Enter the name of the player who was involved in the incident.
*   **Opponent Name**: This field is used to enter the name of the player involved in the incident.
    *   **Label:** Opponent Name
    *   **Type:** text
    *   **Required:** false
    *   **Hint:** Enter the name of the opponent player who was involved in the incident.
*   **Referee Name**: This field is used to enter the name of the referee who reported the incident.
    *   **Label:** Referee Name
    *   **Type:** text
    *   **Required:** false
    *   **Hint:** Enter the name of the referee who reported the incident.
*   **Game Type**: This field is used to identify the type of game where the incident occurred.
    *   **Label:** Game Type
    *   **Type:** text
    *   **Required:** false
    *   **Hint:** Enter the type of game that was being played when the incident occurred.
*   **Location**: This field is used to specify the location of the incident.
    *   **Label:** Location
    *   **Type:** text
    *   **Required:** false
    *   **Hint:** Enter the location where the incident occurred.
*   **Notes**: This field is for any additional comments or information about the incident.
    *   **Label:** Notes
    *   **Type:** note
    *   **Required:** false
    *   **Hint:** Enter any additional comments or information about the incident.

## Tips
*   Be as detailed as possible in the **Incident Details** field.
*   Enter the date and time in the correct format.
*   Enter the game ID number.
*   Enter the player and opponent names correctly.
*   Enter the referee name correctly.
*   Enter the game type and location correctly.
*   Enter any additional comments or information in the **Notes** field.
