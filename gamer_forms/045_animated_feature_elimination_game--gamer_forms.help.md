# Animated Feature Elimination Game - Help Guide
## Purpose
This form is designed to collect demographic and game engagement information from users participating in an Animated Feature Elimination Game.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Name** in the text field.
2. Enter your **Email Address** for notifications.
3. Select your **Age Group** from the dropdown menu.
4. Choose the **Current Round** of the game that you're participating in.
5. If you have a specific **Matchup Number**, fill it in.
6. Select the **Option A** and **Option B** animated features you're evaluating.
7. Choose your **Vote** between **Option A** and **Option B**.
8. Optionally, rate both **Option A** and **Option B** on a 1-10 scale.
9. Select all the elements you **Loved About Option A** and **Option B** (e.g., Animation Quality, Story, Characters, etc.).
10. Identify what you think **Option A** and **Option B** could **Improve** on.
11. If applicable, mention your **All-Time Favorite Animated Feature**.
12. Choose your **Favorite Animation Studio**.
13. Select your **Preferred Animation Era** (classic, renaissance, or modern).
14. Specify how often you **Watch Animated Features** (weekly, monthly, or rarely).
15. Select how you heard about this **Game**.
16. Choose your level of **Game Engagement** (engaged, interested, or not).
17. Decide if you'd like to **Participate in Future Rounds**.
18. Select your preferred **Notification Method** for game updates.
19. If you have suggestions for future game **Features**, list them.
20. Provide any **Feedback on the Game Format**.
21. Optionally, choose if you'd like your vote to be **Shared Publicly**.
22. Join our **Community Discussion Forum** or chat group.
23. Add any **Additional Comments** about the game.

## Field-by-Field Explanation
- **Your Name** (`participant_name`, text, required): Enter your full name or username.
- **Email Address** (`email`, email, required): Enter your email address for notifications.
- **Age Group** (`age_group`, select_one, required): Select your age group from the dropdown menu.
- **Current Round** (`game_round`, select_one, required): Choose the current round you're participating in.
- **Matchup Number** (`matchup_number`, text, optional): If applicable, enter the matchup number.
- **Option A** (`feature_option_a`, text, required): Select the first animated feature in the matchup.
- **Option B** (`feature_option_b`, text, required): Select the second animated feature in the matchup.
- **Your Vote** (`your_vote`, select_one, required): Choose between **Option A** and **Option B**.
- **Why Did You Vote This Way** (`vote_reason`, text, optional): Briefly explain your vote.
- **Rate Option A** (`rating_option_a`, select_one, optional): Rate **Option A** on a 1-10 scale.
- **Rate Option B** (`rating_option_b`, select_one, optional): Rate **Option B** on a 1-10 scale.
- **What Did You Love About Option A** (`favorite_elements_a`, select_multiple, optional): Select all the elements you loved about **Option A** (e.g., animation, story, characters).
- **What Did You Love About Option B** (`favorite_elements_b`, select_multiple, optional): Select all the elements you loved about **Option B** (e.g., animation, story, characters).
- **What Could Option A Improve** (`least_favorite_a`, select_multiple, optional): Select all the elements you think **Option A** could improve on.
- **What Could Option B Improve** (`least_favorite_b`, select_multiple, optional): Select all the elements you think **Option B** could improve on.
- **All-Time Favorite Animated Feature** (`overall_favorite`, text, optional): If you have a favorite animated feature that's not part of the game, mention it.
- **Favorite Animation Studio** (`favorite_studio`, select_one, optional): Choose your favorite animation studio.
- **Preferred Animation Era** (`preferred_era`, select_one, optional): Select your preferred animation era.
- **How Often Do You Watch Animated Features** (`viewing_frequency`, select_one, required): Select how often you watch animated features.
- **How Did You Hear About This Game** (`game_engagement`, select_one, optional): Select how you heard about this game.
- **Would You Like to Participate in Future Rounds** (`participate_future`, select_one, required): Choose if you'd like to participate in future rounds.
- **Notification Preference** (`notification_preference`, select_one, required): Select your preferred notification method.
- **Would You Like to Suggest Features for Future Games** (`suggest_features`, select_one, optional): If you have suggestions, let us know.
- **Feature Suggestions** (`feature_suggestions`, text, optional): List your suggestions for future game features.
- **Any Feedback on the Game Format** (`game_feedback`, text, optional): Provide any feedback on the game format.
- **May We Share Your Vote Publicly** (`share_results`, select_one, required): Choose if you'd like your vote to be shared publicly.
- **Join Our Community Discussion** (`community_participation`, select_one, optional): If you'd like to join our community discussion forum or chat group.
- **Additional Comments** (`additional_comments`, text, optional): Add any additional comments about the game.
