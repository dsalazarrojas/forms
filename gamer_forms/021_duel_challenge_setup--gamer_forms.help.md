# Duel Challenge Setup - Help Guide

## Purpose
This form is designed to collect information for setting up a duel challenge in a competitive gaming or esports context. The goal is to provide a standardized way to gather data for participants, type of duel, and challenge details. This form will help in organizing and managing duel challenges efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your **Participant Details** in the first field. This includes any relevant information about the participant.
2. Choose the **Duel Type** from the available options (Type A, Type B, or Type C). Select the type of duel that best describes the challenge.
3. Enter **Duel Details** in the text field. Provide any additional information about the duel, such as rules or specific requirements.
4. You may also add **Rules** to the form if necessary, using the text area.
5. Set the **Timing** for the duel using the time input field.
6. Enter your **Submit** in the text field. This is where you'll enter any additional comments or remarks.
7. Enter your **Challenge ID** and **Challenge Name** in the text fields, which seem to be used for internal tracking purposes.

## Field-by-Field Explanation

* **Participant Details**: Enter the name and any other relevant details of the participant. This field is optional, and you can enter any information you think is necessary.
* **Duel Type**: Select the type of duel that best fits the challenge. This field will help in categorizing and organizing the duel data.
* **Duel Details**: Enter any additional details about the duel, such as rules, requirements, or specific conditions.
* **Rules**: If you need to add additional rules or requirements for the duel, use this text area.
* **Timing**: Set the timing for the duel using the time input field. This is essential for scheduling purposes.
* **Submit**: Enter any additional comments or remarks about the duel submission. This is not required, but it's a good place to leave feedback or suggestions.
* **Challenge ID**: Enter the unique ID for the challenge, which will be used internally to track the duel.
* **Challenge Name**: Enter the name of the challenge, which will help in identifying and referencing the duel.

## Tips
* Make sure to enter accurate and clear information in each field to ensure proper tracking and organization of the duel.
* If you're unsure about any field, you can always reach out to us at form@gic.mx for assistance.
