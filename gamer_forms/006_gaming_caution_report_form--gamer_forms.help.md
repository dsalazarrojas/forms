# gaming_caution_report_form - Help Guide
## Purpose
The gaming_caution_report_form is a tool used to report gaming-related issues or concerns to the platform's moderators.

## How To Complete This Form
To submit a report, follow the steps outlined above.

## Field-by-Field Explanation

* **Player ID** (`player_id`, number, *): Enter the Player ID of the user involved in the incident.
* **Player Name** (`player_name`, text, *): Enter the Player Name, if available.
* **Incident Type** (`incident_type`, select_one): Choose the type of incident you're reporting (e.g., harassment, cheating, etc.).
* **Description** (`description`, text): Provide a detailed description of the incident.
* **Screenshot URL** (`screenshot_url`, text): If relevant, share a Screenshot URL for evidence.
* **Report Reason** (`report_reason`, text): Select the reason for reporting the issue.
* **Player Message** (`player_message`, text): If desired, add a Player Message.
* **Moderator Message** (`moderator_message`, text): If desired, add a Moderator Message.
* **Date Reported** (`date_reported`, date, *): Set the Date the issue was reported.
* **Time Reported** (`time_reported`, time, *): Set the Time the issue was reported.
* **Report Status** (`report_status`, select_one): Specify the Report Status (resolved or pending).
* **Close Date** (`close_date`, date): Optionally, provide a Close Date.
* **Moderator Name** (`moderator_name`, text): Optionally, specify the Moderator Name.
* **Moderator Note** (`moderator_note`, text): Optionally, provide a Moderator Note.
* **Report ID** (`report_id`, number, *): Enter the Report ID, if available.
* **Assigned Tool** (`assigned_tool`, text): Optionally, specify the tool or user assigned to handle the issue.
* **Assigned User** (`assigned_user`, text): Optionally, specify the user assigned to handle the issue.
* **Close Reason** (`close_reason`, text): Optionally, provide the Close Reason.
* **Resolved** (`resolved`, select_one): Indicate if the issue has been resolved.
* **Created At** (`created_at`, date): Specify the time the issue was created.
* **Updated At** (`updated_at`, date): Specify the time the report was last updated.
* **Deleted At** (`deleted_at`, date): Specify the time the report was deleted, if applicable.
* **Created By** (`created_by`, text): Specify the user who created the report.
* **Updated By** (`updated_by`, text): Specify the user who last updated the report.
* **Deleted By** (`deleted_by`, text): Specify the user who deleted the report, if applicable.

## Tips
When in doubt, refer to the platform's community guidelines and terms of service for guidance on what constitutes acceptable behavior. If you're unsure about a specific field, don't hesitate to ask the moderators for assistance.
