# Game Console Quality Assessment - Help Guide
## Purpose
The Game Console Quality Assessment form is designed to evaluate the quality of a game console, capturing its condition, recorded status, accessories, functionality, and other relevant details. This form helps store staff or inventory managers assess the console's value and make informed decisions about its sale, storage, or disposal.

## How To Complete This Form

1. Review the console and its accessories to ensure you have all the necessary information.
2. Complete the form by selecting the relevant options for each field.
3. Use the notes fields to add any additional comments or explanations for your assessment.

## Field-by-Field Explanation

### Console Condition
* **Console Condition** (`console_condition`, text): Describe the overall condition of the console, such as "excellent," "good," or "poor."

### Recorded
* **Recorded** (`recorded`, select_multiple): Select one or more of the following:
	+ Broken
	+ Functional
	+ Not Recorded

### Accessories
* **Accessories** (`accessories`, select_multiple): Select one or more of the following:
	+ None
	+ Some
	+ All

### Functionality
* **Functionality** (`functionality`, date): Select a date to indicate when the console's functionality was last checked.

### Console Accessories
* **Console Accessories** (`console_accessories`, select_one): Select one of the following:
	+ None
	+ All
	+ Some

### Capture Date
* **Capture Date** (`capture_date`, date): Enter the date you assessed the console.

### Capture Time
* **Capture Time** (`capture_time`, time): Enter the time you assessed the console.

### Quality Rating
* **Quality Rating** (`quality_rating`, number): Enter a score from 1 to 5 to indicate the console's overall quality.

### Store ID
* **Store ID** (`store_id`, number): Enter the store's unique ID for the console.

### Recorded By
* **Recorded By** (`recorded_by`, text): Enter the name of the person who recorded the console.

### Console Type
* **Console Type** (`console_type`, text): Enter the type of console, such as "PS4" or "Xbox."

### Condition Score
* **Condition Score** (`condition_score`, number): Enter a score from 1 to 5 to indicate the console's condition.

### Functionality Score
* **Functionality Score** (`functionality_score`, number): Enter a score from 1 to 5 to indicate the console's functionality.

### Accessories Score
* **Accessories Score** (`accessories_score`, number): Enter a score from 1 to 5 to indicate the console's accessories.

### Console Condition Note
* **Console Condition Note** (`console_condition_note`, text): Add any additional comments about the console's condition.

### Recorded Note
* **Recorded Note** (`recorded_note`, text): Add any additional comments about the recording process.

### Accessories Note
* **Accessories Note** (`accessories_note`, text): Add any additional comments about the console's accessories.

### Functionality Note
* **Functionality Note** (`functionality_note`, text): Add any additional comments about the console's functionality.

### Console Accessories Note
* **Console Accessories Note** (`console_accessories_note`, text): Add any additional comments about the console's accessories.

### Store Note
* **Store Note** (`store_note`, text): Add any additional comments about the store's experience with the console.

### Condition Score Note
* **Condition Score Note** (`condition_score_note`, text): Add any additional comments about the console's condition score.

### Functionality Score Note
* **Functionality Score Note** (`functionality_score_note`, text): Add any additional comments about the console's functionality score.

### Accessories Score Note
* **Accessories Score Note** (`accessories_score_note`, text): Add any additional comments about the console's accessories score.

### Quality Rating Note
* **Quality Rating Note** (`quality_rating_note`, text): Add any additional comments about the console's quality rating.
