# Game Developer Asset Support Request Form - Help Guide

## Purpose
This form is designed to collect information from game developers about their asset support requests. It helps our team quickly identify and address issues related to game assets, such as audio, video, images, text, models, or scenes. By filling out this form, you can report problems with your game's assets and we will do our best to assist you.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose whether this is a game development asset support request (`Yes` or `No`). If you are reporting a problem with an asset related to game development, select `Yes`. Otherwise, select `No`.
2. Enter the specific game developer asset that you are experiencing issues with.
3. Provide a detailed description of the issue you are experiencing with the asset.
4. Select the type of asset that is affected (e.g., Audio, Video, Image, Text, Model, Scene).
5. Specify the location of the asset (e.g., on our servers, on your local machine, etc.).
6. Enter the name of the game associated with the asset.
7. Enter the version of the asset that is causing the issue.
8. Choose the status of the asset (e.g., Available, Not Available, Unknown).
9. Provide additional details about the issue.
10. Explain the reason for the asset status.

## Field-by-Field Explanation

* **Game Developer Asset** (`game_developer_asset`, text, optional): This field is where you report the specific game developer asset that is experiencing issues. Be as specific as possible, including the asset's version and location.
* **Issue Description** (`issue_description`, text, optional): Provide a detailed description of the issue you are experiencing with the asset. This will help us understand the problem and provide better support.
* **Asset Type** (`asset_type`, select_one, optional): Select the type of asset that is affected (e.g., Audio, Video, Image, Text, Model, Scene).
* **Asset Location** (`asset_location`, text, optional): Specify where the asset is located (e.g., on our servers, on your local machine, etc.).
* **Game Name** (`game_name`, text, optional): Enter the name of the game associated with the asset.
* **Asset Version** (`asset_version`, text, optional): Enter the version of the asset that is causing the issue.
* **Issue Date** (`issue_date`, date, optional): Enter the date when the issue started or was noticed.
* **Asset Status** (`asset_status`, select_one, optional): Choose the status of the asset (e.g., Available, Not Available, Unknown).
* **Issue Description Details** (`issue_description_details`, text, optional): Provide additional details about the issue.
* **Asset Status Reason** (`asset_status_reason`, text, optional): Explain the reason for the asset status.
* **Form Response** (`form_response`, select_multiple, optional): Choose whether this is a game development asset support request (Yes or No). This is the first field in the form and will determine what options are available for the rest of the fields.
* **Game Developer** (`game_developer`, text, optional): Enter the name of the game developer associated with the asset.
