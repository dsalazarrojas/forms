# Character Search And Filter Form - Help Guide
## Purpose
The Character Search And Filter Form is designed to help you find characters from a large collection of characters based on various criteria. This form allows you to search for characters by name, filter them by attributes such as gender, role, alignment, and more, and sort the results by various criteria.

## How To Complete This Form
1. Enter a character name or partial name in the "Search by Name" field.
2. Select one or more filters from the following categories:
	* Filter by Gender: Choose a gender identity to match characters with.
	* Filter by Role: Choose a primary story role to match characters with.
	* Filter by Alignment: Choose a moral alignment to match characters with.
	* Filter by Class: Choose a character class or profession to match characters with.
	* Filter by Race: Choose a species or ancestry to match characters with.
	* Filter by Age Range: Choose a character age category to match characters with.
	* Filter by Status: Choose a current story status to match characters with.
3. Select one or more abilities from the "Filter by Abilities" field.
4. Select one or more personality traits from the "Filter by Personality Traits" field.
5. Select one or more story arcs from the "Filter by Story Arc" field.
6. Choose how you want the results to be sorted in the "Sort Results By" field.
7. Choose how many results you want to display per page in the "Results per Page" field.

## Field-by-Field Explanation
* **Search by Name** (search_query, text, optional): Enter a character name or partial name to search for characters. This field is not required, and you can leave it blank to view all characters.
* **Filter by Gender** (character_gender, select_one, optional): Select a gender identity to match characters with. Options: Any, Male, Female, Non-binary, Other.
* **Filter by Role** (character_role, select_one, optional): Select a primary story role to match characters with. Options: Any, Protagonist, Antagonist, Supporting, Minor, Cameo.
* **Filter by Alignment** (character_alignment, select_one, optional): Select a moral alignment to match characters with. Options: Any, Good, Neutral, Evil, Unknown.
* **Filter by Class** (character_class, select_one, optional): Select a character class or profession to match characters with. Options: Any, Warrior, Mage, Rogue, Cleric, Ranger, Noble, Commoner.
* **Filter by Race** (character_race, select_one, optional): Select a species or ancestry to match characters with. Options: Any, Human, Elf, Dwarf, Orc, Halfling, Dragonborn, Other.
* **Filter by Age Range** (age_range, select_one, optional): Select a character age category to match characters with. Options: Any, Child, Teenager, Young adult, Adult, Middle aged, Elderly.
* **Filter by Status** (status_filter, select_one, optional): Select a current story status to match characters with. Options: Any, Alive, Deceased, Missing, Unknown.
* **Filter by Abilities** (abilities_filter, select_multiple, optional): Select one or more special powers or skills to match characters with. Options: Magic, Combat, Stealth, Leadership, Healing, Technology, Persuasion, None.
* **Filter by Personality Traits** (personality_traits, select_multiple, optional): Select one or more personality traits to match characters with. Options: Brave, Intelligent, Loyal, Cunning, Compassionate, Ambitious, Rebellious, Wise.
* **Filter by Story Arc** (story_arc, select_one, optional): Select one or more story arcs to match characters with. Options: Any, Arc 1, Arc 2, Arc 3, Arc 4, Arc 5, Multiple arcs.
* **Sort Results By** (sort_by, select_one, optional): Choose how you want the results to be sorted. Options: Name ascending, Name descending, Importance, First appearance, Last appearance, Popularity.
* **Results per Page** (results_per_page, select_one, optional): Choose how many results you want to display per page. Options: 10, 25, 50, 100.
