# Trading Card Organization Checklist - Help Guide
## Purpose
The Trading Card Organization Checklist is a comprehensive form used to evaluate and track the condition and storage of your trading card collection.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each card in your collection and assess its condition using the condition scale provided.
2. Choose the storage method that best describes how you store each card.
3. Set a storage goal for your cards, if applicable.
4. Record any notes or comments related to each card.
5. Evaluate the storage scale for each card based on how well it is stored.
6. Provide any additional notes or comments as needed.

## Field-by-Field Explanation
- **Card Condition** (`card_condition`): Assess the condition of each card using the provided scale: Near Mint, Lightly Played, Moderately Played, Heavily Played, or Damaged. 
  - Select all conditions that apply.
  - If none of the options are suitable, provide a brief explanation in `condition_scale_other`.
- **Storage Method** (`storage_method`): Choose the method you use to store each card: Box Top-Loader, Single-Loader, Top Loader, Loose in Booster Box, Loose in Deckbox, or Loose.
- **Storage Goal** (`card_storage_goal`): Set a goal for how you would like to store each card, if applicable. For example, "Store all cards in Top Loaders".
- **Card Storage Evaluator** (`storage_evaluations`): Record any notes or comments about the storage of each card.
- **Notes** (`notes`): Record any additional notes or comments about each card.
- **Card Count** (`card_count`): Record the number of copies of each card you have.
- **Condition Scale** (`condition_scale`): Select the condition scale that best describes the condition of each card: FNM, Beckon, CGC, CGC:Beckon, or None.
- **Condition Scale Other** (`condition_scale_other`): If none of the provided condition scales are suitable, provide a brief explanation here.
- **Storage Scale** (`storage_scale`): Choose the storage scale that best describes how well each card is stored: FNM, CGC, CGC:Beckon, or None.
- **Storage Scale Other** (`storage_scale_other`): If none of the provided storage scales are suitable, provide a brief explanation here.
- **Notes** (`notes`): Record any additional notes or comments about each card.

## Tips
- Be as accurate as possible when assessing the condition and storage of each card.
- Use the provided scales to guide your evaluation, but feel free to provide additional explanations if needed.
- This form is designed to be a comprehensive checklist, so complete as much as you can to get the most out of it.
