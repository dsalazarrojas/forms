# Video Game Inventory List - Help Guide
## Purpose
The Video Game Inventory List form is designed to collect information about video games, including their titles, release dates, ratings, console types, statuses, conditions, playtime, notes, retailers, and user information. This form is used to gather data about your video game collection and help you manage your inventory.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the game in the Game Title field.
2. Select the release date of the game from the calendar icon or enter it manually.
3. Select the game's rating from the rating scale.
4. Choose the console type from the dropdown list.
5. Select the game status from the dropdown list.
6. Choose the game condition from the dropdown list.
7. Enter the amount of playtime the game has been used for in the Game Playtime field.
8. Enter any additional notes about the game in the Game Notes field.
9. Choose the retailer where the game was purchased from the dropdown list.
10. Enter your name in the User Name field.
11. Enter your email in the User Email field.
12. Enter your phone number in the User Phone field.
13. Enter your address in the User Address field.

## Field-by-Field Explanation

* **Game Title** (video_game_inventory_list_form_title, Text, Optional): Enter the title of the game. This field should match the game's official title as it appears on the packaging or in the game's metadata.
* **Release Date** (game_release_date, Date, Optional): Select the release date of the game from the calendar icon or enter it manually. This field is used to record the game's release date.
* **Game Rating** (game_rating, Number, Optional): Select the game's rating from the rating scale. This field is used to record the game's rating.
* **Console Type** (console_type, Select One, Optional): Choose the console type from the dropdown list. This field is used to record the type of console the game is played on.
* **Game Status** (game_status, Select Multiple, Optional): Select the game's status from the dropdown list. This field is used to record the game's status (e.g. new, used, collectible, etc.).
* **Game Condition** (game_condition, Select Multiple, Optional): Choose the game's condition from the dropdown list. This field is used to record the game's condition (e.g. mint, used, damaged, etc.).
* **Game Playtime** (game_playtime, Time, Optional): Enter the amount of playtime the game has been used for. This field is used to record the game's playtime.
* **Game Notes** (game_notes, Note, Optional): Enter any additional notes about the game. This field is used to record any additional information about the game.
* **Game Retailer** (game_retailer, Select One, Optional): Choose the retailer where the game was purchased from the dropdown list. This field is used to record the retailer where the game was bought.
* **User Name** (user_name, Text, Optional): Enter your name. This field is used to record your name.
* **User Email** (user_email, Email, Optional): Enter your email. This field is used to record your email.
* **User Phone** (user_phone, Text, Optional): Enter your phone number. This field is used to record your phone number.
* **User Address** (user_address, Text, Optional): Enter your address. This field is used to record your address.

## Tips

* Make sure to enter accurate and up-to-date information about the game.
* Double-check the fields before submitting the form.
* Use the dropdown lists to select options for fields with multiple options.
* Enter your information accurately to ensure we can contact you about your game.
