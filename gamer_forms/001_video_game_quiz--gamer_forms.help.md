# video_game_quiz - Help Guide
## Purpose
This form is designed to collect information about video games, including their genre, title, release date, developer, and other relevant details. This information will help in understanding gamer preferences and behavior.

## How To Complete This Form
1. Select the game genre from the options provided.
2. Enter the game title.
3. Enter the release date of the game.
4. Select the game type (2D, 3D, puzzle, etc.).
5. Choose the player type (solo, multi-player, online, offline).
6. Select the player level (easy, medium, hard).
7. Choose the game language (English, Japanese, French, etc.).
8. Select the game platform (PC, Console, Mobile, Handheld).
9. Enter the game publisher.
10. Enter the game genre subcategory (optional).
11. Select the game rating (ESRB, PEGI, USK).
12. Choose the game age group (0-3, 4-6, 7-10, 11-13).
13. Select the game category (Adventure, Strategy, Puzzle, etc.).
14. Choose the player gender (Male, Female, Other).
15. Select the game rating ages (E - 6, E10+ - 10, E11 - 11, etc.).
16. Enter the player age (optional).
17. Enter the game price range (10 - 50, 50 - 100, 100-500).
18. Enter the minimum game price.
19. Enter the maximum game price.
20. Enter the game rating (optional).
21. Enter the game language ID (optional).
22. Enter the game platform ID (optional).
23. Enter the game publisher ID (optional).

## Field-by-Field Explanation

* **Game Genre** (`game_genre`, `select_one`): Select the genre of the game (action, adventure, role-playing, etc.).
* **Game Title** (`game_title`, `text`): Enter the title of the game.
* **Release Date** (`release_date`, `date`): Enter the release date of the game.
* **Developer** (`developer`, `text`): Enter the game developer's name.
* **Game Type** (`game_type`, `select_multiple`): Select the type of game (2D, 3D, puzzle, etc.).
* **Player Type** (`player_type`, `select_one`): Choose the player type (solo, multi-player, online, offline).
* **Player Level** (`player_level`, `select_multiple`): Select the player level (easy, medium, hard).
* **Game Language** (`game_language`, `select_one`): Choose the game language (English, Japanese, French, etc.).
* **Game Platform** (`game_platform`, `select_multiple`): Select the game platform (PC, Console, Mobile, Handheld).
* **Game Publisher** (`game_publisher`, `text`): Enter the game publisher's name.
* **Game Genre Subcategory** (`game_genre_sub`, `text`): Enter the subcategory of the game genre (optional).
* **Game Rating** (`game_rating`, `select_one`): Select the game rating (ESRB, PEGI, USK).
* **Game Age Group** (`game_age_group`, `select_multiple`): Choose the game age group (0-3, 4-6, 7-10, 11-13).
* **Game Category** (`game_category`, `select_multiple`): Select the game category (Adventure, Strategy, Puzzle, etc.).
* **Player Gender** (`player_gender`, `select_one`): Choose the player gender (Male, Female, Other).
* **Game Rating Ages** (`game_rating_ages`, `select_one`): Select the game rating ages (E - 6, E10+ - 10, E11 - 11, etc.).
* **Player Age** (`player_age`, `number`): Enter the player age (optional).
* **Game Price Range** (`game_price_range`, `select_multiple`): Select the game price range (10 - 50, 50 - 100, 100-500).
* **Game Price Min** (`game_price_min`, `number`): Enter the minimum game price.
* **Game Price Max** (`game_price_max`, `number`): Enter the maximum game price.
* **Game Rating** (`game_rating`, `number`): Enter the game rating (optional).
* **Game Language ID** (`game_language_id`, `text`): Enter the game language ID (optional).
* **Game Platform ID** (`game_platform_id`, `text`): Enter the game platform ID (optional).
* **Game Publisher ID** (`game_publisher_id`, `text`): Enter the game publisher ID (optional).

## Tips
* Please fill out the form carefully, ensuring that all fields are accurate.
