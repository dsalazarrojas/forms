# game_character_demo_consent_form - Help Guide
## Purpose
The game_character_demo_consent_form is used to gather necessary details and approvals for demonstration or showcase events.
## How To Complete This Form
To complete the form, follow these steps:
1. Fill in the required fields: * Creator Details, Demo Usage, Creator Signature, Reviewer Signature, and Date Reviewed.
2. Select the relevant options for: * Event Details, Permission Level, and Event Organizer.
## Field-by-Field Explanation
* **Creator Details**: Provide the name and contact information of the creator of the game content.
* **Event Details**: Describe the event where the demo or showcase will take place, including any relevant information such as date, time, and location.
* **Permission Level**: Choose whether the event will be *Public*, *Private*, or *Restricted*.
* **Demo Usage**: Select all applicable uses for the demo or showcase (e.g., *Events*, *Showcases*, *Development Projects*, *Online Presence*).
* **Additional Permission Notes**: Provide any additional information or notes regarding the permission level.
* **Creator Signature**: Sign and date the form to indicate agreement with the terms and conditions.
* **Reviewer Signature**: Sign and date the form to indicate approval of the terms and conditions.
* **Date Reviewed**: Record the date the reviewer reviewed the form.
* **Event Organizer**: Check if the event is being organized by an external party.
* **Reviewer Signature**: This field is required to be signed by the reviewer to approve the terms and conditions.
* **Date Reviewed**: Record the date the reviewer reviewed the form, which is also a required field.
* **Event Organizer**: Select *True* if the event is being organized by an external party, *False* if it is not, or *Not Applicable* if it doesn't apply.
## Tips
* Please review each field carefully to ensure accuracy and completeness.
* The form is designed to be used for demonstration or showcase events, so ensure the selected options align with this purpose.
* If you are unsure about any field, please consult with the relevant authorities or contacts.
