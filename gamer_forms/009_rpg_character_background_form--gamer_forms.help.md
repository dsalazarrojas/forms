# RPG Character Background Form - Help Guide
## Purpose
The **RPG Character Background Form** is used to collect character background information and campaign details for a role-playing game.

## How To Complete This Form
1. Fill in the character's name in the **character_name** field.
2. Choose the campaign type from the **type** select menu.
3. Select the character's class and other relevant information in the **character_class**, **character_race**, and **character_alignment** select menus.
4. Enter the character's age and gender in the **character_age** and **character_gender** fields.
5. If desired, upload an image for the character's background in the **background_image** field.
6. Add any additional notes about the character or campaign in the **background_note**, **campaign_notes**, and **game_master_notes** fields.
7. Optionally, fill in the **player_id**, **player_name**, **game_master_id**, and **game_master_name** fields for associated player and game master data.

## Field-by-Field Explanation

* **character_name**: The name of the character.
* **Campaign Name**: The name of the campaign this character is part of.
* **type**: The type of campaign (One-Shot, Campaign, or Community Event).
* **character_class**: The character's class (e.g. Fighter, Rogue, Wizard).
* **character_age**: The character's age.
* **character_gender**: The character's gender (Male, Female, Other).
* **character_race**: The character's race (e.g. Human, Elf, Dwarf).
* **character_alignment**: The character's alignment (Chaotic, Lawful, Neutral, Balanced).
* **Player ID**: The ID number for the player who created this character.
* **Player Name**: The name of the player who created this character.
* **Game Master ID**: The ID number for the game master who created this character.
* **Game Master**: The name of the game master who created this character.
* **Game Master Notes**: Any additional notes from the game master about this character.
* **Campaign Notes**: Any additional notes about the campaign.
* **Background**: Any background information about the character.
* **Background Image**: An optional image for the character's background.
* **Background**: This field can be filled with additional background information about the character.
* **GM Notes**: This field is used for the game master to add notes about the character.
