# Vote For Game Revival - Help Guide
## Purpose
The "Vote For Game Revival" form is designed to collect feedback and suggestions from users on games that are considered "dead" or no longer maintained. This form allows users to express their interest in reviving a game and potentially collaborate with game developers to bring it back to life.

## How To Complete This Form

1.  Click on the "Vote For Game Revival" form.
2.  Select the games you're interested in reviving from the list on the first page.
3.  Optionally, provide the game title, developer name, and developer email (if known).
4.  Enter your reason for reviving the game.
5.  Choose the type of revival vote you're casting (Yes/No).
6.  Optionally, enter a message for the developer.

## Field-by-Field Explanation

* **Vote for Game** (`vote_1`, select_multiple, required: false): Select all the games you're interested in reviving by checking the boxes next to them.
* **Game Name** (`game_name`, text, required: false): Enter the title of the game you're interested in reviving (if you know it).
* **Developer Name** (`developer_name`, text, required: false): If you know the game's developer, enter their name here.
* **Reason to Revive** (`revive_reason`, text, required: false): Briefly explain why you'd like to see this game revived.
* **Vote Type** (`vote_type`, select_one, required: false): Indicate whether you want to vote to revive the game (Yes/No).
* **Studio Name** (`studio_name`, text, required: false): If you know the game's development studio, enter their name here.
* **Game Dev Email** (`game_dev_email`, email, required: false): If you know the game's developer email, enter it here.
* **Developer Response** (`dev_response`, text, required: false): Optionally, leave a message for the game developer.

## Tips

* You can select multiple games to revive in the "Vote for Game" field.
* You can provide any relevant context about the game, its developer, or your reasoning for reviving it in the corresponding fields.
* Be as detailed as possible when explaining why you want to see the game revived.
* If you know the game's developer email, it's a good idea to include it so they can contact you directly.
