# Game Feedback Form - Help Guide
## Purpose
The purpose of this form is to collect feedback from players on their experience with a game. This feedback is used to improve the game and enhance the player experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields (marked as required in the form).
2. If a field is optional, feel free to include as much information as you want.
3. Make sure to fill out the correct game title, game mode, and player level for the game you are providing feedback on.
4. If you are a player, select "Player" as the submitted by option.

## Field-by-Field Explanation

* **Game Feedback** (`game_feedback_form`, text, required): This is the main feedback text where you can describe your experience with the game. Be as detailed and specific as possible.
* **Feedback Score** (`feedback_score`, number, optional): If you want to rate your experience with the game, you can enter a number from 1-5 to indicate your satisfaction.
* **Comment** (`comment`, text, optional): If you have additional comments or suggestions for the game, you can include them here.
* **Game Title** (`game_title`, text, optional): Enter the title of the game you are providing feedback on.
* **Played Game Mode** (`played_game_mode`, select_one, optional): Select the game mode in which you played the game (Online, Offline, Unknown).
* **Player Level** (`player_level`, select_one, optional): Select your player level (High, Low).
* **Game System** (`game_system`, text, optional): Enter the system or platform on which you played the game.
* **Player Name** (`player_name`, text, optional): Enter your player name (if applicable).
* **Player ID** (`player_id`, number, optional): Enter your player ID (if applicable).
* **Game ID** (`game_id`, number, optional): Enter the game ID (if applicable).
* **Submitted By** (`submitted_by`, select_one, optional): Select who is submitting the feedback (Player, Staff, Unknown).
* **Submitted Time** (`submitted_time`, time, optional): Enter the time at which you submitted the feedback.
* **Submitted Date** (`submitted_date`, date, optional): Enter the date at which you submitted the feedback.

Note: If you have any further questions or need clarification, please don't hesitate to contact us.
