# Game Animal Processing Guide - Help Guide
## Purpose
This guide is intended to help users collect and process game animal information for the purposes of animal management and game development.

## How To Complete This Form
To complete this form, follow these steps:

1. Make sure you are authorized to access this form and that you understand the game animal data it collects.
2. Ensure that each row in the form represents a single game animal, not a batch of game animals.
3. Fill out the form with accurate and relevant information about each game animal.

## Field-by-Field Explanation

* **Form Start** (`id: 1`, `type: number`, required: false): This field is used to indicate the starting point of the form.
* **Game Species** (`id: 2`, `type: select_one`, required: false): This field asks whether the game animal is of a particular species. You can choose between "Yes" or "No" options.
* **Game Size** (`id: 3`, `type: select_multiple`, required: false): This field asks whether the game animal is of a certain size. You can select multiple options from the list, as applicable.
* **Processing Date** (`id: 4`, `type: date`, required: false): This field is used to record the date of the processing activity. Choose the correct date according to the processing activity.
* **Processing Time** (`id: 5`, `type: time`, required: false): This field is used to record the time of the processing activity. Choose the correct time according to the processing activity.
* **Harvested By** (`id: 6`, `type: select_one`, required: false): This field asks whether the game animal was harvested. You can choose between "Yes" or "No" options.
* **Harvested From** (`id: 7`, `type: select_multiple`, required: false): This field asks whether the game animal was harvested from a particular location. You can select multiple options from the list, as applicable.
* **Notes** (`id: 8`, `type: note`, required: false): This field is used to add any additional information about the game animal.
* **Email** (`id: 9`, `type: email`, required: false): This field is used to record the contact information of the person or organization responsible for the game animal.
* **Phone** (`id: 10`, `type: text`, required: false): This field is used to record any additional contact information of the person or organization responsible for the game animal.
* **Game Animal Processing Guide** (`id: 11`, `type: select_multiple`, required: false): This field is used to indicate whether the game animal requires any special processing guidance. You can select multiple options from the list, as applicable.

## Tips
* Be sure to review the form carefully before submitting any information.
* Double-check your answers for accuracy to avoid errors.
* If you are unsure about any field, ask for clarification or guidance from authorized personnel.
