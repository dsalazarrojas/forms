# Roleplay Session Registration - Help Guide

## Purpose
The purpose of this form is to register roleplaying session details, schedule, and other relevant information for a roleplaying session. This form is meant to provide a structured way for event hosts, organizers, or players to document and share the necessary information about the session.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct submitter type (Event Host, Trainer, or Gamer) to indicate your role in the session.
2. Choose the session's roleplay type (Roleplaying, Improv, or Improvisation).
3. Select any applicable game systems used during the session (D20, FATE, Sorcerer, or World of Darkness).
4. Fill in the session's name, date, and time.
5. Provide the location details for the session.
6. Enter the participant's name, email, and phone number (if applicable).
7. Fill in any additional notes or guidelines for the session.

## Field-by-Field Explanation
- **Session Details** (`session_details`, `text`, required: false): This field is for any additional information about the session that you'd like to share with participants. It's a free-form text field where you can describe the session's theme, setting, or other relevant details.
- **Schedule** (`session_schedule`, `text`, required: false): Enter the schedule for the session, including any start and end times or other relevant information.
- **Session Name** (`session_name`, `text`, required: false): Enter the name of the session, which should be descriptive and clearly identify the session's topic.
- **Date** (`session_date`, `date`, required: false): Select the date for the session. Make sure to use the correct format for the date.
- **Time** (`session_time`, `time`, required: false): Enter the time for the session, using the 24-hour clock format if necessary.
- **Location** (`location_details`, `note`, required: false): Enter any necessary details about the session's location, such as the address or room number.
- **Participant Details** (`participant_details`, `text`, required: false): This field is for any additional information about the participant.
- **Participant Name** (`participant_name`, `text`, required: false): Enter the participant's name.
- **Participant Email** (`participant_email`, `email`, required: false): Enter the participant's email address.
- **Participant Phone** (`participant_phone`, `text`, required: false): Enter the participant's phone number.
- **Guidelines** (`guidelines`, `note`, required: false): Enter any guidelines or rules for the session that participants should be aware of.
- **Submitter** (`submitter`, `select_one`, required: false): Select the submitter type (Event Host, Trainer, or Gamer).
- **Roleplay Type** (`roleplay_type`, `select_one`, required: false): Choose the roleplay type (Roleplaying, Improv, or Improvisation).
- **Game System** (`game_system`, `select_multiple`, required: false): Select any applicable game systems used during the session (D20, FATE, Sorcerer, or World of Darkness).
- **Character Name** (`character_name`, `text`, required: false): Enter the character's name.
- **Character Sheet** (`character_sheet`, `text`, required: false): Enter any character sheet or information for the character.
- **Session Goals** (`session_goals`, `text`, required: false): Enter the session's goals or objectives.
- **Participant Notes** (`participant_notes`, `note`, required: false): Enter any additional notes about the participant.

## Tips
- Make sure to fill in all required fields to ensure accurate and complete information about the session.
- Double-check the session's details for any conflicts or inconsistencies.
- Use the correct format for dates and times.
- If you're unsure about any field, consider reaching out to the form's administrator or the relevant team for guidance.
