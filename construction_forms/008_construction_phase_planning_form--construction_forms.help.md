# Construction Phase Planning Form - Help Guide
## Purpose
This form is used to record and plan the construction phase of a project, including its start and end dates, key milestones, required permits, and other logistical details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project name** in the first text field, which should be the official title of the project.
2. Select the **Phase name** from the options provided or enter a custom text value, which should describe the specific construction phase, e.g., Foundation, Framing, or Finishes.
3. Enter the **Phase start date** in the date field, which should be the planned start date for this construction phase.
4. If applicable, enter the **Phase end date**, which should be the planned completion date for this phase.
5. In the **Key milestones** field, list the important events or tasks expected to be completed during this phase.
6. Indicate the **Required permits** that need to be obtained before work can begin on this phase. You can select multiple options from the dropdown list.
7. If assigned, enter the **Primary contractors** responsible for this phase in the text field.
8. Mention the **Special equipment needed** for this phase, if any, in the text field.

## Field-by-Field Explanation
* **Project name**: Enter the official title of the project.
* **Phase name**: Choose or enter the specific construction phase, e.g., Foundation, Framing, or Finishes.
* **Phase start date**: Planned start date for this construction phase.
* **Phase end date**: (Optional) Planned completion date for this phase.
* **Key milestones**: List important events or tasks expected to be completed during this phase.
* **Required permits**: Select all applicable permits needed before work can begin.
	+ Building permit
	+ Electrical permit
	+ Plumbing permit
	+ Environmental approvals
* **Primary contractors**: List the main contractors assigned to this phase.
* **Special equipment needed**: Mention any heavy equipment or specialized tools required for this phase.

## Tips
* Ensure you fill out all required fields to provide a complete picture of the construction phase.
* Be accurate when entering dates and milestones to facilitate effective project planning.
* If you're unsure about any field, refer to your project's documentation or consult with your team for clarification.
