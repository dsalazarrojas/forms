# Daily Construction Report - Help Guide
## Purpose
The Daily Construction Report is a form used to document daily progress and activities on construction sites. It is designed to help construction project managers and site supervisors track and report on the status of ongoing projects.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Project Name** in the first field.
2. Select the **Date** of the report in the second field using the calendar icon.
3. Enter the **Time Completed** in the third field.
4. Provide a detailed **Task Description** in the last field.

## Field-by-Field Explanation
* **Project Name** (Project Name, text, optional): Enter the name of the project you are reporting on.
* **Date** (Date, date, optional): Select the date you are completing the report.
* **Time Completed** (Time Completed, time, optional): Enter the time you completed the task or project activity.
* **Task Description** (Task Description, text, optional): Provide a detailed description of the task or project activity you completed.

## Tips
* Make sure to fill in all required fields, if any. If you need help with the date field, you can use the calendar icon to select the date.
* If you are unsure about any field, refer to your project documentation or contact your project manager for guidance.
