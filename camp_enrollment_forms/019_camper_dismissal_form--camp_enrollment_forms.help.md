# Camper Dismissal Form - Help Guide
## Purpose
The Camper Dismissal Form is used to document a camper's dismissal from a session. It gathers information about the reason for dismissal, details surrounding the dismissal, and confirmation of certain procedures.

## How To Complete This Form
1. Select the reason for the camper's dismissal from the "Reason for Dismissal" dropdown menu.
2. Enter the details about the reason for dismissal in the "Dismissal Reason Details" text field.
3. Select the date and time of dismissal from the calendar.
4. Enter the name of the person picking up the camper.
5. Select the relationship between the person picking up the camper and the camper.
6. Select a photo ID presented by the person picking up the camper.
7. Confirm that all the camper's belongings are accounted for.
8. Select the status of the financial settlement (e.g., paid in full, refund issued).
9. Confirm that health clearance is given for the camper to leave the session.
10. Select if there are any outstanding fees or charges.
11. Enter any staff notes or comments.
12. Enter the name of the authorized staff member signing off on the form.

## Field-by-Field Explanation

* **Camper Full Name** (`camper_name`, required): Enter the full name of the camper being dismissed.
* **Camper ID or Registration Number** (`camper_id`, optional): Enter the camper's ID or registration number, if available.
* **Cabin Assignment** (`camper_cabin`, optional): Enter the cabin number or location where the camper is currently living.
* **Current Camp Session** (`current_session`, required): Enter the current camp session the camper is enrolled in.
* **Parent or Guardian Name** (`guardian_name`, required): Enter the name of the parent or guardian responsible for the camper.
* **Guardian Contact Number** (`guardian_phone`, required): Enter the contact number of the parent or guardian.
* **Guardian Email Address** (`guardian_email`, required): Enter the email address of the parent or guardian.
* **Reason for Dismissal** (`dismissal_reason`, required): Select the reason for the camper's dismissal from the dropdown menu.
* **Dismissal Reason Details** (`dismissal_reason_details`, optional): Enter any additional details about the reason for dismissal.
* **Dismissal Date and Time** (`dismissal_date_time`, required): Select the date and time of the dismissal from the calendar.
* **Person Picking Up Camper** (`pickup_person_name`, required): Enter the name of the person picking up the camper.
* **Relationship to Camper** (`pickup_person_relationship`, required): Select the relationship between the person picking up the camper and the camper.
* **Photo ID Presented** (`pickup_person_id`, required): Select the type of photo ID presented by the person picking up the camper.
* **All Camper Belongings Accounted For** (`belongings_returned`, required): Confirm that all the camper's belongings are accounted for.
* **Description of Missing Items** (`missing_items_description`, optional): Enter a description of any missing items, if any.
* **Financial Settlement Status** (`financial_settlement`, required): Select the status of the financial settlement.
* **Health Clearance Confirmed** (`health_clearance`, required): Confirm that health clearance is given for the camper to leave the session.
* **Outstanding Fees or Charges** (`outstanding_fees`, required): Select if there are any outstanding fees or charges.
* **Staff Notes and Comments** (`staff_notes`, optional): Enter any staff notes or comments.
* **Authorized Staff Signature Name** (`authorized_staff`, required): Enter the name of the authorized staff member signing off on the form.
