# Reunion Survey - Help Guide
## Purpose
The Reunion Survey form is designed to collect information about your interests, preferences, and needs for the upcoming reunion event. Your input will help the event planning committee create a memorable and enjoyable experience for all attendees.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each page and answer the questions accordingly.
2. Enter your information accurately and completely in the required fields.
3. For multiple-choice questions, select the option that best represents your preference or choice.
4. If you have any additional comments or feedback, please use the "Feedback" field.

## Field-by-Field Explanation

* **Event Planning** (`event_planning`, text, not required):
	+ This field is for any suggestions or ideas you have for the reunion event. Please provide any thoughts you have on what kind of events or activities you would enjoy at the reunion.
* **Reunion Details** (`reunion_details`, text, not required):
	+ In this field, you can provide any additional details about the reunion event that you think would be helpful for the planning committee to know.
* **Attendees** (`attendees`, select_one, not required):
	+ Please select "Yes" if you are planning to attend the reunion, and "No" if you are not planning to attend.
* **Attendee Info** (`attendee_info`, select_multiple, not required):
	+ For attendees who are planning to come, please select "Yes" for each person who will be attending.
* **Feedback** (`feedback`, text, not required):
	+ If you have any comments or suggestions for the reunion event, please provide them here.
* **Date and Time** (`date_and_time`, date, not required):
	+ Please enter the date and time you would prefer for the reunion event.
* **Location** (`location`, text, not required):
	+ Suggest a location for the reunion event that you think would be convenient and enjoyable for attendees.
* **Notes** (`notes`, note, not required):
	+ If you have any additional information or comments about the reunion event that you'd like to share, please enter them in this field.
* **Email** (`email`, email, not required):
	+ Please provide an email address where you can be reached for reunion event updates and announcements.
* **Phone** (`phone`, text, not required):
	+ If you have a phone number where you can be reached during the reunion event, please provide it.

## Tips
* Please answer the questions as accurately and thoroughly as possible to help the planning committee create a successful and enjoyable reunion event.
* If you have any questions or concerns about the form, please don't hesitate to reach out to the planning committee.
* Thank you for taking the time to complete this form! Your input is greatly appreciated.
