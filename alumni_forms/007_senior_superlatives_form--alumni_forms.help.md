# Senior Superlatives Form - Help Guide
## Purpose
The Senior Superlatives Form is used to collect votes and feedback from students on their senior superlatives, a group that represents the spirit and ideals of the institution.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all superlatives you would like to vote for.
2. Enter the number of votes you would like to give each superlative.
3. Provide feedback and comments about the superlatives.
4. Enter the superlatives' email address and phone number (if available).
5. Enter the superlatives' comments and voting duration.

## Field-by-Field Explanation
* **vote_for_superlatives** (Page 1, senior_superlatives_form_1, Select Multiple, Optional): Select all superlatives you would like to vote for.
* **superlative_1_votes** (Page 1, senior_superlatives_form_2, Select Multiple, Optional): Enter the number of votes you would like to give to the first superlative.
* **senior_superlatives_form_3** (Page 1, senior_superlatives_form_3, Select One, Optional): Select one superlative for this field.
* **yearbook_superlatives** (Page 1, senior_superlatives_form_4, Text, Optional): Provide feedback and comments about the superlatives in this field.
* **superlatives_votes_count** (Page 1, senior_superlatives_form_5, Number, Optional): Enter the number of votes you would like to give to the superlatives.
* **superlatives_voting_start_time** (Page 1, senior_superlatives_form_6, Date, Optional): Enter the start time of the voting duration.
* **superlatives_voting_end_time** (Page 1, senior_superlatives_form_7, Time, Optional): Enter the end time of the voting duration.
* **superlatives_voting_comments** (Page 1, senior_superlatives_form_8, Note, Optional): Enter any comments about the voting process.
