# Veterinary Learning Content Update Request - Help Guide
## Purpose
This form is designed to be used by veterinarians and veterinary clinics to request updates to existing learning content in the veterinary learning platform.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the type of request you are making (e.g. Content Update or Content Review).
2. Select the type of content you are requesting to be updated (e.g. Text, Image, or Video).
3. Provide a brief description of the requested update.
4. Select the veterinary clinics where the content will be applied or used.
5. If applicable, provide the number of veterinarians assigned to the clinic.
6. Provide the date the content will be updated.
7. Provide the location where the content will be used.
8. Provide any additional comments or feedback.
9. Select the person assigned to handle the request.
10. Enter your email address so that we can contact you to discuss further.
11. If applicable, enter your phone number and/or submit the form by someone else.
12. Provide a signature or initials to confirm that you are making the request.
13. If applicable, attach any relevant files or documents.
14. Finally, select the current status of the request (e.g. Draft or Published).

## Field-by-Field Explanation
- **Request Type** (`request_type`, select_one, required): Select the type of request you are making, such as Content Update or Content Review.
- **Content Type** (`content_type`, select_one, required): Select the type of content that you are requesting to be updated, such as Text, Image, or Video.
- **Description** (`description`, text, optional): Provide a brief description of the requested update.
- **Veterinary Clinics** (`veterinary_clinics`, select_multiple, required): Select the veterinary clinics where the content will be applied or used.
- **Veterinarians** (`veterinarians`, number, optional): If applicable, enter the number of veterinarians assigned to the clinic.
- **Date** (`date`, date, required): Enter the date the content will be updated.
- **Time** (`time`, time, optional): If applicable, enter the time the content will be used.
- **Location** (`location`, text, required): Enter the location where the content will be used.
- **Comments** (`comments`, text, optional): Provide any additional comments or feedback.
- **Assigned To** (`assigned_to`, select_one, required): Select the person assigned to handle the request.
- **Email** (`email`, email, required): Enter your email address so that we can contact you to discuss further.
- **Phone** (`phone`, text, optional): If applicable, enter your phone number.
- **Submitted By** (`submitted_by`, text, required): Provide your name or initials to confirm that you are making the request.
- **Attachments** (`attachments`, select_multiple, optional): If applicable, attach any relevant files or documents.
- **Files** (`files`, select_multiple, optional): If applicable, select any files or documents that need to be attached.
- **Uploaded By** (`uploaded_by`, text, optional): If applicable, enter the name or initials of the person who uploaded the attachment or file.
- **Uploaded On** (`uploaded_on`, date, optional): If applicable, enter the date the attachment or file was uploaded.
- **Uploaded At** (`uploaded_at`, time, optional): If applicable, enter the time the attachment or file was uploaded.
- **Updated On** (`updated_on`, date, optional): If applicable, enter the date the content was last updated.
- **Updated At** (`updated_at`, time, optional): If applicable, enter the time the content was last updated.
- **Created On** (`created_on`, date, optional): If applicable, enter the date the request was created.
- **Created At** (`created_at`, time, optional): If applicable, enter the time the request was created.
- **Status** (`status`, select_one, required): Select the current status of the request, such as Draft or Published.

## Tips

* Please make sure to fill out the required fields to ensure that your request is processed efficiently.
* If you are unsure about any field, you can contact us for clarification.
* Make sure to attach any relevant files or documents to support your request.
* Double-check your email address and phone number for accuracy.
* Provide a clear and concise description of the requested update.
* Ensure that the content type is correctly selected to avoid delays in processing your request.

Note: This help guide is for end-users to understand how to complete the form and what each field means. If you have any questions or need further clarification, please don't hesitate to contact us.
