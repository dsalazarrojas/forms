# Veterinary Software Feature Preference Survey - Help Guide
## Purpose
This form is designed to collect your feedback and preferences on various software features for our veterinary software. Your input will help us understand what features you're interested in and what you'd like to see improved or added. Please take a few minutes to fill out the form, and your input will be greatly appreciated!

## How To Complete This Form
- Click on the "Submit" button to start the survey.
- Fill in your name and email address in the "First Name" and "Email" fields, respectively.
- Select your preferred phone number option from the "Phone Number" field.
- Choose the software features you're interested in from the "Software Features" field.
- Enter the order of priority for the selected features.
- If you have any additional comments, please type them in the "Comments" field.
- Finally, click the "Submit" button to submit your feedback.

## Field-by-Field Explanation
- **First Name** (text): A field to input your first name for identification purposes.
- **Email** (text): A field to input your email address for correspondence.
- **Phone Number** (select_one): Select your preferred phone number option to help us contact you.
  - Option 1: This option is not described.
  - Option 2: This option is not described.
- **Software Features** (select_multiple): Choose the software features you're interested in from the list:
  - Option 1: This option is not described.
  - Option 2: This option is not described.
  - Option 3: This option is not described.
  - Option 4: This option is not described.
- **Priority Ordering** (number): Enter the order of priority for the selected features.
- **Comments** (note): Type any additional comments you may have.
- **Submit** (text): Click this button to submit your feedback.
- **Thank You** (note): A confirmation page that thanks you for your feedback.

Note: The field labels and descriptions are based on the provided YAML fields and attempt to provide a clear explanation of each field's purpose.
