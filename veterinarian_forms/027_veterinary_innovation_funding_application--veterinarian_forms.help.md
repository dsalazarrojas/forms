## Field-by-Field Explanation
* **Organization Name** (`organization_name`, text, required): Enter the name of the organization submitting the application.
* **Applicant Name** (`applicant_name`, text, required): Enter the name of the person or team responsible for the project.
* **Contact Email** (`contact_email`, email, required): Enter the email address of the contact person or team.
* **Project Summary** (`project_summary`, text, required): Provide a brief description of the project.
* **Project Budget** (`project_budget`, number, required): Enter the total budget allocated for the project.
* **Project Budget Currency** (`project_budget_currency`, text, required): Specify the currency in which the budget is expressed.
* **Supporting Documents** (`supporting_documents`, select_multiple, required): Select the materials that support the project application (Application Form, Supporting Materials, Project Plan, or Other).
* **Project Location** (`project_location`, text, required): Enter the location where the project will be conducted.
* **Contact Phone** (`contact_phone`, text, required): Enter the phone number of the contact person or team.
* **Project Start Date** (`project_start_date`, date, required): Enter the date when the project is expected to begin.
* **Project End Date** (`project_end_date`, date, required): Enter the date when the project is expected to end.
* **Project Status** (`project_status`, select_one, required): Select the current state of the project (ongoing, upcoming, or complete).
* **Application Deadline** (`application_deadline`, date, required): Select the date by which the application must be submitted.
* **Supporting Documents Uploaded** (`supporting_documents_uploaded`, select_one, required): Indicate whether supporting documents have been uploaded or not.
* **Applicant Address** (`applicant_address`, text, required): Enter the address of the applicant.
* **Project Funding Type** (`project_funding_type`, text, required): Enter the type of funding being applied for.
* **Organization URL** (`organization_url`, text, required): Enter the website or URL of the organization submitting the application.
