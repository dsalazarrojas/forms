# veterinary_client_communication_style_survey - Help Guide
## Purpose
The veterinary_client_communication_style_survey form is used to collect information about a client's communication style and preferences. This information helps the veterinary team understand how to better communicate with the client.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the client's contact preferences from the options provided in the "Contact Preferences" page.
2. Choose the communication frequency that best suits your preferences.
3. On the "Tone" page, type in how you would like to be communicated with.
4. On the "Preferred Channel" page, select the channels you would like to use for communication.
5. On the "Updates" page, enter the frequency at which you would like to receive updates.
6. On the "Reminders" page, enter the number of reminders you would like to receive.
7. On the "Follow-Ups" page, enter the number of follow-ups you would like to receive.
8. On the "Preferred Language" page, select your preferred language.
9. If you have a preferred email address, enter it on the "Email" page.
10. If you have a phone number, enter it on the "Phone" page.
11. Use the "Additional Comments" page to add any additional comments or information.
12. Finally, provide the survey details on the "Survey Conducted By" page.

## Field-by-Field Explanation
### Contact Preferences
* **Contact Preferences** (`pet_owners_contact_preferences`, `select_one`, required)
	+ This field allows you to select how you would like to be contacted. Options include "Option 1" and "Other".
### Communication Frequency
* **Communication Frequency** (`communication_frequency`, `select_one`, required)
	+ This field asks how frequently you would like to receive communication from us. Options include "Option 1" and "Other".
### Tone
* **Tone** (`tone`, `text`, required)
	+ This field asks how you would like to be communicated with in terms of tone. Please type in your preferred tone, e.g. friendly, professional, etc.
### Preferred Channel
* **Preferred Channel** (`preferred_channel`, `select_multiple`, required)
	+ This field allows you to select multiple preferred channels for communication. Options include "Option 1", "Option 2", and "Option 3".
### Updates
* **Updates** (`updates`, `time`, required)
	+ This field asks for the frequency at which you would like to receive updates. Please enter the number of updates you would like to receive.
### Reminders
* **Reminders** (`reminders`, `number`, optional)
	+ This field asks for the number of reminders you would like to receive. Please note that this field is optional.
### Follow-Ups
* **Follow-Ups** (`follow_ups`, `number`, required)
	+ This field asks for the number of follow-ups you would like to receive.
### Preferred Language
* **Preferred Language** (`preferred_language`, `select_one`, required)
	+ This field asks for your preferred language for communication.
### Email
* **Email** (`email`, `email`, optional)
	+ This field is for your preferred email address.
### Phone
* **Phone** (`phone`, `text`, optional)
	+ This field is for your phone number.
### Additional Comments
* **Additional Comments** (`additional_comments`, `text`, optional)
	+ This field is for any additional comments or information.
### Survey Conducted By
* **Survey Conducted By** (`survey_conducted_by`, `text`, optional)
	+ This field is for providing information about who conducted the survey.
 
## Tips
* Please ensure that all fields marked as required are filled in before submitting the form.
* If you are unsure about any of the fields, please reach out to our team for assistance.
