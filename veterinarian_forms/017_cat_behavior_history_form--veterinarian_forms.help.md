# Cat Behavior History Form - Help Guide
## Purpose
This form is designed to gather information about a cat's behavior and history. It is meant to be completed by the cat's owner or caregiver to provide a comprehensive understanding of the cat's condition and behavior. This form should only be completed once for each cat, and any subsequent updates or changes should be documented separately.

## How To Complete This Form
1. Review the form carefully and ensure you are completing it for the correct cat.
2. Enter the cat's name, age, and sex/altered status in the relevant fields.
3. Describe the main reason for the behavioral assessment and how long the behavior has been occurring.
4. Provide details about any specific behaviors or concerns you have noticed.
5. Answer questions about the cat's litter box usage habits, aggression towards humans and other pets, vocalization level, and hiding behavior.
6. Describe any recent changes in the household or medications/supplements the cat is taking.
7. Provide any additional details or context about the behavior.

## Field-by-Field Explanation

* **Cat Name** (`cat_name`, text, required): Enter the cat's name.
* **Approximate Age** (`cat_age`, text, required): Enter the cat's approximate age.
* **Sex and Altered Status** (`cat_sex_status`, select_one, required): Select the cat's sex and altered status (neutered or spayed/intact).
* **Main reason for behavioral assessment** (`main_reason_consult`, text, required): Briefly describe the problem behavior.
* **How long has this behavior been occurring** (`duration_of_problem`, text, required): Describe how long the behavior has been occurring.
* **Was there a specific event that triggered the behavior** (`onset_trigger`, text, optional): If applicable, describe the specific event that triggered the behavior (e.g. moving house, new baby, new pet).
* **Litter box usage habits** (`litter_box_use`, select_one, required): Select the cat's litter box usage habits (always uses box, usually uses box, occasional accidents, frequently soiles outside box).
* **Displays aggression towards humans** (`aggression_towards_people`, select_one, required): Select the level of aggression the cat displays towards humans (never, rarely, often, daily).
* **Displays aggression towards other pets** (`aggression_towards_pets`, select_one, required): Select the level of aggression the cat displays towards other pets (never, rarely, often, daily, no other pets).
* **Level of vocalization/meowing** (`vocalization_level`, select_one, required): Select the level of vocalization/meowing the cat displays (quiet, normal, very vocal, excessive meowing at night).
* **How often does the cat hide** (`hiding_behavior`, select_one, required): Select how often the cat hides (rarely, sometimes, most of the day).
* **Any recent changes in the household** (`household_changes`, text, optional): Describe any recent changes in the household that may be contributing to the behavior.
* **Is the cat on any medications or supplements** (`current_medications`, text, optional): List any medications or supplements the cat is taking.
* **Any additional details about the behavior** (`further_details`, text, optional): Provide any additional context or details about the behavior.

This form is designed to be as clear and concise as possible, but if you have any questions or need further clarification, please don't hesitate to contact us.
