# Veterinary Education Resource Access Request - Help Guide
## Purpose
The purpose of this form is to request access to veterinary education resources, such as textbooks, journals, and online resources. These resources are used for educational purposes, such as research, coursework, presentations, or other educational activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the University Name field with the name of the university or institution where you are affiliated.
2. Enter the name and contact information of the contact person who will be handling your request.
3. Select the type of resource you are requesting (Textbooks, Journals, Online Resources, or Other).
4. Provide a brief description of the resource you are requesting.
5. Specify the educational purpose for which you are requesting the resource (Research, Coursework, Presentation, or Other).
6. Select the status of the resource (Available, Pending, or Denied).
7. Enter your email address so that we can contact you regarding your request.
8. Enter your phone number so that we can reach out to you if needed.
9. If you have already been assigned a tool for this resource, enter the name of that tool.

## Field-by-Field Explanation
### University Name (Text)
Enter the name of your university or institution where you are affiliated.

### Contact Person (Text)
Enter the name and contact information of the contact person who will be handling your request.

### Resource Type (Select One)
Select the type of resource you are requesting from the following options:
* Textbooks
* Journals
* Online Resources
* Other

### Resource Description (Text)
Provide a brief description of the resource you are requesting.

### Educational Purpose (Select Multiple)
Select the educational purpose for which you are requesting the resource from the following options:
* For Research
* For Coursework
* For Presentation
* For Other

### Request Date (Date)
Enter the date on which you are submitting this request.

### Resource Status (Select One)
Select the status of the resource from the following options:
* Available
* Pending
* Denied

### Requestor Email (Email)
Enter your email address so that we can contact you regarding your request.

### Requestor Phone (Text)
Enter your phone number so that we can reach out to you if needed.

### Assigned Tool (Text)
If you have already been assigned a tool for this resource, enter the name of that tool.

## Tips
* Ensure that you have not already submitted a similar request for the same resource.
* Be as specific as possible when providing information for the resource you are requesting.
* If you are unsure about any of the fields, please contact your contact person or the support team for assistance.
