# Veterinary Digital Access Update Request Form - Help Guide
## Purpose
The purpose of this form is to request an update to digital access for a user. This form is used by veterinarians and staff members to ensure that their role and access level are accurately reflected in the system.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form completely and accurately with your information.
* Make sure to enter the correct information for the user requesting the update.
* For the "Staff Member Role" field, select the correct role that the user should have.
* For the "Access Level" field, select the correct level of access that the user should have.
* If necessary, enter a reason for the access request in the "Access Reason" field.
* Enter the date and time you submitted the form in the "Submission Date" and "Submission Time" fields.
* Fill out the "Submitter Name", "Submitter Email", "Submitter Phone", and "Submitter Title" fields with your own information.

## Field-by-Field Explanation
* **User Name** (User Name, text, required: false): Enter the name of the user whose access you are requesting to be updated.
* **User Email** (user_email, email, required: false): Enter the email address of the user whose access you are requesting to be updated.
* **Practice Name** (practice_name, text, required: false): Enter the name of the practice for which the user works.
* **Staff Member Role** (staff_member_role, select_multiple, required: false): Select the role that the user should have. Options: 'Yes' and 'No'.
* **Access Level** (access_level, select_multiple, required: false): Select the access level that the user should have. Options: 'High' and 'Low'.
* **Access Reason** (access_reason, text, required: false): If the user's access is being changed, enter a reason for the change.
* **Submission Date** (submission_date, date, required: false): Enter the date you submitted the form.
* **Submission Time** (submission_time, time, required: false): Enter the time you submitted the form.
* **Submitter Name** (submitter_name, text, required: false): Enter your name.
* **Submitter Email** (submitter_email, email, required: false): Enter your email address.
* **Submitter Phone** (submitter_phone, text, required: false): Enter your phone number.
* **Submitter Title** (submitter_title, text, required: false): Enter your title or position.
* **Comments** (comments, text, required: false): Enter any additional comments or information about the request.
