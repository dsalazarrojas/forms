# Hotel Maintenance Request Form - Help Guide
## Purpose
The Hotel Maintenance Request Form is a simple tool for staff to report maintenance requests related to the hotel's premises. The form helps ensure that these issues are addressed promptly, maintaining the hotel's facilities and providing a comfortable environment for guests.

## How To Complete This Form
To complete this form:

1.  Select the type of issue being reported (e.g., General, Maintenance, Repair).
2.  Provide a brief description of the issue.
3.  Specify the room number affected by the issue.
4.  Indicate the priority of the issue (High, Medium, Low).
5.  Specify the location(s) affected by the issue (e.g., Hallway, Bathroom, Bedroom).
6.  Enter your contact information for follow-up purposes.
7.  Add any additional comments or notes about the issue.
8.  Finally, submit the form.
