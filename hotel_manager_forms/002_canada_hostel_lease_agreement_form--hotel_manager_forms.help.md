# Canada Hostel Lease Agreement Form - Help Guide
## Purpose
This form is used to collect information for a hostel lease agreement in Canada. Please fill out the form accurately to ensure a smooth and secure lease experience.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Make sure to review and agree to the lease terms and conditions.

## Field-by-Field Explanation
* **Tenant Full Name**: Please provide your full name as it appears on your government-issued ID. This is the name that will be used in all correspondence and communications.
	+ Label: Tenant Full Name
	+ Type: text
	+ Required: Yes
* **Tenant Email Address**: Provide your primary contact email address.
	+ Label: Tenant Email Address
	+ Type: email
	+ Required: Yes
* **Tenant Phone Number**: Provide your Canadian phone number for contact purposes.
	+ Label: Tenant Phone Number
	+ Type: text
	+ Required: Yes
* **Tenant Date of Birth**: Please provide your date of birth (must be 18 or older).
	+ Label: Tenant Date of Birth
	+ Type: date
	+ Required: Yes
* **Government ID Type**: Select the type of government-issued ID you have (e.g. Canadian Passport, Provincial Driver License, etc.).
	+ Label: Government ID Type
	+ Type: select_one
	+ Required: Yes
* **ID Number**: Provide the number on your government-issued ID.
	+ Label: ID Number
	+ Type: text
	+ Required: Yes
* **Hostel Location**: Select the location of the hostel you are staying at.
	+ Label: Hostel Location
	+ Type: select_one
	+ Required: Yes
* **Room Type**: Choose the type of accommodation you require (e.g. private room, shared dormitory).
	+ Label: Room Type
	+ Type: select_one
	+ Required: Yes
* **Lease Start Date**: Choose the date when your lease will begin.
	+ Label: Lease Start Date
	+ Type: date
	+ Required: Yes
* **Lease Duration**: Select the length of your lease agreement.
	+ Label: Lease Duration
	+ Type: select_one
	+ Required: Yes
* **Monthly Rent Amount CAD**: Enter the rent amount in Canadian dollars.
	+ Label: Monthly Rent Amount CAD
	+ Type: number
	+ Required: Yes
* **Security Deposit Amount CAD**: Enter the security deposit amount in Canadian dollars.
	+ Label: Security Deposit Amount CAD
	+ Type: number
	+ Required: Yes
* **Payment Frequency**: Choose how often you will pay rent (e.g. weekly, bi-weekly, monthly).
	+ Label: Payment Frequency
	+ Type: select_one
	+ Required: Yes
* **Payment Method**: Select your preferred payment method (e.g. credit card, debit card, bank transfer).
	+ Label: Payment Method
	+ Type: select_one
	+ Required: Yes
* **Utilities Included**: Select which utilities are covered in your lease agreement.
	+ Label: Utilities Included
	+ Type: select_multiple
	+ Required: Yes
* **Additional Services Requested**: Choose any additional services you would like to have access to.
	+ Label: Additional Services Requested
	+ Type: select_multiple
	+ Required: No
* **Emergency Contact Name**: Provide the full name of your emergency contact.
	+ Label: Emergency Contact Name
	+ Type: text
	+ Required: Yes
* **Emergency Contact Phone**: Provide the phone number of your emergency contact.
	+ Label: Emergency Contact Phone
	+ Type: text
	+ Required: Yes
* **Emergency Contact Relationship**: Choose the relationship of your emergency contact.
	+ Label: Emergency Contact Relationship
	+ Type: select_one
	+ Required: Yes
* **Special Requirements or Accommodations**: If you have any accessibility or special needs, please describe them.
	+ Label: Special Requirements or Accommodations
	+ Type: text
	+ Required: No
* **Do You Have Pets**: Indicate if you have any pets.
	+ Label: Do You Have Pets
	+ Type: select_one
	+ Required: Yes
* **Smoking Preference**: Indicate your smoking preference.
	+ Label: Smoking Preference
	+ Type: select_one
	+ Required: Yes
* **Lease Terms and Conditions Accepted**: Agree to the lease terms and conditions.
	+ Label: Lease Terms and Conditions Accepted
	+ Type: select_one
	+ Required: Yes
* **Agreement Signature Date**: Date and sign this lease agreement.
	+ Label: Agreement Signature Date
	+ Type: date
	+ Required: Yes

## Tips
* Please ensure that all fields are filled out accurately and truthfully.
* Make sure to review and agree to the lease terms and conditions.
* If you have any questions or concerns, please reach out to the hostel staff.
