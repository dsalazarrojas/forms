# Hostel Management Routine Check Form - Help Guide
## Purpose

The Hostel Management Routine Check Form is used to track and manage various routines and tasks related to hostel maintenance, cleaning, and shopping.

## How To Complete This Form

1. Read each section carefully and select all applicable options for each routine.
2. Fill out all required fields in a clear and concise manner.
3. Provide any additional comments or notes if necessary.
4. Ensure that all sections are complete before submitting the form.

## Field-by-Field Explanation

* **Maintenance Routines** (`hostel_maintenance_routine`, `select_multiple`, required: false): Select all applicable maintenance routines that need to be performed.
* **Cleaning Routines** (`hostel_cleaning_routine`, `text`, required: false): Describe the current cleaning routines being performed.
* **Shopping Routines** (`hostel_shopping_routine`, `select_multiple`, required: false): Select all applicable shopping routines that need to be performed.
* **Status** (`routine_status`, `select_one`, required: false): Select the status of the routine (Available, In Progress, Done, Delayed).
* **Comments** (`comments`, `text`, required: false): Provide any additional comments or notes about the routine.
* **Next Action Date** (`next_action_date`, `date`, required: false): Fill out the date for the next scheduled action.
* **Next Action Time** (`next_action_time`, `time`, required: false): Fill out the time for the next scheduled action.
* **Next Follow-up Date** (`next_followup_date`, `date`, required: false): Fill out the date for the next follow-up action.
* **Next Follow-up Time** (`next_followup_time`, `time`, required: false): Fill out the time for the next follow-up action.
* **Assigned To** (`assigned_to`, `select_one`, required: false): Select the person or department assigned to perform the routine.
* **Completed By** (`completed_by`, `select_one`, required: false): Select the person or department that completed the routine.
* **Comments 2** (`comments_2`, `text`, required: false): Provide any additional comments or notes about the routine.
* **Completed Date** (`completed_date`, `date`, required: false): Fill out the date the routine was completed.
* **Next Review Date** (`next_review_date`, `date`, required: false): Fill out the date for the next review.
* **Completed Time** (`completed_time`, `time`, required: false): Fill out the time the routine was completed.
* **Completed Status** (`completed_status`, `select_one`, required: false): Select the status of the routine (Available, In Progress, Done, Delayed).
* **Routine Type** (`routine_type`, `select_one`, required: false): Select the type of routine (Maintenance, Cleaning, Shopping).
* **Next Review Time** (`next_review_time`, `time`, required: false): Fill out the time for the next review.
* **Next Review Status** (`next_review_status`, `select_one`, required: false): Select the status of the next review (Available, In Progress, Done, Delayed).
* **Completed Status 2** (`completed_status_2`, `select_one`, required: false): Select the status of the routine (Available, In Progress, Done, Delayed).
* **Routine Status 2** (`routine_status_2`, `select_one`, required: false): Select the status of the routine (Available, In Progress, Done, Delayed).
* **Comments 3** (`comments_3`, `text`, required: false): Provide any additional comments or notes about the routine.
* **Next Check Date** (`next_check_date`, `date`, required: false): Fill out the date for the next check.
* **Next Check Time** (`next_check_time`, `time`, required: false): Fill out the time for the next check.
* **Next Check Status** (`next_check_status`, `select_one`, required: false): Select the status of the next check (Available, In Progress, Done, Delayed).
