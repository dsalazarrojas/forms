# Reservation Confirmation Form - Help Guide
## Purpose
The Reservation Confirmation Form is a general-purpose form used by hotel managers to confirm or update details of upcoming events or reservations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your First Name in the "First Name" field.
2. Enter your Last Name in the "Last Name" field.
3. Enter your Email in the "Email" field. Please use a valid email format (e.g., `name@example.com`).
4. Enter your Phone number in the "Phone" field.
5. Select a date for the event in the "Event Date" field. Use a standard date format (e.g., YYYY-MM-DD).
6. Enter the start time of the event in the "Start Time" field. Use a standard time format (e.g., HH:MM AM/PM).
7. Enter the duration of the reservation in the "Reservation Duration" field. Use a numeric value (e.g., 3 for 3 hours).
8. Select the type of event in the "Event Type" field. Choose from options like meeting, wedding, convention, etc.
9. Enter the capacity of the event in the "Event Capacity" field. Use a numeric value (e.g., 50 for 50 attendees).
10. Briefly describe the event setup in the "Event Setup" field.
11. List any special requests in the "Special Requests" field.
12. Enter the name of the person to contact in the "Contact Name" field.
13. Enter the email of the person to contact in the "Contact Email" field.
14. Enter the phone number of the person to contact in the "Contact Phone" field.
15. Enter the name of the venue in the "Venue Name" field.
16. Enter the address of the venue in the "Venue Address" field.

## Field-by-Field Explanation

* **First Name** (`First Name`, text, required): Enter your first name for the event or reservation.
* **Last Name** (`Last Name`, text, required): Enter your last name for the event or reservation.
* **Email** (`Email`, email, required): Enter a valid email address for the event or reservation.
* **Phone** (`Phone`, text, required): Enter the phone number of the person to contact.
* **Event Date** (`Event Date`, date, optional): Select a date for the event.
* **Start Time** (`Start Time`, time, required): Enter the start time of the event.
* **Reservation Duration** (`Reservation Duration`, number, optional): Enter the duration of the reservation.
* **Event Type** (`Event Type`, text, optional): Choose the type of event (e.g., meeting, wedding, convention, etc.).
* **Event Capacity** (`Event Capacity`, number, optional): Enter the capacity of the event (e.g., 50 for 50 attendees).
* **Event Setup** (`Event Setup`, text, required): Describe the event setup.
* **Special Requests** (`Special Requests`, text, optional): List any special requests for the event.
* **Contact Name** (`Contact Name`, text, required): Enter the name of the person to contact.
* **Contact Email** (`Contact Email`, email, required): Enter the email of the person to contact.
* **Contact Phone** (`Contact Phone`, text, required): Enter the phone number of the person to contact.
* **Venue Name** (`Venue Name`, text, optional): Enter the name of the venue.
* **Venue Address** (`Venue Address`, text, optional): Enter the address of the venue.

Please note that this form is designed for hotel managers to use, so it's assumed that they are aware of the internal business logic and event planning concepts.
