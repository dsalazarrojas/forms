# Housekeeping Service Request Form - Help Guide
## Purpose
The Housekeeping Service Request Form is used to request services such as cleaning, disinfecting, and maintenance for specific rooms in the hotel. This form helps hotel staff keep track of which tasks are assigned to which rooms and who is responsible for completing them.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the room for which you want to request service.
2. Choose the services needed (cleaning, disinfecting, maintenance, etc.).
3. Provide any special requests or comments.
4. Select the tool or equipment needed to complete the task.
5. Choose who will be responsible for completing the task.
6. Provide the date when the task should be completed.
7. Choose the status of the task.
8. Select the time when the task was completed.

## Field-by-Field Explanation

* **Request Date (1)** (`date`, required: false): Enter the date when the request was submitted.
* **Room Number (2)** (`text`, required: false): Enter the number of the room for which the service is requested.
* **Room Description (3)** (`text`, required: false): Provide a brief description of the room or the specific area that needs attention.
* **Services Needed (4)** (`select_multiple`, required: false): Select all the services needed for the room, such as:
	+ Cleaning
	+ Disinfecting
	+ Linen
	+ Maintenance
* **Special Requests (5)** (`text`, required: false): Enter any special requests or comments for the service.
* **Assigned Tool (6)** (`select_one`, required: false): Select the tool or equipment needed to complete the task, or select "Other" if it's something else.
* **Assigned User (7)** (`select_one`, required: false): Choose who will be responsible for completing the task, such as:
	+ Hotel Manager
	+ Front Desk
	+ Housekeeping Team
* **Submission Date (8)** (`date`, required: false): Enter the date when the request was submitted.
* **Assigned Status (9)** (`select_one`, required: false): Select the status of the task, such as:
	+ Active
	+ Inactive
* **Due Date (10)** (`date`, required: false): Enter the date when the task should be completed.
* **Completed By (11)** (`select_one`, required: false): Select who completed the task, such as:
	+ Hotel Manager
	+ Front Desk
	+ Housekeeping Team
* **Completion Time (12)** (`time`, required: false): Enter the time when the task was completed.
