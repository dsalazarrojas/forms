# Hotel Booking Form Deep Blue Theme - Help Guide
## Purpose
The Hotel Booking Form Deep Blue Theme is a form designed to collect information from users for booking purposes. The form is meant to be used to gather data that will be stored in the system and used for various administrative tasks.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the required fields with the requested information. Required fields are marked with an asterisk (\*).
* For fields with multiple options, select the desired option from the dropdown list.
* For fields with a "note" type, provide a brief description or any additional information you'd like to add.

## Field-by-Field Explanation

* **First name** (`first_name`, `text`, optional): Enter your first name.
* **Last name** (`last_name`, `text`, optional): Enter your last name.
* **Email** (`email`, `email`, optional): Enter your email address.
* **Phone** (`phone`, `text`, optional): Enter your phone number.
* **Checkin Date** (`checkin_date`, `date`, optional): Select the date you plan to check in.
* **Checkout Date** (`checkout_date`, `date`, optional): Select the date you plan to check out.
* **Room choice** (`room_choice`, `select_one`, optional): Select the type of room you'd like to book (Single, Double, or Suite).
* **Payment Method** (`payment_method`, `select_multiple`, optional): Select one or more payment methods you'd prefer to use (Card, Bank Transfer, or PayPal).
* **Note** (`note`, `note`, optional): Add any additional information you'd like to add about your booking.
* **Assigned To** (`assigned_to`, `select_one`, optional): Select the person you'd like your booking assigned to (chatjimmy, admin1, or admin2).
