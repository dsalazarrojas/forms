# Restraining Order Service Status Form - Help Guide
## Purpose
This form is used to track and report the status of restraining orders. It captures information about the order's status, service updates, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current status of the restraining order from the "Restraining Order Service Status" dropdown list.
2. Provide a brief description of the service status update in the "Restraining Order Service Status Update" field.
3. Enter the next date and time of service in the "Next Date of Service" and "Next Time of Service" fields, respectively.
4. Select the "Contact Person" and "Contact Person Title" options to indicate who the contact person is and their role.
5. Enter the contact person's name, phone number, email, and address in the corresponding fields.
6. Select the "Restraining Order Served" option to indicate whether the order has been served.
7. List any previous service status updates in the "Service Status Updates" field.
8. Enter the date and time of service in the "Date Served" and "Time Served" fields, respectively.
9. Select the options for "Contact Person Email Phone" to indicate whether the contact person has an email and/or phone number.

## Field-by-Field Explanation

* **Restraining Order Status**: Select the current status of the restraining order from the dropdown list.
	+ Options: Active, Complete, Closed

* **Restraining Order Service Status Update**: Briefly describe the service status update.
	+ Type: Text

* **Next Date of Service**: Enter the date of the next service.
	+ Type: Date

* **Next Time of Service**: Enter the time of the next service.
	+ Type: Time

* **Contact Person**: Select the contact person from the dropdown list.
	+ Options: Legal, Police, Other

* **Contact Person Title**: Select the title of the contact person from the dropdown list.
	+ Options: Legal, Police, Other

* **Contact Person Name**: Enter the name of the contact person.
	+ Type: Text

* **Contact Person Phone**: Enter the contact person's phone number.
	+ Type: Text

* **Contact Person Email**: Enter the contact person's email.
	+ Type: Email

* **Contact Person Email Phone**: Select whether the contact person has an email and/or phone number.
	+ Options: Yes, No

* **Contact Person Address**: Enter the contact person's address.
	+ Type: Text

* **Restraining Order Number**: Enter the number of the restraining order.
	+ Type: Text

* **Service Status Updates**: List any previous service status updates.
	+ Type: Text

* **Restraining Order Served**: Select whether the restraining order has been served.
	+ Options: True, False

* **Date Served**: Enter the date the restraining order was served.
	+ Type: Date

* **Time Served**: Enter the time the restraining order was served.
	+ Type: Time

* **Assigned Officer**: Enter the name of the assigned officer.
	+ Type: Text

* **Assigned Officer Title**: Select the title of the assigned officer from the dropdown list.
	+ Options: Legal, Police, Other

* **Notes**: Enter any additional comments or details.
	+ Type: Text

* **Date Last Updated**: Enter the date the form was last updated.
	+ Type: Date

* **Date Last Status Update**: Enter the date of the last status update.
	+ Type: Date

* **Restraining Order Service Status**: Select the current service status from the dropdown list.
	+ Options: Active, Complete, Closed
