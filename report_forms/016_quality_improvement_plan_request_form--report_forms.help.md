# Quality Improvement Plan Request Form - Help Guide

## Purpose
This form is used to submit a Quality Improvement Plan (QIP) proposal, which is a document used to propose changes or enhancements to improve the quality of a product, process, or service.

## How To Complete This Form

1. **Quality Improvement Plan Request** (Page 1)
	* A brief overview of the improvement proposal.
2. **Additional Comments** (Page 2)
	* If needed, add any additional comments or information to support your proposal.
3. **Quality Improvement Proposal Title** (Page 3)
	* A clear and concise title for your proposal.
4. **Quality Improvement Proposal Description** (Page 4)
	* A detailed description of the proposal, including the expected outcome.
5. **Quality Improvement Proposal Category** (Page 5)
	* Choose from: 
		+ Improvement
		+ Enhancement
		+ Change Request
6. **Quality Improvement Proposal Impact** (Page 6)
	* Choose from:
		+ High
		+ Medium
		+ Low
7. **Quality Improvement Proposal Priority** (Page 7)
	* Enter a number from 1-10, indicating the level of priority.
8. **Quality Improvement Proposal Owner** (Page 8)
	* Enter the email address of the person responsible for the proposal.
9. **Quality Improvement Proposal Due Date** (Page 9)
	* Enter the due date for the proposal.
10. **Quality Improvement Proposal Status** (Page 10)
	* Choose from:
		+ New
		+ In Progress
		+ Completed
11. **Quality Improvement Proposal Comments** (Page 11)
	* Additional comments or information about the proposal.

## Field-by-Field Explanation

* **Quality Improvement Plan Request**:
	+ A brief overview of the improvement proposal.
* **Additional Comments**:
	+ If needed, add any additional comments or information to support your proposal.
* **Quality Improvement Proposal Title**:
	+ A clear and concise title for your proposal.
* **Quality Improvement Proposal Description**:
	+ A detailed description of the proposal, including the expected outcome.
* **Quality Improvement Proposal Category**:
	+ The type of proposal, which can be:
		- Improvement
		- Enhancement
		- Change Request
* **Quality Improvement Proposal Impact**:
	+ The expected impact of the proposal, which can be:
		- High
		- Medium
		- Low
* **Quality Improvement Proposal Priority**:
	+ A number from 1-10, indicating the level of priority.
* **Quality Improvement Proposal Owner**:
	+ The email address of the person responsible for the proposal.
* **Quality Improvement Proposal Due Date**:
	+ The due date for the proposal.
* **Quality Improvement Proposal Status**:
	+ The current status of the proposal, which can be:
		- New
		- In Progress
		- Completed
* **Quality Improvement Proposal Comments**:
	+ Additional comments or information about the proposal.
