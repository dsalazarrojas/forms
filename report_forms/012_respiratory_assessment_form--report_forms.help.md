# Respiratory Assessment Form - Help Guide
## Purpose
The Respiratory Assessment Form is designed to collect information about a patient's respiratory system and medical condition. It is intended to be used by healthcare professionals to assess a patient's respiratory status and identify potential respiratory issues.

## How To Complete This Form
To complete this form, follow these steps:

* Enter the patient's name in the "Patient Name" field.
* Provide any relevant medical history in the "Medical History" field, if applicable.
* Answer "Yes" or "No" to the question "Respiratory Symptoms", indicating if the patient is experiencing respiratory symptoms.
* Enter the patient's current lung function, if applicable, in the "Lung Function" field.
* Enter the patient's oxygen saturation level, if applicable, in the "Oxygen Saturation" field.
* Enter the patient's respiratory rate, if applicable, in the "Respiratory Rate" field.
* Select the method of oxygen delivery from the "Oxygen Delivery Method" dropdown menu.
* Select all applicable breathing difficulties from the "Breathing Difficulties" dropdown menu.
* Select the patient's current respiratory status from the "Respiratory Status" dropdown menu.
* Select all applicable medical conditions from the "Medical Condition" dropdown menu, if applicable.
* Enter the patient's oxygen level, if applicable, in the "Oxygen Level" field.
* Enter the patient's heart rate, if applicable, in the "Heart Rate" field.
* Select the patient's blood pressure, if applicable, from the "Blood Pressure" dropdown menu.
* Enter the patient's respiratory rate, if applicable, in the "Respiratory Rate 1" field.
* Enter the patient's respiratory rate, if applicable, in the "Respiratory Rate 2" and "Respiratory Rate 3" fields.
* Enter the patient's oxygen level, if applicable, in the "Oxygen Level 2" and "Oxygen Level 3" fields.
* Select the patient's blood pressure, if applicable, from the "Blood Pressure 2" and "Blood Pressure 3" dropdown menus.
* Select the patient's respiratory status, if applicable, in the "Respiratory Status 2" field.
* Select all applicable medical conditions, if applicable, from the "Medical Condition 2" dropdown menu.

## Field-by-Field Explanation

* **Patient Name** (`patient_name`, text, required): Enter the patient's name.
* **Medical History** (`medical_history`, note, optional): Provide any relevant medical history for the patient.
* **Respiratory Symptoms** (`respiratory_symptoms`, select_one, optional): Answer "Yes" or "No" to indicate if the patient is experiencing respiratory symptoms.
* **Lung Function** (`lung_function`, number, optional): Enter the patient's current lung function.
* **Oxygen Saturation** (`oxygen_saturation`, number, optional): Enter the patient's oxygen saturation level.
* **Respiratory Rate** (`respiratory_rate`, number, optional): Enter the patient's respiratory rate.
* **Oxygen Delivery Method** (`oxygen_delivery_method`, select_one, required): Select the method of oxygen delivery used by the patient.
* **Breathing Difficulties** (`breathing_difficulties`, select_multiple, required): Select all applicable breathing difficulties experienced by the patient.
* **Respiratory Status** (`respiratory_status`, select_one, required): Select the patient's current respiratory status.
* **Medical Condition** (`medical_condition`, select_multiple, optional): Select all applicable medical conditions for the patient.
* **Oxygen Level** (`oxygen_level`, number, optional): Enter the patient's oxygen level.
* **Heart Rate** (`heart_rate`, number, optional): Enter the patient's heart rate.
* **Blood Pressure** (`blood_pressure`, select_multiple, optional): Select the patient's blood pressure.
* **Respiratory Rate 1** (`respiratory_rate_1`, number, optional): Enter the patient's respiratory rate 1.
* **Respiratory Rate 2** (`respiratory_rate_2`, number, optional): Enter the patient's respiratory rate 2.
* **Respiratory Rate 3** (`respiratory_rate_3`, number, optional): Enter the patient's respiratory rate 3.
* **Oxygen Level 2** (`oxygen_level_2`, number, optional): Enter the patient's oxygen level 2.
* **Blood Pressure 2** (`blood_pressure_2`, select_multiple, optional): Select the patient's blood pressure 2.
* **Respiratory Rate 4** (`respiratory_rate_4`, number, optional): Enter the patient's respiratory rate 4.
* **Respiratory Rate 5** (`respiratory_rate_5`, number, optional): Enter the patient's respiratory rate 5.
* **Oxygen Level 3** (`oxygen_level_3`, number, optional): Enter the patient's oxygen level 3.
* **Blood Pressure 3** (`blood_pressure_3`, select_multiple, optional): Select the patient's blood pressure 3.
* **Respiratory Status 2** (`respiratory_status_2`, select_one, optional): Select the patient's respiratory status 2.
* **Medical Condition 2** (`medical_condition_2`, select_multiple, optional): Select all applicable medical conditions for the patient.

**Tips**

* This form should only be filled out by authorized personnel.
* Double-check all answers for accuracy and completeness.
* Consult medical guidelines and supervisor for guidance on any unclear questions.
* Please ensure that a patient's previous respiratory assessment form has not been submitted before filling out this form.
