# Inverter Service Report - Help Guide
## Purpose
The Inverter Service Report is a form used to report on inverter service visits. This form helps track the status of inverters, service visits, and any additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as indicated by the asterisk (\*) symbol. The "Inverter Status" field is required to ensure that you accurately report the inverter's status.
2. If a service visit needs to be updated, create a new report and make changes as necessary.
3. Ensure that you submit only one report per service visit.

## Field-by-Field Explanation

* **Inverter Service Visit**: This field is a note field for you to describe the service visit in as much detail as needed. 
* **Date**: Enter the date of the service visit. 
* **Technician Name**: Enter the name of the technician who performed the service visit. 
* **Inverter Model**: Enter the model number of the inverter that was serviced. 
* **Service Visit Date**: Enter the date the service visit took place. 
* **Service Start Time**: Enter the start time of the service visit. 
* **Service End Time**: Enter the end time of the service visit. 
* **Inverter Status**: Select the current status of the inverter (Working, Non-Working, Unknown). 
* **Notes**: Enter any additional comments or notes about the service visit. 

## Tips
* Double-check that all required fields are completed before submitting the report.
* If you need to report multiple service visits, create multiple reports.
