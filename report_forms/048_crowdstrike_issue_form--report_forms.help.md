# CrowdStrike Issue Form - Help Guide
## Purpose
The CrowdStrike Issue Form is a tool for customers to report and track technical issues related to our platform. It helps our support team to identify and resolve problems efficiently.

## How To Complete This Form
1. Enter your name or contact information in the "Customer" field.
2. Provide a detailed description of the issue in the "Description" field.
3. Select the type of issue you are experiencing from the options in the "Issue" field.
4. If applicable, enter the date and time of when you first encountered the issue in the "Date" and "Time" fields.
5. Provide your email address in the "Email" field (optional, but recommended for follow-up communication).
6. Enter your phone number in the "Phone" field (optional).
7. Provide additional comments or notes about the issue in the "Comments" field (optional).
8. Attach any relevant files or screenshots to the "Attachment" field (optional).
9. Select the tool that is currently being used to resolve the issue from the options in the "Assigned Tool" field.
10. Tag your issue with relevant keywords from the options in the "Tags" field.
11. Select the current status of the issue from the options in the "Status" field.
12. If the issue has been resolved, enter the name of the person or team that resolved it in the "Resolved By" field.
13. If applicable, enter the date when the issue was resolved in the "Resolved Date" field.

## Field-by-Field Explanation
### Customer (1)
* **Customer**: Enter your name or contact information, so we can get back to you.
### Description (2)
* **Description**: Provide a detailed description of the issue, including error messages, screenshots, or steps to reproduce.
### Issue (3)
* **Issue**: Select the type of issue you are experiencing (Bug, Problem, or Error).
### Date (4)
* **Date**: If you are reporting a recurring issue, enter the date you first encountered it.
### Time (5)
* **Time**: If you are reporting a time-specific issue, enter the time of when you first encountered it.
### Email (6)
* **Email**: Enter your email address, so we can contact you for follow-up questions or updates.
### Phone (7)
* **Phone**: Enter your phone number, so we can reach out to you if needed.
### Note (8)
* **Note**: Provide additional comments or notes about the issue.
### Issue Type (9)
* **Issue Type**: Select the type of issue related to our platform (Software, Hardware, Configuration).
### Environment (10)
* **Environment**: Select the environment where you are experiencing the issue (Local, Cloud, Cluster).
### Reporter (11)
* **Reporter**: Enter your name, so we can get back to you.
### Comments (12)
* **Comments**: Provide additional comments or notes about the issue.
### Attachment (13)
* **Attachment**: Attach any relevant files or screenshots.
### Assigned Tool (14)
* **Assigned Tool**: Select the tool currently being used to resolve the issue.
### Tags (15)
* **Tags**: Select relevant keywords to help us identify the issue.
### Status (16)
* **Status**: Select the current status of the issue (To-Do, In Progress, Done).
### Resolved By (17)
* **Resolved By**: Enter the name of the person or team that resolved the issue (if applicable).
### Resolved Date (18)
* **Resolved Date**: Enter the date when the issue was resolved (if applicable).
