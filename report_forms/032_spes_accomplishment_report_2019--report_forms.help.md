# Spes Accomplishment Report 2019 - Help Guide

## Purpose
The Spes Accomplishment Report 2019 is a form designed to track and document the progress of tasks, projects, or activities within an organization. It helps to record the start and end dates, times, locations, and other relevant details of accomplishments, and also allows for the submission and review of these reports by authorized personnel.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form fields as required by your organization or task requirements.
2. Enter the start and end dates of the activity or project.
3. Select the location where the activity or project took place.
4. Describe the activity or project in the "Notes" field.
5. Indicate if the activity or project is an accomplishment by selecting "Yes" or "No" in the "Activity" field.
6. Choose the current status of the accomplishment from the options provided in the "Accomplishment Status" field.
7. Optionally, add any comments or feedback in the "Comments" field.
8. Enter the name of the person who submitted the report in the "Submitted By" field.
9. Record the date and time when the report was submitted.
10. Identify the person responsible for reviewing the report in the "Reviewer" field.
11. Add any review comments or feedback in the "Review Comments" field.
12. Select the current approval status of the report from the options provided in the "Approval Status" field.

## Field-by-Field Explanation
* **Title**: (Text Field, Required, No Hint Available)
	+ The title of the report should accurately reflect the name of the activity or project.
* **Start Date**: (Date Field, Optional, No Hint Available)
	+ The start date of the activity or project.
* **End Date**: (Date Field, Optional, No Hint Available)
	+ The end date of the activity or project.
* **Start Time**: (Time Field, Optional, No Hint Available)
	+ The start time of the activity or project.
* **End Time**: (Time Field, Optional, No Hint Available)
	+ The end time of the activity or project.
* **Location**: (Text Field, Optional, No Hint Available)
	+ The location where the activity or project took place.
* **Notes**: (Text Field, Optional, No Hint Available)
	+ A description of the activity or project.
* **Activity**: (Select Multiple, Optional, Yes/No)
	+ Indicate if the activity or project is an accomplishment.
* **Accomplishment Status**: (Select One, Optional, Active/Inactive)
	+ The current status of the accomplishment.
* **Comments**: (Text Field, Optional, No Hint Available)
	+ Any comments or feedback about the activity or project.
* **Submitted By**: (Text Field, Optional, No Hint Available)
	+ The name of the person who submitted the report.
* **Submitted On**: (Date Field, Optional, No Hint Available)
	+ The date and time when the report was submitted.
* **Submitted Time**: (Time Field, Optional, No Hint Available)
	+ The time when the report was submitted.
* **Reviewer**: (Text Field, Optional, No Hint Available)
	+ The name of the person responsible for reviewing the report.
* **Review Comments**: (Text Field, Optional, No Hint Available)
	+ Any comments or feedback from the reviewer.
* **Approval Status**: (Select One, Optional, Active/Inactive)
	+ The current approval status of the report.
