# Pest Control Service Report - Help Guide
## Purpose
The Pest Control Service Report form is used to document and record the details of pest control services provided to clients.

## How To Complete This Form
To complete this form, follow these steps:
1. Ensure you are only submitting reports for services that have not been previously reported for the same property.
2. Select the **on site treatments** field and enter a brief description of the on-site treatments performed.
3. In the **pest control teams** field, select the team that performed the service.
4. Enter the **property manager** name and contact information (if available).
5. Select the **homeowner** from the list of available options (if applicable).
6. Enter the **date of treatment** and **time of treatment** fields using the date and time pickers (if applicable).
7. Add any relevant **notes** about the service, if applicable.

## Field-by-Field Explanation
* **on site treatments**: A field to enter a brief description of the on-site treatments performed. This could be a list of services performed, chemicals used, or any other relevant details. 
* **Pest Control Teams**: Select the team that performed the service from the list of available options. This information will help track which team performed the service.
* **Property Manager**: Enter the name and contact information of the property manager. If the property manager does not have contact information, you can leave this field empty.
* **Homeowner**: Select the homeowner who received the service from the list of available options. If no homeowner is listed, or the service was performed without a homeowner, leave this field empty.
* **Date of Treatment**: Use the date picker to select the date the service was performed.
* **Time of Treatment**: Use the time picker to select the time the service was performed.
* **Notes**: Add any additional notes about the service, if applicable.

## Tips
* Ensure you are only submitting reports for services that have not been previously reported for the same property.
* If you are unsure about any information, please contact your supervisor for clarification.
