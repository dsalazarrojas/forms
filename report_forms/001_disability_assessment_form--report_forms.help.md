# Disability Assessment Form - Help Guide

## Purpose
The Disability Assessment Form is a critical tool used to assess and document a student's disability status and its impact on their academic performance. This form helps gather essential information about a student's condition, which can be used to determine reasonable accommodations that can be made to support their success in academic settings.

## How To Complete This Form
To complete this form accurately, follow these steps:

1. Ensure you have all the necessary information and support to fill out the form, such as relevant medical documentation or expert assessment.
2. Fill out the Student ID field with the student's unique identifier.
3. Enter the student's name in the Student Name field.
4. Answer the question about the student's disability type by selecting "Yes" or "No" from the dropdown menu.
5. Provide a brief description of the student's disability in the Disability Description field, if applicable.
6. Describe the impact of the disability on the student's academic performance in the Impact on Academic Performance field.
7. Enter the date of the assessment in the Assessment Date field.
8. Add any next steps or recommendations for the student in the Next Steps field, if applicable.
9. If necessary, provide comments from the student or other professionals in the Student Comments and Professional Comments fields.

## Field-by-Field Explanation

* **Student ID (id: 1)**: Enter the student's unique identifier.
* **Student Name (id: 2)**: Enter the student's name.
* **Disability Type (id: 3)**: Answer "Yes" if the student has a disability, or "No" if they do not. This question is used to determine whether the student requires accommodations.
* **Disability Description (id: 4)**: Provide a brief description of the student's disability, if applicable.
* **Functional Limitation (id: 5)**: Describe any functional limitations the student may experience as a result of their disability.
* **Impact on Academic Performance (id: 6)**: Describe how the student's disability affects their academic performance.
* **Assessment Date (id: 7)**: Enter the date the assessment was conducted.
* **Next Steps (id: 8)**: Suggest any next steps or recommendations for the student, if applicable.
* **Student Comments (id: 9)**: Provide comments or feedback from the student, if applicable.
* **Professional Comments (id: 10)**: Add comments or feedback from professionals, such as teachers or counselors, if applicable.
