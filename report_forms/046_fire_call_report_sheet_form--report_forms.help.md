# Fire Call Report Sheet Form - Help Guide
## Purpose
This form is used to document fire calls where the fire department has responded, including the incident date, type, location, status, and details of the incident.

## How To Complete This Form

1. Select the correct date for the incident.
2. Choose the type of fire call from the dropdown menu (e.g., fire call, other, etc.).
3. Enter the precise location where the incident occurred.
4. Select multiple incident types (if applicable, e.g., engine fire, building fire, etc.).
5. Update the status of the incident.
6. Provide a description of the incident.
7. Choose the response team that was dispatched.
8. Enter a unique call number assigned to the incident.
9. Enter the unit number (if available).
10. Enter a unique incident ID (if assigned).

## Field-by-Field Explanation
* **Incident Date (Page 1)**: The date the incident occurred. Please enter the exact date in the format of MM/DD/YYYY.
* **Call Type (Page 1)**: Select the type of fire call from the options provided (e.g., Fire Call, Other, etc.). This will help categorize the incident for reporting and response purposes.
* **Incident Location (Page 1)**: Enter the precise location where the incident occurred, including the address or a brief description of the area.
* **Incident Type (Page 1)**: Select multiple incident types that apply (e.g., Engine Fire, Building Fire, etc.). This will help identify the scope and severity of the incident.
* **Incident Status (Page 1)**: Update the status of the incident as it currently stands (e.g., Active, In Progress, Completed).
* **Incident Description (Page 1)**: Provide a detailed description of the incident, including any relevant details or context.
* **Response Team (Page 1)**: Choose the response team that was dispatched to the incident (e.g., Engine, Ladder, Rescue).
* **Call Number (Page 1)**: Enter the unique call number assigned to the incident, if applicable.
* **Unit Number (Page 1)**: Enter the unit number (if available).
* **Incident ID (Page 1)**: Enter a unique incident ID, if assigned.

## Tips
* Please ensure that you're submitting accurate and relevant information.
* If you're unsure about any field, please consult with a fire department supervisor or employee for clarification.
* This form is intended for fire department employees only; if you're not a fire department employee, please do not submit this form.
