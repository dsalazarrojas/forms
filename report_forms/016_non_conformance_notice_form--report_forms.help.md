# Non Conformance Notice Form - Help Guide
## Purpose
The Non Conformance Notice Form is a document used to report incidents or events 
that occur during non-conformance inspections. It helps to record and track 
non-conformances encountered during the inspection process.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter a brief description of the non-conformance topic in the **Non 
Conformance Topic** field.
2. Provide additional comments or details about the non-conformance in the 
**Comments** field.
3. Indicate whether or not files were attached to support your non-conformance 
report by selecting **Yes** or **No** in the **Attached Files** field.
4. Add any additional comments or details about the non-conformance in the 
**Comments** field (this field is identical to the one above, it's meant to 
allow for further elaboration of comments if needed).

## Field-by-Field Explanation
* **Non Conformance Topic** (`non_conformance_topic`, text, optional): A short 
description of the non-conformance topic being reported.
* **Comments** (`comments`, text, optional): Additional comments or details 
about the non-conformance.
* **Attached Files** (`attached_files`, select_multiple, optional): 
Indicates if files were attached to support the non-conformance report. 
Select "Yes" if files were uploaded, "No" otherwise.
* **Comments** (`comments`, text, optional): Identical to the **Comments** 
field above, meant for further elaboration of comments if needed.
* **Signature** (`signature`, text, optional): Optional field for a 
signature, but not currently required.

## Tips
* Please provide as much detail as possible in the **Comments** fields to help 
the reviewer understand the non-conformance reported.
* Be sure to check the "Attached Files" field to ensure that files were 
uploaded correctly.
* If a signature is required by your organization's policies, please use 
the **Signature** field to add it.
* Submit the form once, as duplicates may be considered unnecessary and 
can cause confusion.
