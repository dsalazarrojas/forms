# Patrol Report Form - Help Guide
## Purpose
The Patrol Report Form is a reporting tool for law enforcement or security personnel to document their daily patrol activities. It captures essential information such as the start date, officer's details, and location of the patrol.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the start date of your patrol from the calendar.
2. Enter your officer's name and ID number in the corresponding fields.
3. If applicable, provide the call number for any incidents or actions taken during the patrol.
4. Enter the date of the patrol in the date field.
5. Enter the time of the patrol in the time field.
6. Provide the location of the patrol in the location field.
7. Add any additional notes about the patrol in the notes field.

## Field-by-Field Explanation
* **Start**: Select the start date of your patrol from the calendar.
* **Officer** (`officer_name`): Enter your officer's name in this field. This is a required field.
* **Officer ID** (`officer_number`): Enter your officer's ID number in this field.
* **Call Number** (`call_number`): Enter any call numbers for incidents or actions taken during the patrol.
* **Date**: Enter the date of the patrol in the date field. This is a required field.
* **Time** (`time`): Enter the time of the patrol in the time field. This is a required field.
* **Location** (`location`): Provide the location of the patrol in this field. This is a required field.
* **Notes** (`notes`): Add any additional notes or comments about the patrol in this field.
