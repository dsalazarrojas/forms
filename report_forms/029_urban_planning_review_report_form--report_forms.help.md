# Urban Planning Review Report Form - Help Guide
## Purpose
This form is used to review and track projects within an urban planning context. It is designed to gather necessary information for project management and tracking.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **project name** in the "Project Name" field.
2. Provide a brief description of the project in the "Project Description" field.
3. Enter the project's **location** in the "Project Location" field.
4. Enter the contact person's name and title in the "Project Contact" field.
5. Enter the name of the project officer responsible for the project in the "Project Officer" field.
6. Select the current **status** of the project from the options provided in the "Project Status" field.
7. Enter the date of the project's current status in the "Status Date" field using the YYYY-MM-DD format.
8. If needed, provide any additional notes or comments about the project in the "Project Notes" field.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, required: false): Enter the name of the project.
* **Project Location** (`project_location`, text, required: false): Enter the location of the project.
* **Project Description** (`project_description`, note, required: false): Provide a brief description of the project.
* **Project Contact** (`project_contact`, text, required: false): Enter the contact person's name and title.
* **Project Officer** (`project_officer`, text, required: false): Enter the name of the project officer responsible for the project.
* **Project Status** (`project_status`, select_one, required: false): Select the current status of the project from the options provided.
    *   Approved
    *   Rejected
    *   Pending
* **Status Date** (`project_status_date`, date, required: false): Enter the date of the project's current status in the YYYY-MM-DD format.
* **Project Notes** (`project_notes`, note, required: false): If needed, provide any additional notes or comments about the project.
