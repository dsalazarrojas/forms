# End Of Work Day Report - Help Guide
## Purpose
The End Of Work Day Report form is used to record your status and progress at the end of each workday. This report helps the team or manager understand your work status, tasks completed, and goals achieved, facilitating better communication and collaboration.

## How To Complete This Form
To complete this form, follow these steps:
1. Select your current status from the "Status" field.
2. Enter any tasks you've completed, if applicable.
3. If you've completed a task, enter the task ID and name.
4. Enter the start time and duration of the task, if applicable.
5. Enter any goals you've completed, if applicable.
6. If you've completed a goal, enter the goal ID and name.
7. Enter the start time and duration of the goal, if applicable.
8. Add any additional notes or comments, if needed.
9. Enter your email address, if you want to receive any updates or reminders.

## Field-by-Field Explanation
* **Report Form**: This is the main form section where you'll enter your information.
* **Status**: Select your current status (Active, Inactive, Completed, On Break, On Leave, or On Training).
* **Tasks Completed**: Enter the tasks you've completed, if any.
* **Task Id**: Enter the ID of the completed task.
* **Task Name**: Enter the name of the completed task.
* **Start Time**: Enter the start time of the task, in the format of 24-hour clock (HH:MM).
* **Duration**: Enter the duration of the task, in hours.
* **Goals Completed**: Enter the goals you've achieved, if any.
* **Goal Id**: Enter the ID of the completed goal.
* **Goal Name**: Enter the name of the completed goal.
* **Start Time**: Enter the start time of the goal, in the format of 24-hour clock (HH:MM).
* **Duration**: Enter the duration of the goal, in hours.
* **Notes**: Add any additional comments or notes about your workday.
* **Email**: Enter your email address, if you want to receive any updates or reminders.

Tips:
* Make sure to enter accurate and clear information for each field.
* If you're unsure about any field or its requirements, please refer to the field-by-field explanation above.
* This form is meant to be completed at the end of each workday, so please fill it out accordingly.
* If you have any questions or need help with this form, feel free to contact your team or manager.
