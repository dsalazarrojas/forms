# Distribution Error Investigation Report Form - Help Guide
## Purpose
This form is designed to document and investigate distribution errors, track progress, and provide space for notes and recommendations.

## How To Complete This Form

1. **Date of Incident**: Please fill in the date when the distribution error occurred or when it was first noticed.
2. **Description of Incident**: Provide a brief description of the distribution error, including any relevant details.
3. **Distribution Error Details**: Describe the distribution error in more detail, including any steps taken to correct it.
4. **Root Cause**: Identify the root cause of the distribution error.
5. **Action Taken**: Describe any actions taken to correct the distribution error.
6. **Lessons Learned**: Share any lessons learned from the distribution error.
7. **Recommendations**: Suggest any recommendations to improve the distribution process.
8. **Distribution Error Investigation Status**: Choose the current status of the investigation (Pending, In Progress, Completed).
9. **Distribution Error Investigation Status 2**: Choose all statuses that apply (Pending, In Progress, Completed).
10. **Follow Up Details**: If a follow-up is necessary, provide the details.
11. **Notes**: Add any additional notes or comments about the distribution error.
12. **Follow Up Schedule**: If a follow-up is necessary, provide the schedule for it.
13. **Follow Up Due Date**: Set the due date for the next follow-up.
14. **Follow Up Contact**: Provide the contact information for the follow-up.
15. **Follow Up Status**: Choose the status of the follow-up (Pending, Completed).
16. **Next Follow Up Due Date**: Set the due date for the next follow-up.
17. **Next Follow Up Contact**: Provide the contact information for the next follow-up.
18. **Next Follow Up Schedule**: Provide any schedule information for the next follow-up.
19. **Follow Up Frequency**: Describe the frequency of follow-ups.
20. **Next Follow Up Frequency**: Describe the frequency of next follow-ups.
21. **Last Follow Up Contact**: Provide the contact information for the last follow-up.
22. **Last Follow Up Contact Date**: Set the date of the last follow-up.
23. **Last Follow Up Status**: Choose the status of the last follow-up (Pending, Completed).
24. **Last Follow Up Date**: Set the date of the last follow-up.
