# Group Statistics Submission Form - Help Guide
## Purpose
The Group Statistics Submission Form is designed to collect statistics for specific groups, providing an organized and structured way to gather data about group activities, progress, and accomplishments.

## How To Complete This Form
1. Fill in the required fields:
	* Group Name
	* Reporting Period
	* Group ID (if applicable)
	* Manager Name
	* Manager Email (for contact purposes)
	* Manager Phone (for contact purposes)
2. Select the reporting frequency for the group:
	* Every Week
	* Every Two Weeks
	* Every Four Weeks
3. Fill in the dates for the reporting period:
	* Start Date
	* End Date
4. Upload any supporting documentation if necessary.
5. Add any additional notes or comments about the group's progress.

## Field-by-Field Explanation

* **Group Name** (`group_name`, text, required): Enter the name of the group you are submitting statistics for.
* **Reporting Period** (`reporting_period`, select_one, required): Select the reporting period for the group from the given options.
* **Reporting Frequency** (`reporting_frequency`, select_multiple, required): Select the frequency at which the group reports.
* **Group ID** (`group_id`, number, required): Enter the unique ID for the group.
* **Manager Name** (`manager_name`, text, required): Enter the name of the group manager.
* **Manager Email** (`manager_email`, email, required): Enter the email address of the group manager.
* **Manager Phone** (`manager_phone`, text, required): Enter the phone number of the group manager.
* **Supporting Documentation** (`supporting_documentation`, text, optional): Upload any relevant documentation to support the group's progress.
* **Notes** (`notes`, note, optional): Add any additional comments or notes about the group's progress.

## Tips
* Ensure that you are submitting statistics for the correct group.
* Be thorough and accurate when filling out the form.
* Upload any necessary documentation to support your submission.
