# Government Service Program Audit Form - Help Guide
## Purpose
This form is used to collect information about government services programs. It is intended for government employees or program administrators to evaluate and improve the effectiveness and efficiency of these programs.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter the name of the program** (Program Name): Enter the name of the government service program being audited.
2. **Choose the location of the program** (Program Location): Select the location where the program is being offered.
3. **Select the type of program** (Program Type): Choose whether the program is Public, Private, or Other.
4. **Enter more details about the program** (Program Name Details): Provide any additional information about the program.
5. **Enter the start and end dates of the program** (Program Start Date and Program End Date): Enter the dates when the program started and ended, in the format mm/dd/yyyy.
6. **Evaluate the program** (Program Review): Rate the program's effectiveness (Excellent, Good, Fair, Poor).
7. **Enter your rating and comments** (Program Rating and Program Comments): Enter a rating and any comments you have about the program.
8. **Choose follow-up methods** (Follow-up): Select how you would like to be contacted for further information (Email, Phone, In-person, Other).
9. **Enter any additional comments** (Program Notes): Provide any additional comments about the program.
10. **Make a recommendation** (Program Recommendation): Choose whether you recommend the program (Recommend, No Recommendation).
