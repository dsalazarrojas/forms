# Shipping Report Form - Help Guide
## Purpose
The Shipping Report Form is a tool for documenting and tracking shipping-related information. It helps in maintaining accurate records of shipments, customers, and the shipping process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with the required information, making sure to accurately report on the shipping details.
2. Select the correct options for the "item type" field based on the type of item being shipped (books, parcels, or craft items).
3. Enter the correct shipping method(s) for the package(s) being reported (ground or air).
4. If applicable, provide the customer's name, email, and phone number.
5. Report the number of items in the package and any additional notes or comments.

## Field-by-Field Explanation
* **Report Date** (2): The date on which the report was generated.
* **Dispatch Date** (3): The date on which the package was dispatched or shipped.
* **Item Type** (4): Select the type of item being shipped (books, parcels, or craft items).
* **Item Weight** (5): The weight of the item(s) in kilograms.
* **Package Size** (6): The size of the package.
* **Shipping Method** (7): The method of shipping used for the package (ground or air).
* **Customer Name** (8): The name of the customer (if applicable).
* **Customer Email** (9): The email address of the customer (if applicable).
* **Customer Phone** (10): The phone number of the customer (if applicable).
* **Item Count** (11): The number of items in the package.
* **Notes** (12): Additional comments or notes about the shipping event.
* **Submitted By** (13): The user who submitted the form.
* **Submitted At** (14): The time at which the form was submitted.
* **Submitted Date** (15): The date on which the form was submitted.
* **Item Received Date** (16): The date on which the item was received.
