# Copyright Declaration Form - Help Guide
## Purpose
The Copyright Declaration Form is a document used to record and declare the ownership of a copyrightable work. This form is used to capture critical details about the copyright holder, work, and declaration specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the copyright holder in the "Copyright Holder Name" field.
2. Provide a valid email address in the "Email" field.
3. Enter a valid phone number in the "Phone" field.
4. Fill in the "Declaration Date" field with the date you are declaring the copyright.
5. Enter the time of declaration in the "Declaration Time" field.
6. Provide the location where the declaration is made in the "Declaration Location" field.
7. Write a detailed description of the declaration in the "Declaration Content" field.
8. If applicable, provide the work title in the "Work Title" field.
9. Enter the work license number if applicable in the "Work License Number" field.
10. Finally, sign and date the declaration by entering your signature in the "Declaration Signature" field.

## Field-by-Field Explanation
* **Copyright Holder Name (`copyright_holder_name`, text, required): Enter the name of the person or entity declaring the copyright.**
* **Email (`email`, email, required): A valid email address for contact purposes.**
* **Phone (`phone`, text, required): A valid phone number for contact purposes.**
* **Declaration Date (`declaration_date`, date, required): The date of the declaration.**
* **Declaration Time (`declaration_time`, time, required): The time of the declaration.**
* **Declaration Location (`declaration_location`, text, required): The location where the declaration is made.**
* **Declaration Content (`declaration_content`, text, required): A detailed description of the declaration.**
* **Work Title (`work_title`, text, optional): The title of the work being declared.**
* **Work License Number (`work_license_number`, text, optional): The license number associated with the work, if applicable.**
* **Declaration Signature (`declaration_signature`, text, required): Sign and date the declaration.**
* **Declaration Notary (`declaration_notary`, text, optional): The notary or witness of the declaration, if applicable.**
* **Declaration Witness (`declaration_witness`, text, optional): The witness of the declaration, if applicable.**
* **Declaration Date of Birth (`declaration_date_of_birth`, date, optional): The date of birth of the copyright holder, if applicable.**
* **Declaration Place of Birth (`declaration_place_of_birth`, text, optional): The place of birth of the copyright holder, if applicable.**
* **Declaration Country of Birth (`declaration_country_of_birth`, text, optional): The country of birth of the copyright holder, if applicable.**
* **Declaration Place of Work (`declaration_place_of_work`, text, optional): The place of work of the copyright holder, if applicable.**
* **Declaration Employment Status (`declaration_employment_status`, select_one, required): The employment status of the copyright holder.**
* **Declaration Employment Type (`declaration_employment_type`, text, optional): The type of employment of the copyright holder, if applicable.**
* **Declaration Employment Start Date (`declaration_employment_start_date`, date, optional): The start date of employment of the copyright holder, if applicable.**
* **Declaration Employment End Date (`declaration_employment_end_date`, date, optional): The end date of employment of the copyright holder, if applicable.**
* **Declaration Employment Location (`declaration_employment_location`, text, optional): The location of work of the copyright holder, if applicable.**
* **Declaration Employment Status Change (`declaration_employment_status_change`, text, optional): The employment status change of the copyright holder, if applicable.**
* **Declaration Employment Status Details (`declaration_employment_status_details`, text, optional): Additional details about the employment status of the copyright holder, if applicable.**
* **Declaration Work License (`declaration_work_license`, text, optional): The work license number of the copyright holder, if applicable.**
* **Declaration Work License Number (`declaration_work_license_number`, text, optional): The license number associated with the work, if applicable.**

## Tips
* Ensure that all required fields are filled in accurately and completely.

* Review the declaration carefully before signing it to ensure that all information is correct and complete.
