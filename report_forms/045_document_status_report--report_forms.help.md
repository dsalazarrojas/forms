# Document Status Report - Help Guide
## Purpose
The Document Status Report form is used to collect and track information about the current status of a document within a project or workflow.

## How To Complete This Form
1. Select the owner of the document from the options provided.
2. Enter the deadline for the document, if applicable.
3. Choose the current progress of the document from the options provided.
4. Add any additional comments related to the document status.
5. Select the document type from the options provided.
6. Choose the current document status from the options provided.
7. Select the person who last updated the document status.
8. Enter the date and time of the last update.
9. Enter the due date and time for the document.
10. Add any additional comments for the document status report.

## Field-by-Field Explanation
* **Document Status Report** (`document_status_report`, text, optional): A field for adding any additional comments about the document status report.
* **Owner** (`owner`, select_one, optional): The person responsible for the document.
* **Deadline** (`deadline`, date, optional): The deadline for the document.
* **Progress** (`progress`, select_multiple, optional): The current progress of the document (Not Started, In Progress, Done).
* **Comments** (`comments`, text, optional): Additional comments about the document status.
* **Document ID** (`document_id`, number, optional): The identifier for the document (if applicable).
* **Document Name** (`document_name`, text, optional): The name of the document.
* **Document Type** (`document_type`, select_one, optional): The type of the document (Type1, Type2, Type3).
* **Document Status** (`document_status`, select_multiple, optional): The current status of the document (Not Started, In Progress, Done).
* **Updated by** (`updated_by`, select_one, optional): The person who last updated the document status.
* **Updated at** (`updated_at`, date, optional): The date of the last update.
* **Updated Time** (`updated_time`, time, optional): The time of the last update.
* **Due Date** (`due_date`, date, optional): The due date for the document.
* **Due Time** (`due_time`, time, optional): The due time for the document.
* **Document Status Comments** (`document_status_comments`, text, optional): Additional comments about the document status.
* **Document Status Report Comments** (`document_status_report_comments`, text, optional): Additional comments for the document status report.
