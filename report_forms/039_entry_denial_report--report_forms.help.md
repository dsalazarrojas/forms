# Entry Denial Report - Help Guide
## Purpose
The Entry Denial Report is used to document reasons for entry denials, providing a brief explanation and supporting evidence. This report helps in understanding why an entry was denied or rejected.

## How To Complete This Form
1. Review the entry denial reason(s) and ensure you have a clear understanding of the issue.
2. Select the relevant reason(s) for denial from the "reasons_for_denial_1" dropdown.
3. Provide a brief explanation of the denial reason(s) in the "capture_evidence_description" field.
4. Add any supporting evidence in the "capture_evidence" field.
5. Describe the incident in the "incident" field.
6. Select the relevant option from the "reasons_for_denial" dropdown.
7. Provide any additional reasons for denial in the "capture_reasons_for_denial" field.

## Field-by-Field Explanation
* **Reasons for Denial 1** (`reasons_for_denial_1`, select multiple, optional):
	+ Select the reason for denial from the dropdown list.
* **Uploaded Evidence** (`uploaded_evidence`, text, optional):
	+ Provide any supporting evidence for the entry denial.
* **Capture Evidence Description** (`capture_evidence_description`, text, optional):
	+ Briefly explain the denial reason(s) for the entry.
* **Incident** (`incident`, text, optional):
	+ Describe the incident related to the entry denial.
* **Capture Evidence** (`capture_evidence`, text, optional):
	+ Add any additional evidence to support the denial reason(s).
* **Reasons for Denial** (`reasons_for_denial`, select one, optional):
	+ Select the reason for denial from the dropdown list.
* **Capture Reasons for Denial** (`capture_reasons_for_denial`, text, optional):
	+ Provide any additional reasons for denial.

Note: The form fields are ordered from 1 to 7 to match the ID provided in the YAML input schema.
