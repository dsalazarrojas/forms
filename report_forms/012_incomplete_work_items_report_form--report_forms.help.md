# Incomplete Work Items Report Form - Help Guide
## Purpose
This form is designed to collect information about incomplete work items for reporting and management purposes.

## How To Complete This Form

To use this form, follow these steps:

* Select the category of the work item from the dropdown menu.
* Enter a brief description of the work item.
* Select the user assigned to the work item from the dropdown menu.
* Enter the date the report was submitted.
* Select the status of the work item (e.g., new, in progress, done).
* Enter any additional comments or notes on the work item.
* Select the user who submitted the report.
* Select multiple work items to be included in the report.
* Select multiple IDs of work items to be included in the report.
* Select multiple status of work items to be included in the report.
* Select the priority level of the work item.
* Enter the due date and due time of the work item.

## Field-by-Field Explanation

* **Category (incomplete)**: Select the category of the work item.
* **Form ID (form_id)**: A unique identifier for the form (not applicable for report purposes).
* **Description (description)**: Enter a brief description of the work item.
* **Assigned User (assigned_user)**: Select the user assigned to the work item.
* **Date Submitted (date_submitted)**: Enter the date the report was submitted.
* **Status (status)**: Select the status of the work item (e.g., new, in progress, done).
* **Assigned Tool (assigned_tool)**: Select the tool assigned to the work item (not applicable for report purposes).
* **Comments (comments)**: Enter any additional comments or notes on the work item.
* **Submitted By (submitted_by)**: Select the user who submitted the report.
* **Work Items (work_items)**: Select multiple work items to be included in the report.
* **Work Item IDs (work_item_ids)**: Select multiple IDs of work items to be included in the report.
* **Work Item Status (work_item_status)**: Select multiple status of work items to be included in the report.
* **Work Item Priority (work_item_priority)**: Select the priority level of the work item.
* **Work Item Due Date (work_item_due_date)**: Enter the due date of the work item.
* **Work Item Due Time (work_item_due_time)**: Enter the due time of the work item.
* **Work Item (work_items)**: Select multiple work items to be included in the report.
* **Notes (notes)**: Enter any additional notes on the work item (not applicable for report purposes).
