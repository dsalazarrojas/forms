# Document Handover Form - Help Guide

## Purpose
The Document Handover Form is designed to help you hand over documents to the right people, preventing duplication and ensuring the correct documents are uploaded.

## How To Complete This Form

1. Select the relevant client from the list.
2. Choose the type of document to be handed over.
3. Upload the file containing the document.
4. Enter the date and time the document was uploaded.
5. Enter your email address so we can contact you with further instructions.
6. Enter your phone number so we can contact you if needed.
7. Enter your address so we can send you any further instructions.
8. Review your information to ensure it's accurate before submitting the form.

## Field-by-Field Explanation
* **Company Name** (`document_handover_form_page_1`): Enter the name of your company or organization.
* **Select Client** (`document_handover_form_page_2`): Choose the client for whom the document is intended. This will help us ensure the correct person receives the document.
* **Select Document** (`document_handover_form_page_3`): Select the type of document that needs to be handed over. This will help prevent duplication and ensure the correct document is uploaded.
* **Document Date** (`document_handover_form_page_4`): Enter the date the document was uploaded. This will help us track the document's history.
* **Document Date** (`document_handover_form_page_5`): Enter the time the document was uploaded. This will help us track the document's history.
* **Email** (`document_handover_form_page_6`): Enter your email address so we can contact you with further instructions.
* **Phone** (`document_handover_form_page_7`): Enter your phone number so we can contact you if needed.
* **Address** (`document_handover_form_page_8`): Enter your address so we can send you any further instructions.
* **Select Document Type** (`document_handover_form_page_9`): Choose the type of document that needs to be handed over. This will help us ensure the correct document is uploaded.
* **File Upload 1** (`document_handover_form_page_10`): Upload the file containing the document. Ensure it's the correct file and in the correct format.

## Tips
* Please ensure you have the correct file before uploading it.
* Double-check your information before submitting the form to avoid errors.
* If you're unsure about any field, please ask for clarification.
