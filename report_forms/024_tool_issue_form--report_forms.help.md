# tool_issue_form - Help Guide

## Purpose
This form helps to report and track tool issues for efficient resolution. 

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the tool category and subcategory of the tool with the issue.
2. Provide a detailed description of the problem with the tool.
3. Select the status of the tool (Active or Inactive).
4. If applicable, select where the tool is located (Warehouse, Toolroom, Workshop, or Office).
5. If applicable, provide the serial number of the tool.
6. Date and time of when the issue was discovered.
7. Select who replaced the tool (Employee, Customer, or Other).
8. If applicable, select when the tool was replaced.
9. Select if the tool was reassigned to someone.
10. If applicable, select when the tool was reassigned.
11. Select if the tool has been returned.
12. If applicable, select when the tool was returned.
13. Select if any notes are available.
14. Provide any additional comments regarding the tool issue.

## Field-by-Field Explanation
- **Tool Category**: Select the primary category of the tool (Drill Bit, Hand Tool, Handheld Tool, Machine Tool, Power Tool, or Other).
  * This field is essential in helping to track and categorize tool issues based on the tool's category.
- **Tool Subcategory**: Select the subcategory of the tool (Hammer, Screwdriver, Tape Measure, Level, or Other).
  * This field helps to narrow down the issue to a more specific tool subcategory.
- **Tool Description**: Provide a detailed description of the problem with the tool.
  * This field is crucial in understanding the issue and ensuring it can be resolved efficiently.
- **Status**: Select the status of the tool (Active or Inactive).
  * This field helps to track if the tool is currently usable or not.
- **Location**: Select the location of the tool (Warehouse, Toolroom, Workshop, or Office).
  * This field is essential in knowing where the tool can be retrieved or replaced.
- **Serial Number**: Enter the serial number of the tool (if applicable).
  * This field helps in identifying the tool and tracking its history.
- **Issue Date**: Date when the issue was discovered.
  * This field is crucial in tracking when the issue was first reported.
- **Issue Time**: Time when the issue was discovered.
  * This field helps in tracking when the issue was first reported.
- **Replaced By**: Select who replaced the tool (Employee, Customer, or Other).
  * This field helps in tracking who replaced the tool and when.
- **Replaced Date**: Date when the tool was replaced (if applicable).
  * This field is essential in knowing when the tool was replaced.
- **Reassigned To**: Select if the tool was reassigned to someone else.
  * This field helps in tracking who currently has the tool.
- **Reassigned Date**: Date when the tool was reassigned (if applicable).
  * This field is essential in knowing when the tool was reassigned.
- **Returned**: Select if the tool has been returned (Yes or No).
  * This field helps in tracking if the tool has been returned.
- **Returned Date**: Date when the tool was returned (if applicable).
  * This field is essential in knowing when the tool was returned.
- **Notes**: Provide any additional notes regarding the tool issue.
  * This field is useful for keeping a record of any discussions or follow-up actions.
- **Returned To**: Select if the tool was returned to its original location.
  * This field helps in tracking if the tool was returned to its original location.
- **Returned By**: Select who returned the tool (Yes or No).
  * This field helps in tracking who returned the tool.
- **Returned Status**: Select the status of the tool after return (Active or Inactive).
  * This field helps in tracking the tool's status after return.

## Tips
- Make sure to provide as much detail as possible in each field to ensure efficient resolution of the issue.
- If you are unsure about any field, please don't hesitate to reach out to your supervisor for guidance.
- This form is an essential tool in maintaining a record of tool issues, and your cooperation is greatly appreciated.
