# Performance Test Results Form - Help Guide
## Purpose
The Performance Test Results Form is used to document performance test results for a system. This form provides a structured way to record the date and time the test was run, the duration of the test, and the outcome of the test (pass or fail), along with other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with all required fields (marked with a *) and any other fields you think are relevant to the test.
2. In the "test_results" field, enter a short description of the test results.
3. In the "date_run" field, select the date and time the test was run.
4. In the "test_duration" field, enter the duration of the test in minutes.
5. In the "test_outcome" field, select the outcome of the test (pass, fail, or not applicable).
6. In the "test_results_notes" field, enter any additional notes about the test results.
7. In the "user_name" field, enter your name.
8. In the "user_email" field, enter your email address.
9. In the "test_duration_unit" field, select the unit of time used for the test duration (e.g., "Yes" for yes, "No" for no, but since the field is "select_multiple" type, we will ignore this option).
10. In the "test_results_comments" field, enter any additional comments about the test results.
