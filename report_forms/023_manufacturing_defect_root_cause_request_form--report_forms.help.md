# Manufacturing Defect Root Cause Request Form - Help Guide
## Purpose
This form is intended to be used to report and investigate manufacturing defects. Please only submit one request per incident to ensure accurate tracking and analysis. Before submitting, verify that the incident has not been previously reported and that the form is not a duplicate of an already submitted request.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a brief description of the manufacturing defect that occurred.
2. Indicate whether or not the root cause of the defect has been identified. If yes, select the corresponding option(s) from the list.
3. Provide additional information or context about the defect, if necessary.

## Field-by-Field Explanation

* **Manufacturing Defect Root Cause Request** (`manufacturing_defect_root_cause_request_form`): This is the main field where you will enter a brief description of the manufacturing defect that occurred.
* **root_cause** (`root_cause`): This field is used to indicate whether the root cause of the defect has been identified. If you have identified the root cause, select 'Yes' from the list. If not, select 'No'. 
* **description** (`description`): This field is optional but recommended for providing additional context or information about the defect, such as steps taken to investigate or rectify the issue, or any relevant documentation or images that may be useful for analysis.

## Tips

* Please make sure to provide as much detail as possible about the defect when filling out this form.
* If you are unsure about the root cause, it is okay to select 'No' and submit the form. The team will investigate further to determine the root cause.
* If you are submitting a duplicate request, please note the original incident number in the 'description' field.
