# Pesticide Application Record - Help Guide

## Purpose
This form is used to record pesticide applications, providing a structured way to collect and store details about each application. It helps track and manage applications across different farms, pest control services, or grounds crews.

## How To Complete This Form
1. Enter the date of the pesticide application in the "Pesticide Application Date" field.
2. Choose the Applicator responsible for the application from the dropdown menu.
3. Enter the location where the pesticide was applied.
4. Specify the name of the product used.
5. Provide the Product ID number of the product used.
6. Enter the application rate.
7. Specify the number of acres treated.
8. Enter the number of gallons used.
9. Add any additional notes about the application.
10. Choose the type of entity the application is related to (Farms, Pest Control Services, Grounds Crews).

## Field-by-Field Explanation

* **Pesticide Application Date**: The date of the pesticide application. Select a date from the calendar to ensure accuracy.
* **Applicator**: The person or entity responsible for applying the pesticide. Choose from the dropdown menu to select the correct option.
* **Location**: The place where the pesticide was applied. Enter the exact address or location name.
* **Product Name**: The name of the product used for the application.
* **Product ID**: The unique identifier number of the product used.
* **Rate**: The application rate of the pesticide. Enter the rate in the relevant unit of measurement.
* **Acres Treated**: The number of acres treated with the pesticide. Enter the exact number.
* **Gallons Used**: The number of gallons of the pesticide used. Enter the exact number.
* **Notes**: Any additional comments or notes about the application. Use this field to add any relevant information not captured elsewhere on the form.
* **Farms/Pest Control Services/Grounds Crews**: Choose the type of entity the application is related to.
