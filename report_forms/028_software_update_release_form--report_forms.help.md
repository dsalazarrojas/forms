# Software Update Release Form - Help Guide

## Purpose

This form is used by IT and/or product teams to report new software updates and track their status.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the "Software Update Release" field with a brief description of the software update.
2. Select the "Release Date" of the update.
3. Specify the "Release Version" of the update.
4. Enter the "Release Number" of the update.
5. Fill out the "Product Name" field with the name of the software product.
6. Enter the "Release Description" of the update.
7. Add "Release Notes" about the update.
8. Select the "Release Status" of the update (In Progress, Released, or Cancelled).
9. Fill out the "Submitter" field with your name or ID.
10. Select the "Approver" who will approve the release.
11. Enter your "Email" address for contact purposes.
12. Enter your "Phone" number for additional contact information.
13. Add any "Comments" about the update.

## Field-by-Field Explanation

* **Software Update Release**: A brief description of the software update.
* **Release Date**: Select the date when the software update will be released or has been released.
* **Release Version**: Specify the version number of the software update.
* **Release Number**: Enter the release number of the update.
* **Product Name**: Enter the name of the software product.
* **Release Description**: Enter a brief description of the software update.
* **Release Notes**: Add any additional release notes or information about the update.
* **Release Status**: Select the status of the software update (In Progress, Released, or Cancelled).
* **Submitter**: Enter your name or ID as the submitter of the update.
* **Approver**: Select the person who will approve the software update.
* **Email**: Enter your email address for contact purposes.
* **Phone**: Enter your phone number for additional contact information.
* **Comments**: Add any additional comments or information about the software update.

## Tips

* Be as specific and detailed as possible when filling out the form.
* Make sure to select the correct "Release Status" for accurate tracking.
* Enter your actual name or ID as the "Submitter" and "Approver" for accurate tracking.
* Use your actual email and phone number for contact purposes.
* Add any additional comments or information that might be relevant to the software update.
