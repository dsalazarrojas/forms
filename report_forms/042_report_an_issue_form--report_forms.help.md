# Report An Issue Form - Help Guide
## Purpose
The Report An Issue Form is used to report a problem or concern to the relevant team or department. It helps to gather information to resolve the issue efficiently.

## How To Complete This Form
To complete this form, follow these steps:
1. Choose the type of issue you are experiencing (step 1)
2. Describe the issue in detail (step 2)
3. Provide the date and time the issue occurred (steps 3 and 4)
4. Specify the location where the issue occurred (step 5)
5. Provide any additional information about the issue (step 6)
6. Review and submit your report (step 7)

## Field-by-Field Explanation
* **issue_type** (Select multiple): Choose all the types of issues that apply to your report.
	+ 'Yes': Indicates that you are reporting an issue.
	+ 'No': Not applicable.
* **describe_issue** (Text): Explain the problem you are experiencing.
* **issue_date** (Date): Enter the date when the issue occurred.
* **issue_time** (Time): Enter the time when the issue occurred.
* **issue_location** (Text): Provide the location where the issue occurred.
* **issue_report** (Text): If you have any additional information about the issue, type it in this field.
* **submit** (Select one): Choose to submit your report or cancel it.
* **email** (Email): If you want to be contacted about this issue, enter your email address here. 

## Tips
- Make sure to provide as much detail as possible when describing the issue.
- If you are unsure about any field, ask your supervisor or colleague for guidance.
- Review your report before submitting it to ensure it is accurate and complete.
