# Public Transport Usage Change Report Form - Help Guide
## Purpose
This form is designed to help us understand changes in your public transport usage patterns. If you have experienced a change in your usual public transport usage, please fill out this form to report this change. This information will help us improve our services.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the form completely, including all required fields.
2. Choose the "Service Improvement" option that best describes the change you experienced.
3. Provide any additional "Rider Feedback" you have about the change, if applicable.
4. Select all relevant "Transit Usage Change" options that describe the change you experienced.
5. If you have any ideas for how to improve our service, please provide them under "Service Improvement Idea".
6. If you wish to be contacted for follow-up, please provide a phone number and/or email.

## Field-by-Field Explanation

* **Public Transport Usage Change Report Form** (1, Public Transport Usage Change Report Form, required): This is the form title and header.
* **Service Improvement** (2, Service Improvement, optional): If you experienced a change that was caused by an improvement in our service, choose "Yes". This might include things like new routes, better schedules, or improved stations.
* **Rider Feedback** (3, Rider Feedback, optional): If you would like to provide additional comments about the change you experienced, please enter them here. This helps us understand your experience and improve our services.
* **Transit Usage Change** (4, Transit Usage Change, optional): Select all options that describe the change you experienced. For example, if you started taking the bus less frequently, choose "Yes" for "Less Frequent".
* **Service Improvement Idea** (5, Service Improvement Idea, optional): If you think of a way to improve our service, please let us know here. This might include suggestions for new routes, new schedules, or other service improvements.
* **Phone** (6, Phone, optional): If you would like to be contacted for follow-up, please provide your phone number here.
* **Email** (7, Email, optional): If you would like to be contacted for follow-up, please provide your email here.

## Tips
- Please only fill out this form once per incident.
- If you need to report multiple changes, please fill out a new form for each change.
- If you have any technical difficulties or errors with the form, contact your administrator or technical support team.
