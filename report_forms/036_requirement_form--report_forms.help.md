# Requirement Form - Help Guide
## Purpose
The Requirement Form is used to gather essential information about a project, including event dates, project names, and team member involvement.

## How To Complete This Form

To complete the form, please follow these steps:

1. Enter the event date in the format YYYY-MM-DD.
2. Provide the name of the project.
3. Describe the project in brief.
4. Add a description of the event or project.
5. Identify the project lead.
6. Specify whether team members are involved in the project by selecting 'Yes' or 'No' for each option.
7. Choose the project status as either 'Active' or 'Inactive'.
8. Enter the due date of the project in the format YYYY-MM-DD.
9. Indicate whether required fields are necessary for the project by selecting 'Yes' or 'No' for each option.
10. Add any additional information about the project.

## Field-by-Field Explanation

* **Event Date (1)**: Enter the date of the event or project milestone. Format: YYYY-MM-DD. 
* **Project Name (2)**: Type the name of the project, such as "Marketing Campaign" or "Software Development."
* **Project Description (3)**: Write a brief description of the project, including its purpose and objectives.
* **Event Description (4)**: Provide a detailed description of the event or project task.
* **Project Lead (5)**: Enter the name of the person responsible for the project.
* **Team Members (6)**: Select 'Yes' or 'No' to indicate whether team members are involved in the project.
* **Project Status (7)**: Choose 'Active' if the project is ongoing, or 'Inactive' if it has been completed or terminated.
* **Due Date (8)**: Enter the date by which the project should be completed.
* **Required Fields (9)**: Indicate whether certain fields are mandatory or not for the project. Select 'Yes' or 'No' for each option.
* **Additional Info (10)**: Add any additional details or context about the project, as needed.

## Tips
- Be precise when filling out the form to ensure accurate and relevant information is recorded.
- Review each field carefully before submitting the form to ensure all required information is provided.
- Use standard date formats (YYYY-MM-DD) when filling out the date fields.
