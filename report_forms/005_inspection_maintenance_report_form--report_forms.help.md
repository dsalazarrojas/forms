# Inspection Maintenance Report Form - Help Guide
## Purpose
The Inspection Maintenance Report Form is used to track and document the maintenance status of an asset after inspection.

## How To Complete This Form
- Start by selecting the correct Asset Type for the asset being inspected.
- Enter the Asset ID, which is unique to each asset.
- Select the Asset Condition rating to describe the asset's current state.
- Enter the date of the maintenance, using the date field.
- Add any additional notes regarding the asset's condition or maintenance in the Notes field.
- If necessary, describe what specific aspect of the asset's condition was maintained.
- Enter a description of the condition of the asset after the maintenance.
- Rate the asset's condition after maintenance using the number field.

## Field-by-Field Explanation

* **Asset Type (equipment/vehicle/other)**: Select the correct category for the asset being inspected.
* **Asset Id**: Enter the unique ID number for the asset.
* **Asset Condition**: Describe the asset's current condition.
* **Maintenance Date**: Enter the date the maintenance was performed.
* **Notes**: Add any additional comments regarding the asset's condition or maintenance.
* **Asset Condition (what maintained)**: Specify what was maintained during the inspection.
* **Asset Condition Description**: Describe the asset's condition after maintenance.
* **Asset Condition Rating**: Rate the asset's condition after maintenance.

## Tips
- Complete this form accurately and thoroughly to ensure accurate records.
- Review and update the form as needed to reflect changes in the asset's condition.
- Submit the form after completion to ensure it is documented in the system.
