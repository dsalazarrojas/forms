# Livestock Sanitation Support Request Form - Help Guide
## Purpose
This form is used to report issues related to livestock sanitation, such as odors, waste management, or biosecurity concerns. Fill out this form to get assistance from our support team.

## How To Complete This Form
1. Fill in your farm information, including any relevant details about your farm.
2. Provide an accurate count of the animals affected by the issue.
3. Select the type of animal involved (e.g., Beef Cattle, Pigs, etc.).
4. Describe the issue in as much detail as possible.
5. Attach any relevant photos or additional information about the issue.
6. Indicate the urgency level of the issue (Low, Medium, or High).
7. Choose the contact person responsible for addressing the issue.
8. Select the location of the farm (Local, Regional, or National).
9. Provide any additional support request information.
10. If necessary, add any further details about the support request.

## Field-by-Field Explanation
- **Farm Information**: Provide a brief description of your farm, including any relevant details that might help us understand the issue.
  * Type: text
  * Required: false
- **Animal Count**: Estimate the number of animals affected by the issue. This will help us prioritize your support request.
  * Type: number
  * Required: false
- **Animal Type**: Select the type of animal that is affected by the issue (e.g., Beef Cattle, Pigs, etc.).
  * Type: select_one
  * Required: false
- **Issue Description**: Describe the issue in detail, including any symptoms or problems you are experiencing.
  * Type: text
  * Required: false
  * Hint: Describe the issue in as much detail as possible.
- **Photos**: Attach any photos or videos that might help us understand the issue better.
  * Type: text
  * Required: false
  * Hint: You can attach up to 10 photos or videos for our review.
- **Additional Photos Information**: If you have additional information about the photos, please provide it here.
  * Type: text
  * Required: false
- **Urgency**: Indicate the level of urgency for the support request (Low, Medium, or High).
  * Type: select_one
  * Required: false
- **Contact Person**: Choose the person responsible for addressing the issue.
  * Type: select_multiple
  * Required: false
  * Hint: Select all relevant contact persons.
- **Farm Location**: Select the location of the farm (Local, Regional, or National).
  * Type: select_one
  * Required: false
- **Support Request**: Briefly describe the specific support request you are making.
  * Type: text
  * Required: false
  * Hint: Keep it concise and to the point.
- **Additional Support Request Information**: Provide any additional details about the support request.
  * Type: text
  * Required: false

## Tips
- Be as detailed as possible when describing the issue.
- Attach clear and relevant photos or videos to support your report.
- Choose the correct urgency level for the issue.
- Select all relevant contact persons responsible for the issue.
- Clearly describe the support request and any additional information.
