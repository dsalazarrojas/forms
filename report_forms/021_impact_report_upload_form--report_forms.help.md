# Impact Report Upload Form - Help Guide
## Purpose
The Impact Report Upload Form is designed to collect information on reports related to impact, allowing users to submit their findings and data in an efficient and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant report details from the options provided in the "Report Details" section.
2. Choose any supporting documents that pertain to your report from the "Supporting Documents" section.
3. If you have a file to upload, enter the file name and upload the file in the "Upload File" section.
4. Provide a brief description of your report in the "Description" section.
5. Set the date and time of upload in the "Upload Date" and "Upload Time" sections.

## Field-by-Field Explanation

* **Report Details (Report Details)** (`report_details`, select_multiple, **Required**): Select all applicable report details that apply to your report. This will help ensure that your report is accurate and complete.
* **Supporting Documents (Supporting Documents)** (`supporting_documents`, select_multiple, **Not Required**): Choose any supporting documents that relate to your report, such as images, videos, or other relevant attachments.
* **Upload File (Upload File)** (`upload_file`, text, **Not Required**): If you have a file to upload, enter the file name and upload it here. This can be a useful way to provide additional context or evidence for your report.
* **File Name (File Name)** (`file_name`, text, **Not Required**): Enter the name of the file you are uploading, so that it can be easily identified.
* **Description (Description)** (`description`, text, **Not Required**): Provide a brief description of your report, including any relevant information or context.
* **Upload Date (Upload Date)** (`upload_date`, date, **Not Required**): Set the date on which you uploaded the report.
* **Upload Time (Upload Time)** (`upload_time`, time, **Not Required**): Set the time at which you uploaded the report.
