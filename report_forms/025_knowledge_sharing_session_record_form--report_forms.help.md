# knowledge_sharing_session_record_form - Help Guide
## Purpose
This form is designed to help team members record and report on knowledge sharing sessions. It collects information about session details, key takeaways, feedback, and follow-up actions.

## How To Complete This Form
To complete this form, follow these steps:

* Ensure you have all the necessary information about the session, such as notes, dates, and locations.
* Fill out each field with accurate and complete information.
* Review and edit your input before submitting the form.

## Field-by-Field Explanation
### Session details
* **Session details** (`session_details`): A brief description of the session, including its topic, location, and duration. 
* **Key takeaways** (`key_takeaways`): Select all the important points or outcomes of the session that you'd like to remember.
* **Feedback** (`feedback`): Share your thoughts, comments, or suggestions about the session.
* **Follow-up actions** (`follow_up_actions`): Choose the action(s) you'll take as a follow-up for the session.
* **Internal training** (`internal_training`): Select any internal training that occurred during the session.
* **Date** (`date`): The date of the session.
* **Time** (`time`): The start and end time of the session.
* **Start Date** (`start_date`): The start date of the session.
* **End Date** (`end_date`): The end date of the session.
* **Assigned tool** (`assigned_tool`): The tool used during the session.
* **User** (`user`): The person who conducted the session.
* **Session notes** (`session_notes`): Any additional notes about the session.
* **Team members** (`team_members`): Select all the team members who attended the session.
* **Session topic** (`session_topic`): Select all the topics discussed during the session.
* **Session location** (`session_location`): The location of the session.
* **Session duration** (`session_duration`): The duration of the session.
* **Session capacity** (`session_capacity`): The capacity of the session.
* **Session type** (`session_type`): The type of session (e.g., meeting, training, etc.).
* **Follow-up status** (`follow_up_status`): Select all the follow-up statuses for the session.
* **Follow-up description** (`follow_up_description`): A description of the follow-up action(s).
* **Follow-up date** (`follow_up_date`): The date of the follow-up action.
* **Follow-up time** (`follow_up_time`): The time of the follow-up action.
* **Follow-up location** (`follow_up_location`): The location of the follow-up action.
* **Follow-up notes** (`follow_up_notes`): Any additional notes about the follow-up action.
* **Output file** (`output_file`): Upload any relevant output file associated with the session.

## Tips

* Ensure accurate and up-to-date information is recorded for each session.
* Use this form consistently for all sessions to ensure comparability of data.
* If you're unsure about any field, refer to your session notes or consult your team leader for clarification.
* Review and edit your input before submitting the form.
