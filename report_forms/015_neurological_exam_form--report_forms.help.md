# Neurological Exam Form - Help Guide
## Purpose
This form is designed to collect information from a neurological exam, covering various aspects of a patient's neurological status.

## How To Complete This Form
1. Start by filling in the Medical History section, which includes general information about the patient's medical history.
2. Move on to the Chief Complaint section, where you can describe the patient's main reason for the visit.
3. Next, go through the Neurological Exam section, which includes questions about cranial nerves, motor and sensory function, reflexes, coordination, gait, mental status, and neuroanatomical examination.
4. Finally, review the Neurological System Examination and other sections to gather further information and make notes.

## Field-by-Field Explanation
* **Medical History**: A section to collect general information about the patient's medical history.
	+ This includes any previous medical conditions, allergies, or relevant medical history.
	+ Please be as detailed as possible, but keep it concise.
* **Chief Complaint**: The main reason for the patient's visit.
	+ Describe the patient's main concern or reason for the visit.
	+ Be specific and clear about the symptoms or issues.
* **Neurological Exam**: A section to collect information about the patient's neurological status.
	+ **Cranial Nerves**: Select all the cranial nerves that are affected or abnormal.
	+ **Motor Function**: Select the motor function as normal, abnormal, or not applicable (N/A).
	+ **Sensory Function**: Select the sensory function as normal, abnormal, or not applicable (N/A).
	+ **Reflexes**: Select the number of reflexes present, from 0 to 2+.
	+ **Coordination**: Select the coordination as normal, abnormal, or not applicable (N/A).
	+ **Gait**: Describe the patient's gait.
	+ **Mental Status**: Describe the patient's mental status.
	+ **Cognitive Function**: Select the cognitive function as normal, abnormal, or not applicable (N/A).
* **Neuroanatomical Examination**: A section to collect information about the patient's neuroanatomical examination.
	+ **Neurological System Examination**: Describe the patient's neurological system examination.
	+ **General Examination Note**: Make a note about the general examination.
	+ **Neurological System Examination Note**: Make a note about the neurological system examination.
	+ **Neuroanatomical Examination Summary**: Describe the patient's neuroanatomical examination summary.
* **General Examination Note**: Make a note about the general examination.
* **Neuroimaging**: A section to collect information about neuroimaging.
	+ **Neuroimaging Note**: Make a note about neuroimaging.
* **Neurological Status**: A field to enter the patient's neurological status.
* **Neuroanatomical Status**: A field to enter the patient's neuroanatomical status.

## Tips
* Please ensure that you are familiar with the relevant medical knowledge and guidelines before using this form.
* Be as accurate and detailed as possible when filling out the form.
* If you are unsure about any of the information, do not hesitate to ask for help or guidance from a healthcare professional.
