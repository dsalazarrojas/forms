# Gaming Dismissal Report Form - Help Guide
## Purpose
The Gaming Dismissal Report Form is a tool for players to report the reasons behind terminating a game or gaming session. This form helps collect necessary information to provide insights into player behavior and experiences.

## How To Complete This Form
1. To complete this form, navigate to each page (section) and fill in the corresponding information.
2. Start with the "Report" page, where you can describe the gaming session you want to report.
3. Proceed to the "Player Info" page to provide details about the player involved.
4. On the "Player Name" page, enter the player's name (if available) or a unique identifier for anonymity.
5. Go to the "Game Name" page to record the name of the game being reported.
6. Enter the date and time of the gaming session in the "Game Date" field.
7. Record the time spent playing the game in the "Time Played" field.
8. In "Player Status" provide a brief description of the player's status during the gaming session (e.g., active, inactive, or unknown).
9. Finally, describe the reason for the gaming session dismissal in the "Reason for Dismissal" field.

## Field-by-Field Explanation

* **Report** (Page 1):
	+ **Page 1** is intended for a brief description of the gaming session.
	+ Provide a short narrative of the gaming experience.
* **Player Info** (Page 2):
	+ **Player Info** is used to document details about the player.
	+ If possible, include player demographics (age, location, etc.) if they can be disclosed.
* **Player Name** (Page 3):
	+ **Player Name** is the name of the player or a unique identifier for anonymity.
	+ Enter the name as it appears in records or as a unique identifier.
* **Game Name** (Page 4):
	+ **Game Name** is the name of the game being reported.
	+ Be as specific as possible with the game title.
* **Game Date** (Page 5):
	+ **Game Date** is the date when the gaming session occurred.
	+ Use the format `YYYY-MM-DD` (e.g., 2023-02-20).
* **Time Played** (Page 6):
	+ **Time Played** is the duration of the gaming session in hours and minutes.
	+ Enter the actual time spent playing the game.
* **Player Status** (Page 7):
	+ **Player Status** is a brief description of the player's condition during the gaming session.
	+ Examples include active, inactive, or unknown.
* **Reason for Dismissal** (Page 8):
	+ **Reason for Dismissal** is the explanation for terminating or ending the gaming session.
	+ Be as specific as possible about the reason for the dismissal.

## Tips
- Ensure that the form is filled out accurately and completely for better data quality.
- If you're unsure about any of the fields, refer to your gaming records or contact the form administrator.
- Review each field carefully to avoid missing any necessary information.
- If you need help or clarification, contact us at form@gic.mx.
