# Excursion Trip Report - Help Guide
## Purpose
This form is used to document excursions, providing an easy way to record trip reports. Please use this form to report details of your excursions, ensuring that all relevant information is captured accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Report Date field with the date you're submitting this report for.
2. Enter the Report Time field with the time you're submitting this report for.
3. Enter a detailed description of the trip in the Report Location field.
4. In the Report Details field, add any notes or comments about the excursion.
5. For Report Issues, list any problems or challenges that arose during the trip.
6. Choose whether there were any Vehicles, Assets, or other Equipment involved in the excursion.
7. If any other Assets were involved, select "Yes" in the Other Assets field.
8. Select whether any Vehicles or Equipment were involved in the excursion.

## Field-by-Field Explanation
* **Report Date** (`report_date`, date, required: false): Enter the date you're submitting this report for.
* **Report Time** (`report_time`, time, required: false): Enter the time you're submitting this report for.
* **Report Location** (`report_location`, text, required: true): Enter a detailed description of the trip location.
* **Report Details** (`report_details`, note, required: false): Add any notes or comments about the excursion.
* **Report Issues** (`report_issues`, text, required: false): List any problems or challenges that arose during the trip.
* **Report Vehicles** (`report_vehicles`, select_multiple, required: false): Select whether any Vehicles were involved in the excursion.
* **Report Assets** (`report_assets`, select_multiple, required: false): Select whether any Assets were involved in the excursion.
* **Other Assets** (`report_assets_other`, select_multiple, required: false): Select whether any other Assets were involved in the excursion.
* **Vehicles** (`report_assets_vehicles`, select_multiple, required: false): Select whether any Vehicles were involved in the excursion.
* **Equipment** (`report_assets_equipment`, select_multiple, required: false): Select whether any Equipment were involved in the excursion.

## Tips
* Make sure to fill out all required fields, especially Report Location, as it's crucial to accurately document the excursion location.
* Use the Report Details field to capture any relevant information not covered in the other fields.
* If you're unsure about any field, refer back to this guide for clarification.
