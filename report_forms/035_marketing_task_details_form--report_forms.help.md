# Marketing Task Details Form - Help Guide
## Purpose
This form is designed to collect and organize information about marketing tasks, allowing users to easily track and report on their progress.

## How To Complete This Form
To complete this form, simply fill in the details of your marketing task in the corresponding fields. The form is divided into several pages, and each page corresponds to a specific section of the form.

## Field-by-Field Explanation
* **Marketing Task Details** (`marketing_task_details`, text, required): A brief description of the marketing task.
* **Date** (`date`, date, required): The date on which the marketing task is scheduled to take place.
* **Time** (`time`, time, required): The time at which the marketing task is scheduled to take place.
* **Task Type** (`task_type`, text, required): The type of marketing task (e.g., campaign, event, meeting, etc.).
* **Task Priority** (`task_priority`, select_one, required): The priority level of the marketing task (e.g., high, medium, low).
* **Task Status** (`task_status`, select_multiple, required): The current status of the marketing task (e.g., active, inactive, completed).
* **Assigned To** (`assigned_to`, select_one, required): Whether the marketing task is assigned to someone else.
* **Assigned Time** (`assigned_time`, time, required): The time at which the marketing task is assigned.
* **Due Time** (`due_time`, time, required): The time by which the marketing task is due.
* **Task Description** (`task_description`, text, required): A detailed description of the marketing task.

## Tips
- Be thorough and accurate when filling out this form.
- Use a brief but clear description for the marketing task details.
- Choose the correct task type, priority, status, and assigned to status to ensure correct categorization and tracking.
- Make sure to save your progress frequently while filling out the form, in case of any issues or errors.
