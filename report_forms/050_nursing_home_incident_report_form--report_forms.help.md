# Nursing Home Incident Report Form - Help Guide
## Purpose
The purpose of this form is to report incidents that have occurred at the nursing home, allowing for proper investigation and response to ensure resident safety and well-being.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the resident's name in the "resident-name" field.
2. Select the resident's date of birth from the calendar.
3. Enter the resident's phone number (optional).
4. Enter the date and time of the incident.
5. Provide a detailed description of the incident.
6. Indicate whether the incident was caused by internal or external factors.
7. Check all applicable actions taken to address the incident.
8. Describe the outcome of the incident (if applicable).
9. Indicate whether you submitted the report (Yes/No).

## Field-by-Field Explanation
* **Resident Name** (resident-name, text, required): Enter the name of the resident involved in the incident.
* **Resident Date of Birth** (resident-dob, date, required): Select the resident's date of birth using the calendar.
* **Resident Phone** (resident-phone, text, optional): Enter the resident's phone number (if applicable).
* **Incident Date** (incident-date, date, required): Select the date of the incident using the calendar.
* **Incident Time** (incident-time, time, required): Select the time of the incident using the 24-hour clock format (e.g., 14:30).
* **Incident Description** (incident-description, text, required): Provide a detailed description of what happened.
* **Cause of Incident** (cause-of-incident, select_one, required): Check "Yes" if the incident was caused by internal factors, "No" if external factors.
* **Action Taken** (action-taken, select_multiple, required): Check all actions that were taken to address the incident.
* **Incident Outcome** (Incident Outcome, text, optional): Describe the outcome of the incident (if applicable).
* **Submitted By** (submitted-by, select_one, required): Check "Yes" if you submitted the report, "No" if not.

## Tips
- Make sure to complete all required fields to ensure accurate reporting.
- Be as detailed as possible when describing the incident.
- If the incident is ongoing, please report it as soon as possible and follow up with an update when the outcome is known.
- If the incident has already been reported, please do not resubmit the report.
