# security_camera_review_request_form - Help Guide
## Purpose
The security camera review request form is used to document and review incidents that occurred at a location with security cameras. This form helps the reviewer understand the circumstances surrounding the incident and gather additional information as needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of incident that occurred (e.g., Burglary, Theft, Fire).
2. Enter the date and time of the incident.
3. Provide details about the incident, including the location where it occurred.
4. If applicable, upload any supporting files or provide a link to the CCTV footage.
5. Enter your name and contact information so that we can follow up with you regarding your request.

## Field-by-Field Explanation
* **Incident Type**: Select the type of incident that occurred (e.g., Burglary, Theft, Fire). This will help the reviewer understand the nature of the incident and tailor their review accordingly.
* **Incident Date**: Enter the date on which the incident occurred. Use the MM/DD/YYYY format.
* **Incident Time**: Enter the time the incident occurred. Use the 24-hour clock format (e.g., 14:30 for 2:30 PM).
* **Incident Location**: Enter the location where the incident occurred. This is where the security cameras are located.
* **Supporting Files**: If you have any files related to the incident, such as photos or videos, upload them here. These will be reviewed as part of the incident investigation.
* **CCTV Footage**: If the incident was captured by a security camera, provide a link to the footage or upload it here.
* **Requestor Name**: Enter your name, the person submitting the request for review.
* **Requestor Email**: Enter your email address so that we can follow up with you regarding your request.
* **Requestor Phone**: Enter your phone number in case we need to contact you.
* **Security Camera Details**: Enter any additional details about the security camera(s) that captured the incident, such as the camera model or angle.
