# Dining Room Violation Report - Help Guide
## Purpose
The Dining Room Violation Report form is used to collect information about incidents or issues that occur in the dining room, such as food safety concerns or cleanliness issues. This form will help you report these issues and provide a detailed account of the events.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the required fields marked with an asterisk (*), which are marked as required in the form.
2. Choose the appropriate options for each field based on your observations and information.
3. Provide as much detail as possible, especially when answering open-ended questions like issue description.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation
* **Dining Room Violation** (`dining_room_violation`, text, required/optional): Describe the type of issue or incident you have observed or experienced in the dining room.
* **Date** (`date`, date, required/optional): Enter the date when the issue occurred.
* **Time** (`time`, time, required/optional): Enter the time when the issue occurred. 
* **Photos** (`photos`, select multiple, required/optional): If you have taken photos of the issue, select all that apply.
* **Issue Description** (`issue_description`, text, required/optional): Provide a detailed description of the issue or incident you observed or experienced.
* **Follow-up** (`follow_up`, select one, required/optional): Choose whether you want to be followed up on regarding this issue.
* **School/Workplace Facility** (`school_workplace_facility`, select multiple, required): Choose all facilities where the issue occurred (e.g., School, Workplace, Facility).
* **Assigned To** (`assigned_to`, select one, required): Choose who should be assigned to follow up on this issue.
* **Issue Type** (`issue_type`, select multiple, required): Select all types of issues that apply to your observation.
* **Follow-up Date** (`follow_up_date`, date, required/optional): If you want to be followed up on, enter the desired follow-up date.
* **Follow-up Time** (`follow_up_time`, time, required/optional): If you want to be followed up on, enter the desired follow-up time.
* **Photos Comments** (`photos_comments`, text, required/optional): Provide any comments or explanations for the photos you've selected.
* **Issue Status** (`issue_status`, select one, required): Choose the current status of the issue.
* **Notes** (`notes`, text, required/optional): Add any additional comments or information regarding the issue.
* **Follow-up Notes** (`follow_up_notes`, text, required/optional): Add any notes regarding follow-up on this issue.
* **Location** (`location`, select multiple, required): Choose all locations where the issue occurred (e.g., Kitchen, Dining Room, Other).
* **Incident Details** (`incident_details`, text, required/optional): Provide any additional details about the incident or issue.
* **Photos** (`photos`, text, required/optional): Add any photos or attachments that can help with the investigation.

Note: The fields marked with an asterisk (*) are required fields and should be filled out carefully to ensure the form is properly completed.
