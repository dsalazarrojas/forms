# Expense Statement - Help Guide

## Purpose
This form is used to report expenses for reimbursement. It captures essential information about the expense, including category, date, amount, description, expense type, and assigned user and tool. The form also allows you to attach notes and contact information.

## How To Complete This Form
To complete the form, follow these steps:
1. Select the category of the expense (e.g. "Yes" or "No").
2. Enter the date of the expense.
3. Enter the time of the expense.
4. Enter the amount of the expense.
5. Provide a brief description of the expense.
6. Select the type of expense (e.g. "Yes" or "No").
7. Select the options for the expense type (e.g. "Yes" or "No").
8. Enter the total expenses.
9. Assign the user and tool related to the expense.
10. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Category** (Category, select_one, required): Select the category of the expense (e.g. "Yes" or "No").
* **Date** (Date, date, required): Enter the date of the expense.
* **Time** (Time, time, required): Enter the time of the expense.
* **Amount** (Amount, number, required): Enter the amount of the expense.
* **Description** (Description, text, required): Provide a brief description of the expense.
* **Expense Type** (Expense Type, select_one, required): Select the type of expense (e.g. "Yes" or "No").
* **Expense Type Options** (Expense Type Options, select_multiple, required): Select the options for the expense type (e.g. "Yes" or "No").
* **Total Expenses** (Total Expenses, number, required): Enter the total expenses.
* **Assigned User** (Assigned User, text, optional): Enter the user assigned to the expense.
* **Assigned Tool** (Assigned Tool, text, optional): Enter the tool assigned to the expense.
* **Submit** (Submit, text, required): Click the "Submit" button to complete the form.
* **Notes** (Notes, note, optional): Attach any additional notes related to the expense.
* **Email** (Email, email, optional): Enter the email address of the contact.
* **Phone** (Phone, text, optional): Enter the phone number of the contact.
* **Report Date** (Report Date, date, required): Enter the date of the report.
* **Report Time** (Report Time, time, required): Enter the time of the report.
* **Report Form ID** (Report Form ID, text, optional): Enter the ID of the report form.
* **Form ID** (Form ID, text, optional): Enter the ID of the form.
* **Form Version** (Form Version, text, optional): Enter the version of the form.
* **User Form Version** (User Form Version, text, optional): Enter the version of the form for the user.
* **Submitted** (Submitted, text, optional): Check the "Submitted" status of the form.
* **Form Version Status** (Form Version Status, select_one, optional): Select the status of the form version (e.g. active, inactive).
