# Engineering Project Status Submission Form - Help Guide

## Purpose
This form is used to collect and submit project status information from team leads and team members. It helps project managers and coordinators track project progress and identify potential issues.

## How To Complete This Form
1. Fill out the form with the required information. The form is designed to be filled out once a week, at the same time each week.
2. Provide accurate and detailed information in the fields to ensure clear communication of project status.
3. Make sure to select the correct project status (Active, Completed, or Cancelled) and risk level (High, Medium, or Low).
4. If applicable, enter the date of the next status update and provide a brief description of the project status.
5. List team members working on the project.

## Field-by-Field Explanation
- **Project Name** (`project_name`, text, required/optional): Enter the name of the project being reported on.
  - This field is where you enter the name of the project you're submitting status for.
- **Project Status** (`project_status`, select_one, required/optional): Select the current status of the project (Active, Completed, or Cancelled).
  - This field helps determine the current state of the project.
- **Risk Description** (`risk_description`, text, required/optional): Provide any known risks or issues affecting the project.
  - This field is for listing any known risks or issues that might impact project progress.
- **Risk Level** (`risk_level`, select_one, required/optional): Indicate the level of risk (High, Medium, or Low).
  - This field helps assess the severity of the risk or issue.
- **Next Status Update** (`next_status_update`, date, required/optional): Enter the date of the next status update (if applicable).
  - This field is for scheduling the next status update, if one is expected.
- **Status Update** (`status_update`, text, required/optional): Briefly describe the project status.
  - This field provides a concise update on the project's current status.
- **Team Lead** (`team_lead`, text, required/optional): Enter the name of the team lead or person responsible for the project.
  - This field is for identifying the team lead or person responsible for the project.
- **Team Members** (`team_members`, text, required/optional): List team members working on the project.
  - This field is for listing all team members contributing to the project.

## Tips
- Make sure to fill out the form with accurate and detailed information to ensure clear communication of project status.
- Select the correct project status and risk level to give stakeholders a clear understanding of the project's state.
- If you're unsure about which status or risk level to choose, ask your team lead or project manager for guidance.
- This form should only be filled out once a week, at the same time each week, to maintain consistency.
