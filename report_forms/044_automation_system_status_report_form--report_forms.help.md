# Automation System Status Report Form - Help Guide
## Purpose
The purpose of this form is to collect information about the current state of the automation system, including its performance, availability, and any incidents or issues that have occurred.

## How To Complete This Form
1. **Report Information (1)**: This is the basic report details section. This section includes fields for report date, report time, report type, and reporting period.
2. **System Information (2)**: This section provides information about the system being reported on, including its name, location, and type.
3. **Reporter Information (3)**: This section includes fields for first name, last name, email, and department of the reporter.
4. **System Status (4)**: This section includes fields for system status, overall system status, availability, performance rating, and any incidents or issues that have occurred.
5. **Attachments (5)**: This is not a required field, but you can upload any relevant logs or screenshots as attachments.

## Field-by-Field Explanation

* **Automation System Status Report** (`title`): This is the title of the report.
* **Report Information (1)**
	+ **Report Date** (`report_date`): Enter the date of the report.
	+ **Report Time** (`report_time`): Enter the time of the report.
	+ **Report Type** (`report_type`): Select the type of report (e.g., daily, weekly, or monthly).
	+ **Reporting Period** (`reporting_period`): Select the time period covered by the report (e.g., last 24 hours, last 7 days, or last 30 days).
* **Report Information (2)**:
	+ **Report Name** (`system_name`): Enter the name of the system being reported on.
	+ **System ID** (`system_id`): Enter a unique identifier for the system.
	+ **System Location** (`system_location`): Enter the location of the system.
* **Reporter Information (3)**:
	+ **First Name** (`first_name`): Enter your first name.
	+ **Last Name** (`last_name`): Enter your last name.
	+ **Email Address** (`email`): Enter your email address.
	+ **Department** (`department`): Select your department.
* **System Status (4)**:
	+ **System Status** (`system_status`): Enter the current status of the system.
	+ **Overall System Status** (`overall_status`): Select the overall status of the system (e.g., fully operational, operational with minor issues, degraded performance, partial outage, complete outage, or under maintenance).
	+ **Availability** (`availability`): Select the availability of the system (e.g., 100%, 99-100%, 95-99%, 90-95%, below 90%).
	+ **Performance Rating** (`performance_rating`): Select the performance rating of the system (e.g., excellent, good, fair, poor, or critical).
	+ **Incidents** (`incidents`): Enter any incidents or issues that have occurred.
	+ **Incident Details** (`incident_details`): Enter a description of the incidents or issues.
	+ **Incident Severity** (`incident_severity`): Select the highest severity of the incidents or issues.
* **Maintenance (6)**:
	+ **Maintenance Performed** (`maintenance_performed`): Select if maintenance was performed on the system.
	+ **Maintenance Description** (`maintenance_description`): Enter a description of the maintenance performed.
	+ **Next Scheduled Maintenance** (`next_maintenance`): Enter the date of the next scheduled maintenance.
* **Metrics (7)**:
	+ **Throughput** (`throughput`): Enter the throughput of the system (e.g., units per hour).
	+ **Error Rate** (`error_rate`): Enter the error rate of the system (e.g., percentage).
	+ **Average Cycle Time** (`cycle_time`): Enter the average cycle time of the system (e.g., seconds).
	+ **Quality Rate** (`quality_rate`): Enter the quality rate of the system (e.g., percentage).
* **Attachments (8)**: This is not a required field, but you can upload any relevant logs or screenshots as attachments.
* **Reporter Signature (9)**: This is your digital signature, please enter your name as it is in your email address.
* **Report Submission Date (10)**: This field is automatically filled in when you submit the report.

## Tips

* Make sure to review the form carefully before submitting it to ensure that all required fields are completed.
* Provide as much detail as possible in the fields that have text boxes.
* Use the options list in the select boxes to select the most relevant option.
* Upload any relevant logs or screenshots as attachments if necessary.
* Enter your digital signature and report submission date accurately.
