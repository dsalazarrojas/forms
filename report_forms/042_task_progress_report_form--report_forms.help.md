# Task Progress Report Form - Help Guide
## Purpose
The Task Progress Report Form is a tool used to report progress on tasks, track deadlines, and assign responsibilities to team members. It is designed to be completed by team members to provide a clear and concise report of their work status.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the task status from the dropdown menu.
2. Provide a brief description of the task in the text field.
3. Select the team member assigned to the task from the dropdown menu.
4. Choose the deadline for the task from the calendar.
5. Select the priority level of the task from the dropdown menu.
6. Add any comments or notes about the task in the text field.
7. Upload any relevant files for the task in the file upload fields.

## Field-by-Field Explanation

* **Form Header**: This is a note field that provides a summary of the form's purpose and instructions.
* **Task Status**: Select the current status of the task from the dropdown menu.
	+ Task Not Started: The task has not been started yet.
	+ In Progress: The task is currently being worked on.
	+ Done: The task is complete.
* **Task Description**: Provide a brief description of the task, including any relevant details or instructions.
* **Assigned To**: Select the team member assigned to complete the task from the dropdown menu.
* **Deadline**: Choose the deadline for the task from the calendar.
* **Completed By**: Select the team member who completed the task from the dropdown menu (if applicable).
* **Priority**: Select the priority level of the task from the dropdown menu.
	+ High: The task has high priority and should be completed as soon as possible.
	+ Medium: The task has medium priority and should be completed within a reasonable timeframe.
	+ Low: The task has low priority and can be completed at any time.
* **Comments**: Add any additional comments or notes about the task in this text field.
* **File Upload**: Upload any relevant files related to the task in this text field.
* **File Upload 2**: Upload any additional files related to the task in this text field.

## Tips
* Make sure to choose the correct status, deadline, and priority level for each task.
* Provide a clear and concise description of the task to help team members understand their responsibilities.
* Use the file upload fields to attach relevant documents or files related to the task.
* Fill out the form completely and accurately to ensure that progress is tracked correctly.
