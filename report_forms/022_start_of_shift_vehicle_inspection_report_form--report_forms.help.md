# Start Of Shift Vehicle Inspection Report Form - Help Guide
## Purpose
The Start Of Shift Vehicle Inspection Report Form is a critical document that helps you assess the condition and status of a vehicle at the start of a shift. It is essential for identifying potential issues and ensuring that vehicles are properly inspected and serviced before they are put into operation.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each section carefully and provide details about the condition and status of the vehicle.
2. For numeric fields, enter the current reading or value. For example, if the fuel level is at 75%, enter 75.
3. For text fields, enter a brief description or status. For example, "Green" for good condition, "Red" for poor condition, or "Check engine oil level" for a specific concern.
4. Be thorough and accurate when completing the form, as it will be used to inform maintenance and servicing decisions.

## Field-by-Field Explanation

* **Vehicle Details** (`vehicle_details`): Provide a brief description of the vehicle, including its make, model, and year.
* **Fuel Level** (`fuel_level`): Enter the current fuel level as a percentage (e.g., 75).
* **Engine Oil Level** (`engine_oil_level`): Enter the current engine oil level as a percentage (e.g., 75).
* **Transmission Oil Level** (`transmission_oil_level`): Enter the current transmission oil level as a percentage (e.g., 75).
* **Coolant Level** (`coolant_level`): Enter the current coolant level as a percentage (e.g., 75).
* **Brake Fluid Level** (`brake_fluid_level`): Enter the current brake fluid level as a percentage (e.g., 75).
* **Power Steering Fluid Level** (`power_steering_fluid_level`): Enter the current power steering fluid level as a percentage (e.g., 75).
* **Battery Voltage** (`battery_voltage`): Enter the current battery voltage reading.
* **Air Filter Status** (`air_filter_status`): Describe the air filter status (e.g., green for good condition, red for poor condition).
* **Oil Filter Status** (`oil_filter_status`): Describe the oil filter status (e.g., green for good condition, red for poor condition).
* **Spark Plug Status** (`spark_plug_status`): Describe the spark plug status (e.g., green for good condition, red for poor condition).
* **Spark Plug Wire Status** (`spark_plug_wire_status`): Describe the spark plug wire status (e.g., green for good condition, red for poor condition).
* **Battery Health** (`battery_health`): Describe the battery health (e.g., good, poor, or needs replacement).
* **Air Pressure** (`air_pressure`): Enter the current air pressure reading.
* **Tire Pressure** (`tire_pressure`): Enter the current tire pressure reading.
* **Temperature** (`temperature`): Enter the current temperature reading.
* **Humidity** (`humidity`): Enter the current humidity reading.
* **Air Quality** (`air_quality`): Describe the air quality (e.g., good, poor, or needs attention).
* **Vehicle Status** (`vehicle_status`): Describe the vehicle status (e.g., green for good condition, red for poor condition).
* **Notes** (`notes`): Add any additional comments or notes about the vehicle.
* **Fuel Type** (`fuel_type`): Select the type of fuel used in the vehicle (e.g., gasoline, diesel, other).
* **Vehicle Year** (`vehicle_year`): Enter the vehicle's year of manufacture.
* **Vehicle Make** (`vehicle_make`): Select the vehicle's make (e.g., Chevrolet, Ford, Toyota, Nissan, other).
* **Vehicle Model** (`vehicle_model`): Enter the vehicle's model number or description.
* **Assigned Technician** (`assigned_technician`): Enter the name of the technician assigned to inspect or maintain the vehicle.

## Tips
* Be thorough and accurate when completing the form.
* Review each field carefully to ensure that you are providing the correct information.
* If you are unsure about any aspect of the vehicle, do not hesitate to ask for clarification or guidance.
* This form is not a substitute for a comprehensive vehicle inspection, but rather a tool to aid in identifying potential issues and ensuring that vehicles are properly inspected and serviced.
