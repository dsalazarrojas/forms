# Material Trace Error Report Form - Help Guide
## Purpose
The Material Trace Error Report Form is used to document and report material trace errors that occur during the manufacturing process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the batch number (optional).
2. Select the time when the error occurred.
3. Provide a description of the material error.
4. Enter the batch ID (optional).
5. Select the type of material error (select multiple options).
6. Describe the cause of the material error.
7. Analyze the root cause of the material error.
8. Describe any corrective actions taken.
9. Document any follow-up actions.

## Field-by-Field Explanation
* **Batch Number** (`batch_number`, `number`, optional): Enter the batch number related to the material trace error.
* **Time** (`time`, `date`, optional): Select the date and time when the material trace error occurred.
* **Location** (`location`, `text`, optional): Enter the location where the material trace error occurred.
* **Material Error Description** (`material_error_description`, `text`, optional): Provide a detailed description of the material trace error.
* **Batch ID** (`batch_id`, `number`, optional): Enter the batch ID related to the material trace error.
* **Material Error Type** (`material_error_type`, `select_multiple`, optional): Select one or multiple error types that occurred during the material trace error (e.g., Error Type 1, Error Type 2, Error Type 3).
* **Material Error Cause** (`material_error_cause`, `text`, optional): Describe the root cause of the material trace error.
* **Root Cause Analysis** (`root_cause_analysis`, `text`, optional): Analyze the root cause of the material trace error.
* **Corrective Action** (`corrective_action`, `text`, optional): Describe any corrective actions taken to address the material trace error.
* **Follow Up Action** (`follow_up_action`, `text`, optional): Document any follow-up actions taken or planned.

Note: This form will be completed by production or quality personnel during the material trace error reporting process.
