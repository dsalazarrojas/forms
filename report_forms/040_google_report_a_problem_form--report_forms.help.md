# google_report_a_problem_form - Help Guide
## Purpose
The "google_report_a_problem_form" is designed to help our team understand problems users are experiencing with our product or service. Please use this form to report any issues you are facing.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections and ensure you have all the necessary information ready.
2. Fill in the required fields (identified as "required" in the form).
3. Provide as much detail as possible in the required fields.
4. Select "Yes" or "No" for the select-type fields as relevant.
5. If the "problem_description" field is not filled, you will not be able to submit the form.

## Field-by-Field Explanation
- **contact_info** (Select Multiple, optional): This field is used to indicate if you have any contact information about the problem.
  - Please select all that apply to your situation.
- **problem_description** (Text, required): This field should contain a detailed description of the problem you are experiencing.
  - Please provide as much detail as possible, including any error messages or specific steps that led to the issue.
- **screenshot** (Select One, optional): This field allows you to attach a screenshot related to the problem.
  - Select "Yes" if you have a screenshot, otherwise select "No".
- **problem_type** (Select Multiple, optional): This field is used to specify the type of problem you are experiencing.
  - Select all that apply to your situation.
- **problem_details** (Note, required): This field should contain any additional information about the problem.
  - This can be any relevant details about the issue.
- **problem_priority** (Select One, optional): This field is used to indicate the severity of the problem.
  - Select "Yes" if the problem is critical, otherwise select "No".
- **problem_solution** (Note, optional): This field should contain any information about the steps you have taken to solve the problem.
  - This can be any details about the actions you have taken.
- **problem_category** (Select One, optional): This field is used to specify the category of the problem.
  - Select "Yes" if the problem belongs to this category, otherwise select "No".
- **contact_method** (Text, optional): This field should contain the method of contact you used to reach out to us.
  - Please provide any details about how you contacted us.
- **problem_description_details** (Select Multiple, optional): This field is used to specify the types of problems you are facing.
  - Select all that apply to your situation.
