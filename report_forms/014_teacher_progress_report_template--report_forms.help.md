# Teacher Progress Report Template - Help Guide
## Purpose
This form is designed to capture essential information about a student's progress, including their name, grade, progress level, and comments from the teacher. It also includes fields for report date, school year, and report status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the student's name in the `student_name` field.
2. Select the correct `progress_level` that best describes the student's current progress.
3. Enter the student's grade in the `student_grade` field.
4. Provide comments about the student's progress in the `student_progress_comments` field.
5. Select the report status (e.g., pending, submitted, completed, or cancelled) in the `report_status` field.
6. If applicable, add any additional comments in the `comments` field.

## Field-by-Field Explanation
- **Student Name** (`student_name`, text, required): Enter the student's name in this field.
- **Progress Level** (`progress_level`, select_one, required): Select one of the options (A, B, C, D) to describe the student's current progress.
- **Grade** (`student_grade`, number, required): Enter the student's grade.
- **Report Date** (`report_date`, date, optional): Enter the report date if applicable.
- **School Year** (`school_year`, date, required): Select the school year for the report.
- **Teacher Name** (`teacher_name`, text, optional): Enter the teacher's name.
- **Progress Comments** (`student_progress_comments`, text, required): Provide comments about the student's progress.
- **Report Status** (`report_status`, select_one, required): Select one of the options (pending, submitted, completed, cancelled).
- **Submitted By** (`submitted_by`, text, optional): Enter the name of the person submitting the report.
- **Comments** (`comments`, text, optional): Add any additional comments.
- **Report Status** (`report_status`, select_one, required): This field indicates the report's status.
- **Progress Level** (`progress_level`, select_one, required): This field describes the student's current progress level.
