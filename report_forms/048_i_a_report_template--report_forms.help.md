# I.A. Report Template - Help Guide
## Purpose
The I.A. Report Template is designed to collect information about internal issues or concerns within an organization. This form is meant to provide a structured approach to reporting these issues, ensuring that all relevant information is captured in a clear and concise manner.

## How To Complete This Form
1. Fill in the `Report Category` field by selecting one of the provided options (e.g., 'Yes' or 'No'). This field helps determine the type of report.
2. Enter a brief description of the issue in the `Description` field. This field should provide a clear and concise explanation of the issue.
3. Update the `Status` field by selecting one of the provided options (e.g., 'Active' or 'Inactive'). This field reflects the current state of the report.
4. Enter the date of the issue in the `Date` field. This field should be in the format of MM/DD/YYYY.
5. Fill in the `Time` field with the time of the issue. This field should be in the 24-hour format (e.g., 14:30).
6. Update the `Priority` field by selecting one of the provided options (e.g., 'Yes' or 'No'). This field indicates the level of urgency or importance of the issue.

## Field-by-Field Explanation
* **Report Category**: This field is used to categorize the report as 'Yes' or 'No'. This helps to determine the type of report and ensure it is correctly routed to the relevant department or team.
* **Description**: Enter a brief description of the issue, providing as much detail as possible. This field should be clear and concise.
* **Status**: This field reflects the current state of the report. Select 'Active' to indicate that the report is ongoing, and 'Inactive' to indicate that it has been resolved or closed.
* **Date**: Enter the date of the issue in the format MM/DD/YYYY.
* **Time**: Fill in the time of the issue in the 24-hour format (e.g., 14:30).
* **Priority**: This field indicates the level of urgency or importance of the issue. Select 'Yes' for high-priority issues, and 'No' for low-priority issues.
