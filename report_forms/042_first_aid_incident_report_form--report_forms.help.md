# First Aid Incident Report Form - Help Guide
## Purpose
The First Aid Incident Report Form is a document used to report incidents that have occurred in a medical setting, such as injuries or other health events that require immediate medical attention.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the date and time of the incident using the **incident_date** and **incident_time** fields.
2. Provide the location of the incident using the **incident_location** field.
3. Enter the patient's ID using the **patient_id** field.
4. Enter the patient's name using the **patient_name** field.
5. Describe the incident in detail using the **incident_description** field.
6. Indicate if medical attention was provided to the patient using the **medical_attention** field.
7. Specify what medical attention was given using the **medical_attention_given** field.
8. For each body part affected by the injury, select the corresponding option in the "Yes/No" fields:
	* Head injury
	* Neck injury
	* Chest injury
	* Abdominal injury
	* Back injury
	* Extremities injury (including arms and legs)
	* Face injury
9. If an injury was sustained, select the corresponding Glasgow Coma Scale score (GCS) for each body part:
	* Head injury: GCS 3, 4, 5, or 6
	* Neck injury: GCS 3, 4, 5, or 6
	* Chest injury: GCS 3, 4, 5, or 6
	* Abdominal injury: GCS 3, 4, 5, or 6
	* Back injury: GCS 3, 4, 5, or 6
	* Extremities injury: GCS 3, 4, 5, or 6
	* Face injury: GCS 3, 4, 5, or 6
10. Enter the ID of the medical provider who treated the patient using the **medical_provider_id** field.
11. Enter the name of the medical provider who treated the patient using the **medical_provider_name** field.
12. Enter the signature of the medical provider who treated the patient using the **medical_provider_signature** field.

## Field-by-Field Explanation

* **incident_date**: Date of the incident
* **incident_time**: Time of the incident
* **incident_location**: Location of the incident
* **patient_id**: ID number of the patient
* **patient_name**: Name of the patient
* **incident_description**: Description of the incident
* **medical_attention**: Was medical attention given to the patient? (Yes/No)
* **medical_attention_given**: Types of medical attention given to the patient (e.g., first aid, medication, etc.)
* **head_injury**: Was head injury sustained? (Yes/No)
* **head_injury_glasgow_coma_scale**: If head injury was sustained, select the corresponding GCS score (3, 4, 5, or 6)
* **neck_injury**: Was neck injury sustained? (Yes/No)
* **neck_injury_glasgow_coma_scale**: If neck injury was sustained, select the corresponding GCS score (3, 4, 5, or 6)
* **chest_injury**: Was chest injury sustained? (Yes/No)
* **chest_injury_glasgow_coma_scale**: If chest injury was sustained, select the corresponding GCS score (3, 4, 5, or 6)
* **abdominal_injury**: Was abdominal injury sustained? (Yes/No)
* **abdominal_injury_glasgow_coma_scale**: If abdominal injury was sustained, select the corresponding GCS score (3, 4, 5, or 6)
* **back_injury**: Was back injury sustained? (Yes/No)
* **back_injury_glasgow_coma_scale**: If back injury was sustained, select the corresponding GCS score (3, 4, 5, or 6)
* **extremities_injury**: Were extremities (arms and legs) injured? (Yes/No)
* **extremities_injury_glasgow_coma_scale**: If extremities were injured, select the corresponding GCS score (3, 4, 5, or 6)
* **face_injury**: Was face injury sustained? (Yes/No)
* **face_injury_glasgow_coma_scale**: If face injury was sustained, select the corresponding GCS score (3, 4, 5, or 6)
* **medical_provider_id**: ID number of the medical provider who treated the patient
* **medical_provider_name**: Name of the medical provider who treated the patient
* **medical_provider_signature**: Signature of the medical provider who treated the patient

## Tips
* Use this form only for incidents that require immediate medical attention.
* Refer to your facility's policies and procedures for guidance on when to use this form.
* Ensure that all fields are completed accurately and thoroughly.
* If an injury was sustained, select the corresponding GCS score for each body part affected.
