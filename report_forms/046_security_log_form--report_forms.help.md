# Security Log Form - Help Guide
## Purpose
The purpose of this form is to collect information on security incidents reported by users. This form will help the security team to track and resolve security issues efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out each field accurately and to the best of your ability.
2. Select the correct category for the security incident from the options provided.
3. Enter the date and time of the incident in the format `YYYY-MM-DD HH:MM:SS`.
4. Provide a brief description of the incident in the "Security Issue Description" field.
5. Select the status of the incident (Active, Inactive, or Closed) from the options provided.
6. Enter the user's name and email address associated with the incident.
7. If applicable, attach any relevant attachments to the incident.
8. Review and submit the form.

## Field-by-Field Explanation

* **Security Incident** (`security_incident_label`): This field is used to enter a brief description of the incident. Please be as detailed as possible.
* **Security Issue Description** (`security_issue_description_label`): This field is used to provide a longer description of the incident.
* **Category** (`security_incident_category_label`): Select the category of the incident from the options provided.
* **Date** (`security_incident_date_label`): Enter the date of the incident in the format `YYYY-MM-DD`.
* **Time** (`security_incident_time_label`): Enter the time of the incident in the format `HH:MM:SS`.
* **Status** (`security_incident_status_label`): Select the status of the incident from the options provided.
* **User** (`security_incident_user_label`): Enter the name of the user associated with the incident.
* **Location** (`security_incident_location_label`): Enter the location where the incident occurred.
* **Note** (`security_incident_note_label`): This field is used to enter any additional comments or notes about the incident.
* **Email** (`security_incident_email_label`): Enter the email address of the user associated with the incident.
* **Phone** (`security_incident_phone_label`): Enter the phone number of the user associated with the incident.
* **Comments** (`security_incident_comments_label`): Enter any additional comments or information about the incident.
* **Attachments** (`security_incident_attachment_label`): Attach any relevant files or documents to the incident.
* **Attachment 2** (`security_incident_attachment_2_label`): Attach any additional files or documents to the incident.
* **Attachment 3** (`security_incident_attachment_3_label`): Attach any additional files or documents to the incident.
* **Attachment 4** (`security_incident_attachment_4_label`): Attach any additional files or documents to the incident.
* **Attachment 5** (`security_incident_attachment_5_label`): Attach any additional files or documents to the incident.

Note: If a field is marked as "Not Applicable" or "N/A", please select that option to indicate that the field is not relevant to the incident.
