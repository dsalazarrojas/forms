# Gaming Caution Report Form - Help Guide
## Purpose
The Gaming Caution Report Form is used to report incidents or concerns related to gaming, such as in-game behavior or online interactions. This form allows users to provide information to help resolve the issue and maintain a safe gaming environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your username (optional) in the "User Name" field.
2. If known, enter the player's ID in the "Player ID" field. If not, leave this field blank.
3. Enter the player's name (if known) in the "Player Name" field. If not, leave this field blank.
4. Enter the report ID (if known) in the "Report ID" field. If not, leave this field blank.
5. Select one of the available options for "Report Type" (Inappropriate Behavior, Spam, or Other).
6. Enter a detailed description of the incident or concern in the "Description" field.

## Field-by-Field Explanation

* **User Name**: Enter your username if you want to be contacted for further information.
* **Player ID**: Enter the player's ID (if known) to help identify the account associated with the incident.
* **Player Name**: Enter the player's name (if known) to provide more context to the incident.
* **Report ID**: Enter the report ID (if known) to provide a reference to a previous report.
* **Report Type**: Select one of the following options:
	+ Inappropriate Behavior: Report behavior that is against gaming community guidelines or terms of service.
	+ Spam: Report unwanted messages or content.
	+ Other: Report any other type of incident not listed above.
* **Description**: Enter a detailed description of the incident or concern, including as much information as possible.

## Tips

* Make sure to provide as much information as possible to help with the investigation.
* If you are reporting an incident involving multiple players, provide the names and IDs of all involved parties.
* If you are not sure what to report, choose "Other" as the report type and provide a detailed description.
