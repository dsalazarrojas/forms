# Hanaro Progress Sheet Report Template - Help Guide
## Purpose
The Hanaro Progress Sheet Report Template is designed to track student progress and performance in a language learning or skill assessment program.

## How To Complete This Form

1. Fill in the student's name and ID to identify the student.
2. Select the student's reading, listening, and understanding levels from the options provided.
3. Enter the reading, listening, and understanding levels' progress metrics (average and date).
4. Add any comments on the reading and listening sections, if applicable.
5. Enter the date the task was completed and started.
6. Select the student's progress status (Good, Fair, Poor).
7. Enter any additional progress notes.
8. Outline the next steps for the student.
9. Enter the name and contact information of the assigned user.
10. Enter the dates the task was assigned and submitted.

## Field-by-Field Explanation

* **Student Name** (`student_name`, Text, Required): Enter the student's name.
* **Student ID** (`student_id`, Number, Required): Enter the student's unique ID.
* **Reading Level** (`reading_level`, Select, Optional): Select the student's current reading level from the provided options (Level 1, Level 2, Level 3).
* **Listening Level** (`listening_level`, Select, Optional): Select the student's current listening level from the provided options (Level 1, Level 2, Level 3).
* **Understanding Level** (`understanding_level`, Select, Optional): Select the student's current understanding level from the provided options (Level 1, Level 2, Level 3).
* **Reading Comments** (`reading_comments`, Text, Required): Enter any comments on the student's reading progress.
* **Listening Comments** (`listening_comments`, Text, Required): Enter any comments on the student's listening progress.
* **Teachers Comments** (`teacher_comments`, Text, Required): Enter any comments from the teacher.
* **Date Completed** (`date_completed`, Date, Required): Enter the date the task was completed.
* **Date Started** (`date_started`, Date, Required): Enter the date the task was started.
* **Progress Status** (`progress_status`, Select Multiple, Optional): Select the student's progress status from the provided options (Good, Fair, Poor).
* **Reading Average** (`reading_average`, Number, Required): Enter the student's reading average.
* **Listening Average** (`listening_average`, Number, Required): Enter the student's listening average.
* **Understanding Average** (`understanding_average`, Number, Required): Enter the student's understanding average.
* **Reading Target Date** (`reading_target_date`, Date, Required): Enter the target date for reading.
* **Listening Target Date** (`listening_target_date`, Date, Required): Enter the target date for listening.
* **Understanding Target Date** (`understanding_target_date`, Date, Required): Enter the target date for understanding.
* **Progress Notes** (`progress_notes`, Text, Required): Enter any progress notes.
* **Next Steps** (`next_steps`, Text, Required): Outline the next steps for the student.
* **Assigned User** (`assigned_user`, Text, Required): Enter the name of the assigned user.
* **Assigned Date** (`assigned_date`, Date, Required): Enter the date the task was assigned.
* **Submitted Date** (`submitted_date`, Date, Required): Enter the date the task was submitted.
