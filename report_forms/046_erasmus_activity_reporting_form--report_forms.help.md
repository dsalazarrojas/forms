# Erasmus+ Activity Reporting Form - Help Guide

## Purpose
This form is used to report activities related to the Erasmus+ program, providing a structured way to document and report on various aspects of these activities.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of activity you wish to report (Activity A, Activity B, or Activity C).
2. Provide project details, including any relevant information about the project.
3. Enter the date and time of the activity.
4. Specify the location where the activity took place.
5. List the participants involved in the activity.
6. Describe the outcomes of the activity.
7. Mention any resources used during the activity.
8. Add any additional notes about the activity.
9. Select the evaluation criteria that best fits the activity (Criteria 1, Criteria 2, or Criteria 3).

## Field-by-Field Explanation

* **activity_type** (Select One):
  • **Activity A**: Select this option if the activity is related to a specific event or gathering.
  • **Activity B**: Select this option if the activity is related to a workshop or training.
  • **Activity C**: Select this option if the activity is related to a presentation or lecture.

* **project_details** (Text):
  • Provide a brief description of the project, including its title, objectives, and any relevant details.

* **date_of_activity** (Date):
  • Enter the date of the activity in the format YYYY-MM-DD.

* **time_of_activity** (Time):
  • Enter the time of the activity in the format HH:MM AM/PM.

* **location_of_activity** (Text):
  • Specify the location where the activity took place.

* **participants** (Text):
  • List the names and roles of all participants involved in the activity.

* **outcomes** (Text):
  • Describe the outcomes or results of the activity.

* **resources_used** (Text):
  • Mention any resources used during the activity, such as materials, equipment, or tools.

* **notes** (Note):
  • Add any additional comments or information about the activity.

* **evaluation_criteria** (Select Multiple):
  • Select all applicable evaluation criteria that fit the activity (Criteria 1, Criteria 2, or Criteria 3).
