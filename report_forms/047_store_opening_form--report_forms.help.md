# Store Opening Form - Help Guide
## Purpose
The Store Opening Form is a tool to report a new store opening, providing a structured way to collect information about each store, including address, contact details, and business hours.

## How To Complete This Form
1. Select the type of store from the dropdown menu that best describes the store category.
2. Fill in the store address, including city, state, zip code, and country.
3. Enter the store manager's name, contact information, and store hours.
4. Optionally, provide the store manager's ID number.
5. Select the store opening date.

## Field-by-Field Explanation
* **Store** (`store_opening_form_1`, text, required): Enter the category of the store (e.g., Store, Storefront, Mall).
* **Address** (`address`, text, optional): Enter the store's address.
* **Store Name** (`store_name`, text, optional): Enter the name of the store.
* **City** (`city`, text, optional): Enter the city where the store is located.
* **State** (`state`, text, optional): Enter the state where the store is located.
* **Zip Code** (`zip_code`, text, optional): Enter the store's zip code.
* **Country** (`country`, text, optional): Enter the country where the store is located.
* **Store Hours** (`store_hours`, text, optional): Enter the store's business hours.
* **Store Type** (`store_type_label`, select_one, optional): Select the type of store from the dropdown menu.
* **Store Manager's Name** (`store_manager_name`, text, optional): Enter the name of the store manager.
* **Store Manager's Contact** (`store_manager_contact`, text, optional): Enter the store manager's contact information.
* **Store Manager's Email** (`store_manager_email`, email, optional): Enter the store manager's email address.
* **Store Manager's Phone** (`store_manager_phone`, text, optional): Enter the store manager's phone number.
* **Store Manager's Address** (`store_manager_address`, text, optional): Enter the store manager's address.
* **Store Manager's Zip Code** (`store_manager_zip_code`, text, optional): Enter the store manager's zip code.
* **Store Manager's State** (`store_manager_state`, text, optional): Enter the store manager's state.
* **Store Manager's City** (`store_manager_city`, text, optional): Enter the store manager's city.
* **Store Manager's Country** (`store_manager_country`, text, optional): Enter the store manager's country.
* **Store Manager's Store Hours** (`store_manager_store_hours`, time, optional): Enter the store manager's business hours.
* **Authorized By** (`store_manager_authorized_by`, text, optional): Check this field if the store manager is authorized to manage the store.
* **Store Opening Date** (`store_opening_date`, date, optional): Enter the date the store opened.
* **Store Manager's ID Number** (`store_manager_id_number`, text, optional): Enter the store manager's ID number.
