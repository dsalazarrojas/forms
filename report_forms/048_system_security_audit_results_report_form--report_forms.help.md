# System Security Audit Results Report Form - Help Guide
## Purpose
This form is used to document the results of a system security audit, which is a process to identify risks and their levels, and outline next steps to address them.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page and ensure that you have the necessary information to fill out each field.
2. Start on Page 1 and answer the questions about Risk Outcomes and Risk Levels.
3. For each risk level, select all applicable outcomes (e.g. if you selected "High" as the risk level, select "High" for each outcome).
4. Move on to the next page to answer questions about next steps.
5. Ensure that you answer all questions and fill out all required fields before submitting the form.

## Field-by-Field Explanation

* **Risk Outcomes 1** (`Risk Outcomes 1`, Select Multiple, required/optional): Select all applicable risk outcomes (Low, Medium, High) for the current risk level.
* **Risk Levels 1** (`Risk Levels 1`, Select One, required/optional): Select the level of risk for this section (Low, Medium, High).
* **Next Steps 1** (`Next Steps 1`, Text, required/optional): Describe the next steps to be taken to address the current risk.
* **Page 2** (`Page 2`, Note, required/optional): This page is for additional comments or notes.
* **Risk Outcomes 2** (`Risk Outcomes 2`, Select Multiple, required/optional): Select all applicable risk outcomes (Low, Medium, High) for the current risk level.
* **Risk Levels 2** (`Risk Levels 2`, Select One, required/optional): Select the level of risk for this section (Low, Medium, High).
* **Next Steps 2** (`Next Steps 2`, Text, required/optional): Describe the next steps to be taken to address the current risk.
* **Page 3** (`Page 3`, Note, required/optional): This page is for additional comments or notes.

## Tips

* Be thorough in your answers to ensure that you accurately document the risk outcomes and next steps.
* Use the risk levels (Low, Medium, High) consistently throughout the form.
* If a risk level is not applicable, select "N/A" (Not Applicable) for that field.
