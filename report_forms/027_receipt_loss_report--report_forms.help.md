# Receipt Loss Report - Help Guide
## Purpose
This form is used to report a lost receipt or document related to an employee's, customer's, or vendor's property.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the relevant category (employee, customer, or vendor) to report the lost receipt or document.
2. Enter the ID number of the person or entity related to the lost item.
3. Enter the date you received the item.
4. Enter the amount missing.
5. Provide a reason for the missing item.
6. If necessary, attach any supporting documents or files.
7. Enter any additional notes.

## Field-by-Field Explanation
- **Employee ID**: Enter the ID number of the employee related to the lost item.
- **Customer ID**: Enter the ID number of the customer related to the lost item.
- **Vendor ID**: Enter the ID number of the vendor related to the lost item.
- **Date Received**: Enter the date you received the item.
- **Amount Missing**: Enter the amount missing or value of the lost item.
- **Reason Missing**: Provide a reason for the missing item, such as "misplaced," "damaged," or "stolen."
- **Supporting Documents**: If you have any supporting documents or files related to the lost item, enter a brief description of them.
- **Supporting File**: If you have a file or document that supports your claim, attach it here.
- **Notes**: Enter any additional information or comments about the lost item.

## Tips
- Make sure to enter accurate information to ensure that the report is processed correctly.
- Attach any relevant documents or files to support your claim.
- If you are unsure about any field, please consult with your supervisor or the accounting department.
