# Community Rule Violation Report Form - Help Guide
## Purpose
The Community Rule Violation Report Form is a standardized form for reporting incidents of community rule violations, providing a clear and structured process for documenting and addressing such issues.

## How To Complete This Form

1. Begin by providing a brief description of the incident on the "Violation Report Form" page.
2. Enter your name and email address on the "Reporting User" page, if you wish to be identified as the reporter.
3. Provide the name, role, and date of the accused individual on the "Accused Individual" page.
4. Specify the time and date of the incident on the "Incident Time" and "Incident Date" pages.
5. Describe the location and category of the violation on the "Location of Incident" and "Violation Category" pages.
6. Provide a detailed description of the violation and any witness information on the "Detailed Description of the Violation" and "Witness Names and Contact Info" pages.
7. Indicate whether you have any evidence supporting the report on the "Do you have evidence of the violation?" page.
8. Describe the evidence on the "Description of Evidence" page, if applicable.
9. Specify the requested action for administrative review on the "Requested Action for Administrative Review" page.
10. Sign the report with your full name on the "Reporting User Signature" page.
11. Finally, confirm the date on the "Today's Date" page.

## Field-by-Field Explanation

* **Name of Person Reporting**: A field to store the name of the individual reporting the violation.
	+ Type: Text
	+ Required: False
* **Contact Email Address**: A field to store the email address of the individual reporting the violation.
	+ Type: Email
	+ Required: False
* **Name of Accused Individual**: A field to store the name of the person accused of the violation.
	+ Type: Text
	+ Required: True
* **Accused Individual - s Role**: A field to select the role of the accused individual in the community.
	+ Type: Select One
	+ Required: True
* **Date of Incident**: A field to store the date of the incident.
	+ Type: Date
	+ Required: True
* **Time of Incident**: A field to store the time of the incident.
	+ Type: Time
	+ Required: True
* **Location of Incident**: A field to store a description of the location of the incident.
	+ Type: Text
	+ Required: True
* **Violation Category**: A field to select the category of the violation.
	+ Type: Select One
	+ Required: True
* **Detailed Description of the Violation**: A field to provide a detailed description of the violation.
	+ Type: Text
	+ Required: True
* **Witness Names and Contact Info**: A field to store the names and contact information of witnesses.
	+ Type: Text
	+ Required: False
* **Do you have evidence of the violation?**: A field to indicate whether you have evidence supporting the report.
	+ Type: Select One
	+ Required: True
* **Description of Evidence**: A field to describe the evidence, if applicable.
	+ Type: Text
	+ Required: False
* **Requested Action for Administrative Review**: A field to select the requested action for administrative review.
	+ Type: Select One
	+ Required: True
* **Reporting User Signature**: A field to store the full name of the individual signing the report.
	+ Type: Text
	+ Required: False
* **Today - s Date**: A field to store the current date.
	+ Type: Date
	+ Required: True
* **-- Confidential Submission --**: A note indicating that the report will be reviewed by the community administration.
	+ Type: Note
	+ Required: False
* **-- Signature Block --**: A note indicating that the report should be signed with the full name.
	+ Type: Note
	+ Required: False
