# Financial Forecast Revision Request Form - Help Guide
## Purpose
This form is designed to help users request a revision to a financial forecast. It provides a structured way for users to submit their requests, allowing the finance team to understand their requirements and make adjustments accordingly.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the "Submit" button to begin the form.
* Fill out the required fields with your relevant information.
* For the "Reason" field, please provide a clear and concise explanation for the revision request.
* For the "Supporting Documents" field, attach any relevant documents or files that support your request.
* In the "Review" field, select one or more teams that you would like to review the revised forecast.
* Finally, select a date for the revised forecast.

## Field-by-Field Explanation
### User Input
* **User Input** (`user_input`, text, required: false):
	+ This field is for you to provide your name or identifier.
* **Reason** (`reason_input`, text, required: false):
	+ Please provide a clear and concise explanation for the revision request.
* **Supporting Documents** (`supporting_documents_input`, text, required: false):
	+ Attach any relevant documents or files that support your request.
* **Review** (`review_input`, select multiple, required: false):
	+ Select one or more teams that you would like to review the revised forecast.
* **Date** (`date_input`, date, required: false):
	+ Select a date for the revised forecast.
