# Weekly Experiment Findings Report Form - Help Guide
## Purpose
This form is used to gather information about weekly experiment findings, allowing researchers to report their progress and results in a standardized and organized manner.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the start and end dates of the experiment from the calendar picker or enter them manually.
2. Provide the names of the researchers involved in the experiment.
3. Enter the name of the experiment and its objective.
4. Select the current status of the experiment (Active, Completed, In Progress, Cancelled).
5. Provide any relevant notes about the experiment.
6. Enter any findings or results from the experiment.
7. Specify the next steps planned for the experiment.
8. Add any action items that need to be addressed.
9. Attach any relevant files or documents to the experiment.
10. Enter the contact information of the person submitting the report.
11. Confirm the submission by providing the name of the person submitting the report.

## Field-by-Field Explanation

* **start_date** (`start_date`, date, required): The date when the experiment started.
* **end_date** (`end_date`, date, required): The date when the experiment ended.
* **researcher_names** (`researcher_names`, text, optional): Names of researchers involved in the experiment.
* **experiment_name** (`experiment_name`, text, required): Name of the experiment.
* **objective** (`objective`, text, required): Objective of the experiment.
* **experiment_status** (`experiment_status`, select_one, required): Status of the experiment (Active, Completed, In Progress, Cancelled).
* **notes** (`notes`, text, optional): Any relevant notes about the experiment.
* **findings** (`findings`, text, required): Results or findings from the experiment.
* **next_steps** (`next_steps`, text, optional): Next steps planned for the experiment.
* **action_items** (`action_items`, text, optional): Action items that need to be addressed.
* **attachment** (`attachment`, text, optional): Attach any relevant files or documents to the experiment.
* **email** (`email`, email, required): Contact email of the person submitting the report.
* **phone** (`phone`, text, optional): Contact phone number of the person submitting the report.
* **url** (`url`, text, required): URL related to the experiment.
* **comments** (`comments`, text, optional): Any additional comments about the experiment.
* **created_date** (`created_date`, date, required): The date when the report was created.
* **updated_date** (`updated_date`, date, required): The date when the report was last updated.
* **submitted_by** (`submitted_by`, text, required): Name of the person submitting the report.
* **submitted_to** (`submitted_to`, text, required): Name of the person or team the report was submitted to.
* **submitted_on** (`submitted_on`, date, required): Date when the report was submitted.
* **submitted_by_name** (`submitted_by_name`, text, required): Name of the person submitting the report.
* **created_by** (`created_by`, text, required): Name of the person creating the report.
* **created_by_name** (`created_by_name`, text, required): Name of the person creating the report.
* **attachments** (`attachments`, text, optional): Any attached files or documents to the report.
