# Infection Control Monthly Compliance Report - Help Guide
## Purpose
This form is designed to help facilities track and report incidents that have occurred during the month, as part of the infection control and compliance process. The purpose of this form is to collect information on incident dates, descriptions, and statuses to help facilities identify areas for improvement and take necessary actions to prevent future incidents.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the **Incident Date** of the incident in the "Incident Date" field.
2.  Provide a detailed description of the incident in the "Incident Description" field.
3.  Indicate whether the incident was reviewed by selecting "True" or "False" in the "Reviewer" field.
4.  Describe the **Prevention Actions Taken** to address the incident in the "Prevention Actions Taken" field.
5.  Select the **Incident Status** (Active or Inactive) and the **Follow Up Action** to document the incident's current status.
6.  If applicable, enter the **Facility** name in the corresponding field.
7.  Optionally, select the "Reviewer's Name" if you have been assigned to review the incident.
8.  If applicable, enter a second **Follow Up Action** in the "Follow Up Action 2" field.
9.  Select the **Incident Status 2** (Active or Inactive) if the incident status has changed.
10. Enter any additional details regarding **Actions Taken** in the "Actions Taken" field.
11. Enter the name of the **Facility** where the incident occurred.
12. Optionally, select "True" or "False" in the "Reviewer 2" field if another reviewer has reviewed the incident.

## Field-by-Field Explanation
* **Incident Date**: Enter the date when the incident occurred.
* **Incident Description**: Provide a detailed description of the incident.
* **Reviewer**: Select "True" if you reviewed the incident, "False" otherwise.
* **Prevention Actions Taken**: Describe the actions taken to prevent future incidents.
* **Incident Status**: Select "Active" or "Inactive" to indicate the incident's current status.
* **Follow Up Action**: Describe the follow-up actions taken for the incident.
* **Facility**: Enter the name of the facility where the incident occurred.
* **Reviewer's Name**: Enter your name as the reviewer of the incident (optional).
* **Follow Up Action 2**: Enter any additional follow-up actions taken for the incident.
* **Incident Status 2**: Select "Active" or "Inactive" if the incident status has changed.
* **Actions Taken**: Describe any additional actions taken to address the incident.
* **Facility Name**: Enter the name of the facility where the incident occurred.
* **Reviewer 2**: Select "True" if another reviewer has reviewed the incident (optional).
