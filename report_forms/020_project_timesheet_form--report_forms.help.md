# Project Timesheet Form - Help Guide
## Purpose
The Project Timesheet Form is used to track and manage projects and tasks. It collects information such as project title, description, estimated start and end dates, task status, project status, task priority, and resource name.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title of the project in the "Project Title" field.
2. Describe the task in the "Task Description" field.
3. Enter the estimated start date of the task in the "Estimated Start Date" field.
4. Enter the estimated end date of the task in the "Estimated End Date" field.
5. Select the status of the task in the "Task Status" field (Active or Inactive).
6. Select the status of the project in the "Project Status" field (Active or Inactive).
7. Indicate the priority of the task in the "Task Priority" field (Yes or No).
8. Enter the name of the resource assigned to the task in the "Resource Name" field.

## Field-by-Field Explanation
* **Project Title** (`project_title`, text, optional): Enter a brief title of the project.
* **Task Description** (`task_description`, text, optional): Describe the task in a few sentences.
* **Estimated Start Date** (`estimated_start_date`, date, optional): Enter the estimated start date of the task.
* **Estimated End Date** (`estimated_end_date`, date, optional): Enter the estimated end date of the task.
* **Task Status** (`task_status`, select_multiple, required): Select the status of the task (Active or Inactive).
* **Project Status** (`project_status`, select_one, optional): Select the status of the project (Active or Inactive).
* **Task Priority** (`task_priority`, select_one, optional): Indicate the priority of the task (Yes or No).
* **Resource Name** (`resource_name`, text, optional): Enter the name of the resource assigned to the task.

## Tips
* Make sure to enter accurate and up-to-date information to ensure that your project and task progress is tracked correctly.
* If you're unsure of any field, contact your supervisor or project manager for guidance.
* Use a consistent format for project and task titles to make it easy to distinguish between them.
