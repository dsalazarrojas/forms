# Game Bug Report Form - Help Guide

## Purpose
This form is used to report bugs or issues encountered while playing the game.

## How To Complete This Form
To report a bug, please go through each field in the following sections:

## Field-by-Field Explanation
* **Game Mode** (`game_mode`, select_one): Select the game mode you were playing when the issue occurred.
* **Issue Description** (`issue_description`, text): Describe the issue you encountered, including any error messages or symptoms you experienced.
* **Error Code** (`error_code`, text): If you have an error code or message, enter it here to help the team reproduce the issue.
* **Frequency** (`frequency`, text): Indicate how often you encounter this issue, e.g., always, sometimes, or rarely.
* **Screenshot Upload** (`screenshot_upload`, text): If relevant, attach a screenshot of the issue to help illustrate the problem.
* **Video Upload** (`video_upload`, text): If possible, upload a video recording of the issue to help the team understand what happened.
* **Version** (`version`, number): Enter the game version you are currently playing, e.g., 1.2.3.
* **Report Submit** (`report_submit`, select_one): Choose to submit your report or cancel.

### Tips
* Be as detailed as possible when describing the issue you encountered.
* If you are unsure what to report, try to provide as much information as you can about the context and circumstances surrounding the issue.
* Ensure you fill in all required fields, even if it seems minor.
* Attach screenshots and videos only if they are relevant and help illustrate the issue.
* Review your report before submitting it to ensure it accurately reflects the issue you encountered.

Note: This guide is based on the provided form fields and their labels. If any field label seems unclear or weak, the explanation is provided in a way that best represents the field's intent.
