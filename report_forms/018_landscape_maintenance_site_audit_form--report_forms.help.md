# Landscape Maintenance Site Audit Form - Help Guide
## Purpose

This form is used to collect and track information on ongoing or completed landscape maintenance projects. The collected data will be used to maintain records and track project progress.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure that all required fields are completed.
3. Review the form before submitting to ensure that everything is correct.

## Field-by-Field Explanation

* **Project Name (1)** (`project_name`, text, required)
	+ This field is used to enter the name of the project.
	+ Ensure that the project name is accurate and up-to-date.
* **Site Address (2)** (`site_address`, text, required)
	+ This field is used to enter the site address where the project is located.
	+ Enter the address in the correct format (e.g., street address, city, state, zip).
* **Project Status (3)** (`project_status`, select_multiple, required)
	+ This field is used to select the current status of the project.
	+ Choose one or more of the following options: Active, Inactive, or Pending.
* **Photos Taken (4)** (`photos_taken`, select_one, required)
	+ This field is used to indicate if photos were taken during the project.
	+ Choose 'True' if photos were taken, and 'False' otherwise.
* **Notes (5)** (`notes`, note, optional)
	+ This field is used to add any additional comments or notes about the project.
	+ Enter any relevant information that may be helpful for project tracking.
* **Date Completed (6)** (`date_completed`, date, required)
	+ This field is used to enter the date when the project was completed.
	+ Enter the date in the correct format (e.g., MM/DD/YYYY).
* **Comments (7)** (`comments`, text, optional)
	+ This field is used to add any additional comments or notes about the project.
	+ Enter any relevant information that may be helpful for project tracking.
* **User Comments (8)** (`user_comments`, text, optional)
	+ This field is used to add any comments or notes from the user who completed the form.
	+ Enter any relevant information that may be helpful for project tracking.

## Tips

- Ensure that all fields are completed accurately and completely.
- Review the form before submitting to ensure that everything is correct.
- If you are unsure about any field, please consult with your team or supervisor.
