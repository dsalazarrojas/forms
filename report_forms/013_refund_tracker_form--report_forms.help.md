# refund_tracker_form - Help Guide
## Purpose
The refund tracker form is used to track and report refunds for customers. This form is designed to be completed by both users and administrators to provide detailed information about refunds, including dates, amounts, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **User Input** field with the relevant information about the refund.
2. Select the **Date Received** field to enter the date the refund was received.
3. Enter the **Tracking Number** to track the refund.
4. Enter the **Order ID** associated with the refund.
5. Enter a brief description of the refund.
6. Select the current **Status** of the refund (e.g., Refund Initiated, Refund In Progress, Refund Complete).
7. Enter the **Amount** of the refund.
8. Enter any **User Message** regarding the refund.
9. Enter any **Admin Message** regarding the refund.
10. Enter a **Tracking Link** related to the refund.
11. Enter **Tracking Info** about the refund.
12. Select the current **Tracking Status** (e.g., Active, Inactive, Error).
13. Enter an expected **Expected Date** for the refund.
14. Enter an **Actual Date** for the refund.
15. Enter any **User Comments** about the refund.
16. Enter any **Admin Comments** about the refund.
17. Select the current **Tracking Link Status** (e.g., Active, Inactive, Error).
18. Enter **Tracking Status Notes** about the refund.
19. Enter a date for the **Tracking Status Date**.
20. Enter any **Notes** about the refund.
21. Enter the last update date in **Last Updated**.
22. Enter the date the form was **Created At**.
23. Enter the name of the person who **Created By**.
24. Enter the name of the person who last updated the form in **Updated By**.
25. Enter the date the form was last updated in **Updated At**.

## Field-by-Field Explanation

* **User Input**: Enter any relevant information about the refund.
* **Date Received**: Enter the date the refund was received.
* **Tracking Number**: Enter the tracking number associated with the refund.
* **Order ID**: Enter the ID associated with the refund.
* **Description**: Enter a brief description of the refund.
* **Status**: Select the current status of the refund (e.g., Refund Initiated, Refund In Progress, Refund Complete).
* **Amount**: Enter the amount of the refund.
* **User Message**: Enter any message from the user regarding the refund.
* **Admin Message**: Enter any message from the administrator regarding the refund.
* **Tracking Link**: Enter a link related to the tracking status.
* **Tracking Info**: Enter any information about the tracking status.
* **Tracking Status**: Select the current tracking status (e.g., Active, Inactive, Error).
* **Expected Date**: Enter the expected date for the refund.
* **Actual Date**: Enter the actual date for the refund.
* **User Comments**: Enter any comments from the user regarding the refund.
* **Admin Comments**: Enter any comments from the administrator regarding the refund.
* **Tracking Link Status**: Select the current status of the tracking link (e.g., Active, Inactive, Error).
* **Tracking Status Notes**: Enter any notes regarding the tracking status.
* **Tracking Status Date**: Enter a date for the tracking status.
* **Notes**: Enter any notes about the refund.
* **Last Updated**: Enter the last update date.
* **Created At**: Enter the date the form was created.
* **Created By**: Enter the name of the person who created the form.
* **Updated By**: Enter the name of the person who last updated the form.
* **Updated At**: Enter the date the form was last updated.
