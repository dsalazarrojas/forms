# Medication Error Report Form - Help Guide
## Purpose
The Medication Error Report Form is used to report errors that have occurred with medication administration. This form is used to provide detailed information about the error, including the facility where it occurred, the status of the report, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the facility where the error occurred from the select_one field.
2. Enter a brief description of the error in the description field.
3. Select the status of the report (e.g., pending, resolved) from the select_one field.
4. Enter the date and time the report is being submitted in the report_date and report_time fields.
5. Enter any additional information about the facility in the facility fields.
6. Enter the provider's ID, name, and other relevant information in the provider fields.
7. Enter the patient's ID in the patient_id field.
8. Enter a report number if you have one.
9. Click the submit button to submit your report.
