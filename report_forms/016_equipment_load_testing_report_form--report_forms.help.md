# Equipment Load Testing Report Form - Help Guide
## Purpose
The Equipment Load Testing Report Form is used to capture information about equipment load testing, which is a process of measuring the performance of a piece of equipment under controlled load conditions.

## How To Complete This Form
1. Ensure you have all necessary information and attachments before starting the form.
2. Review the form carefully to ensure you understand each field and its purpose.
3. Complete the form accurately and thoroughly.

## Field-by-Field Explanation
* **Load testing summary**: This field is for a brief description of the testing process. Please provide a concise summary of the test, including the equipment being tested, the testing location, and any other relevant details.
* **Equipment type**: Select the type of equipment that was tested (1, 2, or 3).
* **Test duration**: Enter the date of the test (in mm/dd or dd/mm/yyyy format).
* **Test frequency**: Enter the frequency of the test (e.g., daily, weekly, monthly).
* **Load test results**: This field is for any relevant comments or results from the test. Please provide any notes or observations from the test.
* **Comments**: This field is for any additional comments or notes about the test.
* **Attachments**: You can attach any relevant documents or files to the form.
* **Assigned inspector**: Select the inspector who conducted the test (assigned tool or other).
* **Date test conducted**: Enter the date of the test (in mm/dd or dd/mm/yyyy format).
* **Equipment model**: Select the model of the equipment tested (1, 2, or 3).
* **Test location**: Enter the location where the test was conducted (e.g., lab, field, warehouse).
* **Weather conditions**: Select the weather conditions during the test (sunny, cloudy, rainy).

Note: If a field is marked as "required", please ensure it is completed accurately and thoroughly. If you are unsure about any field, please refer to this guide for clarification.
