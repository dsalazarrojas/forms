# service_interruption_notice_form - Help Guide

## Purpose
The Service Interruption Notice Form is used to notify administrators of service interruptions, allowing them to track and respond to such events. This form helps ensure prompt attention to disruptions that affect service availability.

## How To Complete This Form

1. Select the correct options for each field as instructed below.

## Field-by-Field Explanation

* **Service Interruption Type**: Choose the type of interruption that has occurred, such as yes or no.
	+ This field helps the administrator categorize and identify the type of interruption.
* **Interruption Date**: Enter the date the interruption occurred.
	+ This field ensures that the date is recorded accurately for tracking and reference purposes.
* **Time**: Enter the time the interruption started.
	+ This field is useful for pinpointing the exact time the interruption began.
* **Description**: Provide a detailed description of the interruption, including its nature and impact.
	+ This field is essential for understanding the cause and effects of the interruption.
* **Service Affected**: Select all services that were affected by the interruption.
	+ This field helps the administrator identify which services were impacted and plan accordingly.
* **Contact**: Enter the contact person's email address.
	+ This field allows the administrator to reach out for further information or assistance.
* **Note**: Add any additional comments or notes about the interruption.
	+ This field is for free-form text input for any relevant details.
* **Phone**: Enter a phone number if applicable.
	+ This field allows the administrator to contact the individual directly.
* **Category**: Determine if the interruption was categorized as yes or no.
	+ This field aids in organizing and grouping similar interruptions.
* **Location**: Select the location affected by the interruption.
	+ This field helps pinpoint the exact location of the interruption.
* **Assigned Tool**: Identify which tool was assigned to address the interruption.
	+ This field ensures that the correct tool is used to resolve the issue.
* **Submitted By**: Select who submitted the interruption report.
	+ This field tracks who reported the interruption for reference and follow-up.
* **Form ID**: Enter a unique ID for the form submission.
	+ This field is useful for internal tracking and reference purposes.
* **Output File**: Determine if a file should be exported.
	+ This field controls the export of a report for further analysis or reference.

## Tips
- Ensure accuracy when filling in fields to provide a clear picture of the interruption.
- Review each field to ensure it is filled out correctly according to the provided instructions.
- If unsure about any field, refer to the provided options or ask an administrator for guidance.
