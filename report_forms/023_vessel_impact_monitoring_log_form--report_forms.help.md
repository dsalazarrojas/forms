# Vessel Impact Monitoring Log Form - Help Guide
## Purpose
The Vessel Impact Monitoring Log Form is used to record and document incidents that have occurred on or around vessels. This form helps to gather relevant information about incidents, including date, time, location, and description, to ensure accurate reporting and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the "Incident Date" field with the date the incident occurred.
2. Next, fill out the "Incident Time" field with the time the incident occurred.
3. Provide a detailed description of the incident in the "Description" field.
4. Select the type of incident that occurred from the "Incident Type" field (e.g. Boat, Diving, Other).
5. If applicable, select the cause of the incident from the "Incident Cause" field (e.g. Boat, Diving, Human, Equipment, Other).
6. If injuries or damage occurred, provide a brief description in the "Injuries" and "Damage" fields.
7. If applicable, record any costs associated with the incident in the "Costs" field.
8. Upload any relevant images, videos, or audio recordings of the incident in the "Incident Image", "Incident Video", and "Incident Audio" fields.
9. If an officer is assigned to investigate or respond to the incident, select their name from the "Assigned Officer" field.
10. If a specific tool or equipment is required for investigation or response, select the tool from the "Assigned Tool" field.
11. Finally, provide the location where the incident occurred in the "Assigned Location" field.

## Field-by-Field Explanation

* **Incident Date**: Enter the date the incident occurred. Use the format MM/DD/YYYY.
* **Incident Time**: Enter the time the incident occurred. Use the format HH:MM AM/PM.
* **Incident Location**: Enter a detailed description of the location where the incident occurred.
* **Description**: Provide a detailed description of the incident.
* **Incident Type**: Select the type of incident that occurred (e.g. Boat, Diving, Other).
* **Incident Cause**: If applicable, select the cause of the incident (e.g. Boat, Diving, Human, Equipment, Other).
* **Injuries**: If applicable, provide a brief description of any injuries sustained during the incident.
* **Damage**: If applicable, provide a brief description of any damage sustained during the incident.
* **Costs**: If applicable, record any costs associated with the incident.
* **Incident Image**: Upload any relevant images of the incident.
* **Incident Video**: Upload any relevant videos of the incident.
* **Incident Audio**: Upload any relevant audio recordings of the incident.
* **Assigned Officer**: Select the name of the officer assigned to investigate or respond to the incident.
* **Assigned Tool**: Select the tool or equipment required for investigation or response.
* **Assigned Location**: Enter the location where the incident is being investigated or responded to.

## Tips

* Be as detailed and accurate as possible when filling out the form.
* Use clear and concise language when describing the incident.
* If you are unsure about any field, do not hesitate to consult with the assigned officer or supervisor.
* This form is intended for recording incidents that occurred on or around vessels, so only report incidents that meet this criteria.
