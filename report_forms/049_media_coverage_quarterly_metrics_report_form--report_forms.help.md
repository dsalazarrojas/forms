## Media Coverage Quarterly Metrics Report Form - Help Guide
## Purpose
This form is used to track and report metrics related to media coverage, allowing users to provide an overview of their media activities and efforts. The report form covers various aspects of media coverage, including media channels, types, and values for each quarter.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the media coverage metrics for the current quarter.
2. Select the relevant media channels and types that apply to your report.
3. Enter the values for each of the media coverage metrics (Earned Media Value, Advertising Value, Public Relations Value, Event Value, Media Coverage Value, and Other Value).
4. Add any additional notes or comments about your media coverage activities.

## Field-by-Field Explanation

- **Media Coverage Quarterly Metrics Report Form** (required: no): This is the title of the report form.
- **Media Coverage Quarterly Metrics** (required: no): This field is a placeholder for media coverage metrics.
- **Quarter** (required: no): Select the quarter for which you are reporting media coverage metrics (Quarter 1, Quarter 2, Quarter 3, or Quarter 4).
- **Media Channel** (required: no): Select all media channels that applied to your report (Online, Print, Social, Broadcast).
- **Media Type** (required: no): Select all media types that applied to your report (Press Release, Press Conference, Press Release and Press Conference, Press Release and Social Media, Social Media).
  - **Note**: This field might be a little ambiguous, but it's meant to capture the type of media coverage you've done. For example, if you've sent out a press release and also used social media, select "Press Release and Social Media".
- **Earned Media Value** (required: no): Enter the value of the media coverage (e.g., 500, 1000, etc.).
- **Advertising Value** (required: no): Enter the value of the advertising (e.g., 500, 1000, etc.).
- **Public Relations Value** (required: no): Enter the value of the public relations (e.g., 500, 1000, etc.).
- **Event Value** (required: no): Enter the value of the event (e.g., 500, 1000, etc.).
- **Media Coverage Value** (required: no): Enter the value of the media coverage (e.g., 500, 1000, etc.).
- **Other Value** (required: no): Enter any other value related to your media coverage (e.g., 500, 1000, etc.).
- **Notes** (required: no): Add any additional comments or notes about your media coverage activities.

## Tips
- Make sure to select all relevant media channels and types that applied to your report.
- Enter accurate values for each metric.
- Use the "Notes" field to provide any additional context or information about your media coverage activities.
