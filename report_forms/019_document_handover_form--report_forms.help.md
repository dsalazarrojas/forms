# Document Handover Form - Help Guide

## Purpose
The Document Handover Form is a tool used to facilitate the handover of documents between teams or departments within an organization. It allows users to input necessary information about the document, including its title, date, type, and other relevant details. The form also requires the user to select a client's contact email address and upload the actual document file. 

## How To Complete This Form
To complete the Document Handover Form, follow these steps:

1. Start by filling out the "Document Title" field, which is a text input field that requires a brief description of the document.
2. Select the appropriate "Document Type" from the dropdown menu, choosing from one of the listed options such as "Business Report", "Financial Report", "Presentation", etc.
3. Enter the "Date" of the document in the format "YYYY-MM-DD".
4. Select the "Client Name" from the list of available options, or type it manually if not found in the list.
5. Enter the "Contact E-mail" of the client, which will be used for communication.
6. If available, enter the "Client Phone" number for further contact.
7. Input any additional "Document Notes" that are relevant to the handover.
8. Upload the actual document file using the "Upload File" button.
9. Finally, click "Submit" to submit the form.

## Field-by-Field Explanation
* **Document Title**: A text input field where you need to input the title of the document.
* **Document Date**: A date input field where you need to input the date of the document, in YYYY-MM-DD format.
* **Document Type**: A dropdown menu where you select the type of the document, which helps in organizing and categorizing.
* **Client Name**: A text input field where you need to input the name of the client for whom the document is meant.
* **Contact E-mail**: A text input field where you need to input the email address of the client, for future reference and communication.
* **Client Phone**: An optional text input field where you can input the phone number of the client.
* **Document Notes**: A text input field where you can input any additional notes related to the document.
* **Upload File**: An optional file upload field where you need to upload the actual document file.
* **Submit**: A submit button that finalizes the form and saves the handover information.

## Tips
* Always ensure you have the permission to access and upload the document to be handover.
* Double check all fields to ensure they are filled out correctly before submitting the form.
* Use the "Document Type" field to ensure the document is correctly categorized.
* Use descriptive text for the "Document Title" and "Client Name" fields to ensure easy reference and search.
* Be accurate when entering the "Contact E-mail" and "Client Phone" to ensure proper communication with the client.
