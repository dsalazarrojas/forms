# Human Verification Issue Report Form - Help Guide
## Purpose

This form is used to report human verification issues to our team. Please fill it out to provide us with details about the problem you're experiencing.

## How To Complete This Form

1. Fill out the form carefully, providing as much detail as possible.
2. Make sure to review each field to ensure you're providing all necessary information.
3. If you're unsure about a field, refer to the field-by-field explanation below.

## Field-by-Field Explanation

### Report
**Report** (`1`, `text`, required: false)

* This is a free-form text field where you can describe the problem you're experiencing with human verification.

### User Info
**User Info** (`2`, `select_one`, required: false)

* Choose 'Yes' if you believe the issue is related to your user account or 'No' if it's not.

### Context
**Context** (`3`, `text`, required: false)

* Provide additional details about the issue, such as what steps you took to get to the problem.

### Screenshot URL
**Screenshot URL** (`4`, `text`, required: false)

* If applicable, enter the URL of the screenshot related to the issue.

### Steps to Reproduce
**Steps to Reproduce** (`5`, `text`, required: false)

* Describe the steps you took to get to the issue, step-by-step.

### Error Message
**Error Message** (`6`, `text`, required: false)

* If you've encountered an error message while experiencing the issue, enter it here.

### Additional Info
**Additional Info** (`7`, `text`, required: false)

* Enter any additional information you think is helpful for our team to understand and resolve the issue.

### Attachments
**Attachments** (`8`, `select_multiple`, required: false)

* Choose 'Yes' if you have attachments related to the issue, such as screenshots or log files.

### Reporting Technology
**Reporting Technology** (`9`, `select_multiple`, required: false)

* Choose 'Yes' if you're reporting an issue with a specific technology or platform.

### Report Form Version
**Report Form Version** (`10`, `select_one`, required: false)

* Choose 'Yes' if you're reporting an issue with this specific version of the report form.

Please note that while these fields are not required, providing as much information as possible will help our team better understand and resolve the issue.
