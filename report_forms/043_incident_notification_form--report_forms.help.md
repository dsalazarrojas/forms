# Incident Notification Form - Help Guide
## Purpose

The Incident Notification Form is designed to gather information on incidents that require reporting to the authorities. This form is used to provide a clear and concise report of the incident, including the type of incident, location, and any supporting evidence such as images, videos, or audio recordings.

## How To Complete This Form

1. Select the type of incident that occurred (e.g., Accident, Security Breach, Property Damage).
2. Provide the date of the incident.
3. Enter a brief description of what happened.
4. If applicable, attach any supporting images, videos, or audio recordings to help provide more context to the report.

## Field-by-Field Explanation
* **Incident Type** (`incident_type`):
	+ Choose the type of incident that occurred, such as Accident, Security Breach, or Property Damage.
* **Incident Date** (`incident_date`):
	+ Enter the date and time the incident occurred in the format of YYYY-MM-DD.
* **Incident Location** (`incident_location`):
	+ Enter the location where the incident occurred.
* **Incident Description** (`incident_description`):
	+ Provide a brief description of what happened.
* **Incident Image** (`incident_image`):
	+ Attach any relevant images that support the report.
* **Incident Video** (`incident_video`):
	+ Attach any relevant videos that support the report.
* **Incident Audio** (`incident_audio`):
	+ Attach any relevant audio recordings that support the report.

## Tips

* Please ensure that the information provided is accurate and factual.
* Use the correct incident type and location to help identify the incident correctly.
* Only attach supporting evidence if it is relevant to the report.
* Do not submit duplicate reports for the same incident.
* If you need help or have questions, contact [support contact].
