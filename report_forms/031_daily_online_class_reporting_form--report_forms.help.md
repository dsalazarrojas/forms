# Daily Online Class Reporting Form - Help Guide

## Purpose
The Daily Online Class Reporting Form is designed to gather detailed information about online classes, including class attendance, teacher comments, student feedback, and submitted reports. This form is used to report daily classes and gather feedback from students and teachers.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Class Reporter Name, Class Reporter Email, and Teacher Name fields with your relevant information.
2. Enter the Class ID number to identify the class you are reporting on.
3. Select the Date Reported for when the class occurred.
4. Provide Student Feedback to share with the teacher about the class.
5. Enter Teacher Comments to provide additional information about the class.
6. Choose the Class Attendance status (Active, Inactive, or Unknown) and enter any additional Class Attendance comments.
7. Enter the submitted and submitted time to record when the report was submitted.
8. Fill in the Student Name, Class Subject, Class Grade, Class Level, and Class Location fields with your relevant information.
9. Enter the Class Duration in minutes.
10. Fill in the Class Start and Class End Time fields to indicate the start and end times of the class.
11. Enter the Class Start Date for when the class started.
12. Choose who submitted the report (User, Teacher, or Admin).
13. Fill in the Teacher ID field, if applicable.
14. Finally, click submit to submit your report.

## Field-by-Field Explanation

* **Class Reporter Name**: Enter the name of the person submitting the report.
* **Class Reporter Email**: Enter the email of the person submitting the report.
* **Teacher Name**: Enter the name of the teacher who taught the class.
* **Class ID**: Enter the ID number of the class being reported on.
* **Date Reported**: Enter the date the class occurred.
* **Student Feedback**: Provide feedback about the class from the students.
* **Teacher Comments**: Provide comments or feedback about the class from the teacher.
* **Class Attendance**: Select the status of the class (Active, Inactive, or Unknown).
* **Class Attendance Options**: Enter any additional comments about the class attendance.
* **Submitted**: Enter the date and time the report was submitted.
* **Submitted By**: Choose who submitted the report (User, Teacher, or Admin).
* **Teacher ID**: Enter the ID number of the teacher who taught the class, if applicable.
* **Class Duration**: Enter the duration of the class in minutes.
* **Class Start Time**: Enter the start time of the class.
* **Class End Time**: Enter the end time of the class.
* **Class Start Date**: Enter the date the class started.
* **Student Name**: Enter the name of the student in the class.
* **Class Subject**: Enter the subject of the class.
* **Class Grade**: Enter the grade level of the class.
* **Class Level**: Enter the level of the class (e.g., beginner, intermediate, advanced).
* **Class Location**: Enter the location of the class.
* **Class Status**: Select the status of the class (Active, Inactive, or Unknown).
* **Class Comments**: Enter any additional comments about the class.
* **Student Comments**: Enter any additional comments from the student about the class.

Note: This form is designed to be used daily, so make sure to fill it out promptly after each class.
