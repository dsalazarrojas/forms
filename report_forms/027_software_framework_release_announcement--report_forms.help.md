# Software Framework Release Announcement - Help Guide
## Purpose
The "Software Framework Release Announcement" form is used to collect and document information about the release of a software framework. This includes details such as release date, version, and impact of changes made in the release.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary information about the software framework release, including its release date, version, and impact of changes.
2. Fill out the "Release Date" field with the actual release date of the software framework.
3. Enter the "Release Version" of the software framework.
4. Provide a brief "Change Log" summarizing the changes made in the release.
5. Describe the "Change Description" of the release, including any notable changes or updates.
6. Select the "Change Impact" that best describes the potential impact of the changes made in the release.
7. Add any additional details about the change impact in the "Change Impact Details" field.
8. Enter any "Release Notes" or additional information about the release.
9. Provide the "Support Contact" information for users who may need assistance.
10. Review all fields carefully before submitting the form.

## Field-by-Field Explanation

* **Release Information (Page 1)** (`software_framework_release_announcement`, text, required: false)
	+ This field is used to enter a brief description of the release.
* **Change Log (Page 2)** (`software_framework_change_log`, note, required: false)
	+ This field is used to provide a summary of the changes made in the release.
* **Change Description (Page 3)** (`software_framework_change_description`, text, required: false)
	+ This field is used to describe the changes made in the release in more detail.
* **Change Impact (Page 4)** (`software_framework_change_impact`, select_one, required: false)
	+ Select one of the following:
		- High
		- Low
		- Medium
	+ This field is used to indicate the potential impact of the changes made in the release.
* **Release Date (Page 5)** (`software_framework_release_date`, date, required: false)
	+ Enter the date the software framework was released.
* **Release Version (Page 6)** (`software_framework_release_version`, text, required: false)
	+ Enter the version of the software framework released.
* **Release Summary (Page 7)** (`software_framework_change_summary`, text, required: false)
	+ This field is used to provide a brief summary of the release.
* **Release Notes (Page 8)** (`software_framework_release_notes`, note, required: false)
	+ This field is used to enter any additional information about the release.
* **Support Contact (Page 9)** (`software_framework_support_contact`, email, required: false)
	+ Enter the contact information for users who may need assistance with the software framework.
* **Change Impact Details (Page 10)** (`software_framework_change_impact_details`, text, required: false)
	+ This field is used to provide additional details about the impact of the changes made in the release.

## Tips

* Please fill out the fields carefully and accurately to ensure the correct information is recorded about the software framework release.
* Review all fields before submitting the form to ensure completeness and accuracy.
* If you are unsure about any field, consult with the responsible party or contact person for clarification.
