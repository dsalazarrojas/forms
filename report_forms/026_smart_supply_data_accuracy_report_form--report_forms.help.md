# Smart Supply Data Accuracy Report Form - Help Guide
## Purpose
The Smart Supply Data Accuracy Report Form is a tool used to report issues and discrepancies in the data supply process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **User Id** (if required).
2. Provide your **User Name**.
3. Describe the **Issue Description** in detail.
4. Enter the **Issue Date** and **Issue Time** of the discrepancy.
5. Select the **Data Source** where the issue was found.
6. Assign the issue to someone in the **Assigned To** field.
7. Choose the **Status** of the issue (New, Open, Closed, or Pending).
8. Select the **Priority** level of the issue (High, Medium, or Low).
9. Enter the **Due Date** and **Due Time** if applicable.
10. Add any comments related to the issue in the **Comments** field.
11. Select the comments history from the **Comments History** field.
12. Upload any relevant **Attachment File**.
13. Add any **Attachment Comment**.
14. Choose the **Issue Type** (Type 1, Type 2, or Type 3).
15. Select any relevant **Issue Tags** (Tag 1, Tag 2, or Tag 3).

## Field-by-Field Explanation

* **User Id**: Enter your unique user ID (if required).
* **User Name**: Enter your name.
* **Issue Description**: Describe the issue in detail.
* **Issue Date**: Enter the date the issue was found.
* **Issue Time**: Enter the time the issue was found.
* **Data Source**: Select the source where the issue was found.
* **Comments**: Add any comments related to the issue.
* **Comments History**: Select any comments history related to the issue.
* **Attachment File**: Upload any relevant file related to the issue.
* **Attachment Comment**: Add any comments related to the attachment.
* **Assigned To**: Assign the issue to someone.
* **Status**: Choose the status of the issue (New, Open, Closed, or Pending).
* **Priority**: Choose the priority level of the issue (High, Medium, or Low).
* **Due Date**: Enter the due date of the issue.
* **Due Time**: Enter the due time of the issue.
* **Completed**: Add any information related to the issue's completion.
* **Comments History**: Select any comments history related to the issue.
* **Attachment File**: Upload any relevant file related to the issue.
* **Attachment Comment**: Add any comments related to the attachment.
* **Issue Type**: Choose the type of issue (Type 1, Type 2, or Type 3).
* **Issue Tags**: Select any relevant tags related to the issue (Tag 1, Tag 2, or Tag 3).

Note: The fields marked as "required" are mandatory.
