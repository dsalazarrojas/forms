# Daily Encounter Log - Help Guide
## Purpose
This form is used to record and document daily encounters between users and customers.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields, including:
	+ Date (page 2)
	+ User (page 1)
	+ Interaction Type (page 3)
* Provide a brief description of the encounter (page 4)
* If an incident occurred, select the appropriate incident type (page 5)
* Enter any relevant location information (page 6)
* Provide any follow-up information (page 7)
* Add any additional notes about the encounter (page 8)
* If applicable, select the user that will be handling the follow-up (page 9)

## Field-by-Field Explanation
* **User (page 1)**: Enter the user who was involved in the encounter.
* **Date (page 2)**: Enter the date of the encounter. 
* **Interaction Type (page 3)**: Select whether the interaction was a "Yes" or "No" interaction.
* **Description (page 4)**: Provide a brief description of what happened during the encounter.
* **Incident Type (page 5)**: If an incident occurred, select the type of incident that took place.
* **Location (page 6)**: Enter any relevant location information about the encounter.
* **Follow-up (page 7)**: Provide any follow-up information about the encounter.
* **Notes (page 8)**: Add any additional notes about the encounter.
* **Assigned User (page 9)**: If applicable, select the user that will be handling the follow-up.
