# Student Incident Report Form - Help Guide

## Purpose
The Student Incident Report Form is a tool used to document and report incidents that occur during school hours. This form helps school administrators track and address incidents in a timely and efficient manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Student ID field with the student's ID number.
2. Enter the date and time of the incident in the Incident Date and Incident Time fields.
3. Fill out the Student Name field with the student's name.
4. Select the Student Grade level the student is in (e.g., 'Yes' for students who are eligible for the report).
5. Provide a detailed description of the incident in the Incident Description field.
6. Add any relevant comments from the teacher in the Teacher Comments field.
7. Set the Report Status to indicate whether the report is Active or Inactive.
8. Select the options for who submitted the report and who updated it.
9. Enter the date and time the report was submitted and updated.

## Field-by-Field Explanation
* **Student ID** (`student_id`, Number, Required): Enter the student's ID number.
* **Incident Date** (`incident_date`, Date, Optional): Enter the date of the incident.
* **Incident Time** (`incident_time`, Time, Optional): Enter the time of the incident.
* **Student Name** (`student_name`, Text, Required): Enter the student's name.
* **Student Grade** (`student_grade`, Select One, Optional): Select 'Yes' if the student is eligible for the report.
* **Incident Location** (`incident_location`, Text, Optional): Enter the location of the incident.
* **Incident Description** (`incident_description`, Text, Optional): Provide a detailed description of the incident.
* **Teacher Comments** (`teacher_comments`, Text, Optional): Add any comments from the teacher.
* **Report Status** (`report_status`, Select One, Optional): Set to 'Active' if the report is active, or 'Inactive' if it's not.
* **Submitted By** (`submitted_by`, Select Multiple, Optional): Select 'Yes' if you submitted the report.
* **Submitted At** (`submitted_at`, Date, Optional): Enter the date and time the report was submitted.
* **Updated By** (`updated_by`, Select Multiple, Optional): Select 'Yes' if you updated the report.
* **Updated At** (`updated_at`, Date, Optional): Enter the date and time the report was updated.

## Tips
- Make sure to fill out the form accurately and completely.
- If you're unsure about any of the fields, ask your teacher or school administration for guidance.
- Submit the form only once for each incident.
- Ensure that you're not duplicating existing reports.
- Review and update the report as needed to ensure it remains accurate.
