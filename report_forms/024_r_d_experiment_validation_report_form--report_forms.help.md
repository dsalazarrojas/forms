# r_d_experiment_validation_report_form - Help Guide
## Purpose
This form is used for reporting on experiments, specifically for validation purposes.

## How To Complete This Form
To complete this form, simply fill out the fields as needed. Here's a breakdown of each field:

## Field-by-Field Explanation

* **Experiment Number**: This field is for entering the number of the experiment being reported on.
	+ Type: number
	+ Optional
* **Product Name**: This field is for entering the name of the product being tested.
	+ Type: text
	+ Optional
* **Outcome**: This field is for selecting the outcome of the experiment (Pass, Fail, or Unknown).
	+ Type: select_one
	+ Optional
* **Reason for Outcome**: This field is for entering a reason or explanation for the experiment outcome.
	+ Type: text
	+ Optional
* **Date**: This field is for entering the date of the experiment.
	+ Type: date
	+ Optional
* **Time**: This field is for entering the time of the experiment.
	+ Type: time
	+ Optional
* **Notes**: This field is for entering any additional notes or comments about the experiment.
	+ Type: note
	+ Optional
* **Product Development Stage**: This field is for selecting the stage of product development (Development, Live, or Archived).
	+ Type: select_one
	+ Optional
* **Validation Decision**: This field is for selecting the validation decision (Pass, Fail, or Unknown).
	+ Type: select_multiple
	+ Optional
* **Validated By**: This field is for entering the name of the person who validated the experiment.
	+ Type: text
	+ Optional
* **Validated On**: This field is for entering the date and time the experiment was validated.
	+ Type: date
	+ Optional
* **Validated By Name**: This field is for entering the name of the person who validated the experiment.
	+ Type: text
	+ Optional
* **Validated By Email**: This field is for entering the email of the person who validated the experiment.
	+ Type: email
	+ Optional
* **Validated By Phone**: This field is for entering the phone number of the person who validated the experiment.
	+ Type: text
	+ Optional
* **Validated By Location**: This field is for entering the location of the person who validated the experiment.
	+ Type: text
	+ Optional
* **Comments**: This field is for entering any additional comments or notes about the validation.
	+ Type: note
	+ Optional
* **Validated By Designer**: This field is for entering the name of the person who designed the experiment.
	+ Type: text
	+ Optional
* **Validated By Designer Name**: This field is for entering the name of the person who designed the experiment.
	+ Type: text
	+ Optional
* **Validated By Designer Email**: This field is for entering the email of the person who designed the experiment.
	+ Type: email
	+ Optional
* **Validated By Designer Phone**: This field is for entering the phone number of the person who designed the experiment.
	+ Type: text
	+ Optional
* **Validated By Designer Location**: This field is for entering the location of the person who designed the experiment.
	+ Type: text
	+ Optional
* **Validated By Designer Department**: This field is for entering the department of the person who designed the experiment.
	+ Type: text
	+ Optional
* **File Attachment**: This field is for attaching a file related to the experiment.
	+ Type: text
	+ Optional

## Tips

* Make sure to only fill out the fields that are relevant to the experiment being reported on.
* If you are unsure about any field, refer to the relevant documentation or ask your supervisor for clarification.
* The fields marked as "optional" can be filled out if you have additional information to provide, but are not required for the experiment to be validated.
