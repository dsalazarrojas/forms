# Helpdesk Ticket Resolution Report Form - Help Guide
## Purpose
This guide explains the purpose of the Helpdesk Ticket Resolution Report Form, which is used to capture key information and metrics about resolved helpdesk tickets.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the ticket id number to ensure that the correct ticket is being referenced.
2. Check if the ticket has been resolved by selecting the "resolved" field. If it's not resolved, you can skip this step.
3. If the ticket has been resolved, select the correct team that resolved the ticket from the "support_team" field.
4. Enter the customer's name, email, and phone number to ensure that their information is accurate.
5. Select the case type (Ticket, Task, or Question) to categorize the ticket type.
6. Enter the resolution date and time for the ticket.
7. Enter any notes about the case.
8. Select the goals, objectives, actions, and results achieved for the ticket.
9. Finally, review and submit the form to complete the report.

## Field-by-Field Explanation

* **support_request** (Text, Required): This field is used to enter a brief description of the support request.
* **ticket_id** (Number, Required): Enter the ID number of the ticket being referenced.
* **resolved** (Select One, Required): Check if the ticket has been resolved. If it has, select "True", otherwise select "False".
* **case_type** (Select Multiple, Required): Categorize the ticket type as Ticket, Task, or Question.
* **resolution** (Text, Required): Enter a brief description of the resolution.
* **prophets_resolution** (Text, Required): Enter a detailed description of the resolution.
* **resolution_date** (Date, Required): Enter the date on which the ticket was resolved.
* **prophets_resolution_date** (Date, Optional): Enter the date on which the ticket was resolved.
* **prophets_resolution_time** (Time, Required): Enter the time on which the ticket was resolved.
* **case_notes** (Note, Required): Enter any additional notes about the case.
* **support_team** (Select One, Required): Select the support team that resolved the ticket.
* **customer_name** (Text, Required): Enter the customer's name.
* **customer_email** (Email, Required): Enter the customer's email address.
* **customer_phone** (Text, Required): Enter the customer's phone number.
* **assigned_to** (Select One, Required): Select the support team member assigned to the ticket.
* **ticket_status** (Select One, Required): Select the ticket status (Active, Closed, or In Progress).
* **closed_date** (Date, Optional): Enter the date on which the ticket was closed.
* **closed_time** (Time, Optional): Enter the time on which the ticket was closed.
* **submitted_goals** (Select Multiple, Required): Select the goals achieved as part of the ticket resolution.
* **submitted_objectives** (Select Multiple, Required): Select the objectives achieved as part of the ticket resolution.
* **submitted_actions** (Select Multiple, Required): Select the actions taken as part of the ticket resolution.
* **submitted_results** (Select Multiple, Required): Select the results achieved as part of the ticket resolution.
* **submitted_notes** (Note, Required): Enter any additional notes about the submitted goals, objectives, actions, and results.
* **submitted_attachment** (Note, Optional): Attach any additional files or documents related to the ticket resolution.
