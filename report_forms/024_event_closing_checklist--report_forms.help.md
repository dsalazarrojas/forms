# Event Closing Checklist - Help Guide
## Purpose
The Event Closing Checklist is used to track the status of events in a structured and organized format.

## How To Complete This Form
1. Ensure that you have reviewed the form and understood the purpose and requirements.
2. Select the correct event from the list.
3. Fill in the details of the event, including the date and time it took place.
4. Provide the location of the event.
5. Check the status of the event by selecting the relevant options from the multiple select fields.
6. Submit the form for review and processing.
