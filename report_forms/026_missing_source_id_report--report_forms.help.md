# Missing Source ID Report - Help Guide
## Purpose
The Missing Source ID Report is used to report missing source IDs related to various tasks or projects within your team. This form will help track and keep track of these reports.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the team members' names and dates of the missing source IDs, if available.
2. Provide any relevant notes about the missing source IDs.
3. Select the status of the report from the options provided.
4. If applicable, choose a due date for the report, and the date it was completed.
5. Review your answers and make sure to submit the form.

## Field-by-Field Explanation
* **Team** (team): Enter the name of the team member or members who are missing the source ID.
* **Date Found** (date_found): Enter the date when you noticed that the source ID is missing (if known).
* **Notes** (notes): Provide any additional comments or details about the missing source ID.
* **Source ID** (source-id): Enter the actual source ID that is missing.
* **Assigned To** (assigned_to): Identify the team member or members who are responsible for investigating or resolving the issue.
* **Status** (status): Select the current status of the report from:
	+ **New**: The report has just been created and is waiting for further action.
	+ **In Progress**: The investigation or resolution is ongoing.
	+ **Done**: The issue has been resolved or the source ID found.
	+ **Pending**: The report is waiting for further action or input.
	+ **Cancelled**: The report has been canceled.
* **Due Date** (due_date): Enter the date by which the issue should be resolved or the report completed.
* **Completed Date** (completed_date): Enter the date when the report was completed.

## Tips
Remember to review the form carefully and ensure that all the required fields are filled in completely. If a field is not applicable, you may leave it blank.
