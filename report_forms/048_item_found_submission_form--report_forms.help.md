# Item Found Submission Form - Help Guide
## Purpose
The Item Found Submission Form is a reporting tool used by individuals who have found items in locations managed by the organization. This form allows them to report the found item, providing essential details to help the organization track and manage the item.

## How To Complete This Form
To complete the form, follow these steps:

1.  **Found Item**: Enter a description of the item found, including its condition and any other relevant details.
2.  **Date Found**: Enter the date the item was found.
3.  **Location Found**: Enter the location where the item was found.
4.  **Item Found Description**: Provide a detailed description of the item, including its appearance and any identifying features.
5.  **Item Found Type**: Select the category that best describes the type of item found, e.g. Lost and Found, Abandoned, Other.
6.  **Item Found Value**: Enter an estimate of the item's value, if applicable.
7.  **Item Found Image**: If available, upload a photo or image of the item to aid in identification.
8.  **Contact Name**: Enter the name of the person submitting the report.
9.  **Contact Email**: Enter the contact email of the person submitting the report.
10. **Contact Phone**: Enter the contact phone number of the person submitting the report.
11. **Item Found Status**: Select the current status of the item, e.g. New, Resolved, Closed.
12. **Item Found Note**: Provide any additional comments or notes about the item found, if needed.
