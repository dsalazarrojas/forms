# Tour Package Review Report Form - Help Guide
## Purpose
The Tour Package Review Report Form is used to gather feedback from reviewers and tour operators on a specific tour package. This form is intended to collect information about the package's rating, review, and any comments from both parties.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the tour package's title.
2.  On the "Tour Package Review" page, enter your review of the tour package. Be as detailed as possible.
3.  On the "Package Rating" page, select a rating for the tour package on a scale of 1-5.
4.  On the "Package Review" page, enter any comments you have about the tour package.
5.  On the "Tour Operators Comment" page, enter any comments from the tour operators.
6.  On the "Additional Comments" page, enter any additional comments you have about the tour package.
7.  On the "Tour Operators" page, indicate if the tour operators were present during the tour.
8.  On the "Travel Agency Comment" page, enter any comments from the travel agency.
9.  On the "Submit" page, select "Yes" to submit the form, or "No" if you're not ready to submit.
10.  On the "Email" page, enter your email address. This will be used to contact you if needed.
11.  On the "Contact Number" page, enter your contact number. This will be used to contact you if needed.
12.  On the "Review Date" page, select the date of the review.

## Field-by-Field Explanation

* **Tour Package Review** (`tour_package_review_form_1`, text, not required): Enter your review of the tour package. Be as detailed as possible.
* **Package Rating** (`package_rating`, number, not required): Select a rating for the tour package on a scale of 1-5.
* **Rating** (`rating`, number, not required): Select a rating for the tour package on a scale of 1-5.
* **Package Review** (`package_review`, text, not required): Enter any comments you have about the tour package.
* **Tour Operators Comment** (`tour_operators_comment`, text, not required): Enter any comments from the tour operators.
* **Additional Comments** (`additional_comments`, text, not required): Enter any additional comments you have about the tour package.
* **Tour Operators** (`tour_operators`, select_multiple, not required): Indicate if the tour operators were present during the tour.
* **Travel Agency Comment** (`travel_agency_comment`, text, not required): Enter any comments from the travel agency.
* **Submit** (`submit`, select_one, not required): Select "Yes" to submit the form, or "No" if you're not ready to submit.
* **Email** (`email`, email, not required): Enter your email address. This will be used to contact you if needed.
* **Contact Number** (`contact_number`, text, not required): Enter your contact number. This will be used to contact you if needed.
* **Review Date** (`review_date`, date, not required): Select the date of the review.
