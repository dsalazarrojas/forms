# Daily Gardening Report - Help Guide

## Purpose
The Daily Gardening Report is a form used to document and track gardening tasks, task status, plant health, and site details. It helps gardeners to keep up-to-date records of their tasks and activities, providing a clear overview of their progress and allowing for easy monitoring and evaluation.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by listing all gardening tasks for the day in the "Gardening Task List" field.
2. For each task, select the current status from the "Task Status" dropdown.
3. Enter the start date and time for each task in the "Start Date" and "Start Time" fields.
4. Enter the duration of each task in the "Duration" field.
5. Enter the location where each task was performed in the "Location" field.
6. Evaluate the health of the plants for each task in the "Plant Health" field.
7. Provide any additional details or notes about each site in the "Site Details" field.
8. If necessary, add additional notes about each site in the "Site Notes" field.
9. Select the team lead responsible for each task in the "Team Lead" field.
10. Enter the email address and phone number of the team lead for each task in the "Email" and "Phone" fields.
11. Enter the site location and area for each task in the "Site Location" and "Site Area" fields.

## Field-by-Field Explanation
* **Gardening Task List** (`daily_gardening_report`, `text`, required): List all tasks for today.
* **Task 1 Status** (`task_status_1`, `select_one`, required): Select the current status of Task 1 (Not Started, In Progress, or Completed).
* **Task 1 Start Date** (`task_start_date_1`, `date`, required): Enter the start date of Task 1.
* **Task 1 Start Time** (`task_start_time_1`, `time`, optional): Enter the start time of Task 1. (Note: this field is optional, but useful for tracking start time).
* **Task 1 Duration** (`task_duration_1`, `number`, required): Enter the duration of Task 1.
* **Task 1 Location** (`task_location_1`, `text`, required): Enter the location where Task 1 was performed.
* **Plant Health 1** (`plant_health_1`, `select_multiple`, required): Evaluate the health of the plants for Task 1 (Good, Fair, Poor, or Unknown).
* **Plant Health 2** (`plant_health_2`, `text`, optional): Enter any additional notes about the health of the plants for Task 1.
* **Plant Health 3** (`plant_health_3`, `select_one`, required): Evaluate the health of the plants for Task 2 (Good, Fair, Poor, or Unknown).
* **Site Details 1** (`site_details_1`, `text`, required): Provide any additional details about Site 1.

* **Task 2 Duration** (`task_duration_2`, `number`, required): Enter the duration of Task 2.

* **Plant Health 4** (`plant_health_4`, `text`, optional): Enter any additional notes about the health of the plants for Task 2.
