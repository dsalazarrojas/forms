# drain_problem_report_form - Help Guide
## Purpose
The drain_problem_report_form is designed to collect information about drainage problems or issues. Users can report problems in various drainage areas and provide details about the status and description of the problem.

## How To Complete This Form

*   Start by selecting the drainage area where the problem is located.
*   Provide a detailed description of the problem in the "drain_description" field.
*   Choose the relevant drainage problem from the options in the "drain_problem" field.
*   Update the "drain_status" field to reflect the current status of the problem.
*   Fill in the "submitter_details" field to provide additional information about yourself.
*   Enter your email address in the "submitter_email" field.
*   If applicable, provide the name and phone number of the contact person in the "contact_person" and "contact_phone" fields.
*   Finally, add any additional details about the problem in the "drain_problem_details" field.

## Field-by-Field Explanation

*   **drain_area**: Select the drainage area where the problem is located.
*   **drain_description**: Provide a detailed description of the problem.
*   **drain_problem**: Choose the relevant drainage problem from the list of options.
*   **drain_status**: Update the current status of the problem.
*   **submitter_details**: Provide additional information about yourself.
*   **submitter_email**: Enter your email address.
*   **contact_person**: If applicable, enter the name of the contact person.
*   **contact_phone**: If applicable, enter the phone number of the contact person.
*   **drain_problem_details**: Add any additional details about the problem.

**Tips**

*   Make sure to fill in the necessary fields accurately.
*   Be as detailed as possible when describing the problem.
*   Double-check the drainage area and problem before submitting the report.
