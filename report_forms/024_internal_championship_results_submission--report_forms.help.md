# internal_championship_results_submission - Help Guide
## Purpose
This form is designed for submitting results and status updates related to internal championships or competitions. It helps manage and track the progress of internal competitions by collecting essential information from competitors and organizers.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the submission details, including any relevant information about the submission.
2. Provide the name of the competitor participating in the championship or competition.
3. Enter the name of the event being competed in.
4. Specify the name of the competition or championship.
5. Offer detailed information about the result or outcome.
6. Select the current submission status from the options provided (Pending, Approved, or Rejected).
7. Choose a submission date and time.
8. Include any additional notes or comments about the submission, if needed.

## Field-by-Field Explanation

* **Submission Details** (`submission_details`, text, not required): Enter a brief description of the submission, including any relevant details.
* **Competitor Name** (`competitor_name`, text, not required): Type in the name of the competitor participating in the championship or competition.
* **Event Name** (`event_name`, text, not required): Enter the name of the event being competed in.
* **Competition Name** (`competition_name`, text, not required): Specify the name of the competition or championship.
* **Result Details** (`result_details`, text, not required): Offer a detailed description of the result or outcome.
* **Submission Status** (`submission_status`, select_one, not required): Choose the current status of the submission from the options: Pending, Approved, or Rejected.
* **Submission Date** (`submission_date`, date, not required): Select a date for the submission.
* **Submission Time** (`submission_time`, time, not required): Choose the time for the submission.
* **Submission Notes** (`submission_notes`, note, not required): Include any additional comments or notes about the submission, if needed.
