# Industrial Benchmark Summary Report Form - Help Guide
## Purpose
This form is used to collect and record information about industrial benchmarks, which are measures used to evaluate the performance of industrial systems or processes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Industrial Benchmark Type" field with a brief description of the benchmark being reported.
2. Enter the "Benchmark Name" in the text field provided.
3. Fill in the "Benchmark Value" field with the numerical value of the benchmark, if applicable.
4. Select the start and end dates for the benchmark period in the "Date Start" and "Date End" fields, respectively.
5. Enter the start and end times for the benchmark period in the "Time Start" and "Time End" fields, respectively.
6. Add any comments or notes about the benchmark in the "Comments" field.
7. Enter the name of the user who submitted the report in the "Submitted By" field.
8. If applicable, select the category and add any tags or notes in the "Category" and "Tags" fields.
9. If necessary, upload up to 8 files as attachments using the "File 1" to "File 8" fields.

## Field-by-Field Explanation
* **Industrial Benchmark Type**: Select the type of industrial benchmark being reported (e.g., throughput, efficiency, etc.).
* **Benchmark Name**: Enter a brief description of the benchmark (e.g., production line, process, etc.).
* **Benchmark Value**: Enter the numerical value of the benchmark (e.g., 100 units, 10% increase, etc.).
* **Date Start**: Select the start date of the benchmark period.
* **Date End**: Select the end date of the benchmark period.
* **Time Start**: Select the start time of the benchmark period.
* **Time End**: Select the end time of the benchmark period.
* **Comments**: Add any additional comments or notes about the benchmark.
* **Submitted By**: Enter the name of the user who submitted the report.
* **Category**: Select the category of the benchmark (e.g., production, quality, etc.).
* **Tags**: Enter any relevant tags or keywords for the benchmark.
* **File 1 to 8**: Upload up to 8 files as attachments to support the benchmark report.
