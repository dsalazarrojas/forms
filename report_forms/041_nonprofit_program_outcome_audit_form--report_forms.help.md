# Nonprofit Program Outcome Audit Form - Help Guide
## Purpose
This form helps non-profit organizations to audit and evaluate the outcomes of their programs.

## How To Complete This Form
1. Fill in the **Organization** field with the name of your organization.
2. Fill in the **Program name** field with the name of the program being audited.
3. Fill in the **Program start date** field with the start date of the program.
4. Fill in the **Program end date** field with the end date of the program.
5. Select the **Rating scale** to rate the program's effectiveness.
6. Select the **Program outcome 1**, **Program outcome 2** and **Program outcome 3** fields to add the outcomes achieved by the program.
7. Fill in the **Rating 2** field with an open-ended rating of the program.
8. Click submit to complete the form.

## Field-by-Field Explanation
* **Organization**: This field is required.
* **Program name**: This field is required.
* **Program start date**: This field is required.
* **Program end date**: This field is required.
* **Rating scale**: This field is optional, but recommended.
* **Program outcome 1**: This field is optional, but recommended.
* **Program outcome 2**: This field is optional, but recommended.
* **Rating 2**: This field is optional.
* **Program outcome 3**: This field is optional.

## Tips
- Make sure to fill in all the required fields before submitting the form.
- Use the **Rating scale** field to rate the program's effectiveness based on its outcomes.
- Use the **Program outcome 1** and **Program outcome 2** fields to list the outcomes achieved by the program.
- Use the **Rating 2** field to provide an open-ended rating of the program.
- Use the **Program outcome 3** field to add additional outcomes achieved by the program.
