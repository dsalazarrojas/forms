# HVAC Balance Report Form - Help Guide
## Purpose
The HVAC Balance Report Form is a data collection tool used to gather information about HVAC systems. This form helps users document and report on HVAC system balances, providing a structured format for recording important details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* **System ID**: Enter the unique ID of the HVAC system.
	* **System Name**: Enter the name of the HVAC system.
	* **Date of Test**: Enter the date on which the balance test was performed.
	* **Time of Test**: Enter the time of the balance test.
	* **System Type**: Select the type of HVAC system being balanced (Air System, Gas System, or Other).
2. Enter any additional information you have about the system:
	* **Equipment ID**: Enter the ID of any equipment being balanced or tested.
	* **Technician ID**: Enter the ID of the technician performing the balance test.
	* **Location Name**: Enter the name of the location where the balance test was performed.
3. Add notes as necessary:
	* **Notes**: Enter any additional comments or notes about the system balance.
	* **Additional Notes**: Enter any further comments or information about the system.

## Field-by-Field Explanation
* **System ID** (`system_id`, text, optional): Enter the unique ID assigned to the HVAC system. This field helps identify the system for future reference.
* **System Name** (`system_name`, text, optional): Enter the name of the HVAC system being balanced. This helps to clearly label the system and its purpose.
* **Equipment ID** (`equipment_id`, text, optional): Enter the ID of any equipment being balanced or tested. This field is used to track equipment-specific information.
* **Technician ID** (`technician_id`, text, optional): Enter the ID of the technician performing the balance test. This helps to assign responsibility and track technician activity.
* **Location Name** (`location_name`, text, optional): Enter the name of the location where the balance test was performed. This field helps to identify the site or building being tested.
* **Date of Test** (`date_of_test`, date, optional): Enter the date on which the balance test was performed. This helps to track when the test was conducted.
* **Time of Test** (`time_of_test`, time, optional): Enter the time of the balance test. This field records the time of day the test was performed.
* **System Type** (`system_type`, select_one, optional): Select the type of HVAC system being balanced (Air System, Gas System, or Other). This field determines the type of system being tested.
* **Notes** (`notes`, note, optional): Enter any additional comments or notes about the system balance.
* **Additional Notes** (`notes_2`, note, optional): Enter any further comments or information about the system.

## Tips
* Make sure to fill in all required fields.
* Use specific and clear language when entering information in each field.
* Review and edit your entries as necessary to ensure accuracy and completeness.
