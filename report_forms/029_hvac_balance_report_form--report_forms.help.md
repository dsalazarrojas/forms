## Tips

* **System ID**: This field should be used to enter the unique ID assigned to the HVAC system.
* **System Name**: Enter the name of the HVAC system being balanced.
* **Equipment ID**: This field is used to track equipment-specific information.
* **Technician ID**: This field is used to assign responsibility and track technician activity.
* **Location Name**: Enter the name of the location where the balance test was performed.
* **Date of Test**: Enter the date on which the balance test was performed.
* **Time of Test**: Enter the time of day the test was conducted.
* **System Type**: Select the type of HVAC system being balanced.
* **Notes**: Enter any additional comments or notes about the system balance.
* **Additional Notes**: Enter any further comments or information about the system.
