# Boat Inspection Checklist Form - Help Guide
## Purpose
The Boat Inspection Checklist Form is used to record the results of a boat inspection, capturing detailed information about the boat's condition, including its engine, electrical, and safety systems.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Inspection Date** in the designated date field.
2. Fill in the **Inspector Name** field with the name of the person conducting the inspection.
3. Enter the **Boat Manufacturer** and **Boat Model** fields with the relevant information.
4. Enter the **Boat Year** field with the year of the boat.
5. Answer the questions about the **Engine Type**, **Engine Hours**, **Engine Condition**, **Engine Compression Test**, **Oil Level Check**, **Fuel System Condition**, **Fuel Filter Inspection**, **Battery Condition**, **Electrical System**, **Cooling System**, **Propeller Condition**, **Steering System**, **Hull Integrity**, **Safety Equipment Present**, and **Overall Inspection Assessment** fields based on your observations during the inspection.
6. If any repairs are needed, provide a detailed list in the **Repairs Needed** field.
7. Provide any **Maintenance Recommendations** for the boat.
8. Confirm that you have accurately completed the form by selecting **Yes, I confirm** in the **Inspector Signature Confirmation** field.

## Field-by-Field Explanation

* **Inspection Date** (`inspection_date`, `date`, required): Enter the date of the inspection.
* **Inspector Name** (`inspector_name`, `text`, required): Enter the name of the person conducting the inspection.
* **Boat Manufacturer** (`boat_manufacturer`, `text`, required): Enter the name of the boat manufacturer.
* **Boat Model** (`boat_model`, `text`, required): Enter the model number of the boat.
* **Boat Year** (`boat_year`, `number`, required): Enter the year of the boat.
* **Engine Type** (`engine_type`, `select_one`, required): Select the type of engine the boat has.
	+ Gasoline
	+ Diesel
	+ Electric
	+ Hybrid
* **Engine Hours** (`engine_hours`, `number`, required): Enter the current operating hours of the engine.
* **Engine Condition** (`engine_condition`, `select_one`, required): Select the overall condition of the engine.
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Needs Repair
* **Engine Compression Test** (`engine_compression`, `select_one`, required): Select the result of the engine compression test.
	+ Pass
	+ Fail
	+ Not Tested
* **Oil Level Check** (`oil_level_check`, `select_one`, required): Select the condition of the engine oil level.
	+ Normal
	+ Low
	+ High
	+ Not Checked
* **Fuel System Condition** (`fuel_system_condition`, `select_one`, required): Select the overall condition of the fuel system.
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Fuel Filter Inspection** (`fuel_filter_inspection`, `select_one`, required): Select the condition of the fuel filter.
	+ Clean
	+ Needs Cleaning
	+ Needs Replacement
	+ Not Checked
* **Battery Condition** (`battery_condition`, `select_one`, required): Select the condition of the battery.
	+ Excellent
	+ Good
	+ Fair
	+ Dead
	+ Missing
* **Electrical System** (`electrical_system`, `select_one`, required): Select the condition of the electrical system.
	+ Working Properly
	+ Minor Issues
	+ Major Issues
	+ Not Tested
* **Cooling System** (`cooling_system_check`, `select_one`, required): Select the condition of the cooling system.
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Not Tested
* **Propeller Condition** (`propeller_condition`, `select_one`, required): Select the condition of the propeller.
	+ Excellent
	+ Good
	+ Minor Damage
	+ Severe Damage
	+ Missing
* **Steering System** (`steering_system`, `select_one`, required): Select the condition of the steering system.
	+ Working Properly
	+ Stiff
	+ Loose
	+ Not Functional
* **Hull Integrity** (`hull_integrity`, `select_one`, required): Select the condition of the hull.
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Severe Damage
* **Safety Equipment Present** (`safety_equipment`, `select_one`, required): Select the condition of the safety equipment.
	+ All Present
	+ Some Missing
	+ Most Missing
	+ None Present
* **Overall Inspection Assessment** (`overall_assessment`, `select_one`, required): Select the overall assessment of the boat.
	+ Pass - Ready for Use
	+ Conditional Pass - Minor Repairs Needed
	+ Fail - Major Repairs Required
	+ Not Seaworthy
* **Repairs Needed** (`repairs_needed`, `text`, optional): Provide a detailed list of any repairs needed.
* **Maintenance Recommendations** (`maintenance_recommendations`, `text`, optional): Provide any maintenance recommendations for the boat.
* **Inspector Signature Confirmation** (`inspector_signature_confirmation`, `select_one`, required): Confirm that you accurately completed the form.
	+ Yes, I confirm
	+ No, I do not confirm

## Tips

* If you are unsure about any of the information requested, consult with a qualified inspector or maintenance expert.
