# furnished_rental_property_inventory_and_condition_form - Help Guide
## Purpose
The Furnished Rental Property Inventory and Condition Form is designed to document the condition and inventory of furnished rental properties at the start and end of a rental period. This form helps landlords and tenants to accurately record the state of the property, ensuring a smooth and hassle-free transaction.

## How To Complete This Form
To complete this form, follow these steps:

1. **Page 1: Furnished Rental Property Address**
	* Fill in the furnished rental property's address in the `furnished_rental_property_address` field.
2. **Page 2: Property Status**
	* Select the current status of the property from the options: **Rental**, **For Sale**, or **Leaseback**.
3. **Page 3: Property Type**
	* Select the type of property: **Residential** or **Commercial**.
4. **Page 4: Rent Frequency**
	* Choose the rent frequency: **Monthly**, **Semi-Annually**, or **Annually**.
5. **Page 5: Tenant Information (Note)**
	* This field is for providing additional information about the tenant, if necessary.
6. **Page 6: Landlord Information (Note)**
	* This field is for providing additional information about the landlord, if necessary.
7. **Page 7: Property Condition**
	* Provide a detailed description of the property's condition.
8. **Page 8: Property Equipment**
	* Describe the property's equipment, such as appliances, fixtures, and furniture.
9. **Page 9: Move-in and Move-out Dates**
	* Enter the move-in and move-out dates for the rental period.
10. **Page 10: Rental Property Images**
	* Attach any images of the property that you would like to include in the inventory.
11. **Page 11: Move-in and Move-out Inspection Notes**
	* Add any notes or observations from the move-in and move-out inspections.
12. **Page 12: Signatures**
	* Signatures from the landlord and tenant for move-in and move-out inspections.

## Field-by-Field Explanation

* **furnished_rental_property_address** (Text Field):
	+ Enter the address of the furnished rental property.
* **property_status** (Select One):
	+ Choose the current status of the property (Rental, For Sale, or Leaseback).
* **property_type** (Select One):
	+ Select the type of property (Residential or Commercial).
* **rent_frequency** (Select Multiple):
	+ Choose the rent frequency (Monthly, Semi-Annually, or Annually).
* **tenant_info** (Note Field):
	+ Add any additional information about the tenant, if necessary.
* **landlord_info** (Note Field):
	+ Add any additional information about the landlord, if necessary.
* **property_condition** (Text Field):
	+ Provide a detailed description of the property's condition.
* **property_equipment** (Text Field):
	+ Describe the property's equipment, such as appliances, fixtures, and furniture.
* **move_in_move_out_dates** (Date Field):
	+ Enter the move-in and move-out dates for the rental period.
* **furnished_rental_property_images** (Text Field):
	+ Attach any images of the property that you would like to include in the inventory.
* **move_in_move_out_inspection_notes** (Text Field):
	+ Add any notes or observations from the move-in and move-out inspections.
* **move_in_move_out_signatures** (Select Multiple):
	+ Select the signatures from the landlord and tenant for move-in and move-out inspections.
* **move_in_move_out_signatures_2 to 10** (Select Multiple):
	+ Select the signatures from the landlord and tenant for move-in and move-out inspections.

## Tips
- Ensure that you fill in all required fields accurately.
- Use the space provided for each field to provide detailed descriptions or attach images as needed.
- Make sure to sign each page after completion to confirm agreement.
- Keep the form in a secure and confidential manner to protect both parties' interests.
- Review the form carefully before submission to avoid mistakes.
