# Ride Service Availability Issue Report Form - Help Guide
## Purpose
This form is used to report any issues or problems that occurred with the ride service. Please report any delays, cancellations, or other issues that affected your ride experience.

## How To Complete This Form
1.  To start, ensure that you have all the necessary information at hand, such as the date and time of the incident, location, and any details about what happened.
2.  Fill in the required and optional fields with the relevant information.
3.  Review your submission before submitting it to ensure that all details are accurate and complete.

## Field-by-Field Explanation
* **Service Availability Issue Report Form** (`ride_service_availability_issue_report_form`, text, required): This is the title of the report, which should include a brief description of the issue.
* **Service Availability Issue Date** (`service_availability_issue_date`, date, required): Enter the date on which the issue occurred.
* **Service Availability Issue Time** (`service_availability_issue_time`, time, required): Enter the time of day when the issue happened.
* **Service Availability Issue Location** (`service_availability_issue_location`, text, required): Specify the location where the issue occurred.
* **Service Availability Issue Description** (`service_availability_issue_description`, text, required): Describe the problem that you experienced with the ride service in detail.
* **Service Availability Issue Riders** (`service_availability_issue_riders`, text, optional): If there were other passengers affected by the issue, provide their names and contact information (if you have it).
* **Service Availability Issue Rider Comments** (`service_availability_issue_rider_comments`, note, optional): If there are any additional comments or details from the other riders, please include them here.
* **Service Availability Issue Reported Time** (`service_availability_issue_reported_time`, time, required): Enter the time when you submitted this report.
* **Service Availability Issue Reported By** (`service_availability_issue_reported_by`, text, required): Enter your name and contact information so that we can reach you to follow up on the issue.
* **Service Availability Issue Vehicles** (`service_available_issue_vehicles`, text, optional): If the issue was related to a specific vehicle, please describe it here.
* **Other Issue Details** (`service_availability_issue_other`, text, optional): If the issue was something other than what you've described above, please specify it here.
* **Other Issue Comments** (`service_availability_issue_other_comments`, note, optional): If you have any additional comments about the other issue, please include them here.

## Tips
* Be as specific as possible when describing the issue to help us understand and address it.
* If there's any supporting evidence (e.g., screenshots, photos, or videos), please include them if possible.
* If you have any contact information or communication records (e.g., emails or messages), share them with us if possible. 
* You will receive a response from us after reviewing and addressing your report.
