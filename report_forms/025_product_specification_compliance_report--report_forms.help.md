# Product Specification Compliance Report - Help Guide
## Purpose
This form is designed to collect information about a product's specification compliance status from suppliers.

## How To Complete This Form
1. Start by filling out the "Product Specification" field with a brief description of the product being reported on.
2. Provide information about the supplier in the "Supplier" field.
3. Enter the "Inspection Date" using the date picker.
4. Select the "Inspection Status" from the dropdown menu:
	* Compliance: The product meets the specification.
	* Not Compliant: The product does not meet the specification.
	* Pending: The product's compliance status is still pending.
5. If a corrective action is taken, enter the "Corrective Action Date" in the format `YYYY-MM-DD`.
6. Provide any additional comments or notes about the product's compliance status in the "Remarks" field.
7. Select the "Category" from the dropdown menu:
	* Report Forms
	* Business Report Forms
8. If the category does not fit into one of the above options, enter the category in the "Category Other" field.
9. Enter the name of the tool used to complete the form in the "Assigned Tool" field.
10. If a different tool was used to complete the form, enter the tool's name in the "Assigned Tool Other" field.

## Field-by-Field Explanation

* **Product Specification** (Required): A brief description of the product being reported on.
* **Supplier** (Required): Information about the supplier of the product.
* **Inspection Date** (Required): The date of the product's inspection.
* **Inspection Status**:
	+ **Compliance**: The product meets the specification.
	+ **Not Compliant**: The product does not meet the specification.
	+ **Pending**: The product's compliance status is still pending.
* **Corrective Action Date** (Optional): The date the corrective action was taken.
* **Remarks** (Optional): Additional comments or notes about the product's compliance status.
* **Category** (Optional): The category of the product (Report Forms, Business Report Forms).
* **Category Other** (Optional): If the category does not fit into one of the above options, enter the category here.
* **Assigned Tool** (Optional): The name of the tool used to complete the form.
* **Assigned Tool Other** (Optional): If a different tool was used to complete the form, enter the tool's name here.
