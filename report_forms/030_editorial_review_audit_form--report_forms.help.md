# Editorial Review Audit Form - Help Guide
## Purpose
The Editorial Review Audit Form is designed to gather essential information about manuscripts that have undergone editorial review. This form aims to standardize the review process, making it more efficient and transparent.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all the necessary information before starting the form.
2. For each field, enter the required information accurately and completely.
3. If a field is marked as optional, use it for additional comments or details if necessary.
4. Review each field carefully to ensure you have provided all the necessary information.

## Field-by-Field Explanation

* **Manuscript ID** (`manuscript_id`, required, Number): Enter the unique ID assigned to the manuscript.
* **Reviewer Name** (`reviewer_name`, required, Text): Enter your name and title as the reviewer.
* **Evaluation Date** (`evaluation_date`, required, Date): Enter the date when the review was conducted.
* **Recommended Actions** (`recommended_actions`, required, Select Multiple): Select all applicable actions for the manuscript review.
* **Comments** (`comments`, optional, Text): Enter any additional comments or feedback about the manuscript.
* **Reviewer Feedback** (`reviewer_feedback`, required, Select One): Select the feedback type for the manuscript review.
* **Evaluation Status** (`evaluation_status`, required, Select One): Select the status of the manuscript evaluation.
* **Manuscript Status** (`manuscript_status`, required, Select One): Select the status of the manuscript.
* **Submitted To** (`submitted_to`, optional, Select Multiple): Select the publication(s) to which the manuscript was submitted.
* **Publication Date** (`publication_date`, optional, Date): Enter the publication date of the manuscript.
* **Editorial Decision** (`editorial_decision`, required, Select One): Select the editorial decision for the manuscript.
* **Manuscript Type** (`manuscript_type`, required, Select One): Select the type of manuscript.
* **Evaluation Form Completed** (`evaluation_form_completed`, required, Select One): Select the completion status of the evaluation form.
* **Review Round** (`review_round`, required, Select One): Select the round of review.
* **Editor Review** (`editor_review`, required, Select One): Select the editor review type.
* **Editor Comments** (`editor_comments`, optional, Text): Enter any additional comments from the editor.
* **Reviewer Notes** (`reviewer_notes`, optional, Text): Enter any additional notes from the reviewer.
* **Manuscript Revision** (`manuscript_revision`, required, Select One): Select the status of the manuscript revision.
* **Revised Manuscript Status** (`revised_manuscript_status`, required, Select One): Select the status of the revised manuscript.
* **Final Decision** (`final_decision`, required, Select One): Select the final decision on the manuscript.
* **Final Decision Date** (`final_decision_date`, optional, Date): Enter the date of the final decision.
* **Final Publication Date** (`final_publication_date`, optional, Date): Enter the date of the final publication.
* **Final Publication Status** (`final_publication_status`, required, Select One): Select the final publication status.
* **Submitted To** (`submitted_to`, optional, Select Multiple): Select the publication(s) to which the manuscript was submitted.
