# Daily Location Media Submission - Help Guide

## Purpose
The Daily Location Media Submission form is a tool used to collect media submissions from users to document their daily activities and location. This form is used by [your organization or department] to gather information for [purposes, e.g., quality control, quality assurance, etc.]. Please use this form only for the intended purpose and avoid submission of unnecessary information to ensure accuracy and completeness of the collected data.

## How To Complete This Form

To submit a media file, follow these steps:

1. Fill in the "Form Title" field with a brief description of your media file.
2. Select the type of media you are submitting (e.g., Photo, Video, Observation, Audio, or File).
3. Enter the date you took the media file.
4. Enter the latitude and longitude of the location where you took the media file.
5. Provide a brief description of the media file.
6. Enter the URL of any file associated with the media file (if applicable).
7. Attach any additional media files (if applicable).
8. Add any relevant notes about the location where you took the media file.

## Field-by-Field Explanation

* **Form Title (daily_location_media_submission_form)**: A brief description of your media file submission.
* **Media Type (media_type)**: Select the type of media you are submitting (e.g., Photo, Video, Observation, Audio, or File).
* **Date (location_date)**: The date you took the media file.
* **Latitude (location_lat)**: The latitude of the location where you took the media file.
* **Longitude (location_long)**: The longitude of the location where you took the media file.
* **Description (media_description)**: A brief description of the media file.
* **File URL (file_url)**: Enter the URL of any file associated with the media file (if applicable).
* **Media (media_file)**: Attach any additional media files (if applicable).
* **Notes (location_notes)**: Add any additional notes about the location where you took the media file.

## Tips

* Please use the correct media type for your submission.
* Ensure the date is in the correct format (e.g., YYYY-MM-DD).
* If you are attaching a file, make sure it is relevant and related to the media file.
* Keep your notes brief and focused on the location and media file details.
* If you are unsure about any of the fields, please contact [contact information] for assistance.
