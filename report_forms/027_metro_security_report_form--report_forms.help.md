# Metro Security Report Form - Help Guide
## Purpose
The Metro Security Report Form is a tool used to document and report security incidents or potential threats to the relevant stakeholders within the organization. This form gathers essential information about reported incidents to facilitate prompt and effective response.

## How To Complete This Form
1. Review the form carefully to ensure you have provided all required information.
2. Fill in the following sections:
   - Incident Reported: A brief description of the incident or reported threat.
   - Threat Type: Select the nature of the threat (e.g., Option 1, Option 2, Option 3).
   - Threat Level: Choose the level of severity or priority (e.g., Option 1, Option 2).
   - Threat Details: Provide a detailed description of the threat or incident.
   - Location: Specify where the incident occurred (e.g., office, data center, server room).
   - Reported By: Enter the name and any other relevant contact information (e.g., email, phone number).
   - Incident ID: Enter a unique ID number if applicable.
   - Report Date: Enter the date of the report.

## Field-by-Field Explanation
* **Incident Reported** (incident_reported): Briefly describe the security incident or reported threat.
* **Threat Type** (threat_type): Select the type of threat from the options provided (e.g., Option 1, Option 2, Option 3).
* **Threat Level** (threat_level): Choose the level of severity or priority for the threat (e.g., Option 1, Option 2).
* **Threat Details** (threat_details): Provide a detailed explanation of the threat or incident.
* **Location** (location): Specify the location where the incident occurred.
* **Reported By** (reported_by): Enter the name and any other relevant contact information for the person reporting the incident.
* **Contact Info** (contact_info): Enter the contact information for the person reporting the incident (e.g., email, phone number).
* **Incident ID** (incident_id): Enter a unique ID number for the incident, if required.
* **Report Date** (report_date): Enter the date of the report.

## Tips
- Ensure you have permission to report security incidents or threats.
- Be as detailed as possible when describing the threat or incident.
- If you're unsure about any field, please contact your supervisor or security team for guidance.
- This form is for internal use only, so please do not share it with external parties.
