# Training Report Form - Help Guide
## Purpose
The Training Report Form is a tool for documenting and reporting on training sessions and programs. It collects information on the session's title, dates, description, objectives, and other relevant details.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the **Session Title** of the training session or program in the text field. This is the name of the event, e.g., "Introduction to AI-Generated Forms".
2. Select the **Session Start Date** and **Session End Date** using the calendar picker or enter them manually in the date fields.
3. Provide a brief **Session Description** of the training session or program in the text field.
4. List the **Session Objectives** for the training session or program in the text field.
5. Enter the **Program Title** of the training program, if applicable.
6. Select the **Program Start Date** and **Program End Date** using the calendar picker or enter them manually in the date fields.

## Field-by-Field Explanation

* **Session Title** (`session_title`, text, optional): Enter the title of the session or program.
* **Session Start Date** (`session_start_date`, date, optional): Enter the start date of the session or program.
* **Session End Date** (`session_end_date`, date, optional): Enter the end date of the session or program.
* **Session Description** (`session_description`, text, optional): Enter a brief description of the session or program.
* **Session Objectives** (`session_objectives`, note, optional): List the objectives of the session or program.
* **Program Title** (`program_title`, text, optional): Enter the title of the program.
* **Program Start Date** (`program_start_date`, date, optional): Enter the start date of the program.
* **Program End Date** (`program_end_date`, date, optional): Enter the end date of the program.

## Tips

* Make sure to enter accurate and relevant information for each field to ensure the form submission is complete and useful.
* If you are reporting on multiple sessions or programs, submit each one separately and clearly label each submission with its corresponding title.
* If you are unsure about any field, refer to the form instructions above for clarification.
