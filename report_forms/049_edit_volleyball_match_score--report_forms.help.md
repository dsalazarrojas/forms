# Edit Volleyball Match Score - Help Guide
## Purpose
The purpose of this form is to edit the scores of a volleyball match that has already been played. Use this form to update the scores of the first and second teams that participated in the match.

## How To Complete This Form

1. Select the correct team that you want to edit scores for using the "First Team" dropdown menu.
2. Select the correct team that you want to edit scores for using the "Second Team" dropdown menu.
3. Enter the score of the first team in the "Score First Team" field.
4. Enter the score of the second team in the "Score Second Team" field.
5. Enter any additional details or comments in the "Reason" field.

## Field-by-Field Explanation

* **First Team**: This dropdown menu allows you to select which team was playing against the second team.
* **Second Team**: This dropdown menu allows you to select which team was playing against the first team.
* **Score First Team**: Enter the final score of the first team. This field is required.
* **Score Second Team**: Enter the final score of the second team. This field is required.
* **Reason**: Enter any additional comments or details about the match that you want to record. This field is optional.

## Tips

* Make sure to enter accurate scores to ensure the records are updated correctly.
* Double-check that the team selections are correct before submitting the form.
* If you are unsure about any part of the process, contact a supervisor or colleague for guidance.
