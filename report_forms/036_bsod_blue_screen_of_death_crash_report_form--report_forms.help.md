# BSOD (Blue Screen Of Death) Crash Report Form - Help Guide

## Purpose
The BSOD (Blue Screen Of Death) Crash Report Form is designed to collect information about system crashes to aid our team in troubleshooting and resolving the issue.

## How To Complete This Form
1. Fill out the form with the requested information about the crash, including the report date, time, and any additional details.
2. Be as thorough as possible when describing your experience with the crash, including any steps you took to recover data or system functionality.
3. Answer questions about the crash frequency, operating system, and any potential impact on system or data availability.

## Field-by-Field Explanation
* **Report Date** (`report_date`, date, required): Date on which the crash occurred.
* **Time of Crash** (`report_time`, time, required): Approximate time the system crashed.
* **Reporter Name** (`reporter_name`, text, required): Your full name for contact purposes.
* **Reporter Email** (`reporter_email`, email, required): Your email address for contact purposes.
* **Reporter Phone** (`reporter_phone`, text, optional): Contact number for follow-up.
* **Computer or Device Name** (`computer_name`, text, required): Hostname or device identifier for tracking.
* **Operating System** (`operating_system`, text, required): Windows version, etc.
* **How Often Does This Crash Occur?** (`crash_frequency`, select_one, required): Choose how often the crash has happened.
* **BSOD Error Code** (`error_code`, text, optional): The STOP code displayed.
* **Error Message** (`error_message`, text, optional): Complete error message if available.
* **What Were You Doing When It Crashed?** (`what_you_were_doing`, text, required): Application, task, or activity when the crash occurred.
* **Recently Installed Software or Updates?** (`recently_installed`, select_one, optional): Check if you've installed new software or updates recently.
* **Recent System Changes** (`recent_changes`, text, optional): Describe any recent hardware changes or driver updates.
* **Recovery Steps Attempted** (`recovery_steps`, text, optional): Describe what steps you have taken to recover data or system functionality.
* **Any Data Loss or Corruption?** (`data_loss`, select_one, optional): Check if any data was lost or corrupted.
* **Is Hardware Potentially Affected?** (`hardware_affected`, text, optional): Describe affected hardware components.
* **Latest System Backup Date** (`system_backup`, date, optional): Date of the last system backup.
* **Does This System Store Critical Data?** (`critical_data`, select_one, optional): Check if this system stores critical data.
* **Priority Level** (`priority_level`, select_one, required): Indicate the urgency level of the issue.
* **Additional Notes** (`additional_notes`, text, optional): Provide any other relevant information about the crash.
