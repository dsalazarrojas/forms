# User Logon Activity Report - Help Guide
## Purpose
The User Logon Activity Report form is designed to collect detailed information about user logon activity, which helps in analyzing and identifying trends in user behavior.

## How To Complete This Form
1. Select the correct "Form Submitted From" option: desktop or mobile phone. This will help in understanding the user's interaction with the system.
2. Enter the User Details: provide the user's name, email, phone number, location, and other relevant information if available.
3. Record the Logon and Logoff times: enter the exact dates and times of when the user logged on and off.
4. Specify the Activity Type: choose the correct option that describes the user's logon activity (e.g., login success, login failure, etc.).
5. Select the Device or Location: choose the correct option for the user's device or location (e.g., desktop, laptop, mobile phone, etc.).
6. Choose the Browser Type: select the correct browser type used by the user (e.g., internet explorer, chrome, firefox, etc.).
7. Enter the User IP: provide the user's IP address.
8. Select the Operating System: choose the correct option for the user's operating system (e.g., windows, mac os x, linux, etc.).
9. Choose the Browser Language: select the correct language used by the user's browser (e.g., English, French, German, etc.).
10. Enter the Country, City, Region, and Timezone: provide the user's geographical information.
11. Enter any additional comments or information about the user's logon activity.

## Field-by-Field Explanation

* **Activity Type**: Describes the type of user logon activity, such as login success or failure.
* **Device or Location**: Refers to the user's device or location when they logged on.
* **Browser Type**: Identifies the type of browser used by the user.
* **User Name**: Provides the user's name for identification purposes.
* **User Email**: Enters the user's email address.
* **User Phone**: Enters the user's phone number.
* **User Location**: Enters the user's location.
* **Browser Version**: Enters the user's browser version.
* **Operating System**: Selects the user's operating system.
* **Browser Language**: Selects the user's browser language.
* **Country**: Enters the user's country.
* **City**: Enters the user's city.
* **Region**: Enters the user's region.
* **Timezone**: Enters the user's timezone.
* **IP Country**: Enters the user's IP country.
* **User IP**: Enters the user's IP address.
* **User Agent**: Enters any additional information about the user's browser agent.
* **Referer**: Enters the URL or website that the user visited.
* **Form Submitted From**: Specifies where the form was submitted from, i.e., desktop or mobile phone.
* **Comments**: Enters any additional comments or information about the user's logon activity.
