# Sonar Finding Report Form - Help Guide
## Purpose
This form is designed to collect information about sonar findings, which are observations made by users during a sonar sweep operation. The form is used to record details about the sonar findings, including the date and time of the sweep, the area searched, and any notable findings. The information collected through this form will help in creating comprehensive reports and improving future sonar sweep operations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in each page of the form, starting from page 1 (Sonar Findings).
2. Enter the relevant information in each field, making sure to provide as much detail as possible.
3. Move on to the next page when you have completed each section.
4. Review your input before submitting the form.

## Field-by-Field Explanation
- **Sonar Findings**: On this page, enter any sonar findings made during the sweep operation. This can include any notable or unusual findings.
- **Date Of Sonar Sweep**: Enter the date of the sonar sweep operation. This will help in recording the time frame for the sweep.
- **Time Of Sonar Sweep**: Enter the time of the sonar sweep operation. This will help in recording the duration of the sweep.
- **Date Of Survey**: Enter the date of the survey or inspection. This is to help in recording the time frame for the survey or inspection.
- **Sonar Swept Area**: On this page, enter the area that was searched during the sonar sweep operation.
- **Sonar Sweep Depth**: Enter the depth of the sonar sweep operation. This can include any notable or unusual findings.
- **Sonar Frequency**: Enter the frequency of the sonar sweep operation. This can include the number of times the sonar equipment was used.
- **Sonar Finding Comments**: On this page, enter any comments or notes about the sonar findings. This can include any additional information that may be helpful in understanding the findings.
- **Sonar Location**: Check the box to indicate if there were any sonar findings at the location. If yes, enter the location details in the next field.
- **Sonar Location Other**: If there is any other location information that is not included in the options, enter it here. This can include any additional details about the location.
- **Attached File**: If you have any attached files or documents related to the sonar findings, enter the filename here. This can include images or other documents that may be helpful in understanding the findings.
- **Attached Files**: If you have any additional files or documents related to the sonar findings, enter the filename here. This can include any further information that may be helpful in understanding the findings.
- **Attached File 2**: This field is intended for any additional files or documents that may be attached to the sonar findings.
- **Sonar Finding Report Form Page 15**: This field is intended for any additional comments or information related to the sonar findings.
