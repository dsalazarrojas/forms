# Scam Link Report Form - Help Guide
## Purpose
The purpose of this form is to collect information about suspicious URLs, attachments, and context related to reported incidents.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the suspicious URL into the first field.
2. Select and attach any evidence files related to the incident by clicking on "Attach evidence files".
3. Provide context about the incident in the "Incident context" field.
4. Select the date and time of the report.
5. Provide a detailed description of the incident in the "Report details" field.
6. Finally, choose "Submit" to send the report.

## Field-by-Field Explanation
* **Enter suspicious url** (`suspicious_url`, `text`, required: false): Enter the URL of the suspicious link or activity.
* **Attach evidence files** (`evidence_files`, `select_multiple`, required: false): Select multiple files that support your report. These can be screenshots, documents, or any other relevant evidence.
* **Incident context** (`incident_context`, `text`, required: false): Provide a brief explanation of the incident, including any relevant background information.
* **Report date** (`report_date`, `date`, required: false): Select the date of the report.
* **Report time** (`report_time`, `time`, required: false): Select the time of the report.
* **Report details** (`report_details`, `text`, required: false): Describe the incident in detail, including any relevant events or activities.
* **Submit** (`submit`, `select_one`, required: false): Select "Submit" to send the report. If you are finished, select "Cancel" to close the form.

## Tips
* Please ensure you are not submitting duplicate reports.
* Be as detailed as possible when describing the incident.
* Attach relevant files that support your report.
* Use the correct date and time for the report.
* Review the form carefully before submitting.
* If you have any questions or concerns, contact [form@gic.mx](mailto:form@gic.mx).
