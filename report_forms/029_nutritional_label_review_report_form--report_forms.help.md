# Nutritional Label Review Report Form - Help Guide

## Purpose
The Nutritional Label Review Report Form is used to report on the status of a product's nutritional label. This form is meant to be filled out by label reviewers who need to provide information about the product's label status, the reviewer's details, and any relevant notes.

## How To Complete This Form

To complete this form, follow these steps:

1. Choose the correct status of the product's label using the "Nutritional Label Review Report Form" page.
2. Select "Yes" or "No" to indicate whether the product has a nutritional label.
3. List any ingredients that are present on the label using the "Ingredient List" page.
4. Provide compliance details about the label using the "Compliance Details" page.
5. Select "Yes" or "No" to indicate whether the label was reviewed by the current reviewer.
6. Enter the date of the review using the "Review Date" page.
7. Enter the email address of the reviewer using the "Label Reviewer Email" page.
8. Enter the phone number of the reviewer using the "Label Reviewer Phone" page.
9. Enter the product ID using the "Product ID" page.
10. Select the status of the label using the "Label Status" page.
11. Enter any relevant notes using the "Notes" page.
12. Select "Yes" or "No" to indicate whether the form was created by the current user.
13. Enter the email address of the user who created the form using the "Created By Email" page.
14. Enter the phone number of the user who created the form using the "Created By Phone" page.
15. Enter the date the form was created using the "Created On" page.
16. Enter the form ID using the "Form ID" page.
17. Select "Yes" or "No" to indicate whether the form version is updated.
18. Select the status of the label from the history of updates using the "Label Status History" page.
19. Select "Yes" or "No" to indicate whether the form was updated by the current user.
20. Enter the email address of the user who updated the form using the "Updated By Email" page.
21. Enter the phone number of the user who updated the form using the "Updated By Phone" page.
22. Select "Yes" or "No" to indicate whether the label was reviewed by someone else.
23. Enter the date of the review using the "Label Reviewed On" page.
24. Enter the email address of the person who reviewed the label using the "Label Reviewed By Email" page.
