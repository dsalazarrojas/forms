# Job Form - Help Guide
## Purpose
The Job Form is designed to collect detailed information about jobs and tasks performed by staff members. It is essential for maintaining accurate records and tracking job-related activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Job Title** - This field requires a brief description of the job title or task performed.
2. Enter the **Staff Name** - Type in the name of the staff member who performed the job.
3. Enter the **Start Date** - Select the date the job started.
4. Enter the **End Date** - Select the date the job ended.
5. If necessary, add **Staff Notes** - Enter any additional notes about the job performed.
6. Enter the **Task Start Time** - Select the time the task started.
7. Enter the **Task End Time** - Select the time the task ended.
8. For **Job Category**, select a relevant category for the job.
9. If applicable, select multiple **Job Status** options.
10. Enter the **Work Order** - Type in the work order number.
11. If necessary, add **Staff Notes 2** - Enter additional notes about the job.
12. Enter the **Date** - Select the date of the job.
13. Enter the **Time** - Select the time of the job.
14. Enter a brief description of the **Task**.
15. If applicable, add **Notes** - Enter any additional information about the job.
16. Add **Files** - Enter file names or descriptions of files related to the job.
17. Add additional **Files** - This field can be used to add more files related to the job.
18. If necessary, add **File 2**, **File 3**, **File 4**, **File 5**, or **File 6** - These fields can be used to add more files related to the job.

## Field-by-Field Explanation

* **Job Title** (required): Enter a brief description of the job title or task performed.
* **Staff Name** (required): Type in the name of the staff member who performed the job.
* **Start Date** (required): Select the date the job started.
* **End Date** (required): Select the date the job ended.
* **Staff Notes** (optional): Enter any additional notes about the job performed.
* **Task Start Time** (required): Select the time the task started.
* **Task End Time** (required): Select the time the task ended.
* **Job Category** (required): Select a relevant category for the job.
* **Job Status** (optional): Select multiple job status options.
* **Work Order** (required): Type in the work order number.
* **Staff Notes 2** (optional): Enter additional notes about the job.
* **Date** (required): Select the date of the job.
* **Time** (required): Select the time of the job.
* **Task** (required): Enter a brief description of the task.
* **Notes** (optional): Enter any additional information about the job.
* **Files** (optional): Enter file names or descriptions of files related to the job.
* **File 2**, **File 3**, **File 4**, **File 5**, or **File 6** (optional): Enter additional file names or descriptions.
