# Crime Clearance Rate Report Form - Help Guide
## Purpose
The Crime Clearance Rate Report Form is used to report and record the clearance rate of crimes by law enforcement agencies. This form helps gather and report crime clearance data in a structured manner.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the type of crime that was cleared (e.g., Murder, Violent Crime, or Property Crime).
2.  Enter the clearance date range for the crime was cleared (if applicable).
3.  Enter the start date and end date of the date range (if applicable).
4.  Enter the clearance rate for the crime (if applicable).
5.  Select the agency responsible for clearing the crime (e.g., Local Police Department, State Police Department, or Federal Police Department).
6.  Enter the name of the officer or officer's name who cleared the crime (if applicable).

## Field-by-Field Explanation
* **Crime Type** (`crime_type`, select_one): Select the type of crime that was cleared, such as Murder, Violent Crime, or Property Crime.
* **Clearance Date Range** (`clearance_date_range`, date): Enter the date range during which the crime was cleared (if applicable). This field is not required.
* **Start Date** (`start_date`, date): Enter the start date of the date range (if applicable). This field is not required.
* **End Date** (`end_date`, date): Enter the end date of the date range (if applicable). This field is not required.
* **Clearance Rate** (`clearance_rate`, number): Enter the clearance rate for the crime (if applicable). This field is not required.
* **Agency** (`agency`, select_multiple): Select the agency responsible for clearing the crime, such as Local Police Department, State Police Department, or Federal Police Department.
* **Officer Name** (`officer_name`, text): Enter the name of the officer or officer's name who cleared the crime (if applicable). This field is not required.

## Tips
* Make sure to select the correct crime type for accurate reporting.
* Enter accurate dates for the clearance date range and start/end dates.
* Enter accurate clearance rate data (if applicable).
* Select the correct agency that cleared the crime.
* Enter accurate officer name data (if applicable).
