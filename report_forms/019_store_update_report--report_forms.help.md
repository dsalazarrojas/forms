# Store Update Report - Help Guide
## Purpose
The Store Update Report form is used to update information about a store, including its name, location, phone number, email, status, categories, comments, and update details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the store's name in the "Store Name" field.
2. Enter the store's location in the "Store Location" field.
3. Enter the store's phone number in the "Store Phone Number" field.
4. Enter the store's email address in the "Store Email" field.
5. Select the store's status from the "Store Status" dropdown menu.
6. Choose the categories that apply to the store in the "Store Category" dropdown menu.
7. Specify whether the store has a subcategory by selecting "Yes" or "No" in the "Store Subcategory" dropdown menu.
8. Enter any comments about the store update in the "Store Comments" field.
9. Enter the date and time of the update in the "Store Update Date" and "Store Update Time" fields.
10. Identify the user who last updated the store by entering their name in the "Store Last Updated By" field.
11. Select the browser type used for the last update from the "Store Last Updated Browser Type" dropdown menu.
