# Healthcare Provider Shift Report - Help Guide

## Purpose
The Healthcare Provider Shift Report form is used to collect information about a healthcare provider's shifts. This includes reporting on patient interactions, start and end times, and staff IDs.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary information about the patient and the healthcare provider's shift before starting.
2. Enter the patient's ID (if applicable) in the "Patient Id" field.
3. Enter the start time of the shift in the "Start Time In" field.
4. Enter the end time of the shift in the "End Time Out" field.
5. Enter the healthcare provider's ID in the "Staff Id" field.

## Field-by-Field Explanation

* **Patient Id** (`patient_id`, number, optional): Enter the patient's ID if applicable. This is not a required field, so it can be left blank if not necessary.
* **Start Time In** (`start_time_in`, time, optional): Enter the start time of the shift. This should be the time when the healthcare provider's shift began.
* **End Time Out** (`end_time_out`, time, optional): Enter the end time of the shift. This should be the time when the healthcare provider's shift ended.
* **Staff Id** (`staff_id`, text, optional): Enter the healthcare provider's ID. This is typically a unique identifier for the healthcare provider.
* **Tips**: Make sure to enter accurate and up-to-date information to ensure the form is completed correctly. If you're unsure about any field, contact your supervisor or support team for assistance.
