# Daily Construction Report - Help Guide
## Purpose
The Daily Construction Report is a tool used by construction management teams to document and record daily progress, issues, and next steps for construction projects.

## How To Complete This Form
1. **Start by filling in the "Project Name" field with the name of the project you are working on.**
2. **Enter the location of the project in the "Location" field.**
3. **Provide an update on the current project status in the "Project Status" field.**
4. **List any outstanding work orders in the "Work Orders" field.**
5. **If any issues have been reported, list them in the "Issues Reported" field.**
6. **Describe the corrective action taken or planned for the issue(s) in the "Corrective Action" field.**
7. **Outline the next steps for the project in the "Next Steps" field.**
8. **Enter your name as the "Project Manager" for reference.**
9. **Enter your name as the "Submitted By" for tracking and auditing purposes.**
10. **Select the date and time of the report using the "Date" and "Time" fields.**

## Field-by-Field Explanation
* **Project Name** (required): Enter the name of the project you are currently working on.
* **Location** (optional): Enter the location of the project site.
* **Project Status** (optional): Provide an update on the current project status, e.g., "Ongoing," "Delayed," or "Completed."
* **Work Orders** (optional): List any outstanding work orders for the project.
* **Comments** (optional): Enter any comments or additional information about the project.
* **Issues Reported** (optional): List any issues reported on the project site.
* **Corrective Action** (optional): Describe the action taken or planned for the issue(s) reported.
* **Next Steps** (optional): Outline the next steps for the project.
* **Project Manager** (optional): Enter your name as the project manager for reference.
* **Submitted By** (optional): Enter your name for tracking and auditing purposes.
* **Date** (optional): Select the date of the report.
* **Time** (optional): Select the time of the report.
