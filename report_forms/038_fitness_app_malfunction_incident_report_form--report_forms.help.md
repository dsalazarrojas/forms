# Fitness App Malfunction Incident Report Form - Help Guide
## Purpose
This form is used to report malfunctions or issues with the fitness app. It helps our team to quickly identify and resolve the problems, providing a better user experience.

## How To Complete This Form
To fill out this form, please follow these steps:

1. Review the form and ensure you understand the severity levels for each issue.
2. Select the correct severity level for your reported issue.
3. Complete the fields with accurate and detailed information about the issue, including:
   - The type of app that was malfunctioning (Mobile App, Desktop App, or Web App)
   - A description of the issue
   - The date you first noticed the issue
   - The current status of the issue (Open or Closed)
   - Any additional comments or notes

## Field-by-Field Explanation

* **Fitness App Malfunction Incident Report** (`form_header`, text, required): A brief description of the issue, including the app's name or title.
* **Reported By** (`reported_by`, select_one, required): The person who is reporting the issue, which can be either an "Admin" or a "User".
* **Reported Date** (`reported_date`, date, required): The date when you first noticed the issue.
* **App Type** (`app_type`, select_one, required): The type of app that was malfunctioning, which can be either "Mobile App", "Desktop App", or "Web App".
* **Issue Description** (`issue_description`, text, required): A detailed description of the issue you are experiencing.
* **Issue Severity** (`issue_severity`, select_one, required): The severity level of the issue, which can be "Minor", "Major", or "Critical".
* **Issue Report** (`issue_report`, text, required): A detailed report of the issue, including any steps to reproduce or specific actions to take.
* **Issue Reported At** (`issue_reported_at`, date, required): The date when you are reporting the issue.
* **Issue Status** (`issue_status`, select_one, required): The current status of the issue, which can be either "Open" or "Closed".
* **Notes** (`notes`, note, optional): Additional comments or notes about the issue, if any.

**Tips**:

* Make sure to include all required fields to ensure the form is submitted accurately.
* Use the provided options for the "Reported By" and "Issue Severity" fields to select the correct option.
* Use the "Notes" field for any additional information that may help our team understand the issue better.
