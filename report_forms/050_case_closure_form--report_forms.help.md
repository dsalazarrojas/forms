# Case Closure Form - Help Guide

## Purpose
The Case Closure Form is a crucial document used to finalize a case by providing details about the investigation's outcome, resolution, and status. This form helps to ensure that all relevant information is accurately documented and communicated to stakeholders, promoting transparency and accountability in the investigation process.

## How To Complete This Form

1. Ensure you have permission to access the form.
2. Fill out the form accurately and completely, paying attention to all required fields.
3. Review the form for errors before submitting it.

## Field-by-Field Explanation

* **Case Number**: Enter the primary investigation identifier. This is the unique code for the case.
	+ Example: 2022-01-001
* **Primary Incident Type**: Select the main category of the case from the provided options.
	+ Example: Theft or Larceny
* **Lead Investigating Officer**: Enter the name of the officer responsible for investigating the case.
* **Officer Badge Number**: Enter the badge number of the lead investigating officer.
* **Date Case Opened**: Enter the date the case was initially opened.
* **Date Case Closed**: Enter the date the case was closed.
* **Primary Reason for Closure**: Select the official status of the case closure.
	+ Example: Arrest Made
* **Summary of Final Investigation Findings**: Provide a clear and concise narrative of the outcome.
* **Disposition of Collected Evidence**: Select what happened to the physical items collected during the investigation.
	+ Example: Returned to Owner
* **Suspect Name (if known)**: If applicable, enter the name of the primary suspect.
* **Current Suspect Status**: Select the current status of the suspect.
	+ Example: In Custody
* **Was the victim or complainant notified of closure?**: Select whether the victim or complainant was notified of the closure.
* **Date of Notification**: Enter the date the victim or complainant was notified, if applicable.
* **Method of Notification**: Select how the victim or complainant was informed of the closure.
* **Has the prosecutor reviewed this closure?**: Select whether the prosecutor has reviewed the case closure, for cases involving arrests.
* **Has the case file been digitally archived?**: Select whether the case file has been digitally archived.
* **Approving Supervisor Name**: Enter the name of the supervisor approving the case closure.
* **Supervisor Badge Number**: Enter the badge number of the supervisor approving the case closure.
* **Official Electronic Signature**: Type your official name as digital signature.
