# Raw Material Utilization Report Form - Help Guide
## Purpose
The Raw Material Utilization Report Form is used to report on the utilization and production of raw materials in the organization. This form is used to track and document the details of raw materials that have been used or produced, including quantities, production dates, and production costs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the relevant information about the raw material you want to report on.
2. Select the correct options for each field as applicable.
3. Make sure to provide accurate and detailed information to ensure accurate tracking and reporting.

## Field-by-Field Explanation
* **Material Name** (`material_name`, text, optional): Enter the name of the raw material being reported on.
* **Quantity** (`quantity`, number, optional): Enter the quantity of raw material used or produced.
* **Unit Name** (`unit_name`, text, optional): Enter the unit name or description of the raw material.
* **Wastage Percent** (`wastage_percent`, number, optional): Enter the percent waste of raw material during production.
* **Production Details** (`production_details`, select_one, optional):
	+ Select 'Yes' if the raw material has been produced.
	+ Select 'No' if the raw material has not been produced.
* **Production Date** (`production_date`, date, optional): Enter the date of production.
* **Manufacturing Location** (`manufacturing_location`, select_one, optional):
	+ Select 'Yes' if the raw material has been produced at a manufacturing location.
	+ Select 'No' if the raw material has not been produced at a manufacturing location.
* **Production Cost** (`production_cost`, number, optional): Enter the production cost of the raw material.
* **Production Time** (`production_time`, time, optional): Enter the production time of the raw material.
* **Raw Material ID** (`raw_material_id`, select_one, optional):
	+ Select 'Yes' if the raw material has a unique ID.
	+ Select 'No' if the raw material does not have a unique ID.
* **Material Code** (`material_code`, text, optional): Enter the material code of the raw material.
* **Batch Number** (`batch_number`, text, optional): Enter the batch number of the raw material.
* **Remarks** (`remarks`, note, optional): Enter any additional remarks or comments about the raw material.
* **Email** (`email`, email, optional): Enter the contact email of the person reporting on the raw material.
* **Phone** (`phone`, text, optional): Enter the contact phone number of the person reporting on the raw material.
* **Production Location** (`production_location`, select_one, optional):
	+ Select 'Yes' if the raw material has been produced at a production location.
	+ Select 'No' if the raw material has not been produced at a production location.
* **Production Start Date** (`production_start_date`, date, optional): Enter the start date of production.
* **Production End Date** (`production_end_date`, date, optional): Enter the end date of production.
* **Production Hours** (`production_hours`, time, optional): Enter the production hours of the raw material.
* **Raw Material ID 2** (`raw_material_id_2`, select_one, optional):
	+ Select 'Yes' if the raw material has a second ID.
	+ Select 'No' if the raw material does not have a second ID.
* **Material Code 2** (`material_code_2`, text, optional): Enter the material code of the second raw material.
* **Batch Number 2** (`batch_number_2`, text, optional): Enter the batch number of the second raw material.
* **Remarks 2** (`remarks_2`, note, optional): Enter any additional remarks or comments about the second raw material.
* **Remarks 3** (`remarks_3`, note, optional): Enter any additional remarks or comments about other raw materials.
