# Project Budget Form - Help Guide
## Purpose
The Project Budget Form is used to create and track project budgets. It gathers essential information such as project details, budget, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project details, including the project name and location.
2. Determine if the project is active or inactive.
3. Choose whether the project has a budget.
4. Enter the budgeted and actual costs.
5. Set the budget percentage.
6. Select the project category.
7. Set the project start and end dates.
8. Review and submit the form.

## Field-by-Field Explanation
* **Project Budget** (`project_budget_form`, text, required): Enter the project's budget.
* **Project Status** (`project_status`, select_multiple, required): Choose whether the project is active or inactive.
* **Project Category** (`project_category`, select_one, required): Select the project category.
* **Project Location** (`project_location`, select_multiple, required): Select the project's location.
* **Budgeted Costs** (`budgeted_costs`, number, optional): Enter the budgeted costs.
* **Actual Costs** (`actual_costs`, number, optional): Enter the actual costs.
* **Budget Percentage** (`budget_percentage`, number, optional): Set the budget percentage.
* **Project Name** (`project_name`, text, optional): Enter the project's name.
* **Project Start Date** (`project_start_date`, date, optional): Set the project start date.
* **Project End Date** (`project_start_date`, date, optional): Set the project end date.
