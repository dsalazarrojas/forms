# Pet Health Record Form - Help Guide
## Purpose
This form is designed to collect detailed information about a pet's health status, including medications, vaccinations, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form instructions and make sure you understand what information is required and what each field represents.
2. Fill in the required information for each field, using the options provided for select fields (e.g., medications, vaccinations).
3. Make sure to review and update the form regularly to reflect any changes in the pet's health status.

## Field-by-Field Explanation

- **pet_health_form** (1, number): Enter the pet's health record number or identifier.
- **pet_medications** (2, select_multiple): Select all medications the pet is currently taking.
- **medications** (3, select_one): Select the primary medication the pet is currently taking.
- **food** (4, text): Enter the pet's food information (e.g., type of food, feeding schedule).
- **vaccinations** (5, select_multiple): Select all vaccinations the pet has received.
- **vaccinations** (6, select_one): Select the most recent vaccination the pet received.
- **behavior** (7, text): Describe the pet's behavior (e.g., appetite, energy level).
- **allergies** (8, text): List the pet's allergies, if any.

## Tips

- Make sure to review and update the form regularly to reflect any changes in the pet's health status.
- If you're unsure about any information, consult with a licensed veterinarian.
- Keep the form accurate and up-to-date to ensure the best care for your pet.
