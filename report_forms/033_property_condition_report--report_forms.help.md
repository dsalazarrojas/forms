# Property Condition Report - Help Guide
## Purpose
The Property Condition Report form is designed to collect detailed information about the condition of a property. This report is typically completed after an inspection and is used to assess the property's current state.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the property from the list provided. This will help identify the specific areas that need attention.
2. Choose the type of property (Residential, Commercial, Industrial, or Other) to indicate its usage.
3. Describe the current condition of the property in a few words. This field is for a brief summary.
4. Enter the date you visited the property. This will help track the history of inspections and condition changes.
5. Provide a detailed description of the property's condition. This field is for any notable observations or issues.

## Field-by-Field Explanation

* **Category (Category)** (`select_one`, **not required**): Select one of the provided categories to identify the area of the property's condition.
* **Property Type (Property Type)** (`select_multiple`, **not required**): Choose the type of property (Residential, Commercial, Industrial, or Other) to indicate its usage.
* **Current Condition (Condition Description)** (`text`, **not required**): Describe the current condition of the property in a few words. This field is for a brief summary.
* **Date Visited (Date Visited)** (`date`, **not required**): Enter the date of your visit to the property. This will help track the history of inspections and condition changes.
* **Condition Description (Condition Description)** (`text`, **not required**): Provide a detailed description of the property's condition. This field is for any notable observations or issues.
