# software_code_metrics_report_form - Help Guide
## Purpose
This form is used for reporting code metrics on a software development project.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the project name and project ID (if applicable)
2. Select the code metrics type (e.g., "Yes" or "No")
3. Provide the date and time completed (if applicable)
4. Enter any reviewer comments (if applicable)
5. Select the project status (e.g., "Active" or "Inactive")
6. Fill out any additional pages required (e.g., page 2, page 3, etc.)

## Field-by-Field Explanation

* **software_code_metrics_report_form_page_1_label**: This page is a brief summary page with no specific fields to fill out. You have already reached the end of the form.
* **code_metrics_type**: Choose "Yes" to report on code metrics or "No" if you do not have any metrics to report on.
* **project_name**: Enter the name of the project you are reporting on.
* **project_id**: Enter the ID of the project you are reporting on. If you don't have a project ID, you can leave this field blank.
* **date_completed**: Enter the date the project was completed (if applicable).
* **time_completed**: Enter the time the project was completed (if applicable).
* **reviewer_comments**: Enter any comments from the project reviewer (if applicable).
* **project_status**: Select the current status of the project (e.g., "Active" or "Inactive").
* **code_metrics_report_form_page_2**: This field is not actually a field to fill out, as it is a label for the next page.
* **code_metrics_report_form_page_3**: This field is not actually a field to fill out, as it is a label for the next page.
* **code_metrics_report_form_page_4**: This field is not actually a field to fill out, as it is a label for the next page.

## Tips
* Make sure to fill out all required fields accurately and completely.
* If you're unsure about any field, refer back to the form purpose and instructions above.
* Double-check your report before submitting it to ensure it is accurate and comprehensive.
