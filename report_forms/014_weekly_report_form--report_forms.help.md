# Weekly Report Form - Help Guide
## Purpose
The Weekly Report Form is a tool for users to submit reports on a weekly basis, providing information about their progress, comments, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information ready before starting the form.
2. Select the relevant information for each field, following the guidelines for each field type.
3. Review and edit the form carefully before submission.

## Field-by-Field Explanation
### Page 1: submit
* **Submit** (`submit`, text, required/optional): This is the submit button to finalize your report.

### Page 2: date
* **Date** (`date`, text, required/optional): Enter the date of completion.

### Page 3: progress
* **Progress** (`progress`, text, required/optional): Describe your progress on the project.

### Page 4: comments
* **Comments** (`comments`, note, required/optional): Add any comments or feedback.

### Page 5: email
* **Email** (`email`, text, required/optional): Enter your email address.

### Page 6: phone
* **Phone** (`phone`, text, required/optional): Enter your phone number.

### Page 7: report_details
* **Report Details** (`report_details`, text, required/optional): Provide any additional details.

### Page 8: weekly_report_form
* **Weekly Report Form** (`weekly_report_form`, select_one, required/optional): Select the form type.

### Page 9: notes
* **Notes** (`notes`, note, required/optional): Add any additional notes.

### Page 10: assigned_tool
* **Assigned Tool** (`assigned_tool`, select_multiple, required/optional): Select the tools used.

### Page 11: category
* **Category** (`category`, select_one, required/optional): Select the category of the report.

### Page 12: form_id
* **Form ID** (`form_id`, number, required/optional): Enter the form ID.

### Page 13: output_file
* **Output File** (`output_file`, text, required/optional): Upload a file.

### Page 14: description
* **Description** (`description`, text, required/optional): Add a description of the report.

### Page 15: created_by
* **Created By** (`created_by`, text, required/optional): Enter your name.

### Page 16: created_at
* **Created At** (`created_at`, date, required/optional): Enter the date of creation.

### Page 17: updated_at
* **Updated At** (`updated_at`, date, required/optional): Enter the date of update.

### Page 18: updated_by
* **Updated By** (`updated_by`, text, required/optional): Enter the name of the updater.

### Page 19: form_status
* **Form Status** (`form_status`, select_one, required/optional): Select the status of the form.

### Page 20: comments_section
* **Comments Section** (`comments_section`, text, required/optional): Add comments.

### Page 21: submitted_at
* **Submitted At** (`submitted_at`, date, required/optional): Enter the date of submission.

### Page 22: submitted_by
* **Submitted By** (`submitted_by`, text, required/optional): Enter the name of the submitter.

### Page 23: form_version
* **Form Version** (`form_version`, text, required/optional): Enter the version of the form.

### Page 24: remarks
* **Remarks** (`remarks`, text, required/optional): Add any remarks.

### Page 25: submitter
* **Submitter** (`submitter`, text, required/optional): Enter your name.

### Tips
* Double-check all fields for accuracy before submitting.
* Review the form thoroughly before finalizing your report.
* If you're unsure about any field, consult your supervisor or the form owner for guidance.
