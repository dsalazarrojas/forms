# Duty Manager Daily Checklist - Help Guide
## Purpose
The Duty Manager Daily Checklist is a tool used by duty managers to track and manage their daily tasks and activities. This form helps the duty manager keep a record of their tasks, status, and updates for others.

## How To Complete This Form
1. Fill out the "Daily Checklist" field with a list of your daily tasks and activities.
2. Review the "Check Lists" field and select whether each task has been completed.
3. Provide more details about each task in the "Task Details" field.
4. Select the status of each task in the "Task Status" field (e.g., Active, Inactive).
5. Add any additional comments or notes about your tasks and activities in the "Comments" field.
6. Review the "Completed Tasks" field and select which tasks you have completed.
7. Add additional notes about each task in the "Task Notes" field.
8. Select whether a task has been assigned to someone else in the "Task Assignee" field.

## Field-by-Field Explanation
* **Daily Checklist (Daily Checklist)**: This field is for you to list out your daily tasks and activities. You can enter any relevant information about your tasks and activities.
* **Check Lists (Check Lists)**: In this field, select whether each task has been completed by choosing "Yes" or "No".
* **Task Details (Task Details)**: This field is for you to provide more information about each task and activity listed in the "Daily Checklist" field.
* **Task Status (Task Status)**: Select the status of each task by choosing from the options "Active" or "Inactive".
* **Comments (Comments)**: Add any comments or notes about your tasks and activities.
* **Completed Tasks (Completed Tasks)**: Review and select which tasks you have completed by choosing from the options "Yes" or "No".
* **Task Notes (Task Notes)**: Add additional notes about each task and activity.
* **Task Assignee (Task Assignee)**: Select whether a task has been assigned to someone else by choosing from the options "Yes" or "No".
