## Suspected Child Sexual Abuse Material (CSAM) Report Form - Help Guide
## Purpose
The Suspected Child Sexual Abuse Material (CSAM) Report Form is a tool used to report and document suspected child sexual abuse material incidents. The form is designed to gather relevant information from incident reporters, which can then be used to take appropriate action and support the affected individuals.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure you have all the necessary information before starting.
2. Fill out the form with as much detail as possible.
3. Make sure to select the correct options from the Report Type field, as this will help categorize and prioritize the incident.
4. Provide a clear and concise description of the incident in the Incident Description field.
5. If you're reporting on behalf of someone else, please ensure you have their consent to report the incident.

## Tips
* Please report all incidents that you believe may involve child sexual abuse material.
* If you're unsure about what constitutes child sexual abuse material, please consult with a trusted resource or authority.
* Report as much detail as possible, as this will help in taking appropriate action.
* If you're reporting on behalf of someone else, please ensure you have their consent to report the incident.
* If you need assistance or guidance, please reach out to your local support services or authorities.

Note: This form is not a substitute for professional help or support services. If you're affected by child sexual abuse material, please seek help from trusted resources or authorities.
