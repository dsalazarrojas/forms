# Restaurant Incident Report Form - Help Guide
## Purpose
This form is used to document non-emergency incidents that occur within the restaurant, such as spills, equipment malfunctions, or customer complaints. The information collected will be used to improve restaurant operations and provide a record of past incidents.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the date and time the incident occurred in the "Incident Date" field.
2. Select the location where the incident occurred from the "Location" dropdown menu.
3. Provide a brief description of the location in the "Location Details" field.
4. List any witnesses to the incident in the "Witnesses" field.
5. If applicable, attach any supporting documents related to the incident in the "Supporting Documents" field.
6. Write a brief summary of the incident in the "Incident Summary" field.

## Field-by-Field Explanation
* **Incident Date** (`incident_date`, date, required: false): Enter the date the incident occurred.
* **Incident Time** (`incident_time`, time, required: false): Enter the time the incident occurred.
* **Location** (`location`, select_one, required: false): Select the location where the incident occurred (e.g. kitchen, dining area, etc.).
*   **Location Details** (`location_details`, text, required: false): Provide a brief description of the location where the incident occurred.
*   **Witnesses** (`witnesses`, select_multiple, required: false): List any witnesses to the incident.
*   **Supporting Documents** (`supporting_documents`, text, required: false): If applicable, attach any supporting documents related to the incident (e.g. photos, videos, etc.).
*   **Incident Summary** (`incident_summary`, text, required: false): Write a brief summary of the incident (e.g. what happened, what was the cause, etc.).
