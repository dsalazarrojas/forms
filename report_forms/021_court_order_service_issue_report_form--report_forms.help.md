# Court Order Service Issue Report Form - Help Guide
## Purpose
The Court Order Service Issue Report Form is designed to collect data on issues encountered while serving court orders. This data helps the team identify areas for improvement in the service process, ensuring quality and efficiency.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all applicable service attempts that experienced issues from the list provided. You can select multiple attempts if necessary.
2. Report the number of attempts that resulted in issues.
3. Enter a description of each issue you encountered while serving the court order. Be as detailed as possible to help the team understand the problem.

## Field-by-Field Explanation

* **Service Attempts**: Choose all attempts where issues were encountered. Selecting "Attempt 1" indicates that the issue occurred on the first attempt to serve the court order. Similarly, selecting "Attempt 2" means the issue occurred on the second attempt. You can choose multiple attempts if needed.
* **Number of Attempts**: Report the total number of attempts made to serve the court order. This will help the team track the number of attempts and identify trends.
* **Number of Issues**: Enter the total number of issues reported while serving the court order.
* **Issue Description**: Describe each issue you encountered while serving the court order. Be as detailed as possible, including specific circumstances, dates, and times. This will provide the team with valuable information to understand the root cause of the issue.
