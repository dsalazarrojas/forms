# Insurance Claims Discrepancy Incident Report - Help Guide
## Purpose
The purpose of this form is to report discrepancies in insurance claims, providing a clear and detailed account of the incident.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide the date and time of the incident in the "Incident Date" and "Incident Time" fields.
2.  Enter the location of the incident in the "Incident Location" field.
3.  Describe the incident in detail in the "Incident Description" field.
4.  If the claimant's information is not available, you can enter "Not Applicable" in the respective fields.
5.  If a representative is involved, provide their information in the "Representative Information", "Representative Name", "Representative Phone", and "Representative Email" fields.
6.  Ensure that the claimant and representative signatures are provided in the "Claimant Signature" and "Representative Signature" fields, respectively.
7.  You can provide any additional information about the incident in the "Additional Information" field.

## Field-by-Field Explanation
*   **Incident Date** (`incident_date`, date, required): The date of the incident that you are reporting.
*   **Incident Time** (`incident_time`, time, required): The time of the incident.
*   **Incident Location** (`incident_location`, text, optional): The location where the incident occurred.
*   **Incident Description** (`incident_description`, text, optional): A detailed description of the incident.
*   **Claimant Information** (`claimant_info`, text, optional): Any available information about the claimant.
*   **Claimant Name** (`claimant_name`, text, optional): The name of the claimant.
*   **Claimant Address** (`claimant_address`, text, optional): The address of the claimant.
*   **Claimant Phone** (`claimant_phone`, text, optional): The phone number of the claimant.
*   **Claimant Email** (`claimant_email`, email, optional): The email address of the claimant.
*   **Claimant Relationship** (`claimant_relationship`, select one, required): Check if the claimant is an insurance policyholder or a representative.
*   **Policy Information** (`policy_info`, text, optional): Any information about the insurance policy.
*   **Claimant Signature** (`claimant_signature`, text, required): The claimant's signature.
*   **Representative Information** (`representative_info`, text, optional): Any available information about the representative.
*   **Representative Name** (`representative_name`, text, optional): The name of the representative.
*   **Representative Phone** (`representative_phone`, text, optional): The phone number of the representative.
*   **Representative Email** (`representative_email`, email, optional): The email address of the representative.
*   **Representative Signature** (`representative_signature`, text, required): The representative's signature.
*   **Insurance Information** (`insurance_info`, text, optional): Any information about the insurance.
*   **Adjuster Information** (`adjuster_info`, text, optional): Any information about the adjuster.
*   **Adjuster Name** (`adjuster_name`, text, optional): The name of the adjuster.
*   **Adjuster Phone** (`adjuster_phone`, text, optional): The phone number of the adjuster.
*   **Adjuster Email** (`adjuster_email`, email, optional): The email address of the adjuster.
*   **Adjuster Signature** (`adjuster_signature`, text, optional): The adjuster's signature.
*   **Additional Information** (`additional_info`, text, optional): Any other information about the incident.
