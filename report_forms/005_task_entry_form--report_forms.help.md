# Task Entry Form - Help Guide
## Purpose
The purpose of this form is to gather information about tasks, including objectives, descriptions, start and end dates, and priority levels.

## How To Complete This Form
1. Click on the "Task Entry Form" to begin.
2. Fill out the form with the required information, such as:
	* Objective: A brief description of the task's objective.
	* Task Description: A detailed explanation of the task.
3. Select the task's type from the options provided (Task, Objective, Goal).
4. Choose the start and end dates for the task.
5. Select the priority level (Low, Medium, High) for the task.
6. Select the status of the task (Completed, In Progress, Overdue).
7. Assign the task to a specific person (chatjimmy, John Doe, Jane Doe).
8. Select the person who created the task.
9. Click on "Submit" to save the form.

## Field-by-Field Explanation
* **Objective** (`objective`, required/optional): Enter a brief description of the task's objective.
* **Task Description** (`task_description`, required/optional): Enter a detailed explanation of the task.
* **Task Type** (`task_type`, required/optional): Select the type of task (Task, Objective, Goal).
* **Start Date** (`start_date`, required/optional): Enter the start date of the task.
* **Start Time** (`start_time`, required/optional): Enter the start time of the task.
* **End Date** (`end_date`, required/optional): Enter the end date of the task.
* **End Time** (`end_time`, required/optional): Enter the end time of the task.
* **Priority** (`priority`, required/optional): Select the level of priority (Low, Medium, High).
* **Status** (`status`, required/optional): Select the status of the task (Completed, In Progress, Overdue).
* **Assigned To** (`assigned_to`, required/optional): Select the person assigned to the task (chatjimmy, John Doe, Jane Doe).
* **Created By** (`created_by`, required/optional): Select the person who created the task (chatjimmy, John Doe, Jane Doe).

## Tips
* Use this form to track tasks effectively and accurately.
* Make sure to fill out all required fields.
* Review and edit your form submissions as needed.
* Use the form's options to select relevant and accurate information.
