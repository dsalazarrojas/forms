# Fire Safety Daily Work Report - Help Guide
## Purpose
The Fire Safety Daily Work Report is a standard form used to document and report fire hazards and safety concerns that occurred during daily work activities. It ensures that critical information is collected and documented in a timely and consistent manner.

## How To Complete This Form
To complete this form, follow these steps:

1.  Ensure that you are on-site and have access to the necessary information.
2.  Fill out the form accurately and thoroughly.
3.  Answer all required fields.
4.  If no issues were encountered during your shift, report "No" for the related fields.

## Field-by-Field Explanation

*  **Fire Safety Daily Work Report** (general_info, text, optional): This field is the main title of the report. It is not mandatory to fill out, but it is recommended to include a brief description of the report if applicable.
*  **Facility ID** (facility_id, select_one, required): Please select "Yes" if the fire safety report is related to a specific facility. Select "No" otherwise.
*  **Fire Hazards** (fire_hazards, select_multiple, optional): List all fire hazards encountered during your shift by selecting the corresponding options. If no fire hazards were encountered, select "No".
*  **Fire Hazards Description** (fire_hazards_description, text, required): Provide a detailed description of the fire hazards listed in the previous field.
*  **Fire Precautions** (fire_precautions, select_one, optional): Indicate if any fire precautions were taken during your shift by selecting "Yes". Select "No" otherwise.
*  **Date and Time** (date_and_time, date, required): Enter the date and time when the fire safety report was completed.
*  **Start Time** (start_time, time, required): Record the start time of your shift.
*  **Inspector Signature** (inspector_signature, note, optional): If an inspector is present, please sign the report to confirm their review.
*  **Supervisor Signature** (supervisor_signature, note, optional): If a supervisor is present, please sign the report to confirm their review.
