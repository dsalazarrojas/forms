# COVID 19 Lab Report Form - Help Guide
## Purpose
This form is used to report COVID-19 lab test results, providing essential information for further clinical action and decision-making.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the report date and time in the "Report Date" and "Report Time" fields.
2. Provide the laboratory name and the name of the lab technician who collected the sample.
3. Enter the patient's name, patient ID or MRN, date of birth, and phone number (if available).
4. Select the type of sample collected (e.g., nasopharyngeal swab, blood, sputum, etc.).
5. Enter the sample collection date and time.
6. Enter the test type (e.g., PCR, antigen, antibody, etc.).
7. Select the test result (e.g., positive, negative, invalid, etc.).
8. Enter any Ct value (if applicable).
9. Describe the test methodology used.
10. Enter the clinical interpretation of the results.
11. Enter the name of the lab director who approved the results.
12. Select the approval status (e.g., approved, pending review, rejected).

## Field-by-Field Explanation

* **Report Date (id: 2)**: Enter the date on which the report was generated.
* **Report Time (id: 3)**: Enter the time at which the report was generated.
* **Laboratory Name (id: 4)**: Enter the name of the laboratory where the test was performed.
* **Lab Technician Name (id: 5)**: Enter the name of the lab technician who collected the sample.
* **Patient Name (id: 7)**: Enter the name of the patient for whom the test was performed.
* **Patient ID or MRN (id: 8)**: Enter the patient's ID or MRN (Medical Record Number).
* **Date of Birth (id: 9)**: Enter the patient's date of birth.
* **Patient Phone Number (id: 10)**: Enter the patient's phone number (if available).
* **Referring Physician Name (id: 11)**: Enter the name of the referring physician.
* **Sample Type (id: 13)**: Select the type of sample collected (e.g., nasopharyngeal swab, blood, sputum, etc.).
* **Sample Collection Date (id: 14)**: Enter the date on which the sample was collected.
* **Sample Collection Time (id: 15)**: Enter the time at which the sample was collected.
* **Sample ID or Barcode (id: 16)**: Enter the sample ID or Barcode.
* **Test Type (id: 18)**: Select the type of test performed (e.g., PCR, antigen, antibody, etc.).
* **Test Result (id: 19)**: Select the outcome of the test (e.g., positive, negative, invalid, etc.).
* **Ct Value (id: 20)**: Enter any Cycle Threshold value if applicable.
* **Test Methodology (id: 21)**: Describe the test methodology used.
* **Clinical Interpretation (id: 23)**: Enter the clinical interpretation of the test results.
* **Lab Director Name (id: 24)**: Enter the name of the lab director who approved the results.
* **Approval Status (id: 25)**: Select the approval status (e.g., approved, pending review, rejected).

Please take care to complete each field accurately and thoroughly, and refer to your supervisor or lab director if you have any questions or concerns.
