# Report Found Pet Form - Help Guide
## Purpose
The Report Found Pet Form is designed to collect information about a pet that a user has found. This form is for reporting pets that need attention or care, and is intended to assist the relevant authorities in reuniting the pet with its owner.

## How To Complete This Form

To complete this form, follow these steps:

1. **Select "Yes" or "No" to indicate if you have found any pets**: Use the "Found Pets" section to select all pets that you have found.
2. **Provide pet information**: In the "Pet Information" section, enter a brief description of the pet you have found, such as its species and any identifying features.
3. **Enter owner details**: In the "Pet Owner" section, provide any information you have about the pet's owner, such as their name and contact details.
4. **Provide photo URL**: If you have a photo of the pet, share the URL where it can be accessed.
5. **Enter owner address**: Provide the address of the pet's owner.

## Field-by-Field Explanation

* **Found Pets** (`found_pets`, select_multiple, required): Select all pets you have found.
	+ Please indicate if you have found any pets. If none, select "No".
* **Pet Information** (`pet_info`, text, optional): Enter a brief description of the pet you have found.
	+ This field is intended to provide any identifying features about the pet, such as its species, color, or size.
* **Pet Owner** (`owner`, note, optional): Enter any information you have about the pet's owner.
	+ This field is for providing any details about the pet's owner, such as their name, contact phone number, or address.
* **Photo Url** (`photo_url`, text, optional): Enter the URL where the photo of the pet can be accessed.
	+ If you have a photo of the pet, please provide the URL where it can be found.
* **Owner Address** (`owner_address`, text, optional): Enter the address of the pet’s owner.
	+ This field is for providing the owner’s address, in case they need to be notified directly.

## Tips

* Please ensure that all fields are filled in accurately and completely.
* Do not submit duplicate reports for the same pet. 
* If you are unsure about any field or require further assistance, feel free to contact us directly.
* If you are reporting multiple pets, submit each pet as a separate report.
