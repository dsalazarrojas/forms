# house_checklist_form - Help Guide
## Purpose
This form is designed to collect relevant information about a house's condition, systems, and services. It helps ensure consistent and accurate data collection for maintenance and reporting purposes.

## How To Complete This Form
1. Review each section carefully and provide accurate information.
2. Fill out the form for all houses in the collection to maintain consistency.
3. Answer each field according to the options provided.

## Field-by-Field Explanation

### House Status (1)
* **House Status**: Enter the overall status of the house (e.g., occupied, vacant, etc.).

### House Type (2)
* **House Type**: Select the type of house (e.g., single-family home, duplex, condo).

### Systems Check (3)
* **Systems Check**: Check all basic systems and engines in the house (e.g., heating, cooling, plumbing, electrical).

### Service Requirements (4)
* **Service Requirements**: Describe any service requirements for the house (e.g., cleaning, maintenance, etc.).

### Exterior Information (5)
* **Exterior Information**: Collect information about the house's exterior (e.g., color, material, etc.).

### Security Information (6)
* **Security Information**: Gather security-related data for the house (e.g., cameras, alarms, etc.).

### Workability of Systems (7)
* **Workability of Systems**: Check the workability of all basic systems and engines (e.g., heating, cooling, etc.).
* **Options:** Check 'Yes' if the systems are functional, and 'No' otherwise.

### Service Information (8)
* **Service Information**: This field is currently empty. Please ignore it.

### Security Systems (9)
* **Security Systems**: List all security systems in the house (e.g., cameras, alarms, etc.).
* **Options:** Check 'Yes' if the system is installed, and 'No' otherwise.

### Security Level (10)
* **Security Level**: Select the security level of the house (High, Medium, Low).

### Exterior Condition (11)
* **Exterior Condition**: Identify the exterior condition of the house (e.g., new, old, etc.).
* **Options:** Check 'Yes' if it's true, and 'No' otherwise.

### Exterior Features (12)
* **Exterior Features**: Describe any exterior features of the house (e.g., balcony, pool, etc.).

### Exterior Status (13)
* **Exterior Status**: Determine the status of the house's exterior (Active, Inactive).
* **Options:** Check 'Active' if the house is active, and 'Inactive' otherwise.

### Systems Status (14)
* **Systems Status**: Determine the status of all basic systems and engines (Active, Inactive).
* **Options:** Check 'Active' if the systems are active, and 'Inactive' otherwise.

### Engine Status (15)
* **Engine Status**: Check the status of all engines (Active, Inactive).
* **Options:** Check 'Active' if the engines are active, and 'Inactive' otherwise.

## Tips
* Please fill out the form carefully and accurately to avoid missing critical details.
* If you're unsure about any field, refer to the provided options or ask for help.
* This form is not mandatory, but it is recommended to be filled out for all houses in the collection.
