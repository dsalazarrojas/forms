# Lift Template - Help Guide
## Purpose
This form is used to collect and document essential information for lift operations, including settings, parameters, and templates.

## How To Complete This Form
1. Review the form carefully, making sure you understand what each field represents and how it applies to your work.
2. Fill out the form completely, entering values for each field as required and indicated.
3. Be precise and accurate in your entries, double-checking calculations and data consistency.

## Field-by-Field Explanation
* **Report Forms** (`report_forms_page`, text, optional)
	+ This section is for general reporting information and is not specific to lift operations.
* **Lift Settings** (`lift_settings_page`, time, optional)
	+ This field is for capturing time-related settings for lift operations.
* **Lift Parameters** (`lift_parameters_page`, select_multiple, optional)
	+ This field allows you to select multiple parameters for the lift.
* **Lift Parameters Value** (`lift_parameters_value`, select_one, optional)
	+ This field is for selecting the value associated with the previously selected parameters.
* **Lift Parameters Description** (`lift_parameters_description`, text, optional)
	+ This field is for providing a description for the selected parameters.
* **Lift Parameters Unit** (`lift_parameters_unit`, text, optional)
	+ This field is for specifying the unit of measurement for the selected parameters.
* **Lift Parameters Note** (`lift_parameters_note`, note, optional)
	+ This field is for adding any additional notes about the parameters.
* **Lift Template** (`lift_template_page`, text, optional)
	+ This field is for capturing any additional information about the lift template.
* **Assigned Tool** (`assigned_tool`, text, optional)
	+ This field is for selecting the tool associated with the lift.
* **Assigned Tool Name** (`assigned_tool_name`, text, optional)
	+ This field is for specifying the name of the associated tool.
* **Assigned Tool Version** (`assigned_tool_version`, text, optional)
	+ This field is for specifying the version of the associated tool.

## Tips
- Double-check all calculations and data consistency before submitting the form.
- If you're unsure about any field, please reach out to your supervisor or technical support team for guidance.
