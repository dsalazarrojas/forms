### Stolen Property Report Form - Help Guide
### Purpose

This form is used to report incidents of stolen property to facilitate the recovery and investigation process.

### How To Complete This Form

1.  Start by filling in the required fields:
    *   Stolen Report: Enter a brief description of the incident.
    *   Report Details: Provide additional details about the theft.
    *   Date Stolen: Enter the date the property was stolen.
    *   Time Stolen: Enter the time the property was stolen.
    *   Location Stolen: Enter the location where the property was stolen.
    *   Description of Item Stolen: Provide a detailed description of the stolen item.
    *   Description of Police Response: Describe the police response to the incident.
    *   Police Report Number: Enter the police report number associated with the incident.
    *   Police Officer Name: Enter the name of the police officer who responded to the incident.
    *   Police Officer ID: Enter the ID of the police officer who responded to the incident.
2.  If you have any additional information, you can fill in the optional fields:
    *   Value of Stolen Item: Enter the value of the stolen item if you know it.
    *   Serial Number: Enter the serial number of the stolen item if it has one.
