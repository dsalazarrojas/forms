# Housing Progress Report - Help Guide
## Purpose
This form is used to track the progress of housing construction projects. It is designed to collect information about the project's general details, construction status, site address, construction type, building name, start and end dates, construction status updates, site contacts, and any notes or comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the general details of the project in the "General Info" field.
2. Select the current construction status from the "Construction Status" dropdown menu.
3. Enter the site address in the "Site Address" field.
4. Select the type of construction (Residential, Commercial, or Industrial) in the "Construction Type" dropdown menu.
5. Enter the name of the building in the "Building Name" field.
6. If applicable, enter the start and end dates of the project in the "Start Date" and "End Date" fields, respectively.
7. Enter any updates or status changes in the "Construction Status Updates" field.
8. Select the site contacts from the list in the "Site Contacts" field.
9. Add any notes or comments about the project in the "Notes" field.

## Field-by-Field Explanation
* **General Info** (`general_info`, text, required: false): Enter a brief description of the project.
* **Construction Status** (`construction_status`, select_one, required: false): Select the current status of the project (In Progress, Underway, or Complete).
* **Site Address** (`site_address`, text, required: false): Enter the address of the construction site.
* **Construction Type** (`construction_type`, select_one, required: false): Select the type of construction (Residential, Commercial, or Industrial).
* **Building Name** (`building_name`, text, required: false): Enter the name of the building.
* **Start Date** (`start_date`, date, required: false): Enter the start date of the project, if applicable.
* **End Date** (`end_date`, date, required: false): Enter the end date of the project, if applicable.
* **Construction Status Updates** (`construction_status_updates`, text, required: false): Enter any updates or status changes about the project.
* **Site Contacts** (`site_contacts`, select_multiple, required: false): Select the contacts for the site from the list.
* **Notes** (`notes`, note, required: false): Add any notes or comments about the project.

## Tips
* Make sure to fill out all the required fields, if any.
* Use the "Construction Status" field to report any changes in the project's status.
* Use the "Notes" field to add any important comments or observations about the project.
* If the project has multiple contacts, select all relevant contacts in the "Site Contacts" field.
* Use the "Construction Type" field to indicate the type of construction (e.g., Residential, Commercial, etc.).
