# Recruiting Activity Report Form - Help Guide
## Purpose
This form is for reporting on recruiting activities that have taken place within the week. It is used to document and track recruitments, dial-ins, persons interviewed, and other essential recruitment-related metrics. This report is used by management for monitoring and analyzing recruiting performance.

## How To Complete This Form
1. Fill out this form if you have conducted any recruiting activities during the week that you wish to report on.
2. Review the form carefully and ensure you have filled out all required and optional fields.
3. Submit the completed form as per your organization's submission guidelines.

## Field-by-Field Explanation
* **Weekly Recruitments** (`weekly_recruitments`, number, optional): Record the number of recruitments that took place this week.
* **Recruiting Dials** (`recruiting_dials`, number, optional): Record the number of recruitment dials made this week.
* **Persons Interviewed** (`persons_interviewed`, number, optional): Record the number of persons interviewed this week.
* **Weekly Recruits** (`weekly_recruits`, number, optional): Record the number of recruits acquired this week.
* **Total Recruits** (`total_recruits`, number, optional): Record the cumulative number of recruits acquired up to date.
* **Recruitment Agency** (`recruitment_agency`, text, optional): If applicable, specify the recruitment agency used.
* **Report Comments** (`report_comments`, text, optional): Add any additional comments about the report, such as notable events or challenges faced during the recruiting process.

## Tips
* Make sure to review the form carefully before submitting to ensure all required and optional fields are filled out accurately.
* If you have any questions or concerns about the form, please reach out to your supervisor or support team.
* If you are unsure about any field, refer to this help guide for clarification.
