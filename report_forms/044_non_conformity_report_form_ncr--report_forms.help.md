# Non Conformity Report Form (NCR) - Help Guide
## Purpose
The Non Conformity Report Form (NCR) is designed to collect information about non-conformities that have occurred within a company. This form helps gather details about the issue, including the date and time it occurred, the type and description of the issue, and the steps taken to address it.

## How To Complete This Form
1. Fill out all the required fields.
2. Be as detailed as possible in your answers.
3. If you are unsure about any field, contact the relevant department or team.

## Field-by-Field Explanation
* **Company Name (1)**: Enter the name of the company where the non-conformity occurred.
	+ Type: Text
	+ Required: Required
* **Non Conformity Date (2)**: Enter the date the non-conformity occurred.
	+ Type: Date
	+ Required: Required
* **Non Conformity Time (3)**: Enter the time the non-conformity occurred.
	+ Type: Time
	+ Required: Required
* **Non Conformity Type (4)**: Describe the type of non-conformity that occurred.
	+ Type: Text
	+ Required: Required
* **Non Conformity Description (5)**: Provide a detailed description of the non-conformity.
	+ Type: Text
	+ Required: Required
* **Non Conformity Report Reason (6)**: Explain the reason for reporting the non-conformity.
	+ Type: Text
	+ Required: Required
* **Non Conformity Reported By (7)**: Enter the name of the person reporting the non-conformity.
	+ Type: Text
	+ Required: Required
* **Non Conformity Reported To (8)**: Enter the name of the person or team to whom the non-conformity was reported.
	+ Type: Text
	+ Required: Required
* **Evidence Details (9)**: Provide any supporting evidence or documentation related to the non-conformity.
	+ Type: Text
	+ Required: Required
* **Action Taken (10)**: Describe the steps taken to address the non-conformity.
	+ Type: Text
	+ Required: Required
* **Action Planned (11)**: Describe any planned actions to address the non-conformity.
	+ Type: Text
	+ Required: Required

	+ Type: Date
	+ Required: Required
