# Archived Order Visibility Issue Report - Help Guide
## Purpose

This form is designed to report issues related to the visibility of archived orders. Please use this form to report any difficulties you encounter when trying to access or view archived orders.

## How To Complete This Form

1. Fill out the reporter information section with your name, email address, and phone number.
2. Enter the date and time you discovered the issue.
3. In the issue details section, describe the problem you're experiencing with archived orders.
4. Select the type of issue you're facing from the options provided.
5. Describe the specific problem with archived order visibility.
6. Assess the impact of the issue and select the severity level.
7. Provide information on how many records are affected.
8. If the issue can be reproduced, describe the steps to reproduce it.
9. Specify the browser or system information.
10. Provide your desired resolution for the issue.
11. If time-sensitive, specify when you need the resolution by.

## Field-by-Field Explanation

* **Your Name** (`reporter_name`, text, required): Enter your name as it appears on your official documents.
* **Email Address** (`reporter_email`, email, required): Enter your official email address.
* **Phone Number** (`reporter_phone`, text, required): Enter your official phone number.
* **Department or Team** (`reporter_department`, text, required): If you're part of a department or team, provide the name of it.
* **Report Date** (`report_date`, date, required): Enter the date when you discovered the issue.
* **Time of Issue** (`report_time`, time, optional): Enter the time when you discovered the issue, if known.
* **Order Number** (`order_number`, text, required): Enter the reference ID or order number for the affected order.
* **Customer Name** (`customer_name`, text, optional): If the issue is related to a customer's order, provide their name.
* **Type of Issue** (`issue_type`, select_one, required): Select the type of issue from the provided options.
* **Detailed Issue Description** (`issue_description`, text, required): Describe the specific problem you're experiencing with archived order visibility.
* **Visibility Problem** (`visibility_problem`, select_one, required): Select the type of visibility problem you're experiencing.
* **Severity Level** (`severity_level`, select_one, required): Assess the impact of the issue and select the severity level.
* **Number of Affected Records** (`affected_records`, number, optional): Enter the number of orders affected by the issue.
* **Can the issue be reproduced?** (`reproducible`, select_one, required): Check if you were able to reproduce the issue.
* **Steps to Reproduce Issue** (`steps_to_reproduce`, text, optional): If the issue can be reproduced, describe the steps to reproduce it.
* **Browser or System Information** (`browser_system`, text, optional): Provide browser or system information relevant to the issue.
* **Desired Resolution** (`desired_resolution`, text, optional): Describe the desired resolution for the issue.
* **When is Resolution Needed?** (`urgency_needed_by`, date, optional): If the resolution is time-sensitive, specify the deadline for resolution.

By following this guide, you'll be able to submit your report effectively and help us resolve the issue quickly and efficiently.
