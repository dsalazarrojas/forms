# residential_security_patrol_activity_report_form - Help Guide
## Purpose
This form is used to document and report security incidents that occur during residential security patrols.

## How To Complete This Form

To complete this form, follow these steps:

* Enter the Security Officer ID, which is a unique identifier assigned to each security officer.
* Select the Date Of Incident, which is the date when the security incident occurred.
* Enter the Start Time and End Time of the incident, if applicable.
* Choose the type of incident that occurred (e.g., suspicious activity, crime reported, etc.).
* Provide a brief Description of the incident.
* If a witness was present, enter their name in the Witness field.
* Enter the Officer Notes, which is a space for the security officer to provide any additional information about the incident.
* If the incident was related to a resident's property, select the Residential Status of the affected resident.
* Finally, enter the name of the Patrol Unit that responded to the incident.

## Field-by-Field Explanation
* **Security Officer Id** (1, number, required): Enter the unique ID assigned to you as a security officer.
* **Date Of Incident** (2, date, required): Select the date when the security incident occurred.
* **Start Time** (3, time, optional): If the incident started at a specific time, enter it here.
* **End Time** (4, time, optional): If the incident ended at a specific time, enter it here.
* **Incident Type** (5, select_one, required): Choose the type of incident that occurred (e.g., suspicious activity, crime reported, etc.).
* **Description** (6, text, optional): Provide a brief description of the incident.
* **Witness** (7, text, required): If a witness was present, enter their name here.
* **Officer Notes** (8, text, required): Enter any additional information about the incident.
* **Residential Status** (9, select_one, optional): If the incident was related to a resident's property, select the residential status of the affected resident.
* **Patrol Unit** (10, text, optional): Enter the name of the Patrol Unit that responded to the incident.

## Tips
* Ensure that all required fields are completed accurately and thoroughly.
* Use clear and concise language when entering information in the fields.
* Double-check your answers for accuracy before submitting the form.
* If you are unsure about any of the fields, consult with your supervisor or a colleague for guidance.
