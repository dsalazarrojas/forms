# Real Estate Transaction Summary - Help Guide
## Purpose
The Real Estate Transaction Summary form is designed to collect essential details about a real estate transaction, providing a concise summary of the sale or purchase of a property. This form helps to standardize and document the transaction information in a structured and organized way. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select the transaction status: Choose the current status of the transaction from the available options: Pending, Closed, or Cancelled. 
2. Select the property type: Pick the type of property involved in the transaction, such as Residential, Commercial, or Other. 
3. Enter sale price: Provide the sale price of the property. Please ensure it is a numerical value.
4. Specify sale date: Enter the date of the transaction.
5. Add transaction details: Enter a brief description of the transaction, including any relevant details.
6. Provide agent information: Enter the name and contact details of the agent involved in the transaction.
7. Enter client information: Enter the name and contact details of the client involved in the transaction.

## Field-by-Field Explanation
* **Transaction Status** (transaction_status, select_one, Required): This field determines the current status of the transaction. Select the option that best describes the current state of the transaction.
* **Property Type** (property_type, select_one, Required): This field indicates the type of property involved in the transaction, such as Residential or Commercial.
* **Sale Price** (sale_price, number, Required): Enter the sale price of the property as a numerical value.
* **Sale Date** (sale_date, date, Required): Enter the date of the transaction in the format MM/DD/YY.
* **Agent Name** (agent_name, text, Required): Enter the name of the agent involved in the transaction.
* **Agent License** (agent_license, text, Required): Enter the license number or ID of the agent.
* **Agent Phone** (agent_phone, text, Required): Enter the phone number of the agent.
* **Client Name** (client_name, text, Required): Enter the name of the client involved in the transaction.
* **Client Email** (client_email, email, Required): Enter the email address of the client.

## Tips
* Ensure that all required fields are completed accurately and thoroughly.
* Double-check the transaction status, property type, and sale price for accuracy.
* Use the correct format for the sale date (MM/DD/YY).
* Enter the agent's and client's contact information accurately.
* If you are unsure about any field, refer back to the form's purpose and instructions.
