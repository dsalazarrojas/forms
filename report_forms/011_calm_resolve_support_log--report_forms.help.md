# Calm Resolve Support Log - Help Guide
## Purpose
This form is used to document and track sessions with clients, capturing key information and insights to support coaching and client progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Support Coach Name** in the text field provided.
2. Enter the **Client Name or ID** in the text field provided.
3. Select the **Date of Session** using the date picker or enter it manually.
4. Select the **Time of Session** using the time picker or enter it manually.
5. Choose the **Session Format**, selecting from the available options (Video Call, Phone Call, In-Person, or Chat - Text).
6. Select the **Primary Client Concerns** addressed during the session, choosing from the provided options (Stress Management, Conflict Resolution, Emotional Regulation, Work-Life Balance, Relationship Issues, or Grief and Loss).
7. Enter a **Detailed Session Summary**, summarizing the discussion and outcomes of the session.
8. If applicable, enter the **Strategies and Tools Implemented** to support the client.
9. Enter the **Client Calmness Rating - Pre-Session** and **Client Calmness Rating - Post-Session**, using a scale of 1 to 10.
10. Select whether a **Follow-up Action is Required**, and if so, enter the **Follow-up Task Details**.
11. If applicable, schedule the **Next Session Scheduled Date**.
12. Enter **Internal Coach Reflections**, private notes on client progress.

## Field-by-Field Explanation

* **Support Coach Name**: Enter your name or title as a coach.
* **Client Name or ID**: Enter the client's name or ID.
* **Date of Session**: Enter the date of the session, using the date picker or manual entry.
* **Time of Session**: Enter the time of the session, using the time picker or manual entry.
* **Session Format**: Select the format of the session from the provided options (Video Call, Phone Call, In-Person, or Chat - Text).
* **Primary Client Concerns**: Select the primary concerns addressed during the session, choosing from the provided options.
* **Detailed Session Summary**: Summarize the discussion and outcomes of the session.
* **Strategies and Tools Implemented**: Enter techniques recommended to the client (optional).
* **Client Calmness Rating - Pre-Session**: Rate client calmness level before the session, on a scale of 1 to 10.
* **Client Calmness Rating - Post-Session**: Rate client calmness level after the session, on a scale of 1 to 10.
* **Follow-up Action Required?**: Select whether a follow-up action is required.
* **Follow-up Task Details**: Enter the task details if follow-up action is required (optional).
* **Next Session Scheduled Date**: Schedule the next session date (optional).
* **Internal Coach Reflections**: Enter private notes on client progress.
