# Plant Monitoring Form - Help Guide
## Purpose
The Plant Monitoring Form is designed to collect information about plant monitoring activities for internal record-keeping and analysis purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Plant Monitoring Data" page to input the general information about the plant.
2. On the "Plant Monitoring Data" page, input the date the plant was planted.
3. Enter the name of the plant.
4. Select the plant's goals, if applicable.
5. Input any additional notes about the plant.
6. Review and submit the form.

## Field-by-Field Explanation
- **Plant Monitoring Data** (`plant_monitoring_form_data`, text, optional): This is the main section of the form where you will input the general information about the plant.
- **Date Planted** (`date_planted`, date, optional): Enter the date the plant was planted.
- **Plant Name** (`plant_name`, text, optional): Enter the name of the plant.
- **Goals** (`goals`, select multiple, optional): Select one or more goals that apply to the plant, such as "Yes" or "No".
- **Notes** (`notes`, note, optional): Input any additional notes about the plant.
