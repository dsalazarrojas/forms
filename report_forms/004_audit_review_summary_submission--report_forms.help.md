# Audit Review Summary Submission - Help Guide
## Purpose
This form is for submitting a summary of an audit review, which includes key information about the audit, such as the submission date, audit scope, and findings. It is designed to provide an overview of the audit process, allowing for efficient tracking and analysis of audit results.
## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the submission date in the format MM/DD/YYYY.
2. Select the time period covered by the audit from the options provided.
3. Enter the name of the organization or department that was audited.
4. Specify the areas that were included in the audit.
5. Choose the type of audit conducted.
6. Enter the name of the person conducting the audit.
7. Enter the number of team members involved in the audit.
8. Count the total number of findings identified during the audit.
9. Count the number of critical, major, and minor findings.
10. Assess the overall compliance status of the audited entity.
11. Summarize the main issues identified during the audit.
12. Indicate whether root cause analysis was completed.
13. Count the number of corrective actions recommended.
14. Specify the recommended timeline for addressing findings.
15. Indicate whether management has responded to findings.
16. Determine whether a follow-up audit is recommended.
17. Specify whether supporting documentation is attached.
18. Enter the name and email of the person approving this summary.
## Field-by-Field Explanation

* **Submission Date** (`submission_date`): Enter the date the audit summary was submitted. 
* **Audit Period** (`audit_period`): Select the time period covered by this audit.
* **Audited Entity Name** (`audited_entity`): Enter the name of the organization or department audited.
* **Audit Scope** (`audit_scope`): Specify the areas that were included in the audit.
* **Audit Type** (`audit_type`): Select the type of audit conducted.
* **Lead Auditor Name** (`auditor_name`): Enter the name of the person conducting the audit.
* **Audit Team Size** (`audit_team_size`): Enter the number of team members involved in the audit.
* **Total Number of Findings** (`total_findings`): Count the total number of issues identified during the audit.
* **Critical Findings** (`critical_findings`): Count the number of critical/high-priority findings.
* **Major Findings** (`major_findings`): Count the number of major/medium-priority issues.
* **Minor Findings** (`minor_findings`): Count the number of minor/low-priority issues.
* **Overall Compliance Status** (`compliance_status`): Assess the overall compliance status of the audited entity.
* **Key Findings Summary** (`key_findings_summary`): Summarize the main issues identified during the audit.
* **Root Cause Analysis** (`root_cause_analysis`): Indicate whether root cause analysis was completed.
* **Number of Recommendations** (`recommendations_count`): Count the number of corrective actions recommended.
* **Recommended Implementation Timeline** (`implementation_timeline`): Specify the recommended timeline for addressing findings.
* **Management Response** (`management_response_provided`): Indicate whether management has responded to findings.
* **Follow-Up Audit Recommended** (`followup_audit_needed`): Determine whether a follow-up audit is recommended.
* **Supporting Documentation** (`supporting_documents`): Specify whether audit workpapers and evidence are included.
* **Review Approval Name** (`reviewer_name`): Enter the name of the person approving this summary.
* **Review Approval Email** (`reviewer_email`): Enter the contact email for reviewer.
* **Supporting Documentation Attached** (`supporting_documents`): Specify whether supporting documentation is attached.
