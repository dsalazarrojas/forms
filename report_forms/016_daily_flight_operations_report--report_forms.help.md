# Daily Flight Operations Report - Help Guide
## Purpose
This guide will walk you through completing the Daily Flight Operations Report form, which is used to record and track flight schedules and actual departure/arrival times.

## How To Complete This Form
- Start by filling out the form for the relevant date, using the format `YYYY-MM-DD`.
- Enter the scheduled departure and arrival times for the flight.
- Fill in the actual departure and arrival times, if they differ from the scheduled times.
- Select the current flight status from the dropdown menu (Delayed, On schedule, Cancelled).
- Select the type of flight (Commercial, Private, Charter).
- Enter any notes or reasons for the flight status, if applicable.
- Enter any relevant flight ID number.

## Field-by-Field Explanation
* **Scheduled Departure**: Enter the scheduled departure date and time for the flight.
* **Scheduled Arrival**: Enter the scheduled arrival date and time for the flight.
* **Actual Departure**: Enter the actual departure time, if it differs from the scheduled time.
* **Actual Arrival**: Enter the actual arrival time, if it differs from the scheduled time.
* **Flight Status**: Select the current status of the flight from the dropdown menu (Delayed, On schedule, Cancelled).
* **Flight Type**: Select the type of flight (Commercial, Private, Charter).
* **Flight Status Reason**: Enter any notes or reasons for the flight status, if applicable.
* **Flight ID**: Enter any relevant flight ID number, if applicable.

## Tips
* Ensure that you are reporting accurately and thoroughly for each flight.
* If you are unsure about any field, refer to your flight operations manual or consult with your supervisor.
* If you need to correct any errors or inconsistencies in your previous reports, notify the relevant authorities.
