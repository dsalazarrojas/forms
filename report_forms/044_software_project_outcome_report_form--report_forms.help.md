# Software Project Outcome Report Form - Help Guide
## Purpose
The Software Project Outcome Report Form is used to collect and document project outcome and closeout data for projects that have reached their natural end date.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, optional): Enter the name of the project.
* **Project Manager** (`project_manager`, text, optional): Enter the name of the project manager.
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of the project.
* **Project Status** (`project_status`, select_one, required): Select the current status of the project: Active, Closed, or On Hold.
* **Stakeholder List** (`stakeholder_list`, select_multiple, required): List the stakeholders involved in the project, such as Team Members, External Contractors, Project Sponsor, or Customers.
* **Stakeholder Comments** (`stakeholder_comments`, text, optional): Enter comments from stakeholders.
* **Project Goals** (`project_goals`, text, optional): Enter the project goals and objectives.
* **Project Outcomes** (`project_outcomes`, text, optional): Enter the project outcomes and results.
* **Lessons Learned** (`lessons_learned`, text, optional): Enter lessons learned during the project.
* **Recommendations** (`recommendations`, text, optional): Enter recommendations for future projects.
* **Next Steps** (`next_steps`, text, optional): Enter next steps for future projects.
* **Project Closeout Costs** (`project_closeout_costs`, number, optional): Enter the total costs of the project.
* **Project Closeout Hours** (`project_closeout_hours`, number, optional): Enter the total hours spent on the project.
* **Project Closeout Rating** (`project_closeout_rating`, select_one, required): Select the overall rating of the project: Satisfactory, Unsatisfactory, or Neutral.
* **Stakeholder Uploads** (`stakeholder_uploads`, text, optional): List the stakeholder uploads for the project.
* **Team Member Uploads** (`team_member_uploads`, text, optional): List the team member uploads for the project.
* **Sponsor Uploads** (`sponsor_uploads`, text, optional): List the sponsor uploads for the project.
* **Customer Uploads** (`customer_uploads`, text, optional): List the customer uploads for the project.
* **Project Documents** (`project_documents`, text, optional): List the project documents.
* **Project Files** (`project_files`, text, optional): List the project files.
* **Project Notes** (`project_notes`, text, optional): Enter project notes.
* **Team Comments** (`team_comments`, text, optional): Enter team comments.
* **Project Manager Comments** (`project_manager_comments`, text, optional): Enter project manager comments.
* **Closeout Date** (`closeout_date`, date, optional): Enter the closeout date of the project.

Note: This form is not intended to be a comprehensive project report form. Focus on collecting key information on project outcome and closeout data.
