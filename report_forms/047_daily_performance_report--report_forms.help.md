# Daily Performance Report - Help Guide
## Purpose
The Daily Performance Report form is designed to collect information on an employee's performance, daily activities, and challenges faced on a daily basis. This data will help managers and supervisors evaluate employee performance and identify areas for improvement.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the relevant option for each field, using the provided options or typing your response if necessary.
2. Ensure that all required fields are filled out, as indicated by the "required" label.

## Field-by-Field Explanation

* Label: Employee
* Type: Select One
* Required: Yes
* Explanation: Select the status of the employee, either "Yes" or "No".

* Label: Date
