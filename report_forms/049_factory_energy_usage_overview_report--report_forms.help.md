# Factory Energy Usage Overview Report - Help Guide
## Purpose
The Factory Energy Usage Overview Report is a tool used by factory management to monitor and analyze the energy usage of the factory. This report provides an overview of the factory's energy sources, consumption, and efficiency measures.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the factory name in the "factory_name" field.
2. Enter the factory location in the "location" field.
3. Select the energy sources used by the factory from the "energy_sources" dropdown menu.
4. Enter the energy consumption in the "energy_consumption" field.
5. Mention any efficiency measures taken in the "efficiency_measures" field.
6. Select the date of the report period using the "date" field.
7. Select the time of the report period using the "time" field.

## Field-by-Field Explanation
- **factory_name** (`factory_name`, text, required): Enter the name of the factory for proper identification.
- **location** (`location`, text, required): Enter the location of the factory for accurate reporting.
- **energy_sources** (`energy_sources`, select_multiple, optional): Select the energy sources used by the factory (e.g., electricity, gas, coal, etc.).
- **energy_consumption** (`energy_consumption`, number, optional): Enter the energy consumption of the factory (e.g., megawatt-hours, kilowatt-hours, etc.).
- **efficiency_measures** (`efficiency_measures`, text, optional): Mention any efficiency measures taken by the factory (e.g., energy-efficient lighting, HVAC system upgrades, etc.).
- **date** (`date`, date, optional): Select the date of the report period.
- **time** (`time`, time, optional): Select the time of the report period.
