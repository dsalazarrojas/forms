# Project Closure Report Template - Help Guide
## Purpose
The Project Closure Report Template is a form used to document the status of a project at the end of its lifecycle. It helps track the project's progress, closure reason, and other important details.

## How To Complete This Form
- Fill in the **Project Name** field with the title of the project.
- Select the **Closure Date** field to enter the date when the project was closed.
- Choose the **Closure Status** field to specify whether the project is Active or Inactive.
- Select the **Project Status** field to indicate if the project is Active or Inactive. This field is similar to the **Closure Status** field but provides an additional option for more granular status tracking.
- In the **Reason for Closure** field, provide a note explaining why the project was closed.
- Enter the name of the **Project Manager** responsible for the project.
- Add any relevant comments about the project in the **Comments** field.

## Field-by-Field Explanation
* **Project Name** (Project Name, text, required/optional): The name of the project, e.g., "Marketing Campaign 2023".
* **Closure Date** (closure_date, date, required/optional): The date when the project was closed, e.g., "2023-02-15".
* **Closure Status** (closure_status, select_one, required/optional): A dropdown menu to select whether the project is Active or Inactive.
* **Project Status** (project_status, select_multiple, required/optional): A dropdown menu to select if the project is Active or Inactive, or other statuses if needed.
* **Reason for Closure** (reason_for_closure, note, required/optional): A field for providing a detailed explanation for closing the project.
* **Project Manager** (project_manager, text, required/optional): The name of the person who managed the project.
* **Team Member** (team_member, text, required/optional): The name of the team member responsible for the project.
* **Comments** (comments, text, required/optional): Any additional comments about the project.
