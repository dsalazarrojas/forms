# Incident Report Tracking - Help Guide
## Purpose
The Incident Report Tracking form is used to record and track incidents that affect business operations or processes. This form is intended for personnel who have direct knowledge of the incident and are responsible for reporting it accurately.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of incident that best describes the incident (e.g., Yes, No, Other).
2. Select the severity of the incident (e.g., Yes, No, Other).
3. Choose the status of the incident (e.g., Active, Inactive, Other).

## Field-by-Field Explanation
### **Report Form (1)**
 Report Form: This is the main form where you can enter a detailed description of the incident.

* **Report Form** (text field): Enter a clear and concise description of the incident, including any relevant details and context.

### **Incident Details (2)**
Incident Details: This is a free-form field for any additional notes or comments about the incident.

* **Incident Details** (note field): Enter any additional information or comments that are relevant to the incident.

### **Date Occurred (3)**
Date Occurred: Enter the date when the incident occurred.

* **Date Occurred** (date field): Enter the date in the format MM/DD/YYYY.

### **Time Occurred (4)**
Time Occurred: Enter the time when the incident occurred.

* **Time Occurred** (time field): Enter the time in the format 12:00 AM or 12:00 PM.

### **Location (5)**
Location: Enter the location where the incident occurred.

* **Location** (text field): Enter the specific location where the incident happened.

### **Description (6)**
Description: Enter a detailed description of what happened during the incident.

* **Description** (text field): Enter a clear and concise description of the incident, including any relevant details and context.

### **Incident Type (7, 8)**
Incident Type:
* **Incident Type** (select field): Choose the type of incident from the list (Yes, No, Other).
* **Incident Type Select** (select field): Select all the types of incident that apply (Yes, No, Other).

### **Incident Severity (9, 10)**
Incident Severity:
* **Incident Severity** (select field): Choose the severity of the incident from the list (Yes, No, Other).
* **Incident Severity Select** (select field): Select all the severities of the incident (Yes, No, Other).

### **Incident Status (11, 12)**
Incident Status:
* **Incident Status** (select field): Choose the status of the incident from the list (Active, Inactive, Other).
* **Incident Status Select** (select field): Select all the statuses of the incident (Active, Inactive, Other).

### **Incident Status Select Options (13)**
Incident Status Select Options:
* **Incident Status Select Options** (select field): Choose the status of the incident from the list (Yes, No, Other).

Note: This field is only for selecting options that are not explicitly listed in the other fields.
