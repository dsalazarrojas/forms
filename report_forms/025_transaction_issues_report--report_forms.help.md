# Transaction Issues Report - Help Guide
## Purpose
The Transaction Issues Report form is designed to report any issues or problems related to transactions. This form helps users to document and track issues related to transactions, ensuring that they can be addressed and resolved efficiently. It is an internal tool for customer support teams to identify and resolve transaction-related problems.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the transaction details such as transaction date, amount, and type.
2. Describe the issue or problem you have encountered.
3. Attach any relevant images or supporting documents.
4. Select the customer support team that will handle the issue.
5. Choose the issue priority (low or high).
6. Assign any relevant tags to the issue.
7. Enter any additional comments or information.
8. Enter the customer's email and phone number for contact.
9. Choose the issue status (open or closed).
10. Select the customer support team that resolved the issue.
11. Enter the resolution date and time.
12. Choose the resolution status (open or closed).
13. Enter any issue comments.
14. Attach any relevant issue attachments.
15. Enter the issue ID and subject.
