# library_online_resource_access_report_form - Help Guide
## Purpose

This form is used to report issues with accessing online library resources. Patrons can report problems with accessing specific online resources, and librarians can use the gathered information to resolve these issues.

## How To Complete This Form

To complete this form, follow these steps:

1.  In the "Patron Reported Issues" field, describe the problem you are experiencing with accessing the online resource.
2.  In the "Date of Access Issue" field, enter the date when you first encountered the issue.
3.  If applicable, select all the types of library materials you requested or were trying to access when the issue occurred.
4.  In the "Resource Title" field, enter the title of the resource you were trying to access.
5.  In the "Resource URL" field, enter the URL of the resource you were trying to access.
6.  In the "User Reported Error Message" field, describe the error message you received while trying to access the resource.
7.  If the library has found a solution, select one from the options provided or choose "Other" to describe your own solution.
8.  If applicable, select all the types of library materials that were sourced to resolve the issue.
9.  In the "Librarian Reported Error Message" field, describe any error messages you received from librarians while trying to access the resource.
10. In the "Library Solution Details" field, provide any additional details about the solution the library found to resolve the issue.

## Field-by-Field Explanation

* **Patron Reported Issues**: Describe the problem you are experiencing with accessing the online resource. This is a required field and should be completed thoroughly.
* **Date of Access Issue**: Enter the date when you first encountered the issue. This field is required and should be in the correct date format.
* **Library Materials Requested**: If you were trying to access specific materials, select all that apply. This field is not required but can help librarians better understand the context of the issue.
* **Resource Title**: Enter the title of the resource you were trying to access. This field is required and should be a clear and concise title.
* **Resource URL**: Enter the URL of the resource you were trying to access. This field is not required but can help librarians diagnose the issue.
* **User Reported Error Message**: Describe the error message you received while trying to access the resource. This field is required and should be a clear description of the error.
* **Library Solution**: If the library has found a solution, select one from the options provided. If you know of a better solution, choose "Other" to describe it. This field is not required but can help librarians understand the context of the issue.
* **Library Materials Sourced**: If the library sourced materials to resolve the issue, select all that apply. This field is not required but can help librarians understand the materials used to resolve the issue.
* **Librarian Reported Error Message**: Describe any error messages you received from librarians while trying to access the resource. This field is required and should be a clear description of the error.
* **Library Solution Details**: Provide any additional details about the solution the library found to resolve the issue. This field is not required but can help librarians understand the solution better.

## Tips

* Be as thorough as possible when describing the issue in the "Patron Reported Issues" and "User Reported Error Message" fields.
* Make sure to use the correct date format in the "Date of Access Issue" field.
* If you are not sure about the types of library materials you requested or were trying to access, it's better to err on the side of caution and leave "None" selected.
* If you know of a better solution than what the library has provided, choose "Other" and describe it in the "Library Solution Details" field.
