# Observation And Media Log - Help Guide

## Purpose
The Observation And Media Log form is a tool for users to record and document their observations, including any associated media files. This form is used to capture details such as the date of the observation, the type of media, and any notes or comments related to it.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the **observation date** in the `observation_date` field. This is the date when the observation was made.
2. Select the **media type** from the dropdown menu. This could be an image, video, or audio file.
3. Enter the **media URL** in the `media_url` field. This is the URL where the media file can be found.
4. If needed, add any additional **notes** in the `notes` field. This is a free-text field for any comments or observations.
5. If required, upload any relevant **files** using the `file1` and `file2` fields. These are text fields for uploading file names or descriptions.
6. Choose whether to receive an **email notification** by checking the `email_notification` box. If you choose this option, you will receive an email with the form submission details.
7. Enter your **tracking number** in the `tracking_number` field. This is a field for tracking purposes.
8. Enter your **name** in the `submitted_by` field. This is the name of the person submitting the form.
9. Click the **submit button** to send the form. This will trigger the submission process.
10. Once the form is submitted, you will receive a confirmation message and see the form completion status in the `form_completion` field.

## Field-by-Field Explanation

* **observation_date** (Date): Enter the date when the observation was made.
* **media_type** (Select One: image, video, audio): Choose the type of media associated with the observation.
* **media_url** (Text): Enter the URL where the media file can be found.
* **notes** (Note): Add any additional notes or comments related to the observation.
* **file1** (Text): Upload a file name or description (if applicable).
* **file2** (Text): Upload another file name or description (if applicable).
* **email_notification** (Checkbox): Check this box to receive an email with the form submission details.
* **tracking_number** (Text): Enter a tracking number for the observation.
* **submitted_by** (Text): Enter your name as the person submitting the form.
* **submit** (Text): Click this button to submit the form.
* **form_completion** (Text): This field displays the form completion status.
* **submit_successful** (Note): Displays a note indicating that the submission was successful.
* **submit_unsuccessful** (Note): Displays a note indicating that the submission failed.
* **page 24** (Text): This field is likely a redundant field and can be ignored.
* **Done** (Text): This field is likely a confirmation message.
* **submitted_date** (Date): The date and time of submission.

Note: Some fields are likely redundant or unnecessary and can be ignored or removed.
