# COVID 19 Test Result Reporting Form - Help Guide
## Purpose
This form is used to report COVID-19 test results. It collects information about the test taker's identity, test details, and any related symptoms or isolation status. The form helps track and manage test results, ensuring accurate and up-to-date information for contact tracing and public health monitoring.

## How To Complete This Form

1. Select the correct date for each field where required.
2. Fill in the reporter's details (first name, last name, phone number, email address, and organization name).
3. Specify the type of test performed.
4. Enter the test location (if applicable).
5. Upload a photo or PDF of the test results document (if required).
6. Answer questions about symptoms, isolation, and contact notification status.
7. Verify the truthfulness of the information provided.
8. Date the signature.

## Field-by-Field Explanation
* **Report Date** (1): Date of report, which must be the current date.
* **Who is submitting this report** (2): Select the category of person submitting the report (Employee, Student, Customer or client, etc.).
* **First Name** (3): Legal first name of the person submitting the report.
* **Last Name** (4): Legal last name of the person submitting the report.
* **Date of Birth** (5): Date of birth of the person submitting the report.
* **Phone Number** (6): Contact phone number of the person submitting the report.
* **Email Address** (7): Contact email of the person submitting the report.
* **Organization Name** (8): Name of the organization or school of the person submitting the report.
* **Department or Class** (9): Department or class of the person submitting the report (if applicable).
* **Date of Test** (10): Date the test was performed.
* **Test Result** (11): Select the outcome of the test (Positive, Negative, Inconclusive, Pending).
* **Type of Test** (12): Select the type of test performed (PCR molecular test, Rapid antigen test, etc.).
* **Where was the test performed** (13): Location where the test was performed (if applicable).
* **Testing Facility Name** (14): Name of the lab or clinic where the test was performed (if applicable).
* **Date Results Were Received** (15): Date the test results were received.
* **Are you currently experiencing symptoms** (16): Select the symptom status (No asymptomatic, Yes symptomatic, Symptoms resolved).
* **Which symptoms** (17): Select all symptoms currently being experienced.
* **When did symptoms start** (18): Date when symptoms began (if applicable).
* **Are you currently in isolation** (19): Select the isolation status (Yes at home, Yes at facility, No not isolating, No longer isolating).
* **Isolation Start Date** (20): Date when isolation began (if applicable).
* **Expected Return Date** (21): Date when returning to work or school.
* **Have you notified your close contacts** (22): Select the contact notification status (Yes all notified, Some notified, No not yet, Not applicable).
* **Has your healthcare provider been notified** (23): Select the medical notification status ('True', 'False', I do not have a healthcare provider).
* **Upload Test Result Document** (24): Upload a photo or PDF of the test results document (if required).
* **Additional Comments** (25): Provide any other relevant information.
* **I attest that the information provided is true and accurate** (26): Verify the truthfulness of the information provided (Yes I attest, No I cannot attest).
* **Signature Date** (27): Date the form was signed.
