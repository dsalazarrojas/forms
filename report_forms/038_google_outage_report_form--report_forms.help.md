# google_outage_report_form - Help Guide
## Purpose
The purpose of this form is to report outages on Google services.

## How To Complete This Form
To fill out this form, please follow these steps:

1. Select the appropriate report type from the "report_type" field. This will help us to direct your report to the correct team.
2. Provide a brief description of the outage in the "description" field.
3. Enter the start and end time of the outage in the "start_time" and "end_time" fields.
4. Enter the duration of the outage in the "duration" field.
5. Select the start and end locations of the outage in the "start_location" and "end_location" fields.
6. Provide any relevant notes about the outage in the "notes" field.
