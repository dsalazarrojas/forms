# flu_mask_compliance_form - Help Guide
## Purpose
The flu mask compliance form is designed to track and document patient and employee information for flu mask compliance. This form is used to monitor and report on flu exposure among patients and employees in high-risk environments such as hospitals, clinics, and other healthcare settings.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the `patient_name` field.
2. Select the relevant flu prophets from the `flu_prophets` dropdown menu.
3. Enter the patient's contact information in the `patient_contact_info` field.
4. Enter the employee's ID in the `employee_id` field.
5. Enter the patient's ID in the `patient_id` field.
6. Enter the employee's name in the `employee_name` field.
7. Enter the employee's work location in the `employee_work_location` field.
8. Enter the patient's location in the `patient_location` field.
9. Select the relevant flu exposure options for the patient in the `flu_exposure` dropdown menu.
10. Enter the employee's phone number in the `employee_phone` field.

## Field-by-Field Explanation

* **patient_name**: Enter the patient's name for reference and tracking purposes.
* **flu_prophets**: Select all the relevant flu prophets that apply to the patient's case. This field is a dropdown menu with the following options:
	+ Option 1
	+ Option 2
	+ Option 3
* **patient_contact_info**: Enter the patient's contact information, including address, phone number, and any other relevant details.
* **employee_id**: Enter the employee's ID number for tracking and reference purposes.
* **patient_id**: Enter the patient's ID number for tracking and reference purposes.
* **employee_name**: Enter the employee's name who interacted with the patient.
* **employee_work_location**: Enter the employee's work location for reference and tracking purposes.
* **patient_location**: Enter the patient's location for reference and tracking purposes.
* **flu_exposure**: Select all relevant flu exposure options for the patient, which include:
	+ Option 1
	+ Option 2
	+ Option 3
* **employee_phone**: Enter the employee's phone number for communication and reference purposes.
