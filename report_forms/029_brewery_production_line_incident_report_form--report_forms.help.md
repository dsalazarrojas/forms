# Brewery Production Line Incident Report Form - Help Guide
## Purpose
The Brewery Production Line Incident Report Form is a document used to report and document incidents that occur on a brewery's production line. It helps in identifying and addressing issues, reducing production downtime, and improving overall safety and efficiency.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the report date and time when filling out the form.
2. Provide the incident date and time when the incident occurred.
3. Enter the name of the person reporting the incident.
4. Specify the department or production area affected.
5. Identify the production line number or name.
6. Choose the type of incident that occurred.
7. Describe the incident in detail.
8. Rate the severity level of the incident.
9. Rate the safety impact of the incident.
10. Indicate if there were any injuries reported.
11. If there were injuries, provide details on the persons involved and the extent of their injuries.
12. Check if medical attention was required.
13. If medical attention was required, specify the type of care provided.
14. (Optional) Enter the product or batch affected.
15. Describe the immediate actions taken to address the incident.
16. (Optional) Suggest corrective measures to prevent the incident from recurring.
17. (Optional) Assess the extent of equipment damage.
18. Check if regulatory notification is required.
19. (Optional) Specify follow-up actions required.
20. (Optional) Identify the person responsible for follow-up actions.

## Field-by-Field Explanation

* **Report Date**: The date on which the incident report is being filled out.
	+ Type: Date
	+ Required: Yes
* **Report Time**: The time at which the incident report is being filled out.
	+ Type: Time
	+ Required: Yes
* **Incident Date**: The date on which the incident occurred.
	+ Type: Date
	+ Required: Yes
* **Incident Time**: The time at which the incident occurred.
	+ Type: Time
	+ Required: Yes
* **Reporting Person**: The name of the person making the report.
	+ Type: Text
	+ Required: Yes
* **Department**: The department or production area affected by the incident.
	+ Type: Text
	+ Required: Yes

	+ Type: Text
	+ Required: Yes

	+ Type: Select One
	+ Required: Yes

	+ Type: Text
	+ Required: Yes
* **Suspected Root Cause**: A possible explanation for why the incident occurred.
	+ Type: Text

	+ Type: Select One
	+ Required: Yes
* **Safety Impact**: A rating of the incident's safety impact.
	+ Type: Select One
	+ Required: Yes
* **Injuries Reported**: A report of whether any injuries occurred.
	+ Type: Select One

	+ Type: Text

	+ Type: Text
