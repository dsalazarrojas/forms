# Product Recall Coordination Request Form - Help Guide
## Purpose
The Product Recall Coordination Request Form is designed to collect information for product recall coordination purposes. It's essential to fill out the form accurately and not duplicate it for the same issue to avoid confusion and miscommunication.

## How To Complete This Form
To complete this form, simply follow these steps:

* Fill in the required information for your product and the issue at hand.
* Select the correct recall category and product status from the provided options.
* Enter the production and issue dates if applicable.
* Provide details about the affected units and total units affected.
* Choose the priority level for the recall action.
* Fill in your contact information so that we can reach out to you for further coordination.
* Add any additional comments or issue descriptions if needed.
* Finally, select the assigned tool for the recall action.

## Field-by-Field Explanation

* **Product Recall Request (product_recall_request_form)**: Enter a brief description of the product recall request.
* **Product Id (product_id)**: Enter the product ID number, if known.
* **Product Name (product_name)**: Enter the name of the product.
* **Issue Description (issue_description)**: Describe the issue with the product in as much detail as possible.
* **Recall Category (recall_category)**: Choose the category that best describes the issue:
	+ Recalls: For issues that require a recall.
	+ Product Safety: For issues related to product safety.
	+ Consumer Safety: For issues related to consumer safety.
	+ Quality: For issues related to product quality.
	+ Labeling: For issues related to product labeling.
	+ Packaging: For issues related to product packaging.
	+ Other: For any other issues not listed above.
* **Product Status (product_status)**: Choose the status of the product:
	+ Active: If the product is active on the market.
	+ Discontinued: If the product is no longer being produced or sold.
	+ Out of Production: If the product is no longer in production.
	+ Other: If the product status is different from the above options.
* **Production Date (production_date)**: Enter the production date of the product, if known.
* **Issue Date (issue_date)**: Enter the issue date, if known.
* **Affected Units (affected_units)**: Describe the affected units, if known.
* **Total Units Affected (total_units_affected)**: If not all units are affected, enter the quantity affected, if known.
* **Priority Level (priority_level)**: Choose the priority level for the recall action:
	+ High: For critical issues that require immediate attention.
	+ Medium: For less critical issues that require attention within a few days.
	+ Low: For non-urgent issues that can be addressed later.
	+ Other: For any other priority level not listed above.
* **Contact First Name (contact_first_name)**: Enter the first name of the contact person.
* **Contact Last Name (contact_last_name)**: Enter the last name of the contact person.
* **Contact Email (contact_email)**: Enter the email of the contact person.
* **Contact Phone (contact_phone)**: Enter the phone number of the contact person.
* **Contact Company (contact_company)**: Enter the name of the contact company.
* **Contact Job Title (contact_job_title)**: Enter the job title of the contact person.
* **Contact Address (contact_address)**: Enter the address of the contact person.
* **Contact City (contact_city)**: Enter the city of the contact person.
* **Contact State (contact_state)**: Enter the state of the contact person.
* **Contact Postal Code (contact_postal_code)**: Enter the postal code of the contact person.
* **Additional Issue Description (issue_description_2)**: Provide any additional details about the issue.
* **Additional Comments (additional_comments)**: Add any additional comments about the issue.
* **Assigned Tool (assigned_tool)**: Choose the assigned tool for the recall action:
	+ chatjimmy: For recall actions assigned to chatjimmy.
	+ Other: For any other tool not listed above.

## Tips
* Be accurate and complete when filling out the form.
* Do not duplicate the form for the same issue.
* Ensure that the contact information is correct to allow for efficient recall coordination.
