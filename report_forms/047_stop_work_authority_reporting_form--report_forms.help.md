# Stop Work Authority Reporting Form - Help Guide
## Purpose
The Stop Work Authority Reporting Form is used to report a project stop work authority, which is a critical process for project management. This form collects essential information to ensure the project is properly managed and resolved.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the project status and ensure that you are not duplicating a previously submitted report.
2. Fill out the form accurately and thoroughly, taking into account all necessary fields.
3. Ensure you provide enough details for the project manager to understand and resolve the issue properly.

## Field-by-Field Explanation

* **Project Name**: Enter the name of the project being reported. This is a required field.
* **Project Status**: Select the current status of the project from the options provided. This helps the project manager understand the project's current state. (Required)
* **Project Description**: Provide a brief description of the project, including any relevant details. This field is optional but helps the project manager understand the project context.
* **Stop Reason**: Enter the reason for the project stop work authority. This field is optional but helps the project manager understand the reason for the stop.
* **Problem Details**: If there are any issues or problems with the project, provide a detailed description. This field is optional but helps the project manager understand the problem.
* **Project ID**: Enter the project ID number if applicable. This field is optional.
* **Stop Date**: Enter the date when the project was stopped. This field is optional.
* **Assigned User**: Enter the user assigned to the project. This field is optional.
* **Stop Time**: Enter the time when the project was stopped. This field is optional.
* **Comments**: Provide any additional comments or explanations for the project stop work authority. This field is optional.
* **Email Address**: Enter the email address for the project manager or relevant contact. This field is optional.
* **Phone Number**: Enter the phone number for the project manager or relevant contact. This field is optional.
* **Project Manager**: Enter the project manager's name. This field is optional.
* **Reporting User**: Enter the name of the user submitting the report. This field is optional.
* **Reporting Date**: Enter the date when the report is submitted. This field is optional.
* **Reporting Time**: Enter the time when the report is submitted. This field is optional.
* **Project Manager Email**: Enter the project manager's email address. This field is optional.
* **Project Manager Phone**: Enter the project manager's phone number. This field is optional.
* **Company Name**: Enter the company name related to the project. This field is optional.
* **Company Address**: Enter the company address related to the project. This field is optional.
* **Company Phone**: Enter the company phone number related to the project. This field is optional.
* **Company Email**: Enter the company email address related to the project. This field is optional.
* **Project Status ID**: Select the status of the project from the options provided. This field is optional.
* **Assigned Tool**: Select the tool assigned to the project from the options provided. This field is required.
* **Comments**: Provide any additional comments or explanations for the project stop work authority. This field is optional.

## Tips
Please ensure that all fields are filled out accurately and thoroughly to avoid delays in processing your request. Review each field carefully and ensure that you are not duplicating a previously submitted report. If you have any questions or concerns, please contact the project manager or relevant contact.
