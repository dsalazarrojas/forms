# Soap Dispenser Maintenance Report - Help Guide

## Purpose

The Soap Dispenser Maintenance Report form is used to report the maintenance status of soap dispensers. This form is used to track issues such as soap levels, water levels, and other conditions that require maintenance.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure that you have the correct permissions and roles to access this form.
2. Enter the location information for the soap dispenser, including the Facility ID, Facility Name, and Facility Location.
3. Describe the current condition of the soap dispenser, including any issues or concerns.
4. Select the maintenance activity that has been completed, such as soap dispenser cleaned or replaced.
5. Enter the current soap level and water level for the dispenser.
6. Add any additional location notes about the soap dispenser.
7. Submit the form once you have completed all required fields.

## Field-by-Field Explanation

* **Location Info**: Enter the Facility ID, Facility Name, and Facility Location of the soap dispenser that requires maintenance.
	+ Required: No
	+ Type: Text
	+ Example: 1234, Soap Dispenser Room, Room 101
* **Dispenser Condition**: Describe the current condition of the soap dispenser.
	+ Required: No
	+ Type: Text
	+ Example: Low soap level or Out of order
* **Maintenance Activity**: Select the maintenance activity that has been completed for the soap dispenser.
	+ Required: No
	+ Type: Select Multiple
	+ Example: Soap Dispenser Cleaned, Replaced
* **Soap Level**: Enter the current soap level for the soap dispenser.
	+ Required: No
	+ Type: Number
	+ Example: 50, 100
* **Water Level**: Enter the current water level for the soap dispenser.
	+ Required: No
	+ Type: Number
	+ Example: 50, 100
* **Location Notes**: Enter any additional notes about the location of the soap dispenser.
	+ Required: No
	+ Type: Text
	+ Example: Soap dispenser is located near the bathroom.
* **Facility ID**: Enter the Facility ID for the soap dispenser location.
	+ Required: No
	+ Type: Text
	+ Example: 1234
* **Facility Name**: Enter the Facility Name for the soap dispenser location.
	+ Required: No
	+ Type: Text
	+ Example: Soap Dispenser Room
* **Facility Location**: Enter the Facility Location for the soap dispenser location.
	+ Required: No
	+ Type: Text
	+ Example: Room 101

## Tips

* Please ensure that you have the correct permissions and roles to access this form.
* Only report on soap dispensers that are in urgent need of maintenance.
* Ensure that you enter the correct Facility ID, Facility Name, and Facility Location for the soap dispenser.
* Please submit the form once you have completed all required fields.
