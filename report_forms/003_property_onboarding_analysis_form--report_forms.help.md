# Property Onboarding Analysis Form - Help Guide
## Purpose
The Property Onboarding Analysis Form is a tool used to gather information about a property, including its address, type, status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you have all the necessary information about the property.
2. Fill out the form with accurate and complete information.
3. Ensure that you do not enter duplicate information.
4. If you are unsure about any of the fields, please reach out to the relevant authorities for clarification.

## Field-by-Field Explanation

* **Address Info** (`address_info`, text, required): Enter the property's street address, city, state, and zip code.
* **Property Type** (`property_type`, select_one, required): Select the type of property (Residential, Commercial, or Other).
* **Property Status** (`property_status`, select_one, required): Select the current status of the property (Active, Inactive, or Unknown).
* **Property Address** (`property_address`, text, required): Enter the property's address.
* **Property Size** (`property_size`, number, required): Enter the property's size (in square feet or other units).
* **Rentable Area** (`rentable_area`, number, required): Enter the rentable area (in square feet or other units).
* **Property Use** (`property_use`, select_one, required): Select the intended use of the property (Residential, Commercial, or Other).
* **Property Location** (`property_location`, text, required): Enter the property's location.
* **Property Image** (`property_image`, text, optional): Enter a reference to the property's image (if available).
* **Property Documents** (`property_documents`, text, optional): Enter a reference to the property's documents (if available).
* **Property Notes** (`property_notes`, note, optional): Enter any additional notes about the property.
* **Property Inspection** (`property_inspection`, select_one, required): Select whether a property inspection is required (Required, Not Required, or Unknown).
* **Property Owner** (`property_owner`, text, optional): Enter the property's owner's name and contact information.
* **Property Agent** (`property_agent`, text, optional): Enter the property agent's name and contact information.
* **Property Manager** (`property_manager`, text, optional): Enter the property manager's name and contact information.
* **Property Maintenance** (`property_maintenance`, text, optional): Enter information about the property's maintenance requirements.
* **Property Parking** (`property_parking`, text, optional): Enter information about the property's parking facilities.
* **Property Elevator** (`property_elevator`, text, optional): Enter information about the property's elevator (if available).
* **Elevator Count** (`elevator_count`, number, optional): Enter the number of elevators available.
* **Property Security** (`property_security`, text, optional): Enter information about the property's security features.
* **Property Fire Safety** (`property_fire_safety`, text, optional): Enter information about the property's fire safety features.
* **Property Electricity** (`property_electricity`, text, optional): Enter information about the property's electricity features.
* **Property Water** (`property_water`, text, optional): Enter information about the property's water features.
* **Property Sewerage** (`property_sewerage`, text, optional): Enter information about the property's sewerage features.
* **Property Spray** (`property_spray`, text, optional): Enter information about the property's spray features.

Note: Some fields are optional, but ensure that you have all the necessary information before submitting. If you are unsure about any of the fields, please reach out to the relevant authorities for clarification.
