# Schimmas Cleaning Incident And Improvement Report - Help Guide
## Purpose
This form is used to report and document cleaning incidents, including root causes, non-conformances and continual improvements.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill out the form completely, making sure to provide accurate information for each field.
*   Review each field carefully to ensure that you are providing the correct information.
*   Take your time and fill out the form in sections to ensure that you provide clear and accurate information.

## Field-by-Field Explanation
### 1. incident_date (Date)
*   **incident_date** (`incident_date`, `date`, false):
    The date on which the incident occurred.
    Provide the exact date in YYYY-MM-DD format.

### 2. incident_location (Text)
*   **incident_location** (`incident_location`, `text`, false):
    The location where the incident occurred.
    Enter the location where the incident took place.

### 3. incident_description (Note)
*   **incident_description** (`incident_description`, `note`, false):
    A brief description of the incident.
    Provide a clear and concise description of what happened.

### 4. root_cause (Select One)
*   **root_cause** (`root_cause`, `select_one`, false):
    Was the incident caused by a root cause (e.g. lack of training, equipment failure, etc.)?
    Select 'Yes' if the incident was caused by a root cause.

### 5. non_conformances (Select Multiple)
*   **non_conformances** (`non_conformances`, `select_multiple`, false):
    Were there any non-conformances (e.g. non-compliance with standard procedures, etc.)?
    Select 'Yes' if there were non-conformances.

### 6. continual_improvement (Select One)
*   **continual_improvement** (`continual_improvement`, `select_one`, false):
    Is this an opportunity for continual improvement?
    Select 'Yes' if this incident provides an opportunity for improvement.

### 7. corrective_actions (Text)
*   **corrective_actions** (`corrective_actions`, `text`, false):
    What corrective actions were taken as a result of this incident?
    Enter the corrective actions that were taken.

### 8. preventive_actions (Text)
*   **preventive_actions** (`preventive_actions`, `text`, false):
    What preventive actions can be taken to prevent this incident from happening again?
    Enter the preventive actions that can be taken.

### 9. review_status (Select One)
*   **review_status** (`review_status`, `select_one`, false):
    What is the current status of the review process?
    Select 'Active' if the review process is active, or 'Inactive' if it is inactive.

### 10. reviewer (Text)
*   **reviewer** (`reviewer`, `text`, false):
    The person conducting the review.
    Enter the person's name or title performing the review.
