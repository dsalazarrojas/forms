# Field Report Form Template - Help Guide
## Purpose
The Field Report Form Template is used to document and communicate observations, issues, and actions taken on-site.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Project Manager's name in the **Project Manager Name** field.
2. Enter the date of the inspection in the **Date of Inspection** field.
3. Provide a brief description of the location in the **Location Description** field.
4. Indicate whether any issues were observed in the **Observed Issues** field. Select all applicable options that apply.
5. If issues were observed, describe them in the **Observed Issues Options** field.
6. Enter any relevant on-site observations in the **On Site Observation** field.
7. Describe the action taken in response to any issues in the **Action Taken** field.
8. Outline the next steps to be taken in the **Next Steps** field.
9. Enter your signature in the **Signature** field.
10. Add any additional notes or comments in the **Notes** field.
11. If applicable, enter the tool assigned for the project in the **Assigned Tool** field.
12. Enter the project ID number in the **Project ID** field.

## Field-by-Field Explanation
* **Project Manager Name** (Text): Enter the name of the project manager in charge of the project.
* **Date of Inspection** (Date): Enter the date of the site inspection.
* **Location Description** (Text): Provide a brief description of the location being inspected.
* **Observed Issues** (Select Multiple):
	+ **Yes**: Indicate if any issues were observed during the inspection.
	+ **No**: Select this option if no issues were observed.
* **Observed Issues Options** (Select Multiple): Select all applicable options that describe the observed issues.
* **On Site Observation** (Text): Enter any relevant on-site observations.
* **Action Taken** (Text): Describe the action taken in response to any issues.
* **Next Steps** (Text): Outline the next steps to be taken in response to any issues.
* **Signature** (Text): Enter your signature to validate the report.
* **Notes** (Text): Add any additional notes or comments.
* **Assigned Tool** (Text): If applicable, enter the tool assigned for the project.
* **Project ID** (Text): Enter the project ID number.
