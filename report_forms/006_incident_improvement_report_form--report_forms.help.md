# Incident Improvement Report Form - Help Guide
## Purpose
The Incident Improvement Report Form is used to document and track incidents that have occurred in the workplace. This form helps to identify areas of improvement and facilitate the review process.

## How To Complete This Form
1. Fill out the form with as much detail as possible.
2. Make sure to include all required fields.
3. Review the form for accuracy before submitting.

## Field-by-Field Explanation
- **Form ID** (`form_id`): An optional unique identifier for the form. Please do not fill this out unless you have been instructed to do so.
- **Incident Title** (`incident_title`): A brief title of the incident. This should be a concise and descriptive title that summarizes the incident.
- **Incident Description** (`incident_description`): A detailed description of the incident, including what happened and how it occurred.
- **Incident Date** (`incident_date`): The date of the incident.
- **Incident Time** (`incident_time`): The time of the incident.
- **Root Cause** (`root_cause`): A brief explanation of the root cause of the incident.
- **Corrective Action** (`corrective_action`): A description of any actions taken to address the incident.
- **Review Status** (`review_status`): The current status of the review process. You can select from "Approved", "Not approved", or "Not Reviewed".
- **Category** (`category`): Select a category that describes the incident, such as "category1", "category2", or "category3". You can also select "category_other" if none of the above options apply.
- **Category Other** (`category_other`): If you selected "category_other" above, please provide a brief description of the category.
- **Location** (`incident_location`): The location where the incident occurred.
- **Reviewers** (`reviewers`): A list of individuals who have reviewed this incident. Select from "User1", "User2", or "User3".
- **Review Date** (`review_date`): The date of the review.
- **Review Time** (`review_time`): The time of the review.
- **Review Comments** (`review_comments`): Any comments made during the review process.
- **Review Status** (`review_status`): The status of the review process. This field is not the same as the "Review Status" field above. 
- **Review Notes** (`review_notes`): Any additional notes from the review process.
- **Reviewers 2** (`reviewers_2`): A list of individuals who have reviewed this incident. Select from "User1", "User2", or "User3".
- **Form ID 2** (`form_id_2`): An optional unique identifier for the form. Please do not fill this out unless you have been instructed to do so.
- **Category 2** (`category_2`): A list of categories that describe the incident.
- **Form Data** (`form_data`): An optional field for additional data. Please do not fill this out unless you have been instructed to do so.

## Tips
- Make sure to review the form carefully before submitting.
- If you are unsure about any field, please contact your supervisor for guidance.
- If you have any further questions or concerns, please don't hesitate to contact us.
