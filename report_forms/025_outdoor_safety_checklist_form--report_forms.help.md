# Outdoor Safety Checklist Form - Help Guide
## Purpose
This form is designed to help users identify potential hazards and risks associated with outdoor activities or projects. It is used to gather data on hazards and risks that need to be addressed for a safe outdoor environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the outdoor activity or project being assessed.
2. Identify any potential hazards or natural hazards that may be present.
3. Select the hazards you have identified.
4. Identify any risks associated with the potential hazards.
5. Select the risks you have identified.
6. Record any safety measures taken to mitigate or address the identified hazards and risks.
7. Select the safety measures taken.

## Field-by-Field Explanation
* **Hazards identified** (`hazards identified`, select_multiple, required: false):
	+ Select all potential hazards or natural hazards that may be present in the outdoor environment.
	+ Use the available options to choose from a list of common hazards.
* **Risks identified** (`risks identified`, select_multiple, required: false):
	+ Select all potential risks associated with the identified hazards.
	+ Use the available options to choose from a list of common risks.
* **Safety measures taken** (`safety measures taken`, select_multiple, required: false):
	+ Record all safety measures taken to mitigate or address the identified hazards and risks.
	+ Use the available options to choose from a list of common safety measures.
* **Section** (`section`, text, required: false):
	+ This field is not currently used in the form. However, it's possible that it may be used in future development.
* **Title**:
	+ This field is not currently used in the form.
* **Other** (available in "hazards identified", "risks identified", and "safety measures taken", select_multiple, required: false):
	+ Use this option to select any other hazards, risks, or safety measures not listed in the available options.
	+ This option is used when none of the other available options match your situation.
* **Natural hazard** (available in "hazards identified" and "risks identified", select_multiple, required: false):
	+ Use this option to select any natural hazards or risks.
* **Other** (available in "safety measures taken", select_multiple, required: false):
	+ Use this option to select any other safety measures not listed.
