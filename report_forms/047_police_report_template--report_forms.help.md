# Police Report Template - Help Guide
## Purpose
This form is designed to collect information about a police report in a structured and organized manner. It captures details about the incident, including the time it occurred, a description of the crime, and the suspect's name, if known.

## How To Complete This Form

1. **Fill out the form in its entirety**, making sure to provide accurate and detailed information about the incident.
2. **Review and correct your responses** before submitting the form.
3. **Submit the form** once complete.

## Field-by-Field Explanation

### Crime Description (Page 1)
* **Crime Description**: This field is where you describe the incident, including the type of crime that occurred, and any relevant details. Please provide a clear and concise description of what happened.

### Incident Time (Page 1)
* **Incident Time**: This field collects the date and time the incident occurred. Please use the date format: `YYYY-MM-DD HH:MM:SS` to ensure accurate timestamping.

### Suspect Name (Page 1)
* **Suspect Name**: If the suspect's name is known, please enter their full name. If not, leave this field blank.

## Tips
* Be as detailed as possible when describing the incident.
* Double-check your responses for accuracy before submitting the form.
* If you have any questions or concerns, please contact [Contact: form@gic.mx](mailto:form@gic.mx).
