# Repairs Report - Help Guide
## Purpose
The Repairs Report form is designed to record and track site repair activities, providing a centralized platform for site managers, engineers, and supervisors to report and update site repair information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields marked with an asterisk (\*).
2. Enter the Site Repair Date in the date field (Field 1).
3. Provide a brief description of the repair activity in the Site Repair Description field (Field 2).
4. Select the Site Repair Status from the available options in the Site Repair Status field (Field 4).
5. If applicable, choose the Site Repair Location, Site Repair Type, Site Repair Priority, and Site Repair Responsible Party from their respective fields (Fields 8, 9, 11, and 15).
6. If applicable, enter the Site Repair Cost Estimate and Actual Cost in the Site Repair Cost Estimate and Actual Cost fields (Fields 12 and 13).
7. Select the Site Repair Completion Status from the available options in the Site Repair Completion Status field (Field 15).
8. If necessary, provide Comments on the Site Repair activity in the Comments field (Field 22).
9. Enter the Submitted By and Submitted Date for each Site Repair activity in the respective fields (Fields 16, 17, 23, and 24).
10. Review and submit the form.

## Field-by-Field Explanation

* **Site Repair Date** (Field 1): Enter the date of the site repair activity.
* **Site Repair Description** (Field 2): Provide a brief description of the repair activity.
* **Site Repair Cost** (Field 3): Enter the estimated cost of the repair activity.
* **Site Repair Status** (Field 4): Select the current status of the repair activity from the available options.
* **Assigned Engineer** (Field 5): Indicate whether an engineer is assigned to the repair activity.
* **Assigned Supervisor** (Field 6): Indicate whether a supervisor is assigned to the repair activity.
* **Site Repair Location** (Field 8): Select the location(s) affected by the repair activity.
* **Site Repair Type** (Field 9): Select the type of repair activity.
* **Site Repair Priority** (Field 10): Indicate whether the repair activity has priority status.
* **Site Repair Responsible Party** (Field 11): Indicate whether the repair activity is the responsible party's.
* **Site Repair Cost Estimate** (Field 12): Enter the estimated cost of the repair activity.
* **Site Repair Actual Cost** (Field 13): Enter the actual cost of the repair activity.
* **Site Repair Completion Date** (Field 14): Enter the completion date of the repair activity.
* **Site Repair Completion Status** (Field 15): Select the completion status of the repair activity from the available options.
* **Submitted By** (Field 16): Indicate who submitted the repair activity report.
* **Submitted Date** (Field 17): Enter the date the report was submitted.
* **Site Repair Status 1** (Field 18): Select the status of the repair activity from the available options.
* **Site Repair Status 2** (Field 19): Select the status of the repair activity from the available options.
* **Site Repair Status 3** (Field 20): Select the status of the repair activity from the available options.
* **Site Repair Status 4** (Field 21): Select the status of the repair activity from the available options.
* **Comments** (Field 22): Provide additional comments on the repair activity.
* **Submitted By 1** (Field 23): Indicate whether a report was submitted for the repair activity.
* **Submitted Date 1** (Field 24): Enter the date the report was submitted.
* **Submitted Date 2** (Field 25): Enter the date the report was submitted.
