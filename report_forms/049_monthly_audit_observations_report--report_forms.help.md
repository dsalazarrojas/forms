# Monthly Audit Observations Report - Help Guide

## Purpose
The Monthly Audit Observations Report form is used to record and document audit observations, findings, and follow-up actions during the audit process.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the month in which the audit took place.
2. Enter the year of the audit.
3. Describe the department or area audited.
4. Provide a detailed description of the findings made during the audit.
5. List any action items that need to be addressed.
6. Specify the date and time for the next action item review.
7. Specify the time of day for the next action item review.
8. Choose the follow-up status (Active or Inactive) for the next action item review.
9. Provide any additional notes on the next follow-up review.

## Field-by-Field Explanation

* **Month** (`month`, `select_one`): Select the month in which the audit took place.
* **Year** (`year`, `number`): Enter the year of the audit.
* **Department** (`department`, `text`): Describe the department or area audited.
* **Findings** (`findings`, `text`): Provide a detailed description of the findings made during the audit.
* **Actions Items** (`action_items`, `text`): List any action items that need to be addressed.
* **Next Action Date** (`next_action_date`, `date`): Specify the date for the next action item review.
* **Next Action Time** (`next_action_time`, `time`): Specify the time of day for the next action item review.
* **Follow-up Status** (`follow_up_status`, `select_one`): Choose the follow-up status (Active or Inactive) for the next action item review.
* **Follow-up Notes** (`follow_up_notes`, `text`): Provide any additional notes on the next follow-up review.
* **Next Follow-up Date** (`next_follow_up_date`, `date`): Specify the date for the next follow-up review.
* **Next Follow-up Time** (`next_follow_up_time`, `time`): Specify the time of day for the next follow-up review.
