# Manufacturing Daily Production Submission Form - Help Guide

## Purpose
The purpose of this form is to collect daily production data from the manufacturing floor. Please use it to report your production activities, quantity, and status of goods, as well as any other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Select the correct options for each field from the provided lists.
3. Review your answers for completeness and consistency.
4. Submit the form to ensure that your production data is recorded.

## Field-by-Field Explanation
### 1. Product Name (`product_name`): Text
Enter the name of the product you are producing.

### 2. Manufacturing Process (`manufacturing_process`): Text
Describe the production process used for the current production batch.

### 3. Total Production Quantity (`production_quantity`): Number
Enter the total number of units produced during the current production shift.

### 4. Next 3 Days' Production Quantity (`next_three_days`): Select Multiple
Select the expected production quantity for the next 3 days.

### 5. Production Shift (`production_shift`): Select One
Choose the shift during which the production occurred (Morning, Afternoon, or Evening).

### 6. Production Location (`production_location`): Select One
Select the location where the production took place (Plant 1, Plant 2, or Remote Production).

### 7. Supervisor Name (`supervisor_name`): Text
Enter the name of the supervisor responsible for the production.

### 8. Machine Used (`machine_used`): Select One
Choose the machine used for the production (Machine A, Machine B, or Manual Production).

### 9. Maintenance Schedule (`maintenance_schedule`): Date
Enter the date of the last maintenance schedule for the machine used.

### 10. Quality Control Process (`quality_control_process`): Select One
Select the quality control process used (Visual Inspection, Sampling, or 100% Inspection).

### 11. Production Status (`production_status`): Select One
Choose the current production status (In Progress, Completed, or Delayed).

### 12. Defects Detected (`defects_detected`): Number
Enter the number of defects detected during the production.

### 13. Reason for Delay (`reason_for_delay`): Text
Optional field for entering the reason behind any production delays.

### 14. Units Produced (`units_produced`): Number
Enter the total number of units produced during the current production shift.

### 15. Production Cycle Time (`production_cycle_time`): Number
Enter the time spent on the production cycle.

### 16. Quality of Goods (`quality_of_goods`): Select One
Select the quality of the produced goods (Acceptable, Defective, or Scrap).

### 17. Units Reworked (`units_reworked`): Number
Enter the number of units reworked during the production cycle.

### 18. Special Instructions (`special_instructions`): Checkbox
Check the boxes for any special instructions applied during the production.

### 19. Production Shift Start Time (`production_shift_start_time`): Time
Enter the start time of the production shift.

### 20. Production Shift End Time (`production_shift_end_time`): Time
Enter the end time of the production shift.

### 21. Production Duration (`production_duration`): Date
Enter the duration of the production shift.

### 22. Production Date (`production_date`): Date
Enter the date of the production.

### 23. Production Shift 2 (`production_shift_2`): Select One
Choose the second production shift type (Morning, Afternoon, or Evening).

### 24. Production Shift Type (`production_shift_type`): Select One
Select the type of production shift (Single, Double, or Triple).
