# Time Clock Exception Form - Help Guide
## Purpose

The Time Clock Exception Form is designed to record exceptions to the normal time clock schedule for employees. This form allows users to report any deviations from their usual work hours, providing a clear and concise way to document these exceptions.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Start Time field to specify the time at which the exception began.
2. Enter the End Time field to specify the time at which the exception ended.
3. Enter the Exception Date field to specify the date on which the exception occurred.

## Field-by-Field Explanation

* **Start Time** (`start_time`, time, false): The start time of the exception. If you have multiple exceptions, you can enter the start time of the first exception.
* **End Time** (`end_time`, time, false): The end time of the exception. If you have multiple exceptions, you can enter the end time of the last exception.
* **Exception Date** (`exception_date`, date, false): The date on which the exception occurred.
