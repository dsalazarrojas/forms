# Waffle Redemption Report - Help Guide

## Purpose
The Waffle Redemption Report is a form used to document the redemption of waffles. It is intended to collect information about customers, waffles, and redemption details. This report is crucial for tracking and managing waffle redemptions.

## How To Complete This Form
1. Start by ensuring you have all the necessary information about the customer, waffle, and redemption details.
2. Fill out the form sections in the following order:
   a. Customer Info: Provide basic customer information such as name and contact details.
   b. Waffle Information: Select the status of the waffle (True, False, or Other).
   c. Waffle Code: Enter the waffle code for the redeemed waffle.
   d. Date of Redemption: Enter the date of the waffle redemption.
   e. Total Redemptions: Enter the total number of waffles redeemed.
   f. Redemption Value: Enter the value of the redeemed waffle.
   g. Comments: Add any additional comments about the waffle redemption.
   h. Submission Status: Select the status of the submission (Draft, Published, or Deleted).
   i. Submission Date: (Optional) Enter the date of submission.
   j. Form ID: Enter a unique identifier for the form (if required).
   k. Submission Comments: Add any additional comments about the submission.

## Field-by-Field Explanation
* **Customer Info** (`customer_info`, text, required/optional): Enter the customer's basic information such as name and contact details.
* **Waffle Information** (`waffle_info`, select_one, required): Select the status of the waffle (True, False, or Other).
* **Waffle Code** (`waffle_code`, text, required): Enter the waffle code for the redeemed waffle.
* **Date of Redemption** (`date_of_redemption`, date, required/optional): Enter the date of the waffle redemption.
* **Total Redemptions** (`total_redemptions`, number, required): Enter the total number of waffles redeemed.
* **Redemption Value** (`redemption_value`, number, required): Enter the value of the redeemed waffle.
* **Comments** (`comments`, note, required/optional): Add any additional comments about the waffle redemption.
* **Submission Status** (`submission_status`, select_one, required): Select the status of the submission (Draft, Published, or Deleted).
* **Submission Date** (`submission_date`, date, required/optional): Enter the date of submission.
* **Form ID** (`form_id`, text, required/optional): Enter a unique identifier for the form (if required).
* **Submission Comments** (`submission_comments`, note, required/optional): Add any additional comments about the submission.
