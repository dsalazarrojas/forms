# Equipment Heat Monitoring Report - Help Guide
## Purpose
The Equipment Heat Monitoring Report form is used by maintenance staff to monitor equipment temperature readings and report any issues that may be causing problems with the equipment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the equipment name in the **equipment name** field, which is used to identify the specific piece of equipment being monitored.
2. Enter the current **temperature reading** for the equipment, which is used to track changes in temperature over time.
3. If there are any issues or problems with the equipment, enter a brief **issue description** in the field provided. This helps maintenance staff understand the root cause of the issue.
4. If you have any supporting documentation or evidence that may help maintenance staff diagnose the issue, you can **upload evidence** in the field provided.

## Field-by-Field Explanation
- **Equipment name** (equipment_name, text, optional): Enter the name of the equipment being monitored.
- **Temperature reading** (temperature_reading, number, optional): Enter the current temperature reading for the equipment.
- **Issue description** (issue_description, text, optional): Enter a brief description of any issues or problems with the equipment.
- **Upload evidence** (upload_evidence, text, optional): Upload any supporting documentation or evidence that may help maintenance staff diagnose the issue.
