# Eco Program Outcome Report Form - Help Guide
## Purpose
The Eco Program Outcome Report Form is used to document and track the progress and outcomes of the Eco Program. It is a crucial tool for program participants, administrators, and stakeholders to understand the effectiveness and areas of improvement of the program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a title for the report in the "Form Title" field.
2. Select the program you are reporting on using the "Program ID" field.
3. For each outcome, select the relevant option from the provided list and provide a brief description in the "Outcome <Number> Description" field.
4. Provide supporting evidence for each outcome in the "Outcome <Number> Evidence" field.
5. Enter any challenges you faced while working on the program in the "Challenges" field.
6. Enter the current date and time in the "Form Date" field.
7. Enter the current time in the "Form Time" field (optional).
8. Enter your contact information in the "Email" and "Phone" fields.
9. Click "Submit" to submit the report.

## Field-by-Field Explanation

### Form Title
* **Form Title** (`form_title`, text, required): Enter a brief title for the report.
### Program ID
* **Program ID** (`program_id`, text, optional): Select the ID number of the program you are reporting on.
### Program Name
* **Program Name** (`program_name`, text, optional): Enter the name of the program.
### Outcome 1
* **Outcome 1** (`outcome_1`, select_one, required): Select the relevant outcome from the provided list.
### Outcome 1 Description
* **Outcome 1 Description** (`outcome_1_description`, text, optional): Provide a brief description of the outcome.
### Outcome 1 Evidence
* **Outcome 1 Evidence** (`outcome_1_evidence`, text, optional): Provide supporting evidence for the outcome.
### Outcome 2
* **Outcome 2** (`outcome_2`, select_multiple, optional): Select multiple relevant outcomes from the provided list.
### Outcome 2 Description
* **Outcome 2 Description** (`outcome_2_description`, text, optional): Provide a brief description of the outcome.
### Outcome 2 Evidence
* **Outcome 2 Evidence** (`outcome_2_evidence`, text, optional): Provide supporting evidence for the outcome.
### Supporting Evidence
* **Supporting Evidence** (`supporting_evidence`, note, optional): Enter any additional supporting evidence or comments.
### Challenges
* **Challenges** (`challenges`, text, optional): Enter any challenges you faced while working on the program.
### Outcome 1 Evidence
* **Outcome 1 Evidence** (`outcome_1_evidence`, text, optional): This field is not required, please enter any supporting evidence for the outcome.
### Outcome 2 Evidence
* **Outcome 2 Evidence** (`outcome_2_evidence`, text, optional): This field is not required, please enter any supporting evidence for the outcome.
### Form Date
* **Form Date** (`form_date`, date, required): Enter the current date in the format DD/MM/YY.
### Form Time
* **Form Time** (`form_time`, time, optional): Enter the current time in the format HH:MM, (24-hour clock).
### Email
* **Email** (`email`, email, optional): Enter your email address.
### Phone
* **Phone** (`phone`, text, optional): Enter your phone number.
### Program ID
* **Program ID** (`program_id`, text, optional): This field is not required, please enter the ID number of the program you are reporting on.
### Submit
* **Submit** (`submit`, text, required): Click this button to submit the report.
