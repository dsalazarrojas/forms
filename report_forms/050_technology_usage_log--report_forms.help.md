# technology_usage_log - Help Guide
## Purpose
This form is used to log employee technology usage for auditing, monitoring, and compliance purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select "Technology Usage" and enter the technology item you wish to report.
2. Choose the "Technology Type" that best describes the technology item.
3. Enter a brief "Technology Description" to provide more details about the technology item.
4. Enter the "Technology Usage Start Date" and "Technology Usage End Date" to record the time period of usage.
5. Enter the "Technology Usage Duration" to record the amount of time used.
6. Enter "Technology Usage Notes" to provide any additional information about the usage.
7. Enter "Technology Usage Location" to record where the technology was used.
8. Enter "Technology Usage Who" to record who was using the technology.

## Field-by-Field Explanation
* **Technology Usage** (`title`): Enter a brief title that describes the technology item being used.
* **Technology Type** (`technology_type`): Select one of the following options:
	+ Computer
	+ Tablet
	+ Smartphone
	+ Other (please specify)
* **Technology Description** (`technology_description`): Enter a brief description of the technology item being used.
* **Technology Usage Start Date** (`technology_usage_start_date`): Enter the date the technology was first used.
* **Technology Usage End Date** (`technology_usage_end_date`): Enter the date the technology was last used.
* **Technology Usage Duration** (`technology_usage_duration`): Enter the total duration of technology usage in hours or minutes.
* **Technology Usage Notes** (`technology_usage_notes`): Enter any additional notes about the technology usage.
* **Technology Usage Location** (`technology_usage_location`): Enter where the technology was used.
* **Technology Usage Who** (`technology_usage_who`): Enter the name or ID of the person who used the technology.
