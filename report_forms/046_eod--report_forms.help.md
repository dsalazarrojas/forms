# eod - Help Guide

## Purpose
This form is used for reporting incidents that have occurred in the workplace, including near misses, safety incidents, or other relevant safety and security events.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose a date and time for the incident that occurred using the "Report Date" field.
2. Select the type of incident that occurred using the "Incident Type" field.
3. Provide a brief description of the incident using the "Incident Description" field.
4. Enter the location where the incident occurred using the "Incident Location" field.
5. Enter the time the incident occurred in 24-hour format using the "Incident Time" field.
6. Enter the author of the report using the "Report Author" field.
7. Select the status of the incident using the "Incident Status" field.
8. Select the category of the incident using the "Incident Category" field.
9. Enter any additional details or comments regarding the incident using the "Incident Details" field.

## Field-by-Field Explanation
* **Report Date (report_date)**: Enter the date the incident occurred.
* **Incident Type (incident_type)**: Select the type of incident that occurred (e.g., Incident, Near Miss, Other).
* **Incident Description (incident_description)**: Enter a brief description of the incident, including any relevant details.
* **Incident Location (incident_location)**: Enter the location where the incident occurred.
* **Incident Time (incident_time)**: Enter the time the incident occurred in 24-hour format.
* **Report Author (report_author)**: Enter the author of the report.
* **Report Date Completed (report_date_completed)**: Enter the date the report was completed (not applicable for reporting incidents, this field is likely for internal use only).
* **Incident Status (incident_status)**: Select the status of the incident (e.g., Open, Closed, In Progress).
* **Incident Category (incident_category)**: Select the category of the incident (e.g., Safety, Security, Other).
* **Incident Details (incident_details)**: Enter any additional details or comments regarding the incident.
