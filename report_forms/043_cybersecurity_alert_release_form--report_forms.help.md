# Cybersecurity Alert Release Form - Help Guide
## Purpose
The Cybersecurity Alert Release Form is used to report and manage security incidents, providing a structured format for capturing details and tracking progress.

## How To Complete This Form

To complete this form, follow these steps:

1.  Provide a brief summary of the incident in the **Incident Summary** field.
2.  Enter the date of the incident in the **Incident Date** field.
3.  Select the urgency of the incident from the options in the **Urgency** field.
4.  Select the severity of the incident from the options in the **Severity** field.
5.  Choose all the affected categories for the incident, such as **Incident Category**, **Affected Locations**, **Affected Devices**, **Affected Services**, **Affected Data**, **Affected Assets**.
6.  Select all the respondents who are involved in the incident, such as **Respondent**.
7.  Choose all the affected assets and tags for the incident, such as **Tags**, **Attachments**.
8.  Enter any additional comments or notes about the incident in the **Comments** field.

## Field-by-Field Explanation

* **Incident Summary**: A brief summary of the incident.
* **Incident Date**: The date of the incident.
* **Urgency**: The level of urgency of the incident.
* **Severity**: The level of severity of the incident.
* **Incident Category**: The category of the incident (e.g., Malware, Phishing, Ransomware).
* **Incident Category is a multiple select field**: Select all the applicable categories.
* **Respondent**: The person reporting the incident.
* **Respondent is a multiple select field**: Select all the applicable persons.
* **Tags**: Whether the incident has any tags.
* **Attachments**: Whether the incident has any attachments.
* **Comments**: Additional comments about the incident.
* **Affected Locations**: Whether the incident affected any locations.
* **Affected Locations is a multiple select field**: Select all the locations affected.
* **Affected Devices**: Whether the incident affected any devices.
* **Affected Devices is a multiple select field**: Select all the devices affected.
* **Affected Services**: Whether the incident affected any services.
* **Affected Services is a multiple select field**: Select all the services affected.
* **Affected Data**: Whether the incident affected any data.
* **Affected Data is a multiple select field**: Select all the data affected.
* **Affected Assets**: Whether the incident affected any assets.
* **Affected Assets is a multiple select field**: Select all the assets affected.
* **Reported By**: The person who reported the incident.
* **Updated By**: The person who updated the incident.
* **Resolution Time**: The time it took to resolve the incident.
* **Resolution Time is a multiple select field**: Select the resolution time.
