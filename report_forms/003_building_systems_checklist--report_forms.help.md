# Building Systems Checklist - Help Guide

## Purpose
This form is designed to collect inspection information for building systems, ensuring that all necessary details are captured during an inspection.

## How To Complete This Form
1. Fill out the form in a single session, ensuring that you don't leave any required fields blank.
2. Select the correct options for each field based on your inspection findings.
3. Use the optional fields to provide additional information or observations.
4. Verify that you've completed all required fields before submitting the form.

## Field-by-Field Explanation

* **Inspection Information** (`inspection_info`, `note`, optional): This field is a note-taking space for you to capture any additional information relevant to the inspection.
* **Inspection Date** (`inspection_date`, `date`, required): Enter the date of the inspection in the format MM/DD/YYYY (e.g., 02/01/2024).
* **Inspector Name** (`inspector_name`, `text`, required): Enter the name of the person performing the inspection.
* **Building Name** (`building_name`, `text`, required): Enter the name of the building being inspected.
* **Floor or Area** (`floor_area`, `text`, required): Specify the floor or area inspected during the survey.
* **Security Systems** (`security_systems`, `note`, optional): Use this field to note any security systems issues or concerns.
* **Security Cameras** (`security_cameras`, `select_one`, required): Select the status of the security cameras:
	+ All Functional
	+ Most Functional
	+ Some Issues
	+ Major Issues
	+ Not Functional
* **Access Control Systems** (`access_control_systems`, `select_one`, required): Select the status of access control systems:
	+ All Functional
	+ Most Functional
	+ Some Issues
	+ Major Issues
	+ Not Functional
* **Alarm Systems** (`alarm_systems`, `select_one`, required): Select the status of alarm systems:
	+ All Functional
	+ Most Functional
	+ Some Issues
	+ Major Issues
	+ Not Functional
* **Fire Safety** (`fire_safety`, `note`, optional): Use this field to note any fire safety concerns or issues.
* **Fire Extinguishers** (`fire_extinguishers`, `select_one`, required): Select the status of fire extinguishers:
	+ All Compliant
	+ Most Compliant
	+ Some Issues
	+ Major Issues
	+ Non-Compliant
* **Fire Alarms** (`fire_alarms`, `select_one`, required): Select the status of fire alarms:
	+ All Functional

* **Emergency Lighting** (`emergency_lighting`, `select_one`, required): Select the status of emergency lighting:
	+ All Functional

	+ Major Issues
	+ Not Functional
* **Doors and Gates** (`doors_and_gates`, `note`, optional): This field is a note-taking space for you to capture any door and gate concerns or issues.
* **Main Doors and Contacts** (`main_doors`, `select_one`, required): Select the condition of main entry doors:
	+ Excellent Condition
	+ Good Condition

	+ Poor Condition

* **External Sign Lighting** (`external_sign_lighting`, `select_one`, required): Select the status of external sign lighting:
	+ All Functional
	+ Most Functional
	+ Some Issues
	+ Major Issues
	+ Not Functional
* **Interior Lighting** (`interior_lighting`, `select_one`, required): Select the status of interior lighting:
	+ All Functional
	+ Most Functional
	+ Some Issues
	+ Major Issues
	+ Not Functional
* **Additional Notes** (`additional_notes`, `text`, optional): Use this field to capture any other observations or concerns that are not captured in the previous fields.

	+ False

	+ Yes - Urgent
	+ Yes - Emergency
