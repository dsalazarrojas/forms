# Digital Audit Trail Report Form - Help Guide
## Purpose
The Digital Audit Trail Report Form is designed to collect detailed information about user activities, providing a record of what users have done on a device, and at what time. This form is typically used for monitoring and tracking user behavior, performance, or other relevant activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the activity that occurred, focusing on the main details.
2. Select relevant report details, such as report type.
3. Enter user information, including user ID and IP address.
4. Choose the type of device used to access the system.
5. Select the device's operating system.
6. Choose the type of browser used.
7. Enter the location and any additional comments.
8. Select the date and time of the activity, as well as the status of the activity.
9. Enter the date and time the form was filled out.

## Field-by-Field Explanation
- **Activity Details** (text, required): A brief description of the activity that occurred.
- **Report Details** (select_multiple, optional): Select all relevant report details.
- **User Details** (text, required): Enter user information.
- **Additional Information** (note, optional): Enter any additional relevant information.
- **Date and Time** (date, required): Enter the date and time of the activity.
- **User ID** (number, required): Enter user ID.
- **IP Address** (text, required): Enter IP address.
- **Device Type** (select_one, optional): Select device type.
- **Device OS** (select_one, optional): Select device OS.
- **Browser Type** (select_one, optional): Select browser type.
- **Location** (text, optional): Enter location.
- **Notes** (text, optional): Add any notes about the activity.
- **Date and Time Activity** (select_one, optional): Select date and time of activity.
- **Activity Type** (select_one, optional): Select activity type.
- **Status** (select_one, optional): Select status.
- **Comments** (text, optional): Enter comments.
- **Date** (date, required): Enter date.
- **Time** (time, required): Enter time.
