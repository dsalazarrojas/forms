# Substance Discrepancy Report - Help Guide

## Purpose
The Substance Discrepancy Report form is used to report any discrepancies in the quantity of a substance in stock or received. This form helps in tracking and resolving the issue accurately.

## How To Complete This Form

To fill out this form, follow these steps:

1.  Review and confirm that you are reporting a genuine discrepancy.
2.  Enter the Substance Name to identify the specific substance in question.
3.  Provide the details of the quantity discrepancy.
4.  Select the Discrepancy Type to indicate the nature of the discrepancy (e.g., Discrepancy, Loss, Shortage, or Overstock).
5.  Specify the Location where the discrepancy was found.
6.  Enter a Description of the situation to aid in understanding and resolution.
7.  Enter the person or team that Reported the issue.
8.  Select the date and time when the issue was Reported.
9.  Select the Discrepancy Status as Active or Inactive.
10. Review and submit the form for accurate tracking and resolution.

## Field-by-Field Explanation

*   **Substance Name**: Enter the name of the substance that is in question.
    *   Type: Text Field
    *   Required: No
*   **Quantity Discrepancy**: Enter the quantity of the substance that is discrepant.
    *   Type: Number Field
    *   Required: No
*   **Discrepancy Type**: Select the type of discrepancy (Discrepancy, Loss, Shortage, or Overstock).
    *   Type: Select One Field
    *   Required: No
*   **Location**: Select the location where the discrepancy was found (Facility, Warehouse, or Store).
    *   Type: Select One Field
    *   Required: No
*   **Description**: Provide a brief description of the situation to aid in resolution.
    *   Type: Text Field
    *   Required: No
*   **Reported By**: Enter the person or team responsible for reporting the issue.
    *   Type: Text Field
    *   Required: No
*   **Reported Date**: Enter the date the issue was reported.
    *   Type: Date Field
    *   Required: No
*   **Reported Time**: Enter the time the issue was reported.
    *   Type: Time Field
    *   Required: No
*   **Discrepancy Date**: Enter the date of the discrepancy.
    *   Type: Date Field
    *   Required: No
*   **Discrepancy Status**: Select the status of the discrepancy (Active or Inactive).
    *   Type: Select One Field
    *   Required: No
