# Investigation Findings Report - Help Guide
## Purpose
This form is designed to document the findings and conclusions of an investigation. It is intended for internal or external reporting and might be used across various industries, including legal, finance, or IT. The form aims to gather information that can be used for decision-making, record-keeping, or communication within or outside of an organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a thorough description of the investigation findings on the "Investigation Findings" field.
2. Indicate whether evidence was attached to the report by selecting "Yes" or "No" in the "Evidence Attached" field.
3. Document any actions taken as a result of the investigation findings on the "Actions Taken" field.
4. Plan or document the next steps to be taken following the investigation on the "Next Steps" field.

## Field-by-Field Explanation
### **Investigation Findings** (Page 1)
* This field is where you can provide a detailed description of the investigation's findings. Please include all relevant information and evidence collected during the investigation.
* Ensure this field is filled in as it is not required, but it is crucial for a comprehensive understanding of the investigation's outcome.

### **Evidence Attached** (Page 2)
* This field is a select multiple option field where you can indicate whether evidence was attached to the report.
* Select "Yes" if you have attached evidence related to the investigation.
* Select "No" if no evidence was attached or not applicable.

### **Actions Taken** (Page 3)
* This field is where you can document any actions taken as a result of the investigation findings.
* Please provide a clear and concise description of the actions taken, including any decisions made or changes implemented.

### **Next Steps** (Page 4)
* This field is where you can plan or document the next steps to be taken following the investigation.
* Be as specific as possible when describing the next steps, including any deadlines or milestones.
* Ensure that all next steps are aligned with the investigation's findings and conclusions.
