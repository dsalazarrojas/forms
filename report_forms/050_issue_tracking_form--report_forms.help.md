# Issue Tracking Form - Help Guide
## Purpose
The Issue Tracking Form is used to collect data on issues that need to be addressed. It provides a structured way to report and track issues, making it easier to keep track of problems and their status.

## How To Complete This Form
To complete the form, follow these steps:

1. Choose the type of issue you are reporting by selecting one of the options in the "Issue Type" field.
2. Provide a detailed description of the issue in the "Issue Description" field.
3. Select the current status of the issue from the "Status" field.
4. Choose the severity of the issue from the "Severity" field.
5. Select the priority of the issue from the "Priority" field.
6. Enter the date the issue occurred in the "Date" field.
7. Review and submit the form.

## Field-by-Field Explanation
* **Issue Type**: Select the type of issue you are reporting. Choose "Yes" if the issue is present or "No" if it's not.
* **Issue Description**: Provide a detailed description of the issue to help track and understand the problem. This field should include all relevant details.
* **Status**: Choose the current status of the issue from the options provided (Active or Inactive).
* **Severity**: Indicate the level of severity of the issue. A "Yes" response typically implies a higher level of severity.
* **Priority**: Select the priority level of the issue from the options provided (Yes or No).
* **Date**: Enter the date the issue occurred, in the format MM/DD/YYYY.
* **Issue Tracking Form**: This is a placeholder title field. Do not fill it in, as it is not required for tracking purposes.
