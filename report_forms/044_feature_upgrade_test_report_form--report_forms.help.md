# Feature Upgrade Test Report Form - Help Guide
## Purpose
The Feature Upgrade Test Report Form is used to document and track test results for feature upgrades. It helps ensure that the test results are comprehensive and consistent.

## How To Complete This Form
1. Fill out the form completely, especially the required fields.
2. Ensure the "Test Version" field is filled with the actual version of the feature being tested.
3. Select one of the test outcomes from the list for the "Test Outcome" field.
4. Enter any additional details about the test outcome in the "Test Outcome Details" field.
5. If issues arose during the test, select them in the "Issues" field.
6. Enter additional details about the issues in the "Test Issue Details" field.
7. Enter the environment in which the test was performed in the "Test Environment" field.
8. Enter the duration of the test in the "Test Duration" field.
9. Enter the date of the test in the "Test Date" field.
10. If someone is assigned to follow up on the test, enter their email address in the "Email" field and their name in the "Assigned To" field.
11. Enter your contact information in the "Phone" field and "Email" field.

## Field-by-Field Explanation

* **Feature Upgrade Test Report**: This is a note field where you can add any additional comments about the test report.
* **Test Version**: Enter the version of the feature that was tested.
* **Test Outcome**: Select one of the following outcomes:
  + Pass: The test was successful.
  + Fail: The test was not successful.
  + Not Tested: The test was not performed.
* **Test Outcome Details**: Enter any additional details about the test outcome.
* **Issues**: Select any issues that arose during the test.
  + Bug: A known bug in the feature.
  + Feature Request: A feature that should be added or modified.
  + Security Vulnerability: A security vulnerability in the feature.
* **Test Issue Details**: Enter any additional details about the issues that arose during the test.
* **Test Environment**: Enter the environment in which the test was performed (e.g. local, dev, prod).
* **Test Duration**: Enter the duration of the test in hours and minutes.
* **Test Date**: Enter the date and time of the test.
* **Assigned To**: If someone is responsible for following up on the test, enter their name.
* **Email**: Enter the email address of the person responsible for following up on the test.
* **Phone**: Enter your phone number.
* **Upgrade Version**: This is the version of the feature that was upgraded, or the version that the feature will be upgraded to.
