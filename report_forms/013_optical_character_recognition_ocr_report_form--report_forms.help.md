# Optical Character Recognition (OCR) Report Form - Help Guide

## Purpose
The purpose of this form is to report on the results of Optical Character Recognition (OCR) processing.

## How To Complete This Form

1. Review and fill out each field carefully, taking into account any specific instructions provided by your team or project guidelines.
2. Ensure that all required fields are filled out.
3. For fields with options, select only one option that applies to your case.
4. Double-check your work before submitting the form.

## Field-by-Field Explanation

* **Scanned Document 1** (`scanned-document-1`, text, optional): Please enter the title or description of the scanned document.
* **Extracted Data 1** (`extracted-data-1`, select_multiple, optional): Select all the extracted data that apply to your case. You can choose from the following options:
	+ Yes
	+ No
* **Extracted Data 2** (`extracted-data-2`, select_one, optional): Select only one option that applies to your case. You can choose from the following options:
	+ Yes
	+ No
* **Extracted Data 3** (`extracted-data-3`, time, optional): Enter the extracted time data in the format `HH:MM:SS`.
* **Extracted Data 4** (`extracted-data-4`, note, optional): Enter any additional notes about the extracted data.
* **Extracted Data 5** (`extracted-data-5`, date, optional): Enter the extracted date data in the format `YYYY-MM-DD`.
* **Extracted Data 6** (`extracted-data-6`, text, optional): Enter any additional text data that was extracted from the scanned document.
* **Extracted Data 7** (`extracted-data-7`, text, optional): Enter any additional text data that was extracted from the scanned document.
* **Extracted Data 8** (`extracted-data-8`, number, optional): Enter the extracted number data.
* **Extracted Data 9** (`extracted-data-9`, number, optional): Enter any other extracted number data.
* **Extracted Data 10** (`extracted-data-10`, email, optional): Enter any extracted email data.

## Tips

* Make sure to fill out each field accurately and thoroughly.
* If you're unsure about any field, please consult with your team or project guidelines.
* Double-check your work before submitting the form.
