# Guest Room CheckList - Help Guide

## Purpose
The Guest Room CheckList form is designed to help hospitality staff quickly and easily check and report on the status of various amenities and equipment in guest rooms. This includes cleanliness, bathroom cleanliness, bedding, linen, towel availability, toiletries, amenities, safety equipment, and electrical outlets.

## How To Complete This Form
1. Fill out the form for each room by selecting the current status of each item.
2. Select 'Yes' if the item is present and in good condition.
3. Select 'No' if the item is not present or in poor condition.
4. Select 'Active' for items that are currently active and functioning properly.
5. Select 'Inactive' for items that are not active or not functioning properly.
6. Click 'Submit' to complete the form.

## Field-by-Field Explanation

* **Room Number** (1, Required): Enter the room number you are checking.
* **Room Type** (2, Optional): Check the room type, e.g., single, double, suite, etc.
* **Cleanliness** (3, Optional): Select 'Yes' if the room is clean, 'No' otherwise.
* **Bathroom Cleanliness** (4, Optional): Select 'Yes' if the bathroom is clean, 'No' otherwise.
* **Bedding** (5, Optional): Select 'Yes' if the bedding is in good condition, 'No' otherwise.
* **Linen** (6, Optional): Select 'Yes' if linens are available, 'No' otherwise.
* **Towel** (7, Optional): Select 'Yes' if towels are available, 'No' otherwise.
* **Toiletries** (8, Optional): Select 'Yes' if toiletries are available, 'No' otherwise.
* **Amenities** (9, Optional): Select 'Yes' for any available amenities, 'No' otherwise.
* **Safety Equipment** (10, Optional): Select 'Yes' for any safety equipment available, 'No' otherwise.
* **Electrical Outlet** (11, Optional): Select 'Yes' if the electrical outlet is active and functioning properly, 'No' otherwise.
* **Smoke Detector** (12, Optional): Select 'Yes' if the smoke detector is active and functioning properly, 'No' otherwise.
* **First Aid Kit** (13, Optional): Select 'Yes' if the first aid kit is available and active, 'No' otherwise.
* **Fire Extinguisher** (14, Optional): Select 'Yes' if the fire extinguisher is available and active, 'No' otherwise.
* **Fire Alarm** (15, Optional): Select 'Yes' if the fire alarm is active and functioning properly, 'No' otherwise.
* **Elevator** (16, Optional): Select 'Yes' if the elevator is active and functioning properly, 'No' otherwise.
* **Parking** (17, Optional): Select 'Yes' if parking is available, 'No' otherwise.
* **Smoke Detector Status** (18, Optional): Select 'Active' if the smoke detector is active and functioning properly, 'Inactive' otherwise.
* **Electrical Outlet Status** (19, Optional): Select 'Active' if the electrical outlet is active and functioning properly, 'Inactive' otherwise.
* **Fire Alarm Status** (20, Optional): Select 'Active' if the fire alarm is active and functioning properly, 'Inactive' otherwise.
* **Elevator Status** (21, Optional): Select 'Active' if the elevator is active and functioning properly, 'Inactive' otherwise.
* **Parking Status** (22, Optional): Select 'Active' if parking is available, 'Inactive' otherwise.
* **First Aid Kit Status** (23, Optional): Select 'Active' if the first aid kit is available and active, 'Inactive' otherwise.
* **Fire Extinguisher Status** (24, Optional): Select 'Active' if the fire extinguisher is available and active, 'Inactive' otherwise.
* **Smoke Detector Status** (25, Optional): Select 'Active' if the smoke detector is active and functioning properly, 'Inactive' otherwise.
