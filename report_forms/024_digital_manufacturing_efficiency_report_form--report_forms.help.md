# Digital Manufacturing Efficiency Report Form - Help Guide

## Purpose
The Digital Manufacturing Efficiency Report Form is designed to collect and track production data for quality and productivity assessment. The form is intended to help production team leaders, supervisors, and other stakeholders to monitor and evaluate the efficiency of the production process.

## How To Complete This Form

1.  To start filling out this form, select the "production_shift" field, which is used to identify the shift during which the production took place.
2.  In the "work_center" field, select the relevant machine center where the production occurred.
3.  Choose the correct "production_time" field to enter the time when the production started.
4.  In the "machine_id" field, select the ID of the machine involved in the production process.
5.  Choose the "production_date" field to enter the date of production.
6.  In the "production_hours_per_shift" field, enter the total hours worked during the production.
7.  Choose the start and end times for the shift by using the "shift_start_time" and "shift_end_time" fields.
8.  Enter the total shift length in hours worked in the "shift_length" field.
9.  Report the total parts produced, inspected, defective, reworked, and rejected in the respective fields.
10.  Select the total production rate in the "production_rate" field.
11.  Choose the shift and supervisor involved in the production process by using the "shift" and "supervisor" fields.
12.  In the "production_notes" field, enter any additional comments or remarks about the production process.
13.  Enter the work order and lot number, if available, in the "work_order_number" and "lot_number" fields.
14.  Select the production run and production code involved in the production process by using the "production_run" and "production_code" fields.
15.  In the "production_id" field, enter a unique production ID.
16.  Enter any additional remarks or comments about the production process in the "remarks" field.

## Field-by-Field Explanation

*   **Production Shift** (`production_shift`, Select, required): The shift during which the production took place.
*   **Work Center** (`work_center`, Select, required): The machine center where the production occurred.
*   **Production Time** (`production_time`, Select, required): The time when the production started.
*   **Machine ID** (`machine_id`, Select, required): The ID of the machine involved in the production process.
*   **Production Date** (`production_date`, Select, required): The date of production.
*   **Production Hours per Shift** (`production_hours_per_shift`, Number, required): The total hours worked during the production.
*   **Shift Start Time** (`shift_start_time`, Time, required): The start time for the shift.
*   **Shift End Time** (`shift_end_time`, Time, required): The end time for the shift.
*   **Shift Length** (`shift_length`, Number, required): The total shift length in hours worked.
*   **Total Parts Produced** (`total_parts_produced`, Number, required): The total number of parts produced during the production.
*   **Total Parts Inspected** (`total_parts_inspected`, Number, required): The total number of parts inspected during production.
*   **Total Parts Defective** (`total_parts_defective`, Number, required): The total number of defective parts during the production.
*   **Total Parts Reworked** (`total_parts_reworked`, Number, required): The total number of parts reworked during the production.
*   **Total Parts Rejected** (`total_parts_rejected`, Number, required): The total number of parts rejected during the production.
*   **Total Parts Suspended** (`total_parts_suspended`, Number, required): The total number of parts suspended during the production.
*   **Production Rate** (`production_rate`, Number, required): The total production rate during the production.
*   **Shift** (`shift`, Select, required): The shift during which the production took place.
*   **Supervisor** (`supervisor`, Select, required): The supervisor involved in the production process.
*   **Production Notes** (`production_notes`, Text, required): Any additional comments or remarks about the production process.
*   **Work Order Number** (`work_order_number`, Text, required): The work order number for the production process.
*   **Lot Number** (`lot_number`, Text, required): The lot number for the production process.
*   **Production Run** (`production_run`, Select, required): The production run involved in the production process.
*   **Production Code** (`production_code`, Select, required): The production code involved in the production process.
*   **Production ID** (`production_id`, Number, required): A unique ID for the production process.
*   **Remarks** (`remarks`, Text, required): Any additional remarks or comments about the production process.
