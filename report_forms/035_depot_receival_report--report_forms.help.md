To ensure consistency, it's essential that you accurately and thoroughly fill out this form for every item you receive.

# Depot Receival Report - Help Guide
## Purpose
The purpose of this form is to record the receipt of goods into the warehouse, ensuring accurate and up-to-date inventory records.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the warehouse where the goods were received.
2. Enter the date when the goods were received.
3. Enter the item ID of the goods received.
4. Enter the quantity of the goods received.
5. If necessary, enter any comments or remarks about the goods.
6. Select any discrepancies that occurred during the receipt process, if applicable.
7. Add any comments from the warehouse manager regarding the received goods, if necessary.

## Field-by-Field Explanation

* **Warehouse Name**: Enter the name of the warehouse where the goods were received.
* **Date Receival**: Enter the date when the goods were received. Please use the date format: YYYY-MM-DD.
* **Item ID**: Enter the item ID of the goods received.
* **Item Quantity**: Enter the quantity of the goods received.
* **Received By**: Enter any additional comments or remarks about the goods.
* **Comments**: Enter any comments or remarks about the goods, if necessary.
* **Discrepancies**: Select any discrepancies that occurred during the receipt process, if applicable. Choose all that apply from the options provided.
* **Warehouse Manager Comments**: Enter any comments or remarks from the warehouse manager regarding the received goods, if necessary.
* **Tips**: Make sure to double-check your entries for accuracy and completeness before submitting the form.
*   Use the "Warehouse Manager Comments" field to record any specific instructions or guidance from the warehouse manager.
*   If discrepancies occur, select all relevant options from the "Discrepancies" field.
*   Be mindful of the date format when filling out the "Date Receival" field.
