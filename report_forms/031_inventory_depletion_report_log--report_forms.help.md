# Inventory Depletion Report Log - Help Guide

## Purpose
The purpose of this form is to record and track inventory depletion information. It is designed to gather data on inventory that has been depleted, including the date, location, and other relevant details.

## How To Complete This Form

To complete this form, follow the steps below:

1. Select the inventory depletion date from the provided options.
2. Choose the depleting store location(s) from the available options.
3. Select the stock usage shift (Day, Night, or Weekend).
4. Enter the type of inventory that was depleted.
5. Input the quantity of inventory that was depleted.
6. Add any additional notes or comments about the depletion.
7. Provide any additional details about the inventory depletion.
8. Select the date range for the report (Yesterday, This Week, or Last Week).
9. Choose any additional reports that are relevant to the inventory depletion.
10. Select the stockroom location(s) where the inventory was depleted.
11. Add any comments about the inventory depletion.

## Field-by-Field Explanation
* **Inventory Depletion Date**: Enter the date on which the inventory was depleted.
* **Depleting Store Location(s)**: Choose all locations where the inventory was depleted.
* **Stock Usage Shift**: Select the shift during which the inventory was depleted (Day, Night, or Weekend).
* **Type of Inventory**: Enter the type of inventory that was depleted (e.g., "Product A", "Product B", etc.).
* **Inventory Depleted**: Enter the quantity of inventory that was depleted.
* **Additional Notes**: Add any additional comments or notes about the depletion.
* **Additional Details**: Provide any additional details about the inventory depletion.
* **Select Date Range**: Choose the date range for which the report is being generated (Yesterday, This Week, or Last Week).
* **Depleted Quantity**: Enter the quantity of inventory that was depleted.
* **Additional Reports**: Select any additional reports that are relevant to the inventory depletion.
* **Stockroom Location**: Choose all locations where the inventory was depleted.
* **Comments**: Add any comments or notes about the inventory depletion.
* **Additional Questions**: Ask any additional questions about the inventory depletion.
