# Project Changes Report Form - Help Guide
## Purpose
The Project Changes Report Form is a tool for project team members and managers to report any changes made to a project. It helps in maintaining an accurate record of project changes, facilitating better project management and decision-making.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill out the form for each project change.
*   Ensure that each entry is accurate and not duplicated.
*   Answer all required fields (marked as "required") truthfully.

## Field-by-Field Explanation
*   **project_changes_date** (`number`, required): The date on which the project change was made.
*   **project_change_description** (`text`, optional): A brief description of the project change. This can include details about what was changed, why it was changed, and how it affects the project.
*   **project_change_category** (`select_multiple`, required): Check the options that apply to the project change. This helps in identifying the type of change made.
*   **project_change_type** (`select_one`, required): Select 'Yes' if the change was made and 'No' if it wasn't.
*   **project_changes_notes** (`note`, optional): Add any additional notes or comments about the project change.
*   **project_changes_comments** (`text`, optional): Any comments or observations about the project change.
*   **project_change_owners** (`select_multiple`, required): Check the names of the team members or managers involved in the project change.
