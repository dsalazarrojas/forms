# ประก Retail Promotion Performance Report Form - Help Guide
## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the form title.
2. Enter the campaign start and end dates.
3. Select the campaign name and type.
4. Enter the product name and goals for the campaign.
5. Identify the target audience for the campaign.
6. Specify the location where the campaign was executed.
7. Enter the campaign budget.
8. Choose the media channels used for the campaign.
9. Choose the product promotion channels used for the campaign.
10. Enter any additional information about the campaign.
11. Add any notes you would like to attach to the campaign.
