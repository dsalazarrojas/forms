# hrd_training_log - Help Guide
## Purpose
This form is used to record and track training events for HR-related purposes. It captures information about the training date, location, trainers, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, indicated by an asterisk (\*) after the label.
2. Use the date field to select the date of the training event.
3. Enter the location of the training event.
4. Select the trainers or individuals assigned to the training event.
5. Choose the status of the training event (Active, Inactive, or Pending).
6. Enter the start and end dates and times of the training event.
7. Select the duration of the training event.
8. Choose the level of training (Beginner, Intermediate, or Advanced).
9. Select the topics of the training event.
10. Enter any additional notes about the training event.

## Field-by-Field Explanation
* **Main Form** (`main_form`, text, not required): This field is a text input field where you can enter any additional information about the training event.
* **Training Log** (`training_log`, text, not required): This field is used to enter a brief description of the training event.
* **Date of Training** (`date_of_training`, date, not required): This field is used to select the date of the training event.
* **Location of Training** (`location_of_training`, text, not required): This field is used to enter the location of the training event.
* **Notes** (`notes`, note, not required): This field is used to enter any additional notes about the training event.
* **Assigned To** (`assigned_to`, select multiple, not required): This field allows you to select multiple individuals assigned to the training event.
* **Status** (`status`, select one, not required): This field is used to select the status of the training event (Active, Inactive, or Pending).
* **Start Date** (`start_date`, date, not required): This field is used to select the start date of the training event.
* **End Date** (`end_date`, date, not required): This field is used to select the end date of the training event.
* **Start Time** (`start_time`, time, not required): This field is used to select the start time of the training event.
* **End Time** (`end_time`, time, not required): This field is used to select the end time of the training event.
* **Duration** (`duration`, number, not required): This field is used to enter the duration of the training event.
* **Training Level** (`training_level`, select one, not required): This field is used to select the level of training (Beginner, Intermediate, or Advanced).
* **Training Topic** (`training_topic`, select multiple, not required): This field is used to select multiple topics of the training event.
* **Notes 2** (`notes_2`, note, not required): This field is used to enter any additional notes about the training event.
* **Assigned Tool** (`assigned_tool`, select one, not required): This field is used to select the tool used in the training event.
