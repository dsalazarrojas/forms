# Service Activity Log - Help Guide
## Purpose
The Service Activity Log form is used to document and track customer service activities, including follow-ups and their outcomes. This form helps to maintain a record of service activity and follow-up status.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by filling out the "Follow up" field with the relevant information. This field is required to ensure that you're tracking the correct follow-up activities.
2. Select the "Follow-up Status" field to indicate if the follow-up activity was successful or not.
3. In the "Follow-up Description" field, provide a brief description of the follow-up activity.

## Field-by-Field Explanation
* **Follow up** (`follow_up`, select_one, required): Select the follow-up activity being performed. This field helps to identify the type of follow-up activity being done.
* **Follow-up Status** (`follow_up_status`, select_one, required): Indicate the outcome of the follow-up activity using the available options.
* **Follow-up Description** (`follow_up_description`, text, not required): Provide a brief description of the follow-up activity.
* **Completed Work** (`completed_work`, text, not required): Enter any completed work related to the follow-up activity.
* **Track Follow-ups** (`track_follow_ups`, text, not required): Enter any follow-ups that need to be tracked.
* **Standardize Data Collection** (`standardize_data_collection`, text, not required): Enter any standardized data collection efforts.
* **Stored Managed In Jotform** (`stored_managed_in_jotform`, text, not required): Indicate if the follow-up activity is stored in Jotform.
* **Service Activity Log** (`service_activity_log`, text, not required): Enter any additional information about the service activity log.
