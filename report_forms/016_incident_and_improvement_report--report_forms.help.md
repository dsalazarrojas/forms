# Incident And Improvement Report - Help Guide
## Purpose
This form is used to collect information about incidents and improvement reports from clients. It is designed to gather details about the incident, including its category, description, location, date, and outcome.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields:
	* **Client Name**: Enter the name of the client who experienced the incident.
	* **Category**: Select the category of the incident (e.g., Category 1, Category 2, Category 3).
	* **Date of Incident**: Enter the date of the incident.
	* **Location of Incident**: Enter the location where the incident occurred.
	* **Description**: Enter a brief description of the incident.
	* **Outcome**: Enter the outcome of the incident.
2. Provide detailed information:
	* **Actions Taken**: Describe the actions taken in response to the incident.
	* **Further Actions Taken**: Describe any further actions taken in response to the incident.
	* **Injuries Sustained**: Describe any injuries sustained during the incident.
	* **Incident Cause**: Describe the cause of the incident.
	* **Incident Type**: Select the type of incident (e.g., Type 1, Type 2, Type 3).
	* **Incident Subcategory**: Select the subcategory of the incident (e.g., Subcategory 1, Subcategory 2, Subcategory 3).
	* **Actions Taken By**: Describe the actions taken by each person involved in the incident.
	* **Further Actions Taken By**: Describe any further actions taken by each person involved in the incident.
	* **Incident Reporter**: Select the person who reported the incident (e.g., Person 1, Person 2, Person 3).
3. Leave the optional fields blank:
	* **Client Category**: Select the category of the client (e.g., Category 1, Category 2, Category 3).
	* **Assigned Tool**: Select the tool assigned to handle the incident (e.g., Tool 1, Tool 2, Tool 3).
	* **Incident Status**: Select the status of the incident (e.g., Status 1, Status 2, Status 3).
