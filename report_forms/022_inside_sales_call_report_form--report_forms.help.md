# inside_sales_call_report_form - Help Guide

## Purpose
This form is designed to document the details of inside sales calls, including the date and time of the call, the sales representative involved, the customer's name, phone number, and email, and any follow-up actions that need to be taken.

## How To Complete This Form

### Step 1: Complete the required fields for each section

*   **First Day of Report (1)**: Enter the date of the first day of the report.
*   **Sales Rep (2)**: Enter the name of the sales representative involved in the call.
*   **Customer Name (3)**: Enter the full name of the customer.
*   **Customer Phone (4)**: Enter the customer's phone number.
*   **Customer Email (5)**: Enter the customer's email address.
*   **Date of Call (6)**: Enter the date and time of the call.
*   **Call Notes (7)**: Enter a brief description of the call.
*   **Follow-up Action (8)**: Select one of the follow-up actions that need to be taken (e.g., Follow-up with customer, Send follow-up email, Schedule follow-up call, etc.).
*   **Assigned User (11)**: Enter the name of the user assigned to follow-up on the call.
*   **Created At (12)**: This field is automatically populated with the date and time the report was created.
*   **Updated At (13)**: This field is automatically populated with the date and time the report was last updated.

### Step 2: Optionally complete any additional fields

*   **Additional Comments (10)**: Enter any additional information about the call that is not captured in the other fields.
*   **Other (9)**: If "Follow-up Action" is selected as "Other", please enter a brief description of the action.

### Tips

*   Make sure to only complete this form once for each unique call.
*   Be as detailed as possible in the "Call Notes" field.
*   Ensure that the "Follow-up Action" field is completed to reflect the agreed-upon next steps.
*   The "Assigned User" field should be completed with the name of the user assigned to follow-up on the call.
*   If you are the user assigned to follow-up on the call, ensure that you are aware of the agreed-upon next steps and have them documented in this report.
*   The "Created At" and "Updated At" fields are automatically populated and do not need to be completed manually.
