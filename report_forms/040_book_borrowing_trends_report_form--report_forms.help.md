# Book Borrowing Trends Report Form - Help Guide
## Purpose
This form helps libraries understand and analyze book borrowing trends, providing valuable insights into their collection's popularity and user behavior.

## How To Complete This Form
1. **Library Name**: Enter the name of your institution, which will appear in the report header.
2. **Reporting Period Start**: Select the start date of the reporting period for which you want to collect data.
3. **Reporting Period End**: Select the end date of the reporting period for which you want to collect data.
4. **Total Borrows**: Enter the total number of items borrowed during the reporting period.
5. **Top Genres Borrowed**: Select the top genres that were borrowed during the reporting period. You can choose one or multiple genres from the list.
	* **Fiction**: Select this option if your library has seen a surge in fiction book borrows.
	* **Non fiction**: Select this option if your library has seen a surge in non-fiction book borrows.
	* **Children**: Select this option if your library has seen a high demand for children's books.
	* **Young Adult**: Select this option if your library has seen a high demand for young adult books.
	* **Mystery**: Select this option if your library has seen a surge in mystery book borrows.
6. **Notable Trends**: Provide any notable changes or observations in borrowing behavior during the reporting period. This could include increased demand for certain titles, authors, or formats, or unusual user behavior.
7. **Recommendations**: Offer suggestions for collection adjustments or improvements based on the data collected. This could include new titles, authors, or formats to add or remove from your collection.

## Field-by-Field Explanation
* **Library Name** (`library_name`, text, required): Enter the name of your institution.
* **Reporting Period Start** (`reporting_period_start`, date, required): Select the start date of the reporting period.
* **Reporting Period End** (`reporting_period_end`, date, required): Select the end date of the reporting period.
* **Total Borrows** (`total_borrows`, number, required): Enter the total number of items borrowed during the reporting period.
* **Top Genres Borrowed** (`top_genres`, select_multiple, optional): Select the top genres that were borrowed during the reporting period. You can choose one or multiple genres.
* **Notable Trends** (`notable_trends`, text, optional): Provide any notable changes or observations in borrowing behavior during the reporting period.
* **Recommendations** (`recommendations`, text, optional): Offer suggestions for collection adjustments or improvements based on the data collected.
