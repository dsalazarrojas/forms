# Fire Extinguisher Checklist - Help Guide
## Purpose
The "Fire Extinguisher Checklist" form is used to track and document the status of fire extinguishers in a facility or organization.

## How To Complete This Form
To complete this form, follow the steps outlined in the "To use this form" section above.

## Field-by-Field Explanation

* **Fire Extinguisher Types** (`fire_extinguisher_types`, `select_one`, optional):
	+ Select the type of fire extinguisher you are tracking.
* **Location** (`location_id`, `number`, optional):
	+ Enter the location where the fire extinguisher is installed.
* **Fire Extinguisher Type** (`fire_extinguisher_type`, `select_one`, optional):
	+ Choose the type of fire extinguisher being inspected.
* **Is Functional** (`is_functional`, `select_multiple`, optional):
	+ Indicate whether the fire extinguisher is currently functional or not.
* **Date Last Inspected** (`date_last_inspected`, `date`, optional):
	+ Enter the date of the last inspection if applicable.
* **Time Last Inspected** (`time_last_inspected`, `time`, optional):
	+ Enter the time of the last inspection if applicable.
* **Next Inspection Due** (`next_inspection_due`, `date`, optional):
	+ Enter the date when the next inspection is due if applicable.
* **Note** (`note`, `note`, optional):
	+ Enter any notes or comments about the fire extinguisher.
* **Email** (`email`, `email`, optional):
	+ Enter any contact information for the person completing the form or responsible for the fire extinguisher.
* **Phone** (`phone`, `text`, optional):
	+ Enter any phone number for the person completing the form or responsible for the fire extinguisher.
* **Comments** (`comments`, `note`, optional):
	+ Enter any comments or additional information about the fire extinguisher.
* **Section 2** (`section_2`, `text`, optional):
	+ Enter any additional comments or information in this section.
* **Comments** (`comments`, `note`, optional):
	+ Enter any additional comments or information about the fire extinguisher.
