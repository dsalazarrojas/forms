# courtesy_officer_daily_activity_report_form - Help Guide
## Purpose
The courtesy officer daily activity report form is a tool for reporting the daily activities of courtesy officers. It helps track the work performed during the workday, including user details, dates, locations, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in your name in the **User** field.
* Select the correct date of your workday in the **Date** field.
* Choose a valid location from the dropdown menu in the **Location** field (this field may not be available if there's only one location).
* Select the type of activity you performed by choosing one of the options in the **Activity Type** field.
* Add any relevant notes or comments in the **Notes** field.
* If applicable, enter your email address and phone number in the **Email** and **Phone** fields respectively.
* Select a valid time for the activity in the **Time** field.
* If you have performed this activity, select **Yes** in the **Submitted By** field; otherwise, select **No**.
* If you have submitted this report, select the correct date in the **Submitted At** field; otherwise, leave it blank.
* Mark if the activity has been submitted ( **Yes** or **No** ) in the **Submitted** field.
* Choose the status of the activity: **Active**, **Inactive**.
* Select a date when the activity has been completed, if it has already been closed; otherwise, leave it blank.
* Add any comments about the activity in the **Comments** field.

## Field-by-Field Explanation

* **User** (1): The name of the person performing the activity.
* **Date** (2): The date of the workday when the activity was performed.
* **Location** (3): The location where the activity was performed.
* **Activity Type** (4): Select the type of activity performed. (e.g., 'Yes', 'No')
* **Notes** (5): Additional comments or information about the activity.
* **Email** (6): The email address associated with the activity.
* **Phone** (7): The phone number associated with the activity.
* **Time** (8): The time of the activity.
* **Submitted By** (9): Whether you performed this activity.
* **Submitted At** (10): The date the report was submitted.
* **Submitted** (11): Whether the report has been submitted or not.
* **Status** (12): The current status of the activity (Active, Inactive)
* **Completed** (13): The date the activity has been completed.
* **Comments** (14): Any additional comments about the activity.
