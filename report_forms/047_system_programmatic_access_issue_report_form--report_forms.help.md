# System Programmatic Access Issue Report Form - Help Guide
## Purpose
The purpose of this form is to report any System Programmatic Access issues that you are experiencing. Your detailed input will help the support team troubleshoot and resolve the issue promptly.

## How To Complete This Form
To complete this form, please follow these steps:
- Select the category that best describes the issue.
- Provide a brief description of the problem you are experiencing.
- Select the occurrence date of the issue.
- Select the occurrence time of the issue.
- Select the user affected by the issue.
- Select the location where the issue occurred.
- Choose the priority level of the issue.

## Field-by-Field Explanation
- **Report Category** (`report_category`, required/select_one):
  • This field determines the type of issue you are reporting. Please choose between "Technical" and "Non-Technical" to help us understand the nature of the problem.
- **Brief Description** (`brief_description`, required/text):
  • Provide a clear and concise description of the issue, including any relevant details or screenshots that can aid in troubleshooting.
- **Occurrence Date** (`occurrence_date`, required/date):
  • Enter the date when the issue first occurred or when you last experienced it.
- **Occurrence Time** (`occurrence_time`, required/time):
  • Enter the time when the issue first occurred or when you last experienced it.
- **Affected User** (`affected_user`, required/select_multiple):
  • Select the user who is experiencing the issue. Please choose one or more users from the list.
- **Location** (`location`, required/text):
  • Enter the location where the issue occurred or where you last experienced it.
- **Priority** (`priority`, required/select_one):
  • Choose the priority level of the issue: "High", "Medium", or "Low". This will help us understand the severity of the issue and allocate resources accordingly.
