# Vendor Quality Report Request Form - Help Guide
## Purpose
The Vendor Quality Report Request Form is a tool used to report and document quality issues with vendors. This form helps to track and address these concerns to ensure optimal vendor performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Severity level** of the issue (High/Low).
2. Provide **Vendor issue details** to describe the problem.
3. If necessary, **Upload evidence** to support your report.
4. Specify the **Date** and **Time** the issue occurred.
5. Categorize the issue as **Yes** or **No** for **Issue category**, **Issue severity**, **Issue status**, and **Issue type**.
6. Choose the **Issue priority** level (Yes/No).
7. Add any additional comments in **Form section 2**.
8. Click **Submit form** to finalize your report.

## Field-by-Field Explanation
### 1. **Severity Level** (`Severity Level`, `select_one`, Required)
Indicates the degree of severity of the reported issue. Please select either High or Low to indicate the level of severity.

### 2. **Vendor Issue Details** (`Vendor issue details`, `text`, Optional)
Please provide a brief description of the issue you are reporting.

### 3. **Evidence** (`Evidence`, `text`, Optional)
If you have supporting documentation or evidence, please upload it here.

### 4. **Date** (`Date`, `date`, Required)
Enter the date the issue occurred.

### 5. **Time** (`Time`, `time`, Required)
Enter the time the issue occurred.

### 6. **Issue Description** (`Issue description`, `text`, Optional)
Provide a brief description of the issue.

### 7. **Issue Category** (`Issue category`, `select_multiple`, Required)
Select all that apply for **Yes** or **No**.

### 8. **Issue Severity** (`Issue severity`, `select_one`, Required)
Select either **Yes** or **No** to indicate the level of severity.

### 9. **Issue Status** (`Issue status`, `select_one`, Required)
Select either **Active** or **Inactive** to indicate the status of the issue.

### 10. **Issue Type** (`Issue type`, `select_multiple`, Required)
Select all that apply for **Yes** or **No**.

### 11. **Issue Priority** (`Issue priority`, `select_one`, Required)
Select either **Yes** or **No** to indicate the priority level of the issue.

### 12. **Form Section 2** (`Form section 2`, `text`, Optional)
Add any additional comments or information here.

### 13. **Submit Form** (`Submit form`, `text`, Required)
Click this button to submit your report.
