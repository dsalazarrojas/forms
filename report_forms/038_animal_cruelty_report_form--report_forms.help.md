# Animal Cruelty Report Form - Help Guide
## Purpose
The Animal Cruelty Report Form is designed to gather information from individuals who suspect animal cruelty or neglect. This form will help our team investigate and address these situations effectively.

## How To Complete This Form
- Start by filling out the required fields with as much detail as possible.
- Use the provided help text for guidance on each field.
- Review each page carefully before submitting the form.

## Field-by-Field Explanation

* **Your Full Name** (1, text, required): Please enter your full name to enable us to contact you regarding the report.
* **Email Address** (2, email, required): Provide your email address so we can reach out to you for further information or clarification if needed.
* **Phone Number** (3, text, required): Enter your phone number for us to contact you.
* **Do You Want to Remain Anonymous** (4, select_one, required): Select 'Yes' to keep your information confidential.
* **Animal Cruelty Report Form** (5, note, required): This field is not required but can provide additional information about the report.
* **Date of Report** (6, date, required): Choose the current date to ensure accuracy.
* **Location of Incident** (7, text, required): Enter the address or a detailed description of the location where the incident occurred.
* **Type of Location** (8, select_one, required): Choose from the options provided to describe the location type (e.g., private residence, business, public area).
* **Date of Incident** (9, date, required): Enter the date on which the incident occurred.
* **Time of Incident** (10, time, optional): Enter the approximate time if the incident occurred.
* **Type of Cruelty or Neglect** (11, select_multiple, required): Select all that apply from the list of cruelty or neglect types.
* **Animal Information** (12, note, required): Provide any information about the animal (e.g., breed, age, health conditions).
* **Species** (13, select_one, required): Choose the type of animal involved (e.g., dog, cat, horse).
* **Breed if Known** (14, text, optional): Enter the animal's breed if known.
* **Physical Description** (15, text, optional): Describe the animal's color, size, and markings.
* **How Many Animals Are Involved** (16, select_one, required): Choose the number of animals affected.
* **Describe the Condition of the Animal** (17, text, required): Describe any visible injuries or conditions of the animal.
* **Are There Visible Injuries** (18, select_one, required): Choose whether there are visible injuries.
* **Describe Any Injuries Observed** (19, text, optional): Provide details about the injuries if visible.
* **Describe the Living Conditions** (20, text, required): Describe the environment where the animal was found.
* **Suspect Information** (21, note, optional): Provide information about the suspect or perpetrator.
* **Suspect Name if Known** (22, text, optional): Enter the suspect's name if known.
* **Suspect Description** (23, text, optional): Describe the suspect's physical appearance.
* **Relationship to Animal** (24, select_one, optional): Choose the suspect's relationship to the animal (e.g., owner, neighbor).
* **Describe What You Witnessed** (25, text, required): Provide a detailed account of what you saw or experienced.
* **Is This an Ongoing Situation** (26, select_one, required): Select 'Yes' if the situation is ongoing.
* **Are There Other Witnesses** (27, text, optional): Enter information about any other witnesses.
* **Do You Have Any Evidence** (28, select_one, required): Select if you have evidence (e.g., photos, videos).
* **Has This Been Reported Before** (29, select_one, optional): Select if this is a repeat report.
* **How Urgent Is This Situation** (30, select_one, required): Choose the urgency level of the situation.
* **Additional Comments** (31, text, optional): Enter any additional information that may be helpful.
* **Reporter Signature** (32, text, required): Sign with your full name.
* **Date** (33, date, required): Enter the current date.

## Tips

* Use clear and concise language when filling out the form.
* Double-check the fields for accuracy before submitting.
* If you are unsure about any field, use the provided help text for guidance.
* Report all incidents, even if you are unsure if it is a priority.
* If you have evidence, attach it to the report or provide a link.
* If you are reporting a situation that is not currently happening, select the date of the incident instead of the report date.
