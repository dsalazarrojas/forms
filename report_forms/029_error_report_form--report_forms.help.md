# Error Report Form - Help Guide
## Purpose
The Error Report Form is used to gather information about errors that have occurred in the system. This form helps the development team to identify and resolve issues efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the error in the **Error Description** field (page 2).
2. Select the **Error Status** (page 4) to indicate the current state of the error.
3. Choose the **Systems Affected** (page 5) that were impacted by the error.
4. Select the **Error Cause** (page 6) that led to the error.
5. Choose the **Error Reporter** (page 7) who reported the error.
6. Enter the **Error Location** (page 8) where the error occurred.
7. Enter the **Error Cause Detail** (page 9) for further explanation.
8. Enter your contact information, including your **Contact Email** (page 11), **Contact Method** (page 12), and **Submitter Email** (page 25).
9. If applicable, attach a file to the report by entering the **Attachment File Type** (page 17) and **Attachment File Status** (page 18).
10. Finally, enter the **Submit Date** (page 23) and select the **Submitter** (page 24) who is submitting the report.

## Field-by-Field Explanation

* **Error Report Form Title** (page 1): Enter a brief title for the report to help identify the issue.
* **Error Description** (page 2): Enter a detailed description of the error.
* **Error Date** (page 3): Enter the date the error occurred.
* **Error Status** (page 4): Select the current status of the error (e.g., new, in progress, resolved).
* **Systems Affected** (page 5): Select all systems that were impacted by the error.
* **Error Cause** (page 6): Select the root cause of the error.
* **Error Reporter** (page 7): Select the user who reported the error.
* **Error Location** (page 8): Enter the location where the error occurred.
* **Error Cause Detail** (page 9): Enter further details about the cause of the error.
* **Contact Information** (page 10): Enter your contact information, such as your name and email address.
* **Attachment File Type** (page 17): Select the type of attachment file (e.g., image, document).
* **Attachment File Status** (page 18): Select the status of the attachment (e.g., uploaded, pending).
* **Attachment Upload Date** (page 19): Enter the date the attachment was uploaded.
* **Attachment Upload User** (page 20): Enter the user who uploaded the attachment.
* **Submit Date** (page 23): Enter the date the report was submitted.
* **Submitter** (page 24): Select the user who submitted the report.
* **Submitter Email** (page 25): Enter the email address of the submitter.
