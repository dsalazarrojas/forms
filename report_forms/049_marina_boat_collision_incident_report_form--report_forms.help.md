# Marina Boat Collision Incident Report Form - Help Guide
## Purpose
The Marina Boat Collision Incident Report Form is used to report incidents involving collisions between boats at the marina. This form helps gather information to support the investigation and response to the incident.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the marina staff member's name and email address in the "Marina Staff" and "Marina Staff Email" fields, respectively.
2. Enter the name of the boat involved in the incident in the "Boat Name" field.
3. Select the date of the incident in the "Incident Date" field.
4. Enter the location of the incident in the "Location" field.
5. Describe the incident in detail in the "Incident Description" field.
6. If there are witness statements, enter them in the "Witness Statements" field.
7. If you have any photos or videos related to the incident, enter the file paths in the "Photos" and "Videos" fields.
8. If you have any supporting documents, enter the file paths in the "Supporting Documents" field.
9. If there are any other details not mentioned above, enter them in the "Other Details" field.
10. Select "Yes" or "No" for the following fields:
	* Witness List: Were there any witnesses?
	* Witness Vessels: Were any vessels involved?
	* Witness Crew: Were any crew members involved?
	* Boat Operator: Was the boat operator involved in the incident?
11. Enter the label for the Witness List, Witness Vessels, and Witness Crew fields.

## Tips
* Make sure to fill in all required fields.
* Use clear and concise language when describing the incident.
* If there are any witness statements, make sure to include them in the "Witness Statements" field.
* If you have any photos or videos related to the incident, make sure to include them in the "Photos" and "Videos" fields.
* If there are any supporting documents, make sure to include them in the "Supporting Documents" field.
