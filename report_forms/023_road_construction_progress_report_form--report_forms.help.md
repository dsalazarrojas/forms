# Road Construction Progress Report Form - Help Guide
## Purpose
The purpose of this form is to collect information about the progress of road construction projects. It is used to report on the status of projects, including any delays or issues that may have occurred.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all necessary information and data ready.
2. Complete all required fields (those marked as "true" in the form below).
3. Provide as much detail as possible for each field.

## Field-by-Field Explanation
* **Road Construction Progress Report Form** (`road_construction_progress_report_form`):
	+ This is the title of the form, which should not be completed by users.
* **Project Name** (`project_name`):
	+ Enter the name of the project being reported on.
* **Project Status** (`project_status`):
	+ Select the current status of the project from the options provided:
		- **On Track**: The project is progressing as planned.
		- **Delayed**: The project is behind schedule.
		- **On Hold**: The project is temporarily paused or delayed.
		- **Complete**: The project has been finished.
* **Project Status Details** (`project_status_details`):
	+ Provide a brief description of the project's status, including any relevant details or explanations.
* **Work Completed** (`work_completed`):
	+ Select all tasks or phases of work that have been completed:
		- **Concrete Foundation**: The foundation of the road has been completed.
		- **Structural Frame**: The structural framework of the road has been constructed.
		- **Glazing**: The road has been glazed or coated.
		- **Finishing Work**: The finishing touches, such as painting or sealing, have been completed.
* **Delay Reason** (`delay_reason`):
	+ Provide a brief description of the reason for any delay or issue.
* **Delay Date** (`delay_date`):
	+ Enter the date on which the delay or issue occurred.
* **Delay Date Time** (`delay_date_time`):
	+ Enter the time at which the delay or issue occurred.
* **Remarks** (`remarks`):
	+ Enter any additional comments or notes about the project.
* **Project Manager Name** (`project_manager_name`):
	+ Enter the name of the project manager responsible for the project.
* **Project Manager Email** (`project_manager_email`):
	+ Enter the email address of the project manager responsible for the project.
* **Project Manager Phone** (`project_manager_phone`):
	+ Enter the phone number of the project manager responsible for the project.
* **Site Manager Name** (`site_manager_name`):
	+ Enter the name of the site manager responsible for the site.
* **Site Manager Email** (`site_manager_email`):
	+ Enter the email address of the site manager responsible for the site.
* **Site Manager Phone** (`site_manager_phone`):
	+ Enter the phone number of the site manager responsible for the site.

## Tips
* Be as concise as possible when completing each field.
* Ensure all required fields are completed before submitting the form.
* If you are unsure about any field, contact your project manager or site manager for guidance.
