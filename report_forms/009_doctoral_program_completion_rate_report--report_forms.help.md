# Doctoral Program Completion Rate Report - Help Guide
## Purpose
The Doctoral Program Completion Rate Report is used to track the completion status of doctoral program graduates, providing essential data for institutional or organizational decision-making and evaluation.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **University Name** in the text field.
2. Enter the **Program Name** in the text field.
3. Select the **Completion Date** of the graduate in the date picker field.
4. Select the **Degree Type** (Yes/No) for the graduate.
5. Select the **Completion Outcome** (Yes/No) for the graduate.
6. Enter the **Student Name** in the text field.
7. Enter the **Student ID** in the text field.
8. Enter the **Graduate Name** in the text field.
9. Enter the **Graduating University** in the text field.
10. Enter the **Graduation Email** in the email field.
11. Enter the **Graduation Phone** (optional) in the text field.
12. Select the **Completion Status** (Active/Inactive) for the graduate.
13. Enter the **Completion Status Note** (optional) in the note field.
14. Enter the **Program Start Date** in the date picker field.
15. Enter the **Program End Date** in the date picker field.
16. Enter the **Graduation Year** in the number field.
17. Select the **Graduation Month** (Yes/No) for the graduate.
18. Select the **Graduation Quarter** (Yes/No) for the graduate (if applicable).
19. Select the **Student Location** (Yes/No) for the graduate.
20. Enter the **Graduation Address** in the text field.
21. Select the **Graduation Country** (Yes/No) for the graduate.
22. Enter the **Graduation City** in the text field.
23. Enter the **Graduation State** in the text field.
24. Enter the **Graduation Zip** in the text field.
25. Select the **Graduation Status** (Active/Inactive) for the graduate.
26. Enter the **Graduate Note** (optional) in the note field.

## Field-by-Field Explanation

* **University Name**: Enter the name of the university where the graduate was enrolled.
* **Program Name**: Enter the name of the doctoral program completed by the graduate.
* **Completion Date**: Select the date when the graduate completed the program.
* **Degree Type**: Indicate if the graduate completed the program (Yes) or did not (No).
* **Completion Outcome**: Indicate if the graduate completed the program (Yes) or did not (No).
* **Student Name**: Enter the name of the graduate.
* **Student ID**: Enter the student ID of the graduate.
* **Graduate Name**: Enter the graduate's name.
* **Graduating University**: Enter the university where the graduate received their degree.
* **Graduation Email**: Enter the email of the graduate.
* **Graduation Phone**: Enter the phone number of the graduate (if applicable).
* **Completion Status**: Select the current status of the graduate (Active/Inactive).
* **Completion Status Note**: Enter any additional information about the graduate's completion status (if applicable).
* **Program Start Date**: Select the date when the graduate started the program.
* **Program End Date**: Select the date when the graduate ended the program.
* **Graduation Year**: Enter the year of graduation.
* **Graduation Month**: Indicate if the graduate graduated in the same month as the program started (Yes/No).
* **Graduation Quarter**: Indicate if the graduate graduated within the same quarter as the program started (if applicable).
* **Student Location**: Indicate if the graduate is still located at the university (Yes/No).
* **Graduation Address**: Enter the address of the graduate.
* **Graduation Country**: Indicate if the graduate graduated within their own country (Yes/No).
* **Graduation City**: Enter the city where the graduate graduated.
* **Graduation State**: Enter the state where the graduate graduated.
* **Graduation Zip**: Enter the zip code of the graduate's location.
* **Graduation Status**: Select the current status of the graduate (Active/Inactive).
* **Graduate Note**: Enter any additional information about the graduate (if applicable).
