# it_request_form - Help Guide
## Purpose
This form is used to report internal IT issues that require assistance or resolution.
## How To Complete This Form
To fill out this form, follow these steps:

1. Enter a brief description of the software or hardware issue you're experiencing.
2. Select the urgency level of the issue (High, Medium, or Low).
3. Choose the category of the issue (Software or Hardware).
4. If necessary, add any additional status updates (New, In-progress, or Resolved).
5. Select the priority level of the issue (High, Medium, or Low).
6. Enter your contact email and phone number so we can reach you with updates.
7. Click the "Submit" button to send the form.

## Field-by-Field Explanation

- **software_issue** (1, text, required): Enter a brief description of the software-related issue you're experiencing.
- **hardware_issue** (2, text, required): Enter a brief description of the hardware-related issue you're experiencing.
- **urgency** (3, select_one, required): Select the urgency level of the issue (High, Medium, or Low).
- **description** (4, text, required): Briefly describe the issue in more detail.
- **category** (5, select_one, required): Choose the category of the issue (Software or Hardware).
- **status** (6, select_multiple, required): Add any additional status updates (New, In-progress, or Resolved).
- **priority** (7, select_one, required): Select the priority level of the issue (High, Medium, or Low).
- **submit** (8, text, required): This field is not visible to the user and is used for form submission, but it's required for the form to be submitted.
- **email_1** (9, email, required): Enter your contact email so we can reach you with updates.
- **phone_1** (10, text, required): Enter your contact phone number so we can reach you with updates.

## Tips
* Make sure to provide as much detail as possible to help us assist you efficiently.
* If you're experiencing multiple issues, fill out this form for each one.
* If you're unsure about any field, please ask us for clarification.
