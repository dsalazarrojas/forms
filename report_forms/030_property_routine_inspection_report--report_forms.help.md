# Property Routine Inspection Report - Help Guide
## Purpose

The Property Routine Inspection Report form is used to document the findings of a routine property inspection, collecting data on the condition and status of a property.

## How To Complete This Form

1. **Property Inspection Report** (`property_routine_inspection_report_form`): A text field for a brief summary of the inspection findings.
2. **House Number** (`house_number`): Enter the number of the property being inspected.
3. **Address** (`address`): Enter the address of the property being inspected.
4. **Date of Inspection** (`date_of_inspection`): Enter the date of the inspection.
5. **Time of Inspection** (`time_of_inspection`): Enter the time of the inspection.
6. **Inspector Name** (`inspector_name`): Enter the name of the person conducting the inspection.
7. **Inspection Notes** (`inspection_notes`): A text field for any additional comments or notes about the inspection.
8. **Images/Urls** (`images_urls`): Enter any images or URLs taken during the inspection.
9. **Property Routine Inspection Report Comments** (`property_routine_inspection_report_comments`): A text field for any comments about the inspection report.
10. **Assigned Tool** (`assigned_tool`): Select the tool used during the inspection from the available options.
