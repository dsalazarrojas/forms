# Resource Efficiency Measurement Report Form - Help Guide

## Purpose
This form is used to report on the efficiency of resources used in a business or industrial context. It gathers information on the type of resource, efficiency metric, date and time of measurement, and other relevant details.

## How To Complete This Form

To complete this form, follow these steps:

* Review the form sections and understand what information you are required to provide.
* Fill in the **Report 1**, **Report 2**, and **Report 3** fields, selecting the relevant options as needed.
* Enter the details of the **Resource Used** field.
* Select the **Efficiency Metric** that best describes the measurement.
* Choose the **Date of Measurement** and **Time of Measurement** fields using the respective input fields.
* Enter the **Resource Efficiency** value, if applicable.
* Select the **Measurement Location** and **Measurement Device** from the provided options.
* Provide any additional comments in the **Comments** field.
* Submit the form once all required fields are filled.

## Field-by-Field Explanation

* **Report 1** (Select): Please select from the options provided.
* **Report 2** (Select): Please select from the options provided.
* **Resource Used** (Text): Describe the resource used during the measurement.
* **Efficiency Metric** (Select): Select one of the three options:
	+ Efficiency
	+ Capacity
	+ Utilization
* **Date of Measurement** (Date): Enter the date on which the measurement was taken.
* **Time of Measurement** (Time): Enter the time at which the measurement was taken.
* **Resource Efficiency** (Number): Enter a numerical value to represent the resource efficiency.
* **Measurement Location** (Select): Select one of the three options: Location 1, Location 2, or Location 3.
* **Measurement Device** (Select): Select one of the three options: Device 1, Device 2, or Device 3.
* **Comments** (Text): Provide any additional comments or notes related to the measurement.
* **Report 3** (Select): Please select from the options provided.
