# Unreturned Item Report - Help Guide
## Purpose
The Unreturned Item Report form is used to document and track items that have not been returned by borrowers. This form ensures that accurate and consistent records are kept of unreturned items, allowing staff or administrators to quickly identify and address any issues related to unreturned items.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct borrower details from the options provided.
2. Enter the due date for the item that was not returned.
3. Enter the date the item was returned (if known).
4. Enter the number of days the item was overdue.
5. Provide a brief reason for why the item was not returned.
6. Enter any additional notes about the unreturned item.

## Field-by-Field Explanation

* **Borrower Details** (`borrower_details`, `select_one`, required: false): Select the borrower who did not return the item from the options provided. This field helps identify the borrower associated with the unreturned item.
* **Due Date** (`due_date`, `date`, required: false): Enter the date the item was due to be returned. This field ensures that the correct due date is documented.
* **Return Date** (`return_date`, `date`, required: false): Enter the date the item was returned (if known). This field provides information on when the item was actually returned.
* **Overdue Days** (`overdue_days`, `number`, required: false): Enter the number of days the item was overdue. This field helps calculate the duration of time the item was not returned.
* **Reason** (`reason`, `text`, required: false): Provide a brief explanation for why the item was not returned. This field helps identify the cause of the issue.
* **Notes** (`notes`, `text`, required: false): Enter any additional notes or comments about the unreturned item. This field provides extra context and information about the issue.

## Tips
* Make sure to select the correct borrower details to ensure accurate tracking.
* Enter the due date and return date accurately to ensure consistency.
* Be concise but thorough in providing the reason and notes for the unreturned item.
* If unsure about any field, consult with colleagues or supervisors for guidance.
