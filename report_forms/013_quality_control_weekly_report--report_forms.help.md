This form is used to record the Quality Control Weekly Report, which is a report used to track quality control issues and actions taken during the week. It helps to identify areas of improvement and ensure that quality control measures are being taken.

## Purpose
The purpose of this form is to provide a weekly report on quality control issues and actions taken.

## How To Complete This Form
To complete this form, simply follow these steps:

* Select the rating scale that best describes the quality of your work for the current week.
* Describe the issue that occurred and the corrective action taken.
* Indicate if any issues need to be escalated and why.
* Provide the rating for each issue that occurred.
* Enter the number of corrective actions taken for each issue.
* Enter the start and end time of the work period.
* Select the department involved in the quality control.
* Enter the date of the issue.
* Select the status of the issue.
* Add any notes on the escalation process and corrective actions.
* Enter the email and phone number of the team member or quality team.
* Provide the name of team members and quality team members involved.
* Enter the date of the issue.
* Enter any notes on escalation needs.

## Field-by-Field Explanation

* **Weekly Rating Scale**: This field is used to rate the quality of work for the current week. Select the scale that best describes your work, such as Good or Fair.
* **Issue Description**: This field is used to describe the issue that occurred. Be as detailed as possible so that others can understand the situation.
* **Corrective Action**: This field is used to describe the action taken to correct the issue.
* **Escalation Needs**: This field is used to indicate if any issues need to be escalated and why.
* **Rating 1, 2, 3**: These fields are used to rate each issue that occurred. Enter the rating for each issue.
* **Issues Rating**: This field is used to rate all issues that occurred. Enter the average rating of all issues.
* **Corrective Actions Taken**: This field is used to enter the number of corrective actions taken for each issue.
* **Corrective Actions Issued**: This field is used to enter the number of corrective actions issued for each issue.
* **Notes**: This field is used to enter any notes on the escalation process and corrective actions.
* **Start Time**: This field is used to enter the start time of the work period.
* **End Time**: This field is used to enter the end time of the work period.
* **Department**: This field is used to select the department involved in the quality control.
* **Date**: This field is used to enter the date of the issue.
* **Issue Status**: This field is used to select the status of the issue, such as Active or Inactive.
* **Notes Escalation**: This field is used to enter any notes on escalation needs.
* **Email**: This field is used to enter the email of the team member or quality team.
* **Phone Number**: This field is used to enter the phone number of the team member or quality team.
* **Team Member**: This field is used to enter the name of team members involved.
* **Team Leads**: This field is used to enter the name of team leads involved.
* **Quality Team Members**: This field is used to enter the name of quality team members involved.
* **Issue Date**: This field is used to enter the date of the issue.
* **Notes Escalation Needs**: This field is used to enter any notes on escalation needs.
* **Form Submitted**: This field is used to indicate if the form has been submitted or not.
