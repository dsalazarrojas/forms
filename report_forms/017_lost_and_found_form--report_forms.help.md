# Lost and Found Form - Help Guide
## Purpose

The lost and found form is used to collect information about a lost item. This form will help identify and locate the item.

## How To Complete This Form

To complete this form, follow these steps:

1.  Provide a detailed description of the lost item in the "Item Description" field.
2.  Select the category of the lost item from the "Item Category" dropdown menu.
3.  Enter the value of the lost item in the "Item Value" field.
4.  Describe the condition of the lost item in the "Item Condition" dropdown menu.
5.  Indicate whether the item was found or not in the "Item Location" dropdown menu.
6.  Enter the name of the person who found the item in the "Found By" field.
7.  Enter the name of the person reporting the lost item in the "Reported By" field.
8.  Select the date the item was found in the "Date Found" field.
9.  Select the date the item was reported in the "Date Reported" field.

## Field-by-Field Explanation

*   **Item Description (text, optional)**: Enter a detailed description of the lost item.
*   **Item Category (select multiple, optional)**: Select the category of the lost item from the available options.
*   **Item Value (number, optional)**: Enter the value of the lost item.
*   **Item Condition (select one, optional)**: Select the condition of the lost item from the available options.
*   **Item Location (select one, optional)**: Indicate whether the item was found or not.
*   **Found By (text, optional)**: Enter the name of the person who found the item.
*   **Reported By (text, optional)**: Enter the name of the person reporting the lost item.
*   **Date Found (date, optional)**: Select the date the item was found.
*   **Date Reported (date, optional)**: Select the date the item was reported.

## Tips

*   Enter accurate and detailed information to help identify and locate the lost item.
*   Review each field carefully before submitting the form.
*   If any required fields are not filled in, the form will not be submitted.
*   If you are unsure about the form, contact the relevant personnel for assistance.
