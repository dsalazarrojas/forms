# process-optimization-result-report-form - Help Guide
## Purpose
This form is designed to support process optimization by providing a structured template for users to report on their process improvements and outcomes.
## How To Complete This Form
To complete this form, simply fill in the required and optional fields as applicable to your process improvement report.

## Field-by-Field Explanation
* **Process Improvements** (`process_improvements`, note, false): Enter any process improvements made, if applicable.
* **KPIs** (`key_performance_indicators`, select_one, false): Select the KPIs that were measured or reviewed.
* **Target Metric** (`target_metric`, number, false): Enter the target metric or goal.
* **Current Metric** (`current_metric`, number, false): Enter the current metric or measurement.
* **Improvement Plan** (`improvement_plan`, text, false): Describe the plan for improvement, if applicable.
* **Action Items** (`action_items`, select_multiple, false): Select any action items associated with the process improvement.
* **Action Plan** (`action_plan`, text, false): Enter any details about the action plan, if applicable.
* **Expected Outcome** (`expected_outcome`, select_one, false): Select the expected outcome of the process improvement.
* **Actual Outcome** (`actual_outcome`, select_one, false): Select the actual outcome of the process improvement, if it has been completed.
* **Review Comments** (`review_comments`, text, false): Enter any review comments or feedback.
* **Reviewer** (`reviewer`, email, false): Enter the reviewer's email address.
* **Date Reviewed** (`date_reviewed`, date, false): Enter the date the process improvement was reviewed.

## Tips
* Please fill in all required fields, if applicable.
* For select_one or select_multiple fields, select one or multiple options from the dropdown list.
* For date fields, enter a date in the format MM/DD/YYYY.
* If you are not sure about any field, leave it blank or ask a colleague for guidance.
