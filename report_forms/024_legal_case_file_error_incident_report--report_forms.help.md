# Legal Case File Error Incident Report - Help Guide
## Purpose
The Legal Case File Error Incident Report form is used to report and document errors that occur within the legal case file process. This form collects detailed information about the incident, including the error type, description, date, and time it occurred, as well as the status and assigned user.

## How To Complete This Form
To complete this form, follow these steps:

1. **Report Details**: Fill in the details of the error in the "Report Details" section.
2. Enter the **Case File** number, which is the unique identifier for the case file related to the error.
3. Select the **Error Type** from the provided options (System, User, or Other).
4. Describe the **Error Description** in a few sentences.
5. Enter the **Incident Date** and **Incident Time** when the error occurred.
6. Select the **Assigned User** who is responsible for handling the case file.
7. Choose the **Incident Status** from the provided options (Open, Closed, or Escalated).

## Field-by-Field Explanation

* **Case File**: Enter the unique identifier for the case file related to the error. This field is required.
* **Error Type**: Select the type of error that occurred (System, User, or Other). This field is required.
* **Error Description**: Provide a brief description of the error. This field is required.
* **Incident Date**: Enter the date when the error occurred.
* **Incident Time**: Enter the time when the error occurred.
* **Assigned User**: Select the user responsible for handling the case file. This field is required.
* **Incident Status**: Choose the status of the case file (Open, Closed, or Escalated). This field is required.
* **System**: Select this option if the error occurred due to a system issue.
* **User**: Select this option if the error occurred due to user action.
* **Other**: Select this option if the error occurred due to something else.
* **Open**: Choose this option if the case file is still pending resolution.
* **Closed**: Choose this option if the case file has been resolved.
* **Escalated**: Choose this option if the case file has been escalated to a higher level of handling.
