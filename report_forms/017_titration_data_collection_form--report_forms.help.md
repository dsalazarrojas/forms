# Titration Data Collection Form - Help Guide
## Purpose
This form is used to collect data for titration experiments.

## How To Complete This Form
1. To complete this form, start by selecting the correct page for the information you are providing.
2. Read each field carefully and provide the required information. Each page has a unique set of fields, so ensure you complete all the fields on each page before proceeding.
3. Once you have completed all the fields, review your answers to ensure they are accurate and complete.

## Field-by-Field Explanation
### Experiment Details (page1)
* **Experiment Title**: (`title`, text, required/optional) - A brief title for the experiment you are conducting.
* **Experiment Notes**: (`notes`, text, required/optional) - Any additional notes or information about the experiment.
### Equipment and Methods (page2)
* **Equipment Used**: (`equipment`, text, required/optional) - A list of equipment used during the experiment.
* **Methods**: (`methods`, text, required/optional) - A description of the methods used to conduct the experiment.
### Submission Information (page3)
* **Date of Submission**: (`date_of_submission`, text, required/optional) - The date you are submitting the form.
* **Name of Investigator**: (`name_of_investigator`, text, required/optional) - The name of the person conducting the experiment.
### Additional Information (page4)
* **Additional Comments**: (`additional_comments`, text, required/optional) - Any additional comments or information about the experiment.
### Experiment Details (2) (page5)
* **Experiment Description**: (`experiment_description`, text, required/optional) - A description of the experiment you are conducting.
* **Experimental Conditions**: (`experimental_conditions`, text, required/optional) - A list of experimental conditions used.
### Final Information (page6)
* **Verification Statement**: (`verification_statement`, text, required/optional) - A statement verifying the accuracy of the data.

### Tips
* Please ensure you complete all required fields.
* Double-check your answers for accuracy and completeness.
* If you have any questions or concerns, contact the relevant authorities.
* You can submit multiple forms if you have multiple experiments to report.
