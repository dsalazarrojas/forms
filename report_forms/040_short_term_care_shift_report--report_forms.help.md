# short_term_care_shift_report - Help Guide
## Purpose
This form is used to report on short-term care shift details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for each field as prompted.
2. Complete all required fields (indicated by a *asterisk*) and review the optional fields as needed.
3. Enter accurate and relevant information in each field.
4. Review your entries for completeness and correctness.

## Field-by-Field Explanation
### Shift Details
* Shift Details*: Enter a brief description of the shift, including the type of care provided and any relevant notes.
* 
* Start Date*: Enter the start date of the shift in the YYYY-MM-DD format.
* 
* Start Time*: Enter the start time of the shift in the 12-hour format (e.g., 08:00 for 8:00 AM).
* 
* End Date*: Enter the end date of the shift in the YYYY-MM-DD format.
* 
* End Time*: Enter the end time of the shift in the 12-hour format (e.g., 17:00 for 5:00 PM).
* 
* Shift Duration*: Enter the duration of the shift, measured in minutes.
* 
* Notes*: Enter any additional notes or comments about the shift.
* 
* Handover Notes*: Enter any information that needs to be passed on to the next caregiver, including relevant details or reminders.
