# Email Server Network Traffic Monitoring Log - Help Guide
## Purpose
The Email Server Network Traffic Monitoring Log form is intended for network administrators or IT staff to collect and record email server performance data. This data includes category, start and end dates, specific events or issues, IP addresses, server name, and server IP.

## How To Complete This Form
To complete this form, follow these steps:
1. Select a category for your email server monitoring log (e.g., Email, Security, or Technical).
2. Choose the start and end dates for the monitoring period.
3. Describe any email traffic events or issues encountered during the monitoring period.
4. Enter the IP addresses affected by the monitoring.
5. Identify the server name and IP address.

## Field-by-Field Explanation

* **Category** (Category, Select One, Required): Select a category for your email server monitoring log, such as Email, Security, or Technical.
* **Start Date** (Start Date, Date, Required): Enter the start date of the monitoring period.
* **End Date** (End Date, Date, Required): Enter the end date of the monitoring period.
* **Email Traffic Events** (Email Traffic Events, Text, Required): Describe any email traffic events or issues encountered during the monitoring period.
* **IP Addresses** (IP Addresses, Text, Required): Enter the IP addresses affected by the monitoring.
* **Server Name** (Server Name, Text, Required): Identify the server name involved in the monitoring.
* **Server IP** (Server IP, Text, Required): Enter the server IP address involved in the monitoring.

## Tips
- Be as specific as possible when describing email traffic events or issues.
- Ensure you accurately select the category and start and end dates for the monitoring period.
- Double-check the IP addresses and server name and IP for accuracy.
