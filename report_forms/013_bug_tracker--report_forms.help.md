# Bug Tracker - Help Guide
## Purpose
The Bug Tracker form is a tool used to collect and report technical issues with our software products. It helps our development team to identify and fix problems efficiently, so we can provide the best possible user experience. Fill out this form to report any bugs, feature requests, or other issues you encounter while using our software. Make sure to provide detailed descriptions and step-by-step guides where possible.

## How To Complete This Form

1. **Submitter Name (1)**: Enter your full name as the one who is submitting the report.
2. **Email Address (2)**: Enter your contact email address so we can reach you for further questions or updates.
3. **Submission Date (3)**: This field is automatically populated with the current date.
4. **Product (4)**: Select the product you are experiencing issues with.
5. **Version (5)**: Enter the version of the software you are using.
6. **Issue Type (6)**: Choose the type of issue you are experiencing (e.g., Bug, Feature Request).
7. **Severity (7)**: Rate the severity of the issue (e.g., Critical, High, Medium).
8. **Priority (8)**: Choose the fix priority (e.g., Immediate, High, Normal, Low, Deferred).
9. **Browser Information (9)**: If applicable, enter details about the browser you are using.
10. **Operating System (10)**: If applicable, enter details about the OS you are using.
11. **User Agent String (11)**: If applicable, enter the auto-detected User Agent String.
12. **Issue Title (12)**: Enter a short summary of the issue.
13. **Issue Description (13)**: Enter a detailed description of the issue.
14. **Steps to Reproduce (14)**: Provide a numbered list of steps to reproduce the issue.
15. **Expected Behavior (15)**: Describe the expected behavior.
16. **Actual Behavior (16)**: Describe what actually occurred.
17. **Reproducibility (17)**: Rate how often you are able to reproduce the issue.
18. **Additional Information (18)**: Enter any other relevant details about the issue.
19. **Screenshots Available (19)**: Check if you have attached screenshots and if so, mark as true.
