# Daily Consumption Report Form - Help Guide

## Purpose
The "Daily Consumption Report Form" is designed to collect daily consumption data from users. This data includes sales performance, consumption dates, and other related information. It helps users track their sales and consumption patterns regularly.

## How To Complete This Form
To complete this form, follow these steps:
1. Go to the first page titled "Daily Consumption Report".
2. Enter a brief description or header for your report in this section.
3. Select or enter the "Consumption Date" for the data you're reporting.
4. Choose the "Sales Data" status from the dropdown menu ("Yes" or "No").
5. Enter the "Sales Amount" for the reported date.

## Field-by-Field Explanation
### Daily Consumption Report
- **Daily Consumption Report** (`daily_consumption_report_form_page_1`, `note`, required: false): This is the main description or header for your report. Enter a brief text describing the report you're creating.

### Consumption Date
- **Consumption Date** (`consumption_date`, `date`, required: false): This field is for selecting or entering the date of consumption.

### Sales Data
- **Sales Data** (`sales_data`, `select_multiple`, required: false): Use this dropdown menu to indicate the sales data status ("Yes" or "No") for the selected date.

### Sales Amount
- **Sales Amount** (`sales_amount`, `number`, required: false): Enter the actual sales amount for the reported date in currency.

## Tips
- Double-check your entries for accuracy, especially dates and numbers.
- Ensure you're reporting on the correct consumption date for each entry.
