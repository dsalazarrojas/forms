# Machine Calibration Report Form - Help Guide
## Purpose
The Machine Calibration Report Form is used to capture information related to machine calibration. This includes details such as the technician's name, machine identifier, location, and serial number, as well as the date of calibration, next calibration due date, and the current calibration status. The form also allows for optional notes and comments to be added.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the technician's name in the "Technician Name" field.
2. Provide the machine's identifier in the "Machine Identifier" field.
3. Specify the machine's location in the "Machine Location" field.
4. Enter the machine's serial number in the "Serial Number" field.
5. Choose the date of calibration using the calendar icon in the "Date Of Calibration" field.
6. Select the next calibration due date using the calendar icon in the "Next Calibration Due" field.
7. Choose the current calibration status from the dropdown menu in the "Calibration Status" field.
8. Add any additional comments or notes in the "Comments" field.
9. If applicable, enter the technician's email address in the "Email" field and their phone number in the "Phone Number" field.
10. Finally, specify the assigned tool in the "Assigned Tool" field.

## Field-by-Field Explanation

* **Technician Name** (text): Enter the name of the technician who performed the calibration.
* **Machine Identifier** (text): Enter the identifier or model number of the machine that was calibrated.
* **Machine Location** (text): Enter the location where the machine is installed or used.
* **Serial Number** (text): Enter the serial number of the machine that was calibrated.
* **Date Of Calibration** (date): Choose the date on which the machine was calibrated using the calendar icon.
* **Next Calibration Due** (date): Select the date on which the next calibration is due using the calendar icon.
* **Calibration Status** (select_one): Choose the current status of the machine's calibration from the dropdown menu.
	+ Calibrated: The machine has been calibrated within the specified period.
	+ Not Calibrated: The machine has not been calibrated yet.
	+ Pending: The machine is pending calibration.
* **Notes** (text): Add any additional comments or notes related to the calibration.
* **Email** (email): If applicable, enter the technician's email address.
* **Phone Number** (text): If applicable, enter the technician's phone number.
* **Assigned Tool** (text): Specify the tool assigned to the machine for calibration.
* **Comments** (text): Add any additional comments or notes related to the machine or calibration process.

Tips:

* Make sure to provide accurate information to ensure the machine's calibration record is up-to-date.
* Use the calendar icons to select the correct dates for calibration and next calibration due.
* Choose the correct calibration status to reflect the machine's current condition.
* Keep the comments field for any additional information or notes.
