# Report Antisemitism Incident - Help Guide
## Purpose
This form is designed to collect reports of antisemitism incidents. Please use this form to provide a detailed report of the incident, including your identity and the incident details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Incident Report" page to start filling out the form.
2. On the "Incident Report" page, fill out the "Reporter Information" field to select your title (Mr, Ms, or other).
3. Choose the type of incident you experienced (Bullying, Harassment, Intimidation, or Other).
4. Enter the date the incident occurred.
5. Indicate whether you would like to be followed up on (True or False).
6. If you have additional follow-up information, enter it in the "Follow-up Information" field.
7. Select where the incident was reported (School, Workplace, Organization, or Other).
8. Provide a detailed description of the incident.
9. Select the status of the incident (Active, Inactive, or Completed).

## Field-by-Field Explanation

* **Incident Report** (`incident_report`, text, optional): This is the main page where you start filling out the form. It is a text field where you can describe the incident in detail.
* **Reporter Information** (`reporter_info`, select_one, optional): Select your title (Mr, Ms, or other) from the dropdown menu.
* **Incident Details** (`incident_details`, select_multiple, optional): Choose the type of incident you experienced (Bullying, Harassment, Intimidation, or Other).
* **Date** (`incident_date`, date, optional): Enter the date the incident occurred.
* **Follow-up** (`follow_up`, select_one, optional): Select whether you would like to be followed up on (True or False).
* **Follow-up Information** (`follow_up_info`, text, optional): If you would like to be followed up on, enter any additional information about the follow-up.
* **Report** (`incident_reported_to`, select_one, optional): Select where the incident was reported (School, Workplace, Organization, or Other).
* **Description** (`incident_description`, text, optional): Provide a detailed description of the incident.
* **Status** (`incident_status`, select_one, optional): Select the status of the incident (Active, Inactive, or Completed).
