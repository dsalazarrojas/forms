# Interim Report Form - Help Guide
## Purpose
The Interim Report Form is a tool used to create a report on project information. This form is designed to collect project-level details, such as status, goals, and completion dates. It is intended to provide a comprehensive summary of a project's progress and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name in the **Project Name** field. This should be a brief description of the project.
2. Select the project status in the **project_status** field. Choose from two options: Active or Inactive.
3. If applicable, enter the project manager's name in the **project_manager** field.
4. Enter the start and end dates of the project in the **start_date** and **end_date** fields respectively. Use the date formats expected by your organization (e.g., mm/dd/yyyy or dd/mm/yyyy).
5. Provide the project location in the **location** field.
6. Enter any additional notes about the project in the **notes** field.
7. Enter the email address of the recipient who should receive the report in the **recipient_email** field.
8. Enter the phone number of the recipient who should receive the report in the **recipient_phone** field.
9. Enter the date and time when the report is submitted in the **submit_date** and **submit_time** fields respectively.
10. Enter your name as the submitter of the report in the **submitter** field.
11. Enter any additional comments about the report in the **comments** field.
12. If necessary, upload a file related to the project in the **Upload File** field.

## Field-by-Field Explanation
* **Project Name**: Enter a brief description of the project.
* **project_status**: Select the current status of the project, either Active or Inactive.
* **project_manager**: If applicable, enter the project manager's name.
* **start_date**: Enter the start date of the project.
* **end_date**: Enter the end date of the project.
* **location**: Provide the project location.
* **notes**: Enter any additional notes about the project.
* **recipient_email**: Enter the email address of the recipient who should receive the report.
* **recipient_phone**: Enter the phone number of the recipient who should receive the report.
* **submit_date**: Enter the date when the report is submitted.
* **submit_time**: Enter the time when the report is submitted.
* **submitter**: Enter your name as the submitter of the report.
* **comments**: Enter any additional comments about the report.
* **Upload File**: If necessary, upload a file related to the project.

## Tips
* Make sure to fill in all required fields.
* Use the correct date formats for start and end dates.
* Double-check the recipient's email and phone number for accuracy.
* Ensure that you have permission to submit the report to the recipient.
