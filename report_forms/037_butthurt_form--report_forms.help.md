# Butthurt Form - Help Guide
## Purpose
The Butthurt Form is a tool designed to help individuals report incidents or complaints, providing details about the incident, their experience, and desired outcomes. This form is used to gather information that will help address the issue and prevent similar incidents in the future.

## How To Complete This Form

1. Ensure you have a clear understanding of what you want to report.
2. Fill in the required fields marked with an asterisk (\*).
3. For fields with options, select the most accurate response.
4. Provide as much detail as possible in the text fields.

## Field-by-Field Explanation

* **Your Name** (`complainant_name`, text, required): Enter your full name as it appears on your identification documents.
* **Email Address** (`complainant_email`, email, required): Enter your contact email address.
* **Phone Number** (`complainant_phone`, text, optional): Enter your phone number if you'd like to be contacted.
* **Date of Incident** (`report_date`, date, required): Enter the date the incident occurred or is expected to occur.
* **Time of Incident** (`report_time`, time, optional): Enter the approximate time the incident occurred or is expected to occur.
* **Location of Incident** (`incident_location`, text, required): Enter the location where the incident happened or is expected to happen.
* **Type of Incident** (`incident_type`, select_one, required): Select the type of complaint from the options provided:
	+ Verbal abuse or disrespect
	+ Unfair treatment or discrimination
	+ Threatening behavior
	+ Offensive comment or language
	+ Exclusion or ostracizing
	+ Bullying or harassment
	+ Breach of confidence
	+ Other offense
* **Names of Involved Parties** (`involved_parties`, text, required): Enter the names of people involved in the incident.
* **Were There Witnesses?** (`witness_present`, select_one, required): Select whether there were witnesses:
	+ Yes, there were witnesses
	+ No witnesses present
	+ Unsure
* **Witness Names (if applicable)** (`witness_names`, text, optional): Enter the names of people who witnessed the incident if applicable.
* **Detailed Description of Incident** (`incident_description`, text, required): Provide a detailed account of what happened.
* **How This Incident Affected You** (`impact_on_reporter`, text, required): Explain the emotional, professional, or personal impact of the incident on you.
* **Severity Level** (`severity_level`, select_one, required): Select the level of severity:
	+ Minor irritant
	+ Moderate offense
	+ Serious concern
	+ Critical or severe
* **Have You Reported This Before?** (`prior_complaints`, select_one, required): Select whether you've reported this incident before:
	+ No, first report
	+ Yes, reported once
	+ Yes, reported multiple times
* **If Reported Before, Was It Resolved?** (`prior_resolution`, select_one, optional): Select whether the previous incident was resolved:
	+ Yes, resolved
	+ Partially resolved
	+ Not resolved
	+ N/A
* **Desired Resolution or Outcome** (`desired_resolution`, text, required): Describe the desired resolution or outcome.
* **Supporting Documentation Available** (`supporting_documentation`, select_one, optional): Select whether you have supporting documentation:
	+ Yes, evidence available
	+ No documentation available
	+ Some documentation available
* **Confidentiality or Privacy Concern** (`confidentiality_needed`, select_one, required): Select your preference for confidentiality:
	+ Yes, keep confidential
	+ No, can be disclosed
	+ Confidential within certain circles
* **Additional Context or Background** (`additional_context`, text, optional): Provide any additional relevant information.
* **May We Contact You for Follow-Up?** (`follow_up_contact`, select_one, required): Select whether you'd like to be contacted for follow-up:
	+ Yes, contact me
	+ No, prefer not to be contacted
	+ Only if necessary

This guide should help users understand the form's purpose and how to complete it accurately, ensuring they provide the necessary information for incident reporting and desired resolution.
