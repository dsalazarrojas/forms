# Hardware Issue Report Form - Help Guide
## Purpose
This form is designed to collect information about hardware-related issues that users are experiencing. It is intended to gather details about the problem, including the product involved, the issue's description, and the user's contact information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your First Name and Last Name in the corresponding fields.
2. Enter your Email and Phone numbers for us to contact you if needed.
3. Specify the Product Name that is experiencing the issue.
4. Describe the issue in detail in the Issue Description field.
5. Provide the date and time when the issue occurred in the Issue Date and Issue Time fields.
6. Enter the location where the issue occurred in the Issue Location field.
7. Select the Report Type (Hardware, Software, or Other).
8. Choose the relevant Hardware Type (Desktop, Laptop, or Mobile) if you selected "Hardware" as the Report Type.
9. Select the Operating System (Windows, Linux, or Other) used on the affected device.
10. Choose the Browser (Chrome, Firefox, or Safari) used on the affected device.
11. Enter the Version of the software or operating system used.
12. Describe the steps you took to reproduce the issue in the Steps to Reproduce field.
13. If applicable, provide an Error Message related to the issue.
14. Upload a Screenshot of the issue (optional but highly recommended).

## Field-by-Field Explanation
* **First Name**: Enter your first name for identification purposes.
* **Last Name**: Enter your last name for identification purposes.
* **Email**: Enter your email address so we can contact you about the issue.
* **Phone**: Enter your phone number for further communication.
* **Product Name**: Enter the name of the product experiencing the issue.
* **Issue Description**: Describe the issue you're experiencing in detail.
* **Issue Date**: Enter the date the issue occurred.
* **Issue Time**: Enter the time the issue occurred.
* **Issue Location**: Enter the location where the issue occurred.
* **Report Type**: Select the type of report (Hardware, Software, or Other).
* **Hardware Type**: Choose the type of hardware involved (Desktop, Laptop, or Mobile) if you selected "Hardware" as the Report Type.
* **Operating System**: Choose the operating system used on the affected device (Windows, Linux, or Other).
* **Browser**: Choose the browser used on the affected device (Chrome, Firefox, or Safari).
* **Version**: Enter the version of the software or operating system used.
* **Steps to Reproduce**: Describe the steps you took to reproduce the issue.
* **Error Message**: If applicable, enter the error message related to the issue.
* **Screenshot**: Optionally, upload a screenshot of the issue (recommended for better understanding).
* **Other**: If you've selected "Other" as the Report Type, describe the issue in detail in this field.
