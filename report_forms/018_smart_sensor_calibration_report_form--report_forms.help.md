# Smart Sensor Calibration Report Form - Help Guide
## Purpose
The Smart Sensor Calibration Report Form is designed to capture detailed information about the calibration process of smart sensors. This includes the calibration status, date, technician, and location, as well as the sensor's serial number, ID, and data.

## How To Complete This Form
To complete this form, follow these steps:

1. **Smart Sensor Calibration Report Form Page 1**: Start by filling in the title of the form.
2. **Calibration Details (Page 2)**: Enter the calibration status, date, and technician who performed the calibration. Select the status from the dropdown menu, enter the date using the date picker, and select the technician from the dropdown menu.
3. **Calibration Status (Page 3)**: Select the status of the calibration from the dropdown menu.
4. **Calibration Date (Page 4)**: Enter the date of the calibration.
5. **Calibration Technician (Page 5)**: Select the technician who performed the calibration.
6. **Report Status (Page 6)**: Select the status of the report from the dropdown menu.
7. **Sensor Type (Page 7)**: Select whether the sensor is calibrated ("Yes" or "No") or if it is an "Other" type.
8. **Equipment Serial Number (Page 8)**: Enter the serial number of the calibrated equipment.
9. **Calibration Number (Page 9)**: Enter the calibration number.
10. **Sensor Calibration Frequency (Page 10)**: Enter the frequency of the calibration.
11. **Report Number (Page 11)**: Enter the report number.
12. **Sensor Serial Number (Page 12)**: Enter the serial number of the sensor.
13. **Sensor ID (Page 13)**: Enter the ID of the sensor.
14. **Smart Sensor Calibration Report Form Page 14**: Enter any additional comments about the calibration.
15. **Sensor Data (Page 15)**: Optional - enter any relevant sensor data (not required).
16. **Calibration Location (Page 17)**: Enter the location where the calibration was performed.
17. **Additional Comments (Page 18)**: Enter any additional comments or notes about the calibration.
