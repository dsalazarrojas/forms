# Material Hardness Test Report Form - Help Guide

## Purpose
This form is designed to record the results of a material hardness test. The form is used to collect information about the material being tested, the test temperature, test time, test method, and test results. It is intended to help you accurately report your findings and track your test results in an organized manner.

## How To Complete This Form

1. To start, fill out the required fields on **Page 1**:
	* **test_form** (`material_hardness_test_report_form`, text, required): Enter a brief description of the material being tested.
	* **test_temperature** (test_temperature, number, optional): Enter the temperature at which the test was performed (in degrees).
2. Proceed to **Page 2** and fill out the optional fields:
	* **material_hardness_tested_item** (tested_item, text, optional): Enter a detailed description of the material being tested (e.g., type of metal or polymer).
	* **test_time** (test_time, number, optional): Enter the amount of time the test took to complete (in minutes).
	* **test_method** (test_method, select_one, optional): Select the method used to conduct the test (e.g., scratch test or hardness tester).
	* **test_result** (test_result, select_multiple, optional): Select all applicable test results (e.g., Option 1, Option 2, and Option 3).
	* **comments** (comments, note, optional): Enter any additional comments or notes about the test.

## Tips
* Be sure to complete all required fields on **Page 1**.
* If you need to enter multiple test results, select all applicable options in **test_result**.
* If you have any additional comments or notes about the test, enter them in the **comments** field.
