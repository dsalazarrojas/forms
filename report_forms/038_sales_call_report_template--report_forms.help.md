# Sales Call Report Template - Help Guide
## Purpose

This template is used to document sales calls and provide relevant information about the customer, sales representative, and details of the call. It helps to track and manage sales call data, which can be used to improve sales performance and customer relationships.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the **Customer Name** field with the name of the customer you interacted with.
2. Enter the **Customer Number** if applicable.
3. Select whether the call was successfully closed by a **Sales Rep**.
4. Choose the **Date of Call** when the sales call took place.
5. Select the **Time of Call**.
6. (Optional) You can submit the form without completing all fields, as they are not required.

## Field-by-Field Explanation

* **Report Form** (`report_form`, text, Optional): This field is for any additional comments or details about the sales call.
* **Customer Name** (`customer_name`, text, Optional): Enter the name of the customer you interacted with.
* **Customer Number** (`customer_number`, text, Optional): Enter the customer's account number (if applicable).
* **Sales Rep** (`sales_rep`, select_one, Optional): Select 'Yes' if the call was successfully closed by a sales representative.
* **Date of Call** (`date_of_call`, date, Optional): Choose the date the sales call took place.
* **Time of Call** (`time_of_call`, time, Optional): Select the time of the sales call.

## Tips

* Make sure to complete as many fields as possible to provide a comprehensive report.
* If you are unsure about a field, you can leave it blank or enter an approximation.
* This template is meant to be a quick and simple way to document sales calls.
