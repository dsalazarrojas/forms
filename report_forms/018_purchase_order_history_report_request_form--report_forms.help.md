# Purchase Order History Report Request Form - Help Guide
## Purpose
The Purchase Order History Report Request Form is used to request a report on the history of purchase orders. This form is used to collect information to generate a report that meets your specific requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for your report in the **Title** field.
2. Select a start date for your report period in the **Date** field.
3. Select an end date for your report period in the **Date to** field.
4. Optionally, select a category for your report in the **Category** field.
5. Select a status for your report in the **Status** field.
6. You can optionally provide comments for your report in the **Comments** field.

## Field-by-Field Explanation
### 1. **Title**
* **Title** (text): Enter a title for your report.
* Required: No

### 2. **Date**
* **Date** (date): Select the start date for your report period.
* Required: No

### 3. **Date to**
* **Date to** (date): Select the end date for your report period.
* Required: No

### 4. **Category**
* **Category** (select one): Select whether you want the report to include internal, external, or both categories.
* Required: No

### 5. **Category Options**
* **Category** (select multiple): Select specific categories to include in your report. (Internal, External, Both)
* Required: No

### 6. **Status**
* **Status** (select one): Select whether you want the report to include active, inactive, or all statuses.
* Required: No

### 7. **Status Options**
* **Status** (select multiple): Select specific statuses to include in your report. (Draft, Submitted, Approved)
* Required: No

### 8. **Comments**
* **Comments** (text): Provide any additional comments for your report.
* Required: No

### 9. **Comments**
* **Comments** (text): Repeat of the **Comments** field. This is likely a duplicate field and can be ignored.
* Required: No
