# Safeguarding Reporting Form - Help Guide
## Purpose
The purpose of this form is to collect incident information for safety and security purposes. This will help prevent and address potential issues within the organization.

## How To Complete This Form
1. Review each page carefully to ensure you have all the necessary information.
2. Fill out the form accurately and completely.
3. If you are unsure about any field, contact the relevant person or department for guidance.

## Field-by-Field Explanation

* **Incident Details** (`page_3`, `select_multiple`, required): This field is used to confirm if the incident occurred.
	+ Please select "Yes" if the incident occurred, "No" if it did not.
* **Reporting Person** (`page_4`, `text`, required): This field is used to identify the person reporting the incident.
	+ Please enter your name as it appears on your personnel record.
* **Witness Information** (`page_8`, `select_multiple`, required): This field is used to confirm if witnesses were involved in the incident.
	+ Please select "Yes" if there were witnesses, "No" if there were not.
* **Reporting Person Contact Information** (`page_9`, `text`, required): This field is used to provide contact information for the reporting person.
