# nc_reporting_2019 - Help Guide
## Purpose
The nc_reporting_2019 form is used to report non-conformances and other issues related to equipment, tools, and other assets.

## How To Complete This Form
To complete this form, follow these steps:

1.  Ensure you have all necessary information before filling out this form.
2.  Select the assigned tool from the dropdown menu.
3.  Enter the reporting date and time in the correct formats.
4.  Specify the reporting time zone, if applicable.
5.  Enter the offset value, if necessary.
6.  Provide the location of the non-conformance.
7.  Optionally, add any additional notes about the non-conformance.

## Field-by-Field Explanation

*  **Non Conformance** (`Non Conformance`, `note`, required: no): Briefly describe the non-conformance or issue reported.
*  **Reporting Date** (`Reporting Date`, `date`, required: no): Enter the date when the non-conformance was observed. Please use the format `YYYY-MM-DD`.
*  **Reporting Time** (`Reporting Time`, `time`, required: no): Enter the time when the non-conformance was observed. Please use the format `HH:MM:SS` or `HH:MM`.
*  **Reporting Time Zone** (`Reporting Time Zone`, `text`, required: no): If the non-conformance occurred in a specific time zone, enter it here.
*  **Reporting Time Offset** (`Reporting Time Offset`, `number`, required: no): If applicable, enter the offset from the standard time zone.
*  **Reporting Location** (`Reporting Location`, `text`, required: no): Specify the location where the non-conformance was observed.
*  **Assigned Tool** (`Assigned Tool`, `select_one`, required: yes): Select the tool that is associated with the non-conformance from the dropdown menu. This is a required field as it helps to quickly identify the affected tool.
*  **Reporting Person** (`Reporting Person`, `text`, required: no): Enter your name and contact information.
*  **Reporting Notes** (`Reporting Notes`, `text`, required: no): Provide any additional information or context about the non-conformance.

## Tips
*   Ensure that you have all necessary information before filling out this form.
*   If you're unsure about any field, refer to your team or supervisor for guidance.
*   This form is for reporting non-conformances and other issues related to equipment, tools, and other assets.
