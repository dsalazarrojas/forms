# CrowdStrike Incident Response Form - Help Guide
## Purpose
The form is used for gathering information about incidents to facilitate efficient incident response and management.

## How To Complete This Form
To complete this form, select the relevant information for each field and provide a detailed description of the incident. Some fields are marked as required, please ensure these fields are filled in before submitting the form.

## Field-by-Field Explanation

*   **Incident Type** (`incident_type`, select_one): Select the type of incident from the options (e.g., Phishing Attack, Malware Attack).
*   **Incident Location** (`incident_location`, select_one): Choose the location where the incident occurred (e.g., Remote, Local).
*   **Incident Date** (`incident_date`, date): Enter the date of the incident (YYYY-MM-DD).
*   **Incident Time** (`incident_time`, time): Enter the time of the incident (HH:MM:SS).
*   **Incident Description** (`incident_description`, text): Provide a detailed description of the incident.
*   **Incident Severity** (`incident_severity`, select_one): Select the severity of the incident from the options (Low, Medium, High).
*   **Incident Status** (`incident_status`, select_one): Choose the status of the incident from the provided options (Resolved, In Progress, Pending).
*   **Incident Response** (`incident_response`, text): Enter any additional comments or response actions taken.
*   **Incident Comments** (`incident_comments`, text): Provide any further comments or details about the incident.
