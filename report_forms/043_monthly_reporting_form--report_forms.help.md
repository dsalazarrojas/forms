# Monthly Reporting Form - Help Guide
## Purpose
This form is designed to provide a quick and easy way to report on project progress.

## How To Complete This Form

* Read the form carefully before filling it out to ensure you are using the correct information.
* Enter the project name exactly as it was originally given to you.
* Enter the start and end dates of the project, if applicable.
* Select the current project status from the provided options.
* Enter any additional comments or notes about the project if necessary.
* Ensure that you are submitting the correct project name and status to avoid confusion.

## Field-by-Field Explanation

* **project_name** (`project_name`, text, required): Enter the exact name of the project as given to you.
* **start_date** (`start_date`, date, optional): Enter the start date of the project, if applicable.
* **end_date** (`end_date`, date, optional): Enter the end date of the project, if applicable.
* **project_status** (`project_status`, select_one, optional): Select the current status of the project from the provided options.
* **project_status_note** (`project_status_note`, note, optional): Enter any additional comments or notes about the project status.
* **team_members** (`team_members`, select_multiple, optional): Select all team members who have worked on the project.
* **team_members_note** (`team_members_note`, note, optional): Enter any additional comments or notes about the team members.
* **total_hours** (`total_hours`, number, optional): Enter the total hours worked on the project, if applicable.
* **total_cost** (`total_cost`, number, optional): Enter the total cost of the project, if applicable.
* **submit** (`submit`, text, optional): Enter any additional comments or notes about the submission.
* **assigned_to** (`assigned_to`, select_one, optional): Select the person assigned to submit the report.
* **submitted_by** (`submitted_by`, select_one, optional): Select who submitted the report.
* **submitted_at** (`submitted_at`, time, optional): Enter the time when the report was submitted.
* **submitted_date** (`submitted_date`, date, optional): Enter the date when the report was submitted.
* **comments** (`comments`, note, optional): Enter any additional comments or notes about the submission.
* **attachment** (`attachment`, text, optional): Enter any additional comments or notes about the attached file.
* **project_name_note** (`project_name_note`, note, optional): Enter any additional comments or notes about the project name.
* **project_status_note** (`project_status_note`, note, optional): Enter any additional comments or notes about the project status.
* **project_status_note_2** (`project_status_note_2`, note, optional): Enter any additional comments or notes about the project status.
* **team_members_note** (`team_members_note`, note, optional): Enter any additional comments or notes about the team members.
* **team_members_note_2** (`team_members_note_2`, note, optional): Enter any additional comments or notes about the team members.
* **team_members_note_3** (`team_members_note_3`, note, optional): Enter any additional comments or notes about the team members.
* **total_hours_note_1** (`total_hours_note_1`, note, optional): Enter any additional comments or notes about the total hours.
* **total_hours_note_2** (`total_hours_note_2`, note, optional): Enter any additional comments or notes about the total hours.
* **attachment** (`attachment`, text, optional): Enter any additional comments or notes about the attached file.
