# Installation And Disruption Report - Help Guide

## Purpose
This form is used to report on the outcome of services installed or disrupted in the field. It is essential to complete this form accurately to provide valuable information for future reference and improvement of service delivery.

## How To Complete This Form

*   To complete this form, select the relevant options for each field and provide as much detail as possible in the text fields.
*   Ensure that each field is filled in accurately and truthfully to reflect the actual situation on the ground.
*   Review and verify the completed form before submitting it to ensure that all fields have been filled in correctly.

## Field-by-Field Explanation

*   **Service Outcome** (select_one): Select 'Yes' if the service was successfully installed or 'No' if it was not.
*   **Installed Services** (select_multiple): Select all services that were installed or disrupted.
*   **Disruption Outcome** (select_multiple): Select all services that were disrupted.
*   **Installation Location** (text): Provide the location where the service was installed or disrupted.
*   **Installation Date** (date): Enter the date when the service was installed.
*   **Disruption Date** (date): Enter the date when the disruption occurred.
*   **Cause of Disruption** (text): Provide a brief description of the reason for the disruption.
*   **Affected Services** (select_multiple): Select all services that were affected by the disruption.
*   **Disruption Type** (select_one): Select 'Yes' if the disruption was significant, 'No' if it was minor.
*   **Notes** (note): Provide any additional comments or remarks about the installation or disruption.
*   **Email** (email): Enter the email address of the person submitting the report.
*   **Phone** (text): Enter the phone number of the person submitting the report.
*   **Field Team Member** (text): Enter the name of the field team member who completed the report.
*   **Field Manager** (select_one): Select 'Yes' if the field manager was involved in the installation or disruption.
*   **Customer** (select_one): Select 'Yes' if the customer was present during the installation or disruption.

Note: Fields are not required to be filled in to complete this form, but it is essential to provide as much information as possible to make the report as useful as possible.
