# Uniform Issue Form - Help Guide

## Purpose
This form is used to report and issue uniform-related concerns. Please use it to report any issues with uniforms, such as missing or damaged items, to ensure timely resolution and maintain uniform stock accuracy.

## How To Complete This Form

1. **Uniform Issue Form** (`uniform_issue_form`, text, required): This is the main title of the form. Enter a brief description of the issue you are reporting.
2. **Employee Name** (`employee_name`, text, required): Enter the name of the employee reporting the issue.
3. **Employee ID** (`employee_id`, number, optional): If you have the employee's ID number, please enter it here. This will help us track the issue more efficiently.
4. **Date** (`date`, date, required): Enter the date the issue occurred or is happening.
5. **Uniform Type** (`uniform_type`, text, optional): If the issue is related to a specific type of uniform, please specify it here.
6. **Uniform Size** (`uniform_size`, number, optional): If the issue is related to a specific size of uniform, please enter the size here.

## Tips

* Be as brief as possible when describing the issue, but ensure you provide enough information for us to address the concern efficiently.
* If you are reporting multiple issues, you can submit this form multiple times, but please do not submit duplicate reports for the same issue.
* If you have any supporting evidence, such as images or videos, please attach them to your report so we can investigate further.
