# Student Device Check In Form - Help Guide
## Purpose
The Student Device Check In Form is used by school counselors to check-in/check-out students' devices during events. This form collects information to track device configuration, status, and check-in/check-out times, facilitating efficient inventory management and minimizing issues.

## How To Complete This Form
1. Fill out each field in the sections below according to the instructions.
2. Ensure to review each section carefully before submitting the form.
## Field-by-Field Explanation

* **Student Device Configuration** (`school_counselor_form_1`): A text field where you can describe the student device configuration. Please provide a brief description, e.g., "Laptop with Windows 10" or "Tablet with Android 11".
* **Student Device Configuration 2** (`school_counselor_form_2`): Another text field to describe any additional or specific device configurations.
* **Device Status** (`school_counselor_form_3`): A dropdown menu where you can choose one of the following:
	+ Available: The device is available for student use.
	+ Not Available: The device is not available due to issues such as damage or software problems.
	+ Offline: The device is not currently connected to the internet.
	+ Unknown: The device's status is unknown.
* **Device Configuration 3** (`school_counselor_form_4`): Another text field to further describe any device-specific configurations or details.
* **Device Check-in Time** (`school_counselor_form_5`): Enter the time the student device was checked in, using 24-hour format (e.g., 08:00).
* **Device Check-out Time** (`school_counselor_form_6`): Enter the time the student device was checked out, using 24-hour format (e.g., 10:00).
* **Device Status 2** (`school_counselor_form_7`): A dropdown menu similar to **Device Status** (`school_counselor_form_3`).
* **Device Configuration 4** (`school_counselor_form_8`): A text field for further describing device configurations, if necessary.

## Tips
- Ensure the form is filled out accurately and completely.
- Double-check the fields for correctness before submitting.
- If you need further assistance, consult with a colleague or supervisor.
