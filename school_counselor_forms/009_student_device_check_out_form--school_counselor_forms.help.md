# Student Device Check Out Form - Help Guide
## Purpose
The Student Device Check Out Form is used by students to request a device check-out for use outside of regular school hours. This form is used to capture information about the type of device the student is requesting, their student and teacher details, and the dates for the device check-out period.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of device you are checking out using the "Device Type" field. If you don't see your device type, contact the IT department for assistance.
2. Enter your student name in the "Student Name" field. This is your official student name as per the school records.
3. Enter your teacher's name in the "Teacher Name" field. This is the name of your teacher who will be overseeing your device check-out.
4. Enter the name of the device you are checking out in the "Device Name" field.
5. Select the start date of the device check-out period using the calendar icon next to the "Start Date" field. This date is when you will start using the device.
6. Select the end date of the device check-out period using the calendar icon next to the "End Date" field. This date is when you will return the device.

## Field-by-Field Explanation
* **Device Type (Yes/No)**: Select the type of device you are checking out. This could be a laptop, tablet, or any other electronic device used for academic purposes.
* **Student Name**: Enter your student ID or name as per school records.
* **Teacher Name**: Enter the name of your teacher who will be overseeing your device check-out. This is usually your current teacher or academic advisor.
* **Device Name**: Enter the name of the specific device you are checking out, if applicable.
* **Start Date**: Select the date when you will start using the device. Use the calendar icon to select the date.
* **End Date**: Select the date when you will return the device. Use the calendar icon to select the date.

## Tips

* Make sure to select the correct device type and date range to avoid any discrepancies.
* If you have any questions or concerns about the form, contact the IT department.
* Remember to return the device on the designated end date to avoid any late fees or penalties.
