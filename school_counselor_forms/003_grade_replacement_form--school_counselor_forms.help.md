# Grade Replacement Form - Help Guide

## Purpose
The purpose of this form is to request a replacement for a student's grade in a specific subject or subject group.

## How To Complete This Form
To complete this form, you will need to provide information about the student and the reason for the grade replacement request. Please fill out the form in the following sections.

## Field-by-Field Explanation

* **Student Identifier** (`student_identifier`, text, required): Please enter the student's identifier, such as their student ID number or student name.
* **Reason for Request** (`reason_for_request`, text, optional): If there is a specific reason why the grade needs to be replaced, please provide a brief explanation.
* **Grade to Replace** (`grade_to_replaces`, text, optional): Enter the grade that needs to be replaced.
* **Replacement Grade** (`replacement_grade`, text, required): Enter the grade to replace the current grade with.
* **Grade Replaced** (`grade_replaced`, date, optional): If you have already replaced the grade, enter the date it was replaced.
* **Date of Completion** (`date_of_completion`, date, optional): Enter the date you completed this form.
* **Grade Level** (`grade_level`, select_one, required): Select the grade level of the student (K-12).
* **School Name** (`school_name`, text, required): Enter the name of the school where the student attends.
* **School Phone** (`school_phone`, text, required): Enter the school's phone number.
* **School Email** (`school_email`, email, required): Enter the school's email address.
* **Submitted By** (`submitted_by`, text, required): Enter the name of the person submitting this form.
* **Notes** (`notes`, note, optional): Add any additional notes or comments about the grade replacement request.

## Tips
* Please ensure that you have permission to submit a grade replacement request before completing this form.
* Make sure to include a valid reason for the grade replacement request, if applicable.
* If you have already replaced the grade, be sure to enter the date of completion.
* If you have any additional comments or notes about the grade replacement request, use the notes field.
