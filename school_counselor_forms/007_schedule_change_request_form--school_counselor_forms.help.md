# Schedule Change Request Form - Help Guide
## Purpose
The Schedule Change Request Form is used to request changes to a student's or teacher's schedule. 

## How To Complete This Form
To complete the form, please follow these steps:
1. Enter the teacher name from the drop-down menu provided under "teacher."
2. Enter the student name from the drop-down menu provided under "student."
3. Provide any additional comments about the reason for the schedule change in the text field labeled "teacher_comments" or "student_comments," if necessary.
4. Submit the form.

## Field-by-Field Explanation
* **teacher** (`teacher`, select_one, required): Select the teacher's name from the provided options.
* **student** (`student`, select_one, required): Select the student's name from the provided options.
* **teacher_comments** (`teacher_comments`, text, required): Enter any comments regarding the reason for the schedule change for the teacher's side.
* **student_comments** (`student_comments`, text, required): Enter any comments regarding the reason for the schedule change for the student's side.
