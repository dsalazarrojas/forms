# Student Information Request Form - Help Guide
## Purpose
The Student Information Request Form is used to collect general information from students, allowing school administrators to access and manage student data.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all fields with the requested information.
2. Review and ensure that all required fields are filled before submitting the form.

## Field-by-Field Explanation
### Student Information Request (1)
* **Student Information Request** (`text`, Not Required): This field is a general request for information from the student. Please fill in any relevant details.

### Student Id (2)
* **Student Id** (`number`, Not Required): This field is for entering the student's ID number. Please enter the correct ID number for the student.

### Student First Name (3)
* **Student First Name** (`text`, Not Required): Enter the student's first name here. This will help identify the student.

### Student Last Name (4)
* **Student Last Name** (`text`, Not Required): Enter the student's last name here. This will help identify the student.

### Student Grade (5)
* **Student Grade** (`number`, Not Required): Enter the student's grade level here. Please use a number (e.g. 9 for 9th grade).

### Student Grade Period (6)
* **Student Grade Period** (`number`, Not Required): Enter the student's grade period here. Please use a number (e.g. 1 for period 1, 2 for period 2, etc.).

### Student Birth Date (7)
* **Student Birth Date** (`date`, Not Required): Enter the student's birth date here. Use the format MM/DD/YYYY.

### Student Address (8)
* **Student Address** (`text`, Not Required): Enter the student's address here. This will help with communication and other administrative tasks.

### Student Phone (9)
* **Student Phone** (`text`, Not Required): Enter the student's phone number here. This will help the school staff contact the student.

Tips:

* Please ensure that all required fields are filled before submitting the form.
* If you're unsure about any information, please ask the relevant authorities for clarification.
* This form is for administrative purposes only, and the information collected will be used to improve student services.
