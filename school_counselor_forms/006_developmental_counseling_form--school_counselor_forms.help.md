# Developmental Counseling Form - Help Guide
## Purpose

This form is designed to collect information about a patient's demographics, medical history, and other relevant details to provide a comprehensive understanding of their developmental needs.

## How To Complete This Form

1. Review each section carefully to ensure you are providing accurate and relevant information.
2. Complete each section according to the instructions provided.
3. If you are unsure about any section, please ask your school counselor for assistance.

## Field-by-Field Explanation

* **Patient Name** (`patient_name`, text, required: false): Please enter your name as it appears on your identification documents.
* **Date Of Birth** (`date_of_birth`, date, required: false): Enter your date of birth in the format MM/DD/YYYY.
* **Date Of Birth Time** (`date_of_birth_time`, time, required: false): Enter your date of birth time in the format HH:MM:SS.
* **Date Of Birth Date Time** (`date_of_birth_date_time`, date, required: false): This field is not used in practice and can be ignored.
* **Age** (`age`, number, required: false): Enter your age in years.
* **Gender** (`gender`, select_one, required: false): Please select your gender.
* **Medical History** (`medical_history`, text, required: false): Describe any medical conditions or allergies you have.
* **Medical History List** (`medical_history_list`, select_multiple, required: false): If you have any of the following medical conditions, please select them:
	+ Yes
	+ No
* **Medication** (`medication`, text, required: false): Describe any medications you are currently taking.
* **Medication List** (`medication_list`, select_multiple, required: false): If you have any of the following medications, please select them:
	+ Yes
	+ No
* **Medical Condition** (`medical_condition`, text, required: false): Describe any medical conditions you have.
* **Medical Condition List** (`medical_condition_list`, select_multiple, required: false): If you have any of the following medical conditions, please select them:
	+ Yes
	+ No
* **Allergies** (`allergies`, text, required: false): Describe any allergies you have.
* **Allergies List** (`allergies_list`, select_multiple, required: false): If you have any of the following allergies, please select them:
	+ Yes
	+ No
* **Mental Health Condition** (`mental_health_condition`, text, required: false): Describe any mental health conditions you have.
* **Mental Health Condition List** (`mental_health_condition_list`, select_multiple, required: false): If you have any of the following mental health conditions, please select them:
	+ Yes
	+ No
* **Treatment Plan** (`treatment_plan`, text, required: false): Describe any treatment plans you are currently following.
* **Treatment Plan List** (`treatment_plan_list`, select_multiple, required: false): If you have any of the following treatment plans, please select them:
	+ Yes
	+ No
* **Emergency Contact** (`emergency_contact`, text, required: false): Provide the name and contact information of a trusted emergency contact.
* **Emergency Contact List** (`emergency_contact_list`, select_multiple, required: false): If you have any of the following emergency contacts, please select them:
	+ Yes
	+ No
* **Family History** (`family_history`, text, required: false): Provide any relevant information about your family history.
* **Family History List** (`family_history_list`, select_multiple, required: false): If you have any of the following family history, please select them:
	+ Yes
	+ No
* **Social History** (`social_history`, text, required: false): Provide any relevant information about your social history.
* **Social History List** (`social_history_list`, select_multiple, required: false): If you have any of the following social history, please select them:
	+ Yes
	+ No

Note: Some fields may not be required, but please answer them as accurately and completely as possible to provide the best possible support from your school counselor.
