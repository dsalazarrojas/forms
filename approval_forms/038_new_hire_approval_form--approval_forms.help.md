# new_hire_approval_form - Help Guide
## Purpose
The new hire approval form is used to capture essential information about a new employee, including their identification, job details, and approval status. This form is used to verify the employee's status and ensure that all necessary approvals are in place before they start work.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, marked with an asterisk (\*). These fields are:
	* Employee ID
	* Salary
	* Contract Type
	* Benefits
	* Approval Status
	* Approval Person
	* Job Category
	* Job Type
	* Job Location 2
	* Job Location 3
	* Date of Approval
2. Answer the optional fields as needed:
	* Job Title
	* Department
	* Reporting Manager
	* Reporting Manager 2
	* Date of Joining
	* Employment Status
	* Reason for Hire
	* Notes
	* Email
	* Phone
	* Job Description
	* Job Location 1
3. Ensure that you have the necessary approvals and permissions from your reporting manager and other relevant stakeholders before submitting the form.

## Field-by-Field Explanation
* **Employee ID (\*):** Enter the employee's ID number.
* **Job Title:** Enter the job title of the new employee.
* **Department:** Enter the department the new employee will be working in.
* **Reporting Manager (\*):** Select 'Yes' if you are the reporting manager for the new employee.
* **Reporting Manager 2:** Select 'Yes' if you have another reporting manager for the new employee.
* **Date of Joining:** Enter the date the new employee joined the company.
* **Employment Status (\*):** Select 'Active' or 'Inactive' to indicate the employee's status.
* **Reason for Hire:** Add any additional notes about why the employee was hired.
* **Job Location (\*):** Select 'Yes' if the job is located in one of the available locations.
* **Salary (\*):** Enter the salary of the new employee.
* **Contract Type (\*):** Select 'Yes' to indicate the type of contract.
* **Benefits (\*):** Select 'Yes' to indicate the benefits offered to the employee.
* **Termination Date:** Enter the date the employee's contract will end.
* **Notes:** Add any additional notes about the new employee.
* **Email (\*):** Enter the new employee's email address.
* **Phone (\*):** Enter the new employee's phone number.
* **Reporting Manager 2:** Select 'Yes' if you have another reporting manager for the new employee.
* **Date of Approval (\*):** Enter the date of approval for the new employee.
* **Approval Status (\*):** Select 'Active' or 'Inactive' to indicate the approval status.
* **Approval Person (\*):** Select 'Yes' to indicate who approved the new employee.
* **Job Description:** Enter a brief description of the new employee's job.
* **Job Category (\*):** Select 'Yes' to indicate the job category.
* **Job Type (\*):** Select 'Yes' to indicate the job type.
* **Job Location 2:** Select 'Yes' to indicate the job location.
* **Job Location 3:** Select 'Yes' to indicate the job location.

Note: The fields with an asterisk (\*) are required fields. Make sure to fill out all required fields before submitting the form.
