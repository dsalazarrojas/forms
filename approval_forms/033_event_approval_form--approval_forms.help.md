# Event Approval Form - Help Guide
## Purpose

The Event Approval Form is designed to collect information and approvals for events and meetings within the organization. This form helps event organizers and requesters provide necessary details about the event, including date, location, purpose, and budget, which are essential for approval and planning purposes.

## How To Complete This Form

To complete this form, follow these steps:

*   Select the event status from the "Event Request Form" dropdown menu, which can be either "Yes" or "No".
*   Enter the date of the event using the date format (DD/MM/YY).
*   Type the location where the event will take place in the "Event Location" field.
*   Input the start time of the event in the "Start Time" field.
*   Provide a brief description of the purpose of the event in the "Event Goals" field.
*   Enter the name of the event organizer in the "Event Organizer" field.
*   Enter the name of the person requesting the event in the "Event Requester" field.
*   Specify the department responsible for the event in the "Event Department" field.
*   Enter a budget for the event in the "Event Budget" field.
*   Provide a detailed description of the event in the "Event Description" field.
*   List any specific requirements for the event in the "Event Requirements" field.
*   Select the status of the event's approval: "Approved", "Pending", or "Denied".
*   Add any additional notes or comments regarding the event's approval in the "Event Approval Notes" field.

## Field-by-Field Explanation

*   **Event Request Form** (Select One, Required): This field allows you to indicate whether the event is approved or not.
    *   Select "Yes" if the event is approved.
    *   Select "No" if the event is not approved.
*   **Event Date** (Date, Required): Enter the date of the event in the DD/MM/YY format.
*   **Event Location** (Text, Required): Type the location where the event will take place.
*   **Start Time** (Time, Required): Input the start time of the event.
*   **Event Goals** (Text, Required): Provide a brief description of the purpose of the event.
*   **Event Organizer** (Text, Required): Enter the name of the event organizer.
*   **Event Requester** (Text, Required): Enter the name of the person requesting the event.
*   **Event Department** (Text, Required): Specify the department responsible for the event.
*   **Event Budget** (Number, Required): Enter a budget for the event.
*   **Event Description** (Text, Required): Provide a detailed description of the event.
*   **Event Requirements** (Text, Required): List any specific requirements for the event.
*   **Event Approval Status** (Select Multiple, Required): Select the status of the event's approval: "Approved", "Pending", or "Denied".
*   **Event Approval Notes** (Note, Required): Add any additional notes or comments regarding the event's approval.
