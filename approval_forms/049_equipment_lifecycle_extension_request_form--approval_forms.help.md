# Equipment Lifecycle Extension Request Form - Help Guide
## Purpose
The purpose of this form is to request an extension on the lifecycle of equipment, allowing users to provide additional time for further review and potential approval.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the asset details on Page 1: Provide a clear and concise description of the asset being requested for extension.
2. Select the asset type on Page 1: Choose the correct asset type from the provided options (Construction, Maintenance, Operational, or Other).
3. Choose the category on Page 1: Select the correct category for the asset (Construction, Maintenance, Operational, or Other).
4. Enter the request date on Page 1: Select the date on which the request is being made.
5. Fill in the supervisor's name and email on Page 2: Enter the name and email of the supervisor who approved the request.
6. Fill in any additional comments on Page 2: Provide a reason for the extension request, if necessary.
7. Select the extension request type on Page 2: Choose whether the request is for a "Yes", "No", or "Other" extension.
8. Select the asset condition on Page 2: Choose the current condition of the asset (Poor, Fair, Good, or Excellent).
9. Select the location of the asset on Page 2: Choose where the asset is currently located (Warehouse, Site, Field, or Other).
10. Select the status of the asset on Page 2: Choose the current status of the asset (Active, Retired, Removed, or Pending).
11. Enter the asset serial number on Page 2: Enter the unique serial number of the asset.
12. Select a new request date on Page 3: If necessary, enter a new date for the extension request.
13. Select the approval status on Page 3: Choose the status of the approval request (Pending, Approved, Denied, or Withdrawn).
14. Enter the supervisor's phone number on Page 3: Enter the phone number of the supervisor who approved the request.
