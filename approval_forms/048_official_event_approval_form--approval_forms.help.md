# Official Event Approval Form - Help Guide
## Purpose
The Official Event Approval Form is used for internal stakeholders to review and approve events. It's essential to ensure that all relevant details are provided for a thorough evaluation and approval process.

## How To Complete This Form
1. Ensure you have all required information about the event before starting the form.
2. Select the correct options for the event details, organizers, status, location, dates, and duration.
3. Fill in the text fields with accurate and detailed information about the event location, additional notes, and any other relevant details.
4. Submit the form after reviewing all fields.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, optional)
	+ Provide a brief description of the event.
* **Organizers** (`organizers`, select multiple, optional)
	+ Select all individuals involved in the event.
* **Status** (`event_status`, select one, optional)
	+ Choose whether the event is Active or Inactive.
* **Event Location** (`event_location`, select one, optional)
	+ Select whether the event has a location.
* **Event Dates** (`event_dates`, date, optional)
	+ Choose the date of the event.
* **Start Date** (`start_date`, date, optional)
	+ Select the start date of the event.
* **End Date** (`end_date`, date, optional)
	+ Select the end date of the event.
* **Time** (`event_time`, time, optional)
	+ Choose the time of the event.
* **Duration** (`event_duration`, number, optional)
	+ Enter the duration of the event.
* **Additional Info** (`event_details_additional_info`, text, optional)
	+ Provide any additional information about the event.
* **Location** (`event_location`, text, optional)
	+ Enter the location of the event.
* **Address** (`event_location_address`, text, optional)
	+ Enter the address of the event location.
* **Notes** (`event_location_notes`, text, optional)
	+ Enter any notes about the event location.

## Tips
- Double-check all fields for accuracy before submitting the form.
- Ensure all required information is filled out correctly.
- Review the event details and ensure they align with your role and responsibilities.
