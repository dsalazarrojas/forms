# Video Game Workstation Requisition Form - Help Guide
## Purpose
This form is used to request a new workstation for a specific game title. The workstation will be assigned to an employee who will be using it for their work.

## How To Complete This Form
1. Ensure that you are only submitting one request at a time.
2. Fill out the form completely and accurately.
3. Enter the game title and version number.
4. Select the workstation name and department where the workstation will be used.
5. Enter the employee's name and email address.
6. Enter the date you requested the workstation.
7. Select the budget for the workstation.
8. Enter the employee's phone number.
9. Select the date you received the workstation and the date it was approved.

## Field-by-Field Explanation
- **Game Title** (`game_title`, text, Required): Enter the title of the game you are requesting the workstation for.
- **Game Version** (`game_version`, select_one, Optional): If you need to specify a specific version of the game, select it from the dropdown list.
- **Workstation Name** (`workstation_name`, select_multiple, Optional): Select the type of workstation you are requesting, if applicable.
- **Employee Name** (`employee_name`, text, Required): Enter the name of the employee who will be using the workstation.
- **Department** (`department`, select_one, Required): Select the department where the workstation will be used.
- **Requested Date** (`requested_date`, date, Required): Enter the date you requested the workstation.
- **Assigned To** (`assigned_to`, select_multiple, Optional): If you have a specific person you want to be assigned to the workstation, select them from the dropdown list.
- **Approved By** (`approved_by`, select_multiple, Optional): If you have a specific person who approved the workstation, select them from the dropdown list.
- **Status** (`status`, select_one, Optional): Select the status of the workstation request, if applicable.
- **Comments** (`comments`, note, Optional): Add any additional comments or notes about the workstation request, if applicable.
- **Equipment Requested** (`equipment_requested`, select_multiple, Optional): Select the equipment you are requesting, if applicable.
- **Equipment Type** (`equipment_type`, select_multiple, Optional): Select the type of equipment you are requesting, if applicable.
- **Quantity** (`quantity`, number, Required): Enter the quantity of workstations you are requesting.
- **Price** (`price`, number, Optional): Enter the budget for the workstation, if applicable.
- **Budget** (`budget`, select_one, Required): Select the budget for the workstation.
- **Manager Notes** (`manager_notes`, select_multiple, Optional): Add any additional notes from the manager, if applicable.
- **Employee Notes** (`employee_notes`, select_multiple, Optional): Add any additional notes from the employee, if applicable.
- **Approved By Email** (`approved_by_email`, email, Optional): Enter the email of the person who approved the workstation, if applicable.
- **Assigned To Email** (`assigned_to_email`, email, Optional): Enter the email of the person assigned to the workstation, if applicable.
- **Employee Email** (`employee_email`, email, Required): Enter the email of the employee who requested the workstation.
- **Phone** (`phone`, text, Required): Enter the phone number of the employee who requested the workstation.
- **Date Received** (`date_received`, date, Required): Enter the date the workstation was received.
- **Date Approved** (`date_approved`, date, Required): Enter the date the workstation was approved.
- **Date Rejected** (`date_rejected`, date, Optional): Enter the date the workstation was rejected, if applicable.
