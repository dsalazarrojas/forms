# Grazing Project Approval Survey - Help Guide

## Purpose
This form is used to collect project information for grazing project approvals. It should be filled out for new projects or updates to existing ones.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the project location in the "Project Location" field. This is the physical address where the grazing project will take place.
2. If applicable, select the start and end dates of the project in the respective date fields. If you are unsure of the date, you can leave this field blank.
3. Choose the duration of the project in days. This will help in understanding the scope of the project.
4. Select the type of livestock involved in the project. This is a dropdown list of common types of livestock.
5. Add any additional details about the project location in the "Location Details" field.
6. Enter any environmental measures that will be taken during the project.
7. List the names of the reviewers who will be involved in the project.
8. Add any project notes or comments that are relevant to the project.

## Field-by-Field Explanation

* **Project Location** (`project_location`, text, optional): Enter the location of the grazing project.
* **Start Date** (`project_start_date`, date, optional): Enter the start date of the project. If you're unsure, you can leave this field blank.
* **End Date** (`project_end_date`, date, optional): Enter the end date of the project. If you're unsure, you can leave this field blank.
* **Project Duration** (`project_duration`, number, optional): Select the duration of the project in days.
* **Livestock** (`project_livestock`, select_one, optional): Select the type of livestock involved in the project.
* **Location Details** (`project_location_details`, text, optional): Enter any additional details about the project location.
* **Environmental Measures** (`environmental_measures`, text, optional): Enter any environmental measures that will be taken during the project.
* **Reviewers** (`project_reviewers`, select_multiple, optional): List the names of the reviewers who will be involved in the project.
* **Project Notes** (`project_notes`, note, optional): Add any project notes or comments that are relevant to the project.

## Tips
* Make sure to fill out all required fields (if any) to ensure proper project documentation.
* If unsure about any field, refer to the project manager or relevant documentation.
* This form is only for project approvals and should not be used for other purposes.
