# Workstream Ownership Assignment Form - Help Guide
## Purpose
The Workstream Ownership Assignment Form is used to assign ownership and tasks to specific team members for project-related work. The form captures essential information about the project, such as the project name, status, and key personnel involved.

## How To Complete This Form
To use this form, follow these steps:

1. Ensure you have all the required information, including the accountabilities (tasks and responsibilities), submission date, submitter's name, and assigned team member's name.
2. Fill out the form accurately and completely, providing all necessary details for each field.
3. Review the form carefully before submitting it to verify that all required fields are filled out correctly.

## Field-by-Field Explanation
### **Project Name**: (Required)
* A text field to enter the name of the project or workstream.
* This field is required to ensure that the project is identifiable and linked to its corresponding workstream.

### **Project Status**: (Optional)
* A dropdown menu with options: Active, Inactive, Pending, Cancelled.
* Select the current status of the project, which helps in tracking and management.

### **Project Manager**: (Optional)
* A text field for the project manager's name or contact information.
* This field is helpful for future reference and communication.

### **Project Owner**: (Optional)
* A text field for the project owner's name or contact information.
* This field is also helpful for future reference and communication.

### **Team Lead**: (Optional)
* A text field for the team lead's name or contact information.
* This field is optional, but can be useful for team organization and coordination.

### **Start Date**: (Optional)
* A date field for the project start date.
* This field is essential for tracking project timelines.

### **End Date**: (Optional)
* A time field for the project end date.
* This field is optional, but can be helpful for project closure and evaluation.

### **Accountabilities**: (Required)
* A text field to list specific tasks and responsibilities associated with the workstream.
* This field is essential for clear assignment of ownership and tasks.

### **Submission Date**: (Required)
* A date field for the date of submission.
* This field helps in tracking and recording the submission time.

### **Submitted By**: (Required)
* A text field for the name of the person submitting the form.
* This field is necessary for tracking who submitted the form.

### **Assigned To**: (Required)
* A text field for the name of the person assigned to the workstream.
* This field is essential for clear assignment of ownership.

### **Comments**: (Optional)
* A text field for any additional comments or notes about the project.
* This field is optional but can be helpful for further clarification or context.

### **Form Version**: (Optional)
* A text field for the version of the form, if applicable.
* This field is optional and only necessary if there are multiple versions of the form.

## Tips
* Ensure that all required fields (Project Name, Accountabilities, Submission Date, Submitted By, Assigned To) are filled out correctly.
* Double-check the form for accuracy and completeness before submission.
* If unsure about any field, please ask for clarification or guidance.
