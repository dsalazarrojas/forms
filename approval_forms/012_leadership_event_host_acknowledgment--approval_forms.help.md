# leadership_event_host_acknowledgment - Help Guide
## Purpose
The leadership_event_host_acknowledgment form is used to gather information about leadership events hosted by an individual or organization. This form helps to verify event details and ensures that the event information is accurate and up-to-date for approval purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the event name, host name, start date, and other relevant event details in the respective fields.
2. Choose the correct event type from the provided options.
3. Enter the maximum capacity for the event.
4. Confirm whether the host is confirmed to host the event.
5. Select the date the confirmation was received.

## Field-by-Field Explanation

### 1. event_name 
* `event_name` (text, required)
	+ Enter the name of the event you wish to host.

### 2. host_name 
* `host_name` (text, required)
	+ Enter the name of the person or organization hosting the event.

### 3. start_date 
* `start_date` (date, required)
	+ Enter the start date of the event.

### 4. host_name 
* `host_name` (text, required)
	+ Enter the name of the person or organization hosting the event. (Note: This field is a duplicate of field 2, please ensure to provide accurate information.)

### 5. title 
* `title` (text, required)
	+ Enter a title or name for the host.

### 6. email 
* `email` (email, required)
	+ Enter the email address of the host.

### 7. phone 
* `phone` (text, required)
	+ Enter the phone number of the host.

### 8. location 
* `location` (text, required)
	+ Enter the location of the event.

### 9. event_type 
* `event_type` (select_one, required)
	+ Select the type of event from the provided options (workshops, conferences, leadership programs).

### 10. capacity 
* `capacity` (number, required)
	+ Enter the maximum number of people that can attend the event.

### 11. confirm_host_name 
* `confirm_host_name` (select_multiple, required)
	+ Confirm whether the host is confirmed to host the event.

### 12. confirmation_date 
* `confirmation_date` (date, required)
	+ Select the date you received confirmation for the event.

## Tips
- Please ensure that you provide accurate and up-to-date information to maintain high-quality records.
- If you're unsure about any field, please contact the relevant team for assistance.
- Remember to review the provided event type options carefully to ensure you select the correct category.
