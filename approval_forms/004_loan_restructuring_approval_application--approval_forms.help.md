# Loan Restructuring Approval Application - Help Guide
## Purpose
This form is for loan restructuring requests, to gather information and approval status for restructurings.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the required information, such as borrower details, loan request, restructure details, and submission date.
2. Choose the evaluation result (Approve, Deny, or Pending) and select the approval status (Pending, Approved, or Denied).
3. Add comments, if necessary.
4. Enter the restructured amount and term if applicable.

## Field-by-Field Explanation
* **Loan Restructuring Application (1)**: This is the main section of the form where you can enter the loan restructuring application information.
* **Borrower Details (2)**: Enter information about the borrower, such as name, address, etc.
* **Loan Request (3)**: Enter the details of the loan request, including the loan amount and interest rate.
* **Restructure Details (4)**: Enter any additional information about the restructuring, such as the restructured amount and term.
* **Evaluation Result (5)**: Choose the evaluation result of the loan request (Approve, Deny, or Pending).
* **Approval Status (6)**: Select the approval status of the loan request (Pending, Approved, or Denied).
* **Comments (7)**: Add any comments or observations related to the loan request.
* **Submission Date (8)**: Enter the date the loan request was submitted.
* **Restructured Amount (9)**: Enter the new loan amount after restructurering.
* **Restructured Term (10)**: Enter the new term of the loan after restructuring.
