# SOP Revision And Change Log - Help Guide
## Purpose
The SOP Revision And Change Log form is used to document and record revisions and changes made to Standard Operating Procedures (SOPs). It ensures that updates are transparent and easily verifiable.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields with accurate and relevant information.
2. Verify that you have all necessary approvals and information required for the revision or change.
3. Review and confirm that the form is complete and accurate before submitting.

## Field-by-Field Explanation
- **sop_revision_and_change_log_form_data** (`sop_revision_and_change_log_form_data`, Text, optional): A brief description of the revision or change. Please provide a clear and concise summary of the update.
- **revision_number** (`revision_number`, Number, optional): The revision number for the current change. Please enter the revision number assigned to this update.
- **revision_date** (`revision_date`, Date, optional): The date the revision or change was made. Please use the YYYY-MM-DD format (e.g., 2022-02-20).
- **description** (`description`, Text, optional): A detailed description of the revision or change. Please provide an in-depth explanation of the update.
- **previous_revision** (`previous_revision`, Select Multiple, optional): Select the previous revision(s) that this update replaces. Please choose the relevant previous revision(s).
- **current_revision_status** (`current_revision_status`, Select One, optional): The current status of the revision or change. Please select the current status from the options provided.
- **revision_author** (`revision_author`, Text, optional): The name of the author who made the revision or change. Please enter the name of the personnel responsible.
- **review_and_approvals** (`review_and_approvals`, Note, optional): A note for the review and approval process. Please provide any relevant information about the review and approval process.
- **comments** (`comments`, Text, optional): Any comments or feedback related to the revision or change. Please provide any relevant comments or feedback.
- **routing** (`routing`, Select Multiple, optional): Select the routing options for the revision or change. Please choose the relevant routing options.
- **review_due_date** (`review_due_date`, Date, optional): The due date for the review of the revision or change. Please use the YYYY-MM-DD format (e.g., 2022-02-20).
- **review_date** (`review_date`, Date, optional): The date the revision or change was reviewed. Please use the YYYY-MM-DD format (e.g., 2022-02-20).
- **previous_revision** (`previous_revision`, Select Multiple, optional): Select the previous revision(s) that this update replaces. Please choose the relevant previous revision(s).
- **current_revision_status** (`current_revision_status`, Select One, optional): The current status of the revision or change. Please select the current status from the options provided.

Note: Fields marked as optional are not required for completion, but may be necessary for further clarification or verification.
