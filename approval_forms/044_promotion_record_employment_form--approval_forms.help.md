# Promotion Record Employment Form - Help Guide

## Purpose

The Promotion Record Employment Form is used to record an employee's promotion details. It is essential to fill out this form accurately to ensure that the employee's employment history is up-to-date and reflects their current role and responsibilities. Please fill out this form if an employee has been promoted to a new role within the company.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the employee's details in the "Employee Details" section, including their employee ID, job title, and department.
2. Indicate the current status of the employee's job level and promotion status.
3. Provide the reason for the promotion and any comments from the manager.
4. Confirm the date of the promotion and any changes to the job title, department, manager comments, employee ID, or promotion date.
5. Confirm the employee's status after promotion.
6. Verify the promotion status and confirm if any changes have been made to the job title, department, or promotion date.

## Field-by-Field Explanation

* **Employee ID (`employee_id`, number, required: false)**: Enter the employee's unique identifier.
* **Job Title (`job_title`, text, required: false)**: Enter the employee's current job title.
* **Department (`department`, select_one, required: false)**: Select the department the employee belongs to.
* **Job Role (`role`, select_multiple, required: false)**: Select the roles the employee is currently performing.
* **Salary (`salary`, number, required: false)**: Enter the employee's current salary.
* **Date of Promotion (`date_of_promotion`, date, required: false)**: Enter the date the employee was promoted.
* **Promotion Date (`promotion_date`, date, required: false)**: Enter the date the employee's promotion was officially recognized.
* **Reason for Promotion (`reason_for_promotion`, text, required: false)**: Provide a brief explanation for the promotion.
* **Manager Comments (`manager_comments`, text, required: false)**: Enter any comments from the manager regarding the promotion.
* **Employee Status (`employee_status`, select_one, required: false)**: Select the current status of the employee after promotion.
* **Promotion Status (`promotion_status`, select_one, required: false)**: Select the promotion status.
* **Job Level (`job_level`, select_one, required: false)**: Select the job level of the employee after promotion.
* **Job Title Changes (`job_title_changes`, select_multiple, required: false)**: Indicate if any changes were made to the job title.
* **Department Changes (`department_changes`, select_multiple, required: false)**: Indicate if any changes were made to the department.
* **Manager Comments Changes (`manager_comments_changes`, select_multiple, required: false)**: Indicate if any changes were made to the manager comments.
* **Employee ID Changes (`employee_id_changes`, select_multiple, required: false)**: Indicate if any changes were made to the employee ID.
* **Promotion Date Changes (`promotion_date_changes`, select_multiple, required: false)**: Indicate if any changes were made to the promotion date.
