# Cross Default Request Form - Help Guide

## Purpose
The Cross Default Request Form is used to collect information about requests for exceptions or deviations from standard procedures. It is meant for requests that do not fit the usual flow of the process and require special handling. Before filling out this form, ensure that the request is not a duplicate of a previous submission and that it is not an exception that can be handled through existing processes.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the requestor's information:
	* Requestor: Enter the name of the individual or group requesting the exception.
	* Requestor Name: Enter the name of the person or team making the request.
	* Requestor Department: Enter the department or unit associated with the request.
	* Requestor Email: Enter the email address of the requestor.
2. Select the request type:
	* Select the type of request being made (Loan, Finance, or Contract).
3. Provide a brief description of the request:
	* Description: Enter a short description of the request.
4. Choose the status of the request:
	* Status: Choose the current status of the request (Open, In Progress, or Closed).
5. Select the review date and time:
	* Review Date: Enter the date the request will be reviewed.
	* Review Time: Enter the time the request will be reviewed.
6. Fill in the submitter's information:
	* Submitter: Enter the name of the individual or group submitting the request.
	* Submitter Name: Enter the name of the person submitting the request.
	* Submitter Department: Enter the department or unit associated with the submitter.
	* Submitter Email: Enter the email address of the submitter.
	* Submitter Phone: Enter the phone number of the submitter.
7. Add any additional information:
	* Request Note: Enter any additional information about the request.
8. Specify who submitted the request:
	* Submitted By: Enter the date and time the request was submitted.
	* Submitted By User: Choose who submitted the request (User A or User B).

## Tips

* Make sure to review the form carefully to ensure that all required fields are filled in.
* Double-check that the request is not a duplicate of a previous submission.
* If you're unsure about the request type, contact the relevant team or department for guidance.
* If you're unable to submit the request, contact the system administrator for assistance.
