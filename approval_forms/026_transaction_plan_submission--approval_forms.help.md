# Transaction Plan Submission - Help Guide
## Purpose
The Transaction Plan Submission form is used for submitting a detailed transaction plan for review and approval. It captures information about the proposed transaction, including the proposed amount, currency, date, and time, and other relevant details. The form is designed to guide the user in providing all the necessary information for a smooth and efficient review process.

## How To Complete This Form
1. Please fill in the required fields with accurate information about the proposed transaction.
2. Upload any relevant documents as attachments.
3. Review and submit the form once you have completed all the fields.
4. The form will be reviewed and approved by the relevant stakeholders based on the information provided.

## Field-by-Field Explanation

* **Transaction Plan Submission** (Number): This is the main section of the form where you need to submit your transaction plan.
* **Proposed Transaction Amount** (Number): Enter the amount of the proposed transaction in the specified currency.
* **Proposed Transaction Currency** (Select One): Select the currency of the proposed transaction from the available options (USD, EUR, JPY, CNY).
* **Document Upload 1** (Note): Upload any relevant documents or supporting evidence for the transaction.
* **Document Upload 2** (Note): Upload any additional documents or supporting evidence for the transaction.
* **Proposed Transaction Date** (Date): Enter the date of the proposed transaction.
* **Proposed Transaction Time** (Time): Enter the time of the proposed transaction.
* **Transaction Details** (Text): Provide a brief description of the proposed transaction.
* **Review Status** (Select One): Select the current status of the review for the transaction from the options (Pending, Approved, Rejected).
* **Review Comments** (Text): Enter any comments or feedback for the reviewer about the transaction.
* **Reviewer Comments** (Text): Enter any comments or feedback for the reviewer about the transaction.
* **Reviewer Name** (Text): Enter the name of the reviewer who reviewed the transaction.
* **Review Status 1** (Select One): Select the current status of the review for the first reviewer from the options (Pending, Approved, Rejected).
* **Review Comments 1** (Text): Enter any comments or feedback for the first reviewer about the transaction.
* **Review Name 1** (Text): Enter the name of the first reviewer who reviewed the transaction.
* **Reviewer Name 2** (Text): Enter the name of the second reviewer who reviewed the transaction.
* **Review Status 2** (Select One): Select the current status of the review for the second reviewer from the options (Pending, Approved, Rejected).
* **Review Comments 2** (Text): Enter any comments or feedback for the second reviewer about the transaction.
* **Review Name 2** (Text): Enter the name of the second reviewer who reviewed the transaction.
* **Review Status 3** (Select One): Select the current status of the review for the third reviewer from the options (Pending, Approved, Rejected).
* **Review Comments 3** (Text): Enter any comments or feedback for the third reviewer about the transaction.
* **Review Name 3** (Text): Enter the name of the third reviewer who reviewed the transaction.
* **Email** (Email): Enter your email address.
* **Phone** (Text): Enter your phone number.
