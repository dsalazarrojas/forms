# payment_and_obligation_review - Help Guide
## Purpose
This form is used to track and review payment and obligation information. It helps in maintaining accuracy and completeness of payment records and ensuring that all necessary details are properly documented.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the relevant payment and obligation details as required.
2. Select the correct payment method and status.
3. Choose the correct obligation type and date.
4. Enter the payment and obligation amounts.
5. Review and confirm the details entered.

## Field-by-Field Explanation
- **Payment And Obligation Review (Page 1)** (`base_page`): This is the main page for the form where you can enter all the relevant information.
- **Payment Details (Select One)** (`payment_details`): This section helps you to select the payment method, such as cheque, EFT, or direct debit. Please choose the correct option that applies to your payment.
  - Payment Method: Select the payment method you used for this transaction. 
  - Invoice Number: Select the invoice number related to this payment.
  - Payment Date: Enter the date of the payment.
  - Currency: Select the currency of the payment. 
  - Amount: Enter the amount paid.
- **Obligation Details (Select Multiple)** (`obligation_details`): This section allows you to select the obligation type and date.
  - Obligation Type: Select the type of obligation related to this payment.
  - Obligation Date: Enter the date of the obligation.
- **Payment Terms (Text Field)** (`payment_terms`): Enter any relevant payment terms or conditions that apply to this transaction.
- **Base Page 2 (Text Field)** (`base_page_2`): Enter any additional information or comments related to this payment.
- **Payment Method (Select One)** (`payment_method`): Select the payment method you used for this transaction.
  - Cheque: Select this option if you used a cheque for this payment.
  - EFT: Select this option if you used EFT for this payment.
  - Direct Debit: Select this option if you used direct debit for this payment.
- **Invoice Number (Select One)** (`invoice_number`): Select the invoice number related to this payment.
  - 1: Select this option if the invoice number is 1.
  - 2: Select this option if the invoice number is 2.
  - 3: Select this option if the invoice number is 3.
- **Payment Date (Date Field)** (`payment_date`): Enter the date of the payment.
- **Currency (Select One)** (`currency`): Select the currency of the payment.
  - USD: Select this option if the payment currency is US dollars.
  - EUR: Select this option if the payment currency is euros.
  - JPY: Select this option if the payment currency is Japanese yen.
- **Amount (Number Field)** (`amount`): Enter the amount paid.
- **Obligation Type (Select One)** (`obligation_type`): Select the type of obligation related to this payment.
  - Option A: Select this option if the obligation type is A.
  - Option B: Select this option if the obligation type is B.
  - Option C: Select this option if the obligation type is C.
- **Obligation Date (Date Field)** (`obligation_date`): Enter the date of the obligation.
- **Obligation Amount (Number Field)** (`obligation_amount`): Enter the amount of the obligation.
- **Base Page 3 (Text Field)** (`base_page_3`): Enter any additional information or comments related to this payment.
- **Payment Status (Select One)** (`payment_status`): Select the status of the payment.
  - Paid: Select this option if the payment is completed.
  - Not Paid: Select this option if the payment is not completed.
  - Pending: Select this option if the payment status is pending.
- **Confirmation (Select One)** (`confirmation`): Confirm the payment status.
  - Confirmed: Confirm this option if the payment status is confirmed.
  - Not Confirmed: Confirm this option if the payment status is not confirmed.
  - Pending: Confirm this option if the payment status is pending.
