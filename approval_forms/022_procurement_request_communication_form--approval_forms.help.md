# Procurement Request Communication Form - Help Guide
## Purpose
The Procurement Request Communication Form is designed to facilitate internal communication and updates about procurement requests. 

## How To Complete This Form
1. Start by providing the title of the procurement request.
2. Fill out the Procurement Details field to describe the request.
3. Choose a Date of Request and a Time of Request for context.
4. Select the current Status of the request.
5. Choose any relevant Categories related to the request.
6. Add a Description of the request.
7. If necessary, provide contact information (Requester, Approver, and Reviewer).
8. Add any comments or feedback on the request.
9. Enter the Email and Phone number of the contact person.
10. Finally, add any Additional Comments.

## Field-by-Field Explanation
* **Procurement Request** (`procurement_request_form`): Enter a brief title for the procurement request.
* **Procurement Details** (`procurement_details`): Provide a detailed description of the procurement request.
* **Date of Request** (`procurement_date`): Enter the date the request was made.
* **Time of Request** (`procurement_time`): Enter the time the request was made.
* **Status** (`procurement_status`): Choose the current status of the request from the options provided.
* **Category** (`procurement_category`): Choose any relevant categories related to the request.
* **Description** (`procurement_description`): Add a detailed description of the request.
* **Requester** (`procurement_requester`): Enter the name of the person requesting the procurement.
* **Approver** (`procurement_approver`): Enter the name of the approver for the request.
* **Reviewer** (`procurement_reviewer`): Enter the name of the reviewer for the request.
* **Comments** (`procurement_comments`): Add any comments or feedback related to the request.
* **Email** (`procurement_email`): Enter the email address of the contact person.
* **Phone** (`procurement_phone`): Enter the phone number of the contact person.
* **Additional Comments** (`procurement_comments`): Add any additional comments about the request.

## Tips
* Please ensure that you have all necessary information before filling out the form.
* Double-check that the form is filled out correctly before submitting it for review.
* If you have any questions or concerns, contact the relevant approver or reviewer for assistance.
