# Student Enrollment Approval Form - Help Guide
## Purpose
This form is a collection of fields used to gather student information for academic purposes.

## How To Complete This Form
To fill out this form, please follow these steps:

* Make sure you have all the required information ready before starting.
* Select the correct options for Degree level and Country, as these fields affect the enrollment process.
* Fill out each field with the requested information, using the format specified for each field type (e.g., a date in the format mm/dd/yyyy for Date of Birth).
* Double-check your answers for accuracy, making sure they match the student's actual information.
* Submit the form once you have completed all fields.

## Field-by-Field Explanation
* **First name** (`first_name`, text, optional): Enter the student's first name.
* **Last name** (`last_name`, text, optional): Enter the student's last name.
* **Student ID** (`student_id`, text, optional): Enter the student's ID number.
* **Email** (`email`, email, optional): Enter the student's email address. Please use the correct format (e.g., `student_name@example.com`).
* **Date of Birth** (`date_of_birth`, date, optional): Enter the student's date of birth in the format mm/dd/yyyy.
* **Phone number** (`phone_number`, text, optional): Enter the student's phone number.
* **Address** (`address`, text, optional): Enter the student's address.
* **Country** (`country`, text, optional): Select the student's country of origin (e.g., United States, Canada, Mexico).
* **State** (`state`, select_one, optional): Select the student's state of residence.
* **Zip** (`zip`, text, optional): Enter the student's zip code.
* **Degree level** (`degree_level`, select_one, optional): Select the degree level the student is seeking (e.g., Bachelor's, Master's, PhD).
