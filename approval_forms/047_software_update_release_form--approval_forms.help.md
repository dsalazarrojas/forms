# Software Update Release Form - Help Guide
## Purpose
This form is used to track and document software updates, including planned releases, release dates, and approval statuses. It helps to ensure that all necessary information is collected and approved before a software update is released.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the planned release details in the "Planned Release" field.
2. Select the release date in the "Release Date" field.
3. Provide a brief description of the release in the "Description" field.
4. Enter the release notes in the "Release Notes" field.
5. Select the release version in the "Release Version" field.
6. Choose the release type from the "Release Type" dropdown menu.
7. Enter the IT contact information in the "IT Contact" field.
8. Enter the product contact information in the "Product Contact" field.
9. Select the approval date in the "Approval Date" field.
10. Choose the release status from the "Release Status" dropdown menu.
11. Select the release approvals from the "Release Approvals" dropdown menu.
12. Enter any comments in the "Comments" field.
13. Enter the email address in the "Email" field.
14. Enter the phone number in the "Phone" field.
15. Enter any additional approval notes in the "Approval Note" field.
16. Enter the release number in the "Release Number" field.
17. Enter the release name in the "Release Name" field.
18. Select the release date and time in the "Release Date/Time" field.
19. Select the release time zone in the "Release Time Zone" field.
20. Enter the release notes who in the "Release Notes Who" field.
21. Enter the release notes what in the "Release Notes What" field.
22. Enter the release notes where in the "Release Notes Where" field.
23. Enter the release notes when in the "Release Notes When" field.
24. Enter the release notes why in the "Release Notes Why" field.
25. Enter any release notes comments in the "Release Notes Comments" field.

## Field-by-Field Explanation

* **Planned Release**: Enter the planned release details, such as the release date, version, and any other relevant information.
* **Release Date**: Select the date on which the release will be made available.
* **Description**: Provide a brief description of the release.
* **Release Notes**: Enter any notes about the release, including who is responsible for the release, what changes were made, where they can be accessed, when they will be released, and why they were made.
* **Release Version**: Enter the version number of the release.
* **Release Type**: Choose the type of release from the dropdown menu:
	+ Release: A new version of the software.
	+ Patch: A minor update to the software.
	+ Hotfix: A critical fix for a specific issue.
* **IT Contact**: Enter the email address of the IT contact person.
* **Product Contact**: Enter the email address of the product contact person.
* **Approval Date**: Select the date on which approval was given.
* **Release Status**: Choose the status of the release from the dropdown menu:
	+ Approved: The release has been approved.
	+ Denied: The release has been denied.
	+ Pending: The release is still pending approval.
* **Release Approvals**: Select the release approvals from the dropdown menu:
	+ Yes: Release has been approved.
	+ No: Release has not been approved.
* **Comments**: Enter any additional comments about the release.
* **Email**: Enter the email address of the person responsible for the release.
* **Phone**: Enter the phone number of the person responsible for the release.
* **Approval Note**: Enter any additional approval notes.
* **Release Number**: Enter the release number.
* **Release Name**: Enter the name of the release.
* **Release Date/Time**: Select the date and time on which the release will be made available.
* **Release Time Zone**: Select the time zone in which the release will be made available.
* **Release Notes Who**: Enter the name of the person or team responsible for the release.
* **Release Notes What**: Enter the name of the change or feature being released.
* **Release Notes Where**: Enter the location or environment in which the release can be accessed.
* **Release Notes When**: Enter the date and time on which the release will be available.
* **Release Notes Why**: Enter the reason for the release.
* **Release Notes Comments**: Enter any additional comments about the release.
