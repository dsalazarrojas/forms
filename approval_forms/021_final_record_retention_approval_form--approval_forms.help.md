# Final Record Retention Approval Form - Help Guide
## Purpose
The Final Record Retention Approval Form is used to document and obtain approval for record retention and destruction processes. This form helps to ensure that records are properly maintained and destroyed according to the company's policy and relevant laws and regulations.

## How To Complete This Form
To complete this form, follow these steps:

1. Complete all required fields, denoted by a red asterisk (*).
2. Enter the Record Retention Details, which includes any relevant information about the record to be retained or destroyed.
3. Select a Destruction Date, which is the date when the record will be destroyed.
4. Enter the Retention Period, which is the number of years the record will be maintained.
5. Select the Approval Date, which is the date when the approval was given.
6. Select the Approved By field, which is the person or team responsible for approving the record retention process.
7. Enter any Comments, if desired.
8. Select the Destruction Status, which indicates the current status of the record destruction process.
9. Select the Retention Status, which indicates the current status of the record retention process.
10. Select the Approval Status, which indicates the current status of the approval process.
11. Enter the Record Retention Policy, which is the document that outlines the company's policy on record retention and destruction.

## Field-by-Field Explanation

* **Record Retention Details**: This field is used to provide a brief description of the record to be retained or destroyed. Enter a concise and clear summary of the record.
* **Destruction Date**: This field is used to select the date when the record will be destroyed. Enter the date in the format MM/DD/YYYY.
* **Retention Period**: This field is used to select the number of years the record will be maintained. Enter the number of years, such as 5 or 10.
* **Approval Date**: This field is used to select the date when the approval was given. Enter the date in the format MM/DD/YYYY.
* **Approved By**: This field is used to select the person or team responsible for approving the record retention process. Select from the options provided.
* **Comments**: This field is used to enter any additional comments or notes about the record retention process. Enter any relevant information.
* **Destruction Status**: This field is used to indicate the current status of the record destruction process. Select from the options Pending, Approved, or Rejected.
* **Retention Status**: This field is used to indicate the current status of the record retention process. Select from the options Active, Pending, or Completed.
* **Approval Status**: This field is used to indicate the current status of the approval process. Select from the options Pending, Approved, or Rejected.
* **Record Retention Policy**: This field is used to enter the document that outlines the company's policy on record retention and destruction. Enter a reference to the policy document.
* **Destruction Status**: This field is not a date or duration, but a status. Select Pending to indicate the record is pending destruction, Approved if it's approved for destruction, or Rejected if it's rejected. 
* **Retention Status**: This field is also not a date or duration, but a status. Select Active to indicate the record is active, Pending to indicate it's pending, or Completed to indicate it's completed. 
* **Approval Status**: Similarly, this field is not a date, but a status. Select Pending to indicate the approval is pending, Approved if it's approved, or Rejected if it's rejected.
