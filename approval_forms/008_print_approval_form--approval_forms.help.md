# Print Approval Form - Help Guide
## Purpose
This form is used to confirm details of a print order for a wedding invitation.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the print order (e.g., "Approval Forms").
2. Provide a brief description of the print order.
3. Enter the business name associated with the print order.
4. Enter the customer's name.
5. Confirm the status of the wedding invitation (e.g., "Pending", "In Progress", etc.).
6. Confirm the customer's approval status (e.g., "Approved", "Declined", etc.).
7. Confirm if the customer has given their consent to proceed with the order.
8. Enter any additional notes about the print order.
9. Select a date for the order (in mm/dd/yyyy format).

## Field-by-Field Explanation
* **Category** (`Category`, `select_one`, required): Select the category of the print order.
* **Description** (`Description`, `text`, required): Enter a brief description of the print order.
* **Business Name** (`Business Name`, `text`, required): Enter the business name associated with the print order.
* **Customer Name** (`Customer Name`, `text`, required): Enter the customer's name.
* **Wedding Invitation Status** (`Wedding Invitation Status`, `text`, required): Confirm the status of the wedding invitation.
* **Customer Approval Status** (`Customer Approval Status`, `text`, required): Confirm the customer's approval status.
* **Consent** (`Consent`, `select_multiple`, required): Confirm if the customer has given their consent to proceed with the order.
* **Notes** (`Notes`, `note`, optional): Enter any additional notes about the print order.
* **Date** (`Date`, `date`, required): Select a date for the order (in mm/dd/yyyy format).

## Tips

* Please ensure that all required fields are filled out accurately.
* If the customer has given their consent, make sure to confirm their approval status.
* If the customer's approval status is "Declined", do not proceed with the print order.
