# Regulatory Compliance Extension Request Form - Help Guide
## Purpose
This form is used to request an extension or modification to existing regulatory compliance rules, policies, or guidelines. It is intended to help keep track of compliance requests and ensure that all requests are processed in a timely and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name in the field marked "First name".
2. Enter your last name in the field marked "Last name".
3. Enter your email address in the field marked "Email address".
4. Select a date for the request in the field marked "Request date". You can enter a date in the format "mm/dd/yyyy".
5. Select a time for the request in the field marked "Request time". You can enter a time in the format "HH:MM AM/PM".
6. Describe the reason for the request in the field marked "Reason for request".
7. Add any additional comments or information in the field marked "Additional comments".
8. Choose the type of request you are submitting (e.g., Compliance request, Review request, or Other).
9. Select the parties involved in the request (e.g., Compliance team, Review team, or Other).
10. Click submit to send the request.

## Field-by-Field Explanation

* **First name** (Text): Enter your first name.
* **Last name** (Text): Enter your last name.
* **Email address** (Email): Enter your email address in the format "example@example.com".
* **Request date** (Date): Select a date for the request in the format "mm/dd/yyyy".
* **Request time** (Time): Select a time for the request in the format "HH:MM AM/PM".
* **Reason for request** (Text): Describe the reason for your request.
* **Additional comments** (Text): Add any additional comments or information.
* **Type of request** (Select One): Choose the type of request you are submitting (e.g., Compliance request, Review request, or Other).
* **Involved parties** (Select Multiple): Select the parties involved in the request (e.g., Compliance team, Review team, or Other).
