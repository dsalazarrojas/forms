# Roof Access Permission Request Form - Help Guide
## Purpose
The Roof Access Permission Request Form is used to request permission for roof access for a specific duration.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out your name in the "Requester Name" field.
2. Select the type of access you need: "Emergency" or "Non-emergency".
3. If applicable, select the start and end dates for the access.
4. Enter the reason for your request in the "Reason for Access" field.
5. Provide your contact number and email address for communication purposes.
6. If applicable, enter the duration of the access required.
7. Add any additional information that might be helpful for approval.

## Field-by-Field Explanation
* **Requester Name (Requester Name)**: Enter your name to be associated with this request.
* **Access Type (Access Type)**: Choose the type of access you need: "Emergency" or "Non-emergency".
* **Start Date (Start Date)**: If you selected "Non-emergency" access, select the date you wish to start accessing the roof.
* **End Date (End Date)**: If you selected "Non-emergency" access, select the date you wish to end accessing the roof.
* **Reason for Access (Reason for Access)**: Enter a brief description of the reason for your access request.
* **Contact Number (Contact Number)**: Enter your contact number so we can reach out to you for further questions or approval.
* **Email (Email)**: Enter your email address so we can communicate with you regarding your request.
* **Access Duration (Access Duration)**: If applicable, enter the length of time you will be accessing the roof.
* **Additional Information (Additional Information)**: Enter any additional information that might be helpful for approval purposes.

## Tips
* Ensure you have a legitimate reason for accessing the roof.
* Check that you have not already submitted a similar request in the past.
* Fill out the form completely and accurately.
* If you have any questions or concerns, contact us for assistance.
