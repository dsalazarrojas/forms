# Security Plan Deviation Request Form - Help Guide
## Purpose
The Security Plan Deviation Request Form is used to request changes to the security plan. This form helps to ensure that any deviations to the plan are properly reviewed and approved by relevant stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the security plan and understand the current status.
2. Determine the scope and nature of the proposed deviation.
3. Complete each section of the form, ensuring to provide as much information as possible.
4. Submit the form for review and approval.

## Field-by-Field Explanation
- **Risk Context** (`risk_context`): A brief description of the context in which the deviation will occur.
- **Affected Teams or Departments** (`security_plan_deviation_request_form_page_2`): Select all teams or departments that will be affected by the deviation.
- **Reviewers** (`reviewers`): Select all teams or departments that should be involved in reviewing the deviation.
- **Potential Risks** (`security_plan_deviation_request_form_page_3`): Indicate whether there will be any potential risks involved with the deviation. If yes, select all relevant options.
- **Risk Level** (`risk_level`): A numerical value indicating the level of risk involved with the deviation.
- **Risk Impact** (`risk_impact`): A numerical value indicating the potential impact of the deviation.
- **Risk Urgency** (`risk_urgency`): A numerical value indicating the urgency of addressing the deviation.
- **Risk Frequency** (`risk_frequency`): Select all options that best describe the frequency of the deviation.
- **Security Plan Deviation Request Form Page 5** (`security_plan_deviation_request_form_page_5`): A text field for any additional information or comments.

**Tips**

* Be as specific as possible when completing each field.
* Ensure that you have reviewed and understand the current security plan and the proposed changes.
* This form is intended for requesting changes to the security plan, so only complete it for deviations that are not trivial or minor.
* If you are unsure about any field, consult the relevant policies and procedures or ask for guidance from the relevant stakeholders.
