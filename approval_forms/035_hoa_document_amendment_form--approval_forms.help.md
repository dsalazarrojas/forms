# HOA Document Amendment Form - Help Guide
## Purpose
This form is designed to be a straightforward and easy-to-use submission process for HOA members to propose changes to their governing documents.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure that the proposed changes are original and not a duplicate of a previous proposal.
2. Complete each field with the required information, indicated by an asterisk (\*).
3. Review the form carefully and ensure that all required fields are filled out completely and accurately.

## Field-by-Field Explanation
* **HOA Document Amendment Form** (`hoa_document_amendment_form`, text, optional): This field is the title of the proposed amendment. Please enter a brief description of the amendment.
* **HOA Document Number** (`hoa_document_number`, text, optional): This field is for the current HOA document number that the amendment applies to. Please enter the current document number.
* **Document Date** (`document_date`, date, optional): This field is for the date of the current document that the amendment applies to. Please enter the date in the correct format (MM/DD/YYYY).
* **Board Meeting Date** (`board_meeting_date`, date, optional): This field is for the date of the board meeting where the amendment was approved or will be voted on. Please enter the date in the correct format (MM/DD/YYYY).
* **Proposed Changes** (`proposed_changes`, text, optional): This field is for a detailed description of the proposed changes. Please enter a clear and concise summary of the amendment.
* **Supporting Document Attachments** (`supporting_document_attachments`, note, optional): This field is for any supporting documents related to the amendment. Please attach relevant documents here.
* **Opposing Document Attachments** (`opposing_document_attachments`, note, optional): This field is for any opposing documents related to the amendment. Please attach relevant documents here.
* **Approval Process** (`approval_process`, select_one, optional): Select the approval process for the amendment: Approval by Board, Approval by Committee, or Approval by Voting.
* **Approval Date** (`approval_date`, date, optional): This field is for the date the amendment was approved. Please enter the date in the correct format (MM/DD/YYYY).
* **Submitted To** (`submitted_to`, select_multiple, optional): Select the entity to which the amendment was submitted: HOA Board, Governing Documents Committee, or Other (Specify below).
* **Other Submission Destination** (`other_submission_destination`, text, optional): If submitted to "Other", please enter the specific entity to which the amendment was submitted.
* **HOA ID** (`hoa_id`, text, optional): This field is for the ID number of the HOA document being amended. Please enter the current ID number.
* **Amendment Status** (`amendment_status`, select_one, optional): Select the current status of the amendment: Pending, Approved, Denied, or Withdrawn.
* **Amendment Description** (`amendment_description`, text, optional): This field is for a detailed description of the amendment. Please enter a clear and concise summary of the amendment.
* **Comment** (`comment`, note, optional): This field is for any additional comments or notes related to the amendment. Please enter any relevant information here.
* **Submission Date** (`submission_date`, date, optional): This field is for the date the amendment was submitted. Please enter the date in the correct format (MM/DD/YYYY).
* **Last Updated** (`last_updated`, date, optional): This field is for the date the amendment was last updated. Please enter the date in the correct format (MM/DD/YYYY).
* **Last Updated By** (`last_updated_by`, text, optional): This field is for the person who last updated the amendment. Please enter the name of the person.

## Tips

* Please review the form carefully before submitting to ensure that all required fields are filled out completely and accurately.
* If you are unsure about any field, please contact the HOA office for clarification.
* If you have any questions or need further assistance, please do not hesitate to contact us.
