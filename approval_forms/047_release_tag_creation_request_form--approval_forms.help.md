# Release Tag Creation Request Form - Help Guide

## Purpose
The Release Tag Creation Request Form is used to request the creation of a release tag. This form is designed to gather necessary information from users to create a release tag efficiently. Please fill in the required fields accurately to ensure the creation of the release tag.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Make sure to select the correct options from the dropdown menus.
3. Submit the form after reviewing your entries.

## Field-by-Field Explanation
* **Release Tag Creation Request** (`release_tag_creation_request_form`): This field is the main description of your request. It is not optional.
* **Environment** (`environment`): Choose whether the release tag creation request is for a specific environment or not.
	+ 'Yes' - The release tag creation request is for a specific environment.
	+ 'No' - The release tag creation request is not for a specific environment.
* **Release Tag Name** (`release_tag_name`): Enter the name of the release tag you want to create.
* **Release Tag Version** (`release_tag_version`): Enter the version of the release tag you want to create.
* **Description** (`description`): Briefly describe the reason for creating the release tag.
* **Approver** (`approver`): Choose whether you want someone to be notified of the release tag creation process. If you select 'Yes', the approver's email will be notified.
	+ 'Yes' - The release tag creation process will be notified to the approver.
	+ 'No' - The release tag creation process will not be notified to the approver.
* **Approver Email** (`approver_email`): Enter the email of the person to be notified of the release tag creation process. This field is only required if you select 'Yes' for the `Approver` field.
* **Request Form ID** (`request_form_id`): Enter the ID of the request form related to the release tag creation request. This is for internal use only.
* **Request Form Status** (`request_form_status`): Select the status of the request form.
	+ 'Active' - The request form is active and can be processed.
	+ 'Inactive' - The request form is inactive and cannot be processed.
* **Release Tag Status** (`release_tag_status`): Select the status of the release tag creation request.
	+ 'Active' - The release tag creation request is active and can be processed.
	+ 'Inactive' - The release tag creation request is inactive and cannot be processed.

Please note that all fields are required, except where specified otherwise. If you have any questions or need further clarification, please don't hesitate to reach out to your team or refer to the relevant documentation.
