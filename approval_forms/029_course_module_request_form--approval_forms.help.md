# Course Module Request Form - Help Guide

## Purpose
The Course Module Request Form is a tool used to propose new course modules for approval. This form helps gather essential information about a proposed module, including its description, category, and status. It is intended for instructors and staff members to submit requests for new modules, ensuring that the information is accurately and thoroughly documented.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a brief description of the proposed module in the "Curriculum Proposal" field (field 1).
2. Enter the name of the module in the "Module Name" field (field 2).
3. Write a detailed description of the module in the "Module Description" field (field 3).
4. Choose the category for the module in the "Category" field (field 4).
5. Select the type of module (Lecture, Workshop, or Lab) in the "Module Type" field (field 5).
6. Enter the start date of the module in the "Start Date" field (field 6), using the DD/MM/YY format.
7. Enter the end date of the module in the "End Date" field (field 7), using the DD/MM/YY format.
8. Select the current status of the module (Draft, Approved, or Rejected) in the "Module Status" field (field 8).
9. If the module has a status of "Rejected", select a reason for rejection in the "Module Status Reason" field (field 9).
10. Enter your name or department (if applicable) in the "Submitter" and "Submitter Department" fields (fields 10 and 11).
11. Enter your email address in the "Submitter Email" field (field 12).

## Field-by-Field Explanation

* **Curriculum Proposal (field 1)**: Enter a brief description of the proposed module.
* **Module Name (field 2)**: Enter a name for the proposed module.
* **Module Description (field 3)**: Provide a detailed description of the module, including its content and objectives.
* **Category (field 4)**: Select a category for the module that best describes its purpose.
* **Module Type (field 5)**: Choose the type of module (Lecture, Workshop, or Lab) that aligns with the proposed content.
* **Start Date (field 6)**: Enter the date when the module is scheduled to start, using the DD/MM/YY format.
* **End Date (field 7)**: Enter the date when the module is scheduled to end, using the DD/MM/YY format.
* **Module Status (field 8)**: Select the current status of the module (Draft, Approved, or Rejected).
* **Module Status Reason (field 9)**: If the module has a status of "Rejected", enter a reason for rejection.
* **Submitter (field 10)**: Enter your name or department (if applicable) to be associated with the module request.
* **Submitter Department (field 11)**: Enter your department (if applicable).
* **Submitter Email (field 12)**: Enter your email address.

Please ensure that all fields marked as required are completed accurately and thoroughly. If you have any questions or concerns about this form, please contact form@gic.mx.
