# software_approval_form - Help Guide
## Purpose
The "software approval form" is used to gather information about software-related requests and track their approval status. It helps administrators and approvers to make informed decisions about software approval and implementation.

## How To Complete This Form

1.  Fill out the "Software Approval" field with a brief description of the software being requested.
2.  Provide detailed "Request Details" about the software request, including any relevant information about its purpose and usage.
3.  Enter "Software Information" about the software, such as its version and implementation status.
4.  Choose the "Approval Status" of the software request from the options: "approved", "declined", or "pending".
5.  Select the "Software Requester" from the options: "requestor 1", "requestor 2", or "requestor 3".
6.  Choose the "Software Reviewers" from the options: "reviewer 1", "reviewer 2", or "reviewer 3".
7.  Select the "Software Versioning" from the options: "version 1", "version 2", or "version 3".
8.  Choose the "Software Implementation Status" from the options: "implemented", "not implemented", or "pending".
9.  Select the "Software Last Updated" status from the options: "True", "False", or "n/a".
10. Choose the "Software Review Status" from the options: "reviewed", "not reviewed", or "n/a".
11. Enter any "Software Comments" or comments about the software request.
12. Enter any "Software Requester Comments" or comments from the software requester.
13. Fill out the "Created By" field with the name of the person who created the software request.
14. Fill out the "Updated By" field with the name of the person who last updated the software request.

## Field-by-Field Explanation

*   **Software Approval**:
    *   <name>Software Approval</name>
    *   <type>text</type>
    *   This field is a brief description of the software being requested.
*   **Request Details**:
    *   <name>Request Details</name>
    *   <type>text</type>
    *   This field is used to provide detailed information about the software request.
*   **Software Information**:
    *   <name>Software Information</name>
    *   <type>note</type>
    *   This field is used to enter additional details about the software, such as its version and implementation status.
*   **Approval Status**:
    *   <name>Approval Status</name>
    *   <type>select_one</type>
    *   This field is used to track the approval status of the software request.
*   **Software Requester**:
    *   <name>Software Requester</name>
    *   <type>select_one</type>
    *   This field is used to select the person who requested the software.
*   **Software Reviewers**:
    *   <name>Software Reviewers</name>
    *   <type>select_multiple</type>
    *   This field is used to select the people responsible for reviewing the software.
*   **Software Versioning**:
    *   <name>Software Versioning</name>
    *   <type>select_one</type>
    *   This field is used to select the version of the software being requested.
*   **Software Implementation Status**:
    *   <name>Software Implementation Status</name>
    *   <type>select_one</type>
    *   This field is used to track the implementation status of the software.
*   **Software Last Updated**:
    *   <name>Software Last Updated</name>
    *   <type>select_one</type>
    *   This field is used to track when the software was last updated.
*   **Software Review Status**:
    *   <name>Software Review Status</name>
    *   <type>select_one</type>
    *   This field is used to track the review status of the software.
*   **Software Comments**:
    *   <name>Software Comments</name>
    *   <type>note</type>
    *   This field is used to enter any comments or feedback about the software request.
*   **Software Requester Comments**:
    *   <name>Software Requester Comments</name>
    *   <type>note</type>

*   **Created By**:

*   **Updated By**:
    *   <name>Updated By</name>
    *   <type>text</type>
