# Inventory Management System Approval Form - Help Guide
## Purpose
The Inventory Management System Approval Form is used to request items from the inventory and to facilitate the approval process. It is intended for employees who need to request items from the inventory for work-related purposes. 

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill out the required fields accurately and honestly.
2. Select the correct status of the inventory item from the dropdown menu.
3. Choose the inventory manager responsible for the item from the list of available options.
4. Specify the approval status of the item by selecting one or multiple options.
5. Add any relevant comments if needed.

## Field-by-Field Explanation
- **Inventory Request Form (Text) (1) (**required**)**: Please enter the item you wish to request from the inventory.
- **Inventory Status (**2**, **required**)**: Select the current status of the inventory item from the following options:
  - In progress
  - Completed
  - Not Started
- **Inventory Manager (Text) (3) (**optional**): If you know who the inventory manager is, enter their name here.
- **Approval Status (Select Multiple) (4) (**required**): Select the approval status of the item by choosing one or multiple options:
  - Approved
  - Rejected
  - Waiting on Manager
- **Comments (Text Area) (5) (optional): If you have any additional information or comments about the inventory item, please enter them here.
