# Room Design Approval Upload Form - Help Guide
## Purpose
The Room Design Approval Upload Form is used to collect and validate the room design package details from authorized personnel. The form helps ensure that all necessary information is accurate and complete before approval.

## How To Complete This Form

1.  Review the room design package carefully before starting.
2.  For each field, select "Yes" if the package meets the criteria or "No" if it does not.
3.  Upload files related to the package in the designated fields.
4.  Ensure each file type is correctly selected for each upload field.
