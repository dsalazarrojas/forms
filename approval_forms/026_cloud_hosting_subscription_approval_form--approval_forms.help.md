# Cloud Hosting Subscription Approval Form - Help Guide

## Purpose
The purpose of this form is to collect and review information for cloud hosting subscription approval. It is designed to gather essential details to evaluate and approve or reject cloud hosting requests.

## How To Complete This Form
1. Start by filling out the requester information section, which includes:
	* Requester Name: Enter the person requesting cloud hosting.
	* Email Address: Provide the email address of the requestor.
	* Department: Identify the department or team making the request.
	* Manager Name: Enter the name of the direct supervisor.
2. Next, describe the cloud hosting service details:
	* Type of Cloud Hosting Service: Choose the type of service needed, such as web hosting, application hosting, database hosting, storage hosting, or full cloud infrastructure.
	* Preferred Cloud Provider: Select the cloud service provider, e.g., AWS, Microsoft Azure, or Google Cloud.
	* Service Description and Purpose: Provide a brief description of the service and its purpose.
3. Specify the technical requirements:
	* Estimated Monthly Users - Traffic: Enter the estimated monthly traffic.
	* Storage Capacity Needed - GB: Specify the storage capacity required.
	* Bandwidth Needed - GB per month: Enter the bandwidth required.
	* Uptime Requirement: Select the required uptime percentage.
4. Calculate the estimated costs:
	* Estimated Monthly Cost - USD: Enter the estimated monthly cost.
	* Estimated Annual Cost - USD: Enter the estimated annual cost.
	* Cost Center or Budget Code: Identify the cost center or budget code for billing purposes.

**Important Note:** Ensure that all fields marked 'required' are completed before proceeding.

## Field-by-Field Explanation
* Requester Name: **(Requester Name, Text, Required)**: The name of the person making the request.
* Email Address: **(Email Address, Email, Required)**: The email address of the requestor.
* Department: **(Department, Text, Required)**: The department or team making the request.
* Manager Name: **(Manager Name, Text, Required)**: The name of the direct supervisor.
* Request Date: **(Request Date, Date, Required)**: The date the request was made.
* Type of Cloud Hosting Service: **(Type of Cloud Hosting Service, Select One, Required)**: Choose the type of service needed.
* Preferred Cloud Provider: **(Preferred Cloud Provider, Select One, Required)**: Select the cloud service provider.
* Service Description and Purpose: **(Service Description and Purpose, Text, Required)**: A brief description of the service and its purpose.
* Estimated Monthly Users - Traffic: **(Estimated Monthly Users - Traffic, Number, Required)**: Enter the estimated monthly traffic.
* Storage Capacity Needed - GB: **(Storage Capacity Needed - GB, Number, Required)**: Specify the storage capacity required.
* Bandwidth Needed - GB per month: **(Bandwidth Needed - GB per month, Number, Required)**: Enter the bandwidth required.
* Uptime Requirement: **(Uptime Requirement, Select One, Required)**: Select the required uptime percentage.
* Estimated Monthly Cost - USD: **(Estimated Monthly Cost - USD, Number, Required)**: Enter the estimated monthly cost.
* Estimated Annual Cost - USD: **(Estimated Annual Cost - USD, Number, Required)**: Enter the estimated annual cost.
* Cost Center or Budget Code: **(Cost Center or Budget Code, Text, Required)**: Identify the cost center or budget code.
* Business Justification: **(Business Justification, Text, Required)**: Why is this service needed?
* Approval Status: **(Approval Status, Select One, Required)**: Select the approval status.
* Approver Name: **(Approver Name, Text, Optional)**: If already approved, enter the approver name.
* Approval Date: **(Approval Date, Date, Optional)**: If already approved, enter the approval date.

## Tips
* Please make sure to fill out all required fields accurately and thoroughly.
* If you need help or clarification, contact your IT department.
* If you are already approved, do not fill out this form again.
