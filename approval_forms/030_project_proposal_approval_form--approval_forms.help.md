# Project Proposal Approval Form - Help Guide

## Purpose
This form is used to create a new project proposal. It's meant to be filled out by project team members to gather information about a proposed project.

## How To Complete This Form

1. Fill out all the fields with the relevant information about your project proposal.
2. Be sure to double-check the accuracy of your input before submitting the form.

## Field-by-Field Explanation

* **Project Proposal Form Input** (`project_proposal_form_input`, text, optional): This field is intended for any additional comments or notes about the project proposal. You can provide any relevant information here.
* **Project Lead's Name** (`project_lead_name`, text, optional): Enter the name of the project lead or the person responsible for the project.
* **Project Lead's Email** (`project_lead_email`, email, optional): Enter the email address of the project lead or the person responsible for the project.
* **Project Lead's Phone Number** (`project_lead_phone`, text, optional): Enter the phone number of the project lead or the person responsible for the project.
* **Project Title** (`project_title`, text, optional): Provide a brief title of the project.
* **Project Description** (`project_description`, text, optional): Provide a detailed description of the project, including its objectives and requirements.
* **Project Start Date** (`project_start_date`, date, optional): Enter the planned start date of the project.
* **Project End Date** (`project_end_date`, date, optional): Enter the planned end date of the project.
* **Project Budget** (`project_budget`, text, optional): Provide the budget for the project.
* **Project Location** (`project_location`, text, optional): Enter the location where the project will take place.
* **Project Status** (`project_status`, select multiple, optional): Select the current status of the project: In Progress, Pending, Approved, or Denied.
* **Project Priority** (`project_priority`, select one, optional): Select the priority level of the project: High, Medium, or Low.
* **Project Category** (`project_category`, text, optional): Enter the category of the project.

Please note that all fields are optional, but it is recommended that you fill out as much information as possible for the project proposal.
