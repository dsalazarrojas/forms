# Responsibility And Authority Matrix Form - Help Guide
## Purpose
The Responsibility And Authority Matrix Form is used to document and track project responsibilities and authorities for each project.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the project you want to manage and track in the "Projects" field.
2. Provide a clear and concise name for the process being used in the "Process Name" field.
3. Describe the project's objective, goals, and any relevant details in the "Project Description" field.
4. In the "Roles and Responsibilities" field, select all roles that are involved in this project.
5. In the "Project Owner" field, identify the person in charge of this project.
6. In the "Handoffs" field, describe any handoffs between team members or departments.
7. In the "Centralized Data Collection" field, select all options where data is collected and stored in a centralized location.
8. In the "Manager Review" field, record the date when the project manager will review the project's progress.
9. In the "Completion Date" field, record the expected completion date of the project.
10. In the "Notes" field, add any additional comments or notes related to this project.
## Field-by-Field Explanation
- **Projects** (`projects`, number, required/optional): Select the project you want to manage and track.
- **Process Name** (`process_name`, text, required/optional): Provide a clear and concise name for the process being used in this project.
- **Project Description** (`description`, text, required/optional): Describe the project's objective, goals, and any relevant details.
  * This field helps to clearly outline the project's goals and objectives.
  * Make sure to include any relevant background information that will help others understand the project's scope.
- **Roles and Responsibilities** (`roles`, select_multiple, required/optional): Select all roles that are involved in this project.
  * These roles are typically departments or teams within the organization.
  * Make sure to select all roles that are directly involved in the project.
- **Project Owner** (`owner`, select_one, required/optional): Identify the person in charge of this project.
  * This person is responsible for overseeing the project's progress and making key decisions.
  * Make sure to select the person who will be the primary point of contact for this project.
- **Handoffs** (`handoffs`, text, required/optional): Describe any handoffs between team members or departments.
  * A handoff is when one person or department passes on their work to another person or department.
  * Make sure to describe where the handoff occurs and who is involved.
- **Centralized Data Collection** (`centralized_data_collection`, select_multiple, required/optional): Select all options where data is collected and stored in a centralized location.
  * This helps to ensure that data is consistently collected and stored in one location.
  * Select all options that apply to your project.
- **Manager Review** (`manager_review`, date, required/optional): Record the date when the project manager will review the project's progress.
  * This is when the project manager will assess the project's progress and make any necessary adjustments.
  * Make sure to record the date when the manager will review the project.
- **Completion Date** (`completion_date`, date, required/optional): Record the expected completion date of the project.
  * This is the date when the project is expected to be finished.
  * Make sure to update this date as the project's progress changes.
- **Notes** (`notes`, note, required/optional): Add any additional comments or notes related to this project.
  * Use this field to add any further information or details that will help others understand the project.
  * Make sure to keep this field concise and relevant.

## Tips
- Use this form to track project responsibilities and authorities for each project.
- Ensure that each field is filled out accurately and completely.
- Use this form to document changes in project scope or timeline.
