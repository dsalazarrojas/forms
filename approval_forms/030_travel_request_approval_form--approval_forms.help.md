# Travel Request Approval Form - Help Guide
## Purpose
The Travel Request Approval Form is a tool used to submit and manage travel requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure all required fields are completed.
2. Enter the following information:
   - Approver: Select the name of the person approving the travel request.
   - Travel Date: Enter the date of the trip.
   - Travel Time: Enter the time of the trip.
   - Start Location: Enter the location where the trip will start.
   - End Location: Enter the location where the trip will end.
   - Travel Reason: Explain the purpose of the trip.
   - Travel Duration: Enter the duration of the trip in hours or days.
   - Travel Type: Select the type of travel (Business, Personal, or Both).
   - Return Date: Enter the date of the return trip.
   - Return Time: Enter the time of the return trip.
   - Return Location: Enter the location where the return trip will end.
   - Return Reason: Explain the reason for returning.
   - Return Type: Select the type of return travel (Hotel, Flight, or Train).
   - Notes: Add any additional information or comments about the trip.
   - Email: Enter your email address.
   - Phone: Enter your phone number.
   - Travel Budget: Enter the budget for the trip.
   - Approval Date: This field will be filled out by the approver.
   - Approval Time: This field will be filled out by the approver.
   - Approver Notes: Add any additional information or comments from the approver.
   - Status: Select the status of the trip (Pending, Approved, or Rejected).
   - Assigned User ID: This field is not typically used by users.
   - Assigned User Name: This field is not typically used by users.
   - Assigned User Email: This field is not typically used by users.

## Field-by-Field Explanation
* **Approver**: Select the name of the person approving the travel request. The approver will be notified when they are assigned to approve a request.
* **Travel Date**: Enter the date of the trip in YYYY-MM-DD format.
* **Travel Time**: Enter the time of the trip in 24-hour format (e.g., 09:00).
* **Start Location**: Enter the location where the trip will start.
* **End Location**: Enter the location where the trip will end.
* **Travel Reason**: Explain the purpose of the trip in a few sentences.
* **Travel Duration**: Enter the duration of the trip in hours or days.
* **Travel Type**: Select the type of travel (Business, Personal, or Both).
* **Return Date**: Enter the date of the return trip in YYYY-MM-DD format.
* **Return Time**: Enter the time of the return trip in 24-hour format (e.g., 09:00).
* **Return Location**: Enter the location where the return trip will end.
* **Return Reason**: Explain the reason for returning in a few sentences.
* **Return Type**: Select the type of return travel (Hotel, Flight, or Train).
* **Notes**: Add any additional information or comments about the trip.
* **Email**: Enter your email address for contact purposes.
* **Phone**: Enter your phone number for contact purposes.
* **Travel Budget**: Enter the budget for the trip.
* **Approval Date**: This field will be filled out by the approver and indicates the date of approval.
* **Approval Time**: This field will be filled out by the approver and indicates the time of approval.
* **Approver Notes**: Add any additional information or comments from the approver.
* **Status**: Select the status of the trip (Pending, Approved, or Rejected).
* **Assigned User ID**: This field is not typically used by users.
* **Assigned User Name**: This field is not typically used by users.
* **Assigned User Email**: This field is not typically used by users.
