# Project Addendum Submission Form - Help Guide
## Purpose
The "Project Addendum Submission Form" is used to collect information about project changes and updates. This form helps to keep track of project status and progress, and ensures that all project stakeholders are informed about the changes made to the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Project Manager" or "Client" from the "Submitted By" field.
2. Enter the "Client" email address in the "Client Email" field.
3. Enter the "Client Phone" number in the "Client Phone" field.
4. Select the "Change Type" (e.g. "Changes" or "Additions").
5. Enter the "Change Date" in the format "YYYY-MM-DD".
6. Provide a brief "Description" of the change.
7. Select the current "Project Status" (e.g. "Active" or "Inactive").
8. Enter the "Project Description".
9. Select the "Project Category" (e.g. "Approval Forms" or "Project Management").
10. Enter the "Submitted By Email" and "Submitted By Phone" for the person submitting the form.
11. Enter any additional "Project Manager Notes".
12. Upload any relevant "Output File" and specify the "Output Folder".

## Field-by-Field Explanation
- **Project Manager**: Select the person responsible for managing the project.
- **Client**: Enter the email address of the client associated with the project.
- **Client Phone**: Enter the phone number of the client.
- **Change Type**: Select the type of change made to the project (e.g. "Changes" or "Additions").
- **Change Date**: Enter the date the change was made in the format "YYYY-MM-DD".
- **Description**: A brief description of the change made to the project.
- **Status**: Select the current status of the project (e.g. "Active" or "Inactive").
- **Project Description**: A brief description of the project.
- **Project Category**: Select the category of the project (e.g. "Approval Forms" or "Project Management").
- **Submitted By**: Select the person submitting the form (e.g. "Project Manager" or "Client").
- **Submitted By Email**: Enter the email address of the person submitting the form.
- **Submitted By Phone**: Enter the phone number of the person submitting the form.
- **Submitted At**: Enter the date the form was submitted in the format "YYYY-MM-DD".
- **Project Manager Notes**: Additional notes from the project manager.
- **Output File**: Upload any relevant file related to the project change.
- **Output Folder**: Specify the folder where the output file is located.
- **Assigned Tool**: Select the tool assigned to manage the project (e.g. "Chatjimmy" or "Other").
- **Project Manager Email**: Enter the email address of the project manager.
- **Project Manager Phone**: Enter the phone number of the project manager.

Note: Some fields are optional and can be skipped if not applicable.
