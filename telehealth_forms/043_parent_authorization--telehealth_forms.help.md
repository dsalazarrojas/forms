# Parent Authorization - Help Guide
## Purpose
The Parent Authorization form is used to request authorization from a parent or other responsible individual for a minor patient's medical treatment.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter the parent's name in the "Parent Name" field.
*   Select "Yes" or "No" in the "Other Responsible" field if the parent is not the primary responsible individual.
*   Enter the parent's phone number in the "Phone" field.
*   Enter the parent's email address in the "Email" field.
*   Select "Yes" or "No" in the "Medical Authorization" field to indicate if the parent has given medical authorization.
*   Enter the emergency contact's information in the "Emergency Contact" field.
*   Select "Yes" or "No" in the "Other Authorization" field to indicate if the parent has given other authorization.

## Field-by-Field Explanation
*   **Parent Name** (`parent_name`, text, required/optional): Enter the parent's full name.
*   **Other Responsible** (`other_responsible`, select_multiple, required/optional): Select "Yes" if the other responsible individual is not the parent.
*   **Phone** (`phone`, text, required/optional): Enter the parent's phone number.
*   **Email** (`email`, email, required/optional): Enter the parent's email address.
*   **Medical Authorization** (`medical_authorization`, select_one, required/optional): Select "Yes" if the parent has given medical authorization.
*   **Emergency Contact** (`emergency_contact`, text, required/optional): Enter the emergency contact's name and contact information.
*   **Other Authorization** (`other_authorization`, select_multiple, required/optional): Select "Yes" if the parent has given other authorization.

## Tips
*   Make sure to enter accurate and up-to-date information.
*   Select "No" for authorization fields if the parent has not given authorization.
*   This form should not be completed if the patient is an adult or has a legal guardian who is already aware of their medical treatment.
