# Telepsychology Session Check In Form - Help Guide
## Purpose
The Telepsychology Session Check In Form is used for checking in sessions between telepsychologists and their patients. It is used to document session details and patient information for accurate tracking and billing purposes.

## How To Complete This Form
- Fill in all required fields marked with an asterisk (\*) as they are mandatory for submission.
- Select the correct session type and provider from the provided options.
- Choose the correct session status.
- Enter the session start and end times accurately.
- Select the session duration.
- Fill in the session check-in and check-out times accurately.
- Select the correct session start and end dates.
- Select the correct session checkin location.
- Choose the correct session checkin status.
- Enter accurate session provider phone number (if applicable).
- Enter accurate patient age and ID.

* **Check-in Date (\*)** (`session_check_in_form_10`, `date`, required): Enter the date of the current session.
* **Session Type (\*)** (`session_check_in_form_2`, `text`, required): Select the type of session, e.g., individual, group, or couples.
* **Session Provider (\*)** (`session_check_in_form_3`, `select_one`, required): Select the session provider from the provided options.
* **Session Location (\*)** (`session_check_in_form_4`, `select_multiple`, required): Select the location of the session, e.g., online or in-person.
* **Session Status (\*)** (`session_check_in_form_5`, `select_one`, required): Select the current status of the session, e.g., active, complete, or in progress.
* **Session Start Time (\*)** (`session_check_in_form_6`, `time`, required): Enter the start time of the session accurately.
* **Session End Time (\*)** (`session_check_in_form_7`, `time`, required): Enter the end time of the session accurately.
* **Session Duration (\*)** (`session_check_in_form_8`, `number`, required): Enter the length of the session accurately.
* **Session Checkin Time (\*)** (`session_check_in_form_10`, `date`, required): Enter the time of the current session checkin.
* **Session Check-out Time (\*)** (`session_check_in_form_11`, `date`, required): Enter the time of the current session check-out.
* **Session Start Date (\*)** (`session_check_in_form_12`, `date`, required): Select the date of the current session start.
* **Session End Date (\*)** (`session_check_in_form_13`, `date`, required): Select the date of the current session end.
* **Session Provider Phone** (`session_check_in_form_14`, `text`, optional): Enter the provider's phone number, if applicable.

* **Session Notes** (`session_check_in_form_23`, `note`, optional): Enter any notes for the current session, if applicable.
