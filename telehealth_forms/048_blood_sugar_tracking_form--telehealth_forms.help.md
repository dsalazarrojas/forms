# Blood Sugar Tracking Form - Help Guide

## Purpose
This Blood Sugar Tracking Form is designed to help individuals with diabetes track their blood glucose readings, monitor their patient information, and manage their diabetes condition. This form is intended to be filled out by the individual tracking their blood sugar levels and any other relevant information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your **Patient Name**, which is a required field.
2. Enter your **Date of Birth**, which is a required field.
3. Select your **Diabetes Type** from the provided options (Type 1, Type 2, Gestational, Prediabetes, or Not Diagnosed).
4. Enter the **Tracking Date**, which is when the blood sugar reading was taken.
5. Enter the **Reading Time**, which is when the blood sugar reading was taken.
6. Enter your **Glucose Level**, which is in mg/dL.
7. Select the **Reading Type** from the provided options (Fasting, Before Breakfast, After Breakfast, Before Lunch, After Lunch, Before Dinner, After Dinner, or Bedtime).
8. If applicable, enter your **Meal Carbohydrates** consumed, which can be any value.
9. If applicable, enter a brief description of what you ate.
10. If applicable, enter your **Insulin Dose** in units taken.
11. If applicable, select the **Insulin Type** used.
12. If applicable, select if you have taken any **Oral Medication**.
13. If applicable, list your **Medication Name**.
14. If you exercised today, select **Yes** or **No**.
15. If you exercised, select a brief description of what type of exercise you did.
16. If you are experiencing any **Symptoms**, select all that apply (None, Shakiness, Sweating, Hunger, Dizziness, Confusion, Fatigue, Blurred Vision, Headache).
17. If applicable, rate your **Stress Level** from 1-10.
18. If applicable, select if you are feeling **Ill** (Yes or No).
19. If applicable, enter any additional **Notes**.

## Field-by-Field Explanation

* **Patient Name**: A required field for identifying the patient.
* **Date of Birth**: A required field for patient information.
* **Diabetes Type**: Select the type of diabetes you have been diagnosed with.
* **Tracking Date**: The date when the blood sugar reading was taken.
* **Reading Time**: The time when the blood sugar reading was taken.
* **Glucose Level**: Enter your blood sugar reading in mg/dL.
* **Reading Type**: Select when the blood sugar reading was taken.
* **Meal Carbohydrates**: If known, enter the amount of carbs consumed.
* **Meal Description**: If applicable, describe what you ate.
* **Insulin Dose**: If applicable, enter the units of insulin taken.
* **Insulin Type**: If applicable, select the type of insulin used.
* **Oral Medication**: If applicable, select if you took any oral medication.
* **Medication Name**: If applicable, list the medication name.
* **Exercise Today**: Select if you exercised today (Yes or No).
* **Exercise Type**: If applicable, describe the type of exercise you did.
* **Symptoms**: Select all applicable symptoms you are experiencing.
* **Stress Level**: If applicable, rate your stress level from 1-10.
* **Feeling Ill**: Select if you are feeling ill (Yes or No).
* **Notes**: Any additional comments or observations.
