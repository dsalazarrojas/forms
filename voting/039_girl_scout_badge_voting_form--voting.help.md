# Girl Scout Badge Voting Form - Help Guide
## Purpose
The Girl Scout Badge Voting Form is a tool for collecting voting preferences for badge design or selection. It helps in making informed decisions based on community input.

## How To Complete This Form
To complete this form, follow the steps above.

## Field-by-Field Explanation

* **form_id** (number, **form id**, required): Enter a unique id for the form to identify and track it.
* **category** (select_one, **category**, optional): Choose a category from the dropdown options to help narrow down the type of badge being voted on.
* **description** (text, **description**, required): Enter a description for the badge that corresponds to the chosen category. This is a required field and should be relevant and unique.
* **description 2** (text, **description 2**, optional): Enter a description for the second badge in the chosen category, if applicable.
* **description 3** (text, **description 3**, optional): Enter a description for the third badge in the chosen category, if applicable.
