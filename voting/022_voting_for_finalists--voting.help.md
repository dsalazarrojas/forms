# Voting For Finalists - Help Guide
## Purpose
The form is used to collect votes for the selected finalists in a voting process. It is essential to complete this form accurately to ensure that your vote is counted correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. On each page, carefully read the label and options provided for each field.
2. Select the options that best represent your preferences.
3. If a field is required, ensure you complete it accurately.
4. Use the space provided for any additional comments or explanations.

## Field-by-Field Explanation

* **Select Your Vote (1)**: Select 'True', 'False', or 'I'm Not Sure' to express your opinion on the current page.
* **Describe Your Preferences (2)**: Enter a brief description of your thoughts and preferences regarding the current page.
* **Date of Vote (3)**: Enter the date you are voting on. The format should be in the format 'YYYY-MM-DD'.
* **Time of Vote (4)**: Enter the time you are voting on. The format should be in the format 'HH:MM'.
* **Email Address (5)**: Enter your valid email address to ensure we can contact you with the results of your vote.
* **Rating 1 (6)**: Rate the current page on a scale of 1-10, with 1 being the lowest and 10 being the highest.
* **Rating 2 (7)**: Rate the current page on a scale of 1-10, with 1 being the lowest and 10 being the highest.
* **Select Multiple Options (8)**: Select all the options that apply to you for the current page.
* **Vote for Group (9)**: Select 'True' if you want to vote for the current group, or 'False' otherwise.
* **Select Multiple Options (10)**: Select all the options that apply to you for the current page.
* **Select One Option (11)**: Select the option that best represents your choice for the current page.
* **Thoughts (12)**: Enter any additional thoughts or comments you have regarding the current page.

Note: Ensure you have completed all required fields before submitting your vote.
