# Space Model Competition Voting - Help Guide
## Purpose
The Space Model Competition Voting form is designed to help judges evaluate and provide feedback on submissions in a space model competition. The form allows users to select which submissions they will be evaluating, and to provide their scores and comments for each selected submission.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select all judges that will be evaluating the submissions.
2.  Select the scores for each submission.
3.  Select all submissions that you want to evaluate.
4.  Select the scores for each selected submission.
5.  Enter any additional comments or feedback for each submission.
6.  Enter your email address so that the competition organizers can contact you.
7.  Enter your phone number, if applicable.

## Field-by-Field Explanation

* **Select Judges** (Select Multiple, optional): Select all judges that will be evaluating the submissions. This field allows you to choose which judges will be responsible for evaluating each submission.
* **Select Scores** (Select Multiple, optional): Select the scores for each submission. This field allows you to choose the scores for each submission based on the scores provided in the submission.
* **Select Submissions** (Select Multiple, optional): Select all submissions that you want to evaluate. This field allows you to choose which submissions you will be evaluating.
* **Select Scores** (Select Multiple, optional): Select the scores for each selected submission. This field allows you to choose the scores for each submission.
* **Submit Feedback** (Note, optional): Enter any additional comments or feedback for each submission. This field is for providing more detailed feedback on each submission.
* **Additional Comments** (Note, optional): Enter any additional comments or feedback for each submission. This field is similar to "Submit Feedback" and allows you to provide more detailed feedback.
* **Submit** (Text, optional): Enter any additional information or comments. This field is not clearly labeled, but it seems to be intended for entering any additional information or comments.
* **Email** (Email, optional): Enter your email address so that the competition organizers can contact you. This field is for entering your email address.
* **Phone** (Text, optional): Enter your phone number, if applicable. This field is for entering your phone number.
