# Halloween Costume Contest Voting Form - Help Guide

## Purpose
This form is used to cast votes for participants in the Halloween costume contest. To ensure a fair and accurate outcome, please make sure to fill out the form completely and honestly.

## How To Complete This Form
To complete this form, simply select the options as instructed below. You can select multiple options for some fields if needed.

## Field-by-Field Explanation
* **Vote For** (`id: 1`, `type: select_one`): Choose whether or not you want to vote for the contest. This will determine whether or not your vote will be counted towards the total.
* **Vote For** (`id: 2`, `type: select_multiple`): Select multiple contestants you would like to vote for. You can choose as many or as few as you like.
* **Contestant Name** (`id: 3`, `type: text`): If you want to vote for a specific contestant, enter their name here. If you're not sure of their name, just put in the best guess you can.
* **Contest Costume** (`id: 4`, `type: text`): If you'd like to leave a brief description or comment about the costume, enter it here.
* **Contest Image** (`id: 5`, `type: text`): If you'd like to leave a link to a picture of the costume, enter the URL here. This can be helpful for further reference.

## Tips
- Be honest and accurate when voting.
- Make sure to select only contestants you have actually seen.
- If you're unsure of a contestant's name, try to guess or leave a note in the "Contestant Name" field.
- If you'd like to leave a description or comment, use the "Contest Costume" field.
- If you'd like to leave a link to a picture, use the "Contest Image" field.
