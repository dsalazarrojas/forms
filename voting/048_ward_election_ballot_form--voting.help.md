# Ward Election Ballot Form - Help Guide
## Purpose
The Ward Election Ballot Form is designed to collect information for a ward election output file. This form is meant to be filled out by users who need to participate in the ward election process.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the category of the ward election.
2. Provide a brief description of the ward election.
3. Choose the output file name for the election results.
4. Optionally, select the assigned tool and form ID for the ward election.
5. Fill in the form ID number.
6. Choose the category of the ward election again to confirm the selection.
7. Enter the desired name for the output file.

## Field-by-Field Explanation
### 1. **Voting** (`ward_election_ballot_form_category`, select_one)
Select the category of the ward election: Voting or Other.

### 2. **Ward Election Ballot Form Input** (`ward_election_ballot_form_input`, text)
Provide a brief description of the ward election, if necessary. This field is not required, but it can be helpful in providing context for the output file.

### 3. **Description** (`ward_election_ballot_form_description`, text)
Enter a brief description of the ward election. This field is not required, but it can aid in the understanding of the election details.

### 4. **Output File** (`ward_election_ballot_form_output_file`, text)
The output file will be created in the output directory, with the specified name. This field is not required, but it can help ensure the correct output file is generated.

### 5. **Assigned Tool** (`ward_election_ballot_form_assigned_tool`, text)
Select the tool assigned for the ward election, if applicable. This field is not required, but it can help identify the tool used for the election.

### 6. **Form ID** (`ward_election_ballot_form_form_id`, number)
Enter the form ID number for the ward election. This field is not required, but it can help track the election process.

### 7. **Category** (`ward_election_ballot_form_form_category`, select_one)
Reconfirm the category of the ward election: Voting or Other. This field is not required but helps ensure correct category selection.

### 8. **Output File Name** (`ward_election_ballot_form_output_filename`, text)
Enter the desired name for the output file. The output file will be created in the output directory.
