# Which Pumpkin Is Your Favorite Form - Help Guide
## Purpose
This form is designed to help us understand your preferences for pumpkins. Please answer the questions honestly to help us better understand your interests and behaviors related to pumpkins.

## How To Complete This Form
1. To complete the form, simply select your responses to each question and submit the form when finished.
2. You can select multiple options for questions that allow it (e.g., which_pumpkin_is_your_favorite).
3. You can enter free-text answers for questions that have text fields (e.g., other_pumpkin_size, other_pumpkin_color, special_features).

## Field-by-Field Explanation
### Which Pumpkin Is Your Favorite? (<name>: which_pumpkin_is_your_favorite, <type>: select_multiple)
Select all that apply:
* 'Yes'
* 'No'

### Favorite Pumpkin Size (<name>: favorite_pumpkin_size, <type>: number)
Enter your preferred pumpkin size.

### Favorite Pumpkin Color (<name>: favorite_pumpkin_color, <type>: select_one)

### Other Pumpkin Size (<name>: other_pumpkin_size, <type>: text)

### Special Features Important (<name>: special_feature_important, <type>: select_multiple)

## Tips
* Make sure to submit the form only once.
* You can only select one option for questions that have select_one type.
