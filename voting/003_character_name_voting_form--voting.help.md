# Character Name Voting Form - Help Guide

## Purpose
This form is designed to collect user preferences for character names in a fictional universe. The data collected will be used to create a list of name preferences and characteristics to help with character development.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name or username in the "Voter Name" field. This is a required field.
2. Provide a valid email address in the "Email Address" field. This will be used for vote confirmation purposes, but it is not required.
3. Select your preferred character gender from the options provided in the "Character Gender" field.
4. If you would like to suggest a custom name, provide it in the "Custom Suggestion" field. This is optional.
5. Choose a name that fits your preferred character style from the "What name style do you prefer" options.
6. Select how important you think the name meaning is from the "Is name meaning important to you" options.
7. If you have a custom name suggestion, describe why you prefer it in the "Why did you choose this name" field.
8. Select the personality traits that your preferred name should reflect from the "What personality should the name reflect" options. (You can choose multiple options.)
9. Finally, select your age group from the "Voter age group" options.

## Field-by-Field Explanation

*   **Voter Name** (`name`, `text`, **required**): Enter your name or username.
*   **Email Address** (`email`, **required**: Enter a valid email address for vote confirmation.
*   **Character Gender** (`select_one`, **required**): Select the character gender you prefer. Options are:
    *   Male
    *   Female
    *   Non-binary
    *   Other
    *   Prefer not to say
*   **Preferred name for male character** (`select_one`, **optional**): Choose your favorite name for a male character.
    *   Options are: Alexander, Benjamin, Christopher, Daniel, Ethan, Gabriel, Harrison
*   **Preferred name for female character** (`select_one`, **optional**): Choose your favorite name for a female character.
    *   Options are: Amelia, Charlotte, Eleanor, Isabella, Olivia, Sophia, Victoria
*   **Preferred name for non-binary character** (`select_one`, **optional**): Choose your favorite name for a non-binary character.
    *   Options are: Alex, Avery, Jordan, Morgan, Quinn, Riley, Taylor
*   **What name style do you prefer** (`select_one`, **required**): Choose the name style that fits your character.
    *   Options are: Classic and traditional, Modern and unique, Fantasy inspired, Historical, Nature based, Cultural heritage
*   **Is name meaning important to you** (`select_one`, **required**): Choose how important you think the name meaning is.
    *   Options are: Very important, Somewhat important, Neutral, Not important
*   **Do you have a custom name suggestion** (`text`, **optional**): Share your name suggestion if you have one.
*   **Why did you choose this name** (`text`, **optional**): Explain why you prefer this name if you have a custom suggestion.
*   **What personality should the name reflect** (`select_multiple`, **optional**): Select the personality traits your preferred name should reflect.
    *   Options are: Strong and bold, Gentle and kind, Mysterious, Intelligent, Playful, Noble, Rebellious
*   **Voter age group** (`select_one`, **optional**): Select your age group for demographic purposes.
    *   Options are: Under 18, 18 to 24, 25 to 34, 35 to 44, 45 to 54, 55 or older
