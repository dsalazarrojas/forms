# Director Election Ballot - Help Guide
## Purpose
The Director Election Ballot form is a tool to collect information for the election of a Director. This form allows users to express their opinions and cast their votes for the available options. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select 'Yes' or 'No' for each board member in question 1.
2. Select one option from 1 to 16 for each question 2 to 16.

## Field-by-Field Explanation
- **board_members** (`board_members`, Select Multiple, Optional): Select 'Yes' or 'No' for each board member to indicate whether they are running for the position or not.
  - This field allows you to select which board members you want to vote for.
- **Vote For** (`vote_for`, Select One, Optional): Select one option from 1 to 16 to indicate the person you want to vote for.
  - This field allows you to select a single option for the vote.
- **Title** (`vote_for_title`, Text, Optional): Enter the title of the person you are voting for.
  - This field is optional and only used if you select an option.
- **Initials** (`vote_for_initials`, Text, Optional): Enter the initials of the person you are voting for.
  - This field is only visible when 'Title' is completed and is optional.
- **Phone** (`vote_for_phone`, Text, Optional): Enter the phone number of the person you are voting for.
  - This field is optional and can be used if 'Initials' is completed.
- **Email** (`vote_for_email`, Text, Optional, Email): Enter the email of the person you are voting for.
  - This field is optional and can be used if 'Phone' is completed.
- **Date** (`vote_for_date`, Date, Optional): Select a date for the vote.
  - This field is optional and can be used if any of the previous fields are completed.
- **Time** (`vote_for_time`, Time, Optional): Select a time for the vote.
  - This field is optional and can be used if 'Date' is completed.
- **Note** (`vote_for_note`, Note, Optional): Enter a note about the vote.
