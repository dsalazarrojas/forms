# Best Agent Voting Poll - Help Guide

## Purpose
The "Best Agent Voting Poll" form is designed to collect feedback from agents on various aspects of a project or initiative, including primary selections, estimated values, and preferred times. The collected data will be used to inform and improve the project's performance.

## How To Complete This Form
1. Click on the "Begin" button to start filling out the form.
2. Review the form carefully to ensure you have all the necessary information.
3. Fill out each field with your honest and informed input, following the instructions provided for each field.
4. Click on the "Submit" button to submit your completed form.

## Field-by-Field Explanation
### Personal Information
* **-- Personal Information --** (`section_personal_information`, note, required/optional): This is an informational section that provides context for the rest of the form. Please do not enter any personal information here; instead, focus on the subsequent fields.

### 1. Full name
* **Full name** (`full_name`, text, required): Enter your legal full name for the purpose of this poll.

### 2. Email address
* **Email address** (`email`, email, required): Enter a valid email address for contact purposes. This will enable us to get back to you with any follow-up questions or updates.

### 3. Phone number
* **Phone number** (`phone`, text, optional): If you have a phone number and would like to be contacted, please include it here. Please note the format of the number should include the country code if not local.

### 4. Date
* **Date** (`reference_date`, date, required): Select the date that is most relevant for this poll.

### 5. Primary selection
* **Primary selection** (`primary_selection`, select_one, required): Choose the option that best applies to the context of this poll.

### 6. Quantity or rating
* **Quantity or rating** (`quantity_or_rating`, number, optional): Provide a whole number for quantity or rating if applicable.

### 7. Additional details
* **Additional details** (`additional_details`, text, optional): Provide any additional information that you believe would be helpful for us to know.

### 8. Agreement
* **Please confirm agreement** (`agreement`, select_multiple, required): Select all that apply from the options provided.

### 9. Estimated value
* **Estimated value** (`estimated_value`, number, optional): Use a decimal format if applicable.

### 10. Preferred time
* **Preferred time** (`preferred_time`, time, optional): Enter a time if scheduling is required.

### 11. Final comments or notes
* **Final comments or notes** (`final_comments`, text, optional): Add any last-minute remarks or comments here.

Please submit this form after filling out all required fields, and thank you for taking the time to provide us with your input.
