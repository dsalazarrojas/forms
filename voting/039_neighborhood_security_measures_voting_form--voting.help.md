# Neighborhood Security Measures Voting Form - Help Guide
## Purpose
The Neighborhood Security Measures Voting Form is designed to collect your opinions and preferences on neighborhood security measures. This information will help us understand your concerns and priorities for our community's safety.

## How To Complete This Form
To complete this form, simply fill out each field as instructed below.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, optional): Provide a brief title for your submission.
* **Security Concerns** (`security_concerns`, select_one, optional): Choose the security concern that is most important to you:
	+ Option 1: ...
	+ Option 2: ...
	+ Option 3: ...
* **Safety Measures** (`safety_measures`, select_multiple, required): Select all applicable safety measures you would like to implement:
	+ Option 1: ...
	+ Option 2: ...
* **Comments** (`comments`, note, optional): Provide any additional comments or suggestions you have for neighborhood security.
* **Email Address** (`email_address`, email, optional): If you'd like to be contacted for follow-up, please provide your email address.
* **Phone Number** (`phone_number`, text, optional): If you'd like to be contacted for follow-up, please provide your phone number.
* **Date** (`date`, date, optional): Select the date you would like to implement the safety measures.
* **Time** (`time`, time, optional): Select the time you would like to implement the safety measures.
* **Submit** (`submit`, select_one, required): Choose how you would like to submit your input:
	+ Option 1: ...
	+ Option 2: ...
Note: Fields with an asterisk (\*) are required.
