# dance_season_repertoire_voting_form - Help Guide
## Purpose
The dance season repertoire voting form is a tool used to collect user feedback on the dance season repertoire. It helps us understand which dances are popular among users and make informed decisions on which dances to include in the season repertoire.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the "Dance Repertoire List" page, which shows a list of available dances.
2. On the "Vote For" page, select "Yes" or "No" for the first dance.
3. On the "Second Dance" page, select "Yes" or "No" for the second dance.
4. Optionally, enter your preferred second dance in the "Second Dance" text field.
5. Optionally, enter your preferred first dance in the "First Dance" text field.

## Field-by-Field Explanation

* **Dance Repertoire List** (1, note, optional): This page shows a list of available dances for you to vote on. Review the list to see which dances you are interested in voting for.
* **Vote For** (2, select_one, optional): Select "Yes" next to the first dance you would like to perform, or "No" if you are not interested in performing it.
* **Vote For** (3, select_one, optional): Select "Yes" next to the second dance you would like to perform, or "No" if you are not interested in performing it.
* **Second Dance** (4, text, optional): Enter the name of your preferred second dance, if you would like to suggest a different dance.
* **First Dance** (5, text, optional): Enter the name of your preferred first dance, if you would like to suggest a different dance.

## Tips
* Please only select "Yes" for dances you are really interested in performing.
* Please enter your preferred dances in the text fields, and we will consider them for future seasons.
* Thank you for taking the time to help us improve the dance season repertoire!
