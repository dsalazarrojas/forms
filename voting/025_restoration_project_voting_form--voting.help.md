# Restoration Project Voting Form - Help Guide
## Purpose
This form is designed to collect votes for restoration projects. It helps to gauge the community's interest and support for various projects, ensuring that the most popular ideas get the necessary resources and attention. By filling out this form, you'll be providing valuable feedback to project leaders and contributors.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill out each field according to your opinion. Make sure to provide as much detail as possible for fields that allow text input.
2. For fields with options, select the one that best represents your opinion or preference.
3. If a field is not relevant to your opinion, you can leave it blank. However, please note that required fields cannot be left blank.
4. Review your form carefully before submitting it to ensure that all required fields are filled out correctly.

## Field-by-Field Explanation

* **Project Title** (Project Title, text, required/optional): This field is where you'll enter the title of the project you're voting on.
* **Project Description** (Project Description, text, required/optional): Briefly describe the project you're voting on. This will help others understand the project's scope and goals.
* **Project Budget** (Project Budget, number, required/optional): Enter the estimated budget for the project, if applicable.
* **Category** (Category, select_one, required): Select the category that best fits the project. This helps to categorize and filter projects for easier management.
* **Project Lead** (Project Lead, text, required/optional): If you're familiar with the project lead or team, you can mention them here.
* **Project Start Date** (Project Start Date, date, required/optional): Enter the start date of the project, if known.
* **Project End Date** (Project End Date, date, required/optional): Enter the end date of the project, if known.
* **Project Location** (Project Location, text, required/optional): If the project has a specific location, enter it here.
* **Project Status** (Project Status, select_multiple, required): Select all the status options that apply to the project (e.g., "Completed," "In Progress," "Cancelled").
* **Project Comments** (Project Comments, text, required/optional): Add any additional comments or feedback about the project.
* **Project Rating** (Project Rating, number, required/optional): If applicable, enter a rating for the project (e.g., a score out of 10).
* **Project Votes** (Project Votes, number, required/optional): Enter the number of votes for the project, if applicable.
* **Project Votes For** (Project Votes For, text, required/optional): If applicable, enter the number of votes for or against the project.
* **Project Votes Against** (Project Votes Against, text, required/optional): If applicable, enter the number of votes against the project.
* **Project Votes Abstain** (Project Votes Abstain, text, required/optional): If applicable, enter the number of votes abstained.
* **Project Idea** (Project Idea, text, required/optional): If applicable, enter a brief idea for the project.
* **Project Tags** (Project Tags, text, required/optional): Add relevant tags or keywords for the project.
* **Project Image** (Project Image, text, required/optional): If applicable, enter the URL or link to the project's image.
* **Project Video** (Project Video, text, required/optional): If applicable, enter the URL or link to the project's video.
