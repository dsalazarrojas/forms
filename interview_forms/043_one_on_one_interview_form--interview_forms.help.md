# One On One Interview Form - Help Guide
## Purpose
The One On One Interview Form is used for conducting one-on-one interviews with participants. This form helps gather information from the participant and stores it in a secure location.

## How To Complete This Form
To complete this form, follow these steps:

1.  Read through each page to understand what information is being asked for.
2.  Start at page 1, which is the introduction. This page provides background information about the participant.
3.  Move on to page 2, which consists of three options. Select the one that best describes the participant's situation.
4.  On page 3, type in any notes or observations from the interview.
5.  If you have the participant's email address, enter it on page 4. This will help them get in touch with you if needed.
6.  If you have the participant's phone number, enter it on page 5.

## Field-by-Field Explanation

*   **Introduction** (`page 1`, `note`, not required): This page is to provide background information about the participant. It is a read-only page and does not require input.
*   **Interview Questions** (`page 2`, `select one`, not required): On this page, select the best option that describes the participant's situation. This will help us better understand their circumstances.
*   **Notes** (`page 3`, `text`, not required): Write any notes or observations you made during the interview. This will help us better understand the participant's situation.
*   **Email** (`page 4`, `email`, not required): If you have the participant's email address, enter it here. This will help us get in touch with them if needed.
*   **Phone Number** (`page 5`, `text`, not required): If you have the participant's phone number, enter it here. This will help us get in touch with them if needed.

## Tips
*   Please fill out as much as possible.
*   Ensure you are in a quiet and private location when completing this form.
*   If you are having trouble filling out this form, please contact the interviewee directly.
*   If you have any questions or concerns, contact the relevant department or team directly.
