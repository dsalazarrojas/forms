# Vendor Clerk Interview Questionnaire - Help Guide
## Purpose
This form is designed to collect information from vendors for a specific interview process. The goal is to gather essential details about the candidate to facilitate a smooth and effective interaction.

## How To Complete This Form
1. Start by filling out the form in a new tab or window to ensure that your responses are saved.
2. Enter the candidate's name in the "Candidate Name" field.
3. Provide the contact email address of the candidate in the "Contact Email" field.
4. Enter the candidate's contact phone number in the "Contact Phone" field.
5. In the "Availability" field, enter a brief note about the candidate's availability.
6. Select "Yes" or "No" for "Work Experience" and "Skills" to indicate the candidate's qualifications.
7. Similarly, select "Yes" or "No" for "Qualifications" to confirm the candidate's qualifications.
8. Enter the expected hire date in the "Expected Hire Date" field.
9. Select the start and end times of the candidate's availability in the "Availability Start" and "Availability End" fields.
10. Select the candidate's work status as "Active" or "Inactive" in the "Work Status" field.
11. Choose the type of work the candidate is available for as "Yes" or "No" in the "Work Type" field.
12. Finally, enter a description of the type of work the candidate is available for in the "Work Type Description" field.

## Field-by-Field Explanation

* **Candidate Name (candidate_name)**: Enter the name of the candidate being interviewed.
* **Contact Email (contact_email)**: Enter the candidate's contact email address.
* **Contact Phone (contact_phone)**: Enter the candidate's contact phone number.
* **Availability (availability)**: Enter a brief note about the candidate's availability.
* **Work Experience (work_experience)**: Select "Yes" if the candidate has work experience, otherwise select "No".
* **Skills (skills)**: Select "Yes" if the candidate has the required skills, otherwise select "No".
* **Qualifications (qualifications)**: Select "Yes" if the candidate has the required qualifications, otherwise select "No".
* **Expected Hire Date (expected_hire_date)**: Enter the date the candidate is expected to be hired.
* **Availability Start (availability_start)**: Select the start time of the candidate's availability.
* **Availability End (availability_end)**: Select the end time of the candidate's availability.
* **Work Status (work_status)**: Select "Active" if the candidate is currently working, otherwise select "Inactive".
* **Work Type (work_type)**: Select "Yes" if the candidate is available for this type of work, otherwise select "No".
* **Work Type Description (work_type_description)**: Enter a description of the type of work the candidate is available for.
