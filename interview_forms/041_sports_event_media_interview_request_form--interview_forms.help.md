# Sports Event Media Interview Request Form - Help Guide
## Purpose
The Sports Event Media Interview Request Form is designed for media representatives to request interviews with athletes, teams, or other stakeholders related to sports events. It helps event organizers and media representatives to coordinate and schedule interviews efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of request you are making (Request or Interview).
2. Choose the date and time you would like to schedule the interview.
3. Provide your contact information, including email and phone number.
4. Specify the location where you would like to conduct the interview.
5. Enter the name of the event you are interested in.
6. Add any additional details about the request in the Request Details field.
7. Choose the type of media you represent (Photo, Video, or Audio).
8. Select the decision of the event organizer regarding your request (Approve or Deny).
9. If approved, add any comments or feedback for the event organizer.
10. Enter the name of the person you would like to assign to handle your request.

## Field-by-Field Explanation

* **Request Type** (`request_type`, select_one, required): Choose between Request and Interview to specify the type of request you are making.
* **Date** (`request_date`, date, required): Enter the date you would like to schedule the interview.
* **Time** (`request_time`, time, required): Enter the time you would like to conduct the interview.
* **Interview Requester** (`interview_requester`, text, required): Provide your name and affiliation (e.g., media outlet, company).
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Location** (`location`, text, optional): Specify the location where you would like to conduct the interview.
* **Event Name** (`event_name`, text, optional): Enter the name of the event you are interested in.
* **Request Details** (`request_details`, text, optional): Add any additional details about your request.
* **Media Type** (`media_type`, select_one, required): Choose between Photo, Video, or Audio to specify the type of media you represent.
* **Decision** (`decision`, select_multiple, required): Select Approve or Deny from the event organizer.
* **Comments** (`comments`, text, optional): Add any comments or feedback for the event organizer.
* **Assignee** (`assignee`, text, optional): Enter the name of the person you would like to assign to handle your request.
