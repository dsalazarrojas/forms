# rescue_mission_interview_form - Help Guide

## Purpose
This form is used to collect information about rescue missions, including details about applicants, contact information, and response teams. It is crucial to provide accurate and complete data to ensure effective rescue operations.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the applicant details section with the relevant information about the applicant.
2. Provide contact details, including email and phone number.
3. Answer questions about the rescue history, role, and status of the applicant.
4. Select the correct options for response team, location, and emergency contact.
5. Answer questions about team member status and response team 2 status.

## Field-by-Field Explanation

* **applicant_details** (Text, Required: False): Enter the details about the applicant.
* **contact_details** (Text, Required: False): Provide the contact information for the applicant.
* **rescue_history** (Text, Required: False): Describe the rescue history of the applicant.
* **rescue_role** (Select One, Required: False): Indicate the rescue role of the applicant.
* **rescue_role** (Select Multiple, Required: False): Select multiple rescue roles of the applicant.
* **interview_date** (Date, Required: False): Select the date of the interview.
* **interview_time** (Time, Required: False): Select the time of the interview.
* **rescue_note** (Note, Required: False): Add any additional notes about the rescue mission.
* **rescue_email** (Email, Required: False): Enter the email address of the applicant.
* **rescue_phone** (Text, Required: False): Enter the phone number of the applicant.
* **rescue_phone_type** (Select One, Required: False): Indicate the type of phone number (Yes/No).
* **rescue_phone_ext** (Select Multiple, Required: False): Select multiple types of phone numbers.
* **rescue_status** (Select One, Required: False): Indicate the status of the applicant (Active/Inactive).
* **rescue_status_2** (Select Multiple, Required: False): Select multiple statuses of the applicant.
* **emergency_contact** (Select Multiple, Required: False): Indicate if emergency contact is necessary.
* **emergency_contact_ext** (Select Multiple, Required: False): Select multiple emergency contact options.
* **response_team** (Select Multiple, Required: False): Select the response teams involved.
* **response_team_ext** (Select Multiple, Required: False): Select multiple response teams.
* **rescue_location** (Select One, Required: False): Indicate the location of the rescue mission.
* **rescue_location_2** (Select One, Required: False): Indicate the second location of the rescue mission.
* **location_ext** (Select Multiple, Required: False): Select multiple locations of the rescue mission.
* **response_team_2** (Select Multiple, Required: False): Select the second response team involved.
* **response_team_2_ext** (Select Multiple, Required: False): Select multiple second response teams.
* **team_member_status** (Select One, Required: False): Indicate the status of team members (Active/Inactive).
* **team_member_status_2** (Select Multiple, Required: False): Select multiple statuses of team members.
