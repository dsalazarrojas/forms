# Consultancy Research Analyst Interview Form - Help Guide
## Purpose
This form is used to capture information about a candidate during an interview process for a consultancy research analyst position.

## How To Complete This Form
1. Select the interview stage from the "Interview Stage" field.
2. Fill out the candidate's identification information, including their full name, email address, phone number, and date of interview.
3. Assess the candidate's skills and competencies by rating their analytical and problem-solving skills, primary research and data collection proficiency, written and verbal communication skills, technical tools proficiency, and time management and prioritization skills.
4. Provide qualitative feedback on the candidate's performance, including their single greatest professional strength and primary area for improvement.
5. Make a hiring recommendation based on the candidate's overall performance.
6. Add any additional comments about the candidate.
7. Date and submit the form.

## Field-by-Field Explanation

* **Candidate Full Name**: The candidate's full name as provided by the candidate. Please ensure this field is accurate and complete.
	+ Type: Text
	+ Required: True
* **Candidate Email Address**: The candidate's email address as provided by the candidate. Please ensure this field is accurate and complete.
	+ Type: Email
	+ Required: True
* **Candidate Phone Number**: The candidate's phone number as provided by the candidate. Please ensure this field is accurate and complete.
	+ Type: Text
	+ Required: True
* **Date of Interview**: The date of the interview with the candidate. This will help track interview completion dates.
	+ Type: Date
	+ Required: True
* **Interview Stage**: The stage of the interview process (e.g., Initial Screening/Recruiter Call, Technical Interview (Case Study), Partner Interview (Behavioral), Final Executive Review).
	+ Type: Select One
	+ Required: True
* **Interviewer's Name and Title**: The name and title of the interviewer.
	+ Type: Text
	+ Required: True
* **Interviewing Department**: The department within the consultancy that the candidate is applying to.
	+ Type: Select One
	+ Required: True
* **Analytical and Problem-Solving Skills**: Rate the candidate's analytical and problem-solving skills (1 - Poor, 5 - Exceptional).
	+ Type: Number
	+ Required: True
* **Primary Research and Data Collection Proficiency**: Rate the candidate's primary research and data collection proficiency (1 - Poor, 5 - Exceptional).
	+ Type: Number
	+ Required: True
* **Written and Verbal Communication Skills**: Rate the candidate's written and verbal communication skills (1 - Poor, 5 - Exceptional).
	+ Type: Number
	+ Required: True
* **Technical Tools Proficiency**: Rate the candidate's technical tools proficiency (e.g., Excel, SQL, Tableau, etc.) (1 - Poor, 5 - Exceptional).
	+ Type: Number
	+ Required: True
* **Time Management and Prioritization Skills**: Rate the candidate's time management and prioritization skills (1 - Poor, 5 - Exceptional).
	+ Type: Number
	+ Required: True
* **Single Greatest Professional Strength**: Describe the candidate's single greatest professional strength.
	+ Type: Text
	+ Required: True
* **Primary Area for Improvement**: Describe the primary area for improvement for the candidate.
	+ Type: Text
	+ Required: True
* **Perceived Cultural Fit with the Consultancy**: Rate the candidate's perceived cultural fit with the consultancy (1 - Poor Fit, 5 - Excellent Fit).
	+ Type: Number
	+ Required: True
* **Overall Hiring Recommendation**: Select the overall hiring recommendation based on the candidate's performance.
	+ Type: Select One
	+ Required: True
* **Primary Reason for Recommendation**: Add a primary reason for the hiring recommendation (Max 1000 characters).
	+ Type: Text
	+ Required: True
* **Additional Interview Comments**: Add any additional comments about the candidate.
	+ Type: Text
	+ Required: False
* **Date of Interview Feedback Completion**: Date the form is completed and submitted.
	+ Type: Date
	+ Required: True
