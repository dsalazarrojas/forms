# Responsive Interview Questionnaire Form - Help Guide
## Purpose
The purpose of this form is to collect information about job opportunities, allowing users to input details about job titles, companies, locations, and other relevant job-related information.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the form and ensure you are on the correct page for the relevant job opportunity.
2. Fill out each field with the relevant information about the job opportunity.
3. Use the options provided for select fields to choose the correct answer.

## Field-by-Field Explanation

### Job Application
* **Job Application**: A brief description of the job opportunity.
	+ Type: Text Field
	+ Required: No

### Work Experience
* **Work Experience**: A description of your relevant work experience.
	+ Type: Text Field
	+ Required: No

### Personal Info
* **Personal Info**: Any relevant personal information about yourself.
	+ Type: Text Field
	+ Required: No

### Education
* **Education**: Your educational background.
	+ Type: Text Field
	+ Required: No

### Skills
* **Skills**: A list of relevant skills you possess.
	+ Type: Text Field
	+ Required: No

### Availability
* **Availability**: Your availability for the job opportunity.
	+ Type: Text Field
	+ Required: No

### Job References
* **Job References**: A list of relevant job references.
	+ Type: Text Field
	+ Required: No

### Job Description
* **Job Description**: A detailed description of the job.
	+ Type: Text Field
	+ Required: No

### Job Title

	+ Type: Text Field
	+ Required: No

### Job Position

	+ Type: Text Field
