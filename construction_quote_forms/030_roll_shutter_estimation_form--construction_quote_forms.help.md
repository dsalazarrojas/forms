# Roll Shutter Estimation Form - Help Guide
## Purpose
The Roll Shutter Estimation Form is a tool for construction professionals to collect and organize information about a roll shutter project. This form helps to ensure accuracy and thoroughness in the estimation process.

## How To Complete This Form
1. Select the relevant project information from the "Project Info" page.
2. Fill in the details about the house and its features on the "House Info" and "Roof Info" pages.
3. Choose the type and style of the house on the "House Type" and "House Style" pages.
4. Select the type of wall for the house on the "Wall Type" page.
5. Add any additional room information on the "Room Info" page.

## Field-by-Field Explanation
* **Project Info** (`project_info_page`, select_one, required): This field is where you select the project type from the options provided. It is essential to choose the correct project type to ensure accurate estimation.
* **House Info** (`house_info_page`, select_multiple, required): Select all that apply from the options provided to describe the house features.
* **Roof Info** (`roof_info_page`, text, optional): Enter any additional information about the roof that is not covered in the house features.
* **House Type** (`house_type_page`, select_one, required): Choose the type of house from the options provided.
* **House Style** (`house_style_page`, select_multiple, required): Select all that apply from the options provided to describe the house style.
* **Wall Type** (`wall_type_page`, select_one, required): Choose the type of wall for the house from the options provided.
* **Room Info** (`room_info_page`, text, optional): Enter any additional information about the room that is not covered in the house features.

Note: The form is designed to be completed in order, and each field is essential for accurate estimation.
