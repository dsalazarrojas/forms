# Parkland Development Quote Request - Help Guide
## Purpose
This form is used to gather information necessary for generating a quote request for a construction project. It includes fields for contact details, project information, and site visit details.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are authorized to submit this form. This form is intended for internal use only.
2. Enter the contact details of the person submitting the request, including name, phone number, and email.
3. Provide project details, such as project status, location, and description.
4. Enter the site visit details, including the visit date and status.
5. Complete the project budget and estimate fields.
6. Attach any necessary documents or supporting information to the form.
7. Review and submit the form for review and approval.

## Field-by-Field Explanation

* **Contact Name** (`contact_name`, text): Enter the name of the contact person.
* **Contact Phone** (`contact_phone`, text): Enter the phone number of the contact person.
* **Email** (`email`, email): Enter the email address of the contact person.
* **Project Status** (`project_status`, select_one): Select the current status of the project (Active, In Progress, Completed, or Cancelled).
* **Project Location** (`project_location`, text): Enter the location of the project site.
* **Visit Date** (`site_visit_date`, date): Enter the date of the site visit.
* **Project Description** (`project_description`, text): Enter a brief description of the project.
* **Project Notes** (`project_notes`, text): Enter any additional notes or comments about the project.
* **Site Visit Comments** (`site_visit_comments`, text): Enter any comments or observations from the site visit.
* **Project Estimate** (`project_estimate`, text): Enter an estimate of the project cost.
* **Estimated Cost** (`project_estimate_amount`, number): Enter the estimated cost of the project.
* **Project Quote Request** (`project_quote_request`, text): Enter the specific quote request for the project.
* **Site Visit Status** (`project_site_visit_status`, select_multiple): Select the status of the site visit (Pending, Approved, Completed, or In Progress).
* **Project Manager** (`project_manager`, text): Enter the name of the project manager.
* **Contact Company** (`contact_company`, text): Enter the name of the contact company.
* **Contact Title** (`contact_title`, text): Enter the title of the contact person.
* **Project Start Date** (`project_start_date`, date): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date): Enter the end date of the project.

## Tips

* Ensure that all required fields are completed before submitting the form.
* Use a consistent format for dates and numbers.
* Attach any supporting documentation or files to the form as necessary.
* Review the form carefully before submitting it to ensure accuracy and completeness.
