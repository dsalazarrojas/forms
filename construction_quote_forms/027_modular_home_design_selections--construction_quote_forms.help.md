# Modular Home Design Selections - Help Guide
## Purpose
This form is used to gather your preferences for a modular home design. Your input will help our designers and builders create a customized home that meets your needs and expectations.

## How To Complete This Form
To complete this form, simply select the options that best suit your preferences. You can choose from the following sections:
* Select Home Design
* Exterior Color Scheme
* Exterior Finish
* Interior Color Scheme
* Interior Finish
* Window Type
* Roof Type
* Floor Plan

## Field-by-Field Explanation
### 1. Select Home Design
* **Select Home Design**: This is the first step in creating your customized home design. Please select "Yes" if you want a home design that is a combination of different features or "No" if you prefer a single-style home design.
### 2. Exterior Color Scheme
* **Exterior Color Scheme**: Select "Yes" if you would like a specific exterior color scheme for your home.
* **Exterior Finish**: Select "Yes" if you would like a specific exterior finish for your home.
* **Interior Color Scheme**: Select "Yes" if you would like a specific interior color scheme for your home.
* **Interior Finish**: Select "Yes" if you would like a specific interior finish for your home.
### 3. Window Type
* **Window Type**: Select the types of windows you would like to have in your home (e.g., Double Hung, Single Hung, Fixed).
### 4. Roof Type
* **Roof Type**: Select the type of roof you would like to have in your home (e.g., Flat, Gable, Hip).
### 5. Floor Plan
* **Floor Plan**: Select the types of floor plans you would like to have in your home (e.g., Open, Closed, Hybrid).

## Tips
* Please select the options that best suit your preferences and needs.
* You can select multiple options for each field if applicable.
* If you have any questions or need help, feel free to contact us for assistance.
