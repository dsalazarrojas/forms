# Window Treatment Cost Calculator - Help Guide
## Purpose
This form is used to calculate the cost of window treatments such as blinds, curtains, and window coverings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct options for each field to provide accurate information about the window treatment.
2. Enter the window measurement details such as length and width.
3. Choose the window type, covering type, style, and material type.
4. Select the price range for the window treatment.
5. Enter the contact information to receive a quote or estimate.
6. Optionally, add additional comments or descriptions about the window treatment.
7. Submit the form to receive a calculated price for the window treatment.

## Field-by-Field Explanation

* **Window Measurement**: Enter the length and width of the window in inches.
	+ Length: The length of the window in inches.
	+ Width: The width of the window in inches.
* **Window Type**: Select the type of window you are quoting, such as double hung, single hung, or casement.
* **Measurement Method**: Choose how you measure the window, such as using a tape measure or a specific calculator.
* **Window Covering Type**: Select the type of window covering, such as blinds, curtains, or shades.
* **Window Style**: Choose the style of window, such as modern, traditional, or decorative.
* **Material Type**: Select the material used for the window treatment, such as wood, vinyl, or fabric.
* **Material Color**: Choose the color of the material used for the window treatment.
* **Quantity Needed**: Enter the number of windows to be treated.
* **Price Range**: Select the price range for the window treatment.
* **Contact Name**: Enter your name and title.
* **Contact Email**: Enter your email address.
* **Contact Phone**: Enter your phone number.
* **Message**: Add any additional comments or questions you have about the window treatment.
* **Contact Address**: Enter your address.
* **Contact City**: Enter the city where you are located.
* **Contact State**: Enter the state where you are located.
* **Contact Zip**: Enter your zip code.
* **Window Treatment Price**: This field will display the calculated price for the window treatment based on your inputs.
* **Additional Comments**: Add any additional comments or notes about the window treatment.
* **Window Treatment Description**: Enter a brief description of the window treatment.
* **Is Estimate**: Select if this is an estimate or a final quote.
* **Submit**: Click to submit the form to receive the calculated price.
