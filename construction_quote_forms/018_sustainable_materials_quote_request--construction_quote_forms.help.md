# Sustainable Materials Quote Request - Help Guide
## Purpose
This form is designed to gather information for a sustainable materials quote request, facilitating communication and negotiation between clients and suppliers.

## How To Complete This Form
1. Start by filling out the basic project information, including project name, contact name, email, and phone number.
2. Provide project address and supplier address (if different).
3. Select the material type from the available options.
4. Enter the material amount and unit of measurement.
5. Enter the material price and supplier price (if known).
6. Set up the project budget and currency.
7. Select the project status.
8. Optionally, add supplier and customer logos, references, and notes.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, optional): Enter the name of the project.
* **Contact Name** (`contact_name`, text, optional): Enter the contact name for the project.
* **Contact Email** (`contact_email`, email, optional): Enter the contact email for the project.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact phone number for the project.
* **Quote Date** (`quote_date`, date, optional): Enter the expected quote date for the project.
* **Address** (`address`, text, optional): Enter the project address.
* **Project Address** (`project_address`, text, optional): Enter the supplier address (if different from project address).
* **Material Type** (`material_type`, select_one, optional): Select the type of material required.
* **Material Amount** (`material_amount`, number, optional): Enter the material amount.
* **Material Unit** (`material_unit`, select_one, optional): Select the unit of measurement for the material.
* **Material Price** (`material_price`, number, optional): Enter the material price.
* **Supplier Name** (`supplier_name`, text, optional): Enter the supplier name.
* **Supplier Contact Name** (`supplier_contact_name`, text, optional): Enter the supplier contact name.
* **Supplier Contact Email** (`supplier_contact_email`, email, optional): Enter the supplier contact email.
* **Supplier Contact Phone** (`supplier_contact_phone`, text, optional): Enter the supplier contact phone number.
* **Supplier Notes** (`supplier_notes`, note, optional): Add any supplier notes.
* **Customer Notes** (`customer_notes`, note, optional): Add any customer notes.
* **Supplier Logo** (`supplier_logo`, select_multiple, optional): Indicate if the supplier has a logo.
* **Customer Logo** (`customer_logo`, select_multiple, optional): Indicate if the customer has a logo.
* **Supplier Reference** (`supplier_reference`, text, optional): Enter the supplier reference.
* **Customer Reference** (`customer_reference`, text, optional): Enter the customer reference.
* **Supplier Price** (`supplier_price`, number, optional): Enter the supplier price.
* **Project Budget** (`project_budget`, number, optional): Enter the project budget.
* **Project Budget Currency** (`project_budget_currency`, select_one, optional): Select the currency for the project budget.
* **Project Status** (`project_status`, select_one, optional): Select the project status.
* **Supplier Price** (this field is not present in the original form but is mentioned in the field-by-field explanation, so it's removed for consistency)

## Tips
Please ensure that you provide accurate and complete information to facilitate smooth communication and negotiation between clients and suppliers.
