# High-Rise Window Cleaning Quote Request - Help Guide
## Purpose
This form is a quote request for high-rise window cleaning services. Please provide detailed information to enable service providers to accurately assess your project and provide a comprehensive quote.

## How To Complete This Form
To complete this form, follow the instructions below:

1.  Navigate through each page carefully and fill out the required fields.
2.  Make sure to select the correct options for the "Project Type" field.
3.  Enter accurate measurements for "Building Height", "Building Width", "Building Story Count", and "Building Floor Area".
4.  Provide a valid contact person's name, email, and phone number.
5.  Select the correct service provider and payment terms from the available options.
6.  Add any relevant comments about the project.
7.  Finally, sign the form to confirm the submission.

## Field-by-Field Explanation
### **High-Rise Window Cleaning Quote Request** (page 1, required)
*   **Project Type** (page 1, select_one): Select the type of project you are undertaking, which can be Exterior, Interior, or Other.

### **Project Type** (page 2, required)
*   **Building Height** (page 2, number): Enter the height of the building in meters or feet.
*   **Building Width** (page 2, number): Enter the width of the building in meters or feet.
*   **Building Story Count** (page 2, number): Enter the number of stories in the building.
*   **Building Floor Area** (page 2, number): Enter the total floor area of the building.

### **Service Details** (page 3, required)
*   **Contact Person** (page 3, text): Enter the name of the person responsible for contact.
*   **Contact Email** (page 3, email): Enter the email address of the contact person.
*   **Contact Phone** (page 3, text): Enter the phone number of the contact person.

### **Service Provider Information** (page 4, required)
*   **Service Provider** (page 4, select_multiple): Select the service provider that you would like to work with. Please choose one or more options.
*   **Estimated Cost** (page 4, number): Enter the estimated cost for the service.
*   **Payment Terms** (page 4, select_multiple): Select the payment terms that apply to your project, such as Cash, Bank, Other, or Credit.

### **Additional Information** (page 5, optional)
*   **Comments** (page 5, note): Add any additional comments or information about the project.

### **Quote Submission** (page 6, required)
*   **Signature** (page 6, note): Sign this form to confirm the submission of your quote request.
