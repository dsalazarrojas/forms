# Paint Coverage Estimator - Help Guide
## Purpose
The Paint Coverage Estimator form is used to calculate the estimated quantity of paint required for a construction project.

## How To Complete This Form
To complete the Paint Coverage Estimator form, follow these steps:

1. Enter project details, including project type (yes/no), project status (active/inactive), and project manager (yes/no).
2. Provide wall details, including wall length, width, height, and surface type (yes/no).
3. Select the paint color and type (yes/no) for the project.
4. Enter the primer coverage rate and total paint coverage.
5. Calculate the total area of the wall by entering the wall length, width, and height.
6. Review and submit the form to receive an estimated paint coverage report.

## Field-by-Field Explanation

* **Project Details**
	+ *project_type* (`Project type`, select_one): Select whether this is a 'Yes' or 'No' project.
	+ *project_status* (`Project Status`, select_one): Select whether this project is 'Active' or 'Inactive'.
	+ *project_manager* (`Project Manager`, select_one): Select whether this is a 'Yes' or 'No' project manager.
* **Wall Details**
	+ *wall_length* (`Wall Length`, number): Enter the length of the wall in meters.
	+ *wall_width* (`Wall Width`, number): Enter the width of the wall in meters.
	+ *wall_height* (`Wall Height`, number): Enter the height of the wall in meters.
	+ *wall_surface_type* (`Wall Surface Type`, select_multiple): Select whether the wall has a 'Yes' or 'No' surface type.
* **Paint Details**
	+ *paint_color* (`Paint Color`, select_one): Select the 'Yes' or 'No' paint color.
	+ *paint_type* (`Paint Type`, select_one): Select the 'Yes' or 'No' paint type.
* **Calculations and Results**
	+ *paint_coverage_rate* (`Paint Coverage Rate`, number): Enter the paint coverage rate.
	+ *total_area* (`Total Area`, number): Enter the total area of the wall.
	+ *total_paint_coverage* (`Total Paint Coverage`, number): Enter the total paint coverage.
* **Additional Information**
	+ *paint_color_2* (`Paint Color 2`, select_one): Select the 'Yes' or 'No' paint color 2 (optional).
	+ *phone_number* (`Contact Phone Number`, text): Enter the contact phone number (optional).
	+ *email* (`Email`, email): Enter the email (optional).
	+ *notes* (`Additional Notes`, note): Enter any additional notes (optional).

## Tips

* Make sure to enter accurate values for wall length, width, and height to ensure accurate results.
* Ensure that the paint color and type are selected correctly to get accurate results.
* Review the calculations and results carefully before submitting the form.
* Enter any additional notes if needed to provide context or clarification.
