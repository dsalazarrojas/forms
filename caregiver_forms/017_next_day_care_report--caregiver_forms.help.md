# next_day_care_report - Help Guide
## Purpose
The purpose of this form is for caregivers to report on a client's activities, observations, and progress for the next day's care.

## How To Complete This Form
- Fill out the form completely, making sure to provide information for each required field.
- Ensure that you only report on the client's next day's care, as indicated by the form's title.
- Use the "activity_completed" field to select the activity that was completed for the client.
- In the "observations" field, provide detailed descriptions of any notable observations or incidents that occurred during the day.
- In the "follow_ups" field, list any follow-ups or reminders that need to be addressed or scheduled.
- In the "additional_comments" field, include any other relevant information about the client's care that may be useful for care decisions.

## Field-by-Field Explanation
* **daily_care_plan** (text, required: false): This field is where you can outline the client's daily care plan. 
* **activity_completed** (select_one: Caregiver, Support, Other, required: false): Please select the activity that was completed for the client.
* **observations** (text, required: true): Describe any notable observations or incidents that occurred during the day.
* **follow_ups** (text, required: false): List any follow-ups or reminders that need to be addressed or scheduled.
* **additional_comments** (text, required: false): Include any other relevant information about the client's care that may be useful for care decisions.

## Tips
- Make sure to review the form carefully before submitting it to ensure that all required fields are completed.
- Use clear and concise language when filling out the form.
- Proofread the form for accuracy and completeness before submitting it.
