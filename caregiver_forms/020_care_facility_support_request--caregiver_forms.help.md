# Care Facility Support Request - Help Guide
## Purpose
This form is designed for staff members to submit support requests to the facilities team. It helps the team quickly triage and prioritize requests based on urgency and support type.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name as the staff member requesting support.
2. Specify the department or unit requiring assistance.
3. Choose the type of support needed (e.g., Maintenance, IT support, etc.).
4. Indicate the urgency level of the support request (e.g., Low, Medium, High, etc.).
5. Describe the location and issue within the facility.
6. Provide detailed description of the issue.
7. Select a preferred method of communication for updates (e.g., Phone, Email, etc.).
8. (Optional) If applicable, provide a date by which support is needed.
9. (Optional) If necessary, include additional attachments or links (e.g., photos, documents).

## Field-by-Field Explanation
* **Requester name** (`requester_name`, required): Enter your name as the staff member requesting support.
* **Department** (`department`, optional): Specify the department or unit requiring assistance.
* **Type of support requested** (`support_type`, required): Choose the type of support needed from the options provided.
* **Urgency level** (`urgency_level`, required): Indicate the priority for response (e.g., Low, Medium, High, etc.).
* **Location of issue** (`location_of_issue`, required): Describe the location within the facility where the issue is present.
* **Description of issue** (`description_of_issue`, required): Provide detailed details to help the facilities team triage the request.
* **Preferred contact method** (`preferred_contact`, required): Select a method of communication for updates (e.g., Phone, Email, etc.).
* **Requested by date** (`requested_by_date`, optional): If applicable, provide a date by which support is needed.
* **Additional attachments** (`additional_attachments`, optional): If necessary, include additional attachments or links (e.g., photos, documents).

Please note that all fields are marked as required if they have an asterisk (*) next to them.
