# Trade Certification Enrollment Form - Help Guide
## Purpose
This form is used to enroll a trade certification program into the system.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out all the required fields (if any).
2. Review each field carefully and make sure to enter accurate and complete information.
3. Submit the form once you have filled out all the fields.

## Field-by-Field Explanation
### **Program Name** (Program Name, text, optional)
Enter the name of the trade certification program.

### **Start Date** (start_date, date, optional)
Enter the start date of the program.

### **End Date** (end_date, date, optional)
Enter the end date of the program.

### **Trade Certification Status** (trade_certification_status, select_one, optional)
Select the current status of the trade certification program. You can choose from the following options: 
- **Active**
- **Inactive**

### **Applicant Email** (applicant_email, email, optional)
Enter the email address of the trade certification applicant.

### **Phone Number** (phone_number, text, optional)
Enter the phone number of the trade certification applicant.

### **Program Details** (Program Details, note, optional)
Add any additional information about the trade certification program, such as program description, location, and prerequisites.

### **Tips**
- Make sure to fill out all the required fields correctly.
- Review each field carefully before submitting the form.
- If you are resubmitting an existing program, please make sure to check if the information is the same as before and only submit the changes.
