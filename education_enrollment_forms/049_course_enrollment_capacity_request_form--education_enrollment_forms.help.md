# Course Enrollment Capacity Request Form - Help Guide
## Purpose
This form is used to request changes to the course enrollment capacity. It helps the system administrators to keep track of changes made to course enrollment capacity and assign them to specific users for processing.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the Course Code of the course for which you want to request a capacity change.
2. Enter the Department Code of the department that manages the course.
3. Provide a brief rationale for the change, explaining why you are requesting the capacity change.
4. Specify the amount by which you want to change the course enrollment capacity. This can be either positive (increasing the capacity) or negative (decreasing the capacity).
5. Enter the new seat capacity for the course after the change.
6. Select the date when you want the capacity change to take effect.
7. Select the user who will be assigned to process the capacity change.

## Field-by-Field Explanation

* **Course Code** (`course_code`, text, optional): Enter the code of the course for which you are requesting a capacity change.
* **Department Code** (`department_code`, text, required): Enter the code of the department that manages the course.
* **Rationale** (`rationale`, text, optional): Briefly explain why you are requesting a capacity change for the course.
* **Seat Capacity Change** (`seat_capacity_change`, number, required): Specify the number of seats you want to add or remove from the course enrollment capacity.
* **New Seat Capacity** (`new_seat_capacity`, number, required): Enter the new seat capacity after the change.
* **Change Date** (`change_date`, date, required): Select the date when you want the capacity change to take effect.
* **Assigned User** (`assigned_user`, text, required): Choose the user who will be assigned to process the capacity change.
* **Comments** (`comments`, note, optional): Add any additional comments or information about the capacity change.

## Tips
* Make sure to enter accurate and up-to-date information in all fields.
* Ensure the department code is correct to route the request to the correct department.
* Be specific about the seat capacity change and the new seat capacity to avoid confusion.
* Enter a valid date for the change date to ensure the change is processed correctly.
