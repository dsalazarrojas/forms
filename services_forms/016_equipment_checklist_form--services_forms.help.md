# Equipment Checklist Form - Help Guide

## Purpose
The Equipment Checklist Form is used to track the equipment available or not available for firemen and law enforcement personnel. This form helps in identifying the necessary equipment for each duty station, emergency contact details, and other related information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the relevant equipment for firemen and law enforcement personnel from the provided options on each page.
2. Enter the duty station name in the "Duty Station" field, which is a text field where you can enter a brief description or name of the duty station.
3. If you have an emergency contact, enter their name, phone number, and email in the "Emergency Contact" fields.
4. Choose the correct start time for the duty in the "Duty Start Time" field, using the time picker format.

## Field-by-Field Explanation

* **Fireman Equipment** (`fireman_equipment`, select_multiple, required/optional): Select all the equipment that firemen may use or not use for their duties. This field is a multiple-select field with "Yes" and "No" options.
* **Law Enforcement Equipment** (`law_enforcement_equipment`, select_multiple, required/optional): Select all the equipment that law enforcement personnel may use or not use for their duties. This field is a multiple-select field with "Yes" and "No" options.
* **Duty Station** (`duty_station`, text, required/optional): Enter the name or brief description of the duty station where the equipment will be used. This field is a text field where you can enter a brief description or name of the duty station.
* **Emergency Contact** (`emergency_contact`, select_one, required/optional): If there is an emergency contact, select "Yes" and provide their name in the "Emergency Contact" field. This field is a select-one field with "Yes" and "No" options.
* **Emergency Contact Phone** (`emergency_contact_phone`, text, required/optional): Enter the phone number of the emergency contact person. This field is a text field where you can enter the phone number of the emergency contact person.
* **Emergency Contact Email** (`emergency_contact_email`, email, required/optional): Enter the email address of the emergency contact person. This field is an email field where you can enter the email address of the emergency contact person.
* **Duty Start Time** (`duty_start_time`, time, required/optional): Choose the start time for the duty in the time picker format. This field is a time field where you can select the start time for the duty.
