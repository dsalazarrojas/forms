# online_debt_collection_placement_form - Help Guide
## Purpose
This form is designed to collect information about debts, debtors, and collection activities for online debt collection purposes.

## How To Complete This Form
1. Fill out the form with the required information for each debtor.
2. Select the collection status for each debtor.
3. Enter any additional information as needed.

## Field-by-Field Explanation
* **Contact Info** (`Contact Info`, `text`, required: `false`): This field is for entering contact information for each debtor.
* **Debt Info** (`Debt Info`, `text`, required: `false`): This field is for entering information about each debt.
* **Payment Terms** (`Payment Terms`, `text`, required: `false`): This field is for entering payment terms for each debt.
* **Debtors** (`Debtors`, `select_one`, required: `false`): Select one of the debtors listed to associate with each debt.
* **Collection Status** (`Collection Status`, `select_multiple`, required: `false`): Select multiple statuses for each debt from the options: "Paid", "Unpaid".
* **Payment Amount** (`Payment Amount`, `number`, required: `false`): Enter the payment amount for each debt.
* **Collection Date** (`Collection Date`, `date`, required: `false`): Enter the collection date for each debt.
* **Payment Method** (`Payment Method`, `text`, required: `false`): This field is for entering payment method for each debt.
* **Collection Term** (`Collection Term`, `text`, required: `false`): This field is for entering collection term for each debt.
* **Notes** (`Notes`, `note`, required: `false`): Enter any additional notes about each debt.
* **Email** (`Email`, `email`, required: `false`): Enter the email for each debtor.
* **Phone** (`Phone`, `text`, required: `false`): Enter the phone number for each debtor.
* **Additional Info** (`Additional Info`, `text`, required: `false`): Enter any additional information about each debt.
* **Signature** (`Signature`, `text`, required: `false`): Enter your signature for each debt.

## Tips
* Make sure to select the correct debtor for each debt.
* Be thorough when filling out the form, as it will help in efficient debt collection activities.
* If you are unsure about any field, please contact your supervisor.
