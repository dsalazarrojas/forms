# lush_survey - Help Guide
## Purpose
The Lush Survey form is designed to collect various types of information from users. It is not intended for general public use, so please do not share this link with anyone not authorized to access this form.

## How To Complete This Form
1. To start, click the "Start" button.
2. Review each field carefully and select the correct option for each question.
3. Fill out all required fields, marked as "required" in this guide.
4. For non-required fields, answer them only if you wish to provide more information.
5. Once you have filled out all fields, click the "Submit" button.
