# Building Addition Property Schedule Change - Help Guide
## Purpose
The purpose of this form is to collect information regarding changes to a property's schedule, including additions, deletions, boundary changes, use changes, ownership changes, zoning changes, and assessment changes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields marked as mandatory (e.g., Requestor Name, Job Title, Organization, Email Address, Phone Number, Request Date, Property Name, Property Address, Property Type, Change Type, Change Description, Affected Area Size, Reason for Change, Requested Effective Date, and Information Certification).
2. Fill out the non-mandatory fields that apply to your specific situation (e.g., Addition Details, Deletion Details, Current Assessed Value, Estimated New Value, Legal Description, Parcel Number, Adjacent Owners Notified, Objections Known, and Additional Information).
3. Select the appropriate options for fields like Property Type, Change Type, and Supporting Documents.
4. Attach any required supporting documents as specified in the Supporting Documents field.
5. Review your form carefully before submitting it to ensure that all fields are accurate and complete.

## Field-by-Field Explanation
* **Requestor Name (1)** (`Requestor Name`, `text`, required): This field is used to identify the person or entity submitting the request.
* **Job Title (2)** (`Job Title`, `text`, required): This field is used to identify the requestor's position or title.
* **Organization (3)** (`Organization`, `text`, required): This field is used to identify the requestor's organization or company.
* **Email Address (4)** (`Email Address`, `email`, required): This field is used to contact the requestor.
* **Phone Number (5)** (`Phone Number`, `text`, required): This field is used to contact the requestor.
* **Request Date (6)** (`Request Date`, `date`, required): This field is used to indicate the date of the request.
* **Property Name (7)** (`Property Name`, `text`, required): This field is used to identify the property involved in the schedule change.
* **Property Address (8)** (`Property Address`, `text`, required): This field is used to provide the full address of the property.
* **Property Type (9)** (`Property Type`, `select_one`, required): This field is used to select the type of property (e.g., Residential, Commercial, Industrial, Mixed Use, Agricultural, Vacant Land).
* **Current Use (10)** (`Current Use`, `text`, required): This field is used to describe how the property is currently used.
* **Change Type (11)** (`Change Type`, `select_one`, required): This field is used to select the type of schedule change (e.g., Addition to Property, Deletion from Property, Boundary Change, Use Change, Ownership Change, Zoning Change, Assessment Change).
* **Change Description (12)** (`Change Description`, `text`, required): This field is used to describe the change in detail.
* **Addition Details (13)** (`Addition Details`, `text`, optional): This field is used to provide additional information about the addition to the property.
* **Deletion Details (14)** (`Deletion Details`, `text`, optional): This field is used to provide additional information about the deletion from the property.
* **Affected Area Size (15)** (`Affected Area Size`, `text`, required): This field is used to indicate the size of the affected area (e.g., square footage or acres).
* **Current Assessed Value (16)** (`Current Assessed Value`, `number`, optional): This field is used to indicate the current assessed value of the property.
* **Estimated New Value (17)** (`Estimated New Value`, `number`, optional): This field is used to indicate the estimated new value of the property.
* **Reason for Change (18)** (`Reason for Change`, `text`, required): This field is used to describe why the schedule change is needed.
* **Requested Effective Date (19)** (`Requested Effective Date`, `date`, required): This field is used to indicate the date when the change should take effect.
* **Supporting Documents (20)** (`Supporting Documents`, `select_multiple`, required): This field is used to select the supporting documents to be attached (e.g., Survey Map, Property Deed, Site Plan, Building Permit, Zoning Approval, Appraisal Report, Photos).
* **Legal Description (21)** (`Legal Description`, `text`, optional): This field is used to provide the property's legal description.
* **Parcel Number (22)** (`Parcel Number`, `text`, optional): This field is used to provide the tax parcel ID.
* **Adjacent Owners Notified (23)** (`Adjacent Owners Notified`, `select_one`, optional): This field is used to indicate whether adjacent owners have been notified.
* **Objections Known (24)** (`Objections Known`, `select_one`, optional): This field is used to indicate whether any objections are known.
* **Additional Information (25)** (`Additional Information`, `text`, optional): This field is used to provide any other relevant details.
* **Information Certification (26)** (`Information Certification`, `select_one`, required): This field is used to certify that the information provided is true.

## Tips
* Please ensure that all fields are filled out accurately and truthfully.
* Attach any required supporting documents as specified in the Supporting Documents field.
* If you have any further questions or concerns, do not hesitate to contact us.
