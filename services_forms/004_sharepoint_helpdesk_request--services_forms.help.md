# sharepoint_helpdesk_request - Help Guide
## Purpose
The "sharepoint_helpdesk_request" form is designed to collect information from users when they have issues or requests related to SharePoint services. This form enables support teams to effectively track and manage these requests to provide efficient assistance.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Provide your contact information, including your name and email address.
2. Describe the issue or request you are submitting. Be as specific as possible to help the support team understand the problem.
3. Specify any additional details about the issue, such as the scope of the problem or the desired outcome.
4. Select the relevant options for the following fields:
	* If this is a new issue, select "Yes" for "sharepoint_update" and "group_assignment".
	* If you are reporting an existing issue, select "No" for "sharepoint_update" and "group_assignment".
	* Indicate whether the issue is currently active or inactive.
5. Specify which SharePoint sites are affected by the issue.
6. Identify if personnel are involved in the issue.
7. Select the due date and time for the issue resolution.
8. Specify the tool assigned to handle the issue (if applicable).

## Field-by-Field Explanation
- **requester_info** (Text): Provide your name and any other contact information you wish to share with the support team.
- **contact_name** (Text): Enter your name as the person submitting the request.
- **contact_email** (Text): Enter your email address so the support team can contact you.
- **issue_description** (Text): Describe the problem or issue you are experiencing in detail.
- **issue_details** (Text): Provide any additional information that can help the support team understand the issue.
- **group_assignment** (Select Multiple): Select all relevant groups affected by the issue.
- **sharepoint_update** (Select One): Choose "Yes" if this is a new issue, or "No" if you are reporting an existing issue.
- **sharepoint_issues** (Select Multiple): Select all SharePoint sites affected by the issue.
- **sharepoint_sites** (Select Multiple): Select all SharePoint sites affected by the issue (this field is not clearly labeled, but is assumed to be relevant for tracking issues across sites).
- **personnel** (Select Multiple): Indicate if personnel are involved in the issue.
- **issue_status** (Select One): Mark the issue as Active or Inactive.
- **due_date** (Date): Enter the due date for the issue resolution.
- **due_time** (Time): Enter the due time for the issue resolution.
- **assigned_tool** (Text): If applicable, enter the tool assigned to handle the issue (this field seems to be for fixed values).
- **sharepoint_issues** (Select Multiple): Select all relevant issues related to SharePoint services.

## Tips

* Be as specific as possible when describing the issue to help the support team provide effective assistance.
* Review your information carefully before submitting the form to ensure accuracy.
* If you are unsure about any field or its purpose, please refer to this guide for clarification.
* Contact the support team if you have any questions or need further guidance.
