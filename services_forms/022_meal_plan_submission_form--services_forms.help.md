# Meal Plan Submission Form - Help Guide
## Purpose
The Meal Plan Submission Form is designed to collect information about a client's meal preferences and dietary needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (indicated as "required" in the form).
2. Choose the relevant meal options for each day of the meal plan.
3. Enter any additional details about the meal plan.
4. Review and submit the form for processing.

## Field-by-Field Explanation
* **Meal Plan**: This is the title of the form, which should be a brief description of the client's meal plan.
* **Client Name**: This field is used to identify the client. Please enter the client's full name.
* **Email**: This field is for the client's email address.
* **Phone**: This field is for the client's phone number.
* **Start Date**: This field is for the start date of the meal plan.
* **End Date**: This field is for the end date of the meal plan.
* **Total Days**: This field is for the total number of days in the meal plan.
* **Meal Plan Details**: This field is for any additional details about the meal plan, such as any specific dietary restrictions or preferences.
* **Breakfasts**: Select the types of meals you would like to have for breakfast. Choose one or more from the list: Breakfast, Lunch, Dinner, Snacks.
* **Lunches**: Select the types of meals you would like to have for lunch. Choose one or more from the list: Breakfast, Lunch, Dinner, Snacks.
* **Dinners**: Select the types of meals you would like to have for dinner. Choose one or more from the list: Breakfast, Lunch, Dinner, Snacks.
* **Snacks**: Select the types of snacks you would like to have. Choose one or more from the list: Breakfast, Lunch, Dinner, Snacks.

## Tips
- Please make sure to choose at least one option for each meal type.
- You can select multiple options by holding the Ctrl key and clicking on multiple values in the list.
- If you have any questions or concerns, please contact us for assistance.
