# Vehicle Maintenance Request - Help Guide
## Purpose
The purpose of this form is to collect information about a vehicle maintenance request from a customer.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the vehicle's make and model year in the corresponding fields.
2. Provide a brief description of the maintenance request.
3. Select the type of maintenance required (oil change, tire change, or other).
4. Enter the date and start time of the maintenance request.
5. Enter the customer's contact information, including name, email, phone number, company, address, city, state, zip code, and country.

## Field-by-Field Explanation

* **Vehicle Maintenance Request (1)**: Enter a brief description of the maintenance request.
* **Make (2)**: Enter the make of the vehicle.
* **Model Year (3)**: Enter the year of the vehicle's model.
* **Model Month Year (4)**: Enter the month and year of the vehicle's model.
* **Vehicle Maintenance Request ID (5)**: This is a unique ID for the maintenance request.
* **Description (6)**: Enter a brief description of the maintenance request.
* **Vehicle Maintenance Request Status (7)**: Select the current status of the maintenance request (new, open, or closed).
* **Vehicle Maintenance Request Type (8)**: Select the type of maintenance required (oil change, tire change, or other).
* **Vehicle Maintenance Request Date (9)**: Enter the date of the maintenance request.
* **Vehicle Maintenance Request Start Time (10)**: Enter the start time of the maintenance request.
* **Customer Name (11)**: Enter the customer's name.
* **Customer Email (12)**: Enter the customer's email.
* **Customer Phone (13)**: Enter the customer's phone number.
* **Vehicle Year (14)**: Enter the year of the vehicle.
* **Vehicle Make (15)**: Enter the make of the vehicle.
* **Vehicle Model (16)**: Enter the model of the vehicle.
* **Vehicle VIN (17)**: Enter the vehicle identification number (VIN).
* **Vehicle License Plate (18)**: Enter the vehicle's license plate number.
* **Customer Company (19)**: Enter the customer's company name.
* **Customer Address (20)**: Enter the customer's address.
* **Customer City (21)**: Enter the customer's city.
* **Customer State (22)**: Enter the customer's state.
* **Customer Postal Code (23)**: Enter the customer's postal code (zip code).
* **Customer Country (24)**: Enter the customer's country.
* **Vehicle Description (25)**: Enter a brief description of the vehicle.
