# seo_onboarding_form - Help Guide
## Purpose
This form is designed to collect information from new SEO clients for the onboarding process.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the **Client Name** field with the name of the new SEO client.
2. Select the type of business the client represents by choosing from the options in the **Business Type** dropdown menu.
3. If the client has a website, enter the URL in the **Website** field.
4. Provide the client's **Contact Info** in the **Contact Info** field.
5. Enter the client's **Email** address.
6. Add the client's **Phone** number.
7. If applicable, enter the **Project Start Date** and **Project End Date** for the project.
8. For services specific to this project, select the required **Services Required** using the dropdown menu.
9. For additional services, use the **Services** dropdown to select any other services required.
10. In the **Additional Services** field, provide any further services not listed in the previous options.
11. Add any **Client Notes** regarding the project.
12. Add any additional **Consultant Notes** for internal team members.
13. Add any **Project Manager Notes** for project coordination.

## Field-by-Field Explanation
### Client Name
• **Client Name** (text): Enter the name of the client.

### Business Type
• **Business Type** (select_one): Select the type of business the client represents.

### Website
• **Website** (text): If the client has a website, enter the URL.

### Contact Info
• **Contact Info** (text): Provide the client's contact information.

### Email
• **Email** (email): Enter the client's email address.

### Phone
• **Phone** (text): Enter the client's phone number.

### Project Start Date
• **Project Start Date** (date): Enter the project start date.

### Project End Date
• **Project End Date** (date): Enter the project end date.

### Services Required
• **Services Required** (select_multiple): Select the required services for the project.

### Services
• **Services** (select_multiple): Select any additional services required.

### Additional Services
• **Additional Services** (text): Enter any additional services not listed in the previous options.

### Client Notes
• **Client Notes** (note): Add any client-specific notes or requests.

### Consultant Notes
• **Consultant Notes** (note): Add any notes for the internal team regarding the project coordination.

### Project Manager Notes
• **Project Manager Notes** (note): Add any project management notes or instructions.
