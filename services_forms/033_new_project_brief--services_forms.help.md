# new-project-brief - Help Guide
## Purpose
The new-project-brief form is used to collect project details for new projects, ensuring that all relevant information is captured and stored in a standardized format.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's interest in the project.
2. Provide the project name.
3. Select the project type from the options provided.
4. Enter the project start and end dates in the format yyyy-mm-dd.
5. Add any additional client information.
6. Enter a detailed project brief.
7. Specify whether the project has a project manager.
8. Choose the project status from the options provided.
9. Enter the project budget.
10. Enter the project lead time.
11. Provide the project location.
12. Enter a project description.

## Field-by-Field Explanation

* **Client Interest (text)** (optional):
	+ A brief description of the client's interest in the project.
* **Project Name (text)** (optional):
	+ A short title for the project that will be used to identify it.
* **Project Type (select_one)** (optional):
	+ Choose the type of project (Services, product, or Web Development).
* **Project Start (date)** (optional):
	+ Enter the start date of the project in the format yyyy-mm-dd.
* **Project End (date)** (optional):
	+ Enter the end date of the project in the format yyyy-mm-dd.
* **Client Info (text)** (optional):
	+ Additional information about the client.
* **Project Brief (note)** (optional):
	+ A detailed description of the project.
* **Project Manager (select_multiple)** (optional):
	+ Specify if the project has a project manager.
* **Project Status (select_one)** (optional):
	+ Choose the current status of the project (Not Started, in progress, finished, canceled, or completed).
* **Project Budget (number)** (optional):
	+ Enter the budget for the project.
* **Project Lead Time (time)** (optional):
	+ Enter the lead time for the project.
* **Project Location (text)** (optional):
	+ The location where the project will take place.
* **Project Description (text)** (optional):
	+ A detailed description of the project.
