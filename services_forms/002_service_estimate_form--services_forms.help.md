# Service Estimate Form - Help Guide
## Purpose
The Service Estimate Form is a tool for generating service estimates or quotes for various services. This form helps users to quickly and accurately estimate the cost of a service by providing a structured format for inputting different service costs.

## How To Complete This Form
1. Select the "Report Date" field to enter the date on which the estimate is valid.
2. Enter the "Service Name" field to describe the service being estimated.
3. Fill out the "Service Cost" fields to enter the costs associated with the service. These fields can be left blank if not applicable.
4. Review the automatically calculated "Total Cost" field to see the total estimated cost.

## Field-by-Field Explanation

* **Report Date**: Enter the date on which the estimate is valid. This field is required.
	+ Format: YYYY-MM-DD (e.g., 2022-01-01)
	+ Example: 2022-02-01
* **Service Name**: Enter a description of the service being estimated.
	+ Optional field.
* **Service Cost 1-21**: Enter the costs associated with each service. These fields can be left blank if not applicable.
	+ Optional fields.
	+ Format: numeric value (e.g., 100.00)
* **Total Cost**: This field is automatically calculated based on the entered service costs.
	+ Read-only field.
	+ Example: $0.00 (if no costs are entered)

## Tips
* Make sure to enter all relevant service costs to get an accurate estimate.
* Use numeric values only for the "Service Cost" fields.
* Leave blank fields if they are not applicable.
* Review the "Total Cost" field to ensure it accurately reflects the total estimated cost.
