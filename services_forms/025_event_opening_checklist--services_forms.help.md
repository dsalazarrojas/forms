# Event Opening Checklist - Help Guide
## Purpose
The Event Opening Checklist form collects essential information about an event, helping you to plan and organize it effectively.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the **event_name** field.
2. Select the event date in the **event_date** field.
3. Choose the event start time in the **event_start_time** field.
4. Enter the venue details in the **venue** field.
5. Provide a brief description of the event in the **event_description** field.
6. Select the time zone for the event in the **event_start_time_zone** field.
7. Enter the event location in the **event_location** field.
8. Enter the event organizer's information in the **event_organizer** field.

## Field-by-Field Explanation

* **event_name**: Enter a short title or name for the event (e.g., "Conference 2024").
* **event_date**: Enter the date the event will take place (e.g., "2024-03-12").
* **event_start_time**: Choose the start time for the event (e.g., "09:00 AM").
* **venue**: Enter the location where the event will be held (e.g., "Convention Center").
* **event_description**: Provide a brief description of the event (e.g., "A conference for software developers").
* **event_start_time_zone**: Select the time zone for the event (e.g., "Pacific Time").
* **event_location**: Enter the physical location of the event (e.g., "123 Main St. City").
* **event_organizer**: Enter the person or organization responsible for organizing the event (e.g., "John Doe, Event Co.").

## Tips

* Ensure that the event date and start time are correctly formatted and accurate.
* If you're unsure about the time zone, consult with the event organizer or check the venue's website.
* Double-check the event location and venue details to avoid confusion.
* If you're creating this form for an event organizer, ensure they have the necessary information to plan and promote the event effectively.
