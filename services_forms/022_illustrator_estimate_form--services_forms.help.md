# Illustrator Estimate Form - Help Guide
## Purpose
The Illustrator Estimate Form is used to gather information for estimating the cost of a project. It captures project details such as project name, client information, project dates, location, and artist rates. The form also includes fields for estimating the time needed for the project and selecting the rate per hour.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name in the "Project Name" field.
2. Enter the client's name in the "Client Name" field.
3. Enter the client's email in the "Client Email" field.
4. Enter the project start date in the "Project Start Date" field.
5. Enter the project end date in the "Project End Date" field.
6. Enter the project location in the "Project Location" field.
7. Select the project type from the dropdown menu in the "Project Type" field.
8. Estimate the artist rate for the project in the "Artist Rate" field.
9. Select the time needed for the project from the dropdown menu in the "Time Needed" field.
10. Select the rate per hour for the project from the multiple select menu in the "Rate Hour" field.
11. Enter any additional project notes in the "Project Notes" field.
12. Select the artist assigned to the project from the dropdown menu in the "Assigned Artist" field.
13. Enter any additional client notes in the "Client Notes" field.
14. Select the project status from the dropdown menu in the "Project Status" field.

## Field-by-Field Explanation
* **Project Name (project_name)**: Enter the name of the project you are working on.
* **Client Name (client_name)**: Enter the name of the client for whom you are working on the project.
* **Client Email (client_email)**: Enter the email of the client for whom you are working on the project.
* **Project Start Date (project_start_date)**: Enter the start date of the project.
* **Project End Date (project_end_date)**: Enter the end date of the project.
* **Project Location (project_location)**: Enter the location where the project will take place.
* **Project Type (project_type)**: Select the type of project you are working on.
* **Artist Rate (artist_rate)**: Enter the estimated rate of the artist working on the project.
* **Time Needed (time_needed)**: Select the estimated time needed for the project from the dropdown menu.
	+ 5-10 hours: 5-10 hours are needed for the project.
	+ 11-20 hours: 11-20 hours are needed for the project.
	+ 21-30 hours: 21-30 hours are needed for the project.
	+ 31-40 hours: 31-40 hours are needed for the project.
	+ 41-50 hours: 41-50 hours are needed for the project.
* **Rate Hour (rate_hour)**: Select the rate per hour for the project from the multiple select menu.
	+ Good: The rate per hour is good.
	+ Fair: The rate per hour is fair.
* **Project Notes (project_notes)**: Enter any additional notes about the project.
* **Assigned Artist (assigned_artist)**: Select the artist assigned to the project from the dropdown menu.
* **Client Notes (client_notes)**: Enter any additional notes about the client.
* **Project Status (project_status)**: Select the status of the project from the dropdown menu.
	+ Active: The project is active.
	+ Inactive: The project is inactive.
