# Radiology Requisition Form - Help Guide

## Purpose
The Radiology Requisition Form is used to order various radiological procedures for a patient, such as X-rays, MRI, CT scans, ultrasound, PET scans, and mammograms.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the form to determine which radiological procedures are required for the patient.
2. Select "Yes" or "No" for each procedure to indicate whether it is ordered.
3. Enter the patient's name and ID in the corresponding fields.
4. Review your selections to ensure that all necessary procedures are ordered.
5. Submit the form for review and processing.

## Field-by-Field Explanation

* **Order X-ray** (`order_xray`, select_one, required: false): Check "Yes" if an X-ray is ordered for the patient.
* **Order MRI** (`order_mri`, select_one, required: false): Check "Yes" if an MRI is ordered for the patient.
* **Patient Name** (`patient_name`, text, required: false): Enter the patient's name.
* **Order CT** (`order_ct`, select_one, required: false): Check "Yes" if a CT scan is ordered for the patient.
* **Order Ultrasound** (`order_us`, select_one, required: false): Check "Yes" if an ultrasound is ordered for the patient.
* **Order PET** (`order_pet`, select_one, required: false): Check "Yes" if a PET scan is ordered for the patient.
* **Order Ultrasound 2** (`order_us2`, select_one, required: false): Check "Yes" if a second ultrasound is ordered for the patient.
* **Order Mammogram** (`order_mam`, select_one, required: false): Check "Yes" if a mammogram is ordered for the patient.
* **Order Mammogram** (`order_mamm`, select_one, required: false): Check "Yes" if a mammogram is ordered for the patient.
* **Patient ID** (`patient_id`, text, required: false): Enter the patient's ID number.

## Tips

* Make sure to review all procedures carefully before submitting the form to avoid missing important tests.
* Double-check the patient's name and ID to ensure accuracy.
* If you are unsure about any procedure, consult with a medical professional for guidance.
* The form is not meant to be a comprehensive medical record, but rather a tool to facilitate communication and ordering of procedures.
