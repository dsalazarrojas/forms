# new_client_record_form - Help Guide

## Purpose

This form is used to create a new client record.

## How To Complete This Form

1. Enter the client's name in the "Client Name" field.
2. Fill out the "Client Address" field if the client's address is known.
3. Enter the client's phone number in the "Client Phone" field.
4. Enter the client's email address in the "Client Email" field.
5. Enter the client's date of birth in the "Date of Birth" field in YYYY-MM-DD format.
6. Enter any additional notes about the client in the "Client Notes" field.
7. Select the assigned user from the dropdown list in the "Assigned User" field.
8. Enter the assigned date in the "Assigned Date" field.
9. Select the users who submitted the form from the dropdown list in the "Submitted By" field.
10. Enter the submitted date and time in the "Submitted Date" and "Submitted Time" fields.
11. Select the status of the client from the dropdown list in the "Status" field.
12. Select the user who created the client record from the dropdown list in the "Created By" field.
13. Select the user who last updated the client record from the dropdown list in the "Updated By" field.
14. Enter the date the client record was created in the "Created Date" field.
15. Enter the date the client record was last updated in the "Updated Date" field.
16. Select the client type from the dropdown list in the "Client Type" field.
17. Select "Yes" or "No" in the "Other Client Type" field if the client type is not one of the listed options.
18. Select the client status from the dropdown list in the "Client Status" field.

## Field-by-Field Explanation

* **Client Name (1)**: Enter the client's name.
* **Client Address (2)**: Enter the client's address if known.
* **Client Phone (3)**: Enter the client's phone number.
* **Client Email (4)**: Enter the client's email address.
* **Date of Birth (5)**: Enter the client's date of birth in YYYY-MM-DD format.
* **Client Notes (6)**: Enter any additional notes about the client.
* **Assigned User (7)**: Select the user who will be handling the client's record.
* **Assigned Date (8)**: Enter the date the client was assigned to the selected user.
* **Submitted By (9)**: Select the users who submitted the form.
* **Submitted Date (10)**: Enter the date the form was submitted.
* **Submitted Time (11)**: Enter the time the form was submitted.
* **Status (12)**: Select the status of the client (e.g. Active, Inactive).
* **Created By (13)**: Select the user who created the client record.
* **Updated By (14)**: Select the user who last updated the client record.
* **Created Date (15)**: Enter the date the client record was created.
* **Updated Date (16)**: Enter the date the client record was last updated.
* **Client Type (17)**: Select the type of client (e.g. Individual, Organization).
* **Other Client Type (18)**: Select "Yes" if the client type is not one of the listed options.
* **Client Status (19)**: Select the status of the client (e.g. Active, Inactive).
