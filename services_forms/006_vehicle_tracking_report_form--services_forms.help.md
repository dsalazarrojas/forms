# Vehicle Tracking Report Form - Help Guide
## Purpose
This form is designed to collect information about vehicle trips, including trip details, driver information, vehicle specifics, and trip metrics. The form is likely used to track and manage vehicle usage, fuel consumption, and driver performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the trip details, including trip dates and locations.
2. Provide driver information, including their name and license number.
3. Enter vehicle specifics, such as vehicle number, type, color, and model.
4. Enter trip metrics, including total cost, trip distance, and fuel type.
5. Select the vehicle status and location.
6. Enter any additional details as required.

## Field-by-Field Explanation
* **Trip Details (page 1)**:
	+ *trip_details*: A text field where you can describe the trip, including the destination and any notable events.
* **Destination (page 1)**:
	+ *destination*: A text field where you can enter the destination of the trip.
* **Driver Information (page 2)**:
	+ *driver_info*: A text field where you can enter the driver's name and other relevant details.
* **Driver License (page 2)**:
	+ *driver_license*: A text field where you can enter the driver's license number.
* **Trip Date (page 3)**:
	+ *trip_date*: A date field where you can select the start and end dates of the trip.
* **Total Cost (page 4)**:
	+ *total_cost*: A number field where you can enter the total cost of the trip.
* **Vehicle Number (page 5)**:
	+ *vehicle_number*: A text field where you can enter the vehicle's number.
* **Vehicle Type (page 5)**:
	+ *vehicle_type*: A text field where you can select the type of vehicle.
* **Vehicle Color (page 5)**:
	+ *vehicle_color*: A text field where you can select the color of the vehicle.
* **Vehicle Model (page 5)**:
	+ *vehicle_model*: A text field where you can select the model of the vehicle.
* **Odometer Reading (page 6)**:
	+ *odometer_reading*: A number field where you can enter the odometer reading.
* **Fuel Type (page 6)**:
	+ *fuel_type*: A text field where you can select the type of fuel used.
* **Trip Miles (page 7)**:
	+ *trip_miles*: A number field where you can enter the distance traveled.
* **Driver Hours (page 7)**:
	+ *driver_hours*: A number field where you can enter the time spent driving.
* **Vehicle Status (page 8)**:
	+ *vehicle_status*: A select field where you can select the current status of the vehicle.
* **Vehicle Location (page 8)**:
	+ *vehicle_location*: A select field where you can select the current location of the vehicle.
* **Assigned To (page 9)**:
	+ *assigned_to*: A text field where you can enter the person or team assigned to the vehicle.
* **Vehicle ID (page 9)**:
	+ *vehicle_id*: A text field where you can enter the vehicle's ID number.
* **Trip Start Time (page 10)**:
	+ *trip_start_time*: A time field where you can select the start time of the trip.
* **Trip End Time (page 10)**:
	+ *trip_end_time*: A time field where you can select the end time of the trip.
* **Trip Duration (page 11)**:
	+ *trip_duration*: A number field where you can enter the duration of the trip.
