# Fire Call Report Sheet Form - Help Guide
## Purpose
The Fire Call Report Sheet Form is used to document and record information about fire department responses to incidents. It collects details about the incident, response unit, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the incident number to identify the specific incident being reported.
2. Select the date and time of the incident using the date field.
3. Enter the location of the incident.
4. Select the unit ID of the response unit that responded to the incident.
5. Choose the call type from the provided options (e.g., Fire Call, Medical Call, Traffic Stop).
6. Enter a brief description of the call.
7. Record the response time (e.g., hours and minutes).
8. Enter the name of the response unit that responded to the incident.
9. Select the status of the incident from the options provided (e.g., Active, Resolved, Cancelled).
10. Enter any unit status updates or notes about the response.
11. Enter any incident status updates or notes.
12. Enter the name of the fire department that responded to the incident.
13. Enter a brief description of the reason for the call.
14. Enter any response notes about the incident.
15. Enter any incident notes about the response.
16. Enter the name of the person reporting the incident.
17. Enter the name of the reporting officer who collected the data.
18. Select the date of the incident.

## Field-by-Field Explanation

* **Incident Number** (1): Enter the unique identifier for the incident.
* **Date And Time** (2): Enter the date and time of the incident using the date format (e.g., mm/dd/yyyy hh:mm AM/PM).
* **Location** (3): Enter the address or location where the incident occurred.
* **Unit Id** (4): Enter the ID number of the response unit that responded to the incident.
* **Call Type** (5): Select the type of call from the options provided (e.g., Fire Call, Medical Call, Traffic Stop).
* **Call Description** (6): Enter a brief description of the call.
* **Response Time** (7): Record the time it took for the response unit to arrive on the scene.
* **Response Unit** (8): Enter the name of the response unit that responded to the incident.
* **Incident Status** (9): Select the status of the incident from the options provided (e.g., Active, Resolved, Cancelled).
* **Unit Status Update** (10): Enter any updates or notes about the response unit's status.
* **Incident Status Update** (11): Enter any updates or notes about the incident's status.
* **Fire Department** (12): Enter the name of the fire department that responded to the incident.
* **Call Reason** (13): Enter a brief description of the reason for the call.
* **Response Notes** (14): Enter any notes about the response.
* **Incident Notes** (15): Enter any additional notes about the incident.
* **Incident Reporter** (16): Enter the name of the person reporting the incident.
* **Reporting Officer** (17): Enter the name of the officer who collected the data.
* **Incident Date** (18): Select the date of the incident in the date format (e.g., mm/dd/yyyy).
