# standard_and_technical_work_log_templates - Help Guide
## Purpose
This template provides a structured format for creating standard and technical work logs, enabling teams and individuals to track and document their work activities accurately and efficiently.

## How To Complete This Form

1. Select the type of log you want to create: Troubleshooting Logs, Standard Work Logs, or Technical Work Logs.
2. Fill in the relevant details for each section, including the Log Date and Due Date (if applicable).
3. Choose the Log Status and assign the log to specific users.
4. Add any attachments or comments as needed.
5. Select the Log Type (Standard or Technical) and Log Sub Type (if applicable).
6. Enter any additional information in the Description field.
7. Document any Action Taken and Next Steps.
8. Record any technical notes or details in the Technical Notes field.
9. Update the Log Status and Due Date as the log progresses.
10. Review and update the form as necessary.

## Field-by-Field Explanation
* **Troubleshooting Logs (Page 1)**: This section is for logging issues encountered during work activities.
	+ **Log Date** (`log_date`): The date of the logged entry.
	+ **Log Time** (`log_time`): The time of the logged entry.
	+ **User Name** (`user_name`): The name of the user who performed the work activity.
	+ **User Title** (`user_title`): The title of the user who performed the work activity.
	+ **Description** (`description`): A brief description of the issue or activity.
	+ **Issue** (`issue`): A detailed description of the issue or problem encountered.
	+ **Action Taken** (`action_taken`): A summary of the steps taken to resolve the issue.
	+ **Notes** (`notes`): Additional comments or observations about the issue.
* **Standard Work Logs (Page 2)**: This section is for logging standard work activities.
	+ **Log Date** (`log_date`): The date of the logged entry.
	+ **Log Time** (`log_time`): The time of the logged entry.
	+ **User Name** (`user_name`): The name of the user who performed the work activity.
	+ **User Title** (`user_title`): The title of the user who performed the work activity.
	+ **Description** (`description`): A brief description of the activity.
	+ **Action Taken** (`action_taken`): A summary of the steps taken to complete the activity.
	+ **Technical Notes** (`technical_notes`): Additional technical details about the activity.
* **Technical Work Logs (Page 3)**: This section is for logging technical work activities.
	+ **Log Date** (`log_date`): The date of the logged entry.
	+ **Log Time** (`log_time`): The time of the logged entry.
	+ **User Name** (`user_name`): The name of the user who performed the work activity.
	+ **User Title** (`user_title`): The title of the user who performed the work activity.
	+ **Description** (`description`): A brief description of the activity.
	+ **Action Taken** (`action_taken`): A summary of the steps taken to complete the activity.
	+ **Technical Notes** (`technical_notes`): Additional technical details about the activity.
* **Additional Fields**
	+ **Log Status** (`log_status`): The current status of the log (Open, Closed, or On Hold).
	+ **Assigned To** (`assigned_to`): The users assigned to the log.
	+ **Priority** (`priority`): The priority level of the log (High, Medium, or Low).
	+ **Due Date** (`due_date`): The deadline for the completion of the log.
	+ **Completed** (`completed`): Whether the log is completed or not.
	+ **Comments** (`comments`): Additional comments or observations about the log.
	+ **Attachment** (`attachment`): Any additional files or attachments related to the log.
	+ **Log Type** (`log_type`): The type of log (Standard or Technical).
	+ **Log Sub Type** (`log_sub_type`): A more specific sub-type of the log.
	+ **Log Category** (`log_category`): A category for the log.

## Tips
* Be sure to fill in the required fields for each log entry.
* Use the technical notes field for any additional technical details.
* Update the log status and due date as the log progresses.
* Review and update the form regularly to ensure accurate and up-to-date information.
