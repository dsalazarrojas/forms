# DSWD Appointment Request Form - Help Guide
## Purpose
This form is used to request an appointment with a services provider. You will be asked to provide basic contact information and select the services you are interested in.

## How To Complete This Form
To complete this form, follow these steps:
- Fill out your name and phone number in the `services_1` field.
- Select all the services you are interested in.
- Choose a date and time for the appointment.
- Add any additional notes in the `services_1` field.

## Field-by-Field Explanation
- **services_1** (`services_1`, text, required): Fill in your name and phone number.
- **services** (select_multiple, required): Choose all the services you are interested in. The possible options are 'Yes' and 'No'.
  - 'Yes': Select 'Yes' if you are interested in the service.
  - 'No': Select 'No' if you are not interested in the service.
- **dswd_appointment_request_form_date** (date, required): Choose a date for the appointment. Please use the date format `YYYY-MM-DD`.
- **dswd_appointment_request_form_time** (time, required): Choose a time for the appointment. Please use the time format `HH:MM`.
- **dswd_appointment_request_form_note** (note, optional): Add any additional notes about your appointment request.
- **dswd_appointment_request_form_email** (email, required): Enter your email address.
- **services_1** to **services_16** (select_one, required): Select the services you are interested in.

Note: The services field is a multi-select field with 16 options. Please make sure to select all the services you are interested in. 

## Tips
* Please make sure to select all the services you are interested in, so the services provider can prepare and deliver the best services.
* If you have any additional comments or requests, use the `services_1` field to add them.
* Double-check your email address for correctness.
* Choose a specific date and time for the appointment.
