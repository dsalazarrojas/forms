# Requirement Form - Help Guide
## Purpose
The Requirement Form is a general-purpose tool for collecting information about events or projects. It is designed to be a starting point for further development and customization.

## How To Complete This Form
1.  Select "Event" or "Project" from the dropdown menu.
2.  Enter the name of the event or project.
3.  Enter a detailed description of the project or event.
4.  Select the start date of the project or event.
5.  Select the end date of the project or event.
6.  Enter the location of the project or event.
7.  Enter any additional information about the event or project.
8.  Select the status of the project (Active, Inactive, Cancelled).
9.  Enter the tool assigned to the project or event.
10. Enter the name of the person who created the project or event.

## Field-by-Field Explanation
* **Event or Project** (`event_or_project`, `select_one`, required/optional): Select one option from the dropdown menu to indicate whether the form is for an event or a project.
* **Project Name** (`project_name`, `text`, optional): Enter a brief name of the project.
* **Project Description** (`project_description`, `text`, optional): Enter a detailed description of the project.
* **Start Date** (`start_date`, `date`, optional): Select the start date of the project or event.
* **End Date** (`end_date`, `date`, optional): Select the end date of the project or event.
* **Location** (`location`, `text`, optional): Enter the location of the project or event.
* **Event Details** (`event_details`, `text`, optional): Enter any additional information about the event or project.
* **Project Status** (`project_status`, `select_one`, optional): Select one of the three options (Active, Inactive, Cancelled) to indicate the status of the project.
* **Assigned Tool** (`assigned_tool`, `text`, optional): Enter the tool assigned to the project or event.
* **Created By** (`created_by`, `text`, optional): Enter the name of the person who created the project or event.

## Tips
* Make sure to fill out the form with accurate and relevant information to ensure that your project or event is well-documented.
* If you are unsure about any of the fields, feel free to ask for help or clarification.
* You can always modify the form to fit your specific needs and requirements.
