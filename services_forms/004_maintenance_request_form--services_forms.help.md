# Maintenance Request Form - Help Guide
## Purpose
The Maintenance Request Form is a tool for employees to submit and track maintenance requests for facilities, equipment, or other assets. This form helps to centralize maintenance information, ensure timely resolution, and improve overall facility management.

## How To Complete This Form

To use this form, follow these steps:

1. Go to the designated page where the form is displayed.
2. Click on the "Maintenance Request" page to access the form.
3. Fill out the form with the required information:
	* Provide a brief description of the issue or problem that requires maintenance.
	* Select the priority level of the maintenance request (Low, Medium, or High).
4. Click the "Submit" button to submit the form.

## Field-by-Field Explanation

* **Maintenance Request** (`request_form`): This field is where you provide a brief description of the issue or problem that requires maintenance. Please type in a clear and concise explanation of the maintenance request.
* **Submit Date** (`submit_date`): This field is not required, but if you fill it in, it will help us track when you submitted the form. You can use the calendar picker to select a date.
* **Submit Time** (`submit_time`): Similar to "Submit Date", this field is optional and allows you to specify the time you submitted the form. You can use the clock picker to select the time.
* **Description** (`description`): This field is optional, but if you provide a detailed explanation of the issue, it will help us understand the problem better.
* **Priority** (`priority`): This field is optional, but selecting a priority level (Low, Medium, or High) will help us prioritize maintenance requests.
