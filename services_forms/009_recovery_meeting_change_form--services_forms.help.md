# recovery_meeting_change_form - Help Guide
## Purpose

This form is used for documenting changes made to meeting details in the recovery program.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure you have the necessary permissions to access and update meeting changes.
2. Select the meeting status from the options: Active or Inactive.
3. Enter the description of the changes made to the meeting.
4. Provide detailed information about the meeting details.
5. Enter the changes made to the recovery program.
6. Enter any additional recovery program changes if necessary.

## Field-by-Field Explanation

* **Category** (category): Select the category for the meeting change (Yes or No).
* **Services Forms** (services_forms): Choose whether services are involved in the meeting change (Yes or No).
* **Description** (description): Enter a description of the changes made to the meeting.
* **Meeting Details** (meeting_details): Enter detailed information about the meeting details.
* **Recovery Program Changes** (recovery_program_changes): Enter the changes made to the recovery program.
* **Recovery Program Changes 2** (recovery_program_changes_2): Enter any additional recovery program changes if necessary.
* **Meeting Type** (meeting_type): Select the type of meeting (Yes or No).
* **Meeting Date** (meeting_date): Enter the date of the meeting (in date format, e.g., MM/DD/YYYY).
* **Meeting Time** (meeting_time): Enter the time of the meeting (in 24-hour format, e.g., 14:30).
* **Meeting Location** (meeting_location): Enter the location of the meeting.
* **Meeting Status** (meeting_status): Select the status of the meeting (Active or Inactive).
* **Recovery Program Changes 3** (recovery_program_changes_3): Enter any additional recovery program changes if necessary.

## Tips

* Make sure to enter accurate and detailed information to ensure the meeting changes are correctly documented.
* If unsure about any field, refer to the organization's meeting change policy or seek assistance from authorized personnel.
* Double-check the form before submitting to ensure all required fields are filled and accurate.
