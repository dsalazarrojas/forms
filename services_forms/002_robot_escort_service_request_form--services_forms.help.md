# robot_escort_service_request_form - Help Guide
## Purpose
The "robot_escort_service_request_form" is a tool used for robot escort requesters to provide essential details about their service requests. This information is crucial for efficient and proper service delivery.

## How To Complete This Form
1. Please fill out the required fields accurately and completely.
2. Review each field for any required information and ensure it's filled out correctly.
3. Double-check the form for any errors before submitting it.

## Field-by-Field Explanation
- **robot escort service request form**: This is the title of the form, which will be displayed on the screen.
  - **robot escort requester**: This field is used to capture the name of the person requesting the robot escort service.
  - **escort duration**: This field is used to specify the length of time required for the robot escort service. Please enter a numerical value.
  - **robot escort request date**: This field is used to select a date for the robot escort service. Choose a date that suits your needs.
  - **robot escort request time**: This field is used to select a time for the robot escort service. Please choose a time that fits your schedule.
  - **escort location**: This field is used to specify the location where the robot escort service is required.
  - **escort note**: This field is used to provide any additional information about the robot escort service.
  - **contact number**: This field is used to capture the phone number of the robot escort requester.
  - **robot escort requester email**: This field is used to capture the email address of the robot escort requester.
  - **robot escort requester name**: This field is used to capture the name of the robot escort requester.
  - **robot escort requester address**: This field is used to capture the address of the robot escort requester.
  - **robot escort requester organization**: This field is used to capture the organization where the robot escort requester works or is associated with.
  - **robot escort requester job title**: This field is used to capture the job title of the robot escort requester.
  - **robot escort requester department**: This field is used to capture the department of the robot escort requester's organization.
  - **robot escort requester phone**: This field is used to capture the phone number of the robot escort requester.
  - **robot escort requester ext phone**: This field is used to capture any extension number for the robot escort requester's phone.
  - **robot escort requester ext email**: This field is used to capture an alternative email address for the robot escort requester.
  - **robot escort requester ext url**: This field is used to capture the URL of the robot escort requester's organization.

## Tips
- Review each field carefully before submitting the form.
- Please ensure accuracy and completeness of the required fields.
- If you need further assistance, please contact us.
