# Parking Pass Request Form - Help Guide

## Purpose

This form is used to collect information from users requesting parking passes. It ensures that essential details are provided to facilitate the parking pass request process.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Ensure that all required fields are filled in.
3. Double-check your submission before submitting it.

## Field-by-Field Explanation

* **Requesting User** (`parking_pass_request_form_1`, number, required/optional): This field is used to capture the ID of the user requesting a parking pass. If you are a user, ensure that you fill this field accurately.
* **Requested Date** (`requested_date`, date, required/optional): This field is used to capture the date when the user is requesting a parking pass. Select the date when you would like to use the parking pass.
* **End Date** (`end_date`, date, required/optional): This field is used to capture the end date when the user is requesting a parking pass. Select the date when you would like the parking pass to end.
* **User Email** (`user_email`, email, required/optional): This field is used to capture the email of the user requesting a parking pass. Enter your email address.
* **Phone Number** (`phone_number`, text, required/optional): This field is used to capture the phone number of the user requesting a parking pass. Enter your phone number.
* **Vehicle Type** (`vehicle_type`, select_one, required/optional): This field is used to select the type of vehicle you need the parking pass for. Select from: Car, Motorbike, Truck.
* **Parking Facility** (`parking_facility`, select_multiple, required/optional): This field is used to select the parking facility you will be using. Select from: Parking Facility 1, Parking Facility 2, Parking Facility 3.
* **Special Requests** (`special_requests`, select_multiple, required/optional): This field is used to capture any special requests you may have for your parking pass. Select from: Special Request 1, Special Request 2, Special Request 3.
* **Parking Details** (`parking_details`, note, required/optional): This field is used to capture any additional parking details. Provide any necessary information.
* **Parking Status** (`parking_status`, select_one, required/optional): This field is used to select the status of your parking pass. Select from: Active, Inactive, Pending.
* **Assigned To** (`assigned_to`, select_one, required/optional): This field is used to select who is assigned to manage your parking pass. Select from: Admin User 1, Admin User 2, Admin User 3.
* **Assigned By** (`assigned_by`, select_one, required/optional): This field is used to select who assigned the parking pass to you. Select from: User 1, User 2, User 3.
* **Comments** (`comments`, text, required/optional): This field is used to capture any comments about your parking pass. Enter any comments.
* **Form ID** (`form_id`, number, required/optional): This field is used to capture the ID of the form submission. Do not fill this field.
* **Timestamp** (`timestamp`, date, required/optional): This field is used to capture the timestamp of your form submission. Do not fill this field.
* **User** (`user`, number, required/optional): This field is used to capture the user ID. Do not fill this field.
* **User Status** (`user_status`, select_multiple, required/optional): This field is used to select the status of the user requesting a parking pass. Select from: Active, Inactive.
* **Facility Status** (`facility_status`, select_one, required/optional): This field is used to select the status of the parking facility. Select from: Active, Inactive.
* **Facility** (`facility`, number, required/optional): This field is used to capture the facility ID. Do not fill this field.
* **Comments Status** (`comments_status`, select_multiple, required/optional): This field is used to select the status of the comments. Select from: Active, Inactive.
* **User Type** (`user_type`, select_multiple, required/optional): This field is used to select the type of user requesting a parking pass. Select from: Admin User 1, Admin User 2, Admin User 3.
* **Comments Type** (`comments_type`, select_multiple, required/optional): This field is used to select the type of comments. Select from: Active, Inactive.
* **Facility Type** (`facility_type`, select_multiple, required/optional): This field is used to select the type of facility. Select from: Active, Inactive.
* **Assigned Date** (`assigned_date`, date, required/optional): This field is used to capture the date when the parking pass was assigned. Do not fill this field.
* **Assigned Time** (`assigned_time`, time, required/optional): This field is used to capture the time when the parking pass was assigned. Do not fill this field.
