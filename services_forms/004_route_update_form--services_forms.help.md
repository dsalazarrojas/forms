# route_update_form - Help Guide
## Purpose
The route_update_form is used to update the status and attributes of a route. This form is designed for administrative purposes and should only be used for route updates.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form fields as required. Fields marked as "required" are necessary to complete the form.
2. For the "Route Status" field, select the current status of the route from the dropdown menu.
3. For the "Update Method" field, select one or more methods for updating the route, such as "Email" or "Text Message".
4. Enter any additional notes about the update in the "Notes" field.
5. Click the "Update" button to submit the form.

## Field-by-Field Explanation
- **Route Update Form**
	* (Text input field): Enter the updated route information.
- **Email**
	* (Email input field): Enter the email address of the person to be updated.
	* Note: This field is required.
- **Message**
	* (Text input field): Enter a brief message to be sent with the update.
	* Note: This field is required.
- **Driver Phone**
	* (Text input field): Enter the phone number of the driver, if applicable.
* **Driver Email**
	* (Email input field): Enter the email address of the driver, if applicable.
* **Route Status**
	* (Select one from dropdown menu): Select the current status of the route.
	* Options: Active, Inactive, Archived
* **Update Method**
	* (Select multiple from dropdown menu): Select one or more methods for updating the route.
	* Options: Email, Text Message
* **Notes**
	* (Text input field with no options): Enter any additional notes about the update.
	* Note: This field is not required.
* **Form ID**
	* (Number input field): Enter the form ID, which is a unique identifier for the form.
	* Note: This field is required.
