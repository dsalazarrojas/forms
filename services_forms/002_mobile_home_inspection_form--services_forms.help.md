# Mobile Home Inspection Form - Help Guide
## Purpose
This form is designed to collect information about a mobile home inspection. It will help create a comprehensive picture of the property's condition and characteristics, which can be used for internal documentation, reporting, and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the address of the mobile home in the `Address` field.
2. Select the type of the mobile home from the options provided in the `Home Type` field.
3. If you are unsure about the type, you can choose `Other` and provide a description in the `Home Type` field.
4. Enter the square footage of the mobile home in the `Square Footage` field.
5. Enter the number of bedrooms and bathrooms in the `Number of Bedrooms` and `Number of Bathrooms` fields respectively.
6. Enter the year the mobile home was built in the `Year Built` field.
7. Enter the lot size of the mobile home in the `Lot Size` field.
8. Select the type of property from the options provided in the `Property Type` field.
9. Enter the dimensions of the lot in the `Lot Dimensions` field.
10. Enter the name of the neighborhood in the `Neighborhood` field.

## Field-by-Field Explanation
- **Address** (`Address`, `text`, required: false): Enter the address of the mobile home, including the street number and name.
- **Home Type** (`Home Type`, `select_one`, required: false): Select the type of mobile home from the options provided (Mobile Home, Single Family, Townhouse, etc.).
- **Square Footage** (`sqft`, `number`, required: false): Enter the total square footage of the mobile home.
- **Number of Bedrooms** (`bedrooms`, `number`, required: false): Enter the number of bedrooms in the mobile home.
- **Number of Bathrooms** (`bathrooms`, `number`, required: false): Enter the number of bathrooms in the mobile home.
- **Year Built** (`year_built`, `number`, required: false): Enter the year the mobile home was built.
- **Lot Size** (`lot_size`, `number`, required: false): Enter the size of the lot in square feet.
- **Property Type** (`property_type`, `select_multiple`, required: false): Select the type of property from the options provided (Single Family, Townhouse, Condo, etc.).
- **Lot Dimensions** (`lot_dimensions`, `number`, required: false): Enter the dimensions of the lot in feet.
- **Neighborhood** (`neighborhood`, `text`, required: false): Enter the name of the neighborhood where the mobile home is located.

## Tips
- If you are unsure about the type of mobile home, select `Other` and provide a description in the `Home Type` field.
- Make sure to enter accurate information in the `Square Footage`, `Number of Bedrooms`, `Number of Bathrooms`, `Year Built`, `Lot Size`, and `Lot Dimensions` fields as they are crucial for assessing the property's condition and features.
