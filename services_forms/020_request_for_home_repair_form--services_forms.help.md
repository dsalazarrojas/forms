# request_for_home_repair_form - Help Guide
## Purpose
This form is for homeowners to request home repairs, such as scheduling an appointment, providing contact details, and indicating the services needed.

## How To Complete This Form
To fill out this form, please follow these steps:

1. Enter your First name in the First name field.
2. Enter your Last name in the Last name field.
3. Enter your email address in the Email field.
4. Enter a description of the repair issue in the Description field.
5. Enter your phone number in the Phone field.
6. Choose a date for the repair visit in the Date field.
7. Choose a time for the repair visit in the Time field.
8. Indicate which services you would like to have performed in the Services field.
9. If you have an assigned tool, select Yes or No from the Assigned Tool field.

## Field-by-Field Explanation

* **First name** (Text): Enter your first name.
* **Last name** (Text): Enter your last name.
* **Email** (Email): Enter your email address.
* **Description** (Text): Describe the repair issue you're experiencing.
* **Phone** (Text): Enter your phone number, e.g., 123-456-7890.
* **Date** (Date): Choose a date for the repair visit.
* **Time** (Time): Choose a time for the repair visit.
* **Services** (Select Multiple): Indicate which services you would like to have performed.
	+ Yes: Select this option if you need this service.
	+ No: Select this option if you do not need this service.
* **Assigned Tool** (Select One): 
	+ Yes: Select this option if you have an assigned tool.
	+ No: Select this option if you do not have an assigned tool.

## Tips

* Make sure to fill out all required fields, marked with an asterisk (\*).
* Double-check your email address for accuracy.
* Enter a clear and concise description of the issue to ensure the repair team can quickly understand your request.
* If you have any questions or concerns, please don't hesitate to contact the facility management team.
