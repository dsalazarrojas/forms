# Karaoke Contest Judging Form - Help Guide
## Purpose
The Karaoke Contest Judging Form is used to collect information about the performance of each contestant in a competition. To complete this form, you will need to input information about the contestants and their performances.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Contestant Name in the field labeled "Contestant Name".
2. Enter the Score for the performance in the field labeled "Score".
3. Select the Ranking for the performance from the options provided in the field labeled "Ranking".
4. Select the awards for the performance from the options provided in the field labeled "Award" and "Special Award".
5. Enter the Entry Number for the performance in the field labeled "Entry Number".
6. Enter the Entry Name for the performance in the field labeled "Entry Name".
7. Enter the Entry Score for the performance in the field labeled "Entry Score".

* **Contestant Name** (`contestant_name`, text, optional): Enter the name of the contestant being judged.
* **Score** (`score`, number, optional): Enter the score for the performance, with a range of 1-10.
* **Ranking** (`ranking`, select_one, optional): Select the ranking for the performance from 1st to 10th place.
* **Award** (`award`, select_multiple, optional): Select the awards for the performance, choosing from Award 1, Award 2, or Award 3.
* **Special Award** (`special_award`, select_multiple, optional): Select the special awards for the performance, choosing from Special Award ประก, Special Award 2, or Special Award 3.
* **Entry Number** (`entry_number`, number, optional): Enter the entry number for the performance.
* **Entry Name** (`entry_name`, text, optional): Enter the name of the performance.
* **Entry Score** (`entry_score`, number, optional): Enter the score for the performance, with a range of 1-10.

## Tips
* Make sure to fill out all required fields for accurate results.
* If you are unsure about the ranking or awards, you can refer to the contest's rules and guidelines.
