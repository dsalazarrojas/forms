# Facilities Request Form - Help Guide
## Purpose
The Facilities Request Form is a tool used to collect information from users to request facilities for events or meetings.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information ready, including your contact details, event name and dates, expected number of people, facilities required and any additional notes.
2. Fill in the form fields with the required information:
	* **Contact information**: Provide your name and contact details so we can get in touch with you.
	* **Name**: Enter the name of the event or meeting.
	* **Event date from**: Select the start date of the event or meeting.
	* **Event date to**: Select the end date of the event or meeting.
	* **Expected people**: Enter the estimated number of people attending the event or meeting.
	* **Chairs needed**: Enter the number of chairs required for the event or meeting.
	* **Tables needed**: Enter the number of tables required for the event or meeting.
	* **External form link**: If you have an external form link, please provide it.
	* **Facilities request note**: Provide any additional notes or details about the event or meeting.

## Field-by-Field Explanation
* **Contact information (Text)**:
	+ **Name**: Enter your name.
	+ **Email**: Enter your email address.
	+ **Phone**: Enter your phone number.
* **Name (Text)**:
	+ Enter the name of the event or meeting.
* **Event date from (Date)**:
	+ Select the start date of the event or meeting.
* **Event date to (Date)**:
	+ Select the end date of the event or meeting.
* **Expected people (Number)**:
	+ Enter the estimated number of people attending the event or meeting.
* **Chairs needed (Number)**:
	+ Enter the number of chairs required for the event or meeting.
* **Tables needed (Number)**:
	+ Enter the number of tables required for the event or meeting.
* **External form link (Text)**:
	+ If you have an external form link, please provide it.
* **Facilities request note (Note)**:
	+ Enter any additional notes or details about the event or meeting.
