# copy_request_form - Help Guide

## Purpose

This form is designed to help staff members request a copy of a specific type of file, such as a file, document, or report. The information gathered will be used to facilitate the process of requesting a copy.

## How To Complete This Form

1.  Fill out the form with accurate and detailed information.
2.  Select the correct staff member who is requesting the copy.
3.  Choose the type of file requested (file, document, or report).
4.  Select the department the request is related to.
5.  Provide a detailed description of the reason for the request.
6.  Enter the file name.
7.  Enter the date the copy is needed.
8.  Specify the staff member who is requesting the copy.
9.  Enter the purpose of the request.
10.  If necessary, select the tool assigned for the request.
11.  If submitting a file, provide the necessary attachments.

## Field-by-Field Explanation

*   **Staff Member**: Select your staff member ID number.
*   **File Type**: Choose the type of file requested (file, document, or report).
*   **Department**: Select the department related to the request.
*   **Description**: Enter a detailed description of the reason for the request.
*   **File Name**: Enter the name of the file to be copied.
*   **Date of Creation**: Enter the date when the file was created.
*   **Requested By**: Enter your staff member ID number.
*   **Purpose**: Enter a brief description of the purpose of the request.
*   **Assigned Tool**: If applicable, select the tool assigned for the request.
*   **Attachments**: If submitting a file, upload the necessary attachments.
*   **Email**: Enter your email address.
*   **Phone**: Enter your phone number.
*   **Notes**: Enter any additional notes or comments.
*   **Attachments**: If submitting a file, select the type of attachment (file, document, or report).
