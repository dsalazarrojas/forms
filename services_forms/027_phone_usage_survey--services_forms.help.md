# phone_usage_survey--services_forms - Help Guide
## Purpose
This guide will walk you through the phone usage survey form, used to collect information about phone usage habits and preferences of service providers.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out each field carefully and accurately. If you're unsure about a particular field, you can refer to the field-by-field explanations below.
2. Make sure to complete all required fields (marked as "required").
3. If a field is not required, you can leave it blank if you don't have any information to fill it out.

## Field-by-Field Explanation
### 1. phone_survey_template
* **phone_survey_template** (`phone_survey_template`, `text`, required): This field is used to record the phone usage survey template used by the service provider. Please fill out this field with the name of the template you use.

### 2. mobile_phone_screen_time
* **mobile_phone_screen_time** (`mobile_phone_screen_time`, `text`, required): This field is used to record the average time spent on phone screen by the service provider.

### 3. screen_time_by_day
* **screen_time_by_day** (`screen_time_by_day`, `time`, required): This field is used to record the average screen time per day by the service provider.

### 4. phone_model
* **phone_model** (`phone_model`, `text`, required): This field is used to record the phone model used by the service provider.

### 5. operating_system
* **operating_system** (`operating_system`, `select_one`, required): This field is used to record the operating system used on the phone. Please select one of the following options:
	+ Android
	+ iOS
	+ Windows

### 6. screen_size
* **screen_size** (`screen_size`, `select_one`, required): This field is used to record the screen size of the phone. Please select one of the following options:
	+ large
	+ medium
	+ small

### 7. screen_resolution
* **screen_resolution** (`screen_resolution`, `select_multiple`, required): This field is used to record the screen resolution of the phone. Please select all that apply:
	+ HD
	+ FullHD
	+ 4K

### 8. carrier_survey
* **carrier_survey** (`carrier_survey`, `text`, required): This field is used to record any survey or feedback about the carrier used by the service provider.

### Tips

* Make sure to fill out all required fields accurately.
* If you're unsure about a particular field, you can refer to the field-by-field explanations above.
* If you have any other comments or feedback, you can include them in the carrier_survey field.
