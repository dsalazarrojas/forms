# Design Approval Form - Help Guide
## Purpose
The Design Approval Form is a critical tool for design project review and approval.

## How To Complete This Form
To complete the Design Approval Form, follow these steps:

1. Select the status of your design project (Active or Inactive)
2. Provide a brief description of the project
3. Determine if you have design files that need to be approved
4. Select the necessary approvals for the design project
5. Enter any relevant notes for the reviewer
6. Enter your email address for notification purposes
7. Enter a phone number for communication purposes
8. Set the due date and due time for the review
9. Select the assignee for the review (if applicable)
10. Select the assigned tool for the review (if applicable)
11. Enter any custom information for the reviewer

## Field-by-Field Explanation

* **Design Approval**: Select 'Yes' to indicate that the design project has been approved.
* **Description**: Enter a brief description of the design project.
* **Design Files**: Select 'Yes' if you have design files that need to be approved. This will prompt the reviewer to review the files.
* **Approvals**: Select the necessary approvals for the design project.
* **Notes**: Enter any relevant notes for the reviewer.
* **Email**: Enter your email address for notification purposes.
* **Phone**: Enter a phone number for communication purposes.
* **Due Date**: Set the due date for the review.
* **Due Time**: Set the due time for the review.
* **Assignee**: Select 'Yes' if you want to assign a specific reviewer to the project.
* **Assigned Tool**: Select 'Yes' if you want to assign a specific tool to the review.
* **Custom**: Enter any custom information for the reviewer.
* **Design ID**: Enter the ID of the design project.
* **Client Name**: Enter the name of the client.
* **Design URL**: Enter the URL of the design project.
* **Client URL**: Enter the URL of the client's website.
* **Category**: Enter the category of the design project.
* **Tags**: Select 'Yes' if you want to add custom tags to the project.
* **Custom Tags**: Select 'Yes' if you want to add custom tags to the project.
* **Status**: Select 'Active' or 'Inactive' to indicate the status of the design project.
* **Custom Status**: Select 'Active' or 'Inactive' to indicate the custom status of the design project.
* **Submitter**: Enter the name of the person submitting the design project.
* **Submitted At**: Enter the date the design project was submitted.

Remember to double-check all fields for accuracy before submitting the form.
