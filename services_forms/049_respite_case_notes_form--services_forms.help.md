# respite_case_notes_form - Help Guide
## Purpose
The respite_case_notes_form is a tool used to document the details of respite care provided to a client. This form helps to ensure that the care provided is accurate and can be easily accessed for future reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the relevant information about the client.
2. Enter the date and time that respite care began.
3. Specify the duration of time that respite care was provided.
4. Add any notes about the respite care provided.
5. Enter the name of the respite care provider.
6. Specify the location where respite care was provided.

## Field-by-Field Explanation
### 1. what_is_respite_care (`what_is_respite_care`)
* Label: what_is_respite_care
* Type: text
* Required: false
* Explanation: This field is an optional text field where you can enter a brief description of what respite care means to the client or caregiver.
* Hint: Not required but recommended to provide context for the respite care provided.

### 2. client_name (`client_name`)
* Label: client_name
* Type: text
* Required: false
* Explanation: Enter the name of the client receiving respite care.
* Hint: Please use the client's full name, as it will help with future reference and identification.

### 3. date_respite_began (`date_respite_began`)
* Label: date_respite_began
* Type: date
* Required: false
* Explanation: Enter the date when respite care began for the client.
* Hint: Use the standard date format (e.g., MM/DD/YYYY).

### 4. time_respite_began (`time_respite_began`)
* Label: time_respite_began
* Type: time
* Required: false
* Explanation: Enter the time when respite care began for the client.
* Hint: Use the 12-hour clock format (e.g., 01:30 PM).

### 5. duration_respite_provided (`duration_respite_provided`)
* Label: duration_respite_provided
* Type: number
* Required: false
* Explanation: Enter the number of hours or days respite care was provided to the client.
* Hint: Enter a numeric value, for example, 2 (for 2 hours), 3 (for 3 days), etc..

### 6. notes (`notes`)
* Label: notes
* Type: text
* Required: false
* Explanation: Enter any additional comments or notes about the respite care provided to the client.
* Hint: This is a free text field for any relevant details.

### 7. respite_care_provider (`respite_care_provider`)
* Label: respite_care_provider
* Type: text
* Required: false
* Explanation: Enter the name of the person providing respite care for the client.
* Hint: This can be a staff member's name or a contracted agency.

### 8. respite_care_location (`respite_care_location`)
* Label: respite_care_location
* Type: text
* Required: false
* Explanation: Enter the location where respite care was provided to the client.
* Hint: This can be the client's home, a care facility, or other locations.
