# Service Request - Help Guide
## Purpose

The Service Request form is used to capture details of a service request, including the category, description, assigned tool, and any additional notes. This helps ensure that the correct information is gathered and communicated accurately.

## How To Complete This Form

1. **Submit the form only once for each service request**: To avoid duplication, please submit the form only once for each unique service request.
2. **Select the correct category**: Choose the correct category from the dropdown list.
3. **Provide a clear description**: Enter a concise and accurate description of the service request.
4. **Select the assigned tool**: Choose the tool that will be used to complete the service request from the dropdown list.
5. **Add any additional notes**: Provide any relevant information that may be helpful for the service request.

## Field-by-Field Explanation
- **Category** (`category`, `select_one`, required): Choose the category of the service request (e.g., 1, 2, or 3).
- **Description** (`description`, `text`, required): Enter a brief description of the service request.
- **Phone** (`phone`, `text`, optional): Provide your phone number for any follow-up communication.
- **Assigned Tool** (`assigned_tool`, `select_one`, required): Select the tool that will be used to complete the service request (e.g., chatjimmy or chatbot).
- **Notes** (`notes`, `note`, optional): Add any additional notes about the service request.
