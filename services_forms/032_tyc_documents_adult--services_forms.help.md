# TYC Documents Adult - Help Guide
## Purpose
The "TYC Documents Adult" form is a critical tool used to collect and store adult documentation information. It's essential to fill this form out accurately and thoroughly to ensure the adult receives the proper documentation they need from our services.

## How To Complete This Form
1. Fill in the required fields: 
   - Adult Enrollment Process
   - Adult Document
   - Date
   - Email (if applicable)
2. Select the correct option for the adult's documentation status: 
   - Select One
3. Optionally, provide the time for the adult's documentation appointment if necessary.
4. Optionally, provide additional notes about the adult's documentation process.
5. If required, select the correct multiple options for the adult's documentation status: 
   - Select Multiple

## Field-by-Field Explanation
* **Adult Enrollment Process** (`adult_enrollment_process`, text, required): Describe the adult's current enrollment process, including their current status and any challenges they're facing.
* **Adult Document** (`adult_document`, text, required): Enter a detailed description of the adult's documentation, including the type of document they need and any relevant details.
* **Date** (`date`, date, required): Enter the date of the adult's documentation appointment or the date they need documentation by.
* **Time** (`time`, time, optional): Provide the time of the adult's documentation appointment, if scheduled.
* **Email** (`email`, email, required): Enter the adult's email address for communication and documentation purposes.
* **Phone** (`phone`, text, optional): Enter the adult's phone number for communication and follow-up.
* **Note** (`note`, note, optional): Add any additional comments or notes about the adult's documentation process.
* **Select One** (`select_one`, select_one, required): Choose the correct option to indicate the adult's documentation status:
	+ Yes
	+ No
* **Select Multiple** (`select_multiple`, select_multiple, optional): Select multiple options to indicate the adult's documentation status:
	+ Yes
	+ No
* **Date Range** (`date_range`, text, optional): Enter a range of dates for the adult's documentation appointment or process.
* **Time Range** (`time_range`, text, optional): Enter a range of times for the adult's documentation appointment or process.
* **Email List** (`email_list`, text, optional): Enter a list of email addresses for the adult's documentation purposes.
