# Pet Walking And Play Session Guide - Help Guide
## Purpose
This guide explains how to complete the Pet Walking And Play Session form, which is used by pet owners to schedule a pet walking and play session with a pet walker or caregiver.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of session you are booking: Pet Walker or Caregiver.
2. Enter the start and end time of the session.
3. Choose the start date of the session.
4. Assign a preferred pet walker or caregiver from the list.
5. Enter your email address.
6. Enter your phone number.
7. Add any additional notes about the session.

## Field-by-Field Explanation

* **Pet Walker/Owner Details** (`pet_walker`, text, optional): This field is used to input the pet walker or caregiver's name.
* **Owner Details** (`owner_details`, text, optional): This field is used to input any additional information about the pet owner.
* **Session Preferences** (`session_preferences`, text, optional): This field is used to input any special requests or preferences for the session.
* **Consent** (`consent`, select_one, required): This field allows the pet owner to select whether the pet will be walked by a Pet Walker or a Caregiver.
* **Start Time** (`start_time`, time, optional): This field is used to input the start time of the session.
* **End Time** (`end_time`, time, optional): This field is used to input the end time of the session.
* **Start Date** (`start_date`, date, optional): This field is used to input the start date of the session.
* **End Date** (`end_date`, date, optional): This field is used to input the end date of the session.
* **Owner Email** (`owner_email`, email, optional): This field is used to input the pet owner's email address.
* **Owner Phone** (`owner_phone`, text, optional): This field is used to input the pet owner's phone number.
* **Notes** (`notes`, note, optional): This field is used to add any additional comments or notes about the session.
* **Assigned Tool** (`assigned_tool`, select_multiple, required): This field is used to select the pet walker or caregiver who will be assigned to the session.
* **Owner Name** (`owner_name`, text, optional): This field is used to input the pet owner's name.

## Tips
* Make sure to select the correct type of session (Pet Walker or Caregiver).
* Double-check that you have entered the correct start and end times for the session.
* Ensure you have entered the correct start and end dates for the session.
* Be clear and concise in your input for the Owner Name, Owner Email, and Owner Phone fields.
