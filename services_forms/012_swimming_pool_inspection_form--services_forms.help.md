# swimming_pool_inspection_form - Help Guide
## Purpose
This form is for inspecting swimming pools. It is used to gather information about the condition and status of a swimming pool during an inspection. 

## How To Complete This Form
To complete this form, follow these steps:
1. Answer each question carefully and thoroughly. 
2. Fill in the general information on the first page.
3. Select all relevant options for pool wall, pool deck, and pool stairs on the first page.
4. Enter the number of pool furniture and electrical equipment on the second page.
5. Enter the type and status of pool pumps on the second page.
6. Choose the pool filter type on the second page.
7. Describe the pool cover on the second page.
8. Enter the pool water quality on the second page.
9. Describe the pool equipment on the second page.
10. Select all relevant safety precautions on the second page.

## Field-by-Field Explanation
- **general_info** (General Information, text, required: false): Enter a brief description of the pool and its surroundings. 
  This field is meant to gather any relevant information that does not fit into other categories.
- **pool_wall** (Pool Wall, text, required: false): Describe the condition and features of the pool wall.
  This field is used to inspect the pool wall's condition and features.
- **pool_floor** (Pool Floor, select_multiple, required: false): Select all features of the pool floor.
  This field is used to inspect the pool floor's features.
  Options: Pool Wall 1, Pool Wall 2, Pool Wall 3
- **pool_deck** (Pool Deck, number, required: false): Enter the number of pool deck features.
  This field is used to inspect the pool deck's features.
- **pool_stairs** (Pool Stairs, text, required: false): Describe the pool stairs' condition and features.
  This field is used to inspect the pool stairs' condition and features.
- **pool_furniture** (Pool Furniture, number, required: false): Enter the number of pool furniture.
  This field is used to inspect the number of pool furniture.
- **pool_electrical** (Pool Electrical, text, required: false): Describe the pool electrical system's condition and features.
  This field is used to inspect the pool electrical system's condition and features.
- **pool_pumps** (Pool Pumps, text, required: false): Describe the pool pumps' condition and features.
  This field is used to inspect the pool pumps' condition and features.
- **pool_filter** (Pool Filter, select_one, required: false): Select the type of pool filter.
  This field is used to select the pool filter type.
  Options: Pool Filter 1, Pool Filter 2, Pool Filter 3
- **pool_cover** (Pool Cover, text, required: false): Describe the pool cover's condition and features.
  This field is used to inspect the pool cover's condition and features.
- **pool_water_quality** (Pool Water Quality, number, required: false): Enter the pool water quality.
  This field is used to inspect the pool water quality.
- **pool_equipment** (Pool Equipment, text, required: false): Describe the pool equipment's condition and features.
  This field is used to inspect the pool equipment's condition and features.
- **pool_safety** (Pool Safety, select_multiple, required: false): Select all relevant safety precautions.
  This field is used to select all relevant safety precautions.
  Options: Safety 1, Safety 2, Safety 3
