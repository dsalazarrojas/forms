# Housekeeping Service Request Form - Help Guide
## Purpose
The Housekeeping Service Request Form is used by users to request housekeeping services such as cleaning, janitorial, and maintenance services. This form should only be used for housekeeping services and not for other purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of service you need from the "Service Type" dropdown menu.
2. If you have a specific date for the service, enter it in the "Date of Service" field. If not, leave this field blank.
3. If you have a specific start time, enter it in the "Start Time" field. If not, leave this field blank.
4. If you have a specific end time, enter it in the "End Time" field. If not, leave this field blank.
5. Select all the areas where you need the service from the "Service Area" dropdown menu.
6. If there are any additional requests or information, please provide in the "Additional Requests" field.
7. Enter your contact number in the "Contact Number" field.
8. Enter your email in the "Email" field.
9. Select the person who should be assigned to perform the service from the "Assigned To" dropdown menu.

## Field-by-Field Explanation

* **Service Type** (`service_type`, required): Select the type of service you need (Cleaning, Janitorial, Maintenance)
* **Date of Service** (`date_of_service`, optional): Enter the date you would like to have the service performed. If not applicable, leave blank.
* **Start Time** (`start_time`, optional): Enter the start time of the service. If not applicable, leave blank.
* **End Time** (`end_time`, optional): Enter the end time of the service. If not applicable, leave blank.
* **Frequency of Service** (`service_frequency`, required): Select how often you need the service (Daily, Weekly, Biweekly, Monthly, One Time)
* **Service Area** (`service_area`, required): Select all the areas where you need the service (Kitchen, Living Room, Bedroom, Bathroom, Hallway)
* **Additional Requests** (`additional_requests`, optional): Please provide any additional requests or information.
* **Contact Number** (`contact_number`, required): Enter your contact number.
* **Email** (`email`, required): Enter your email.
* **Assigned To** (`assigned_to`, required): Select the person who should be assigned to perform the service (John, Jane, Bob)
