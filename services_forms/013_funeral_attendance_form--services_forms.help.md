# Funeral Attendance Form - Help Guide
## Purpose
This form is used to collect information about funeral attendance for event organizers to manage attendance effectively.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your name in the `Name` field.
2. Select the type of attendee (Family Member, Friend, or Guest).
3. Enter your contact number in the `Contact Number` field.
4. Select the date and time of attendance using the respective fields.
5. Choose the seating arrangement (Traditional, Non-traditional, or Other).
6. Enter the number of attendees and seating capacity in the respective fields.
7. You can add any additional notes or comments about the attendee's preferences.
8. If you have any special requests or needs, please fill in the `Logistics` field.
9. If you want to provide any funeral services, describe them in the `Funeral Services` field.
10. Indicate if parking will be provided on-site or off-site.
11. Choose if you want any catering services.
12. Select if you need any audio/visual aids.
13. Indicate if you want to provide a video stream or live stream of the funeral service.
14. If you want to provide a live stream, choose the streaming service you prefer (e.g., YouTube, Vimeo, or Other).
15. Provide any additional information about the live stream (e.g., URL).

## Field-by-Field Explanation
- **Name** (1, Text, Required): Enter your name to identify yourself.
- **Attendee Type** (2, Select One, Required): Choose the type of attendee (Family Member, Friend, or Guest).
- **Contact Number** (3, Text, Required): Enter your contact number so we can reach you if needed.
- **Date** (4, Date, Required): Select the date you plan to attend the funeral.
- **Time** (5, Time, Required): Choose the time you plan to attend the funeral.
- **Seating Arrangement** (6, Select One, Required): Select your preferred seating arrangement (Traditional, Non-traditional, or Other).
- **Number of Attendees** (10, Number, Required): Enter the number of people attending with you.
- **Seating Capacity** (9, Number, Required): Enter the total seating capacity for your group.
- **Seating** (11, Select Multiple, Optional): Choose any additional seating requirements (Traditional, Non-traditional, or Other).
- **Logistics** (12, Text, Optional): Add any special logistics requests or needs.
- **Email** (8, Email, Optional): Enter your email address for future communication.
- **Seating Capacity** (16, Number, Optional): Enter the total seating capacity for your group.
- **Logistics** (13, Text, Optional): Add any special logistics requests or needs.
- **Funeral Services** (14, Text, Optional): Describe any funeral services you want to provide.
- **Parking** (15, Select Multiple, Optional): Choose if you want to provide on-site or off-site parking.
- **Catering** (16, Select One, Optional): Check if you want any catering services.
- **Audio/Visual** (17, Select Multiple, Optional): Choose if you need any audio/visual aids.
- **Video Stream** (18, Select Multiple, Optional): Check if you want to provide a video stream of the funeral service.
- **Live Stream** (19, Select Multiple, Optional): Check if you want to provide a live stream of the funeral service.
