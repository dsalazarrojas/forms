# Emergency Road Service Call Form - Help Guide

## Purpose
The Emergency Road Service Call Form is used to report emergency road incidents and services. It helps in quickly collecting and processing information about road closures, accidents, and maintenance issues.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose "Yes" or "No" for "Category" regarding whether the incident is related to an emergency.
2. Provide a short description of the incident in the "Description" field.
3. Select the relevant "Road Service Area" from the provided options (e.g., Emergency Roadside, Emergency Roadway, Emergency Highway).
4. Choose "Yes" or "No" for "Emergency Service Request" regarding whether service is required.
5. Select the assigned tool for the incident from the provided options (e.g., chatjimmy, chatjimmy1).
6. Provide any output file generated from the service call in the "Output File" field.
7. Indicate whether a form was assigned to the incident in the "Assigned Form" field.

## Field-by-Field Explanation

### **Category** (`Category`, Select Multiple, Not Required)
Choose "Yes" if the incident is related to an emergency, otherwise choose "No".

### **Description** (`Description`, Text, Not Required)
Provide a brief description of the incident, e.g., "Road closure due to accident" or "Maintenance issue on the highway".

### **Road Service Area** (`Road Service Area`, Select One, Not Required)
Select the relevant road service area from the provided options, e.g., Emergency Roadside, Emergency Roadway, Emergency Highway.

### **Emergency Service Request** (`Emergency Service Request`, Select Multiple, Not Required)
Choose "Yes" if emergency service is required, otherwise choose "No".

### **Assigned Tool** (`Assigned Tool`, Select One, Not Required)
Select the assigned tool for the incident from the provided options, e.g., chatjimmy, chatjimmy1.

### **Output File** (`Output File`, Text, Not Required)
Provide any output file generated from the service call, e.g., a report or document.

### **Assigned Form** (`Assigned Form`, Select One, Not Required)
Indicate whether a form was assigned to the incident, e.g., "Yes" if a form was assigned.

Note: The fields marked as "Not Required" are optional and can be skipped if not applicable.
