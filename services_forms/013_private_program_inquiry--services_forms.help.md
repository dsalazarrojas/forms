# Private Program Inquiry - Help Guide
## Purpose
The Private Program Inquiry form is designed to gather information from users about specific events or sessions they are interested in. It will be reviewed internally to confirm event details and follow-up with the submitter for any additional information or questions.

## How To Complete This Form
1. Select the type of event or session you are interested in:
	* Event Type: Choose between Session, Event, or Other
2. Select the type of program you are interested in:
	* Program Type: Choose between Personalized Training, Group Session, or Private Training
3. Enter the name of the program or session:
	* Program Name: Enter the name of the program or session
4. Briefly describe the program or session:
	* Program Details: Write a brief description of the program or session
5. Enter your name:
	* Contact Name: Enter your name
6. Enter your email address:
	* Email: Enter your email address
7. Enter the program location:
	* Program Location: Enter the location of the event or session
8. (Optional) Select a preferred date for the event or session:
	* Preferred Start Date: Select a date for the event or session
9. (Optional) Select a preferred start time for the event or session:
	* Preferred Start Time: Select a start time for the event or session
10. (Optional) Select a preferred end time for the event or session:
	* Preferred End Time: Select an end time for the event or session
11. (Optional) Select the preferred start date for the event or session:
	* Preferred Start Date: Select the start date for the event or session
12. (Optional) Select the preferred end date for the event or session:
	* Preferred End Date: Select the end date for the event or session
13. Add any additional notes about the event or session:
	* Notes: Add any additional notes about the event or session
14. (Optional) Enter the name of the program instructor:
	* Program Instructor: Enter the name of the program instructor
15. (Optional) Provide any additional information:
	* Additional info: Provide any additional information about the event or session
16. Review and submit the form.

## Field-by-Field Explanation
- **Event Type** (`event_type`, `select_one`, required/true): Select the type of event or session you are interested in.
- **Program Type** (`program_type`, `select_multiple`, required/true): Select the type of program you are interested in.
- **Start Date** (`start_date`, `date`, required/false): Select the date of the event or session.
- **End Date** (`end_date`, `date`, required/false): Select the end date of the event or session.
- **Start Time** (`start_time`, `time`, required/false): Select the start time of the event or session.
- **End Time** (`end_time`, `time`, required/false): Select the end time of the event or session.
- **Program Name** (`program_name`, `text`, required/true): Enter the name of the program or session.
- **Program Details** (`program_details`, `text`, required/true): Briefly describe the program or session.
- **Contact Name** (`contact_name`, `text`, required/true): Enter your name.
- **Email** (`email`, `email`, required/true): Enter your email address.
- **Phone** (`phone`, `text`, required/false): Provide your phone number.
- **Program Location** (`program_location`, `text`, required/true): Enter the location of the event or session.
- **Preferred Date** (`preferred_date`, `date`, required/false): Select a preferred date for the event or session.
- **Preferred Start Time** (`preferred_start_time`, `time`, required/false): Select a preferred start time for the event or session.
- **Preferred End Time** (`preferred_end_time`, `time`, required/false): Select a preferred end time for the event or session.
- **Preferred Start Date** (`preferred_start_date`, `date`, required/true): Select the preferred start date for the event or session.
- **Preferred End Date** (`preferred_end_date`, `date`, required/true): Select the preferred end date for the event or session.
- **Notes** (`notes`, `text`, required/false): Add any additional notes about the event or session.
- **Assigned** (`assigned`, `text`, required/false): Enter the name of the person assigned to.
- **Status** (`status`, `select_one`, required/true): Select the status of the event or session.
- **Follow up** (`follow_up`, `text`, required/false): Enter the follow-up date and time.
- **Follow-up Email** (`follow_up_email`, `text`, required/false): Enter the follow-up email address.
- **Follow-up Phone** (`follow_up_phone`, `text`, required/false): Enter the follow-up phone number.
- **Program Instructor** (`program_instructor`, `text`, required/false): Enter the name of the program instructor.
- **Additional info** (`additional_info`, `text`, required/false): Provide any additional information about the event or session.
