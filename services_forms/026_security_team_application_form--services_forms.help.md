# Security Team Application Form - Help Guide
## Purpose
The Security Team Application Form is a tool designed to help identify potential candidates for security-related tasks and roles. Completing this form will provide valuable information about your availability, experience, and skills to the security team, who will use this information to determine your suitability for security positions.

## How To Complete This Form

To complete this form, simply follow the instructions below:

1. Fill in the required information accurately and thoroughly.
2. Answer all questions, but feel free to skip any questions that do not apply to you.
3. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **First Name** (1): Please enter your first name.
* **Last Name** (2): Please enter your last name.
* **Email** (3): Please enter a valid email address to help us contact you.
* **Job Title** (4): If you are currently employed, please enter your job title.
* **Phone** (5): Please enter your contact phone number.
* **Experience** (6): Describe your relevant work experience, including relevant job roles and skills used.
* **Skills** (7): Select all relevant skills you possess, such as "Yes" or "No".
* **Availability** (8): Select "Yes" if you are available for shifts, "No" otherwise.
* **Security Clearance** (9): If you have a security clearance, select "Yes" and enter any other clearance details in the "Other Security Clearance" field.
* **Other Security Clearance** (10): If you have a security clearance that is not listed, please enter it here.
* **Security Clearance Level** (11): If you have a security clearance, select "High" or "Low" to indicate its level.
* **Shift Worked** (12): Select "Yes" if you have experience with shift work, "No" otherwise.
* **Shifts** (13): Select all types of shifts you are available to work, such as "Yes" or "No".
* **Availability Date** (14): Select your earliest available date for work.
* **Shift Length** (15): Select "Yes" if you are comfortable with longer shifts, "No" otherwise.

Tips: 

* Please answer all questions truthfully and accurately.
* If you are unsure about any question, feel free to ask the security team for clarification.
* This form is a non-committal process, and filling it out does not guarantee a position on the security team.
