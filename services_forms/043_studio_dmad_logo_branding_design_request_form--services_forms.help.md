# Studio DMAD Logo Branding Design Request Form - Help Guide
## Purpose
The purpose of this form is to collect requests for logo branding design services. We need to know the category and description of your request to provide accurate design services.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter your Form Title**: Enter a brief title that describes the request, e.g., "Logo Design for Website Header."
2. **Choose the Category**: Select the category that best fits your request from the list.
3. **Provide a Description**: Write a clear and concise description of the design requirements and expectations.
4. **Specify the Tool**: Enter the tool or software used for the design.

## Field-by-Field Explanation
* **Title**: Enter a brief title that describes the request, e.g., "Logo Design for Website Header."
	+ This is the title of the request, which will be used to identify the project.
* **Category**: Select the category that best fits your request from the list.
	+ This field helps us understand the scope and type of design required.
* **Description**: Write a clear and concise description of the design requirements and expectations.
	+ Provide as much detail as possible to ensure we can deliver the desired result.
* **Tool**: Enter the tool or software used for the design.
	+ This helps us ensure compatibility and compatibility with your design.

## Tips
* Please provide as much detail as possible to ensure we can deliver the desired result.
* If you have any attachments or references that can help us understand the design requirements, please attach them to the request.
* If you have any questions or need clarification, feel free to contact form@gic.mx.
