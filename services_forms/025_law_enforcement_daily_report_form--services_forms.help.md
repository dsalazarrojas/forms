# Law Enforcement Daily Report Form - Help Guide
## Purpose
This form is intended for law enforcement officers to report their daily activities, including the number of incidents encountered, addresses, and descriptions of each run they conduct. This form helps to track and record the daily operations and activities of law enforcement officers.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your Precinct Head (if applicable).
2. Enter your Officer ID.
3. Select the date of the report.
4. Enter the time of the report.
5. Enter the address of the location where the incidents were reported.
6. Provide a brief description of the incidents.
7. For each run conducted, select "Yes" or "No" to indicate if it was conducted, and enter the address and time of the run if applicable.
8. Enter a brief description of each run.

## Field-by-Field Explanation

* **Precinct Head (precinct_head)**: Enter the name of your precinct head if you are reporting for them.
* **Officer ID (officer_id)**: Enter your officer ID number for identification purposes.
* **Date (date)**: Enter the date of the report using the standard date format (month/day/year).
* **Time (time)**: Enter the time of the report in the 24-hour format (HH:MM).
* **Address (address)**: Enter the address of the location where the incidents were reported.
* **Description (description)**: Provide a brief description of the incidents.
* **Incident Count (incident_count)**: Optional field for reporting the total number of incidents.
* **Run 1 (run_one_run)**: Select "Yes" or "No" to indicate if Run 1 was conducted.
* **Run 1 Address (run_one_address)**: Enter the address of Run 1 if it was conducted.
* **Run 1 Time (run_one_time)**: Enter the time of Run 1 if it was conducted.
