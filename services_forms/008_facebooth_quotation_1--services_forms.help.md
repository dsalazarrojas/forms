# facebooth_quotation_1 - Help Guide
## Purpose
This form is used to collect event information for events that require a high level of customization and attention to detail. It is meant to be completed by event planners or coordinators to ensure that all necessary information is collected.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Event Name in the text field.
2. Select the Event Date from the calendar dropdown.
3. Select the Event Time from the dropdown.
4. Enter the Event Location in the text field.
5. Provide Event Details in the text field.
6. Select the Services offered from the list (you can select multiple options).
7. Select the Photographer from the list.
8. Select the Videographer from the list.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required/optional): Enter a unique name for the event.
* **Event Date** (`event_date`, date, required/optional): Select the date of the event from the calendar.
* **Event Time** (`event_time`, time, required/optional): Select the time of the event from the dropdown.
* **Event Location** (`event_location`, text, required/optional): Enter the location of the event.
* **Event Details** (`event_details`, text, required/optional): Enter any additional details about the event.
* **Services** (`services`, select_multiple, required/optional): Select the services that will be offered during the event. You can select multiple options.
* **Photographer** (`photographer`, select_one, required/optional): Select the Photographer assigned to the event.
* **Videographer** (`videographer`, select_one, required/optional): Select whether a Videographer will be assigned to the event.
