# Garden Pond Cleaning Request Form - Help Guide

## Purpose
This form is used to request a garden pond cleaning service.

## How To Complete This Form
1. If you need to request a garden pond cleaning, select "Yes" in the first field.
2. If you want to schedule an appointment, select "Yes" in the first field and fill out the next fields (Day and Time) with your preferred date and time.
3. Fill out the "Client Information" field with your name and contact details.
4. Provide details about the pond you would like to be cleaned in the "Pond Details" field.

## Field-by-Field Explanation
* **Schedule an Appointment** (`Schedule an Appointment`, `select_multiple`, optional):
	+ Select "Yes" to indicate that you would like to schedule an appointment for a garden pond cleaning.
* **Select a Day** (`Select a Day`, `date`, optional):
	+ Choose a day for the pond cleaning appointment.
* **Select a Time** (`Select a Time`, `time`, optional):
	+ Choose a time for the pond cleaning appointment.
* **Client Information** (`Client Information`, `text`, optional):
	+ Enter your name and contact details to provide context for the cleaning service.
* **Select a Service** (`Select a Service`, `select_one`, optional):
	+ Select "Yes" to request that the cleaning service be performed.
* **Pond Details** (`Pond Details`, `text`, optional):
	+ Provide information about the pond you would like to be cleaned.
