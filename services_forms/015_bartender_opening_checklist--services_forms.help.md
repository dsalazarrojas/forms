# Bartender Opening Checklist - Help Guide
## Purpose

The Bartender Opening Checklist is a form designed to ensure that the bar is ready for service before opening. It helps the bartenders and management team to quickly and efficiently verify that all necessary tasks and areas of the bar are in order, making sure that the bar is safe, functional, and ready to provide excellent service to customers.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your name as the bartender.
2. Select the date of your shift.
3. Choose the section of the bar you are opening (e.g. Main bar, Side bar, Patio bar, or Full bar).
4. Answer each question in the corresponding field, following the options provided:
	* Select "True" if the condition is met, "False" if it is not, or choose "Not applicable" if it does not apply.
	* Type "Yes, fully stocked" if you have enough stock, "Some items low" if you need to restock, or "Need reorder" if you need to order more.
	* Select "Yes, all ready" if everything is prepared, "Partially prepared" if some items are not ready, or "False" if nothing is prepared.
5. Check if any issues or problems are found during the opening process and type them in the "Issues Found" field.
6. Sign your full name in the "Bartender Signature" field.
7. Review your answers to ensure that all tasks and areas of the bar are in order.
8. Click submit to save your responses.

## Field-by-Field Explanation

* **Bartender Name**: Your full name as the bartender opening the bar.
* **Shift Date**: The date you are opening your shift.
* **Shift Start Time**: The time you arrived at the bar to begin your shift.
* **Bar Section**: The section of the bar you are opening (e.g. Main bar, Side bar, Patio bar, Full bar).
* **Alarm System Disarmed**: Has the security alarm been turned off?
	+ "True": The alarm is off.
	+ "False": The alarm is still on.
	+ "Not applicable": Does not apply to this shift.
* **Lights Turned On**: Are all bar lights turned on?
	+ "True": All lights are on.
	+ "False": Some or all lights are off.
* **Equipment Powered On**: Are all necessary equipment (e.g. POS system, registers, appliances) turned on?
	+ "Yes, all on": Everything is functioning.
	+ "Some issues": Some equipment is not functioning.
	+ "False": None of the equipment is on or functioning.
* **Refrigerators Checked**: Were the refrigerators checked and verified for proper temperature and contents?
	+ "Yes, all good": Everything is in order.
	+ "Temperature issue": The temperature is not correct.
	+ "Inventory issue": Some items are missing or low.
* **Ice Supply Adequate**: Is there enough ice for service?
	+ "Yes, fully stocked": Enough ice is available.
	+ "Need more": Not enough ice is available.
	+ "Machine running": The ice machine is running but not producing ice.
* **Liquor Inventory Checked**: Is the liquor inventory fully stocked and present?
	+ "Yes, fully stocked": Everything is in order.
	+ "Some items low": Some items are low.
	+ "Missing items": Some items are missing.
* **Beer Inventory Checked**: Is the beer inventory adequate?
	+ "Yes, adequate": Enough beer is available.
	+ "Running low": Not enough beer is available.
	+ "Need reorder": Need to order more beer.
* **Wine Inventory Checked**: Is the wine inventory adequate?
	+ "Yes, adequate": Enough wine is available.
	+ "Running low": Not enough wine is available.
	+ "Need reorder": Need to order more wine.
* **Garnishes Prepared**: Are the garnishes (e.g. lemon wedges, olives) prepared and stored?
	+ "Yes, all ready": Everything is prepared.
	+ "Partially prepared": Some items are not prepared.
	+ "False": None of the garnishes are prepared.
* **Mixers Stocked**: Are the mixers (e.g. juices, sodas, syrups) available?
	+ "Yes, fully stocked": Everything is in order.
	+ "Some items low": Some items are low.
	+ "Need restock": Need to restock.
* **Glassware Available**: Is there enough glassware?
	+ "Yes, plenty": Enough glassware is available.
	+ "Adequate": Enough glassware is available, but not enough to fill an empty bar.
	+ "Need to wash": Need to wash and clean the glassware.
* **Bar Tools Available**: Are the bar tools (e.g. shakers, strainers, jiggers) available?
	+ "Yes, all ready": Everything is available.
	+ "Some missing": Some tools are missing.
	+ "Need to locate": Need to find the tools.
* **Bar Counters Clean**: Are the bar counters clean and wiped?
	+ "True": The counters are clean.
	+ "Needs cleaning": The counters need cleaning.
* **Bar Stools Arranged**: Are the bar stools properly positioned and arranged?
	+ "True": The stools are in order.
	+ "Needs adjustment": The stools need adjustment.
* **Floors Clean**: Are the floors clean and swept?
	+ "True": The floors are clean.
	+ "Needs cleaning": The floors need cleaning.
* **Restrooms Checked**: Are the restrooms clean and stocked?
	+ "Yes, ready": Everything is in order.
	+ "Needs attention": Some issues are found.
	+ "Not applicable": Does not apply to this shift.
* **POS System Ready**: Is the POS system ready for service?
	+ "Yes, ready": The system is operational.
	+ "Issue noted": Some issue is found.
	+ "Needs manager": Need to involve management.
* **Cash Drawer Counted**: Is the cash drawer counted and verified?
	+ "Yes, correct": The count is correct.
	+ "Discrepancy found": Some issues are found.
	+ "Not yet counted": Not yet counted.
* **Menus Available**: Are the menus clean and presented?
	+ "True": The menus are clean and available.
	+ "Need to print": Need to print new menus.
	+ "Not applicable": Does not apply to this shift.
* **Music System On**: Is the background music system on?
	+ "True": The music is playing.
	+ "False": The music is not playing.
	+ "Not applicable": Does not apply to this shift.
* **TVs Functioning**: Are the TV screens functioning?
	+ "Yes, all working": Everything is working.
	+ "Some issues": Some screens are not working.
	+ "Not applicable": Does not apply to this shift.
* **Manager Notified**: Have you notified the manager that the bar is ready?
	+ "True": The manager has been notified.
	+ "False": The manager has not been notified.
* **Any Issues Found**: Are there any issues or problems that need attention?
	+ Type any issues or problems found during the opening process.
* **Bartender Signature**: Your full signature as the bartender who completed this checklist.

## Tips

* Take your time to complete this form carefully.
* Double-check each section before moving on to the next.
* If you are unsure about any of the fields, ask your manager or colleague for guidance.
* Complete this form before opening the bar to ensure that everything is in order.
* Review and update this form as needed to reflect changes to the bar and its operations.
