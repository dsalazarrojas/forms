# Installation Completion Form - Help Guide
## Purpose
This form is used to capture information about completed installations to help internal teams track and monitor project progress.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each section completely and accurately, paying attention to any required fields.
2. If you are unsure about a particular field, refer back to this help guide for clarification.
3. Enter your contact information so that we can get back in touch with you with any follow-up questions.

## Field-by-Field Explanation
* **Project Details** (`project_details`, text, required): Provide a brief description of the project, including its name and any relevant details.
* **Installation Details** (`installation_details`, text, required): Describe the installation process, including any notable issues or successes.
* **Satisfaction** (`satisfaction`, number, required): Rate your overall satisfaction with the installation on a scale from 1 to 10.
* **Contact Person** (`contact_person`, text, optional): If you would like to be contacted about the installation, enter your name and title here.
* **Contact Phone** (`contact_phone`, text, required): Enter your contact phone number so that we can get in touch with you.
* **Contact Email** (`contact_email`, email, required): Enter your contact email address so that we can get in touch with you.
* **Date Installed** (`date_installed`, date, required): Enter the date the installation was completed.
* **Installation Comments** (`installation_comments`, note, optional): Provide any additional comments or feedback about the installation.
* **Project Status** (`project_status`, select_multiple, required): Choose the status of the project from the options provided.
* **Assigned Tool** (`assigned_tool`, text, optional): If relevant, enter the tool or equipment used for the installation.
* **Comments** (`comments`, text, optional): Provide any additional comments or feedback about the installation.
* **Assigned Tool** (`assigned_tool`, text, optional): If relevant, enter the tool or equipment used for the installation.
