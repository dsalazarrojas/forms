# Machine Setup Checklist - Help Guide
## Purpose
This form is used to collect information related to machine setup and maintenance. It's essential to fill out this form accurately to ensure that all necessary details are captured for future reference and to prevent equipment malfunctions.

## How To Complete This Form

1. Select the correct "Equipment ID" from the provided options.
2. Enter the "Machine Name" in the text field.
3. Fill out the "Setup Date" in the required date format (MM/DD/YYYY).
4. Select the "Calibration Status" that best describes the current state of the equipment.
5. Fill out the "Calibration Date" in the required date format (MM/DD/YYYY) if applicable.
6. Enter the "User ID" for the person responsible for the machine setup.
7. Select the "Location" where the machine is set up.
8. Fill out any additional comments or remarks in the "Comments" field.
9. If applicable, select the "Assigned User" who is responsible for the machine.
10. Fill out the "Completed By" field with the user's name who completed the form.
11. Fill out the "Completed Date" in the required date format (MM/DD/YYYY) if applicable.
12. Enter any additional "Notes" related to the machine setup.

## Field-by-Field Explanation

* **Equipment ID**: Select the unique identifier for the equipment being set up.
	+ Options: Equipment ID 1, Equipment ID 2, Equipment ID 3
* **Machine Name**: Enter the name of the machine or equipment.
* **Setup Date**: Enter the date the machine was set up in the MM/DD/YYYY format.
* **Calibration Status**: Select the current status of the machine's calibration.
	+ Options: Calibrated, Not Calibrated, Needs Calibration
* **Calibration Date**: Enter the date the machine was calibrated in the MM/DD/YYYY format if applicable.
* **User ID**: Enter the ID of the user who set up the machine.
* **Location**: Select the location where the machine is set up.
	+ Options: Location 1, Location 2, Location 3
* **Comments**: Enter any additional comments or remarks related to the machine setup.
* **Assigned User**: Select the user who is responsible for the machine if applicable.
* **Completed By**: Enter the name of the user who completed the form.
* **Completed Date**: Enter the date the form was completed in the MM/DD/YYYY format if applicable.
* **Notes**: Enter any additional notes related to the machine setup.
* **Machine Type**: Select the type of machine being set up.
	+ Options: Type 1, Type 2, Type 3
* **Equipment Serial Number**: Enter the serial number of the machine or equipment.
* **Manufacturer**: Select the manufacturer of the machine or equipment.
	+ Options: Manufacturer 1, Manufacturer 2, Manufacturer 3
* **Model Number**: Enter the model number of the machine or equipment.
* **Model Year**: Enter the year the machine or equipment was produced.
* **Model Number Suffix**: Enter any additional information for the model number.
* **Machine Type**: Select the type of machine being set up.
	+ Options: Type 1, Type 2, Type 3
* **Machine Serial Number**: Enter the serial number of the machine.
* **Machine Model Number**: Enter the model number of the machine.
* **Machine Manufacturer**: Select the manufacturer of the machine.
	+ Options: Manufacturer 1, Manufacturer 2, Manufacturer 3
* **Machine Notes**: Enter any additional notes related to the machine setup.
* **Equipment Notes**: Enter any additional notes related to the equipment.
* **User ID**: Enter the ID of the user who set up the machine.
