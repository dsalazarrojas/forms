# virtual_assistant_application_form - Help Guide

## Purpose
The virtual_assistant_application_form is designed to collect information from applicants interested in becoming Virtual Assistants.

## How To Complete This Form
To complete this form, please fill out each field carefully and accurately. 

## Field-by-Field Explanation

* **User Information**: This field is used to capture the applicant's basic contact information.
  * (`id`: 1, `name`: user_info, `type`: text, `required`: false)
  * A simple text field to input the applicant's name.
* **First Name**: This field is used to collect the applicant's first name.
  * (`id`: 2, `name`: first_name, `type`: text, `required`: false)
  * Please enter your first name.
* **Last Name**: This field is used to collect the applicant's last name.
  * (`id`: 3, `name`: last_name, `type`: text, `required`: false)
  * Please enter your last name.
* **Email**: This field is used to collect the applicant's email address.
  * (`id`: 4, `name`: email, `type`: email, `required`: false)
  * Please enter a valid email address.
* **Phone**: This field is used to collect the applicant's phone number.
  * (`id`: 5, `name`: phone, `type`: text, `required`: false)
  * Please enter your phone number.
* **Availability**: This field is used to collect the applicant's availability.
  * (`id`: 6, `name`: availability, `type`: time, `required`: false)
  * Please select a time that you are available to work.
* **Preferred Hours**: This field is used to collect the applicant's preferred hours to work.
  * (`id`: 7, `name`: preferred_hours, `type`: time, `required`: false)
  * Please select a time that you prefer to work.
* **Skills**: This field is used to collect the applicant's skills.
  * (`id`: 8, `name`: skills, `type`: select_multiple, `required`: false)
  * Please select the skills you have experience with. You can select multiple skills.
* **Experience**: This field is used to collect the number of years of experience the applicant has.
  * (`id`: 9, `name`: experience, `type`: number, `required`: false)
  * Please enter the number of years you have experience.
* **Availability Date**: This field is used to collect the availability date of the applicant.
  * (`id`: 10, `name`: availability_date, `type`: date, `required`: false)
  * Please enter a date that you are available to start working.

## Tips
* Please fill out each field carefully and accurately.
* Make sure to include all required fields.
* If you have any questions or need clarification on any field, please do not hesitate to ask.
