# NCR Employee Product Reporting Tool - Help Guide
## Purpose
The NCR Employee Product Reporting Tool is a form designed to help employees report issues with products they have encountered. By reporting these issues, employees can help improve product quality and contribute to a safer work environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Employee" from the drop-down menu to identify yourself.
2. Select "Reported to" from the drop-down menu to identify the person you reported the issue to.
3. Fill in the "Product name", "Category", "Item name", and "Item description" fields with as much detail as possible.
4. Indicate if you have encountered an issue with the product by selecting "Yes" or "No" from the "Item issue" field.
5. If you have selected "Yes", select the relevant recipient from the drop-down menu and provide a date and time when you experienced the issue.
6. Add any additional comments or notes about the issue in the "Comments" field.
7. If you have attached a file related to the issue, provide the URL in the "Attachment URL" field.
8. If you have any further comments about the resolution of the issue, add them in the "Resolution" field.

## Field-by-Field Explanation

* **Employee**: Select the employee who reported the issue.
* **Product name**: The name of the product that caused the problem.
* **Category**: The category of the product that caused the problem.
* **Item name**: The specific item or part of the product that caused the issue.
* **Item description**: A brief description of the item or part of the product that caused the issue.
* **Item issue**: Select "Yes" if you have encountered an issue with the product, and "No" otherwise.
* **Recipient**: Select the person you reported the issue to.
* **Date**: The date when you experienced the issue.
* **Time**: The time when you experienced the issue.
* **Note**: Add any additional comments or notes about the issue.
* **Email**: Your email address.
* **Phone**: Your phone number.
* **Comment**: Add any further comments about the issue.
* **Status**: Select the current status of the resolution.
* **Resolution**: Add any comments about the resolution of the issue.
* **Resolved by**: Add any comments about who resolved the issue.
* **Resolved date**: The date when the issue was resolved.
* **Resolved time**: The time when the issue was resolved.
* **Closed**: Select "Yes" to indicate that the issue has been closed.
* **Comments**: Add any further comments about the issue.
* **Attachment**: If you have attached a file related to the issue.
* **Attachment URL**: Provide the URL of the attached file.
* **Attachment description**: A brief description of the attached file.
