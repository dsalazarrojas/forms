# Pest Control Service Report - Help Guide
## Purpose

This form is used to document pest control services performed for customers.

## How To Complete This Form

1. Ensure you have all the necessary information and approvals before filling out this form.
2. Fill out the fields as required and provide accurate information in each field.

## Field-by-Field Explanation

* **On site treatments** (`on_site_treatments`, text, required): Describe the services provided on site.
* **Customer Info** (`customer_info`, number, optional): Enter the customer's name, address, and contact information (if applicable).
* **Treatment Type** (`treatment_type`, select_one, optional): Select the type of treatment performed (e.g., Baiting, Trapping, Fumigation, Other).
* **Date of treatment** (`date_of_treatment`, date, optional): Enter the date and time of the treatment.
* **Pest Type** (`pest_type`, select_multiple, optional): Select all types of pest treated (e.g., Cockroaches, Rodents, Termites, Other).
* **Pest control method** (`pest_control_method`, select_multiple, optional): Select all methods of pest control used (e.g., Baiting, Trapping, Fumigation, Other).
* **Treatment area** (`treatment_area`, text, required): Enter the location or area of treatment (e.g., kitchen, bathroom, entire home).
* **Notes** (`notes`, note, optional): Add any additional comments or notes from the customer.
* **Customer signature** (`customer_signature`, text, optional): The customer's signature, if required.
