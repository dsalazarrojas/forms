# Events & Hospitality Consultation Form - Help Guide
## Purpose
This form is designed to collect information about an event or hospitality consultation from clients.

## How To Complete This Form
To complete this form, follow these steps:

* Ensure you have been assigned a unique event ID by the service provider.
* Select the relevant event services from the options provided in the "event_services" field.
* Enter the details of the event in the "event_details" field.
* Choose a date for the event in the "event_date" field.
* Select the time for the event in the "event_time" field.
* Enter the number of guests attending the event in the "event_guests" field.
* Enter the location of the event in the "event_location" field.
* Enter a note or message about the event in the "event_note" field.
* Enter your contact email in the "contact_email" field.
* Enter your contact phone number in the "contact_phone" field.

## Field-by-Field Explanation
* **event_services** (Select Multiple): Select all the services you require for your event from the options provided.
* **event_details** (Text): Enter a brief description of the event, including any relevant details such as event theme, style, or purpose.
* **event_date** (Date): Choose a date for the event.
* **event_time** (Time): Select the time for the event.
* **event_guests** (Number): Enter the number of guests attending the event.
* **event_location** (Text): Enter the location where the event will take place.
* **event_note** (Note): Enter any additional notes or instructions about the event.
* **contact_email** (Email): Enter your email address so we can contact you about the event.
* **contact_phone** (Text): Enter your phone number so we can contact you about the event.
