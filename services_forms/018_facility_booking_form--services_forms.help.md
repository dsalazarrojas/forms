# facility_booking_form - Help Guide
## Purpose
This form is used to book a facility for a specified duration. Please provide the necessary details to complete your booking request.

## How To Complete This Form
To complete this form, follow these steps:
- Fill in the facility booking details, including a clear description of the facility you want to book.
- Select the duration of your booking from the available options (1 day, 2 days, or 4 days).
- If applicable, provide your start and end dates for the booking.
- Enter any contact details if you need to be contacted for further information.
- Finally, enter your name and phone number (optional) if you would like to be contacted back.

## Field-by-Field Explanation
- **facility_booking_details** (facility_booking_details, text, required): Enter a clear description of the facility you want to book.
- **facility_usage_duration** (facility_usage_duration, select_one, optional): Select the duration of your booking from the available options (1 day, 2 days, or 4 days).
- **start_date** (start_date, date, optional): If you have a specific start date for your booking, please enter it here.
- **end_date** (end_date, date, optional): If you have a specific end date for your booking, please enter it here.
- **contact_details** (contact_details, text, optional): Provide any contact information if you need to be contacted for further information.
- **name** (name, text, optional): Enter your name if you would like to be contacted back.
- **phone_number** (phone_number, text, optional): Enter your phone number if you would like to be contacted back.

## Tips
- Please make sure to fill in all the required fields to ensure your booking request is processed correctly.
- If you have any questions or need further assistance, feel free to contact us.
