# Software Development Assessment - Help Guide

## Purpose
The Software Development Assessment form is used to gather information about software development projects. This form helps assess the status, description, and other relevant details of a software development project. 

## How To Complete This Form
To complete this form, follow the steps below:

* Fill in the required information as prompted.
* Review the form carefully to ensure accuracy.
* Submit the completed form once you have reviewed and verified the information.

## Field-by-Field Explanation
- **Software Development Assessment** (`Software Development Assessment`, `text`, required: false): This is the title of the form, which should be filled in with a brief description of the software development project.
- **Assessment Description** (`assessment_description`, `text`, required: false): This field is used to provide a detailed description of the software development project.
- **Software Description** (`software_description`, `text`, required: false): This field is used to describe the software itself, including its purpose and functionality.
- **Software Development Assessment Date** (`software_development_assessment_date`, `date`, required: false): This field should be filled in with the date of the software development assessment, in the format "YYYY-MM-DD".
- **Software Development Assessment Time** (`software_development_assessment_time`, `time`, required: false): This field is used to note the time at which the software development assessment was conducted, in the format "HH:MM".
- **Software Version** (`software_version`, `text`, required: false): This field is used to track the version of the software being assessed.
- **Software Development Assessment Status** (`software_development_assessment_status`, `select_one`, required: false): This field is used to report the status of the software development project, with options:
	+ Published
	+ Under Development
	+ Retired
- **Software Development Assessment Notes** (`software_development_assessment_notes`, `note`, required: false): This is an optional field for adding any additional notes or comments about the software development project.
- **Software Development Assessment Email** (`software_development_assessment_email`, `email`, required: false): This field is used to enter a contact email associated with the software development project.
- **Software Development Assessment Phone** (`software_development_assessment_phone`, `text`, required: false): This field is used to enter a contact phone number associated with the software development project.
- **Contact Name** (`contact_name`, `text`, required: false): This field is used to enter the name of the contact person associated with the software development project.
