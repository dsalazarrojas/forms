# Upholstery Service Request - Help Guide
## Purpose
The Upholstery Service Request form is designed to collect information from customers for upholstery services. This form helps the team to understand the customer's needs and provide the best possible service.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the required fields with the customer's information.
2. Select the relevant service type from the options provided.
3. Add any additional details about the customer's request in the "Furniture Description" field.
4. Choose the schedule date for the service.
5. Add any follow-up information in the "Follow-up" field.
6. Assign the request to a team member.
7. Add any customer notes and team notes if required.

## Field-by-Field Explanation
* **Customer Name** (`customer_name`, Text, optional): This is where you'll enter the customer's name.
* **Email** (`email`, Text, optional): This is where you'll enter the customer's email address.
* **Phone** (`phone`, Text, optional): This is where you'll enter the customer's phone number.
* **Service Type** (`service_type`, Select One, optional): Choose the type of service the customer requires: Upholstery, Repair, or Reupholstery.
* **Furniture Description** (`furniture_description`, Text, optional): Add any additional details about the customer's request.
* **Schedule** (`schedule`, Date, optional): Select the date for the service.
* **Follow-up** (`follow_up`, Text, optional): Add any follow-up information.
* **Assigned To** (`assigned_to`, Select Multiple, optional): Choose the team member to assign this request to.
* **Customer Notes** (`customer_notes`, Note, optional): Add any notes for the customer.
* **Team Notes** (`team_notes`, Note, optional): Add any notes for the team member assigned to this request.

## Tips
- Make sure to double-check all fields before submitting the form.
- Use clear and concise language when filling out the form.
- Proofread your submission for errors before clicking "submit".
- If you're unsure about any field, feel free to ask for clarification.
