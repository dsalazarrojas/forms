# kitchen_task_assessment_form - Help Guide
## Purpose
This form helps assess and evaluate kitchen tasks for quality and efficiency.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the tasks in the 'select_task' field.
2. Select whether the task is being performed (yes or no).
3. If the task is being performed, provide an assessment of its importance using the 'assess_scale' field.
4. Enter any comments or feedback about the task in the 'comments' field.
5. Click on the 'submit' button to submit your assessment.

## Field-by-Field Explanation
* **Select Task**: Select whether the task is being performed ('Yes' or 'No'). This field helps identify which tasks are being done and which ones need attention.
* **Assess Scale**: If the selected task is being performed, use this scale to evaluate its importance (e.g., 1-10). This helps gauge the task's quality and priority.
* **Comments**: Enter any feedback, suggestions, or notes about the task. This field provides a space for users to elaborate on their thoughts.
* **Submit**: Clicking this button submits your assessment for review. 

## Tips
- Ensure you complete all required fields before submitting the form. 
- Select 'No' for tasks that do not apply to the current context.
- Use clear and concise language when providing comments or feedback. 

The submit button is a placeholder to indicate the last action to be performed by the user. Since all other fields have specific labels that explain their purpose and context, it can be safely removed.
