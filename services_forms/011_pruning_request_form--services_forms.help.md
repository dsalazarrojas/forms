# Pruning Request Form - Help Guide
## Purpose
The Pruning Request Form is designed to collect information from users for pruning-related requests.

## How To Complete This Form
To complete this form, follow these steps:
1. Provide your Date of interest.
2. Specify the Time of your request.
3. Add any additional notes or comments.
4. If you have an email address, please provide it for follow-up.
5. If you have a phone number, please add it for faster communication.
6. If applicable, select the desired Option from the select-one field.
7. If applicable, select any relevant Options from the select-multiple field.

## Field-by-Field Explanation
- **Date** (Date, required): Enter the date you are interested in for pruning.

- **Note** (Note, optional): Add any additional notes or comments about your pruning needs.
- **Email** (Email, optional): If you want to be contacted, please provide your email address.
- **Phone Number** (Phone Number, optional): If you want to be contacted by phone, please add your phone number.
