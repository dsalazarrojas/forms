# Pool Chemicals Check Form - Help Guide
## Purpose
The Pool Chemicals Check Form is used to record the status of pool chemicals and gather information about the pool's chemical condition.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the pool's current condition with either "Yes" or "No" as to whether the pool has chemicals.
* Select either "Yes" or "No" for the current state of recommended products.
* Enter any relevant water test results in the text field.
* Enter any additional comments about the pool's chemical condition.

## Field-by-Field Explanation
* **Chemicals**: Check the box if the pool has chemicals. If the pool does not have chemicals, leave this field blank.
* **Chemicals (Select One)**: Select "Yes" if recommended products are suggested for the pool.
* **Water Test Results**: Enter any relevant results from water tests performed on the pool.
* **Recommended Products**: Select "Yes" if the pool operator recommends any products based on the current chemical condition.
* **Additional Comments**: Enter any additional comments or notes about the pool's chemical condition.

## Tips
* Make sure to check the pool's chemicals regularly to ensure the pool's water quality.
* Use this form to track the pool's chemical condition over time.
* If you have any questions or concerns about the pool's chemical condition, contact your supervisor or pool maintenance personnel.
