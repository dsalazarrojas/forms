# New Hardware Request - Help Guide
## Purpose
This form is used to request new hardware for various purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide your user details in the "User Details" fields. This includes information that helps us know who the hardware is for.
2.  Select the specific parts that are damaged and need replacement. Please choose the parts that are out of order.
3.  Select the new parts you need.
4.  Add any additional notes about the request if you have any specific requirements.
5.  Provide your contact information by entering your email address or phone number.
6.  Choose the tool to be assigned to the user, if applicable.
7.  Finally, submit your request by clicking the "Submit" button.

## Field-by-Field Explanation

* **User Details**: This field is used to enter the name and other relevant details of the user who needs the new hardware.
* **Damaged Parts**: Select the parts that are currently damaged or not working properly. Please choose one or more of the following options: "damaged part 1", "damaged part 2", or "damaged part 3".
* **New Parts**: Choose the new parts you need for replacement. Select one or more of the following options: "new part 1", "new part 2", or "new part 3".
* **Notes**: If you have any additional information or specific requirements for the new hardware, enter them in the "Notes" field.
* **Email**: This field is used to enter the email address of the user who needs the new hardware.
* **Phone**: Enter the phone number of the user who needs the new hardware.
* **Assigned Tool**: This field is used to assign a tool to the user. Please select one of the following options: "chatjimmy" or "chat jimmy 123".
*   **Assigned Tool**: This is a duplicate field, please select one of the following options: "chatjimmy" or "chat jimmy 123".
*   **Submit**: This is the button to submit your request. Please make sure you have filled out all the required fields before clicking the submit button.

## Tips
*   Please make sure to fill out all required fields before submitting your request.
*   If you have any questions or concerns, do not hesitate to contact us.
*   Our team will review and process your request as soon as possible.
