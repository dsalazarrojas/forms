# Tree Trimming Request Form - Help Guide
## Purpose

The Tree Trimming Request Form is used by clients to request tree trimming services from our team. This form provides a clear and structured way to collect the necessary information for the service team to perform the tasks efficiently and effectively.

## How To Complete This Form

1. Please fill in the **Tree Trimming Request Form Title** field with a clear and concise description of the request.
2. In the **Client** field, enter the name of the client making the request.
3. Select a **Request Date** for the service using the calendar icon.
4. If applicable, enter the estimated **Tree Height** of the tree.
5. Indicate if the tree is a **Tree Species** that requires special handling by selecting 'Yes' or 'No'.
6. Enter the location of the tree in the **Tree Location** field.
7. Provide any additional contact details in the **Contact Details** field.
8. If required, add any **Additional Info** about the service request.

## Field-by-Field Explanation

* **Tree Trimming Request Form Title**:
	+ (text, required/optional): This field is used to provide a clear and concise title for the service request.
* **Client**:
	+ (text, required): Enter the name of the client making the request.
* **Request Date**:
	+ (date, required): Select a date for the service using the calendar icon.
* **Tree Height**:
	+ (number, optional): If applicable, enter the estimated height of the tree.
* **Tree Species**:
	+ (select_one, required): Select 'Yes' if the tree species requires special handling, otherwise 'No'.
* **Tree Location**:
	+ (text, optional): Enter the location of the tree.
* **Contact Details**:
	+ (text, optional): Provide any additional contact details.
* **Additional Info**:
	+ (text, optional): If required, add any additional information about the service request.

## Tips

* Please ensure that the form is filled out correctly and thoroughly to avoid delays in processing.
* Review your request before submitting to ensure it is accurate.
* Do not submit multiple times, as this will cause delays and may lead to duplicate or conflicting entries.
