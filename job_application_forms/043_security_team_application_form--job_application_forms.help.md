# Security Team Application Form - Help Guide
## Purpose
The Security Team Application Form is designed to collect information from potential candidates who are applying to join the security team. Please fill out this form to provide accurate and complete information about yourself.

## How To Complete This Form
1. **Read each field carefully** before entering any information.
2. **Fill out the form in order** (pages 1-10).
3. **Enter accurate and relevant information** in each field.
4. **Use the provided hints** to help guide you through the process.
5. **Submit the form when complete**.

## Field-by-Field Explanation
### <label> (Page 1: Candidate name) (Required: False)
* **Candidate name**: Please enter your full name as it appears on your official documents.

### <label> (Page 1: Candidate address) (Required: False)
* **Candidate address**: Enter your current address to help us verify your identity.

### <label> (Page 1: Security clearance level) (Required: False)
* **Security clearance level**: Select one of the following options: Level 1, Level 2, or Level 3. If you have a different level, please select "Other" and provide a brief explanation.

### <label> (Page 2: Security clearance level (other)) (Required: False)
* **Explain security clearance level**: Briefly explain your security clearance level, if different from the standard options.

### <label> (Page 2: Security clearance type) (Required: False)
* **Security clearance type**: Select one of the following options: Type 1, Type 2, or Type 3. If you have a different type, please select "Other" and provide a brief explanation.

### <label> (Page 2: Security clearance type (other)) (Required: False)
* **Explain security clearance type**: Briefly explain your security clearance type, if different from the standard options.

### <label> (Page 3: Security question 1) (Required: False)
* **Security question 1**: Select all that apply from the following options: Option 1, Option 2, Option 3.

### <label> (Page 3: Security question 2) (Required: False)
* **Security question 2**: Select all that apply from the following options: Option 4, Option 5, Option 6.

## Tips
* **Double-check your information** before submitting the form.
* **Use clear and concise language** when explaining security clearance level and type.
* **Be thorough and accurate** in completing all fields.
