# Student Assistant Application Form - Help Guide
## Purpose
The Student Assistant Application Form is used to gather information from students applying for job positions within the institution. This form helps to streamline the hiring process by capturing relevant details and reducing duplication of efforts.

## How To Complete This Form
1. Select the category that best represents the job you are applying for (e.g., Academic, Administrative, Technical).
2. Choose the subcategory that corresponds to your desired position (e.g., Administration, Recruitment, Selection).
3. Select the job type that aligns with your availability (e.g., Part-time, Full-time, Intern).
4. Enter the job title that you are applying for (e.g., Student Assistant, Tutor, Research Assistant).
5. Indicate the location where you would like to work (e.g., On-campus, Off-campus, Flexible).
6. Enter the job application deadline and employment start date (if applicable).
7. If necessary, enter the employment end date.
8. Specify the hours you are willing to work per week.
9. Enter any additional work details, if required.
