# Front End Engineer Application Form - Help Guide
## Purpose
This form is designed to collect information from candidates who are applying for a Front End Engineer position in our company. Completing this form will help us understand your experience, skills, and qualifications, and will aid in the assessment of your eligibility for the position.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the correct answer for each field, and make sure to check the boxes next to each option that applies to you.
2. Provide accurate and detailed answers in the text fields, and attach your resume if required.
3. Review each field carefully before submitting the form to ensure that you have provided all the necessary information.

## Field-by-Field Explanation
* **Job Application Form** (`job_application_form`, select_multiple, required/optional: No): Select 'Yes' if you are applying for a job, 'No' otherwise.
* **Work experience** (`work_experience`, text, optional): This field is for you to describe your previous work experience, including the company, position, and duration.
* **Portfolio links** (`portfolio_links`, text, optional): If you have a portfolio or website that showcases your work, please provide the link here.
* **Candidate info** (`candidate_info`, select_one, optional): Select 'Yes' if you are a candidate, 'No' otherwise.
* **Resume** (`resume`, text, optional): If your resume is not attached, please attach it here.
* **Job position** (`job_position`, text, optional): This field is for you to describe the job position you are applying for.
* **Employment status** (`employment_status`, select_multiple, optional): Select 'Active' if you are currently employed, 'Inactive' if you are not.
* **Submit** (`submit`, text, optional): This field is for you to confirm that you have completed and reviewed the form accurately. Please make sure to proofread carefully before submitting.
