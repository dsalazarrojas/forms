## Media Editor Interview Form - Help Guide

## Purpose
This form is used to collect information from media editors for the purpose of evaluating their qualifications and suitability for a role. The form is designed to gather details about the editor's media editing experience, ideal work environment, and other relevant factors.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Review the form carefully to ensure you are answering the questions in the correct manner.
2. For each field, provide as much detail as possible to ensure accurate and thorough evaluation.

## Field-by-Field Explanation

* **Media Editor Application** (1): A brief description of your media editing experience and qualifications.
* **Teams** (2): Select all the creative teams you have worked with. You can choose multiple teams by holding down the Ctrl key (Windows) or Command key (Mac).
* **Agencies** (3): Select all the agencies you have worked with. You can choose multiple agencies by holding down the Ctrl key (Windows) or Command key (Mac).
* **Ideal For** (4): Select the type of environment you are most suited for. This could be a creative team or an agency. 
* **Consistent Candidate Screening** (5): Check if you have undergone consistent candidate screening. If you have not, please provide more information on how you usually screen candidates.
* **Organized Data Collection** (6): Check if you organize data collection for your media editing projects. If not, provide more details on how you usually collect data.
* **Jotform** (7): Check if you have used Jotform for any media editing projects. If not, please provide information on other tools you have used.
* **Media Editor Application Description** (8): A brief description of your media editing application and experience.
* **Media Type** (9): Select the type of media you have experience with, such as image or video editing.
* **Media Length** (10): If applicable, provide the length of the media you have edited.
* **Media Size** (11): If applicable, provide the size of the media you have edited.

## Tips
- Please answer each field as accurately and thoroughly as possible.
- If you are unsure about any field, please provide more details in the description field.
- If you have any questions or concerns, please contact your HR representative for assistance.
