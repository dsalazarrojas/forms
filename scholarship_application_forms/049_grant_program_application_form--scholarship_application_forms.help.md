# grant_program_application_form - Help Guide
## Purpose
The grant program application form is used to collect and manage information related to grant programs, including grant amounts, applicant contact information, and terms and conditions of the grant.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk (\*), which includes:
   - Grant Program Application (Page 1)
   - Grant Amount (Page 2)
   - Applicant Name (Page 3)
   - Applicant Contact (Page 4)
   - Email (Page 5)
   - Phone (Page 6)
   - Address (Page 7)
   - Grant Description (Page 8)
   - Purpose (Page 9)
   - Grant Date (Page 10)
   - Grant Time (Page 11)
   - Application Date (Page 12)

2. If you are applying for multiple grant programs, select the relevant options for each page (Page 13-14).

3. If you want to add any additional comments or notes, use the "Grant Program Note" and "Grant Program Comment" fields on Page 15-16.

4. Finally, review and submit the form.

## Field-by-Field Explanation
### Page 1: Grant Program Application
* **Grant Program Application** (`grant_program_application`, text, required): Enter a brief description of the grant program you are applying for.
* **Grant Amount** (`grant_amount`, number, required): Enter the grant amount you are applying for.
* **Grant Description** (`grant_description`, text, required): Enter a brief description of the grant program you are applying for.
* **Purpose** (`purpose`, text, required): Enter a brief description of the purpose of the grant.
* **Grant Date** (`grant_date`, date, required): Enter the date of the grant.
* **Grant Time** (`grant_time`, time, required): Enter the time of the grant.

### Page 2: Applicant Contact Information
* **Applicant Name** (`applicant_name`, text, required): Enter your name.
* **Applicant Contact** (`applicant_contact`, text, required): Enter your contact information.
* **Email** (`email`, email, required): Enter your email address.
* **Phone** (`phone`, text, required): Enter your phone number.
* **Address** (`address`, text, required): Enter your address.

### Page 3: Grant Program Selection
* **Selected Grant Program** (`selected_grant_program`, select_one, required): Select the relevant grant program from the options provided.
* **Multiple Grant Programs** (`multiple_grant_programs`, select_multiple, required): Select multiple relevant grant programs from the options provided.

### Page 4-5: Notes and Comments
* **Grant Program Note** (`grant_program_note`, text, note): Enter any additional comments or notes regarding the grant program.
* **Grant Program Comment** (`grant_program_comment`, text, note): Enter any additional comments or notes regarding the grant program.

### Page 6-7: Grant Program Details
* **Grant Program Reference** (`grant_program_reference`, text, required): Enter any relevant information about the grant program.
* **Grant Program Agreement** (`grant_program_agreement`, number, required): Enter any relevant information about the grant program agreement.
* **Grant Program Terms** (`grant_program_terms`, text, required): Enter any relevant terms and conditions of the grant program.
* **Grant Program Conditions** (`grant_program_conditions`, text, required): Enter any relevant conditions of the grant program.
* **Grant Program Acknowledgement** (`grant_program_acknowledgement`, text, required): Enter any acknowledgement of the grant program.
* **Grant Program Disclaimer** (`grant_program_disclaimer`, text, required): Enter any disclaimer of the grant program.
* **Grant Program Declaration** (`grant_program_declaration`, text, required): Enter any declaration of the grant program.
* **Grant Program Certfication** (`grant_program_certification`, text, required): Enter any certification of the grant program.
* **Grant Program Agreement Date** (`grant_program_agreement_date`, date, required): Enter the date of the grant program agreement.

### Tip: Make sure to carefully review all fields before submitting the form to ensure accurate and complete information.
