# Single Parent Grant Application - Help Guide
## Purpose

The Single Parent Grant Application form is used to help single parents apply for financial assistance or support to aid with their child's needs. This form requires information about the applicant's name, address, grant amount, grant type, grant status, application date, organization name, and organization address.

## How To Complete This Form

1. Fill out the form with the required information.
2. Make sure to fill out all fields accurately and completely.
3. If a field is not required, you can leave it blank.
4. Review the form for any errors before submitting.

## Field-by-Field Explanation

* **Name** (id: 2, label: Name, type: text, required: false)
	+ This field is for the single parent's name.
* **Address** (id: 3, label: Address, type: text, required: false)
	+ This field is for the single parent's address.
* **Grant Amount** (id: 4, label: Grant Amount, type: number, required: false)
	+ This field is for the amount of money the single parent is requesting for the grant.
* **Grant Type** (id: 5, label: Grant Type, type: select_one, required: false)
	+ This field is for the type of grant the single parent is applying for (financial assistance or support funding).
* **Grant Status** (id: 6, label: Grant Status, type: select_multiple, required: false)
	+ This field is for the current status of the grant (pending, approved, or declined).
* **Single Parent Grant Application Date** (id: 7, label: Single Parent Grant Application Date, type: date, required: false)
	+ This field is for the date the grant application was submitted.
* **Organization Name** (id: 8, label: Organization Name, type: text, required: false)
	+ This field is for the name of the organization that the single parent is applying to or working with.
* **Organization Address** (id: 9, label: Organization Address, type: text, required: false)
	+ This field is for the address of the organization that the single parent is applying to or working with.

## Tips

* Please make sure to double-check your answers for accuracy.
* If you are unsure about any field, you can contact our office for clarification.
* We will review your application form and contact you if we need more information.
