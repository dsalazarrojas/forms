# Scholarship Program Expansion Request Form - Help Guide
## Purpose
This form is designed to help stakeholders request an expansion of an existing scholarship program.

## How To Complete This Form
This form is divided into several sections. Please complete it in order from top to bottom, and make sure to review each field carefully.

1. **Program Name** (`program_name`, text, optional): Please enter the name of the scholarship program you wish to expand.
2. **Program Type** (`program_type`, select_one, optional): Choose the type of program you are requesting to expand (e.g., Type 1, Type 2, Type 3).
3. **Stakeholder Name** (`stakeholder_name`, text, optional): Enter your name and title/position in the organization or institution associated with the program.
4. **Stakeholder Organization** (`stakeholder_organization`, text, optional): Enter the name of your organization or institution.
5. **Program Description** (`program_description`, text, optional): Briefly describe the current state and goals of the program you wish to expand.
6. **Expansion Reason** (`expansion_reason`, text, optional): Provide a clear and concise explanation for the expansion request, including any new opportunities for growth.
7. **Expansion Budget** (`expansion_budget`, number, optional): Enter an estimated budget for the expansion (if applicable).
8. **Expansion Timeline** (`expansion_timeline`, date, optional): Provide a proposed timeline for the expansion (e.g., start date and end date).
9. **Submitted By** (`submitted_by`, text, optional): Please enter your name and title/position, as the person responsible for submitting this request.

## Field-by-Field Explanation
* **Program Name**: This is the name of the scholarship program you are requesting to expand.
* **Program Type**: This field helps us understand the type of program you are expanding, which aids in our evaluation process.
* **Stakeholder Name**: Please ensure you include your name and title/position to help us understand your role and affiliation with the program.
* **Stakeholder Organization**: Provide the name of your organization or institution associated with the program.
* **Program Description**: This field helps us understand the current state and goals of the program, which aids in our evaluation and decision-making process.
* **Expansion Reason**: This is a crucial field that requires a clear and concise explanation for the expansion request, including any new opportunities for growth.
* **Expansion Budget**: If applicable, please estimate the budget required for the expansion.
* **Expansion Timeline**: Enter a proposed timeline for the expansion, including start and end dates.
* **Submitted By**: This field is a formal acknowledgement of who is submitting this request.

## Tips
- Make sure to review each field carefully before submitting.
- If you are unsure or have questions, please contact us for guidance.
- This form should not be used for minor adjustments or routine requests.
