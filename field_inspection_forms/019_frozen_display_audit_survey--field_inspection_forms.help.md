# Frozen Display Audit Survey - Help Guide
## Purpose
The Frozen Display Audit Survey is a tool used by store managers and inventory control personnel to audit and evaluate the condition of frozen display cases in store shelves.

## How To Complete This Form
- Please select the correct store where you would like to conduct the audit.
- Choose the correct options for each field based on the store's frozen display case conditions.
- Ensure you provide accurate and truthful information for each field.

## Field-by-Field Explanation
- **Store**: Please enter the store's name or identifier where you are conducting the audit.
- **Frozen Cabinet**: Select 'Yes' if the frozen display case is present, 'No' otherwise.
- **Frozen Shelves**: Enter the number of shelves in the frozen display case.
- **Temperature Controller**: Select the correct option based on the presence and functionality of the temperature controller, i.e., 'Temperature Control', 'No Temperature Control', or 'Unknown'.
- **Freezer Doors**: Select 'Yes' if the freezer doors are present and functional, 'No' otherwise.
- **Freezer Compartments**: Select 'Yes' if the freezer case has compartments, 'No' otherwise.
- **Store Manager**: Enter the email of the store manager (optional, but recommended for follow-up communication).
 

## Tips
- Please ensure you are providing accurate and truthful information for each field.
- If you're unsure about any field, please contact your inventory control team for guidance.
- If you have already conducted a survey for this store, do not fill the form again.
