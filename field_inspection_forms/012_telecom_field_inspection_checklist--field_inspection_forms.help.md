# Telecom Field Inspection Checklist - Help Guide
## Purpose
The Telecom Field Inspection Checklist form is a data collection tool used to gather information on the condition and status of various telecommunications equipment and locations during field inspections.

## How To Complete This Form
1. Select the location to be inspected.
2. Select the inspector who conducted the inspection.
3. Enter the date of the inspection.
4. Check if issues were found during the inspection and provide a description of the issues.
5. Indicate the priority of the issue(s) found.
6. Enter the action planned for resolution.
7. Enter the action taken for the issue(s) found.
8. Enter any additional notes related to the inspection.
9. Enter the location notes (if applicable).
10. Select if the issue is active or inactive.
11. Indicate if the issue is a type of problem (e.g., hardware, software).
12. Select if the issue requires urgency.
13. Select if the issue is a priority issue.
14. Enter the inspection date.
15. Enter the inspection time.
16. Select the type of location being inspected.
17. Select the status of the location.
18. Enter the equipment ID.
19. Enter the type of equipment.
20. Select if the equipment is in good condition.
21. Enter the location of the equipment.
22. Enter any inspection notes.
23. Select if photos were taken during the inspection.
24. Select if videos were taken during the inspection.

## Field-by-Field Explanation

* **location_id** (Number): Enter the ID of the location being inspected.
* **inspector id** (Select One): Select the ID of the inspector who conducted the inspection.
* **date** (Date): Enter the date of the inspection in the format mm/dd/yyyy.
* **issues found** (Select Multiple): Check if issues were found during the inspection and select the corresponding issues. If no issues were found, select "No".
* **priority** (Select One): Select the priority of the issue(s) found. This will help in prioritizing the resolution of the issue.
* **issue description** (Text): Enter a detailed description of the issue(s) found.
* **action planned** (Text): Enter the action planned for resolution of the issue.
* **action taken** (Text): Enter the action taken for the issue(s) found.
* **notes** (Text): Enter any additional notes related to the inspection.
* **location notes** (Text): Enter any notes related to the location being inspected (if applicable).
* **issue status** (Select One): Select if the issue is active or inactive.
* **issue type** (Select One): Indicate if the issue is a type of problem (e.g., hardware, software).
* **urgency** (Select One): Select if the issue requires urgency.
* **issue priority** (Select One): Select if the issue is a priority issue.
* **inspection date** (Date): Enter the date of the inspection in the format mm/dd/yyyy.
* **inspection time** (Time): Enter the time of the inspection in the format hh:mm AM/PM.
* **location type** (Select One): Select the type of location being inspected.
* **location status** (Select One): Select the status of the location.
* **equipment id** (Text): Enter the ID of the equipment being inspected.
* **equipment type** (Text): Enter the type of equipment being inspected.
* **equipment condition** (Select One): Select if the equipment is in good condition.
* **equipment location** (Text): Enter the location of the equipment.
* **inspection notes** (Text): Enter any notes related to the inspection.
* **photos** (Select Multiple): Select if photos were taken during the inspection.
* **videos** (Select Multiple): Select if videos were taken during the inspection.

Note: Please ensure that all required fields are completed to ensure accurate and comprehensive data collection.
