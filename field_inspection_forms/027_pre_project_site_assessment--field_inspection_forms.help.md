# Pre Project Site Assessment - Help Guide
## Purpose
The Pre-Project Site Assessment form is used to collect essential site-specific information before commencing a project. It helps project managers and site supervisors identify potential hazards, environmental concerns, and logistical challenges that may affect the project's success.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question truthfully and thoroughly.
2. For each section, provide details that accurately reflect the site's current state.
3. When unsure about a particular question, use your best judgment or research if needed.

## Field-by-Field Explanation
* **Site Details**
Site Details is a text field where you can enter relevant site information such as address, project location, and surrounding environment.
* **Site Access Instructions**
Please provide clear and concise instructions for accessing the site, including entry points, parking information, and security protocols.
* **Site Access Restrictions**
Select the current access restrictions for the site. Options include "True" for restricted access or "False" for unrestricted access.
* **Safety Hazards**
Choose all safety hazards that apply from the dropdown list. Options include "True" for each hazard type such as fire risk, chemical exposure, etc.
* **Other Safety Hazards**
If there are other safety hazards not listed, enter them here in the text field.
* **Site Conditions**
Enter a description of the site's current condition, including any environmental concerns or obstacles.
* **Site Equipment**
Select the types of equipment currently on-site. Options include "True" for each equipment type such as cranes, excavators, etc.
* **Other Equipment**
If there are other equipment not listed, enter them here in the text field.
* **Weather**
Choose the current weather conditions. Please select the correct date and time.
* **Weather Conditions**
Choose the weather conditions for the site, including temperature, precipitation, etc.
* **Emergency Services**
Provide a list of emergency services available on-site, including phone numbers and contact information.
* **Emergency Contacts**
Enter the contact information for emergency services, including names and phone numbers.
* **Notes (Emergency Contacts)**
Use this text field for additional emergency contact information or notes.
