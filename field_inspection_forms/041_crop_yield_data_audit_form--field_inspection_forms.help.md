# Crop Yield Data Audit Form - Help Guide
## Purpose
This form is designed to help you inspect and report on crop yields.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form purpose and make sure you're using it for its intended use case.
2. Select the options for each field based on your inspection or assessment.
3. Enter numerical data into fields 3 and 4.

## Field-by-Field Explanation

* **section_1**: A simple yes or no question to help us understand your findings. Select 'Yes' if the yield data meets the required standards, or 'No' otherwise.
* **field_1**: A field for numerical data entry. Select a number to report the total yield quantity or value for this data point.
* **field_2**: Another field for numerical data entry. Select a number to report another data point.
* **field_3**: You may want to enter a number here to report a specific yield data point.
