# Sign Installation Site Survey Form - Help Guide
## Purpose
The Sign Installation Site Survey Form is used to collect site-specific information from customers who are requesting a sign installation service. This form helps our team evaluate the site conditions and ensure that the project is properly scoped and executed.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill in the required fields (marked as "required" in the form).
2.  Be as detailed and accurate as possible in your responses.
3.  Use the options provided for select_multiple fields to select all applicable options.
4.  If a field has multiple options, select all that apply.

## Field-by-Field Explanation

* **Sign Installation Site** (`sign_installation_site`): This field is used to collect the site address or location where the sign will be installed.
* **Site Contact Information** (`site_contact_information`): Please provide the contact information for the person responsible for the site, including their name, email, and phone number.
* **Site Description** (`site_description`): Briefly describe the site where the sign will be installed, including any relevant details or features.
* **Site Photos** (`site_photos`): Attach any relevant photos of the site to help us better understand the conditions.
* **Site Permit Requirements** (`site_permit_requirements`): If required, specify any necessary permits or approvals needed for the sign installation project.
* **Installation Schedule** (`installation_schedule`): Provide the expected installation date and time range.
* **Installation Timeframe** (`installation_timeframe`): Specify the expected installation duration in hours.
* **Site Access** (`site_access`): Choose all applicable options for the site access conditions:
	+ Option 1: Public Access
	+ Option 2: Private Access
	+ Option 3: Restricted Access
* **Electrical Power** (`electrical_power`): Choose all applicable options for the site's electrical power conditions:
	+ Option 1: On-Site Power Availability
	+ Option 2: External Power Availability
	+ Option 3: No Power Availability
* **Site Elevation** (`site_elevation`): If applicable, provide the site elevation in feet.
* **Installation Team** (`installation_team`): Choose all applicable options for the installation team composition:
	+ Option 1: On-Site Team
	+ Option 2: Off-Site Team
	+ Option 3: Hybrid Team
* **Site Inspections** (`site_inspections`): Choose all applicable options for the site inspection requirements:
	+ Option 1: Pre-Installation Inspection
	+ Option 2: Post-Installation Inspection
	+ Option 3: Continuous Inspection
* **Site Weather** (`site_weather`): Choose all applicable options for the site weather conditions:
	+ Option 1: Sunny
	+ Option 2: Overcast
	+ Option 3: Rainy
* **Site Notes** (`site_notes`): Provide any additional notes or comments about the site conditions.

Note: Please refer back to the form for specific field labels and options.
