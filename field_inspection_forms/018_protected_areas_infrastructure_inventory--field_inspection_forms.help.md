# Protected Areas Infrastructure Inventory - Help Guide
## Purpose
The purpose of this form is to collect and record information about the infrastructure within protected areas such as parks, conservation areas, or other protected environments.

## How To Complete This Form
1. Select the category of the protected area you are inventorying from the "Category" dropdown menu. If the protected area does not fit into the provided categories, select "Other".
2. Provide a brief description of the protected area infrastructure you are inventorying in the "Description" field.
3. Enter the location of the infrastructure within the protected area in the "Location" field.
4. Select the type of asset being inventoryed from the "Asset Type" dropdown menu. If the asset type is not listed, select "Other".
5. Indicate the condition of the asset by selecting from the "Condition" dropdown menu. If the asset is in good condition, select "Good". If the asset is in fair condition, select "Fair". If the asset is in poor condition, select "Poor".
6. If applicable, enter the number of photos you have taken of the asset in the "Photo Count" field.
7. If applicable, provide a description of the photos you have taken in the "Photo Description" field.

## Field-by-Field Explanation
* **Protected Area Category**: Choose the category of protected area you are inventorying, such as "Field Inspection Forms" or "Other".
* **Description**: Enter a brief description of the protected area infrastructure, including the name, location, and any distinguishing features.
* **Location**: Enter the exact location of the protected area, including the name of the park, conservation area, or other protected environment.
* **Asset Type**: Select the type of asset being inventoryed, such as a "Infrastructure".
* **Condition**: Select the current condition of the asset, such as "Good", "Fair", or "Poor".
* **Photo Count**: Enter the number of photos you have taken of the asset, if applicable.
* **Photo Description**: Provide a description of the photos you have taken, including the date and time taken, and any other relevant details.
