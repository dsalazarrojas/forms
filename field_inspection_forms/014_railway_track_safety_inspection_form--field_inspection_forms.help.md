# Railway Track Safety Inspection Form - Help Guide

## Purpose
This form is used for safety inspections of railway tracks to document findings and status of the railway track's safety inspection.

## How To Complete This Form
To complete this form, fill out each field as instructed below.

## Field-by-Field Explanation
- **Railway Track Safety Inspection Form**: This is the main form title.
- **track-geometry**: Choose the geometry of the railway track from the options provided.
- **track-surface**: Select all applicable options to describe the track's surface condition.
- **track-signs**: Select all applicable options to describe track signs condition.
- **inspection-date**: Date when the safety inspection was performed.
- **safety-certificate**: Choose the status of the safety certificate.
- **inspector-name**: Enter the name of the inspector who performed the inspection.
- **comments**: Enter any additional comments or observations about the inspection.
- **contact-number**: Enter the contact number for the inspector.
- **email**: Enter the email address of the inspector.
- **asset-id**: Enter the asset ID number for the railway track.
- **railway-track-condition**: Select all applicable options to describe the track's overall condition.
- **track-geometry-condition**: Select all applicable options to describe the track's geometry condition.
- **track-geometry-measurements**: Select the option that describes the track's geometry measurement.
- **track-safety-inspection-form-status**: Choose the status of the safety inspection form from the options provided.

## Tips
- Make sure to review the form carefully before submission to ensure all fields are completed accurately.
- Select all applicable options for each field to provide a detailed description of the track's condition.
- Enter correct contact information to ensure the inspector can be reached for further inquiries.
