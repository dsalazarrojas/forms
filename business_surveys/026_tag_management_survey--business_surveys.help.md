# Tag Management Survey - Help Guide
## Purpose
The Tag Management Survey form is used to collect and manage information about tags in a structured and organized manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the introduction page, which provides background information about the form.
2. Fill out the form pages with the required information, starting from the "tag_name" page.
3. On the "tag_type" page, select the appropriate tag type from the list of options.
4. On the "tag_status" page, select all applicable tag status options that apply to the tag.
5. On the "tag_description" page, enter a brief description of the tag.
6. On the "tag_category" page, select the category of the tag from the list of options.
7. On the "tag_subcategory" page, enter the subcategory of the tag.
8. On the "tag_priority" page, enter the priority level of the tag.
9. On the "tag_value" page, enter the value of the tag.
10. On the "tag_tags" page, select all applicable tags that apply to the tag.
11. On the "tag_tagged_by" page, enter the person who tagged the item.
12. On the "tag_date_tagged" page, enter the date when the tag was tagged.
13. On the "tag_date_added" page, enter the date when the tag was added.

## Field-by-Field Explanation

* **tag_name** (text, required): Enter the name of the tag. 
* **tag_type** (select_one, required): Select the type of the tag from the list of options (Tag A, Tag B, Tag C).
* **tag_status** (select_multiple, required): Select all applicable status options that apply to the tag (Active, Inactive, Pending).
* **tag_description** (text, required): Enter a brief description of the tag.
* **tag_category** (select_one, required): Select the category of the tag from the list of options (Category A, Category B, Category C).
* **tag_subcategory** (text, required): Enter the subcategory of the tag.
* **tag_priority** (number, required): Enter the priority level of the tag.
* **tag_value** (number, required): Enter the value of the tag.
* **tag_tags** (select_multiple, required): Select all applicable tags that apply to the tag (Tag 1, Tag 2, Tag 3).
* **tag_tagged_by** (text, required): Enter the person who tagged the item.
* **tag_date_tagged** (date, required): Enter the date when the tag was tagged.
* **tag_date_added** (date, required): Enter the date when the tag was added.

## Tips

* Please make sure to fill out all required fields.
* Select only relevant options that apply to the tag.
* Enter accurate and complete information for each field.
* If you are unsure about any field, contact your administrator for assistance.
