# Data Transformation Progress Survey - Help Guide
## Purpose
The purpose of this form is to gather information on the progress of data transformation projects. It helps project stakeholders to evaluate the project's milestones, adoption level, feedback, and overall effectiveness.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the correct project milestone from the dropdown menu.
2. Enter the current progress percentage of the project (out of 100%).
3. Provide any feedback or comments related to the project's progress.
4. Select the adoption level of the project, indicating how well the new data transformation process is being adopted.
5. Choose a feedback rating for the project, indicating your overall satisfaction with the process.

## Field-by-Field Explanation
- **Project Milestone** (`project_milestone`, `date`, required/optional: false): Select the current project milestone from the list to ensure that the correct stage of the project is being assessed. This helps to track progress against project goals and objectives.
- **Progress Percentage** (`progress_percentage`, `number`, required/optional: false): Enter the current progress percentage of the project as a number between 0 and 100. This gives a clear indication of how far the project has progressed.
- **Feedback Comments** (`feedback_comments`, `text`, required/optional: false): Provide any comments or feedback you have about the project's progress. This helps to identify areas of improvement and successes.
- **Adoption Level** (`adoption_level`, `select_one`, required/optional: false): Select how well the new data transformation process is being adopted by the team or stakeholders. Choose from the options provided to indicate the current adoption level.
- **Adoption Option 1** (`adoption_level_option_1`, `select_one`, required/optional: false): This is one of the options for the adoption level of the project. Select this option if the adoption level is at this stage.
- **Adoption Option 2** (`adoption_level_option_2`, `select_one`, required/optional: false): This is another option for the adoption level of the project. Select this option if the adoption level is at this stage.
- **Adoption Option 3** (`adoption_level_option_3`, `select_one`, required/optional: false): This is the final option for the adoption level of the project. Select this option if the adoption level is at this stage.
- **Feedback Rating** (`feedback_rating`, `select_one`, required/optional: false): Select a feedback rating for the project, indicating your overall satisfaction with the process. Choose from the provided options to indicate your feedback.
