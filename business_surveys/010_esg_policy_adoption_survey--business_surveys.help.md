# ESG Policy Adoption Survey - Help Guide
## Purpose
The ESG Policy Adoption Survey is designed to collect information about the adoption of Environmental, Social, and Governance (ESG) policies within an organization. This information will be used to inform future decision-making and drive business growth.

## How To Complete This Form
1. Please complete all sections of the form accurately and thoroughly.
2. If you have any experience with ESG policies, please select "Yes" for the question "esg_framework".
3. If you have implemented ESG policies, please select all applicable options under "esg_implementation_status".
4. For questions with multiple options, please select all that apply.
5. If you have any additional comments or concerns, please provide them in the "esg_implementation_status_other_description" field.
6. If you are unsure of any of the questions, please answer "Undetermined" and provide an explanation in the relevant field.

## Field-by-Field Explanation
- **ESG Framework** (`esg_framework`, select_one): Select "Yes" if you have experience with ESG policies. If not, select "No".
- **ESG Framework Type** (`esg_framework_type`, select_multiple): Select all that apply if you have implemented ESG policies.
- **ESG Framework Type Option A** (`esg_framework_type_option`, text): If you have implemented ESG policies, provide more details about type A.
- **ESG Framework Type Option B** (`esg_framework_type_option_b`, text): If you have implemented ESG policies, provide more details about type B.
- **ESG Framework Type Option C** (`esg_framework_type_option_c`, text): If you have implemented ESG policies, provide more details about type C.
- **Policy Areas** (`policy_areas`, text): If you have implemented ESG policies, provide more details about the areas covered by the policies.
- **ESG Implementation Status** (`esg_implementation_status`, select_multiple): Select all that apply if you have implemented ESG policies.
- **ESG Implementation Status Yes** (`esg_implementation_status_yes`, text): If you have implemented ESG policies, provide more details about the "Yes" status.
- **ESG Implementation Status No** (`esg_implementation_status_no`, text): If you have implemented ESG policies, provide more details about the "No" status.
- **ESG Implementation Status Undetermined** (`esg_implementation_status_undetermined`, text): If you are unsure of the ESG implementation status, provide an explanation.
- **ESG Implementation Status Other** (`esg_implementation_status_other`, text): If you have implemented ESG policies, but the status is not listed, provide more details.
- **ESG Implementation Status Other Description** (`esg_implementation_status_other_description`, text): If you have implemented ESG policies, but the status is not listed, provide more details.
- **Policy Areas Details** (`policy_areas_details`, text): If you have implemented ESG policies, provide more details about the policy areas.
- **ESG Framework Type Other** (`esg_framework_type_other`, text): If you have implemented ESG policies, but the type is not listed, provide more details.
- **ESG Framework Type Other Description** (`esg_framework_type_other_description`, text): If you have implemented ESG policies, but the type is not listed, provide more details.
- **ESG Policy Adoption Date** (`esg_policy_adoption_date`, date): If you have implemented ESG policies, provide the date of adoption.
- **ESG Policy Adoption Time** (`esg_policy_adoption_time`, time): If you have implemented ESG policies, provide the time of adoption.
- **ESG Survey Response Time** (`esg_survey_response_time`, time): If you have implemented ESG policies, provide the time of your response.
- **ESG Survey Response Date** (`esg_survey_response_date`, date): If you have implemented ESG policies, provide the date of your response.
- **ESG Policy Adoption Status** (`esg_policy_adoption_status`, select_one): Select "Adopted" if ESG policies have been implemented.
- **ESG Policy Adoption Status Other** (`esg_policy_adoption_status_other`, text): If ESG policies have been implemented, but the status is not listed, provide more details.
