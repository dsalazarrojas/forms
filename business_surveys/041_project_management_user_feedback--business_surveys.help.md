# Project Management User Feedback - Help Guide
## Purpose
The "Project Management User Feedback" form is designed to collect feedback from users about projects managed by the project management team. This form will help the project management team to understand user experiences and improve the project management processes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the project in the "Form Title" field. This will help us identify the project being referred to in your feedback.
2. Provide a brief description of the project in the "Form Description" field.
3. Select the current status of the project in the "Project Status" field.
4. Enter the project start date in the "Project Start Date" field.
5. Enter the project end date in the "Project End Date" field.
6. Enter the project manager's ID in the "Project Manager Id" field.
7. Enter your user ID in the "User Id" field.
8. Provide your feedback about the project in the "User Feedback" field.
9. Rate the usability of the project management process in the "Usability Rating" field.
10. Rate your satisfaction with the project management process in the "Satisfaction Rating" field.
11. Provide any improvement suggestions for the project management process in the "Improvement Suggestions" field.
12. Add any additional comments about the project in the "Form Comments" field.
13. Upload any relevant attachments related to the project in the "Form Attachments" field.
14. Finally, select the number of submissions you have made for the project in the "Form Submissions" field.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, optional): Enter the title of the project you are providing feedback on.
* **Form Description** (`form_description`, text, optional): Briefly describe the project you are providing feedback on.
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project.
	+ Options: In Progress, Completed, Delayed, Canceled
* **Project Start Date** (`project_start_date`, date, optional): Enter the start date of the project.
* **Project End Date** (`project_end_date`, date, optional): Enter the end date of the project.
* **Project Manager Id** (`project_manager_id`, number, optional): Enter the ID of the project manager.
* **User Id** (`user_id`, number, optional): Enter your user ID.
* **User Feedback** (`user_feedback`, text, optional): Provide your feedback about the project.
* **Usability Rating** (`usability_rating`, number, optional): Rate the usability of the project management process.
* **Satisfaction Rating** (`satisfaction_rating`, number, optional): Rate your satisfaction with the project management process.
* **Improvement Suggestions** (`improvement_suggestions`, text, optional): Provide any suggestions for improvement for the project management process.
* **Form Comments** (`form_comments`, text, optional): Add any additional comments about the project.
* **Form Attachments** (`form_attachments`, select_multiple, optional):
	+ Options: Attachment 1, Attachment 2, Attachment 3
* **Form Submissions** (`form_submissions`, number, optional): Enter the number of submissions you have made for the project.

## Tips

* Make sure to provide accurate and truthful feedback about the project.
* Be as detailed and specific as possible when providing feedback and suggestions.
* Use attachments only when necessary and relevant to your feedback.
* Enter your user ID correctly to ensure your feedback is associated with your account.
* If you are unsure about any field, please ask for clarification or guidance.
