# Facility and Production Capabilities Survey - Help Guide
## Purpose

The Facility and Production Capabilities Survey is designed to gather information on facility and production-related data to inform business decisions and improve operational efficiency.

## How To Complete This Form

1. Review the form carefully to ensure you understand each field's purpose and requirements.
2. Complete all required fields to the best of your ability.
3. Be accurate and concise in your responses.
4. If you have any questions or concerns, please don't hesitate to reach out to your supervisor or support team.

## Field-by-Field Explanation

### Page 1 - Facility and Production Capabilities Survey

* **Facility and Production Capabilities Survey** (`title`, `text`, not required): A brief description of the facility and production capabilities.
* **Facility Name** (`facility_name`, `text`, not required): The name of the facility.
* **Location** (`location`, `text`, not required): The location of the facility.
* **Facility Capacity** (`facility_capacity`, `number`, not required): The facility's capacity, expressed as a numerical value.
* **Production Capacity** (`production_capacity`, `number`, not required): The production capacity, also expressed as a numerical value.
* **Production Capacity Unit** (`production_capacity_unit`, `select_one`, not required): The unit of measurement for the production capacity.
	+ Select from: Unit, Piece, Lot
* **Facility Contact** (`facility_contact`, `text`, not required): The contact person for the facility.
* **Facility Email** (`facility_email`, `email`, not required): The facility's email address.
* **Facility Phone** (`facility_phone`, `text`, not required): The facility's phone number.
* **Facility Website** (`facility_website`, `text`, not required): The facility's website.
* **Facility Hours** (`facility_hours`, `time`, not required): The facility's operating hours.
* **Facility Notes** (`facility_notes`, `note`, not required): Additional notes about the facility.
* **Facility Address** (`facility_address`, `text`, not required): The facility's address.
* **Facility Type** (`facility_type`, `text`, not required): The type of facility.

### Page 2 - Facility and Production Capabilities Survey

* **Subcontractors** (`facility_subcontractors`, `select_multiple`, not required): The facility's subcontractors.
	+ Select from: Option 1, Option 2, Option 3
* **Production Process** (`production_process`, `text`, not required): The production process used by the facility.
* **Facility Equipment** (`facility_equipment`, `text`, not required): The equipment used by the facility.
* **Facility Employees** (`facility_employees`, `number`, not required): The number of employees at the facility.
* **Facility Capacity Status** (`facility_capacity_status`, `select_one`, not required): The current facility capacity status.
	+ Select from: Option 1, Option 2, Option 3
* **Facility Capacity Last Updated** (`facility_capacity_last_updated`, `date`, not required): The last date the facility capacity was updated.
* **Facility Capacity Last Updated Time** (`facility_capacity_last_updated_time`, `time`, not required): The last time the facility capacity was updated.
* **Facility Capacity Last Updated By** (`facility_capacity_last_updated_by`, `text`, not required): The person who last updated the facility capacity.

### Page 3 - Facility and Production Capabilities Survey

* **Production Capacity Status** (`production_capacity_status`, `select_one`, not required): The current production capacity status.
	+ Select from: Option 1, Option 2, Option 3
* **Production Capacity Notes** (`production_capacity_notes`, `note`, not required): Additional notes about production capacity.
* **Facility Capacity Notes** (`facility_capacity_notes`, `note`, not required): Additional notes about facility capacity.
* **Facility Capacity Last Updated By** (`facility_capacity_last_updated_by`, `text`, not required): The person who last updated the facility capacity.

Note: The form consists of three pages, with each page containing a few fields. Please refer to each page's fields individually for specific details.
