# Flooring Cleaning Chemical Survey - Help Guide
## Purpose
The "flooring_cleaning_chemical_survey" form is designed to gather information about the flooring cleaning process, focusing on the types of chemicals used, satisfaction, issues, and condition of the flooring.
## How To Complete This Form
To complete this form, follow these steps:
1. Answer each question carefully and honestly.
2. Select the relevant options from the provided lists for each field.
3. Ensure that you complete the form only once for each flooring area.

## Field-by-Field Explanation

* **Flooring Types**: Describe the type of flooring in the area being surveyed.
* **Chemical Used**: Select the type of chemical used for cleaning from the options provided.
* **Satisfaction**: Rate your satisfaction with the current cleaning process, using the number field to input your score.
* **Issues**: List any issues or problems encountered during the cleaning process. Select multiple issues from the options provided, as needed.
* **Maintenance**: Provide a brief description of the decision made for maintenance, if applicable.
* **Flooring Condition**: Rate the condition of the flooring from the options provided.
* **Facility Manager**: Enter the name of the facility manager responsible for maintenance and cleaning.
* **Cleaning Team**: Enter the name of the cleaning team responsible for the area.
Note: All fields are optional, so only enter information if you have relevant details to provide.
