# Customer Churn Survey - Help Guide
## Purpose
The customer churn survey is designed to gather information about customers who have left or are about to leave your business. This survey helps identify the reasons behind customer churn and provides valuable insights to improve customer relationships and retention.

## How To Complete This Form
1. Ensure you have all the required information and answers prepared before filling out the survey.
2. Review each page carefully to understand the questions and options.
3. Fill out the survey in its entirety, including all required fields.
4. Provide clear and concise answers in the required fields.

## Field-by-Field Explanation

### 1. **Contact Info** (First Name, Last Name, Phone Number, Email)
* Select the appropriate contact information of the customer who is leaving or has left your business.
* Choose one option for each field.

### 2. **Reason for Churn** (Poor Quality, Lack of Features, Cost, Support)
* Select all applicable reasons why the customer is leaving or has left your business.
* You can choose more than one reason.

### 3. **Contact Frequency**
* If applicable, select the frequency of contact the customer had with your business.
* This is an optional field, so select only if relevant.

### 4. **Last Contact Date**
* If applicable, select the date of the last contact with the customer.
* This is an optional field, so select only if relevant.

### 5. **Last Interaction**
* If applicable, select the time of the last interaction with the customer.
* This is an optional field, so select only if relevant.

### 6. **Reason for Leaving** (No Longer Needed, Dissatisfied with Quality, Dissatisfied with Cost, Other)
* Select the reason why the customer has left your business.
* This is a required field and must be selected.

### 7. **Next Steps**
* Select all applicable next steps to improve customer relationships and retention.
* You can choose more than one next step.

### 8. **Customer Comments** (Note field)
* Provide any additional comments about the customer's experience.
* This is an optional field, so write only if necessary.

### 9. **Customer Feedback** (Positive, Negative, Neutral, Unhappy)
* Select the customer's feedback about their experience with your business.
* You can choose more than one feedback option.

### 10. **Customer Satisfaction** (Very Satisfied, Somewhat Satisfied, Somewhat Dissatisfied, Very Dissatisfied)
* Select the customer's level of satisfaction with your business.
* This is a required field and must be selected.

### 11. **Customer Service Rep Name** (John, Jane, Joe)
* Select the name of the customer service representative who handled the customer's case.
* This is a required field and must be selected.

### 12. **Customer Service Rep Phone**
* If applicable, enter the phone number of the customer service representative.
* This is an optional field, so enter only if necessary.

### 13. **Customer Service Rep Email**
* If applicable, enter the email of the customer service representative.
* This is an optional field, so enter only if necessary.

### 14. **Customer Service Rep Notes** (Note field)
* Provide any additional notes about the customer's case.
* This is an optional field, so write only if necessary.

### 15. **Customer Service Rep Comments** (Note field)
* Provide any additional comments from the customer service representative.
* This is an optional field, so write only if necessary.

### 16. **Manager Comments** (Note field)
* Provide any additional comments or recommendations from the manager.
* This is an optional field, so write only if necessary.

Please review each field carefully and fill out the survey with the most accurate information to provide valuable insights to improve customer relationships and retention.
