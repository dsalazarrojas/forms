# research_data_management_practices_survey - Help Guide
## Purpose
The purpose of this form is to collect information about research data management practices from researchers. This information will help improve research data management practices within an institution.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Introduction" page.
2. Review the instructions and guidelines provided.
3. Fill out the required fields (researcher ID, institution, research title, research description, research data services, research data storage, data retention, data destruction, data access control, data disposition, data disposition location, data disposition method, and comments).
4. Fill out the optional fields (department, collaborators, data types, data location, data security, data sharing, documentation, data backup, data archiving, research data services, and research data storage).
5. Select multiple options for the following fields: department, collaborators, data types, data location, data security, data sharing, documentation, data backup, data archiving, data storage, data disposal, data retention, data disposition, and access control.

## Field-by-Field Explanation

* **Introduction**:
	+ The introduction page explains the purpose and guidelines of the form.
* **Researcher ID**:
	+ A unique identifier for the researcher.
* **Institution**:
	+ The institution where the researcher works.
* **Department**:
	+ The department within the institution where the researcher works. (Optional)
* **Research Title**:
	+ The title of the research project.
* **Research Description**:
	+ A brief description of the research project.
* **Collaborators**:
	+ A list of collaborators for the research project. (Optional)
* **Data Types**:
	+ Types of data used for the research project. (Optional)
* **Data Location**:
	+ Where the data is stored. (Optional)
* **Data Security**:
	+ The security level of the data. (Optional)
* **Data Sharing**:
	+ How the data is shared. (Optional)
* **Documentation**:
	+ A list of documents related to the data. (Optional)
* **Data Backup**:
	+ A list of data backup methods. (Optional)
* **Data Archiving**:
	+ A brief description of data archiving practices. (Optional)
* **Research Data Services**:
	+ Services used for managing research data. (Optional)
* **Research Data Storage**:
	+ The storage system used for research data. (Optional)
* **Data Disposal**:
	+ A list of methods for disposing of data. (Optional)
* **Data Retention**:
	+ The retention period for the data. (Optional)
* **Data Destruction**:
	+ A brief description of data destruction practices. (Optional)
* **Access Control**:
	+ A description of access control practices. (Optional)
* **Data Access Control**:
	+ A description of data access control practices. (Optional)
* **Data Disposition**:
	+ A brief description of data disposition practices. (Optional)
* **Data Disposition Location**:
	+ The location where the data is disposed of. (Optional)
* **Data Disposition Method**:
	+ The method used to dispose of the data. (Optional)
* **Comments**:
	+ Additional comments about data management practices. (Optional)
