# Marine Diagenesis Survey - Help Guide

## Purpose
The Marine Diagenesis Survey is a form used to collect information about marine samples, specifically sediment samples, their type, and other relevant features. This form helps researchers to document and standardize the collection of data from these samples, ensuring consistency and accuracy in their analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the survey in the "survey_name" field.
2. Provide a brief description of the sediment sample.
3. Select the type of sediment from the available options.
4. Select the methods used for sampling from the available options.
5. If necessary, upload any supporting files related to the survey (up to three files can be uploaded).
6. Enter any additional survey methods used.
7. Select any relevant diagenetic features from the available options.
8. Provide any other diagenetic features not listed.

## Field-by-Field Explanation

* **survey_name** (text, required/optional): Enter the name of the survey.
* **sediment_sample_description** (text, required/optional): A brief description of the sediment sample.
* **sediment_type** (select_one, required/optional): Select the type of sediment from the available options, such as Option 1, Option 2, or Option 3.
* **sampling_method** (select_multiple, required/optional): Select all the methods used for sampling from the available options, such as Option 1, Option 2, or Option 3.
* **supporting_files** (note, required/optional): If you have any supporting files for the survey, upload them here. You can upload up to three files.
* **supporting_file_1**, **supporting_file_2**, **supporting_file_3** (text, required/optional): Enter the details of each uploaded supporting file.
* **survey_method** (text, required/optional): Enter any additional survey methods used.
* **diagenetic_features** (select_multiple, required/optional): Select any relevant diagenetic features from the available options, such as Option 1, Option 2, or Option 3.
* **other_diagenetic_features** (text, required/optional): Provide any other diagenetic features not listed.

## Tips
* Make sure to provide as much information as possible for each field to ensure accuracy and thoroughness.
* If you are unsure about any field, please contact the relevant authority for guidance.
* Upload files in a format that is easily accessible for our team to review.
