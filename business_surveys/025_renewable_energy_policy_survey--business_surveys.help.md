# Renewable Energy Policy Survey - Help Guide
## Purpose
This form is designed to collect information about renewable energy policies for research, analysis, or decision-making purposes.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the Policy Name field with a brief description of the policy you are surveying.
2. Select the Category from the drop-down list to categorize the policy.
3. If relevant, select the Assigned Tool that corresponds to the category.
4. Provide the Output File name if the policy is to be generated as an output file.
5. Optionally, provide the Form ID if you want to track the form's unique identifier.
6. Fill in the Category Label field with a descriptive label for the category.
7. Fill in the Description Label field with a descriptive label for the policy description.
8. Fill in the Output File Label field with a descriptive label for the output file.
9. Fill in the Assigned Tool Label field with a descriptive label for the assigned tool.
10. Fill in the Form ID Label field with a descriptive label for the form ID.
11. Fill in the Form Title field with a title for the policy.
12. Fill in the Description field with a description of the policy.
13. Fill in the Form Description field with a description of the form.
14. Select the Category 2 from the drop-down list to further sub-categorize the policy.
15. Optionally, fill in the Form ID 2 field with a unique identifier for the policy.
16. Optionally, fill in the Form Description 2 field with a description of the policy.

## Field-by-Field Explanation
* **Policy Name** (text, required): Enter a brief description of the policy.
* **Category** (select_one, required): Select a category for the policy, such as "Business Surveys".
* **Assigned Tool** (text, optional): If applicable, select the tool used for the policy.
* **Output File** (text, optional): Enter a name for the output file.
* **Form ID** (number, optional): Enter a unique identifier for the form.
* **Category Label** (text, optional): Enter a label for the category.
* **Description Label** (text, optional): Enter a label for the policy description.
* **Output File Label** (text, optional): Enter a label for the output file.
* **Assigned Tool Label** (text, optional): Enter a label for the assigned tool.
* **Form ID Label** (text, optional): Enter a label for the form ID.
* **Form Title** (text, optional): Enter a title for the policy.
* **Description** (text, optional): Enter a description of the policy.
* **Form Description** (text, optional): Enter a description of the form.
* **Category 2** (select_one, optional): Select a second category for the policy.
* **Form ID 2** (number, optional): Enter a unique identifier for the policy.
* **Form Description 2** (text, optional): Enter a description for the policy.
