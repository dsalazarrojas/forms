# Marketing Campaign ROI Evaluation Form - Help Guide
## Purpose
The Marketing Campaign ROI Evaluation Form is designed to help evaluate the return on investment (ROI) of marketing campaigns. It gathers information about campaign performance, goals, target audience, budget allocation, and more to determine whether a campaign has been profitable or not.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the campaign's performance metrics and goals.
2. Check if the campaign has achieved its goals.
3. Identify the target audience for the campaign.
4. Report the budget allocation for the campaign.
5. Provide any additional comments or feedback about the campaign.

## Field-by-Field Explanation

### 1. **Marketing Campaign Performance** (`campaign_performance`, `text`, required: `false`)
This field should be used to describe the campaign's performance, such as its reach, engagement, or conversion rates.

*   Please provide a brief description of the campaign's performance.
*   For example, "The campaign reached 10,000 people, with 5% engagement rate and 2% conversion rate."

### 2. **Goals** (`goals`, `select_one`, options: `Yes, No`, required: `false`)
Check if the campaign achieved its goals.

*   Select `Yes` if the campaign achieved its goals.
*   Select `No` if the campaign did not achieve its goals.

### 3. **Target Audience** (`target_audience`, `select_multiple`, options: `Yes, No`, required: `false`)
Identify the target audience for the campaign.

*   Select `Yes` for each target audience type (e.g., age, location, interests).

### 4. **Budget Allocation** (`budget_allocation`, `number`, required: `false`)
Report the budget allocation for the campaign.

*   Enter the total budget allocated for the campaign.

### 5. **Return On Investment** (`roi`, `number`, required: `false`)
Report the return on investment (ROI) of the campaign.

*   Enter the calculated ROI for the campaign.

### 6. **ROI Calculator** (`roi_calculator`, `select_one`, options: `Yes, No`, required: `false`)
Check if the ROI calculator was used.

*   Select `Yes` if the ROI calculator was used.
*   Select `No` if the ROI calculator was not used.

### 7. **Comments** (`comments`, `note`, required: `false`)
Provide any additional comments or feedback about the campaign.

*   Enter any comments or feedback about the campaign.
*   For example, "The campaign was very successful, but we could have done better with a more targeted approach."

### 8. **Email** (`email`, `email`, required: `false`)
Enter your email address.

*   This field is optional, but it will help us contact you with any further questions or follow-up.

### 9. **Phone** (`phone`, `text`, required: `false`)
Enter your phone number.

*   This field is optional, but it will help us contact you with any further questions or follow-up.

### 10. **Date** (`date`, `date`, required: `false`)
Enter the date the campaign was run.

*   This field is optional, but it will help us track the campaign's performance over time.

### 11. **Time** (`time`, `time`, required: `false`)
Enter the time the campaign was run.

*   This field is optional, but it will help us track the campaign's performance over time.

### 12. **Time Zone** (`time_zone`, `select_one`, options: `Yes, No`, required: `false`)
Check if the campaign was run in a specific time zone.

*   Select `Yes` if the campaign was run in a specific time zone.
*   Select `No` if the campaign was not run in a specific time zone.

### 13. **Time Zone Options** (`time_zone_options`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all time zones where the campaign was run.

*   Select `Yes` for each time zone where the campaign was run.
*   Select `No` if the campaign was not run in a specific time zone.

### 14. **Time Zone Value** (`time_zone_value`, `text`, required: `false`)
Enter the time zone value.

*   This field is optional, but it will help us track the campaign's performance in different time zones.

### 15. **Time Zone Value Options** (`time_zone_value_options`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all time zone value options.

*   Select `Yes` for each time zone value option.
*   Select `No` if the campaign was not run in a specific time zone value.

### 16. **Campaign Manager** (`campaign_manager`, `select_one`, options: `Yes, No`, required: `false`)
Check if the campaign was managed by a specific person.

*   Select `Yes` if the campaign was managed by a specific person.
*   Select `No` if the campaign was not managed by a specific person.

### 17. **Campaign Manager Options** (`campaign_manager_options`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all campaign manager options.

*   Select `Yes` for each campaign manager option.
*   Select `No` if the campaign was not managed by a specific person.

### 18. **Marketing Channel** (`marketing_channel`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all marketing channels used for the campaign.

*   Select `Yes` for each marketing channel.
*   Select `No` if the campaign was not run through a specific marketing channel.

### 19. **Marketing Channel Options** (`marketing_channel_options`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all marketing channel options.

*   Select `Yes` for each marketing channel option.
*   Select `No` if the campaign was not run through a specific marketing channel.

### 20. **Lead Source** (`lead_source`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all lead sources for the campaign.

*   Select `Yes` for each lead source.
*   Select `No` if the campaign was not generated from a specific lead source.

### 21. **Lead Source Options** (`lead_source_options`, `select_multiple`, options: `Yes, No`, required: `false`)
Select all lead source options.

*   Select `Yes` for each lead source option.
*   Select `No` if the campaign was not generated from a specific lead source.

### 22. **Customer Acquisition Cost** (`customer_acquisition_cost`, `number`, required: `false`)
Enter the customer acquisition cost.

*   This field is optional, but it will help us track the campaign's performance in terms of customer acquisition cost.

### 23. **Customer Acquisition Cost Options** (`customer_acquisition_cost_options`, `select_one`, options: `Yes, No`, required: `false`)
Check if the customer acquisition cost options were used.

*   Select `Yes` if the customer acquisition cost options were used.
*   Select `No` if the customer acquisition cost options were not used.

### 24. **Customer Acquisition Cost Value** (`customer_acquisition_cost_value`, `text`, required: `false`)
Enter the customer acquisition cost value.

*   This field is optional, but it will help us track the campaign's performance in terms of customer acquisition cost.

### 25. **Customer Acquisition Cost Value Options** (`customer_acquisition_cost_value_options`, `number`, required: `false`)
Select all customer acquisition cost value options.

*   Select `Yes` for each customer acquisition cost value option.
*   Select `No` if the campaign was not run with a specific customer acquisition cost value.
