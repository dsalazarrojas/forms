# Grid Plotting Survey - Help Guide
## Purpose
The Grid Plotting Survey is designed to gather information about your experience with grid plotting, including the tools and challenges you've encountered.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the answer for "grid_plotting_survey_experience" by choosing between "Yes" and "No".
2. If you answered "Yes", select the tools you've used for grid plotting from the list of options.
3. In the "challenges" field, enter any challenges you've faced during grid plotting.
4. In the "suggestions" field, enter any suggestions you have for improving grid plotting.
5. In the "more_suggestions" field, enter any additional suggestions.

## Field-by-Field Explanation
- **grid_plotting_survey_experience** (`Yes/No`, required/optional): This question asks if you have experience with grid plotting. Select "Yes" if you have, "No" if you haven't.
- **tools** (`select_multiple`, optional): If you've answered "Yes" to grid_plotting_survey_experience, select the tools you've used for grid plotting from the list of options.
- **challenges** (`text`, optional): Enter any challenges you've faced during grid plotting in this field.
- **suggestions** (`text`, optional): Enter any suggestions you have for improving grid plotting.
- **more_suggestions** (`text`, optional): Enter any additional suggestions you have for grid plotting.

## Tips
* Be honest about your experience with grid plotting. This information will help us better understand your perspective.
* If you've used multiple tools, select all that apply in the "tools" field.
