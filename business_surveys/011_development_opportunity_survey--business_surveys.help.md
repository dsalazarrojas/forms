# Development Opportunity Survey - Help Guide
## Purpose
The Development Opportunity Survey is a tool used to collect information about ongoing and upcoming projects within the organization. It helps to identify areas for improvement and opportunities for growth.

## How To Complete This Form

To complete this form, follow these steps:

1. Start by reading the introduction, which provides background information about the form's purpose.
2. Fill in the project title and project description in the corresponding fields.
3. Select the project type and status from the provided options.
4. Choose the project priority and select all applicable options.
5. Enter the project start and end dates, if applicable.
6. Provide feedback about the project, if any.
7. Submit the form once you have completed all the fields.

## Field-by-Field Explanation

* **project title** (`project_title`, text, required): Enter the title of the project.
* **project type** (`project_type`, select_one, optional): Select the type of project (e.g., "Option 1" or "Option 2").
* **project description** (`project_description`, text, optional): Enter a brief description of the project.
* **project status** (`project_status`, select_one, optional): Select the status of the project (e.g., "Option 1" or "Option 2").
* **project priority** (`project_priority`, select_multiple, optional): Select all applicable priority options for the project.
* **project owners** (`project_owners`, text, optional): Enter the names of people involved in the project.
* **project start date** (`project_start_date`, date, optional): Enter the project's start date.
* **project end date** (`project_end_date`, date, optional): Enter the project's end date.
* **feedback** (`feedback`, text, optional): Provide any feedback about the project.

## Tips

* Be as specific as possible when filling in the project description and project priority fields.
* If you're unsure about the project type or status, please consult with your supervisor or project manager.
* Remember to keep all responses confidential and not share them outside the organization.
