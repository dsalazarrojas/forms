# pax_load_management_survey - Help Guide

## Purpose

This form is used to collect information about a flight's load management data. The purpose of the form is to capture key details about the flight's number, date, time, type, status, and other relevant information that can be used for reporting and analysis.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the flight number in the "Flight Number" field (Field 1).
2. Enter the flight date in the "Flight Date" field (Field 2), using the date format (YYYY-MM-DD).
3. Enter the flight time in the "Flight Time" field (Field 3), using the time format (HH:MM:SS).
4. Select the flight type from the drop-down menu in the "Flight Type" field (Field 4).
5. Select the flight status from the drop-down menu in the "Flight Status" field (Field 5).
6. Enter any additional flight number (if applicable) in the "Flight Number 2" field (Field 6).
7. Select the passenger type(s) relevant to the flight in the "Passenger Type" field (Field 7), using the available options.
8. Enter the aircraft type in the "Aircraft Type" field (Field 8).
9. Enter the cargo weight in the "Cargo Weight" field (Field 9), using numerical values.
10. Enter any additional comments or notes about the flight in the "Notes" field (Field 10).

## Field-by-Field Explanation

* **Flight Number (Field 1)**: Enter the unique identifier for this flight.
* **Flight Date (Field 2)**: Enter the date of the flight in the format YYYY-MM-DD.
* **Flight Time (Field 3)**: Enter the time of the flight in the format HH:MM:SS.
* **Flight Type (Field 4)**: Select the type of flight (Flight, Charter, or Ferry).
* **Flight Status (Field 5)**: Select the status of the flight (Scheduled, Departed, Arrived, or Canceled).
* **Flight Number 2 (Field 6)**: Enter any additional flight number (if applicable).
* **Passenger Type (Field 7)**: Select the type of passengers on this flight (Adult, Senior, Child).
* **Aircraft Type (Field 8)**: Enter the type of aircraft used for this flight.
* **Cargo Weight (Field 9)**: Enter the weight of cargo carried on this flight.
* **Notes (Field 10)**: Enter any additional comments or notes about this flight.
