# Tenant Portal Security Survey - Help Guide
## Purpose
This form is designed to gather information about security incidents reported by tenants in a building or property managed by the landlord. It helps the landlord identify potential security concerns and implement measures to ensure tenant safety.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and answer each question to the best of your ability.
2. Be as detailed as possible when providing information, especially in fields like Security Incident Description, Security Incident Location, and Security Incident Reporter.
3. If you have any additional comments or suggestions, use the Comments field to provide more information.

## Field-by-Field Explanation

* **Security Incidents** (`security_incidents`, select_multiple): Select all security incidents that have occurred. This field is required.
* **Security Incident Type** (`security_incident_type`, select_one): Choose the type of security incident you are reporting. This field is required.
* **Security Incident Date** (`security_incident_date`, date): Provide the date the security incident occurred. This field is required.
* **Security Incident Time** (`security_incident_time`, time): Provide the time the security incident occurred. This field is required.
* **Security Incident Location** (`security_incident_location`, text): Enter a detailed description of the location where the security incident occurred. This field is required.
* **Security Incident Description** (`security_incident_description`, text): Provide a detailed description of what happened during the security incident. This field is required.
* **Security Incident Reporter** (`security_incident_reporter`, text): Enter the name or ID of the person who reported the security incident. This field is required.
* **Building Safety Features** (`building_safety_features`, select_multiple): Select any safety features that are currently in place, such as emergency exits, emergency lighting, or fire alarms. This field is required.
* **Tenant Portal Security Measures** (`tenant_portal_security_measures`, select_multiple): Select any measures the landlord has taken to ensure tenant safety, such as security cameras or on-site guards. This field is required.
* **Building Maintenance** (`building_maintenance`, select_one): Choose the status of building maintenance, such as regular or emergency maintenance. This field is required.
* **Security Incident Image** (`security_incident_image`, text): If applicable, attach an image or document related to the security incident (e.g., a photo of a security breach). This field is optional.
* **Comments** (`comments`, note): If you have any additional comments or suggestions, provide them in this field. This field is optional.
