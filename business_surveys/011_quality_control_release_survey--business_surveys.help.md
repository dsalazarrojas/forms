# Quality Control Release Survey - Help Guide
## Purpose

The Quality Control Release Survey is used to gather information from quality control inspectors on the release of products or batches. The form helps to track and document inspection dates, results, and release decisions for quality assurance purposes.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the relevant information for each inspection date and product or batch ID.
2. Enter the dates for each inspection, if applicable.
3. Enter the product or batch ID numbers, if applicable.
4. Enter the results of each inspection, if applicable.
5. Make a release decision for each inspection, selecting one of the options provided.
6. Submit the form when finished.

## Field-by-Field Explanation

* **Inspection Date 1**: Enter the date of the initial inspection, if applicable.
* **Inspection Date 2**: Enter the date of the final inspection, if applicable.
* **Product or Batch ID 1**: Enter the ID number of the product or batch being inspected.
* **Product or Batch ID 2**: Enter the ID number of the product or batch being inspected (if different from the first ID).
* **Results 1**: Enter the outcome of the initial inspection, if applicable.
* **Results 2**: Enter the outcome of the final inspection, if applicable.
* **Release Decision 1**: Make a release decision for the product or batch, selecting one of the provided options.
* **Release Decision 2**: Make a release decision for the product or batch, selecting one of the provided options.
* **Submit**: Review and submit the form when finished.
* **Email 1**: Enter the email address to send updates to, if applicable.
* **Email 2**: Enter the email address to send updates to, if applicable.

## Tips

* Please ensure that all required fields are filled out accurately and completely.
* Review the form carefully before submission to ensure all information is correct.
* If any fields are not applicable, please leave them blank.
* For any issues or concerns, please contact the quality control team.
