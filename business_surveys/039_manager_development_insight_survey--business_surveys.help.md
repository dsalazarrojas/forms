# Manager Development Insight Survey - Help Guide
## Purpose
The Manager Development Insight Survey is a form designed to collect feedback on your manager's development progress, strengths, and areas of improvement. This information helps the manager to identify areas where they need to focus their development efforts.

## How To Complete This Form

1. The form consists of several sections, and you will go through them one by one.
2. Please ensure you're providing accurate and honest feedback about your manager's progress.
3. You can save your answers and go back to them later if needed.
4. Please select the correct options from the dropdowns for questions where applicable.

## Field-by-Field Explanation

* **introduction** (`introduction`, `text`, not required): This is the first page of the form where you can briefly introduce the manager you are providing feedback on.
* **manager_name** (`manager_name`, `text`, not required): This is the manager's name you are providing feedback on.
* **employee_feedback** (`employee_feedback`, `text`, not required): In this section, describe how the manager has been performing recently.
* **strengths** (`strengths`, `select_multiple`, not required): List the manager's strengths, select the ones that apply to your feedback.
	+ Yes: The manager exhibits strength in this area.
	+ No: The manager does not exhibit strength in this area.
* **areas_improvement** (`areas_improvement`, `select_multiple`, not required): Identify the areas where the manager needs improvement, select the ones that apply to your feedback.
	+ Yes: The manager needs improvement in this area.
	+ No: The manager does not need improvement in this area.
* **action_plan** (`action_plan`, `text`, not required): In this section, describe any action plan you think the manager should follow to improve.
* **follow_up** (`follow_up`, `select_one`, not required): If you have any concerns or issues that need to be addressed, select one of the options below.
	+ Yes: There are concerns or issues that need to be addressed.
	+ No: There are no concerns or issues that need to be addressed.
* **date** (`date`, `date`, not required): The date this feedback was given, this will automatically be set by the system.
* **time** (`time`, `time`, not required): The time this feedback was given, this will automatically be set by the system.
* **email** (`email`, `email`, not required): The email address of the person submitting this form, this will automatically be set by the system.
* **phone** (`phone`, `text`, not required): Any contact number to reach out to for follow-up conversations.
* **categories** (`categories`, `select_multiple`, not required): Select the categories of improvement that this feedback pertains to.
	+ Manager Development
	+ Other
