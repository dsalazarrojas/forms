# media_viewer_preference_report_form - Help Guide
## Purpose
The Media Viewer Preference Report Form is used by teams to collect data on media viewer preferences and viewing habits, providing valuable insights for data-driven decision making and improving media viewer experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category for the report. This will help determine which type of data will be collected.
2. Enter a title for the report, making sure it accurately reflects the purpose of the data collection.
3. Provide a brief description of the report, explaining its purpose and scope.
4. Select the category for the data collection (e.g. Business Surveys).
5. Enter a title for the report again, ensuring it matches the initial title.
6. Specify the tool assigned to this report, as it will be used for further analysis.
