# Productivity Tool Usage Report Form - Help Guide

## Purpose
The Productivity Tool Usage Report Form is designed to collect information about the usage of productivity tools within an organization. This form aims to gather insights into how employees are utilizing specific tools to improve organizational productivity and efficiency.

## How To Complete This Form
1. Fill out the form with accurate and complete information about the tool in question.
2. Ensure that all required fields are completed to provide a comprehensive report.
3. If a field is unclear, refer to the Field-by-Field Explanation section for assistance.

## Field-by-Field Explanation
* **Organization name** (`organization_name`, `text`, required): Enter the name of the organization that uses the tool.
* **Tool used** (`tool_used`, `select_multiple`, required): Select the tools used in the organization (e.g., 'Yes' for tools that are used and 'No' for tools that are not used).
* **Tool usage frequency** (`tool_usage_frequency`, `number`, required): Enter the number of times the tool is used within the organization.
* **User name** (`user_name`, `text`, required): Enter the name of the individual who uses the tool.
* **User title** (`user_title`, `text`, required): Enter the title or role of the individual who uses the tool.
* **Organization size** (`organization_size`, `select_one`, optional): If the organization size is relevant to the tool's usage, select the appropriate size category (e.g., 'Yes' for large organization and 'No' for small organization).
* **Tool type** (`tool_type`, `select_multiple`, required): Select all tool types used in the organization (e.g., 'Yes' for multiple tool types).
* **Tool feature** (`tool_feature`, `select_multiple`, required): Select all features used with the tool in the organization (e.g., 'Yes' for multiple features).
* **Tool version** (`tool_version`, `select_one`, optional): If the tool version is relevant, select the version number of the tool used.
* **Tool license** (`tool_license`, `select_one`, required): Confirm the tool's license status in the organization (e.g., 'Yes' for an active license).
* **Tool vendor** (`tool_vendor`, `select_one`, required): Enter the tool's vendor or provider.
* **Tool purchase date** (`tool_purchase_date`, `date`, required): Enter the date the tool was purchased or first introduced in the organization.
* **Tool last used date** (`tool_last_used_date`, `date`, required): Enter the date the tool was last used in the organization.
* **Tool last used time** (`tool_last_used_time`, `time`, required): Enter the time the tool was last used in the organization.
* **Tool last used duration** (`tool_last_used_duration`, `number`, required): Enter the duration the tool was last used.
* **Tool last used location** (`tool_last_used_location`, `text`, required): Enter a detailed description of the location where the tool was last used.
* **Tool used by** (`tool_used_by`, `text`, required): Enter the name of the individual or team who use the tool.
* **Tool comment** (`tool_comment`, `text`, required): Enter any relevant comments or feedback about the tool.
* **Organization email** (`organization_email`, `email`, required): Enter the email address of the organization responsible for the tool's usage.
* **User email** (`user_email`, `email`, required): Enter the email address of the individual who uses the tool.
* **Tool used by others** (`tool_used_by_others`, `text`, optional): If applicable, describe who else uses the tool within the organization.
* **Tool comment by others** (`tool_comment_by_others`, `text`, optional): If applicable, enter any comments or feedback from others about the tool.
* **Tool last used by others** (`tool_last_used_by_others`, `text`, optional): If applicable, describe the last time the tool was used by others within the organization.
* **Tool last used by others duration** (`tool_last_used_by_others_duration`, `number`, optional): If applicable, enter the duration the tool was last used by others.

## Tips
* Ensure accurate and complete information is entered for each field.
* If a field is unclear, refer to the Field-by-Field Explanation section for assistance.
* This form is designed to gather comprehensive insights into tool usage; please provide as much detail as possible.
