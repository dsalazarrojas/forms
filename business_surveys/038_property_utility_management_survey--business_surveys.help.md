# Property Utility Management Survey - Help Guide
## Purpose
This form is for collecting data on property utility management, including property information, service details, and contact details. It helps authorized personnel to track and manage properties and their utility services effectively.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the **tenant name** of the property in the "tenant name" field.
2. Select the **property type** (e.g., Option 1, Option 2, or Option 3) from the dropdown menu.
3. Enter the **property address** in the "property address" field.
4. Select the **service type** (e.g., Option 1, Option 2, or Option 3) from the dropdown menu.
5. Enter the **start date** of the service in the "start date" field.
6. Enter the **end date** of the service in the "end date" field.
7. Select the **service frequency** (e.g., Option 1, Option 2, or Option 3) from the dropdown menu.
8. Enter the **contact name** in the "contact name" field.
9. Enter the **contact email** (if available) in the "contact email" field.
10. Enter the **contact phone number** (if available) in the "contact phone" field.
11. Add any **note** (if necessary) in the "note" field.
12. Select the **assigned tool** (e.g., Option 1, Option 2, or Option 3) from the dropdown menu.
13. Enter the **created by** personnel in the "created by" field.
14. Enter the **updated by** personnel in the "updated by" field (if applicable).
15. Enter the **created at** time in the "created at" field (if applicable).
16. Enter the **updated at** time in the "updated at" field (if applicable).
17. Select the **category** (e.g., Option 1, Option 2, or Option 3) from the dropdown menu.
18. Enter a **description** (if necessary) in the "description" field.
19. Select the **assigned tool** (e.g., Option 1, Option 2, or Option 3) from the dropdown menu.
20. Enter the **assigned date** in the "assigned date" field (if applicable).
21. Enter the **form id** in the "form id" field (if applicable).
22. Enter the **submitted at** time in the "submitted at" field (if applicable).
23. Add any additional **comments** (if necessary) in the "comments" field.

## Field-by-Field Explanation
* **tenant name** (1, Text, Required): Enter the name of the property's tenant.
* **property type** (2, Select One, Required): Select the type of property (e.g., Option 1, Option 2, or Option 3).
* **property address** (3, Text, Required): Enter the property's address.
* **service type** (4, Select One, Required): Select the type of service (e.g., Option 1, Option 2, or Option 3).
* **start date** (5, Date, Required): Enter the start date of the service.
* **end date** (6, Date, Required): Enter the end date of the service.
* **service frequency** (7, Select One, Required): Select the frequency of the service (e.g., Option 1, Option 2, or Option 3).
* **contact name** (8, Text, Required): Enter the contact person's name.
* **contact email** (9, Email, Optional): Enter the contact person's email (if available).
* **contact phone** (10, Text, Optional): Enter the contact person's phone number (if available).
* **note** (11, Note, Optional): Add any additional notes on the service.
* **assigned tool** (12, Select One, Required): Select the tool assigned to the service (e.g., Option 1, Option 2, or Option 3).
* **created by** (13, Text, Required): Enter the personnel who created this form.
* **updated by** (14, Text, Optional): Enter the personnel who last updated this form (if applicable).
* **created at** (15, Time, Optional): Enter the time this form was created (if applicable).
* **updated at** (16, Time, Optional): Enter the time this form was last updated (if applicable).
* **form id** (17, Number, Optional): Enter the form's ID (if applicable).
* **output file** (18, Text, Optional): Enter the output file (if applicable).
* **category** (19, Select One, Required): Select the category (e.g., Option 1, Option 2, or Option 3).
* **description** (20, Text, Optional): Enter a description of the service (if necessary).
* **assigned tool** (21, Select One, Required): Select the tool assigned to the service (e.g., Option 1, Option 2, or Option 3).
* **assigned date** (22, Date, Optional): Enter the assigned date (if applicable).
* **form id** (23, Number, Optional): Enter the form's ID (if applicable).
* **submitted at** (24, Time, Optional): Enter the time this form was submitted (if applicable).
* **comments** (25, Note, Optional): Add any additional comments on the service (if necessary).

## Tips
* Make sure to fill out all required fields before submitting the form.
* Use the correct format for dates (DD/MM/YYYY) and times (HH:MM).
* Ensure that all fields are filled out accurately and truthfully.
* If you are not sure about a particular field, please consult with authorized personnel for clarification.
* This form is for collecting property utility management survey data only. Do not use it for other purposes.
