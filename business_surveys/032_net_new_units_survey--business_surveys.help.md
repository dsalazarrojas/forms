# Net New Units Survey - Help Guide
## Purpose
This form is used to collect information about new units that are being added to or removed from the company's inventory.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the number of new units being added or removed from inventory.
2. Select the type(s) of the new unit(s) being added or removed (e.g. Office, Factory, Store, Warehouse, Headquarters).
3. Enter the address of the unit being added or removed (if applicable).

## Field-by-Field Explanation

* **New Units** (`new_units`, `number`, required): Enter the number of new units being added or removed from inventory. This field is required, so please make sure to enter a value.
* **Unit Type** (`unit_type`, `select_multiple`, required): Select the type(s) of the new unit(s) being added or removed. Options include:
	+ Office
	+ Factory
	+ Store
	+ Warehouse
	+ Headquarters
* **Unit Address** (`unit_address`, `note`, optional): Enter the address of the unit being added or removed. This field is not required, but if you are entering a physical unit, please provide the address where it is located.

## Tips

* Make sure to fill out all required fields to ensure that the form is submitted correctly.
* If you are unsure about the unit type, select all that apply to ensure accurate representation.
* If you are entering a unit address, please use a valid format (e.g. 123 Main St, Anytown, USA).
