# Precision Tools Feedback Survey - Help Guide
## Purpose
This survey aims to gather feedback from users about the Precision Tools they have used. We value your opinions and suggestions to continuously improve our tools and provide better services to you and our users in the future.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question carefully and accurately.
2. For fields where you have the option to choose from, select the best fitting response.
3. If you have used a tool that is not listed in the "What tool used" dropdown, select "Other" and describe it in the text box.
4. Make sure to provide as much detail as you can about your experience with the tool.

## Field-by-Field Explanation

* **Feedback** (`feedback_form`, Text, Optional): Please share any general feedback you have about the Precision Tools you used.
* **Experience Rating** (`experience_rating`, Number, Optional): Rate your overall experience with the tools, on a scale from 0 to 10.
* **How Useful Do the Tools Feel** (`how_useful_do_the_tools_feel`, Select Multiple, Optional): Rate how useful you found the tools in your work.
* **Suggest Improvement** (`suggest_improvement`, Text, Optional): If you have any suggestions for improvement, please share them here.
* **Open Issues** (`open_issued`, Text, Optional): If you have encountered any open issues while using the tools, describe them here.
* **Contact Email** (`contact_email`, Email, Optional): Please enter the email address where we can contact you for any further questions or clarification.
* **Feedback Email** (`feedback_email`, Email, Optional): Enter the email address where we would like to send you feedback on your responses.
* **Feedback Subject** (`feedback_subject`, Text, Optional): Enter a brief subject line for our email feedback response.
* **Feedback Description** (`feedback_description`, Text, Optional): Share more details about your feedback.
* **What Tool Used** (`what_tool_used`, Select One, Optional): If you used one of our tools, select it from the dropdown list. Otherwise, select "Other" and describe it in the text box.
* **Tool Used Other** (`tool_used_other`, Text, Optional): Enter the name of the tool you used if it is not listed in the "What tool used" dropdown.
* **Feedback Date** (`feedback_date`, Date, Optional): Enter the date you used the tool.
* **Feedback Time** (`feedback_time`, Time, Optional): Enter the time you used the tool.
* **Submitted At** (`submitted_at`, Date, Optional): Enter the date and time you submitted this feedback.
* **Submitted By** (`submitted_by`, Select One, Optional): Select who submitted this form (e.g. Chat Jimmy, Chat Bob, Chat Alice).
* **Assigned Tool** (`assigned_tool`, Text, Optional): Enter the name of the tool you are providing feedback on.
* **Tool Type** (`tool_type`, Select One, Optional): Select the type of tool you used (e.g. General Tools, Data Analysis, Machine Learning).

Note: The fields marked as "Optional" are not required to be filled out, but your feedback will be more helpful if you can provide as much detail as possible.
