# treasury_system_enhancement_survey - Help Guide
## Purpose
This form is designed to gather feedback and suggestions from users on how to enhance the treasury system.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Start by reading the introduction page, which provides a brief overview of the purpose and context of the form.
2. Answer the questions on the following pages, which will guide you through the areas where the treasury system can be improved.
3. For each question, select the best answer from the options provided or type in your comments and feedback.
4. Fill out your name and email address in the required fields.
5. If you're not sure about any of the questions, please answer "No" and provide a brief explanation in the comments section.

## Field-by-Field Explanation

* **Introduction** (`Introduction`, note, required: false): This page provides a brief overview of the form and its purpose.
* **systemUsage** (`systemUsage`, select_one, required: true): Please select whether you use the treasury system:
	+ 'Yes': I regularly use the system.
	+ 'No': I do not use the system or only occasionally.
* **Satisfaction** (`Satisfaction`, select_multiple, required: true): Please select your level of satisfaction with the treasury system:
	+ Satisfied: The system meets my needs.
	+ Dissatisfied: The system does not meet my needs.
* **improvement_areas** (`improvementAreas`, select_multiple, required: true): Please select areas where you think the treasury system can be improved:
	+ 'Yes': This area needs improvement.
	+ 'No': This area is satisfactory.
* **Comments** (`Comments`, text, required: false): If you have any additional comments or feedback, please type them in this field.
* **name** (`name`, text, required: true): Please enter your name.
* **department** (`department`, text, required: false): If you're completing this form on behalf of your department, please enter the department name.
* **email** (`email`, email, required: true): Please enter your email address.
* **phone** (`phone`, text, required: false): If you'd like to be contacted for further discussion, please enter your phone number.
* **assigned_to** (`assignedTo`, select_one, required: true): Please select whether you've been assigned to someone for this form:
	+ 'Yes': I'm the assigned person.
	+ 'No': I'm not the assigned person.
