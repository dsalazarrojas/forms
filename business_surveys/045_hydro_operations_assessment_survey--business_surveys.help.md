## Hydro Operations Assessment Survey - Help Guide

## Purpose
The Hydro Operations Assessment Survey is designed to assess the performance of hydroelectric operations and maintenance activities. It is meant to be a quick and easy way to collect data on the current state of the operations.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Select the relevant options for each question from the provided list.
2. Fill in the text fields as needed.
3. Make sure to provide accurate and honest answers to the questions.
4. Review the form before submitting to ensure all questions are answered.

## Field-by-Field Explanation

* **Hydroelectric Operations** (`select_multiple`): This question asks if hydroelectric operations are currently being performed. Select all that apply.
* **Operations Performance** (`text`): Enter a description of the current operations performance, e.g., high, medium, or low.
* **Maintenance** (`select_one`): Select the level of maintenance required, High, Medium, or Low.
* **Hydroelectric Power Plants** (`number`): Enter the number of hydroelectric power plants that are currently operational.
* **Water Sources** (`select_multiple`): This question asks if water sources are currently being used for hydroelectric operations. Select all that apply.
* **Hydroelectric Turbine** (`select_one`): This question asks if hydroelectric turbine is currently being used. Select Yes or No.
* **Turbine Performance** (`number`): Enter the performance of the hydroelectric turbine, e.g., 100%.
* **Maintenance Schedule** (`select_multiple`): This question asks if a maintenance schedule is currently in place. Select all that apply.
* **Operations Performance** (`text`): Enter a description of the current operations performance, e.g., high, medium, or low.
* **Performance Monitoring** (`date`): Enter the date of the last performance monitoring, in the format DD/MM/YYYY.
* **Note**: This field is not currently used, but will be used for future improvements.
