# survey_on_space_planning - Help Guide
## Purpose
This form is designed to gather feedback and suggestions from end-users regarding the current space planning. By filling out this form, you'll help the business department to make informed decisions on how to improve the space planning and make the workplace more comfortable and efficient for employees.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with your personal information and answers.
2. Make sure to answer all required fields.
3. Review your answers before submitting the form.

## Field-by-Field Explanation

* **Please introduce yourself** (`introduction`, `text`, required): This field is a text input where you can briefly introduce yourself.
* **How do you use your workspace?** (`space_usage`, `select_one`, required): Please select how you use your workspace from the available options: **True**, **False**, or **Maybe**.
* **What is your satisfaction level with the current space planning?** (`satisfaction_level`, `select_multiple`, required): Please select all the satisfaction levels that apply to you from the available options:
	+ **Very Satisfied**
	+ **Somewhat Satisfied**
	+ **Neutral**
	+ **Somewhat Dissatisfied**
	+ **Very Dissatisfied**
* **What are the main challenges you face when using the available space?** (`challenges_list`, `text`, required): This field is a text input where you can list the main challenges you face when using the available space.
* **Do you have any additional feedback?** (`feedback`, `text`, required): This field is a text input where you can provide any additional feedback you have about the space planning.
* **Is the available space sufficient for your needs?** (`space_availability`, `select_multiple`, required): Please select all the options that apply to you from the available:
	+ **True**
	+ **False**
* **How many hours do you spend at work in a typical day?** (`time_spent_in_workplace`, `time`, optional): If you feel comfortable sharing, please input the number of hours you spend at work in a typical day.
* **Do you have any suggestions for improving the space planning?** (`suggestions_for_improvement`, `text`, required): This field is a text input where you can suggest ideas for improving the space planning.
* **Are you assigned a tool for your task?** (`assigned_tool`, `select_one`, required): Please select whether you have been assigned a tool for your task from the available options: **True** or **False**.
* **What is your form ID?** (`form_id`, `text`, required): This field is a text input where you can input your unique form ID.
* **Which category do you belong to?** (`category`, `select_one`, required): Please select which category you belong to from the available options: **True** or **False**.
* **What is the current form version?** (`form_version`, `text`, required): This field is a text input where you can input the current form version.

## Tips

* Please make sure to answer all required fields.
* Take your time to answer all questions carefully and accurately.
* If you're unsure about any field, please ask for clarification before submitting the form.
* If you have any questions or concerns, please contact the business department.
* Thank you for taking the time to help us improve the space planning!
