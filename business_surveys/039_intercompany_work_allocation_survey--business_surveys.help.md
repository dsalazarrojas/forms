# Intercompany Work Allocation Survey - Help Guide
## Purpose
This form is designed to collect information about intercompany tasks and their allocations. It's used for tracking progress, task management, and collaboration within the company.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by answering the questions on **Page 1: Intercompany Tasks**.
2. For each task, provide a description of the task you are responsible for in the **Intercompany Tasks** field.
3. On **Page 2: Task Allocation**, choose how often the task is allocated (Daily, Weekly, Monthly, etc.).
4. Select the tools used for each task from the list in **Allocated Tool**.
5. If you have comments or suggestions, add them in the **Comments** field.
6. Finally, submit your answers by selecting **Submit**.

## Field-by-Field Explanation

* **Intercompany Tasks** (`intercompany_tasks`, `text`, optional): Provide a description of the task you are responsible for.
* **Task Allocation** (`task_allocation`, `number`, optional): This field is not very descriptive, but it seems to be related to allocating tasks. You might consider how often the task is performed (Daily, Weekly, etc.).
* **Allocated Tasks** (`allocated_tasks`, `select_multiple`, optional): Select the tasks you are responsible for from the list.
* **Challenges** (`challenges`, `text`, optional): Mention any challenges or difficulties you are facing with the task.
* **Suggestions** (`suggestions`, `text`, optional): Share any suggestions you have for improving task performance.
* **Time Spent** (`time_spent`, `time`, optional): Record the time spent on the task, using the format HH:MM.
* **Time Allocated** (`time_allocated`, `number`, optional): This field is somewhat confusing, but it might be related to the allocated time for each task.
* **Allocated Time** (`allocated_time`, `select_multiple`, optional): Select how much time is allocated for each task from the list.
* **Task Frequency** (`task_frequency`, `select_one`, required): Choose how often the task is performed (Daily, Weekly, Monthly, etc.).
* **Comments** (`comments`, `text`, optional): Share any comments or thoughts about the task.
* **Assigned Tool** (`assigned_tool`, `select_one`, optional): Select the tool assigned to perform the task.
* **Comments 2** (`comments_2`, `text`, optional): Add additional comments or thoughts about the task.
* **Additional Comments** (`additional_comments`, `text`, optional): Provide any additional information about the task.
* **Email** (`email`, `email`, optional): Enter your email address.
* **Phone** (`phone`, `text`, optional): Enter your phone number.
* **Task Comments** (`task_comments`, `text`, optional): Share comments or thoughts about the task performance.
* **Allocated Tool** (`allocated_tool`, `select_multiple`, optional): Select the tool allocated for each task.
* **Time Allocated Comments** (`time_allocated_comments`, `text`, optional): Record any comments about the allocated time for the task.
* **Allocated Time** (`allocated_time`, `text`, optional): Add comments about the allocated time for the task.
* **Comments 3** (`comments_3`, `text`, optional): Provide additional comments or thoughts.
* **Allocated Time 2** (`allocated_time_2`, `number`, optional): Enter the allocated time for each task.
* **Allocated Tool 2** (`allocated_tool_2`, `select_multiple`, optional): Select the tools allocated for each task.
* **Comments 4** (`comments_4`, `text`, optional): Share additional comments or thoughts.
* **Task Comments 2** (`task_comments_2`, `text`, optional): Record comments or thoughts about the task performance.

## Tips
* Please answer each field accurately and honestly.
* Review the form before submitting to ensure you have completed all required fields.
* If you are unsure about any field, refer to your supervisor or team leader for guidance.
* Please note that some fields are optional, but providing complete information will help in better tracking and management.
