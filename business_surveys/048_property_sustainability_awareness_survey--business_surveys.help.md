# Property Sustainability Awareness Survey - Help Guide
## Purpose
The Property Sustainability Awareness Survey is designed to gather information about your property's current sustainability performance and identify areas for improvement. This survey will help us understand how sustainable your property is and provide insights for future improvements.

## How To Complete This Form
To complete this form, please answer the questions honestly and to the best of your ability. You can submit this form online or print it out and fill it in by hand. Please make sure to complete all the required fields. If you are unsure about any of the questions, please ask for clarification.

## Field-by-Field Explanation
* **Property Name** (`property_name`, text, optional): Please enter the name of your property.
* **Location** (`location`, text, optional): Please enter the location of your property.
* **Sustainability Features** (`sustainability_features`, select multiple, optional): Please select all the sustainability features that your property has, such as Green Walls, Solar, Energy Efficiency, etc.
* **Sustainability Knowledge** (`sustainability_knowledge`, text, optional): Please provide any additional information about your property's sustainability knowledge or practices.
* **Barriers to Improvement** (`barriers_to_improvement`, text, optional): Please list any barriers that prevent your property from improving its sustainability performance.
* **Current Level of Sustainability** (`current_level_of_sustainability`, select one, optional): Please select the current level of sustainability of your property (Low, Medium, High).
* **Target Level of Sustainability** (`target_level_of_sustainability`, select one, optional): Please select the target level of sustainability that you aim to achieve (Low, Medium, High).
* **Timeframe for Improvement** (`timeframe_for_improvement`, time, optional): Please enter a timeframe for improving your property's sustainability performance.
* **Budget for Improvement** (`budget_for_improvement`, number, optional): Please enter a budget for improving your property's sustainability performance.
* **Priority for Improvement** (`priority_for_improvement`, select one, optional): Please select the priority level for improving your property's sustainability performance (Low, Medium, High).
* **Communication Channels** (`communication_channels`, select multiple, optional): Please select the communication channels you use to share sustainability information with stakeholders.
* **Sustainability Team** (`sustainability_team`, select one, optional): Please indicate if you have a dedicated sustainability team.
* **Feedback** (`feedback`, text, optional): Please provide any additional feedback or comments about the survey.
* **Additional Comments** (`additional_comments`, text, optional): Please provide any additional comments or information about your property.
* **Property Type** (`property_type`, select one, optional): Please select the type of your property (Office Building, Residential Building, Commercial Building, Industrial Building).
* **Number of Units** (`number_of_units`, number, optional): Please enter the number of units in your property.
* **Square Footage** (`square_footage`, text, optional): Please enter the square footage of your property.
* **Year Built** (`year_built`, text, optional): Please enter the year your property was built.
* **Building Age** (`building_age`, text, optional): Please enter the age of your building.
* **Energy Rating** (`energy_rating`, select one, optional): Please select the energy rating of your building (High, Medium, Low).
* **Water Rating** (`water_rating`, select one, optional): Please select the water rating of your building (High, Medium, Low).
* **Waste Rating** (`waste_rating`, select one, optional): Please select the waste rating of your building (High, Medium, Low).
* **Carbon Footprint** (`carbon_footprint`, select one, optional): Please select the carbon footprint of your building (High, Medium, Low).
* **Green Building Certification** (`green_building_certification`, select multiple, optional): Please select any green building certifications that your property has.
* **Sustainability Features** (`sustainability_features`, select multiple, optional): Please select all the sustainability features that your property has.
* **Energy Efficiency** (`energy_efficiency`, select one, optional): Please select the energy efficiency of your building (High, Medium, Low).
* **Solar** (`solar`, select one, optional): Please select the solar features that your property has.
* **Water Conservation** (`water_conservation`, select one, optional): Please select the water conservation features that your property has.
* **Waste Management** (`waste_management`, select one, optional): Please select the waste management features that your property has.
* **Recycling** (`recycling`, select one, optional): Please select the recycling features that your property has.
* **Rainwater Harvesting** (`rainwater_harvesting`, select one, optional): Please select the rainwater harvesting features that your property has.
* **Greenhouse Gas Reduction** (`greenhouse_gas_reduction`, select one, optional): Please select the greenhouse gas reduction features that your property has.
* **Green Infrastructure** (`green_infrastructure`, select one, optional): Please select the green infrastructure features that your property has.
* **Green Walls** (`green_walls`, select one, optional): Please select the green walls features that your property has.
* **Green Roofs** (`green_roofs`, select one, optional): Please select the green roofs features that your property has.
* **High Performance Glazing** (`high_performance_glazing`, select one, optional): Please select the high performance glazing features that your property has.
* **High Performance Insulation** (`high_performance_insulation`, select one, optional): Please select the high performance insulation features that your property has.
* **High Performance Windows** (`high_performance_windows`, select one, optional): Please select the high performance windows features that your property has.
* **High Performance Doors** (`high_performance_doors`, select one, optional): Please select the high performance doors features that your property has.
* **High Performance Roofing** (`high_performance_roofing`, select one, optional): Please select the high performance roofing features that your property has.
