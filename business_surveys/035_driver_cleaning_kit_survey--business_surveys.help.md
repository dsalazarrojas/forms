# Driver Cleaning Kit Survey - Help Guide

## Purpose
This form is used to collect information about the vehicle cleaning kit used by drivers, including its type, frequency of use, contact method, and other relevant details. It helps the organization to understand the usage and preferences of the drivers.

## How To Complete This Form

1. Select the options for "Vehicle Cleaning Kit" to specify the type of cleaning kit the driver uses.
2. Choose the frequency of use for the "Vehicle Cleaning Frequency" field, if applicable.
3. Select the contact method for the driver, if applicable.
4. Enter any vehicle details in the "Vehicle Details" field, if applicable.
5. Select the vehicle model from the list provided in the "Vehicle Model" field, if applicable.
6. Enter the driver's name in the "Driver Name" field, if applicable.
7. Enter the driver's email address in the "Email" field, if applicable.
8. Enter the driver's phone number in the "Phone" field, if applicable.
9. Enter the driver's location in the "Location" field, if applicable.
10. Add any additional comments in the "Comments" field, if applicable.
11. Enter the date the vehicle was cleaned in the "Date" field, if applicable.
12. Enter the time the vehicle was cleaned in the "Time" field, if applicable.
13. Select the type of vehicle from the list provided in the "Vehicle Type" field, if applicable.
14. Select the vehicle color from the list provided in the "Vehicle Color" field, if applicable.
15. Enter the vehicle year in the "Vehicle Year" field, if applicable.
16. Enter the vehicle make in the "Vehicle Make" field, if applicable.
17. Select the vehicle condition from the list provided in the "Vehicle Condition" field, if applicable.
18. Select the status of the vehicle from the list provided in the "Vehicle Status" field, if applicable.

## Field-by-Field Explanation

* **Vehicle Cleaning Kit (vehicle_cleaning_kit, select_multiple)**: Select the type of cleaning kit used by the driver. This field allows multiple selections.
* **Vehicle Cleaning Frequency (vehicle_cleaning_frequency, select_one)**: Choose how often the driver uses the cleaning kit. Options include "Never", "Daily", "Weekly", and "Monthly".
* **Contact Method (contact_method, select_multiple)**: Select the method the driver uses to contact them. Options include "Phone", "Email", "SMS", and "Chat".
* **Vehicle Details (vehicle_details, note)**: Enter any additional details about the vehicle, if applicable.
* **Vehicle Model (vehicle_model, select_one)**: Select the model of the vehicle. Options include "Model 1", "Model 2", "Model 3", and "Model 4".
* **Driver Name (driver_name, text)**: Enter the driver's name.
* **Email (email, email)**: Enter the driver's email address.
* **Phone (phone, text)**: Enter the driver's phone number.
* **Location (location, text)**: Enter the driver's location.
* **Comments (comments, note)**: Add any additional comments about the vehicle or the cleaning process.
* **Date (date, date)**: Enter the date the vehicle was cleaned.
* **Time (time, time)**: Enter the time the vehicle was cleaned.
* **Vehicle Type (vehicle_type, select_one)**: Select the type of vehicle. Options include "Car", "Motorcycle", "Truck", and "Van".
* **Vehicle Color (vehicle_color, select_one)**: Select the color of the vehicle. Options include "Red", "Blue", "Green", and "Yellow".
* **Vehicle Year (vehicle_year, number)**: Enter the year of the vehicle.
* **Vehicle Make (vehicle_make, text)**: Enter the make of the vehicle.
* **Vehicle Condition (vehicle_condition, select_one)**: Select the condition of the vehicle. Options include "New", "Used", "Reconditioned", and "Old".
* **Vehicle Status (vehicle_status, select_multiple)**: Select the status of the vehicle. Options include "Active", "Inactive", "Sold", and "Lost".

## Tips

* Make sure to select the correct options for each field, if applicable.
* Enter accurate and complete information for each field.
* If you have any additional questions or concerns, please contact the support team.
