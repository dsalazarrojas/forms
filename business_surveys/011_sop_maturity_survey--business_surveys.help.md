# sop_maturity_survey - Help Guide
## Purpose
The Sop Maturity Survey form is designed to assess the maturity level of standard operating procedures (SOPs) within an organization. It gathers data on various aspects of SOPs, including review cadence, communication channels, and documentation. This form helps inform decisions and drive improvements to SOPs.

## How To Complete This Form

1. Select the relevant information for each question, taking into consideration the options provided.
2. For select multiple and select one fields, select all applicable options that apply.
3. Provide detailed descriptions for text fields when requested.
4. Ensure that all required fields are filled out, indicated by a star (*).
5. Review the form carefully before submitting to ensure accuracy and completeness.

## Field-by-Field Explanation

* **Review Cadence** (2, select_one, *): Choose the frequency of your review cycle (e.g., Monthly, Quarterly, Bi-Annually, Annually, Ad-hoc).
* **Communication** (3, select_multiple, ): Select all applicable communication channels used for reviews (e.g., Email, Phone, Meetings, Document, Chatbot, Other).
* **Adherence Trends** (4, select_one, ): Select the current state of adherence to SOPs (e.g., Increasing, Stable, Decreasing).
* **Review Process** (5, select_one, ): Choose the type of review process in place (e.g., Formal, Informal, No Review Process).
* **Review Documentation** (6, select_one, ): Choose the level of documentation for reviews (e.g., Formal, Informal, No Documentation).
* **SOP Maturity Index** (7, number, *): Enter the current SOP Maturity Index value.
* **Review Frequency** (8, select_one, ): Select the frequency of reviews (e.g., Monthly, Quarterly, Bi-Annually, Annually, Ad-hoc).
* **Communication Channels** (9, select_multiple, ): Select all applicable communication channels used for reviews (e.g., Email, Phone, Meetings, Document, Chatbot, Other).
* **Adherence Trends Description** (10, text, ): Provide a detailed description of the current state of adherence to SOPs.
* **Review Process Description** (11, text, ): Describe the type of review process in place.
* **Review Documentation Description** (12, text, ): Describe the level of documentation for reviews.
* **SOP Maturity Index Description** (13, text, ): Provide a detailed description of the current SOP Maturity Index value.
* **Review Frequency Description** (14, text, ): Describe the frequency of reviews.
* **Communication Channels Description** (15, text, ): Provide a detailed description of communication channels used for reviews.
* **Review Cadence Description** (16, text, ): Describe the review cycle's cadence.
* **Review Cycle** (17, number, *): Enter the current Review Cycle value.
* **Review Cycle Description** (18, text, ): Describe the review cycle's description.
* **Review Cycle Frequency** (19, select_one, ): Select the frequency of review cycles (e.g., Monthly, Quarterly, Bi-Annually, Annually, Ad-hoc).
* **Cycle Duration** (20, number, ): Enter the cycle duration value.
* **Cycle Duration Description** (21, text, ): Describe the cycle duration.
* **Total SOP Count** (22, number, ): Enter the total number of SOPs.
* **Active SOP Count** (23, number, ): Enter the number of active SOPs.
* **Inactive SOP Count** (24, number, ): Enter the number of inactive SOPs.
* **Total Pages** (25, number, ): Enter the total number of pages.
