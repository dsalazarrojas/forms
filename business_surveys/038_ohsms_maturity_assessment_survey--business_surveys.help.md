# ohsms_maturity_assessment_survey - Help Guide
## Purpose
This form is used to assess the maturity level of a website's overall performance and functionality.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
* **Site Name** (`site_name`, text, required/optional): Enter a unique name for the website being assessed.
* **Assessment Level** (`assessment_level`, select_one, optional): Select the assessment level of the website (High/Low).
* **Site ID** (`site_id`, text, required): Enter a unique identifier for the website.
* **Score** (`score`, number, required): Enter a score between 1 and 10 for the website's performance.
* **Site Name 2** (`site_name_2`, text, optional): Enter a second name for the website (likely for redundancy).
* **Site Name 3** (`site_name_3`, text, optional): Enter a third name for the website (likely for redundancy).
* ...
* **Site Name 16** (`site_name_16`, text, optional): Enter a sixteenth name for the website.
* **Site ID 2** (`site_id_2`, text, required): Enter a second unique identifier for the website.
* **Score 2** (`score_2`, number, required): Enter a second score between 1 and 10 for the website's performance.
* **Site ID 3** (`site_id_3`, text, required): Enter a third unique identifier for the website.
* **Score 3** (`score_3`, number, required): Enter a third score between 1 and 10 for the website's performance.

## Tips
This form is designed to be used multiple times to evaluate multiple websites. Be sure to fill in all required fields for each website assessment. Use the "Assessment Level" field to provide additional context for each website's performance.
