# Perimeter Threat Detection Survey - Help Guide

## Purpose
The Perimeter Threat Detection Survey is designed to gather information about existing systems, incident history, systems design, security standards, existing controls, controls configuration, security concerns, and improvements plans related to perimeter threats. This form is intended to help security teams or system administrators assess the current state of perimeter security and identify potential threats.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Review each field and provide the requested information about your existing systems, incident history, systems design, security standards, existing controls, controls configuration, security concerns, and improvements plans.
2. Fill in the fields with the requested information, using the options provided as a reference.
3. Make sure to provide thorough and accurate information to help security teams or system administrators make informed decisions about perimeter security.
