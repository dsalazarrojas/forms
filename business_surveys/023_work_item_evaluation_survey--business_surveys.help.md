# work_item_evaluation_survey - Help Guide
## Purpose
The "work_item_evaluation_survey" form is designed to collect feedback on projects, evaluating aspects like project effectiveness, quality, ease of use, value, and satisfaction. 

## How To Complete This Form

- Click on the "Submit" button to start filling out the form.
- Select the project you want to evaluate from the dropdown options (only if you are a project member).
- Fill out each field according to your thoughts and experiences about the project.
- Select the appropriate options for each field, if available.
- Use the text fields to provide more detailed comments.
- Click "Submit" again to send your evaluation form.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, optional): Enter the name of the project you are evaluating.
* **Evaluation Item Type** (`evaluation_item_type`, select_one, optional): Choose the type of evaluation item you are evaluating (e.g., Project, Work Item, Task, etc.).
* **Evaluation Scale** (`evaluation_scale`, select_multiple, optional): Select one or more scales to evaluate (e.g., Very Good, Fair, Poor, Good, Excellent).
* **Evaluation Item** (`evaluation_item`, text, optional): Enter a brief description of the item being evaluated (e.g., project, task, feature, etc.).
* **Evaluation Scale Item** (`evaluation_scale_item`, text, optional): Enter comments about the evaluation scale (e.g., why you chose this scale, how it applies, etc.).
* **Evaluation Scale Item Rating** (`evaluation_scale_item_rating`, number, optional): Rate the evaluation scale from 1-5 (if rating is available).
* **Evaluation Scale Item Comment** (`evaluation_scale_item_comment`, text, optional): Add comments about the rating.
* **Evaluation Time** (`evaluation_time`, time, optional): Enter the time you spent evaluating the project.
* **Evaluation Comment** (`evaluation_comment`, text, optional): Add comments about your overall evaluation.
* **Evaluation Time Scale** (`evaluation_time_scale`, select_one, optional): Choose the time scale (e.g., High, Medium, Low).
* **Evaluation Time Scale Comment** (`evaluation_time_scale_comment`, text, optional): Add comments about the time scale.
* **Evaluation Project Effectiveness** (`evaluation_project_effectiveness`, select_multiple, optional): Select one or more scales to evaluate project effectiveness (e.g., High, Medium, Low).
* **Evaluation Project Effectiveness Comment** (`evaluation_project_effectiveness_comment`, text, optional): Add comments about project effectiveness.
* **Evaluation Project Quality** (`evaluation_project_quality`, select_multiple, optional): Select one or more scales to evaluate project quality (e.g., High, Medium, Low).
* **Evaluation Project Quality Comment** (`evaluation_project_quality_comment`, text, optional): Add comments about project quality.
* **Evaluation Project Ease of Use** (`evaluation_project_ease_of_use`, select_multiple, optional): Select one or more scales to evaluate project ease of use (e.g., High, Medium, Low).
* **Evaluation Project Ease of Use Comment** (`evaluation_project_ease_of_use_comment`, text, optional): Add comments about project ease of use.
* **Evaluation Project Value** (`evaluation_project_value`, select_multiple, optional): Select one or more scales to evaluate project value (e.g., High, Medium, Low).
* **Evaluation Project Value Comment** (`evaluation_project_value_comment`, text, optional): Add comments about project value.
* **Evaluation Project Satisfaction** (`evaluation_project_satisfaction`, select_multiple, optional): Select one or more scales to evaluate project satisfaction (e.g., High, Medium, Low).
* **Evaluation Project Satisfaction Comment** (`evaluation_project_satisfaction_comment`, text, optional): Add comments about project satisfaction.
