# Tester Accountability Survey - Help Guide

## Purpose
This form is used to gather information about your testing status and any blockers you're currently experiencing. This information will help us track progress and identify potential issues that may impact the testing process.

## How To Complete This Form
To complete this form, simply select the most accurate options for each field and enter any relevant information in the text fields. You can select multiple options in the "Self-Assessed Accountability" field, but you must select only one option for "Test Status", "Blocker Reason", "Blocker Priority", and "Blockers".

## Field-by-Field Explanation
### 1. **Test Status** (Select One)
Select one of the following options: 
  - **Pass**: You've completed the test.
  - **Fail**: You were unable to complete the test.
  - **Blocked**: You encountered a blocker that's preventing you from proceeding.
  - **In Progress**: You're still working on the test, but you're making progress.

### 2. **Blocker Reason** (Text)
Enter a brief description of the reason for the blocker.

### 3. **Blocker Description** (Text)
Enter a detailed description of the blocker you're experiencing. This will help us understand the issue better.

### 4. **Self-Assessed Accountability** (Select Multiple)
Select all that apply:
  - **On Track**: You're making progress as expected.
  - **Behind Schedule**: You're off schedule, but you expect to catch up.
  - **Blocked**: You've encountered a blocker that's preventing you from proceeding.
  - **Unknown**: You're unsure of your progress.

### 5. **Test Cycle** (Number)
Enter the current test cycle number.

### 6. **Blocker Priority** (Select One)
Select one of the following options:
  - **Low**
  - **Medium**
  - **High**

### 7. **Blockers** (Select Multiple)
Select all that apply:
  - **Technical**
  - **Non-Technical**

## Tips
* Be as specific as possible when describing blockers.
* Only select options that accurately reflect your current situation.
* If you're unsure of your progress or have any questions, don't hesitate to reach out for assistance.
