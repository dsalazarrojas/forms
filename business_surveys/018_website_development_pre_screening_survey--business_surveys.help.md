# Website Development Pre Screening Survey - Help Guide
## Purpose
This form is designed to help project managers and team members quickly screen and assess website development projects. It captures essential information about project goals, budget, timeline, and other key details.

## How To Complete This Form
1. Fill in all the required fields marked as "required" in the form.
2. Select the correct options from the dropdown menus for "Project Goals", "Project Priority", and "Status" fields.
3. Enter the project description and contact information accurately.
4. Review and submit the form once all required fields have been filled.

## Field-by-Field Explanation

* **Lead Capture**: A dropdown menu with three options, indicating whether the project is a lead, not a lead, or maybe a lead. This field helps in identifying which projects to pursue first.
* **Project Details**: A dropdown menu with three options, representing project goals, budget, and timeline. Select the option that best describes the project.
* **Project Goals**: A text field to capture the project's main objectives.
* **Project Budget**: A numerical field to input the project's budget.
* **Project Timeline**: A date field to input the project's expected completion date.
* **Project Description**: A text field to provide a brief description of the project.
* **Contact Info**: A text field to input the contact person's email address.
* **Phone**: A text field for the contact person's phone number (optional).
* **Email**: A text field to input the contact person's email address. This field is required for communication purposes.
* **Company Details**: A text field to provide any additional company information.
* **Business Hours**: A time field to input the business hours of operation (optional).
* **Work Experience**: A text field for the contact person's work experience (optional).
* **Project Priority**: A dropdown menu with three options, indicating the project's priority level: High, Medium, or Low.
* **Follow Up**: A dropdown menu with two options, indicating whether to follow up on the project (True) or not (False).
* **Assigned Tool**: A text field to input the tool assigned to the project (optional).
* **Assigned To**: A text field for the person assigned to the project (optional).
* **Assigned At**: A date field to input the date the project was assigned (optional).
* **Status**: A dropdown menu with three options, indicating the project's status: Not Started, In Progress, or Done.
* **Notes**: A text field for project notes (optional).
* **Project Status**: A dropdown menu with three options, indicating the project's status: Active, Passive, or Archived.
* **Project Notes**: A text field for project notes (optional).
* **Project Comments**: A text field for project comments (optional).
* **Tags**: A text field for project tags (optional).
* **Submit**: A submit button to save the project information once all required fields have been filled.

Note: Please review all the required fields before submitting the form to ensure accuracy and completeness.
