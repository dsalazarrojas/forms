# Statistical Analysis Report Form - Help Guide

## Purpose
This form is used to collect relevant data for statistical analysis, specifically for business surveys. Please ensure that you have all necessary information before filling out this form.

## How To Complete This Form
- Please select the category as "Business Surveys" to ensure that your data is correctly categorized.
- Enter a brief description of the data you are submitting.
- Indicate the data source from which you collected the data.
- If the data source is not listed, select "Other" and provide the name of the data source.
- If you are uploading a file, please select the file format and size as required for statistical analysis.

## Field-by-Field Explanation

* **Statistical Analysis Report Form Input (1)** (`statistical_analysis_report_form_input`, text, not required): This field is where you can provide any additional information that is not covered by other fields in this form.
* **Category (2)** (`category`, select_one, required): Select this field to specify that the data belongs to the "Business Surveys" category.
* **Description (3)** (`description`, text, not required): This field is used to describe the data you are submitting, giving context to the statistical analysis.
* **Data Source (4)** (`data_source`, text, not required): Please indicate the source of the data you are submitting. For example, a spreadsheet, database, or external report.
* **Other (5)** (`data_source_other`, select_one, not required): If the data source is not listed, select "Other" and provide the name of the data source in the "Statistical Analysis Report Form Input" field.
* **Output File (6)** (`output_file`, number, not required): If you are uploading a file, please enter the file size as a number in bytes.

## Tips
- Please make sure to provide accurate and clear information to ensure proper statistical analysis.
- If you are unsure about any field, please contact your administrator for guidance.
- This form is for internal use only, please do not share with external parties without explicit permission.
