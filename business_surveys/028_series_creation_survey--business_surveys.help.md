# Series Creation Survey - Help Guide
## Purpose
The Series Creation Survey form is used to collect information about series creation, including series names, show IDs, concepts, target audiences, and submitter details.

## How To Complete This Form
1. Fill out all the required fields, which are marked as required (indicated by a red asterisk *).
2. Review each field carefully to ensure you are providing the correct information.
3. Use the correct format for fields with specific formats, such as email addresses and phone numbers.
4. Use commas to separate items in comma-separated list fields.
5. Be mindful of the submitter status and series status fields, which have options to track the progress of a series.

## Field-by-Field Explanation

* **Series Name (Series Name)** (`series_name`, text, required) - Enter the name of the series.
* **Show ID (Show ID)** (`show_id`, number, optional) - Enter the ID for the show.
* **Concept (Concept)** (`concept`, text, optional) - Enter a brief description of the concept.
* **Target Audience (Target Audience)** (`target_audience`, select_one, optional) - Select the target audience for the series.
	+ Options: Young Adults, Adults, Old Adults
* **Idea Description (Idea Description)** (`idea_description`, text, optional) - Enter a brief description of the series.
* **Idea Location (Idea Location)** (`idea_location`, text, optional) - Enter the location of the series.
* **Tags (Tags)** (`tags`, text, optional, comma-separated list) - Enter any relevant tags or keywords for the series.
* **Submitter Name (Submitter Name)** (`submitter_name`, text, optional) - Enter the name of the submitter.
* **Submitter Email (Submitter Email)** (`submitter_email`, email, optional) - Enter the email address of the submitter.
* **Submitter Phone (Submitter Phone)** (`submitter_phone`, text, optional) - Enter the phone number of the submitter.
* **Submitter Note (Submitter Note)** (`submitter_note`, note, optional) - Enter any notes or comments from the submitter.
* **Status (Status)** (`status`, select_one, optional) - Select the status of the series.
	+ Options: Active, In Development, Cancelled
* **Series Status (Series Status)** (`series_status`, select_multiple, optional) - Select the status of the series.
	+ Options: Active, In Development, Cancelled
* **Submission Date (Submission Date)** (`submission_date`, date, optional) - Enter the date the series was submitted.
* **Submitted By (Submitted By)** (`submitted_by`, select_one, optional) - Select the submitter.
	+ Options: Chat Jimmy, John Doe
* **Submitter Comment (Submitter Comment)** (`submitter_comment`, text, optional) - Enter any comments from the submitter.
* **Submitter Location (Submitter Location)** (`submitter_location`, text, optional) - Enter the location of the submitter.
* **Idea Type (Idea Type)** (`idea_type`, select_one, optional) - Select the type of the series.
	+ Options: Series, Show, Product, Book, Movie
* **Submitter Company (Submitter Company)** (`submitter_company`, text, optional) - Enter the company of the submitter.

Note: Some fields may have additional explanations or specific formatting requirements that are not included in this guide. If you are unsure, please refer to the original form instructions or contact the relevant authorities for clarification.
