# Risk Advisory Outcomes Survey - Help Guide
## Purpose
The purpose of the risk_advisory_outcomes_survey form is to collect data on project risk management outcomes, including risk levels, descriptions, mitigation plans, and project status. This form helps to identify areas where further improvement is needed and track project progress over time.
## How To Complete This Form
To complete the form, follow these steps:
1. Select the appropriate risk level for the project from the risk_level dropdown menu.
2. Provide a brief description of the risk, if necessary.
3. Outline any mitigation plans or strategies to mitigate the risk.
4. Choose a risk outcome (Successful, Neutral, or Unsuccessful) for the project.
5. Add a description of the risk outcome if desired.
6. Select the current project status (Active or Closed).
7. If the project is closed, enter the closed date.
8. If necessary, provide a reason for why the project was closed.
9. Set the next review date for the project, if desired.

## Field-by-Field Explanation

* **Project Info (Project Info)** (`project_info`, text, optional): Enter a brief description of the project.
* **Risk Level (risk_level)** (`risk_level`, select_one, optional): Choose the level of risk associated with the project (Low, Medium, or High).
* **Risk Description (risk_description)** (`risk_description`, text, optional): Provide a detailed description of the risk, if necessary.
* **Mitigation Plan (mitigation_plan)** (`mitigation_plan`, text, optional): Outline strategies to mitigate or reduce the risk.
* **Risk Outcome (risk_outcome)** (`risk_outcome`, select_multiple, optional): Select one or more risk outcomes for the project (Successful, Neutral, or Unsuccessful).
* **Risk Outcome Description (risk_outcome_description)** (`risk_outcome_description`, text, optional): Add a description of the risk outcome, if desired.
* **Project Status (project_status)** (`project_status`, select_one, optional): Choose the current status of the project (Active or Closed).
* **Closed Date (closed_date)** (`closed_date`, date, optional): Enter the date the project was closed, if applicable.
* **Closed Reason (closed_reason)** (`closed_reason`, text, optional): Provide a reason for why the project was closed, if necessary.
* **Next Review Date (next_review_date)** (`next_review_date`, date, optional): Set the next review date for the project, if desired.
