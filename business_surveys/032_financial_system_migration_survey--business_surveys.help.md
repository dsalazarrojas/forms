# Financial System Migration Survey - Help Guide
## Purpose
The Financial System Migration Survey is a form used to gather information about the current financial system and the system being migrated to. It is intended for IT and finance teams to assess the feasibility of migrating to a new system and understand the challenges and opportunities involved.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure that you are filling it out on behalf of your department or team.
2. Fill out the form honestly and accurately, providing as much detail as possible for each question.
3. If you are unsure about any of the questions, do not hesitate to contact your IT or finance team member for guidance.

## Field-by-Field Explanation

* **Current Finance System** (`current-finance-system`, select_one, required): This field allows you to select the current financial system being used by your organization. Please choose the option that best describes your current system.
* **Migrated Finance System** (`migrated-finance-system`, select_multiple, required): This field allows you to select the new financial system being migrated to. Please choose all options that apply.
* **Migrated To** (`migrated-to`, select_multiple, required): This field allows you to select the environment where the new financial system will be hosted (e.g., Cloud, On-Premise). Please choose all options that apply.
* **Migration Date** (`migration-date`, date, required): This field asks for the planned date of the migration. Please format the date in YYYY-MM-DD format.
* **Migration Time** (`migration-time`, time, optional): This field is optional and asks for the estimated time spent on the migration. Please use the time format (HH:MM:SS).
* **Reason** (`reason`, text, required): This field is a text box for any additional information that you want to provide about the migration.
* **Notes** (`notes`, note, required): This field is a text box for any additional comments or observations about the migration.
* **Email** (`email`, email, optional): This field is a text box for your contact email address.
* **Phone** (`phone`, text, optional): This field is a text box for your contact phone number.

Note: If you are having trouble accessing the form or have any questions, please contact your IT or finance team member for assistance.
