# Supervisor Survey - Help Guide
## Purpose
The Supervisor Survey is a form used to collect information from supervisors about upcoming events or meetings.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the event schedule and ensure you have all necessary information ready.
2. Enter the event details in the fields provided.

## Field-by-Field Explanation
* **Manager Name** (`manager_name`, text, required/optional): Enter the name of the event manager.
* **Event Name** (`event_name`, text, required/optional): Enter the name of the event or meeting.
* **Date** (`date`, date, required/optional): Enter the date of the event or meeting.
* **Start Time** (`start_time`, time, required/optional): Enter the start time of the event or meeting.
* **End Time** (`end_time`, time, required/optional): Enter the end time of the event or meeting.
* **Location** (`location`, text, required/optional): Enter the location of the event or meeting.
* **Description** (`description`, text, required/optional): Enter a brief description of the event or meeting.
* **Manager Email** (`manager_email`, email, required/optional): Enter the email address of the event manager.
* **Manager Phone** (`manager_phone`, text, required/optional): Enter the phone number of the event manager.
* **Event Date** (`event_date`, date, required/optional): Enter the date of the event or meeting (if different from the main page date).
* **Event Time** (`event_time`, time, required/optional): Enter the start time of the event or meeting (if different from the main page time).
* **Event Location** (`event_location`, text, required/optional): Enter the location of the event or meeting (if different from the main page location).
* **Event Description** (`event_description`, text, required/optional): Enter a brief description of the event or meeting (if different from the main page description).

## Tips
* Double-check the event details to ensure accuracy.
* Use a consistent format for dates and times.
* Make sure to enter the correct email and phone number for the event manager.
