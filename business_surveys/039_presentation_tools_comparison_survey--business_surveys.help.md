# Presentation Tools Comparison Survey - Help Guide
## Purpose
The Presentation Tools Comparison Survey is designed to gather information about presentation tools used in businesses. This includes rating and commenting on presentation tools such as PowerPoint, Google Slides, and Keynote.

## How To Complete This Form
1. Start by selecting the category of the presentation tool you are answering about.
2. Fill out the presentation tool name you are answering about.
3. Choose the type of presentation tool (e.g., PowerPoint, Google Slides, Keynote).
4. Rate the presentation tool (on a scale of 1-10).
5. Provide a comment about the presentation tool.
6. If you have used any other presentation tools, list them in the multiple-select field.
7. Enter your email address and phone number for contact purposes.

## Field-by-Field Explanation
* **Category** (`category`, `select_one`, required: false): Select the category of the presentation tool you are answering about. This field is optional, but it will help to sort the answers later.
* **Presentation Tool Name** (`presentation_tool_name`, `select_multiple`, required: false): List all the presentation tools you have used. Select as many as apply.
* **Presentation Tool Type** (`presentation_tool_type`, `select_one`, required: false): Choose the type of presentation tool you are answering about. Options include PowerPoint, Google Slides, and Keynote.
* **Presentation Tool Version** (`presentation_tool_version`, `text`, required: false): Enter the version of the presentation tool you are answering about.
* **Presentation Tool Rating** (`presentation_tool_rating`, `number`, required: false): Rate the presentation tool on a scale of 1-10. This will help to determine the popularity of the tool.
* **Presentation Tool Rating Comment** (`presentation_tool_rating_comment`, `text`, required: false): Provide a comment about the presentation tool. This will help to understand the reasoning behind your rating.
* **Email** (`email`, `email`, required: false): Enter your email address for contact purposes.
* **Phone** (`phone`, `text`, required: false): Enter your phone number for contact purposes.
