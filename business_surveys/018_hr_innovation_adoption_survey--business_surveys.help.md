# HR Innovation Adoption Survey - Help Guide

## Purpose
This form is designed to collect data on the adoption of HR innovations within a company, including the type of innovation, implementation status, and budget allocated. This information will help in understanding the current state of HR innovations and identify areas for improvement.

## How To Complete This Form

1. Select the relevant options for the "Survey" question that best describes the current status of HR innovations in the company.
2. Enter the number of employees within the company.
3. Select multiple options for "Implementation" that describe the types of HR tools implemented or planned to be implemented.
4. Choose the type of innovation that the company is currently adopting or planning to adopt.
5. Select the current status of the innovation adoption.
6. Enter the estimated impact of the innovation on the company.
7. Choose the status of the innovation implementation.
8. Enter the date when the innovation implementation started.
9. Enter the date when the innovation implementation ended.
10. Enter any additional notes about the innovation.
11. Select multiple options for "Company Roadmap" that describe the phases of the innovation roadmap.
12. Choose the current status of the company's innovation roadmap.
13. Enter the budget allocated for the company's innovation roadmap.
14. Enter the start date of the company's innovation roadmap.
15. Enter the end date of the company's innovation roadmap.
16. Enter any additional notes about the company's innovation roadmap.

## Field-by-Field Explanation

* **Survey**: Select an option that best describes the current status of HR innovations in the company.
	+ Adoption of new tools: Choose this option if the company has adopted new HR tools or software.
	+ New tool implementation: Choose this option if the company is implementing new tools or software.
	+ HR innovation: Choose this option if the company is innovating in HR practices or processes.
	+ Other: Choose this option if none of the above options apply.
	+ None of the above: Choose this option if the company is not innovating in HR.
* **Company**: Enter the number of employees within the company.
* **Implementation**: Select multiple options for the types of HR tools implemented or planned to be implemented.
	+ Automated HR systems: Choose this option if the company has implemented automated HR systems.
	+ HR software: Choose this option if the company has implemented HR software.
	+ HR apps: Choose this option if the company has implemented HR apps.
	+ HR hardware: Choose this option if the company has implemented HR hardware.
* **Type**: Choose the type of innovation that the company is currently adopting or planning to adopt.
	+ HR analytics: Choose this option if the company is adopting HR analytics.
	+ HR automation: Choose this option if the company is adopting HR automation.
	+ HR communication: Choose this option if the company is adopting HR communication.
	+ HR engagement: Choose this option if the company is adopting HR engagement.
	+ HR management: Choose this option if the company is adopting HR management.
	+ HR reporting: Choose this option if the company is adopting HR reporting.
* **Status**: Choose the current status of the innovation adoption.
	+ Not adopted: Choose this option if the innovation has not been adopted.
	+ Pilot: Choose this option if the innovation is in the pilot phase.
	+ Adopted: Choose this option if the innovation has been adopted.
	+ Planning: Choose this option if the innovation is planned but not implemented.
	+ Not planned: Choose this option if the innovation is not planned.
* **Impact**: Enter the estimated impact of the innovation on the company.
* **Implementation Status**: Choose the status of the innovation implementation.
	+ Not planned: Choose this option if the innovation is not planned.
	+ In progress: Choose this option if the innovation is in progress.
	+ Completed: Choose this option if the innovation has been completed.
	+ On-hold: Choose this option if the innovation is on hold.
* **Date**: Enter the date when the innovation implementation started and ended.
* **Notes**: Enter any additional notes about the innovation.
* **Company Roadmap**: Select multiple options for the phases of the company's innovation roadmap.
	+ Phase 1: Choose this option if the company is in Phase 1 of the innovation roadmap.
	+ Phase 2: Choose this option if the company is in Phase 2 of the innovation roadmap.
	+ Phase 3: Choose this option if the company is in Phase 3 of the innovation roadmap.
	+ Phase 4: Choose this option if the company is in Phase 4 of the innovation roadmap.
	+ Phase 5: Choose this option if the company is in Phase 5 of the innovation roadmap.
* **Company Roadmap Status**: Choose the current status of the company's innovation roadmap.
	+ Not started: Choose this option if the company's innovation roadmap has not started.
	+ In progress: Choose this option if the company's innovation roadmap is in progress.
	+ Completed: Choose this option if the company's innovation roadmap has been completed.
	+ On-hold: Choose this option if the company's innovation roadmap is on hold.
* **Company Roadmap Budget**: Enter the budget allocated for the company's innovation roadmap.
* **Company Roadmap Start Date**: Enter the start date of the company's innovation roadmap.
* **Company Roadmap End Date**: Enter the end date of the company's innovation roadmap.
* **Company Roadmap Notes**: Enter any additional notes about the company's innovation roadmap.

Note: Some fields may not be applicable to all companies, please fill in the applicable ones.
