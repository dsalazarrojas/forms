# Vendor Dispute Resolution Survey - Help Guide
## Purpose
This form is for reporting vendor disputes. Please use it to report any issues you have experienced with our company.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Answer the multiple-choice question on page 1.
2. Type a clear description of the dispute on page 2.
3. Provide the vendor's name in case you want to remain anonymous.
4. Select a date for the dispute.
5. If applicable, upload supporting documents (e.g., images, videos, or PDFs).
6. Select a resolution status for the dispute.
7. Provide optional feedback on your satisfaction with the resolution.
8. Optionally, describe the resolution outcome and any additional notes.

## Field-by-Field Explanation
* **Vendor Dispute Resolution** (`vendor_dispute_resolution_page`, select_multiple, required):
	+ Select 'Yes' if the dispute was resolved or 'No' if it was not.
* **Dispute Description** (`dispute_description`, text, required):
	+ A clear description of the issue you experienced with our company.
* **Vendor Name** (`vendor_name`, text, required):
	+ If you want to remain anonymous, you can leave this field blank or enter your business name instead.
* **Dispute Date** (`dispute_date`, date, required):
	+ The date the dispute occurred.
* **Supporting Documents** (`supporting_documents`, text, optional):
	+ Upload any documents related to the dispute, such as images, videos, or PDFs.
* **Resolution Status** (`resolution_status`, select_one, required):
	+ Select 'No Resolution' if no resolution was reached, 'Pending' if it's still in progress, or 'Completed' if it was resolved.
* **Satisfaction Feedback** (`satisfaction_feedback`, text, optional):
	+ Share your thoughts on how satisfied you were with the resolution.
* **Resolution Outcome** (`resolution_outcome`, text, optional):
	+ Describe the outcome of the resolution, if any.
* **Resolution Notes** (`resolution_notes`, text, optional):
	+ Add any additional notes on the resolution process.
* **Supporting Documents Uploads** (`supporting_document_uploads`, select_multiple, required):
	+ Select 'Yes' to upload supporting documents, 'No' otherwise.
