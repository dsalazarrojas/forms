# network_service_evaluation_survey - Help Guide
## Purpose
This form is designed to gather feedback and opinions from customers or users of a network service. It helps to evaluate the performance and quality of the service, providing valuable insights to improve it.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each question carefully and answer them accordingly.
2. Select the options that best describe your experience with the network service.
3. Provide detailed comments and feedback in the "Comments" field.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, required: false): A text field where you can provide any additional information about your experience with the network service.
* **Network Performance** (`network_performance`, select_one, required: false): Select one of the options that best describes your experience with the network performance.
	+ Option 1: Very good
	+ Option 2: Good
	+ Option 3: Poor
* **Network Quality** (`network_quality`, select_multiple, required: false): Select all the options that best describe your experience with the network quality.
	+ Option 1: Very good
	+ Option 2: Good
	+ Option 3: Poor
* **Service Improvement** (`service_improvement`, text, required: false): A text field where you can suggest improvements for the network service.
* **Customer Satisfaction** (`customer_satisfaction`, select_one, required: false): Select one of the options that best describes your customer satisfaction.
	+ Option 1: Very satisfied
	+ Option 2: Satisfied
	+ Option 3: Dissatisfied
* **Feedback** (`feedback`, text, required: false): A text field where you can provide any additional feedback about the network service.
* **Comments** (`comments`, note, required: false): A field for any detailed comments you may have about the network service.
* **Email** (`email`, email, required: false): Enter your email address if you would like to receive further communication about the network service.
* **Phone** (`phone`, text, required: false): Enter your phone number if you would like to receive further communication about the network service.
