# Creative Planning Survey - Help Guide
## Purpose
The Creative Planning Survey is a form used to collect and organize information about creative projects. It helps to identify key details such as title, category, description, and assigned tool. This form is used to create a comprehensive understanding of a project's scope and requirements.

## How To Complete This Form
To complete the Creative Planning Survey, follow these steps:

1. Enter the **Title** of the project in the "Title" field. This is the main heading of the project.
2. Select the **Category** of the project in the "Category" field. This field is used to classify the project for easy filtering and searching.
3. Provide a brief **Description** of the project in the "Description" field. This is a short summary of the project's goals and objectives.
4. Enter a list of **Form IDs** (if applicable) in the "Form IDs" field. This field is used to identify associated forms or projects.
5. Select the **Assigned Tool** used for the project in the "Assigned Tool" field. This field is used to identify the tool or software used to manage or execute the project.
6. Enter a file name in the "Output File" field for the project's output file.
7. Provide an optional **Description** of the project in the "Description" field. This is an additional, more detailed explanation of the project.
8. Select a **Category** for the project (if not already selected). This field is used to further classify the project.

## Field-by-Field Explanation
* **Title (Text, Required)**: Enter a brief title for the project.
* **Category (Text, Optional)**: Select a category for the project to make it easier to find and filter.
* **Description (Text, Optional)**: Enter a short description of the project.
* **Form IDs (Number, Optional)**: Enter any associated form IDs (if applicable).
* **Assigned Tool (Text, Optional)**: Select the tool or software used for the project.
* **Output File (Text, Optional)**: Enter a file name for the project's output.
* **Description (Text, Optional)**: Enter a more detailed description of the project.
* **Category (Text, Optional)**: Select a category for the project.
* **Notes (Note, Optional)**: Enter any notes or additional information about the project.
