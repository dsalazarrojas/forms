# real_estate_tech_efficiency_survey - Help Guide
## Purpose
The "real_estate_tech_efficiency_survey" is a survey designed to collect information about the technology used by real estate companies. It is used to assess current technology usage and identify areas for improvement.

## How To Complete This Form
To complete the form, follow these steps:

* Begin with the first page, which asks for contact information.
* Select the correct contact type (Company or Individual).
* Proceed to the next page, which asks for company details.
* Enter the required company details in the corresponding text fields.
* Move on to the next page, which asks about software used.
* Select all the software currently used by your company from the list.
* Continue to the next page, which asks for additional company details.
* Enter the required details in the corresponding text fields.
* Proceed to the last page, which asks for submission information.
* Select the correct submission type (Admin, Staff, or Manager).

## Field-by-Field Explanation
* **Contact Information (Page 1)**
	+ **Contact Type (Company/Individual):** Select whether the contact is a company or an individual.
* **Company Details (Page 2)**
	+ **Company Details Field 1:** Enter a brief description of your company.
* **Software Used (Page 3)**
	+ **Software Used:** Select all the software currently used by your company.
* **Additional Company Details (Page 4)**
	+ **Company Details Field 2:** Enter the number of employees in your company.
* **Software Used (Page 5)**
	+ **Software Used Field 1:** Enter the number of years using the software.
* **Additional Company Details (Page 6)**
	+ **Company Details Field 3:** Enter the software version used.
* **Software Used (Page 7)**
	+ **Software Used Field 2:** Enter the software cost per user.
* **Additional Company Details (Page 8)**
	+ **Company Details Field 4:** Enter the number of users.
* **Software Used (Page 9)**
	+ **Software Used Field 3:** Enter the last update date of the software.
* **Additional Company Details (Page 10)**
	+ **Company Details Field 5:** Enter a brief description of the software's purpose.
* **Submission Information (Page 11)**
	+ **Submitted By:** Select who submitted the survey (Admin, Staff, or Manager).
