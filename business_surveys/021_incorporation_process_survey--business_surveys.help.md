# incorporation_process_survey - Help Guide
## Purpose
The "Incorporation Process Survey" form is designed to collect feedback and suggestions from business users on how to improve the incorporation process for law firms, corporate service providers, and business registries.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for the "Form Helps" field, which includes law firms, corporate service providers, and business registries.
2. Provide a clear and concise description of the incorporation process in the "Incorporation Process Journey" field, if necessary.
3. If you have any feedback or comments, use the "Incorporation Process Feedback" field for a note or comment.
4. Enter your email address in the "Email" field, if you want to receive updates on the form results.
5. Enter your phone number in the "Phone" field, if you want to be contacted for further discussions.
6. Provide a brief description of the form in the "Form Description" field, if necessary.
7. Select the category for this form from the "Category" field, which is "Business Surveys".
8. If you want to assign a unique ID to this form, enter it in the "Form ID" field.
9. Finally, select the tool used for this form from the "Tool" field, if applicable.

## Field-by-Field Explanation

* **Steps** (`steps`, text, required): Describe the steps involved in the incorporation process.
* **Form Helps** (`form_helps`, select_multiple, required): Select the relevant options to help with the incorporation process, such as law firms, corporate service providers, and business registries.
* **Incorporation Process Journey** (`journey`, text, optional): Provide a detailed description of the incorporation process, if necessary.
* **Incorporation Process Feedback** (`feedback`, note, optional): Enter your feedback, comments, or suggestions on how to improve the incorporation process.
* **Email** (`email`, email, optional): Enter your email address to receive updates on the form results, if applicable.
* **Phone** (`phone`, text, optional): Enter your phone number to be contacted for further discussions, if applicable.
* **Form Description** (`form_description`, text, optional): Briefly describe the form and its purpose, if necessary.
* **Category** (`category`, select_one, required): Select the category for this form, which is "Business Surveys".
* **Form ID** (`form_id`, number, optional): Enter a unique ID for this form, if desired.
* **Tool** (`tool`, text, optional): Select the tool used for this form, if applicable.
