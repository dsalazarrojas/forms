# Anti Steering Disclosure Form - Help Guide
## Purpose
The Anti Steering Disclosure Form is designed to capture the details of loan options presented to a borrower, ensuring transparency and compliance with regulations. This form helps maintain accurate records and promotes a smooth lending process.

## How To Complete This Form
1. Fill in the borrower's name and the loan officer's name in the respective fields.
2. Provide a brief description of the loan options discussed with the borrower.
3. Confirm whether the borrower acknowledged the options presented.
4. If applicable, select the loan option chosen by the borrower.
5. Add any additional notes about the conversation or loan process.
6. Record the date of the discussion.

## Field-by-Field Explanation
* **Borrower name** (Required): Enter the full name of the applicant.
* **Loan officer name** (Required): Type in the name of the staff member who discussed the loan options with the borrower.
* **Loan options presented** (Required): Provide a brief description of the loan options that were discussed.
* **Borrower acknowledgement** (Required): Confirm whether the borrower acknowledged the loan options.
* **Borrower preference** (Optional): If applicable, select the loan option chosen by the borrower.
* **Date recorded** (Optional): Enter the date of the discussion.
* **Additional notes** (Optional): Add any other commentary or observations about the conversation or loan process.

**Tips**
- Ensure that you fill in all required fields.
- Be concise and accurate when describing the loan options and borrower acknowledgement.
- Use the date format MM/DD/YYYY to record the date of the discussion.
- If you have any additional comments or observations, please use the additional notes field.
