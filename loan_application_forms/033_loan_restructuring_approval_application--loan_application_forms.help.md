# Loan Restructuring Approval Application - Help Guide

## Purpose
The Loan Restructuring Approval Application form is used to request changes to a previously submitted loan application. This form allows the borrower and loan officer to update loan details, including the amount, term, and type of loan.

## How To Complete This Form
To complete this form, follow these steps:

1. Review and understand the form's fields and their requirements.
2. Fill in the fields as prompted by the system.
3. Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Form Header** (`form_header`, note, not required): This is the title of the form that appears at the top of the page.
* **Borrower Details** (`borrower_details`, text, not required): Enter the borrower's name, address, or any other relevant information.
* **Loan Amount** (`loan_amount`, number, not required): Enter the original loan amount.
* **Restructure Amount** (`restructure_amount`, number, not required): Enter the proposed amount for the loan modification.
* **Loan Term** (`loan_term`, time, not required): Enter the proposed term for the loan modification.
* **Approval Status** (`approval_status`, select_one, not required): Select the current status of the loan application from the options provided (Approved, Denied, Under Review).
* **Loan Type** (`loan_type`, select_one, not required): Select the type of loan from the options provided (Business Loan, Personal Loan).
* **Contact Method** (`contact_method`, select_multiple, not required): Select the preferred method of contact (Email, Phone Call, SMS).
* **Email** (`email`, email, not required): Enter the borrower's email address.
* **Phone** (`phone`, text, not required): Enter the borrower's phone number.

## Tips
* Ensure all required fields are completed before submitting the form.
* Verify the accuracy of the information entered before submission.
* Use the form only for loan applications that require modification.
* If you are unsure about any field, contact the loan officer for guidance.
* Review and update the form regularly to reflect any changes to the loan application.
