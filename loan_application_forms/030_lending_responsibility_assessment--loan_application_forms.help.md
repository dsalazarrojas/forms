# Lending Responsibility Assessment - Help Guide
## Purpose
The Lending Responsibility Assessment form is used to evaluate the creditworthiness of individuals or businesses. It helps lenders assess their ability to repay loans and credit obligations.

## How To Complete This Form
To complete this form, please provide the following information:

1. **Borrower Name**: Enter your name as it appears on your identification documents.
2. **Employment Status**: Select one of the provided options that best describes your current employment situation.
3. **Annual Income**: Enter your annual income, if applicable.
4. **Monthly Debt**: Enter your monthly debt obligations, if applicable.
5. **Monthly Expenses**: Select all monthly expenses that apply to you, if any.
6. **Credit Score**: Select the option that best describes your credit score.
7. **Income Verification**: If you have an income verification document, select "True". If not, select "False".
8. **Employment Verification**: If you have an employment verification document, select "True". If not, select "False".

## Field-by-Field Explanation
* **Borrower Name**: This field is required to identify the individual or business applying for a loan.
* **Employment Status**: This field helps assess your current employment situation. Select the option that best describes your circumstances.
* **Annual Income**: If you have an annual income, enter it here. This field is not required if you select "Unemployed", "Retired", or "Disabled".
* **Monthly Debt**: If you have monthly debt obligations, enter the amount here. This field is not required if you select "Unemployed", "Retired", or "Disabled".
* **Monthly Expenses**: Select all applicable monthly expenses from the options provided. This field is not required if you have no monthly expenses.
* **Credit Score**: This field helps assess your creditworthiness. Select the option that best describes your credit score.
* **Income Verification**: If you have an income verification document, select "True". If not, select "False".
* **Employment Verification**: If you have an employment verification document, select "True". If not, select "False".

## Tips
* Ensure the information provided is accurate and up-to-date.
* If you are unsure about any field, please ask for assistance.
* Please note that this form is for assessment purposes only and does not guarantee approval or denial of a loan.
