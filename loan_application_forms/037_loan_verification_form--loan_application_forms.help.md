# loanVerificationForm - Help Guide
## Purpose
The loanVerificationForm is a tool for loan officers to gather necessary information from loan requesting parties to evaluate loan applications.

## How To Complete This Form

1.  Review the form fields and ensure you understand what information is being requested.
2.  Fill in the requested information for the loan requesting party.
3.  Ensure you have all necessary supporting documents before completing the form.
4.  Submit the completed form for review and processing.

## Field-by-Field Explanation

* **Loan Request Date** (`loan_request_date`, date, required): Enter the date the loan was requested.
* **Customer Name** (`customer_name`, text, optional): Enter the name of the customer.
* **Loan Amount** (`loan_amount`, number, optional): Enter the amount of the loan.
* **Loan Term** (`loan_term`, select_one, optional): Select the loan term (e.g., Yes or No).
* **Loan Type** (`loan_type`, select_multiple, optional): Select the loan type (e.g., Option 1 or Option 2).
* **Loan Status** (`loan_status`, select_one, optional): Select the loan status (e.g., Active or Inactive).
* **Contact Method** (`contact_method`, select_multiple, optional): Select the method of contact (e.g., Option 1 or Option 2).
* **Notes** (`notes`, note, optional): Add any additional notes about the loan.
* **Loan Agreement Signed** (`loan_agreement_signed`, select_one, optional): Indicate if the loan agreement is signed (e.g., Yes or No).
* **Contact Details** (`contact_details`, select_multiple, optional): Indicate if contact details are included (e.g., Yes or No).
* **Employment Status** (`employment_status`, select_one, optional): Select the employment status (e.g., Active or Inactive).
* **Income Source** (`income_source`, select_multiple, optional): Select the income source (e.g., Yes or No).
* **Income Verification Documents** (`income_verification_documents`, select_multiple, optional): Indicate if income verification documents are included (e.g., Yes or No).
* **Loan Officer Notes** (`loan_officer_notes`, note, optional): Add any notes from the loan officer.
* **Customer Signature** (`customer_signature`, select_one, optional): Indicate if the customer signature is available (e.g., Yes or No).
* **Customer Signature Date** (`customer_signature_date`, date, optional): Enter the date of the customer signature.
* **Loan Officer Signature** (`loan_officer_signature`, select_one, optional): Indicate if the loan officer signature is available (e.g., Yes or No).
* **Loan Officer Signature Date** (`loan_officer_signature_date`, date, optional): Enter the date of the loan officer signature.
* **Loan Status Comments** (`loan_status_comments`, note, optional): Add any comments about the loan status.
* **Customer Notes** (`customer_notes`, note, optional): Add any additional notes from the customer.
* **Loan Requesting Party** (`loan_requesting_party`, select_multiple, optional): Indicate if the loan requesting party is the customer (e.g., Yes or No).
* **Loan Requesting Party Address** (`loan_requesting_party_address`, text, optional): Enter the address of the loan requesting party.
* **Loan Requesting Party Phone** (`loan_requesting_party_phone`, text, optional): Enter the phone number of the loan requesting party.
* **Loan Requesting Party Email** (`loan_requesting_party_email`, email, optional): Enter the email of the loan requesting party.
* **Loan Requesting Party Business Phone** (`loan_requesting_party_business_phone`, text, optional): Enter the business phone number of the loan requesting party.
