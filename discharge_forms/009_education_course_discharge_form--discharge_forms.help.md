# Education Course Discharge Form - Help Guide
## Purpose
The Education Course Discharge Form is a document used to formally notify the education institution and other relevant parties that a student has been discharged from a course. This form is used to record the circumstances surrounding the student's discharge and ensure a smooth transition for the student and staff.

## How To Complete This Form
1. Review the form carefully and ensure you have all necessary information before proceeding.
2. Select the correct withdrawal option from the "Withdrawal Form" field.
3. Provide a clear and concise description of the student's feedback, if applicable.
4. Choose the correct course information option from the "Course Information" field.
5. Select the reason for withdrawal from the "Reason for Withdrawal" field.
6. Enter any additional comments or remarks about the discharge process.
7. Record the date and time of the last class attended.
8. Report on the student's last class attendance, if applicable.
9. Enter the discharge date, which is the date the student is officially discharged from the course.
10. Outline the next steps to be taken after discharge.
11. Enter the name of the staff member submitting the form.

## Field-by-Field Explanation
* **Withdrawal Form (<type> select_multiple, required: false)**: Select "Yes" if the student has withdrawn from the course, "No" otherwise.
* **Student Feedback (<type> text, required: false)**: Enter a clear and concise description of the student's feedback, if applicable.
* **Course Information (<type> select_one, required: false)**: Choose the correct course information option that best describes the student's situation.
* **Reason for Withdrawal (<type> select_one, required: false)**: Select the reason for the student's withdrawal from the course.
* **Comments (<type> text, required: false)**: Enter any additional comments or remarks about the discharge process.
* **Date of Last Class (<type> date, required: false)**: Record the date of the last class attended by the student.
* **Time of Last Class (<type> time, required: false)**: Record the time of the last class attended by the student.
* **Last Class Attendance (<type> text, required: false)**: Report on the student's last class attendance, if applicable.
* **Discharge Date (<type> date, required: false)**: Enter the official discharge date of the student.
* **Next Steps (<type> text, required: false)**: Outline the next steps to be taken after discharge.
* **Submitted By (<type> text, required: false)**: Enter the name of the staff member submitting the form.
