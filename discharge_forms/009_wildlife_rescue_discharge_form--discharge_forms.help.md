# Wildlife Rescue Discharge Form - Help Guide
## Purpose
This form is used to document the release of a rescued animal from a wildlife sanctuary or rescue organization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure that you have been authorized to access this form.
2. Gather the required information about the animal:
	* Animal Species
	* Animal Name
	* Animal Type
3. Provide details about the rescue and discharge:
	* Rescue Date
	* Discharge Date
	* Discharge Location
4. Specify the new guardian's contact details:
	* New Guardian Name
	* New Guardian Phone

## Field-by-Field Explanation
* **Animal Species** (`animal_species`, text, optional):
	* Enter the species of the animal being released (e.g. "Canis lupus" for a wolf, "Felis catus" for a domestic cat).
* **Animal Name** (`animal_name`, text, optional):
	* Enter the name of the animal being released (if known).
* **Animal Type** (`animal_type`, text, optional):
	* Enter a brief description of the animal's type (e.g. "mammal", "bird", "reptile").
* **Rescue Date** (`rescue_date`, date, optional):
	* Enter the date the animal was rescued (if known).
* **Discharge Date** (`discharge_date`, date, required):
	* Enter the date the animal is being released.
* **Discharge Location** (`discharge_location`, text, optional):
	* Enter the location where the animal is being released.
* **New Guardian Name** (`new_guardian_name`, text, optional):
	* Enter the name of the new guardian or caregiver taking responsibility for the animal.
* **New Guardian Phone** (`new_guardian_phone`, text, optional):
	* Enter the contact phone number of the new guardian or caregiver.
	* Please ensure that the new guardian has granted permission for their information to be shared with the rescue organization.
* **Tips**
	+ Be as accurate as possible when filling out the form.
	+ Ensure that all required fields are completed before submitting the form.
	+ If any field does not apply, please leave it blank or enter "N/A" (not applicable).
	+ If you are unsure about any information, please contact the rescue organization for guidance.
