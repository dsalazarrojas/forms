# financial_advisory_discharge_form - Help Guide
## Purpose
The financial advisory discharge form is used to document the end of a relationship between a financial institution and a client. This form is intended to be completed by an authorized user to accurately and clearly record the details of the discharge.

## How To Complete This Form
To complete this form, follow these steps:

*   Ensure you have all necessary information and permissions before starting the form.
*   Review the form carefully to understand the fields and questions asked.
*   Fill out the form with the correct information and answers.
*   Review and verify the information before submitting the form.

## Field-by-Field Explanation
*   **end_of_relationship** (page 1): This field is a note field where you can enter the reason for the discharge or a brief summary of the relationship termination. It's not a mandatory field.
*   **client_name** (page 1): This field requires the name of the client. Enter the full name of the client as it appears on public records.
*   **financial_institution** (page 1): Enter the name of the financial institution involved in the relationship being discharged.
*   **institution_id** (page 1): Enter the ID number or code of the financial institution (if applicable).
*   **financial_institution_type** (page 1): Select 'Yes' or 'No' to indicate if the financial institution type is present or not.
*   **reason_for_discharge** (page 1): This field asks for multiple selections of reasons for discharge. Select all applicable reasons from the list.
*   **advisory_discharge_date** (page 1): Enter the date of the financial advisory discharge in the format 'YYYY-MM-DD' (year-month-day).
*   **advisory_discharge_note** (page 1): This field is a note field for any additional information about the financial advisory discharge.
*   **assigned_tool** (page 1): Enter any specific tool or system used to assist with the discharge.
*   **user** (page 1): Enter your user ID or name for tracking purposes.

## Tips
*   Ensure all fields marked as 'required' are completed before submitting the form.
*   Be accurate and clear in your input to avoid errors or miscommunication.
*   Use the correct format for date entries (YYYY-MM-DD).
