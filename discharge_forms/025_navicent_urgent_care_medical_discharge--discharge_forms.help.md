# navicentUrgentCareMedicalDischarge - Help Guide
## Purpose
This form is used to gather information on a patient's medical discharge from Navicent Health System.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Ensure you have all the necessary information on the patient's identification and medical history.
2. Fill out each field as instructed, paying attention to any required fields marked as "required".
3. Review each field for clarity and accuracy before submitting the form.

## Field-by-Field Explanation

* **patientid** (1, Number): Enter the patient's identification number.
* **patientsdob** (2, Date): Enter the patient's date of birth.
* **patientsname** (3, Text): Enter the patient's name.
* **patientssex** (4, Select One): Select 'Yes' or 'No' to indicate the patient's sex.
* **patientsaddressstreet** (5, Text): Enter the patient's street address.
* **patientsaddresscity** (6, Text): Enter the patient's city.
* **patientsaddressstate** (7, Select One): Select 'Yes' or 'No' to indicate the patient's address state.
* **patientsaddresspostalzip** (8, Text): Enter the patient's postal zip code.
* **patientsaddressphone** (9, Text): Enter the patient's phone number.
* **patientsmedicallastname** (10, Text): Enter the patient's last medical name.
* **patientsmedicarenumber** (11, Text): Enter the patient's Medicare number.
* **patientsdiagnosis** (12, Select Multiple): Select all applicable medical diagnoses.
* **patientscondition** (13, Select Multiple): Select all applicable medical conditions.
* **patientsreasonfordischarge** (14, Text): Enter the reason for discharge.
* **patientsdischargedate** (15, Date): Enter the date of discharge.
* **patientsdischargedoctor** (16, Select One): Select 'Yes' or 'No' to indicate whether the doctor is discharging the patient.
* **patientsdischargedateofdischarge** (17, Date): Enter the date of discharge.
* **patientsdischargedoctorname** (18, Text): Enter the doctor's name discharging the patient.
* **patientsreasonfordoctorvisit** (19, Text): Enter the reason for the doctor's visit.
* **patientsvisitcount** (20, Number): Enter the total number of visits.
* **patientsdiagnosiscode** (21, Select Multiple): Select all applicable diagnosis codes.
* **patientsicdcodes** (22, Select Multiple): Select all applicable ICD codes.
* **patientsdischargeduration** (23, Select One): Select 'Yes' or 'No' to indicate the duration of discharge.
* **patientsdischargestatus** (24, Select One): Select 'Active' or 'Inactive' to indicate the patient's discharge status.
* **patientsfollowupinstructions** (25, Text): Enter any follow-up instructions for the patient.
