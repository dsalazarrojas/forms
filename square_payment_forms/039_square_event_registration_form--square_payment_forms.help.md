# Square Event Registration Form - Help Guide
## Purpose
This form is used to register events with Square, collecting information for payment processing and event management.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Name field with the name of the event you are registering.
2. Enter the Event Date in the format MM/DD/YY.
3. Select the Event Time using the time input field.
4. Enter the Event Location in the format you would like to appear in Square's payment interface.
5. List the Attendees, separated by commas, in the field provided.
6. Enter the Payment Amount in USD.
7. Select the Payment Method from the available options.
8. Enter your Email address for verification and communication purposes.

## Field-by-Field Explanation
* **Event Name (1)**: A text field where you enter the name of the event.
* **Event Date (2)**: A date field where you enter the date of the event in MM/DD/YY format.
* **Event Time (3)**: A time field where you select the time of the event.
* **Event Location (4)**: A text field where you enter the location of the event.
* **Attendees (5)**: A text field where you list the attendees, separated by commas.
* **Payment Amount (6)**: A number field where you enter the payment amount in USD.
* **Payment Method (7)**: A select field where you choose the payment method from the options provided (Visa, Mastercard, Amex).
* **Email (8)**: An email field where you enter your email address for verification and communication purposes.

## Tips
* Please ensure that you have all the necessary information before submitting this form.
* Be careful when entering the Payment Amount to avoid errors.
* If you need to make changes to a previously registered event, contact your Square support team for assistance.
