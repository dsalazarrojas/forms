# Innovation Lab Referral Form - Help Guide
## Purpose
This form is used to refer a project to the Innovation Lab, ensuring that it aligns with the lab's interests and goals. 
## How To Complete This Form

To complete this form, follow the steps below:

1. Provide User Information: This section captures the details of the referring user.
* **User Information** (`user_info`, `text`, required: false): Enter your name and email address to identify yourself as the referring user.
2. Project Details: This section captures the project description and owner details.
* **Project Details** (`project_info`, `text`, required: false): Enter a brief description of the project.
* **Project Owner** (`project_owner`, `text`, required: false): Provide the name and email address of the project owner.
3. Project Status: This section captures the current status of the project.
* **Project Status** (`project_status`, `select_one`, required: false): Choose the status of the project from the available options: In progress, On-hold, or Completed.
4. Innovation Area: This section captures the innovation area that the project belongs to.
* **Innovation Area** (`innovation_area`, `select_one`, required: false): Choose the innovation area that the project belongs to from the available options: Artificial Intelligence, Data Science, or Cyber Security.
5. Project Contact: This section captures the contact information of the project.
* **Project Contact** (`project_contact`, `text`, required: false): Provide the name and email address of the project contact.
6. Project Link: This section captures the link to the project.
* **Project Link** (`project_link`, `text`, required: false): Provide the URL or link to the project.
7. Project Description: This section captures a detailed description of the project.
* **Project Description** (`project_description`, `text`, required: false): Provide a brief description of the project.
8. Project Tags: This section captures the tags associated with the project.
* **Project Tags** (`project_tags`, `select_multiple`, required: false): Choose multiple tags that best describe the project from the available options: AI-powered, Data-driven, Security-focused, or Innovation-driven.
9. Lab Interests: This section captures the interests of the lab.
* **Lab Interests** (`lab_interests`, `select_multiple`, required: false): Choose multiple interests that align with the lab's interests from the available options: AI-powered, Data-driven, Security-focused, or Innovation-driven.

## Tips

* Ensure that you have all the necessary permissions and approvals before submitting a referral.
* Be accurate and detailed when filling out the form to ensure that the project is properly assessed.
* If you are unsure about any field, you can contact the Innovation Lab for assistance.
