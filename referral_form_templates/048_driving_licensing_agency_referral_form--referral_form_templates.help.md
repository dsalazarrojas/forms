# driving_licensing_agency_referral_form - Help Guide
## Purpose
This form is used to refer an applicant to a driving licensing agency. It captures essential information about the applicant and the referral process.

## How To Complete This Form

1. Fill in the required fields: `First Name`, `Last Name`, `Email`, `Date of Birth`, `License Number`, `License Type`, `Address`, `City`, `State`, `Zip`, and `Country`.
2. Select the `License Type` from the options provided.
3. Fill in the `Phone` field if required (not required for submission).
4. Fill in the `Referral Request` field with the reason for the referral.
5. Set the `Follow-up` date and time.
6. Select the `License Officer` and `Team` if applicable.
7. Set the `Submitted` field to indicate if the form has been submitted.
8. Fill in the `Follow-up By` field with the name of the person following up.
9. Fill in the `Team Leader` field with the name of the team leader.

## Field-by-Field Explanation
### First Name (1)
* A text input field for the applicant's first name.
### Last Name (2)
* A text input field for the applicant's last name.
### Email (3)
* An email input field for the applicant's email address.
### Phone (4)
* A text input field for the applicant's phone number.
### Date of Birth (5)
* A date input field for the applicant's date of birth.
### License Number (6)
* A text input field for the applicant's license number.
### License Type (7)
* A select-one input field for the type of license.
* Options: Commercial, Private, Motorcycle, Motorcycle Endorsement.
### Address (8)
* A text input field for the applicant's address.
### City (9)
* A text input field for the city where the applicant resides.
### State (10)
* A text input field for the state where the applicant resides.
### Zip (11)
* A number input field for the applicant's zip code.
### Country (12)
* A text input field for the country of residence.
### License Officer (13)
* A select-multiple input field for the license officer.
* Options: Officer 1, Officer 2, Officer 3.
### Team (14)
* A select-one input field for the team.
* Options: Team 1, Team 2, Team 3.
### Follow-up (15)
* A date input field for the follow-up date.
### Follow-up Time (16)
* A time input field for the follow-up time.
### Notes (17)
* A note input field for any additional notes.
### Referral Request (18)
* A text input field for the referral request.
### Submitted (19)
* A select-one input field to indicate if the form has been submitted.
* Options: True, False.
### Submitted Date (20)
* A date input field for the submitted date.
### Submitted Time (21)
* A time input field for the submitted time.
### Submitted By (22)
* A text input field for the name of the person submitting the form.
### Follow-up By (23)
* A text input field for the name of the person following up.
### Team Leader (24)
* A text input field for the name of the team leader.
### Assigned Tool (25)
* A text input field for the assigned tool.

Note: The fields marked as required are mandatory and must be filled out. The fields not marked as required are optional and can be filled out if applicable.
