# Cybersecurity Data Recovery Referral Form - Help Guide
## Purpose
This form is used for referring or reporting cybersecurity incidents or data breaches.

## How To Complete This Form
1. Fill out all the required fields.
2. Answer each question accurately and thoroughly.
3. Use the available options and hints for guidance.

## Field-by-Field Explanation

* **User Name** (`user_name`, text, required): This is the name of the person filling out the form.
* **Company** (`company`, text, optional): If you are representing a company, please enter the name of the company.
* **Job Title** (`job_title`, text, optional): This is your job title or position.
* **Description** (`description`, text, optional): A brief description of the incident or issue.
* **Category** (`category`, select_one, optional): Select one of the available options (Yes/No).
* **Risk Level** (`risk_level`, select_one, optional): Select one of the available options (High/Low).
* **Urgency** (`urgency`, select_one, required): Select one of the available options (Yes/No).
* **Priority** (`priority`, select_one, required): Select one of the available options (Yes/No).
* **Status** (`status`, select_one, required): Select one of the available options (Active/Inactive).
* **Incident Type** (`incident_type`, select_multiple, required): Select all applicable options (Yes/No).
* **Impact** (`impact`, select_multiple, optional): Select all applicable options (Yes/No).
* **Date** (`date`, date, optional): Enter the date of the incident.
* **Time** (`time`, time, optional): Enter the time of the incident.
* **Notes** (`notes`, note, optional): Enter any additional notes or comments about the incident.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Contact** (`email_phone`, text, required): Enter your name, email, and phone number.
* **Submit** (`submit`, text, required): Enter your name.
* **Is Company Aware?** (`company_aware`, select_one, optional): Select one of the available options (Yes/No).
* **Is Report Available?** (`report`, select_one, optional): Select one of the available options (Yes/No).
* **Incident Report** (`incident_report`, text, optional): Enter the URL of the incident report.
* **Attachment** (`attachment`, text, optional): Upload any attachments related to the incident.
* **Is User Aware?** (`user_aware`, select_one, optional): Select one of the available options (Yes/No).
* **Incident Report URL** (`incident_report_url`, text, optional): Enter the URL of the incident report.
* **Name of Submitter** (`submitter_name`, text, required): Enter your name.

## Tips

* Please answer each question accurately and thoroughly.
* Use the available options and hints for guidance.
* If you are unsure about any field, please contact the support team.
