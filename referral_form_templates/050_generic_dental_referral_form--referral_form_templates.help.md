# Generic Dental Referral Form - Help Guide

## Purpose
This form is designed to gather information from the patient and doctor for referrals to other healthcare providers or facilities. It should only be used for new patient referrals and not for resubmitting information already provided.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the required fields with accurate and thorough information.
2. Ensure that all fields are filled out completely before submitting the form.

## Field-by-Field Explanation

* **Patient Info** (page 1)
	+ Label: Patient Info
	+ Type: text
	+ Required: false
	+ Explanation: Fill in the patient's name, date of birth, and contact information.
* **Dental Info** (page 1)
	+ Label: Dental Info
	+ Type: text
	+ Required: false
	+ Explanation: Provide a description of the patient's current dental condition, including relevant medical history and treatment plans.
* **Specialty Services** (page 2)
	+ Label: Specialty Services
	+ Type: select_multiple
	+ Required: false
	+ Explanation: Check the boxes for any specialty services the patient may require, such as orthodontics, oral surgery, or pediatric dentistry.
* **Referral Info** (page 2)
	+ Label: Referral Info
	+ Type: text
	+ Required: false
	+ Explanation: Fill in the referral information, including the patient's medical record number, insurance information, and relevant medical history.
* **Doctor Notes** (page 3)
	+ Label: Doctor Notes
	+ Type: text
	+ Required: false
	+ Explanation: Add any relevant notes from the doctor, including the patient's current treatment plan and any medications being taken.
* **Referral Date** (page 3)
	+ Label: Referral Date
	+ Type: date
	+ Required: false
	+ Explanation: Select the date of the referral.
* **Referral Reason** (page 3)
	+ Label: Referral Reason
	+ Type: text
	+ Required: false
	+ Explanation: Describe the reason for the referral.
* **Patient Signature** (page 4)
	+ Label: Patient Signature
	+ Type: select_one
	+ Required: false
	+ Explanation: The patient must sign to confirm they have read and understand the above information.

## Tips

* Make sure to fill out all required fields thoroughly and accurately.
* Double-check the patient's contact information for accuracy.
* Ensure that the referral information is clear and concise.
* Review the form carefully before submitting it for accuracy and completeness.
