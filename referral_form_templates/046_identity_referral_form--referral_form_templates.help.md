# Identity Referral Form - Help Guide

## Purpose
The Identity Referral Form is used to collect and track referrals for identity-related purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a category for the referral from the options provided.
2. Provide a brief description of the referral.
3. Enter the name of the organization involved.
4. Add any relevant referral details.
5. Confirm consent for the referral.
6. Add any follow-up information if necessary.
7. Enter contact details.
8. Provide email and phone number (if applicable).
9. Set follow-up dates and times (if applicable).
10. Specify the next follow-up date and time (if applicable).

## Field-by-Field Explanation

* **Identity Referral Form** (`form_title`, text, optional): Enter a brief title for the referral.
* **Category** (`category`, select_one, optional): Select a category for the referral from the options provided.
* **Description** (`description`, text, optional): Provide a brief description of the referral.
* **Organization** (`organization`, text, optional): Enter the name of the organization involved.
* **Referral Details** (`referral_details`, note, optional): Add any relevant referral details.
* **Consent Confirmation** (`consent_confirmation`, select_multiple, optional): Confirm whether consent is given or not.
* **Follow-up Information** (`follow_up_information`, text, optional): Add any follow-up information if necessary.
* **Contact Details** (`contact_details`, note, optional): Enter contact details for follow-up purposes.
* **Email** (`email`, email, optional): Enter a valid email address.
* **Phone Number** (`phone_number`, text, optional): Enter a valid phone number.
* **Follow-up Date** (`follow_up_date`, date, optional): Set a follow-up date if applicable.
* **Follow-up Time** (`follow_up_time`, time, optional): Set a follow-up time if applicable.
* **Next Follow-up Date** (`next_follow_up_date`, date, optional): Set the next follow-up date if applicable.
* **Next Follow-up Time** (`next_follow_up_time`, time, optional): Set the next follow-up time if applicable.
