# Event Florist Referral Form - Help Guide
## Purpose
This form is designed to collect data about event florist referrals, including wedding and corporate events, and associated partnerships and vendor recommendations.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of event for which you are providing the referral (Wedding Event or Corporate Event).
2. If applicable, enter the name of the venue or location for the event.
3. If applicable, indicate whether you have a referral for the JST (Just-So-There) service.
4. If applicable, mention any vendor partnerships or recommendations.
5. Provide any additional organized data collection information.
6. Enter any recommendations for other vendors who may be suitable for the event.
7. Finally, double-check that all required fields (Vendor Recommendation) are filled in before submitting the form.

## Field-by-Field Explanation
- **Event Florist Referral** (`event_florist_referral`, text, required): Provide a brief description of the event florist referral, including the type of event and any other relevant details.
- **Wedding Event** (`wedding_event`, text, optional): Specify if the event is a wedding, and include any other details if necessary.
- **Corporate Event** (`corporate_event`, text, optional): Mention if the event is a corporate event, and provide any other relevant information.
- **Venue Partnership** (`venue_partnership`, text, optional): If applicable, enter the name of the venue or location for the event.
- **Jst Referral** (`jst_referral`, text, optional): Indicate whether you have a referral for the JST service.
- **Vendor Partnership** (`vendor_partnership`, text, optional): If applicable, mention any vendor partnerships or recommendations.
- **Easy Follow Up** (`easy_follow_up`, text, optional): Provide any additional organized data collection information.
- **Vendor Recommendation** (`vendor_recommendation`, text, required): Enter any recommendations for other suitable vendors.

## Tips
- Please be as thorough as possible when providing information about the event and vendors.
- If you are unsure about any field, refer to your notes or previous communications.
- Remember to submit the form only when all required fields have been filled in.
