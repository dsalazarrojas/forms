# Event MC Referral Form - Help Guide
## Purpose
This guide is intended to assist users in understanding the event medical director referral form. The form is designed to gather essential details about medical conferences or events, allowing for efficient and accurate communication with event stakeholders.

## How To Complete This Form
*   Please start by filling out the form in sections, taking into consideration that some fields are not mandatory (indicated by "no"). 
*   For non-mandatory fields, please feel free to leave them blank or add relevant information if possible. 
*   Double-check your entries for accuracy and completeness before submitting.

## Field-by-Field Explanation

*   **Event Date** (`event_date`, date, required/optional): Enter the date of the event in the format "YYYY-MM-DD" (e.g., 2022-07-25).
*   **Event Start Time** (`event_start_time`, time, required/optional): Enter the start time of the event in the format "HH:MM:SS" (e.g., 08:00:00).
*   **Event Location** (`event_location`, text, required/optional): Provide the location of the event, including the city and venue if necessary.
*   **Event MC Name** (`event_mc_name`, text, required/optional): Enter the name of the Medical Director.
*   **Event MC Email** (`event_mc_email`, email, required/optional): Enter the email of the Medical Director.
*   **Event MC Phone** (`event_mc_phone`, text, required/optional): Enter the phone number of the Medical Director.
*   **Event Description** (`event_description`, text, required/optional): Enter a concise description of the event to provide context and context for further communication.

## Tips
*   Review the provided fields carefully and ensure accurate entries.
*   Please refrain from entering duplicate referrals. Each entry represents a unique event.
*   If you have any questions or concerns, feel free to reach out to the Event Coordinators.
