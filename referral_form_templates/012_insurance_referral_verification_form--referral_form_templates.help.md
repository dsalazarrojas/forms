# Insurance Referral Verification Form - Help Guide

## Purpose
This form is designed to collect and verify information about referrals from insurance providers. It is used to ensure that referrals are properly processed and followed up on.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the Referral Form Data section with any relevant details about the referral.
2. Select the Referral Type (e.g., Medicare, Medicaid, Private Insurance).
3. Provide Contact Info for the insurance provider.
4. Select the Insurance Type (e.g., Medicare, Medicaid, Private Insurance).
5. Record the Date Received and Date Completed for the referral.
6. Select the Referral Status (e.g., New, Active, Resolved).
7. Provide Additional Notes about the referral.
8. Select the Insurance Provider (e.g., UnitedHealth, BlueCross, Cigna).
9. Enter the Phone Number of the insurance provider.
10. Enter the Email of the insurance provider.

## Field-by-Field Explanation
* **Referral Form Data** (`referral_form_data`, text, optional): A text field for entering any relevant details about the referral.
* **Referral Type** (`referral_type`, select_one, optional): Select the type of referral (e.g., Medicare, Medicaid, Private Insurance).
* **Contact Info** (`contact_info`, text, optional): A text field for entering the contact information of the insurance provider.
* **Insurance Type** (`insurance_type`, select_multiple, optional): Select the type of insurance (e.g., Medicare, Medicaid, Private Insurance).
* **Date Received** (`date_received`, date, optional): The date the referral was received.
* **Date Completed** (`date_completed`, date, optional): The date the referral was completed.
* **Referral Status** (`referral_status`, select_multiple, optional): Select the status of the referral (e.g., New, Active, Resolved).
* **Additional Notes** (`notes`, note, optional): A text field for entering any additional notes about the referral.
* **Insurance Provider** (`insurance_provider`, select_multiple, optional): Select the insurance provider (e.g., UnitedHealth, BlueCross, Cigna).
* **Phone Number** (`phone_number`, text, optional): Enter the phone number of the insurance provider.
* **Email** (`email`, email, optional): Enter the email of the insurance provider.
