# travel_nurse_reference_form - Help Guide
## Purpose
This form is used to collect information about a travel nurse's reference, which includes the person's basic contact details, supervision information, and work environment.

## How To Complete This Form

To complete this form, please follow the steps below:

1. Fill out the first name, last name, email, and phone number fields with the person's contact information.
2. Select the reference type (yes or no) and reference length of time (yes or no).
3. Choose the supervisor's relationship (yes or no) and work environment (yes or no).
4. Provide the supervisor's contact information (name, title, email, and phone number).
5. Describe the supervisor's work environment.
6. Enter any additional comments or insights about the person being referred.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, optional): Enter the person's first name.
* **Last Name** (`last_name`, text, optional): Enter the person's last name.
* **Email** (`email`, email, optional): Enter the person's email address.
* **Phone Number** (`phone_number`, text, optional): Enter the person's phone number.
* **Reference Type** (`reference_type`, select_one, optional): Select "Yes" to indicate that you have referred this person in the past.
* **Reference Length of Time** (`reference_length_of_time`, select_one, optional): Select "Yes" if you have referred this person for a significant amount of time (e.g., over 1 year).
* **Relationship** (`relationship`, select_multiple, optional): Select all that apply (e.g., supervisor, colleague, mentor) to describe your relationship with the person.
* **Company** (`company`, select_multiple, optional): Select all that apply (e.g., hospital, clinic, office) to describe the company or organization the person works for.
* **Job Title** (`job_title`, text, optional): Enter the person's job title.
* **Department** (`department`, text, optional): Enter the person's department.
* **Supervisor Name** (`supervisor_name`, text, optional): Enter the supervisor's name.
* **Supervisor Title** (`supervisor_title`, text, optional): Enter the supervisor's title.
* **Supervisor Email** (`supervisor_email`, email, optional): Enter the supervisor's email address.
* **Supervisor Phone** (`supervisor_phone`, text, optional): Enter the supervisor's phone number.
* **Supervisor Relationship** (`supervisor_relationship`, select_one, optional): Select "Yes" to indicate that you have a relationship with the supervisor.
* **Work Environment** (`work_environment`, select_multiple, optional): Select all that apply (e.g., hospital, clinic, office) to describe the work environment.
* **Supervisor Work Environment** (`supervisor_work_environment`, select_multiple, optional): Select all that apply (e.g., hospital, clinic, office) to describe the supervisor's work environment.
* **Comments** (`comments`, note, optional): Enter any comments or insights about the person being referred.
* **Additional Comments** (`additional_comments`, note, optional): Enter any additional comments or insights about the person being referred.

## Tips

* Please answer all the questions truthfully and thoroughly.
* Use specific examples or details to support your responses.
* Make sure to provide enough information to help the travel nurse make an informed decision about future travel assignments.
* You can use the "Additional Comments" field to enter any other relevant information that you don't have space for in the other fields.
