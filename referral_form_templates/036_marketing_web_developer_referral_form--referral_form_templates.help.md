# Marketing Web Developer Referral Form - Help Guide
## Purpose
The Marketing Web Developer Referral Form is a tool used to refer web developers to an agency. It helps the agency to identify potential new web developers to work with.

## How To Complete This Form
To fill out this form, follow these steps:

1. Go to the first page and fill out the "User Input" field with the relevant information about the referred web developer.
2. On the next page, provide details about the project, including the "Project URL" and "Submission Status" fields.
3. Continue to the next page and fill out the "Developer Details" field with any additional information about the referred web developer.
4. On the next page, enter the "Submission Date", "Submission Status 2", and "Assigned Tool 2" fields for the second submission.
5. Finally, review all the fields and make sure they are accurate and up-to-date before submitting the form.

## Field-by-Field Explanation

- **User Input** (`user_input`, text, required): This field is for the user to enter any relevant information about the referred web developer. Please be as detailed as possible.

- **Project Details** (`project_details`, text, required): In this field, enter the details about the project, including the project URL and any other relevant information.

- **Candidate Referral** (`candidate_referral`, text, required): This field is for the user to enter any additional information about the referred web developer.

- **Developer Details** (`developer_details`, text, optional): This field is for the user to enter any additional information about the referred web developer.

- **Submission Date** (`submission_date`, date, optional): Enter the submission date of the project, if applicable.

- **Submission Status** (`submission_status`, select_one, required): Select "Active" or "Inactive" to indicate the status of the project.

- **Submission Comments** (`submission_comments`, text, optional): This field is for the user to enter any comments or feedback about the submission.

- **Assigned Tool** (`assigned_tool`, select_one, required): Select "Yes" or "No" to indicate if the developer has been assigned to the project.

- **User Email** (`user_email`, email, optional): Enter the email of the user who filled out the form, if applicable.

- **User Name** (`user_name`, text, optional): Enter the name of the user who filled out the form, if applicable.

- **Agency Name** (`agency_name`, text, optional): Enter the name of the agency, if applicable.

- **Agency Email** (`agency_email`, text, optional): Enter the email of the agency, if applicable.

- **Submission Date 2** (`submission_date_2`, date, optional): Enter the submission date of the second submission, if applicable.

- **Submission Status 2** (`submission_status_2`, select_one, optional): Select "Active" or "Inactive" to indicate the status of the second submission, if applicable.

- **Submitted by** (`submitted_by`, text, optional): This field is for the user to enter the name of the person who submitted the form, if applicable.

- **Submission Comments 2** (`submission_comments_2`, text, optional): This field is for the user to enter any comments or feedback about the second submission, if applicable.

- **Submission URL** (`submission_url`, text, optional): Enter the URL of the submission, if applicable.

- **Project Type** (`project_type`, select_one, optional): Select "Yes" or "No" to indicate if the project is of a certain type, if applicable.

- **Project Url 2** (`project_url_2`, text, optional): Enter the URL of the project, if applicable.

- **Project Title** (`project_title`, text, optional): Enter the title of the project, if applicable.

- **Project Description** (`project_description`, text, optional): Enter the description of the project, if applicable.

- **Assigned Tool 2** (`assigned_tool_2`, text, optional): Select "Yes" or "No" to indicate if the tool is assigned to the project, if applicable.

- **User Input 2** (`user_input_2`, text, optional): This field is for the user to enter any information about the second submission, if applicable.

- **Submission Status 2 2** (`submission_status_2_2`, select_one, optional): Select "Active" or "Inactive" to indicate the status of the second submission, if applicable.
