## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the "Fashion Fabric Wholesaler Referral Form" title.
2. Select the reason for referral from the options provided (Fabric Type, Fabric Width, Color).
3. Choose the type of fabric you are referring (Cotton, Polyester, Rayon).
4. Select the width of the fabric (1/4, 1/2, 3/4, Full).
5. Enter the contact's name.
6. Enter the contact's phone number.
7. Enter the contact's email address.
8. Choose the source of the referral (Designer, Brand, Manufacturer).
9. Enter a brief message about the referral.

## Field-by-Field Explanation

* **Fashion Fabric Wholesaler Referral Form** (Text): Enter the name of the fabric wholesaler referring the contact. (Text field, required)
* **referral_reason** (Select One): This field is used to determine why you are referring this contact. Select one of the following options:
	+ Fabric Type: The type of fabric you are referring (e.g., cotton, polyester, etc.).
	+ Fabric Width: The width of the fabric you are referring (e.g., 1/4, 1/2, 3/4, Full).
	+ Color: The color of the fabric you are referring (not shown on this form).
* **fabric_type** (Select One): This field is used to select the type of fabric you are referring.
	+ Cotton: A popular type of fabric.
	+ Polyester: A synthetic fabric.
	+ Rayon: A semi-synthetic fabric.
* **fabric_width** (Select Multiple): Select all that apply:
	+ 1/4: A quarter width fabric.
	+ 1/2: A half-width fabric.
	+ 3/4: Three-quarter width fabric.
	+ Full: Full width fabric.
* **contact_name** (Text): Enter the name of the contact you are referring.
* **contact_phone** (Text): Enter the contact's phone number.
* **contact_email** (Email): Enter the contact's email address.
* **referral_source** (Select One): This field is used to select the source of the referral.
	+ Designer: A design-focused referral.
	+ Brand: A brand-focused referral.
	+ Manufacturer: A manufacturer-focused referral.
* **referral_message** (Text): Enter a brief message about the referral.

## Tips

* Make sure to fill in all required fields.
* Select "yes" if the referral is not new.
* Double-check your entries for accuracy and completeness.
