# Lab Test Referral Form - Help Guide
## Purpose
This form is used to refer patients to a lab test, allowing healthcare providers to document relevant information about the patient, test type, and test result.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant fields and enter the required information. Each field is labeled with its corresponding name and type.
2. Ensure that all required fields are completed before submitting the form.
3. Use the provided options for fields of type select or select_multiple to select the most relevant option.

## Field-by-Field Explanation
* **Patient Identifier** (`patient_identifier`, text): Enter the patient's unique identifier, such as their hospital ID or patient ID.
* **Lab Test Type** (`lab_test_type`, select_one): Select the type of lab test being referred for, such as blood work or imaging.
* **Lab Test Date** (`lab_test_date`, date): Enter the date of the lab test.
* **Lab Test Time** (`lab_test_time`, time): Enter the time of the lab test.
* **Lab Test Result** (`lab_test_result`, select_multiple): Select the test result, such as normal or abnormal.
* **Patient Comments** (`patient_comments`, text): Provide any additional comments or information about the patient.
* **Lab Test Referral** (`lab_test_referral`, text): Provide the referral information for the lab test.
* **Referring Provider Identifier** (`referring_provider_identifier`, text): Enter the identifier of the referring provider.
* **Lab Test Referral Comments** (`lab_test_referral_comments`, note): Enter any comments or information about the referral.
* **Lab Test Priority** (`lab_test_priority`, select_one): Select the priority of the lab test, such as normal or high.
* **Lab Test Status** (`lab_test_status`, select_one): Select the status of the lab test, such as pending or complete.
* **Lab Test Result Comments** (`lab_test_result_comments`, text): Enter any comments or information about the test result.
* **Lab Test Referral Number** (`lab_test_referral_number`, number): Enter a unique referral number.
* **Lab Test Referral Date** (`lab_test_referral_date`, date): Enter the date of the referral.
* **Lab Test Referral Time** (`lab_test_referral_time`, time): Enter the time of the referral.
* **Referring Provider Name** (`referring_provider_name`, text): Enter the name of the referring provider.
* **Referring Provider Contact Information** (`referring_provider_contact_info`, text): Enter any contact information for the referring provider.
* **Lab Test Report** (`lab_test_report`, text): Enter the lab test report.
* **Lab Test Report Date** (`lab_test_report_date`, date): Enter the date of the lab test report.
* **Lab Test Report Time** (`lab_test_report_time`, time): Enter the time of the lab test report.
* **Lab Test Referral Status** (`lab_test_referral_status`, select_one): Select the status of the referral, such as pending or complete.
* **Lab Test Referral Options** (`lab_test_referral_options`, select_multiple): Select any additional referral options.
* **Lab Test Referral** (`lab_test_referral`, select_multiple): Select whether the lab test referral is accepted or not.
* **Lab Test Referral Number (2)** (`lab_test_referral_number`, text): Enter a unique referral number.
* **Lab Test Referral** (`lab_test_referral`, select_multiple): Select whether the lab test referral is accepted or not.

Note: Some fields may have additional options or types not mentioned in this help guide. If you are unsure about a specific field, please refer to the provided options or consult with a healthcare professional.
