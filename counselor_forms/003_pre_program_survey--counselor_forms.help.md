# Pre Program Survey - Help Guide

## Purpose
The Pre Program Survey is a form designed to collect information about an individual's background and interests before participating in a program. This form is intended to gather essential details to ensure that the program is a good fit for the individual and to provide a more personalized experience. Please note that this form is not intended for individuals who have already been a part of the program.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide your first name.
2. Enter your last name.
3. Enter your email address.
4. Provide your phone number (if applicable).
5. Enter your address.
6. If you have a graduation date, please enter it in the specified format.
7. Select all program interests that apply to you.
8. Provide a brief description of your academic history (if applicable).
9. Select whether or not you have certain academic history options (if applicable).
10. Select one option regarding academic history (if applicable).
11. Select your program aptitudes that you possess (if applicable).
12. Select one option regarding program aptitudes (if applicable).
13. Enter your aptitude (1-5) for each of the 11 program aptitudes listed (if applicable).
14. Enter any additional comments or information you would like to provide.

## Field-by-Field Explanation

* **first_name**: Enter your first name.
* **last_name**: Enter your last name.
* **email**: Enter your email address. Please note that this will be used to communicate with you about the program.
* **phone**: If you have a phone number, enter it. This will help us contact you for any additional information.
* **address**: Enter your address.
* **graduation_date**: If you have a graduation date, enter it in the format MM/DD/YYYY.
* **program_interest**: Select all program interests that apply to you.
* **academic_history**: Provide a brief description of your academic history.
* **academic_history_2**: Select whether or not you have certain academic history options.
* **academic_history_2_options**: Select one option regarding academic history.
* **program_aptitudes**: Select all program aptitudes that you possess.
* **program_aptitudes_options**: Select one option regarding program aptitudes.
* **aptitude**: Enter a number from 1-5 for each of the 11 program aptitudes listed, indicating your level of proficiency.
* **comments**: Enter any additional comments or information you would like to provide.
