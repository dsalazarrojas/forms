# pbe_feedback_survey - Help Guide

## Purpose
This form is designed to collect feedback from students and teachers to evaluate the effectiveness of a program or event. It aims to gather insights on teacher performance, strengths, student feedback, and other relevant aspects to inform future developments and improvements.

## How To Complete This Form

To complete this form, follow these steps:

1. Start with the **Introduction** section, where you can briefly describe the program or event.
2. For **Teacher Performance**, rate the teacher's performance using a numerical scale (e.g., 1-10).
3. In the **Teacher Strengths** section, select one or more strengths that you observed (e.g., "Yes" or "No").
4. In the **Student Feedback** section, provide any comments or suggestions you have about the student's experience.
5. In the **Teacher Comments** section, provide any comments or feedback you have about the teacher's performance.
6. In the **Student Comments** section, provide any comments or feedback you have about the student's performance.
7. For **Student Performance**, rate the student's performance using a numerical scale (e.g., 1-10).
8. In the **Teacher Feedback** section, provide any comments or feedback you have about the teacher's performance.
9. In the **Next Steps** section, note any next steps or suggestions for future improvements.
10. Finally, provide a **Form Submission** date and time.

## Field-by-Field Explanation

* **Introduction**: A brief description of the program or event (text).
* **Teacher Performance**: Rate the teacher's performance using a numerical scale (1-10). 
* **Teacher Strengths**: Select one or more strengths that you observed (Yes or No).
* **Student Feedback**: Provide any comments or suggestions about the student's experience (text).
* **Teacher Comments**: Provide any comments or feedback about the teacher's performance (text).
* **Student Comments**: Provide any comments or feedback about the student's performance (text).
* **Student Performance**: Rate the student's performance using a numerical scale (1-10).
* **Teacher Feedback**: Provide any comments or feedback about the teacher's performance (text).
* **Next Steps**: Note any next steps or suggestions for future improvements (text).
* **Form Submission**: Provide a date and time for form submission.
* **Time Spent**: Not applicable in this version, but may be used in the future.

Note: The form submission field is intended for administrators to track when the form was submitted, but it is not required in this version.
