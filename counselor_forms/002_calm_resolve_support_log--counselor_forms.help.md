# Calm Resolve Support Log - Help Guide
## Purpose
This form is designed to document the progress and outcomes of support sessions with clients. It helps counselors track key information about the client's condition, session details, and any interventions or techniques used. By filling out this form, counselors can maintain accurate records and inform future support sessions.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the client's name, ID number (if applicable), and other identifying information on **Client Name** and **Client ID Number** fields.
2. Select the date of the session on **Session Date** field.
3. Choose the start time of the session on **Session Time** field.
4. Indicate the duration of the session on **Session Duration in Minutes** field.
5. Enter the name of the counselor conducting the session on **Counselor Name** field.
6. Select the type of support session on **Session Type** field (e.g., Individual counseling, Group therapy, etc.).
7. Choose the location of the session on **Session Location** field (e.g., In-person office, Video call, etc.).
8. Briefly describe the issues or concerns discussed during the session on **Presenting Issues or Concerns** field.
9. Select the client's mood at the start of the session on **Client Mood at Start of Session** field (e.g., Calm, Anxious, etc.).
10. Select the interventions or techniques used during the session on **Interventions or Techniques Used** field (e.g., Active listening, Cognitive behavioral therapy, etc.).
11. Describe what was accomplished or achieved during the session on **Session Outcomes** field.
12. Rate the client's progress on **Client Progress Level** field (e.g., Significant improvement, Slight improvement, etc.).
13. Identify any risk factors or concerns on **Risk Assessment** field.
14. Determine if follow-up is needed on **Is Follow-up Needed** field.
15. If follow-up is needed, enter the scheduled follow-up date on **Follow-up Date** field.

## Field-by-Field Explanation
* **Client Name**: Full name of the client. Required to identify the client's identity.
* **Client ID Number**: Unique identifier for the client (if applicable).
* **Session Date**: Date of the session when the support was provided.
* **Session Time**: Start time of the session.
* **Session Duration in Minutes**: Length of the session.
* **Counselor Name**: Name of the counselor conducting the session.
* **Session Type**: Type of support session (e.g., Individual counseling, Group therapy, etc.).
* **Session Location**: Where the session took place (e.g., In-person office, Video call, etc.).
* **Presenting Issues or Concerns**: Brief description of issues or concerns discussed during the session.
* **Client Mood at Start of Session**: Client's mood at the beginning of the session (e.g., Calm, Anxious, etc.).
* **Interventions or Techniques Used**: Select all that apply (e.g., Active listening, Cognitive behavioral therapy, etc.).
* **Session Outcomes**: Description of what was accomplished or achieved during the session.
* **Client Progress Level**: Rate the client's progress (e.g., Significant improvement, Slight improvement, etc.).
* **Risk Assessment**: Identify any risk factors or concerns.
* **Is Follow-up Needed**: Determine if follow-up is required.
* **Follow-up Date**: Scheduled date for next session (if follow-up is needed).
* **Referrals Made**: List any referrals to other services.
* **Additional Notes**: Enter any other relevant information.
