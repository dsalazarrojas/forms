# discord report form - Help Guide
## Purpose
The "discord report form" is used to record incidents of misconduct on Discord servers.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the User ID of the user who was reported.
2. Enter the username of the user who was reported.
3. Select the reason for the report from the dropdown menu.
4. Enter the time and date of the incident.
5. Enter a brief description of the incident.
6. Optionally, enter a Screenshot URL or upload a screenshot file.
7. Optionally, enter a Channel link related to the incident.
8. If applicable, select one or more reasons why the user was reported.
9. Enter any additional information about the incident.
10. Enter the username of the user who made the report.
11. Enter the name of the user who was reported.
12. Enter the user's discriminator (a unique identifier for the user).
13. Optionally, upload a file to attach to the report.
14. Enter the ID of the channel where the incident occurred.
15. Optionally, enter a message from the user who was reported.
16. Select the moderator's action: Accept, Reject, or Hold.
17. If the report was rejected, enter a reason for rejection.
18. Enter any additional information about the incident.

## Field-by-Field Explanation

* **User ID** (`user_id`, text, required): Enter the ID of the user who was reported.
* **Username** (`username`, text, required): Enter the username of the user who was reported.
* **Report Reason** (`report_reason`, text, required): Select the reason for the report from the dropdown menu.
* **Report Time** (`report_time`, time, required): Enter the time of the incident.
* **Report Date** (`report_date`, date, required): Enter the date of the incident.
* **Description** (`description`, text, required): Enter a brief description of the incident.
* **Screenshot URL** (`screenshot_url`, text, optional): Enter a URL for a screenshot related to the incident.
* **Screenshot File** (`screenshot_file`, text, optional): Upload a screenshot file related to the incident.
* **Channel Link** (`channel_link`, text, optional): Enter a link to the channel where the incident occurred.
* **User Reported Reason** (`user_report_reason`, select_multiple, optional): Select one or more reasons why the user was reported.
* **Moderator Notes** (`moderator_notes`, note, required): Enter any notes about the incident.
* **Attachment File** (`attachment_file`, text, optional): Upload a file related to the incident.
* **Channel ID** (`channel_id`, number, optional): Enter the ID of the channel where the incident occurred.
* **User Message** (`user_message`, text, optional): Enter a message from the user who was reported.
* **Moderator Action** (`moderator_action`, select_one, required): Select the moderator's action: Accept, Reject, or Hold.
* **Reason for Rejection** (`reason_for_rejection`, text, optional): Enter a reason for rejecting the report.
* **Additional Information** (`additional_information`, text, optional): Enter any additional information about the incident.
* **User Username** (`user_username`, text, optional): Enter the username of the user who made the report.
* **User Name** (`user_name`, text, optional): Enter the name of the user who was reported.
* **User Discriminator** (`user_discriminator`, text, optional): Enter the user's discriminator.
* **User Avatar** (`user_avatar`, text, optional): Enter the user's avatar.
* **Guild Name** (`guild_name`, text, optional): Enter the name of the guild where the incident occurred.
* **Guild ID** (`guild_id`, number, optional): Enter the ID of the guild where the incident occurred.
* **Channel Name** (`channel_name`, text, optional): Enter the name of the channel where the incident occurred.
* **Channel ID** (`channel_id`, number, optional): Enter the ID of the channel where the incident occurred.
