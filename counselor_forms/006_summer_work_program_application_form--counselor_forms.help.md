# Summer Work Program Application Form - Help Guide
## Purpose
The Summer Work Program Application Form is designed to collect demographic and background information from students interested in participating in the work program.
## How To Complete This Form
To complete the form, follow these steps:

1. Fill in your First Name and Last Name in the respective fields.
2. Enter a valid Email address for contact purposes.
3. If you have a Phone Number, enter it for us to get in touch with you.
4. If you have a Student ID, enter it if available.
5. Indicate your interest in the Summer Work Program by selecting a brief Program Interest (e.g., Internship, Research, etc.).
6. Provide a brief description of your Work Experience, if any.
7. Ensure you fill out all required fields and submit the form for review.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Enter your given name.
* **Last Name** (`last_name`, text, required): Enter your surname.
* **Email** (`email`, email, required): Enter a valid email address we can use to contact you.
* **Phone Number** (`phone_number`, text, required): If you have a phone number, enter it.
* **Student ID** (`student_id`, text, optional): If you have a student ID, enter it if available.
* **Program Interest** (`program_interest`, text, required): Describe your interest in the Summer Work Program (e.g., Internship, Research, etc.).
* **Work Experience** (`work_experience`, text, optional): Provide a brief description of any work experience you have.

## Tips
* Make sure to fill out all required fields accurately and thoroughly.
* Ensure your email address is up-to-date and valid.
* If you have any work experience, provide a detailed description to help us better understand your qualifications.
* If you have any questions or concerns, feel free to contact us.
