# Graduate Student Questionnaire - Help Guide
## Purpose
The Graduate Student Questionnaire is a tool used to collect information from graduate students for various purposes, such as research, administrative, or academic activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reading the form carefully to understand what each question is asking.
2. Fill in your name and contact information in the "contact info" field.
3. Answer each question to the best of your ability, using the options provided.
4. If you have any questions or concerns, contact the person or department responsible for administering this form.

## Field-by-Field Explanation
- **contact info** (`contact info`, `email`, optional): Please enter your name and email address.
- **question 1** (`question 1`, `select_one`, optional): Choose one of the options to answer this question.
- **question 2** (`question 2`, `select_multiple`, optional): Select all the options that apply to answer this question.
- **question 3** (`question 3`, `date`, optional): Enter a date in the required format (MM/DD/YYYY).
- **question 4** (`question 4`, `time`, optional): Enter a time in the required format (HH:MM AM/PM).
- **question 5** (`question 5`, `note`, optional): Enter any additional information or comments about question 5.
- **question 6** (`question 6`, `text`, optional): Enter a brief answer to question 6.
- **question 7** (`question 7`, `number`, optional): Enter a numerical value to answer this question.
- **question 8** (`question 8`, `number`, optional): Enter another numerical value to answer this question.

## Tips
- Make sure to review each question carefully before answering.
- If you are unsure about any question, contact the person or department responsible for administering this form.
- This form is for general information collection only, and your responses will be kept confidential.
- If you have any questions or concerns, please don't hesitate to reach out.
