# Agent Coaching Form - Help Guide
## Purpose
The Agent Coaching Form is a tool used by coaches to document and assess the effectiveness of coaching sessions with sales agents. It helps to identify strengths and areas for improvement in the agents' performance and to set goals and timelines for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the agent being coached (coached_agent_name) and the coach's name (coach_name) in the respective fields.
2. Record the date and time of the coaching session (coaching_session_date and coaching_session_time).
3. Indicate the location where the coaching session took place (coaching_session_location).
4. Select the primary focus area for the session (coaching_focus_area) from the provided options.
5. Describe the objectives of the coaching session (coaching_objectives).
6. Assess the agent's current performance in the focus area (current_performance_assessment).
7. Identify the agent's strengths and weaknesses, if any (strengths_identified and areas_for_improvement).
8. Describe the coaching methods used during the session (coaching_methods_used).
9. Record any specific examples discussed during the session (examples_discussed).
10. List the skills practiced during the session (skills_practiced).
11. Develop an action plan for improvement (action_plan_development).
12. Set specific goals for the agent (goals_set).
13. Establish a timeline for achieving the goals (timeline_for_improvement).
14. Indicate if a follow-up session is planned (follow_up_session_planned) and record the date for the follow-up session (follow_up_date).
15. Record the agent's feedback about the session (agent_feedback).
16. Sign the form as a coach (coach_signature) and the agent (agent_signature).

## Field-by-Field Explanation
* **Coached Agent Name** (`coached_agent_name`, text, required): Enter the name of the agent being coached.
* **Coach Name** (`coach_name`, text, required): Enter the name of the coach or supervisor.
* **Coaching Session Date** (`coaching_session_date`, date, required): Enter the date of the coaching session.
* **Coaching Session Time** (`coaching_session_time`, text, required): Enter the start and end time of the session.
* **Coaching Session Location** (`coaching_session_location`, text, required): Enter the location where the session took place.
* **Coaching Focus Area** (`coaching_focus_area`, select_one, required): Select the primary focus area for this session from the provided options.
* **Coaching Objectives** (`coaching_objectives`, text, required): Describe the objectives for this coaching session.
* **Current Performance Assessment** (`current_performance_assessment`, select_one, required): Assess the agent's current performance in the focus area from the provided options.
* **Strengths Identified** (`strengths_identified`, text, optional): Identify the agent's strengths in the focus area.
* **Areas for Improvement** (`areas_for_improvement`, text, optional): Describe the areas for improvement in the focus area.
* **-- Coaching Activities --** (`coaching_activities_header`, note, optional): This is a header for the coaching activities section.
* **Coaching Methods Used** (`coaching_methods_used`, select_multiple, required): Select the coaching methods used during the session from the provided options.
* **Examples Discussed** (`examples_discussed`, text, optional): Describe specific examples discussed during the session.
* **Skills Practiced** (`skills_practiced`, text, optional): List the skills practiced during the session.
* **Action Plan Development** (`action_plan_development`, text, required): Develop an action plan for improvement.
* **Goals Set** (`goals_set`, text, required): Set specific goals for the agent.
* **Timeline for Improvement** (`timeline_for_improvement`, text, required): Establish a timeline for achieving the goals.
* **Resources Provided** (`resources_provided`, text, optional): Record any resources provided to support improvement.
* **Follow-up Session Planned** (`follow_up_session_planned`, select_one, required): Indicate if a follow-up session is planned.
* **Follow-up Date** (`follow_up_date`, date, optional): If yes, enter the date for the follow-up session.
* **Agent Feedback** (`agent_feedback`, text, optional): Record the agent's feedback about the session.
* **Coach Signature** (`coach_signature`, text, required): Sign the form as a coach.
* **Agent Signature** (`agent_signature`, text, required): Sign the form as an agent.

## Tips
* Be as specific as possible when filling out the form.
* Use clear and concise language when describing strengths, weaknesses, objectives, and goals.
* Take into account the agent's feedback and concerns when developing an action plan.
* Ensure that the timeline for improvement is realistic and achievable.
