**Youth Group Registration Form - Help Guide**

## Purpose
This form is designed to collect information from parents and guardians for the youth group program. It is used to ensure that all necessary details are provided for the student's well-being and safety. Please ensure that you have permission from the student's parent or guardian to register them for this program before proceeding.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to ensure you have all necessary information.
2. Fill in the required fields (marked as "required" in the form).
3. If applicable, fill in any optional fields that you believe are relevant.
4. Review your responses for accuracy before submitting the form.

## Field-by-Field Explanation

### 1. Parents Name (Required)
**Parent's Name** (parents_name): This field is for the name of the parent or guardian registering the student. Please enter their full name.

### 2. Student Name (Required)
**Student Name** (student_name): This field is for the name of the student registering for the program. Please enter their full name.

### 3. Birth Date (Optional)
**Birth Date** (birth_date): This field is for the student's birth date. If known, please enter the date of birth.

### 4. Contact Number (Required)
**Contact Number** (contact_number): This field is for the contact number of the parent or guardian. Please enter a valid phone number.

### 5. Email Address (Optional)
**Email Address** (email_address): This field is for the email address of the parent or guardian. If you have one, please enter it.

### 6. School (Required)
**School** (school): This field is for the student's school. Please select the correct option from the dropdown menu.

### 7. Grade (Required)
**Grade** (grade): This field is for the student's grade level. Please select all applicable options from the dropdown menu.

### 8. Guardian Name (Required)
**Guardian Name** (guardian_name): This field is for the name of the guardian or person responsible for the student's care. Please enter their full name.

### 9. Parent Email Address (Required)
**Parent Email Address** (parent_email_address): This field is for the email address of the guardian or person responsible for the student's care. Please enter a valid email address.

### 10. Emergency Contact (Required)
**Emergency Contact** (emergency_contact): This field is for the name of the person to contact in case of an emergency. Please enter their full name.

### 11. Emergency Contact Number (Required)
**Emergency Contact Number** (emergency_contact_number): This field is for the contact number of the emergency contact person. Please enter a valid phone number.

### 12. Emergency Contact Person (Required)
**Emergency Contact Person** (emergency_contact_person): This field is for the name of the person responsible for emergency contact. Please enter their full name.

### 13. Medical Information (Optional)
**Medical Information** (medical_information): This field is for any relevant medical information. If known, please enter it.

### 14. Medical Condition (Optional)
**Medical Condition** (medical_condition): This field is for any pre-existing medical conditions. If known, please enter the condition(s).

### 15. Allergies (Optional)
**Allergies** (allergies): This field is for any allergies the student has. If known, please enter them.

### 16. Medications (Optional)
**Medications** (medications): This field is for any prescribed medications. If known, please enter them.

### 17. Student Medical History (Optional)
**Student Medical History** (student_medical_history): This field is for any past medical history. If known, please enter it.

### 18. Emergency Contact Plan (Required)
**Emergency Contact Plan** (emergency_contact_plan): This field is for a plan for emergency contact. Please enter it.

### 19. Medical Insurance (Optional)
**Medical Insurance** (medical_insurance): This field is for medical insurance information. If known, please enter it.

### 20. Student Diet (Optional)
**Student Diet** (student_diet): This field is for any dietary restrictions or needs. If known, please enter them.

### 21. Student Dietary Restrictions (Optional)
**Student Dietary Restrictions** (student_dietary_restrictions): This field is for any dietary restrictions or needs. If known, please enter them.

### 22. Student Medical Conditions (Optional)
**Student Medical Conditions** (student_medical_conditions): This field is for any medical conditions. If known, please enter them.

### 23. Student Medical Treatment (Optional)
**Student Medical Treatment** (student_medical_treatment): This field is for any medical treatment. If known, please enter them.

### 24. Comments (Optional)
**Comments** (comments): This field is for any additional comments or information. If known, please enter them.
