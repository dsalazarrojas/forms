# Prospective Student Inquiry Form - Help Guide
## Purpose
This form is designed to collect information from prospective students who are interested in enrolling in the institution.

## How To Complete This Form
To complete this form, follow these steps:

1. Please provide your general information in the General Info section.
2. Enter your name in the name field.
3. Enter your email address in the email field.
4. Enter your phone number in the phone field (optional).
5. Select your inquiry type from the dropdown menu.
6. Select any relevant student programs you are interested in.
7. Add any additional comments you would like to share with us.
8. If you have a student ID, please enter it in the student ID field (optional).
9. If you have a counsellor ID, please enter it in the counsellor ID field (optional).
10. If you have a school ID, please enter it in the school ID field (optional).
11. If you have a form ID, please enter it in the form ID field (optional).
12. If you are a student agent, please select 'Yes' or 'No' from the dropdown menu.
13. Please select a date and time for your inquiry.
14. Please select a date for your inquiry.
15. Please select a time for your inquiry.

## Field-by-Field Explanation
* **General Info** (text): This is the section where you can provide any general information about yourself.
* **name** (text): Please enter your name as it should appear on your inquiry.
* **email** (text): Please enter your email address where you can be reached.
* **phone** (text): If you have a phone number, please enter it here (optional).
* **Inquiry Type** (select_one): Please select the type of inquiry you are making (e.g. 'Yes' or 'No').
* **Student Programs** (select_multiple): Please select any relevant student programs you are interested in.
* **report_name** (text): Please enter a report name (optional).
* **Additional Comments** (text): If you have any additional comments or information you would like to share, please enter them here.
* **student_id** (number): If you have a student ID, please enter it here (optional).
* **counselor_id** (number): If you have a counsellor ID, please enter it here (optional).
* **school_id** (number): If you have a school ID, please enter it here (optional).
* **form_id** (number): If you have a form ID, please enter it here (optional).
* **user_agent** (select_one): Please select 'Yes' or 'No' if you are a student agent.
* **timestamp** (date): Please select a date for your inquiry.
