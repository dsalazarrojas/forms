# Stand In And Double Registration Form - Help Guide
## Purpose
This form is used to register a stand-in and double for a specific category, ensuring that all relevant information is captured for report generation.

## How To Complete This Form
1. Select the appropriate category from the dropdown menu.
2. Provide a brief description of the stand-in and double.
3. If applicable, enter the Form ID and Assigned Tool.
4. Optionally, provide a more detailed Description of the stand-in and double.
5. Specify the Output File location.

## Field-by-Field Explanation

* **Category (id: 2)**: Select the category for which the stand-in and double will be registered.
* **Description (id: 3)**: Briefly describe the stand-in and double, e.g., their role, location, and any other relevant details.
* **Description (id: 4)**: Provide a more detailed description of the stand-in and double, if applicable.
* **Form ID (id: 5)**: Enter the ID of the form, if applicable.
* **Assigned Tool (id: 6)**: Specify the tool assigned to the stand-in and double, if applicable.
* **Category Description (id: 7)**: Provide a description of the category, if applicable.
* **Output File (id: 8)**: Specify the location where the generated report will be saved.

## Tips
* Ensure you select the correct category from the dropdown menu.
* If you need to register a stand-in and double for multiple categories, complete this form for each category separately.
* Double-check that you have provided all necessary information to avoid incomplete registration.
