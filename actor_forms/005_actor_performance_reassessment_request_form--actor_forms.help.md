# Actor Performance Reassessment Request Form - Help Guide
## Purpose
The purpose of this form is to request a reassessment of an actor's performance. This form is used by requesters to provide specific details about the reasons for the reassessment and the desired outcome.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your name as the requester, so we can contact you about this request.
2. Enter the name of the actor to be reassessed.
3. Select the role or production associated with this request, if applicable.
4. Provide a brief rationale for the reassessment.
5. Choose the desired outcome from the options listed.
6. If there are any supporting documents or evidence, list them here.
7. Select the urgency level of your request.
8. Choose your preferred contact method for follow-up.
9. If you have any additional information or context, you can provide it here.

## Field-by-Field Explanation
* **Requester name**: The full name of the person submitting this request.
* **Actor name**: The full name of the actor to be reassessed.
* **Role or production**: The specific role or production associated with this request. If not applicable, leave this field blank.
* **Reason for reassessment**: A brief explanation of the reason for the reassessment.
* **Requested outcome**: The desired outcome of the reassessment. Select one of the following options:
	+ Performance notes
	+ Full reassessment
	+ Coaching referral
* **Supporting documents**: If you have any supporting documents or evidence, list them here.
* **Urgency level**: The level of urgency for this request. Select one of the following options:
	+ Routine
	+ Priority
	+ Immediate
* **Preferred contact method**: The best way to reach you for follow-up.
* **Additional notes**: Any further context or information that can help reviewers understand this request.

## Tips
* Please provide specific details to help reviewers understand the reason for the reassessment and the desired outcome.
* If you have already submitted a request for the same reason and outcome, please do not submit this form.
* If you have submitted a request for a related but different reason and outcome, please submit this form.
* You can submit supporting documents or evidence to help reviewers understand the context of this request.
