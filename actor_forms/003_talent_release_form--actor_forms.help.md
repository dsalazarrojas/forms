# Talent Release Form - Help Guide
## Purpose
The "Talent Release Form" is used to document agreements between talent and the organization on projects. It ensures that all parties involved are aware of their responsibilities, rights, and obligations.

## How To Complete This Form

1. **Title** (1, text, required/optional): Enter the name of the form to refer to it later.
2. **Category** (2, select_one, required/optional): Select the correct category for the form. Choose "Actor Forms" if the form is related to an actor project.
3. **Description** (3, text, required/optional): Briefly describe the project in a few sentences.
4. **Project Name** (4, text, required/optional): Enter the project name assigned to the talent.
5. **Project Start Date** (5, date, required/optional): Enter the start date of the project if applicable.
6. **Project End Date** (6, date, required/optional): Enter the end date of the project if applicable.
7. **Talent Name** (7, text, required/optional): Enter your name as the talent involved in the project.
8. **Talent Contact Number** (8, text, required/optional): Enter your contact number for communication.
9. **Consent** (9, note, required/optional): Write your consent to participate in the project, indicating that you understand the terms and conditions outlined in the form.
10. **Project Details** (10, text, required/optional): Provide additional project details if necessary.
11. **Contact Details** (11, text, required/optional): Enter any contact details for project coordination or communication.
12. **Assigned Tool** (12, text, required/optional): Identify the assigned tool for project coordination.

Note: If you're unsure about any of the above fields or have questions, please contact your project coordinator or manager for guidance.
