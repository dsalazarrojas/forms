# day_out_of_days - Help Guide
## Purpose
The "day_out_of_days" form is used to calculate the difference between two dates. This form helps users to determine how many days have passed between the start and end dates.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the start date in the "start date" field.
2. Enter the end date in the "end date" field.
3. The calculated date difference will be displayed once both dates are entered.

## Field-by-Field Explanation
* **calculate date difference** (`number`, required/optional: false): This field will display the calculated difference between the start and end dates.
* **start date** (`date`, required: true): Enter the start date for which you want to calculate the difference.
* **end date** (`date`, required: true): Enter the end date for which you want to calculate the difference.

## Tips
* Make sure to enter the correct start and end dates to ensure accurate calculations.
* If the start date is after the end date, the calculation will not be displayed.
