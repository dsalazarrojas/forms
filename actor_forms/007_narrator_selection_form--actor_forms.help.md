# narrator_selection_form - Help Guide
## Purpose
This form is used to gather information about a narrator for a story or scriptwriting purpose.

## How To Complete This Form

1. Fill out each field carefully, making sure to select the correct options for each question.
2. If you are unsure about any of the fields, please refer to the field-by-field explanation below for more information.

## Field-by-Field Explanation

* **Enter Narrator Name**: This field is where you enter the name of the narrator.
* **Enter Narrator Age**: This field is where you enter the age of the narrator.
* **Enter Narrator Experience**: This field is where you enter the narrator's level of experience. 
* **Enter Narrator Ethnicity**: This field is where you select the ethnicity of the narrator. Please choose from the following options: African American, Asian American, Caucasian, Hispanic, Native American, Other.
* **Enter Narrator Gender**: This field is where you select the gender of the narrator. Please choose from the following options: Male, Female, Non-Binary.
* **Enter Narrator Occupation**: This field is where you select the occupation of the narrator. Please choose from the following options: Actor, Author, Artist, Other.
* **Enter Narrator Language**: This field is where you select the language spoken by the narrator. Please choose from the following options: English, Spanish, French, German, Other.
* **Enter Narrator Genre**: This field is where you select the genre of the story that the narrator is part of. Please choose from the following options: Action, Romance, Thriller, Other.
* **Enter Narrator Nationality**: This field is where you select the nationality of the narrator. Please choose from the following options: American, British, Canadian, Other.
* **Enter Narrator Physical Appearance**: This field is where you select the physical appearance of the narrator. Please choose from the following options: Tall, Short, Fat, Thin, Average, Other.
* **Enter Narrator Voicedescription**: This field is where you enter a description of the narrator's voice.
* **Enter Narrator Characteristics**: This field is where you select the characteristics of the narrator. Please choose from the following options: Brave, Adventurous, Confident, Other.
* **Enter Narrator Education**: This field is where you select the education level of the narrator. Please choose from the following options: High School, Bachelor, Master, Other.
* **Enter Narrator Employment**: This field is where you select the employment status of the narrator. Please choose from the following options: Self-Employed, Employed, Unemployed, Student.
* **Enter Contact Email**: This field is where you enter the contact email of the narrator.
* **Enter Contact Phone**: This field is where you enter the contact phone number of the narrator.
* **Enter Contact Country**: This field is where you select the country of the narrator's contact information. Please choose from the following options: America, Canada, Mexico, Other.
* **Enter Narrator Birthplace**: This field is where you select the birthplace of the narrator. Please choose from the following options: America, Canada, China, Mexico, Other.
* **Enter Narrator Birthdate**: This field is where you enter the birthdate of the narrator. 
* **Enter Narrator Height**: This field is where you enter the height of the narrator.
* **Enter Contact Zip**: This field is where you enter the contact zip code of the narrator.
* **Enter Narrator Address**: This field is where you enter the contact address of the narrator.

## Tips

* Please make sure to fill out all required fields to ensure that the form is complete.
* If you have any questions or concerns, please refer to the field-by-field explanation above for more information.
* Please be as detailed and accurate as possible when filling out the form to ensure that the narrator is well-described and realistic.
