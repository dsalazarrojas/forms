# Fitness Studio Window Branding Order Form - Help Guide
## Purpose
The purpose of this form is to provide information for creating a new branding order for a Fitness Studio's window branding.

## How To Complete This Form
To complete this form, follow these steps:

1. **Form Title**: Enter a brief title for the branding order.
2. **Name**: Enter the name of the Fitness Studio representative completing the form.
3. **Phone**: Enter the phone number of the representative.
4. **Email**: Enter the email address of the representative.
5. **Date**: Select the date for the branding order.
6. **Time**: Select the time for the branding order.
7. **Select One**: Select one option from the available choices.
8. **Select Multiple**: Select multiple options from the available choices.
9. **Note**: Enter any additional notes or comments for the branding order.
10. **Select Multiple 2** to **Select Multiple 22**: These fields allow you to select multiple options from the available choices for different branding orders.

## Field-by-Field Explanation
* **Form Title** (id: 1, <required>): A brief title for the branding order.
	+ Enter a short description of the branding order.
* **Name** (id: 2, <required>): The name of the Fitness Studio representative completing the form.
	+ Enter your name as it should appear on the branding order.
* **Phone** (id: 3, <required>): The phone number of the representative.
	+ Enter your phone number as a reference point for communication.
* **Email** (id: 4, <required>): The email address of the representative.
	+ Enter your email address as a reference point for communication.
* **Date** (id: 5, <required>): The date for the branding order.
	+ Select the date when the branding order is needed.
* **Time** (id: 6, <required>): The time for the branding order.
	+ Select the time when the branding order is needed.
* **Select One** (id: 7, <required>): Select one option from the available choices.
	+ Choose one option that best suits the branding order.
* **Select Multiple** (id: 8, <required>): Select multiple options from the available choices.
	+ Choose multiple options that best suits the branding order.
* **Note** (id: 9, <required>): Any additional notes or comments for the branding order.
	+ Enter any comments or notes for the branding order.
* **Select Multiple 2** to **Select Multiple 22** (id: 10-32, <required>): Select multiple options from the available choices for different branding orders.
	+ Choose multiple options for different branding orders as needed.
	+ Note that these fields are not required, but can be completed for future branding orders.
