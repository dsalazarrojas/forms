# Factory Air Filter Cartridge Order Form - Help Guide
## Purpose
The Factory Air Filter Cartridge Order Form is designed to collect information from customers or their representatives for a factory air filter cartridge order. This form includes fields for personal details, order specifics, payment method, and order status.

## How To Complete This Form
1. Fill in your User Name, which is a required field.
2. If necessary, provide the Order Date and Contact Number for order tracking purposes.
3. Enter your Email Address for communication and order updates.
4. Enter the Shipping Address for delivery purposes.
5. Provide Order Details, which is a note field for any additional information about the order.
6. Select the Payment Method from the options provided (Credit Card, Bank Transfer, or PayPal).
7. Enter the Order Quantity for the number of filter cartridges needed.
8. Indicate the Product Type, which is optional but helpful for specific filter needs.
9. Enter the Company Name if this is a company order.
10. Add any Order Notes, which is an optional note field for further information.
11. Enter the Customer Reference for future reference.
12. Name the Salesperson responsible for the order.
13. Enter the Account Number if applicable.
14. Enter the Customer PO number if applicable.
15. Provide Order Comments in case additional information is needed.
16. Enter the Order Date Time for accurate order tracking.
17. Name the Sales Representative handling the order.
18. Enter Customer Notes if applicable.
19. Enter the Order Total, which is optional for tracking purposes.
20. Indicate the Order Submitted By for order submission verification.
21. Select the Order Status (Not Started, In Progress, Completed, or Cancelled).
22. Choose the Sales Region, which is optional.
23. Name the Sales Manager, which is optional.
24. Enter the Sales Area, which is optional.

## Field-by-Field Explanation

* **User Name (1)**: This field is a required field to identify the user placing the order.
* **Order Date (2)**: Enter the date when the order is required.
* **Contact Number (3)**: Optional field for contact details.
* **Email Address (4)**: Enter your email address for order updates and communication.
* **Shipping Address (5)**: Enter the address where the order will be shipped.
* **Order Details (6)**: Enter any additional information about the order in this field.
* **Payment Method (7)**: Choose from Credit Card, Bank Transfer, or PayPal for payment.
* **Order Quantity (8)**: Enter the number of filter cartridges needed.
* **Product Type (9)**: Optional field to indicate the type of filter cartridge needed.
* **Company Name (10)**: Enter the company name if this is a company order.
* **Customer Notes (11)**: Optional note field for further information.
* **Customer Reference (12)**: Enter a reference for future reference.
* **Salesperson (13)**: Name the salesperson responsible for the order.
* **Account Number (14)**: Enter the account number if applicable.
* **Customer PO (15)**: Enter the customer purchase order number if applicable.
* **Order Comments (16)**: Enter any additional information.
* **Order Date Time (17)**: Enter the date and time of the order.
* **Sales Representative (18)**: Name the sales representative handling the order.
* **Customer Notes (19)**: Optional note field for customer comments.
* **Order Total (20)**: Enter the total cost of the order, which is optional.
* **Order Submitted By (21)**: Indicate who submitted the order.
* **Order Status (22)**: Select the status of the order (Not Started, In Progress, Completed, or Cancelled).
* **Sales Region (23)**: Enter the sales region.
* **Sales Manager (24)**: Name the sales manager handling the order.
* **Sales Area (25)**: Enter the sales area.
