# Material Handling Crane Component Order Form - Help Guide
## Purpose
This form is used to collect order details from customers for material handling crane components.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct crane model from the options provided.
2. Enter the quantity of components ordered.
3. Select the delivery date and time (if applicable).
4. List the specific crane parts ordered.
5. Enter the customer's name and contact information (email, phone number, and address).
6. Enter the delivery address (if different from the customer's address).
7. Review and update the order details as needed.
