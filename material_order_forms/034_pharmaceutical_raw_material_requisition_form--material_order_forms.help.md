# Pharmaceutical Raw Material Requisition Form - Help Guide
## Purpose
This form is used to gather information about the pharmaceutical raw materials requisitioned by the team, including their quantities, unit prices, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Material Request field with a brief description of the material required.
2. Select the Material Type from the provided options.
3. Enter the Quantity of the material needed.
4. Enter the Unit Price of the material.
5. Calculate the Total Price by multiplying the Quantity and Unit Price.
6. Select the Material Vendor from the provided options.
7. Add a Material Note if necessary.
8. Select the Route To options as relevant.
9. Enter the Date Requested and Time Completed (if applicable).
10. Add a Material Note if necessary.
11. Select the Submitted By option.
12. Enter the Submitted Date and Time.
13. Select the Approved By option (if applicable).
14. Enter the Approved Date and Time (if applicable).
15. Select the Rejected By option (if applicable).
16. Enter the Rejected Date and Time (if applicable).
17. Select the Submitted To option.
18. Select the Material Category.
19. Select the Material Status.
20. Add any Remarks if necessary.

## Field-by-Field Explanation

* **Material Request (1)** (`Material Request`, text, required): Enter a brief description of the material required.
* **Material Type (2)** (`Material Type`, select one, optional): Select the type of material needed.
* **Quantity (3)** (`Quantity`, number, required): Enter the quantity of the material needed.
* **Unit Price (4)** (`Unit Price`, number, required): Enter the unit price of the material.
* **Total Price (5)** (`Total Price`, number, optional): Calculate the total price by multiplying the Quantity and Unit Price.
* **Material Vendor (6)** (`Material Vendor`, select one, optional): Select the vendor of the material.
* **Material Note (7)** (`Material Note`, note, optional): Add any additional information about the material.
* **Route To (8)** (`Route To`, select multiple, optional): Select the routes to deliver the material.
* **Date Requested (9)** (`Date Requested`, date, required): Enter the date the material was requested.
* **Date Completed (10)** (`Date Completed`, date, optional): Enter the date the material was completed (if applicable).
* **Time Completed (11)** (`Time Completed`, time, optional): Enter the time the material was completed (if applicable).
* **Material Note (12)** (`Material Note`, note, optional): Add any additional information about the material.
* **Submitted By (13)** (`Submitted By`, select one, optional): Select who submitted the request.
* **Submitted Date (14)** (`Submitted Date`, date, required): Enter the date the request was submitted.
* **Submitted Time (15)** (`Submitted Time`, time, required): Enter the time the request was submitted.
* **Approved By (16)** (`Approved By`, select one, optional): Select who approved the request (if applicable).
* **Approved Date (17)** (`Approved Date`, date, optional): Enter the date the request was approved (if applicable).
* **Approved Time (18)** (`Approved Time`, time, optional): Enter the time the request was approved (if applicable).
* **Rejected By (19)** (`Rejected By`, select one, optional): Select who rejected the request (if applicable).
* **Rejected Date (20)** (`Rejected Date`, date, optional): Enter the date the request was rejected (if applicable).
* **Rejected Time (21)** (`Rejected Time`, time, optional): Enter the time the request was rejected (if applicable).
* **Submitted To (22)** (`Submitted To`, select one, required): Select who the request was submitted to.
* **Material Category (23)** (`Material Category`, select one, required): Select the category of the material.
* **Material Status (24)** (`Material Status`, select one, optional): Select the status of the material.
* **Remarks (25)** (`Remarks`, note, optional): Add any additional comments or remarks about the material.

## Tips

* Please ensure that all required fields are filled before submitting the form.
* Double-check the material information to ensure accuracy.
* Review the form before submitting to avoid any errors.
* If you have any questions or concerns, contact the relevant authorities for assistance.
