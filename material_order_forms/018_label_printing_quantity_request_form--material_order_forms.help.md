# Label Printing Quantity Request Form - Help Guide

## Purpose
This form is used to request label printing services with specific quantity and deadline specifications.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Label Specs** field (page 1) with a brief description of the labels to be printed.
2. Specify the **Quantities** (page 1) of each label to be printed.
3. Set a **Deadline** (page 1) for the label printing request.
4. Indicate if you will be providing **Artwork Files** (page 2) to support the label printing.
5. Determine if you will be providing additional **Label Printing Form Files** (page 2) to support the label printing.
6. Choose whether you will be providing **Form Files** (page 2) to support the label printing.
7. Confirm whether you will be submitting the request by selecting **Submit** (page 3).
8. Add any additional **Label Printing Form Notes** (page 3) to provide further context or instructions.
9. If required, provide a link to the **Artwork Url** (page 3) for the label printing.

## Field-by-Field Explanation

* **Label Specs**: Enter a brief description of the labels to be printed, including any relevant details such as size, material, or design requirements.
* **Quantities**: Specify the quantity of each label to be printed, including any minimum order quantities or special handling instructions.
* **Deadline**: Set a deadline for the label printing request, including the date and any relevant time constraints.
* **Artwork Files**: If you are providing artwork files for the label printing, select "Yes" to upload them. This will help us process your request efficiently.
* **Label Printing Form Files**: If you are providing additional label printing form files, select "Yes" to upload them. This will help us process your request efficiently.
* **Form Files**: If you are providing form files related to the label printing, select "Yes" to upload them. This will help us process your request efficiently.
* **Submit**: Confirm your submission of the request by selecting "Yes".
* **Label Printing Form Notes**: Add any additional context or instructions to support your label printing request.
* **Artwork Url**: If you are providing artwork files, enter the URL where they can be accessed. This will help us retrieve the files for processing. 

Note: This guide assumes that each field is optional, as per the provided YAML. However, it is likely that some fields are required for a successful submission. If a field is required, please make sure to fill it in accordingly.
