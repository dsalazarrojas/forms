# Material Request Form - Help Guide

## Purpose
This form is used for requesting materials for a project. It allows users to provide information about the project, the materials requested, and the contact details of the person submitting the request.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the project you are submitting the request for from the project ID field.
2.  Choose the type of materials you are requesting (e.g., Cement, Lumber, Steel, Glass, or Aluminum).
3.  Select the current stage of the project (e.g., Pre-Construction, Underway, or Post-Construction).
4.  Choose the person who requested the materials (e.g., Builder, Architect, Development Director, or Property Manager).
5.  Enter the date you are requesting the materials.
6.  Provide a brief description of the requested item(s).
7.  Enter the quantity of the requested item(s).
8.  Enter your contact email address.
9.  Enter your contact phone number.
10. Add any additional notes about the request.
11. Select the user who will be assigned to handle this request.
12. Choose the person who submitted this request.
13. Select the current status of the project (e.g., Open, Closed, Pending).
14. Enter the ID of the project manager who will handle this request.
15. Enter your submitted date and time.
16. Finally, enter any notes from the project manager.

## Field-by-Field Explanation

* **project_id** (ID, number, optional): Enter the ID of the project you are submitting the request for. If no project ID is selected, the request will be submitted without a project assignment.
* **Building Material** (select multiple, optional): Choose the type of materials you are requesting (e.g., Cement, Lumber, Steel, Glass, or Aluminum). Multiple selections are allowed.
* **Project Stage** (select one, optional): Select the current stage of the project (e.g., Pre-Construction, Underway, or Post-Construction).
* **Requested By** (select one, optional): Choose the person who requested the materials (e.g., Builder, Architect, Development Director, or Property Manager).
* **Request Date** (date, optional): Enter the date you are requesting the materials.
* **Requested Item** (text, optional): Provide a brief description of the requested item(s).
* **Item Quantity** (number, optional): Enter the quantity of the requested item(s).
* **Contact Email** (email, optional): Enter your contact email address.
* **Contact Phone** (text, optional): Enter your contact phone number.
* **Notes** (note, optional): Add any additional notes about the request.
* **Assigned Tool** (text, optional): Enter the tool assigned to handle this request.
* **Assigned User** (select one, optional): Select the user who will be assigned to handle this request.
* **Submitted By** (select one, optional): Choose the person who submitted this request.
* **Submitted Date** (date, optional): Enter the date this request was submitted.
* **Submitted Time** (time, optional): Enter the time this request was submitted.
* **Project Manager Note** (text, optional): Enter any notes from the project manager.
* **Project Status** (select one, optional): Select the current status of the project (e.g., Open, Closed, or Pending).
* **Project Manager ID** (text, optional): Enter the ID of the project manager who will handle this request.
