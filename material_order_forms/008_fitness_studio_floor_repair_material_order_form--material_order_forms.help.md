# Fitness Studio Floor Repair Material Order Form - Help Guide

## Purpose
The Fitness Studio Floor Repair Material Order Form is used to gather information about the materials needed for repairs and maintenance of the studio floor. This form is used to ensure that the correct materials are ordered and delivered to the correct location.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your information on the "customer" field. This will be the name of the person responsible for the order.
2. Enter the address where the materials are to be delivered.
3. Enter the contact information of the person who will be responsible for coordinating the delivery.
4. Enter the email address and phone number of the person who will be coordinating the delivery.
5. Select the materials that are needed for the repair from the list provided.
6. If you have any additional comments or instructions, please enter them in the "comments" field.
7. If you need to specify who should be assigned to handle the order, please select from the list provided.
8. If you need to specify who created the order, please select from the list provided.
9. If you need to specify who updated the order, please select from the list provided.
10. If you need to specify who submitted the order, please select from the list provided.
11. If you need to specify who should receive email, please enter their email address.
12. If you need to specify who should receive phone calls, please enter their phone number.
13. If you need to specify who should receive comments, please select from the list provided.

## Field-by-Field Explanation

* **customer** (Text, Required):
	+ This field is where you enter the name of the person responsible for the order.
* **customer address** (Text, Required):
	+ This field is where you enter the address where the materials are to be delivered.
* **customer contact** (Text, Required):
	+ This field is where you enter the contact information of the person who will be responsible for coordinating the delivery.
* **email** (Text, Required):
	+ This field is where you enter the email address of the person who will be coordinating the delivery.
* **phone number** (Text, Required):
	+ This field is where you enter the phone number of the person who will be coordinating the delivery.
* **delivery details** (Text, Optional):
	+ This field is where you can enter any additional information about the delivery.
* **materials needed** (Select Multiple, Required):
	+ This field is where you select the materials that are needed for the repair from the list provided. The options are:
		- Epoxy
		- Cement
		- Sealant
		- Paint
		- Sanding
		- Other
* **comments** (Note, Optional):
	+ This field is where you can enter any additional comments or instructions about the order.
* **form id** (Number, Optional):
	+ This field is not currently used and can be ignored.
* **assigned to** (Select One, Required):

## Tips

* Please make sure to fill in all required fields.
* If you have any questions or concerns, please contact the order coordinator.
* If you need to make any changes to the order, please update the "updated" field.
* Please make sure to submit the form only once you have filled in all required fields.
