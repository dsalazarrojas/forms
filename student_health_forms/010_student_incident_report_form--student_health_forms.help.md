# Student Incident Report Form - Help Guide
## Purpose
This form is used to report incidents involving students. It provides a structured way to document and collect information about the incidents.

## How To Complete This Form
- **Report A Student Incident** (Page 1)
   - Please provide a brief description of the incident.
- **Incident Description** (Page 1)
   - Please provide a detailed explanation of the incident.
- **Incident Date** (Page 1)
   - Please enter the date the incident occurred, in the format `YYYY-MM-DD`.
- **Incident Time** (Page 1)
   - Please enter the time the incident occurred, in the format `HH:MM:SS`.
- **Incident Location** (Page 1)
   - Please provide the location where the incident occurred.
- **Incident Type** (Page 1)
   - Please select `Yes` if the incident was a student incident, `No` otherwise.
- **Incident Details** (Page 1)
   - Please provide any additional details about the incident.
- **Incident Witness** (Page 1)
   - Please provide the names of any witnesses or people involved in the incident.
- **Incident Resolution** (Page 1)
   - Please provide a brief description of the resolution or outcome of the incident.
- **Follow-up** (Page 1)
   - Please use this space to note any follow-up actions or next steps that need to be taken.
