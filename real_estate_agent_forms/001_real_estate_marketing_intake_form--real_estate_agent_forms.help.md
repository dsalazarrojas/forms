# Real Estate Marketing Intake Form - Help Guide
## Purpose
This form is designed to assist real estate agents in gathering information from clients or prospects for marketing purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's name in the "Client Name" field.
2. Choose the type of property (rental, buy, or sell) that the client is interested in.
3. Select the target audience and follow-up frequency for the client.
4. Enter the contact method and email address for the client (if applicable).
5. Optionally, specify the source of the lead and any follow-up message or notes.
6. Review and refine your answers to provide accurate and relevant information.

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, optional): Enter the name of the person or entity interested in real estate services.
* **Property Type** (`property_type`, select_one, optional): Choose the type of property the client is interested in (rental, buy, or sell).
* **Property Address** (`property_address`, text, optional): Enter the address of the property the client is interested in.
* **Marketing Goals** (`marketing_goals`, text, optional): Describe the marketing goals or objectives for the client.
* **Target Audience** (`target_audience`, select_one, optional): Select the target audience for the marketing strategy.
* **Target Age Range** (`target_age_range`, select_multiple, optional): Choose the age range of the target audience.
* **Contact Method** (`contact_method`, select_one, optional): Select the primary method of contact (e.g., phone, email, etc.).
* **Follow Up Reminders** (`follow_up_reminders`, select_one, optional): Determine if follow-up reminders are necessary.
* **Lead Source** (`lead_source`, select_one, optional): Select the source of the lead (e.g., social media, referral, etc.).
* **Lead Source Other** (`lead_source_other`, text, optional): If the lead source is not listed, specify it here.
* **Email** (`email`, email, optional): Enter the email address of the client.
* **Phone** (`phone`, text, optional): Enter the phone number of the client.
* **Website** (`website`, text, optional): Enter the website of the client.
* **Social Media** (`social_media`, text, optional): Enter the social media handle or profile of the client.
* **Notes** (`notes`, note, optional): Add any additional notes or comments about the client.
* **Follow Up Reminders Frequency** (`follow_up_reminders_frequency`, select_one, optional): Select the frequency of follow-up reminders.
* **Follow Up Reminders Interval** (`follow_up_reminders_interval`, text, optional): Enter the interval for follow-up reminders.
* **Follow Up Reminders Message** (`follow_up_reminders_message`, text, optional): Enter the message for follow-up reminders.
* **Lead Source Other Frequency** (`lead_source_other_frequency`, text, optional): If the lead source is not listed, enter the frequency of the lead source.
* **Lead Source Other Interval** (`lead_source_other_interval`, text, optional): If the lead source is not listed, enter the interval of the lead source.
* **Lead Source Other Message** (`lead_source_other_message`, text, optional): If the lead source is not listed, enter a message for the lead source.
* **Rental** (`property_type_rental`, select_one, optional): Determine if the property is for rental.
* **Buy** (`property_type_buy`, select_one, optional): Determine if the property is for sale.
* **Sell** (`property_type_sell`, select_one, optional): Determine if the property is for sale.
* **Follow Up Reminders** (`follow_up_reminders`, select_one, optional): Determine if follow-up reminders are necessary.
* **Lead Source Other** (`lead_source_other`, text, optional): If the lead source is not listed, specify it here.
* **Lead Source Other Message** (`lead_source_other_message`, text, optional): If the lead source is not listed, enter a message for the lead source.
