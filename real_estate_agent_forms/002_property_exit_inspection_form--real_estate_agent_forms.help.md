# Property Exit Inspection Form - Help Guide
## Purpose
This form is for real estate agents to document their property inspections. The form aims to gather information about the property's condition, details, and other relevant data.

## How To Complete This Form
1. Fill in the property details, including the property's exterior and interior.
2. Provide contact information for further communication.
3. Add any property photos as necessary for documentation.
4. Enter the inspection date for reference.
5. Sign and date the form as the inspector for verification.
6. Have the property agent sign and date the form as confirmation.

## Field-by-Field Explanation
* **Property Details** (`property_details`, text, optional): Provide a brief description of the property being inspected.
* **Property Exterior** (`property_exterior`, text, optional): Report any notable issues or observations about the property's exterior.
* **Property Interior** (`property_interior`, text, optional): Report any notable issues or observations about the property's interior.
* **Contact Information** (`contact_information`, text, optional): Enter the contact information for the property agent or relevant personnel.
* **Property Photos** (`property_photos`, text, optional): Attach any relevant photos of the property.
* **Additional Notes** (`additional_notes`, text, optional): Record any additional notes or comments about the property.
* **Inspection Date** (`inspection_date`, date, optional): Enter the date of the inspection.
* **Inspector's Name** (`inspector_name`, text, optional): Sign and date the form as the inspector.
* **Inspector's Signature** (`inspector_signature`, text, optional): Sign the form for verification.
* **Property Agent's Signature** (`property_agent_signature`, text, optional): Sign the form as the property agent for confirmation.
* **Property Status** (`property_status`, select-one, optional): Select the current status of the property (Sold, Unsold, Leased, or Other).
* **Property Condition** (`property_condition`, text, optional): Report any notable issues or observations about the property's condition.
* **Tips**
* Make sure to fill in all the required fields for accurate documentation.
