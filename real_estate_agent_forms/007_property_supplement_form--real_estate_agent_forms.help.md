# Property Supplement Form - Help Guide

## Purpose
The Property Supplement Form is a tool for real estate agents to gather and document detailed information about a property. This form is used to supplement property records and provide additional context for managing properties.

## How To Complete This Form

1.  Start by filling in the **Property Owner Name** field with the name of the property owner.
2.  Enter the **Property Address** in the next field, providing the complete address of the property.
3.  Select the **Property Type** from the dropdown menu to indicate the type of property (Apartment, House, Townhouse, etc.).
4.  Enter the **Property Rent** amount, if applicable.
5.  Provide the **Property Broker** and **Property Manager** details if applicable.
6.  Select the **Property Status** from the dropdown menu to indicate the property's current status (Active, Inactive, Pending, etc.).
7.  Enter the **Property Status Date** and **Property Status Time** if applicable.
8.  Enter **Property Notes** if you have any additional comments or observations about the property.
9.  Enter **Property Emails** and **Property Phones** if applicable.
10. Select the **Property Benefits** that apply to the property (Benefits 1, Benefits 2, Benefits 3, etc.).
11. Enter the **Property Benefit Date** and **Property Benefit Time** if applicable.
12. Enter **Property Benefit Notes** if you have any additional comments or observations about the benefits.
13. Enter **Property Benefit Emails** and **Property Benefit Phones** if applicable.
14. Add **Property Additional Notes** if you have any further comments or observations about the property.
15. Enter **Property Additional Emails** and **Property Additional Phones** if applicable.
16. Enter **Property Additional Broker** and **Property Additional Manager** details if applicable.
17. Enter **Property Additional Broker Notes** if you have any additional comments or observations about the additional broker.
18. Enter **Property Additional Broker Emails** if applicable.

## Field-by-Field Explanation

* **Property Owner Name** (Text): Enter the name of the property owner.
* **Property Address** (Text): Enter the complete address of the property.
* **Property Type** (Select One): Select the type of property (Apartment, House, Townhouse, etc.).
* **Property Rent** (Number): Enter the rent amount, if applicable.
* **Property Broker** (Text): Enter the property broker's details.
* **Property Manager** (Text): Enter the property manager's details.
* **Property Status** (Select One): Select the current property status (Active, Inactive, Pending, etc.).
* **Property Status Date** (Date): Enter the date of the property status.
* **Property Status Time** (Time): Enter the time of the property status.
* **Property Notes** (Note): Enter any additional comments or observations about the property.
* **Property Emails** (Email): Enter any additional property emails.
* **Property Phones** (Text): Enter any additional property phones.
* **Property Benefits** (Select Multiple): Select the benefits that apply to the property (Benefits 1, Benefits 2, Benefits 3, etc.).
* **Property Benefit Date** (Date): Enter the date of the property benefits.
* **Property Benefit Time** (Time): Enter the time of the property benefits.
* **Property Benefit Notes** (Note): Enter any additional comments or observations about the benefits.
* **Property Benefit Emails** (Email): Enter any additional property benefit emails.
* **Property Benefit Phones** (Text): Enter any additional property benefit phones.
* **Property Additional Notes** (Note): Enter any additional comments or observations about the property.
* **Property Additional Emails** (Email): Enter any additional property emails.
* **Property Additional Phones** (Text): Enter any additional property phones.
* **Property Additional Broker** (Text): Enter the additional property broker's details.
* **Property Additional Manager** (Text): Enter the additional property manager's details.
* **Property Additional Broker Notes** (Note): Enter any additional comments or observations about the additional broker.
* **Property Additional Broker Emails** (Email): Enter any additional property additional broker emails.
