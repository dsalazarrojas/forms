# Security Deposit Itemized Deduction Form - Help Guide
## Purpose
This form is used to record and track security deposit itemizations and deductions for rental properties.

## How To Complete This Form

1. Enter the **Security Deposit Itemized Deduction Form** title, which will automatically fill in the form title field.
2. Enter the **Landlord name**, which is required to authenticate the form and ensure that the correct person is submitting the form.
3. Enter the **Tenant name**, which is also required.
4. Enter the **Date received**, when the security deposit was received.
5. Enter the **Amount deducted**, which is the amount being deducted from the security deposit.
6. Enter the **Amount remaining**, which is the current balance of the security deposit.
7. Enter the **Date deducted**, when the deduction was made.
8. Enter a **Reason for deduction**, if applicable.
9. Sign the form with the **Landlord signature**, which is required to authenticate the form.
10. Sign the form with the **Tenant signature**, also required.
11. Enter the **Date signed**, when the form was completed.
12. Set the **Form status** to either **Completed**, **Incomplete**, or **Pending**.
13. Enter the **Form version**, which should reflect the latest version of the form.
14. Assign the form to a specific **Assigned user**, who will be responsible for tracking the form.
15. (Optional) Enter the **Reason for refund**, if any refund is due.
16. (Optional) Enter the **Amount refund**, if any refund is due.
17. (Optional) Enter any additional **Form notes**.
18. (Optional) Enter the **Landlord comments**, if any additional information is required.
19. (Optional) Enter the **Tenant comments**, if any additional information is required.
20. Finally, set the **Date completed**, when the form was fully completed.
