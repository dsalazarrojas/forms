# real_estate_referral_form - Help Guide
## Purpose
The real_estate_referral_form is a tool for capturing and managing real estate agent referrals.

## How To Complete This Form
1. Select the Referral Type from the options provided (Agent, Real Estate Company, or Other).
2. Enter the contact information for the referral (Contact Info, real_estate_agent_name, contact_number, email_address, real_estate_agent_address).
3. Enter the referral details (real_estate_referral_name, real_estate_referral_phone, real_estate_referral_email, real_estate_referral_address, real_estate_referral_note).
4. Set the referral status (Open, Closed, or Pending) and the last follow-up status (Scheduled, Done, or Not Scheduled).
5. Enter the last follow-up details (real_estate_referral_last_follow_up, real_estate_referral_last_follow_up_note, real_estate_referral_last_follow_up_time, real_estate_referral_last_follow_up_status, real_estate_referral_last_follow_up_location).

## Field-by-Field Explanation

* **Contact Info (id: 1)**: Enter the contact information for the referral.
* **real_estate_agent_name (id: 2)**: Enter the name of the real estate agent or the real estate company.
* **contact_number (id: 3)**: Enter the contact number of the referral.
* **email_address (id: 4)**: Enter the email address of the referral.
* **real_estate_agent_address (id: 5)**: Enter the address of the real estate agent or the real estate company.
* **Referral Type (id: 6)**: Select the type of referral (Agent, Real Estate Company, or Other).
* **referral_date (id: 7)**: Enter the date of the referral.
* **real_estate_referral_message (id: 8)**: Enter any additional message related to the referral.
* **real_estate_referral_name (id: 9)**: Enter the name of the referral.
* **real_estate_referral_phone (id: 10)**: Enter the phone number of the referral.
* **real_estate_referral_email (id: 11)**: Enter the email address of the referral.
* **real_estate_referral_address (id: 12)**: Enter the address of the referral.
* **real_estate_referral_note (id: 13)**: Enter any additional notes about the referral.
* **real_estate_referral_status (id: 14)**: Set the status of the referral (Open, Closed, or Pending).
* **real_estate_referral_follow_up (id: 15)**: Enter the date and time of the last follow-up.
* **real_estate_referral_follow_up_time (id: 16)**: Enter the time of the last follow-up.
* **real_estate_referral_follow_up_note (id: 17)**: Enter any additional notes about the last follow-up.
* **real_estate_referral_follow_up_status (id: 18)**: Set the status of the last follow-up (Scheduled, Done, or Not Scheduled).
* **real_estate_referral_last_follow_up (id: 19)**: Enter the date of the last follow-up.
* **real_estate_referral_last_follow_up_note (id: 20)**: Enter any additional notes about the last follow-up.
* **real_estate_referral_last_follow_up_time (id: 21)**: Enter the time of the last follow-up.
* **real_estate_referral_last_follow_up_status (id: 22)**: Set the status of the last follow-up (Done or Not Done).
* **real_estate_referral_last_follow_up_location (id: 23)**: Enter the location of the last follow-up.
* **real_estate_referral_last_follow_up_note (id: 24)**: Enter any additional notes about the last follow-up.
* **real_estate_referral_last_follow_up_following (id: 25)**: Indicate if you are following up with the referral (True or False).

## Tips
* Make sure to enter accurate and complete information for each field.
* Check the status and follow-up details carefully before saving the form.
* Use the form to track and manage referrals from agents, real estate companies, or other sources.
