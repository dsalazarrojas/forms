# Key Release Form - Help Guide
## Purpose
The Key Release Form is used to document the key release process for real estate agents, ensuring accuracy and consistency in key release activities. This form captures specific details relevant to each property, avoiding duplication and ensuring that only one form is submitted per property.

## How To Complete This Form
1. Fill in the tenant's name in the "Tenants Name" field.
2. Provide the tenant's contact information in the "Tenant Contact Information" field.
3. Indicate whether an authorized person is involved in the key release process by selecting "Yes" or "No" in the "Authorized Person" field.
4. Select "Yes" or "No" for the "Contact Person" field, indicating if the contact person is involved.
5. Determine if the property manager is involved, selecting "Yes" or "No" in the "Property Manager" field.
6. Enter a date for key release in the "Date" field using the format MM/DD/YY.
7. Specify the time for key release, using the format HH:MM.
8. Enter a brief description for the reason behind the key release in the "Reason" field.
9. Enter the key code or number for easy reference.
10. Provide any additional comments about key release in the "Comments" field.

## Field-by-Field Explanation
* **Tenants Name** (text, required/optional): The name of the tenant or owner of the property.
* **Tenant Contact Information** (note, required/optional): Additional contact information for the tenant or owner, including phone number, email, or address.
* **Authorized Person** (select_one, required/optional): Indicates if an authorized person is involved in the key release process.
* **Contact Person** (select_multiple, required/optional): Select "Yes" or "No" to indicate if the contact person is involved.
* **Property Manager** (select_one, required/optional): Select "Yes" or "No" to determine if the property manager is involved.
* **Date** (date, required/optional): Enter the date for key release using the format MM/DD/YY.
* **Time** (time, required/optional): Enter the time for key release using the format HH:MM.
* **Reason** (text, required/optional): Briefly describe the reason for key release.
* **Key** (text, required/optional): Enter the key code or number for easy reference.
* **Comments** (text, required/optional): Provide any additional comments or notes about key release.
