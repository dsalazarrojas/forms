# security_deposit_release_form - Help Guide
## Purpose
The purpose of this form is to document the return of a security deposit to a tenant.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide tenant information in the "Tenant Information" section.
2. Specify the reason for the return of the security deposit in the "Has Deposit Been Returned" field.
3. Provide the reason for the return of the security deposit in the "Reason for Return" field.
4. Enter the date the deposit was returned in the "Date Returned" field.
5. Provide a signature from the landlord in the "Landlord Signature" field.
6. Provide a signature from the witness in the "Witness Signature" field.
7. Enter the witness's name in the "Witness Name" field.
8. Enter the witness's title in the "Witness Title" field.

## Field-by-Field Explanation
* **Tenant Information (<name>)**: Enter the name and contact information of the tenant who is receiving the security deposit back.
* **Landlord Information (<name>)**: Enter the name and contact information of the landlord who is returning the security deposit.
* **Has Deposit Been Returned (<name>)**: Select "Yes" if the deposit has been returned, or "No" if it has not.
* **Reason for Return (<name>)**: Select the reason for the return of the security deposit from the list provided, or select "Other" and type in the reason below.
* **Reason for Refund (<name>)**: This field is for providing additional information if the reason for the return of the security deposit is "Other".
* **Date Returned (<name>)**: Enter the date the security deposit was returned.
* **Landlord Signature (<name>)**: Sign and date this field to confirm that the landlord is returning the security deposit.
* **Tenant Signature (<name>)**: Sign and date this field to confirm that the tenant has received the security deposit back.
* **Date (<name>)**: Enter the date this form was completed.
* **Witness Signature (<name>)**: Sign and date this field to confirm that the witness has witnessed the return of the security deposit.
* **Witness Name (<name>)**: Enter the name of the witness who has confirmed the return of the security deposit.
* **Witness Title (<name>)**: Enter the title of the witness who has confirmed the return of the security deposit.
