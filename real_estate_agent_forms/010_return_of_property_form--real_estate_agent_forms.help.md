# return_of_property_form - Help Guide
## Purpose
The "return_of_property_form" is used to collect information about the return of a property. This form helps to gather accurate and complete data for the return process, ensuring that all necessary details are captured.

## How To Complete This Form
To complete this form, follow these steps:

1. On the first page (Page 1), enter the details of the property being returned.
2. On the second page (Page 2), provide the return date.
3. On the third page (Page 3), select the current status of the property (Active or Inactive).
4. On the fourth page (Page 4), enter any reasons for return.
5. On the fifth page (Page 5), select the items to be returned (Yes or No).
6. On the sixth page (Page 6), enter any notes related to the return.
7. On the seventh page (Page 7), provide the return date.
8. On the eighth page (Page 8), select whether the property was returned (Yes or No).
9. On the ninth page (Page 9), select the status of the returned items (Active or Inactive).

## Field-by-Field Explanation
* **Property Details** (Page 1, `return_of_property_form_page_1`, label: property_details, type: text, required: false): Enter the details of the property being returned.
* **Return Date** (Page 2, `return_of_property_form_page_2`, label: return_date, type: number, required: false): Enter the date the property is expected to be returned.
* **Return Status** (Page 3, `return_of_property_form_page_3`, label: return_status, type: select_one, required: false): Select the current status of the property (Active or Inactive).
* **Return Reason** (Page 4, `return_of_property_form_page_4`, label: return_reason, type: text, required: false): Enter the reason for returning the property.
* **Return Items** (Page 5, `return_of_property_form_page_5`, label: return_items, type: select_multiple, required: false): Select whether items are to be returned (Yes or No).
* **Return Notes** (Page 6, `return_of_property_form_page_6`, label: return_notes, type: note, required: false): Enter any notes related to the return.
* **Return Date** (Page 7, `return_of_property_form_page_7`, label: return_date, type: date, required: false): Enter the return date.
* **Property Returned** (Page 8, `return_of_property_form_page_8`, label: return_property, type: select_one, required: false): Select whether the property was returned (Yes or No).
* **Return Status** (Page 9, `return_of_property_form_page_9`, label: return_status, type: select_multiple, required: false): Select the status of the returned items (Active or Inactive).

## Tips
* Make sure to enter accurate and complete information to ensure a smooth return process.
* If you are unsure about any field, consult with the relevant department for guidance.
* Double-check your entries before submitting the form.
