# Housing Discrimination Disclosure Form - Help Guide
## Purpose

This Housing Discrimination Disclosure Form is designed to help monitor and address potential housing-related discrimination. It is a tool to help identify areas where discrimination may be occurring, facilitating fair housing practices.

## How To Complete This Form

1.  Review the form carefully before starting to fill it out.
2.  Fill out the form honestly and accurately based on your status.
3.  Ensure that all required fields are completed.

## Field-by-Field Explanation

*   **Tenant Information** (Tenant Information, text, required: false):
    This section is meant to capture general information about the tenant.
*   **Tenant Status** (Tenant Status, select_one, required: false):
    *   **Currently employed**: If you are currently employed, select this option.
    *   **Not employed**: If you are not employed, select this option.
    *   **Recently unemployed**: If you were recently unemployed, select this option.
    *   **Retired**: If you are retired, select this option.
*   **Discrimination Status** (Discrimination Status, select_multiple, required: false):
    *   **Racial or ethnic origin**: If you have experienced discrimination due to your racial or ethnic origin, select this option.
    *   **Gender**: If you have experienced discrimination due to your gender, select this option.
    *   **Sexual orientation or gender identity**: If you have experienced discrimination due to your sexual orientation or gender identity, select this option.
    *   **Disability**: If you have experienced discrimination due to your disability, select this option.
    *   **Pregnancy or marital status**: If you have experienced discrimination due to your pregnancy or marital status, select this option.
    *   **Age**: If you have experienced discrimination due to your age, select this option.
    *   **Other (specify)**: If you have experienced discrimination for reasons not listed, select this option.
*   **Housing Status** (Housing Status, select_multiple, required: false):
    *   **Currently renting**: If you are currently renting, select this option.
    *   **Currently own a home**: If you currently own a home, select this option.
    *   **Recently sold a home**: If you have recently sold a home, select this option.
    *   **Never owned a home**: If you have never owned a home, select this option.
    *   **Renting from relative**: If you are renting from a relative, select this option.
*   **Reason For Move** (Reason For Move, select_multiple, required: false):
    *   **Job or career change**: If you are moving for a job or career change, select this option.
    *   **Family or family planning**: If you are moving for family or family planning reasons, select this option.
    *   **School or education**: If you are moving for school or education reasons, select this option.
    *   **Medical**: If you are moving for medical reasons, select this option.
    *   **Financial**: If you are moving for financial reasons, select this option.
    *   **Partner or family member**: If you are moving for a partner or family member, select this option.
    *   **Other (specify)**: If you are moving for reasons not listed, select this option.
*   **Housing Discrimination Disclosure Details** (Housing Discrimination Disclosure Details, note, required: false):
    This section is meant to provide additional information about any discrimination you have experienced.
*   **Signature** (Signature, text, required: false):
    Please sign below to acknowledge that you have completed this form accurately and honestly.
*   **Date** (Date, date, required: false):
    Please enter the date you completed this form.

Please note that while this form is provided as a template, it is essential to review and customize it according to your specific business needs and regional regulations. Additionally, ensure that the form is reviewed and approved by relevant authorities before use.
