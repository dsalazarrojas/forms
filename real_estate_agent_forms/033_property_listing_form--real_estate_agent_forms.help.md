The form purpose is to gather information about a property for real estate listings. It includes fields for property address, type, status, price, currency, and other relevant details such as bedrooms, bathrooms, square footage, lot size, year built, status changes, listing agent details, and property listings status. This form is designed to be completed by listing agents or real estate professionals to provide accurate and up-to-date information about properties listed for sale or rent.

### Property Address
* **Property Address** (`property_address`, text, required/optional): Enter the property's street address.
* **Property Type** (`property_type`, select_one, required/optional): Select the type of property, such as Residential, Commercial, or Industrial.
* **Status** (`property_status`, text, required/optional): Enter the status of the property, such as Active, Sold, or Pending.
* **Price** (`property_price`, text, required/optional): Enter the property's price.
* **Price Currency** (`property_price_currency`, select_one, required/optional): Select the currency of the property's price, such as USD, EUR, CAD, JPY.
* **Bedrooms** (`property_bedrooms`, text, required/optional): Enter the number of bedrooms in the property.
* **Bathrooms** (`property_bathrooms`, text, required/optional): Enter the number of bathrooms in the property.
* **Square Footage** (`property_sqft`, text, required/optional): Enter the square footage of the property.
* **Lot Size** (`property_lot_size`, text, required/optional): Enter the lot size of the property.
* **Year Built** (`property_year_built`, date, required/optional): Enter the year the property was built.
* **Status Changed** (`property_status_changed`, text, required/optional): Enter the reason for any status changes.
* **Status Changed Date** (`property_status_changed_date`, date, required/optional): Enter the date of any status changes.
* **Property Status Description** (`property_status_description`, text, required/optional): Enter a brief description of the property's status.
* **Square Footage** (`property_sqft`, text, required/optional): Enter the square footage of the property.
* **Status Change Reason** (`property_status_changed_reason`, text, required/optional): Enter a brief description of the reason for any status changes.
* **Listing Agent** (`property_listing_agent`, text, required/optional): Enter the listing agent's name.
* **Listing Agent Phone** (`property_listing_agent_phone`, text, required/optional): Enter the listing agent's phone number.
* **Listing Agent Email** (`property_listing_agent_email`, text, required/optional): Enter the listing agent's email.
* **Listing Agent Notes** (`property_listing_agent_notes`, text, required/optional): Enter any notes about the listing agent.
* **Listing Agent Commission** (`property_listing_agent_commission`, text, required/optional): Enter the listing agent's commission.
* **Listing Agent Commission Rate** (`property_listing_agent_commission_rate`, text, required/optional): Enter the listing agent's commission rate.
* **Listing Agent Company** (`property_listing_agent_company`, text, required/optional): Enter the listing agent's company name.
* **Listing Agent Company Website** (`property_listing_agent_company_website`, text, required/optional): Enter the listing agent's company website.
* **Property Listings Status** (`property_listings_status`, text, required/optional): Enter the status of the property listings.
* **Property Listings Status Description** (`property_listings_status_description`, text, required/optional): Enter a brief description of the property's listings status.
* **Property Listings Status Changed Date** (`property_listings_status_changed_date`, date, required/optional): Enter the date of any status changes in the property listings.
* **Property Listings Status Changed Reason** (`property_listings_status_changed_reason`, text, required/optional): Enter a brief description of the reason for any status changes in the property listings.

## Tips
* Ensure you fill out all required fields accurately and completely.
* Double-check the property's address and type to ensure they match the property's actual characteristics.
* If you are unsure about any field, consult the listing agent or property owner.
