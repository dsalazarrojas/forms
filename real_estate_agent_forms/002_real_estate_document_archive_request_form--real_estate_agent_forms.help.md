# real_estate_document_archive_request_form - Help Guide
## Purpose
The real_estate_document_archive_request_form is designed to collect information for real estate document archives.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the property address.
2. Provide a reason for the request.
3. Select the type of document you are requesting to archive.
4. Enter the date and other relevant details about the document.
5. Add any additional notes if necessary.
6. Enter the contact information of the person requesting the archive.
7. Select the real estate office and property manager involved.
8. Enter the due date and time for the archive.
9. Set the priority level of the archive.
10. Finally, submit the form.

## Field-by-Field Explanation

* **Property Address** (`property_address`, text, required): Enter the address of the property related to the document you are requesting to archive.
* **Request Reason** (`request_reason`, text, required): Briefly explain why you are requesting the document to be archived.
* **Document Type** (`document_type`, select_one, required): Select the type of document you are requesting to archive (e.g., Deed, Lease, Assignment).
* **Document Date** (`document_date`, date, required): Enter the date of the document.
* **Document Name** (`document_name`, text, required): Enter the name of the document.
* **Document Location** (`document_location`, text, required): Enter the location of the document.
* **Document Number** (`document_number`, text, required): Enter the number of the document.
* **Document Date Received** (`document_date_received`, date, required): Enter the date the document was received.
* **Document Notes** (`document_notes`, text, optional): Add any additional notes about the document.
* **Document Status** (`document_status`, select_multiple, required): Select the status of the document (e.g., Pending, In Progress, Completed).
* **Contact Name** (`contact_name`, text, optional): Enter the name of the person requesting the archive.
* **Contact Email** (`contact_email`, email, optional): Enter the email of the person requesting the archive.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the person requesting the archive.
* **Document URL** (`document_url`, text, optional): Enter any URL related to the document.
* **Real Estate Office** (`real_estate_office`, text, required): Select the real estate office involved.
* **Property Manager** (`property_manager`, text, required): Select the property manager involved.
* **Legal Team** (`legal_team`, text, required): Select the legal team involved.
* **Notes** (`notes`, text, optional): Add any additional notes about the archive.
* **Request Date** (`request_date`, date, required): Enter the date the request was made.
* **Request Time** (`request_time`, time, optional): Enter the time the request was made.
* **Assigned To** (`assigned_to`, text, optional): Enter the person assigned to the archive.
* **Due Date** (`due_date`, date, required): Enter the date the archive is due by.
* **Due Time** (`due_time`, time, optional): Enter the time the archive is due by.
* **Priority** (`priority`, number, optional): Set the priority level of the archive (e.g., 1, 2, 3).
* **Submitted By** (`submitted_by`, text, optional): Enter the name of the person submitting the request.

Note: Fields marked as required must be filled in for the form to be submitted successfully. Optional fields can be left blank if not applicable.
