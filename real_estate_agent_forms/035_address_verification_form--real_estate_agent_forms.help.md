**Address Verification Form - Help Guide**

**Purpose**
-----------

This form is designed to collect information for verifying an address through a third-party verification process. It's meant for individuals or entities that need to confirm an address as part of a transaction, rental agreement, or other official process.

**How To Complete This Form**
---------------------------

1.  Fill out the required fields with accurate and complete information.
2.  Choose the correct options for each field as prompted.
3.  Submit the form once all fields have been filled out.

**Field-by-Field Explanation**

*   **Verifier Information** (`Verifier Information`, `note`, **required:** **false**): This field is intended for any additional information about the person verifying the address.
*   **Subject Name** (`Subject name`, `text`, **required:** **true**): Enter the name of the person or entity to be verified.
*   **Claimed Address** (`Claimed address`, `text`, **required:** **true**): Enter the address to be verified.
*   **Verification Method** (`Verification method`, `select_one`, **required:** **true**): Choose the type of proof provided for verification.
    \* Utility bill
    \* Lease agreement
    \* Government ID
    \* Other
*   **Document Details** (`Document details`, `text`, **required:** **false**): If applicable, enter the issuing authority and date of the document.
*   **Verifier Name** (`Verifier name`, `text`, **required:** **true**): Enter the name of the person completing the verification.
*   **Verification Date** (`Verification date`, `date`, **required:** **true**): Enter the date the document was checked.
*   **Verification Outcome** (`Verification outcome`, `select_one`, **required:** **true**): Choose whether the address was verified, not verified, or is pending.
    \* Verified
    \* Not verified
    \* Pending
*   **Notes** (`Notes`, `text`, **required:** **false**): If necessary, add any additional comments or observations about the verification process.
*   **Signature** (`Signature name`, `text`, **required:** **true**): Enter the typed name of the person completing the verification.
