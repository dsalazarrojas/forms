# House Disclosure Form - Help Guide
## Purpose
The House Disclosure Form is designed to collect information about a house or property, allowing users to provide accurate and necessary details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the property address in the **Property Address** field.
2. Enter the name of the seller in the **Seller** field.
3. Enter the name of the buyer in the **Buyer** field.
4. Select the type of property from the **Property Type** dropdown menu.
5. Enter the square footage of the property in the **Square Footage** field.

## Field-by-Field Explanation
* **Property Address (Property Address, Text, Optional)**: Enter the address of the property in a format such as "123 Main St, Anytown, USA 12345".
* **Seller (Seller, Text, Optional)**: Enter the name of the person selling the property.
* **Buyer (Buyer, Text, Optional)**: Enter the name of the person buying the property.
* **Property Type (Property Type, Select One, Required)**: Select the type of property from the dropdown menu:
	+ Single Family
	+ Condo
	+ Townhouse
	+ Duplex
	+ Apartment
* **Square Footage (Square Footage, Number, Optional)**: Enter the square footage of the property in a numerical value.

## Tips
* Ensure that the property address is accurate and complete.
* If you are unsure about the property type, consult with the seller or real estate agent for guidance.
* Enter the square footage in a numerical value, without any commas or other characters.
