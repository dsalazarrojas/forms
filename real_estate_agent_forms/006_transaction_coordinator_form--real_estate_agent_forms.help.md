# Transaction Coordinator Form - Help Guide
## Purpose
The Transaction Coordinator Form is a crucial tool for gathering information from Transaction Coordinators in real estate transactions. It helps to streamline the coordination process by collecting relevant details and facilitating efficient communication between parties.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select the relevant options for each field accurately and thoroughly.
2. Ensure that you have the necessary permissions or approvals to complete this form.
3. Review and verify the information before submitting.

## Field-by-Field Explanation

* **Contact Information (1)** (`Yes/No`, required/optional): This field is used to indicate whether the transaction involves contact with the client. Please select 'Yes' if the transaction involves direct contact with the client.
* **Client (2)** (`Yes/No`, required/true): This field indicates if the client is involved in the transaction. Select 'Yes' if the client is directly involved.
* **Transaction Details (3)** (text, required/true): Enter a brief description of the transaction details.
* **Real Estate Agents (4)** (`Yes/No`, required/optional): This field is used to indicate if real estate agents are involved in the transaction. Select 'Yes' if real estate agents are involved.
* **Property Status (5)** (Active/Inactive, required/true): Select the current status of the property (Active or Inactive).
* **Loan Amount (6)** (number, required/true): Enter the loan amount associated with the transaction.
* **Down Payment (7)** (number, optional/false): If applicable, enter the down payment amount.
* **Closing Date (8)** (date, required/true): Enter the expected closing date of the transaction.
* **Closing Time (9)** (time, required/true): Enter the expected closing time of the transaction.
* **Comments (10)** (note, optional/false): Provide any additional comments or notes about the transaction.
* **Email (11)** (email, optional/false): Enter your email address for communication purposes.
* **Phone (12)** (text, optional/false): Enter your phone number for communication purposes.
* **Assigned Tool (13)** (`chatjimmy/Other`, required/true): This field is used to select which tool or system will be used for communication and coordination. Select 'chatjimmy' if the transaction will be coordinated using this tool.
* **Assigned Agent (14)** (`Yes/No`, required/true): This field indicates if an agent is assigned to the transaction. Select 'Yes' if an agent is assigned.

Note: Fields with a (*) are mandatory fields, while others are optional.
