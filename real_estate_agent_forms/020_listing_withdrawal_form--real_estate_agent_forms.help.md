# Listing Withdrawal Form - Help Guide
## Purpose
The purpose of this form is to withdraw a listing from the system. This form is used to notify the system that a listing is no longer active and update its status accordingly.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with the relevant information about the listing you want to withdraw.
2. Choose the reason for withdrawal from the select_one field.
3. Add any additional notes if necessary.
4. Enter the agent's email address and phone number for communication purposes.
5. Select the date and time of withdrawal.
6. Review and submit the form to update the listing status.

## Field-by-Field Explanation
* **withdrawal_form_details**: A text field to enter a brief description of the listing withdrawal.
* **withdrawal_reason**: Select the reason for withdrawal from the provided options:
	+ Cancellation of Listing
	+ Sale Pending
	+ Withdrawal Request
* **agent_note**: A free-text field for the agent to add any additional notes about the withdrawal.
* **client_name**: Enter the name of the client associated with the listing.
* **agent_name**: Enter the name of the agent associated with the listing.
* **property_address**: Enter the address of the property being withdrawn.
* **reason_for_withdrawal**: Enter a brief description of the reason for the listing withdrawal.
* **agent_email**: Enter the agent's email address for communication purposes.
* **phone_number**: Enter the agent's phone number for communication purposes.
* **date_of_withdrawal**: Select the date of withdrawal from the calendar options.
* **time_of_withdrawal**: Select the time of withdrawal from the clock options.
* **additional_notes**: Add any additional notes about the withdrawal.
 
## Tips
* Make sure to fill in all the required fields to ensure accurate listing status update.
* Use clear and concise language when filling in the text fields to avoid confusion.
* If the reason for withdrawal is not listed, choose the option that best describes the situation.
