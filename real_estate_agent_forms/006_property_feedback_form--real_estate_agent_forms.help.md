# Property Feedback Form - Help Guide
## Purpose
The Property Feedback Form is designed to collect feedback and insights about properties from users. This form is intended to help us improve our services and provide a better experience for our clients.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the property address in the `Property Address` field.
2. Select the current status of the property from the `Property Status` dropdown.
3. Choose the type of property from the `Type of Property` dropdown.
4. If applicable, provide the price range of the property.
5. Enter any additional feedback or comments in the `Feedback` field.
6. If you obtained the property information from a source other than an agent, select the correct source from the `Source` dropdown.
7. Finally, enter any additional message or comments in the `Message` field.
8. Select the date you obtained the property information from the `Date` field.

## Field-by-Field Explanation
### Property Address
* **Property Address (text)**: Enter the address of the property you are providing feedback on.

### Property Status
* **Property Status (select_one)**: Select the current status of the property (Active, Pending, or Sold).

### Type of Property
* **Type of Property (select_multiple)**: Choose all that apply from the list of property types (Condo, House, Townhouse).

### Price Range
* **Price Range (number)**: If applicable, enter the price range of the property. This field is optional.

### Feedback
* **Feedback (note)**: Enter any additional feedback or comments about the property you are providing input on.

### Property Agent
* **Property Agent (text)**: If you received the property information from an agent, enter their name.

### Source
* **Source (select_one)**: Select where you obtained the property information from (Online, Agent, Social Media, Word of Mouth, or Other).

### Message
* **Message (note)**: Enter any additional message or comments you would like to provide.

### Date
* **Date (date)**: Select the date you obtained the property information from the calendar. This field is optional.

This guide provides a clear understanding of each field and how to complete the form correctly, making it easier for end-users to provide valuable feedback to help improve our services.
