# House Appraisal Checklist Form - Help Guide
## Purpose
The House Appraisal Checklist Form is designed to collect data about a property's exterior features, condition, and other relevant details to help real estate agents assess its value and condition.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to ensure you have all the necessary information about the property.
2. Answer each field according to your observations and knowledge about the property.
3. Use the select_one and select_multiple fields to choose the correct options for each question.
4. If you are unsure about any information, please provide an explanation in the text field for further clarification.

## Field-by-Field Explanation
* **Exterior Features**: Enter a brief description of the property's exterior features, such as its condition, materials, and any notable characteristics.
	+ Type: text
	+ Required: False
* **Roof Condition**: Select the correct condition of the property's roof from the options provided:
	+ Asphalt: The roof is made of asphalt shingles.
	+ Clay-Tile: The roof is made of clay tiles.
	+ Composite: The roof is made of composite materials.
	+ Metal: The roof is made of metal materials.
	+ None: The property does not have a roof.
	+ Other: The property has a roof made of other materials.
	+ Slate: The roof is made of slate.
	+ Wood: The roof is made of wood.
	+ Required: False
* **Foundation Type**: Select the correct type of foundation for the property:
	+ Concrete: The property has a concrete foundation.
	+ Gravel: The property has a gravel foundation.
	+ Sand: The property has a sand foundation.
	+ Required: False
* **Lot Size**: Enter the size of the property's lot in square feet or acres.
	+ Type: number
	+ Required: False
* **Square Footage**: Enter the total square footage of the property.
	+ Type: number
	+ Required: False
* **Year Built**: Enter the year the property was built.
	+ Type: number
	+ Required: False
* **Number Of Bedrooms**: Enter the number of bedrooms in the property.
	+ Type: number
	+ Required: False
* **Number Of Bathrooms**: Enter the number of bathrooms in the property.
	+ Type: number
	+ Required: False
* **Number Of Levels**: Enter the number of levels or stories in the property.
	+ Type: number
	+ Required: False
* **Garage Parking**: Select whether the property has a garage or parking:
	+ None: The property does not have a garage or parking.
	+ True: The property has a garage or parking.
	+ Required: False
* **Pool**: Select whether the property has a pool:
	+ True: The property has a pool.
	+ False: The property does not have a pool.
	+ Required: False
* **Fireplaces**: Select whether the property has fireplaces:
	+ True: The property has fireplaces.
	+ False: The property does not have fireplaces.
	+ Required: False
* **Basement**: Select the type of basement the property has:
	+ Finished: The property has a finished basement.
	+ Partial: The property has a partially finished basement.
	+ None: The property does not have a basement.
	+ Required: False
* **Has Septic System**: Select whether the property has a septic system:
	+ True: The property has a septic system.
	+ False: The property does not have a septic system.
	+ Required: False
* **Has Wells**: Select whether the property has wells:
	+ True: The property has wells.
	+ False: The property does not have wells.
	+ Required: False
* **Neighborhood**: Enter a brief description of the property's neighborhood.
	+ Type: text
	+ Required: False

Note: This help guide is intended to be a general guide and may not cover every possible scenario. If you have any questions or concerns, please consult the real estate agent or property owner directly.
