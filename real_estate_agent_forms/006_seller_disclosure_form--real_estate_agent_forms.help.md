# Seller Disclosure Form - Help Guide
## Purpose
This form is used by real estate agents to gather information about potential hazards in a property. It's used to inform a seller of any issues that might affect the value or safety of a property.

## How To Complete This Form
To complete this form, follow these steps:
1. Select whether or not you are using real estate forms.
2. Check off any hazards that you have found during the inspection.
3. Provide a description of the form's purpose.
4. Select whether or not an output file should be generated based on the form's data.
5. Choose a category for the form.
6. Enter a description of the form content.
7. (Optional) Select whether or not an assigned tool was used during the inspection.

## Field-by-Field Explanation
* **Seller Disclosure Form** (Note Field): This is a title field, it's for informational purposes only.
* **Real Estate Agent Forms** (Select One: Yes/No): Select "Yes" if you are using real estate forms for this property, otherwise select "No".
* **Property Hazards** (Select Multiple: Yes/No): Check off any hazards you have found during the inspection.
* **Seller Disclosure Form Description** (Text): Provide a brief description of the form's purpose and use.
* **Real Estate Agent Forms Description** (Text): This field is redundant and not necessary. You can skip this field.
* **Form ID** (Number): This field is for tracking and identifying the form within the system.
* **Assigned Tool** (Select One: Yes/No): Select "Yes" if you are using an assigned tool during the inspection, otherwise select "No".
* **Output File** (Select One: Yes/No): Select "Yes" if you want to generate a report or document based on the form's data, otherwise select "No".
* **Category** (Select One): Choose a category for the form.
* **Description** (Text): Enter a description of the form content.
* **Form ID** (Number): This field is redundant and not necessary. You can skip this field.
* **Category** (Select One): Select a category for the form.
* **Description** (Text): Enter a description of the form content.
* **Form ID** (Number): This field is redundant and not necessary, same as field 11.
