# Landlord Inspection Form - Help Guide
## Purpose
This form is designed to guide landlords through a comprehensive inspection of a rental property, ensuring that all essential systems and features are checked and documented.

## How To Complete This Form
1. Start by carefully reading the form and understanding the different sections and fields.
2. Complete each field with the information you find during the inspection, making sure to check all required fields.
3. For select fields, choose the correct option from the provided list.
4. If you're unsure about any aspect of the form, refer to the field-by-field explanations below.

## Field-by-Field Explanation
* **General Inspection (Text)** (`general_inspection`, required, Text): Describe the overall condition and appearance of the property, including any notable issues or concerns.
* **Electrical Systems (Select)** (`electrical_systems`, required, Select One): Choose one option to describe the current status of the electrical systems, such as Appliances, Fixtures, or Wiring.
* **Plumbing Systems (Select Multiple)** (`plumbing_systems`, required, Select Multiple): Select all applicable options that describe the current status of the plumbing systems, such as Water Heater, Sink, and Toilet.
* **Heating/Cooling Systems (Select Multiple)** (`heatingcooling_systems`, required, Select Multiple): Choose all applicable options that describe the current status of heating and cooling systems, such as Air Conditioning, Fireplace, and Heating.
* **Safety Equipment (Select)** (`safety_equipment`, required, Select One): Select one option to describe the current status of safety equipment, such as Smoke Detector, Fire Extinguisher, or Fire Alarm.
* **Doors and Windows (Select Multiple)** (`doorsandwindows`, required, Select Multiple): Select all applicable options that describe the condition of doors and windows, such as Doors, Windows, and Locks.
* **Roof and Siding (Select Multiple)** (`roof_and_siding`, required, Select Multiple): Choose all applicable options that describe the condition of the roof and siding, such as Roof, Siding, and Gutters.
