# Property Showing Reminder Form - Help Guide
## Purpose
The Property Showing Reminder Form is designed to record and track property showings, providing a centralized location for real estate agents to capture and share information about upcoming showings.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the date of the showing from the calendar picker.
2. Enter the showing time.
3. Enter the address of the property being shown.
4. Identify the contact person responsible for the showing.
5. Provide details about the property type.
6. (Optional) Select the showing status and enter any additional details.

## Field-by-Field Explanation
* **Property Showings** (`property_showing_reminder_form`, note, required): This field is the title of the form, it is not a field to fill in.
* **Showings Date** (`property_showing_reminder_date`, date, required): Select the date of the showing using the calendar picker.
* **Showing Time** (`property_showing_time`, time, required): Enter the time of the showing.
* **Property Address** (`property_address`, text, required): Enter the address of the property being shown.
* **Contact Person** (`contact_person`, text, required): Identify the contact person responsible for the showing.
* **Property Type** (`property_type`, text, optional): Provide details about the property type (e.g., single-family home, condominium, etc.).
* **Property Price** (`property_price`, text, optional): Enter the price of the property.
* **Showing Status** (`showing_status`, select_multiple, optional): Select the showing status from the options: Available, Under Offer, or Sold.
* **Showing Details** (`showing_details`, text, optional): Enter any additional details about the showing.

## Tips
* Make sure to fill out all required fields.
* Use the calendar picker to select the date of the showing for accuracy.
* If the showing status is under offer, be sure to provide any additional details about the offer.
* If the showing status is sold, update the form accordingly and remove any further showings.
* Review and update the form regularly to ensure all showings are accurately recorded.
