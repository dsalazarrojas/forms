# Home Sale Pre-Approval Request Form - Help Guide
## Purpose

This form is used by real estate agents to request a pre-approval for a home sale. It collects information about the sale and the pre-approval status.

## How To Complete This Form

1.  Select the relevant fields for the pre-approval request.
2.  Fill out the fields required for the pre-approval request.
3.  Review the form for accuracy before submitting.

## Field-by-Field Explanation

*   **Seller Details (<type> select_one)**:
    *   Please select your name and contact information.
*   **Home Type (<type> select_one)**:
    *   Please select the type of home (Home, Condo/Townhouse, Townhouse/Condo, Duplex, Single-Family Home) associated with the pre-approval request.
*   **Purchase Price (<type> number)**:
    *   Enter the purchase price of the home.
*   **Down Payment (<type> number)**:
    *   Enter the down payment amount.
*   **Credit Score (<type> number)**:
    *   Enter your credit score.
*   **Home Value (<type> number)**:
    *   Enter the home value.
*   **Property Type (<type> select_one)**:
    *   Please select the property type (Single Family Home, Condominum, Townhome, Apartment) associated with the pre-approval request.
*   **Loan Term in Years (<type> number)**:
    *   Enter the loan term in years.
*   **Loan Amount in Dollars (<type> number)**:
    *   Enter the loan amount.
*   **Pre-Approval (<type> select_one)**:
    *   Check if pre-approval is requested.
*   **Pre-Approval Status (<type> select_one)**:
    *   Please select the pre-approval status (Active, Inactive).
*   **Pre-Approval Comments (<type> text)**:
    *   Enter any comments about the pre-approval request.
*   **Pre-Approval Reason (<type> text)**:
    *   Enter any reason for the pre-approval request.
*   **Loan Provider (<type> text)**:
    *   Enter the loan provider information.

**Tips:**

*   Make sure to fill out all required fields.
*   Validate that the input data is within the specified ranges or formats.
*   Review the form for accuracy before submitting.
