# online-commercial-lease-application-form - Help Guide
## Purpose
This form is designed for agents to collect online commercial lease application information from clients. It is intended to be used during the commercial lease process, and it helps to streamline the application process by gathering essential details from both the landlord and the tenant.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. **Fill out each page of the form**, which includes sections for **User Information**, **Contact Information**, **Lease Information**, **Property Information**, **Landlord Information**, and **Lease Term**.
2. **Select "Yes" or "No" answers** for questions that require a binary response (e.g., Lease Term, Lease Duration).
3. **Enter your answers** in the text fields for questions that ask for descriptive information (e.g., User Information, Property Address).
4. **Choose a date** for questions that ask for a specific date (e.g., Lease Date).
5. **Submit the form** once you have completed all the required and optional fields.

## Field-by-Field Explanation
* **User Information** (id: 1, type: text, required: false): Enter your personal details to help us understand who you are.
* **Contact Information** (id: 2, type: text, required: false): Provide your contact information so we can get in touch with you for any further queries.
* **Lease Information** (id: 3, type: text, required: false): Describe the type of lease you are looking for (e.g., commercial, retail, residential).
* **Property Information** (id: 4, type: text, required: false): Enter the address and details of the property you are looking for.
* **Landlord Information** (id: 5, type: text, required: false): Provide information about the landlord or property owner (e.g., name, contact details).
* **Tenant Information** (id: 6, type: text, required: false): Enter the details of the tenant (e.g., name, contact details).
* **Lease Term** (id: 7, type: select_one, required: false): Choose whether the lease is for a fixed term or month-to-month.
* **Lease Signature** (id: 8, type: date, required: false): Date on which you sign this lease.
* **Tenant Signature** (id: 9, type: date, required: false): Date on which the tenant signs this lease.
* **Lease Date** (id: 10, type: date, required: false): Date on which the lease commences.
* **Lease Duration** (id: 11, type: select_multiple, required: false): Check the lease duration you are interested in (e.g., 6 months, 1 year).
* **Property Location** (id: 12, type: text, required: false): Describe the location of the property (e.g., city, state, country).
* **Property Address** (id: 13, type: text, required: false): Enter the property address in full.
* **Rent Amount** (id: 14, type: number, required: false): Enter the rent amount (e.g., $1000, $2000).
* **Rent Period** (id: 15, type: select_one, required: false): Choose whether the rent is paid monthly or annually.

## Tips
* Make sure to fill out all the required fields to ensure that your application is complete and processed smoothly.
* If you have any questions or concerns, please don't hesitate to contact us.
* This form is intended to be used during the commercial lease process, so please ensure that you are providing accurate and relevant information.
