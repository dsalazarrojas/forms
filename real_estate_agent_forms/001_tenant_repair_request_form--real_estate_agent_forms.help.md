# Tenant Repair Request Form - Help Guide
## Purpose
The Tenant Repair Request Form is designed to allow tenants to report any issues or problems they encounter in their rented property. This form will be reviewed by the property manager, who will then address the repair request accordingly.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your name or a unique identifier for the property manager to reference your request.
2. Provide the address of the property where the issue is located.
3. Select the type of repair needed from the options provided.
4. Describe the issue in detail, providing as much information as possible about the problem you are experiencing.

## Field-by-Field Explanation
* **property_manager**:
	+ (text input field)
	+ This field is used to collect your name or a unique identifier for the property manager to reference your request. Please enter your name or a recognizable identifier so that your request can be accurately tracked.
* **property_address**:
	+ (text input field)
	+ Please enter the address of the property where the issue is located. This will help the property manager quickly identify the location of the problem.
* **repair_type**:
	+ (select_one dropdown list)
	+ Choose the type of repair needed from the options provided. This will help the property manager understand the nature of the issue and prioritize the repair accordingly.
* **issue_description**:
	+ (text input field)
	+ Describe the issue in as much detail as possible, including any relevant information about the problem you are experiencing. This will help the property manager understand the root cause of the issue and provide an effective solution.
