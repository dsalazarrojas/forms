# Lease Renewal Or Termination Form - Help Guide
## Purpose
The Lease Renewal Or Termination Form is a form used to manage the renewal or termination of a lease. It helps you to document the details of the lease end date, renewal request, and any termination reason. This form is essential for landlords and tenants to communicate and agree on lease terms.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the lease details and ensure you are filling out the correct type of form (renewal or termination).
2. Fill out the required fields with accurate and up-to-date information.
3. Ensure that you are not duplicating any information that is already present in the lease agreement or other relevant documents.

## Field-by-Field Explanation

* **Tenant Information (`tenant_info`, text, required: false)**: This field is used to capture the tenant's contact information and any other relevant details.
* **Lease Information (`lease_info`, text, required: false)**: This field is used to provide a brief description of the lease and its terms.
* **Renewal Request (`renewal_request`, text, required: false)**: This field is used to document the tenant's request for lease renewal, including any specific terms or conditions they wish to apply for the renewal.
* **Termination Reason (`termination_reason`, text, required: false)**: This field is used to document the reason for lease termination, if applicable.
* **Lease End Date (`lease_end_date`, date, required: false)**: This field is used to specify the date when the lease will end, if the form is being used for termination.
* **Renewal Date (`renewal_date`, date, required: false)**: This field is used to specify the date when the lease will renew, if the form is being used for renewal.
* **Lease Term (`lease_term`, number, required: false)**: This field is used to document the lease term or duration.
* **Rent Amount (`rent_amount`, number, required: false)**: This field is used to document the rent amount or any changes to it.
* **Termination Fee (`termination_fee`, number, required: false)**: This field is used to document any termination fees or penalties, if applicable.
* **Lease End Date (`lease_end_date`, date, required: false)**: This field is a duplicate of `lease_end_date` and is not actually part of the form; it was likely a duplicate entry in the form schema.

Note: The fields marked as "required: false" can be omitted if the user does not have any information to provide for that field.
