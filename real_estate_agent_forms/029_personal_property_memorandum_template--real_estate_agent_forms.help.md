# personal-property-memorandum-template - Help Guide
## Purpose

The "personal-property-memorandum-template" form is designed to help users document and describe a personal property. It is essential for real estate agents and other professionals to accurately collect and record property details to facilitate effective communication and decision-making.

## How To Complete This Form

1.  To complete this form, start by carefully selecting the correct options for each field. Make sure to review and understand each field's explanation before proceeding.
2.  Begin by selecting the property address from the "Properties List" field. This field allows you to choose from a list of available properties.
3.  Next, select the type of property from the "Property Type" field. Choose from the available options such as Single Family, Condo, Townhouse, Apartment, or Multi.
4.  If applicable, enter the square footage of the property in the "Square Footage" field.
5.  Enter the lot size of the property in the "Lot Size" field.
6.  In the "Street" field, enter the name of the street on which the property is located.
7.  In the "City" field, select the city where the property is located.
8.  Finally, in the "State" field, select the state where the property is located.

## Field-by-Field Explanation

*   **Personal Property Memorandum** (`Personal Property Memorandum`, `text`, optional): Enter a brief description or memo about the property. This field provides a space to record any important notes or details about the property.
*   **Properties List** (`Properties List`, `select_multiple`, optional): Select from the list of available properties to associate with this memoranda template. This field helps to narrow down the property information and provide a specific property to focus on.
*   **Property Type** (`Property Type`, `select_one`, optional): Choose the type of property from the available options such as Single Family, Condo, Townhouse, Apartment, or Multi. This field helps to classify the property type.
*   **Square Footage** (`Square Footage`, `number`, optional): Enter the square footage of the property. If the property has multiple square footage, you can enter the total or main area.
*   **Lot Size** (`Lot Size`, `number`, optional): Enter the size of the property's lot or land area.
*   **Street** (`Street`, `text`, optional): Enter the name of the street on which the property is located.
*   **City** (`City`, `select_one`, optional): Select the city where the property is located from the available options.
*   **State** (`State`, `select_one`, optional): Select the state where the property is located from the available options.

## Tips

*   Make sure to carefully review and understand each field before proceeding with filling out the form.
*   Use the form to document and describe a specific property, ensuring all fields are filled with accurate information.
*   The form's fields can be filled in any order, but it is recommended to start with the "Properties List" field to narrow down the property information.
