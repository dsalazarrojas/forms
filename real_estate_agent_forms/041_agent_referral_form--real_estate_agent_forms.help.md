# Agent Referral Form - Help Guide
## Purpose
The Agent Referral Form is used by agents to refer new clients or prospects to our organization. It captures essential information about the referrer, the referred client, and the referral reason.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the person making the referral (Referrer name).
2. Provide the email address of the person making the referral (Referrer contact email).
3. Enter the name of the client being referred.
4. Select the type of property the client is interested in (Residential, Commercial, Rental, or Land).
5. Briefly describe the reason for the referral.
6. (Optional) Enter a specific time when it's best to contact the referred client.
7. If an incentive agreement is in place for the referral, mark the "True" option.
8. If you know the agent handling the referral, enter their name.
9. Add any additional notes about the referral.

## Field-by-Field Explanation
- **Referrer name**: Enter the name of the person making the referral.
  * Type: Text
  * Required: Yes
  * Hint: Person making the referral
- **Referrer contact email**: Enter the email address of the person making the referral.
  * Type: Email
  * Required: Yes
  * Hint: Email for follow up
- **Referred client name**: Enter the name of the client being referred.
  * Type: Text
  * Required: Yes
  * Hint: Name of the person being referred
- **Property type**: Select the type of property the client is interested in.
  * Type: Select One
  * Required: Yes
  * Options: Residential, Commercial, Rental, Land
- **Reason for referral**: Briefly describe the reason for the referral.
  * Type: Text
  * Required: No
  * Hint: Brief description of motivation
- **Preferred contact time for referred client**: Enter a specific time when it's best to contact the referred client.
  * Type: Time
  * Required: No
  * Hint: Best time to reach referred client
- **Is an incentive agreement in place**: If an incentive agreement is in place for the referral, mark the "True" option.
  * Type: Select One
  * Required: No
  * Hint: Referral fee agreement status
- **Assigned agent**: If you know the agent handling the referral, enter their name.
  * Type: Text
  * Required: No
  * Hint: Agent to handle referral if known
- **Notes**: Add any additional information about the referral.
  * Type: Text
  * Required: No
  * Hint: Any other helpful information

## Tips
- Always enter the required fields for the referrer and referred client information.
- Make sure to select the correct property type from the options provided.
- If no incentive agreement is in place, mark "False".
- Add any additional comments or information in the notes field as needed.
