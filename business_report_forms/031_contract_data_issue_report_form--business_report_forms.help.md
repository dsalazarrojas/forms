# Contract Data Issue Report Form - Help Guide
## Purpose
The Contract Data Issue Report Form is designed to collect information about any data issues or discrepancies found in contract data. This form is used to report problems with contract data, enabling the technical and business teams to address these issues quickly.

## How To Complete This Form
To complete the form, please follow these steps:
1. Select the category of the issue from the dropdown menu.
2. Enter the reporter's name and email address in the corresponding fields.
3. Choose the correct department from the dropdown menu.
4. Select the date when the issue was discovered.
5. Enter the contract number and title.
6. Describe the specific issue in the issue description field.
7. Indicate which fields are affected by the issue.
8. Select the priority level and the level of business impact.
9. If known, enter the root cause.
10. Choose the systems affected by the issue.
11. Evaluate the current state of the data accuracy.
12. Check if a workaround is available.
13. Enter the stakeholders informed about the issue.
14. Suggest a resolution to the problem, if applicable.
15. Estimate the time to resolve the issue, if known.
16. If necessary, upload any attachments (screenshots or documents).
17. Select if follow-up is required.

## Field-by-Field Explanation

* **Reporter Name** (`Reporter Name`, text, required): Enter your full name as the person submitting this report.
* **Reporter Email** (`Reporter Email`, email, required): Enter your email address for follow-up communication.
* **Department** (`Department`, select_one, required): Choose the department you belong to from the provided options.
* **Report Date** (`Report Date`, date, required): Enter the date you discovered the issue.
* **Contract Number** (`Contract Number`, text, required): Enter the contract reference number.
* **Contract Title** (`Contract Title`, text, required): Enter the name of the contract.
* **Issue Category** (`Issue Category`, select_one, required): Select the type of data issue from the dropdown menu.
* **Issue Description** (`Issue Description`, text, required): Clearly describe the problem you've encountered.
* **Affected Fields** (`Affected Fields`, text, required): Specify which data fields are affected by the issue.
* **Issue Discovery Date** (`Issue Discovery Date`, date, required): Enter the date when you found the issue.
* **Priority Level** (`Priority Level`, select_one, required): Evaluate the urgency of the fix from the provided options.
* **Business Impact** (`Business Impact`, select_one, required): Determine the level of impact on the organization from the dropdown menu.
* **Root Cause** (`Root Cause`, text, optional): If known, provide details about the root cause of the issue.
* **Systems Affected** (`Systems Affected`, select_multiple, required): Indicate which systems show the issue from the provided options.
* **Data Accuracy Impact** (`Data Accuracy Impact`, select_one, required): Assess the current state of data accuracy.
* **Workaround Available** (`Workaround Available`, select_one, required): Check if a temporary fix is available.
* **Stakeholders Notified** (`Stakeholders Notified`, text, optional): Indicate who has been informed about the issue.
* **Recommended Resolution** (`Recommended Resolution`, text, optional): Suggest a solution to the problem, if applicable.
* **Estimated Resolution Time** (`Estimated Resolution Time`, select_one, optional): Estimate the time required to resolve the issue, if known.
* **Attachments** (`Attachments`, text, optional): Upload any relevant screenshots or documents to support your report.
* **Follow-up Required** (`Follow-up Required`, select_one, required): Confirm if follow-up is necessary.
