## Treasury Report Correction Request Form - Help Guide

## Purpose
The Treasury Report Correction Request Form is a tool used to request corrections to treasury reports. This form helps users to identify and correct errors or discrepancies found in these reports, ensuring accurate financial data.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the form title to clearly describe the purpose of your correction request.
2.  Enter the report date to indicate the date of the report that needs to be corrected.
3.  Enter the report ID to identify the specific report that requires correction.
4.  Fill in the employee name who is associated with the report or correction.
5.  Select the department from the options provided, as this information is crucial for processing the correction request.
6.  Provide a brief description of the issue that needs to be corrected.
7.  Specify the reason for the correction, clearly explaining why the change is needed.
8.  Include detailed information regarding the correction that needs to be made.

## Field-by-Field Explanation
* **Form Title (<form_title>, text, optional)**: Enter a brief description of the purpose of your correction request.
*  **Report Date (<report_date>, date, optional)**: Enter the date of the report that requires correction.
*  **Report ID (<report_id, number, optional)**: Enter the ID of the report that needs to be corrected.
*  **Employee Name (<employee_name, text, optional)**: Enter the name of the employee associated with the report or correction request.
*  **Department (<department, select_one, required)**: Select the department that the report or correction request is related to. This is crucial for processing your request.
*  **Description (<description, text, optional)**: Briefly describe the issue that needs to be corrected.
*  **Reason for Correction (<reason_for_correction, text, optional)**: Clearly explain why the correction is needed.
*  **Correction Details (<correction_details, text, optional)**: Include detailed information regarding the correction that needs to be made.
