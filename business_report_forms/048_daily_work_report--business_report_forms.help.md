# Daily Work Report - Help Guide
## Purpose
The Daily Work Report is designed to collect essential information about a team member's work activities and progress. This report is used to keep track of tasks, time spent, and any other relevant details that need to be reported for review and analysis.

## How To Complete This Form
To complete this form, follow these steps:
1. **Describe your work activities** (Daily Work Report, id 1): Write a short summary of your work tasks and activities for the day.
2. **Enter work hours** (Work Hours, id 3): Type the total hours spent on work-related tasks.
3. **Specify the date** (Date, id 4): Choose the date for which you're submitting this report.
4. **Select the time** (Time, id 5): Enter the time you started and ended your work, using the format HH:MM AM/PM.
5. **Provide your email address** (Email, id 6): Enter your work email address.
6. **Enter your phone number** (Phone, id 7): Type your work-related phone number.
7. **Assigned Prophets** (Assigned Prophets, id 8): Select the person(s) you've been assigned to work with.
8. **Additional Comments** (Additional Comments, id 9): Enter any other relevant comments or notes about your work.
9. **Work Status** (Work Status, id 10): Choose whether your work is Active, Inactive, or Vacation status.
10. **Reporting Officer** (Reporting Officer, id 11): Select the person who should review and analyze your report.

## Field-by-Field Explanation
* **Daily Work Report (Work Summary, id 1)**: A short text field where you can describe your daily work activities in a few sentences.
* **Work Hours (Work Hours, id 3)**: Type the total hours you've spent on work-related tasks.
* **Date (Date, id 4)**: Choose the date for which you're submitting this report.
* **Time (Time, id 5)**: Enter the start and end time of your work, in the format HH:MM AM/PM.
* **Email (Email, id 6)**: Enter your work email address for reference and contact.
* **Phone (Phone, id 7)**: Type your work-related phone number for communication purposes.
* **Assigned Prophets (Assigned Prophets, id 8)**: Choose the person(s) you've been assigned to work with.
* **Additional Comments (Additional Comments, id 9)**: Enter any other relevant comments or notes about your work.
* **Work Status (Work Status, id 10)**: Choose whether your work is Active, Inactive, or Vacation status.
* **Reporting Officer (Reporting Officer, id 11)**: Select the person who should review and analyze your report.

## Tips
* Please ensure that you're filling out the report for the correct date and time.
* If you're unsure about any field, refer back to this guide for clarification.
* If you're unable to complete this form, contact your supervisor or manager for assistance.
