# Tree Removal Cost Estimate Form - Help Guide
## Purpose
The Tree Removal Cost Estimate Form is a tool used to collect information about a tree removal request from customers. This form will help estimate the cost of tree removal and provide a contact information to discuss further details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Tree Removal Type" field with the type of tree removal service you are requesting.
2. Select the "Tree Species" field with the species of the tree you want to remove.
3. Enter the "Tree Height" in feet or meters.
4. Enter the "Removal Cost" if you have a specific budget in mind.
5. Enter the "Estimated Cost" if you have an estimated cost in mind.
6. Fill in the "Contact Name", "Contact Company", "Contact Email", and "Contact Phone" fields with your contact information.
7. Select the "Removal Date" and "Removal Time" fields with the date and time you would like the removal to take place.
8. Add any additional comments or notes in the "Notes" field.
9. Fill in the "Tree Location" field with the location of the tree you want to remove.
10. Select the "Tree Height Unit" field with the unit of measurement for the tree height (e.g., feet, meters).
11. Select the "Removal Method" field with the method of removal you would like to use.
12. Select the "Property Type" field with the type of property where the tree is located.
13. Add any additional comments in the "Additional Comments" field.
14. Fill in the "Contact Notes" field with any relevant information about the contact person.
15. Add a "Contact Message" with any additional information you would like to convey to the contact person.
16. Set the "Contact Message Priority" field with the priority of the message.
17. Add any "Removal Cost Notes" or "Estimated Cost Notes" if you have any additional information to provide.
18. Fill in the "Contact Requesting" field with the reason for the contact request.

## Field-by-Field Explanation

* **Tree Removal Type**: Select the type of tree removal service you are requesting (e.g., stump grinding, stump chemical treatment, root grinding, root removal).
* **Tree Species**: Select the species of the tree you want to remove.
* **Tree Height**: Enter the height of the tree in feet or meters.
* **Removal Cost**: Enter the budget you have in mind for the removal cost.
* **Estimated Cost**: Enter the estimated cost of the tree removal.
* **Contact Name**: Enter the name of the contact person.
* **Contact Company**: Enter the name of the company the contact person represents.
* **Contact Email**: Enter the email address of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.
* **Removal Date**: Select the date you would like the removal to take place.
* **Removal Time**: Select the time you would like the removal to take place.
* **Notes**: Add any additional comments or notes about the tree removal.
* **Tree Location**: Enter the location of the tree you want to remove.
* **Tree Height Unit**: Select the unit of measurement for the tree height (e.g., feet, meters).
* **Removal Method**: Select the method of removal you would like to use.
* **Property Type**: Select the type of property where the tree is located.
* **Additional Comments**: Add any additional comments about the tree removal.
* **Contact Notes**: Enter any relevant information about the contact person.
* **Contact Message**: Add a message for the contact person.
* **Contact Message Priority**: Set the priority of the contact message.
* **Removal Cost Notes**: Add any additional information about the removal cost.
* **Estimated Cost Notes**: Add any additional information about the estimated cost.
* **Contact Requesting**: Enter the reason for the contact request.

Please note that the "Removal Cost" and "Estimated Cost" fields can be left blank if you do not have a specific budget or estimated cost.
