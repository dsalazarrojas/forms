# Personnel Activity Report Form For Federal Grants - Help Guide
## Purpose
The purpose of this form is to collect and document information about personnel activity reports for federal grants. This form is used to track project details such as project name, category, and description.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the project name in the "Project Name" field.
2. Select the appropriate category for the project from the "Category" dropdown list.
3. Provide a brief description of the project in the "Description" field.
4. Indicate if the project has been assigned a tool, and if so, select "Yes" from the "Assigned Tool" dropdown list.
5. Specify if the project is complete, and if so, select "Yes" from the "Project Completed" dropdown list.
6. Enter the output file name in the "Output File" field.
7. If the project is not complete, provide a description of the form's purpose and how it will be used in the "Form Description" field.
8. Enter the form ID number in the "Form ID" field (optional).
9. Indicate if the project is federally funded, and if so, select "Yes" from the "Is Federally Funded" dropdown list.
10. Confirm if this is a repeat occurrence, and if so, select "Yes" from the "Repeat Occurrence" dropdown list.
11. Indicate if another tool has been assigned to the project, and if so, select "Yes" from the "Assigned Tool 2" dropdown list.
12. Select relevant categories for the "Category 2" field.

## Field-by-Field Explanation
* **Project Name** (1, text, required): Enter the name of the project.
* **Category** (2, select_one, required): Select the category of the project from the dropdown list.
* **Description** (3, text, required): Provide a brief description of the project.
* **Assigned Tool** (4, select_one, required): Indicate if the project has been assigned a tool.
* **Project Completed** (5, select_one, required): Specify if the project is complete.
* **Output File** (6, text, required): Enter the output file name.
* **Form Description** (7, text, optional): If the project is not complete, provide a description of the form's purpose and how it will be used.
* **Form ID** (8, number, optional): Enter the form ID number.
* **Is Federally Funded** (9, select_one, required): Indicate if the project is federally funded.
* **Repeat Occurrence** (10, select_one, required): Confirm if this is a repeat occurrence.
* **Assigned Tool 2** (11, select_one, required): Indicate if another tool has been assigned to the project.
* **Category 2** (12, select_multiple, required): Select relevant categories for the project.
