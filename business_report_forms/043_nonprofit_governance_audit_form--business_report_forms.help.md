# Nonprofit Governance Audit Form - Help Guide
## Purpose
This form is a tool for evaluating and improving the governance practices of a nonprofit organization.

## How To Complete This Form
Please fill out the form in the following order:

1. Provide Organization Information (fields 1-3)
2. Answer Governance Practices questions (fields 4-7)
3. Answer Committee Information questions (fields 8-11)
4. Provide Audit Finding, Improvement Opportunities, and Recommended Actions (fields 12-14)
5. Provide contact information (fields 15-17)

## Field-by-Field Explanation

* **Organization Information (1)** (`non_profit_info`, select_one, required: false):
	+ Select the type of nonprofit organization you represent.
* **Non Profit Type (15)** (`non_profit_type`, select_one, required: false):
	+ Select the type of nonprofit organization (Nonprofit or For Profit).
* **Non Profit Name (12)** (`non_profit_name`, text, required: false):
	+ Enter the name of the nonprofit organization.
* **Address (13)** (`address`, text, required: false):
	+ Enter the address of the nonprofit organization.
* **Contact Person (14)** (`contact_person`, text, required: false):
	+ Enter the name of the contact person for the organization.
* **Board Of Directors (17)** (`board_of_directors`, select_multiple, required: false):
	+ Indicate if the board of directors is present.
* **Board Size (18)** (`board_size`, text, required: false):
	+ Enter the number of members on the board of directors.
* **Board Meeting (19)** (`board_meeting`, date, required: false):
	+ Enter the date of the board meeting.
* **Board Meeting Frequency (20)** (`board_meeting_frequency`, text, required: false):
	+ Enter the frequency of board meetings (e.g., monthly, quarterly, etc.).
* **Board Meeting Location (21)** (`board_meeting_location`, text, required: false):
	+ Enter the location of the board meeting.
* **Board Meeting Minutes (22)** (`board_meeting_minutes`, text, required: false):
	+ Enter the details of board meeting minutes (e.g., decisions, actions, etc.).
* **Board Meeting Attendance (23)** (`board_meeting_attendance`, text, required: false):
	+ Enter the attendance record of board meetings.
* **Executive Director (24)** (`executive_director`, text, required: false):
	+ Enter the name of the executive director.
* **Executive Director Title (25)** (`executive_director_title`, text, required: false):
	+ Enter the title of the executive director.

## Tips
* Please answer the questions truthfully and accurately.
* Make sure to provide all required information.
* If you are unsure about any question, please ask for clarification.
