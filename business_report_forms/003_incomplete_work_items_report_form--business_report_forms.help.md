# Incomplete Work Items Report Form - Help Guide
## Purpose
The purpose of this form is to report and manage incomplete work items in a project or task context.

## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "Incomplete work items report form" field and enter a descriptive title for the report.
2.  Enter your "Form ID" in the corresponding field. This ID is a unique identifier for the form.
3.  Select "Yes" or "No" for "Category" to indicate the type of category the work item belongs to.
4.  Provide a brief description of the incomplete work item in the "Description" field.
5.  Indicate which tools or resources are assigned to the work item in the "Assigned Tool" field by selecting multiple options.
6.  Finally, enter the desired "Output File" name in the last field to specify where the report will be saved.

## Field-by-Field Explanation

*   **Form ID**: Enter a unique identifier for the form, which will help in tracking and organizing the reported work items.
*   **Category**: Select "Yes" if the work item belongs to the specified category, "No" otherwise.
*   **Description**: A brief description of the incomplete work item, which should include all necessary details for understanding and resolving the issue.
*   **Assigned Tool**: Choose all tools or resources that are assigned or required for the work item's completion. Multiple options can be selected.
*   **Output File**: Specify the name of the file where the report will be saved.
