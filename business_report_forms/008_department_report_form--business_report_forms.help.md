# Department Report Form - Help Guide
## Purpose
The Department Report Form is used to collect information about departmental issues, actions taken, and other relevant details. It helps departmental managers or administrators record and track issues within their department, enabling others to better understand the situation and make informed decisions.

## How To Complete This Form

1. Fill out the form with the relevant details for your department.
2. Select the correct options for each field based on your situation.
3. Ensure that you are reporting issues and taking actions for your own department.

## Field-by-Field Explanation

* **weekly_issues** (`weekly_issues`, select_multiple): Select all the issues that you are currently facing in your department. This field allows you to select multiple options.
	+ Example: If you are facing multiple issues, select all that apply.
* **actions_taken** (`actions_taken`, text): Describe the actions you have taken to address the issues in your department. This field is for free-form text.
	+ Example: Provide a brief description of the actions you have taken.
* **actions_description** (`actions_description`, text): Describe the actions you have taken to address the issues in your department. This field is for free-form text.
	+ Example: Provide a detailed description of the actions you have taken.
* **date_solved** (`date_solved`, date): Enter the date the issue was solved.
	+ Example: Enter the date in the format DD/MM/YYYY.
* **reported_by** (`reported_by`, select_one): Select whether you are reporting the issue for yourself or someone else.
	+ Example: Select 'Yes' if you are reporting the issue for yourself, or 'No' if you are reporting for someone else.
* **prophets** (`prophets`, select_multiple): Select all the prophets that are relevant to this issue.
	+ Example: If there are multiple prophets, select all that apply.
* **department** (`department`, select_one): Select the department that this issue belongs to.
	+ Example: Select the correct department from the list.
* **comments** (`comments`, text): Provide any additional comments about the issue.
	+ Example: Add any relevant information about the issue.
* **reported_by_email** (`reported_by_email`, email): Enter the email of the person who reported the issue.
	+ Example: Enter the email address of the person who reported the issue.
* **reported_by_phone** (`reported_by_phone`, text): Enter the phone number of the person who reported the issue.
	+ Example: Enter the phone number of the person who reported the issue.
* **prophets_phone** (`prophets_phone`, text): Enter the phone number of the person who is a prophet.
	+ Example: Enter the phone number of the person who is a prophet.
* **department_phone** (`department_phone`, text): Enter the phone number of the department.
	+ Example: Enter the phone number of the department.
* **reported_by_date** (`reported_by_date`, date): Enter the date the issue was reported.
	+ Example: Enter the date in the format DD/MM/YYYY.
* **field_14** (`field_14`, text): Provide any additional information.
	+ Example: Add any relevant information about the issue.
* **department** (`department`, select_one): Select whether this issue is related to a department.
	+ Example: Select 'Yes' if the issue is related to a department.
* **department_name** (`department_name`, text): Enter the name of the department.
	+ Example: Enter the name of the department.
* **reported_by_time** (`reported_by_time`, time): Enter the time the issue was reported.
	+ Example: Enter the time in 24-hour format.
* **department_id** (`department_id`, number): Enter the ID of the department.
	+ Example: Enter the department ID.

## Tips

* Please ensure that you are reporting issues and taking actions for your own department.
* Be accurate and clear when filling out the form.
* If you are unsure about any field, please ask for help.
