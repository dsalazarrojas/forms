# Event Financial Overview - Help Guide
## Purpose
This form is designed to provide an overview of the financial details of an event, including income and expenses. It is a quick and easy way to collect and review event financial data.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the provided financial data and records for the event.
2. Enter the event's income and expenses in the corresponding fields.
3. Calculate the overall profit or loss by subtracting the expenses from the income.

## Field-by-Field Explanation
* **Event Income**:
	+ Label: event_income
	+ Type: number
	+ Required: false
	+ Explanation: Enter the total income earned from the event, including ticket sales, sponsorships, and any other revenue streams.
* **Event Expenses**:
	+ Label: event_expenses
	+ Type: number
	+ Required: false
	+ Explanation: Enter the total expenses incurred during the event, including venue rental, staff costs, and any other expenses.
* **Overall Profit/Loss**:
	+ Label: overall_profit_loss
	+ Type: number
	+ Required: false
	+ Explanation: Calculate the overall profit or loss by subtracting the expenses from the income.
* **Profit/Loss**:
	+ Label: profit_loss
	+ Type: number
	+ Required: false
	+ Explanation: Calculate the profit or loss for the event by subtracting the income from the expenses.

## Tips
* Double-check all financial data for accuracy and completeness.
* Ensure all fields are filled in before submitting the form.
* If you have any questions or concerns about this form, please contact your supervisor or event coordinator.
