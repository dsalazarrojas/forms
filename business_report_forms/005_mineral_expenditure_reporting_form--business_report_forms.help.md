# Mineral Expenditure Reporting Form - Help Guide
## Purpose
This form is designed to collect information on mineral expenditure reports for projects involving gold, silver, and copper mining.

## How To Complete This Form

1. Select the project belonging to the client.
2. Choose the reporting period (e.g., January-February).
3. Select the type of mineral being reported (e.g., gold).
4. Enter the expenditure amount.
5. Select the submission date and time.
6. Identify the user who submitted the report.
7. Provide the submission country.
8. Specify the submission city.
9. Specify the submission browser and operating system used.
10. State the submission device used.
11. Report the submission screen resolution.
12. Mention the submission browser version.
13. Specify the submission language.
14. Specify the submission timezone offset.
15. Confirm that the report was submitted in UTC (Coordinated Universal Time) timezone.
16. Confirm the submission timezone.

## Field-by-Field Explanation

* **Project** (Project, text, required): Enter the project's name or ID that belongs to the client.
* **Reporting Period** (Reporting Period, select_one, required): Choose the period of the project report from the provided options (e.g., January-February).
* **Mineral Type** (Mineral Type, select_one, required): Select the type of mineral being reported (e.g., gold).
* **Expenditure** (Expenditure, number, required): Enter the amount of expenditure for the project.
* **Submission Date** (Submission Date, date, required): Enter the date on which the report was submitted.
* **Submission Time** (Submission Time, time, required): Enter the time at which the report was submitted.
* **Submission User** (Submission User, text, required): Identify the user who submitted the report.
* **Submission Country** (Submission Country, text, required): Specify the country where the report was submitted from.
* **Submission City** (Submission City, text, required): Specify the city where the report was submitted from.
* **Submission Browser** (Submission Browser, text, required): Specify the web browser used to submit the report.
* **Submission OS** (Submission OS, text, required): Specify the operating system used to submit the report.
* **Submission Device** (Submission Device, text, required): Specify the device used to submit the report.
* **Submission Screen Resolution** (Submission Screen Resolution, text, required): Report the screen resolution used to submit the report.
* **Submission Browser Version** (Submission Browser Version, text, required): Mention the version of the web browser used.
* **Submission Language** (Submission Language, text, required): Specify the language used to submit the report.
* **Submission Timezone Offset** (Submission Timezone Offset, text, required): Specify the timezone offset used to submit the report.
* **Submission UTC** (Submission UTC, text, required): Confirm that the report was submitted in UTC (Coordinated Universal Time) timezone.
* **Submission Timezone** (Submission Timezone, text, required): Confirm the submission timezone.

## Tips

* Make sure to fill out all required fields.
* Double-check your entries for accuracy.
* If you are unsure about any field, contact the relevant authorities or departmental representatives for guidance.
