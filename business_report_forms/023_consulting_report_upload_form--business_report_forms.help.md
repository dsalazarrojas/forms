# Consulting Report Upload Form - Help Guide

## Purpose
The Consulting Report Upload Form is a document used to collect information from consultants and their teams about their reports, which are then reviewed and approved by clients. This form helps to ensure that all necessary details are gathered and documented in a standard format.

## How To Complete This Form

1. Fill out the form with the required information for the consultant, including name, email, submission date, client name, project name, report title, report type, and other details such as report period start and end dates.
2. Attach the main report document as a PDF file.
3. Choose the format of the uploaded file.
4. Optionally, add additional files, appendices, or separate executive summaries if necessary.
5. Select the review status and approver's name, if applicable.
6. Add any additional notes for the client or team.

## Field-by-Field Explanation

### Page 1: Consultant Information

* **Consultant Name** (`consultant_name`, text, required): Enter the name of the consultant submitting the report.
* **Email** (`consultant_email`, email, required): Enter the email address of the consultant.
* **Submission Date** (`submission_date`, date, required): Enter the date on which the report was submitted.
* **Client Name** (`client_name`, text, required): Enter the name of the client organization.
* **Project Name** (`project_name`, text, required): Enter the name of the project.
* **Project Code** (`project_code`, text, optional): Enter an internal project reference.
* **Report Title** (`report_title`, text, required): Enter the title of the report.
* **Report Type** (`report_type`, select_one, required): Select the type of report, such as Initial Assessment, Progress Report, etc.

### Page 2: Report Information

* **Reporting Period Start** (`report_period_start`, date, optional): Enter the start date of the reporting period.
* **Reporting Period End** (`report_period_end`, date, optional): Enter the end date of the reporting period.
* **Report Version** (`report_version`, text, optional): Enter the version number of the report if applicable.
* **Report Summary** (`report_summary`, text, required): Enter a brief executive summary of the report.
* **Key Findings** (`key_findings`, text, required): Enter a summary of main findings.
* **Key Recommendations** (`recommendations`, text, optional): Enter a summary of recommendations.
* **Confidentiality Level** (`confidentiality_level`, select_one, required): Select the classification level of the report, such as Public, Internal Use Only, etc.
* **Upload Report File** (`report_file_upload`, text, required): Attach the main report document as a PDF file.
* **File Format** (`file_format`, select_one, required): Choose the format of the uploaded file, such as PDF, Word Document, etc.
* **Additional Files** (`additional_files`, text, optional): List any supplementary files.
* **Are Appendices Included** (`appendices_included`, select_one, optional): Select if appendices are attached.
* **Is Executive Summary Separate** (`executive_summary_separate`, select_one, optional): Select if executive summary is a separate file.
* **Is Presentation Required** (`presentation_required`, select_one, optional): Select if a presentation is required.
* **Presentation Date** (`presentation_date`, date, optional): Enter the scheduled presentation date.
* **Review Status** (`review_status`, select_one, required): Select the current review status, such as Draft, Internal Review Complete, etc.
* **Approver Name** (`approver_name`, text, optional): Enter the name of the person who approved the report.
* **Additional Notes** (`additional_notes`, text, optional): Enter any additional notes for the client or team.

### Review and Approval

* **Review Status** (`review_status`, select_one, required): Select the current review status, such as Draft, Internal Review Complete, etc.
* **Approver Name** (`approver_name`, text, optional): Enter the name of the person who approved the report.

### Tips

* Make sure to fill out all required fields before submitting the form.
* Attach the main report document as a PDF file.
* Choose the correct format of the uploaded file.
* Select the correct review status and approver's name if applicable.
* Add any additional notes for the client or team.
* Use the correct classification level for the report.
* Make sure to review and proofread the form before submitting it.
