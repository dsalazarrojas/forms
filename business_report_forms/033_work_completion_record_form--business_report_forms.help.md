# Work Completion Record Form - Help Guide
## Purpose
This form is designed to record and track the completion status of individual work items. It helps to monitor progress, update status, and keep a record of ongoing and completed tasks. The form is intended for internal use within organizations to facilitate communication and coordination among team members and stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter User Input**: In this text field, type in the name or identifier of the work item to be recorded.
2. **Select Work Status**: Choose the status of the work item from the options provided:
	* **Active**: The work item is currently being worked on.
	* **Completed**: The work item has been finished.
	* **In Progress**: The work item is ongoing, but not yet completed.
3. **Add Notes (Optional)**: If you have any additional comments, updates, or reminders related to the work item, type them in this text field.

## Field-by-Field Explanation
* **User Input**: A text field where you can enter the name or identifier of the work item.
* **Work Status**: A dropdown menu to select the current status of the work item.
* **Notes**: A text field for providing additional information, comments, or reminders about the work item. If you don't have any notes to add, feel free to leave this field blank.

## Tips
- Make sure to fill out the required fields (User Input and Work Status) before submitting the form.
- Use the User Input field to reference a specific work item, such as a project code or task ID.
- The form is designed to be completed on a per-work-item basis; each submission should correspond to a unique work item.
- Review and update the form regularly to reflect changes in work status.
- Consider using this form as part of your project management process to improve collaboration and tracking within your team.
