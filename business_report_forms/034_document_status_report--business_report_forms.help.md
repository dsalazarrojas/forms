# Document Status Report - Help Guide
## Purpose
The Document Status Report form is used to track and report on the status of documents. This form helps project managers and administrators keep up-to-date information on document progress, deadlines, and more.

## How To Complete This Form
To complete this form, follow these steps:

1.  Input your name and other relevant details in the "User Input" field.
2.  Select the owner of the document from the "Document Owner" field.
3.  Set the deadline for the document in the "Document Deadline" and "Deadline Time" fields.
4.  Select the document type and status from the respective dropdown menus.
5.  Input any comments or follow-up actions in the "Comments" and "Follow up actions" fields.
6.  Assign users to and from the document using the "Assigned To", "Document Type", and "Document Status Updated By" fields.
7.  Set the due date and time in the "Due Date" and "Due Time" fields.
8.  Finally, submit the form to update the document status.

## Field-by-Field Explanation
*   **User Input (User Input, text, optional)**: This field allows you to input any additional information you'd like to include with the document.
*   **Document Owner (Document Owner, text, optional)**: Select the owner of the document from the dropdown menu.
*   **Document Deadline (Document Deadline, date, optional)**: Set the deadline for the document.
*   **Deadline Time (Deadline Time, time, optional)**: Set the deadline time for the document.
*   **Document Type (Document Type, select multiple, optional)**: Select the type of document (e.g., Report, Document, Presentation).
*   **Status (Status, select one, optional)**: Select the current status of the document (e.g., Draft, In progress, Completed).
*   **Comments (Comments, text, optional)**: Input any comments or notes about the document.
*   **Follow up actions (Follow up actions, text, optional)**: Input any follow-up actions or tasks related to the document.
*   **Assigned To (Assigned To, select multiple, optional)**: Select the users assigned to the document.
*   **Due Date (Due Date, date, optional)**: Set the due date for the document.
*   **Due Time (Due Time, time, optional)**: Set the due time for the document.
*   **Document Status (Document Status, select one, optional)**: Select the current status of the document (e.g., Not Started, In progress, Completed).
*   **Document Owner (Document Owner, select multiple, optional)**: Select the owner of the document.
*   **Document Updated By (Document Updated By, select multiple, optional)**: Select the user who updated the document status.
*   **Document Updated At (Document Updated At, date, optional)**: Set the date and time the document was last updated.
*   **Document Deleted At (Document Deleted At, date, optional)**: Set the date and time the document was deleted.
*   **Created By (Created By, select multiple, optional)**: Select the user who created the document.
*   **Created By Email (Created By Email, email, optional)**: Input the email of the user who created the document.
*   **Updated By (Updated By, select multiple, optional)**: Select the user who updated the document.
*   **Updated By Email (Updated By Email, email, optional)**: Input the email of the user who updated the document.
*   **Document Status Updated By (Document Status Updated By, select multiple, optional)**: Select the user who updated the document status.
*   **Document Deleted At (Document Deleted At, date, optional)**: Set the date and time the document was deleted.

## Tips

*   Use clear and concise language when filling out the form to avoid confusion.
*   Double-check dates and deadlines to ensure accuracy.
*   Make sure to select the correct document owner and status to ensure proper tracking.
*   Use the "Created By" and "Updated By" fields to keep track of document history.
