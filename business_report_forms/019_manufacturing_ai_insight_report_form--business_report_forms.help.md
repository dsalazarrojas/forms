# Manufacturing AI Insight Report Form - Help Guide
## Purpose
The Manufacturing AI Insight Report Form is designed to collect detailed information about a manufacturing project, providing stakeholders with valuable insights into its progress, challenges, and impact.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the project details section (fields 1-3) and provide a brief overview of the project, including its scope, objectives, and goals.
2. Identify and select the project's impacts (field 4).
3. Choose the AI technologies used in the project (field 5).
4. Provide the expected project outcomes (field 6).
5. Select the project's impact level (field 7).
6. Specify the consultants involved in the project (field 8).
7. Enter the project start and end dates (fields 9-10).
8. Choose the project status (field 11).
9. Identify the project lead (field 12).
10. Provide a brief description of the project (field 13).
11. Outline the project goals (field 14).
12. Describe the project scope (field 15).
13. Outline the project objectives (field 16).
14. Specify the project success criteria (field 17).
15. Add any additional comments for project challenges (field 18).
16. Add any additional comments for project impact (fields 19-22).

## Field-by-Field Explanation

* **Project Details** (`project_details`, text, required): A brief overview of the project, including its scope, objectives, and goals.
* **Project Impacts** (`project_impacts`, select_multiple, required): Identify and select the project's impacts.
* **Project Challenges** (`project_challenges`, text, required): Describe any challenges faced by the project.
* **AI Technologies** (`ai_technologies`, select_multiple, required): Choose the AI technologies used in the project.
* **Project Outcomes** (`project_outcomes`, number, required): Provide the expected project outcomes.
* **Project Impact Level** (`project_impact_level`, select_one, required): Select the project's impact level (High, Medium, Low).
* **Consultants Involvement** (`consultants_involvement`, number, required): Specify the consultants involved in the project.
* **Project Start Date** (`project_start_date`, date, required): Enter the project start date.
* **Project End Date** (`project_end_date`, date, required): Enter the project end date.
* **Project Status** (`project_status`, select_one, required): Choose the project status (Active, Completed, Pending).
* **Project Lead** (`project_lead`, text, required): Identify the project lead.
* **Project Description** (`project_description`, text, required): Provide a brief description of the project.
* **Project Goals** (`project_goals`, text, required): Outline the project goals.
* **Project Scope** (`project_scope`, text, required): Describe the project scope.
* **Project Objectives** (`project_objectives`, text, required): Outline the project objectives.
* **Project Success Criteria** (`project_success_criterias`, text, required): Specify the project success criteria.
* **Project Challenges Comments** (`project_challenges_comments`, text, required): Add any additional comments for project challenges.
