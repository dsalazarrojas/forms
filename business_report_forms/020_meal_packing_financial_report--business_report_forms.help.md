# Meal Packing Financial Report - Help Guide
## Purpose
This form is designed to capture the financial information related to a specific event, including income and expenses, as well as funding sources.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter the name of the event in the "Event Name" field.
2. Select the date of the event in the "Event Date" field.
3. Enter the total income earned from the event in the "Income" field.
4. Enter the total expenses related to the event in the "Expenses" field.
5. Select the source of funding for the event from the "Funding" field.
6. If additional funding sources are used for the event, enter them in the "Other Funding" field.
7. Attach the financial report for the event in the "Financial Reports" field.
8. Attach any receipts for the event in the "Receipts" field.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Event Date** (`event_date`, date, required): Select the date of the event using the date picker.
* **Income** (`income`, number, required): Enter the total income earned from the event.
* **Expenses** (`expenses`, number, required): Enter the total expenses related to the event.
* **Funding** (`funding`, select_one, required): Select the source of funding for the event from the options provided.
* **Other Funding** (`other_funding`, text, optional): If additional funding sources were used for the event, enter them here.
* **Financial Reports** (`file1`, text, required): Attach the financial report for the event.
* **Receipts** (`file2`, text, required): Attach any receipts for the event.

## Tips

- Ensure that all required fields are filled out accurately to avoid discrepancies in financial records.
- If this form is being used in conjunction with a standard financial reporting process, submit the results for review and reconciliation with the accounting department.
- If you are unsure of any of the fields or options, please reach out to the event management team for assistance.
