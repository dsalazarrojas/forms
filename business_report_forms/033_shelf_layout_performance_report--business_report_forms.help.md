## Shelf Layout Performance Report - Help Guide
## Purpose
The Shelf Layout Performance Report form is used to collect data about the performance of shelves in a store.

## How To Complete This Form
1. To complete this form, start by filling in the **Store Name** field with the name of the store.
2. Next, enter the **Section Name**, which should be the name of the section where the shelf is located.
3. For the **Shelf Performance Rating**, enter a numerical value from 1 to 5 to indicate the performance of the shelf.
4. Enter the number of **Photos Count**, which is the total number of photos taken on the shelf.
5. Enter the number of **Ratings Count**, which is the total number of ratings received on the shelf.
6. In the **Notes** field, enter any additional comments or information about the shelf.
7. Enter the **Rating**, which should be a numerical value between 1 and 5 to indicate the overall rating of the shelf.
8. In the **Comments** field, enter any additional comments or feedback about the shelf.
9. Enter the **Brand Name**, which should be the name of the brand associated with the shelf.
10. Enter the number of **Sales**, which is the total number of sales made on the shelf.
11. Enter the **Date**, which is the date when the data was collected.
12. Finally, enter the **Time**, which is the time when the data was collected.

## Field-by-Field Explanation
* **Store Name** (`store_name`, text, required): The name of the store where the shelf is located. This field should be filled in to identify the store.
* **Section Name** (`section_name`, text, required): The name of the section where the shelf is located. This field should be filled in to identify the section.
* **Shelf Performance Rating** (`shelf_performance_rating`, number, required): A numerical value from 1 to 5 to indicate the performance of the shelf. This field should be filled in to rate the shelf's performance.
* **Photos Count** (`photos_count`, number, required): The total number of photos taken on the shelf. This field should be filled in to track the number of photos taken.
* **Ratings Count** (`ratings_count`, number, required): The total number of ratings received on the shelf. This field should be filled in to track the number of ratings.
* **Notes** (`notes`, note, required): Any additional comments or information about the shelf. This field should be filled in to provide additional context.
* **Rating** (`rating`, number, required): A numerical value between 1 and 5 to indicate the overall rating of the shelf. This field should be filled in to rate the shelf.
* **Comments** (`comments`, text, required): Any additional comments or feedback about the shelf. This field should be filled in to provide feedback.
* **Brand Name** (`brand_name`, text, required): The name of the brand associated with the shelf. This field should be filled in to identify the brand.
* **Sales** (`sales`, number, required): The total number of sales made on the shelf. This field should be filled in to track sales.
* **Date** (`date`, date, required): The date when the data was collected. This field should be filled in to track the collection date.
* **Time** (`time`, time, required): The time when the data was collected. This field should be filled in to track the collection time.
