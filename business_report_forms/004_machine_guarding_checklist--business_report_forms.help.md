# Machine Guarding Checklist - Help Guide
## Purpose
This form is used to assess and record the safety measures and protocols implemented for machine guarding on a specific machine or equipment.

## How To Complete This Form

1. Review the machine or equipment to be assessed.
2. Answer the questions and complete the fields on the form based on your assessment.
3. Ensure that all fields are completed thoroughly and accurately.
4. If you are unsure about any aspect of machine guarding, please seek guidance from a qualified safety professional.

## Field-by-Field Explanation

* **1. Machine Guarding Checklist 1** (`machine_guarding_checklist_1`, text, required): Briefly describe the machine or equipment being assessed.
* **2. Machine Guarding Checklist 2** (`machine_guarding_checklist_2`, select_one, required): What type of machine or equipment is being assessed? (e.g., drill press, saw, conveyor belt)
* **3. Machine Guarding Checklist 3** (`machine_guarding_checklist_3`, number, required): How many guards are currently installed on the machine?
* **4. Machine Guarding Checklist 4** (`machine_guarding_checklist_4`, number, required): What is the current condition of the machine (e.g., good, fair, poor)?
* **5. Machine Guarding Checklist 5** (`machine_guarding_checklist_5`, time, required): When was the last maintenance or cleaning of the machine performed?
* **6. Machine Guarding Checklist 6** (`machine_guarding_checklist_6`, date, required): Record the date of the last maintenance or cleaning of the machine.
* **7. Machine Guarding Checklist 7** (`machine_guarding_checklist_7`, note, required): Any additional comments or observations about the machine or equipment?
* **8. Machine Guarding Checklist 8** (`machine_guarding_checklist_8`, email, required): Record the name and email of the person performing the assessment.
* **9. Machine Guarding Checklist 9** (`machine_guarding_checklist_9`, text, required): Is the machine or equipment in use?
* **10. Machine Guarding Checklist 10** (`machine_guarding_checklist_10`, text, required): What is the last time the machine or equipment was inspected or assessed?
* **11. Machine Guarding Checklist 11** (`machine_guarding_checklist_11`, text, required): What is the next action or maintenance schedule for the machine or equipment?
* **12. Machine Guarding Checklist 12** (`machine_guarding_checklist_12`, text, required): Record any safety concerns or observations about the machine or equipment.
* **13. Machine Guarding Checklist 13** (`machine_guarding_checklist_13`, text, required): What is the location where the machine or equipment is used?
* **14. Machine Guarding Checklist 14** (`machine_guarding_checklist_14`, text, required): Record any training records for the machine or equipment operators.
* **15. Machine Guarding Checklist 15** (`machine_guarding_checklist_15`, text, required): What is the manufacturer's instructions or manual for the machine or equipment?
* **16. Machine Guarding Checklist 16** (`machine_guarding_checklist_16`, text, required): Record any regulatory or compliance requirements for the machine or equipment.
* **17. Machine Guarding Checklist 17** (`machine_guarding_checklist_17`, text, required): Are there any additional safety measures in place for the machine or equipment?
* **18. Machine Guarding Checklist 18** (`machine_guarding_checklist_18`, text, required): Record any observations or comments about the machine's condition.
* **19. Machine Guarding Checklist 19** (`machine_guarding_checklist_19`, text, required): What is the machine's or equipment's purpose or function?
* **20. Machine Guarding Checklist 20** (`machine_guarding_checklist_20`, text, required): Record any other safety concerns or observations about the machine or equipment.
* **21. Machine Guarding Checklist 21** (`machine_guarding_checklist_21`, text, required): What is the machine's or equipment's age or year of purchase?
* **22. Machine Guarding Checklist 22** (`machine_guarding_checklist_22`, text, required): Record any other information about the machine or equipment.
* **23. Machine Guarding Checklist 23** (`machine_guarding_checklist_23`, text, required): What is the last time the machine or equipment was inspected or assessed?
* **24. Machine Guarding Checklist 24** (`machine_guarding_checklist_24`, text, required): Record any regulatory or compliance updates for the machine or equipment.
* **25. Machine Guarding Checklist 25** (`machine_guarding_checklist_25`, text, required): Record any other relevant information about the machine or equipment.

This guide is designed to ensure that users thoroughly complete the form and understand the purpose and context of each field.
