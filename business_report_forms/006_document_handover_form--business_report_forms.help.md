# Document Handover Form - Help Guide
## Purpose
The Document Handover Form is a tool used to manage and track document handovers between teams and stakeholders. This form captures key information about the document being handovered, including client name, document type, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client name in the "Client Name" field.
2. Select the type of document being handovered from the "Document Type" dropdown menu.
3. Enter the current status of the document in the "Status" dropdown menu.
4. If applicable, upload the file associated with the document in the "File" field.
5. Enter the name of the person or team sending the document in the "Sender Name" field.
6. Enter the company associated with the sender in the "Sender Company" field.
7. Enter the sender's email address in the "Sender Email" field.
8. Enter the sender's phone number in the "Sender Phone" field.
9. Select the review type for the document in the "Review Type" field.
10. Select the review status in the "Review Status" dropdown menu.
11. Enter any comments or notes about the document in the "Comments" field.
12. Select the next action required for the document in the "Next Action" dropdown menu.
13. Confirm that the file has been uploaded successfully in the "Confirm Upload" field.

## Field-by-Field Explanation
* **Client Name** (Client Name, text, required/optional): Enter the name of the client associated with the document.
* **Company Name** (Company Name, text, required/optional): Enter the name of the company associated with the document.
* **Email** (Email, email, required/optional): Enter the email address of the client or associated company.
* **Phone** (Phone, text, required/optional): Enter the phone number of the client or associated company.
* **Document Type** (Document Type, select_one, required/optional): Select the type of document being handovered from the dropdown menu.
* **Document Name** (Document Name, text, required/optional): Enter the name of the document being handovered.
* **Document Description** (Document Description, text, required/optional): Enter a brief description of the document being handovered.
* **File** (File, text, required/optional): Upload the associated file with the document.
* **Sender Name** (Sender Name, text, required/optional): Enter the name of the person or team sending the document.
* **Sender Company** (Sender Company, text, required/optional): Enter the name of the company associated with the sender.
* **Sender Email** (Sender Email, email, required/optional): Enter the email address of the sender.
* **Sender Phone** (Sender Phone, text, required/optional): Enter the phone number of the sender.
* **Status** (Status, select_one, required/optional): Select the current status of the document from the dropdown menu.
* **Review Date** (Review Date, date, required/optional): Enter the date the document is due for review.
* **Comments** (Comments, text, required/optional): Enter any comments or notes about the document.
* **Next Action** (Next Action, select_one, required/optional): Select the next action required for the document from the dropdown menu.
* **Review Type** (Review Type, text, required/optional): Enter the type of review required for the document.
* **Review Status** (Review Status, select_one, required/true): Select the current review status of the document from the dropdown menu.
* **Review Notes** (Review Notes, text, required/optional): Enter any review notes or comments about the document.
* **File Upload** (File Upload, text, required/optional): Upload the file associated with the document.
* **Confirm Upload** (Confirm Upload, select_one, required/true): Confirm that the file has been uploaded successfully.
