# intellectual_property_portfolio_report_form - Help Guide
## Purpose
The purpose of this form is to collect and document Intellectual Property (IP) portfolio information for businesses. This form helps track and update IP case status, filing dates, and other relevant details.

## How To Complete This Form

1. **Business Type**: Enter the type of business that owns the IP case or asset. This field helps categorize and filter IP portfolio information.
2. **Asset Type**: Select whether the asset is 'Yes' or 'No' to indicate its type (e.g., patent, trademark, or copyright).
3. **Date Of Filing**: Enter the date when the IP case or asset was filed. This date should follow the YYYY-MM-DD format (e.g., 2022-07-25).
4. **Filing Date**: Enter the date when the IP case or asset was filed. This date should follow the YYYY-MM-DD format (e.g., 2022-07-25). (Note: This field seems redundant with Date Of Filing, but it's included for consistency with other fields.)
5. **Case Number**: Enter the unique identifier for the IP case or asset. This field helps track and reference the case or asset.
6. **Client Name**: Enter the client's name associated with the IP case or asset.
7. **Attorney Name**: Enter the attorney's name handling the IP case or asset.
8. **Case Status**: Select the status of the IP case or asset ('Active' or 'Inactive').
9. **Case Details**: Enter any additional details about the IP case or asset.
10. **Asset Description**: Enter a brief description of the IP asset.
11. **Intellectual Property**: Enter a description of the IP asset (this field is similar to Asset Description, but with a more specific label).
12. **Jurisdiction**: Enter the jurisdiction where the IP case or asset is registered.
13. **Filing Location**: Enter the location where the IP case or asset was filed.
14. **Filing Date Time**: Enter the date and time when the IP case or asset was filed. This date should follow the YYYY-MM-DD HH:MM:SS format (e.g., 2022-07-25 14:30:00).
15. **Notes**: Enter any additional notes or comments about the IP case or asset.
16. **File Attachment**: Upload any supporting documents for the IP case or asset.
17. **Email**: Enter the email address of the contact person or representative.
18. **Phone**: Enter the phone number of the contact person or representative.
19. **Address**: Enter the address of the contact person or representative.
20. **Country**: Enter the country where the IP case or asset is registered.
21. **State**: Enter the state where the IP case or asset is registered.
22. **City**: Enter the city where the IP case or asset is registered.
23. **Postal Code**: Enter the postal code of the contact person or representative.
24. **Business Type Options**: Select multiple business types that apply to the IP case or asset (e.g., 'Yes' or 'No').
25. **Asset Type Options**: Select multiple asset types that apply to the IP case or asset (e.g., 'Yes' or 'No').

## Tips

* Use the YYYY-MM-DD or YYYY-MM-DD HH:MM:SS format for date fields.
* Ensure you select 'Active' or 'Inactive' for Case Status accurately.
* Use 'Yes' or 'No' for Asset Type and Asset Type Options fields.
* Upload relevant supporting documents in the File Attachment field.
