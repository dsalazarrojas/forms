# Factory Energy Usage Overview Report - Help Guide

## Purpose
The Factory Energy Usage Overview Report is a tool to help collect and present data for energy usage reporting in a factory. The report is designed to be used by factories that have specific energy usage reporting requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Form Data field with a brief description of the factory's energy usage.
2. Select "Yes" or "No" for the Plant ID field to identify the plant.
3. Enter the name of the plant in the Plant Name field.
4. Enter the start and end dates for the period being reported in the Date From and Date To fields respectively.
5. Select "Yes" or "No" for the Energy Source field to indicate whether the energy source is available or not.
6. Select the type of energy being used in the Energy Type field.
7. Enter a numerical value for the Energy Usage field.
8. In the Efficiency Measures field, enter any additional comments or notes about efficiency measures taken.
9. In the Comments field, enter any additional comments or feedback.

## Field-by-Field Explanation

* **Form Data (1)**: A brief description of the factory's energy usage.
* **Plant ID (2)**: Select "Yes" to identify the plant, or "No" if not applicable.
* **Plant Name (3)**: Enter the name of the plant.
* **Date From (4)**: Enter the start date of the period being reported.
* **Date To (5)**: Enter the end date of the period being reported.
* **Energy Source (6)**: Select "Yes" to indicate the energy source is available, or "No" if not available.
* **Energy Type (7)**: Select the type of energy being used.
* **Energy Usage (8)**: Enter a numerical value to measure energy usage.
* **Efficiency Measures (9)**: Enter any additional comments or notes about efficiency measures taken.
* **Comments (10)**: Enter any additional comments or feedback about the report.

Note: The Energy Source and Energy Type fields are intended to be binary indicators of the availability and type of energy, respectively.
