# Website Analytics Report Form - Help Guide
## Purpose
This form is for collecting website analytics report data and related information. It is used to gather insights on website performance, report frequency, and other metrics.

## How To Complete This Form

1.  Select the metrics you require for your report from the "Requested metrics" dropdown list.
2.  Align the report with specific goals by selecting "Yes" or "No" in the "Align goals" field.
3.  Choose whether data collection is required by selecting "Yes" or "No" in the "Data collection" field.
4.  Specify the report frequency by selecting one of the options in the "Report frequency" field.
5.  Enter the website's performance in the "Website performance" text field.
6.  Set the reporting deadline in the "Reporting deadline" date field.
7.  Choose the reporting time in the "Reporting time" field.
8.  Select the type of report you require from the "Report type" field.
9.  Select the report frequency period from the "Report frequency period" field.
10.  Enter the report start and end dates in the "Report start date" and "Report end date" fields.
11.  Choose whether the report is delivered to you or others from the "Report delivery" field.
12.  Select the reporting tool used from the "Reporting tool" field.
13.  Enter any additional information in the "Additional info" text field.
14.  Enter report notes in the "Report notes" text field.
15.  Enter the Jotform API key in the "Jotform API Key" field.
16.  Select whether the report frequency unit is required by selecting "Yes" or "No" in the "Report frequency unit" field.
17.  Enter your name in the "User Name" field.
18.  Enter your email address in the "Email" field.
19.  Enter your phone number in the "Phone" field.
20.  Enter the name of your organization in the "Organization" field.
21.  Enter the name of the reporting team or agency in the "Reporting Team" and "Reporting Agency" fields.
22.  Select whether a specific tool is assigned to you from the "Assigned tool" field.

## Field-by-Field Explanation

* **Requested metrics** (`analytics_request`, select_multiple, required/optional): Select the specific metrics you require for your report from the dropdown list.
* **Align goals** (`goal_alignment`, select_one, required/optional): Align the report with specific goals by selecting "Yes" or "No".
* **Data collection** (`data_collection`, select_one, required/optional): Choose whether data collection is required by selecting "Yes" or "No".
* **Data collection** (`data_collection`, select_one, required/optional): This field is redundant and should not be selected.
* **Standardize** (`standardize_data`, select_multiple, required/optional): Select whether data should be standardized by selecting "Yes" or "No".
* **Report frequency** (`report_frequency`, select_one, required/optional): Specify the report frequency by selecting one of the options.
* **Website performance** (`website_performance`, text, required/optional): Enter the website's performance in this text field.
* **Reporting deadline** (`reporting_deadline`, date, required/optional): Set the reporting deadline in this date field.
* **Reporting time** (`reporting_time`, time, required/optional): Choose the reporting time in this field.
* **Report type** (`report_type`, select_one, required/optional): Select the type of report you require from this field.
* **Report frequency period** (`report_frequency_period`, select_one, required/optional): Select the report frequency period from this field.
* **Report start date** (`report_start_date`, date, required/optional): Enter the report start date in this field.
* **Report end date** (`report_end_date`, date, required/optional): Enter the report end date in this field.
* **Report delivery** (`report_delivery`, select_multiple, required/optional): Choose whether the report is delivered to you or others from this field.
* **Reporting tool** (`reporting_tool`, select_one, required/optional): Select the reporting tool used from this field.
* **Additional info** (`additional_info`, text, required/optional): Enter any additional information in this field.
* **Report notes** (`report_notes`, text, required/optional): Enter report notes in this field.
* **Jotform API Key** (`jotform_api_key`, text, required/optional): Enter the Jotform API key in this field.
* **Report frequency unit** (`report_frequency_unit`, select_one, required/optional): Select whether report frequency unit is required by selecting "Yes" or "No".
* **User Name** (`user_name`, text, required/optional): Enter your name in this field.
* **Email** (`user_email`, email, required/optional): Enter your email address in this field.
* **Phone** (`user_phone`, text, required/optional): Enter your phone number in this field.
* **Organization** (`organization`, text, required/optional): Enter the name of your organization in this field.
* **Reporting Team** (`reporting_team`, text, required/optional): Enter the name of the reporting team or agency in this field.
* **Reporting Agency** (`reporting_agency`, text, required/optional): Enter the name of the reporting agency in this field.
* **Assigned tool** (`assigned_tool`, select_one, required/optional): Select whether a specific tool is assigned to you from this field.

## Tips

* Make sure to select only the metrics that are necessary for your report.
* Aligning goals with "Yes" is not always necessary; select "No" if not required.
* Data collection is not always required; select "No" if not necessary.
* Enter website performance in a descriptive manner to provide clear insights.
* Enter your contact information accurately to ensure smooth communication.
* Report notes can be used to provide additional context or explanations.
* Enter the Jotform API key correctly to allow for proper report generation.
* The report frequency unit is not always required; select "No" if not necessary.
* Ensure that you are entering your contact information correctly to ensure that your report is delivered to the right person.
* This form is for collecting website analytics report data and information. Please ensure that you are providing only necessary fields with accurate and relevant data.
* Double-check that you have filled out all required fields before submitting the form.
