# Project Handover Form - Help Guide
## Purpose
The Project Handover Form is a tool used to document and track project handovers, ensuring that all necessary information is captured and communicated effectively among team members and stakeholders.

## How To Complete This Form
1. Review each field carefully and ensure you understand its purpose before filling it out.
2. Fill out the form accurately and completely, without leaving any fields blank.
3. If a field is not applicable, please indicate this by selecting "N/A" or leaving it blank.
4. Review and verify the information before submitting the form.

## Field-by-Field Explanation
- **Project Handover Details** (`project_handover_info`, text, required/optional): This field captures the project handover details, providing a brief description of the project and its status.
- **Handover Date** (`handover_date`, date, required/optional): Enter the date of the project handover.
- **Responsible Party** (`responsible_party`, select_one, required/optional): Select the party responsible for the project handover.
- **Handover Notes** (`handover_notes`, note, required/optional): Add any additional notes or comments about the project handover.
- **Project Status** (`project_status`, select_one, required/optional): Indicate the current status of the project.
- **Resource Details** (`resource_details`, text, required/optional): Enter any resource details related to the project.
- **Resource List** (`resource_list`, select_multiple, required/optional): Select the resources involved in the project.
- **Next Steps** (`next_steps`, note, required/optional): Enter any next steps or actions required for the project.
- **Handover Person** (`handover_person`, select_one, required/optional): Select the person responsible for the project handover.
- **Handover Date and Time** (`handover_date_time`, time, required/optional): Enter the date and time of the project handover.
- **Handover Date and Time Comment** (`handover_date_time_comment`, text, required/optional): Add any comments or notes about the handover date and time.
- **Handover Date and Time Note** (`handover_date_time_note`, note, required/optional): Enter any additional notes or comments about the handover date and time.
- **Assigned Resources** (`assigned_resources`, select_multiple, required/optional): Select the resources assigned to the project.
- **Handover Resources** (`handover_resources`, select_multiple, required/optional): Select the resources involved in the handover.
- **Handover Date Time 2** (`handover_date_time_2`, time, required/optional): Enter the date and time of the handover 2.
- **Handover Notes 2** (`handover_notes_2`, note, required/optional): Enter any additional notes or comments about the handover 2.
- **Handover Person Comments** (`handover_person_comments`, select_multiple, required/optional): Select any comments about the handover person 2.
- **Project Notes** (`project_notes`, note, required/optional): Enter any additional notes or comments about the project.
- **Project Status 2** (`project_status_2`, select_one, required/optional): Indicate the current status of the project 2.
- **Handover Person 2** (`handover_person_2`, select_one, required/optional): Select the person responsible for the project 2.
- **Resources** (`resources`, select_multiple, required/optional): Select the resources involved in the project 2.
- **Project Status 3** (`project_status_3`, select_one, required/optional): Indicate the current status of the project 3.
- **Handover Date Time 3** (`handover_date_time_3`, time, required/optional): Enter the date and time of the handover 3.
