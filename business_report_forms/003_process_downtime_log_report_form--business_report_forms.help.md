# Process Downtime Log Report Form - Help Guide
## Purpose
The purpose of this form is to track and report on downtime events in a business process.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the correct category under which the downtime event falls.
2.  Provide a detailed description of the reason for the downtime event.
3.  Identify the individual or team responsible for resolving the issue.
4.  Leave the Form ID field blank as it's automatically generated.
5.  Optionally, specify an output file name.

## Field-by-Field Explanation
*   **Category** (`Category`, `select_one`, required: false): Select the category under which the downtime event falls.
    *   Options: Business Report Forms, Manufacturing Forms
*   **Description** (`Description`, `text`, required: false): Provide a detailed description of the reason for the downtime event.
*   **Assigned To** (`Assigned To`, `text`, required: false): Identify the individual or team responsible for resolving the issue.
*   **Form ID** (`Form ID`, `number`, required: false): Automatically generated unique identifier. Leave this field blank.
*   **Output File** (`Output File`, `text`, required: false): Specify the output file name or leave blank for default naming.
