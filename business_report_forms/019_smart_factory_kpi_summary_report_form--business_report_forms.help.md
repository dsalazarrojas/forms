# Smart Factory KPI Summary Report Form - Help Guide
## Purpose
The Smart Factory KPI Summary Report Form is used to collect and summarize key performance indicators for a manufacturing site.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter relevant information in the Production Data field.
2. Select the Manufacturing Site name.
3. Choose categories for KPIs in Category 1 and Category 2.
4. Enter values for KPIs 01-08.
5. Add any additional Notes about the report.

## Field-by-Field Explanation
* **Production Data**: Enter information about the current production state, such as production numbers or other relevant data.
* **Manufacturing Site**: Select the name of the manufacturing site to specify which factory is being reported on.
* **Category 1**: Choose a category for KPIs 01-08. This allows you to group KPIs into different categories.
* **KPI 01**: Enter a value for KPI 01.
* **KPI 02**: Enter a value for KPI 02.
* **KPI 03**: Enter a value for KPI 03.
* **KPI 04**: Enter a value for KPI 04.
* **KPI 05**: Enter a value for KPI 05.
* **KPI 06**: Enter a value for KPI 06.
* **KPI 07**: Enter a value for KPI 07.
* **KPI 08**: Enter a value for KPI 08.
* **Notes**: Add any additional information or comments about the report.
* **Category 2**: Choose categories for KPIs in this category.
* **Date**: Enter the date for which the report is being created.
* **Time**: Enter the time for which the report is being created.
