# Media Coverage Quarterly Metrics Report Form - Help Guide
## Purpose
This form is designed to collect media coverage metrics on a quarterly basis for a company or organization. It helps track and report on various aspects of media coverage, including impressions, reach, engagement, sentiment, and earned media value, to measure the success of media campaigns and identify areas for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the quarter for which you are reporting media coverage metrics.
2. Choose the type of media channels used for the coverage (e.g., TV, Print, Radio, Online, Social).
3. Enter the total number of impressions, reach, clicks, and engagement for the selected media channel.
4. Select the sentiment of the media coverage (e.g., Positive, Negative, Neutral).
5. Enter any additional comments or information about the media coverage.
6. Attach any relevant documents or files to support the report.
7. Enter the earned media value and currency used for the coverage.
8. Enter the date and time of the earned media value.
9. Enter any notes or comments about the earned media value.
10. Finally, review and submit the form to complete the media coverage quarterly metrics report.

## Field-by-Field Explanation

* **media_coverage_quarterly_metrics_report_form**: This is the title of the form, which is used to identify the report.
* **quarter**: Select the quarter for which you are reporting media coverage metrics. This can be any of the following options: January, February, March, April, May, June, July, August, September, October, November, December.
* **media_type**: Choose the type of media channels used for the coverage. Options include: 
	+ TV
	+ Print
	+ Radio
	+ Online
	+ Social
* **media_outlets**: Enter the total number of media outlets that covered the campaign.
* **impressions**: Enter the total number of impressions for the selected media channel.
* **reach**: Enter the total reach for the selected media channel.
* **clicks**: Enter the total number of clicks for the selected media channel.
* **engagement**: Enter the total engagement for the selected media channel.
* **sentiment**: Select the sentiment of the media coverage. Options include: 
	+ Positive
	+ Negative
	+ Neutral
* **comments**: Enter any additional comments or information about the media coverage.
* **media_coverage_quarterly_metrics_report_form_attachments**: Attach any relevant documents or files to support the report.
* **media_coverage_quarterly_metrics_report_form_earned_media_value**: Enter the earned media value for the coverage.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_currency**: Enter the currency used for the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_currency_symbol**: Enter the currency symbol used for the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_date**: Enter the date of the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_time**: Enter the time of the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_notes**: Enter any notes or comments about the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_comments**: Enter any additional comments about the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_attachments**: Attach any relevant documents or files to support the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_spent**: Enter the spent amount for the earned media value.
* **email**: Enter your email address.
* **phone**: Enter your phone number.
* **media_coverage_quarterly_metrics_report_form_additional_info**: Enter any additional information about the media coverage.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_currency_symbol**: Enter the currency symbol used for the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_date**: Enter the date of the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_time**: Enter the time of the earned media value.
* **media_coverage_quarterly_metrics_report_form_earned_media_value_spent**: Enter the spent amount for the earned media value.
