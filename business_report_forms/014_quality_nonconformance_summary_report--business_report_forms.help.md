# Quality Nonconformance Summary Report - Help Guide
## Purpose
The Quality Nonconformance Summary Report is used to document and track nonconformances (issues or defects) that occur within a business process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date of the nonconformance in the first field, using the date format YYYY-MM-DD.
2. Provide a brief description of the nonconformance in the second field.
3. Enter the location where the nonconformance occurred in the third field.
4. Indicate whether the nonconformance is internal or external by selecting 'Yes' or 'No' in the issue category field.
5. Select the severity level of the nonconformance (Critical, Major, Minor, or Informational) from the issue severity field.
6. Choose the status of the nonconformance (Open or Resolved) from the nonconformance status field.
7. Enter a description of the root cause of the nonconformance in the root cause field.
8. Provide a description of the corrective actions taken in the corrective action description field.
9. Select whether the corrective actions were taken or not from the corrective actions field.

## Field-by-Field Explanation
* **Nonconformance Date** (`nonconformance_date`, date, required/optional): Enter the date of the nonconformance in the format YYYY-MM-DD.
* **Nonconformance Description** (`nonconformance_description`, text, required/optional): Provide a brief description of the nonconformance.
* **Nonconformance Location** (`nonconformance_location`, text, required/optional): Enter the location where the nonconformance occurred.
* **Issue Category** (`issue_category`, select_multiple, optional): Indicate whether the nonconformance is internal (select 'Yes') or external (select 'No') by choosing 'Yes' or 'No' from the dropdown menu.
* **Issue Severity** (`issue_severity`, select_one, required/optional): Select the severity level of the nonconformance from the dropdown menu: Critical, Major, Minor, or Informational.
* **Nonconformance Status** (`nonconformance_status`, select_one, required/optional): Choose the status of the nonconformance: Open or Resolved from the dropdown menu.
* **Nonconformance Type** (`nonconformance_type`, text, required/optional): Enter a brief description of the nonconformance type.
* **Root Cause** (`root_cause`, text, required/optional): Enter a description of the root cause of the nonconformance.
* **Corrective Action Description** (`corrective_action_description`, text, required/optional): Provide a description of the corrective actions taken.
* **Corrective Actions** (`corrective_actions`, select_multiple, required/optional): Select whether the corrective actions were taken or not by choosing 'Yes' or 'No' from the dropdown menu.
