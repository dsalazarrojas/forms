# Project Timeline Adherence Report Form - Help Guide
## Purpose
The Project Timeline Adherence Report Form is used to collect information about project timelines and their adherence to schedule.

## How To Complete This Form
1. Select the project you want to report on by entering the project ID in the "Project Id" field.
2. Enter the name of the team responsible for the project in the "Team Name" field.
3. If applicable, enter the start and end dates of the project in the "Start Date" and "End Date" fields, respectively.
4. Choose the status of the project from the options provided in the "Status" field.
5. Enter the progress made on the project in the "Progress" field.
6. If applicable, enter any delays or issues that have occurred during the project in the "Delay" field.
7. Describe any corrective actions taken or planned to be taken in the "Corrective Action" field.
8. Optionally, add any additional remarks about the project in the "Remarks" field.
9. If you have a personal email address and phone number that you'd like to be associated with the report, enter them in the "Email" and "Phone" fields, respectively.
10. Indicate whether the project was assigned to someone or not by selecting "Yes" or "No" in the "Assigned To" field.
11. If applicable, select whether you or someone else created the report by selecting "Yes" or "No" in the "Created By", "Updated By", and "Submitted By" fields.

## Field-by-Field Explanation

* **Project Id (1)**: Enter the unique ID for the project.
* **Team Name (2)**: Enter the name of the team responsible for the project.
* **Start Date (3)**: Enter the start date of the project if it applies.
* **End Date (4)**: Enter the end date of the project if it applies.
* **Status (5)**: Choose the status of the project from the options provided:
	+ Active
	+ Inactive
* **Progress (6)**: Enter the progress made on the project.
* **Delay (7)**: Enter any delays or issues that have occurred during the project.
* **Corrective Action (8)**: Describe any corrective actions taken or planned to be taken.
* **Remarks (9)**: Add any additional remarks about the project.
* **Email (10)**: Enter your personal email address if you'd like to be associated with the report.
* **Phone (11)**: Enter your personal phone number if you'd like to be associated with the report.
* **Assigned To (12)**: Indicate whether the project was assigned to someone or not by selecting "Yes" or "No".
* **Created By (13)**: Select whether you or someone else created the report by selecting "Yes" or "No".
* **Updated By (14)**: Select whether someone else updated the report by selecting "Yes" or "No".
* **Submitted By (15)**: Select whether you submitted the report by selecting "Yes" or "No".
