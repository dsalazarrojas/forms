# Social Media Performance Report Form - Help Guide
## Purpose

This form is designed to collect social media performance data for analysis and reporting purposes. It provides a structured way to gather metrics on engagement, reach, and click-through rates from various social media platforms.

## How To Complete This Form

1. **Select the Date Range**: Choose the start and end dates for which you want to gather performance data.
2. **Choose the Platform**: Select the social media platform from which you want to gather data (e.g., Twitter, Facebook, Instagram, LinkedIn).
3. **Choose the Post Type**: Select the type of post you want to analyze (e.g., Video, Image, Link, Article, Story, etc.).
4. **Select Engagement Metrics**: Choose the metrics you want to track (e.g., Likes, Comments, Shares, Saves, Posts).
5. **Enter Engagement Metric Values**: Enter the actual values for the selected metrics.
6. **Select Reach Metrics**: Choose the metrics you want to track for reach (e.g., Impression, Engagement, Conversions, Clicks, Views).
7. **Enter Reach Metric Values**: Enter the actual values for the selected metrics.
8. **Click-Through Rate (CTR)**: Enter the CTR value for the selected platform and post type.

## Field-by-Field Explanation

* **User Id** (`user_id`, `number`, required: false): Enter your unique ID, if applicable.
* **Date Range Start** (`date_range_start`, `date`, required: false): Choose the start date for which you want to gather performance data.
* **Date Range End** (`date_range_end`, `date`, required: false): Choose the end date for which you want to gather performance data.
* **Platform** (`platform_id`, `select_one`, required: false): Select the social media platform from which you want to gather data (e.g., Twitter, Facebook, Instagram, LinkedIn).
* **Post Type** (`post_type_id`, `select_one`, required: false): Select the type of post you want to analyze (e.g., Video, Image, Link, Article, Story, etc.).
* **Engagement Metric** (`engagement_metric`, `select_multiple`, required: false): Choose the metrics you want to track (e.g., Likes, Comments, Shares, Saves, Posts).
* **Engagement Metric Value** (`engagement_metric_value`, `number`, required: false): Enter the actual values for the selected metrics.
* **Reach Metric** (`reach_metric`, `select_multiple`, required: false): Choose the metrics you want to track for reach (e.g., Impression, Engagement, Conversions, Clicks, Views).
* **Reach Metric Value** (`reach_metric_value`, `number`, required: false): Enter the actual values for the selected metrics.
* **Click-Through Rate** (`click_through_rate`, `number`, required: false): Enter the CTR value for the selected platform and post type.
