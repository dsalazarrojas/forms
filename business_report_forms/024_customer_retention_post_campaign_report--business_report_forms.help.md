# Customer Retention Post Campaign Report - Help Guide
## Purpose
The Customer Retention Post Campaign Report is a tool used to gather valuable information from customers about their experiences with recent campaigns. This information will help the marketing team to improve the effectiveness of future campaigns.

## How To Complete This Form
To complete this form, follow these steps:
1. Answer the questions about the outcomes of the last campaign.
2. Provide information on the performance of the last campaign over time.
3. Share any learnings or insights you gained from participating in the campaign.
4. Describe the outcomes of previous campaigns.
5. Select the best description of the performance of previous campaigns.
6. Share any learnings or insights from previous campaigns.
7. Provide feedback on the customer experience with the last campaign.
8. Describe the outcome of the customer feedback provided.

## Field-by-Field Explanation
* **Campaign Outcomes** (`campaign_outcomes`, Select Multiple, required: false): This field is used to select multiple outcomes of the last campaign.
* **Performance Over Time** (`performance_over_time`, Select Multiple, required: false): Choose the best description of the performance of the last campaign over time.
* **Learnings Shared** (`learnings_shared`, Text, required: false): Describe any learnings or insights you gained from participating in the last campaign.
* **What Were The Outcomes Of The Last Campaign** (`campaign_outcomes_1`, Select One, required: false): Select one description of the outcomes of the last campaign.
* **Which Of The Following Best Describe The Performance Of The Campaign Over Time** (`performance_over_time_1`, Select Multiple, required: false): Select multiple descriptions that best describe the performance of the last campaign over time.
* **What Learnings Were Shared With Stakeholders** (`learnings_shared_1`, Text, required: false): Describe any learnings or insights you gained from participating in the last campaign.
* **What Were The Outcomes Of The Previous Campaign** (`campaign_outcomes_2`, Select One, required: false): Select one description of the outcomes of the previous campaign.
* **Which Of The Following Best Describe The Performance Of The Previous Campaign** (`performance_over_time_2`, Select Multiple, required: false): Select multiple descriptions that best describe the performance of the previous campaign.
* **What Learnings Were Shared With Previous Stakeholders** (`learnings_shared_2`, Text, required: false): Describe any learnings or insights from the previous campaign.
* **What Feedback Have You Got From Customers** (`customer_feedback_1`, Text, required: false): Provide feedback on the customer experience with the last campaign.
* **Have You Received** (`customer_feedback_1_1`, Text, required: false): This field is not explicitly described, it seems to be a follow-up question for customer feedback.
* **What Was The Outcome Of It** (`customer_feedback_1_2`, Select One, required: false): Describe the outcome of the customer feedback provided.
