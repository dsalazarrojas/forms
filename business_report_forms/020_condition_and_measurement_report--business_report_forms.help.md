# Condition And Measurement Report - Help Guide

## Purpose

This form is for creating a Condition and Measurement Report. It captures essential information about a condition assessment of an asset.

## How To Complete This Form

1.  Fill in the required fields:
	* Report Date: Enter the date of inspection.
	* Report Number: Enter the unique ID of the report.
	* Inspector Name: Enter the name of the person conducting the inspection.
	* Inspector Company: Enter your organization's name (if required).
	* Asset Name: Enter the name of the equipment or facility inspected.
	* Asset Location: Enter where the asset is located.
	* Asset Type: Choose the category of the asset from the options (e.g., Building Structure, HVAC System).
	* Overall Condition: Rate the general condition of the asset (Excellent, Very Good, Good, Fair, Poor, Critical).
	* Functional Condition: Assess the operational status of the asset (Fully Functional, Minor Issues, Major Issues, Non Functional).
	* Priority Level: Determine the urgency of repairs (Low No Immediate Action, Medium Schedule Soon, High Urgent Attention, Critical Immediate Action).
	* Follow Up Required: Indicate if re-inspection is needed.
	* Inspector Signature: Confirm the report accuracy.
2. If applicable, fill in the additional fields:
	* Asset Information: Enter details about the inspected asset.
	* Defects Found: Describe any issues found during inspection.
	* Photos Attached: Indicate if documentation photos are included.
3. For measurements, if you need to record multiple values:
	* Enter Measurement Name and Value in separate fields for each measurement.
	* Choose the Measurement Unit for each measurement (e.g., Meters, Feet, Inches).
4. Enter any recommendations and actions needed for asset maintenance or repair.

## Field-by-Field Explanation

* **Report Header** (Note): A brief description of the condition assessment.
* **Report Date** (Date): The date the inspection was conducted.
* **Report Number** (Text): A unique ID for the report.
* **Inspector Name** (Text): The name of the person conducting the inspection.
* **Inspector Company** (Text): Optional field for organization name.
* **Asset Information** (Note): Details about the inspected asset.
* **Asset Name** (Text): The name of the equipment or facility inspected.
* **Asset Location** (Text): Where the asset is located.
* **Asset Type** (Select One): The category of the asset.
* **Overall Condition** (Select One): Overall condition rating of the asset.
* **Functional Condition** (Select One): Operational status of the asset.
* **Priority Level** (Select One): Urgency of repairs.
* **Defects Found** (Text): Describe any issues found during inspection.
* **Photos Attached** (Select One): Indicate if documentation photos are included.
* **Follow Up Required** (Select One): Whether re-inspection is needed.
* **Inspector Signature** (Select One): Confirm report accuracy.
* **Measurement 1 Name** (Text): Name of the first measurement (if applicable).
* **Measurement 1 Value** (Number): Recorded value of the first measurement.
* **Measurement 1 Unit** (Select One): Unit of the first measurement.
* **Measurement 2 Name** (Text): Name of the second measurement (if applicable).
* **Measurement 2 Value** (Number): Recorded value of the second measurement.
* **Measurement 2 Unit** (Select One): Unit of the second measurement.
* **Recommendations** (Text): Suggested actions for asset maintenance or repair.
* **Priority Level** (Select One): Urgency of repairs.
* **Photos Attached** (Select One): Indicate if documentation photos are included.
* **Follow Up Required** (Select One): Whether re-inspection is needed.
* **Inspector Signature** (Select One): Confirm report accuracy.

Tips:
* Ensure the report accurately reflects the condition assessment of the asset.
* Enter all applicable details for a comprehensive report.
* Use the options for Overall Condition, Functional Condition, and Priority Level to assess the asset's status accurately.
* If applicable, attach photos or documentation to support the report.
* Confirm the report accuracy by signing the inspector's signature field.
