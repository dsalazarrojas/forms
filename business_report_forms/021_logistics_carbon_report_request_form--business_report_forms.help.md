# Logistics Carbon Report Request Form - Help Guide
## Purpose
The Logistics Carbon Report Request Form is used to request a logistics carbon report for a specific logistics activity. The report will provide an assessment of the carbon footprint of the activity, which can be used to identify areas for improvement and reduce carbon emissions.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the company location where the logistics activity took place.
2. Select the start date and time of the activity.
3. Select the end date and time of the activity.
4. Enter the distance traveled during the activity.
5. Enter the estimated carbon emissions of the activity.
6. Select the mode of transport used during the activity (e.g. Air, Land, Sea, Train, Other).
7. Add any additional comments about the activity.

## Field-by-Field Explanation
* **Logistics Carbon Report** (`logistics_carbon_report_request_form`, text, required: false): Enter a brief description of the logistics activity.
* **Company Location** (`company_location`, text, required: false): Enter the company location where the logistics activity took place.
* **Start Date** (`start_date`, date, required: false): Select the start date of the activity.
* **Start Time** (`start_time`, time, required: false): Select the start time of the activity.
* **End Date** (`end_date`, date, required: false): Select the end date of the activity.
* **End Time** (`end_time`, time, required: false): Select the end time of the activity.
* **Distance** (`distance`, number, required: false): Enter the distance traveled during the activity.
* **Carbon Emissions** (`carbon_emissions`, number, required: false): Enter the estimated carbon emissions of the activity.
* **Mode of Transport** (`mode_of_transport`, select_one, required: false): Select the mode of transport used during the activity (e.g. Air, Land, Sea, Train, Other).
* **Comments** (`comments`, note, required: false): Add any additional comments about the activity.

Note: All fields are optional, but please ensure that you provide as much information as possible to get a accurate assessment of the carbon footprint of the activity.
