# Graduate Employment Rate Report Form - Help Guide
## Purpose
This form is used to gather information about graduate employment rates for various programs. It helps administrators track the employment status of graduates and make informed decisions about program implementation.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the program name in the "Program Name" field.
2. Enter the cohort start date in the "Cohort Start Date" field in YYYY-MM-DD format.
3. Enter the program duration in the "Program Duration" field.
4. Select the gradation employment rate from 0-100 in the "Grad Employment Rate" field.
5. Select one or more employment outcomes for the graduate in the "Employment Outcome Indicators" field. Choose from the options "Employed", "Unemployed", "Not Contacted", or "Other".
6. Add any additional comments about the employment outcome in the "Employment Outcome Comments" field (optional).
7. Enter the email of the graduate in the "Email" field (optional).

## Field-by-Field Explanation
- **Program Name** (text, required/optional): Enter the name of the program for which you are reporting on the graduate's employment status.
- **Cohort Start Date** (date, required/optional): Enter the start date of the program cohort in YYYY-MM-DD format.
- **Program Duration** (number, required/optional): Enter the duration of the program in months or years.
- **Grad Employment Rate** (number, required/optional): Enter the graduate employment rate as a percentage, between 0 and 100.
- **Employment Outcome Indicators** (select multiple, required/optional): Select one or more employment outcomes for the graduate, such as "Employed", "Unemployed", "Not Contacted", or "Other".
- **Employment Outcome Comments** (note, required/optional): Add any additional comments about the employment outcome.
- **Email** (email, required/optional): Enter the email of the graduate (if available).
