# Organization Awards Nomination Form - Help Guide

## Purpose
The Organization Awards Nomination Form is designed to collect information about an organization's award nominations. This form is used to gather data on the categories, recipients, justification, and other details of the nominations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the **Category** for the nomination. Please choose from the options "Industry" or "Organization".
2. Select the **Recipient(s)** for the nomination. Please choose from the options "Team", "Employee", or "Client".
3. Provide a justification for the nomination in the **Nomination Justification** field.
4. If you plan to submit multiple nominations, please indicate how many you plan to submit in the **Planned Nominations** field.
5. If you have already submitted some nominations, please indicate how many you actually submitted in the **Actual Nominations** field.
6. Enter the nomination year and date for the award in the **Nomination Year** and **Date Nominations** fields respectively.
7. Provide your contact information (email address and phone number) in the **Email Contact** and **Phone Contact** fields.
8. If you have additional nominations not listed above, please provide them in the **Additional Nominations** field.
9. If you have any additional comments or notes, please use the **Notes** field.

## Field-by-Field Explanation

* **Organization**: This is the name of the organization nominating for an award. Please enter the name of your organization.
* **Category**: Select the category for the nomination. Please choose from the options "Industry" or "Organization".
* **Recipient**: Select the recipient(s) of the nomination. Please choose from the options "Team", "Employee", or "Client".
* **Nomination Justification**: This is a text field for you to explain why you are nominating this organization for an award.
* **Planned Nominations**: If you plan to submit multiple nominations, please enter the number of nominations you plan to submit.
* **Actual Nominations**: If you have already submitted some nominations, please enter the number of nominations you actually submitted.
* **Nomination Year**: Enter the year for which the nomination is for.
* **Date Nominations**: Enter the date for which the nomination is for.
* **Award Date**: Enter the date on which the award was given.
* **Nomination Amount**: This field is not currently applicable, please leave it blank.
* **Email Contact**: Enter your email address so we can contact you for further information.
* **Phone Contact**: Enter your phone number so we can contact you for further information.
* **Award Recipient Phone**: Enter the phone number of the award recipient.
* **Additional Nominations**: If you have any additional nominations not listed above, please provide them here.
* **Notes**: If you have any additional comments or notes, please use this field.
