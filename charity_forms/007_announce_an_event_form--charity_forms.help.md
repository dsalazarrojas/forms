# Announce An Event Form - Help Guide

## Purpose
The Announce An Event Form is designed to collect information about events hosted by charities or organizations. This information will be displayed on our website to promote awareness and support for various causes.

## How To Complete This Form

1.  Fill out the required fields marked with an asterisk (\*) as you progress through the form.
2.  Ensure that you complete each field accurately and truthfully.
3.  If you're unsure about a field or have questions, please refer to the help guide below.

## Field-by-Field Explanation

*   **Contact Person Name (*)**: The full name of the person or organization hosting the event.
    This field is required for contact and follow-up purposes.
*   **Organization Name (*)**: The name of your organization or charity.
    This field helps us identify the event's association with a specific charity.
*   **Email Address (*)**: The primary contact email for the event organizer.
    This field is used for communication and follow-up.
*   **Phone Number (*)**: The best contact number for the event organizer.
    This field is used for urgent or out-of-band communication.
*   **Event Title (*)**: The official title of the event.
    This is the main title that will be displayed on the event listing.
*   **Event Type (*)**: The type of event (e.g., Fundraiser, Charity Gala, Community Event).
    This field helps us categorize the event type for promotion and filtering.
*   **Event Category (*)**: The primary cause or category of the event.
    This field helps us group events by cause for promotion and filtering.
*   **Event Date (*)**: The date of the event.
    This field is used to schedule the event on the calendar.
*   **Event Start Time (*)**: The start time of the event.
    This field is used to schedule the event on the calendar.
*   **Event End Time**: The end time of the event. (Optional)
    This field is used to schedule the event on the calendar.
*   **Venue Name (*)**: The name of the event location.
    This field is used to locate the event on a map.
*   **Venue Address (*)**: The full address of the event location.
    This field helps us provide directions to the venue.
*   **Event Format (*)**: The format of the event (e.g., In-Person, Virtual, Hybrid).
    This field helps us promote the event's format to the right audience.
*   **Expected Attendance (*)**: The approximate number of attendees.
    This field helps us plan and promote the event accordingly.
*   **Event Description (*)**: A detailed description of the event.
    This field provides context and information about the event's purpose and goals.
*   **Mission or Purpose (*)**: A brief statement of the event's mission or purpose.
    This field helps us understand the event's underlying goals and values.
*   **Fundraising Goal**: The target amount to raise for the event. (Optional)
    This field is used to promote the fundraising goal and encourage donations.
*   **Registration Required**: Whether registration is required for the event.
    This field helps us promote the event's registration requirements.
*   **Registration Fee**: The cost to register for the event. (Optional)
    This field is used to promote the registration fee and encourage registration.
*   **Registration URL**: The link to register for the event. (Optional)
    This field is used to direct attendees to the registration page.
*   **Event Website**: The URL for more information about the event. (Optional)
    This field is used to provide additional resources and information.
*   **Social Media Links**: Relevant social media pages for the event. (Optional)
    This field is used to promote the event's social media presence.
*   **Target Audience**: The group the event is intended for.
    This field helps us promote the event to the right audience.
*   **Accessibility Features**: Select all applicable features that will be provided at the event.
    This field helps us promote the event's accessibility features.
*   **Sponsorship Opportunities Available**: Whether sponsorship opportunities are available for the event.
    This field helps us promote the event's sponsorship opportunities.
*   **Media Contact Name**: The person to contact for press inquiries.
    This field is used for media and press communication.
*   **Additional Information**: Any other details about the event.
    This field is used to provide additional context and information.
*   **Additional Notes**: Any other details that are not covered in other fields.
    This field is used to provide additional context and information.

## Tips

*   Always complete each field truthfully and accurately.
*   Review each field's help guide before proceeding.
*   Double-check your responses before submitting the form.
*   If you're unsure about a field or have questions, please reach out to us for clarification.
