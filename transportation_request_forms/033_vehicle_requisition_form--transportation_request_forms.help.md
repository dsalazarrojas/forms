# vehicle_requisition_form - Help Guide
## Purpose
The "vehicle_requisition_form" is designed to request a vehicle for official use within the organization. It helps to collect essential details such as vehicle ID, user ID, and other relevant information for efficient vehicle management.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **Vehicle ID**, a unique identifier for the vehicle you are requesting.
2. Enter your **User ID**, your unique identifier for the system.
3. Select the **Date Required** when you need the vehicle, or leave blank if not applicable.
4. Select the **Time Required** when you need the vehicle, or leave blank if not applicable.
5. Choose the **Vehicle Type** of the vehicle you need, if applicable.
6. Select whether the vehicle you are requesting is a **Vehicle Make**, if applicable.
7. Enter the **Vehicle Model**, if applicable.
8. Choose the **Purpose** of the vehicle request, if applicable.
9. Enter your **Department ID**, if applicable.
10. Enter your **Approver ID**, if applicable.
11. Choose the **Status** of the vehicle request, if applicable.
12. Provide any **Comments** about your vehicle request, if applicable.
13. Select whether you are the **Form Submitter**, if applicable.
14. Choose whether the vehicle is **Assigned To**, if applicable.
15. Select whether the vehicle is **Assigned By**, if applicable.

## Field-by-Field Explanation

* **Vehicle ID** (<name>): Enter the unique identifier for the vehicle you are requesting.
* **User ID** (<name>): Enter your unique identifier for the system.
* **Date Required** (<name>): Select the date when you need the vehicle. If not applicable, leave blank.
* **Time Required** (<name>): Select the time when you need the vehicle. If not applicable, leave blank.
* **Vehicle Type** (<name>): Choose the type of vehicle you need, if applicable.
* **Vehicle Make** (<name>): Select whether the vehicle you are requesting is a make, if applicable.
* **Vehicle Model** (<name>): Enter the model of the vehicle you are requesting, if applicable.
* **Purpose** (<name>): Choose the purpose of the vehicle request, if applicable.
* **Department ID** (<name>): Enter your department ID, if applicable.
* **Approver ID** (<name>): Enter your approver ID, if applicable.
* **Status** (<name>): Choose the status of the vehicle request, if applicable.
* **Comments** (<name>): Provide any comments about your vehicle request, if applicable.
* **Form Submitter** (<name>): Select whether you are the form submitter, if applicable.
* **Vehicle Assigned To** (<name>): Choose whether the vehicle is assigned to someone, if applicable.
* **Vehicle Assigned By** (<name>): Choose whether the vehicle is assigned by someone, if applicable.
