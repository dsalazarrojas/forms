# Test Drive Request Form - Help Guide
## Purpose
The "Test Drive Request Form" is used to request a test drive for a vehicle. It is an essential step in the vehicle purchasing process, allowing the user to experience the vehicle's features and performance before making a decision.

## How To Complete This Form
1. Ensure you have all the necessary information and documents ready before starting the form.
2. Fill out the form carefully, making sure to complete all required fields.
3. Select the correct options for each field according to your preference.

## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, required): Enter your first name as it appears on your government-issued ID.
* **Last Name** (`last_name`, `text`, required): Enter your last name as it appears on your government-issued ID.
* **Email** (`email`, `email`, required): Enter your email address where you can be contacted for test drive arrangements.
* **Phone** (`phone`, `text`, optional): Enter your phone number where you can be contacted for test drive arrangements.
* **Date of Birth** (`date`, `date`, required): Enter your date of birth in the format MM/DD/YYYY.
* **Vehicle** (`vehicle`, `select_one`, required): Select the make of the vehicle you wish to test drive (Ford, Chevrolet, Toyota).
* **Test Drive Location** (`test_drive_location`, `select_multiple`, required): Select where you would like to take the test drive (Dealership, Customer's Home, Other).
* **Comments** (`comments`, `note`, optional): Add any additional comments or notes about the test drive request.
* **Assigned to** (`assigned_to`, `select_one`, required): Select who you would like to be assigned to (chatjimmy, chatjimmy1).
* **Form Submitted By** (`form_submitted`, `select_one`, required): Select who submitted the form (user, admin).
* **Test Drive Duration** (`test_drive_duration`, `select_multiple`, required): Select the duration of the test drive (30, 60, 90).
* **Test Drive Distance** (`test_drive_distance`, `select_multiple`, required): Select the distance of the test drive (short, long).
* **Test Drive Time of Day** (`test_drive_time_of_day`, `select_multiple`, required): Select the time of day for the test drive (morning, afternoon, evening).
* **Test Drive Comments** (`test_drive_comments`, `select_multiple`, required): Select how you feel about the test drive (positive, negative, neutral).
* **Form Status** (`form_status`, `select_one`, optional): Select the current status of the form (new, pending, completed).
