# Stage Performance Transport Request Form - Help Guide
## Purpose
The Stage Performance Transport Request form is used to collect information from performers about their transportation needs for stage performance events. This form is essential for event organizers to make necessary arrangements and ensure a smooth event execution.

## How To Complete This Form
To fill out the Stage Performance Transport Request form, follow the steps below:

1. Enter your name as the performer.
2. Choose whether or not you will be bringing a crew (number of crew members is optional if yes is selected).
3. Select the type of transportation you will need (yes/no).
4. Provide the date you will be traveling for the event.
5. Indicate if you will be traveling with a crew or not.

## Field-by-Field Explanation
* **Stage Performance Transport Request**: Enter a brief description of your transportation requirements for the event.
* **Performer Name**: Enter your name as the performer.
* **Number of Crew**: If you will be bringing a crew, enter the number of crew members who will be accompanying you.
* **Crew Members**: If you will be bringing a crew, select all applicable crew members from the options. If not, select 'No'.
* **Transport Type**: Select 'Yes' if you will need transportation, and 'No' otherwise.
* **Travel Date**: Provide the date you will be traveling for the event.
* **Travel Date (again)**: This field should match the date you provided in the previous field to confirm consistency.
* **Transport Type (again)**: This field should match the selection you made in the previous field.
