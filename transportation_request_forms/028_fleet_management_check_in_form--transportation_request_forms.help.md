# Fleet Management Check In Form - Help Guide
## Purpose
This form is designed to gather essential information about vehicle check-ins, including the vehicle's status, location, and condition.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the status of the vehicle from the dropdown menu.
2. Enter the date of the vehicle check-in using the date picker.
3. Enter the location of the vehicle check-in.
4. Select the time of the vehicle check-in using the time picker.
5. Add any additional notes about the vehicle check-in (optional).
6. Assign a driver to the vehicle (if applicable).
7. Select the condition of the vehicle (if applicable).

## Field-by-Field Explanation
* **Vehicle** (`Vehicle`, select_multiple, **required**): Select the current status of the vehicle from the options provided.
* **Date** (`check_in_date`, date, **required**): Enter the date of the vehicle check-in using the calendar picker.
* **Location** (`check_in_location`, text, **optional**): Enter the location where the vehicle is checked in.
* **Time** (`check_in_time`, time, **required**): Select the time of the vehicle check-in using the time picker.
* **Notes** (`notes`, note, **optional**): Add any additional notes or comments about the vehicle check-in.
* **Assigned Driver** (`assigned_driver`, select_one, **optional**): Select the driver assigned to the vehicle (if applicable).
* **Vehicle Condition** (`vehicle_condition`, select_one, **optional**): Select the current condition of the vehicle from the options provided.
* **Fuel Level** (`fuel_level`, select_one, **optional**): Select the current fuel level of the vehicle from the options provided.
