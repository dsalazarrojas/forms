# Guest Shuttle Route Request Form - Help Guide
## Purpose
The Guest Shuttle Route Request Form is used to create or edit a new route request for the guest shuttle service.

## How To Complete This Form
To complete this form, follow these steps:
1. Ensure you are authorized to fill this form.
2. Fill in the required fields as accurately as possible.
3. Make sure to select the correct options for the shuttle service.

## Field-by-Field Explanation

* **Title** (text): This is the title of the form, and it will be used as the header of the form. You can't change this field.
* **Shuttle Info** (text): This field is used to provide any additional information about the shuttle request.
* **Passenger Info** (text): This field is used to provide any additional information about the passengers.
* **Shuttle Date** (date): Select the date of the shuttle request.
* **Shuttle Locations** (text): Enter the locations that you want to be transported between.
* **Shuttle Time** (time): Select the time of the shuttle request.
* **Shuttle Vehicle** (select_one):
	+ "Yes" - You want a vehicle to be assigned to the shuttle.
	+ "No" - You do not want a vehicle to be assigned to the shuttle.
* **Notes** (note): Enter any additional notes about the shuttle request.
* **Submit Request** (select_one):
	+ "Yes" - You want to submit the shuttle request.
	+ "No" - You do not want to submit the shuttle request.

## Tips
* Make sure to select a valid date and time for the shuttle request.
* Ensure that you have permission to request transportation on behalf of the guests.
* Double-check the form before submission to avoid errors.
