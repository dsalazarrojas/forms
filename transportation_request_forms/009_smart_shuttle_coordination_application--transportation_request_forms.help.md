# Smart Shuttle Coordination Application - Help Guide
## Purpose
This form is used to request a transportation service for a trip. It gathers information about the trip details to ensure that the shuttle service can be provided correctly.

## How To Complete This Form
To fill out this form, follow these steps:
1. Select whether you are requesting a shuttle service or not.
2. Provide details about your trip, such as the date and time you need to be picked up and dropped off.
3. Specify the location of the pickup and dropoff points.
4. Enter the number of riders for the trip.
5. Optionally, select a time range for the pickup and dropoff.
6. Add any additional comments or notes about your trip.

## Field-by-Field Explanation

* **Transport Request Form** (Yes/No):
	+ Choose 'Yes' if you are requesting a shuttle service, 'No' otherwise.
* **Trip Details** (Select One):
	+ Select 'Yes' if you are requesting a specific trip, 'No' if you are not.
* **Pickup/Dropoff Time** (time):
	+ Enter the time you need to be picked up or dropped off.
* **Pickup/Dropoff Date** (date):
	+ Enter the date of the trip.
* **Pickup/Dropoff Location** (text):
	+ Enter the location where you need to be picked up or dropped off.
* **Number of Riders** (number):
	+ Enter the number of people traveling with you.
* **Pickup/Dropoff Time Range** (number):
	+ Enter a time range for the pickup and dropoff (e.g., 30 minutes, 1 hour, etc.).
* **Additional Notes** (note):
	+ Enter any additional comments or information about your trip.
