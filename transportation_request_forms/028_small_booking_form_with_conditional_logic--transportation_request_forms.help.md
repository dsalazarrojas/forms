# small_booking_form_with_conditional_logic - Help Guide
## Purpose
This form is used to collect information on transportation requests. It helps staff members or users to submit details of a trip, including departure and arrival dates, travel class, and other relevant information.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the trip details: Provide the necessary information about your trip, including the departure and arrival dates.
2. Select the travel class: Choose the class of travel that best suits your needs.
3. Indicate travel agency involvement: Decide if your travel involves a travel agency.
4. Specify pickup and dropoff locations: Choose the type of location you would like the transportation to be picked up or dropped off at.
5. Add any special requests: If you have any specific needs or requirements for your transportation, add them in this field.
6. Confirm assignment: Decide if the transportation request has been assigned to someone.
7. Confirm tool assignment: Decide if a specific tool has been assigned for the transportation.

## Field-by-Field Explanation

* **Trip Details** (page 1, trip_details): Enter a brief description of your trip, including any relevant details.
* **Departure Date** (page 1, departure_date): Select the date you would like to depart from your location.
* **Arrival Date** (page 1, arrival_date): Select the date you would like to arrive at your destination.
* **Travel Class** (page 1, travel_class): Choose the class of travel that best suits your needs, such as Economy, First Class, or Business.
* **Travel Agency** (page 1, travel_agency): Decide if your travel involves a travel agency.
	+ Select 'Yes' if you are using a travel agency.
	+ Select 'No' if you are not using a travel agency.
* **Pickup/Dropoff** (page 1, pickup_dropoff): Choose the type of location you would like the transportation to be picked up or dropped off at.
	+ Select 'Pickup' if you would like the transportation to be picked up at your location.
	+ Select 'Dropoff' if you would like the transportation to be dropped off at your destination.
* **Notes** (page 2, notes): Enter any additional information that may be helpful for the person arranging your transportation.
* **Special Requests** (page 2, special_requests): Enter any special requests or requirements for your transportation.
* **Assigned To** (page 2, assigned_to): Decide if the transportation request has been assigned to someone.
	+ Select 'Yes' if it has been assigned.
	+ Select 'No' if it hasn't been assigned yet.
* **Assigned Tool** (page 2, assigned_tool): Decide if a specific tool has been assigned for the transportation.
	+ Select 'Yes' if it has been assigned.
	+ Select 'No' if it hasn't been assigned yet.

Please note that the form has conditional logic, where certain fields may be required or optional based on the user's selection in other fields.
