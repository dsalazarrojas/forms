**Front Seat Access Request Form - Help Guide**
## Purpose
The Front Seat Access Request Form is a tool used by tour leaders and event organizers to request front seat access for students on a school tour or event. This form helps to collect important details required for granting front seat access.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the relevant fields with accurate information.
2.  Ensure the "Front Seat Access Request" field is complete and accurate.
3.  Enter the name of the school where the tour or event is taking place in the "School Name" field.
4.  Input the number of students requiring front seat access in the "Student Count" field.
5.  Choose the date for the requested front seat access in the "Date Requested" field.

## Field-by-Field Explanation
* **Front Seat Access Request**: Enter a brief description of the reason for the front seat access request. Please ensure it is clear and concise.
* **School Name**: Enter the name of the school where the tour or event is taking place.
* **Tour Leader or Event Orgs Name**: Enter the name of the tour leader or event organizer requesting front seat access.
* **Student Count**: Enter the number of students who will be attending the tour or event.
* **Date Requested**: Select the date you are requesting front seat access for the students. This is the date of the tour or event.

## Tips
*   Make sure to provide accurate and up-to-date information to avoid any issues with your front seat access request.
*   If you are requesting front seat access for multiple students, ensure that all the required fields for each student are completed accurately.
