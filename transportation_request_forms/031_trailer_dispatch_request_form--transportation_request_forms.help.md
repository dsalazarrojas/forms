# Trailer Dispatch Request Form - Help Guide
## Purpose
The Trailer Dispatch Request Form is a crucial tool for requesting trailer dispatch services from our company. It is used to provide detailed information about the trailer and shipment requirements, ensuring accurate and efficient trailer dispatch. This form should be completed by drivers, dispatchers, or anyone requesting trailer services to streamline the communication process.

## How To Complete This Form

- Ensure you have all the required information ready before proceeding.
- Select the correct trailer type from the list provided:
	+ Dry Van Trailer
	+ Reefer Trailer
	+ Flatbed Trailer

- Enter the pickup location where the trailer should be dispatched to:
	+ Provide the exact street address, including city and state.
	+ This field is mandatory, as it helps us locate the trailer accurately.

- Enter the delivery location where the trailer should be delivered:
	+ Provide the exact street address, including city and state.
	+ This field is mandatory.

- Select the dispatch date for the trailer:
	+ Choose the date when the trailer is expected to be dispatched.
	+ This field is mandatory.

- Enter the name of the driver assigned to handle the trailer:
	+ If no driver is assigned, leave this field empty.

- Enter the phone number of the driver (if assigned):
	+ If no driver is assigned, leave this field empty.

- Enter the unique trailer number:
	+ This is the ID for the specific trailer to be dispatched.
	+ This field is mandatory.

- Enter the shipment number:
	+ Provide a unique reference number for the shipment.
	+ This field is optional but helps our team track the shipment.

- Enter the weight of the shipment:
	+ Provide the total weight of the shipment in kilograms or pounds.
	+ This field is mandatory.

- Select the size of the trailer:
	+ Choose from options:
		+ 48 ft
		+ 53 ft
		+ 63 ft
	+ This field is mandatory.

- Enter any additional details about the shipment:
	+ Provide as much context as possible without exceeding the character limit.
	+ This field is optional.

- Enter any additional information:
	+ Provide any other details that might be helpful for our team.
	+ This field is optional.

- Select the capacity of the trailer:
	+ Choose from options:
		+ 20 tons
		+ 40 tons
		+ 50 tons
	+ This field is mandatory.

- Enter the value of the shipment:
	+ Provide the monetary value of the shipment.
	+ This field is mandatory.

- Select the shipment terms:
	+ Choose from options:
		+ FTL
		+ LTL
		+ TL
	+ This field is mandatory.

- Select the type of broker:
	+ Choose from options:
		+ Carrier
		+ Broker
	+ This field is optional.

- Select the status of the shipment:
	+ Choose from options:
		+ Available
		+ Scheduled
		+ Delivered
	+ This field is mandatory.

- Enter any notes about the shipment:
	+ Provide any relevant comments or updates about the shipment.
	+ This field is optional.

- Enter any notes about the trailer:
	+ Provide any relevant comments or updates about the trailer.
	+ This field is optional.

- Enter any contact information for the carrier:
	+ Provide the carrier's name, phone number, and any other relevant details.
	+ This field is optional.

- Enter image URLs for the shipment:
	+ Provide one or multiple image URLs as attachments.
	+ This field is optional.

Please fill out the form carefully to ensure accurate and timely trailer dispatch. If you need help or clarification about any field, do not hesitate to reach out to our team.
