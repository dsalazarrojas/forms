# Baggage Drop Off Time Confirmation Form - Help Guide
## Purpose
This form is used to collect and confirm the details of a traveler's baggage drop-off for transportation purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields with accurate and up-to-date information about the traveler and their baggage.
2. Review each field carefully to ensure that you are providing the correct information.
3. Select the correct options for each field as instructed.
4. Submit the form once you have confirmed the accuracy of the information provided.

## Field-by-Field Explanation
* **Full Name** (`traveler_name`, text, required): Enter the full name of the traveler as it appears on their identification.
* **Confirmation/Booking Number** (`confirmation_number`, text, required): Enter the confirmation or booking number associated with the traveler's reservation.
* **Email Address** (`email_address`, email, required): Enter the email address of the traveler.
* **Phone Number** (`phone_number`, phone, required): Enter the phone number of the traveler.
* **Flight Number** (`flight_number`, text, required): Enter the flight number for which the baggage is being dropped off.
* **Departure Date** (`departure_date`, date, required): Enter the date of the flight departure.
* **Scheduled Departure Time** (`departure_time`, time, required): Enter the scheduled time of the flight departure.
* **Departure Airport Code** (`origin_airport`, text, required): Enter the airport code from which the traveler is departing.
* **Destination Airport Code** (`destination_airport`, text, required): Enter the airport code to which the traveler is traveling.
* **Airline Name** (`airline_name`, text, required): Enter the name of the airline operating the flight.
* **Number of Baggage Pieces** (`num_pieces`, integer, required): Enter the number of baggage pieces being dropped off.
* **Baggage Description** (`baggage_description`, text, required): Describe each piece of baggage, including type and color.
* **Total Weight (in pounds)** (`total_weight`, decimal, optional): If applicable, enter the total weight of the baggage.
* **Baggage Tag Numbers (if available)** (`baggage_tags`, text, optional): If available, enter the baggage tag numbers.
* **Requested Drop-Off Date** (`dropoff_date`, date, required): Enter the date on which the baggage is to be dropped off.
* **Requested Drop-Off Time** (`dropoff_time`, time, required): Enter the time on which the baggage is to be dropped off.
* **Drop-Off Location/Counter** (`dropoff_location`, text, required): Enter the location or counter where the baggage is to be dropped off.
* **Full Drop-Off Address** (`dropoff_address`, text, required): Enter the full address of the drop-off location.
* **Special Requests or Handling Instructions** (`special_requests`, text, optional): If applicable, enter any special requests or handling instructions for the baggage.
* **I Confirm the Above Information is Accurate** (`confirmation_agreement`, select_one, required): Select "I Confirm" to confirm that the information provided is accurate.
* **Drop-Off Time Confirmation Submitted** (`submit_confirmation`, select_one, required): Select "Confirmed" to submit the drop-off time confirmation.
