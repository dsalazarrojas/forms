# drivers_needed - Help Guide
## Purpose
The purpose of this form is to collect information from drivers, including their name, contact information, and details about their availability and transportation preferences. This form is used to request transportation services and gather necessary data for coordination.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill in the driver's name in the "Driver Name" field.
*   Enter the driver's email address in the "Email" field.
*   Specify the driver's phone number in the "Phone" field.
*   Enter the number of hours the driver is available to work in the "Hours Worked" field.
*   Select the number of available hours the driver is available to work in the "Available Hours" field.
*   Choose the preferred transportation type from the "Transportation Type" options (Taxi, Uber, or Lyft).
*   Select the assigned tool from the "Assigned Tool" options (chatjimmy, chatSue, or chatJen).
*   Add any additional description or details in the "Description" field.
*   Include any extra comments or notes in the "Notes" field.
*   Finally, categorize the request under "Transportation Request Forms" or "Other".

## Field-by-Field Explanation
*   **Driver Name** (`driver_name`, text, required/optional): Please fill in the driver's name.
*   **Email** (`email`, email, required/optional): Enter the driver's email address.
*   **Phone** (`phone`, text, required/optional): Specify the driver's phone number.
*   **Hours Worked** (`hours_worked`, number, required/optional): Enter the number of hours the driver is available to work.
*   **Available Hours** (`available_hours`, number, required/optional): Select the number of available hours the driver has.
*   **Transportation Type** (`transportation_type`, select_one, required/optional): Choose the preferred transportation type (Taxi, Uber, or Lyft).
*   **Assigned Tool** (`assigned_tool`, select_one, required/optional): Select the assigned tool (chatjimmy, chatSue, or chatJen).
*   **Description** (`description`, note, required/optional): Add any additional description or details about the driver or request.
*   **Notes** (`notes`, note, required/optional): Include any extra comments or notes about the driver or request.
*   **Category** (`category`, select_one, required/optional): Categorize the request under "Transportation Request Forms" or "Other".
