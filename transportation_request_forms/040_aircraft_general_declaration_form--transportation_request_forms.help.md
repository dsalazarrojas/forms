# Aircraft General Declaration Form - Help Guide
## Purpose
This form is used to collect information about an aircraft's flight details, crew, and cargo. It is designed for airlines, airports, or other organizations handling air travel or cargo.

## How To Complete This Form

1. Please fill out the form with the required information.
2. Ensure that all fields are accurate and complete.
3. Select the correct options for select fields.
4. Sign and date fields that require signatures.

## Field-by-Field Explanation

* **Flight Date** (`id: 1`): Enter the date of the flight.
* **Flight Number** (`id: 2`): Enter the flight identifier.
* **Aircraft Registration** (`id: 3`): Enter the tail number of the aircraft.
* **Aircraft Type** (`id: 4`): Enter the make and model of the aircraft.
* **Operator Name** (`id: 5`): Enter the name of the airline or operator.
* **Operator Address** (`id: 6`): Enter the business address of the operator.
* **Departure Airport** (`id: 7`): Enter the airport code of the departure airport.
* **Departure Time (UTC)** (`id: 8`): Enter the off-block time of departure.
* **Arrival Airport** (`id: 9`): Enter the airport code of the arrival airport.
* **Arrival Time (UTC)** (`id: 10`): Enter the on-block time of arrival.
* **Commander Name** (`id: 11`): Enter the name of the pilot in command.
* **Commander Nationality** (`id: 12`): Enter the nationality of the commander.
* **Commander License Number** (`id: 13`): Enter the pilot license number.
* **Crew Count** (`id: 14`): Enter the total number of crew members.
* **Passenger Count** (`id: 15`): Enter the total number of passengers.
* **Total Persons On Board** (`id: 16`): Enter the total number of crew and passengers.
* **Cargo Description** (`id: 17`): Enter a general description of the cargo (optional).
* **Cargo Weight (kg)** (`id: 18`): Enter the total cargo weight (optional).
* **Mail On Board** (`id: 19`): Select 'True' if mail is being carried, 'False' otherwise.
* **Dangerous Goods** (`id: 20`): Select 'True' if dangerous goods are on board, 'False' otherwise.
* **Dangerous Goods Details** (`id: 21`): Enter a description of the dangerous goods if selected as 'True'.
* **Aircraft Certificate of Registration** (`id: 22`): Select 'True' if the certificate is on board, 'False' otherwise.
* **Airworthiness Certificate** (`id: 23`): Select 'True' if the certificate is on board, 'False' otherwise.
* **Insurance Certificate** (`id: 24`): Select 'True' if the certificate is on board, 'False' otherwise.
* **Crew Licenses** (`id: 25`): Select 'True' if crew licenses are on board, 'False' otherwise.
* **Journey Log Book** (`id: 26`): Select 'True' if the log book is on board, 'False' otherwise.
* **Health Documents** (`id: 27`): Select 'True' if health documents are on board, 'False' otherwise.
* **Vaccination Certificates** (`id: 28`): Select 'True' if certificates are on board, 'False' otherwise.
* **Passenger Manifest** (`id: 29`): Select 'True' if the manifest is attached, 'False' otherwise.
* **Crew Manifest** (`id: 30`): Select 'True' if the manifest is attached, 'False' otherwise.
* **Aircraft Stores** (`id: 31`): Enter a description of duty-free and bonded stores (optional).
* **Currency On Board** (`id: 32`): Enter the amount of currency on board (optional).
* **Purpose of Flight** (`id: 33`): Select the reason for the flight (scheduled passenger, charter, cargo, private, medical, government, or other).
* **Remarks** (`id: 34`): Enter any additional information.
* **Commander Signature** (`id: 35`): Sign and date the form with the commander's signature.
* **Signature Date** (`id: 36`): Date of signing.
* **Authorized Officer Name** (`id: 37`): Enter the name of the immigration or customs officer (optional).
* **Officer Signature** (`id: 38`): Enter the official stamp or signature of the officer.

Note: Ensure that all fields are accurate and complete before submitting the form.
