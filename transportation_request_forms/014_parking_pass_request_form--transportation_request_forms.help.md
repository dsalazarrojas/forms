# Parking Pass Request Form - Help Guide
## Purpose
This form is used to request a parking pass for parking-related activities.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the fields below to submit your parking pass request.
2. Provide your name, the reason for the request, and the expected start and end dates.
3. If necessary, assign a tool or user to handle the request.
4. Add any additional comments.
5. Enter your email and phone number (optional).

## Field-by-Field Explanation
* **Parking Pass Name** (parking_pass_request_form): Enter the name you want to use for your parking pass.
* **Reason for the pass** (reason): Explain the purpose or reason for requesting a parking pass.
* **Expected start** (expected_start): Enter the date when you expect to use the parking pass to start.
* **Expected end** (expected_end): Enter the date when you expect to use the parking pass to end.
* **Assigned Tool** (assigned_tool): Select the tool you want to be assigned to handle your request (e.g. "chatjimmy").
* **Assigned User** (assigned_user): Select whether you want to assign a user to handle your request (e.g. "Yes" or "No").
* **Comments** (comments): Add any additional comments or information about your request.
* **Email** (email): Enter your email address (optional).
* **Phone** (phone): Enter your phone number (optional).

## Tips
* Please make sure to fill in all required fields (name, reason, expected start, and expected end).
* Use the assigned fields to assign a tool or user as needed.
* You can add comments to provide more information about your request.
* Use your email and phone number to help the requester contact you.
* If you're unsure about any field, ask a supervisor or colleague for assistance.
