# Delivery Service Ticket - Help Guide
## Purpose
The purpose of this form is to create a delivery service ticket that can be used to schedule and manage deliveries.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Pickup Location field with the address or description of the pickup location.
2. Enter the Drop off Location in the corresponding field.
3. Select the Delivery Date from the calendar or enter it manually.
4. Enter the Delivery Time in the time field.
5. If necessary, specify the Pickup Time Window for a more precise delivery time.
6. Provide any additional contact information for the delivery contact in the Delivery Contact field.

## Field-by-Field Explanation
* **Pickup Location** (`pickup_location`, text, required: false): Enter the address or description of the location where the delivery will be picked up.
* **Drop off Location** (`dropoff_location`, text, required: false): Enter the address or description of the location where the delivery will be dropped off.
* **Delivery Date** (`delivery_date`, date, required: false): Select the date for the delivery from the calendar or enter it manually.
* **Delivery Time** (`delivery_time`, time, required: false): Enter the time for the delivery.
* **Pickup Time Window** (`pickup_time_window`, time, required: false): If necessary, specify the time window for pickup.
* **Delivery Contact** (`delivery_contact`, text, required: false): Provide any additional contact information for the delivery contact.

## Tips
* Make sure to fill in all the required fields for accurate delivery planning.
* Double-check the information you enter to ensure it is correct.
* If you need to make any changes, you can always come back and update your delivery service ticket.
