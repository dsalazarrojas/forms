# Summer Camp Return Transportation Signup Form - Help Guide
## Purpose
This form is used to collect information about summer camp return transportation needs and preferences.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter your name in the "Form Title" field.
2. Select a category for your transportation request in the "Category" field.
3. Provide a brief description of your transportation needs in the "Description" field.
4. Indicate the tool assigned to you for this task in the "Assigned Tool" field.
5. Enter your form ID in the "Form ID" field.
6. Specify the output file format and name in the "Output File" fields.
7. Select any additional tools assigned to you for this task in the "Form Assigned Tool 2" field.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, required): Enter a brief title for your transportation request.
* **Category** (`summer_camp_return_transportation_signup_form_category`, text, required): Select a category for your transportation request.
* **Description** (`form_description`, text, required): Provide a brief description of your transportation needs.
* **Transportation Request Forms** (`form_transportation_request_forms`, text, required): This field is not currently used. Please ignore it.
* **Form Transportation Request Forms Category** (`form_transportation_request_forms_category`, text, required): This field is not currently used. Please ignore it.
* **Form Transportation Request Forms Description** (`form_transportation_request_forms_description`, text, required): This field is not currently used. Please ignore it.
* **Assigned Tool** (`form_assigned_tool`, select_one, required): Select the tool assigned to you for this task. Options include "chatjimmy" and "Other".
* **Form ID** (`form_form_id`, number, required): Enter your unique form ID.
* **Output File** (`form_output_file`, text, required): Specify the format and name of the output file.
* **Output File Name** (`form_output_file_name`, text, required): Enter the name of the output file.
* **Output File Ext** (`form_output_file_ext`, text, required): Enter the file extension for the output file.
* **Form Assigned Tool 2** (`form_assigned_tool_2`, select_multiple, required): Select any additional tools assigned to you for this task. Options include "chatjimmy" and "jimmy".
* **This form template can be opened via the standard direct link or embed it on any webpage** (`summer_camp_return_transportation_signup_form_description`, text, required): This field is a description of the form template itself and is not used in the transportation request process. Please ignore it.
* **Transportation Request Forms** (`form_transportation_request_forms`, text, required): This field is not currently used. Please ignore it.
