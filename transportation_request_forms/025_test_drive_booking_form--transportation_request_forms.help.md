# test_drive_booking_form - Help Guide
## Purpose
The test_drive_booking_form is used to manage test drives for customers. It collects information about customers, test drive details, and status updates to facilitate coordination and communication between sales teams and customers.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the test drive date in the "Test Drive Date" field (id: 1).
2.  Provide the customer's name in the "Customer Name" field (id: 2).
3.  Enter the customer's phone number in the "Customer Phone" field (id: 4).
4.  Enter the customer's email address in the "Customer Email" field (id: 5).
5.  Select the test drive duration in the "Test Drive Duration" field (id: 6).
6.  Enter the test drive time in the "Test Drive Time" field (id: 7).
7.  Select the test drive status from the available options in the "Test Drive Status" field (id: 9).
8.  Assign the test drive to a team member from the available options in the "Assigned To" field (id: 10).
9.  Enter any test drive notes in the "Test Drive Notes" field (id: 11).
10.  Select the people to report to for the test drive in the "Reported To" field (id: 12).
11.  Enter a customer message in the "Customer Message" field (id: 13).
12.  Select the new test drive status from the available options in the "Test Drive Status Change" field (id: 14).
13.  Enter a note for the test drive status change in the "Test Drive Status Change Note" field (id: 15).
14.  Select a tool or resource to be assigned to for the test drive in the "Assigned Tool" field (id: 16).
15.  Enter a test drive booking confirmation in the "Test Drive Booking Confirmation" field (id: 17).
16.  Enter a test drive booking notification in the "Test Drive Booking Notification" field (id: 18).
17.  Enter any additional test drive booking notes in the "Test Drive Booking Note" field (id: 19).
18.  Enter the customer's signature in the "Customer Signature" field (id: 20).
19.  Enter any test drive status updates in the "Test Drive Status Update" field (id: 21).
20.  Enter any test drive update notes in the "Test Drive Update Note" field (id: 22).
21.  Enter a test drive revocation reason in the "Test Drive Revoke" field (id: 23).
22.  Enter a note for the test drive revocation in the "Customer Revoke Note" field (id: 24).
23.  Enter a test drive revocation note in the "Test Drive Revoke Note" field (id: 25).

## Field-by-Field Explanation

*   **Test Drive Date (id: 1)**: Enter the date of the test drive.
*   **Customer Name (id: 2)**: Enter the customer's name.
*   **Customer Phone (id: 4)**: Enter the customer's phone number.
*   **Customer Email (id: 5)**: Enter the customer's email address.
*   **Test Drive Duration (id: 6)**: Select the test drive duration.
*   **Test Drive Time (id: 7)**: Enter the test drive time.
*   **Test Drive Status (id: 9)**: Select the current test drive status.
*   **Assigned To (id: 10)**: Select a team member to assign to the test drive.
*   **Test Drive Notes (id: 11)**: Enter any additional notes about the test drive.
*   **Reported To (id: 12)**: Select the people to report to for the test drive.
*   **Customer Message (id: 13)**: Enter a message to be sent to the customer.
*   **Test Drive Status Change (id: 14)**: Select the new test drive status.
*   **Test Drive Status Change Note (id: 15)**: Enter a note for the test drive status change.
*   **Assigned Tool (id: 16)**: Select the tool or resource to be assigned to the test drive.
*   **Test Drive Booking Confirmation (id: 17)**: Enter a test drive booking confirmation message.
*   **Test Drive Booking Notification (id: 18)**: Enter a test drive booking notification message.
*   **Test Drive Booking Note (id: 19)**: Enter any additional test drive booking notes.
*   **Customer Signature (id: 20)**: Enter the customer's signature.
*   **Test Drive Status Update (id: 21)**: Enter any test drive status updates.
*   **Test Drive Update Note (id: 22)**: Enter any test drive update notes.
*   **Test Drive Revoke (id: 23)**: Enter a test drive revocation reason.
*   **Customer Revoke Note (id: 24)**: Enter a note for the test drive revocation.
*   **Test Drive Revoke Note (id: 25)**: Enter a note for the test drive revocation.

## Tips

*   Make sure to fill in all required fields accurately and thoroughly.
*   Double-check the test drive status and assignee to ensure correct coordination and assignment.
*   Use the test drive notes and status updates to maintain clear communication and understanding with customers and team members.
*   Enter customer signatures and messages to keep customers informed and engaged throughout the process.
*   Review and update test drive status and notes regularly to reflect changes and progress.
