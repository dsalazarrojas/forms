# okm_form - Help Guide
## Purpose
The okm_form is a transportation request form designed to collect information from users who are requesting transportation-related services. It aims to provide a standardized and structured way to gather the necessary details about the user's request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title for your request in the "okm form" field.
2. Select the category of transportation you are requesting from the "category" dropdown menu.
3. Provide a detailed description of the service you are requesting in the "description" field.
4. If applicable, select the tool assigned to fulfill your request from the "assigned tool" dropdown menu.
5. Optionally, provide additional information or notes for the tool assigned in the "tool hint" field.

## Field-by-Field Explanation
### okm form
* **okm form (Title)** (`form_title`, text, optional): A brief title for your request. This will help us identify your service request.
* **category** (`form_category`, select_one, optional): Choose the category of transportation you are requesting. Please select from the options provided: "transportation request forms" or "other categories".
* **description** (`form_description`, text, optional): A detailed description of the service you are requesting. Try to be as specific as possible so we can better understand your needs.
* **assigned tool** (`form_assigned_tool`, select_one, optional): If a tool has been assigned to you, please select it from the options provided.
* **tool hint** (`form_assigned_tool_hint`, text, optional): If you need to provide additional information for the tool assigned, please enter it here.

## Tips
- Please provide as much detail as possible in the description field to help us better understand your request.
- Selecting a tool and providing a tool hint can help us tailor our response to your specific needs.
- If you need assistance with something not covered by the "transportation request forms" category, please select "other categories".
