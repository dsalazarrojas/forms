# Transport Rental Referral Form - Help Guide
## Purpose
The Transport Rental Referral Form is designed to collect information from users who are interested in renting a vehicle for a specific period.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your First name, Last name, and Company (if applicable).
2. Enter your Email address, Phone number, and select the Transport type that you are interested in renting.
3. Enter Trip details, if applicable.
4. Select the Assigned tools that you are interested in using.
5. Fill in Date and Time for your rental period.
6. Provide a Description of your rental purpose.
7. If you want to save the output file for your records, enter a name for the Output file.
8. Select the Category for your rental request.
9. Confirm if you are interested in the Transport rental referral form - Transportation request forms.
10. Confirm if you are interested in the Assigned tool 2.
11. Confirm if you are interested in the Category 2.
12. Fill in Description 2, if applicable.
13. Confirm if you are interested in the Transport rental referral form - Transportation request forms 2.
14. Confirm if you are interested in the Assigned tool 3.
15. Confirm if you are interested in the Category 3.
16. Fill in Description 3, if applicable.
17. Confirm if you are interested in the Transport rental referral form - Transportation request forms 3.

## Field-by-Field Explanation

* **First Name** (`first_name`, `text`, **required**): Enter your first name.
* **Last Name** (`last_name`, `text`, **required**): Enter your last name.
* **Company** (`company`, `text`, **optional**): If you are representing a company, enter the name of the company.
* **Email** (`email`, `email`, **required**): Enter your email address.
* **Phone** (`phone`, `text`, **required**): Enter your phone number.
* **Transport Type** (`transport_type`, `select_one`, **required**): Select the type of transport you are interested in renting (e.g., Bus, Car, Train, Bike, Boat).
* **Trip Details** (`trip_details`, `note`, **optional**): If you are planning a specific trip, describe the details of your trip.
* **Assigned Tools** (`assigned_tool`, `select_multiple`, **optional**): Select any tools that you are interested in using for your rental.
* **Date** (`date`, `date`, **required**): Enter the date for your rental period.
* **Time** (`time`, `time`, **required**): Enter the time for your rental period.
* **Description** (`description`, `text`, **required**): Provide a brief description of your rental purpose.
* **Output File** (`output_file`, `text`, **optional**): If you want to save the output file for your records, enter a name for the file.
* **Category** (`category`, `select_one`, **required**): Select the category for your rental request (e.g., Transportation Request Forms).
* **Transport Rental Referral Form - Transportation Request Forms** (`transport_rental_referral_form_transportation_request_forms`, `select_multiple`, **optional**): Confirm if you are interested in this form.
* **Assigned Tool 2** (`assigned_tool_2`, `select_one`, **optional**): Confirm if you are interested in this tool.
* **Category 2** (`category_2`, `select_one`, **optional**): Confirm if you are interested in this category.
* **Description 2** (`description_2`, `text`, **optional**): If you are interested in this category, provide a description.
* **Transport Rental Referral Form - Transportation Request Forms 2** (`transport_rental_referral_form_transportation_request_forms_2`, `select_multiple`, **optional**): Confirm if you are interested in this form.
* **Assigned Tool 3** (`assigned_tool_3`, `select_one`, **optional**): Confirm if you are interested in this tool.
* **Category 3** (`category_3`, `select_one`, **optional**): Confirm if you are interested in this category.
* **Description 3** (`description_3`, `text`, **optional**): If you are interested in this category, provide a description.
* **Transport Rental Referral Form - Transportation Request Forms 3** (`transport_rental_referral_form_transportation_request_forms_3`, `select_multiple`, **optional**): Confirm if you are interested in this form.

**Tips:**

* Ensure that all required fields are filled before submitting the form.
* Double-check your selections, especially for transport type and category.
* Use clear and concise descriptions for your rental purpose and category.
* If you have any issues or questions, please contact our support team.
