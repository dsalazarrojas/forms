# Hospice Spiritual Assessment Form - Help Guide
## Purpose

The Hospice Spiritual Assessment Form is designed to help healthcare providers assess a patient's spiritual needs and experiences. This form is part of the hospice care process, which aims to provide comfort, relief, and support to patients and their families during the end-of-life care period.

## How To Complete This Form

1. Please fill out the form for patients who are receiving or have received hospice care.
2. Answer all the questions accurately and completely.
3. Use the options provided as a guide, but feel free to add any additional information in the notes section if necessary.

## Field-by-Field Explanation

* **Patient Information (1)** (`patient_info`, `text`, required): Please provide the patient's name, date of birth, and any other relevant medical or personal information.
* **Spiritual Values (2)** (`spiritual_values`, `select_one`, required): This question asks whether the patient's spiritual values are important to them. Please select 'Yes' if the patient's spiritual values are important to them, and 'No' otherwise.
* **Spiritual Support (3)** (`spiritual_support`, `select_multiple`, optional): Please select all the ways in which the patient would like to receive spiritual support, such as prayer, meditation, or counseling.
* **Religious Practices (4)** (`religious_practices`, `select_multiple`, optional): Please select all the religious practices the patient would like to continue or practice, such as prayer, worship, or rituals.
* **Spiritual Therapy (5)** (`spiritual_therapy`, `note`, optional): This is a space for healthcare providers to note any spiritual therapy or counseling they have provided to the patient.
* **Pastoral Therapy (6)** (`pastoral_therapy`, `note`, optional): This is a space for healthcare providers to note any pastoral therapy or counseling they have provided to the patient.
* **Patient Fears (7)** (`patient_fears`, `select_multiple`, optional): Please select all the patient's fears or concerns, such as fear of death, fear of pain, or fear of the unknown.
* **Coping Mechanism (8)** (`coping_mechanism`, `select_multiple`, optional): Please select all the coping mechanisms the patient uses, such as meditation, prayer, or deep breathing.
* **Spiritual Values Important (9)** (`spiritual_values_important`, `number`, optional): Please rate how important the patient's spiritual values are to them, on a scale of 1-10.
* **Spiritual Values Current (10)** (`spiritual_values_current`, `number`, optional): Please rate how important the patient's current spiritual values are to them, on a scale of 1-10.
* **Hospice Spiritual Clinic (11)** (`hospice_spiritual_clinic`, `select_multiple`, optional): Please select all the spiritual clinic services the patient would like to receive, such as individual therapy, group therapy, or spiritual direction.
* **Spiritual Status (12)** (`spiritual_status`, `select_one`, optional): This question asks about the patient's spiritual status, please select 'Active' if the patient is actively practicing their spirituality, and 'Inactive' otherwise.
* **Spiritual Care (13)** (`spiritual_care`, `select_multiple`, optional): Please select all the spiritual care services the patient would like to receive, such as chaplaincy services, spiritual direction, or counseling.
* **Spiritual Assessment Date (14)** (`spiritual_assessment_date`, `date`, optional): Please enter the date of the spiritual assessment.
* **Spiritual Assessment Time (15)** (`spiritual_assessment_time`, `time`, optional): Please enter the time of the spiritual assessment.
* **Pastoral Counseling Referral (16)** (`pastoral_counseling_referral`, `select_multiple`, optional): Please select all the pastoral counseling referrals the patient would like to receive.
* **Hospice Spiritual Referral (17)** (`hospice_spiritual_referral`, `select_multiple`, optional): Please select all the hospice spiritual referrals the patient would like to receive.
* **Hospice Spiritual Referral Note (18)** (`hospice_spiritual_referral_note`, `note`, optional): This is a space for healthcare providers to note any hospice spiritual referrals they have provided to the patient.
* **Pastoral Referral Note (19)** (`pastoral_referral_note`, `note`, optional): This is a space for healthcare providers to note any pastoral referrals they have provided to the patient.
* **Other Spiritual Referral (20)** (`other_spiritual_referral`, `select_multiple`, optional): Please select all the other spiritual referrals the patient would like to receive.
* **Other Spiritual Referral Note (21)** (`other_referral_note`, `note`, optional): This is a space for healthcare providers to note any other spiritual referrals they have provided to the patient.
* **Patient Spiritual Referral (22)** (`patient_spiritual_referral`, `select_multiple`, optional): Please select all the spiritual referrals the patient would like to receive from other healthcare providers.
* **Patient Spiritual Referral Note (23)** (`patient_spiritual_referral_note`, `note`, optional): This is a space for healthcare providers to note any spiritual referrals they have provided to the patient.
* **Other Referral Source (24)** (`other_referral_source`, `select_multiple`, optional): Please select all the referral sources the patient would like to receive referrals from, such as a hospital or community organization.
* **Other Referral Source Note (25)** (`other_referral_source_note`, `note`, optional): This is a space for healthcare providers to note any other referral sources they have provided to the patient.

Please note that the form should only be completed by healthcare providers who are familiar with the patient's care and medical history. If you are unsure about any of the questions or options, please consult with a healthcare provider.
