# Work Hours Complaint Form - Help Guide
## Purpose
The Work Hours Complaint Form is a formal channel for employees to report issues related to their work hours. This form should be used to report concerns or complaints about scheduling conflicts, time-tracking discrepancies, or other work hours-related problems.
## How To Complete This Form
To complete this form, please follow these steps:
- Select whether you have experienced a work hours issue or not.
- Describe the issue in the text field provided.
- Select the date you first noticed the issue.
- Select the time of day the issue occurred.
## Field-by-Field Explanation
### 1. **Work Hours Form** (`Work Hours Form`, select_multiple, optional)
This field allows you to report whether you have experienced a work hours issue or not. Please select the option that best describes your situation.
*   If you have experienced a work hours issue, select "Yes".
*   If you have not experienced a work hours issue, select "No".

### 2. **Issue Description** (`Issue Description`, text, optional)
Please describe the issue you experienced in as much detail as possible. This will help us understand the context and provide a resolution.

### 3. **Complaint Date** (`Complaint Date`, date, optional)
This field is used to select the date you first noticed the issue. Please use the date picker to choose the correct date.

### 4. **Complaint Time** (`Complaint Time`, time, optional)
This field is used to select the time of day the issue occurred. Please use the 24-hour clock format to choose the correct time.
## Tips
*   Please be as detailed and objective as possible when describing the issue.
*   Use the date and time fields to provide context for the issue.
*   If you are unsure about how to fill out this form, please contact your HR representative or supervisor for guidance.
