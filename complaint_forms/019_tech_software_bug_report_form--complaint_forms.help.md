# Tech Software Bug Report Form - Help Guide
## Purpose
This form is designed to gather information about bugs or issues with our tech software applications, allowing us to quickly identify and address problems.

## How To Complete This Form
To submit a bug report, simply fill in the required fields as follows:

*   Provide a brief description of the issue in the **Bug Details** field (id: 2).
*   Specify the **Software Version** used at the time of the issue (id: 3).
*   Indicate the **Operating System** on which you encountered the issue (id: 4).
*   Mention the **Browser** you were using (id: 5).
*   Categorize the issue as a **Bug**, **Feature Request**, or **Feedback** (id: 6).
*   Set the **Report Priority** level as **Bug**, **Critical**, **High**, **Low**, or **Medium** (id: 7).
*   Select the current **Report Status** as **In Progress**, **Resolved**, **Waiting for Response**, **Waiting for Feedback**, **Duplicate**, or **Closed** (id: 8).
*   If you have a file or attachment that can help us reproduce the issue, upload it using the **Report Attachment** field (id: 17).
*   Optionally, provide any additional information in the **Report Additional Info** field (id: 14).
*   If you have further comments, use the **Submitter Comment** field (id: 15).
*   If you're reporting on someone else's behalf, please fill in the **Submitter Name** field (id: 16).
*   Enter your **Submitter Email** and **Submitter Phone** (id: 10 and id: 11).
*   If you're reporting from a company, please enter your **Submitter Company** (id: 23).
*   If you're reporting from your workplace, please enter your **Submitter Job Title** (id: 24).

## Field-by-Field Explanation
*   **Bug Details** (id: 2): A brief description of the issue you encountered.
*   **Software Version** (id: 3): The version of the software you were using at the time of the issue.
*   **Operating System** (id: 4): The operating system on which you encountered the issue.
*   **Browser** (id: 5): The browser you were using when the issue occurred.
*   **Report Type** (id: 6): Categorize the issue as a bug, feature request, or feedback.
*   **Report Priority** (id: 7): Set the priority level of the report as Bug, Critical, High, Low, Medium.
*   **Report Status** (id: 8): Current status of the report, such as In Progress, Resolved, Waiting for Response, etc.
*   **Submitter** (id: 9): A brief description of who reported the issue (you or someone else).
*   **Submitter Email** (id: 10): Enter your email address for follow-up communication.
*   **Submitter Phone** (id: 11): Enter your phone number for follow-up communication.
*   **Description** (id: 12): A detailed description of the issue.
*   **Report Steps to Reproduce** (id: 13): A step-by-step guide on how to reproduce the issue.
*   **Report Additional Info** (id: 14): Any additional information about the issue.
*   **Submitter Comment** (id: 15): Further comments or questions from the submitter.
*   **Submitter Name** (id: 16): Enter the name of the person reporting the issue.
*   **Report Attachment** (id: 17): Upload any file or attachment that helps us reproduce the issue.
*   **Report Attachment Name** (id: 18): Enter a brief description of the attached file.
*   **Submitter Location** (id: 19): Location where you encountered the issue.
*   **Submitter Department** (id: 20): The department or team you're reporting from.
*   **Report Reproduction Steps** (id: 21): Further details on how to reproduce the issue.
*   **Report Reproduction Environment** (id: 22): Environment where you encountered the issue.
*   **Submitter Company** (id: 23): The company you're reporting from.
*   **Submitter Job Title** (id: 24): Enter your job title.
*   **Report Reproduction Steps** (id: 21 and id: 22): These fields can be skipped if not applicable. 

Note: Fields with id 25 are duplicates of fields with id 24 and can be removed.
