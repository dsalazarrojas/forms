This guide is intended for users who want to submit complaints on a forum. To ensure that the form is filled out correctly and not duplicated, we first check if there are any existing open complaints for the same issue. If there are no open complaints, we then check if the issue is already resolved. 

# Forum Complaint Form - Help Guide
## Purpose
This form is used to submit complaints about issues encountered on the forum. Please fill out this form completely to ensure that your issue is properly documented and can be addressed by moderators.

## How To Complete This Form
1. Fill out the `Complaint Details` section, describing the issue in as much detail as possible.
2. Select the `Complainant Details` section to choose how you want to report the issue (e.g. as a user, as a moderator, etc.).
3. In the `Moderators Notes` section, add any additional information that moderators may find helpful in resolving the issue.
4. Choose the current `Status` of the issue from the dropdown menu (e.g. Open, Closed, In Progress).
5. If the issue has already been resolved, fill out the `Resolved Date` field with the date of resolution.

## Field-by-Field Explanation
* **Complaint Details**: `complaint_details`
	+ (Text, Required): Please provide a detailed description of the issue you are experiencing.
* **Complainant Details**: `complainant_details`
	+ (Select Multiple, Optional): Who are you reporting the issue as? (e.g. User, Moderator, etc.)
* **Moderators Notes**: `moderators_notes`
	+ (Note, Optional): Provide any additional information that moderators may find helpful in resolving the issue.
* **Status**: `complaint_status`
	+ (Select One, Optional): Choose the current status of the issue (e.g. Open, Closed, In Progress).
* **Resolved Date**: `resolved_date`
	+ (Date, Optional): If the issue has already been resolved, fill out the date of resolution.

## Tips
* Please ensure that you fill out all required fields to ensure that your issue is properly documented.
* If you are unsure about how to fill out any of the fields, feel free to ask a moderator for assistance.
* If there is already an existing open complaint about the same issue, please do not submit a duplicate complaint.
