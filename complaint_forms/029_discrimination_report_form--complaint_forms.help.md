# Discrimination Report Form - Help Guide
## Purpose
The Discrimination Report Form is used to gather information about alleged discrimination incidents, which will be used to investigate and resolve the situation.

## How To Complete This Form
To fill out this form, follow these steps:

1. Choose a title for your report.
2. Select "Yes" or "No" to confirm that the incident was a discrimination case.
3. Provide a brief description of the incident.
4. Specify the date and time of the incident.
5. Enter the location of the incident.
6. If a witness was present, provide their name, email, and message.
7. Check if the witness has agreed to cooperate with the agency.
8. If an incident report was made, provide the report date and time.
9. Check if the incident report has agreed to cooperate with the agency.
10. Specify the reason for the incident report.
10. Provide a message with any additional information about the incident.

## Field-by-Field Explanation

* **Discrimination Report Form** (`form_title`): This is a title for your report.
* **Category** (`form_category`): Confirm that the incident was a discrimination case (Yes or No).
* **Description** (`form_description`): Provide a brief description of the incident.
* **Date of Incident** (`incident_date`): Enter the date of the incident.
* **Time of Incident** (`incident_time`): Enter the time of the incident.
* **Location of Incident** (`incident_location`): Enter the location of the incident.
* **Witness Name** (`witness_name`): If a witness was present, enter their name.
* **Witness Email** (`witness_email`): If a witness was present, enter their email address.
* **Witness Message** (`witness_message`): If a witness was present, provide a message from them.
* **Has the witness agreed to cooperate with the agency?** (`witness_agreed`): Check if the witness has agreed to cooperate with the agency.
* **Incident Report Form** (`incident_report`): If an incident report was made, provide the report.
* **Incident Report Date** (`incident_report_date`): If an incident report was made, enter the report date.
* **Incident Report Time** (`incident_report_time`): If an incident report was made, enter the report time.
* **Has the incident report agreed to cooperate with the agency?** (`incident_report_agreed`): Check if the incident report has agreed to cooperate with the agency.
* **Reason for Incident Report** (`incident_report_reason`): If an incident report was made, specify the reason for the report.
* **Incident Report Message** (`incident_report_message`): If an incident report was made, provide a message with any additional information about the incident.
* **Name** (`contact_name`): Enter your name.
* **Email** (`contact_email`): Enter your email address.
* **Phone** (`contact_phone`): Enter your phone number.
* **Message** (`contact_message`): Provide any additional message with your contact information.
* **Reporting Agency** (`reporting_agency`): Confirm if you are reporting to the agency (Yes or No).
* **Reason for Report** (`report_reason`): Specify the reason for your report.
* **Has the witness agreed to cooperate with the agency?** (`witness_agreed`): Check if the witness has agreed to cooperate with the agency.
