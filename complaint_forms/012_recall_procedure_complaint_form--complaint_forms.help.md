# Recall procedure complaint form - Help Guide
## Purpose
This form is designed to collect information about the recall procedure complaints. It's a tool for users to provide feedback and report issues related to a product or procedure. The goal is to help the relevant teams identify and address problems, ensuring the highest quality standards are maintained.

## How To Complete This Form
To complete this form, follow these steps:

1. Determine if you are experiencing a recall procedure issue and answer "Yes" or "No" to the first question.
2. If you answered "Yes", provide the name of the product related to the issue.
3. Describe the problem in detail in the issue description field.

## Field-by-Field Explanation
* **complaint_form** (Yes/No, required): 
  - This field asks if you have experienced a recall procedure issue.
  - Select "Yes" if you have had a problem, "No" otherwise.
* **product_name** (text, optional): 
  - If you have answered "Yes" to the first question, provide the name of the product that caused the issue.
  - This helps us understand which product is being reported.
* **issue_description** (text, optional): 
  - Describe the issue you experienced in as much detail as possible.
  - This is an opportunity for you to provide a clear account of the problem you encountered.

## Tips
* Please answer "Yes" only if you have had a genuine issue with a recall procedure.
* If you are unsure about the product name, try to provide the best description you can.
* Be as detailed as possible when describing the issue to help us understand and address the problem efficiently.
