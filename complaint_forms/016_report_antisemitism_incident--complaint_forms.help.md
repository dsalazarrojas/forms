# Report Antisemitism Incident - Help Guide
## Purpose
This form is designed to collect information about antisemitism incidents, ensuring that we address each incident effectively and efficiently.

## How To Complete This Form
To complete the form, follow these steps:

1. Provide a brief title and description of the incident.
2. Enter the victim's name and email address, if available.
3. Enter the victim's phone number, if available.
4. Specify the date and location of the incident.
5. Describe the incident in detail.
6. Select the type of report (e.g., hate crime, harassment, or other).
7. Indicate if a follow-up email has been sent to the victim.

## Field-by-Field Explanation

* **Incident report** (Optional): This is the main text field where you’ll provide a brief description of the incident.
* **Victim name** (Optional): Enter the name of the person affected by the incident, if available.
* **Email address** (Optional): Enter the email address of the victim, if available.
* **Phone number** (Optional): Enter the phone number of the victim, if available.
* **Date of the incident** (Optional): Enter the date of the incident in the format MM/DD/YYYY.
* **Incident location** (Optional): Describe the location where the incident occurred.
* **Description** (Optional): Provide a detailed description of the incident.
* **Report type** (Required): Select the type of report (e.g., hate crime, harassment, or other).
* **Follow up email sent** (Optional): Indicate if a follow-up email has been sent to the victim.

## Tips

* Please provide as much detail as possible about the incident.
* If the victim's information is not available, try to provide alternative contact methods.
* If you’re unsure about any of the information, please try to gather as much detail as possible.
* Ensure that the report is accurate and thorough.
