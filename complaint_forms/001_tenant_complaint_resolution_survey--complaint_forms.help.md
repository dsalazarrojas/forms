# Tenant Complaint Resolution Survey - Help Guide
## Purpose

The Tenant Complaint Resolution Survey is a form designed to capture and resolve tenant complaints related to their housing. This form is used to gather information about the complaint and provide a resolution status.

## How To Complete This Form

1. Review the form carefully before submitting.
2. Select "Yes" or "No" to indicate if the complaint has already been resolved.
3. If the complaint has already been resolved, you do not need to submit any additional information.
4. Select "Housing Rent", "Maintenance and Repairs", "Noise and Nuisance", "Lease and Agreement", or "Security and Safety" as the type of complaint.
5. Type a detailed description of the issue in the "Description" field.
6. Select "Yes" or "No" to indicate if the complaint will require further action (e.g., follow-up phone call, email).
7. Select the status of the resolution (Active or Inactive).
8. Add any comments from the tenant in the "Tenant Comments" field.
9. Add any comments from the Property Manager in the "Property Manager Comments" field.
10. If the resolution has been completed, select a date for the resolution.

## Field-by-Field Explanation

* **Complaint Form Questions**: This field is used to determine if the complaint has already been resolved. Select "Yes" if the complaint has been resolved. Select "No" otherwise.
* **Complaint Type**: This field asks for the type of complaint. Select one of the following:
	+ Housing Rent: Issues related to rent payment or rent amount.
	+ Maintenance and Repairs: Issues with maintenance or repairs in the property.
	+ Noise and Nuisance: Issues with excessive noise or disturbance in the property.
	+ Lease and Agreement: Issues with lease terms or agreement between tenant and property owner.
	+ Security and Safety: Issues with security or safety features in the property.
* **Description**: Type a detailed description of the issue, including any relevant dates or events.
* **Complaint Report Type**: This field is not clear in its intent. However, it is likely meant to determine if the complaint will require further action (e.g., follow-up phone call, email). Select "Yes" if further action is needed, "No" otherwise.
* **Resolution Status**: This field shows the status of the resolution. Select "Active" if the resolution is ongoing or has not been completed, "Inactive" if the resolution has been completed.
* **Tenant Comments**: Add any comments or additional information from the tenant.
* **Property Manager Comments**: Add any comments or additional information from the Property Manager.
* **Resolution Date**: If the resolution has been completed, select a date for the resolution.
