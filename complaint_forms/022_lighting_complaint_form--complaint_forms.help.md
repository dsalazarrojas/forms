# Lighting Complaint Form - Help Guide
## Purpose
The Lighting Complaint Form is used to document and track lighting-related issues.

## How To Complete This Form
- To complete this form, please fill out each field with the required information.
- Make sure to select the correct option for the "Issue Type" field, as this will help us better understand the type of lighting issue you are experiencing.
- If a tool was used to report the issue, please select "chatjimmy" in the "Assigned Tool" field.
- If the issue occurred in a specific location, please provide the address in the "Address" field.
- Enter your User ID and email to ensure we can contact you for further information.
- Make sure to enter a clear description of the issue in the "Description" field.

## Field-by-Field Explanation

* **User ID** (`number`, required): Enter your unique User ID assigned to you by our system.
* **Description** (`text`, required): Please provide a clear description of the issue, including any details you think would be helpful for us to understand the problem.
* **Address** (`select_one`, optional): Select the address where the issue occurred. 
* **Email** (`email`, required): Enter your email address so we can contact you for further information.
* **Phone** (`text`, required): Enter your phone number, so we can contact you if needed.
* **Report Date** (`date`, optional): Select the date when the issue occurred.
* **Assigned Tool** (`select_one`, optional): Select the tool used to report the issue. Please select "chatjimmy" if you used a chatjimmy tool.
* **Category** (`select_one`, optional): Select the category of the issue. Please select "Lighting" if the issue is related to lighting.
* **Location** (`text`, required): Enter the location of the issue, including any details about the room or area.
* **Issue Type** (`select_one`, required): Select the type of issue you are experiencing, either Brightness or Darkness.
* **Other** (`text`, optional): If you select "Other" in the "Assigned Tool" or "Category" field, please provide a brief explanation of your selection. 

## Tips
- Please ensure that you provide as much detail as possible about the issue.
- If you are unsure about any field, feel free to ask us for clarification.
- Please submit this form only once for each issue.
