# Transaction Issues Report - Help Guide

## Purpose
The Transaction Issues Report form is designed to collect information about problems or errors that have occurred during a transaction. This form helps the team to quickly identify and resolve issues related to transactions.

## How To Complete This Form
1. Start by selecting the category of the issue (e.g., "Yes" or "No") in the Category field.
2. Enter the date of the transaction that is related to the issue in the Transaction Date field.
3. Provide a brief description of the problem in the Description field.
4. Enter the amount of the transaction (if applicable) in the Transaction Amount field.
5. Select whether the transaction is active or inactive in the Transaction Status field.
6. Enter the name of the product or service related to the issue in the Product Name field (if applicable).
7. Select whether the transaction occurred (e.g., "Yes" or "No") in the Transaction Type field.
8. Enter any additional details about the transaction in the Transaction Details field.
9. Enter the contact information of the person or party involved in the issue in the Contact Info field.
10. Provide a brief resolution or outcome of the issue in the Resolution field (if applicable).
11. Select whether the issue was assigned to someone (e.g., "Yes" or "No") in the Assigned To field.
12. Select whether the issue was created by someone (e.g., "Yes" or "No") in the Created By field.

## Field-by-Field Explanation
* **Category** (`category`, `select_one`, required: false): Select the category of the issue to help the team understand the type of problem.
* **Transaction Date** (`transaction_date`, `date`, required: false): Enter the date of the transaction that is related to the issue.
* **Description** (`description`, `text`, required: false): Provide a brief description of the problem.
* **Transaction Amount** (`transaction_amount`, `number`, required: false): Enter the amount of the transaction (if applicable).
* **Transaction Status** (`transaction_status`, `select_one`, required: false): Select whether the transaction is active or inactive.
* **Product Name** (`product_name`, `text`, required: false): Enter the name of the product or service related to the issue (if applicable).
* **Transaction Type** (`transaction_type`, `select_one`, required: false): Select whether the transaction occurred (e.g., "Yes" or "No").
* **Transaction Details** (`transaction_details`, `text`, required: false): Enter any additional details about the transaction.
* **Contact Info** (`contact_info`, `text`, required: false): Enter the contact information of the person or party involved in the issue.
* **Resolution** (`resolution`, `note`, required: false): Provide a brief resolution or outcome of the issue (if applicable).
* **Assigned To** (`assigned_to`, `select_one`, required: false): Select whether the issue was assigned to someone (e.g., "Yes" or "No").
* **Created By** (`created_by`, `select_one`, required: false): Select whether the issue was created by someone (e.g., "Yes" or "No").

## Tips
- Be as descriptive as possible when filling out this form.
- If the issue is related to a specific product or service, make sure to enter the product name.
- If the transaction amount is relevant, be sure to enter it.
- If the transaction status is active or inactive, select the correct option.
- If you have any additional details about the transaction, enter them in the Transaction Details field.
