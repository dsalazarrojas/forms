# Customer Complaint Submission Form - Help Guide
## Purpose
The purpose of this form is to allow customers to submit complaints and feedback about their experiences with the business.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your name as the customer.
2. Provide a brief description of the issue you experienced.
3. Enter your email address and contact number.
4. Select the issue you encountered from the list of options provided.
5. Choose how you would like to be contacted about the issue.
6. If you have a message for the customer, you can include it in the text box provided.
7. If you have a response or feedback for the business, you can include it in the text box provided.

## Field-by-Field Explanation
* **Customer Name** (`customer_name`, text, required): This is the name of the customer submitting the complaint.
* **Description** (`description`, text, not required): Please describe the issue you experienced in a few sentences.
* **Email** (`email`, email, required): Enter your email address to enable us to contact you about your complaint.
* **Contact Number** (`contact_number`, text, required): Enter your contact number so we can contact you about your complaint.
* **Issue Description** (`issue_description`, select one, required): Select the issue you encountered from the list of options provided.
* **Preferred Contact Method** (`preferred_contact_method`, select one, required): Choose how you would like to be contacted about your issue, such as phone, email, or in-person.
* **Message to Customer** (`customer_complaint_message`, text, not required): If you have any message for the customer, you can include it in this text box.
* **Response** (`business_response`, text, not required): If you have any feedback or response for the business, you can include it in this text box.
