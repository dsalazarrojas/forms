# Donation Allocation Complaint Form - Help Guide
## Purpose
The Donation Allocation Complaint Form is used to report issues with donations, such as allocation errors, missing donors, or incorrect allocation. This form helps us identify and address these problems promptly.

## How To Complete This Form
To fill out the form, follow these steps:

1. Fill out the Donour Name field with the name of the person who made the donation.
2. Enter the Donour Email address associated with the donation.
3. If available, enter the Donour Phone number for easier contact.
4. Select a reason for the complaint from the Issue dropdown menu (e.g., Allocation Error, Missing Donors, etc.).
5. Provide additional details about the issue in the Details field.
6. If necessary, provide the Donour Donations Id for reference.
7. Choose the Donour Distributer from the list (if applicable).
8. Select the status of the Donour (Active, Inactive, Archived, or Pending).
9. If you have any further comments or information about the issue, enter them in the Donour Comments field.

## Field-by-Field Explanation
- **Donour Name** (`donour_name`, required): Enter the name of the person who made the donation.
- **Donour Email** (`donour_email`, required): Enter the email address associated with the donation.
- **Donour Phone** (`donour_phone`, optional): Enter the phone number of the donor for easier contact.
- **Issue** (`issue`, required): Select a reason for the complaint from the list:
  - Allocation Error
  - Missing Donors
  - Incorrect Allocation
  - Other
- **Details** (`details`, optional): Provide additional information about the issue.
- **Donour Donations Id** (`donour_donation_id`, optional): If available, enter the donor's donation ID for reference.
- **Donour Distributer** (`donour_distributer`, optional): Choose the distributor associated with the donation.
- **Donour Status** (`donour_status`, optional): Select the status of the donor (Active, Inactive, Archived, or Pending).
- **Donour Comments** (`donour_comments`, optional): Enter any additional comments about the issue.
