# Ride Service Availability Issue Report Form - Help Guide
## Purpose
The Ride Service Availability Issue Report Form is used by riders to report any issues they experienced with ride services. This form is designed to gather information to help in resolving these issues.

## How To Complete This Form
To complete this form, follow these steps:

- Enter your location in the `rider_location` field.
- Select the date you experienced the issue in the `service_availability_date` field.
- Provide a detailed description of the issue in the `issue_description` field.
- Indicate whether you have experienced a problem (yes/no) in the `problem_type` field.
- Provide additional details about the issue in the `issue_details` field.
- Select the types of follow-up that is needed in the `follow_up_needed` field.
- Enter any follow-up details in the `follow_up_details` field.
- Indicate whether you have contacted a representative (yes/no) in the `contacted` field.
- Enter the date you contacted a representative in the `contacted_date` field.
- Select whether a follow-up has been contacted (yes/no) in the `follow_up_contacted` field.
- Indicate whether the next action is required (yes/no) in the `next_action` field.
- Enter the date of the next action in the `next_action_date` field.
- Select whether this issue has been assigned to a representative (yes/no) in the `assigned_to` field.
- Enter any comments in the `comments` field.
- Select whether follow-up activities have been completed (yes/no) in the `follow_up_completed` field.
- Select whether the issue has been reopened (yes/no) in the `issue_reopened` field.
- Indicate whether the issue has been closed (yes/no) in the `closed` field.
- Enter the date the issue was closed in the `closed_date` field.
- Enter the reason for closure in the `closed_reason` field.
- Provide any comments about the closure in the `closed_comments` field.
- Enter the follow-up status in the `follow_up_status` field.

## Field-by-Field Explanation

* **Rider Location** (`rider_location`, text, required: false): Enter your location where you experienced the issue.
* **Service Availability Date** (`service_availability_date`, date, required: false): Select the date you experienced the issue.
* **Issue Description** (`issue_description`, text, required: false): Provide a detailed description of the issue you experienced.
* **Problem Type** (`problem_type`, select_one, required: false): Indicate whether you have experienced a problem (yes/no).
* **Issue Details** (`issue_details`, text, required: false): Enter any additional details about the issue.
* **Follow-up Needed** (`follow_up_needed`, select_multiple, required: false): Select the types of follow-up activities that are needed.
* **Follow-up Details** (`follow_up_details`, text, required: false): Enter any follow-up details.
* **Contacted** (`contacted`, select_one, required: false): Indicate whether you have contacted a representative (yes/no).
* **Contacted Date** (`contacted_date`, date, required: false): Enter the date you contacted a representative.
* **Follow-up Contacted** (`follow_up_contacted`, select_one, required: false): Select whether a follow-up has been contacted (yes/no).
* **Next Action** (`next_action`, select_one, required: false): Indicate whether the next action is required (yes/no).
* **Next Action Date** (`next_action_date`, date, required: false): Enter the date of the next action.
* **Assigned To** (`assigned_to`, select_one, required: false): Select whether this issue has been assigned to a representative (yes/no).
* **Comments** (`comments`, text, required: false): Enter any comments.
* **Follow-up Completed** (`follow_up_completed`, select_one, required: false): Select whether follow-up activities have been completed (yes/no).
* **Follow-up Completed Date** (`follow_up_completed_date`, date, required: false): Enter the date follow-up activities were completed.
* **Issue Reopened** (`issue_reopened`, select_one, required: false): Select whether the issue has been reopened (yes/no).
* **Issue Reopened Date** (`issue_reopened_date`, date, required: false): Enter the date the issue was reopened.
* **Closed** (`closed`, select_one, required: false): Indicate whether the issue has been closed (yes/no).
* **Closed Date** (`closed_date`, date, required: false): Enter the date the issue was closed.
* **Closed Reason** (`closed_reason`, text, required: false): Enter the reason for closure.
* **Closed Comments** (`closed_comments`, text, required: false): Enter any comments about the closure.
* **Follow-up Status** (`follow_up_status`, text, required: false): Enter the follow-up status.
