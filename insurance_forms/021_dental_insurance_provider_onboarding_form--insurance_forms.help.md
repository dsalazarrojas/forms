# Dental Insurance Provider Onboarding Form - Help Guide
## Purpose
The Dental Insurance Provider Onboarding Form is used to collect and store information about dental insurance providers. This information is used to keep their records up-to-date and accurate.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the provider's address and practice address in the respective fields.
2. Enter the provider's contact details, including phone, fax, and email.
3. Select the provider type and specialty from the dropdown menus.
4. If the provider type is "Other", specify the type in the "Other Provider Type" field.
5. If the provider specialty is "Other", specify the specialty in the "Other Provider Specialty" field.
6. Enter the practice hours and specialty, if applicable.
7. Review and update the form as needed before submitting.

## Field-by-Field Explanation
* **Provider Address 1**: Enter the street address of the provider.
* **Provider Address 2**: Enter the city, state, and ZIP of the provider.
* **Provider Name**: Enter the name of the provider.
* **Provider License Number**: Enter the state license number of the provider.
* **Provider Phone**: Enter the phone number of the provider.
* **Provider Email**: Enter the email of the provider.
* **Provider Fax**: Enter the fax number of the provider.
* **Provider Type**: Select the type of provider (e.g. general, specialist, etc.).
* **Other Provider Type**: If provider type is "Other", specify the type in this field.
* **Provider Specialty**: Select the specialty of the provider (e.g. general, orthodontist, etc.).
* **Other Provider Specialty**: If provider specialty is "Other", specify the specialty in this field.
* **Practice Address 1**: Enter the street address of the practice.
* **Practice Address 2**: Enter the city, state, and ZIP of the practice.
* **Practice Phone**: Enter the phone number of the practice.
* **Practice Name**: Enter the name of the practice.
* **Practice License Number**: Enter the state license number of the practice.
* **Practice Email**: Enter the email of the practice.
* **Practice Fax**: Enter the fax number of the practice.
* **Practice Hours**: Enter the hours of operation of the practice.
* **Practice Specialty**: Select the specialty of the practice (e.g. general, orthodontist, etc.).
* **Other Practice Specialty**: If practice specialty is "Other", specify the specialty in this field.
* **Provider Status**: Select the current provider status (e.g. active, inactive, etc.).
* **Other Provider Status**: If provider status is "Other", specify the status in this field.
* **Provider Notes**: Enter any additional notes about the provider.
* **Provider Date Opened**: Enter the date the practice was opened.
