# Tristone Financial Intake Form - Help Guide

## Purpose
This form is designed to collect information from patients to provide a comprehensive financial intake process. It is intended to be used by healthcare professionals to gather necessary details about a patient's contact information, medical history, and insurance coverage.

## How To Complete This Form

To complete this form, follow the steps below:

1. Provide your contact details, including your address, phone number, and email.
2. Fill out the medical history section, including your history, details, and dates.
3. Answer questions about your current symptoms and medical insurance coverage.
4. Select any allergies, medications, or medical conditions you may have.
5. Indicate whether you are undergoing a medical procedure and provide further details if necessary.
6. Optionally, provide follow-up instructions or information about your insurance coverage.

## Field-by-Field Explanation

* **Contact Details**:
	+ Label: Contact Details
	+ Type: text (text input field)
	+ Required: optional

Provide your name, address, phone number, and email address.

* **Address**:
	+ Label: Address
	+ Type: text (text input field)
	+ Required: optional

Enter your current address.

* **Phone**:
	+ Label: Phone
	+ Type: text (text input field)
	+ Required: optional

Enter your phone number.

* **Email**:
	+ Label: Email
	+ Type: email (email input field)
	+ Required: optional

Enter your email address.

* **Medical History**:
	+ Label: Medical History
	+ Type: text (text input field)
	+ Required: optional

Describe your medical history.

* **Medical History Details**:
	+ Label: Medical History Details
	+ Type: text (text input field)
	+ Required: optional

Provide further details about your medical history.

* **Medical History Date**:
	+ Label: Medical History Date
	+ Type: date (date picker field)
	+ Required: optional

Enter the date of your medical history.

* **Medical History Time**:
	+ Label: Medical History Time
	+ Type: time (time picker field)
	+ Required: optional

Enter the time of your medical history.

* **Symptoms**:
	+ Label: Symptoms
	+ Type: select one (select one dropdown)
	+ Required: optional

Indicate whether you are currently experiencing symptoms. Options: Yes, No.

* **Medical Insurance**:
	+ Label: Medical Insurance
	+ Type: select one (select one dropdown)
	+ Required: optional

Select your medical insurance coverage. Options: Medicare, Medicaid, None.

* **Allergies**:
	+ Label: Allergies
	+ Type: select multiple (checkboxes)
	+ Required: optional

Select any allergies you may have. Options: Penicillin, Ibuprofen, Aspirin.

* **Medications**:
	+ Label: Medications
	+ Type: select multiple (checkboxes)
	+ Required: optional

Select any medications you are currently taking. Options: Atenolol, Ibuprofen, Aspirin.

* **Medical Conditions**:
	+ Label: Medical Conditions
	+ Type: select multiple (checkboxes)
	+ Required: optional

Select any medical conditions you may have. Options: Diabetes, Asthma, Epilepsy.

* **Medical Procedure**:
	+ Label: Medical Procedure
	+ Type: select one (select one dropdown)
	+ Required: optional

Indicate whether you are undergoing a medical procedure. Options: Yes, No.

* **Medical Procedure Detail**:
	+ Label: Medical Procedure Detail
	+ Type: text (text input field)
	+ Required: optional

Provide further details about the medical procedure.

* **Follow Up Instructions**:
	+ Label: Follow Up Instructions
	+ Type: note (text area)
	+ Required: optional

Provide any necessary follow-up instructions.

* **Insurance Info**:
	+ Label: Insurance Info
	+ Type: select one (select one dropdown)
	+ Required: optional

Indicate whether you have medical insurance. Options: Yes, No.
