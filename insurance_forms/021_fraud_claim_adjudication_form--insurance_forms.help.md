# Fraud Claim Adjudication Form - Help Guide
## Purpose
The Fraud Claim Adjudication Form is used to gather information about fraudulent claims and to determine their legitimacy. It is a critical document that helps in making informed decisions regarding fraud claims.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Start by filling out the first page, which includes the basic details about the fraud claim.
2. Proceed to the subsequent pages, which will ask for more specific information about the claim.
3. Make sure to answer all the questions truthfully and accurately.
4. If you are unsure about any field or have any questions, please do not hesitate to contact a supervisor or the relevant authorities.

## Field-by-Field Explanation

* **Fraud Claim Adjudication Form** (`title`, text, required: false): This is the title of the form, which is used to identify the purpose and content of the form.

* **Claimant Details** (`claimant_details`, text, required: false): Please provide a brief description of the claimant, including their name, address, and any other relevant information.

* **Fraud Type** (`fraud_type`, select_one, required: false): Please select the type of fraud that is being claimed. You can choose from the following options: "Yes" or "No".

* **Other Fraud Type** (`fraud_type_other`, text, required: false): If the fraud type is not listed, please provide a description of the type of fraud being claimed.

* **Fraud Claim Date** (`fraud_claim_date`, date, required: false): Please enter the date when the fraud claim was made.

* **Fraud Claim Amount** (`fraud_claim_amount`, number, required: false): Please enter the amount of the fraud claim.

* **Fraud Claim Status** (`fraud_claim_status`, select_one, required: false): Please select the status of the fraud claim. You can choose from the following options: "Active" or "Inactive".

* **Other Fraud Claim Status** (`fraud_claim_status_other`, text, required: false): If the fraud claim status is not listed, please provide a description of the status of the claim.

* **Fraud Claim Reason** (`fraud_claim_reason`, text, required: false): Please provide a brief description of the reason for the fraud claim.

* **Fraud Claim Description** (`fraud_claim_description`, text, required: false): Please provide a detailed description of the fraud claim.

* **Fraud Claim Evidence** (`fraud_claim_evidence`, text, required: false): Please attach any evidence related to the fraud claim.

* **Fraud Claim Adjudication** (`fraud_claim_adjudication`, select_one, required: false): Please select whether the fraud claim has been adjudicated. You can choose from the following options: "Yes" or "No".

* **Other Fraud Claim Adjudication** (`fraud_claim_adjudication_other`, text, required: false): If the fraud claim has not been adjudicated, please provide a description of the reasons for not adjudicating it.

* **Fraud Claim Decision** (`fraud_claim_decision`, select_multiple, required: false): Please select the decision made regarding the fraud claim. You can choose from the following options: "Yes" or "No".

* **Other Fraud Claim Decision** (`fraud_claim_decision_other`, text, required: false): If the fraud claim decision is not listed, please provide a description of the decision made.

* **Fraud Claim Outcome** (`fraud_claim_outcome`, text, required: false): Please provide a brief description of the outcome of the fraud claim.

* **Fraud Claim Comments** (`fraud_claim_comments`, text, required: false): Please provide any comments or observations regarding the fraud claim.

Note: This help guide is a general guide and may not cover all possible scenarios or fields. If you are unsure about any field or the process as a whole, please consult with a supervisor or the relevant authorities.
