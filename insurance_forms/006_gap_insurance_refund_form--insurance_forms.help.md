# Gap Insurance Refund Form - Help Guide
## Purpose
The Gap Insurance Refund Form is used to process claims for insurance refunds.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form accurately and thoroughly.
2. Ensure that all required fields are completed before submitting the form.
3. Use the provided options for select fields to select the most accurate answer.
4. Date fields should be in the format MM/DD/YYYY.
5. Sign and date the form before submitting it.

## Field-by-Field Explanation
* **Customer Name** (id: 2, label: Customer Name, type: text, required: true): Enter the customer's name as it appears on their insurance policy.
* **Customer Email** (id: 3, label: Customer Email, type: email, required: true): Enter the customer's email address associated with their insurance policy.
* **Policy Number** (id: 4, label: Policy Number, type: number, required: true): Enter the policy number associated with the claim.
* **Claim Type** (id: 5, label: Claim Type, type: select_one, required: true): Select the type of claim being made (e.g., "Option 1", "Option 2", etc.).
* **Reason for Claim** (id: 6, label: Reason for Claim, type: select_multiple, required: true): Select all reasons that apply for the claim (e.g., "Option 1", "Option 2", "Option 3", etc.).
* **Claim Date** (id: 7, label: Claim Date, type: date, required: true): Enter the date of the claim in the format MM/DD/YYYY.
* **Claim Amount** (id: 8, label: Claim Amount, type: number, required: true): Enter the total amount of the claim.
* **Bank Name** (id: 9, label: Bank Name, type: text, required: true): Enter the name of the bank associated with the claim.
* **Bank Account Number** (id: 10, label: Bank Account Number, type: text, required: true): Enter the bank account number associated with the claim.
* **Bank Account Type** (id: 11, label: Bank Account Type, type: select_one, required: true): Select the type of bank account (e.g., "Option 1", "Option 2", etc.).
* **Check Number** (id: 12, label: Check Number, type: text, required: true): Enter the check number associated with the claim.
* **Claim Status** (id: 13, label: Claim Status, type: select_one, required: true): Select the status of the claim (e.g., "Option 1", "Option 2", etc.).
