# Liability Waiver Rental Agreement - Help Guide
## Purpose
The Liability Waiver Rental Agreement is a document that protects both the renter and the landlord by releasing each party from liability in the event of an injury or damage during a rental or use of equipment.

## How To Complete This Form
- Start by entering the **Rental Agreement** in the text field.
- Then select **Yes/No** for whether the renter accepts the terms of the waiver in the **Renter Information** field.
- Enter the **Rent Date** and **End Date** using the date format.
- Select **Yes/No** for whether the waiver type is applicable.
- Select **Yes/No** for whether the renter accepts the terms of the waiver in the **Waiver Acceptance** field.
- Select **Yes/No** for whether the waiver is **Waiver Type**, if applicable.
- Enter the **Waiver Version** in the text field.

## Field-by-Field Explanation
- **Rental Agreement (required: no)**: This field is for the text description of the rental agreement. Please enter a clear and concise statement that includes all the terms and conditions of the rental.
- **Renter Information (required: no)**: Select **Yes** if the renter accepts the terms of the waiver, otherwise select **No**.
- **Equipment Details (required: no)**: This field is not required for the form but it's a good idea to include any additional equipment details, if any.
- **Rent Date (required: no)**: Enter the start date of the rental period in the date format.
- **End Date (required: no)**: Enter the end date of the rental period in the date format.
- **Waiver Acceptance (required: no)**: Select **Yes** if the renter accepts the terms of the waiver, otherwise select **No**.
- **Waiver Type (required: no)**: Select **Yes** if the waiver type is applicable, otherwise select **No**.
- **Waiver Version (required: no)**: Enter the version of the waiver that you are referencing.
