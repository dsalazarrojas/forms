# Vehicle Insurance Inquiry Form - Help Guide
## Purpose
This form is used to gather information about an individual's vehicle and their insurance inquiry status. It is designed for new insurance inquires.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the vehicle's make.
2. Fill in the vehicle's model.
3. Fill in the vehicle's year.
4. Provide the driver's name.
5. Provide the driver's address.
6. Provide the driver's license number.
7. Select the date of inquiry.
8. Select the vehicle's insurance provider (e.g., 'Yes' for existing insurance provider).
9. Select the vehicle insurance type (e.g., 'Yes' for insurance type available).
10. Provide the driver's phone number.
11. Select the vehicle's purpose (e.g., 'Yes' for personal vehicle).
12. Add any additional information in the "Note" field (optional).

## Field-by-Field Explanation
* **Vehicle Make**: Enter the make of the vehicle (e.g., Toyota, Ford, Honda).
* **Vehicle Model**: Enter the model of the vehicle (e.g., Camry, Focus, Civic).
* **Vehicle Year**: Enter the year of the vehicle (e.g., 2018, 2020, etc.).
* **Driver's Name**: Enter the name of the person who will be driving the vehicle.
* **Driver's Address**: Enter the address where the vehicle will be kept.
* **Driver's License**: Enter the driver's license number (e.g., ABC123).
* **Date of Inquiry**: Select the date when the insurance inquiry was made.
* **Vehicle Insurance Provider**: Select 'Yes' if the vehicle is already insured, 'No' if not, or select 'Other' if unsure.
* **Vehicle Insurance Type**: Select 'Yes' if insurance type is available, 'No' if not, or select 'Other' if unsure.
* **Driver's Phone**: Enter the driver's phone number (e.g., 123-456-7890).
* **Vehicle Purpose**: Select 'Yes' if the vehicle is for personal use, 'No' if commercial use, or select 'Other' if unsure.
* **Note**: Add any additional information that may help with the insurance inquiry (optional).
