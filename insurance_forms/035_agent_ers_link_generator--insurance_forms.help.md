# Agent ERS Link Generator - Help Guide

## Purpose
This form is designed to generate a secure link for insurance reviews and assessments.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the agent's full name.
2. Enter the agent's ID number.
3. Enter the agent's official email address, where the link will be delivered.
4. Enter the 15-digit Jotform form number.
5. Select the target region for link distribution.
6. Choose the custom suffix for tracking (optional).
7. Select the intended platform for sharing the link (e.g., email, SMS, social media, or QR code generation).
8. Choose the priority for link activation (standard or urgent).

## Field-by-Field Explanation

* **Agent Full Name**: Enter the full name of the agent as it should be displayed on the generated link.
* **Agent ID Number**: Enter the agent's ID number as it should be displayed on the generated link.
* **Agent Official Email**: Enter the agent's official email address where the link will be delivered. This is the email address that will receive the link.
* **Jotform Form Number to Link**: Enter the 15-digit Jotform form number that you want to link to.
* **Region for Link Distribution**: Select the target region where the link will be distributed (e.g., North America, Europe, Asia Pacific, or Latin America).
* **Custom Suffix for Tracking**: Enter a custom suffix for tracking purposes (e.g., Fall_Campaign_2026). This is optional.
* **Intended Platform for the Link**: Select the platform where the link will be shared (e.g., email, SMS, social media, or QR code generation).
* **Priority for Link Activation**: Choose the priority for link activation (standard or urgent).

## Tips

* Make sure to enter the correct email address for the link to be delivered to the correct agent.
* Select the correct region for link distribution to ensure the link is delivered to the right audience.
* If you want to track the link, enter a custom suffix for tracking purposes.
* Choose the correct platform for sharing the link to ensure it reaches the intended audience.
* Select the correct priority for link activation based on the urgency of the link delivery.
