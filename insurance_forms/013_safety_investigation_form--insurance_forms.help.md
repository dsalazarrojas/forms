# Safety Investigation Form - Help Guide
## Purpose
This form is used to document and investigate incidents that occurred within our organization.
## How To Complete This Form
To complete this form, follow these steps:

1. Provide details about the incident, including any contributing factors that may have led to it.
2. Summarize the incident in a few sentences.
3. If necessary, indicate any corrective actions that can be taken to prevent similar incidents in the future.
4. State the outcome of the investigation, indicating if any action was taken or if the matter was resolved.
5. Document the incident date, time, and location.
6. Provide a description of the incident.
7. Enter the name and title of the person conducting the investigation.

## Field-by-Field Explanation

* **Incident Details** (`incident_details`): Enter a brief description of the incident.
* **Contributing Factors** (`contributing_factors`): Indicate if any contributing factors existed during the incident. If yes, select all that apply.
	+ 'Yes'
	+ 'No'
* **Incident Summary** (`incident_summary`): Enter a brief summary of the incident.
* **Corrective Actions** (`corrective_actions`): If necessary, indicate any corrective actions that can be taken to prevent similar incidents in the future. If none, select 'No'.
	+ 'Yes'
	+ 'No'
* **Investigation Outcome** (`investigation_outcome`): Indicate if the matter was resolved or if any action was taken.
	+ 'Yes'
	+ 'No'
* **Incident Date** (`incident_date`): Enter the date of the incident.
* **Incident Time** (`incident_time`): Enter the time of the incident.
* **Incident Location** (`incident_location`): Indicate the location where the incident occurred.
	+ 'Yes'
	+ 'No'
* **Incident Description** (`incident_description`): Enter a detailed description of the incident.
* **Investigator Name** (`investigator_name`): Enter the name of the person conducting the investigation.
* **Investigator Title** (`investigator_title`): Enter the title of the person conducting the investigation.
* **Investigation Notes** (`investigation_notes`): Enter any notes about the investigation.

Note: Some fields are not required, but it's recommended to complete as much of the form as possible to ensure thorough documentation.
