# Insurance Coverage Declaration Form - Help Guide

## Purpose
The Insurance Coverage Declaration Form is designed to help insurance providers document policy coverage declarations in a consistent and clear manner. It is used by various teams within the organization to gather and store policy information.

## How To Complete This Form

1. The form consists of multiple pages, each with specific fields that need to be completed. Please ensure that you complete all required fields as indicated by the "required" status in each field.
2. The form includes a variety of field types, including text, date, time, number, select, and select multiple. Please select the relevant options for each field as prompted.
3. If you are unsure about any field, please refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **First page**: This field is the first page of the form. Please complete this page first.
* **Coverage limits**: Enter the coverage limits for the policy, if applicable.
* **Exclusions list**: Select the exclusions that apply to the policy (Liability, Fire, Water).
* **Coverage amount**: Enter the coverage amount for the policy, if applicable.
* **Coverage date**: Enter the coverage date for the policy, if applicable.
* **Coverage time**: Enter the coverage time for the policy, if applicable.
* **Policy type**: Select the type of policy (Type 1, Type 2, Type 3).
* **Policy status**: Select the status of the policy (Active, Inactive).
* **Coverage start date**: Enter the coverage start date for the policy, if applicable.
* **Coverage end date**: Enter the coverage end date for the policy, if applicable.
* **Policy start date**: Enter the policy start date for the policy, if applicable.
* **Policy end date**: Enter the policy end date for the policy, if applicable.
* **Policy number**: Enter the policy number, if applicable.
* **Policy number 2**: Select the policy number from the options provided.
* **Coverage type**: Select the type of coverage (Single, Multiple).
* **Coverage name**: Enter the coverage name, if applicable.
* **Coverage description**: Enter the coverage description, if applicable.
* **Coverage start time**: Enter the coverage start time for the policy, if applicable.
* **Coverage end time**: Enter the coverage end time for the policy, if applicable.
* **Coverage limit**: Enter the coverage limit, if applicable.
* **Policy limit**: Enter the policy limit, if applicable.
* **Policy description**: Enter the policy description, if applicable.
* **Policy start limit**: Enter the policy start limit, if applicable.
* **Policy end limit**: Enter the policy end limit, if applicable.
* **Additional information**: Enter any additional information about the policy, if applicable.

Note: Please ensure that all required fields are completed accurately and completely before submitting the form.
