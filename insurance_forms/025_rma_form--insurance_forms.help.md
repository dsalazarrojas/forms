# rma_form - Help Guide
## Purpose
This form is used to collect information from customers for product return requests.

## How To Complete This Form
1. Select the reason for return from the options provided in "Product Return Reason" field.
2. Enter the reason description for return in the "Reason For Return" field.
3. Fill in the customer's name, email, phone number, and address in the fields labeled "Customer Name", "Customer Email", "Customer Phone", and "Customer Address", respectively.
4. Enter the order number for the product being returned.
5. Check the status of the return request in the "Order Status" field.
6. If applicable, enter the serial number, description, and reason description for the reason returned item.
7. Check the status of whether the item was returned in the "Reason Returned Item Returned Status" field.
8. Enter the date and any comments for the returned item.
9. Check the box if the customer agrees with the return process.
10. Sign the form digitally with the current date.
11. Finally, click "Submit" to complete the form.

## Field-by-Field Explanation
- **Product Return Reason** (`Product Return Reason`, select multiple): Select the reason for return from the options provided.
- **Reason For Return** (`Reason For Return`, text): Enter a brief description of the reason for return.
- **Customer Name** (`Customer Name`, text): Enter the customer's name.
- **Customer Email** (`Customer Email`, email): Enter the customer's email address.
- **Customer Phone** (`Customer Phone`, text): Enter the customer's phone number.
- **Customer Address** (`Customer Address`, text): Enter the customer's address.
- **Order Number** (`Order Number`, number): Enter the order number for the product being returned.
- **Reason For Return** (`Reason For Return`, text): Enter a brief description of the reason for return.
- **Product Serial Number** (`Product Serial Number`, text): Enter the serial number of the product being returned.
- **Customer Note** (`Customer Note`, text): Enter any notes from the customer about the return.
- **Customer Signature** (`Customer Signature`, text): Enter the customer's signature.
- **Customer Agreement** (`Customer Agreement`, text): Check the box if the customer agrees with the return process.
- **RMA Form Completion Status** (`RMA Form Completion Status`, select one): Set the status of the form completion.
- **Order Status** (`Order Status`, select one): Set the status of the order.
- **Reason Returned Item ID** (`Reason Returned Item ID`, text): Enter the ID of the item being returned.
- **Reason Returned Item Serial Number** (`Reason Returned Item Serial Number`, text): Enter the serial number of the item being returned.
- **Reason Returned Item Description** (`Reason Returned Item Description`, text): Enter a description of the item being returned.
- **Reason Returned Item Reason Description** (`Reason Returned Item Reason Description`, text): Enter a description of the reason for returning the item.
- **Reason Returned Item Serial Number** (`Reason Returned Item Serial Number`, text): Enter the serial number of the item being returned.
- **Reason Returned Item Returned Status** (`Reason Returned Item Returned Status`, select one): Set the status of whether the item was returned.
- **Reason Returned Item Returned Date** (`Reason Returned Item Returned Date`, date): Enter the date the item was returned.
- **Reason Returned Item Returned By** (`Reason Returned Item Returned By`, text): Enter the person who returned the item.
- **Reason Returned Item Returned Comments** (`Reason Returned Item Returned Comments`, text): Enter any comments about the return of the item.
- **Customer Signature Date** (`Customer Signature Date`, date): Enter the current date of the customer's signature.
- **Reason Returned Item Return Status** (`Reason Returned Item Return Status`, select one): Set the status of the return of the item.
