# Home Insurance Declaration Form - Help Guide
## Purpose
This form is designed for individuals to declare their home insurance information, including property address, year built, property value, and list of insurance providers.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your property address in the "House Street" field.
2. Provide the year the house was built in the "House Year Built" field.
3. Enter the value of your property in the "House Property Value" field.
4. Select the correct owner of the property from the "Who is the Property Owner" dropdown menu.
5. For each of the remaining fields, select "Yes" or "No" for each insurance provider.

## Field-by-Field Explanation
* **House Street** (Address, text, optional): Enter the address of the property.
* **House Year Built** (Year Built, number, optional): Provide the year the house was built.
* **House Property Value** (Property Value, number, optional): Enter the value of the property.
* **Who is the Property Owner** (Property Owner, select one, optional): Select whether the property owner is Mr., Mrs., or Ms.
* **Insurance Provider** (Insurance Provider, select multiple, optional):
	+ **Insurance Provider 1** (Yes/No, select multiple, optional): Select "Yes" if the provider provides insurance.
	+ **Insurance Provider 2** (Yes/No, select multiple, optional): Select "Yes" if the provider provides insurance.
	+ **Insurance Provider 3** (Yes/No, select multiple, optional): Select "Yes" if the provider provides insurance.
	+ ...
	+ **Insurance Provider 20** (Yes/No, select multiple, optional): Select "Yes" if the provider provides insurance.

## Tips
* Double-check the accuracy of the information entered.
* Make sure to select all insurance providers that apply.
* Review the form before submission.
