# Team Social Event Survey - Help Guide
## Purpose
This form is used to gather information about team social events, including the event name, location, date, time, attendees, type, and feedback.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Event Name" field with the name of the event that was held.
2. Enter the location where the event took place in the "Location" field.
3. Select the date of the event in the "Date" field.
4. Choose the time the event started in the "Time" field.
5. In the "Who attended" field, select all the individuals who attended the event.
6. In the "Type of event" field, choose the type of event that it was (e.g. happy hour, team building, etc.).
7. If you have any additional details about the event, you can type them in the "Event details" field.
8. Answer "Yes" or "No" in the "Did you attend this event?" field to indicate whether you were present.
9. If you have any feedback about the event, you can type it in the "Feedback" field.
10. If you have suggestions for future events, type them in the "Suggestion for future events" field.
11. If you have any comments about the event, type them in the "Comments" field.
12. If you have any contact information, type it in the "Contact info" field.
13. Finally, enter your email address in the "Email" field.

## Field-by-Field Explanation
- **Event Name** (text, required): Enter the name of the event that was held.
- **Location** (text, required): Enter the location where the event took place.
- **Date** (date, required): Select the date of the event.
- **Time** (time, required): Choose the time the event started.
- **Who attended** (select multiple, optional): Select all the individuals who attended the event.
- **Type of event** (select one, optional): Choose the type of event that it was (e.g. happy hour, team building, etc.).
- **Event details** (note, optional): If you have any additional details about the event, type them here.
- **Did you attend this event?** (select one, optional): Answer "Yes" or "No" to indicate whether you were present.
- **Feedback** (text, optional): If you have any feedback about the event, type it here.
- **Suggestion for future events** (text, optional): If you have any suggestions for future events, type them here.
- **Comments** (text, optional): If you have any comments about the event, type them here.
- **Contact info** (text, optional): If you have any contact information, type it here.
- **Email** (email, optional): Enter your email address.

## Tips
* Make sure to be as specific as possible when filling in the "Event Name", "Location", and "Date" fields to help others understand what happened.
* If you are unsure about the type of event, you can choose "Other" and type in a description.
* If you have any contact information, please make sure to enter a valid email address.
