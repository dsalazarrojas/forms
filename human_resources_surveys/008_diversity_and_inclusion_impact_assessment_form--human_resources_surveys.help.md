# Diversity And Inclusion Impact Assessment Form - Help Guide
## Purpose

The purpose of this form is to collect data on the impact assessment of diversity and inclusion within an organization's team members and departments. This form is used by HR teams to analyze and improve diversity initiatives and inclusion practices within the company.

## How To Complete This Form

1.  Fill in the required fields: employee name, role, and job classification.
2.  Select the correct job level for each employee: High or Low.
3.  Indicate if diversity initiatives are present: Yes or No.
4.  Enter the team members involved in the assessment: Team Lead, Department Head, Manager, etc.
5.  Choose the assessment location and time.
6.  Input the team size and department members.

## Field-by-Field Explanation

* **Team Members (1)** (number): List the number of team members involved in this assessment.
* **Diversity Initiatives (2)** (select_multiple): Select 'Yes' if diversity initiatives are present; otherwise, select 'No'.
* **Assessment Date (3)** (date): Enter the date of the assessment (mm/dd/yyyy).
* **Assessment Time (4)** (time): Enter the time of the assessment (HH:MM AM/PM).
* **Assessment Location (5)** (text): Enter the location of the assessment.
* **Email (6)** (email): Enter the email address of the person filling out the form.
* **Phone Number (7)** (text): Enter the phone number of the person filling out the form.
* **Team Lead (8)** (select_one): Select 'Yes' if the team lead is involved; otherwise, select 'No'.
* **Department (9)** (select_one): Select 'Yes' if the department is involved; otherwise, select 'No'.
* **Team Size (10)** (select_one): Select 'Yes' if the team size is involved; otherwise, select 'No'.
* **Department Head (11)** (select_one): Select 'Yes' if the department head is involved; otherwise, select 'No'.
* **Team Location (12)** (select_one): Select 'Yes' if the team location is involved; otherwise, select 'No'.
* **Manager Name (13)** (select_one): Select 'Yes' if the manager is involved; otherwise, select 'No'.
* **Department Manager (14)** (select_one): Select 'Yes' if the department manager is involved; otherwise, select 'No'.
* **Team Lead Name (15)** (select_one): Select 'Yes' if the team lead is involved; otherwise, select 'No'.
* **Team Members (16)** (select_multiple): Select 'Yes' if team members are involved; otherwise, select 'No'.
* **Team Member Name (17)** (select_multiple): Select 'Yes' if team members are involved; otherwise, select 'No'.
* **Department Members (18)** (select_multiple): Select 'Yes' if department members are involved; otherwise, select 'No'.
* **Team Member (19)** (select_multiple): Select 'Yes' if team member is involved; otherwise, select 'No'.
* **Department Team Members (20)** (select_multiple): Select 'Yes' if department team members are involved; otherwise, select 'No'.
* **Employee (21)** (text): Enter the employee's name.
* **Role (22)** (text): Enter the role of the employee.
* **Job Title (23)** (text): Enter the job title of the employee.
* **Job Classification (24)** (select_one): Select 'Yes' if the job classification is involved; otherwise, select 'No'.
* **Job Level (25)** (select_one): Select 'High' if the job level is high; otherwise, select 'Low'.

## Tips

* This form is meant to be filled out by one employee at a time.
* Make sure to select only relevant fields when filling out the form.
* Fill in all required fields.
* Be honest when selecting whether diversity initiatives are present or not.
