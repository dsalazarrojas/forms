# Employee Referral Questionnaire Centennial - Help Guide
## Purpose
The Employee Referral Questionnaire Centennial is a form designed to collect information about job openings within a company. This form helps HR departments gather details about job referrals from employees.

## How To Complete This Form
1. Fill in the required fields, such as Job Title, Job Location, Job Description, and Referred By.
2. For fields like Job Type and Job Status, select one or multiple options that apply.
3. Enter any additional details in the Note field.
4. Provide your email address and phone number for contact.
5. Choose the Category and Assigned Tool for the form.
6. Optionally, add an Output File and Form ID if necessary.

## Field-by-Field Explanation

* **Company Name** (`company_name`, text, required: false): Enter the name of the company.
* **Job Title** (`job_title`, text, required: false): Enter the title of the job opening.
* **Job Location** (`job_location`, text, required: false): Enter the location of the job opening.
* **Job Description** (`job_description`, text, required: false): Enter a brief description of the job opening.
* **Referred By** (`referred_by`, select_one, required: false): Select the employee who referred you to this job opening.
* **Referred Date** (`referred_date`, date, required: false): Enter the date you were referred to this job opening.
* **Referred Time** (`referred_time`, time, required: false): Enter the time you were referred to this job opening.
* **Job Type** (`job_type`, select_multiple, required: false): Select the type of job (Full-time, Part-time, Temporary).
* **Job Status** (`job_status`, select_one, required: false): Select the current status of the job (Active, Inactive).
* **Note** (`note`, text, required: false): Add any additional details about the job opening.
* **Email** (`email`, email, required: false): Enter your email address.
* **Phone** (`phone`, text, required: false): Enter your phone number.
* **Category** (`category`, select_one, required: false): Select the category of the form (Human Resources Surveys, Human Resources Forms).
* **Assigned Tool** (`assigned_tool`, select_one, required: false): Select the tool assigned to this form.
* **Output File** (`output_file`, text, required: false): Add an output file if necessary.
* **Form ID** (`form_id`, text, required: false): Enter the ID of the form.
* **Form IDs** (`form_ids`, text, required: false): Enter any IDs associated with the form.
* **Category 1** (`category_1`, text, required: false): Enter the category of the form.
* **Category 2** (`category_2`, text, required: false): Enter the category of the form.
* **Form Category** (`form_category`, text, required: false): Enter the category of the form.
* **Description** (`description`, text, required: false): Enter a description of the form.
* **Form Description** (`form_description`, text, required: false): Enter a description of the form.
* **Form Title** (`form_title`, text, required: false): Enter the title of the form.
* **Form Category 1** (`form_category_1`, text, required: false): Enter the category of the form.
* **Output File 1** (`output_file_1`, text, required: false): Add an output file if necessary.

Note: This form is designed to be completed by employees to refer job openings within their company. Please ensure that you're using this form correctly and only for its intended purpose.
