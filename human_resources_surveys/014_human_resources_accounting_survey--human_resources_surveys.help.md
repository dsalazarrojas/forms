# Human Resources Accounting Survey - Help Guide

## Purpose
The Human Resources Accounting Survey is designed to collect comprehensive data on employee information for accurate and efficient HR accounting processes.

## How To Complete This Form

1. Select the correct employee from the "Employee" dropdown menu.
2. Enter the employee's name in the "Employee Name" field.
3. Choose the employee's department from the "Department" dropdown menu.
4. Select the employee's job title from the "Job Title" dropdown menu.
5. Choose the employee's reporting manager from the "Reporting Manager" dropdown menu.
6. Select the employee's job function from the "Job Function" dropdown menu.
7. Choose the employment type (full-time, part-time, or contract) from the "Employment Type" dropdown menu.
8. Select the employee's job category from the "Job Category" dropdown menu.
9. Choose the employee's job level (junior, mid-level, or senior) from the "Job Level" dropdown menu.
10. Enter the employment start and end dates in the "Employment Start Date" and "Employment End Date" fields, respectively.
11. If applicable, choose the employee's department ID from the "Department ID" dropdown menu.
12. Enter the employee's job title code in the "Job Title Code" field.
13. Enter the employee's manager's name in the "Manager Name" field.
14. Select the employee's employment status (active, inactive, or prophets) from the "Employment Status" dropdown menu.
15. Enter the employee's department name in the "Department" field.
16. Choose the employee's job level code from the "Job Level Code" dropdown menu.
17. Enter the employee's employment start date 2 in the "Employment Start Date 2" field.
18. Select the employee's prophet from the "Prophet" dropdown menu.
19. Select the employee's employment category from the "Employment Category" dropdown menu.

## Field-by-Field Explanation

* **Employee** (select_one): Select the correct employee from the dropdown menu.
* **Employee Name** (text): Enter the employee's name.
* **Department** (select_multiple): Choose the employee's department from the dropdown menu.
* **Job Title** (text): Enter the employee's job title.
* **Reporting Manager** (select_one): Choose the employee's reporting manager from the dropdown menu.
* **Job Function** (select_one): Select the employee's job function from the dropdown menu.
* **Employment Type** (select_one): Choose the employee's employment type (full-time, part-time, or contract).
* **Job Category** (select_one): Select the employee's job category from the dropdown menu.
* **Job Level** (select_one): Choose the employee's job level (junior, mid-level, or senior).
* **Employment Start Date** (date): Enter the employee's employment start date.
* **Employment End Date** (date): Enter the employee's employment end date.
* **Department ID** (number): If applicable, choose the employee's department ID.
* **Job Title Code** (text): Enter the employee's job title code.
* **Manager Name** (text): Enter the employee's manager's name.
* **Employment Status** (select_one): Select the employee's employment status (active, inactive, or prophets).
* **Department** (text): Enter the employee's department name.
* **Job Level Code** (select_one): Choose the employee's job level code.
* **Employment Start Date 2** (date): Enter the employee's employment start date 2.
* **Prophet** (select_multiple): Select the employee's prophet.
* **Employment Category** (select_one): Select the employee's employment category.

## Tips

* Make sure to select the correct employee from the "Employee" dropdown menu.
* Ensure that the data entered is accurate and up-to-date.
* If an employee's employment status is "active", ensure that the employment end date is not entered.
* If an employee's employment status is "inactive", ensure that the employment start date and end date are entered accurately.
