# Machine Setup Checklist - Help Guide
## Purpose
This form is used to record the completion status of machine setup by technicians. It is used to keep a record of which machines have been set up and who completed the setup.

## How To Complete This Form
To complete this form, simply fill in the required and optional fields as you see fit. You can find instructions for each field below.

## Field-by-Field Explanation
* **machine_name** (`machine_name`, text, Optional): This field is for entering the name of the machine that was set up. Enter the name as it appears on the machine's label or manufacturer's documentation.
* **machine_number** (`machine_number`, number, Optional): This field is for entering the machine's serial number, which can be found on the machine's label or manufacturer's documentation.
* **machine_serial_number** (`machine_serial_number`, text, Optional): This field is for entering the machine's serial number. If you have already entered the machine number, do not enter the serial number here.
* **setup_completed_by** (`setup_completed_by`, select_one, Optional): This field is for selecting whether the machine setup was completed by you or someone else. Select 'Yes' if you are certain, or 'No' if it was not completed.
* **setup_completed_date** (`setup_completed_date`, date, Optional): This field is for entering the date when the machine setup was completed. Enter the date in the correct format (YYYY-MM-DD).
* **setup_completed_time** (`setup_completed_time`, time, Optional): This field is for entering the time when the machine setup was completed. Enter the time in the correct format (HH:MM:SS).
* **notes** (`notes`, note, Optional): This field is for entering any additional comments or notes about the machine setup. If you have any comments or notes, use this field to add them.

## Tips
Please make sure to only enter accurate and up-to-date information. If you are unsure about any field, please contact the relevant personnel for clarification. If you have any further questions or concerns, please email [support email] or call [support phone number].
