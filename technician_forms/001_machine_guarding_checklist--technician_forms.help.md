# Machine Guarding Checklist - Help Guide
## Purpose
The Machine Guarding Checklist is a form used to collect information about the state of machine guarding systems and safety features. It helps users assess the safety of machines and equipment to identify any necessary repairs or maintenance.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you are authorized to inspect the machine or equipment.
2. Physically inspect the machine or equipment to observe its guarding system and safety features.
3. Choose the relevant options for each field based on your observation:
   * Machine Guards: Select 'Yes' if the machine has a guarding system, 'No' otherwise.
   * Electrical Components: Select 'Yes' if the machine's electrical components are well-maintained, 'No' otherwise.
   * Warning Labels: Select 'Yes' if the machine has warning labels, 'No' otherwise.
   * Guarding System: Select 'Yes' if the machine's guarding system is in good working order, 'No' otherwise.
   * Guarding System Components: Select 'Yes' if the machine's guarding system components are in good condition, 'No' otherwise.
   * Inspection Schedule: Enter the next inspection date for the machine.
   * Maintenance Schedule: Enter the next maintenance date for the machine.
   * Review Date: Enter the last review date for the machine.
   * Technician Signature: Sign as the technician performing the inspection or assessment.
   * Manager Signature: Sign as the person authorizing the assessment and ensuring the machine is safe to operate.

## Field-by-Field Explanation
* **Introduction**: This is a note field for any additional comments or notes about the machine or equipment.
* **Machine Guards**: This field indicates whether the machine has a guarding system in place to prevent accidents. Select 'Yes' if the machine has a guarding system, 'No' otherwise.
* **Electrical Components**: This field indicates whether the machine's electrical components are well-maintained and safe to operate. Select 'Yes' if the machine's electrical components are well-maintained, 'No' otherwise.
* **Warning Labels**: This field indicates whether the machine has warning labels to alert operators of potential hazards. Select 'Yes' if the machine has warning labels, 'No' otherwise.
* **Guarding System**: This field indicates the state of the machine's guarding system. Select 'Yes' if the system is in good working order, 'No' otherwise.
* **Guarding System Components**: This field indicates the condition of the machine's guarding system components. Select 'Yes' if the components are in good condition, 'No' otherwise.
* **Inspection Schedule**: Enter the date of the next planned inspection for the machine.
* **Maintenance Schedule**: Enter the date of the next planned maintenance for the machine.
* **Review Date**: Enter the date of the last review of the machine.
* **Technician Signature**: Sign as the technician performing the inspection or assessment.
* **Manager Signature**: Sign as the person authorizing the assessment and ensuring the machine is safe to operate.
