# Pool Water Testing Form - Help Guide
## Purpose
The Pool Water Testing Form is used to record and report on the results of pool water testing. This includes the test methods used, water samples taken, and any notable comments or results.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the general information tab.
2. In the **General Information** field, enter a brief description of the test, including the pool location and any other relevant details.
3. In the **Test Methods** field, select all the methods used to test the pool water. You can select one or more options.
4. In the **Water Samples** field, select the sample type taken from the pool.
5. In the **Results** field, enter the test results for each sample taken.
6. In the **Comments** field, enter any additional comments or notes about the test.

## Field-by-Field Explanation
- **General Information (General Information)**: Enter a brief description of the test, including the pool location and any other relevant details.
  * This field is optional, but provides context for the test results.
- **Test Methods (Test Methods)**: Select all the methods used to test the pool water. You can select one or more options.
  * You can choose one or more test methods to report on.
  * Options: Option 1, Option 2, Option 3
- **Water Samples (Water Samples)**: Select the sample type taken from the pool.
  * Options: Option 1, Option 2, Option 3
- **Results (Results)**: Enter the test results for each sample taken.
  * This field is optional, but provides detailed information about the test results.
- **Comments (Comments)**: Enter any additional comments or notes about the test.
  * This field is optional, but provides further context for the test results.

## Tips
* Make sure to select all relevant test methods and sample types for accurate reporting.
* Enter clear and concise comments to provide context for the test results.
* Review and verify the test results carefully before submitting the form.
