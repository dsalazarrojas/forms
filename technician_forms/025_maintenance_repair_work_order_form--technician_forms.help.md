# Maintenance Repair Work Order Form - Help Guide
## Purpose
This form is used to document and track work orders related to maintenance and repair activities on site.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the work order from the dropdown menu.
2. Enter the location where the maintenance or repair is being performed.
3. Provide a brief description of the equipment being serviced.
4. Enter the equipment's serial number, if applicable.
5. Select the status of the work order.
6. Choose the technician assigned to the work order.
7. Input the date and time of completion, if applicable.
8. Add any notes or comments about the job.
9. Enter the contact information of the individual who initiated the work order.
10. Provide any additional comments or notes.

## Field-by-Field Explanation
* **Work Order Form** (Page 1): Enter a brief description of the maintenance or repair work order.
* **Category* (Page 1): Select the category of the work order from:
	+ Electrical
	+ Plumbing
	+ HVAC
* **Location** (Page 1): Enter the location where the maintenance or repair is being performed.
* **Equipment Description** (Page 1): Provide a brief description of the equipment being serviced.
* **Equipment Serial Number** (Page 1): Enter the serial number of the equipment, if applicable.
* **Work Order Number** (Page 1): Enter a unique identifier for the work order, if required.
* **Job Status* (Page 2): Select the current status of the work order from:
	+ Open
	+ In Progress
	+ Complete
* **Technician* (Page 2): Choose the technician assigned to the work order from:
	+ John Doe
	+ Jane Doe
	+ Bob Smith
* **Date Completed* (Page 2): Input the date of completion, if applicable.
* **Time Completed* (Page 2): Input the time of completion, if applicable.
* **Notes** (Page 3): Add any notes or comments about the job.
* **Email** (Page 3): Enter the contact information of the individual who initiated the work order.
* **Phone** (Page 3): Enter the phone number of the individual who initiated the work order.
* **Comments** (Page 3): Provide any additional comments or notes from:
	+ Yes
	+ No
	+ Maybe
* **Additional Comments** (Page 3): Provide any additional comments or notes about the job.
* **Repair Status* (Page 4): Select the repair status from:
	+ Needs Repair
	+ Does Not Need Repair
	+ Unknown

Note: Fields marked with an asterisk (*) are required.
