# Truck Trailer Repair Request Form - Help Guide
## Purpose
The Truck Trailer Repair Request Form is used to request repair services for a truck trailer. This form will help the repair team to gather all necessary information to fix the trailer as quickly and efficiently as possible.

## How To Complete This Form
To complete this form, follow the steps below:

1.  Answer the "Trailer Type" question with "Yes" if the trailer needs repair, otherwise select "No".
2.  Enter the trailer's "Make" and "Model" in the corresponding text fields.
3.  Provide the "Trailer Location" where the issue was found.
4.  Enter the dates when the trailer was last used and is expected to be returned ("Date In" and "Date Out").
5.  If applicable, enter the current "Mileage" of the trailer.

## Field-by-Field Explanation

*   **Trailer Type (`trailer_type`, select_one, required: false)**: Please indicate if the trailer indeed requires repair. Select "Yes" if it does, "No" otherwise.
*   **Trailer Make (`trailer_make`, text, required: false)**: Enter the trailer's make (e.g., Peterbilt, Mack, etc.).
*   **Trailer Model (`trailer_model`, text, required: false)**: Enter the trailer's model number or type (e.g., 1x6, etc.).
*   **Trailer Location (`trailer_location`, text, required: false)**: Provide the exact location where the trailer was found or is currently located (e.g., warehouse, farm, etc.).
*   **Date In (`date_in`, date, required: false)**: Enter the date when the trailer was last used before the issue occurred.
*   **Date Out (`date_out`, date, required: false)**: Enter the date when the trailer is expected to be returned to service.
*   **Trailer Mileage (`trailer_mileage`, number, required: false)**: If applicable, enter the current mileage of the trailer.

Note: If you're unsure about any of the information, please do not hesitate to contact the repair team for assistance.
