# equipment_order_form - Help Guide
## Purpose
The equipment order form is a tool used by technicians to collect vital information from customers for efficient order processing.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields marked with an asterisk (\*).
2. For the 'Equipment Type' field, select all applicable options from the provided list.
3. Ensure the 'Order Date' is formatted as 'mm/dd/yyyy' (e.g., 01/15/2024).
4. Enter the correct 'Equipment Model' and 'Quantity Ordered' numbers.
5. Enter the 'Cost' in the specified format.
6. If desired, include any 'Comments' for additional context.
7. Provide your 'Email' and 'Phone' for communication purposes.

## Field-by-Field Explanation
* **Order Details** (`equipment_order_form_1`, text, required): This field is a brief description of the order.
* **Employee Information** (`equipment_order_form_2`, text, optional): This is a field for employee details, if applicable.
* **Order Date** (`equipment_order_form_3`, date, required): Enter the date of the order in the 'mm/dd/yyyy' format.
* **Equipment Type** (`equipment_order_form_4`, select multiple, required): Select all applicable equipment types from the provided list.
* **Equipment Model** (`equipment_order_form_5`, text, required): Enter the model of the equipment ordered.
* **Quantity Ordered** (`equipment_order_form_6`, number, required): Enter the number of units ordered.
* **Cost** (`equipment_order_form_7`, number, required): Enter the cost in the format specified.
* **Comments** (`equipment_order_form_8`, note, optional): Provide any additional comments or context about the order.
* **Email** (`equipment_order_form_9`, email, optional): Enter your email address for communication purposes.
* **Phone** (`equipment_order_form_10`, text, optional): Enter your phone number for communication purposes.

## Tips
- Ensure all required fields are filled in before submitting the form.
- Review the form before submitting to prevent errors.
- Double-check the 'Order Date' format to avoid errors.
