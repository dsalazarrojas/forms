# satellite_technician_service_request - Help Guide
## Purpose
The satellite_technician_service_request form is used by technicians to document and track satellite-related service requests. This form helps in providing detailed information about the customer's satellite, service request, and technician's progress.

## How To Complete This Form
1. Review the customer's information, including their name, contact details, and address.
2. Enter the satellite's location, appointment details, and equipment information.
3. Provide a brief description of the service request, including any specific issues or concerns.
4. Confirm with the customer if they are available for the scheduled service.
5. Enter the technician's availability and schedule for the service request.
6. Add any additional notes or comments for the technician's reference.
7. Submit the form to create a service request record.

## Field-by-Field Explanation

* **Customer Information** (`customer_info`, text, not required): Enter the customer's name, contact details, and address.
* **Appointment Details** (`appointment_details`, text, not required): Enter the appointment date, time, and any other relevant details.
* **Satellite Location** (`satellite_location`, text, not required): Enter the satellite's location, including the address or coordinates.
* **Technician Notes** (`technician_notes`, text, not required): Add any notes or comments for the technician's reference.
* **Satellite Equipment** (`satellite_equipment`, text, not required): Enter the satellite's equipment details, such as model or serial number.
* **Service Request Date** (`service_request_date`, date, not required): Select the date for the service request.
* **Service Request Time** (`service_request_time`, time, not required): Select the time for the service request.
* **Customer Confirmation** (`customer_confirmation`, select one, not required): Confirm with the customer if they are available for the scheduled service. Options: 'Yes', 'No'.
* **Customer Confirmation Email** (`customer_confirmation_email`, email, not required): Enter the customer's email address for confirmation.
* **Customer Confirmation Phone** (`customer_confirmation_phone`, text, not required): Enter the customer's phone number for confirmation.
* **Satellite Status** (`satellite_status`, select multiple, not required): Select the satellite's status. Options: 'Active', 'Inactive', 'Offline'.
* **Technician Name** (`technician_name`, text, not required): Enter the technician's name who will perform the service.
* **Service Request Comments** (`service_request_comments`, text, not required): Add any additional comments or details for the service request.
* **Service Schedule** (`service_schedule`, text, not required): Enter the technician's schedule for the service request.
* **Follow Up Date** (`follow_up_date`, date, not required): Select the follow-up date for the service request.
* **Technician Schedule** (`technician_schedule`, text, not required): Enter the technician's availability for the service request.
* **Satellite Address** (`satellite_address`, text, not required): Enter the satellite's address.
* **Satellite Notes** (`satellite_notes`, text, not required): Add any additional notes or comments for the satellite's reference.
* **Customer Address** (`customer_address`, text, not required): Enter the customer's address.
* **Customer Service Request** (`customer_service_request`, text, not required): Enter the customer's service request details.
* **Service Request Priority** (`service_request_priority`, select one, not required): Select the service request priority. Options: 'Low', 'Medium', 'High'.
* **Service Request Type** (`service_request_type`, select multiple, not required): Select the service request type. Options: 'Scheduled', 'Urgent', 'Routine'.
* **Technician Availability** (`technician_availability`, text, not required): Enter the technician's availability for the service request.
* **Technician Availability Date** (`technician_availability_date`, date, not required): Select the date for the technician's availability.
* **Submitted By** (`submitted_by`, text, not required): Enter the person submitting the service request.
