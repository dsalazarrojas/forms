# Hardware Survey Form - Help Guide

## Purpose
The Hardware Survey Form is designed for technicians to gather detailed information about a computer's hardware specifications for maintenance, troubleshooting, or upgrade purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. **Start by filling out the Hardware Survey page, where you'll capture the overall survey purpose.**
2. For each question, select the relevant option from the list or enter the correct information.
3. **Ensure all required fields are completed before submitting the form.**

## Field-by-Field Explanation

* **Hardware Survey** (Page 1): This is the starting point of the survey. Please enter a brief description of the computer's current state.
* **Operating System** (Page 2):
	+ **Label:** Operating System
	+ **Type:** Select one of the following options: MS Windows, Linux, or Mac OS.
	+ **Purpose:** Record the operating system currently running on the computer.
* **Processor Type** (Page 3):
	+ **Label:** Processor Type
	+ **Type:** Select one of the following options: i3, i5, or i7.
	+ **Purpose:** Record the type of processor installed in the computer.
* **Computer Age** (Page 4):
	+ **Label:** Computer Age
	+ **Type:** Enter the age of the computer in years.
	+ **Purpose:** Track the computer's age for maintenance or upgrade planning.
* **Operating System Version** (Page 5):
	+ **Label:** Operating System Version
	+ **Type:** Enter the version of the operating system installed.
	+ **Purpose:** Record the version of the operating system installed on the computer.
* **Processor Version** (Page 6):
	+ **Label:** Processor Version
	+ **Type:** Select one of the following options: i3 10th Gen, i5 10th Gen, or i7 10th Gen.
	+ **Purpose:** Record the version of the processor installed.
* **Motherboard Type** (Page 7):
	+ **Label:** Motherboard Type
	+ **Type:** Select one of the following options: Intel, AMD, or NVIDIA.
	+ **Purpose:** Record the type of motherboard installed.
* **Monitor Size** (Page 8):
	+ **Label:** Monitor Size
	+ **Type:** Enter the size of the monitor in inches.
	+ **Purpose:** Record the size of the monitor attached to the computer.
* **Monitor Resolution** (Page 9):
	+ **Label:** Monitor Resolution
	+ **Type:** Enter the resolution of the monitor (e.g., 1080p, 4K, etc.).
	+ **Purpose:** Record the resolution of the monitor.
* **Computer Model** (Page 10):
	+ **Label:** Computer Model
	+ **Type:** Enter the model of the computer.
	+ **Purpose:** Capture the specific model of the computer.

## Tips

* Ensure all required fields are completed before submitting the form.
* If a field is not relevant, please leave it blank or select "N/A" (Not Applicable).
* If you're unsure about any field, contact a technician or the system administrator for guidance.
