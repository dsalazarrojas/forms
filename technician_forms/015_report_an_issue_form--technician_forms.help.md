# Report An Issue Form - Help Guide
## Purpose
The Report An Issue Form is designed to collect information about issues reported by users, allowing your team to efficiently track and resolve these issues. Please use this form to report any problems, errors, or concerns you're experiencing, and we'll do our best to address them promptly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with as much detail as possible.
2. Select the correct issue type and location from the available options.
3. If applicable, attach a relevant image or file to provide further context.
4. Select the priority level of the issue.
5. Choose the status of the issue.
6. Select the person responsible for creating and updating the issue.
7. Select the date and time of when the issue was created and last updated.
8. Fill in the issue number (if available).
9. Select the report date range (if applicable).

## Field-by-Field Explanation

### 1. **Report Description** (report_an_issue_form)
Provide a detailed description of the issue you're experiencing.

### 2. **Report Description** (issue_description)
Provide a detailed description of the issue you're experiencing.

### 3. **Issue Type** (issue_type)
Select one or more issues types that best describe the problem: Problem, Error, or Concern.

### 4. **Location** (issue_location)
Select the location where the issue occurred: Head Office, Server Room, or Other.

### 5. **Submitter Information** (submitter_info)
This field is not currently being used. You can skip this field.

### 6. **Submitter Email** (submitter_email)
Enter the email address of the submitter, if applicable.

### 7. **Submitter Phone** (submitter_phone)
Enter the phone number of the submitter, if applicable.

### 8. **Submitter Comments** (submitter_comments)
Leave any additional comments or information you'd like to include about the submitter.

### 9. **Image or Video** (issue_image)
Attach an image or video that illustrates the issue, if applicable.

### 10. **Attach File** (issue_attach)
Attach a file that provides further context about the issue, if applicable.

### 11. **Priority** (issue_priority)
Select the priority level of the issue: High, Medium, or Low.

### 12. **Status** (issue_status)
Select the current status of the issue: Open, In Progress, or Closed.

### 13. **Created By** (created_by)
Select the person responsible for creating the issue: Technician or Customer.

### 14. **Updated By** (updated_by)
Select the person responsible for updating the issue: Technician or Customer.

### 15. **Created Date** (created_date)
Select the date and time when the issue was created.

### 16. **Updated Date** (updated_date)
Select the date and time when the issue was last updated.

### 17. **Created Time** (created_time)
Select the time when the issue was created.

### 18. **Updated Time** (updated_time)
Select the time when the issue was last updated.

### 19. **Issue Number** (issue_number)
Enter the issue number, if applicable.

### 20. **Issue Number 2** (issue_number2)
Enter the issue number, if applicable.

### 21. **Report Date** (report_date)
Select the date range for the report: Last 30, Last 7, or Last 1.

### 22. **Notes** (submitter_notes)
Leave any additional comments or information you'd like to include.

### 23. **Assignee** (assignee)
Select the person responsible for resolving the issue: Technician or Customer.

### 24. **Reportee** (reportee)
Select the person reporting the issue: Technician or Customer.

### 25. **Issue Type** (issue_type2)
Select one or more issue types that best describe the problem: Problem, Error, or Concern.
