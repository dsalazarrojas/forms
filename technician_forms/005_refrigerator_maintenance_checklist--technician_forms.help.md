# Refrigerator Maintenance Checklist - Help Guide
## Purpose
The Refrigerator Maintenance Checklist is a form designed to collect information about the status of various components and settings of a refrigerator. It is used to help identify any issues that may need to be addressed for optimal performance and efficiency of the appliance.

## How To Complete This Form

1. Ensure you have the following information:
	* Your refrigerator's ID number (if applicable)
	* A clear workspace with the refrigerator's components easily accessible
2. Go through each section of the form, carefully checking each component and setting as described. For each component, select the corresponding status from the options provided.

## Tips

* Ensure to carefully inspect each component before selecting a status.
* If a component is not functioning, note it as "Not Found" and indicate why it is not working.
* Use the provided options to select the status that best represents the current condition of each component.
* Take note of any issues or malfunctions observed during the inspection, and document them as needed.
