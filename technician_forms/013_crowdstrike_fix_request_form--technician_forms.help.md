# CrowdStrike Fix Request Form - Help Guide
## Purpose
The CrowdStrike Fix Request Form is used to collect information about technical issues that require attention from the support team. It's essential to accurately report these issues so that we can prioritize and resolve them efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Customer Details** section with the customer's information.
2. Provide a clear and concise description of the **Issue Description** in the second section.
3. Select the **Issue Type** that best describes the problem you're trying to fix (e.g., Bug, Feature Request, or Other).
4. Estimate the **Expected Resolution Time** in the format "X hours" or "X minutes" (e.g., "4 hours" or "15 minutes").
5. In the **Assigned Technician** section, select one or more technicians who are most suitable to handle the issue.
6. Add any additional comments or details in the **Comment** field.
7. Click the **Submit** button to send the request to the support team.

## Field-by-Field Explanation

* **Customer Details**: Enter the customer's name, email address, and any other relevant contact information.
* **Issue Description**: Provide a clear and concise explanation of the problem you're trying to fix. Try to include as much detail as possible, including error messages, steps to reproduce the issue, and any other relevant information.
* **Issue Type**: Select the type of issue you're trying to fix:
	+ Bug: A problem that prevents the system from functioning as expected.
	+ Feature Request: A new feature or enhancement you'd like to see added to the system.
	+ Other: A request for general technical assistance or support.
* **Expected Resolution Time**: Estimate the time it should take to resolve the issue. For example, "4 hours" or "15 minutes".
* **Assigned Technician**: Select one or more technicians who you think are most suitable to handle the issue.
* **Comment**: Add any additional comments or details about the issue.
* **Submit**: Click this button to send the request to the support team.
