# Nail Technician Team Review Appointment Form - Help Guide
## Purpose
The "Nail Technician Team Review Appointment Form" is used by the salon management team to evaluate and schedule meetings with the nail technicians.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the provided fields and determine which ones you need to fill out for the current meeting.
2. Fill out the form with the relevant information, such as meeting details, ratings, and comments.
3. Select the correct options for the meeting attendees, location, and other required fields.
4. Submit the form to schedule the meeting and provide feedback to the technician.

## Field-by-Field Explanation

* **Salon Details** (`salon_details`, text, optional)
	+ Enter a brief description of the salon or location where the meeting will take place.
* **Team Review** (`team_review`, text, optional)
	+ Provide a brief description of the purpose of the meeting and any relevant feedback or concerns.
* **Meeting Details** (`meeting_details`, text, optional)
	+ Enter the details of the meeting, including date, time, and any other relevant information.
* **Technician Performance** (`technician_performance`, text, optional)
	+ Evaluate the technician's performance during the meeting using the rating options provided.
* **Meeting Comments** (`meeting_comments`, text, optional)
	+ Enter any additional comments or feedback for the meeting.
* **Salon Manager Details** (`salon_manager_details`, text, optional)
	+ Enter any relevant information about the salon manager or management team.
* **Meeting Notes** (`meeting_notes`, text, optional)
	+ Enter any notes or action items from the meeting.
* **Technician Comments** (`technician_comments`, text, optional)
	+ Enter any comments or feedback for the technician.
* **Review Rating** (`review_rating`, number, optional)
	+ Evaluate the overall review rating for the technician using the provided number rating system.
* **Review Comments** (`review_comments`, text, optional)
	+ Enter any additional comments or feedback for the review.
* **Overall Rating** (`overall_rating`, number, optional)
	+ Evaluate the overall rating for the technician using the provided number rating system.
* **Meeting Schedule** (`meeting_schedule`, date, optional)
	+ Enter the scheduled date for the meeting.
* **Start Time** (`start_time`, time, optional)
	+ Enter the start time for the meeting.
* **End Time** (`end_time`, time, optional)
	+ Enter the end time for the meeting.
* **Meeting Duration** (`meeting_duration`, number, optional)
	+ Enter the duration of the meeting.
* **Meeting Topic** (`meeting_topic`, text, optional)
	+ Enter the topic or subject of the meeting.
* **Meeting Attendees** (`meeting_attendees`, select_multiple, optional)
	+ Select whether the meeting will include attendees or not.
* **Meeting Location** (`meeting_location`, text, optional)
	+ Enter the location where the meeting will take place.
* **Salon Phone** (`salon_phone`, text, optional)
	+ Enter the phone number for the salon.
* **Salon Address** (`salon_address`, text, optional)
	+ Enter the address of the salon.
* **Technician Name** (`technician_name`, text, optional)
	+ Enter the name of the technician being reviewed.
* **Technician Email** (`technician_email`, email, optional)
	+ Enter the email address of the technician.
* **Technician Phone** (`technician_phone`, text, optional)
	+ Enter the phone number for the technician.
* **Technician Notes** (`technician_notes`, text, optional)
	+ Enter any notes or comments for the technician.
* **Submit** (`submit`, select_one, optional)
	+ Select whether to submit the form and schedule the meeting.

Note: Required fields are marked as "required: true" and will be highlighted in the form. Optional fields will not be highlighted.
