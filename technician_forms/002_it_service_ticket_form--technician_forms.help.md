# it_service_ticket_form - Help Guide
## Purpose
This form is used to submit tickets for IT services.

## How To Complete This Form

To complete this form, follow these steps:

*   Select whether or not you want to submit the ticket.
*   Choose the category of the ticket.
*   Enter a description of the issue.
*   Select the priority level of the ticket.
*   Choose which technician the ticket is assigned to.
*   Set the due date for the ticket.
*   Select the status of the ticket.
*   Add any additional notes about the issue.
*   Enter a contact email address.
*   Enter a contact phone number.
*   Select the categories associated with the ticket.
