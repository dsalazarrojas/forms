# Work Ticket Form - Help Guide
## Purpose
The Work Ticket Form is used to create and manage work tickets. It is intended for requesting and tracking tasks that require attention from the technical team.

## How To Complete This Form
To complete this form, follow these steps:

* Start by filling in the **Requesting** field. This is an open text field where you can enter any information or comments you need to provide context for the ticket.
* Next, select an option for **Priority**, which indicates the urgency level of the ticket. Please note that this field is optional.
* Then, select an option for **Ticket Type**, which indicates the type of ticket you are submitting. Again, this field is optional.
* Finally, provide a brief **Summary** of the issue or task that requires attention. This field is also optional.

## Field-by-Field Explanation

* **Requesting**:
	+ (Text field)
	+ Optional

	+ Enter any information or comments you need to provide context for the ticket.

* **Priority**:
	+ (Select One field)
	+ Optional

	+ This field determines the urgency level of the ticket. Please note that this field is not required but recommended to help the technical team prioritize tasks.

* **Ticket Type**:
	+ (Select One field)
	+ Optional

	+ This field indicates the type of ticket you are submitting. Selecting one of the options will help the technical team understand the nature of the task.

* **Summary**:
	+ (Text field)
	+ Optional

	+ Enter a brief description of the issue or task that requires attention. This field is useful for providing context to the technical team.
