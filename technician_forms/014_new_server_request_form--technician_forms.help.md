# New Server Request Form - Help Guide

## Purpose
The New Server Request Form is used to collect information about a new server request from a customer or internal team member.

## How To Complete This Form

### To complete this form, follow these steps:

1. **Server Request Form** (`server_request_form`)
	* Enter a brief description of the server request.
2. **Product Details** (`product_details`)
	* Enter the name and version of the product related to the server request.
3. **Operating Environment** (`operating_environment`)
	* Enter the operating system and version that will be used for the server.
4. **Server Request Details** (`server_request_details`)
	* Enter a detailed description of the server request.
5. **Server Request Form Submitted** (`server_request_form_submitted`)
	* Check 'Yes' if this is a new server request, 'No' if you are revising or updating an existing request.
6. **Product Name** (`product_name`)
	* Enter the name of the product related to the server request.
7. **Product Version** (`product_version`)
	* Enter the version of the product related to the server request.
8. **Operating System** (`operating_system`)
	* Select the operating system that will be used for the server (Windows, Linux, macOS, or Other).
9. **Operating System Version** (`operating_system_version`)
	* Enter the version of the operating system that will be used for the server.
10. **RAM Size** (`ram_size`)
	* Enter the amount of RAM required for the server.
11. **CPU Type** (`cpu_type`)
	* Select the type of CPU that will be used for the server (Intel Core i5, AMD Ryzen 7, or Other).
12. **CPU Speed** (`cpu_speed`)
	* Enter the speed of the CPU required for the server.
13. **Storage Type** (`storage_type`)
	* Select the storage type that will be used for the server (256 GB, 512 GB, 1 TB, or Other).
14. **Storage Size** (`storage_size`)
	* Enter the storage size required for the server.
15. **Request Date** (`request_date`)
	* Enter the date when the server request was made.
16. **Request Time** (`request_time`)
	* Enter the time when the server request was made.
17. **Server Request Form URL** (`server_request_form_url`)
	* Enter the URL of the server request form, if applicable.
18. **Notes** (`notes`)
	* Enter any additional notes or comments about the server request.
19. **Email** (`email`)
	* Enter your email address for follow-up communication.
20. **Phone** (`phone`)
	* Enter your phone number for follow-up communication.
