# it_operation_checklist - Help Guide
## Purpose

The "it_operation_checklist" form is a comprehensive checklist for IT personnel to assess the operational status of a system or server. It provides a detailed overview of various system and network parameters, enabling technicians to quickly identify potential issues and take corrective actions.

## How To Complete This Form

1. To complete this form, select each field to indicate its current status.
2. Ensure that you select the correct status for each field based on your knowledge of the system or server.
3. If a field does not apply, select "N/A" (Not Applicable) or "Unknown".
4. Complete all fields that are relevant to your assessment.

## Field-by-Field Explanation

* **check_status**: Check the status of the system or server, selecting "Active" if it is currently in operation, and "Inactive" if it is not.
	+ Type: Select One
	+ Required: False
* **power_on_off**: Confirm if the system or server is currently powered on or off.
	+ Type: Select Multiple
	+ Required: False
* **network_connections**: Specify the number of network connections currently established.
	+ Type: Number
	+ Required: False
* **ram_usage**: Enter the current RAM usage of the system or server.
	+ Type: Number
	+ Required: False
* **cpu_usage**: Check the CPU usage status, selecting "Yes" if it is high, and "No" if it is normal.
	+ Type: Select One
	+ Required: False
* **disk_space**: Confirm if disk space is full or not.
	+ Type: Select Multiple
	+ Required: False
* **system_time**: Specify the system time, if applicable.
	+ Type: Time
	+ Required: False
* **operating_system**: Select the operating system currently installed.
	+ Type: Select One
	+ Required: False
* **installed_apps**: List the installed applications.
	+ Type: Select Multiple
	+ Required: False
* **user_accounts**: Confirm if user accounts are active or not.
	+ Type: Select Multiple
	+ Required: False
* **system_updates**: Check if system updates are currently installed.
	+ Type: Select One
	+ Required: False
* **network_speed**: Confirm if network speed is good or not.
	+ Type: Select Multiple
	+ Required: False
* **network_protocols**: Specify the network protocols currently enabled.
	+ Type: Select One
	+ Required: False
* **network_interfaces**: List the network interfaces currently active.
	+ Type: Select Multiple
	+ Required: False
* **network_adapters**: Confirm if network adapters are currently enabled.
	+ Type: Select Multiple
	+ Required: False
* **network_address**: Confirm if the system has a network address.
	+ Type: Select One
	+ Required: False
* **server_status**: Check the server status, selecting "Active" if it is currently serving, and "Inactive" if it is not.
	+ Type: Select One
	+ Required: False
* **system_status**: Confirm the system status, selecting "Active" if it is currently operational, and "Inactive" if it is not.
	+ Type: Select One
	+ Required: False
* **system_uptime**: Confirm if the system is currently up or not.
	+ Type: Select One
	+ Required: False
* **system_reboot**: Confirm if the system has been rebooted recently.
	+ Type: Select One
	+ Required: False
* **user_login**: Confirm if user login is enabled or not.
	+ Type: Select Multiple
	+ Required: False
* **network_firewall**: Confirm if network firewall is active or not.
	+ Type: Select Multiple
	+ Required: False
* **system_patches**: List the system patches currently installed.
	+ Type: Select Multiple
	+ Required: False
* **system_backups**: Confirm if system backups are currently enabled.
	+ Type: Select Multiple
	+ Required: False
* **system_patches** ( duplicate field ): Ignore this field as it is a duplicate of "system_patches".
