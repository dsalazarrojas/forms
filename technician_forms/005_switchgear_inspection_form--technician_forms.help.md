# Switchgear Inspection Form - Help Guide
## Purpose
This form is for conducting an inspection of switchgear items to ensure they are functioning correctly and safely.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant switchgear item from the "switchgear_item" dropdown list.
2. Record the date of the inspection in the "date" field.
3. Answer the following questions about the switchgear item:
	* Is the switchgear item in good condition? (switchgear_condition)
	* Is the switchgear item in an active state? (switchgear_rack_status)
	* Is the switchgear item mounted on a switchgear rack? (switchgear_rack_mounting)
	* Is the switchgear item connected? (switchgear_connection_type)
	* Has the switchgear item been previously inspected? (switchgear_ins_reported)
	* Has the switchgear item been checked? (switchgear_ins_checked)
	* Record any notes about the switchgear item (switchgear_ins_notes)
	* Select any action items that need to be taken (switchgear_ins_action_items)
	* Record the date the switchgear item was inspected (switchgear_ins_date_inspected)
	* Record any remarks about the inspection (switchgear_ins_remark)

## Field-by-Field Explanation
* **switchgear_item** (Select One): Select the switchgear item being inspected.
* **date** (Date): Record the date of the inspection.
* **switchgear_condition** (Select One): Answer "Yes" if the switchgear item is in good condition, "No" otherwise.
* **switchgear_rack_status** (Select One): Answer "Active" if the switchgear item is active, "Inactive" otherwise.
* **switchgear_rack_mounting** (Select One): Answer "Yes" if the switchgear item is mounted on a switchgear rack, "No" otherwise.
* **switchgear_connection_type** (Select One): Answer "Yes" if the switchgear item is connected, "No" otherwise.
* **switchgear_ins_reported** (Select One): Answer "Yes" if the switchgear item has been previously inspected, "No" otherwise.
* **switchgear_ins_checked** (Select One): Answer "Yes" if the switchgear item has been previously checked, "No" otherwise.
* **switchgear_ins_notes** (Note): Record any notes about the switchgear item.
* **switchgear_ins_action_items** (Select Multiple): Select any action items that need to be taken.
* **switchgear_ins_date_inspected** (Date): Record the date the switchgear item was inspected.
* **switchgear_ins_remark** (Note): Record any remarks about the inspection.
