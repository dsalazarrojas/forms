# CrowdStrike Issue Form - Help Guide
## Purpose
The CrowdStrike Issue Form is used to submit issues that require attention from the technical team. This form ensures that all relevant details about the issue are captured efficiently.

## How To Complete This Form
- Start by filling in the issue title, a brief description of the problem, and any further information that might aid the technical team in resolving it.
- Enter the date and time the issue was first observed, as well as the location.
- If applicable, provide the date and time the issue recurred, along with the location again.
- Describe the steps taken to investigate or resolve the issue.
- Select the current status of the issue from the available options (Open, In Progress, Closed).
- If you have already spoken with a technician, select the assigned technician or choose "Other" if the technician is not on the list.

## Field-by-Field Explanation
* **Issue Title** (1): A brief title of the issue.
* **Issue Description** (2): A detailed description of the issue, including any relevant background information.
* **Date First Observed** (3): The date the issue was first noticed.
* **Time First Observed** (4): The time the issue was first noticed.
* **Location First Observed** (5): The location where the issue was first observed.
* **Date Second Observed** (6): If the issue recurred, enter the date it happened again. 
* **Time Second Observed** (7): If the issue recurred, enter the time it happened again.
* **Location Second Observed** (8): If the issue recurred, enter the location where it happened again.
* **Steps Taken** (9): Briefly describe any actions taken to address or investigate the issue.
* **Issue Status** (10): Select the current status of the issue from the given options.
* **Assigned Technician** (11): Select the technician already assigned to the issue or choose "Other" if not applicable.
