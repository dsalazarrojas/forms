# golf_cart_daily_inspection_form - Help Guide
## Purpose
This form is for performing a daily inspection of a golf cart. It ensures that all critical systems and components are in good working condition, ready for safe operation.

## How To Complete This Form
To complete this form, follow these steps:

1. Go to the golf cart to be inspected.
2. Conduct a thorough inspection of the cart, checking each component.
3. Select the appropriate option for each component from the list provided.
4. Enter any comments or notes about the inspection in the "Comments" field.
5. Submit the form when complete.

## Field-by-Field Explanation
* **General Inspection** (`1`, `text`, required): A brief overview of the cart's overall condition.
* **Brakes** (`2`, `select_one`, required): Check if the brakes are:
	+ Good: Functioning properly.
	+ Fair: Functioning but showing signs of wear or degradation.
	+ Poor: Not functioning at all.
* **Suspension System** (`3`, `select_multiple`, required): Check if the suspension system is:
	+ Good: Functioning properly.
	+ Needs Adjustment: Needs minor adjustments to function properly.
	+ Failed: Not functioning at all.
	+ Not Inspected: Not inspected in this check.
* **Engine** (`4`, `select_one`, required): Check if the engine is:
	+ Good: Functioning properly.
	+ Needs Service: Showing signs of wear or degradation, needs maintenance.
	+ Failed: Not functioning at all.
* **Frame and Body** (`5`, `select_multiple`, required): Check if the frame and body are:
	+ Good: No damage or wear.
