# ticket_incident_portal_for_it_issues_form - Help Guide
## Purpose
The ticket incident portal for IT issues form is used to report incidents related to IT issues. It helps IT staff gather information to troubleshoot and resolve issues efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select whether you have submitted this form before.
2. Fill out the Incident Details field with a brief description of the issue.
3. Choose the category of the issue (Hardware, Software, or Networking).
4. Select the type of issue (e.g., Hardware, Software, Networking).
5. Select the severity of the issue (Low, High, Critical).
6. Choose the priority of the issue (Low, High, Critical).
7. Click the "Submit" button to submit the form.

## Field-by-Field Explanation

* **Submit** (Submit Button, Select One, Required: False): This field allows you to confirm whether you have submitted this form before or not.
* **Incident Details** (incident_details, Text, Required: False): Briefly describe the issue here. This field is used to provide a clear understanding of the problem.
* **Incident Type** (incident_type, Select Multiple, Required: False): This field allows you to select one or multiple types of issues related to the incident (e.g., Hardware, Software, Networking).
* **Incident Category** (incident_category, Select Multiple, Required: False): This field allows you to choose one or multiple categories related to the incident (e.g., Hardware, Software, Networking).
* **Incident Severity** (incident_severity, Select One, Required: False): This field allows you to select the severity of the issue (Low, High, Critical).
* **Incident Priority** (incident_priority, Select One, Required: False): This field allows you to select the priority of the issue (Low, High, Critical).
* **Incident Description** (incident_description, Text, Required: False): This field is used to provide a brief description of the issue.
* **Incident Submission** (submit_button, Select One, Required: False): This field allows you to confirm or deny that you have submitted this form before.
