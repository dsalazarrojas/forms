# Equipment Return Form - Help Guide
## Purpose
This form is used to document the return of equipment after it has been borrowed by a student or teacher.

## How To Complete This Form
- Make sure you are returning equipment that you have borrowed or that has been borrowed by someone else.
- Review each field carefully to ensure you provide accurate information.
- If you're unsure about any field, contact the equipment inventory team for clarification.

## Field-by-Field Explanation

* **School equipment borrowed**: Please enter the school equipment that you are returning. This field is for your reference, and it's not required.
* **Return Date**: Enter the date when you return the equipment. This is used for tracking purposes. If you're unsure, check the equipment's due date or ask the inventory team.
* **Remarks**: Add any additional comments or details about the return. This can be useful for staff or technicians for future reference.
* **Equipment returned**: Select whether the equipment was indeed returned from the options:
	+ Not yet: If the equipment is still not returned.
	+ Yes: If you are returning the equipment.
	+ No: If you are not returning the equipment.
* **Remarks details**: If you added any additional comments in the "Remarks" field, provide more details here.
* **Equipment returned**: Select whether the equipment was returned from the options:
	+ Not yet: If the equipment is still not returned.
	+ Yes: If you are returning the equipment.
	+ No: If you are not returning the equipment. (This field is similar to "Equipment returned" but has a one-choice select option.)
* **Staff comments**: Add any comments or details that staff might need to know. This can be helpful for staff to take necessary actions.
* **Teacher comments**: Add any comments or details that the teacher might need to know. This can be helpful for the teacher to be aware of the return and take necessary actions.

## Tips
- Review the form carefully to ensure all required fields are completed accurately.
- Double-check your answers for spelling and grammar mistakes.
- If you're unsure about any field, contact the equipment inventory team for clarification.
