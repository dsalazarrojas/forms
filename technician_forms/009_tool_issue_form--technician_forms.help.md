# Tool Issue Form - Help Guide
## Purpose
The Tool Issue Form is used to report issues with tools or equipment that need repair or replacement.

## How To Complete This Form
1. Fill out each page of the form, providing as much detail as possible.
2. Ensure you select "Yes" for "assigned_tool" if the issue is related to a specific tool.
3. Choose the "issue_type" that best describes the problem (e.g., "faulty", "missing").
4. Enter the date and time the issue was reported in the "date_reported" and "time_reported" fields.
5. Provide a brief description of the issue in the "description" field.
6. Enter the tool number (if applicable) in the "tool_number" field.
7. Select the status of the issue (e.g., "open", "closed") and the person who closed it (if applicable) in the "status" and "closed_by" fields.
8. Enter the date and time the issue was closed in the "closed_date" and "closed_time" fields.
9. Enter the issue number (if applicable) in the "submitted" field.
