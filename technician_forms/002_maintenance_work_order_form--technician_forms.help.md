# Maintenance Work Order Form - Help Guide
## Purpose
The Maintenance Work Order Form is used to document and track maintenance activities for equipment. This form is used to provide necessary information for technicians to perform maintenance tasks and for supervisors to monitor progress.

## How To Complete This Form
1. Fill in the equipment ID and description to identify the equipment being maintained.
2. Select the maintenance type from the options provided.
3. Enter the date and time submitted for the maintenance work order.
4. Enter the cost of maintenance if applicable.
5. Add any relevant notes to the maintenance work order.
6. Select the assigned technician(s) for the maintenance task.
7. Select the submitter of the maintenance work order.
8. Select the status of the maintenance work order.
9. Enter any additional details such as equipment serial number, equipment type, and maintenance type (if not already selected).
10. Enter the submitted date.

## Field-by-Field Explanation

* **equipment_id** (`equipment_id`, Number): Enter the unique ID for the equipment being maintained.
* **equipment_description** (`equipment_description`, Text): Provide a brief description of the equipment being maintained.
* **job_id** (`job_id`, Number): This field is currently not being used. Please ignore it.
* **maintenance_type** (`maintenance_type`, Select One): Select the type of maintenance required (e.g., "equipment id", "maintenance type 2", "maintenance type 3").
* **maintenance_type_2** (`maintenance_type_2`, Select One): Select an additional maintenance type (e.g., "maintenance type 2", "maintenance type 3", "maintenance type 4").
* **maintenance_type_3** (`maintenance_type_3`, Select One): Select an additional maintenance type (e.g., "maintenance type 2", "maintenance type 3", "maintenance type 4").
* **date_submitted** (`date_submitted`, Date): Enter the date the maintenance work order was submitted.
* **time_submitted** (`time_submitted`, Time): Enter the time the maintenance work order was submitted.
* **maintenance_cost** (`maintenance_cost`, Number): Enter the estimated cost of the maintenance work.
* **notes** (`notes`, Text): Add any additional comments or details for the maintenance work order.
* **assigned_technician** (`assigned_technician`, Select One): Select the technician assigned to perform the maintenance.
* **assigned_technician_1** (`assigned_technician_1`, Select One): Select an additional technician assigned to the maintenance.
* **assigned_technician_2** (`assigned_technician_2`, Select One): Select an additional technician assigned to the maintenance.
* **submitted_by** (`submitted_by`, Select One): Select who submitted the maintenance work order.
* **submitted_by_1** (`submitted_by_1`, Select One): This field is currently not being used. Please ignore it.
* **submitted_by_2** (`submitted_by_2`, Select One): This field is currently not being used. Please ignore it.
* **status** (`status`, Select One): Select the current status of the maintenance work order (e.g., "status 1", "status 2", "status 3").
* **status_1** (`status_1`, Select One): This field is currently not being used. Please ignore it.
* **status_2** (`status_2`, Select One): This field is currently not being used. Please ignore it.
* **equipment_serial_number** (`equipment_serial_number`, Text): Enter the serial number of the equipment being maintained.
* **equipment_type** (`equipment_type`, Text): Enter a brief description of the equipment type.
* **equipment_description_2** (`equipment_description_2`, Text): This field is currently not being used. Please ignore it.
* **maintenance_type_4** (`maintenance_type_4`, Text): This field is currently not being used for maintenance_type. Please use maintenance_type field.
* **submitted_date** (`submitted_date`, Date): Enter the date the maintenance work order was submitted.

## Tips
* Please fill out all required fields for accurate tracking and reporting.
* If additional maintenance types are needed, please select "maintenance type 2" or "maintenance type 3" from the options.
* If a technician is unable to perform the maintenance task, please select "Not assigned" from the options.
* If the status of the maintenance work order changes, please update the status field accordingly.
