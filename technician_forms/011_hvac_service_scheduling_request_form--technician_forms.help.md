# HVAC Service Scheduling Request Form - Help Guide

## Purpose
The HVAC Service Scheduling Request Form is used to collect information from customers to schedule an appointment for service. This form ensures that customers' service requests are handled efficiently and accurately.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill in the required fields marked with an asterisk (*).
2. Select the correct options for each field according to your preferences.
3. Make sure to fill in any additional information you'd like to provide to the technician who will be handling your request.
4. Submit the form once you have completed it.

## Field-by-Field Explanation

* **Scheduling Request**: Please enter a brief description of the service you need (max 255 characters).
	+ Type: text
	+ Required: false
* **Contact Info**: Please enter your email address so we can contact you to confirm your appointment.
	+ Type: email
	+ Required: true
* **Appointment Date**: Please select the date you'd like to schedule the service appointment.
	+ Type: date
	+ Required: true
* **Appointment Time**: Please select the time you'd like to schedule the service appointment.
	+ Type: time
	+ Required: false
* **Service Type**: Are you interested in a regular service or a maintenance visit?
	+ Type: select_one
	+ Required: true
* **Service Location**: Are you interested in scheduling for a service at your home, office, or elsewhere?
	+ Type: select_multiple
	+ Required: true
* **Description**: Is there anything else you'd like to tell us about the service you need?
	+ Type: text
	+ Required: false
* **Notes**: Is there anything else you'd like to add about your service request?
	+ Type: note
	+ Required: false
* **Tech Name**: Would you like to select a specific technician to handle your service request?
	+ Type: select_one
	+ Required: false
* **Tech Phone**: Is there a specific phone number you'd like to provide to contact the technician?
	+ Type: text
	+ Required: false
* **Repeated Appointment Date**: Please select the date you'd like to schedule a repeated service appointment. (Note: only if you want to schedule a repeated appointment)
	+ Type: date
	+ Required: false
* **Repeated Appointment Time**: Please select the time you'd like to schedule a repeated service appointment. (Note: only if you want to schedule a repeated appointment)
	+ Type: time
	+ Required: false
* **Repeated Service Type**: Are you interested in a regular service or a maintenance visit for the repeated appointment?
	+ Type: select_one
	+ Required: false
* **Repeated Service Location**: Are you interested in scheduling for a service at your home, office, or elsewhere for the repeated appointment?
	+ Type: select_multiple
	+ Required: false
* **Repeated Service Type 2**: (This field is not used and can be ignored)

## Tips
* Please make sure to fill in all required fields.
* If you're unsure about any field, please contact our support team for assistance.
* Please submit the form once you have completed it.
