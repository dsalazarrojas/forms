# Fire Alarm Inspection Form - Help Guide

## Purpose
This form is designed to collect data about the fire alarm system's status and configuration in a building or facility. The goal is to gather accurate information to ensure the system is functioning correctly and identify any potential issues.

## How To Complete This Form
To complete this form, simply answer each question in the corresponding field. You may need to refer to the system's documentation or manual for specific technical details.

## Field-by-Field Explanation

* **System Description (1)**: A brief description of the fire alarm system, including its location and purpose.
* **Fire Alarm System Location (2)**: The specific location of the fire alarm system within the building or facility.
* **Fire Alarm System Status (3)**: The overall status of the fire alarm system, including any issues or concerns.
* **Fire Alarm Control Panel Type (4)**: The type of control panel used in the system, such as Siemens or Honeywell.
* **Fire Alarm Control Panel Manufacturer (5)**: The manufacturer of the control panel.
* **Fire Alarm Control Panel Model (6)**: The model number of the control panel.
* **Fire Alarm Control Panel Serial Number (7)**: The serial number of the control panel.
* **Fire Alarm Control Panel Software Version (8)**: The software version of the control panel.
* **Fire Alarm Panel Board Status (9)**: The status of the panel board, including any issues or concerns.
* **Fire Alarm Main Panel Status (10)**: The status of the main panel, including any issues or concerns.
* **Fire Alarm Annunciation Status (11)**: The status of the annunciation system, including any issues or concerns.
* **Fire Alarm Annunciation Speaker Status (12)**: The status of the annunciation speaker, including any issues or concerns.
* **Fire Alarm Annunciation Speaker Size (13)**: The size of the annunciation speaker.
* **Fire Alarm Annunciation Speaker Location (14)**: The location of the annunciation speaker.
* **Fire Alarm Main Panel Status 2 (15)**: The status of the main panel 2, including any issues or concerns.
* **Fire Alarm Annunciation Status 2 (16)**: The status of the annunciation system 2, including any issues or concerns.
* **Fire Alarm Annunciation Speaker Size 2 (17)**: The size of the annunciation speaker 2.
* **Fire Alarm Annunciation Speaker Location 2 (18)**: The location of the annunciation speaker 2.
* **Fire Alarm Annunciation Speaker Type (19)**: The type of annunciation speaker.
* **Fire Alarm Annunciation Speaker Location 3 (20)**: The location of the annunciation speaker 3.
* **Fire Alarm Main Panel Board Status (21)**: The status of the main panel board, including any issues or concerns.
* **Fire Alarm Main Panel Board Location (22)**: The location of the main panel board.
* **Fire Alarm Sprinkler System Status (23)**: The status of the sprinkler system, including any issues or concerns.
* **Fire Alarm Horn Status (24)**: The status of the horn, including any issues or concerns.
* **Fire Alarm Horn Location (25)**: The location of the horn.

## Tips
* Take your time and be thorough when completing this form.
* Refer to the system's documentation or manual for specific technical details.
* If you are unsure about any information, please consult with a qualified technician or engineer.
