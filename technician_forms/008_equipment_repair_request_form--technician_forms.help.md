# Equipment Repair Request Form - Help Guide
## Purpose
The Equipment Repair Request Form is used by technicians to report equipment malfunctions, damage, or other issues that require attention.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct Equipment ID of the equipment that needs repair.
2. Choose the type(s) of equipment that requires repair.
3. Briefly describe the problem with the equipment.
4. Specify the location where the equipment is currently being used.
5. Indicate the current condition of the equipment (e.g., good, bad).
6. Provide contact information for the person responsible for the equipment.
7. Choose the contact person for the repair request.
8. Add any additional notes about the repair request.

## Field-by-Field Explanation
* **Equipment ID**: Select the unique identifier for the equipment that needs repair.
* **Equipment Type**: Choose all applicable types of equipment that require repair (e.g., Option 1, Option 2, Option 3).
* **Problem Description**: Briefly describe the issue with the equipment, including any symptoms or error messages.
* **Location**: Specify the current location where the equipment is being used.
* **Equipment Condition**: Indicate the current condition of the equipment (e.g., good, bad).
* **Contact Info**: Enter the contact information for the person responsible for the equipment (e.g., name, phone number, email).
* **Contact Person**: Select the person responsible for the repair request.
* **Notes**: Add any additional comments or context about the repair request.
