# New Hardware Request - Help Guide

## Purpose

This form is used by technicians to request new hardware that they need to perform their tasks effectively. Please fill out this form to provide a detailed description of the required hardware and the reasons why you need it.

## How To Complete This Form

1. Fill in the **New Hardware Request** field with a brief title or summary of your request.
2. Provide a detailed description of the hardware you need in the **Description** field.
3. Select all the damaged parts you are requesting replacement for in the **Damaged Parts** field. This can be:
	+ Headset
	+ Microphone
	+ Monitor
	+ Keyboard
	+ Mouse
4. Enter the quantity of the hardware you need in the **Quantity** field.
5. If applicable, enter the replacement cost of the hardware in the **Replacement Cost** field.
6. Select the date you need to receive the hardware by in the **Purchase Order** field.

## Field-by-Field Explanation

* **New Hardware Request**: A brief title or summary of your request, which will help us understand your needs.
* **Description**: A detailed description of the hardware you need, including the specific features or functionalities required.
* **Damaged Parts**: Select all the parts that are damaged or broken, which we will replace. (e.g., Headset, Microphone, Monitor, Keyboard, Mouse)
* **Quantity**: Enter the number of units you need, or leave this field blank if you only need one unit.
* **Replacement Cost**: If you have a specific replacement cost in mind, enter it here. This will help us with budgeting purposes.
* **Purchase Order**: Select the date you need to receive the hardware by. This will help us with timely delivery and planning.
