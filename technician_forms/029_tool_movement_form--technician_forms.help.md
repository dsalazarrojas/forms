# Tool Movement Form - Help Guide

## Purpose

The Tool Movement Form is used by technicians to record the movement of tools within the inventory management system. This form helps track the movement of tools from one location to another, ensuring that the tool's status, condition, and ownership are updated accordingly.

## How To Complete This Form

1. **Select the tool being moved**: Choose the tool that is being moved from the "Assigned Tool" field.
2. **Choose the location the tool is moving from**: Select the starting location of the tool in the "From Location" field.
3. **Choose the location the tool is moving to**: Select the ending location of the tool in the "To Location" field.
4. **Choose the type of movement**: Select the type of movement in the "Movement Type" field.
5. **Enter the movement date**: Enter the date of the movement in the "Movement Date" field.
6. **Enter the movement time**: Enter the time of the movement in the "Movement Time" field.
7. **Add comments (optional)**: Enter any additional comments about the movement in the "Comments" field (optional).
8. **Update assigned to and assigned by fields**: Select the individuals or teams involved in the movement in the "Assigned To", "Assigned By", "Location Owners", and "Location Types" fields (optional).
9. **Update tool status and condition**: Select the new status and condition of the tool in the "Tool Status" and "Tool Condition" fields (optional).

## Field-by-Field Explanation

* **Assigned Tool**: Select the tool being moved to update its status and location.
* **From Location**: Select the location the tool is currently in.
* **To Location**: Select the location the tool is moving to.
* **Movement Type**: Choose the type of movement (e.g., "Move", "Transfer", "Repair", etc.).
* **Movement Date**: Enter the date of the movement (format: YYYY-MM-DD).
* **Movement Time**: Enter the time of the movement (format: HH:MM AM/PM).
* **Comments**: Enter any additional comments about the movement (optional).
* **Assigned To**: Select the individuals or teams responsible for the tool (optional).
* **Assigned By**: Select the individuals or teams responsible for assigning the tool (optional).
* **Location Owners**: Select the location owners or stakeholders involved in the movement (optional).
* **Location Types**: Select the types of locations involved in the movement (optional).
* **Tool Status**: Select the new status of the tool (e.g., "Active", "Inactive", etc.).
* **Tool Condition**: Select the condition of the tool (e.g., "Good", "Bad", etc.).
