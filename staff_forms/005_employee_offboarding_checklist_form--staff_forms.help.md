# Employee Offboarding Checklist Form - Help Guide
## Purpose
This form is used to collect information from employees who are leaving the company. It helps to ensure that all necessary steps are taken to offboard an employee correctly and in a timely manner.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the employee's job title.
2. Enter the employee's ID.
3. Select the manager's name from the list.
4. Enter the date of departure (if applicable).
5. Enter the reason for departure (if applicable).
6. Select the notice period (if applicable).
7. Answer if an exit interview was conducted.
8. Select any company assets that need to be returned.
9. Select any equipment that needs to be returned.
10. Select any keycards that need to be returned.
11. Select any property that needs to be returned.
12. Select any equipment that needs to be returned.
13. Select any other assets that need to be returned.
14. Select any assets that have been returned.
15. Select the employee who returned the assets.
16. Enter the date the assets were returned.
17. Answer any exit interview questions.
18. Select any assets that were returned.
19. Select any employee survey answers.
20. Select the other assets that were returned.

## Field-by-Field Explanation

* **Employee Offboarding Checklist Form**: This is the main title of the form.
* **job_title**: Enter the job title of the employee leaving the company.
* **Employee ID**: Enter the employee's ID number.
* **manager_name**: Select the name of the manager who will be handling the offboarding process.
* **Date of Departure**: Enter the date the employee will be leaving the company (if known).
* **reason_for_departure**: Enter the reason the employee is leaving the company (if applicable).
* **notice_period**: Select the notice period given to the employee.
* **exit_interview**: Answer if an exit interview was conducted.
* **company_assets**: Select any company assets that need to be returned.
* **equipment_return**: Select any equipment that needs to be returned.
* **keycard_return**: Select any keycards that need to be returned.
* **return_all_property_assets**: Select any property that needs to be returned.
* **return_all_equipment**: Select any equipment that needs to be returned.
* **property_return**: Select any property that needs to be returned.
* **return_all_company_assets**: Select any company assets that need to be returned.
* **return_all_property_equipment**: Select any property equipment that needs to be returned.
* **exit_interview_questions**: Answer any exit interview questions.
* **return_all_assets**: Select any assets that need to be returned.
* **employee_survey**: Select any employee survey answers.
* **other_assets**: Select any other assets that need to be returned.
* **assets_returned**: Select any assets that were returned.
* **assets_returned_by**: Select the employee who returned the assets.
* **assets_returned_date**: Enter the date the assets were returned.
