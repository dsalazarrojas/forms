# Phone Exchange Form - Help Guide
## Purpose
The Phone Exchange Form is a simple form used for staff to exchange phone numbers for internal communication purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **phone number** field with the number you would like to exchange.
2. Select the **exchange date** and **exchange time** fields to schedule the phone call.
3. Click "Submit" to send the form.

## Field-by-Field Explanation

* **phone_exchange_form (phone_exchange_form, text, required: false)**: This field is optional, but recommended for a brief description or context of the phone call.
* **phone_number (phone_number, number, required: false)**: Enter the phone number you would like to exchange.
* **exchange_date (exchange_date, date, required: false)**: Select the date of the phone call.
* **exchange_time (exchange_time, time, required: false)**: Select the time of the phone call.

## Tips
* Make sure to double-check the phone number for accuracy before submitting the form.
* If you need to exchange multiple phone numbers, you can create a new form for each number.
* If you have any issues or concerns about this form, contact the internal support team.
