# phased_return_to_work_form - Help Guide
## Purpose
The Phased Return to Work Form is designed to create a gradual return-to-work plan for employees who have been on leave. This form helps gather essential information to ensure a smooth transition back to work.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the return date in the `return_date` field.
2. Specify the duration of leave taken using the `leave_duration` field.
3. Select the start and end dates for the gradual return period using the `gradual_return_start` and `gradual_return_end` fields.
4. Choose the number of hours you plan to work per day using the `work_hours` field.
5. Select the frequency of work, whether it's full-time, part-time, or telecommute, using the `work_frequency` field.
6. Enter the number of days you plan to work using the `work_days` field.
7. Select the work location using the `work_location` field.
8. Identify the individuals who need to approve your return-to-work plan using the `supervisor_approvals` field.
9. Choose the type of work arrangement you require for your return-to-work period using the `work_arrangement` field.

## Field-by-Field Explanation

* **return_date** (`return_date`, date, required): Enter the date you plan to return to work.
* **leave_duration** (`leave_duration`, number, optional): Specify the total duration of leave taken.
* **gradual_return_start** (`gradual_return_start`, date, optional): Enter the start date of your gradual return period.
* **gradual_return_end** (`gradual_return_end`, date, optional): Enter the end date of your gradual return period.
* **work_hours** (`work_hours`, number, optional): Enter the number of hours you plan to work per day.
* **work_frequency** (`work_frequency`, select_one, optional): Select your work frequency:
	+ Full-time
	+ Part-time
	+ Telecommute
* **work_days** (`work_days`, number, optional): Enter the number of days you plan to work.
* **work_location** (`work_location`, text, optional): Enter your work location (e.g., office, remote, etc.).
* **supervisor_approvals** (`supervisor_approvals`, select_multiple, optional): Identify the individuals who need to approve your return-to-work plan:
	+ Supervisor
	+ HR
	+ Manager
* **work_arrangement** (`work_arrangement`, select_multiple, optional): Choose a work arrangement for your return-to-work period:
	+ Flexible
	+ Flexible (hybrid)
	+ Modified duty hours
	+ Regular

## Tips
- Make sure to fill out this form accurately and thoroughly to ensure a smooth transition back to work.
- If you're unsure about any field, consult with your supervisor or HR representative.
- Keep in mind that this form should not be filled out if you're returning to work immediately or if you've already been cleared for regular return to work.
