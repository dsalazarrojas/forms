# Skill Set Evaluation Form - Help Guide
## Purpose
The Skill Set Evaluation Form is used by employers to assess a candidate's skills and suitability for a specific job position.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields, marked with an asterisk \*.
2. Enter the Employer Name, the Candidate Name, and the Job Title in the corresponding fields.
3. Select the Evaluation Date from the calendar.
4. Choose the relevant programming languages and development environments you are proficient in.
5. Select the databases you have used.
6. Enter the number of years of experience you have in the role.
7. Evaluate your proficiency level in programming languages using the scale provided.
8. Enter your email address and phone number for contact purposes.

## Field-by-Field Explanation
* **Employer Name** (`employer_name`, required): Enter the name of the organization you are evaluating.
* **Candidate Name** (`candidate_name`, required): Enter the name of the candidate being evaluated.
* **Job Title** (`job_title`, required): Enter the title of the job position being evaluated.
* **Evaluation Date** (`evaluation_date`, required): Select the date the evaluation was completed.
* **Programming Languages** (`programming_languages`, required): Select all the programming languages you are proficient in.
	+ Example: "C++", "Java", "Python", etc.
* **Development Environment** (`development_environment`, required): Select all the development environments you are proficient in.
	+ Example: "Windows", "Linux", "Mac", etc.
* **Databases Used** (`databases_used`, optional): Select all the databases you have used.
	+ Example: "SQL", "NoSQL", "Oracle", etc.
* **Proficient Programming Languages** (`programming_languages_proficient`, required): Select all the programming languages you are proficient in.
	+ Example: "C++", "Java", "Python", etc.
* **Experience** (`experience`, required): Enter the number of years of experience you have in the role.
* **Evaluation Score** (`evaluation_score`, required): Evaluate your proficiency level on a scale of 1-5.
* **Email** (`email`, required): Enter your email address for contact purposes.
* **Phone** (`phone`, optional): Enter your phone number for contact purposes.
* **Comments** (`comments`, optional): Enter any additional comments or feedback.
* **Additional Comments** (`evaluation_comments`, optional): Enter any additional comments or feedback from the evaluation.
