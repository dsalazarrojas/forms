# Screening Checklist For Visitors And Employees - Help Guide
## Purpose
This form is designed to gather information on the health and recent travel history of visitors and employees to ensure they do not pose a risk of infection or contamination to the organization.

## How To Complete This Form
1.  Answer each question carefully and honestly.
2.  Select all that apply for the select_multiple questions.
3.  If you do not have any symptoms or recent travel, select the corresponding option (e.g., "None" or "False").
4.  Ensure you have reviewed all fields before submitting the form.

## Field-by-Field Explanation

*   **Has the person had any symptoms** (`Fever`, `select_one`, required: false): Has the person experienced a fever?
    *   Select "Fever" if the person has had a fever.
*   Select "None" if the person has not had a fever.
*   Select "Other" if the person has any other symptoms not listed above.

*   **Has the person had any symptoms** (`Coughing`, `select_one`, required: false): Has the person experienced coughing?
    *   Select "Coughing" if the person is coughing.
*   Select "None" if the person has not experienced coughing.
*   Select "Other" if the person has any other symptoms not listed above.

*   **Has the person had any symptoms** (`Sore Throat`, `select_one`, required: false): Has the person experienced a sore throat?
    *   Select "Sore Throat" if the person has a sore throat.
*   Select "None" if the person has not experienced a sore throat.
*   Select "Other" if the person has any other symptoms not listed above.

*   **Has the person had any symptoms** (`Other`, `select_one`, required: false): Has the person experienced any other symptoms not listed above?
    *   Select "Other" if the person has any other symptoms not listed above.
*   Select "None" if the person has not experienced any other symptoms not listed above.

*   **Has the person had any recent travel** (`has the person had any recent travel`, `select_one`, required: false): Has the person had any recent travel?
    *   Select "True" if the person has had any recent travel.
*   Select "False" if the person has not had any recent travel.

*   **Date of last travel** (`date_of_last_travel`, `date`, required: false): What was the date of the person's last travel?
    *   Enter the date of the last travel.
