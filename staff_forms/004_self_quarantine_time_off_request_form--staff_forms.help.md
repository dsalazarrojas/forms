# self_quarantine_time_off_request_form - Help Guide
## Purpose
The self_quarantine_time_off_request_form is used to request time off due to self-quarantine. This form helps employees inform their manager about their request for time off and allows the manager to approve or deny the request.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of your reason for requesting time off in the "reason_for_requesting_time_off" field.
2. Select the date you expect to return to work in the "expected_return_date" field.
3. If you have any supporting documentation, such as a doctor's note, upload it in the "supporting_document" field.
4. If you have any comments or additional information, type them in the "comments" field.
5. Finally, ask your manager to approve your request by selecting "yes" in the "manager_approval" field.

## Field-by-Field Explanation

* **request_time_off**: Enter a short description of your reason for requesting time off. (Text, Required)
* **employee_name**: Enter your name so we can identify you. (Text, Not Required)
* **job_title**: Enter your job title so we can verify your position. (Text, Not Required)
* **reason_for_requesting_time_off**: Enter a brief description of your reason for requesting time off. (Text, Required)
* **expected_return_date**: Select the date you expect to return to work. (Date, Required)
* **manager_approval**: Ask your manager to approve your request by selecting "yes". (Select One, Not Required)
* **supporting_document**: If you have any supporting documentation, upload it here. (Text, Not Required)
* **comments**: If you have any comments or additional information, type them here. (Text, Not Required)
