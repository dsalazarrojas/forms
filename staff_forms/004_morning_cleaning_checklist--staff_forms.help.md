# Morning Cleaning Checklist - Help Guide

## Purpose
The Morning Cleaning Checklist is a form designed to track the completion of morning cleaning tasks. It helps ensure that all necessary tasks are completed during the morning routine, promoting a clean and safe environment for all users.

## How To Complete This Form

1. Review the form carefully before starting your morning cleaning routine.
2. Check off each task as you complete it.
3. Select "Yes" or "No" for each task to indicate completion status.
4. Ensure you submit the form accurately to ensure up-to-date tracking of cleaning tasks.

## Field-by-Field Explanation

* **Morning Cleaning Checklist**: This is the title of the form, which you have already read.
* **Cleaning Tasks**: Check the box next to each task as you complete it. Select "Yes" to indicate that the task is complete, or "No" if it is not.
	+ **Emptying Trash and Recycling**: Check this box if you empty the trash and recycling containers during your morning cleaning routine.
	+ **Sweeping and Mopping**: Check this box if you sweep and mop all floors during your morning cleaning routine.
	+ **Other (please specify)**: Check this box if you have other cleaning tasks that are not listed above.
* **Task Completed**: Select "Yes" if you have already completed all the listed tasks, or "No" if there are still tasks remaining.
* **Completed Tasks**: If you selected "Yes" for "Task Completed", list all tasks that were actually completed during the morning cleaning routine.
