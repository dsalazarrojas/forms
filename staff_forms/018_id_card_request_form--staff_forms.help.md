# id_card_request_form - Help Guide
## Purpose
This form is used to request an ID card for employees or non-employees.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of ID card you need (Employee ID Card, Non-Employee ID Card, or Replacement ID Card).
2. Enter your ID number in the "ID Number" field.
3. Provide the reason for your ID card request.
4. Sign the form with your signature.
5. Enter your contact details (contact number, contact email, contact phone, contact address).
6. Optionally, select your department, branch, location, manager, and supervisor.
7. Optionally, enter your employee number, date of damage, date of loss, and date of information change.
8. Add any additional information or comments in the "ID Request Note" field.
9. Select "Submit" to complete the form.

## Field-by-Field Explanation
* **ID Request Reason**: This field should be filled in to explain why you are requesting an ID card.
* **ID Number**: Enter the ID number of the ID card you are requesting.
* **ID Card Type**: Select the type of ID card you need (Employee ID Card, Non-Employee ID Card, or Replacement ID Card).
* **ID Type**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **ID Card Number**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Reason**: This field is optional and should be filled in to provide additional context for the ID card request.
* **Date of Damage**: This field is optional and should be filled in if you are requesting a Replacement ID Card.
* **Date of Loss**: This field is optional and should be filled in if you are requesting a Replacement ID Card.
* **Date of Information Change**: This field is optional and should be filled in if you are requesting a Replacement ID Card.
* **Signature**: Sign this form with your signature to confirm your request.
* **Contact Number**: Enter your contact number.
* **Contact Email**: Enter your contact email.
* **Contact Phone**: Enter your contact phone number.
* **Contact Address**: Enter your contact address.
* **Employee Number**: This field is optional and should be filled in if you are requesting an Employee ID Card.
* **Department**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Branch**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Location**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Manager**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Manager Number**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Supervisor**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **Supervisor Number**: This field is optional and should be filled in if you are requesting a Non-Employee ID Card or Replacement ID Card.
* **ID Request Note**: This field is optional and should be filled in to provide additional information or comments.
* **Date**: This field is optional and should be filled in if you are requesting a Replacement ID Card.
* **Submit**: Select "Submit" to complete the form and submit your request.
