# hotel_staff_check_out_form - Help Guide
## Purpose
This form is used to collect information from hotel staff after a guest has checked out. It helps the hotel staff to gather data about the reason for leaving, next contact date and time, and other relevant details.

## How To Complete This Form
1. **reason_for_leaving**: The reason for the guest's departure. Please provide a brief description of why the guest checked out.
2. **next_steps**: Optional information about the next steps that were taken after the guest checked out.
3. **feedback**: Any feedback or comments the guest provided after checking out.
4. **contact_preferences**: If the guest is available for contact, please select 'Yes'. Otherwise, select 'No'.
5. **contact_details**: Select all the contact details that apply to the guest's next contact (e.g., email, phone, etc.).
6. **next_contact_date**: Enter the date of the guest's next contact.
7. **next_contact_time**: Enter the time of the guest's next contact.
8. **contact_preferences**: If the guest is available for contact, please select 'Yes'. Otherwise, select 'No'.
9. **contact_details**: Select all the contact details that apply to the guest's next contact (e.g., email, phone, etc.).
10. **next_contact_method**: Select the method of the guest's next contact (e.g., phone, email, etc.).

## Field-by-Field Explanation
* **Introduction**: This is a note field where hotel staff can take note of any important information about the guest's stay.
* **reason_for_leaving**: This field asks for a brief description of why the guest checked out.
* **next_steps**: This field is for optional information about the next steps that were taken after the guest checked out.
* **feedback**: This field is for any feedback or comments the guest provided after checking out.
* **contact_preferences**: This field asks if the guest is available for contact, and if so, it's checked.
* **contact_details**: This field allows hotel staff to select all the contact details that apply to the guest's next contact.
* **next_contact_date**: This field asks for the date of the guest's next contact.
* **next_contact_time**: This field asks for the time of the guest's next contact.
* **contact_preferences**: This field confirms if the guest is available for contact.
* **contact_details**: This field is the same as the previous "contact_details" field.
* **next_contact_method**: This field asks for the method of the guest's next contact (e.g., phone, email, etc.).

## Tips
* Make sure to complete all required fields (marked with *) before submitting the form.
* If a guest is not available for contact, select 'No' in the contact preferences field.
* If there are multiple contact details that apply, select all applicable options in the "contact_details" field.
* Be accurate when entering the date and time of the guest's next contact.
