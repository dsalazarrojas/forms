# Time Clock Adjustment Form - Help Guide
## Purpose
The Time Clock Adjustment Form is used to correct inaccuracies in an employee's time tracking record.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each field carefully and select 'Yes' for each item that applies to your situation.
2. Select 'No' for each item that does not apply.
3. Enter a description of the reason for the adjustments in the 'Description' field.
4. Enter the start and end times of the original inaccurate entry.
5. Select 'Yes' to confirm the submission of the form.

## Field-by-Field Explanation

* **Time Clock Adjustment** (`time_clock_adjustment_form`, select_one): Indicates whether or not you need to make any time clock adjustments.
	+ Select 'Yes' if you need to make adjustments.
	+ Select 'No' if you do not need to make any adjustments.
* **Employee** (`employee`, select_multiple): Select all employees affected by the adjustment.
	+ Select 'Yes' for each affected employee.
	+ Select 'No' if there are no affected employees.
* **Date** (`date`, date): Enter the date of the original inaccurate entry.
	+ Use the format: YYYY-MM-DD (e.g., 2022-02-16)
* **Start Time** (`start_time`, time): Enter the start time of the original inaccurate entry.
	+ Use the format: HH:MM:SS (e.g., 08:30:00)
* **End Time** (`end_time`, time): Enter the end time of the original inaccurate entry.
	+ Use the format: HH:MM:SS (e.g., 16:00:00)
* **Description** (`description`, text): Enter a brief description of the reason for the adjustments.
* **Reason** (`reason`, text): Enter a detailed description of the reason for the adjustments.
* **Submit** (`submit`, select_multiple): Confirm that the form has been completed correctly.
	+ Select 'Yes' to confirm the submission.
	+ Select 'No' to cancel the submission.

## Tips

* Make sure to select 'Yes' only for fields that apply to your situation.
* If you are unsure about any field, contact your HR representative for guidance.
* Enter accurate and detailed information in the 'Description' and 'Reason' fields to ensure that the adjustments are approved correctly.
