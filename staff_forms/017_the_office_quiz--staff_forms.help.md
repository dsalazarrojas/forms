# The Office Quiz - Help Guide

## Purpose
The Office Quiz is a form used to gather information about the main characters and key features of The Office.

## How To Complete This Form
1. Please select the correct answers for each field, following the instructions below.
2. For the main character fields, select the characters you are familiar with.
3. For the report fields, provide a detailed answer, up to 2000 characters.

## Field-by-Field Explanation

* **Scenes from Episodes** (`scenes_from_episodes`, select_multiple, required): Select all the episodes that you are familiar with. You can select multiple episodes.
* **Main Characters** (`main_characters`, select_one, required): Choose one character from the list that you are most familiar with.
* **Episodes from Series** (`episodes_from_series`, select_multiple, optional): Select all the episodes that you are familiar with from this series.
* **Guest Characters** (`guest_characters`, select_multiple, optional): Select all the guest characters you are familiar with.
* **Scenes from Seasons** (`scenes_from_seasons`, select_multiple, optional): Select all the seasons you are familiar with.
* **Main Character Names** (`main_character_names`, select_multiple, optional): Select all the main character names you are familiar with.
* **Episode Names** (`episode_names`, select_multiple, optional): Select all the episode names you are familiar with.
* **Main Character Quotes** (`main_character_quotes`, select_multiple, optional): Select all the main character quotes you are familiar with.
* **Episode Themes** (`episode_themes`, select_multiple, optional): Select all the episode themes you are familiar with.
* **Office Features** (`office_features`, text, required): Please provide a description of any notable features of the Office.
* **Main Character Traits** (`main_character_traits`, select_multiple, optional): Select all the main character traits you are familiar with.
* **Main Character Goals** (`main_character_goals`, select_multiple, optional): Select all the main character goals you are familiar with.
* **Office Episodes** (`office_episodes`, select_multiple, optional): Select all the Office episodes you are familiar with.
* **Main Character Families** (`main_character_families`, select_multiple, optional): Select all the main character families you are familiar with.
* **Main Character Relationships** (`main_character_relationships`, select_multiple, optional): Select all the main character relationships you are familiar with.
* **Main Character Jobs** (`main_character_jobs`, select_multiple, optional): Select all the main character jobs you are familiar with.
* **Main Character Birthdays** (`main_character_birthdays`, select_multiple, optional): Select all the main character birthdays you are familiar with.
* **Main Character Hobbies** (`main_character_hobbies`, select_multiple, optional): Select all the main character hobbies you are familiar with.
* **Main Character Report** (`main_character_report`, note, required): Please provide a detailed report on the main character, up to 2000 characters.
* **Main Character Goals Report** (`main_character_goals_report`, date, required): Please provide a date for the main character goals report.
* **Scenes from Episodes Report** (`scenes_from_episodes_report`, note, required): Please provide a detailed report on scenes from episodes, up to 2000 characters.
* **Office Themes Report** (`office_themes_report`, note, required): Please provide a detailed report on Office themes, up to 2000 characters.
* **Main Character Goals Report Details** (`main_character_goals_report_details`, text, required): Please provide a detailed description of the main character goals report.
* **Main Character Goals Report Summary** (`main_character_goals_report_summary`, text, required): Please provide a summary of the main character goals report, up to 2000 characters.

Note: Please fill in all the required fields, and provide detailed answers for the report fields.
