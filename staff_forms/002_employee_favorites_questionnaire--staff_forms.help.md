# employee_favorites_questionnaire - Help Guide
## Purpose
The employee_favorites_questionnaire form is designed to collect employee preferences and interests for non-mandatory, internal use. It's meant to be a fun and informal way for employees to express their favorite things.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Read each page carefully and answer the questions to the best of your ability.
2. Choose your favorite items from the provided options for each question.
3. Submit the form when you're finished.

## Field-by-Field Explanation

* **Introduction** (Page 1):
	+ A brief introduction to let you know what this form is about.
* **favorite_item** (Page 2):
	+ Choose your favorite food item (Apple, Pear, or Grape) 
* **favorite_activity** (Page 3):
	+ Select all activities that you enjoy (Reading, Exercise, or Playing) 
* **do_you_like** (Page 4):
	+ Choose how you feel about a certain thing (True, False, or Undecided) 
* **favorite_food** (Page 5):
	+ Select all your favorite foods (Pizza, Sushi, or Tacos) 
* **would_you_recommend** (Page 6):
	+ Choose if you would recommend something (True, False, or Undecided) 
* **favorite_color** (Page 7):
	+ Select all your favorite colors (Red, Green, or Blue) 
* **favorite_place** (Page 8):
	+ Choose your favorite place (Home, Office, or Store) 
* **favorite_time** (Page 9):
	+ This is where you can select a specific time. If there are no options, select a custom time. 
* **favorite_date** (Page 10):
	+ This is where you can select a specific date. If there are no options, select a custom date. 
* **favorite_month** (Page 11):
	+ Select your favorite month (January, February, or March) 
* **favorite_year** (Page 12):
	+ This is where you can select a specific year. If there are no options, select a custom year. 
* **favorite_thing** (Page 13):
	+ A text field for you to write about your favorite thing. 
* **favorite_number** (Page 14):
	+ Select a number that you like (e.g. your favorite number between 1-100) 

Please note that some fields might have custom options or custom answers, please follow the provided instructions for those specific fields.
