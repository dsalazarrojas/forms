# Peer Evaluation - Help Guide
## Purpose

This form is designed to facilitate peer evaluation and feedback between team members, allowing them to assess and provide input on each other's work, behavior, and performance.

## How To Complete This Form

1. Please answer each question based on your personal experiences and observations with the individual being evaluated.
2. Select the correct answer for each question, and use the available options to provide feedback.
3. Use the space provided for each question to elaborate on your answers, if necessary.
4. Make sure to submit the form once you have completed all the required questions.

## Field-by-Field Explanation

* **evaluation_criteria** (id: 2): This question allows you to provide feedback on the individual's performance in the following areas:
	+ Communication effectiveness
	+ Collaboration and teamwork
	+ Problem-solving
	+ Creativity
	+ Innovation
	+ Other (please specify)
* **form_1_form_group_1** (id: 3): This section is intended for you to provide any additional comments or feedback you have about the individual's work or performance.
* **form_1_form_group_2** (id: 4): Another section for additional comments or feedback.
* ...
* **peer_evaluation_comments** (id: 25): Please provide any other comments or feedback you have about the individual's performance or work.
* **overall_rating** (id: 26): Use the number scale to rate the individual's overall performance.
* **overall_recommendation** (id: 27): Provide an overall recommendation based on your feedback and observations.
* **submit** (id: 28): Select the "Submit" option to complete and submit your evaluation.
* **date_submitted** (id: 29): This field is automatically generated and displays the date and time of submission.
