# staff_availability_survey - Help Guide
## Purpose
The "staff_availability_survey" form is designed to collect information about staff members' availability for a given period. This information will be used by managers and administrators to schedule tasks and projects efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. **Staff member's availability**: Select the days of the week you are available to work.
	* Label: working_days
	* Type: select_multiple
2. **Time slots**: Select the time slots you are available to work.
	* Label: time_slots
	* Type: select_multiple
3. **Availability note**: Write a brief note about your availability, if needed.
	* Label: staff_ava_survey_note
	* Type: note
4. **Staff member ID**: Enter your ID number (not required).
	* Label: employee_id
	* Type: number
5. **Department availability**: Confirm if you are available in the current department.
	* Label: department_id
	* Type: select_one
6. **Submission information**: Select who submitted this form (optional).
	* Label: submitted_by
	* Type: select_one
7. **Creation information**: Select who created this form (optional).
	* Label: created_by
	* Type: select_one
8. **Update information**: Select who updated this form (optional).
	* Label: updated_by
	* Type: select_one

## Field-by-Field Explanation
* **Staff member's availability**: Select all the days you are available to work. For example, if you are available on Monday and Wednesday, select both "Monday" and "Wednesday".
* **Time slots**: Select all the time slots you are available to work. For example, if you are available from 09:00-10:00 and 14:00-15:00, select both "09:00-10:00" and "14:00-15:00".
* **Availability note**: Write a brief note about your availability, if needed. This is an optional field, but it can be helpful to add any additional information about your availability.
* **Staff member ID**: Enter your ID number, if you have one. This is not required, but it can be useful for reference purposes.
* **Department availability**: Confirm if you are available in the current department. Select "Yes" if you are available, "No" if you are not.
* **Submission information**: Select who submitted this form. This field is optional, but it can be useful for tracking who submitted the form.
* **Creation information**: Select who created this form. This field is optional, but it can be useful for tracking who created the form.
* **Update information**: Select who updated this form. This field is optional, but it can be useful for tracking who updated the form.

## Tips
* Make sure to select all the days and time slots you are available to work.
* If you have any additional information about your availability, write it in the "Availability note" field.
* If you have an ID number, enter it for reference purposes.
* Select "Yes" if you are available in the current department, "No" otherwise.
* These fields are optional, so feel free to fill them out if you have that information.
