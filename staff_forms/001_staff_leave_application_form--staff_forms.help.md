> # Staff Leave Application Form - Help Guide
## Purpose
The Staff Leave Application Form is a tool to help staff members request leave from work for various reasons. It provides a structured format for submitting requests, making it easier for staff and management to process and approve or deny leave applications.

## How To Complete This Form
1. Select the type of leave you are requesting (sick, annual, or other).
2. Enter the start and end dates of your leave period.
3. Specify the duration of your leave, if applicable.
4. Enter a brief reason for your leave application.
5. Add any additional comments, if needed.
6. Select the person you would like to be assigned to process your leave.
7. Select who submitted this application (usually yourself).
8. Choose the status of your leave application (pending, approved, or denied).
9. Select the time when you submitted the application.
10. Select the time when the application was created.
11. Select the time when the application was last updated.
12. Select the time when the application was deleted, if applicable.
13. Select who deleted the application, if applicable.
14. Select who last updated the application, if applicable.
15. Select the time when the application was last updated.
16. Select the person who assigned the tool to process your leave.
17. Select the category of the form (Staff Forms).
18. Enter a description of the form, if needed.
19. Select who assigned the form to process (usually yourself).
20. Select the category of the form (usually Staff Forms).

## Field-by-Field Explanation
* **Staff Leave Application Form**: A brief title of the form.
* **leave_type**: Select the type of leave you are requesting (sick, annual, or other).
* **start_date**: The date you would like your leave to start.
* **end_date**: The date you would like your leave to end.
* **duration**: The number of days you would like your leave to last.
* **reason**: A brief reason for your leave application.
* **comments**: Any additional comments or details you would like to provide.
* **Assigned To**: Select the person you would like to be assigned to process your leave.
* **Submitted By**: Select who submitted this application (usually yourself).
* **status**: Choose the status of your leave application (pending, approved, or denied).
* **Submitted At**: The time when you submitted the application.
* **Created At**: The time when the application was created.
* **Updated At**: The time when the application was last updated.
* **Deleted At**: The time when the application was deleted, if applicable.
* **Deleted By**: Select who deleted the application, if applicable.
* **Updated By**: Select who last updated the application, if applicable.
* **Deleted By 2**: Select who deleted the application, if applicable.
* **Updated By 2**: Select who last updated the application, if applicable.
* **Created At 2**: The time when the application was created.
* **Form ID**: A unique identifier for the form.
* **Assigned Tool**: Select who assigned the tool to process your leave.
* **Category**: The category of the form (Staff Forms).
* **Description**: A description of the form, if needed.
* **Assigned To**: Select who assigned the form to process (usually yourself).
* **Category 2**: The category of the form (usually Staff Forms).
