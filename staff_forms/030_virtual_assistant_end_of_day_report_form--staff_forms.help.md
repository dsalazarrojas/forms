# virtual_assistant_end_of_day_report_form - Help Guide
## Purpose
The virtual assistant end-of-day report form is used to record the work completed by virtual assistants at the end of each working day. This form helps in tracking the activities, time spent, and other relevant details of the virtual assistant's work.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the client(s) you've worked with on this day using the "Client Details" dropdown.
2. Enter a brief description of the work completed in the "Work Completed" field.
3. Choose the type of task(s) you've completed (e.g., Call, Meeting, Email) using the "Task Details" dropdown.
4. Add any additional notes about your work in the "Notes" field (optional).
5. Enter the time spent on tasks using the "Time Spent" field. You can break down the time spent into hours and minutes using the corresponding fields.
6. Select the tool you've used to complete the tasks using the "Assigned Tool" dropdown.
7. Enter any comments about your work in the "Comments" field.
8. If you've worked on behalf of another user, select the user's name from the "Submitted By" dropdown.
9. Finally, choose the date you're submitting this report using the "Submitted Date" field.

## Field-by-Field Explanation
* **Client Details (Select)**: This field allows you to select the client(s) you've worked with on this day.
* **Work Completed (Text)**: Enter a brief description of the work you've completed.
* **Task Details (Select One)**: Choose the type of task you've completed (e.g., Call, Meeting, Email, Task).
* **Notes (Text)**: Add any additional notes about your work (optional).
* **Time Spent (Time)**: Enter the time you've spent on tasks.
* **Time Spent (Hours)**: Enter the hours spent on tasks (optional).
* **Time Spent (Minutes)**: Enter the minutes spent on tasks (optional).
* **Assigned Tool (Select One)**: Select the tool you've used to complete the tasks.
* **Comments (Text)**: Enter any comments about your work.
* **Submitted By (Select One)**: If you've worked on behalf of another user, select their name.
* **Submitted Date (Date)**: Choose the date you're submitting this report.
