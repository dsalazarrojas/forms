# Remote Worker Assessment Form - Help Guide
## Purpose
The Remote Worker Assessment Form is used to assess a remote worker's performance, productivity, and attendance. It helps to identify areas of strength and weakness, and inform decisions about development opportunities and resource allocation.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the rating for the remote worker's overall performance.
2. Select the remote worker's productivity level (High, Medium, Low).
3. Select the remote worker's performance level (High, Medium, Low).
4. Select the remote worker's attendance level (Excellent, Good, Fair, Poor).
5. Optionally, provide comments about the remote worker's performance, productivity, and attendance.
6. Enter the date and time of the assessment.
7. Optionally, enter any comments or feedback about the remote worker.

## Field-by-Field Explanation

* **Rating**: Rate the remote worker's overall performance. Select one of the following options: Excellent, Good, Fair, or Poor.
* **Remote Worker Rating**: This field is not used. Please ignore it.
* **Comment**: Provide any comments or feedback about the remote worker's performance, productivity, and attendance. This field is optional.
* **Date of Assessment**: Enter the date of the assessment in the format "YYYY-MM-DD" (e.g., 2022-02-16).
* **Time of Assessment**: Enter the time of the assessment in the format "HH:MM:SS" (e.g., 14:30:00).
* **Productivity**: Select the remote worker's productivity level. You can select multiple levels (High, Medium, Low).
* **Performance**: Select the remote worker's performance level. You can select multiple levels (High, Medium, Low).
* **Attendance**: Select the remote worker's attendance level. You can select multiple levels (Excellent, Good, Fair, Poor).
* **Comments**: Provide any additional comments or feedback about the remote worker's performance, productivity, and attendance. This field is optional.
* **Assigned Tool**: This field is not used. Please ignore it.
* **Remote Worker Comments**: This field is the same as the comments field above. Please ignore this field.
