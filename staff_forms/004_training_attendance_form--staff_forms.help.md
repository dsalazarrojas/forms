# training attendance form - Help Guide
## Purpose
The "Training Attendance Form" is used by employees to report their attendance status for a specific training session. This form is meant to be filled out by employees after attending or not attending a training session, and is used to track attendance and provide feedback on the training's effectiveness.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your Employee Name in the first field.
2. Enter the name of the training session you attended (or did not attend) in the second field.
3. Select whether you attended or did not attend the training session using the dropdown menu in the third field.
4. If you attended the training session, enter the start and end times of the session in the fourth and fifth fields, respectively.
5. If you attended the training session, select whether the session is In Progress or Completed in the sixth field.
6. If not required, you can enter the location of the training session in the seventh field.
7. If not required, you can add any notes about the session in the eighth field.

## Field-by-Field Explanation
* **Employee Name (Employee Name)**: Enter your full name as it appears on your employee ID card.
* **Training Session Name (training session name)**: Enter the name of the training session you attended.
* **Attended (Attended)**: Indicate whether you attended or did not attend the training session.
	+ Select "True" if you attended the session.
	+ Select "False" if you did not attend the session.
* **Started (started)**: Enter the start time of the training session in 24-hour format (HH:MM).
* **Finished (finished)**: Enter the end time of the training session in 24-hour format (HH:MM).
* **Completed (completed)**: Select whether the training session is In Progress or Completed.
	+ Select "In Progress" if the session is still ongoing.
	+ Select "Completed" if the session has concluded.
* **Training Location (Training location)**: Enter the location of the training session (optional).
* **Notes (Notes)**: Enter any additional notes about the training session (optional).
