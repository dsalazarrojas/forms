# Wound Assessment Form - Help Guide
## Purpose

The Wound Assessment Form is a tool used by healthcare professionals to gather detailed information about a patient's wound. This form will help you assess the wound's characteristics, patient's condition, and treatment and rehabilitation plans.

## How To Complete This Form

To complete this form, follow these steps:

1. Review the patient's general information (Page 1).
2. Record the patient's wound characteristics (Page 2).
3. Document the wound's location, size, depth, surface, and edges (Pages 3-5).
4. Report the wound's base color and any other relevant information (Pages 6-7).
5. Record the patient's condition, allergies, and any relevant medical history (Pages 8-9).
6. Develop a treatment and rehabilitation plan for the wound (Pages 10-11).
7. Document any complications related to the wound (Page 12).
8. Report the wound's care and any other relevant information (Pages 13-14).
9. Document the patient's vaccinations and medications (Pages 15-16).
10. Record any additional notes about the wound (Pages 17-18).

## Field-by-Field Explanation

* **General Information** (Page 1):
	+ Provide the patient's name, date of birth, and other relevant identification details.
* **Patient Information** (Page 2):
	+ Provide the patient's medical history and any relevant information.
* **Wound Characteristics** (Page 3):
	+ Describe the wound's overall appearance and characteristics.
* **Wound Location** (Page 4):
	+ Specify the exact location of the wound on the patient's body.
* **Wound Size** (Page 5):
	+ Measure the wound's size in centimeters or other relevant units.
* **Wound Depth** (Page 6):
	+ Describe the wound's depth and any underlying tissue damage.
* **Wound Surface** (Page 7):
	+ Select the wound's surface type from the options listed (e.g., Slender, Lobulated, etc.).
* **Wound Edges** (Page 8):
	+ Select the wound's edge type from the options listed (e.g., Rolled, Everted, etc.).
* **Wound Base** (Page 9):
	+ Select the wound's base type from the options listed (e.g., Intact, Everted, etc.).
* **Wound Base Color** (Page 10):
	+ Select the wound's base color from the options listed (e.g., Red, Pink, etc.).
* **Patient Condition** (Page 11):
	+ Report the patient's overall condition and any relevant medical history.
* **Patient Allergies** (Page 12):
	+ Document any allergies or medical concerns related to the wound.
* **Wound Treatment Plan** (Page 13):
	+ Develop a treatment plan for the wound, including any necessary medications or interventions.
* **Wound Rehabilitation Plan** (Page 14):
	+ Develop a rehabilitation plan for the wound, including any necessary physical therapy or activities.
* **Wound Complications** (Page 15):
	+ Report any complications related to the wound.
* **Wound Complications Other** (Page 16):
	+ Report any other complications not listed in the previous option.
* **Wound Care** (Page 17):
	+ Select the wound's care type from the options listed (e.g., Frequent dressing changes, etc.).
* **Wound Care Other** (Page 18):
	+ Report any other wound care not listed in the previous option.
* **Wound Vaccinations** (Page 19):
	+ Report any vaccinations or immunizations related to the wound.
* **Wound Vaccinations Other** (Page 20):
	+ Report any other vaccinations or immunizations not listed.
* **Wound Medications** (Page 21):
	+ Report any medications related to the wound.
* **Wound Medications Other** (Page 22):
	+ Report any other medications not listed.
* **Wound Notes** (Page 23):
	+ Record any additional notes or comments about the wound.
* **Wound Comments** (Page 24):
	+ Record any additional comments or recommendations for the wound.

## Tips

* Be thorough and detailed when completing this form.
* Use the provided fields to ensure accurate and complete information.
* Review and update the form regularly to reflect any changes in the wound's condition.
* Consult with other healthcare professionals if you have any doubts or concerns.
* Ensure the patient's informed consent and confidentiality is maintained throughout the assessment process.
