# Tandem Nutrition Weekly Check In Form - Help Guide
## Purpose
The Tandem Nutrition Weekly Check In Form is a tool designed to help users track their nutrition information on a weekly basis. This form is intended to gather data on an individual's first name, email address, phone number, date, time, and other relevant details. The form aims to streamline the process of collecting and reviewing nutritional information, making it easier for healthcare professionals to provide personalized guidance and support.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your **First Name** in the text field labeled "First Name".
2.  Enter your **Email** address in the text field labeled "Email".
3.  Enter your **Phone Number** in the text field labeled "Phone".
4.  Select a date from the calendar for the "Date" field.
5.  Select a time from the time picker for the "Time" field.
6.  Select one option from the list for the "Select One" field.
7.  Select multiple options from the list for the "Select Multiple" field.
8.  Enter any additional comments or notes in the text area labeled "Note".
9.  Enter any further comments or notes in the text area labeled "Another Note".
10. Enter a value in the text field labeled "Date/Time".


## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, required: false): Enter your first name in this field.
* **Email** (`email`, `email`, required: false): Enter your email address in this format (e.g., [user@example.com](mailto:user@example.com).
* **Phone** (`phone`, `text`, required: false): Enter your phone number in this field.
* **Date** (`date`, `date`, required: false): Select a date from the calendar provided.
* **Time** (`time`, `time`, required: false): Select a time from the time picker provided.
* **Select One** (`select_one`, `select_one`, required: false): Choose one option from the list provided.
	+ Options: 0, 1, 2
* **Select Multiple** (`select_multiple`, `select_multiple`, required: false): Choose multiple options from the list provided.
	+ Options: 0, 1, 2
* **Note** (`note`, `note`, required: false): Enter any additional comments or notes in this text area.
* **Another Note** (`note`, `note`, required: false): Enter any further comments or notes in this text area.
* **Date/Time** (`date_time`, `text`, required: false): Enter a value in this text field.
* **Decimal** (`decimal`, `number`, required: false): Enter a decimal value in this field.
* **Integer** (`integer`, `number`, required: false): Enter an integer value in this field.
* **Text Area** (`text_area`, `text`, required: false): Enter any additional comments or notes in this text area.
