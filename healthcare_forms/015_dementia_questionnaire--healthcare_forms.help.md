# Dementia Questionnaire - Help Guide
## Purpose
The Dementia Questionnaire is designed to gather information about an individual's cognitive functioning, memory symptoms, behavioral changes, medical history, social interaction, emotional symptoms, and other related factors. This information can be used for research, clinical, or administrative purposes.

## How To Complete This Form
1. Review each question carefully and choose the option that best describes your experiences or knowledge about the individual's condition.
2. For select_multiple questions, select all applicable options that apply to the individual's condition.
3. If you are unsure about any question, please consult with the individual or their healthcare provider.
4. Complete the form in a quiet, distraction-free environment to minimize errors.

## Field-by-Field Explanation
* **Cognitive Functioning (1)**: Please choose the option that best describes the individual's cognitive functioning. 
  * Option 1: The individual has no cognitive issues.
  * Option 2: The individual has some cognitive issues.
  * Option 3: The individual has severe cognitive issues.
* **Memory Symptoms (2)**: Please select all options that apply to the individual's memory symptoms.
  + Option 1: Forgetfulness
  + Option 2: Confusion
* **Behavioral Changes (3)**: Please choose the option that best describes the individual's behavioral changes.
  * 'Yes' - The individual exhibits behavioral changes.
  * 'No' - The individual does not exhibit behavioral changes.
* **Medical History (4)**: Please select all options that apply to the individual's medical history.
  + Option 1: Previous stroke or TIA
  + Option 2: Family history of dementia
* **Cognitive Symptoms (5)**: Please choose the option that best describes the individual's cognitive symptoms.
  * 'Yes' - The individual exhibits cognitive symptoms.
  * 'No' - The individual does not exhibit cognitive symptoms.
* **Social Interaction (6)**: Please select all options that apply to the individual's social interaction.
  + Option 1: Difficulty with conversation
  + Option 2: Social withdrawal
* **Emotional Symptoms (7)**: Please choose the option that best describes the individual's emotional symptoms.
  * 'Yes' - The individual exhibits emotional symptoms.
  * 'No' - The individual does not exhibit emotional symptoms.
* **Cognitive Functioning 1-5 (8-12)**: Please choose the option that best describes the individual's cognitive functioning for each of these questions.
  * 'Yes' - The individual exhibits normal cognitive functioning.
  * 'No' - The individual does not exhibit normal cognitive functioning.
* **Behavioral Changes 1-2 (13-14)**: Please select all options that apply to the individual's behavioral changes.
  + Option 1: Mood swings
  + Option 2: Confusion
* **Medical History 1-5 (15-19)**: Please select all options that apply to the individual's medical history.
  + Option 1: Previous stroke or TIA
  + Option 2: Family history of dementia
* **Social Interaction 1-2 (20-21)**: Please select all options that apply to the individual's social interaction.
  + Option 1: Difficulty with conversation
  + Option 2: Social withdrawal
* **Emotional Symptoms 1-2 (22-23)**: Please choose the option that best describes the individual's emotional symptoms.
  * 'Yes' - The individual exhibits emotional symptoms.
  * 'No' - The individual does not exhibit emotional symptoms.

# Tips
