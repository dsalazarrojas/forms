# Living Will Form - Help Guide
## Purpose
This form is used to create a living will, which is a legal document that outlines an individual's medical treatment preferences and end-of-life care in the event of a terminal illness or incapacitation.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category that best describes the form's purpose (e.g., Healthcare Forms).
2. Write a brief description of your medical condition or situation.
3. Choose the tools or resources that you would like to be assigned to you in case of an emergency (e.g., chatjimmy).
4. (Optional) Provide any additional information about your wishes or preferences.

## Field-by-Field Explanation
### 1. Category
* **Category** (Healthcare Forms, Optional): Select the category that best describes the purpose of this form. If unsure, choose "Healthcare Forms" as a default.

### 2. Description
* **Description** (Text, Optional): Write a brief description of your medical condition or situation. This will help your healthcare providers and loved ones understand your needs.

### 3. Assigned Tool
* **Assigned Tool** (Select Multiple, Optional): Choose one or more tools or resources that you would like to be assigned to you in case of an emergency, such as "chatjimmy". You can select multiple options if needed.

### 4. Form ID
* **Form ID** (Number, Optional): This field is not intended for user input. 

### 5. Description (Again)
* **Description** (Text, Optional): This field is intended for any additional information or comments about your wishes or preferences.

## Tips
* Please ensure that you are filling out the correct form based on your needs and situation.
* Take your time to complete this form carefully and accurately.
* Review your form before submitting it to ensure it reflects your true wishes.
* If you are unsure about any field, ask your healthcare provider for guidance.
