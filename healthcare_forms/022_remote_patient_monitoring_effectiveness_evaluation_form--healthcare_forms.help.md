# Remote Patient Monitoring Effectiveness Evaluation Form - Help Guide
## Purpose
This form is designed to gather feedback from patients on the effectiveness of remote patient monitoring systems used in their care.
## How To Complete This Form
To complete this form, please follow these steps:

1. Please answer the questions as honestly and accurately as possible.
2. If you are unsure about any question, please explain your response in the comments section.
3. You can save your progress and come back to the form later if needed.

## Field-by-Field Explanation
* **Patient ID** (`1`, number, required: false): Please enter your patient ID number as recorded in your medical record.
* **Remote Monitoring System** (`2`, select_one, required: false): This question is to determine if you used a remote monitoring system as part of your care. Please select 'Yes' if you did.
* **Overall Effectiveness** (`3`, select_multiple, required: false): This question is to assess the overall effectiveness of the remote monitoring system. Select all that apply:
	+ 'Yes'
	+ 'No'
* **Patient Outcome** (`4`, number, required: false): This question is to gather more specific information about your health outcome. Please enter a numerical value (e.g., 1-10).
* **System Usefulness** (`5`, number, required: false): This question is to assess how useful you found the remote monitoring system. Please enter a numerical value (e.g., 1-10).
* **System Usefulness 2** (`6`, select_one, required: false): This question is to rate the effectiveness of the system for improving your health outcomes. Select:
	+ Good
	+ Fair
* **System Usefulness 3** (`7`, select_one, required: false): This question is to rate the ease of use of the system. Select:
	+ Good
	+ Fair
* **Monitor Frequency** (`8`, date, required: false): This question is to gather information about how often you were monitored. Please enter the date and time of the last monitoring session.
* **Monitor Frequency 2** (`9`, time, required: false): This question is to gather more specific information about the duration of the monitoring session. Please enter the start and end time of the session.
* **Monitor Frequency 3** (`10`, select_one, required: false): This question is to determine if you were monitored frequently. Select:
	+ 'Yes'
	+ 'No'
* **Feedback** (`11`, text, required: false): Please provide any comments or concerns you have about the remote monitoring system. This is an optional field, and you can add as much or as little information as you like.
* **Email** (`12`, email, required: false): This is your contact email address. Please enter your email address if you'd like to receive follow-up questions or notifications from us.
* **Phone** (`13`, text, required: false): This is your phone number. Please enter your phone number if you'd like to receive follow-up calls from us.
* **Resources** (`14`, select_multiple, required: false): This question is to determine if you had access to any additional resources or support. Select all that apply:
	+ 'Yes'
	+ 'No'

Note: Please complete the form as accurately and honestly as possible. If you have any questions or concerns, please don't hesitate to contact us.
