# Network Development Onboarding Form - Help Guide
## Purpose
This form is for onboarding network development projects. It's used to collect project details and assign them a status, priority, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information for your project.
2. Select the correct options from the dropdown menus.
3. Provide a brief description of your project.

## Field-by-Field Explanation

* **Network Development Onboarding Project** (`network_development_onboarding_project`): 
Enter the name of your project.
* **Project Manager** (`project_manager`): 
Select "Yes" if you are the project manager, "No" otherwise.
* **Project Team** (`project_team`): 
Select all applicable options from the dropdown menu.
* **Start Date** (`start_date`): 
Enter the start date of your project.
* **End Date** (`end_date`): 
Enter the end date of your project.
* **Location** (`location`): 
Enter the location of your project.
* **Description** (`description`): 
Provide a brief description of your project.
* **Status** (`status`): 
Select the status of your project from the dropdown menu.
* **Priority** (`priority`): 
Select all applicable options from the dropdown menu.
