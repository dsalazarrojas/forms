# Pathology Report Template - Help Guide
## Purpose
The Pathology Report Template is a form used to document and communicate laboratory test results to patients. It helps healthcare professionals to gather and record information about a patient's test results, which can be used for further diagnosis and treatment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's information in the **Patient Information** field.
2. Enter the patient's ID number in the **Patient ID** field.
3. Enter any relevant information about the lab where the test was performed in the **Lab Information** field.
4. Describe the test results in the **Test Results** field.
5. If applicable, upload any relevant files in the **File Upload** field.
6. Enter the name of the test in the **Test Name** field.
7. Add any relevant pathology findings in the **Pathology Findings** field (note: this field allows for longer text descriptions).

## Field-by-Field Explanation
* **Patient Information** (`patient_info`, text, optional): Enter the patient's name, date of birth, and any other relevant demographic information.
* **Patient ID** (`patient_id`, number, optional): Enter the patient's ID number or a unique identifier.
* **Lab Information** (`lab_info`, text, optional): Enter the name of the lab where the test was performed and any relevant details about the lab or testing procedure.
* **Test Results** (`test_results`, text, optional): Describe the test results, including any notable or unexpected findings.
* **File Upload** (`file_upload`, text, optional): Upload any relevant files or images related to the test results.
* **Submit** (`submit`, text, optional): Confirm that you have completed the form accurately and submit it for review.
* **Pathology Findings** (`pathology_findings`, note, optional): Add any relevant comments or descriptions about the test results, especially if they are significant or unusual.
* **Test Name** (`test_name`, text, optional): Enter the name of the test that was performed.
