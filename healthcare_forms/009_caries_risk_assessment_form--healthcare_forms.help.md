# Caries Risk Assessment Form - Help Guide
## Purpose
The Caries Risk Assessment Form is designed to evaluate the risk of dental caries in a patient. This form will help assess the risk level based on various factors and provide a recommended treatment plan.

## How To Complete This Form
1.  Answer the questions accurately and thoroughly, providing the most up-to-date information available.
2.  For fields with multiple options, choose the one that best describes the patient's condition.
3.  If any information is unclear or unknown, provide the most accurate information available.
4.  Ensure that the required fields are completed accurately.

## Field-by-Field Explanation

* **Patient Full Name** (`patient_name`, text, **required**): Enter the patient's full name as it appears on their medical record.
* **Patient ID Number** (`patient_id`, text, **required**): Enter the patient's medical record number.
* **Date of Birth** (`date_of_birth`, date, **required**): Enter the patient's date of birth.
* **Assessment Date** (`assessment_date`, date, **required**): Enter the current date.
* **Age at Assessment** (`age_at_assessment`, number, **required**): Enter the patient's age in years.
* **Visible Cavities Present** (`visible_cavities`, select_one, **required**): Select the number of surfaces with visible cavities:
	+ None
	+ 1 to 2 surfaces
	+ 3 to 5 surfaces
	+ More than 5 surfaces
* **Approximal Cavities** (`approximal_cavities`, select_one, **required**): Select the number of approximal (between-teeth) cavities:
	+ None
	+ 1 to 2 surfaces
	+ 3 to 5 surfaces
	+ More than 5 surfaces
* **New Restorations in Last 3 Years** (`restorations_last_3_years`, select_one, **required**): Select the number of new restorations in the last 3 years:
	+ None
	+ 1 to 2
	+ 3 to 5
	+ More than 5
* **White Spot Lesions Present** (`white_spot_lesions`, select_one, **required**): Select the number of teeth with white spot lesions:
	+ None
	+ 1 to 2 teeth
	+ 3 to 5 teeth
	+ More than 5 teeth
* **Enamel Lesions Present** (`enamel_lesions`, select_one, **required**): Select the presence of enamel lesions:
	+ None
	+ Yes - localized
	+ Yes - generalized
* **Plaque Level** (`plaque_level`, select_one, **required**): Select the level of plaque on the patient's teeth:
	+ None or minimal
	+ Moderate
	+ Heavy
* **Gingival Health Status** (`gingival_health`, select_one, **required**): Select the patient's gingival health status:
	+ Healthy
	+ Mild gingivitis
	+ Moderate gingivitis
	+ Severe gingivitis
	+ Periodontitis
* **Saliva Assessment** (`saliva_assessment`, note, **optional**): Enter a note regarding the patient's salivary function.
* **Saliva Flow Rate** (`saliva_flow`, select_one, **required**): Select the patient's saliva flow rate:
	+ Normal
	+ Reduced
	+ Very reduced or absent
	+ Not tested
* **Saliva Consistency** (`saliva_consistency`, select_one, **required**): Select the patient's saliva consistency:
	+ Normal - watery
	+ Slightly viscous
	+ Very viscous or sticky
	+ Not assessed
* **Risk Factors** (`risk_factors`, note, **optional**): Enter a note regarding the patient's risk factors.
* **Fluoride Exposure** (`fluoride_exposure`, select_one, **required**): Select the patient's fluoride exposure:
	+ Optimal - daily use
	+ Some - occasional use
	+ Minimal - rare use
	+ None
* **Dietary Sugar Intake** (`dietary_habits`, select_one, **required**): Select the patient's dietary sugar intake:
	+ Low - less than 3 times daily
	+ Moderate - 3 to 5 times daily
	+ High - more than 5 times daily
	+ Very high - constant snacking
* **Between Meal Snacking Frequency** (`between_meal_snacking`, select_one, **required**): Select the frequency of between-meal snacking:
	+ Rarely
	+ 1 to 2 times daily
	+ 3 to 5 times daily
	+ More than 5 times daily
* **Sugary Drink Consumption** (`sugary_drinks`, select_one, **required**): Select the patient's sugary drink consumption:
	+ None
	+ 1 to 2 per week
	+ 1 to 2 per day
	+ 3 or more per day
* **Relevant Medical History** (`medical_history`, select_multiple, **required**): Select any relevant medical history:
	+ None
	+ Diabetes
	+ Dry mouth conditions
	+ GERD or acid reflux
	+ Eating disorders
	+ Radiation therapy to head or neck
	+ Medications causing dry mouth
	+ Special healthcare needs
* **Social History Factors** (`social_history`, select_multiple, **optional**): Select any social history factors:
	+ None
	+ Limited access to dental care
	+ Substance abuse
	+ Tobacco use
	+ Low socioeconomic status
	+ Caregiver dependency
* **Protective Factors** (`protective_factors`, note, **optional**): Enter a note regarding the patient's protective factors.
* **Fluoride Toothpaste Use** (`fluoride_toothpaste`, select_one, **required**): Select the patient's fluoride toothpaste use:
	+ Yes - twice daily
	+ Yes - once daily
	+ Occasionally
	+ False
* **Dental Visits** (`dental_visits`, select_one, **required**): Select the patient's dental visit frequency:
	+ Every 6 months
	+ Annually
	+ Irregularly
	+ Rarely or never
* **Dental Sealants Present** (`sealants_present`, select_one, **required**): Select the presence of dental sealants:
	+ Yes - all molars
	+ Yes - some molars
	+ False
* **Xylitol Use** (`xylitol_use`, select_one, **optional**): Select the patient's xylitol product use:
	+ Yes - daily
	+ Yes - occasionally
	+ False
* **Overall Caries Risk Assessment** (`risk_assessment`, select_one, **required**): Select the overall caries risk level:
	+ Low risk
	+ Moderate risk
	+ High risk
	+ Extreme risk
* **Rationale for Risk Level** (`risk_rationale`, text, **required**): Enter a clinical reasoning for the selected risk level.
* **Recommended Treatment Plan** (`treatment_plan`, text, **required**): Enter a recommended treatment plan for the patient.
* **Recommended Recall Interval** (`recall_interval`, select_one, **required**): Select the recommended recall interval:
	+ 3 months
	+ 6 months
	+ 9 months
	+ 12 months
	+ As needed
* **Assessing Dentist's Name** (`dentist_name`, text, **required**): Enter the dentist's name.
* **Assessment Date and Signature** (`dentist_signature_date`, date, **required**): Enter the assessment date and sign below.

Note: The fields with `**required**` are compulsory fields. Please ensure that they are accurately completed before submitting the form.
