# Inpatient Care Discharge Form - Help Guide
## Purpose
This form is used to document the discharge of an inpatient patient, ensuring that all relevant details are accurately recorded.

## How To Complete This Form
1. Fill in the patient's name.
2. Enter the admission date of the patient.
3. Enter the discharge date and time.
4. Choose the patient's discharge disposition (e.g., home, skilled nursing facility).
5. Provide the follow-up provider's name.
6. Enter the follow-up provider's phone number.
7. Choose the follow-up date.
8. Specify the discharge status (e.g., completed, incomplete, pending).
9. Enter the follow-up location.
10. Provide any follow-up instructions.
11. Enter any follow-up notes.
12. (Optional) Enter the follow-up provider's name if different from the main follow-up provider.
13. (Optional) Enter the follow-up phone number if different from the main follow-up provider.
14. Choose the discharge diagnosis(es) (e.g., heart failure, hypertension).
15. (Optional) Choose any follow-up diagnoses.
16. (Optional) List any follow-up allergies.
17. (Optional) List any follow-up medications.
18. (Optional) List any discharge medications.
19. (Optional) List any follow-up tests.
20. (Optional) List any other follow-up tests.
21. (Optional) Enter any follow-up test results.
22. (Optional) Enter any other follow-up test results.
23. (Optional) Enter any discharge notes.

## Field-by-Field Explanation
* **patient name** (`patient_name`, text, required): Enter the patient's full name.
* **admission date** (`admission_date`, date, optional): Record the date the patient was admitted.
* **discharge date** (`discharge_date`, date, required): Enter the date the patient was discharged.
* **discharge disposition** (`discharge_disposition`, select_one, required): Choose the reason for the patient's discharge (e.g., home, skilled nursing facility).
* **follow up provider** (`follow_up_provider`, text, required): Enter the name of the follow-up provider.
* **follow up phone** (`follow_up_phone`, text, required): Enter the phone number of the follow-up provider.
* **follow up date** (`follow_up_date`, date, required): Choose the follow-up date.
* **discharge status** (`discharge_status`, select_one, required): Specify the discharge status (e.g., completed, incomplete, pending).
* **follow up location** (`follow_up_location`, text, required): Enter the location where the follow-up will take place.
* **follow up instructions** (`follow_up_instructions`, text, required): Provide any additional instructions for the follow-up care.
* **follow up note** (`follow_up_note`, note, required): Enter any additional follow-up notes.
* **discharge diagnosis** (`discharge_diagnosis`, select_multiple, required): Choose any discharge diagnosis (e.g., heart failure, hypertension).
* **follow up diagnosis** (`follow_up_diagnosis`, select_multiple, optional): Choose any follow-up diagnosis.
* **follow up allergies** (`follow_up_allergies`, text, optional): List any allergies that the patient has.
* **follow up medications** (`follow_up_medications`, text, optional): List any medications that the patient will need during follow-up.
* **discharge medications** (`discharge_medications`, text, optional): List any medications that were administered during discharge.
* **follow up tests** (`follow_up_tests`, text, optional): List any tests that the patient will need during follow-up.
* **other tests** (`follow_up_tests_other`, text, optional): List any other tests that the patient will need during follow-up.
* **other test results** (`follow_up_test_results`, text, optional): Enter any other test results.
* **discharge notes** (`discharge_notes`, note, optional): Enter any additional discharge notes.
