# Parent Guardian Attestation - Help Guide
## Purpose
The Parent Guardian Attestation form is designed to gather information about a child's health status in relation to COVID-19. The form asks questions about the child's symptoms, contacts, and travel history to help healthcare professionals assess the child's risk of exposure and take necessary precautions.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions about the child's health status as accurately as possible.
2. Choose the correct options for each question from the provided list.
3. If a question does not apply to the child, choose the "False" option.
4. If the child has a medical condition that requires special consideration, inform the healthcare provider.
5. Submit the completed form to the healthcare provider.

## Field-by-Field Explanation

* **Parent Guardian Attestation**
	+ This is a label to identify the parent or guardian completing the form.
	+ No explanation is required as it's a simple label to identify the person completing the form.

* **Has Covid**
	+ Select "True" if the child has a known or suspected COVID-19 infection.
	+ Select "False" if the child does not have a known or suspected COVID-19 infection.

* **Has Covid Symptoms**
	+ Select the level of symptoms the child is experiencing:
		- "mild" if the symptoms are mild and not severe.
		- "moderate" if the symptoms are moderate and affecting the child's daily activities.
		- "severe" if the symptoms are severe and affecting the child's ability to breathe or stay alert.

* **Has Temperature**
	+ Select the child's current temperature:
		- "normal" if the child's temperature is normal.
		- "high" if the child has a high temperature.

* **Contact With Someone Diagnosed With Covid**
	+ Select "True" if someone in the household has been diagnosed with COVID-19.
	+ Select "False" if no one in the household has been diagnosed with COVID-19.

* **Contact With Someone With Covid Symptoms**
	+ Select "True" if someone in the household is currently experiencing COVID-19 symptoms.
	+ Select "False" if no one in the household is experiencing COVID-19 symptoms.

* **Travelled Abroad**
