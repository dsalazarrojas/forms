# tell_us_about_yourself - Help Guide
## Purpose
This form collects demographic and personal information to create a comprehensive dataset for analysis, research, or administrative purposes.

## How To Complete This Form

1. Start by reading the form carefully and ensuring you understand the purpose of each field.
2. Fill out the form according to the instructions provided for each field.
3. Double-check your answers for accuracy and completeness.

## Field-by-Field Explanation

* **1. Tell Us About Yourself (tell_us_about_yourself)**: This field is a title that serves as a header for the form.
* **2. Name (name)**: Please enter your name, as you would like it to be displayed.
	+ Type: text
	+ Required: False
* **3. Name (name)**: This is a redundant field and not required. If you have already entered your name in the previous field, you can skip this one.
	+ Type: text
	+ Required: False
* **4. Email (email)**: Please enter your valid email address.
	+ Type: email
	+ Required: False
* **5. Phone (phone)**: Please enter your phone number.
	+ Type: text
	+ Required: False
* **6. Address (address)**: Please enter your address.
	+ Type: text
	+ Required: False
* **7. Birthdate (birthdate)**: Please enter your birthdate in the format "MM/DD/YYYY".
	+ Type: date
	+ Required: False
* **8. Gender (gender)**: Please select your gender from the provided options.
	+ Type: select_one
	+ Required: False
	+ Options: male, female, other, unknown
* **9. Ethnicity (ethnicity)**: Please select your ethnicity from the provided options.
	+ Type: select_one
	+ Required: False
	+ Options: hispanic, non hispanic
* **10. Education (education)**: Please select your education level from the provided options.
	+ Type: select_multiple
	+ Required: False
	+ Options: less than high school, some college, bachelors, masters, unknown
* **11. Income (income)**: Please select your income range from the provided options.
	+ Type: select_multiple
	+ Required: False
	+ Options: less than 10000, 10000 to 20000, 20000 to 50000, 50000 to 75000, 75000 to 100000, 100000 to 150000, more than 150000
* **12. Occupation (occupation)**: Please enter your occupation.
	+ Type: text
	+ Required: False
* **13. Occupation Other (occupation_other)**: This field is for any additional information about your occupation.
	+ Type: text
	+ Required: False
* **14. Insurance (insurance)**: Please select your insurance type from the provided options.
	+ Type: select_one
	+ Required: False
	+ Options: private, public, other
* **15. Insurance Other (insurance_other)**: This field is for any additional information about your insurance.
	+ Type: text
	+ Required: False
* **16. Emergency Contact (emergency_contact)**: Please enter the name of your emergency contact.
	+ Type: text
	+ Required: False
* **17. Emergency Contact Relationship (emergency_contact_relationship)**: Please describe your relationship with the emergency contact.
	+ Type: text
	+ Required: False
* **18. Emergency Contact Phone (emergency_contact_phone)**: Please enter the phone number of your emergency contact.
	+ Type: text
	+ Required: False
* **19. Emergency Contact Address (emergency_contact_address)**: Please enter the address of your emergency contact.
	+ Type: text
	+ Required: False
* **20. Emergency Contact Relationship Other (emergency_contact_relationship_other)**: This field is for any additional information about your emergency contact relationship.
	+ Type: text
	+ Required: False
* **21. Employment Status (employment_status)**: Please select your employment status from the provided options.
	+ Type: select_one
	+ Required: False
	+ Options: working, not working, student, other
* **22. Employment Status Other (employment_status_other)**: This field is for any additional information about your employment status.
	+ Type: text
	+ Required: False
* **23. Employment Other (employment_other)**: This field is for any additional information about your employment.
	+ Type: text
	+ Required: False
* **24. Employment Length (employment_length)**: Please select your employment length from the provided options.
	+ Type: select_multiple
	+ Required: False
	+ Options: less than 1 year, 1 to 2 years, 2 to 5 years, more than 5 years
* **25. Employment Length Other (employment_length_other)**: This field is for any additional information about your employment length.
	+ Type: text
	+ Required: False
* **26. Employment Type (employment_type)**: Please select your employment type from the provided options.
	+ Type: select_one
	+ Required: False
	+ Options: employed, unemployed, student, other
* **27. Employment Type Other (employment_type_other)**: This field is for any additional information about your employment type.
	+ Type: text
	+ Required: False
