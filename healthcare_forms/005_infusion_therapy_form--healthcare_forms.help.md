# infusion_therapy_form - Help Guide
## Purpose
The Infusion Therapy Form is designed to collect information from patients about their medical history, therapy type, and other relevant details for administering infusion therapy.

## How To Complete This Form
1. **Patient Information (1)**: This field is a text field for entering the patient's information. Enter the patient's name, date of birth, and any other relevant details.
2. **Medical Organizations (2)**: This is a dropdown list of medical organizations that the patient may have visited in the past. Select all organizations that apply to the patient's medical history.
3. **Date (3)**: Enter the date of the patient's visit or treatment. Use the correct format to avoid errors (YYYY-MM-DD).
4. **Time (4)**: Enter the time of the patient's visit or treatment. Use the correct format to avoid errors (HH:MM:SS or 24-hour format).
5. **Note (5)**: This field is for additional notes or comments about the patient's visit or treatment.
6. **Email (6)**: Enter the patient's email address if available.
7. **Phone (7)**: Enter the patient's phone number if available.
8. **Medical History (8)**: Describe the patient's medical history, including any allergies, conditions, or previous treatments.
9. **Infusion Information (9)**: Enter any relevant information about the infusion therapy, such as the treatment plan or dosage.
10. **Therapy Type (10)**: Select the type of therapy the patient is undergoing. This will help healthcare professionals understand the treatment plan.
11. **Assigned Tool (11)**: Select the tool assigned to the patient for the therapy. This will help healthcare professionals understand the equipment used for the treatment.
12. **Output File (12)**: This field is for entering any additional output files or documents related to the patient's treatment.
13. **Infusion Form (13)**: This field is not currently used and can be ignored.
14. **Category (14)**: Select the category of the treatment (e.g., Healthcare).
15. **Description (15)**: Enter a brief description of the patient's treatment or condition.
16. **Form ID (16)**: This field is not currently used and can be ignored.
17. **Category ID (17)**: This field is not currently used and can be ignored.
