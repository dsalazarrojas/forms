# Deceased Parent Medical Record Request Form - Help Guide
## Purpose
The Deceased Parent Medical Record Request Form is a document used to request access to the medical records of a deceased parent. This form is designed to collect necessary information for estate management, insurance claims, or other legal matters related to the deceased individual.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the basic information about the deceased parent, including their name, date of birth, and date of death.
2. Provide the name of the physician who treated the deceased parent, if known.
3. If applicable, provide the physician's license number and the name of the facility where they treated the deceased parent.
4. Describe the reason for requesting the medical record, and provide any additional comments or information related to the request.
5. Select the individual or entity submitting the request, if you are authorized to do so.
6. Add any relevant submitter information, if required.

## Field-by-Field Explanation
* **Form Information (1)**: Enter a brief description of the purpose of this request.
* **Deceased Parents Name (2)**: Enter the full name of the deceased parent.
* **Deceased Parents DOB (3)**: Enter the date of birth of the deceased parent.
* **Deceased Parents Death Date (4)**: Enter the date of death of the deceased parent.
* **Physician Name (5)**: Enter the name of the physician who treated the deceased parent.
* **Physician License Number (6)**: Enter the medical license number of the physician who treated the deceased parent, if known.
* **Facility Name (7)**: Enter the name of the facility where the deceased parent was treated.
* **Medical Record Request Reason (8)**: Explain the reason for requesting the medical record, and provide any additional comments or information related to the request.
* **Medical Record Request Comments (9)**: Add any additional comments or information related to the request.
* **Submitted By (10)**: Select the individual or entity submitting the request, if authorized.
* **Submitter Information (11)**: Enter any relevant submitter information, if required.
