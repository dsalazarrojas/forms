# Nursing Home Incident Report Form - Help Guide

## Purpose

The Nursing Home Incident Report Form is designed to gather information on incidents that have occurred within the nursing home environment. This form helps to ensure that incidents are documented accurately and thoroughly, and that necessary actions can be taken to prevent future occurrences.

## How To Complete This Form

1. Review the form carefully to understand what information is required.
2. Ensure that you have all necessary information before starting to fill out the form.
3. Complete the form in a clear and accurate manner.
4. Review your answers before submitting.

## Field-by-Field Explanation

- **Resident Info**: Enter the information of the resident involved in the incident. This can include their name, ID number, or other identifying details.
  - Type: Text
  - Required: False
  - Hint: Enter the resident's name, ID number, or other identifying details.

- **Incident Details**: Describe the incident in as much detail as possible. This can include what happened, when it happened, and where it happened.
  - Type: Text
  - Required: False
  - Hint: Provide a clear and detailed description of the incident.

- **Incident Location**: Enter the location of the incident.
  - Type: Text
  - Required: False
  - Hint: Enter the room number or exact location where the incident occurred.

- **Incident Date**: Enter the date the incident occurred. This must be in the format YYYY-MM-DD.
  - Type: Date
  - Required: False
  - Hint: Enter the date in the format YYYY-MM-DD.

- **Incident Description**: Enter a detailed description of the incident.
  - Type: Text
  - Required: False
  - Hint: Provide a clear and detailed description of the incident.

- **Witness Info**: If there were any witnesses to the incident, enter their information here.
  - Type: Text
  - Required: False
  - Hint: Enter the names and contact information of any witnesses.

- **Staff Involved**: If staff members were involved in the incident, enter their information here.
  - Type: Text
  - Required: False
  - Hint: Enter the names and contact information of any staff members involved.

- **Incident Outcome**: Describe the outcome of the incident.
  - Type: Text
  - Required: False
  - Hint: Enter the outcome of the incident, including any actions taken or consequences.

- **Resident Signature**: The resident must sign the form to confirm that the information is accurate.
  - Type: Text
  - Required: False
  - Hint: The resident's signature must be legible and clear.

- **Staff Signature**: A staff member must sign the form to confirm that they witnessed the incident or were involved in reporting it.
  - Type: Text
  - Required: False
  - Hint: A staff member's signature must be legible and clear.

- **Incident Reporter**: Enter the name and contact information of the person reporting the incident.
  - Type: Text
  - Required: False
  - Hint: Enter the name and contact information of the person reporting the incident.

- **Submission Date**: Enter the date the form was submitted.
  - Type: Date
  - Required: False
  - Hint: Enter the date in the format YYYY-MM-DD.

- **Submitter**: Enter the name and contact information of the person submitting the form.
  - Type: Text
  - Required: False
  - Hint: Enter the name and contact information of the person submitting the form.

- **Submitter Phone**: Enter the phone number of the person submitting the form.
  - Type: Text
  - Required: False
  - Hint: Enter the phone number of the person submitting the form.

- **Incident Report**: Select the type of incident reported.
  - Type: Select One
  - Required: False
  - Hint: Select the type of incident from the provided options.

- **Incident Type**: Select all types of incidents that occurred.
  - Type: Select Multiple
  - Required: False
  - Hint: Select all types of incidents that occurred from the provided options.

- **Submitter Email**: Enter the email address of the person submitting the form.
  - Type: Text
  - Required: False
  - Hint: Enter the email address of the person submitting the form.

- **Submitter Address**: Enter the address of the person submitting the form.
  - Type: Text
  - Required: False
  - Hint: Enter the address of the person submitting the form.

- **Submitter DOB**: Enter the date of birth of the person submitting the form.
  - Type: Date
  - Required: False
  - Hint: Enter the date of birth in the format YYYY-MM-DD.

- **Resident Name**: Select the resident involved in the incident.
  - Type: Select One
  - Required: False
  - Hint: Select the resident's name from the provided options.

- **Staff Name**: Select the staff member involved in the incident.
  - Type: Select One
  - Required: False
  - Hint: Select the staff member's name from the provided options.

- **Submitter Gender**: Select the gender of the person submitting the form.
  - Type: Select One
  - Required: False
  - Hint: Select the gender from the provided options.

- **Submitter Title**: Select the title of the person submitting the form.
  - Type: Select One
  - Required: False
  - Hint: Select the title from the provided options.

- **Submitter Relationship**: Select the relationship of the person submitting the form to the resident.
  - Type: Select One
  - Required: False
  - Hint: Select the relationship from the provided options.

- **Incident Time**: Enter the time of the incident.
  - Type: Time
  - Required: False
  - Hint: Enter the time in 24-hour format (HH:MM:SS).
