# Fluid Balance Assessment Form - Help Guide
## Purpose
The Fluid Balance Assessment Form is a tool used by healthcare professionals to assess a patient's fluid balance status. It helps to identify potential complications and inform patient care.

## How To Complete This Form
1. **Patient ID**: Enter the patient's ID number, which can be found on their hospital chart or medical record.
2. **Date**: Enter the date of the assessment, using the date format (YYYY-MM-DD).
3. **Fluid Balance Assessment Form - Patient Weight**: Enter the patient's current weight in kg or lbs.
4. **Fluid Balance Assessment Form - Intake**: Enter the total fluid intake (mL) in 24 hours.
5. **Fluid Balance Assessment Form - Output**: Enter the total fluid output (mL) in 24 hours.
6. **Vital Signs - Fluid Balance Assessment Form**: Select 'Normal' if the patient's vital signs are within the normal range, or 'Abnormal' if they are not.
7. **Vital Signs - Blood Pressure - Fluid Balance Assessment Form**: Select 'Yes' if the patient's blood pressure is within the normal range, or 'No' if it is not.
8. **Vital Signs - Temperature - Fluid Balance Assessment Form**: Select 'Normal' (<37°C), 'Abnormal' (36-37°C), or 'Critical' (<36°C) based on the patient's body temperature.
9. **Vital Signs - Pupil Size - Fluid Balance Assessment Form**: Select 'Yes' if the pupil size is normal or 'No' if it is not.
10. **Vital Signs - Heart Rate - Fluid Balance Assessment Form**: Select 'Good' if the heart rate is within the normal range or 'Fair' if it is not.
11. **Vital Signs - Respiratory Rate - Fluid Balance Assessment Form**: Select 'Good' if the respiratory rate is within the normal range or 'Fair' if it is not.
12. **Medical History - Fluid Balance Assessment Form**: Select 'Yes' if the patient has a medical history that may affect fluid balance, or 'No' if not.
13. **Medications - Fluid Balance Assessment Form**: Select 'Yes' if the patient is on medications that may affect fluid balance, or 'No' if not.
14. **Allergies - Fluid Balance Assessment Form**: Select 'Yes' if the patient has allergies that may affect fluid balance, or 'No' if not.
15. **Fluid Balance Assessment Form - Notes**: Use this field to record any additional information or observations related to the patient's fluid balance.
16. **Fluid Balance Assessment Form - Comments**: Use this field for any additional comments or concerns about the patient's fluid balance.
