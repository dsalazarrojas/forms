# Food Consumption Survey - Help Guide

## Purpose
This form is designed to collect information about an individual's food consumption habits, including how often they eat fast food, how much fast food they consume per day, their fruit and vegetable intake, healthy and unhealthy food preferences, and potential food allergies or medical conditions.

## How To Complete This Form
To complete this form, follow the steps outlined in the above guide.

## Field-by-Field Explanation

* **How Many Times Do You Eat Fast Food Per Week**:
  * 1-2 times: Select this option if you eat fast food 1-2 times a week.
  * 3-5 times: Select this option if you eat fast food 3-5 times a week.
  * Daily: Select this option if you eat fast food every day.
* **How Much Fast Food Do You Consume Per Day**:
  * 1: Select this option if you consume 1 serving of fast food per day.
  * 2: Select this option if you consume 2 servings of fast food per day.
  * 3: Select this option if you consume 3 servings of fast food per day.
  * 4: Select this option if you consume 4 servings of fast food per day.
  * 5: Select this option if you consume 5 servings of fast food per day.
* **How Many Servings Of Fruits Do You Typically Eat Per Day**:
  * Type in the number of servings of fruits you typically eat per day.
* **How Many Servings Of Vegetables Do You Typically Eat Per Day**:
  * Type in the number of servings of vegetables you typically eat per day.
* **What Healthy Foods Do You Consume Per Week**:
  * Salad: Select this option if you consume salad per week.
  * Baked Chicken: Select this option if you consume baked chicken per week.
  * Fresh Fruits: Select this option if you consume fresh fruits per week.
* **What Unhealthy Foods Do You Consume Per Week**:
  * Pizza: Select this option if you consume pizza per week.
  * Burger: Select this option if you consume burger per week.
  * Fries: Select this option if you consume fries per week.
* **What Foods Do You Prefer**:
  * Fries: Select this option if you prefer fries.
  * Pizza: Select this option if you prefer pizza.
  * Ice Cream: Select this option if you prefer ice cream.
* **Do You Have Any Food Allergies**:
  * Yes: Select this option if you have any food allergy.
  * No: Select this option if you do not have any food allergy.
  * Maybe: Select this option if you are unsure about having any food allergy.
* **Do You Have Any Medical Conditions**:
  * Yes: Select this option if you have any medical condition.
  * No: Select this option if you do not have any medical condition.
  * Maybe: Select this option if you are unsure about having any medical condition.

## Tips
* Please answer all questions honestly and thoroughly.
* If you are unsure about any question, select the 'Maybe' option.
* Make sure to type in the exact number of servings for questions that ask for servings.
* Select all that apply for questions that ask for multiple options.
