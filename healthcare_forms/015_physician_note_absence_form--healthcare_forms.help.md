# Physician Note Absence Form - Help Guide
## Purpose
This form is used to document a healthcare professional's absence from work or other activities, including the reason for the absence, start and end dates (if applicable), and other relevant details.

## How To Complete This Form
1. Start by checking if an absence record for this healthcare professional already exists. If it does, you do not need to fill out this form again.
2. Fill out the form with the necessary information:
   - Select the reason for absence from the provided options (Medical, Personal, or Other).
   - Enter the start date of the absence, if applicable.
   - Enter the end date of the absence, if applicable.
   - Provide a brief note about the absence.
   - Select the medical cause (Medical Reasons, Medical Conditions, or Other Medical Reasons, or Other Medical Conditions).
   - Check if employer and institution notifications are required.
   - Enter the healthcare professional's ID.
   - Enter the healthcare professional's name.
   - Enter the employer's email.

## Field-by-Field Explanation

* **Physician Note Absence Form**: This is the title of the form.
* **reason_for_absence**: Select the reason for the healthcare professional's absence. This can be Medical, Personal, or Other.
* **start_date**: If applicable, enter the date the absence started. 
* **end_date**: If applicable, enter the date the absence ended.
* **physician_note**: Provide a brief note about the absence, for reference.
* **medical_cause**: Select the medical cause of the absence. This can be Medical Reasons, Medical Conditions, Other Medical Reasons, or Other Medical Conditions.
* **employer_notification**: Check if the healthcare professional's employer needs to be notified about the absence.
* **institution_notification**: Check if the institution needs to be notified about the absence.
* **employee_id**: Enter the healthcare professional's ID number.
* **employee_name**: Enter the healthcare professional's name.
* **employer_email**: Enter the email address of the healthcare professional's employer.
* **institution**: Enter the name of the institution where the healthcare professional works. 

## Tips
- Ensure the form is filled out accurately and completely to avoid confusion or errors.
- Double-check the information provided before submitting the form.
- If you are unsure about any of the fields, consult with the relevant healthcare professional or administrator.
