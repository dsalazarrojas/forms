# Patient Medical History Survey - Help Guide
## Purpose
This form is designed to collect comprehensive medical history information from patients.

## How To Complete This Form
1. Select the relevant pages based on the patient's information.
2. Fill in the required and optional fields as per the page instructions.
3. Review the form for accuracy and completeness before submission.

## Field-by-Field Explanation

### Medical History (Page 1)
* **Medical History (medical_history)**: This field is for the patient's medical history. Please provide a brief description of the patient's medical history, including any previous illnesses, treatments, or surgeries.
* **Medical Condition (medical_condition)**: This field is for listing any medical conditions the patient has or has had. Please select from the provided options or type in any other conditions.
* **Medication Use (medication_use)**: This field is for listing any medications the patient is currently taking. Please select from the provided options or type in any other medications.

### Allergies and Surgical History (Page 2)
* **Allergy (allergy)**: This field is for listing any allergies the patient has. Please select from the provided options or type in any other allergies.
* **Surgical History (surgical_history)**: This field is for listing any surgical procedures the patient has undergone. Please provide a brief description of each procedure.
* **Medical Devices (medical_devices)**: This field is not applicable in this example.

### Medical Information (Page 3)
* **Medication (medication)**: This field is for listing any medications the patient is currently taking. Please select from the provided options or type in any other medications.
* **Health Care Provider (health_care_provider)**: This field is for listing the patient's current healthcare provider. Please provide the name and contact information of the healthcare provider.
* **Medical Condition List (medical_condition_list)**: This field is for listing any medical conditions the patient has or has had. Please select from the provided options or type in any other conditions.
* **Medication List (medication_list)**: This field is for listing any medications the patient is currently taking. Please select from the provided options or type in any other medications.
* **Allergy List (allergy_list)**: This field is for listing any allergies the patient has. Please select from the provided options or type in any other allergies.

### Contact and Date Information (Page 4)
* **Contact Number (contact_number)**: This field is for listing the patient's contact information. Please provide the phone number or other contact method.
* **Email (email)**: This field is for listing the patient's email address. Please provide the email address.
* **Medical History Date (medical_history_date)**: This field is for the date of the patient's medical history. Please select the date from the calendar picker or type in the date manually.
* **Medical History Time (medical_history_time)**: This field is for the time of the patient's medical history. Please select the time from the clock picker or type in the time manually.
* **Patient Name (patient_name)**: This field is for the patient's name. Please provide the name as per the format (First Name Last Name).
* **Patient Age (patient_age)**: This field is for the patient's age. Please select the age from the provided options or type in the age manually.
* **Blood Type (blood_type)**: This field is for listing the patient's blood type. Please select from the provided options or type in any other blood type.
* **Note (note)**: This field is for providing any additional comments or notes about the patient's medical history. Please provide any relevant information.

### Survey Completion (Page 5)
* **Medical Survey Completion Date (medical_survey_completion_date)**: This field is for the date the survey was completed. Please select the date from the calendar picker or type in the date manually.
* **Medical Survey Completion Time (medical_survey_completion_time)**: This field is for the time the survey was completed. Please select the time from the clock picker or type in the time manually.
* **Survey Completed By (survey_completed_by)**: This field is for listing the person who completed the survey. Please select from the provided options or type in any other person's name.
* **Medical Survey Completion Time Zone (medical_survey_completion_time_zone)**: This field is not applicable in this example.
* **Medical Survey Completion Date Zone (medical_survey_completion_date_zone)**: This field is not applicable in this example.
* **Medical Survey Completion Time Zone (medical_survey_completion_timezone)**: This field is not applicable in this example.

## Tips
1. Review the form for accuracy and completeness before submission.
2. Ensure all required fields are filled in.
3. If unsure about any field, please contact the healthcare provider or the survey administrator.
