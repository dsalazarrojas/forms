# Rapid Antigen Template - Help Guide

## Purpose
The Rapid Antigen Template is a form used to collect and manage patient data for rapid antigen testing. This guide will walk you through the process of completing the form.

## How To Complete This Form
To start, ensure you have all the necessary information ready and follow these steps:

1. **Enter the patient's name**: Type the patient's name in the text field.
2. **Select the antigen type**: Select all applicable options for the patient's antigen type.
3. **Enter the job number**: If required, enter the job number in the numerical field.

## Field-by-Field Explanation
### Patient Name
* **Patient Name (patient_name)** (optional): Enter the name of the patient, including any relevant identifiers such as initials or nickname.

### Antigen Type
* **Antigen Type (antigen_type)** (optional): Select all relevant options from the provided list that apply to the patient's antigen type.

### Job Number
* **Job Number (job_number)** (optional): Enter the job number, if applicable, to associate with the patient's record.

## Tips
* If you are unsure of the antigen type, refer to the relevant medical literature or seek guidance from a healthcare professional.
* Ensure you have the necessary permissions to access and enter patient data.
* Review the form carefully before submitting to ensure all required and optional fields are complete.
