# group_therapy_informed_consent_form - Help Guide

## Purpose
This form is intended to be a document for informed consent in group therapy settings, allowing therapists or facilitators to inform their clients about the services they provide.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter a title in the "Group Therapy Informed Consent Form" field.
2. Select the category of the form from the options provided (e.g., "Healthcare Forms" or "Other forms").
3. Optionally add a description of the form, explaining its purpose and content.
4. Optionally enter a unique ID for the form.
5. Optionally select an assigned tool or platform where the form will be used.

## Field-by-Field Explanation
* **Group Therapy Informed Consent Form** (`form_title`, text, required): Enter a title that will represent this form in the system.
* **Category** (`category`, select_one, required): Select the category of this form (e.g., "Healthcare Forms" or "Other forms").
* **Description** (`description`, note, required): A detailed description of this form, explaining its purpose and content.
* **Form ID** (`form_id`, text, required): Enter a unique ID for this form.
* **Assigned Tool** (`assigned_tool`, text, required): Select the tool or platform where this form will be used.

## Tips
* Please ensure that the title accurately represents the form's purpose and content.
* Use a clear and concise description to inform clients about the therapy services.
* Select the correct category and tool to ensure proper form usage and tracking.
* Enter a unique ID to avoid duplicates and ensure correct form identification.
