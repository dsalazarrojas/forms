# Dementia Screening Form - Help Guide

## Purpose

## How To Complete This Form

### Step 1: Collect Patient Information

* Complete the "Patient Information" page with the patient's details, including any relevant medical history.

### Step 2: Assess Cognitive Decline

* Answer the screening questions in the "Screening Questions" page to help assess the patient's cognitive decline over the last 5 years or more.

### Step 3: Identify Risk Factors

* Select any relevant risk factors for dementia in the "Risk Factors" page that the patient has experienced.

### Step 4: Document Medical History

* Provide a brief description of the patient's medical history in the "Medical History" page.

### Step 5: Evaluate Cognitive Function

* Choose the relevant cognitive functions that the patient is experiencing difficulty with in the "Cognitive Function" page.

### Step 6: Record Diagnosis and Treatment Plan

* Select the diagnosis and treatment plan for the patient from the options provided in the "Diagnosis" and "Treatment Plan" pages.

### Step 7: Record Medications

* List any medications the patient is currently taking in the "Medications" page.

### Step 8: Update Patient Status

* Provide an update on the patient's status and any changes in their condition in the "Patient Status" page.

## Field-by-Field Explanation

### Patient Information (page 1)

* **Patient Name** (`text`, required): Enter the patient's name.
* **Date of Birth** (`date`, required): Enter the patient's date of birth.
* **Contact Information** (`text`, required): Enter the patient's contact information.

### Screening Questions (page 2)

* **Screening Questions** (`select_multiple`, required): Select one or more of the following:
	+ Cognitive decline in the last year?
	+ Cognitive decline in the last 5 years?
	+ Cognitive decline in the last 10 years?
	+ Cognitive decline in the last 15 years?
	+ Cognitive decline in the last 20 years?

### Cognitive Impairment (page 3)

* **Cognitive Impairment Description** (`text`, required): Describe the patient's cognitive impairment.

### Risk Factors (page 4)

* **Risk Factors** (`select_multiple`, required): Select any relevant risk factors:
	+ Vascular disease
	+ Traumatic brain injury
	+ Neurodegenerative disease
	+ Infection
	+ Inflammation
	+ Autoimmune disease
	+ Tumors
	+ Other

### Medical History (page 5)

* **Medical History** (`text`, required): Provide a brief description of the patient's medical history.

### Cognitive Function (page 6)

* **Cognitive Function** (`select_multiple`, required): Select any of the following cognitive functions that are affected:
	+ Memory
	+ Language
	+ Problem solving
	+ Executive function
	+ Motor function
	+ Emotional function
	+ Attention
	+ Perception
	+ Orientation
	+ Social interaction

### Diagnosis (page 7)

* **Diagnosis** (`select_one`, required): Select one of the following options:
	+ None
	+ Mild cognitive impairment
	+ Moderate cognitive impairment
	+ Severe cognitive impairment
	+ Dementia

### Treatment Plan (page 8)

* **Treatment Plan** (`text`, required): Describe the treatment plan for the patient.

### Medications (page 9)

* **Medications** (`text`, required): List any medications the patient is currently taking.

### Patient Status (page 10)

* **Patient Status** (`text`, required): Provide an update on the patient's status and any changes in their condition.

## Tips

* Please answer all questions honestly and accurately to ensure a thorough assessment.
* If you are unsure about any of the questions, please consult with the patient's primary care physician.
* This form is for screening purposes only and should not be used as a definitive diagnosis.
* Please refer to the patient's medical record for a final diagnosis and treatment plan.
