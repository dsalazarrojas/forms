# File Upload Form - Help Guide
## Purpose
The File Upload Form is used for uploading files of different types, such as images, videos, and audio files.

## How To Complete This Form
1. Select the type of file you want to upload (Image, Video, or Audio).
2. Fill in the file upload field with the file you want to upload.
3. Make sure to fill in all required fields to complete the form successfully.

## Field-by-Field Explanation
* **Upload-File**: (<name>, <type>, required/optional: text, optional>):
	+ This is the field where you upload your file. You can upload any type of file, but you must select its type in the field below.
* **File-Type**: (<name>, <type>, required/optional: select_one, optional>):
	+ Use this field to select the type of file you are uploading. You can choose from Image, Video, or Audio.
* There is no required field, so feel free to fill in the fields as needed.
