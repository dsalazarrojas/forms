# Hospice Service Quotation Form - Help Guide
## Purpose
This form is used to collect information for creating a quote for hospice services. It gathers patient details, service specifics, payment information, and contact details necessary for the quote creation process.

## How To Complete This Form
- Fill out the form with all required and optional fields as necessary.
- Ensure accuracy and consistency of information throughout the form.
- Review and verify all entered information before submission.
- Submit the form to create a comprehensive quote for the hospice services.

## Field-by-Field Explanation

* **Patient Information (1)**: 
  * Patient Information: This field is for collecting basic patient details, such as name, date of birth, and medical history.
  * Type: text
  * Required: false

* **Service Information (2)**: 
  * Service Information: Enter the specific details of the service needed, such as service type and frequency.
  * Type: text
  * Required: false

* **Care Team (3)**: 
  * Care Team: List the names and qualifications of the healthcare team involved in the patient's care.
  * Type: text
  * Required: false

* **Client Preferences (4)**: 
  * Client Preferences: Note any specific preferences or requirements for the patient's care.
  * Type: text
  * Required: false

* **Service Details (5)**: 
  * Service Details: Enter a detailed description of the service needed, including any specific requirements or needs.
  * Type: text
  * Required: false

* **Payment Information (6)**: 
  * Payment Information: Provide any payment details such as insurance information or method of payment.
  * Type: text
  * Required: false

* **Contact Information (7)**: 
  * Contact Information: Enter contact information for the patient or representative, including name, email, and phone number.
  * Type: text
  * Required: false

* **Review (8)**: 
  * Review: This field is for reviewing and finalizing the quote before submission.
  * Type: text
  * Required: false

* **Submission (9)**: 
  * Submission: This field is for the final submission of the quote.
  * Type: text
  * Required: false

* **Service Type (10)**: 
  * Service Type: Select the type of service needed, such as hospice inpatient or outpatient.
  * Type: select_one
  * Options: Hospice Inpatient, Hospice Outpatient, Both inpatient and outpatient, Other, None
  * Required: false

* **Care Frequency (11)**: 
  * Care Frequency: Select the frequency of the service needed, such as daily, weekly, etc.
  * Type: select_multiple
  * Options: Daily, Weekly, Biweekly, Monthly, Other, None
  * Required: false

* **Care Duration (12)**: 
  * Care Duration: Enter the duration of the service needed.
  * Type: number
  * Required: false

* **Start Date (13)**: 
  * Start Date: Enter the start date of the service.
  * Type: date
  * Required: false

* **End Date (14)**: 
  * End Date: Enter the end date of the service.
  * Type: date
  * Required: false

* **Start Time (15)**: 
  * Start Time: Enter the start time of the service.
  * Type: time
  * Required: false

* **End Time (16)**: 
  * End Time: Enter the end time of the service.
  * Type: time
  * Required: false

* **First Name (17)**: 
  * First Name: Enter the first name of the contact person.
  * Type: text
  * Required: false

* **Last Name (18)**: 
  * Last Name: Enter the last name of the contact person.
  * Type: text
  * Required: false

* **Email (19)**: 
  * Email: Enter the email of the contact person.
  * Type: email
  * Required: false

* **Phone (20)**: 
  * Phone: Enter the phone number of the contact person.
  * Type: text
  * Required: false

* **Address 1 (21)**: 
  * Address 1: Enter the address of the contact person.
  * Type: text
  * Required: false

* **Address 2 (22)**: 
  * Address 2: Enter any additional address information.
  * Type: text
  * Required: false

* **City (23)**: 
  * City: Enter the city of the contact person's address.
  * Type: text
  * Required: false

* **ZIP (24)**: 
  * ZIP: Enter the zip code of the contact person's address.
  * Type: text
  * Required: false

* **Review (25)**: 
  * Review: Final review of the quote before submission.
  * Type: note
  * Required: false
