# location_history_form - Help Guide
## Purpose
The location history form is used to collect data on a location's history, including information about the infected person, suspected contacts, location status, start and end dates, and sync status with other locations and apps.

## How To Complete This Form
1. Fill out the form for the correct location history.
2. Ensure you have all the necessary information before submitting the form.

## Field-by-Field Explanation
- **Infected Person** (`infected_person`, text, required: false): Enter the name of the person who was infected with the disease or condition.
- **Suspected Contacts** (`suspected_contacts`, select_multiple, required: false): Indicate if there were any suspected contacts with the infected person. Select "Yes" if there were any suspected contacts, and "No" if there were no suspected contacts.
- **Location History Contacts** (`location_history_form_contacts`, text, required: false): Enter any additional information about the contacts related to the location history.
- **Location Status** (`location_history_form_location`, select_one, required: false): Indicate the status of the location, either "Yes" or "No".
- **Start Date** (`location_history_form_start_date`, date, required: false): Enter the start date of the location history.
- **End Date** (`location_history_form_end_date`, date, required: false): Enter the end date of the location history.
- **Sync with** (`location_history_form_sync_with`, select_multiple, required: false): Select if the location history is synced with other locations, choosing "Yes" or "No".
- **Apps Synced** (`location_history_form_apps_synced`, select_multiple, required: false): Select if the location history is synced with apps, choosing "Yes" or "No".
 
## Tips
- Make sure to fill out the form correctly to gather accurate information about the location history.
- If you are unsure about any of the fields, please refer to the relevant sections in the help guide for more information.
- If you need further assistance, please contact the relevant support team.
