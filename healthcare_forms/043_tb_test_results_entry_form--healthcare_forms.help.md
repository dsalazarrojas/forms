# TB Test Results Entry Form - Help Guide
## Purpose
The TB Test Results Entry Form is used to collect and document the results of tuberculosis (TB) testing for patients. This form helps ensure accurate and efficient record-keeping and reporting.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by entering the patient's test results in the `Test Results` section. This will be used to document the actual test results.
2. Enter the patient's name in the `Patient Name` field.
3. Enter the date of the test in the `Test Date` field.
4. Enter the location where the test was taken in the `Test Location` field.
5. Enter the patient's age in the `Patient Age` field.
6. Select the patient's gender in the `Patient Gender` field.
7. Select the type of test result in the `Test Result Type` field.
8. Indicate the status of the test result in the `Result Status` field.
9. Enter any additional test details in the `Test Type` field.
10. Enter any additional patient contact information in the `Patient Contact Info` field.
11. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **Test Results** (`test_results_1`, `text`, required): Enter the patient's test results.
* **Patient Name** (`patient_name`, `text`, required): Enter the patient's name.
* **Test Date** (`test_date`, `date`, required): Enter the date of the test.
* **Test Location** (`test_location`, `text`, optional): Enter the location where the test was taken.
* **Patient Age** (`patient_age`, `number`, optional): Enter the patient's age.
* **Patient Gender** (`patient_gender`, `select_one`, optional): Select the patient's gender.
* **Test Result Type** (`test_result_type`, `select_one`, optional): Select the type of test result.
* **Result Status** (`result_status`, `select_multiple`, optional): Indicate the status of the test result.
* **Test Type** (`test_type`, `text`, optional): Enter any additional test details.
* **Patient Contact Info** (`patient_contact_info`, `text`, optional): Enter any additional patient contact information.
* **Test Results 2-16** (`test_results_2-16`, `text`, optional): Enter any additional test results (2-16).

Note: The fields with IDs 2-16 are for optional additional test results. You can enter as many as you need.
