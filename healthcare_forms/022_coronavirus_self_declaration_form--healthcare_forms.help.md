# Coronavirus Self Declaration Form - Help Guide
## Purpose
This form is designed to collect information about your health status and any potential COVID-19 symptoms. It's intended for healthcare providers to gather data for their patients.

## How To Complete This Form

1. Select the category for the form (Healthcare Forms or Other Forms).
2. Briefly describe any COVID-19 symptoms you are experiencing (e.g., fever, cough, etc.).
3. Indicate if any coding is required or not.
4. Choose whether this form is for HIPAA compliance or not.
5. Optionally, indicate if coding is required or not.

## Field-by-Field Explanation
* **Category** (`category`, select_one, required: false): Select the category for this form. This could be Healthcare Forms or Other Forms.
* **Description** (`description`, text, required: false): Report any COVID-19 symptoms you are experiencing. This could include fever, cough, etc.
* **No Coding Required?** (`no_coding_required`, select_one, required: false): Indicate if no coding is required for this form.
* **HIPAA Compliance** (`hipaa_compliance_option`, select_one, required: false): Choose whether this form is for HIPAA compliance or not.
* **No Coding Required** (`no_coding_required`, select_one, required: false): Indicate if no coding is required for this form.

## Tips
* Please answer only the fields that are relevant to your specific use case.
* If you're unsure about any of the fields, please ask your healthcare provider for clarification.
* If the form is being used for HIPAA purposes, please select the correct option.
