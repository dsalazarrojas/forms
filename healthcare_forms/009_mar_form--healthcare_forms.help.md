# mar_form - Help Guide
## Purpose
The mar_form is used to document medication administration events for patients.

## How To Complete This Form
To complete the mar_form, please follow these steps:

1. Enter the patient's name in the `patient_name` field.
2. Indicate whether the medication was administered in the `medication_administered` field.
3. Select the dose of the medication that was administered in the `dose` field.
4. Enter the time the medication was administered in the `time_administered` field.
5. Select the frequency of the medication administration in the `frequency` field.
6. Select the route of the medication administration in the `route` field.
7. Enter any additional comments about the medication administration in the `comments` field.
8. Select the facility where the medication was administered in the `facility` field.
9. Enter the date the medication was administered in the `date` field.
10. Enter the start time of the medication administration, if applicable, in the `start_time` field.
11. Enter the end time of the medication administration, if applicable, in the `end_time` field.
12. Enter any notes about the medication administration in the `note` field.
13. Enter any additional details about medications administered in the `medication_administered_1`, `medication_administered_2`, `medication_administered_3`, `medication_administered_4`, and `medication_administered_5` fields.
14. Enter any additional patient names in the `patient_name_1`, `patient_name_2`, `patient_name_3`, `patient_name_4`, and `patient_name_5` fields.

## Field-by-Field Explanation

* **Medication Administered** (`medication_administered`): Check if the medication was administered.
* **Patient Name** (`patient_name`): Enter the patient's name.
* **Dose** (`dose`): Enter the dose of the medication that was administered.
* **Time Administered** (`time_administered`): Enter the time the medication was administered.
* **Frequency** (`frequency`): Select how often the medication is administered.
* **Route** (`route`): Select the route of the medication administration.
* **Comments** (`comments`): Enter any additional comments about the medication administration.
* **Facility** (`facility`): Select the facility where the medication was administered.
* **Date** (`date`): Enter the date the medication was administered.
* **Start Time** (`start_time`): Enter the start time of the medication administration, if applicable.
* **End Time** (`end_time`): Enter the end time of the medication administration, if applicable.
* **Note** (`note`): Enter any notes about the medication administration.
* **Medication Administered 1** (`medication_administered_1`): Enter any additional details about the medication administered.
* **Patient Name 1** (`patient_name_1`): Enter any additional patient names.
* **Medication Administered 2** (`medication_administered_2`): Enter any additional details about the medication administered.
* **Patient Name 2** (`patient_name_2`): Enter any additional patient names.
* **Medication Administered 3** (`medication_administered_3`): Enter any additional details about the medication administered.
* **Patient Name 3** (`patient_name_3`): Enter any additional patient names.
* **Medication Administered 4** (`medication_administered_4`): Enter any additional details about the medication administered.
* **Patient Name 4** (`patient_name_4`): Enter any additional patient names.
* **Medication Administered 5** (`medication_administered_5`): Enter any additional details about the medication administered.
* **Prophets** (`prophets`): Enter any additional patient names.
* **Medication Administered 5** (`medication_administered_5`): Enter any additional details about the medication administered.

Note: Some fields are optional. If you are unsure which fields are required, refer to the form header or your healthcare professional for guidance.
