# Nursing Practices Audit Form - Help Guide
## Purpose
The Nursing Practices Audit Form is designed to gather information on the nursing practices that have been evaluated in a healthcare setting. This information is crucial for identifying areas of improvement and ensuring that nursing practices are up-to-date and effective.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully and ensure that all fields are relevant to your patient's care.
2. For each field, select the appropriate option that best describes the nursing practice that has been evaluated.
3. If the option "Other" is selected, please provide a brief explanation in the text field (not shown in this example).

## Field-by-Field Explanation

* **Nursing Practices Audit Form** (`page_one`, text, optional): This field is the title of the form and is not a required field. Please enter the name of the form if you want to save it with a specific title.
* **Which of the following nursing practices have been evaluated?** (`page_two`, select_multiple, optional): Select all the nursing practices that have been evaluated for the patient. For example, "Yes" for each practice that was evaluated, or "No" if none were evaluated. You can select multiple options by holding down the Ctrl key (Windows) or Command key (Mac) while clicking on the options.
* **Has the patient's care plan been reviewed?** (`page_three`, select_one, optional): Select "Yes" if the patient's care plan has been reviewed, or "No" if it has not.
* **Page Four** (`page_four`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 4.
* **Has the patient's care plan been completed?** (`page_five`, select_one, optional): Select "Yes" if the patient's care plan has been completed, or "No" if it has not.
* **Page Six** (`page_six`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 6.
* **Page Seven** (`page_seven`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 7.
* **Page Eight** (`page_eight`, select_one, optional): Select "Yes" if the patient's care plan has been reviewed on page 8, or "No" if it has not.
* **Page Nine** (`page_nine`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 9.
* **Page Ten** (`page_ten`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 10.
* **Page Eleven** (`page_eleven`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 11.
* **Page Twelve** (`page_twelve`, select_multiple, optional): Select all the nursing practices that have been evaluated on page 12.
