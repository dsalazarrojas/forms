# Session Assignment And Feedback Form (SAFF) - Help Guide
## Purpose
The Session Assignment And Feedback Form (SAFF) is used for users to provide feedback and assign sessions to others. This form helps collect information about assigned sessions and any feedback or comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and its sections.
2. Select "Yes" or "No" for the Session Assignment section to indicate if the session has been assigned.
3. Provide any feedback or comments in the Feedback section.

## Field-by-Field Explanation
### Session Assignment
* **Session Assignment** (`session_assignment`, select_multiple, required: false): Select "Yes" if you have assigned the session, or "No" if you haven't.
### Feedback
* **Feedback** (`feedback`, note, required: false): Provide any comments or feedback about the session here.

## Tips
* Please be concise and clear in your feedback.
* If you've assigned the session, provide the reason for assignment.
* You can assign multiple sessions by selecting "Yes" for each one.
