# pharmaceutical_stock_validation_form - Help Guide
## Purpose
This form is used to validate pharmaceutical stock information. It ensures that the stock is properly managed and tracked, and any discrepancies or issues are identified and addressed.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the pharmacy details section with accurate and up-to-date information about the pharmacy where the stock is currently located.
* Fill out the stock date section with the date when the stock was last checked.
* Fill out the stock quantity section with the current quantity of stock available.
* Fill out the expiration date section with the date when the stock is set to expire.
* Fill out the stock status section with the current status of the stock (Active or Inactive).
* Fill out the stock type section with the type of stock (Prescription or Over-the-counter).
* Fill out the location section with the current location of the stock.
* Fill out the storage condition section with the condition of the stock (Good or Used).
* Fill out the stock date/time section with the date and time when the stock was last checked.
* Fill out the batch number section with the batch number of the stock.
* Fill out the batch date section with the date when the batch was created.
* Fill out the stock number section with the stock number of the stock.
* Fill out the expiration date/time section with the date and time when the stock is set to expire.
* Fill out the expiration date/time format section with the format of the expiration date/time (YYYY-MM-DD or DD/MM/YY).
* Fill out the storage condition note section with any additional information about the storage condition.
* Fill out the stock status note section with any additional information about the stock status.
* Fill out the location note section with any additional information about the location.
* Fill out the stock type note section with any additional information about the stock type.
* Fill out the batch number note section with any additional information about the batch number.
* Fill out the batch date note section with any additional information about the batch date.
* Fill out the stock number note section with any additional information about the stock number.
* Fill out the expiration date note section with any additional information about the expiration date.
* Fill out the expiration date/time note section with any additional information about the expiration date/time.
* Fill out the stock date note section with any additional information about the stock date.
* Fill out the stock quantity note section with any additional information about the stock quantity.

## Field-by-Field Explanation
* **Pharmacy**: (`pharmacy_details`, `text`, required) Enter the name and address of the pharmacy where the stock is currently located.
* **Stock Date**: (`stock_date`, `date`, required) Enter the date when the stock was last checked.
* **Stock Quantity**: (`stock_quantity`, `number`, required) Enter the current quantity of stock available.
* **Expiration Date**: (`expiration_date`, `date`, required) Enter the date when the stock is set to expire.
* **Stock Status**: (`stock_status`, `select_multiple`, required) Select the current status of the stock (Active or Inactive).
* **Stock Type**: (`stock_type`, `select_one`, required) Select the type of stock (Prescription or Over-the-counter).
* **Location**: (`stock_location`, `text`, required) Enter the current location of the stock.
* **Storage Condition**: (`storage_condition`, `select_multiple`, required) Select the condition of the stock (Good or Used).
* **Stock Date/Time**: (`stock_date_time`, `date`, required) Enter the date and time when the stock was last checked.
* **Batch Number**: (`batch_number`, `number`, required) Enter the batch number of the stock.
* **Batch Date**: (`batch_date`, `date`, required) Enter the date when the batch was created.
* **Stock Number**: (`stock_number`, `number`, required) Enter the stock number of the stock.
* **Expiration Date/Time**: (`expiration_date_time`, `date`, required) Enter the date and time when the stock is set to expire.
* **Expiration Date/Time Format**: (`expiration_date_time_format`, `select_one`, required) Select the format of the expiration date/time (YYYY-MM-DD or DD/MM/YY).
* **Storage Condition Note**: (`storage_condition_note`, `text`, required) Enter any additional information about the storage condition.
* **Stock Status Note**: (`stock_status_note`, `text`, required) Enter any additional information about the stock status.
* **Location Note**: (`stock_location_note`, `text`, required) Enter any additional information about the location.
* **Stock Type Note**: (`stock_type_note`, `text`, required) Enter any additional information about the stock type.
* **Batch Number Note**: (`batch_number_note`, `text`, required) Enter any additional information about the batch number.
* **Batch Date Note**: (`batch_date_note`, `text`, required) Enter any additional information about the batch date.
* **Stock Number Note**: (`stock_number_note`, `text`, required) Enter any additional information about the stock number.
* **Expiration Date Note**: (`expiration_date_note`, `text`, required) Enter any additional information about the expiration date.
* **Expiration Date/Time Note**: (`expiration_date_time_note`, `text`, required) Enter any additional information about the expiration date/time.
* **Stock Date Note**: (`stock_date_note`, `text`, required) Enter any additional information about the stock date.
* **Stock Quantity Note**: (`stock_quantity_note`, `text`, required) Enter any additional information about the stock quantity.
