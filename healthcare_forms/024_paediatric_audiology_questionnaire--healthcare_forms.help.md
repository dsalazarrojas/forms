# Paediatric Audiology Questionnaire - Help Guide
## Purpose
The Paediatric Audiology Questionnaire is a form used to collect information from patients, specifically children, for audiology assessments. This form is designed to aid healthcare professionals in diagnosing and treating audiological disorders.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Enter the patient's first name in the first name field.
2.  Enter the patient's last name in the last name field.
3.  Enter the patient's age.
4.  Select the patient's gender.
5.  Select any relevant medical conditions that apply to the patient.
6.  Select the date of the patient's last hearing test, if applicable.
7.  Enter any results from the patient's last hearing test, if applicable.
8.  Enter the patient's medical history, if applicable.
9.  Enter any symptoms the patient is experiencing, if applicable.
10.  Enter any treatment plans or notes, if applicable.
11.  Select the follow-up method and contact information, if applicable.
12.  Enter the patient's contact information, including email and phone number.
13.  Enter any additional notes or comments.

## Field-by-Field Explanation

* **First Name (first_name)**: Enter the patient's first name.
* **Last Name (last_name)**: Enter the patient's last name.
* **Age (age)**: Enter the patient's age.
* **Gender (gender)**: Select the patient's gender.
* **Medical Condition (medical_condition)**: Select any relevant medical conditions that apply to the patient.
* **Hearing Loss (hearing_loss)**: If applicable, enter the date of the patient's last hearing test.
* **Hearing Test (hearing_test)**: Select the result of the patient's last hearing test.
* **Medical History (medical_history)**: Enter the patient's medical history.
* **Symptoms (symptoms)**: Enter any symptoms the patient is experiencing.
* **Treatment Plan (treatment_plan)**: Enter any treatment plans or notes.
* **Follow-Up (follow_up)**: Select the follow-up method and contact information.
* **Contact Info (contact_info)**: Enter the patient's contact information, including email and phone number.
* **Phone (phone)**: Enter the patient's phone number.
* **Note (note)**: Enter any additional notes or comments.
* **Follow-Up Appointment (follow_up_appointment)**: If applicable, enter the date of the next follow-up appointment.
* **Follow-Up Contact (follow_up_contact)**: If applicable, enter the contact information for the next follow-up.
* **Follow-Up Location (follow_up_location)**: If applicable, enter the location of the next follow-up appointment.
* **Medical History 2 (medical_history_2)**: Enter any additional medical history, if applicable.
* **Allergies (allergies)**: Enter any allergies the patient has, if applicable.
* **Medications (medications)**: Enter any medications the patient is taking, if applicable.
* **Medical History 3 (medical_history_3)**: Enter any additional medical history, if applicable.
* **Medical History 4 (medical_history_4)**: Enter any additional medical history, if applicable.
* **Medical History 5 (medical_history_5)**: Enter any additional medical history, if applicable.

## Tips

*   Please ensure that all required fields are completed before submitting the form.
*   If a field is not applicable to the patient, please select "N/A" or enter "None" in the field.
*   If you are unsure about any of the fields, please consult with the healthcare professional completing the form.
