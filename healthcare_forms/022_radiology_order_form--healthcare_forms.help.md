# Radiology Order Form - Help Guide

## Purpose

The Radiology Order Form is a tool used to collect patient information and radiology order details for healthcare professionals to schedule and manage radiology exams.

## How To Complete This Form

1. Ensure all required fields are filled in accurately and thoroughly.
2. Provide as much detail as possible for optional fields to help with communication and scheduling.
3. Pay attention to specific input types (e.g., dates, times, or email addresses).
