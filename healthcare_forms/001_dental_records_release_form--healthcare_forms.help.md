# Dental Records Release Form - Help Guide
## Purpose
This form is used to release medical records of a patient to a medical provider. It collects essential patient information and the details of the record release, ensuring that both the patient and the provider have the necessary documentation.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the patient's first name in the "First Name" field.
2. Enter the patient's last name in the "Last Name" field.
3. Enter the patient's date of birth in the "Date of Birth" field using the correct date format (MM/DD/YYYY).
4. Enter the patient's address in the "Address" field.
5. Enter the patient's phone number in the "Phone Number" field.
6. Select whether the medical record should be released (Yes/No) in the "Medical Record Release Type" field.
7. Select the date of release in the "Release Date" field using the correct date format (MM/DD/YYYY).
8. Enter the name of the medical provider in the "Medical Provider Name" field.
9. Enter the phone number of the medical provider in the "Medical Provider Phone" field.
10. Enter the address of the medical provider in the "Medical Provider Address" field.
11. Provide any additional comments or notes in the "Medical Record Release Note" field (optional).

## Field-by-Field Explanation
* **First Name**: Enter the patient's first name.
	+ Type: text
	+ Required: true
* **Last Name**: Enter the patient's last name.
	+ Type: text
	+ Required: true
* **Date of Birth**: Enter the patient's date of birth using the format MM/DD/YYYY.
	+ Type: date
	+ Required: true
* **Address**: Enter the patient's address.
	+ Type: text
	+ Required: true
* **Phone Number**: Enter the patient's phone number.
	+ Type: text

	+ Required: true
* **Release Date**: Select the date the medical record should be released using the format MM/DD/YYYY.
	+ Type: date
	+ Required: true
* **Medical Provider Name**: Enter the name of the medical provider.
	+ Type: text
	+ Required: true
* **Medical Provider Phone**: Enter the phone number of the medical provider.
	+ Type: text
	+ Required: true
* **Medical Provider Address**: Enter the address of the medical provider.
	+ Type: text

* **Medical Record Release Note**: Enter any additional comments or notes regarding the medical record release.
	+ Type: text
	+ Required: false

## Tips
* Double-check the accuracy of the patient's information before completing the form.
* Ensure the medical provider's contact information is up-to-date and accurate.
* Review the form thoroughly to avoid errors and ensure all necessary fields are filled in.
* Consult with the patient or medical provider if unsure about any field or requirement.
