# Self Harm Survey - Help Guide
## Purpose
This form is designed to collect information about an individual's self-harming experiences, including their frequency, methods, and prevention strategies. It helps healthcare professionals to assess the individual's mental health and provide guidance on prevention methods.

## How To Complete This Form
To complete this form, please select the options that apply to you from the provided options for each field. If you have any difficulty understanding a question or option, please let the healthcare professional know and they will assist you.

## Field-by-Field Explanation

* **Survey Background** (`survey_background`, text, optional): A brief background about yourself, which will help us understand your context.
* **Self-harming experiences** (`self_harming_experiences`, select_one, required): Select one of the options that best describe your self-harming experiences.
	+ Option 1: I have had self-harming experiences (e.g., cutting, burning, scratching, etc.)
	+ Option 2: I have not had self-harming experiences
* **Self-cutting experiences** (`self_cutting_experiences`, select_multiple, required): Select all the options that apply to you.
	+ Option 1: I have cut myself (e.g., with a knife, razor, etc.)
	+ Option 2: I have not cut myself
* **Self-cutting frequency** (`self_cutting_frequency`, select_one, required): Select one of the options that best describe how often you have cut yourself.
	+ 1 week or less
	+ 2-4 weeks
	+ 1-2 months
	+ more than 2 months
* **Self-harming frequency** (`self_harming_frequency`, select_one, required): Select one of the options that best describe how often you have harmed yourself.
	+ 1 week or less
	+ 2-4 weeks
	+ 1-2 months
	+ more than 2 months
* **Methods used** (`methods_used`, select_multiple, required): Select all the options that apply to you.
	+ Cutting
	+ Burning
	+ Scratching
	+ Hitting or beating self
	+ Other
	+ Other (please specify)
* **Reasons** (`reasons`, select_multiple, required): Select all the options that apply to you.
	+ Emotional difficulties
	+ Physical difficulties

	+ Other
* **Help Searched** (`help_searched`, select_multiple, required): Select all the options that apply to you.

	+ Art or music

	+ Other
* **Self-harming causes** (`self_harming_causes`, select_multiple, required): Select all the options that apply to you.
	+ Emotional difficulties
	+ Physical difficulties
	+ Social difficulties
	+ Other
* **Self-mutilation History** (`self_mutilation_history`, select_one, required): Select one of the options that apply to you.
	+ False
	+ True
* **Self-harm prevented** (`self_harm_prevented`, select_one, required): Select one of the options that apply to you.
	+ True
	+ False
* **Self-harm prevented reasons** (`self_harm_prevented_reasons`, select_multiple, required): Select all the options that apply to you.
	+ Physical health
	+ Social health
	+ Emotional health
	+ Mental health

	+ False

	+ Emotional difficulties

## Tips
* Please answer the questions truthfully and honestly.
* If you need help or have any difficulty understanding a question, please let the healthcare professional know.
* You can select all the options that apply to you for each field.
