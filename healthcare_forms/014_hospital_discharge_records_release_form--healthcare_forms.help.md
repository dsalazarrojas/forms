# hospital_discharge_records_release_form - Help Guide
## Purpose
The hospital discharge records release form is used to authorize the release of patient records. This form collects information to verify the authenticity of the request and ensure that the patient's records are released to the correct person.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of authorization:
	* Choose "Patient" if you are the patient.
	* Choose "Authorized Representative" if you are a person authorized by the patient to receive their records.
	* Choose "Healthcare Agent" if you are a healthcare professional authorized to receive the patient's records.
2. Select the types of records you want to release:
	* Medical Record
	* Surgical Record
	* Radiology Report
	* Laboratory Report
	* Pathology Report
3. Select the location of the records:
	* Hospital
	* Clinic
	* Lab
	* Office
4. Choose who you want to release the records to:
	* Self
	* Family Member
	* Authorized Representative
	* Healthcare Agent
5. Enter the contact person's information:
	* First Name
	* Last Name
	* Phone Number
	* Email
	* Address
	* City
	* State
	* Zip
	* Country
