# Home Medical Device Order Form - Help Guide
## Purpose
This form is used to order home medical devices for patients.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Ensure that you have the necessary information to complete each field.

## Field-by-Field Explanation

* **User Info**: 
  * This field is used to collect the patient's name and contact information.
  * Please enter the patient's name, email address, and phone number in this field.
* **Medical Device**: 
  * This field allows you to select the type of medical device being ordered.
  * Please select the device from the list provided, as this will help us process the order correctly.
* **Order Date**: 
  * This field is used to select the date on which the order should be processed.
  * Please enter the date in the format MM/DD/YYYY.
* **Order Time**: 
  * This field is used to select the time on which the order should be processed.
  * Please enter the time in the format HH:MM AM/PM.
* **Order Note**: 
  * This field is used to provide any additional information about the order.
  * Please enter any relevant details or comments about the order.
* **User Email**: 
  * This field is used to collect the patient's email address.
  * Please enter the patient's email address.
* **User Phone**: 
  * This field is used to collect the patient's phone number.
  * Please enter the patient's phone number.
* **Healthcare Provider**: 
  * This field is used to collect the name and contact information of the healthcare provider.
  * Please enter the name and contact information of the healthcare provider.
* **Order Instructions**: 
  * This field is used to provide any additional instructions or information about the order.
  * Please enter any relevant details or comments about the order.

## Tips

* Please ensure that all fields are filled out accurately and completely.
* If you are unsure about any field, please contact us for assistance.
* This form is only for ordering home medical devices, so please do not use it for any other purpose.
