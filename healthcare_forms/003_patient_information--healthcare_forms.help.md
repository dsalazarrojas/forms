# Patient Information - Help Guide
## Purpose
This form is used to collect patient information for healthcare purposes. It is used to gather demographic and medical history data from patients.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's first name in the "First Name" field.
2. Enter the patient's last name in the "Last Name" field.
3. Enter the patient's date of birth in the "Date of Birth" field in the format MM/DD/YYYY.
4. Enter the patient's email address in the "Email" field.
5. Enter the patient's phone number in the "Phone Number" field.
6. Enter the patient's address in the "Address" field.
7. If applicable, enter any medical history in the "Medical History" field.
8. If applicable, enter the patient's medical insurance information in the "Medical Insurance" field.
9. If applicable, enter the emergency contact name in the "Emergency Contact Name" field.
10. If applicable, select the emergency contact relationship from the "Emergency Contact Relationship" field.
11. If applicable, enter the emergency contact phone number in the "Emergency Contact Phone" field.
12. If applicable, enter the emergency contact email address in the "Emergency Contact Email" field.
13. If applicable, enter the emergency contact address in the "Emergency Contact Address" field.
14. If applicable, enter any medical conditions in the "Medical Conditions" field.
15. If applicable, list any allergies in the "Allergies" field.
16. If applicable, list any medications in the "Medications" field.
17. If applicable, list any medical tests performed in the "Medical Tests" field.
18. If applicable, enter any surgical history in the "Surgical History" field.
19. If applicable, list any medical procedures performed in the "Medical Procedures" field.
20. If applicable, enter any other medical history in the "Other Medical History" field.
21. If applicable, select the patient's emergency services from the "Emergency Services" field.
22. If applicable, select the patient's medical specialties from the "Medical Specialties" field.
23. If applicable, select the patient's medical providers from the "Medical Providers" field.
24. If applicable, select the patient's patient caregivers from the "Patient Caregivers" field.
25. If applicable, select the patient's caregiver relationship from the "Patient Caregiver Relationship" field.

## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, required): Enter the patient's first name.
* **Last Name** (`last_name`, `text`, required): Enter the patient's last name.
* **Date of Birth** (`date_of_birth`, `date`, required): Enter the patient's date of birth in the format MM/DD/YYYY.
* **Email** (`email`, `email`, required): Enter the patient's email address.
* **Phone Number** (`phone_number`, `text`, required): Enter the patient's phone number.
* **Address** (`address`, `text`, optional): Enter the patient's address.
* **Medical History** (`medical_history`, `text`, optional): If applicable, enter any medical history.
* **Medical Insurance** (`medical_insurance`, `text`, optional): If applicable, enter the patient's medical insurance information.
* **Emergency Contact Name** (`emergency_contact_name`, `text`, optional): If applicable, enter the emergency contact name.
* **Emergency Contact Relationship** (`emergency_contact_relationship`, `text`, optional): If applicable, select the emergency contact relationship.
* **Emergency Contact Phone** (`emergency_contact_phone`, `text`, optional): If applicable, enter the emergency contact phone number.
* **Emergency Contact Email** (`emergency_contact_email`, `text`, optional): If applicable, enter the emergency contact email address.
* **Emergency Contact Address** (`emergency_contact_address`, `text`, optional): If applicable, enter the emergency contact address.
* **Medical Conditions** (`medical_conditions`, `text`, optional): If applicable, enter any medical conditions.
* **Allergies** (`allergies`, `text`, optional): If applicable, list any allergies.
* **Medications** (`medications`, `text`, optional): If applicable, list any medications.
* **Medical Tests** (`medical_tests`, `text`, optional): If applicable, list any medical tests performed.
* **Surgical History** (`surgical_history`, `text`, optional): If applicable, enter any surgical history.
* **Medical Procedures** (`medical_procedures`, `text`, optional): If applicable, list any medical procedures performed.
* **Other Medical History** (`medical_history_other`, `text`, optional): If applicable, enter any other medical history.
* **Emergency Services** (`emergency_services`, `select_multiple`, optional): If applicable, select the patient's emergency services.
* **Medical Specialties** (`medical_specialties`, `select_multiple`, optional): If applicable, select the patient's medical specialties.
* **Medical Providers** (`medical_providers`, `select_multiple`, optional): If applicable, select the patient's medical providers.
* **Patient Caregivers** (`patient_caregivers`, `select_multiple`, optional): If applicable, select the patient's caregivers.
* **Patient Caregiver Relationship** (`patient_caregiver_relationship`, `select_multiple`, optional): If applicable, select the patient's caregiver relationship.

## Tips
* Please ensure the patient's information is accurate and up-to-date.
* If you are unsure about any field, please contact the healthcare provider for guidance.
* If you have any questions or concerns, please contact the healthcare provider or our support team.
