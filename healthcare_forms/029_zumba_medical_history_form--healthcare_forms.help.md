# zumba_medical_history_form - Help Guide
## Purpose
The zumba_medical_history_form is designed to collect information about a patient's history related to Zumba dancing activities.

## How To Complete This Form

### Complete the form in the following steps:

* Answer each question to the best of your ability.
* For each question, select the option that most accurately reflects your situation.
* If you are not sure about an answer or have additional information to share, use the text fields to provide more details.
* Make sure to submit the form once you have answered all the questions.

## Field-by-Field Explanation

* **has_zumba_dancing_experience** (`patient_zumba_activities`, `select_multiple`, required: false):
	+ This question asks about your experience with Zumba dancing activities.
	+ Select all the options that apply to you.
* **how_often_do_you_zumba** (`frequency_zumba_dancing`, `select_one`, required: false):
	+ This question asks about how often you engage in Zumba dancing activities.
	+ Select the option that best describes your frequency of practice.
* **zumba_dancing_duration** (`zumba_dancing_duration`, `number`, required: false):
	+ This question asks about how long you have been doing Zumba dancing activities.
	+ Enter the number of years you have been practicing Zumba.
* **any_zumba_injuries** (`zumba_injuries`, `select_multiple`, required: false):
	+ This question asks about any injuries you have experienced while doing Zumba dancing activities.
	+ Select all the options that apply to you.
* **details_about_zumba_injuries** (`zumba_injury_details`, `text`, required: false):
	+ This question is for you to provide more details about any injuries you have experienced while doing Zumba dancing activities.
	+ Use the text field to share more information if needed.
* **any_medical_conditions** (`medical_conditions`, `select_multiple`, required: false):
	+ This question asks about any medical conditions you have that might be related to Zumba dancing activities.
	+ Select all the options that apply to you.
* **any_medication_use** (`medication_use`, `select_multiple`, required: false):
	+ This question asks about any medications you are currently taking or have taken for your medical conditions.
	+ Select all the options that apply to you.
* **other_medical_history** (`other_medical_history`, `text`, required: false):
	+ This question is for you to provide any other medical history that is not listed in the previous questions.
	+ Use the text field to share more information if needed.
* **doctor** (`zumba_doctor`, `select_one`, required: false):
	+ This question asks about your doctor.
	+ Select the name of your doctor.
* **zumba_clinic** (`zumba_clinic`, `select_one`, required: false):
	+ This question asks about your Zumba clinic.
	+ Select the name of your Zumba clinic.
 
## Tips

* Answer all questions to the best of your ability.
* If you are unsure about any question or have additional information to share, use the text fields to provide more details.
* Make sure to submit the form once you have answered all the questions.
