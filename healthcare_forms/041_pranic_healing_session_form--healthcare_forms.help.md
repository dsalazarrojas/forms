# Pranic Healin Session Form - Help Guide
## Purpose

This form is used to record and manage Pranic Healin sessions.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the session details, including the client's name, phone number, and email.
2. Select the session status (Booked, Cancel, or Done).
3. Enter the session dates and times.
4. Select the assigned therapist (Jimmy, Sarah, or Jane).
5. Add any additional notes or comments about the session.
