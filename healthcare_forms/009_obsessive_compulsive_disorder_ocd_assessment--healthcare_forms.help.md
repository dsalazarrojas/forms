# Obsessive Compulsive Disorder (OCD) Assessment - Help Guide
## Purpose

The Obsessive Compulsive Disorder (OCD) Assessment form is a questionnaire designed to help healthcare professionals understand the symptoms, severity, and impact of OCD on an individual's daily life.

## How To Complete This Form

1. Review the questions carefully and answer them accurately and honestly.
2. Complete each section based on your current situation and experience.
3. If you are unsure about any question, please consult with a healthcare professional.

## Field-by-Field Explanation

* **Introduction (1)**: This section is an introduction to the form. Please read it carefully and ask questions if you need clarification.
* **Symptoms Frequency (2)**: Please indicate how often you experience OCD symptoms, using the frequency scale below:
	+ daily: Almost every day
	+ occasionally: Several times a week
	+ rarely: Only now and then
	+ never: Never
* **Time In Suffering From Symptoms (3)**: Please describe how long you have been experiencing OCD symptoms.
* **Severity Of Symptoms (4)**: Please rate the severity of your OCD symptoms on a scale of 1-10, where 1 is mild and 10 is severe.
* **Frequency Of Symptoms (5)**: Please indicate how often you experience OCD symptoms, using the same frequency scale as above.
* **Time In Suffering From Symptoms 2 (6)**: Please describe how long you have been experiencing OCD symptoms in more detail.
* **Impact On Lifestyle (7)**: Please select all that apply to describe how OCD impacts your daily life:
	+ daily: Almost every day

	+ never: Never
* **Impact On Relationships (8)**: Please select all that apply to describe how OCD impacts your relationships:
	+ daily: Almost every day

	+ rarely: Only now and then
	+ never: Never
* **Impact On Work Or School (9)**: Please select all that apply to describe how OCD impacts your work or school life:
	+ daily: Almost every day

	+ rarely: Only now and then
	+ never: Never
* **Treatment Status (10)**: Please select one of the following:
	+ Currently seeking treatment
