# COVID 19 AttendanceChecklist - Help Guide
## Purpose
The COVID-19 Attendance Checklist is a form designed to help track the attendance of students in a class, while ensuring their health and safety during the pandemic. This form will guide you through collecting information about your class, the participants, their health status, and clearance to attend.

## How To Complete This Form
1. Select the correct class date and time from the dropdown menu.
2. Enter the instructor's name and select the class type (Beginner, Intermediate, Advanced, Children, Youth, or Adult).
3. Enter the class location.
4. Move on to the participant's information section.
5. Enter the participant's name and ID number.
6. If applicable, enter the participant's date of birth.
7. Select the participant's phone number and email address (if available).
8. Complete the health screening section:
	* Select 'Yes' or 'No' if the participant has had a health screening.
	* If yes, select 'Yes - Normal' or 'Yes - Elevated' if the screening was normal or elevated, respectively.
	* Select 'Yes' or 'No' if the participant has COVID-19 symptoms.
	* If yes, describe the symptoms in the provided text field.
	* Select 'Yes', 'No', or 'Unsure' if the participant has had recent COVID-19 exposure.
9. Move on to the attendance and clearance section:
	* Select 'Yes' or 'No' if the participant is cleared to participate.
	* If not cleared, provide a reason in the text field.
	* Select the participant's prior participation status (Regular, Occasional, or First time).
10. Finally, acknowledge and sign off:
	* Select 'Yes' or 'No' if you acknowledge and understand the health and safety protocols.
11. Review your answers for accuracy before submitting the form.

## Field-by-Field Explanation
* **Class Date** (ID: 2, Date, Required): Enter the date of the class you are attending.
* **Class Time** (ID: 3, Time, Required): Enter the time of the class you are attending.
* **Instructor Name** (ID: 4, Text, Required): Enter your name as the instructor.
* **Class Type** (ID: 5, Select One, Required): Select the type of class you are teaching (Beginner, Intermediate, Advanced, Children, Youth, or Adult).
* **Class Location** (ID: 6, Text, Required): Enter the location of the class.
* **Participant Name** (ID: 8, Text, Required): Enter the participant's name.
* **Participant ID** (ID: 9, Text, Required): Enter the participant's ID number.
* **Date of Birth** (ID: 10, Date, Optional): Enter the participant's date of birth (if applicable).
* **Phone Number** (ID: 11, Text, Optional): Enter the participant's phone number (if applicable).
* **Email Address** (ID: 12, Email, Optional): Enter the participant's email address (if applicable).
* **Health Screening Completed** (ID: 14, Select One, Required): Select 'Yes' or 'No' if the participant has had a health screening.
* **Temperature Taken** (ID: 15, Select One, Required): Select 'Yes - Normal' or 'Yes - Elevated' or 'No' if the participant's temperature was taken during the screening.
* **COVID-19 Symptoms Present** (ID: 17, Select One, Required): Select 'Yes' or 'No' if the participant has COVID-19 symptoms.
* **If Yes, Describe Symptoms** (ID: 18, Text, Optional): Provide a description of the participant's symptoms if they have them.
* **Recent COVID-19 Exposure** (ID: 19, Select One, Required): Select 'Yes', 'No', or 'Unsure' if the participant has had recent COVID-19 exposure.
* **Cleared to Participate** (ID: 21, Select One, Required): Select 'Yes' or 'No' if the participant is cleared to participate.
* **Reason if Not Cleared** (ID: 22, Text, Optional): Provide a reason if the participant is not cleared to participate.
* **Prior Participation** (ID: 23, Select One, Optional): Select the participant's prior participation status (Regular, Occasional, or First time).
* **I acknowledge and understand...** (ID: 25, Select One, Required): Select 'Yes' or 'No' to acknowledge and understand the health and safety protocols.
*   **Temperature Reading** (ID: 16, Number, Optional): Enter the participant's temperature reading if taken during the screening.
*   **Unsure** (ID: 19, Optional) is a valid answer if you are unsure about the participant's recent COVID-19 exposure.
*   **Yes - Normal** (ID: 15, Optional) and **Yes - Elevated** (ID: 15, Optional) are options for temperature taken during screening.
*   **Previous Class Attendance** (ID: 23, Optional) options include Regular, Occasional, and First time. 

## Tips
* Please ensure accuracy when filling in each field, as this form is used for tracking participant's health and safety status.
* If you are unsure about any field, select the 'Unsure' option. 
* This form is only accessible to authorized personnel.
