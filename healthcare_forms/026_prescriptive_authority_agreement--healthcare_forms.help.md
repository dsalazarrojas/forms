# Prescriptive Authority Agreement - Help Guide
## Purpose
The Prescriptive Authority Agreement form is used to document and verify the prescriptive authority of healthcare providers.

## How To Complete This Form
1. Start by reviewing the form carefully to ensure you understand its purpose and the required fields.
2. Select the appropriate options for each field:
	* "Healthcare Providers": Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
	* "Authority 1" to "Authority 3", "Provider 2" to "Provider 4": Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
3. Enter the "Agreement Date" and "End Date" if applicable.
4. If necessary, add additional providers under "More Providers".

## Field-by-Field Explanation
* **Proscribe Authority Agreement** (`prophets_authority`, text, required/optional): Enter a brief statement describing the prescriptive authority agreement.
* **Healthcare Providers** (`providers`, select_one, required/optional): Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
* **Additional Providers** (`providers_2`, select_one, required/optional): Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
* **Authority 1** (`authority_1`, date, required/optional): Enter the start date of the prescriptive authority.
* **Authority 2** (`authority_2`, date, required/optional): Enter the end date of the prescriptive authority.
* **Agreement Date** (`agreement_date`, date, required/optional): Enter the date of the agreement.
* **Authority 3** (`authority_3`, select_multiple, required/optional): Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
* **More Providers** (`providers_3`, select_multiple, required/optional): If additional providers need to be included, select their name from the options.
* **End Date** (`end_date`, date, required/optional): Enter the end date of the prescriptive authority.
* **Reason** (`reason`, text, required/optional): Enter a brief description of the prescriptive authority.
* **Provider 2** (`provider_2`, select_one, required/optional): Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
* **Provider 3** (`provider_3`, select_one, required/optional): Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.
* **Provider 4** (`provider_4`, select_one, required/optional): Select 'Yes' if the provider has prescriptive authority, 'No' otherwise.

## Tips
* Make sure to fill out all the required fields carefully and accurately.
* Double-check the form for any errors or duplicates.
* If you are unsure about any field or section, consult with a relevant authority or expert.
* Save the form after completion to avoid losing your work.
