# Restricted Antibiotic Request Form - Help Guide
## Purpose
The "Restricted Antibiotic Request Form" is designed to help healthcare providers assess and manage requests for antibiotics in a responsible and safe manner. This form is used to gather information about the patient, the request, and the healthcare provider's approval, promoting antimicrobial stewardship and patient safety.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the patient information (page 1)
2. Select the appropriate reason for the request (page 2)
3. Choose the desired antibiotic (page 2)
4. Select the treatment route (page 3)
5. Enter the quantity and dosage (page 4)
6. Select the approval authority (page 5)
7. Add any additional comments (page 6)
8. Sign and submit the form (page 7)

## Field-by-Field Explanation

* **Patient Info** (page 1, text field): Enter the patient's information, including name, date of birth, and ID number.
* **Request Info** (page 1, text field): Briefly describe the reason for the request.
* **Prescriber Info** (page 1, text field): Enter your healthcare provider's information, including name, title, and contact number.
* **Medical Info** (page 2, select multiple):
	+ **Antimicrobial Stewardship Request**: Select this option for requests related to antimicrobial stewardship.
	+ **Non-antibiotic related reason**: Select this option for non-antibiotic related requests.
* **Antibiotic Info** (page 2, select one): Choose the specific antibiotic required (e.g., Amikacin, Aztreonam, Cefepime, etc.).
* **Route Info** (page 3, select multiple):
	+ **Inpatient**: Select this option for hospital or inpatient treatment.
	+ **Outpatient**: Select this option for outpatient treatment.
	+ **Emergency**: Select this option for emergency situations.
	+ **Urgent Care**: Select this option for urgent care situations.
* **Quantity Info** (page 4, number field): Enter the required quantity of the antibiotic.
* **Dosage Info** (page 4, text field): Describe the required dosage.
* **Approval Info** (page 5, select multiple):
	+ **Antimicrobial Stewardship Team**: Select this option for approval from the antimicrobial stewardship team.
	+ **Pharmacy**: Select this option for approval from the pharmacy department.
	+ **Clinical**: Select this option for approval from the clinical team.
* **Comments** (page 6, note field): Add any additional comments or explanations.
* **Signature** (page 7, text field): Sign and date your name and title.
* **Submit** (page 7, text field): Click to submit the form.
