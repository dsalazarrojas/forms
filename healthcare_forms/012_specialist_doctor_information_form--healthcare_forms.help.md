The Specialist Doctor Information Form is a tool used to collect information from specialists who will be performing medical procedures. The form helps in gathering essential data about the provider's availability, medical specialties, licenses, and other crucial details.

### How To Complete This Form
To complete this form, follow the steps below:
1. Fill out the form by providing the required information in each field.
2. Ensure that all required fields are filled out before submitting the form.
3. If a field is marked as optional, you can choose to fill it out or leave it blank.

### Field-by-Field Explanation

* **1. form_provider_info**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter your name as a provider.
* **2. patient_medical_history**: 
	+ Type: text
	+ Required: No
	+ Purpose: Describe the patient's medical history.
* **3. contact_details**: 
	+ Type: number
	+ Required: No
	+ Purpose: Provide your contact details in the format of "phone number: XXX-XXX-XXXX, email: [email address]".
* **4. doctor_info**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter a brief description of your specialty and qualifications.
* **5. medical_specialties**: 
	+ Type: select_multiple
	+ Required: No
	+ Purpose: Select the medical specialties you provide.
* **6. medical_licenses**: 
	+ Type: select_one
	+ Required: No
	+ Purpose: Confirm if you hold a medical license.
* **7. medical_board_certifications**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter any board certifications you hold.
* **8. address_details**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter your practice address.
* **9. phone_numbers**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter your practice phone numbers.
* **10. email_addresses**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter your practice email addresses.
* **11. availability_days**: 
	+ Type: select_one
	+ Required: No
	+ Purpose: Select the days you are available to work.
* **12. medical_certifications**: 
	+ Type: select_one
	+ Required: No
	+ Purpose: Confirm if you hold a medical certification.
* **13. insurance_info**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter any relevant insurance information.
* **14. emergency_info**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter emergency contact information.
* **15. payment_info**: 
	+ Type: text
	+ Required: No
	+ Purpose: Enter payment information.
* **16. notes**: 
	+ Type: text
	+ Required: No
	+ Purpose: Add any additional notes.

### Tips
* Make sure to fill out all required fields to ensure accurate and complete information.
* Use a brief description when entering medical specialties.
* Use phone number and email format for contact details (e.g. phone number: XXX-XXX-XXXX, email: [email address]).
* Select all applicable specialties you provide.
* Confirm holding medical licenses and certifications.
* Enter all relevant practice address, phone numbers, and email addresses.
* Select all applicable availability days.
* Confirm holding medical certifications.
* Enter all relevant insurance and emergency contact information.
* Add any additional notes about your practice.
