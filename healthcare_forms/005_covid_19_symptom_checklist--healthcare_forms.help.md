# covid_19_symptom_checklist - Help Guide
## Purpose
This form is designed to collect information about COVID-19 symptoms to help healthcare professionals quickly identify potential COVID-19 cases.

## How To Complete This Form
1. Review each page carefully and answer each question truthfully.
2. Select the options that best match your symptoms from the provided list.
3. Make sure to complete all required fields (indicated by an asterisk \*).
4. Click submit once you've finished filling out the form.
