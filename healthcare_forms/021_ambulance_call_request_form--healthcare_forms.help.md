# Ambulance Call Request Form - Help Guide
## Purpose
The Ambulance Call Request Form is used to collect information from the person calling for an emergency or non-emergency transport. This form helps the ambulance dispatcher determine the urgency of the situation and ensure that the correct response is sent to the scene.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Request Type" that best describes the urgency of the situation. Options include:
	* Emergency - Life threatening
	* Urgent - Serious but not life threatening
	* Non-Emergency - Scheduled transport
	* Inter-Facility Transfer
2. Enter the caller's contact information:
	* Enter the caller's first name
	* Enter the caller's last name
	* Enter the caller's phone number (for immediate contact)
	* Enter the caller's alternate phone number (optional)
3. Select the caller's relationship to the patient:
	* Self
	* Spouse/Partner
	* Parent
	* Child
	* Sibling
	* Friend
	* Coworker
	* Bystander
	* Healthcare Provider
	* Other
4. Enter the patient's information:
	* Enter the patient's first name
	* Enter the patient's last name
	* Enter the patient's age
	* Select the patient's gender (male, female, non-binary, unknown)
5. Enter the location:
	* Enter the address of the emergency location (street address, city, state, zip code)
	* Select the location type (private residence, public place, workplace, school, restaurant, shopping center, healthcare facility, nursing home, other)
	* Enter access instructions (gate codes, landmarks, etc.)
6. Enter the patient's condition:
	* Enter the chief complaint (what happened)
	* Select all the patient's current symptoms (select multiple from the list)
	* Enter the patient's detailed symptoms
7. Select the level of consciousness:
	* Alert and oriented
	* Confused
	* Drowsy
	* Unresponsive
	* Unknown
8. Select the breathing status:
	* Normal
	* Labored
	* Shallow
	* Not breathing
	* Unknown
9. Select the bleeding status:
	* No bleeding
	* Minor bleeding
	* Severe bleeding
	* Bleeding controlled
10. Select the location type:
	* Private residence
	* Public place
	* Workplace
	* School
	* Restaurant
	* Shopping center
	* Healthcare facility
	* Nursing home
	* Other
11. Select any known medical conditions:
	* Heart disease
	* Diabetes
	* High blood pressure
	* Asthma
	* COPD
	* Seizure disorder
	* Cancer
	* Kidney disease
	* None known
	* Unknown
12. Enter any current medications:
	* List if known
13. Enter any known allergies:
	* List if known
14. Enter the preferred hospital:
	* If patient has a preference
15. Enter any additional comments:
	* Any other important information about the situation
16. Indicate if you want to be called back:
	* Yes, no, or if you're available to answer additional questions
17. Select the time of the request:
	* Enter the time of the request
18. Enter the date of the request:
	* Enter the date of the request

## Field-by-Field Explanation
* **Request Type**: Select the urgency level of the situation (emergency, urgent, non-emergency, inter-facility transfer).
* **Caller First Name**: Enter the first name of the person making the call.
* **Caller Last Name**: Enter the last name of the person making the call.
* **Caller Phone Number**: Enter the phone number of the person making the call for immediate contact.
* **Caller Alternate Phone Number**: Enter a backup phone number of the person making the call.
* **Caller Relationship to Patient**: Select the relationship between the caller and the patient (self, spouse/partner, parent, child, sibling, friend, coworker, bystander, healthcare provider, other).
* **Patient First Name**: Enter the first name of the patient.
* **Patient Last Name**: Enter the last name of the patient.
* **Patient Age**: Enter the patient's age.
* **Patient Gender**: Select the patient's gender (male, female, non-binary, unknown).
* **Emergency Location**: Enter the address of the emergency location (street address, city, state, zip code).
* **Location Type**: Select the location type (private residence, public place, workplace, school, restaurant, shopping center, healthcare facility, nursing home, other).
* **Access Instructions**: Enter any access instructions for the location (gate codes, landmarks, etc.).
* **Chief Complaint**: Enter a brief description of what happened to the patient.
* **Current Symptoms**: Select all the patient's current symptoms.
* **Detailed Symptoms**: Enter any additional details about the symptoms.
* **Level of Consciousness**: Select the level of consciousness (alert and oriented, confused, drowsy, unresponsive, unknown).
* **Breathing Status**: Select the breathing status (normal, labored, shallow, not breathing, unknown).
* **Bleeding Status**: Select the bleeding status (no bleeding, minor bleeding, severe bleeding, bleeding controlled).
* **Known Medical Conditions**: Select any known medical conditions.
* **Current Medications**: List any current medications the patient is taking.
* **Known Allergies**: List any known allergies.
* **Preferred Hospital**: Enter the patient's preferred hospital (if applicable).
* **Reason for Hospital Preference**: Enter the reason for the patient's preferred hospital.
* **Additional Information**: Enter any additional comments or information about the situation.
* **May We Call You Back**: Indicate if you want to be called back for additional information.
* **Time of Request**: Enter the time of the request.
* **Date of Request**: Enter the date of the request.

## Tips
* Please fill out the form completely and accurately to ensure that the ambulance service can provide the best possible care and attention to the patient.
* If you're unsure about any information, try to enter "unknown" or "not applicable" to indicate that you're unsure.
* Make sure to enter the correct contact information so that the ambulance service can contact you for additional information.
* If you have any additional comments or information, enter them in the "Additional Comments" field.
