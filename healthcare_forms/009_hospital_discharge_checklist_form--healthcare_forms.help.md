# Hospital Discharge Checklist Form - Help Guide
## Purpose
This form is designed to collect information for the discharge process of a patient after their hospital stay. It helps healthcare providers gather necessary details to ensure a smooth transition for the patient and their families.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you have all necessary information.
2. Fill out the form with accurate and up-to-date information for the patient.
3. Make sure to select the correct options for each field as required.

## Field-by-Field Explanation

* **1. patient_info** (`patient_info`, text, optional)
  This field is used to capture any additional information about the patient.
* **2. patient_name** (`prophets_name`, text, optional)
  This field is used to enter the patient's name.
* **3. patient_date_of_birthday** (`prophets_date_of_birthday`, number, optional)
  This field is used to enter the patient's date of birth.
* **4. discharge_date** (`discharge_date`, date, optional)
  This field is used to enter the date of discharge.
* **5. discharge_time** (`discharge_time`, time, optional)
  This field is used to enter the time of discharge.
* **6. medical_status** (`medical_status`, select_one, optional)
  This field is used to select the current medical status of the patient (Stable, Critical, Unstable, or Unknown).
* **7. discharge_location** (`discharge_location`, select_multiple, optional)
  This field is used to select where the patient will be discharged to (Hospital, Home, Clinic, or Other).
* **8. follow_up_info** (`follow_up_info`, text, optional)
  This field is used to capture any follow-up information.
* **9. discharge_status** (`discharge_status`, select_one, optional)
  This field is used to select the discharge status (Complete, Partial, None, or Unknown).
* **10. discharge_summary** (`discharge_summary`, text, optional)
  This field is used to enter a summary of the discharge.
* **11. medications** (`medications`, select_multiple, optional)
  This field is used to select any prescribed medications.
* **12. medical_team** (`medical_team`, select_multiple, optional)
  This field is used to select the medical team members involved in the patient's care.
* **13. next_steps** (`next_steps`, text, optional)
  This field is used to capture any next steps for the patient.
* **14. additional_comments** (`additional_comments`, text, optional)
  This field is used to capture any additional comments.
* **15. discharge_destination** (`discharge_destination`, select_one, optional)
  This field is used to select where the patient will be discharged to (Hospital, Home, Clinic, or Other).
* **16. discharge_destination_other** (`discharge_destination_other`, text, optional)
  This field is used to enter any other discharge destination.
* **17. patient_signature** (`patient_signature`, text, optional)
  This field is used to obtain the patient's signature.
* **18. goals** (`goals`, text, optional)
  This field is used to enter any goals for the patient's care.
* **19. discharge_location_other** (`discharge_location_other`, text, optional)
  This field is used to enter any other discharge location.
* **20. patient_address** (`patient_address`, text, optional)
  This field is used to enter the patient's address.
* **21. patient_city** (`city`, text, optional)
  This field is used to enter the patient's city.
* **22. patient_state** (`state`, text, optional)
  This field is used to enter the patient's state.
* **23. patient_zip** (`zip`, number, optional)
  This field is used to enter the patient's zip code.
* **24. phone** (`phone`, text, optional)
  This field is used to enter the patient's phone number.
* **25. medical_record_number** (`medical_record_number`, number, optional)
  This field is used to enter the patient's medical record number.

## Tips

* Make sure to review and complete each field accurately.
* Ensure you have the necessary permissions or authorization to access patient information.
* This form is intended for hospital discharge, please select the correct discharge location.
* Please note that this form is for informational purposes only and should be reviewed and updated by a healthcare professional before finalizing the patient's discharge.
* If you are unsure about any field, please refer to the healthcare provider for guidance.
