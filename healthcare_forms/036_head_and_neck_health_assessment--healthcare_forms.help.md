# Head And Neck Health Assessment - Help Guide

## Purpose
The Head And Neck Health Assessment is a form used to collect information about the symptoms and conditions affecting the patient's head and neck region. This information will be used to guide further evaluation and treatment.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question carefully and accurately, providing as much information as possible.
2. Complete all required fields (fields marked as required).
3. If a field is not required, you can leave it blank, but note that this may affect the accuracy of the assessment.
4. If you are unsure about any question, please ask for clarification or assistance from a healthcare professional.

## Field-by-Field Explanation

- **Introduction** (`introduction`, `note`, required: false): This is a note field where you can provide any additional information about the patient's condition.

- **Head And Neck Region Symptoms** (`head_and_neck_region_symptoms`, `text`, required: false): Describe the symptoms you are experiencing in the head and neck region, such as pain, numbness, tingling, or weakness.

- **Neck Pain Score** (`neck_pain_score`, `number`, required: false): Rate the level of pain you are experiencing in the neck area, using the following scale:
	+ 0: No pain
	+ 1: Mild pain
	+ 2: Moderate pain
	+ 3: Severe pain

- **Neck Movement Impairment** (`neck_movement_impairment`, `select_one`, required: false): Select the level of impairment you are experiencing in the neck area:
	+ 0: No impairment
	+ 1: Mild impairment
	+ 2: Moderate impairment

- **Head Pain Score** (`head_pain_score`, `number`, required: false): Rate the level of pain you are experiencing in the head area, using the same scale as for the neck pain:
	+ 0: No pain
	+ 1: Mild pain
	+ 2: Moderate pain
	+ 3: Severe pain

- **Head And Neck Region Numbness Score** (`head_and_neck_region_numbness_score`, `number`, required: false): Rate the level of numbness you are experiencing in the head and neck region, using the following scale:
	+ 0: No numbness
	+ 1: Mild numbness
	+ 2: Moderate numbness
	+ 3: Severe numbness

- **Head And Neck Region Tingling Score** (`head_and_neck_region_tingling_score`, `number`, required: false): Rate the level of tingling you are experiencing in the head and neck region, using the same scale as for numbness:
	+ 0: No tingling
	+ 1: Mild tingling
	+ 2: Moderate tingling
	+ 3: Severe tingling

- **Head And Neck Region Weakness Score** (`head_and_neck_region_weakness_score`, `number`, required: false): Rate the level of weakness you are experiencing in the head and neck region, using the same scale as for numbness:
	+ 0: No weakness
	+ 1: Mild weakness
	+ 2: Moderate weakness
	+ 3: Severe weakness

## Tips

* Please answer honestly and accurately to ensure the best possible outcome.
* If you have any concerns or questions, please ask for assistance from a healthcare professional.
* This form is for the assessment of the head and neck region only. If you have symptoms in other areas, please complete separate assessments for those areas as well.
