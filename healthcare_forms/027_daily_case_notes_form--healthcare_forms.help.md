# daily_case_notes_form - Help Guide
## Purpose
The daily case notes form is designed to document essential information about each patient's visit, including session notes, case manager involvement, client name, dates of visit, and follow-up plans. This form helps healthcare professionals gather and record crucial details to ensure comprehensive patient care and continuity.

## How To Complete This Form

1. To complete this form, start by entering the session notes for the patient's visit. This is an open-ended text field where you can write any relevant information about the session.
2. Check if a case manager was involved in the patient's care. Select "Yes" if the case manager was present, or "No" if not.
3. Enter the client's name, which is required for identification purposes.
4. Select the date of the visit from the calendar.
5. If a next appointment is planned, select the date for the appointment.
6. Indicate if follow-up is needed, with options "Yes" or "No".
7. Enter any notes for the case manager, if applicable.
8. Choose the next step in the patient's care, with options "Yes" or "No".
9. Select the outcome of the visit, with options "Yes" or "No".

## Field-by-Field Explanation

* **Session Notes** (text, required/optional): Enter a brief summary of the patient's session, including any notable discussions, actions taken, or decisions made.
* **Case Manager** (select_one, required/optional): Check if a case manager was involved in the patient's care.
* **Client Name** (text, required/optional): Enter the patient's name for identification purposes.
* **Date Visited** (date, required/optional): Select the date of the patient's visit.
* **Next Appointment** (date, required/optional): Select the date of the planned next appointment.
* **Follow-up** (select_multiple, required/optional): Indicate if follow-up is needed, with options "Yes" or "No".
* **Case Manager Notes** (text, required/optional): Enter any notes for the case manager, if applicable.
* **Next Step** (select_one, required/optional): Choose the next step in the patient's care, with options "Yes" or "No".
* **Outcome** (select_one, required/optional): Select the outcome of the visit, with options "Yes" or "No".
