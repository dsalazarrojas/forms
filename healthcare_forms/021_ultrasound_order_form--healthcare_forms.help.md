# Ultrasound Order Form - Help Guide
## Purpose
This form is designed for healthcare professionals to order an ultrasound examination for a patient.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of ultrasound examination needed from the `Ultrasound Type` field.
2. Enter the patient's name in the `Patient Name` field.
3. Enter the patient's phone number in the `Patient Phone` field.
4. Select the payment method from the `Payment Method` field.
5. Enter the payment status in the `Payment Status` field.
6. Enter the patient's medical record number in the `Medical Record Number` field.
7. Enter the doctor's name in the `Doctor Name` field.
8. Select the doctor's specialty from the `Doctor Specialty` field.
9. Select the hospital from the `Hospital` field.
10. Select the insurance provider from the `Insurance Provider` field.
11. Select the medical specialist from the `Medical Specialist` field.
12. Enter the patient's address in the `Patient Address` field.
13. Enter the payment amount in the `Payment Amount` field.
14. Enter any patient notes in the `Patient Note` field.
15. Enter the doctor's phone number in the `Doctor Phone` field.
16. Select the insurance plan from the `Insurance Plan` field.
17. Enter the doctor's email in the `Doctor Email` field.
18. Select the patient's gender from the `Patient Gender` field.
19. Enter the patient's medical record number 2 in the `Medical Record Number 2` field.

## Field-by-Field Explanation

* **Appointment Request** (`1`, `number`, required): This field is used to specify the appointment request number.
* **Patient Name** (`2`, `text`, required): Enter the patient's full name.
* **Appointment Date** (`3`, `date`, required): Enter the date of the appointment.
* **Patient Phone** (`4`, `text`, required): Enter the patient's phone number.
* **Payment Method** (`5`, `select_multiple`, required): Select the payment method used for the appointment.
* **Payment Status** (`6`, `select_one`, required): Select the payment status of the appointment.
* **Medical Record Number** (`7`, `text`, required): Enter the patient's medical record number.
* **Doctor Name** (`8`, `text`, required): Enter the doctor's name.
* **Ultrasound Type** (`9`, `select_one`, required): Select the type of ultrasound examination needed.
* **Ultrasound Report** (`10`, `select_multiple`, required): Select the ultrasound report type.
* **Patient Condition** (`11`, `select_one`, required): Select the patient's condition.
* **Doctor Specialty** (`12`, `select_one`, required): Select the doctor's specialty.
* **Hospital** (`13`, `select_one`, required): Select the hospital where the examination will take place.
* **Insurance Provider** (`14`, `select_one`, required): Select the insurance provider for the patient.
* **Medical Specialist** (`15`, `select_one`, required): Select the medical specialist for the examination.
* **Patient Address** (`16`, `text`, required): Enter the patient's address.
* **Payment Amount** (`17`, `number`, required): Enter the payment amount.
* **Patient Note** (`18`, `text`, required): Enter any patient notes.
* **Doctor Phone** (`19`, `text`, required): Enter the doctor's phone number.
* **Insurance Plan** (`20`, `select_multiple`, required): Select the insurance plan for the patient.
* **Doctor Email** (`21`, `email`, required): Enter the doctor's email.
* **Patient Gender** (`22`, `select_one`, required): Select the patient's gender.
* **Medical Record Number 2** (`23`, `text`, required): Enter the patient's medical record number 2.

## Tips
* Please ensure that all fields are filled out accurately and completely.
* This form should not be used for duplicate or unnecessary examinations.
* All fields should be relevant to the patient's appointment.
* If you are unsure about any field, please consult with the doctor or the hospital's administration.
