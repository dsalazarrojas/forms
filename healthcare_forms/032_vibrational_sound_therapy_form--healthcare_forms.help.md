# Vibrational Sound Therapy Form - Help Guide

## Purpose
The Vibrational Sound Therapy Form is designed to collect information for vibrational sound therapy sessions. This form is essential for recording session details, capturing clinician and patient notes, and ensuring accurate documentation.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's ID.
2. Enter the patient's name.
3. Enter the patient's email.
4. Enter the patient's phone number.
5. Select the session's date.
6. Select the session's start time.
7. Select the session's end time.
8. Enter the session duration.
9. Provide notes for the clinician and patient.
10. Select the session location.
11. Choose the assigned clinician.
12. Select the submitted date and time.

## Field-by-Field Explanation

* **Patient ID** (`patient_id`, number, required): Enter the patient's unique identifier.
* **Patient Name** (`patient_name`, text, required): Enter the patient's name.
* **Patient Email** (`patient_email`, email, required): Enter the patient's email address.
* **Patient Phone** (`patient_phone`, text, required): Enter the patient's phone number.
* **Session Date** (`session_date`, date, required): Select the date of the session.
* **Session Start Time** (`session_start_time`, time, required): Select the start time of the session.
* **Session End Time** (`session_end_time`, time, required): Select the end time of the session.
* **Session Duration** (`session_duration`, text, required): Enter the session duration.
* **Clinician Notes** (`clinician_notes`, note, required): Enter notes for the clinician.
* **Patient Notes** (`patient_notes`, note, required): Enter notes for the patient.
* **Session Location** (`session_location`, select_multiple, required): Select the location of the session.
* **Assigned Clinician** (`assigned_clinician`, select_one, required): Choose the assigned clinician.
* **Session Location** (`session_location`, select_multiple, required): Select the location of the session.
* **Form Submitted By** (`form_submitted_by`, select_one, required): Choose who submitted the form.
* **Date** (`date`, date, required): Select the date the form was submitted.
* **Time** (`time`, time, required): Select the time the form was submitted.
* **Submitted By Name** (`submitted_by_name`, text, required): Enter the name of the person who submitted the form.
* **Assigned Tool** (`assigned_tool`, text, required): Enter the assigned tool used during the session.
* **Category** (`category`, text, required): Enter the category for the session.
* **Form ID** (`form_id`, number, required): Enter the unique ID of the form.

Please ensure that all required fields are completed accurately to ensure proper documentation and follow-up procedures.
