# Recovery Plan Form - Help Guide
## Purpose
The Recovery Plan Form is a template designed to help businesses, organizations, or individuals create a comprehensive recovery plan in response to a disruptive event. The form is used to gather information and develop a strategy to return to normalcy.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form title and ensure you understand the purpose of the form.
2. Select the category under which you want to store the recovery plan (Healthcare Forms or Other Forms).
3. Provide a brief description of the plan, including the event being addressed and the objectives of the recovery process.
4. Choose the tool assigned to the recovery plan (Chatjimmy or Other Tool).

## Field-by-Field Explanation

### Category (Page 2)
* **Category** (`category`, `select_one`, required/optional): Select the category under which you want to store the recovery plan. This will help with organization and searchability. You can choose between Healthcare Forms and Other Forms.

### Description (Page 3)
* **Description** (`description`, `text`, required/optional): Enter a brief description of the recovery plan, including the event being addressed and the objectives of the recovery process. This description should provide context for the plan and help others understand the recovery strategy.

### Assigned Tool (Page 4)
* **Assigned Tool** (`assigned_tool`, `select_one`, required/optional): Select the tool assigned to the recovery plan. You can choose between Chatjimmy and Other Tool.

### Recovery Plan Form (Page 1)
* **Recovery Plan Form** (`recovery_plan_form`, `text`, required/optional): Enter the title of the recovery plan form, which should reflect the specific plan being created.
