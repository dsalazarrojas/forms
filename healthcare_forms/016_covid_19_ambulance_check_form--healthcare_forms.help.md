# COVID 19 Ambulance Check Form - Help Guide
## Purpose
The COVID 19 Ambulance Check Form is used to inspect and assess the overall condition of an ambulance, ensuring it's ready for service.

## How To Complete This Form
1. Review the form carefully and understand each section's purpose.
2. Gather all necessary information and equipment required for the inspection.
3. Complete each section accurately and thoroughly.

## Field-by-Field Explanation

* **Inspection Date** (`inspection_date`, date, required): Enter the date of the inspection.
* **Inspection Time** (`inspection_time`, time, required): Enter the time of the inspection.
* **Ambulance Unit Number** (`ambulance_unit_number`, text, required): Enter the vehicle identification number of the ambulance.
* **Vehicle Type** (`vehicle_type`, select_one, required): Select the type of ambulance being inspected (ALS, BLS, etc.).
* **Inspector Name** (`inspector_name`, text, required): Enter the name of the person conducting the inspection.
* **Inspector Title** (`inspector_title`, text, optional): Enter the title of the person conducting the inspection (EMT, Paramedic, etc.).
* **PPE Inventory Sufficient** (`ppe_inventory_sufficient`, select_one, required): Check if the personal protective equipment supplies are adequate.
* **N95 Masks Available** (`n95_masks`, select_one, optional): Check if N95 masks are available.
* **Protective Gowns Available** (`gowns_available`, select_one, optional): Check if protective gowns are available.
* **Gloves Available** (`gloves_available`, select_one, optional): Check if gloves are available.
* **Face Shields Available** (`face_shields_available`, select_one, optional): Check if face shields are available.
* **Disinfection and Cleaning Supplies Available** (`disinfection_supplies`, select_one, required): Check if disinfection and cleaning supplies are available.
* **Ambulance Interior Cleanliness** (`ambulance_cleanliness`, select_one, required): Rate the condition of the ambulance interior.
* **Ventilation System Operational** (`ventilation_system`, select_one, optional): Check if the air circulation system is working properly.
* **All Medical Equipment Functional** (`equipment_functional`, select_one, required): Check if all medical equipment is functional.
* **Equipment Issues or Maintenance Needed** (`equipment_issues`, text, optional): Describe any problems found with equipment.
* **Isolation Protocols Posted** (`isolation_protocols`, select_one, optional): Check if COVID-19 protocols are clearly visible.
* **Biohazard Disposal Containers Available** (`bio_hazard_disposal`, select_one, required): Check if biohazard disposal containers are available.
* **Documentation Complete and Current** (`documentation_complete`, select_one, optional): Check if trip logs and maintenance records are up-to-date.
* **Overall Vehicle Condition** (`overall_condition`, select_one, required): Rate the overall condition of the vehicle.
* **Recommendations or Repairs Needed** (`recommendations`, text, optional): List any necessary actions or repairs.
* **Inspection Approval Status** (`approval_status`, select_one, required): Indicate the inspection status.

Tips: 

* Make sure you have all necessary information and equipment before starting the inspection.
* Review each section carefully to ensure accuracy.
* Use the correct terminology and options for each field.
* If you're unsure about any question, try to answer based on your best judgment.
* Remember to provide clear and thorough answers to ensure the form is completed accurately.
