# Negative Test Result Submission - Help Guide
## Purpose
This guide explains how to submit a negative test result.

## How To Complete This Form
To complete this form, follow the instructions below:

1.  Enter your contact details in the Contact Details section.
2.  Upload your test result document in the Upload File field.
3.  Complete the Date Tested and Time Tested fields.
4.  Select the Test Type from the given options.
5.  Upload the test result document in the Test Result Upload field.
6.  Select the type of file you uploaded in the Test Result Upload Type field.
7.  Complete the Contact Details 2 section with any additional contact information.

## Field-by-Field Explanation
*  **Contact Details** (`contact_details`, text): 
    +   Enter your name, email, and phone number or any other relevant contact information.
*  **Test Result** (`test_result`, text): 
    +   Upload your test result document here. Ensure the document is accurate and complete.
*  **Date Tested** (`date_tested`, date): 
    +   Enter the date when the test was performed in mm/dd/yyyy format.
*  **Time Tested** (`time_tested`, time): 
    +   Enter the time of the test in 12-hour format (e.g., 12-00 PM).
*  **Test Type** (`test_type`, select_one): 
    +   Select the type of test performed from the given options.
*  **Upload File** (`upload_file`, text): 
    +   Upload your test result document here. Ensure the document is accurate and complete.
*  **Test Result Upload** (`test_result_upload`, text): 
    +   Upload your test result document here. Ensure it's the same document as in the Upload File field.
*  **Test Result Upload Type** (`test_result_upload_type`, select_multiple): 
    +   Select the type of file you uploaded from the given options.
*  **Test Result File** (`test_result_file`, text): 
    +   This field is not editable; it displays the uploaded file name.
*  **Submit Form 2** (`submit_form_2`, text): 
    +   This is a submit button.
*  **Contact Details 2** (`contact_details_2`, text): 
    +   Enter any additional contact information.
