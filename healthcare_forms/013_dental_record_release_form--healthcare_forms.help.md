# dental_record_release_form - Help Guide
## Purpose
This guide will walk you through the process of completing the "dental_record_release_form" which is used for updating or transferring a patient's dental records to a new dentist or healthcare provider.

## How To Complete This Form
To complete this form, follow the steps below:

1. Provide patient information: Start by filling out the patient's personal details such as date of birth, contact number, and emergency contact information.
2. Medical history: Fill out the medical history, allergies, and medical conditions sections with the patient's relevant medical information.
3. New dentist information: Provide details about the new dentist or healthcare provider, including their name, phone number, and address.
4. Complete the rest of the form: Answer the remaining questions as necessary, providing any additional information requested.

## Field-by-Field Explanation
* **patient_info**: This field is where you will enter the patient's name, date of birth, and contact information (phone number, emergency contact, and emergency contact number).
	+ Type: text
	+ Required: false
* **new_dentist_info**: This field is where you will enter the new dentist's name and contact information (phone number and address).
	+ Type: text
	+ Required: false
* **consent**: Please indicate whether the patient has given their consent to transfer their records.
	+ Type: text
	+ Required: false
* **medical_history**: Please provide any relevant medical history for the patient.
	+ Type: text
	+ Required: false
* **medication_use**: Provide any medication information relevant to the patient's dental treatment.
	+ Type: text
	+ Required: false
* **allergies**: Select whether the patient has any allergies.
	+ Type: select_multiple
	+ Required: false
* **medical_condition**: Select whether the patient has any medical conditions.
	+ Type: select_multiple
	+ Required: false
* **medical_history_details**: Provide any additional medical history for the patient.
	+ Type: text
	+ Required: false
* **medication_info**: Provide any medication information relevant to the patient's dental treatment.
	+ Type: text
	+ Required: false
* **medical_procedure**: Provide any medical procedures relevant to the patient's dental treatment.
	+ Type: text
	+ Required: false
* **dental_record_number**: Enter the patient's dental record number (if applicable).
	+ Type: text
	+ Required: false
* **dentist_signature**: Please provide the new dentist's or healthcare provider's signature.
	+ Type: text
	+ Required: false
* **date_of_transfer**: Enter the date of the record transfer (if applicable).
	+ Type: date
	+ Required: false
* **date_of_last_visit**: Enter the date of the patient's last visit (if applicable).
	+ Type: date
	+ Required: false
* **date_of_birth**: Enter the patient's date of birth.
	+ Type: date
	+ Required: false
* **contact_number**: Enter the patient's contact number.
	+ Type: text
	+ Required: false
* **medical_facility**: Enter the name of the medical facility where the patient receives treatment.
	+ Type: text
	+ Required: false
* **medical_provider**: Enter the name of the medical provider.
	+ Type: text
	+ Required: false
* **emergency_contact**: Enter the patient's emergency contact's name.
	+ Type: text
	+ Required: false
* **emergency_contact_number**: Enter the patient's emergency contact's phone number.
	+ Type: text
	+ Required: false
* **patient_notes**: Enter any notes or comments about the patient.
	+ Type: text
	+ Required: false
* **new_dentist_name**: Enter the new dentist's name.
	+ Type: text
	+ Required: false
* **new_dentist_phone**: Enter the new dentist's phone number.
	+ Type: text
	+ Required: false
* **new_dentist_address**: Enter the new dentist's address.
	+ Type: text
	+ Required: false
* **new_dentist_notes**: Enter any notes or comments about the new dentist.
	+ Type: text
	+ Required: false

Note: The fields marked as "required: false" are not mandatory and can be completed or left empty depending on the specific requirements of your institution or regulatory guidelines.
