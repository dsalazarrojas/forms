# initial_lifestyle_advisor_questionnaire - Help Guide
## Purpose
The initial_lifestyle_advisor_questionnaire is a form designed to collect information about an individual's health and lifestyle habits.

## How To Complete This Form
To complete this form, simply fill in the required fields as follows:
- Ensure that you have all necessary information and answers before starting the form.
- For fields with multiple options, select all that apply.
- Enter numbers as numerals, e.g., 5.
- Enter values for height and weight in the specified units.

## Field-by-Field Explanation
- **Employee Information** (`employee_information`, `number`, optional): This field is not relevant to this form as it does not ask for any employee specific information.
  - This field is likely a relic from a previous version of the form and has not been properly removed.
- **Medical Conditions** (`medical_conditions`, `select_multiple`, optional): Answer 'Yes' if you have any of the following medical conditions: [insert medical conditions here]. Answer 'No' if you do not have any medical conditions.
- **Medications** (`medications`, `select_one`, optional): Answer 'Yes' if you are currently taking any medications.
- **Medical Procedure** (`medical_procedure`, `select_one`, optional): Answer 'Yes' if you have undergone any medical procedures.
- **Medical History** (`medical_history`, `date`, optional): Enter the date of your last medical history update, if applicable.
- **Family History** (`family_history`, `number`, optional): Answer the number of family members with the following medical conditions: [insert medical conditions here].
- **Smoking History** (`smoking_history`, `number`, optional): Answer the number of years you have been smoking, if applicable.
- **Alcohol History** (`alcohol_history`, `number`, optional): Answer the number of years you have been consuming alcohol, if applicable.
- **Physical Activity Level** (`physical_activity_level`, `select_multiple`, optional): Select all that apply for your physical activity level:
  - High
  - Low
- **Height** (`height`, `number`, optional): Enter your height in centimeters.
- **Weight** (`weight`, `number`, optional): Enter your weight in kilograms.
- **Body Mass Index** (`body_mass_index`, `number`, optional): Calculate your Body Mass Index using the following formula: [insert formula here].
- **Blood Pressure** (`blood_pressure`, `number`, optional): Enter your blood pressure in millimeters of mercury.
- **Blood Sugar** (`blood_sugar`, `number`, optional): Enter your blood sugar in milligrams per deciliter.
- **Blood Cholesterol** (`blood_cholesterol`, `number`, optional): Enter your blood cholesterol in milligrams per deciliter.
- **Blood Oxygen Saturation** (`blood_oxygen_saturation`, `number`, optional): Enter your blood oxygen saturation, if applicable.
- **Allergy** (`allergy`, `select_one`, optional): Answer 'Yes' if you have any allergies.
- **Medical Device** (`medical_device`, `select_one`, optional): Answer 'Yes' if you use any medical devices.
- **Medical Condition Type** (`medical_condition_type`, `select_multiple`, optional): Select all that apply for any medical conditions:
  - [insert medical conditions here]
- **Family Member Status** (`family_member_status`, `select_multiple`, optional): Select all that apply for family member status:
  - Active
  - Inactive
- **Blood Type** (`blood_type`, `select_one`, optional): Answer 'Yes' if you have a specific blood type.
- **Height Unit** (`height_unit`, `select_one`, optional): Answer 'Yes' if you use the metric system for height.
- **Weight Unit** (`weight_unit`, `select_one`, optional): Answer 'Yes' if you use the metric system for weight.
- **Blood Pressure Unit** (`blood_pressure_unit`, `select_one`, optional): Answer 'Yes' if you use the metric system for blood pressure.
- **Blood Sugar Unit** (`blood_sugar_unit`, `select_one`, optional): Answer 'Yes' if you use a specific unit for blood sugar.

## Tips
- Double-check your answers for accuracy.
- If you are unsure about any fields, consult the relevant medical professional.
- If you have any additional information to add, contact the medical team directly.
