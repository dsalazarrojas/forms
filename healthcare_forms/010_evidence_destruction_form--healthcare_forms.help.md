# Evidence Destruction Form - Help Guide
## Purpose
This form is used to document the secure and transparent destruction of evidence in a controlled environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information. This includes:
	* Inventory ID
	* Item Count
	* Inventory Item Type (e.g., Drugs, Equipment)
	* Inventory Location
	* Disposal Date
	* Destruction Method (e.g., Burn, Crush, Shred)
	* Destruction Date
	* Inventory Status (e.g., active, inactive, pending)
2. Enter any additional notes or comments as necessary.
3. Provide contact information for the person submitting the form.
4. Enter the department, location, facility, employee, and manager responsible for the destruction.

## Field-by-Field Explanation

* **Inventory ID** (2, inventory id, required): Enter the unique ID assigned to the inventory item being destroyed.
* **Item Count** (3, inventory_item_count, required): Enter the number of items being destroyed.
* **Item Type** (4, inventory_item_type, required): Select the type of item (e.g., Drugs, Equipment) being destroyed.
* **Inventory Location** (5, inventory_location, required): Enter the location where the item was stored.
* **Disposal Date** (6, inventory_date, required): Enter the date on which the item was disposed of or scheduled for destruction.
* **Destruction Method** (7, destruction_method, required): Select the method used to destroy the item (e.g., Burn, Crush, Shred).
* **Destruction Date** (8, destruction_date, required): Enter the date on which the item was destroyed.
* **Inventory Status** (9, inventory_status, required): Select the current status of the item (e.g., active, inactive, pending).
* **Notes** (10, notes, optional): Enter any additional comments or notes about the destruction.
* **Submitter** (11, submitter, required): Enter your name and contact information.
* **Contact** (12, contact, required): Enter your contact information.
* **Department** (13, department, required): Enter the department responsible for the destruction.
* **Location** (14, location, required): Enter the location where the destruction took place.
* **Facility** (15, facility, required): Enter the facility where the destruction took place.
* **Employee** (16, employee, required): Enter the employee responsible for the destruction.
* **Manager** (17, manager, required): Enter the manager responsible for the destruction.
* **Destruction Location** (18, destruction_location, required): Enter the location where the item was destroyed.

Note: All fields marked as "required" must be completed before submitting the form.
