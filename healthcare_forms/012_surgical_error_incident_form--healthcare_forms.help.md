# Surgical Error Incident Form - Help Guide
## Purpose
The Surgical Error Incident Form is designed to gather information about errors that occur during surgical procedures. This form helps to document and investigate errors, ensuring that essential details are gathered and recorded accurately.

## How To Complete This Form
1. Answer the questions in the following pages:
	* Page 1: "What type of error occurred?" - Select "Yes" if the error occurred, "No" if it did not.
	* Page 2: Please describe the error in detail.
	* Page 3: Enter the patient's name (if applicable).
	* Page 4: Enter the date and time of the error.
	* Page 5: Enter the name of the surgeon or operating team member involved.
	* Page 6: Enter the name of the anesthesist or operating team member involved.
	* Page 7: Enter the name of the operating room or procedure location.
	* Page 8: Enter additional details about the error (if any).
	* Page 9: Specify the cause of the error (if known).
	* Page 10: Describe any actions taken to address the error.
	* Page 11: Indicate the status of the investigation.
	* Page 12: Specify the outcome of the error (if applicable).
	* Page 13: Describe the outcome for the patient.
	* Page 14: Describe the outcome for staff involved.

## Field-by-Field Explanation

### Page 1: What type of error occurred?
* **What type of error occurred?** (`What type of error occurred?`, select_one, required): This field allows you to indicate whether the error occurred.
* **Yes/No** (select_one): Choose "Yes" if the error occurred, "No" if it did not.

### Page 2: Error Description
* **Error Description** (`error_description`, text, required): Provide a detailed description of the error that occurred.

### Page 3: Patient Name
* **Patient Name** (`patient_name`, text, required=false): Enter the patient's name, if applicable.

### Page 4: Date of Error
* **Date of Error** (`date_of_error`, date, required): Enter the date the error occurred.

### Page 5: Surgeon Name
* **Surgeon Name** (`surgeon_name`, text, required=false): Enter the name of the surgeon or operating team member involved.

### Page 6: Anesthesist Name
* **Anesthesist Name** (`anesthesist_name`, text, required=false): Enter the name of the anesthesist or operating team member involved.

### Page 7: Operating Room
* **Operating Room** (`operating_room_name`, text, required=false): Enter the name of the operating room or procedure location.

### Page 8: Error Details
* **Error Details** (`error_details`, text, required): Provide additional details about the error, if any.

### Page 9: Cause of Error
* **Cause of Error** (`cause_of_error`, text, required=false): If known, specify the cause of the error.

### Page 10: Action Taken
* **Action Taken** (`action_taken`, text, required=false): Describe the actions taken to address the error.

### Page 11: Investigation Status
* **Investigation Status** (`investigation_status`, select_one, required): Indicate the status of the investigation.
* **Active/Inactive** (select_one): Choose "Active" if the investigation is ongoing, "Inactive" if it's completed.

### Page 12: Outcome
* **Outcome** (`outcome`, select_one, required=false): Specify the outcome of the error (if applicable).
* **Yes/No** (select_one): Choose "Yes" if the error had an outcome, "No" if it did not.

### Page 13: Patient Outcome
* **Patient Outcome** (`patient_outcome`, text, required=false): Describe the outcome for the patient.

### Page 14: Staff Outcome
* **Staff Outcome** (`staff_outcome`, text, required=false): Describe the outcome for staff involved.

## Tips

* Ensure that you fill out this form accurately and thoroughly to ensure that errors are properly documented and investigated.
* Review your responses carefully before submitting the form.
* If you're unsure about any of the fields, do not hesitate to seek assistance from your supervisor or a colleague.
