# Fitness Section Questionnaire - Help Guide
## Purpose
The purpose of this form is to collect information about your health habits and lifestyle.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each page and answer all the questions to the best of your ability.
2. Select the options that best apply to your situation.
3. Enter numerical values for questions that require a number.
4. If you're unsure or do not know the answer to a question, please select "Undecided" or "Don't Know" as the answer.

## Field-by-Field Explanation

* **Health Lifestyle** (`health_lifestyle`, text, optional): This field asks about your overall health lifestyle habits.
* **Do you smoke** (`health_lifestyle`, select_one, optional): This question asks whether you smoke or not. If you do, please select "True" and provide the number of cigarettes you smoke per day.
* **Do you follow a particular diet** (`health_lifestyle`, select_multiple, optional): This question asks if you follow a specific diet. Select all the diets that apply to you.
* **How many hours do you usually sleep per day** (`sleep_duration`, number, optional): This field asks about your sleep habits. Please enter the number of hours you usually sleep per day.
* **How often do you exercise** (`exercise_frequency`, select_one, optional): This question asks about your physical activity level. Select the frequency that best applies to you.
* **What type of exercise do you usually do** (`exercise_type`, select_one, optional): This question asks about the type of exercise you usually do. Select the type that best applies to you.
* **Do you have any medical conditions** (`medical_conditions`, select_multiple, optional): This question asks if you have any medical conditions. Select all the conditions that apply to you.
* **Do you take any medications** (`medications`, select_one, optional): This question asks if you take any medications. If yes, please specify the type of medication.
* **How many doctor visits do you have per month** (`doctor_visits`, number, optional): This field asks about your doctor visits. Please enter the number of visits per month.
* **Do you have any medical records** (`medical_records`, select_one, optional): This question asks if you have any medical records. If yes, please specify the type of record.
* **What type of medical records do you have** (`medical_records_type`, select_multiple, optional): This question asks about the type of medical records you have. Select all the types that apply to you.
