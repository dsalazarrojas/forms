# Session Note Documentation - Help Guide
## Purpose
This form is used to document each client's session, ensuring that important details are recorded and tracked for ongoing care.
## How To Complete This Form
- To start, select the client's name and the type of session that was completed.
- Answer all required fields, including goals and care plans.
- Record session start and end times, including date and time.
- Enter any follow-up actions and client notes.
- Update the follow-up status and any follow-up care status.
## Field-by-Field Explanation

* **Client Session** (1): Enter a brief description of the session.
* **Goals** (2): Indicate whether goals were achieved during the session.
* **Notes** (3): Record any important notes from the session.
* **Follow Up** (4): Indicate whether follow-up is required.
* **Therapist Name** (5): Enter the name of the therapist who conducted the session.
* **Client Notes** (6): Enter any notes from the client.
* **Session Length** (7): Record the length of the session.
* **Session Start Time** (8): Enter the start time of the session.
* **Session End Time** (9): Enter the end time of the session.
* **Follow Up Actions** (10): Record any follow-up actions taken after the session.
* **Next Session Date** (11): Enter the date of the next session.
* **Next Session Time** (12): Enter the time of the next session.
* **Therapist Notes** (13): Enter any notes from the therapist.
* **Client Care Plan** (14): Indicate whether the client has a care plan.
* **Care Plan Goals** (15): Enter any care plan goals.
* **Session Location** (16): Indicate where the session was held.
* **Client Care Plan Notes** (17): Enter any notes from the client care plan.
* **Client Goals** (18): Indicate whether the client has goals.
* **Follow Up Notes** (19): Record any follow-up notes.
* **Client Goals Status** (20): Indicate the status of the client's goals.
* **Session Type** (21): Indicate the type of session conducted.
* **Client Care Status** (22): Indicate the client's care status.
* **Follow Up Status** (23): Indicate the follow-up status.
* **Follow Up Care Status** (24): Indicate the follow-up care status.
* **Follow Up Next Session** (25): Enter the date of the next follow-up session.
