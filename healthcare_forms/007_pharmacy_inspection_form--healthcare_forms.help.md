# Pharmacy Inspection Form - Help Guide
## Purpose
This form is used to collect information for pharmacy inspections, which may include facility details, contact information, and compliance with specific regulations.

## How To Complete This Form
1. Start by filling out the "Facility Information" section, providing details about the pharmacy's address, name, and any other relevant information.
2. In the "Contact Details" section, fill out the necessary contact information for the person responsible for the inspection.
3. The "Safety Standards" section should include notes about the pharmacy's adherence to safety standards and any concerns or issues that need to be addressed.
4. In the "Compliance Checklist" section, mark off the items that the pharmacy is compliant with.
5. Use the "Note Section" for any additional comments or notes about the inspection.
6. If applicable, provide the "Email Addresses" of key contacts.
7. Finally, ensure that the "Assigned Tool" field is filled out with the specific tool or system used for the inspection.
8. Once all fields are completed, save the form as an "Output File" for record-keeping purposes.
## Field-by-Field Explanation
* **Facility Information (1)** (`text`, required: false): This field is for providing the name and address of the pharmacy being inspected.
* **Facility Information (2)** (`text`, required: false): This field is a duplicate of the first facility information field and seems to be a mistake in the form design.
* **Contact Details (3)** (`text`, required: false): Enter the contact person's name and phone number for the pharmacy.
* **Safety Standards (4)** (`text`, required: false): Note any issues or concerns regarding the pharmacy's safety standards.
* **Compliance Checklist (5)** (`text`, required: false): Check off the items that the pharmacy has complied with.
* **Note Section (6)** (`text`, required: false): Add any additional comments or notes about the inspection.
* **Email Addresses (7)** (`text`, required: false): Provide the email addresses of key contacts for the pharmacy.
* **Assigned Tool (8)** (`text`, required: true): Indicate the specific tool or system used for the inspection.
* **Output File (9)** (`text`, required: false): Save the completed form as an output file for record-keeping purposes.
* **Form IDs (10)** (`text`, required: false): This field seems to be unused and is likely a placeholder.

## Tips
* Make sure to fill out the "Assigned Tool" field accurately, as this is a required field.
* Review the form carefully to ensure that all relevant information is included.
* Save the completed form as an "Output File" to maintain accurate records.
