# coronavirus_measures_checklist - Help Guide
## Purpose
This form is designed to collect information about your COVID-19 symptoms, travel history, and contact information. It will help healthcare providers and authorities assess your situation and provide guidance on necessary measures to take.

## How To Complete This Form
1. Answer each question thoroughly and accurately.
2. Select "Yes" or "No" for each question, unless otherwise specified.
3. For select multiple questions, choose the relevant option(s).
4. Enter text answers for questions that require written responses.

## Field-by-Field Explanation
* **Symptoms**: Describe any COVID-19 symptoms you are experiencing.
* **Temperature**: Report your current body temperature.
* **Travel History**: Select "Yes" if you have recently traveled to a country or region affected by COVID-19. If "Yes", provide more information in the "Travel Destination" field.
* **Recent Contacts**: Select "Yes" if you have been in contact with someone who has been diagnosed with COVID-19. If "Yes", provide more information in the "Emergency Contact Name" field.
* **Symptoms Duration**: Report the duration of your symptoms, if any.
* **Travel Country**: If you selected "Yes" for "Travel History", select "Yes" if you traveled to this country. 
* **Travel Destination**: Provide the name of the country or region you traveled to.
* **Travel State**: If you selected "Yes" for "Travel History", select "Yes" if you traveled to this state. 
* **Travel Type**: If you selected "Yes" for "Travel History", select the type of travel (e.g., business, leisure, etc.).
* **Travel Date**: Report the date of your travel.
* **Return Date**: Report the date of your return, if you have already returned.
* **Test Results**: Select "Yes" if you have been tested for COVID-19.
* **Self Diagnosis**: Select "Yes" if you have self-diagnosed yourself with COVID-19.
* **Travel Method**: If you selected "Yes" for "Travel History", select the method you used for travel (e.g., plane, car, etc.).
* **Travel Status**: Select "Active" if you are currently traveling, or "Inactive" if you are not.
* **Health Insurance Provider**: Select "Yes" if you have a health insurance provider.
* **Health Insurance Number**: Provide your health insurance number, if you selected "Yes" for "Health Insurance Provider".
* **Emergency Contact Name**: Provide the name of an emergency contact.
* **Emergency Contact Number**: Provide the contact number of an emergency contact.
* **Emergency Contact Relationship**: Select "Yes" if the emergency contact is a family member or friend.
* **Emergency Contact Phone**: Provide the phone number of the emergency contact.
* **Travel History Other**: Provide any additional information about your travel history.
