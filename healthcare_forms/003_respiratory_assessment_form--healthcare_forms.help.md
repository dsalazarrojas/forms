# Respiratory Assessment Form - Help Guide
## Purpose
The Respiratory Assessment Form is used to gather information about a patient's respiratory health and medical history. This form helps healthcare professionals assess the patient's respiratory status, identify potential respiratory issues, and determine the need for further medical evaluation or intervention.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the patient's general information, including their name and ID number.
2. Provide the date of birth (optional).
3. Answer questions about the patient's respiratory symptoms, medical history, and allergies.
4. List the patient's current medications (if any).
5. Assess the patient's oxygen saturation, respiratory rate, breathing rate, and oxygen flow (if applicable).
6. Identify any medical conditions that may be related to the patient's respiratory system.
7. Indicate the patient's current respiratory status and condition.
8. Provide any additional information that may be relevant to the patient's respiratory health.

## Field-by-Field Explanation

* **General Information (General Information, text, required: false)**: Enter the patient's name and ID number.
* **Patient ID (Patient ID, number, required: true)**: Enter the patient's unique ID number.
* **Patient Name (Patient Name, text, required: true)**: Enter the patient's full name.
* **Date of Birth (Date of Birth, date, required: false)**: Enter the patient's date of birth (optional).
* **Respiratory Symptoms (Respiratory Symptoms, select_multiple, required: false)**: Answer questions about the patient's respiratory symptoms, such as shortness of breath, coughing, or wheezing.
* **Medical History (Medical History, text, required: false)**: Enter any relevant medical history, such as previous respiratory conditions or medical procedures.
* **Allergy List (Allergy List, select_one, required: false)**: Answer if the patient has any allergies or sensitivities.
* **Current Medications (Current Medications, text, required: false)**: List any current medications the patient is taking.
* **Current Medications List (Current Medications List, select_multiple, required: false)**: Select all medications the patient is currently taking.
* **Oxygen Saturation (Oxygen Saturation, number, required: true)**: Measure the patient's oxygen saturation level (percentage).
* **Respiratory Rate (Respiratory Rate, number, required: false)**: Record the patient's respiratory rate (breaths per minute).
* **Respiratory Rate Units (Respiratory Rate Units, select_one, required: true)**: Select the units for the respiratory rate (e.g., Good, Fair).
* **Respiratory Rate Value (Respiratory Rate Value, text, required: true)**: Enter the patient's respiratory rate value.
* **Breathing Rate (Breathing Rate, number, required: false)**: Record the patient's breathing rate (breaths per minute).
* **Breathing Rate Units (Breathing Rate Units, select_one, required: true)**: Select the units for the breathing rate (e.g., Good, Fair).
* **Breathing Rate Value (Breathing Rate Value, text, required: true)**: Enter the patient's breathing rate value.
* **Oxygen Flow (Oxygen Flow, text, required: false)**: Record the patient's oxygen flow information (if applicable).
* **Oxygen Flow Value (Oxygen Flow Value, number, required: false)**: Enter the patient's oxygen flow value (if applicable).
* **Medical Condition (Medical Condition, text, required: false)**: List any relevant medical conditions related to the patient's respiratory system.
* **Medical Condition List (Medical Condition List, select_multiple, required: false)**: Select any relevant medical conditions related to the patient's respiratory system.
* **Respiratory Condition (Respiratory Condition, select_one, required: true)**: Answer if the patient has a respiratory condition (e.g., asthma, COPD).
* **Respiratory Condition Other (Respiratory Condition Other, text, required: false)**: Enter any other respiratory conditions not listed in the previous field.
* **Respiratory Status (Respiratory Status, text, required: false)**: Record the patient's current respiratory status.
* **Respiratory Status Other (Respiratory Status Other, text, required: false)**: Enter any other respiratory status information not listed in the previous field.
* **Additional Information (Additional Information, text, required: false)**: Provide any additional information that may be relevant to the patient's respiratory health.
