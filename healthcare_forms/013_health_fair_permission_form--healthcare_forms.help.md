# Health Fair Permission Form - Help Guide
## Purpose
This form is designed to collect participant information for health screenings, including their informed consent, contact method, medical history, and other relevant details.

## How To Complete This Form
1.  **Participant Informed Consent**: Please select "Yes" to indicate that you have read and understand the consent form.
2.  **Screening Description**: Describe the purpose and process of the health screening.
3.  **Screening Conducted By**: If someone other than you will be conducting the screening, select "Yes" to indicate that they will be doing so.
4.  **Participant Contact Method**: Select how you would like to be contacted after the screening, such as by phone, email, or mail.
5.  **Participant Agreed to Screening**: Select "Yes" to indicate that you have agreed to participate in the screening.
6.  **Screening Conducted Date**: Enter the date the screening was conducted.
7.  **Screening Conducted Time**: Enter the time the screening was conducted.
8.  **Screening Conducted by Staff**: If the screening was conducted by staff, select "Yes" to indicate this.
9.  **Additional Comments**: If you have any additional comments or questions, please provide them here.
10. **Participant Signature**: Please sign this form to indicate that you have completed it accurately.
11. **Staff Signature**: If someone else conducted the screening, please sign this field to confirm that you conducted the screening.
12. **Screening Completed**: Select "Yes" to indicate that the screening is complete.
13.  **Screening Notes**: If there are any notes about the screening, please provide them here.
14.  **Screening Follow-up Date**: Enter the date for any follow-up screenings.
15.  **Participant Health History**: Please describe any medical conditions you have.
16.  **Participant Allergies**: List any allergies you have.
17.  **Participant Medical Condition**: Describe any medical conditions you have.
18.  **Participant Medications**: List any medications you are taking.
19.  **Participant Medical Device**: If you use any medical devices, please describe them here.
20.  **Participant Medical Device Serial Number**: If you have a serial number for your medical device, please provide it here.
21.  **Participant Medical Device Model Number**: If you have a model number for your medical device, please provide it here.
22.  **Participant Medical Device Software Version**: If you have a software version for your medical device, please provide it here.
23.  **Participant Medical Device Serial Number 2**: If you have another serial number for your medical device, please provide it here.
24.  **Participant Medical Device Model Number 2**: If you have another model number for your medical device, please provide it here.
25.  **Participant Other Devices**: If you use any other medical devices, please describe them here.
