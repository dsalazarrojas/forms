# Pediatric Symptom Checklist - Help Guide
## Purpose
This form is designed to gather information from parents or caregivers about the symptoms exhibited by a child in order to aid in the assessment and diagnosis of common pediatric symptoms with the help of a healthcare professional.

## How To Complete This Form
To complete this form, follow these steps:

1. Please describe the child's symptoms in the **Description** field.
2. Answer the questions in the subsequent fields regarding the presence of specific symptoms.
3. For select one fields (**fever**, **cough**, **rash**, **vomiting**, **sore_mouth**), choose the answer that best matches the child's condition.
4. For select multiple fields (**sore_throat**, **difficulty_breathing**, **ear_infection**, **sore_throat**), choose all the answers that apply to the child's condition.

## Field-by-Field Explanation
* **Description**: Enter a brief description of the child's symptoms.
* **parent_name**: Enter the child's name.
* **fever**: Select **Yes** if the child has a fever, and **No** otherwise.
* **cough**: Select **Yes** if the child is coughing, and **No** otherwise.
* **rash**: Select **Yes** if the child has a rash, and **No** otherwise.
* **sore_throat**: Select **Yes** if the child has a sore throat, and select all other relevant symptoms if applicable.
* **runny_eyes**: Select **Yes** if the child has runny eyes, and select all other relevant symptoms if applicable.
* **vomiting**: Select **Yes** if the child is vomiting, and **No** otherwise.
* **sore_mouth**: Select **Yes** if the child has a sore mouth, and **No** otherwise.
* **difficulty_breathing**: Select **Yes** if the child is having difficulty breathing, and select all other relevant symptoms if applicable.
* **ear_infection**: Select **Yes** if the child has an ear infection, and select all other relevant symptoms if applicable.
* **sore_throat**: Select **Yes** if the child has a sore throat, and select all other relevant symptoms if applicable.

## Tips
* Please ensure that you answer all questions accurately and thoroughly.
* If you are unsure about any of the symptoms or their severity, please consult with a healthcare professional.
* This form is meant to be a guide, not a substitute for medical diagnosis.
