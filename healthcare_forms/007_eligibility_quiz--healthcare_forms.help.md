# Eligibility Quiz - Help Guide

## Purpose
This form is designed to assess a person's eligibility for some sort of healthcare benefit or service.

## How To Complete This Form
To complete this form, simply answer each question to the best of your ability. You can select from the provided options for each question. If you have any questions or concerns, feel free to ask.

## Field-by-Field Explanation

* **Is this person 18 years or older?** (`eligibility_question_1`, select_one, Required/Optional): This question is asking about the age of the person. Please select "18 years or older" if the person is 18 or older.
* **Has this person been previously diagnosed with any of the following medical conditions?** (`eligibility_question_2`, select_multiple, Required/Optional): This question is asking about the person's medical history. Select all the conditions that apply.
* **How many hours do you sleep each night?** (`eligibility_question_3`, number, Required/Optional): This question is asking about the person's sleep habits. Please enter the number of hours you sleep each night.
* **Do you have access to internet?** (`eligibility_question_4`, select_one, Required/Optional): This question is asking about the person's access to digital resources. Please select "Yes" if you have access to the internet.
* **Do you have a stable job or income?** (`eligibility_question_5`, select_one, Required/Optional): This question is asking about the person's economic stability. Please select "Yes" if you have a stable job or income.
* **Do you have a stable residence address?** (`eligibility_question_6`, select_one, Required/Optional): This question is asking about the person's living situation. Please select "Yes" if you have a stable residence address.
* **Has this person ever used any of the following substances?** (`eligibility_question_7`, select_one, Required/Optional): This question is asking about the person's substance use. Select "Yes" if the person has used any of the listed substances.
* **What is this person's weight in kilograms?** (`eligibility_question_8`, number, Required/Optional): This question is asking about the person's weight. Please enter the person's weight in kilograms.
* **What is this person's height in centimeters?** (`eligibility_question_9`, number, Required/Optional): This question is asking about the person's height. Please enter the person's height in centimeters.
* **What is this person's BMI?** (`eligibility_question_10`, number, Required/Optional): This question is asking about the person's BMI. Please enter the person's BMI.
* **Do you have a history of smoking?** (`eligibility_question_11`, select_one, Required/Optional): This question is asking about the person's smoking habits. Select "Yes" if you have a history of smoking.
* **Do you take any medications?** (`eligibility_question_12`, select_one, Required/Optional): This question is asking about the person's medication use. Select "Yes" if you take any medications.
