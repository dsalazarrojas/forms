# Insulin Pump Settings Worksheet - Help Guide
## Purpose
The Insulin Pump Settings Worksheet is a form used by healthcare professionals to document settings for patients using insulin pumps. This form helps providers quickly access and update patient settings as needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the "Patient Name" field.
2. Select the insulin pump model from the list in the "Pump Model" field.
3. Enter the provider's notes in the "Provider Notes" field.
4. Configure the basal settings for the patient by selecting the appropriate frequency and dose units in the "Basal Settings" and "Basal Settings Frequency" fields.
5. Configure the bolus settings by entering the dose and unit in the "Bolus Settings" and "Bolus Settings Unit" fields.
6. Select the bolus frequencies for the patient in the "Bolus Frequencies" field.
7. Configure the basal frequencies for the patient in the "Basal Frequencies" field.
8. Repeat steps 4-7 for the second set of basal and bolus settings (if applicable).

## Field-by-Field Explanation
* **Patient Name**: Enter the patient's name as it appears on their medical record.
* **Pump Model**: Select the model of the patient's insulin pump from the list.
* **Provider Notes**: Enter any additional notes or comments about the patient's insulin pump settings.
* **Basal Settings**: Enter the basal settings for the patient, including the frequency and dose.
* **Basal Settings Frequency**: Select the frequency for the basal settings.
* **Basal Settings Dose**: Enter the dose for the basal settings.
* **Bolus Settings**: Enter the bolus settings for the patient, including the dose and unit.
* **Bolus Frequencies**: Select the frequencies for the bolus settings.
* **Basal Dose**: Enter the basal dose.
* **Basal Units**: Select the units for the basal dose.
* **Basal Settings Unit**: Select the unit for the basal settings.
* **Bolus Units**: Select the unit for the bolus settings.
* **Basal Frequencies 2**: Select the frequencies for the second set of basal settings.
* **Basal Dose 2**: Enter the dose for the second set of basal settings.
* **Basal Units 2**: Select the units for the second set of basal settings.
* **Bolus Dose 2**: Enter the dose for the second set of bolus settings.
* **Basal Settings Unit 2**: Select the unit for the second set of basal settings.
* **Bolus Units 2**: Select the units for the second set of bolus settings.
* **Basal Frequencies 2**: Select the frequencies for the second set of basal settings.
* **Bolus Settings Unit 2**: Select the unit for the second set of bolus settings.

## Tips
- Make sure to review and update the patient's insulin pump settings regularly.
- Ensure that the patient understands their settings and can manage their pump effectively.
- If you have any questions or concerns about the patient's settings, reach out to the healthcare team for guidance.
