# flu_mask_compliance_form - Help Guide
## Purpose
This form is used to determine if a user is compliant with the flu mask policy in healthcare settings. It helps to ensure that users are aware of the policy and understand their responsibilities in maintaining compliance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of healthcare forms you are currently using.
2. Provide a brief description of your current form usage.
3. Choose the tool you are using for form submission.
4. Enter your form ID (if applicable).
5. Indicate whether you would like to generate an output file for your form submission.

## Field-by-Field Explanation

* **healthcare_forms** (`category`, select_one, required): Select the category of healthcare forms you are currently using.
* **flu_mask_compliance_form_description** (`description`, text, required): Provide a brief description of your current form usage.
* **assigned_tool** (`assigned_tool`, select_one, required): Choose the tool you are using for form submission (e.g., "chatjimmy").
* **form_id** (`form_id`, number, required): Enter your form ID if applicable.
* **output_file** (`output_file`, select_multiple, required): Indicate whether you would like to generate an output file for your form submission. 

## Tips
- Make sure to select the correct category of healthcare forms you are using.
- Provide a clear and concise description of your current form usage.
- Choose the correct tool for form submission if applicable.
- Enter your form ID accurately if it is required.
- Select the correct option for output file generation.
