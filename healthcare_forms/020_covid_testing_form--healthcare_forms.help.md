# covid_testing_form - Help Guide
## Purpose
This form is used to collect data for COVID-19 testing.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the patient's name in the "Patient Name" field.
2. Provide the patient's phone number in the "Patient Phone" field.
3. Enter the date of the test in the "Test Date" field in the format "YYYY-MM-DD".
4. Record the test results in the "Test Results" field.
5. Select the test result status from the options provided in the "Test Result Status" field.
6. If applicable, provide a consent form in the "Consent" field.

## Field-by-Field Explanation
- **Patient Name (text):** Enter the name of the patient.
  * Required field: No
  * Format: Free text input
  * Example: John Doe
- **Patient Phone (text):** Enter the phone number of the patient.
  * Required field: Yes
  * Format: 10-digit number
  * Example: 123-456-7890
- **Test Date (date):** Enter the date of the test in "YYYY-MM-DD" format.
  * Required field: No
  * Format: "YYYY-MM-DD"
  * Example: 2022-02-15
- **Test Results (text):** Enter the results of the test.
  * Required field: No
  * Format: Free text input
  * Example: Positive
- **Test Result Status (select one):** Select the status of the test result from the options provided.
  * Required field: No
  * Options: Active, Inactive
  * Example: Active
- **Consent (note):** If required, provide a consent form in this field.
  * Required field: No
  * Format: Free text input
  * Example: See attached consent form for details.
