# Medical Staff Accommodation Form - Help Guide
## Purpose
The Medical Staff Accommodation Form is used to request medical accommodations for staff members.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of accommodation requested.
2. Choose the start date of the accommodation.
3. Choose the end date of the accommodation.
4. Enter the number of nights requested.
5. Enter the address of the accommodation.
6. Enter the postal code of the accommodation.
7. Provide any additional information.
8. Enter the name of the staff member requesting the accommodation.

## Field-by-Field Explanation
* **Staff ID (1)**: This field is optional and asks for your staff ID.
* **Accommodation Request Type (2)**: Select the type of accommodation needed, such as a meeting room or equipment.
* **Accommodation Start Date (3)**: Enter the start date of the accommodation request.
* **Accommodation End Date (4)**: Enter the end date of the accommodation request.
* **Number of Nights (5)**: Enter the number of nights the accommodation is needed.
* **Accommodation Address (6)**: Enter the address of the accommodation location.
* **Accommodation Postal Code (7)**: Enter the postal code of the accommodation location.
* **Accommodation Additional Info (8)**: Enter any additional information about the accommodation request.
* **Staff Member Name (9)**: Enter the name of the staff member making the request.
