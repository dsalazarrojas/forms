# Denture Processing Checklist - Help Guide
## Purpose
The Denture Processing Checklist is a form used to track and document the steps involved in the denture processing process. This form is designed to ensure that each step is completed accurately and on time, reducing the risk of errors and improving patient care.

## How To Complete This Form
To complete this form, follow these steps:

1. Begin by filling out the **Patient Info** field with the patient's identifying information (name, date of birth, ID number, etc.).
2. Next, fill out the **Doctor Info** field with the relevant details about the doctor who will be performing the treatment.
3. Select the **Treatment** option that applies to the patient's condition (e.g. 'Yes' for a dental implant, 'No' for other types of treatment).
4. For the **Impressions** field, select all relevant options that apply to the patient's denture impressions (e.g. upper, lower, full, etc.).
5. In the **Fabrication** field, select all relevant options that apply to the denture fabrication process (e.g. metal, acrylic, etc.).
6. If applicable, select the **Try-In** option that applies to the try-in process (eassistant).
7. Finally, fill out the **Delivery** date for when the dentures will be delivered to the patient.

## Field-by-Field Explanation

* **Introduction (page 1)**: This is a brief explanation of the form and the purpose of the denture processing checklist.
* **Patient Info (page 2)**: Fill out this field with the patient's identifying information (name, date of birth, ID number, etc.). This field is required.
* **Doctor Info (page 3)**: Fill out this field with the relevant details about the doctor who will be performing the treatment. This field is required.
* **Treatment (page 4)**: Select the option that applies to the patient's condition (e.g. 'Yes' for a dental implant, 'No' for other types of treatment). This field is required.
* **Impressions (page 5)**: Select all relevant options that apply to the patient's denture impressions (e.g. upper, lower, full, etc.). This field is not required but recommended.
* **Fabrication (page 6)**: Select all relevant options that apply to the denture fabrication process (e.g. metal, acrylic, etc.). This field is not required but recommended.
* **Try-In (page 7)**: If applicable, select the option that applies to the try-in process. This field is not required but recommended.
* **Delivery (page 8)**: Fill out this field with the date when the dentures will be delivered to the patient. This field is not required but recommended.

## Tips

* Make sure to carefully review each field before proceeding to the next step to avoid errors.
* If you're unsure about any field, consult with the relevant staff member or supervisor.
* Double-check the **Delivery** date to ensure that it aligns with the patient's scheduled appointment.
