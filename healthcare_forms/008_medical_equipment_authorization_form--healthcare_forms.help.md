# Medical Equipment Authorization Form - Help Guide
## Purpose
This form is used to authorize medical equipment for use in a healthcare setting. It collects information about the medical equipment authorized, including the equipment name, location, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all authorized medical equipment from the list below:
	* Select "Option 1" if the medical equipment in question is authorized for use.
	* Select "Option 2" if the medical equipment is not authorized for use.

2. Enter the patient's last name in the "Patient Last Name" field.

3. Enter the patient's first name in the "Patient First Name" field.

4. Enter the name of the medical equipment in the "Equipment Name" field.

5. Enter the location where the medical equipment is located in the "Equipment Location" field.

## Field-by-Field Explanation

* **Authorized Equipment List** (`medical_equipment_authorized`, select_multiple, required: false)
	+ This field allows you to select all authorized medical equipment.
* **Patient Last Name** (`patient_last_name`, text, required: false)
	+ This field is for the patient's last name.
* **Patient First Name** (`patient_first_name`, text, required: false)
	+ This field is for the patient's first name.
* **Equipment Name** (`medical_equipment_name`, text, required: false)
	+ This field is for the name of the medical equipment.
* **Equipment Location** (`equipment_location`, text, required: false)
	+ This field is for the location where the medical equipment is located.
