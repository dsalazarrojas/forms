# Security_Awareness_Training_Acknowledgement - Help Guide
## Purpose
The purpose of this form is to acknowledge that you have completed the required security awareness training and provide any feedback or comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the acknowledgement form (page 1).
2. Select whether you have completed the training (page 2).
3. If you have completed the training, select the training program you have completed (page 6).
4. If you have completed the training, select the training status (page 7).
5. Enter the completion date and time of the training (page 8 and 9).
6. Enter your email address (page 4).
7. Optionally, provide any feedback or comments (page 3).

## Field-by-Field Explanation

* **Acknowledgement** (`1`, `text`, required): 
	+ This field is a text box where you enter your acknowledgement of completing the security awareness training. 
* **Has_training_been_completed** (`2`, `select_one`, required): 
	+ This field is a dropdown menu where you select if you have completed the training. Please select 'True' if you have completed the training.
* **Feedback** (`3`, `text`, required false):
	+ This field is a text box where you can provide any feedback or comments about the training.
* **Email** (`4`, `email`, required): 
	+ This field is a text box where you enter your email address.
* **Phone_number** (`5`, `text`, required false):
	+ This field is a text box where you can enter your phone number.
* **Training_program** (`6`, `select_one`, required): 
	+ This field is a dropdown menu where you select the training program you have completed. Please select 'Basic', 'Intermediate', or 'Advanced'.
* **Training_status** (`7`, `select_multiple`, required false): 
	+ This field is a dropdown menu where you select the status of the training. Please select 'Completed', 'Not started', or 'Pending'.
* **Completion_date** (`8`, `date`, required): 
	+ This field is a date picker where you select the date you completed the training.
* **Completion_time** (`9`, `time`, required): 
	+ This field is a time picker where you select the time you completed the training.

## Tips
* Make sure to fill out all required fields.
* Double-check the accuracy of your information before submitting the form.
* If you have any issues with the form, contact your supervisor or HR representative.
