# Quality Training Module Request Form - Help Guide

## Purpose
This form is designed to collect information from employees about their training preferences, which will be used to tailor the training experience to their needs.

## How To Complete This Form

1.  **Training Module Request**: Enter a brief description of the training module you're interested in.
2.  **Employee Details**: Select "Yes" if you are an employee. This field is optional but helps us understand who is submitting the request.
3.  **Training Module Details**: Enter any additional details about the training module you're requesting, such as the specific topics or dates you're interested in.
4.  **Training Preferences**: Select "Yes" if you have specific training preferences, such as online or in-person training.
5.  **Training Start Date**: Enter the start date for the training module, if applicable. If you're unsure, you can leave this field blank.
6.  **Training End Date**: Enter the end date for the training module, if applicable. If you're unsure, you can leave this field blank.
7.  **Training Hours Per Week**: Enter the number of hours per week you're willing to commit to the training.
8.  **Training Location**: Select "Yes" if you're willing to travel to a training location. This field is optional but helps us understand your preferences.
