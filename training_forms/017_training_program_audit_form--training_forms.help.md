# Training Program Audit Form - Help Guide
## Purpose
This form is used to collect feedback and evaluation of a training program.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Form ID**, which is a unique identifier for the program.
2. Provide a brief **Description** of the program, including its goals and objectives.
3. Select the **Category** of the program, which indicates whether it is effective or not.
4. Evaluate the **Effectiveness** of the program, choosing from "Very Effective", "Somewhat Effective", or "Not Effective".
5. Indicate your **Satisfaction** with the program, choosing from "Satisfied" or "Dissatisfied" (optional).
6. If you have any **Feedback** for the program, please provide it in the text field below.
7. If you have an **Output File** related to the program, please upload it.
8. If you assigned a specific **Tool** for the program, please mention it.
9. If you assigned a **User** for the program, please mention it.
10. You can also provide a **Category ID** if you have one.
11. Optionally, provide a brief **Description** of the program.

## Field-by-Field Explanation
### Form ID (id 1)
* **Form ID**: The unique identifier for the program.
### Description (id 2)
* **Description**: A brief description of the program, including its goals and objectives.
### Category (id 3)
* **Category**: Select "True" or "False" to indicate whether the program is effective or not.
### Effectiveness (id 4)
* **Effectiveness**: Evaluate the program's effectiveness, choosing from "Very Effective", "Somewhat Effective", or "Not Effective".
### Satisfaction (id 5)
* **Satisfaction**: Indicate your satisfaction with the program, choosing from "Satisfied" or "Dissatisfied" (optional).
### Feedback (id 6)
* **Feedback**: Provide any comments or suggestions for the program in this text field (optional).
### Output File (id 7)
* **Output File**: Upload any files related to the program (optional).
### Tool (id 8)
* **Tool**: Mention any tools assigned for the program (optional).
### User (id 9)
* **User**: Mention the user who was assigned for the program (optional).
### Category ID (id 10)
* **Category ID**: Provide a category ID if you have one (optional).
### Category (id 11)
* **Category (2)**: Select a category from the list (optional).
### Description (id 12)
* **Description (2)**: Provide a brief description of the program (optional).

## Tips
* Please answer all questions accurately and thoroughly to provide valuable insights for improvement.
* If you're unsure about any field, please ask your supervisor or the training team for guidance.
* This form is designed to be a one-time evaluation tool, so please ensure that you do not duplicate submissions.
