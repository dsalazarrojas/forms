# Aerial Rescue Skills Assessment - Help Guide
## Purpose
This form is designed to assess a candidate's aerial rescue skills, technical competence, and ability to follow safety protocols in emergency situations.

## How To Complete This Form

1. **Candidate Information**
    Enter the candidate's complete legal name, department or unit they belong to, and any current certifications relevant to aerial rescue.
2. **Assessment Information**
    Enter the date when the assessment is being conducted and where it is taking place.
3. **Assessment Conducted By**
    Enter the name of the person conducting the assessment and their qualifications or credentials.
4. **Equipment Preparation and Safety**
    This section is for note-taking and is not a required field.
5. **Equipment Inspection Performed**
    Rate the candidate's performance in inspecting all equipment before use, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
6. **Equipment Selection Appropriateness**
    Rate the candidate's selection of equipment for the scenario, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
7. **Safety Protocol Adherence**
    Rate the candidate's adherence to safety protocols, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
8. **Technical Skills Assessment**
    This section is for note-taking and is not a required field.
9. **Knot Tying Proficiency**
    Rate the candidate's proficiency in tying essential rescue knots, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
10. **Rigging System Setup**
    Rate the candidate's setup of the rigging system, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
11. **Communication with Team Members**
    Rate the candidate's communication with team members, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
12. **Problem Solving Under Pressure**
    Rate the candidate's ability to solve problems under pressure, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
13. **Victim Extraction Technique**
    Rate the candidate's performance in extracting the victim, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
14. **Emergency Response Time**
    Rate the candidate's emergency response time, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
15. **Decision Making Accuracy**
    Rate the candidate's decision-making accuracy, using the following options:
    - Excellent
    - Proficient
    - Needs Improvement
    - Unsatisfactory
16. **Scenario-Based Assessment**
    This section is for note-taking and is not a required field.
17. **Scenario Complexity Level**
    Rate the complexity level of the assessment scenario, using the following options:
    - Basic
    - Intermediate
    - Advanced
    - Expert
18. **Overall Competency Rating**
    Rate the candidate's overall competency in aerial rescue skills, using the following options:
    - Exceeds Standards
    - Meets Standards
    - Partially Meets Standards
    - Does Not Meet Standards
19. **Recommendations for Improvement**
    Enter any specific areas where the candidate needs improvement.
20. **Certification Decision**
    Rate the candidate's eligibility for certification, using the following options:
    - Certified
    - Conditionally Certified
    - Requires Retesting
    - Not Certified
21. **Assessor's Signature**
    Enter your electronic signature.

## Tips

*   Please ensure that all sections are filled out completely and accurately.
*   When rating candidate performance, use the provided options (Excellent, Proficient, Needs Improvement, Unsatisfactory).
*   If a candidate does not meet the required standard, provide specific feedback and recommendations for improvement.
*   Ensure that the assessment is conducted in a fair and unbiased manner. 

Note: This help guide is a general guide to assist users in completing the form. The specific instructions and requirements may vary depending on the specific assessment scenario. Please refer to the assessment's specific requirements and guidelines.
