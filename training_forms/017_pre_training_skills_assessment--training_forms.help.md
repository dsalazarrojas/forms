# Pre Training Skills Assessment - Help Guide
## Purpose
The Pre Training Skills Assessment form is used to evaluate an individual's pre-training skills, training form questions, and training outcome expectations to determine their suitability for a training session.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for each question based on your knowledge and experience.
2. Provide detailed answers to the questions that require text input.
3. Ensure that you answer all questions accurately and thoroughly.

## Field-by-Field Explanation
* **Pre-training Skills Assessment Form** (`pre_training_skills_assessment_form`): This field is a text input where you can provide a detailed description of the individual's pre-training skills.
* **Training Form Questions** (`training_form_questions`): Select all questions that apply from the list below:
	+ Yes
	+ No
* **Employee Skills Assessment** (`employee_skills_assessment`): Enter a numerical value to assess the individual's skills.
* **Training Session Needs** (`training_session_needs`): Select one of the options:
	+ Yes
	+ No
* **Training Session Needs Description** (`training_session_needs_description`): Provide a detailed description of the individual's training session needs.
* **Employee Skills Rating** (`employee_skills_rating`): Select one of the options:
	+ Good
	+ Fair
* **Training Outcome Expectations** (`training_outcome_expectations`): Select one of the options:
	+ Yes
	+ No
* **Training Outcome Expectations Description** (`training_outcome_expectations_description`): Provide a detailed description of the individual's training outcome expectations.
* **Evaluation Comments 1-10** (`evaluation_comments_1`, `evaluation_comments_2`, etc.): Enter any evaluation comments or feedback for the individual.
* **Next Steps** (`next_steps`): Provide a detailed description of the next steps or actions to be taken after the training session.
* **Follow-up Needs Next Steps** (`follow_up_needs_next_steps`): Select one of the options:
	+ Yes
	+ No
* **Follow-up Needs Next Steps Description** (`follow_up_needs_next_steps_description`): Provide a detailed description of the follow-up needs next steps.

Note: Some fields are not required, but it is still recommended to fill them out if possible.
