# Worker Training Module Request Form - Help Guide
## Purpose
This form is used to request access to a training module for a worker. Please fill out this form to provide the necessary information for the training module request.

## How To Complete This Form
1. Review the module choices and select all the modules you need access to.
2. Enter the name of the training module you are requesting.
3. Select the type of training module you are requesting.
4. Enter the date you would like to take the training module (if you have a preferred date, please select it from the options).
5. Enter the time of day you would like to take the training module (if you have a preferred time, please select it from the options).
6. Select if the training location is preferred.
7. Enter any required equipment or skills for the training module.
8. Enter the location of the training (if different from the training location selected in the previous step).
9. Enter the name of the trainer you would like to receive the training from.
10. Add any additional comments or information regarding your request.

## Field-by-Field Explanation

* **Module Choices** (module_choices, Select Multiple, Required): Select all the modules you are requesting access to. Please note that you should not select modules you have already received access to in the past 30 days.
* **Training Module Name** (training_module_name, Text, Required): Enter the name of the training module you are requesting.
* **Training Module Type** (training_module_type, Select One, Required): Select the type of training module you are requesting.
* **Training Module Date** (training_module_date, Date, Required): Enter the date you would like to take the training module.
* **Training Time** (training_time, Time, Required): Enter the time of day you would like to take the training module.
* **Preferred Date** (preferred_date, Select One, Required): Select if you have a preferred date for the training module.
* **Required Skills** (required_skills, Text, Required): Enter any required skills for the training module.
* **Required Equipment** (required_equipment, Text, Required): Enter any required equipment for the training module.
* **Training Location** (training_location, Text, Required): Enter the location of the training (if different from the location selected in the previous step).
* **Trainer** (trainer, Text, Required): Enter the name of the trainer you would like to receive the training from.
* **Comments** (comments, Note, Required): Add any additional comments or information regarding your request.
