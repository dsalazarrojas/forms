# Cryptocurrency Survey Template - Help Guide
## Purpose
This form is designed to collect information about cryptocurrency market trends and gather any notes or thoughts the user may have.

## How To Complete This Form
To complete this form, please follow these steps:

1. Go to the General info field and enter a brief description about the current state of the cryptocurrency market.
2. Move on to the Market trends field and provide more in-depth information about the market trends.
3. If you have any additional thoughts or notes, type them in the Note field.

## Field-by-Field Explanation
* **General info** (`general_info`, text, optional): Enter a brief description about the current state of the cryptocurrency market.
* **Market trends** (`market_trends`, text, optional): Provide more in-depth information about market trends.
* **Note** (`note`, note, optional): Type any additional thoughts or notes you may have.
