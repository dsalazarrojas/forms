# Mortgage Loan Application - Help Guide
## Purpose
The Mortgage Loan Application form is designed to gather necessary information for a loan application. It helps lenders to assess the applicant's creditworthiness and the property's value. By providing accurate and complete information, applicants can expedite the loan processing time and increase the chances of loan approval.

## How To Complete This Form
1.  Please select the correct property type (e.g., Single Family Home, Townhouse, or Condo).
2.  Enter the loan amount and loan term (in years) that suits your needs.
3.  Choose the loan frequency (e.g., Semi-Annual, Monthly, Quarterly, or Annually).
4.  Fill out the applicant's information: first name, last name, email, phone number, and address.
5.  Enter the property location and provide a brief description of the property.

## Field-by-Field Explanation
*   **loan_application_id** (Number, Optional): Enter the loan application ID (if assigned by the lender). If not assigned, you can leave it blank.
*   **property_type** (Select One, Optional): Select the type of property you're applying for (Single Family Home, Townhouse, or Condo).
*   **loan_amount** (Number, Optional): Enter the loan amount you require.
*   **loan_term** (Select One, Optional): Choose the loan term (15, 30, or 40 years).
*   **loan_term_years** (Number, Optional): Enter the loan term in years (related to the loan term).
*   **loan_frequency** (Select One, Optional): Select the loan repayment frequency (Semi-Annual, Monthly, Quarterly, or Annually).
*   **applicant_first_name** (Text, Optional): Enter the first name of the applicant.
*   **applicant_last_name** (Text, Optional): Enter the last name of the applicant.
*   **applicant_email** (Email, Optional): Enter the applicant's email address.
*   **applicant_phone** (Text, Optional): Enter the applicant's phone number.
*   **applicant_address** (Text, Optional): Enter the applicant's address.
*   **property_location** (Text, Optional): Enter the property's location.
*   **property_type_description** (Text, Optional): Describe the property in detail.
*   **loan_status** (Select One, Optional): Select the loan status (Pending or Closed).

**Tips:** Please ensure that all required fields are filled out accurately to avoid delays in the loan application process. Double-check your information before submission to prevent errors. If you have any questions or need assistance, contact the lender for guidance.
