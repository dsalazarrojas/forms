# Information Matrix Template Form - Help Guide
## Purpose
The purpose of this form is to help users provide detailed information in a structured format. 

## How To Complete This Form
1. Fill in all the required fields. The required fields will have an asterisk (\*) symbol next to the field label.
2. For fields with multiple options, select the desired option from the dropdown list.
3. Enter dates and times in the format "YYYY-MM-DD" and "HH:MM", respectively.
4. Enter numbers and decimal values using numerical characters only (0-9).
5. Enter email addresses in the format "example@example.com".

## Field-by-Field Explanation

* **Information Matrix Form First Page** (`information_matrix_form_first_page`, text, optional): This field is a text input field. Enter any relevant information here.
* **Section 1** (`information_matrix_form_section_1`, select_one, optional): Select one option from the dropdown list.
* **Section 2** (`information_matrix_form_section_2`, select_multiple, optional): Select multiple options from the dropdown list.
* **Section 3** (`information_matrix_form_section_3`, date, optional): Enter a date in the format "YYYY-MM-DD".
* **Section 4** (`information_matrix_form_section_4`, time, optional): Enter a time in the format "HH:MM".
* **Section 5** (`information_matrix_form_section_5`, number, optional): Enter a numerical value.
* **Section 6** (`information_matrix_form_section_6`, decimal value, optional): Enter a decimal value using numerical characters only (0-9).
* **Section 7** (`information_matrix_form_section_7`, note, optional): This field is for any additional information or notes.
* **Section 8** (`information_matrix_form_section_8`, email, optional): Enter an email address in the format "example@example.com".
* **Section 9** (`information_matrix_form_section_9`, phone number, optional): Enter a phone number.
* **Section 10** (`information_matrix_form_section_10`, text, optional): This field is a text input field. Enter any relevant information here.
* **Section 11** (`information_matrix_form_section_11`, select_one, optional): Select one option from the dropdown list.
