# property_information_form_template - Help Guide
## Purpose
The property information form template is designed to collect property-related data from users. This form is intended for real estate agents, property managers, or other stakeholders involved in property transactions.

## How To Complete This Form
To complete this form, follow these steps:

*   Fill in the property details page with the requested information.
*   Move on to the property address page and enter the property's address.
*   In the property status section, select the current status of the property from the options provided.
*   On the property type page, select all relevant types of property that apply.
*   Enter the property price in the designated field.
*   If applicable, select a date from the calendar.

## Field-by-Field Explanation
*   **Property Details (property_details)**: Enter a brief description of the property.
    *   This field is optional. Please provide a concise summary of the property's characteristics.
*   **Property Address (property_address)**: Enter the property's address.
    *   This field should be formatted as per the standard address format (street number and name, unit number, city, province/state, postal code/zip).
*   **Property Status (property_status)**: Select the current status of the property from the provided options.
    *   Please choose the status that best describes the property's current condition (e.g., for sale, rented, under renovation, etc.).
*   **Property Type (property_type)**: Select all types of property that apply.
    *   You may choose multiple types that describe the property (e.g., residential, commercial, industrial, etc.).
*   **Property Price (property_price)**: Enter the property's price.
    *   This field is a monetary value and should be formatted as per your local currency standards.
*   **Property Date (property_date)**: Select a date if applicable.
    *   This field is optional and should be used to indicate any relevant dates associated with the property (e.g., completion date of a construction project, lease start/end dates, etc.).
