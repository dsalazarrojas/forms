# Isc Information Form - Help Guide
## Purpose
The Isc Information Form is used to collect and store information about various forms. It is designed for internal purposes, such as keeping track of forms created, modified, or deleted within a system or organization.

## How To Complete This Form
1. Fill in all relevant fields to provide accurate and complete information about the form.
2. Select the correct options for select fields, such as form status or select one options.
3. Use the notes field to add any additional comments or explanations.
4. Submit the form to save your information.

## Field-by-Field Explanation

- **Form Information** (isc_info_form_1): Provide a brief description of the form, including its purpose and scope.
- **ISC Number** (isc_info_form_2): Enter the unique identifier or code for this form.
- **Phone Number** (isc_info_form_3): Enter the phone number associated with this form.
- **Email Address** (isc_info_form_4): Enter the email address associated with this form.
- **Form Date** (isc_info_form_5): Enter the date this form was created or modified.
- **Form Time** (isc_info_form_6): Enter the time this form was created or modified.
- **Notes** (isc_info_form_7): Add any additional comments or explanations about this form.
- **ISC Select One** (isc_info_form_8): Select one option from the available choices (e.g., 'Yes' or 'No').
- **ISC Select Multiple** (isc_info_form_9): Select multiple options from the available choices (e.g., 'Yes' or 'No').
- **Form Description** (isc_info_form_10): Enter a short description of this form.
- **Form Category** (isc_info_form_11): Enter the category or classification for this form.
- **Form Title** (isc_info_form_12): Enter a brief title for this form.
- **Form Category** (isc_info_form_13): Enter the category or classification for this form. (Note: This field is a duplicate of the previous "Form Category" field, and you should only fill it out if the information differs from the first "Form Category" field.)
- **Form ID** (isc_info_form_14): Enter a unique identifier or code for this form.
- **Form Description** (isc_info_form_15): Enter a short description of this form.
- **Form Status** (isc_info_form_16): Select the status of this form (e.g., 'Active' or 'Inactive').
- **Form Type** (isc_info_form_17): Enter the type or classification for this form.
- **Form Notes** (isc_info_form_18): Add any additional comments or explanations about this form.
- **Form Phone** (isc_info_form_19): Enter the phone number associated with this form.
- **Form Email** (isc_info_form_20): Enter the email address associated with this form.
- **Form URL** (isc_info_form_21): Enter the URL or link associated with this form.
- **Form Created** (isc_info_form_22): Enter the date this form was created.
- **Form Modified** (isc_info_form_23): Enter the date this form was modified.
- **Form Deleted** (isc_info_form_24): Enter the date this form was deleted.
