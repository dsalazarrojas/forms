# property_info - Help Guide

## Purpose
The property_info form is used to collect and store property-related information for internal use.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the property name in the "Property Name" field.
2. Choose the property type from the "property_type" dropdown menu.
3. Enter the property address in the "Address" field.
4. Enter the property email in the "Email" field, ensuring it is a valid email address.
5. Enter the property phone number in the "Phone" field, following the standard phone number format.
6. Choose the property date in the "Date" field.
7. Choose the property time in the "Time" field.
8. Provide any additional notes in the "Note" field.
9. Select the category for the property from the "Category" dropdown menu.
10. Select the subcategory for the property from the "SubCategory" dropdown menu.
11. Choose the property status from the "Status" dropdown menu.
12. Assign the property to a specific person from the "Assigned To" dropdown menu.

## Field-by-Field Explanation

* **Property Name** (text, required): Enter the name of the property, which should be a unique identifier for the property.
* **property_type** (select_one, optional): Select the type of property, which can be one of the following options: Option 1, Option 2, or Option 3.
* **Address** (text, optional): Enter the physical address of the property.
* **Email** (email, optional): Enter the contact email address of the property owner or manager.
* **Phone** (text, optional): Enter the property phone number, following the standard format with country code and area code.
* **Date** (date, optional): Choose the date of a specific event or occurrence related to the property.
* **Time** (time, optional): Choose the time of a specific event or occurrence related to the property.
* **Note** (note, optional): Enter any additional notes or comments about the property.
* **Category** (select_one, optional): Select the category for the property, which can be one of the following options: Option 4, Option 5, or Option 6.
* **SubCategory** (select_one, optional): Select the subcategory for the property, which can be one of the following options: Option 7, Option 8, or Option 9.
* **Status** (select_one, optional): Choose the status of the property, which can be one of the following options: Option 10, Option 11, or Option 12.
* **Assigned To** (select_one, optional): Assign the property to a specific person, which can be one of the following options: Option 13, Option 14, or Option 15.
 
**Tips**:
- Make sure to complete all required fields and select relevant options for accuracy and completeness.
- Review and edit your input before submission to ensure consistency and correctness.
