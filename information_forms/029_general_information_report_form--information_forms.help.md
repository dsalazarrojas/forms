# General Information Report Form - Help Guide

## Purpose
This form is designed to collect general information regarding employee reports. The form's purpose is to gather data on reports submitted by employees, including the report date, employee details, department information, location, issue description, issue priority, status, assigned personnel, and report type.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the report date field with the date the report was submitted.
2. Enter the employee's name in the employee name field.
3. Select the department the employee belongs to from the department dropdown list.
4. Type in the location where the issue occurred.
5. Provide a brief description of the issue in the issue description field.
6. Choose the priority level of the issue (High, Medium, or Low).
7. Select the current status of the issue (Open, Closed, or Pending).
8. Choose the personnel assigned to handle the issue (optional).
9. Select the type of report submitted (Issue Report or General Information Report).

## Field-by-Field Explanation
- **Report Date** (`report_date`, date, required:false): Enter the date the report was submitted.
- **Employee Name** (`employee_name`, text, required:false): Enter the name of the employee submitting the report.
- **Department** (`department`, select_one, required:false): Select the department the employee belongs to from the list: Accounting, Engineering, Finance, Marketing, Operations.
- **Location** (`location`, text, required:false): Type in the location where the issue occurred.
- **Issue Description** (`issue_description`, text, required:false): Provide a brief description of the issue.
- **Issue Priority** (`issue_priority`, select_one, required:false): Choose the priority level of the issue from the list: High, Medium, Low.
- **Issue Status** (`issue_status`, select_one, required:false): Select the current status of the issue from the list: Open, Closed, Pending.
- **Assigned To** (`assigned_to`, select_multiple, required:false): Choose the personnel assigned to handle the issue (if applicable).
- **Report Type** (`report_type`, select_multiple, required:false): Select the type of report submitted from the list: Issue Report, General Information Report.

## Tips
- Make sure to fill in all the required fields (report date and issue description).
- Select the correct department and location to ensure accurate information.
- If applicable, assign the issue to the correct personnel.
- Double-check the issue priority and status to ensure accurate information.
- If unsure about any field, you can always contact the form administrators for assistance.
- You can submit multiple reports if you need to report multiple issues.
