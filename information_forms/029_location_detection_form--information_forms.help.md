# Location Detection Form - Help Guide
## Purpose
This form is used to detect locations, teams, and events.

## How To Complete This Form
1. **First Location (first_location)**: Type in the first location you want to detect.
2. **Last Location (last_location)**: Type in the last location you want to detect.
3. **Why Did You Visit (why_did_you_visit)**: Select one of the options to explain why you visited the location. Options include:
	* Option 1
	* Option 2
	* Option 3
4. **Date Visited (date_visited)**: Select the date you visited the location.
5. **Time Visited (time_visited)**: Select the time you visited the location.
6. **Location Details (location_details)**: Provide any additional information about the location.
7. **Team Member (team_member)**: Type in the name of the team member.
8. **Team Name (team_name)**: Type in the name of the team.
9. **Event Name (event_name)**: Type in the name of the event.
10. **Event Date (event_date)**: Select the date of the event.
11. **Event Location (event_location)**: Type in the location of the event.
12. **Event Time (event_time)**: Select the time of the event.
13. **Purpose Of Event (purpose_of_event)**: Select one of the options to explain the purpose of the event.
	* Option 1
	* Option 2
	* Option 3
14. **Event Details (event_details)**: Provide any additional information about the event.

## Field-by-Field Explanation
* **First Location (first_location)**: A text field to collect the first location you want to detect.
* **Last Location (last_location)**: A text field to collect the last location you want to detect.
* **Why Did You Visit (why_did_you_visit)**: A select-one field to explain why you visited the location.
* **Date Visited (date_visited)**: A date field to select the date you visited the location.
* **Time Visited (time_visited)**: A time field to select the time you visited the location.
* **Location Details (location_details)**: A note field to provide additional information about the location.
* **Team Member (team_member)**: A text field to collect the name of the team member.
* **Team Name (team_name)**: A text field to collect the name of the team.
* **Event Name (event_name)**: A text field to collect the name of the event.
* **Event Date (event_date)**: A date field to select the date of the event.
* **Event Location (event_location)**: A text field to collect the location of the event.
* **Event Time (event_time)**: A time field to select the time of the event.
* **Purpose Of Event (purpose_of_event)**: A select-one field to explain the purpose of the event.
* **Event Details (event_details)**: A note field to provide additional information about the event.
