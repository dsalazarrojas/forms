# Image Upload For Search - Help Guide
## Purpose
This form is for users to submit images or video requests for visual search purposes.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the Search Request field (Field 1) with the description of what you are looking for.
2. Choose the Image Type field (Field 2) to select whether you are uploading a photo or video.
3. (Optional) Read and agree on the Consent field (Field 3) about what happens to the uploaded image or video.
4. If you're uploading an image file, fill out the Image File field (Field 4) with the URL or path of the image file.
5. If you're providing consent, select the Consent Type field (Field 5) to specify how you'd like to be contacted regarding the image or video.
6. In the Context field (Field 6), provide any relevant details about the search request.
7. If you've already uploaded the image elsewhere, fill out the Image URL field (Field 7) with the URL of the image.
8. In the Search Keywords field (Field 8), enter any relevant search keywords related to your image or video.
9. Finally, in the Search Description field (Field 9), provide a brief description of what you're searching for.

## Field-by-Field Explanation
* **Search Request** (Field 1, text, required): Enter a brief description of what you're searching for.
* **Image Type** (Field 2, select_one, optional): Choose whether you're uploading a photo or video.
* **Consent** (Field 3, note, optional): A note explaining what happens to the uploaded image or video. Please read and agree if you understand.
* **Image File** (Field 4, text, optional): If you're uploading an image file, enter the URL or path of the image file.
* **Consent Type** (Field 5, select_one, optional): If you're providing consent, select how you'd like to be contacted regarding the image or video.
* **Context** (Field 6, text, required): Provide any relevant details about the search request.
* **Image URL** (Field 7, text, optional): If you've already uploaded the image elsewhere, enter the URL of the image.
* **Search Keywords** (Field 8, text, optional): Enter any relevant search keywords related to your image or video.
* **Search Description** (Field 9, text, optional): Provide a brief description of what you're searching for.
