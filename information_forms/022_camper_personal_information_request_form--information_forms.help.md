# Camper Personal Information Request Form - Help Guide
## Purpose
This form is intended to gather necessary information about the camper's parent or guardian and the camper themselves. This information will be used to provide a safe and enjoyable experience for the camper during their stay.

## How To Complete This Form

1. Fill out the form completely and accurately. Each field is required unless marked as optional.
2. Please use the format specified for each field type (e.g., date format for date of birth).
3. If you are unsure about any field, please ask for clarification before proceeding.

## Field-by-Field Explanation

* **Parent or Guardian Name** (`Parent or Guardian Name`, text, required): Please provide the name of the camper's parent or guardian who is responsible for their care.
* **Email Address** (`Email Address`, email, required): Please provide the email address of the camper's parent or guardian.
* **Phone Number** (`Phone Number`, text, required): Please provide the phone number of the camper's parent or guardian.
* **Street Address** (`Street Address`, text, required): Please provide the street address of the camper's parent or guardian.
* **City** (`City`, text, required): Please provide the city of the camper's parent or guardian.
* **State** (`State`, text, required): Please provide the state of the camper's parent or guardian.
* **Zip Code** (`Zip Code`, text, required): Please provide the zip code of the camper's parent or guardian.
* **Camper First Name** (`Camper First Name`, text, required): Please provide the first name of the camper.
* **Camper Last Name** (`Camper Last Name`, text, required): Please provide the last name of the camper.
* **Date of Birth** (`Date of Birth`, date, required): Please provide the date of birth of the camper in the format `MM/DD/YYYY`.
* **Age** (`Age`, number, required): Please provide the age of the camper.
* **Gender** (`Gender`, select_one, required): Please select the camper's gender from the options provided.
* **Describe your child's personality** (`Describe your child's personality`, text, optional): If you would like to provide additional information about the camper's personality, please do so here.
* **How comfortable is your child in social situations** (`How comfortable is your child in social situations`, select_one, optional): Please select how comfortable your child is in social situations from the options provided.
* **Special interests or hobbies** (`Special interests or hobbies`, text, optional): If you would like to provide information about the camper's special interests or hobbies, please do so here.
* **Any fears, anxieties, or concerns** (`Any fears, anxieties, or concerns`, text, optional): If you would like to provide information about any fears, anxieties, or concerns the camper may have, please do so here.
* **Current Grade Level** (`Current Grade Level`, text, optional): If you would like to provide information about the camper's current grade level, please do so here.
* **Academic strengths** (`Academic strengths`, text, optional): If you would like to provide information about the camper's academic strengths, please do so here.
* **Any learning challenges or accommodations needed** (`Any learning challenges or accommodations needed`, text, optional): If you would like to provide information about any learning challenges or accommodations the camper may need, please do so here.
* **Additional Information** (`Additional Information`, text, optional): If you would like to provide any additional information, please do so here.

Note: Please ensure you complete each field accurately and thoroughly to provide the best possible experience for the camper. If you are unsure about any field, please ask for clarification before proceeding.
