# Property Unit Setup Form - Help Guide
## Purpose
This form is used to create a new property unit in the database. It gathers information about the property's details, address, and lease terms.

## How To Complete This Form
1. Select the property unit type (e.g. Property 1 Unit, Property 2 Unit, etc.) from the drop-down menu.
2. Choose the unit type (e.g. Studio/Room, 1 Bedroom, 2 Bedroom, etc.) from the drop-down menu.
3. Enter the property's address.
4. Select the property manager (e.g. Owner, Agent, Other).
5. Enter the rent amount.
6. Select the lease start date.
7. Select the lease end date.
8. Choose the lease term (e.g. Week to Week, Week to Month, Month to Month, Month to End, Other).
9. Select the property type (e.g. House, Apartment, Other).
10. Enter the property's subtype (e.g. single-family home, condominium, etc.).
11. Select the property status (e.g. Vacant, Available, Occupied).
12. Select the rent frequency (e.g. Monthly, Fortnight, Weekly).

## Field-by-Field Explanation
* **Property Unit Details (select_multiple)**: Select the property unit from the drop-down menu.
* **unit_type (select_one)**: Choose the unit type (e.g. Studio/Room, 1 Bedroom, 2 Bedroom, etc.).
* **property_address (text)**: Enter the property's address.
* **property_manager (select_one)**: Select the property manager (e.g. Owner, Agent, Other).
* **rent (number)**: Enter the rent amount.
* **lease_start_date (date)**: Select the lease start date.
* **lease_end_date (date)**: Select the lease end date.
* **lease_term (select_one)**: Choose the lease term (e.g. Week to Week, Week to Month, Month to Month, Month to End, Other).
* **property_type (select_one)**: Select the property type (e.g. House, Apartment, Other).
* **property_subtype (text)**: Enter the property's subtype (e.g. single-family home, condominium, etc.).
* **property_status (select_one)**: Select the property status (e.g. Vacant, Available, Occupied).
* **rent_frequency (select_one)**: Select the rent frequency (e.g. Monthly, Fortnight, Weekly).
