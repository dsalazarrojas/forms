# Virtual Assistance Information Form - Help Guide
## Purpose
This form is used to collect information about a virtual assistance project. It is essential to fill out this form accurately and completely to ensure that the project's goals and expectations are clearly understood by all parties involved.

## How To Complete This Form
1. Start by selecting the correct options for each field. Make sure to read each field's label and hint carefully before making your selection.
2. For fields with multiple options, such as "Project Details" and "Contact Details," select all applicable options that apply to the project.
3. Enter your selections and notes into the relevant text fields.
4. Ensure that you have attached any required or necessary uploaded documents.
5. Review your selections carefully before submitting the form.

## Field-by-Field Explanation
### 1. **Client Details** (`client_details`, text, optional)
* This field is used to collect information about the client, including name, contact information, or any other relevant details.

### 2. **Task Requirements** (`task_requirements`, text, optional)
* This field is used to describe the tasks and requirements of the project.

### 3. **Timelines** (`timelines`, date, optional)
* This field is used to specify the project's timeline, including start and end dates.

### 4. **Uploaded Documents** (`uploaded_files`, note, optional)
* This field is used to attach and store relevant documents that support the project's requirements and timelines. You can upload multiple files.

### 5. **Task Requirements Details** (`task_requirements_details`, text, optional)
* This field is used to provide more detailed information about the tasks and requirements of the project.

### 6. **Project Details** (`project_details`, select_multiple, optional)
* This field allows you to select which project details apply to the project. Select all that apply:
	+ Yes
	+ No

### 7. **Contact Details** (`contact_details`, select_multiple, optional)
* This field allows you to select which contact details apply to the project. Select all that apply:
	+ Yes
	+ No

### 8. **Project Lead** (`project_lead`, select_one, optional)
* This field is used to select if the project has a project lead:
	+ Yes
	+ No

### 9. **Project Manager** (`project_manager`, select_one, optional)
* This field is used to select if the project has a project manager:
	+ Yes
	+ No

### 10. **Team Members** (`team_members`, select_multiple, optional)
* This field allows you to select which team members are involved in the project. Select all that apply:
	+ Yes
	+ No
