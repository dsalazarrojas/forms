# Coverage Selection Form - Help Guide
## Purpose
This form is used to select coverage details for a specific purpose. It's meant to be filled out by users who need to choose between different coverage options for a particular process or project.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the correct coverage type from the first field. This field is not required, so you can skip it if you're not sure or don't have a specific coverage type in mind.
2. Enter the amount of coverage you need in the "amount" field. This field is also not required, so you can leave it blank if you're not sure or don't have an exact amount in mind.
3. Select any relevant add-ons that you need for your coverage from the "add-ons" field. This field is not required, so you can skip it if you don't need any add-ons.
4. Choose a date for your coverage to be effective from the "effective_date" field. This field is not required, so you can leave it blank if you're not sure or don't have a specific date in mind.

## Field-by-Field Explanation
* **coverage_type**: This is a dropdown list of coverage options. Select the one that best fits your needs. 
* **amount**: This field is meant to allow you to enter the exact amount of coverage you need. You can leave it blank if you're not sure or don't have a specific amount in mind.
* **add-ons**: This field allows you to select any additional features or options that you need for your coverage. You can select multiple options if needed.
* **effective_date**: This field is meant to let you choose a specific date when you want your coverage to be effective. You can leave it blank if you're not sure or don't have a specific date in mind.

## Tips
* Make sure to choose the correct coverage type and date if they are required for your specific purpose.
* Don't worry about the "amount" and "add-ons" fields if you're not sure or don't have a specific amount or add-ons in mind, as they are not required.
* If you have any questions or need help filling out this form, please let us know and we'll be happy to assist you.
