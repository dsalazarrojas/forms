# new_hire_information_form - Help Guide
 
## Purpose
This form is used to collect and manage information about new hires.
 
## How to Complete This Form
To complete this form, please follow the steps outlined above.
 
## Field-by-Field Explanation
The following is a detailed explanation of each field:
* **Job Title (select_one, required: false)**: Select whether the job is active or not.
* **Job Description (note, required: false)**: Enter a brief description of the job.
* **Job Start Date (date, required: false)**: Enter the date when the job starts in YYYY-MM-DD format.
* **Job End Date (date, required: false)**: Enter the date when the job ends in YYYY-MM-DD format.
* **Employee Name (select_one, required: false)**: Select whether the employee is active or not.
* **Department (select_multiple, required: false)**: Select one or multiple departments for the employee.
* **Job Level (select_one, required: false)**: Select the job level for the employee. It can be either High or Low.
* **Salary (number, required: false)**: Enter the employee's salary.
* **Hire Date (date, required: false)**: Enter the date when the employee was hired in YYYY-MM-DD format.
* **Termination Date (date, required: false)**: Enter the date when the employee terminated in YYYY-MM-DD format.
* **Employee Status (select_one, required: false)**: Select the status of the employee. It can be Active or Inactive.
