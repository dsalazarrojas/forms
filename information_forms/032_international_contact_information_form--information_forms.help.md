# International Contact Information Form - Help Guide

## Purpose
This form is designed to collect your international contact information and assign the correct tools and resources based on your location.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your first name in the "First Name" field.
2. Enter your last name in the "Last Name" field.
3. Enter your email address in the "Email" field. Please note that this field requires a valid email address.
4. Select your country from the "Country" dropdown menu.
5. Select your language from the "Language" dropdown menu.
6. Select your timezone from the "Time Zone" dropdown menu.
7. Optionally, enter any additional notes in the "Notes" field.
8. If necessary, select whether you have been assigned a tool or not in the "Assigned Tool" dropdown menu.
9. Optionally, select which output template to use in the "Output File" dropdown menu.
10. Optionally, enter a category for your information in the "Category" field.
11. Optionally, enter a brief description of your connection in the "Description" field.
12. If necessary, select whether you have been assigned a tool or not in the "Assigned Tool 2" dropdown menu.

## Field-by-Field Explanation
* **First Name (text, required)**: Enter your first name here.
* **Last Name (text, required)**: Enter your last name here.
* **Email (email, required)**: Enter a valid email address here.
* **Country (select_one, required)**: Select your country of origin from the dropdown menu.
* **Language (select_one, required)**: Select the language you speak from the dropdown menu.
* **Time Zone (select_one, required)**: Select your time zone from the dropdown menu.
* **Notes (note, optional)**: Add any additional notes or comments here.
* **Assigned Tool (select_one, optional)**: If you have been assigned a tool, select "Yes" here.
* **Output File (select_one, optional)**: Select which output template to use if you have been assigned a tool.
* **Category (text, optional)**: Enter a category for your information here.
* **Description (text, optional)**: Enter a brief description of your connection here.
* **Assigned Tool 2 (select_one, optional)**: If you have been assigned a tool, select "Yes" here.
* **Country and timezone are strictly validated**: Please ensure that you select a matching country and timezone combination for accurate tool assignment. If not, you will be required to re-fill the form.
