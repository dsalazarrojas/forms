# Pro Release Information Request - Help Guide
## Purpose
This form is designed to collect information from users about a release, including the purpose, urgency, supporting documents, and other relevant details.

## How To Complete This Form
1. Fill out the form fields as needed and submit the form.
2. Make sure to provide accurate and up-to-date information.

## Field-by-Field Explanation

* **Release Information Request Form**: This is the main form section where you will input the release information.
	+ This field is not required.
* **Purpose**: Enter a brief description of the purpose of the release.
	+ This field is not required.
* **Urgency**: Indicate the level of urgency for the release.
	+ This field is not required.
* **Supporting Documents**: List any supporting documents that are relevant to the release.
	+ This field is not required.
* **Release Information Request Form Notes**: This is an optional field for additional comments or notes.
	+ This field is not required.
* **Category**: Select the relevant category for the release.
	+ This field is not required.
* **Release Date**: Enter the date for the release.
	+ This field is not required.
* **Release Time**: Enter the time for the release.
	+ This field is not required.
* **Category Name**: Enter the category name.
	+ This field is not required.
* **Notes**: Enter any additional notes about the release.
	+ This field is not required.

## Tips
* Please make sure to provide accurate and up-to-date information to ensure that the form is completed correctly.
* If you have any questions or need further clarification, contact form@gic.mx.
