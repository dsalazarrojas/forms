# Information Technology Services Server Request Form - Help Guide
## Purpose
This form is designed to collect information from end-users to request IT services for server-related issues or maintenance. The information provided will be used to determine the best course of action to resolve the issue.

## How To Complete This Form
To complete this form, follow the steps below:
1. Click on the "Submit" button to begin filling out the form.
2. Select the server type that requires assistance from the "Server Type" dropdown menu.
3. Choose the status of the server from the "Server Status" dropdown menu.
4. Provide the location of the server.
5. Enter a brief description of the issue or maintenance request.
6. Select the priority level of the request.
7. Assign a technician to handle the request (optional).
8. Enter the date and time of the request.
9. Add any additional notes or information about the request.
10. Enter the email and phone number of the contact person.
11. Add any additional information about the request.

## Field-by-Field Explanation

* **Server Type** (`Server Type`, select_one): Choose the type of server that requires assistance from the dropdown menu. This could be Dell, HP, or IBM.
* **Server Status** (`Server Status`, select_multiple): Select all relevant statuses for the server, such as Active, Offline, or Maintenance.
* **Location** (`Location`, text): Enter the location of the server, such as a floor or room number.
* **Description** (`Description`, text): Briefly describe the issue or maintenance request for the server.
* **Priority** (`Priority`, number): Select the level of priority for the request, with higher numbers indicating higher priority.
* **Assigned Technician** (`Assigned Technician`, select_one): Choose a technician to handle the request from the dropdown menu.
* **Request Date** (`Request Date`, date): Enter the date when the request was made.
* **Request Time** (`Request Time`, time): Enter the time when the request was made.
* **Note** (`Note`, note): Add any additional notes or information about the request.
* **Email** (`Email`, email): Enter the email address of the contact person.
* **Phone** (`Phone`, text): Enter the phone number of the contact person.
* **Additional Information** (`Additional Information`, text): Add any additional information that may be helpful in resolving the issue.
