# Pre Construction Information Form - Help Guide
## Purpose
The Pre Construction Information Form is a collection of questions that gather essential information about a construction project before it commences. This form helps the project team, construction professionals, and stakeholders understand project parameters, contact details, and other critical information that sets the foundation for a successful project execution.
## How To Complete This Form
To complete this form, please follow these steps:
1. Select the relevant options for each field as required by your project circumstances.
2. Fill in the provided text fields with accurate and concise information.
3. Ensure that all required fields are completed before submission.

## Field-by-Field Explanation

* **Project Information** (`project_info`, note, required: false): This field is an introductory section that describes the project in general. You can provide any relevant details about the project, such as its purpose, scope, and objectives.
* **Contact Information** (`contact_info`, select_one, required: false): This field asks whether contact information is provided. Select 'Yes' if you are providing contact details, or 'No' if not.
* **Email** (`contact_email`, email, required: false): If you selected 'Yes' for contact information, fill in your email address here.
* **Project Address** (`project_address`, text, required: false): Enter the address where the project will take place.
* **Building Type** (`building_type`, select_multiple, required: false): Select the relevant building types from the provided options (Option 1, Option 2, Option 3).
* **Building Age** (`building_age`, number, required: false): If applicable, enter the age of the building.
* **Project Status** (`project_status`, select_one, required: false): Choose the status of the project from the provided options (Option 1, Option 2, Option 3, Option 4).
* **Project Location** (`project_location`, text, required: false): Enter the location of the project.
* **Phone** (`contact_phone`, text, required: false): If you selected 'Yes' for contact information, enter your phone number here.
* **Name** (`contact_name`, text, required: false): If you selected 'Yes' for contact information, enter your name here.
* **Project Notes** (`project_notes`, note, required: false): Provide any additional project notes that might be relevant to the project team.
* **Project Manager Name** (`project_manager_name`, text, required: false): Enter the name of the project manager.
* **Project Manager Email** (`project_manager_email`, email, required: false): Enter the email address of the project manager.
* **Project Manager Phone** (`project_manager_phone`, text, required: false): Enter the phone number of the project manager.
* **Project Manager Address** (`project_manager_address`, text, required: false): Enter the address of the project manager.
* **Project Manager Notes** (`project_manager_notes`, note, required: false): Provide any additional notes about the project manager.
* **Project Manager Title** (`project_manager_title`, text, required: false): Enter the title of the project manager.
