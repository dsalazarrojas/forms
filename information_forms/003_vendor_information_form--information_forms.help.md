# Vendor Information Form - Help Guide
## Purpose
The Vendor Information Form is used to collect essential details about a vendor for efficient communication and collaboration.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, marked as "Required."
2. Select the correct vendor type from the "Vendor Type" field, which determines the fields that appear below.
3. Enter the vendor's name and other relevant contact information.
4. Select the preferred contact method(s) from the "Contact Method" field.

## Field-by-Field Explanation

* **First Name** (first_name, text, Required): Enter the first name of the vendor.
* **Last Name** (last_name, text, Required): Enter the last name of the vendor.
* **Email** (email, email, Optional): Enter the email address of the vendor.
* **Phone** (phone, text, Required): Enter the phone number of the vendor.
* **Company** (company, text, Optional): Enter the name of the vendor's company (if applicable).
* **Address** (address, text, Required): Enter the address of the vendor.
* **Zip Code** (zip_code, text, Required): Enter the zip code of the vendor.
* **Website** (website, text, Optional): Enter the website of the vendor (if applicable).
* **Vendor Type** (vendor_type, select_one, Required): Select the type of vendor (e.g., Retailer, Manufacturer, Wholesaler, Service Provider).
* **Contact Person** (contact_person, text, Optional): Enter the name of the contact person (if applicable).
* **Job Title** (job_title, text, Required): Enter the job title of the contact person (if applicable).
* **Phone Extension** (phone_ext, text, Required): Enter the phone extension of the vendor.
* **Fax** (fax, text, Optional): Enter the fax number of the vendor (if applicable).
* **Email Extension** (email_ext, email, Required): Enter the email extension of the vendor.
* **Website Extension** (website_ext, text, Optional): Enter the website extension of the vendor (if applicable).
* **Social Media** (social_media, select_multiple, Required): Select the social media platforms used by the vendor.
* **Date Established** (date_established, date, Optional): Enter the date the vendor was established (if applicable).
* **Contact Number** (contact_number, text, Required): Enter the contact number of the vendor.
* **Company Representative** (company_rep, select_one, Required): Select the company representative (e.g., Male, Female, Other).
* **Language** (language, select_multiple, Required): Select the languages spoken or used by the vendor.
* **Currency** (currency, select_one, Required): Select the currency used by the vendor.
* **Time Zone** (time_zone, select_one, Required): Select the time zone of the vendor.
* **Time Zone(s)** (timezone, select_multiple, Required): Select the time zone(s) used by the vendor.
* **Contact Method** (contact_method, select_multiple, Required): Select the contact method(s) used by the vendor.
* **Notes** (notes, note, Optional): Enter any additional notes or comments about the vendor.
