# property_owner_account_preferences - Help Guide
## Purpose
The property_owner_account_preferences form is used to collect contact information and communication preferences from property owners.

## How To Complete This Form
To complete this form, please follow these steps:
1. Fill in the "Property Owner Name" field with the name of the property owner.
2. If applicable, enter the contact phone number for the property owner in the "Contact Phone" field.
3. Enter the property owner's contact email in the "Contact Email" field.
4. Select the preferred communication channel in the "Preferred Communication Channel" field.
5. If necessary, provide additional contact details in the "Primary Contact Address" and "Alternate Contact Phone" fields.
6. Specify the preferred communication method for the "Alternate Contact" in the "Preferred Communication Method Alternate" field.
7. Select the options for the property owner's communication preferences in the "Owner Communication Preferences" field.

## Field-by-Field Explanation

* **Property Owner Name** (text, required): Enter the name of the property owner.
* **Contact Phone** (number, optional): Enter the property owner's contact phone number.
* **Contact Email** (email, optional): Enter the property owner's contact email.
* **Preferred Communication Channel** (select_one, optional): Select the preferred communication channel for the property owner. Options include: Email, Phone, Text Message.
* **Primary Contact Address** (text, optional): Enter the primary contact address for the property owner.
* **Alternate Contact Phone** (number, optional): Enter an alternate contact phone number for the property owner.
* **Alternate Contact Email** (email, optional): Enter an alternate contact email for the property owner.
* **Preferred Communication Method Alternate** (select_one, optional): Select the preferred communication method for the alternate contact. Options include: Email, Phone, Text Message.
* **Owner Communication Preferences** (select_multiple, optional): Select the options for the property owner's communication preferences. Options include: Send Updates and Announcements via Email, Send Updates and Announcements via Phone, Send No Updates and Announcements, Send Updates and Announcements via Text Message.

## Tips
- Please ensure that you provide accurate and up-to-date contact information.
- Make sure to select the correct preferred communication channels to avoid missed updates or announcements.
