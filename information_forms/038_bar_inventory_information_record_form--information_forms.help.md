# Bar Inventory Information Record Form - Help Guide
## Purpose
The "Bar Inventory Information Record Form" is used to record and track inventory information for bars or establishments. This form helps to keep accurate and up-to-date records of the bar's inventory, enabling efficient stock management and decision-making.

## How To Complete This Form
1. Enter the **Record Date** in the format MM/DD/YY. This date will be used to track the current state of the inventory.
2. Enter the **Bar or Establishment Name**, which should match the name used in other inventory records.
3. Enter the **Location/Address** where the item is stored.
4. Select the **Item Category** from the list to specify the type of inventory item.
5. Enter the **Item Name** or product name.
6. Enter the **Brand or Manufacturer** name, if applicable.
7. Enter the **Item Size or Volume**, in milliliters or ounces, or provide a description.
8. Select the **Unit of Measure** from the list to specify the measurement unit.
9. Enter the **Quantity On Hand**, the current stock quantity.
10. Set the **Minimum Stock Level**, the reorder point, if applicable.
11. Set the **Maximum Stock Level**, the maximum capacity, if applicable.
12. Enter the **Cost Per Unit**, if applicable.
13. Calculate the **Total Value of Item** by multiplying the Quantity On Hand with the Cost Per Unit.
14. Select the **Storage Location**, where the item is stored.
15. Enter the **Expiration Date**, if applicable.
16. Enter the **Supplier Name**, if applicable.
17. Enter the **Supplier Contact Information**, if applicable.
18. Enter the **Last Reorder Date**, if applicable.
19. Enter the **Typical Reorder Quantity**, if applicable.
20. Select the **Item Condition**, if applicable.
21. Add any **Comments or Special Notes**, if necessary.

## Field-by-Field Explanation
* **Record Date**: Enter the date of this inventory record.
* **Bar or Establishment Name**: Enter the name of the business.
* **Location/Address**: Enter the address where the item is stored.
* **Recorded By**: Enter the name of the person documenting the inventory.
* **Item Category**: Select the type of inventory item (e.g., Spirits/Liquor, Beer, etc.).
* **Item Name**: Enter the specific product or equipment name.
* **Brand or Manufacturer**: Enter the brand name, if applicable.
* **Item Size or Volume**: Enter the size or volume of the item.
* **Unit of Measure**: Select the measurement unit (e.g., Bottles, Cases, etc.).
* **Quantity On Hand**: Enter the current stock quantity.
* **Minimum Stock Level**: Set the reorder point, if applicable.
* **Maximum Stock Level**: Set the maximum capacity, if applicable.
* **Cost Per Unit**: Enter the unit cost, if applicable.
* **Total Value of Item**: Calculate the total value by multiplying the Quantity On Hand with the Cost Per Unit.
* **Storage Location**: Select the storage location where the item is kept.
* **Expiration Date**: Enter the expiration date, if applicable.
* **Supplier Name**: Enter the supplier name, if applicable.
* **Supplier Contact Information**: Enter the contact information of the supplier.
* **Last Reorder Date**: Enter the date when this item was last reordered.
* **Typical Reorder Quantity**: Enter the typical reorder quantity, if applicable.
* **Item Condition**: Select the current condition of the item (e.g., Excellent, Good, etc.).
* **Comments or Special Notes**: Enter any additional information.
