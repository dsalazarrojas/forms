# Project Manager Information Form - Help Guide
## Purpose
The Project Manager Information Form is used to collect and store project-related information from project managers for administrative or tracking purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project manager's information, including their name, address, email, and phone number.
2. Provide details about the project, such as its title, description, start and end dates, and status.
3. Select the project category and contact preferences.
4. Add any additional notes about the project manager.

## Field-by-Field Explanation
### Project Manager Information
* **Manager Name**: Enter the name of the project manager.
* **Manager Address**: Enter the address of the project manager.
* **Manager Email**: Enter the email address of the project manager.
* **Manager Phone**: Enter the phone number of the project manager.

### Project Details
* **Project Title**: Enter a brief title of the project.
* **Project Description**: Enter a detailed description of the project.
* **Project Manager Start Date**: Enter the start date of the project.
* **Project Manager End Date**: Enter the end date of the project.
* **Project Status**: Select the current status of the project (Active or Inactive).
* **Project Category**: Select the category of the project (Yes or No).
* **Contact Preferences**: Select whether to contact the project manager (Yes or No).
* **Contact Details**: Enter any additional contact information.
* **Manager Notes**: Add any notes or comments about the project manager.

### Project Manager
* **Project Manager**: Select whether the project manager is active (Yes or No).

## Tips
* Ensure that all fields are filled in accurately and completely.
* If unsure about any field, refer to the project manager or project team for clarification.
* This form is meant to be used for internal purposes only.
