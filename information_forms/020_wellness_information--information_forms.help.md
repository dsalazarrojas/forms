# Wellness Information - Help Guide
## Purpose
The "Wellness Information" form is designed to collect information related to employee wellness, including categories, descriptions, and assigned tools. This form is intended to be used for tracking and organizing employee wellness data.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select a category for the wellness information from the "Category" dropdown menu.
2. Enter a brief description of the wellness information in the "Description" field.
3. If desired, provide an expanded description in the "Expanded Description" field.
4. Choose the assigned tool from the "Assigned Tool" dropdown menu.
5. If applicable, select multiple form IDs from the "Form IDs" dropdown menu.
6. Enter the output file name in the "Output File" field.

## Field-by-Field Explanation
* **Wellness Information** (`wellnesstitle`, text, required/optional: optional): Enter a brief title for the wellness information.
* **Category** (`category`, select_one, required/optional: optional): Select a category for the wellness information from the dropdown menu.
* **Description** (`description`, text, required/optional: optional): Enter a brief description of the wellness information.
* **Expanded Description** (`wellnessexpandedescription`, text, required/optional: optional): Provide an expanded description of the wellness information if desired.
* **Assigned Tool** (`assigned_tool`, select_one, required/optional: optional): Select the assigned tool from the dropdown menu.
* **Output File** (`output_file`, text, required/optional: optional): Enter the output file name.
* **Form ID** (`form_id`, text, required/optional: optional): Enter the form ID number.
* **Assigned Tool** (`assigned_tool`, select_one, required/optional: optional): Select the assigned tool from the dropdown menu.
* **Form IDs** (`form_ids`, select_multiple, required/optional: optional): Select multiple form IDs from the dropdown menu.
* **Output File** (`output_file`, text, required/optional: optional): Enter the output file name.

## Tips
* Make sure to fill in all required fields to ensure accurate and complete wellness information.
* Use the "Expanded Description" field for detailed and additional information about the wellness topic.
* If multiple form IDs are assigned, ensure that all relevant data is correctly linked to the corresponding ID.
* Be concise in the "Description" and "Expanded Description" fields to keep the form easy to read.
* The "Assigned Tool" field will be linked to the corresponding tool's ID and output file.
