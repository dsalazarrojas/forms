# Specialty Court Application Form - Help Guide
## Purpose
This form is used to track and manage specialty court applications.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the correct application status of the case. You can choose from the following options:
	* New: The application is new and has not been reviewed.
	* Pending: The application is in progress, but it has not been approved or denied.
	* Approved: The application is approved.
	* Denied: The application has been denied.
	* Rejected: The application has been rejected.
2. Select the correct veteran status of the applicant. You can choose from the following options:
	* Active: The applicant is an active veteran.
	* Inactive: The applicant is an inactive veteran.
3. Choose the type of court the application is related to. You can select from:
	* Drug Court
	* Mental Health Court
	* Veterans Court
4. Indicate whether the court location is correct. You can choose from:
	* Yes
	* No
5. Confirm whether the court has a program. You can choose from:
	* Yes
	* No
6. Confirm whether the application is for this type of program. You can choose from:
	* Yes
	* No
7. Select who submitted the application. You can choose from:
	* Yes
	* No
8. Choose the relationship of the person who submitted the application. You can select from:
	* Yes
	* No
9. Enter the court case number (if applicable).
10. Enter the case manager's name (if applicable).
11. Enter any additional notes about the application.

## Field-by-Field Explanation

* **Application Status** (`application_status`, select_one, required): Select the current status of the application.
* **Veteran Status** (`veteran_status`, select_one, required): Indicate whether the applicant is a veteran.
* **Court Type** (`court_type`, select_one, required): Choose the type of court the application is related to.
* **Court Location** (`court_location`, select_one, required): Indicate whether the court location is correct.
* **Program Type** (`program_type`, select_one, required): Confirm whether the court has a program.
* **Application Type** (`application_type`, select_one, required): Confirm whether the application is for this type of program.
* **Submitted By** (`submitted_by`, select_one, required): Select who submitted the application.
* **Submitted By Relationship** (`submitted_by_relationship`, select_one, required): Choose the relationship of the person who submitted the application.
* **Court Case Number** (`court_case_number`, text, optional): Enter the case number if applicable.
* **Case Manager Name** (`case_manager_name`, text, optional): Enter the name of the case manager if applicable.
* **Notes** (`notes`, text, optional): Enter any additional notes about the application.
* **Contact Info** (`contact_info`, text, optional): Enter any additional contact information.
* **Submitted At** (`submitted_at`, time, optional): Enter the date and time the application was submitted. 

## Tips

* Make sure to complete each field accurately to ensure that the application is correctly tracked and managed.
* If you are unsure about any information, please contact the court staff for clarification.
* This form should only be filled out by authorized personnel.
