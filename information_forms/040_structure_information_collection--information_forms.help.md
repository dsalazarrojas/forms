# Structure Information Collection - Help Guide
## Purpose
The "Structure Information Collection" form is used to collect detailed information about structures for inspections. This includes building name, facility type, structure type, address, and other relevant contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter the building name** (Building Name): This field is required. Please enter the name of the building being inspected.
2. **Select the facility type** (Facility Type): Choose the type of facility from the available options (Residential, Commercial, Industrial).
3. **Select the structure type(s)** (Structure Type): Choose one or more structure types from the available options (Office Building, Warehouse, Residential Building). This field is not required.
4. **Enter the structure address** (Structure Address): This field is not required but recommended for reference.
5. **Enter the manager name** (Manager Name): This field is required. Please enter the name of the manager responsible for the structure.
6. **Schedule an inspection date and time** (Inspection Date, Inspection Time): These fields are required. Please select a date and time for the inspection.
7. **Add any additional notes** (Notes): This field is not required but can be used for any additional information or notes about the structure.
8. **Enter contact email** (Email): This field is not required but recommended.
9. **Enter contact phone number** (Phone): This field is not required but recommended.
10. **Assign an inspector** (Assigned Inspector): This field is not required but recommended.
11. **Assign a team** (Assigned Team): This field is required. Please select the team responsible for the inspection from the available options (Facility Team, Property Managers, Inspectors).

## Field-by-Field Explanation
* **Building Name (Building Name)**: Enter the name of the building being inspected.
* **Facility Type (Facility Type)**: Choose the type of facility from the available options.
* **Structure Type (Structure Type)**: Choose one or more structure types from the available options.
* **Structure Address (Structure Address)**: Enter the address of the structure for reference.
* **Manager Name (Manager Name)**: Enter the name of the manager responsible for the structure.
* **Inspection Date (Inspection Date)**: Select a date for the inspection.
* **Inspection Time (Inspection Time)**: Select a time for the inspection.
* **Notes (Notes)**: Add any additional information or notes about the structure.
* **Email (Email)**: Enter the contact email for the structure.
* **Phone (Phone)**: Enter the contact phone number for the structure.
* **Assigned Inspector (Assigned Inspector)**: Enter the name of the inspector assigned to the structure.
* **Assigned Team (Assigned Team)**: Select the team responsible for the inspection from the available options.
