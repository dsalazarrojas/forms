# Cost Of Goods Sold Information Form - Help Guide
## Purpose
The Cost Of Goods Sold Information Form is used to capture key information related to the cost of goods sold (COGS) for a given period. This information is essential for accurate COGS calculations and reporting.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the COGS information in the **COGS Value** field (Field 2).
2.  Specify the **COGS Value in USD** in the corresponding field (Field 3).
3.  Select the **COGS Currency** (Field 4) in which the COGS value is in (Field 2).
4.  Enter the **Inventory Cost** (Field 5) for the given period.
5.  Specify the **Inventory Cost Currency** (Field 6) in which the inventory cost is in.
6.  Select the **Period Start Date** (Field 7) from which the COGS information is being reported.
7.  Select the **Period End Date** (Field 8) to which the COGS information is being reported.
8.  Choose the **Reporting Period** (Field 9) for which the COGS information is being reported (e.g., Q1, Q2, Q3, Q4).
9.  Select the team members responsible for the **Operations Team** (Field 10) who are involved in the COGS information.
10.  Select the team members responsible for the **Accountant** (Field 11) who are involved in the COGS information.
11.  Select the team members responsible for the **Bookkeeper** (Field 12) who are involved in the COGS information.
12.  Enter the **Operations Contact** (Field 13) email address.
13.  Enter the **Accountant Contact** (Field 14) email address.
14.  Enter the **Bookkeeper Contact** (Field 15) email address.

## Field-by-Field Explanation

* **COGS Information** (Field 1): This is a note field where users can enter any relevant information related to the COGS.
* **COGS Value** (Field 2): Enter the actual COGS value for the given period.
* **COGS Value in USD** (Field 3): This field is used to specify the COGS value in USD.
* **COGS Currency** (Field 4): Select the currency in which the COGS value is represented (e.g., USD, EUR, JPY, CNY).
* **Inventory Cost** (Field 5): Enter the inventory cost for the given period.
* **Inventory Cost Currency** (Field 6): Select the currency in which the inventory cost is represented (e.g., USD, EUR, JPY, CNY).
* **Period Start Date** (Field 7): Select the start date of the period from which the COGS information is being reported.
* **Period End Date** (Field 8): Select the end date of the period to which the COGS information is being reported.
* **Reporting Period** (Field 9): Choose the quarter in which the COGS information is being reported (e.g., Q1, Q2, Q3, Q4).
* **Operations Team** (Field 10): Select the team members responsible for the COGS information (e.g., Accounting, Bookkeeping, Operations, Management).
* **Accountant** (Field 11): Select the team members responsible for the COGS information (e.g., Accounting, Bookkeeping, Operations, Management).
* **Bookkeeper** (Field 12): Select the team members responsible for the COGS information (e.g., Accounting, Bookkeeping, Operations, Management).
* **Operations Contact** (Field 13): Enter the email address of the contact person from the operations team.
* **Accountant Contact** (Field 14): Enter the email address of the contact person from the accountant team.
* **Bookkeeper Contact** (Field 15): Enter the email address of the contact person from the bookkeeper team.

## Tips

* Make sure to fill in all the required fields to ensure accurate COGS calculations and reporting.
* Double-check the information provided to ensure its accuracy and consistency.
* If you are unsure about any field or information, please consult with the relevant team members or contact the operations, accountant, or bookkeeper contacts listed in the form.
