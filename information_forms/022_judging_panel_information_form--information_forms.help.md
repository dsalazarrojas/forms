# Judging Panel Information Form - Help Guide
## Purpose
The Judging Panel Information Form is used to collect information from event organizers to provide a clear and accurate representation of the events submitted for judging. This form helps us better understand the event details and make informed decisions. Please fill out this form carefully, and make sure to provide accurate and complete information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the event type from the options provided. This will help us understand the nature of the event.
2.  Enter the name of the event. This can be a simple text description of the event.
3.  Provide a brief description of the event, including any relevant details. This is an optional field, but it helps us understand the context of the event.

## Field-by-Field Explanation
### Event Type
*   **Event Type** (`event_type`, select_one, optional): Select one of the two options provided to indicate the type of event. For example, if the event is a competition, select "Yes", and if it's not, select "No".

### Event Name
*   **Event Name** (`event_name`, text, optional): Enter the name of the event, such as "Event Name".

### Event Details
*   **Event Details** (`event_details`, text, optional): Provide a brief description of the event, including any relevant details. This is an optional field, so you can skip it if you don't have much to add.

## Tips
*   Make sure to fill out the form completely and accurately to ensure we have a clear understanding of the event.
*   If you have any attachments or supporting documents, please attach them separately to your submission.
*   If you're unsure about anything, feel free to ask us for clarification. We're here to help!
