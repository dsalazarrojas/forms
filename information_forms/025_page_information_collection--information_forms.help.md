## page_information_collection - Help Guide

## Purpose
This form is used to collect metadata about a page. It is a general-purpose form for gathering relevant information about a page, including its title, description, keywords, image URL, URL, keywords list, form ID, status, page type, and category.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the title of the page in the **page_title** field.
2. Add a description of the page in the **page_description** field.
3. Select the keywords associated with the page from the **page_keywords** field.
4. Enter the URL of the page's image in the **page_image_url** field.
5. Enter the URL of the page in the **page_url** field.
6. Select the keywords list associated with the page from the **page_keywords_list** field.
7. Enter the ID of the form in the **form_id** field.
8. Select the status of the page from the **page_status** field.
9. Select the type of the page from the **page_type** field.
10. Select the category of the page from the **page_category** field.

## Field-by-Field Explanation

* **page_title** (text, required: false): Enter a descriptive title for the page.
* **page_description** (text, required: false): Add a brief description of the page.
* **page_keywords** (select_one, required: false): Choose whether the page has keywords.
* **page_image_url** (text, required: false): Enter the URL of the page's image.
* **page_url** (text, required: false): Enter the URL of the page.
* **page_keywords_list** (select_multiple, required: false): Select the keywords associated with the page (yes/no).
* **form_id** (number, required: false): Enter the ID of the form.
* **page_status** (select_one, required: false): Select the status of the page (active/inactive).
* **page_type** (select_one, required: false): Select the type of the page (website/landing-page/blog-post).
* **page_category** (select_multiple, required: false): Select the category of the page (yes/no).
