# liquidation_information_collection_form - Help Guide
## Purpose
This form is designed to collect information related to liquidation, which may include the liquidation of assets, inventory, or equipment. The form is likely used to gather details that support this process.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the liquidation details section, which includes the basic information about the liquidation.
2. Next, provide the reason for the liquidation, including details about the assets, inventory, or equipment being liquidated.
3. If you're liquidating assets or inventory, select the appropriate type of liquidation from the options provided.
4. If you have any supporting documents, you can upload them in the document upload field.
5. Finally, provide any additional reason for the document upload, if necessary.

## Field-by-Field Explanation
### Liquidation Details
* **Liquidation Details** (`liquidation_details`, text, optional): Fill in the basic information about the liquidation, such as the date and time it occurred.

### Reason for Liquidation
* **Reason for Liquidation** (`reason_for_liquidation`, text, optional): Explain the reason for the liquidation, including details about the assets, inventory, or equipment being liquidated.

### Liquidation Date
* **Liquidation Date** (`liquidation_date`, date, optional): Enter the date of the liquidation, if applicable.

### Reason for Liquidation Type
* **Reason for Liquidation Type** (`reason_for_liquidation_type`, text, optional): Provide additional details about the reason for the liquidation type selected.

### Liquidation Type
* **Liquidation Type** (`liquidation_type`, select_one, optional): Select the type of liquidation from the options provided, such as Liquidation of assets, Liquidation of inventory, or Liquidation of equipment.

### Document Upload
* **Document Upload** (`document_upload`, text, optional): Upload any supporting documents related to the liquidation, if necessary.

### Reason for Document Upload
* **Reason for Document Upload** (`reason_for_document_upload`, text, optional): Provide a reason for uploading the document, if necessary.
