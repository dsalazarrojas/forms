# update_your_profile_form - Help Guide
## Purpose
The update_your_profile_form is used by administrators to update the profile information of a user or client.

## How To Complete This Form
To complete this form, please follow the steps below:

1. **Update Your Profile Title** (`form_title`): A text field for entering a title for the profile information.
2. **Category** (`category`): Select the category that best fits your profile information.
   - Choose from: Online, Offline, or Other.
3. **Description** (`description`): A text field for entering a description of your profile information.
4. **Other Category** (`category_other`): If your category is not listed above, select "Other" and enter a specific category.
5. **Form Category** (`form_category`): Select the category of the form that this information will be part of.
   - Choose from: Information Forms, Other Forms.
6. **Assigned Tool** (`assigned_tool`): Select the tool that will be assigned to this form.
   - Choose from: chatjimmy, other.
7. **Form ID** (`form_id`): A text field for entering a unique ID for the form.
8. **Output File** (`output_file`): A text field for entering the output file of the form.
9. **Required Check** (`required_check`): Check if the information is required.
   - Choose from: True, False.
10. **Form IDs** (`form_ids`): A text field for entering multiple IDs for the form.
11. **Description** (`form_description`): A text field for entering a description for the form.
12. **Required** (`required`): Check if the information is required.
   - Choose from: True, False.
