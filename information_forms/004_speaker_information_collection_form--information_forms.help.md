# Speaker Information Collection Form - Help Guide
## Purpose
This form is designed to collect information about speakers for various events. Please use this form to input details about the speaker, including their name, email, phone number, address, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the speaker's name, email, phone number, and school name.
2. Select the event type from the options provided.
3. Input the event's title, start date, and start time.
4. Input any relevant information about the speaker's image and video URL.
5. Enter a brief description of the speaker.
6. Select the speaker's interests from the available options.

## Field-by-Field Explanation
* **Speaker Name** (`speaker_name`, `text`, optional): Enter the speaker's name.
* **Speaker Email** (`speaker_email`, `email`, optional): Enter the speaker's email address.
* **Speaker Phone** (`speaker_phone`, `text`, optional): Enter the speaker's phone number.
* **School Name** (`school_name`, `text`, optional): Enter the speaker's school or institution name.
* **Event Title** (`event_title`, `text`, optional): Enter the event's title.
* **Event Start Date** (`event_start_date`, `date`, optional): Enter the event's start date in the format `YYYY-MM-DD`.
* **Event Start Time** (`event_start_time`, `time`, optional): Enter the event's start time in the format `HH:MM`.
* **Event Type** (`event_type`, `select_one`, optional): Select the type of event from the options provided: Concert, Seminar, Conference, or Meeting.
* **Event Organizer** (`event_organizer`, `text`, optional): Enter the person or organization organizing the event.
* **Speaker Image URL** (`speaker_image_url`, `text`, optional): Enter a URL linking to the speaker's image.
* **Speaker Video URL** (`speaker_video_url`, `text`, optional): Enter a URL linking to the speaker's video.
* **Speaker Description** (`speaker_description`, `text`, optional): Enter a brief description of the speaker.
* **Speaker Interest** (`speaker_interest`, `select_multiple`, optional): Select the speaker's interests from the options provided: Dance, Music, Science, Art, or Sports.
