# living_room_property_management_property_information_form - Help Guide
## Purpose
This form is used to collect detailed information about properties in a living room management system.

## How To Complete This Form
1. Please select the **Property Type** from the dropdown menu, indicating if the property is a living room property or not. If you're unsure, please check the options available.
2. Enter the **Location** of the property in the text field.
3. Provide the **Address** of the property in the text field.
4. Select all **Cities** that apply to the property, if any.
5. Choose the **States** that are relevant to the property, if any.
6. Enter the **Zip Code** of the property.
7. Input the **Phone Number** of the property's contact.
8. Enter the **Email Address** of the property's contact.
9. Select the **Start Date** when the property's management started.
10. Select the **End Date** when the property's management ended.
11. Input the **Start Time** when the property's management started.
12. Input the **End Time** when the property's management ended.

## Field-by-Field Explanation

* **Property Type** (id: 1, type: select_one): Select the type of property to indicate if it's a living room property or not.
* **Location** (id: 2, type: text): Enter the location of the property.
* **Address** (id: 3, type: text): Enter the address of the property.
* **City** (id: 4, type: select_multiple): Select all cities that apply to the property.
* **State** (id: 5, type: select_multiple): Select all states that apply to the property.
* **Zip Code** (id: 6, type: text): Enter the zip code of the property.
* **Phone Number** (id: 7, type: text): Input the phone number of the property's contact.
* **Email Address** (id: 8, type: email): Enter the email address of the property's contact.
* **Start Date** (id: 9, type: date): Select the start date of the property's management.
* **End Date** (id: 10, type: date): Select the end date of the property's management.
* **Start Time** (id: 11, type: time): Input the start time of the property's management.
* **End Time** (id: 12, type: time): Input the end time of the property's management.

## Tips
* Ensure you provide accurate and complete information for each field.
* If you're unsure about a field, refer to the available options or contact the property owner.
* Double-check your submissions to avoid errors.
