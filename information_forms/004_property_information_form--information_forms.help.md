# Property Information Form - Help Guide
## Purpose
This form is meant to collect property-related information for reference or record-keeping purposes. Please fill out this form to provide accurate details about the property in question.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the property type to categorize the property.
2. Enter the property name.
3. Add the property address.
4. Specify the city.
5. Enter the postal code for the property.
6. Choose the relevant region.
7. Select the status of the property (e.g., active, inactive, etc.).
8. Enter the property's date (if applicable).
9. Enter the property's description.

## Field-by-Field Explanation

* **property_type** (Option 1, Option 2, Option 3): Select the type of property (e.g., house, apartment, etc.).
* **Property Name** (Property Name): Enter the exact name of the property.
* **Address** (Address): Type in the address of the property.
* **City** (City): Enter the city where the property is located.
* **Postal Code** (Postal Code): Enter the postal code of the property.
* **Region** (Option A, Option B, Option C): Choose the relevant region for the property.
* **Status** (Option 1, Option 2, Option 3, Option 4): Select the current status of the property (e.g., active, inactive, etc.).
* **Date** (Date): If applicable, select the date of the property's event or update.
* **Description** (Description): Add any additional details or description about the property.

## Tips
- Please ensure accuracy when filling out the form.
- Double-check for any missing or incorrect information.
- If you're unsure about a field, you can ask for clarification.
