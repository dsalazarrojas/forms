## Superannuation Member Details Update Form - Help Guide

## Purpose
This form is intended to collect and update member details for superannuation-related purposes. Please review the fields carefully and ensure you have the necessary information before proceeding.

## How To Complete This Form

To complete this form accurately and efficiently, please follow these steps:

1. Review the form purpose and ensure you have all the required information.
2. Fill in the relevant fields with the correct details, and select the correct options from the dropdown lists where applicable.

## Field-by-Field Explanation
### 1. **member_details**
* Label: member_details
* Type: text
* Required: false
* Explanation: Please enter the updated member details in this text field.

### 2. **category**
* Label: category
* Type: select_one
* Required: false
* Explanation: Select the relevant category for the superannuation member details. The options are:
	+ Information Forms
	+ Other Forms

### 3. **description**
* Label: description
* Type: text
* Required: false
* Explanation: Enter a brief description of the member details, if applicable.

### 4. **assigned_tool**
* Label: assigned_tool
* Type: select_one
* Required: false
* Explanation: Select the tool assigned to the member, if applicable. The options are:
	+ chatjimmy
	+ other tool

## Tips
* Please ensure you have reviewed the form purpose and the relevant fields carefully before proceeding.
* If you're unsure about any field, refer back to the form purpose and the field explanations above.
* If you need further assistance, do not hesitate to contact support.
