# esports_live_informing_form - Help Guide
## Purpose
This form is designed for users to input information about esports events and strategies, for internal tracking and reporting purposes.

## How To Complete This Form
1. Start by filling in the required fields, such as Event Name, Date, Time, Location, and Event Status.
2. If necessary, select the Live Status and add any Live Comments.
3. In the Event Details section, select the relevant Event Name, Date, and Time.
4. In the Strategy section, add any additional information about the strategy, such as Strategy Description.
5. If applicable, upload any attachments and select the relevant Event Status.
6. Finally, review the form for completeness and submit it.

* **Additional Info** (`id: 9`, `type: text`, required: false): Add any additional information about the event or strategy.
* **Attachments** (`id: 7`, `type: select_multiple`, required: false): Select any attachments related to the event or strategy.
