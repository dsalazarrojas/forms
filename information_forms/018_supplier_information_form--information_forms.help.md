# Supplier Information Form - Help Guide
## Purpose
The Supplier Information Form is used to collect and store information about suppliers. This includes their company name, contact details, supplier type, and status.

## How To Complete This Form
1. Enter the supplier's company name in the "Company Name" field.
2. Choose the supplier type from the "Supplier Type" select option.
3. Enter the supplier's email address in the "Email" field.
4. Enter the supplier's contact details in the "Supplier Contact" field.
5. Enter the supplier's address in the "Address" field.
6. Enter the supplier's phone number in the "Phone" field.
7. Enter a description of the supplier in the "Description" field.
8. Mark the supplier as active or inactive in the "Supplier Status" select option.
9. Optionally, add any additional notes about the supplier in the "Supplier Notes" field.

## Field-by-Field Explanation
* **Company Name**: Enter the supplier's company name.
* **Supplier Type**: Choose the type of supplier (Supplier, Service, or Other).
* **Email**: Enter the supplier's email address.
* **Supplier Contact**: Enter the supplier's contact details.
* **Address**: Enter the supplier's address.
* **Phone**: Enter the supplier's phone number.
* **Description**: Enter a description of the supplier.
* **Supplier Status**: Mark the supplier as active or inactive.
* **Supplier Notes**: Add any additional notes about the supplier.
* **Supplier ID**: This field is not currently used. You can leave it blank.
* **Supplier Code**: Enter the supplier's code.
* **Supplier Status**: This field is currently not used. You can leave it blank.
* **Created At**: This field displays the timestamp when the supplier was created. You cannot edit this field.
* **Created By**: This field displays the user who created the supplier. You cannot edit this field.
* **Updated At**: This field displays the timestamp when the supplier was last updated. You cannot edit this field.
* **Updated By**: This field displays the user who last updated the supplier. You cannot edit this field.
* **Deleted At**: This field displays the timestamp when the supplier was deleted. You cannot edit this field.
* **Deleted By**: This field displays the user who deleted the supplier. You cannot edit this field.
* **Archived At**: This field displays the timestamp when the supplier was archived. You cannot edit this field.
* **Archived By**: This field displays the user who archived the supplier. You cannot edit this field.
* **Updated By User**: This field displays the user who last updated the supplier. You cannot edit this field.
* **Updated By User ID**: This field is not currently used. You can leave it blank.
* **Updated By User Group**: This field is not currently used. You can leave it blank.
* **Updated By User Group ID**: This field is not currently used. You can leave it blank.

## Tips
* Make sure to fill in all required fields (Company Name, Supplier Type, Email, Supplier Contact, Address, Phone, and Supplier Status).
* You can add any additional notes in the "Supplier Notes" field.
* You cannot edit fields that display timestamps or user information (Created At, Created By, Updated At, Updated By, Deleted At, Deleted By, Archived At, Archived By, Updated By User, Updated By User ID, Updated By User Group, and Updated By User Group ID).
