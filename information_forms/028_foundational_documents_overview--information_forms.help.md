# Foundational Documents Overview - Help Guide
## Purpose
The "Foundational Documents Overview" form is used to collect and maintain information about the organization's foundational documents. This form is essential for tracking and managing these documents effectively.

## How To Complete This Form
1. Review the form purpose and ensure you have the necessary information to complete it.
2. Select the relevant document status from the available options (Active, Draft, Inactive).
3. If applicable, choose the dates for the review process (Review Dates).
4. Indicate the number of document copies (Document Copies).
5. Provide a brief description of the document (Document Description).
6. Select the author of the document (Document Author).
7. Enter the date the document was created (Document Date).
8. Select the type of document (Document Type).
9. If applicable, choose the reviewers of the document (Document Reviewer).

## Field-by-Field Explanation
* **Document Status** (`Document Status`, select_multiple, required/optional): Select the status of the document from the available options (Active, Draft, Inactive).
* **Review Dates** (`Review Dates`, date, required/optional): Enter the dates for the review process. If not applicable, leave this field blank.
* **Document Copies** (`Document Copies`, number, required/optional): Indicate the number of document copies, if applicable. Leave this field blank if not applicable.
* **Document Versions** (`Document Versions`, text, required/optional): Provide a brief description of the document, including any relevant versions.
* **Document Description** (`Document Description`, text, required/optional): Enter a concise description of the document, including its purpose and relevance.
* **Document Author** (`Document Author`, select_one, required/optional): Select the author of the document from the available options.
* **Document Date** (`Document Date`, date, required/optional): Enter the date the document was created.
* **Document Type** (`Document Type`, select_one, required/optional): Select the type of document from the available options.
* **Document Reviewer** (`Document Reviewer`, select_multiple, required/optional): If applicable, choose the reviewers of the document. If not applicable, leave this field blank.

## Tips
* Ensure that you have reviewed the relevant organizational policies and procedures related to foundational documents.
* Do not create duplicate records using this form.
* This form is designed to update or maintain existing foundational documents.
* If you are unsure about any field, consult with your supervisor or relevant department for clarification.
