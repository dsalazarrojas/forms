# game_animal_processing_guide - Help Guide
## Purpose
The game_animal_processing_guide form is used to collect information related to processing game animals in a food or meat processing context. This form is used to provide detailed data about the animal, including its type, weight, length, and processing specifics.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Animal Type** field to specify the type of game animal being processed.
2. Enter the **Harvested By** field with the name or organization responsible for harvesting the animal.
3. Input the **Game Weight** field with the weight of the animal.
4. Input the **Game Length** field with the length of the animal.
5. Select the **Processing Method** field to indicate the method used to process the animal (Machine, Hand, or Other).
6. Choose the **Game Condition** field to specify the state of the animal (Fresh, Smoked, Cured, or Jammed).
7. Enter the **Processing Date** field with the date the animal was processed.
8. Input the **Processing Time** field with the time the animal was processed.
9. Enter any **Additional Comments** about the animal's state or processing.
10. Enter your **Email** if you need to contact you for further information or questions.

## Field-by-Field Explanation
### 1. **Animal Type** (text, required: false)
* A field to specify the type of game animal being processed.

### 2. **Harvested By** (text, required: false)
* Enter the name or organization responsible for harvesting the animal.

### 3. **Game Weight** (number, required: false)
* Input the weight of the game animal.

### 4. **Game Length** (number, required: false)
* Input the length of the game animal.

### 5. **Processed By** (text, required: false)
* Enter the name or organization responsible for processing the animal.

### 6. **Processing Method** (select_one, required: false)
* Select the method used to process the animal (Machine, Hand, or Other).

### 7. **Game Condition** (select_multiple, required: false)
* Choose the state of the animal (Fresh, Smoked, Cured, or Jammed).

### 8. **Processing Date** (date, required: false)
* Enter the date the animal was processed.

### 9. **Processing Time** (time, required: false)
* Input the time the animal was processed.

### 10. **Additional Comments** (note, required: false)
* Enter any additional comments about the animal's state or processing.

### 11. **Email** (email, required: false)
* Enter your email if you need to be contacted for further information or questions.
