# Retail Data Governance Registration Form - Help Guide
## Purpose
The Retail Data Governance Registration Form is designed to gather information from users who want to access and work with retail data. This form ensures that all users understand how the data will be used, who has access to it, and what kind of access they have.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the User Registration section (Page 1) with your name and any other relevant information.
2. In the Purpose section (Page 2), briefly describe the project or task you want to access retail data for.
3. In the Project Details section (Page 3), select the options that apply to your project:
   * Yes for projects that require retail data access.
   * No for projects that do not require retail data access.
4. In the Data Access section (Page 4), select the level of access you need for your project:
   * Yes for full access to retail data.
   * No for limited access to retail data.
5. In the Project Start and End Dates section (Page 5), fill out the start and end dates for your project.
6. In the Data Classification section (Page 6), select the type of data you will be working with:
   * Yes for sensitive data.
   * No for non-sensitive data.
7. In the Project Status section (Page 7), select the status of your project:
   * Active for ongoing projects.
   * Inactive for completed projects.
8. In the Approval Details section (Page 8), provide any additional information about the approval procedures for your project.

## Field-by-Field Explanation

* **User Registration** (Page 1):
	+ **User Registration**: Enter your name and any other relevant information.
* **Purpose** (Page 2):
	+ **Purpose**: Describe the project or task you want to access retail data for.
* **Project Details** (Page 3):
	+ **Project Details**: Select **Yes** if your project requires retail data access.
* **Data Access** (Page 4):
	+ **Data Access**: Select **Yes** for full access to retail data or **No** for limited access.
* **Project Start Date** (Page 5):
	+ **Project Start Date**: Enter the start date for your project.
* **Project End Date** (Page 6):
	+ **Project End Date**: Enter the end date for your project.
* **Retail Data Access** (Page 7):
	+ **Retail Data Access**: Select **Yes** if you need access to retail data.
* **Data Classification** (Page 8):
	+ **Data Classification**: Select **Yes** for sensitive data.
* **Project Status** (Page 9):
	+ **Project Status**: Select **Active** for ongoing projects or **Inactive** for completed projects.
* **Approval Details** (Page 10):
	+ **Approval Details**: Provide any additional information about the approval procedures for your project.

## Tips

* Please fill out the form accurately and completely to ensure your project is properly registered.
* If you are unsure about any of the fields, consult with your supervisor or the data governance team.
* Review and understand the project details and data access before filling out the form.
* Remember to update your project status and approval details regularly to ensure accurate records.
