# Registration Update Form - Help Guide
## Purpose
This form is used to collect information about updates made to a user's record in the system.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the user's first name in the "First Name" field.
2. Enter the user's last name in the "Last Name" field.
3. Enter the user's email in the "Email" field.
4. Enter the user's phone number in the "Phone" field.
5. Enter the user's organization in the "Organization" field.
6. Enter the user's job title in the "Job Title" field.
7. Choose the "Updated Since" date from the calendar.
8. Enter any additional notes in the "Notes" field.
9. Select the "Update Reason" for the change.
10. Select the "Update Type" for the change.
11. Choose the "Update Status" for the change.
12. Enter the "Update By" field with the name of the person making the update.
13. Enter any additional update comments in the "Update Comments" field.
14. Select the update frequency for the change (if applicable).
15. Enter any additional information about the update frequency in the "Update Frequency Details" field (if applicable).
16. Confirm that the user has been informed of the update (if applicable).
17. Enter the user's confirmation details (if applicable).
18. Confirm that the organization has been informed of the update (if applicable).
19. Enter any additional organization confirmation details (if applicable).

## Field-by-Field Explanation
* **First Name** (`1`, `text`, `false`): Enter the user's first name.
* **Last Name** (`2`, `text`, `true`): Enter the user's last name.
* **Email** (`3`, `email`, `false`): Enter the user's email address.
* **Phone** (`4`, `text`, `false`): Enter the user's phone number.
* **Organization** (`5`, `text`, `false`): Enter the user's organization.
* **Department** (`6`, `text`, `false`): Enter the user's department (if applicable).
* **Job Title** (`7`, `text`, `false`): Enter the user's job title.
* **Updated Since** (`8`, `date`, `false`): Choose the date of the update.
* **Notes** (`9`, `note`, `false`): Enter any additional notes about the update.
* **Update Reason** (`10`, `select_one`, `true`): Select the reason for the update.
* **Update Type** (`11`, `select_multiple`, `true`): Select the type of update.
* **Update Status** (`14`, `select_one`, `true`): Choose the status of the update.
* **Update By** (`15`, `text`, `false`): Enter the name of the person making the update.
* **Update Comments** (`17`, `text`, `false`): Enter any additional comments about the update.
* **Update Frequency** (`18`, `select_multiple`, `false`): Select the update frequency.
* **Update Frequency Other** (`19`, `text`, `false`): Enter any additional information about the update frequency (if applicable).
* **Update Frequency Details** (`20`, `text`, `false`): Enter any additional details about the update frequency (if applicable).
* **User Confirmation** (`21`, `select_one`, `true`): Confirm that the user has been informed of the update.
* **User Confirmation Other** (`22`, `text`, `false`): Enter any additional user confirmation details (if applicable).
* **User Confirmation Details** (`23`, `text`, `false`): Enter any additional user confirmation details (if applicable).
* **Organization Confirmation** (`24`, `select_one`, `true`): Confirm that the organization has been informed of the update.
* **Organization Confirmation Other** (`25`, `text`, `false`): Enter any additional organization confirmation details (if applicable).

Note: Some fields may not be required depending on the selected options, but all fields are optional if not marked as required.
