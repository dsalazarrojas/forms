# House Buyers Need Analysis Form - Help Guide

## Purpose
This form is designed to help us understand your requirements and preferences when it comes to finding a home. It will ask you a series of questions about your needs and interests, and provide guidance on finding the right home for you.

## How To Complete This Form
To complete this form, simply answer the questions as honestly as possible, and be sure to select the options that best match your needs and preferences. If you have any questions or concerns, feel free to contact us for assistance.

## Field-by-Field Explanation

* **Form Id** (`form_id`, number, required: false): This is a unique identifier for the form, and will not affect your results. You can leave this field blank.
* **Category** (`category`, select_one, required: false): Please select 'Yes' if you are looking for a home in a specific category (e.g. single-family home, condo, etc.). If you are not sure, you can select 'No'.
* **Name** (`name`, text, required: false): Please enter your name as you would like it to appear in our records.
* **Email** (`email`, email, required: false): Please enter your email address so we can contact you with your results and recommendations.
* **Phone** (`phone`, text, required: false): Please enter your phone number so we can contact you with any further questions or requests.
* **Preferred Location** (`preferred_location`, select_multiple, required: false): Please select all locations that you are interested in (e.g. city, state, etc.).
* **Desired Location** (`desired_location`, select_one, required: false): Please select the desired location for your home (e.g. urban, rural, etc.).
* **Price Range** (`price_range`, select_multiple, required: false): Please select all price ranges that you are interested in (e.g. $100,000 - $500,000, etc.).
* **Desired Home Size** (`desired_size`, select_multiple, required: false): Please select all home sizes that you are interested in (e.g. 1-2 bedrooms, 3-4 bedrooms, etc.).
* **Preferred Home Type** (`preferred_home_type`, select_multiple, required: false): Please select all home types that you are interested in (e.g. single-family home, condo, etc.).
* **Preferred Number of Bedrooms** (`preferred_bedrooms`, select_multiple, required: false): Please select all numbers of bedrooms that you are interested in (e.g. 1-2, 3-4, etc.).
* **Preferred Number of Bathrooms** (`preferred_bathrooms`, select_multiple, required: false): Please select all numbers of bathrooms that you are interested in (e.g. 1-2, 3-4, etc.).
* **Preferred Bedroom Size** (`preferred_bedroom_size`, select_multiple, required: false): Please select all bedroom sizes that you are interested in (e.g. small, medium, large, etc.).
* **Preferred Floor Plan** (`preferred_floor_plan`, select_multiple, required: false): Please select all floor plans that you are interested in (e.g. ranch, two-story, etc.).
* **Preferred Outdoor Features** (`preferred_outdoor_features`, select_multiple, required: false): Please select all outdoor features that you are interested in (e.g. pool, yard, etc.).
* **Preferred Amenities** (`preferred_amenities`, select_multiple, required: false): Please select all amenities that you are interested in (e.g. gym, pool, etc.).
* **Preferred Neighborhood** (`preferred_neighborhood`, select_multiple, required: false): Please select all neighborhoods that you are interested in (e.g. downtown, suburban, etc.).
* **Preferred Commerce** (`preferred_commerce`, select_multiple, required: false): Please select all commercial areas that you are interested in (e.g. shopping center, etc.).
* **Preferred Community** (`preferred_community`, select_multiple, required: false): Please select all communities that you are interested in (e.g. family-friendly, etc.).
* **Preferred School District** (`preferred_school_district`, select_multiple, required: false): Please select all school districts that you are interested in (e.g. highly-rated, etc.).
* **Preferred Public Transit** (`preferred_public_transit`, select_multiple, required: false): Please select all public transit options that you are interested in (e.g. bus, train, etc.).
* **Preferred Age Range** (`preferred_age_range`, select_multiple, required: false): Please select all age ranges that you are interested in (e.g. 20-30, 40-50, etc.).
* **Preferred Income Range** (`preferred_income_range`, number, required: false): Please enter your preferred income range.
* **Preferred Lifestyle** (`preferred_lifestyle`, select_multiple, required: false): Please select all lifestyles that you are interested in (e.g. family-oriented, etc.).
* **Comments** (`comments`, note, required: false): Please add any additional comments or notes about your preferences.

## Tips
* Please answer all fields truthfully and accurately to ensure the best possible results.
* If you have any questions or concerns, feel free to contact us for assistance.
* This form will be used to provide general guidance and recommendations, not to make any binding agreements or commitments.
