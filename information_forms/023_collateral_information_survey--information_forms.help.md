# Collateral Information Survey - Help Guide
## Purpose
The Collateral Information Survey is a comprehensive form used to gather detailed information about a borrower's collateral. This information is essential for lenders to assess the value and condition of the collateral and make informed decisions regarding the loan process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields marked as "required" in the form.
2. Provide accurate and detailed information for each field.
3. Ensure that the information is consistent throughout the form.

## Field-by-Field Explanation

* **Borrower Name** (`Borrower Name`, text, required): Enter the name of the individual or business that owns the collateral.
* **Borrower Type** (`Borrower Type`, select_one, required): Select the type of entity that owns the collateral (e.g., Individual, Corporation, LLC, etc.).
* **Loan Officer Name** (`Loan Officer Name`, text, required): If applicable, enter the name of the loan officer assigned to this collateral.
* **Loan Number** (`Loan Number`, text, required): Enter the reference number for this loan.
* **Survey Date** (`Survey Date`, date, required): Enter the date and time when this form was completed.
* **Type of Collateral** (`Type of Collateral`, select_one, required): Select the primary type of collateral (e.g., Real Estate, Vehicle, Equipment, etc.).
* **Collateral Description** (`Collateral Description`, text, required): Provide a detailed description of the collateral.
* **Collateral Address** (`Collateral Address`, text, optional): If applicable, enter the location of the collateral.
* **Year Manufactured** (`Year Manufactured`, number, optional): If applicable, enter the year the collateral was manufactured.
* **Make** (`Make`, text, optional): If applicable, enter the name of the manufacturer of the collateral.
* **Model** (`Model`, text, optional): If applicable, enter the model number or name of the collateral.
* **Serial Number or VIN** (`Serial Number or VIN`, text, optional): If applicable, enter the identification number for the collateral.
* **Appraised Value** (`Appraised Value`, text, required): Enter the current appraised value of the collateral.
* **Appraisal Date** (`Appraisal Date`, date, required): Enter the date the collateral was appraised.
* **Appraiser Name** (`Appraiser Name`, text, optional): If applicable, enter the name of the appraiser who performed the appraisal.
* **Original Purchase Price** (`Original Purchase Price`, text, optional): If applicable, enter the original purchase price of the collateral.
* **Purchase Date** (`Purchase Date`, date, optional): If applicable, enter the date the collateral was purchased.
* **Ownership Status** (`Ownership Status`, select_one, required): Select the ownership status of the collateral (e.g., Owned Free and Clear, Partially Financed, etc.).
* **Existing Liens** (`Existing Liens`, select_one, required): Select whether there are existing liens on the collateral (e.g., True, False).
* **Lien Holder Name** (`Lien Holder Name`, text, optional): If applicable, enter the name of the lien holder.
* **Outstanding Lien Amount** (`Outstanding Lien Amount`, text, optional): If applicable, enter the amount of the lien.
* **Insurance Required** (`Insurance Required`, select_one, required): Select whether insurance is required on the collateral (e.g., True, False).
* **Insurance Provider** (`Insurance Provider`, text, optional): If applicable, enter the insurance company.
* **Insurance Policy Number** (`Insurance Policy Number`, text, optional): If applicable, enter the policy identifier.
* **Insurance Coverage Amount** (`Insurance Coverage Amount`, text, optional): If applicable, enter the coverage value of the insurance.
* **Insurance Expiry Date** (`Insurance Expiry Date`, date, optional): If applicable, enter the date the insurance expires.
* **Condition Rating** (`Condition Rating`, select_one, required): Select the current condition of the collateral (e.g., Excellent, Very Good, etc.).
* **Condition Notes** (`Condition Notes`, text, optional): If applicable, enter any notes about the condition of the collateral.
* **Marketability** (`Marketability`, select_one, required): Select how easy or difficult it is to sell the collateral (e.g., Highly Marketable, Not Marketable, etc.).
* **Depreciation Rate** (`Depreciation Rate`, select_one, required): Select the expected depreciation rate (e.g., Low, High, etc.).
* **Storage Location** (`Storage Location`, text, optional): If applicable, enter the location where the collateral is stored.
* **Access Restrictions** (`Access Restrictions`, text, optional): If applicable, enter any limitations on access to the collateral.
* **Additional Collateral** (`Additional Collateral`, text, optional): If applicable, list any other assets that are part of the collateral package.
* **Supporting Documents Attached** (`Supporting Documents Attached`, select_multiple, required): Select all supporting documents that apply (e.g., Title Document, Registration, etc.).
* **Borrower Certification** (`Borrower Certification`, select_one, required): Select to certify that the information provided is accurate (e.g., Yes I Certify, Other).
