# Bridesmaid Information Form - Help Guide
## Purpose
This form is designed to collect information from the bridesmaids attending the wedding. The bride will use this information to plan and coordinate the bridal shower, bachelorette party, and other wedding events.

## How To Complete This Form
To complete this form, simply fill out the required fields and select your options from the dropdown menus. Make sure to answer all required fields, as indicated by the asterisk (\*) symbol.

## Field-by-Field Explanation

* **Bridesmaid Name** (`Bridesmaid Name`, `text`, *): Enter your full name.
* **Email Address** (`Email Address`, `email`, *): Enter your contact email address.
* **Phone Number** (`Phone Number`, `text`, *): Enter your contact phone number.
* **Bride Name** (`Bride Name`, `text`, *): Enter the name of the bride.
* **Role in Bridal Party** (`Your Role in Bridal Party`, `select_one`, *): Select one of the following options:
	+ Maid of Honor
	+ Bridesmaid
	+ Junior Bridesmaid
	+ Matron of Honor
	+ Other
* **Relationship to Bride** (`Your Relationship to the Bride`, `select_one`, *): Select one of the following options:
	+ Best friend
	+ Close friend
	+ Sister
	+ Cousin
	+ College friend
	+ Coworker
	+ Other family
	+ Other
* **Dress Size** (`Dress Size`, `select_one`, *): Select one of the following options:
	+ XS
	+ S
	+ M
	+ L
	+ XL
	+ 1X
	+ 2X
	+ 3X+
* **Shoe Size** (`Shoe Size`, `text`, ): Enter your shoe size. (Optional)
* **Height** (`Height`, `text`, ): Enter your approximate height. (Optional)
* **Hair Color** (`Hair Color`, `select_one`, ): Select one of the following options:
	+ Blonde
	+ Brown
	+ Black
	+ Red
	+ Gray
	+ Other
* **Eye Color** (`Eye Color`, `select_one`, ): Select one of the following options:
	+ Blue
	+ Green
	+ Brown
	+ Hazel
	+ Other
* **Skin Tone** (`Skin Tone`, `select_one`, ): Select one of the following options:
	+ Fair
	+ Light
	+ Medium
	+ Olive
	+ Tan
	+ Deep
	+ Very deep
* **Dietary Restrictions** (`Dietary Restrictions`, `select_multiple`, ): Select any of the following options:
	+ Vegetarian
	+ Vegan
	+ Gluten-free
	+ Dairy-free
	+ Nut allergy
	+ Shellfish allergy
	+ Other allergy
	+ None
* **Detailed Dietary Needs** (`Detailed Dietary Needs`, `text`, ): Specify any dietary restrictions. (Optional)
* **Accessibility or Mobility Needs** (`Accessibility or Mobility Needs`, `text`, ): Describe any special accommodations you need. (Optional)
* **Jewelry Preference** (`Jewelry Preference`, `text`, ): Enter your preferred jewelry style. (Optional)
* **Makeup Preference** (`Makeup Preference`, `text`, ): Enter your preferred makeup style. (Optional)
* **Hair Style Preference** (`Hair Style Preference`, `text`, ): Enter your preferred hair style. (Optional)
* **Which Events Will You Attend?** (`Which Events Will You Attend?`, `select_multiple`, *): Select any of the following events:
	+ Bridal shower
	+ Bachelorette party
	+ Rehearsal dinner
	+ Wedding ceremony
	+ Reception
	+ All events
* **Ways You Can Help** (`Ways You Can Help`, `select_multiple`, ): Select any of the following options:
	+ Event planning
	+ Decorating
	+ Setup and breakdown
	+ Photography
	+ Running errands
	+ Speech or toast
	+ Emotional support
	+ Other
* **Transportation Needs** (`Transportation Needs`, `select_one`, ): Select one of the following options:
	+ No, I have transportation
	+ Yes, need ride
	+ Yes, can provide ride
	+ Maybe, will confirm later
* **Budget Concerns** (`Budget Concerns`, `text`, ): Enter any financial constraints you have. (Optional)
* **Questions or Concerns** (`Questions or Concerns`, `text`, ): Enter anything you'd like to discuss. (Optional)
