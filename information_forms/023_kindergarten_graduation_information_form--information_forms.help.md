# Kindergarten Graduation Information Form - Help Guide
## Purpose
This form is used to capture information about kindergarten students who are graduating. It will help administrators to track and record the details of students, including their name, contact information, academic achievements, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form carefully and answer all the questions.
2. Fill in the blanks with accurate and up-to-date information about the student.
3. Make sure to provide all required information, as indicated by the `*` symbol.
4. You can use the "Note" field to add any additional comments or information about the student.

## Field-by-Field Explanation
### 1. Information
* This field is an optional introduction to the form, intended to provide any additional context or comments.
* Use this field to briefly describe the purpose and scope of the form.

### 2. Student Name
* This is the student's full name, as it appears on their records.
* Make sure to spell it correctly and use the correct formatting (e.g., Mr., Mrs., Ms., etc.).

### 3. Student Id
* This is the student's ID number, assigned by their school or institution.
* If you don't know the ID, you can leave it blank.

### 4. Date of Birth
* This is the student's date of birth.
* Use the format `MM/DD/YYYY` (e.g., 01/01/2001).

### 5. Grade Completed
* Choose the grade that the student has completed (e.g., First Grade, Second Grade, etc.).
* Make sure to select the correct grade from the options.

### 6. Start Date
* This is the date when the student started at their current school.
* Use the format `MM/DD/YYYY` (e.g., 09/01/2018).

### 7. End Date
* This is the date when the student graduated from kindergarten.
* Use the format `MM/DD/YYYY` (e.g., 06/01/2022).

### 8. Student School
* This is the name of the school where the student attended kindergarten.
* Choose the correct school from the options.

### 9. Teacher Name
* This is the name of the student's teacher or contact person.
* Make sure to spell it correctly.

### 10. Email
* This is the student's email address.
* Use a valid email format (e.g., `john.doe@example.com`).

### 11. Phone
* This is the student's phone number.
* Use a valid phone number format (e.g., `123-456-7890`).

### 12. Address
* This is the student's address.
* Use a valid address format (e.g., `123 Main Street, Anytown, USA 12345`).

### 13. Note
* This is an optional field for adding any additional comments or information about the student.
* You can use it to provide any relevant context or details.

### 14. Status
* This field is intended to track the student's status.
* Use it to indicate the student's current status (e.g., active, inactive, etc.).

### 15. Graduation Date
* This is the date when the student graduated from kindergarten.
* Use the format `MM/DD/YYYY` (e.g., 06/01/2022).

### 16. Student School
