# Respect Message Submission Form - Help Guide
## Purpose
The Respect Message Submission Form is used for staff to submit information about a message or a piece of work that they have submitted for approval.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Respect Message Submission Form" link or button to open the form.
2. Fill in the required fields:
   * Select your organization (Option 1, Option 2, or Option 3).
   * Choose how you would like to be recognized (Option 4, Option 5, or Option 6).
   * Enter your time zone (PST, MST, or EST).
3. Optionally, fill in the non-required fields:
   * Enter your name and message in the text boxes.
   * Enter your email and phone number (if you wish to be contacted).
   * Select the date and time you submitted the message (note: this field is optional).

## Field-by-Field Explanation
### Organization (<name>) 
* Type: Select multiple options
* Description: Select one or more of the provided options to represent the organization you work for or are associated with.

### Name 
* Type: Text
* Description: Enter your name as you would like to be recognized.

### Message 
* Type: Text
* Description: Enter a brief description or message about the work you have submitted.

### How would you like to be recognized? 
* Type: Select one option
* Description: Choose how you would like to be recognized for your work. This may include as an individual, as a team, or as an organization.

### Email 
* Type: Email
* Description: Enter your email address if you wish to be contacted about your submission.

### Phone 
* Type: Text
* Description: Enter your phone number if you wish to be contacted about your submission.

### Date Submitted 
* Type: Date
* Description: Optional: enter the date you submitted the work or message being submitted.

### Time Submitted 
* Type: Time
* Description: Optional: enter the time you submitted the work or message being submitted.

### Time Zone 
* Type: Select one option
* Description: Select your time zone to ensure accurate time submission.

### Time Zone Offset 
* Type: Text
* Description: This field is optional and not currently used.

### IP Address 
* Type: Text
* Description: Optional: enter your IP address if you wish to provide this information.

Note: The fields "Time Zone Offset" and "IP Address" are optional and not currently being used.
