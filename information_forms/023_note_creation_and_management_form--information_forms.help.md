# Note Creation And Management Form - Help Guide
## Purpose
This form is used to create and manage notes for different purposes such as Meeting Records, Project Updates, and Follow-ups.

## How To Complete This Form
To complete this form, please follow these steps:

1. Click on the "Note Creation" section and enter your note title and description in the "Note" field.
2. Select the relevant category for your note from the "Categories" dropdown.
3. Choose who to share the note with by selecting team members or managers from the "Share Note With" dropdown.
4. Set a reminder date for follow-up if required.
5. Select the project update type from the "Project Updates" dropdown.
6. Update the status of your note by selecting "In Progress" or "Complete" from the "Update Status" dropdown.
7. Update the follow-up status by selecting "New" or "Completed" from the "Follow-up Status" dropdown.
8. Optionally, select a date for follow-up if required.
9. Click "Submit" to save your note.

## Field-by-Field Explanation

* **Note Creation** (Note Creation And Management Form Step 1):
	+ A text field where you can enter a brief title for your note.
* **Capture** (Capture):
	+ A text field where you can enter a brief description of your note.
* **Categories** (Categories):
	+ A dropdown menu where you can select the relevant category for your note (e.g., Meeting Records, Project Updates, Follow-ups).
* **Share Note With** (Share Note With):
	+ A dropdown menu where you can select team members or managers to share the note with.
* **Reminders** (Reminders):
	+ A date field where you can select a date for follow-up.
* **Note** (Note):
	+ A text field where you can enter the main content of your note.
* **Follow-up Date** (Follow-up Date):
	+ A time field where you can select a date for follow-up.
* **Project Updates** (Project Updates):
	+ A dropdown menu where you can select the type of project update (e.g., Meeting Minutes, Meeting Notes, Project Status).
* **Update Status** (Update Status):
	+ A dropdown menu where you can update the status of your note to "In Progress" or "Complete".
* **Follow-up Status** (Follow-up Status):
	+ A dropdown menu where you can update the follow-up status to "New" or "Completed".
* **Share With User** (Share With User):
	+ A dropdown menu where you can select whether to share the note with a specific user or not.
* **Update Note** (Update Note):
	+ A text field where you can enter an update to the original note.
