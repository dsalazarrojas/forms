# Time Period Information Form - Help Guide
## Purpose
This form is used to gather information about a specific time period. The purpose of this form is to provide a clear and concise description of a time period, including its start and end dates, a brief description, and any additional historical context.

## How To Complete This Form
1. Start by filling in the start and end year fields, which are required fields that must be populated.
2. Enter the start month and day as a numerical value or a month name.
3. Enter the end month and day as a numerical value or a month name.
4. Provide a brief description of the time period in the brief description field.
5. Select the historical record type from the dropdown options, or type "Other" and provide a description in the historical record type other field.
6. If "Other" is selected, provide a description of the other historical record type in the historical record other description field.
7. Optionally, provide additional notes on the time period in the time period notes field.

## Field-by-Field Explanation
* **start_year**: Enter the year that marks the start of the time period. (Number)
* **end_year**: Enter the year that marks the end of the time period. (Number)
* **start_month**: Enter the month (as a numerical value or month name) that marks the start of the time period. (Text)
* **start_day**: Enter the day of the month that marks the start of the time period. (Text)
* **end_month**: Enter the month (as a numerical value or month name) that marks the end of the time period. (Text)
* **end_day**: Enter the day of the month that marks the end of the time period. (Text)
* **brief_description**: Provide a brief description of the time period. (Text)
* **historical_record_type**: Select the type of historical record that this time period belongs to. (Select One)
	+ Select one of the provided options or type "Other" to provide a custom option.
* **historical_record_type_other**: If "Other" is selected, enter a description of the other historical record type. (Text)
* **historical_record_other_description**: Enter a description of the other historical record type. (Text)
* **time_period**: Enter a description of the time period. (Text)
* **time_period_notes**: Provide any additional notes on the time period. (Note)

## Tips
* Be as specific as possible when entering the start and end dates to ensure accurate representation of the time period.
* Use clear and concise language when entering the brief description and any additional notes.
* If selecting "Other" from the historical record type dropdown, provide a clear and concise description of the other historical record type.
