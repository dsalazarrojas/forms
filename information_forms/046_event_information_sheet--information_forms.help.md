# Event Information Sheet - Help Guide
## Purpose
This form is used to collect event information for internal or external use.

## How To Complete This Form

1. Fill out the form with the necessary details about the event you are creating or participating in.
2. Ensure that you have all the necessary information before proceeding.
3. Review your input carefully to ensure accuracy.

## Field-by-Field Explanation
### **Event Name** (event_name, text, required: false)
The name of the event.

*   This field is where you provide the name of the event.

### **Event Date** (event_date, date, required: false)
The date of the event.

*   This field is for the date of the event you are creating or participating in.

### **Event Time** (event_time, time, required: false)
The time of the event.

*   Enter the time of the event.

### **Event Location** (event_location, text, required: false)
The location of the event.

*   Provide the location where the event will take place.

### **Event Description** (event_description, text, required: false)
A brief description of the event.

*   Write a short description of the event.

### **Contact** (event_contact, text, required: false)
Contact information for the event organizer or participant.

*   Provide the contact information, such as email or phone number.

### **Email** (event_email, email, required: false)
The email of the event organizer or participant.

*   Enter the email of the event organizer or participant.

### **Tags** (event_tags, select_multiple, required: false)
Tags related to the event.

*   Choose relevant tags for the event.

### **File** (event_file, text, required: false)
An optional file to attach to the event.

*   If applicable, attach a file related to the event.

### **Status** (event_status, select_one, required: false)
The status of the event.

*   Choose the status of the event (Active or Inactive).

### **Category** (event_category, select_one, required: false)
The category of the event.

*   Choose a category for the event (Yes or No).

### **Organizer** (event_organizer, text, required: false)
The name of the event organizer.

*   Provide the name of the event organizer.

### **Start Date** (event_start_date, date, required: false)
The start date of the event.

*   Enter the start date of the event.

### **Start Time** (event_start_time, time, required: false)
The start time of the event.

*   Enter the start time of the event.

### **End Date** (event_end_date, date, required: false)
The end date of the event.

*   Enter the end date of the event.

### **End Time** (event_end_time, time, required: false)
The end time of the event.

*   Enter the end time of the event.

### **Date and Time** (event_datetime, text, required: false)
An alternative way to enter start and end dates and times.

*   If you prefer, enter the date and time in a single field.

### **Duration** (event_duration, number, required: false)
The duration of the event.

*   Enter the duration of the event in a numerical format (e.g., 1 hour).

### **Duration Units** (event_duration_units, select_one, required: false)
The unit of time for the duration.

*   Choose the unit for the duration (e.g., hours, minutes).

### **Location Alternative** (event_location_alt, text, required: false)
An alternative location where the event may be held.

*   Enter an alternative location where the event may take place.

### **Website** (event_website, text, required: false)
The website of the event.

*   Provide the website of the event.

### **Social** (event_social, text, required: false)
Social information for the event.

*   Enter social information, such as Twitter or Facebook handles.

### **Address** (event_address, text, required: false)
The address of the event location.

*   Enter the address of the event location.

### **City** (event_city, text, required: false)
The city where the event takes place.

*   Enter the city of the event.

### **State** (event_state, select_one, required: false)
The state where the event takes place.

*   Choose the state where the event will be held (e.g., Yes or No).

## Tips
*   Ensure that you have all the necessary information before filling out the form.
*   Review your input carefully to ensure accuracy.
*   If you encounter any issues while filling out the form, contact the event organizer or support team.
