# Tips And Advice Sharing Form - Help Guide
## Purpose
The purpose of this form is to collect tips and advice from users, which will be shared with others to provide guidance and recommendations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title for the tip or advice you want to share.
2. Provide a detailed description of the tip or advice.
3. Select a category that best describes the type of content you are submitting (e.g. Information Forms, Forms, etc.).
4. Add any relevant tags to help others quickly find the content.
5. If relevant, select an assigned tool that is related to the tip or advice.
6. Enter a unique Form ID (only required for internal tracking purposes).
7. (Optional) Select a form category that best fits the submission.

## Field-by-Field Explanation
- **Form Title** (`form_title`, text, optional): Enter a brief title for the tip or advice you want to share.
- **Tips And Advice** (`tips_and_advice`, text, optional): Provide a detailed description of the tip or advice.
- **Category** (`category`, select_multiple, optional): Select a category that best describes the type of content you are submitting (e.g. Information Forms, Forms, etc.).
- **Description** (`description`, text, optional): Add any additional details about the tip or advice.
- **Form Category** (`form_category`, select_one, optional): Select a form category that best fits the submission (if applicable).
- **Form Tags** (`form_tags`, text, optional): Add any relevant tags to help others quickly find the content.
- **Assigned Tool** (`assigned_tool`, text, optional): If relevant, select an assigned tool that is related to the tip or advice.
- **Form ID** (`form_id`, number, optional): Enter a unique Form ID (only required for internal tracking purposes).
- **Created At** (`created_at`, date, optional): This field will be automatically populated with the date and time of submission.
- **Updated At** (`updated_at`, date, optional): This field will be automatically populated with the date and time of last update.
