# Country Search And Filter - Help Guide
## Purpose
The Country Search And Filter form is used to find countries that match specific criteria such as name, language, currency, region, and other relevant factors.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the "Search By Name" option to search for a country by its name.
2. You can also select multiple countries from the "Select Country" option to filter by country name.
3. If you want to filter by other criteria, select the corresponding option from the "Select" options.
4. Make sure to fill in all required fields marked as required.
5. Click the "Submit" button to get the search results.

## Field-by-Field Explanation

* **Search By Name** (1, text, required): Enter the name of the country you are looking for.
* **Select Country** (2, select_multiple, required): Choose multiple countries from the list to filter by country name.
* **Search By Flag** (3, select_one, optional): Select 'Yes' to search by flag status.
* **Select Language** (4, select_multiple, optional): Choose languages to filter by language spoken.
* **Search By Region** (5, select_one, optional): Select 'Yes' to search by region.
* **Search By Size** (6, select_one, optional): Select 'Yes' to search by size.
* **Search By Currency** (7, select_one, optional): Select 'Yes' to search by currency.
* **Search By Economic** (8, select_one, optional): Select 'Yes' to search by economic status.
* **Search By Government** (9, select_one, optional): Select 'Yes' to search by government type.
* **Search By Population** (10, select_one, optional): Select 'Yes' to search by population.
* **Search By Capital** (11, select_one, optional): Select 'Yes' to search by capital.
* **Select Currency** (12, select_multiple, optional): Choose currencies to filter by currency.
