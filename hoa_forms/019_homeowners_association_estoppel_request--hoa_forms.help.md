# Homeowners Association Estoppel Request - Help Guide

## Purpose
This form is for homeowners or individuals to submit an estoppel request to a homeowners association (HOA). The estoppel request is a formal declaration that the HOA has not received a certain notice or payment. Please ensure that the submitted information is accurate and complete to facilitate the verification process.

## How To Complete This Form
1. Fill in the required fields with the correct information.
2. Select the correct option for the "Signature Authorizing" field.
3. Choose one or multiple delivery preferences for the "Delivery Preference" field.
4. Confirm the signature and date of the submission.

## Field-by-Field Explanation

* **Home Address** (`home_address`): Enter the address of the property you are submitting the estoppel request for.
* **Home Address 2** (`home_address_2`): Enter the address to which the estoppel request should be mailed or delivered (if different from the property address).
* **Name On Estoppel** (`name_on_estoppel`): Enter your full name as it appears on the estoppel request.
* **Name And Address** (`name_and_address`): Enter your full name and address for delivery purposes.
* **Signature Authorizing** (`signature_authorizing`): Select who is authorizing the estoppel request:
	+ **Homeowner**: The property owner is authorizing the request.
	+ **Buyer**: The buyer is authorizing the request.
	+ **Property Manager**: The property manager is authorizing the request.
* **Delivery Preference** (`delivery_preference`): Choose one or more delivery options for the estoppel request:
	+ **Email**: Receive the estoppel request via email.
	+ **Text Message**: Receive the estoppel request via text message.
	+ **Mail**: Receive the estoppel request via postal mail.
* **Signed By** (`signed_by`): Select who signed the estoppel request:
	+ **Homeowner**: The homeowner signed the request.
	+ **Buyer**: The buyer signed the request.
	+ **Property Manager**: The property manager signed the request.
* **Signed Date** (`signed_date`): Enter the date the estoppel request was signed.
* **Signed Time** (`signed_time`): Enter the time the estoppel request was signed.

## Tips
- Ensure that all fields are accurately filled in to avoid delays in processing the estoppel request.
- Double-check the information before submitting the form.
- If you need to submit multiple estoppel requests, create a new form for each request.
