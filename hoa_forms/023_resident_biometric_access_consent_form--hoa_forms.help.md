# resident_biometric_access_consent_form - Help Guide
## Purpose
This form collects biometric access consent from residents. Users can choose which biometric access type (Face ID, Iris Scanner, Fingerprint Reader, Retina Scanner) they consent to use and submit their signature and date of signature.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each field description carefully to understand what information is being requested.
2. Select the biometric access type you consent to use (Face ID, Iris Scanner, Fingerprint Reader, Retina Scanner) from the options provided.
3. If you consent to multiple biometric access types, select all relevant options.
4. Indicate your consent by selecting either 'True' or 'False' from the "consent" field.
5. Leave a note to provide any additional information or comments as needed.
6. Enter the date of signature.
7. Click "submit" to submit the form.

## Field-by-Field Explanation
* **resident_biometric_access_form** (`resident_biometric_access_form`, text, optional): This field asks for a brief description or reference related to biometric access for the resident.
* **resident_details** (`resident_details`, text, optional): This field is for any additional information about the resident that is relevant to biometric access.
* **access_type** (`access_type`, select_one, optional): Choose which biometric access type you consent to use (Face ID, Iris Scanner, Fingerprint Reader, Retina Scanner).
* **biometric_access_type** (`biometric_access_type`, select_multiple, optional): Choose multiple biometric access types you consent to use.
* **consent** (`consent`, select_one, optional): Check 'True' if you give consent or 'False' if you do not consent.
* **signature** (`signature`, note, optional): Provide any additional information or comments related to biometric access.
* **signature_date** (`signature_date`, date, optional): Enter the date of your signature.
* **submit** (`submit`, text, optional): Click this field to submit the form.

## Tips
- Make sure to review each field carefully before submitting.
- Be sure to select the correct biometric access types you consent to use.
- Enter your signature and date of signature accurately.
- Use this form to ensure biometric access is done securely and safely.
