# Currency Exchange Limit Increase Request - Help Guide
## Purpose
The "Currency Exchange Limit Increase Request" form is used to request an increase in the current currency exchange limit for a client. This form is used to provide additional information required for the review process.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's details on the first page.
2. Select the currencies you wish to increase the limit for on the second page.
3. Enter the new limit for the selected currencies.
4. Provide a clear and concise reason for the limit increase request.
5. Review the current limit and new limit for accuracy.
6. Select the review status of the request (Pending, Approved, Rejected).
7. Add any additional notes about the request.
8. Enter your name and submit the form.

## Field-by-Field Explanation
- **Client Details**: Enter the client's name, ID, or any other relevant information to help us identify the client.
  - Type: Text
  - Required: Required

- **Currency Details**:
  - Select the currencies you wish to increase the limit for.
  - Type: Select multiple options
  - Required: Optional

- **Amount**: Enter the new limit for the selected currencies.
  - Type: Number
  - Required: Optional

- **Reason**: Provide a clear and concise reason for the limit increase request.
  - Type: Text
  - Required: Optional

- **Current Limit**: Review and verify the current limit for accuracy.
  - Type: Number
  - Required: Optional

- **New Limit**: Enter the new limit for the selected currencies.
  - Type: Number
  - Required: Optional

- **Review Status**: Select the review status of the request (Pending, Approved, Rejected).
  - Type: Select one option
  - Required: Optional

- **Notes**: Add any additional notes about the request.
  - Type: Text area
  - Required: Optional

- **Submitter**: Enter your name and title for the recordkeeping.
  - Type: Text
  - Required: Required

- **Submitted Date**: This field will automatically populated when the form is submitted.
  - Type: Date
  - Required: Not editable

## Tips
- Make sure to fill out all required fields before submitting the form.
- Review your selections carefully before submitting the form.
- Ensure that the new limit is accurate and reasonable.
- Enter clear and concise reasons for the limit increase request.
- Use this form only if the client's current limit is below the desired limit or needs to be reviewed.
