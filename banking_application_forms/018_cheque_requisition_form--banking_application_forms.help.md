# Cheque Requisition Form - Help Guide
## Purpose
The Cheque Requisition Form is a tool for employees to request a cheque for payment or reimbursement.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the requested information.
2. Make sure to enter accurate and complete details for the payee and payment information.
3. Select the correct cheque delivery method for your situation.
4. Enter the name of your approving manager.
5. Review the form for any special instructions or notes.

## Field-by-Field Explanation
- **Requisition number**: This is a auto-generated or user-entered number for identification purposes. You can leave it blank if it's auto-generated.
  * Type: text
  * Required: false
  * Hint: Auto-generated or leave blank
- **Date of requisition**: The date when the form is filled out.
  * Type: date
  * Required: true
  * Hint: null
- **Name of requester**: The name of the person making the requisition.
  * Type: text
  * Required: true
  * Hint: null
- **Department**: The department of the person making the requisition.
  * Type: text
  * Required: true
  * Hint: null
- **Employee ID**: The ID of the person making the requisition (if applicable).
  * Type: text
  * Required: false
  * Hint: null
- **Contact phone number**: The phone number of the person making the requisition.
  * Type: text
  * Required: true
  * Hint: null
- **Email address**: The email address of the person making the requisition.
  * Type: email
  * Required: true
  * Hint: null
- **Payee name**: The name to appear on the cheque.
  * Type: text
  * Required: true
  * Hint: Name to appear on the cheque
- **Payee mailing address**: The address of the payee.
  * Type: text
  * Required: true
  * Hint: null
- **City**: The city of the payee.
  * Type: text
  * Required: true
  * Hint: null
- **State or province**: The state or province of the payee.
  * Type: text
  * Required: true
  * Hint: null
- **Postal code**: The postal code of the payee.
  * Type: text
  * Required: true
  * Hint: null
- **Country**: The country of the payee.
  * Type: text
  * Required: false
  * Hint: null
- **Cheque amount**: The amount of the cheque.
  * Type: number
  * Required: true
  * Hint: null
- **Amount in words**: The amount of the cheque in words.
  * Type: text
  * Required: true
  * Hint: null
- **Purpose of payment**: The purpose of the payment.
  * Type: select_one
  * Required: true
  * Hint: null
- **Detailed description of payment**: A brief description of the payment.
  * Type: text
  * Required: true
  * Hint: null
- **Invoice or reference number**: The invoice or reference number (if applicable).
  * Type: text
  * Required: false
  * Hint: null
- **Cost center or project code**: The cost center or project code (if applicable).
  * Type: text
  * Required: false
  * Hint: null
- **Account coding**: The account coding (if applicable).
  * Type: text
  * Required: false
  * Hint: null
- **Cheque delivery method**: The method of delivering the cheque.
  * Type: select_one
  * Required: true
  * Hint: null
- **Approving manager name**: The name of the manager approving the requisition.
  * Type: text
  * Required: true
  * Hint: null
- **Special instructions or notes**: Any special instructions or notes.
  * Type: text
  * Required: false
  * Hint: null
