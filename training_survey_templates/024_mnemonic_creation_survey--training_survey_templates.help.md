# MnemonicCreationSurvey - Help Guide
## Purpose
This survey is designed to gather feedback on memory aids that help learners in different learning scenarios.

## How To Complete This Form
1. Fill out the form title to provide a brief description of the memory aid you are referring to.
2. Select the category of the learner that the memory aid is intended for (e.g., student, teacher, staff).
3. Choose the type of memory aid you found useful (at least one is required).
4. Describe the characteristics of the memory aid that made it useful to you.
5. Provide an example of a memory aid you have used.
6. Rate how useful the memory aid was to you on a scale from 1 to 5.
7. Indicate how often you used the memory aid (e.g., often, occasionally, rarely).
8. For multiple usage frequency questions, select all that apply.
9. Rate the memory aid's usefulness on a scale from 1 to 5.
10. Estimate the time it took to create the memory aid.
11. Indicate how often you have used the memory aid (e.g., often, occasionally, rarely), up to 4 times.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, optional): Enter a brief description of the memory aid you are referring to.
* **Learner Category** (`learner_category`, select_one, optional): Select the category of learner that the memory aid is intended for (e.g., student, teacher, staff).
* **Memory Aid Type** (`memory_aid_type`, select_multiple, required): Choose the type of memory aid you found useful (at least one is required).
* **Memory Aid Characteristics** (`memory_aid_characteristics`, select_multiple, optional): Describe the characteristics of the memory aid that made it useful to you.
* **Memory Aid Example** (`memory_aid_example`, text, optional): Provide an example of a memory aid you have used.
* **Memory Aid Characteristics Example** (`memory_aid_characteristics_example`, text, optional): Not applicable.
* **How Useful was the Memory Aid?** (`memory_aid_usefulness`, number, optional): Rate how useful the memory aid was to you on a scale from 1 to 5.
* **Rate the Aid's Memory Aid Usefulness** (`mnemonic_aid_usefulness_rating`, number, optional): Rate the aid's memory aid usefulness on a scale from 1 to 5.
* **Memory Aid Creation Time** (`memory_aid_creation_time`, time, optional): Estimate the time it took to create the memory aid.
* **Memory Aid Usage Frequency** (`memory_aid_usage_frequency`, select_multiple, optional): Indicate how often you used the memory aid (e.g., often, occasionally, rarely).
* **Memory Aid Usage Frequency 2** (`memory_aid_usage_frequency_2`, select_multiple, optional): Select all that apply for how often you used the memory aid.
* **Memory Aid Usage Frequency 3** (`memory_aid_usage_frequency_3`, select_multiple, optional): Select all that apply for how often you used the memory aid.
* **Memory Aid Usage Frequency 4** (`memory_aid_usage_frequency_4`, select_multiple, optional): Select all that apply for how often you used the memory aid.
