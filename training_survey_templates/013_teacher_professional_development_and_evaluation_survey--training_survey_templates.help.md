# Teacher Professional Development And Evaluation Survey - Help Guide
## Purpose
This form is used to gather information from teachers about their experiences with training survey templates, including whether they are used for training and evaluation, the tool assigned to them, and other relevant details.

## How To Complete This Form
1. Select one or more of the options for "What are the training survey templates used for?".
2. Enter the form ID if it is provided to you.
3. Write a brief description of the teacher professional development and evaluation survey in the designated space.
4. Select the tool assigned to you from the provided options.
5. Select the category the tool belongs to from the provided options.
6. Enter the desired output file format.
7. If applicable, provide a description and select the tool assigned to you from the provided options.
8. Select the category the tool belongs to from the provided options.
9. Enter the desired output file format again.
10. If applicable, provide a description of the teacher professional development and evaluation survey.

## Field-by-Field Explanation
- **What are the training survey templates used for?** (Yes, for training and evaluation, No, only for evaluation): This field asks you to select one or more options that describe the purpose of the training survey templates used by you.
- **What is the form ID?** (number): If a form ID is provided to you, enter it here.
- **Description of the teacher professional development and evaluation survey** (text): Write a brief description of the survey you are creating.
- **Which tool has been assigned to you?** (select_one): Select the tool assigned to you from the provided options.
- **Which tool is assigned to you?** (select_one): Select the tool assigned to you from the provided options.
- **What category does the tool belong to?** (select_one): Select the category the tool belongs to from the provided options.
- **What is the output file format?** (text): Enter the desired output file format.
- **Description** (text): If applicable, provide a brief description of the survey.
- **Output File 2** (text): Enter the desired output file format again.
- **Teacher Professional Development And Evaluation Survey Description 3** (text): If applicable, provide a description of the survey.
- **Form Id 2** (number): If a form ID 2 is provided to you, enter it here.
