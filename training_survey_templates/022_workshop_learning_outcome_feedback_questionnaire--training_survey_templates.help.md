# Workshop Learning Outcome Feedback Questionnaire - Help Guide
## Purpose
The Workshop Learning Outcome Feedback Questionnaire is a form designed to collect feedback from workshop participants on their experience, learning outcomes, and effectiveness of the workshop. It is intended to be completed by workshop organizers and facilitators to gather valuable insights on how to improve their workshops.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form questions and options carefully to understand what is being asked.
2. Select the relevant options that best match your experience and opinions.
3. Fill out all required fields to provide comprehensive feedback.

## Field-by-Field Explanation

* **What do participants think of this workshop?** (`workshop_learning_outcome_feedback_questionnaire`, select_multiple): Please select all that apply from the provided options (Option 1, Option 2, Option 3) to express your thoughts on the workshop.
* **What were the main learning outcomes of this workshop?** (`learning_outcome`, text): Describe the main learning outcomes you achieved from attending the workshop. Please provide a brief but clear explanation.
* **How effective was this workshop?** (`workshop_effectiveness`, select_one): Select one option from the provided list (Option 1, Option 2, Option 3) that best reflects your opinion on the workshop's effectiveness.
* **What fast feedback will you get from participants after using this form?** (`participant_insights`, text): Describe any immediate feedback or insights you gained from participants after using this form. Please be as concise as possible.
* **Which tool was this form assigned with?** (`assigned_tool`, select_one): Select the tool with which this form was assigned (ChatJot, FormAssembly, Other).
* **Who created this form?** (`created_by`, select_one): Select the person who created this form (User 1, User 2, User 3).
* **Form ID** (`form_id`, number): This field is automatically generated and not editable.
* **Category** (`category`, select_one): Select the category under which this form falls (Training Survey Templates, Other).
* **Description** (`description`, text): Provide a brief description of the form, if needed.
* **Output file** (`output_file`, select_one): Select the output file format (022 workshop learning outcome feedback questionnaire--training survey templates.yaml, Other).
* **Tool** (`tool`, select_one): Select whether this form was used with a tool (Yes, No).
* **Created at** (`created_at`, date): This field is automatically generated and not editable.
* **Updated at** (`updated_at`, date): This field is automatically generated and not editable.

## Tips
- Be honest and thorough in your feedback, as it will help workshop organizers and facilitators improve their workshops.
- Make sure to select all relevant options that apply to your experience and opinions.
- If you need help or have questions, please don't hesitate to reach out to the form creator or workshop organizers.
