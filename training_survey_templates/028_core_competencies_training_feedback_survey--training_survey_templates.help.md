# Core Competencies Training Feedback Survey - Help Guide
## Purpose
This guide is designed to walk you through the process of filling in the Core Competencies Training Feedback Survey form.

## How To Complete This Form
The form is divided into several pages, each with specific questions. Please fill out each page as instructed below:

1. **Session Name** (`session_name`, text, optional): Please enter the name of the session you attended.
2. **Session Type** (`session_type`, select_one, optional): Please select the type of session you attended (e.g., workshop, class, webinar).
3. **Session Date** (`session_date`, date, optional): Enter the date on which the session took place.
4. **Session Start Time** (`session_start_time`, time, optional): Enter the start time of the session.
5. **Session Length** (`session_length`, number, optional): Please enter the duration of the session.
6. **Session Location** (`session_location`, text, optional): Enter the location of the session.
7. **Session Facilitator** (`session_facilitator`, text, optional): Please enter the name of the session facilitator.
8. **Overall Satisfaction** (`overall_satisfaction`, select_one, optional): Please select one of the following:
	* Very satisfied
	* Somewhat satisfied
	* Not satisfied
9. **Session Improvement Areas** (`session_improvement_areas`, select_multiple, optional): Please select all areas you feel need improvement (e.g., presentation, facilitation, content, materials).
10. **Session Suggestions** (`session_suggestions`, text, optional): Please enter any suggestions you have for improving the session.
11. **Evaluation Comments** (`evaluation_comments`, note, optional): Please enter any additional comments you have about the session.

## Tips
* Please be honest and thorough in your feedback.
* If you are unsure about any question, please don't hesitate to reach out to the facilitator or the training team.
* The session name and session type fields are not required, but they are helpful in providing context to the facilitator for future reference.
* For the Overall Satisfaction field, select the option that best reflects your feelings about the session.
