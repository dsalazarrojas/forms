# Key Fob Battery Check Form - Help Guide
## Purpose
The Key Fob Battery Check Form is used to monitor and document the condition of key fobs used for vehicles. This form helps to assess the battery level, status, and required follow-up actions, enabling efficient tracking and maintenance.
## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the details of the key fob in the **key_fob_details** field.
2.  Select the **battery_condition** in the drop-down menu.
3.  Enter the **battery_level** if it's relevant.
4.  Add any notes in the **notes_section** if necessary.
5.  Choose the follow-up action required for the key fob from the **follow_up_action** options.
6.  Enter the next check date and interval in the **next_check_date** and **next_check_interval** fields, respectively, if applicable.
7.  Select the current status of the key fob from the **key_fob_status** options.
8.  Choose the status of the associated equipment from the **equipment_status** options.
9.  Select the type of equipment from the **equipment_type** options (e.g., fleet vehicle or key fob).
10. Select the make of the vehicle associated with the key fob from the **vehicle_make** options.
11. Select the model of the vehicle from the **vehicle_model** options.

## Field-by-Field Explanation
* **key_fob_details**: Enter the key fob's ID or any other relevant information.
* **battery_condition**: Select whether the key fob's batteries are good or dead.
* **battery_level**: Enter the battery level (not used for select options but provided as an option if relevant).
* **notes_section**: Add any additional comments or notes about the key fob's condition.
* **follow_up_action**: Select the necessary actions for the key fob, such as replace or recommend replacement.
* **next_check_date**: Enter the date for the next check.
* **next_check_interval**: Enter the interval for the next check (e.g., weekly, monthly, annually).
* **key_fob_status**: Choose whether the key fob is normal, faulty, or missing.
* **equipment_status**: Select whether the associated equipment is active, inactive, or retired.
* **equipment_type**: Select whether the associated equipment is a fleet vehicle or key fob.
* **vehicle_make**: Choose the vehicle's make (e.g., Acura, Audi, BMW).
* **vehicle_model**: Select the vehicle's model.
## Tips

This form is a simple, user-friendly tool to ensure efficient tracking and maintenance of key fobs. By filling out this form, you'll be able to quickly identify and address any issues with the key fob, reducing downtime and enhancing overall vehicle performance.
