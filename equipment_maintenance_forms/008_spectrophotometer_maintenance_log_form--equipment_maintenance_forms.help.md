# Spectrophotometer Maintenance Log Form - Help Guide
## Purpose
This form is used to record the maintenance history and upkeep of spectrophotometers. It is intended to be a structured and organized way of tracking the maintenance activities performed on these instruments.

## How To Complete This Form
1. Start by filling in the "Location" field with the current location of the spectrophotometer. This can be one of the following options: Lab A, Lab B, Lab C, or Lab D.
2. Enter the "Upkeep" field with a value between 0 and 100, representing the percentage of upkeep performed on the spectrophotometer.
3. Enter the "Date" field with the date of the maintenance activity.
4. Fill in the "Notes" field with any additional information about the maintenance activity.
5. In the "Maintenance History" fields, enter a brief description of the maintenance activity.
6. Make sure to review and update the existing "Maintenance History" fields if the spectrophotometer has been maintained before.

## Field-by-Field Explanation

* **Location** (`location`, `select_one`, required: false): This field is used to identify the current location of the spectrophotometer. Select the correct location from the dropdown menu: Lab A, Lab B, Lab C, or Lab D.
* **Upkeep** (`Upkeep`, `number`, required: false): This field is used to report the percentage of upkeep performed on the spectrophotometer, with values between 0 and 100.
* **Date** (`Date`, `time`, required: false): This field is used to enter the date of the maintenance activity.
* **Notes** (`Notes`, `note`, required: false): This field is used to add any additional information about the maintenance activity.
* **Maintenance History** (`Maintenance History`, `text`, required: false): This field is used to document a brief description of the maintenance activity.
