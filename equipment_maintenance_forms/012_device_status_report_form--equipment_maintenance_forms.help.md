# device_status_report_form - Help Guide
## Purpose
The device status report form is used to collect information about the status of devices.

## How To Complete This Form
1. Fill in the device condition field with a brief description of the device's current status.
2. Select the maintenance needs of the device from the options provided.
3. Enter the scheduled maintenance date for the device if applicable.
4. Provide a description of any work performed on the device in the description field.
5. Add any comments or additional information about the device in the comments field.
6. Select the individuals or teams responsible for maintaining the device from the options provided.

## Field-by-Field Explanation
* **Device Condition** (`device_status_report_form_1`, number): Enter a brief description of the device's current condition.
* **Maintenance Needs** (`device_status_report_form_2`, select_one): Select the level of maintenance needed for the device from the options provided.
* **Maintenance Scheduling** (`device_status_report_form_3`, date): Enter the scheduled maintenance date for the device if applicable.
* **Description** (`device_status_report_form_4`, note): Provide a description of any work performed on the device.
* **Comments** (`device_status_report_form_5`, text): Add any additional comments or information about the device.
* **Assigned To** (`device_status_report_form_6`, select_multiple): Select the individuals or teams responsible for maintaining the device from the options provided.

## Tips
* Make sure to complete all required fields.
* Use clear and concise language when filling in the fields.
* If you're unsure about any field, refer to the device's documentation or contact the relevant team for guidance.
