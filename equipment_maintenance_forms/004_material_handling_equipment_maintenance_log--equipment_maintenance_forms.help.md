This form is used to log the maintenance activities performed on material handling equipment. It helps track the start and end dates and times of maintenance activities, as well as the equipment status and comments.

The purpose of this form is to provide a clear and concise record of maintenance activities, enabling efficient tracking and reporting of equipment performance and maintenance history.

**Material Handling Equipment Maintenance Log - Help Guide**

## Purpose
The form is used to record maintenance activities on material handling equipment, including start and end dates and times, equipment status, and comments.

## How To Complete This Form

1. Fill in the Equipment ID, which is the unique identifier for the equipment being maintained.
2. Select the Type of the equipment being maintained, which indicates the type of maintenance activity performed.
3. Enter a brief Description of the maintenance activity, if applicable.
4. Select the Start Date and Time of the maintenance activity.
5. Select the End Date and Time of the maintenance activity.
6. Select the Status of the equipment after the maintenance activity, indicating whether it is working properly or not.
7. Enter any Comments related to the maintenance activity, if applicable.

## Field-by-Field Explanation

* **Equipment ID** (`equipment_id`, text, optional): Enter the unique identifier for the equipment being maintained.
* **Type** (`equipment_type`, select_one, required): Select the type of maintenance activity performed on the equipment.
* **Description** (`description`, text, optional): A brief description of the maintenance activity, if applicable.
* **Start Date** (`start_date`, date, optional): Select the start date of the maintenance activity.
* **Start Time** (`start_time`, time, optional): Select the start time of the maintenance activity.
* **End Date** (`end_date`, date, optional): Select the end date of the maintenance activity.
* **End Time** (`end_time`, time, optional): Select the end time of the maintenance activity.
* **Status** (`status`, select_one, optional): Select the status of the equipment after the maintenance activity.
* **Comments** (`comments`, text, optional): Enter any comments related to the maintenance activity.

## Tips

* Please ensure that you are entering the correct Equipment ID and Type to ensure accurate tracking and reporting.
* If the equipment is not working properly after maintenance, select "Not Working" as the Status.
* Comments can be useful for documenting any issues or observations related to the maintenance activity.
