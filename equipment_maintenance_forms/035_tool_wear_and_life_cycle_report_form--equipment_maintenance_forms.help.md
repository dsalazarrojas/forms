# Tool Wear And Life Cycle Report Form - Help Guide

## Purpose
The Tool Wear And Life Cycle Report Form is designed to track and report the condition and life cycle of tools and equipment. This form helps maintenance personnel collect and store data in a structured and standardized way.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the `equipment_id` field with the specific ID of the equipment being reported on.
2. Provide the name of the tool in the `tool_name` field.
3. Assess the current condition of the tool using the select box and choose from the options provided: Good, Medium, or Bad.
4. Enter the number of documents attached to the tool in the `document_wear` field.
5. Enter the date the tool was last serviced in the `date_last_serviced` field.
6. Enter the date the tool was last inspected in the `date_last_inspected` field.
7. Enter the date the tool is due for next servicing in the `next_servicing_date` field.
8. Select the department responsible for the tool from the options provided: Maintenance, Operations, or Other.
9. If applicable, enter the name of the assigned personnel in the `supervisor_name` field.
10. If applicable, enter the email and phone number of the supervisor in the `supervisor_email` and `supervisor_phone` fields respectively.
11. Enter the date the form was submitted by in the `submitted_by` field.
12. Enter any additional comments in the `comments` field.

## Field-by-Field Explanation

* **Equipment ID (equipment_id)**: Enter the unique ID of the equipment being reported on.
* **Tool Name (tool_name)**: Enter the name of the tool being reported on.
* **Condition (condition)**: Assess the current condition of the tool using the select box and choose from the options provided: Good, Medium, or Bad.
* **Document Wear (document_wear)**: Enter the number of documents attached to the tool.
* **Servicing Plan (servicing_plan)**: Enter the date the tool is due for next servicing.
* **Date Last Serviced (date_last_serviced)**: Enter the date the tool was last serviced.
* **Date Last Inspected (date_last_inspected)**: Enter the date the tool was last inspected.
* **Next Servicing Date (next_servicing_date)**: Enter the date the tool is due for next servicing.
* **Assigned Tool (assigned_tool)**: Enter the name of the personnel assigned to the tool.
* **Comments (comments)**: Enter any additional comments or notes.
* **Department (department)**: Select the department responsible for the tool from the options provided: Maintenance, Operations, or Other.
* **Supervisor Name (supervisor_name)**: Enter the name of the supervisor responsible for the tool.
* **Supervisor Email (supervisor_email)**: Enter the email of the supervisor responsible for the tool.
* **Supervisor Phone (supervisor_phone)**: Enter the phone number of the supervisor responsible for the tool.
* **Submitted By (submitted_by)**: Enter the date the form was submitted by.

Tips:
* Make sure to fill in all the required fields before submitting the form.
* Use the correct format for dates (dd/mm/yyyy).
* If you are unsure about the condition of the tool, use the options provided for guidance.
* Make sure to select the correct department and supervisor if applicable.
* Review the form carefully before submitting to ensure accuracy.
