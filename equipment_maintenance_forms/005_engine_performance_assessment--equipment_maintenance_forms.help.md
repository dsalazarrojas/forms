# Engine Performance Assessment - Help Guide
## Purpose
The Engine Performance Assessment form is used to gather data about engine performance to evaluate the overall condition and health of an engine.

## How To Complete This Form
1. Begin by selecting the correct engine type from the dropdown menu.
2. Assess the engine condition by selecting from the options provided.
3. Enter the current oil level, temperature, engine RPM, and engine hours.
4. Report any smoke color observed, if applicable.
5. Evaluate the vibration of the engine, if applicable.
6. Check for any leaks, if applicable.
7. Select the fuel type.
8. Select the engine oil type.
9. Enter the coolant temperature.
10. Select the coolant level.
11. Evaluate the engine coolant condition.
12. Check the transmission temperature, if applicable.
13. Select the transmission fluid level.
14. Select the drive type.
15. Select the engine type.
16. Evaluate the engine oil condition.
17. Select the fuel level.
18. Evaluate the transmission condition.
19. Enter the engine RPM range.
20. Enter the engine hours range.

## Field-by-Field Explanation
* **Engine Performance** (1, text, required): Enter a brief description of the engine performance.
* **Engine Type** (2, select_one, optional): Select the type of engine, e.g., Gasoline, Diesel, Hybrid, or Electric.
* **Engine Condition** (3, select_multiple, required): Assess the engine condition, selecting from Normal, Abnormal, or Critical.
* **Oil Level** (4, select_one, required): Select the current oil level, e.g., Low, Normal, or High.
* **Temperature** (5, number, required): Enter the current engine temperature.
* **Engine RPM** (6, number, required): Enter the current engine RPM.
* **Smoke Color** (7, select_one, optional): If smoke is observed, select the color.
* **Vibration** (8, select_multiple, required): Assess the engine vibration, selecting from Low, Medium, or High.
* **Leaks** (9, select_multiple, optional): Check for any engine leaks, selecting from None, Low, or High.
* **Engine Hours** (10, number, required): Enter the total engine hours.
* **Fuel Type** (11, select_one, required): Select the fuel type, e.g., Gasoline, Diesel, Hybrid, or Electric.
* **Engine Oil Type** (12, select_one, required): Select the engine oil type, e.g., Mineral, Synthetic, or Synthetic Blend.
* **Coolant Temperature** (13, number, required): Enter the current coolant temperature.
* **Coolant Level** (14, select_one, required): Select the current coolant level, e.g., Low, Normal, or High.
* **Engine Coolant** (15, select_multiple, required): Assess the engine coolant condition, selecting from Good, Fair, or Bad.
* **Transmission Temperature** (16, number, optional): If applicable, enter the current transmission temperature.
* **Transmission Fluid** (17, select_one, optional): If applicable, select the transmission fluid level, e.g., Fluid, Low, or High.
* **Transmission Fluid Level** (18, select_one, required): If applicable, select the current transmission fluid level, e.g., High, Low, or Fluid.
* **Drive Type** (19, select_one, required): Select the drive type, e.g., Front-Wheel Drive, Rear-Wheel Drive, or Four-Wheel Drive.
* **Engine Type** (20, select_one, required): Select the engine type, e.g., Gasoline, Diesel, Hybrid, or Electric.
* **Engine Oil Condition** (21, select_multiple, required): Assess the engine oil condition, selecting from Clean, Dirty, or Severe.
* **Fuel Level** (22, select_one, required): Select the current fuel level, e.g., High, Normal, or Low.
* **Transmission Condition** (23, select_multiple, required): Assess the transmission condition, selecting from Good, Fair, or Bad.
* **Engine RPM Range** (24, text, required): Enter the current engine RPM range.
* **Engine Hours Range** (25, text, required): Enter the total engine hours range.
