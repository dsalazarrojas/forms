# Preventive Maintenance Access Control Form - Help Guide
## Purpose
The Preventive Maintenance Access Control Form is a critical tool used to manage and track maintenance access within facilities. It ensures that all necessary information is gathered accurately and efficiently.

## How To Complete This Form

1. Fill out the form for each maintenance access request, providing accurate and detailed information.
2. Select the correct access date from the calendar provided or enter a custom date.
3. Choose the correct maintenance type from the options provided (Scheduled or Emergency).
4. Enter the reason for the access request in the text field provided.
5. Select the correct facility access requester from the options provided (Administrator, Manager, Supervisor, or Worker).
6. Select the correct facility access approver from the options provided (Manager, Supervisor, or Worker).
7. Enter the equipment ID (if applicable).
8. Enter the equipment name (if applicable).
9. Provide details about the maintenance type (if applicable).
10. Set the access time for the maintenance.
11. Specify the access duration for the maintenance.
12. Set the maintenance start time.
13. Set the maintenance end time.
14. Select the maintenance status (Scheduled, In Progress, or Complete).
15. Add any additional notes about the maintenance.
16. Enter a valid email address (if applicable).
17. Enter the phone number (if applicable).
18. Select the assigned user for the maintenance (optional).

## Field-by-Field Explanation

* 1. **Access Date**: Select the date you need access to the facility for maintenance.
* 2. **Maintenance Type**: Choose between Scheduled or Emergency maintenance types.
* 3. **Reason For Access Request**: Provide a clear and concise description of the reason for the maintenance access request.
* 4. **Facility Access Requester**: Select who requested access to the facility (Administrator, Manager, Supervisor, or Worker).
* 5. **Facility Access Approver**: Select who should approve access to the facility (Manager, Supervisor, or Worker).
* 6. **Equipment ID**: Enter the unique identifier for the equipment if applicable.
* 7. **Equipment Name**: Enter the name of the equipment if applicable.
* 8. **Maintenance Type Details**: Provide any additional details about the maintenance type if necessary.
* 9. **Access Time**: Set the time when you need access to the facility.
* 10. **Access Duration**: Specify how long you need access to the facility.
* 11. **Maintenance Start Time**: Set the start time for the maintenance.
* 12. **Maintenance End Time**: Set the end time for the maintenance.
* 13. **Maintenance Status**: Select the current status of the maintenance (Scheduled, In Progress, or Complete).
* 14. **Notes**: Add any additional comments or information about the maintenance.
* 15. **Email**: Enter a valid email address (if applicable).
* 16. **Phone**: Enter the phone number (if applicable).
* 17. **Assigned User**: Select the user assigned to perform the maintenance (optional).

## Tips
- Always fill out the form accurately and completely.
- Ensure that you have the necessary permissions and clearances before submitting the form.
- Review and verify the information before submitting it to avoid errors.
- If you are unsure about any field, do not hesitate to reach out to your supervisor or maintenance team.
