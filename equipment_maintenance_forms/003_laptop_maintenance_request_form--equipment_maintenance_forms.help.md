# laptop_maintenance_request_form - Help Guide
## Purpose
The laptop maintenance request form is used to submit a request for laptop maintenance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required information:
	* Select the type of equipment that requires maintenance (Laptop).
	* Enter the serial number of the laptop.
	* Specify the priority level of the maintenance request (High or Low).
2. Enter optional information:
	* Briefly describe the maintenance request in the Description field.
	* Choose the team member responsible for handling the maintenance request (IT or Other).
	* Enter a contact email address for the user submitting the request.
	* Enter a contact phone number for the user submitting the request.

## Field-by-Field Explanation
* **Laptop Maintenance Request**: This field is where you enter the description of the maintenance request.
* **Equipment Type**: This field is where you select the type of equipment that requires maintenance. Choose "Laptop".
* **Serial Number**: This field is where you enter the serial number of the laptop that requires maintenance.
* **Description**: This field is where you provide a brief description of the maintenance request.
* **Date**: This field is where you enter the date when the maintenance request was made.
* **Time**: This field is where you enter the time when the maintenance request was made.
* **Priority**: This field is where you specify the level of priority for the maintenance request. Choose "High" or "Low".
* **Assignee**: This field is where you choose the team member responsible for handling the maintenance request. Choose "IT" or "Other".
* **Notes**: This field is where you can add any additional information about the maintenance request.
* **Email**: This field is where you enter a contact email address for the user submitting the request.
* **Phone**: This field is where you enter a contact phone number for the user submitting the request.
