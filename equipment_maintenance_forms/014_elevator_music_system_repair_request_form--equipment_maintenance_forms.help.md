# Elevator Music System Repair Request Form - Help Guide
## Purpose
The Elevator Music System Repair Request Form is used to report issues with the elevator music system to the maintenance team. It's essential to report any issues, no matter how small they may seem, to ensure that the system is functioning correctly and that users are not affected.

## How To Complete This Form

### Step 1: Identify the Issue
* Go to the first page and type a brief description of the problem you are experiencing with the elevator music system in the "Music System Issues" field.

### Step 2: Select Audio Type
* On the second page, select the type of audio equipment you are using for the elevator music system: Audio Loop, Music Server, Audio Server, or Other.

### Step 3: Specify Audio Source
* On the second page, select the source of the audio: Music Stream, CD, Radio, or Other.

### Step 4: Describe the Issue
* On the third page, provide a detailed description of the issue in the "Issue Description" field.

### Step 5: Set Priority
* On the fourth page, select the priority of the issue: Low, Medium, or High.

### Step 6: Track Progress
* On the fifth page, select the status of the issue: Open, In Progress, Closed.

### Step 7: Attach Supporting Documents
* On the sixth page, select whether you want to attach any supporting documents to the issue.

### Step 8: Provide Resolution Information
* On the seventh page, select who resolved the issue, when it was resolved, and what time it was resolved.

### Step 9: Additional Comments
* On the eighth page, add any additional comments about the issue.

## Field-by-Field Explanation

* **Music System Issues**: A brief description of the problem you are experiencing with the elevator music system.
* **Audio Type**: Select the type of audio equipment you are using for the elevator music system. 
  - Audio Loop: The system is looping music continuously.
  - Music Server: The system is playing music from a server.
  - Audio Server: The system is playing music from an audio server.
  - Other: Select this option if your system is not one of the above.
* **Audio Source**: Select the source of the audio for the elevator music system.
  - Music Stream: The system is streaming music from a music streaming service.
  - CD: The system is playing music from a CD player.
  - Radio: The system is playing music from a radio source.
  - Other: Select this option if your system is not one of the above.
* **Issue Description**: A detailed description of the issue you are experiencing with the elevator music system.
* **Priority**: Select the priority of the issue. 
  - Low: The issue is not affecting the system's functionality but is a minor annoyance.
  - Medium: The issue is affecting the system's functionality but is not critical.
  - High: The issue is critical and needs immediate attention.
* **Status**: Select the status of the issue. 
  - Open: The issue is new and has not been addressed.
  - In Progress: The issue is being worked on.
  - Closed: The issue has been resolved.
* **Attachments**: Select whether you want to attach any supporting documents to the issue.
* **Resolved By**: Select who resolved the issue.
  - Maintenance Team: The maintenance team resolved the issue.
  - Property Management: The property management team resolved the issue.
  - Facility Team: The facility team resolved the issue.
  - Other: Select this option if the issue was resolved by someone else.
* **Resolved By User**: Enter the name of the user who resolved the issue.
* **Resolved By Date**: Enter the date the issue was resolved.
* **Resolved By Time**: Enter the time the issue was resolved.
* **Escalation Notes**: Enter any additional comments about the issue.
* **Escalated To**: Select who the issue was escalated to.
  - Maintenance Team: The issue was escalated to the maintenance team.
  - Property Management: The issue was escalated to the property management team.
  - Facility Team: The issue was escalated to the facility team.
  - Other: Select this option if the issue was escalated to someone else.
* **Closed By**: Select who closed the issue.
  - Maintenance Team: The maintenance team closed the issue.
  - Property Management: The property management team closed the issue.
  - Facility Team: The facility team closed the issue.
  - Other: Select this option if the issue was closed by someone else.
* **Closed Date**: Enter the date the issue was closed.
* **Closed Time**: Enter the time the issue was closed.
* **Reopened**: Select whether the issue was reopened.
  - True: The issue was reopened.
  - False: The issue was not reopened.
* **Reopened By**: Select who reopened the issue.
  - Maintenance Team: The maintenance team reopened the issue.
  - Property Management: The property management team reopened the issue.
  - Facility Team: The facility team reopened the issue.
  - Other: Select this option if the issue was reopened by someone else.
* **Reopened Date**: Enter the date the issue was reopened.
* **Reopened Time**: Enter the time the issue was reopened.
* **Responsible Party**: Select who is responsible for the issue.
  - Maintenance Team: The maintenance team is responsible for the issue.
  - Property Management: The property management team is responsible for the issue.
  - Facility Team: The facility team is responsible for the issue.
  - Other: Select this option if someone else is responsible for the issue.
* **Additional Comments**: Enter any additional comments about the issue.

## Tips
* Please report any issues, no matter how small they may seem, to ensure that the system is functioning correctly.
* If you are unsure about any of the fields, please contact the maintenance team for assistance.
* Please attach any supporting documents to the issue to help the maintenance team troubleshoot and resolve the issue.
