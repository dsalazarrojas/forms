# Smart Machine Diagnostics Request Form - Help Guide
## Purpose
The Smart Machine Diagnostics Request Form is designed to gather information for diagnostic visits to equipment. This form helps us understand the issue with the equipment and schedule the visit accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the issue with the equipment in the **Issue Description** field.
2. Specify the **Equipment Location** where the issue is occurring.
3. Answer the question about scheduling a visit in the **Schedule Visit** field. Choose "Yes" if you need a visit scheduled, and "No" if it's an emergency visit.
4. Indicate the type of diagnostic visit required in the **Diagnostic Visit Type** field.
5. Select a date and time for the visit in the **Visit Scheduled Time** and **Visit Scheduled Date** fields.
6. Provide any additional supporting details for the diagnostic visit in the **Supporting Details** field.
7. Confirm whether any files have been uploaded to support the issue in the **Files Uploaded** field.
8. Add any comments or information that might be helpful for the diagnostic team in the **Comments** field (optional).

## Field-by-Field Explanation
* **Issue Description** (Text, Required): Briefly describe the issue with the equipment.
* **Equipment Location** (Text, Required): Specify the location where the equipment is located.
* **Schedule Visit** (Select One, Required): Choose "Yes" to schedule a visit, or "No" if it's an emergency visit.
* **Diagnostic Visit Type** (Select One, Required): Select the type of diagnostic visit required.
* **Visit Scheduled Time** (Date, Required): Select a specific time for the visit.
* **Visit Scheduled Date** (Date, Required): Select a specific date for the visit.
* **Supporting Details** (Text, Required): Provide any additional information that might be helpful for the diagnostic team.
* **Files Uploaded** (Select Multiple, Required): Confirm whether files have been uploaded to support the issue.
* **Comments** (Text, Optional): Add any additional comments or information that might be helpful for the diagnostic team.
