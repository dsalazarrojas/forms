# Employee Absence Return To Work Form - Help Guide

## Purpose
This form is used to document an employee's return to work process after an absence.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all the necessary information required by the form before starting.
2. Fill in the `Physician's Name` field with your name as the physician.
3. Date and sign in the `Signatures` field, indicating the date of your signature.
4. Add your signature in the `Physician's Signature` field, confirming your signature.
5. If applicable, enter the employee's ID number in the `Employee's ID` field.
6. Fill in the `Employee's First Name` and `Employee's Last Name` fields with the employee's name.
7. Provide a brief reason for the employee's absence in the `Reason for Absence` field.
8. Fill in the `Return Date` and `Return Time` fields with the date and time the employee is expected to return to work.
9. If necessary, provide additional comments in the `Physician's Comments` field.

## Field-by-Field Explanation

* **Physician's Name**: This is your name as the physician. 
* **Signatures**: This field is used for the date of your signature. You should date and sign this field.
* **Physician's Signature**: This is your signature confirming your signature.
* **Employee's ID**: This is the ID number of the employee. If you do not have this information, please leave this field blank.
* **Employee's First Name**: This is the first name of the employee.
* **Employee's Last Name**: This is the last name of the employee.
* **Reason for Absence**: This is a brief description of the reason for the employee's absence.
* **Return Date**: This is the date the employee is expected to return to work. Please ensure this date is accurate.
* **Return Time**: This is the time the employee is expected to return to work. Please ensure this time is accurate.
* **Physician's Comments**: This is an optional field for you to provide any additional comments regarding the employee's absence or return.
