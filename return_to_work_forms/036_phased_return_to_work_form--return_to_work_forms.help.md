# phased_return_to_work_form - Help Guide
## Purpose
This form is designed to help employees return to work in a phased manner after an extended leave, facilitating a smooth transition back to work.

## How To Complete This Form
1. Select the employee's information.
2. Choose their leave start and end dates.
3. Select dates for their gradual return (Return Schedule).
4. Choose days of the week for their return (Return Days).
5. Select work hours for their phased return (Work Hours).
6. Select dates for each phase of return (Return Date 1, 2, and 3).
7. Add any comments, if necessary.

## Field-by-Field Explanation
* **Employee Information** (`employee_information`, text, optional): Enter the employee's name and any other relevant details.
* **Leave Start Date** (`leave_start_date`, date, optional): Select the date when the employee's leave started.
* **Leave End Date** (`leave_end_date`, date, optional): Select the date when the employee's leave ended or is expected to end.
* **Return Schedule** (`return_schedule`, select_multiple, optional): Choose the number of weeks for the gradual return (2 weeks, 3 weeks, 4 weeks).
* **Return Days** (`return_days`, select_multiple, optional): Select the days of the week for the employee's return (Monday, Tuesday, Wednesday, Thursday, Friday, Saturday, Sunday).
* **Work Hours** (`work_hours`, select_multiple, optional): Choose the employee's work hours during their phased return (8am-12pm, 12pm-4pm, 4pm-8pm).
* **Return Date 1** (`return_date_1`, date, optional): Select the date for the first phase of return.
* **Return Date 2** (`return_date_2`, date, optional): Select the date for the second phase of return.
* **Return Date 3** (`return_date_3`, date, optional): Select the date for the third phase of return.
* **Comments** (`comments`, text, optional): Add any additional comments about the employee's return.

## Tips
- Please ensure you select all relevant fields to provide a comprehensive return plan.
- If you're unsure about any field, please leave it blank or contact your supervisor for guidance.
- This form is designed to adapt to individual needs, so feel free to adjust dates and schedules as necessary.
