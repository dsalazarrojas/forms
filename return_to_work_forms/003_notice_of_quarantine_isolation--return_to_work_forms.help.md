# Notice Of Quarantine/Isolation - Help Guide
## Purpose
This form is used to report quarantine exposure and isolation incidents in the workplace. It helps the management team track and respond to these incidents, ensuring a safe and healthy work environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for "Quarantine Exposure" from the available choices.
2. Enter the date of return, if applicable.
3. Enter the employee's name.
4. Enter the manager's name.
5. Provide the location where the exposure occurred.
6. Enter the employee's contact number.
7. Enter the employee's email address.
8. Select whether a PDF was sent to the employee.

## Field-by-Field Explanation

* **Quarantine Exposure** (`quarantine_exposure`, select_multiple, required): Select all applicable exposure options from the list.
  • Exposed: The employee has been exposed to a quarantined person or place.
  • Positive: The employee has tested positive for a quarantined disease.
* **return_date** (`return_date`, date, required): The date the employee will return to work, if applicable.
* **employee_name** (`employee_name`, text, required): Enter the name of the employee reporting the quarantine exposure.
* **manager_name** (`manager_name`, text, required): Enter the name of the employee's manager.
* **location** (`location`, text, required): Enter the location where the exposure occurred.
* **contact_number** (`contact_number`, text, required): Enter the employee's contact number.
* **email** (`email`, email, required): Enter the employee's email address.
* **pdf_sent** (`pdf_sent`, select_one, required): Select whether a PDF was sent to the employee.

## Tips
When filling out this form, make sure to select the correct "Quarantine Exposure" options and enter accurate contact information for the employee.
