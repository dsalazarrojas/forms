# Physician Release To Return To Work Form - Help Guide
## Purpose

This form is used to confirm an employee's ability to return to work after a work-related injury or illness. It provides essential information to ensure a smooth transition back to work.

## How To Complete This Form

1. Fill out the form completely, ensuring all required fields are completed.
2. Answer each question accurately and truthfully.
3. Sign and date the form as required.

## Field-by-Field Explanation

* **Return To Work Form** (`return_to_work_form`, text, required/optional): This is the main form title.
* **Date Of Injury** (`date_of_injury`, date, required/optional): The date when the injury or illness occurred.
* **Physician Name** (`physician_name`, text, required/optional): The name of the physician who is signing the form.
* **Physician Signature** (`physician_signature`, select_one, required/optional): Select 'Yes' if the physician confirms the employee's fitness to return to work. Select 'No' if they do not.
* **Employee Name** (`employee_name`, text, required/optional): The name of the employee returning to work.
* **Job Title** (`job_title`, text, required/optional): The job title of the employee returning to work.
* **Date Return To Work** (`date_return_to_work`, date, required/optional): The date the employee is scheduled to return to work.
* **Work Status** (`work_status`, select_one, required/optional): Select 'available' if the employee can return to work with full duties. Select 'unavailable' if the employee has restrictions or modified duties. Select 'restricted' if the employee has modified duties and is not cleared to return to work.
* **Physician Note** (`physician_note`, text, required/optional): Any additional comments or notes from the physician.
* **Employer Signature** (`employer_signature`, select_one, required/optional): Select 'Yes' if the employer agrees with the release. Select 'No' if they do not.

## Tips

* Complete the form accurately and thoroughly to ensure a smooth return-to-work process.
* If you are unsure about any information, please ask your supervisor or HR representative for guidance.
* Ensure you sign and date each field as required.
