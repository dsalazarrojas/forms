# Fashion Talent Sign Out Sheet - Help Guide
## Purpose
This form is designed to record the details of fashion talents who are checking out of a work or event setup.

## How To Complete This Form
1. Ensure you have all necessary information about the fashion talent, such as their fashion talent ID, date, time in and time out, and any production-related information.
2. Fill out the form with the relevant information for the talent, making sure to select all applicable options for agency, production company, and production team.
3. Provide a brief reason for the talent's check-out, if applicable.
4. Add any additional notes or comments about the talent's check-out.

## Field-by-Field Explanation
* **Fashion Talent ID** (`fashion_talent_id`, `number`, required: false): Enter the unique ID assigned to the fashion talent.
* **Date** (`date`, `date`, required: true): Enter the date the fashion talent checked out.
* **Time In** (`time_in`, `time`, required: true): Enter the time the fashion talent arrived at the work or event setup.
* **Time Out** (`time_out`, `time`, required: true): Enter the time the fashion talent checked out.
* **Talent Type** (`talent_type`, `select_multiple`, required: true): Select all categories that apply to the fashion talent (e.g. model, photographer, designer).
* **Agency** (`agency`, `select_one`, required: true): Select the agency that represents the fashion talent (e.g. yes or no).
* **Production Company** (`production_company`, `select_one`, required: true): Select the production company working with the fashion talent (e.g. yes or no).
* **Production Team** (`production_team`, `select_one`, required: true): Select the production team working with the fashion talent (e.g. yes or no).
* **Reason** (`reason`, `text`, required: false): Provide a brief reason for the talent's check-out, if applicable.
* **Note** (`note`, `text`, required: false): Add any additional comments or notes about the talent's check-out.

## Tips
- Make sure to fill out all required fields accurately to ensure correct information is recorded.
- Use the options provided for agency, production company, and production team to select all applicable values.
- Use clear and concise language when providing a reason for the talent's check-out, if applicable.
- Use the "Note" field for any additional information that doesn't fit in the other fields.
