# Computer Check Out Form - Help Guide
## Purpose
This form is used to track loaned equipment and borrower details.

## How To Complete This Form
1. Enter the borrower's full name in the "Borrower name" field.
2. If applicable, enter the borrower's employee or student ID in the "Borrower ID" field.
3. Select the type of equipment being checked out from the drop-down menu in the "Equipment type" field.
4. Enter the asset tag or serial number of the equipment in the "Equipment serial" field.
5. Set the "Checkout date" to the date the equipment was checked out.
6. Enter the expected return date for the equipment in the "Expected return date" field.
7. Optional: Note any existing damage or issues with the equipment in the "Condition at checkout" field.
8. Enter a typed name to confirm the borrower's identification in the "Borrower signature" field.

## Field-by-Field Explanation

* **Borrower name** (`borrower_name`, Text, required): Enter the full name of the person borrowing the equipment.
* **Borrower ID** (`borrower_id`, Text, optional): Enter the employee or student ID number of the borrower.
* **Equipment type** (`equipment_type`, Select one, required): Choose the type of equipment being checked out (e.g., Laptop, Charger, Monitor, etc.).
* **Equipment serial** (`equipment_serial`, Text, required): Enter the asset tag or serial number of the equipment.
* **Checkout date** (`checkout_date`, Date, required): Enter the date the equipment was checked out.
* **Expected return date** (`expected_return_date`, Date, required): Enter the date the borrower expects to return the equipment.
* **Condition at checkout** (`condition_at_checkout`, Text, optional): Note any existing damage or issues with the equipment.
* **Borrower signature** (`borrower_signature`, Text, required): Enter a typed name to confirm the borrower's identification.

## Tips

* Make sure to enter the correct equipment type and serial number to ensure accurate tracking.
* Enter the correct expected return date to set clear expectations with the borrower.
* Double-check the condition of the equipment at checkout to avoid any disputes.
* Ensure the borrower signs their name to confirm their identity.
* Review and follow up on the expected return date to ensure timely return of the equipment.
