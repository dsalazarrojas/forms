This is the Ambassador Event Check Out Form, used to collect information about events hosted by ambassadors. This form is used to gather data on event details, ambassador performance, event outcomes, and feedback. It is crucial that only one ambassador submits one form per event. Please make sure to review the form fields carefully and provide accurate information to ensure correct data collection.

# Ambassador Event Check Out Form - Help Guide
## Purpose
The purpose of this form is to collect event details, performance metrics, and feedback from ambassadors after an event. This helps us assess the success of the event and make necessary adjustments for future events.

## How To Complete This Form
Before filling out this form, ensure you have all necessary information handy. The form consists of several sections:

*   **Event Information (Pages 1-4)**: Enter the details of the event.
*   **Ambassador Information (Pages 5-8)**: Enter your personal details as an ambassador.
*   **Event Performance (Pages 9-12)**: Report on the performance of the event.
*   **Feedback (Pages 13-17)**: Share your thoughts on the event.

## Field-by-Field Explanation

### Event Information (Pages 1-4)

*   **Event Name (Page 2)**: Enter the name of the event.
    *   Type: Text
    *   Required: Yes
*   **Event Date (Page 3)**: Enter the date of the event.
    *   Type: Date
    *   Required: Yes
*   **Event Location (Page 4)**: Enter the venue or location name.
    *   Type: Text
    *   Required: Yes

### Ambassador Information (Pages 5-8)

*   **Ambassador First Name (Page 6)**: Enter your first name.
    *   Type: Text
    *   Required: Yes
*   **Ambassador Last Name (Page 7)**: Enter your last name.
    *   Type: Text
    *   Required: Yes
*   **Ambassador ID Number (Page 8)**: Enter your ID number.
    *   Type: Text
    *   Required: No
*   **Email Address (Page 9)**: Enter your email address.
    *   Type: Email
    *   Required: Yes
*   **Phone Number (Page 10)**: Enter your phone number.
    *   Type: Text
    *   Required: Yes

### Event Performance (Pages 9-12)

*   **Check-Out Date (Page 12)**: Enter the date you checked out.
    *   Type: Date
    *   Required: Yes
*   **Check-Out Time (Page 13)**: Enter the time you checked out.
    *   Type: Time
    *   Required: Yes
*   **Approximate Number of Attendees Engaged (Page 14)**: Report on the number of attendees engaged.
    *   Type: Number
    *   Required: No

### Feedback (Pages 13-17)

*   **Event Success Rating (Page 16)**: Rate the event's success.
    *   Type: Select One
    *   Required: Yes
    *   Options: 1 - Not Successful, 2 - Below Average, 3 - Average, 4 - Successful, 5 - Very Successful
*   **Goal Achievement (Page 17)**: Report on goal achievement.
    *   Type: Select One
    *   Required: Yes
    *   Options: Yes - Exceeded goals, Yes - Met goals, Partially - Some goals met, No - Goals not met
*   **Audience Engagement (Page 18)**: Rate audience engagement.
    *   Type: Select One
    *   Required: Yes
    *   Options: Excellent, Good, Fair, Poor, Very poor
*   **Event Organization (Page 19)**: Rate event organization.
    *   Type: Select One
    *   Required: Yes
    *   Options: Excellent, Good, Fair, Poor, Very poor

### Additional Information (Pages 18-22)

*   **What Worked Well (Page 20)**: Share successes and highlights.
    *   Type: Text
    *   Required: No
*   **Challenges Faced (Page 21)**: Share difficulties encountered.
    *   Type: Text
    *   Required: No
*   **Suggested Improvements (Page 22)**: Suggest improvements for future events.
    *   Type: Text
    *   Required: No

### Support and Resources (Pages 23-25)

*   **Support Rating (Page 24)**: Rate event support.
    *   Type: Select One
    *   Required: No
    *   Options: Very Satisfied, Satisfied, Neutral, Dissatisfied, Very dissatisfied
*   **Resources Adequacy (Page 25)**: Report on resource adequacy.
    *   Type: Select One
    *   Required: No
    *   Options: Yes - More than enough, Yes - Adequate, No - Insufficient
*   **Additional Support Needed (Page 26)**: Share what would have helped.
    *   Type: Text
    *   Required: No

### Future Events (Pages 26-28)

*   **Interest in Future Events (Page 27)**: Report on interest in future events.
    *   Type: Select One
    *   Required: Yes
    *   Options: Very Interested, Interested, Neutral, Not very interested, Not interested
*   **Preferred Event Types (Page 28)**: Select preferred event types.
    *   Type: Select Multiple
    *   Required: No
*   **Availability (Page 29)**: Report on general availability.
    *   Type: Select One
    *   Required: No
    *   Options: Weekdays, Weekends, Both, Flexible

### Additional Information (Pages 30-32)

*   **Photos Submitted (Page 31)**: Report on photos submitted.
    *   Type: Select One
    *   Required: No
    *   Options: Yes - Submitted, Yes - Will submit later, No - Not applicable
*   **Expense Report Status (Page 32)**: Report on expense report status.
    *   Type: Select One
    *   Required: No
    *   Options: Submitted, Will submit, No expenses
*   **Additional Comments (Page 33)**: Share any additional comments.
    *   Type: Text
    *   Required: No
*   **Supervisor/Coordinator Name (Page 34)**: Enter the supervisor's name.
    *   Type: Text
    *   Required: No
*   **Check-Out Verified By (Page 35)**: Enter the supervisor's signature.
    *   Type: Text
    *   Required: No
