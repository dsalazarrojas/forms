# Postcard Order Form - Help Guide
## Purpose
This form is used to order postcards for your use. Please select the desired options for your order from the fields below.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the option for the type of postcard you would like to order.
2. Choose the quantity of postcards you need.
3. Choose the product you would like to include on the postcard.
4. Indicate whether you would like to make a payment.
5. Select the date you would like the postcard to be delivered.
6. If applicable, select a specific time for the delivery.
7. Add a note for any further information about your order.
8. Provide an email address so we can contact you.
9. Enter your phone number for any additional communication.
10. Finally, select the category of postcard you would like to order.

## Field-by-Field Explanation
- **Select Postcard** (page 1): Choose the type of postcard you would like to order. This field has two options: "Yes" and "No". Select "Yes" if you would like to order a postcard.
- **Choose Quantity** (page 1): Enter the number of postcards you would like to order.
- **Product** (page 2): Select the product you would like to include on the postcard. This field is a multiple selection field, where you can choose multiple products.
- **Make Payment** (page 2): If you would like to make a payment immediately, select "Yes".
- **Select Date** (page 3): Choose the date you would like the postcard to be delivered. This field is a date field, where you can select a specific date.
- **Select Time** (page 3): If applicable, select the time for the delivery. This field is a time field, where you can select a specific time.
- **Note** (page 4): Add any additional notes about your order in this text area.
- **Email** (page 4): Enter your email address so we can contact you with any updates about your order.
- **Phone** (page 5): Enter your phone number for any additional communication about your order.
- **Category** (page 5): Select the category of postcard you would like to order. This field has two options: "Yes" and "No". Select "Yes" to order a postcard.

## Tips
- Double-check your selections before submitting the form to ensure accuracy.
- If you have any questions or concerns, please don't hesitate to contact us.
- We'll be in touch with you shortly after submitting this form to confirm your order.
