# Full Color Order Form - Help Guide

## Purpose
The Full Color Order Form is designed to collect information for orders of products with multiple colors. It is typically used for customers who are ordering multiple items with different colors. This form ensures that all relevant details, including product information, customer information, shipping details, and order notes, are collected accurately.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide the following details for the first product:
	* **Print Order**: Enter the print order number (e.g., 1234).
	* **Product Details**: Enter the product details (e.g., product name, quantity).
	* **Product Color**: Select the product color.
	* **Customer Info**: Enter customer information (e.g., name, email, phone number).
2. If applicable, repeat the product details for additional products:
	* **Product Color 2**: Select the product color for the second product.
	* **Product Details 2**: Enter the product details for the second product.
	* **Product Details 3**: Enter the product details for the third product.
3. Enter shipping details:
	* **Shipping Method**: Select the shipping method (e.g., Ship to Store, Ship to Home, Ship to Office).
	* **Shipping Address**: Enter the shipping address.
	* **Shipping City**: Enter the shipping city.
	* **Shipping Zip**: Enter the shipping zip code.
	* **Shipping Country**: Select the shipping country.
	* **Shipping State**: Select the shipping state.
4. Enter any additional shipping details:
	* **Shipping Method 2**: Select the shipping method for the second product (if different from the first product).
	* **Shipping Address 2**: Enter the shipping address for the second product.
	* **Shipping City 2**: Enter the shipping city for the second product.
	* **Shipping Zip 2**: Enter the shipping zip code for the second product.
	* **Shipping Country 2**: Select the shipping country for the second product.
	* **Shipping State 2**: Select the shipping state for the second product.
5. Add any order notes:
	* **Order Notes**: Enter any additional information or instructions for the order.
6. Review and submit the form.
