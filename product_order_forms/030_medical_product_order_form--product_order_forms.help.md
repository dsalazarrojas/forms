# Medical Product Order Form - Help Guide
## Purpose
The Medical Product Order Form is used to collect information from customers for ordering medical products.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select the appropriate page from the form to fill out.
2. Fill out the required fields as prompted.
3. Ensure that each field is complete before submitting the form.

## Field-by-Field Explanation
### Product Order Form (Page 1)
* **Product Order Form**: This is the main form where you will input your order details.
	+ This field is not required.
* **Contact Form**: This field is used to input your contact information.
	+ This field is not required.
* **Medical Products**: This field is used to input the medical product you wish to order.
	+ This field is not required.
* **Product Name**: This field is used to input the name of the product you wish to order.
	+ This field is not required.
* **Price**: This field is used to input the price of the product you wish to order.
	+ This field is not required.
* **Assigned Tool**: This field is used to input the assigned tool for your order.
	+ This field is not required.

### Contact Form (Page 2)
* **Contact Name**: This field is used to input your contact name.
	+ This field is not required.
* **Email**: This field is used to input your email address.
	+ This field is valid email address only.
* **Phone**: This field is used to input your phone number.
	+ This field is not required.
* **Note**: This field is used to input any additional notes about your order.
	+ This field is not required.

## Tips
* Only submit one order per form.
* Please ensure all fields are filled out before submitting.
