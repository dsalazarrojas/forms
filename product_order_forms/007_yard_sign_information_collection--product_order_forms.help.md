# Yard Sign Information Collection - Help Guide
## Purpose
This form is designed to collect information about yard signs, including specifications, artwork, installation details, and other relevant details.

## How To Complete This Form

* To complete this form, simply navigate through each page, answering the questions as they appear.
* Make sure to fill in all the required fields to ensure accurate collection of information.
* If a field is not required, you can still fill it out if you have additional information to provide.
* Click "Submit" when you have completed all the fields.

## Field-by-Field Explanation

* **Yard Sign Specs**: This field is used to collect the specifications of the yard sign, such as its size and shape.
* **Artwork**: Select whether the sign will have artwork or not. If yes, choose one of the options.
* **Artwork Color**: Select all the colors for the artwork, multiple selections are allowed.
* **Installation Details**: Enter any additional details about the installation, such as installation location and type.
* **Contact Person**: Select all the contact persons involved in the order, multiple selections are allowed.
* **Email**: Enter the email of the contact person.
* **Phone**: Enter the phone number of the contact person.
* **Notes**: Enter any additional notes about the contact person.
* **Date**: Enter the date of the order.
* **Time**: Enter the time of the order.
* **Yard Size**: Select the size of the yard for the sign.
* **Yard Location**: Select all the locations for the yard, multiple selections are allowed.
* **Sign Material**: Select all the materials for the sign, multiple selections are allowed.
* **Installation Location**: Select all the locations for the installation, multiple selections are allowed.
* **Yard Sign Type**: Select all the types of yard signs, multiple selections are allowed.
* **Quantity**: Enter the quantity of the yard signs.
* **Price**: Enter the price of the yard sign.
* **Notes**: Enter any additional notes about the order.
* **Customer Name**: Enter the name of the customer.
* **Customer Phone**: Enter the phone number of the customer.
* **Customer Email**: Enter the email of the customer.
* **Customer Notes**: Enter any additional notes about the customer.
* **Order Notes**: Enter any additional notes about the order.
* **Sales Rep**: Select whether the sales rep is involved in the order or not. 

**Tips:**

* Make sure to double-check your answers before submitting the form.
* If you need to make changes to an existing order, please note the changes in the "Notes" field.
