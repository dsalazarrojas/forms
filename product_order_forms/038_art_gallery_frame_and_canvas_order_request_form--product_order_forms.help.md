# Art Gallery Frame And Canvas Order Request Form - Help Guide
## Purpose
The Art Gallery Frame And Canvas Order Request Form is a tool for customers to place orders for custom art framing and canvas products. The form collects essential information required to process and deliver the order correctly.

## How To Complete This Form
To complete the form, follow these steps:
1. Fill out the "Requester name" field with the person placing the order.
2. Provide a valid email address for order confirmations in the "Contact email" field.
3. Select the type of item you are ordering from the "Item type" dropdown (Frame or Canvas).
4. Enter the dimensions of the item in the "Dimensions" field (Width x Height in cm or inches).
5. Specify the number of units you are ordering in the "Quantity" field.
6. If applicable, select your preferred material from the "Material preference" dropdown (Wood, Metal, or Synthetic).
7. Optionally, provide any special instructions or finish details in the "Finish" field.
8. If you have a desired delivery date, select it in the "Desired delivery date" field.
9. Enter your internal account code for charging purposes in the "Billing code" field.
10. If you have any special instructions or custom framing requirements, provide them in the "Special instructions" field.

## Field-by-Field Explanation
- **Requester name** (1, text, required): The name of the person placing the order.
- **Contact email** (2, email, required): A valid email address for order confirmations.
- **Item type** (3, select_one, required): Select "Frame" or "Canvas" to specify the type of product.
- **Dimensions** (4, text, required): Enter the width and height of the item in cm or inches (e.g., 50 x 60).
- **Quantity** (5, number, required): The number of units you are ordering.
- **Material preference** (6, select_one, optional): Select your preferred material (Wood, Metal, or Synthetic).
- **Finish** (7, text, optional): Optionally, provide any special instructions or finish details.
- **Desired delivery date** (8, date, optional): Enter a date for when you would like the item delivered.
- **Billing code** (9, text, required): Enter your internal account code for charging purposes.
- **Special instructions** (10, text, optional): Provide any special instructions or custom framing requirements.
