# Pre Launch Sample Distribution Order Form - Help Guide
## Purpose
This form is used to collect information for pre-launch sample distribution orders. It includes details such as the customer's request date, customer information, sample requests, shipping details, and order status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields marked as "required".
2. Enter the customer's request date in the "Request Date" field.
3. Enter the customer's name in the "customer" field.
4. Enter the customer's email address in the "Email" field.
5. Enter the customer's phone number in the "Phone" field (optional).
6. Select the samples you would like to request in the "sample_request" field.
7. Enter the shipping address in the "Shipping" field.
8. Add any additional notes in the "notes" field (optional).
9. Select the order status in the "Product Order Status" field.
10. Select the customer status in the "customer_status" field.
11. Select the payment status in the "Payment Status" field.
12. Enter the product order ID and customer order ID.
13. Enter the total order cost.
14. Enter the customer cost (optional).
15. Enter the shipping cost (optional).
16. Add any notes for the admin in the "Notes for Admin" field (optional).
17. Add any payment notes in the "Payment Notes" field (optional).
18. Select the order status in the "Order Status" field.
19. Enter any order details in the "Order Details" field (optional).

## Field-by-Field Explanation

* **Request Date**: Enter the date when you would like to make a request for the product samples.
* **customer**: Enter the customer's name.
* **Email**: Enter the customer's email address.
* **Phone**: Enter the customer's phone number (optional).
* **sample_request**: Select the samples you would like to request.
* **Shipping**: Enter the shipping address.
* **notes**: Add any additional notes (optional).
* **Request Date**: Enter the date when you would like to make a request for the product samples (Note: This field is similar to the "Request Date" field above, but it is optional and is used for additional information).
* **Customer Order**: Select the customer order.
* **Customer Notes**: Add any notes for the customer (optional).
* **Shipping Details**: Enter any additional shipping details (optional).
* **Shipping Notes**: Add any notes for shipping (optional).
* **Product Order Status**: Select the order status.
* **Customer Status**: Select the customer status.
* **Payment Status**: Select the payment status.
* **Product Order ID**: Enter the product order ID.
* **Customer Order ID**: Enter the customer order ID.
* **Total Order Cost**: Enter the total order cost.
* **Customer Cost**: Enter the customer cost (optional).
* **Shipping Cost**: Enter the shipping cost (optional).
* **Notes for Admin**: Add any notes for the admin (optional).
* **Payment Notes**: Add any payment notes (optional).
* **Order Status**: Select the order status.
* **Order Details**: Enter any additional order details (optional).
