# Color Street Spring - Help Guide
## Purpose
The Color Street Spring form is designed to collect information for a product order. Please refer to the "Internal Note" section for more information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the customer's name.
2. Enter a valid email address for order communication.
3. Choose the product selection.
4. Select the color or pattern of the product.
5. Specify the number of units to be ordered.
6. Choose a shipping method.
7. Enter the delivery address (if shipping is selected).
8. Enter a promo code if available.
9. Add any additional order notes (optional).

## Field-by-Field Explanation
• **Customer name** (Customer name, text, required): Enter the customer's full name.
• **Email address** (Email address, email, required): Enter a valid email address for order communication.
• **Product selection** (Product selection, text, required): Choose the product to be ordered.
• **Color choice** (Color choice, text, optional): Select a specific color or pattern of the product.
• **Quantity** (Quantity, number, required): Enter the number of units to be ordered.
• **Shipping method** (Shipping method, select_one, required): Choose the shipping option (Standard, Express, Local pickup).
• **Delivery address** (Delivery address, text, optional): Enter the full delivery address if shipping is selected.
• **Promo code** (Promo code, text, optional): Enter a promo code if available.
• **Order notes** (Order notes, text, optional): Add any additional instructions for the order.
