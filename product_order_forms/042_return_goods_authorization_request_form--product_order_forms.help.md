# Return Goods Authorization Request Form - Help Guide
## Purpose
The Return Goods Authorization Request Form is used to request authorization for returning products that are faulty or incorrect. This form helps in capturing necessary information required for the return process.

## How To Complete This Form
To complete this form, follow the steps below:

1. Enter a brief description of the issue with the product in the "Reason for Return" field.
2. Select the date you intend to return the product.
3. Enter the amount of products you wish to return.
4. Choose the status of your return request (Authorized, Pending, or Rejected).
5. If your reason for return is "Other", provide a detailed description in the "Other Reason" field.
6. Optionally, you can enter the tool assigned to you for this return process.
## Field-by-Field Explanation
* **Return Goods Authorization** (id: 1, text, optional):
	+ Enter a brief description of the issue with the product.
* **Reason for Return** (id: 2, select_one, optional):
	+ Select the reason for return from the provided options: Faulty products, Incorrect orders, or Other.
	+ If you select "Other", please enter a detailed description in the "Other Reason" field.
* **Return Date** (id: 3, date, optional):
	+ Enter the date you intend to return the product.
* **Return Amount** (id: 4, number, optional):
	+ Enter the amount of products you wish to return.
* **Return Status** (id: 5, select_multiple, optional):
	+ Choose the status of your return request from the provided options: Authorized, Pending, or Rejected.
* **Other Reason** (id: 6, text, optional):
	+ If you selected "Other" in the Reason for Return field, enter a detailed description of your reason for return.
* **Assigned Tool** (id: 7, text, optional):
	+ Optionally, enter the tool assigned to you for this return process.
## Tips
* Make sure to enter accurate information in the "Reason for Return" field, as this will help expedite the return process.
* If you are unsure about any field, please contact our support team for assistance.
