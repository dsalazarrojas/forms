# Afterpay Fashion Accessories Order Form - Help Guide

## Purpose
The purpose of this form is to collect essential information required for processing an order of fashion accessories after a sale has been agreed upon.

## How To Complete This Form
1. Please fill in the required fields as follows:
- **Full name**: Enter the name of the person or organization placing the order.
- **Email**: Enter the email address to be used for order confirmation and communication.
- **Item description**: Include the product's SKU and color to ensure accurate identification.
- **Quantity**: Enter the number of items being ordered.
- **Use Afterpay**: Select whether to use the Afterpay payment method or not.
- **Shipping address**: Enter the shipping address accurately, including the street, city, and postal code.
- Optionally, you may select whether a gift wrap is needed or not, and leave any additional **Order notes** for the seller.

## Field-by-Field Explanation
- **Full name**: A field for the name of the customer, which is required for order processing and communication.
- **Email**: Enter a valid email address to receive order confirmations and updates.
- **Item description**: Enter a clear description of the item(s) being ordered, including the product's SKU and color for accurate identification.
- **Quantity**: Enter the number of items being ordered. Please ensure this is accurate to avoid confusion during delivery.
- **Use Afterpay**: This field determines the payment method used. Selecting 'True' indicates the use of the Afterpay payment method.
- **Shipping address**: Enter the address where the order should be shipped, including the street, city, and postal code for accurate delivery.
- **Gift wrap required**: If the order is a gift, select 'True' to indicate that gift wrap is required.
- **Order notes**: Leave any additional instructions or comments about the order in this field.

## Tips
- Please double-check all fields for accuracy before submitting the form.
- Ensure that you have entered a valid email address for order communication.
- If you need to make any changes or updates to your order, please contact the seller directly.
- If you have any questions or concerns, do not hesitate to reach out for assistance.
