# Retailer Product Placement Request Form - Help Guide
## Purpose
The purpose of this form is to submit a product placement request to our team for processing. Fill out this form to request placement of your products in our stores.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the product name in the "Product Name" field.
2. Provide a brief description of the product in the "Product Description" field.
3. If you have an image of the product, paste the URL in the "Product Image URL" field.
4. Select the preferred placement area for your product from the dropdown list in the "Preferred Placement Area" field.
5. Choose the start date for the placement in the "Start Date" field.
6. Select the start time for the placement in the "Start Time" field.
7. Choose the end date for the placement in the "End Date" field.
8. Select the end time for the placement in the "End Time" field.

## Field-by-Field Explanation
* **Product Name** (`product_name`, text, required: no): Enter the name of the product you are requesting to be placed.
* **Product Description** (`product_description`, text, required: no): A brief description of the product to help our team better understand your request.
* **Product Image URL** (`product_image_url`, text, required: no): If you have an image of the product, paste the URL here.
* **Preferred Placement Area** (`preferred_placement_area`, select_multiple, required: no):
	+ Front face outlets
	+ Side glass front
	+ End caps
	+ Other
* **Start Date** (`start_date`, date, required: no): Choose the date you would like the product to be placed.
* **Start Time** (`start_time`, time, required: no): Select the time for the product placement.
* **End Date** (`end_date`, date, required: no): Choose the date the product placement should end.
* **End Time** (`end_time`, time, required: no): Select the time the product placement should end.

Note: All fields marked as "required: no" are optional. Please fill out only the fields that are relevant to your request.
