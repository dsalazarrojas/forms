# Return Shipment Form - Help Guide
## Purpose
The Return Shipment Form is used to capture information about a return shipment, including details about the recipient, shipment details, and any notes or comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "Start" button to begin the form.
2. Enter the recipient's name in the "Recipient Name" field.
3. Enter the recipient's phone number in the "Recipient Phone" field.
4. Provide a reason for the return in the "Reason for Return" field.
5. Add any additional comments or notes in the "Notes" field.
6. Click on the "Submit" button to complete the form.

## Field-by-Field Explanation
* **Recipient Name** (`recipient_name`, text, required): Enter the name of the person receiving the shipment.
* **Recipient Phone** (`recipient_phone`, text, required): Enter the phone number of the person receiving the shipment.
* **Reason for Return** (`reason_for_return`, text, required): Enter the reason why the shipment is being returned.
* **Notes** (`notes`, note, optional): Add any additional comments or notes about the return shipment.

## Tips
* Ensure you provide accurate information about the recipient and reason for return.
* Enter any relevant comments or notes to help facilitate the return process.
* Make sure to submit the form after completing all required fields.
