# Takeout Bag Branding Order Form - Help Guide
## Purpose
This form is used to collect information for takeout bag branding orders from restaurants. It is essential to fill out this form accurately to ensure that your order is processed correctly.

## How To Complete This Form
1. Fill out the "Restaurant Name" field with the name of the restaurant where the takeout bag branding order is being placed.
2. Choose whether the bag has any "bag_preferences" (yes or no).
3. (Optional) Upload a "bag_file" to specify the design for the bag.
4. (Optional) Upload a "logo" for the branding.
5. Select the "payment_method" (yes or no) to indicate if the order is a payment method that will be used.
6. In the "order_details" field, provide any additional details about the order.
7. Add any "notes" about the order in this field.
8. Enter the email address of the person placing the order in the "email" field.
9. Enter the phone number of the person placing the order in the "phone" field.
10. Enter the address of the person placing the order in the "address" field.
11. Enter the city of the person placing the order in the "city" field.
12. Select the "state" (yes or no) to indicate if the order is for a specific state.
13. Enter the zip code of the person placing the order in the "zip_code" field.
14. Select whether the order should be reviewed (yes or no).
15. Enter the date of the order in the "order_date" field.
16. Enter the time of the order in the "order_time" field.
17. Add any comment about the order time in the "order_time_comment" field.
18. Enter the quantity of the order in the "quantity" field.
19. Enter the unit price of the order in the "unit_price" field.
20. Enter the subtotal of the order in the "subtotal" field.
21. Select the tax rate (good or fair).
22. Add any comment about the tax rate in the "tax_rate_comment" field.
23. Enter the total cost of the order in the "total" field.
24. Add any additional notes about the order in the "notes2" field.
25. Enter the name of the person assigned to handle the order in the "assigned_to" field.
26. Select the payment status (active or inactive).

## Field-by-Field Explanation

* **Restaurant Name** (text, optional): Enter the name of the restaurant where the takeout bag branding order is being placed.
* **Bag Preferences** (select multiple, optional): Choose if the bag has any specific preferences (yes or no).
* **Upload Bag File** (text, optional): (Optional) Upload a design file for the bag.
* **Upload Logo** (text, optional): (Optional) Upload a logo design for the branding.
* **Payment Method** (select one, required): Select if the order is a payment method (yes or no).
* **Order Details** (text, optional): Add any additional details about the order.
* **Notes** (note, optional): Add any notes about the order.
* **Email** (email, optional): Enter the email address of the person placing the order.
* **Phone** (text, optional): Enter the phone number of the person placing the order.
* **Address** (text, optional): Enter the address of the person placing the order.
* **City** (text, optional): Enter the city of the person placing the order.
* **State** (select one, optional): Select if the order is for a specific state (yes or no).
* **Zip Code** (text, optional): Enter the zip code of the person placing the order.
* **Review** (select multiple, required): Select if the order should be reviewed (yes or no).
* **Order Date** (date, required): Enter the date of the order.
* **Order Time** (time, required): Enter the time of the order.
* **Order Time Comment** (text, optional): Add any comment about the order time.
* **Quantity** (number, required): Enter the quantity of the order.
* **Unit Price** (number, required): Enter the unit price of the order.
* **Subtotal** (text, required): Enter the subtotal of the order.
* **Tax Rate** (select one, optional): Select the tax rate (good or fair).
* **Tax Rate Comment** (text, optional): Add any comment about the tax rate.
* **Total** (text, required): Enter the total cost of the order.
* **Notes2** (note, optional): Add any additional notes about the order.
* **Assigned To** (text, optional): Enter the name of the person assigned to handle the order.
* **Payment Status** (select one, required): Select the payment status (active or inactive).

## Tips
- Make sure to fill out the required fields accurately to ensure your order is processed correctly.
- If you are unsure about any field, refer to the "Notes" field for any additional information.
- The "Review" field is required for orders, make sure to select the correct option.
- The "Order Date" and "Order Time" fields are required for orders, make sure to fill them out accurately.
- The "Quantity", "Unit Price", "Subtotal", and "Total" fields are required for orders, fill them out accurately.
