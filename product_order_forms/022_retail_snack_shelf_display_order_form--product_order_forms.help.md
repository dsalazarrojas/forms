# Retail Snack Shelf Display Order Form - Help Guide
## Purpose
This form is designed to capture information about retailers' snack shelf display orders. Retailers can use this form to provide details about their orders, including retailer information, delivery information, merchandising details, and additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your retailer name in the "Retailer Name" field (Page 2, id: 2).
2. Enter the delivery date and time in the "Delivery Date" and "Delivery Time" fields (Page 3, id: 4 and 6, respectively).
3. Select the merchandising details for your order:
	* Select "Yes" or "No" for "Merchandising Item" (Page 5, id: 8).
	* Enter a description of the item in the "Item Description" field (Page 6, id: 10).
	* Select the item type (e.g., "Yes" or "No") (Page 7, id: 12).
	* Select the item subtype (e.g., "Yes" or "No") (Page 7, id: 14).
	* Select multiple item sizes (e.g., "Yes" or "No") (Page 8, id: 16).
	* Select the item color (e.g., "Yes" or "No") (Page 8, id: 18).
4. Enter any additional merchandising information in the "Notes" field (Page 9, id: 20).
5. Enter your retailer's contact information:
	* Enter your retailer's name and email address in the "Retailer Information" fields (Page 11, id: 22 and 24).
	* Enter your retailer's phone number in the "Phone" field (Page 12, id: 26).

## Field-by-Field Explanation
* **Retailer Name (Page 2, id: 2)**: Enter your company name as the retailer.
* **Delivery Date (Page 3, id: 4)**: Enter the date you would like to have the order delivered.
* **Delivery Time (Page 3, id: 6)**: Enter the time you would like to have the order delivered.
* **Merchandising Item (Page 5, id: 8)**: Select "Yes" or "No" to indicate if the order includes merchandising items.
* **Item Description (Page 6, id: 10)**: Enter a description of the item ordered.
* **Item Type (Page 7, id: 12)**: Select "Yes" or "No" to indicate the type of item.
* **Item Subtype (Page 7, id: 14)**: Select "Yes" or "No" to indicate the subtype of item.
* **Item Size (Page 8, id: 16)**: Select multiple item sizes (e.g., "Yes" or "No").
* **Item Color (Page 8, id: 18)**: Select "Yes" or "No" to indicate the color of item.
* **Notes (Page 9, id: 20)**: Enter any additional information about the order.
* **Retailer Information Retailer Notes (Page 11, id: 22)**: Enter any notes or comments about your retailer information.
* **Email (Page 12, id: 24)**: Enter your retailer's email address.
* **Phone (Page 12, id: 26)**: Enter your retailer's phone number.
