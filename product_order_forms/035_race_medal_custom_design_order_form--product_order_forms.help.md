# race_medal_custom_design_order_form - Help Guide
## Purpose
The "race_medal_custom_design_order_form" is a form designed to collect information for creating a custom order for a race medal. This form guides the user through the process of specifying medal specifications, artwork requirements, and order information to ensure accurate and timely production.

## How To Complete This Form
1. Review the form carefully to ensure you have all the necessary information.
2. Fill in the required fields (marked as "required" in the form).
3. Select the relevant options for each field.
4. Double-check your entries before submitting the form.

## Field-by-Field Explanation

* **Medal Specs** (`1`, `text`, required): Enter a brief description of the medal specifications.
* **Artwork** (`2`, `text`, optional): Enter a brief description of the artwork.
* **Artwork Type** (`3`, `select_multiple`, optional): Select the type of artwork required, such as Logo, Icon, Emblem, Badge, or Sticker.
* **Artwork Description** (`4`, `text`, optional): Enter a brief description of the artwork.
* **Medal Size** (`5`, `select_one`, optional): Select the size of the medal from the available options.
* **Medal Shape** (`6`, `select_one`, optional): Select the shape of the medal from the available options.
* **Medal Material** (`7`, `select_one`, optional): Select the material of the medal from the available options.
* **Medal Color** (`8`, `select_multiple`, optional): Select the color of the medal from the available options.
* **Quantity** (`9`, `number`, optional): Enter the quantity of medals required.
* **Quantity Unit** (`10`, `select_one`, optional): Select the unit of quantity from the available options.
* **Artwork Size** (`11`, `select_multiple`, optional): Select the size of the artwork from the available options.
* **Artwork Color** (`12`, `select_multiple`, optional): Select the color of the artwork from the available options.
* **Artwork Size Option** (`13`, `select_multiple`, optional): Select the size option for the artwork from the available options.
* **Medal Text** (`14`, `text`, optional): Enter the text to be displayed on the medal.
* **Order Comments** (`15`, `text`, optional): Enter any additional comments about the order.
* **Order Date** (`16`, `date`, optional): Enter the date of the order.
* **Order Time** (`17`, `time`, optional): Enter the time of the order.
* **Order Time Zone** (`18`, `select_one`, optional): Select the time zone of the order from the available options.
* **Artwork Orientation** (`19`, `select_multiple`, optional): Select the orientation of the artwork from the available options.
* **Medal Type** (`20`, `select_one`, optional): Select the type of medal from the available options.
* **Medal Text Alignment** (`21`, `select_multiple`, optional): Select the alignment of the text on the medal from the available options.
* **Artwork Text** (`22`, `text`, optional): Enter the text to be displayed on the artwork.
* **Artwork Orientation Size** (`23`, `select_multiple`, optional): Select the size of the artwork orientation from the available options.
* **Artwork Text Color** (`24`, `select_multiple`, optional): Select the color of the text on the artwork from the available options.
* **Artwork Text Alignment** (`25`, `select_multiple`, optional): Select the alignment of the text on the artwork from the available options.

## Tips
* Please ensure that you have all necessary information before submitting the form.
* If you have any questions or concerns, please contact our support team.
* We strive to produce high-quality medals, but please allow 2-3 business days for production and delivery.
