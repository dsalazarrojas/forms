# Helmet Decal Request Form - Help Guide
## Purpose
This form is used to request a helmet decal for a team. It gathers information about the team's artwork, colors, sizing, and other specific details to ensure the correct design and production of the decal.

## How To Complete This Form
1. Fill out the team artwork field by selecting the artwork that best represents the team. You can select multiple options.
2. Choose the team colors that the team would like to feature on the decal. Select only one color.
3. Determine if the team requires specific sizing for the decal. Select one option.
4. Enter the number of decal quantities required.
5. Enter the team's name.
6. Enter any additional team artwork details.
7. Enter any specific details about the team's sizing requirements.
8. Enter any specific details about the team's colors.
9. Enter any special notes about the order.
10. Enter the team's email address.
11. Enter the team's phone number.
12. Choose whether the decal should be assigned to a person or group.
13. Choose which production tool to use for the decal.
14. Choose the type of team to be produced.
15. Choose the type of decal to be produced.
16. Choose the team's color scheme.
17. Enter the decal size.
18. Enter the decal quantity.
