# Sustainability Report Printing Order Form - Help Guide
## Purpose

This form is designed to collect information from users for sustainability report printing orders. It is intended for users to provide details about their order, including report format, delivery instructions, and delivery schedule.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill out the "Report PDF" field on page 1 to specify the report format.
2. Provide any additional delivery instructions in the "Delivery Details" field on page 2.
3. Add any additional information relevant to the order in the "Order Information" field on page 3.
4. Specify a date for the delivery of the report in the "Delivery Date" field on page 4.
5. Specify a time for the delivery of the report in the "Delivery Time" field on page 5.

## Field-by-Field Explanation

* **Report PDF** (`report_pdf`, text, required/optional): Enter the report format, e.g., "Sustainability Report 2022".
* **Delivery Details** (`delivery_details`, text, optional): Provide any additional delivery instructions, such as address or shipping method.
* **Order Information** (`order_info`, text, optional): Add any additional information relevant to the order, e.g., order quantity or special requests.
* **Delivery Date** (`delivery_date`, date, optional): Specify a date for the delivery of the report, in the format YYYY-MM-DD.
* **Delivery Time** (`delivery_time`, time, optional): Specify a time for the delivery of the report, in the format HH:MM (24 hour format).
