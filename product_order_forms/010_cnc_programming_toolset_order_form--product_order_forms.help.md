# CNC Programming Toolset Order Form - Help Guide
## Purpose
The CNC Programming Toolset Order Form is designed to gather information from customers interested in purchasing the CNC programming toolset. This form helps us understand their needs and preferences for the toolset, allowing us to provide the best possible experience and support.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the order date from the calendar and enter the date when you would like to receive the toolset.
2. Enter the customer's name, email address, phone number, and organization name.
3. Choose the type of organization (e.g., Manufacturing Company, Training Center, etc.).
4. Select the CNC programming toolset package you wish to order (e.g., Basic, Professional, etc.).
5. Choose the software components you need (e.g., G-Code Generator, CAM Software, etc.).
6. Select the types of CNC machines you support.
7. Enter the number of licenses you need.
8. Choose the type of license (e.g., Single-User, Multi-User, etc.).
9. If you require training, select "Yes" and enter the number of trainees.
10. Enter the billing address (street address).
11. Enter the city, state/province, and postal code for the billing address.
12. If you need to ship the toolset to a different address, enter the shipping address (street address).
13. Select a delivery date needed.
14. If applicable, enter a company purchase order number.
15. Enter an estimated budget (if you have one).

## Field-by-Field Explanation

* **Order Date (1)**: Enter the date when you would like to receive the toolset.
* **Customer Name (2)**: Full name of the person placing the order.
* **Email Address (3)**: Email address of the person placing the order.
* **Phone Number (4)**: Phone number of the person placing the order.
* **Organization Name (5)**: Name of the company or training center.
* **Organization Type (6)**: Select the type of organization (e.g., Manufacturing Company, Training Center, etc.).
* **CNC Programming Toolset Package (7)**: Select the toolset you wish to order (e.g., Basic, Professional, etc.).
* **Software Components Needed (8)**: Select all applicable software modules (e.g., G-Code Generator, CAM Software, etc.).
* **CNC Machine Types You Support (9)**: Select the types of CNC machines you support.
* **Number of Licenses (10)**: Enter the number of software licenses you need.
* **License Type (11)**: Choose the type of license (e.g., Single-User, Multi-User, etc.).
* **Training Required (12)**: If you need training, select "Yes".
* **Number of Trainees (13)**: If you selected "Yes" for training, enter the number of trainees.
* **Billing Address (14)**: Enter the street address for billing.
* **City (15)**: Enter the city for the billing address.
* **State/Province (16)**: Enter the state or province for the billing address.
* **Postal Code (17)**: Enter the postal code for the billing address.
* **Shipping Address (18)**: If different from the billing address, enter the shipping address (street address).
* **Delivery Date Needed (19)**: Select the date when you need to receive the toolset.
* **Special Requirements or Notes (20)**: Enter any custom modifications or additional needs.
* **Preferred Payment Method (21)**: Select the preferred payment method (e.g., Credit Card, Wire Transfer, etc.).
* **Company Purchase Order Number (22)**: If applicable, enter the company purchase order number.
* **Estimated Budget (23)**: Enter an estimated budget (if you have one).
