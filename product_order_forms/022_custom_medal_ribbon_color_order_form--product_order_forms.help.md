# Custom Medal Ribbon Color Order Form - Help Guide
## Purpose

This form is used to collect information for a custom medal ribbon color order. It is designed to be used by school staff or organization members to place orders for custom medal ribbons.

## How To Complete This Form

*   Fill out the form carefully and accurately.
*   Ensure you have all the necessary information before proceeding.
*   Use this form only when you have a new order to place, and not for updating or canceling an existing one.
*   Review and submit the form only after filling out all the required fields.

## Field-by-Field Explanation

*   **Ribbon Color**: Select whether the medal ribbon requires a specific color or not. This field is required.
*   **Quantity**: Enter the number of medal ribbons required. This field is required.
*   **Shipping Details**: Enter any additional shipping instructions or requirements. This field is required.
*   **Payment**: Enter payment information such as the payment method and amount. This field is required.
*   **School**: If the order is placed on behalf of a school or organization, enter the name of the school or organization. This field is optional.
*   **Sports Club**: If the order is for a sports club, enter the name of the sports club. This field is optional.
*   **Organizer**: If the order is organized by a specific person, enter their name. This field is optional.
*   **Award Supplier**: If the order is from an award supplier, enter their name. This field is optional.
*   **Email**: Enter the email address of the contact person. This field is required.
*   **Phone**: Enter the contact phone number. This field is required.
*   **Date**: Enter the date for the event or order placement. This field is required.
*   **Time**: Enter the time for the event or order placement. This field is required.
*   **Ribbon Color**: Select the color of the medal ribbon. This field is required.
*   **Ribbon Size**: Enter the size of the medal ribbon. This field is required.
*   **Ribbon Type**: Select the type of medal ribbon required. This field is required.
*   **Ribbon Material**: Select the material of the medal ribbon. This field is required.
*   **Ribbon Shape**: Select the shape of the medal ribbon. This field is required.
*   **Ribbon Pattern**: Select whether a specific pattern is required or not. This field is optional.
*   **Note**: Add any additional comments or notes about the order. This field is optional.
*   **Form Type**: Select the type of form being used. This field is optional.
*   **Ribbon Color Form**: Select whether a custom color form is used. This field is optional.
*   **Ribbon Size Form**: Enter the size of the custom color form. This field is optional.
*   **Ribbon Shape Form**: Select the shape of the custom color form. This field is optional.
*   **Ribbon Pattern Form**: Select whether a specific pattern is required or not for the custom color form. This field is optional.
