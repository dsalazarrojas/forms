# Store Compliance Poster Order Form - Help Guide

## Purpose
This form is used to order compliance posters for stores, ensuring they have all the necessary information for poster production and installation.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the store details, including the store id.
2. Enter the store's address.
3. Provide shipping details.
4. Select the necessary compliance posters (e.g., ADA Poster, Emergency Exit Plan, Sexual Harassment).
5. Choose the total number of posters needed.
6. Add any order comments if necessary.
7. Select the assigned tool for order fulfillment (e.g., chatjimmy, chatjimmy2).
8. Add any additional order notes.
9. Optionally, enter the unique identifier for this order form.

## Field-by-Field Explanation

* **Store Details (Text)** (`store_details`, Text, Required: No): Enter the name of your store.
* **Store ID (Number)** (`store_id`, Number, Required: No): Enter the unique ID number assigned to your store.
* **Store Address (Text)** (`address`, Text, Required: No): Enter your store's physical address.
* **Shipping Details (Text)** (`shipping_details`, Text, Required: No): Enter the shipping details, if different from the store address.
* **Shipping Address (Text)** (`shipping_address`, Text, Required: No): Enter the shipping address for the compliance posters.
* **Shipping City (Text)** (`shipping_city`, Text, Required: No): Enter the city for the shipping address.
* **Shipping State (Text)** (`shipping_state`, Text, Required: No): Enter the state for the shipping address.
* **Shipping Zip (Text)** (`shipping_zip`, Text, Required: No): Enter the zip code for the shipping address.
* **Compliance Poster (Select Multiple)** (`compliance_posters`, Select Multiple, Required: No): Choose the compliance posters needed for your store (e.g., ADA Poster, Emergency Exit Plan, Sexual Harassment).
* **Total Posters (Number)** (`total_posters`, Number, Required: No): Enter the total number of posters needed.
* **Order Comments (Text)** (`order_comments`, Text, Required: No): Add any comments or notes about your order.
* **Assigned Tool (Select One)** (`assigned_tool`, Select One, Required: No): Choose the tool assigned for order fulfillment (e.g., chatjimmy, chatjimmy2).
* **Order Notes (Text)** (`order_notes`, Text, Required: No): Add any additional notes about your order.
* **Store Compliance Poster Order Form ID (Number)** (`store_compliance_poster_order_form_id`, Number, Required: No): Enter a unique identifier for this order form.
* **Created By (Text)** (`created_by`, Text, Required: No): Enter the name of the person who created this order form.
* **Created At (Date)** (`created_at`, Date, Required: No): Enter the date and time this order form was created.
* **Updated At (Date)** (`updated_at`, Date, Required: No): Enter the date and time this order form was last updated.

Note: All fields with "Required: No" are optional and can be left blank if not applicable.
