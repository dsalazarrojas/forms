# Factory LED Display Board Order Form - Help Guide
## Purpose
The Factory LED Display Board Order Form is used to create and manage factory LED display board orders.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the **Category** in the "Category" field.
2. Describe the **Description** of the order.
3. Assign the **Assigned to** field to the relevant person or tool.
4. Optionally, enter the **Form ID** if you have it.
5. If necessary, attach a file for the **Output File**.

## Field-by-Field Explanation
* **Category** (`category`, text, required): Enter the category of the product being ordered.
* **Description** (`description`, text, required): Enter a brief description of the product being ordered.
* **Assigned to** (`assigned_tool`, text, required): Assign the product to the relevant person or tool.
* **Form ID** (`form_ids`, number, optional): Enter the ID of the form, if you have it.
* **Output File** (`output_file`, text, optional): Attach a file that will be used to generate the order board.

## Tips
* Double-check your entries for accuracy and completeness before submitting the form.
* Ensure that you have attached the correct Output File if necessary.
* If you are unsure about any field, please ask your supervisor or contact the relevant person for clarification.
