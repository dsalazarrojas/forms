# Shelf Talker Printing Order Form - Help Guide
## Purpose
The Shelf Talker Printing Order Form is designed to collect necessary information for creating a printing order. This form helps us understand the client's requirements for printing, including product selection, delivery details, and payment information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all relevant information about the client's requirements.
2. Select the products you want to include in the order.
3. Provide details about the artwork files required for the print job.
4. Fill out your delivery details, including the date and time you expect to receive the order.
5. Enter your payment information for the order.
6. Add any notes about the order that you would like to include in the communication with the client.
7. Enter the client's email address and phone number so we can contact them for updates and tracking.

## Field-by-Field Explanation
- **Print Shop Info** (Print Shop Info, text, optional): Please enter the print shop name and contact information where the order will be executed.
- **Product Selections** (Product Selections, select multiple, optional): Select all the products that you want to include in the order. This includes 'Yes' for products you want to include and 'No' for products you don't want to include.
- **Artwork Files** (Artwork Files, select multiple, optional): Select all the artwork files required for the print job. This includes 'Yes' for files you want to include and 'No' for files you don't want to include.
- **Delivery Details** (Delivery Details, text, optional): Enter the date and time you expect to receive the order. This will help us ensure we can deliver the order on time.
- **Payment Info** (Payment Info, text, optional): Enter your payment information, including the payment method and amount.
- **Order Notes** (Order Notes, note, optional): Add any notes you would like to include in the communication with the client.
- **Customer Email** (Customer Email, email, optional): Enter the client's email address so we can contact them for updates and tracking.
- **Customer Phone** (Customer Phone, text, optional): Enter the client's phone number so we can contact them for urgent matters.
