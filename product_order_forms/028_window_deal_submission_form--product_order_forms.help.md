# window_deal_submission_form - Help Guide
## Purpose
The "window_deal_submission_form" is a form used to collect information and data related to window deals, including property details, deal types, and supporting documents.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the property details section with the relevant information about the property.
2. Select the type of deal being submitted (e.g. new installation, repair, or replacement).
3. Enter the window specs if necessary.
4. Upload any supporting documents related to the deal.
5. Write any additional notes regarding the deal (deal notes).
6. Write any additional notes regarding the sales process (sales notes).
7. Provide the contractor details (if applicable).
8. Provide the dealer details (if applicable).
9. Indicate the property status (active or sold).

## Field-by-Field Explanation

* **Property Details** (`property_details`, text, required: false)
	+ Enter the relevant information about the property.
* **Deal Type** (`deal_type`, select_one, required: false)
	+ Select the type of deal being submitted (e.g. new installation, repair, or replacement).
* **Window Specs** (`window_specs`, text, required: false)
	+ Enter any additional specs about the windows.
* **Supporting Documents** (`supporting_documents`, text, required: false)
	+ Upload any supporting documents related to the deal.
* **Deal Notes** (`deal_notes`, text, required: false)
	+ Write any additional notes regarding the deal.
* **Sales Notes** (`sales_notes`, text, required: false)
	+ Write any additional notes regarding the sales process.
* **Contractor Details** (`contractor_details`, text, required: false)
	+ Enter any relevant information about the contractor involved in the deal.
* **Dealer Details** (`dealer_details`, text, required: false)
	+ Enter any relevant information about the dealer involved in the deal.
* **Property Status** (`property_status`, select_one, required: false)
	+ Indicate the current status of the property (e.g. active or sold).

## Tips
* Ensure that all required fields are filled out correctly to avoid any submission issues.
* If a field is marked as optional, it is up to your discretion whether to fill it out or not.
* Be as specific and detailed as possible when filling out the form.
