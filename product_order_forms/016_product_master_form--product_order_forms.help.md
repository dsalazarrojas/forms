# Product Master Form - Help Guide
## Purpose
The Product Master Form is designed to manage and track product information, providing a centralized platform for product managers or administrators to update and monitor product details, evaluation results, and tracking units.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the appropriate options for each field, as necessary.
2. Enter relevant product details, such as product information and proposed products.
3. Update tracking units and tracking unit options as needed.
4. Select the release status of the product.

## Field-by-Field Explanation

* **Product details**: Select the correct options for the product's details.
* **Product info**: Enter relevant product information.
* **Evaluation results**: Select the correct option for the product's evaluation results.
* **Release status**: Select the correct option for the product's release status.
* **Proposed product**: Enter proposed product details.
* **Product tracking units**: Select the correct options for the product's tracking units.
* **Product tracking units 1, 2, 3, 4, 5, 6**: Select the correct options for each tracking unit.
* **Tracking units**: Select the correct option for the overall tracking units.
* **Product release form**: Select the correct option for the product release form.
* **Proposed product 1, 2, 3**: Enter proposed product details for each product.
* **Tracking unit 1, 2, 3**: Select the correct options for each tracking unit.

## Tips
* Make sure to select the correct options for each field to ensure accurate product information.
* Enter relevant product details and proposed products as needed.
* Update tracking units and tracking unit options as necessary to reflect changes in product status.
