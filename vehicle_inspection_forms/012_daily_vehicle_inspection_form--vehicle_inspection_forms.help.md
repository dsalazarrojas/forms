# Daily Vehicle Inspection Form - Help Guide
## Purpose
The Daily Vehicle Inspection Form is used to document the current state of a vehicle, identify potential issues, and ensure that all relevant information is collected in a consistent manner.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the vehicle's current condition and note any issues or concerns.
2. Provide a description of the vehicle's condition for each of the listed areas.
3. Select "Yes" or "No" for each area that is not applicable or not relevant.
4. Enter any comments or notes about the vehicle's condition.
5. Review and submit the form once complete.

## Field-by-Field Explanation

* **Vehicle Condition**: Describe the overall condition of the vehicle. For example, "The vehicle is currently in good condition, with no major issues."
* **Engine Oil Level**: Check the engine oil level and report if it is at or below the minimum recommended level.
* **Transmission**: Check the transmission and report if it is functioning properly or if any issues are present.
	+ Select "Yes" if the transmission is functioning properly.
	+ Select "No" if there are issues with the transmission.
* **Brake Pads**: Check the brake pads and report their condition.
* **Air Conditioning**: Check the air conditioning system and report if it is functioning properly or if any issues are present.
* **Tire Condition**: Check the tire condition and report any issues or concerns.
* **Vehicle Safety**: Check the vehicle's overall safety features, including:
	+ Select "Yes" for any feature that is functioning properly.
	+ Select "No" if any feature is not present or is not functioning properly.
* **Vehicle Make**: Enter the vehicle's make (e.g. Toyota, Ford, etc.).
