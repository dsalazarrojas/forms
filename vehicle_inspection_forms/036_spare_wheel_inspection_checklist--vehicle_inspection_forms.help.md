# Spare Wheel Inspection Checklist - Help Guide

## Purpose
The Spare Wheel Inspection Checklist is designed to gather information about the condition and status of a vehicle's spare wheel. This form is used to inspect the spare wheel and ensure it's in good working condition. The form is divided into several fields that need to be completed for a thorough inspection.

## How To Complete This Form

1. Select all the relevant inspection categories that apply to the spare wheel:
	* Spare Wheel Inspections: Choose whether the spare wheel has been inspected or not.
	* Vehicle Type: Choose the type of vehicle the spare wheel is attached to.
	* Wheel Rotation: Check if the wheel has been rotated or replaced recently.
2. Describe the location of the spare wheel:
	* Spare Wheel Location: Enter the location of the spare wheel in the vehicle, e.g., trunk, under the seat, etc.
3. Check the condition of the spare wheel:
	* Wheel Position: Enter a brief description of the spare wheel's position, e.g., centered, slightly loose, etc.
	* Spare Wheel Condition: Check if the spare wheel has any damage or issues that need attention.
	* Spare Wheel Pressure Test: If applicable, input the pressure reading for the spare wheel.
4. Add any additional comments or notes:
	* Notes: Enter any additional information about the inspection that may be relevant.

## Field-by-Field Explanation

* **Spare Wheel Inspections**: Select whether the spare wheel has been inspected or not. This field is required.
* **Vehicle Type**: Choose the type of vehicle the spare wheel is attached to. This field is optional but helps identify the vehicle's characteristics.
* **Spare Wheel Location**: Enter the location of the spare wheel in the vehicle. This field is optional but helps with inspection accuracy.
* **Wheel Rotation**: Check if the wheel has been rotated or replaced recently. This field is optional but helps with maintenance planning.
* **Wheel Position**: Enter a brief description of the spare wheel's position, e.g., centered, slightly loose, etc. This field is optional but provides additional context for the inspection.
* **Spare Wheel Condition**: Check if the spare wheel has any damage or issues that need attention. This field is optional but ensures the wheel is in good working condition.
* **Spare Wheel Pressure Test**: If applicable, input the pressure reading for the spare wheel. This field is optional but provides important information for maintenance and safety purposes.
* **Notes**: Enter any additional information about the inspection that may be relevant. This field is optional but helps with future reference and record-keeping.
