# School Bus Cleaning Checklist Form - Help Guide
## Purpose
The School Bus Cleaning Checklist Form is used to track the cleanliness and maintenance status of school buses. This form helps ensure that all buses are properly cleaned and inspected as required.

## How To Complete This Form
1. Review the form carefully before starting.
2. Fill in the bus details such as make and year, exterior and interior conditions.
3. Select the emergency equipment, safety inspection, cleaning supplies, and vehicle inspection status as applicable.
4. Choose the cleaning frequency and certification status of the bus.
5. Fill in the certification date and vehicle inspection dates.
6. Add any additional notes or comments.
7. Save and submit the form.

## Field-by-Field Explanation
- **Bus Make** (`bus_make`, text, optional): Enter the make of the bus.
  This is to help identify the bus's model.
- **Bus Year** (`bus_year`, number, optional): Enter the year of the bus.
  This is to track the age of the bus.
- **Exterior Wheels** (`exterior_wheels`, text, optional): Describe the condition of the bus's wheels.
- **Exterior Windows** (`exterior_windows`, text, optional): Describe the condition of the bus's windows.
- **Interior Seats** (`interior_seats`, text, optional): Describe the condition of the bus's seats.
- **Interior Doors** (`interior_doors`, text, optional): Describe the condition of the bus's doors.
- **Exterior Doors** (`exterior_doors`, text, optional): Describe the condition of the bus's exterior doors.
- **Interior Floors** (`interior_floor`, text, optional): Describe the condition of the bus's floors.
- **Exterior Body** (`exterior_body`, text, optional): Describe the condition of the bus's body.
- **Emergency Equipment** (`emergency_equipment`, select multiple, optional): Select which emergency equipment is present on the bus.
  Fire extinguisher, First aid kit, Safety vest.
- **Safety Inspection** (`safety_inspection`, select multiple, optional): Select which safety inspections have been performed.
  Stop sign, Reflective tape, Fire alarm.
- **Bus Cleaning Supplies** (`bus_cleaning_supplies`, select multiple, optional): Select the cleaning supplies used on the bus.
  Soap, Paper towels, Trash bags.
- **Cleaning Frequency** (`cleaning_frequency`, select one, optional): Select the frequency of cleaning for the bus.
  Daily, Weekly, Monthly.
- **Bus Cleaning Certified** (`bus_cleaning_certified`, select one, optional): Select the certification status for the bus cleaning.
  Certified, Not Certified.
- **Certification Date** (`certification_date`, date, optional): Enter the date of the certification.
- **Notes** (`notes`, note, optional): Add any additional notes or comments about the bus.
- **Category** (`category`, text, optional): Select the category of the bus.
- **Vehicle Inspection Certified** (`vehicle_inspection_certified`, select one, optional): Select the certification status for the vehicle inspection.
  Certified, Not Certified.
- **Vehicle Inspection Frequency** (`vehicle_inspection_frequency`, select one, optional): Select the frequency of vehicle inspection.
  Daily, Weekly, Monthly.
- **Vehicle Inspection Last Date** (`vehicle_inspection_last_date`, date, optional): Enter the date of the last vehicle inspection.
- **Vehicle Inspection Next Date** (`vehicle_inspection_next_date`, date, optional): Enter the date of the next vehicle inspection.
- **Vehicle Inspection Status** (`vehicle_inspection_status`, select one, optional): Select the status of the vehicle inspection.
  Passed, Failed, Pending.
- **Vehicle Inspection Comment** (`vehicle_inspection_comment`, text, optional): Add any comments about the vehicle inspection.
- **Vehicle Inspection Report** (`vehicle_inspection_report`, text, optional): Add any additional notes about the vehicle inspection.
- **Vehicle Status** (`vehicle_status`, select one, optional): Select the status of the vehicle.
  Available, Available for Inspection, In Transit, Out of Service.
- **Additional Notes** (`notes2`, note, optional): Add any additional notes or comments about the vehicle.
