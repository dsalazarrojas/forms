# Straight Truck Pre Trip Inspection Form - Help Guide
## Purpose
The Straight Truck Pre Trip Inspection Form is used to inspect and report the condition of a straight truck vehicle before it starts its journey. This helps ensure the vehicle is safe to operate and reduces the risk of accidents or vehicle breakdowns.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the vehicle status from the options provided. If the vehicle is active and ready for operation, choose "Active". If it's not, choose "Inactive".
2. Choose the type of vehicle from the options provided, such as Dry Van, Reefer Van, Conventional, or Tanker.
3. Provide any specific cargo securement details if applicable.
4. Check the vehicle's condition and select "Yes" if it's in good condition, or "No" if it's not.
5. Inspect and report the condition of each system, such as brake system, steering system, suspension system, etc.
6. Provide details on the trailer connections, trailer brakes, coupling device, coupling device location, cargo securement location, trailer mounting, trailer coupling, trailer condition, and cargo securement condition.
7. Ensure all fields are completed before submitting the form.

## Field-by-Field Explanation
* **Vehicle Status (1)**: Select the current status of the vehicle. Choose "Active" if the vehicle is ready for operation, or "Inactive" if it's not.
* **Vehicle Type (2)**: Choose the type of vehicle, such as Dry Van, Reefer Van, Conventional, or Tanker.
* **Cargo Securement (3)**: Provide any specific cargo securement details.
* **Vehicle Condition (4)**: Check if the vehicle is in good condition. Select "Yes" if it is, or "No" if it's not.
* **Vehicle Status Condition (5)**: This field is similar to Vehicle Status, but it seems to be a duplicate. Please ignore this field.
* **Tire Condition (6)**: Check if the vehicle's tires are in good condition. Select "Yes" if they are, or "No" if they're not.
* **Brake System (7)**: Inspect and report the condition of the brake system. Select "Normal Operation" if it's working as expected, "Warning" if there's an issue, or "Malfunction" if it's not working at all.
* **Parking Brakes (8)**: Check if the parking brakes are working properly. Select "Normal Operation" if they are, "Stiff" if they're difficult to engage, or "Malfunction" if they're not working.
* **Trailer Connections (9)**: Check if the trailer connections are secure. Select "Yes" if they are, or "No" if they're not.
* **Trailer Brakes (10)**: Inspect and report the condition of the trailer brakes. Select "Yes" if they're working as expected, or "No" if they're not.
* **Steering System (11)**: Check if the steering system is in good condition. Select "Yes" if it is, or "No" if it's not.
* **Suspension System (12)**: Inspect and report the condition of the suspension system. Select "Yes" if it's working as expected, or "No" if it's not.
* **Wheel Condition (13)**: Check if the wheels are in good condition. Select "Yes" if they are, or "No" if they're not.
* **Coupling Device (14)**: Check if the coupling device is secure. Select "Yes" if it is, or "No" if it's not.
* **Coupling Device Location (15)**: Check if the coupling device is located properly. Select "Yes" if it is, or "No" if it's not.
* **Cargo Securement Location (16)**: Provide details on the cargo securement location.
* **Trailer Mounting (17)**: Check if the trailer is properly mounted on the vehicle. Select "Yes" if it is, or "No" if it's not.
* **Trailer Coupling (18)**: Check if the trailer coupling is secure. Select "Yes" if it is, or "No" if it's not.
* **Trailer Condition (19)**: Inspect and report the condition of the trailer. Select "Yes" if it's in good condition, or "No" if it's not.
* **Cargo Securement Condition (20)**: Check if the cargo securement is in good condition. Select "Yes" if it is, or "No" if it's not.

## Tips
