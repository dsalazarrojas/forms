# Pre Delivery Inspection Form - Help Guide
## Purpose
The Pre Delivery Inspection Form is used to collect detailed information about a vehicle during the pre-delivery inspection process. This information is likely used to ensure that the vehicle meets certain standards or requirements before it is delivered to customers.

## How To Complete This Form
- Please fill out each field accurately and thoroughly.
- Make sure to review each field carefully before submitting the form.

## Field-by-Field Explanation
* **Vehicle Year** (`vehicle_year`): A numeric field to input the year of the vehicle.
* **Vehicle Make** (`vehicle_make`): A text field to input the make of the vehicle.
* **Vehicle Model** (`vehicle_model`): A text field to input the model of the vehicle.
* **Vehicle License Number** (`vehicle_license_number`): A text field to input the license number of the vehicle.
* **Odometer Reading** (`odometer_reading`): A numeric field to input the odometer reading of the vehicle.
* **Vehicle Color** (`vehicle_color`): A text field to input the color of the vehicle.
* **Vehicle Condition** (`vehicle_condition`): A text field to input the condition of the vehicle.
* **Vehicle Odometer** (`vehicle_odometer`): A numeric field to input the vehicle's odometer reading.
* **Vehicle Engine Type** (`vehicle_engine_type`): A select-one field to choose the type of engine the vehicle has. Options include: Gas, Electric, Hybrid, and Other.
* **Vehicle Transmission** (`vehicle_transmission`): A select-multiple field to choose the type of transmission the vehicle has. Options include: Manual, Automatic, CVT/Semiautomatic, and Other.
* **Vehicle Type** (`vehicle_type`): A text field to input the type of vehicle.
* **Vehicle Weight** (`vehicle_weight`): A numeric field to input the weight of the vehicle.
* **Vehicle Length in Meters** (`vehicle_length_in_meters`): A numeric field to input the length of the vehicle in meters.
* **Vehicle Width in Meters** (`vehicle_width_in_meters`): A numeric field to input the width of the vehicle in meters.
* **Vehicle Height in Meters** (`vehicle_height_in_meters`): A numeric field to input the height of the vehicle in meters.
* **Vehicle Wheel Base** (`vehicle_wheel_base`): A numeric field to input the wheel base of the vehicle.
* **Vehicle Wheel Radius** (`vehicle_wheel_radius`): A numeric field to input the wheel radius of the vehicle.
* **Vehicle Track** (`vehicle_track`): A numeric field to input the track of the vehicle.
* **Vehicle Front Overall Length** (`vehicle_front_overall_length`): A numeric field to input the front overall length of the vehicle.
* **Vehicle Rear Overall Length** (`vehicle_rear_overall_length`): A numeric field to input the rear overall length of the vehicle.
* **Vehicle Wheel Base Width** (`vehicle_wheel_base_width`): A numeric field to input the wheel base width of the vehicle.
* **Vehicle Wheel Base Offset** (`vehicle_wheel_base_offset`): A numeric field to input the wheel base offset of the vehicle.
* **Vehicle Wheel Base Angle** (`vehicle_wheel_base_angle`): A numeric field to input the wheel base angle of the vehicle.
* **Vehicle Overall Length** (`vehicle_overall_length`): A numeric field to input the overall length of the vehicle.
