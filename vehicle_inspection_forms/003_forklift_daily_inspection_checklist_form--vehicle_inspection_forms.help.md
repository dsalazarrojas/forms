# Forklift Daily Inspection Checklist Form - Help Guide

## Purpose
The Forklift Daily Inspection Checklist Form is designed to streamline the process of inspecting and maintaining forklifts, ensuring they are in good working order and ready for use.

## How To Complete This Form
1. Review the forklift's pre-startup checks, ensuring all required items are functioning correctly.
	* Select all items that apply:
		+ Forklift horn is functioning correctly
		+ Forklift is securely fastened to the load
		+ All safety devices are in working order
		+ All controls are functioning correctly
2. Conduct an operation check during use, ensuring the forklift operates smoothly and safely.
	* Select all items that apply:
		+ Check for any issues during the operation
		+ Forklift is running smoothly
		+ All safety devices are functioning correctly
		+ Controls are operating properly
3. Perform a post-operation check, verifying all safety devices and controls are functioning correctly.
	* Select all items that apply:
		+ Check for any issues after the operation
		+ Forklift is parked correctly
		+ All safety devices are functioning correctly
		+ Controls are in the correct position
4. Record any maintenance issues found during the inspection.
	* Enter any maintenance issues in the text field.
5. Enter the inspection date and time.
	* Date: MM/dd/yy
	* Time: HH:MM (24-hour format)
6. Add any further notes about the inspection.
	* Enter additional notes in the text field.
7. Select the forklift operator conducting the inspection.
	* Select from the provided options: John, Jane, or Jimmy
8. Select the department or team responsible for the forklift.
	* Select from the provided options: chatjimmy, warehouse, distribution, or center
