# Automotive Vehicle Safety Standards Audit Form - Help Guide
## Purpose
The Automotive Vehicle Safety Standards Audit Form is designed to assess the safety standards of an automotive vehicle. It helps identify areas that require attention to ensure the vehicle meets the required safety standards.

## How To Complete This Form

1. Review the vehicle's documentation and inspect the vehicle's components as per the provided sections.
2. For each section, use the assessment options to evaluate the condition of the component or system.
3. Select the relevant option for each field based on the observed condition.
4. Enter any safety recommendations or concerns in the "Safety Recommendations" field.

## Field-by-Field Explanation

* **Audit Information** (`2`, `audit_date`, required): Enter the date of the audit.
* **Audit Time** (`3`, `audit_time`, required): Enter the time of the audit.
* **Auditor Name** (`4`, `auditor_name`, required): Enter the name of the auditor.
* **Vehicle Information** (`5`, `section_header_vehicle`, required): This section is a header for the vehicle information section.
* **Vehicle Year** (`6`, `vehicle_year`, required): Enter the year of the vehicle.
* **Vehicle Make** (`7`, `vehicle_make`, required): Enter the make of the vehicle.
* **Vehicle Model** (`8`, `vehicle_model`, required): Enter the model of the vehicle.
* **Vehicle VIN** (`9`, `vehicle_vin`, required): Enter the Vehicle Identification Number (VIN) of the vehicle.
* **Current Mileage** (`10`, `mileage`, required): Enter the current mileage of the vehicle.
* **Brake System Assessment** (`11`, `section_header_brake`, required): This section is a header for the brake system assessment.
* **Brake Pad Condition** (`12`, `brake_pad_condition`, required): Evaluate the condition of the brake pads using the provided options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Needs Replacement
* **Brake Fluid Level** (`13`, `brake_fluid_level`, required): Evaluate the brake fluid level using the provided options:
	+ Full
	+ Adequate
	+ Low
	+ Critical
* **Brake Lines and Hoses Condition** (`14`, `brake_lines_condition`, required): Evaluate the condition of the brake lines and hoses using the provided options:
	+ Excellent
	+ Good
	+ Fair
	+ Leaking
	+ Damaged
* **Suspension and Steering** (`15`, `section_header_suspension`, required): This section is a header for the suspension and steering assessment.
* **Suspension System Condition** (`16`, `suspension_condition`, required): Evaluate the condition of the suspension system using the provided options:
	+ Excellent
	+ Good
	+ Fair
	+ Worn
	+ Damaged
* **Tire Condition and Tread Depth** (`17`, `tire_condition`, required): Evaluate the condition and tread depth of the tires using the provided options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Unsafe
* **Steering Responsiveness** (`18`, `steering_responsiveness`, required): Evaluate the steering responsiveness using the provided options:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Lighting and Visibility** (`19`, `section_header_lights`, required): This section is a header for the lighting and visibility assessment.
* **Headlights Function and Brightness** (`20`, `headlights_condition`, required): Evaluate the condition of the headlights using the provided options:
	+ Both Working
	+ One Damaged
	+ Both Damaged
	+ Both Inoperative
* **Tail Lights and Brake Lights** (`21`, `tail_lights`, required): Evaluate the condition of the tail lights and brake lights using the provided options:
	+ All Working
	+ Some Not Working
	+ All Inoperative
* **Windshield Wipers and Washer** (`22`, `windshield_wipers`, required): Evaluate the condition of the windscreen wipers and washer using the provided options:
	+ Excellent
	+ Good
	+ Fair
	+ Not Working
* **Overall Safety Assessment** (`23`, `section_header_overall`, required): This section is a header for the overall safety assessment.
* **Overall Safety Rating** (`24`, `safety_rating`, required): Evaluate the overall safety rating of the vehicle using the provided options:
	+ Pass - Safe
	+ Pass with Maintenance
	+ Fail - Unsafe
	+ Fail - Immediate Action Required
* **Safety Recommendations** (`25`, `safety_recommendations`, required): Enter any safety recommendations or concerns for the vehicle.

## Tips

* Always inspect the vehicle thoroughly and accurately evaluate the condition of each component or system.
* Use the assessment options to provide a clear and concise rating for each field.
* Enter any additional safety recommendations or concerns in the "Safety Recommendations" field.
