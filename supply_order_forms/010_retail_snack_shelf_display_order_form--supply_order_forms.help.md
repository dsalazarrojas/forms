# Retail Snack Shelf Display Order Form - Help Guide
## Purpose
This form is used to place an order for retail snack shelf displays. It captures essential information about the order, including store details, delivery information, merchandising details, and payment terms.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the store's name and address in the **store_name** and **store_address** fields respectively.
2. Enter the store's city, state, and zip code in the **city**, **state**, and **zip** fields respectively.
3. Enter the date of delivery in the **delivery_date** field in MM/DD format.
4. Enter the time of delivery in the **delivery_time** field in 24-hour format.
5. In the **merchandising_details** field, enter any details about the merchandising, such as any promotions or special requests.
6. In the **order_details** field, enter any additional comments or details about the order.
7. In the **delivery_instructions** field, enter any special instructions for the delivery of the order.
8. Select the frequency of the order from the options in the **order_frequency** field.
9. Enter the total amount of the order in the **order_amount** field.
10. Select the products ordered from the options in the **product_list** field.
11. Enter any payment terms in the **payment_terms** field.
12. Enter any additional comments or notes about the order in the **notes** field.
13. Enter the store manager's name in the **store_manager_name** field.
14. Enter the store manager's phone number in the **store_manager_phone** field (if required).
15. Enter the store manager's email address in the **store_manager_email** field (if required).
16. Enter the store manager's external phone number in the **store_manager_ext_phone** field (if required).
17. Enter the store manager's external email address in the **store_manager_ext_email** field (if required).

## Field-by-Field Explanation

* **title**: The name of the order, which should be clearly stated as "Retail Snack Shelf Display Order Form".
* **store_name**: The name of the store, which should include the name of the store.
* **store_address**: The physical address of the store, which should include the street address, city, state, and zip code.
* **city**: The city of the store, which should include the city name.
* **state**: The state of the store, which should include the two-letter state abbreviation.
* **zip**: The zip code of the store, which should include the 5-digit zip code.
* **delivery_date**: The date of delivery, which should be entered in MM/DD format.
* **delivery_time**: The time of delivery, which should be entered in 24-hour format.
* **merchandising_details**: Any details about the merchandising, such as any promotions or special requests.
* **order_details**: Any additional comments or details about the order.
* **delivery_instructions**: Any special instructions for the delivery of the order.
* **contact_phone**: The store's phone number, which should be entered if required.
* **contact_email**: The store's email address, which should be entered if required.
* **order_frequency**: The frequency of the order, which should be selected from the options "Weekly", "Bi-Weekly", or "Monthly".
* **order_amount**: The total amount of the order, which should be entered as a number.
* **product_list**: A list of products ordered, which should be selected from the available options.
* **payment_terms**: Any payment terms, such as any discounts or special payment arrangements.
* **notes**: Any additional comments or notes about the order.
* **order_comments**: Any additional comments or notes about the order (if required).
* **store_manager_name**: The store manager's name, which should be entered.
* **store_manager_phone**: The store manager's phone number, which should be entered if required.
* **store_manager_email**: The store manager's email address, which should be entered if required.
* **store_manager_ext_phone**: The store manager's external phone number, which should be entered if required.
* **store_manager_ext_email**: The store manager's external email address, which should be entered if required.
* **order_total**: The total amount of the order, which should be entered as a number.
