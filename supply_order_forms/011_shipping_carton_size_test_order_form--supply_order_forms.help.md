# shipping_carton_size_test_order_form - Help Guide
## Purpose
The shipping carton size test order form is used to collect information for shipping carton size testing orders. 

## How To Complete This Form
- To complete this form, please fill in the required and optional fields as needed.
- Review each field carefully before submitting the form.
- Ensure that all fields have been filled in completely and accurately.

## Field-by-Field Explanation

* **Test Request** (`test_request`, text, required: false): This field is used to enter a brief description of the test request.
* **Test Carton Size** (`test_canton_size`, select_one, required: false): This field is used to select the size of the carton being tested. Choose from the list of options provided.
* **Delivery Preference** (`delivery_preference`, select_multiple, required: false): This field is used to select the preferred delivery option. Select one or more options from the list.
* **Delivery Date** (`delivery_date`, date, required: false): This field is used to enter the date of delivery. Please use the correct format for dates.
* **Delivery Time** (`delivery_time`, time, required: false): This field is used to enter the time of delivery. Please use the correct format for times.
* **Order Details** (`order_details`, note, required: false): This is a text field for entering any additional information regarding the order.
* **Contact Email** (`contact_email`, email, required: false): This field is used to enter the contact email for the order.
* **Contact Phone** (`contact_phone`, text, required: false): This field is used to enter the contact phone number for the order.
* **Vendor Name** (`vendor_name`, text, required: false): This field is used to enter the name of the vendor for the order.
