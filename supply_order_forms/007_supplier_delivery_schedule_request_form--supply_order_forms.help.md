# Supplier Delivery Schedule Request Form - Help Guide
## Purpose
The Supplier Delivery Schedule Request Form is used to request a delivery schedule from a supplier for the delivery of products or services. This form is a standard form that all suppliers are required to fill out for internal tracking and reporting purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form completely and accurately.
2. Make sure all required fields are filled out.
3. If you're not sure about any field, you can ask for help or clarification.

## Field-by-Field Explanation
### **First Name** (`first_name`, text, not required)
First name of the supplier.
### **Last Name** (`last_name`, text, not required)
Last name of the supplier.
### **Email** (`email`, email, not required)
Enter the email address of the supplier. This will be used as the contact email for communication purposes.
### **Phone Number** (`phone`, text, not required)
Phone number of the supplier. This will be used as the contact phone number for communication purposes.
### **Start Date** (`start_date`, date, not required)
Date when the delivery is expected to start.
### **End Date** (`end_date`, date, not required)
Date when the delivery is expected to end.
### **Supplier Name** (`supplier_name`, select_one, not required)
Confirm that you are a supplier by selecting 'Yes'. If you are not a supplier, select 'No'.
### **Delivery Date** (`delivery_date`, date, not required)
Date when the delivery is expected to take place.
### **Supplier ID** (`supplier_id`, number, not required)
Supplier ID number assigned to the supplier.
### **Delivery Time** (`delivery_time`, time, not required)
Time when the delivery is expected to take place.
### **Delivery Details** (`delivery_details`, note, not required)
Additional details about the delivery.
### **Confirm Delivery** (`confirm_delivery`, select_multiple, not required)
Confirm that you have received the delivery by selecting 'Yes'. If you haven't received the delivery, select 'No'.
### **Supplier Delivery Status** (`supplier_delivery_status`, select_one, not required)
Select the current status of the delivery: Active or Inactive.

Tips: If you're unsure about any field, you can ask for clarification. Please ensure that all required fields are filled out and that all information is accurate and up-to-date.
