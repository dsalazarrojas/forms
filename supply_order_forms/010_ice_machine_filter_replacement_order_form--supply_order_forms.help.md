# Ice Machine Filter Replacement Order Form - Help Guide
## Purpose
This form is designed for customers or users to order replacement filters for their ice machines.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the machine's ID, which is a unique identifier for the machine that needs a replacement filter.
2.  Enter the customer's name, contact number, and email address for communication.
3.  Choose the order date when the order is being placed.
4.  Check if the filter model is required.
5.  Enter the number of filters ordered.
6.  Enter the total number of parts needed for the order.
7.  Enter the cost of the filters being ordered.
8.  Enter the total cost of the order.
9.  Select the shipping option (Shipping, Local Pickup, In-Store Pickup).
10.  Add any additional notes about the order.
11.  Check if the order is assigned to a specific person.
12.  Check if the order is assigned to a specific person.
13.  Leave the created at, updated at, and created by fields blank, as these are automatically filled by the system.

## Field-by-Field Explanation
*   **Machine Id** (`machine_id`, `number`, not required): Enter the machine's unique ID for the replacement filter order.
*   **Customer Name** (`customer_name`, `text`, not required): Enter the customer's name here.
*   **Contact Number** (`contact_number`, `text`, not required): Enter the customer's phone number here.
*   **Email** (`email`, `email`, not required): Enter the customer's email address here.
*   **Order Date** (`order_date`, `date`, not required): Enter the date the order is being placed.
*   **Filter Model** (`filter_model`, `select_one`, not required): Check if the filter model is required.
*   **Filter Quantity** (`filter_quantity`, `number`, not required): Enter the number of filters ordered.
*   **Total Parts** (`total_parts`, `number`, not required): Enter the total number of parts needed for the order.
*   **Filter Cost** (`filter_cost`, `number`, not required): Enter the cost of the filters being ordered.
*   **Total Amount** (`total_amount`, `number`, not required): Enter the total cost of the order.
*   **Shipping** (`shipping`, `select_multiple`, not required): Select the shipping option (Shipping, Local Pickup, In-Store Pickup).
*   **Notes** (`notes`, `note`, not required): Add any additional information about the order.
*   **Assigned To** (`assigned_to`, `select_one`, not required): Check if the order is assigned to a specific person.
*   **Assigned By** (`assigned_by`, `select_one`, not required): Check if the order is assigned to a specific person.
*   **Created At** (`created_at`, `time`, not required): Leave blank, this field is automatically filled by the system.
*   **Updated At** (`updated_at`, `time`, not required): Leave blank, this field is automatically filled by the system.
*   **Created By** (`created_by`, `select_one`, not required): Leave blank, this field is automatically filled by the system.
