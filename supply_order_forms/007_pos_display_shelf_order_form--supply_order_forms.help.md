# POS Display Shelf Order Form - Help Guide

## Purpose
The POS Display Shelf Order Form is a template designed for managing orders for point of sale (POS) display shelving. This form helps you collect and track customer information, order details, and other relevant data associated with the order.

## How To Complete This Form
To complete this form, follow these steps:

1. **Order Details** (Page 1):
	* Enter a brief description of the order.
2. **Customer Information** (Page 2):
	* Enter the customer's name.
	* Enter the customer's email address.
	* Enter the customer's phone number.
	* Enter the customer's address.
3. **Order Total** (Page 3):
	* Enter the total value of the order.
4. **Customer Notes** (Page 4):
	* Enter any additional comments or notes related to the customer.
5. **Assigned To** (Page 5):
	* Select the person or team member assigned to handle the order.
6. **Order Comments** (Page 6):
	* Enter any comments or notes related to the order.
7. **Order Form Selection** (Page 7):
	* Select the type of order form to use (e.g., order form 1, order form 2, or order form 3).
8. **Product Information** (Page 8):
	* Enter the product name or description.
	* Enter the quantity ordered.
	* Enter the unit price.
9. **Order Form 2 Selection** (Page 9):
	* Select the type of order form 2 to use (e.g., order form 2 or order form 3).
10. **Order Form 3 Selection** (Page 10):
	* Select the type of order form 3 to use (e.g., order form 3 or order form 4).

## Field-by-Field Explanation

* **Order Details**:
	+ Enter a brief description of the order. This field is optional.
* **Customer Information**:
	+ **Customer Name** (`customer_name_1`): Enter the customer's name.
	+ **Customer Email** (`customer_email_1`): Enter the customer's email address.
	+ **Customer Phone** (`customer_phone_1`): Enter the customer's phone number.
	+ **Customer Address** (`customer_address_1`): Enter the customer's address.
* **Order Total**:
	+ **Order Total** (`order_total_1`): Enter the total value of the order. This field is not required.
* **Customer Notes**:
	+ **Customer Notes** (`customer_notes_1`): Enter any additional comments or notes related to the customer. This field is not required.
* **Assigned To**:
	+ **Assigned To** (`assigned_to_1`): Select the person or team member assigned to handle the order.
* **Order Comments**:
	+ **Order Comments** (`order_comments_1`): Enter any comments or notes related to the order.
* **Order Form Selection**:
	+ **Order Form** (`order_form_1`): Select the type of order form to use (e.g., order form 1, order form 2, or order form 3). This field has three options.
* **Product Information**:
	+ **Product** (`product_1`): Enter the product name or description.
	+ **Quantity** (`quantity_1`): Enter the quantity ordered.
	+ **Unit Price** (`unit_price_1`): Enter the unit price.
* **Order Form 2 Selection**:
	+ **Order Form 2** (`order_form_2`): Select the type of order form 2 to use (e.g., order form 2 or order form 3). This field has two options.
* **Order Form 3 Selection**:
	+ **Order Form 3** (`order_form_3`): Select the type of order form 3 to use (e.g., order form 3 or order form 4). This field has two options.

Remember to review each field carefully and complete them according to your needs.
