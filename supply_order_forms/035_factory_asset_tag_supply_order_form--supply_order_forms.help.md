# Factory Asset Tag Supply Order Form - Help Guide
## Purpose
This form is used to create a request for ordering factory assets or supplies.

## How To Complete This Form
1. Select "Yes" for "Select Item" to indicate that you are creating a new order.
2. Enter a brief description of the item in the "description" field.
3. For items that require a specific tag, select the corresponding "Item Tag" field.
4. Enter the date of the order in the "Order Date" field.
5. Enter the time of the day you are requesting the order in the "Order Time" field.
6. Enter the quantity of the item you are requesting in the "Item Quantity" field.
7. Select the "Order Frequency" field to indicate how often you would like to receive the ordered items.
8. Select the "Order Status" field to indicate the current status of the order.
9. Use the "Order Note" field to add any additional comments or details about the order.

## Field-by-Field Explanation
* **Select Item** (factory_asset_tag_supply_order_form_1, select_one, required): Select "Yes" to indicate that you are creating a new order.
* **description** (item_description_1, text, required): Enter a brief description of the item.
* **Item Tag** (item_tag_1, select_one, required): Select the item tag that applies to the item you are ordering.
* **Order Date** (order_date_1, date, required): Enter the date of the order.
* **Order Time** (order_time_1, time, required): Enter the time of the order.
* **Item Quantity** (item_quantity_1, number, required): Enter the quantity of the item you are ordering.
* **Order Frequency** (order_frequency_1, select_one, required): Select the frequency of the order (Daily, Weekly, Monthly).
* **Order Status** (order_status_1, select_one, required): Select the status of the order (Active, In Progress, Completed).
* **Order Note** (order_note_1, note, required): Add any additional comments or details about the order.
