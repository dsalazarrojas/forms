# Race Course Supply Kit Order Form - Help Guide
## Purpose
The Race Course Supply Kit Order Form is used to order a Race Course Supply Kit, which is a collection of supplies and equipment needed for a racing event or course.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Race Course Supply Kit (page 1) field with the name of the kit you wish to order.
2. Select the delivery date you would like the kit to be delivered on (page 2).
3. If you have any special instructions for the delivery, enter them in the Special Instructions field (page 3).
4. Choose the type of race course supply kit you need from the options provided (page 4).

## Field-by-Field Explanation
* **Race Course Supply Kit (race_course_supply_kit, text, optional)**: Enter the name of the Race Course Supply Kit you wish to order.
* **Delivery Date (delivery_date, date, optional)**: Select the date on which you would like the kit to be delivered.
* **Special Instructions (special_instructions, note, optional)**: Enter any special instructions or notes you have for the delivery.
* **Race Course Supply Kit Type (race_course_supply_kit_type, select_multiple, optional)**: Choose the type of race course supply kit you need. Options include:
	+ 5K
	+ Marathons
	+ School Run
	+ Other
