# Factory Equipment Fastener Order Form - Help Guide
## Purpose
This form is used to collect information for fastener orders from customers.

## How To Complete This Form

1.  Fill out the form with all required and optional fields, following the instructions for each field below.
2.  Once complete, submit the form to the designated team or contact.

## Field-by-Field Explanation

*   **Factory Equipment Fastener Order Form**: This is the main title of the form.
*   **Customer Name** (`customer_name`, text, **required**: **false**): Enter the name of the customer who is placing the order.
*   **Order Type** (`order_type`, select one, **required**: **false**): Select the type of order (Standard, Custom, Special).
*   **Order Date** (`order_date`, date, **required**: **false**): Enter the date of the order.
*   **Order Time** (`order_time`, time, **required**: **false**): Enter the time of the order.
*   **Order Quantity** (`order_quantity`, number, **required**: **false**): Enter the quantity of the order.
*   **Order Description** (`order_description`, text, **required**: **false**): Enter a brief description of the order.
*   **Customer PO** (`customer_po`, text, **required**: **false**): Enter the customer's purchase order number or any other reference number.
*   **Order Priority** (`order_priority`, select one, **required**: **false**): Select the priority of the order (High, Medium, Low).
*   **Delivery Date** (`delivery_date`, date, **required**: **false**): Enter the date for delivery.
*   **Delivery Time** (`delivery_time`, time, **required**: **false**): Enter the time for delivery.
*   **Delivery Location** (`delivery_location`, text, **required**: **false**): Enter the location for delivery.
*   **Order Status** (`order_status`, select one, **required**: **false**): Select the status of the order (Open, Shipped, Cancelled).
*   **Shipping Cost** (`shipping_cost`, number, **required**: **false**): Enter the shipping cost.
*   **Total Cost** (`total_cost`, number, **required**: **false**): Enter the total cost of the order.
*   **Customer Contact** (`customer_contact`, text, **required**: **false**): Enter any relevant contact information for the customer.
*   **Order Notes** (`order_notes`, text, **required**: **false**): Enter any additional notes about the order.
*   **Customer Email** (`customer_email`, email, **required**: **false**): Enter the customer's email address.
*   **Customer Phone** (`customer_phone`, text, **required**: **false**): Enter the customer's phone number.
*   **Customer Address** (`customer_address`, text, **required**: **false**): Enter the customer's address.
*   **Delivery Note** (`delivery_note`, text, **required**: **false**): Enter any notes for delivery.
*   **Fastener Type** (`fastener_type`, select one, **required**: **false**): Select the type of fastener (Bolt, Screw, Nut, Washer).
*   **Fastener Size** (`fastener_size`, text, **required**: **false**): Enter the size of the fastener.
*   **Fastener Material** (`fastener_material`, text, **required**: **false**): Enter the material of the fastener.
*   **Fastener Description** (`fastener_description`, text, **required**: **false**): Enter a brief description of the fastener.

## Tips

*   Ensure all fields are filled out completely and accurately to avoid delays or errors in processing the order.
*   Double-check the order status before initiating the process to avoid duplicating an existing order.
*   For orders with special requirements, please provide additional information or notes in the "Order Notes" field.
