# Athletic Tape And Wrap Supply Order Form - Help Guide
## Purpose
This form is designed for athletic facilities or teams to order supplies of athletic tape and wraps. It gathers essential information for processing the order, including product selection, delivery details, and billing information.

## How To Complete This Form
- Read through each section carefully before filling out the form.
- Ensure you provide accurate and complete information for each field.
- If a field is not required, you can skip it; however, this may impact the processing of your order.

## Field-by-Field Explanation

*   **Order Date (2)** (`Date`, **required**): Date of this supply order.
    Please enter the date on which you are placing this order.
*   **Order Number (3)** (`Text`, **optional**): Reference number for this order.
    This field is for your reference only and not required for order processing.
*   **Required Delivery Date (4)** (`Date`, **required**): When do you need the supplies?
    Indicate the date by which you need the supplies delivered.
*   **Facility/Team Name (6)** (`Text`, **required**): Name of athletic facility or team.
    Enter the name of your facility or team.
*   **Contact Person Name (7)** (`Text`, **required**): Name of authorized contact.
    Enter the name of the person authorized to receive the order.
*   **Email Address (8)** (`Email`, **required**): Email Address.
    Enter the email address of the contact person.
*   **Phone Number (9)** (`Text`, **required**): Phone Number.
    Enter the contact person's phone number.
*   **Delivery Address (10)** (`Text`, **required**): Street address for delivery.
    Enter the address where the supplies should be delivered.
*   **City (11)** (`Text`, **required**): City.
    Enter the city for the delivery address.
*   **State (12)** (`Text`, **required**): State.
    Enter the state for the delivery address.
*   **Zip Code (13)** (`Text`, **required**): ZIP Code.
    Enter the zip code for the delivery address.
*   **Athletic Tape Type (15)** (`Select Multiple`, **required**): Which type(s) of tape needed?
    Choose the type(s) of athletic tape you require (White Athletic Tape, Elastic Tape, Kinesiology Tape, Waterproof Tape, Pre-Wrap).
*   **Athletic Tape Quantity (16)** (`Number`, **required**): Number of rolls/units needed.
    Enter the quantity of each required tape type.
*   **Wrap/Bandage Type (17)** (`Select Multiple`, **optional**): Which wrap types needed?
    Choose the type(s) of wraps you require (Compression Wraps, Elastic Bandages, Cohesive Bandages, ACE Bandages, Ankle Supports).
*   **Wrap Quantity (18)** (`Number`, **optional**): Number of wraps needed.
    Enter the quantity of each required wrap type.
*   **Preferred Tape Width (19)** (`Select One`, **required**): Standard widths available.
    Choose the preferred width for the athletic tape (0.5 inch, 1 inch, 1.5 inch, 2 inch).
*   **Special Requirements (20)** (`Text`, **optional**): Any specific brands or specifications?
    Enter any special requirements or specifications for the order.
*   **Bulk Discount Eligible (21)** (`Select One`, **optional**): Is this order eligible for bulk pricing?
    Choose whether the order is eligible for bulk pricing ('Yes', 'No').
*   **Billing Address Same as Delivery (23)** (`Select One`, **required**): Billing Address Same as Delivery?
    If the billing address is the same as the delivery address, choose 'Yes', otherwise choose 'No'.
*   **Billing Address (24)** (`Text`, **optional**): If different from delivery address.
    Enter the billing address if different from the delivery address.
*   **Purchase Order Number (25)** (`Text`, **optional**): If applicable.
    Enter the purchase order number if applicable.
