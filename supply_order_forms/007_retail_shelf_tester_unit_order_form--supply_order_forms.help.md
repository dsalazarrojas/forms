# Retail Shelf Tester Unit Order Form - Help Guide
## Purpose
This form is used to create a new order for retail shelf test units. It collects information from customers to facilitate the order process.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the unit type from the options provided.
2. Enter the quantity of units ordered.
3. Enter the unit price.
4. Choose the order date for the units.
5. Enter the name of the unit being tested.
6. Select whether the unit number is present.
7. Enter the customer's name.
8. Enter the customer's email address.
9. Enter the customer's phone number.
10. Enter the shipping address.
11. Enter the city.
12. Enter the state.
13. Enter the country.
14. If desired, add any customer notes in the "Customer Notes" field.

## Field-by-Field Explanation
* **Unit Type**: Select the type of unit being ordered (Yes/No).
* **Quantity**: Enter the number of units being ordered.
* **Unit Price**: Enter the price of each unit.
* **Order Date**: Choose the date on which the units are to be ordered.
* **Tester Unit Name**: Enter the name of the unit being tested.
* **Unit Number**: Select whether the unit number is present (Yes/No).
* **Customer Name**: Enter the customer's name.
* **Email**: Enter the customer's email address.
* **Phone**: Enter the customer's phone number.
* **Shipping Address**: Enter the address where the units will be shipped.
* **City**: Enter the city where the units will be shipped.
* **State**: Enter the state where the units will be shipped.
* **Country**: Enter the country where the units will be shipped.
* **Customer Notes**: Add any additional notes about the order (optional).
* **Customer Notes 2**: Add any further notes about the order (optional).

## Tips
- Make sure to fill out all required fields to ensure accurate order processing.
- Double-check the information entered before submitting the form.
- If you are unsure about any field, contact the relevant support personnel.
