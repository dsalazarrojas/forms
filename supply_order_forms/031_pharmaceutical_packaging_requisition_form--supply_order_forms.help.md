# Pharmaceutical Packaging Requisition Form - Help Guide
## Purpose
This form is used to create new packaging requisitions for pharmaceutical products.

## How To Complete This Form
- Fill in the required fields to ensure accurate and complete information.
- Select the package type, product ID, and other relevant details.
- Ensure that the packaging status is up-to-date.
- Fill in the packaging priority if it is necessary.
- Add any remarks if required.
- Fill in the packaging quantity and notes if necessary.
- Select the packaging location and responsible personnel.
- Fill in the shipping method and cost if required.
- Fill in the shipping time and packaging time if required.
- Select the packaging remarks if necessary.

## Field-by-Field Explanation

* **Package Type (1)** (`packaging_type`, select_one, optional): Select the type of package you need (e.g., 'Yes' or 'No').
* **Product ID (2)** (`product_id`, number, optional): Enter the product ID to ensure accurate product identification.
* **Packaging Size (3)** (`packaging_size`, select_multiple, optional): Select the size of the package needed.
* **Packaging Color (4)** (`packaging_color`, select_one, optional): Select the color of the package if required.
* **Package Contents (5)** (`package_contents`, text, optional): Enter a brief description of the package contents.
* **Manufacturing Date (6)** (`manufacturing_date`, date, optional): Enter the date the product was manufactured.
* **Packaging Status (7)** (`packaging_status`, select_one, optional): Select the current status of the packaging (e.g., 'Active' or 'Inactive').
* **Packaging Priority (8)** (`packaging_priority`, select_one, optional): Select the priority level of the packaging (e.g., 'Yes' or 'No').
* **Remarks (9)** (`remarks`, note, optional): Add any additional remarks or comments about the packaging.
* **Packaging Quantity (10)** (`packaging_quantity`, number, optional): Enter the quantity of the package needed.
* **Packaging Notes (11)** (`packaging_notes`, text, optional): Enter any additional notes about the packaging.
* **Packaging Location (12)** (`packaging_location`, select_one, optional): Select the location where the package will be stored.
* **Packaging Cost (13)** (`packaging_cost`, number, optional): Enter the cost of the packaging.
* **Packaging Time (14)** (`packaging_time`, time, optional): Enter the time it takes to complete the packaging process.
* **Packaging Scheduling (15)** (`packaging_scheduling`, date, optional): Enter the date and time for scheduling the packaging.
* **Packaging Responsible (16)** (`packaging_responsible`, select_one, optional): Select the person responsible for the packaging.
* **Packaging Supervisor (17)** (`packaging_supervisor`, select_one, optional): Select the packaging supervisor.
* **Package Shipping Method (18)** (`package_shipping_method`, select_one, optional): Select the shipping method (e.g., 'Yes' or 'No').
* **Package Shipping Cost (19)** (`package_shipping_cost`, number, optional): Enter the cost of shipping the package.
* **Package Shipping Time (20)** (`package_shipping_time`, time, optional): Enter the time it takes to ship the package.
* **Packaging Remarks (21)** (`packaging_remarks`, note, optional): Add any additional remarks or comments about the packaging.
