# Software Promo Items Order Request Form - Help Guide
## Purpose
The Software Promo Items Order Request Form is a tool to help you request software promo items from the team. This form will guide you through the process of specifying what you need, and submitting your request for processing.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately, making sure to select the correct options for each field.
2. Review each field to ensure you've selected the correct information.

## Field-by-Field Explanation
* **Category** (Software, Hardware, Other): This field helps us understand what type of promo item you are requesting. Please select the category that best matches the item you need.
* **Description** (text): Provide a brief description of the item you are requesting. This will help us understand what you need and process your request efficiently.
* **Marketing** (Marketing, Event): Check the boxes for the types of marketing activities you'd like to see the promo item used for. This will help us tailor our distribution and usage of the item.
* **Quantity** (number): Indicate how many items you need. This will ensure we order the correct amount for you.
* **Shipping Method** (Shipping, Not Shipping): Let us know whether you'd like us to ship the item to you or if you'd like to collect it from us.
* **Shipping Date** (date): Provide the date by which you'd need the item for shipping. This will help us plan and prepare for timely delivery.
* **Needed By** (date): Indicate the date by which you'd like to receive the item. This will help us set a realistic deadline for fulfillment.
## Tips
* Be sure to fill out each field accurately and completely to avoid any confusion or delays.
* If you have any questions or concerns, don't hesitate to reach out to us for assistance.
