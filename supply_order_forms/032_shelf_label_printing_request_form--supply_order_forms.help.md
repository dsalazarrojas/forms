# Shelf Label Printing Request Form - Help Guide
## Purpose

This form is used for requesting shelf label printing to ensure that the correct and efficient printing of shelf labels.

## How To Complete This Form

1.  Fill out the Supply Order Form with the required details of the supply order.
2.  In the Content field, describe the content of the order that will be used for printing the shelf label.
3.  Enter the size and quantity of the shelf label needed.
4.  Set a due date for the printing of the shelf label.
5.  Select the team member responsible for printing the shelf label (Retail team or Warehouse team).
6.  Choose the production status of the supply order (In progress, Complete, or Delayed).
7.  Add any additional comments or instructions in the Notes field.
8.  Enter a unique identifier for the form.
9.  Select the tool assigned to the supply order.
10. Enter the category and description of the supply order.
11. Choose the file format for the output file.

## Field-by-Field Explanation

* **Supply order form**: Enter the necessary details of the supply order, including content, size, and quantity.
* **Content**: Describe the content of the supply order for printing the shelf label.
* **Size**: Enter the size of the shelf label that needs to be printed.
* **Quantity**: Specify the number of shelf labels required.
* **Due date**: Set a due date for the printing of the shelf label.
* **Assigned to**: Select the team member responsible for printing the shelf labels (Retail team or Warehouse team).
* **Production status**: Choose the production status of the supply order (In progress, Complete, or Delayed).
* **Notes**: Provide any additional comments or instructions for the supply order.
* **Form ID**: Enter a unique identifier for the form.
* **Assigned tool**: Enter the tool assigned to the supply order.
* **Category**: Enter the category of the supply order.
* **Description**: Enter a brief description of the supply order.
* **Output file**: Enter the file format for the output file.
* **Form Title**: Enter a title for the form.
* **Form Category**: Enter the category of the form.
* **Form Description**: Enter a brief description of the form.
* **Assigned To**: Enter the person assigned to the supply order.
* **Form IDs**: Enter the IDs of the form.
* **Assigned Jimmy**: (Note: This field is redundant with "Assigned To" and can be removed.)
* **Form Name**: Enter a name for the form.
* **Form Version**: Enter the version of the form.
* **Form File**: Enter the file path for the form.
* **Form Version File**: Enter the version file path for the form.
* **Form Category File**: Enter the category file path for the form.
* **Form Description File**: Enter the description file path for the form.

## Tips

* Make sure to fill out the form correctly to avoid duplication of work and ensure that the right personnel are assigned to the task.
* Review the form carefully before submitting to ensure that all necessary information is provided.
* If you're unsure about any field, refer to this guide for clarification.
* Use the correct team member for printing the shelf labels based on your team's role in the supply chain.
