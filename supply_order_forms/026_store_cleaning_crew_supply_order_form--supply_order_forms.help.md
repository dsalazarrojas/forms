# Store Cleaning Crew Supply Order Form - Help Guide
## Purpose
The purpose of this form is to allow store owners to place orders for cleaning crew supplies. It gathers information for delivery scheduling and product distribution purposes.

## How To Complete This Form
To complete the form, follow these steps:
1. Review the form's fields and sections.
2. Fill in the required and optional fields as needed.

## Field-by-Field Explanation
* **Store Cleaning Crew Supply Order Form** (`title`, note, **optional**):
  This is a title field for the form. It provides a description of the form's purpose.
* **Select Products** (`select_multiple`, **optional**):
  This field is used to select multiple products for the order. Please select one or more products from the available options:
  - Product A
  - Product B
  - Product C
* **Delivery Date** (`date`, **optional**):
  This field is used to specify the delivery date. Please enter a date in YYYY-MM-DD format, or leave it empty for the current date.
* **Store ID** (`text`, **optional**):
  This field is used to enter the store's ID. Please enter the store's unique identifier.
* **Quantity** (`number`, **optional**):
  This field is used to specify the quantity of the product ordered. Please enter a whole number.
* **Email** (`email`, **optional**):
  This field is used to enter a valid email address. Please use a format such as `username@example.com`.
* **Phone** (`text`, **optional**):
  This field is used to enter the store's phone number. Please enter a valid phone number.
* **Additional Information** (`text`, **optional**):
  This field is used to provide any additional information for the order. You can enter any relevant details about the order.

## Tips
- Make sure to enter accurate and complete information for all fields.
- If you have any questions or issues, contact our support team.
