# Worker First Aid Kit Refill Order Form - Help Guide
## Purpose
This form is used to request the refilling of first aid kits for workers. Please fill out the form accurately to ensure that the kits are refilled correctly and that the workers have access to the necessary supplies.

## How To Complete This Form
1. Ensure that you have read and understood the purpose of this form.
2. Fill out the form with the correct information for the location where the first aid kit needs to be refilled.
3. Select the correct type and size of the kit according to the needs of the workers and location.
4. Choose the correct frequency of the refill request based on the usage of the first aid kit.
5. Submit the form once you have completed it accurately.

## Field-by-Field Explanation

* **Location**: This is the location where the first aid kit needs to be refilled. Please enter the address or name of the location where the kits are used.
* **Address**: This is the address associated with the location where the first aid kit needs to be refilled. Please enter the address accurately to ensure correct delivery.
* **Contact**: This is the contact person responsible for the refill request. Please enter the name and contact information accurately.
* **Phone**: This is the contact phone number for the location where the first aid kit needs to be refilled. Please enter the correct phone number.
* **First Aid Kit**:
	+ **Kit Type**: This is the type of first aid kit you need. Please select **Basic**, **Enhanced**, or **Advanced** according to the level of supplies required.
	+ **Kit Size**: This is the size of the first aid kit you need. Please select **Small**, **Large**, or **Extra Large** according to the number of workers and supplies required.
	+ **Location**: This is the location where the first aid kit will be used. Please select **Office**, **Warehouse**, or **Home** according to the location where the kits are used.
* **Request Quantity**: This is the number of first aid kits you need to be refilled. Please enter the correct quantity accurately.
* **Request Frequency**: This is the frequency at which you would like the first aid kit to be refilled. Please select **Weekly**, **Monthly**, **Quarterly**, or **Annually** according to your needs.

## Tips
- Double-check your location and contact details to ensure accurate delivery.
- Confirm that you have selected the correct type and size of the kit according to the needs of the workers and location.
- Choose the correct frequency of the refill request based on the usage of the first aid kit.
