# Cleaning Supply Order Form - Help Guide
## Purpose
This form is used to place orders for cleaning supplies, including products, equipment, and materials. It helps ensure that all necessary information is collected to process the order correctly and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the order date and order ID number.
2. Enter the requester's name, email address, and phone number.
3. Identify the department or location that will receive the supplies.
4. List the items being ordered, including their quantities and unit costs.
5. Select the delivery address and urgency level.
6. Provide a budget code or cost center for accounting purposes (if applicable).
7. Enter the estimated total cost (if known).
8. Confirm whether the total cost is within the budget.
9. Add any additional notes or special requests.
10. Specify any preferred vendor (if applicable).

## Field-by-Field Explanation
* **-- Order Information --**: This section contains general order information.
* **Order Date**: The date this order is placed. (Required)
* **Order ID Number**: Internal reference number for this order.
* **-- Requester Information --**: This section contains contact information for the person placing the order.
* **Requester Name**: Name of person placing the order. (Required)
* **Email Address**: Email address for order confirmation. (Required)
* **Phone Number**: Contact number for the person placing the order.
* **Department/Location**: Which facility or area will receive the supplies.
* **-- Supplies to Order --**: This section lists the items being ordered.
* **Item 1 - Product Name**: Name of the first item being ordered. (Required)
* **Item 1 - Type**: Category of the product. (Required, Select from options)
* **Item 1 - Quantity**: Number of units being ordered. (Required)
* **Item 1 - Unit of Measure**: Unit of measure for the item. (Required, Select from options)
* **Item 1 - Unit Cost**: Price per unit. (Optional)
* **Item 2 - Product Name**: Name of the second item being ordered. (Optional)
* **Item 2 - Type**: Category of the product. (Optional, Select from options)
* **Item 2 - Quantity**: Number of units being ordered. (Optional)
* **Additional Items**: List any other supplies needed.
* **-- Delivery and Urgency --**: This section contains delivery details.
* **Delivery Address**: Where should the items be delivered? (Required)
* **Date Needed By**: When do you need the supplies? (Required)
* **Urgency Level**: How quickly do you need this? (Required, Select from options)
* **-- Budget and Approval --**: This section contains budget information.
* **Budget Code or Cost Center**: For accounting purposes. (Optional)
* **Estimated Total Cost**: Approximate order total. (Optional)
* **Is This Within Budget?**: Confirm whether the total cost is within the budget. (Required)
* **-- Additional Information --**: This section contains additional notes.
* **Special Requests or Specifications**: Any specific brands or types? (Optional)
* **Preferred Vendor**: Any preference for supplier? (Optional)
* **Additional Notes**: Any other information. (Optional)

**Tips**

* Double-check that all required fields are filled in before submitting the form.
* Ensure that all items are accurately listed and quantified.
* Clearly select the delivery address and urgency level.
* Review the estimated total cost and confirm whether it is within the budget.
* Add any additional notes or special requests as needed.
* Specify any preferred vendor (if applicable).
