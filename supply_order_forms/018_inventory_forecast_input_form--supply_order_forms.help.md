# Inventory Forecast Input Form - Help Guide
## Purpose
The Inventory Forecast Input Form is used to input data related to inventory forecasts for different product variants.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct product variant section (1, 3, 5, etc.) that corresponds to the product you are forecasting.
2. Fill out the required fields for each section:
	* Product Name
	* Forecasted Date
	* Forecasted Value
	* Location Name
	* Forecasted By
	* Forecasted Frequency
	* Forecasted UOM
	* Forecasted Date 2
	* Forecasted Value 2
	* Forecasted UOM 2
	* Forecasted Frequency 2
	* Forecasted By 2
	* Forecasted UOM 3
	* Forecasted Frequency 3
	* Forecasted Value 3
3. Ensure that you fill out all required fields for each section.
4. Review and submit the form.

## Field-by-Field Explanation

* **Product Name** (1): Enter the name of the product being forecasted.
* **Forecasted Date** (2): Enter the date for which the forecast is being made.
* **Forecasted Value** (3): Enter the forecasted value for the product.
* **Location Name** (4): Enter the name of the location for which the forecast is being made.
* **Forecasted By** (5): Select whether the forecast is made by "Forecast" or "Actual".
* **Forecasted Frequency** (6): Select the frequency of the forecast (Daily, Weekly, Monthly).
* **Forecasted UOM** (7): Select the unit of measure for the forecast (Pieces, Units, Cases).
* **Notes** (8, 18): Enter any additional comments or notes related to the forecast.
* **Location ID** (9, 19): Enter the location ID for the location being forecasted.
* **Product ID** (10, 20): Enter the product ID for the product being forecasted.
* **Forecasted Date 2** (11): Enter the date for which the forecast is being made for the second product variant.
* **Forecasted UOM 2** (14): Select the unit of measure for the forecast (Pieces, Units, Cases).
* **Forecasted Frequency 2** (15): Select the frequency of the forecast (Daily, Weekly, Monthly).
* **Forecasted By 2** (17): Select whether the forecast is made by "Forecast" or "Actual".
* **Forecasted Value 2** (16): Enter the forecasted value for the second product variant.
* **Notes 2** (18): Enter any additional comments or notes related to the second product variant.
* **Forecasted Date 3** (21): Enter the date for which the forecast is being made for the third product variant.
* **Forecasted UOM 3** (22): Select the unit of measure for the forecast (Pieces, Units, Cases).
* **Forecasted Frequency 3** (23): Select the frequency of the forecast (Daily, Weekly, Monthly).
* **Forecasted Value 3** (24): Enter the forecasted value for the third product variant.
* **Forecasted By 3** (25): Select whether the forecast is made by "Forecast" or "Actual".
