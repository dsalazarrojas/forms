# Website Funding Content Upload Form - Help Guide
## Purpose
This form is designed to help you upload website content funding information for review and potential publication. It's essential to provide accurate and complete information to ensure successful publication.

## How To Complete This Form
1. Start by filling in the required fields: Category, Website URL, and File (if applicable).
2. Select the relevant Category (Donation Forms or Other) from the options.
3. Provide a brief Description of the content being uploaded.
4. If your content is a file, select 'Yes' or 'No' to indicate if it requires a file to be uploaded.
5. If required, upload your file using the File field.
6. Click the "Submit" button to complete and submit your form.

## Field-by-Field Explanation
* **Category**: Choose the category that best fits your uploaded content. Options include: Donation Forms and Other.
* **Website URL**: Enter the URL of the website where the content can be found. This helps us understand the context of your submission.
* **Description**: A brief summary of the content being uploaded. This will help reviewers quickly grasp the purpose and relevance of your submission.
* **File Type**: Select 'Yes' if a file upload is required for your submission, and 'No' otherwise. This helps our team determine if a file needs to be reviewed before publication.
* **File**: If a file upload is required (i.e., you selected 'Yes' for File Type), upload your file using this field. Please ensure the file is in the correct format and size as specified in the internal guidelines.
* **Upload File**: Please upload your file using this field if you selected 'Yes' for File Type. Ensure the file is the correct size and format as specified in the internal guidelines.
