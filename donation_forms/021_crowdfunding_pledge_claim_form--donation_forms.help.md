# Crowdfunding Pledge Claim Form - Help Guide
## Purpose
The Crowdfunding Pledge Claim Form is a tool used to collect information from donors or contributors who have pledged to support a project or campaign. This form helps track and verify pledges, ensuring that the necessary details are collected and recorded accurately.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide base information (page 1).
2. Enter the donation amount (page 2).
3. Fill out the supporter's information form (page 3), which includes:
	* Supporter name
	* Supporter email
	* Supporter phone number
	* Supporter address
	* Supporter city
	* Supporter state
	* Supporter country
	* Supporter zip code
4. Add any additional comments or notes about the supporter (page 12).
5. Provide payment information (page 13-17), which includes:
	* Payment name (page 14)
	* Payment method (page 15)
	* Payment date (page 16)
	* Payment time (page 17)
	* Payment amount (page 18)

## Field-by-Field Explanation
* **Base Info Form** (page 1):
	* *Base information form*: This section is for capturing any additional information about the pledge.
	* Type: Text
	* Required: No
* **Donation Amount** (page 2):
	* *Donation amount*: Enter the amount pledged by the supporter.
	* Type: Number
	* Required: No
* **Supporter Info Form** (page 3):
	* *Supporter name*: Enter the name of the supporter.
	* Type: Text
	* Required: No
* **Supporter Name** (page 4):
	* *Supporter name*: Enter the name of the supporter.
	* Type: Text
	* Required: No
* **Supporter Email** (page 5):
	* *Supporter email*: Enter the email address of the supporter.
	* Type: Email
	* Required: No
* **Supporter Phone** (page 6):
	* *Supporter phone number*: Enter the phone number of the supporter.
	* Type: Text
	* Required: No
* **Supporter Address** (page 7):
	* *Supporter address*: Enter the address of the supporter.
	* Type: Text
	* Required: No
* **Supporter City** (page 8):
	* *Supporter city*: Enter the city of the supporter.
	* Type: Text
	* Required: No
* **Supporter State** (page 9):
	* *Supporter state*: Enter the state of the supporter.
	* Type: Text
	* Required: No
* **Supporter Country** (page 10):
	* *Supporter country*: Enter the country of the supporter.
	* Type: Text
	* Required: No
* **Supporter Zip** (page 11):
	* *Supporter zip code*: Enter the zip code of the supporter.
	* Type: Text
	* Required: No
* **Supporter Comment** (page 12):
	* *Supporter comment*: Enter any additional comments or notes about the supporter.
	* Type: Note
	* Required: No
* **Payment Info Form** (page 13):
	* *Payment info form*: This section is for capturing any payment information related to the pledge.
	* Type: Text
	* Required: No
* **Payment Name** (page 14):
	* *Payment name*: Enter the name associated with the payment.
	* Type: Text
	* Required: No
* **Payment Method** (page 15):
	* *Payment method*: Select whether the payment was made using 'Yes' or 'No'.
	* Type: Select One
	* Required: No
* **Payment Date** (page 16):
	* *Payment date*: Enter the date of the payment.
	* Type: Date
	* Required: No
* **Payment Time** (page 17):
	* *Payment time*: Enter the time of the payment.
	* Type: Time
	* Required: No
* **Payment Amount** (page 18):
	* *Payment amount*: Enter the amount paid for the pledge.
	* Type: Number
	* Required: No
