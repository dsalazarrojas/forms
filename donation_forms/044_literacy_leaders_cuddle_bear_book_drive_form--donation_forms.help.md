## Literacy Leaders Cuddle Bear Book Drive Form - Help Guide

## How To Complete This Form

*   Start by entering a title for the form in the "Form Title" field. This will help identify the form for internal tracking purposes.
*   Choose the category for the donation by selecting "Donation Forms" or "other".
*   Provide a brief description of the donation, including details about the books donated, the donor, and any additional relevant information.
*   In the "Output File" field, enter the path for the file where you want to output the data in case you need to save or use it for later reference.
*   Enter the internal form ID to help identify the form for tracking purposes.
*   In the "Assigned Tool" field, indicate which tool is assigned for the collection or distribution of the donated books.
*   Provide the category ID for the donation.

## Field-by-Field Explanation

*   **Form Title** (`form_title`, text, required/optional): Enter a title for the form that will help identify it for internal tracking purposes.
*   **Category** (`category`, select_one, required/optional): Choose the category of the donation, either "Donation Forms" or "other".
*   **Description** (`description`, text, required/optional): Enter a brief description of the donation, including details about the books, donor, and any other relevant information.
*   **Output File** (`output_file`, text, required/optional): Enter the path for where you want to save the collected data.
*   **Form ID** (`form_id`, number, required/optional): Enter the internal form ID to help identify the form for tracking purposes.
*   **Assigned Tool** (`assigned_tool`, text, required/optional): Indicate which tool is assigned for the collection or distribution of the donated books.
*   **Category ID** (`category_id`, number, required/optional): Enter the category ID for the donation.
