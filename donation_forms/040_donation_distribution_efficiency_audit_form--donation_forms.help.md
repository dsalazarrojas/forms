# Donation Distribution Efficiency Audit Form - Help Guide
## Purpose
The Donation Distribution Efficiency Audit Form is used to collect information about the distribution of donations for different programs, campaigns, and reporting periods.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the **program** that the form is for.
2. Choose the **campaign** related to this distribution.
3. Select the **reporting period** (Q1, Q2, Q3, or Q4) for which you are reporting.
4. Choose the distribution types (e.g. Type A, Type B, Type C).
5. Select the distribution channels (e.g. Channel A, Channel B, Channel C).
6. Enter the **distribution method** used (a text description).
7. Finally, select the distribution frequency (e.g. Once, Twice, Multiple).

## Field-by-Field Explanation

* **program**: This field is used to select the program that the distribution is for. Please choose the program that this distribution is related to.
* **campaign**: This field is used to select the campaign that this distribution is for. Please choose the campaign that this distribution is related to.
* **reporting_period**: This field is used to select the reporting period for which you are reporting. Please choose the quarter for which you are reporting (Q1, Q2, Q3, or Q4).
* **distribution_type**: This field is used to select the type of distribution (e.g. Type A, Type B, Type C). Please choose all relevant distribution types.
* **distribution_channel**: This field is used to select the distribution channels (e.g. Channel A, Channel B, Channel C). Please choose all relevant distribution channels.
* **distribution_method**: This field is used to enter the method used for distribution. Please describe the method used to distribute the donations.
* **distribution_frequency**: This field is used to select the distribution frequency (e.g. Once, Twice, Multiple). Please choose the frequency of distribution.

## Tips
- Be accurate when selecting the program, campaign, and reporting period to ensure that the form data is correct.
- Make sure to choose all relevant distribution types and channels.
- Provide a clear description of the distribution method used.
- Choose the correct distribution frequency.
