# volunteerProgramDonationForm - Help Guide
## Purpose
This form is designed to collect information about volunteer programs and donations. It is used to gather data on program names, donor details, donation dates and times, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the program name in the **Volunteer Program Name** field.
2. Enter the donor's name in the **Donor Name** field.
3. Enter the donor's email address in the **Donor Email** field.
4. Enter the donor's phone number in the **Donor Phone** field.
5. Select a donation date and time in the **Donation Date** and **Donation Time** fields.
6. Indicate if the donor has made any donations in the **Donations** field by selecting "Yes" or "No".
7. Add any additional notes about the donor in the **Donor Notes** field.
8. Add any additional notes about the volunteer in the **Volunteer Notes** field.
9. Enter the donor's address in the **Donor Address** field.

## Field-by-Field Explanation
* **Volunteer Program Name**: Enter the name of the volunteer program you are donating to.
* **Donor Name**: Enter the name of the person making the donation.
* **Donor Email**: Enter the email address of the person making the donation.
* **Donor Phone**: Enter the phone number of the person making the donation.
* **Donation Date**: Select the date of the donation. This should be in the format MM/DD/YYYY.
* **Donation Time**: Select the time of the donation. This should be in the format HH:MM.
* **Donations**: Indicate if the donor has made any donations to the program by selecting "Yes" or "No".
* **Donor Notes**: Add any additional notes about the donor, such as any relevant information or comments.
* **Volunteer Notes**: Add any additional notes about the volunteer, such as any relevant information or comments.
* **Donor Address**: Enter the address of the person making the donation.
