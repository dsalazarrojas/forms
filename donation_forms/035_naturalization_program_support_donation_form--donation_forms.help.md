# Naturalization Program Support Donation Form - Help Guide
==============================================

## Purpose

The naturalization program support donation form is designed to collect information from donors for the naturalization program. This form allows you to provide support to the program by making a donation. Please review the instructions below to ensure you complete the form accurately and effectively.

## How To Complete This Form

1.  Complete all required fields (marked as `required` in the form).
2.  Fill out the `donation_amount` field with the amount you wish to donate.
3.  Select the `donation_frequency` field to indicate if this is a one-time or recurring donation.
4.  In the `donor_type` field, select all that apply to describe the type of donor you are (e.g. individual, organization, etc.).
5.  For the `payment_gateway` field, select the payment method you wish to use (if applicable).
6.  Optionally, you can add any additional information in the `custom_fields` field.
7.  Finally, submit the form by providing your contact information and email in the `contact_info` and `email` fields.

## Field-by-Field Explanation

*   **Donor Info (donor_info)**: Please provide a brief description of yourself or your organization.
*   **Donation Amount (donation_amount)**: Enter the amount you wish to donate to the naturalization program.
*   **Donation Date (donation_date)**: Enter the date of the donation.
*   **Donation Note (donation_note)**: If you have any additional information about your donation, please provide it here.
*   **Donor Organization (donor_organization)**: If you are representing an organization, please provide the name and description of the organization.
*   **Contact Info (contact_info)**: Provide your contact information so we can get in touch with you about your donation.
*   **Email (email)**: Enter your email address so we can follow up on your donation.
*   **Donation Frequency (donation_frequency)**: Select "Yes" for a one-time donation or "No" for a recurring donation.
*   **Donor Type (donor_type)**: Select all that apply to describe the type of donor you are (e.g. individual, organization, etc.).
*   **Payment Gateway (payment_gateway)**: If you wish to use a specific payment gateway (e.g. PayPal, Stripe, etc.), select "Yes" to indicate this.
*   **Custom Fields (custom_fields)**: You can provide any additional information you feel is relevant to your donation here.
