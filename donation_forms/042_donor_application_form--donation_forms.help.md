# Donor Application Form - Help Guide
## Purpose
This form is designed to help organizations collect information from individuals who want to donate to their cause. It's a simple and straightforward process that requires some basic details from the donor.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in your category (e.g. "General Donations" or "Event Sponsorship") in the "category" field.
2. In the "description" field, type a short and detailed description of why you're choosing to donate.
3. Select the "assigned tool" you'd like to use for your donation.
4. Input your "form id" (a unique number, if you're unsure, please leave it blank and it will be automatically generated).
5. Upload your "output file" (e.g. proof of payment, ID, etc.).

## Field-by-Field Explanation
* **Donor Application Form** (`donor_application_form`, text, required): This is the main section where you can enter any information that you feel is relevant about your application.
* **Category** (`category`, text, required): Select the category related to your application, e.g. "General Donations" or "Event Sponsorship".
* **Description** (`description`, text, required): Write a brief description of your application. Please be as detailed as possible.
* **Assigned Tool** (`assigned_tool`, text, required): Choose the tool that you want to use for your donation.
* **Form ID** (`form_id`, text, required): Enter a unique ID for your application, if you know it. If not, it will be automatically generated.
* **Output File** (`output_file`, text, required): Upload a file that proves your payment or ID, e.g. proof of payment, ID, etc.

## Tips
* Please ensure that all the fields are filled correctly and accurately.
* Be as detailed as possible in your description.
* Use a unique ID for your form ID if you have one.
* Proof of payment or ID should be uploaded for verification purposes.
