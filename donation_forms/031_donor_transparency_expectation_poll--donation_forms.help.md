# Donor Transparency Expectation Poll - Help Guide
## Purpose
The Donor Transparency Expectation Poll is a form designed to collect information about donor expectations, financial details, and contact information. This form is intended for donors, organizations, or individuals interested in discussing or providing transparency about their expectations. It's a helpful tool for gathering and analyzing data on donor expectations.

## How To Complete This Form
To complete the Donor Transparency Expectation Poll, follow these steps:

1. Start by providing a title and description of your expectations in the "Donor Expectations" field.
2. If you have any additional financial information, please provide it in the "Financial Information" field.
3. Specify your preferred timeframes for expectations in the "Timeframes for Expectations" field (this field is for time-related expectations).
4. If you have any additional contact information, please enter it in the "Contact Information" field.
5. If you have any additional comments, please add them in the "Additional Comments" field.
6. If you have any specific timeframes you'd like to emphasize, please enter them in the "Timeframes" field.
7. If you have any specific financial information you'd like to emphasize, please enter it in the "Financial" field.
8. If you have any specific contact details you'd like to highlight, please enter them in the "Contact" field.

## Field-by-Field Explanation

* **Donor Expectations (<name>)**: This is the main field where you can specify your donor expectations.
	+ Type: text field
	+ Required: No
* **Financial Information (<name>)**: Enter any additional financial information you'd like to share.
	+ Type: text field
	+ Required: No
* **Timeframes for Expectations (<name>)**: Specify your preferred timeframes for expectations.
	+ Type: time field
	+ Required: No
* **Contact Information (<name>)**: Enter any additional contact information you'd like to provide.
	+ Type: text field
	+ Required: No
* **Additional Comments (<name>)**: Add any additional comments you'd like to make.
	+ Type: text field
	+ Required: No
* **Timeframes (<name>)**: Specify any specific timeframes you'd like to emphasize.
	+ Type: text field
	+ Required: No
* **Financial (<name>)**: Enter any additional financial information you'd like to emphasize.
	+ Type: text field
	+ Required: No
* **Contact (<name>)**: Enter any additional contact details you'd like to highlight.
	+ Type: text field
	+ Required: No

## Tips
* Please provide clear and concise information in each field to ensure accurate data collection.
* If you have any further questions or concerns, please contact us at form@gic.mx.
