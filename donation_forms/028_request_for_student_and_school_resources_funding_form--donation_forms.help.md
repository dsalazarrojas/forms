# request_for_student_and_school_resources_funding_form - Help Guide
## Purpose
This form is designed to provide school administrators with a way to request financial support from the assigned user for student and school resources. Please use this form to provide accurate and clear information to help facilitate the processing of your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the school information and financial situation.
2. Answer all the relevant fields accurately.
3. Provide detailed notes if necessary.

## Field-by-Field Explanation
### School Enrollment
* **School Enrollment** (`school_enrollment`, `text`, required: false): Enter the number of students enrolled in the school.
* **Financial Situation** (`financial_situation`, `text`, required: false): Describe the school's current financial situation.
* **School Resources** (`school_resources`, `text`, required: false): Specify the types of resources needed (e.g., textbooks, equipment, etc.).
* **School Location** (`school_location`, `text`, required: false): Enter the school's location (city, state, country, etc.).
* **Total Students** (`total_students`, `number`, required: false): Enter the total number of students.
* **Student to Faculty Ratio** (`student_to_faculty_ratio`, `select_one`, required: false):
	+ Yes: Select if the school has a high student-to-faculty ratio.
	+ No: Select if the school does not have a high student-to-faculty ratio.
* **Financial Support Needed** (`financial_support_needed`, `select_multiple`, required: false):
	+ Yes: Select if financial support is needed for student resources.
	+ No: Select if financial support is not needed.
* **Financial Support Type** (`financial_support_type`, `select_one`, required: false):
	+ Yes: Select if the school needs financial support for resources other than student resources.
	+ No: Select if the school does not need financial support for resources other than student resources.
* **Amount Needed** (`amount_needed`, `number`, required: false): Enter the exact amount of financial support needed.
* **School Email** (`school_email`, `email`, required: false): Enter the school's email address.
* **School Phone** (`school_phone`, `text`, required: false): Enter the school's phone number.
* **School Address** (`school_address`, `note`, required: false): Enter the school's address.
* **School Website** (`school_website`, `text`, required: false): Enter the school's website URL.
* **School Facebook** (`school_facebook`, `text`, required: false): Enter the school's Facebook URL.
* **School Twitter** (`school_twitter`, `text`, required: false): Enter the school's Twitter URL.
* **School Instagram** (`school_instagram`, `text`, required: false): Enter the school's Instagram URL.
* **School YouTube** (`school_youtube`, `text`, required: false): Enter the school's YouTube URL.
* **School Other Social Media** (`school_other_social_media`, `text`, required: false): Enter the school's other social media URL.
* **Assigned User** (`assigned_user`, `text`, required: false): Enter the name of the assigned user.
* **Notes** (`notes`, `note`, required: false): Enter any additional notes or comments.

## Tips
* Please ensure that all fields are filled out accurately and thoroughly.
* If you have any doubts or concerns, please contact the assigned user directly.
* The assigned user will review and process your request as soon as possible.
