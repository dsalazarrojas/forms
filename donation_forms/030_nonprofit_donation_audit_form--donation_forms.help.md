# Nonprofit Donation Audit Form - Help Guide
## Purpose
The Nonprofit Donation Audit Form is a tool for tracking and managing donations received by a nonprofit organization. It is used to capture details about the donator, including their contact information and donation specifics such as date, amount, frequency, and source of the donation.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the Donator Info field with any additional information about the donator that you would like to record.
2.  Enter the Donator Name in the field provided.
3.  Enter the Donator Email address in the field provided.
4.  Enter the Donator Phone number in the field provided.
5.  Add any additional Notes about the donation in the Notes field.
6.  Fill in the Donation Date and Donation Time for the donation.
7.  Enter the Donation Amount in the field provided.
8.  Select the Donation Frequency from the provided options.
9.  Select the source of the Donation from the provided options.
10.  Select the current Donation Status from the provided options.
11.  Select the Payment Method used for the donation from the provided options.
12.  Fill in any additional Notes (other) about the donation in the field provided.
13.  Select the Notes (other) Frequency from the provided options.

## Field-by-Field Explanation
* **Donator Info**: Enter any additional information about the donator that you would like to record. This field is optional.
* **Donator Name**: Enter the name of the donator. This field is required.
* **Donator Email**: Enter the email address of the donator. This field is optional.
* **Donator Phone**: Enter the phone number of the donator. This field is optional.
* **Notes**: Add any additional notes about the donation in this field. This field is optional.
* **Donation Date**: Enter the date of the donation in the format MM/DD/YYYY. This field is required.
* **Donation Time**: Enter the time of the donation in the format 12:00. This field is optional.
* **Donation Amount**: Enter the amount of the donation. This field is required.
* **Donation Frequency**: Select how often the donator donates from the provided options. This field is optional.
* **Donation Source**: Select the source of the donation from the provided options. This field is optional.
* **Donation Status**: Select the current status of the donation from the provided options. This field is optional.
* **Payment Method**: Select the method of payment used for the donation from the provided options. This field is optional.
* **Notes (other)**: Add any additional notes about the donation in this field. This field is optional.
* **Notes (other) Frequency**: Select the frequency of the additional notes. This field is optional.
* **Other Notes Source**: Select the source of the additional notes from the provided options. This field is optional.
* **Other Donations Source**: Select the source of the other donations from the provided options. This field is optional.
* **Other Notes**: Add any other notes about the donation in this field. This field is optional.
* **Other Donations Frequency**: Select the frequency of the other donations from the provided options. This field is optional.
*   **Other Notes Source**: Select the source of the other notes from the provided options. This field is optional.

## Tips
* Please make sure to fill in all required fields before submitting the form.
* If you have any questions or concerns about filling out this form, feel free to reach out to us.
* If you are unsure about any of the options provided, try to choose the one that best fits the information you are recording.
