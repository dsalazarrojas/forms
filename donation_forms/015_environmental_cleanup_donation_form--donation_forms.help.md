# Environmental Cleanup Donation Form - Help Guide
## Purpose
This form is designed to help us understand your interest in supporting environmental cleanup efforts. Your input will help us manage and track our initiatives effectively.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Review the form carefully and fill in the required fields.
2. Ensure that you answer all the questions truthfully and accurately.
3. If you have any questions or concerns, please contact us for assistance.

## Field-by-Field Explanation

* **Environmental (Page 1)** (`environmental_cleanup_donation_form_1`, Note, Not Required)
	+ This field is a space for you to briefly describe the environmental aspect you are interested in. Be as specific as possible.
* **Cleanup (Page 2)** (`environmental_cleanup_donation_form_2`, Date, Not Required)
	+ This field is used to record the date of the cleanup project. Please enter the date in the format `MM/DD/YYYY`.
* **Initiative (Page 3)** (`environmental_cleanup_donation_form_3`, Text, Not Required)
	+ This field is for you to describe the specific initiative or project you are interested in. Be as detailed as possible.
* **Location (Page 4)** (`environmental_cleanup_donation_form_4`, Select Multiple, Not Required)
	+ Please select all the locations where you would like to support environmental cleanup efforts. You can choose multiple options.
* **Amount (Page 5)** (`environmental_cleanup_donation_form_5`, Number, Not Required)
	+ This field is for you to specify the amount you are willing to donate. Please enter a valid number.
* **Payment (Page 6)** (`environmental_cleanup_donation_form_6`, Select One, Not Required)
	+ Please indicate whether you are willing to make a payment for the donation. Options are "Yes" and "No".
* **Donation (Page 7)** (`environmental_cleanup_donation_form_7`, Date, Not Required)
	+ This field is not currently being used. Please disregard it.

## Tips
* Please ensure that you enter accurate and truthful information.
* If you have any questions or concerns, please contact us for assistance.
* This form is for demonstration purposes only and should not be used for actual financial transactions or commitments.
