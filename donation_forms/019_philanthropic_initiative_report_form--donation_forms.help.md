# Philanthropic Initiative Report Form - Help Guide

## Purpose
This form is used to report on philanthropic initiatives that have already been completed or are ongoing. This information will help the organization track and evaluate the effectiveness of these initiatives.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the correct category for your philanthropic initiative from the dropdown menu.
3. Enter a detailed description of the initiative.
4. Provide the date and time of the initiative if applicable.
5. Describe the outcomes of the initiative for each of the up to five outcome fields.
6. Enter the contact information for follow-up if desired.

## Field-by-Field Explanation

* **Category** (Donation, Grant, Other): Select the type of philanthropic initiative being reported. This will help the organization track the type of initiatives it is supporting.
* **Description** (text, required): Enter a detailed description of the charitable initiative.
* **Date** (date, optional): Enter the date the initiative was completed or is ongoing. If the initiative is ongoing, you can enter the start date.
* **Time** (time, optional): Enter the time the initiative was completed or is scheduled to be completed. If the initiative is ongoing, you can enter the start time.
* **Outcome 1, 2, 3, 4, 5** (text, optional): Describe the outcome of each of these initiatives for up to five separate outcomes.
* **Email** (email, optional): Enter the contact information for follow-up, including a valid email address.
* **Phone** (text, optional): Enter the contact information for follow-up, including a valid phone number.

Note: All fields are optional, but filling out the description field is highly recommended to provide a complete picture of the initiative.
