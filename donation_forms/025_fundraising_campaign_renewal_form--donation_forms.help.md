# fundraising_campaign_renewal_form - Help Guide
## Purpose
This form is designed to help donors renew their existing fundraising campaigns. It collects information about the donor and the campaign details to ensure that the campaign continues without interruption.

## How To Complete This Form
1. Fill out the donor information section (ID 1-6) with accurate and up-to-date information.
2. Fill out the campaign details section (ID 7-10) with the campaign's title, start date, and end date.
3. Select the desired donation frequency (ID 14).
4. Choose a payment method (ID 15).
5. Fill out any additional notes or comments (ID 16).
6. Check if the campaign is still active (ID 17).
7. Fill out any other campaign details (ID 18-20).
8. Fill out the frequency start and end dates (ID 21-22).

## Field-by-Field Explanation
* **Donor Information** (ID 1: donor_information):
	+ This field is for the donor's name and contact information.
* **Campaign Details** (ID 2: campaign_details):
	+ This field is for the campaign's title and details.
* **Payment Information** (ID 3: payment_info):
	+ This field is for the payment method and other relevant information.
* **Renewal Information** (ID 4: renewal_info):
	+ This field is for any additional renewal information.
* **Donor Email** (ID 5: donor_email):
	+ This field is for the donor's email address.
* **Donor Phone** (ID 6: donor_phone):
	+ This field is for the donor's phone number.
* **First Name** (ID 7: first_name):
	+ This field is for the donor's first name.
* **Last Name** (ID 8: last_name):
	+ This field is for the donor's last name.
* **Address** (ID 9: address):
	+ This field is for the donor's address.
* **City** (ID 10: city):
	+ This field is for the donor's city.
* **State** (ID 11: state):
	+ This field is for the donor's state.
* **Zip** (ID 12: zip):
	+ This field is for the donor's zip code.
* **Amount** (ID 13: amount):
	+ This field is for the amount of the donation.
* **Donation Frequency** (ID 14: frequency):
	+ This field is for how often the donor wishes to make the donation. Options include monthly, quarterly, or annually.
* **Payment Method** (ID 15: donation_method):
	+ This field is for how the donor wants to make the donation. Options include check, bank transfer, or online.
* **Notes** (ID 16: notes):
	+ This field is for any additional comments or notes.
* **Campaign Status** (ID 17: campaign_id):
	+ This field is for whether the campaign is still active or not.
* **Campaign Name** (ID 18: campaign_name):
	+ This field is for the campaign's title.
* **Campaign Start Date** (ID 19: campaign_start_date):
	+ This field is for the campaign's start date.
* **Campaign End Date** (ID 20: campaign_end_date):
	+ This field is for the campaign's end date.
* **Frequency Start Date** (ID 21: frequency_start):
	+ This field is for the start date of the donation frequency.
* **Frequency End Date** (ID 22: frequency_end):
	+ This field is for the end date of the donation frequency.
