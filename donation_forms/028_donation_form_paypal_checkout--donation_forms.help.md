# Donation Form PayPal Checkout - Help Guide
## Purpose
The "Donation Form PayPal Checkout" is a form used for making donations to a website or application. This form allows users to input the amount and currency of their donation, as well as other optional fields such as notes and contact information.

## How To Complete This Form
To complete the "Donation Form PayPal Checkout", follow these steps:

1. Select the amount you wish to donate.
2. Choose the currency for the donation.
3. (Optional) Add any notes or comments about the donation.
4. (Optional) Enter your email address.
5. (Optional) Enter your phone number.
6. (Optional) Select whether the donor information should be public.
7. (Optional) Select whether to submit the form.
8. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Donation Form PayPal Checkout** (`donation_form_paypal_checkout`): This field is the main field for the form, where the user inputs the name of the form.
* **amount** (`amount`): Enter the amount you wish to donate. This is a required field to input a number value for the donation amount.
* **currency** (`currency`): Choose the currency for the donation. This field is required to select a currency for the donation.
* **paypal_button** (`paypal_button`): This field is currently a select multiple field and should be treated as a radio button or toggle option. It should be selected if you wish to make a payment via PayPal.
* **notes** (`notes`): This field is a free text box where you can add any additional comments or notes for the donation. It is an optional field and can be left blank.
* **email** (`email`): This field is an optional field where you can input your email address.
* **phone** (`phone`): This field is an optional field where you can input your phone number.
* **donor_info** (`donor_info`): This field is a select multiple field and should be treated as a toggle option. It should be selected if you wish to share donor information. 
* **submit** (`submit`): This field is a select multiple field and should be treated as a toggle option. It should be selected if you wish to submit the form. 
* **cancel** (`cancel`): This field is currently a select multiple field and should be treated as a toggle option. It should be selected if you wish to cancel the form submission.
