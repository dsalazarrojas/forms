# Donor Records Checklist Form - Help Guide
## Purpose
The Donor Records Checklist Form is used to collect and record information about donors, including their personal details, contact information, and donation history.

## How To Complete This Form
1. Start by filling out the required fields with the correct information about the donor.
2. Review the form carefully before submitting to ensure that all necessary information is provided.
3. Use the select_one and select_multiple fields to choose the correct options for each field.
4. Enter the date and time for the assigned date and time fields.
5. Submit the form once complete.

## Field-by-Field Explanation
* **Donor Name** (`donor_name`, text, required): Enter the full name of the donor.
* **Donor Address** (`donor_address`, text, required): Enter the donor's address.
* **Donor City** (`donor_city`, text, required): Enter the city where the donor resides.
* **Donor State** (`donor_state`, select_multiple, required): Select the state where the donor resides.
* **Donor Zip** (`donor_zip`, number, required): Enter the donor's zip code.
* **Donor Country** (`donor_country`, text, required): Enter the country where the donor resides.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the contact person (e.g., the donor's assistant).
* **Contact Phone** (`contact_phone`, text, required): Enter the phone number of the contact person.
* **Contact Email** (`contact_email`, email, optional): Enter the email of the contact person.
* **Relationship** (`relationship`, select_one, optional): Check if the donor is related to the organization.
* **Date of Last Donation** (`date_of_last_donation`, date, optional): Enter the date of the last donation.
* **Gift Frequency** (`gift_frequency`, select_multiple, optional): Select the frequency of the donor's gifts (e.g., monthly, quarterly).
* **Gift Amount** (`gift_amount`, number, optional): Enter the amount of the last donation.
* **Gift Frequency Other** (`gift_frequency_other`, text, optional): If the donor has a non-standard gift frequency, enter the details.
* **Additional Comments** (`additional_comments`, note, optional): Enter any additional comments about the donor.
* **Assigned User** (`assigned_user`, select_multiple, optional): Check if a user is assigned to the donor.
* **Assigned Date** (`assigned_date`, date, optional): Enter the date the donor was assigned to a user.
* **Assigned Time** (`assigned_time`, time, optional): Enter the time the donor was assigned to a user.
* **Assigned Location** (`assigned_location`, text, optional): Enter the location where the donor will be assigned.
* **Assigned Status** (`assigned_status`, select_one, required): Select the status of the donor (Active or Inactive).
* **Assigned User ID** (`assigned_user_id`, select_one, required): Check if a user ID is assigned to the donor.
* **Assigned Date Time** (`assigned_date_time`, text, required): Enter the date and time the donor was last updated.
* **Assigned Notes** (`assigned_notes`, text, optional): Enter any additional notes about the donor.
* **Created By** (`created_by`, select_one, optional): Check if the form was created by a user.
* **Created By ID** (`created_by_id`, select_one, optional): Check if the form was created by a user ID.

Note: The fields marked as required should be filled out for accurate and complete records. The fields marked as optional provide additional information and context for the donor record.
