# Tip Jar Get On The List Form - Help Guide
## Purpose
This form is for submitting a tip jar request to get on a list. Fill out the form with your category and any additional notes to describe your request.

## How To Complete This Form
1. Select the category you are requesting to get on the list in the "category" field.
2. Enter your email address in the "email" field to ensure we can contact you with further instructions.
3. If applicable, enter your phone number in the "phone" field.
4. Enter your name and organization (if any) in the "name" and "organization" fields, respectively.
5. Select your assigned tool or service from the "assigned_tool" dropdown menu.
6. Select additional categories you would like to get on the list in the "category" dropdown menu.
7. Enter any additional notes in the "notes" field.
8. If necessary, provide additional notes in the "additional notes" field.
9. Enter the desired output file name in the "output file" field.
10. If necessary, provide an additional output file name in the "additional output file" field.
11. Enter the form ID number in the "form id" field.
12. If necessary, enter an additional form ID number in the "additional form id" field.

## Field-by-Field Explanation
* **category** (`category`, Select Multiple, required): Select the category or categories you would like to get on the list.
* **description** (`description`, Text, optional): Provide a brief description of your request if necessary.
* **email** (`email`, Text, required): Enter your email address so we can contact you with further instructions.
* **phone** (`phone`, Text, optional): Enter your phone number if you would like us to contact you via phone.
* **name** (`name`, Text, optional): Enter your name.
* **organization** (`organization`, Text, optional): Enter your organization (if any).
* **assigned_tool** (`assigned_tool`, Select One, optional): Select the tool or service you are requesting.
* **category** (`category`, Select Multiple, optional): Select additional categories you would like to get on the list.
* **notes** (`notes`, Text, optional): Enter any additional notes you would like to provide about your request.
* **additional notes** (`additional notes`, Text, optional): Enter additional notes if necessary.
* **output file** (`output file`, Text, optional): Enter the desired output file name.
* **additional output file** (`additional output file`, Text, optional): Enter an additional output file name.
* **form id** (`form id`, Number, optional): Enter the form ID number.
* **additional form id** (`additional form id`, Number, optional): Enter an additional form ID number.
