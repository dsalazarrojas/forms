# New Book Collection Donation Form - Help Guide
## Purpose
The New Book Collection Donation Form is used to gather information from donors who wish to contribute books to the library's collection.

## How To Complete This Form
- Fill out the form completely and accurately, providing all required information.
- Ensure that you are donating a book that is in good condition.
- If you are representing an organization, please enter the correct organization name and contact phone number.
- If you have any questions or concerns, please contact the library staff.

## Field-by-Field Explanation
- **First Name** (`First Name`, text, required: false): Enter the first name of the person donating the book.
  - This field is optional, but provides the library with a way to address the donor and include them in any future communications.
- **Last Name** (`Last Name`, text, required: true): Enter the last name of the person donating the book.
  - This field is required, as it provides the library with a way to identify the donor and their contact information.
- **Organization** (`Organization`, text, required: true): Enter the name of the organization donating the book.
  - This field is required for organizational donors, and should include the name of the organization.
- **Contact Phone** (`Contact Phone`, text, required: false): Enter the contact phone number of the person responsible for the donation.
  - This field is optional, but provides the library with a way to contact the donor for any additional information.
- **Email** (`Email`, email, required: false): Enter the email address of the person responsible for the donation.
  - This field is optional, but provides the library with a way to contact the donor for any additional information.
- **Donation Date** (`Donation Date`, date, required: false): Enter the date the book was donated.
  - This field is optional, but provides the library with information about the donation timeline.
- **Book Title** (`Book Title`, text, required: true): Enter the title of the book being donated.
  - This field is required, as it provides the library with the title of the book being donated.
- **Edition** (`Edition`, select_one, required: false): Select the edition of the book being donated.
  - This field is optional, but provides the library with information about the book's edition.
- **Condition** (`Condition`, select_multiple, required: true): Select the condition of the book being donated (Good, Fair, Used).
  - This field is required, as it provides the library with information about the book's condition.
  - Please select all that apply.

## Tips
- Please ensure that the book is in good condition and suitable for the library's collection.
- If the book has any damage or defects, please describe them in the form or attach a note.
- If you are unsure about any of the fields, please contact the library staff for assistance.
