# Cuddle Bear Share Copy - Help Guide
## Purpose
The Cuddle Bear Share Copy form is used by authorized personnel to report a donation of cuddle bears made available for distribution.

## How To Complete This Form
1. Fill out the **Form Data** field with a brief description of the cuddle bear donation.
2. Enter your **Name**, **Email**, and **Phone** if you wish to be contacted for further information.
3. Provide your **Address** if you are willing to receive further communication from us.
4. Enter the **Amount Donated** and **Date Donated** for accurate record-keeping.
5. Enter the **Time Donated** if applicable.
6. Select one or more options from the **Select One** dropdown menu.
7. Select multiple options from the **Select Multiple** dropdown menu.
8. Add any additional **Note** about the donation.

## Field-by-Field Explanation
* **Form Data** (`form_data`, text, required): Enter a brief description of the cuddle bear donation.
* **Name** (`name`, text, required): Enter your name for record-keeping purposes.
* **Email** (`email`, email, required): Enter your email address so we can contact you for further information.
* **Phone** (`phone`, text, required): Enter your phone number so we can reach out to you for further information.
* **Address** (`address`, text, required): Enter your address if you are willing to receive further communication from us.
* **Amount Donated** (`amount_donated`, number, required): Enter the number of cuddle bears donated.
* **Date Donated** (`date_donated`, date, required): Enter the date the cuddle bears were donated.
* **Time Donated** (`time_donated`, time, optional): Enter the time the cuddle bears were donated if applicable.
* **Select One** (`select_one`, select_one, optional): Select one option from the dropdown menu.
* **Select Multiple** (`select_multiple`, select_multiple, optional): Select multiple options from the dropdown menu.
* **Note** (`note`, note, optional): Add any additional notes about the donation.

## Tips
* Make sure to fill out all required fields to ensure accurate record-keeping.
* Use a clear and concise description in the **Form Data** field.
* Select only the options that apply to your donation.
* If you have any questions, feel free to contact us for further assistance.
