# third-party-release-form - Help Guide
## Purpose
The purpose of this form is to create a third-party release form, which is a document that grants permission to a third party to access or use sensitive information.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Provide a brief **Description** of the third-party release, including any relevant details.
2. Select the **Third Party Name** from the provided list.
3. If necessary, provide **Sensitive Information** related to the release, such as dates or amounts.
4. Sign the form on the **Signature Date**, which is typically the date of signature.

## Field-by-Field Explanation
- **Employment Release Forms**: This field is the name of the form, which is used to identify the type of release being created.
- **Description**: A brief description of the third-party release, including any relevant details.
- **Third Party Name**: Select the name of the third party to whom permission is being granted.
  - Example: John Doe or Jane Doe
- **Sensitive Information**: If applicable, provide sensitive information related to the release, such as dates or amounts.
  - Format: YYYY-MM-DD or numerical value
- **Signature Date**: The date on which the form is signed, which is typically the date of signature.
  - Format: YYYY-MM-DD

## Tips
- Ensure that the third party name is accurate and complete.
- If sensitive information is required, make sure to format it correctly.
- Sign the form on the designated date to avoid any confusion.
