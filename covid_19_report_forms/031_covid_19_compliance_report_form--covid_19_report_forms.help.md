# COVID 19 Compliance Report Form - Help Guide
## Purpose
This form is a compliance report for healthcare facilities to track their COVID-19 vaccination rates and other related metrics.

## How To Complete This Form
1. Ensure you have all necessary information and data before starting.
2. Select the month or quarter for which you are reporting.
3. Enter the name of your healthcare facility.
4. Choose the type of healthcare facility (e.g., hospital, clinic, nursing home, etc.).
5. Enter the name and title of the person responsible for this report.
6. Provide the contact information for the reporting official.
7. Enter the number of total employees required to comply with the vaccine mandate.
8. Enter the number of fully vaccinated employees.
9. Enter the number of partially vaccinated employees.
10. Enter the number of unvaccinated employees.
11. Enter the number of medical exemptions granted.
12. Enter the number of religious exemptions granted.
13. Enter the number of employees with booster doses.
14. Enter the vaccination deadline date.
15. Enter the current compliance percentage.
16. Describe any enforcement actions taken, if applicable.
17. Enter the number of pending medical exemption requests.
18. Enter the number of pending religious exemption requests.
19. Describe the testing protocol for unvaccinated employees.
20. Enter the number of COVID-19 cases among employees.
21. Enter the number of reported outbreaks.
22. Describe any compliance challenges faced.
23. Describe any improvements made to improve compliance.
24. Finally, certify that the information provided is accurate.

## Field-by-Field Explanation

* **Report Date**: This field is used to select the date of this report.
* **Reporting Period**: This field is used to select the month or quarter for which you are reporting. Please choose the correct period from the options.
* **Facility Name**: This field is used to enter the name of your healthcare facility.
* **Facility Type**: This field is used to choose the type of healthcare facility (e.g., hospital, clinic, nursing home, etc.).
* **Reporting Official Name**: This field is used to enter the name of the person responsible for this report.
* **Reporting Official Title**: This field is used to enter the title of the person responsible for this report.
* **Contact Email**: This field is used to enter the email address of the reporting official.
* **Contact Phone**: This field is used to enter the phone number of the reporting official (optional).
* **Total Number of Employees**: This field is used to enter the number of employees required to comply with the vaccine mandate.
* **Fully Vaccinated Employees**: This field is used to enter the number of fully vaccinated employees.
* **Partially Vaccinated Employees**: This field is used to enter the number of partially vaccinated employees.
* **Unvaccinated Employees**: This field is used to enter the number of unvaccinated employees.
* **Medical Exemptions Granted**: This field is used to enter the number of medical exemptions granted.
* **Religious Exemptions Granted**: This field is used to enter the number of religious exemptions granted.
* **Booster Doses**: This field is used to enter the number of employees with booster doses.
* **Vaccination Deadline**: This field is used to enter the date by which employees must comply with the vaccine mandate.
* **Compliance Percentage**: This field is used to enter the current compliance percentage.
* **Enforcement Actions Taken**: This field is used to describe any enforcement actions taken, if applicable.
* **Pending Medical Exemption Requests**: This field is used to enter the number of pending medical exemption requests.
* **Pending Religious Exemption Requests**: This field is used to enter the number of pending religious exemption requests.
* **Testing Protocol for Unvaccinated Employees**: This field is used to describe the testing protocol for unvaccinated employees.
* **COVID-19 Cases Among Employees**: This field is used to enter the number of COVID-19 cases among employees.
* **Outbreaks Reported**: This field is used to enter the number of reported outbreaks.
* **Compliance Challenges**: This field is used to describe any compliance challenges faced.
* **Improvements Made**: This field is used to describe any improvements made to improve compliance.
* **Certify**: This field is used to certify that the information provided is accurate.
