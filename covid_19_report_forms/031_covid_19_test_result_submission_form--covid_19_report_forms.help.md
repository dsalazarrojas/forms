# COVID 19 Test Result Submission Form - Help Guide
## Purpose
This form is for submitting COVID-19 test results for diagnosis. It is used to collect accurate and consistent data for reporting test results.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the submission date (1) with the date you are submitting the test result.
2. Select the submitter type (2) to indicate who is submitting this result (e.g., Patient or individual, Healthcare provider, etc.).
3. Enter the submitter's first name (3), last name (4), phone number (5), and email (6) to provide contact information.
4. Enter the patient's first name (7), last name (8), date of birth (9), and gender (10) to identify the individual being tested.
5. Fill out the date of test (13) when the test was taken.
6. Select the test result (14) to indicate whether it is positive (P), negative (N), or other (inconclusive, etc.).
7. Select the type of test (15) used to determine the type of test (e.g., PCR, rapid antigen, etc.).
8. Enter the test brand or manufacturer (16) to provide more information about the test.
9. Select the specimen type (17) to indicate the type of sample collected (e.g., nasopharyngeal swab, etc.).
10. Enter the specimen collection date (18) and time (19) to record when the sample was collected.
11. Enter the testing facility name (20), address (21), city (22), state (23), and zip code (24) to identify where the test was performed.
12. Enter the ordering provider name (26) and national provider identifier (27) to record who ordered the test.
13. Enter the date the test result was reported (28) and upload any supporting documents (29) if necessary.
14. Enter any additional comments or information (30) about the test result.
15. Finally, indicate whether you attest that the information submitted is accurate and true (31) and sign with your signature date (32).

## Field-by-Field Explanation
* **Submission Date (1)**: Date of submission of test result.
* **Submitter Type (2)**: Category of who is submitting this result (e.g., Patient or individual, Healthcare provider, etc.).
* **Submitter First Name (3)**: Legal first name of the person submitting the result.
* **Submitter Last Name (4)**: Legal last name of the person submitting the result.
* **Submitter Phone (5)**: Contact phone number of the person submitting the result.
* **Submitter Email (6)**: Contact email of the person submitting the result.
* **Patient First Name (7)**: Legal first name of the individual being tested.
* **Patient Last Name (8)**: Legal last name of the individual being tested.
* **Patient Date of Birth (9)**: MM/DD/YYYY format date of birth of the individual being tested.
* **Patient Gender (10)**: Gender of the individual being tested.
* **Patient Phone (11)**: Contact phone number of the individual being tested (optional).
* **Patient Email (12)**: Contact email of the individual being tested (optional).
* **Test Date (13)**: Date of test when it was taken.
* **Test Result (14)**: Status of test result (positive, negative, etc.).
* **Test Type (15)**: Type of test used to determine the result (e.g., PCR, rapid antigen, etc.).
* **Test Brand or Manufacturer (16)**: Brand or manufacturer of test.
* **Specimen Type (17)**: Type of sample collected (e.g., nasopharyngeal swab, etc.).
* **Specimen Collection Date (18)**: When sample was collected.
* **Specimen Collection Time (19)**: Time of specimen collection (optional).
* **Testing Facility Name (20)**: Name of testing facility where test was performed.
* **Testing Facility Address (21)**: Street address of testing facility.
* **Testing Facility City (22)**: City of testing facility.
* **Testing Facility State (23)**: State of testing facility.
* **Testing Facility ZIP Code (24)**: Postal code of testing facility.
* **Testing Facility Phone (25)**: Contact phone number of testing facility (optional).
* **Ordering Provider Name (26)**: Name of healthcare provider who ordered the test.
* **Ordering Provider NPI (27)**: National provider identifier of healthcare provider.
* **Result Report Date (28)**: Date test result was reported.
* **Upload Test Result Document (29)**: Supporting document for test result (e.g., photo, scan, etc.).
* **Additional Comments (30)**: Any other comments or information about the test result.
* **I Attest (31)**: Statement of attestation that submitted information is accurate and true.
* **Signature Date (32)**: Date of signature of attestation.

## Tips
* Ensure that the form is filled out accurately and truthfully to avoid duplication and ensure correct data collection.
* Upload supporting documents when necessary to provide more information about the test result.
* Verify that test results are reported correctly to ensure accurate data collection and processing.
