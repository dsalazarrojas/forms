# Covid Testing Registration - Help Guide
## Purpose
The Covid Testing Registration form is used to record and track the results of COVID-19 tests performed on patients.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* **Test Type**: Select the type of test performed (PCR, Rapid Antigen Test, or Rapid Antibody Test)
	* **Test Result**: Select the outcome of the test (Positive or Negative)
2. Provide optional information as needed:
	* **Test Name**: A description or identifier for the test
	* **Test Date**: The date the test was performed
	* **Symptoms**: A description of any symptoms exhibited by the patient
	* **Provider Name**: The name of the healthcare provider administering the test
	* **Patient Name**: The name of the patient
	* **Patient Email**: The email address of the patient
	* **Patient Phone**: The phone number of the patient
	* **Patient Address**: The address of the patient

## Field-by-Field Explanation
### Test Name
* **Test Name** (Text, Optional): Enter a description or identifier for the test.

### Test Date
* **Test Date** (Date, Optional): Enter the date the test was performed.

### Test Type
* **Test Type** (Select One, Required): Select the type of test performed.
	+ **PCR**: Polymerase Chain Reaction (PCR) test
	+ **Rapid Antigen Test**: Rapid antigen test for COVID-19
	+ **Rapid Antibody Test**: Rapid antibody test for COVID-19

### Test Result
* **Test Result** (Select Multiple, Required): Select the outcome of the test.
	+ **Positive**: The test was positive for COVID-19
	+ **Negative**: The test was negative for COVID-19

### Symptoms
* **Symptoms** (Text, Optional): Describe any symptoms exhibited by the patient.

### Provider Name
* **Provider Name** (Text, Optional): Enter the name of the healthcare provider administering the test.

### Patient Name
* **Patient Name** (Text, Optional): Enter the name of the patient.

### Patient Email
* **Patient Email** (Email, Optional): Enter the email address of the patient.

### Patient Phone
* **Patient Phone** (Text, Optional): Enter the phone number of the patient.

### Patient Address
* **Patient Address** (Text, Optional): Enter the address of the patient.
