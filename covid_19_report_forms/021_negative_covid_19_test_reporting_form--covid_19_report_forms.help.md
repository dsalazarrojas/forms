# Negative COVID 19 Test Reporting Form - Help Guide
## Purpose
This form is designed to report a negative COVID 19 test result. Please ensure that you are filling out this form correctly and accurately to report a genuine negative test result.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the patient's name.
2. Enter the patient's email address.
3. Select the date of the test.
4. Enter the doctor's name who conducted the test.
5. Enter the test results (e.g., "Negative" if the test was negative).
6. Choose the department where the test was conducted (e.g., Emergency Room, Primary Care Clinic, etc.).
7. Enter your name as the reporting doctor.
8. Select the type of test conducted.

## Field-by-Field Explanation
* **Patient Name** (`patient_name`, `text`, required): This is the name of the patient who underwent the COVID 19 test.
* **Patient Email** (`patient_email`, `email`, required): This is the email address of the patient who underwent the COVID 19 test.
* **Test Date** (`test_date`, `date`, required): Enter the date on which the test was conducted.
* **Doctor Name** (`doctor_name`, `text`, required): Enter the name of the doctor who conducted the test.
* **Test Results** (`test_results`, `text`, required): Enter the result of the test (e.g., "Negative" if the test was negative).
* **Department** (`department`, `text`, required): Choose the department where the test was conducted (e.g., Emergency Room, Primary Care Clinic, etc.).
* **Reporting Doctor** (`reporting_doctor`, `text`, required): Enter your name as the doctor who is reporting the test results.
* **Test Type** (`test_type`, `select_one`, required): Select the type of test that was conducted (e.g., Test 1, Test 2, Test 3).

## Tips
* Make sure to enter accurate and complete information to report a genuine negative test result.
* Use the same format for entering dates (e.g., "MM/DD/YYYY").
* If you are reporting test results for a different test type, select the corresponding option from the dropdown menu.
* This form is intended for reporting negative COVID 19 test results, so make sure to only report actual test results, not positive test results.
* If you're unsure about any information, please contact the relevant authority for further assistance.
