# Library Services Community Feedback Form - Help Guide
## Purpose
The purpose of this form is to gather community feedback about library services.

## How To Complete This Form
1. Please select the branch where you received the service.
2. Choose the type of service you used.
3. Provide the hours you visited the branch.
4. Select any programs or services you participated in.
5. Enter your email address (if you want to receive a response).
6. Enter your phone number (if you want to receive a call).
7. Enter the branch name.
8. Enter the branch address.
9. Enter the branch postal code.
10. Enter the branch city.
11. Enter the branch province.
12. Describe the library programs or services you used.
13. Enter the branch manager's name.
14. Enter the branch manager's title.
15. Enter the branch manager's email.
16. Enter the branch manager's phone number.
17. Enter the branch manager's hours of operation.
18. Enter the branch manager's contact method (e.g. email, phone, etc.).
19. Enter the branch manager's contact information.
20. Select up to 3 images of the branch manager.
21. Enter a description of the branch manager.
22. Enter the branch manager's Facebook handle.
23. Enter the branch manager's Twitter handle.
24. Enter the branch manager's Instagram handle.

## Field-by-Field Explanation
* **Library Branch** (`library_branch`): Select the branch where you received the service.
* **Service** (`staff_service`): Choose the type of service you used (e.g. borrowing a book, asking a question, etc.).
* **Facility Hours** (`library_hours`): Enter the hours you visited the branch (if any).
* **Branch Programs** (`branch_programs`): Select any programs or services you participated in.
* **Email** (`email`): Enter your email address if you want to receive a response.
* **Phone** (`phone`): Enter your phone number if you want to receive a call.
* **Branch Name** (`branch_name`): Enter the name of the branch.
* **Branch Address** (`branch_address`): Enter the address of the branch.
* **Branch Postal Code** (`branch_postal_code`): Enter the postal code of the branch.
* **Branch City** (`branch_city`): Enter the city of the branch.
* **Branch Province** (`branch_province`): Enter the province of the branch.
* **Library Programs** (`library_programs`): Describe the library programs or services you used.
* **Branch Manager** (`branch_manager`): Enter the branch manager's name.
* **Branch Manager Title** (`branch_manager_title`): Enter the branch manager's title.
* **Branch Manager Email** (`branch_manager_email`): Enter the branch manager's email.
* **Branch Manager Phone** (`branch_manager_phone`): Enter the branch manager's phone number.
* **Branch Manager Hours** (`branch_manager_hours`): Enter the branch manager's hours of operation.
* **Branch Manager Contact Method** (`branch_manager_contact_method`): Enter the branch manager's contact method (e.g. email, phone, etc.).
* **Branch Manager Contact Info** (`branch_manager_contact_info`): Enter the branch manager's contact information.
* **Branch Manager Image** (`branch_manager_image`): Select up to 3 images of the branch manager.
* **Branch Manager Description** (`branch_manager_description`): Describe the branch manager.
* **Branch Manager Facebook** (`branch_manager_facebook`): Enter the branch manager's Facebook handle.
* **Branch Manager Twitter** (`branch_manager_twitter`): Enter the branch manager's Twitter handle.
* **Branch Manager Instagram** (`branch_manager_instagram`): Enter the branch manager's Instagram handle.
