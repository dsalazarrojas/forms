# Book Circulation Trend Report Form - Help Guide
## Purpose
The Book Circulation Trend Report Form is used by librarians to report on book circulation trends in their branch. This report helps to identify areas of high demand and opportunities for improvement in circulation services.

## How To Complete This Form
1. Enter a title for this report, which will help to distinguish it from other reports.
2. Enter your name as the librarian responsible for completing this report.
3. Select your branch's name from the dropdown list.
4. Enter the start and end dates of the reporting period.
5. Enter the total number of checkouts and returns for this period.
6. Enter the total number of new member registrations for this period.
7. Enter the number of overdue items for this period.
8. Enter the number of lost items for this period.
9. Select the day with the highest number of checkouts for this period.
10. Enter the date this report was submitted.

## Field-by-Field Explanation

* **Report Title** (Report Title, text, required): Enter a brief title for this report to help distinguish it from other reports.
* **Librarian Name** (Librarian Name, text, required): Enter your name as the librarian responsible for this report.
* **Library Branch** (Library Branch, select_one, required): Select your branch's name from the dropdown list.
* **Reporting Period Start Date** (Reporting Period Start Date, date, required): Enter the start date of the reporting period.
* **Reporting Period End Date** (Reporting Period End Date, date, required): Enter the end date of the reporting period.
* **Total Checkouts This Period** (Total Checkouts This Period, number, required): Enter the total number of items checked out for this period.
* **Total Returns This Period** (Total Returns This Period, number, required): Enter the total number of items returned for this period.
* **New Member Registrations** (New Member Registrations, number, required): Enter the total number of new member registrations for this period.
* **Overdue Items Count** (Overdue Items Count, number, required): Enter the current number of overdue items.
* **Lost Items Count** (Lost Items Count, number, required): Enter the total number of items reported lost for this period.
* **Peak Checkout Day** (Peak Checkout Day, select_one, required): Select the day with the highest number of checkouts for this period.
* **Report Submission Date** (Report Submission Date, date, required): Enter the date this report was submitted.
* **Most Popular Category** (Most Popular Category, select_one, optional): Select the category with the most checkouts for this period.
* **Checkout Trend Compared to Last Period** (Checkout Trend Compared to Last Period, select_one, optional): Select how checkouts compare to the previous period.
* **Percentage Change** (Percentage Change, number, optional): Enter the approximate percentage change in checkouts compared to the previous period.
* **Average Loan Duration Days** (Average Loan Duration Days, number, optional): Enter the average number of days items were kept for this period.
* **Seasonal Factors Affecting Circulation** (Seasonal Factors Affecting Circulation, select_multiple, optional): Select any seasonal factors affecting circulation, such as school holidays or summer reading programs.
* **Challenges or Issues Noted** (Challenges or Issues Noted, text, optional): Enter any challenges or issues affecting circulation that you've noticed.
* **Recommendations for Improvement** (Recommendations for Improvement, text, optional): Enter any suggestions for improving circulation services.
* **Most Popular Titles This Period** (Most Popular Titles This Period, text, optional): List the top 3-5 most popular titles for this period.
* **Checkout Trend Compared to Last Period** (Checkout Trend Compared to Last Period, select_one, optional): Select how checkouts compare to the previous period.
