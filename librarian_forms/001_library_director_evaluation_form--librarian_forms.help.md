# library_director_evaluation_form - Help Guide
## Purpose
The library_director_evaluation_form is designed to collect feedback and evaluations from library directors, patrons, and employees. It's used to assess library director's performance, interactions with patrons, and feedback from employees.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely, making sure to select relevant options for each field.
2. Provide honest and accurate feedback for each section.
3. Select the assigned tools or categories as per the options provided.

## Field-by-Field Explanation

* **Library Director** (`library_director`, text, required): Enter the library director's name or title to associate feedback with a specific director.
* **Patron Feedback** (`patron_evaluation`, text, required): Describe any interactions or experiences you've had with the library director as a patron.
* **Employee Feedback** (`employee_evaluation`, text, required): Share your insights or concerns about library director-employee interactions.
* **Comments** (`library_director_comments`, text, optional): Add any additional comments or feedback you may have about the library director.
* **Assigned Tool** ( `assigned_tool`, select_one, required): Select one tool assigned to the library director for evaluation.
* **Output File** (`output_file`, text, optional): Enter a file name or reference number related to this evaluation.
* **Form ID** (`form_id`, number, optional): Enter a unique ID for this form submission (if required).
* **Description** (`description`, text, optional): Provide a brief description of the evaluation or feedback you're submitting.
* **Category** (`category`, select_one, required): Select the category for this evaluation (e.g., Librarian Forms).
* **Assigned Tool** ( `assigned_tool`, select_multiple, required): Select multiple tools assigned to the library director for evaluation.

Note: This form requires a clear and honest submission to ensure accurate and reliable data collection.
