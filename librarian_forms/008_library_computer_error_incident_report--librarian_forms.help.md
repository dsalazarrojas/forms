# Library Computer Error Incident Report - Help Guide
## Purpose
The Library Computer Error Incident Report form is used to document and report computer errors that have occurred in the library environment. This form helps gather information about the incident, which will aid library staff in identifying and addressing the issue promptly.

## How To Complete This Form
- To complete this form, please read each field description carefully and fill out the required information.
- If you are unsure about any field, please contact your supervisor or IT support for guidance.
- Ensure that you have all necessary information before starting to fill out the form.

## Field-by-Field Explanation
- **User Name** (`user_name`, text, optional): The name of the person who reported the incident.
  Please enter your name as it appears on your library card or badge.
- **Date Incident Began** (`date_incident_began`, date, optional): The date when the incident started.
  Please enter the date in the format YYYY-MM-DD.
- **Description Of Incident** (`description_of_incident`, text, optional): Briefly describe the incident that occurred.
  Be as specific as possible to help library staff understand the issue.
- **Type Of Error** (`type_of_error`, select_one, optional): Select the type of error that occurred.
  Choose from the options provided:
    - Error 1
    - Error 2
    - Error 3
- **Location Where Occurred** (`location_where_occurred`, select_multiple, optional): Select all locations where the incident occurred.
  Choose from the options provided:
    - Location 1
    - Location 2
    - Location 3
- **Urgency** (`urgency`, select_one, optional): Select the urgency level of the incident.
  Choose from the options:
    - Low
    - Medium
    - High
- **Incident Follow Up** (`incident_follow_up`, date, optional): The date when you will follow up with the staff member.
  Enter the date in the format YYYY-MM-DD.
- **Staff Member Name** (`staff_member_name`, text, optional): The name of the staff member involved in the incident.
  Please enter the name as it appears on their library card or badge.

## Tips
- Review each field carefully before submitting the form.
- If you are unsure about any field, please contact your supervisor or IT support for guidance.
- Ensure that you have all necessary information before starting to fill out the form.
