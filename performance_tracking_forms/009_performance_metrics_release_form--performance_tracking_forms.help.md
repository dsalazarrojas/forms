# Performance Metrics Release Form - Help Guide
## Purpose
The Performance Metrics Release Form is used to collect new performance data or updates on existing projects.

## How To Complete This Form
1. Begin by selecting the relevant options for "Employee Performance" and "Project Outcome". You can select multiple options for "Project Outcome" if applicable.
2. Enter the date of the performance metrics release.
3. Enter the time of the performance metrics release.
4. Add any additional notes about the release.
5. Enter the email address of the employee or contact person.
6. Enter the phone number of the employee or contact person.

## Field-by-Field Explanation
* **Employee Performance** (`employee_performance`, text, required): Enter a brief description of the employee's performance.
* **Project Outcome** (`project_outcome`, select_multiple, required): Select all applicable options to describe the project outcome.
* **Date** (`date`, date, required): Enter the date of the performance metrics release in the format `YYYY-MM-DD`.
* **Time** (`time`, time, required): Enter the time of the performance metrics release in the format `HH:MM:SS`.
* **Note** (`note`, note, required): Add any additional comments or notes about the release.
* **Email** (`email`, email, required): Enter the email address of the employee or contact person.
* **Phone** (`phone`, text, required): Enter the phone number of the employee or contact person.
