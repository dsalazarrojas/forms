# Performance Assessment Form - Help Guide
## Purpose
This form is designed to assess an individual's performance in a specific context, such as evaluating employees, students, or other stakeholders. It helps to provide a clear and comprehensive assessment of performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant options for each field based on your assessment of the individual's performance.
2. Answer the questions truthfully and provide accurate information.
3. Ensure that you have a clear understanding of the context and the individual's performance before completing this form.

## Field-by-Field Explanation
- **Performance Assessment Form** (`performance_assessment_form`, Select Multiple, Optional): This field allows you to select all the relevant performance assessments that apply to the individual.
	+ Select all the assessments that you consider relevant to the individual's performance.
	+ Example: If you assess the individual as "Yes" in "Yes" and "No", select both options.
- **Performance Goal** (`performance_goal`, Select One, Optional): This field asks you to select the individual's performance goal.
	+ Choose the option that best describes the individual's performance goal.
	+ Example: If the individual's performance goal is to improve, select "Yes".
- **Performance Rating** (`performance_rating`, Number, Optional): This field asks you to rate the individual's performance on a scale.
	+ Enter a numerical value between 1 and 5 to rate the individual's performance.
- **Feedback Frequency** (`feedback_frequency`, Text, Optional): This field is for providing feedback frequency.
	+ Enter the frequency of feedback you provide to the individual.
- **Performance Level** (`performance_level`, Select One, Optional): This field asks you to select the individual's performance level.
	+ Choose the option that best describes the individual's performance level.
	+ Example: If the individual's performance level is high, select "High".
- **Development Areas** (`development_areas`, Select Multiple, Optional): This field allows you to select all the development areas that apply to the individual.
	+ Select all the development areas that you consider relevant to the individual's performance.
- **Action Plans** (`action_plans`, Text, Optional): This field is for providing action plans for improvement.
	+ Enter any action plans you recommend for the individual to improve their performance.
- **Performance Assessment** (`performance_assessment`, Text, Optional): This field is for providing any additional performance assessment comments.
	+ Enter any additional comments or observations about the individual's performance.
