# Employee Performance Review Extension Form - Help Guide
## Purpose
The Employee Performance Review Extension Form is a tool used by managers to evaluate and provide feedback to employees during a performance period. This form is designed to help identify areas of improvement and strengths, and can be used as a reference for future employee development.

## How To Complete This Form
1. Ensure you are completing this form for the designated performance period to maintain data consistency.
2. Please select an employee from the database or use the unique employee code to access their details.
3. Enter the employee's name in the "Employee Name" field.
4. Select the performance rating for the current period using the "Performance Rating" drop-down menu.
5. Provide feedback on the employee's performance in the "Feedback" field.
6. Select the performance period for the review using the "Performance Period" date field.
7. If desired, add any additional comments for the manager in the "Manager Comments" field.
8. Choose the performance rating scale for this review from the "Performance Rating Scale" drop-down menu.

## Field-by-Field Explanation

* **Employee Name** (text): Enter the name of the employee being reviewed.
* **Performance Review** (text): This field is used to document any notable events or achievements during the performance period.
* **Performance Rating** (select one): Select the rating for the employee's performance during the performance period.
	+ Scale 1: Below expectations.
	+ Scale 2: Meeting expectations.
	+ Scale 3: Exceeding expectations.
	+ Scale 4: Exceeding expectations with some areas for improvement.
	+ Scale 5: Exceeding expectations in most areas.
* **Feedback** (text): Provide detailed feedback on the employee's performance during the performance period.
* **Performance Period** (date): Select the date for the performance period of this review.
* **Manager Comments** (text): Add any additional comments from the manager.
* **Performance Rating Scale** (select one): Select the performance rating scale used during this review.
	+ Scale 1: Below expectations.
	+ Scale 2: Meeting expectations.
	+ Scale 3: Exceeding expectations.
	+ Scale 4: Exceeding expectations with some areas for improvement.
	+ Scale 5: Exceeding expectations in most areas.

## Tips
- Ensure you complete the form for the correct performance period to maintain data consistency.
- Be honest and constructive in your feedback and ratings.
- If you're unsure about a particular field, refer to the employee's job description or previous evaluations.
- Review the form carefully before submission to ensure accuracy.
- Keep the feedback and ratings focused on the performance period specified.
