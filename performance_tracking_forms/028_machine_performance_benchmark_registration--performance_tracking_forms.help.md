# Machine Performance Benchmark Registration - Help Guide
## Purpose
This form is used to register and track the performance of machines, allowing you to record and analyze benchmark test results. This information is crucial for evaluating the performance of machines in various benchmark tests, enabling data-driven decisions to improve performance and optimize machine capabilities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the machine's unique identifier (Machine Id).
2. Provide the machine's name and type (Machine Name and Machine Type).
3. Select whether the machine participated in a benchmark test (Machine Type).
4. Enter the name and description of the benchmark test (Benchmark Test Name and Benchmark Test Description).
5. Set the start and end dates of the benchmark test (Benchmark Start Date and Benchmark End Date).
6. Record the duration of the benchmark test (Benchmark Test Duration).
7. Indicate the test result (Benchmark Test Result).
8. Add any additional notes or comments for the benchmark test (Benchmark Notes).
9. Determine the status of the test (Benchmark Test Status).
10. Enter any additional details or comments for the test result (Benchmark Test Result Details).
11. Provide a comment for the test result (Benchmark Test Result Comment).
12. Record any remarks for the test (Benchmark Test Remarks).
13. Specify who submitted the form and when (Submitted By and Submitted On).

## Field-by-Field Explanation
### Machine Id (<machine_id>)
* **Machine Id** (`<number>`, **required**): Enter the machine's unique identifier.
### Machine Name (<machine_name>)
* **Machine Name** (`<text>`, **required**): Enter the machine's name.
### Machine Type (<machine_type>)
* **Machine Type** (`<select_one>`, **optional**): Select whether the machine participated in a benchmark test. You can choose between 'Yes' or 'No'.
### Benchmark Test Name (<benchmark_test_name>)
* **Benchmark Test Name** (`<text>`, **required**): Enter the name of the benchmark test.
### Benchmark Test Description (<benchmark_test_description>)
* **Benchmark Test Description** (`<text>`, **required**): Enter a brief description of the benchmark test.
### Benchmark Start Date (<benchmark_start_date>)
* **Benchmark Start Date** (`<date>`, **required**): Enter the start date of the benchmark test in YYYY-MM-DD format.
### Benchmark End Date (<benchmark_end_date>)
* **Benchmark End Date** (`<date>`, **required**): Enter the end date of the benchmark test in YYYY-MM-DD format.
### Benchmark Test Duration (<benchmark_test_duration>)
* **Benchmark Test Duration** (`<number>`, **required**): Record the duration of the benchmark test.
### Benchmark Test Result (<benchmark_test_result>)
* **Benchmark Test Result** (`<select_multiple>`, **required**): Indicate the test result by selecting 'Yes' or 'No'.
### Benchmark Notes (<benchmark_notes>)
* **Benchmark Notes** (`<note>`, **optional**): Add any additional notes or comments for the benchmark test.
### Benchmark Test Status (<benchmark_test_status>)
* **Benchmark Test Status** (`<select_one>`, **required**): Determine the status of the test by selecting 'Active' or 'Inactive'.
### Benchmark Test Result Details (<benchmark_test_result_details>)
* **Benchmark Test Result Details** (`<text>`, **optional**): Enter any additional details or comments for the test result.
### Benchmark Test Result Comment (<benchmark_test_result_comment>)
* **Benchmark Test Result Comment** (`<text>`, **optional**): Provide a comment for the test result.
### Benchmark Test Remarks (<benchmark_test_remarks>)
* **Benchmark Test Remarks** (`<text>`, **optional**): Record any remarks for the test.
### Submitted By (<submitted_by>)
* **Submitted By** (`<text>`, **required**): Specify who submitted the form.
### Submitted On (<submitted_on>)
* **Submitted On** (`<date>`, **required**): Enter the date the form was submitted in YYYY-MM-DD format.
