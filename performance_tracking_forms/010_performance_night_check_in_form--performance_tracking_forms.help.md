# performance_night_check_in_form - Help Guide
## Purpose
The performance_night_check_in_form is designed to record information about night-time events and performances.

## How To Complete This Form

To complete this form, follow these steps:

* Fill in your personal details: enter your name, phone number, check-in time, and check-in date.
* If you are attending an event, provide the event details:
	+ Enter the event name.
	+ Select the event date.
	+ Choose the event type (e.g., Event Type 1, Event Type 2, or Event Type 3).
	+ Enter the event description.
	+ Select the event start time.
	+ Enter the event location.
	+ Enter the entrance fee (if applicable).
	+ Enter the event organizer.

## Field-by-Field Explanation

* **Name** (`name`, text, optional): Enter your full name.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Check In Time** (`check_in_time`, time, optional): Enter the time you arrived for the event.
* **Check In Date** (`check_in_date`, date, optional): Enter the date of your arrival.
* **Event Name** (`event_name`, text, optional): Enter the name of the event you are attending.
* **Event Date** (`event_date`, date, optional): Select the date of the event.
* **Event Type** (`event_type`, select one, optional): Choose the type of event (e.g., Event Type 1, Event Type 2, or Event Type 3).
* **Event Location** (`event_location`, text, optional): Enter the event location.
* **Event Start Time** (`event_start_time`, time, optional): Enter the start time of the event.
* **Event Organizer** (`event_organizer`, text, optional): Enter the name of the event organizer.
* **Entrance Fee** (`event_entrance_fee`, number, optional): Enter the entrance fee for the event.
* **Event Description** (`event_description`, text, optional): Enter a description of the event.

## Tips

* Ensure that the event details you enter are accurate and consistent with your actual attendance and performance schedules.
* This form is designed to be completed once per event attendance; if you attend multiple events, create a new form for each occurrence.
* If you have any issues or questions about this form, please contact our support team for assistance.
