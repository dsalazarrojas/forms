# Employment Progress Report - Help Guide
## Purpose
This form is used to track and report on employee performance progress in the organization during a specific reporting period.

## How To Complete This Form

1. Select all the performance goals that the employee has achieved or made progress on during the reporting period.
2. Choose the reporting period for which this progress report applies.
3. Describe the actual performance of the employee in the space provided.
4. Provide any necessary follow-up information, such as deadlines or actions to be taken.
5. Choose the review status of the employee's progress report (Active or Inactive).
6. Add any additional comments or notes about the employee's performance in the documentation field.
7. Enter the email address of the employee being reported on.

## Field-by-Field Explanation

* **Employee Performance** (employee_performance, select_multiple, Optional)
	+ Select all the performance goals that the employee has achieved or made progress on during the reporting period.
* **Reporting Period** (reporting_period, date, Optional)
	+ Choose the date range for which this progress report applies.
* **Performance Goals** (performance_goals, text, Optional)
	+ Describe the performance goals that the employee has achieved or made progress on during the reporting period.
* **Actual Performance** (actual_performance, select_one, Optional)
	+ Choose whether the employee's actual performance is yes or no.
* **Follow-up** (follow_up, time, Optional)
	+ Provide any necessary follow-up information, such as deadlines or actions to be taken.
* **Review Status** (review_status, select_one, Optional)
	+ Choose whether the employee's progress report is Active or Inactive.
* **Documentation** (documentation, note, Optional)
	+ Add any additional comments or notes about the employee's performance in this field.
* **Employee Email** (employee_email, email, Optional)
	+ Enter the email address of the employee being reported on.

## Tips

* Make sure to select all relevant performance goals that the employee has achieved or made progress on.
* Use the reporting period field to ensure that the progress report is for the correct time period.
* Keep the actual performance field to a simple yes or no answer.
* Use the documentation field to add any additional comments or notes about the employee's performance.
* Use a valid email address in the employee email field.
