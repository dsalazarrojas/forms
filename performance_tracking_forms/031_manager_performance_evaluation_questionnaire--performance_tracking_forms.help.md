# Manager Performance Evaluation Questionnaire - Help Guide
## Purpose
The Manager Performance Evaluation Questionnaire is used to assess the performance of a manager based on leadership skills, performance indicators, and other key areas. It is designed to help managers evaluate their performance regularly and identify areas for improvement.

## How To Complete This Form
1. Select the employee feedback options that best describe the manager's performance. (Fields 1-5)
	* **Employee Feedback** (`employee_feedback`): Select one or more of the options provided to describe the manager's performance from the employee's perspective. (Required)
	* **Leadership Skills** (`leadership_skills`): Select whether the manager possesses the leadership skills required for their role. (Required)
	* **Performance Indicators** (`performance_indicators`): Select one or more of the performance indicators that the manager is meeting or exceeding. (Required)
	* **Evaluation Frequency** (`evaluation_frequency`): Select how often the manager is evaluated. (Optional)
	* **Employee Performance** (`employee_performance`): Select one or more of the options that describe the manager's performance. (Required)
2. Enter the evaluation date and cycle date. (Fields 6 and 17)
	* **Evaluation Date** (`evaluation_date`): Enter the date of the current evaluation. (Required)
	* **Evaluation Cycle Date** (`evaluation_cycle_date`): Enter the date of the evaluation cycle. (Required)
3. Enter any manager comments and recommendations. (Fields 7 and 8)
	* **Manager Comments** (`manager_comments`): Enter any comments or feedback from the manager. (Optional)
	* **Manager Recommendations** (`manager_recommendations`): Select any recommendations for the manager's improvement. (Optional)
4. Enter the evaluation status and type. (Fields 10 and 13)
	* **Evaluation Status** (`evaluation_status`): Select whether the evaluation is active or inactive. (Required)
	* **Evaluation Type** (`evaluation_type`): Select the type of evaluation. (Required)
5. Enter the performance rating and employee rating. (Fields 11 and 12)
	* **Employee Rating** (`employee_rating`): Select a rating for the employee's performance. (Required)
	* **Performance Rating** (`performance_rating`): Select a rating for the manager's performance. (Required)
6. Select the form assignment and next evaluation cycle date. (Fields 24 and 22)
	* **Form Assigned To** (`form_assigned_to`): Select who this form is assigned to. (Required)
	* **Next Evaluation Cycle Date** (`next_evaluation_cycle_date`): Enter the date of the next evaluation cycle. (Optional)
7. Select the evaluation cycle frequency and completion status. (Fields 18 and 23)
	* **Evaluation Cycle Frequency** (`evaluation_cycle_frequency`): Select how often the evaluation cycle is completed. (Optional)
	* **Evaluation Cycle Completed** (`evaluation_cycle_completed`): Select whether the evaluation cycle is completed. (Optional)
