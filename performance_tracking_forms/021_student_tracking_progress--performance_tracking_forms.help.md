# Student Tracking Progress - Help Guide
## Purpose
The Student Tracking Progress form is designed to help teachers track and evaluate student progress, identify areas where students need improvement, and provide feedback and support. This form is an essential tool for educators to assess student language skills, monitor their growth, and adjust instruction to meet student needs.

## How To Complete This Form
### Step 1: Gather Information
Before completing the form, make sure you have all the necessary information about the student. This includes their name, language skills, and teacher or teacher assistant assigned to them.

### Step 2: Enter Student Information
- **Student Name**: Enter the student's name to identify them uniquely.
- **Language**: Enter the student's language skills, which can be beginner, intermediate, or advanced.
- **Week Starting Date** and **Week Ending Date**: Enter the start and end dates of the week you observed or assessed the student.
- **Student Level**: Select the student's current level of proficiency.
- **Weekly Progress**: Enter a brief description of the student's progress.
- **Notes**: Add any additional comments or remarks about the student's progress.
- **Email** and **Phone**: Enter the student's contact information, if available.

### Step 3: Select Relevant Teachers and Tools
- **Assigned Teacher**: Select the teacher or teacher assistant assigned to the student.
- **Assigned Tool**: Select the tool or resource used to support the student.

### Step 4: Categorize and Evaluate Progress
- **Category**: Indicate if the student has a category or classification (e.g., 'Yes' or 'No').
- **Category Name**: Enter a brief description of the category or classification.
- **Subcategory**: Select relevant subcategories or classifications (e.g., 'Yes' or 'No').
- **Subcategory Name**: Enter a brief description of the subcategory or classification.
- **Language Proficiency**: Indicate the student's language proficiency level.
- **Language Proficiency Name**: Enter a brief description of the language proficiency level.

## Field-by-Field Explanation

* **Student Name** (`student_name`, text, required): Enter the student's name, which helps to identify them uniquely in the progress assessment.
* **Language** (`language`, text, required): Enter the student's language skills, which can be beginner, intermediate, or advanced.
* **Week Starting Date** (`week_starting_date`, date, required): Enter the start date of the week you observed or assessed the student.
* **Week Ending Date** (`week_ending_date`, date, required): Enter the end date of the week you observed or assessed the student.
* **Student Level** (`student_level`, select_one, required): Select the student's current level of proficiency.
* **Current Language Grade** (`current_language_grade`, text, required): Enter a brief description of the student's current language grade or proficiency level.
* **Weekly Progress** (`weekly_progress`, text, required): Enter a brief description of the student's progress.
* **Notes** (`notes`, note, required): Add any additional comments or remarks about the student's progress.
* **Email** (`email`, email, required): Enter the student's email address, if available.
* **Phone** (`phone`, text, required): Enter the student's phone number, if available.
* **Category** (`category`, select_multiple, required): Indicate if the student has a category or classification (e.g., 'Yes' or 'No').
* **Category Name** (`category_name`, text, required): Enter a brief description of the category or classification.
* **Subcategory** (`subcategory`, select_multiple, required): Select relevant subcategories or classifications (e.g., 'Yes' or 'No').
* **Subcategory Name** (`subcategory_name`, text, required): Enter a brief description of the subcategory or classification.
* **Language Proficiency** (`language_proficiency`, select_one, required): Indicate the student's language proficiency level.
* **Language Proficiency Name** (`language_proficiency_name`, text, required): Enter a brief description of the language proficiency level.

## Tips
* Make sure to fill out all required fields to ensure accurate and complete tracking of student progress.
* Use clear and concise language when filling out fields to avoid confusion.
* Review and update the form regularly to track student progress and adjust instruction accordingly.
