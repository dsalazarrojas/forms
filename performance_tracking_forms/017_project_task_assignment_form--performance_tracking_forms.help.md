# Project Task Assignment Form - Help Guide
## Purpose
The Project Task Assignment Form is a tool used by project managers and owners to assign tasks to team members, track progress, and set deadlines. It provides a clear and structured way to capture essential project information.

## How To Complete This Form

1.  To use this form, simply follow these steps:
    1.  Enter the **Project Title** to provide a brief description of the project.
    2.  Enter the **Task Title** to describe the specific task that needs to be completed.
    3.  Select the **Owner** of the project from the dropdown list.
    4.  Choose the **Assignee** from the dropdown list who will be responsible for completing the task.
    5.  Set the **Due Date** for the task, which represents the deadline for completion.
    6.  Update the **Status** of the task to reflect its current progress.
    7.  Choose the **Priority** level of the task (not used in the current implementation).
    8.  Add any additional **Comments** about the task.
    9.  Finally, enter the **Created By** and **Created At** information, which will be automatically populated.

## Field-by-Field Explanation

*   **Project Title** (text, required/optional):
    The title of the project, briefly describing what the project is about.
*   **Task Title** (text, required/optional):
    A concise description of the specific task that needs to be completed.
*   **Owner** (text, required/optional):
    The person who is leading or responsible for the project.
*   **Assignee** (select one, required/optional):
    The team member or individual assigned to complete the task.
*   **Due Date** (date, required/optional):
    The deadline for the task's completion.
*   **Status** (select one, required/optional):
    The current status of the task, which can be Not Started, In Progress, or Completed.
*   **Priority** (number, required/optional):
    The priority level of the task, currently not used in the implementation.
*   **Comments** (text, required/optional):
    Additional information about the task, for notes or updates.
*   **Created By** (text, required/optional):
    The person who created the project assignment.
*   **Created At** (date, required/optional):
    The date and time when the project assignment was created.

Note: This form is primarily used for internal purposes within the organization and should only be filled out by project managers and owners. If you are not sure about any of the fields, please reach out to the project management team for guidance.
