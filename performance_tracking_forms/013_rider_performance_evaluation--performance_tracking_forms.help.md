# Rider Performance Evaluation - Help Guide
## Purpose
The Rider Performance Evaluation form is designed to collect data on a rider's performance, providing valuable insights for training, development, and evaluation purposes.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the relevant page from the form's pages (currently 1).
2. Fill in the required and optional fields as instructed below.

## Field-by-Field Explanation
- **Performance Assessment** (`rider_performance_evaluation_form_1`, text, optional): This field allows you to provide a brief description or assessment of the rider's performance. You can type in your observations or thoughts about their performance.
- **Rider Name** (`rider_performance_evaluation_form_2`, text, optional): Enter the name of the rider being evaluated.
- **Date of Assessment** (`rider_performance_evaluation_form_3`, date, optional): Fill in the date when the performance assessment was conducted or completed.
- **Rider Performance Score** (`rider_performance_evaluation_form_4`, number, optional): This field is for evaluating the rider's performance on a scale of 0-10. Please enter a numerical value to indicate their performance level.
- **Score** (`rider_performance_evaluation_form_5`, number, optional): Similar to the Rider Performance Score, this field is also for evaluating the rider's performance on a scale of 0-10.
- **Comments** (`rider_performance_evaluation_form_6`, text, optional): Provide any additional comments or feedback about the rider's performance.

## Tips
- Please ensure you've filled in all required fields and provided accurate information about the rider's performance.
- If you're unsure about any field or the form's purpose, refer back to the form's purpose explanation or ask a colleague for assistance.
- This form is intended for internal use only, so please keep sensitive data private and secure.
