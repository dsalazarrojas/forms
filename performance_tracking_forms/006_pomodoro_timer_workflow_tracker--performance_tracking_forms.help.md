# Pomodoro Timer Workflow Tracker - Help Guide
## Purpose
This form is used to track individual Pomodoro timer sessions, providing a comprehensive view of your workflow performance.

## How To Complete This Form

1.  Fill out the form once per session.
2.  Ensure you fill in the Start Time and End Time fields to accurately log your session's start and end.
3.  Enter the Duration in the format `HH:MM:SS`.
4.  Enter the work done for the session in the Work Done field.
5.  Add any notes or comments about the session in the Notes field.
6.  Enter your Email address and Phone number for contact purposes.
7.  Select a Category for the session from the dropdown list.
8.  Select one or more Subcategories relevant to the session.
9.  Select the Assigned Tool used during the session.

## Field-by-Field Explanation

*   **Work Session ID** (`work_session_id`, text, optional): Enter a unique identifier for the session if needed.
    *   This field is optional but provides an extra layer of tracking and referencing.
*   **Start Time** (`start_time`, time, optional): Enter the start time of the session, e.g., 08:00 or 8:00 AM.
    *   Enter the exact time the session began.
*   **End Time** (`end_time`, time, optional): Enter the end time of the session, e.g., 10:30 or 10:30 AM.
    *   Enter the exact time the session ended.
*   **Duration** (`duration`, number, optional): Enter the duration of the session in minutes, e.g., 120 for two hours.
    *   Enter the duration of the session.
*   **Work Done** (`work_done`, number, optional): Enter the amount of work completed during the session.
    *   Enter the amount of work completed.
*   **Notes** (`notes`, note, optional): Add any notes or comments about the session.
    *   Enter any notes or comments.
*   **Email** (`email`, email, optional): Enter your email address for contact purposes.
    *   Enter your email address.
*   **Phone** (`phone`, text, optional): Enter your phone number for contact purposes.
    *   Enter your phone number.
*   **Category** (`category`, select_one, optional): Select a category for the session from the dropdown list.
    *   Select a category for the session.
*   **Subcategory** (`subcategory`, select_multiple, optional): Select one or more subcategories for the session from the dropdown list.
    *   Select one or more subcategories for the session.
*   **Assigned Tool** (`assigned_tool`, select_one, optional): Select the tool used for the session from the dropdown list.
    *   Select the tool used.
