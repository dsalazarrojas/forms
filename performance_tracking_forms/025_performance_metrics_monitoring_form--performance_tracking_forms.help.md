# Performance Metrics Monitoring Form - Help Guide

## Purpose
The purpose of this form is to collect and track performance metrics. Users are expected to input relevant performance indicators and data for analysis and reporting purposes.

## How To Complete This Form

1.  Navigate to the Performance Metrics Monitoring Form, which is likely located in a designated area for performance tracking.
2.  Select the relevant performance indicators from the options provided in the "Select Performance Indicators" field. This field allows users to choose from a list of pre-defined options, including "Performance Metrics", "Other", "None", and "Data".
3.  Indicate whether you plan to collect data for the selected performance indicator(s) by answering "Yes" or "No" in the "Collect Data" field.
4.  If you select "Yes" in the "Collect Data" field, you will be able to input relevant data in the "Performance Metrics" field on the next page.
5.  Review and submit the form to complete the performance metrics monitoring process.

## Field-by-Field Explanation

*   **Select Performance Indicators** (`Select Performance Indicators`, `select_one`, required: false): This field allows users to choose from pre-defined options for performance indicators, which can include performance metrics, other indicators, none, and data collection.
    *   Choose the relevant performance indicators from the options provided, as they relate to the areas you are tracking performance in.
*   **Collect Data** (`Collect Data`, `select_multiple`, required: false): This field indicates whether you plan to collect data for the selected performance indicator(s).
    *   Answer "Yes" if you plan to input data for the selected performance indicator(s), and "No" otherwise.
*   **Performance Metrics** (`Performance Metrics`, `note`, required: false): This field is for inputting actual performance metrics data.
    *   Input relevant data that corresponds to the selected performance indicator(s), such as numerical or text-based metrics.
*   This field appears after selecting "Yes" in the "Collect Data" field.

## Tips
*   Ensure that you have relevant performance metrics data to input before filling out this form.
*   If you are unsure about any field, review the form and its fields for clarity.
*   If you are unable to find the performance metrics monitoring form, contact your supervisor or the designated performance tracking team for assistance.
