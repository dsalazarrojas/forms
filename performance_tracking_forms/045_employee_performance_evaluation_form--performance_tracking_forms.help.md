**Employee Performance Evaluation Form - Help Guide**

## Purpose
The purpose of this form is to assess an employee's performance during a specific period. It allows managers to evaluate an employee's progress towards goals, provide feedback, and identify areas for improvement. This form is to be completed by the manager after the performance period has ended.

## How To Complete This Form

1. Select the employee from the dropdown menu to whom the performance evaluation is being made.
2. Choose the performance period for which the evaluation is being conducted.
3. Enter the date of the performance evaluation.
4. Provide a brief summary of the goals and objectives set for the employee during the performance period.
5. Enter any feedback or comments for the employee.
6. Choose the ratings for the employee's performance (Good or Fair).
7. Select any action items that need to be addressed for the employee.
8. Enter any additional comments or observations about the employee's performance.
9. (Optional) Enter the date of the next performance evaluation.
10. Indicate if this is a yes or no evaluation.

## Field-by-Field Explanation

* **Employee** (`employee`, `select_one`, **required:** No): Choose the employee for whom this performance evaluation is being made.
* **Performance Period** (`performance_period`, `date`, **required:** Yes): Select the period of time for which the evaluation is being conducted.
* **Evaluation Date** (`evaluation_date`, `date`, **required:** Yes): Enter the date of the performance evaluation.
* **Goals** (`goals`, `note`, **required:** No): Enter a brief summary of the goals and objectives set for the employee during the performance period.
* **Feedback** (`feedback`, `text`, **required:** Yes): Enter any feedback or comments for the employee.
* **Ratings** (`ratings`, `select_multiple`, **required:** No): Choose the ratings for the employee's performance (Good or Fair).
* **Action Items** (`action_items`, `select_multiple`, **required:** No): Select any action items that need to be addressed for the employee.
* **Comments** (`comments`, `note`, **required:** No): Enter any additional comments or observations about the employee's performance.
* **Next Evaluation Date** (`next_eval_date`, `date`, **required:** No): (Optional) Enter the date of the next performance evaluation.
* **Evaluation Type** (`evaluation_type`, `select_one`, **required:** Yes): Indicate if this is a yes or no evaluation.

**Tips**

* Make sure to select the correct employee and performance period for accurate evaluation.
* Enter specific and constructive feedback to help the employee improve.
* Use the ratings and action items to guide the employee towards improvement.
* Keep the comments and next evaluation date optional, but provide them if relevant to the evaluation.
* Ensure the evaluation type is accurate to reflect the nature of the evaluation.
