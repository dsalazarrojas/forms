# Task Entry Form - Help Guide
## Purpose
The Task Entry Form is a tool for users to record and track new tasks, including task names, due dates, start and end times, and categorization. This form helps to ensure accurate tracking of tasks, reducing duplication and mismanagement.

## How To Complete This Form
To complete the form, follow these steps:
1. **Start by filling out the "Task Name" field** with a brief and clear description of the task.
2. **Select the "Objective Name" field** to provide more context and details about the task, if necessary.
3. **Enter the "Due Date" in the format `YYYY-MM-DD`** to set a specific date for the task completion.
4. **Set the "Start Time" and "End Time" fields** according to the planned duration of the task, including start and end dates and hours.
5. **Provide a brief description of the task in the "Description" field**, if needed.
6. **Choose a category from the "Category" field** from the options: Performance, Projects, or Reports, to classify the task type.

## Field-by-Field Explanation
* **Task Name (Required)**: A clear and concise name for the task, e.g., "Weekly Meeting".
* **Objective Name**: A more detailed description of the task, e.g., "Bi-weekly team meeting to review progress."
* **Due Date (Required)**: The date by which the task should be completed, in the format `YYYY-MM-DD`.
* **Start Time (Required)**: The start date and time of the task, e.g., `09:00 AM`.
* **End Time**: The end date and time of the task, e.g., `09:00 AM`.
* **Description (Optional)**: A brief description of the task, if needed.
* **Category (Required)**: A classification of the task type, e.g., Performance, Projects, or Reports.
