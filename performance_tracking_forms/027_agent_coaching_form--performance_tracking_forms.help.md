# Agent Coaching Form - Help Guide
## Purpose
The "Agent Coaching Form" is a tool used by coaches and supervisors to provide coaching and development opportunities to agents, focusing on improving their performance in specific areas.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the session details:
	* **-- Coaching Session --**: This is the header section of the form.
	* **Agent name**: Enter the name of the agent being coached.
	* **Coach name**: Enter the name of the coach or supervisor conducting the session.
2. Set the session date:
	* **Session date**: Enter the date of the coaching session.
3. Identify performance focus areas:
	* **Performance focus areas**: Select all areas that need improvement, such as:
		+ Communication
		+ Time management
		+ Product knowledge
		+ Customer handling
		+ Sales technique
4. Document observed issues:
	* **Observed issues**: Describe specific behaviors or outcomes that need improvement.
5. Create an action plan:
	* **Action plan and goals**: Outline measurable objectives agreed upon with the agent.
6. Schedule follow-up:
	* **Follow-up date**: (Optional) Enter the date to review progress (not required for every session).
7. Record coach comments:
	* **Coach comments**: Add any additional coaching notes.
8. Confirm agent understanding:
	* **Agent acknowledgment**: Confirm that the agent understands and acknowledges the action plan.
