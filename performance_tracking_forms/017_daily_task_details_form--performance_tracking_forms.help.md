# Daily Task Details Form - Help Guide
## Purpose
The Daily Task Details Form is designed to collect information about daily tasks, allowing users to record and track their progress, status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief title for the task in the `Daily Task Details Form Title` field.
2. Select the client ID associated with the task.
3. Choose the start and end dates for the task.
4. Choose the start and end times for the task.
5. Provide any additional comments about the task in the `Daily Task Details Form Comments` field.
6. Select the current status of the task from the `Task Status` dropdown menu.
7. Select one or more users assigned to complete the task.
8. Choose the priority level of the task from the `Task Priority` dropdown menu.
9. Optionally, provide additional comments or information in the `Form Comments` field.
10. Enter the email address and phone number associated with the task (optional).
11. Click the "Submit" button to save your changes.

## Field-by-Field Explanation
* **Daily Task Details Form Title** (text, optional): Enter a brief title for the task.
* **Client ID** (number, optional): Select the client ID associated with the task.
* **Start Date** (date, optional): Choose the start date for the task.
* **Start Time** (time, optional): Choose the start time for the task.
* **End Date** (date, optional): Choose the end date for the task.
* **End Time** (time, optional): Choose the end time for the task.
* **Daily Task Details Form Comments** (note, optional): Provide any additional comments or information about the task.
* **Task Status** (select one, required): Select the current status of the task from the dropdown menu.
* **Assigned To** (select multiple, optional): Select one or more users assigned to complete the task.
* **Task Priority** (select one, required): Choose the priority level of the task from the dropdown menu.
* **Form Comments** (text, optional): Provide additional comments or information (optional).
* **Email Address** (email, optional): Enter the email address associated with the task (optional).
* **Phone Number** (text, optional): Enter the phone number associated with the task (optional).
