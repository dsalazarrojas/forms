# Performance And Attention Evaluation - Help Guide
## Purpose
The Performance And Attention Evaluation form is designed to collect data on an individual's or organization's performance and attention evaluation. This form is used for reporting and evaluation purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form fields carefully and ensure you understand what each field represents.
2. Enter your answers to each field based on your knowledge of the individual's or organization's performance and attention.
3. Make sure to complete all required fields, but note that some fields are optional.
4. Double-check your answers for accuracy and completeness.

## Field-by-Field Explanation

* **Performance And Attention Evaluation** (`1`, `text`, required: false):
	+ This field is not a field in the classical sense, but rather a title or header for the form.
* **focus_areas** (`2`, `select_one`, required: false):
	+ Select one of the available options to indicate the areas where the individual or organization excels in terms of performance and attention.
* **Performance Indicators** (`3`, `select_multiple`, required: false):
	+ Choose multiple indicators that reflect the individual's or organization's performance and attention levels.
* **Indicator 1** (`4`, `text`, required: false):
	+ Describe one of the selected performance indicators.
* **Indicator 2** (`5`, `text`, required: false):
	+ Describe another of the selected performance indicators.
* **Indicator 3** (`6`, `text`, required: false):
	+ Describe the third performance indicator.
* **Performance Data Collection** (`7`, `time`, required: false):
	+ Enter the duration for which performance data was collected (e.g., a specific time period or range of dates).
* **data_collection_frequency** (`8`, `select_one`, required: false):
	+ Select how often performance data was collected (Daily, Weekly, or Monthly).
* **data_collection_method** (`9`, `select_one`, required: false):
	+ Choose the method used for performance data collection (Face-to-face, Online, or Other).
* **data_collection_location** (`10`, `select_one`, required: false):
	+ Select where performance data was collected (In-person, Online, or Other).
* **performance_rating** (`11`, `select_one`, required: false):
	+ Evaluate the individual's or organization's performance as Excellent, Needs Improvement, or Satisfactory.
* **performance_rationale** (`12`, `note`, required: false):
	+ Provide a brief explanation for the performance rating, if necessary.
* **Attention Areas** (`13`, `select_multiple`, required: false):
	+ Choose multiple areas where the individual or organization excels in terms of attention.
* **Attention Indicators** (`14`, `select_multiple`, required: false):

* **Attention Indicators 2** (`16`, `text`, required: false):
	+ Describe another of the selected attention indicators.
* **Attention Indicators 3** (`17`, `text`, required: false):
	+ Describe the third attention indicator.
* **Attention Data Collection** (`18`, `time`, required: false):

* **collection_frequency** (`19`, `select_one`, required: false):
	+ Select how often attention data was collected (Daily, Weekly, or Monthly).
* **collection_method** (`20`, `select_one`, required: false):
	+ Choose the method used for attention data collection (Face-to-face, Online, or Other).
* **collection_location** (`21`, `select_one`, required: false):

* **Overall Attention** (`25`, `text`, required: false):
