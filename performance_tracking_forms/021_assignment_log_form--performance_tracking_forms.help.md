# Assignment Log Form - Help Guide

## Purpose
The Assignment Log Form is used to track student assignment progress and performance. This form helps instructors and administrators to record and analyze key details about a student's assignment completion, submission, and grading process.

## How To Complete This Form

1.  To complete this form, find the relevant assignment and student data in your records or system.
2.  Fill in the required fields, including:
	*   Log Entry Date
	*   Student Name
	*   Student ID
	*   Class or Course
	*   Assignment Number
	*   Assignment Title
	*   Assignment Type
	*   Due Date
	*   Submission Date
	*   Submission Method
	*   Was it Late
	*   Is Log Entry Complete
3.  Fill in any applicable optional fields, including:
	*   Days Late (if applicable)
	*   Grade Received
	*   Letter Grade (if applicable)
	*   Grader Comments
	*   Student Notes
	*   Approximate Time Spent (hours)
	*   Difficulty Level
	*   Learning Objectives Met
	*   Resubmission Allowed
	*   Extra Credit Points
	*   Log Recorded By

## Field-by-Field Explanation

*   **Log Entry Date** (`log_entry_date`, date, required): Enter the date of this log entry.
*   **Student Name** (`student_name`, text, required): Enter the full name of the student.
*   **Student ID** (`student_id`, text, required): Enter the student's identification number.
*   **Class or Course** (`class_or_course`, text, required): Enter the name of the class or course.
*   **Assignment Number** (`assignment_number`, text, required): Enter the assignment number in sequence.
*   **Assignment Title** (`assignment_title`, text, required): Enter the title of the assignment.
*   **Assignment Type** (`assignment_type`, select_one, required): Select the type of assignment:
	+   Essay
	+   Project
	+   Problem Set
	+   Presentation
	+   Lab Report
	+   Research Paper
	+   Quiz
	+   Case Study
	+   Other
*   **Due Date** (`due_date`, date, required): Enter the due date of the assignment.
*   **Submission Date** (`submission_date`, date, required): Enter the date of submission.
*   **Submission Method** (`submission_method`, select_one, required): Select the submission method:
	+   Online Portal
	+   Email
	+   In Person
	+   Document Upload
	+   Other
*   **Was it Late** (`is_late`, select_one, required): Was the assignment submitted late?
	+   No
	+   Yes
*   **Days Late** (`days_late`, number, optional): Enter the number of days late (if applicable).
*   **Grade Received** (`grade_received`, number, optional): Enter the numerical grade or score received.
*   **Letter Grade** (`letter_grade`, text, optional): Enter the letter grade received (if applicable).
*   **Grader Comments** (`comments_from_grader`, text, optional): Enter feedback from the grader.
*   **Student Notes** (`student_notes`, text, optional): Enter comments from the student.
*   **Approximate Time Spent** (`time_spent_hours`, number, optional): Enter the approximate time spent on the assignment (in hours).
*   **Difficulty Level** (`difficulty_level`, select_one, optional): Select the difficulty level:
	+   Easy
	+   Moderate
	+   Challenging
	+   Very Difficult
*   **Learning Objectives Met** (`learning_objectives_met`, text, optional): Enter the learning objectives met.
*   **Resubmission Allowed** (`resubmission_allowed`, select_one, optional): Can the student resubmit?
	+   No
	+   Yes
	+   With Conditions
*   **Extra Credit Points** (`extra_credit`, number, optional): Enter any bonus points.
*   **Log Recorded By** (`recorded_by`, text, required): Enter the name of the person logging this entry.
*   **Is Log Entry Complete** (`entry_complete`, select_one, required): Is this log entry complete?
	+   Yes
	+   No

## Tips

*   Ensure that all required fields are filled in before submitting the form.
*   Use clear and concise language when filling in fields.
*   Review and edit your entry before submitting to ensure accuracy.
*   Use this form to track student progress and performance consistently.
