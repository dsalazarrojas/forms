# WAR Weekly Activity Report - Help Guide
## Purpose
This form is designed to collect information for performance tracking, including sales, appointments, recruiting, and other relevant metrics. It is intended to be used by teams within an organization to track their progress and analyze their performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: **WAR Weekly Activity Report** (1), **Category** (2), and **Form ID** (7).
2. Optionally, select a category from the list in **Category** (2) field.
3. Enter a brief description in the **Description** (3) field.
4. Enter a number for **Sales** (4), **Appointments** (5), and **Recruiting** (6) performance metrics.
5. If you have assigned a tool, select it from the list in **Assigned Tool** (8) field.
6. If an output file is required, enter its name in the **Output File** (9) field.

## Field-by-Field Explanation
* **WAR Weekly Activity Report** (1): Enter a brief title for the report.
* **Category** (2): Select a category from the list to classify the report. (Performance Tracking Forms, Other)
* **Description** (3): Enter a brief description of the report, explaining its purpose and content.
* **Sales** (4): Enter the number of sales for the performance period.
* **Appointments** (5): Enter the number of appointments made for the performance period.
* **Recruiting** (6): Enter the number of successful recruitments for the performance period.
* **Form ID** (7): Enter a unique identifier for the form.
* **Assigned Tool** (8): If a tool is assigned to the report, select it from the list. (chatjimmy, Other)
* **Output File** (9): If an output file is required, enter its name.

## Tips
* Ensure that the fields are filled in correctly to ensure accurate performance tracking.
* Use the correct category to classify the report.
* Use a brief and descriptive title for the report.
* Keep the output file name consistent for easy reference.
* Review and revise the report as needed before submission.
