# performance_feedback_session_booking_form - Help Guide
## Purpose
The performance Feedback Session Booking Form is used to collect information for performance feedback sessions between booking managers and reviewers.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary permissions to complete this form.
2. Select the relevant options for each field as required for your session.
3. Enter accurate dates and times for the session.
4. Provide your email address to ensure that you receive any follow-up notifications.
5. Review and select the relevant options for the review form.

## Field-by-Field Explanation
* **First Page** (`1`, `text`, required/optional): Enter the first page of the form, which is usually the name of the session or the title of the form.
* **Session Booking Form** (`2`, `select_one`, required/optional): Select the relevant option for the session booking form, which indicates the type of session being conducted.
* **Date and Time** (`3`, `date`, required/optional): Enter the date and time of the session, which helps in scheduling and recording the session.
* **Time** (`4`, `time`, required/optional): Enter the time of the session, which is usually used to determine the duration of the session.
* **Location** (`5`, `text`, required/optional): Enter the location where the session is being conducted, which helps in identifying the venue.
* **Session Length** (`6`, `number`, required/optional): Enter the length of the session, which is usually used to determine the duration of the session.
* **Booking Manager** (`7`, `select_multiple`, required/optional): Select the relevant booking manager(s) who will be conducting the session, which is usually the person responsible for managing the session.
* **Booking Manager Email** (`8`, `email`, required/optional): Enter the email address of the booking manager, which helps in contacting them for further information.
* **Reviewer** (`9`, `select_one`, required/optional): Select the relevant reviewer who will be providing feedback, which is usually the person providing performance feedback.
* **Reviewer Email** (`10`, `email`, required/optional): Enter the email address of the reviewer, which helps in contacting them for further information.
* **Session Start Time** (`11`, `time`, required/optional): Enter the start time of the session, which is usually used to schedule the session.
* **Session End Time** (`12`, `time`, required/optional): Enter the end time of the session, which is usually used to determine the duration of the session.
* **Session Date** (`13`, `date`, required/optional): Enter the date of the session, which helps in scheduling the session.
* **Review Form** (`14`, `select_multiple`, required/optional): Select the relevant options for the review form, which indicates the type of feedback to be provided.

## Tips
* Be sure to review the form carefully to ensure all required fields are filled out accurately.
* If you are unsure about any field, contact your supervisor or the booking manager for guidance.
* Make sure to submit the form before the session starts to ensure that it is recorded properly.
