# Driver Performance Quarterly Report Form - Help Guide

## Purpose
This form is designed to track and evaluate a driver's performance over a quarter. It provides a structured way to assess their overall performance, feedback, and other relevant details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the overall performance level of the driver using the "Overall Performance" dropdown menu.
2. Provide feedback on the driver's performance in the "Feedback" text field.
3. Record the frequency and duration of the driver's performances using the "Performance Frequency" and "Performance Duration" fields respectively.
4. Evaluate the fleet's performance using the "Fleet Performance" dropdown menu.
5. Enter a numerical rating for the driver and the fleet using the "Overall Rating" and "Fleet Rating" fields respectively.
6. Enter a rating for the driver's performance using the "Rating" field.
7. Enter comments for the driver and the fleet using the "Performance Comments" and "Fleet Comments" fields respectively.
8. Select the good performance levels of the driver using the "Good Performance" dropdown menu.
9. Record the good performance duration of the driver using the "Good Duration" field.
10. Enter a numerical rating for the driver's overall performance using the "Overall Rating 2" field.
11. Enter comments for the driver's overall performance using the "Comments 2" field.
12. Enter a numerical rating for the fleet's overall performance using the "Fleet Rating" field.
13. Enter comments for the fleet's overall performance using the "Fleet Comments" field.
14. Select the overall performance level of the driver using the "Overall Performance 2" dropdown menu.
15. Record the frequency of the driver's performance using the "Performance Frequency 2" field.
16. Enter a numerical rating for the driver's overall performance using the "Overall Rating 3" field.

## Field-by-Field Explanation

* **Overall Performance** (`1`, `select_one`, required):
	+ Select the overall performance level of the driver, which can be Excellent, Good, or Needs Improvement.

	+ Provide feedback on the driver's performance, such as strengths and weaknesses.
* **Performance Frequency** (`3`, `time`, required):
	+ Record the frequency of the driver's performances, such as how often they perform well.
