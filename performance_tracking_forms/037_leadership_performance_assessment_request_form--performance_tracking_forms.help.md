# Leadership Performance Assessment Request Form - Help Guide

## Purpose
The Leadership Performance Assessment Request Form is used to request a performance assessment for a leader within the organization. This form helps assess the leader's performance over a specific period, taking into account the employee's job title, performance ratings, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required and optional fields as instructed below.
2. Ensure that all required fields are filled before submitting the form.
3. Review the form carefully before submitting.

## Field-by-Field Explanation

* **Request Form** (`request_form`): This is the main text field for entering your request.
* **Employee Name** (`employee_name`): Please fill in the name of the employee you are requesting performance assessment for.
* **Job Title** (`job_title`): Fill in the employee's job title to provide context to their performance assessment.
* **Performance Period** (`performance_period`): Select the quarter in which you want to assess the employee's performance (Q1, Q2, Q3, or Q4).
* **Assessment Date** (`assessment_date`): This field is not used for the assessment but is likely intended for tracking purposes. You can leave it blank or fill it in if required by your organization.
* **Manager Name** (`manager_name`): If you are requesting performance assessment from another manager, fill in their name here.
* **Employee Email** (`employee_email`): This field is intended for the employee's email address but is not currently used. You can leave it blank.
* **Employee Phone** (`employee_phone`): This field is intended for the employee's phone number but is not currently used. You can leave it blank.
* **Performance Ratings** (`performance_ratings`): Select the performance ratings for the employee's performance (Excellent, Satisfactory, Needs Improvement).
* **Comments** (`comments`): This is the field for entering any comments or additional information about the employee's performance.
* **Submit Request** (`submit_request`): Choose whether to submit the request or save it for later (Submit, Save for Later).
* **Additional Comments** (`additional_comments`): This field is intended for any additional comments or information but is currently not used. You can leave it blank.
* **Submit Button** (`submit_button`): This field is not used and can be ignored.
* **Employee ID** (`employee_id`): This field is not used and can be ignored.
* **Submit** (`submit_button`): This field is the final submit button for submitting the request.
