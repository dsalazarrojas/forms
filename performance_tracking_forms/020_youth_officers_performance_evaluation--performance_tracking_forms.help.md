# Youth Officers Performance Evaluation - Help Guide
## Purpose
This form is designed to evaluate the performance of youth officers in their role. It is used to gather feedback from supervisors or peers on specific aspects of the youth officer's performance, such as communication and leadership skills, attendance, meeting attendance, time management, and problem-solving abilities.

## How To Complete This Form

1. Select the relevant options for each field, taking into account your first-hand experience with the youth officer's performance.
2. For fields with multiple options (e.g., "Report Submission" and "Collaboration Skills"), select all options that apply.
3. For numerical fields (e.g., "Attendance Record", "Extra Hours", and "Tasks Completed"), enter the actual numbers.
4. For date fields (e.g., "Last Meeting"), enter the date in the correct format.
5. For time fields (e.g., "Start Time"), enter the time in 24-hour format (e.g., 08:00).

## Field-by-Field Explanation

* **Communication Skills (1)** (Select One):
	+ How would you rate the youth officer's communication skills? Rate on a scale of 1-5.
* **Leadership Skills (2)** (Select One):
	+ How would you rate the youth officer's leadership skills? Rate on a scale of 1-5.
* **Attendance Record (3)** (Number):
	+ What is the youth officer's average attendance record? Enter as number.
* **Last Meeting (4)** (Date):
	+ When was the last time the youth officer attended a staff meeting? Enter date.
* **Start Time (5)** (Time):
	+ What is the youth officer's average start time for work each day? Enter time.
* **Report Submission (6)** (Select Multiple):
	+ How well do you rate the youth officer's ability to write and submit reports on time? Select all that apply.
* **Extra Hours (7)** (Number):
	+ What is the number of hours spent on tasks outside of work hours to help with work-related tasks? Enter number.
* **Collaboration Skills (8)** (Select Multiple):
	+ How would you rate the youth officer's ability to work with colleagues and other departments? Select all that apply.
* **Time Management (9)** (Select One):
	+ How would you rate the youth officer's time management skills? Rate on a scale of 1-5.
* **Tasks Completed (10)** (Number):
	+ What is the number of tasks completed within deadlines? Enter number.
* **Problem Solving (11)** (Select Multiple):
	+ How well do you rate the youth officer's problem-solving skills? Select all that apply.
* **Suggestions for Improvement (12)** (Text):
	+ Are there any suggestions or areas for improvement for the youth officer? Enter text.

**Tips**

* Be honest and constructive in your evaluation.
* Provide specific examples to support your answers.
* Focus on performance rather than personality.
* Complete the form in one sitting, if possible.
* Review your answers before submitting the form to ensure accuracy.
* If you are unsure about any field, refer back to your first-hand experience with the youth officer's performance.
