# Performance Improvement Declaration Form - Help Guide
## Purpose
The "Performance Improvement Declaration Form" is designed to collect and track employee performance issues and areas for improvement. This form provides a standard way to document and report on performance problems, ensuring consistency and accuracy in data collection.

## How To Complete This Form

1. **Company**: Type your company's name in this field.
2. **Name**: Enter your name and position in this field.
3. **Role**: Select your role or function that is affected by the performance issue.
4. **Issue**: Choose the specific issue or problem you want to report.
5. **Description**: Briefly describe the issue or problem.
6. **Prophets**: Note the relevant prophets or references, if any.
7. **Date Start**: Enter the start date of the problem or issue.
8. **Date End**: Enter the end date of the problem or issue.
9. **Status**: Select the current status of the problem or issue (In Progress, Completed, or Canceled).
10. **Assigned To**: Optionally, select the person or team assigned to follow up on the issue.
11. **Notes**: Any additional notes or comments about the issue.
12. **Category**: Choose relevant categories for the issue, if any.
13. **Category Other**: If the category does not appear in the list, type it here.
14. **Improvement Goals**: Describe the specific improvement goals or actions to be taken.
15. **Improvement Actions**: Describe the steps to be taken to improve performance.
16. **Next Steps**: Outline the next steps to be taken to resolve the issue.
17. **Follow-up**: If a follow-up action is required, specify it here.
18. **Follow-up Other**: If the follow-up action is not listed, describe it here.
19. **Follow-up Time**: Note the expected time for the follow-up action, if any.
20. **Follow-up Frequency**: Specify the follow-up frequency, if any.
21. **Review Date**: Note when the issue will be reviewed for progress.
22. **Next Follow-up**: Specify the next follow-up date, if any.
23. **Next Follow-up Frequency**: Specify the next follow-up frequency, if any.
24. **Follow-up Status**: Select the current status of the follow-up action (In Progress, Completed, or Canceled).
25. **Follow-up Other**: If the follow-up action is not listed, describe it here.

## Tips
* Make sure to fill out the form with accurate and detailed information.
* Only complete this form for new performance issues, not for updates to existing ones.
* If you are unsure about any field, please contact your supervisor or HR representative for guidance.
