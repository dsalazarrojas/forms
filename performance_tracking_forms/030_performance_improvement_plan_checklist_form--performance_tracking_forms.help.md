# Performance Improvement Plan Checklist Form - Help Guide
## Purpose

The Performance Improvement Plan Checklist Form is a tool used by employees to identify areas where they need to improve their performance and develop plans to address these gaps. The form helps employees and their supervisors to focus on specific goals and actions that need to be taken to improve performance.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the Employee Name and Department fields with the relevant information.
2. Answer the performance gap questions by selecting 'Yes' or 'No' for each question.
3. If you answer 'Yes' to a performance gap, provide a detailed description of the gap in the corresponding text fields.
4. Develop a Performance Improvement Plan by outlining specific goals and actions that need to be taken to address the identified gaps.
5. Select the target start and end dates for when you aim to start and complete the performance improvement plan.
6. Enter your actual start and end dates for when you actually started and finished the performance improvement plan.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text): Enter the name of the employee for whom the performance improvement plan is being created.
* **Employee Department** (`employee_department`, text): Enter the department or team of the employee.
* **Performance Gap** (`performance_gap`, text): Describe the area where the employee needs to improve.
* **Actionable Goals** (`actionable_goals`, text): Outline specific goals that need to be achieved to address the performance gap.
* **Structured Feedback** (`structured_feedback`, text): Describe the feedback that has been given to the employee.
* **Performance Improvement Plan** (`performance_improvement_plan`, text): Outline specific actions and steps that need to be taken to address the performance gap.
* **Target Start Date** (`target_start_date`, date): Enter the date when you aim to start the performance improvement plan.
* **Target End Date** (`target_end_date`, date): Enter the date when you aim to complete the performance improvement plan.
* **Actual Start Date** (`actual_start_date`, date): Enter the date when you actually started the performance improvement plan.
* **Actual End Date** (`actual_end_date`, date): Enter the date when you actually completed the performance improvement plan.
* **Performance Gap Impact** (`performance_gap_impact`, select one): Answer whether the performance gap has had an impact on work.
* **Employee Name 2** (`employee_name_2`, text): Enter the name of another employee (if applicable).
* **Performance Gap 2** (`performance_gap_2`, text): Describe the performance gap for another employee (if applicable).
* **Actionable Goals 2** (`actionable_goals_2`, text): Outline specific goals for another employee (if applicable).
* **Structured Feedback 2** (`structured_feedback_2`, text): Describe feedback given to another employee (if applicable).
* **Performance Improvement Plan 2** (`performance_improvement_plan_2`, text): Outline a performance improvement plan for another employee (if applicable).
* **Target Start Date 2** (`target_start_date_2`, date): Enter the target start date for another employee's performance improvement plan (if applicable).
* **Target End Date 2** (`target_end_date_2`, date): Enter the target end date for another employee's performance improvement plan (if applicable).
* **Actual Start Date 2** (`actual_start_date_2`, date): Enter the actual start date for another employee's performance improvement plan (if applicable).
* **Actual End Date 2** (`actual_end_date_2`, date): Enter the actual end date for another employee's performance improvement plan (if applicable).
* **Performance Gap Impact 2** (`performance_gap_impact_2`, select one): Answer whether the performance gap for another employee has had an impact on work.
* **Phone Number 1** (`phone_number_1`, text): Enter a phone number for another contact (if applicable).
* **Email 1** (`email_1`, email): Enter an email address for another contact (if applicable).
* **Phone Number 2** (`phone_number_2`, text): Enter a phone number for another contact (if applicable).
* **Email 2** (`email_2`, email): Enter an email address for another contact (if applicable).

## Tips

* Ensure that you are filling out the form accurately and completely.
* If you are unsure about any information, consult with your supervisor or HR representative before proceeding.
* Review the form carefully before submitting it to ensure that you have covered all necessary information.
