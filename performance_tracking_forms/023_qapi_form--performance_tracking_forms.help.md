# Qapi Form - Help Guide
## Purpose
This form is designed to track performance and quality improvement activities within an organization. It helps to evaluate and monitor progress in various areas, ensuring that improvements are made and standards are met.

## How To Complete This Form
1. Review each page carefully to understand what information is required.
2. Fill in all required fields, indicated by an asterisk (\*) or marked as "required" in the field label.
3. For select_one fields (like "quality_assurance"), select only one option that best describes the current situation.
4. For date fields (like "quality_improvement"), enter the date in the format MM/DD/YYYY.
5. For number fields (like "performance_improvement"), enter a numerical value.

## Field-by-Field Explanation

* **performance_tracking_form** (page_1, text, required/optional): This field is used to record any relevant details about the performance tracking activity.
* **quality_assurance** (page_2, select_one, required/optional): This field is used to evaluate the quality of the activity. Select one of the options provided: Good or Poor.
* **nursing_home** (page_3, text, required/optional): Enter any relevant information about the nursing home being tracked.
* **improvement_activities** (page_4, text, required/optional): Describe any improvement activities that were performed or planned.
* **quality_improvement** (page_5, date, required/optional): Enter the date of the quality improvement activity.
* **activities** (page_6, text, required/optional): Record any activities performed or planned for quality improvement.
* **performance_improvement** (page_7, number, required/optional): Enter a numerical value representing the performance improvement.
* **improvement_activities** (page_8, text, required/optional): Describe any additional improvement activities performed or planned.
