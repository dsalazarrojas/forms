# Employee Performance Monitoring Form - Help Guide
## Purpose
The Employee Performance Monitoring Form is a tool used to evaluate and monitor employee performance. It is designed to help managers assess an employee's work quality, identify areas for improvement, and set goals for future performance.

## How To Complete This Form
To complete the form effectively, follow these steps:

1. **Manager Rating**: This section is optional, but if used, it allows you to rate the employee's overall performance. Select a number from 1 to 5, where 1 is Unsatisfactory and 5 is the highest rating.
2. **Feedback Comments**: Share your observations and thoughts about the employee's performance. This section is also optional, but it helps provide specific feedback that can be used to improve performance.
3. **Evaluation Criteria**: Select all criteria relevant to the employee's performance. This ensures that all important aspects are considered during the evaluation.
4. **Performance Level**: Assess the employee's performance by selecting one option from the given scale: Satisfactory, Needs Improvement, or Unsatisfactory.
5. **Employee Rating**: Select one option from the 5-point scale to rate the employee's performance. A higher number indicates better performance.
6. **Action Items**: Provide a text area for suggestions or action items for the employee to improve their performance.
7. **Next Review Date**: Enter the date for the next review, if applicable.
8. **Review Notes**: Add any additional comments or notes about the employee's performance.
9. **Evaluation Notes**: Record any observations or insights gained during the evaluation.
10. **Manager Signature**: This is for your digital signature, indicating that you have completed the review.
