# Performance Review Meeting Request Form - Help Guide
## Purpose
The Performance Review Meeting Request Form is designed to request a meeting for employee performance reviews. This form collects necessary information to facilitate the meeting preparation process.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the date requested for the meeting.
2.  Enter the ID of the employee being reviewed.
3.  Fill in the name of the employee being reviewed.
4.  Enter the ID of the employee's manager.
5.  Enter the name of the employee's manager.
6.  Choose the type of review meeting (Regular, Development, or Performance Improvement).
7.  Select the meeting time.
8.  Specify the meeting duration in minutes.
9.  Choose the meeting location (Office, Offsite, or Remote).
10.  Optionally, add any additional notes for the meeting.
11.  Enter the email address of the employee being reviewed.
12.  Enter the phone number of the employee being reviewed.
13.  Finally, specify the tool assigned for the meeting (this field is optional).

## Field-by-Field Explanation

*   **Meeting Request**: Enter a brief description of the meeting request.
    *   Type: Text
    *   Required: No
*   **Date Requested**: Enter the date you would like to hold the meeting.
    *   Type: Date
    *   Required: No
*   **Employee ID**: Enter the ID of the employee being reviewed.
    *   Type: Text
    *   Required: No
*   **Employee Name**: Enter the name of the employee being reviewed.
    *   Type: Text
    *   Required: No
*   **Manager ID**: Enter the ID of the employee's manager.
    *   Type: Text
    *   Required: No
*   **Manager Name**: Enter the name of the employee's manager.
    *   Type: Text
    *   Required: No
*   **Review Type**: Choose the type of review meeting (Regular, Development, or Performance Improvement).
    *   Type: Select One
    *   Required: No
*   **Meeting Time**: Enter the time of the meeting.
    *   Type: Time
    *   Required: No
*   **Meeting Duration**: Specify the meeting duration in minutes.
    *   Type: Number
    *   Required: No
*   **Location**: Choose the meeting location (Office, Offsite, or Remote).
    *   Type: Select One
    *   Required: No
*   **Note**: Add any additional notes for the meeting.
    *   Type: Note
    *   Required: No
*   **Email**: Enter the email address of the employee being reviewed.
    *   Type: Email
    *   Required: No
*   **Phone**: Enter the phone number of the employee being reviewed.
    *   Type: Text
    *   Required: No
*   **Assigned Tool**: Specify the tool assigned for the meeting.
    *   Type: Text
    *   Required: No
