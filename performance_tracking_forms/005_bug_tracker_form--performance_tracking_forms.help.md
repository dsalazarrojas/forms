# Bug Tracker Form - Help Guide
## Purpose
The Bug Tracker Form is a tool used to report and track bugs or issues that need to be addressed. It helps in gathering all necessary information to efficiently identify and resolve the problem.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your contact information in the top section.
2. In the Bug Details section, provide a brief summary of the issue in the Bug title field.
3. Describe the problem in detail in the Bug description field.
4. Specify the steps to reproduce the bug in the reproduce steps field.
5. State the expected and current behavior of the system.
6. Select the urgency level of the issue.
7. Provide system information such as the operating system and browser being used.
8. If applicable, specify the operating system version and browser version.
9. Identify the type of device you are using.
10. Select the frequency of occurrence of the issue.
11. If available, copy and paste any error messages or codes.
12. If a workaround is available, describe it.
13. Specify the impact of the issue on users.

## Field-by-Field Explanation
* **Full name**: Enter your full name for contact purposes.
* **Email address**: Enter your email address so we can contact you for more information.
* **Phone number**: Provide your phone number for immediate contact (optional).
* **Bug title**: A brief summary of the issue.
* **Bug description**: Describe the problem in detail.
* **Steps to reproduce**: List each step clearly.
* **Expected behavior**: Describe how the system should behave.
* **Current behavior**: Describe what is actually happening.
* **Urgency level**: Select the urgency level of the issue (Critical, High, Medium, Low).
* **Operating system**: Specify the operating system you are using.
* **Browser being used**: Specify the browser being used.
* **Device type**: Specify the type of device you are using.
* **Application version**: Specify the application version.
* **Network connection type**: Specify the type of network connection.
* **Frequency of occurrence**: Select the frequency of occurrence of the issue (Every time, Most of the time, Sometimes, Rarely, Could not reproduce).
* **Error message or code**: If available, copy and paste any error messages or codes.
* **Is there a workaround?**: Select if a workaround is available.
* **Workaround description**: If a workaround is available, describe it.
* **Impact on users**: Select the impact on users (Just me, A few users, Multiple departments, All users).
