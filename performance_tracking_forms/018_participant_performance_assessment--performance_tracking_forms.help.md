# Participant Performance Assessment - Help Guide
## Purpose
The Participant Performance Assessment form is used to evaluate the performance of participants in various activities, events, or programs. It helps assess their skills, progress, and overall performance. This form is typically used by facilitators, coaches, or instructors to gather data on participant's abilities and provide feedback for improvement.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the participant for whom you want to create the assessment.
2. Fill in the Participant ID number.
3. Enter the participant's current skills level on the "participant_skills" field.
4. Rate the participant's progress on the "participant_progress" field using a numerical value (e.g., 1-10).
5. Fill in any additional comments or notes about the participant's performance.

## Field-by-Field Explanation
* **participant_skills** (number, Optional): Enter the participant's current level of skills in this activity/event/program, using a numerical value (e.g., 1-10).
* **participant_progress** (number, Optional): Rate the participant's progress on this activity/event/program, using a numerical value (e.g., 1-10).
* **Participant ID** (number, Required): Enter the participant's unique ID number. This is the unique identifier for the participant being assessed.
