# Match Performance Evaluation - Help Guide
## Purpose
The "Match Performance Evaluation" form is used to assess the performance of a match, considering various factors such as player, team, and match information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide a brief description of the player's or team's performance during the match.
2.  Specify the match details, including any relevant information about the match such as date, opponents, and location.
3.  Evaluate the match outcome, selecting either "Yes" or "No" to indicate if the player or team was successful.
4.  Enter the match score, if applicable.
5.  Record the match time, if relevant.
6.  Ensure that all fields are completed as necessary, as some fields are optional.

## Field-by-Field Explanation
- **player_performance** (`player_performance`, text, optional): Enter a description of the player's performance during the match. This could include notes on their strengths, weaknesses, and areas for improvement.
- **match_details** (`match_details`, text, optional): Provide any relevant information about the match, such as date, opponents, and location.
- **team_performance** (`team_performance`, text, optional): Describe the team's performance during the match. This could include notes on their strategy, teamwork, and overall execution.
- **match_outcome** (`match_outcome`, select one, optional): Evaluate the match outcome by selecting either "Yes" or "No" to indicate if the player or team was successful.
- **match_score** (`match_score`, number, optional): Enter the match score, if applicable. This could be a numerical value or a description of the score.
- **match_time** (`match_time`, time, optional): Record the match time, if relevant. This could be the length of the match or the time elapsed during the match.

## Tips
- Be specific and objective when evaluating the match performance.
- Use clear and concise language when describing the player's, team's, and match information.
- Ensure that all fields are completed as necessary, as some are optional.
- Review the form carefully before submitting it to ensure accuracy and completeness.
