# leadership_performance_monitoring_form - Help Guide
## Purpose
This form is designed to help track leadership performance by gathering feedback and insights on assigned tools and output files.
## How To Complete This Form
To complete this form, please follow these steps:

1. Navigate through the different pages, and fill in the required fields for each page.
2. For select one and select multiple fields, choose the relevant option from the dropdown list.
3. For text fields, provide a brief description or explanation.
4. For notes, add any additional information or comments.

## Field-by-Field Explanation

* **Category** (`leadership_performance_monitoring_form_category`, select_one, required): Select one of the provided options to indicate the category of the leader being monitored.
* **Form Category** (`form_category`, select_multiple, required): Select multiple options that apply to the leader's category.
* **Description** (`description`, text, optional): Provide a brief description or explanation of the leader's performance.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select one of the options to indicate if the leader has an assigned tool.
* **Output File** (`output_file`, text, optional): Provide the path to the output file.
