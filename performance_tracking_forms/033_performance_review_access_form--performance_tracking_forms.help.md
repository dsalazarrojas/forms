# Performance Review Access Form - Help Guide

## Purpose

This form is used to access and evaluate employee performance over a specific period. It's designed for managers to assess an employee's strengths and areas for improvement. Ensure that you're accessing the correct form and completing it for the right person to avoid duplication and errors.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Employee Name to associate the form with the correct employee.
2. Select the Manager Name who is responsible for this performance review.
3. Select the Department and Job Title of the employee being evaluated.
4. Choose the Rating Scale and Performance Ratings for each of the seven categories.
5. Enter any additional comments or recommendations for promotion or termination.
6. Set the Evaluation Date and Frequency.

## Field-by-Field Explanation

* **Employee Name**: Enter the name of the employee being evaluated.
* **Manager Name**: Select the name of the manager responsible for this performance review.
* **Department**: Select the department the employee belongs to (Finance, HR, Marketing, or Sales).
* **Job Title**: Enter the job title of the employee being evaluated.
* **Rating Scale**: Select the rating scale for each category (Scale 1-5, Scale 6-10, or Scale 11-15).
* **Performance Comments**: Enter any additional comments or feedback for the employee.
* **Recommendation for Promotion**: Select "Yes" or "No" to indicate if a promotion is recommended.
* **Recommendation for Termination**: Select "Yes" or "No" to indicate if termination is recommended.
* **Evaluation Date**: Set the date of the performance evaluation.
* **Evaluation Frequency**: Select the frequency of the evaluation (Monthly, Quarterly, Semi-Annually, or Annually).
* **Evaluation Comments**: Enter any additional comments or feedback for the employee.
* **Performance Rating**: Enter a number rating for each category (1-10).
* **Rating Scale 2-7**: Repeat the same field explanations for each of the seven categories (2-7).
* **Performance Rating 2-7**: Enter a number rating for each category.

## Tips

* Ensure that you've filled out all required fields before submitting the form.
* Double-check that you've selected the correct rating scales and performance ratings for each category.
* Enter any additional comments or feedback for the employee to help them improve.
* Review the form carefully before submitting it to prevent errors and ensure accuracy.
