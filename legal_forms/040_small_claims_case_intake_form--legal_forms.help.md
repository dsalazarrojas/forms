# Small Claims Case Intake Form - Help Guide

## Purpose
This form is used to collect and manage information for new, previously unfilled small claims cases.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the Claimant Info section with the relevant information about the claimant.
2. Provide details about the defendant in the Defendant Info section.
3. Add a description of the case in the Case Description field.
4. Choose the case type from the Case Type dropdown menu.
5. Select the court location where the case will be heard.
6. Choose the court date and time.
7. Select the case status.
8. If the case is not a standard small claims case, select "Other" as the case type and provide a description in the Other Case Type Description field.
9. Select the case category.
10. Fill in any relevant notes or comments.
11. Enter the email and phone number of the claimant or representative.
12. Enter the case number (if available).
13. Click the Submit button to send the form.

## Field-by-Field Explanation

* **Claimant Info (<name>, <type: text, required: false>):** Enter the information about the claimant.
* **Defendant Info (<name>, <type: text, required: false>):** Enter the information about the defendant.
* **Case Details (<name>, <type: text, required: false>):** Provide a brief description of the case.
* **Case Type (<name>, <type: select_one, required: false>):** Select the type of case (e.g. "Small Claims").
* **Court Location (<name>, <type: select_multiple, required: false>):** Choose the location where the case will be heard.
* **Court Date (<name>, <type: date, required: false>):** Enter the date of the court hearing.
* **Court Time (<name>, <type: time, required: false>):** Enter the time of the court hearing.
* **Case Status (<name>, <type: select_one, required: false>):** Select the current status of the case (e.g. "Filing Started", "In Progress", "Resolved").
* **Assigned Clerk (<name>, <type: select_one, required: false>):** Select the clerk assigned to the case.
* **Notes (<name>, <type: note, required: false>):** Enter any additional notes or comments about the case.
* **Email (<name>, <type: email, required: false>):** Enter the email of the claimant or representative.
* **Phone (<name>, <type: text, required: false>):** Enter the phone number of the claimant or representative.
* **Case Number (<name>, <type: text, required: false>):** Enter the case number (if available).
* **Case Name (<name>, <type: text, required: false>):** Enter the name of the case.
* **Case Description (<name>, <type: text, required: false>):** Enter a description of the case.
* **Plaintiff Name (<name>, <type: text, required: false>):** Enter the name of the plaintiff.
* **Defendant Name (<name>, <type: text, required: false>):** Enter the name of the defendant.
* **Court Case Number (<name>, <type: text, required: false>):** Enter the case number (if available).
* **Other Case Type (<name>, <type: text, required: false>):** Select "Other" as the case type and provide a description.
* **Other Case Type Description (<name>, <type: text, required: false>):** Enter a description of the other case type.
* **Case Category (<name>, <type: select_multiple, required: false>):** Select the category of the case.
* **Case Category Description (<name>, <type: text, required: false>):** Enter a description of the category.
* **Jurisdiction (<name>, <type: text, required: false>):** Enter the jurisdiction.
* **Jurisdiction Description (<name>, <type: text, required: false>):** Enter a description of the jurisdiction.
* **Submit (<name>, <type: text, required: false>):** Click this button to submit the form.
