# Legal Case File Error Incident Report - Help Guide
## Purpose
The Legal Case File Error Incident Report form is designed to report errors or incidents that have occurred during the legal case filing process. By providing detailed information about the case number, incident date, error description, and other relevant details, this form helps the case team to quickly identify and resolve the issue.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the case number of the case you are reporting the error for.
2. Provide a brief description of the error or incident that occurred.
3. Specify the date the error or incident happened.
4. Choose the error level (High or Low) to indicate the severity of the issue.
5. Provide a detailed description of the error cause.
6. Describe the corrective action to be taken.
7. Enter the name of the person submitting the report.
8. Enter the name of the contact person responsible for the case.

## Field-by-Field Explanation

* **Case Number** (`case_number`, number, required: false): Enter the case number of the case you are reporting the error for. This is an optional field, but it helps the case team to quickly identify the case and resolve the issue.
* **Case Name** (`case_name`, text, required: false): Provide a brief description of the case, including the name of the parties involved. This is an optional field, but it helps the case team to understand the context of the issue.
* **Incident Date** (`incident_date`, date, required: false): Enter the date when the error or incident occurred. This is an optional field, but it helps the case team to understand when the issue happened.
* **Error Description** (`error_description`, text, required: false): Provide a detailed description of the error or incident. This field should include all relevant details about what happened, including any steps taken to correct the issue.
* **Error Level** (`error_level`, select multiple, required: false): Choose the error level (High or Low) to indicate the severity of the issue. This helps the case team to prioritize and handle the case accordingly.
* **Error Cause** (`error_cause`, text, required: false): Provide a detailed description of the cause of the error or incident. This field should include all relevant details about what led to the issue.
* **Corrective Action** (`corrective_action`, text, required: false): Describe the action taken to correct the error or incident. This field should include any steps taken to resolve the issue.
* **Submitter** (`submitter`, text, required: false): Enter the name of the person submitting the report. This field is optional, but it helps the case team to contact the submitter if any follow-up questions arise.
* **Contact Person** (`contact_person`, text, required: false): Enter the name of the contact person responsible for the case. This field is optional, but it helps the case team to communicate with the person involved.

## Tips
- Please provide accurate and clear information about the error or incident.
- Make sure to include all relevant details to help the case team understand the issue.
- If you are unsure about what to enter in a field, refer to your case notes or ask your supervisor for guidance.
