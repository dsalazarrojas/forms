# FOD Clarity Agreement Signing - Help Guide
## Purpose
The FOD Clarity Agreement Signing form is used to document and track the agreement process between the consultant, team, and project manager. This form ensures that all relevant details are captured accurately and efficiently.

## How To Complete This Form
1. Start by filling in the project name in the "Project Name" field. This is the name of the project being agreed upon.
2. Provide a brief description of the agreement in the "Agreement Details" field.
3. Enter the date the consent was given in the "Consent Date" field.
4. Input the consultant's electronic signature in the "E-Signature" field.
5. Enter the consultant's name, email, and phone number in the "Consultant Name", "Consultant Email", and "Consultant Phone" fields respectively.
6. Enter the project manager's name, email, and phone number in the "Project Manager Name", "Project Manager Email", and "Project Manager Phone" fields respectively.
7. Enter the client's name, email, and phone number in the "Client Name", "Client Email", and "Client Phone" fields respectively.
8. Enter the organization's name in the "Organization" field.
9. Select the consultant's status in the "Consultant Status" field.
10. Select the project's status in the "Project Status" field.
11. Select the team's status in the "Team Status" field.
12. Select the agreement status of the consultant in the "Consultant Agreement Status" field.
13. Select the agreement status of the team in the "Team Agreement Status" field.
14. Finally, click "Submit" to save the form data.

## Field-by-Field Explanation
* **Project Name** (1, text, required): Enter the name of the project being agreed upon.
* **Agreement Details** (2, text, optional): Provide a brief description of the agreement.
* **Consent Date** (3, date, optional): Enter the date the consent was given.
* **E-Signature** (4, email, optional): Input the consultant's electronic signature.
* **Consultant Name** (5, text, optional): Enter the consultant's name.
* **Consultant Email** (6, email, optional): Enter the consultant's email address.
* **Consultant Phone** (7, text, optional): Enter the consultant's phone number.
* **Project Manager Name** (8, text, optional): Enter the project manager's name.
* **Project Manager Email** (9, email, optional): Enter the project manager's email address.
* **Project Manager Phone** (10, text, optional): Enter the project manager's phone number.
* **Client Name** (11, text, optional): Enter the client's name.
* **Client Email** (12, email, optional): Enter the client's email address.
* **Client Phone** (13, text, optional): Enter the client's phone number.
* **Organization** (14, text, optional): Enter the organization's name.
* **Consultant Status** (15, select_one, optional): Select the consultant's status.
* **Project Status** (16, select_one, optional): Select the project's status.
* **Team Status** (17, select_one, optional): Select the team's status.
* **Consultant Agreement Status** (18, select_one, optional): Select the consultant's agreement status.
* **Team Agreement Status** (19, select_one, optional): Select the team's agreement status.
* **Notes** (8, note, optional): Enter any additional notes related to the agreement.
* **Output File** (9, text, optional): Enter the output file name.
* **Team Name** (10, text, optional): Enter the team name.
* **Team Email** (11, email, optional): Enter the team email address.
* **Team Phone** (12, text, optional): Enter the team phone number.
* **Project Manager Name** (13, text, optional): Enter the project manager's name.
* **Project Manager Email** (14, email, optional): Enter the project manager's email address.
* **Project Manager Phone** (15, text, optional): Enter the project manager's phone number.
