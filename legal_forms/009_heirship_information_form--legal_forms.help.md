# Heirship Information Form - Help Guide
## Purpose
The Heirship Information Form is used to collect details about the relationships between heirs and beneficiaries in a legal context. This form is useful for administrative or legal purposes, such as estate planning or probate.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you understand each field and its purpose.
2. Answer all required fields. Fields with the label "required" are essential to providing accurate information.
3. Provide accurate and clear information for each field. If you're unsure about a field, ask for clarification.
4. Submit the form when you've completed all required fields.

## Field-by-Field Explanation

* **family_tree**: Enter a brief description of the family tree, including any relevant details about the relationships between the heir and the beneficiary.
	+ Type: text
	+ Required: false
* **beneficiary_relationship**: Select whether there is a beneficiary relationship.
	+ Type: select_one
	+ Options: Yes, No
	+ Required: false
* **beneficiary_relationship_2**, **beneficiary_relationship_3**, **beneficiary_relationship_4**, **beneficiary_relationship_5**, **beneficiary_relationship_6**: These fields are similar to "beneficiary_relationship" and should be answered consistently with the previous field.
	+ Type: select_multiple
	+ Options: Yes, No
	+ Required: false
* **heirship_property_1**, **heirship_property_2**, **heirship_property_3**: Enter details about the heirship property, if applicable.
	+ Type: text
	+ Required: false
* **heir_beneficiary_account_1**, **heir_beneficiary_account_2**, **heir_beneficiary_account_3**, **heir_beneficiary_account_4**, **heir_beneficiary_account_5**, **heir_beneficiary_account_6**: These fields are related to the account of the heir and beneficiary. Enter details about these accounts, if applicable.
	+ Type: text
	+ Required: false
* **heirship_follow_ups_1**, **heirship_follow_ups_2**, **heirship_follow_ups_3**, **heirship_follow_ups_4**, **heirship_follow_ups_5**: Select whether there are follow-ups related to the heirship.
	+ Type: select_multiple
	+ Options: Yes, No
	+ Required: false
* **heir_beneficiary_update_1**, **heir_beneficiary_update_2**, **heir_beneficiary_update_3**, **heir_beneficiary_update_4**: These fields are related to the update of the heir and beneficiary. Enter details about these updates, if applicable.
	+ Type: text
	+ Required: false

## Tips

* Be careful not to duplicate information across fields.
* Review each field carefully to ensure accurate and clear information.
* If you're unsure about a field, ask for clarification.
* Submit the form when you've completed all required fields.
