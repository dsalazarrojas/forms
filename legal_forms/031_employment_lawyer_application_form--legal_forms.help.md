# employment_lawyer_application_form - Help Guide
## Purpose

This form is designed to collect information from users for employment law matters. It helps legal professionals understand the user's context and requirements for employment-related legal issues.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your user details.
2. Describe the employment issues you are facing.
3. Provide a brief description of the legal issue you are experiencing.
4. Choose your preferred language for communication.
5. Enter your email address and phone number for contact purposes.
6. Select a category for the issue (e.g., Legal Forms, Personal Finance, Real Estate).
7. Describe the issue in more detail (optional).
8. Choose the tool you would like to use for assistance (e.g., chatjimmy, james, john).
9. Select the format of the output file (e.g., employment lawyer application form--legal forms.yaml, other).

## Field-by-Field Explanation

* **User Details** (1, text, required: false): Enter your name and other relevant contact information.
* **Employment Issues** (2, text, required: false): Describe the employment issues you are facing, e.g., termination, contract disputes, etc.
* **Legal Issue Description** (3, text, required: false): Provide a brief description of the legal issue you are experiencing.
* **Preferred Language** (4, select_one, required: false): Choose your preferred language for communication (e.g., English, Spanish, French).
* **Email** (5, email, required: false): Enter your email address for contact purposes.
* **Phone** (6, text, required: false): Enter your phone number for contact purposes.
* **Category** (8, select_one, required: false): Select a category for the issue (e.g., Legal Forms, Personal Finance, Real Estate).
* **Description** (9, text, required: false): Provide additional details about the issue (optional).
* **Assigned Tool** (10, select_one, required: false): Choose the tool you would like to use for assistance (e.g., chatjimmy, james, john).
* **Output File** (11, select_one, required: false): Select the format of the output file (e.g., employment lawyer application form--legal forms.yaml, other).
