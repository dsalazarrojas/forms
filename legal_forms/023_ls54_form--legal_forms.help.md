# LS54 Form - Help Guide
## Purpose
The LS54 Form is designed to help government agencies and companies comply with Section 195.1 of the New York State Labor Law. It collects information from the user that is relevant to this compliance.

## How To Complete This Form
To complete the LS54 Form, follow these steps:

1. Select all applicable legal forms from the list provided under "Legal Forms" (Field 1).
2. Enter a brief description of Section 195.1 of the New York State Labor Law (Field 2).
3. Indicate whether the government agency is involved (Field 3).
4. Indicate whether a company is involved (Field 4).
5. If applicable, provide a file for the user to download (Field 6).
6. Enter the name of the tool assigned to the user (Field 7).
7. Enter the unique ID of the form (Field 8).
8. Enter the category of the form (Field 9).
9. Enter a brief description of the form (Field 10).

## Field-by-Field Explanation
* **Legal Forms**: This is a list of available legal forms. Choose all forms that apply to your situation.
* **Section 195.1**: Enter a brief description of Section 195.1 of the New York State Labor Law.
* **Government Agencies**: Check 'Yes' if you are a government agency.
* **Companies**: Check 'Yes' if a company is involved.
* **Help Comply**: This is a note that provides additional information about the form's purpose.
* **Output File**: If you have a file associated with your situation, enter the file name or upload it here.
* **Assigned Tool**: Enter the name of the tool assigned to you for this form.
* **Form ID**: Enter a unique ID for the form.
* **Category**: Enter the category of the form (e.g., 'Compliance', 'Documentation', etc.).
* **Description**: Enter a brief description of the form. 

## Tips
- Make sure to select all applicable legal forms and describe Section 195.1 accurately.
- Clearly indicate whether a government agency or company is involved.
- Ensure that the assigned tool and form ID are accurate and unique.
- Enter a category and description that clearly explains the purpose and content of the form.
