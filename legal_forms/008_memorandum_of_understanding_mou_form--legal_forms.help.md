# Memorandum Of Understanding (MOU) Form - Help Guide
## Purpose
The Memorandum Of Understanding (MOU) Form is used to document agreements between two or more parties to cooperate in a project or initiative.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the details of the partnership on **Page 1: partnership_details**.
2. On **Page 2: timelines**, select the dates for the start and end of the partnership.
3. On **Page 3: approvals**, select the approvals for the partnership from the provided options.
4. On **Page 4: partnership_type**, select the type of partnership from the provided options.
5. On **Page 5: review_frequency**, select the review frequency for the partnership from the provided options.
6. On **Page 6: status**, select the status of the partnership from the provided options.
7. On **Page 7: agreement_version**, enter the version of the agreement.
8. On **Page 8: agreement_version_number**, enter the version number of the agreement.
9. On **Page 9: agreement_version_comment**, enter any comments about the agreement version.

## Field-by-Field Explanation

* **partnership_details**: Enter the details of the partnership, including the name and description of the partnership.
* **timelines**: Select the start and end dates of the partnership.
* **approvals**: Select whether the partnership has been approved or not.
* **partnership_type**: Select the type of partnership (e.g. partnership with school, non-profit, business, public agency).
* **start_date**: Enter the date when the partnership started.
* **end_date**: Enter the date when the partnership ended.
* **review_frequency**: Select how often the partnership will be reviewed (e.g. quarterly, semi-annually, annually).
* **status**: Select the status of the partnership (e.g. draft, approved, rejected).
* **agreement_version**: Enter the version of the agreement.
* **agreement_version_number**: Enter the version number of the agreement.
* **agreement_version_comment**: Enter any comments about the agreement version.

## Tips
* Please make sure to fill out the form accurately and completely.
* Consult with relevant parties if you are unsure about any details.
* Review and update the form as needed to reflect any changes in the partnership.
