# Legal Request Form - Help Guide
## Purpose
The Legal Request Form is a general-purpose form for collecting information about legal-related requests. It is used to gather details about a user's request, including the requestor, request date and time, request type, location, and additional notes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the fields carefully to ensure you are providing the correct information.
2. Fill in the requested details, such as the requestor, request date, and request type.
3. Enter any relevant notes or comments about the request.

## Field-by-Field Explanation

* **Request Details**: This field is for providing a brief description of the request.
* **Requestor**: This field is for indicating whether the request is being made by the current user or someone else.
* **Request Date**: This field is for selecting the date the request is being made.
* **Request Time**: This field is for selecting the time the request is being made.
* **Request Type**: This field is for selecting the type of request being made.
* **Request Location**: This field is for providing a location where the request is being made or relevant.
* **Notes**: This field is for providing any additional comments or context about the request.
* **Email Address**: This field is for providing an email address where the user can be contacted.
* **Phone Number**: This field is for providing a phone number where the user can be contacted.
