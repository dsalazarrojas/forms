# Legal AI Consultation Feedback Form - Help Guide
## Purpose
This form is intended to collect feedback on the effectiveness of a legal AI consultation. Please use this form to share your thoughts and experiences with the consultation, including any issues you encountered or solutions you found useful.

## How To Complete This Form
1. Fill out the form completely, providing as much detail as possible.
2. Make sure to fill out all required fields (marked with an asterisk \*).
3. If you have any attachments or additional comments, you can upload files or type them in the text areas provided.

## Field-by-Field Explanation
- **Contact Person**: Please enter the name of the person who was in contact with the AI consultation.
  * Required for users who have interacted with the AI consultation
  * Type: text input
- **Email**: Please enter your email address, which will be used to contact you for follow-up questions or to provide updates on any actions taken based on your feedback.
  * Required for all users
  * Type: email input
- **Feedback Details**: This is the main text area where you can provide your thoughts and experiences with the AI consultation. Please be as detailed as possible.
  * Required for all users
  * Type: text input
- **Expected Solution**: Please select the expected outcome or solution you were looking for from the provided options.
  * Optional
  * Type: select one
  * Options: Yes, No
- **Actual Solutions**: Select any actual solutions you found useful from the provided options.
  * Optional
  * Type: select multiple
  * Options: Yes, No
- **Overall Satisfaction**: Please select how satisfied you are with the AI consultation.
  * Required
  * Type: select one
  * Options: Satisfied, Dissatisfied
- **Rating**: Please rate your experience with the AI consultation on a scale of 1-10.
  * Required
  * Type: numerical input
- **Additional Comments**: Please enter any additional comments or thoughts you have about the AI consultation.
  * Optional
  * Type: text input
- **Attachments**: If you have any attachments or documents related to your experience with the AI consultation, you can upload them here.
  * Optional
  * Type: file upload
- **More Information**: Please enter any additional information you think would be helpful to provide about your experience with the AI consultation.
  * Optional
  * Type: text input
- **More Attachments**: If you have any additional attachments or documents related to your experience with the AI consultation, you can upload them here.
  * Optional
  * Type: file upload

Note: Please make sure to proofread your submission before submitting it, as it will be used to help us improve the AI consultation.
