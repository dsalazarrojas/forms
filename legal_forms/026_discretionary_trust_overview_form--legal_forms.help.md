# Discretionary Trust Overview Form - Help Guide
## Purpose
This form is used to collect information about a discretionary trust arrangement.

## How To Complete This Form
1. Please complete all required fields. Required fields are marked with an asterisk (\*) in the field label.
2. Review each field carefully to ensure accuracy.

## Field-by-Field Explanation

* **Trust Arrangement Info** (`trust_arrangement_info`): Enter a brief description of the trust arrangement. This field is optional.
* **Trust Type** (`trust_type`): Select 'Yes' if the trust is a discretionary trust. This field is optional.
* **Grantor** (`grantor`): The person or entity creating the trust. This field is required.
* **Grantor Relationship** (`grantor_relationship`): Describe the relationship between the grantor and the beneficiary. This field is required.
* **Beneficiary** (`beneficiary`): The person or entity receiving the benefits of the trust. This field is required.
* **Beneficiary Relationship** (`beneficiary_relationship`): Describe the relationship between the beneficiary and the grantor. This field is required.
* **Asset Distribution** (`asset_distribution`): Select 'Yes' if the trust distributes assets to the beneficiary. This field is required.
* **Asset Distribution Other** (`asset_distribution_other`): Provide additional information about asset distribution if not selecting 'Yes'. This field is optional.
* **Trust Administration** (`trust_administration`): Select 'Yes' if the trust has administration. This field is required.
* **Trust Administration Other** (`trust_administration_other`): Provide additional information about trust administration if not selecting 'Yes'. This field is optional.
* **Trust Arrangement Duration** (`trust_arrangement_duration`): The length of time the trust is in effect. This field is required.
* **Trust Arrangement End Date** (`trust_arrangement_end_date`): The date the trust will end. This field is required.
* **Trust Arrangement Start Date** (`trust_arrangement_start_date`): The date the trust began. This field is required.
* **Trust Arrangement Status** (`trust_arrangement_status`): Select 'Active' if the trust is currently active. This field is required.
* **Trust Arrangement Other** (`trust_arrangement_other`): Provide additional information about the trust arrangement if not selecting 'Active' or 'Inactive'. This field is optional.
* **Trust Arrangement Comments** (`trust_arrangement_comments`): Enter any additional comments about the trust arrangement. This field is optional.
* **Review and Approval** (`review_and_approval`): Select 'Yes' if the trust has been reviewed and approved. This field is required.
* **Review and Approval Other** (`review_and_approval_other`): Provide additional information about review and approval if not selecting 'Yes'. This field is optional.
* **Trust Documentation** (`trust_documentation`): Select 'Yes' if the trust has documentation. This field is required.
* **Trust Documentation Other** (`trust_documentation_other`): Provide additional information about trust documentation if not selecting 'Yes'. This field is optional.
* **Trust Documentation Status** (`trust_documentation_status`): Select 'Active' if the trust is currently active in terms of documentation. This field is required.
* **Trust Documentation Status Other** (`trust_documentation_status_other`): Provide additional information about trust documentation status if not selecting 'Active' or 'Inactive'. This field is optional.
* **Submitted By** (`submitted_by`): The person submitting the form. This field is required.
