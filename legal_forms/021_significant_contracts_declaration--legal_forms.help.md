# Significant Contracts Declaration - Help Guide
## Purpose
This form is used for declaring significant contracts, which are agreements between two or more parties that have a material impact on the business operations.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the contract types that apply to this declaration from the dropdown menu.
2. Enter the date of the contract (if applicable).
3. Enter the contract amount (if applicable).

## Field-by-Field Explanation

* **contract_type** (`contract_type`, `select_multiple`, required: false):
	+ Select the type(s) of contract that apply to this declaration.
	+ This field is not required, but selecting relevant contract types helps to ensure accurate reporting.
* **contract_date** (`contract_date`, `date`, required: false):
	+ Enter the date of the contract, if applicable.
	+ If not applicable, leave this field blank.
* **contract_amount** (`contract_amount`, `number`, required: false):
	+ Enter the amount of the contract, if applicable.
	+ If not applicable, leave this field blank.

## Tips
* Make sure to select all relevant contract types for accurate reporting.
* If the contract date is not known or not applicable, leave the field blank.
* If the contract amount is not known or not applicable, leave the field blank.

Note: The form fields are not required, so users can fill it out partially if they don't have all the information.
