# identity_theft_incident_report_form - Help Guide
## Purpose
The purpose of this form is to report incidents of identity theft, including types of theft, locations, and dates.

## How To Complete This Form

1. Start by providing some basic contact information so that we can get in touch with you regarding the incident.
* **user_info** (user_info, text, required): Please enter your name, email address, and phone number so we can contact you regarding your incident.
*   If you are a minor (less than 18 years old), please have a parent or guardian sign this form.
2. Next, select the type of identity theft that occurred to you.
* **theft_type** (thief_type, select_one, required): Choose from the options below:
	+ Identity Theft
	+ Credit Card Fraud
	+ Bank Account Theft
	+ Social Security Number Theft
	+ Tax Identification Number Theft
	+ Other (Please specify in the notes below)
3. If the theft occurred in a different location, please enter the address where it happened.
* **incident_location** (incident_location, text, required): Enter the address where the incident occurred.
4. Lastly, select the date when the incident occurred.
* **incident_date** (incident_date, date, required): Enter the date when the incident occurred.

## Field-by-Field Explanation
* **user_info**: This is the contact information section where you can enter your name, email address, and phone number. This will help us get in touch with you regarding your incident.
* **theft_type**: This is a dropdown menu where you can select the type of identity theft that occurred to you. Please choose from the options provided, and if none fit, you can select "Other" and explain in the notes.
* **incident_location**: This is the text field where you can enter the address where the incident occurred.
* **incident_date**: This is the date field where you can select the date when the incident occurred.

## Tips
Please be as detailed as possible when filling out this form, and if you are unsure about any of the information, please contact us so we can assist you further.
