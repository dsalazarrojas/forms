# law_office_reference_material_order_form - Help Guide
## Purpose
This form is used by law office staff to order reference materials for their office.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the order, if desired. This field is optional but can help with organization and identification of the order.
2. Select the category of the reference material being ordered. This will help the staff know what type of material to order.
3. Provide a brief description of the material being ordered. This will help the staff understand what is being ordered and ensure that the correct material is received.
4. Enter the name of the file that will be output for the ordered reference material. This field is also optional but can help with organization and identification of the file.
5. Choose the tool that will be used to create the ordered reference material. This is a crucial field as it determines which tool will be used to create the material.

## Field-by-Field Explanation
* **Law Office Reference Material Order Form (form_title)**: A title for the order, if desired.
* **Category (form_category)**: Select the category of the reference material being ordered. This will help the staff know what type of material to order.
* **Description (form_description)**: Enter a brief description of the material being ordered. This will help the staff understand what is being ordered and ensure that the correct material is received.
* **Output File (form_output_file)**: Enter the name of the file that will be output for the ordered reference material. This field is optional but can help with organization and identification of the file.
* **Assigned Tool (form_assigned_tool)**: Choose the tool that will be used to create the ordered reference material. This is a crucial field as it determines which tool will be used to create the material.

## Tips
* Be sure to fill out all required fields to ensure that the order is properly processed.
* If you are unsure about any of the fields, contact your supervisor or IT department for assistance.
