# Non Disclosure Agreement Request Form - Help Guide

## Purpose
This form is used to request a non-disclosure agreement for a document or project. Please use this form only for new requests that do not already have a similar agreement in place.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the document or project that you are requesting a non-disclosure agreement for. This will help us quickly identify the purpose of the request.
2. Select the category of the document or project. Choose "Legal Forms" if it's a document or project that falls under this category.
3. Provide a brief description of the document or project. This will help us understand the context of the request.

## Field-by-Field Explanation

* **Non Disclosure Agreement Request Form** (`form_title`, text, optional): Enter a title for the document or project that you are requesting a non-disclosure agreement for.
* **Category** (`form_category`, select_one, optional): Select the category of the document or project. Choose "Legal Forms" if it's a document or project that falls under this category.
* **Description** (`form_description`, text, optional): Provide a brief description of the document or project. This will help us understand the context of the request and ensure that we are not duplicating existing agreements or using this form for an unrelated purpose.
