# Landlord Records Release Form - Help Guide
## Purpose
The purpose of this form is to document the release of records by landlords. It is used to verify the release of records to authorized parties.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the tenant's name.
2.  Enter the address of the property.
3.  Select the release type (Landlord, Property Manager, or Attorney).
4.  Enter the release date.
5.  Enter the name of the authorized party.
6.  Enter the date of authorization.
7.  Enter the tenant's signature.
8.  Enter the landlord's signature.
9.  Optional: Enter additional notes, the landlord's agreement, authorized by, release expiration, release date range start and end, and release date range type.

## Field-by-Field Explanation
*   **Tenant Name**: This field captures the name of the tenant. Enter the full name of the tenant.
*   **Address**: This field captures the address of the property. Enter the address of the property in a clear and concise manner.
*   **Release Date**: This field is used to capture the date when the records are released. Enter the date in the format MM/DD/YYYY.
*   **Release To**: This field captures the name of the party releasing the records. Enter the name of the party releasing the records.
*   **Release Type**: This field captures the type of release. Select one of the following options: Landlord, Property Manager, or Attorney.
*   **Authorization Date**: This field captures the date when the release is authorized. Enter the date in the format MM/DD/YYYY.
*   **Authorized Party**: This field captures the name of the authorized party. Enter the name of the authorized party.
*   **Tenant Agreement**: This field is used to capture any additional agreement or comments from the tenant. Enter any additional comments or agreements made between the tenant and the landlord.
*   **Tenant Signature**: This field is used to capture the signature of the tenant. Enter the signature of the tenant.
*   **Landlord Signature**: This field is used to capture the signature of the landlord. Enter the signature of the landlord.
*   **Notes**: This field captures any additional comments or notes from the landlord.
*   **Landlord Agreement**: This field is used to capture any additional agreement or comments from the landlord. Enter any additional comments or agreements made between the landlord and the tenant.
*   **Authorized By**: This field captures the name of the person authorizing the release. Enter the name of the person authorizing the release.
*   **Date Signed**: This field captures the date when the release is signed. Enter the date in the format MM/DD/YYYY.
*   **Authorized Party Title**: This field captures the title of the authorized party. Enter the title of the authorized party.
*   **Landlord Name**: This field captures the name of the landlord. Enter the name of the landlord.
*   **Release Expiration**: This field captures the expiration date of the release. Enter the expiration date of the release.
*   **Release Date Range Start**: This field captures the start date of the release range. Enter the start date of the release range in the format MM/DD/YYYY.
*   **Release Date Range End**: This field captures the end date of the release range. Enter the end date of the release range in the format MM/DD/YYYY.
*   **Release Date Range Type**: This field captures the type of release date range. Select one of the following options: Month or Year.
*   **Release Date Range Start Date**: This field captures the start date of the release range. Enter the start date of the release range in the format MM/DD/YYYY.
*   **Release Date Range End Date**: This field captures the end date of the release range. Enter the end date of the release range in the format MM/DD/YYYY.
*   **Release Date Range Start Date Note**: This field captures any additional notes for the start date of the release range.
*   **Release Date Range End Date Note**: This field captures any additional notes for the end date of the release range.

## Tips
*   Make sure to fill in all required fields.
*   Enter dates in the correct format (MM/DD/YYYY).
*   Be clear and concise in your entries.
*   Review the form carefully before submission.
