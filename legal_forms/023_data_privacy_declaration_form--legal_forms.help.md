# Data Privacy Declaration Form - Help Guide
## Purpose
This form is used to collect information about data privacy declarations.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the form in the "Data Privacy Declaration Form" field.
2. Select the category from the provided options.
3. Enter a brief description of the data collection process.
4. Specify the purpose for which the data will be used.
5. Choose the method of data collection.
6. Select whether you agree or disagree with the data collection.
7. Enter the date the data was collected.

## Field-by-Field Explanation
* **Data Privacy Declaration Form** (`form_title`, text, optional): Enter the title of the form, which should be a clear and concise description of the form's purpose.
* **Category** (`category`, select_one, optional): Select the category of data collection, such as "Legal Forms", "Other", or "None".
* **Description** (`description`, text, optional): Provide a brief description of the data collection process, including what type of data will be collected and how it will be used.
* **Purpose** (`purpose`, text, optional): Specify the purpose for which the data will be used, such as "Marketing", "Research", or "Compliance".
* **Data Collection** (`data_collection`, text, optional): Choose the method by which the data will be collected, such as "Manual Entry", "Online Form", or "File Upload".
* **Consent** (`consent`, select_one, optional): Select whether you agree or disagree with the data collection, with options being "I agree" and "I disagree".
* **Date Collected** (`date_collected`, date, optional): Enter the date the data was collected.

## Tips
* Make sure to clearly title the form to accurately describe its purpose.
* Choose the correct category for the data collection process.
* Keep the description brief but informative.
* Specify the purpose of the data collection clearly.
* Be honest about the data collection method.
* Select the correct consent option.
* Enter the correct date of data collection.
