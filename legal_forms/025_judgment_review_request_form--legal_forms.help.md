# judgment_review_request_form - Help Guide
## Purpose
This form is used to request a review of a judgment, which is a critical process in the legal system. It helps to ensure that the judgment is accurate and fair.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the case number of the judgment you wish to review.
2. Provide the name of the reviewer who will review the judgment.
3. Select the review date for the judgment.
4. Specify the type of review you are requesting (optional).
5. Provide a reason for the review (optional).
6. Select the status of the review (optional).
7. Add any comments about the review.
8. Enter the name of the person submitting the request.
9. Enter the name of the person or organization the request is submitted to.
10. Enter the ID for the review request.
11. Select the date the request was submitted.
12. Optionally, select the status of the review.
13. Optionally, select whether the review request has been updated.

## Field-by-Field Explanation
- **Case Number** (`case_number`, required): This field is used to identify the specific case being reviewed. Please enter the correct case number.
- **Reviewer Name** (`reviewer_name`, required): This field is used to select the person reviewing the judgment. Please enter the correct name of the reviewer.
- **Review Date** (`review_date`, required): This field is used to select the date of the review. Please enter the date in the correct format (DD/MM/YYYY).
- **Request Type** (`request_type`, optional): This field determines the type of review requested. Select "Yes" if you are requesting a review, and "No" if you are not requesting a review.
- **Reason for Review** (`reason_for_review`, optional): This field provides a clear explanation for the review. If a reason is not provided, it will be left blank.
- **Review Status** (`review_status`, optional): This field determines the status of the review. Select "Active" if the review is active, and "Inactive" if it is not active.
- **Comments** (`comments`, required): This field is used to add any comments or feedback about the review.
- **Submitted By** (`submitted_by`, required): This field is used to enter the name of the person submitting the request.
- **Submitted To** (`submitted_to`, required): This field is used to enter the name of the person or organization the request is submitted to.
- **Review Request ID** (`review_request_id`, required): This field is used to enter the ID for the review request.
- **Submitted On** (`submitted_on`, required): This field is used to select the date the request was submitted.
- **Review Date** (`review_date`, optional): This field is used to select an additional review date (if necessary).
- **Review Status Updated** (`review_status_updated`, optional): This field determines whether the review status has been updated. Select "Active" if the status has been updated, and "Inactive" if it has not.
- **Review Request Updated** (`review_request_updated`, optional): This field determines whether the review request has been updated. Select "Yes" if it has been updated, and "No" if it has not.
