# Patent Application Information Form - Help Guide
## Purpose
This form is used to collect information about patent applications, including patent details and inventor/contact information. It is intended for use by authorized personnel to gather accurate and relevant data for patent-related activities.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the correct application type from the options provided.
2.  Enter the inventor's name and address in the designated fields.
3.  Provide the patent title and description as they appear on the patent application.
4.  Enter the patent filing date, if known.
5.  Enter the inventor's email address and phone number.
6.  Select the current patent status from the options provided.
7.  Enter the applicant's name and address, if applicable.

## Field-by-Field Explanation
*   **Inventor Name**: Enter the name of the inventor or inventors responsible for the patent application. This field is optional.
*   **Application Type**: Select the type of patent application being submitted (Patent, Provisional Patent, Utility Patent, or Design Patent). This field is optional.
*   **Inventor Address**: Enter the address of the inventor or inventors responsible for the patent application. This field is optional.
*   **Patent Title**: Enter the title of the patent application as it appears on the patent. This field is optional.
*   **Patent Description**: Enter a brief description of the patent application. This field is optional.
*   **Patent Filing Date**: Enter the date the patent application was filed, if known. This field is optional.
*   **Inventor Email**: Enter the email address of the inventor or inventors responsible for the patent application. This field is optional.
*   **Inventor Phone**: Enter the phone number of the inventor or inventors responsible for the patent application. This field is optional.
*   **Patent Status**: Select the current status of the patent application (Pending, Published, Granted, or Abandoned). This field is optional.
*   **Applicant Name**: Enter the name of the applicant or entity responsible for the patent application. This field is optional.
*   **Applicant Address**: Enter the address of the applicant or entity responsible for the patent application. This field is optional.

Note: This form is designed to collect information about patent applications, and all fields are optional unless otherwise specified.
