# Workplace Violence Restraining Order Request Form - Help Guide
## Purpose
The Workplace Violence Restraining Order Request Form is a document used to report and address workplace violence incidents. It helps to provide essential details about the incident and allows the reporting employee to request protective actions.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide details about the incident, including location, date, and description.
2. If applicable, provide information about the victim, including their name, job title, and any injuries sustained.
3. List any witnesses, including their names, positions, and relationships to the victim.
4. Request protective actions, such as a police report or restraining order, if necessary.
5. Provide details about the measures taken to ensure the incident does not happen again.

## Field-by-Field Explanation

* **Incident Details** (`incident_details`):
	+ This field is used to provide a brief description of the incident.
	+ Please be as concise as possible while including all relevant details.
* **Where did the incident occur** (`incident_location`):
	+ This field is used to specify the location where the incident took place.
	+ If the incident occurred in a specific area or room, please provide the exact location.
* **Date of incident** (`incident_date`):
	+ This field is used to specify the date of the incident.
	+ Please use the format MM/DD/YYYY.
* **Reporting Employee** (`reporting_employee`):
	+ This field is used to specify the name of the employee who is reporting the incident.
	+ Please ensure that your name is accurate and complete.
* **Witness Info** (`witness_info`):
	+ This field is used to specify if there were any witnesses to the incident.
	+ Choose 'True' if there were witnesses.
* **Witness names** (`witness_names`):
	+ This field is used to list the names of any witnesses.
	+ Please include all relevant witnesses.
* **Witness positions** (`witness_positions`):
