# Document Retrieval Agreement - Help Guide
## Purpose
The Document Retrieval Agreement form is designed to collect information about documents that have been retrieved from an organization. This form gathers data on the organization's details, the representative handling the document, and the document's status throughout its journey, including the date and time of retrieval, delivery, and verification.

## How To Complete This Form
To complete this form, follow these steps:

1. On the first page, enter the name of the organization and the name of the representative handling the document.
2. Fill in the date and time of retrieval, if applicable.
3. On subsequent pages, select the relevant options for the document's status, delivery, and verification.
4. Enter any comments or additional information about the document, if needed.

## Field-by-Field Explanation
### Page 1
* **organization** (Required): Enter the name of the organization from which the document was retrieved.
* **representative** (Required): Enter the name of the representative responsible for handling the document.
* **date** (Optional): Enter the date of retrieval, if applicable.
* **time** (Optional): Enter the time of retrieval, if applicable.
* **purpose** (Optional): Enter a brief description of the purpose of retrieving the document.

### Page 2
* **document type** (Optional, Select One): Choose the type of document being retrieved.
* **document name** (Optional): Enter the name of the document being retrieved.
* **requester** (Optional): Enter the name of the person or department requesting the document.
* **date received** (Optional): Enter the date the document was received.
* **time received** (Optional): Enter the time the document was received.
* **purpose received** (Optional): Enter a brief description of the purpose for which the document was received.

### Page 3
* **document status** (Optional, Select One): Select the current status of the document.
* **date sent** (Optional): Enter the date the document was sent.
* **time sent** (Optional): Enter the time the document was sent.
* **purpose sent** (Optional): Enter a brief description of the purpose for which the document was sent.
* **comments** (Optional, Note): Enter any additional comments about the document.

### Additional Pages (4-6)
* **date retrieved** (Optional): Enter the date the document was retrieved.
* **time retrieved** (Optional): Enter the time the document was retrieved.
* **purpose retrieved** (Optional): Enter a brief description of the purpose for which the document was retrieved.
* **date verified** (Optional): Enter the date the document was verified.
* **time verified** (Optional): Enter the time the document was verified.
* **purpose verified** (Optional): Enter a brief description of the purpose for which the document was verified.
* **date delivered** (Optional): Enter the date the document was delivered.
* **time delivered** (Optional): Enter the time the document was delivered.
* **purpose delivered** (Optional): Enter a brief description of the purpose for which the document was delivered.

## Tips
- Make sure to fill out each field as accurately and completely as possible.
- If a field is not applicable, indicate this clearly by leaving it blank or entering "N/A", if possible.
- Review the form carefully before submission to avoid errors.
- If you are unsure about any part of the form, consult with your supervisor or the form's administrator.
