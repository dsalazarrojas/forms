# Immigration Lawyer Application Form - Help Guide
## Purpose
The Immigration Lawyer Application Form is a tool used to collect and record information for immigration lawyer applications. This form is designed to ensure that all necessary details are captured accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's name in the "Client Name" field, ensuring it is accurately spelled and formatted.
2. Enter the client's email address in the "Client Email" field, using the format `example@domain.com`.
3. Enter the client's phone number in the "Client Phone" field, including the area code and country code if applicable.
4. Select the type of immigration case from the "Case Type" dropdown menu.
5. Provide a brief description of the case in the "Case Description" field.
6. Select the current status of the application from the "Application Status" dropdown menu.
7. Upload any relevant documents in the "Document Upload" field.
8. If necessary, provide any special circumstances related to the case in the "Special Circumstances" field.
9. Select the payment method used (e.g., check, credit card, bank transfer) from the "Payment Method" dropdown menu.
10. Enter the payment amount in USD in the "Payment Amount" field.
11. Enter the date of payment in the "Payment Date" field.
12. Add any additional notes about the case in the "Notes" field.

## Field-by-Field Explanation

* **Client Name** (`client_name`, text, required): Enter the name of the client, accurately spelled and formatted.
* **Client Email** (`client_email`, email, required): Enter a valid email address for the client, in the format `example@domain.com`.
* **Client Phone** (`client_phone`, text, required): Enter the client's phone number, including the area code and country code if applicable.
* **Case Type** (`case_type`, select_one, required): Select the type of immigration case (e.g., Family Immigration, Business Immigration, Student Visa).
* **Case Description** (`case_description`, text, required): Provide a brief description of the case.
* **Application Status** (`application_status`, select_multiple, required): Select the current status of the application (e.g., Pending, In Progress, Completed, Cancelled, On Hold).
* **Document Upload** (`document_upload`, text, required): Upload any relevant documents related to the case.
* **Special Circumstances** (`special_circumstances`, text, required): Provide any special circumstances related to the case, if necessary.
* **Payment Method** (`payment_method`, select_one, required): Select the method used to make payment (e.g., check, credit card, bank transfer).
* **Payment Amount** (`payment_amount`, number, required): Enter the payment amount in USD.
* **Payment Date** (`payment_date`, date, required): Enter the date of payment.
* **Notes** (`notes`, note, required): Add any additional notes about the case.
