# Hearing Request Submission - Help Guide
## Purpose
The Hearing Request Submission form is used to submit a request for a hearing. This form is intended to gather information about the requestor, the nature of the request, and the desired hearing details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and email address in the corresponding fields.
2. Select "Yes" or "No" for the Request Type field, depending on the type of hearing you are requesting.
3. If you selected "Yes" for the Request Type, enter the date you would like to have the hearing on.
4. Fill in the Request Description field with a brief description of your request.
5. Select "Active" or "Inactive" for the Hearing Status field, depending on whether the hearing request is active or inactive.
6. Enter your phone number in the Requestor Phone field.
7. Select "Yes" or "No" for the Assigned Hearing Officer field, depending on whether you would like to be assigned a hearing officer.
8. Fill in any additional information you would like to provide in the Additional Info field.

## Field-by-Field Explanation
* **Hearing Request Submission**:
	+ A text field where you can enter the title of your hearing request.
* **Requestor Name**: 
	+ A text field where you can enter your name.
* **Requestor Email**:
	+ An email field where you can enter your email address.
* **Request Type**: 
	+ A dropdown select field where you can select "Yes" or "No" depending on the type of hearing you are requesting.
* **Request Date**:
	+ A date field where you can enter the date you would like to have the hearing on.
* **Hearing Location**:
	+ A text field where you can enter the location where you would like to have the hearing.
* **Request Description**: 
	+ A note field where you can enter a brief description of your hearing request.
* **Hearing Date**:
	+ A date field where you can enter the date of the hearing.
* **Hearing Time**:
	+ A time field where you can enter the time of the hearing.
* **Hearing Status**: 
	+ A dropdown select field where you can select "Active" or "Inactive" depending on the status of the hearing request.
* **Requestor Phone**: 
	+ A text field where you can enter your phone number.
* **Assigned Hearing Officer**:
	+ A dropdown select field where you can select "Yes" or "No" depending on whether you would like to be assigned a hearing officer.
* **Additional Info**:
	+ A text field where you can enter any additional information about your hearing request.
* **Hearing Request ID**: 
	+ A number field where you can enter the ID of the hearing request.

Note: The Hearing Request ID field is not required to be filled in by the requestor.
