# Motion For Return Of Property - Help Guide
## Purpose
This form is for filing a motion for the return of property in a court case.

## How To Complete This Form
### Step 1: General Information
- Fill out the "Motion For Return Of Property" section with a clear and concise description of the motion.
- Ensure that all required fields are completed accurately and thoroughly.

### Step 2: Property Details
- Select the relevant option(s) for "property_type" as it pertains to the type of property in question.
- Provide a detailed description of the property in the "property_description" field.
- Enter the "return_reason" for the motion, selecting the relevant option from the list.

### Step 3: Submitting Party and Officer Details
- Complete the "submitting_party" section with either "Yes" or "No", indicating if it's the submitting party or not.
- Enter the name and contact information of the submitting party in the "party" section.
- Enter additional information about the party in the "party_info" field.
- Enter the party's address in the "party_address" field.

### Step 4: Submitting Officer Details
- Complete the "submitting_officer" section with the name and title of the officer submitting the motion.
- Enter the officer's agency and contact information in the "submitting_officer_agency" and "submitting_officer_contact" fields.
- Sign the "submitting_officer_signature" field with the officer's signature.

## Field-by-Field Explanation

* **motion_for_return_of_property** (1, text, required): A clear and concise description of the motion for return of property.
* **supporting_documentation** (2, text, optional): Any additional documentation supporting the motion.
* **case_number** (3, text, required): The case number associated with the motion.
* **property_type** (4, select_multiple, required): Select the type(s) of property in question (e.g., "Yes", "No").
* **property_description** (5, text, required): A detailed description of the property in question.
* **return_reason** (6, select_one, required): Select the reason for the return of property (e.g., "Yes", "No").
* **return_date** (7, date, required): The date the property is to be returned.
* **return_time** (8, time, required): The time the property is to be returned.
* **agency** (9, text, required): The name of the agency submitting the motion.
* **officer_name** (10, text, required): The name of the officer submitting the motion.
* **contact_info** (11, text, required): Contact information for the submitting party or officer.
* **notes** (12, note, required): Any additional notes about the motion.
* **submitting_party** (13, select_one, required): Indicate if it's the submitting party or not ("Yes", "No").
* **party** (14, text, required): Enter the name of the party involved.
* **party_info** (15, text, required): Enter additional information about the party.
* **party_address** (16, text, required): Enter the party's address.
* **submitter_info** (17, text, required): Enter the submitter's information.
* **submitting_date** (18, date, required): Enter the date the motion is being submitted.
* **submitting_time** (19, time, required): Enter the time the motion is being submitted.
* **submitting_officer** (20, text, required): Enter the name of the submitting officer.
* **submitting_officer_title** (21, text, required): Enter the title of the submitting officer.
* **submitting_officer_agency** (22, text, required): Enter the agency of the submitting officer.
* **submitting_officer_contact** (23, text, required): Enter the contact information of the submitting officer.
* **submitting_officer_signature** (24, text, required): Sign the motion with the submitting officer's signature.

## Tips
- Ensure that all required fields are completed accurately and thoroughly.
- Double-check for any additional documentation or attachments required for the motion.
- Review the form carefully before submission to ensure completeness and accuracy.
