# Legal Services Termination Notice - Help Guide
## Purpose
This form is used to record the termination of legal services provided to a client. It captures essential details about the termination date, reason, and any relevant circumstances surrounding the termination.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct termination date from the calendar.
2. Choose the reason for termination from the provided options (e.g., Termination by Mutual Agreement, Client Requested, Service Provider Cancellation).
3. Enter the name of the service that was terminated.
4. If applicable, select the date when the service was last terminated.
5. Check if the client conducted a conference (yes/no).
6. Enter the service agreement number (if applicable).
7. Select the reason for the last termination (if applicable).
8. Enter any details about the service provider that was terminated (if applicable).
9. If applicable, select the date when the last service was terminated and the reason for the last termination.

## Field-by-Field Explanation
* **Termination Date** (`termination_date`): Enter the date the legal service was terminated.
* **Reason for Termination** (`reason_for_termination`): Select one of the provided options for the reason why the service was terminated.
* **Service Name** (`service_name`): Enter the name of the service that was terminated.
* **Termination Effective Date** (`termination_effective_date`): Enter the date when the termination took effect.
* **Termination Effective Time** (`termination_effective_time`): Select the time when the termination took effect.
* **Reason for Termination Details** (`reason_for_termination_details`): Describe the circumstances leading to termination in detail.
* **Termination Date of Service** (`termination_date_of_service`): Select the date when the service was last terminated.
* **Client Conducted Conference** (`client_conducted_conference`): Check if a conference was conducted (yes/no).
* **Service Agreement Number** (`service_agreement_number`): Enter the number of the service agreement.
* **Reason for Termination 2** (`reason_for_termination_2`): Select an alternative reason for termination.
* **Last Termination Date** (`last_termination_date`): Select the date when the service was last terminated.
* **Termination Cause** (`termination_cause`): Select the cause of termination (e.g., Non-Performance, Non-Payment, Discharge).
* **Last Termination Date 2** (`last_termination_date_2`): Select the date when the last service was terminated.
* **Last Service Termination Effective Date** (`last_service_termination_effective_date`): Select the date when the last termination took effect.
* **Last Service Provided** (`last_service_provided`): Enter the last service provided.
* **Service Provider Terminated** (`service_provider_terminated`): Describe the circumstances surrounding the termination of the service provider.
* **Client Conducted Conference 2** (`client_conducted_conference_2`): Check if a conference was conducted (yes/no).
* **Reason for Renewal** (`reason_for_renewal`): Select the reason for renewal.
* **Last Service Provider** (`last_service_provider`): Enter the name of the last service provider.
* **Service Provider Terminated 2** (`service_provider_terminated_2`): Describe the circumstances surrounding the termination of the service provider.
* **Last Termination Reason** (`last_termination_reason`): Select the reason for the last termination.
* **Last Termination Cause** (`last_termination_cause`): Select the cause of the last termination.
* **Last Termination Date 2** (`last_termination_date_2`): Select the date when the last service was terminated.
* **Last Service Termination Effective Date** (`last_service_termination_effective_date`): Select the date when the last termination took effect.
* **Last Service Provided** (`last_service_provided`): Enter the last service provided.

## Tips
* Make sure to enter accurate dates and details to ensure accurate records are kept.
* Review each field carefully to ensure the correct information is entered.
* If you're unsure about any field, refer to the provided options or seek guidance from a relevant authority.
