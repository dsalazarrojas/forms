# Small Estate Declaration Form - Help Guide
## Purpose
The Small Estate Declaration Form is a document used to declare and identify a small estate. This form is used to provide information about the estate, its details, and any supporting documents that may be relevant. It is an important part of the estate's documentation process and should be completed carefully and accurately.

## How To Complete This Form
To complete the Small Estate Declaration Form, follow these steps:

1. Select the correct Category from the dropdown menu. For most purposes, you will want to select "Legal Forms."
2. Enter a brief Description of the form and its purpose in the text field.
3. Provide Estate Details in the text field, including any relevant information about the estate.
4. If required, attach any Supporting Documents relevant to the estate.

## Field-by-Field Explanation
* **Small Estate Declaration Form**: 
  * Type: text
  * Required: false
  * This is the main title of the form, where you should enter a brief description of the form and its purpose.
* **Category**: 
  * Type: select_one
  * Required: false
  * Select the category of the form from the dropdown menu. For most purposes, you should select "Legal Forms."
* **Description**: 
  * Type: text
  * Required: false
  * Enter a brief description of the form and its purpose in this field.
* **Estate Details**: 
  * Type: note
  * Required: false
  * Provide a detailed description of the estate, including any relevant information.
* **Supporting Documents**: 
  * Type: note
  * Required: false
  * Attach any supporting documents that are relevant to the estate. This can include receipts, certificates, or other documentation.

## Tips
* Ensure that the form is completed accurately and thoroughly.
* Attach any supporting documents that are relevant to the estate.
* If unsure about any information, please consult with relevant authorities or experts.
