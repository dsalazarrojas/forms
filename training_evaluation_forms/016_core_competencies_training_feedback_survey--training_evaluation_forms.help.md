# Core Competencies Training Feedback Survey - Help Guide
## Purpose
This form is designed to gather feedback from trainees after a training session.

## How To Complete This Form

To complete this form, please follow these steps:

1. Answer the questions honestly and thoroughly, providing as much detail as possible.
2. For each question, please select the most appropriate response from the options provided, or enter a free-form text response if no options are provided.
3. If you have any additional comments or feedback, please use the "Notes" field at the end of the form.
4. Once you have completed the form, please click the "Submit" button to send your feedback to us.

## Field-by-Field Explanation

* **Overall Satisfaction (page 1)** (`overall_satisfaction`, text, required)
	+ This question asks how satisfied you are with the training session overall.
	+ Please answer with a brief text description of your level of satisfaction.
* **Feedback from Trainee (page 1)** (`feedback_from_trainee`, text, required)
	+ This question asks for feedback on how we can improve the training session.
	+ Please provide specific suggestions or ideas on how we can do better.
* **Future Satisfaction (page 1)** (`future_satisfaction`, text, required)
	+ This question asks what you think you will achieve from this training.
	+ Please answer with a brief text description of your expectations.
* **Core Competencies Topics (page 1)** (`core_competencies_topics`, select_multiple, required)
	+ This question asks which core competencies were covered in the training session.
	+ Please select all that apply from the options provided.
* **Session Length (page 1)** (`session_length`, number, required)
	+ This question asks how long the training session lasted.
	+ Please answer with the actual length of the session.
* **Session Date (page 1)** (`session_date`, date, required)
	+ This question asks on what date the training session took place.
	+ Please enter the date in YYYY-MM-DD format.
* **Session Location (page 1)** (`session_location`, text, required)
	+ This question asks where the training session took place.
	+ Please answer with the physical location of the session.
* **Trainee Feedback (page 1)** (`trainee_feedback`, text, required)
	+ This question asks for your overall feedback on the training session.
	+ Please provide a brief text description of your experience.
* **Trainee Attendance (page 1)** (`trainee_attendance`, select_multiple, required)
	+ This question asks whether you were able to attend the full session.
	+ Please select all that apply from the options provided.
* **Feedback from Session (page 1)** (`feedback_from_session`, text, required)
	+ This question asks for feedback on the training session specifically.
	+ Please provide specific suggestions or ideas on how we can do better.
* **Session Improvements (page 1)** (`session_improvements`, text, required)
	+ This question asks for areas where you think we could improve the session.
	+ Please provide specific suggestions or ideas on how we can do better.
* **Trainee Satisfaction (page 1)** (`trainee_satisfaction`, text, required)
	+ This question asks how satisfied you are with the training session.
	+ Please answer with a brief text description of your level of satisfaction.
* **Trainee Email (page 2)** (`trainee_email`, email, optional)
	+ This question asks for your email address for future communications.
	+ Please enter your email address if you wish to receive updates or communications.
* **Trainee Notes (page 2)** (`trainee_notes`, note, optional)
	+ This question asks for any additional notes or comments you may have.
	+ Please provide any additional information or suggestions that you think are important.

## Tips

* Please answer all questions honestly and thoroughly.
* If you have any concerns or issues, please let us know so we can address them.
* If you have any additional feedback or suggestions, please use the "Notes" field.
