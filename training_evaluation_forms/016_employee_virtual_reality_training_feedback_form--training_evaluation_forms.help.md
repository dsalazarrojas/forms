# Employee Virtual Reality Training Feedback Form - Help Guide
## Purpose

This form is designed to gather feedback from employees after they have completed a virtual reality training session.

## How To Complete This Form

1. Answer each question honestly and thoroughly.
2. If a question does not apply, please select "No" or "Not Applicable" where applicable.
3. If you have any technical issues, please describe them in the "Technical Issues" field.

## Field-by-Field Explanation

* **Module 1 (Select Multiple)** (`training_feedback`, `select_multiple`, required: false): 
  Please select all the modules that you found helpful or not helpful. For example, if you found Module 1 helpful, select "Yes".
* **Module 2 (Text)** (`module_2_name`, `text`, required: false): 
  Please enter your feedback about Module 2.
* **Technical Issues (Text)** (`technical_issues`, `text`, required: false): 
  Please describe any technical issues you experienced during the training.
* **Comments (Text)** (`comments`, `text`, required: false): 
  If you have any additional comments or suggestions, please enter them here.
* **Future Improvement (Text)** (`future_improvement`, `text`, required: false): 
  Please enter any suggestions on how we can improve the training.
* **Department Feedback (Select One)** (`department_feedback`, `select_one`, required: false):
  Please select whether you want to provide feedback for your department. 
* **Employee Feedback (Select One)** (`employee_feedback`, `select_one`, required: false):
  Please select whether you want to provide feedback about the trainer.
* **Overall Satisfaction (Select One)** (`overall_satisfaction`, `select_one`, required: false):
  Please select your overall satisfaction with the training.
* **Date of Training (Date)** (`date_of_training`, `date`, required: false):
  Please enter the date of your training session in the YYYY-MM-DD format.
* **Time of Training (Time)** (`time_of_training`, `time`, required: false):
  Please enter the time of your training session.
* **Email (Email)** (`email`, `email`, required: false):
  Please enter your email address for follow-up communication.
* **Phone Number (Text)** (`phone_number`, `text`, required: false):
  Please enter your phone number for follow-up communication.

## Tips

* Please fill out all fields if possible.
* If you have any questions or concerns, please contact your trainer or HR representative.
* If you have any technical issues, please be as specific as possible so we can resolve them.
