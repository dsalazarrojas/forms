# Intercultural Competence Training Request Form - Help Guide

## Purpose
This form is used to request training on intercultural competence, which is the ability to interact effectively with people from different cultural backgrounds. The form is used to provide information about the training you are interested in, including the topic, location, and format of the training. This information will help us tailor the training to your needs and preferences.

## How To Complete This Form
To complete this form, simply fill in the required fields and select the options that best suit your needs. Make sure to provide as much detail as possible to ensure that we can provide you with the best possible training experience.

## Field-by-Field Explanation

* **Training Request** (id: 1, required: true): This is the title of the training you are requesting. Please provide a short and descriptive title that clearly states what you want to learn.
* **Training Format** (id: 2, select one: Yes/No): This option is for those who want to know whether you prefer online or on-site training. Please select one of the options.
* **Start Date** (id: 3, date): This is the date you would like to start the training on.
* **End Date** (id: 4, text): This is the date when you would like to finish the training on. Please provide the date in the standard YYYY-MM-DD format.
* **Training Topic** (id: 5, required: true): This is the topic of the training you are interested in. Please select one from the list.
* **Training Location** (id: 6, required: true): This is the location where you would like to have the training.
* **Training Time** (id: 7, time): This is the time you would like to have the training. Please provide a 24-hour format (e.g., 09:00 or 14:00).
* **Training Duration** (id: 8, number): This is the length of time you would like the training to last. Please provide the number of hours or days.
* **Training Format** (id: 9, select_one: Online/Classroom/In-person): This is the format you prefer for the training. Select one from the list.
* **Training Language** (id: 10, select one: English/Spanish/French): This is the language of the training. Select one from the list.
* **Training Level** (id: 11, select one: Basic/Intermediate/Advanced): This is the level of training you are interested in.
* **Evaluation Format** (id: 12, select one: On-site/Off-site/Self): This is the format of the evaluation after the training. Select one from the list.
* **Follow-up** (id: 13, select multiple: None/Other): This is the follow-up schedule you would like to have after the training.
* **Follow-up Frequency** (id: 14, select multiple: None/Other): This is the frequency of follow-up you would like to have after the training.
* **Follow-up 1** (id: 15, text): This is a text field for any additional information about the follow-up schedule.
* **Follow-up 2** (id: 16, text): This is a text field for any additional information about the follow-up schedule.
* **Follow-up 3** (id: 17, text): This is a text field for any additional information about the follow-up schedule.

## Tips
* Please make sure to provide as much detail as possible to ensure that we can provide you with the best possible training experience.
* If you have any special requests or needs, please provide them in the "Follow-up 1", "Follow-up 2", or "Follow-up 3" fields.
* If you are unsure about any of the options, please ask for clarification before submitting the form.
