# Tenant Community Poll Consent Form - Help Guide
## Purpose
This form is used to collect information from tenants regarding their consent to participate in a poll or event. It captures essential details such as poll title, message, start and end dates, event title, event description, event start and end dates, poll type, poll frequency, and event location.

## How To Complete This Form
1. Please fill out the form completely, ensuring you provide accurate information.
2. If you need to specify a different poll frequency or event location, use the "Other" option.

## Field-by-Field Explanation
* **Title** (`poll_title`): A brief and descriptive title for the poll.
* **Message** (`poll_message`): A clear and concise message regarding the poll.
* **Start Date** (`poll_start_date`): The date the poll is scheduled to start.
* **End Date** (`poll_end_date`): The date the poll is scheduled to end.
* **Event Title** (`event_title`): A brief and descriptive title for the event.
* **Event Description** (`event_description`): A clear and concise description of the event.
* **Event Start Date** (`event_start_date`): The date the event is scheduled to start.
* **Event End Date** (`event_end_date`): The date the event is scheduled to end.
* **Poll Type** (`poll_type`): Choose between "Multiple Choice" and "Open-Ended".
* **Poll Frequency** (`poll_frequency`): Choose how often the poll will be conducted, e.g., Weekly, Bi-Weekly, Monthly, Quarterly, Semi-Annually, Annually.
* **Poll Frequency Other** (`poll_frequency_other`): If you select "Other" as your poll frequency, please specify the frequency here.
* **Event Location** (`event_location`): The location where the event will take place.
* **Event Location Other** (`event_location_other`): If you select "Other" as your event location, please specify the location here.

## Tips
* Make sure to fill out all required fields, especially the "Message" field.
* If you need help or clarification on any field, feel free to contact us at form@gic.mx.
