# Stationery Delivery Form - Help Guide
## Purpose
This form is for requesting delivery of stationery items within the office.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of stationery items you need from the "Stationery Type" dropdown list.
2. Enter the quantity of stationery items you require.
3. Optionally, provide your contact information: address, email, and phone number.
4. Choose a delivery date and time if required.
5. Add any additional delivery notes.
6. Include any order comments or notes.
7. Select any additional stationery items you need.

## Field-by-Field Explanation

### 1. **Stationery Type**
(Stationery type, Select one, Required: false)
This field allows you to select the type of stationery items you need, such as A4 paper, Bond paper, cards, etc.

### 2. **Quantity**
(Quantity, Number, Required: true)
Enter the number of stationery items you require.

### 3. **Address**
(Address, Text, Required: false)
If you have a specific address where you would like the stationery delivered, enter it here.

### 4. **Contact Email**
(Contact Email, Email, Required: false)
If you have a contact email, enter it here so we can reach you regarding the delivery.

### 5. **Contact Phone**
(Contact Phone, Text, Required: false)
If you have a contact phone number, enter it here.

### 6. **Delivery Date**
(Delivery Date, Date, Required: false)
If you have a specific delivery date, choose it from the calendar.

### 7. **Delivery Time**
(Delivery Time, Time, Required: false)
If you need the delivery to be done at a specific time, choose it from the available options.

### 8. **Delivery Note**
(Delivery Note, Note, Required: false)
Add any additional delivery notes or instructions here.

### 9. **Order Notes**
(Order Notes, Note, Required: true)
Include any additional comments or notes about your order here.

### 10. **Comments**
(Comments, Text, Required: false)
Add any additional comments or questions about your order here.

### 11. **Additional Stationery Items**
(Additional Stationery Items, Select multiple, Required: false)
If you need any additional stationery items not listed above, select them from the options.
