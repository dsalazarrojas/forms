# IT System Onboarding Form - Help Guide
## Purpose
The IT System Onboarding Form is used to gather essential information about new employees and provision system access as needed. This form must be completed by new employees to ensure proper integration into the company's IT systems.

## How To Complete This Form
1.  Complete the form in its entirety, ensuring all required fields are filled.
2.  Review and update information as needed.
3.  Submit the form to initiate system access and onboarding.

## Field-by-Field Explanation
* **New Employees Info** (`new_employees_info`, text, optional): Enter new employee's name and department/unit.
* **System Access** (`system_access`, select_multiple, optional): Select the systems or applications this new employee needs access to.
* **Required Documents** (`required_documents`, text, optional): Attach any necessary documents for new employee onboarding (e.g., contract, ID, etc.).
* **Contact Info** (`contact_info`, text, optional): Enter new employee's contact information, including phone number and email address.

## Tips
* Please ensure all fields are filled accurately and correctly to avoid any issues with system access or employee records.
* If any fields are unclear or require further explanation, please refer to the specific field explanations above.
* Review and update information as necessary to ensure proper integration into the company's IT systems.
