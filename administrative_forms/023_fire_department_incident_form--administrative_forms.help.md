# Fire Department Incident Form - Help Guide
## Purpose
This form is designed for the Fire Department to report and document incidents. It collects information about the location, type, date, time, status, and description of the incident. The form is intended for internal use within the department to track and manage incidents.

## How To Complete This Form
To complete this form, follow the steps below:
1. Fill out the required and optional fields as necessary.
2. Provide accurate and concise information in each field.
3. Review the form for completeness before submitting.

## Field-by-Field Explanation

### Incident Location
* **Incident Location (text)**: Enter a brief description of the incident location. This can include the address, building name, or any other identifying features.
*   **Incident Type (select one)**: Choose from the following options:
	+ Fire: This option should be selected for any incident involving fire or fire-related equipment.
	+ Emergency: This option should be selected for situations that require immediate attention, such as 911 calls or severe medical emergencies.
	+ Other: Select this option if the incident does not fit into the above categories.
*   **Date (date)**: Enter the date of the incident in the format MM/DD/YYYY.
*   **Time (time)**: Enter the time of the incident in the format HH:MM AM/PM.
*   **Incident Status (select one)**: Choose from the following options:
	+ Active: This option should be selected if the incident is currently ongoing or unresolved.
	+ Resolved: This option should be selected if the incident has been addressed and closed.
	+ Closed: This option should be selected if the incident is no longer being actively addressed.
*   **Incident Description (text)**: Provide a brief description of the incident, including any relevant details or circumstances.

## Tips
* Make sure to provide accurate and complete information in each field.
* Double-check the form for completeness before submitting.
* If you are unsure about any field, consult with your supervisor or colleague for guidance.
