# Resident Registration Form - Help Guide

## Purpose
The Resident Registration Form is a collection of fields designed to gather relevant information from new residents, including their contact details, emergency contact, lease terms, lease dates, and rent details. This information will be used to update our records and facilitate administrative tasks.

## How To Complete This Form
1. Read through each field carefully and provide accurate information.
2. Complete all required fields (none marked as required in this form).
3. Double-check your submission before submitting.

## Field-by-Field Explanation

* **New Resident Form**:
	+ Label: New Resident Form
	+ Type: Text field
	+ Purpose: This field is intended to collect a brief description or name of the resident.
* **Contact Information**:
	+ Label: Contact Information
	+ Type: Text field
	+ Purpose: This field collects the resident's contact details, such as phone number or email.
* **Emergency Contact**:
	+ Label: Emergency Contact
	+ Type: Text field
	+ Purpose: This field is meant to gather the contact information of an emergency contact for the resident.
* **Lease Terms**:
	+ Label: Lease Terms
	+ Type: Text field
	+ Purpose: This field is intended to record any specific lease terms or conditions relevant to the resident.
* **Lease Start Date**:
	+ Label: Lease Start Date
	+ Type: Number field ( likely a date picker)
	+ Purpose: This field is meant to record the start date of the lease.
* **Lease End Date**:
	+ Label: Lease End Date
	+ Type: Number field (likely a date picker)
	+ Purpose: This field is intended to record the end date of the lease.
* **Move In Date**:
	+ Label: Move In Date
	+ Type: Number field (likely a date picker)
	+ Purpose: This field is meant to record the date the resident moved in.
* **Rent**:
	+ Label: Rent
	+ Type: Number field
	+ Purpose: This field is intended to record the resident's rent amount.

## Tips
- Please ensure accurate information is provided for each field.
- If unsure about a field, contact support.
- This form is for new residents only, please do not complete this form if you are already a resident.
