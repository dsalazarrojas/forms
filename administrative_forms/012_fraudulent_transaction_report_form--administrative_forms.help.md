# Fraudulent Transaction Report Form - Help Guide
## Purpose
This form is used to report a suspicious or fraudulent transaction.

## How To Complete This Form
To complete this form, simply fill in the required fields with as much information as you have. You can submit the form with partial information, and add more details later if needed. Make sure to review your entries carefully before submitting.

## Field-by-Field Explanation

* **Transaction Date**: The date the transaction was made.
* **Transaction Amount**: The amount of the transaction.
* **Description**: A brief description of the transaction.
* **Suspicous Activities**: Check the type of suspicious activity that occurred. (Transactional, Non-Transactional, or Other)
* **Investigation Officer**: The person handling the investigation. (Select from: John, Jane, or Joe)
* **Suspicious IP**: The IP address associated with the transaction.
* **Transaction Type**: The type of transaction. (Credit, Debit, Transfer, or Other)
* **Suspicous Location**: The location where the transaction was made.
* **Transaction Time**: The time the transaction was made.
* **Notes**: Additional comments or details about the transaction.
* **Email**: The email address associated with the suspect.
* **Phone**: The phone number associated with the suspect.
* **Reported By**: The person reporting the transaction. (Select from: Jimmy, Jane, or John)
* **Reported On**: The date the transaction was reported.
* **IP Address**: The IP address associated with the transaction.
* **Suspect Name**: The name of the suspect.
* **Suspect Address**: The address of the suspect.
* **Suspect Country**: The country where the suspect is from. (Select from: United States, Mexico, or Canada)
* **Suspect City**: The city where the suspect is from.
* **Suspect Zip**: The zip code where the suspect is from.
* **Suspect State**: The state where the suspect is from.
* **Suspect Phone**: The phone number associated with the suspect.
* **IP Geolocation**: Additional information about the IP address.
* **Suspect Email**: The email address associated with the suspect.
* **Suspect Browser**: The browser used by the suspect.
