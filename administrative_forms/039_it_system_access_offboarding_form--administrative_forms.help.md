# it_system_access_offboarding_form - Help Guide
## Purpose
The IT System Offboarding Form is used to collect information necessary for the deactivation of an employee's IT system access upon departure from the company. This form is to be filled out by the employee before their offboarding process is completed.

## How To Complete This Form
To complete this form, simply follow these steps:
1. Fill out the fields with the required information.
2. Ensure that the "System Access Deactivated" field is set to "IT System Access" to indicate that all IT system access will be deactivated.
3. Select "Yes" for "IT Administrators" to confirm that the IT administrators have been notified.
4. Choose "Yes" or "No" as needed for "Manager Approvals" and "System Access" fields.
5. Fill out the "Deactivation Date" field with the date the IT system access will be deactivated.
6. Enter any additional information in the "Additional Information" field if necessary.
7. Complete the "Manager Name", "Manager Email", and "Manager Title" fields with the relevant manager's details.

## Field-by-Field Explanation
- **Employee Information**: This is the section where the employee can enter their own information, including their details that will be used during the offboarding process.
  - **Manager Approvals**: This field is used to confirm if the manager has approved the offboarding process. Select "Yes" if the manager has approved and "No" if they have not.
  - **Deactivation Date**: This field is used to enter the date when the IT system access will be deactivated.
  - **Reason For Departure**: This field is used to enter the reason for the employee's departure from the company.
  - **System Access Deactivated**: This field is used to indicate what type of access will be deactivated. Select "IT System Access", "Network Access", "Email", or "Phone" depending on what type of access the employee will have.
  - **Additional Information**: This field is used to enter any additional information that is relevant to the offboarding process.
  - **Manager Name**: This field is used to enter the name of the employee's manager.
  - **Manager Email**: This field is used to enter the email of the employee's manager.
  - **Manager Title**: This field is used to enter the manager's title.
  - **IT Administrators**: This field is used to confirm if the IT administrators have been notified about the offboarding process. Select "Yes" if they have been notified.
  - **System Access**: This field is used to indicate what type of system access the employee will have. Select "Yes" or "No" depending on what type of access the employee will have.

## Tips
- Before submitting the form, make sure to have your manager's approval.
- Ensure that all required fields are filled out before submitting the form.
- If you have any doubts about the offboarding process, contact your HR representative for guidance.
