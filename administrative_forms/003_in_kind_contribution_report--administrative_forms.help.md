# In-Kind Contribution Report - Help Guide
## Purpose
The In-Kind Contribution Report form is used to report non-cash donations made to a political campaign or committee. This form is required for individuals and organizations that have made in-kind contributions, which include goods and services provided by a donor to support a campaign or committee.

## How To Complete This Form
1. Review the form to understand what information is required.
2. Determine if you have made any in-kind contributions that need to be reported.
3. Fill out the form with the required information, including:
	* Non-Cash Donations (field 1): Indicate if you have made any non-cash contributions.
	* Contribution Date (field 2): Provide the date of the contribution.
	* Prophets (field 3): This field may not be directly relevant for most users. If you are unsure, leave it blank.
	* Non-Cash Donations Value (field 4): Enter the value of the non-cash contribution.
	* In-Kind Description (field 5): Provide a brief description of the in-kind contribution.
	* Non-Cash Donations Type (field 6): Indicate the type of non-cash contribution (Cash, Other, In-Kind).
	* Non-Cash Donations Source (field 7): Indicate the source of the non-cash contribution (Cash, In-Kind, Other).
	* Non-Cash Donations Destination (field 8): Indicate the destination of the non-cash contribution (In-Kind, Other, Public).
	* Non-Cash Donations Recipient (field 9): Indicate if the non-cash contribution was received by the recipient (Yes, No).
	* Non-Cash Donations (field 10): Indicate if the contribution is non-cash (Yes, No).
	* In-Kind Contribution Report Date (field 11): Provide the date of the contribution.
	* Administrative (field 12): Indicate if the contribution is administrative (In-Kind, Other, Non-Cash).
	* Other Administrative (field 13): Indicate if the contribution is administrative (Yes, No).
	* Non-Cash Donations Total (field 14): Enter the total value of non-cash contributions.
	* In-Kind (field 15): Indicate if the contribution is in-kind (Cash, In-Kind, Other).
	* Other In-Kind (field 16): Indicate if the contribution is other in-kind (Yes, No).
	* Non-Cash Donations Other (field 17): Provide any additional information about the non-cash contribution.
	* In-Kind Contribution Total (field 18): Enter the total value of in-kind contributions.
	* In-Kind Report (field 19): This is a text field for any additional comments.
	* In-Kind Report 2 (field 20): This is a text field for any additional comments.
	* In-Kind Report 2 (field 21): Indicate the type of in-kind report (Cash, In-Kind, Other).
	* In-Kind Report 2 Value (field 22): Enter the value of the in-kind report 2.
	* In-Kind Report 2 Value 2 (field 23): Enter the value of the in-kind report 2.
	* In-Kind Report 2 Value 3 (field 24): This is a text field for any additional comments.
4. Review your answers for accuracy and completeness.
