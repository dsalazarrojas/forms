# Access Control Monitoring Form - Help Guide
## Purpose

The Access Control Monitoring Form is a vital tool for monitoring and recording access control and incident reporting during a shift. It helps ensure that all necessary details are captured accurately, and provides a comprehensive picture of any incidents that may have occurred.

## How To Complete This Form

1. Fill in the "Monitoring Officer Name" field with the name of the officer on duty.
2. Select the current date in the "Date of Monitoring" field.
3. Record the start time of the shift in the "Shift or Session Start Time" field.
4. Enter the total number of successful and denied access attempts in the "Total Number of Successful Entries" and "Total Number of Denied Access Attempts" fields, respectively.
5. Provide reasons for denied access attempts in the "Reasons for Denied Access" field.
6. Indicate whether all security cameras are operational in the "Are all security cameras operational?" field.
7. Check the status of the access control server in the "Access Control Server Status" field.
8. Report any security incidents that occurred during the shift in the "Were there any security incidents during this shift?" field.
9. If an incident occurred, provide a brief summary of what happened in the "Summary of incidents - if any" field.
10. Enter any handover notes for the next shift or officer in the "Notes for the next shift or officer" field.
11. Finally, confirm the accuracy of this monitoring log in the "I confirm the accuracy of this monitoring log" field.

## Field-by-Field Explanation

* **Monitoring Officer Name**: Enter the name of the officer on duty.
* **Date of Monitoring**: Select the current date.
* **Shift or Session Start Time**: Record the start time of the shift.
* **Total Number of Successful Entries**: Enter the total number of successful access attempts.
* **Total Number of Denied Access Attempts**: Enter the number of denied access attempts.
* **Reasons for Denied Access**: Provide reasons for denied access attempts. For example, if access was denied due to expired ID or restricted zones, enter those reasons here.
* **Are all security cameras operational?**: Check if all security cameras are operational.
* **Access Control Server Status**: Check the status of the access control server.
* **Were there any security incidents during this shift?**: Report any security incidents that occurred during the shift.
* **Summary of incidents - if any**: Briefly describe what happened if an incident occurred.
* **Notes for the next shift or officer**: Enter any handover notes for the next shift or officer.
* **I confirm the accuracy of this monitoring log**: Confirm the accuracy of this monitoring log.
