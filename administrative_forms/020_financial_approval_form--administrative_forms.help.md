# Financial Approval Form - Help Guide

## Purpose
This form is designed to facilitate financial approval processes for budget requests and expense reimbursements. It ensures that all necessary information is captured and reviewed before processing financial transactions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant budget requests from the list provided under "Budget requests".
2. Choose the correct expense reimbursement date from the calendar input field.
3. Enter any additional funding allocation information in the "Funding allocations" field (if required).
4. Provide the financial amount for approval (if required).
5. Select the approval date for the request.

## Field-by-Field Explanation

* **Budget requests** (`budget_requests`, `select_multiple`, required): Choose one or more budget requests relevant to your financial approval. These could be expense requests, reimbursements, or other budget-related needs.
* **Expense reimbursements** (`expense_reimbursements`, `date`, optional): Select the date of the expense reimbursement if it's an optional field. This date should reflect when the expense was incurred.
* **Funding allocations** (`funding_allocations`, `note`, optional): Enter any additional information regarding funding allocations. This could include details about the funding source or allocation process. Note that this field is not required for most users.
* **Financial Amount** (`financial_amount`, `number`, optional): If financial approval is required, enter the exact financial amount being requested or approved.
* **Approval Date** (`approval_date`, `date`, optional): Select the date of approval for the financial request. This is typically when the approval process was completed.

## Tips
Remember to review the form carefully before submitting it, ensuring all required fields are filled out accurately. If you're unsure about any field, please seek guidance from your supervisor or the financial team.
