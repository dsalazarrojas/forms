# Building Maintenance Forecast Request Form - Help Guide

## Purpose
This form is used to gather information about anticipated maintenance work for a building. It helps the maintenance team plan and budget for the required work.

## How To Complete This Form

1. Please fill in the required fields with accurate and complete information.
2. Make sure to review each field carefully to ensure you are providing the correct information.
3. If you are unsure about any field, please ask your supervisor or department manager for guidance.

## Field-by-Field Explanation

* **Requester name** (`requester_name`, text, required): This field is for you to enter your name as the person requesting the maintenance work.
* **Department or area** (`requester_department`, text, required): Please enter the department or area that the maintenance work is related to.
* **Email address** (`requester_email`, email, required): Enter your email address so we can contact you with updates and questions.
* **Phone number** (`requester_phone`, text, required): Enter your phone number so we can contact you with questions or updates.
* **Building name or identifier** (`building_name`, text, required): Enter the name or identifier of the building that requires maintenance work.
* **Building address** (`building_address`, text, required): Enter the address of the building that requires maintenance work.
* **Facility type** (`facility_type`, select_one, required): Select the type of facility that the building is, e.g. Office building, Residential, etc.
* **Building square footage** (`square_footage`, number, optional): If applicable, enter the square footage of the building.
* **Type of maintenance needed** (`maintenance_type`, select_multiple, required): Select the type of maintenance needed, e.g. Preventive maintenance, Corrective repair, etc.
* **Specific areas or systems affected** (`specific_areas`, select_multiple, required): Select the specific areas or systems that require maintenance.
* **Detailed description of maintenance needed** (`maintenance_description`, text, required): Provide a detailed description of the maintenance work needed.
* **Anticipated timeframe for maintenance** (`forecast_timeframe`, select_one, required): Select the anticipated timeframe for the maintenance work.
* **Preferred start date** (`preferred_start_date`, date, optional): If applicable, enter the preferred start date for the maintenance work.
* **Preferred completion date** (`preferred_end_date`, date, optional): If applicable, enter the preferred completion date for the maintenance work.
* **Urgency level** (`urgency_level`, select_one, required): Select the urgency level of the maintenance work, e.g. Critical, High, Medium, etc.
* **Current condition of equipment/area** (`current_condition`, select_one, required): Select the current condition of the equipment or area that requires maintenance, e.g. Good, Fair, Poor, etc.
* **Impact if maintenance is delayed** (`impact_if_delayed`, text, optional): If applicable, enter the impact if the maintenance is delayed.
* **Estimated cost** (`estimated_cost`, number, optional): If applicable, enter an estimate of the cost for the maintenance work.
* **Confidence in cost estimate** (`cost_confidence`, select_one, optional): If applicable, select the level of confidence in the cost estimate, e.g. High, Moderate, Low, etc.
* **Scope of work** (`work_scope`, select_one, required): Select the scope of the maintenance work, e.g. Single item replacement, Multiple items repair, etc.
* **Anticipated funding source** (`funding_source`, select_one, optional): If applicable, select the source of funding for the maintenance work.
* **Will maintenance require building closure?** (`requires_building_closure`, select_one, optional): If applicable, select whether the maintenance work will require building closure.
* **Expected closure duration** (`closure_duration`, text, optional): If applicable, enter the expected duration of building closure.
* **Occupant notification required** (`occupant_notification`, select_one, optional): If applicable, select whether occupant notification is required.
* **Equipment specifications or requirements** (`equipment_specifications`, text, optional): If applicable, enter equipment specifications or requirements.
* **Compliance or code requirements** (`compliance_requirements`, text, optional): If applicable, enter compliance or code requirements.
* **Sustainability preferences** (`sustainability_preferences`, text, optional): If applicable, enter sustainability or efficiency preferences.
* **Potential complications or risks** (`potential_complications`, text, optional): If applicable, enter potential complications or risks.
* **Contingency plan if issues discovered** (`contingency_plan`, text, optional): If applicable, enter a contingency plan if issues are discovered.
* **Preferred contractors or vendors** (`preferred_contractors`, text, optional): If applicable, enter preferred contractors or vendors.
* **Approval level needed** (`approval_needed`, select_one, optional): If applicable, select the level of approval needed.
* **Direct manager name** (`manager_name`, text, required): Enter the name of the direct manager for approval routing.
* **Additional notes or attachments** (`additional_notes`, text, optional): If applicable, enter any additional notes or attachments.

## Tips

* Make sure to review each field carefully to ensure you are providing the correct information.
* If you are unsure about any field, please ask your supervisor or department manager for guidance.
* Please provide detailed and accurate information to ensure that the maintenance team can plan and budget for the required work.

By following this guide, you should be able to complete this form accurately and effectively. If you have any further questions or concerns, please don't hesitate to reach out to your supervisor or department manager.
