# document_management_system_access_form - Help Guide
## Purpose
This form is used to manage access to the document management system. It requires a unique ID, role, access level, and start and end dates for access.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name in the First name field.
2. Enter your last name in the Last name field.
3. Enter your email address in the Email field.
4. Enter your phone number in the Phone field.
5. Enter your user name in the User name field.
6. Select your role from the Role menu. This will determine who has access to the system and what level of access they have.
7. Select your access level from the Access level menu. This will determine how much access you have to the system.
8. Enter your start date for access in the Start date field.
9. Enter your end date for access in the End date field.
10. Enter the ID of the tool being used in the Tool field.
11. Enter any additional description in the Description field.
12. Enter the ID of the assigned tool in the Assigned Tool field.
13. Enter any additional description for the assigned tool in the Description 2 field.
14. Enter the unique ID of the form in the ID field.

## Field-by-Field Explanation

* **First name** (`first_name`, text, optional): Enter your first name.
* **Last name** (`last_name`, text, optional): Enter your last name.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **User name** (`user_name`, text, optional): Enter your user name.
* **Role** (`role`, select_one, required): Select your role from the menu. This determines who has access to the system.
* **Department** (`user_department`, text, optional): Enter your department.
* **Date of birth** (`date_of_birth`, date, optional): Enter your date of birth.
* **Job position** (`user_job_position`, text, optional): Enter your job position.
* **Access level** (`access_level`, select_multiple, required): Select your access level from the menu. This determines how much access you have to the system.
* **Start date** (`access_start_date`, date, optional): Enter your start date for access.
* **End date** (`access_end_date`, date, optional): Enter your end date for access.
* **Tool** (`assigned_tool`, text, optional): Enter the ID of the tool being used.
* **Category** (`category`, text, optional): Enter the category of the tool.
* **Description** (`description`, text, optional): Enter any additional description for the tool.
* **ID** (`form_id`, number, required): Enter the unique ID of the form.
* **Assigned Tool 2** (`assigned_tool_2`, text, optional): Enter the ID of the assigned tool.
* **Description 2** (`description_2`, text, optional): Enter any additional description for the assigned tool.
