# vehicle_registration_extension_form - Help Guide
## Purpose
This form is designed to collect information for vehicle registration purposes.

## How To Complete This Form
1. Fill out each page of the form completely.
2. Make sure to review and correct any errors before submitting.
3. Double-check all required fields, as indicated in the form.

## Field-by-Field Explanation

* **Vehicle Registration Details** (`vehicle_registration_details`, text, required):
	+ This page asks for vehicle registration details. Please provide the make, model, year, and any other relevant information about the vehicle.
* **Owner Details** (`owner_details`, text, required):
	+ This page asks for owner information, including name and contact details.
* **Registration Extension** (`registration_extension`, text, optional):
	+ This page is for additional information about the vehicle's registration. Please use this field only if you need to add something that does not fit in the "Vehicle Registration Details" page.

## Tips
* Review the form carefully before submitting to ensure accuracy.
* Double-check all required fields.
* If you need further clarification or have any questions, contact your administrator or support team.
