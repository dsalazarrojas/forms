# Landlord Documentation Access Form - Help Guide

## Purpose
This form is used by landlords to request access to documentation submitted by tenants, which may be required for various administrative purposes such as verifying rental agreements, checking maintenance records, or accessing other relevant documents. The form helps streamline the process by providing a standardized way for landlords to collect and store documentation from multiple tenants in a single format.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the tenants that you are requesting documentation from by selecting their names from the "Tenant Submission" field.
2. Choose the type of document you are requesting by selecting the "Document Type" option from the dropdown menu.
3. You can either upload a document or type in a description if you do not have the document readily available.
4. Add a brief description of the document in the "Document Description" field.
5. You can add a second document upload if needed.
6. If you have a physical signature, you can add it in the "Tenant Signature" field.
7. Add your own signature in the "Landlord Signature" field.
8. Enter the date and time you signed the document in the "Date Signed" and "Time Signed" fields.
9. Finally, provide your email address and phone number for contact purposes.

## Field-by-Field Explanation

* **Tenant Submission** (Select Multiple):
	+ This field allows you to select the tenants that you are requesting documentation from.
	+ Please select all applicable tenants from the available options.
* **Document Type** (Select One):
	+ Choose the type of document you are requesting from the dropdown menu.
	+ Select "Lease" for rental agreements, "Rent" for payment records, or "Other" for other types of documents.
* **Document Upload** (Text):
	+ If you have a document available, you can upload it here.
	+ Please make sure the document is in a supported format (e.g. PDF, JPG, PNG).
* **Document Description** (Text):
	+ Add a brief description of the document, including its type and contents.
* **Document Upload 2** (Text):
	+ If you need to upload another document, add it here.
	+ Please make sure the document is in a supported format.
* **Tenant Signature** (Text):
	+ Add your tenant's signature if you have a physical copy.
* **Landlord Signature** (Text):
	+ Add your own signature as proof of authenticity.
* **Date Signed** (Date):
	+ Enter the date you signed the document.
* **Time Signed** (Time):
	+ Enter the time you signed the document.
* **Email** (Email):
	+ Enter your contact email address.
* **Phone** (Text):
	+ Enter your contact phone number.
* **Date Submitted** (Date):
	+ Enter the date you submitted the document.
