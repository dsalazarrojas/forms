# Emergency Contact Information Validation Form - Help Guide

# Purpose
The Emergency Contact Information Validation Form is used to gather and validate information about a person's emergency contacts, including their name, relationship, phone number, email address, and language spoken.

# How To Complete This Form
1. Select the relevant information for the emergency contact.
2. Fill out each field accordingly.
3. Review the information for accuracy.
4. Save the changes to update the emergency contact information.

# Field-by-Field Explanation

* **Emergency Contact Form** (`emergency_contact_form`, **required**): This is a text field that provides a brief description of the purpose of the form.
* **Emergency Contact Name** (`emergency_contact_name`, **required**): Enter the name of the emergency contact.
* **Relation** (`emergency_contact_relation`, **required**): Select the relation of the emergency contact (e.g., First, Second, Third).
* **Emergency Contact Phone** (`emergency_contact_phone`, **required**): Enter the phone number of the emergency contact.
* **Emergency Contact Email** (`emergency_contact_email`, **required**): Enter the email address of the emergency contact.
* **Emergency Contact Address** (`emergency_contact_address`, **required**): Enter the address of the emergency contact.
* **Contact** (`relation_to_contact`, **required**): Enter the contact person's name.
* **Important Details** (`emergency_contact_important_details`, **required**): Provide any important details about the emergency contact.
* **Is Emergency Contact** (`emergency_contact_is_emergency_contact`, **required**): Select 'True' if this is an emergency contact, 'False' otherwise.
* **Relationship Type** (`emergency_contact_relationship_type`, **required**): Select the relationship type (e.g., Spouse, Child, Parent).
* **Relationship** (`emergency_contact_relationship`, **required**): Select the relationship (e.g., Mother, Father, Brother).
* **Language** (`emergency_contact_language`, **required**): Select the language spoken by the emergency contact.
* **Important Info** (`emergency_contact_important_info`, **required**): Provide additional important information.
* **Additional Info** (`emergency_contact_additional_info`, **required**): Provide any additional information.
* **Emergency Contact Status** (`emergency_contact_status`, **required**): Select the emergency contact status (e.g., Active, Inactive).
* **Important Info 2** (`emergency_contact_important_info_2`, **required**): Provide additional important information.
* **Additional Info 2** (`emergency_contact_additional_info_2`, **required**): Provide any additional information.
* **Emergency Contact Status 2** (`emergency_contact_status_2`, **required**): Select the emergency contact status.
* **Important Info 3** (`emergency_contact_important_info_3`, **required**): Provide important information.
* **Additional Info 3** (`emergency_contact_additional_info_3`, **required**): Provide any additional information.
* **Emergency Contact Status 3** (`emergency_contact_status_3`, **required**): Select the emergency contact status.
* **Important Info 4** (`emergency_contact_important_info_4`, **required**): Provide important information.
* **Additional Info 4** (`emergency_contact_additional_info_4`, **required**): Provide any additional information.
* **Emergency Contact Status 4** (`emergency_contact_status_4`, **required**): Select the emergency contact status.
* **Important Info 5** (`emergency_contact_important_info_5`, **required**): Provide important information.
