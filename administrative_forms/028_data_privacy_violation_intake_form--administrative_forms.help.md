# data_privacy_violation_intake_form - Help Guide
## Purpose
This form is used to report data privacy violations that have occurred within the organization.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of report from the "Report Type" dropdown menu.
2. Provide a detailed description of the violation in the "Description" field.
3. Enter the date and time of the incident in the "Date of Incident" and "Time of Incident" fields, respectively.
4. If applicable, provide the location where the violation occurred in the "Location" field.
5. If applicable, provide your contact information and witness information in the "Contact Information" and "Witness Information" fields, respectively.
6. If applicable, attach any relevant evidence to the "Evidence" field.
7. Enter your name and title in the "Incident Reporter" field.
8. Select the reporting unit responsible for handling the report from the "Reporting Unit" select menu.
9. Enter the date and time the report was made in the "Report Date" and "Report Time" fields, respectively.
10. Select the tool used to investigate the violation from the "Assigned Tool" select menu.
11. Enter any additional comments or notes about the report in the "Report Notes" field.
12. Finally, select the current status of the report from the "Report Status" select menu.

## Field-by-Field Explanation

* **Report Type** (`report_type`, select_one, required): Select the type of report from the dropdown menu.
* **Description** (`description`, text, required): Provide a detailed description of the violation.
* **Date of Incident** (`date_of_incident`, date, required): Enter the date of the incident.
* **Time of Incident** (`time_of_incident`, time, required): Enter the time of the incident.
* **Location** (`location`, text, required): Provide the location where the violation occurred.
* **Contact Information** (`contact_information`, text, required): Provide your contact information.
* **Witness Information** (`witness_information`, text, required): If applicable, provide witness information.
* **Evidence** (`evidence`, text, required): Attach any relevant evidence.
* **Incident Reporter** (`incident_reporter`, text, required): Enter your name and title.
* **Reporting Unit** (`reporting_unit`, select_multiple, optional): Select the unit responsible for handling the report.
* **Report Date** (`report_date`, date, required): Enter the date the report was made.
* **Report Time** (`report_time`, time, required): Enter the time the report was made.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select the tool used to investigate the violation.
* **Report Notes** (`report_notes`, text, optional): Enter any additional comments or notes about the report.
* **Report Status** (`report_status`, select_one, optional): Select the current status of the report.

## Tips

* Please ensure that you have the necessary permissions to report data privacy violations within your department or organization.
* If you are unsure about any information or require clarification, please contact the appropriate authorities.
* If you are reporting a duplicate or non-urgent report, please indicate this on your report so that it can be handled accordingly.
