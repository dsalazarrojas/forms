# Street Sign Replacement Order Form - Help Guide
## Purpose
This form is intended to be used when you need to replace a street sign. Please fill in the required fields to provide the necessary information for the replacement process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Home Address** (page 1, field 1) to help us locate the street sign.
2. Enter the **Street Name** (page 1, field 2) of the sign to be replaced.
3. If you're not sure what type of street it is, select one or more of the options under **Street Type** (page 1, field 3). 
4. Provide a brief **Reason for Replacement** (page 1, field 4) to help us understand why the sign needs to be replaced.
5. Enter your **Contact Phone** (page 1, field 5) so we can get in touch with you for any further information.
6. Add any **Additional Notes** (page 1, field 6) if you have any specific concerns or requirements.
7. Select the person you'd like the task to be **Assigned to** (page 1, field 7) from the provided options.
8. Enter the **Output File** (page 1, field 8) if you have any specific file requirements for the replacement process.
9. Choose the **Category** (page 1, field 9) of the sign replacement request.
10. Enter the **Form ID** (page 1, field 10) for any internal tracking purposes.
11. Add a brief **Description** (page 1, field 11) of the issue with the street sign.

## Field-by-Field Explanation
### **Home Address** (page 1, field 1) - Text
* The home address is required to be filled in to help us locate the street sign.

### **Street Name** (page 1, field 2) - Text
* Enter the name of the street where the sign is located.

### **Street Type** (page 1, field 3)
* Select one or more of the options to determine the type of street (e.g. street type, house number).

### **Reason for Replacement** (page 1, field 4) - Text
* Provide a brief explanation of why the street sign needs to be replaced.

### **Contact Phone** (page 1, field 5) - Text
* Enter your phone number so we can get in touch with you for any further information.

### **Additional Notes** (page 1, field 6) - Text
* Add any specific concerns or requirements for the replacement process.

### **Assigned to** (page 1, field 7) - Text
* Select the person you'd like to be responsible for the task.

### **Assigned to** (page 1, field 8) - Text
* Select from the options to determine who will be assigned to the task.

### **Output File** (page 1, field 9) - Text
* Enter any specific file requirements for the replacement process.

### **Category** (page 1, field 9) - Text
* Choose the category of the sign replacement request.

### **Form ID** (page 1, field 10) - Text
* Enter the form ID for internal tracking purposes.

### **Description** (page 1, field 11) - Text
* Add a brief description of the issue with the street sign.

## Tips
* Please ensure that you fill in the form accurately to facilitate the replacement process. If you're unsure about any field, don't hesitate to ask for help.
* You can add any additional notes or concerns to the **Additional Notes** field to help us understand your needs better.
* Please note that the selection of the person you'd like to be assigned to will influence the priority and handling of the task.
