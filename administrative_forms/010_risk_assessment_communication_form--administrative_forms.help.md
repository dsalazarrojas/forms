# Risk Assessment Communication Form - Help Guide
## Purpose
The Risk Assessment Communication Form is used to capture information about risk assessments and communications within an organization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Choose the category of the risk assessment.
2. Provide a brief description of the risk assessment.
3. Select the assigned tool.
4. Repeat steps 1-3 for each of the multiple risk assessment form fields.

## Field-by-Field Explanation
- **Category** (Administrative Forms, Other): Select the category of the risk assessment.
- **Description 1** (description 1): Enter a brief description of the risk assessment.
- **Description 2** (description 2): Enter another brief description of the risk assessment.
- **Description 3** to **Description 14** (description 3-14): Enter additional brief descriptions of the risk assessment.
- **Assigned Tool** (chatjimmy, other): Select the tool used for risk assessment.
  * If you select "chatjimmy", provide the specific chat tool used.
  * If you select "other", provide the specific other tool used.
  * Note: The "chatjimmy" option seems to be a choice for a specific tool, but its relevance to risk assessment is unclear.
- **Risk Assessment Communication Form 1** to **Risk Assessment Communication Form 8** (Risk Assessment Communication Form 1-8): Enter any additional information about the risk assessment.
  * These fields seem to be redundant with the description fields.
  * You can fill out any of these fields if you have additional information to provide.
  * If you don't have any additional information, you can leave these fields blank.
