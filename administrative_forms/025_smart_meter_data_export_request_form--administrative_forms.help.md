# Smart Meter Data Export Request Form - Help Guide
## Purpose

The Smart Meter Data Export Request Form is used to collect information for data export requests from smart meters. This form is used to gather essential details about the user's data export preferences.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your name (first and last name)
2. Provide your contact email address
3. Enter your phone number
4. Select the type of data you would like to export (e.g., all data, last 30 days, last 30 days with usage)
5. Select a date for the meter reading (optional)
6. Select a date for export (optional)

## Field-by-Field Explanation

* **Smart Meter Data Export Request** (`smart_meter_data_export_request_form`, text, optional): This field is a general description of your data export request.
* **First Name** (`smart_meter_data_export_request_form_first_name`, text, optional): Please enter your first name.
* **Last Name** (`smart_meter_data_export_request_form_last_name`, text, optional): Please enter your last name.
* **Email** (`smart_meter_data_export_request_form_email`, email, optional): Enter a valid email address where we can contact you.
* **Phone** (`smart_meter_data_export_request_form_phone`, text, optional): Enter your phone number.
* **Export Type** (`smart_meter_data_export_request_form_select_type`, select multiple, optional): Choose from the options:
	+ export all data
	+ export last 30 days
	+ export last 30 days with usage
* **Meter Read Date** (`smart_meter_data_export_request_form_date`, date, optional): Please select a date for the meter reading (this is optional).
* **Export Date** (`smart_meter_data_export_request_form_date`, date, optional): Please select a date for the export (this is optional).
* **Date of Birth** (`smart_meter_data_export_request_form_date`, date, optional): Please select a date of birth (this is optional).
