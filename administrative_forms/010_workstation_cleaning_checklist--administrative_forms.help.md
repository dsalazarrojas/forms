# Workstation Cleaning Checklist - Help Guide

## Purpose
This form is used to document workstation cleaning tasks and activities. Please report the tasks you completed, the area cleaned, and your comments for future reference.

## How To Complete This Form

To complete this form, please follow these steps:

* Select the area you cleaned (e.g., Office, Break Room, etc.)
* Report the products used for cleaning
* Choose the frequency of cleaning (e.g., Daily, Weekly, etc.)
* Select the tasks completed during the cleaning
* Enter the time spent on cleaning
* Enter any comments or observations you have about the cleaning process
* Select the form category and description (this will automatically be filled with the default values, but you can override them as needed)

## Field-by-Field Explanation

* **Work Area** (`work_area`, select_multiple, required: false): Select the area you cleaned (e.g., Office, Break Room, etc.).
* **Cleaning Products Used** (`cleaning_products_used`, text, required: false): List the products you used for cleaning.
* **Cleaning Frequency** (`cleaning_frequency`, select_one, required: false): Choose the frequency of cleaning (e.g., Daily, Weekly, etc.).
* **Time Spent Cleaning** (`cleaning_time`, time, required: false): Enter the time spent on cleaning.
* **Completed Tasks** (`completed_tasks`, select_multiple, required: false): Select the tasks completed during the cleaning (e.g., Cleaning the Sink, Disinfecting the Toilet, etc.).
* **Comments** (`comments`, note, required: false): Enter any comments or observations you have about the cleaning process.
* **Workstation Cleaning Checklist Comments** (`workstation_cleaning_checklist_comments`, note, required: false): Enter any additional comments about the cleaning process.
* **Assigned To** (`assigned_user`, text, required: false): Enter the name of the person assigned to the task.
* **Assigned Tool** (`assigned_tool`, text, required: false): Enter the tool used for the task.
* **Output File Name** (`output_file_name`, text, required: false): Enter the name of the output file.
* **Output File** (`output_file`, text, required: false): Enter the path to the output file.
* **Form Id** (`form_id`, number, required: false): Enter the form id.
* **Category** (`category`, select_one, required: false): Select the category (e.g., Administrative Forms, Other).
* **Description** (`description`, text, required: false): Enter the description of the form.
* **Category Name** (`category_name`, text, required: false): Enter the name of the category.
* **Workstation Cleaning Checklist Comments** (`workstation_cleaning_checklist_comments`, note, required: false): Enter any additional comments about the form.
