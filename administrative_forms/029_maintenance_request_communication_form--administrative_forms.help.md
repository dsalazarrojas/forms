# Maintenance Request Communication Form - Help Guide

## Purpose
This form is used to submit maintenance requests for various categories, such as HVAC, Electrical, Plumbing, and Appliance. The form helps communicate maintenance needs to the relevant teams for processing.

## How To Complete This Form

*   **Step 1: Select the Tenant**: Enter the name of the tenant whose maintenance request you are submitting.
*   **Step 2: Select the Request Type**: Choose the category of maintenance required from the options: HVAC, Electrical, Plumbing, or Appliance.
*   **Step 3: Description**: Provide a brief description of the maintenance request.
*   **Step 4: Set the Priority**: Choose the priority level of the maintenance request from Low, Medium, or High.
*   **Step 5: Enter Contact Information**: Provide the contact name, contact phone number, and contact email for the person submitting the request.
*   **Step 6: Set the Inspection Date and Time**: Enter the date and time of the inspection.
*   **Step 7: Add Comments**: If necessary, provide any additional comments or details about the maintenance request.
*   **Step 8: Select Categories**: Choose the categories of maintenance required from the options: HVAC, Electrical, Plumbing, or Appliance.
*   **Step 9: Assign a Tool**: Enter the name of the tool assigned to perform the maintenance.
*   **Step 10: Submit**: Click the "Submit" button to complete and submit the form.

## Field-by-Field Explanation

*   **Tenant Name**: Enter the name of the tenant who is submitting the maintenance request.
    *   Type: text
    *   Required: false
*   **Request Type**: Choose the category of maintenance required.
    *   Type: select_one
    *   Options: HVAC, Electrical, Plumbing, Appliance
    *   Required: false
*   **Description**: Provide a brief description of the maintenance request.
    *   Type: text
    *   Required: false
*   **Priority**: Choose the priority level of the maintenance request.
    *   Type: select_one
    *   Options: Low, Medium, High
    *   Required: false
*   **Contact Name**: Enter the name of the person submitting the request.
    *   Type: text
    *   Required: false
*   **Contact Phone**: Enter the phone number of the person submitting the request.
    *   Type: text
    *   Required: false
*   **Contact Email**: Enter the email of the person submitting the request.
    *   Type: email
    *   Required: false
*   **Date Of Inspection**: Enter the date of the inspection.
    *   Type: date
    *   Required: false
*   **Time Of Inspection**: Enter the time of the inspection.
    *   Type: time
    *   Required: false
*   **Comments**: Provide any additional comments or details about the maintenance request.
    *   Type: note
    *   Required: false
*   **Category**: Choose the categories of maintenance required.
    *   Type: select_multiple
    *   Options: HVAC, Electrical, Plumbing, Appliance
    *   Required: false
*   **Assigned Tool**: Enter the name of the tool assigned to perform the maintenance.
    *   Type: text
    *   Required: false
*   **Submitted**: Date the request was submitted.
    *   Type: date
    *   Required: false

Note: The fields with "Required: false" in the YAML are optional.
