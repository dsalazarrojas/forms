# Team Management Software Requisition Form - Help Guide
## Purpose
This form is used to request or submit team requests for software or resources within the organization. 

## How To Complete This Form
To complete this form, follow the steps below:

* Select whether a team request is being made or software request is required.
* Enter the requested date if the request is for a specific date.
* Choose the requester or team member who is making the request.
* Provide the team name and brief description.
* Indicate if software requisition is needed.
* If software requisition is selected, enter the software version and vendor.
* Indicate if the software requisition is for a specific software.
* Select the approval status of the team request.
* Enter the approval date if the request has been approved.
* Select who approved the team request.
* Enter any comments regarding the team request.
* Provide any additional comments about the request.

## Field-by-Field Explanation
* **Team Request Form**: Select whether a team request is being made (`Yes` or `No`).
* **Requested Date**: Enter the date when the team request was requested if applicable (format: MM/DD/YYYY). This field is not required.
* **Requester**: Select the person or team member who is requesting the team (`Yes` or `No`). This field is not required.
* **Team Name**: Enter the name of the team requesting the resource (`text`). This field is not required.
* **Team Description**: Enter a brief description of the team requesting the resource (`text`). This field is not required.
* **Software Requisition**: Indicate if software requisition is needed (`Yes` or `No`). This field is not required.
* **Software Requisitioner**: Select if software requisition is being made for a specific software (`Yes` or `No`). This field is not required.
* **Approval Status**: Select the status of the team request (`Active` or `Inactive`). This field is not required.
* **Approval Date**: Enter the date when the team request was approved. This field is not required.
* **Approved By**: Select the person who approved the team request (`Yes` or `No`). This field is not required.
* **Comments**: Enter any comments or remarks regarding the team request. This field is optional.
* **Software Version**: Enter the version number of the software requisitioned for if applicable.
* **Software Vendor**: Enter the name of the software vendor if applicable.
* **Requisited By**: Select the person who requisited the resource (`Yes` or `No`). This field is not required.
* **Request Reason**: Enter a brief explanation of the reason for the team request.
* **Additional Comments**: Enter any additional comments about the team request. This field is optional.
* **Form Status**: Select the status of the form (`Active` or `Inactive`). This field is not required.
* **Submitter**: Select if the form has been submitted by the user (`Yes` or `No`). This field is not required.
