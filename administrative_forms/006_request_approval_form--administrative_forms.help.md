# request_approval_form - Help Guide
## Purpose
The "request_approval_form" is used for requesting approval from multiple managers for specific tasks or activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the "Request Form" page (page 1) with a brief description of the request, including the requested date and time.
2. On the "Managers" page (page 2), select the managers involved in the approval process by choosing their name from the dropdown menu.
3. On the "Approval" page (page 3), select the status of each manager's approval, if applicable.
4. On the "Additional Information" page (page 4), you can add any additional comments or details about the request.

## Field-by-Field Explanation
* **Request Form** (`request_1`, text, optional): A brief description of the request, including the requested date and time.
* **Manager 1** (`approval_1`, select_one, optional): Select the manager involved in this approval process from the dropdown menu.
* **Manager 1 Approval** (`manager_1`, select_multiple, optional): Select the status of Manager 1's approval.
* **Manager 2 Approval** (`approval_2`, select_one, optional): Select the status of Manager 2's approval.
* **Manager 3 Approval** (`manager_3`, select_multiple, optional): Select the status of Manager 3's approval.
* **Date** (`date_1`, date, optional): The date of the request, in the format of MM/DD/YYYY.
* **Time** (`time_1`, time, optional): The time of the request, in the format of HH:MM AM/PM.
* **Note** (`note_1`, note, optional): A note about the request, if any.
* **Email** (`email_1`, email, optional): The email address for follow-up communication.
* **Phone** (`phone_1`, text, optional): The phone number for follow-up communication.
* **Additional Comments** (`request_2`, text, optional): Any additional comments or details about the request.

## Tips
* Ensure that you select the correct manager for each approval status.
* Double-check the date and time of the request for accuracy.
* Use the "Additional Comments" field for any extra information that may be helpful for the manager's consideration.
* If you are requesting approval for a recurring event, please specify the start and end dates in the "Additional Comments" field.
* If you are not sure about any of the fields, please consult with your team or departmental contact for assistance.
