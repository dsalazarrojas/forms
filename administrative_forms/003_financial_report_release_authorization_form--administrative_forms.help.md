# Financial Report Release Authorization Form - Help Guide
## Purpose
The Financial Report Release Authorization Form is designed to authorize the release of financial reports. It is used to determine who can access the financial report and when it can be released.

## How To Complete This Form
1. Ensure you are authorized to fill out this form and that the report has not been previously submitted.
2. Fill out the form carefully, providing accurate information for each field.
3. Review your answers carefully before submitting the form.

## Field-by-Field Explanation
- **User Details** (`user`, `text`, required): Please enter your name and other relevant details to be associated with this form.
- **Report Details** (`report_details`, `select_one`, required): Choose 'Yes' to release the financial report, and 'No' to not release it.
- **Release Date** (`release_date`, `date`, optional): Enter the date you would like to release the financial report. If left blank, the report will be released as soon as possible.
- **Financial Institution** (`financial_institution`, `select_one`, optional): Select the financial institution associated with this report.
- **Contact Info** (`contact_info`, `text`, optional): Enter the contact information of the person or department that should be notified after the report is released.
- **Confirm** (`confirm`, `select_multiple`, optional): Choose all the options that apply to confirm your authorization.
