# Supervision Activity Log - Help Guide
## Purpose

The Supervision Activity Log form is designed to document and track individual supervision activities. The form is intended to be completed by a supervisor to record the details of a supervision activity that occurred.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the category of the supervision activity (e.g. Administrative, Financial, HR).
2. Enter a description of the supervision activity.
3. Enter the date the supervision activity started.
4. Enter the date the supervision activity ended.
5. Select the user who was supervised.
6. Add any additional notes about the supervision activity (optional).
7. Enter the name of the superviser.

## Field-by-Field Explanation

* **Category** (`category`, `select_one`, required/optional): Select the category of the supervision activity (e.g. Administrative, Financial, HR). This field helps to classify the supervision activity and ensure it is recorded in the correct departmental context.
* **Description** (`description`, `text`, required/optional): Enter a brief description of the supervision activity. This field should provide a clear and concise summary of what occurred.
* **Date Start** (`date_start`, `date`, required/optional): Enter the date the supervision activity started. Use the format MM/DD/YYYY.
* **Date End** (`date_end`, `date`, required/optional): Enter the date the supervision activity ended. Use the format MM/DD/YYYY.
* **User** (`user`, `select_one`, required): Select the user who was supervised. This field is mandatory and should be filled out to ensure accurate tracking of supervision activities.
* **Notes** (`notes`, `note`, required/optional): Add any additional notes about the supervision activity. This field is optional and can be used to provide further context or details about the supervision activity.
* **Superviser name** (`superviser_name`, `text`, required/optional): Enter the name of the superviser who oversaw the supervision activity. This field is optional but recommended for accurate tracking of supervisers.

## Tips

* Ensure that you have a clear understanding of the supervision activity before completing this form.
* Use the correct category for the supervision activity to ensure it is accurately recorded.
* Enter the correct date for the supervision activity start and end dates.
* Select the correct user who was supervised.
* Use the notes field to provide further context or details about the supervision activity if necessary.
