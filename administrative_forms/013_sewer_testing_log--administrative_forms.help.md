# Sewer Testing Log - Help Guide
## Purpose
The Sewer Testing Log form is designed to record and track information about sewer testing activities, including testing locations, dates, and results.

## How To Complete This Form
To complete this form, follow these steps:

* Select a testing location from your area of responsibility and enter it in the `Site ID` field.
* Enter your unique `Tester ID` in the designated field.
* Choose the date of the test from the calendar input field `Date Tested`.
* Briefly describe the outcome of the test in the `Test Result` field.
* Add any additional comments or notes about the test in the `Testing Log` field.

## Field-by-Field Explanation
* **Testing Log (note)**: A text field for recording any relevant notes or comments about the test.
* **Site ID (text)**: A unique identifier for the testing location, such as a code or a name.
* **Date Tested (date)**: The date on which the test was conducted.
* **Tester ID (text)**: A unique identifier for the person conducting the test, typically an employee or contractor number.
* **Test Location (text)**: The location where the test was conducted, such as a street address or a landmark.
* **Test Result (text)**: A brief description of the test outcome, such as "Clear" or "Failed".
