# Theater Incident Form - Help Guide
## Purpose
The purpose of this form is to gather information about incidents that occur within a theater setting, such as accidents, injuries, or near misses.

## How To Complete This Form

1. Review the incident type options and select all that apply to the incident you're reporting.
2. Enter a brief description of the incident in the text box.
3. Choose the location where the incident occurred from the dropdown list.
4. Enter the date of the incident using the date format (e.g., MM/DD/YYYY).
5. Select the time of the incident using the time format (e.g., 12:00 PM).
6. Enter a detailed description of what happened in the incident description text box.
7. Select the incident status as 'Resolved' or 'Unresolved'.
8. Enter the name of the person who reported the incident.
9. Choose whether the incident was severe or not.
10. Select the category of the incident from the dropdown list.
11. Enter any follow-up information or comments in the text box.

## Field-by-Field Explanation
* **Incident Type** (`incident_type`): Select all that apply from the list of options to describe the type of incident (e.g., accident, injury, near miss).
* **Description** (`description`): Enter a brief description of what happened.
* **Location** (`location`): Choose the location where the incident occurred from the list of options.
* **Incident Date** (`incident_date`): Enter the date of the incident using the MM/DD/YYYY format.
* **Time** (`time`): Enter the time of the incident using the 12:00 PM format.
* **Incident Description** (`incident_description`): Enter a detailed description of what happened.
* **Incident Status** (`incident_status`): Select 'Resolved' if the incident has been resolved or 'Unresolved' if it's still ongoing.
* **Incident Reporter** (`incident_reporter`): Enter the name of the person who reported the incident.
* **Incident Severity** (`incident_severity`): Choose whether the incident was severe or not.
* **Incident Category** (`incident_category`): Select all that apply from the list of categories to describe the type of incident.
* **Follow Up** (`follow_up`): Enter any follow-up information or comments about the incident.
