# Shopping Mall Emergency Exit Inspection Form - Help Guide
## Purpose
The purpose of this form is to ensure that all emergency exit points in a shopping mall are thoroughly inspected and recorded. This form is used to document the status of emergency exits, exits, signs, alarms, and other critical safety features.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and fill out all required fields.
2. Ensure that you have inspected all emergency exits, exits, signs, alarms, and other critical safety features.
3. Record your findings and observations in the corresponding fields.

## Field-by-Field Explanation

* **Emergency Exit Inspection** (`emergency_exit_inspection_form`, text, required/optional): This is the header field for the form.
* **Emergency Exits** (`emergency_exits`, text, required/optional): List all emergency exits in the mall.
* **Exit Doors** (`exit_doors`, text, required/optional): List each exit door's details, including any issues or notes.
* **Emergency Exit Signs** (`emergency_exit_signs`, select_one, required/optional): Ensure all exit signs are clear. Select '1' to indicate that signs are clear, and '0' otherwise.
* **Fire Exits** (`fire_exits`, select_multiple, required/optional): List fire exits. Select multiple options if there are multiple fire exits.
* **Emergency Exit Emergency Exits** (`emergency_exit_emergency_exits`, select_multiple, required/optional): This field is similar to the previous one.
* **Emergency Exit Emergency Exit Signs** (`emergency_exit_emergency_exit_signs`, select_multiple, required/optional): This field is similar to the previous one.
* **Emergency Exit Fire Exits** (`emergency_exit_fire_exits`, select_multiple, required/optional): This field is similar to the previous one.
* **Emergency Exit Exit Doors** (`emergency_exit_exit_doors`, select_multiple, required/optional): This field is similar to the previous one.
* **Emergency Exit Exit Signs** (`emergency_exit_exit_signs`, select_multiple, required/optional): This field is similar to the previous one.
* **Emergency Exit Fire Exit Signs** (`emergency_exit_fire_exit_signs`, select_multiple, required/optional): This field is similar to the previous one.
* **Emergency Exit Alarms** (`emergency_exit_alarms`, select_one, required/optional): Check if alarms are functioning properly.
* **Emergency Exit Emergency Exit Doors** (`emergency_exit_emergency_exit_doors`, select_multiple, required/optional): This field is similar to the previous one.
* **Exit Doors Condition** (`emergency_exit_exit_doors_condition`, select_one, required/optional): Check the condition of exit doors.
* **Inspection Date** (`emergency_exit_inspection_date`, date, required/optional): Enter the date of the inspection.
* **Inspection Time** (`emergency_exit_inspection_time`, time, required/optional): Enter the time of the inspection.
* **Inspector Name** (`emergency_exit_inspector_name`, text, required/optional): Enter your name as the inspector.
* **Inspector Signature** (`emergency_exit_inspector_signature`, text, required/optional): Sign your name to affirm that the inspection was performed.
* **Inspection Notes** (`emergency_exit_inspection_notes`, text, required/optional): Enter any additional notes or comments about the inspection.
* **Inspection Comments** (`emergency_exit_inspection_comments`, text, required/optional): Enter any additional comments about the inspection.
* **Inspection Result** (`emergency_exit_inspection_result`, select_one, required/optional): Record the result of the inspection. Select '1' to indicate that the exits are compliant, and '0' otherwise.
* **Remarks** (`emergency_exit_remarks`, text, required/optional): Enter any additional remarks or comments about the inspection.
* **Date** (`emergency_exit_date`, date, required/optional): Enter the date of the inspection.
* **Time** (`emergency_exit_time`, time, required/optional): Enter the time of the inspection.
* **User** (`emergency_exit_user`, text, required/optional): Enter the name of the user.
* **Inspection Status** (`emergency_exit_inspection_status`, select_one, required/optional): Record the status of the inspection. Select '1' to indicate that the inspection was completed, and '2' or '3' otherwise.
* **Completed** (`emergency_exit_completed`, select_one, required/optional): Record if the inspection was completed. Select '1' to indicate that it was completed, and '0' otherwise.
* **Status** (`emergency_exit_status`, select_multiple, required/optional): Record the status of the inspection. Select multiple options if there are multiple statuses.
* **Completed** (`emergency_exit_completed`, select_one, required/optional): This field is similar to the previous one.

Note: Fields with similar names are similar in purpose, but with different names, they are meant to be different fields.
