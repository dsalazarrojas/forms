# Lease Extension Amendment Approval Form - Help Guide
## Purpose

The Lease Extension Amendment Approval Form is used to document lease extension requests from tenants and track the approval process for these requests.

## How To Complete This Form

To complete this form, follow these steps:

*   Complete the Tenant Request section with a note summarizing the tenant's request.
*   Enter the Lease Start Date and Lease End Date as per the current lease terms.
*   Fill in the Property Address and Landlord Name as required.
*   Include your Tenant Signature in the designated text box.
*   Enter the Property Manager Name.
*   Select the Approval Status as "Approved" or "Denied".
*   If the approval status is "Denied", provide a brief reason for the denial in the Reason for Denial text box.

## Field-by-Field Explanation

*   **Tenant Request** (`tenant_request`, note, required: false): A note summarizing the tenant's request for lease extension.
*   **Lease Start Date** (`lease_start_date`, date, required: false): The start date of the current lease, as per the lease terms.
*   **Lease End Date** (`lease_end_date`, text, required: false): The end date of the current lease, as per the lease terms.
*   **Property Address** (`property_address`, text, required: false): The address of the property that is leased.
*   **Tenant Signature** (`tenant_signature`, text, required: false): A text box where the tenant can sign their name to confirm their request.
*   **Landlord Name** (`landlord_name`, text, required: false): The name of the landlord or property owner.
*   **Property Manager Name** (`property_manager_name`, text, required: false): The name of the person who is handling the lease extension request.
*   **Approval Date** (`approval_date`, date, required: false): The date on which the approval or denial was made.
*   **Approval Status** (`approval_status`, select, required: false): The status of the approval or denial, with options "Approved" and "Denied".
*   **Reason for Denial** (`reason_for_denial`, text, required: false): A text box for providing the reason for denial, if the approval status is "Denied".

## Tips

*   Please ensure that all fields are filled out completely and accurately.
*   Use clear and concise language for all text boxes.
*   If the approval status is "Denied", provide a detailed reason for the denial. 
*   The form should be saved and printed for future reference.
