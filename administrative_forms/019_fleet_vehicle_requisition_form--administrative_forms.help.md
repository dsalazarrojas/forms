# fleet_vehicle_requisition_form - Help Guide
## Purpose
This form is used to request access to a company's fleet vehicle. It is intended to capture essential information about the vehicle and the reason for the request.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the "Company Details" page with your company information.
2. On the "Driver Details" page, select the applicable vehicle type.
3. On the "Vehicle Type Details" page, select the applicable vehicle model.
4. On the "Vehicle Year" page, select the year of the vehicle.
5. On the "Vehicle Make" page, enter the vehicle make.
6. On the "Vehicle Color" page, select the vehicle color.
7. On the "Vehicle Registration" page, enter the vehicle registration number.
8. In the "Reason for Request" field, explain the reason for the vehicle request.
9. On the "Assigned Tool" page, enter the tool assigned for the vehicle request.
10. On the "Assigned User" page, enter the user assigned for the vehicle request.
11. In the "Notes" field, enter any additional comments or notes about the vehicle request.
12. On the "Vehicle Requisition Status" page, select the current status of the vehicle request.

## Field-by-Field Explanation

* **Company Details** (1): Enter your company details here.
* **vehicle_type** (2): Select the type of vehicle you need access to (e.g., "Yes" or "No").
* **Fleet Manager Details** (3): Enter the name and contact information of the fleet manager handling the request.
* **Driver Details** (4): Select the drivers who will be driving the vehicle (e.g., "Yes" or "No").
* **Vehicle Type Details** (5): Enter detailed information about the vehicle type (e.g., model, make, etc.).
* **Vehicle Model** (6): Select the vehicle model (e.g., "Yes" or "No").
* **Vehicle Year** (7): Select the year of the vehicle.
* **Vehicle Make** (8): Enter the vehicle make.
* **Vehicle Color** (9): Select the color of the vehicle.
* **Vehicle Registration** (10): Enter the vehicle registration number.
* **Reason for Request** (11): Explain the reason for the vehicle request.
* **Assigned Tool** (12): Enter the tool assigned for the vehicle request.
* **Assigned User** (13): Enter the user assigned for the vehicle request.
* **Notes** (14): Enter any additional comments or notes about the vehicle request.
* **Vehicle Requisition Status** (15): Select the current status of the vehicle request (e.g., "Active" or "Inactive").
