This form is a Media Coverage Records Release Form, used to document and manage media coverage related records. It is designed to collect information from individuals or organizations that have been featured in media coverage, such as interviews, articles, or videos. The form is used to gather consent for reproduction, distribution, and archiving of the media content, as well as any other specific uses of the recorded media.

The form is typically used by media professionals, such as journalists, public relations specialists, or marketing teams, to ensure they have the necessary permissions and documentation for using and sharing media content.

To use this form, follow these steps:

# Media Coverage Records Release Form - Help Guide
## Purpose
This form is used to document and manage media coverage related records.

## How To Complete This Form

*   Please select the appropriate fields based on the media coverage you are dealing with.
*   Fill out the form completely and accurately.
*   Ensure you have permission to complete this form on behalf of the individual or organization being featured.
*   Review the form for accuracy before submitting.

## Field-by-Field Explanation

*   **Organization** (`Organization`, text, required): The name of the organization being featured in the media coverage.
    This field is a required text field where you will enter the name of the organization being covered.
*   **Contact Email** (`contact_email`, email, required): The contact email of the person responsible for the organization.
    This field is a required email field where you will enter the contact email of the person responsible for the organization.
*   **Name** (`name`, text, required): The name of the person responsible for the organization.
    This field is a required text field where you will enter the name of the person responsible for the organization.
*   **Media Type** (`media_type`, text, required): The type of media being covered, such as article, interview, video, or social media.
    This field is a required text field where you will enter the type of media being covered.
*   **Date of Publication** (`date_of_publication`, date, required): The date the media was published or broadcast.
    This field is a required date field where you will enter the date the media was published or broadcast.
*   **Time of Publication** (`time_of_publication`, time, required): The time the media was published or broadcast.
    This field is a required time field where you will enter the time the media was published or broadcast.
*   **Consent for Reproduction** (`consent_for_reproduction`, text, required): The permission for reproduction of the media content.
    This field is a required text field where you will enter the permission for reproduction of the media content.
*   **Consent for Distribution** (`consent_for_distribution`, text, required): The permission for distribution of the media content.
    This field is a required text field where you will enter the permission for distribution of the media content.
*   **Consent for Archiving** (`consent_for_archiving`, text, required): The permission for archiving of the media content.
    This field is a required text field where you will enter the permission for archiving of the media content.
*   **Consent for Other Uses** (`consent_for_other`, text, required): The permission for other uses of the media content.
    This field is a required text field where you will enter the permission for other uses of the media content.
*   **Consent for Other Uses Description** (`consent_for_other_description`, text, optional): A description of the other uses of the media content.
    This field is an optional text field where you will enter a description of other uses of the media content.
*   **Notes** (`notes`, note, required): Any additional notes or comments regarding the media coverage.
    This field is a required note field where you will enter any additional notes or comments regarding the media coverage.
*   **Assigned To** (`assigned_to`, text, required): The name of the person assigned to manage the media coverage records.
    This field is a required text field where you will enter the name of the person assigned to manage the media coverage records.
