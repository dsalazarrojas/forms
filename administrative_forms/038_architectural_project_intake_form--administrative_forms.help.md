# Architectural Project Intake Form - Help Guide
## Purpose
This form is designed to collect information from clients or developers about their architectural projects. It aims to gather essential details about the project, including client information, project specifics, and project goals. The collected data will be used to provide guidance and support throughout the project's development process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the client's name, email, and phone number in the "Client Information" section.
2. Choose the preferred contact method in the "Preferred Contact Method" dropdown.
3. Provide a brief description of the project and its name in the "Project Details" section.
4. Select the project type and location in the "Project Type" and "Project Location" sections.
5. Answer the project vision and goals questions in the "Project Vision" and "Project Goals" sections.
6. Provide information about the project's size, budget, and timeline in the "Project Parameters" section.
7. If applicable, describe any special requirements or constraints in the "Special Requirements" section.
8. Finally, review and submit the form.

## Field-by-Field Explanation

* **Client or Developer Name** (`client_name`): This field is required and should contain the individual or company's name.
* **Email Address** (`client_email`): This field is required and should be a valid email address.
* **Phone Number** (`client_phone`): This field is required and should be a phone number.
* **Company or Organization** (`client_organization`): This field is optional and can be left blank if not applicable.
* **Preferred Contact Method** (`contact_preference`): Choose how you would like to be contacted (Phone, Email, Text, or In-person).
* **Project Name or Description** (`project_name`): This field is required and should contain a brief description of the project.
* **Project Type** (`project_type`): Select the type of project (New Construction, Addition, Renovation, Adaptive Reuse, Interior Redesign, or Mixed-use).
* **Project Location** (`project_location`): This field is required and should contain the address or area of the project.
* **Do you own or control the land?** (`land_owned`): Check "True" if you own or control the land, "False" otherwise. Note: "In process" can be selected if land ownership is pending.
* **Project Vision** (`project_vision`): This field is optional and can be left blank if not applicable.
* **What are your primary project goals?** (`project_goals`): This field is required and should describe the project's objectives.
* **Who will use this space?** (`target_users`): This field is optional and can be left blank if not applicable.
* **Design Style or Preferences** (`design_preferences`): This field is optional and can be left blank if not applicable.
* **Site Area (Square Feet)** (`site_area_sf`): This field is optional and should contain the total lot size.
* **Building Area (Square Feet)** (`building_area_sf`): This field is optional and should contain the total built space.
* **Estimated Budget** (`estimated_budget`): This field is optional and should contain the total project cost.
* **Desired Timeline** (`timeline`): This field is optional and should contain the desired start date.
* **Any Special Requirements or Constraints** (`special_requirements`): This field is optional and can be left blank if not applicable.
* **Sustainability or Green Building Goals** (`sustainability_goals`): This field is optional and can be left blank if not applicable.

Note: This form has been designed to gather the necessary information to provide accurate and efficient support throughout the project's development process. Please complete the form thoroughly and accurately to ensure the best possible outcome for your project.
