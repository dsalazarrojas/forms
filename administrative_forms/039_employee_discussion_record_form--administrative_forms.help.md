# Employee Discussion Record Form - Help Guide
## Purpose
The Employee Discussion Record Form is used to document discussions between employees, including location, date, time, and details of the discussion. This form helps administrators to keep a record of discussions, which can be useful for performance evaluations, employee development, and other administrative purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Company Discussion" field to describe the main topic or subject of the discussion.
2. Enter the "Discussion Date" field with the date of the discussion.
3. Enter the "Discussion Time" field with the time of the discussion.
4. Enter the "Location" field with the location where the discussion took place.
5. Enter the "Discussion Topic" field with a brief description of the discussion topic.
6. Enter the "Employee" field with the employee's name or ID.
7. Enter the "Manager" field with the manager's name or ID.
8. Enter the "Discussion Details" field with a detailed description of the discussion.

## Field-by-Field Explanation
* **Company Discussion** (`employee_discussion_record_form`, note, not required): A brief description of the main topic or subject of the discussion.
* **Discussion Date** (`discussion_date`, date, not required): The date of the discussion.
* **Discussion Time** (`discussion_time`, time, not required): The time of the discussion.
* **Location** (`discussion_location`, text, not required): The location where the discussion took place.
* **Discussion Topic** (`discussion_topic`, text, not required): A brief description of the discussion topic.
* **Employee** (`employee_id`, text, not required): The employee's name or ID.
* **Manager** (`manager_id`, text, not required): The manager's name or ID.
* **Discussion Details** (`discussion_details`, text, not required): A detailed description of the discussion.

## Tips
* Only one discussion record per employee should be created per day.
* Please make sure to enter accurate and complete information to ensure the record is useful for future reference.
* If you have any questions or need assistance, contact us at form@gic.mx.
