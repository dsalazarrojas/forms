# Landlord Records Release Form - Help Guide
## Purpose
This form is used by tenants to release their landlord records to authorized parties.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out all required fields completely.
2. Select the correct record types to be released.
3. Provide a valid authorization date.
4. If necessary, fill out the 'Contact Information' section to provide information for the authorized party.

## Field-by-Field Explanation

* **Tenant Name** (`tenant_name`, text, **required**): Enter the name of the tenant who is releasing their landlord records.
* **Release Authorization** (`release_authorization`, select_one, **required**): Select one of the options to authorize the release of records.
* **Record Types** (`record_types`, select_multiple, **required**): Select multiple record types to be released.
* **Authorization Date** (`authorization_date`, date, **required**): Enter a valid date for the authorization.
* **Release Until** (`release_until`, time, **optional**): Enter a date and time to release records until. Leave this field blank if not applicable.
* **Reason for Release** (`reason_for_release`, text, **optional**): Enter a reason for the release.
* **Contact Name** (`contact_name`, text, **optional**): Enter the contact name of the authorized party.
* **Contact Email** (`contact_email`, email, **optional**): Enter the contact email of the authorized party.
* **Contact Phone** (`contact_phone`, text, **optional**): Enter the contact phone number of the authorized party.
* **Contact Address** (`contact_address`, text, **optional**): Enter the contact address of the authorized party.
