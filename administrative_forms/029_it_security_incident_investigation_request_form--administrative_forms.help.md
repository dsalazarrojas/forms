# it_security_incident_investigation_request_form - Help Guide

## Purpose
This form is used to report and track IT security incidents that have occurred within the organization.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the correct incident type from the list provided.
2. Provide a brief description of the incident.
3. Enter the date and time of the incident in the correct format (YYYY-MM-DD and HH:MM AM/PM).
4. Specify the location of the incident.
5. Provide as much detail as possible about the incident.
6. Select the status of the incident (if required).
7. Select the priority and severity of the incident.
8. Provide any additional details or comments if needed.

## Field-by-Field Explanation

* **Incident Description** (1): Provide a brief description of the incident.
* **Incident Date** (2): Enter the date of the incident in YYYY-MM-DD format.
* **Incident Time** (3): Enter the time of the incident in HH:MM AM/PM format.
* **Incident Details** (4): Provide as much detail as possible about the incident.
* **Incident Location** (5): Specify the location of the incident.
* **Reporting Person** (6): Enter the name of the person reporting the incident.
* **Department** (7): Select the department where the incident occurred.
* **Incident Type** (8): Select the type of incident from the list provided.
* **Incident Status** (9): Select the status of the incident (if required).
* **Incident Priority** (10): Select the priority of the incident.
* **Incident Severity** (11): Select the severity of the incident.
* **Incident Asset** (12): Provide the asset(s) involved in the incident.
* **Incident Asset ID** (13): Enter the ID of the asset(s) involved in the incident.
* **Description** (14): Provide a brief description of the incident (optional).
* **Location** (15): Specify the location of the incident (optional).
* **Incident Type 2** (16): Select the type of incident from the list provided (if additional information is required).
* **Incident Status 2** (17): Select the status of the incident (if required).
* **Incident Priority 2** (18): Select the priority of the incident.
* **Incident Severity 2** (19): Select the severity of the incident.
* **Incident Date 2** (20): Enter the date of the incident in YYYY-MM-DD format.
* **Incident Time 2** (21): Enter the time of the incident in HH:MM AM/PM format.
* **Incident Details 2** (22): Provide as much detail as possible about the incident.
* **Location 3** (23): Specify the location of the incident.
* **Incident Status 3** (24): Select the status of the incident (if required).
* **Incident Type 3** (25): Select the type of incident from the list provided.

Note: Some fields are marked as "optional" and will not be required for all incidents. Please ensure you only fill out the required fields for the specific incident you are reporting.
