# Vehicle Issues Report Form - Help Guide
## Purpose

The Vehicle Issues Report Form is used to collect and document information about vehicle issues reported by users. It helps in tracking and resolving these issues effectively.

## How To Complete This Form

To complete this form, follow these steps:

1.  Select the "Issue Location" from the given options to specify where the issue is located (inside or outside the vehicle).
2.  Enter a detailed description of the issue in the "Issue Description" field.
3.  Choose the "Vehicle Model" of the affected vehicle.
4.  Select the "Issue Date" of when the issue was reported.
5.  Select the "Issue Time" of when the issue was reported.
6.  Specify if the issue occurred in the morning or afternoon using the "AM/PM" field.
7.  Choose the "Issue Priority" from the given options to specify the urgency of the issue.
8.  Select the "Issue Status" from the given options to specify the current status of the issue.
9.  Enter a detailed "Issue Resolution" if the issue has been resolved.
10. Enter your name and contact information in the "Issue Reporter" and "Issue Reporter Email" fields.
11. Select the "Issue Category" and "Issue Subcategory" from the given options.
12. Attach any relevant images, videos, or audio files using the "Issue Image", "Issue Video", and "Issue Audio" fields.
13. Enter any additional "Issue Notes" about the issue.
14. Select the attachments you want to include with the report using the "Attach" field.
15. Enter any "Report Comment" about the report.
16. Select the "Report Status" from the given options.
17. Enter the "Report Date" of when the report was submitted.
18. Enter your contact information in the "Issue Reporter Phone" field.

## Field-by-Field Explanation

* **Vehicle Issues Report** (Text Field): The main title of the report.
* **Issue Location** (Select Multiple): Select where the issue occurred, inside or outside the vehicle.
  * Inside the vehicle
  * Outside the vehicle
  * Other
* **Issue Description** (Text Field): A detailed description of the issue.
* **Vehicle Model** (Select One): The model of the vehicle affected by the issue.
* **Report Date** (Date Field): The date when the report was submitted.
* **Issue Date** (Date Field): The date when the issue occurred.
* **Issue Time** (Time Field): The time when the issue occurred.
* **AM/PM** (Select One): Specify if the issue occurred in the morning or afternoon.
* **AM** 
* **PM**
* **Issue Priority** (Select One): Specify the urgency of the issue.
* **High**
* **Low**
* **Issue Status** (Select One): Specify the current status of the issue.
* **Open**
* **Resolved**
* **Issue Resolution** (Text Field): A detailed description of how the issue was resolved.
* **Issue Reporter** (Text Field): The name of the person reporting the issue.
* **Issue Year** (Number Field): The year of the vehicle affected by the issue.
* **Vehicle Make** (Text Field): The make of the vehicle affected by the issue.
* **Vehicle Model Year** (Text Field): The model year of the vehicle affected by the issue.
* **Issue Category** (Select One): Select the category of the issue.
* **Category 1**
* **Category 2**
* **Issue Subcategory** (Select One): Select the subcategory of the issue.
* **Subcategory 1**
* **Subcategory 2**
* **Issue Image** (Note Field): Attach any relevant images of the issue.
* **Issue Video** (Note Field): Attach any relevant videos of the issue.
* **Issue Audio** (Note Field): Attach any relevant audio files of the issue.
* **Issue Notes** (Text Field): Additional notes about the issue.
* **Attach** (Select Multiple): Attach any relevant files to the report.
* **Option 1**
* **Option 2**
* **Report Comment** (Text Field): A comment about the report.
* **Report Status** (Select One): Specify the status of the report.
* **Status 1**
* **Status 2**
* **Report Date** (Date Field): The date when the report was submitted.
* **Issue Reporter** (Text Field): The name of the person reporting the issue.
* **Issue Reporter Email** (Email Field): The email address of the person reporting the issue.
* **Issue Reporter Phone** (Text Field): The phone number of the person reporting the issue.

## Tips

* Please make sure to fill out all required fields completely and accurately.
* If you are not sure about the correct field to select, refer to the field label for guidance.
* If you have any questions or need help, contact the support team.
* Attach relevant files to support your report.
* Make sure to keep the report up-to-date and accurate.
