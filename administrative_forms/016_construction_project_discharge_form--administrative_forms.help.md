# Construction Project Discharge Form - Help Guide
## Purpose
This form is used to document the completion and closure of a construction project. It ensures that all necessary project closure tasks have been completed and that the project is officially discharged.

## How To Complete This Form
1. Ensure that the project is actually complete and that all required documents and inspections have been finalized.
2. Review the project details to confirm that there are no outstanding issues or items.
3. Complete each field accurately and thoroughly.
4. Sign and date the form to confirm that it is submitted on behalf of the client or company.

## Field-by-Field Explanation
- **Project name (2)**: Enter the full title of the project being discharged.
- **Completion date (3)**: Enter the date on which the project is officially complete.
- **Final inspection passed (4)**: Confirm that the final inspection has been completed and passed.
	+ Select 'True' if the inspection was completed and passed.
	+ Select 'False' if the inspection was not completed or failed.
- **Outstanding items (5)**: List any outstanding defects, punch list items, or issues that have not been addressed.
- **Client sign off name (6)**: Enter the name of the client representative approving the discharge.
- **Final documents submitted (7)**: Confirm that handover documents were provided to the client.
	+ Select 'True' if documents were provided.
	+ Select 'False' if documents were not provided or not yet submitted.

## Tips
- Always ensure that the form is completed accurately and thoroughly to avoid errors or delays.
- Check with the project manager or supervisor if you're unsure about any project details.
- Save a copy of the completed form for future reference.
