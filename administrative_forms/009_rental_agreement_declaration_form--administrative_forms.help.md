# rental_agreement_declaration_form - Help Guide
## Purpose
The rental agreement declaration form is a template used for internal administrative purposes to collect information about rental properties, tenants, and agreement terms.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the rental property's details on page 1, including the name and description of the property.
2. Select the rent frequency on page 2, which can be Weekly, Monthly, or Annually.
3. Enter the rent amount on page 2.
4. Enter the start date of the rent on page 3.
5. Provide the tenant's contact information, including their name, phone number, and any additional details on page 4.
6. Select the payment method on page 5, which can be Cash, Bank Transfer, or Cheque.
7. Review and confirm the agreement terms on page 6.
8. Enter the lease duration on page 6.
9. Enter the lease start and end dates on page 6.
10. Select the rent status on page 6, which can be Active or Passive.
11. Review and submit the form.

## Field-by-Field Explanation

* **rental_agreement_details** (Text, Optional): Enter a brief description of the rental property.
* **rent_frequency** (Select One, Optional): Select the frequency of the rent, which can be Weekly, Monthly, or Annually.
* **rent_amount** (Number, Optional): Enter the amount of rent to be paid.
* **rent_start_date** (Date, Optional): Enter the start date of the rent.
* **tenant_details** (Text, Optional): Enter any additional details about the tenant.
* **tenant_name** (Text, Optional): Enter the name of the tenant.
* **tenant_phone** (Text, Optional): Enter the phone number of the tenant.
* **landlord_details** (Text, Optional): Enter any additional details about the landlord.
* **landlord_name** (Text, Optional): Enter the name of the landlord.
* **landlord_phone** (Text, Optional): Enter the phone number of the landlord.
* **agreement_terms** (Note, Optional): Review and confirm the agreement terms.
* **rent_period** (Select Multiple, Optional): Select the duration of the rent period, which can be 30, 60, or 90 days.
* **rent_frequency_period** (Select One, Optional): Select the rent frequency period, which can be Month or Months.
* **lease_date** (Date, Optional): Enter the start date of the lease.
* **lease_end_date** (Date, Optional): Enter the end date of the lease.
* **rent_status** (Select One, Optional): Select the status of the rent, which can be Active or Passive.
* **payment_method** (Select One, Optional): Select the payment method, which can be Cash, Bank Transfer, or Cheque.

## Tips

* Make sure to review the agreement terms carefully before submitting the form.
* Ensure that the tenant's contact information is accurate and up-to-date.
* If you are unsure about any field, please seek guidance from the relevant authorities.
* The form can be saved and edited as a template for future use.
