# public-works-program-release-form - Help Guide
## Purpose
The Public Works Program Release Form is used to obtain releases from participants in a public works program, verifying their understanding of project risks and terms and conditions.

## How To Complete This Form
1. Fill in your name as the participant.
2. Enter the project name in which you are involved.
3. Select the contract date when the release applies.
4. Choose the correct option regarding the risks associated with the project (you understand, you have read and understood, you have read, understand, and acknowledge).
5. Confirm that you have read and understood the release terms and conditions.
6. Sign your name as the participant.

## Field-by-Field Explanation
- **Participant Name** (`participant_name`, text, required): Enter your name as the participant.
- **Project Name** (`project_name`, text, required): Enter the name of the project in which you are involved.
- **Contract Date** (`contract_date`, date, required): Select the date when the release applies.
- **Risks Acknowledgment** (`risk_acknowledgment`, select_multiple, required): Choose the correct option regarding the risks associated with the project:
  - I understand the risks associated with this project
  - I have read and understood the risks associated with this project
  - I have read, understand, and acknowledge the risks associated with this project
- **Release Terms and Conditions** (`release_terms_and_conditions`, select_one, required): Confirm that you have read and understood the release terms and conditions:
  - I have read and understood the release terms and conditions
  - I have not read the release terms and conditions
- **Participant Signature** (`release_form_signature`, text, required): Sign your name as the participant.

## Tips
- Ensure you have read and understood the project details and risks before completing this form.
- Double-check the provided information for accuracy.
- Do not complete this form if you have already submitted a similar form or agreement.
- If you are unsure about any of the questions, contact the form administrator at form@gic.mx.
