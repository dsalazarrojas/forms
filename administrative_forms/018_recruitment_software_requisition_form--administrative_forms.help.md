# Recruitment Software Requisition Form - Help Guide
## Purpose
The purpose of the Recruitment Software Requisition Form is to collect information about the software or system you are requesting from the IT department. This form ensures that all relevant details about the software are captured, making it easier for the IT department to process your request and provide the necessary support.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with the necessary information.
2. Ensure that you have checked the boxes for the software type and benefits.
3. Enter the software name, description, and version.
4. If applicable, select the software type and enter the software cost.
5. List the software benefits.
6. Enter the name of the person requesting the software.
7. Enter the name of the person or team requesting the software.
8. Enter the department that will be using the software.
9. Enter the location where the software will be used.
10. Enter the date and time you are requesting the software.

## Field-by-Field Explanation
- **software name** (`software_name`, text, required): Enter the name of the software or system you are requesting.
- **software description** (`software_description`, text, required): Enter a brief description of the software or system you are requesting.
- **software version** (`software_version`, text, required): Enter the version of the software or system you are requesting.
- **software type** (`software_type`, select_one, required): Select yes or no to indicate if this is a new or existing software request.
- **software cost** (`software_cost`, number, optional): Enter the cost of the software or system you are requesting (if applicable).
- **software benefits** (`software_benefits`, select_multiple, required): Select all the benefits that apply to the software or system you are requesting (e.g., improve productivity, reduce costs, increase efficiency).
- **requested by** (`requested_by`, text, optional): Enter the name of the person requesting the software.
- **requisitioned by** (`requisitioned_by`, text, optional): Enter the name of the person or team requesting the software.
- **department** (`department`, text, required): Enter the department that will be using the software.
- **location** (`location`, text, optional): Enter the location where the software will be used.
- **date requested** (`date_requested`, date, optional): Enter the date and time you are requesting the software.
- **time requested** (`time_requested`, time, optional): Enter the time you are requesting the software.

## Tips
* Ensure that all fields are filled in with accurate and complete information to avoid delays in processing your request.
* If you are unsure about any of the fields, please ask your IT department for assistance.
