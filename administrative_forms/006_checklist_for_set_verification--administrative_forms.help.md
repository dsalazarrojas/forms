# Checklist For Set Verification - Help Guide

## Purpose
The "Checklist For Set Verification" form is designed to ensure that all aspects of a production or event setup are properly verified before it begins. This form helps the verifier to systematically check and confirm that all necessary elements are in place, including event details, technical requirements, and safety measures.

## How To Complete This Form

1. Fill out the form carefully, ensuring all fields are completed accurately.
2. Enter the Event Name and Venue Name as they appear in your records.
3. Set the Verification Date as the date you are conducting the verification.
4. Enter the name of the person conducting the verification.
5. Select the correct Production Type (e.g., Theater Production, Concert, Corporate Event, etc.).
6. For each technical check (Stage Setup Complete, Lighting, Sound System, etc.), select the corresponding status to indicate whether it is complete, partially complete, not started, or in issue.
7. In the Props Inventory field, select the status of your inventory, and in the Furniture Placement field, select whether furniture is correctly placed or needs adjustment.
8. In the Special Effects field, indicate whether the systems are ready and tested, ready but not tested, not ready, or not applicable.
9. Check off all safety measures in place and accessible, including emergency exits clear and marked.
10. Ensure adequate power is available and distributed, and that cables are properly managed and secured.
11. In the Dressing Rooms Ready field, select whether dressing rooms are prepared or not.
12. Confirm that all signage is properly displayed.
13. In the Issues Identified field, list any issues that need attention.
14. If there are issues, provide a brief description of the corrective actions needed in the Corrective Actions field.
15. Select the Final Approval Status, indicating whether the set is approved for the event or not.
16. Finally, confirm that the verification is accurate by selecting "Yes, I confirm" in the Verifier Confirmation field.

## Field-by-Field Explanation

* **Event Name**: Enter the name of the event or production being verified. Ensure it is accurate and matches your records.
* **Venue Name**: Enter the location where the event will take place.
* **Verification Date**: Set the date of the verification, when you are conducting the check.
* **Verifier Name**: Enter the name of the person conducting the verification.
* **Production Type**: Select the type of production or event (e.g., Theater Production, Concert, Corporate Event, etc.).
* **Stage Setup Complete**: Check if the stage has been properly set up.
* **Lighting Check**: Verify if all lighting systems are functional.
* **Sound System Check**: Check if the sound system is working properly.
* **Backdrop and Scenery**: Check if backdrops and scenery are in place.
* **Props Inventory**: Check if all props are accounted for.
* **Furniture Placement**: Check if furniture is correctly positioned.
* **Special Effects**: Check if special effects systems are ready and tested.
* **Safety Equipment**: Check if safety equipment is in place and accessible.
* **Emergency Exits**: Check if emergency exits are clear and marked.
* **Power Supply**: Ensure adequate power is available and distributed.
* **Cable Management**: Check if cables are properly managed and secured.
* **Dressing Rooms Ready**: Check if dressing rooms are prepared.
* **Signage and Display**: Check if all signage is properly displayed.
* **Issues Identified**: List any issues that need attention.
* **Corrective Actions**: Provide a brief description of the corrective actions needed.
* **Final Approval Status**: Select whether the set is approved for the event or not.
* **Verifier Confirmation**: Confirm that the verification is accurate.
