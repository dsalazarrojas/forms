# Asset Inventory Verification Form - Help Guide
## Purpose
This form is used to verify the inventory of assets within the organization.

## How To Complete This Form

1. Select the asset for which you are completing this form.
2. Fill out the required fields for the asset:
   * Date of verification
   * Verifier name
   * Verifier ID
   * Location verified
   * Department
   * Type of verification
   * Asset ID
   * Asset description
   * Asset category
   * Recorded quantity
   * Actual quantity
   * Variance
   * Was asset found
   * Actual location
   * Condition verified
   * Does serial number match
   * Is asset tag intact
   * Custodian confirmed
   * Are there discrepancies
   * Discrepancy description
   * Number of photos taken
   * Is action required
   * Action description
   * Priority level
   * Supervisor review required
   * Verification status
   * Verifier signature
   * Supervisor signature

## Field-by-Field Explanation

* **Verification Date**: Select the date of the verification process.
* **Verifier Name**: Enter the name of the person completing this form.
* **Verifier ID**: Enter your employee ID.
* **Location Verified**: Enter the location where you verified the asset.
* **Department**: Enter the department that owns the asset.
* **Verification Type**: Select the type of verification being performed:
  + Full Inventory Count
  + Spot Check
  + Cycle Count
  + Annual Audit
  + Random Verification
  + Transfer Verification
* **Asset ID**: Enter the asset tag number.
* **Asset Description**: Briefly describe what the asset is.
* **Asset Category**: Select the type of asset:
  + IT Equipment
  + Office Furniture
  + Vehicles
  + Machinery
  + Tools
  + Electronics
  + Other
* **Recorded Quantity**: Enter the quantity of the asset as shown in the system.
* **Actual Quantity**: Enter the quantity of the asset that you counted.
* **Variance**: Calculate the difference between the recorded and actual quantities.
* **Was Asset Found**: Select the status of the asset:
  + Yes - In Expected Location
  + Yes - Different Location
  + No - Missing
  + No - Disposed
  + No - Transferred
* **Actual Location**: Enter the location where you found the asset.
* **Condition Verified**: Select the current condition of the asset:
  + Excellent
  + Good
  + Fair
  + Poor
  + Damaged
  + Not Accessible
* **Does Serial Number Match**: Select whether the serial number matches:
  + Yes
  + No
  + Not Applicable
* **Is Asset Tag Intact**: Select whether the asset tag is in good condition:
  + Yes - Clear and Readable
  + Yes - Damaged but Readable
  + No - Missing
  + No - Illegible
* **Custodian Confirmed**: If applicable, enter the name of the person who owns the asset.
* **Are There Discrepancies**: Select whether there are any issues with the asset:
  + Yes
  + No
* **Discrepancy Description**: If there are discrepancies, describe them.
* **Number of Photos Taken**: Enter the number of photos taken during the verification process.
* **Is Action Required**: Select whether further action is needed:
  + Yes - Update Records
  + Yes - Locate Asset
  + Yes - Repair Needed
  + Yes - Replace Tag
  + No
* **Action Description**: If action is required, describe what needs to be done.
* **Priority Level**: Select the level of priority:
  + Low
  + Medium
  + High
  + Critical
* **Supervisor Review Required**: Select whether the supervisor needs to review this:
  + Yes
  + No
* **Verification Status**: Select the final status:
  + Verified
  + Verified with Notes
  + Discrepancy Found
  + Pending Resolution
* **Verifier Signature**: Sign your name to confirm that you verified the asset.
* **Supervisor Signature**: Sign the supervisor's name if required.
* **Additional Tips:**
  + Make sure to fill out all required fields accurately.
  + If you're unsure about any field, consult with your supervisor or asset manager.
  + Take clear photos of the asset for documentation purposes.
  + Update the records according to the results of the verification process.
