# Project Management Board - Help Guide
## Purpose
The Project Management Board form is a tool for team members to view and manage project tasks. It allows them to track progress, assign tasks, and categorize them according to different labels.

## How To Complete This Form
1. Navigate to the Project Management Board page.
2. If the form is empty, click the "Add New Task" button to create a new task.
3. Fill in the task information:
	* Enter the Task ID (a unique identifier for the task).
	* Enter the Task Title (a brief description of the task).
	* Enter the Task Description (a more detailed description of the task).
	* Select the Start Date (when the task is scheduled to begin).
	* Select the Due Date (when the task is scheduled to be completed).
	* Enter the Progress (a time estimate for the task).
	* Select the Assignee (the team member responsible for the task).
	* Select the Status (In Progress, Completed, or Delayed).
	* Select the Priority (if the task is high, medium, or low priority).
	* Select the Category (if the task belongs to a specific category).
4. Choose the Labels (relevant labels for the task).

## Field-by-Field Explanation
* **Project Management Board**: This is the title of the form, displaying the name of the project.
* **Task ID** (`task_id`, number, optional): A unique identifier for the task.
* **Task Title** (`title`, text, optional): A brief description of the task.
* **Task Description** (`description`, text, optional): A more detailed description of the task.
* **Start Date** (`start_date`, date, optional): The date when the task is scheduled to begin.
* **Due Date** (`due_date`, date, optional): The date when the task is scheduled to be completed.
* **Progress** (`progress`, time, optional): A time estimate for the task.
* **Assignee** (`assignee`, select_one, optional): The team member responsible for the task.
* **Status** (`status`, select_one, optional): The task status (In Progress, Completed, or Delayed).
* **Priority** (`priority`, select_one, optional): The task priority (High, Medium, or Low).
* **Category** (`category`, select_one, optional): The category that the task belongs to.
* **Labels** (`labels`, select_multiple, optional): Relevant labels for the task.

## Tips
* Make sure to enter accurate and up-to-date information to ensure efficient task management.
* Use the "Add New Task" button to create new tasks.
* Use the "Assignee" field to assign tasks to team members.
* Use the "Status" field to track task progress.
* Use the "Priority" field to prioritize tasks.
* Use the "Category" field to categorize tasks.
* Use the "Labels" field to add relevant labels to tasks.
