# Important Dates Reference Form - Help Guide
## Purpose
This form is used to record and reference important dates and events.

## How To Complete This Form
To fill out this form, please follow these steps:

1. Select the type of event or date being recorded from the "Event type" field.
2. In the "Dates and events" field, list all the dates and events that need to be recorded.
3. Fill out the "Date 1" and "Date 2" fields with specific dates in the format of MM/DD/YYYY.
4. Fill out the "Time 1" and "Time 2" fields with the corresponding time in the 24-hour format (HH:MM).
5. In the "Note" field, provide a brief description or note about the date or event.
6. If necessary, fill out the "Email" and "Phone" fields with contact information.
7. Review your entries for accuracy and completeness before submitting the form.

## Field-by-Field Explanation
* **Important Dates Reference Form (Text)**: This is the main title of the form.
* **Event type (Select One)**: *Select the type of event or date being recorded, such as Birthday, Anniversary, Holiday, or Other*.
	+ Birthday: A birthday is a personal date for an individual.
	+ Anniversary: An anniversary is a special date for a couple or organization.
	+ Holiday: A holiday is a significant date with cultural or national importance.
	+ Other: Other types of dates or events not listed above.
* **Dates and events (Select Multiple)**: *List all the dates and events that need to be recorded, separated by commas*.
* **Date 1 (Date)**: *Fill out with a specific date in the format of MM/DD/YYYY*.
* **Date 2 (Date)**: *Fill out with a specific date in the format of MM/DD/YYYY*.
* **Time 1 (Time)**: *Fill out with the corresponding time in the 24-hour format (HH:MM)*.
* **Time 2 (Time)**: *Fill out with the corresponding time in the 24-hour format (HH:MM)*.
* **Note (Note)**: *Provide a brief description or note about the date or event*.
* **Email (Email)**: *Fill out with contact information, if applicable*.
* **Phone (Text)**: *Fill out with contact information, if applicable*.
* **Event type (Select One)**: *Select the type of event or date being recorded*.

## Tips
* Make sure to select the correct event type for each date or event.
* Be as precise as possible when filling out the dates and times.
* Use the "Note" field to provide additional information about the date or event.
* If you need to contact someone, fill out the "Email" and "Phone" fields.
