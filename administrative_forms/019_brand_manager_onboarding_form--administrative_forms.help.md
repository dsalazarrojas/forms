# Brand Manager Onboarding Form - Help Guide
## Purpose
This form is used to capture information about the new brand manager's details for onboarding purposes.

## How To Complete This Form
- **Step 1:** Begin by ensuring you have the necessary information for each field.
- **Step 2:** Fill out each field as instructed.
- **Step 3:** Review your submission for completeness and accuracy.
- **Step 4:** Submit the form to the designated HR contact for review and coordination.

## Field-by-Field Explanation

* **New hire name**: This is the full name of the new brand manager.
	+ Label: New hire name
	+ Type: text
	+ Required: true
* **Start date**: This is the date the new hire started their employment.
	+ Label: Start date
	+ Type: date
	+ Required: true
* **Department**: This is the name of the department or team the brand manager will be working with.
	+ Label: Department
	+ Type: text
	+ Required: true
* **Role summary**: This is a brief overview of the brand manager's responsibilities.
	+ Label: Role summary
	+ Type: text
	+ Required: false
* **Systems access needed**: This is a list of required systems and tools the brand manager will need access to.
	+ Label: Systems access needed
	+ Type: text
	+ Required: false
* **Training needs**: This is any initial training or certifications the brand manager may need.
	+ Label: Training needs
	+ Type: text
	+ Required: false
* **Manager name**: This is the name of the brand manager's direct supervisor.
	+ Label: Manager name
	+ Type: text
	+ Required: true
* **HR contact email**: This is the email address of the HR contact person for onboarding coordination.
	+ Label: HR contact email
	+ Type: email
	+ Required: true

## Tips
- Double-check that all required fields are filled out correctly.
- If you're unsure about any information, please consult with your HR contact or manager.
- Ensure to keep your submission up-to-date in case of any changes during onboarding.
