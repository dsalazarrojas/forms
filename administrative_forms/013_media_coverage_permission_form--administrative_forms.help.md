# media_coverage_permission_form - Help Guide
## Purpose
This form is designed to collect information and obtain permission from individuals or organizations for media coverage of an event. Media coverage can include photo, video, or audio recordings of events. 

## How To Complete This Form

1. Fill out the form with the required information.
2. Select the type of media you want to record and use (photo/video/audio).
3. Choose how you intend to use the media (e.g. social media, website, press release).
4. Provide your contact information, including contact name and phone number.
5. Confirm whether you have received permission from the event organizer or host.

## Field-by-Field Explanation

* **Media Coverage Permission**: This field is not actually a field to be filled out by the user. It is a header label for the form.
* **Organization**: This field is for entering the name of the organization seeking permission for media coverage.
* **Event Date**: Enter the date of the event for which you are seeking permission to record media.
* **Event Time**: Enter the time of the event for which you are seeking permission to record media.
* **Event Location**: Enter the location of the event for which you are seeking permission to record media.
* **Photo/Video/Audio Recording**: Select the type of media you want to record (photo, video, or audio).
* **Media Usage**: Enter how you plan to use the media recorded (e.g. social media, website, press release).
* **Consent**: Check all the boxes that apply to indicate that you have received permission from the event organizer or host for each type of media.
* **Contact Information**: Enter your name and contact information (e.g. email, phone number).
* **Contact Name**: Enter the name of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.

**Tips**

* Please fill out this form carefully and accurately to ensure you have the necessary permission for media coverage.
* Make sure to confirm with the event organizer or host that you have received permission before submitting this form.
* If you have any questions about the form, please contact the relevant authorities or support team.
* You can submit this form multiple times if you need to record and use media from different events.
