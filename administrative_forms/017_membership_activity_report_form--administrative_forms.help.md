# Membership Activity Report Form - Help Guide
## Purpose
This form is used to collect information on membership activities and engagement from users. It helps to track and document the activities performed by members, ensuring that the data is accurate and consistent.

## How To Complete This Form
To complete this form, follow these steps:

1.  Determine if you have been involved in any membership activities. If yes, proceed to the next step.
2.  Select the type of activity you have been involved in (Yes/No).
3.  If applicable, provide the date since when you became a member.
4.  Report the last activity you were involved in (if applicable).
5.  If you were involved in membership activities, indicate how many activities you were involved in.
6.  Provide a label to describe the activities you were involved in (e.g., "Membership meeting", "Event attendance").
7.  If you were engaged with other members, indicate if this engagement was positive (Yes/No).
8.  If you were engaged with other members, provide additional labels to describe the types of engagement (e.g., "Discussion", "Collaboration").
9.  If all the above steps are complete, submit your report by selecting "Yes" from the "Submit" field.

## Field-by-Field Explanation
* **Activity Type** (`activity_type`, select_one, required): Select "Yes" if you have been involved in any membership activities. If not, select "No".
* **Member Since** (`member_since`, date, optional): If you are a member, provide the date since when you became a member.
* **Last Activity** (`last_activity`, time, optional): Report the last activity you were involved in.
* **Activity Count** (`activity_count`, number, optional): If you were involved in activities, indicate how many activities you were involved in.
* **Activity Count Label** (`activity_count_label`, text, optional): Provide a label to describe the activities you were involved in (e.g., "Membership meeting", "Event attendance").
* **Member Engagement** (`member_engagement`, select_multiple, required): If you were engaged with other members, select "Yes" from this field.
* **Member Engagement Label** (`member_engagement_label`, text, optional): If you were engaged with other members, provide additional labels to describe the types of engagement (e.g., "Discussion", "Collaboration").
* **Member Engagement Label 2** (`member_engagement_label2`, text, optional): Another field to provide additional labels to describe the types of engagement.
* **Member Engagement Label 3** (`member_engagement_label3`, text, optional): Another field to provide additional labels to describe the types of engagement.
* **Submit** (`submit`, select_one, required): Select "Yes" to submit your report once all fields are complete.

## Tips
* Ensure that you have provided accurate and consistent information to maintain the quality of data.
* If you are unsure about any of the fields, please contact your supervisor or administrator for guidance.
* This form should only be filled out by users who are directly involved in membership activities.
