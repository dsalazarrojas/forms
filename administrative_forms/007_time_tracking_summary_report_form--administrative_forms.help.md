# Time Tracking Summary Report Form - Help Guide
## Purpose
This form is used to provide a summary of work hours, project start and end dates, and other relevant details for administrative purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project title.
2. Enter your employee name.
3. Enter the project start date (the date the project began).
4. Enter the project end date (the date the project ended).
5. Fill in the actual work hours spent on the project.
6. Fill in the actual work minutes spent on the project (if applicable).
7. Add any additional comments about the project.
8. If you want to be contacted or updated about the project, provide your email and phone number (if applicable).

## Field-by-Field Explanation

### Project Title
* **Project Title**: Enter the title of the project you worked on.
* **Label:** Project Title
* **Required:** No (optional but recommended)

### Employee Name
* **Employee Name**: Enter your name as it appears on your company ID or personnel document.
* **Label:** Employee Name
* **Required:** Yes (required)

### Project Start Date
* **Project Start Date**: Enter the date when the project started.
* **Label:** Project Start Date
* **Required:** Yes (required)

### Project End Date
* **Project End Date**: Enter the date when the project ended.
* **Label:** Project End Date
* **Required:** Yes (required)

### Work Hours
* **Work Hours**: Fill in the actual hours spent on the project.
* **Label:** Work Hours
* **Required:** Yes (required)

### Work Minutes
* **Work Minutes**: Fill in the actual minutes spent on the project (if applicable).
* **Label:** Work Minutes
* **Required:** No (optional)

### Comments
* **Comments**: Add any additional comments or information about the project.
* **Label:** Comments
* **Required:** No (optional)

### Email
* **Email**: Enter your email address if you want to be updated or contacted about the project.
* **Label:** Email
* **Required:** No (optional)

### Phone
* **Phone**: Enter your phone number if you want to be updated or contacted about the project.
* **Label:** Phone
* **Required:** No (optional)
