# Demerit Warning Form - Help Guide
## Purpose
This form is used to document incidents involving student warnings, such as behavior or academic warnings, where a teacher needs to report the details of the incident, actions taken, and signatures from both the student and the teacher.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of warning that occurred (e.g., "1" for a specific behavior warning, "2" for a general warning, or "3" for a warning related to a rule infraction).
2. Enter the date of the incident, using the format MM/DD/YYYY.
3. Provide a detailed description of what happened, including the specific actions taken or steps needed to resolve the issue.
4. Select the names of any individuals involved in giving or receiving the warning.
5. Choose any actions taken in response to the incident.
6. Write a witness statement, if applicable.
7. Summarize the consequences of the incident.
8. Both the student and teacher must sign and date the form to acknowledge that it was completed accurately and truthfully.

## Field-by-Field Explanation

* **Warning Type** (`Warning Type`, `select_one`): Choose the category of warning from the dropdown menu:
	+ 1: Specific behavior-related warning
	+ 2: General warning
	+ 3: Warning related to a rule infraction
* **Date of Incident** (`Date of Incident`, `date`): Enter the date of the incident in MM/DD/YYYY format (e.g., 02/20/2024).
* **Description** (`Description`, `text`): Provide a detailed description of the incident, including any relevant details or actions taken.
* **Warning Given By** (`Warning Given By`, `select_multiple`): Select the names of any individuals giving the warning:
	+ 1: First Name Last Name
	+ 2: First Name Last Name
	+ 3: First Name Last Name
* **Action Taken** (`Action Taken`, `select_multiple`): Choose any actions taken in response to the incident:
	+ 1: Specific action or step taken
	+ 2: Specific action or step taken
	+ 3: Specific action or step taken
* **Witness Statement** (`Witness Statement`, `text`): Write a witness statement, if applicable, to provide additional context or details about the incident.
* **Consequence Statement** (`Consequence Statement`, `text`): Summarize the consequences of the incident, if any.
* **Student Signature** (`Student Signature`, `text`): The student must sign and date this form to acknowledge that it is completed accurately and truthfully.
* **Teacher Signature** (`Teacher Signature`, `text`): The teacher must sign and date this form to confirm that it is completed correctly and accurately.
