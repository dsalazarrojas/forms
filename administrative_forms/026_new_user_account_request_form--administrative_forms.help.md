# New User Account Request Form - Help Guide

## Purpose
This form is used to request a new user account. It's meant for users who want to create a new account for administrative purposes. Please fill out this form only if you're certain you need an account. If you've already submitted a request for an account, please do not resubmit. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Category of the account you're requesting.
2. Enter a brief Description of the purpose of the new account.
3. Choose your Account Preferences, selecting all that apply.

## Field-by-Field Explanation

* **Category** (`Category`, select_one, required: false): Select the category for which you're requesting an account. Choose from "Administrative Forms" or "Other".
* **Description** (`description`, text, required: false): Enter a brief description of the purpose of the new account.
* **Account Preferences** (`account_preferences`, select_multiple, required: false): Select all that apply to customize your account preferences. Options include:
	+ Option 1
	+ Option 2
	+ Option 3
	+ Other (enter in the text field)
* 
## Tips
* Be sure to check your email for a confirmation link to activate your account after submission.
* If you encounter any issues while filling out this form, contact our support team.

Note: This help guide is intended to be brief and to the point, with a focus on user understanding and usability.
