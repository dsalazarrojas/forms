# home_renovation_completion_discharge_form - Help Guide
## Purpose
The home renovation completion discharge form is used to document the completion of a home renovation project, providing a centralized record of key details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your project details in the "project_details" field, including any relevant information about the project.
2. Provide information about the contractor or company involved in the project in the "contractor_info" field.
3. Enter details about the property owner's information in the "property_owner_info" field.
4. Report on the project's completion status in the "project_completion" field.
5. Select the current status of the project in the "project_status" field.
6. Enter any notes or comments about the project in the "project_notes" field.
7. If applicable, enter the certification number for the project in the "certification" field.
8. If applicable, enter the certification date for the project in the "certification_date" field.

## Field-by-Field Explanation
- **project_details** (`project_details`, text, required): Enter a brief description of the project, including the project scope, objectives, and any other relevant details.
- **contractor_info** (`contractor_info`, text, optional): Enter information about the contractor or company involved in the project, including their name, address, and contact details.
- **property_owner_info** (`property_owner_info`, text, optional): Enter information about the property owner, including their name, address, and contact details.
- **project_completion** (`project_completion`, text, optional): Report on the project's completion, including the completion date and any other relevant details.
- **project_status** (`project_status`, text, optional): Select the current status of the project from the options provided.
- **project_notes** (`project_notes`, text, optional): Enter any notes or comments about the project, including photos, videos, or other documentation.
- **certification** (`certification`, text, optional): If applicable, enter the certification number for the project.
- **certification_number** (`certification_number`, number, optional): If applicable, enter the certification number for the project.
- **certification_date** (`certification_date`, date, optional): If applicable, enter the certification date for the project.

## Tips

* Make sure to complete all required fields before submitting the form.
* Ensure that all information is accurate and up-to-date.
* If you are unsure about any field, contact your project manager or a relevant authority for guidance.
