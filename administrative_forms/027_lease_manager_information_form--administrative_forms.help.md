# lease_manager_information_form - Help Guide

## Purpose
This form is designed to collect and store lease manager information from tenants. The information collected will be used to manage and maintain accurate records of lease-related data.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling in the "tenant information" section with the relevant details about the tenant.
2. Provide contact information, including phone, fax, and cell numbers, as well as email address.
3. Select the correct lease term and status from the respective fields.
4. Enter the rental unit type (studio, one bedroom, or two bedroom).
5. Enter the lease start and end dates, including start and end times if applicable.
6. Add any additional notes or comments in the "note" field.
7. Finally, confirm your submission by reviewing the information provided.

## Field-by-Field Explanation

* **Tenant Information (Text)**: Enter the name and other relevant details of the tenant.
* **Contact Information (Text)**: Enter the contact details of the tenant, such as phone, fax, and email.
* **Lease Term (Number)**: Select the type of lease term (e.g., studio, one bedroom, or two bedroom).
* **Lease Status (Select Multiple)**: Select the status of the lease (e.g., Active or Inactive).
* **Rental Unit (Select One)**: Select the type of rental unit (e.g., studio, one bedroom, or two bedroom).
* **Tenant ID (Number)**: Enter a unique identifier for the tenant.
* **Address (Text)**: Enter the address of the rental property.
* **Email (Email)**: Enter the email address of the tenant or property manager.
* **Minimialist Lease (Number)**: Select the type of minimalist lease option.
* **Lease Start Date (Date)**: Enter the start date of the lease.
* **Lease End Date (Date)**: Enter the end date of the lease.
* **Note (Text)**: Add any additional notes or comments about the lease.
* **Property Name (Text)**: Enter the name of the rental property.
* **Phone (Text)**: Enter the phone number of the property manager or tenant.
* **Fax (Text)**: Enter the fax number of the property manager or tenant.
* **Cell (Text)**: Enter the cell phone number of the property manager or tenant.
* **Lease Start Time (Time)**: Enter the start time of the lease (if applicable).
* **Lease End Time (Time)**: Enter the end time of the lease (if applicable).

Note: All fields are optional unless marked as required in the form schema.
