# Project Management Tracker - Help Guide
## Purpose
The Project Management Tracker form is designed to help project managers track multiple projects and their tasks in a structured manner. The form is used to input and manage project and task details, resources, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project title and description in the respective fields.
2. Select the tasks that are part of the project from the task list.
3. Choose the deadline for the project.
4. Select the resources involved in the project.
5. Update the task status.
6. Fill in the task description.
7. Set the project and task deadlines and time estimates.
8. Choose the project and task priority levels.
9. Select the resources assigned to the tasks.
10. Confirm your changes by clicking the "Submit" button.
