# Crime Clearance Rate Report Form - Help Guide
## Purpose

The Crime Clearance Rate Report Form is used to track and analyze the rate of crimes cleared by law enforcement agencies.

## How To Complete This Form

1. Select the report date for the case.
2. Select the agency that was involved in the case.
3. Enter the incident date for the case.
4. Enter the clearance rate (as a percentage) for the case.
5. Enter the total number of crimes involved in the case.
6. Enter the number of crimes that were cleared.
7. Select the percent cleared (calculated based on the clearance rate and total crimes).
8. Add any additional notes about the case.
9. Select any agency comments related to the case.

## Field-by-Field Explanation

* **Report Date (report_date)**: This is the date on which the case was reported to the agency.
* **Agency (agency_id)**: Select the agency that was involved in the case.
* **Incident Date (incident_date)**: This is the date on which the incident occurred.
* **Clearance Rate (clearance_rate)**: Enter the clearance rate as a percentage (e.g., 0, 50, or 100%).
* **Total Crimes (total_crimes)**: Enter the total number of crimes involved in the case.
* **Cleared Crimes (cleared_crimes)**: Enter the number of crimes that were cleared.
* **Percent Cleared (percent_cleared)**: This is automatically calculated based on the clearance rate and total crimes. It shows the percentage of crimes cleared.
* **Notes (notes)**: Add any additional comments or details about the case.
* **Agency Comments (agency_comments)**: Select any additional comments or feedback from the agency about the case.
