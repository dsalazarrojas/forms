# Payroll Adjustment Request Form - Help Guide
## Purpose
This form is used to request a change to an employee's compensation package.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your employee name.
2. Select the type of adjustment you are requesting (Salary, Bonus, or Leave).
3. If applicable, select the start and end dates of the adjustment.
4. Provide the reason for the adjustment.
5. If applicable, select the tool you were assigned to perform the adjustment.
6. Enter the amount of the adjustment, if applicable.
7. Select the status of your request (Pending, Approved, or Rejected).

## Field-by-Field Explanation

* **Employee Name** (Text, Optional): This is your name as an employee.
* **Adjustment Type** (Select One, Required): Select the type of adjustment you are requesting: Salary, Bonus, or Leave.
* **Start Date** (Date, Optional): If your request is for a future date, enter the start date of the adjustment. Leave blank if your request is for a retroactive adjustment.
* **End Date** (Date, Optional): If your request is for a future date, enter the end date of the adjustment. Leave blank if your request is for a retroactive adjustment.
* **Reason** (Text, Optional): Provide a brief explanation for your request.
* **Comment** (Text, Optional): Add any additional comments or context to your request.
* **Amount** (Number, Optional): Enter the amount of the adjustment, if applicable. If the adjustment type is Leave, leave this field blank.
* **Assigned Tool** (Select One, Optional): Select the tool you were assigned to perform the adjustment. This will ensure that the correct tool is used to process your request.
* **Status** (Select Multiple, Optional): Select the status of your request: Pending, Approved, or Rejected. This will help the payroll team track the progress of your request.

**Tips**

* Ensure that you only submit one adjustment request per form.
* Be as specific as possible when providing dates for future adjustments.
* If you are unsure about any field, contact your HR representative for clarification.
