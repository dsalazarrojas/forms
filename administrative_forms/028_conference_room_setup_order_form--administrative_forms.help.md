# Conference Room Setup Order Form - Help Guide

## Purpose
This form is used to schedule and confirm conference room setups for events, ensuring that all necessary details are collected for efficient setup and management.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your contact information (orderer's name, email, and phone number).
2. Select the room to be setup ( Conference Room A, B, or other options).
3. Enter the setup date and time.
4. Specify the event's start and end times.
5. Provide details for the event, such as event type, title, number of attendees, and specific requirements.
6. Choose the table and chair configuration, including number of tables and chairs.
7. Confirm the setup details and submit the form.

## Field-by-Field Explanation
* **Orderer Full Name (1)** (`orderer_name`, required): Please enter your complete name for contact purposes.
* **Email Address (2)** (`email`, required): Enter your contact email for communication.
* **Phone Number (3)** (`phone`, required): Enter your contact phone number.
* **Department (4)** (`department`, required): Specify your department or team name.
* **Room Name (5)** (`room_name`, required): Select the conference room to be setup (Conference Room A, B, or other options).
* **Setup Date (6)** (`setup_date`, required): Enter the date for the setup.
* **Setup Time (7)** (`setup_time`, required): Enter the time for the setup.
* **Event Start Time (8)** (`event_start`, required): Enter the start time of the event.
* **Event End Time (9)** (`event_end`, required): Enter the end time of the event.
* **Breakdown Time (10)** (`breakdown_time`, optional): If applicable, enter the time for clearing the room.
* **Event Type (11)** (`event_type`, required): Choose the type of event (Board Meeting, Client Presentation, etc.).
* **Event Title (12)** (`event_title`, required): Enter the name of the event.
* **Number of Attendees (13)** (`number_of_attendees`, required): Enter the expected number of attendees.
* **Table Configuration (14)** (`table_configuration`, required): Select the desired table arrangement (Boardroom Rectangle, U-Shape, etc.).
* **Number of Tables (15)** (`table_count`, optional): If specific count is required, enter it.
* **Number of Chairs (16)** (`chair_count`, required): Enter the number of chairs needed.
* **Special Chair Requirements (17)** (`special_chairs`, optional): If any special chair requirements, describe them.
* **Podium Required (18)** (`podium_required`, required): Choose if a podium is needed for the event.
* **Stage or Platform (19)** (`stage_required`, optional): If a raised platform is required, choose yes.
* **Stage Dimensions (20)** (`stage_dimensions`, optional): If a stage is required, specify its dimensions.
* **Registration Table (21)** (`registration_table`, optional): If a registration table is needed at the entrance, choose yes.
* **Display Tables (22)** (`display_tables`, optional): If display tables are needed for materials, enter the count.
* **Linen Color Preference (23)** (`linen_color`, optional): Choose the preferred color of table covers.
* **Room Dividers (24)** (`room_dividers`, optional): If partitioning is required, choose yes.
* **Signage Placement (25)** (`signage_placement`, optional): If signs are needed, describe where they should be placed.
* **Coat Check Area (26)** (`coat_check`, optional): If a coat check area is needed, choose yes.
* **Special Setup Notes (27)** (`special_setup_notes`, optional): Provide any additional setup requirements.
* **On-Site Contact (28)** (`contact_onsite`, required): Enter the contact information for the on-site person.
* **I Confirm Setup Order Details (29)** (`setup_confirmation`, required): Verify that the setup details are accurate before submission.
