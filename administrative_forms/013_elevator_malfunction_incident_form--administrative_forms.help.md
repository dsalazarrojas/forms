# Elevator Malfunction Incident Form - Help Guide
## Purpose
This form is used to report and document elevator malfunctions in a building. It helps the maintenance team to identify the issue, take necessary steps to resolve it, and follow up on the incident.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the building location where the malfunction occurred.
2. Select the date and time of the malfunction.
3. Choose the type of elevator that malfunctioned (2, 4, or 6).
4. Indicate the direction of the malfunction (Up, Down, Side, or Center).
5. Provide a detailed description of the issue.
6. If available, include a witness statement.
7. Mention any preventive measures taken to address the issue.
8. If necessary, specify the cause of the malfunction.
9. Enter the name of the assigned inspector who will be handling the case.
10. Enter the name of the tool used to investigate the issue.
11. Enter the name of the output file related to the incident.
12. Leave this field blank (it is not intended to be filled out).

## Field-by-Field Explanation
* **Building Location**: Enter the location of the building where the malfunction occurred.
* **Date and Time**: Enter the date and time when the malfunction occurred.
* **Elevator Type**: Choose the type of elevator that malfunctioned. Options are 2, 4, or 6.
* **Direction**: Indicate the direction of the malfunction. Options are Up, Down, Side, or Center.
* **Issue Description**: Provide a detailed description of what happened during the malfunction.
* **Witness Statement**: If there were any witnesses, include their statement.
* **Preventive Measures**: Mention any actions taken to address the issue before it occurred.
* **Cause of Malfunction**: If you know the cause of the malfunction, provide it here.
* **Assigned Inspector**: Enter the name of the person assigned to investigate the issue.
* **Assigned Tool**: Enter the name of the tool used to investigate the issue.
* **Output File Name**: Enter the name of the output file related to the incident.
* **Form ID**: Leave this field blank, it is not intended to be filled out.
* **Form Version**: Leave this field blank, it is not intended to be filled out.
* **Category**: Enter the category for this form (always "administrative_forms").
* **Description**: Leave this field blank, it is not intended to be filled out.
