# Maintenance Request Check In Form - Help Guide
## Purpose
The Maintenance Request Check In Form is used to report maintenance requests for tracking and management within the organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name as the submitter in the "Submitter" field.
2. Select the date of the request using the calendar or date field.
3. Provide the time of the request if applicable.
4. Describe the specific issue or problem in the "Issue" field.
5. Enter detailed information about the request in the "Details" field.
6. If necessary, choose the priority level of the request from "Low", "Medium", or "High".
7. Select the category of the request from "Maintenance", "Repairs", or "Upgrades".
8. Enter any contact information if applicable.
9. Enter any additional description details.
10. Choose the tool or equipment that the issue is related to from the list of options.
11. If necessary, select the person assigned to work on the issue from the list of options.

## Field-by-Field Explanation

* **Submitter (Submitter, text, required)**: Enter your name as the person submitting this maintenance request.
* **Date (Date, date, required)**: Enter the date the issue occurred or was noticed.
* **Time (Time, time, optional)**: Enter the time the issue occurred or was noticed, if applicable.
* **Issue (Issue, text, required)**: Describe the specific issue or problem in as much detail as possible.
* **Details (Details, text, required)**: Provide detailed information about the request.
* **Priority (Priority, select_one, optional)**: Select the priority level of the request, which helps in organizing and scheduling maintenance tasks.
	+ Options: "Low", "Medium", "High"
* **Category (Category, select_one, optional)**: Select the category of the request from "Maintenance", "Repairs", or "Upgrades".
	+ Options: "Maintenance", "Repairs", "Upgrades"
* **Contact (Contact, text, optional)**: If applicable, enter any contact information related to the issue.
* **Email (Email, email, optional)**: Enter any email address related to the contact information.
* **Description (Description, text, optional)**: Enter any additional details about the issue.
* **Assigned Tool (Assigned Tool, text, required)**: Choose the tool or equipment related to the issue from the list of options.
* **Assigned User (Assigned User, text, optional)**: If necessary, select the person assigned to work on the issue from the list of options.
