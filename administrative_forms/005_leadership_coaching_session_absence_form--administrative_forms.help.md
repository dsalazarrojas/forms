# leadership_coaching_session_absence_form - Help Guide
## Purpose
The leadership coaching session absence form is used to request absence from a leadership coaching session. This form is required for all absence requests.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide your participant's name.
2.  Enter the date of the absence.
3.  Specify the reason for the absence.
4.  Enter your email address.
5.  Enter your phone number (optional).
6.  Enter the session ID (optional).
7.  Choose the session time.
8.  Add any follow-up notes (optional).
9.  Add any additional notes (optional).
10.  Select the assigned tool for the absence request (optional).
11.  Choose the output file (optional).
12.  Select the category (e.g., Administrative Forms).
13.  Enter a description of the absence request.
14.  Choose the form ID.

## Field-by-Field Explanation

* **participant_name** (Text): Enter your name as a participant in the leadership coaching session.
* **date** (Date): Enter the date of the absence in the format MM/DD/YYYY.
* **reason** (Text): Specify the reason for your absence from the leadership coaching session.
* **email** (Email): Enter your email address for contact purposes.
* **phone** (Text): Enter your phone number for contact purposes (optional).
* **session_id** (Number): Enter the ID of the leadership coaching session you are requesting absence from (optional).
* **session_time** (Time): Choose the session time for which you are requesting absence.
* **follow_up** (Note): Add any additional follow-up notes for the absence request (optional).
* **notes** (Note): Add any additional notes for the absence request (optional).
* **assigned_tool** (Select One): Choose the tool assigned for the absence request (e.g., chatjimmy).
* **output_file** (Select Multiple): Choose the output file for the absence request (e.g., 005 leadership coaching session absence form--administrative forms).
* **category** (Select One): Select the category for the absence request (e.g., Administrative Forms).
* **description** (Text): Enter a description of the absence request.
* **form_id** (Select One): Choose the form ID for the absence request (e.g., 76599).
