# employee_access_authorization_form - Help Guide
## Purpose
This form is intended to grant employees access to certain areas or systems within the organization.

## How To Complete This Form
1.  Ensure you have all the necessary information about the employee and their access request.
2.  Fill out the employee name field with the employee's full name.
3.  Select the employee's job function from the dropdown menu.
4.  Select the type of access being requested from the multiple-select box.
5.  Enter the start date of the access period, if applicable.
6.  Enter the end date of the access period, if applicable.
7.  Enter a brief description of the reason for access, if applicable.

## Field-by-Field Explanation
*   **employee_name**: 
    +   Type: text
    +   Required: false
    +   This field collects the name of the employee requesting access.
*   **employee_job_title**: 
    +   Type: text
    +   Required: false
    +   This field collects the employee's job title.
*   **job_function**: 
    +   Type: select_one
    +   Required: false
    +   This field is a select box with two options: "Manager" or "Non-Manager".
    +   The selection will inform access level decisions.
*   **access_type**: 
    +   Type: select_multiple
    +   Required: false
    +   This field is a multiple-select box with three options: "Level 1", "Level 2", "Level 3".
    +   The selection will inform access level decisions.
*   **start_date**: 
    +   Type: date
    +   Required: false
    +   This field collects the start date of the access period in MM/DD/YYYY format.
*   **end_date**: 
    +   Type: date
    +   Required: false
    +   This field collects the end date of the access period in MM/DD/YYYY format.
*   **reason_for_access**: 
    +   Type: text
    +   Required: false
    +   This field collects a brief description of the reason for access.

## Tips
*   Be sure to fill out all required fields.
*   If you're unsure about a particular field, you can reach out to the HR or administrative team for clarification.
*   Be clear and concise in the reason for access to help inform access decisions.
