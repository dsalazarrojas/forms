# Hourly Manager Contract Agreement - Help Guide
## Purpose
This form is meant to record the details of an hourly manager contract agreement between a client company and an employee. It's essential to ensure accurate and comprehensive documentation for future reference and communication with the employee.

## How To Complete This Form
1. Start by filling in the job details, including the job title and any other relevant information.
2. Enter the manager ID, which is typically a unique identifier assigned to the manager.
3. Specify the start and end dates of the contract period.
4. Add the manager's name, which is the person signing the agreement.
5. Provide payment terms and any other specific conditions related to the hourly manager contract.
6. Finally, obtain the manager's signature in the designated area.

## Field-by-Field Explanation

### **Job Details** (`job_details`, text, not required)
* A brief description of the job or project being managed. This field is not mandatory, so you can leave it blank if there's no specific job title.

### **Manager ID** (`manager_id`, number, not required)
* The unique identifier assigned to the manager. If your organization uses a specific ID system, fill it in accordingly.

### **Job Title** (`job_title`, text, not required)
* The title of the job or project the manager will be managing. This can be a descriptive name to help identify the work scope.

### **Start Date** (`start_date`, date, not required)
* The date from which the contract begins. This can be a specific date or a general start period (e.g., 1st January 2024).

### **End Date** (`end_date`, date, not required)
* The date up to which the contract remains in effect. Similar to the start date, this can be a specific date or a general end period.

### **Manager Name** (`manager_name`, text, not required)
* The full name of the person signing the manager contract agreement. Ensure it matches the manager's ID if provided.

### **Payment Terms** (`payment_terms`, text, not required)
* Any specific conditions regarding payment, bonuses, or other incentives that apply to this manager contract. If there are no special conditions, leave this field blank.

### **Manager Signature** (`manager_signature`, note, not required)
* The manager's signature confirms that they have read and understood this agreement. Sign this area using your pen and include the date. 

Note: The fields marked as "not required" are optional, so you only need to fill them in if the information is necessary or relevant to the manager contract.
