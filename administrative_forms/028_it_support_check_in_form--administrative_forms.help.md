# it_support_check_in_form - Help Guide
## Purpose
This form is used to submit requests for IT support, providing detailed information to help our team assist you efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1.  Start by filling out the "Submit Request" field, a text area where you can provide a brief description of your IT support request.
2.  Next, choose the type of support you need from the "Request Type" dropdown menu, which includes Technical Support, General Support, Equipment Support, or Other.
3.  If your request has a specific priority level, select it from the "Priority" dropdown menu, which includes High, Medium, and Low.
4.  If you need the request to be completed by a specific date, enter it in the "Due Date" field.
5.  Finally, if you have any additional information to share with our team, you can do so in the "Issue Summary" field.

## Field-by-Field Explanation

*   **Submit Request (Submit Request, text, required: false)**: A text area where you can provide a brief description of your IT support request.
*   **Problem Description (Problem Description, text, required: false)**: A text field for you to describe the problem you are experiencing.
*   **Request Type (Request Type, select_multiple, required: false)**: Choose the type of support you need from the dropdown menu, which includes Technical Support, General Support, Equipment Support, or Other.
*   **Priority (Priority, select_one, required: false)**: Select the priority level of your request, which determines the urgency with which it will be addressed.
*   **Due Date (Due Date, date, required: false)**: If you need the request to be completed by a specific date, enter the date in this field.
*   **Submitter (Submitter, text, required: false)**: A text field for you to provide your name or title.
*   **Contact Number (Contact Number, text, required: false)**: Enter your contact number for our team to reach out to you.
*   **Email (Email, email, required: false)**: Provide your email address for our team to contact you.
*   **Issue Summary (Issue Summary, text, required: false)**: Add any additional information about the issue you are experiencing.

Note: Please fill out the form with as much detail as possible to ensure our team can assist you efficiently.
