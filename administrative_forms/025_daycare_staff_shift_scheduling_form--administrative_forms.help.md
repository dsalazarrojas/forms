# Daycare Staff Shift Scheduling Form - Help Guide
## Purpose
This form is used to schedule and manage daycare staff shifts.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Dayshift Start Time field with the scheduled start time of the shift.
2. Enter the Staff Count field with the number of staff members assigned to the shift.
3. Enter the Shift Start Date field with the scheduled start date of the shift.
4. Enter the Shift End Date field with the scheduled end date of the shift.
5. Enter the Shift Duration field with the duration of the shift.
6. Select the Staff Availability field with the availability of the staff members assigned to the shift.
7. Enter the Shift Notes field with any additional comments or notes about the shift.

## Field-by-Field Explanation

* **Dayshift Start Time** (`dayshift_start_time`, time, required/optional): This field is used to input the scheduled start time of the shift. Please enter the time in 24-hour format (e.g., 09:00).
* **Staff Count** (`staff_count`, number, required/optional): This field is used to input the number of staff members assigned to the shift. Enter the number of staff members you want to schedule.
* **Shift Start Date** (`shift_start_date`, date, required/optional): This field is used to input the scheduled start date of the shift. Please enter the date in the format `YYYY-MM-DD`.
* **Shift End Date** (`shift_end_date`, date, required/optional): This field is used to input the scheduled end date of the shift. Please enter the date in the format `YYYY-MM-DD`.
* **Shift Duration** (`shift_duration`, number, required/optional): This field is used to input the duration of the shift. Please enter the duration in hours.
* **Staff Availability** (`staff_availability`, select multiple, required/optional): This field is used to select the availability of the staff members assigned to the shift. Select `Yes` or `No` to indicate whether the staff members are available or not.
* **Shift Notes** (`shift_notes`, note, required/optional): This field is used to input any additional comments or notes about the shift. Please use this field to provide any necessary information about the shift.
