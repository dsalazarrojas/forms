# Team Collaboration Request Form - Help Guide
## Purpose
The Team Collaboration Request Form is used for team members to request assistance, resources, or collaborate on a specific project with others.

## How To Complete This Form
To submit a team collaboration request, follow these steps:

1. Fill out the form completely and accurately.
2. Choose the appropriate request type: assistance, resources, or project collaboration.
3. Provide a detailed description of your request in the "Request Details" field.
4. Select the collaboration type: assistance, resource request, or project partnership.
5. Enter the desired start and end dates for the collaboration.
6. Provide any relevant project information.
7. Specify the collaboration note if necessary.

## Field-by-Field Explanation
* **Team Collaboration Request** (Field 1):
	+ A brief description of your collaboration request.
* **Request Details** (Field 2):
	+ A detailed description of your request, including any specific needs or requirements.
* **Request Type** (Field 3):
	+ Choose the type of collaboration you are requesting: assistance, resources, or project collaboration.
* **Project Information** (Field 4):
	+ Provide any relevant details about the project you are collaborating on.
* **Collaboration Type** (Field 5):
	+ Choose the type of collaboration you are interested in: assistance, resource request, or project partnership.
* **Collaboration Start Date** (Field 6):
	+ Enter the start date for the collaboration.
* **Collaboration End Date** (Field 7):
	+ Enter the end date for the collaboration.
* **Collaboration Note** (Field 8):
	+ Any additional comments or notes about the collaboration.
* **Email** (Field 9):
	+ Your email address for follow-up communication.
* **Phone** (Field 10):
	+ Your phone number for follow-up communication.
* **Assigned Tool** (Field 11):
	+ Select the tool you would like to use for collaboration (Chatjimmy or Other).
* **Other Tool (Field 12)**:
	+ If you select "Other", provide the name of the tool you would like to use.
