# Urban Planning Review Report Form - Help Guide

## Purpose
The Urban Planning Review Report Form is used to document and track project details to aid project administrators in monitoring and reviewing projects.

## How To Complete This Form
1. **Enter a title for the project**: Enter a brief and descriptive title for the project.
2. **Provide project name and location**: Enter the name and location of the project.
3. **Describe the project**: Enter a short description of the project.
4. **Select project status**: Choose the current status of the project from the available options.
5. **Enter project start and end dates**: Enter the start and end dates of the project.
6. **Enter project budget**: Enter the budget for the project.
7. **List project owners and contacts**: Select the owners and contacts for the project from the available options.
8. **Add project contacts information**: Enter any additional contact information for the project.
9. **Add project notes**: Enter any additional information about the project.

## Field-by-Field Explanation
- **Urban Planning Review Report Form** (1, text, required): Enter a title for the form that will be used for identification purposes.
  - Enter a brief and descriptive title for the form.
- **project name** (2, text, required): Enter the name of the project.
  - This is the name of the project, e.g., "New Park Development."
- **project location** (3, text, required): Enter the location of the project.
  - Provide the exact location of the project, e.g., "City Center."
- **project description** (4, text, required): Enter a short description of the project.
  - Give a brief overview of the project's objectives and goals.
- **project status** (5, select_one, required): Choose the current status of the project from the available options.
  - Select the current state of the project, e.g., "Active," "Completed," or "Deferred."
- **project start date** (6, date, required): Enter the start date of the project.
  - Enter the date when the project began.
- **project end date** (7, date, required): Enter the end date of the project.
  - Enter the date when the project is expected to conclude.
- **project budget** (8, number, required): Enter the budget for the project.
  - Provide the financial amount allocated for the project.
- **project owners** (9, select_multiple, required): Select the owners and contacts for the project from the available options.
  - Choose the individuals or groups responsible for the project's management.
- **project contacts** (10, text, required): Enter any additional contact information for the project.
  - Add any extra contact details, e.g., email addresses, phone numbers, or URLs.
- **project notes** (11, note, required): Enter any additional information about the project.
  - Provide extra details or context about the project.
