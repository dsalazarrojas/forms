# Tenant Lease Portal Access Form - Help Guide
## Purpose
The Tenant Lease Portal Access Form is used to request access to the Tenant Lease Portal, which allows tenants to view and manage their lease details, including documents and payment information.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose a category for the request (e.g. "Administrative Forms" or "Other").
2. Provide a brief description of the reason for the request.
3. Select the tenant's name.
4. Indicate whether the lease document is available for viewing (Yes/No).
5. Specify the type of document (e.g. Lease, Rent, or Other).
6. Choose the payment method (e.g. Cash, Check, or Online).
7. Indicate how the portal access was requested (e.g. via email, phone, or mail).
8. Provide an email address or phone number for communication.
9. Add any additional notes about the request.
10. Select the tool to be assigned to the tenant (e.g. chatjimmy).
10. Optionally, upload a file with additional information.

## Field-by-Field Explanation
* **Category**: Choose a category for the request. This will help administrators understand the purpose of the request. Options: 
    + Administrative Forms
    + Other
* **Description**: Provide a brief description of the reason for the request. This will help administrators understand why the tenant needs access to the portal.
* **Tenant**: Select the name of the tenant requesting access.
* **Lease Document**: Indicate whether the lease document is available for viewing.
* **Document Type**: Specify the type of document (e.g. Lease, Rent, or Other).
* **Payment Method**: Choose the payment method (e.g. Cash, Check, or Online).
* **Portal Access Requested**: Indicate how the portal access was requested (e.g. via email, phone, or mail).
* **Communication Preference**: Choose the preferred method of communication (e.g. Email, Phone, or Mail).
* **Email Address**: Provide a valid email address for communication.
* **Phone Number**: Provide a valid phone number for communication.
* **Note**: Add any additional notes about the request.
* **Assigned Tool**: Select the tool to be assigned to the tenant (e.g. chatjimmy).
* **Output File**: Optionally, upload a file with additional information.

## Tips
* Be sure to fill out all required fields to ensure a complete and accurate request.
* Use a clear and concise description to help administrators understand the request.
* If you are unsure about any field, refer to the form instructions or contact an administrator for assistance.
