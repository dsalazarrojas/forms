# Facility Use Request Form - Help Guide
## Purpose
The Facility Use Request Form is used to request use of a facility for a specific event or activity.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the requested event start and end dates and times.
2. Select the facility to be used from the options provided.
3. Enter the contact information for the person requesting the facility use.
4. Provide a description of the event or activity.
5. Choose the purpose of the facility use (e.g., event, meeting, etc.).
6. Select the status of the facility use request (e.g., approved, pending, etc.).
7. Enter any additional notes about the facility use.

## Field-by-Field Explanation

* **event_reservation_requests** (1, text, optional): Enter a brief description of the event or activity being requested.
* **start_date** (2, date, optional): Enter the start date of the event or activity. Please use the format dd/mm/yyyy.
* **start_time** (3, time, optional): Enter the start time of the event or activity. Please use the 24-hour clock format (HH:MM).
* **end_date** (4, date, optional): Enter the end date of the event or activity. Please use the format dd/mm/yyyy.
* **end_time** (5, time, optional): Enter the end time of the event or activity. Please use the 24-hour clock format (HH:MM).
* **facility_name** (6, text, optional): Enter the name of the facility being requested.
* **facility_id** (7, number, optional): Enter the ID number of the facility being requested.
* **contact_name** (8, text, optional): Enter the name of the person requesting the facility use.
* **contact_email** (9, email, optional): Enter the email address of the person requesting the facility use.
* **contact_phone** (10, text, optional): Enter the phone number of the person requesting the facility use.
* **event_description** (11, text, optional): Enter a detailed description of the event or activity.
* **event_notes** (12, text, optional): Add any additional notes about the event or activity.
* **facility_use_type** (13, select one, optional): Choose the purpose of the facility use (e.g., event, meeting, etc.).
* **facility_use_status** (14, select one, optional): Select the status of the facility use request (e.g., approved, pending, etc.).
* **facility_use_start_date** (15, date, optional): Enter the start date of the facility use. Please use the format dd/mm/yyyy.
* **facility_use_start_time** (16, time, optional): Enter the start time of the facility use. Please use the 24-hour clock format (HH:MM).
* **facility_use_end_date** (17, date, optional): Enter the end date of the facility use. Please use the format dd/mm/yyyy.
* **facility_use_end_time** (18, time, optional): Enter the end time of the facility use. Please use the 24-hour clock format (HH:MM).
* **facility_use_start_time** (19, time, optional): Enter the start time of the facility use. Please use the 24-hour clock format (HH:MM).
* **facility_use_end_time** (20, time, optional): Enter the end time of the facility use. Please use the 24-hour clock format (HH:MM).
* **facility_use_status_note** (21, text, optional): Enter any additional notes about the facility use status.
* **facility_use_requester** (22, text, optional): Enter the name of the person or organization requesting the facility use.
* **facility_use_requester_phone** (23, text, optional): Enter the phone number of the person or organization requesting the facility use.
* **facility_use_requester_email** (24, email, optional): Enter the email address of the person or organization requesting the facility use.
* **facility_use_requester_notes** (25, text, optional): Enter any additional notes about the person or organization requesting the facility use.
