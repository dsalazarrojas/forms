# Employee One On One Meeting Form - Help Guide
## Purpose
The purpose of this form is to record and document one-on-one meeting information between employees.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's name for whom the meeting is scheduled.
2. Select the meeting date.
3. Choose the start and end times for the meeting.
4. Enter the manager's name for the meeting.
5. Select the location where the meeting took place.
6. Record any notable notes from the meeting.
7. Provide employee feedback on the meeting.
8. List any action items that need to be addressed.
9. Select the assigned tool(s) for the meeting.
10. Choose the category(s) related to the meeting.

## Field-by-Field Explanation

* **Employee Name**: Enter the name of the employee for whom the meeting is scheduled.
* **Meeting Date**: Select the date of the meeting. This field should be in the format `YYYY-MM-DD`.
* **Start Time**: Select the start time of the meeting. This field should be in the format `HH:MM`.
* **End Time**: Select the end time of the meeting. This field should be in the format `HH:MM`.
* **Manager Name**: Enter the name of the manager for the meeting.
* **Location**: Enter the location where the meeting took place.
* **Meeting Notes**: Record any notable notes from the meeting.
* **Employee Feedback**: Provide feedback on the meeting from the employee's perspective.
* **Action Items**: List any action items that need to be addressed.
* **Assigned Tool**: Select the tool assigned to the meeting. Choose `chatjimmy` or select `Other`.
* **Category**: Select the category(s) related to the meeting. Multiple categories can be chosen.
* **Description**: This field is optional and provides an opportunity to add further description about the meeting.
* **Output File**: This field is not currently used and can be ignored.
* **Form Ids**: This field is not currently used and can be ignored.
* **Category List**: This field is not currently used and can be ignored.
* **Assigned Tool List**: This field is not currently used and can be ignored.
* **Description List**: This field is not currently used and can be ignored.
* **Category List 1-8**: These fields are used to record multiple categories related to the meeting. They are optional and can be ignored if not required.

Note: The `Assigned Tool List`, `Description List`, and `Category List 1-8` fields are not currently used and can be ignored.
