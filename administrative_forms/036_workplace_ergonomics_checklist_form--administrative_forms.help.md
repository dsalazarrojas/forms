# Workplace Ergonomics Checklist Form - Help Guide
## Purpose
This form is a tool to help employees or supervisors assess and improve the ergonomics of a workspace. It gathers information on the comfort, safety, and awareness of the employees working in the space.

## How To Complete This Form
To complete this form, follow these steps:
1. Choose the correct workspace location from the drop-down menu.
2. Provide text input for the Ergonomic Condition, Employee Comfort, and Employee Feedback fields.
3. Select all applicable options for Employee Comfort and Safety Measures.
4. If required, enter the date of the ergonomics checkup.
5. If required, select the work hours for the space.

## Field-by-Field Explanation
### **Workspace** (`work_station`, `select_one`, required: false)
Choose the correct workspace location from the drop-down menu.

* The workspace location could be an office, home office, or an outdoor work area.
* Select the option that accurately reflects where you are completing this form.

### **Ergonomic Condition** (`ergonomic_condition`, `text`, required: false)
Provide a written description of the overall ergonomics condition of your workspace.

* Be as specific as possible when describing your workspace's ergonomics.
* For example, "The room temperature is comfortable, but the seating is too tight for some employees."

### **Employee Comfort** (`employee_confort`, `select_multiple`, required: false)
Select all that apply:
* Comfortable
* Uncomfortable

### **Safety Measures** (`safety_measures`, `select_one`, required: false)
Select one of the options:
* True
* False

### **Employee Awareness** (`employee_awareness`, `select_multiple`, required: false)
Select all that apply:
* True
* False

### **Ergo Checklist** (`ergo_checklist`, `date`, required: false)
Enter the date of the ergonomics checkup if required.

### **Work Hours** (`work_hours`, `time`, required: false)
Enter the work hours if required.

### **Ergonomic Issues** (`ergonomic_issues`, `text`, required: false)
Provide a written description of any ergonomic issues you have encountered.

* Be as specific as possible when describing the ergonomic issues.
* For example, "The chair height is too low for some employees."

### **Employee Feedback** (`employee_feedback`, `text`, required: false)
Provide written feedback on any suggestions you have for improving the ergonomics of your workspace.

* Be specific and constructive in your feedback.
* For example, "We need to adjust the lighting levels to prevent eye strain."
