# Resource Booking Access Form - Help Guide
## Purpose
The Resource Booking Access Form is designed to collect information for booking resources. This form is used to book access to resources such as equipment, rooms, or facilities. It's essential to fill out this form accurately to ensure that resources are booked correctly and that the correct people have access to them.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the date you wish to book the resource for.
2.  Select the time you wish to book the resource for.
3.  Choose the resource you wish to book.
4.  Select who will be using the resource (if applicable).
5.  Add any additional comments or information regarding the booking.
6.  Finally, click the submit button to send the form.

## Field-by-Field Explanation
* **Resource Booking Date** (`resource_booking_date`): Please select the date you wish to book the resource for. This date will be used to schedule the resource booking.
* **Resource Booking Time** (`resource_booking_time`): Select the time slot you wish to book the resource for. This time slot will be used to schedule the resource booking.
* **Resource** (`resource_booking_resource`): Choose the resource you wish to book. This can be equipment, a room, or any other facility. Please select the correct resource from the provided options.
* **Who** (`resource_booking_who`): This field is used to select who will be using the resource. If applicable, please select the correct individual or group from the provided options. If not applicable, please leave this field blank.
* **Resource Booking Comments** (`resource_booking_comments`): If you have any additional information regarding the booking, please add it here. This can include any specific requirements or requests you have.
* **Additional Information** (`resource_booking_additional_info`): This field is for any extra information you'd like to provide. Please use this section to add any relevant details regarding the booking.

Remember to fill out the form accurately and completely to avoid any confusion or issues with resource bookings. If you have any questions or need clarification on any of the fields, please don't hesitate to contact us.
