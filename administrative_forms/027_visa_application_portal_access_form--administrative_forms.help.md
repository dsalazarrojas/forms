# visaApplicationPortalAccessForm - Help Guide
## Purpose
This form is used to submit information for a visa application. It collects various details about the applicant, including contact information, visa type, and document upload.

## How To Complete This Form

1. Click on the "Submit" button to begin the application process.
2. Fill in the required fields with the necessary information.
3. Ensure that all fields are complete before submitting the form.

## Field-by-Field Explanation

* **Application Form Information**: This field is where you can enter any additional information about your visa application.
	+ Type: `text` (text box)
	+ Required: False
* **Applicant Contact**: Please select the correct option to indicate if you are the applicant.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Email**: Enter your email address.
	+ Type: `email` (email input field)
	+ Required: False
* **Contact Information**: Enter your contact information.
	+ Type: `text` (text box)
	+ Required: False
* **Date of Birth**: Enter your date of birth.
	+ Type: `date` (date picker)
	+ Required: False
* **Country of Birth**: Please select the country of your birth.
	+ Type: `select_one` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Visa Application Type**: Please select the type of visa application.
	+ Type: `select_one` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Visa Application Category**: Please select the category of visa application.
	+ Type: `select_one` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Nationality**: Please select your nationality.
	+ Type: `select_one` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Passport Number**: Enter your passport number.
	+ Type: `number` (number input field)
	+ Required: False
* **Passport Expiration Date**: Enter your passport expiration date.
	+ Type: `date` (date picker)
	+ Required: False
* **Passport Issued**: Please select the passport issued status.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Photo**: This field is not applicable for this form.
	+ Type: `note` (note field)
	+ Required: False
* **Visa Application Fee**: Enter your visa application fee.
	+ Type: `number` (number input field)
	+ Required: False
* **Visa Application Fees**: Please select the visa application fees.
	+ Type: `select_one` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Applicant Signature**: Please select the applicant signature status.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Applicant Signature 2**: Please select the second applicant signature status.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Visa Application Status**: Please select the visa application status.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Active, Inactive`
	+ Required: False
* **Visa Application Fee**: Please select the visa application fee status.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Visa Application Type**: Please select the visa application type.
	+ Type: `select_multiple` (drop-down menu)
	+ Options: `Yes, No`
	+ Required: False
* **Document Upload**: This field is not applicable for this form.
	+ Type: `note` (note field)
	+ Required: False
* **Document Upload 2**: This field is not applicable for this form.
	+ Type: `note` (note field)
	+ Required: False
* **Visa Application Comment**: Enter your comments about the visa application.
	+ Type: `note` (note field)
	+ Required: False

Please ensure that all fields are complete before submitting the form. If you have any questions or concerns, please contact us.
