# New Client Record Form - Help Guide
## Purpose
The New Client Record Form is used to create a new client record in the system. This form collects personal and contact information from clients, which will be stored in the system for future reference and management.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's first name in the "First Name" field.
2. Enter the client's last name in the "Last Name" field.
3. Enter the client's email address in the "Email" field.
4. Enter the client's phone number in the "Phone Number" field.
5. Select the client's birthdate in the "Birthdate" field.
6. Enter the client's address in the "Address 1" field.

## Field-by-Field Explanation
* **First Name**: Enter the client's first name in this field. This is a required field.
* **Last Name**: Enter the client's last name in this field. This is a required field.
* **Email**: Enter the client's email address in this field. This is a required field and must be in a valid email format.
* **Phone Number**: Enter the client's phone number in this field. This is an optional field.
* **Birthdate**: Select the client's birthdate in this field. This is an optional field.
* **Address 1**: Enter the client's address in this field. This is an optional field.

## Tips
* Make sure to enter accurate and up-to-date information to ensure that client records are accurate and complete.
* If you are unsure about any field, please check the field label for clarification.
* If you have any questions or concerns about completing this form, please reach out to the system administrator.
