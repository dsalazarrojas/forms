# Tool Inspection Declaration Form - Help Guide
## Purpose
The Tool Inspection Declaration Form is used to gather information about a tool's condition, category, and inspection history. This data helps ensure that tools are properly maintained and monitored.

## How To Complete This Form
1. Start by filling out the tool name, description, and assigned tool fields with the relevant information.
2. Select the tool category from the provided options.
3. Indicate the tool's condition using the select multiple option.
4. If applicable, fill out the last inspection and next inspection dates.
5. Optionally, provide the name of the person or team that last inspected the tool.

## Field-by-Field Explanation
* **Tool Inspection Form (1)**: Enter a brief description of the form, which will be used to help identify the tool.
* **Tool Name (2)**: Type the name of the tool being inspected.
* **Tool Description (3)**: Provide a short description of the tool, including its usage and any notable features.
* **Assigned Tool (4)**: Enter the name of the tool's owner or department responsible for the tool.
* **Tool Category (5)**: Select the category that best describes the tool (Hand tools, Power tools, or Machine tools).
* **Tool Condition (6)**: Indicate the tool's current condition, choosing from Good, Fair, or Poor.
* **Last Inspection (7)**: If the tool has been inspected before, fill out the date of the last inspection. If not applicable, leave blank.
* **Next Inspection (8)**: Schedule the next inspection date for the tool. If not applicable, leave blank.
* **Last Inspected By (9)**: Optionally, enter the name of the person or team that performed the last inspection.

## Tips
* Make sure to accurately describe the tool's condition to ensure correct tracking and maintenance.
* Use the correct category to ensure that the tool is properly monitored and maintained.
* Fill out the inspection dates to track the tool's inspection history.
* If the tool is no longer in use or has been removed, mark it as such in the condition field.
