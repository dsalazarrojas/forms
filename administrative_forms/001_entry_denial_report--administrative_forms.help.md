# entry_denial_report - Help Guide
## Purpose
The entry denial report is a formal document used to record and manage incidents that have been denied entry or access to a system or facility.

## How To Complete This Form
1. Fill in the incident details section (page 1) with information about the incident, including the reason for denial.
2. Enter the uploader's information, including their name and the date and time the evidence was uploaded.
3. If necessary, upload any supporting evidence for the denial.
4. Confirm the submitter's name.

## Field-by-Field Explanation
* **Incident Details** (`incident_details`, `text`, required/optional): Enter a brief description of the incident that has been denied.
* **Reason for Denial** (`reason_for_denial`, `text`, required): Provide a clear and concise explanation for the denial.
* **Evidence Uploader** (`evidence_uploader`, `text`, required): Enter the name of the person who uploaded the evidence.
* **Upload Date** (`upload_date`, `date`, optional): Enter the date the evidence was uploaded (if applicable).
* **Upload Time** (`upload_time`, `time`, optional): Enter the time the evidence was uploaded (if applicable).
* **Upload File** (`upload_file`, `text`, optional): If you have uploaded a file as evidence, enter the file name (if applicable).
* **Submitter's Name** (`submitters_name`, `text`, optional): Enter your name as the person submitting the report.
