# Loan Repayment Declaration Form - Help Guide
## Purpose
The Loan Repayment Declaration Form is designed to collect information about loans, including loan terms, borrower details, and payment schedules. This form helps to gather relevant data in a structured format, which can be used for administrative or reporting purposes.

## How To Complete This Form
1. Start by filling out the loan terms section, including loan amount, interest rate, and loan duration.
2. Provide borrower information, including their name, contact details, and loan status.
3. Specify the loan schedule, including the payment frequency and amount.
4. Add any additional information about the loan, such as payment terms, fees, and security deposits.

## Field-by-Field Explanation

* **loan_terms** (`loan_terms`, `text`, required: false): This field is used to enter the loan terms, including the loan amount, interest rate, and duration. It should be filled out with the relevant information about the loan.
* **lender_info** (`lender_info`, `text`, required: false): This field is used to enter the lender's information, including their name and contact details. It is not a required field.
* **borrower_info** (`borrower_info`, `text`, required: false): This field is used to enter the borrower's information, including their name and contact details. It is not a required field.
* **contact_info** (`contact_info`, `text`, required: false): This field is used to enter the contact information for both the lender and borrower. It is not a required field.
* **agreement_terms** (`agreement_terms`, `text`, required: false): This field is used to enter any relevant agreement terms related to the loan. It is not a required field.
* **loan_status** (`loan_status`, `select_one`, required: false): This field allows you to select the current loan status as either "Available" or "Not Available".
* **loan_terms_and_conditions** (`loan_terms_and_conditions`, `text`, required: false): This field is used to enter any additional loan terms and conditions. It is not a required field.
* **loan_repayment_plan** (`loan_repayment_plan`, `text`, required: false): This field is used to enter the loan repayment plan, including any relevant details about the payment schedule. It is not a required field.
* **loan_fees** (`loan_fees`, `text`, required: false): This field is used to enter any fees associated with the loan. It is not a required field.
* **loan_security_deposits** (`loan_security_deposits`, `text`, required: false): This field is used to enter any security deposits for the loan. It is not a required field.
* **loan_security_deposits_status** (`loan_security_deposits_status`, `select_one`, required: false): This field allows you to select the status of the security deposits as either "Available" or "Not Available".
* **payment_schedule** (`payment_schedule`, `text`, required: false): This field is used to enter the payment schedule for the loan. It is not a required field.
* **payment_frequency** (`payment_frequency`, `select_multiple`, required: false): This field allows you to select the payment frequency as "Daily", "Weekly", or "Monthly".
* **payment_amount** (`payment_amount`, `number`, required: false): This field is used to enter the payment amount. It is not a required field.
* **total_outstanding** (`total_outstanding`, `number`, required: false): This field is used to enter the total outstanding amount. It is not a required field.
* **payment_terms** (`payment_terms`, `text`, required: false): This field is used to enter any payment terms or conditions. It is not a required field.
* **interest_rate** (`interest_rate`, `number`, required: false): This field is used to enter the interest rate for the loan. It is not a required field.
* **loan_start_date** (`loan_start_date`, `date`, required: false): This field is used to enter the start date of the loan. It is not a required field.
* **loan_end_date** (`loan_end_date`, `date`, required: false): This field is used to enter the end date of the loan. It is not a required field.
* **loan_duration** (`loan_duration`, `text`, required: false): This field is used to enter the loan duration. It is not a required field.
* **payment_frequency_details** (`payment_frequency_details`, `text`, required: false): This field is used to enter any additional details about the payment frequency. It is not a required field.
* **loan_status_update** (`loan_status_update`, `text`, required: false): This field is used to enter any updates about the loan status. It is not a required field.
