# Retail Loss Prevention Incident Form - Help Guide
## Purpose
The Retail Loss Prevention Incident Form is used to report and document incidents related to retail loss prevention, such as theft, fraud, or vandalism.

## How To Complete This Form
1. Start by filling in the form title.
2. Select the category of the incident (e.g., Administrative Forms, Loss Prevention, Security).
3. Provide a detailed description of the incident.
4. Choose the type of incident (e.g., Theft, Fraud, Vandalism, Trespassing).
5. Enter the date of the incident.
6. Select the details of the suspect (e.g., Known, Unknown).
7. Select the suspect's gender (e.g., Male, Female, Other).
8. Enter the suspect's age.
9. Enter the suspect's height.
10. Enter the suspect's weight.
11. Select the suspect's eye color.
12. Select the suspect's hair color.
13. Select the suspect's race.
14. Check if the suspect has any distinguishing features.
15. Select the unit of measurement for the suspect's height.
16. Select the unit of measurement for the suspect's age.
17. Select the unit of measurement for the suspect's weight.
18. Enter a detailed description of the suspect.
19. Enter the location where the incident occurred.
20. Enter the date and time of the incident.
21. Enter the name of the employee involved.
22. Enter the employee's ID number.
23. Enter the name of any witness.
24. Enter the witness's ID number.

## Field-by-Field Explanation

* **Retail Loss Prevention Incident Form** (text, title, required): Enter a brief title to identify the incident.
* **Category** (select_one, category, required): Select the category of the incident (e.g., Administrative Forms, Loss Prevention, Security).
* **Description** (text, description, required): Provide a detailed description of the incident.
* **Incident Type** (select_one, incident_type, required): Choose the type of incident (e.g., Theft, Fraud, Vandalism, Trespassing).
* **Incident Date** (date, incident_date, required): Enter the date of the incident.
* **Suspect Details** (select_multiple, suspect_details, required): Select the details of the suspect (e.g., Known, Unknown).
* **Suspect Gender** (select_one, suspect_gender, required): Select the suspect's gender (e.g., Male, Female, Other).
* **Suspect Age** (number, suspect_age, required): Enter the suspect's age.
* **Suspect Height** (number, suspect_height, required): Enter the suspect's height.
* **Suspect Weight** (number, suspect_weight, required): Enter the suspect's weight.
* **Suspect Eye Color** (select_one, suspect_eye_color, required): Select the suspect's eye color.
* **Suspect Hair Color** (select_one, suspect_hair_color, required): Select the suspect's hair color.
* **Suspect Race** (select_one, suspect_race, required): Select the suspect's race.
* **Distinguishing Features** (select_multiple, suspect_distinguishing_features, required): Check if the suspect has any distinguishing features.
* **Suspect Height Unit** (select_one, suspect_height_unit, required): Select the unit of measurement for the suspect's height.
* **Suspect Age Unit** (select_one, suspect_age_unit, required): Select the unit of measurement for the suspect's age.
* **Suspect Weight Unit** (select_one, suspect_weight_unit, required): Select the unit of measurement for the suspect's weight.
* **Suspect Description** (text, suspect_description, required): Enter a detailed description of the suspect.
* **Location** (text, location, required): Enter the location where the incident occurred.
* **Date** (date, date, required): Enter the date of the incident.
* **Time** (time, time, required): Enter the time of the incident.
* **Employee Name** (text, employee_name, required): Enter the name of the employee involved.
* **Employee ID** (text, employee_id, required): Enter the employee's ID number.
* **Witness Name** (text, witness_name, required): Enter the name of any witness.
* **Witness ID** (text, witness_id, required): Enter the witness's ID number.
