# first_aid_kit_checklist_form - Help Guide
## Purpose
The First Aid Kit Checklist Form is used to track and manage first aid kits within an organization, ensuring that they are properly stocked, inspected, and maintained. This form helps ensure that first aid kits are not forgotten, and that necessary supplies are reordered when needed.

## How To Complete This Form
To complete this form, follow these steps:

* Ensure you have access to the first aid kit and its contents.
* Check the First Aid Items field for the correct supplies, and select all the items that are available in the kit.
* Choose the First Aid Level that best describes the kit's stock level.
* Enter the location of the first aid kit, including a brief description of where it is located.
* Enter the serial number of the first aid kit.
* Select the status of the kit (Stocked, Low, or Empty).
* Record the date and time of the last inspection.
* Enter the name of the person who last inspected the kit.
* Enter any notes from the last inspection.
* Choose the frequency of inspections (Daily, Weekly, or Monthly).
* Select the reorder level for the first aid supply (Low, Moderate, or High).
* Check if a reorder is needed.
* Enter any notes for the first aid kit.
* Enter any notes for the serial number of the first aid kit.
* Enter the date of the last serial number check (optional).
* Enter any serial number notes for the first aid supply (optional).

## Field-by-Field Explanation
* **First Aid Items** (Multiple Select):
	+ Check the boxes for the items that are available in the first aid kit. Examples: Bandages, antiseptic ointment, antibiotic ointment, etc.
* **First Aid Level** (Single Select):
	+ Choose the level that best describes the amount of stock available in the kit. Options: Low, Moderate, High.
* **First Aid Kit Location** (Text):
	+ Enter the location where the first aid kit is stored.
* **First Aid Kit Location Description** (Text):
	+ Briefly describe where the first aid kit is located (e.g., on a floor, in a closet, etc.).
* **First Aid Kit Serial Number** (Text):
	+ Enter the serial number of the first aid kit.
* **First Aid Kit Status** (Single Select):
	+ Choose the status of the first aid kit (Stocked, Low, or Empty).
* **Last Inspection Date** (Date):
	+ Record the date of the last inspection.
* **Last Inspection By** (Text):
	+ Enter the name of the person who last inspected the kit.
* **Last Inspection Notes** (Text):
	+ Enter any notes from the last inspection.
* **Last Inspection Time** (Time):
	+ Record the time of the last inspection.
* **Last Inspection Location** (Text):
	+ Enter the location of the last inspection.
* **First Inspection Date** (Date):
	+ Record the date of the first inspection.
* **First Inspection By** (Text):
	+ Enter the name of the person who first inspected the kit.
* **First Inspection Notes** (Text):
	+ Enter any notes from the first inspection.
* **First Inspection Time** (Time):
	+ Record the time of the first inspection.
* **First Inspection Location** (Text):
	+ Enter the location of the first inspection.
* **Inspection Frequency** (Single Select):
	+ Choose the frequency of inspections for the first aid kit. Options: Daily, Weekly, Monthly.
* **First Aid Supply Reorder Level** (Single Select):
	+ Choose the reorder level for the first aid supply. Options: Low, Moderate, High.
* **Reorder Needed** (Single Select):
	+ Check if a reorder is needed.
* **First Aid Kit Notes** (Text):
	+ Enter any notes for the first aid kit.
* **First Aid Kit Serial Number Notes** (Text):
	+ Enter any notes for the serial number of the first aid kit.
* **Serial Number Date** (Date):
	+ Enter the date of the last serial number check (optional).
* **Serial Number Location** (Text):
	+ Enter any notes for the serial number location (optional).
* **First Aid Supply Serial Number** (Text):
	+ Enter the serial number of the first aid supply.
* **First Aid Supply Serial Number Notes** (Text):
	+ Enter any notes for the serial number of the first aid supply.
* **Serial Number Location** (Text):
	+ Enter the location of the serial number (optional).
