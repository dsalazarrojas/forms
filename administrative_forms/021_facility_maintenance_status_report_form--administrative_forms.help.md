# Facility Maintenance Status Report Form - Help Guide
## Purpose
The Facility Maintenance Status Report Form is used by facility management teams to gather information about the status of facilities after maintenance. It helps track and report on maintenance requests, current status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. **Maintenance Requests**: Provide a detailed description of the maintenance request on this page.
2. **Facility Status**: Select the current status of the facility from the available options.
3. **Facility Type**: Choose the type of facility from the options.
4. **Equipment Status**: Select the status of facility equipment from the available options. (Note that this field is optional, so you can skip it if not applicable.)
5. **Repair History**: Enter any repair history related to the facility.
6. **Facility Manager**: Enter the name of the facility manager responsible for the maintenance.
7. **Facility Location**: Select the location of the facility from the available options.
8. **Facility Address**: Enter the address of the facility.

## Field-by-Field Explanation
- **Maintenance Requests**: A text field for providing a detailed description of the maintenance request.
    - Type: Text
    - Required: True
- **Facility Status**: A select-multiple field with options:
    - Fully Functional
    - Partially Functional
    - Non-Functional
    - Required: True
- **Facility Type**: A select-one field with options:
    - Office Building
    - Classroom Building
    - Laboratory Building
    - Required: True
- **Equipment Status**: A select-multiple field with options:
    - Operational
    - Non-Operational
    - Required: False
- **Repair History**: A note field for entering repair history. 
    - Type: Note
    - Required: True
- **Facility Manager**: A text field for entering the name of the facility manager.
    - Type: Text
    - Required: True
- **Facility Location**: A select-one field with options:
    - New York
    - Los Angeles
    - Chicago
    - Required: True
- **Facility Address**: A text field for entering the address of the facility.
    - Type: Text
    - Required: True

## Tips
* Make sure to provide accurate and detailed information about the facility's status and maintenance requests.
* Use the correct options for the Facility Type and Facility Location fields.
* If you are unsure about the Equipment Status, it's okay to leave it blank as it's optional.
