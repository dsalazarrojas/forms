# User Documentation Form - Help Guide
## Purpose
This form is designed to gather user feedback, documentation requests, and support issues from users to improve the overall user experience.

## How To Complete This Form

1. Select the "Feedback Category" field to choose between "Technical" and "Non-Technical" feedback.
2. In the "Documentation Requests" field, enter a clear and concise description of your documentation request.
3. In the "Support Issues" field, provide details about any support issues you are experiencing.
4. Select the "Feedback Category" field to choose the type of documentation you are requesting (Manual, Online, or Phone).
5. Choose the "Documentation Request Priority" field to set the priority level of your request (Low, Medium, or High).

## Field-by-Field Explanation

* **Feedback Category** (`Feedback Category`, `select_one`, required): Choose between "Technical" and "Non-Technical" feedback.
* **Email** (`Email`, `email`, required): Enter your email address for the support team to contact you.
* **Phone Number** (`Phone Number`, `text`, optional): Enter your phone number for the support team to contact you.
* **Documentation Requests** (`Documentation Requests`, `text`, required): Enter a clear and concise description of your documentation request.
* **Support Issues** (`Support Issues`, `text`, required): Provide details about any support issues you are experiencing.
* **Documentation Request Comments** (`Documentation Request Comments`, `text`, required): Enter any additional comments about your documentation request.
* **Support Issue Details** (`Support Issue Details`, `text`, required): Enter details about any support issues you are experiencing.
* **Documentation Type** (`Documentation Type`, `select_multiple`, required): Select the type of documentation you are requesting (Manual, Online, or Phone).
* **Documentation Request Priority** (`Documentation Request Priority`, `select_one`, required): Choose the priority level of your request (Low, Medium, or High).

## Tips

* Be clear and concise in your descriptions to ensure your requests are handled efficiently.
* Choose the correct feedback category to ensure your feedback is directed to the right team.
* Set the correct priority level to ensure your request is handled promptly.
