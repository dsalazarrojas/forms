# Letter Writing Guide - Help Guide
## Purpose
This guide will walk you through the "Letter Writing Guide" form, which is designed to assist users in generating a basic letter template.

## How To Complete This Form
To complete this form, follow these steps:
1. Start by selecting the purpose of your letter (Personal or Business) in the "Purpose" field.
2. Fill out the "Recipient" field with the name and address or department of the person you are writing to.
3. Choose a salutation (Mr, Mrs, Ms, or Dr) in the "Salutation" field.
4. Enter the date of the letter in the "Date" field (in the format MM/DD/YYYY).
5. Select a sign-off (Sincerely, All the Best, etc.) in the "Sign Off" field.
6. (Optional) You can add any additional attachments or files to be included with the letter in the "Attachment" field.
7. Finally, fill out the "CC" field if you want to include additional recipients.
8. Upload any necessary files to be attached to the letter in the "File Uploader" field.

## Field-by-Field Explanation
* **Purpose** (`purpose_form`, select_one, required: false): Select the purpose of your letter, either Personal or Business.
* **Recipient** (`recipient_form`, text, required: false): Enter the name and address or department of the person you are writing to.
* **Date** (`date_form`, date, required: false): Enter the date of the letter in the format MM/DD/YYYY.
* **Salutation** (`salutation_form`, select_one, required: false): Choose a salutation (Mr, Mrs, Ms, or Dr.).
* **Sign Off** (`sign_off_form`, text, required: false): Select a sign-off (Sincerely, All the Best, etc.).
* **CC** (`cc_form`, text, required: false): Enter additional recipient names or addresses.
* **Attachment** (`attachment_form`, note, required: false): Enter any additional attachments or files to be included with the letter.
* **File Uploader** (`file_uploader`, text, required: false): Upload files to be attached to the letter.
* **Attachment File** (`attachment_file`, text, required: false): Enter the file name and description to be attached to the letter.
