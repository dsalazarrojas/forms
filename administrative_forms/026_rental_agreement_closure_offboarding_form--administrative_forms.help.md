# Rental Agreement Closure Offboarding Form - Help Guide
## Purpose
The purpose of this form is to collect relevant information about the tenant's situation when a rental agreement is closed. It's used to ensure that all necessary details are documented for future reference and to maintain a smooth and professional offboarding process.

## How To Complete This Form
1. Fill in the form with the necessary information about the tenant's situation.
2. Select the correct reason for vacating from the provided options.
3. Add any additional comments or notes that might be helpful for the landlord.
4. Include the contact person's name and signature for verification purposes.

## Field-by-Field Explanation

* **Tenants Information** (tenant_info): Enter the tenant's name and any other relevant contact information.
* **Property Details** (property_details): Provide a brief description of the property, including its address and any other essential details.
* **Contact Details** (contact_details): Enter the contact information of the person completing the form and their relationship to the tenant (if applicable).
* **Move In Date** (move_in_date): Enter the date when the rental agreement started.
* **Move Out Date** (move_out_date): Enter the date when the rental agreement will close.
* **Reason for Vacating** (reason_for_vacating):
	+ **Renting elsewhere**: Select this option if the tenant is moving to a new location.
	+ **Financial issues**: Select this option if the tenant's financial situation no longer allows them to rent the property.
	+ **Health reasons**: Select this option if the tenant's health issues require them to relocate.
	+ **Other**: Select this option to provide a custom reason for vacating.
* **Comments** (comments): Add any additional comments or notes that might be helpful for the landlord to know.
* **Contact Person** (contact_person): Enter the name of the person responsible for the tenant's offboarding process.
* **Signature** (signature): Include your signature and name for verification purposes.

Please note that the completion of this form is an essential part of the offboarding process, and it should be filled out carefully and accurately to ensure a smooth transition.
