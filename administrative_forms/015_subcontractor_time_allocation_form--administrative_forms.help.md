# subcontractor_time_allocation_form - Help Guide
## Purpose
This form is designed to record and manage time allocations for subcontractors working on various projects. It helps track hours worked, projects, and other relevant details for administrative and reporting purposes.

## How To Complete This Form
1. Fill in the required fields for each section to ensure accurate and complete information.
2. Select the correct project(s) for the work done by the subcontractor.
3. Enter the start and end dates of work.
4. Provide the number of hours worked.
5. Add any additional notes if necessary.
6. Enter the name of the person submitting the record.
7. Optionally, select a tool or system used to complete the work.
8. Finally, confirm who created the record.

## Field-by-Field Explanation

* **Subcontractor Name**: Enter the name of the subcontractor who performed the work.
* **Work Type**: Select the type of work done by the subcontractor (Hourly, Flat Rate, or Project).
* **Project**: Select the project(s) the subcontractor worked on. You can choose one or more projects from the list.
* **Start Date**: Enter the date when the work started.
* **End Date**: Enter the date when the work ended.
* **Hours Worked**: Enter the total hours worked by the subcontractor.
* **Notes**: Add any additional comments or remarks about the work done.
* **Submitted By**: Enter the name of the person submitting the record.
* **Assigned Tool**: If a specific tool or system was used to complete the work, select it from the list.
* **Created By**: Enter the name of the person who created the record.

## Tips
- Make sure to fill out all required fields.
- Double-check the accuracy of the information entered.
- Use the correct work type and project(s) for each record.
- Update existing records if the work details change.
