# Temperature Monitoring Alert Request Form - Help Guide

## Purpose
This form is used to generate a temperature monitoring alert request. Fill out this form to inform us about any temperature-related issues in your environment, such as high or low temperatures. You can choose which environments are sensitive to temperature changes and whether you'd like to receive alerts about these issues.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select "Report Temperature" to describe the temperature-related issue you're experiencing.
2. Choose the environments that are sensitive to temperature changes.
3. Enter the critical temperature value if you've noticed a temperature that's higher or lower than normal.
4. Decide whether you'd like to receive alerts about temperature changes in your sensitive environments.
5. Add any additional comments about the issue, if needed.

## Field-by-Field Explanation
* **Report Temperature**: This is the main description of the temperature-related issue. Please be as detailed as possible about what's happening.
* **Select Sensitive Environments**: Choose all environments that might be affected by the temperature issue. This will allow us to target our response effectively.
* **Critical Temperature**: If there's a specific temperature threshold that's causing concern, enter it here. This is useful for us to understand the severity of the situation.
* **Receive Alerts**: Decide whether you want us to send alerts about temperature changes in your sensitive environments. This ensures you stay informed about any changes.
* **Comments**: If you have any additional information or context about the issue, add it here to help us help you better.
