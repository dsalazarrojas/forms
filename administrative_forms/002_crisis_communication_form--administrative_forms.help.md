# crisis_communication_form - Help Guide
## Purpose

The crisis_communication_form is a tool designed to help manage and respond to emergencies and crises within an organization. It collects essential information to facilitate effective communication and response.

## How To Complete This Form

1.  Select the type of crisis or emergency you are facing (if applicable).
2.  Enter the exact location of the incident.
3.  Provide the contact person's name and their preferred method of contact (phone, email, or other).
4.  Enter any additional details about the emergency.
5.  Select the category of the emergency (e.g., Fire, Police).
6.  Write a brief description of the emergency.
7.  Choose how you would like to be contacted (phone, email, or other).
8.  Select the status of your contact.
9.  Select the response time.
10.  Enter the date of the response.
11.  Indicate the contact person and their contact method (if needed).
12.  Select the contact status.
13.  If needed, select additional contact options (e.g., contact person 2, response date 2).

## Field-by-Field Explanation

* **Emergency Type (1)**: Select the type of crisis or emergency you are facing (e.g., fire, natural disaster).
* **Incident Location (2)**: Enter the exact location of the incident (e.g., building number, room).
* **Contact Person Name (3)**: Provide the name of the person you need to contact.
* **Contact Person Email (4)**: Enter the email address of the contact person.
* **Contact Person Phone (5)**: Enter the phone number of the contact person.
* **Emergency Details (6)**: Enter any additional details about the emergency.
* **Contact Method (7)**: Choose how you would like to be contacted (phone, email, or other).
* **Category of Emergency (8)**: Select the category of the emergency (e.g., Fire, Police).
* **Emergency Description (9)**: Write a brief description of the emergency.
* **Contact Person (10)**: Select the contact person (if needed).
* **Contact Method (11)**: Choose the contact method for the selected contact person.
* **Response Time (12)**: Select the response time for the emergency.
* **Response Date (13)**: Enter the date of the response.
* **Contact Status (14)**: Indicate the status of the contact (e.g., contacted, not contacted).
* **Contact Status Label (15)**: Enter a label for the contact status (if needed).
* **Contact Person 2 (16)**: Select an additional contact person (if needed).
* **Contact Status 2 (17)**: Select the status of the second contact.
* **Response Date 2 (18)**: Enter the date of the response for the second contact.

Tips:

* Be as specific as possible when filling out the form.
* Ensure the correct contact information is provided.
* Choose the correct category and emergency type for accurate response and management.
* Use the "Emergency Details" field for any additional context or information.
* Review your form submissions carefully to ensure accuracy and completeness.
