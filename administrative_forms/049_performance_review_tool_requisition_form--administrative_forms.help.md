# Performance Review Tool Requisition Form - Help Guide
## Purpose
This form is used to collect information for performance review and evaluation of an employee.

## How To Complete This Form
1. Fill in the required fields as prompted. All fields marked as "required" must be filled out.
2. Enter employee name in the `employee_name` field.
3. Enter job title in the `job_title` field.
4. Select the evaluation date in the `evaluation_date` field.
5. Enter the performance area in the `performance_area` field.
6. Select the evaluation date in the `evaluation_date` field.
7. Enter your name in the `manager_name` field.
8. Enter your title in the `manager_title` field.
9. Enter the evaluation score in the `evaluation_score` field.
10. Enter your comments in the `evaluation_comments` field.
11. Select the approval status in the `approval_status` field.
12. Enter your name in the `submitted_by` field.
13. Select the submitted date in the `submitted_date` field.
14. Select performance categories in the `performance_category` field (if applicable).
15. Select performance levels in the `performance_level` field (if applicable).
16. Select performance frequency in the `performance_frequency` field (if applicable).
17. Select the performance status in the `performance_status` field.
18. Enter performance status note in the `performance_status_note` field.
19. Select the performance status note date in the `performance_status_note_date` field.
20. Select the performance status note time in the `performance_status_note_time` field.
21. Enter performance status note category in the `performance_status_category` field (if applicable).

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, `text`, required): Enter the name of the employee being evaluated.
* **Job Title** (`job_title`, `text`, required): Enter the job title of the employee being evaluated.
* **Evaluation Date** (`evaluation_date`, `date`, required): Select the date for the performance evaluation.
* **Performance Area** (`performance_area`, `text`, required): Enter a description of the performance area being evaluated.
* **Evaluation Date** (`evaluation_date`, `date`, required): Select the date for the performance evaluation.
* **Manager Name** (`manager_name`, `text`, required): Enter your name as the manager performing the evaluation.
* **Manager Title** (`manager_title`, `text`, required): Enter your title as the manager performing the evaluation.
* **Evaluation Score** (`evaluation_score`, `number`, required): Enter a score for the performance evaluation.
* **Evaluation Comments** (`evaluation_comments`, `text`, required): Enter any comments you have regarding the evaluation.
* **Manager Comments** (`manager_comments`, `text`, required): Enter any comments you have regarding the evaluation.
* **Approval Status** (`approval_status`, `select_one`, required): Select the status of the approval, such as Approved, Denied, Pending, or In Progress.
* **Submitted By** (`submitted_by`, `text`, required): Enter your name as the person submitting the evaluation.
* **Submitted Date** (`submitted_date`, `date`, required): Select the date the evaluation was submitted.
* **Performance Category** (`performance_category`, `select_multiple`, optional): Select one or more performance categories, such as Category1, Category2, Category3, Category4.
* **Performance Level** (`performance_level`, `select_multiple`, required): Select one or more performance levels, such as Level1, Level2, Level3.
* **Performance Frequency** (`performance_frequency`, `select_multiple`, required): Select one or more performance frequencies, such as Frequency1, Frequency2, Frequency3.
* **Performance Status** (`performance_status`, `select_one`, required): Select the performance status, such as Status 1, Status 2, Status 3.
* **Performance Status Note** (`performance_status_note`, `text`, required): Enter any additional information regarding the performance status.
* **Performance Status Note Date** (`performance_status_note_date`, `date`, required): Select the date for the performance status note.
* **Performance Status Note Time** (`performance_status_note_time`, `time`, required): Select the time for the performance status note.
* **Performance Status Category** (`performance_status_category`, `text`, optional): Enter any category related to the performance status.
* **Performance Status Note Category** (`performance_status_note_category`, `text`, optional): Enter any category related to the performance status note.
* **Performance Status Note Frequency** (`performance_status_note_frequency`, `text`, optional): Enter any frequency related to the performance status note.
* **Assigned Tool** (`assigned_tool`, `text`, required): Enter the tool assigned to the performance evaluation.

## Tips
* Make sure to fill out all required fields before submitting the form.
* Double-check the information entered before submitting the form.
* If you are unsure about any field, consult your supervisor or the performance review system administrator.
