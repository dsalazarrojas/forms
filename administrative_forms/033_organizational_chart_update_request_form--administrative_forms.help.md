# Organizational Chart Update Request Form - Help Guide
## Purpose
The Organizational Chart Update Request Form is used to request updates to the company's organizational structure.

## How To Complete This Form
Follow the steps outlined above to complete the form.

## Field-by-Field Explanation
* **New Hire** (`page_1`, select_multiple, optional): Check this box if you are requesting a new hire.
* **New Hire Department** (`new_hire_department`, select_one, optional): Select the department of the new hire.
* **Reporting Manager** (`reporting_manager`, select_one, optional): Choose the manager for the new hire or change.
* **Reporting Team** (`reporting_team`, select_one, optional): Select whether the new hire will report to a team.
* **Reporting Team Name** (`reporting_team_name`, text, optional): If selecting "Yes" for "Reporting Team", provide the name of the team.
* **Position** (`position`, select_one, optional): Select the position of the new hire or changed employee.
* **Reporting Level** (`reporting_level`, select_multiple, optional): Select the reporting level of the new hire or changed employee.
* **Reporting Level Name** (`reporting_level_name`, text, optional): If selecting "High" or "Low" for "Reporting Level", provide a brief description of the reporting level.
* **Reason for Change** (`reason_for_change`, text, optional): Provide a brief explanation for the change.
* **Manager Name** (`manager_name`, text, optional): Enter the name of the manager affected by the change.
* **Manager Email** (`manager_email`, email, optional): Enter the email address of the manager affected by the change.
* **Effective Date** (`effective_date`, date, optional): Enter the effective date of the change.
* **End Date** (`end_date`, date, optional): Enter the end date of the change, if applicable.
* **Comments** (`comments`, note, optional): Provide any additional comments about the change.

## Tips
* Please make sure to complete all necessary fields to ensure accurate processing of your request.
* If you are unsure about any question, please ask your manager or HR representative for clarification.
* Make sure to proofread your form for accuracy and completeness before submitting it.
