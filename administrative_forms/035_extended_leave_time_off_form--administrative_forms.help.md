# extended_leave_time_off_form - Help Guide

## Purpose
The Extended Leave Time Off Form is a document used to request an extended leave of absence from work. This form is typically used by employees to submit a formal request for a leave of absence, which may be due to illness, family and medical reasons, bereavement, or other valid circumstances. The form is intended to provide a standardized and structured approach to requesting leave, ensuring that all necessary information is provided and that the request is evaluated fairly and consistently.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the employee's name in the "Employee Name" field.
2. Select the correct job title from the "Job Title" dropdown menu.
3. Input the start date of the leave in the "Start Date" field.
4. Input the end date of the leave in the "End Date" field.
5. Enter the duration of the leave in days in the "Leave Duration" field.
6. Enter the reason for the leave in the "Leave Reason" field.
7. Enter the date the employee plans to return to work in the "Return to Work Date" field.
8. Select the type of leave from the "Leave Type" dropdown menu.
9. Select the status of the leave from the "Leave Status" dropdown menu.
10. If necessary, enter any comments or remarks in the "Comments" field.
11. Enter the manager's comments in the "Manager Comments" field.
12. Select whether the request has been approved or not by the approver in the "Approver" field.
13. Select the department for the leave request in the "Department" field.
14. If necessary, enter any notes from the approver in the "Approver Notes" field.

## Field-by-Field Explanation

* **Employee Name (1)**: This field is for the employee's name who is requesting the leave. Enter the employee's full name as it appears on their ID card or personnel file.
* **Job Title (2)**: Select the correct job title from the dropdown menu that corresponds to the employee's job position.
* **Leave Start Date (3)**: This field is for the start date of the leave. Enter the date the employee wishes to begin their leave in the format MM/DD/YYYY.
* **Leave End Date (4)**: This field is for the end date of the leave. Enter the date the employee wishes to end their leave in the format MM/DD/YYYY.
* **Leave Duration (5)**: This field is for the duration of the leave in days. Enter the number of days the employee wishes to be on leave.
* **Leave Reason (6)**: This field is for the reason the employee is requesting leave. Enter a brief description of the reason for the leave.
* **Return to Work Date (7)**: This field is for the date the employee plans to return to work. Enter the date the employee expects to return to work in the format MM/DD/YYYY.
* **Leave Type (8)**: Select the type of leave from the dropdown menu that corresponds to the employee's request. Options include Vacation, Sick, Bereavement, and Family and Medical.
* **Leave Status (9)**: Select the status of the leave from the dropdown menu that corresponds to the current state of the request. Options include Pending, Approved, and Denied.
* **Comments (10)**: If necessary, enter any comments or remarks related to the leave request.
* **Manager Comments (11)**: If necessary, enter any comments or remarks from the manager related to the leave request.
* **Approver (12)**: Select whether the request has been approved or not by the approver.
* **Department (13)**: Select the department for the leave request.
* **Approver Notes (14)**: If necessary, enter any notes from the approver related to the leave request.
