# pharmaceutical_stock_validation_form - Help Guide
## Purpose
The pharmaceutical stock validation form is used to validate the stock of pharmaceutical products. It helps in ensuring that the stock is up-to-date and accurate, and that the products are available for use.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully before filling it out.
2. Read each field carefully and understand its purpose.
3. Fill in the required fields with the correct information.

## Field-by-Field Explanation
- **Form Header**: (`form_header`, note, required: false) This is a note that provides a description of the form. Please read it carefully before filling out the form.
- **Stock Type**: (`stock_type`, select_one, required: false) This field asks if the stock is valid or not. Select "Yes" if the stock is valid, and "No" if it's not.
- **Product Info**: (`product_info`, select_multiple, required: false) This field allows you to select multiple products that are part of the stock. Select all the products that apply.
- **Stock Status**: (`stock_status`, select_one, required: false) This field asks for the current status of the stock. Select "Active" if the stock is active, and "Inactive" if it's not.
- **Expiration Date**: (`expiration_date`, date, required: false) This field is used to enter the expiration date of the stock. Enter the date in the correct format (DD/MM/YYYY).

## Tips
* Make sure to fill in all the required fields accurately and completely.
* Review the form carefully before submitting it.
* If you're unsure about any field, ask for help.
