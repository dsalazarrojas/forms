# incident_report_information_form - Help Guide
## Purpose
The incident report form is used to collect information about incidents that have occurred within the organization. This form helps in gathering relevant details to facilitate the investigation and resolution of incidents.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the date and time of the incident in the "Incident Date" field, if applicable.
2. Provide the time of the incident in the "Incident Time" field, if applicable.
3. Enter the location of the incident in the "Incident Location" field.
4. Select the type of incident that occurred from the "Incident Type" dropdown menu. This will help in categorizing and prioritizing the incident.
5. Describe the incident in the "Incident Description" field.

## Field-by-Field Explanation
* **Incident Date** (`incident_date`, date): Enter the date of the incident. Use the calendar icon to select the date.
* **Incident Time** (`incident_time`, time): Enter the time of the incident. Use the clock icon to select the time.
* **Incident Location** (`incident_location`, text): Enter the location where the incident occurred.
* **Incident Type** (`incident_type`, select_one): Select one of the following options:
	+ Yes
	+ No
* **Incident Description** (`incident_description`, text): Describe the incident in as much detail as possible, including what happened and any actions taken.
