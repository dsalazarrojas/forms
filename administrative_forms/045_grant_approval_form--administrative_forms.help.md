# Grant Approval Form - Help Guide
## Purpose
The Grant Approval Form is used to gather and process grant proposals. It's essential for grant applicants to submit accurate and complete information to enable timely and effective processing.

## How To Complete This Form
1. Review each field carefully and ensure accuracy and completeness.
2. Enter all required fields (marked with an asterisk *).

## Field-by-Field Explanation
* **grant_approval_form** (`grant_approval_form`, text, optional): 
	+ A text field for entering any additional comments or information related to the grant proposal.
* **project_proposal** (`project_proposal`, text, optional): 
	+ A text field for providing a brief overview of the project being proposed.
* **budget** (`budget`, number, optional): 
	+ A numerical field for inputting the budget for the project.
* **grant_timeline** (`grant_timeline`, time, optional): 
	+ A date and time field for scheduling the grant approval.
* **grant_amount** (`grant_amount`, select_multiple, optional): 
	+ Select one or more options for the grant amount.
	+ Options: Option 1, Option 2, Option 3.
* **grant_start_date** (`grant_start_date`, date, required): 
	+ A date field for entering the project start date.
* **grant_end_date** (`grant_end_date`, date, required): 
	+ A date field for entering the project end date.
* **grant_frequency** (`grant_frequency`, select_one, optional): 
	+ A select-one field for selecting the grant frequency.
	+ Options: Option 1, Option 2, Option 3.
* **grant_total** (`grant_total`, select_one, optional): 
	+ A select-one field for selecting the grant total.
	+ Options: Option 1, Option 2, Option 3.
* **grant_status** (`grant_status`, select_one, optional): 
	+ A select-one field for selecting the grant status.
	+ Options: Option 1, Option 2, Option 3.
* **grant_note** (`grant_note`, text, optional): 
	+ A text field for adding any additional notes.
* **grant_contact_email** (`grant_contact_email`, email, required): 
	+ An email field for entering the grant contact's email address.
* **grant_contact_phone** (`grant_contact_phone`, text, required): 
	+ A text field for entering the grant contact's phone number.
* **grant_organization** (`grant_organization`, text, required): 
	+ A text field for entering the grant organization's name.
* **grant_address** (`grant_address`, text, required): 
	+ A text field for entering the grant address.
* **grant_city** (`grant_city`, text, required): 
	+ A text field for entering the grant city.
* **grant_state** (`grant_state`, text, required): 
	+ A text field for entering the grant state.
* **grant_zip** (`grant_zip`, text, required): 
	+ A text field for entering the grant zip code.
* **grant_country** (`grant_country`, text, required): 
	+ A text field for entering the grant country.
* **grant_region** (`grant_region`, text, required): 
	+ A text field for entering the grant region.
* **grant_currency** (`grant_currency`, text, required): 
	+ A text field for entering the grant currency.
* **grant_currency_symbol** (`grant_currency_symbol`, text, required): 
	+ A text field for entering the grant currency symbol.
* **grant_application_fee** (`grant_application_fee`, number, required): 
	+ A numerical field for inputting the grant application fee.
* **grant_payment_terms** (`grant_payment_terms`, select_one, optional): 
	+ A select-one field for selecting the grant payment terms.
	+ Options: Option 1, Option 2, Option 3.
* **grant_additional_info** (`grant_additional_info`, text, optional): 
	+ A text field for entering any additional grant information.

## Tips
* Always review each field carefully before submitting the form.
* Ensure all required fields are filled out accurately and completely.
* Use the correct format for date fields (dd/mm/yyyy).
