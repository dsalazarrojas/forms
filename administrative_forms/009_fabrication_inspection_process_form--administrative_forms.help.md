# Fabrication Inspection Process Form - Help Guide
## Purpose
The Fabrication Inspection Process Form is used to record and document the fabrication inspection process for a specific manufacturing site and equipment type. This form is essential for ensuring that the fabrication process is accurately and comprehensively inspected, and any issues or discrepancies are captured for reference and improvement purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Start by selecting the Manufacturing Site from the text field.
2.  Select the correct Equipment Type from the dropdown list.
3.  Enter the Fabrication Process, providing a brief description of the process.
4.  Enter the Inspection Date, using the date picker to ensure accuracy.
5.  Enter the name of the Inspector conducting the inspection.
6.  Optionally, provide additional Fabrication Inspection Process Notes if needed.

## Field-by-Field Explanation
* **Manufacturing Site**: 
	+ This field is used to enter the name of the manufacturing site where the fabrication took place.
	+ Please type in the name of the site.
* **Equipment Type**: 
	+ Select the type of equipment used during the fabrication process, e.g., CNC Machine, Manual, or Other.
	+ This field is required.
* **Fabrication Process**: 
	+ Enter a brief description of the fabrication process, including any relevant details or notes.
	+ This field is not required.
* **Inspection Date**: 
	+ Use the date picker to select the date of inspection.
	+ This field is required.
* **Inspector Name**: 
	+ Enter the name of the person conducting the inspection.
	+ This field is required.
* **Fabrication Inspection Process Notes**: 
	+ Provide any additional notes or comments about the inspection process.
	+ This field is not required.

## Tips
* Please ensure that the Manufacturing Site field is accurate and relevant to the inspection location.
* When selecting Equipment Type, choose the option that best describes the equipment used.
* For Fabrication Inspection Process Notes, provide any necessary details or observations for reference and improvement.
