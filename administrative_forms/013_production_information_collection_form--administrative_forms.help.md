# Production Information Collection Form - Help Guide
## Purpose
This form is used to collect production information for a specific product or project. It helps gather essential details about the manufacturing team, project manager, product type, production capacity, and other relevant information. This form is a crucial tool for production planning and coordination.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information before starting.
2. Fill in the required fields, indicated by an asterisk (\*).
3. For select_one fields (manufacturing_team, project_manager, product_type), select the relevant option.
4. Enter the production data in the production_data field.
5. Enter the production capacity in the production_capacity field.
6. If applicable, fill in the production_time field.
7. Add any additional notes in the notes field (optional).

## Field-by-Field Explanation
* **Production Information** (`production_information_collection_form_fields`, text, required/optional): This field is where you should enter a brief description of the production process.
* **Manufacturing Team** (`manufacturing_team`, select_one, required): This field indicates whether a manufacturing team is involved in the production process. Select 'Yes' if a team is involved, and 'No' otherwise.
* **Project Manager** (`project_manager`, select_one, required): This field indicates whether a project manager is involved in the production process. Select 'Yes' if a manager is involved, and 'No' otherwise.
* **Production Data** (`production_data`, text, required): This field is used to enter specific production data relevant to the product or project.
* **Product Type** (`product_type`, select_one, required): This field is used to select the type of product being produced.
* **Production Capacity** (`production_capacity`, number, required): This field is used to enter the production capacity, which is the maximum amount of a product that can be produced within a given timeframe.
* **Production Time** (`production_time`, time, optional): This field is used to enter the time required for production.
* **Notes** (`notes`, note, optional): This field is used to add any additional notes or comments about the production process.

## Tips
* Ensure you provide accurate and complete information for all required fields.
* Double-check your answers before submitting the form.
* If you have any questions or concerns, please contact the production team for assistance.
