# Construction Punch List - Help Guide
## Purpose
The Construction Punch List form is used to collect and track issues or deficiencies found during the construction process. It captures information about each item, including location, description, trade responsible, priority, status, and completion deadline.

## How To Complete This Form

1. Fill out the form with the required information.
2. Complete the "Punch List Date" field with the date the punch list is created.
3. Fill out the "Project Name" field with the name of the construction project.
4. Enter the "Project Address" and "Project Number" fields with the project's location and reference number.
5. Identify the "General Contractor" and "Client Name" fields with the primary and client's names, respectively.
6. Complete the "Prepared By" field with the name of the person creating the punch list.
7. Complete the "Additional Punch List Items" field with any other items that need to be addressed.
8. Count and enter the total number of items in the "Total Number of Items" field.
9. Enter the "Completion Deadline" field with the expected completion date for all punch list items.
10. Sign and date the form in the "Inspector Signature" and "Contractor Signature" fields.

## Field-by-Field Explanation

* **Punch List Date** (`punch_list_date`, date, required): Enter the date the punch list is created.
* **Project Name** (`project_name`, text, required): Enter the name of the construction project.
* **Project Address** (`project_address`, text, required): Enter the full site address.
* **Project Number** (`project_number`, text, optional): Enter the project reference number.
* **General Contractor** (`general_contractor`, text, required): Enter the primary contractor company name.
* **Client Name** (`client_name`, text, required): Enter the project owner or client name.
* **Prepared By** (`prepared_by`, text, required): Enter the name of the person creating the punch list.
* **Item 1 Location** (`punch_item_1_location`, text, required): Enter the location of the first issue.
* **Item 1 Description** (`punch_item_1_description`, text, required): Describe the first issue or deficiency.
* **Item 1 Trade Responsible** (`punch_item_1_trade`, select_one, required): Select the trade responsible for fixing the first issue.
* **Item 1 Priority** (`punch_item_1_priority`, select_one, required): Select the priority level of the first issue.
* **Item 1 Status** (`punch_item_1_status`, select_one, required): Select the current status of the first issue.
* **Item 2 Location** (`punch_item_2_location`, text, optional): Enter the location of the second issue.
* **Item 2 Description** (`punch_item_2_description`, text, optional): Describe the second issue or deficiency.
* **Item 2 Trade Responsible** (`punch_item_2_trade`, select_one, optional): Select the trade responsible for fixing the second issue.
* **Item 2 Priority** (`punch_item_2_priority`, select_one, optional): Select the priority level of the second issue.
* **Item 2 Status** (`punch_item_2_status`, select_one, optional): Select the current status of the second issue.
* **Additional Punch List Items** (`additional_items`, text, optional): Describe any other items that need attention.
* **Total Number of Items** (`total_items_count`, number, required): Count and enter the total number of items.
* **Completion Deadline** (`completion_deadline`, date, required): Enter the expected completion date for all punch list items.
* **Reinspection Date** (`reinspection_date`, date, optional): Enter the date for follow-up inspection.
* **Special Instructions** (`special_instructions`, text, optional): Enter any specific requirements for completing items.
* **Contractor Acknowledgment** (`contractor_acknowledgment`, select_one, required): Select whether the contractor acknowledges and accepts this punch list.
* **Contractor Comments** (`contractor_comments`, text, optional): Enter any comments or concerns from the contractor.
* **Client Approval** (`client_approval`, select_one, required): Select whether the client approves this punch list.
* **Inspector Signature** (`inspector_signature`, text, required): Sign and date the form with your full name.
* **Contractor Signature** (`contractor_signature`, text, required): Sign and date the form with your full name.

## Tips
* Make sure to complete all required fields.
* Double-check that you have entered accurate information for each field.
* Review and edit the form before submitting it.
* Ensure that all necessary signatures are included.
* Keep a record of completed punch lists for future reference.
* Use this form to communicate with all stakeholders and ensure that everyone is on the same page.
