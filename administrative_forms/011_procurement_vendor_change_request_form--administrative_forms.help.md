# Procurement Vendor Change Request Form - Help Guide

## Purpose
This form is used to request changes to procurement vendors. It's essential to provide accurate and up-to-date information to ensure that procurement changes are processed correctly and efficiently. Please fill out this form carefully and thoroughly, and submit it only after careful consideration.

## How To Complete This Form
To complete this form, follow these steps:

1.  On the "Request Details" page, select the appropriate option from the dropdown menu for "Vendor ID". This field is used to identify the vendor associated with the change request.
2.  Provide a clear and concise reason for the change in the "Reason For Change" field. This will help the procurement team understand the justification behind the request.
3.  Enter the date and time of the change in the "Change Date" and "Change Time" fields, respectively. If the change is not time-sensitive, you can leave these fields blank.
4.  Select the procurement contact and team members involved in the change request from the dropdown menus for "Procurement Contact ID" and "Procurement Team ID", respectively. These fields are not mandatory, so you can leave them blank if not applicable.
5.  Indicate whether the change affects the procurement vendor by selecting "Yes" or "No" in the "Procurement Vendor ID" field.
6.  Choose the type of request from the dropdown menu for "Request Type". This field is used to categorize and process the change request.
7.  Add any additional notes or comments in the "Notes" field, if necessary.
8.  Select the status of the review from the dropdown menu for "Review Status" to indicate whether the request is pending, approved, or rejected.

## Field-by-Field Explanation

* **Vendor ID** (1): Select the vendor ID of the vendor associated with the change request.
* **Reason For Change** (3): Provide a clear and concise reason for the change.
* **Change Date** (4): Enter the date of the change.
* **Change Time** (5): Enter the time of the change.
* **Procurement Contact ID** (6): Select the procurement contact involved in the change request (optional).
* **Procurement Team ID** (7): Select the procurement team members involved in the change request (optional).
* **Procurement Vendor ID** (8): Indicate whether the change affects the procurement vendor (Yes/No).
* **Request Type** (9): Choose the type of request from the dropdown menu.
* **Notes** (10): Add any additional notes or comments about the request.
* **Submitted By** (11): Select the person submitting the request (optional).
* **Submitted Date** (12): Enter the date the request was submitted.
* **Submitted Time** (13): Enter the time the request was submitted.
* **Review Status** (14): Select the status of the review (pending, approved, or rejected).
