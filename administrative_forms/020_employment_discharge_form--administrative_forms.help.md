# Employment Discharge Form - Help Guide
## Purpose
The purpose of this form is to document the details of an employee's discharge from their position. This form is used to gather information about the employee's termination, including the reason for discharge, termination date, and status.

## How To Complete This Form
1. Start by filling out the employee information section (employee-information) with the employee's details.
2. Next, select the reason for discharge from the provided options in the reason-for-discharge-select field. You can also provide additional information in the reason optional field.
3. Enter the termination date in the termination-date field.
4. Select the termination method (Voluntary or Involuntary) and status (Active, Inactive, Terminated, Retired) from the provided options in the termination-method and termination-status fields.
5. Provide any additional notes about the termination in the notes field.
6. Finally, sign and date the form.

## Field-by-Field Explanation
* **main-page**: This is the main page of the form. You will use this page to enter any additional information not specified in other fields.
* **employee-information**: Enter the employee's details such as name, ID number, department, etc.
* **termination-details**: Enter any additional details about the termination.
* **discharge-date**: Enter the date the employee was discharged.
* **reason-for-discharge**: Select the reason for discharge from the provided options (Disability, Retirement, Resignation, Other).
* **reason-for-discharge-select**: Select the reason for discharge from the provided options.
* **termination-method**: Select the termination method (Voluntary, Involuntary).
* **termination-date**: Enter the date of termination.
* **last-working-day**: Enter the last day the employee worked.
* **last-day**: Enter the last time the employee worked.
* **Reason For Discharge Select Optional**: Select whether the reason for discharge is Yes or No.
* **Reason**: Enter any additional reason for discharge.
* **manager-acknowledgement**: Select whether the manager acknowledges the termination (Yes, No).
* **termination-status**: Select the status of the termination (Active, Inactive, Terminated, Retired).
* **notes**: Enter any additional notes about the termination.
* **employee-signature**: Enter the employee's signature.
* **manager-signature**: Enter the manager's signature.
* **date-signed**: Enter the date the form was signed.
* **Manager Acknowledgement Optional**: Select whether the manager acknowledges the termination (Yes, No).
* **Termination Status Optional**: Select the status of the termination (Active, Inactive).
* **Notes Optional**: Enter any additional notes about the termination.
* **Employee Signature Optional**: Enter the employee's signature.
* **Date Signed Optional**: Enter the date the form was signed.
* **Manager Signature Optional**: Enter the manager's signature.
* **Date Signed Optional 2**: Enter the date the form was signed again.
