# Job Description Revision Request Form - Help Guide

## Purpose
The Job Description Revision Request Form is used to request updates to an existing job description. This form is used to gather information about the job title, job category, and the reason for the update, allowing HR and management teams to efficiently review and process job description revisions.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Choose the category of the job you are requesting the revision for (Administrative, Technical, or Other).
2.  Enter the title of the job you are requesting the revision for.
3.  Briefly describe the job description you are requesting changes to.
4.  Briefly describe the changes you are requesting to be made to the job description.
5.  Enter the reason for the update.
6.  Enter the date and time you need to receive a response to this request.
7.  Enter your name and email address so we can contact you about this request.
8.  Enter your phone number so we can contact you about this request.

## Field-by-Field Explanation

* **Job Description Revision Request**: 
  *   Type: note
  *   This field is a free-form text field where you can enter a brief description of the job description you are requesting changes to.
* **Category**: 
  *   Type: select_one
  *   This field is used to select the category of the job you are requesting the revision for (Administrative, Technical, or Other).
* **Job Title**: 
  *   Type: text
  *   This field is used to enter the title of the job you are requesting the revision for.
* **Job Description**: 
  *   Type: text
  *   This field is used to briefly describe the job description you are requesting changes to.
* **Category**: 
  *   Type: select_one
  *   This field is used to select the category of the job you are requesting the revision for (Administrative, Technical, or Other).
*   (Duplicate of Category field, not used)
* **Role**: 
  *   Type: text
  *   This field is used to briefly describe the role you are requesting changes to.
* **Current Responsibilities**: 
  *   Type: text
  *   This field is used to briefly describe the current job responsibilities.
* **Update Responsibilities**: 
  *   Type: text
  *   This field is used to briefly describe the changes you are requesting to be made to the job description.
*   (This field is marked as required, but no other field is marked as required in this form)
* **Reason for Update**: 
  *   Type: text
  *   This field is used to briefly describe the reason for the update.
* **Date Required**: 
  *   Type: date
  *   This field is used to enter the date you need to receive a response to this request.
* **Time Required**: 
  *   Type: time
  *   This field is used to enter the time you need to receive a response to this request.
* **Submitted By**: 
  *   Type: text
  *   This field is used to enter your name so we can contact you about this request.
* **Submitted By Email**: 
  *   Type: email
  *   This field is used to enter your email address so we can contact you about this request.
* **Submitted By Phone**: 
  *   Type: text
  *   This field is used to enter your phone number so we can contact you about this request.

## Tips
* Please ensure that you have a valid email address and phone number entered in the "Submitted By" fields so we can contact you about this request.
* If you have any questions or concerns about this form, please contact us.
