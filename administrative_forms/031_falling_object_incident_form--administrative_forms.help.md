# falling_object_incident_form - Help Guide

## Purpose

The Falling Object Incident Form is designed to document and report incidents where objects fall from a certain height. This form helps to gather necessary information for investigation and resolution.

## How To Complete This Form

1. Fill in the required fields:
	* `incident_date` (date of the incident)
	* `incident_time` (time of the incident)
	* `location` (location of the incident)
2. Provide a detailed description of the incident in the `incident_description` field.
3. Specify the type of object that fell in the `falling_object_type` field.
4. Enter the weight of the object that fell in the `falling_object_weight` field.
5. Describe the position of the object when it fell in the `object_position` field.
6. Provide any additional relevant details in the `location_details` field.

## Field-by-Field Explanation

* **Incident Description**: Enter a detailed description of what happened during the incident.
* **Incident Location**: Enter the location where the incident occurred.
* **Incident Date**: Enter the date of the incident.
* **Incident Time**: Enter the time of the incident.
* **Falling Object Type**: Specify the type of object that fell.
* **Falling Object Weight**: Enter the weight of the object that fell.
* **Object Position**: Describe where the object was when it fell.
* **Location Details**: Provide any additional details about the location where the incident occurred.
* **Incident Description**: Enter a detailed description of what happened during the incident (this field is optional).
* **Location Details**: This field is optional and can be used to provide additional context about the incident location.
