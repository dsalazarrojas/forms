# Rescue Operation Checklist Form - Help Guide
## Purpose
The Rescue Operation Checklist Form is designed to collect information and track the progress of rescue operations. It helps teams and individuals involved in rescue operations to keep track of the team members, resources, and details of the rescue operation. This form is used to document the team's performance and ensure that all necessary steps are taken during the rescue operation.
## How To Complete This Form
To complete the form, follow these steps:

1.  Review each page carefully and complete the form fields as instructed.
2.  Begin with the Introduction page, which provides an overview of the form and its purpose.
3.  On the Team Leader page, select the team leader from the options provided.
4.  On the Team Assist page, list the team members assisting the team leader.
5.  On the Rescue Team page, select the type of rescue team (e.g., Rescue Team, Other team, Self).
6.  On the Resources page, list any available resources that the team has.
7.  On the Notes page, provide any additional notes about the rescue operation.
8.  On the Contact Information page, list the contact information of the team members and other relevant stakeholders.
9.  On the Rescue Operation page, select the type of rescue operation (e.g., Rescue, Evacuation, Search).
10.  On the Status page, update the status of the rescue operation (e.g., Completed, In Progress, Pending).
11.  On the Comments page, provide any additional comments about the rescue operation.

## Field-by-Field Explanation

* **Introduction** (Page 1):
	+ Type: Text
	+ Required: No
	+ This page provides an overview of the form and its purpose. Please review it carefully before proceeding.
* **Team Leader** (Page 2):
	+ Type: Text
	+ Required: No
	+ This field is for selecting the team leader who is leading the rescue operation.
* **Team Assist** (Page 3):
	+ Type: Select Multiple
	+ Required: No
	+ This field is for listing the team members who are assisting the team leader. Select all members who are involved in the rescue operation.
* **Rescue Team** (Page 4):
	+ Type: Select One
	+ Required: No
	+ This field is for selecting the type of rescue team. Choose from the options: Rescue Team, Other team, Self.
* **Resources** (Page 5):
	+ Type: Text
	+ Required: No
	+ This field is for listing any available resources that the team has. This can include equipment, personnel, or other assets.
* **Notes** (Page 6):
	+ Type: Note
	+ Required: No
	+ This field is for providing any additional notes about the rescue operation. This can include details about the situation, challenges, or lessons learned.
* **Contact Information** (Page 7):
	+ Type: Text
	+ Required: No
	+ This field is for listing the contact information of the team members and other relevant stakeholders.
* **Rescue Operation** (Page 8):
	+ Type: Select One
	+ Required: No
	+ This field is for selecting the type of rescue operation. Choose from the options: Rescue, Evacuation, Search.
* **Status** (Page 9):
	+ Type: Select One
	+ Required: No
	+ This field is for updating the status of the rescue operation. Choose from the options: Completed, In Progress, Pending.
* **Comments** (Page 10):
	+ Type: Text
	+ Required: No
	+ This field is for providing any additional comments about the rescue operation.

## Tips
* Always review each page carefully before proceeding.
* Be sure to select the correct options from the drop-down menus.
* Use the available resources field to list any relevant assets or equipment.
* Keep the comments field for any additional notes or comments about the rescue operation.
* Use this form for tracking the progress of rescue operations and ensuring that all necessary steps are taken.
