# Child Safety Checklist Form - Help Guide
## Purpose
This form is designed to help parents or guardians ensure the safety of their child in their home environment.

## How To Complete This Form

1. Review each question carefully and answer based on your knowledge of the home environment.
2. Answer "Yes" or "No" for questions that have a clear "Yes" or "No" answer.
3. For questions that have "Select One" options, choose the most accurate answer based on your assessment.
4. If you are unsure about any question, choose "Unsure" or "Not Applicable" as needed.
5. In the "Safety Concerns Identified" section, list any potential safety concerns that you think may exist in the home.
6. In the "Action Plan" section, describe the steps you will take to address any safety concerns you have identified.

## Field-by-Field Explanation

* **Checklist Date** (ID: 1):
	+ This is the date you completed the safety checklist.
* **Parent or Guardian First Name** (ID: 2):
	+ Enter your first name as it appears on your identification.
* **Parent or Guardian Last Name** (ID: 3):
	+ Enter your last name as it appears on your identification.
* **Child First Name** (ID: 4):
	+ Enter the child's first name as it appears on their identification.
* **Child Last Name** (ID: 5):
	+ Enter the child's last name as it appears on their identification.
* **Child Age** (ID: 6):
	+ Enter the child's current age in years.
* **Environment Type** (ID: 7):
	+ Choose the type of environment you are evaluating (e.g., home interior, home exterior, daycare or school, etc.).
* **Smoke Detectors Present** (ID: 8):
	+ Answer "Yes" if smoke detectors are installed and functioning, "No" if not.
* **Smoke Detectors Tested** (ID: 9):
	+ Answer "Yes" if smoke detectors have been tested in the last month, "No" if not.
* **Carbon Monoxide Detector** (ID: 10):
	+ Answer "Yes" if a carbon monoxide detector is installed and functioning, "No" if not.
* **Fire Extinguisher Available** (ID: 11):
	+ Answer "Yes" if a fire extinguisher is accessible, "No" if not.
* **Electrical Outlets Covered** (ID: 12):
	+ Answer "Yes" if all unused electrical outlets are covered with safety caps, "No" if not.
* **Electrical Cords Secured** (ID: 13):
	+ Answer "Yes" if all electrical cords are secured and out of reach, "No" if not.
* **Chemicals and Cleaning Supplies Secured** (ID: 14):
	+ Answer "Yes" if chemicals and cleaning supplies are stored safely, "No" if not.
* **Medications Secured** (ID: 15):
	+ Answer "Yes" if all medications are stored out of child's reach, "No" if not.
* **Sharp Objects Secured** (ID: 16):
	+ Answer "Yes" if sharp objects (e.g., knives, scissors) are stored safely, "No" if not.
* **Heavy Furniture Anchored** (ID: 17):
	+ Answer "Yes" if heavy furniture (e.g., bookshelves) is anchored to walls, "No" if not.
* **Window Guards Installed** (ID: 18):
	+ Answer "Yes" if windows are equipped with safety guards or stops, "No" if not.
* **Stair Gates Installed** (ID: 19):
	+ Answer "Yes" if stair gates are installed, "No" if not.
* **Water Temperature Set Safely** (ID: 20):
	+ Answer "Yes" if the water heater is set to 120 degrees Fahrenheit or below, "No" if not.
* **Pool Safety Measures** (ID: 21):
	+ Answer based on the specific safety measures in place for the pool (e.g., fenced with self-latching gate, pool cover, alarm system).
* **Choking Hazards Removed** (ID: 22):
	+ Answer "Yes" if all chocking hazards are removed, "No" if not.
* **Emergency Numbers Posted** (ID: 23):
	+ Answer "Yes" if emergency contact numbers are posted and easily accessible, "No" if not.
* **First Aid Kit Available** (ID: 24):
	+ Answer "Yes" if a first aid kit is accessible, "No" if not.
* **Safety Concerns Identified** (ID: 25):
	+ If any safety concerns are identified, list them here.
* **Action Plan** (ID: 26):
	+ Describe the steps you will take to address any identified safety concerns.

## Tips

* Answer all questions honestly based on your assessment of the home environment.
* If unsure about any question, choose "Unsure" or "Not Applicable" as needed.
* Take notes or create an action plan to address any identified safety concerns.
* Review and update this form regularly to ensure the home environment remains safe for children.
