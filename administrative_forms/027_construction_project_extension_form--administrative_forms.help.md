# Construction Project Extension Form - Help Guide
## Purpose
The Construction Project Extension Form is a tool used to request an extension to a construction project. This form is designed to gather necessary information about the project and the reasons for the extension request.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and detailed information.
2. Provide a clear and concise explanation for each field.
3. Ensure that all necessary supporting documentation is attached or ready for review.

## Field-by-Field Explanation

* **Full Project Name** (`project_name`): Enter the full name of the project.
	+ This field is required and should be entered exactly as it appears on the project's official documentation.
* **Project ID or Number** (`project_id`): Enter the project's ID or number as it appears in the project's records.
	+ This field is required and should be entered accurately.
* **Original Contract Completion Date** (`original_contract_completion`): Enter the original completion date of the project.
	+ This field is required and should be entered exactly as it appears in the project's documentation.
* **Current (Revised) Completion Date** (`current_contract_completion`): Enter the current or revised completion date of the project.
	+ This field is not required but should be entered if applicable.
* **Requesting Party Name and Title** (`lead_requestor_name`): Enter the name and title of the project manager or team lead requesting the extension.
	+ This field is required and should be entered accurately.
* **Total Additional Calendar Days Requested** (`requested_extension_days`): Enter the total number of additional calendar days requested for the extension.
	+ This field is required and should be entered accurately.
* **Requested New Completion Date** (`requested_new_completion_date`): Enter the requested new completion date for the project.
	+ This field is required and should be entered exactly as it appears in the project's documentation.
* **Primary Reason for Extension** (`extension_reason_category`): Select the primary reason for the extension request from the provided options.
	+ This field is required and should be selected accurately.
* **Detailed Justification for Extension** (`detailed_justification`): Enter a detailed explanation of the events that led to the extension request.
	+ This field is required and should provide a clear and concise explanation.
* **Impact on Critical Path** (`critical_path_impact_desc`): Describe how the events affected the project's critical path.
	+ This field is required and should provide a clear and concise explanation.
* **Estimated Additional Costs Associated with Extension ($)** (`additional_costs_req`): Enter the estimated additional costs associated with the extension.
	+ This field is required and should be entered accurately.
* **Steps taken to Mitigate the Delay** (`mitigation_steps_taken`): Enter the steps taken to mitigate the delay.
	+ This field is required and should provide a clear and concise explanation.
* **Supporting Documentation Ready** (`supporting_docs_ready`): Select whether supporting documentation is ready for review.
	+ This field is required and should be selected accurately.
* **Additional Comments** (`additional_comments`): Enter any additional comments or information about the extension request.
	+ This field is not required but should be used to provide any additional context.
* **Date of Request Submission** (`submission_date`): Enter the date the form was submitted.
	+ This field is required and should be entered accurately.
* **Project Manager Approval Name** (`manager_approval_name_label`): Enter the name of the project manager who approved the extension request.
	+ This field is required and should be entered accurately.

## Tips

* Ensure that all necessary information is provided before submitting the form.
* Double-check the form for accuracy and completeness before submission.
* Review the form's instructions and requirements carefully to ensure a smooth review and approval process.
