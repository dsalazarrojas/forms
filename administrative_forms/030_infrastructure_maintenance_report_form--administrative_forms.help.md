# Infrastructure Maintenance Report Form - Help Guide
## Purpose
This form is used to report on infrastructure projects that require maintenance. It helps project managers and maintenance personnel to track and report on ongoing and upcoming maintenance activities. 

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the name of the infrastructure project you are reporting on in the "Infrastructure Project" field.
2.  Enter the location of the project in the "Project Location" field.
3.  Select the current status of the project from the "Project Status" dropdown menu.
4.  Enter the work order number or any other relevant information in the "Work Order" field.
5.  Describe the type of maintenance required in the "Maintenance Type" field.

## Field-by-Field Explanation

* **Infrastructure Project** (`infrastructure_project`, text, optional): Enter the name of the infrastructure project you are reporting on. This could be the name of the project as it appears in your project management system or the name of the building or equipment being maintained.
* **Project Location** (`project_location`, text, optional): Enter the location of the project, such as the address or the city and state where the project is located.
* **Project Status** (`project_status`, select_one, optional): Select the current status of the project. The options are "active" and "inactive". This field is used to indicate whether the project is currently being maintained or not.
* **Work Order** (`work_order`, text, optional): Enter the work order number or any other relevant information related to the project. This could be a unique identifier assigned to the project or any other details that need to be tracked.
* **Maintenance Type** (`maintenance_type`, text, optional): Describe the type of maintenance required for the project. This could be a brief description of the work needed, such as "electrical work" or "plumbing repair".
