# retirement_benefits_overview - Help Guide
## Purpose
The "retirement_benefits_overview" form is designed to collect relevant information about an employee's retirement benefits. This includes their eligibility and coverage details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you are filling out the form for the correct employee.
2. Select the relevant category for the retirement benefits.
3. Provide a brief description of the benefits.
4. Enter the form ID, if applicable.
5. If an assigned tool is present, enter its details.

## Field-by-Field Explanation
- **category**: Select 'Yes' if the employee has retirement benefits, 'No' otherwise.
- **description**: Enter a brief description of the employee's retirement benefits.
- **form_id**: Enter the unique ID of the form if you are filling out a paper-based form.
- **assigned_tool**: Enter the details of the assigned tool, if applicable.
