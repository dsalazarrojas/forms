# Insurance Coverage Limit Amendment Form - Help Guide
## Purpose
This form is used to amend the insurance coverage limit for a specific policy. Please use this form to update the coverage limit for an existing policy. This form should not be used for new policy applications.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the policyholder information and policy that the amendment is applicable to.
2. Enter the new coverage limit and effective date of the amendment.
3. Provide a reason for the change.
4. Sign and date the form as the agent and broker (if applicable).

## Field-by-Field Explanation
* **Policyholder Information** (Policyholder Information, text, optional):
	+ This field is used to capture the policyholder's name and contact information.
* **Coverage Limit** (Coverage Limit, number, optional):
	+ This field is used to enter the current coverage limit.
* **Policy** (Policy, select_one, optional):
	+ This field is used to select the policy that the amendment is applicable to.
* **New Coverage Limit** (New Coverage Limit, number, optional):
	+ This field is used to enter the new coverage limit.
* **Effective Date** (Effective Date, date, optional):
	+ This field is used to select the effective date of the amendment.
* **Agent Information** (Agent Information, text, optional):
	+ This field is used to capture the agent's name and contact information.
* **Agent Signature** (Agent Signature, note, optional):
	+ This field is for the agent's signature, indicating that they have reviewed and approved the changes.
* **Broker Information** (Broker Information, text, optional):
	+ This field is used to capture the broker's name and contact information.
* **Broker Signature** (Broker Signature, note, optional):
	+ This field is for the broker's signature, indicating that they have reviewed and approved the changes.
* **Reason for Change** (Reason for Change, text, optional):
	+ This field is used to enter a brief explanation for the coverage limit amendment.
* **Customer Signature** (Customer Signature, note, optional):
	+ This field is for the customer's signature, indicating that they have reviewed and approved the changes.

## Tips
- Please ensure that you are filling out this form for the correct purpose and not creating a duplicate policy.
- If you are not sure about the policy that the amendment is applicable to, please contact your broker or agent for assistance.
- Please sign and date the form as the agent and broker (if applicable), indicating that you have reviewed and approved the changes.
- This form should only be used to amend the coverage limit for an existing policy. If you are requesting a new policy, please use the new policy application form instead.
