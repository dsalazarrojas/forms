# Packing Materials Requisition Form - Help Guide
## Purpose
This form is used to request packing materials for shipping products. It is intended for use by warehouse or shipping personnel to provide detailed information about the materials needed for packaging and shipping.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the shipping location from the list of options.
2. Choose the type of material needed (e.g. cardboard, bubble mailer, paper towel).
3. Enter the quantity of material required.
4. Provide a brief description of the material needed.
5. Enter the shipping date and time.
6. If applicable, select the tool assigned to handle the packaging (e.g. forklift, hand truck).
7. Enter a unique identifier for the form (if required).
8. Select a category for the request (e.g. for inventory purposes).

## Field-by-Field Explanation
### Request Packing Materials
* **Request Packing Materials** (`request_packing_materials`, text, optional): This field is for entering a brief description of the reason for the request.
### Shipping Location
* **Shipping Location** (`shipping_location`, select_one, optional): This field is for selecting the location from which the materials will be shipped.
### Material Type
* **Material Type** (`material_type`, select_multiple, optional): This field is for choosing the type of material needed (e.g. cardboard, bubble mailer, paper towel).
### Quantity
* **Quantity** (`quantity`, number, optional): This field is for entering the amount of material required.
### Description
* **Description** (`description`, text, optional): This field is for providing additional details about the material needed.
### Shipping Date
* **Shipping Date** (`shipping_date`, date, optional): This field is for entering the date on which the materials are to be shipped.
### Shipping Time
* **Shipping Time** (`shipping_time`, time, optional): This field is for entering the time on which the materials are to be shipped.
### Assigned Tool
* **Assigned Tool** (`assigned_tool`, text, optional): This field is for selecting the tool used to handle the packaging (e.g. forklift, hand truck).
### Form ID
* **Form ID** (`form_id`, text, optional): This field is for entering a unique identifier for the form.
### Category
* **Category** (`category`, text, optional): This field is for selecting a category for the request (e.g. for inventory purposes).

## Tips
* Please ensure that you provide accurate and complete information in each field to ensure that your request is processed correctly.
* If you are unsure about any field, please ask your supervisor or team lead for guidance.
* This form is intended for internal use only, and sensitive information should not be entered into it.
