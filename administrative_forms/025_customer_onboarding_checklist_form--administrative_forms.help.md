# customer_onboarding_checklist_form - Help Guide
## Purpose
The customer onboarding checklist form is used to collect information about new clients. It is essential to ensure that you have all the necessary details to onboard a client successfully.

## How To Complete This Form
1. Please ensure that the client you are onboarding is indeed a new client.
2. Review each field carefully and fill in the required information.
3. If you are unsure about any field, you can ask your administrator for clarification.

## Field-by-Field Explanation

* **New Client Info** (1, text, required: false)
	+ This field is used to enter any relevant information about the new client.
* **Account Details** (2, text, required: false)
	+ This field is used to enter the client's account details, such as username, password, etc.
* **Tax Info** (3, text, required: false)
	+ This field is used to enter any tax-related information about the client.
* **Financial Info** (4, text, required: false)
	+ This field is used to enter any financial information about the client.
* **Contact Preferences** (5, text, required: false)
	+ This field is used to enter the client's contact preferences, such as phone number, email, etc.
* **Payment Info** (6, text, required: false)
	+ This field is used to enter any payment-related information about the client.
* **Tax ID Number** (7, text, required: false)
	+ This field is used to enter the client's tax ID number.
* **Address** (8, text, required: false)
	+ This field is used to enter the client's address.
* **Phone Number** (9, text, required: false)
	+ This field is used to enter the client's phone number.
* **Email** (10, email, required: false)
	+ This field is used to enter the client's email.
* **Date of Birth** (11, date, required: false)
	+ This field is used to enter the client's date of birth.
* **Time** (12, time, required: false)
	+ This field is used to enter the client's time.
* **Note** (13, note, required: false)
	+ This field is used to enter any additional notes about the client.
* **Select One Tax ID Number** (14, select_one, required: false)
	+ This field is used to select one tax ID number from the options provided.
	+ Options: tax id number, address, phone number, email, date of birth, time.
* **Select Multiple Tax ID Number** (15, select_multiple, required: false)
	+ This field is used to select multiple tax ID numbers from the options provided.
	+ Options: tax id number, address, phone number, email, date of birth, time.
* **Select One Contact Preference** (16, select_one, required: false)
	+ This field is used to select one contact preference from the options provided.
	+ Options: phone number, email, address.
* **Select Multiple Contact Preferences** (17, select_multiple, required: false)
	+ This field is used to select multiple contact preferences from the options provided.
	+ Options: phone number, email, address.

## Tips

* Please ensure that you have all the necessary information before submitting the form.
* If you are unsure about any field, you can ask your administrator for clarification.
* Please review the form carefully before submitting it to avoid any errors.
