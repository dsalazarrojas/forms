# Performance Review Registration Form - Help Guide
## Purpose
This form is designed to facilitate the performance review process, providing an organized and structured approach to evaluating an employee's performance.
## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the employee's name in the "Employee Name" field.
2. Select the job title from the "Job Title" field.
3. Provide a performance rating in the "Performance Rating" field.
4. Add feedback in the "Feedback" field.
5. Choose the review date from the "Review Date" field.
6. Enter the reviewer's name in the "Reviewer Name" field.
7. Select the review type from the "Review Type" field (Review, Feedback, or Assessment).
8. Choose the evaluation criteria from the "Evaluation Criteria" field (Goal 1, Goal 2, etc.).
9. Select the performance improvement goals from the "Performance Improvement Goals" field (Goal 1, Goal 2, etc.).
10. Enter the evaluation date and time in the "Evaluation Date" and "Evaluation Time" fields.
11. Set the evaluation duration in the "Evaluation Duration" field.
12. Enter any comments in the "Comments" field.
13. Enter a performance score in the "Performance Score" field.
14. Set the performance score out of a specific range in the "Performance Score Out Of" field.

## Field-by-Field Explanation
- **Employee Name**: Enter the employee's name as it appears on their personnel record. (text, required: false)
- **Job Title**: Select the employee's job title from the list of available options. (text, required: false)
- **Performance Rating**: Rate the employee's performance on a scale of 1-5. (number, required: false)
- **Feedback**: Provide any feedback or comments about the employee's performance. (text, required: false)
- **Review Date**: Choose the date of the performance review. (date, required: false)
- **Reviewer Name**: Enter the reviewer's name. (text, required: false)
- **Review Type**: Select the type of review (Review, Feedback, or Assessment). (select_one, required: false)
- **Evaluation Criteria**: Choose the criteria to be evaluated (Goal 1, Goal 2, etc.). (select_multiple, required: false)
- **Prophets**: Select the prophets to be evaluated (Prophet 1, Prophet 2, etc.). (select_multiple, required: false)
- **Performance Improvement Goals**: Choose the goals for improvement (Goal 1, Goal 2, etc.). (select_multiple, required: false)
- **Evaluation Date**: Choose the date of the evaluation. (date, required: false)
- **Evaluation Time**: Set the time of the evaluation. (time, required: false)
- **Evaluation Duration**: Set the duration of the evaluation. (number, required: false)
- **Comments**: Enter any additional comments. (text, required: false)
- **Performance Score**: Enter a score representing the employee's performance. (number, required: false)
- **Performance Score Out Of**: Set the range for the performance score. (number, required: false)
