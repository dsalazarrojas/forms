# identity_verification_authorization_form - Help Guide
## Purpose
The Identity Verification Authorization Form is a document used to collect information for verifying identities and authorizing access. This form is essential for ensuring the accuracy and legitimacy of an individual's identity and granting permission to access sensitive information or facilities.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the correct category for the form using the Category field.
2. Provide a description of the identity verification process in the Description field.
3. Enter the title of the form, if applicable (optional).
4. Choose how the identity verification will be performed using the Verify By field.
5. Specify the date and time of the verification (Verify Date and Verify Time fields).
6. Select the method used for verification (Verify Method field).
7. Choose the location where the verification took place (Location field).
8. Enter any additional details about the verification method (Verify Method Details field).
9. Select the result of the verification process (Verification Result field).
10. Specify the status of the verification process (Verification Status field).
11. Click the Submit button to save the form or click the Cancel button to discard changes.

## Field-by-Field Explanation
* **Category (Administrative Forms)** (`form_category`, required): Select the category for this form from the available options.
* **Description (`form_description`, required): Provide a brief description of the identity verification process.
* **Identity Verification Authorization Form (`form_title`, optional): Enter a title for the form if desired.
* **Verify By (`verify_by`, required): Choose how the identity verification will be performed (Self-Verification or Third-Party Verification).
* **Verify Date (`verify_date`, required): Enter the date of the verification process.
* **Verify Time (`verify_time`, required): Enter the time of the verification process.
* **Verify Method (`verify_method`, required): Select one or more methods used for verification (Face-to-Face, Online, Phone).
* **Location (`verify_location`, required): Choose the location where the verification took place (Office Location, Home, Other).
* **Verify Method Details (`verify_method_details`, optional): Provide additional details about the verification method, if applicable.
* **Verification Result (`verification_result`, required): Select the outcome of the verification process (Verified, Not Verified, Pending).
* **Verification Status (`verification_status`, required): Specify the status of the verification process (Complete, Incomplete, Unknown).
* **Submit (`submit`, required): Click this button to save the form.
* **Cancel (`cancel`, optional): Click this button to discard changes and exit the form.
