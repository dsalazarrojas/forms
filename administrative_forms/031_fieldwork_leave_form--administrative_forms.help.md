# Fieldwork Leave Form - Help Guide
## Purpose
This form is used to record and track fieldwork activities, allowing administrators to manage events and keep records of their status and comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of fieldwork event you are completing (e.g., Fieldwork, Meeting, or Training).
2. Enter the start and end dates of the event.
3. Select the start and end times of the event.
4. Specify the location of the event.
5. Choose the status of the event (Approved, Pending, or Denied).
6. Add any additional comments or remarks.
7. If necessary, add any additional comments to clarify further.

## Field-by-Field Explanation

* **Type**: Select the type of fieldwork event (e.g., Fieldwork, Meeting, or Training).
  * This field is used to classify the event and help administrators track and categorize events.
  * Options: Fieldwork, Meeting, Training, and Other.
* **Dates**: Enter the dates of the event in the format MM/DD/YYYY, where MM is the month, DD is the day, and YYYY is the year.
  * This field is used to record the period of the event.
  * Format: MM/DD/YYYY
* **Location**: Enter the location of the event (e.g., address, city, state, or zip code).
  * This field is used to track the location of the event.
  * Example: 123 Main St, Anytown, USA 12345
* **Start Time**: Select the start time of the event in the format HH:MM AM/PM or 24-hour format.
  * This field is used to record the start of the event.
  * Format: HH:MM AM/PM (e.g., 08:00 AM)
* **End Time**: Select the end time of the event in the format HH:MM AM/PM or 24-hour format.
  * This field is used to record the end of the event.
  * Format: HH:MM AM/PM (e.g., 10:00 PM)
* **Status**: Select the status of the event (e.g., Approved, Pending, or Denied).
  * This field is used to keep track of the event's status.
  * Options: Approved, Pending, Denied
* **Comments**: Add any comments or remarks about the event.
  * This field is used to record any comments or observations about the event.
  * Format: plain text
* **Additional Comments**: Add any further comments or remarks about the event.
  * This field is used to record any additional comments or observations about the event.
  * Format: plain text

Note: This form is for internal use.
