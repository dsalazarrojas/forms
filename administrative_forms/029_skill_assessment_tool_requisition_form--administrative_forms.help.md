# Skill Assessment Tool Requisition Form - Help Guide
## Purpose
The purpose of this form is to collect information for a Skill Assessment Tool requisition, which is used to evaluate an employee's skills and abilities.

## How To Complete This Form
To fill out this form, follow the instructions below:

1. Select the required skills for the assessment by choosing from the "Select Skills" dropdown menu.
2. Choose the skill level for the assessment by selecting from the "Select Skill Level" dropdown menu.
3. Choose the type of assessment by selecting from the "Assessment Type" dropdown menu.
4. Enter the date of the assessment in the "Date Assessment" field.
5. Enter the phone number and email of the employee being assessed.
6. Select the person to whom the assessment will be assigned to.
7. Enter the first name, last name, job title, and department of the employee being assessed.
8. Enter the employee ID and manager ID (if applicable).
9. Select the status of the employee (Active or Inactive).
10. Enter any notes or comments about the assessment.
11. Click "Submit" to create the requisition.

## Field-by-Field Explanation

* **Select Skills** (`skills`, select_multiple): Select the required skills for the assessment.
* **Select Skill Level** (`skill_level`, select_one): Choose the skill level for the assessment.
* **Assessment Type** (`assessment_type`, select_multiple): Choose the type of assessment (Self-Assessment or Manager Assessment or Peer Assessment).
* **Date Assessment** (`date_assessment`, date): Enter the date of the assessment.
* **Phone** (`phone`, text): Enter the phone number of the employee being assessed.
* **Email** (`email`, email): Enter the email address of the employee being assessed.
* **Assigned To** (`assigned_to`, select_one): Select the person to whom the assessment will be assigned to.
* **Assigned Date** (`assigned_date`, date): Enter the date the assessment will be assigned.
* **Comments** (`comments`, note): Enter any notes or comments about the assessment.
* **First Name** (`first_name`, text): Enter the first name of the employee being assessed.
* **Last Name** (`last_name`, text): Enter the last name of the employee being assessed.
* **Job Title** (`job_title`, text): Enter the job title of the employee being assessed.
* **Department** (`department`, text): Enter the department of the employee being assessed.
* **Employee ID** (`employee_id`, text): Enter the employee ID (if applicable).
* **Manager ID** (`manager_id`, text): Enter the manager ID (if applicable).
* **Employee Status** (`employee_status`, select_one): Select the status of the employee (Active or Inactive).
* **Skill Assessment Tool ID** (`skill_assessment_tool_id`, text): Enter any relevant tool ID (if applicable).
* **Created By** (`created_by`, select_one): Select the person creating the requisition.
* **Created Date** (`created_date`, date): Enter the date the requisition was created.
* **Updated By** (`updated_by`, select_one): Select the person who updated the requisition.
* **Updated Date** (`updated_date`, date): Enter the date the requisition was updated.
* **Deleted By** (`deleted_by`, select_one): Select the person who deleted the requisition.

## Tips

* Please make sure to select the correct skills and skill level for the assessment.
* Double-check the date of the assessment to ensure it is accurate.
* Ensure that the employee has given their consent for the assessment.
* Make sure to assign the assessment to the correct person.
* Review the employee's status before creating the requisition.
* Use the correct employee ID and manager ID if applicable.
* Enter any relevant comments or notes about the assessment.
