# Daily Task Checklist Form - Help Guide
## Purpose
The Daily Task Checklist Form is a tool used to report on daily tasks and activities. It is meant to be completed daily to help users keep track of their progress and stay organized.

## How To Complete This Form
1. Click on the "Submit" button to begin completing the form.
2. Start by selecting the checkboxes next to each task on the task checklist.
3. Enter the start and end times for your task session.
4. Select the date for the corresponding day.
5. Add any notes or additional comments about your task session.
6. Choose "Yes" or "No" to indicate whether the task has been assigned to someone else.
7. Select the person to whom the task has been assigned, if applicable.
8. Finally, click on the "Submit" button to complete and submit the form.

## Field-by-Field Explanation
* **Task List 1** (`task_checklist_1`, Text, Optional): A list of tasks to be completed daily. Check the boxes next to each task to indicate completion status.
* **Start Time** (`start_time`, Time, Optional): Enter the start time of your task session. Use the time picker to select the correct time.
* **End Time** (`end_time`, Time, Optional): Enter the end time of your task session. Use the time picker to select the correct time.
* **Date** (`date`, Date, Optional): Select the date for which the task session took place.
* **Task List 2** (`task_checklist_2`, Text, Optional): Another list of tasks to be completed daily. Check the boxes next to each task to indicate completion status.
* **Task List 3** (`task_checklist_3`, Text, Optional): A third list of tasks to be completed daily. Check the boxes next to each task to indicate completion status.
* **Task List 4** (`task_checklist_4`, Text, Optional): A fourth list of tasks to be completed daily. Check the boxes next to each task to indicate completion status.
* **Notes** (`notes`, Note, Optional): Add any notes or comments about your task session.
* **Assigned To** (`assigned_to`, Select One, Optional): Indicate whether the task has been assigned to someone else. Choose "Yes" or "No".
* **Assigned To Options** (`assigned_to_options_1`, Text, Optional): If the task has been assigned to someone else, enter their name or details here.
