# winter_event_inventory_request - Help Guide

## Purpose
This form is used to request winter event inventory. It is intended for event organizers to submit their requests for winter event-related items.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your event's name in the "Event Name" field.
2. Select the date of your event.
3. For "Event Item Type", choose the type of inventory you need for your event (if applicable).
4. List the items you need in the "Items Needed" field.
5. Enter the event location in the "Event Location" field.
6. Enter the name and email address of the event manager in the corresponding fields.

## Field-by-Field Explanation
* **Event Name (text, required: false)**: Enter the name of your event to help us quickly identify your request.
* **Event Date (date, required: true)**: Select the date of your event so we can schedule our delivery accordingly.
* **Event Item Type (select_one, required: false)**: If your event requires specific types of inventory (e.g., winter clothing), select the relevant option from the dropdown list.
* **Items Needed (text, required: false)**: List the specific items you need for your event.
* **Event Location (text, required: true)**: Enter the location of your event so we can ensure accurate delivery.
* **Event Manager Name (text, required: true)**: Enter the name of the event manager responsible for your event.
* **Event Manager Email (email, required: true)**: Enter the email address of the event manager so we can contact them for further information or questions.
* **Event Description (text, required: false)**: Provide a brief description of your event, if necessary.
