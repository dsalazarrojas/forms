# Shipping Document Authorization Form - Help Guide
## Purpose
The "Shipping Document Authorization Form" is used to authorize and track shipping documents. This form collects essential information about the customer, shipment details, and document status to facilitate smooth and organized shipping processes.

## How To Complete This Form

1. Fill out the form completely and accurately as requested.
2. Ensure all required fields are filled out before submitting the form.
3. Double-check your input before submitting the form for final review and authorization.

## Field-by-Field Explanation

* **Customer Name (customer_1)**: Enter the name of the customer who is receiving the shipment.
* **Shipping Date (shipping_date_1)**: Enter the date the shipment is scheduled to be delivered or has been delivered.
* **Customer Email (customer_email_1)**: Enter the email address of the customer (optional).
* **Customer Phone (customer_phone_number_1)**: Enter the phone number of the customer (required for communication purposes).
* **Document Number (shipping_document_id_1)**: Enter the identification number of the shipping document.
* **Document Status (shipping_document_status_1)**: Select the current status of the shipping document from the options provided (required).
	+ In Transit: The document is being shipped to the customer.
	+ Out For Delivery: The document is scheduled to be delivered.
	+ Delivered: The document has been successfully delivered.
	+ Pending: The document is awaiting shipment or confirmation.
	+ Cancelled: The document was cancelled.
* **Document Type (shipping_document_type_1)**: Select the type of document from the options provided (optional).
* **Document Note (shipping_document_note_1)**: Add any additional comments or notes about the shipment (optional).
* **Document Comment (shipping_document_comment_1)**: Enter any additional comments or details about the shipment (optional).

## Tips

* Double-check all fields before submitting the form to ensure accurate and complete information.
* Ensure the document status is up-to-date to reflect the current shipment status.
* Use the provided document type options to categorize the shipment for easier tracking and management.
