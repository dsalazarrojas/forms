# Fire Alarm System Monitoring Form - Help Guide
## Purpose
This form is used to collect information about fire alarm systems. It is intended for administrative purposes to ensure that fire alarm systems are properly monitored and maintained.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the Category of the fire alarm system being monitored.
2. Enter a Description of the system.
3. Choose the Assigned Tool (if applicable).
4. Select the Output File.
5. Enter the Fire Alarm System Monitoring Form ID.

## Field-by-Field Explanation
* **Category** (`Administrative Forms`, `Other`): Choose the category under which the fire alarm system is being monitored.
* **Description**: Enter a brief description of the fire alarm system.
* **Assigned Tool** (`chatjimmy`, `Other`): Choose the tool assigned to monitor the system (if applicable).
* **Output File**: Upload or enter the path to the output file related to the fire alarm system.
* **Fire Alarm System Monitoring Form ID** (`Number`): Enter a unique ID for the form.
* **Form Version**: This field is optional and used to track version changes (if applicable).
