# daily_worker_check_out_form - Help Guide
## Purpose
The daily_worker_check_out_form is an administrative form used to document the check-out of workers from their assigned tools. This form is typically used by supervisors or administrators to collect information about the check-out process, which helps to ensure accurate and timely tracking of tool availability.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Category** field and choose "Administrative Forms" from the dropdown menu to indicate that this is an administrative form.
2. Provide a brief **Description** of the check-out process, including any relevant details about the tool and its current status.
3. Enter the **Assigned Tool** name or number in the text field.
4. Choose a file format for the **Output File**, which will be generated after submitting the form.

## Field-by-Field Explanation
* **Form ID**: Enter the unique ID of the form, which helps identify the check-out request.
* **Category**: Select "Administrative Forms" to classify this form as an administrative task.
* **Description**: Provide a clear and concise description of the check-out process, including any relevant details.
* **Assigned Tool**: Enter the name or number of the tool being checked out, such as "Tool #123".
* **Output File**: Choose a file format for the output file, such as CSV or PDF.
* **Date**: Enter the date of the check-out, using the format MM/DD/YYYY.
* **Time**: Enter the time of the check-out, using the format HH:MM AM/PM.
