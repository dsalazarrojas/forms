# Accounting System User Registration Form - Help Guide
## Purpose
The purpose of this form is to register new users in the accounting system, providing them with the necessary access and permissions to perform their assigned tasks and roles.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your **full name** as it should appear in the system.
2.  Provide your **desired username**, which will be used as your system login ID.
3.  Enter your **email address**, which will be used for system notifications.
4.  Fill in your **phone number** (if available), which will be used for support purposes.
5.  Choose your **department**, which will be used to identify your team or business unit.
6.  Select your **role**, which will define your system permissions:
    *   Viewer: Access to view system information only.
    *   Data entry: Access to create and edit data.
    *   Manager: Access to manage user roles and permissions.
    *   Administrator: Full system admin access.
7.  Choose your **access level**, which will define your system permissions:
    *   Read only: Access to view system information only.
    *   Edit: Access to create and edit system data.
    *   Approve: Access to approve system changes.
    *   Full admin: Full system admin access.
8.  Select the **start date** when you would like your access to the system to begin.
9.  List the **systems to integrate**, if any other systems need to be linked to your account.
10. Indicate if **training is required** before accessing the system.
11. If necessary, provide your **manager's name** for approval.
12. Fill in the **person making the access request**.
13. Provide any **additional notes**, such as specific instructions for onboarding.

## Field-by-Field Explanation

*   **Full name**: Your name as it should appear in the system.
*   **Desired username**: Your login ID for the system.
*   **Email address**: Your corporate email for system notifications.
*   **Phone number**: Optional phone number for support.
*   **Department**: Your team or business unit.
*   **Role**: System role or position.
*   **Access level**: Required system permissions.
*   **Start date**: Date when access to the system should begin.
*   **Systems to integrate**: Other systems that need to be linked to your account.
*   **Training required**: Indicate if training is needed before accessing the system.
*   **Manager approval**: Manager name for approval.
*   **Requested by**: Person making the access request.
*   **Additional notes**: Any special instructions for onboarding.
