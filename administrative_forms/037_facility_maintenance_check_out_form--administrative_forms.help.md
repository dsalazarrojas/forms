# Facility Maintenance Check Out Form - Help Guide
## Purpose
The Facility Maintenance Check Out Form is used to track equipment and tools borrowed for maintenance purposes. This form helps to ensure that all borrowed items are accounted for and returned on time.

## How To Complete This Form
1. Select the equipment that was borrowed for maintenance from the dropdown options.
2. Enter the date when the equipment is expected to be returned.
3. Enter a brief description of the assigned tool or equipment.
4. Provide any additional notes about the equipment or task at hand.

## Field-by-Field Explanation
* **Equipment Borrowed**:
	+ This field allows you to select the equipment or tool that was borrowed for maintenance. Choose from the available options or type in a custom value if not listed.
* **Equipment Return Date**:
	+ Enter the date when the equipment is expected to be returned. Format the date in the standard "YYYY-MM-DD" format.
* **Assigned Tool**:
	+ Enter a brief description of the tool or equipment assigned to the maintenance task. This can be the tool name, serial number, or a brief description.
* **Note**:
	+ Provide any additional notes or comments about the equipment or task at hand. This can include details about any issues or concerns that need to be addressed.

## Tips
* Be sure to select the correct equipment from the dropdown options to ensure accuracy.
* Format the equipment return date in the correct date format (YYYY-MM-DD).
* Keep the assigned tool field brief and to the point, but include any important details that need to be known.
* Use the note field to provide any additional context or information that may be helpful for future reference.
