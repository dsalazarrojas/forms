# Sprinkler System Inspection Form - Help Guide
## Purpose
The Sprinkler System Inspection Form is designed to inspect and evaluate the performance of a sprinkler system. This form helps to identify potential issues or defects with the system and ensure that it is functioning correctly.

## How To Complete This Form
To complete this form, simply fill out each page with the requested information. You can move between pages using the navigation buttons at the top or bottom of each page.

## Field-by-Field Explanation
- **Sprinkler System Inspection Form Page 1:**
  - **Sprinkler System Inspection Form Page 1 Label** (`sprinkler_system_inspection_form_page_1_label`, Text, Required: No): This is the first page of the form. You will be asked to provide a label for this page, which will help us identify it as part of the form.
  - **No other fields on this page**
- **Sprinkler System Inspection Form Page 2:**
  - **Sprinkler System Inspection Form Page 2 Label** (`sprinkler_system_inspection_form_page_2_label`, Text, Required: No): This is the second page of the form. You will be asked to provide a label for this page, which will help us identify it as part of the form.
  - **Question: Has the sprinkler system been functioning properly over the past 7 days?** (`sprinkler_system_inspection_form_page_2`, Select, Required: False): Answer this question by selecting "Yes" or "No".
  - **No other fields on this page**
- **Sprinkler System Inspection Form Page 3:**
  - **Sprinkler System Inspection Form Page 3 Label** (`sprinkler_system_inspection_form_page_3_label`, Text, Required: No): This is the third page of the form. You will be asked to provide a label for this page, which will help us identify it as part of the form.
  - **Question: Are there any leaks or blockages in the system?** (`sprinkler_system_inspection_form_page_3`, Select, Required: False): Answer this question by selecting "Yes" or "No".
  - **No other fields on this page**
- **Sprinkler System Inspection Form Page 4:**
  - **Sprinkler System Inspection Form Page 4 Label** (`sprinkler_system_inspection_form_page_4_label`, Text, Required: No): This is the fourth page of the form. You will be asked to provide a label for this page, which will help us identify it as part of the form.
  - **Inspection Date** (`sprinkler_system_inspection_form_page_4`, Date, Required: False): This field is for recording the date of the inspection. You can enter the date in the format MM/DD/YY.

## Tips
* Make sure to answer all questions thoroughly and honestly to ensure that the inspector has a complete understanding of the sprinkler system's performance.
* If you have any issues or concerns with the form, please reach out to the inspector for assistance.
* The form is not required to be completed, but it is recommended that it be filled out thoroughly to ensure that all necessary information is collected.
