# <string> - Help Guide

## Purpose
This form is designed to assist project teams in defining and monitoring their long-term and strategic goals, collaboration approach, data collection methods, and other essential project information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review each field carefully and provide accurate information.
2. Fill in the required fields (marked as "required" in the form).
3. Use the "Select Multiple" options for fields with multiple choices.
4. For text fields, provide brief but clear descriptions.
5. Save your progress frequently to avoid losing work.

* **Long Term Goals** (`long_term_goals`, text, required: false): Briefly describe your long-term goals for this project.
* **Strategic Goals** (`strategic_goals`, text, required: false): Describe your strategic goals for this project.
* **Collaboration Approach** (`collaboration_approach`, text, required: false): Outline your approach to collaboration for this project.
* **Data Collection** (`data_collection`, text, required: false): Describe the methods you will use to collect data for this project.
* **Team Members** (`team_members`, select_multiple, required: true): Select all team members involved in this project.
* **Long Term Outcomes** (`long_term_outcomes`, text, required: false): Describe the expected long-term outcomes of this project.
* **Strategic Plan** (`strategic_plan`, text, required: false): Outline your strategic plan for this project.
* **Key Performance Indicators** (`key_performance_indicators`, text, required: false): Identify the key performance indicators for this project.
* **Action Items** (`action_items`, text, required: false): List action items related to this project.
* **Timeline** (`timeline`, text, required: false): Describe the project timeline.
* **Review Process** (`review_process`, text, required: false): Outline the review process for this project.
* **Communication Plan** (`communication_plan`, text, required: false): Describe the communication plan for this project.
* **Monitoring Progress** (`monitoring_progress`, text, required: false): Describe how you will monitor progress on this project.
* **Review Schedule** (`review_schedule`, text, required: false): Outline the review schedule for this project.
* **Resource Allocation** (`resource_allocation`, text, required: false): Describe the resource allocation plan for this project.
* **Budget Plan** (`budget_plan`, text, required: false): Outline the budget plan for this project.
* **Contingency Plan** (`contingency_plan`, text, required: false): Describe the contingency plan for this project.
* **Evaluation Criteria** (`evaluation_criteria`, text, required: false): Identify the evaluation criteria for this project.
* **Action Items Status** (`action_items_status`, select_multiple, required: true): Select the status of action items for this project (Active, In Progress, Complete, or On Hold).
* **Long Term Goals Description** (`long_term_goals_description`, text, required: false): Describe your long-term goals.
* **Strategic Goals Description** (`strategic_goals_description`, text, required: false): Describe your strategic goals.
