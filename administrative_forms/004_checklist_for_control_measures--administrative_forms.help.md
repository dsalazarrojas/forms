# Checklist For Control Measures - Help Guide
## Purpose
The Checklist For Control Measures form is designed to help organizations evaluate their control measures in place for workplace safety and health. It's used to assess the organization's policies, procedures, and practices related to managing hazards and risks associated with their operations.

## How To Complete This Form
1. Review the organization's safety protocols, policies, and procedures.
2. Answer each question based on the organization's current state of control measures.
3. Use the provided options for each question, selecting the one that best describes the organization's situation.
4. If unsure about any question, consult with the organization's safety team or experts.
5. Enter your name and title in the "Assessor Name" and "Assessor Title" fields.
6. Fill in the "Assessment Date" field with the date of this evaluation.
7. Enter the "Organization Name" field with the name of the organization assessed.
8. Answer all questions honestly and accurately.

## Field-by-Field Explanation

* **Organization Name (1)**: Enter the name of your organization.
* **Department (2)**: Enter the name of the department conducting this assessment.
* **Assessment Date (3)**: Enter the date of this control measures evaluation.
* **Assessor Name (4)**: Enter the name of the person conducting this assessment.
* **Facility Location (5)**: Enter the location or site being assessed.
* **Safety Protocols Documented (6)**: Select the option that best describes the organization's safety protocols documentation:
	+ **Yes, fully documented**: All safety protocols are properly documented.
	+ **Partially documented**: Some safety protocols are documented, while others are not.
	+ **Not documented**: No safety protocols are documented.
	+ **Not applicable**: Not applicable (e.g., new organization or no safety protocols).
* **Risk Assessment Current (7)**: Select the option that best describes the organization's risk assessment status:
	+ **Yes, current**: The risk assessment is up to date.
	+ **Needs update**: The risk assessment is not up to date.
	+ **Not available**: No risk assessment is available.
* **PPE Availability (8)**: Select the option that best describes the organization's PPE availability:
	+ **Fully available**: All PPE is available and accessible.
	+ **Partially available**: Some PPE is available, while others are not.
	+ **Not available**: No PPE is available.
	+ **Not applicable**: Not applicable (e.g., not relevant for the organization).
* **Emergency Procedures Posted (9)**: Select the option that best describes the organization's emergency procedures:
	+ **Yes, all areas**: All emergency procedures are clearly displayed in all areas.
	+ **Yes, some areas**: Some emergency procedures are displayed, while others are not.
	+ **False**: No emergency procedures are displayed.
* **Training Records Complete (10)**: Select the option that best describes the organization's training records:
	+ **Yes, all complete**: All training records are up to date.
	+ **Partially complete**: Some training records are up to date, while others are not.
	+ **Incomplete**: No training records are up to date.
* **Equipment Maintenance Current (11)**: Select the option that best describes the organization's equipment maintenance status:
	+ **Yes, all current**: All equipment is properly maintained.
	+ **Some overdue**: Some equipment maintenance is overdue.
	+ **Not maintained**: No equipment is maintained.
* **Hazard Communication (12)**: Select the option that best describes the organization's hazard communication:
	+ **Excellent**: Hazards are properly communicated to staff.
	+ **Adequate**: Hazards are generally communicated, but room for improvement.
	+ **Needs improvement**: Hazards are not properly communicated.
	+ **Poor**: Hazards are not communicated.
* **Incident Reporting System (13)**: Select the option that best describes the organization's incident reporting system:
	+ **Yes, fully functional**: The incident reporting system is fully functional.
	+ **Yes, with issues**: The incident reporting system is functional, but with some issues.
	+ **No system in place**: No incident reporting system is available.
* **First Aid Supplies (14)**: Select the option that best describes the organization's first aid supplies:
	+ **Fully stocked**: All first aid supplies are stocked and accessible.
	+ **Partially stocked**: Some first aid supplies are stocked, while others are not.
	+ **Not stocked**: No first aid supplies are stocked.
* **Fire Safety Equipment (15)**: Select the option that best describes the organization's fire safety equipment:
	+ **All functional**: All fire safety equipment is functional.
	+ **Some issues**: Some fire safety equipment is not functional.
	+ **Not functional**: No fire safety equipment is functional.
* **Ventilation System (16)**: Select the option that best describes the organization's ventilation system:
	+ **Adequate and working**: The ventilation system is adequate and working.
	+ **Adequate but needs repair**: The ventilation system is adequate, but some maintenance is required.
	+ **Inadequate**: The ventilation system is not adequate.
	+ **Not applicable**: Not applicable (e.g., not relevant for the organization).
* **Corrective Actions Needed (17)**: List any corrective actions required to address control measure issues.
* **Follow-up Date (18)**: Enter the date for follow-up assessment (optional).
* **Overall Compliance Rating (19)**: Select the option that best describes the organization's overall compliance with control measures:
	+ **Excellent**: The organization has excellent compliance with control measures.
	+ **Good**: The organization has good compliance with control measures.
	+ **Fair**: The organization has fair compliance with control measures.
	+ **Poor**: The organization has poor compliance with control measures.
	+ **Critical**: The organization has critical compliance with control measures.
* **Assessor Confirmation (20)**: Select the option that confirms the accuracy of this assessment:
	+ **Yes, I confirm**: The assessor confirms the accuracy of this assessment.
	+ **False**: The assessor does not confirm the accuracy of this assessment.

## Tips
- Ensure that this form is completed by one person per organization.
- Review the organization's safety protocols, policies, and procedures before completing this form.
- Answer each question based on the organization's current state of control measures.
- Select the option that best describes the organization's situation.
- Enter the Assessor Name and Assessor Title fields with your name and title.
- Enter the Assessment Date field with the date of this evaluation.
- Answer all questions honestly and accurately.
- If unsure about any question, consult with the organization's safety team or experts.
- Ensure that this form is not duplicated by organizations that have already undergone a similar assessment in the recent past (e.g., within the last 6-12 months).
