## Community Event Permit Request Form - Help Guide

### Purpose

This form is used for requesting a community event permit to host an event in the community area. It helps us process and review your event details quickly and efficiently. Please ensure that all required information is complete and accurate to ensure that your event permit can be processed in a timely manner.

### How To Complete This Form

1. Review the form instructions and fields carefully before starting.
2. Fill in the required fields, marked with \*.
3. Provide accurate and relevant information for each field.

### Field-by-Field Explanation

* **Event name** (`event_name`, text, \*): Enter the official title of the event.
* **Organizer name** (`organizer_name`, text, \*): Enter the individual or organization name responsible for the event.
* **Organizer contact email** (`organizer_contact_email`, email, \*): Enter the email address for communication with the event organizer.
* **Event date** (`event_date`, date, \*): Enter the start date of the event in the standard date format (e.g., 2024-02-27).
* **Event start time** (`event_start_time`, time, ): Enter the local time the event will start (format: 14:00 or 02:00).
* **Expected attendance** (`expected_attendance`, number, \*): Estimate the approximate number of attendees for the event.
* **Location address** (`location_address`, text, \*): Enter the full address of the event location.
* **Required permits and services** (`required_permits`, text, ): Check if any special permits are required (e.g., security, road closure).
* **Safety plan summary** (`safety_plan`, text, \*): Summarize the crowd management and first aid procedures for your event.
