# Wind Turbine Inspection Form - Help Guide
## Purpose
This form is used to collect information for the periodic inspection of wind turbines.

## How To Complete This Form

Please complete each page of the form thoroughly and accurately.

### Inspection Details (Page 1)
* **Inspection Details** (`inspection_details`, text, required/optional): Enter any details about the inspection that are not covered by other fields.
*   **Inspection Date**: This field is not currently used by the form.

### Issues Reported (Page 2)
* **Issues Reported** (`issues_reported`, select_multiple, required/optional): Select any issues that were reported during the inspection.
*   *Choose as many issues as necessary to report.*
*   *Select "None" if no issues were reported.*

### Maintenance Schedules (Page 3)
* **Maintenance Schedules** (`maintenance_schedules`, date, required/optional): Enter any maintenance schedules for the wind turbine.
*   *Use the format "MM/DD/YY" (e.g., 02/01/2024).*

### Safety Risk Level (Page 4)
* **Safety Risk Level** (`safety_risk_level`, select_one, required/optional): Select the current safety risk level of the wind turbine.
*   *Choose "Low", "Medium", or "High" based on the risk level.*

### Notes (Page 5)
* **Notes** (`notes`, note, required/optional): Enter any additional comments or notes about the inspection.
*   *Provide any relevant information about the inspection.*

### Next Inspection Date (Page 6)
* **Next Inspection Date** (`next_inspection_date`, date, required/optional): Enter the date of the next scheduled inspection.
*   *Use the format "MM/DD/YY" (e.g., 02/01/2024).*

### Energy Production (Page 7)
* **Energy Production** (`energy_production`, number, required/optional): Enter the current energy production levels of the wind turbine.
*   *Provide the production levels in the format "X.XX".*

### Wind Turbine Status (Page 8)
* **Wind Turbine Status** (`wind_turbine_status`, select_one, required/optional): Select the current status of the wind turbine.
*   *Choose "Online", "Offline", or "Maintenance".*

### Maintenance Status (Page 9)
* **Maintenance Status** (`maintenance_status`, text, required/optional): Enter any additional comments or status updates about the maintenance schedules.
*   *Provide any relevant information about the maintenance schedules.*

### Issue Status (Page 10)
* **Issue Status** (`issue_status`, select_one, required/optional): Select the current status of any issues that were reported.
*   *Choose "Open", "Closed", or "In Progress".*

## Tips

*   Please ensure that all required fields are filled in before submitting the form.
*   If a field is not required, but the information is relevant, please fill it in for accuracy and completeness.
*   Use the format "MM/DD/YY" for dates.
*   Select all relevant issues and maintenance schedules.
*   Enter the energy production levels in the format "X.XX".
