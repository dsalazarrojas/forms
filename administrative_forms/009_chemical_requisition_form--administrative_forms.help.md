# Chemical Requisition Form - Help Guide

## Purpose

This form is used to submit chemical requests for inventory management. It helps to track and record the necessary information for chemicals to be properly stored, handled, and managed.

## How To Complete This Form

1. Fill in the required fields, including Requisition number, Date of requisition, Requester name, Department, Email address, Phone number, Chemical name, CAS number (if available), Chemical grade, Quantity needed, Unit of measurement, Intended use, and Urgency level.
2. If applicable, select the correct answer for Safety Data Sheet (SDS) required.
3. Select all that apply for the Known hazard classification.
4. Enter any Special storage requirements, if necessary.
5. Choose a Preferred supplier, if desired.
6. Enter a Budget or cost center code, if applicable.
7. Specify Manager or supervisor for approval.
8. Select the urgency level for the request.
9. Enter the date needed by.

## Field-by-Field Explanation

* **Requisition number**: Enter a unique identifier for the request, which can be auto-generated or manually entered.
* **Date of requisition**: Record the date the request is submitted.
* **Requester name**: Enter the name of the person or team making the request.
* **Department**: Select the department responsible for the request.
* **Email address**: Enter the contact email address for the requester.
* **Phone number**: Enter the contact phone number for the requester.
* **Chemical name**: Enter the IUPAC or common name of the chemical.
* **CAS number**: If available, enter the Chemical Abstracts Service number for the chemical.
* **Chemical grade**: Select the grade of the chemical, such as Reagent grade or Analytical grade.
* **Quantity needed**: Enter the quantity of the chemical required.
* **Unit of measurement**: Select the unit of measurement for the quantity needed.
* **Intended use**: Describe the intended use of the chemical.
* **Safety Data Sheet (SDS) required**: If the SDS is required, select 'True'. Otherwise, select 'False' or 'Already have SDS'.
* **Known hazard classification**: Select all applicable hazard classifications for the chemical.
* **Special storage requirements**: Enter any special storage requirements for the chemical.
* **Preferred supplier**: Choose a preferred supplier for the chemical.
* **Budget or cost center code**: Enter a budget or cost center code for the request.
* **Manager or supervisor for approval**: Enter the name of the manager or supervisor for approval.
* **Urgency level**: Select the urgency level for the request, such as Routine, Standard, Urgent, or Emergency.
* **Needed by date**: Enter the date the chemical is needed by.
* **Additional notes or special requests**: Enter any additional notes or special requests for the chemical.
