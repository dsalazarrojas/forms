# Daily Cleaning Staff Evaluation - Help Guide

## Purpose

This form is used to evaluate the performance of cleaning staff, providing a way for supervisors to assess the cleanliness of an area, rate the staff's performance, and document any relevant notes or comments.

## How To Complete This Form

1. Select the area that was cleaned.
2. Rate the staff's performance using the provided rating scale (if applicable).
3. Provide any additional comments or notes about the area cleaned or staff performance.
4. Select the status of the evaluation (Completed or Not Completed).
5. Select the person assigned to perform the task.
6. Indicate whether or not the form is completed.
7. Add any additional notes or comments about the evaluation process.

## Field-by-Field Explanation

* **Cleaning Staff Rating** (`staff_rating`, number, optional): Rate the staff's performance using a numeric value (if provided).
* **Staff Performance** (`staff_performance`, number, optional): Rate the staff's performance using a numeric value (if provided).
* **Area Cleared** (`area_cleaned`, text, optional): Select the area that was cleaned.
* **Other Area Cleared** (`area_cleaned_other`, text, optional): If the area cleaned does not match any of the provided options, describe the area in this field.
* **Time Spent** (`time_spent`, number, optional): Record the amount of time spent cleaning the area.
* **Time Spent (Note)** (`time_spent_note`, note, optional): Add any additional comments or notes about the time spent cleaning the area.
* **Evaluation Date** (`evaluation_date`, date, optional): Record the date of the evaluation.
* **Comments** (`comments`, note, optional): Provide any additional comments or notes about the evaluation process.
* **Evaluation Status** (`evaluation_status`, select_one, optional): Select the status of the evaluation (Completed or Not Completed).
* **Evaluation Status Note** (`evaluation_status_note`, note, optional): Add any additional comments or notes about the evaluation status.
* **Assigned To** (`assigned_to`, select_one, optional): Select the person assigned to perform the task.
* **Assigned To Note** (`assigned_to_note`, note, optional): Add any additional comments or notes about the assigned person.
* **Form Completed** (`form_completed`, select_one, optional): Indicate whether or not the form is completed.
* **Form Notes** (`form_notes`, note, optional): Add any additional comments or notes about the evaluation process.
