# Real Estate Closing Checklist - Help Guide
## Purpose
This form is a checklist for real estate closing processes, used to track and record details of real estate transactions.

## How To Complete This Form
1. Select the status of the property (e.g. Pending, Closed, Contingent, Sold)
2. Enter the closing date (if applicable)
3. Enter the sale price (if applicable)
4. Select the buyer's agent (if applicable)
5. Enter the buyer's name (if applicable)
6. Select the type of property (e.g. Single Family, Condo, Townhouse, Duplex)
7. Enter the property address (if applicable)
8. Enter any sale terms or conditions
9. Enter any financing terms or conditions
10. Select any documents required from the buyer (if applicable)
11. Select any documents required from the seller (if applicable)
12. Enter the amount of escrow funds (if applicable)
13. Enter any closing instructions
14. Select the buyer's signature (if applicable)
15. Select the seller's signature (if applicable)
16. Enter any other documents that may be required
17. Enter any notes about other documents
18. Enter the due date for any buyer documents (if applicable)
19. Enter the due date for any seller documents (if applicable)
20. Enter any closing fees (if applicable)
21. Select the closing inspector (if applicable)
22. Enter any notes from the closing inspector
23. Select the type of title insurance (if applicable)
24. Select the type of survey report (if applicable)
25. Select any other survey type (if applicable)

## Field-by-Field Explanation
* **Property Status** (`property_status`, select_one, required): Select the current status of the property, such as Pending, Closed, Contingent, or Sold.
* **Closing Date** (`closing_date`, date, optional): Enter the date of the closing.
* **Sale Price** (`sale_price`, number, optional): Enter the sale price of the property.
* **Buyer Agent** (`buyer_agent`, select_multiple, optional): Select the agent representing the buyer.
* **Buyer Name** (`buyer_name`, text, optional): Enter the name of the buyer.
* **Property Type** (`property_type`, select_one, optional): Select the type of property, such as Single Family, Condo, Townhouse, or Duplex.
* **Property Address** (`property_address`, text, optional): Enter the address of the property.
* **Sale Terms** (`sale_terms`, text, optional): Enter any sale terms or conditions.
* **Financing Terms** (`financing_terms`, text, optional): Enter any financing terms or conditions.
* **Buyer Documents** (`buyer_documents`, select_multiple, optional): Select any documents required from the buyer.
* **Seller Documents** (`seller_documents`, select_multiple, optional): Select any documents required from the seller.
* **Escrow Funds** (`escrow_funds`, number, optional): Enter the amount of escrow funds.
* **Closing Instructions** (`closing_instructions`, text, optional): Enter any closing instructions.
* **Buyer Signature** (`buyer_signature`, select_one, optional): Select the buyer's signature.
* **Seller Signature** (`seller_signature`, select_one, optional): Select the seller's signature.
* **Other Documents** (`other_documents`, text, optional): Enter any other documents that may be required.
* **Other Documents Notes** (`other_documents_notes`, text, optional): Enter any notes about other documents.
* **Buyer Documents Due Date** (`buyer_documents_due_date`, date, optional): Enter the due date for any buyer documents.
* **Seller Documents Due Date** (`seller_documents_due_date`, date, optional): Enter the due date for any seller documents.
* **Closing Fees** (`closing_fees`, number, optional): Enter any closing fees.
* **Closing Inspector** (`closing_inspector`, select_one, optional): Select the closing inspector.
* **Closing Inspector Notes** (`closing_inspector_notes`, text, optional): Enter any notes from the closing inspector.
* **Title Insurance** (`title_insurance`, select_multiple, optional): Select the type of title insurance.
* **Survey Report** (`survey_report`, select_one, optional): Select the type of survey report.
* **Other Survey** (`other_survey`, select_one, optional): Select any other survey type.
