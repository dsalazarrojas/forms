# Equipment Software License Request Form - Help Guide
## Purpose
The Equipment Software License Request Form is used to request and manage the software licenses for equipment within the organization. This form helps to ensure that all the necessary information is collected and documented for each equipment software license, preventing duplication and ensuring that the licenses are properly managed and approved.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with the required information, including:
	* Organization Name
	* License Type
	* Software Version
	* Software License Start Date
	* Software License End Date
	* Software License Expiration Date
	* Approved By
	* Software License Status (Active or Inactive)
	* Remarks

## Field-by-Field Explanation

* **Organization Name** (`organization_name`, text, optional): Enter the name of your organization.
* **License Type** (`license_type`, select_one, optional): Select 'Yes' or 'No' to indicate if the software license is required.
* **Software Version** (`software_version`, text, optional): Enter the version of the software you are requesting a license for.
* **Software License Start Date** (`software_license_start_date`, date, optional): Enter the start date of the software license.
* **Software License End Date** (`software_license_end_date`, date, optional): Enter the end date of the software license.
* **Software License Expiration Date** (`software_license_expiration_date`, date, optional): Enter the expiration date of the software license.
* **Approved By** (`approved_by`, select_one, optional): Select 'Yes' or 'No' to indicate if the license is approved.
* **Software License Status** (`software_license_status`, select_multiple, optional): Select 'Active' or 'Inactive' to indicate the status of the software license.
* **Remarks** (`remarks`, text, optional): Enter any additional comments or notes about the software license.

## Tips
* Please ensure that you are not submitting duplicate requests for the same equipment software license.
* Review your existing records before submitting a request to ensure that the license is not already approved or being processed.
