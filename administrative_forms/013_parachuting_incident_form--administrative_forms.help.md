This form is used to document and report incidents that occur during parachuting activities, such as skydiving accidents or near misses. The form helps to ensure that incidents are thoroughly reported, investigated, and addressed to improve safety and prevent future incidents. 

To ensure the accuracy and completeness of the incident report, please carefully review and provide as much detail as possible for each field. 

Note: If you are reporting an incident that has already been resolved or is not currently active, please select "Closed" or "Under Review" as the incident status.

Please follow these steps to complete the form:

## How To Complete This Form

1. Fill in the required fields with the requested information.
2. Select the correct options from the dropdown menus for fields like incident_type, incident_resolution, and incident_status.
3. Be as detailed as possible in the text fields like incident_description, incident_cause_detail, and incident_status_comments.

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, date, optional): Enter the date of the incident.
* **Jump Site** (`jump_site`, text, optional): Enter the location where the incident occurred.
* **Incident Description** (`incident_description`, note, optional): Briefly describe the incident.
* **Skydiver Name** (`skydiver_name`, text, optional): Enter the name of the skydiver involved.
* **Incident Location** (`incident_location`, text, optional): Enter the location where the incident occurred.
* **Incident Type** (`incident_type`, select_one, optional): Select the type of incident (e.g., Skydive Equipment Failure, Skydiver Error, etc.).
* **Skydiver Experience** (`skydiver_experience`, number, optional): Enter the skydiver's experience level.
* **Skydiver License** (`skydiver_license`, select_multiple, required): Select the skydiver's license type.
* **Skydiver Equipment** (`skydiver_equipment`, text, optional): List and describe the equipment failure.
* **Incident Injuries** (`incident_injuries`, number, optional): Enter the number of injuries sustained.
* **Incident Hospitalizations** (`incident_hospitalizations`, number, optional): Enter the number of hospitalizations.
* **Incident Cause** (`incident_cause`, select_one, optional): Select the cause of the incident (e.g., Skydive Equipment Failure, Skydiver Error, etc.).
* **Incident Cause Detail** (`incident_cause_detail`, text, optional): Briefly describe the cause of the incident.
* **Incident Resolution** (`incident_resolution`, select_one, required): Select the resolution status of the incident.
* **Incident Reporter** (`incident_reporter`, text, optional): Enter the name of the person reporting the incident.
* **Incident Status** (`incident_status`, select_one, required): Select the current status of the incident.
* **Incident Status Detail** (`incident_status_detail`, text, optional): Briefly describe the status of the incident.
* **Incident Status Date** (`incident_status_date`, date, optional): Enter the date the incident status was last updated.
* **Incident Status Comments** (`incident_status_comments`, text, optional): Enter any comments about the incident status.
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool assigned to the incident.
* **Incident Status Responsible** (`incident_status_responsible`, select_multiple, optional): Select the person responsible for the incident status.
* **Skydiver License Number** (`skydiver_license_number`, text, optional): Enter the skydiver's license number.
* **Skydiver License Type** (`skydiver_license_type`, select_multiple, optional): Select the type of skydiver's license.
* **Incident Date** (`incident_date`, date, optional): Enter the date of the incident.

Note: The required fields are marked as required and must be filled in for the form to be submitted.
