# Land Use Rezoning Application Form - Help Guide
## Purpose

The Land Use Rezoning Application Form is a formal application used to change the land use designation of a property. This form requires detailed information about the property, the proposed land use, and supporting documentation.

## How To Complete This Form

1.  Ensure you have all the required information before starting the application process.
2.  Review the municipal zoning ordinance for specific requirements and regulations.
3.  Fill in the form accurately and thoroughly, including all required fields.
4.  Attach supporting documents as specified in the form.

## Field-by-Field Explanation

* **User Email (Required)**: Enter your email address to be contacted regarding the application status.
* **First Name (Required)**: Provide your first name as the applicant or representative.
* **Last Name (Required)**: Enter your last name as the applicant or representative.
* **Property Address (Required)**: Enter the exact address of the property in question.
* **Project Location (Optional)**: Specify whether the project will be located on the property (Yes/No).
* **Zoning Description (Required)**: Provide a detailed description of the proposed land use.
* **Supporting Documents (Required)**: Attach any relevant documents supporting your application, such as plans or diagrams.
* **Land Use (Optional)**: Specify whether the land use will be single or multi-family (Yes/No).
* **Zone Type (Optional)**: Select the type of zone for the property (single/multi).
* **Justification (Required)**: Provide a clear and concise explanation for the rezoning request.
* **Property Owner (Optional)**: Specify whether the property owner is the applicant (Yes/No).

## Tips

* Ensure all required fields are filled out accurately and thoroughly.
* Attach all necessary supporting documents to facilitate the application process.
* If you're unsure about any aspect of the form or the rezoning process, review the municipal zoning ordinance or consult with the relevant authorities.
