# Fuel Expense Validation Form - Help Guide

## Purpose
The Fuel Expense Validation Form is used to gather information about employee fuel expenses. The form is designed to collect data on expenses such as date, type, amount, mileage, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:
* Enter the date of the expense in the "Expense Date" field.
* Select the type of expense from the options provided (Vehicle, Fuel Card, or Other).
* Enter the amount of the expense.
* Enter the mileage for the expense.
* Provide any additional notes or comments about the expense.
* Select the status of the expense (Approved, Rejected, or Pending).
* Select the employee, manager, and department IDs associated with the expense.
* Enter the vehicle ID, fuel card ID, and other relevant information about the expense.
* Enter the employee, manager, and department names associated with the expense.
* Enter the vehicle and fuel card numbers associated with the expense.
* Enter any additional mileage details such as miles and rate description.

## Field-by-Field Explanation

* **Date Of Expense**: Enter the date on which the expense was incurred.
* **Expense Type**: Select the type of expense (Vehicle, Fuel Card, or Other).
* **Amount**: Enter the total amount of the expense.
* **Mileage**: Enter the total mileage associated with the expense.
* **Notes**: Enter any additional notes or comments about the expense.
* **Expense Date**: Enter the date on which the expense is being reported.
* **Mileage Rate**: Enter the mileage rate associated with the expense.
* **Expense Type ID**: Select the type of expense (Vehicle, Fuel Card, or Other).
* **Expense Date ID**: Select the date on which the expense is being reported (Today, Yesterday, or Last Week).
* **Mileage Rate ID**: Select the mileage rate associated with the expense.
* **Expense Status**: Select the status of the expense (Approved, Rejected, or Pending).
* **Employee ID**: Select the ID of the employee associated with the expense.
* **Manager ID**: Select the ID of the manager associated with the expense.
* **Department ID**: Select the ID of the department associated with the expense.
* **Vehicle ID**: Select the type of vehicle associated with the expense.
* **Fuel Card ID**: Select the type of fuel card associated with the expense.
* **Employee Name**: Enter the name of the employee associated with the expense.
* **Manager Name**: Enter the name of the manager associated with the expense.
* **Department Name**: Enter the name of the department associated with the expense.
* **Vehicle Number**: Enter the number of the vehicle associated with the expense.
* **Fuel Card Number**: Enter the number of the fuel card associated with the expense.
* **Mileage Miles**: Enter any additional mileage details.
* **Mileage Rate Description**: Enter any additional details about the mileage rate.
* **Expense Date Description**: Enter any additional details about the expense date.
* **Notes**: Enter any additional notes or comments about the expense.
