# Meeting Communication Form - Help Guide
## Purpose
The Meeting Communication Form is used to capture relevant details and feedback from meeting participants after the meeting has taken place. This information helps the organizers and attendees to communicate more effectively and follow up on necessary actions.

## How To Complete This Form

To complete this form, please review the meeting agenda and other relevant details before providing feedback. Ensure all relevant fields are filled out accurately and completely.

1. **Meeting Agenda**: Enter a brief summary of the meeting's agenda, including any discussion or actions that need to be followed up on.
2. **Participant Feedback**: Provide any comments or feedback from the participants regarding the meeting.
3. **Follow Up Actions**: List any actions that need to be taken as a result of the meeting, including deadlines and responsible parties.
4. **Participant Names**: Select which participants attended the meeting, using the options provided.
5. **Participant Emails**/Participant Phones**: Enter the email addresses and/or phone numbers of the participants who attended.
6. **Meeting Notes**: Enter any additional meeting notes, such as decisions made or action items discussed.
7. **Meeting Start Time**: Enter the start time of the meeting, using the time picker.
8. **Meeting End Time**: Enter the end time of the meeting, using the time picker.
9. **Meeting Date**: Enter the date of the meeting, using the date picker.

## Field-by-Field Explanation

* **Meeting Agenda** (`meeting_agenda`, text, optional): Enter a brief summary of the meeting's agenda, including any discussion or actions that need to be followed up on.
* **Participant Feedback** (`participant_feedback`, text, optional): Provide any comments or feedback from the participants regarding the meeting.
* **Follow Up Actions** (`follow_up_actions`, text, optional): List any actions that need to be taken as a result of the meeting, including deadlines and responsible parties.
* **Participant Names** (`participant_names`, select_multiple, optional): Select which participants attended the meeting, using the options provided.
*   *Note: The participant names option will list available participant names from previous meetings. You can select all or some of them.*
* **Participant Emails** (`participant_emails`, text, optional): Enter the email addresses of the participants who attended.
* **Participant Phones** (`participant_phones`, text, optional): Enter the phone numbers of the participants who attended.
*   *Note: This field is for phone numbers, not participant names.*
* **Meeting Notes** (`meeting_notes`, text, optional): Enter any additional meeting notes, such as decisions made or action items discussed.
* **Meeting Start Time** (`meeting_start_time`, time, optional): Enter the start time of the meeting, using the time picker.
* **Meeting End Time** (`meeting_end_time`, time, optional): Enter the end time of the meeting, using the time picker.
* **Meeting Date** (`meeting_date`, date, optional): Enter the date of the meeting, using the date picker.
