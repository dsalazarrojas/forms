# vendor_banking_information_update - Help Guide
## Purpose
The vendor_banking_information_update form is used for updating vendor banking information.

## How To Complete This Form
1. Fill out all the required fields with accurate and up-to-date information.
2. Review your answers carefully before submitting.
3. Double-check for any errors or typos.
4. Make sure to update all necessary fields to ensure that the information is correct.

## Field-by-Field Explanation
* **Vendor Name** (`vendor_name`, text, optional): This field is for the vendor's name.
* **Banking Institution** (`banking_institution`, text, optional): This field is for the banking institution's name.
* **Branch** (`branch`, text, optional): This field is for the branch's name.
* **Account Number** (`account_number`, text, optional): This field is for the account number.
* **Account Type** (`account_type`, text, optional): This field is for the account type.
* **Routing Number** (`routing_number`, text, optional): This field is for the routing number.
* **Bank Name** (`bank_name`, text, optional): This field is for the bank's name.
* **Address** (`address`, text, optional): This field is for the bank's address.
* **City** (`city`, text, optional): This field is for the city's name.
* **State** (`state`, text, optional): This field is for the state's name.
* **Zip** (`zip`, text, optional): This field is for the zip code.
* **Email** (`email`, text, optional): This field is for the bank's email.
* **Phone** (`phone`, text, optional): This field is for the bank's phone number.
* **Fax** (`fax`, text, optional): This field is for the bank's fax number.
* **Note** (`note`, text, optional): This field is for any additional comments or notes.
* **Bank Account Type** (`bank_account_type`, text, optional): This field is for the type of bank account.
* **Bank Account Number** (`bank_account_number`, text, optional): This field is for the bank account number.
* **Bank Routing Number** (`bank_routing_number`, text, optional): This field is for the bank's routing number.
* **Bank Branch** (`bank_branch`, text, optional): This field is for the bank branch.
* **Bank Name** (`bank_name`, text, optional): This field is for the bank's name.
* **Bank ABA** (`bank_aba`, text, optional): This field is for the bank's ABA number.
* **Bank Account Status** (`bank_acount_status`, text, optional): This field is for the bank account status.
* **Bank ABA Status** (`bank_aba_status`, text, optional): This field is for the bank's ABA status.
* **Bank Routing Status** (`bank_routing_status`, text, optional): This field is for the bank's routing status.
* **Bank Account Verification** (`bank_acount_verification`, text, optional): This field is for verifying the bank account.
