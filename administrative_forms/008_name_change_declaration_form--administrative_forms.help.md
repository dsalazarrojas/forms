# Name Change Declaration Form - Help Guide
## Purpose
The "Name Change Declaration Form" is used to request a formal change to an individual or entity's name. This form is meant for significant name changes, such as mergers, acquisitions, or other major rebranding events.

## How To Complete This Form
1. Ensure you are a registered user and have the authority to submit this form.
2. Review the form fields and ensure you understand each field's purpose.
3. Fill out the form carefully and accurately, providing all required and optional information.

## Field-by-Field Explanation
* **Name** (`name_change_declaration_form_name`, text, required): Enter the new name you wish to declare.
* **Old Name** (`name_change_old`, text, optional): If applicable, enter the old name for context or reference.
* **Date of Event** (`name_change_date_of_event`, date, optional): If the name change is the result of an event (e.g., merger), enter the date of this event.
* **Reason for Name Change** (`name_change_reason`, text, optional): Briefly explain the reason for the name change.
* **Documentation Type** (`name_change_documentation_type`, select_one, optional): Indicate the type of documentation supporting the name change. Choose from the provided options.
* **Documentation** (`name_change_documentation`, text, optional): Attach any supporting documentation for the name change.
* **Attachment** (`name_change_documentation_attachment`, text, optional): If additional attachments are required, upload them here.
* **Signed by** (`name_change_declaration_form_signed_by`, text, optional): Sign the form with your name and title/position.

## Tips
* Ensure all required fields are completed accurately and truthfully.
* Attach all necessary documentation to support the name change.
* If unsure about any field, consult the relevant authorities or seek guidance.
