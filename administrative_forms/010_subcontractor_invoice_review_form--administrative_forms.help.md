# Subcontractor Invoice Review Form - Help Guide
## Purpose
This form is used to review and manage subcontractor invoices to ensure accuracy and completeness before proceeding with the payment process.

## How To Complete This Form
1. Scroll through the form and review each field for required and optional information.
2. Enter your review status, whether the invoice is "Active" or "Inactive".
3. Select "Yes" or "No" to indicate if you reviewed the invoice.
4. If applicable, enter the date you reviewed the invoice.
5. Enter any comments or notes you'd like to make about the invoice.
6. Specify the number of approvals required for the invoice.
7. Specify the number of revisions made to the invoice.

## Field-by-Field Explanation
* **Subcontractor Invoices**: This field is a list of subcontractor invoices that need to be reviewed. Please scroll through the list and review each invoice.
* **Review Status**: This field allows you to indicate the status of the invoice, whether it is "Active" or "Inactive". Please select the status that applies to the invoice.
* **Reviewed By**: This field indicates whether you or someone else reviewed the invoice. Please select "Yes" or "No" to indicate your involvement.
* **Date Reviewed**: This field is used to record the date you reviewed the invoice. Please enter the date using the date picker format.
* **Comment**: This field is for any additional comments or notes you'd like to make about the invoice. Please enter your comments here.
* **Approvals**: This field is used to specify the number of approvals required for the invoice. Please enter the number of approvals needed.
* **Revisions**: This field is used to record the number of revisions made to the invoice. Please enter the number of revisions.
