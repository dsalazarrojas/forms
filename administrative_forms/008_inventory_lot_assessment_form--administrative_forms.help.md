# Inventory Lot Assessment Form - Help Guide
## Purpose
The Inventory Lot Assessment Form is used to gather information about a specific lot, including its number, size, value, status, and assigned tool. This information is essential for maintaining accurate inventory records and ensuring that the lot is properly managed and accounted for.
## How To Complete This Form
To complete this form, follow these steps:
1. Enter the Lot Number, which is the unique identifier for the lot.
2. Provide the Lot Size, a brief description of the lot, if necessary.
3. Enter the Quantity of items in the lot.
4. Enter the Lot Value, which is the total value of the items in the lot.
5. Select the Currency of the lot value.
6. Choose the status of the lot from the available options (Active, Pending, or Reserved).
7. Optionally, provide a detailed description of the lot, if necessary.
8. Enter the contact information for the assigned tool, if applicable.

## Field-by-Field Explanation
* **Lot Number** (`1`, `number`, required): Enter the unique identifier for the lot, which is used to track and identify the lot.
* **Lot Size** (`2`, `text`, optional): Provide a brief description of the lot, which can be helpful for reference.
* **Quantity** (`3`, `number`, required): Enter the total quantity of items in the lot.
* **Lot Value** (`4`, `number`, required): Enter the total value of the items in the lot.
* **Currency** (`5`, `select_one`, required): Select the currency of the lot value (USD, CAD, EUR, or GBP).
* **Lot Status** (`6`, `select_multiple`, required): Choose the status of the lot from the available options (Active, Pending, or Reserved).
* **Lot Description** (`7`, `note`, optional): Optionally, provide a detailed description of the lot for further reference.
* **Assigned Tool** (`8`, `text`, required): Enter the contact information for the assigned tool, in the format 123-456-7890.
Note: This form is designed to be completed once a specific lot is identified. If the lot's details have changed, please create a new assessment form with the updated information. 

Tips:
* Please ensure that all required fields are completed accurately and thoroughly.
* If you are unsure about the lot's status, please contact the inventory team or the assigned tool for further clarification.
* This form is intended to provide a clear and concise overview of the lot's status and value. Please provide as much detail as possible to ensure accurate assessment.
