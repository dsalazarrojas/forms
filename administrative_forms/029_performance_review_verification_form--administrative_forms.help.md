# performance_review_verification_form - Help Guide

## Purpose
The performance Review Verification form is used to verify the performance review of employees in the organization. This form is used to record and track employee performance reviews, ensuring that all required information is collected and verified. The form is essential for maintaining accurate and up-to-date records of employee performance.

## How To Complete This Form

To complete this form, follow these steps:

1.  Select the performance review status for each employee: 
    - Choose "Yes" or "No" for each employee to indicate if their performance review is complete or not.
2.  Enter the name of the employee: 
    - Type the full name of the employee.
3.  Enter the review date: 
    - Select a date from the calendar when the performance review was done.
4.  Rate the performance: 
    - Select a rating for the performance review from the options "Good" or "Fair".
5.  Enter feedback: 
    - Type any additional comments or notes about the performance review.
6.  Evaluation form: 
    - Enter any additional information or comments about the performance review.

## Field-by-Field Explanation

*   **Performance Review (performance_review)**: 
    - This field allows you to select whether the performance review is complete or not. Choose "Yes" or "No" to indicate the status.
*   **Employee Name (employee_name)**: 
    - This field is used to enter the full name of the employee being reviewed.
*   **Review Date (review_date)**: 
    - Select the date when the performance review was completed.
*   **Rating (rating)**: 
    - Select a rating from "Good" or "Fair" to evaluate the performance review.
*   **Feedback (feedback)**: 
    - Enter any additional comments or notes about the performance review.
*   **Evaluation Form (evaluation_form)**: 
    - Enter any additional information or comments about the performance review.

**Tips**

*   Please ensure that all required fields are completed before submitting the form.
*   Use the "Good" or "Fair" rating for the performance review based on your evaluation.
*   Keep the feedback section concise and relevant to the performance review.
*   If you need to make any changes to the performance review, please contact the relevant personnel for assistance.
