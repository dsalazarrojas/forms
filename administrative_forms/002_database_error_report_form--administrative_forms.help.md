# Database Error Report Form - Help Guide
## Purpose
The "Database Error Report Form" is designed for users to report database errors that occur within a system or application. This form collects information about the nature, severity, and impact of the errors, which will be used to assist the support team in resolving these issues efficiently.

## How To Complete This Form

1.  Select a date for the error to report.
2.  Describe the error in as much detail as possible.
3.  Choose the user who experienced the error.
4.  Indicate the category of the error (if applicable).
5.  Select the severity level of the error.
6.  Enter any further error details that might be helpful.
7.  If applicable, choose the error code(s) related to the issue.
8.  Optionally, attach a screenshot that might illustrate the error.

## Field-by-Field Explanation

*   **Database Error Form**: This field is a note type field where you can enter any additional comments or remarks about the error.
    *   Type: note
*   **Report Date**: This field is a date field where you select the date the error occurred.
    *   Type: date
*   **Description**: This field is a text field where you can enter details about the error.
    *   Type: text
*   **User**: This field is a dropdown menu where you select the user who experienced the error.
    *   Type: select_one
*   **Category**: This field is a dropdown menu where you select a category related to the error (if applicable).
    *   Type: select_multiple
*   **Severity**: This field is a dropdown menu where you select the severity level of the error.
    *   Type: select_one
*   **Error Details**: This field is a text field where you can enter further details that might be helpful in resolving the error.
    *   Type: text
*   **Error Code**: This field is a dropdown menu where you select error code(s) related to the issue (if applicable).
    *   Type: select_multiple
*   **Screenshot**: This field is a text field where you can attach a screenshot that might illustrate the error.
    *   Type: text

Tips:
- Please be as detailed as possible when filling out the "Description" and "Error Details" fields.
- If you are unsure about the error category or severity, you can choose "Other" or "Unknown" to indicate this uncertainty.
- If you are unable to attach a screenshot, you can skip this field.
- Remember, providing accurate and comprehensive information will assist the support team in resolving the errors more efficiently.
