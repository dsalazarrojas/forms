# Project Milestone Monitoring Form - Help Guide
## Purpose
This form is designed to help monitor and track project milestones, ensuring that progress and deadlines are met. It gathers essential information about project status, deadlines, and responsible parties.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary information about the project.
2. Fill in the required fields:
	* **Project Milestone**: Enter a brief description of the project milestone.
	* **Project Deadline**: Select the date the project is expected to be completed.
	* **Responsible Party**: Identify the person or team responsible for the project.
	* **Project Status**: Choose the current status of the project from the available options (On Track, Delayed, or Completed).
3. Optionally, add any additional information or comments about the project if needed.

## Field-by-Field Explanation
### Project Milestone
* **Project Milestone** (`project_milestone`, text, optional): A brief description of the project milestone, such as a specific task or objective.

### Project Deadline
* **Project Deadline** (`project_deadline`, date, optional): The date the project is expected to be completed.

### Responsible Party
* **Responsible Party** (`responsible_party`, text, optional): The person or team responsible for the project.

### Project Status
* **Project Status** (`project_status`, select_one, optional): Choose from the available options:
	+ **On Track**: The project is progressing as planned.
	+ **Delayed**: The project is behind schedule.
	+ **Completed**: The project is finished.

## Tips
* Be accurate when selecting the project status to ensure accurate tracking.
* If you're unsure about a project's status, consult with the project lead or team members.
* Remember to update the form regularly to reflect changes in project status.
