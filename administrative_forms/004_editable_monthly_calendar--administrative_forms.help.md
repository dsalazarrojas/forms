# Editable Monthly Calendar - Help Guide

## Purpose
This form is used to create a customizable calendar entry for various purposes such as scheduling events, meetings, appointments, or tasks.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the month you want to create the calendar entry for from the dropdown menu provided.
2. Enter the start date of the event by selecting the date from the calendar or typing it manually.
3. Enter the start and end times of the event in 24-hour format.
4. Choose whether the event is all-day, half-day, or full-day by selecting the appropriate option.
5. Enter any additional information or notes about the event in the notes field.
6. If applicable, select the event's organizer from the provided options.
7. Decide if the event is recurring by selecting the option from the dropdown menu.

## Field-by-Field Explanation
### Calendar Month
* Calendar Month (number): Select the month for which you want to create the calendar entry for.
* Type: number

### Start Date
* Start Date (date): Enter the start date of the event.
* Type: date

### Start Time
* Start Time (time): Enter the start time of the event in 24-hour format (e.g., 14:00 for 2:00 PM).
* Type: time

### End Time
* End Time (time): Enter the end time of the event in 24-hour format (e.g., 16:00 for 4:00 PM).
* Type: time

### Duration
* Duration (number): Enter the duration of the event.
* Type: number

### All Day
* All Day (select_one): Choose whether the event is all-day, half-day, or full-day.
* Options: All Day, Half Day, Full Day
* Type: select_one

### Notes
* Notes (note): Enter any additional information or notes about the event.
* Type: note

### Organizer
* Organizer (select_multiple): If applicable, select the event's organizer from the provided options.
* Options: Yes, No
* Type: select_multiple

### Recurring
* Recurring (select_multiple): Decide if the event is recurring by selecting the option from the dropdown menu.
* Options: Yes, No
* Type: select_multiple

### Tags
* Tags (select_multiple): Currently not supported in this form.

### Example Use Cases
This form is useful for creating event schedules, meetings, appointments, or tasks for various purposes such as work, school, or personal events. It is also useful for creating repeating events or recurring tasks.
