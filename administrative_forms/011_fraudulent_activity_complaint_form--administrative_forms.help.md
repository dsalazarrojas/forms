# Fraudulent Activity Complaint Form - Help Guide
## Purpose
This form is designed to report and document fraudulent activity, allowing for a detailed investigation and resolution of the issue.

## How To Complete This Form
1. Fill out each field accurately and thoroughly.
2. Provide supporting documentation if applicable.
3. Ensure all required fields are filled out, indicated by an asterisk (\*) or a bold font.

## Field-by-Field Explanation
* **Report Fraudulent Activity** (`report_fraudulent_activity`, text, required): Briefly describe the fraudulent activity that occurred.
* **Activity Details** (`activity_details`, text, required): Provide a detailed description of the suspicious activity.
* **Supporting Documents** (`supporting_documents`, select_multiple, required): Select any supporting documents that can help with the investigation (e.g., receipts, photos, or videos).
* **Contact Info** (`contact_info`, text, optional): Provide your contact information if you would like to be updated on the investigation status.
* **Email** (`email`, email, optional): Enter your email address if you would like to receive updates on the investigation status.
* **Complaint Summary** (`complaint_summary`, note, optional): Summarize your complaint, if desired.
* **Investigation Status** (`investigation_status`, select_one, required): Select the current status of the investigation (Under Investigation, Closed, or Not Investigated).
* **Follow-up** (`follow_up`, date, optional): Enter the date you would like to receive a follow-up on the investigation status.
* **Fraud Type** (`fraud_type`, select_one, required): Select the type of fraud that occurred (Credit Card Fraud, Identity Theft, or Other).
* **Report Date** (`report_date`, date, optional): Enter the date you submitted this report.
* **Reported By** (`reported_by`, text, optional): Enter your name, if you would like to be identified as the complainant.
* **Investigation Date** (`investigation_date`, date, optional): Enter the date the investigation started.
* **Closed Date** (`closed_date`, date, optional): Enter the date the case was closed.
* **Follow-up Date** (`follow_up_date`, date, optional): Enter the date you received follow-up on the investigation status.
* **Follow-up Status** (`follow_up_status`, select_one, required): Select the follow-up status (Done, Not Done).
* **Fraud Amount** (`fraud_amount`, number, optional): Enter the amount involved in the fraud.
* **Case Status** (`case_status`, select_one, required): Select the status of the case (Open, Closed, Dismissed).
* **Case Manager** (`case_manager`, select_one, required): Select the manager handling the case (Manager 1, Manager 2, Manager 3).
* **Notes** (`notes`, text, optional): Enter any notes or comments about the case.
* **Follow-up Notes** (`follow_up_notes`, text, optional): Enter any follow-up notes.
* **Investigation Notes** (`investigation_notes`, text, optional): Enter any investigation notes.
* **Fraud Type Details** (`fraud_type_details`, text, optional): Enter more details about the fraud type.
* **Fraud Summary** (`fraud_summary`, text, optional): Enter a summary of the fraud.
* **Follow-up Summary** (`follow_up_summary`, text, optional): Enter a follow-up summary.
* **Closed Comments** (`closed_comments`, text, optional): Enter any comments about the case closure.

## Tips
* Ensure you have all necessary information and supporting documents before submitting this form.
* Complete the form accurately and thoroughly.
* Review and double-check your information before submission.
* Contact the designated contact person or department for any questions or concerns.
