# Project Plan Upload Form - Help Guide
## Purpose
This form is for uploading project plan documents with details about a project, including its name, description, start and end dates, status, teams involved, project manager's email, budget, and other supporting information.

## How To Complete This Form
1. Start by filling in the **project name** field with the name of the project you are uploading the plan for.
2. Provide a brief **project description** in the text field.
3. Enter the **project start date** using the date picker.
4. Enter the **project end date** using the date picker.
5. Choose the **project status** by selecting from the dropdown menu.
6. Select the relevant **teams** involved in the project from the dropdown menu.
7. Click on the **upload project plan document** field to upload a file.
8. Enter the **project manager email** in the format of "example@example.com".
9. Enter the **project budget** as a numerical value.
10. Add any **additional notes** about the project in the text field.
11. Enter the **expected completion date** using the date picker.
12. Finally, choose the **project type** from the dropdown menu.

## Field-by-Field Explanation
* **project name** (Text): The name of the project being uploaded.
* **project description** (Text): A brief description of the project.
* **project start date** (Date): The start date of the project.
* **project end date** (Date): The end date of the project.
* **project status** (Select One): The current status of the project.
* **Choose relevant teams** (Select Multiple): Select all the teams involved in the project.
* **upload project plan document** (Text): Upload a file with the project plan details.
* **project manager email** (Email): The email of the project manager.
* **project budget** (Number): The budget allocated for the project.
* **additional notes** (Text): Any additional notes about the project.
* **expected completion date** (Date): The expected completion date of the project.
* **project type** (Select One): The type of the project.
