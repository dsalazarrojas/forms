# Soda Spill Incident Report - Help Guide
## Purpose

The Soda Spill Incident Report is a form designed to record incidents involving soda spills. This report helps with inventory tracking, safety, and regulatory compliance.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the **Spill Location** field with the exact address or location where the spill occurred.
2. Choose the date of the spill from the calendar provided.
3. Select the time of the spill using the time picker.
4. Enter the amount of soda spilled, if known.

## Field-by-Field Explanation

* **Spill Location** (`spill_location`, text, optional): Enter the exact address or location where the spill occurred.
* **Spill Date** (`spill_date`, date, optional): Select the date of the spill from the calendar provided.
* **Spill Time** (`spill_time`, time, optional): Select the time of the spill using the time picker.
* **Spill Amount** (`spill_amount`, number, optional): Enter the amount of soda spilled, if known.

## Tips

* If the spill occurred outside, be sure to include the nearest landmark or a brief description of the location.
* If the spill was caused by a specific event, such as a machine failure or human error, be sure to specify the cause.
* If the spill resulted in a known impact, such as contamination or financial loss, be sure to document the consequences.
