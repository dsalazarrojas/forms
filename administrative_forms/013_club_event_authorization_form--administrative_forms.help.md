# Club Event Authorization Form - Help Guide
## Purpose
The Club Event Authorization Form is designed to collect essential information about events organized by the club. This form helps ensure that all necessary details are captured for proper planning and approval. It's essential to fill out this form accurately to avoid any issues with event organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the official name of the event in the "Event Name" field (Field 1).
2. Select the date of the event in the "Event Date" field (Field 2).
3. Choose the start and end times of the event in the "Event Start Time" and "Event End Time" fields (Fields 3 and 4).
4. Enter the location of the event in the "Event Location" field (Field 5).
5. Specify the expected number of attendees for the event in the "Expected Number of Attendees" field (Field 6).
6. Identify the primary event organizer in the "Primary Event Organizer" field (Field 7).
7. Provide the email address of the primary event organizer in the "Organizer Email" field (Field 8).
8. Enter the phone number of the primary event organizer in the "Organizer Phone" field (Field 9).
9. Select the name of the club sponsoring the event in the "Club Name" field (Field 10).
10. Choose the type of event from the provided options in the "Type of Event" field (Field 11).
11. Indicate whether food or beverages will be served during the event in the "Will Food or Beverages Be Served" field (Field 12).
12. Specify if alcohol will be served during the event in the "Will Alcohol Be Served" field (Field 13).
13. Check if the event is held outdoors in the "Is This an Outdoor Event" field (Field 14).
14. Describe the safety measures in place for the event in the "Safety Plan Description" field (Field 15).
15. Confirm if insurance coverage is required for the event in the "Insurance Coverage Confirmation" field (Field 16).
16. Indicate if approval from a higher authority is needed for the event in the "Approval Status" field (Field 17).

## Field-by-Field Explanation

* **Event Name** (1): Enter the official name of the event.
* **Event Date** (2): Select the date of the event.
* **Event Start Time** (3): Choose the start time of the event.
* **Event End Time** (4): Choose the end time of the event.
* **Event Location** (5): Enter the location of the event, such as building or venue.
* **Expected Number of Attendees** (6): Specify the expected number of attendees.
* **Primary Event Organizer** (7): Enter the name of the primary event organizer.
* **Organizer Email** (8): Enter the email address of the primary event organizer.
* **Organizer Phone** (9): Enter the phone number of the primary event organizer.
* **Club Name** (10): Select the name of the club sponsoring the event.
* **Type of Event** (11): Choose the type of event from the provided options.
* **Will Food or Beverages Be Served** (12): Indicate if food or beverages will be served during the event.
* **Will Alcohol Be Served** (13): Specify if alcohol will be served during the event.
* **Is This an Outdoor Event** (14): Check if the event is held outdoors.
* **Safety Plan Description** (15): Describe the safety measures in place for the event.
* **Insurance Coverage Confirmation** (16): Confirm if insurance coverage is required for the event.
* **Approval Status** (17): Indicate if approval from a higher authority is needed for the event.
