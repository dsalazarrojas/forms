# Student Organization Reimbursement Request - Help Guide
## Purpose
The Student Organization Reimbursement Request form is used to submit a reimbursement request for expenses related to student organization activities. To complete this form, follow the steps below.

## How To Complete This Form
1. Fill out the required fields with the necessary information.
2. Upload any relevant supporting documents, such as receipts.
3. Submit the form.

## Field-by-Field Explanation

* **Student Organization Reimbursement Request** (`request_form`, `text`, **required**):
	+ Enter a brief description of the reason for the reimbursement request.
* **Expense Details** (`expense_details`, `number`, **required**):
	+ Enter the total cost of the expense.
* **Upload Expense Receipt** (`upload_expense_receipt`, `text`, **optional**):
	+ Upload any receipts or documents that support the expense.
* **Expense Date** (`expense_date`, `date`, **required**):
	+ Enter the date of the expense.
* **Expense Description** (`expense_description`, `text`, **optional**):
	+ Enter a brief description of the expense.
* **Expense Type** (`expense_type`, `select_one`, **optional**):
	+ Select the type of expense (Student Club, Club Event, Club Travel, or Other).
* **Expense Category** (`expense_category`, `select_multiple`, **optional**):
	+ Select the categories of expense (Travel, Food, or Other).
* **Expense Subtype** (`expense_subtype`, `select_one`, **optional**):
	+ Select the subtype of expense (Local, Regional, National, or International).
