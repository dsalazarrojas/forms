# Cybersecurity Breach Intake Form - Help Guide
## Purpose
The Cybersecurity Breach Intake Form is used to gather information about incidents that may compromise the security of an organization's systems or data.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct incident type from the list provided.
2. Choose the date and time the incident occurred.
3. Provide a detailed description of what happened during the incident.
4. Fill in all other required fields (indicated by *).

## Field-by-Field Explanation

* **Incident Details (Page 1)**:
	+ *Incident Type*: Select the type of incident that occurred (e.g., Phishing, Malware, Ransomware).
	+ *Date of Incident*: Enter the date the incident occurred.
	+ *Time of Incident*: Enter the time the incident occurred.
* **Incident Description (Page 2)**:
	+ *Incident Description*: Provide a detailed description of what happened during the incident, including as much information as possible.
* **Incident Description (Page 2)**:
	+ *This field is a duplicate of the previous field. Please skip it*.

## Tips
* If you are unsure of the incident type, select "Other" and describe it in the description field.
* If you are unable to determine the exact date and time of the incident, provide an estimate.
* If you are unable to complete this form, please contact [form@gic.mx](mailto:form@gic.mx).
