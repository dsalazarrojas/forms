# Peer Support Program Time Off Form - Help Guide

## Purpose
This form is used to request time off for the Peer Support Program. Please use this form to formally request time off for peer support program activities, such as attending meetings, workshops, or other program-related events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your employee ID in the "employee_id" field.
2. Select the date of your peer support program activity from the calendar in the "peer_support_program_date" field.
3. If applicable, select the start and end times of your activity in the "peer_support_program_start_time" and "peer_support_program_end_time" fields.
4. Provide any additional information about your activity in the "additional_information" field.
5. Select the peer support approver from the options in the "peer_support_program_approver" field.
6. Select the status of your activity from the options in the "peer_support_program_status" field.

## Field-by-Field Explanation

### **employee_id** (Number)
This is the employee's ID number.

### **peer_support_program_date** (Date)
Select the date of your peer support program activity.

### **peer_support_program_start_time** (Time)
If you have a specific start time for your activity, enter it here. This field is optional.

### **peer_support_program_end_time** (Time)
Enter the end time of your peer support program activity. This field is required.

### **additional_information** (Text)
Enter any additional details about your peer support program activity, such as location or agenda.

### **peer_support_program_approver** (Select One)
Select the person who will approve your peer support program activity.

### **peer_support_program_status** (Select Multiple)
Select all the statuses that apply to your peer support program activity.
