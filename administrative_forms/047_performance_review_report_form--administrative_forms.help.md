# Performance Review Report Form - Help Guide
## Purpose
The Performance Review Report Form is designed to document and evaluate employee performance, helping managers to track progress and provide constructive feedback.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's name in the "Employee Name" field (1).
2. Enter the manager's name in the "Manager Name" field (2).
3. Select the date of the evaluation in the "Evaluation Date" field (3), using the calendar icon to choose the correct date.
4. Write any relevant feedback in the "Feedback" field (4).
5. List the employee's strengths in the "Strengths" field (5).
6. Identify areas for improvement in the "Areas for Improvement" field (6).

## Field-by-Field Explanation
### 1. Employee Name
• **Employee Name** (`employee_name`, text, optional): Enter the employee's name as it appears on their personnel record.

### 2. Manager Name
• **Manager Name** (`manager_name`, text, optional): Enter the manager's name as it appears on their personnel record.

### 3. Evaluation Date
• **Evaluation Date** (`evaluation_date`, date, optional): Select the date of the performance evaluation using the calendar icon.

### 4. Feedback
• **Feedback** (`feedback`, text, optional): Provide any comments or suggestions for the employee's improvement.

### 5. Strengths
• **Strengths** (`strengths`, text, optional): List the employee's notable strengths, skills, or qualities that have contributed to their performance.

### 6. Areas for Improvement
• **Areas for Improvement** (`areas_for_improvement`, text, optional): Identify areas where the employee needs to improve, and suggest specific actions or training to support growth.
