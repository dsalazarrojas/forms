# Employee Records Access Form - Help Guide
## Purpose
The Employee Records Access Form is a tool used to manage employee access levels and permissions within the organization. It is used to input, update, and manage employee information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the requested information for the employee.
2. Select the appropriate access level for the employee from the dropdown menu.
3. Confirm the access level by selecting 'True' or 'False' in the 'confirm access' field.
4. Add any necessary notes about the employee's access level.
5. Save the form to update the employee's access level in the system.

## Field-by-Field Explanation

* **First Name** (1): Enter the employee's first name.
* **Last Name** (2): Enter the employee's last name.
* **Email** (3): Enter the employee's email address.
* **Job Title** (4): Enter a brief description of the employee's job title.
* **Department** (5): Select the department the employee belongs to. Options: HR, Finance, Sales, Marketing.
* **Manager ID** (6): Enter the ID of the employee's manager.
* **Employee ID** (7): Enter the ID of the employee.
* **Access Level** (8): Select the level of access the employee has. Options: View, Edit, Admin.
* **Access Notes** (9): Add any notes about the employee's access level.
* **Confirm Access** (10): Confirm the employee's access level by selecting 'True' or 'False'.
* **Created By** (11): Select who created the record. If filling out the form for yourself, choose "Self".
* **Updated By** (12): Select who last updated the record. If filling out the form for yourself, choose "Self".
* **Updated At** (13): The date the record was last updated. This will be automatically populated based on the system time.
* **Updated By At** (14): The time the record was last updated. This will be automatically populated based on the system time.

Please note that some fields have specific options, such as department and access level. These options should be carefully reviewed before selecting the correct answer.
