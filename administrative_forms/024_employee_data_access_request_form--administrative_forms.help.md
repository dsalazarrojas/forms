# Employee Data Access Request Form - Help Guide
## Purpose
This form is used to request access to sensitive or confidential data for various business purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill out the "Manager Name" field with the name of your manager.
2.  Select a valid reason for the data access request from the "Data Access Reason" dropdown menu.
3.  Choose the level of access you require from the "Access Level" dropdown menu.
4.  Enter your employee email address in the "Employee Email" field.
5.  Enter your employee phone number in the "Employee Phone" field.
6.  Provide any additional notes regarding your request in the "Employee Notes" field.

## Field-by-Field Explanation

* **Manager Name (Manager Name)** (text, required): Enter the name of your direct manager.
* **Data Access Reason (Data Access Reason)** (select_one, required): Select a valid reason for your data access request. Options: Data Access Request, Data Access Request for IT Security, Data Access Request for HR.
* **Access Level (Access Level)** (select_multiple, required): Choose the level of access you require. Options: Basic Access, Advanced Access, Critical Access.
* **Employee Email (Employee Email)** (email, required): Enter your employee email address.
* **Employee Phone (Employee Phone)** (text, required): Enter your employee phone number.
* **Employee Notes (Employee Notes)** (note, optional): Provide any additional notes or context regarding your request. 
* **Manager Notes (Manager Notes)** (note, optional): Provide any additional comments or context from your manager regarding your request. 

## Tips
* Please ensure that you have a valid reason for requesting data access before filling out this form.
* Please be specific about the level of access you require.
* This form is intended for data access requests for various business purposes. If you are unsure about the purpose of this form, please consult with your manager or HR representative.
* You can only select one reason for the data access request from the "Data Access Reason" dropdown menu.
* You can select multiple levels of access from the "Access Level" dropdown menu.
* You can leave the "Manager Notes" field empty if you are unsure about what to write or if you have no additional comments.
* You can use the "Employee Notes" field to provide any additional context or comments about your request.
