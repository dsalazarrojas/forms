# weekly_fire_alarm_test_checklist - Help Guide
## Purpose
The weekly fire alarm test checklist is a form used to monitor and record the status of the fire alarm system in your facility. This form helps ensure that the system is functioning correctly and meets the required safety standards.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Safety Officer responsible for the test.
2. Indicate the current system status (Active or Inactive).
3. Check if there are any alarm indicators.
4. Enter the maintenance schedule.
5. Choose the fire supervision level (High or Low).
6. Select the type of fire alarm system being tested.
7. Check if the system is inspected on a regular basis (Yes or No).
8. Enter the date of the last system inspection.
9. Check if the system has been tested (Yes or No).
10. Enter the date of the last system test.
11. Enter the test result (Yes or No).
12. Enter any comments for the test.
13. Enter the maintenance due date.
14. Check if the system is tested on a regular interval (Yes or No).
15. Select the test frequency (Yes or No).
16. Enter the maintenance status (Active or Inactive).
17. Enter any comments for the system.
