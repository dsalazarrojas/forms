# User Guide Update Form - Help Guide
## Purpose
This form is used to update user guides, which are essential resources for users to learn about a system or process.

## How To Complete This Form
To complete this form, follow the below steps:

1. Choose the category of the user guide from the Category field.
2. Input the description of the user guide in the Description field.
3. Input the title of the user guide in the Form Title field.
4. Choose one or more tags for the user guide from the Tags field.
5. Upload the file associated with the user guide using the File field.
6. Input the description of the file in the File Description field.
7. Input the size of the file in the File Size field.
8. Choose the MIME type of the file in the File MIME Type field.
9. Choose the version of the user guide from the Version field.
10. Input the date of the update in the Date field.
11. Input the time of the update in the Time field.
12. Input the email of the contact person in the Email field.
13. Input the phone number of the contact person in the Phone field.
14. Input any additional comments or notes in the Notes field.
