# scaffolding_incident_report - Help Guide
## Purpose
The Scaffolding Incident Report form is a tool used to document and report incidents that have occurred within a scaffolding construction site. It helps gather relevant information about the incident, including details about the incident itself, witness statements, and reporter information.

## How To Complete This Form
To complete this form, follow these steps:

* Review each page carefully to ensure you are filling out the form completely and accurately.
* For each field, provide detailed and relevant information about the incident.
* If you are unsure about any field, you can refer to the field-by-field explanations below for clarification.

## Field-by-Field Explanation

* **Incident Details**
	+ <label>Incident Details</label> (`name`: `incident_details`, `type`: `text`, `required`: `false`)
	+ This field is used to provide a brief description of the incident. Please provide as much detail as possible about what happened.
* **Incident Date**
	+ <label>Incident Date</label> (`name`: `incident_date`, `type`: `date`, `required`: `false`)
	+ This field is used to record the date the incident occurred. Please enter the date in the format MM/DD/YYYY.
* **Incident Time**
	+ <label>Incident Time</label> (`name`: `incident_time`, `type`: `time`, `required`: `false`)
	+ This field is used to record the time the incident occurred. Please enter the time in the format HH:MM AM/PM.
* **Incident Location**
	+ <label>Incident Location</label> (`name`: `incident_location`, `type`: `text`, `required`: `false`)
	+ This field is used to record the location where the incident occurred. Please provide the exact location, including the address or area where the incident took place.
* **Incident Description**
	+ <label>Incident Description</label> (`name`: `incident_description`, `type`: `text`, `required`: `false`)
	+ This field is used to provide a detailed description of the incident. Please provide as much information as possible about what happened, including any relevant details or circumstances surrounding the incident.
* **Incident Image**
	+ <label>Incident Image</label> (`name`: `incident_image`, `type`: `text`, `required`: `false`)
	+ This field is used to upload or link to an image related to the incident. This can be a useful tool for documenting visual evidence.
* **Witness Details**
	+ <label>Witness Details</label> (`name`: `witness_details`, `type`: `text`, `required`: `false`)
	+ This field is used to record any details about witnesses who may have been present during the incident. Please provide any relevant information about the witnesses, including their names, positions, or any other relevant details.
* **Witness Statement**
	+ <label>Witness Statement</label> (`name`: `witness_statement`, `type`: `text`, `required`: `false`)
	+ This field is used to record a statement from any witnesses who may have seen or experienced the incident. Please provide a clear and detailed statement from the witness.
* **Incident Reporter**
	+ <label>Incident Reporter</label> (`name`: `incident_reporter`, `type`: `text`, `required`: `false`)
	+ This field is used to record the name or title of the person reporting the incident. Please enter the name or title of the person completing this report.
* **Reporting Date**
	+ <label>Reporting Date</label> (`name`: `reporting_date`, `type`: `date`, `required`: `false`)
	+ This field is used to record the date this incident report is being submitted. Please enter the date in the format MM/DD/YYYY.
* **Reporting Time**
	+ <label>Reporting Time</label> (`name`: `reporting_time`, `type`: `time`, `required`: `false`)
	+ This field is used to record the time this incident report is being submitted. Please enter the time in the format HH:MM AM/PM.

## Tips
* Please fill out the form completely and accurately to ensure that all relevant information about the incident is documented.
* If you are unsure about any field, refer to the field-by-field explanations above for clarification.
* If you have any issues or concerns while filling out this form, please contact form@gic.mx for assistance.
