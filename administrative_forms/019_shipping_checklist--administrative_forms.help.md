# Shipping Checklist - Help Guide
## Purpose
This form is used to collect and verify important information for smooth shipping processes.

## How To Complete This Form
To complete the Shipping Checklist form, follow these steps:

1. Fill out the **Package Details** field (Page 1) with any relevant information about the package, such as its contents or special handling requirements.
2. Enter the **Shipping Address** (Page 1) where the package will be delivered to, in a clear and readable format.
3. Choose the **Shipping Method** (Page 2) from the options provided (Yes/No).
4. If applicable, provide the **Tracking Number** (Page 2) for easier tracking and monitoring.
5. Select the **Ship By** date (Page 2) when the package should be shipped by.
## Field-by-Field Explanation

* **Package Details** (`package_details`, text, optional): Enter any relevant details about the package.
* **Shipping Address** (`shipping_address`, text, optional): Enter the shipping address, including any relevant notes or special instructions.
* **Shipping Method** (`shipping_method`, select_multiple, optional): Choose 'Yes' or 'No' to indicate the shipping method used.
* **Tracking Number** (`tracking_number`, text, optional): If available, enter the tracking number for easier tracking and monitoring.
* **Ship By** (`ship_by_date`, date, optional): Select the date by which the package should be shipped.

## Tips
- Make sure to fill out the form as accurately and thoroughly as possible to ensure smooth shipping processes.
- Double-check all fields before submitting the form to avoid errors.
- Use the tracking number provided to monitor package delivery status.
- Update the ship by date if changes occur or if the package needs to be rescheduled.
