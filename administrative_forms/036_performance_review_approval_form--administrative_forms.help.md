# Performance Review Approval Form - Help Guide
## Purpose
The Performance Review Approval Form is a document that helps managers approve or reject performance reviews submitted by employees. It provides a structured way to evaluate an employee's performance over a period of time and makes it easier for managers to make informed decisions about promotions, bonuses, or other employment actions.

## How To Complete This Form
To complete this form, follow these steps:

1.  **Enter the Manager Name**: In this field, enter the name of the manager responsible for the performance review.
2.  **Enter the Employee Name**: Enter the name of the employee being reviewed.
3.  **Enter the Job Title**: Enter the employee's current job title.
4.  **Enter the Review Date**: Select the date on which the performance review was completed.
5.  **Provide the Performance Rating**: Enter a numerical rating from 1 to 5 to reflect the employee's overall performance.
6.  **Provide Comments (optional)**: If you have any comments about the review, you can enter them in this field. Note that this field is not required.
7.  **Choose the Approval Status**: Select the approval status of the performance review:
    *   **Approved**: The review is approved without any issues or modifications.
    *   **Pending**: The review is waiting for further information or modifications before approval.
    *   **Rejected**: The review is not approved due to some issues or concerns.

## Field-by-Field Explanation
*   **Manager Name** (Manager Name, text, required): Enter the name of the manager responsible for the performance review.
*   **Employee Name** (Employee Name, text, required): Enter the name of the employee being reviewed.
*   **Job Title** (Job Title, text, required): Enter the employee's current job title.
*   **Review Date** (Review Date, date, required): Select the date on which the performance review was completed.
*   **Performance Rating** (Performance Rating, number, required): Enter a numerical rating from 1 to 5 to reflect the employee's overall performance.
*   **Comments** (Comments, text, optional): If you have any comments about the review, enter them in this field.
*   **Approval Status** (Approval Status, select_one, required): Select the approval status of the performance review.
