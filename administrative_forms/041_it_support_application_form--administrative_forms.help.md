# it_support_application_form - Help Guide
## Purpose
This form is used to submit and manage issues. Users can provide information about new issues, including the issue type, description, report date, report time, contact method, contact phone, contact email, and issue resolution. The form is designed to facilitate effective issue management.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "New Issue" field with a brief description of the issue.
2. Select the type of issue from the "Issue Type" dropdown list.
3. Enter a detailed description of the issue in the "Description" field.
4. Enter the date and time of the issue report in the "Report Date" and "Report Time" fields, respectively.
5. Select the contact method and enter the contact phone number and email address in the "Contact Method", "Contact Phone", and "Contact Email" fields, respectively.
6. Attach any relevant images or documents to the issue using the "Issue Image" and "Issue Attachment" fields.
7. Provide a brief description of the issue resolution in the "Issue Resolution" field.
8. Add any additional comments or explanations in the "Additional Comments" field.
9. Submit the form by clicking the "Submit" button.

## Field-by-Field Explanation

* **New Issue** (`new_issue`, text, optional): A brief description of the issue.
* **Issue Type** (`issue_type`, select_one, required): Select the type of issue from the dropdown list.
* **Description** (`description`, text, required): A detailed description of the issue.
* **Report Date** (`report_date`, date, required): The date of the issue report.
* **Report Time** (`report_time`, time, optional): The time of the issue report.
* **Contact Method** (`contact_method`, select_multiple, required): Select the contact method.
* **Contact Phone** (`contact_phone`, text, optional): Enter the contact phone number.
* **Contact Email** (`contact_email`, email, optional): Enter the contact email address.
* **Issue Image** (`issue_image`, text, optional): Attach an image related to the issue.
* **Issue Attachment** (`issue_attachment`, text, optional): Attach a document related to the issue.
* **Issue Description** (`issue_description`, text, required): A detailed description of the issue.
* **Contact Details** (`contact_details`, text, optional): Additional contact details.
* **Additional Comments** (`additional_comments`, text, optional): Add any additional comments or explanations.
* **Support Request** (`support_request`, text, optional): Provide a support request.
* **Support Request Comments** (`support_request_comments`, text, optional): Add comments related to the support request.
* **Issue Resolution** (`issue_resolution`, select_one, required): Select the issue resolution from the dropdown list.
* **Issue Resolution Comments** (`issue_resolution_comments`, text, optional): Add comments related to the issue resolution.
* **User Comments** (`user_comments`, text, optional): Add comments from the user.
* **Admin Comments** (`admin_comments`, text, optional): Add comments from the admin.
* **Submit** (`submit`, text, required): Click to submit the form.
* **Reset** (`reset`, text, optional): Reset the form.
* **Save** (`save`, text, optional): Save the form without submitting.
* **Save All** (`save_all`, text, optional): Save all changes without submitting.
* **Cancel** (`cancel`, text, optional): Cancel the form.
* **Back to Draft** (`back_to_draft`, text, optional): Go back to the draft version of the form.
