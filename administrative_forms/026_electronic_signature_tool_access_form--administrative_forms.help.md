# Electronic Signature Tool Access Form - Help Guide
## Purpose
This form is used to request access to the Electronic Signature Tool (EST) for authorized users.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with your information.
2. Select the correct tool type from the options provided.
3. Choose the correct tool name from the options provided.

## Field-by-Field Explanation
- **User Requesting Access** (`user_requesting_access`, `text`, optional): This field is for the name of the user requesting access to the EST.
  - Please enter the name of the user requesting access.
- **Tool ID** (`tool_id`, `number`, optional): This field is for the ID of the tool being requested.
  - If you are unsure of the ID, please ask your administrator for assistance.
- **Tool Name** (`tool_name`, `text`, optional): This field is for the name of the tool being requested.
  - Please enter the name of the tool being requested.
- **Tool Type** (`tool_type`, `select_one`, optional): This field is for the type of tool being requested.
  - Select "Electronic Signature Tool" if you are requesting access to the EST.
- **Tool Description** (`tool_description`, `text`, optional): This field is for a brief description of the tool being requested.
  - Please provide a brief description of the tool.
- **Assigned Tool** (`assigned_tool`, `select_one`, optional): This field is for the assigned tool from the options provided.
  - Please select the assigned tool from the list.
- **User Requested Tool ID** (`user_requested_tool_id`, `number`, optional): This field is for the ID of the tool being requested by the user.
  - If you are unsure of the ID, please ask your administrator for assistance.
- **User Requested Tool Name** (`user_requested_tool_name`, `text`, optional): This field is for the name of the tool being requested by the user.
  - Please enter the name of the tool being requested by the user.
