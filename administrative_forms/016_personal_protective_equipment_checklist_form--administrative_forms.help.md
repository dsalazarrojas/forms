# personal_protective_equipment_checklist_form - Help Guide

## Purpose
This form is used to record the status of personal protective equipment (PPE) used on a work site. It helps in tracking the availability and condition of PPE, ensuring that it is properly maintained and inspected.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the work site from the provided options.
2. Provide the employee ID of the person using the equipment.
3. Indicate if safety equipment is provided on the work site.
4. Check if the safety equipment is inspected regularly.
5. List the personal equipment being used.
6. Check if each item of personal equipment is worn and maintained.
7. Check if each item is checked out and returned.
8. Add any comments about the equipment.
9. Record the work start and finish times.
10. Record the date of work.

## Field-by-Field Explanation

* **Work Site**: Select the work site where the equipment is being used. This field is required.
	+ If you are not sure which work site you are on, please ask your supervisor or refer to the relevant documentation.
* **Employee ID**: Enter the ID of the employee using the equipment. This field is optional.
	+ If you are not sure of the employee ID, you can leave this field blank.
* **Equipment**: Indicate if safety equipment is provided on the work site.
	+ A 'Yes' or 'No' selection will help in tracking the availability of safety equipment.
* **Is Safety Equipment Inspected**: Check if the safety equipment is inspected regularly.
	+ Regular inspection of safety equipment ensures it is in good working condition.
* **Personal Equipment**: List the personal equipment being used on the work site.
	+ Examples: Hard hat, Safety glasses, Steel-toed shoes, etc.
* **Is Worn**: Check if each item of personal equipment is worn.
	+ Only select 'Yes' if the equipment is being used.
* **Is Maintained**: Check if each item of personal equipment is maintained.
	+ Regular maintenance ensures the equipment is in good working condition.
* **Is Checked Out**: Check if each item of personal equipment is checked out.
	+ This indicates that the equipment has been taken out for use.
* **Is Returned**: Check if each item of personal equipment is returned after use.
	+ This ensures the equipment is available for future use.
* **Comments**: Add any comments about the equipment or its condition.
* **Work Start Time**: Record the time when work started on the specified date.
* **Work Finish Time**: Record the time when work finished on the specified date.
* **Work Date**: Record the date of work.
