# Server Health Monitoring Check In Form - Help Guide

## Purpose
The Server Health Monitoring Check In Form is a tool used to track the status and performance of servers in your organization. It allows you to monitor and report on the health of individual servers, helping to identify potential issues and prevent downtime. 

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct server status: Choose the status of the server from the options provided. This will help us understand the current state of the server.
2. Rate the server performance: Evaluate the performance of the server, selecting either 'Yes' or 'No' to indicate whether the server is functioning properly.
3. Indicate if maintenance is required: Choose all the maintenance tasks that are required for the server from the provided options.
4. Enter the date of the last check-in: Select the date of the last check-in for the server, which will help us track the frequency and consistency of check-ins.

## Field-by-Field Explanation
- **server_health_check_in** (1, number, optional): Enter the server health check-in number, if applicable. This is a unique identifier for the check-in, which can be used for reference.
- **Server Status** (2, select_one, required): Choose the status of the server from the options provided. This indicates the current state of the server and can be 'Active' or 'Inactive'.
- **Server Performance** (3, select_one, optional): Evaluate the performance of the server, selecting either 'Yes' or 'No' to indicate whether the server is functioning properly.
- **Maintenance Required** (4, select_multiple, optional): Choose all the maintenance tasks that are required for the server from the provided options. This helps to identify specific issues that need to be addressed.
- **Check In Date** (5, date, optional): Enter the date of the last check-in for the server. This helps us track the frequency and consistency of check-ins.

## Tips
* Make sure to complete the form accurately and thoroughly.
* Review and update the form regularly to ensure the health of your servers is consistently monitored and reported.
* This form is not intended for immediate action, but as a record-keeping tool for server health monitoring.
* If you have any questions or concerns, please reach out to the server administration team.
