# Lockout/Tagout Procedures Training Form - Help Guide

## Purpose
This form is used to document lockout/tagout procedures, which is a critical aspect of maintaining equipment and machinery in a safe and organized manner. Lockout/tagout procedures ensure that equipment is safely shut down and cannot be used until it is properly inspected, tested, and repaired. This form helps to standardize and record procedures, reducing errors and improving equipment reliability.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category that best describes the purpose of the form.
2. Enter a brief description of the equipment or task being addressed.
3. Choose the tool that will be used for the lockout/tagout procedure.
4. Select a date for the training session.
5. Review and verify all information before submitting the form.

## Field-by-Field Explanation

* **Form ID** (`form_id`, Number, Optional): Enter a unique number to identify this form.
* **Category** (`category`, Select Multiple, Optional): Choose a category that best describes the purpose of the form. Options include:
	+ Administrative Forms
	+ Other
	+ Safety Procedures
* **Description** (`description`, Text, Optional): Enter a brief description of the equipment or task being addressed.
* **Assigned Tool** (`assigned_tool`, Select One, Optional): Choose the tool that will be used for the lockout/tagout procedure. Options include:
	+ chatjim
	+ chatjane
	+ chatjim
* **Training Session** (`training_session`, Date, Optional): Select a date for the training session.
 
## Tips
- Make sure to review the form carefully before submitting it to ensure all information is accurate and complete.
- If you are unsure about any part of the form, consult with your supervisor or the maintenance team.
- This form is for documenting lockout/tagout procedures only. If you need to document other types of procedures, please use the appropriate form for that purpose.
