# Trademark Infringement Report Form - Help Guide
## Purpose
This form is used to collect information about potential trademark infringement. Please fill out this form to report any instances of trademark infringement you are aware of.

## How To Complete This Form
1. Choose whether the trademark infringement has occurred by selecting the appropriate option from the dropdown menu.
2. Enter the name of the trademark being infringed upon.
3. Enter the name of the alleged infringer.
4. Provide a brief description of the infringement.
5. If applicable, enter the address where the alleged infringer is located.
6. Record the date and time of the infringement.
7. Enter any contact information for the alleged infringer (if known).
8. If there are additional instances of trademark infringement, select 'True' from the dropdown menu.
9. If you've selected "Additional Infringements" as true, please provide details about the additional infringing activities.

## Field-by-Field Explanation
* **Trademark Infringement** (Select Multiple):
	+ This field is used to determine if the trademark infringement has occurred. Select 'Yes' if you believe the infringement has taken place, 'No' otherwise.
* **Trademark Name**:
	+ Enter the name of the trademark being infringed upon.
* **Alleged Infringer Name**:
	+ Enter the name of the person or entity allegedly committing the trademark infringement.
* **Description of Infringement**:
	+ Provide a brief description of the infringement, including any relevant details such as the location and circumstances.
* **Alleged Infringer Address**:
	+ If you have this information, enter the address of the alleged infringer.
* **Infringement Date**:
	+ Record the date on which the infringement took place.
* **Infringement Time**:
	+ Enter the time at which the infringement occurred.
* **Contact Number**:
	+ If you have a contact number for the alleged infringer, please enter it here.
* **Additional Infringements**:
	+ If there are additional instances of trademark infringement, select 'True' to indicate this. If you've selected true, please provide details in the next field.
* **Additional Infringement Details**:
	+ If you've selected "Additional Infringements" as true, provide any additional details about the infringement in this field.
