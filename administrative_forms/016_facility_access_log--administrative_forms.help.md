# Facility Access Log - Help Guide
## Purpose
The Facility Access Log form is used to record access to facilities, providing a secure and auditable record of entries and exits.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Entry Time of the individual accessing the facility. This is the time the individual first accessed the facility.
2. Enter the User Entry Time, which should be the time the user was present within the facility.
3. Enter the Exit Time, which is the time the individual left the facility.
4. Enter the Access Reason, a brief description of the reason for accessing the facility.
5. Select whether the facility was accessed 'Yes' or 'No' to indicate if the access was approved or denied.
6. Choose the Access Level: High or Low, to indicate the level of access granted or denied.
7. Select whether the User ID is 'Yes' or 'No', which should be 'Yes' if a user is authorized to access the facility.

## Field-by-Field Explanation

* **Facility Access Log**: This is the form title, not a field for input.
* **Entry Time**: Enter the exact time the individual first accessed the facility.
	+ Type: Time
	+ Required: False
* **User Entry Time**: Enter the time the user was present within the facility.
	+ Type: Time
	+ Required: False
* **Exit Time**: Enter the exact time the individual left the facility.
	+ Type: Time
	+ Required: False
* **Access Reason**: Provide a brief description of the reason for accessing the facility.
	+ Type: Text
	+ Required: False
* **Access Type**: Select 'Yes' if the access was approved, 'No' if denied.
	+ Type: Select One
	+ Required: False
* **Access Level**: Choose the level of access granted: High or Low.
	+ Type: Select Multiple
	+ Required: False
* **User ID**: Select 'Yes' if the user is authorized to access the facility, 'No' otherwise.
	+ Type: Select Multiple
	+ Required: False
