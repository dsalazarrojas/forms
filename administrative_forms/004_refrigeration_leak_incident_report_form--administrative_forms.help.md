# Refrigeration Leak Incident Report Form - Help Guide

## Purpose
This form is designed to collect information about refrigeration system leaks or malfunctions, including the incident details, location, description, and status. This information will help identify areas for improvement and ensure that the refrigeration systems are functioning properly.

## How To Complete This Form

To complete this form, follow these steps:

1. **Fill out the form completely and accurately**, as this information will be used to track and analyze the incident.
2. Make sure to include as much detail as possible about the incident.

## Field-by-Field Explanation

* **Incident Details**:
	+ This field is used to describe the incident in detail.
* **Date Reported**:
	+ Enter the date the incident was reported.
* **Location**:
	+ Enter the location of the incident.
* **Leak Description**:
	+ Provide a detailed description of the leak or malfunction.
* **Leak Type**:
	+ Choose 'Yes' if there was a leak, 'No' if there was no leak.
* **Leak Category**:
	+ Choose 'Yes' if the leak was a category (e.g., temperature, pressure), 'No' if not.
* **Leak Location**:
	+ Choose 'Yes' if the leak was located within the refrigeration system, 'No' if not.
* **Leak Status**:
	+ Choose 'Active' if the leak is still active, 'Inactive' if it is not.
* **Corrective Action**:
	+ Describe any corrective actions taken to address the leak or malfunction.
* **Notes**:
	+ Enter any additional comments or information about the incident.

## Tips

* Be as detailed as possible when describing the incident and the corrective action taken.
* If the incident is still active, make sure to update the form regularly.
* If you are unsure about any of the questions, contact the maintenance or quality control team for guidance.
