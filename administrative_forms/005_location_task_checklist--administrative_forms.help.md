# Location Task Checklist - Help Guide
## Purpose
The Location Task Checklist form is used to track and manage tasks or activities related to specific locations or regions within a company or organization.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the `location_id` field with the ID number of the location related to the task.
2. Enter the `task_id` field with the ID number of the task to be tracked.
3. Select the `task_status` field to indicate the status of the task (Active or Inactive).
4. Select the `assigned_user` field to indicate whether the task is assigned to a specific user (Yes or No).
5. Select the `completed_by` field to indicate whether the task has been completed (Yes or No).
6. Enter the `due_date` field with the date the task is due.
7. Enter the `created_at` field with the date and time the task was created.
8. Enter the `updated_at` field with the date the task was last updated.
9. Enter a description of the task in the `description` field.

## Field-by-Field Explanation
* **location_id**: A unique identifier for the location related to the task.
* **task_id**: A unique identifier for the task being tracked.
* **task_status**: The current status of the task (Active or Inactive).
* **assigned_user**: Whether the task is assigned to a specific user (Yes or No).
* **completed_by**: Whether the task has been completed (Yes or No).
* **due_date**: The date the task is due.
* **created_at**: The date and time the task was created.
* **updated_at**: The date the task was last updated.
* **description**: A brief description of the task.

## Tips
* Make sure to enter the correct location ID and task ID to ensure accurate tracking.
* Select the correct status and assigned user status to reflect the current state of the task.
* Enter the due date accurately to ensure timely completion.
* Use the description field to provide context and clarity about the task.
