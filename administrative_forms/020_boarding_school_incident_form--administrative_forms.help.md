# Boarding School Incident Form - Help Guide
## Purpose
The Boarding School Incident Form is used to document and report incidents that occur within the boarding school environment. This form helps to gather essential details about the incident, which can aid in the investigation, reporting, and follow-up procedures.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the date and time when the incident occurred in the "Incident Date" and "Incident Time" fields.
2.  Provide the location where the incident took place in the "Incident Location" field.
3.  Select the type of location where the incident happened in the "Location Type" field.
4.  Enter the name of the person reporting the incident in the "Reporter Name" field.
5.  Choose the reporter's role from the options provided in the "Reporter Role" field.
6.  Enter the name(s) of the student(s) involved in the "Student Name" field.
7.  Select the student's grade level from the options provided in the "Student Grade Level" field.
8.  Choose the type of incident from the options provided in the "Incident Type" field.
9.  Indicate the severity of the incident from the options provided in the "Incident Severity" field.
10.  Provide a detailed description of what happened in the "Incident Description" field.
11.  Indicate if there were any witnesses present in the "Witnesses Present" field.
12.  Enter the names of any witnesses in the "Witness Names" field (this field is optional).
13.  Describe any injuries sustained in the "Injuries Sustained" field (this field is optional).
14.  Select the type of medical response required from the options provided in the "Medical Response" field.
15.  Indicate if parents/guardians have been notified in the "Parents Notified" field.
16.  Select the time when parents/guardians were contacted in the "Parent Contact Time" field (this field is optional).
17.  Describe any immediate actions taken in response to the incident in the "Immediate Actions Taken" field.
18.  Select if follow-up is required for the incident from the options provided in the "Follow-Up Required" field.
19.  Describe the planned follow-up in the "Follow-Up Details" field (this field is optional).
20.  Enter the name of the administrator notified in the "Administrator Notified" field.
21.  Enter the incident report number if assigned in the "Incident Report Number" field (this field is optional).

## Field-by-Field Explanation

* **Incident Date** (`incident_date`, `date`, required): Enter the date when the incident occurred.
* **Incident Time** (`incident_time`, `time`, required): Enter the time when the incident occurred.
* **Incident Location** (`incident_location`, `text`, required): Provide the location where the incident happened.
* **Location Type** (`location_type`, `select_one`, required): Select the type of location where the incident occurred.
* **Reporter Name** (`reporter_name`, `text`, required): Enter the name of the person reporting the incident.
* **Reporter Role** (`reporter_role`, `select_one`, required): Choose the reporter's role from the provided options.
* **Student Name** (`student_name`, `text`, required): Enter the name of the student(s) involved.
* **Student Grade Level** (`student_grade`, `select_one`, required): Select the student's grade level from the provided options.
* **Incident Type** (`incident_type`, `select_one`, required): Select the type of incident from the provided options.
* **Incident Severity** (`incident_severity`, `select_one`, required): Indicate the severity of the incident from the provided options.
* **Incident Description** (`incident_description`, `text`, required): Provide a detailed description of what happened.
* **Witnesses Present** (`witnesses_present`, `select_one`, required): Indicate if there were any witnesses present.
* **Witness Names** (`witness_names`, `text`, optional): Enter the names of any witnesses (optional).
* **Injuries Sustained** (`injuries_sustained`, `text`, optional): Describe any injuries sustained (optional).
* **Medical Response** (`medical_response`, `select_one`, required): Select the type of medical response required from the provided options.
* **Parents Notified** (`parents_notified`, `select_one`, required): Indicate if parents/guardians have been notified.
* **Parent Contact Time** (`parent_contact_time`, `time`, optional): Select the time when parents/guardians were contacted (optional).
* **Immediate Actions Taken** (`immediate_actions_taken`, `text`, required): Describe any immediate actions taken in response to the incident.
* **Follow-Up Required** (`follow_up_required`, `select_one`, required): Select if follow-up is required for the incident from the provided options.
* **Follow-Up Details** (`follow_up_details`, `text`, optional): Describe the planned follow-up (optional).
* **Administrator Notified** (`administrator_notified`, `text`, required): Enter the name of the administrator notified.
* **Incident Report Number** (`incident_report_number`, `text`, optional): Enter the incident report number if assigned (optional).
