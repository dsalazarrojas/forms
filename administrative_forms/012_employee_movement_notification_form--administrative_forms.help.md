# Employee Movement Notification Form - Help Guide
## Purpose
The Employee Movement Notification Form is used to collect information for internal employee movement, such as promotions, transfers, or terminations. This form is used to notify relevant parties of an employee's status change.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in all required fields (indicated by an asterisk `*`) accurately and completely.
2. Select an employee status from the "employee_status" field, if applicable.
3. Provide a brief description of the reason for the employee's movement in the "reason_for_movement" field.
4. If applicable, select the new manager's ID from the "new_manager_id" field.
5. Enter the effective and separation dates in the "effective_date" and "separation_date" fields, if applicable.
6. Enter the reason for separation in the "reason_for_separation" field, if applicable.
7. Enter any additional details about the employee's movement in the "employee_movement_details" field.

## Field-by-Field Explanation
* **Employee Movement** (`employee_movement`, text, optional): This field is for entering a brief description of the employee's movement.
* **Employee ID** (`employee_id`, number, optional): Enter the employee ID of the person whose status is changing.
* **Manager ID** (`manager_id`, number, optional): Enter the ID of the current manager of the person whose status is changing.
* **Reason for Movement** (`reason_for_movement`, text, optional): Enter a brief description of the reason for the employee's movement.
* **New Manager ID** (`new_manager_id`, number, optional): Enter the ID of the new manager of the person whose status is changing.
* **Effective Date** (`effective_date`, date, optional): Enter the date on which the employee's status change is effective.
* **Separation Date** (`separation_date`, date, optional): Enter the date on which the employee's separation is effective.
* **Reason for Separation** (`reason_for_separation`, text, optional): Enter a brief description of the reason for the employee's separation.
* **Employee Status** (`employee_status`, select_one, optional): Select the new status of the employee from the options "Active" and "Inactive".
* **Employee Movement Details** (`employee_movement_details`, text, optional): Enter any additional details about the employee's movement.
