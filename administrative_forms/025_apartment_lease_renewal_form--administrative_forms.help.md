# Apartment Lease Renewal Form - Help Guide
## Purpose
The apartment lease renewal form is used by tenants to notify their landlords or property managers of their intention to renew their lease, and to provide necessary information for the renewal process.

## How To Complete This Form
To complete this form, the tenant will need to provide the following information:
* Date of lease renewal request
* Property address
* Unit or apartment number (if applicable)
* Landlord or property manager name
* Landlord or property manager email
* Tenant full name
* Tenant email
* Tenant phone number
* Current lease start date
* Current lease end date
* Current monthly rent
* Proposed renewal start date
* Proposed renewal end date
* Proposed length of renewal term in months
* New monthly rent amount
* Reason for any rent increase (if applicable)
* Tenant acceptance of new rental terms
* Tenant concerns or requests
* Property condition upon renewal
* Maintenance or repairs requested
* Utility terms remain unchanged
* If utility terms changed - describe changes
* Pet policy remains unchanged
* If other terms changed - describe changes
* Rent payment method
* If not renewing - move-out date
* Notice period provided
* Landlord signature date
* Tenant signature date

## Field-by-Field Explanation
* **Lease Renewal Request Date** (`renewal_date`, date, required): The date you are requesting to renew your lease.
* **Property Address** (`property_address`, text, required): The address of the property you are leasing.
* **Unit or Apartment Number** (`unit_number`, text, optional): The unit or apartment number you are leasing.
* **Landlord or Property Manager Name** (`landlord_name`, text, required): The name of the person you are leasing from.
* **Landlord or Property Manager Email** (`landlord_email`, email, optional): The email address of the person you are leasing from.
* **Tenant Full Name** (`tenant_name`, text, required): Your full name.
* **Tenant Email** (`tenant_email`, email, required): Your email address.
* **Tenant Phone Number** (`tenant_phone`, text, required): Your phone number.
* **Current Lease Start Date** (`current_lease_start`, date, required): The start date of your current lease.
* **Current Lease End Date** (`current_lease_end`, date, required): The end date of your current lease.
* **Current Monthly Rent** (`current_rent`, number, required): The current rent amount for the property.
* **Proposed Renewal Start Date** (`renewal_start_date`, date, required): The proposed start date of the renewed lease.
* **Proposed Renewal End Date** (`renewal_end_date`, date, required): The proposed end date of the renewed lease.
* **Proposed Length of Renewal Term in Months** (`renewal_term_months`, number, required): The length of time you are proposing for the renewed lease.
* **New Monthly Rent Amount** (`new_rent_amount`, number, required): The new rent amount for the renewed lease.
* **Reason for Any Rent Increase** (`rent_increase_reason`, text, optional): If there is a rent increase, please provide a reason for the increase.
* **Tenant Acceptance of New Rental Terms** (`tenant_acceptance`, select_one, required): Select "Yes, accept renewal" to indicate you agree to the new rental terms.
* **Tenant Concerns or Requests** (`tenant_concerns`, text, optional): If you have any concerns or requests, please list them here.
* **Property Condition Upon Renewal** (`property_condition`, select_one, required): Describe the condition of the property upon renewal.
* **Maintenance or Repairs Requested** (`maintenance_requested`, text, optional): If you have any maintenance or repairs requests, please list them here.
* **Utility Terms Remain Unchanged** (`utilities_terms_unchanged`, select_one, required): If the utility terms are unchanged, select "Yes, same as current".
* **If Utility Terms Changed - Describe Changes** (`utilities_changes`, text, optional): If the utility terms have changed, describe the changes here.
* **Pet Policy Remains Unchanged** (`pet_policy_unchanged`, select_one, required): If the pet policy is unchanged, select "Yes, same as current".
* **If Other Terms Changed - Describe Changes** (`other_terms_changes`, text, optional): If other terms have changed, describe the changes here.
* **Rent Payment Method** (`payment_method`, select_one, required): Select the method of rent payment you will be using.
* **If Not Renewing - Move-Out Date** (`move_out_plan`, date, optional): If you are not renewing the lease, provide the date of move-out.
* **Notice Period Provided** (`notice_period_met`, select_one, required): If you are providing notice, select "Yes, 30 days notice" or "Yes, 60 days notice".
* **Landlord Signature Date** (`landlord_signature_date`, date, required): The date the landlord signs this form.
* **Tenant Signature Date** (`tenant_signature_date`, date, required): The date you sign this form.
