# Wheel Torquing Procedure Checklist - Help Guide
## Purpose
The Wheel Torquing Procedure Checklist is used to document the completion of a specific procedure for ensuring correct wheel torquing on vehicles.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you understand the purpose and the fields required.
2. Answer all required fields.
3. Select 'Yes' or 'No' for each field where applicable, and provide any necessary comments or explanations.
4. If you are unsure about any part of the form, please consult with the relevant personnel or procedures.

## Field-by-Field Explanation

* **Wheel Torquing Procedure Checklist** (`wheel_torquing_procedure_checklist`, `text`, required: false): This field is for entering the details of the wheel torquing procedure that was performed. Please enter the procedure in the text box provided.
* **Safety Inspection** (`safety_inspection`, `select_multiple`, required: false): Please indicate if a safety inspection was performed during the procedure. If 'Yes' is selected, please explain in the comments field what was checked.
* **Proper Torque Value** (`proper_torque_value`, `number`, required: false): Enter the correct torque value specified for the wheel.
* **Verify Torque Specification** (`verify_torque_specification`, `select_one`, required: false): If 'Yes' is selected, indicate that the torque specification was verified. If 'No' is selected, please provide an explanation.
* **Safety Procedure** (`safety_procedure`, `select_multiple`, required: false): Please indicate if a safety procedure was performed during the procedure. If 'Yes' is selected, please explain in the comments field what was checked.
* **Notes** (`notes`, `note`, required: false): Any additional comments or explanations can be provided in this field.

## Tips
* Ensure all required fields are completed before submitting the form.
* If you are unsure about any part of the form, please consult with the relevant personnel or procedures.
* This form is for internal use only and should not be shared outside of the organization.
