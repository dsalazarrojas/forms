# Employee Badge Issuance Authorization Form - Help Guide
## Purpose
The Employee Badge Issuance Authorization Form is used to request the issuance of a badge for an employee. This form ensures that the employee receives the badge they need to perform their job duties.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the employee's name in the "employee-name" field.
2. Select the type of badge the employee needs in the "badge-type" field.
3. Enter the employee's ID in the "employee-id" field.
4. If applicable, select the department(s) the employee belongs to in the "department" field.
5. Choose the approval level for the badge issuance in the "approval-level" field.
6. If applicable, enter the start and end dates for the badge issuance in the "start-date" and "end-date" fields.
7. Add any additional notes about the badge issuance in the "note" field.
8. Enter the employee's email and phone number in the "email" and "phone" fields, respectively.
9. Select the tool assigned to the employee in the "assigned-tool" field.

## Field-by-Field Explanation
* **employee-name** (`employee_name`, text, required/optional: false): Enter the name of the employee for whom you are requesting a badge.
* **badge-type** (`badge_type`, select_one, required: true): Choose the type of badge the employee needs. Please select from the available options.
* **employee-id** (`employee_id`, number, required: true): Enter the employee's ID number.
* **department** (`department`, select_multiple, required: false): If applicable, select the department(s) the employee belongs to. This will help with badge access permissions.
* **approval-level** (`approval_level`, select_one, required: false): Choose the approval level for the badge issuance. This will help with badge issuance workflow.
* **start-date** (`start_date`, date, required: false): If applicable, enter the start date for the badge issuance.
* **end-date** (`end_date`, date, required: false): If applicable, enter the end date for the badge issuance.
* **note** (`note`, note, required: false): Add any additional notes about the badge issuance.
* **email** (`email`, email, required: false): Enter the employee's email address.
* **phone** (`phone`, text, required: false): Enter the employee's phone number.
* **assigned-tool** (`assigned_tool`, select_one, required: false): Select the tool assigned to the employee.

## Tips
* Please ensure that you have the necessary approvals and permissions to request a badge for the employee.
* Double-check that this form is not already filled out for the same employee and purpose.
* If you're unsure about any field or process, please contact the relevant personnel for clarification.
