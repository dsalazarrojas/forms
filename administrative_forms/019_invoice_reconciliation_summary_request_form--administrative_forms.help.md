# invoice_reconciliation_summary_request_form - Help Guide
## Purpose
This form is used for requesting administrative form reconciliations, which involve reviewing and resolving discrepancies between different systems or processes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the category of the reconciliation request (e.g., Administrative Forms).
2. Provide a detailed description of the issue or discrepancy.
3. Choose the assigned tool or system related to the request.
4. Select the IDs of the forms involved in the reconciliation.

## Field-by-Field Explanation

* **Title** (`text`, required): Enter a brief title for the reconciliation request.
* **Category** (`select_one`, required): Select the category for the reconciliation request (e.g., Administrative Forms).
* **Description** (`text`, required): Provide a detailed description of the issue or discrepancy.
* **Assigned Tool** (`select_one`, required): Choose the assigned tool or system related to the request.
* **Form IDs** (`number`, required): Select the IDs of the forms involved in the reconciliation.
* **Output File** (`text`, optional): Provide the path to the output file if applicable.
* **Created Date** (`date`, optional): Enter the date when the issue was first detected (if applicable).
* **Updated Date** (`date`, optional): Enter the date when the issue was last updated (if applicable).

## Tips

* Please ensure that you have reviewed all the fields carefully before submitting the form.
* If you are unsure about any field, you can ask for clarification or support.
* Please submit only one request per form to avoid duplication.
* You can attach additional information or context to the request using the output file field.
