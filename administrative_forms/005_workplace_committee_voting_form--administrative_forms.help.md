# Workplace Committee Voting Form - Help Guide
## Purpose
The Workplace Committee Voting Form is an internal tool used by the workplace committee to facilitate voting and decision-making processes. This form is designed to collect information on the voting process, committee name, and other relevant details.

## How To Complete This Form

To complete this form, follow the steps below:

1. Fill out all required fields, marked as `*Required`.
2. Enter the `committee_name` in the designated field.
3. Describe the `voting_process` being used.
4. Enter any additional comments in the `comments` field, if necessary.
5. Select the current `voting_status` of the form using the dropdown menu.
6. Enter any additional comments on the voting status in the `voting_comments` field, if necessary.
7. Set the `submitted_date` and `due_date` fields to the current and expected completion dates, respectively.

## Field-by-Field Explanation

* **Form Label** (`workplace_committee_voting_form`, text, *Required*): Enter a brief description of the form.
* **Committee Name** (`workplace_committee_name`, text): Enter the name of the workplace committee that is voting.
* **Voting Process** (`workplace_committee_voting_process`, text): Describe the voting process being used by the committee.
* **Comments** (`form_comments`, text): Enter any additional comments or explanations.
* **Submitted By** (`workplace_committee_form_submitted_by`, text): Enter your name as the person submitting the form.
* **Submitted Date** (`workplace_committee_form_submitted_date`, date): Enter the date you are submitting the form, in the format `YYYY-MM-DD`.
* **Due Date** (`workplace_committee_form_due_date`, date): Enter the date by which you expect the form to be completed, in the format `YYYY-MM-DD`.
* **Voting Status** (`workplace_committee_form_voting_status`, select_one): Select the current status of the form using the dropdown menu.
  * Select one of the following options:
    + Option 1
    + Option 2
    + Option 3
* **Voting Comments** (`workplace_committee_form_voting_comments`, text): Enter any comments on the voting status, if necessary.

## Tips

* Ensure that you have the necessary permissions to access and complete this form.
* Be thorough in providing details for the `voting_status` and `comments` fields to ensure that the form is completed accurately.
* If you are unsure about any field, refer to the form's instructions or contact the form administrators for guidance.
