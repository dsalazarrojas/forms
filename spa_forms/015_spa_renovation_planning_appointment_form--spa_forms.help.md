# Spa Renovation Planning Appointment Form - Help Guide
## Purpose
The Spa Renovation Planning Appointment Form is used to gather information from a spa manager to plan and manage spa renovations. It captures details about the project, the consultant, appointment requests, contact information, project budget, spa features, location, and follow-up details.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the project details such as title, and location.
2. Provide consultant information and appointment requests.
3. Fill in the contact information for the spa manager and the client.
4. Enter the project budget.
5. Select the spa features and location relevant to the project.
6. Enter follow-up date and follow-up status.

## Field-by-Field Explanation

* **Project Details** (`project_details`): Enter a brief description of the project.
* **Consultant Info** (`consultant_info`): Enter the name and contact information of the consultant involved in the project.
* **Appointment Request** (`appointment_request`): Enter any special appointment requests or requirements for the consultant.
* **Contact Info** (`contact_info`): Enter contact information for the spa manager and the client.
* **Project Budget** (`project_budget`): Enter the budget for the renovation project.
* **Spa Features** (`spa_features`): Select from the list of spa features required for the project.
* **Project Location** (`project_location`): Select the location of the spa where the project will be executed.
* **Spa Manager Name** (`spa_manager_name`): Enter the name of the spa manager.
* **Spa Manager Email** (`spa_manager_email`): Enter the email of the spa manager.
* **Spa Manager Phone** (`spa_manager_phone`): Enter the phone number of the spa manager.
* **Renovation Start Date** (`renovation_start_date`): Enter the start date of the renovation project.
* **Renovation End Date** (`renovation_end_date`): Enter the end date of the renovation project.
* **Renovation Budget** (`renovation_budget`): Enter the budget for the renovation project.
* **Payment Terms** (`payment_terms`): Select from the list of payment terms.
* **Payment Method** (`payment_method`): Select the payment method for the project.
* **Spa Manager Address** (`spa_manager_address`): Enter the address of the spa manager.
* **Spa Manager Notes** (`spa_manager_notes`): Enter any notes from the spa manager.
* **Client Info** (`client_info`): Enter any information about the client.
* **Client Name** (`client_name`): Enter the name of the client.
* **Client Email** (`client_email`): Enter the email of the client.
* **Client Phone** (`client_phone`): Enter the phone number of the client.
* **Client Notes** (`client_notes`): Enter any notes about the client.
* **Follow-up Info** (`follow_up_info`): Enter any follow-up information about the project.
* **Follow-up Date** (`follow_up_date`): Enter the follow-up date of the project.
* **Follow-up Status** (`follow_up_status`): Select the follow-up status of the project.
