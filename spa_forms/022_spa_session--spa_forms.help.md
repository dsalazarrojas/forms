# Spa Session - Help Guide
## Purpose
The Spa Session form is used to collect information about spa services provided to clients. This form helps spa therapists or administrators keep track of client bookings, service types, and payments.

## How To Complete This Form
To complete the Spa Session form, follow these steps:

1. **Spa Session Form**: Enter a brief description of the spa session (e.g., massage, facial, etc.). This field is not required, but filling it out can help with future reference.
2. **Client Name**: Enter the client's name as it appears on their records or as they have introduced themselves. This field is not required but can aid in identifying the client.
3. **Service Type**: Choose the type of service provided to the client from the options: Client, Therapist, or Spa. This field helps categorize the service for administrative purposes.
4. **Date**: Enter the date of the spa session. This field is essential for scheduling and tracking client appointments.
5. **Start Time**: Enter the start time of the spa session. This field helps determine the duration of the session.
6. **End Time**: Enter the end time of the spa session. This field calculates the duration of the session when combined with the start time.
7. **Duration**: Enter the total duration of the spa session (optional). If not provided, the system may estimate the duration based on the start and end times.
8. **Notes**: Add any additional comments or notes about the session (optional). This field can be used for reference or future communication with the client.
9. **Email**: Enter the client's email address (optional). This field can be used for communication or follow-up notifications.
10. **Phone**: Enter the client's phone number (optional). This field can be used for communication or follow-up calls.
11. **Spa Session Form Repeat**: Select the type of spa session (e.g., first, second, third session, etc.) (optional). This field helps identify the session's sequence.
12. **Session Price**: Enter the total price of the spa session (optional). This field is essential for billing and payment tracking.
13. **Payment Status**: Choose the payment status from the options: Paid, Pending, or Unpaid (optional). This field helps track payment status.
14. **Total Time**: Enter the total duration of the spa session (optional). This field is not required if the session duration can be calculated from the start and end times.
15. **Tip**: Enter any tip or gratuity given to the client (optional). This field can be used for future reference or accounting purposes.
16. **Client Status**: Choose the client status from the options: Active, Inactive, or New (optional). This field helps categorize the client's status.
17. **Payment Type**: Choose the payment type from the options: Online or Offline (optional). This field helps track payment methods.
18. **Service Notes**: Add any additional comments or notes about the service provided (optional). This field can be used for future reference or communication with the client.
19. **Therapist Notes**: Add any additional comments or notes from the therapist (optional). This field is for reference or future communication with the therapist.
20. **Cancellation Type**: Choose the cancellation type from the options: Client, Therapist, or Management (optional). This field helps identify the reason for cancellation.
21. **Cancellation Status**: Choose the cancellation status from the options: Confirmed, Pending, or Cancelled (optional). This field tracks the cancellation status.
22. **Session Status**: Choose the session status from the options: Scheduled, Active, or Done (optional). This field tracks the session's status.
23. **Session Status 2**: Another field for tracking session status, similar to Session Status (optional). 
24. **Session Status 3**: Yet another field for tracking session status (optional). 
25. **Cancellation Reason**: Add any reason for cancellation (optional). This field provides additional context for cancellations. 

**Tips**

* Be sure to fill out all required fields to ensure accurate record-keeping.
* Use the "Spa Session Form Repeat" field to track session sequence.
* For sessions with multiple clients, repeat the form for each client.
* If you're unsure about any field, contact your administrator or colleague for guidance.
