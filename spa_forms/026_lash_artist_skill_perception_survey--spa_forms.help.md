# lash_artist_skill_perception_survey - Help Guide

## Purpose
This form is designed to help evaluate the skills and qualities of lash artists.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Go to the relevant page (1-10) and complete the required fields.
2.  For each field, answer the questions as accurately and honestly as possible.
3.  Ensure that you're providing clear and concise feedback.

## Field-by-Field Explanation

*   **LashArtistSkillPerceptionSurvey** (Page 1): A short description of the survey.
    *   Label: LashArtistSkillPerceptionSurvey
    *   Type: Text
    *   Required: False
*   **LashArtistRating** (Page 2): Rate the artist's skill level on a scale.
    *   Label: LashArtistRating
    *   Type: Number
    *   Required: False
*   **LashArtistServiceQuality** (Page 3): Describe the artist's service quality.
    *   Label: LashArtistServiceQuality
    *   Type: Text
    *   Required: False
*   **LashArtistCommunication** (Page 4): Evaluate the artist's communication skills.
    *   Label: LashArtistCommunication
    *   Type: Text
    *   Required: False
*   **LashArtistPunctuality** (Page 5): Rate the artist's punctuality.
    *   Label: LashArtistPunctuality
    *   Type: Number
    *   Required: False
*   **LashArtistWillingnessToReturn** (Page 6): Rate the artist's willingness to return or follow up on work.
    *   Label: LashArtistWillingnessToReturn
    *   Type: Text
    *   Required: False
*   **LashArtistWillamsburg** (Page 7): Describe any notable incidents or experiences with the artist at Williamsburg.
    *   Label: LashArtistWillamsburg
    *   Type: Text
    *   Required: False
*   **LashArtistRecommendations** (Page 8): Suggest any skills or areas the artist should improve on.
    *   Label: LashArtistRecommendations
    *   Type: Text
    *   Required: False
*   **LashArtistSkillsToImprove** (Page 9): Rate the artist's skills that need improvement.
    *   Label: LashArtistSkillsToImprove
    *   Type: Text
    *   Required: False
*   **LashArtistAverageRate** (Page 10): Calculate the average rate of the artist's skills.
    *   Label: LashArtistAverageRate
    *   Type: Number
    *   Required: False

## Tips

*   Please answer each question accurately and honestly.
*   Avoid duplication or overlapping of feedback.
*   Provide specific examples or incidents whenever possible.
*   Be respectful and constructive in your feedback.
