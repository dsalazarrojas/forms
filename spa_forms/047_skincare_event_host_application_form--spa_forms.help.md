# Skincare Event Host Application Form - Help Guide

## Purpose
The Skincare Event Host Application Form is used for event hosts to submit their application with required information. This form is designed to collect details about the host and the event, ensuring that your event runs smoothly and efficiently.

## How To Complete This Form
To complete the form, follow the steps below:

1.  **Host Details**: Enter a brief description of the host's details.
2.  **Host Name**: Enter the host's name.
3.  **Host Email**: Enter the host's email address.
4.  **Host Phone**: Enter the host's phone number.
5.  **Event Details**: Add any additional notes about the event.
6.  **Event Date**: Select the date of the event.
7.  **Event Time**: Select the time of the event.
8.  **Venue Details**: Describe the location of the event.
9.  **Event Location**: Choose one or more of the available event locations.
10.  **Event Duration**: Enter the duration of the event.
11.  **Event Setup**: Select one of the available event setup options.
12.  **Event Setup Other**: If none of the provided event setup options apply, enter your own setup in this field.
13.  **Host Notes**: Add any additional notes about the host.
14.  **Host Requirements**: Enter any requirements the host has for the event.
15.  **Host Requirements List**: List any additional requirements for the host.
16.  **Event Agreement**: Select one of the available event agreement options.

## Field-by-Field Explanation

*   **Host Details**: A description of the host's details. 
*   **Host Name**: The name of the host.
*   **Host Email**: The email of the host.
*   **Host Phone**: The phone number of the host.
*   **Event Details**: A note field for event details.
*   **Event Date**: The date of the event.
*   **Event Time**: The time of the event.
*   **Venue Details**: A description of the event location.
*   **Event Location**: A multiple-select option for event location.
*   **Event Duration**: The duration of the event.
*   **Event Setup**: A select-one option for event setup.
*   **Event Setup Other**: A text field for specifying other event setup options.
*   **Host Notes**: A note field for event host notes.
*   **Host Requirements**: A text field for event host requirements.
*   **Host Requirements List**: A list of event host requirements.
*   **Event Agreement**: A select-one option for event agreement.
