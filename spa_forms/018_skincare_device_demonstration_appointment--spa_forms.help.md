# Skincare Device Demonstration Appointment - Help Guide
## Purpose
This form is used to schedule a demonstration of a skincare device. Please fill out the form below to provide necessary details for the demonstration.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Enter the required information for the demonstration.
3. Review the form for any errors before submitting.

## Field-by-Field Explanation

* **Demo Details** (`demo_details`, text, optional): Briefly describe the purpose and focus of the demonstration.
* **Client Info** (`client_info`, text, optional): Enter any relevant information about the client, such as contact details or preferences.
* **Contact Number** (`contact_number`, text, optional): Enter the contact number of the client.
* **Email** (`email`, email, optional): Enter the email of the client.
* **Time of Day** (`time_of_day`, select_one, optional): Select the time of day for the demonstration.
* **Date** (`date`, date, optional): Select the date for the demonstration.
* **Appointment Duration** (`appointment_duration`, select_multiple, optional): Select the duration of the appointment.
* **Notes** (`notes`, note, optional): Add any additional notes or comments for the demonstration.
* **Assigned To** (`assigned_to`, select_one, optional): Check if the demonstration is assigned to someone specific.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the name of the tool assigned for the demonstration.
* **Form ID** (`form_id`, text, optional): Enter a unique identifier for the form, if necessary.
* **Category** (`category`, text, optional): Enter the category of the demonstration.
* **Description** (`description`, text, optional): Enter a brief description of the demonstration.
* **Output File** (`output_file`, text, optional): Upload a file with any relevant information for the demonstration.
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the name of the tool assigned for the demonstration.
