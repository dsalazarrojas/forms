# Skincare Trainer Orientation Appointment - Help Guide
## Purpose
This form is for scheduling a skincare trainer orientation appointment.

## How To Complete This Form
To complete this form, you need to provide the following information:

1. Fill in the Session Date field with the desired date of the orientation session.
2. Enter the Session Time field with the specific time of the session.
3. Enter the Trainer Name field with the name of the trainer who will be conducting the session.
4. Select the Topics Preference field with the topics you would like to cover during the session.
5. In the Background field, enter any relevant background information about yourself or the client.
6. In the Topics Preferred field, select the topics you prefer.
7. In the Session Details field, add any additional session details.
8. In the Trainer Notes field, write any notes about the trainer.
9. In the Client Notes field, write any notes about the client.

## Field-by-Field Explanation

* **Session Date** (`spa_form_session_date`, date, required: false): Enter the date of the orientation session.
* **Session Time** (`spa_form_session_time`, time, required: false): Enter the time of the orientation session.
* **Trainer Name** (`trainer_name`, text, required: false): Enter the name of the trainer who will be conducting the session.
* **Background** (`background`, note, required: false): Enter any background information about yourself or the client.
* **Topics Preference** (`topics_preference`, select_one, required: false): Select the topics you would like to cover during the session. Options: Aromatherapy, Chemical Peel, Facial, Skincare, Massage, Micro-needling, Microneedling, Skin Analysis, Skincare Training.
* **Topics Preferred** (`spa_form_topics_preferred`, select_multiple, required: false): Select the topics you prefer.
* **Session Details** (`spa_form_session_details`, note, required: false): Add any additional session details.
* **Trainer Notes** (`spa_form_trainer_notes`, note, required: false): Write any notes about the trainer.
* **Client Notes** (`spa_form_client_notes`, note, required: false): Write any notes about the client.

# Tips
* Make sure to fill out this form accurately and clearly.
* Ensure that the trainer and client are on the same page about the session details.
* Review the form carefully before submitting to prevent errors.
