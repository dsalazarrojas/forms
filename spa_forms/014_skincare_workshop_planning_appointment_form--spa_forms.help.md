# Skincare Workshop Planning Appointment Form - Help Guide
## Purpose
This form is designed to collect information for planning skincare workshops. It's used to gather details about the session and participant information to ensure that the planning process runs smoothly.

## How To Complete This Form
To complete this form, follow the instructions below:
1. Fill out the Session Details page with the necessary information about the workshop.
2. Move on to the Participant Details page and enter the required participant details.
3. On the Appointment Time and Date pages, select the desired appointment time and date for the workshop.
4. Enter the session duration and participant information as required.

## Field-by-Field Explanation
* **Session Details**: This page is used to fill out the workshop's details. Enter the relevant information such as workshop name or topic.
* **Participant Details**: This page is used to fill out the participant's details such as their name, age and contact number.
* **Appointment Time**: This page allows you to select a suitable time for the workshop. Make sure to select a time that works for both the participant and the workshop organizer.
* **Appointment Date**: This page allows you to select a suitable date for the workshop. Make sure to select a date that works for both the participant and the workshop organizer.
* **Session Duration**: This field allows you to select the duration of the workshop session.
* **Participant Name**: This field is used to enter the participant's name. This is an essential piece of information for the workshop.
* **Participant Age**: This field is used to enter the participant's age. This information is necessary for the workshop planning process.
* **Participant Gender**: This field allows you to select the participant's gender. Please choose from the available options.
* **Participant Contact Number**: This field is used to enter the participant's contact number. This information is necessary for future reference.
* **Participant Email**: This field is used to enter the participant's email. This information is necessary for future reference.

## Tips
* Make sure to double-check all the entered information before submitting the form.
* If you are unsure about any of the field's requirements, please contact the workshop organizer.
* If you have any other questions or concerns, please don't hesitate to reach out.
