# Aircraft Line Maintenance Tool Inventory Form - Help Guide
## Purpose
This form is designed to track and inventory tools and equipment within the aircraft line maintenance environment. It captures essential details about each tool, including the tool's condition, calibration status, and location within the facility. The form helps to ensure that tools are properly accounted for, and their maintenance and replacement needs are accurately documented.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant date of the inventory from the "Inventory Date" field.
2. Enter the location where the inventory was conducted in the "Location" field.
3. Enter the name of the technician who conducted the inventory in the "Technician Name" field.
4. Enter the technician's employee ID number in the "Technician ID" field.
5. Select the type of tool from the "Tool Category" field.
6. Enter a unique identifier for the tool in the "Tool ID Number" field.
7. Provide a detailed description of the tool in the "Tool Name" field.
8. Enter the tool's specific type (e.g., wrench, hammer, etc.) in the "Tool Type" field.
9. If applicable, enter the tool's manufacturer and model number in the "Manufacturer" and "Model Number" fields.
10. Enter the tool's serial number in the "Serial Number" field.
11. Enter the number of tools accounted for in the "Quantity" field.
12. Select the current condition of the tool from the "Condition" field.
13. Select the current calibration status of the tool from the "Calibration Status" field.
14. If applicable, enter the date the tool was last calibrated in the "Last Calibration Date" field.
15. Enter the date the tool is due for next calibration in the "Next Calibration Due" field.
16. Enter the location where the tool is stored in the "Storage Location" field.
17. Select the tool's checkout status from the "Checkout Status" field.
18. If the tool is checked out, enter the name of the technician who checked it out in the "Checked Out To" field.
19. Enter the date the tool was checked out in the "Checkout Date" field.
20. Enter the expected return date of the tool in the "Expected Return Date" field.
21. If applicable, enter the specific aircraft the tool is assigned to in the "Assigned Aircraft" field.
22. Enter the date the tool was purchased or acquired in the "Purchase Date" field.
23. Enter the original purchase cost of the tool in the "Purchase Cost (USD)" field.
24. Enter the current replacement value of the tool in the "Replacement Value (USD)" field.
25. If applicable, enter the date the tool underwent its last maintenance in the "Last Maintenance Date" field.
26. Enter any maintenance notes in the "Maintenance Notes" field.
27. Select whether the tool needs replacement from the "Replacement Needed" field.
28. If applicable, enter the location of the tool's shadow board in the "Shadow Board Location" field.
29. Select whether the tool is FOD controlled from the "FOD Control Status" field.
30. Enter the number of tools not accounted for in the "Missing Tools Count" field.
31. Enter any discrepancy notes in the "Discrepancy Notes" field.
32. Select the overall inventory status from the "Inventory Status" field.
33. Enter the name of the supervisor who reviewed the form in the "Supervisor Review" field.
34. Provide a digital signature of the technician who completed the form in the "Technician Signature" field.

## Field-by-Field Explanation
- **Inventory Date** (1, date, required): Date of the inventory.
- **Location** (2, text, required): Location where the inventory was conducted.
- **Technician Name** (3, text, required): Name of the technician who conducted the inventory.
- **Technician ID** (4, text, required): Employee ID number of the technician.
- **Tool Category** (5, select_one, required): Type of tool (e.g., hand tools, power tools, etc.).
- **Tool ID Number** (6, text, required): Unique identifier for the tool.
- **Tool Name** (7, text, required): Description of the tool.
- **Tool Type** (8, text, required): Specific type of tool (e.g., wrench, hammer, etc.).
- **Manufacturer** (9, text, optional): Brand of the tool.
- **Model Number** (10, text, optional): Model designation of the tool.
- **Serial Number** (11, text, optional): Tool serial number.
- **Quantity** (12, number, required): Number of tools accounted for.
- **Condition** (13, select_one, required): Current state of the tool (e.g., excellent, good, etc.).
- **Calibration Status** (14, select_one, required): Is the tool calibrated (e.g., current, due soon, etc.).
- **Last Calibration Date** (15, date, optional): Date the tool was last calibrated.
- **Next Calibration Due** (16, date, optional): Date the tool is due for next calibration.
- **Storage Location** (17, text, required): Location where the tool is stored.
- **Checkout Status** (18, select_one, required): Is the tool checked out (e.g., in stock, checked out, etc.).
- **Checked Out To** (19, text, optional): Technician who checked out the tool.
- **Checkout Date** (20, date, optional): Date the tool was checked out.
- **Expected Return Date** (21, date, optional): Date the tool is due to be returned.
- **Assigned Aircraft** (22, text, optional): Specific aircraft the tool is assigned to.
- **Purchase Date** (23, date, optional): Date the tool was purchased or acquired.
- **Purchase Cost (USD)** (24, number, optional): Original purchase cost of the tool.
- **Replacement Value (USD)** (25, number, optional): Current replacement value of the tool.
- **Last Maintenance Date** (26, date, optional): Date the tool underwent its last maintenance.
- **Maintenance Notes** (27, text, optional): Notes about maintenance performed on the tool.
- **Replacement Needed** (28, select_one, required): Does the tool need replacement (e.g., false, yes, etc.).
- **Shadow Board Location** (29, text, optional): Location of the tool's shadow board.
- **FOD Control Status** (30, select_one, required): Is the tool FOD controlled (e.g., true, false, etc.).
- **Missing Tools Count** (31, number, required): Number of tools not accounted for.
- **Discrepancy Notes** (32, text, optional): Any discrepancy or issue found with the tool.
- **Inventory Status** (33, select_one, required): Overall status of the tool (e.g., complete, incomplete, etc.).
- **Supervisor Review** (34, text, optional): Name of the supervisor who reviewed the form.
- **Technician Signature** (35, text, required): Digital signature of the technician who completed the form.

## Tips
- Double-check the inventory date and location to ensure accuracy.
- Be precise when describing the tool's condition, calibration status, and other relevant details.
- Verify the tool's calibration status with the manufacturer's requirements.
- Update the tool's status regularly to maintain an up-to-date inventory.
- Sign the form digitally to confirm completion.
- Review the form with a supervisor before closing it.
- Store the completed form in a secure location for reference and recordkeeping.
