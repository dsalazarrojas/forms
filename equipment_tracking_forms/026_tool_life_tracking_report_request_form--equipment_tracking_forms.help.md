# Tool Life Tracking Report Request Form - Help Guide
## Purpose
The Tool Life Tracking Report Request Form is designed to provide staff and department members with information about equipment usage and status.

## How To Complete This Form

1. To fill out this form, please go to the relevant page and enter your information into the provided text boxes.
2. Fill in the required fields: requestor name, request date, assigned to, due date, and tool status.
3. The tool status field allows you to select the current status of the tool using the dropdown menu provided. You can select from the following options:
	* Tool Not Available
	* Tool Not Available (Awaiting Repair)
	* Tool Available
	* Available (Scheduled For Use)
	* Available (Not Scheduled)
	* Available (Awaiting Repair)
	* Available (Available and Scheduled)
4. You can add any comments or additional information about the tool usage in the usage comments field.
5. If you have any attachments or additional information to support your request, you can upload them in the attachment field.
6. Fill in the tool ID and equipment ID fields with the corresponding information.
7. Finally, click on the submit button to send the request.

## Field-by-Field Explanation

* **Form Title**: This is the title of the form, and it is used to identify the purpose of the form.
* **Category**: This field is used to select whether the tool is available or not. Please choose 'Yes' if the tool is available, or 'No' if it is not.
* **Equipment ID**: This field is used to enter the unique identifier of the equipment being requested. Please enter the correct equipment ID.
* **Tool ID**: This field is used to enter the unique identifier of the tool being requested. Please enter the correct tool ID.
* **Requestor Name**: This field is used to enter the name of the person requesting the report.
* **Requestor Email**: This field is used to enter the email address of the person requesting the report.
* **Request Date**: This field is used to enter the date when the report was requested.
* **Usage Comments**: This field is used to add any comments or additional information about the tool usage.
* **Tool Status**: This field is used to select the current status of the tool using the dropdown menu provided. Please select from the available options.
* **Attachment**: This field is used to upload any attachments or additional information to support the request.
* **Assigned To**: This field is used to enter the person or department assigned to use the tool.
* **Due Date**: This field is used to enter the date when the tool is due to be returned or used.
* **Completed Date**: This field is used to enter the date when the report was completed.
