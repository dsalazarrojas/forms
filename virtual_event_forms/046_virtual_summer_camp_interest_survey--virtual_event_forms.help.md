# virtual_summer_camp_interest_survey - Help Guide
## Purpose
The virtual summer camp interest survey is designed to gather information from individuals interested in participating in a virtual summer camp. This form will help us understand your interests and preferences for the camp.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Review each field and provide the necessary information for each.
2. Answer all required fields (those marked as "required" in the form).
3. If you need help with a particular field, refer to the Field-by-Field Explanation section for clarification.

## Field-by-Field Explanation
Below are explanations for each field in the form:

* **Virtual Summer Camp Interest** (`summer_camp_interest`, number, required/optional): This field is not applicable as it is not present in the actual YAML. However, we can infer that it should be a field to capture the individual's interest in the virtual summer camp. Please select the number that best represents your level of interest.
* **Number of Campers** (`number_of_campers`, select multiple, required/optional): Please select the number of campers you are interested in attending. This includes yourself and any other family members who may be joining.
* **Preferred Date** (`preferred_date`, date, required/optional): Enter the date on which you would prefer to attend the virtual summer camp. Please note that dates may be subject to change.
* **Preferred Time** (`preferred_time`, time, required/optional): Choose a time slot that suits you best to attend the virtual summer camp.
* **Email** (`email`, email, required/optional): Please enter your email address where you can be contacted by us.
* **Phone** (`phone`, text, required/optional): Enter your phone number to be contacted in case we need to communicate with you.
* **Comments** (`comment`, note, required/optional): If you have any additional comments or feedback, please enter them here.
* **Assigned Tool** (`assigned_tool`, text, required/optional): Please enter any specific tools or equipment you need to be assigned for the virtual summer camp.
