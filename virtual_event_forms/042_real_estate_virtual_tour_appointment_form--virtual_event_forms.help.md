# Real Estate Virtual Tour Appointment Form - Help Guide
## Purpose

This form is used to schedule and organize virtual real estate tours. It gathers essential information from clients, including their contact details and preferences, to ensure smooth and efficient virtual tour experiences.

## How To Complete This Form

1. **Review the form carefully**: Make sure you have all necessary information before submitting the form.
2. **Provide accurate details**: Double-check your contact and address information to avoid mistakes.
3. **Select a virtual event name**: Choose a name that best describes the virtual event you're interested in.
4. **Choose an assigned user**: Select the person responsible for handling your virtual event.
5. **Submit the form**: Click the "Submit" button to send your request.

## Field-by-Field Explanation

* **Virtual Event Name** (`virtual_event_name`, text, optional): Enter a name that describes the virtual event you're interested in.
* **Client Name** (`client_name`, text, optional): Enter your name, so we know who you are.
* **Client Email** (`client_email`, email, optional): Enter your email address, so we can get in touch with you.
* **Client Phone** (`client_phone`, text, optional): Enter your phone number, in case we need to contact you.
* **Appointment Date** (`appointment_date`, date, optional): Choose a date for the virtual tour.
* **Appointment Time** (`appointment_time`, time, optional): Select the time for the virtual tour.
* **Tour Address** (`tour_address`, text, optional): Enter the address of the property you'd like to tour.
* **Virtual Event Details** (`virtual_event_details`, note, optional): Add any additional information or notes about the virtual event.
* **Assigned User** (`assigned_user`, select_one, optional, select from: Jimmy, John, Jane): Select the person responsible for handling your virtual event.
* **Submit** (`submit`, text, optional, not a field to fill, just a button to press): Click this button to send your request.

## Tips

* Please fill out as much information as possible to ensure we have all necessary details.
* If you have any questions or concerns, reach out to us directly.
* We will get in touch with you once we receive your form submission.
