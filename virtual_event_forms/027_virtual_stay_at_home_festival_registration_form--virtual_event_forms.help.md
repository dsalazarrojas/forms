# Virtual Stay At Home Festival Registration Form - Help Guide
## Purpose
This form is meant to gather attendee details for virtual events. Please complete it to let us know about your festival preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Festival Details page with information about the festival you are interested in.
2. On the Attendee Info page, provide your name and any additional details about yourself.
3. On the Contact Preferences page, let us know how you would like to be contacted about future events.
4. If you have purchased tickets for the festival, please enter the number of tickets on the Festival Tickets page.

## Field-by-Field Explanation
* **Festival Details (<id: 1>, label: Festival Details):**
	+ Enter a brief description about the virtual festival you are registering for (e.g., name, date, or type of event).
* **Attendee Info (<id: 2>, label: Attendee Info):**
	+ Provide your name as you want it to be displayed on the festival list.
* **Contact Preferences (<id: 3>, label: Contact Preferences):**
	+ Choose how you want to be contacted about future events (e.g., email, phone, or mail).
* **Festival Tickets (<id: 4>, label: Festival Tickets):**
	+ Enter the number of festival tickets you have purchased.

## Tips
* Please make sure to fill out the form carefully, as incorrect information may cause issues with event management.
* If you are unsure about any of the fields, feel free to contact us for assistance.
