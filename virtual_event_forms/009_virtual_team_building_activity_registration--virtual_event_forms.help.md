# Virtual Team Building Activity Registration - Help Guide
## Purpose
This form is designed to register participants for virtual team building activities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your participant name in the "Participant Name" field.
2. Select the date of the virtual activity in the "Date" field.
3. Choose the start time of the virtual activity in the "Start Time" field.
4. Select the end time of the virtual activity in the "End Time" field.
5. Enter any additional details about the virtual activity in the "Event Details" field.

## Field-by-Field Explanation

* **Participant Name** (participant_name, text, required: false): Enter your name as it appears on your official documents or ID.
* **Date** (date, date, required: false): Select the date of the virtual activity. Please format the date in the YYYY-MM-DD format (e.g., 2024-03-15).
* **Start Time** (start_time, time, required: false): Choose the start time of the virtual activity. Format the time in 24-hour format (e.g., 14:00).
* **End Time** (end_time, time, required: false): Select the end time of the virtual activity. Format the time in 24-hour format (e.g., 15:00).
* **Event Details** (event_details, text, required: false): Enter any additional details about the virtual activity, such as the agenda, objectives, or any other relevant information.

## Tips
* Ensure that the date and time fields are filled in correctly to avoid any scheduling conflicts.
* Enter your name and event details accurately to ensure that your participation is recorded correctly.
