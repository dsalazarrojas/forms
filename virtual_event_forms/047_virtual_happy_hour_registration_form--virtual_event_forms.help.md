# Virtual Happy Hour Registration Form - Help Guide
## Purpose
The Virtual Happy Hour Registration Form is designed to gather essential details about virtual events or happy hours. This form helps event planners and hosts to provide accurate and comprehensive information for attendees, ensuring a smooth experience for all parties involved.

## How To Complete This Form
1. Fill in your name, email, and phone number to help us contact you regarding your event.
2. Enter the number of guests attending the virtual happy hour.
3. Choose the event date, time, and recurrence details (e.g., whether it's a one-time event or if it repeats).
4. Select the type of event (e.g., virtual, in-person, hybrid, or other).
5. If the event type is other, please specify in the 'Other Event Type' field.
6. Provide the Happy Hour's name, description, and URL.
7. Enter the Happy Hour's password for security reasons.
8. Choose the event's recurrence (how often it will happen: daily, weekly, monthly, or quarterly).
9. Set both the start and end dates for the Happy Hour.
10. Determine how long the event will repeat (in number of days).
11. Specify the frequency of repeats (daily, weekly, or monthly).
12. Optionally, select a timezone for your event, but note that this is not mandatory.
