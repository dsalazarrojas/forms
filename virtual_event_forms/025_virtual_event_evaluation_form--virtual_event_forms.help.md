# Virtual Event Evaluation Form - Help Guide
## Purpose
The Virtual Event Evaluation Form is designed to gather feedback and suggestions from attendees of virtual events. It is used to collect information on event title, speaker name, event description, and other relevant details. This form also allows users to rate and provide suggestions for improvement.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the **Event Title** field with the title of the event you attended.
2. Enter the **Speaker Name** field with the name of the speaker(s) who spoke at the event.
3. Provide a brief description of the **Event Description** in the field below.
4. If applicable, enter your **Rating** of the event. You can choose from "Good" or "Fair".
5. If you have any comments or suggestions, use the **Virtual Event Feedback** field.
6. If you would like to provide additional feedback, you can use the **In-Person Feedback** field.
7. Enter your **Email** and **Phone** fields if you would like to be contacted for follow-up.
8. If you have any additional suggestions, you can use the **Virtual Event Suggestion** field.
9. If you attended an in-person event, provide the **In-Person Event Location** field with the location of the event.
10. Finally, you can provide any additional comments or suggestions in the **Virtual Event Evaluation** field.

## Field-by-Field Explanation

* **Event Title** (required): Enter the title of the event you attended.
* **Speaker Name** (required): Enter the name of the speaker(s) who spoke at the event.
* **Event Description** (required): Provide a brief description of the event.
* **Speaker Description** (optional): Provide a brief description of the speaker.
* **Rating** (optional): Rate the event as "Good" or "Fair".
* **Virtual Event Feedback** (optional): Provide any comments or suggestions for the virtual event.
* **In-Person Feedback** (optional): Provide any comments or suggestions for in-person events.
* **Virtual Event Suggestion** (optional): Provide any suggestions for the virtual event.
* **Email** (required): Enter your email address if you would like to be contacted for follow-up.
* **Phone** (optional): Enter your phone number if you would like to be contacted for follow-up.
* **Virtual Event Feedback** (optional): Provide any additional comments or feedback.
* **In-Person Feedback** (optional): Provide any additional comments or feedback.
* **Virtual Event Suggestion** (optional): Provide any additional suggestions.
* **Follow-up** (optional): Select a date and time for follow-up.
* **Follow-up Time** (optional): Select a time for follow-up.
* **Follow-up Date** (optional): Select a date for follow-up.
* **Email Follow-up** (optional): Enter your email address if you would like to be contacted for follow-up.
* **Phone Follow-up** (optional): Enter your phone number if you would like to be contacted for follow-up.
* **Virtual Event Evaluation** (optional): Provide any final comments or evaluation.
* **Event Date** (optional): Select the date of the event.
* **Event Time** (optional): Select the time of the event.
* **Event Location** (optional): Enter the location of the event.
* **In-Person Event Location** (optional): Enter the location of the in-person event.
* **Assigned Tool** (optional): Enter the tool used for the event.
