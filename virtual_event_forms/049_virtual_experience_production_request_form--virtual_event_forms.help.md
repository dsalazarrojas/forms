# Virtual Experience Production Request Form - Help Guide
## Purpose
The Virtual Experience Production Request Form is a tool used to gather information about a virtual event for production purposes. This form helps us understand the event details, such as date, time, and type, and ensures that the production team has all necessary information to deliver a high-quality virtual event.

## How To Complete This Form
1. Select the event type from the options provided in the "Event Type" field. This will help us understand the scope and format of the event.
2. Enter the event date in the "Event Date" field in the correct format (YYYY-MM-DD).
3. Enter the event duration in the "Event Duration" field. Please note that this field is for the total duration of the event, not the individual session duration.
4. Enter the event name in the "Event Name" field. This is the title of the event that will be used for production and promotion.
5. Enter a brief description of the event in the "Event Description" field. This will help us understand the purpose and objectives of the event.
6. Click on the "Submit" button to submit the form and the information will be reviewed by the production team.

## Field-by-Field Explanation
### **Production Request** (`production_request`, text, optional)
* This field is a placeholder for any additional comments or requests you have for the production of the event. Please use it to provide any extra information you feel is necessary to ensure the success of the event.

### **Event Date** (`event_date`, date, optional)
* Enter the date on which the event will take place.

### **Event Time** (`event_time`, time, optional)
* Enter the time at which the event will take place. If the event spans multiple time zones, please enter the start time in UTC.

### **Event Duration** (`event_duration`, number, optional)
* Enter the total duration of the event in minutes. For example, if the event will last 8:00 am - 12:00 pm (4 hours), enter 480.

### **Event Type** (`event_type`, select_one, required)
* Select the type of event from the dropdown menu. Please note that not all event types may be supported by the production team.

### **Event Name** (`event_name`, text, optional)
* Enter a brief title for the event that will be used for production and promotion.

### **Event Description** (`event_description`, text, optional)
* Enter a brief description of the event, including its purpose and objectives. This will help the production team understand the event and deliver a high-quality experience.

### **Tips**
* Please ensure that you have checked with the event production team before submitting a request for the same event or event type.
* If you are unsure about any aspect of the form, please contact the event production team for guidance.
