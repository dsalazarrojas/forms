# Virtual Event Access Renewal Form - Help Guide
## Purpose
The Virtual Event Access Renewal Form is used to update and renew access to a virtual event. This form is designed to collect necessary information from attendees to ensure they can access the event.

## How To Complete This Form
- To complete this form, navigate through each page of the form.
- Review the questions and provide the requested information for each field.

## Field-by-Field Explanation
### Page 1: Attendee Information
* **Attendee Information**: Enter your name, email address, or phone number to identify yourself as the event attendee.
  (Required)

* **Email** (Page 1): Enter your email address for event updates and access.
  (Required)

* **Phone** (Page 1): Enter your phone number for event updates and access.
  (Required)

### Page 2: Payment Information
* **Payment Method**: Choose how you would like to make the payment:
  + Bank Transfer
  + Online Payment Gateway
  + Offline Payment
  (Optional)

* **Payment Amount**: Enter the amount you wish to pay for the event.
  (Optional)

* **Payment Frequency**: Choose how many times you want to make the payment:
  + One Time
  + Multiple Times
  (Optional)

* **Payment Status**: Choose the status of your payment:
  + Paid
  + Unpaid
  (Optional)

* **Payment Terms**: This field serves as a note for any special payment terms or notes.
  (Optional)

### Page 3: Event Information
* **Event Info**: Enter any relevant event information.
  (Optional)

* **Event Status**: Choose the status of the event:
  + Active
  + Inactive
  (Optional)

* **Event Type**: Choose the type of the event:
  + Virtual
  + In-Person
  (Optional)

* **Event Date**: Enter the date of the event.
  (Optional)

* **Start Time**: Enter the start time of the event.
  (Optional)

* **End Time**: Enter the end time of the event.
  (Optional)

* **Event Time Zone**: Choose the time zone of the event:
  + UTC
  + EST
  (Optional)

* **Event Organizer**: Enter the name of the event organizer.
  (Optional)

* **Event Location**: Enter the address of the event location.
  (Optional)

### Page 4: Payment Details
* **Payment Details**: Enter any additional payment information.
  (Optional)

* **Payment Method Choice**: Choose the payment method for this specific payment:
  + Bank Transfer
  + Online Payment Gateway
  + Offline Payment
  (Optional)

### Tips
- Ensure that all required fields are completed to avoid any access issues.
- Review each page to ensure you're providing the correct information.
- If you have any issues or questions, contact the event organizer or support.
