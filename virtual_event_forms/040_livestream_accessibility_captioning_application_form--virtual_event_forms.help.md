# Livestream Accessibility Captioning Application Form - Help Guide
## Purpose
This form is designed to collect information from event organizers or administrators to request accessibility captioning services for their live streams or events.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the `Event Details` section with the following information:
	* `Event Title`: A short description of the event.
	* `Event Date`: The date of the event.
	* `Event Description`: A brief description of the event.
2. In the `Platform` section, select the platform on which the live stream will take place (e.g. AWS WebCastr, Zoom, Kaltura, etc.).
3. Fill in the `Start Time` and `End Time` fields with the scheduled start and end times of the event.
4. In the `Accessibility Needs` section, specify the language in which the captioning is required (e.g. English, Spanish, Mandarin Chinese, etc.).
5. In the `Platform Accessibility Features` section, describe the accessibility features of the platform being used (e.g. auto-play, subtitles, etc.).
6. Fill in the `Live Streaming URL` field with the URL of the live stream.
7. In the `Accessibility Technology` section, specify the accessibility technologies required (e.g. captioning, subtitling, etc.).
8. Add any additional notes or information in the `Additional Notes` field.

## Field-by-Field Explanation
* **Event Details** (`event_details`): A short description of the event.
* **Platform** (`platform`): The platform on which the live stream will take place (e.g. AWS WebCastr, Zoom, Kaltura, etc.).
* **Start Time** (`start_time`): The scheduled start time of the event.
* **End Time** (`end_time`): The scheduled end time of the event.
* **Accessibility Needs** (`accessibility_needs`): Specify the language in which the captioning is required (e.g. English, Spanish, Mandarin Chinese, etc.).
* **Platform Accessibility Features** (`platform_accessibility_features`): Describe the accessibility features of the platform being used (e.g. auto-play, subtitles, etc.).
* **Live Streaming URL** (`live_streaming_url`): The URL of the live stream.
* **Accessibility Technology** (`accessibility_technology`): Specify the accessibility technologies required (e.g. captioning, subtitling, etc.).

## Tips
* Make sure to provide accurate information to ensure that the captioning services are provided efficiently and effectively.
* If you have any additional notes or information, use the `Additional Notes` field to provide more details.
* If you have any questions or concerns, please contact the event administrators.
* The form will be reviewed and processed in a timely manner.
* You will receive a confirmation email once your request is processed.
