# Online Art Class Registration Form - Help Guide
## Purpose
The Online Art Class Registration Form is designed to collect essential information from users who are registering for an online art class. This form will help instructors or administrators to manage registrations and track class details.

## How To Complete This Form

To complete this form, simply follow the steps:

1.  Fill in your registration name, email address, and phone number on pages 1-3.
2.  For page 4, please enter the name of the course you are registering for.
3.  If you have a preferred start and end date for the class, enter those dates on page 5 and 6 respectively.
4.  On page 7, select the time slot for the class that suits you best.
5.  On page 8, select your preferred payment method (Cash, Bank, Transfer, or Card).
6.  If you have any additional notes about your registration, enter them on page 10.
7.  On page 11, select the number of students you will be bringing with you to the class.
8.  On page 12, select the assigned tool for the class (you will have to choose between Chatjimmy, Jenniffer, or Bob).

## Field-by-Field Explanation

* **Registration Name** (page 1, text, required): Enter your name to register for the art class.
* **Email** (page 2, text, required): Enter your email address to be contacted about the class.
* **Phone** (page 3, text, required): Enter your phone number to be contacted in case of emergencies.
* **Course Name** (page 4, text, required): Enter the name of the course you are registering for.
* **Start Date** (page 5, date, required): Select the start date for the art class.
* **End Date** (page 6, date, required): Select the end date for the art class.
* **Time** (page 7, time, required): Select the time slot for the class that suits you best.
* **Registration Fee** (page 8, number, required): Enter your preferred registration fee.
* **Payment Method** (page 9, select one, required): Select your preferred payment method (Cash, Bank, Transfer, or Card).
* **Note** (page 10, note, required): Enter any additional notes about your registration.
* **Student Count** (page 11, select multiple, required): Select the number of students you will be bringing with you to the class.
* **Assigned Tool** (page 12, select one, required): Select the assigned tool for the class (Chatjimmy, Jenniffer, or Bob).
