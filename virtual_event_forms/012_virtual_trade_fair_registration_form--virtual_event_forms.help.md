# Virtual Trade Fair Registration Form - Help Guide
## Purpose
This form is designed to collect information from attendees for the virtual trade fair. Please fill it out to confirm your attendance and create an instant certificate, if desired.

## How To Complete This Form
To complete this form, simply fill out the required fields, and select your responses where indicated. Each field is explained in more detail in the "Field-by-Field Explanation" section.

## Field-by-Field Explanation
* **Trade Fair Details (<type: text>):** This field is for the title of the trade fair you wish to attend.
* **Attendees (<type: text>):** This field is for any additional attendees you're registering, if applicable.
* **Confirm Attendance (<type: select_one>):** Please select "Yes" to confirm your attendance at the virtual trade fair.
* **Create Instant Certificate (<type: select_one>):** If you'd like to receive an instant certificate, select "Yes". If not, select "No".

## Tips
* Please make sure to fill out all fields accurately to ensure smooth processing.
* If you're unsure about any field, refer to the "Field-by-Field Explanation" section for clarification.
* If you need help, contact [form@gic.mx](mailto:form@gic.mx)
