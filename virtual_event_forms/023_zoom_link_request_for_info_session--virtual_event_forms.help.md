# Zoom Link Request For Info Session - Help Guide
## Purpose
This form is used to request a Zoom link for an info session. Please fill out the form with your school's name, the date and time of the session, your name, email, and phone number, as well as a brief description of the event and whether or not you want to send the meeting link.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Make sure to provide your school's name, date, time, and your personal contact information.
3. If you have any additional information about the event, you can include it in the Event Description field.

## Field-by-Field Explanation
* **School Name** (school_name, text, required): Enter the name of the school hosting the info session.
* **Info Session Date** (info_session_date, date, required): Choose the date of the info session.
* **Session Time** (info_session_time, time, required): Choose the time of the info session.
* **Attendee Name** (attendee_name, text, required): Enter your name as the attendee.
* **Attendee Email** (attendee_email, email, required): Enter your email address.
* **Attendee Phone** (attendee_phone, text, required): Enter your phone number.
* **Zoom Meeting URL** (zoom_meeting_url, text, required): The Zoom meeting link will be generated based on the information you provide.
* **Event Description** (event_description, text, optional): Provide a brief description of the event.
* **Event Type** (event_type, select_multiple, required): Indicate if this is an in-person or virtual info session. You can choose one or multiple options.
* **Send Meeting URL** (send_meeting_url, select_one, required): Decide if you want to receive the meeting URL via email.

Note that fields marked as required must be filled out, or you will not be able to submit the form. Fields marked as optional can be left blank, but keep in mind that providing additional information can make the request more complete and easier to process internally.
