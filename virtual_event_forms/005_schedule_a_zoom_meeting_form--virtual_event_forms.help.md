# schedule_a_zoom_meeting_form - Help Guide
## Purpose
This form is used to schedule a Zoom meeting.

## How To Complete This Form

### Meeting Details
To schedule a new meeting, start by selecting the `Meeting Details` page.

- **Meeting Details** (`meeting_details`, text, not required): Enter a brief description of the meeting. This field is optional.

### Meeting Time
To set the meeting time, select the `Start Time` and `End Time` fields.

- **Start Time** (`start_time`, time, not required): Enter the start time of the meeting.
- **End Time** (`end_time`, time, not required): Enter the end time of the meeting.

### Meeting Date
- **Date** (`date`, date, not required): Select the date of the meeting.

### Meeting Type
- **Meeting Type** (`meeting_type`, select_one, not required): Choose the type of meeting. Options: Meeting, Event, Webinar.

### Attendees
- **Attendees** (`attendees`, select_multiple, not required): Select who will be attending the meeting. Options: Coworker, Client, Both.

### Registrant Information
To add registrants, select the `Registrants` page.

- **Registrants** (`registrants`, select_multiple, not required): Choose what action to take on registrants. Options: Add, Remove, Update.
- **Registrant Email** (`registrant_email`, email, not required): Enter the email of the registrant.
- **Registrant Phone** (`registrant_phone`, text, not required): Enter the phone number of the registrant.
- **Registrant Notes** (`registrant_notes`, note, not required): Enter notes about the registrant.
- **Registrant Attendance** (`registrant_attendance`, select_multiple, not required): Choose the registrant's attendance. Options: Present, Absent, Maybe.
- **Registrant Notes 2** (`registrant_notes2`, note, not required): Enter additional notes about the registrant.

### Tips
- Make sure to enter the correct meeting details to ensure it appears correctly in the meeting schedule.
- If you need to make changes to a registrant, select the `Registrants` page and choose the action you want to take.
- If you are unsure about any of the fields, refer to the meeting details or contact the meeting organizer.
