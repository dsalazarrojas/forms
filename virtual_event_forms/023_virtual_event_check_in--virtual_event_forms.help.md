# Virtual Event Check In - Help Guide
## Purpose
This form is for attendees to check in for a virtual event. It collects information about the attendee and event details to help event organizers track attendance and manage event logistics.

## How To Complete This Form
1. Select the "Not Registered" or "Registered" option for the "Registration Status" field to indicate your attendance status.
2. Enter your name in the "Attendee Name" field.
3. Enter your email address in the "Attendee Email" field.
4. Enter your address in the "Attendee Address" field.
5. Enter your phone number in the "Attendee Phone" field.
6. Enter the event name in the "Event Name" field.
7. Enter the event start date in the "Event Start Date" field.
8. Enter the event start time in the "Event Start Time" field.
9. Enter the event end date in the "Event End Date" field.
10. Enter the event end time in the "Event End Time" field.
11. Enter the event location in the "Event Location" field.
12. Enter a brief description of the event in the "Event Description" field.
13. Select the event category as "Virtual Event" or "In-person Event" in the "Event Category" field.
14. Enter any additional tags for the event in the "Event Tag" field.
15. Enter any comments about your attendance in the "Attendee Comment" field.
16. Upload any photo or file associated with your attendance in the "Attendee Photo" and "Attendee File" fields.
17. Enter any link or Facebook information for the event in the "Event Link" and "Event Facebook" fields.
18. Finally, select "True" or "False" for the "Form Completed" field to confirm that you have filled out this form accurately.

## Field-by-Field Explanation
- **User Information**: A text field for attendees to enter their general information.
- **Attendee Details**: A text field for attendees to enter their details, such as their name, email, and address.
- **Event Info**: A text field for attendees to enter event details, such as the event name and dates.
- **Registration Status**: A select field to indicate whether the attendee is registered or not for the event.
- **Attendee Name**: A text field for attendees to enter their name.
- **Attendee Email**: A text field for attendees to enter their email address.
- **Attendee Address**: A text field for attendees to enter their address.
- **Attendee Phone**: A text field for attendees to enter their phone number.
- **Event Name**: A text field for attendees to enter the event name.
- **Event Start Date**: A date field for attendees to enter the event start date.
- **Event Start Time**: A time field for attendees to enter the event start time.
- **Event End Date**: A date field for attendees to enter the event end date.
- **Event End Time**: A time field for attendees to enter the event end time.
- **Event Location**: A text field for attendees to enter the event location.
- **Event Description**: A text field for attendees to enter a brief description of the event.
- **Event Category**: A select field for attendees to select the event category as "Virtual Event" or "In-person Event".
- **Event Tag**: A text field for attendees to enter any additional tags for the event.
- **Attendee Comment**: A text field for attendees to enter any comments about their attendance.
- **Attendee Photo**: A note field for attendees to upload a photo associated with their attendance.
- **Attendee File**: A text field for attendees to upload any file associated with their attendance.
- **Event Link**: A text field for attendees to enter any link for the event.
- **Event Facebook**: A text field for attendees to enter any Facebook information for the event.
- **Attendee Facebook**: A text field for attendees to enter their Facebook information.
- **Form Completed**: A select field for attendees to confirm that they have filled out this form accurately.
