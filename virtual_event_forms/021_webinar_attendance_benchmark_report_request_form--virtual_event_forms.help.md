# webinar_attendance_benchmark_report_request_form - Help Guide
## Purpose
This form is designed to help you collect data for a webinar attendance benchmark report. The report will provide insights into your webinar's performance compared to industry benchmarks.

## How To Complete This Form
To complete this form, follow these steps:

1.  Provide the webinar performance details (page 1).
2.  Indicate if you would like to request a benchmark report for this webinar (page 2).
3.  Specify the webinar date, start time, and topic (pages 3-5).
4.  Enter the number of attendees and any feedback received from them (pages 6-7).
5.  Choose the channels used for marketing (page 8) and education (page 9).
6.  Select the marketing strategy employed (page 10).
7.  Specify the format of the webinar (page 11).
8.  Choose the target audience and language (pages 12-13).
9.  Select the location and type of the event (pages 14-15).
10. Indicate the event status and any further details (pages 16-17).

## Field-by-Field Explanation
### 1. Webinar Performance Details
*   **Webinar Performance Details** (`webinar_performance_details`, `text`, required: false): Describe the performance details of your webinar.
### 2. Webinar Request Benchmark Report
*   **Webinar Request Benchmark Report** (`webinar_request_benchmark_report`, `select_one`, required: false): Indicate if you would like to request a benchmark report for this webinar.
### 3. Webinar Date
*   **Webinar Date** (`webinar_date`, `date`, required: false): Enter the date of your webinar.
### 4. Webinar Start Time
*   **Webinar Start Time** (`webinar_start_time`, `time`, required: false): Enter the start time of your webinar.
### 5. Webinar Topic
*   **Webinar Topic** (`webinar_topic`, `text`, required: false): Enter the topic of your webinar.
### 6. Attendees Count
*   **Attendees Count** (`attendees_count`, `number`, required: false): Enter the number of attendees you had for your webinar.
### 7. Attendee Feedback
*   **Attendee Feedback** (`attendee_feedback`, `text`, required: false): Enter any feedback received from your attendees.
### 8. Marketing Channel
*   **Marketing Channel** (`marketing_channel`, `select_multiple`, required: false): Select the channels you used for marketing your webinar. Options include:
    +   Social Media
    +   Email
    +   Influencer
### 9. Education Channel
*   **Education Channel** (`education_channel`, `select_multiple`, required: false): Select the channels you used for education. Options include:
    +   Website
    +   Blog
    +   Influencer
### 10. Marketing Strategy
*   **Marketing Strategy** (`marketing_strategy`, `select_one`, required: false): Choose the marketing strategy you employed. Options include:
    +   Awareness
    +   Engagement
    +   Conversion
### 11. Event Format
*   **Event Format** (`event_format`, `select_one`, required: false): Select the format of your webinar. Options include:
    +   Live
    +   Pre-recorded
    +   Hybrid
### 12. Target Audience
*   **Target Audience** (`target_audience`, `select_multiple`, required: false): Select your target audience. Options include:
    +   General public
    +   Specific Industry
    +   Targeted audience
### 13. Event Duration
*   **Event Duration** (`event_duration`, `text`, required: false): Enter the duration of your event.
### 14. Event Location
*   **Event Location** (`event_location`, `text`, required: false): Enter the location of your event.
### 15. Event Format Detail
*   **Event Format Detail** (`event_format_detail`, `select_multiple`, required: false): Select the format of your event. Options include:
    +   Webinar
    +   Video
    +   Presentation
### 16. Event Language
*   **Event Language** (`event_language`, `select_multiple`, required: false): Select the language of your event. Options include:
    +   English
    +   Spanish
    +   Chinese
### 17. Target Location
*   **Target Location** (`target_location`, `text`, required: false): Enter the target location of your event.
### 18. Event Type
*   **Event Type** (`event_type`, `select_multiple`, required: false): Select the type of your event. Options include:
    +   Online
    +   Offline
    +   Hybrid
### 19. Event Status
*   **Event Status** (`event_status`, `select_one`, required: false): Select the status of your event. Options include:
    +   Upcoming
    +   Past
    +   Future
### 20. Event Status Detail
*   **Event Status Detail** (`event_status_detail`, `text`, required: false): Enter further details about the status of your event.

**Tips**: Ensure you fill out the form correctly, and only submit one form per webinar. If you have any questions or concerns, please contact us.
