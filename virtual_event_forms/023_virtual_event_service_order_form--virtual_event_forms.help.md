# Virtual Event Service Order Form - Help Guide
## Purpose
This form is designed to collect information from clients or customers about their virtual event service orders. It is intended to be used by event planners, organizers, or businesses to gather essential details about the event and services required.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the **Event Organizer** field with the name or title of the person responsible for the event.
2. In the **Event Details** field, provide a brief description of the event, including its purpose, date, and any other relevant information.
3. Select the **Event Start Time** and **Event End Time** fields to enter the start and end dates and times of the event.

## Field-by-Field Explanation

* **Event Organizer** (`event_organizer`, text, **required**): This field is used to input the name or title of the person responsible for the event.
* **Event Details** (`event_details`, text, **required**): This field is used to provide a brief description of the event, including its purpose, date, and any other relevant information.
* **Event Start Time** (`event_start_time`, date, **required**): This field is used to enter the start date and time of the event. The format is a standard date field, where the user can select the date and time of the start of the event.
* **Event End Time** (`event_end_time`, date, **required**): This field is used to enter the end date and time of the event. The format is similar to the start time field, where the user can select the date and time of the end of the event.

## Tips

* Please make sure to fill in all required fields to ensure the form is complete and accurate.
* Double-check the event details to ensure they are correct and complete.
* If you have any questions or issues with the form, please contact [form@gic.mx](mailto:form@gic.mx)
