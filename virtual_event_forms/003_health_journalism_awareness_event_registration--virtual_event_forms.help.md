# Health Journalism Awareness Event Registration - Help Guide

## Purpose

This form is designed to gather information from participants about their interest in attending a virtual health journalism awareness event. The event organizers use this information to plan and prepare for the event, ensuring that participants have a positive experience.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the **Event Name** field with the name of the event you are interested in.
2. Select the **Event Date** field by choosing the date you plan to attend the event.
3. Choose your **Role** in the event (e.g., attendee, speaker, sponsor).
4. Select one or more **Roles** you are interested in assuming during the event (e.g., moderator, presenter).
5. Choose your **Session Preferences** by selecting one or more sessions you are interested in attending.
6. In the **Attendee Details** field, provide any additional information about yourself that you think would be helpful for the event organizers to know.

## Field-by-Field Explanation

* **Event Name** (`event_name`, Text, Optional): Enter the name of the event you are interested in.
* **Event Date** (`event_date`, Date, Optional): Choose the date you plan to attend the event.
* **Role** (`role`, Select One, Optional): Select your role in the event (e.g., attendee, speaker, sponsor).
* **Roles** (`roles`, Select Multiple, Optional): Choose one or more roles you are interested in assuming during the event (e.g., moderator, presenter).
* **Session Preferences** (`session_preferences`, Select Multiple, Optional): Choose one or more sessions you are interested in attending.
* **Attendee Details** (`attendee_details`, Note, Optional): Provide any additional information about yourself that you think would be helpful for the event organizers to know.
