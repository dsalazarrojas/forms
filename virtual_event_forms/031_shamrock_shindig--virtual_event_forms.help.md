# Shamrock Shindig - Help Guide
## Purpose
The Shamrock Shindig form is used to collect information for events hosted by Shamrock Shindig. This form helps event organizers gather and store data for their virtual events.

## How To Complete This Form
1. Fill in the form title to describe the event in a few words.
2. Choose a category that best fits the event.
3. Provide a short description of the event.
4. Enter the price of the tickets for the event.
5. Link to where tickets can be purchased.
6. Choose the date of the event.
7. Select the time of the event.
8. If applicable, note where the event kit can be purchased from.

## Field-by-Field Explanation
* **Shamrock Shindig** (`form_title`, text, optional): A brief title for the event that will appear on the event page.
* **Category** (`form_category`, text, optional): The category of the event, such as sports, music, etc.
* **Description** (`form_description`, text, optional): A short description of the event that will appear on the event page.
* **Ticket Price** (`form_tickets_price`, number, optional): The price of the tickets for the event.
* **Ticket Link** (`form_tickets_link`, text, optional): A link to where tickets can be purchased.
* **Event Date** (`form_event_date`, date, optional): The date of the event.
* **Event Time** (`form_event_time`, time, optional): The time of the event.
* **Purchased from** (`form_purchased_from`, text, optional): If applicable, where the event kit can be purchased from, such as an online store or a physical location.
* **Event Kit** (`form_event_kit`, text, optional): If applicable, the name of the event kit, such as a bundle of resources or supplies.
