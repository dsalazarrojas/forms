# Daycare Observation Form - Help Guide

## Purpose

This form is used to record observations made in a daycare setting. The form captures key information about the observation, including details about the child's behavior and actions.

## How To Complete This Form

To complete this form:

1. Ensure you have all necessary information about the observation, such as the date and time of the observation.
2. Enter the child's first name in the "first_name" field.
3. Enter the teacher's name in the "teacher_name" field.
4. Enter the person observing in the "observed_by" field.
5. Enter the date of the observation in the "date_observed" field in the format MM/DD/YYYY.
6. Enter the time of the observation in the format HH:MM AM/PM.
7. If you have any comments, enter them in the "comments" field.
8. If you have any observations, enter them in the "observations" field.
9. If you have any recommendations, enter them in the "recommendations" field.
10. If you have any notes, enter them in the "notes" field.

## Field-by-Field Explanation

* **First Name**: Enter the child's first name.
* **Teacher Name**: Enter the name of the teacher or staff member responsible for the child.
* **Observed By**: Enter the name of the person who made the observation.
* **Date Observed**: Enter the date of the observation in the format MM/DD/YYYY (e.g. 02/28/2023).
* **Time Observed**: Enter the time of the observation in the format HH:MM AM/PM (e.g. 09:30 AM).
* **Comments**: If you have any comments about the observation, enter them here.
* **Observations**: If you have any observations about the child's behavior, enter them here.
* **Recommendations**: If you have any recommendations for the child or teacher, enter them here.
* **Notes**: If you have any additional notes about the observation, enter them here.

## Tips

* Be sure to fill out all required fields before submitting the form.
* If you need to add more observations or comments, you can add multiple lines in the corresponding fields.
* If you have any further questions or concerns, contact form@gic.mx.
