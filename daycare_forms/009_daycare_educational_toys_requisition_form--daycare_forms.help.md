# Daycare Educational Toys Requisition Form - Help Guide
## Purpose
The Daycare Educational Toys Requisition Form is a request form used by daycare administration to submit a request for educational toys. The form should be completed by the daycare administrator to provide details about the toys requested for the classes and students.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in all the required fields.
2. Choose the educational toy from the options provided in the "Select Toys" field.
3. Select all the classes that the toys are requested for.
4. Fill in the name and contact information of the submitter.
5. Submit the form.

## Field-by-Field Explanation
### Submit Request
* **Submit Request** (`submit_request`, text, optional): Fill in a brief description of the request.

### Select Toys
* **Select Toys** (`select_toys`, select one, optional): Choose the educational toy you want to request from the available options. The options are:
	+ Educational Toy 1
	+ Educational Toy 2
	+ Educational Toy 3

### Date Requested
* **Date Requested** (`date_requested`, date, optional): Choose the date when you want to request the educational toys.

### Select Class
* **Select Class** (`select_class`, select multiple, optional): Select all the classes that the educational toys are requested for. The options are:
	+ Class 1
	+ Class 2
	+ Class 3

### Submitter Name
* **Submitter Name** (`submitter_name`, text, optional): Fill in the name of the person submitting the request.

### Email
* **Email** (`email`, email, optional): Fill in the email of the person submitting the request.

### Phone
* **Phone** (`phone`, text, optional): Fill in the phone number of the person submitting the request.

### Submitter Email
* **Submitter Email** (`submitter_email`, text, optional): Fill in the email of the person submitting the request.

### Tips
*   Please make sure to provide accurate and clear information.
*   Please make sure to choose the correct options for the classes and toys.
*   Please make sure to fill in all the required fields.
*   Please make sure to submit the form once you have completed all the fields.
