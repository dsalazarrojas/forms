# Expense Report Export Request Form - Help Guide
## Purpose
The Expense Report Export Request Form is a tool for users to request an expense report export for their organization. This form helps to gather information from the user about the desired export, such as date range, category, format, delivery method, and report type.

## How To Complete This Form
To complete this form, follow these steps:

1. Select a date range for the expense report you would like to export. You can choose a specific date range or select "Start Date" and "End Date" separately.
2. Choose the category of expenses you would like to export. You can select one category from the options provided.
3. Select the format in which you would like to receive the export. You can choose from Excel, CSV, or PDF.
4. Decide on the delivery method for your export. You can choose to receive it via email or as a file.
5. Specify the report type you would like to export. You can choose from Daily, Weekly, or Monthly reports.
6. Finally, submit your request by selecting "Submit".

## Field-by-Field Explanation

* **Date Range** (`date_range`, date, required: false): This field allows you to select a date range for the expense report export. You can choose a specific date range or select "Start Date" and "End Date" separately. This field is optional.
* **Category** (`category`, select_one, options: [Accounting, Other], required: false): This field allows you to choose the category of expenses you would like to export. You can select one category from the options provided.
* **Format** (`format`, select_multiple, options: [Excel, CSV, PDF], required: false): This field allows you to select the format in which you would like to receive the export. You can choose from Excel, CSV, or PDF.
* **Delivery Method** (`delivery_method`, select_one, options: [Email, File], required: false): This field allows you to decide on the delivery method for your export. You can choose to receive it via email or as a file.
* **Start Date** (`start_date`, date, required: false): This field is used to set the start date for the expense report export.
* **End Date** (`end_date`, date, required: false): This field is used to set the end date for the expense report export.
* **Report Type** (`report_type`, select_multiple, options: [Daily, Weekly, Monthly], required: false): This field allows you to specify the report type you would like to export. You can choose from Daily, Weekly, or Monthly reports.
* **Submit** (`submit`, select_one, options: [Submit, Cancel], required: false): This field is used to finalize your request and submit your expense report export request.
