# Expense Request Form - Help Guide
## Purpose
The purpose of this form is to provide information about an expense request for reimbursement.

## How To Complete This Form
- Review the form carefully to ensure all required fields are completed accurately.
- Fill in the date the expense was incurred.
- Choose whether the expense is a "Yes" or "No" for "Expense Type".
- Enter the amount spent on the expense.
- Provide a brief note about the expense, if necessary.
- If you are requesting reimbursement, the administrator will update the date approved field when the request is approved.

## Field-by-Field Explanation
- **Expense Request** (`expense_request_form`, text, not required):
  This field is for a brief description of the expense.
- **Expense Date** (`expense_date`, date, not required):
  Enter the date the expense was incurred.
- **Expense Type** (`expense_type`, select_one, not required):
  Choose whether the expense is a "Yes" or "No".
- **Amount** (`expense_amount`, number, not required):
  Enter the amount spent on the expense.
- **Note** (`expense_note`, note, not required):
  Provide a brief note about the expense, if necessary.
- **Date Approved** (`expense_date_approved`, date, not required):
  This field is prepopulated by the administrator when the request is approved.

## Tips
- Ensure that you are only submitting one form per expense.
- If you are requesting reimbursement, please ensure that your request is accurate and complete.
- If you have any questions or concerns, please contact the administrator for assistance.
