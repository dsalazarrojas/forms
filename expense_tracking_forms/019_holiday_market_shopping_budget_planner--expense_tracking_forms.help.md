# Holiday Market Shopping Budget Planner - Help Guide
## Purpose
This guide is designed to help you complete the Holiday Market Shopping Budget Planner form. This form is a tool for tracking and managing holiday market shopping events.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form title at the top of the page.
2. Select the category of the event.
3. Enter a brief description of the event.
4. Provide the shopper's name and email address.
5. Input the shopper's phone number.
6. Enter the budgeted amount for the event.
7. Enter the actual amount spent on the event.
8. Add any additional notes about the shopper.
9. Enter the start and end dates of the event.
10. Provide feedback or comments about the event.
11. Enter the name and email of the event organizer.
12. Enter the phone number of the event organizer.
13. Enter any notes about the event.
14. Select the number of shoppers involved in the event.
15. Select the dates and times of the events.
16. Select the type of event.
17. Select the budget allocated for each shopper.

## Field-by-Field Explanation
* **Holiday Market Shopping Budget Planner** (`form_title`, text, required): Enter the title of the holiday market shopping event.
* **Category** (`category`, text, required): Select the category of the event (e.g. Christmas, Thanksgiving, etc.).
* **Description** (`description`, text, required): Enter a brief description of the event.
* **Shopper Name** (`shopper_name`, text, required): Enter the name of the shopper.
* **Shopper E-mail** (`shopper_email`, email, required): Enter the email address of the shopper.
* **Shopper Phone** (`shopper_phone`, text, required): Enter the phone number of the shopper.
* **Budgeted Amount** (`budgeted_amount`, number, required): Enter the budgeted amount for the event.
* **Actual Spent** (`actual_spent`, number, required): Enter the actual amount spent on the event.
* **Shopper Notes** (`shopper_notes`, note, required): Enter any additional notes about the shopper.
* **Event Start Date** (`event_start_date`, date, required): Enter the start date of the event.
* **Event End Date** (`event_end_date`, date, required): Enter the end date of the event.
* **Shopper Feedback** (`shopper_feedback`, note, required): Enter any feedback or comments about the event.
* **Organizer Name** (`organizer_name`, text, required): Enter the name of the event organizer.
* **Organizer E-mail** (`organizer_email`, email, required): Enter the email address of the event organizer.
* **Organizer Phone** (`organizer_phone`, text, required): Enter the phone number of the event organizer.
* **Notes** (`notes`, note, required): Enter any notes about the event.
* **Shopper Count** (`shopper_count`, number, required): Select the number of shoppers involved in the event.
* **Event Count** (`event_count`, number, required): Select the number of events (e.g. multiple dates and times).
* **Total Budget** (`total_budget`, number, required): Enter the total budget for the event.
* **Total Spent** (`total_spent`, number, required): Enter the total amount spent on the event.
* **Shopper Budget** (`shopper_budget`, select_multiple, required): Select the budget allocated to each shopper.
* **Event Date** (`event_date`, select_multiple, required): Select the dates of the events.
* **Event Time** (`event_time`, select_multiple, required): Select the time of the events.
* **Event Type** (`event_type`, select_multiple, required): Select the type of event.
* **Shopper Budget Type** (`shopper_budget_type`, select_multiple, required): Select the type of budget allocated to each shopper.

## Tips
* Make sure to fill in all required fields.
* Double-check the entered data for accuracy.
* Use the form to track and manage holiday market shopping events.
* Take note of any additional notes or feedback.
* Review and update the form as needed.
