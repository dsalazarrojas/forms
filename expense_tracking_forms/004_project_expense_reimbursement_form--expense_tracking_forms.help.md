# project_expense_reimbursement_form - Help Guide
## Purpose
The project expense reimbursement form is used to collect and track project expenses. To complete this form, please follow the steps below.

## How To Complete This Form
To complete this form, please provide the following information:

1. **Project ID** (`project_id`): Please enter the ID of the project you are submitting an expense for.
2. **Date** (`date`): Enter the date the expense was incurred.
3. **Amount** (`amount`): Enter the amount of the expense.
4. **Description** (`description`): Provide a brief description of the expense.
5. **Status** (`status`): Select the status of the expense (Approved, Pending, or Rejected).
6. **Expense Type** (`expense_type`): Choose the type of expense (Travel, Food, or Accommodation).
7. **Category** (`category`): Select all applicable categories for the expense (Yes or No).
8. **Assigned User** (`assigned_user`): Select the user to whom the expense is assigned (Yes or No).

## Field-by-Field Explanation
* **Project ID** (`project_id`): Enter the ID of the project you are submitting an expense for.
* **Date** (`date`): Enter the date the expense was incurred.
* **Amount** (`amount`): Enter the amount of the expense.
* **Description** (`description`): Provide a brief description of the expense.
* **Status** (`status`): Select the status of the expense (Approved, Pending, or Rejected).
	+ Approved: The expense has been reviewed and approved.
	+ Pending: The expense is waiting for review.
	+ Rejected: The expense has been rejected.
* **Expense Type** (`expense_type`): Choose the type of expense (Travel, Food, or Accommodation).
	+ Travel: Expenses related to travel (e.g., flights, hotels).
	+ Food: Expenses related to food (e.g., meals, snacks).
	+ Accommodation: Expenses related to accommodation (e.g., hotels, rentals).
* **Category** (`category`): Select all applicable categories for the expense (Yes or No).
	+ Yes: The expense falls under this category.
	+ No: The expense does not fall under this category.
* **Assigned User** (`assigned_user`): Select the user to whom the expense is assigned (Yes or No).
	+ Yes: The expense is assigned to this user.
	+ No: The expense is not assigned to this user.

## Tips

* Make sure to fill out all required fields carefully and accurately.
* If the expense is related to a specific project, please ensure the project ID is correct.
* If the expense has been approved or rejected, please select the corresponding status.
* If the expense falls under a specific category, please select Yes.
