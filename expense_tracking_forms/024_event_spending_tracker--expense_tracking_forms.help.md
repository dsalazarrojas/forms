This form is designed to help users track event spending, allowing them to record details about an event, including the event date, amount spent, category of expense, and any additional description or uploaded files related to the event. The form should not be used for duplicate events or events that are not relevant to the user's current context. This form will serve as a tracking tool for users to monitor their events and expenses.

# event_spending_tracker - Help Guide
## Purpose
The event spending tracker form is a tool for users to record and track spending associated with events.

## How To Complete This Form

1.  Fill out the **Event Details** field with a brief title or description of the event.
2.  Enter the **Expense Date** of the event by selecting the correct date in the calendar format.
3.  Type in the **Amount** of money spent on the event.
4.  Choose the category or categories that best describe the event's nature by checking the corresponding boxes under **Category Options**.
5.  Add any additional **Description** of the event, if needed.
6.  If required, upload a file related to the event.
7.  Select the **Event Budget** for the event from the provided options.

## Field-by-Field Explanation

*   **Event Details** (Event Details, text, optional)
    *   Enter a brief title or description of the event.
*   **Expense Date** (Expense Date, date, optional)
    *   Enter the date of the event using the calendar format (YYYY-MM-DD).
*   **Amount** (Amount, number, optional)
    *   Enter the total amount of money spent on the event.
*   **Category** (Category, select_multiple, optional)
    *   This field is not currently active; it seems to be intended for category selection in some capacity but is not currently being used as expected based on the provided YAML.
*   **Description** (Description, text, optional)
    *   Enter any additional description about the event, if needed.
*   **Upload File** (Upload File, text, optional)
    *   If necessary, upload a file related to the event.
*   **Category Options** (Category Options, select_one, optional)
    *   Select one category that best describes the event's nature.
*   **Event Budget** (Event Budget, number, optional)
    *   Select the event budget from the provided options.
