# smart_lighting_calibration_consent_form - Help Guide

## Purpose
This form is used to obtain informed consent from users for smart lighting calibration. The purpose of this form is to ensure that users understand the process and requirements for calibration, and to obtain their consent before proceeding. It is essential to complete this form carefully and honestly, as it will be used as a reference point for future services and adjustments.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Review each field carefully to ensure you understand what is being asked.
2. Select the correct options for each field based on your situation.
3. Enter any required information accurately and truthfully.
4. Save your changes and submit the form when finished.

## Field-by-Field Explanation

* **User**: (`1`, select_one, required: false) - Please select 'Yes' if you are the end-user of the service, or 'No' if you are not.
* **Contact Method**: (`2`, select_one, required: false) - Please select 'Yes' if you have contacted us about the service, or 'No' if you have not contacted us.
* **Phone**: (`3`, text, required: false) - Enter your phone number if you would like to be contacted by us, or leave it blank if you do not.
* **Email**: (`4`, email, required: false) - Enter your email address if you would like to receive updates and communications from us, or leave it blank if you do not.
* **Address**: (`5`, select_multiple, required: false) - Please select 'Yes' if you have an address where we can contact you, or 'No' if you do not have a fixed address.
* **Manager**: (`6`, select_one, required: false) - Please select 'Yes' if you are the manager of the service, or 'No' if you are not.
* **Service Provider**: (`7`, select_one, required: false) - Please select 'Yes' if you are the service provider, or 'No' if you are not.
* **Approval Date**: (`8`, date, required: false) - Enter the date of your approval, if applicable.
* **Service Adjustments**: (`9`, text, required: false) - Enter any service adjustments or requests you have, if applicable.

## Tips
* Be honest and accurate when filling out this form.
* If you are unsure about any field, please contact us for clarification.
* Please review your form carefully before submitting it, to ensure everything is accurate and complete.
