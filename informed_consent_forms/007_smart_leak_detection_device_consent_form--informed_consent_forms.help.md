# Smart Leak Detection Device Consent Form - Help Guide
## Purpose
The Smart Leak Detection Device Consent Form is a crucial document that ensures clients or property managers are informed and approve the installation of the device on their properties. This form is a critical step in the installation process, as it requires the consent of the person in charge of the property before the device is installed.
## How To Complete This Form
To complete this form, please follow these steps:
1. Review the form carefully and understand the implications of installing the device.
2. Select "Yes" or "No" for the Client Approval field to indicate your approval or disapproval of the installation.
3. If you are a property manager, select "Property manager 1" or "Property manager 2" from the dropdown menu to indicate which property manager has authorized the installation.
4. Enter the installation date in the correct format (MM/DD/YYYY).
## Field-by-Field Explanation
* **Client Approval** (`Client Approval`, yes/no, required): Select "Yes" to indicate that you approve of the installation of the smart leak detection device. Select "No" if you do not approve.
* **Property Manager Details** (`Property Manager Details`, dropdown, optional): If you are a property manager, select the name of the property manager who has authorized the installation of the device.
* **Smart Leak Sensors Details** (`Smart Leak Sensors Details`, text area, optional): This field is for additional notes or comments about the installation of the device. You can enter any relevant information here.
* **Installation Date** (`Installation Date`, date, optional): Enter the date the device will be installed on the property. Use the standard date format (MM/DD/YYYY).
