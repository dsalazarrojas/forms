# healthcareroboticsresearchfilmingconsentform - Help Guide

## Purpose
This form is designed for participants to provide informed consent for health care robotics research filming. The form is intended to ensure that participants understand and agree to the terms of the filming, including the types of filming methods that will be used and the purpose of the research project.

## How To Complete This Form
To complete this form, please follow these steps:

1. Read through each section carefully and answer all required questions.
2. Select the appropriate options for each field.
3. Enter any necessary contact information if you wish to be contacted for follow-up questions or to learn more about the project.

## Field-by-Field Explanation
### 1. Introduction (id: 1)
* **Introduction** (`text`, required: false): This is a brief description of the research project.

### 2. Informed Consent (id: 2)
* **Do you agree** (`select_one`, required: true): Please select "I do" to agree to participate in the research project.

### 3. Filming Consent (id: 3)
* **Filming Consent** (`select_multiple`, required: true): Please select all methods that apply to you:
	+ Camera
	+ Audio
	+ Video
	+ Photograph

### 4. Filming Method (id: 4)
* **Filming Method** (`select_multiple`, required: true): Please select all methods that apply to you:
	+ Video
	+ Audio
	+ Photograph

### 5. Filming Location (id: 5)
* **Filming Location** (`text`, required: false): This field is optional and should only be filled out if you wish to be filmed in a specific location.

### 6. Contact Information (id: 6)
* **Contact Information** (`text`, required: false): Please enter any contact information you wish to be contacted with for follow-up questions or to learn more about the project.

### 7. Name (id: 7)
* **Name** (`text`, required: false): Enter your name for contact purposes.

### 8. Phone Number (id: 8)
* **Phone Number** (`text`, required: false): Enter your phone number for contact purposes.

### 9. Email (id: 9)
* **Email** (`email`, required: false): Enter your email address for contact purposes.

### 10. Researcher Information (id: 10)
* **Researcher Information** (`text`, required: false): This field is for additional notes from the researcher.

### 11. Research Project (id: 11)
* **Research Project** (`text`, required: false): This field is for notes about the research project.

### 12. Researcher Name (id: 12)
* **Researcher Name** (`text`, required: false): Enter the researcher's name for contact purposes.

### 13. Prohibited Prophets (id: 13)
* **Prohibited Prophets** (`select_multiple`, required: false): Please select any prohibited areas, such as:
	+ Animals
	+ Bacteria
	+ Virology
