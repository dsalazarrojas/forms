# Facility Upgade Observation Consent Form - Help Guide

## Purpose
The Facility Upgrade Observation Consent Form is a document that requires users to acknowledge and consent to the observation and upgrade of facilities within their system. This form ensures that users understand the implications of these upgrades and acknowledge their consent in the process.

## How To Complete This Form

To complete this form, follow these steps:

* Fill out each page of the form as instructed.

## Field-by-Field Explanation

* **Facility Upgrade Observation Consent Form** (Page 1, facility_upgrade_observation_consent_form_page_1, text, not required)
  This is the title of the form, which should be read and understood before proceeding.
* **Facility Upgrades** (Page 2, facility_upgrade_observation_consent_form_page_2, select_one, required)
  Select the specific upgrades you consent to from the options provided. Please note that selecting "Other" requires additional explanation.
* **Facility Upgrades** (Page 3, facility_upgrade_observation_consent_form_page_3, select_multiple, required)
  Select multiple upgrades you consent to, as applicable. Note that you may select more than one option.
* **Facility Upgrades** (Page 4, facility_upgrade_observation_conscent_form_page_4, text, required)
  Describe the selected upgrades in detail, if not already captured in the previous field.

## Tips

* Make sure to thoroughly understand the implications of each selected upgrade before proceeding.
* Select only the upgrades you are willing to consent to.
* Clearly describe the upgrades in the last field, if not already captured in the previous fields.
