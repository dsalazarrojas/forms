# School Intent Form - Help Guide

## Purpose
This form is used to collect information from schools about their intended enrollment and pre-registration dates for the upcoming semester. It is essential to complete this form accurately to ensure that the school's information is up-to-date and reflects their actual intentions.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "School Intent Form" page.
2. Fill in the expected enrollment details in the "Expected Enrollment" field.
3. Enter the pre-registration start and end dates in the corresponding fields.
4. Enter the number of students, if applicable.
5. Review and submit the form.

## Field-by-Field Explanation

* **School Intent Form** (`school_intent_form`, text, **required**): Enter a brief description of the school's intention for the upcoming semester.
* **Expected Enrollment** (`expected_enrollment`, number, **optional**): Enter the expected number of students to be enrolled for the upcoming semester. This field is not required but is helpful for planning purposes.
* **Pre-Registration Start Date** (`pre_registration_start_date`, date, **optional**): Enter the date when the pre-registration process is expected to start for the upcoming semester.
* **Pre-Registration End Date** (`pre_registration_end_date`, date, **optional**): Enter the date when the pre-registration process is expected to end for the upcoming semester.
* **Number of Students** (`number_of_students`, number, **optional**): Enter the expected number of students to be enrolled, if applicable.

## Tips
* Make sure to fill in the form accurately to reflect the school's actual intentions.
* Review and submit the form only after completing all the fields.
* If you need to make any changes, you can always edit the form before submitting it.
