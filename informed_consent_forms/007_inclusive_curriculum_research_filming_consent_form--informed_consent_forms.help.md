# inclusive_curriculum_research_filming_consent_form - Help Guide
## Purpose
The inclusive_curriculum_research_filming_consent_form is designed to collect informed consent from participants for filming in a research context.

## How To Complete This Form
To complete this form, please follow the steps below:

1.  Review each page and ensure that all required fields are filled out.
2.  Complete all text fields by typing in the requested information.
3.  Select the appropriate options from the dropdown lists.

## Field-by-Field Explanation

* **1. Form Information (required)**: Provide a general description of the research project and the purpose of filming.
* **2. Participant Information (optional)**: Select "Yes" if you are a participant.
* **3. Filming Information (required)**: Provide a description of the filming process, including any specific details about what will be filmed and when.
* **4. Contact Information (optional)**: Select "Yes" if you would like to be contacted for further information.
* **5. Participant Phone (required)**: Enter the participant's phone number.
* **6. Participant Email (required)**: Enter the participant's email address.
* **7. Filming Location (required)**: Enter the filming location.
* **8. Filming Duration (required)**: Enter the duration of the filming session.
* **9. Filming Date (required)**: Enter the date of the filming session.
* **10. Filming Time (required)**: Enter the time of the filming session.
* **11. Additional Filming Details (required)**: Provide any additional information about the filming session, such as equipment or crew members.
* **12. Participant Permission (optional)**: Select "Yes" if you grant permission for the participant to be filmed.
* **13. Filming Conduct (optional)**: Select "Yes" if you will be filming in a way that does not cause harm or discomfort to the participant.
* **14. Filming Supervision (optional)**: Select "Yes" if you will have supervision during the filming session.
* **15. Participant Informed Consent (optional)**: Select "Yes" if you have informed the participant about the filming process.
* **16. Participant Age (required)**: Enter the participant's age.
* **17. Participant Gender (optional)**: Select the participant's gender.
* **18. Participant School Attendance (optional)**: Select "Yes" if the participant is in school.
* **19. Participant Language (optional)**: Select the participant's language.
* **20. Participant Culture (optional)**: Select the participant's culture.
* **21. Participant Ethnicity (optional)**: Select the participant's ethnicity.
* **22. Participant Disability (optional)**: Select "Yes" if the participant has a disability.
* **23. Participant Special Education Needs (optional)**: Select "Yes" if the participant requires special education accommodations.
* **24. Participant Medical Conditions (optional)**: Select "Yes" if the participant has any medical conditions.
* **25. Participant Medication (optional)**: Select "Yes" if the participant takes any medication.
