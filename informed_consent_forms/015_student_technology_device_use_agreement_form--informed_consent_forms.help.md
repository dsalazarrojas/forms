# Student Technology Device Use Agreement Form - Help Guide
## Purpose

This form is used to gather information about student's technology device usage, warranty, and return policies.

## How To Complete This Form

1. Please select the type of device you have access to (page 1).
2. Enter the Device Model (page 2).
3. Enter the Device Serial Number (page 2).
4. Select the device owner (page 3).
5. Select the start date of device usage (page 4).
6. Select the end date of device usage (page 5).
7. Enter the device warranty (page 6).
8. Select the date to return the device (page 7).
9. Agree to the terms and conditions (page 8).
10. Enter your signature (page 9).
11. Enter your student ID (page 10).
12. Enter your student email (page 11).
13. Enter your student phone (page 12).
14. Enter the faculty name (page 13).
15. Enter the faculty email (page 14).
16. Enter the faculty phone (page 15).
17. Select the device return policy (page 16).
18. Select the device return status (page 17).
19. Enter the device return notes (page 18).
20. Select the date of device return (page 19).
21. Enter your student name (page 20).
22. Enter the device type ID (page 21).
23. Enter the faculty (page 22).
24. Enter the student department (page 23).
25. Enter the department (page 24).

## Field-by-Field Explanation

* **What type of device do you have access to? (Page 1)**: Select the type of device you have access to (e.g., Apple, Android, Other).
* **Device Model (Page 2)**: Enter the model of your device (e.g., iPhone, Samsung Galaxy S21).
* **Device Serial Number (Page 2)**: Enter the serial number of your device.
* **Device Owner (Page 3)**: Select the owner of the device.
* **Device Usage Start Date (Page 4)**: Select the start date of device usage.
* **Device Usage End Date (Page 5)**: Select the end date of device usage.
* **Device Warranty (Page 6)**: Enter the warranty information of your device.
* **Date to return the device (Page 7)**: Select the date you plan to return the device.
* **Terms and Conditions (Page 8)**: Agree to or disagree with the terms and conditions.
* **Signature (Page 9)**: Enter your signature to confirm agreement to the terms and conditions.
* **Student ID (Page 10)**: Enter your student ID number.
* **Student Email (Page 11)**: Enter your student email address.
* **Student Phone (Page 12)**: Enter your student phone number.
* **Faculty Name (Page 13)**: Enter the name of the faculty member.
* **Faculty Email (Page 14)**: Enter the email address of the faculty member.
* **Faculty Phone (Page 15)**: Enter the phone number of the faculty member.
* **Device Return Policy (Page 16)**: Select the device return policy.
* **Device Return Status (Page 17)**: Select the device return status.
* **Device Return Notes (Page 18)**: Enter any notes about the device return.
* **Date of device return (Page 19)**: Select the date of device return.
* **Student Name (Page 20)**: Enter your student name.
* **Device Type ID (Page 21)**: Enter the ID of your device type.
* **Faculty (Page 22)**: Enter the faculty member's name.
* **Student Department (Page 23)**: Enter the department you belong to.
* **Department (Page 24)**: Enter the department name.
