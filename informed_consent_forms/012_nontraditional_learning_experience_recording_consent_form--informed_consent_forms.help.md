# Nontraditional Learning Experience Recording Consent Form - Help Guide
## Purpose
The Nontraditional Learning Experience Recording Consent Form is designed to collect participant's consent and permissions for recording non-traditional learning experiences. This form ensures that participants understand what they are consenting to and can provide their permission for recordings to be made.

## How To Complete This Form
1. **Please read through the form carefully and answer the questions honestly**.
2. **Answer all the questions, even if some fields have "do not" options**.
3. **Select the correct options for each field**.

## Field-by-Field Explanation
* **Particpant Name** (`participant_name`, text, required): This field is for you to enter your name as the participant.
* **Education Program** (`education_program`, text, optional): This field is for you to specify the education program you are participating in, if any.
* **Training** (`training`, text, optional): This field is for you to specify the training you are participating in, if any.
* **Internship** (`internship`, text, optional): This field is for you to specify the internship you are participating in, if any.
* **Record Audio** (`record_audio`, select_multiple, optional): Select "Recording is allowed with participant permission" if you give consent for audio recordings. Otherwise, select "Participant will not be recorded".
* **Record Video** (`record_video`, select_one, optional): Select "record video" if you give consent for video recordings. Otherwise, select "do not record video".
* **Record Phone** (`record_phone`, select_one, optional): Select "record phone" if you give consent for phone recordings. Otherwise, select "do not record phone".
* **Record Computer** (`record_computer`, select_one, optional): Select "record computer" if you give consent for computer recordings. Otherwise, select "do not record computer".
* **Record Other** (`record_other`, select_one, optional): Select "record other" if you give consent for other type of recordings. Otherwise, select "do not record other".
* **Record Audio Phone** (`record_audio_phone`, select_one, optional): Select "record audio phone" if you give consent for audio phone recordings. Otherwise, select "do not record audio phone".
* **Record Interview** (`record_interview`, select_one, optional): Select "record interview" if you give consent for interview recordings. Otherwise, select "do not record interview".
* **Record Meeting** (`record_meeting`, select_one, optional): Select "record meeting" if you give consent for meeting recordings. Otherwise, select "do not record meeting".
* **Record Other Device** (`record_other_device`, select_one, optional): Select "record other device" if you give consent for other type of recordings. Otherwise, select "do not record other device".
* **Consent to Record** (`consent_to_record`, select_one, optional): Select "consent to record" if you give consent for recordings. Otherwise, select "do not consent to record".
* **Record Consent** (`record_consent`, select_one, optional): Select "record consent" if you give consent for consent recordings. Otherwise, select "do not record consent".
* **Record Signature** (`record_signature`, select_one, optional): Select "record signature" if you give consent for signature recordings. Otherwise, select "do not record signature".
* **Record Note Taking** (`record_note_taking`, select_one, optional): Select "record note taking" if you give consent for note-taking recordings. Otherwise, select "do not record note taking".
* **Record Audio Notes** (`record_audio_notes`, select_one, optional): Select "record audio notes" if you give consent for audio notes recordings. Otherwise, select "do not record audio notes".
* **Record Other Notes** (`record_other_notes`, select_one, optional): Select "record other notes" if you give consent for other type of notes recordings. Otherwise, select "do not record other notes".
* **Participant Permission Given** (`participant_permission_given`, select_one, optional): Select "participant permission given" if you give permission for recordings. Otherwise, select "participant permission not given".
* **Participant Permission Revoke** (`participant_permission_revoke`, select_one, optional): Select "participant permission revoke" if you revoke permission for recordings. Otherwise, select "participant permission not revoke".
* **Participant Permission Change** (`participant_permission_change`, select_one, optional): Select "participant permission change" if you want to change your permission for recordings. Otherwise, select "participant permission not change".
* **Participant Permission End Date** (`participant_permission_end_date`, select_one, optional): Select "participant permission end date" if you want to specify an end date for your permission. Otherwise, select "participant permission no date".
* **Participant Permission Reason** (`participant_permission_reason`, select_one, optional): Select "participant permission reason" if you have a reason for your permission. Otherwise, select "participant permission no reason".

## Tips
* Make sure to answer honestly and accurately to ensure that your recordings are valid and compliant with any relevant regulations.
* If you're unsure about any field, don't hesitate to ask for clarification.
* Review and sign the form before submitting it to confirm your consent.
