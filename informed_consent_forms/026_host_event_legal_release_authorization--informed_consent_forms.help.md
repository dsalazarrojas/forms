# Host Event Legal Release Authorization - Help Guide

## Purpose
The Host Event Legal Release Authorization form is a document used to collect informed consent from participants in events or activities where they may be recorded, photographed, or otherwise captured for promotional or other purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the participant's information on **page 1: Participant Information**.
   - Please fill in the **Host Name**, as it will be used as a reference for participant data.
   - Enter the **Participant Name**, which should match the name of the person participating in the event.
   - Provide the **Participant Phone Number** and **Participant Email**, if applicable.
2. Confirm your agreement with the **Participant Service Agreement** on **page 2: Service Agreement**.
   - Select "Yes" if you agree to the terms of the service agreement.
3. Determine which types of releases you are granting consent for on **page 3: Release Authorization**.
   - Choose "Yes" for the type(s) of release you are consenting to.
   - Please note that you can choose multiple releases.
4. Provide event details on **page 4: Event Details**.
   - Enter the **Participant Event Name** and **Participant Event Date** (if applicable).
   - Fill in the **Participant Event Location** and **Participant Event Description** (if applicable).
   - Select the **Participant Event Type** (if applicable).
5. Add any additional notes or comments on **page 5: Other Event Details**.
   - Please use this section for any other information that may be relevant to your participation in the event.

## Field-by-Field Explanation

* **Host Name** (`host_name`, `text`, required): Enter the name of the host or organization responsible for the event.
* **Participant Name** (`participant_name`, `text`, required): Enter the name of the participant (same as the person participating in the event).
* **Participant Phone** (`participant_phone`, `text`, optional): Enter the participant's phone number, if applicable.
* **Participant Email** (`participant_email`, `email`, optional): Enter the participant's email address, if applicable.
* **Participant Service Agreement** (`participant_service_agreement`, `select_multiple`, optional): Confirm your agreement with the participant service agreement.
* **Host Agreement** (`host_agreement`, `text`, optional): Enter any additional agreement or notes from the host.
* **Participant Photo Release** (`participant_photo_release`, `select_multiple`, optional): Select "Yes" if you are granting photo release for the participant.
* **Participant Video Release** (`participant_video_release`, `select_multiple`, optional): Select "Yes" if you are granting video release for the participant.
* **Participant Audio Release** (`participant_audio_release`, `select_multiple`, optional): Select "Yes" if you are granting audio release for the participant.
* **Participant Image Release** (`participant_image_release`, `select_multiple`, optional): Select "Yes" if you are granting image release for the participant.
* **Participant Live Release** (`participant_live_release`, `select_multiple`, optional): Select "Yes" if you are granting live release for the participant.
* **Participant Event Name** (`participant_event_name`, `text`, optional): Enter the name of the event or activity.
* **Participant Event Date** (`participant_event_date`, `date`, optional): Enter the date of the event or activity (if applicable).
* **Participant Event Location** (`participant_event_location`, `text`, optional): Enter the location of the event or activity (if applicable).
* **Participant Event Description** (`participant_event_description`, `text`, optional): Enter a description of the event or activity (if applicable).
* **Participant Event Type** (`participant_event_type`, `select_one`, optional): Select the type of event or activity.
* **Participant Other Release** (`participant_other_release`, `text`, optional): Enter any additional releases or agreements.
* **Participant Other Event Details** (`participant_other_event_details`, `text`, optional): Enter any additional notes or comments about the event or activity.
* **Participant Other** (`participant_other`, `text`, optional): Enter any other information about the participant.
