# Employee Offboarding Checklist Form - Help Guide
## Purpose
This form is used to document the necessary steps taken during the offboarding process for an employee leaving the company. It helps to ensure that all parties involved are informed and all assets and access are properly updated and returned.

## How To Complete This Form
1. Review the form carefully and answer all questions honestly.
2. Confirm whether the employee has been informed of their termination or resignation.
3. Select the relevant options for each field based on the employee's situation.
4. Provide any additional comments or details as needed.
5. Submit the form once complete.

## Field-by-Field Explanation

* **Confirm Termination** (`confirm_termination`, Select, Required): Confirm whether the employee's termination has been formally communicated to them.
	+ Select "Yes" if the employee has been informed of their termination.
	+ Select "No" if the employee has not been informed.
* **Update Employee Status** (`update_employee_status`, Select, Required): Update the employee's status in the company system.
	+ Select "Active" to update the employee's status to active.
	+ Select "Inactive" to update the employee's status to inactive.
* **Notify Superior** (`notify_superior`, Note, Optional): Note to superior(s) to be informed of the employee's offboarding.
* **Notify IT** (`notify_it`, Note, Optional): Note to IT department to be informed of the employee's offboarding.
* **Notify HR** (`notify_hr`, Note, Optional): Note to HR department to be informed of the employee's offboarding.
* **Notify Admin** (`notify_admin`, Note, Optional): Note to admin department to be informed of the employee's offboarding.
* **Update Access** (`update_access`, Select, Required): Update employee's access to company systems.
	+ Select "Yes" to update access.
	+ Select "No" to maintain current access.
* **Update Network Access** (`update_network_access`, Select, Required): Update employee's network access.
	+ Select "Yes" to update network access.
	+ Select "No" to maintain current network access.
* **Update Email Forwarding** (`update_email_forwarding`, Select, Required): Update email forwarding settings.
	+ Select "Yes" to update email forwarding.
	+ Select "No" to maintain current email forwarding.
* **Update Phone Forwarding** (`update_phone_forwarding`, Select, Required): Update phone forwarding settings.
	+ Select "Yes" to update phone forwarding.
	+ Select "No" to maintain current phone forwarding.
* **Notify Benefits** (`notify_benefits`, Note, Optional): Note to benefits team to be informed of the employee's offboarding.
* **Collect Secrets** (`collect_secrets`, Note, Optional): Note to collect any company secrets or confidential information from the employee.
* **Update Credentials** (`update_credentials`, Note, Optional): Note to update employee's credentials (e.g. login, passwords, etc.).
* **Return Equipment** (`return_equipment`, Note, Optional): Note to return company equipment to the employee.
* **Document Destruction** (`document_destruction`, Note, Optional): Note to destroy any company documents or records related to the employee.
* **Update Passwords** (`update_passwords`, Note, Optional): Note to update employee's passwords.
* **Notify Accounting** (`notify_accounting`, Note, Optional): Note to accounting department to be informed of the employee's offboarding.
* **Update Credit Cards** (`update_credit_cards`, Note, Optional): Note to update employee's credit card information.
* **Send Outgoing** (`send_outgoing`, Note, Optional): Note to send any outgoing mail or packages to the employee.
* **Update Incoming** (`update_incoming`, Note, Optional): Note to update incoming mail or packages for the employee.
