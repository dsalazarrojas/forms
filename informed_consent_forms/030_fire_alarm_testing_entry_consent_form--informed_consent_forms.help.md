# fire_alarm_testing_entry_consent_form - Help Guide
## Purpose
This form is used to gather informed consent from users before performing fire alarm testing on a given site. It's essential to complete this form to ensure that users are aware of their responsibilities and the testing process.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the correct answer for each question based on your current status.
2. Provide accurate and detailed answers where applicable.
3. Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Tenant Authorization**: Select 'Yes' if you're authorized to perform testing on this site. This question helps us understand your role and permissions.
* **Contact Details**: Enter your name, email, and phone number so we can contact you in case of emergencies or follow-up questions.
* **Preferred Testing Time**: Choose a time that suits you best for the testing session. This helps us schedule the testing accordingly.
* **Testing Frequency**: Select 'Yes' if you're willing to participate in regular testing sessions. This helps us determine the testing schedule.
* **Testing Method**: Choose the most suitable method for the testing, such as 'Yes' for traditional testing or 'No' for online testing.
* **Test Location**: Select 'Yes' for the site where you'll be performing the testing, 'No' for other locations.
* **Emergency Contact**: Enter the name and contact information of an emergency contact person. This ensures we can reach someone if you're unable to proceed with the testing.
* **Test Date**: Choose a date for the testing session. Be aware that this is not the actual testing date.
* **Test Time**: Select a time for the testing session. This helps us schedule the testing accordingly.
* **Tester Name**: Enter your name and any relevant details. This is essential for identifying you as the tester.
* **Test Location**: Select 'Yes' if you'll be performing the testing at the designated site, 'No' otherwise.
* **Test Date**: Enter the actual date of the testing session. This is crucial for scheduling and record-keeping purposes.
* **Test Time**: Select a time for the actual testing session. This helps us keep track of the testing schedule.
* **Test Location**: Select 'Yes' if you'll be performing the testing at the designated site, 'No' otherwise.
* **Tester Name**: Enter your name as the actual tester. This is essential for identification purposes.
