# criminal conviction declaration form - Help Guide
## Purpose
The purpose of this form is to collect information about an individual's criminal history. This form is used to determine if an individual has any criminal convictions that may impact their eligibility for certain programs or services. By completing this form, you will be providing accurate and truthful information about your criminal history.

## How To Complete This Form
To complete this form, please follow these steps:

* Please answer all the questions truthfully and accurately.
* Start by providing application information on page 1.
* On page 2, answer the question about whether you have any criminal convictions.
* If you have any criminal convictions, please provide details on page 3.
* If you have multiple criminal convictions, please provide the count on page 4.
* Finally, provide the date of your criminal conviction(s) on page 5.

## Field-by-Field Explanation

* **Application Information** (`application_info`, text, optional): This is the first page of the form where you will provide general information about yourself and your application. Please fill in your name, address, and any other relevant details.
* **Criminal History** (`criminal_history`, note, optional): On this page, please answer the question "Have you ever been convicted of a crime in the past?"
* **Criminal Convictions** (`criminal_convictions`, select_one, optional): Please select "True" if you have been convicted of a crime, and "False" if you have not.
* **Criminal Convictions Details** (`criminal_convictions_details`, text, optional): If you selected "True" for the previous question, please provide details about your criminal conviction(s) on this page.
* **Criminal Convictions Count** (`criminal_convictions_count`, number, optional): If you have multiple criminal convictions, please count the number of convictions you have.
* **Criminal Conviction Date** (`criminal_conviction_date`, date, optional): If you selected "True" for the previous question, please provide the date of your criminal conviction(s) on this page.

## Tips
* Please be honest and accurate when answering the questions on this form.
* If you are unsure about any of the questions, please ask for clarification.
* If you need help with filling out this form, please ask for assistance.
