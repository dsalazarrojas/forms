# Student Travel Declaration Form - Help Guide

## Purpose
The purpose of this form is to collect information about a student's travel plans and declarations.

## How To Complete This Form
To complete this form accurately, please follow the instructions below.

## Field-by-Field Explanation
* **Has the student traveled?** (student_traveled): This field asks whether or not the student has traveled. Select 'True' if the student has traveled, and 'False' if not.
* **Country of destination** (country_traveled_to): This field asks for the country the student traveled to. Please enter the correct country name.
* **State of destination** (state_traveled_to): This field asks for the state the student traveled to. Please enter the correct state name.
* **Travelled outside state?** (traveled_outside_state): This field asks whether the student traveled outside their state. Select 'Within my state' if the student did not travel outside their state, and 'Outside my state' if they did.
* **Travel Date** (travel_date): This field asks for the date the student traveled. Please enter the date in the correct format (MM/DD/YYYY).
* **Return Date** (return_date): This field asks for the date the student returned. Please enter the date in the correct format (MM/DD/YYYY).
* **Travel Details** (travel_details): This field asks for any additional details about the student's travel. Please provide as much information as possible.
* **Contact Number** (contact_number): This field asks for the student's contact number. Please enter a valid phone number.
* **Contact Email** (email_address): This field asks for the student's contact email. Please enter a valid email address.
* **Student Signature** (student_signature): This field is for the student's signature. Please sign your name as proof of declaration.
* **School Admin Signature** (school_admin_signature): This field is for the school admin's signature. Please sign as proof of declaration.
* **School Admin Comments** (school_admin_comments): This field is for any additional comments from the school admin. Please enter any relevant comments.
* **School Admin Date** (school_admin_date): This field asks for the date the school admin signed the declaration. Please enter the date in the correct format (MM/DD/YYYY).
* **Submitted On** (submitted_on): This field shows the date and time the form was submitted. This is automatically populated.
* **Submitted By** (submitted_by): This field shows who submitted the form, either the student or the school admin. This is automatically populated.

## Tips
- Please complete the form accurately and thoroughly.
- Make sure to sign the student signature and school admin signature fields.
- Enter dates in the correct format (MM/DD/YYYY).
- Enter contact information and travel details accurately.
- Review the form before submission to ensure all fields are complete and accurate.
