# iv_therapy_consent_form - Help Guide
## Purpose
The iv_therapy_consent_form is used to gather patient information, including consent and medical history before IV therapy.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct options for each field.
2. Enter any required information in the text fields.

## Field-by-Field Explanation
* **Patient Information** (`Patient Information`, `select_one`, required/optional): Select the patient's status (Yes or No) regarding their willingness to undergo IV therapy.
* **IV Therapy Consent** (`IV Therapy Consent`, `note`, required/optional): Provide detailed consent for IV therapy. Please provide a clear and concise explanation of your understanding of the treatment and any risks involved.
* **Allergy Information** (`Allergy Information`, `text`, required/optional): If the patient has any known allergies, please list them here.
* **Medical History** (`Medical History`, `text`, required/optional): Provide any relevant medical history that may impact IV therapy, such as previous reactions to medications or medical conditions.
* **Treatment Details** (`prophets_treatment_details`, `date`, required/optional): Please note the expected start and end dates for IV therapy. 
* **IV Medication** (`IV Medication`, `number`, required/optional): If applicable, indicate the expected dose of IV therapy.
* **I Consent** (`I Consent`, `select_multiple`, required/optional): Select all that apply for which you consent to:
	+ Blood products
	+ IV fluids
* **Medical Condition** (`Medical Condition`, `select_one`, required/optional): Select if you have any medical condition (Yes or No).
* **Emergency Contact** (`Emergency Contact`, `text`, required/optional): Provide information about a contact to be notified in case of an emergency. 
Note: All fields are optional unless otherwise specified, and any information that is not filled out will default to the default option or a default value (e.g., "No" for select_one fields, or an empty string for text fields).
