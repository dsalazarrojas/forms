# simple_informed_consent_form - Help Guide
## Purpose
The simple informed consent form is a straightforward document intended to ensure users understand and agree to the terms of a particular process or project. Its primary goal is to gather informed consent from users, ensuring they have all the necessary information to make informed decisions.

## How To Complete This Form
1. **Title**: Enter a brief title for the form, describing the purpose of the form.
2. **Informed Consent Form Template**: Type in a short description of the form, outlining what the user is consenting to.
3. **Category**: Choose a category from the provided options (Option 1, Option 2, Option 3) to best describe the form's purpose. If none of the options match, type in a category description or provide an optional "other" category field.
4. **Other Category (if applicable)**: Enter a detailed description of the custom category you've selected.
5. **Category Example (if applicable)**: Provide a brief example of what the custom category might look like in practice.
6. **Description**: Write a clear and concise description of the form's purpose and the information it collects.
7. **Example**: Enter a brief example of what the form might look like in practice.
8. **Notes**: Use this field for any additional comments or notes related to the form.
