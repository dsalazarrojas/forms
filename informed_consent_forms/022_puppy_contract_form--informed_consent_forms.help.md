# Puppy Contract Form - Help Guide
## Purpose
The "Puppy Contract Form" collects information about a puppy sale transaction, including buyer and seller details, the puppy's medical history, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields (if any).
2. Provide accurate and clear information for all fields.
3. Review each field explanation for specific guidance on what to enter.

## Field-by-Field Explanation
* **Buyer Name** (`buyer_name`, text, optional): Enter the name of the buyer purchasing the puppy.
* **Puppy Name** (`puppy_name`, text, optional): Enter the name of the puppy being sold.
* **Purchase Date** (`purchase_date`, date, optional): Enter the date of the purchase transaction.
* **Price** (`price`, number, optional): Enter the price of the sold puppy.
* **Seller Name** (`seller_name`, text, optional): Enter the name of the seller of the puppy.
* **Contact Number** (`contact_number`, text, optional): Enter the contact number of the seller or buyer for communication.
* **Email** (`email`, email, optional): Enter the email address of the seller or buyer.
* **Veterinary Information** (`veterinary_info`, text, optional): Enter any relevant information about the puppy's veterinary needs or history.
* **Spay Necessary** (`spay_necessary`, select_one, optional):
	+ **Spay Yes**: Indicate if the puppy needs to be spayed.
	+ **Spay No**: Indicate if the puppy does not need to be spayed.
* **Neuter Necessary** (`neuter_necessary`, select_one, optional):
	+ **Neuter Yes**: Indicate if the puppy needs to be neutered.
	+ **Neuter No**: Indicate if the puppy does not need to be neutered.
* **Microchip Important** (`microchip_important`, select_multiple, optional):
	+ **Microchip Yes**: Indicate if microchipping is an important condition for the puppy.
	+ **Microchip No**: Indicate if microchipping is not important.
* **Vaccination Record** (`vaccination_record`, select_multiple, optional):
	+ **Vaccination Records Yes**: Indicate if the puppy has a vaccination record available.
	+ **Vaccination Records No**: Indicate if the puppy does not have a vaccination record.

## Tips

* Please provide accurate and clear information for all fields.
* If a field is marked as optional, it's up to you to decide if it's necessary to fill it in or not.
* If you're unsure about any field, review the explanations provided above for guidance.
