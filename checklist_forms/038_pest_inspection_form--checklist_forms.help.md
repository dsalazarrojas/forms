# Pest Inspection Form - Help Guide

## Purpose
The Pest Inspection Form is a critical tool for inspecting pests and documenting the inspection process. It ensures accurate and comprehensive data collection.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each page carefully, as they are all required.
2. For page 1, "Pest Inspections", simply type in the title of the pest inspection.
3. For page 2, "Treatment Details", type in the details of the treatment.
4. For page 3, "Pest Activity", select all that apply from the options provided.
5. For page 4, "Inspections", select all that apply from the options provided.
6. For page 5, "Treatment Results", type in the results of the treatment.
7. For page 6, "Pest Control Activity", select the activity that was performed.
8. For page 7, "Treatment Activity", select all that apply from the options provided.
9. For page 8, "Notes", type in any additional comments or notes about the inspection.
10. For page 9, "Inspected", select whether the pest inspection was performed.
11. For page 10, "Inspection Date", select the date of the inspection.
12. For page 11, "Inspected By", type in the name of the person who performed the inspection.
13. For page 12, "Inspection Method", type in the method used for the inspection.
14. For page 13, "Additional Comments", type in any additional comments or notes about the inspection.

## Field-by-Field Explanation

* **Pest Inspections** (Page 1, text): Type in the title of the pest inspection.
* **Treatment Details** (Page 2, text): Type in the details of the treatment.
* **Pest Activity** (Page 3, select multiple): Select all that apply from the options provided.
	+ Yes
	+ No
* **Inspections** (Page 4, select multiple): Select all that apply from the options provided.
	+ Yes
	+ No
* **Treatment Results** (Page 5, text): Type in the results of the treatment.
* **Pest Control Activity** (Page 6, select one): Select the activity that was performed.
	+ Spraying
	+ Trapping
* **Treatment Activity** (Page 7, select multiple): Select all that apply from the options provided.
	+ Yes
	+ No
* **Notes** (Page 8, text): Type in any additional comments or notes about the inspection.
* **Inspected** (Page 9, select one): Select whether the pest inspection was performed.
	+ Yes
	+ No
* **Inspection Date** (Page 10, date): Select the date of the inspection.
* **Inspected By** (Page 11, text): Type in the name of the person who performed the inspection.
* **Inspection Method** (Page 12, text): Type in the method used for the inspection.
* **Additional Comments** (Page 13, text): Type in any additional comments or notes about the inspection.

Note: This form is designed to be filled out by users who have completed a pest inspection. Please review each field carefully and answer all questions truthfully and completely.
