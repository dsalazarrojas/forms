# Mobile Inspection Form - Help Guide

## Purpose
This form is designed to gather information about the condition of a vehicle's various systems and components. It is used to identify potential issues and ensure the vehicle meets specific standards or requirements.

## How To Complete This Form
1. Review each page carefully and select the relevant options for each field.
2. Answer each question honestly and thoroughly.
3. Ensure you have checked the vehicle thoroughly before completing this form.

## Field-by-Field Explanation

### General (Page 1)
* General (id: 1, name: general, label: General, type: note, options: null, required: false) 
    This field is a general notes section where you can add any additional comments or observations about the vehicle.

* Vehicle (id: 2, name: vehicle, label: Vehicle, type: select_multiple, options: ['Yes', 'No'], required: true)
    This field is used to indicate if the vehicle is in good or bad condition. Please select all that apply.

### Exterior (Page 2)
* Exterior (id: 3, name: exterior, label: Exterior, type: select_one, options: ['True', 'False'], required: true)
    This field is used to rate the overall condition of the vehicle's exterior. Select True if the vehicle's exterior is in good condition, False otherwise.

* Exterior (id: 4, name: interior, label: Interior, type: select_multiple, options: ['True', 'False'], required: true)
    This field is used to rate the condition of the vehicle's interior. Select True if the interior is in good condition, False otherwise.

### Engine (Page 3)
* Engine (id: 5, name: engine, label: Engine, type: select_one, options: ['Running', 'Not Running'], required: true)
    This field is used to check if the engine is running or not.

* Brakes (id: 6, name: brakes, label: Brakes, type: select_multiple, options: ['Good', 'Bad'], required: true)
    This field is used to rate the condition of the vehicle's brakes. Select Good if the brakes are functioning properly, Bad otherwise.
