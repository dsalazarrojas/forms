# ROV Pre-Launch Checklist - Help Guide
## Purpose
The ROV Pre-Launch Checklist is a critical tool to guarantee a successful product or service launch. It ensures that all crucial steps and tasks are completed before going live, helping teams maintain a high level of quality, reliability, and consistency in their offerings.
## How To Complete This Form
To complete the form, follow these steps:

1. Review the checklist carefully to understand the tasks and milestones associated with the launch.
2. Select the appropriate deployment status (Deployed, Not Deployed, or Not Applicable) for each section.
3. If applicable, enter the deployment date in the correct format (e.g., YYYY-MM-DD).
4. Choose the review status (Completed, In Progress, or Not Completed) for each task.
5. Ensure all required fields are filled out accurately and completely.

## Field-by-Field Explanation
- **Deployment Status** (`deployment_status`, `select_one`, required: false):
  This field determines the current state of the deployment process. Select "ROV Deployed" if the deployment is completed, "Not Deployed" if it's pending, or "Not Applicable" if it does not apply to the current product/service.
- **Deployment Date** (`deployment_date`, `date`, required: false):
  Enter the date the product or service is planned or scheduled for deployment, following the YYYY-MM-DD format.
- **Review Status** (`review_status`, `select_one`, required: false):
  Choose the status of the review process for each task: "Completed", "In Progress", or "Not Completed". This indicates the progress of reviewing and verifying each task.

## Tips
- Make sure to carefully review each field to ensure accurate and complete information.
- If a field is not applicable, select "Not Applicable" to avoid confusion.
- Use the deployment date in the correct format (e.g., YYYY-MM-DD) to ensure proper sorting and searching.
