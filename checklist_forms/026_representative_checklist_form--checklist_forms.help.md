# Representative Checklist Form - Help Guide
## Purpose
The Representative Checklist Form is used to collect information about representatives and their tasks within an organization. This form is designed to gather data from multiple representatives, ensuring each representative's status is up-to-date and accurate.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Representative Checklist tab or section.
2. Enter the Representative Name (ID #3).
3. Enter the Date Completed (ID #2) if applicable.
4. Choose the Status (ID #4) of the representative.
5. Enter the Due Date (ID #5) and Completed On (ID #6) dates if applicable.
6. Enter any Representative Notes (ID #7) regarding the representative's status.
7. Enter the Client Name (ID #8) if applicable.
8. Select the representative to be Assigned To (ID #9) if applicable.
9. Choose the Checklist Type (ID #10) if applicable.
10. Enter the Task Name (ID #11) if applicable.

## Field-by-Field Explanation
- **Representative Name (ID #3)**: Enter the name of the representative you are reporting on.
  - **Type:** text
  - **Required:** false
- **Date Completed (ID #2)**: Enter the date the representative completed their task.
  - **Type:** date
  - **Required:** false
- **Status (ID #4)**: Choose the current status of the representative's task.
  - **Type:** select_one
  - **Options:** Pending, In Progress, Completed, Deferred, Cancelled
  - **Required:** false
- **Due Date (ID #5)**: Enter the date the representative's task is due.
  - **Type:** date
  - **Required:** false
- **Completed On (ID #6)**: Enter the date the representative's task was completed.
  - **Type:** date
  - **Required:** false
- **Representative Notes (ID #7)**: Enter any notes regarding the representative's status.
  - **Type:** note
  - **Required:** false
- **Client Name (ID #8)**: Enter the name of the client associated with the representative's task.
  - **Type:** text
  - **Required:** false
- **Assigned To (ID #9)**: Select the representative the task is assigned to.
  - **Type:** select_one
  - **Options:** John, Jane, Jim
  - **Required:** false
- **Checklist Type (ID #10)**: Choose the type of checklist associated with the representative's task.
  - **Type:** select_one
  - **Options:** Type A, Type B, Type C, Other, N/A
  - **Required:** false
- **Task Name (ID #11)**: Enter a brief description of the representative's task.
  - **Type:** text
  - **Required:** false

## Tips
- Double-check the information entered to ensure accuracy.
- If unsure about the representative's status, refer to the original task description or representative's notes.
- If a representative's status has changed, update the form accordingly to reflect the new status.
