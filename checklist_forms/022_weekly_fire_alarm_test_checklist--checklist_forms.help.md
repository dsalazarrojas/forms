# weekly-fire-alarm-test-checklist - Help Guide
## Purpose
This form is designed to be a checklist for testing the functionality and status of fire alarm systems.

## How To Complete This Form
To complete this form, follow these steps:

1. Begin by filling out the "Page 1" section.
2. Select the correct "Safety Officer" responsible for the test.
3. Enter the "Fire Alarm System" name and description.
4. Select the "Test Schedule" date and time.
5. Choose the "System Components" that need to be tested.
6. Check the condition of each selected "System Component".
7. Enter the test "Test Result" in the notes section.
8. Schedule the next "Maintenance Schedule" date and time.

## Field-by-Field Explanation

* **Page 1 (text)**: Enter a name for this test, for example, "Weekly Fire Alarm Test 2024".
* **Safety Officer (select_one)**: Choose the safety officer responsible for conducting this test from the list provided.
* **Fire Alarm System (text)**: Enter the name and description of the fire alarm system being tested.
* **Test Schedule (date)**: Enter the date and time of this test.
* **System Components (select_multiple)**: Select the components of the fire alarm system that need to be tested.
* **Component Condition (select_one)**: Check the condition of each selected component.
* **Test Result (note)**: Enter the result of the test in the notes section.
* **Maintenance Schedule (date)**: Schedule the next maintenance date and time for the fire alarm system.

## Tips

* Make sure to thoroughly read and understand each field before filling it out.
* Double-check the "Test Schedule" date and time to ensure it aligns with the actual test date and time.
* For "System Components", select all the components that need to be tested.
* For "Component Condition", choose the correct condition for each selected component.
* Use the "Test Result" section to provide any additional comments or notes about the test.
* For "Maintenance Schedule", schedule the next maintenance date and time after the test.
