# vehicle_pre_sale_checklist - Help Guide
## Purpose
The vehicle pre-sale checklist is designed to collect information about a vehicle's condition, history, and specifications before it is sold. This helps to ensure that accurate and fair market value pricing is established.
## How To Complete This Form
To complete this form, please provide the following information about the vehicle:
1. Vehicle Condition: Describe the overall condition of the vehicle, including any existing dings, dents, scratches, or other cosmetic damage.
2. Interior Damage: Indicate if there is any damage to the interior of the vehicle, such as broken glass, torn seats, or stains.
3. Exterior Damage: Describe any exterior damage, including scratches, dents, or other issues.
4. Engine Condition: Specify the engine condition, including any leaks, noises, or other performance issues.
5. Odometer Reading: Enter the current odometer reading of the vehicle.
6. Recent Repairs: List any recent repairs or maintenance performed on the vehicle.
7. Previous Owners: List the previous owners of the vehicle.
8. Purchase Price: Enter the price at which you purchased the vehicle.
9. Sale Date: Enter the date the vehicle will be sold.
10. Sales Price: Enter the price at which the vehicle will be sold.
11. Vehicle Year: Enter the year of manufacture of the vehicle.
12. Make: Enter the make of the vehicle.
13. Model: Enter the model of the vehicle.
14. Vehicle Type: Select the type of vehicle (e.g., sedan, SUV, truck, etc.).
15. Transmission: Select the transmission type (e.g., manual, automatic, etc.).
16. Drive Side: Select the drive side (e.g., left, right, etc.).
17. Engine Size: Enter the engine size (e.g., 2.0L, 3.0L, etc.).
18. Fuel Level: Select the fuel level (e.g., full, half-full, etc.).
19. Drive Type: Select the drive type (e.g., front-wheel, rear-wheel, etc.).
20. Drive Side 2: Select the drive side 2 (e.g., left, right, etc.).
21. Drive Type 2: Select the drive type 2 (e.g., front-wheel, rear-wheel, etc.).
22. Drive Side 3: Select the drive side 3 (e.g., left, right, etc.).
23. Drive Side 4: Select the drive side 4 (e.g., left, right, etc.).
24. Vehicle Color: Enter the color of the vehicle.
25. Vehicle Status: Select the status of the vehicle (e.g., sold, trade-in, etc.).

## Field-by-Field Explanation

*   **Vehicle Type** (`vehicle_type`, text, required): Select the type of vehicle, such as sedan, SUV, truck, etc.
*   **Drive Side** (`drive_side`, text, required): Select the drive side, such as left or right.
*   **Fuel Level** (`fuel_level`, text, required): Select the fuel level, such as full or half-full.
*   **Drive Type** (`drive_type`, text, required): Select the drive type, such as front-wheel or rear-wheel.
*   **Drive Side 2** (`drive_side2`, text, required): Select the drive side 2, such as left or right.
*   **Drive Type 2** (`drive_type2`, text, required): Select the drive type 2, such as front-wheel or rear-wheel.
*   **Drive Side 3** (`drive_side3`, text, required): Select the drive side 3, such as left or right.
*   **Drive Side 4** (`drive_side4`, text, required): Select the drive side 4, such as left or right.

## Tips
- Ensure that all required fields are filled out accurately to avoid any errors in data collection.
- If unsure about any field, please consult the vehicle's documentation or contact the vehicle's previous owners for clarification.
- Double-check the vehicle's condition and specifications to ensure accuracy in the form.
