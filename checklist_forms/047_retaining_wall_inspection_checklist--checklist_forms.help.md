# Retaining Wall Inspection Checklist - Help Guide
## Purpose
The purpose of this form is to conduct a thorough inspection of a retaining wall and gather information about its condition and characteristics.

## How To Complete This Form
- Read each section carefully and answer the questions as accurately as possible.
- Use the provided options for select_one and select_multiple questions.
- Enter numerical values for fields that require numerical answers.
- Use the text fields to provide detailed descriptions or notes.

## Field-by-Field Explanation
- **Wall Condition**: Describe the overall condition of the wall.
  - This field is for you to describe the general state of the wall, including any visible signs of wear or damage.
  - Be as detailed as possible to help identify any potential issues.
- **Wall Structure**: Check the options to indicate if the wall has a specific structure.
  - Select all options that apply to the wall's structure.
  - This will help identify the type of structure the wall has, such as a gravity wall or a reinforced concrete wall.
- **Wall Materials**: Select the options that apply to the materials used to build the wall.
  - This field will help identify the type of materials used, such as concrete, brick, or stone.
- **Wall Height**: Enter the height of the wall in meters.
  - This field is for measuring the height of the wall.
- **Foundation Type**: Check the options to indicate the type of foundation the wall has.
  - Select all options that apply to the foundation type, such as a footing or a slab.
- **Foundation Condition**: Describe the condition of the foundation.
  - This field is for you to describe the state of the foundation, including any signs of wear or damage.
- **Drainage System**: Check the options to indicate if the wall has a drainage system.
  - Select all options that apply to the wall's drainage system, such as a French drain or a sump pump.
- **Wall Height Measured**: Enter the height of the wall measured in meters.
  - This field is for measuring the height of the wall.
- **Wall Condition Rating**: Enter a numerical value between 1-5 to rate the condition of the wall.
  - This field is to rate the condition of the wall, with 1 being poor and 5 being excellent.
- **Foundation Design**: Check the options to indicate if the foundation design meets specific requirements.
  - Select all options that apply to the foundation design, such as if it meets the building code or if it's designed for drainage.
- **Inspector's Note**: Enter any notes or comments about the inspection.
  - This field is for you to provide any additional information or observations about the wall.
- **Inspector's Comment**: Enter any additional comments or observations about the inspection.
  - This field is for providing any additional information or context about the inspection.
- **Inspector's Signature**: Check the options to indicate if the inspector has signed off the wall.
  - Select all options that apply to indicate if the inspector has signed off the wall.
- **Technician's Note**: Enter any notes or comments from the technician.
  - This field is for you to provide any additional information or observations about the wall.
- **Inspector Name**: Enter the name of the inspector.
  - This field is for recording the name of the person conducting the inspection.
- **Inspector Signature**: This field is not applicable.
  - This field is not used in the form.

Note: This help guide is for the "Retaining Wall Inspection Checklist" form and provides an explanation of each field in the form.
