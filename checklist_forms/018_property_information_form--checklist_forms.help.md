# property_information_form - Help Guide
## Purpose
This form is used to capture information about a property.

## How To Complete This Form
1. Ensure that all required fields are filled in. Required fields are marked with an asterisk (*) symbol next to the label.
2. Fill in the Property Title field with the title of the property.
3. Enter the address of the property in the Address field.
4. Select the Property Type in the Property Type field.
5. Provide a brief description of the property in the Property Description field.
6. Enter the Property Size in the Property Size field.
7. Enter the Property Features in the Property Features field. This field is a text area for listing multiple features.
8. Enter the Property Year Built in the Property Year Built field in the format YYYY-MM-DD.
9. Enter the Property Age in the Property Age field.
10. Select the Property Price Range in the Property Price Range field.
11. Enter the Property Lot Size in the Property Lot Size field.
12. Select the Property Status in the Property Status field.
13. Enter the Property Owner in the Property Owner field.
14. Enter the Property Agent in the Property Agent field.
15. Enter the Property Manager in the Property Manager field.
16. Enter the Property Location in the Property Location field.
17. Enter the Property Image in the Property Image field.
18. Enter the Property Video in the Property Video field.
19. Enter the Property Notes in the Property Notes field. This field is a text area for listing multiple notes.
20. Select whether Property Documents are available or not.
21. Select the Property Amenities provided or not.
22. Enter the Property Viewport in the Property Viewport field.
23. Enter the Property Views in the Property Views field.

## Field-by-Field Explanation
* **Property Title** (`property_title`, text, optional): Enter the title of the property.
* **Address** (`address`, text, required): Enter the address of the property.
* **City** (`city`, text, optional): Enter the city of the property.
* **State** (`state`, text, optional): Enter the state of the property.
* **Zip** (`zip`, text, required): Enter the zip code of the property.
* **Property Type** (`property_type`, select_one, required): Select the type of property.
* **Property Description** (`property_description`, text, optional): Enter a brief description of the property.
* **Property Size** (`property_size`, text, optional): Enter the size of the property.
* **Property Features** (`property_features`, note, required): List the features of the property.
* **Property Year Built** (`property_year_built`, date, optional): Enter the year the property was built in the format YYYY-MM-DD.
* **Property Age** (`property_age`, text, optional): Enter the age of the property.
* **Property Price Range** (`property_price_range`, number, optional): Enter the price range of the property.
* **Property Lot Size** (`property_lot_size`, text, optional): Enter the lot size of the property.
* **Property Status** (`property_status`, select_one, required): Select the status of the property.
* **Property Owner** (`property_owner`, text, optional): Enter the property owner.
* **Property Agent** (`property_agent`, text, optional): Enter the property agent.
* **Property Manager** (`property_manager`, text, optional): Enter the property manager.
* **Property Location** (`property_location`, text, optional): Enter the property location.
* **Property Image** (`property_image`, text, optional): Enter the property image.
* **Property Video** (`property_video`, text, optional): Enter the property video.
* **Property Notes** (`property_notes`, note, optional): List the notes for the property.
* **Property Documents** (`property_documents`, select_multiple, optional): Select whether property documents are available or not.
* **Property Amenities** (`property_amenities`, select_multiple, optional): Select the property amenities provided or not.
* **Property Viewport** (`property_viewport`, time, optional): Enter the view port of the property.
* **Property Views** (`property_views`, text, optional): Enter the views of the property.
