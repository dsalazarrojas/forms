# Pod Start Checklist - Help Guide
## Purpose
The Pod Start Checklist is a form used to track and report on the progress of a project's start-up process. It ensures that all necessary steps are taken before the project's launch.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you are filling out this form for a new project.
2. Select the project launch team members involved in the project.
3. Enter the project launch date and time.
4. Specify the project launch location.
5. Enter the project launch budget.
6. List the items to be checked on the project start-up checklist.
7. Select the status of the project's start-up process from the available options.

## Field-by-Field Explanation

### Project Launch Team
* **Project Launch Team** (optional): Select the team members involved in the project.
	+ This field allows you to specify who is part of the project's launch team. Select as many team members as are relevant to the project.
### Project Launch Date
* **Project Launch Date** (optional): Enter the date the project will launch.
	+ This field is used to record the date when the project will start. Use the standard date format (DD/MM/YYYY).
### Project Launch Time
* **Project Launch Time** (optional): Enter the time the project will launch.
	+ This field is used to record the time of the project's launch. Use the 24-hour clock format (HH:MM).
### Project Launch Location
* **Project Launch Location** (optional): Enter the location where the project will launch.
	+ This field is used to record the location where the project will take place. Enter the full address or a brief description.
### Project Launch Budget
* **Project Launch Budget** (optional): Enter the budget allocated for the project launch.
	+ This field is used to record the budget allocated for the project's start-up process. Enter a numerical value.
### Pod Start Checklist Items
* **Pod Start Checklist Items** (optional): List the items to be checked on the project start-up checklist.
	+ This field is used to specify the tasks or activities to be performed before the project's launch. Enter as many items as are relevant to the project.
### Pod Start Checklist Status
* **Pod Start Checklist Status** (optional): Select the status of the project's start-up process.
	+ This field is used to report the current status of the project's start-up process. Select from the available options: Not Started, In Progress, or Completed.
