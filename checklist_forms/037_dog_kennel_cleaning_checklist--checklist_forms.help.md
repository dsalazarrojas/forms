# dog_kennel_cleaning_checklist - Help Guide
## Purpose
This form is used to track and manage cleaning tasks for the dog kennel. It helps organize and keep track of various cleaning activities, including checks, cleaning, disinfection, and follow-up tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Check the status of the dog kennel.
2. Determine if any runs need to be cleaned.
3. Decide if all surfaces need to be disinfected.
4. Schedule the next cleaning activity.
5. List the cleaning products used.
6. Add any notes about the task.
7. Enter the dog's name.
8. Provide contact information.
9. Identify the person assigned to the task.
10. Determine if the follow-up task is completed.

## Field-by-Field Explanation

* **Check Dog Kennel** (`check_dog_kennel`, select_multiple, required): Check the dog kennel for cleanliness.
* **Clean Runs** (`clean_runs`, select_one, required): Determine if any runs need to be cleaned.

## Tips
* Always check the dog kennel and schedule cleaning activities before proceeding.
* Ensure that follow-up tasks are properly managed and completed.
* Review and update this form regularly to maintain accurate records.
