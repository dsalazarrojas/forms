# Sunday Service Altar Checklist - Help Guide

## Purpose

This guide will walk you through the Sunday Service Altar Checklist form, explaining each field and its intended use.

## How To Complete This Form

1. To begin, select the fields that apply to your service from the options provided. For the most accurate results, fill in the fields with your preferred selections.
2. Review each field carefully to ensure you are using the correct selections for your service.
3. If you need to add any additional notes or comments, use the "additional_notes" field.
4. Finally, submit the form to save your selections and generate a report or summary of your service.

## Field-by-Field Explanation

* **Sunday Service Altar Checklist** (`title`, text, required: false): This is the main title of the form, which you cannot edit.
* **Sacraments** (`sacraments`, text, required: false): Select the sacraments that will be used during the service. This field is intended for listing the sacraments that will be used.
* **Hymns** (`hymns`, select_multiple, required: false): Choose a few hymns for the service by selecting multiple options from the list.
	+ Select a few hymns for the service. This field allows you to choose multiple hymns.
* **Opening Scripture** (`opening_scripture`, select_one, required: false): Select a scripture to be used for the opening prayer or reading.
	+ Select a scripture from the options provided. This field is intended for selecting a single scripture.
* **Sermon** (`sermon`, select_one, required: false): Select a sermon or talk for the service.
	+ Choose a sermon or talk from the options provided. This field is intended for selecting a single sermon.
* **Closing Scripture** (`closing_scripture`, select_one, required: false): Select a scripture for the closing prayer or reading.
	+ Select a scripture from the options provided. This field is intended for selecting a single scripture.
* **Closing Hymn** (`closing_hymn`, select_one, required: false): Select a closing hymn.
	+ Choose a closing hymn from the options provided. This field is intended for selecting a single closing hymn.
* **Altar Arrangements** (`altar_arrangements`, select_multiple, required: false): Specify the arrangements for the altar.
	+ Select "Yes" or "No" to indicate whether the altar arrangements will be used.
* **Altar Decorations** (`altar_decorations`, select_multiple, required: false): Specify the altar decorations.
	+ Select "Yes" or "No" to indicate whether the altar decorations will be used.
* **Additional Notes** (`additional_notes`, note, required: false): If needed, add any additional notes or comments.
* **Date** (`date`, date, required: false): Select the date of the service.
* **Time** (`time`, time, required: false): Select the time of the service.

## Tips

* Review the form carefully before submitting to ensure all necessary fields are filled out.
* Use the form to plan and prepare for your Sunday service.
* Use the selected fields to create a smooth and well-structured service.
