# Conference Planning Checklist - Help Guide
## Purpose
This guide will walk you through the Conference Planning Checklist, a tool designed to help conference planners manage and track the various tasks involved in planning a conference.

## How To Complete This Form
To complete this form, simply go through each section and answer the questions accordingly. For each task, select the status that best describes your progress.

## Field-by-Field Explanation
* **Conference Name** (`conference_name`): Enter the name of the conference you are planning.
* **Conference Date** (`conference_date`): Select the date of the conference.
* **Planner Name** (`planner_name`): Enter your name as the conference planner.
* **Planner Email** (`planner_email`): Enter your email address for contact purposes.
* **Initial Planning** (`initial_planning`): This is the early stage of planning where you identify the conference objectives and set the overall plan.
* **Define Conference Objectives** (`define_objectives`): Select the status of defining the conference objectives.
* **Set Budget** (`set_budget`): Select the status of setting the conference budget.
* **Select Conference Dates** (`select_dates`): Select the status of selecting the conference dates.
* **Form Planning Committee** (`form_committee`): Select the status of forming the planning committee.
* **Venue Tasks** (`venue_tasks`): This is a note field for any specific venue-related tasks or issues.
* **Research Potential Venues** (`research_venues`): Select the status of researching potential venues.
* **Visit and Evaluate Venues** (`venue_visit`): Select the status of visiting and evaluating potential venues.
* **Book and Contract Venue** (`book_venue`): Select the status of booking and contracting a venue.
* **Program Tasks** (`program_tasks`): This is a note field for any specific program-related tasks or issues.
* **Identify Potential Speakers** (`identify_speakers`): Select the status of identifying potential speakers.
* **Send Speaker Invitations** (`invite_speakers`): Select the status of sending speaker invitations.
* **Confirm Speaker Participation** (`confirm_speakers`): Select the status of confirming speaker participation.
* **Develop Conference Agenda** (`develop_agenda`): Select the status of developing the conference agenda.
* **Marketing Tasks** (`marketing_tasks`): This is a note field for any specific marketing-related tasks or issues.
* **Create Conference Website** (`create_website`): Select the status of creating a conference website.
* **Design Marketing Materials** (`design_materials`): Select the status of designing marketing materials.
* **Launch Registration System** (`launch_registration`): Select the status of launching the registration system.
* **Begin Social Media Campaign** (`social_media`): Select the status of starting a social media campaign.
* **Logistics Tasks** (`logistics_tasks`): This is a note field for any specific logistics-related tasks or issues.
* **Arrange Catering** (`arrange_catering`): Select the status of arranging catering.
* **Arrange Audio-Visual Equipment** (`arrange_av`): Select the status of arranging audio-visual equipment.
* **Plan Transportation** (`plan_transport`): Select the status of planning transportation.
* **Book Room Blocks** (`book_accommodation`): Select the status of booking room blocks.
* **Final Tasks** (`final_tasks`): This is a note field for any last-minute tasks or issues.
* **Print Conference Materials** (`print_materials`): Select the status of printing conference materials.
* **Confirm All Vendors** (`confirm_vendors`): Select the status of confirming all vendor arrangements.
* **Brief Staff and Volunteers** (`brief_staff`): Select the status of briefing staff and volunteers.
* **Overall Progress** (`overall_progress`): Select the general status of the conference planning progress.
* **Additional Notes** (`additional_notes`): Enter any additional notes or information about the conference planning process.
This guide assumes that the user has basic knowledge of HTML and Markdown formatting. If you need help with anything else, don't hesitate to reach out.
