## Medical Exam Room Supply Checklist - Help Guide
## Purpose
The Medical Exam Room Supply Checklist is a tool used to verify the availability of essential supplies in an exam room. This form helps in maintaining a clean and well-stocked room, ensuring patient comfort and safety.

## How To Complete This Form
To complete the form, follow these steps:

1. Review the room's supplies, including trash cans, soap dispensers, paper towels, toilet paper, air conditioners, thermostats, and other essential items.
2. Answer each question based on your observation of the room. Check the corresponding box to indicate if the item is present or not.
3. Fill out the form carefully, using the following pages as reference:

### Exam Room Supply Checklist

#### 1. Room Number
 * **Room Number** (`room_number`, text, optional): Enter the room number where the exam took place.

#### 2. Bed Number
 * **Bed Number** (`bed_number`, text, optional): Enter the bed number used during the exam.

#### 3. Exam Table Number
 * **Exam Table Number** (`exam_table_number`, text, optional): Enter the exam table number used during the exam.

#### 4. Trash Can Contents
 * **Trash Can Contents** (`trash_can_contents`, text, optional): Describe the contents of the trash can (e.g., biohazard waste, recyclables, or regular trash).

#### 5. Soap Dispenser
 * **Soap Dispenser** (`soap_dispenser`, text, optional): Check the soap dispenser to see if it is working properly or if there are any issues.

#### 6. Paper Towels
 * **Paper Towels** (`paper_towels`, text, optional): Check if the paper towel supply is adequate and accessible.

#### 7. Toilet Paper
 * **Toilet Paper** (`toilet_paper`, text, optional): Check if toilet paper is readily available and sufficient for the exam.

#### 8. Air Conditioner
 * **Air Conditioner** (`air_conditioner`, text, optional): Check if the air conditioner is working properly.

#### 9. Thermostat
 * **Thermostat** (`thermostat_set`, text, optional): Check if the thermostat is set to an appropriate temperature for the exam.

#### 10. Trash Can Lid
 * **Trash Can Lid** (`trash_can_lid`, text, optional): Check if the trash can lid is securely closed or if there are any issues.

#### 11. Exam Table
 * **Exam Table** (`exam_table`, text, optional): Check if the exam table is clean and in good condition.

#### 12. Blood Pressure Monitor
 * **Blood Pressure Monitor** (`blood_pressure_monitor`, text, optional): Check if the blood pressure monitor is available and working properly.

#### 13. Stethoscope
 * **Stethoscope** (`stethoscope`, text, optional): Check if the stethoscope is available and clean.

#### 14. OtoScope
 * **Otoscope** (`otoscope`, text, optional): Check if the otoscope is available and in good condition.

#### 15. OtoScope Light
 * **Otoscope Light** (`otoscope_light`, text, optional): Check if the otoscope light is working properly.

#### 16. Blood Pressure Dresser
 * **Blood Pressure Dresser** (`blood_pressure_dresser`, text, optional): Check if the blood pressure dressor is available and in good condition.

#### 17. Blood Pressure Dresser Bottle
 * **Blood Pressure Dresser Bottle** (`blood_pressure_dresser_bottle`, text, optional): Check if the blood pressure dressor bottle is full or empty.

#### 18. Sharps Container
 * **Sharps Container** (`sharps_container`, text, optional): Check if the sharps container is available and in good condition.

#### 19. Sharps Recyclable
 * **Sharps Recyclable** (`sharps_recyclable`, text, optional): Check if sharps are recyclable.

#### 20. Sharps Disposable
 * **Sharps Disposable** (`sharps_disposable`, text, optional): Check if sharps are disposable.

#### 21. Sharps Reusable
 * **Sharps Reusable** (`sharps_reusable`, text, optional): Check if sharps are reusable.

#### 22. Sharps Container Type
 * **Sharps Container Type** (`sharps_container_type`, text, optional): Check if the sharps container type is correct for the exam.

#### 23. Sharps Container Location
 * **Sharps Container Location** (`sharps_container_location`, text, optional): Check if the sharps container location is correct.

#### 24. Sharps Container Empty
 * **Sharps Container Empty** (`sharps_container_empty`, select_one, optional): Check if the sharps container is full, half empty, or empty.

#### 25. Blood Pressure Dresser Empty
 * **Blood Pressure Dresser Empty** (`blood_pressure_dresser_empty`, select_one, optional): Check if the blood pressure dressor is full, half empty, or empty.

### Room Information

#### 1. Room Number
 * **Room Number** (`room_number`, text, optional): Enter the room number where the exam took place.

#### 2. Exam Table
 * **Exam Table** (`exam_table`, text, optional): Check if the exam table is clean and in good condition.

#### 3. Sharps Container
 * **Sharps Container** (`sharps_container`, text, optional): Check if the sharps container is available and in good condition.
