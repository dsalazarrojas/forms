# Forensic Examination Checklist - Help Guide
## Purpose
The Forensic Examination Checklist is used to collect and document information about a case that is being investigated or examined. This form should be filled out by the examiner or investigator who is conducting the examination.

## How To Complete This Form
1. Review the case details and ensure the case is not already documented in the system.
2. Fill out the case details section, providing information about the case number, type, status, and assignee.
3. Select the type of evidence being examined.
4. Provide a description of the evidence being examined.
5. Enter the location of the examination.
6. Enter the examiner's name and email.
7. Enter the examination date and time.
8. Choose the examination status.
9. Enter any relevant notes about the examination.
10. Select the case priority and category.
11. Enter any additional case tags.
12. Select the case type and status.
13. Enter the examiner's name (if not already entered).
14. Select the examination result.
15. Enter any examination notes.
16. Enter case notes.
17. Enter examination date and time for multiple examinations (if applicable).

## Field-by-Field Explanation

* **Case Details**: Enter the unique case number and any other relevant case details. 
* **Evidence Type**: Select the type of evidence being examined (e.g., "DNA", "Fingerprint", "Footprint", etc.). 
* **Evidence Description**: Provide a brief description of the evidence being examined. 
* **Location**: Enter the location where the examination took place. 
* **Examiner**: Enter the name and email of the person conducting the examination. 
* **Examination Date**: Enter the date of the examination. 
* **Examination Time**: Enter the time of the examination. 
* **Examination Status**: Select the status of the examination (e.g., "Completed", "Pending", "Deferred", etc.). 
* **Notes**: Enter any notes or comments about the examination. 
* **Case Number**: Enter the unique case number. 
* **Case Type**: Select the type of case (e.g., "Homicide", "Arson", "Robbery", etc.). 
* **Case Status**: Select the status of the case (e.g., "Active", "Closed", "In Progress", etc.). 
* **Examiner Name**: Enter the name of the examiner. 
* **Examination Result**: Select the result of the examination (e.g., "Positive", "Negative", "Inconclusive", etc.). 
* **Examination Notes**: Enter any notes or comments about the examination. 
* **Case Notes**: Enter any notes or comments about the case. 
* **Case Priority**: Select the priority of the case. 
* **Case Category**: Select the category of the case. 
* **Case Tags**: Enter any additional tags or keywords for the case. 
* **Case Assignee**: Enter the email of the person assigned to the case. 
* **Examination Date 1**: Enter the date of the first examination. 
* **Examination Time 1**: Enter the time of the first examination. 
* **Examination Date 2**: Enter the date of the second examination. 
* **Examination Time 2**: Enter the time of the second examination. 
* **Notes 1**: Enter any notes or comments about the first examination. 

Please note that each field is optional, but please ensure to fill out all relevant fields to ensure accurate and complete documentation.
