# Daily Kitchen Prep Checklist - Help Guide
## Purpose
This form is a daily checklist for kitchen management, covering various tasks, routines, and activities to keep your kitchen organized and efficient.
## How To Complete This Form
To complete this form, follow these steps:
1. Review each section and select 'Yes' or 'No' for each task or activity.
2. Add any notes or comments in the 'Notes' field if needed.
3. Make sure to review and adjust your selections according to your specific kitchen needs.
## Field-by-Field Explanation

* **Morning Routine** (Morning Routine, note, Required): This section is for checking off morning tasks and routines that need to be done daily, such as making coffee or tea.
* **Breakfast Cooking** (Breakfast Cooking, select_one, Optional): Select 'Yes' if you are cooking breakfast, 'No' otherwise.
* **Lunch Preparations** (Lunch Preparations, select_multiple, Optional): Select all 'Yes' if you are preparing lunch, or 'No' otherwise.
* **Snack Time** (Snack Time, select_one, Optional): Select 'Yes' if you are having a snack, 'No' otherwise.
* **Dinner Planning** (Dinner Planning, note, Optional): This is for notes and reminders about dinner planning and preparation.
* **Cooking Supplies** (Cooking Supplies, select_multiple, Optional): Select all 'Yes' if you need to restock or order supplies.
* **Kitchen Cleaning** (Kitchen Cleaning, select_one, Optional): Select 'Yes' if you are doing kitchen cleaning, 'No' otherwise.
* **Trash Disposal** (Trash Disposal, select_multiple, Optional): Select all 'Yes' if you need to dispose of trash.
* **Notes** (Notes, note, Optional): Add any additional notes or comments about your kitchen activities.
* **Kitchen Equipment** (Kitchen Equipment, select_one, Optional): Select 'Yes' if your kitchen equipment is active, 'No' otherwise.
* **Kitchen Tasks** (Kitchen Tasks, select_multiple, Optional): Select all 'Yes' if you have tasks to complete in the kitchen.
