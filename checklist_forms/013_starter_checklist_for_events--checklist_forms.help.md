# Starter Checklist For Events - Help Guide
## Purpose
This form is used to collect details about events, including their title, date, location, and other relevant information. It's a starting point for planning and organizing events.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the **Event Title**: This is the name of the event. It should be a brief and descriptive title that captures the essence of the event.
2. Select a **Date**: Choose the date when the event is scheduled to take place. Make sure to select the correct date in the correct format (DD/MM/YYYY).
3. Choose the **Time**: Select the time when the event is expected to start and end. Be specific and accurate.
4. Enter the **Location**: Provide the address or venue where the event will be held.
5. Write a brief **Event Description**: This should be a concise description of the event, including any essential details.
6. Determine if the event has **Tasks**: Select whether tasks are associated with the event or not.
7. Specify **Deadlines**: If applicable, provide the deadlines for tasks or milestones related to the event.
8. List **Attendees**: Select whether attendees are required or not for the event.
9. Add **Notes**: Provide any additional information or details about the event.
10. Set up **Reminders**: Choose whether reminders are needed for the event.
11. Assign a **Tool**: Enter the tool or resource assigned to manage the event.
12. Identify the **Category**: Choose the category or type of event (e.g., meeting, conference, training).
13. Specify the **Output File**: If applicable, provide the output file related to the event.
14. Assign a **Tool Name**: If applicable, enter the tool name (this field is optional).
15. Specify the **Event Type**: Choose the type of event (e.g., online, offline, recurring).

## Field-by-Field Explanation

* **Event Title**: A brief and descriptive title for the event. (required)
* **Date**: The date when the event is scheduled to take place. (required)
* **Time**: The time when the event is expected to start and end. (required)
* **Location**: The address or venue where the event will be held. (optional)
* **Event Description**: A brief description of the event, including essential details. (optional)
* **Tasks**: Whether tasks are associated with the event or not. (optional)
* **Deadlines**: Deadlines for tasks or milestones related to the event. (optional)
* **Attendees**: Whether attendees are required or not for the event. (optional)
* **Notes**: Additional information or details about the event. (optional)
* **Reminders**: Whether reminders are needed for the event. (optional)
* **Assigned Tool**: The tool or resource assigned to manage the event. (optional)
* **Category**: The category or type of event (e.g., meeting, conference, training). (optional)
* **Output File**: If applicable, provide the output file related to the event. (optional)
* **Assigned Tool Name**: The tool name (this field is optional). 
* **Event Type**: The type of event (e.g., online, offline, recurring). (optional)

This help guide should provide a clear understanding of each field's purpose and requirements, helping you complete the form accurately and efficiently.
