# Agent Communication Protocol Compliance Checklist - Help Guide
## Purpose
The Agent Communication Protocol Compliance Checklist is used to evaluate an agent's adherence to standard operating procedures during a call or chat interaction. This form assesses the agent's performance in several key areas, including using a mandatory greeting, mentioning the client's name, demonstrating active listening, providing accurate information, using professional language, and closing the interaction effectively.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the interaction recording or transcript to answer the questions on this form.
2. Answer each question based on your evaluation of the agent's performance during the interaction.
3. For select_one questions, choose one of the provided options that best describe your evaluation of the agent's performance.
4. Enter any coaching notes in the text box for areas where the agent needs improvement.

## Field-by-Field Explanation

* **Evaluator Name** (`evaluator_name`): This is the name of the person evaluating the agent's performance.
* **Agent Name** (`agent_name`): This is the name of the agent being evaluated.
* **Date of Evaluation** (`eval_date`): This is the date the interaction was evaluated.
* **Interaction ID - Call or Chat** (`interaction_id`): This is a reference to the recorded session being evaluated.
* **Greeting Check** (`greeting_check`): Check if the agent used the mandatory greeting, including their name and company identity.
* **Client Name Check** (`client_name_check`): Check if the agent mentioned the client's name during the interaction.
* **Listening Check** (`listening_check`): Check if the agent demonstrated active listening by summarizing and acknowledging the client's points.
* **Accuracy Check** (`accuracy_check`): Check if the agent provided accurate and complete information.
* **Language Check** (`language_check`): Check if the agent used professional and polite language, avoiding jargon or slang.
* **Closing Check** (`closing_check`): Check if the agent used the mandatory closing to offer further assistance.
* **Overall Protocol Score** (`overall_score`): Select the final assessment of the agent's performance, based on the evaluation.
* **Coaching Notes** (`coaching_notes`): Enter any specific coaching notes for areas where the agent needs improvement.
