# Pool Excavation Safety Checklist - Help Guide
## Purpose
The Pool Excavation Safety Checklist is a tool used to ensure safe pool excavation practices by monitoring the presence of confined spaces, hazards, and the condition of equipment. It helps in identifying potential risks and take necessary precautions to prevent accidents.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Review each question carefully and answer them based on the actual situation during the excavation process.
2. For each question, select the most accurate answer from the options provided.
3. Describe any hazards or risks identified in the text fields.
4. If the site has been cleared, select 'Yes' for the corresponding question.

## Field-by-Field Explanation

* **Is there a confined space present** (`pool_excavation_safety_checklist_page_1`, select_one, not required): This question helps in identifying if there are any confined spaces present during the excavation process. A confined space is an area that can trap or restrict the movement of people or equipment.
* **excavation_equipment_procedure** (`excavation_equipment_procedure`, text, not required): Describe any pre-operational checks performed on the equipment before starting the excavation process. This includes checks on the condition of the equipment, lubrication, and other maintenance activities.
* **hazards_present** (`hazards_present`, text, not required): Identify any hazards present during the excavation process. This includes hazards such as uneven terrain, slippery surfaces, or other obstacles that can cause accidents.
* **Confined spaces** (`confined_spaces`, select_one, not required): This question helps in identifying if the excavation process is taking place in a confined space or not.
* **personal_protection_equipment** (`personal_protection_equipment`, select_multiple, not required): Check if personnel on site are wearing personal protective equipment such as helmets, hard hats, vests, etc. This helps in preventing head injuries and other accidents.
* **excavation_equipment_operating_condition** (`excavation_equipment_operating_condition`, text, not required): Describe the operating condition of the equipment being used during the excavation process. This includes information about any malfunctions or issues with the equipment.
* **hazards_control_measures** (`hazards_control_measures`, text, not required): List any control measures taken for the identified hazards during the excavation process.
* **site_clearance** (`site_clearance`, select_one, not required): This question helps in identifying if the site has been cleared after the excavation process. If the site is clear, select 'Yes'. Otherwise, select 'No'.

## Tips
- Review each question carefully and answer them based on the actual situation.
- Take necessary precautions to prevent accidents if any hazards are identified.
- Regularly update this form after each excavation process to track and document any changes in the safety conditions.
