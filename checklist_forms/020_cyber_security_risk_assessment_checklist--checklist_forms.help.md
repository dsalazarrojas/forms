# Cyber Security Risk Assessment Checklist - Help Guide
## Purpose

The Cyber Security Risk Assessment Checklist is a form used to identify potential security risks and threats within an organization. It helps to assess and mitigate risks to ensure the security and integrity of assets.

## How To Complete This Form

To complete this form, follow these steps:

1. Click on each page to progress through the form.
2. Review each field carefully and provide accurate information.
3. Use the provided options for select multiple and select one fields.

## Field-by-Field Explanation

* **Risk Assessment** (`risk_assessment`, note, required: false):
	+ This field provides a space for users to note any risk assessments or comments.
* **Threat Modeling** (`threat_modeling`, text, required: false):
	+ This field allows users to describe the potential threats to their assets.
* **Risk Factors** (`risk_factors`, select multiple, required: false):
	+ This field provides a list of yes/no options to identify if the risk factors are present.
* **Risk** (`risk`, number, required: false):
	+ This field is used to input the level of risk.
* **Asset Identification** (`asset_identification`, select one, required: false):
	+ This field asks whether the asset is identified.
* **Vulnerability Assessment** (`vulnerability_assessment`, date, required: false):
	+ This field is used to input the date of the last vulnerability assessment.
* **Threat Risk Matrix** (`threat_risk_matrix`, select multiple, required: false):
	+ This field provides a list of yes/no options to identify the threat risk matrix.
* **Risk Rating** (`risk_rating`, select one, required: false):
	+ This field asks for the risk rating (Good/Fair).
* **Remediation** (`remediation`, note, required: false):
	+ This field provides a space for users to note any remediation actions.
* **Risk Summary** (`risk_summary`, note, required: false):
	+ This field provides a space for users to provide a summary of the risks.
 

## Tips

* Please provide accurate and clear information for each field.
* Use the provided options for select multiple and select one fields.
* If you are unsure about any field, please consult with your supervisor or team lead.
