# Buyer Sales Checklist - Help Guide
## Purpose
This form is designed to track the progress of a home sale, providing a structured and organized way to capture key milestones and tasks related to the transaction.

## How To Complete This Form
To complete this form, simply navigate through the pages and fill in the required information for each field. Each page corresponds to a specific stage of the home sale process. 

## Field-by-Field Explanation

### Page 1: Sale or Transaction Date
* **Sale or Transaction Date** (`sale_date`, `date`, required): Enter the date of the sale or transaction.

### Page 2: Sales Agent Name
* **Sales Agent Name** (`agent_name`, `text`, required): Enter the name of the sales agent managing this sale.

### Page 3: Buyer Information
* **Buyer Name** (`buyer_name`, `text`, required): Enter the full name of the buyer.
* **Buyer Contact Information** (`buyer_contact`, `text`, required): Enter the buyer's phone number and email.

### Page 4: Property Details
* **Property Address** (`property_address`, `text`, required): Enter the subject property address.

### Page 5: Sale Details
* **Purchase Price** (`purchase_price`, `number`, required): Enter the agreed sale price.
* **Earnest Money Received** (`earnest_money_received`, `select_one`, required): Select whether earnest money has been received.
* **Earnest Money Amount** (`earnest_money_amount`, `number`, optional): Enter the amount of earnest money if applicable.
* **Home Inspection Scheduled** (`inspection_scheduled`, `select_one`, required): Select the status of the home inspection.
* **Home Inspection Date** (`inspection_date`, `date`, optional): If applicable, enter the date of the home inspection.
* **Inspection Scheduling Status** (`inspection_scheduled`, `select_one`, required): Select the status of the home inspection scheduling.

### Page 6: Additional Documents
* **Appraisal Ordered** (`appraisal_ordered`, `select_one`, required): Select the status of the appraisal order.
* **Appraisal Value** (`appraisal_value`, `number`, optional): If applicable, enter the appraisal value.
* **Title Search Ordered** (`title_search_ordered`, `select_one`, required): Select the status of the title search order.
* **Financing Application** (`financing_application`, `select_one`, required): Select the status of the financing application.
* **Loan Approval Status** (`loan_approval_status`, `select_one`, optional): If applicable, select the loan approval status.
* **Homeowners Insurance Quote** (`homeowners_insurance`, `select_one`, required): Select the status of the homeowners insurance quote.

### Page 7: Final Steps
* **HOA Documents Reviewed** (`hoa_documents`, `select_one`, required): Select the status of HOA documents if applicable.
* **Final Walkthrough Scheduled** (`final_walkthrough`, `select_one`, required): Select the status of the final walkthrough.
* **Closing Date Scheduled** (`closing_scheduled`, `date`, optional): If applicable, enter the date of the closing.
* **All Items Complete** (`all_items_complete`, `select_one`, required): Select the overall status of the transaction.
