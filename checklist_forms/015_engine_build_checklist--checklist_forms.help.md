# engine_build_checklist - Help Guide
## Purpose
The engine build checklist is used to ensure that all necessary checks and inspections are performed on an engine before it is considered safe and ready for use. This is crucial for both quality control and safety purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each field carefully and select the correct options for the specific checks and inspections performed on your engine.
2. For fields with multiple options, select all applicable options that apply to your engine.
3. Enter any additional comments or information that may be relevant to the specific checks and inspections performed.

## Field-by-Field Explanation

* **oil_pump** (oil_pump, select_one, required: false): Select the type of oil pump used in your engine.
	+ Options: oil pump, electric pump
* **oil_leak_test** (oil_leak_test, select_multiple, required: false): Check the oil leak test results for your engine.
	+ Options: True, False
* **coolant_leak_test** (coolant_leak_test, select_multiple, required: false): Check the coolants leak test results for your engine.
	+ Options: True, False
* **engine_mounts** (engine_mounts, text, required: false): Enter any additional information about the engine mounts.
* **fuel_system_check** (fuel_system_check, select_one, required: false): Check the status of the fuel system.
	+ Options: True, False

	+ Options: True, False
* **engine_block** (engine_block, select_multiple, required: false): Check the status of the engine block.
	+ Options: True, False
* **engine_block_location** (engine_block_location, text, required: false): Enter the location of the engine block.
* **engine_cylinder_head** (engine_cylinder_head, text, required: false): Enter any additional information about the engine cylinder head.
