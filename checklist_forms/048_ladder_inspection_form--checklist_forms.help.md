# Ladder Inspection Form - Help Guide

## Purpose
The Ladder Inspection Form is used to document the inspection of ladders in a workplace or facility. This form helps ensure that ladders are in good condition and meet safety standards.

## How To Complete This Form
1. Review the form carefully to understand the purpose and required fields.
2. Complete the form in a step-by-step manner, following the pages and fields as presented.
3. Be sure to select the correct ladder type and height, and accurately report any issues or concerns.
4. Use the user notes field to provide additional context or comments about the inspection.
5. Review and submit the completed form for record-keeping and reference.

## Field-by-Field Explanation
* **Ladder Type** (`ladder_type`, select_one, required: false):
	+ Select the correct type of ladder being inspected (e.g., Ladder A, Ladder B, Ladder C).
	+ This field helps identify the specific type of ladder being inspected.
* **Ladder Height** (`ladder_height`, number, required: false):
	+ Enter the height of the ladder in inches or meters.
	+ This field is used to report the actual height of the ladder.
* **Ladder Width** (`ladder_width`, number, required: false):
	+ Enter the width of the ladder in inches or meters.
	+ This field is used to report the actual width of the ladder.
* **Ladder Material** (`ladder_material`, select_multiple, required: false):
	+ Select the material used to make the ladder (e.g., Metal, Wood, Plastic).
	+ This field helps identify the material composition of the ladder.
* **Ladder Angle** (`ladder_angle`, number, required: false):
	+ Enter the angle of the ladder in degrees.
	+ This field is used to report the actual angle of the ladder.
* **User Notes** (`user_notes`, note, required: false):
	+ Provide any additional comments or notes about the inspection.
	+ This field is used to document any specific observations or issues with the ladder.
* **First Page 2** (`first_page_2`, note, required: false):
	+ This field is currently not used, but may be used for additional notes or comments in the future.
	+ Currently, it's best to leave this field blank.

## Tips
* Be sure to accurately report any issues or concerns during the inspection.
* Use standard units of measurement for height and width (e.g., inches or meters).
* Select the correct material type for the ladder.
* Use the user notes field to provide context or additional information.
* Review and submit the completed form for record-keeping and reference.
