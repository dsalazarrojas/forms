# Guest Room CheckList - Help Guide
## Purpose
The Guest Room CheckList is a form used to assess the condition and features of a hotel room. This form helps hotel staff evaluate the room's quality and identify any areas that require attention.

## How To Complete This Form
1. Review the room and select the correct options for each field.
2. Answer each field based on your observation of the room's condition and features.
3. If you are unsure about a particular field, please make your best estimate or ask for clarification.

## Field-by-Field Explanation

* **Room Number** (1, number, required): Enter the room number you are inspecting.
* **Condition** (2, select_one, required): Evaluate the room's condition using the provided options: Excellent, Good, Poor, or Unsatisfactory.
* **Cleanliness** (3, number, required): Assess the room's cleanliness using the provided options (e.g., 1-5 scale).
* **Amenities** (4, select_multiple, required): Select all amenities that are available in the room from the provided options: Free Wi-Fi, Free Parking, Free Breakfast, In-room Mini-bar.
* **In-Room Mini-bar** (5, select_one, required): Determine if the room has an in-room mini-bar, and select 'True' or 'False'.
* **Free Parking** (6, select_one, required): Determine if the room has free parking, and select 'True' or 'False'.
* **Free Breakfast** (7, select_one, required): Determine if the room has free breakfast, and select 'True' or 'False'.
* **Room Type** (8, select_one, required): Select the type of room (Single, Double, Suite).
* **Bed Type** (9, select_one, required): Select the type of bed (Single, Double, King).
* **Bathroom** (10, select_multiple, required): Select the type(s) of bathroom in the room (Private, Public, Shared).
* **Bathroom Type** (11, select_one, required): Determine the type of bathroom (En-suite, Shared).
* **Bathroom Type - Shower** (12, select_one, required): Determine if the room has a modern, old, or shared shower.
* **Hair-dryer** (13, select_one, required): Determine if the room has a hair-dryer, and select 'True' or 'False'.
* **Bed Size** (14, select_one, required): Select the size of the bed (Queen, King, Single).
* **Smoking** (15, select_one, required): Determine if the room allows smoking, and select 'True' or 'False'.
* **Room Layout** (16, select_one, required): Select the layout of the room (L-shape, U-shape, Straight).
* **Room View** (17, select_one, required): Select the view of the room (City View, Garden View, None).
* **Free Gym** (18, select_one, required): Determine if the room has a free gym, and select 'True' or 'False'.
* **Room Condition** (19, select_one, required): Select the condition of the room (New, Clean, Average, Needs Improvement).
* **Bed Frame** (20, select_one, required): Determine the type of bed frame (Wooden, Metal, Plastic).
* **Toilet Type** (21, select_one, required): Select the type of toilet (Modern, Old, Shared).
* **Shower Type** (22, select_one, required): Determine the type of shower (Modern, Old, Shared).
* **Free Wi-Fi** (23, select_one, required): Determine if the room has free Wi-Fi, and select 'True' or 'False'.
* **Toilet Frame** (24, select_one, required): Determine the type of toilet frame (Wooden, Plastic, Metal).
* **Free Parking** (25, select_one, required): Determine if the room has free parking, and select 'True' or 'False'.
