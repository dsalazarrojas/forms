# uber_inspection_form - Help Guide
## Purpose
The "uber_inspection_form" is a comprehensive form designed to collect information about the condition and status of a vehicle. It is used to assess the overall condition of a vehicle and provide an evaluation of its pass or fail status.

## How To Complete This Form
To complete this form accurately, follow these steps:

* Review each page and section carefully before starting to ensure you have all the necessary information.
* Fill in all required fields, marked as "required" in the form.
* Use the provided options for select fields, or choose "Other" if the vehicle's condition doesn't match any of the options.
* Be as detailed as possible in the text fields (e.g., vehicle_info, license_plate, comments).

## Field-by-Field Explanation

* **Vehicle Info** (Page 1, vehicle_info): Enter a brief description of the vehicle, including its make, model, and year.
* **Vehicle Make** (Page 1, vehicle_make): Select the make of the vehicle from the provided options (e.g., Toyota, Honda, Ford).
* **Vehicle Model** (Page 1, vehicle_model): Select the model of the vehicle from the provided options (e.g., Camry, Civic, Focus).
* **Vehicle Year** (Page 1, vehicle_year): Enter the year of the vehicle.
* **License Plate** (Page 1, license_plate): Enter the license plate number of the vehicle.
* **Odometer Reading** (Page 1, odometer_reading): Enter the current odometer reading of the vehicle.
* **Engine Condition** (Page 2, engine_condition): Select the condition of the engine from the provided options (e.g., Good, Fair, Poor).
* **Transmission Condition** (Page 2, transmission_condition): Select the condition of the transmission from the provided options (e.g., Good, Fair, Poor, Doesn't Work).
* **Brake System** (Page 2, brake_system): Select the condition of the brake system from the provided options (e.g., Working, Not Working, Unknown).
* **Suspension System** (Page 2, suspension_system): Select the condition of the suspension system from the provided options (e.g., Good, Fair, Poor).
* **Tire Condition** (Page 2, tire_condition): Select the condition of the tires from the provided options (e.g., Good, Fair, Poor).
* **Steering System** (Page 2, steering_system): Select the condition of the steering system from the provided options (e.g., Working, Not Working, Unknown).
* **Frame and Body** (Page 2, frame_and_body): Select the condition of the frame and body from the provided options (e.g., Good, Fair, Poor, Damaged).
* **Exhaust System** (Page 2, exhaust_system): Select the condition of the exhaust system from the provided options (e.g., Good, Fair, Poor, Not Working).
* **Battery** (Page 2, battery): Select the condition of the battery from the provided options (e.g., Good, Fair, Poor, Not Charged).
* **Lights and Signals** (Page 2, lights_and_signals): Select the condition of the lights and signals from the provided options (e.g., Good, Fair, Poor).
* **Wheels and Tires** (Page 2, wheels_and_tires): Select the condition of the wheels and tires from the provided options (e.g., Good, Fair, Poor, Worn).
* **Body and Paint** (Page 2, body_and_paint): Select the condition of the body and paint from the provided options (e.g., Good, Fair, Poor, Damaged).
* **Interior** (Page 3, interior): Select the condition of the interior from the provided options (e.g., Good, Fair, Poor, Damaged).
* **Electrical Systems** (Page 3, electrical_systems): Select the condition of the electrical systems from the provided options (e.g., Good, Fair, Poor, Not Working).
* **Glass and Mirrors** (Page 3, glass_and_mirrors): Select the condition of the glass and mirrors from the provided options (e.g., Good, Fair, Poor).
* **Other Damage** (Page 3, other_damage): Enter any other damage or issues with the vehicle that are not listed in the previous fields.
* **Comments** (Page 3, comments): Enter any additional comments or notes about the vehicle.
* **Vehicle Status** (Page 3, vehicle_status): Select the overall status of the vehicle from the provided options (e.g., Pass, Fail, Not Inspected).
* **Vehicle Condition** (Page 3, vehicle_condition): Select the overall condition of the vehicle from the provided options (e.g., Pass, Fail, Not Inspected).
