# Electrical Installation Periodic Inspection Checklist - Help Guide
## Purpose
This is a comprehensive checklist for electrical installation periodic inspections. The purpose of this form is to ensure that electrical installations are inspected regularly to identify potential hazards and ensure compliance with safety standards. This checklist helps inspectors verify that all electrical installations are in good working condition and meet the required safety standards.

## How To Complete This Form
To complete this form, follow these steps:

1. Read through the form carefully and ensure you understand each field's purpose and requirements.
2. Fill out the form with the relevant information for the electrical installation being inspected.
3. Answer each question truthfully and accurately, providing as much detail as possible.
4. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **Introduction** (`id: 1`, `name: introduction`, required: false): This is an optional introduction section where you can provide any additional information about the electrical installation being inspected.
* **Site Address** (`id: 2`, `name: site_address`, required: false): Enter the address of the site where the electrical installation is located.
* **Inspector** (`id: 3`, `name: inspector`, required: false): Enter your name and contact information as the inspector conducting the review.
* **Site Location** (`id: 4`, `name: site_location`, required: false): Enter the location of the site, such as a room or area number.
* **Electrical Installation** (`id: 5`, `name: electrical_installation`, required: false): Enter a brief description of the electrical installation being inspected.
* **Circuit Breaker** (`id: 6`, `name: circuit_breaker`, required: false): Enter the number of circuit breakers in the electrical installation.
* **Electrical Connections** (`id: 7`, `name: electrical_connections`, required: false): Describe the type and number of electrical connections in the installation.
* **Electrical Outlets** (`id: 8`, `name: electrical_outlets`, required: false): List the number and type of electrical outlets in the installation.
* **Safety Equipment** (`id: 9`, `name: safety_equipment`, required: false): Describe the safety equipment installed in the electrical installation.
* **Emergency Exit Lighting** (`id: 10`, `name: emergency_exit_lighting`, required: false): Check if emergency exit lighting is installed and functional.
* **Exit Door Hardware** (`id: 11`, `name: exit_door_hardware`, required: false): Describe the type of exit door hardware used in the installation.
* **Fire Alarm System** (`id: 12`, `name: fire_alarm_system`, required: false): Check if a fire alarm system is installed and functional.
* **Electrical Room** (`id: 13`, `name: electrical_room`, required: false): Select the type of electrical room (Option 1, Option 2, or Option 3).
* **Electrical Cabinet** (`id: 14`, `name: electrical_cabinet`, required: false): Enter a brief description of the electrical cabinet used in the installation.
* **Electrical Panels** (`id: 15`, `name: electrical_panels`, required: false): Select all types of electrical panels used in the installation (Panel 1, Panel 2, or Panel 3).
* **Ground Level Electrical** (`id: 16`, `name: ground_level_electrical`, required: false): Enter a brief description of the ground level electrical components.
* **Electrical Room Equipment** (`id: 17`, `name: electrical_room_equip`, required: false): Describe the electrical room equipment installed in the installation.
* **Electrical Systems** (`id: 18`, `name: electrical_systems`, required: false): Enter a brief description of the electrical systems installed in the installation.
* **Electrical Equipment** (`id: 19`, `name: electrical_equipment`, required: false): Describe the electrical equipment installed in the installation.
* **Electrical System Control** (`id: 20`, `name: electrical_system_control`, required: false): Enter a brief description of the electrical system control used in the installation.
* **Ground Level Accessories** (`id: 21`, `name: ground_level_accessories`, required: false): Enter a brief description of the ground level accessories used in the installation.
* **Electrical System Accessory** (`id: 22`, `name: electrical_system_accessories`, required: false): Describe the electrical system accessories used in the installation.
* **Electrical System Accessory Equipment** (`id: 23`, `name: electrical_system_accessories_equip`, required: false): Enter a brief description of the electrical system accessory equipment used in the installation.
* **Electrical Connection Accessories** (`id: 24`, `name: electrical_connection_accessories`, required: false): Describe the electrical connection accessories used in the installation.
* **Electrical Wiring Systems** (`id: 25`, `name: electrical_wiring_systems`, required: false): Enter a brief description of the electrical wiring systems used in the installation.

Note: The following fields are required for the inspector to fill out: None.

## Tips

* Make sure to answer each question truthfully and accurately.
* If you are unsure about any question, ask for clarification.
* Review the form carefully before submitting it.
* Keep the form in a safe and secure location.
* Do not leave any blank fields without an explanation.
* If you have any additional comments or recommendations, add them to the introduction section.
* This form is for your personal use only, do not share it with anyone else.
* This form is for electrical installation periodic inspections only.
* Make sure to follow all relevant safety protocols when conducting the inspection.
