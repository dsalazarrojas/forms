# Daily QA Task Checklist - Help Guide
## Purpose
The "Daily QA Task Checklist" form is designed to help QA team members document and track their daily tasks and issues. This form serves as a simple, easy-to-use template for recording information about tasks, departments, and issues encountered during testing and quality assurance processes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant department from the list of available options.
2. Enter the name of the task you are currently working on.
3. Add any additional notes about the task, if necessary.
4. Choose the type of issue, if applicable.
5. Provide a brief description of the issue, if necessary.
6. Select the person who will be checking or verifying the task.
7. Once you have filled out all the required fields, review your submission for accuracy and completeness.

## Field-by-Field Explanation
* **Department**: Select the department responsible for the task or issue from the list of available options.
* **Task Name**: Enter a brief description of the task you are currently working on. This field is for identifying the specific task or activity.
* **Task Notes**: Add any additional information or comments about the task, if necessary. This field is optional but can be helpful for providing more context or clarification.
* **Issue Type**: If the task involves an issue, select the type of issue from the list of available options.
* **Issue Description**: Provide a brief description of the issue, if applicable. This field is optional but can help with issue tracking and resolution.
* **Checked By**: Select the person who will be checking or verifying the task. This field is usually filled out by the person responsible for verifying the task's completion or resolution.

## Tips
- Make sure to fill out all required fields (department and task name) before submitting.
- Use the issue type and description fields to provide clear and concise information about the issue.
- If multiple issues are involved, select all relevant issue types and descriptions.
- Use the task notes field to add additional context or clarification about the task.
- Review your submission carefully before submitting to ensure accuracy and completeness.
