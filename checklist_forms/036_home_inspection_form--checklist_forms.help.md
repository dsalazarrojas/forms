# Home Inspection Form - Help Guide
## Purpose
This form is designed to collect information about a home's condition, safety, and systems, making it a useful starting point for further inspection and assessment.

## How To Complete This Form
1.  Start with the "General Information" field and provide a brief description of the property.
2.  Move on to the other fields, describing the condition and any issues with each category of home inspection.
3.  Be as detailed as possible when filling out the form to ensure accurate documentation.

## Field-by-Field Explanation
* **General Information** (`general_info`, text, optional): A free text area to describe the property in general terms.
* **Home Details** (`home_details`, text, optional): Describe any notable features or issues with the home's overall condition.
* **Safety Checklist** (`safety_checklist`, text, optional): Document any safety concerns or hazards found during the inspection.
* **Electrical Systems** (`electrical_systems`, text, optional): Describe the condition and any issues with the electrical systems of the property.
* **Plumbing Systems** (`plumbing_systems`, text, optional): Describe the condition and any issues with the plumbing systems of the property.
* **Heating and Cooling** (`heating_and_cooling`, text, optional): Describe the condition and any issues with the heating and cooling systems of the home.
* **Exterior** (`exterior`, text, optional): Describe the condition and any issues with the home's exterior.
* **Interior** (`interior`, text, optional): Describe the condition and any issues with the home's interior.
* **Foundation** (`foundation`, text, optional): Describe the condition and any issues with the home's foundation.
* **Roof** (`roof`, text, optional): Describe the condition and any issues with the home's roof.
* **Garage** (`garage`, text, optional): Document any details specific to the garage, such as condition and any issues.

## Tips
* Be as detailed as possible when filling out the form to ensure accurate documentation.
* Use this form as a starting point for further inspection and assessment.
* If you're a certified professional, consider using a more comprehensive inspection tool for a more detailed evaluation.
