# weekly_generator_maintenance_checklist - Help Guide
## Purpose
The weekly generator maintenance checklist is a simple form designed to help users check and report the status of a generator's various components.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and enter the correct status for each component.
2. For numerical fields (e.g., oil pressure), enter a numerical value.
3. For select fields (e.g., oil leakage), select one of the provided options.
4. For multiple select fields (e.g., electrical component status), select one or more of the provided options.
5. Enter any additional comments or notes as needed.

## Field-by-Field Explanation
* **weekly_generator_maintenance_checklist** (1): Enter a brief description of the generator's current status (optional).
* **generator_status** (2): Enter the current status of the generator (e.g., operational, offline, etc.).
* **electrical_components_status** (3-11): Enter the status of the electrical component(s) being checked (e.g., no, yes).
* **gas_system_status** (4): Enter the status of the gas system (e.g., normal, off, etc.).
* **cooling_system_status** (5): Enter the status of the cooling system (e.g., normal, off, etc.).
* **control_system_status** (6): Enter the status of the control system (e.g., normal, off, etc.).
* **mechanical_system_status** (7): Enter the status of the mechanical system (e.g., normal, off, etc.).
* **generator_condition** (8): Enter a brief description of the generator's overall condition.
* **oil_level** (9): Enter the current oil level (e.g., low, normal, high).
* **oil_leakage** (10): Select whether there is oil leakage (yes or no).
* **oil_color** (11): Select the current color of the oil (clear, cloudy, dull).
* **oil_smell** (12): Select whether there is an oil smell (yes or no).
* **oil_temperature** (13): Select the current temperature of the oil (normal, high, low).
* **oil_pressure** (14): Enter the current oil pressure.
* **electrical_component_status_1-11** (15-21): Select the status of each electrical component (e.g., no, yes).
* **electrical_component_status_12** (22): Select the status of the electrical component 12 (e.g., no, yes).
* **electrical_component_status_13** (23): Select the status of the electrical component 13 (e.g., no, yes).
* **electrical_component_status_14** (24): Select the status of the electrical component 14 (e.g., no, yes).
* **electrical_component_status_15** (25): Select the status of the electrical component 15 (e.g., no, yes).
