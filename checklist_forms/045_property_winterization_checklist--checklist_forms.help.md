# property_winterization_checklist - Help Guide
## Purpose
This form is a property winterization checklist designed to help users inspect and prepare properties for winter conditions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the property name, address, and type.
2. Choose the current winter preparation status of the property.
3. Enter the date of the inspection.
4. Fill in the name and company of the inspector.
5. Add any additional notes about the property's winterization status.
6. Select the items that need to be inspected and possibly checked off.

## Field-by-Field Explanation
* **Winterization Checklist Header**: This is a note field that explains the purpose of the form and serves as a title for the rest of the form.
* **property_name**: This is the name of the property that is being inspected.
* **property_address**: This is the address of the property that is being inspected.
* **property_type**: This is the type of property (Residential, Commercial, Industrial, or Agricultural).
* **winter_prep_status**: This is the current status of the property's winterization preparation (Completed, In Progress, Not Required, or Cancelled).
* **inspection_date**: This is the date of the inspection.
* **inspector_name**: This is the name of the person performing the inspection.
* **inspector_company**: This is the company of the person performing the inspection.
* **winterization_notes**: This is a text field where additional comments about the property's winterization status can be entered.
* **winterization_checklist_items**: This is a list of items that should be inspected and possibly checked off.

## Tips
* Make sure to fill in all required fields.
* Choose the correct property type and winter preparation status.
* Use clear and concise language in the notes field.
* Double-check the inspection date and inspector information.
* Select all items that need to be inspected and possibly checked off.
