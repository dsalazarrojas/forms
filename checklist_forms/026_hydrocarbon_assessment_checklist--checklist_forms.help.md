# Hydrocarbon Assessment Checklist - Help Guide
## Purpose
The Hydrocarbon Assessment Checklist is a form designed to assess the presence of hydrocarbons at a site and ensure that a spill response plan is in place.

## How To Complete This Form

1.  Fill out each field according to the instructions below:
2.  For each field, please enter the relevant information based on your assessment.
3.  Make sure to fill out all fields, if possible.

## Field-by-Field Explanation

*   **Site Location** (1, text, required): Enter the name of the location where the hydrocarbon is being handled.
*   **Hydrocarbon Present** (2, select_one, required): Select the presence and quantity of hydrocarbons at the site from the dropdown menu.
*   **Storage Facility** (3, select_multiple, optional): Select the type of storage facility available at the site.
*   **Spill Response Plan** (4, text, optional): Enter a description of the spill response plan in place.
*   **Training Records** (5, select_multiple, optional): Select the type of training records available for site staff.
*   **Spill Response Equipment** (6, select_multiple, optional): Select the type of spill response equipment available at the site.
*   **Spill Response Plan Review** (7, number, optional): Enter the reviewer's notes for the spill response plan review.
*   **Hydrocarbon Assessment** (8, text, optional): Enter a description of the hydrocarbon assessment.
*   **Site Inspection** (9, date, optional): Enter the date of the site inspection.
*   **Spill Response Plan Approval** (10, time, optional): Select the status of the spill response plan approval.
*   **Staff Training** (11, select_one, optional): Select the type of staff training available.
*   **Site Visit** (12, note, optional): Enter any additional notes for the site visit.
*   **Spill Response Equipment Maintenance** (13, text, optional): Enter a description of the spill response equipment maintenance.

## Tips

*   Please fill out all fields, if possible.
*   If a field is not applicable, please select "Not Applicable" or "Not Required".
*   Make sure to review the form carefully before submission.
*   If you have any questions or need clarification, please contact your supervisor or site management.
