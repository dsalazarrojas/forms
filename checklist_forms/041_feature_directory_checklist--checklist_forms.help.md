# feature_directory_checklist - Help Guide
## Purpose
The feature directory checklist is a form used for multiple teams to review and track the status of features in the "Feature Directory".

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant feature status from the dropdown list.
2. Enter the completed date and time if applicable.
3. Add any additional notes or comments as needed.
4. Repeat steps 1-3 for each additional feature on the list.

## Field-by-Field Explanation
* **Team Review** (`Team Review`, text, not required): This field is where the team can enter any comments or feedback for the feature.
* **Feature Status** (`Feature Status`, select_one, required): Select the current status of the feature from the dropdown list. The status can be either "Active" or "Inactive".
* **Notes** (`Notes`, note, not required): This field is where the team can enter any additional comments or notes for the feature.
* **Feature Completed Date** (`Feature Completed Date`, date, not required): Enter the date when the feature was completed.
* **Feature Completed Time** (`Feature Completed Time`, time, not required): Enter the time when the feature was completed.
* **Team Review 1**, **Team Review 2**, **Team Review 3**, **Team Review 4**, **Team Review 5** (`Team Review 1`, `Team Review 2`, `Team Review 3`, `Team Review 4`, `Team Review 5`, text, not required): Repeat the team review process for each additional feature on the list.
* **Feature Status 1**, **Feature Status 2**, **Feature Status 3**, **Feature Status 4**, **Feature Status 5** (`Feature Status 1`, `Feature Status 2`, `Feature Status 3`, `Feature Status 4`, `Feature Status 5`, select_one, not required): Select the status of each feature from the dropdown list.
* **Feature Completed Date 1**, **Feature Completed Date 2**, **Feature Completed Date 3**, **Feature Completed Date 4**, **Feature Completed Date 5** (`Feature Completed Date 1`, `Feature Completed Date 2`, `Feature Completed Date 3`, `Feature Completed Date 4`, `Feature Completed Date 5`, date, not required): Enter the date when each feature was completed.
* **Feature Completed Time 1**, **Feature Completed Time 2**, **Feature Completed Time 3**, **Feature Completed Time 4**, **Feature Completed Time 5** (`Feature Completed Time 1`, `Feature Completed Time 2`, `Feature Completed Time 3`, `Feature Completed Time 4`, `Feature Completed Time 5`, time, not required): Enter the time when each feature was completed.
* **Completed By** (`Completed By`, text, not required): This field is not currently used in the form, but may be used in the future to track who completed each feature.
* **Feature Directory Status** (`Feature Directory Status`, select_multiple, not required): This field is not currently used in the form, but may be used in the future to track the status of the feature directory. 

## Tips
* Make sure to only use this form for features that are part of the "Feature Directory".
* Ensure that the form is not used for other purposes.
* Use the form multiple times for each feature as needed.
* Enter relevant information for each field as applicable.
* Review each field carefully before submitting the form.
* Make sure to save your work before submitting.
