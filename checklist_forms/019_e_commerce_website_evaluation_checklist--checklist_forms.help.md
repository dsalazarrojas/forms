# E Commerce Website Evaluation Checklist - Help Guide
## Purpose
This form is designed to be used for evaluating an E Commerce website. The goal is to assess the overall quality and performance of a website in several key aspects, including its design, user experience, and functionality.

## How To Complete This Form

1.  Please select the website you wish to evaluate and enter the website URL in the "Website URL" field.
2.  For each field, select the corresponding option that best describes your experience or opinion about the website.
3.  You can choose from the options provided for each field, such as "good", "bad", or "neutral".
4.  If a field is marked as "required", please make sure to fill it out as it is essential for the evaluation.
5.  You can choose multiple options in the "Search Box" field by holding down Ctrl (on Windows) or Command (on Mac) and selecting multiple options.
