# Rental History Verification Form - Help Guide
## Purpose
The Rental History Verification Form is used to gather information about the applicant's rental experiences. This information will be used to verify the applicant's rental history and help us get a better understanding of the applicant's needs and expectations.

## How To Complete This Form

1. Please complete this form accurately and thoroughly.
2. Answer all questions related to your rental experiences, including the length of each rental period.
3. If you have multiple rental experiences, please fill out a separate form for each experience.
4. For each rental experience, please fill out the necessary information, including the start and end dates, lease term, and rent amount.
5. If you have any questions or concerns, please contact our office for assistance.

## Field-by-Field Explanation

### Applicant Information
* **Applicant Information** (applicant_info): This is the applicant's name and other relevant contact information.
    * Required: No

### Rental History
* **Rental History** (rental_history): This is a brief description of your rental experience.
    * Required: No

### Employment Information
* **Employment Information** (employment_info): Check if the applicant is employed.
    * Options: Full-time, Part-time, Contract
    * Required: No

### Rental Info 1
* **Rental Info 1** (rental_info_1): Select the length of your rental period.
    * Options: 12 months, 24 months, 36 months
    * Required: No

### Rental Info 2
* **Rental Info 2** (rental_info_2): Select the length of your rental period.
    * Options: 1 month, 2 months
    * Required: No

### Property Details
* **Property Details** (property_details): Check if the applicant owns property.
    * Options: True, False
    * Required: No

### Rental Agreement
* **Rental Agreement** (rental_agreement): Check if you had a rental agreement.
    * Options: True, False
    * Required: No

### Lease Term
* **Lease Term** (lease_term): Select the length of your rental lease.
    * Options: Month-to-Month, 6 Months, 12 Months
    * Required: No

### Lease Start Date
* **Lease Start Date** (lease_start_date): Select the start date of your rental lease.
    * Type: Date
    * Required: No

### Lease End Date
* **Lease End Date** (lease_end_date): Select the end date of your rental lease.
    * Type: Date
    * Required: No

### Landlord Info
* **Landlord Info** (landlord_info): This is the landlord's name and contact information.
    * Required: No

### Tenant Info
* **Tenant Info** (tenant_info): This is the tenant's name and contact information.
    * Required: No

### Move-in Date
* **Move-in Date** (move_in_date): Select the date you moved-in to the rental property.
    * Type: Date
    * Required: No

### Move-out Date
* **Move-out Date** (move_out_date): Select the date you moved-out of the rental property.
    * Type: Date
    * Required: No

### Rental Amount
* **Rental Amount** (rental_amount): Select the rent amount you paid each month.
    * Type: Number
    * Required: No

### Rental Address
* **Rental Address** (rental_address): This is the address of the rental property.
    * Required: No

### Rent
* **Rent** (rent): Select the rent amount you paid each month.
    * Type: Number
    * Required: No

### Utilities
* **Utilities** (utilities): Select the utilities you paid each month.
    * Type: Number
    * Required: No

### Security Deposit
* **Security Deposit** (deposit): Select the security deposit you paid.
    * Type: Number
    * Required: No

### Lease Start Date 1
* **Lease Start Date 1** (lease_start_date_1): Select the start date of your first rental lease.
    * Type: Date
    * Required: No

### Lease End Date 1
* **Lease End Date 1** (lease_end_date_1): Select the end date of your first rental lease.
    * Type: Date
    * Required: No

### Landlord Info 1
* **Landlord Info 1** (landlord_info_1): This is the landlord's name and contact information for your first rental experience.
    * Required: No

### Tenant Info 1
* **Tenant Info 1** (tenant_info_1): This is the tenant's name and contact information for your first rental experience.
    * Required: No

### Move-in Date 1
* **Move-in Date 1** (move_in_date_1): Select the date you moved-in to your first rental property.
    * Type: Date
    * Required: No

### Move-out Date 1
* **Move-out Date 1** (move_out_date_1): Select the date you moved-out of your first rental property.
    * Type: Date
    * Required: No

Please note that this form is not exhaustive and you may need to provide additional information or attachments to support your rental experiences. If you have any questions or concerns, please contact our office for assistance.
