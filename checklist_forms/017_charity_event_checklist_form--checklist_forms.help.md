# Charity Event Checklist Form - Help Guide
## Purpose
The Charity Event Checklist Form is a tool used by event organizers to track and manage various aspects of charity events. It helps to ensure that all necessary tasks are completed before, during, and after the event to guarantee its success.

## How To Complete This Form
1. Review each section carefully and answer all questions.
2. Enter your information in the corresponding fields accurately and thoroughly.
3. Make sure to check the relevant box for each section after completion.
4. Scroll down to the next section once you have answered all questions on the current page.
5. Review your answers before submitting the form.

## Field-by-Field Explanation
### Event Name
* **Event Name** (`event_name`, `text`, required): Enter the name of your charity event.
*   Please ensure that the name is descriptive and easy to identify the event by.

### Event Date
* **Event Date** (`event_date`, `date`, required): Enter the date of the charity event.
*   This date should be in the format of month/day/year.

### Event Location
* **Event Location** (`event_location`, `text`, required): Enter the venue or address of the event.
*   Make sure to include the address or venue name for easy identification.

### Organizer Name
* **Organizer Name** (`organizer_name`, `text`, required): Enter the name of the lead organizer.
*   This should be the person or organization responsible for overseeing the event.

### Organizer Email
* **Organizer Email** (`organizer_email`, `email`, required): Enter the email address of the lead organizer.
*   This should be a valid email that can be used for communication.

### Expected Attendees
* **Expected Number of Attendees** (`expected_attendees`, `number`, required): Enter the estimated number of attendees expected.
*   This helps in arranging for sufficient resources and logistics.

### Venue Booked and Confirmed
* **Venue Booked and Confirmed** (`venue_booked`, `select_one`, required): Select the status of the venue booking.
*   This should reflect if the venue has been booked and confirmed or not.

### Permits and Licenses Obtained
* **Permits and Licenses Obtained** (`permits_obtained`, `select_one`, required): Select the status of necessary permits and licenses.
*   Ensure that all necessary permits and licenses have been secured.

### Vendors and Catering Confirmed
* **Vendors and Catering Confirmed** (`vendors_confirmed`, `select_one`, required): Select the status of vendor and catering arrangements.
*   Confirm if vendors and catering services have been arranged.

### Volunteers Recruited
* **Volunteers Recruited** (`volunteers_recruited`, `select_one`, required): Select the status of volunteers recruitment.
*   Ensure that sufficient volunteers have been recruited for the event.

### Marketing Materials Prepared
* **Marketing Materials Prepared** (`marketing_materials`, `select_one`, required): Select the status of marketing materials preparation.
*   Ensure that all necessary promotional materials have been created.

### Registration System Set Up
* **Registration System Set Up** (`registration_system`, `select_one`, required): Select the status of registration system setup.
*   Ensure that attendee tracking system is in place.

### Audio Visual Equipment Arranged
* **Audio Visual Equipment Arranged** (`audio_visual`, `select_one`, required): Select the status of audio visual equipment arrangements.
*   Ensure that necessary audio visual equipment has been arranged.

### Security Arranged
* **Security Arranged** (`security_arranged`, `select_one`, required): Select the status of security arrangements.
*   Ensure that necessary safety measures have been taken.

### Insurance Coverage Confirmed
* **Insurance Coverage Confirmed** (`insurance_confirmed`, `select_one`, required): Select the status of insurance coverage confirmation.
*   Ensure that necessary liability coverage has been secured.

### Sponsorships Secured
* **Sponsorships Secured** (`sponsorship_secured`, `select_one`, required): Select the status of sponsorships secured.
*   Ensure that sufficient sponsorships have been secured.

### Day-of Schedule Created
* **Day-of Schedule Created** (`day_of_schedule`, `select_one`, required): Select the status of event timeline creation.
*   Ensure that the event timeline is well-planned and communicated.

### Cleanup Plan Established
* **Cleanup Plan Established** (`cleanup_plan`, `select_one`, required): Select the status of post-event cleanup plans.
*   Ensure that post-event cleanup plans are in place.

### Additional Tasks or Notes
* **Additional Tasks or Notes** (`additional_tasks`, `text`, optional): Enter any additional tasks or notes that are not listed in the other sections.
*   This is an optional field for any extra information that you want to include.
