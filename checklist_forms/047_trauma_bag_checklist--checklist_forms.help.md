# Trauma Bag Checklist - Help Guide
## Purpose
The purpose of this form is to collect and track information about trauma bags, which are essential in emergency medical responses. This form helps users document the condition, contents, and certification status of each trauma bag to ensure compliance with regulatory requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form carefully.
2. Answer each question based on your knowledge or observations.
3. Ensure you complete all required fields (indicated by an asterisk).
4. Use the provided instructions and guidelines to guide your responses.

## Field-by-Field Explanation

### 1. Trauma Bag (text)

This field is for you to confirm or deny the presence of a trauma bag.
- Type: Text
- Required: False
- Description: Check to confirm or deny the presence of a trauma bag.

### 2. Trauma Bags (Select One: Yes/No)

Indicate if you have found any trauma bags.
- Type: Select One
- Required: False
- Description: Check "Yes" if you have found trauma bags, "No" otherwise.

### 3. Trauma Bags Location (Text)

Enter the location where the trauma bags are kept.
- Type: Text
- Required: False
- Description: Provide the location where the trauma bags are stored.

### 4. Trauma Bags Contents (Text)

Describe the contents of the trauma bags.
- Type: Text
- Required: False
- Description: List the items and materials found in the trauma bags.

### 5. Trauma Bags Condition (Text)

Assess the condition of the trauma bags.
- Type: Text
- Required: False
- Description: Evaluate the overall condition of the trauma bags, including any damage or wear.

### 6. Trauma Bags Missing Items (Select Multiple: Yes/No)

Check the items that are missing from the trauma bags.
- Type: Select Multiple
- Required: False
- Description: Select "Yes" for missing items, "No" otherwise.

### 7. Emergency Supplies (Text)

Describe the emergency supplies found in the trauma bags.
- Type: Text
- Required: False
- Description: List the emergency supplies, such as gloves, scissors, etc.

### 8. Emergency Supplies Location (Text)

Enter the location where the emergency supplies are kept.
- Type: Text
- Required: False
- Description: Provide the location where the emergency supplies are stored.

### 9. Emergency Supplies Contents (Text)

Describe the emergency supplies contents.
- Type: Text
- Required: False
- Description: List the contents of the emergency supplies.

### 10. Emergency Supplies Condition (Text)

Assess the condition of the emergency supplies.
- Type: Text
- Required: False
- Description: Evaluate the overall condition of the emergency supplies, including any damage or wear.

### 11. Trauma Bags Certification (Select One: Yes/No)

Check if the trauma bags are certified.
- Type: Select One
- Required: False
- Description: Check "Yes" if the trauma bags are certified, "No" otherwise.

### 12. Last Inspection Date (Date)

Enter the date of the last inspection.
- Type: Date
- Required: False
- Description: Provide the date of the last inspection.

### 13. Next Due Date (Date)

Enter the next due date for the trauma bags.
- Type: Date
- Required: False
- Description: Provide the next due date for the trauma bags.

### 14. Last Inspected By (Text)

Enter the name of the person who last inspected the trauma bags.
- Type: Text
- Required: False
- Description: Provide the name of the person who last inspected the trauma bags.

### 15. Last Certified By (Text)

Enter the name of the person who last certified the trauma bags.
- Type: Text
- Required: False
- Description: Provide the name of the person who last certified the trauma bags.

### 16. Notes (Text)

Enter any additional notes or comments.
- Type: Text
- Required: False
- Description: Provide any additional information or comments about the trauma bags.
