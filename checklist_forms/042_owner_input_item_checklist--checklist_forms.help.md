# Owner Input Item Checklist - Help Guide
## Purpose
The Owner Input Item Checklist form is designed to help owners input information about items in their possession. This form allows owners to create a clear and concise record of items they have inputted.

## How To Complete This Form
To complete this form, follow the steps below:

1. Navigate to the correct page for the item you want to input information about.
2. For each item, input the required information in the corresponding fields.
3. Select the appropriate option to confirm your ownership of the item.
4. Review and submit the form when complete.

## Field-by-Field Explanation

* **item_1** (`item_1`, text, not required): Enter a brief description of the item, e.g., "Laptop"
* **condition_notes_1** (`condition_notes_1`, text, not required): Add any additional notes about the item's condition, e.g., "Dented but functional"
* **owner_confirmation_1** (`owner_confirmation_1`, select_one, required): Select "Yes" to confirm that you own this item.
* **item_2** (`item_2`, text, not required): Enter a brief description of the item, e.g., "Tablet"
* **condition_notes_2** (`condition_notes_2`, text, not required): Add any additional notes about the item's condition, e.g., "No scratches"
* **owner_confirmation_2** (`owner_confirmation_2`, select_one, required): Select "Yes" to confirm that you own this item.
* **item_3** (`item_3`, text, not required): Enter a brief description of the item, e.g., "Chair"
* **item_4** (`item_4`, text, not required): Enter a brief description of the item, e.g., "Desk"

## Tips

* Make sure to complete each page carefully and accurately to ensure that the form is complete and accurate.
* If you are unsure about any field, refer back to this guide for clarification.
* If you have any further questions or need assistance, contact your supervisor or support team.
