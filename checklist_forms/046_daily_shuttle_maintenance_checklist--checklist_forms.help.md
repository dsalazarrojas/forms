# Daily Shuttle Maintenance Checklist - Help Guide
## Purpose
The Daily Shuttle Maintenance Checklist is a form used to record the status of daily shuttle maintenance activities. It helps facility managers, shuttle operators, and other personnel ensure that the shuttle is in a safe and operational state before and after each trip.

## How To Complete This Form
To complete the form, follow these steps:

1. Review the pre-trip checklist and select the status of each item.
2. If any issues are found, provide a detailed description in the "Issues Details" field.
3. Indicate if the shuttle is ready to operate by selecting "Yes" or "No" from the "Readiness to Operate" field.
4. Record the next maintenance date, if applicable.
5. Add any additional comments or notes regarding the shuttle's status.
6. Select the assigned department or person responsible for the maintenance activity.

## Field-by-Field Explanation

* **Pre-Trip Checklist (pre_trip_checklist)** (`select_multiple`, optional): This field provides a list of items to check before the shuttle is put into operation. Select all applicable items that have been completed.
* **Issues (issues)** (`text`, optional): Enter any issues or concerns regarding the shuttle's condition that were found during the pre-trip or post-trip checks.
* **Issues Details (issues_details)** (`text`, optional): Provide a detailed description of any issues or concerns listed in the "Issues" field.
* **Readiness to Operate (readiness_to_operate)** (`select_one`, optional): Indicate if the shuttle is ready to operate by selecting "Yes" or "No". If "No", provide a brief explanation for future reference.
* **Next Maintenance Date (next_maintenance_date)** (`date`, optional): Record the date for the next scheduled maintenance activity, if applicable.
* **Comments (comments)** (`text`, optional): Add any additional comments or notes regarding the shuttle's status.
* **Assigned To (assigned_to)** (`select_one`, optional): Select the department or person responsible for the maintenance activity, such as Fleet Management, Facilities Operations, etc.
