# Forklift Daily Inspection Checklist Form - Help Guide
## Purpose
This form is designed to support forklift inspections and ensure consistency and thoroughness in reporting.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the inspection date to record the date of the inspection.
2. Enter the equipment ID to identify the specific forklift being inspected.
3. Enter the shift number to specify the work shift during which the inspection was performed.
4. Type in the location where the inspection was conducted.
5. Provide your name as the operator performing the inspection.
6. In the "Inspection Items" field, select all items that were inspected or found defective.
7. In the "Completed Items" field, select all items that were completed or found to be in good condition.
8. Add any additional comments about the inspection, if necessary.

## Field-by-Field Explanation

* **Inspection Date** (`inspection_date`, date, required): This field is used to record the date of the inspection.
* **Equipment ID** (`equipment_id`, number, required): This field is used to identify the specific forklift being inspected.
* **Shift Number** (`shift_number`, number, required): This field is used to specify the work shift during which the inspection was performed.
* **Location** (`location`, text, required): This field is used to type in the location where the inspection was conducted.
* **Operator** (`operator_name`, text, required): This field is used to provide your name as the operator performing the inspection.
* **Inspection Items** (`inspection_items`, select_multiple, required): This field is used to select all items that were inspected or found defective.
* **Completed Items** (`completed_items`, select_multiple, required): This field is used to select all items that were completed or found to be in good condition.
* **Additional Comments** (`additional_comments`, text, required): This field is used to add any additional comments or context about the inspection.

## Tips
- Make sure to fill out all required fields accurately to ensure the inspection is properly recorded.
- Be thorough when selecting items in the "Inspection Items" and "Completed Items" fields.
- Use the "Additional Comments" field to provide any relevant details that are not captured in the other fields.
- This form is meant to be used daily, so try to keep it up-to-date and consistent.
