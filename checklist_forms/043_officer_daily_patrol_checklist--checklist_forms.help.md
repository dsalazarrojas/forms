# Officer Daily Patrol Checklist - Help Guide
## Purpose
The Officer Daily Patrol Checklist is used to document an officer's daily activities, including morning roll call, incident reports, arrests, vehicle checks, and officer notes.

## How To Complete This Form
1. Start by completing the Morning Roll Call section, which includes:
	* Officer Name: Enter your name as identified on your badge.
	* Date: Enter the date of the patrol.
	* Time: Enter the time of the patrol.
2. Next, complete the Incident Reports section, which includes:
	* Select the type of incident report from the drop-down list (e.g., Incident Report 1, Incident Report 2, etc.).
3. Move on to the Arrests section, which includes:
	* Arrests: Enter the number of arrests made.
4. Complete the Vehicle Check section, which includes:
	* Select the vehicles checked from the drop-down list (e.g., Vehicle 1, Vehicle 2, etc.).
5. Move on to the Call Logs section, which includes:
	* Call Logs: Enter the date and time of each call.
	* Call Logs 2: Enter additional call log information (optional).
6. Complete the Notes section, which includes:
	* Notes: Enter any additional notes or comments.
7. Enter the Officer Notes section, which includes:
	* Officer Notes: Enter any additional notes or comments about the officer's activities.
8. Finally, complete the Vehicle Speed Limit section, which includes:
	* Vehicle Speed Limit: Enter the speed of each vehicle checked.
9. Enter the Officer Badge Number, Officer Badge Number 2, and Badge Number 3 fields, which are used to track officer identification.
10. Enter any additional information in the Call Number and Call Number 2 fields, if applicable.
