# gmp_data_integrity_monitoring_checklist - Help Guide
## Purpose
The gmp_data_integrity_monitoring_checklist is a form used to assess the current state of data integrity in a facility's quality monitoring process.

## How To Complete This Form
This form is designed to be completed by a reviewer who has access to the facility's data management practices and procedures. To complete the form, follow these steps:

1. Start by reviewing the "Facility Audit" section, which asks you to evaluate the current state of the facility's data management practices.
2. Next, move on to the "Facility Audit Questions" section, where you will select all the questions that apply to the current state of data management practices.
3. Complete the "Audit Frequency" section by selecting a date for the most recent audit.
4. In the "Reviewer Notes" section, provide any additional comments or observations about the facility's data management practices.
5. The "Corrective Actions" section requires you to select "Yes" or "No" to indicate if any corrective actions have been taken.
6. The "Quality Team Notes" section is where you can provide any notes or comments from the quality team about the facility's data management practices.
7. The "Manufacturing Team Notes" section is optional and should only be completed if there are any observations or comments from the manufacturing team about the facility's data management practices.
8. In the "Action Due Date" section, select a date for the planned completion date of any corrective actions.
9. Finally, complete the "Completed Actions" and "Closed Actions" sections by selecting "Yes" or "No" to indicate the status of any actions taken.

## Field-by-Field Explanation
### Facility Audit
• **Facility Audit** (1, number, required): This field is used to evaluate the current state of the facility's data management practices. Select a number from 1 to 5 to indicate the level of compliance.

### Facility Audit Questions
• **Facility Audit Questions** (2, select_multiple, required): Select all the questions that apply to the current state of data management practices.

### Audit Frequency
• **Audit Frequency** (3, date, required): Select a date for the most recent audit.

### Reviewer Notes
• **Reviewer Notes** (4, text, required): Provide any additional comments or observations about the facility's data management practices.

### Corrective Actions
• **Corrective Actions** (5, select_one, required): Select "Yes" if any corrective actions have been taken, or "No" otherwise.

### Quality Team Notes
• **Quality Team Notes** (6, text, required): Provide any notes or comments from the quality team about the facility's data management practices.

### Manufacturing Team Notes
• **Manufacturing Team Notes** (7, text, optional): This field is optional and should only be completed if there are any observations or comments from the manufacturing team about the facility's data management practices.

### Action Due Date
• **Action Due Date** (8, date, required): Select a date for the planned completion date of any corrective actions.

### Completed Actions
• **Completed Actions** (9, select_multiple, required): Select "Yes" to indicate that all corrective actions have been completed, or "No" otherwise.

### Closed Actions
• **Closed Actions** (10, select_one, required): Select "Yes" to indicate that all corrective actions have been closed, or "No" otherwise.

## Tips
- Ensure that all fields are completed thoroughly and accurately.
- Use the options provided for each field to ensure consistent formatting and data collection.
- Review the form carefully before starting to ensure understanding of each section and field.
