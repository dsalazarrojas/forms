# Executor Checklist Form - Help Guide

## Purpose
The Executor Checklist Form is a document that allows you to evaluate the status of an executor's progress in various areas. This form is designed to ensure that the executor's work is being completed accurately and on time.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully to understand what is being asked.
2. For each field, select the relevant option or input the required information.
3. If a field is optional, you can skip it if it does not apply to your situation.

## Field-by-Field Explanation

* **Confirm Progress** (`confirm_progress`, note, required: false): This field is intended to confirm the progress made so far in the executor's work. Please note down any important updates or comments related to the progress.
* **Capture Confirmations** (`capture_confirmations`, select_multiple, required: false): In this field, you will select all confirmations that have been made. Choose 'Yes' if confirmations have been made and 'No' if not.
* **Estate Administrative Progress** (`estate_administrative_progress`, select_one, required: false): Select the level of progress made in estate administration, with options being '1', '5', '10', or '20'.
* **Document Uploads** (`document_uploads`, select_multiple, required: false): Choose 'Yes' if documents have been uploaded, and 'No' if not.
* **Estate Administration Tasks** (`estate_administration_tasks`, select_multiple, required: false): Select all tasks that have been completed in estate administration. Choose 'Yes' for completed tasks and 'No' for tasks that are still pending.
* **Executor Notes** (`executor_notes`, text, required: false): This field is for the executor to add any additional notes or comments about their progress.
