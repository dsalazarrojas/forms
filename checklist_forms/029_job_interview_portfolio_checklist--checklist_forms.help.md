# job_interview_portfolio_checklist - Help Guide
## Purpose
This form is a checklist for job interviews, used by internal staff to track and analyze various aspects of the hiring process. It helps in maintaining accurate and organized information about each candidate, interview, and evaluation process.

## How To Complete This Form

1. **Start by selecting the relevant information**: Choose the applicable fields according to your current task or requirement.
2. **Fill in each field**: Enter the required information for each selected field.
3. **Review and validate**: Double-check your entries before submitting the form to ensure accuracy and completeness.

## Field-by-Field Explanation
* **Job Application**: Enter the job application details, if applicable.
* **Interviewer**: Select one or more interviewers involved in the process.
* **Evaluation**: Enter the evaluation results or comments, if any.
* **Recommendations**: Provide any recommendations or suggestions for the candidate.
* **Job Status**: Select the current status of the job (Active, Inactive, or Pending).
* **Interview Rounds**: Enter the number of interview rounds conducted.
* **Candidate Comparisons**: Choose how easy, medium, or hard it was to compare candidates.
* **Evaluation Scores**: Enter the evaluation scores, if applicable.
* **Recommendation Scores**: Enter the recommendation scores, if applicable.
* **Rounds Score**: Enter the score for the interview rounds, if applicable.
* **Application Score**: Enter the score for the job application, if applicable.
* **Interviewer Score**: Enter the score for the interviewer, if applicable.
* **Evaluation Time**: Enter the time taken for evaluation, if applicable.
* **Recommendation Time**: Enter the time taken for recommendations, if applicable.
* **Application Time**: Enter the time taken for the job application, if applicable.
* **Candidate Time**: Enter the time taken by the candidate, if applicable.
* **Interview Time**: Enter the time taken for the interview, if applicable.
* **Rounds Time**: Enter the time taken for the interview rounds, if applicable.
* **Evaluation Notes**: Enter any notes or comments for the evaluation, if applicable.
* **Recommendation Notes**: Enter any notes or comments for the recommendations, if applicable.
* **Application Notes**: Enter any notes or comments for the job application, if applicable.
* **Interviewer Notes**: Enter any notes or comments for the interviewer, if applicable.
* **Candidate Notes**: Enter any notes or comments for the candidate, if applicable.
* **Rounds Notes**: Enter any notes or comments for the interview rounds, if applicable.
* **Interviewer Contact**: Enter any contact information for the interviewer, if applicable.

Note: This guide assumes that the internal staff is familiar with the form's purpose and fields. If there are any doubts or concerns, please refer to your supervisor or relevant department for further clarification.
