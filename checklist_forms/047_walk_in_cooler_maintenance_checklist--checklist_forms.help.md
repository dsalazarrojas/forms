# Walk In Cooler Maintenance Checklist - Help Guide
## Purpose

This form is designed to collect information about the condition of walk-in coolers and refrigeration systems in your facility. The purpose of this form is to help maintenance personnel and facility managers to efficiently identify issues and take corrective actions to maintain optimal cooling conditions.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the coolers that were checked during the maintenance routine.
2. Indicate whether the refrigeration system is working correctly or not.
3. Provide notes on any issues or observations about the coolers and refrigeration system.

## Field-by-Field Explanation

* **Coolers Checked** (Cooler A, Cooler B, Cooler C):
	+ Select the coolers that were checked during the maintenance routine. This field is required.
* **Coolers Checked Notes**:
	+ Provide any notes or comments about the coolers that were checked.
* **Refrigeration System Working Correctly**:
	+ Select 'True' if the refrigeration system is working correctly, 'False' if it is not, or 'Unknown' if you are unsure.
* **Refrigeration System Working Correctly Notes**:
	+ Provide any notes or comments about the refrigeration system's status.
* **Evaporator Coiled Tubes Clogged**:
	+ Select 'True' if the evaporator coiled tubes are clogged, 'False' if they are not, or 'Unknown' if you are unsure.
* **Evaporator Coiled Tubes Clogged Notes**:
	+ Provide any notes or comments about the evaporator coiled tubes' status.
* **Compressor Moldy Smell**:
	+ Select 'True' if there is a moldy smell from the compressor, 'False' if there is not, or 'Unknown' if you are unsure.
* **Compressor Moldy Smell Notes**:
	+ Provide any notes or comments about the compressor's status.
* **Drain System Clogged**:
	+ Select 'True' if the drain system is clogged, 'False' if it is not, or 'Unknown' if you are unsure.
* **Drain System Clogged Notes**:
	+ Provide any notes or comments about the drain system's status.

## Tips

* Please select 'Unknown' if you are unsure about any of the options.
* Be as detailed as possible when providing notes or comments for each field.
* This form is designed to be used in a refrigeration or cold storage facility. If you are using this form for a different purpose, please adjust the fields accordingly.
