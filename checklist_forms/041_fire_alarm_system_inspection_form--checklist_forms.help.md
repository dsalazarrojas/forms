# Fire Alarm System Inspection Form - Help Guide
## Purpose
The fire alarm system inspection form is used to gather information about the current status of the fire alarm system, including its description, location, and inspection results, to ensure the system is properly maintained and inspected regularly.


## How To Complete This Form

To complete this form, follow the steps above and provide the required information to ensure accuracy and completeness.


## Field-by-Field Explanation

* **Fire Alarm System Inspection Data** (`fire_alarm_system_inspection_form_data`): A brief description of the fire alarm system, if applicable.
* **Fire Alarm System Status** (`fire_alarm_system_status`): Select the current status of the fire alarm system from the options provided:
	+ Working: The system is currently functional and working properly.
	+ Inactive: The system is not currently functional or is not working properly.
	+ Removed: The system has been removed from the facility or building.
	+ Unknown: The status of the system is unknown or not reported.
* **Fire Alarm System Location** (`fire_alarm_system_location`): Select the location of the fire alarm system from the options provided:
	+ Building: The system is installed in a building.
	+ Building and System: The system is installed in a building and also has a system component.
	+ Electrical Room: The system is installed in an electrical room.
	+ Other: The system is installed in a different location.
* **Fire Alarm System Installed Date** (`fire_alarm_system_installed_date`): Enter the date when the fire alarm system was installed.
* **Fire Alarm System Inspection Frequency** (`fire_alarm_system_inspection_frequency`): Select the frequency of the fire alarm system inspections from the options provided:
	+ Daily
	+ Weekly
	+ Monthly
	+ Quarterly
	+ Semi-Annually
	+ Annually
* **Fire Alarm System Inspection Result** (`fire_alarm_system_inspection_result`): Select the result of the last inspection from the options provided:
	+ Passed: The system passed the inspection.
	+ Failed: The system failed the inspection.
	+ In Progress: There are ongoing issues or inspections in progress.
* **Fire Alarm System Inspection Date** (`fire_alarm_system_inspection_date`): Enter the date of the last inspection.
* **Fire Alarm System Inspection Time** (`fire_alarm_system_inspection_time`): Enter the time of the last inspection.
* **Fire Alarm System Inspection Notes** (`fire_alarm_system_inspection_notes`): Add any additional notes or comments about the inspection, such as issues found or tasks to be performed.
* **Fire Alarm System Inspection Comments** (`fire_alarm_system_inspection_comments`): Add any recommendations or comments about future improvements or actions to be taken.
