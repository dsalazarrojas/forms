> # Property Condition Checklist Form - Help Guide

## Purpose
This form is used to evaluate the condition of a property before and after various events or periods, such as lease start and end dates. It helps to gather information on the property's type, condition, and damage status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the property address.
2. Select the property type.
3. Choose the current property condition.
4. Select the tenant's possession status.
5. Choose the options that apply to the property's inside and outside condition.
6. Describe any damage to the property.
7. Provide contact information for the tenant and landlord.
8. Enter the lease start and end dates.
9. Add any comments or notes about the property.
10. Enter the property ID.

## Field-by-Field Explanation

* **Property Address**: Enter the address of the property being evaluated. This is a required field.
* **Property Type**: Select the type of property (e.g., residential, commercial, etc.). This is a required field.
* **Property Condition**: Describe the current condition of the property.
* **Inside Possession**: Select whether the property is currently in possession of the tenant or not. This is a required field.
* **Outside Possession**: Select the options that apply to the property's condition outside.
* **Damage Description**: Describe any damage to the property.
* **Inside Damage**: Select the option that best describes the inside damage.
* **Outside Damage**: Select the options that apply to the property's condition outside.
* **Damage Location**: Enter the location of the damage.
* **Tenant Contact**: Enter the contact information for the tenant.
* **Landlord Contact**: Enter the contact information for the landlord.
* **Date Start**: Enter the start date of the lease.
* **Date End**: Enter the end date of the lease.
* **Comments**: Add any additional comments or notes about the property.
* **Property ID**: Enter the ID of the property.
* **Tenant Status**: Select the status of the tenant (e.g., active, inactive, etc.). This is a required field.
* **Lease Start**: Enter the start date of the lease.
* **Lease End**: Enter the end date of the lease.
* **Notes**: Add any additional notes or comments about the property.
* **Property Status**: Select the status of the property (e.g., occupied, vacant, etc.). This is a required field.
* **Property Condition Before**: Describe the condition of the property before the current evaluation.
* **Property Condition After**: Describe the condition of the property after the current evaluation.
* **Tenant ID**: Enter the ID of the tenant.
* **Landlord ID**: Enter the ID of the landlord.
* **Property ID**: Enter the ID of the property.

By following these steps, you will be able to complete the Property Condition Checklist Form effectively and gather the necessary information for the property evaluation.
