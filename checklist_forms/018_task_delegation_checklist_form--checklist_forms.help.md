# Task Delegation Checklist Form - Help Guide

## Purpose
This form is used to collect and track information about task delegations, ensuring that all necessary details are captured accurately.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Review the form pages and sections carefully.
2. Select the relevant options for each field as instructed in the Field-by-Field Explanation section.
3. Ensure that all required fields are filled out before submitting the form.

## Field-by-Field Explanation
### Task Assignment Form
* **Task Assignment Form** (`assignment_form`, select_multiple, optional): This field is used to indicate whether a task has been assigned or not. Select 'Yes' if the task has been delegated to someone, or 'No' if it has not.

### Task Description
* **Task Description** (`task_description`, text, optional): This field is used to describe the task in detail, including any specific instructions or requirements. Enter a clear and concise description to ensure understanding.

### Assignee
* **Assignee** (`assignee`, select_one, optional): This field is used to select the person to whom the task has been assigned. Choose the relevant option from the list to indicate the assignee's status.

### Deadline
* **Deadline** (`deadline`, date, optional): This field is used to specify the task deadline. Enter the date by which the task should be completed.

### Priority
* **Priority** (`priority`, select_one, optional): This field is used to indicate the task's priority level. Select 'Yes' for high priority or 'No' for low priority.

### Status
* **Status** (`status`, select_one, optional): This field is used to indicate the task's status. Choose between 'Active' or 'Inactive' to reflect its current state.

### Due Date
* **Due Date** (`due_date`, date, optional): This field is used to specify the date by which the task is due. Enter the date to help track the task's progression.

### Task Status
* **Task Status** (`task_status`, select_one, optional): This field is used to select the task's status. Choose between 'Active' or 'Inactive' to reflect its current state.

### Assigned By
* **Assigned By** (`assigned_by`, select_one, optional): This field is used to indicate who assigned the task. Choose 'Yes' or 'No' to reflect the assigner's status.

### Assigned To
* **Assigned To** (`assigned_to`, select_one, optional): This field is used to select who the task is assigned to. Choose 'Yes' or 'No' to reflect the assignee's status.

Note: Some fields are optional, but it's essential to fill out all required fields before submitting the form.
