# Sewer Maintenance Workflow Checklist Form - Help Guide
## Purpose

This form is designed to collect and track information for sewer maintenance activities, ensuring that all relevant details are captured and stored accurately.

## How To Complete This Form

1.  Select one or more Work Orders related to the activity.
2.  Choose the appropriate Site Check category.
3.  Select one or more Safety Reviews relevant to the activity.
4.  Select one or more Files to be uploaded.
5.  Enter the specific tool or equipment used.
6.  Enter the date and time of creation or last update.
7.  Select the user who created or last updated the record.
8.  Provide any additional comments or tags.
9.  Enter a link to any additional files or tags.
10. Enter the date when the file was uploaded.
11. Enter the time when the file was uploaded.
12. Enter a brief description of the file.
13. Enter any additional tags.

## Field-by-Field Explanation

*   **Work Orders (Required)**: Select one or more relevant orders related to the sewer maintenance activity.
    *   This field is essential to track the work orders associated with the activity.
    *   Choose the orders that are most relevant to the maintenance activity.
*   **Site Checks (Optional)**: Choose the appropriate site check category.
    *   This field helps to categorize the site condition during the maintenance activity.
    *   Select 'Normal' for standard site conditions or 'Abnormal' for any unusual conditions.
*   **Safety Reviews (Optional)**: Select one or more relevant reviews related to the safety aspect of the sewer maintenance activity.
    *   This field helps to identify any safety concerns or issues during the maintenance activity.
    *   Select the reviews that are most relevant to the activity.
*   **Files Uploaded (Required)**: Select one or more files relevant to the sewer maintenance activity.
    *   This field is crucial to provide additional context or evidence for the activity.
    *   Choose the files that are most relevant to the maintenance activity.
*   **Assigned Tool (Optional)**: Enter the specific tool or equipment used for the sewer maintenance activity.
    *   This field helps to record the equipment used during the maintenance activity.
    *   Enter the tool or equipment that was used.
*   **Date Created/Updated (Optional)**: Enter the date and time when the record was created or last updated.
    *   This field helps to track the creation or last update of the record.
    *   Enter the date and time accurately.
*   **User Created/Updated (Optional)**: Select the user who created or last updated the record.
    *   This field helps to track the user responsible for the record.
    *   Choose the user who created or last updated the record.
*   **Comments/Tags (Optional)**: Provide any additional comments or tags relevant to the sewer maintenance activity.
    *   This field helps to add any additional context or information about the activity.
    *   Enter any comments or tags that are relevant.
*   **Files Link/Tags 2 (Optional)**: Enter a link to any additional files or tags that are relevant to the activity.
    *   This field helps to provide additional context or evidence for the activity.
    *   Enter the link to any additional files or tags.
*   **File Uploaded Date 2/Time 2 (Optional)**: Enter the date and time when the additional file was uploaded.
    *   This field helps to track the upload of additional files.
    *   Enter the date and time accurately.
*   **File Description (Optional)**: Enter a brief description of the uploaded file.
    *   This field helps to provide additional context about the file.
    *   Enter a brief description.
*   **Tags 2 (Optional)**: Enter any additional tags relevant to the activity.
    *   This field helps to add any additional context or information about the activity.
    *   Enter any tags that are relevant.

## Tips

*   Ensure that all required fields are completed accurately and thoroughly.
*   Review the form carefully before submission to avoid errors.
*   Use the form to maintain a comprehensive record of sewer maintenance activities.
