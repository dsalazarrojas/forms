# Sports Event Preparation Checklist Form - Help Guide
## Purpose
This form is designed to guide event organizers in preparing for a sports event by providing a comprehensive checklist of essential details.

## How To Complete This Form
1. To begin, select the "Event Status" to indicate whether the event is active or inactive.
2. Enter the event's "Event Date" and "Event Start Time" in the respective fields.
3. Provide the "Contact Information" for the event organizer.
4. Enter the number of participants and their "Participant Gender" and "Participant Age Groups" in the respective fields.
5. Enter the "Event Budget" and "Event Fees" for the event.
6. If applicable, enter "Venue Cost" and "Participant Fees".
7. Select the "Event Type" as "Sports" or "Non-Sports".
8. Finally, review all fields to ensure accuracy and completeness.

## Field-by-Field Explanation
* **Event Details**
	+ **Event Details**: Enter a brief description of the event.
	+ **Organizer Details**: Provide the contact information for the event organizer.
	+ **Event Date**: Enter the date of the sports event in the required format (DD/MM/YYYY).
	+ **Event Start Time**: Enter the start time of the sports event in the required format (HH:MM).
	+ **Location Details**: Enter a brief description of the event location.
* **Participant Details**
	+ **Participant Details**: Enter a brief description of the participants.
	+ **Participant Number**: Enter the number of participants for the event.
	+ **Participant Gender**: Select the participant gender(s) applicable to the event.
	+ **Participant Age Groups**: Select the age group(s) applicable to the event.
* **Financial Details**
	+ **Event Budget**: Enter the budget allocated for the event.
	+ **Event Fees**: Enter the fees applicable to participants.
	+ **Venue Cost**: Enter the cost for the venue (if applicable).
	+ **Participant Fees**: Enter the participant fees (if applicable).

## Tips
- Double-check all fields for accuracy and completeness before submitting the form.
- Review all fields regularly to ensure the information is up-to-date.
- Ensure that all required fields are filled before submitting the form.
