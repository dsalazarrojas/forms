# Vintage Item Condition Checklist - Help Guide

## Purpose
This form is used to gather information about the condition and details of a vintage item being assessed. The form helps to categorize and evaluate the item's condition, material, rarity, price range, and other relevant attributes. This data is vital for collectors, dealers, and enthusiasts to make informed decisions when buying, selling, or trading vintage items.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the item's details in the **Item Details** text field.
2. Select the item's **Condition** by choosing from the provided options (a, b, c, or d).
3. Choose the item's **Material** from the available options (e, f, g, or h).
4. Select the item's **Rarity** by choosing multiple options from the list (i, j, or k).
5. Enter the item's **Damage** level using the numerical field.
6. Choose the item's **Price Range** from the available options (l, m, or o).
7. Select the item's **Certification** from the available options (p or q).

## Field-by-Field Explanation
* **Item Details** (item_details, text, optional): Enter a brief description of the vintage item, including its name, maker, and any notable features or characteristics.
* **Condition** (condition, select_one, optional): Select the item's condition, which can be:
	+ item a: Excellent
	+ item b: Very Good
	+ item c: Fair
	+ item d: Poor
* **Material** (material, select_one, optional): Choose the item's material, which can be:
	+ item e: Wood
	+ item f: Metal
	+ item g: Glass
	+ item h: Plastic
* **Rarity** (rarity, select_multiple, optional): Select the item's rarity, which can be:
	+ item i: Common
	+ item j: Uncommon
	+ item k: Rare
* **Damage** (damage, number, optional): Enter the item's damage level, using numbers to indicate the extent of wear or deterioration.
* **Price Range** (price_range, select_one, optional): Choose the item's price range, which can be:
	+ item l: Low
	+ item m: Medium
	+ item n: High
	+ item o: Very High
* **Certification** (certification, select_one, optional): Select the item's certification, which can be:
	+ item p: Certified
	+ item q: Uncertified

## Tips
- Make sure to enter accurate and truthful information to ensure the item's condition and details are assessed correctly.
- If unsure about any field, consult with an expert or refer to relevant documentation for guidance.
- This form is meant to be a tool for evaluation and categorization; the form data does not guarantee the item's authenticity or value.
