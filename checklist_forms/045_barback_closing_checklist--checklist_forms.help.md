# Barback Closing Checklist - Help Guide
## Purpose
This form is a checklist for barbacks to complete before closing their shifts. It ensures that all tasks are completed and the bar area is properly cleaned and prepared for the next shift.

## How To Complete This Form

1. Fill out the form on your device or computer.
2. Complete each field carefully and accurately.
3. Make sure to review the form before submitting it.

## Field-by-Field Explanation

* **Checklist Date** (1): This field is used to record the date of the shift closing.
* **Shift End Time** (2): Enter the time your shift ended.
* **Barback Name** (3): Enter your name.
* **Manager on Duty** (4): Enter the name of your supervisor or manager on duty.
* **Bar Section/Station** (5): Enter the name of the bar section or station you were responsible for.
* **Dirty Glasses Collected** (6): Select how many dirty glasses were collected.
	+ Yes - All Collected: All glasses were collected and put away.
	+ Yes - Mostly Collected: Most glasses were collected, but some remain.
	+ Some Still Remaining: Some glasses were not collected.
	+ No - Not Done: Glasses were not collected.
* **Glass Washer Emptied and Cleaned** (7): Select if the glass washer was emptied and cleaned.
	+ True: The glass washer was emptied and cleaned.
	+ False: The glass washer was not emptied and cleaned.
	+ In Progress: The glass washer was in the process of being emptied and cleaned.
* **Empty Bottles Removed** (8): Select if all empty bottles were removed.
	+ Yes - All Removed: All empty bottles were removed.
	+ Mostly Removed: Most empty bottles were removed, but some remain.
	+ Some Remaining: Some empty bottles were not removed.
	+ Not Done: Empty bottles were not removed.
* **Bar Sink Cleaned and Sanitized** (9): Select if the bar sink was properly cleaned and sanitized.
	+ Yes - Thoroughly: The bar sink was thoroughly cleaned and sanitized.
	+ Yes - Adequately: The bar sink was adequately cleaned and sanitized.
	+ Partial: The bar sink was partially cleaned and sanitized.
	+ False: The bar sink was not cleaned and sanitized.
* **Bar Counter Wiped Down** (10): Select if the bar counter was properly wiped down.
	+ Yes - Thoroughly: The bar counter was thoroughly wiped down.
	+ Yes - Adequately: The bar counter was adequately wiped down.
	+ Partial: The bar counter was partially wiped down.
	+ False: The bar counter was not wiped down.
* **Beer Taps Cleaned** (11): Select if the beer taps were properly cleaned.
	+ True: The beer taps were cleaned.
	+ False: The beer taps were not cleaned.
	+ Not Applicable: The beer taps do not apply to your area.
* **Ice Bin Emptied and Cleaned** (12): Select if the ice bin was properly emptied and cleaned.
	+ True: The ice bin was emptied and cleaned.
	+ False: The ice bin was not emptied and cleaned.
	+ Partial: The ice bin was partially emptied and cleaned.
* **Fresh Ice for Next Shift Added** (13): Select if fresh ice was added for the next shift.
	+ True: Fresh ice was added.
	+ False: Fresh ice was not added.
	+ Not Needed: No ice was needed for the next shift.
* **Cutting Board Sanitized** (14): Select if the cutting board was properly sanitized.
	+ True: The cutting board was sanitized.
	+ False: The cutting board was not sanitized.
	+ Not Applicable: The cutting board does not apply to your area.
* **Garnishes Removed** (15): Select if garnishes (limes, lemons, etc.) were properly removed.
	+ Yes - All Removed: All garnishes were removed.
	+ Mostly Removed: Most garnishes were removed, but some remain.
	+ Some Remaining: Some garnishes were not removed.
	+ False: Garnishes were not removed.
* **Trash Emptied and Replaced** (16): Select if trash was properly emptied and replaced.
	+ True: The trash was emptied and replaced.
	+ False: The trash was not emptied and replaced.
	+ Partial: The trash was partially emptied and replaced.
* **Floor Swept and Mopped** (17): Select if the floor was properly swept and mopped.
	+ Yes - Thoroughly Mopped: The floor was thoroughly swept and mopped.
	+ Yes - Swept: The floor was properly swept, but not mopped.
	+ Partial: The floor was partially swept and mopped.
	+ False: The floor was not swept and mopped.
* **Bar Stools Cleaned** (18): Select if the bar stools were properly cleaned.
	+ True: The bar stools were cleaned.
	+ False: The bar stools were not cleaned.
	+ Partial: The bar stools were partially cleaned.
* **Equipment Checked and Shut Down** (19): Select if all equipment was properly checked and shut down.
	+ Yes - All Off: All equipment was checked and shut down.
	+ Yes - Most Off: Most equipment was checked and shut down, but some remain on.
	+ Some Still On: Some equipment was not checked and shut down.
	+ Not Checked: Equipment was not checked and shut down.
* **Supplies Restocked** (20): Select if supplies were properly restocked.
	+ Yes - Fully Stocked: All supplies were restocked.
	+ Partially Stocked: Most supplies were restocked, but some remain.
	+ Not Restocked: No supplies were restocked.
* **Inventory Needs Updated** (21): Select if the inventory needs to be updated.
	+ Yes: The inventory needs to be updated.
	+ No: The inventory does not need to be updated.
	+ Some Items Low: Some items need to be restocked or reordered.
* **Bar Area Secured** (22): Select if the bar area was properly secured.
	+ Yes - All Secured: The bar area was thoroughly secured.
	+ Mostly Secured: Most of the bar area was secured, but some remain open.
	+ Needs Attention: Some areas of the bar area were not secured.
	+ False: The bar area was not secured.
* **Any Issues or Damage Noted** (23): This is a text field for any issues or damage noticed during the shift.
* **Closing Tasks Complete** (24): Select if all closing tasks were completed.
	+ Fully Complete: All closing tasks were completed.
	+ Mostly Complete: Most closing tasks were completed, but some remain.
	+ Partially Complete: Some closing tasks were not completed.
	+ Not Complete: Closing tasks were not completed.
