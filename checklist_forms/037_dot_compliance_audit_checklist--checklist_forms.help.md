# dot_compliance_audit_checklist - Help Guide
## Purpose
This form is designed to conduct a dot-compliance audit checklist for vehicles, assessing their condition and standards.
## How To Complete This Form
To complete this form, follow these steps:

1. Select all the options that apply to the vehicle from the "Vehicle Checklist" field.
2. Enter the number of drivers who will be operating the vehicle in the "Driver Information" field.
3. Provide any additional information about the vehicle's condition in the "Vehicle Inspection" field.
4. Answer "Yes" or "No" to indicate if the vehicle has a history of accidents.
5. Select all the options that apply to the vehicle from the "Vehicle Condition", "Safety Equipment", "Vehicle Maintenance", "Driver Training", and "Vehicle Inspection Certificate" fields.
6. Indicate if the vehicle has a history of accidents, and select all the options that apply from the "Accident Reporting" field.
7. Select all the options that apply from the "Corrective Action" field.

## Field-by-Field Explanation
* **Vehicle Checklist** (`vehicle_checklist`, `select_multiple`, required: false): Select all the options that apply to the vehicle.
* **Driver Information** (`driver_info`, `number`, required: false): Enter the number of drivers who will be operating the vehicle.
* **Vehicle Inspection** (`vehicle_inspection`, `text`, required: false): Provide any additional information about the vehicle's condition.
* **Accident History** (`accident_history`, `select_one`, required: false): Answer "Yes" or "No" to indicate if the vehicle has a history of accidents.
* **Vehicle Condition** (`vehicle_condition`, `select_multiple`, required: false): Select all the options that apply to the vehicle.
* **Safety Equipment** (`safety_equipment`, `select_multiple`, required: false): Select all the options that apply to the vehicle.
* **Vehicle Maintenance** (`vehicle_maintenance`, `select_multiple`, required: false): Select all the options that apply to the vehicle.
* **Driver Training** (`driver_training`, `select_multiple`, required: false): Select all the options that apply to the vehicle.
* **Vehicle Inspection Certificate** (`vehicle_inspection_cert`, `select_multiple`, required: false): Select all the options that apply to the vehicle.
* **Accident Reporting** (`accident_reporting`, `select_multiple`, required: false): Indicate if the vehicle has a history of accidents and select all the options that apply.
* **Corrective Action** (`corrective_action`, `select_multiple`, required: false): Select all the options that apply from the vehicle.

## Tips
- Make sure to fill out all the fields that apply to the vehicle.
- Be specific and accurate when answering the questions.
