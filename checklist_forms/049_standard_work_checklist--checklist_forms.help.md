# Standard Work Checklist - Help Guide
## Purpose
This form is a checklist for recording task completion and dates for up to 9 shifts.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Select one of the options from each task field for the corresponding shift.
2. Enter notes for each shift if necessary.
3. Enter the date for each shift if necessary.
