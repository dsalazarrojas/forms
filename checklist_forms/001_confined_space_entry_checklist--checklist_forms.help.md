# Confined Space Entry Checklist - Help Guide

## Purpose
This help guide is designed to assist users in filling out the Confined Space Entry Checklist form. The form is used to ensure a safe and controlled confined space entry by collecting and verifying crucial information about the space, personnel, and equipment.

## How To Complete This Form
1. Read each section carefully and fill out the required fields.
2. Ensure you have all necessary information and documentation before proceeding.
3. Enter the required details for each field, including supervisor's and attendant's information.
4. Verify and confirm that you have checked all the necessary boxes and fields.

## Field-by-Field Explanation

* **Entry Supervisor Name** (1, text, required):
	+ Enter the name of the person authorizing and overseeing the entry.
* **Entry Date** (2, date, required):
	+ Enter the date of the confined space entry.
* **Entry Time** (3, time, required):
	+ Enter the time of entry into the confined space.
* **Confined Space Location** (4, text, required):
	+ Enter the specific location or identifier of the confined space.
* **Space Description** (5, text, required):
	+ Enter a brief description of the confined space.
* **Atmospheric Testing Required** (6, select_one, required):
	+ Select 'True' if atmospheric testing is needed before entry.
* **Oxygen Level Check Completed** (7, select_one, required):
	+ Select 'Yes - Within Range' if oxygen levels are between 19.5% and 23.5%.
* **Flammable Gases Check** (8, select_one, required):
	+ Select 'None Detected' if no flammable gases or vapors are detected.
* **Toxic Contaminants Check** (9, select_one, required):
	+ Select 'None Detected' if no toxic substances like CO H2S are detected.
* **Ventilation Required** (10, select_one, required):
	+ Select 'Yes - Continuous' if mechanical ventilation is required.
* **Ventilation Equipment Checked** (11, select_one, required):
	+ Select 'True' if ventilation equipment is functional.
* **Isolation and Lockout Completed** (12, select_one, required):
	+ Select 'True' if all energy sources are isolated and locked out.
* **Rescue Equipment Available** (13, select_one, required):
	+ Select 'Yes - All Available' if all rescue equipment is available.
* **Attendant Assigned** (14, select_one, required):
	+ Select 'True' if a trained attendant is stationed outside the space.
* **Attendant Name** (15, text, required):
	+ Enter the name of the assigned attendant.
* **Authorized Entrants List** (16, text, required):
	+ Enter the names of all personnel entering the space.
* **Personal Protective Equipment Required** (17, select_multiple, required):
	+ Select all necessary PPE for the entry, such as Hard Hat, Safety Glasses, Respirator, etc.
* **Communication Method** (18, select_one, required):
	+ Select the method of communication with the attendant, such as Voice, Radio, etc.
* **Adequate Lighting Provided** (19, select_one, required):
	+ Select 'True' if the lighting is sufficient for the work to be performed.
* **Emergency Plan Reviewed** (20, select_one, required):
	+ Select 'True' if all personnel have been briefed on emergency procedures.
* **Entry Permit Issued** (21, select_one, required):
	+ Select 'True' if the confined space entry permit has been issued.
* **Permit Number** (22, text, required):
	+ Enter the permit identification number.
* **Additional Hazards Identified** (23, text, optional):
	+ List any other hazards not covered above.
* **Supervisor Signature** (24, text, required):
	+ Enter the supervisor's electronic or printed name.
* **Entry Approved** (25, select_one, required):
	+ Select 'Approved - Proceed with Entry' to authorize the entry.
