# Property Listing Evaluation Checklist - Help Guide
## Purpose
The Property Listing Evaluation Checklist form is designed to collect information about a property listing evaluation. 

## How To Complete This Form

To complete this form, follow the instructions below:

* Select the appropriate options for the following fields:
	+ **Property Listing Evaluation Checklist**: This field is a dropdown menu that allows you to select whether the property meets the evaluation criteria.
	+ **Property Address**: This field is a text box where you can enter the property's address.
	+ **Property Type**: This field is a dropdown menu where you can select the type of property.
	+ **Property Description**: This field is a text box where you can enter the property's description.
	+ **Listing Agent**: This field is a dropdown menu where you can select whether the listing agent is involved.
	+ **Property Status**: This field is a dropdown menu where you can select the property's status.
	+ **Property Condition**: This field is a dropdown menu where you can select the property's condition.
	+ **Property Price**: This field is a number input box where you can enter the property's price.
	+ **Property Area**: This field is a text box where you can enter the property's area.
	+ **Property Age**: This field is a number input box where you can enter the property's age.
	+ **Listing Agency**: This field is a text box where you can enter the listing agency's name.
	+ **Property Manager**: This field is a text box where you can enter the property manager's name.
	+ **Evaluation Date**: This field is a date input box where you can select the evaluation date.
	+ **Evaluated By**: This field is a text box where you can enter the person's name who evaluated the property.
