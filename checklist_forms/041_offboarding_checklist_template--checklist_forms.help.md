# offboarding_checklist_template - Help Guide
## Purpose
This form is a comprehensive checklist for offboarding employees from the company, ensuring that all necessary steps are taken to finalize their departure.

## How To Complete This Form

1. Fill out the form completely and accurately, providing all required information.
2. Review each field carefully to ensure that you are capturing the correct details.
3. Use this form as a template for offboarding processes, updating fields as needed to suit individual employee circumstances.

## Field-by-Field Explanation

### Company Information
* **Company Information** (`company_info`, text, required): Enter the company's name, including any subsidiaries or departments the employee was part of.

* **Reason for Offboarding** (`reason_for_offboarding`, text, required): Provide a clear and concise explanation for the employee's offboarding.

* **Date of Last Login** (`date_last_login`, date, required): Record the date of the employee's last login to the system.

* **Last Day of Work** (`last_day_of_work`, date, required): Note the last day the employee worked for the company.

* **Notice Period** (`notice_period`, number, required): Specify the number of days' notice provided to the employee.

* **Reason for Leaving** (`reason_for_leaving`, text, required): Provide a clear and concise explanation for the employee's reason for leaving the company.

### Asset Management
* **Company Assets** (`company_assets`, select multiple, optional): Identify which company assets the employee will be returning (e.g., Laptop, Smartphone, Other).
* **Asset Return Date** (`asset_return_date`, date, optional): Record the date the employee plans to return the asset.
* **Asset Return Status** (`asset_return_status`, select one, required): Confirm whether the asset has been returned or not.
* **Asset Return Condition** (`asset_return_condition`, select multiple, optional): Describe the condition of the returned asset (e.g., Excellent, Fair, Poor).
* **Asset Return Method** (`asset_return_method`, select one, optional): Specify how the asset was returned (e.g., Mail, Courier, Other).
* **Asset Return Details** (`asset_return_details`, text, optional): Record any additional details about the asset return.
* **Asset Returned** (`asset_returned`, select one, required): Confirm whether the asset has been returned or not.
* **Asset Return Date Details** (`asset_return_date_details`, text, optional): Record any additional details about the asset return date.

### Employee Information
* **Employee ID** (`employee_id`, number, required): Record the employee's ID number.
* **Email Address** (`email_address`, email, required): Provide the employee's current email address.
* **Contact Number** (`contact_number`, text, required): Record the employee's contact number.
* **Address** (`address`, text, optional): Note the employee's current or last known address.
* **Manager Information** (`manager_info`, text, optional): Record any relevant information from the employee's manager.
* **Team Information** (`team_info`, text, optional): Record any relevant information from the team the employee was part of.

### Status and Finalization
* **Offboarding Form Status** (`offboarding_form_status`, select one, required): Confirm the status of the offboarding process (e.g., Completed, In Progress, Incomplete).
* **Offboarding Date** (`offboarding_date`, date, required): Record the date of the offboarding process completion.
* **Reason for Offboarding Details** (`reason_for_offboarding_details`, text, required): Provide additional details for the reason for offboarding.
* **Asset Status** (`asset_status`, select one, required): Confirm the current status of company assets (e.g., In Use, In Warehouse, Missing).
* **Asset Condition** (`asset_condition`, select multiple, optional): Describe the condition of company assets (e.g., Excellent, Fair, Poor).
* **Offboarding Date Details** (`offboarding_date_details`, text, optional): Record any additional details about the offboarding date.

## Tips

* Use this form in conjunction with the company's offboarding process and procedure.
* Ensure that all necessary fields are completed and accurate to finalize the offboarding process.
* Review and update the form regularly to ensure that all relevant information is captured.
* Use this form as a template for future offboarding processes, tailoring it to suit individual employee circumstances.
