# Galaxy Themed Event Checklist Form - Help Guide
## Purpose
The Galaxy Themed Event Checklist Form is a crucial tool for event organizers to gather and store information about their events. This form is designed to collect the most critical details about an event, making it an essential part of the event planning process.

## How To Complete This Form
To complete the form, follow these steps:

1. Fill in the required fields: **event_name**, **event_date**, **event_time**, **event_location**, **event_organizer**, **event_budget**, **event_status**, **event_email**, and **event_address**. These fields are marked as required, meaning you cannot save the form without filling them in.
2. For fields that are not required (e.g., **event_details**, **event_notes**, and **event_participants**), you can provide as much information as you need.
3. Ensure the **event_status** field matches the actual status of your event.
4. Review and double-check your entries to ensure accuracy before submission.

## Field-by-Field Explanation

*   **event_name** (text, required): The name of the event. This is a text field where you can type in the name of your event, e.g., "Galactic Gathering."
*   **event_date** (date, required): The date of the event. Use the calendar icon to select the date.
*   **event_time** (time, required): The time of the event. Use the time picker to select the time.
*   **event_location** (text, required): The location of the event. This can be a physical address or a virtual location.
*   **event_organizer** (text, required): The person or organization responsible for the event.
*   **event_budget** (number, required): The budget allocated for the event.
*   **event_status** (select_one, required): The current status of the event. Choose from the options: Active, Inactive, or Cancelled.
*   **event_notes** (text, optional): Additional notes about the event. This field is not required, so you can leave it blank if you don't have any notes.
*   **event_participants** (select_multiple, optional): List the participants of the event. You can select multiple participants from the options provided.
*   **event_email** (email, required): The email address of the event organizer or contact person.
*   **event_phone** (text, optional): The phone number of the event organizer or contact person.
*   **event_address** (text, required): The physical address of the event location.
*   **event_capacity** (number, optional): The maximum capacity of the event.
*   **event_details** (text, optional): Additional details about the event, such as the event description or any specific requirements.
