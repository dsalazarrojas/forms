# hiring-procedure-checklist - Help Guide

## Purpose
This form is a checklist for the hiring procedure, helping hiring managers and their assistants to make informed decisions about candidate selection.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the options for each field and select the relevant ones for your hiring process.
2. Answer each question honestly and accurately, using the options provided.
3. Make sure to review the form carefully before submitting it, ensuring that all necessary steps are taken.

## Field-by-Field Explanation

* **Hiring Procedure Checklist** (1, text, required/optional): This field is a brief introduction to the form, reminding users of the purpose and importance of the hiring procedure.
* **Candidate Interview** (2, select_one, required/optional): This field allows you to select the type of interview you conducted with the candidate, either phone, email, or in-person.
* **Background Checks** (3, select_multiple, required/optional): This field enables you to verify the candidate's employment history, education, and personal references. Select all relevant checks that were performed.
* **Reference Checks** (4, select_multiple, required/optional): This field allows you to select the type of reference checks performed, such as professional or personal references.
* **Hiring Manager Approval** (5, select_one, required/optional): This field requires the hiring manager to approve or reject the candidate.
* **Candidate Offer** (6, select_one, required/optional): This field allows you to select whether the candidate accepted or declined the offer.
* **Candidate Start Date** (7, date, required/optional): This field is used to record the candidate's start date, if applicable.
* **Candidate End Date** (8, date, required/optional): This field is used to record the candidate's end date, if applicable.
* **Hiring Manager Comments** (9, note, required/optional): This field is for the hiring manager to provide comments on the hiring decision.
* **Assistant Comments** (10, note, required/optional): This field is for the assistant to provide comments on the hiring decision.
* **Candidate Comments** (11, note, required/optional): This field is for the candidate to provide comments on the hiring decision.
* **Hiring Decision** (12, select_one, required/optional): This field requires the hiring manager to make a final decision, either to hire or decline the candidate.
* **Assistant Hiring Manager Comments** (13, note, required/optional): This field is for the assistant hiring manager to provide comments on the hiring decision.
* **Assistant Hiring Decision** (14, select_one, required/optional): This field requires the assistant hiring manager to make a final decision, either to hire or decline the candidate.

## Tips
- Make sure to review the form carefully before submitting it, ensuring that all necessary steps are taken.
- Use the options provided to select the relevant information for your hiring process.
- Keep the form up to date and accurate to ensure the hiring process runs smoothly.
