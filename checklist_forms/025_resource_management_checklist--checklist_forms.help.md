# resource_management_checklist - Help Guide
## Purpose
The purpose of this form is to collect information about the management of resources. It is used to gather data on resource allocation, utilization, and availability.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer each question carefully and accurately.
2. Select the correct response for each field based on the available options.
3. Enter any relevant comments or notes in the space provided.

## Field-by-Field Explanation

* **project_details** (`project_details`, `text`, optional): Enter a brief description of the resource being managed.
* **resource_types** (`resource_types`, `select_one`, optional): Select `Yes` if the resource is a type that is typically managed by the resource management process, or `No` if it is not.
* **allocated_resources** (`allocated_resources`, `select_multiple`, optional): Select one or more resources that are currently allocated to the project.
* **resource_utilization** (`resource_utilization`, `number`, optional): Enter the number of resources currently being utilized.
* **resource_requests** (`resource_requests`, `time`, optional): Enter the time when the resource request was made.
* **resource_availability** (`resource_availability`, `number`, optional): Enter the total number of resources available.
* **resource_usage_status** (`resource_usage_status`, `select_one`, optional): Select `Active` if the resource is currently being used, or `Inactive` if it is not.
* **notes** (`notes`, `note`, optional): Enter any additional comments or notes about the resource.
* **contact_info** (`contact_info`, `email`, optional): Enter the contact information for the person responsible for managing the resource.
* **phone_number** (`phone_number`, `text`, optional): Enter the phone number for the person responsible for managing the resource.
* **allocated_budget** (`allocated_budget`, `number`, optional): Enter the budgeted amount for the resource.
* **budgeted** (`budgeted`, `number`, optional): Enter the budgeted amount for the resource.
* **actual_cost** (`actual_cost`, `number`, optional): Enter the actual cost of the resource.
* **resource_status** (`resource_status`, `select_one`, optional): Select `Active` if the resource is currently being managed, or `Inactive` if it is not.
* **resource_request_date** (`resource_request_date`, `date`, optional): Enter the date when the resource request was made.
* **resource_request_time** (`resource_request_time`, `time`, optional): Enter the time when the resource request was made.
* **resource_request_duration** (`resource_request_duration`, `text`, optional): Enter the duration of the resource request.
* **resource_availability_date** (`resource_availability_date`, `date`, optional): Enter the date when the resource became available.
* **resource_availability_time** (`resource_availability_time`, `time`, optional): Enter the time when the resource became available.
* **resource_availability_duration** (`resource_availability_duration`, `text`, optional): Enter the duration of the resource's availability.
* **resource_allocation_status** (`resource_allocation_status`, `select_one`, optional): Select `Active` if the resource is currently allocated, or `Inactive` if it is not.
* **allocated_resources_status** (`allocated_resources_status`, `select_multiple`, optional): Select one or more resources that are currently allocated.
* **resource_usage_status** (`resource_usage_status`, `select_one`, optional): Select `Active` if the resource is currently being used, or `Inactive` if it is not.

## Tips
* Please answer each question carefully and accurately.
* If you are unsure about any information, contact the person responsible for managing the resource for clarification.
* This form is for official use only and is subject to data retention and security policies.
