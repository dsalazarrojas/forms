# data_verification_checklist - Help Guide
## Purpose
The "data_verification_checklist" form is a tool used to assess the accuracy and verification status of entries. It is designed to gather information about the verification process and accuracy standards related to a specific entry.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by selecting the "Verify Entry" field, which is the first page of the form.
2. Enter the relevant information in the "Verify Entry" field.
3. On the second page, select the accuracy standard for the entry from the options provided in the "Check Accuracy" field.
4. Choose the verification status for the entry from the options in the "Verification Status" field.
5. You can optionally select multiple accuracy standards if required.

## Field-by-Field Explanation
* **Verify Entry** (`1`, `text`, required/optional): Enter the entry that you want to verify or check.
* **Check Accuracy** (`2`, `select_multiple`, required/optional):
	+ Select the accuracy standard for the entry: "Correct" or "Inaccurate".
* **Verification Status** (`3`, `select_one`, required/optional):
	+ Choose the status of the verification: "Verified", "Unverified", or "Partially Verified".

## Tips
* Make sure to carefully select the accuracy standard and verification status based on your evaluation.
* If the entry is partially verified, provide a brief explanation for the discrepancy.
* If you have any questions or concerns, contact [form@gic.mx](mailto:form@gic.mx) for assistance.
