# Dot Inspection Form - Help Guide
## Purpose
The Dot Inspection Form is a template used for collecting information about a vehicle's condition and history. It's designed to gather data for regular inspections or evaluations, which can be used for various purposes such as damage assessments, insurance, or workflow analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **General Info** section with any relevant details about the vehicle.
2. Select the **vehicle_make** field with the correct make of the vehicle (e.g. Dodge, Ford, Honda, etc.).
3. Enter the **vehicle_year** (the year the vehicle was manufactured).
4. Enter the **vehicle_model** (the specific model of the vehicle, e.g. Mustang, Camry, Accord, etc.).
5. Select the **vehicle_license_number** field with the correct state or region where the vehicle is registered (e.g. US, CA, AZ, etc.).
6. Enter the **mileage_miles** field with the current mileage of the vehicle.
7. Select the **engine_condition** field with the current condition of the vehicle's engine (e.g. Excellent, Good, Fair, Poor).
8. Select the **brake_condition** field with the current condition of the vehicle's brakes (e.g. Excellent, Good, Fair, Poor).
9. Select the **tire_condition** field with the current condition of the vehicle's tires (e.g. Excellent, Good, Fair, Poor).
10. Select the **battery_status** field with the current status of the vehicle's battery (e.g. Excellent, Good, Fair, Poor).
11. Enter the **vehicle_inspection_date** field with the date of the most recent inspection or evaluation.
12. Add any additional **notes** about the vehicle in the **notes** field, if necessary.

## Field-by-Field Explanation

* **General Info** (1, text, required: false): This is the general information section where you can enter any relevant details about the vehicle.
* **vehicle_make** (2, select_one, required: false): Select the make of the vehicle from the provided options (e.g. Dodge, Ford, Honda, etc.).
* **vehicle_year** (3, number, required: false): Enter the year the vehicle was manufactured.
* **vehicle_model** (4, text, required: false): Enter the specific model of the vehicle (e.g. Mustang, Camry, Accord, etc.).
* **vehicle_license_number** (5, select_multiple, required: false): Select the state or region where the vehicle is registered from the provided options (e.g. US, CA, AZ, etc.).
* **mileage_miles** (6, number, required: false): Enter the current mileage of the vehicle.
* **engine_condition** (7, select_one, required: false): Select the current condition of the vehicle's engine (e.g. Excellent, Good, Fair, Poor).
* **brake_condition** (8, select_one, required: false): Select the current condition of the vehicle's brakes (e.g. Excellent, Good, Fair, Poor).
* **tire_condition** (9, select_one, required: false): Select the current condition of the vehicle's tires (e.g. Excellent, Good, Fair, Poor).
* **battery_status** (10, select_one, required: false): Select the current status of the vehicle's battery (e.g. Excellent, Good, Fair, Poor).
* **vehicle_inspection_date** (11, date, required: false): Enter the date of the most recent inspection or evaluation.
* **notes** (12, note, required: false): Add any additional notes about the vehicle.
