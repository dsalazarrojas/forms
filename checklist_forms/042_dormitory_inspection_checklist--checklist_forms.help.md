# Dormitory Inspection Checklist - Help Guide
## Purpose
This form is used to assess the condition of a dormitory room and record any issues or observations.

## How To Complete This Form
1. Enter the room number of the dormitory room you are inspecting.
2. Select the current status of the room from the options.
3. Enter any comments or observations about the room's condition.
4. Record any additional notes or comments about the room.
5. Select the date the room was visited.

## Field-by-Field Explanation
* **room_number**: Enter the number of the room you are inspecting.
* **room_status**: Select the current status of the room from the options: good, maintenance required, not visited, or not checked.
* **room_condition**: Enter any comments or observations about the room's condition. This field is free-text, so you can describe any issues or concerns you have about the room.
* **notes**: Enter any additional notes or comments about the room. This field is also free-text, so you can include any other information you think is relevant.
* **date_visited**: Select the date the room was visited. Please enter the date in the correct format (YYYY-MM-DD).

## Tips
- Make sure to be thorough and accurate when inspecting the room and filling out this form.
- If you're unsure about a room's status or condition, it's always better to err on the side of caution and select "not visited" or "not checked" to flag the issue for further review.
- Don't forget to enter the date you visited the room for reference and record-keeping purposes.
