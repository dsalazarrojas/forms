# # Personal Cyber Security Checklist - Help Guide

## Purpose
This form helps you assess and improve your online security practices by covering various aspects of cyber security, including user information, password strength, security questions, two-factor authentication, sensitive data, security questions, account activity, password expiration, 2 factor backup, sensitive data backup, account recovery, account lockout, account notifications, and password change.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and answer truthfully based on your current online security practices.
2. For each field, select the correct option that best describes your situation.
3. Ensure you complete each field accurately and comprehensively.
4. Use the provided options to guide you through the process.

## Field-by-Field Explanation

* **User Information** (id: 1, required: false): Provide your name, email address, and contact information. This field helps us understand your online persona and context.
* **Password Strength** (id: 2, required: false): Describe your current password strength. Is it more than 12 characters long? Do you use a password manager?
* **Security Question** (id: 3, required: false): Select one or more security questions from the provided options. These questions help you think critically about potential security risks.
* **Two-Factor** (id: 4, required: false): Select two or more two-factor authentication methods. This ensures you're using multiple verification methods to protect your accounts.
* **Sensitive Data** (id: 5, required: false): Select any sensitive data you've shared online. This helps us understand your exposure to potential security risks.
* **Security Questions** (id: 6, required: false): Select one or more security questions from the provided options. These questions help you think critically about potential security risks.
* **Account Activity** (id: 7, required: false): Provide information about your account activity, including login frequency and recent login locations.
* **Password Expiration** (id: 8, required: false): Select when your password expires. This helps you and your account administrators track your password expiration dates.
* **2 Factor Backup** (id: 9, required: false): Select a 2-factor authentication method backup. This ensures you have a backup in case of a primary 2-factor method failure.
* **Sensitive Data Backup** (id: 10, required: false): Select any sensitive data you've backed up. This helps us understand your data management practices.
* **Account Recovery** (id: 11, required: false): Select your account recovery method. This helps you and your account administrators recover your account quickly in case of a security incident.
* **Account Lockout** (id: 12, required: false): Select the account lockout duration. This helps you set up account protection measures to prevent unauthorized access.
* **Account Notifications** (id: 13, required: false): Select notification methods for account-related updates. This keeps you informed about account activity and potential security risks.
* **Password Change** (id: 14, required: false): Select when you change your password. This helps you and your account administrators track your password updates.

Please fill out the form carefully, and let us know if you have any questions or concerns!
