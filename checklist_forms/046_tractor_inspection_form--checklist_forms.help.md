# Tractor Inspection Form - Help Guide
## Purpose
This form is used to evaluate the condition of a tractor's engine, tires, hydraulics, transmission, brakes, steering, and frame. The assessment helps identify any potential issues that may affect the tractor's performance and safety.

## How To Complete This Form
1. Carefully inspect each of the tractor's components and select the condition that best describes the current state of each one. For example, if the tires are clean and have good tread, select "Yes" under the "Tire Condition" field.
2. Make sure to fill out every field, even if the condition is "Yes" for all components, as this form is designed to provide a comprehensive inspection report.

## Field-by-Field Explanation
1. **Engine Condition**
	* `Engine Condition` (`engine_condition`, select_multiple, required: false): Check the engine's overall condition, including cleanliness, leaks, and proper function. Select "Yes" if the engine is in good condition, and "No" if it's not.
2. **Tire Condition**
	* `Tire Condition` (`tire_condition`, select_multiple, required: false): Evaluate the tires' condition, including tread depth, wear, and proper inflation. Select "Yes" if the tires are in good condition, and "No" if they're not.
3. **Hydraulic Condition**
	* `Hydraulic Condition` (`hydraulic_condition`, select_multiple, required: false): Check the hydraulic system's condition, including leaks, proper function, and cleanliness. Select "Yes" if the system is in good condition, and "No" if it's not.
4. **Transmission Condition**
	* `Transmission Condition` (`transmission_condition`, select_multiple, required: false): Assess the transmission's condition, including proper function, leaks, and cleanliness. Select "Yes" if the transmission is in good condition, and "No" if it's not.
5. **Brakes Condition**
	* `Brakes Condition` (`brakes_condition`, select_multiple, required: false): Check the brakes' condition, including proper function, wear, and cleanliness. Select "Yes" if the brakes are in good condition, and "No" if they're not.
6. **Steering Condition**
	* `Steering Condition` (`steering_condition`, select_multiple, required: false): Evaluate the steering's condition, including proper function, leaks, and cleanliness. Select "Yes" if the steering is in good condition, and "No" if it's not.
7. **Frame Condition**
	* `Frame Condition` (`frame_condition`, select_multiple, required: false): Check the frame's condition, including rust, dents, and structural integrity. Select "Yes" if the frame is in good condition, and "No" if it's not.
8. **Electrical Condition**
	* `Electrical Condition` (`electrical_condition`, select_multiple, required: false): Assess the electrical system's condition, including proper function, cleanliness, and wear. Select "Yes" if the electrical system is in good condition, and "No" if it's not.

## Tips
* Make sure to thoroughly inspect each component before selecting the condition.
* If a component is not functioning properly or has a known issue, select "No" for that field.
* If you're unsure about a component's condition, consult with a qualified mechanic or the tractor's owner/operator.
* This form is designed to provide a comprehensive inspection report; fill out every field to get a complete evaluation of the tractor's condition.
