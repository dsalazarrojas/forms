# Residential Grounds Maintenance Checklist - Help Guide
## Purpose
The Residential Grounds Maintenance Checklist is a tool used to assess the condition of residential properties grounds and report any issues that need to be addressed.

## How To Complete This Form

To complete this form, follow these steps:

1. Review each section carefully and answer the questions honestly.
2. For each section, select the most accurate description of the condition of the property.
3. If an issue is found, provide a clear description of the problem and suggest a course of action for maintenance or repairs.
4. Fill out the property owner/manager's contact information so we can get in touch with them about any issues that need to be addressed.

## Field-by-Field Explanation

* **Home Address** (`home_address`, text, **optional**): Enter the address of the property that is being assessed.
* **Date Of Last Inspection** (`date_of_last_inspection`, date, **optional**): Enter the date of the last inspection of the property's grounds.
* **Condition Of Walkways** (`condition_of_walkways`, select_one, **optional**): Select the condition of the walkways at the property, using the options:
	+ Walkways in good condition
	+ Walkways in fair condition
	+ Walkways in poor condition
* **Condition Of Stairs** (`condition_of_stairs`, select_one, **optional**): Select the condition of the stairs at the property, using the options:
	+ Stairs in good condition
	+ Stairs in fair condition
	+ Stairs in poor condition
* **Condition Of Handrails** (`condition_of_handrails`, select_one, **optional**): Select the condition of the handrails at the property, using the options:
	+ Handrails in good condition
	+ Handrails in fair condition
	+ Handrails in poor condition
* **Condition Of Fences** (`condition_of_fences`, select_one, **optional**): Select the condition of the fences at the property, using the options:
	+ Fences in good condition
	+ Fences in fair condition
	+ Fences in poor condition
* **Condition Of Gates** (`condition_of_gates`, select_one, **optional**): Select the condition of the gates at the property, using the options:
	+ Gates in good condition
	+ Gates in fair condition
	+ Gates in poor condition
* **Condition Of Playgrounds** (`condition_of_playgrounds`, select_one, **optional**): Select the condition of the playgrounds at the property, using the options:
	+ Playgrounds in good condition
	+ Playgrounds in fair condition
	+ Playgrounds in poor condition
* **Condition Of Pathways** (`condition_of_pathways`, select_one, **optional**): Select the condition of the pathways at the property, using the options:
	+ Pathways in good condition
	+ Pathways in fair condition
	+ Pathways in poor condition
* **Condition Of Landscaping** (`condition_of_landscaping`, select_one, **optional**): Select the condition of the landscaping at the property, using the options:
	+ Landscaping in good condition
	+ Landscaping in fair condition
	+ Landscaping in poor condition
* **Comments** (`comments`, note, **optional**): Provide any additional comments or notes about the property's condition.
* **Property Manager** (`property_manager`, text, **optional**): Enter the name of the property manager or contact person.
* **HOA Contact** (`hoa_contact`, text, **optional**): Enter the contact information for the property's HOA.
* **Maintenance Supervisor** (`maintenance_supervisor`, text, **optional**): Enter the name of the maintenance supervisor or contact person.
* **Date Completed** (`date_completed`, date, **optional**): Enter the date this form was completed.
* **Completed By** (`completed_by`, text, **optional**): Enter the name of the person who completed this form.
* **Signature** (`signature`, text, **optional**): Enter the signature of the person who completed this form.
* **Form ID** (`form_id`, text, **optional**): Enter a unique identifier for this form.
* **Property Address** (`property_address`, text, **optional**): Enter the address of the property.
* **HOA Email** (`hoa_email`, email, **optional**): Enter the email address of the property's HOA.
* **HOA Phone** (`hoa_phone`, text, **optional**): Enter the phone number of the property's HOA.
* **Property Owner Name** (`property_owner_name`, text, **optional**): Enter the name of the property owner.
* **Property Owner Phone** (`property_owner_phone`, text, **optional**): Enter the phone number of the property owner.
* **Property Owner Email** (`property_owner_email`, email, **optional**): Enter the email address of the property owner.
* **Property Owner Address** (`property_owner_address`, text, **optional**): Enter the address of the property owner.

Note: Fields marked as **optional** are not required to be filled out, but providing them will help us get in touch with you and keep you updated on any issues that need to be addressed.
