# Park Maintenance Checklist Form - Help Guide
## Purpose
The Park Maintenance Checklist Form is used to track and manage park maintenance tasks.

## How To Complete This Form

To complete this form, follow these steps:

1. Select a park for which you want to add a maintenance task.
2. Add the maintenance task in the "Maintenance Task" field.
3. Choose the status of the task (Completed, Not Started, In Progress) in the "Status" field.
4. Select the frequency of the task (Daily, Weekly, Monthly) in the "Frequency" field.
5. Enter the date the task is due in the "Due Date" field.
6. Enter the time the task is due in the "Due Time" field.
7. Add any additional notes or comments in the "Notes" field.
8. Select the park manager responsible for the task in the "Park Manager" field.
9. Enter the park contact person's email in the "Park Contact" field.
10. Enter the park email address in the "Park Email" field.
11. Select the responsible person for the task in the "Responsible" field.
12. Enter the park address in the "Park Address" field.
13. Enter the location of the task in the "Location" field.
14. Enter a description of the task in the "Description" field.
15. Set the priority of the task (High, Middle, Low) in the "Priority" field.
16. Select the "Complete" status in the "Completed" field.

## Field-by-Field Explanation
### Park Tasks (Task List, <type>: text, required: <false>)
This field is where you can enter the park maintenance tasks that need to be completed.

* Enter the specific tasks that need to be performed on the park.
* Use a separate line for each task.

### Maintenance Task (Maintenance Task, <type>: text, required: <false>)
This field is where you can enter the specific maintenance task you want to add.

* Enter a clear and concise description of the task.
* For example, "Mow the lawn" or "Repair the swing set".

### Status (Status, <type>: select_multiple, required: <false>)
This field allows you to select the status of the maintenance task.

* Select "Completed" if the task is finished.
* Select "Not Started" if the task has not been started.
* Select "In Progress" if the task is ongoing.

### Frequency (Frequency, <type>: select_one, required: <false>)
This field allows you to select the frequency of the maintenance task.

* Select "Daily" for tasks that need to be performed daily.
* Select "Weekly" for tasks that need to be performed weekly.
* Select "Monthly" for tasks that need to be performed monthly.

### Date (Date, <type>: date, required: <false>)
This field is where you can enter the due date for the maintenance task.

* Enter the date in the format MM/DD/YYYY.
* For example, 12/15/2023.

### Time (Time, <type>: time, required: <false>)
This field is where you can enter the due time for the maintenance task.

* Enter the time in the format HH:MM AM/PM.
* For example, 02:30 PM.

### Notes (Notes, <type>: note, required: <false>)
This field is where you can enter any additional notes or comments about the maintenance task.

* Enter any relevant information that will help the park manager or staff complete the task.

### Park ID (Park ID, <type>: number, required: <false>)
This field is not used in this form.

### Park Name (Park Name, <type>: text, required: <false>)
This field is where you can enter the name of the park.

* Enter the name of the park for which the maintenance task is for.

### Park Manager (Park Manager, <type>: text, required: <false>)
This field is where you can enter the park manager's name.

* Enter the name of the park manager responsible for the maintenance task.

### Park Contact (Park Contact, <type>: email, required: <false>)
This field is where you can enter the park contact person's email.

* Enter the email of the park contact person.

### Park Email (Park Email, <type>: email, required: <false>)
This field is not used in this form.

### Responsible (Responsible, <type>: text, required: <false>)
This field is where you can enter the person responsible for the maintenance task.

* Enter the name of the person responsible for the task.

### Park Address (Park Address, <type>: text, required: <false>)
This field is where you can enter the park address.

* Enter the address of the park where the maintenance task is located.

### Location (Location, <type>: text, required: <false>)
This field is where you can enter the location of the maintenance task.

* Enter a specific location within the park where the task is to be performed.

### Notes (Notes, <type>: text, required: <false>)
This field is not used in this form.

### Description (Description, <type>: text, required: <false>)
This field is where you can enter a description of the maintenance task.

* Enter a clear and concise description of the task.

### Priority (Priority, <type>: select_one, required: <false>)
This field allows you to select the priority of the maintenance task.

* Select "High" for high-priority tasks.
* Select "Middle" for medium-priority tasks.
* Select "Low" for low-priority tasks.

### Due Date (Due Date, <type>: date, required: <false>)
This field is where you can enter the due date for the maintenance task.

* Enter the date in the format MM/DD/YYYY.

### Due Time (Due Time, <type>: time, required: <false>)
This field is where you can enter the due time for the maintenance task.

* Enter the time in the format HH:MM AM/PM.

### Completed (Completed, <type>: text, required: <false>)
This field is not used in this form.

# Tips

* Make sure to fill out all required fields.
* Use clear and concise language when entering task descriptions and notes.
* Select the correct status and priority for each task.
