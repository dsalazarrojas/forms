# New Hire Checklist Form Template - Help Guide
## Purpose
The New Hire Checklist Form Template is a standardized form used to collect necessary information and ensure that all new hires complete the required steps before starting work. This form is designed to be completed by new employees and their managers/supervisors.

## How To Complete This Form

1. Fill out the form with the requested information, including employee name, job title, supervisor's name, and other relevant details.
2. Select the correct job classification (e.g., Administrative, Management, Operations, Sales) and job status (e.g., Active, Inactive, Pending).
3. Choose the shift schedule and job type (Yes/No).
4. Enter the job description and job code.
5. Complete any other required fields as necessary.

## Field-by-Field Explanation

* **Employee Name**: Enter the full name of the new hire.
* **Job Title**: Enter the title of the new job or position.
* **Supervisor's Name**: Enter the name of the supervisor or manager responsible for the new hire.
* **Reporting Manager Name**: Enter the name of the reporting manager for the new hire.
* **Date of Birth**: Enter the date of birth of the new hire.
* **Hire Date**: Enter the date the new hire was hired.
* **Job Start Date**: Enter the date the new hire will start working.
* **Department**: Enter the department where the new hire will be working.
* **Job Location**: Enter the location of the new job.
* **Job Classification**: Select one or more classifications that apply to the new hire's job (e.g., Administrative, Management, Operations, Sales).
* **Shift Schedule**: Select the shift schedule for the new hire (e.g., Full-time, Part-time, Variable, Remote).
* **Job Status**: Select the current job status (e.g., Active, Inactive, Pending).
* **Job Type**: Select whether the job is a yes or no answer.
* **Job Description**: Enter a brief description of the new hire's job.
* **Job Code**: Enter the job code for the new hire.
* **Reporting Manager ID**: Enter the ID of the reporting manager for the new hire.
* **Manager Reporting Manager ID**: Enter the ID of the manager's reporting manager.
* **Job Code ID**: Enter the ID of the job code.
* **New Hire Form Data 2**: This field is a text field for any additional information.
* **Employee ID**: Enter the ID of the new hire.
* **Manager ID**: Enter the ID of the manager or supervisor.
* **Team Members**: Enter the names of team members working with the new hire.
* **Job Classifications**: Select one or more classifications that apply to the new hire's job (e.g., Administrative, Management, Operations, Sales).
* **Job Titles**: Select one or more titles that apply to the new hire's job (e.g., Administrative, Management, Operations, Sales, Manager).
