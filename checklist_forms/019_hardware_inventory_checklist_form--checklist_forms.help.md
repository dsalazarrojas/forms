# hardware_inventory_checklist_form - Help Guide
## Purpose
This form helps you to create a hardware inventory checklist. Fill in the required fields to accurately capture the details of your hardware assets.

## How To Complete This Form
- Read the entire form carefully before starting.
- Fill in the provided fields with the actual values for each hardware asset.
- Use the correct format for the date fields.

## Field-by-Field Explanation
* **hardware_type** (`hardware_type`, text, optional): Enter the type of hardware asset (e.g., computer, printer, etc.).
* **serial_number** (`serial_number`, text, optional): Enter the serial number of the hardware asset.
* **model_number** (`model_number`, text, optional): Enter the model number of the hardware asset.
* **manufacturer** (`manufacturer`, text, optional): Enter the name of the hardware manufacturer.
* **location** (`location`, text, optional): Enter the location where the hardware asset is stored or used.
* **asset_status** (`asset_status`, select_one, optional): Select the status of the hardware asset (Active or Inactive).
* **asset_status_options** (`asset_status_options`, select_multiple, optional): Select multiple status options for the hardware asset (Available, Maintenance, In Use, In Transit, Retired).
* **maintenance_status** (`maintenance_status`, text, optional): Enter any maintenance information or status for the hardware asset.
* **purchase_date** (`purchase_date`, date, optional): Enter the date the hardware asset was purchased.
 
## Tips
- Double-check the fields for accurate information before submitting the form.
- If a field is not required, fill it in if relevant to your specific asset.
- Save the form after completion to avoid losing your work.
