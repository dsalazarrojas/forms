# Wedding Vendor Checklist - Help Guide

## Purpose
This form is designed to gather necessary details about vendors you are working with or considering working with for your wedding. It is recommended to fill it out for all relevant vendors, such as caterers, photographers, DJs, etc.

## How To Complete This Form
1.  Select the **Wedding Vendors** page, which should display all the fields.
2.  Review each field carefully and answer accordingly:

## Field-by-Field Explanation
*   **Wedding Vendors**:
    +   **Vendor Name** (Text): Enter the name of the vendor, if you already have it. If not, skip this field or fill it out once you know the name.
*   **Wedding Planning Progress**: Check **Yes** or **No** to indicate whether you are in contact with this vendor or if you are still planning to work with them.
*   **Contact Info** (Text): Enter any relevant contact information you have for the vendor, if available.
*   **Email Address** (Email): Enter the email address of the vendor, if you have it. This helps ensure that you can reach out to them efficiently.
*   **Phone Number** (Text): If you have a contact number for the vendor, enter it here. Otherwise, skip this field.
*   **Vendor Notes**:
    +   **Yes** or **No**: Check **Yes** if you have notes about this vendor that you would like to keep, or **No** otherwise.
*   **Vendor Type** (Select):
    +   **Yes**, **No**: This field helps you categorize the type of vendor (e.g., caterer, photographer, DJ, etc.). Select **Yes** for the correct type or **No** if not applicable.
*   **Vendor Address** (Text): Enter the physical address of the vendor, if available.
*   **Vendor Phone Number** (Text): Enter the contact number of the vendor, if you have it.
*   **Vendor Notes**:
    +   **Yes** or **No**: Similar to "Vendor Notes" above, if you have notes, mark as **Yes** to save them.
    -   If you do not have notes, mark as **No**.

## Tips
*   Be as detailed as possible in each field to ensure that you can contact or work with the vendor easily.
*   Double-check all fields for accuracy to save time and reduce confusion.
*   If you need to make changes to this form, please contact the relevant team.
*   For any questions or issues with this form, feel free to reach out to us.
*   Remember that the purpose of this form is to gather essential information for your wedding planning.
