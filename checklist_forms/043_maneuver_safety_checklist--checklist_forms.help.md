# Maneuver Safety Checklist - Help Guide
## Purpose
This form is designed to help conductors and operators ensure that their vehicle is safe and ready for a maneuver. It checks the condition of the vehicle and its systems, ensuring that it is in a state to safely proceed.

## How To Complete This Form
1. Scroll through the form and select the options that apply to your current state of the vehicle. Make sure to answer all required fields.
2. Fill in any additional comments or notes if necessary.
3. Fill in the form id and output file name if applicable.

## Field-by-Field Explanation
* **Is the vehicle in good condition** (`vehicle_check`): Select "Yes" if the vehicle is in good condition, "No" otherwise.
* **Seatbelts** (`seatbelts`): Select all seatbelts that are in use.
* **Hazard Alerts** (`hazard_alerts`): Enter any hazard alerts that need to be noted.
* **Check for Hazards** (`check_for_hazards`): Enter the date of when you checked for hazards.
* **Maneuver Control** (`maneuver_control`): Select the control used during the maneuver (Steering Wheel, Brake Pedal, Accelerator).
* **Check safety systems** (`check_safety_systems`): Enter the time of when you checked the safety systems.
* **Vehicle Precedence** (`vehicle_precedence`): Select "Left," "Right," or "None."
* **Check signals** (`check_signals`): Select all turn signals in use.
* **Check signals2** (`check_signals2`): Select all turn signals in use.
* **Check speed** (`check_speed`): Enter the current speed of the vehicle.
* **Check speed2** (`check_speed2`): Enter the current speed of the vehicle.
* **Check engine** (`check_engine`): Select "Running" if the engine is running, "Not running" otherwise.
* **Check engine2** (`check_engine2`): Select "Running" if the engine is running, "Not running" otherwise.
* **Check engine3** (`check_engine3`): Select "Running" if the engine is running, "Not running" otherwise.
* **Notes** (`notes`): Enter any additional comments.
* **Assigned Tool** (`assigned_tool`): Enter the tool assigned.
* **Form ID** (`form_id`): Enter the form id.
* **Output File** (`output_file`): Enter the output file name.
* **Category** (`category`): Enter the category.
* **Title** (`title`): Enter the title.
* **Description** (`description`): Enter the description.
* **Category 1** (`category_1`): Enter the category 1.
* **Category 2** (`category_2`): Enter the category 2.
* **Category 3** (`category_3`): Enter the category 3.
