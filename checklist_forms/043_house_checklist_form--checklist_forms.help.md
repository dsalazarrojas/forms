This help guide is intended to assist users in understanding the purpose and usage of the "House Checklist Form" and its various fields. 

The form's purpose is to collect information regarding the status and condition of a house, including its workability, systems, engine status, service requirements, exterior information, security, and any additional comments. This form is designed to be completed by users who need to assess the current state of a house and make informed decisions based on the collected data.

# House Checklist Form - Help Guide
## Purpose
The House Checklist Form is a tool used to gather information about the condition and status of a house. It is used to determine the workability, systems, and other essential aspects of a house.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the status of the house from the options provided for each field.
2. For fields with multiple options, select all applicable options.
3. Provide any additional comments if necessary.

## Field-by-Field Explanation
### 1. **House Status** (`house_status`, `select_one`, required: false)
This field is used to select the current status of the house. Select the status from the provided options.

### 2. **Systems Workability** (`systems_workability`, `select_multiple`, required: false)
Select all systems that are currently working in the house. 

### 3. **Basic Systems & Engine Status** (`basic_systems_engine_status`, `select_multiple`, required: false)
Select all basic systems and engine components that are currently active or inactive in the house. 

### 4. **Service Requirements** (`service_requirements`, `select_one`, required: false)
Select the service requirements of the house, if applicable. 

### 5. **Exterior Information** (`exterior_info`, `select_one`, required: false)
Select whether the house has any exterior information, such as a fence, gate, or other features. 

### 6. **Security** (`security`, `select_multiple`, required: false)
Select all security features that are currently active or inactive in the house. 

### 7. **Additional Comments** (`additional_comments`, `note`, required: false)
Provide any additional comments or information about the house that is not covered by the other fields.
