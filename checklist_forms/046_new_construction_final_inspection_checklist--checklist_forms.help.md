# new-construction-final-inspection-checklist-form - Help Guide
## Purpose
The new-construction-final-inspection-checklist-form is used to record the results of a final inspection of a new construction project. It is designed to ensure that all necessary items are checked and documented in a standardized format.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate construction phase number from the options provided.
2. Enter the contractor's name in the text box.
3. Enter the date of the inspection in the date field.
4. Select the inspector's name from the text box.

## Field-by-Field Explanation

* **New Construction Final Inspection** (`new_construction_final_inspection`, select_one, required/optional): Select the current status of the new construction project.
	+ Options: 1, 2, 3 (please select one of these options)
* **Contractor Name** (`contractor_name`, text, required/optional): Enter the name of the contractor involved in the project.
* **Date** (`date`, date, required/optional): Enter the date of the inspection.
* **Inspector Name** (`inspector_name`, text, required/optional): Enter the name of the person conducting the inspection.
