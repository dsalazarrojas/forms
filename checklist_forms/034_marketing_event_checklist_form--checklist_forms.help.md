# Marketing Event Checklist Form - Help Guide
## Purpose
The Marketing Event Checklist Form is designed to capture essential information about marketing events. This form will help you collect and organize data in a structured and organized way to ensure effective event planning and communication.

## How To Complete This Form

1.  Navigate to the Marketing Event Checklist Form. If you have any issues accessing the form, please contact your system administrator or support team.
2.  Select a page (tab) from the form's navigation menu to access the relevant fields for the selected page. Each page focuses on a specific part of the event information.

## Field-by-Field Explanation

* **Event Details**
    * **Event Title** (`event_details`): Enter the name of the marketing event. This is a brief title that will help identify the event.
* **Event Date** (`event_date`): Enter the date of the marketing event. This is the primary date for the event, including the start and end dates if applicable.
* **Marketing Team** (`marketing_team`): Select 'Yes' if the event involves a marketing team. This helps in identifying team involvement.
*   **Assigned Tool** (`assigned_tool`): Select 'Yes' if a tool has been assigned to the event.
*   **Event Status** (`event_status`): Select from the options to indicate the status of the event. Choose 'Active' for ongoing events and 'Inactive' for events that are no longer active or completed.
*   **Event Organizers** (`event_organizers`): Select 'Yes' if the event has organizers. This indicates who is leading the event.
*   **Event Venue** (`event_venue`): Enter a brief description or name of the event venue. This could be an online platform or a physical location.
*   **Event Notes** (`event_notes`): Add any additional notes about the event. This field is open for free-form text comments.
*   **Contact Person** (`contact_person`): Enter the name or title of the contact person for the event.
*   **Contact Email** (`contact_email`): Enter the email of the contact person. This is their primary email for communication.
*   **Contact Phone** (`contact_phone`): Enter the phone number of the contact person. This should be a primary phone number for communication.
*   **Event Start Time** (`event_start_time`): Enter the start time of the event. If the event has a start and end time, ensure both are entered.
*   **Event End Time** (`event_end_time`): Enter the end time of the event. If the event has a start and end time, ensure both are entered.
*   **Event Address** (`event_address`): Enter the physical address of the event, if applicable.
*   **Event Description** (`event_description`): Enter a brief description of the event. This could include details about the event type, objectives, and expectations.
*   **Event Hashtags** (`event_hashtags`): Enter relevant hashtags for the event. These should be related to the event's theme or topic.
*   **Event Tags** (`event_tags`): Select 'Yes' if the event includes tags.
*   **Hashtags** (`event_hashtag_list`): Select 'Yes' if the event includes hashtags.
*   **Assigned Tool ID** (`assigned_tool_id`): Enter the tool ID assigned to the event.
*   **Event URL** (`event_url`): Enter the URL for the event, if applicable. This could be a registration link or the event's landing page.

**Tips**
- Ensure all fields are filled out accurately to maintain the integrity of your event data.
- Use the form as a reference tool to ensure you cover all necessary aspects of your marketing event.
- Review and adjust your form preferences according to your specific event types and needs.
