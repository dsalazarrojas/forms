# Unit Control Checklist - Help Guide

## Purpose
The Unit Control Checklist is a form used to track and document the status of units in your organization. This form helps ensure that all necessary checklists are completed and up-to-date, and provides a centralized location for reviewing and managing unit control checklists.

## How To Complete This Form

1. **Checklists**: Select all applicable checklists for the unit from the list provided. You can choose multiple checklists by holding down the Ctrl key or Shift key and clicking on the desired options.
2. **Unit Name**: Enter the name of the unit being controlled.
3. **Checklist Items**: Select the status of each checklist item.
4. **Checklist Date**: Enter the date the checklist was completed.
5. **Checklist Time**: Enter the time the checklist was completed.
6. **Checklist Status**: Select the current status of the checklist.
7. **Checklist Completed**: Select whether the checklist is completed.
8. **Unit Completed**: Select whether the unit is completed.
9. **Checklist Notes**: Enter any additional notes related to the checklist.
10. **Checklist Comments**: Enter any comments related to the checklist.
11. **Checklist Attachments**: Select whether attachments are included with the checklist.

## Field-by-Field Explanation

* **Checklists** (`checklists`, select multiple, optional): Select all applicable checklists for the unit from the list provided.
* **Unit Name** (`unit_name`, text, required): Enter the name of the unit being controlled.
* **Checklist Items** (`checklist_items`, select one, optional): Select the status of each checklist item.
* **Checklist Date** (`checklist_date`, date, optional): Enter the date the checklist was completed.
* **Checklist Time** (`checklist_time`, time, optional): Enter the time the checklist was completed.
* **Checklist Status** (`checklist_status`, select one, optional): Select the current status of the checklist.
* **Checklist Completed** (`checklist_completed`, select one, optional): Select whether the checklist is completed.
* **Unit Completed** (`unit_completed`, select one, optional): Select whether the unit is completed.
* **Checklist Notes** (`checklist_notes`, text, optional): Enter any additional notes related to the checklist.
* **Checklist Comments** (`checklist_comments`, text, optional): Enter any comments related to the checklist.
* **Checklist Attachments** (`checklist_attachments`, select multiple, optional): Select whether attachments are included with the checklist.
