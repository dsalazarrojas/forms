# Final Walkthrough Checklist - Help Guide
## Purpose
This form is used to verify that all building systems are functioning correctly before completion of the building.

## How To Complete This Form
To complete this form, follow these steps:

* Select the relevant options for each system from the provided list.
* Ensure all required fields are completed before submitting the form.
* Review the form carefully to ensure accuracy before submitting it.

## Field-by-Field Explanation

* **Electrical Systems** (<code>electrical_systems</code>, `select_multiple`, required)
	+ Select 'Yes' if the electrical system is complete and functioning correctly.
* **Plumbing Systems** (<code>plumbing_systems</code>, `select_multiple`, required)
	+ Select 'Yes' if the plumbing system is complete and functioning correctly.
* **Heating and Cooling** (<code>heating_and_cooling</code>, `select_multiple`, required)
