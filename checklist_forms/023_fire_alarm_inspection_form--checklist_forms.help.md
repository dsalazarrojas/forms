# fire_alarm_inspection_form - Help Guide
## Purpose

The fire alarm inspection form is used to collect information about fire alarm systems, including their description, type, location, and certificate details. This form is intended to ensure that fire alarm systems are functioning properly and are compliant with relevant regulations.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the system description field with a brief description of the fire alarm system being inspected.
2. Select the type of fire alarm system from the options provided.
3. Enter the location of the system.
4. Select the inspection date from the calendar.
5. Enter the name of the person who performed the inspection.
6. Enter the details of the fire alarm system certificate.
7. If applicable, enter the expiration date of the certificate.
8. Enter any additional description of the fire alarm system.
9. Enter the location of the inspection.
10. Enter any additional description of the system.
11. Select the status of the fire alarm inspection (Active or Inactive).
12. Select whether the fire alarm system has a certificate (Yes or No).
13. Enter the location of the inspection.
14. Enter any additional description of the system.
15. Enter the renewal date of the certificate, if applicable.

## Field-by-Field Explanation

* **Fire Alarm Inspection Form** (`fire_alarm_inspection_form`, text, required/optional): This is the title of the form.
* **System Description** (`system_description`, text, optional): Enter a brief description of the fire alarm system being inspected.
* **System Type** (`system_type`, select_one, optional): Select the type of fire alarm system from the options provided.
* **System Location** (`system_location`, text, optional): Enter the location of the fire alarm system.
* **Inspection Date** (`inspection_date`, date, optional): Select the inspection date from the calendar.
* **Inspected By** (`inspected_by`, text, optional): Enter the name of the person who performed the inspection.
* **Fire Alarm System Certificate** (`fire_alarm_system_certificate`, text, optional): Enter the details of the fire alarm system certificate.
* **System Certificate Expiration Date** (`system_certificate_expiration_date`, date, optional): If applicable, enter the expiration date of the certificate.
* **Fire Alarm System Description** (`fire_alarm_system_description`, text, optional): Enter any additional description of the fire alarm system.
* **Fire Alarm System Location** (`fire_alarm_system_location`, text, optional): Enter the location of the fire alarm system.
* **Fire Alarm System Type** (`fire_alarm_system_type`, text, optional): Enter any additional description of the system.
* **Fire Alarm System Certificate 2** (`fire_alarm_system_certificate_2`, text, optional): Enter any additional details of the fire alarm system certificate.
* **Inspection Location** (`inspection_location`, text, optional): Enter the location of the inspection.
* **Fire Alarm System Description 2** (`fire_alarm_system_description_2`, text, optional): Enter any additional description of the system.
* **Fire Alarm System Certificate Expiration Date** (`fire_alarm_system_certificate_expiration_date`, date, optional): If applicable, enter the expiration date of the certificate.
* **System Certificate Holder** (`system_certificate_holder`, text, optional): Enter the details of the certificate holder.
* **Inspection Date 2** (`inspection_date_2`, date, optional): Select the inspection date from the calendar.

* **Fire Alarm System Certificate Type** (`fire_alarm_system_certificate_type`, select_one, optional): Select whether the fire alarm system has a certificate (Yes or No).
* **Fire Alarm Inspection Location** (`fire_alarm_inspection_location`, text, optional): Enter the location of the inspection.

* **System Certificate Renewal Date** (`system_certificate_renewal_date`, date, optional): If applicable, enter the renewal date of the certificate.
