# Food Production Process Flow Checklist - Help Guide
## Purpose
This form is used to document the production process, including production steps, dates, times, equipment used, employee names, and comments.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by reviewing the introduction page, which provides an overview of the production process.
2. For each production phase, select the relevant production steps and equipment used.
3. Enter the production date and time for each phase.
4. Add employee names and signatures for each phase.
5. Enter any comments or additional information for each phase.
6. Review each phase and confirm that the production process was completed correctly.

## Field-by-Field Explanation

* **Introduction** (`introduction_page`, note, optional): This page provides an overview of the production process and its purpose.
* **Production Steps** (`production_steps_page`, select_one, optional): Select the relevant production steps for this phase of production.

## Tips

* Make sure to select all relevant production steps and equipment used for each phase of production.
* Confirm that the production process was completed correctly for each phase.
* Enter accurate production dates and times.
* Ensure that employee names and signatures are correct.
* Use the "Comments" field to enter any additional information or explanations.
* Review each phase carefully before submitting the form.
* Make sure to enter the correct production number for each phase.
* Review each phase again after completing the form to ensure that all required fields are filled out correctly.
