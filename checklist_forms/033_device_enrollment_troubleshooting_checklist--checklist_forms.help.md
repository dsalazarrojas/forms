## Purpose

This form is used to document and track issues related to device enrollment, ensuring that they can be resolved efficiently and effectively.

## How To Complete This Form

1. Select the device model experiencing the issue.
2. Enter the device serial number.
3. Choose the date the device was enrolled.
4. Select the enrollment status of the device.
5. Describe the issue with the device.
6. Choose the type of issue (Hardware or Software).
7. Describe any troubleshooting steps taken so far.
8. Add any additional notes about the issue.
9. Schedule a follow-up date and time.
10. Enter the email address and phone number of the person to follow up with.
11. Enter the name of the person submitting the form.
12. Select the status of the follow-up (Follow-up Sent or Not Sent).
13. Enter the date the form was submitted.
14. Select whether the issue is closed or not.
15. Select whether the issue is solved or not.
16. Describe any next steps to take on the issue.
17. Choose the date the issue was resolved.
18. Schedule a resolution time.
19. Select the method used to resolve the issue (Phone Call, Email, Walk-in).
20. Select the method used for follow-up (Phone Call, Email, Walk-in).
21. Add any notes about the resolution.
22. Add any notes from the submitter.
23. Select whether the issue is closed or not.
