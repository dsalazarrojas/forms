# Night Supervision Task Checklist - Help Guide
## Purpose
The Night Supervision Task Checklist is a form used to document and report on night supervision tasks, allowing for better oversight and evaluation of the night shift activities.

## How To Complete This Form
1. The form consists of multiple pages, each with a different section focused on a specific aspect of night supervision tasks.
2. Please answer the questions and complete the fields as per your experience and knowledge.
3. Make sure to answer all the fields, if a field is not required, it will be indicated as "Optional".

## Field-by-Field Explanation
* **Night Supervision Details** (`Night Supervision Details`, Text, Required: No, Field 1): This is the main section for providing details about the night supervision tasks. Please provide a brief description of the tasks performed during the night shift.
* **Completed Tasks** (`Completed Tasks`, Select Multiple, Optional): Select the tasks that were completed during the night shift. The options include Night Supervision Task 1, Night Supervision Task 2, and Night Supervision Task 3.
* **Incidents** (`Incidents`, Text, Optional): If any incidents occurred during the night shift, please provide a detailed description here.
* **Supervisor Sign-Off** (`Supervisor Sign-Off`, Select One, Optional): Indicate whether the night supervision tasks were signed-off by a supervisor.
* **Notes** (`Notes`, Note, Optional): Provide any additional notes or comments about the night supervision tasks or incidents that occurred during the night shift.
* **Supervisor Sign-Off** (`Supervisor Sign-Off`, Select One, Optional): This field is identical to the previous field, please make sure to select the correct option.
