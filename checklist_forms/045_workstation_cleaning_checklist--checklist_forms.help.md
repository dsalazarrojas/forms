# Workstation Cleaning Checklist - Help Guide

## Purpose
This form is used to track the cleaning status of a workstation. It is designed to be completed daily, after each shift or use, to ensure all necessary cleaning tasks are performed, reducing the risk of contamination and promoting a healthy work environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the "Cleaning Tasks" section and select all the tasks that were completed during the day.
2. For each task, enter 'Yes' or 'No' to indicate completion status.
3. Review the "Is the area clean?" field and enter 'Yes' if all tasks have been completed and the area is clean, or 'No' if there are still tasks left to complete.
4. Review the "Use of cleaning solution" field and select the correct option if a cleaning solution was used during the cleaning process.
5. Review the "Dust containers" field and enter any dust that was cleaned from the containers.
6. Review the "Disinfectant used" field and select the correct option if a disinfectant solution was used.
7. Review the "High-touch areas" field and select all high-touch areas that were disinfected.
8. Review the "Dust boards" field and enter any dust that was cleaned from the boards.

## Field-by-Field Explanation
* **Cleaning Tasks**: Select all the tasks that were completed during the day. This includes tasks like wiping down all surfaces, sweeping and mopping floors, etc.
* **Wipe down all surfaces**: Wipe down all surfaces with a disinfectant solution. If this task was completed, select 'Yes', if not, select 'No'.
* **Sweep and mop floors**: Select the floors option that was cleaned during the day.
* **Sweep**: Select 'Fridges and countertops', 'Floors', or 'Trash cans' to indicate what type of floor was cleaned.
* **Clean dust from all boards**: Enter any dust that was cleaned from the boards, including computer monitors, keyboards, and other electronic devices.
* **Disinfect all high-touch areas**: Select the correct option to indicate if a disinfectant solution was used to disinfector all high-touch areas.
* **Disinfectant**: Select 'Yes' if a disinfectant solution was used, 'No' otherwise.
* **Dust containers**: Enter any dust that was cleaned from the containers, including drawers, cabinets, and shelves.
* **Use a cleaning solution**: Select the correct option to indicate if a cleaning solution was used during the cleaning process.
* **Cleaning Solution**: Select 'Yes' if a cleaning solution was used, 'No' otherwise.
* **Is the area clean?**: Enter 'Yes' if all tasks have been completed and the area is clean, 'No' otherwise.
* **High-Touch Areas**: Select all high-touch areas that were disinfected, including handles, buttons, and other areas that are frequently touched.
* **Dust Boards**: Enter any dust that was cleaned from the boards, including computer monitors, keyboards, and other electronic devices.

## Tips
* Make sure to complete this form daily, after each shift or use.
* Review the form carefully before submitting to ensure all tasks are completed and accurate.
* If a task was completed but the corresponding field was not selected, make sure to select the correct option to avoid incomplete submissions.
