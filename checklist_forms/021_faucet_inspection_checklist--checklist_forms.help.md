# Faucet Inspection Checklist - Help Guide

## Purpose
This form is used to inspect and report on the status of faucets in a building or facility.

## How To Complete This Form

* Start by selecting the status of the faucet. Please select "Active" if the faucet is working properly, "Disabled" if it is not working due to maintenance or other issues, or "Leaking" if there is a leak.
* If the faucet is leaking, select "True" under "Leaking" to indicate this issue.
* Select the water quality for the faucet, using "Good", "Fair", or "Poor" as options.
* If you have any photos of the faucet, you can add them under "Photos". You can also add notes or comments about the faucet under "Notes".
* Enter the date and time the faucet was last inspected or checked under "Date Last Checked" and "Time Last Checked".
* Enter the name of the person who completed the inspection under "Checked By".
* Enter the building number and floor number for the location of the faucet under "Building Number" and "Floor Number".
* Enter the address of the building where the faucet is located under "Address".
* If you have any comments or additional information about the location, you can add them under "Location Notes".
* Select the person or team assigned to work on the faucet under "Assigned To".
* Select the status of the maintenance or repair under "Status" as "Completed", "In Progress", or "Not Assigned".
* If you have any comments or additional information, you can add them under "Comments".
* If you have any photos or additional notes about the location, you can add them under "Location Notes".
* Enter the tool assigned to work on the faucet under "Assigned Tool".
* If you have any additional comments or information about the inspection, you can add them under "Notes 2".
* If you have any photos or additional notes about the location, you can add them under "Location Notes 2".
* If you have any photos or additional notes about the faucet, you can add them under "Photos 2".
* Select whether the maintenance or repair is completed under "Completed Status" as "True" or "False".

## Field-by-Field Explanation

* **Faucet Status** (`Faucet Status`, select_one, required): Select the status of the faucet. Please see the options above.
* **Leaking** (`Leaking`, select_one, required): Select "True" if the faucet is leaking.
* **Water Quality** (`Water Quality`, select_multiple, required): Select the quality of the water from the options "Good", "Fair", or "Poor".
* **Photos** (`Photos`, note, required): If you have any photos of the faucet, you can add them here.
* **Date Last Checked** (`Date Last Checked`, date, required): Enter the date the faucet was last inspected or checked.
* **Time Last Checked** (`Time Last Checked`, time, required): Enter the time the faucet was last inspected or checked.
* **Checked By** (`Checked By`, text, required): Enter the name of the person who completed the inspection.
* **Building Number** (`Building Number`, text, required): Enter the building number for the location of the faucet.
* **Floor Number** (`Floor Number`, text, required): Enter the floor number for the location of the faucet.
* **Address** (`Address`, text, required): Enter the address of the building where the faucet is located.
* **Location Notes** (`Location Notes`, note, required): If you have any comments or additional information about the location, you can add them here.
* **Assigned To** (`Assigned To`, text, required): Enter the name of the person or team assigned to work on the faucet.
* **Status** (`Status`, select_one, required): Select the status of the maintenance or repair under "Completed", "In Progress", or "Not Assigned".
* **Completed Date** (`Completed Date`, date, required): Enter the date the maintenance or repair is completed.
* **Assigned Time** (`Assigned Time`, time, optional): Enter the time the maintenance or repair is scheduled or assigned.
* **Comments** (`Comments`, note, optional): If you have any comments or additional information about the inspection, you can add them here.
* **Location Notes** (`Location Notes`, note, optional): If you have any photos or additional notes about the location, you can add them here.
* **Photos 2** (`Photos 2`, note, optional): If you have any photos or additional notes about the faucet, you can add them here.
* **Assigned Tool** (`Assigned Tool`, text, required): Enter the tool assigned to work on the faucet.
* **Notes 2** (`Notes 2`, note, optional): If you have any comments or additional information about the inspection, you can add them here.
* **Location Notes 2** (`Location Notes 2`, note, optional): If you have any photos or additional notes about the location, you can add them here.
* **Completed Status** (`Completed Status`, select_one, required): Select "True" if the maintenance or repair is completed, or "False" if it is not.

## Tips

* Make sure to complete the form thoroughly and accurately to ensure that the information is reliable and useful for maintenance and repair purposes.
* If you have any photos or additional notes, use the corresponding fields to add them.
* If you have any comments or additional information, use the corresponding fields to add them.
* If you are not sure about any of the fields, please ask someone for help or clarification.
* Remember to update the form regularly to reflect changes in the status of the faucets.
