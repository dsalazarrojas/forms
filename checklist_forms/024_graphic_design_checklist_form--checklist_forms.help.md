# Graphic Design Checklist Form - Help Guide
## Purpose
The Graphic Design Checklist Form is a comprehensive form designed to gather essential information about graphic design projects. This form is meant for internal use within an organization, possibly for project managers, designers, and other stakeholders to review and track project progress.

## How To Complete This Form
1. Fill in the **Project Details** field with a concise description of the project.
2. Choose whether the project involves the **Designer Information** in the select one field.
3. Enter the URL or location of the **Design File** associated with the project.
4. Record the **Review Date** of the project.
5. Enter the **Deadline** for the project.
6. Enter any additional **Comments** about the project.
7. Indicate the project's **Project Status** in the select multiple field.
8. Choose whether a specific **Assigned Tool** is associated with the project.
9. Select users who are **Assigned User** to the project.
10. Indicate who **Created By** the project.
11. Indicate who **Updated By** the project.
12. Record the **Created At** date of the project.
13. Record the **Updated At** date of the project.
14. Enter a **Form ID** for the project.
15. Enter the location or URL of the **Output File** associated with the project.
16. Indicate the project's **Category** in the select multiple field.
17. Enter a brief **Description** of the project.
18. Enter a title for the **Form Title** field.

## Field-by-Field Explanation

* **Project Details** (Text): A brief description of the project.
* **Designer Information** (Select One): Choose whether the project involves the designer or not. If you are unsure, it's best to answer 'Yes'.
* **Design File** (Text): Enter the URL or location of the design file associated with the project. If you don't have access to the file, please leave it blank.
* **Review Date** (Date): Record the date the project was reviewed. This will help in tracking progress and deadlines.
* **Deadline** (Time): Enter the deadline for the project. Make sure it's accurate and up-to-date.
* **Comments** (Text): Enter any additional comments or notes about the project. This is an open field, feel free to add any relevant information.
* **Project Status** (Select Multiple): Indicate the project's status, whether it's Active or Inactive. This will help in filtering and tracking projects.
* **Assigned Tool** (Select One): Choose whether a specific tool is assigned to the project. If it's not assigned, choose 'No'.
* **Assigned User** (Select Multiple): Select users who are assigned to the project. This will help in keeping track of responsible individuals.
* **Created By** (Select Multiple): Indicate who created the project. This will help in tracking ownership and history.
* **Updated By** (Select Multiple): Indicate who last updated the project. This will help in tracking changes and progress.
* **Created At** (Date): Record the date the project was created. This will help in tracking history and progression.
* **Updated At** (Date): Record the date the project was last updated. This will help in tracking changes and progress.
* **Form ID** (Number): Enter a unique ID for the form.
* **Output File** (Text): Enter the location or URL of the output file associated with the project. If you don't have access to the file, please leave it blank.
* **Category** (Select Multiple): Indicate the project's category. This will help in filtering and categorizing projects.
* **Description** (Text): Enter a brief description of the project. This will help in providing context and background information.
* **Form Title** (Text): Enter a title for the form. This will help in identifying and categorizing the form.
