# Cabinet Cleaning Checklist - Help Guide
## Purpose
The Cabinet Cleaning Checklist is a standardized form for cleaning staff to report on the status of cabinet cleaning activities and identify potential issues.
## How To Complete This Form
1. Fill in the required fields, marked with an asterisk (\*). These fields are:
	* Property or Facility Name (\*)
	* Cleaning Staff Name (\*)
	* Date of Cleaning (\*)
	* Time of Completion (\*)
2. Answer the questions for each section according to your observations and actions.
	+ For each section (Exterior Cleaning Tasks and Interior Cleaning Tasks), select "Done" if the corresponding task has been completed, "N/A" if it is not applicable, or "Partial" if the task has not been completed but is in progress.
	* For the question regarding "Any signs of pest activity inside cabinets", select "False" if there are no signs of pest activity, "Yes - Needs immediate attention" if there are signs of pest activity that require immediate attention.
## Field-by-Field Explanation

* **Property or Facility Name (property_address)**: Enter the name of the property or facility being cleaned.
* **Cleaning Staff Name (cleaner_name)**: Enter the name of the cleaning staff member who performed the cleaning tasks.
* **Date of Cleaning (inspection_date)**: Enter the date on which the cleaning was performed.
* **Room or Location of Cabinets (cabinet_location)**: Select the location of the cabinets, such as "Kitchen", "Lab A", "Office 201", etc.
* **Dust and wipe cabinet tops (dust_tops)**: Select "Done" if the cabinet tops have been dusted and wiped clean, "N/A" if they have not been cleaned, or "Partial" if they have been partially cleaned.
* **Wipe down door surfaces and frames (wipe_doors)**: Select "Done" if the door surfaces and frames have been wiped down, "N/A" if they have not been cleaned, or "Partial" if they have been partially cleaned.
* **Clean and polish handles/knobs (polish_hardware)**: Select "Done" if the handles and knobs have been cleaned and polished, "N/A" if they have not been cleaned, or "Partial" if they have been partially cleaned.
* **Wipe kickplates and baseboards (kickplate_cleaning)**: Select "Done" if the kickplates and baseboards have been wiped clean, "N/A" if they have not been cleaned, or "Partial" if they have been partially cleaned.
* **Shelves emptied and wiped (empty_shelves)**: Select "Done" if the shelves have been emptied and wiped clean, "Partial" if they have been partially cleaned, or "N/A" if they have not been cleaned.
* **Sanitize interior surfaces (sanitize_surfaces)**: Select "Done" if the interior surfaces have been sanitized, "N/A" if they have not been sanitized, or "Partial" if they have been partially sanitized.
* **Contents neatly organized upon return (organize_contents)**: Select "Done" if the contents have been neatly organized, "N/A" if they have not been organized, or "Partial" if they have been partially organized.
* **Are there any loose hinges or hardware (loose_hinges)**: Select "None" if there are no loose hinges or hardware, "Yes - Minor" if there are minor issues with loose hinges or hardware, or "Yes - Repair Needed" if there are issues that require repair.
* **Any signs of pest activity inside cabinets (pest_activity)**: Select "False" if there are no signs of pest activity, "Yes - Needs immediate attention" if there are signs of pest activity that require immediate attention.
* **General Cleaning Notes (additional_comments)**: Enter any general comments about the cleaning or the cabinets.
* **Time of Completion (completion_time)**: Enter the time at which the cleaning was completed.
