# Site Commissioning Checklist - Help Guide
## Purpose
This form is used to track site commissioning outcomes and site readiness. It helps evaluate whether a site is ready for commissioning and what outcomes are expected from the process.

## How To Complete This Form
To complete this form, please follow these steps:

* Select the site commissioning status from the options provided in the Site Commissioning Checklist field.
* Choose one of the commissioning outcomes from the options provided in the Commissioning Outcomes field.
* Enter the site's readiness level as a number in the Site Readiness field.
* Provide any additional review comments in the Review Comments field.
* Select the site commissioning date from the calendar picker.

## Field-by-Field Explanation

* **Site Commissioning Checklist** (`site_commissioning_checklist`, select_multiple, required: false): This field allows you to select the site commissioning status. Please choose one or more of the options to indicate whether the site is ready for commissioning.
* **Commissioning Outcomes** (`commissioning_outcomes`, select_one, required: false): This field is used to select one of the commissioning outcomes. Please choose the outcome that best describes the result of the commissioning process.
* **Site Readiness** (`site_readiness`, number, required: false): This field is used to enter a numerical value indicating the site's readiness level. The exact meaning of this value depends on the context of your organization, but it should be used to assess the site's readiness for commissioning.
* **Review Comments** (`review_comments`, text, required: false): This field is used to provide additional review comments about the site commissioning process. Any relevant information that doesn't fit in the other fields can be entered here.
* **Site Commissioning Date** (`site_commissioning_date`, date, required: false): This field is used to select the date when the commissioning process was performed. Please use the calendar picker to select the correct date.

## Tips

* Make sure to select the correct commissioning outcomes and site commissioning status to ensure accurate tracking and evaluation.
* Enter the site's readiness level in a way that makes sense to your organization's context.
* Use the Review Comments field to provide any additional context or explanations that may be useful for future reference.
* Use the Site Commissioning Date to ensure accurate record-keeping and tracking of the commissioning process.
