# Freezer Inventory Checklist - Help Guide
## Purpose
The Freezer Inventory Checklist is a form used to maintain the inventory of frozen stock. It helps users conduct a systematic check on the condition and quantity of frozen stock, ensuring proper storage and handling practices.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form to ensure you have all the necessary information.
2. For each field, select the correct option that best describes the current state of the frozen stock.
3. If a field is not applicable or not known, select the corresponding option (e.g., "Not Applicable" for restock needs).

## Field-by-Field Explanation
### Page 1: Main Page
* **Freezer Inventory Checklist** (`Main Page`, text, required): This is the title of the form.
* **Frozen Stock Checks** (`frozen_stock_checks`, select_multiple, required): Choose the current state of the frozen stock:
	+ Frozen: The stock is frozen solid and in good condition.
	+ Almost Frozen: The stock is mostly frozen but may not be fully frozen.
	+ Not Frozen: The stock is not frozen at all.
* **Restock Needs** (`restock_needs`, select_multiple, required): Select the restock needs:
	+ True: The stock needs restocking.
	+ False: The stock does not need restocking.
	+ Not Applicable: The stock is not relevant for restocking.
* **Freezer Condition** (`freezer_condition`, text, required): Describe the current condition of the freezer.
* **Storage Temperature** (`storage_temperature`, number, required): Enter the current storage temperature (e.g., 0°C, -20°C, etc.).
* **Storage Humidity** (`storage_humidity`, number, required): Enter the current storage humidity (e.g., 60%, 80%, etc.).
* **Stock Quantity** (`stock_quantity`, text, required): Record the current stock quantity.
* **Storage Location** (`storage_location`, text, required): Record the storage location of the stock.
* **Comments** (`comments`, text, required): Provide any additional comments or notes about the stock.

## Tips
* Ensure you review each field carefully to ensure accurate and complete information.
* If you are unsure about any field, select the corresponding option or leave it blank and ask for clarification.
* Complete the form regularly to maintain accurate and up-to-date inventory records.
