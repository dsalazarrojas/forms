# duty_manager_daily_checklist - Help Guide
## Purpose
The "duty_manager_daily_checklist" form is a tool designed to help duty managers track and manage their daily tasks effectively. It collects information on tasks' status, priority, and other relevant details for supervisory or administrative purposes.

## How To Complete This Form
To complete the "duty_manager_daily_checklist" form, follow these steps:

1.  On the "Daily Tasks" page, enter the tasks you need to accomplish today.
2.  On the "Task Priority" page, select the priority level of each task:
    *   High: Important tasks that need immediate attention.
    *   Medium: Tasks that require moderate attention.
    *   Low: Less urgent tasks.
    *   Not Prioritized: Tasks without a specific priority.
3.  On the "Task Status" page, select the current status of each task:
    *   Assigned: Tasks that have been assigned to someone.
    *   Due Today: Tasks with a deadline that falls within today's date.
    *   Overdue: Tasks that have missed their deadline.
    *   Not Started: Tasks that are still in the planning stage.
4.  On the "Notes" page, add any notes or comments about each task.
5.  You can enter your email address and phone number on the respective fields if you need to be contacted about these tasks.
6.  If necessary, enter the created date and start/end time of each task.

## Field-by-Field Explanation
*   **Daily Tasks**: A text field where you can list all the tasks you need to accomplish today. This is where you should input all the tasks that you or others are expected to complete.
*   **Task Priority**: A dropdown field where you need to select the priority level of each task. This helps to categorize tasks based on their urgency and importance.
*   **Task Status**: A dropdown field to select the current status of each task. This indicates how much progress has been made on each task or where it is in the process.
*   **Notes**: A note field where you can add comments or details about each task. This is a good place to record any observations or information that might be useful in the future.
*   **Email**: Enter your email address if you want to be contacted about these tasks or if others need to reach you about them.
*   **Phone**: Enter your phone number if you need to be contacted about these tasks or if others need to reach you about them.
*   **Created At**: The date the task was created.
*   **Start Time**: The time you started working on the task.
*   **End Time**: The time you finished working on the task.

## Tips
*   Make sure to accurately select the priority and status of each task to reflect its actual urgency and progress.
*   Keep the notes field concise but informative to help in the tracking and reference of each task.
*   Be cautious when entering sensitive information such as email and phone numbers.
*   Use the form in accordance with your role and the organization's internal procedures.
