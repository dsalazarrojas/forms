# Shop Assistant Opening Routine Checklist - Help Guide
## Purpose
The Shop Assistant Opening Routine Checklist is designed to help you prepare your workstation for the start of the day. It guides you through the essential tasks and checks that need to be completed before opening the shop.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Review each section carefully and ensure you have completed all required tasks.
2. Select the relevant options for each section based on your specific shop needs.
3. Fill out each section accurately and thoroughly.

## Field-by-Field Explanation

* **Pre-opening tasks**:
	+ This field is for recording any pre-opening tasks that need to be completed before the shop opens.
* **Storefront cleaning**:
	+ This field is for noting the condition of the storefront, including any cleaning or maintenance that needs to be done.
* **Display setup**:
	+ This field is for ensuring that all displays and fixtures are in working order and ready for customers.
* **Inventory verification**:
	+ This field is for checking that the inventory is accurate and up-to-date.
* **Staff scheduling**:
	+ This field is for indicating whether staff are scheduled to work on this day.
	+ Select 'Yes' if staff are scheduled, 'No' if they are not.
* **Stockroom organization**:
	+ This field is for noting the organization and tidiness of the stockroom.
	+ Select multiple options if applicable (e.g., 'Yes', 'No').
* **Equipment checking**:
	+ This field is for ensuring that all equipment is in working order and ready for use.
	+ Select 'Yes' if equipment is functioning correctly, 'No' if not.
* **Security checking**:
	+ This field is for verifying that security measures are in place and functioning properly.
	+ Select 'Yes' if security measures are in place, 'No' if not.
* **Customer safety**:
	+ This field is for ensuring that all safety measures are in place for customers.
	+ Select multiple options if applicable (e.g., 'Yes', 'No').
* **Shop financials**:
	+ This field is a note section for recording any relevant financial information or notes related to the shop's opening routine.
