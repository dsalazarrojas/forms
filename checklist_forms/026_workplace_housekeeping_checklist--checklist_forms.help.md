# Workplace Housekeeping Checklist - Help Guide
## Purpose
The Workplace Housekeeping Checklist is a form used for maintaining and updating information about employee workplace housekeeping details. The purpose of this form is to collect relevant data in a structured and organized manner, making it easier for users to track and analyze employee information. This form is intended for use in a work environment and should only be used to collect data from employees in the relevant departments.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct Checklist Type (e.g., Checklist 1, 2, or 3) to indicate the purpose of the form.
2. Enter the Employee Name, which is the name of the employee being checked.
3. Fill in the Employee Contact information, including Phone and Email.
4. Enter the Employee Address, which is the address of the employee's workplace.
5. Select the correct Supervisor for the employee.
6. Choose the departments the employee belongs to (select one or more departments).
7. Choose the status of the form (Active or Inactive).
8. Optionally, add any additional Notes about the form.

## Field-by-Field Explanation
* **Workplace**: This field is a text field where you can enter any relevant information about the employee's workplace. This field is not required.
* **Date**: This field is a date field where you can enter the date the form was last updated or completed. This field is not required.
* **Time**: This field is a time field where you can enter the time the form was last updated or completed. This field is not required.
* **Employee Name**: This field is a text field where you can enter the name of the employee being checked. This field is not required.
* **Employee Contact**: This field is a text field where you can enter the employee's contact information, including phone number and email. This field is not required.
* **Employee Email**: This field is an email field where you can enter the employee's email address. This field is not required.
* **Employee Phone**: This field is a text field where you can enter the employee's phone number. This field is not required.
* **Employee Address**: This field is a text field where you can enter the employee's workplace address. This field is not required.
* **Employee Supervisor**: This field is a dropdown field where you can select the supervisor of the employee. This field is not required.
* **Employee Department**: This field is a multi-select field where you can choose the departments the employee belongs to. This field is not required.
* **Checklist Type**: This field is a dropdown field where you can select the type of checklist (e.g., Checklist 1, 2, or 3). This field is not required.
* **Checklist Date**: This field is a date field where you can enter the date the checklist was last updated or completed. This field is not required.
* **Checklist Time**: This field is a time field where you can enter the time the checklist was last updated or completed. This field is not required.
* **Checklist Notes**: This field is a note field where you can add any additional information about the checklist. This field is not required.
* **Checklist Status**: This field is a dropdown field where you can select the status of the form (Active or Inactive). This field is not required.

## Tips
* Make sure to fill in accurate and up-to-date information about the employee's workplace and contact details.
* Choose the correct Supervisor and departments for the employee.
* Select the correct Checklist Type and status for the form.
* If you need to add any additional information about the form, use the Checklist Notes field.
* Remember to review and update the form regularly to ensure the information is current and accurate.
