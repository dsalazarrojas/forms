# Beginner Swimming Skills Checklist - Help Guide
## Purpose
The Beginner Swimming Skills Checklist is a tool used by swimming instructors to evaluate the swimming skills of their students. It helps instructors assess the student's proficiency in various swimming skills, identify areas of strength and weakness, and make informed decisions about student progression.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the student's name and the instructor's name in the respective fields.
2. Select the lesson level or class name for the student from the given options.
3. Record the date of evaluation for the student.
4. Go through each skill section and select the corresponding level of proficiency (Mastered, In Progress, or Not Attempted) for each skill.
5. Enter the overall water confidence level of the student (1-5) and any key skills to focus on in the next lessons.
6. Answer the question of whether the student is recommended for progression to the next level.
7. Finally, add any additional comments or progress notes from the instructor.

* **Date of Evaluation** (Date of Evaluation, date, required): Enter the date of the evaluation.

* **Front float (with support)** (Skill Front float (with support), select_one, required): Select if the student has mastered, is in progress, or has not attempted this skill.
* **Back float (with support)** (Skill Back float (with support), select_one, required): Select if the student has mastered, is in progress, or has not attempted this skill.
