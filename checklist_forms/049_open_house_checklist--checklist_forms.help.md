# Open House Checklist - Help Guide
## Purpose
The Open House Checklist is a tool to help you evaluate the condition and features of a house. It's essential to complete this form accurately to get a clear picture of the house's suitability for your needs.

## How To Complete This Form
1. Start by filling out the basic information about the house.
2. Go through each field carefully and answer the questions truthfully.
3. Don't hesitate to ask for clarification if you're unsure about any field.

## Field-by-Field Explanation

* **House Address** (`house_address`, text, required/optional): This field is for the address of the house. Please enter the full address, including street number and name.
* **House Type** (`house_type`, text, required/optional): This field is for the type of house. You can select from a list of options or enter a description of the type (e.g., single-family home, condo, etc.).
* **Year Built** (`year_built`, number, required/optional): This field is for the year the house was built. If you're unsure, you can estimate or leave it blank.
* **Condition** (`condition`, text, required/optional): This field is for the overall condition of the house. You can select from a list of options or enter a description (e.g., excellent, fair, etc.).
* **Bathrooms** (`bathrooms`, number, required/optional): This field is for the number of bathrooms in the house.
* **Bedrooms** (`bedrooms`, number, required/optional): This field is for the number of bedrooms in the house.
* **Square Footage** (`square_footage`, number, required/optional): This field is for the square footage of the house.
* **Lot Size** (`lot_size`, number, required/optional): This field is for the size of the lot.
* **Lot Frontage** (`lot_frontage`, text, required/optional): This field is for the frontage of the lot.
* **Garage Parking** (`garage_parking`, text, required/optional): This field is for the garage parking available.
* **Exterior Finish** (`exterior_finishes`, text, required/optional): This field is for the exterior finish of the house.
* **Interior Finish** (`interior_finishes`, text, required/optional): This field is for the interior finish of the house.
* **Electrical** (`electrical`, text, required/optional): This field is for the electrical features available in the house.
* **Plumbing** (`plumbing`, text, required/optional): This field is for the plumbing features available in the house.
* **Heating** (`heating`, text, required/optional): This field is for the heating features available in the house.
* **Cooling** (`cooling`, text, required/optional): This field is for the cooling features available in the house.
* **Fire Safety** (`fire_safety`, text, required/optional): This field is for the fire safety features available in the house.
* **Security** (`security`, text, required/optional): This field is for the security features available in the house.
* **Electrical Outlets** (`electrical_outlets`, select_multiple, required): This field is for selecting multiple electrical outlets available in the house. You can select from the options provided.
* **Electrical Outlets Note** (`electrical_outlets_note`, note, required/optional): This field is for any additional information about the electrical outlets.

Note: Some fields are required to be filled out, while others are optional. Make sure to fill out all the required fields to get an accurate assessment of the house.
