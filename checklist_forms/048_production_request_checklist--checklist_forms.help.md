# Production Request Checklist - Help Guide

## Purpose
The Production Request Checklist form is used to collect information from production teams to ensure that all necessary steps and checks are performed before starting production.

## How To Complete This Form
To complete this form, follow the steps outlined in the explanation above.

## Field-by-Field Explanation
* **production_request_checklist_1** (`production_request_checklist_1`, select_multiple, optional): Choose "Yes" if this step is required for production, "No" otherwise.
* **job_requester** (`job_requester`, text, optional): Enter the name of the person requesting the production job.
* **job_requester_email** (`job_requester_email`, email, optional): Enter the email address of the person requesting the production job.
* **job_request_details** (`job_request_details`, note, optional): Enter a detailed description of the production job.
* **job_priority** (`job_priority`, select_one, optional): Select the priority level of the job from the dropdown menu.
* **job_priority_label** (`job_priority_label`, text, optional): This field is not used for the purpose of this form.
* **production_request_checklist_2** (`production_request_checklist_2`, select_multiple, optional): Choose "Yes" if this step is required for production, "No" otherwise.
* **production_request_checklist_3** (`production_request_checklist_3`, select_multiple, optional): Choose "Yes" if this step is required for production, "No" otherwise.
