# lawn_mower_inspection_checklist_checklist_forms - Help Guide
## Purpose

This guide is for users who are experienced with lawn mower maintenance and repair. It walks through the process of completing the lawn mower inspection checklist form to help identify potential issues with the mower.

## How To Complete This Form

To complete this form, follow these steps:

* Review each section of the form carefully and provide information about the current state of the lawn mower.
* Answer each question based on your observation of the mower.
* Be thorough and accurate in your answers, as the information will be used to determine the mower's condition.

## Field-by-Field Explanation

* **Model Number** (`model_number`, number, required): Enter the model number of the lawn mower.
* **Location** (`location`, text, required): Enter the location where the mower is currently being used.
* **Oil Level** (`oil_level`, select_multiple, required): Select the current oil level of the mower (High, Low).
* **Air Filter Clean** (`air_filter_clean`, select_one, required): Check if the air filter is clean (Yes, No).
* **Sparkplug Worn** (`sparkplug_worn`, select_one, required): Check if the sparkplug is worn (Yes, No).
* **Sparkplug Gapped** (`sparkplug_gapped`, select_one, required): Check if the sparkplug is gapped (Yes, No).
* **Cutting Edge Condition** (`cutting_edge_condition`, number, required): Enter the current condition of the cutting edge (e.g., 1-5).
* **Blade Clean** (`blade_clean`, select_one, required): Check if the blade is clean (Yes, No).
* **Drive System** (`drive_system`, select_one, required): Check if the drive system is functioning properly (Yes, No).
* **Tire Condition** (`tire_condition`, select_one, required): Check the condition of the tires (Yes, No).
* **Tire Tread** (`tire_tread`, select_one, required): Check the tread of the tires (Yes, No).
* **Tire Inflated** (`tire_inflated`, select_one, required): Check if the tires are inflated (Yes, No).
* **Oil Change** (`oil_change`, select_one, required): Check if the oil has been changed recently (Yes, No).
* **Blade Sharpening** (`blade_sherp`, select_one, required): Check if the blade has been sharpened recently (Yes, No).
* **Air Filter Clean** (`air_filter_clean`, select_one, required): Check if the air filter has been cleaned recently (Yes, No).
* **Sparkplug Replaced** (`sparkplug_replaced`, select_one, required): Check if the sparkplug has been replaced recently (Yes, No).
