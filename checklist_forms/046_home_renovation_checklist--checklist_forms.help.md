# Home Renovation Checklist - Help Guide
## Purpose
This form is designed to manage home renovation projects, allowing project managers and reviewers to track and record relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information from the provided options for each field.
2. Enter all the required and optional information as needed.
3. Review and submit the form once you have completed all the necessary fields.

## Field-by-Field Explanation

* **Contractor information** (`Contractor information`, `select_multiple`, required: false):
	+ Select the name of the contractor(s) involved in the project.
* **Project details** (`Project details`, `select_one`, required: false):
	+ Choose the relevant project details that apply to your project.
* **Renovation plan** (`Renovation plan`, `text`, required: false):
	+ Enter a detailed renovation plan, including any timelines.
* **Budget** (`Budget`, `number`, required: false):
	+ Enter your budget details.
* **Contact info** (`Contact info`, `text`, required: false):
	+ Enter the contact information for your contact person.
* **Phone numbers** (`Phone numbers`, `text`, required: false):
	+ Enter multiple phone numbers separated by commas.
* **Start date** (`Start date`, `date`, required: false):
	+ Enter the start date of the project.
* **End date** (`End date`, `time`, required: false):
	+ Enter the end date of the project.
* **Notes** (`Notes`, `note`, required: false):
	+ Enter any general notes about the project.
* **Contractor notes** (`Contractor notes`, `note`, required: false):
	+ Enter any notes about the contractor.
* **Review status** (`Review status`, `select_one`, required: false):
	+ Select the status of the review (In review, Approved, Rejected).
* **Review comments** (`Review comments`, `text`, required: false):
	+ Enter your review comments.
* **Architect info** (`Architect info`, `text`, required: false):
	+ Enter your architect's contact information.
* **Project manager info** (`Project manager info`, `text`, required: false):
	+ Enter your project manager's contact information.
* **Client info** (`Client info`, `text`, required: false):
	+ Enter your client's contact information.
* **Project status** (`Project status`, `select_one`, required: false):
	+ Select the project status (Active, Completed, Cancelled).
* **Project notes** (`Project notes`, `note`, required: false):
	+ Enter any notes about the project.
* **Contractor status** (`Contractor status`, `select_one`, required: false):
	+ Select the contractor's status (Active, Completed, Not Started).
* **Contract notes** (`Contract notes`, `note`, required: false):
	+ Enter any notes about the contractor.
* **Additional notes** (`Additional notes`, `text`, required: false):
	+ Enter any additional notes.
* **Contractor additional notes** (`Contractor additional notes`, `note`, required: false):
	+ Enter any additional notes about the contractor.
* **Reviewer info** (`Reviewer info`, `text`, required: false):
	+ Enter your reviewer's contact information.
* **Review date** (`Review date`, `date`, required: false):
	+ Enter the review date.
* **Reviewed by** (`Reviewed by`, `text`, required: false):
	+ Enter the name of the person who reviewed the project.
* **Review comments** (`Review comments`, `text`, required: false):
	+ Enter your review comments.

**Tips**

* Ensure that all required fields are completed before submitting the form.
* Use the correct format for dates and times.
* Enter any relevant additional notes or comments where possible.
* Review and verify all information before submission.
