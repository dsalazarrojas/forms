# equipment_readiness_checklist - Help Guide

## Purpose
The equipment readiness checklist is a tool to assess the current status of equipment, ensuring it's ready for use and maintenance. This form helps identify potential issues and track inspection history, maintenance status, and other crucial information.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have access to the equipment's records and any relevant documents.
2. Review the form pages below and select the relevant information for each field.

## Field-by-Field Explanation

* **Equipment Status**: Enter a brief description of the equipment's current status (e.g., operational, non-operational, in repair).
* **Inspection Dates**: Select all relevant inspection dates, or type "None" if there are no inspections recorded.
* **Prophets**: Select the prophet(s) associated with this equipment, or type "None" if not applicable.
* **Last Equipment Inspection**: Enter the date of the last equipment inspection.
* **Last Equipment Check**: Enter the time of the last equipment check.
* **Maintenance Status**: Enter a brief description of the equipment's maintenance status (e.g., up-to-date, pending, overdue).
* **Maintenance History**: Add a detailed note about the equipment's maintenance history, if applicable.
* **Equipment Type**: Select the type of equipment (e.g., A, B, C, or None).
* **Notes**: Add any additional comments or notes about the equipment's status, if necessary.
