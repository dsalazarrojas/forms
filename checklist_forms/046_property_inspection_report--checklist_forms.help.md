# property_inspection_report - Help Guide
## Purpose
This form is designed to collect information about property inspections. It gathers details such as property type, condition, location, size, and other relevant information for reporting purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the **property_type** field to specify whether the property is active or inactive.
2.  In the **property_condition** field, select multiple options to indicate any observed damages or issues with the property.
3.  Enter the **property_location** to specify the location of the property.
4.  Enter the **property_size** to provide the size of the property.
5.  In the **property_features** field, provide a brief description of the property's features.
6.  Select the **property_status** field to specify whether the property is active or inactive.
7.  In the **property_damage** field, select multiple options to indicate any observed damages or issues with the property.
8.  Enter the **tenant_inspection** date to record the date of the property inspection.
9.  Enter the **agent_inspection** time to record the time of the property inspection.
10. Select the **report_status** field to specify the status of the report.
11. Enter the **property_id** field to provide the ID of the property.
12. Enter the **tenant_id** field to provide the ID of the tenant.
13. Enter the **agent_id** field to provide the ID of the agent.
14. Select the **report_completed** field to record the date when the report was completed.
15. Select the **report_completed_by** field to indicate whether the report was completed.

## Field-by-Field Explanation

* **property_type** (`property_type`, select_one, optional): Select whether the property is active or inactive.
* **property_condition** (`property_condition`, select_multiple, optional): Select multiple options to indicate any observed damages or issues with the property.
* **property_location** (`property_location`, text, optional): Enter the location of the property.
* **property_size** (`property_size`, number, optional): Enter the size of the property.
* **property_features** (`property_features`, text, optional): Provide a brief description of the property's features.
* **property_status** (`property_status`, select_one, optional): Select whether the property is active or inactive.
* **property_damage** (`property_damage`, select_multiple, optional): Select multiple options to indicate any observed damages or issues with the property.
* **tenant_inspection** (`tenant_inspection`, date, optional): Enter the date of the property inspection.
* **agent_inspection** (`agent_inspection`, time, optional): Enter the time of the property inspection.
* **report_status** (`report_status`, select_one, optional): Select the status of the report.
* **property_id** (`property_id`, text, optional): Enter the ID of the property.
* **tenant_id** (`tenant_id`, text, optional): Enter the ID of the tenant.
* **agent_id** (`agent_id`, text, optional): Enter the ID of the agent.
* **report_completed** (`report_completed`, date, optional): Enter the date when the report was completed.
* **report_completed_by** (`report_completed_by`, select_one, optional): Select whether the report was completed.
