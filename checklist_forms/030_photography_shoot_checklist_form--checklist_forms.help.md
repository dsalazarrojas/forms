# photography_shoot_checklist_form - Help Guide
## Purpose
This form is used to document and confirm important details related to a photography shoot, ensuring a smooth execution and accurate information capture.

## How To Complete This Form

1. Review each page carefully and ensure you understand the question or field before proceeding.
2. Answer each question truthfully and accurately to the best of your ability.
3. If you are unsure about any question, please consult with the team or supervisor before proceeding.
4. Complete each section thoroughly and take note of any necessary follow-up actions or comments.

## Field-by-Field Explanation

### Preparation (Page 1)
* **Preparation** (`Preparation`, select_multiple, required/optional): Select 'Yes' if the necessary preparation for the shoot has been completed, or 'No' if not. This includes ensuring all necessary equipment, location, and other logistical details are in order.
* **Location** (`Location`, select_one, required/optional): Select 'Yes' if the location for the shoot is confirmed, or 'No' if not.
* **Client Info** (`Client Info`, note, required/optional): Briefly note any relevant client information that might be useful for the shoot.
* **Shoot Notes** (`Shoot Notes`, text, required/optional): Add any additional notes or comments about the shoot that might be important for the team or supervisor to know.

### Equipment (Page 2)
* **Equipment** (`Equipment`, text, required/optional): List the necessary equipment required for the shoot, if any.

### Schedule (Page 3)
* **Schedule** (`Schedule`, date, required/optional): Note the date for the shoot.
* **Shoot Date** (`Shoot Date`, date, required/optional): Select a specific date for the shoot.
* **Shoot Start** (`Shoot Start`, time, required/optional): Note the start time for the shoot.
* **Shoot End** (`Shoot End`, time, required/optional): Note the end time for the shoot.
* **Shoot Time** (`Shoot Time`, time, required/optional): Select a specific time for the shoot.

### Team Info (Page 4)
* **Team Info** (`Team Info`, text, required/optional): Briefly note any relevant team information that might be useful for the shoot.
* **Photographer Notes** (`Photographer Notes`, text, required/optional): Add any additional notes or comments from the photographer.

### Client Confirmation (Page 5)
* **Client Confirmation** (`Client Confirmation`, select_one, required/optional): Select 'Yes' if the client has confirmed the shoot, or 'No' if not.
* **Client Approval** (`Client Approval`, select_one, required/optional): Select 'Yes' if the client has approved the shoot, or 'No' if not.

### Additional Info (Page 6)
* **Client Info (Additional)** (`Client Info (Additional)`, text, required/optional): Add any additional information from the client that might be relevant for the shoot.
* **Photographer Notes (Additional)** (`Photographer Notes (Additional)`, text, required/optional): Add any additional notes or comments from the photographer.

## Tips
- Ensure to review and update this form thoroughly before and after the shoot.
- Use clear and concise language when filling out the form.
- Do not hesitate to ask if you are unsure about any question or field.
- This form is for the benefit of the team and the shoot's success, so please fill it out accurately and completely.
