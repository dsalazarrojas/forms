# DLP Incident Response Checklist - Help Guide
## Purpose
The DLP Incident Response Checklist is a form used to report and track potential incidents. It is designed to collect key information about an incident and provide a structured way to categorize and prioritize them.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide a brief description of what happened.
2. Classify the incident using the provided options or specify a different classification if it does not fit into any of the options.
3. Select the type of incident that occurred (e.g., A, B, C).
4. If the incident type does not fit into any of the provided options, specify the type in the "Incident Type Other" field.
5. Enter the date and time the incident occurred.
6. Provide the location where the incident occurred.
7. Describe the incident in more detail.
8. Select the potential impact of the incident (e.g., Low, Medium, High).
9. If the potential impact does not fit into any of the provided options, specify the impact in the "Incident Impact Other" field.
10. Select the severity of the incident (e.g., Low, Medium, High).
11. If the severity does not fit into any of the provided options, specify the severity in the "Incident Severity Other" field.
12. Provide the contact information of the responder(s) who will handle the incident.
13. Add any additional notes or comments about the incident.

## Field-by-Field Explanation

* **What happened** (Text): A brief description of what happened.
* **Classification** (Select One): Classify the incident using one of the provided options (A, B, C) or specify a different classification if it does not fit into any of the options.
* **If other please specify** (Text): If the incident classification does not fit into any of the provided options, use this field to specify a different classification.
* **Type** (Select Multiple): Select one or more incident types that apply to the incident (e.g., A, B, C).
* **Incident Type Other** (Text): If the incident type does not fit into any of the provided options, use this field to specify a different type.
* **Date** (Date): Enter the date the incident occurred.
* **Time** (Time): Enter the time the incident occurred.
* **Location** (Text): Provide the location where the incident occurred.
* **Incident description** (Text): Describe the incident in more detail.
* **Impact** (Select One): Select the potential impact of the incident (e.g., Low, Medium, High).
* **Incident Impact Other** (Text): If the potential impact does not fit into any of the provided options, use this field to specify a different impact.
* **Severity** (Select Multiple): Select one or more severity levels that apply to the incident (e.g., Low, Medium, High).
* **Incident Severity Other** (Text): If the severity does not fit into any of the provided options, use this field to specify a different severity.
* **Responder** (Text): Provide the name of the responder(s) who will handle the incident.
* **Incident Responder 2** (Text): Provide the name of the second responder (if applicable).
* **Responder email** (Email): Enter the email address of the responder(s).
* **Responder phone** (Text): Enter the phone number of the responder(s).
* **Responder notes** (Note): Add any additional notes or comments about the incident.
* **Incident Responder Note 2** (Text): Add any additional notes or comments from the second responder (if applicable).
* **Responder notes 2** (Note): Add any additional notes or comments about the incident.
* **Incident Responder Note 2 3** (Text): Add any additional notes or comments from the third responder (if applicable).
* **Reviewed By** (Text): Enter the name of the person who reviewed the incident.
