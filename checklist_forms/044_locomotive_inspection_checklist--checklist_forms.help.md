# Locomotive Inspection Checklist - Help Guide
## Purpose
The Locomotive Inspection Checklist is a form used to collect information about the status and condition of a locomotive.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the locomotive type from the dropdown list.
2. Enter the inspection date and time using the date and time fields.
3. Enter the location where the inspection was performed.
4. Answer if the locomotive was inspected by multiple people or just one.
5. Choose the locomotive's status as active or inactive.
6. Enter any comments about the locomotive's status.
7. Enter any additional comments about the inspection.
8. Enter any comments about the inspection process itself.
9. Choose whether the locomotive is assigned to someone or not.

## Field-by-Field Explanation

* **Locomotive Type** (locomotive_type): This field allows you to select the type of locomotive being inspected. Please choose the correct option from the dropdown list.
* **Inspection Date** (inspection_date): This field is used to enter the date of the inspection. Please use the standard date format (MM/DD/YYYY) to avoid any formatting issues.
* **Inspection Time** (inspection_time): This field is used to enter the time of the inspection. Please use the 24-hour format (HH:MM).
* **Inspection Location** (inspection_location): This field is used to enter the location where the inspection was performed.
* **Inspected By** (inspected_by): This field indicates whether the locomotive was inspected by multiple people or just one. Please choose the correct option from the dropdown list.
* **Locomotive Status** (locomotive_status): This field is used to indicate the locomotive's status as active or inactive. Please choose the correct option from the dropdown list.
* **Locomotive Status Comment** (locomotive_status_comment): This field is used to enter any comments about the locomotive's status.
* **Additional Comments** (additional_comments): This field is used to enter any additional comments about the inspection.
* **Locomotive Inspection Checklist Comments** (locomotive_inspection_checklist_comments): This field is used to enter any comments about the inspection process itself.
* **Assigned To** (assigned_to): This field is used to indicate whether the locomotive is assigned to someone or not. Please choose the correct option from the dropdown list.
