# Art Exhibition Setup Checklist Form - Help Guide
## Purpose
The Art Exhibition Setup Checklist Form is used to ensure that all necessary steps are taken to prepare the exhibition space for the event. It is a checklist to help the setup coordinator keep track of the progress and status of each task.

## How To Complete This Form
1. Fill in the **Exhibition Title** field with the title of the exhibition.
2. Enter the **Setup Coordinator Name**.
3. Select the **Scheduled Setup Date and Time**.
4. For each of the remaining fields, select the status of the task from the options provided. For example, if the walls are cleaned and prepped for hanging, select **Complete**.
5. Enter any **Additional Setup Observations or Notes** if necessary.
6. Sign and date the **Setup Approved By (Signature)** field to confirm completion of the form.
7. Enter the time of completion in the **Time of Completion** field.

## Field-by-Field Explanation

* **Exhibition Title**: The title of the exhibition.
* **Setup Coordinator Name**: The name of the person responsible for setting up the exhibition.
* **Scheduled Setup Date and Time**: The date and time the exhibition is scheduled to be set up.
* **Walls cleaned and prepped for hanging**: Select **Complete** if the walls are cleaned and prepped for hanging artwork.
* **Lighting adjusted for artwork positions**: Select **Complete** if the lighting is adjusted for artwork positions.
* **Entrance and directional signage installed**: Select **Complete** if the entrance and directional signage is installed.
* **All artworks delivered and inspected for damage**: Select **True** if all artworks have been delivered and inspected for damage.
* **Hanging hardware and mounts secured**: Select **Complete** if hanging hardware and mounts are secured.
* **Artwork labels and descriptions placed correctly**: Select **Complete** if artwork labels and descriptions are placed correctly.
* **All framed works checked for level**: Select **Complete** if all framed works are checked for level.
* **Pedestals and cases stabilized and locked**: Select **Stable** if pedestals and cases are stabilized and locked. For 3D works.
* **Insurance inventory list finalized and signed**: Select **True** if the insurance inventory list is finalized and signed.
* **Price list available at the front desk**: Select **Ready** if the price list is available at the front desk.
* **Floor areas cleared of tripping hazards**: Select **Clear** if floor areas are cleared of tripping hazards.
* **Additional Setup Observations or Notes**: Enter any additional setup observations or notes.
* **Setup Approved By (Signature)**: Sign and date this field to confirm completion of the form.
* **Time of Completion**: Enter the time of completion.
