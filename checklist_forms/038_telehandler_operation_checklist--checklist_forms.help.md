# Telehandler Operation Checklist - Help Guide
## Purpose
This form is designed to collect information about telehandler operations on construction sites. It includes fields for key details such as operation date, start and end times, site area, number of operators and observers, and supervisor contact information. The form also includes a status field to track the current status of the operation and a comments section for any additional notes or comments.

## How To Complete This Form
1. Enter the **Construction Site Name** in the text box provided. This is the specific location where the telehandler operation took place.
2. Select the **Telehandler Type** from the dropdown menu. This will help identify the specific type of telehandler used for the operation.
3. Choose the **Operation Date** from the calendar or date picker. This is the date when the operation occurred.
4. Enter the **Operation Start Time** and **Operation End Time** using the time input fields. These fields will help track the duration of the operation.
5. Enter the **Site Area** in the text box. This is the specific area within the construction site where the telehandler was used.
6. Enter the **Number of Operators** and **Number of Observers** using the number input fields. These fields will help track the number of personnel involved.
7. Enter the **Supervisor Name** and **Supervisor Phone** in the text boxes. This information will allow others to contact the supervisor if needed.
8. Enter the **Job Number** in the text box. This is a unique identifier for the operation.
9. Select the **Operation Status** from the dropdown menu. This will indicate the current status of the operation.
10. Use the **Comments** field for any additional notes or comments about the operation.
11. Enter the **Assigned Tool** if any specialized equipment was used. This can include specific tool serial numbers or models.

## Field-by-Field Explanation
* **Construction Site Name (ID 1)**: The specific location where the operation occurred.
* **Telehandler Type (ID 2)**: The specific type of telehandler used, such as Boom Lift, Articulated Digger, or Telehandler.
* **Operation Date (ID 3)**: The date the operation took place. Use the calendar or date picker to choose the correct date.
* **Operation Start Time (ID 4)**: The start time of the operation. Enter the time in the correct format.
* **Operation End Time (ID 5)**: The end time of the operation. Enter the time in the correct format.
* **Site Area (ID 6)**: The specific area within the site where the operation occurred.
* **Number of Operators (ID 7)**: The number of people operating the telehandler.
* **Number of Observers (ID 8)**: The number of people observing the operation.
* **Supervisor Name (ID 9)**: The name of the supervisor responsible for the operation.
* **Supervisor Phone (ID 10)**: The phone number of the supervisor.
* **Job Number (ID 11)**: A unique identifier for the operation.
* **Operation Status (ID 12)**: The current status of the operation, such as Active, In Progress, or Completed.
* **Comments (ID 13)**: Any additional notes or comments about the operation.
* **Assigned Tool (ID 14)**: Any specific tool or equipment used during the operation, including serial numbers or models.
