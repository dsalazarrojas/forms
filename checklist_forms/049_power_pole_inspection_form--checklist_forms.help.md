# Power Pole Inspection Form - Help Guide
## Purpose
The Power Pole Inspection Form is a comprehensive form used to record the condition and inspection data of power poles. It is intended for routine inspections of power poles that are not in an emergency situation.

## How To Complete This Form
1. Start by selecting the inspection method used (Visual or Non-Visual).
2. Record the inspection date and time.
3. Enter the inspection location.
4. Evaluate the condition of the pole, checking weather protection, grounding, conduit, and insulation.
5. Record any other conditions that are present.

## Field-by-Field Explanation

* **Inspect power pole** (Text, Optional): Enter a description of the pole being inspected.
* **Condition** (Select One, Required): Select the overall condition of the pole (Good, Fair, Poor).
* **Paint Condition** (Select Multiple, Optional): Select the condition of the pole's paint.
* **Base Condition** (Select One, Required): Select the condition of the pole's base (Good, Fair, Poor).
* **Record Inspection** (Text, Optional): Enter a description of the inspection.
* **Check Elevation** (Number, Optional): Enter the pole's elevation.
* **Weather Condition** (Select One, Optional): Select the condition of the weather (Good, Fair, Poor).
* **Structural Integrity** (Select Multiple, Optional): Select the condition of the pole's structural integrity.
* **Grounding** (Select One, Optional): Select the condition of the pole's grounding.
* **Grounding Wires** (Select Multiple, Optional): Select the condition of the grounding wires.
* **Grounding Type** (Select One, Optional): Select the type of grounding.
* **Grounding Size** (Number, Optional): Enter the size of the grounding.
* **Inspection Date** (Date, Optional): Enter the inspection date.
* **Inspection Time** (Time, Optional): Enter the inspection time.
* **Inspection Location** (Text, Optional): Enter the inspection location.
* **Inspection Method** (Select One, Required): Select the inspection method used (Visual or Non-Visual).
* **Weather Protection** (Select Multiple, Optional): Select the condition of the weather protection.
* **Grounding Insulation** (Select Multiple, Optional): Select the condition of the grounding insulation.
* **Conduit Type** (Select One, Optional): Select the type of conduit.
* **Conduit Condition** (Select One, Optional): Select the condition of the conduit.
* **Insulated Conduit** (Select Multiple, Optional): Select the condition of the insulated conduit.
* **Insulation Type** (Select One, Optional): Select the type of insulation.
* **Insulation Condition** (Select One, Optional): Select the condition of the insulation.
* **Other Conditions** (Text, Optional): Enter any other conditions that are present.
