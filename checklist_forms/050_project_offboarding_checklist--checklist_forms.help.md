# project_offboarding_checklist - Help Guide
## Purpose
The project offboarding checklist is used to collect and document information about projects that are being removed from the project portfolio.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant sections and fields that apply to the project.
2. Answer each field as accurately and thoroughly as possible.
3. Review the form for completeness and accuracy before submitting.

## Field-by-Field Explanation
### Project Goals
* **What was the primary project goal?** (`project_offboarding_checklist_field_1`, `text`, required: false): Enter a brief description of the project's primary goal.
* **What was the project timeline?** (`project_offboarding_checklist_field_2`, `date`, required: false): Enter the project start and end dates.
* **What was the project budget?** (`project_offboarding_checklist_field_3`, `number`, required: false): Enter the project budget, if applicable.
* **What were the project deliverables?** (`project_offboarding_checklist_field_4`, `select_multiple`, required: false): Select all the deliverables that were part of the project.
* **What were the project risks?** (`project_offboarding_checklist_field_5`, `select_one`, required: false): Select the risk that was most relevant to the project.
* **What were the project stakeholders?** (`project_offboarding_checklist_field_6`, `email`, required: false): Enter the email addresses of the project stakeholders.
* **What were the project outcomes?** (`project_offboarding_checklist_field_8`, `select_multiple`, required: false): Select all the outcomes that were achieved by the project.

### Project Team
* **Who was the project manager?** (`project_offboarding_checklist_field_7`, `text`, required: false): Enter the name of the project manager.
* **What were the project team members?** (`project_offboarding_checklist_field_10`, `select_multiple`, required: false): Select all the team members involved in the project.
* **What were the project dependencies?** (`project_offboarding_checklist_field_11`, `select_multiple`, required: false): Select all the dependencies that were part of the project.
* **What were the project team members?** (`project_offboarding_checklist_field_12`, `select_multiple`, required: false): Select all the team members involved in the project.

### Project Offboarding Checklist

* **What were the project dependencies?** (`project_offboarding_checklist_field_15`, `select_multiple`, required: false): Select all the dependencies that were part of the project.
