# Facility Walkthrough Checklist - Help Guide
## Purpose
The Facility Walkthrough Checklist is a form used to assess the condition and readiness of a facility for occupancy.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the checklist, which covers different aspects of the facility.
2. For each page, select the relevant options to indicate the presence or absence of specific features or conditions.
3. Enter any additional comments or notes as necessary.

## Field-by-Field Explanation
* **First Floor**: Check to indicate if the first floor of the facility has been inspected. Select 'Yes' if it has been inspected, 'No' otherwise.
* **Second Floor**: Check to indicate if the second floor of the facility has been inspected. Select 'Yes' if it has been inspected, 'No' otherwise.
* **Third Floor**: Check to indicate if the third floor of the facility has been inspected. Select 'Yes' if it has been inspected, 'No' otherwise.
* **Facility Equipment**: Enter any information about the facility's equipment, such as its condition and availability.
* **Facility Documents**: Check to indicate if the facility's documents (e.g., contracts, policies) are present and up-to-date. Select 'Yes' if they are, 'No' otherwise.
* **Facility Supplies**: Check to indicate if the facility's supplies (e.g., cleaning, maintenance) are present and sufficient. Select 'Yes' if they are, 'No' otherwise.
* **Facility Security**: Check to indicate if the facility's security features (e.g., cameras, alarms) are functional and effective. Select 'Yes' if they are, 'No' otherwise.
* **Facility Facilities**: Enter any information about the facility's facilities (e.g., restrooms, break rooms) and their condition.
* **Facility Equipments**: Check to indicate if the facility's equipment (e.g., machinery, tools) is present and in good condition. Select 'Yes' if it is, 'No' otherwise.
* **Facility Supplies Included**: Check to indicate if all necessary facility supplies (e.g., cleaning, maintenance) are included. Select 'Yes' if they are, 'No' otherwise.
* **Facility Security Notes**: Enter any additional comments or notes about the facility's security features.
* **Facility Documents Included**: Check to indicate if all necessary facility documents (e.g., contracts, policies) are included. Select 'Yes' if they are, 'No' otherwise.
* **Facility Safety**: Check to indicate if the facility's safety features (e.g., fire extinguishers, emergency exits) are functional and effective. Select 'Yes' if they are, 'No' otherwise.
* **Facility Equipments Included**: Check to indicate if all necessary facility equipment (e.g., machinery, tools) is included. Select 'Yes' if they are, 'No' otherwise.
* **Facility Notes**: Enter any additional comments or notes about the facility.
* **Facility Review Comments**: Check to indicate if you have any additional comments or notes about the facility. Select 'Yes' if you do, 'No' otherwise.
