# Prototype Inspection Checklist - Help Guide
## Purpose
The "Prototype Inspection Checklist" form is used to collect inspection data from stakeholders involved in the prototype development process. It helps evaluate the state of a prototype, track its status, and document the outcomes of inspections.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct prototype version and iteration number if applicable.
2. Evaluate the prototype inspection status and select the corresponding option for each field.
3. Provide a brief description of the prototype, if necessary.
4. Indicate the outcomes of inspections for each team involved (development, QA, and manufacturing).
5. Fill out the notes section if necessary.
6. Capture the date and user who performed the inspection.

## Field-by-Field Explanation

* **Check Prototype Inspection** (`prototype_inspection`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the prototype inspection is complete.
* **Prototype Description** (`prototype_description`, text, not required):
	+ Write a brief description of the prototype, if necessary.
* **Inspection Outcomes** (`inspection_outcomes`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the inspection outcomes are complete.
* **Status** (`prototype_status`, select_one, not required):
	+ Select the status of the prototype (Passed, Failed, In-Progress).
* **Development Team** (`prototype_development_team`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the development team has inspected the prototype.
* **QA Team** (`qa_team`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the QA team has inspected the prototype.
* **Manufacturing Team** (`manufacturing_team`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the manufacturing team has inspected the prototype.
* **Capture Date** (`capture_date`, date, not required):
	+ Enter the date the inspection was performed.
* **Captured By** (`captured_by`, select_one, not required):
	+ Select the user who performed the inspection.
* **Review Outcomes** (`review_outcomes`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the review outcomes are complete.
* **Prototype Version** (`prototype_version`, select_one, not required):
	+ Select the prototype version number.
* **Iteration** (`iteration`, select_one, not required):
	+ Select the iteration number.
* **Inspection Outcomes** (`inspection_outcomes`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the inspection outcomes are complete.
* **Notes** (`notes`, text, not required):
	+ Write any additional notes or comments.
* **Review Notes** (`review_notes`, text, not required):
	+ Write any additional review notes or comments.
* **Captured At** (`captured_at`, date, not required):
	+ Enter the date and time the inspection was captured.
* **Captured By** (`captured_by`, select_one, not required):
	+ Select the user who captured the inspection data.
* **Development Team** (`prototype_development_team`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the development team has inspected the prototype.
* **QA Team** (`qa_team`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the QA team has inspected the prototype.
* **Manufacturing Team** (`manufacturing_team`, select_multiple, not required):
	+ Select "Yes" or "No" to indicate if the manufacturing team has inspected the prototype.

This help guide is not exhaustive and may need to be adapted according to your specific organization's needs. If you are unsure about any field or have any questions, please contact your local support team for assistance.
