# Reception Area Security Checklist - Help Guide
## Purpose
The Reception Area Security Checklist is a form designed to assess and document the security risks associated with the reception area of a facility. This form helps users identify potential security concerns and provide a detailed description of the risks.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate risk level for each risk description.
2. Provide a detailed description of the risk, including any additional comments or notes.
3. Enter any relevant security risk ID numbers.
4. Add any additional comments or notes.

## Field-by-Field Explanation
- **Security Assessment** (`reception_area_security_checklist_form_security_assessment`): This field asks you to determine whether the security risk is present or not. Select "Yes" if the risk is present, and "No" if it is not.
  - **Risk Level** (`reception_area_security_checklist_form_risk_level`): Choose the level of risk associated with the security concern.
  - **Risk Description 1** (`reception_area_security_checklist_form_risk_level_description`): Provide a detailed description of the risk.
  - **Risk Description 2** (`reception_area_security_checklist_form_risk_level_description_2`): Provide another detailed description of the risk (if applicable).
  - **Risk Description 3** (`reception_area_security_checklist_form_risk_level_description_3`): Provide another detailed description of the risk (if applicable).
  - **Security Risk ID** (`reception_area_security_checklist_form_security_risk_level_id`): Enter any relevant security risk ID numbers.
  - **Comments** (`reception_area_security_checklist_form_comments`): Add any additional comments or notes about the assessment.
  - **Comments 2** (`reception_area_security_checklist_form_comments_2`): Add any additional comments or notes (if applicable).
  - **Comments 3** (`reception_area_security_checklist_form_comments_3`): Add any additional comments or notes (if applicable).
  - **Comments 4** (`reception_area_security_checklist_form_comments_4`): Add any additional comments or notes (if applicable).

## Tips
- Be thorough in your assessment and provide as much detail as possible.
- Select the most accurate option for each field.
- If a field is not applicable, enter "N/A" or provide a brief explanation.
- Review and update your assessment as needed.
