# Employee Offboarding Checklist Form - Help Guide
## Purpose
The Employee Offboarding Checklist Form is a systematic guide to help you complete the offboarding process for departing employees. It ensures all necessary steps are taken to return company property, equipment, and documents, and complete any outstanding onboarding procedures.

## How To Complete This Form
To complete this form, simply review each page and follow these steps:

1. On each page, answer the questions according to your situation.
2. Review the instructions and notes provided for each field.
3. Sign and date each page when you have completed the tasks listed.
4. Submit the form to your supervisor or HR representative for review and approval.

## Field-by-Field Explanation
### **Onboarding Procedures** (`onboarding_procedures`, text, optional)
This field is used to track the completion of onboarding procedures for the departing employee. If the procedures have been completed, mark "Yes", otherwise, mark "No".

*   Please provide a brief description of the completed onboarding procedures.

### **Exit Interview** (`exit_interview`, select_one, optional)
This field is used to determine if an exit interview has been conducted with the departing employee. Please select the answer that best describes the situation:
    * 'Yes' - An exit interview has been conducted.
    * 'No' - An exit interview has not been conducted.

### **Return Company Property** (`return_company_property`, select_multiple, optional)
This field is used to track the return of company property. Please select all applicable options:
    * 'Yes' - All company property has been returned.
    * 'No' - Some or all company property has not been returned.
    * 'Not Applicable' - This property is not owned by the company.

### **Change of Address** (`change_of_address`, text, optional)
Please provide your new address for the company records.

### **Return Company Equipment** (`return_company_equipment`, date, optional)
If you have returned any company equipment, please provide the date it was returned.

### **Onboarding Checklist Completed** (`onboarding_checklist_completed`, select_multiple, optional)
This field is used to track the completion of the onboarding checklist. Please select all applicable options:
    * 'Yes' - The onboarding checklist has been completed.
    * 'No' - The onboarding checklist has not been completed.
    * 'Not Applicable' - The onboarding checklist is not relevant to this offboarding.

### **Return Company Vehicle** (`return_company_vehicle`, time, optional)
If you have returned a company vehicle, please enter the exact time it was returned.

### **Return Keycard** (`return_keycard`, select_one, optional)
Please select how you returned the key card:
    * 'Yes' - The keycard has been returned.
    * 'No' - The keycard has not been returned.

### **Return ID Card** (`return_id_card`, select_multiple, optional)
This field is used to track the return of ID cards. Please select all applicable options:
    * 'Yes' - All ID cards have been returned.
    * 'No' - Some or all ID cards have not been returned.
    * 'Not Applicable' - ID cards are not issued.

### **Employee Return Date** (`employee_return_date`, date, optional)
Please enter the date you will be returning to work.
