# Swimming Pool Inspection Form - Help Guide
## Purpose
The purpose of this form is to collect comprehensive information about a swimming pool, including its location, type, size, condition, safety features, equipment, and status.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide the pool location where the inspection is being conducted.
2. Specify the type of pool (residential, commercial, or public).
3. Enter the pool depth (if known).
4. Select the pool surface type(s) (concrete, vinyl, fiberglass, or fiberglass/polymer).
5. Enter the pool size (if known).
6. Describe the pool's condition.
7. Select the safety features (fencing, gate, or locks) present.
8. Select the pool equipment (pumps, filters, heaters, or cleaners) present.
9. Specify the pool status (open, closed, or under maintenance).

## Field-by-Field Explanation
### Pool Location
* Pool Location (`pool_location`, text): Enter the location of the pool.

### Pool Address
* Pool Address (`pool_address`, text): Enter the address of the pool (if applicable).

### Pool Type
* Pool Type (`pool_type`, select_one): Select the type of pool (residential, commercial, or public).

### Pool Depth
* Pool Depth (`pool_depth`, number): Enter the pool depth (if known).

### Pool Surface
* Pool Surface (`pool_surface`, select_multiple): Select the pool surface type(s) (concrete, vinyl, fiberglass, or fiberglass/polymer).

### Pool Size
* Pool Size (`pool_size`, text): Enter the pool size (if known).

### Pool Condition
* Pool Condition (`pool_condition`, text): Describe the pool's condition.

### Safety Features
* Safety Features (`safety_features`, select_multiple): Select the safety features (fencing, gate, or locks) present.

### Pool Equipment
* Pool Equipment (`pool_equipment`, select_multiple): Select the pool equipment (pumps, filters, heaters, or cleaners) present.

### Pool Status
* Pool Status (`pool_status`, select_one): Specify the pool status (open, closed, or under maintenance).

### Tips
* Make sure to fill out all required fields and select all applicable options.
* Provide accurate and detailed information to ensure a thorough inspection.
