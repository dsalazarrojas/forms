# Access Control System Checklist Form - Help Guide
## Purpose
The Access Control System Checklist Form is designed to help inspectors evaluate and record the status of physical and electronic security systems, including locks, doors, surveillance cameras, alarm systems, and other safety features. This form ensures that facilities meet or exceed regulatory requirements and industry standards.

## How To Complete This Form

1. Select the relevant section of the form that corresponds to the area you are inspecting (e.g., **-- Inspection Overview --**, **-- Physical Locks and Barriers --**, etc.).
2. For each field, follow the instructions provided in the **Field-by-Field Explanation** section to ensure accurate and complete reporting.

## Field-by-Field Explanation
### -- Inspection Overview --
- **title:** This is the form title, indicating the type of form and its purpose.
- **inspector_name:** Enter the full name of the person performing the inspection.
- **inspection_date:** Select the date of the inspection using the date input field.

### -- Physical Locks and Barriers --
- **external_doors_secure:** Check if all external doors are locking correctly, and select the corresponding option (Yes, Issues Found, or N/A).
- **physical_keys_accounted:** Check if all master keys are accounted for, and select the corresponding option (Yes, No).
- **turnstile_functionality:** Check if turnstiles are operating smoothly, and select the corresponding option (Functional, Maintenance Required, or N/A).

### -- Electronic Systems --
- **reader_connectivity:** Check if all card readers show a green status, and select the corresponding option (Yes, Some Red or Offline).
- **alarm_system_test:** Test the alarm system and select if it was triggered successfully (Yes, No).
- **emergency_exit_override:** Check if the emergency exit override function works correctly, and select the corresponding option (Yes - Functional or Other).

### -- Surveillance --
- **camera_angles_clear:** Check if all camera views are unobstructed and clear, and select the corresponding option (Yes, Obstructions Found).
- **recording_system_status:** Check if the NVR or DVR recording is active, and select the corresponding option (Recording Active, Error Logged).

### -- Comments and Sign-off --
- **observations_and_repairs:** Provide detailed notes on any issues or repairs needed.

### Final Section
- **checklist_completion:** Select if all security checks have been performed (I Certify, Other).
