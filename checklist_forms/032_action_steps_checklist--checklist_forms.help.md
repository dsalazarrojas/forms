# Action Steps Checklist - Help Guide
## Purpose
This form is a checklist designed to help individuals or teams track and manage project progress through a series of structured steps. By completing this form, users can ensure that all necessary actions are taken and document lessons learned.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the "Project Name" field with a brief description of the project or task being managed.
2. Enter the "Responsible Person" who is in charge of completing these action steps.
3. Enter the "Checklist Date" when this checklist was created or last updated.
4. Select the status of each step from the options provided ("Not Started", "In Progress", "Completed") as you complete each action.
5. Provide any additional "Notes or Comments" in the last field if needed.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, required): Enter the name of the project or task being managed.
* **Responsible Person** (`responsible_person`, text, required): Identify the person responsible for completing these action steps.
* **Checklist Date** (`checklist_date`, date, required): Enter the date when this checklist was created or last updated.
* **Step 1 - Define project scope and objectives** (`step_1`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 2 - Identify stakeholders and requirements** (`step_2`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 3 - Develop project timeline and milestones** (`step_3`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 4 - Allocate resources and assign tasks** (`step_4`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 5 - Execute planned activities** (`step_5`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 6 - Monitor progress and adjust as needed** (`step_6`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 7 - Review deliverables and quality assurance** (`step_7`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 8 - Communicate progress to stakeholders** (`step_8`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 9 - Document lessons learned** (`step_9`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Step 10 - Close project and archive documentation** (`step_10`, select_one, required): Select the status of this step as completed, in progress, or not started.
* **Additional Notes or Comments** (`additional_notes`, text, optional): Add any additional notes or comments about the project or checklist.

## Tips
* Make sure to update the checklist regularly to reflect changes in project status.
* Be sure to review each step carefully before marking it as completed.
* Use the "Additional Notes or Comments" field to document any issues or concerns that arise during the project.
