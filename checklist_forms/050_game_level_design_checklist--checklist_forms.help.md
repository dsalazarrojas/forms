## Game Level Design Checklist - Help Guide
## Purpose
The Game Level Design Checklist is a form designed to help game level designers and testers evaluate the completeness and polish of a game level. It checks for various aspects of level design, including visuals, technical integrity, and player guidance.

## How To Complete This Form
1. Go through each page of the form carefully, ensuring you answer all the required fields.
2. For each field, answer based on your evaluation of the level's design.
3. Use the options provided for each field to select the most accurate response.
4. Fill in any additional comments or observations in the `Tester Comments` field, if necessary.

## Field-by-Field Explanation

* **Game Level Checklist** (`level_design_checklist_gameplay`, text, required): This field assesses the level's overall design and functionality. Please provide a brief description of the level's main objectives, gameplay mechanics, and any notable features.
* **Visuals** (`level_design_checklist_visuals`, select_multiple, required): Select all the visuals that the level has, such as Level background and assets and Level lighting and Level texture and material quality.
* **Technical Issues** (`level_design_checklist_technical_issues`, select_one, required): Identify and select any technical issues you find with the level, such as Level physics issues or Level animation issues.
* **Player Guidance** (`level_design_checklist_player_guidance`, text, required): Provide a brief description of the level's guidance and instructions for the player. This could include hints, tips, or any other helpful information to aid the player in completing the level.
* **Test Results** (`level_design_checklist_test_results`, select_multiple, required): If you have tested the level, select the outcome of your test, whether it was Pass or Fail.
* **Level Completion** (`level_design_checklist_level_completion`, select_one, required): Indicate whether the level is complete or not. If not complete, please explain why.
* **Level Length** (`level_design_checklist_level_length`, number, required): Provide the estimated length of the level, in terms of playtime or completion time.
* **Tester Comments** (`level_design_checklist_tester_comments`, text, optional): If you have any additional comments or feedback about the level, please enter them here. These comments will be helpful for the level designers.
* **Version** (`game_level_design_checklist_version`, number, required): Enter the current version number of the level, so that the level's design can be updated accordingly.
