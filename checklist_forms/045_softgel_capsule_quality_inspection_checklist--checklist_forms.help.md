# softgel_capsule_quality_inspection_checklist - Help Guide
## Purpose
The softgel capsule quality inspection checklist is a form used by inspectors to collect data on the quality of softgel capsules during a shift.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the page with the title "Softgel Capsule Quality Inspection Checklist".
2. Fill in the batch number.
3. Enter the inspector's name.
4. Select the shift start time using the date input field.
5. Select the shift end time using the time input field.
6. Enter the number of capsules checked.
7. Enter the number of capsules rejected.
8. Enter the number of capsules reprocessed.
9. Enter your signature as the inspector.
10. Add any batch notes, if necessary.

## Field-by-Field Explanation
* **Batch Number** (`batch_number`, `number`, required/optional): Enter the batch number of the softgel capsules being inspected.
* **Inspector** (`inspector`, `text`, required/optional): Enter your name as the inspector.
* **Shift Start Time** (`shift_start_time`, `date`, required/optional): Enter the start time of your shift using the date input field. (Format: YYYY-MM-DD)
* **Shift End Time** (`shift_end_time`, `time`, required/optional): Enter the end time of your shift using the time input field. (Format: HH:MM:SS)
* **Capsules Checked** (`capsules_checked`, `number`, required/optional): Enter the total number of softgel capsules inspected.
* **Capsules Rejected** (`capsules_rejected`, `number`, required/optional): Enter the number of softgel capsules rejected during the inspection.
* **Capsules Reprocessed** (`capsules_reprocessed`, `number`, required/optional): Enter the number of softgel capsules reprocessed.
* **Inspector Signature** (`inspector_signature`, `text`, required/optional): Enter your signature as the inspector.
* **Batch Notes** (`batch_notes`, `note`, required/optional): Add any notes about the batch being inspected.
