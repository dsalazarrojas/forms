# event_closing_checklist - Help Guide
## Purpose
The event_closing_checklist form is used to gather information about event closing details to ensure that all aspects of the event are properly closed.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully to ensure that you are providing accurate information.
2. Select the relevant options for each field based on the event's closing details.
3. Fill in all required fields.
4. Review your answers before submitting the form.

## Field-by-Field Explanation
### Event Closing Item 1
* **Event Closing Item 1**: A text field for noting any important closing items specific to the event.

### Staff Present
* **Staff Present**: Select 'Yes' if staff were present at the event, or 'No' if not.

### Event Fees Paid
* **Event Fees Paid**: Enter the amount of fees paid for the event, if applicable.

### Sponsors
* **Sponsors**: Select all sponsors that were present at the event, such as 'Food' or 'Drink'. You can also select 'Other' if you have other types of sponsors not listed.

### Other Sponsor Information
* **Other Sponsor Information**: If you selected 'Other' as a sponsor, provide more details about the sponsor here.

### Speaker
* **Speaker**: Enter the name of the speaker for the event, if applicable.

### Other Speaker Information
* **Other Speaker Information**: If you need to provide additional information about the speaker, enter it here.

### Event Insurance
* **Event Insurance**: Select 'Yes' if event insurance was purchased for the event, or 'No' if not.

### Vendors
* **Vendors**: Select all vendors that were present at the event, such as 'Audio-Visual' or 'Food and Beverage'. You can also select 'Other' if you have other types of vendors not listed.

## Tips
* Please ensure that you are providing accurate information about the event's closing details.
* If you are unsure about any field, review the event's original details to ensure you are providing the correct information.
