# Fire Safety Equipment Checklist - Help Guide

## Purpose
The Fire Safety Equipment Checklist is designed to ensure that fire safety equipment, such as fire extinguishers and fire hydrants, are properly installed, inspected, and maintained in your building or facility.

## How To Complete This Form

1. Review each section carefully and answer all questions honestly.
2. Select the correct answers for each question based on your observations and knowledge.
3. Enter dates in the correct format (mm/dd/yyyy).
4. Use the provided options for select and select_multiple fields.
5. Enter any additional comments or notes as needed.

## Field-by-Field Explanation

* **General Check** (`general_check`, select_multiple, optional):
	+ Select all that apply to indicate that a general check has been performed.
* **Fire Extinguisher Locations** (`fire_extinguisher_locations`, text, required):
	+ Enter the locations of fire extinguishers in the building or facility, including floor numbers and room numbers.
* **Fire Extinguisher Types** (`fire_extinguisher_types`, select_one, required):
	+ Select the type of fire extinguisher present (e.g., dry chemical, foam, etc.).
* **Fire Extinguisher Condition** (`fire_extinguisher_condition`, select_multiple, required):
	+ Select all that apply to indicate the condition of the fire extinguishers (e.g., fully charged, partially charged, etc.).
* **Fire Hydrant Locations** (`fire_hydrant_locations`, text, required):
	+ Enter the locations of fire hydrants in the building or facility, including floor numbers and room numbers.
* **Fire Hydrant Types** (`fire_hydrant_types`, select_one, required):
	+ Select the type of fire hydrant present (e.g., water-based, dry chemical, etc.).
* **Fire Hydrant Condition** (`fire_hydrant_condition`, select_multiple, required):
	+ Select all that apply to indicate the condition of the fire hydrants (e.g., fully charged, partially charged, etc.).
* **Alarm System** (`alarm_system`, text, optional):
	+ Enter any information about the alarm system, including location and type.
* **Fire Extinguisher Pressure Test** (`fire_extinguisher_pressure_test`, select_one, optional):
	+ Select whether a pressure test has been performed on the fire extinguishers.
* **Fire Hydrant Pressure Test** (`fire_hydrant_pressure_test`, select_one, optional):
	+ Select whether a pressure test has been performed on the fire hydrants.
* **Fire Extinguisher Inspection Frequency** (`fire_extinguisher_inspection_frequency`, number, optional):
	+ Enter the recommended inspection frequency for fire extinguishers.
* **Fire Hydrant Inspection Frequency** (`fire_hydrant_inspection_frequency`, number, optional):
	+ Enter the recommended inspection frequency for fire hydrants.
* **Fire Extinguisher Last Inspection** (`fire_extinguisher_last_inspection`, date, required):
	+ Enter the date of the last inspection of fire extinguishers.
* **Fire Hydrant Last Inspection** (`fire_hydrant_last_inspection`, date, required):
	+ Enter the date of the last inspection of fire hydrants.
* **Fire Extinguisher Next Inspection** (`fire_extinguisher_next_inspection`, date, optional):
	+ Enter the date of the next scheduled inspection of fire extinguishers.
* **Fire Hydrant Next Inspection** (`fire_hydrant_next_inspection`, date, optional):
	+ Enter the date of the next scheduled inspection of fire hydrants.
* **Fire Extinguisher Notes** (`fire_extinguisher_notes`, text, required):
	+ Enter any additional notes about the fire extinguishers.
* **Fire Hydrant Notes** (`fire_hydrant_notes`, text, required):
	+ Enter any additional notes about the fire hydrants.
* **Fire Extinguisher Comments** (`fire_extinguisher_comments`, text, optional):
	+ Enter any additional comments about the fire extinguishers.
* **Fire Hydrant Comments** (`fire_hydrant_comments`, text, optional):
	+ Enter any additional comments about the fire hydrants.
* **Fire Extinguisher Review** (`fire_extinguisher_review`, select_one, optional):
	+ Select whether a review has been performed on the fire extinguishers.
* **Fire Hydrant Review** (`fire_hydrant_review`, select_one, required):
	+ Select whether a review has been performed on the fire hydrants.
* **Fire Extinguisher Approvals** (`fire_extinguisher_approvals`, select_multiple, required):
	+ Select all that apply to indicate the approvals for the fire extinguishers.
* **Fire Extinguisher Revisions** (`fire_extinguisher_revisions`, select_multiple, optional):
	+ Select all that apply to indicate the revisions for the fire extinguishers.
* **Fire Extinguisher Signature** (`fire_extinguisher_signature`, note, required):
	+ Enter the name and date of the person completing this form.

## Tips

* Please ensure that all fields are completed accurately and thoroughly.
* If you are unsure about any of the questions, please consult with your facility's fire safety officer or relevant experts.
* This form should be completed for each fire safety inspection and review cycle.
