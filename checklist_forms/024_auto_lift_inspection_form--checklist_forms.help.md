# Auto Lift Inspection Form - Help Guide
## Purpose
The Auto Lift Inspection Form is a comprehensive checklist used to evaluate the safety and functionality of an auto lift. It guides the inspector through a series of questions and checks to ensure the lift is safe to operate and meets the necessary standards.

## How To Complete This Form
To complete this form, follow these steps:

* Review the provided fields and sections carefully.
* Fill out each field according to the information you gather during the inspection.
* Ensure that you select the correct options for each field, taking note of the required fields.
* Complete all required fields before submitting the form.

## Field-by-Field Explanation

* **Lift ID Number** (Lift ID Number, Text, Required): Please enter the internal tracking or serial number of the lift.
* **Lift Manufacturer** (Lift Manufacturer, Text, Required): Please enter the manufacturer of the lift, for example, "Rotary" or "BendPak".
* **Lift Model** (Lift Model, Text, Required): Please enter the model of the lift, for example, "2-Post" or "4-Post".
* **-- Safety Checklist --** (Safety Checklist, Note, Not Required): This section is an overview of the safety checks conducted during the inspection. Please use this space to record your findings.
* **Controls Functioning** (Controls Functioning, Select One, Required): Please select "Pass" if the up, down, and stop buttons are functioning correctly. Select "Fail" if any of these controls are not working properly.
* **Synchronization Working** (Synchronization Working, Select One, Required): Please select "Pass" if the lift's posts are rising and falling evenly. Select "Fail" if they are not.
* **Structural Integrity Visual** (Structural Integrity Visual, Select One, Required): Please select "Pass" if the lift's structural integrity is intact and shows no visible cracks, bends, or damage. Select "Fail" if you notice any issues.
* **Lift Arms and Locks Secure** (Lift Arms and Locks Secure, Select One, Required): Please select "Pass" if the lift's arms and locks engage properly. Select "Fail" if they do not.
* **Hydraulic Leaks Present** (Hydraulic Leaks Present, Select One, Required): Please select "True" if you find any hydraulic leaks. Select "False" if there are no leaks.
* **Electrical Wiring Condition** (Electrical Wiring Condition, Select One, Required): Please select "Good" if the electrical wiring is in good condition. Select "Frayed or Damaged" if there are any issues.
* **-- Final Approval --** (Final Approval, Note, Not Required): This section is for recording any final approval or conclusions from the inspection. Please use this space to summarize your findings.
* **Inspector Name** (Inspector Name, Text, Required): Please enter the full name of the inspecting mechanic.
* **Inspection Date** (Inspection Date, Date, Required): Please enter the date of the inspection.
* **Safe to Operate** (Safe to Operate, Select One, Required): Please select "True" if the lift is safe to operate based on your inspection. Select "False" if it is not.
* **Maintenance Notes** (Maintenance Notes, Text, Not Required): This section is for recording any maintenance notes or required repairs.
* **Overall Safety Determination** (Overall Safety Determination, Select One, Required): Please select "True" if the lift is safe to operate based on your inspection. Select "False" if it is not.
