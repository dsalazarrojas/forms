# Clergy Candidate Document Checklist - Help Guide
## Purpose

The Clergy Candidate Document Checklist is a form designed to ensure that you, as a candidate, submit the required documents for the search process. Please fill out this form to provide the search committee with the necessary information and documents for review.

## How To Complete This Form

1. Fill out all the fields with the required information.
2. For each document listed, select the status of your readiness to submit it.
3. Upload all necessary documents as a single ZIP file or provide a link to a cloud folder.
4. Enter the date of submission.

## Field-by-Field Explanation

* **Candidate Full Name**: Enter your full name as you would like it to appear on the search committee's documents.
* **Email Address**: Enter your email address to ensure that the search committee can contact you for any further information.
* **Phone Number**: Enter your phone number to facilitate communication with the search committee.
* **Current Church or Denominational Affiliation**: Enter your current church or denominational affiliation to help the search committee understand your current context.
* **-- Document Submission Checklist --**: This section is a summary of the required documents. Please review and respond to each listed document:
	+ **Ministerial Credentials / Ordination Certificate**: Select "Ready to upload" if you have already prepared this document, "In progress" if you are working on it, or "Not applicable" if it is not required for your candidacy.
	+ **Academic Transcripts (Seminary or equivalent)**: Select "Ready to upload" if you have already prepared this document, "In progress" if you are working on it, or "Not applicable" if it is not required for your candidacy.
	+ **Signed Background Check Consent Form**: Select "Ready to upload" if you have already prepared this document, "In progress" if you are working on it, or "Not applicable" if it is not required for your candidacy.
	+ **Three Letters of Recommendation**: Select "Ready to upload" if you have already prepared this document, "In progress" if you are working on it, or "Not applicable" if it is not required for your candidacy.
	+ **Personal Statement / Faith Journey**: Select "Ready to upload" if you have already prepared this document, "In progress" if you are working on it, or "Not applicable" if it is not required for your candidacy.
	+ **Medical Clearance Form (if required)**: Select "Ready to upload" if you have already prepared this document, "In progress" if you are working on it, or "Not applicable" if it is not required for your candidacy.
* **Please upload all documents as a single ZIP file or provide a link to a cloud folder**: Upload your documents or provide the link, following the instructions.
* **Date of Submission**: Enter the date you submitted your application.

## Tips

* Please ensure that all documents are accurate and complete before submitting your application.
* If you have any issues with the submission process, contact the search committee.
