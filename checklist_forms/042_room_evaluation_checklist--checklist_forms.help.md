# Room Evaluation Checklist - Help Guide
## Purpose
This form is designed to evaluate the condition of a room, providing a comprehensive assessment of its various aspects.

## How To Complete This Form
To complete this form, simply follow the steps below:

1. Go through each page and fill out the form according to the questions and options provided.
2. Select the relevant options for each field based on your observation of the room.
3. Enter any additional comments or notes in the 'Notes' field for further information.

## Field-by-Field Explanation

* **General Condition** (`general_condition`, text, optional): Describe the overall condition of the room, including any notable features or issues.
* **Amenities** (`amenities`, select_one, optional): Choose one of the options to indicate the availability of amenities such as cleanliness, maintenance, and housekeeping:
	+ Clean
	+ Not Clean
	+ Partially Clean
* **Cleanliness** (`cleanliness`, select_multiple, optional): Select one or more options to describe the cleanliness of the room:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Room Condition** (`room_condition`, select_one, optional): Choose one option to describe the condition of the room:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Maintenance** (`maintenance`, select_one, optional): Select one option to indicate the need for maintenance:
	+ Required
	+ Not Required
* **Housekeeping** (`housekeeping`, select_multiple, optional): Select one or more options to describe the housekeeping of the room:
	+ Good
	+ Fair
	+ Poor
* **Safety** (`safety`, select_one, optional): Choose one option to describe the safety of the room:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Electrical Systems** (`electrical_systems`, select_multiple, optional): Select one or more options to describe the condition of electrical systems:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Furniture and Fixtures** (`furniture_and_fixtures`, select_multiple, optional): Select one or more options to describe the condition of furniture and fixtures:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
* **Cleanliness Rating** (`cleanliness_rating`, number, optional): Enter a numerical value to describe the cleanliness of the room.
* **General Rating** (`general_rating`, text, optional): Enter a brief description of your overall impression of the room.
* **Notes** (`notes`, text, optional): Enter any additional comments or observations about the room.
