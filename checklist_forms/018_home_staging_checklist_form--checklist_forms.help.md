# Home Staging Checklist Form - Help Guide
## Purpose
The Home Staging Checklist Form is a tool used by home stagers to document and manage tasks for each room in a property. This form helps track progress, assign tasks to technicians, and provide a clear overview of the work to be done.

## How To Complete This Form
1. Select a room type from the options provided in the "Room Types" field.
2. Choose the task types you want to complete in the selected room using the "Task Types" field. You can select multiple task types.
3. Select the specific tasks you want to complete for each room using the "Staging Tasks" field. You can select multiple tasks.
4. (Optional) Set the priority of the tasks using the "Priority" field.
5. (Optional) Set the completion date for the tasks using the "Completion Date" field.
6. Add any comments about the tasks or the room using the "Comments" field.
7. Assign a technician to be responsible for the tasks using the "Assigned Technician" field.

## Field-by-Field Explanation
* **Room Types** (`room_types`): Select the type of room for which you are creating the checklist (e.g., Kitchen, Living Room, Bathroom, etc.).
* **Task Types** (`task_types`): Choose the type of tasks you want to complete for the selected room (e.g., Deep Clean, Organize, Decorate, etc.).
* **Staging Tasks** (`staging_tasks`): Select the specific tasks to be completed for the room (e.g., Move Out Trash, Vacuum Carpets, etc.).
* **Priority** (`priority`): Set the priority of the tasks, but note that this field is currently not in use and may not have an effect.
* **Completion Date** (`completion_date`): Set the date the tasks were completed, but note that this field is currently not linked to any deadline or alert system.
* **Comments** (`comments`): Add any comments or notes about the tasks or the room.
* **Assigned Technician** (`assigned_technician`): Assign a technician who will be responsible for completing the tasks.
