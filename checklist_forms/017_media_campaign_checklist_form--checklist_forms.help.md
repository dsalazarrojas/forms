# Media Campaign Checklist Form - Help Guide
## Purpose
The Media Campaign Checklist Form is used to gather and organize information about a media campaign. It's a tool for marketing or media teams to track and manage campaign details, such as name, dates, budget, tasks, and responsibilities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the campaign name in the "Campaign Name" field.
2. Select the marketing manager responsible for the campaign.
3. Select the media managers responsible for the campaign.
4. Enter the start and end dates for the campaign.
5. Enter the budget allocated for the campaign.
6. List any tasks associated with the campaign.
7. Enter any deadlines for the campaign.
8. List any responsibilities associated with the campaign.
9. Enter the review date to track the campaign's progress.

## Field-by-Field Explanation

* **Campaign Name (text)**: Enter the name of the campaign.
* **Marketing Manager (select_one)**: Select the person responsible for the campaign's marketing aspects.
* **Media Manager (select_multiple)**: Select the people responsible for the media aspects of the campaign.
* **Start Date (date)**: Enter the start date of the campaign.
* **End Date (date)**: Enter the end date of the campaign.
* **Budget (number)**: Enter the budget allocated for the campaign.
* **Tasks (text)**: List any tasks associated with the campaign.
* **Deadlines (text)**: Enter any deadlines for the campaign.
* **Responsibilities (text)**: List any responsibilities associated with the campaign.
* **Review Date (date)**: Enter the date to track the campaign's progress.
