# Rental Property Self Inspection Form - Help Guide
## Purpose
The form is used to conduct a self-inspection of a rental property, which helps identify potential issues and ensures the property is in a good condition.

## How To Complete This Form
To complete this form, follow these steps:
1. Answer each question carefully, indicating whether the property is in a good, average, or bad condition for each aspect.
2. Select "Yes" if the property has any damages, cleanliness issues, or other problems.
3. Select "No" if the property is in a good condition.
4. Make sure to answer all questions, even if there are no issues to report.

## Field-by-Field Explanation

* **Check for damages** (rental_property_self_inspection_form_1, Select multiple, required): 
  This question checks for any visible damages or issues that affect the overall structure and appearance of the property.
* **check for cleanliness** (rental_property_self_inspection_form_2, Select multiple, required): 
  This question assesses the overall cleanliness of the property, including the state of the kitchen, bathroom, living areas, and any other areas that need attention.
* **check for functionality** (rental_property_self_inspection_form_3, Select multiple, required): 
  This question reviews the functionality of electrical, plumbing, and other essential systems in the property.
* **check for safety** (rental_property_self_inspection_form_4, Select multiple, required): 
  This question ensures that all safety features, such as smoke detectors, fire extinguishers, and emergency exits, are in good working condition.
* **check for security** (rental_property_self_inspection_form_5, Select multiple, required): 
  This question checks for any security issues, such as broken locks, open windows, or other vulnerabilities.
* **check for utilities** (rental_property_self_inspection_form_6, Select multiple, required): 
  This question assesses the functionality of utilities like water, electricity, and gas supply.
* **check for electrical** (rental_property_self_inspection_form_7, Select multiple, required): 
  This question checks for any electrical issues, such as flickering lights, malfunctioning outlets, or other electrical problems.
* **check for plumbing** (rental_property_self_inspection_form_8, Select multiple, required): 
  This question reviews the functionality of the property's plumbing system, including sinks, toilets, showers, and other fixtures.
* **check for HVAC** (rental_property_self_inspection_form_9, Select multiple, required): 
  This question ensures that the heating, ventilation, and air conditioning system is in good working condition.
* **check for appliances** (rental_property_self_inspection_form_10, Select multiple, required): 
  This question checks for the condition and functionality of any installed appliances, such as washing machines, dishwashers, or refrigerators.

## Tips
- If unsure about an aspect, select "No" or "Unknown".
- If issues are found, be specific and provide details.
- If the property condition is excellent, select "Yes" for all fields.
- Please review and submit the form carefully, as it is crucial for accurate reporting.
