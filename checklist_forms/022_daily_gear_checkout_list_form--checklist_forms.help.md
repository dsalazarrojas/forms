# Daily Gear Checkout List Form - Help Guide
## Purpose
This form helps track the daily gear checkout list for employees or users within an organization.

## How To Complete This Form

1.  Fill in the form with the required information, or at least with the minimum amount of required data (indicated by the "required" field).
2.  Make sure to select the correct options for the "Gear List", "Checked Out By", and "Date Borrowed" fields based on your situation.
3.  You can fill out the other fields as per your preference or according to your organization's policies.

## Field-by-Field Explanation

*   **Gear List** (select_multiple, id: 2):
    Select the type of gear that was borrowed. You can choose one or multiple options from the list.
*   **Gear Description List** (note, id: 3):
    Provide a brief description of the gear borrowed, if necessary.
*   **User ID** (number, id: 4):
    Enter the employee or user ID of the person borrowing the gear.
*   **Date Borrowed** (date, id: 5):
    Enter the date the gear was borrowed.
*   **Date Returned** (date, id: 6):
    If applicable, enter the date the gear was returned.
*   **Checked Out By** (select_one, id: 7):
    Select the assistant who borrowed the gear.
*   **Borrowed Gear List** (note, id: 1):
    This field is not used in this form. It is an empty placeholder and does not have any options.
