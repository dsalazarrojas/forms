# mba_program_admission_checklist_form_template - Help Guide
## Purpose
This form is designed to help admissions staff track and document the status of MBA program applications. It provides a checklist for evaluating and updating the status of each application.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out each field as instructed, making sure to provide accurate and detailed information.
2. Review each field carefully to ensure all required information is filled out.
3. Submit the form once completed.

## Field-by-Field Explanation

* **MBA Program Details** (`mba_program_details`, `text`, required/optional): Enter a brief description of the MBA program to which the application pertains.
* **MBA Application Status** (`mba_application_status`, `select_one`, required/optional): Choose the current status of the application:
	+ Complete
	+ Incomplete
	+ Not Applicable
* **MBA Application Comments** (`mba_application_comments`, `note`, required/optional): Enter any comments or notes regarding the application.
* **MBA Program Advisor** (`mba_program_advisor`, `text`, required/optional): Enter the name of the program advisor or contact person.
* **MBA Additional Comments** (`mba_additional_comments`, `text`, required/optional): Enter any additional comments or information about the application.
* **MBA Program Admission Decision** (`mba_program_admission_decision`, `select_one`, required/optional): Choose the admission decision:
	+ Complete
	+ Incomplete
	+ Not Applicable
* **MBA Admission Date** (`mba_decision_date`, `date`, required/optional): Enter the date of the admission decision.
* **MBA Status Update Date** (`mba_status_update_date`, `date`, required/optional): Enter the date of the last status update.
* **MBA Application ID** (`mba_application_id`, `text`, required/optional): Enter a unique identifier for the application.
* **MBA Status Update Reason** (`mba_status_update_reason`, `text`, required/optional): Enter a brief explanation for the status update.
* **MBA Application Fee** (`mba_application_fee`, `number`, required/optional): Enter the fee associated with the application.
* **MBA Program Fee** (`mba_program_fee`, `number`, required/optional): Enter the fee associated with the MBA program.
* **MBA Application Fee Date** (`mba_application_fee_date`, `date`, required/optional): Enter the date the application fee was paid.
