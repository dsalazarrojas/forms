# ILR Application Checklist - Help Guide
## Purpose
The ILR Application Checklist is a form designed to collect and process information related to International Leave Requests (ILR) applications.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Applicant Details section with the necessary information about the applicant.
2. Select the type of leave from the options provided in the Student Status section.
3. Choose the correct leave type from the options in the Leave Type section.
4. Enter the leave date in the Leave Date field.
5. Provide a reason for leave in the Reason for Leave field.
6. Upload any supporting documents required for the leave in the Supporting Document field.
7. Specify the next action required in the Next Action field.
8. Add any additional notes or comments in the Notes field.
9. Complete any other relevant fields as required.

## Field-by-Field Explanation

* **Applicant Details**: Enter the name, ID number, and other relevant details of the applicant.
* **Application Form**: Provide any additional information about the application, such as student ID, course, and program.
* **Student Status**: Select the current status of the student, such as Active Student, Inactive Student, Allocated Student, Suspended Student, or Graduating Student.
* **Leave Type**: Select the type of leave, such as Indefinite Leave to Remain, Leave of Absence, Leave of Absence with a fixed date, or Other.
* **Leave Date**: Enter the date when the leave will begin.
* **Reason for Leave**: Provide a brief description of the reason for the leave.
* **Supporting Document**: Attach any documents required to support the leave request, such as medical certificates or other relevant papers.
* **Supporting Document Description**: Briefly describe the attached document, its relevance, and any other necessary details.
* **Next Action**: Specify the next action required, such as review by admissions or student support.
* **Notes**: Add any additional comments or notes for follow-up actions.
* **Created By**: Automatically populated with the name of the user who created the form.
* **Updated By**: Automatically populated with the name of the user who last updated the form.
* **Created Date**: Automatically populated with the date when the form was created.
* **Updated Date**: Automatically populated with the date when the form was last updated.
* **Assigned To**: Specify the user to whom the form is assigned.
* **Status**: Select the current status of the form, such as New, In Progress, Done, or Not Applicable.
* **Follow-up Date**: Enter the date when a follow-up action is required.
* **Follow-up By**: Specify the user responsible for the follow-up action.
* **Follow-up Status**: Select the current status of the follow-up action, such as Not Required, Completed, In Progress, or Due Soon.
* **Follow-up Comments**: Add any comments related to the follow-up action.
* **Submitted By**: Automatically populated with the name of the user who submitted the form.
* **Submitted Date**: Automatically populated with the date when the form was submitted.
* **Review By**: Automatically populated with the name of the user who reviewed the form.
* **Reviewed By**: Automatically populated with the name of the user who last reviewed the form.
* **Reviewed Date**: Automatically populated with the date when the form was last reviewed.

## Tips

* Please ensure that all fields are completed accurately and thoroughly.
* Double-check the leave type and student status to ensure they match the applicant's circumstances.
* Upload any necessary supporting documents to support the leave request.
* Specify the next action required to ensure the leave request is processed efficiently.
* Review the form carefully before submitting it to ensure all necessary information is provided.
