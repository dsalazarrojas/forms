# Closing Check Survey - Help Guide
## Purpose
The Closing Check Survey is used to document the completion of closing procedures, ensuring that the facility is secure, clean, and prepared for the next day.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the required fields marked as such.
2. Answer each section carefully, making sure to select the correct status for each task or issue.
3. Provide any additional notes or observations as needed.

## Field-by-Field Explanation
* **Employee Name** (`employee_name`, required): Enter the name of the person performing the closing procedures.
* **Employee ID** (`employee_id`, optional): Enter the ID number of the employee performing the closing procedures.
* **Location or Department** (`location`, required): Enter the location or department being closed.
* **Closing Date** (`closing_date`, required): Enter the date of the closing procedures.
* **Closing Time** (`closing_time`, required): Enter the time when closing procedures started.
* -- **Facility Condition--** (`section_facility`, optional): Check the facility status in this optional section.
* **All floors cleaned and swept** (`floors_cleaned`, required): Select the status of floor cleaning and sweeping.
* **Restrooms cleaned and restocked** (`restrooms_checked`, required): Select the status of restrooms cleaning and restocking.
* **All trash removed and bins emptied** (`trash_removed`, required): Select the status of trash removal and bin emptying.
* **All surfaces wiped and disinfected** (`surfaces_wiped`, required): Select the status of surface cleaning and disinfection.
* -- **Security and Access--** (`section_security`, optional): Check the security and access procedures.
* **All doors locked and secured** (`doors_locked`, required): Select the status of door locking and securing.
* **All windows locked and checked** (`windows_locked`, required): Select the status of window locking and checking.
* **Security alarm armed and activated** (`alarm_activated`, required): Select the status of security alarm.
* **All unnecessary lights turned off** (`lights_off`, required): Select the status of light turning off.
* -- **Equipment and Systems--** (`section_equipment`, optional): Check the equipment and systems shutdown.
* **All equipment powered down and secured** (`equipment_powered_down`, required): Select the status of equipment shutdown.
* **Water and utilities checked** (`water_shut_off`, required): Select the status of water and utilities check.
* **Climate control set appropriately** (`climate_control`, required): Select the status of climate control.
* -- **Issues and Maintenance--** (`section_issues`, optional): Report any issues or problems encountered.
* **Any issues or problems encountered** (`issues_found`, required): Select the status of any issues or problems.
* **Describe any issues found** (`issue_description`, optional): Provide a detailed description of any issues or problems.
* **Issues reported to management** (`issue_reported`, optional): Select the status of issue reporting to management.
* **Supervisor name if contacted** (`supervisor_notified`, optional): Enter the supervisor's name if contacted.
* **Additional notes or observations** (`additional_notes`, optional): Enter any additional notes or observations.

Note: Required fields are marked as such in the form.
