# Apartment Turn Checklist Form - Help Guide
## Purpose
The Apartment Turn Checklist Form is designed to collect and document the status of an apartment unit during the turn-over process, ensuring that all relevant aspects are addressed and updated accurately.

## How To Complete This Form
1. Fill out the form for each unit that is undergoing turn-over.
2. Ensure all required fields are filled out accurately.
3. If a condition is not applicable, mark it as "Not needed" or "N/A" in the relevant field.
4. Update the form regularly to reflect changes in the unit's status.

## Field-by-Field Explanation

* **Move-out date** (Turnover date): Date of the tenant's departure from the unit.
* **Property address**: The address of the apartment unit being turned over.
* **Unit number**: The unit number or identification number for the apartment.
* **Outgoing tenant name**: The name of the outgoing tenant.
* **Expected next move-in date**: The anticipated date the unit will be ready for the next tenant.
* **Property manager name**: The name of the property manager responsible for the unit.
* **Turnover inspection date**: Date the unit inspection was performed.
* **General cleaning needed**: Indicate if the unit requires deep, standard, or minimal cleaning.
* **Carpet condition**: Assess the condition of the carpet, with options for no cleaning needed, standard cleaning, or replacement.
* **Carpet cleaning scheduled**: Indicate if carpet cleaning is scheduled or not.
* **Flooring repairs needed**: Specify if no repairs, minor, or major repairs are required.
* **Paint needed**: Indicate if full, spot, or minor touch-ups are needed.
* **Paint color selected**: If paint is needed, specify the selected color.
* **Wall damage assessment**: Describe any wall damage, including holes, marks, or stains.
* **Appliances inspection needed**: Check if all appliances are functioning well, or if some or all need repair.
* **Appliance issues**: If any appliances require repair, describe the issues in detail.
* **Plumbing inspection needed**: Indicate if no plumbing issues, minor, or major repairs are required.
* **Plumbing issues**: If plumbing issues exist, describe them in detail.
* **HVAC system inspection needed**: Check if the system is working properly, or if filter change, service, or replacement is needed.
* **Pest control treatment needed**: Indicate if a full or targeted treatment is required.
* **Odor treatment needed**: Specify if extensive, minor, or no odor removal is needed.
* **Hardware replacement needed**: Indicate if extensive or minor hardware replacement is required.
* **Security lock changes needed**: Specify if locks need rekeying, replacement, or no changes are required.
* **Move-out damages recorded**: Describe any damages recorded during the move-out process.
* **Estimated total repair costs**: Record the estimated total repair costs for the unit.
* **When will unit be ready for showings**: Anticipate when the unit will be ready for showings.
* **Anticipated turnover completion date**: Estimate when the turn-over process will be completed.
