# Kitchen Inventory Checklist - Help Guide
## Purpose
The Kitchen Inventory Checklist is used to track the inventory levels of food items, refrigerators, freezers, and dishware, as well as identify urgent restocking needs and maintenance issues. This form helps maintain accurate and up-to-date inventory information, allowing for efficient stock management and timely restocking or maintenance actions.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the stock levels for each category (Pantry, Refrigerator, Freezer, and Dishware) using the options provided.
2. Check the urgent restocking needs for each category (Pantry, Refrigerator, Freezer) using the options provided.
3. Check the maintenance issues for each category (Pantry, Refrigerator, Freezer) using the options provided.
4. Add any comments or notes about the current stock levels or issues, if needed.

## Field-by-Field Explanation
* **Stock Levels** (<label> Stock Levels, <type> select_multiple): Choose the stock level (High, Low) for the following areas:
  * Pantry: Select the stock level of food items currently available in the pantry.
  * Refrigerator: Select the stock level of food items currently available in the refrigerator.
  * Freezer: Select the stock level of food items currently available in the freezer.
  * Dishware: Select the stock level of dishware (plates, cups, etc.) available in the kitchen.
* **Urgent Restocking Needs** (<label> Urgent Restocking Needs, <type> select_multiple): Check if any urgent restocking needs are present:
  * Pantry: Check if urgent restocking needs are present in the pantry.
  * Refrigerator: Check if urgent restocking needs are present in the refrigerator.
  * Freezer: Check if urgent restocking needs are present in the freezer.
* **Urgent Restocking Needs** (<label> Urgent Restocking Needs Pantry, <type> select_one): Choose the urgent restocking need status for the pantry.
  * Pantry: Check if urgent restocking needs are present in the pantry.
* **Urgent Restocking Needs** (<label> Urgent Restocking Needs Refrigerator, <type> select_one): Choose the urgent restocking need status for the refrigerator.
  * Refrigerator: Check if urgent restocking needs are present in the refrigerator.
* **Urgent Restocking Needs** (<label> Urgent Restocking Needs Freezer, <type> select_one): Choose the urgent restocking need status for the freezer.
  * Freezer: Check if urgent restocking needs are present in the freezer.
* **Maintenance Issues** (<label> Maintenance Issues, <type> select_multiple): Check if any maintenance issues are present in the kitchen:
  * Pantry: Check for maintenance issues in the pantry.
  * Refrigerator: Check for maintenance issues in the refrigerator.
  * Freezer: Check for maintenance issues in the freezer.
* **Maintenance Issues** (<label> Maintenance Issues Pantry, <type> select_one): Check for maintenance issues in the pantry.
  * Pantry: Choose the maintenance issue status for the pantry.
* **Maintenance Issues** (<label> Maintenance Issues Refrigerator, <type> select_one): Check for maintenance issues in the refrigerator.
  * Refrigerator: Choose the maintenance issue status for the refrigerator.
* **Maintenance Issues** (<label> Maintenance Issues Freezer, <type> select_one): Check for maintenance issues in the freezer.
  * Freezer: Choose the maintenance issue status for the freezer.
* **Comments** (<label> Comments, <type> note): Add any comments or notes about the current stock levels or issues.
  * Comments 1: Add comments or notes about the current stock levels or issues in this field.
  * Comments 2: Add comments or notes about the current stock levels or issues in this field.
  * Comments 3: Add comments or notes about the current stock levels or issues in this field.

## Tips
* Always check the stock levels regularly to ensure accurate information.
* Report urgent restocking needs and maintenance issues promptly to prevent shortages or equipment failure.
* Use the comments field to add any additional information that may be helpful for future reference.
