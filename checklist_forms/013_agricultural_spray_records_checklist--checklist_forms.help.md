# Agricultural Spray Records Checklist - Help Guide
## Purpose
The Agricultural Spray Records Checklist is a form used to record the details of a pesticide application. This form helps ensure accurate and safe application of pesticides in agricultural settings.

## How To Complete This Form

1. **Provide Application Details**: Fill in the application details section.
	* Enter the **Applicator Name**: This is your name and contact information.
	* Enter the **License Number**: This is your state applicator license ID.
	* Select the **Date of Application**: This is the date on which the application took place.
2. **Specify the Crop and Location**: Enter the **Field Location ID**: This is a reference to the field or map location.
	* Enter the **Crop Treated**: This is the type of crop being treated (e.g. Corn, Apples).
3. **Chemical Information**: Enter the **Chemical Product Name**: This is the brand name of the chemical product used.
	* Enter the **EPA Registration Number**: This is the EPA registration number found on the product label.
	* Enter the **Rate per Acre**: This is the amount of chemical applied per unit area.
	* Enter the **Total Amount Used**: This is the total amount of chemical applied.
4. **Weather Conditions**: Select the **Wind Speed (mph)**: This is the wind speed at the time of application. Ensure it is within legal limits.
	* Enter the **Wind Direction**: This is the direction from which the wind is coming.
	* Enter the **Temperature (F)**: This is the temperature at the time of application.
5. **Safety Protocols**: Verify **Safety Checks**: This is a note section to record any safety protocols followed.
6. **Tank Cleanout and PPE**: Select **Tank Cleanout Verified**:
	+ If yes, select **True**
	+ If no, select **False**
7. **Personal Protective Equipment (PPE)**: Select **PPE Worn**:
	+ If yes, select **True**
	+ If no, select **False**

## Field-by-Field Explanation

* **Application Details**: This section collects general application information.
	+ **Applicator Name**: Your name and contact information.
	+ **License Number**: Your state applicator license ID.
	+ **Date of Application**: The date on which the application took place.
* **Field Location ID**: A reference to the field or map location.
* **Crop Treated**: The type of crop being treated (e.g. Corn, Apples).
* **Chemical Information**: This section provides details on the chemical product used.
	+ **Chemical Product Name**: The brand name of the chemical product used.
	+ **EPA Registration Number**: The EPA registration number found on the product label.
	+ **Rate per Acre**: The amount of chemical applied per unit area.
	+ **Total Amount Used**: The total amount of chemical applied.
* **Weather Conditions**: Select the wind speed and direction at the time of application.
	+ **Wind Speed (mph)**: The wind speed at the time of application.
	+ **Wind Direction**: The direction from which the wind is coming.
	+ **Temperature (F)**: The temperature at the time of application.
* **Safety Protocols**: This section is for recording any safety protocols followed.
* **Tank Cleanout and PPE**:
	+ **Tank Cleanout Verified**: If the tank was cleaned before/after use.
	+ **PPE Worn**: If personal protective equipment was used during the application.
