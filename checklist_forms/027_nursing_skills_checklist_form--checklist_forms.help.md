# Nursing Skills Checklist Form - Help Guide
## Purpose
This form is designed to help healthcare professionals assess a patient's vital signs, medical conditions, and treatment needs.

## How To Complete This Form
To complete this form, follow these steps:

1. Select "Yes" or "No" for each field as appropriate.
2. For fields with multiple options, select all applicable options.
3. For fields that require a text response, enter a brief description in the provided field.
4. Make sure to carefully review each field before submitting the form to ensure accuracy and completeness.

## Field-by-Field Explanation
* **First Page** (`first_page`, Select Multiple, Optional): Select "Yes" or "No" for each section.
* **Blood Pressure Check** (`blood_pressure_check`, Select One, Optional): Check if the patient's blood pressure is being checked.
	+ Select "Yes" if you are checking the patient's blood pressure.
	+ Select "No" if you are not checking the patient's blood pressure.
* **Oxygen Saturations** (`oxygen_saturations`, Number, Optional): Record the patient's oxygen saturations level (e.g., 92%, 98%).
* **Oxygen Levels** (`oxygen_levels`, Select Multiple, Optional): Select the patient's oxygen levels.
	+ "High" if the patient's oxygen levels are high.
	+ "Low" if the patient's oxygen levels are low.
* **Medication Administered** (`medication_administered`, Select One, Optional): Check if medication has been administered to the patient.
	+ Select "Yes" if medication has been given to the patient.
	+ Select "No" if no medication has been given to the patient.
* **Vital Signs** (`vital_signs`, Select Multiple, Optional): Select the patient's vital signs.
	+ "Yes" if the patient's vital signs are being recorded.
	+ "No" if vital signs are not being recorded.
* **Medical Therapy** (`medical_therapy`, Select One, Optional): Check if the patient is receiving medical therapy.
	+ Select "Yes" if the patient is receiving medical therapy.
	+ Select "No" if the patient is not receiving medical therapy.
* **Patient Status** (`patient_status`, Select Multiple, Optional): Select the patient's status.
	+ "Active" if the patient is active.
	+ "Inactive" if the patient is inactive.
* **Medical Conditions** (`medical_conditions`, Text, Optional): Record any medical conditions the patient may have.
* **Allergies** (`allergies`, Select Multiple, Optional): Select the patient's allergies.
	+ "Yes" if the patient has allergies.
	+ "No" if the patient does not have allergies.
* **Medication Allergies** (`medication_allergies`, Select One, Optional): Check if the patient has medication allergies.
	+ Select "Yes" if the patient has medication allergies.
	+ Select "No" if the patient does not have medication allergies.
* **Patient History** (`patient_history`, Text, Optional): Record a brief description of the patient's medical history.
* **Medical Certifications** (`medical_certifications`, Select Multiple, Optional): Select the patient's medical certifications.
	+ "Yes" if the patient has medical certifications.
	+ "No" if the patient does not have medical certifications.
* **Patient Therapy** (`patient_therapy`, Select One, Optional): Check if the patient is receiving therapy.
	+ Select "Yes" if the patient is receiving therapy.
	+ Select "No" if the patient is not receiving therapy.
* **Patient Medical History** (`patient_medical_history`, Text, Optional): Record a brief description of the patient's medical history.
* **Nursing Skills** (`nursing_skills`, Select Multiple, Optional): Select the nursing skills used on the patient.
	+ "Yes" if nursing skills are being used.
	+ "No" if nursing skills are not being used.
* **Medical Skills** (`medical_skills`, Select Multiple, Optional): Select the medical skills used on the patient.
	+ "Yes" if medical skills are being used.
	+ "No" if medical skills are not being used.
* **First Aid Skills** (`first_aid_skills`, Select Multiple, Optional): Select the first aid skills used on the patient.
	+ "Yes" if first aid skills are being used.
	+ "No" if first aid skills are not being used.
* **Blood Boroderm** (`blood_boroderm`, Select One, Optional): Check if blood boroderm is being used on the patient.
	+ Select "Yes" if blood boroderm is being used.
	+ Select "No" if blood boroderm is not being used.
* **Oxygen Boroderm** (`oxygen_boroderm`, Select One, Optional): Check if oxygen boroderm is being used on the patient.
	+ Select "Yes" if oxygen boroderm is being used.
	+ Select "No" if oxygen boroderm is not being used.
* **Patient Ventilation** (`patient_ventilation`, Select Multiple, Optional): Select the patient's ventilation status.
	+ "Yes" if the patient is being ventilated.
	+ "No" if the patient is not being ventilated.
* **Patient Resuscitation** (`patient_resuscitation`, Select Multiple, Optional): Select the patient's resuscitation status.
	+ "Yes" if the patient is being resuscitated.
	+ "No" if the patient is not being resuscitated.
* **Patient Resuscitation Status** (`patient_resuscitation_status`, Select One, Optional): Check the patient's resuscitation status.
	+ Select "Active" if the patient is active.
	+ Select "Inactive" if the patient is inactive.
* **Patient Intubation** (`patient_intubation`, Select One, Optional): Check if the patient is intubated.
	+ Select "Yes" if the patient is intubated.
	+ Select "No" if the patient is not intubated.
* **Patient Exhubation** (`patient_extubation`, Select One, Optional): Check if the patient is exhubated.
	+ Select "Yes" if the patient is exhubated.
	+ Select "No" if the patient is not exhubated.

## Tips
* Make sure to carefully review each field before submitting the form to ensure accuracy and completeness.
* If you are unsure about any field, do not hesitate to consult with a colleague or medical professional for guidance.
* This form is designed to be a quick and efficient way to record key information about a patient.
