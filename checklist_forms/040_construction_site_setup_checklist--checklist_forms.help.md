# Construction Site Setup Checklist - Help Guide
## Purpose
The Construction Site Setup Checklist is a comprehensive form used to evaluate the readiness of a construction site for work. It ensures that all necessary safety measures, utilities, and facilities are in place before construction activities begin.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully and answer the questions based on the site's current status.
2. Ensure you answer all required fields, marked as "required" in the form.
3. If an option is not applicable, select "Not Required" or "False" accordingly.
4. For fields like "Yes, Complete" or "Yes, All," ensure that all requirements are met.
5. For fields like "Some" or "Partial," provide a brief explanation or note on the specific areas that are incomplete or partially ready.
6. For fields like "Items Not Complete," list any unchecked items that need attention.
7. Finally, confirm your answers and submit the form.

## Field-by-Field Explanation

* **Checklist Date** (`checklist_date`, date, required): Record the date when the checklist is completed.
* **Site Name** (`site_name`, text, required): Enter the name of the construction site.
* **Site Address** (`site_address`, text, required): Provide the full address of the construction site.
* **Site Manager** (`site_manager`, text, required): Enter the name of the site manager.
* **General Contractor** (`general_contractor`, text, required): Enter the name of the general contractor company.
* **Site Security Fence Installed** (`site_security_fence`, select_one, required): Select "Yes, Complete" if the perimeter is fully secured; "Yes, Partially" if some areas are secured; "False" if not secured; "Not Required" if not applicable.
* **Site Gates Installed** (`site_gates`, select_one, required): Select "Yes, All" if all entry points are fully secured; "Some" if some are secured; "False" if not secured; "Not Required" if not applicable.
* **Safety Signs Posted** (`signage_safety`, select_one, required): Select "Yes, All Posted" if all required signs are present; "Some Posted" if some are present; "False" if not posted; "Not Required" if not applicable.
* **Emergency Contact Signs Posted** (`signage_contact`, select_one, required): Select "True" if contact information is visible; "False" if not visible; "Not Required" if not applicable.
* **Office Trailer Set Up** (`office_trailer`, select_one, required): Select "Yes, Complete" if the site office is fully prepared; "In Progress" if still setting up; "False" if not set up; "Not Required" if not applicable.
* **Utilities Connected** (`utilities_connected`, select_one, required): Select "Yes, All" if all necessary utilities are connected; "Some Connected" if some are connected; "None" if not connected; "Not Required" if not applicable.
* **Temporary Power Installed** (`temporary_power`, select_one, required): Select "True" if temporary power is available; "False" if not available; "Not Required" if not applicable.
* **Temporary Water Available** (`temporary_water`, select_one, required): Select "True" if temporary water is available; "False" if not available; "Not Required" if not applicable.
* **Portable Toilets Delivered** (`portable_toilets`, select_one, required): Select "Yes, Sufficient" if sufficient toilets are available; "Yes, Limited" if limited toilets are available; "False" if not available.
* **Waste Containers Placed** (`waste_containers`, select_one, required): Select "Yes, Sufficient" if sufficient waste containers are available; "Yes, Limited" if limited containers are available; "False" if not available.
* **Material Storage Area Designated** (`material_storage_area`, select_one, required): Select "Yes, Marked" if the area is clearly marked; "Yes, Informal" if the area is not clearly marked but still accessible; "False" if not designated.
* **Worker Parking Area Designated** (`parking_area`, select_one, required): Select "Yes, Marked" if the area is clearly marked; "Yes, Informal" if not clearly marked but still accessible; "False" if not designated.
* **First Aid Station Set Up** (`first_aid_station`, select_one, required): Select "Yes, Fully Stocked" if the station is fully stocked; "Yes, Basic" if basic supplies are available; "False" if not stocked.
* **Fire Extinguishers Placed** (`fire_extinguishers`, select_one, required): Select "Yes, All Placed" if all fire extinguishers are available; "Some Placed" if some are available; "False" if not placed.
* **Emergency Exits Marked** (`emergency_exits`, select_one, required): Select "Yes, All Marked" if all exits are clearly marked; "Some Marked" if some are marked; "False" if not marked.
* **Site Lighting Adequate** (`lighting_adequate`, select_one, required): Select "Yes, Full Coverage" if full lighting is available; "Yes, Partial" if partial lighting is available; "False" if not available.
* **Equipment Staging Area Ready** (`equipment_staging`, select_one, required): Select "Yes, Prepared" if the area is ready; "Yes, Needs Work" if still being prepared; "False" if not ready.
* **Erosion Control Measures** (`erosion_control`, select_one, required): Select "Yes, Installed" if erosion control measures are in place; "Yes, Partially" if partially in place; "False" if not in place; "Not Required" if not applicable.
* **Dust Control Measures** (`dust_control`, select_one, required): Select "Yes, In Place" if dust control measures are available; "Yes, Partially" if partially available; "False" if not available.
* **Safety Barriers Installed** (`safety_barriers`, select_one, required): Select "Yes, All Areas" if all barriers are in place; "Some Areas" if some are in place; "False" if not in place.
* **Check-In Station Ready** (`check_in_station`, select_one, required): Select "Yes, Complete" if the station is fully set up; "Basic Setup" if basic setup is available; "False" if not set up.
* **Items Not Complete** (`items_incomplete`, text, false): List any unchecked items that require attention.
* **Action Items** (`action_items`, text, required): List any tasks that need to be performed for site readiness.
* **Site Ready for Work** (`site_ready_for_work`, select_one, required): Select "Yes, Fully Ready" if the site is fully ready; "Yes, With Minor Items" if some minor tasks need to be completed; "No, Not Ready" if not ready.
* **Inspector Signature** (`inspector_signature`, text, required): Enter the full name as a signature.

## Tips
* Ensure that all required fields are completed before submitting the form.
* Provide clear explanations for fields like "Some" or "Partially" to help with site-specific context.
* List specific items or tasks that need attention in "Items Not Complete" and "Action Items" fields.
* Review the form carefully before submitting to ensure accurate representation of the site's status.
