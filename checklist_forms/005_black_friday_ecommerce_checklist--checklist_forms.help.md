# Black Friday Ecommerce Checklist - Help Guide
## Purpose
This form is used to ensure that the ecommerce store is properly set up and prepared for the Black Friday sales event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the store name and platform information in sections 1 and 3.
2. Check the inventory synchronization status in section 4.
3. Verify that payment gateway testing has been completed in section 5.
4. Check that site speed has been checked in section 6.
5. Enter the shipping cutoff date if applicable in section 7.
6. Enter the customer support staffing levels in section 8.
7. Check that promotional assets are ready in section 9.
8. Enter any contingency notes in section 10.

## Field-by-Field Explanation
* **Store name** (`store_name`, required): Enter the platform store identifier or domain.
* **Ecommerce platform** (`platform`, required): Select the platform where the store is hosted from the dropdown list.
* **Inventory synced with sales channels** (`inventory_synced`, required): Choose 'True' if inventory is synced with sales channels, 'False' otherwise.
* **Payment gateway tested** (`payment_gateway_tested`, required): Choose 'True' if payment gateway testing has been completed, 'False' otherwise.
* **Site speed check completed** (`site_speed_check`, required): Choose 'True' if site speed check has been completed, 'False' otherwise.
* **Shipping cutoff date** (`shipping_cutoff_date`, optional): Enter the last date orders ship before delay if applicable.
* **Customer support staffing levels** (`customer_support_staffing`, optional): Enter the number of support staff scheduled.
* **Promotional assets ready** (`promotional_assets_ready`, required): Choose 'True' if promotional assets (banners, social media and email templates) are ready, 'False' otherwise.
* **Contingency notes** (`contingency_notes`, optional): Enter brief backup plan description if applicable.
* **Store overview** (`section_store_overview`, optional): Enter basic store setup verification notes.
