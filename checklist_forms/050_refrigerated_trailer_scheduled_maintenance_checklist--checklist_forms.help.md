# Refrigerated Trailer Scheduled Maintenance Checklist - Help Guide

## Purpose
This form is used to schedule and document the maintenance of refrigerated trailers.

## How To Complete This Form

1.  Start by filling out the trailer information section, which includes selecting the type of trailer being maintained (Trailer, Tractor, or Generator).
2.  For the engine oil field, select the correct oil type that was used last time the trailer was maintained (5k, 10k, or 20k).
3.  Check the condition of the trailer's air filter and select the correct option (Clean, Dirty, or Not Applicable).
4.  Check the trailer's coolant temperature and select the correct range (50-60, 40-50, or Below 40).
5.  Check the condition of the trailer's brakes and select the correct option (Good, Fair, or Poor).
6.  Check the condition of the trailer's suspension and select the correct option (Good, Fair, or Poor).
7.  Check the condition of the trailer's tires and select the correct option (Good, Fair, or Poor).
8.  Check the condition of the trailer's wheels and select the correct option (Good, Fair, or Poor).
9.  Check the condition of the trailer's electrical system and select the correct option (Good, Fair, or Poor).
10. Check the condition of the trailer's lights and select the correct option (Good, Fair, or Poor).
11. Check if the safety certification is expired, renewed, or not applicable.
12. Record the date of the last maintenance.
13. Record the date of the next scheduled maintenance.
14. Add any additional notes about the maintenance process.
15. Sign the form as the technician and supervisor (if required).
16. Record the date and time of the maintenance.
17. Record the location of the maintenance.
18. Record the trailer number.
19. Record the odometer readings.
20. Record the engine hours.
21. Record the engine oil level.
22. Record the fuel level.

## Field-by-Field Explanation

*   **Trailer Info (2)**: Select the type of trailer being maintained (Trailer, Tractor, or Generator).
*   **Engine Oil (3)**: Select the correct oil type that was used last time the trailer was maintained (5k, 10k, or 20k).
*   **Air Filter (4)**: Check the condition of the trailer's air filter and select the correct option (Clean, Dirty, or Not Applicable).
*   **Coolant Temperature (5)**: Check the trailer's coolant temperature and select the correct range (50-60, 40-50, or Below 40).
*   **Brake Temp (6)**: Check the condition of the trailer's brakes and select the correct option (Good, Fair, or Poor).
*   **Suspension (7)**: Check the condition of the trailer's suspension and select the correct option (Good, Fair, or Poor).
*   **Tire (8)**: Check the condition of the trailer's tires and select the correct option (Good, Fair, or Poor).
*   **Wheel (9)**: Check the condition of the trailer's wheels and select the correct option (Good, Fair, or Poor).
*   **Electrical (10)**: Check the condition of the trailer's electrical system and select the correct option (Good, Fair, or Poor).
*   **Lights (11)**: Check the condition of the trailer's lights and select the correct option (Good, Fair, or Poor).
*   **Safety Certif (12)**: Check if the safety certification is expired, renewed, or not applicable.
*   **Maintenance Date (13)**: Record the date of the last maintenance.
*   **Next Scheduled Maint (14)**: Record the date of the next scheduled maintenance.
*   **Notes (15)**: Add any additional notes about the maintenance process.
*   **Tech Signature (16)**: Sign the form as the technician.

## Tips

*   Be sure to fill out all required fields.
*   Double-check the condition of the trailer's systems before filling out the form.
*   Keep the form up-to-date and consistent across different entries.
*   Make sure to sign the form as the technician and supervisor (if required).
