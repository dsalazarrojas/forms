# Furnishing Task Entry Checklist - Help Guide
## Purpose
This form is designed to collect data about furnishing tasks, including task status, assigned tasks, task names, descriptions, types, deadlines, and start dates. Please complete the form accurately to provide relevant information about the tasks.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Ensure you have all the necessary information about the task before starting.
2. Select the correct page (if applicable) and fill out the required fields.

## Field-by-Field Explanation

### Room Number (Page 1)
* **Room Number** (`room_number`, number, optional): This field is used to identify the room associated with the task. Enter the room number if known.

### Task Status (Page 1)
* **Task Status** (`task_status`, select_one, optional): Choose the status of the task from the options: Active or Inactive.

### Assigned To (Page 1)
* **Assigned To** (`assigned_to`, select_multiple, optional): Select Yes or No to indicate if the task is assigned to anyone.

### Task Name (Page 1)
* **Task Name** (`task_name`, text, optional): Enter a brief description of the task.

### Task Description (Page 1)
* **Task Description** (`task_description`, text, optional): Provide a detailed description of the task.

### Task Type (Page 1)
* **Task Type** (`task_type`, select_one, optional): Choose Yes or No to indicate if the task type is relevant to the task.

### Deadline (Page 2)
* **Deadline** (`deadline`, date, optional): Enter the deadline for the task if applicable.

### Start Date (Page 2)
* **Start Date** (`start_date`, date, optional): Enter the start date for the task if applicable.

## Tips
* If you're unsure about the task status or type, choose the most accurate option based on your best judgment.
* Ensure you have all the necessary information before filling out the form.
* If you need to add more tasks, you can navigate through the page options to access additional pages.
* If you encounter any issues or have questions, please contact the administrator.
