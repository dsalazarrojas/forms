# document_archiving_checklist - Help Guide
## Purpose
The document archiving checklist is a form used to capture metadata about archived documents. This form helps to track and categorize documents, making it easier to locate and retrieve them when needed.

## How To Complete This Form
1. Select the appropriate status of the archived document from the options provided.
2. Choose the correct storage location for the document.
3. Specify the retention period for the document in months.
4. Select the date the document was archived.
5. Select the last updated date for the document.
6. Provide any additional notes about the document.
7. Specify who archived the document.
8. Enter the document name and number.
9. Select the document version and category.
10. Select the document subcategory.
11. Enter a brief summary of the document description.
12. Select the date the document was created.
13. Select the date the document was archived.
14. Specify the document size.
15. Select the date of the document version.
16. Select the document tags.
17. Select the date of the document status.
18. Select the date the document was last archived.
19. Specify the retention period in days.
20. Select the status of the document in the archive.

## Field-by-Field Explanation

* **Archived Documents**: Select whether the document is archived, unarchived, not started, in progress, or complete.
	+ Archived: The document has been archived.
	+ Unarchived: The document has not been archived.
	+ Not Started: The document has not been started.
	+ In Progress: The document is currently being worked on.
	+ Complete: The document is finished.
* **Document Type**: Select the type of document (paper, digital, or electronic).
* **Storage Location**: Choose the location where the document is stored (onsite, offsite, or cloud storage).
* **Document Status**: Select the status of the document (active, inactive, or pending).
* **Retention Period**: Specify the retention period for the document in months.
* **Date Archived**: Enter the date the document was archived in the format YYYY-MM-DD.
* **Last Updated**: Enter the last updated date for the document in the format YYYY-MM-DD.
* **Notes**: Provide any additional notes or comments about the document.
* **Archived By**: Select who archived the document.
* **Document Name**: Enter the document name or title.
* **Document Number**: Enter the document identification number.
* **Document Version**: Enter the document version number or identifier.
* **Document Category**: Select the category of the document.
* **Document Subcategory**: Select the subcategory of the document.
* **Document Description**: Enter a brief summary of the document.
* **Date Created**: Enter the date the document was created.
* **Archived At**: Select the date the document was archived.
* **Date Due**: Enter the date the document is due in the format YYYY-MM-DD.
* **Document Size**: Enter the size of the document.
* **Document Version Date**: Enter the date of the document version in the format YYYY-MM-DD.
* **Document Tags**: Select the tags associated with the document.
* **Document Status Date**: Select the date of the document status.
* **Date Last Archived**: Enter the date the document was last archived in the format YYYY-MM-DD.
* **Retention Period (days)**: Specify the retention period in days.
* **Archive Status**: Select the status of the document in the archive (archive or not archived).

Note: This help guide is based on the provided YAML fields and is meant to be a general guide. The specific fields and options may vary based on the actual implementation of the form.
