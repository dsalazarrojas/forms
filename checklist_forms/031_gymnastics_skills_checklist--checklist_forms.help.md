# Gymnastics Skills Checklist - Help Guide
## Purpose
This form is designed to help track and evaluate the skills and progress of gymnasts. It's meant to be filled out by coaches, instructors, or parents to assess the gymnasts under their care.

## How To Complete This Form

To complete this form, follow these steps:

1. **Select the skills the gymnast has achieved**: Choose the skills the gymnast has mastered from the list of options on the first page. 
2. **Choose the skill level**: Select the skill level the gymnast has reached, whether beginner, intermediate, or advanced. This helps to categorize their progress.
3. **Add progress comments**: Provide any comments or notes about the gymnast's progress, if needed.
4. **Date practiced**: Record the date the gymnast last practiced the skill.
5. **Date mastered**: Mark the date the gymnast mastered the skill.
6. **Notes**: Add any additional comments or thoughts about the gymnast's performance.
7. **Skills checked**: Select how many skills the gymnast has checked as mastered, with options 1, 2, or 3.
8. **Gymnast name**: Enter the name of the gymnast being evaluated.
9. **Practice session**: Indicate the time of day the gymnast practiced, whether morning, afternoon, or evening.
10. **Practice location**: Record the location where the gymnast practiced.

## Field-by-Field Explanation

* **Skills List (`skills_list`, select_multiple)**: This is the list of gymnastics skills to be evaluated. Choose all the skills the gymnast has mastered.
* **Skill Level (`skill_level`, select_one)**: Select the skill level the gymnast has achieved, whether beginner, intermediate, or advanced.
* **Progress Comments (`progress_comments`, text)**: Add any comments or notes about the gymnast's progress.
* **Date Practiced (`date_practiced`, date)**: Record the date the gymnast last practiced the skill.
* **Date Mastered (`date_mastered`, date)**: Mark the date the gymnast mastered the skill.
* **Notes (`notes`, text)**: Add any additional comments or thoughts about the gymnast's performance.
* **Skills Checked (`skill_checked`, select_one)**: Select how many skills the gymnast has mastered, with options 1, 2, or 3.
* **Gymnast Name (`gymnast_name`, text)**: Enter the name of the gymnast being evaluated.
* **Practice Session (`practice_session`, select_multiple)**: Indicate the time of day the gymnast practiced, whether morning, afternoon, or evening.
* **Practice Location (`practice_location`, text)**: Record the location where the gymnast practiced.
