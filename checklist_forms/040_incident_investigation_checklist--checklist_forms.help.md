# incident_investigation_checklist - Help Guide
## Purpose
The incident investigation checklist is a tool used to gather and track information about incidents, including investigation actions, dates, locations, descriptions, employee involvement, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and ensure you have all the necessary information before starting the investigation.
2. Select the relevant options for each field as applicable to the incident.
3. Ensure you complete each section thoroughly, providing as much detail as possible.
4. Save your progress regularly to avoid data loss in case of unexpected interruptions.

## Field-by-Field Explanation
### Investigation Actions
* **Investigation actions** (`investigation_actions`, `select_multiple`, required/optional): This field allows you to select the actions taken during the investigation. Select all applicable actions from the list.

### Incident Information
* **incident_date** (`incident_date`, `date`, required/optional): Enter the date of the incident.
* **incident_time** (`incident_time`, `time`, required/optional): Enter the time of the incident.
* **incident_location** (`incident_location`, `text`, required/optional): Describe the location where the incident occurred.
* **incident_description** (`incident_description`, `note`, required/optional): Provide a detailed explanation of the incident.

### Incident Parties
* **employee_name** (`employee_name`, `text`, required/optional): Enter the name of the employee(s) involved in the incident.
* **investigation_manager** (`investigation_manager`, `select_one`, required/optional): Select if the investigation manager is involved.
* **incident_type** (`incident_type`, `select_one`, required/optional): Select the type of incident.
* **incident_priority** (`incident_priority`, `select_one`, required/optional): Select the priority of the incident.
* **incident_status** (`incident_status`, `select_one`, required/optional): Select the status of the incident.

### Incident Reporting
* **incident_report** (`incident_report`, `select_multiple`, required/optional): Select if an incident report is required.
* **witness_list** (`witness_list`, `select_multiple`, required/optional): Select if a witness list is required.
