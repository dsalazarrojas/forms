# Electrical Commissioning Checklist - Help Guide
## Purpose
The Electrical Commissioning Checklist is a form used to collect and track information about electrical commissioning projects. It is intended to ensure that all necessary steps and checks are completed during the commissioning process.
## How To Complete This Form
1. Select the relevant checklists for your project from the "Checklists" dropdown menu.
2. Indicate the presence or absence of identified risks using the "Risks" field.
3. Choose the electrical systems that will be commissioned using the "Electrical Systems" field.
4. Select the equipment that will be commissioned using the "Equipment" field.
5. Identify the commissioning team members using the "Commissioning Team Members" field.
6. Choose the commissioning phases that will be completed for each system or equipment using the "Commissioning Phases" field.
7. Indicate the commissioning status for each electrical system or equipment using the "Electrical Commissioning" field.
8. Enter any additional information or comments about the commissioning process using the "Commissioning Checklist" field.
