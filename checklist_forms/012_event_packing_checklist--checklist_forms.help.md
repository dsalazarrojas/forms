# Event Packing Checklist - Help Guide

## Purpose
This form is used to create and manage an event packing checklist. The form contains fields to input event details, items to pack, and status updates.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the required fields:
	* **event_date**: Enter the date of the event.
	* **event_time**: Enter the time of the event.
	* **event_location**: Enter the location of the event.
	* **event_organizer**: Enter the name of the event organizer.
2. Select the items to pack from the list:
	* **event_items**: Choose the items you need to pack for the event.
3. Update the status of each item:
	* **item_status**: Select the status of each item (e.g., packed, not packed, etc.).
4. Add any comments about each item:
	* **item_comments**: Enter any comments or notes about each item.
5. Add any additional notes:
	* **event_notes**: Enter any additional notes about the event.
6. Enter the contact phone number:
	* **event_phone**: Enter the contact phone number for the event organizer.

## Field-by-Field Explanation

* **event_packing_checklist**: This field is the title of the event packing checklist.
	+ Type: Text
	+ Required: No
* **event_date**: Enter the date of the event.
	+ Type: Date
	+ Required: Yes
* **event_time**: Enter the time of the event.
	+ Type: Time
	+ Required: Yes
* **event_location**: Enter the location of the event.
	+ Type: Text
	+ Required: Yes
* **event_items**: Choose the items you need to pack for the event.
	+ Type: Select One
	+ Required: No
* **item_status**: Select the status of each item (e.g., packed, not packed, etc.).
	+ Type: Select Multiple
	+ Required: No
* **item_comments**: Enter any comments or notes about each item.
	+ Type: Text
	+ Required: No
* **event_organizer**: Enter the name of the event organizer.
	+ Type: Text
	+ Required: No
* **event_notes**: Enter any additional notes about the event.
	+ Type: Note
	+ Required: No
* **event_phone**: Enter the contact phone number for the event organizer.
	+ Type: Text
	+ Required: No
