# Assistance Checklist - Help Guide
## Purpose
This form is designed to help case managers provide assistance and support to their clients. It outlines key tasks, deadlines, and progress tracking to ensure that clients receive the necessary help and resources they need.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form fields as required. All fields marked as "required" must be filled in before submitting the form.
2. Ensure that you are entering accurate and up-to-date information for each field.
3. Select the correct status for each item from the dropdown list.
4. Enter the date for each item when completed or due.
5. Sign the form with your name to acknowledge that you have reviewed and agreed to the information provided.

## Field-by-Field Explanation

* **Checklist Date** (`checklist_date`, date): Date of the checklist.
* **Client Name** (`client_name`, text): Person receiving help. Please enter the client's name.
* **Client ID** (`client_id`, text): Case or account number. Please enter the client's ID number.
* **Case Manager Name** (`case_manager`, text): Who is assisting. Please enter your name.
* **Organization** (`organization`, text): Agency name. Please enter the organization's name.
* **Service Type** (`service_type`, select_one): Category of assistance. Choose from:
	+ Financial Assistance
	+ Housing Support
	+ Employment Services
	+ Healthcare Navigation
	+ Food Assistance
	+ Transportation
	+ Childcare
	+ Legal Aid
	+ Other
* **Assistance Category 1** (`assistance_category_1`, text): First area. Please enter the first area of assistance.
* **Item 1a** (`assistance_item_1a`, text): Specific task. Please enter a specific task for the first area.
* **Item 1a Status** (`item_1a_status`, select_one): Complete or not. Select the status for Item 1a from:
	+ Completed
	+ In Progress
	+ Not Started
	+ Not Applicable
* **Item 1a Date** (`item_1a_date`, date): When done or due. Enter the date for Item 1a.
* **Item 1a Notes** (`item_1a_notes`, text): Comments. Enter any additional notes for Item 1a.
* **Item 1b** (`assistance_item_1b`, text): Specific task. Please enter a specific task for the first area.
* **Item 1b Status** (`item_1b_status`, select_one): Complete or not. Select the status for Item 1b from:
	+ Completed
	+ In Progress
	+ Not Started
	+ Not Applicable
* **Item 1b Date** (`item_1b_date`, date): When done or due. Enter the date for Item 1b.
* **Item 1b Notes** (`item_1b_notes`, text): Comments. Enter any additional notes for Item 1b.
* **Item 1c** (`assistance_item_1c`, text): Specific task. Please enter a specific task for the first area.
* **Item 1c Status** (`item_1c_status`, select_one): Complete or not. Select the status for Item 1c from:
	+ Completed
	+ In Progress
	+ Not Started
	+ Not Applicable
* **Item 1c Date** (`item_1c_date`, date): When done or due. Enter the date for Item 1c.
* **Item 1c Notes** (`item_1c_notes`, text): Comments. Enter any additional notes for Item 1c.
* **Assistance Category 2** (`assistance_category_2`, text): Second area. Please enter the second area of assistance.
* **Item 2a** (`assistance_item_2a`, text): Specific task. Please enter a specific task for the second area.
* **Item 2a Status** (`item_2a_status`, select_one): Complete or not. Select the status for Item 2a from:
	+ Completed
	+ In Progress
	+ Not Started
	+ Not Applicable
* **Item 2a Date** (`item_2a_date`, date): When done or due. Enter the date for Item 2a.
* **Item 2a Notes** (`item_2a_notes`, text): Comments. Enter any additional notes for Item 2a.
* **Item 2b** (`assistance_item_2b`, text): Specific task. Please enter a specific task for the second area.
* **Item 2b Status** (`item_2b_status`, select_one): Complete or not. Select the status for Item 2b from:
	+ Completed
	+ In Progress
	+ Not Started
	+ Not Applicable
* **Item 2b Date** (`item_2b_date`, date): When done or due. Enter the date for Item 2b.
* **Item 2b Notes** (`item_2b_notes`, text): Comments. Enter any additional notes for Item 2b.
* **Item 2c** (`assistance_item_2c`, text): Specific task. Please enter a specific task for the second area.
* **Item 2c Status** (`item_2c_status`, select_one): Complete or not. Select the status for Item 2c from:
	+ Completed
	+ In Progress
	+ Not Started
	+ Not Applicable
* **Item 2c Date** (`item_2c_date`, date): When done or due. Enter the date for Item 2c.
* **Item 2c Notes** (`item_2c_notes`, text): Comments. Enter any additional notes for Item 2c.
* **Overall Progress** (`overall_progress`, select_one): How things are going. Choose from:
	+ Excellent - On Track
	+ Good - Minor Delays
	+ Fair - Some Challenges
	+ Poor - Significant Barriers
* **Barriers Identified** (`barriers_identified`, text): What is blocking. Please enter any barriers identified.
* **Next Steps** (`next_steps`, text): What comes next. Please enter next steps for the client.
* **Follow-up Date** (`follow_up_date`, date): When to check in. Enter the follow-up date for the client.
* **Client Signature** (`client_signature`, text): Type name to acknowledge. Enter your name as the client.
* **Case Manager Signature** (`case_manager_signature`, text): Type name to sign. Enter your name as the case manager.
