# Return Shipment Form - Help Guide
## Purpose
This form is used to document and track the return shipment process, ensuring accurate and efficient processing of returned goods.

## How To Complete This Form
1. Fill out the form with all required and optional information.
2. Ensure all fields are accurate and up-to-date.
3. Review and submit the form for review and processing.

## Field-by-Field Explanation

* **Shipment Details** (`Shipment Details`, Text, Optional): Enter a brief description of the shipment being returned.
* **Recipient Details** (`Recipient Details`, Text, Optional): Provide information about the recipient, including their name, address, and contact details.
* **Shipping Method** (`Shipping Method`, Select One, Optional): Choose from one of the available shipping options (shipping 1, shipping 2, or shipping 3). 
* **Reason for Return** (`Reason for Return`, Text, Optional): Describe the reason for returning the shipment, including any relevant details or explanations.
* **Date Shipped** (`Date Shipped`, Date, Optional): Enter the date the shipment was originally shipped.
* **Shipment Weight** (`Shipment Weight`, Number, Optional): Enter the weight of the shipment in the required unit (e.g., pounds, kilograms).
* **Shipment Status** (`Shipment Status`, Select One, Optional): Choose from among "shipped", "received", or "pending" to indicate the current status of the shipment.
* **Shipment Notes** (`Shipment Notes`, Text, Optional): Add any additional notes or comments about the shipment.
* **Shipment ID** (`Shipment ID`, Text, Optional): Enter a unique identifier for the shipment.
* **Shipment Type** (`Shipment Type`, Text, Optional): Describe the type of shipment being returned (e.g., product, package, etc.).

## Tips

* Ensure all fields are accurate and up-to-date.
* If unsure about any field, refer back to this help guide for clarification.
* Review and submit the form carefully before finalizing it.
