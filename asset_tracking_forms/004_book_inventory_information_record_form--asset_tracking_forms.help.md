# Book Inventory Information Record Form - Help Guide

## Purpose
The purpose of this form is to provide a comprehensive record of book inventory information for library management and decision-making purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Ensure you have all the necessary information about the book at hand.
2.  Search for an existing record in the system to prevent duplicate records.
3.  Fill out the form with the following information:

### Field-by-Field Explanation

*   **Record Date** (`record_date`): Date of this inventory record.
    Please enter the date in the format `YYYY-MM-DD`.
*   **Library Location** (`library_location`): Which library branch or location.
    Enter the full name or abbreviation of the library branch or location.
*   **Book Title** (`book_title`): Full title of the book.
    Enter the title of the book, including subtitle and author name.
*   **Author Name** (`author_name`): Author or authors of the book.
    Enter the name of the author or authors of the book.
*   **ISBN Number** (`isbn_number`): ISBN-10 or ISBN-13.
    If available, enter the ISBN number of the book.
*   **Library Call Number** (`call_number`): Dewey Decimal or Library of Congress number.
    Enter the call number of the book, including any necessary prefixes.
*   **Total Copies in Inventory** (`total_copies`): How many copies do we have.
    Enter the total number of copies in the inventory.
*   **Currently Available Copies** (`available_copies`): How many are available for checkout.
    Enter the number of copies currently available for checkout.
*   **Checked Out Copies** (`checked_out_copies`): How many are currently borrowed.
    Enter the number of copies currently borrowed.
*   **Publication Year** (`publication_year`): Year the book was published.
    If available, enter the year the book was published.
*   **Edition Information** (`edition_info`): Edition number or year.
    If available, enter the edition number or year of the book.
*   **Average Condition of Copies** (`book_condition`): Overall condition of the inventory.
    Choose the average condition of the copies in the inventory.
*   **Unit Acquisition Cost** (`acquisition_cost`): Cost per copy when acquired.
    If available, enter the cost per copy when acquired.
*   **Last Updated By** (`last_updated`): Name of staff member who updated this record.
    Enter the name of the staff member who updated this record.
*   **Additional Notes** (`inventory_notes`): Any special notes about this inventory.
    Enter any special notes or comments about the book in the inventory.

## Tips
- Ensure all fields are accurate and up-to-date.
- If a book is not found in the system, search for it before creating a new record.
- If the book is found, update the existing record instead of creating a new one.
- Use the same format for date fields (YYYY-MM-DD).
- Use the same format for number fields (e.g., 123).
