# Financial Management Waiver Form Template - Help Guide
## Purpose
The Financial Management Waiver Form Template is a document used to record and track financial waivers. It is used to collect information about the user, waiver details, and other relevant data.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the User Name field with the name of the user requesting the waiver.
2. Next, select the Waiver Type by choosing from the available options (Active or Inactive).
3. If applicable, provide a Reason for Waiver in the text field.
4. Enter the Waiver Period in the number field.
5. Enter the Waiver Duration in the number field (optional).
6. Fill out the User Contact Information text field with the user's contact information.
7. Enter the Waiver Date using the date picker.
8. Enter the Waiver Expiration Date using the date picker.
9. Enter the Waiver Renewal Date using the date picker.
10. Finally, read and agree to the User Agreement, which is a standard waiver template.

## Field-by-Field Explanation

* **User Waiver**: This field is a text field where you can enter a brief description of the user's waiver request.
* **Financial Management Waiver Details**: This field is a text area where you can provide more detailed information about the waiver request, if necessary.
* **User Name**: Enter the name of the user requesting the waiver.
* **Waiver Type**: Select the type of waiver being requested (Active or Inactive).
* **Reason for Waiver**: If necessary, enter a brief description of the reason for the waiver.
* **Waiver Terms**: This field is a text area where you can provide any additional terms or conditions related to the waiver.
* **User Input 7**: This field is reserved for any additional user input that may be required for the waiver request.
* **Waiver Period**: Enter the period for which the waiver is being requested.
* **Waiver Duration**: Enter the duration of the waiver (optional).
* **User Contact Information**: Enter the user's contact information, such as phone number or email.
* **Waiver Date**: Enter the date on which the waiver was granted or is effective.
* **Waiver Expiration Date**: Enter the date on which the waiver will expire.
* **Waiver Renewal Date**: Enter the date on which the waiver will be renewed (if applicable).
* **User Agreement**: This field is a standard waiver template that the user must agree to before submitting the form.
