# Resource Management Waiver Form Template - Help Guide

## Purpose
This form is used to manage the waiver process for resource usage, ensuring that resources are used responsibly and within agreed-upon terms.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Acknowledge the risks associated with resource usage.
2.  Select the usage rules that apply to the resource.
3.  Enter the resource access information.
4.  Specify the resource usage terms.
5.  Enter the resource return information.
6.  Select the user acknowledgment for the resource usage.
7.  Indicate the resource owner status.
8.  Enter the resource name.
9.  Enter a brief description of the resource.
10. Enter the resource identifier.
11. Enter the resource version.
12. Select the resource status.
13. Enter the resource location.
14. Select the resource location type.
15. Enter the resource location details.
16. Enter the resource owner's email address.
17. Enter the resource phone number.
18. Add any additional comments about the resource.
19. Enter the waiver expiration date.

## Field-by-Field Explanation

*   **Acknowledge Risks for Resource Usage**: Select "True" or "False" indicating whether you acknowledge the risks associated with resource usage.
*   **Usage Rules**: Select "True" or "False" indicating whether you agree to abide by the usage rules.
*   **Resource Access Information**: Enter details about who has access to the resource.
*   **Resource Usage Terms**: Enter the specific terms for resource usage, such as any specific conditions or restrictions.
*   **Resource Return Information**: Enter details about returning the resource after usage.
*   **User Acknowledgement**: Select "True" or "False" indicating whether you acknowledge the resource usage terms.
*   **Resource Owner Status**: Select "True" or "False" indicating whether the resource owner is aware of the usage.
*   **Resource Name**: Enter the name of the resource.
*   **Resource Description**: Enter a brief description of the resource.
*   **Resource Identifier**: Enter a unique identifier for the resource.
*   **Resource Version**: Enter the version number of the resource.
*   **Resource Status**: Select "Active" or "Inactive" indicating the resource status.
*   **Resource Location**: Enter the location of the resource.
*   **Resource Location Type**: Select "True" or "False" indicating the type of resource location.
*   **Resource Location Details**: Enter additional details about the resource location.
*   **Resource Owner Email**: Enter the email address of the resource owner.
*   **Resource Phone**: Enter the phone number of the resource owner.
*   **Resource Additional Comments**: Enter any additional comments or notes about the resource.
*   **Waiver Expiration Date**: Enter the date when the waiver expires.
