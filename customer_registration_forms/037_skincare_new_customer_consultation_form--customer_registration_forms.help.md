# Skincare New Customer Consultation Form - Help Guide
## Purpose
The Skincare New Customer Consultation Form is a tool used to gather information from new customers about their skincare needs and goals. This information will be used to provide personalized skincare recommendations and create an account for the customer.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Please fill out the form with your information, making sure to answer all required fields (denoted by an asterisk \*).
2. Make sure to select the correct options for each field based on your needs and goals.

## Field-by-Field Explanation
* **New Customer** (1, text, required: false): This field is a text box where you can enter your name or other identifying information.
* **Health Information** (2, text, required: false): This field is a text box where you can enter any relevant health information you feel is important for us to know.
* **Skin Details** (3, text, required: false): This field is a text box where you can describe your skin concerns or issues.
* **Skincare Goals** (4, select_one, required: false): This field is a dropdown menu where you can select one of the following options:
	+ goals
	+ Other (if you select this option, please type in your specific goals in the **Treatment Goals** field)
* **Availability** (5, date, required: false): This field is a date picker where you can select a date and time that works best for your skincare appointment.
* **Consent To Terms** (6, select_one, required: false): This field is a dropdown menu where you can select one of the following options:
	+ yes no (if you select this option, please make sure to read and understand our terms and conditions before proceeding)
* **Medical History** (7, text, required: false): This field is a text box where you can enter any medical history that may be relevant to your skincare needs.
* **Treatment Goals** (8, text, required: false): This field is a text box where you can enter your specific skincare goals or treatment objectives.
* **Medical Condition** (9, select_one, required: false): This field is a dropdown menu where you can select one of the following options:
	+ no (if you select this option, please make sure to provide more information in the **Medical Condition Details** field)
* **Skin Condition** (10, select_one, required: false): This field is a dropdown menu where you can select one of the following options:
	+ normal acne sensitive aging etc (if you select this option, please provide more information in the **Medical Condition Details** field)
* **Medical Condition Details** (11, text, required: false): This field is a text box where you can enter any additional information about your medical condition or skin concerns.

## Tips
- Please make sure to answer all required fields to ensure that we can provide you with accurate and effective skincare recommendations.
- If you have any questions or concerns about the form, please don't hesitate to contact us.
- Our skincare experts will review your information and contact you to discuss your skincare goals and needs.
