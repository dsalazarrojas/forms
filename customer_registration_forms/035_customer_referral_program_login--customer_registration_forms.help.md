# Customer Referral Program Login - Help Guide
## Purpose
The "Customer Referral Program Login" form is used to collect information about a customer's referral to the Referral Program. This form is required to be filled out by customers who wish to join or be referred to the program.

## How To Complete This Form
- Please fill out all the required fields, indicated by a red star (*).
- If a field is not required, you can leave it blank.
- Click the "Submit" button to save your changes.

## Field-by-Field Explanation
### Referral Code (customer_referral_program_login_referral_code)
* **Referral Code** (`customer_referral_program_login_referral_code`, text, optional): This field is for entering the referral code provided to you by your referrer. If you do not have a referral code, you can leave this field blank.

### Program Choice (customer_referral_program_login_program_choice)
* **Program Choice** (`customer_referral_program_login_program_choice`, select multiple, optional): Choose your program choice by selecting one or more options from the dropdown list. You can select multiple options by holding the Ctrl key while clicking on the desired options.

### First Name (customer_referral_program_login_first_name)
* **First Name** (`customer_referral_program_login_first_name`, text, optional): Please enter your first name here.

### Last Name (customer_referral_program_login_last_name)
* **Last Name** (`customer_referral_program_login_last_name`, text, optional): Please enter your last name here.

### Email (customer_referral_program_login_email)
* **Email** (`customer_referral_program_login_email`, email, optional): This is your email address where you will receive information and updates from the Referral Program. Please enter a valid email address.

### Phone (customer_referral_program_login_phone)
* **Phone** (`customer_referral_program_login_phone`, text, optional): Please enter your phone number here.

### Consent (customer_referral_program_login_consent)
* **Consent** (`customer_referral_program_login_consent`, select multiple, optional): Select "Yes" to agree to receive emails and updates from the Referral Program. Select "No" to decline.

### Agree (customer_referral_program_login_agree)
* **Agree** (`customer_referral_program_login_agree`, select multiple, optional): Select "Yes" to agree to the terms and conditions of the Referral Program. Select "No" to decline.

# Tips
- Please double-check that all the required fields are filled out.
- If you have any issues filling out the form, please contact the system administrator.
