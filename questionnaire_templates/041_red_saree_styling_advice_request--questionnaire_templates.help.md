# red_saree_styling_advice_request - Help Guide
## Purpose
This form is designed to collect information about a client's event styling preferences and recommendations from a stylist.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your First Name and Last Name in the respective fields.
2. Enter your email address to ensure we can contact you for any further information.
3. If you have a specific Event Date, please enter it in the format MM/DD/YYYY.
4. If you have a preferred Event Time, please enter it in the format 12:00 AM.
5. Please provide your Style Preferences in a few sentences or bullet points.
6. If you have any additional Event Details, feel free to include them in the text box.
7. If you have any Stylist Recommendations, please provide them in a few sentences or bullet points.

## Field-by-Field Explanation

* **First Name** (`first_name`, `text`, **Required**): Please enter your first name as it appears on your official documents.
* **Last Name** (`last_name`, `text`, **Required**): Please enter your last name as it appears on your official documents.
* **Email** (`email`, `email`, **Required**): Please enter your email address so we can contact you for further information.
* **Event Date** (`event_date`, `date`, **Optional**): If you have a specific event date, please enter it in the format MM/DD/YYYY.
* **Event Time** (`event_time`, `time`, **Optional**): If you have a preferred event time, please enter it in the format 12:00 AM.
* **Style Preferences** (`style_preferences`, `text`, **Optional**): Please provide your preferred style or any specific style-related requests.
* **Event Details** (`event_details`, `text`, **Optional**): If you have any additional event details, please include them in this text box.
* **Stylist Recommendations** (`stylist_recommendations`, `text`, **Optional**): If you have any recommendations for our stylists, please provide them in this text box.

## Tips

* Please double-check that you have entered your information correctly before submitting the form.
* If you have any questions or concerns, please contact us at form@gic.mx.
