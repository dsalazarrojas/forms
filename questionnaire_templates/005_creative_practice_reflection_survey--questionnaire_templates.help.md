# Creative Practice Reflection Survey - Help Guide
## Purpose
The purpose of this form is to collect information about projects, their status, duration, location, collaborators, and other relevant details for reflection and analysis.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by filling in your artist name and project name.
2. Provide a brief overview of the project, including project details, goals and objectives, outcomes, and any other relevant information.
3. Select the correct project status from the options provided.
4. Choose the project type and project duration.
5. Select the project location and any collaborators involved.
6. If applicable, provide dates for project start and end times.
7. Optionally, provide any feedback or recommendations for the project.
8. Finally, select the project status update type and provide any location update information.

## Field-by-Field Explanation

- **Artist Name** (`artist_name`, text, required): Please enter your name as the artist or project manager.
- **Project Name** (`project_name`, text, required): Enter a brief description or title of the project.
- **Project Details** (`project_details`, text, optional): Provide any additional project information or context.
- **Goals and Objectives** (`goals_objectives`, text, optional): Describe the project's goals and objectives.
- **Outcomes** (`outcomes`, text, optional): Report any notable outcomes or results from the project.
- **Process** (`process`, text, optional): Share any insights or observations about the project process.
- **Reflections** (`reflections`, text, optional): Write any reflections or lessons learned from the project.
- **Feedback** (`feedback`, text, optional): Provide any feedback or suggestions for future projects.
- **Recommendations** (`recommendations`, text, optional): Offer any recommendations for future projects or improvements.
- **Project Status** (`project_status`, select_one, required): Select the current status of the project (active, inactive, or pending).
- **Project Type** (`project_type`, select_multiple, required): Choose the type of project (art, educational, or commercial).
- **Project Duration** (`project_duration`, select_one, optional): Select the project duration (short, medium, or long).
- **Project Location** (`project_location`, select_multiple, optional): Choose the location where the project is taking place (local or remote).
- **Collaborators** (`collaborators`, select_multiple, optional): Select any collaborators involved in the project (team, individual, or external).
- **Project Start Date** (`project_start_date`, date, optional): Provide the date when the project started.
- **Project End Date** (`project_end_date`, date, optional): Provide the date when the project ended.
- **Project Status Update** (`project_status_update`, text, optional): Provide any updates on the project status.
- **Project Status Update Type** (`project_status_update_type`, select_one, optional): Select the type of project status update (weekly, monthly, or quarterly).
- **Project Frequency** (`project_frequency`, select_one, optional): Select how often the project occurs (once, multiple, or irregular).
- **Project Frequency Interval** (`project_frequency_interval`, text, optional): Provide any additional frequency details if applicable.
- **Project Location Update** (`project_location_update`, select_multiple, optional): Choose if the project location has changed.
- **Project Start Time** (`project_start_time`, time, optional): Provide the time when the project started.
- **Project End Time** (`project_end_time`, time, optional): Provide the time when the project ended.
- **Project Comments** (`project_comments`, text, optional): Share any comments or notes about the project.

## Tips
When filling out this form, please be as concise and detailed as possible. If you're unsure about any field, feel free to ask for clarification.
