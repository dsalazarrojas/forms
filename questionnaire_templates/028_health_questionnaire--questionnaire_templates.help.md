# Health Questionnaire - Help Guide
## Purpose
This form is designed to collect medical information from patients or individuals for administrative purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Please review the form carefully and answer all required questions.
2. For each question, select the corresponding answer based on your medical history.
3. If you are unsure about any question, please contact your healthcare provider for guidance.
4. Please note that some fields are optional, but please complete all required fields.
5. Once you have completed the form, please review it carefully for accuracy before submitting.

## Field-by-Field Explanation

* **Medical History** (`1`, `text`, required: false): This is a text field where you can provide a brief description of your medical history.
* **Allergies** (`2`, `select_multiple`, required: false): This field allows you to list any allergies you may have. Please select "Yes" if you have an allergy, and "No" if you do not.
* **Medications** (`3`, `select_multiple`, required: false): This field asks about any medications you are currently taking. Please select "Yes" if you are taking medications, and "No" if you are not.
* **Medical Procedure** (`4`, `note`, required: false): This is a text field where you can provide more information about any medical procedures you have undergone.
* **Medical Condition** (`5`, `select_one`, required: false): This field asks about any existing medical conditions. Please select "Yes" if you have a medical condition, and "No" if you do not.
* **Medical Test** (`6`, `select_multiple`, required: false): This field asks about any medical tests or procedures you have undergone. Please select "Yes" if you have had a test, and "No" if you have not.
* **Health Insurance** (`7`, `select_one`, required: false): This field asks about your health insurance status. Please select "Yes" if you have health insurance, and "No" if you do not.
* **Emergency Contact** (`8`, `select_multiple`, required: false): This field asks for any emergency contacts. Please list any emergency contacts you have.
* **Medical Procedure 2** (`9`, `note`, required: false): This is a text field where you can provide more information about any additional medical procedures you have undergone.
* **Medical Test 2** (`10`, `select_multiple`, required: false): This field asks about any additional medical tests or procedures you have undergone. Please select "Yes" if you have had a test, and "No" if you have not.
