# Web Design Questionnaire - Help Guide
## Purpose
The purpose of this questionnaire is to collect information about individuals' preferences and habits related to web design.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review each page of the questionnaire carefully.
2. Answer each question truthfully to the best of your ability.
3. Make sure to fill out all required fields.

## Field-by-Field Explanation

* **Submitter Contact Details** (`submitter_contact_details`, text, required: false):
	+ This field is where you can enter your contact information, such as your name and email address.
* **Background Information** (`background_information`, text, required: false):
	+ In this field, please describe a bit about yourself and your background.
* **Brand Identity** (`brand_identity`, text, required: false):
	+ Please provide a brief description about your brand or company.
* **Design Preferences** (`design_preferences`, select_one, required: false):
	+ Choose from the options 'Yes' or 'No' for the following design preference questions. 
* **Content Management Details** (`content_management_details`, text, required: false):
	+ Provide details about how you manage content on your website.
* **Website Features and Links** (`website_features_and_links`, select_multiple, required: false):
	+ Select all the features that apply to your website. 
* **Supporting Content** (`supporting_content`, note, required: false):
	+ Please provide any supporting content that you would like to add.
* **Submitter Background** (`submitter_background`, number, required: false):
	+ Please note your background information, this can be your work experience and any other relevant information.
* **Submitter Education** (`submitter_education`, text, required: false):
	+ Provide your educational background. 

## Tips

* Make sure to fill out all required fields.
* If you are unsure about any question, please ask for clarification.
* If you need help with submitting the form, please contact the form administrators.
