# Employee Communication Tools Satisfaction Questionnaire - Help Guide
## Purpose
This form is designed to collect feedback from employees on the communication tools used in the organization. It helps identify areas of satisfaction and areas for improvement for employee communication tools.

## How To Complete This Form
1. Please review the form carefully and answer the questions honestly.
2. Select the category that best fits the purpose of the form.
3. Choose the tools that you have used for communication in the current period.
4. Rate your satisfaction with the selected tools using the scale provided.
5. If necessary, add any additional comments or feedback.

## Field-by-Field Explanation
* **Employee Communication Tools Satisfaction Questionnaire Page 1** (`employee_communication_tools_satisfaction_questionnaire_page_1`): This page is a text field where you can provide any additional information or comments about the communication tools used.
* **Category** (`employee_communication_tools_satisfaction_questionnaire_category`): Select the category that best describes the purpose of this form.
	+ **Category 1**: This category is for general feedback on employee communication tools.
	+ **Category 2**: This category is for specific feedback on a particular tool.
	+ **Category 3**: This category is for suggestions on new tools or improvements.
* **Description** (`employee_communication_tools_satisfaction_questionnaire_description`): Provide a brief description of your experience with the communication tools used.
* **Tools Used** (`employee_communication_tools_satisfaction_questionnaire_tools_used`): Select all the tools you have used for communication in the current period. This could include email, phone, or video conferencing tools.
* **Satisfaction** (`employee_communication_tools_satisfaction_questionnaire_satisfaction`): Rate your satisfaction with the selected tools using the number scale provided.
* **Comments** (`employee_communication_tools_satisfaction_questionnaire_comments`): Provide any additional comments or feedback on the communication tools used.
* **Additional Comments** (`employee_communication_tools_satisfaction_questionnaire_additional_comments`): If you have any further comments or feedback that don't fit in the above fields, provide them here.

## Tips
* Be honest and thorough in your feedback.
* Select all relevant categories and tools used.
* Provide specific examples or instances where you've used the tools.
* If unsure, ask for clarification from the form creator or supervisor.
