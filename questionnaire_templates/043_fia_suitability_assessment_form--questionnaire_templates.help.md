FIA Suitability Assessment Form - Help Guide
=====================================

### Purpose

The FIA Suitability Assessment Form is used to gather information about a client's goals, risk tolerance, and investment preferences. This form helps determine if a fixed index annuity is suitable for a client's investment goals and financial needs. The information collected will help identify potential matches with annuity products that align with the client's requirements.

### How to Complete This Form

1.  Review each section carefully and enter your honest answers to the best of your ability.
2.  If you have any questions or concerns, don't hesitate to reach out to your financial advisor.
3.  Ensure that all required fields are filled out accurately and truthfully.

### Field-by-Field Explanation

- **Client Goals** (`Client Goals`, `text`, required: false)
    Enter a brief description of the client's financial goals, such as income, tax savings, or retirement planning.

- **Risk Tolerance** (`Risk Tolerance`, `number`, required: false)
    Select a number between 1-100 to indicate the client's risk tolerance level. A higher number indicates a higher risk tolerance.

- **Time Horizon** (`Time Horizon`, `text`, required: false)
    Enter the time frame over which the client is willing to invest, such as short-term or long-term.

- **Fixed Index Annuity Investment Options** (`Fixed Index Annuity Investment Options`, `select_one`, required: false)
    Select "Yes" if the client is interested in fixed index annuity investment options.

- **Risk Free Rate** (`Risk Free Rate`, `number`, required: false)
    Enter the client's risk-free rate, which indicates the rate of return without risk.

- **Investment Return Assumptions** (`Investment Return Assumptions`, `select_multiple`, required: false)
    Select all applicable investment return assumptions, such as "Yes" for guaranteed minimum income or "No" for variable returns.

- **Investment Return Period** (`Investment Return Period`, `time`, required: false)
    Enter the period over which the client expects to receive returns.

- **Inflation Rate** (`Inflation Rate`, `number`, required: false)
    Enter the client's expected inflation rate.

- **Investment Return Rate** (`Investment Return Rate`, `number`, required: false)
    Enter the client's expected investment return rate.

- **Tax Impact** (`Tax Impact`, `select_one`, required: false)
    Select "Yes" if the client is concerned about tax impact.

- **Fixed Index Annuity Fees** (`Fixed Index Annuity Fees`, `number`, required: false)
    Enter the client's expected annuity fees.

- **Risk Tolerance Level** (`Risk Tolerance Level`, `select_multiple`, required: false)
    Select "High" or "Low" risk tolerance level.

- **Fixed Index Annuity Investment Minimums** (`Fixed Index Annuity Investment Minimums`, `number`, required: false)
    Enter the minimum investment amount for the fixed index annuity.

- **Fixed Index Annuity Investment Maximums** (`Fixed Index Annuity Investment Maximums`, `number`, required: false)
    Enter the maximum investment amount for the fixed index annuity.

- **Investment Return Frequency** (`Investment Return Frequency`, `select_one`, required: false)
    Select "Yes" if the client expects investment return.

- **Fixed Index Annuity Liquidity** (`Fixed Index Annuity Liquidity`, `select_one`, required: false)
    Select "Yes" if the client prefers annuities with liquidity.

- **Tax Free Rate** (`Tax Free Rate`, `select_one`, required: false)
    Select "Good", "Fair", or "Poor" tax-free rate.

- **Fixed Index Annuity Benefits** (`Fixed Index Annuity Benefits`, `select_multiple`, required: false)
    Select "Yes" for fixed index annuity benefits.

- **Fixed Index Annuity Riders** (`Fixed Index Annuity Riders`, `select_multiple`, required: false)
    Select all applicable fixed index annuity riders.

- **Annuity Fees** (`Annuity Fees`, `number`, required: false)
    Enter the annuity fees.

- **Fixed Index Annuity Annuity Surrender Charges** (`Fixed Index Annuity Annuity Surrender Charges`, `number`, required: false)
    Enter the annuity surrender charges.

- **Fixed Index Annuity Annuity Exercise Frequency** (`Fixed Index Annuity Annuity Exercise Frequency`, `select_one`, required: false)
    Select "Yes" if the client exercises annuity frequency.

- **Fixed Index Annuity Annuity Exercise Window** (`Fixed Index Annuity Annuity Exercise Window`, `select_one`, required: false)
    Select "Yes" if the client has exercise window.

- **Fixed Index Annuity Annuity Exercise Window Start Date** (`Fixed Index Annuity Annuity Exercise Window Start Date`, `date`, required: false)
    Enter the exercise window start date.

- **Fixed Index Annuity Annuity Exercise Window End Date** (`Fixed Index Annuity Annuity Exercise Window End Date`, `date`, required: false)
    Enter the exercise window end date.
