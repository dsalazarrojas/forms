# Job Opportunity Questionnaire - Help Guide
## Purpose
The Job Opportunity Questionnaire is designed to help users showcase their job opportunities and increase their chances of being considered for a position.

## How To Complete This Form
1. Start by reviewing the form carefully and answering all the questions accurately.
2. Fill out each section with the requested information.
3. Make sure to provide detailed information in the job description and other job-related fields.
4. If you are unsure about any question, please ask for clarification before proceeding.
5. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **Introduction** (Page 1): A brief introduction to the job opportunity.
	+ This is a required field.
* **Job Title** (Page 2):
	+ Enter a brief title of the job opportunity.
	+ This is a required field.
* **Job Description** (Page 3):
	+ Provide a detailed description of the job opportunity, including job responsibilities, requirements, and qualifications.
	+ This is a required field.
* **Contact Information** (Page 4):
	+ Enter your contact information, including your name, email, and phone number.
	+ This is an optional field.
* **Resume** (Page 5):
	+ Attach your resume to provide additional information about your qualifications.
	+ This is an optional field.
* **Role Preferences** (Page 6):
	+ Select the roles you are interested in, such as part-time or full-time.
	+ This is an optional field.
* **Other Role** (Page 7):
	+ If you don't see a specific role listed, describe your interest in other roles.
	+ This is an optional field.
* **Role 1** (Page 8):
	+ Select your primary role interest.
	+ This is an optional field.
* **Other Preference** (Page 9):
	+ Enter any additional information about your preferences.
	+ This is an optional field.
* **Resume Upload** (Page 10):
	+ Upload your resume to provide additional information.
	+ This is an optional field.
* **Resume Link** (Page 11):
	+ Enter a link to your resume online.
	+ This is an optional field.
* **Role 1** (Page 12):
	+ Select your other primary role interest.
	+ This is an optional field.
* **Job Description** (Page 13):
	+ Enter the job description.
	+ This is an optional field.
* **Job Time** (Page 14):
	+ Enter the job time.
	+ This is an optional field.
* **Job Date** (Page 15):
	+ Enter the job date.
	+ This is an optional field.
* **Other Information** (Page 16):
	+ Enter any other information about the job.
	+ This is an optional field.
* **Job Salary** (Page 17):
	+ Enter the job salary.
	+ This is an optional field.
* **Job Location** (Page 18):
	+ Enter the job location.
	+ This is an optional field.
* **Job Type** (Page 19):
	+ Select the job type.
	+ This is an optional field.
* **Other Information 2** (Page 20):
	+ Enter any other information about the job.
	+ This is an optional field.
* **Job Status** (Page 21):
	+ Select the job status.
	+ This is an optional field.

## Tips

* Double-check your answers before submitting the form.
* Ensure that all required fields are filled out accurately.
* If you have any questions or concerns, please contact us.
