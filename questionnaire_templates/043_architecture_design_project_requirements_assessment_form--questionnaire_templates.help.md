# Architecture Design Project Requirements Assessment Form - Help Guide
## Purpose
This form is designed to collect essential information about a client's architecture design project requirements, including client information, project overview, project details, and project requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your client's information in the "Client Information" section, including their name, email address, and phone number.
2. Provide a brief description of the project in the "Project Overview" section.
3. Enter the project's details, such as its name, description, location, type, and budget range.
4. List the primary project objectives in the "Primary Project Objectives" section.
5. If applicable, select the relevant key requirements for the project, such as sustainability and accessibility.
6. Assess the priority level of the project's aesthetic, functionality, cost, and timeline.
7. Estimate the site and building areas, if applicable.
8. Add any additional notes or questions in the "Additional Notes or Questions" section.

## Field-by-Field Explanation
- **Client Name** (`client_name`, text, required): Enter the client's name.
- **Email Address** (`client_email`, email, required): Enter the client's email address.
- **Phone Number** (`client_phone`, text, required): Enter the client's phone number.
- **Company or Organization** (`client_company`, text, optional): If the client is a company or organization, enter its name.
- **Project Name** (`project_name`, text, required): Enter the project's name.
- **Project Description** (`project_description`, text, required): Provide a brief description of the project.
- **Project Type** (`project_type`, select_one, required): Select the project type from the given options (e.g., New building, renovation, etc.).
- **Project Location** (`project_location`, text, required): Enter the project's location.
- **Primary Project Objectives** (`primary_objectives`, text, required): List the primary project objectives.
- **Budget Range** (`budget_range`, number, optional): Estimate the project budget range.
- **Project Timeline** (`timeline`, text, optional): Provide the desired start and completion dates.
- **Key Requirements** (`key_requirements`, select_multiple, optional): Select all applicable key requirements for the project.
- **Aesthetic Design Priority** (`aesthetic_priority`, number, optional): Assess the priority level of the project's aesthetic design (1-5).
- **Functionality Priority** (`functionality_priority`, number, optional): Assess the priority level of the project's functionality (1-5).
- **Cost Efficiency Priority** (`cost_priority`, number, optional): Assess the priority level of the project's cost efficiency (1-5).
- **Timeline Priority** (`timeline_priority`, number, optional): Assess the priority level of the project's timeline (1-5).
- **Site Area** (`site_area`, number, optional): Estimate the site area.
- **Building Area** (`building_area`, number, optional): Estimate the building area.
- **Additional Notes or Questions** (`additional_notes`, text, optional): Add any additional notes or questions about the project.

## Tips
- Ensure you answer all required fields to provide sufficient information for the architect or designer to begin work on the project.
- Use the provided options for select fields to avoid errors.
- If unsure about any field, please consult the project manager or contact the relevant department.
- You can add any additional information or questions in the "Additional Notes or Questions" section.
