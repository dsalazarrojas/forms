# Pre Work Strategy Planning Survey - Help Guide

## Purpose
This form is designed to collect essential information from team members for the Pre-Work Strategy Planning Survey. This survey aims to gather crucial details about project planning, team readiness, risks, and communication preferences. Your input will help us better understand your needs and preferences to provide a more effective and efficient work strategy. Please ensure you answer the questions accurately and completely, as your responses will help shape the project's scope and timeline.

## How To Complete This Form

To complete this form, follow these steps:

1. Ensure you have all the necessary information ready before starting.
2. Read each question carefully and provide detailed answers.
3. If a field is marked as required, it is essential that you answer it correctly.
4. Use the available options or select "N/A" if you don't have an answer to a specific question.

## Field-by-Field Explanation

* **Team Member**: This question helps us understand if you will be part of the project team. Please select either "Yes" or "No".
* **Project Title**: This is a free text field where you can provide the title of the project.
* **Readiness**: Please provide a numerical value between 1 and 100, where 1 indicates lowest readiness and 100 highest readiness to start the project.
* **Risks**: Indicate which risks you are aware of regarding the project. Please select either "Yes" or "No".
* **Communication Preferences**: You can provide any additional comments or notes about your communication preferences.
* **Review Frequency**: Please select when you would like to review the project progress. You can choose from the available options.
* **Project Kickoff Date**: Provide the date when the project is expected to kickoff.
* **Project Manager**: This is a text field where you can provide the name or email of the project manager.
* **Team Members**: Indicate which team members will be involved in the project. Please select either "Yes" or "No".
* **Review Location**: Please select where you would like to review the project. You can choose from the available options.
* **Notes**: This is a free text field where you can provide any additional information or comments.
* **Risk Rationale**: You can provide a brief description of the risks you are aware of.
* **Risk Impact**: Please provide a numerical value indicating the impact of the risk (e.g., 1-100).
* **Risk Probability**: Please provide a numerical value indicating the probability of the risk (e.g., 1-100).
* **Risk Frequency**: Please provide a numerical value indicating the frequency of the risk (e.g., 1-100).
* **Risk Impact, Probability, and Frequency**: Please provide a date in the format YYYY-MM-DD for the risk impact, probability, and frequency.
* **Project Description**: This is a free text field where you can provide a brief description of the project.
* **Project Status**: Please select the current status of the project from the available options.
* **Project Manager Email**: Provide the email address of the project manager.
* **Team Members Email**: Provide a list of email addresses of the team members involved.
* **Review Date**: Provide the date when you would like to review the project progress.
* **Project Kickoff Time**: Please provide the time when the project is expected to kickoff.
* **Project Kickoff Location**: Provide the location where the project is expected to kickoff.
* **Project Budget**: Please provide the budget allocated for the project.
* **Team Members**: Indicate which team members are involved in the project. Please select either "Yes" or "No".
