# Early Childhood Behavior Questionnaire - Help Guide
## Purpose
The Early Childhood Behavior Questionnaire is a tool designed to assess the behavior and development of children in early childhood. It focuses on the frequency of various behaviors, including adaptive and self-help development, self-maintenance, and adaptive development.

## How To Complete This Form

1. The form is divided into several sections, each representing a different aspect of early childhood development.
2. For each section, select the answer that best describes the frequency of the behavior in question.
3. Make sure to answer all required questions, as they are essential for a comprehensive assessment.
4. Review your answers carefully, as they will be used to identify potential areas of concern or strengths.

## Field-by-Field Explanation

* **Adaptive Development**: This section assesses the frequency of behaviors that help children adapt to new situations and challenges. Select the answer that best describes how often you have observed the child exhibiting these behaviors:
	+ Rarely
	+ Never
	+ Occasionally
	+ Very Often
* **Self-Help Development**: This section evaluates the frequency of behaviors that promote self-sufficiency and independence in children. Select the answer that best describes how often you have observed the child exhibiting these behaviors:
	+ Rarely
	+ Never
	+ Occasionally
	+ Very Often
* **Self-Maintenance Development**: This section assesses the frequency of behaviors that promote self-care and self-sufficiency in children. Select the answer that best describes how often you have observed the child exhibiting these behaviors:
	+ Rarely
	+ Never
	+ Occasionally
	+ Very Often
* **Self-Maintenance Development 1**: This section is similar to self-maintenance development, but with a different set of questions. Select the answer that best describes how often you have observed the child exhibiting these behaviors:
	+ Rarely
	+ Never
	+ Occasionally
	+ Very Often
* **Adaptive Development 1 2**: This section assesses the frequency of behaviors that promote adaptive development, similar to the first adaptive development section. Select the answer that best describes how often you have observed the child exhibiting these behaviors:
	+ Rarely
	+ Never
	+ Occasionally
	+ Very Often
* **Self-Maintenance**: This section is a free-text question that allows you to describe any behaviors or habits that promote self-maintenance in the child. Please provide a brief description of the behaviors or habits you have observed:
	+ Type your answer in the text field and provide as much detail as possible.

## Tips
* Make sure to answer all questions truthfully and to the best of your knowledge.
* If you are unsure about any question, please consult with the child's parent or caregiver for clarification.
* If you have any questions or concerns about the form, please contact us at form@gic.mx.
