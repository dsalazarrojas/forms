# Royalty Accounting Pre Engagement Survey - Help Guide
## Purpose
The Royalty Accounting Pre Engagement Survey is designed to help accounting firms collect and manage information about their engagements with clients. It's an essential tool for ensuring accurate and up-to-date data about current and upcoming engagements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Company Name" field with the name of the firm or entity you're representing.
2. Provide your contact information, including your name, email, phone number, and address.
3. Select the "Accounting Firm Name" and "Client Type" (individual or company).
4. Enter the dates of the current engagement.
5. Describe the "Royalty Process" being used, if applicable.
6. Choose the "Engagement Type" (audit or review).
7. Select the "Engagement Status" (pending, in progress, or completed).
8. Choose the "Current Engagement Status" (none, ongoing, or completed).
9. If applicable, select the "Next Engagement Start Date" and "Next Engagement End Date".
10. Add any additional "Notes" about the engagement.
11. If applicable, provide information about the accounting system used, including the URL, username, password, IP address, and notes.

## Field-by-Field Explanation

* **Company Name** (1): Enter the name of the firm or entity you're representing.
* **Contact Person** (2): Provide your name and contact information.
* **Company Address** (3): Enter the address of the firm or entity.
* **Contact Email** (4): Enter your email address.
* **Contact Phone** (5): Enter your phone number.
* **Accounting Firm Name** (6): Select the name of the accounting firm.
* **Engagement Start Date** (7): Enter the start date of the current engagement.
* **Engagement End Date** (8): Enter the end date of the current engagement.
* **Royalty Process Description** (9): Describe the royalty process being used, if applicable.
* **Royalty Process Level** (10): Choose the level of royalty process used (Level 1, Level 2, or Level 3).
* **Client Type** (11): Select whether the client is an individual or a company.
* **Engagement Type** (12): Choose whether the engagement is an audit or a review.
* **Engagement Status** (13): Select the status of the engagement (pending, in progress, or completed).
* **Current Engagement Status** (14): Select the current status of the engagement (none, ongoing, or completed).
* **Next Engagement Start Date** (15): Enter the start date of the next engagement, if applicable.
* **Next Engagement End Date** (16): Enter the end date of the next engagement, if applicable.
* **Notes** (17): Add any additional notes about the engagement.
* **Accounting System Used** (18): Select whether the accounting system is used (true or false).
* **Accounting System Version** (19): Enter the version of the accounting system used, if applicable.
* **System Username** (20): Enter the username for the accounting system.
* **System Password** (21): Enter the password for the accounting system.
* **System IP Address** (22): Enter the IP address of the accounting system.
* **System URL** (23): Enter the URL of the accounting system.
* **System Port** (24): Enter the port number of the accounting system.
* **System Notes** (25): Add any additional notes about the accounting system, if applicable.
