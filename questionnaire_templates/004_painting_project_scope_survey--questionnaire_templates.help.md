# Painting Project Scope Survey - Help Guide
## Purpose
This form is designed to gather information about painting projects, including project details, scope, and timeline.

## How To Complete This Form

1. Please fill out each field carefully, following the instructions provided for each section.
2. Make sure to enter all required fields, marked as **required**.

## Field-by-Field Explanation

* **Project Name (Required)** (`project_name`, text, required): Enter the name of the painting project you're working on.
* **Contractor (Required)** (`contractor`, text, required): Provide the name of the company or individual responsible for the project.
* **Address** (`address`, text, optional): If relevant, enter the address related to the project (e.g., building location).
* **Scope of Work (Required)** (`scope_of_work`, text, required): Describe the scope of the painting project, including any specific tasks or tasks involved.
* **Start Date** (`start_date`, date, optional): Enter the expected start date of the project.
* **End Date** (`end_date`, date, optional): Enter the expected end date of the project.
* **Contact Name** (`contact_name`, text, optional): Enter the name of the contact person responsible for the project.
* **Contact Email** (`contact_email`, email, optional): Enter the email address of the contact person responsible for the project.
* **Contact Phone** (`contact_phone`, text, optional): Enter the phone number of the contact person responsible for the project.
* **Project Manager** (`project_manager`, text, optional): Enter the name of the project manager.
* **Architect** (`architect`, text, optional): Enter the name of the architect.
* **Structural Engineer** (`structural_engineer`, text, optional): Enter the name of the structural engineer.
* **Electrical Engineer** (`electrical_engineer`, text, optional): Enter the name of the electrical engineer.
* **Mechanical Engineer** (`mechanical_engineer`, text, optional): Enter the name of the mechanical engineer.
* **Plumbing** (`plumbing`, text, optional): Enter the name related to plumbing.
* **Painting Type** (`painting_type`, text, optional): Enter the type of painting project (e.g., interior, exterior).
* **Painting Area** (`painting_area`, text, optional): Enter the specific area or location for painting (e.g., building, room).
* **Painting Surface** (`painting_surface`, text, optional): Enter the surface type or material related to the painting project (e.g., wood, metal).
* **Color Scheme** (`color_scheme`, text, optional): Describe the color scheme or color palette for the project.
* **Color Type** (`color_type`, text, optional): Enter the color type or finish (e.g., gloss, matte).
* **Color Number** (`color_number`, text, optional): Enter the specific color number or code.
* **Additional Work** (`additional_work`, text, optional): If applicable, describe any additional work or services required.
* **Equipment** (`equipment`, text, optional): Enter any necessary equipment or materials.
* **Safety Equipment** (`safety_equipment`, text, optional): Enter any safety equipment needed.
* **Comments** (`comments`, note, optional): If you have any further comments or notes about the project, please enter them here.

**Tips:**

* Double-check your entries for accuracy and completeness before submitting the form.
* If you're unsure about any field, please reach out to your project manager or team lead for guidance.
* This form will help us better understand your project's requirements and scope, ensuring we can provide you with the best support and resources possible.
