# Water Design Discovery Survey - Help Guide
## Purpose
The Water Design Discovery Survey is a form designed to gather information about a residential water design project. This form is intended to help the designer understand the project's requirements, preferences, and constraints.

## How To Complete This Form
To complete this form, please select the relevant options for each field. Most fields are optional, but please fill in as much information as possible to help the designer create a comprehensive design.

## Field-by-Field Explanation

* **Residential Project**: Select the type of residential project you are designing for (e.g. Single Family Home, Apartment Complex, etc.).
* **Budget**: Enter the budget for the project.
* **Water Use**: Select how much water the project will use (Low, Medium, High).
* **Priority**: Select the priorities for the project (e.g. Planning, Design, Construction).
* **Project Location**: Select the location of the project.
* **Client Preferences**: Enter any specific preferences or requirements the client has for the project.
* **Project Status**: Select the current status of the project (Active, Inactive).
* **Stakeholders Involved**: Select who is involved in the project (Client, Architect, Engineer).
* **Water Sources**: Select the sources of water for the project (Groundwater, Well, Surface).
* **Treatment Systems**: Select any treatment systems the project will use (None, Treatment, Storage).
* **Distribution Systems**: Select any distribution systems the project will use (None, Distribution, Collection).
* **Water Quality**: Enter the expected water quality for the project.
* **Water Temperature**: Select the expected water temperature for the project (Cold, Warm, Hot).
* **Water Pressure**: Enter the expected water pressure for the project.
* **Water Flow**: Enter the expected water flow for the project.
* **Project Budget**: Enter the project budget.
* **Project Duration**: Enter the project duration.
* **Priority Benefits**: Select the benefits of prioritizing the project (Cost Savings, Sustainability, Water Availability).
* **Design Considerations**: Select any design considerations for the project (Water Conservation, Water Efficiency, Sustainability).
* **Project Phases**: Select the phases of the project (Planning, Design, Construction).
* **Project Location Details**: Enter any specific details about the project location.
* **Client Preferences Details**: Enter any specific preferences or requirements the client has for the project.
* **Project Status Details**: Enter the current status of the project.
* **Stakeholders Involved Details**: Enter any specific details about the stakeholders involved in the project.
* **Water Sources Details**: Enter any specific details about the water sources for the project.

Note: This form is intended to be used as a guide, and the information gathered will be used to inform the design process. Please fill in as much information as possible to help the designer create a comprehensive design.
