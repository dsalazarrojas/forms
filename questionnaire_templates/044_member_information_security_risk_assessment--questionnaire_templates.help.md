# Member Information Security Risk Assessment - Help Guide
## Purpose
This form is used to assess the security risk of a member within an organization. It is intended to capture detailed information about the member's job role, department, and security-related factors.

## How To Complete This Form
To complete this form, please fill out the fields as follows:

*   Ensure you have the necessary information about the member, including their first name, last name, job title, department, and manager's name and email.
*   Enter the member's job function, location, and average hours worked per week.
*   Answer the questions regarding the member's security readiness, phish-readiness, and phish attacks.
*   Check the box to indicate if the member has recently received security training.
*   Provide any security concerns that the member may have.

## Field-by-Field Explanation

*   **First Name (<required>)**: Please enter the member's first name.
*   **Last Name (<required>)**: Enter the member's last name.
*   **Job Title (<optional>)**: Enter a brief description of the member's job title.
*   **Department (<optional>)**: Enter the member's department name.
*   **Job Function (<optional>)**: Enter a brief description of the member's job function.
*   **Location (<optional>)**: Enter the member's location.
*   **Manager Name (<optional>)**: Enter the name of the member's manager.
*   **Manager Email (<optional>)**: Enter the email address of the member's manager.
*   **Employee Since (<required>)**: Enter the date the member has been employed.
*   **Last Security Training (<optional>)**: Check the box if the member has received security training recently.
*   **Average Hours Worked (<optional>)**: Enter the average hours worked by the member per week.
*   **Security Readiness (<required>)**: Select the level of the member's security readiness.
*   **Phishing Readiness (<required>)**: Select all phish-readiness levels that apply to the member.
*   **Phishing Attacks (<required>)**: Enter the number of phish attacks the member has experienced.
*   **Security Training (<required>)**: Check the box if the member has received security training.
*   **Security Concerns (<optional>)**: Enter any security concerns that the member may have.
*   **Security Awareness (<optional>)**: Enter any security awareness that may be relevant. 

## Tips

*   Please ensure that the member's information is accurate and up-to-date.
*   If a field is required, ensure that it is filled out accordingly.
*   If you're unsure about any of the fields, please consult with the member or their manager.
