# Parable Identification Quiz - Help Guide
## Purpose
This form is designed to collect information about the parables you are familiar with.

## How To Complete This Form
1. Start by selecting which parable you know or have heard of on page 1.
2. On page 2, enter any details you can remember about the parable you selected.
3. On page 3, select all the parables that you know or have heard of that you'd like to identify.
4. On page 4, select which parable you know or have heard of again, to confirm your previous selection.

## Field-by-Field Explanation
* **Parable Identification Quiz**:
	+ This field asks for the title of the parable you've heard or know.
* **Which parable**:
	+ Select one of the parables listed. This is where you choose which parable you are familiar with.
* **Which parable**: (Page 2)
	+ Enter any details you can remember about the parable you selected.
* **Which parables**:
	+ Select all the parables that you know or have heard of.
* **Parable Identification**:
	+ Enter any other parable you've heard or know that you'd like to identify.

Note: The form is not affiliated with, endorsed by, or derived from any form platform, and is an original adaptation of the parable metadata provided.
