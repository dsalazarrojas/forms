# Multilingual Family Needs Survey - Help Guide
## Purpose
The Multilingual Family Needs Survey is a tool to understand the languages spoken at home and the needs of multilingual families. It is designed to help identify the languages spoken at home and to collect information on the needs of these families.

## How To Complete This Form
This form is divided into several sections, each addressing different aspects of language use and needs within multilingual families. To complete this form, follow the instructions below:

* Fill in the languages spoken at home section by selecting all the languages that are spoken at home.
* Select the options that best describe the needs of the multilingual family.
* Provide a list of languages spoken at home in the text field.
* If necessary, provide additional languages spoken at home in the "Other" text field.
* Select the options that best describe the needs of the multilingual family.
* If necessary, provide a description of the needs in the text field.

## Field-by-Field Explanation

* **Languages Spoken at Home**: Select all the languages that are spoken at home.
	+ **Yes**: This option is chosen if you speak at least one language at home.
	+ **No**: This option is chosen if no languages are spoken at home.
* **Support Needs**: Select all the needs that best describe the needs of the multilingual family.
	+ **Spanish**: This option is chosen if the language is needed or spoken at home.
	+ **English**: This option is chosen if the language is needed or spoken at home.
	+ **Other**: This option is chosen if another language is needed or spoken at home.
* **Languages Spoken at Home**: Provide a list of all languages spoken at home.
* **Languages Spoken Other**: If you need to mention languages not listed, enter them here.
* **Needs Assistance**: Select all the needs that best describe the needs of the multilingual family.
	+ **Yes**: This option is chosen if the multilingual family needs assistance.
	+ **No**: This option is chosen if the multilingual family does not need assistance.
* **Description**: If you need to provide more information about the needs, enter it here.
* **First Language Spoken**: Select the first language spoken at home.
	+ **Spanish**: This option is chosen if the first language spoken at home is Spanish.
	+ **English**: This option is chosen if the first language spoken at home is English.
	+ **Other**: This option is chosen if another language is spoken at home.
* **Languages Spoken Other Other**: If you need to mention additional languages spoken at home, enter them here.

Note: The form is designed to be flexible, allowing end users to provide as much information as needed about the languages spoken at home and the needs of the multilingual family.
