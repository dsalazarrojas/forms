# Apartment Hunting Checklist - Help Guide
## Purpose
This form is designed to help us understand your needs and preferences when searching for a new apartment. Please answer all questions accurately and honestly, and don't hesitate to ask if you have any questions or concerns.

## How To Complete This Form
1. Start by carefully reading each question and ensuring you understand what is being asked.
2. Answer each question truthfully, and don't leave any fields blank unless specified as optional.
3. For select options, choose all that apply.
4. For text fields, provide as much detail as needed.

## Field-by-Field Explanation

*   **Your Name** (`renter_name`, `text`, required):
    Your name is the first piece of information we need to know. Please enter your full name as you would like it to be displayed in our records.
*   **Search Start Date** (`search_start_date`, `date`, required):
    This is the date you started looking for an apartment. Please enter the date in the format MM/DD/YYYY.
*   **Target Move-in Date** (`target_move_in_date`, `date`, required):
    This is the date you plan to move into your new apartment. Please enter the date in the format MM/DD/YYYY.
*   **Maximum Monthly Budget** (`budget_monthly`, `number`, required):
    This is your maximum monthly budget, including rent and utilities. Please enter the amount as a number, using decimal points for dollars and cents.
*   **Available for Deposit** (`budget_deposit`, `number`, required):
    This is the maximum amount you are able to pay for a security deposit. Please enter the amount as a number.
*   **Desired Location** (`desired_location`, `text`, required):
    Please describe the location you are looking for. This can be a neighborhood, city, or area name.
*   **Commute Destination** (`commute_destination`, `text`, optional):
    If applicable, please enter your work or school location.
*   **Maximum Commute Time** (`max_commute_time`, `number`, optional):
    If applicable, please enter your maximum acceptable commute time in minutes.
*   **Bedroom Requirement** (`bedroom_requirement`, `select_one`, required):
    Please select the number of bedrooms you need.
*   **Bathroom Requirement** (`bathroom_requirement`, `select_one`, required):
    Please select the number of bathrooms you need.
*   **Must-Have Amenities** (`must_have_amenities`, `select_multiple`, required):
    Please select all amenities that are absolutely necessary for you.
*   **Nice-to-Have Amenities** (`nice_to_have_amenities`, `select_multiple`, required):
    Please select all amenities that are highly preferred.
*   **Pet Ownership** (`pet_ownership`, `select_one`, required):
    Please select your pet ownership status.
*   **Pet Details** (`pet_details`, `text`, optional):
    If you have pets, please provide more information about them.
*   **Smoking Preference** (`smoking_preference`, `select_one`, required):
    Please select your smoking preference.
*   **Floor Preference** (`floor_preference`, `select_one`, required):
    Please select the floor you prefer.
*   **Laundry Preference** (`laundry_preference`, `select_one`, required):
    Please select your laundry preference.
*   **Parking Needs** (`parking_needs`, `select_one`, required):
    Please select your parking needs.
*   **Accessibility Needs** (`accessibility_needs`, `select_multiple`, required):
    Please select any accessibility needs you have.
*   **Preferred Lease Term** (`lease_term_preference`, `select_one`, required):
    Please select the lease term you prefer.
*   **Monthly Utilities Budget** (`utilities_budget`, `number`, optional):
    If applicable, please enter your estimated monthly utilities cost.
*   **Preferred Utilities Included** (`preferred_utilities_included`, `select_multiple`, required):
    Please select all utilities you would like to be included in your rent.
*   **Neighborhood Priorities** (`neighborhood_priorities`, `select_multiple`, required):
    Please select the most important factors in your desired neighborhood.
*   **Property Viewing Availability** (`property_viewing_schedule`, `select_multiple`, required):
    Please select when you are available to view properties.
*   **Application Readiness** (`application_readiness`, `select_one`, required):
    Please select how prepared you are to apply for an apartment.
*   **Documents Available** (`documents_available`, `select_multiple`, required):
    Please select all documents you have available.
*   **Guarantor Needed** (`guarantor_needed`, `select_one`, required):
    Please select if you need a guarantor.
*   **Current Housing Situation** (`current_housing`, `select_one`, required):
    Please select your current housing situation.
*   **Reason for Moving** (`reason_for_moving`, `select_one`, required):
    Please select the reason for your move.
*   **Working with an Agent** (`real_estate_agent`, `select_one`, required):
    Please select if you are working with a real estate agent.
*   **Agent Contact Information** (`agent_contact`, `text`, optional):
    If applicable, please enter your agent's contact information.
*   **Additional Requirements** (`additional_requirements`, `text`, optional):
    If you have any other important requirements, please describe them here.
*   **Additional Notes** (`notes`, `text`, optional):
    If you have any other comments or preferences, please share them here.

## Tips
- Please answer all questions accurately to ensure we can better understand your needs.
- Double-check the format of all date fields to ensure correctness.
- For select fields, select all that apply or relevant options.
- For text fields, provide clear and concise responses.
- If you need assistance or clarification, please don't hesitate to contact us.
