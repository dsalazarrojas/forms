# New Manager Onboarding Questionnaire - Help Guide
## Purpose
The New Manager Onboarding Questionnaire is a form used to gather essential information about new managers, ensuring a smooth and efficient onboarding process.

## How To Complete This Form
1. Fill out this form with the necessary information about the new manager.
2. Provide accurate and complete details to avoid any potential issues.
3. Submit the form to complete the onboarding process.

## Field-by-Field Explanation
* **First Name**: Enter the new manager's first name (`<name>`, `text`, required: false)
	+ The first name of the new manager.
* **Last Name**: Enter the new manager's last name (`<name>`, `text`, required: false)
	+ The last name of the new manager.
* **Email**: Enter the new manager's email address (`<email>`, `email`, required: false)
	+ The email address of the new manager.
* **Reporting Manager**: Enter the name of the manager that the new manager will be reporting to (`<name>`, `text`, required: false)
	+ The name of the manager to whom the new manager will report.
* **Direct Reports**: Enter the number of direct reports the new manager will have (`<number>`, `number`, required: false)
	+ The number of people directly reporting to the new manager.
* **Indirect Reports**: Enter the number of indirect reports the new manager will have (`<number>`, `number`, required: false)
	+ The number of people indirectly reporting to the new manager.
* **Job Title**: Enter the new manager's job title (`<name>`, `text`, required: false)
	+ The title of the new manager's position.
* **Location**: Select "Yes" or "No" to indicate if the new manager will be located at the main office or not (`<select_multiple>`, `select_multiple`, required: false)
	+ Whether the new manager will be located at the main office or not.
* **Start Date**: Enter the date the new manager will start (`<date>`, `date`, required: false)
	+ The date the new manager will begin working.
* **End Date**: Enter the date the new manager's contract will end (`<date>`, `date`, required: false)
	+ The date the new manager's contract will expire.

## Tips
* Ensure you fill out all required fields accurately.
* If a field is marked as optional, fill it out if necessary to provide additional information.
* If you're unsure about any field, contact your HR representative for guidance.
