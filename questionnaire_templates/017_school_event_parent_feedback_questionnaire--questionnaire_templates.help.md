# School Event Parent Feedback Questionnaire - Help Guide
## Purpose
The School Event Parent Feedback Questionnaire is a tool for collecting information from parents about their experiences and opinions after a school event. This form will help event organizers understand what worked well and what didn't, enabling them to improve future events.

## How To Complete This Form
To complete this form, follow these steps:

1. Please answer all the questions truthfully and thoroughly.
2. Use the options provided in the select fields to select the most accurate response.
3. If a question is not applicable, you can leave it blank or write 'Not Applicable' in the text field.
4. Ensure that you've filled out all the pages of the form to provide comprehensive feedback.

## Field-by-Field Explanation

* **School Event Parent Feedback Questionnaire (Page 1)** (`school_event_parent_feedback_questionnaire`, text, optional)
	+ This is the title of the form. You can leave this field blank if you'd like.
* **Parent Feedback (Page 2)** (`parent_feedback`, select_multiple, optional)
	+ Please select all that apply:
		- Parent's Name: This is the name of the parent providing feedback.
		- Teacher's Name: The name of the teacher associated with this event.
		- Event Date: The date of the event.
		- Event Time: The time of the event.
		- Comments: Any additional comments about the event.
* **Event Satisfaction (Page 3)** (`event_satisfaction`, select_one, optional)
	+ Rate your satisfaction with the event:
		- Very Satisfied: You were very satisfied with the event.
		- Somewhat Satisfied: You were somewhat satisfied with the event.
		- Neutral: You were neutral about the event.
		- Somewhat Dissatisfied: You were somewhat dissatisfied with the event.
		- Very Dissatisfied: You were very dissatisfied with the event.
* **Event Improvement Suggestions (Page 4)** (`event_improvement_suggestions`, text, optional)
	+ Suggest any improvements or changes for future events.
* **Feedback (Page 5)** (`feedback`, date, optional)
	+ This field is not currently used.
* **Event Rating (Page 6)** (`event_rating`, number, optional)
	+ Rate this event out of 10.
* **Event Rating (Page 7)** (`event_rating_2`, time, optional)
	+ This field is not currently used.
* **Event Rating (Page 8)** (`event_rating_3`, number, optional)
	+ This field is similar to Event Rating (Page 6).
* **Email (Page 9)** (`email`, email, optional)
	+ Enter your email address to provide a convenient way for us to contact you about future events.
* **Phone (Page 10)** (`phone`, text, optional)
	+ If you'd like to be contacted directly, please enter your phone number.

Please note that some fields are not currently used and can be ignored. The goal is to provide feedback about the event, so focus on the fields that are relevant to your experience.
