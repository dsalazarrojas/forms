# Future Planning Questionnaire - Help Guide
## Purpose
The "Future Planning Questionnaire" is a tool for creating a clear and actionable plan for long-term goals and aspirations.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by answering the "Goals And Aspirations" question on page 1. This section is a text field where you can describe your goals and aspirations.
2. On page 2, answer the "Long Term Goals" question, which is also a text field.
3. Proceed to page 3 and answer the "Time Frame For Achieving Goals", which is a number field.
4. On page 4, select any obstacles that apply to you from the "Obstacles" multiple select field.
5. On page 5, select a support system from the "Support System" single select field.
6. On page 6, add a detailed action plan in the "Action Plan" text field.
7. On page 7, add any additional notes or comments in the "Review And Update" note field.
8. On page 8, select a future focus area from the "Future Focus" single select field.
9. On page 9, set a goals alignment score in the "Goals Alignment" number field.
10. Finally, on page 10, add a clear and concise description of your goal clarity in the "Goal Clarity" text field.

## Field-by-Field Explanation
### Page 1: Goals And Aspirations
* **Goals And Aspirations** (`title`, `text`, required: false): Describe your current goals and aspirations.

### Page 2: Long Term Goals
* **Long Term Goals** (`title`, `text`, required: false): Describe your long-term goals.

### Page 3: Time Frame For Achieving Goals
* **Time Frame For Achieving Goals** (`title`, `number`, required: false): Enter a realistic time frame (in years) for achieving your goals.

### Page 4: Obstacles
* **Obstacles** (`title`, `select_multiple`, required: false): Select any obstacles that apply to you.

### Page 5: Support System
* **Support System** (`title`, `select_one`, required: false): Select a support system for achieving your goals.

### Page 6: Action Plan
* **Action Plan** (`title`, `text`, required: false): Add a detailed action plan for achieving your goals.

### Page 7: Review And Update
* **Review And Update** (`title`, `note`, required: false): Add any additional notes or comments.

### Page 8: Future Focus
* **Future Focus** (`title`, `select_one`, required: false): Select a future focus area.

### Page 9: Goals Alignment
* **Goals Alignment** (`title`, `number`, required: false): Set a goals alignment score.

### Page 10: Goal Clarity
* **Goal Clarity** (`title`, `text`, required: false): Add a clear and concise description of your goal clarity.
