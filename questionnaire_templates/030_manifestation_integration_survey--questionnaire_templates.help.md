# Manifestation Integration Survey - Help Guide

## Purpose
This form is designed to collect information about a client's manifestation goals and integration progress. It's meant to be used by clients, project managers, or other stakeholders to track and analyze the status of client integrations.

## How To Complete This Form
1. Please answer each question to the best of your ability.
2. You can use the options in the "select_one" type fields to choose a progress status for each integration.
3. If there are any challenges or support needs not listed, feel free to add them in the designated text fields.

## Field-by-Field Explanation
### 1. **Client Manifestation Goals** (`integration_goals`, `text`, optional)
This field is for the client to describe their current manifestation goals.

### 2. **Client Integration Progress** (`integration_progress`, `select_one`, optional)
Choose the current status of the integration from the options: Not Started, In Progress, Complete.

### 3. **Challenges** (`challenges`, `text`, optional)
List any challenges the client is currently experiencing with the integration.

### 4. **Support Needs** (`support_needs`, `text`, optional)
Describe the support needs the client requires at this time.

### 5-13. **Manifestation Goals** (`manifestation_goals_1`-`manifestation_goals_8`, `text`, optional)
These fields are for the client to describe their current manifestation goals 1-8.

### 14-18. **Integration Challenges** (`integration_challenges`, `text`, optional)
List any integration challenges the client is currently experiencing.

### 15-21. **Support Needs** (`support_needs_1`-`support_needs_8`, `text`, optional)
Describe the support needs the client requires at this time.

### 15-22. **Integration Progress** (`integration_progress_2`-`integration_progress_9`, `select_one`, optional)
Choose the current status of each integration from the options: Not Started, In Progress, Complete.

## Tips
* Make sure to answer each question to the best of your ability.
* If you're unsure about any option in the "select_one" type fields, choose the status that best describes your current integration progress.
* For text fields, provide as much detail as possible to help us better understand your situation.
* If you have any questions or concerns, please don't hesitate to contact form@gic.mx.
