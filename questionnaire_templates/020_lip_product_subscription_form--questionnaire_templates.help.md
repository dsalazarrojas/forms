# lip_product_subscription_form - Help Guide
## Purpose
The lip_product_subscription_form is used to capture information about a product subscription. This form is essential for understanding customer preferences and requirements for a subscription plan. It is usually filled out by customers during the onboarding process.

## How To Complete This Form
To complete this form, follow the steps below:

1. Start by filling out the first field, which is a text input field for the product subscription form page 1 label.
2. Proceed to the second field, which is a select_one input field with two options: "option 1" and "option 2".
3. Fill out the third field, which is a select_multiple input field that allows you to select multiple options: "option 1" and "option 2".
4. Finally, fill out the fourth field, which is a number input field.

## Field-by-Field Explanation

* **lip_product_subscription_form_page_1** (`text`, required/optional: false): This is a text input field where you can enter a brief description or label for the product subscription form page 1.
* **lip_product_subscription_form_1_2** (`select_one`, required/optional: false): This field allows you to select one option for the product subscription form. You can choose between "option 1" or "option 2".
* **lip_product_subscription_form_page_1_3** (`select_multiple`, required/optional: false): This field lets you select multiple options for the product subscription form. You can choose between "option 1" and "option 2".
* **lip_product_subscription_form_1_4** (`number`, required/optional: false): This is a number input field where you can enter a numerical value for the product subscription form.
