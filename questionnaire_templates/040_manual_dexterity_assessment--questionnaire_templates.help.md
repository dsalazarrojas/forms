# manual_dexterity_assessment - Help Guide
## Purpose
The manual dexterity assessment form is designed to evaluate an individual's manual dexterity and fine motor skills.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Review the questions on both pages and make sure you have understood what is being asked.
2. For each question, provide as specific and concrete observations as possible, focusing on facts rather than subjective opinions.
3. For the 'task performance' section, select all relevant options that apply from the dropdown menu.
4. For the 'assessment history' section, enter the date of the assessment, if applicable.
5. For the text fields, provide clear and concise answers, avoiding unnecessary information.

## Field-by-Field Explanation
- **task_performance** (Select Multiple): Please select all relevant options that apply to the individual's manual dexterity performance.
  - Option 1: The individual performs tasks with ease and speed.
  - Option 2: The individual experiences difficulty with some tasks, but is able to adapt.
  - Option 3: The individual requires significant assistance with tasks.
- **assessment_history** (Date): Enter the date of the assessment, if applicable.
- **observation_1-21** (Text): Please provide clear and concrete observations about the individual's manual dexterity and performance. Avoid unnecessary information and focus on facts. 

  Example: "The individual is able to grip a pen with ease, but their fingers appear shaky during writing."
