# Consulting Company Storage Questionnaire - Help Guide
## Purpose
This form is designed to help consulting companies assess their storage needs, providing an overview of their physical and data storage requirements.

## How To Complete This Form
1. Fill in the Company name and provide an estimated number of boxes or GB of data stored (if applicable).
2. Choose the storage types that are required for your company.
3. Select the frequency at which items are accessed.
4. Describe any specific security or compliance needs.

## Field-by-Field Explanation
* **Company Name (Company name)** (`company_name`, text, **Required**): Enter the name of your consulting company.
* **Storage types required (Storage types required)** (`storage_types_required`, select_multiple, **Required**): Select all storage types that are required for your company:
	+ Document storage
	+ Digital archival
	+ Equipment storage
	+ Off site warehouse
* **Approximate Volume (Approximate volume)** (`approximate_volume`, text, **Optional**): Estimate the number of boxes or GB of data that need to be stored.
* **Access Frequency (Access frequency)** (`access_frequency`, select_one, **Optional**): Select the frequency at which items are accessed:
	+ Daily
	+ Weekly
	+ Monthly
	+ Rarely
* **Security Requirements (Security requirements)** (`security_requirements`, text, **Optional**): Describe any specific security or compliance needs, such as data encryption, firewalls, or on-site storage.
