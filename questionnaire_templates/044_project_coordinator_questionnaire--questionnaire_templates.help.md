# Project Coordinator Questionnaire - Help Guide
## Purpose
The Project Coordinator Questionnaire is a form designed to collect information about project coordinators to better understand their capabilities and fit for a project role.

## How To Complete This Form
To complete this form, please select the relevant options for each field, taking care to answer every question accurately and truthfully.

## Field-by-Field Explanation
### **Project Coordinator** (`project_coordinator_questionnaire`)
*   The title of the project you would be working on as a project coordinator.

### **Project Details** (`project_details`)
*   A short description of the project you would be working on as a project coordinator.

### **Job Type** (`job_type`)
*   Select the type of job you would be performing as a project coordinator. Options include:
    *   Project Coordinators
    *   Project Managers
    *   Team Leads

### **Experience** (`experience`)
*   Please input your years of experience as a project coordinator, or the number of years you have experience in this field.

### **Skills** (`skills`)
*   Select the skills you possess that are relevant to the project coordinator role. Options include:
    *   Problem Solving
    *   Time Management
    *   Communication
    *   Team Work
    *   Leadership

### **Work Arrangement** (`work_arrangement`)
*   Select the arrangement that best suits your working style as a project coordinator. Options include:
    *   Full-time
    *   Part-time
    *   Flexible
    *   Other

### **Available For** (`available_for`)
*   Select the days you are available to work as a project coordinator. Options include:
    *   Weekdays
    *   Weekends

### **Time Available** (`time_available`)
*   Input your available working hours as a project coordinator.

### **Contact Info** (`contact_info`)
*   Input your work contact information.

### **Contact Number** (`contact_number`)
*   Input your personal contact number.

### **Available Hours** (`available_hours`)
