# Due Diligence Assessment Questionnaire - Help Guide
## Purpose
The Due Diligence Assessment Questionnaire is designed to provide a structured framework for assessing a potential business partner or entity's due diligence process, financial standing, and legal compliance. This form helps to identify potential risks and areas of concern for investors, partners, or stakeholders.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer each question thoroughly and accurately based on the provided options.
2. Select all relevant options for the "Potential Business Partners" section that apply to your assessment.
3. Enter the actual values for "Entity Finance" and "Financial Standing" sections.
4. Select one option for the "Entity Legal", "Vetting Process", and "Entity Status" sections.
5. Enter the name of the entity and the contact person responsible for the business.
6. Provide any additional vetting notes as needed.

## Field-by-Field Explanation

- **Potential Business Partners** (<type> select_multiple, <required> false)
  + Select all relevant options for the potential business partners that you have assessed.
  + Examples: Select multiple options if you have multiple partners.

- **Entity Finance** (<type> number, <required> false)
  + Enter the actual financial value for the entity's finance.
  + Example: $1,000,000

- **Entity Legal** (<type> select_one, <required> false)
  + Select one option for the entity's legal standing.
  + Examples: Option 1, Option 2, Option 3

- **Financial Standing** (<type> number, <required> false)
  + Enter the actual financial standing value for the entity.
  + Example: 500

- **Vetting Process** (<type> select_one, <required> false)
  + Select one option for the vetting process used.
  + Examples: Option 1, Option 2, Option 3

- **Business Partners** (<type> number, <required> false)
  + Enter the actual number of business partners.
  + Example: 3

- **Entity Name** (<type> text, <required> false)
  + Enter the actual name of the entity.
  + Example: John Doe Corporation

- **Contact Person** (<type> text, <required> false)
  + Enter the name of the contact person.
  + Example: Jane Doe

- **Entity Status** (<type> select_one, <required> false)
  + Select one option for the entity's status.
  + Examples: Option 1, Option 2, Option 3

- **Vetting Notes** (<type> note, <required> false)
  + Provide any additional notes related to the vetting process.
  + Example: Additional notes about the vetting process.
