# Wardrobe Design Preferences Survey - Help Guide
## Purpose
This form is designed to collect information about a client's wardrobe design preferences, including their style, budget, and fabric type preferences.

## How To Complete This Form

To complete this form, follow the steps below:

1. Review the form carefully and ensure you understand each field and option.
2. Answer each question to the best of your ability, providing as much detail as possible.
3. For fields marked as "select_one", select only one option that best describes your preference.
4. For fields marked as "select_multiple", select all applicable options that best describe your preference.
5. For fields marked as "text", provide a brief description or comment as instructed.
6. When finished, review your answers carefully to ensure accuracy and completeness.
7. Submit the form to complete the survey.

## Field-by-Field Explanation

* **Client Style**: Select a style that best describes your preferences (Client Style)
	+ Client Style is a subjective measure to gauge your personal taste in clothing and fashion.
* **Space Type**: Select the type of space you want to design for (Space Type)
	+ Space Type defines the type of room or area you want to design for, such as a bedroom, living room, or office.
* **Budget Range**: Select the budget range that best fits your needs (Budget Range)
	+ Budget Range provides an estimate of how much you are willing to spend on the design project.
* **Wardrobe Size**: Select the size of wardrobe you want to design for (Wardrobe Size)
	+ Wardrobe Size helps determine the scale of the design project.
* **Fabric Type**: Select all applicable fabric types you would like to use (Fabric Type)
	+ Fabric Type refers to the material and weave of the fabrics you prefer.
* **Design Style**: Select a design style that best fits your preferences (Design Style)
	+ Design Style defines the aesthetic or atmosphere you want to achieve with your design.
* **Color Scheme**: Select all applicable colors you would like to use (Color Scheme)
	+ Color Scheme refers to the palette of colors you prefer for your design project.
* **Space Features**: Provide a brief description of any special features or requirements for the space (Space Features)
	+ Space Features allows you to provide additional information about any unique features or requirements for the space.
* **Custom Designs**: Provide a brief description of any custom designs or requests you have (Custom Designs)
	+ Custom Designs gives you an opportunity to share any special requests or ideas you have for the design project.
* **Budget Details**: Provide a brief description of your budget details (Budget Details)
	+ Budget Details allows you to provide additional information about your budget, such as any specific costs or restrictions.
* **Submit**: Select the submit option to complete the survey (Submit)
	+ Submit completes the survey and submits it to the project manager or designer.
* **Confirm**: Confirm that you have completed the survey accurately (Confirm)
	+ Confirm ensures that you have reviewed and accurately completed the survey.
* **Client Name**: Provide your name for identification purposes (Client Name)
	+ Client Name is for identification purposes only.
* **Client Email**: Provide your email address for communication purposes (Client Email)
	+ Client Email is for communication with the designer or project manager.
* **Client Phone**: Provide your phone number for communication purposes (Client Phone)
	+ Client Phone is for communication with the designer or project manager.
* **Designer Name**: Provide the name of your assigned designer (Designer Name)
	+ Designer Name is for identification purposes only.
* **Designer Email**: Provide the email address of your assigned designer (Designer Email)
	+ Designer Email is for communication with the designer.
* **Designer Phone**: Provide the phone number of your assigned designer (Designer Phone)
	+ Designer Phone is for communication with the designer.
* **Fabric Type Details**: Provide details about the fabric type you prefer (Fabric Type Details)
	+ Fabric Type Details provides additional information about the fabric type you prefer.
* **Fabric Type Color**: Provide details about the color of fabric you prefer (Fabric Type Color)
	+ Fabric Type Color provides additional information about the color of fabric you prefer.
* **Fabric Type Material**: Provide details about the material of fabric you prefer (Fabric Type Material)
	+ Fabric Type Material provides additional information about the material of fabric you prefer.
* **Fabric Type Pattern**: Provide details about the pattern of fabric you prefer (Fabric Type Pattern)
	+ Fabric Type Pattern provides additional information about the pattern of fabric you prefer.
* **Fabric Type Weave**: Provide details about the weave of fabric you prefer (Fabric Type Weave)
	+ Fabric Type Weave provides additional information about the weave of fabric you prefer.
* **Fabric Type Other**: Provide any other fabric type details you prefer (Fabric Type Other)
	+ Fabric Type Other provides an opportunity to share any additional fabric type preferences.

## Tips

* Please take your time and answer each question carefully to ensure accuracy and completeness.
* If you are unsure about any field or option, please contact your assigned project manager or designer for clarification.
* Make sure to proofread your answers before submitting the survey to ensure accuracy and completeness.
* If you have any questions or concerns, please contact your assigned project manager or designer.
