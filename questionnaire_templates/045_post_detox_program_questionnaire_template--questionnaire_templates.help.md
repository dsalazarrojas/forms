# # Post Detox Program Questionnaire Template - Help Guide
## Purpose
The Post Detox Program Questionnaire Template is designed to collect information from individuals who have undergone a detox program. This form is used to gather overall experience, ratings, and feedback about the program. It is intended for individuals to provide their honest opinions and suggestions for improvement.

## How To Complete This Form
1. Please fill out this form completely and accurately.
2. Answer each question honestly and thoroughly.
3. If you have any additional comments or suggestions, please provide them in the "Additional Comments" field.
4. If you have any follow-up questions or concerns, please list them in the "Follow Up Questions" field.

## Field-by-Field Explanation
* **Overall Experience** (`overall_experience`, `number`, required): This field asks you to rate your overall experience with the detox program. Please select a number from 1 to 10 to indicate your level of satisfaction.
* **Detox Program Rating** (`detox_program_rating`, `select_one`, required): This field asks you to rate your satisfaction with the detox program. Please select from the options: High, Medium, or Low.
* **Detox Program Effectiveness** (`detox_program_effectiveness`, `number`, required): This field asks you to rate how effective you feel the detox program was in helping you. Please select a number from 1 to 10.
* **Overall Health Status** (`overall_health_status`, `select_multiple`, required): This field asks you to select all that apply to your current health status. Please choose from: Excellent, Good, Fair, or Poor.
* **Health Issue** (`health_issue`, `text`, required): Please enter a brief description of any health issues you experienced before or after the detox program.
* **Health Concern** (`health_concern`, `text`, optional): If you have any concerns about your health, please enter them here.
* **Health Issue Description** (`health_issue_description`, `text`, optional): Please provide a brief description of your health issue.
* **Recommendations** (`recommendations`, `text`, optional): If you have any recommendations for the detox program, please enter them here.
* **Additional Comments** (`additional_comments`, `note`, optional): If you have any additional comments or suggestions, please enter them here.
* **Contact Name** (`contact_name`, `text`, required): Please enter your name.
* **Contact Phone** (`contact_phone`, `text`, required): Please enter a valid phone number where we can contact you.
* **Contact Email** (`contact_email`, `email`, required): Please enter a valid email address where we can contact you.
* **Alternate Contact Phone** (`contact_phone_alternate`, `text`, optional): If you have an alternate contact phone number, please enter it here.
* **Alternate Contact Email** (`contact_email_alternate`, `email`, optional): If you have an alternate contact email, please enter it here.
* **Date** (`date`, `date`, optional): Please enter the date you completed the detox program.
* **Time** (`time`, `time`, optional): Please enter the time you completed the detox program.
* **Address** (`address`, `text`, optional): If you have a specific address related to your detox program experience, please enter it here.
* **City** (`city`, `text`, optional): If you have a city related to your detox program experience, please enter it here.
* **State** (`state`, `select_one`, optional): Please select the state where you experienced the detox program. Options: CA, NYC, USA, Other, None.
* **Zip** (`zip`, `text`, optional): If you have a zip code related to your detox program experience, please enter it here.
* **State Abbreviation** (`state_abbreviation`, `select_multiple`, optional): Select all that apply to indicate the state(s) you visited for the detox program. Options: CA, NYC, USA, Other, None.
* **Overall Satisfaction** (`overall_satisfaction`, `number`, optional): This field asks you to rate your overall satisfaction with the detox program. Please select a number from 1 to 10.
* **Reason For Unsatisfaction** (`satisfaction_reasons`, `text`, optional): If you have any reason for unsatisfaction, please enter it here.
* **Suggestions For Improvement** (`suggestions_for_improvement`, `text`, optional): If you have any suggestions for improvement, please enter them here.
* **Follow Up Questions** (`follow_up_questions`, `text`, optional): If you have any follow-up questions, please list them here.
