# Early Childhood Math Skills Survey - Help Guide
## Purpose
This form is designed to gather information about a child's math skills in early childhood, covering various aspects such as counting, basic numbers, place value, money, time telling, math language, problem-solving, emotional intelligence, attention span, and conceptualization.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form carefully to understand the sections and questions.
2. Fill in the demographic information: name, age, gender, and native language.
3. Answer the math-related questions, selecting the relevant options for each field.
4. Report the number of questions asked during math sessions, time spent on math activities, and math scores.

## Field-by-Field Explanation

* **Name** (`name`, text, required/optional): Enter the child's name.
* **Age** (`age`, number, required/optional): Enter the child's age.
* **Gender** (`gender`, select_one, required/optional): Select the child's gender from the options: male, female, other.
* **Native Language** (`language`, select_one, required/optional): Select the child's native language from the options: English, Spanish, French, Mandarin.
* **Math Concept** (`math_concept`, select_multiple, required/optional): Select the math concepts the child has been exposed to, such as counting, basic numbers, place value, money.
* **Counting** (`counting`, select_multiple, required/optional): Select the counting skills the child has demonstrated, such as 1, 2, 3, 4, 5.
* **Basic Numbers** (`basic_numbers`, select_multiple, required/optional): Select the basic number concepts the child understands, such as six, ten, twenty, hundred.
* **Place Value** (`place_value`, select_multiple, required/optional): Select the place value concepts the child has grasped, such as tens, hundreds, thousands, ten thousands.
* **Money** (`money`, select_multiple, required/optional): Select the money-related skills the child has shown, such as counting money, comparing money, making change.
* **Time Telling** (`time_telling`, select_multiple, required/optional): Select the time-telling skills the child has demonstrated, such as counting time, telling time, understanding time.
* **Math Language** (`math_language`, select_one, required/optional): Select the math language the child uses, such as math in words, math with numbers, math with symbols.
* **Math Problem Solving** (`math_problem_solving`, select_multiple, required/optional): Select the math problem-solving skills the child has shown, such as basic problem-solving, complex problem-solving, making connections.
* **Emotional Intelligence** (`math_emotional_intelligence`, select_multiple, required/optional): Select the math-related emotional intelligence the child has demonstrated, such as math emotional intelligence, math anxiety, math confidence.
* **Attention Span** (`math_attention_span`, select_multiple, required/optional): Select the math attention span the child has shown, such as math attention span, math focus, math sustained effort.
* **Conceptualization** (`math_conceptualization`, select_multiple, required/optional): Select the math conceptualization skills the child has grasped, such as counting conceptualization, place value conceptualization, money conceptualization.
* **Number of Questions** (`num_questions`, number, required/optional): Report the number of math questions asked during sessions.
* **Time Spent** (`time_spent`, number, required/optional): Report the time spent on math activities.
* **Number of Questions Asked** (`num_questions_asked`, number, required/optional): Report the number of math questions asked during sessions.
* **Math Score** (`math_score`, number, required/optional): Report the math score obtained.
* **Math Score Range** (`math_score_range`, number, required/optional): Report the math score range.
* **Number of Questions Asked 2** (`num_questions_asked_2`, number, required/optional): Report the number of math questions asked during sessions.
* **Time Spent 2** (`time_spent_2`, number, required/optional): Report the time spent on math activities.
* **Number of Questions Asked 3** (`num_questions_asked_3`, number, required/optional): Report the number of math questions asked during sessions.
