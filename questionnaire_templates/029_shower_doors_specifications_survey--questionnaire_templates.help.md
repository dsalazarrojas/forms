# Shower Doors Specifications Survey - Help Guide
## Purpose
The purpose of this form is to collect detailed specifications for custom-made shower doors. This information will be used to guide the production and installation of the shower doors.

## How To Complete This Form
- Read each field carefully and fill out the form in its entirety.
- Make sure to provide accurate and detailed information to ensure accurate production and installation of the shower doors.
- Double-check your entries before submitting the form.

## Field-by-Field Explanation

* **Project Name** (`project_name`, text, required): Enter the name of the project, e.g., "Home Renovation" or "Office Building."
* **Client Name** (`client_name`, text, required): Enter the name of the client or the project's owner.
* **Project Type** (`project_type`, select_one, required): Select the type of project: Residential or Commercial.
* **Glass Type** (`glass_type`, select_multiple, required): Select the type of glass required for the project: Frameless, Semi-Frameless, or Bifold.
* **Glass Thickness** (`glass_thickness`, number, required): Enter the thickness of the glass (in mm).
* **Frame Type** (`frame_type`, select_one, required): Select the type of frame required: No Frame or Frame.
* **Frame Material** (`frame_material`, select_multiple, required): Select the material for the frame: Aluminum or Wood.
* **Glass Finish** (`glass_finish`, select_one, required): Select the type of glass finish: Satin, Haze, Low-Irid, or High-Irid.
* **Glass Treatment** (`glass_treatment`, select_one, required): Select the type of glass treatment: Tempering or Laminating.
* **Glass Size** (`glass_size`, select_multiple, required): Select the size of the glass: Small or Large.
* **Quantity of Units** (`quantity_of_units`, number, required): Enter the quantity of units required.
* **Glass Height** (`glass_height`, number, required): Enter the height of the glass (in mm).
* **Glass Width** (`glass_width`, number, required): Enter the width of the glass (in mm).
* **Shower Frame Type** (`shower_frame_type`, select_one, required): Select the type of shower frame: No Frame or Hinged.
* **Door Height** (`door_height`, number, required): Enter the height of the door (in mm).
* **Door Width** (`door_width`, number, required): Enter the width of the door (in mm).
* **Purpose of Shower** (`shower_purpose`, select_multiple, required): Select the purpose of the shower: Bath, Shower, or Walk-in Closet.
* **Notes** (`notes`, note, required): Enter any additional notes or comments about the project.
* **Email Address** (`email_address`, email, required): Enter the email address of the contact person.
* **Phone Number** (`phone_number`, text, required): Enter the phone number of the contact person.
* **Address** (`address`, text, optional): Enter the address of the contact person, if applicable.
* **City** (`city`, text, optional): Enter the city of the contact person, if applicable.
* **State** (`state`, text, optional): Enter the state of the contact person, if applicable.
* **Zip** (`zip`, text, optional): Enter the zip code of the contact person, if applicable.
* **Submitted By** (`submitted_by`, text, required): Enter the name of the person submitting the form.
