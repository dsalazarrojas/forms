# Tuxedo Fitting Information Form - Help Guide
## Purpose
This form collects information about a Tuxedo fitting, including client details and event details.

## How To Complete This Form
1. Fill in the form with the client's details.
2. Provide event details such as date, start and end time.
3. Fill in any other relevant fields as required.

## Field-by-Field Explanation
* **Tuxedo Fitting Details**: This field is for any additional comments about the Tuxedo fitting.
	+ Type: text
	+ Required: Not required
* **Client Info**: This field is for any additional comments about the client.
	+ Type: text
	+ Required: Not required
* **Event Details**: This field is for any additional comments about the event.
	+ Type: text
	+ Required: Not required
* **Tuxedo Size**: This field is for selecting the size of the Tuxedo.
	+ Type: text
	+ Required: Not required
* **Jacket Size**: This field is for selecting the size of the jacket.
	+ Type: text
	+ Required: Not required
* **Trouser Size**: This field is for selecting the size of the trousers.
	+ Type: text
	+ Required: Not required
* **Pant Size**: This field is for selecting the size of the pant.
	+ Type: text
	+ Required: Not required
* **Sleeve Length**: This field is for selecting the sleeve length of the Tuxedo.
	+ Type: text
	+ Required: Not required
* **Event Date**: This field is for selecting the date of the event.
	+ Type: date
	+ Required: Not required
* **Start Time**: This field is for selecting the start time of the event.
	+ Type: time
	+ Required: Not required
* **End Time**: This field is for selecting the end time of the event.
	+ Type: time
	+ Required: Not required
* **Event Time**: This field is not clearly defined. It is for selecting a time related to the event.
	+ Type: time
	+ Required: Not required
* **Client Phone**: This field is for the client's contact phone number.
	+ Type: text
	+ Required: Not required
* **Client Email**: This field is for the client's email address.
	+ Type: email
	+ Required: Not required
