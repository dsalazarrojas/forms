# Legitimate Interest Assessment Questionnaire - Help Guide
## Purpose
The Legitimate Interest Assessment Questionnaire is a tool used to evaluate whether a data controller can rely on legitimate interest as a basis for processing personal data. This questionnaire gathers information about the purposes for which personal data are being processed and assessed against the legitimate interest criteria to ensure that such processing is compliant with data protection regulations.

## How To Complete This Form
To complete this questionnaire accurately, follow these steps:

1. Answer all questions honestly and to the best of your knowledge.
2. Ensure that all questions apply to your specific data processing activities.
3. Provide detailed descriptions for text fields where necessary.

## Field-by-Field Explanation

* **Legal Basis** (text): This field is for describing the legal basis for processing personal data, such as the legitimate interest exemption. Please provide a clear and specific explanation of the basis for your data processing activities.

* **Data Category** (select_one): In this field, select 'Yes' if the purpose of processing is to provide information about the company, its products, or services. Select 'No' otherwise.

* **Data Subject** (text): Please describe the categories or subjects of data being processed, e.g., customers, employees, users, or other relevant categories.

* **Data Processing Purpose** (text): Describe the purpose for which personal data are being processed, e.g., marketing, sales, HR management, etc.

* **Data Retention Period** (number): Specify the period for which personal data are retained, e.g., 3 months, 1 year, etc. If the retention period is indefinite, please select zero.

* **Data Security Mechanisms** (select_multiple): Check all the applicable security mechanisms used for protecting personal data, such as encryption, pseudonymization, etc.

* **Legal Basis for Lawful** (text): Describe the legal basis for lawful processing, e.g., consent, performance of a contract, etc.

* **Data Breach Response** (select_multiple): Check all the applicable procedures for responding to a data breach, such as notification, rectification, etc.

* **Legal Basis for Compliance** (text): Describe the legal basis for compliance with relevant data protection regulations, e.g., GDPR, local laws, etc.

* **Consent** (select_one): Select 'Yes' if you have obtained explicit consent from data subjects for the processing of their data. Select 'No' otherwise.

* **Data Subject Categories** (text): Describe the categories or subjects of data being processed, e.g., customers, employees, users, etc.

Please ensure that you have carefully reviewed all questions and provided accurate information to ensure that your data processing activities comply with relevant regulations.
