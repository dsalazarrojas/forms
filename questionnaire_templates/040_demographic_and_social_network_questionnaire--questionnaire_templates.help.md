# Demographic And Social Network Questionnaire - Help Guide
## Purpose

This form is used to collect demographic and social network information for users.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the output file format from the dropdown menu.
2. (Optional) Enter your demographic and social network information in the provided fields.

## Field-by-Field Explanation

* **Output File** (Output File, select_one, required): This field allows you to select the format in which you would like to receive your data. Currently, you have the option to choose between "040 demographic and social network questionnaire--questionnaire templates" and "Other".
* **Assigned Tool Version** (Assigned Tool Version, number, optional): This field is not currently utilized, but it may be used in the future to track versioning information. You can enter any number value, but it is not required.
* **Category** (Category, select_multiple, optional): This field allows you to categorize your demographic and social network information. You can select one or more of the following categories: 'True' or 'False'.
* **Description** (Description, text, optional): This field is for you to provide a brief description of your demographic and social network information.
* **Assigned Tool Name** (Assigned Tool Name, text, optional): This field is not currently utilized, but it may be used in the future to provide a name for the tool assigned to your demographic and social network information. You can enter any text value, but it is not required.
* **Form Ids** (Form Ids, number, optional): This field is not currently utilized, but it may be used in the future to track form-specific information. You can enter any number value, but it is not required.

## Tips

* Please select the output file format that best suits your needs.
* You can enter any information you feel is relevant to your demographic and social network characteristics in the description field.
* If you have any issues or concerns while completing this form, please contact your designated support team for assistance.
