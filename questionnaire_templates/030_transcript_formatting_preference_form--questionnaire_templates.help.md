This form is intended to capture user preferences for transcript formatting, which will be used to generate a custom transcript based on the user's input. The form should be completed by users to provide their preferred formatting options for the transcript, such as title, description, categories, delivery preferences (e.g., format, time frame, notes), language, time zone, and file type.

The form is designed to be flexible and allow users to select multiple options for categories, delivery preferences, form language, and file type. The form also includes a field for specifying the time frame for delivery, which can be a date.

To complete this form, follow these steps:

1. Enter the title of the transcript in the **Form Title** field.
2. Provide a brief description of the transcript in the **Form Description** field.
3. Select the categories that apply to the transcript in the **Form Categories** field.
4. Specify the transcript requirements in the **Transcript Requirements** field.
5. Choose the delivery preferences, including format, time frame, and notes, in the **Delivery Preferences** field.
6. Select the language of the transcript in the **Form Language** field.
7. Choose the time zone for the transcript in the **Time Zone** field.
8. Set the time zone awareness in the **Time Zone Aware** field.
9. Select the file type for the transcript in the **File Type** field.

**Tips:**
- Make sure to fill in all required fields marked as required.
- Use the **Transcript Requirements** field to specify any specific requirements for the transcript, such as format, time frame, or special notes.
- Use the **Delivery Preferences** field to specify the format, time frame, and notes for the delivery of the transcript.
- Use the **Form Language** field to select the language of the transcript.
- Use the **Time Zone** field to select the time zone for the transcript.
- Use the **Time Zone Aware** field to specify whether the time zone should be taken into account when generating the transcript.
- Use the **File Type** field to select the type of file to generate for the transcript.

# Transcript Formatting Preference Form - Help Guide
## Purpose

This form is used to capture user preferences for transcript formatting.

## How To Complete This Form

To complete this form, follow the steps outlined above.

## Field-by-Field Explanation

* **Form Title** (1, text, required): Enter the title of the transcript.
* **Form Description** (2, text, required): Provide a brief description of the transcript.
* **Form Categories** (3, select_multiple, required): Select the categories that apply to the transcript.
* **Transcript Requirements** (4, text, required): Specify the transcript requirements.
* **Delivery Preferences** (5, select_multiple, required): Choose the delivery preferences, including format, time frame, and notes.
* **Delivery Format** (6, select_one, required): Choose the format of the delivery.
* **Time Frame** (7, date, required): Choose the time frame for the delivery.
* **Delivery Notes** (8, note, required): Provide any additional delivery notes.
* **Form Language** (9, select_multiple, required): Select the language of the transcript.
* **Time Zone** (10, select_one, required): Choose the time zone for the transcript.
* **Time Zone Aware** (11, number, required): Specify whether the time zone should be taken into account when generating the transcript.
* **File Type** (12, select_multiple, required): Select the type of file to generate for the transcript.
