# Performance And Attention Evaluation - Help Guide

## Purpose
This form is intended to collect feedback and data from professionals on their current role, performance, and attention requirements in various contexts.

## How To Complete This Form
1. Select your current role from the options provided in **What is your current role?**.
2. Rate your current role's performance using a numerical value in **How would you rate your current role's performance?**.

5. Rate your current level of attention using a numerical value in **How would you rate your current level of attention?**.

14. If you'd like to track any specific performance metrics, enter them in **Are there any performance metrics you'd like to track?**.
15. If you'd like to track any other areas of focus, enter them in **Are there any other areas of focus you'd like to track?**.

20. Describe the expected outcomes of performance evaluations in **What are the expected outcomes of performance evaluations?**.
21. If you'd like to track any other performance metrics, enter them in **Are there any other performance metrics you'd like to track?**.
