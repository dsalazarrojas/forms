# Flashcard Creation Survey - Help Guide
## Purpose

This survey aims to gather information about your experiences and preferences regarding flashcards. Your responses will help us understand your needs and behaviors when it comes to creating and using flashcards.

## How To Complete This Form

1. **Please answer each question based on your personal experiences and preferences.**
2. **Select the appropriate options for each question, taking into account your true experiences and feelings about flashcards.**
3. **You can skip any questions that do not apply to you or your experiences with flashcards.**

## Field-by-Field Explanation

* **Platforms Used** (`platform_used`, Select Multiple, optional): This question asks about the platforms you use for creating and using flashcards. Please select all the platforms that you use for creating or using flashcards.
* **How Often** (`how_prophets_used`, Select One, optional): This question inquires about how frequently you use flashcards. Choose the option that best represents your average or usual frequency of using flashcards.
* **Content Types** (`content_types`, Select Multiple, optional): This question is about the types of content you typically find on flashcards. Please select all the content types you usually or prefer to see on flashcards.
* **Frequency** (`flashcards_frequency`, Number, optional): If you don't see your frequency of flashcard use in the provided options, you can enter the number of months you use flashcards.
* **Other Frequency** (`flashcards_frequency_other`, Select One, optional): If you don't find an exact match for your frequency in the previous question, you can choose from the provided options or specify a different frequency in the "Other Frequency" field.
* **How Flashcards Used** (`how_flashcards_used`, Select Multiple, optional): This question asks about how you use flashcards. Select all the methods you use for creating, accessing, or interacting with flashcards.
* **Frequency** (`frequency`, Select One, optional): Please choose the frequency with which you use flashcards, considering the options provided.
* **Flashcard Content** (`flashcard_content`, Select Multiple, optional): This question is about the types of content you see or want on flashcards. Select all the types of content that appeal to you or are relevant to your interests.
* **Platforms** (`platforms`, Select Multiple, optional): This question is about the platforms you use for accessing or interacting with flashcards. Please select all the platforms you use for flashcards.
* **Content Sources** (`content_sources`, Select Multiple, optional): This question is about the sources of content you use for creating or finding flashcards. Select all the sources that you use or trust.
* **Desired Features** (`flashcard_desired_features`, Select Multiple, optional): This question is about the features you would like to see on flashcards. Select all the features that would enhance your flashcard experience.
