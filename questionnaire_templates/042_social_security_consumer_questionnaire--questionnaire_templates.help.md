# Social Security Consumer Questionnaire - Help Guide
## Purpose
This form is designed to collect feedback and opinions from social security consumers on their awareness, usage, concerns, and satisfaction levels with the system.

## How To Complete This Form
To complete this form, follow these steps:

1. Please provide your email address and phone number in the "Email" and "Phone" fields, respectively, if you want to be contacted for follow-up questions or to be kept informed about future improvements.
2. For "Awareness", select one of the options that best describes your level of awareness about the social security system.
3. For "Usage", select all applicable options that describe your use of the social security system.
4. In "Concerns", please type any concerns or issues you have with the social security system.
5. For "Satisfaction", select one of the options that best describes your level of satisfaction with the social security system.
6. Use the "Notes" field to provide any additional comments or feedback about your experience with the social security system.

## Field-by-Field Explanation

* **User Info** (`user_info`, text, optional): Please provide your name and contact information (email and phone number) if you want to be contacted for follow-up questions or to be kept informed about future improvements.
* **Awareness** (`awareness`, select_one, optional): This question measures your level of awareness about the social security system. Please select one of the options:
	+ Very Likely
	+ Not Very Likely
	+ Not At All Likely
* **Usage** (`usage`, select_multiple, optional): This question asks about your use of the social security system. Please select all applicable options:
	+ 'True'
	+ 'False'
* **Concerns** (`concerns`, text, optional): Please type any concerns or issues you have with the social security system.
* **Satisfaction** (`satisfaction`, select_one, optional): This question asks about your level of satisfaction with the social security system. Please select one of the options:
	+ Very Satisfied
	+ Somewhat Satisfied
	+ Neither Satisfied Nor Unsatisfied
	+ Somewhat Dissatisfied
	+ Very Dissatisfied
* **Email** (`email`, email, optional): Please enter your email address if you want to be contacted for follow-up questions or to be kept informed about future improvements.
* **Phone** (`phone`, text, optional): Please enter your phone number if you want to be contacted for follow-up questions or to be kept informed about future improvements.
* **Notes** (`notes`, note, optional): Use this field to provide any additional comments or feedback about your experience with the social security system.
