# Cryptic Text Analysis Survey - Help Guide
## Purpose
This form is designed to collect information from users about their experience and expertise in creating and analyzing puzzles and cryptic texts.

## How To Complete This Form
1. Please fill out the form in its entirety, providing as much detail as possible.
2. If you are unsure about any question, please feel free to ask for clarification.
3. If you have any feedback or suggestions, please use the "Feedback" field.

## Field-by-Field Explanation
* **What is your interpretation of the ambiguous passage?** (`intro_question`, `text`, `required: false`)
	+ This question is an open-ended question asking you to describe your understanding of the ambiguous passage.
* **What is your sentiment towards this passage?** (`sentiment_question`, `text`, `required: false`)
	+ This question is also an open-ended question asking you to describe your feelings towards the passage.
* **What type of puzzle is this?** (`puzzle_type`, `select_one`, `required: false`)
	+ This question asks you to select from the following options:
		- Logic
		- Riddle
		- Maze
		- Labyrinth
* **What type of passage is this?** (`passage_type`, `select_one`, `required: false`)
	+ This question asks you to select from the following options:
		- Story
		- Riddle
		- Joke
		- Puzzle
* **What type of solution is required?** (`solution_type`, `select_one`, `required: false`)
	+ This question asks you to select from the following options:
		- Single
		- Multiple
		- None
* **How long does the solution take?** (`solution_length`, `select_multiple`, `required: false`)
	+ This question asks you to select from the following options:
		- Short
		- Medium
		- Long
* **How difficult is this puzzle?** (`difficulty_level`, `select_one`, `required: false`)
	+ This question asks you to select from the following options:
		- Easy
		- Medium
		- Hard
		- Very Hard
* **What is the solution hint?** (`solution_hint`, `text`, `required: false`)
	+ This question is an open-ended question asking you to describe the solution hint.
* **Will the solution be submitted?** (`submission_type`, `select_one`, `required: false`)
	+ This question asks you to select from the following options:
		- True
		- False
		- Ask
* **What is the submission date?** (`submission_date`, `date`, `required: false`)
	+ This question asks for the date of submission.
* **What is the submission time?** (`submission_time`, `time`, `required: false`)
	+ This question asks for the time of submission.
* **How many years of experience as a researcher do you have?** (`researcher_experience`, `number`, `required: false`)
	+ This question asks for the number of years of experience as a researcher.
* **What is your title?** (`researcher_title`, `text`, `required: false`)
	+ This question is an open-ended question asking for your title as a researcher.
* **How many years of experience as an educator do you have?** (`educator_experience`, `number`, `required: false`)
	+ This question asks for the number of years of experience as an educator.
* **How many years of experience as a puzzle creator do you have?** (`puzzle_creator_experience`, `number`, `required: false`)
	+ This question asks for the number of years of experience as a puzzle creator.
* **Do you have any feedback for us?** (`feedback`, `text`, `required: false`)
	+ This question is an open-ended question asking you to provide feedback.
* **What is your email?** (`email`, `email`, `required: false`)
	+ This question asks for your email address.
* **What is your phone number?** (`phone`, `text`, `required: false`)
	+ This question asks for your phone number.
* **Which institution do you represent?** (`researcher_institution`, `text`, `required: false`)
	+ This question asks for the name of the institution you represent.
* **Which puzzle organization do you represent?** (`puzzle_creator_institution`, `text`, `required: false`)
	+ This question asks for the name of the puzzle organization you represent.
* **What is the purpose of your research?** (`research_purpose`, `text`, `required: false`)
	+ This question is an open-ended question asking for the purpose of your research.
* **What is the purpose of the puzzle?** (`puzzle_purpose`, `text`, `required: false`)
	+ This question is an open-ended question asking for the purpose of the puzzle.
* **What is the theme of the puzzle?** (`puzzle_theme`, `text`, `required: false`)
	+ This question is an open-ended question asking for the theme of the puzzle.
* **How will you be submitting the solution?** (`submission_method`, `select_multiple`, `required: false`)
	+ This question asks you to select from the following options:
		- Online
		- Offline
		- Both
* **Where will you be submitting the solution?** (`submission_location`, `select_multiple`, `required: false`)
	+ This question asks you to select from the following options:
		- Online
