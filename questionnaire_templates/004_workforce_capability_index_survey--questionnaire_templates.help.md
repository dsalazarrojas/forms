# workforce_capability_index_survey - Help Guide
## Purpose
This form collects feedback and scores on various aspects of an individual's or team's workforce capabilities.

## How To Complete This Form
1. Select all relevant categories that describe the workforce.
2. For each selected category, enter a score from 0 to 4 that reflects the workforce's capability in that area.
3. Select a single overall score that reflects the overall workforce capability.
4. Enter any additional comments or feedback.
5. Click the "Submit" button to complete the form.

## Field-by-Field Explanation

* **Introduction**: This is a note field to introduce the survey and provide any additional context.
* **Workforces**: Select all relevant categories that describe the workforce's capabilities. These categories are:
	+ Accounting and Finance
	+ Engineering
	+ IT
	+ Management
	+ Research
* **Categories**: Select all relevant categories that describe the workforce's capabilities. These categories are:
	+ Analytical
	+ Communication
	+ Leadership
	+ Problem Solving
	+ Technical
	+ Time Management
	+ Workforce Development
* **Categories Score (0-4)**: Enter a score from 0 to 4 that reflects the workforce's capability in each selected category. 
* **Scores**: Select a single score from 0 to 4 that reflects the overall workforce capability.
* **Comments**: Please enter any additional comments or feedback.
* **Submit**: Click this button to complete and submit the survey.
