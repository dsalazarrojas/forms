# Urban Planning Community Development Needs Assessment - Help Guide
## Purpose
This form is designed to gather information on the needs and priorities of urban communities for development planning. It is a crucial tool to help stakeholders understand the community's requirements and make informed decisions.

## How To Complete This Form
To complete this form, follow these steps:
1. Review each page and answer the questions honestly and accurately.
2. Be sure to select all applicable options for each field.
3. If you have any questions or concerns, don't hesitate to reach out to the project lead or manager.

### Page 1: First Page
* **First Page**: _Note_ (Required: False)
	+ This is a note field where you can enter any additional information related to the topic.
### Page 2: Page Two
* **Page Two**: _Text_ (Required: False)
	+ This field is for entering a brief description or comment.

### Page 4: Page Four
* **Page Four**: _Number_ (Required: False)

### Tips
* Be thorough and honest when completing the form.
* If you are unsure about any question, feel free to ask for clarification.
