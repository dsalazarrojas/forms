# Juvenile Justice Survey Questionnaire - Help Guide
## Purpose
The Juvenile Justice Survey Questionnaire is designed to collect information about juvenile justice, allowing users to specify who the justice refers to, the type of question being asked, and provide additional details or hints to help with the question type.

## How To Complete This Form
To complete this form, follow the steps outlined in the "How To Complete This Form" section above.

## Field-by-Field Explanation
### Survey Questionnaire Intro
*   **Survey Questionnaire Intro** (`survey_questionnaire_intro`, text, not required): This is a free-text field where you can provide any introduction or background information about the survey.
### Who Does Justice Refer To?
*   **Who does justice refer to?** (`justice_who_does_it_apply_to`, text, not required): In this field, please specify who the justice is referring to, such as yourself, your family, or your community.
### What Type Of Question Is This?
*   **What type of question is this?** (`survey_questionnaire_question_type`, select_one, not required): Select one of the following options:
    - **Question about a person**: This type of question is about a specific person.
    - **Question about a program**: This type of question is about a specific program or service.
    - **Other (please specify)**: This type of question does not fit into the other categories.
### Who Does Justice Refer To Hint
*   **Who Does Justice Refer To Hint** (`who_does_justice_refer_to_hint`, select_multiple, not required): Select all that apply for who justice refers to, such as:
    - **You**
    - **Your family**
    - **Your community**
### Survey Question Type Hint
*   **Survey Question Type Hint** (`survey_questionnaire_question_type_hint`, text, not required): Provide any additional information that might help with the question type.
### Juvenile Justice Question Type
*   **Juvenile Justice Question Type** (`juvenile_justice_question_type`, select_one, not required): Select one of the following options:
    - **Question about a person**
    - **Question about a program**
### What Type Of Question Is This About?
*   **What type of question is this about?** (`program_question_type_hint`, text, not required): Provide any additional information about the type of question being asked, especially if it's about a program.
### Juvenile Question Type Hint
*   **Juvenile Question Type Hint** (`juvenile_question_type_hint`, text, not required): Provide any additional information or hints about the type of question being asked.
### What Question Is This About?
*   **What question is this about?** (`question_about_person_hint`, text, not required): Provide any additional information or hints about the type of question being asked, especially if it's about a person.

## Tips
*   Make sure to specify who the justice refers to and what type of question is being asked.
*   Provide any additional information or hints to help with the question type.
*   Be as specific as possible when answering the questions.
*   If you have any questions or need further clarification, contact form@gic.mx.
