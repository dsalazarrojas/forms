# Youth Empowerment Assessment - Help Guide
## Purpose
This form is designed to gather information about a youth empowerment program, which aims to provide support and resources to young people. The purpose of this form is to assess the program's effectiveness and identify areas for improvement. The assessment consists of a series of questions that cover various aspects of the program, including school survey, youth participation, services provided, assessment outcomes, and demographic information.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully and answer all the questions according to the instructions provided.
2. For multiple-choice questions, select the options that best fit your response.
3. For open-ended questions, provide detailed and clear answers.
4. Ensure that you complete all required fields.

## Field-by-Field Explanation

* **School Survey** (`school_survey`, text, required: false): This page asks about the school environment and how it affects the youth's daily life.
	+ Please provide a brief description of the current school environment.
* **Youth Participation** (`youth_participation`, text, required: false): This question asks about the level of youth participation in the program's activities.
	+ Please indicate how involved the youth are in the program activities (e.g., High, Medium, Low).
* **Services Provided by the Youth Program** (`program_services`, select_multiple, required: false): This question asks about the services provided by the youth program.
	+ Select all the services that best fit your response (e.g., After school programs, Academic support, Housing support, etc.).
* **Assessment and Outcomes** (`assessment_outcomes`, select_one, required: true): This question asks about the assessment outcomes of the program.
	+ Please select the assessment outcome that best fits your response (e.g., High, Medium, Low).
* **Open-Ended Feedback** (`feedback`, text, required: false): This is an open-ended question where you can provide any additional feedback about the program.
	+ Please provide your thoughts and suggestions for improvement.
* **Email** (`email`, email, required: false): This question asks for your email address.
	+ Please provide your email address for contact purposes.
* **Phone** (`phone`, text, required: false): This question asks for your phone number.
	+ Please provide your phone number for contact purposes.
* **Note** (`note`, note, required: false): This question allows you to provide any additional note about the assessment.
	+ Please use this field for any additional comments or thoughts.
* **Time** (`time`, time, required: false): This question asks for the time it takes to complete the program.
	+ Please provide the time in the format (HH:MM).
* **Date** (`date`, date, required: false): This question asks for the date when the program was completed.
	+ Please provide the date in the format (YYYY-MM-DD).
* **Number of Youth** (`decimal`, number, required: false): This question asks for the number of youth involved in the program.
	+ Please provide the number of youth.
* **Note 2** (`note_2`, note, required: false): This question allows you to provide any additional note about the assessment.
	+ Please use this field for any additional comments or thoughts.
