# Earthquake Risk Assessment Questionnaire - Help Guide
## Purpose
This form is used to assess the risk of a building or property in the context of earthquake resilience.

## How To Complete This Form
To complete this form, please follow these steps:

* Answer each question carefully and accurately, providing as much detail as possible.
* If you are unsure about any question, please refer to the field-by-field explanations below.

## Field-by-Field Explanation

* **What's the property location?** (`property_location`, text, optional): Please enter the address or description of the property.
* **building_type** (`building_type`, select_one, optional): Select the type of building or property:
	+ Earthquake-resistant
	+ Non-earthquake-resistant
	+ Not Applicable
* **Building Age** (`building_age`, number, optional): Enter the age of the building in years.
* **Building Height** (`building_height`, number, optional): Enter the height of the building in meters.
* **Building Designation** (`building_designation`, select_one, optional): Select whether the building has:
	+ 'True'
	+ 'False'
	+ Not Applicable
* **Building Designation 2** (`building_designation_2`, select_multiple, optional): Select the additional features or characteristics of the building:
	+ 'True'
	+ 'False'
	+ Not Applicable
* **Property Use** (`property_use`, text, optional): Describe the usage of the property.
* **Building Structure** (`building_structure`, text, optional): Describe the building structure.
* **Building Type 2** (`building_type_2`, select_one, optional): Select whether the building has:
	+ 'True'
	+ 'False'
	+ Not Applicable
* **Building Height 2** (`building_height_2`, number, optional): Enter the height of the building in meters.
* **Building Designation 3** (`building_designation_3`, select_one, optional): Select whether the building has:
	+ 'True'
	+ 'False'
	+ Not Applicable
* **Building Designation 4** (`building_designation_4`, select_multiple, optional): Select the additional features or characteristics of the building:
	+ 'True'
	+ 'False'
	+ Not Applicable

## Tips
* Please answer all questions that apply to your property.
* If you are unsure about any question, please consult with a relevant expert or authority.
* This form is for general guidance only and should not be relied upon as the sole basis for risk assessment or decision-making.
* Please review and update your answers if your property's situation changes over time.
