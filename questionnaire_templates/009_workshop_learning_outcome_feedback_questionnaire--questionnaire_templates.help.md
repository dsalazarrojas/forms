# Workshop Learning Outcome Feedback Questionnaire - Help Guide
## Purpose
The Workshop Learning Outcome Feedback Questionnaire is a form designed to gather feedback on the effectiveness of workshop sessions. It helps us to understand what we did well and what we can improve on for future sessions.

## How To Complete This Form

1. Select the relevant options for each question based on your experience with the workshop session.
2. Fill out the required fields accurately and thoroughly.
3. Ensure that you are not duplicating this form for the same workshop session.

## Field-by-Field Explanation

* **workshop_feedback_questionnaire** (Select multiple): This question asks about your overall feedback on the workshop session. Please select all that apply.
* **workshop_effectiveness** (Number): This question asks for your numerical rating of the workshop effectiveness. Rate it from 1 to 5, where 1 is poor and 5 is excellent.
* **learning_outcome_measures** (Select one): This question is about the learning outcomes of the workshop. Select one that best describes your experience.
* **participants_feedback** (Select multiple): This question asks about the feedback of the participants in the workshop. Select all that apply.
* **trainers_feedback** (Select one): This question asks about the feedback of the trainers. Select one that best describes your experience.
* **facilitators_feedback** (Select one): This question asks about the feedback of the facilitators. Select one that best describes your experience.
* **overall_rating** (Number): This question asks for your overall numerical rating of the workshop session. Rate it from 1 to 5, where 1 is poor and 5 is excellent.
* **comments** (Note): Please provide any additional comments about your experience with the workshop session.
* **email** (Email): This is your email address for communication purposes.
* **phone** (Text): This is your contact phone number for communication purposes.
* **name** (Text): This is your name for identification purposes.
* **session_id** (Text): This is the ID of the workshop session.
* **session_date** (Date): This is the date of the workshop session.
* **session_time** (Time): This is the start time of the workshop session.
* **workshop_name** (Select one): This question asks if the workshop session was successful. Select one that best describes your experience.
* **workshop_id** (Number): This is the ID of the workshop session.
* **participants** (Select multiple): This question asks about the number of participants in the workshop session. Select all that apply.
* **session_location** (Text): This is the location of the workshop session.
* **session_length** (Text): This is the length of the workshop session.
* **session_start_time** (Time): This is the start time of the workshop session.
* **session_end_time** (Time): This is the end time of the workshop session.
* **end_session** (Select one): This question asks if the workshop session ended on time. Select one that best describes your experience.
* **start_session** (Select one): This question asks if the workshop session started on time. Select one that best describes your experience.
* **session_duration** (Text): This is the duration of the workshop session.
* **form_completion_status** (Select one): This question asks about the completion status of the form. Select one that best describes your experience.
