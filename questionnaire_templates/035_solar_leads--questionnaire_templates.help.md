# Solar Leads - Help Guide
## Purpose
The Solar Leads form is used to gather information about potential customers interested in solar panels. The data collected will help the company understand their interests and tailor their sales approach.

## How To Complete This Form

1. Fill in the User Email field with the lead's email address.
2. Enter the User Name in the User Name field.
3. Add the User Phone number in the User Phone field.
4. Enter the User Address in the User Address field.
5. Select 'Yes' or 'No' for Solar System Type, indicating whether the lead is interested in solar system type A or B.
6. For Solar Panel Size, select 'Yes' or 'No' to indicate the size of the solar panel system the lead is interested in.
7. Enter the Roof Area in the Roof Area field.
8. Provide the Solar Install Date in the format DD/MM/YYYY.
9. Add any additional User Message in the User Message field.
10. Enter any relevant User Note in the User Note field.
11. Select 'Yes' or 'No' for Assigned Tool to indicate if a tool is assigned to the lead.
12. Choose 'Yes' or 'No' for Assigned User to select if a user is assigned to the lead.
13. Enter the Assigned Date for when the lead is assigned to a user in the format DD/MM/YYYY.

## Field-by-Field Explanation
* **User Email** (user_email, text, required): Enter the lead's email address for communication purposes.
* **User Name** (user_name, text, required): Enter the lead's name.
* **User Phone** (user_phone, text, required): Add the lead's phone number for follow-up calls.
* **User Address** (user_address, text, required): Enter the lead's address for location-based services.
* **Solar System Type** (solar_system_type, select_one, required): Select 'Yes' if the lead is interested in solar system type A, 'No' otherwise.
* **Solar Panel Size** (solar_panel_size, select_one, required): Select 'Yes' if the lead is interested in a large solar panel system, 'No' otherwise.
* **Roof Area** (roof_area, number, required): Enter the area of the roof in square meters for installation purposes.
* **Solar Install Date** (solar_install_date, date, required): Provide the date of solar panel installation in the format DD/MM/YYYY.
* **User Message** (user_message, text, required): Add any additional information or message for the lead.
* **User Note** (user_note, note, required): Enter any relevant notes about the lead.
* **Assigned Tool** (assigned_tool, select_one, required): Select 'Yes' if a tool is assigned to the lead, 'No' otherwise.
* **Assigned User** (assigned_user, select_one, required): Choose 'Yes' if a user is assigned to the lead, 'No' otherwise.
* **Assigned Date** (assigned_date, date, required): Enter the date when the lead is assigned to a user in the format DD/MM/YYYY.

## Tips
* Make sure to enter accurate and up-to-date information for each field.
* If you are unsure about a field's meaning, try to use your best judgment or contact the sales or marketing team for clarification.
* Do not duplicate or report false leads, as this can cause confusion and affect sales performance.
* If you have any issues or questions while filling this form, contact the sales or marketing team for assistance.

Please note that the form fields are marked as required or optional, but it is recommended to fill in all fields for a comprehensive understanding of the lead's preferences and needs.
