# Invertebrate Classification Survey - Help Guide
## Purpose
The Invertebrate Classification Survey is a tool designed to gather information about the classification of invertebrates. The form is intended to collect data on various aspects of invertebrates, including their type, habitat, size, and other relevant details.

## How To Complete This Form

1. To start, select the type of invertebrate you are classifying from the options provided in the "invertebrate_type" field.
2. Indicate the typical habitat of the invertebrate from the options provided in the "habitat" field. You can choose multiple habitats if necessary.
3. If you have more information about the habitat, you can provide additional details in the "habitat_detail" field.
4. Select the primary color of the invertebrate from the options provided in the "color" field.
5. Choose the size of the invertebrate from the options provided in the "size" field.
6. If you have more information about the characteristics that help identify the invertebrate, list them in the "characteristics" field.
7. If you have additional habitat information, provide it in the "habitat_note" field.
8. If you have more information about the characteristics of the invertebrate, provide it in the "characteristics_note" field.
9. Enter the common name of the invertebrate in the "common_name" field.
10. Enter the scientific name of the invertebrate in the "scientific_name" field.
11. Provide any taxonomy information for the invertebrate in the "taxonomy" field.
12. If you have more information about the taxonomy, provide it in the "taxonomy_note" field.

## Field-by-Field Explanation

* **invertebrate_type** (select_one): Choose the type of invertebrate from the options provided. For example, Arthropoda or Echinodermata.
* **habitat** (select_multiple): Indicate the typical habitat of the invertebrate. For example, terrestrial, aquatic, or marine. You can choose multiple habitats if necessary.
* **habitat_detail** (note): If you have more information about the habitat, provide additional details here.
* **color** (text): Select the primary color of the invertebrate.
* **size** (select_one): Choose the size of the invertebrate from the options provided. For example, small, medium, or large.
* **characteristics** (note): List any additional characteristics that help identify the invertebrate.
* **habitat_note** (note): Provide additional habitat information.
* **characteristics_note** (note): Provide more information about the characteristics of the invertebrate.
* **common_name** (text): Enter the common name of the invertebrate.
* **scientific_name** (text): Enter the scientific name of the invertebrate.
* **taxonomy** (text): Provide any taxonomy information for the invertebrate.
* **taxonomy_note** (note): Provide more taxonomy information.
