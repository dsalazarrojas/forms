# Donor Feedback Questionnaire - Help Guide
## Purpose
This form is designed to collect feedback from donors on their experiences with events or campaigns.

## How To Complete This Form
To complete this form, please answer the questions as specifically and thoroughly as possible. For each question, please select the most accurate option or provide a detailed response.

## Field-by-Field Explanation
- **Donor Feedback Form** (id: 1)
  - This is the main feedback section of the form.
  - Please provide a brief description of your experience with the event or campaign.
  - You can type your answer freely, and it will be reviewed by event organizers for feedback.
- **Event Details** (id: 2)
  - This section is for providing more context about the event or campaign.
  - Please provide any relevant details about the event or campaign that you feel are necessary for event organizers to know.
  - You can type your answer freely.
- **Feedback On Event Type** (id: 3)
  - Please select one of the following options to indicate what type of feedback you are providing:
    - Event: This feedback is specifically about the event itself.
    - Campaign: This feedback is specifically about the campaign.
    - Both: This feedback is about both the event and the campaign.
- **Event** (id: 4)
  - This field is only visible if you selected "Event" as the feedback type in the previous field.
  - Please provide any feedback about the specific event you attended.
  - You can type your answer freely.
- **Campaign** (id: 5)
  - This field is only visible if you selected "Campaign" as the feedback type in the previous field.
  - Please provide any feedback about the campaign.
  - You can type your answer freely.
- **Feedback On What Went Well** (id: 6)
  - In this field, please describe what went well during the event or campaign.
  - Try to be specific about what you liked and why.
  - You can type your answer freely.
- **Feedback On What Didn't Go Well** (id: 7)
  - In this field, please describe what didn't go well during the event or campaign.
  - Be specific about what went wrong and why it was difficult.
  - You can type your answer freely.
- **Feedback On Improvement** (id: 8)
  - In this field, please suggest ways that the event or campaign could be improved in the future.
  - Think about what would make the event or campaign more effective and enjoyable for donors.
  - You can type your answer freely.
- **Feedback On What Was Helpful** (id: 9)
  - In this field, please indicate what was helpful during the event or campaign.
  - Select all that apply:
    - Yes: This was helpful.
    - No: This was not helpful.
  - Please select both if you think something was both helpful and not helpful.
- **Additional Comments** (id: 10)
  - In this field, you can add any additional comments or feedback that you feel are not covered in the previous questions.
  - You can type your answer freely.

## Tips
- Please answer each question as thoroughly as possible.
- If a question does not apply to your experience, please mark it as "Not Applicable" or "N/A".
- If you have any additional comments or feedback, please use the "Additional Comments" field.
- Thank you for taking the time to provide detailed feedback!
