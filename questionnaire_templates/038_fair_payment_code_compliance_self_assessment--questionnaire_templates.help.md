# Fair Payment Code Compliance Self Assessment - Help Guide

## Purpose
The Fair Payment Code Compliance Self-Assessment is a tool designed to help businesses and organizations assess their compliance with the Fair Payment Code, a regulatory framework that promotes fair and transparent payment practices. This form will guide you through a series of questions and fields to help you evaluate your current policies, procedures, and practices related to payment code compliance.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review each question carefully and answer honestly to the best of your ability.
2. For select_one questions, choose one of the provided options that best describes your situation.
3. For text questions, provide clear and concise answers in the provided space.
4. Date fields are where you will input the date you have taken certain actions or completed specific tasks.
5. Time fields are where you will input the time of day you have taken certain actions or completed specific tasks.

## Field-by-Field Explanation

* **Payment Code Compliance** (`payment_code_compliance`, text, required): This field is for you to describe your understanding of the Fair Payment Code and its relevance to your business or organization.
* **Do you have a Fair Payment Code policy in place?** (`payment_code_compliance_1`, select_one, required): This question helps you determine if you have a clear policy in place to guide your payment practices. Choose 'True' if you have a policy, 'False' if you do not have a policy, or 'Other' if you have a policy but are unsure or have a custom policy.
* **Do you have a Fair Payment Code complaint procedure in place?** (`payment_code_compliance_2`, select_one, required): This question helps you determine if you have a clear procedure in place for handling payment-related complaints. Choose 'True' if you have a procedure, 'False' if you do not have a procedure, or 'Other' if you have a procedure but are unsure or have a custom procedure.
* **Do you have a Fair Payment Code policy and procedure in place?** (`payment_code_compliance_3`, select_one, required): This question helps you assess if you have a comprehensive approach to payment code compliance, with both a policy and procedure in place to guide your actions.
* **Signed Agreement** (`signed_agreement`, date, required): This field is for you to input the date you signed the agreement or policy related to the Fair Payment Code.
* **Review Date** (`review_date`, date, required): This field is for you to input the date you reviewed your Fair Payment Code policy and procedure.
* **Review Time** (`review_time`, time, required): This field is for you to input the time of day you reviewed your Fair Payment Code policy and procedure.
* **Fair Payment Compliance** (`fair_payment_compliance`, text, optional): This field is for you to provide additional information about your payment practices and how you ensure compliance with the Fair Payment Code.
* **Payment Compliance Statement** (`payment_compliance_statement`, text, optional): This field is for you to provide a statement about your payment practices and how they align with the Fair Payment Code.
* **Signed Agreement**: This is a placeholder field for any signed agreements related to payment code compliance.
* **Review Date**: This is a placeholder field for the date you reviewed your payment code compliance practices.
* **Review Time**: This is a placeholder field for the time of day you reviewed your payment code compliance practices.
