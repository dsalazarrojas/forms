# PAR Q Template - Help Guide

## Purpose
The PAR Q Template is designed to gather information about your exercise habits, including how often, how long, and how intense you exercise. This guide will walk you through each question to help you complete the form accurately.

## How To Complete This Form
1. Read each question carefully and answer based on your typical exercise habits.
2. Select the correct options that match your usual exercise frequency, duration, and intensity.
3. Make sure to answer each question honestly and based on your actual habits.
4. If a question does not apply to you, please select the "Never" option.

## Field-by-Field Explanation

	+ Choose "Light" if you exercise lightly, for example, walking or yoga.
	+ Choose "Moderate" if you exercise moderately, for example, jogging or cycling.
	+ Choose "Vigorous" if you exercise vigorously, for example, running or swimming laps.
	+ Choose "Very Vigorous" if you exercise very vigorously, for example, high-intensity strength training.
