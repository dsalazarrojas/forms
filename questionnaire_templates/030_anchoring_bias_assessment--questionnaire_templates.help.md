# Anchoring Bias Assessment - Help Guide

## Purpose
This form is designed to help assess your ability to recognize and manage anchoring bias in decision-making. By participating in this form, you will be presented with two scenarios where you will be asked to estimate a value based on an initial anchor value. You will also be asked about your background and familiarity with cognitive biases.

## How To Complete This Form
1. Start by reading the instructions and understanding the scenarios presented to you.
2. For each scenario, read the anchor value carefully and think about the context.
3. Estimate the value as accurately as possible based on the anchor value.
4. Enter your estimated value in the corresponding field.
5. Provide a brief description of your reasoning for each estimate.
6. Finally, answer questions about your background and familiarity with cognitive biases.

## Field-by-Field Explanation

* **Participant ID / Name** (`participant_id`, `text`, required): Please enter your participant ID or name for identification purposes.
* **-- Scenario 1 - Estimating Value --** (`section_scenario_1`, `note`, required): This is a brief introduction to the first scenario. Read it carefully and think about the context.
* **Consider the number 85** (`anchor_value_info`, `note`, required): This is the anchor value for the first scenario. Read it carefully and think about the context.
* **What is your estimated market value for a vintage camera?** (`your_estimated_value`, `number`, required): Estimate the market value of a vintage camera based on the anchor value. Enter a numerical value.
* **Briefly describe your reasoning for this estimate** (`reasoning_for_estimate_1`, `text`, required): Provide a brief description of your reasoning for the estimate.
* **-- Scenario 2 - Negotiation --** (`section_scenario_2`, `note`, required): This is a brief introduction to the second scenario. Read it carefully and think about the context.
* **An initial offer of $1,200 has been made for a freelance project** (`initial_offer_info`, `note`, required): This is the anchor value for the second scenario. Read it carefully and think about the context.
* **What would be your counter-offer?** (`your_counter_offer`, `number`, required): Estimate the counter-offer based on the anchor value. Enter a numerical value.
* **Briefly describe your reasoning for this counter-offer** (`reasoning_for_estimate_2`, `text`, required): Provide a brief description of your reasoning for the counter-offer.
* **-- Demographics --** (`section_demographics`, `note`, required): This is a brief introduction to the demographics section.
* **Are you familiar with cognitive biases?** (`familiar_with_cognitive_biases`, `select_one`, required): Answer with one of the following options: True, False, or Somewhat.
* **Your Professional Background** (`professional_background`, `select_one`, required): Select one of the following options: Finance, Education, Healthcare, Tech, or Other.
* **Feedback on these assessment scenarios** (`feedback_on_assessment_scenarios`, `text`, required): Provide any feedback on the assessment scenarios.
