# Respiratory Therapist Skills Checklist - Help Guide
## Purpose
The Respiratory Therapist Skills Checklist is a comprehensive evaluation tool used to assess the skills and qualifications of a respiratory therapist. This form is used to evaluate the therapist's proficiency in various skills and equipment, experience, and licensure, as well as make hiring decisions.

## How To Complete This Form

1. Review the "skills_and_equipment" section and select "Yes" for each skill or piece of equipment you possess.
2. Review the "experience_and_licensure" section and select "Yes" or "No" for your experience and licensure in each area.
3. In the "hiring_decisions" section, select "Yes" if you are being hired or "No" if you are not.
4. Fill out the "first_page" section with the date and time of the assessment or evaluation process.

* **skills_and_equipment** (required): This section asks about your proficiency in various skills and equipment.
	+ **1.** `skills_and_equipment_1` (Yes/No): Select "Yes" if you possess this skill or equipment.
	+ **2.** `skills_and_equipment_2` (Yes/No): Select "Yes" if you possess this skill or equipment.
	+ **3.** `skills_and_equipment_3` (Yes/No): Select "Yes" if you possess this skill or equipment.
	+ ...
	+ **40.** `skills_and_equipment_40` (Yes/No): Select "Yes" if you possess this skill or equipment.
* **experience_and_licensure** (required): This section asks about your experience and licensure.
	+ **1.** `experience_and_licensure_1` (Yes/No): Select "Yes" if you have this experience or licensure.
	+ **2.** `experience_and_licensure_2` (Yes/No): Select "Yes" if you have this experience or licensure.
	+ **3.** `experience_and_licensure_3` (Yes/No): Select "Yes" if you have this experience or licensure.
	+ ...
	+ **40.** `experience_and_licensure_40` (Yes/No): Select "Yes" if you have this experience or licensure.
* **hiring_decisions** (required): Select "Yes" if you are being hired or "No" if you are not.
* **first_page** (required): Fill out this section with the date and time of the assessment or evaluation process.

## Tips

* Please answer each question truthfully and accurately.
* Make sure to read each label carefully to understand what it represents.
* Select "Yes" or "No" accordingly for each field.
* Fill out the "first_page" section with the correct date and time.
