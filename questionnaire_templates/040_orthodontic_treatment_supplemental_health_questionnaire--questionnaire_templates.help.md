# Orthodontic Treatment Supplemental Health Questionnaire - Help Guide
## Purpose
The "Orthodontic Treatment Supplemental Health Questionnaire" is designed to collect essential information about a patient's medical history, current health status, and other relevant details that can impact their orthodontic treatment.

## How To Complete This Form
To complete this form, follow the steps outlined above in the "How to Complete This Form" section.

## Field-by-Field Explanation

* **Patient Info** (`patient_info`, text, required/optional): Enter your basic contact information, including your name, date of birth, and contact details.
* **Allergies** (`allergies`, select_multiple, required/false): Select "Yes" if you have any known allergies, and "No" if you do not. If you have allergies, please specify them in the "Medical History" section.
* **Medical History** (`medical_history`, text, required/false): Describe any past or present medical conditions that you are experiencing or have experienced. This includes any conditions that you are currently taking medication for or that have been diagnosed by a doctor.
* **Current Medications** (`current_medications`, select_multiple, required/false): Select "Yes" if you are currently taking any prescription or over-the-counter medications, and "No" if you are not.
* **Current Conditions** (`current_conditions`, select_multiple, required/false): Select "Yes" if you are currently experiencing any medical conditions, and "No" if you are not.
* **Past Medical History** (`past_medical_history`, select_multiple, required/false): Select "Yes" if you have experienced any medical conditions in the past, and "No" if you have not.
* **Family History** (`family_history`, select_multiple, required/false): Select "Yes" if you have a family history of any medical conditions, and "No" if you do not.
* **Medical Conditions** (`medical_conditions`, select_multiple, required/false): Select "Yes" if you are currently experiencing any medical conditions, and "No" if you are not.
* **Surgical History** (`surgical_history`, select_multiple, required/false): Select "Yes" if you have undergone any surgeries, and "No" if you have not.
* **Medications** (`medications`, select_multiple, required/false): Select "Yes" if you are currently taking any medications, and "No" if you are not.
* **Treatment History** (`treatment_history`, select_multiple, required/false): Select "Yes" if you have received any orthodontic treatments, and "No" if you have not.
* **Patient Comments** (`patient_comments`, select_multiple, required/false): Provide any additional information that you think is relevant to your orthodontic treatment.
