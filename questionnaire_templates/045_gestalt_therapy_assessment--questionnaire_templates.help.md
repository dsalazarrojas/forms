# Gestalt Therapy Assessment - Help Guide
## Purpose
This form is used to gather information about a client's experiences and perceptions during a gestalt therapy session.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all that apply for each field, as indicated by the "Select Multiple" option.
2. For text fields, provide a detailed description of the client's thoughts, feelings, and experiences.
3. If you are unsure about any field, please refer to this help guide or contact the relevant personnel for guidance.

## Field-by-Field Explanation
### Client Info
• **Client Info** (`client_info`, `select_multiple`, Required: False): Select all that apply from the list provided.

### Session Details
• **Session Details** (`session_details`, `select_multiple`, Required: False): Select all that apply from the list provided.

### Client Reflections
• **Client Reflections** (`client_reflections`, `text`, Required: False): Describe the client's thoughts, feelings, and experiences in detail.

### Session Goals
• **Session Goals** (`session_goals`, `select_multiple`, Required: False): Select all that apply from the list provided.

### Client Relationships
• **Client Relationships** (`client_relationships`, `select_multiple`, Required: False): Select all that apply from the list provided.

### Emotional Stability
• **Emotional Stability** (`emotional_stability`, `number`, Required: False): Enter the client's emotional stability rating (e.g., 1-10).

### Self-Care Activities
• **Self-Care Activities** (`self_care_activities`, `text`, Required: False): Describe the client's self-care activities.

### Coping Skills
• **Coping Skills** (`coping_skills`, `text`, Required: False): Describe the client's coping skills.

### Stressors
• **Stressors** (`stressors`, `text`, Required: False): Describe the client's stressors.

### Goals and Objectives
• **Goals and Objectives** (`goals_and_objectives`, `select_one`, Required: False): Select the relevant option from the list provided.

### Session Outcomes
• **Session Outcomes** (`session_outcomes`, `select_one`, Required: False): Select the relevant option from the list provided.

### Session Notes
• **Session Notes** (`session_notes`, `text`, Required: False): Describe the session's progress, outcomes, and any relevant notes.

### Follow-Up Plan
• **Follow-Up Plan** (`follow_up_plan`, `date`, Required: False): Enter the date for the next session.

### Next Session Date
• **Next Session Date** (`next_session_date`, `date`, Required: False): Enter the date for the next session.

### Therapist Notes
• **Therapist Notes** (`therapist_notes`, `text`, Required: False): Describe any notes or progress made during the session.

### Client Comments
• **Client Comments** (`client_comments`, `text`, Required: False): Describe the client's comments or feedback.

### Client Signature
• **Client Signature** (`client_signature`, `text`, Required: False): Client's signature or name.

### Therapist Signature
• **Therapist Signature** (`therapist_signature`, `text`, Required: False): Therapist's signature or name.
