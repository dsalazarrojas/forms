# wioa_monthly_check_in - Help Guide
## Purpose

The "wioa_monthly_check_in" form is used to collect information for the Monthly Check In process. This process is essential for tracking progress, identifying areas for improvement, and ensuring that all necessary steps have been taken for ongoing projects or tasks.

## How To Complete This Form

1. Fill in the form with the relevant information for the program or project being reviewed.
2. Enter the program name in the "Program Name" field.
3. Enter your name in the "Name" field.
4. Provide your contact number in the "Contact Number" field.
5. Enter your email address in the "Email" field.
6. Enter your phone number in the "Phone Number" field.
7. Select the location from the provided options in the "Location" field.
8. If applicable, select the date and time the task was completed in the "Date Completed" and "Time Completed" fields, respectively.
9. If applicable, enter the date the task was received in the "Date Received" field.
10. Enter any additional notes about the task or project in the "Notes" field.
11. If applicable, select any comments about the task or project from the provided options in the "Comments" field.
12. Select the tool used for the task or project from the provided options in the "Assigned Tool" field.
13. Select the category of the task or project from the provided options in the "Category" field.

## Field-by-Field Explanation

* **Program Name** (`program_name`, `text`, required/optional): Enter the name of the program or project being reviewed.
* **Name** (`name`, `text`, required/optional): Enter your name, typically the person completing the form.
* **Contact Number** (`contact_number`, `text`, required/optional): Enter your contact number, which can be a phone number or another relevant contact method.
* **Email** (`email`, `email`, required/optional): Enter your email address.
* **Phone Number** (`phone_number`, `text`, required/optional): Enter your phone number.
* **Location** (`location`, `select_one`, required/optional): Select the location where the task or project was completed from the provided options.
* **Date Completed** (`date_completed`, `date`, required/optional): Enter the date the task or project was completed.
* **Time Completed** (`time_completed`, `time`, required/optional): Enter the time the task or project was completed.
* **Date Received** (`date_received`, `date`, required/optional): Enter the date the task or project was received.
* **Notes** (`notes`, `note`, required/optional): Enter any additional notes about the task or project.
* **Comments** (`comments`, `select_multiple`, required/optional): Select any comments about the task or project from the provided options.
* **Assigned Tool** (`assigned_tool`, `select_one`, required/optional): Select the tool used for the task or project from the provided options.
* **Category** (`category`, `select_one`, required/optional): Select the category of the task or project from the provided options.
