# Child Habit Tracker Setup Form - Help Guide
## Purpose
This form is designed to help you set up a child's habit tracker. You will be asked for information about the child's family details, habits to track, tracking frequency, reward system, specific goals, and start details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the child's full name in the "Parent Full Name" field.
2. Enter the child's full name in the "Child Full Name" field.
3. Select all the habits you want to track for the child in the "Habits to Track" field.
4. Choose how often you want to track the child's progress in the "Tracking Frequency" field.
5. Select a reward system to motivate the child in the "Reward System Type" field.
6. Set a specific goal for the child for this month in the "Specific Goal for this Month" field.
7. Choose when you want tracking to begin on the "Proposed Start Date" field.
8. Decide if you want to receive weekly progress reminders via email in the "Send weekly progress reminders?" field.

## Field-by-Field Explanation
### Parent Full Name
* **Parent Full Name** (text, required): Enter the full name of the child's parent or primary account holder.

### Child Full Name
* **Child Full Name** (text, required): Enter the full name of the child, e.g., "John Doe" or "Jane Doe".

### Habits to Track
* **Habits to Track** (select multiple, required): Select all the habits you want to track for the child, such as:
	+ Brushing Teeth Twice Daily
	+ Tidying Room and Toys
	+ Reading for 20 Minutes
	+ Completing Homework on Time
	+ Eating All Vegetables

### Tracking Frequency
* **Tracking Frequency** (select one, required): Choose how often you want to track the child's progress:
	+ Daily Basis
	+ Weekdays only
	+ Weekends only

### Reward System Type
* **Reward System Type** (select one, required): Select a reward system to motivate the child:
	+ Sticker Chart
	+ Extra Screen Time
	+ Small Toy or Prize
	+ Special Family Outing

### Specific Goal for this Month
* **Specific Goal for this Month** (text, required): Set a specific goal for the child for this month, e.g., "20 days of reading".

### Proposed Start Date
* **Proposed Start Date** (date, required): Choose when you want tracking to begin.

### Send weekly progress reminders?
* **Send weekly progress reminders?** (select one, required): Decide if you want to receive weekly progress reminders via email:
	+ Yes - Email reminders
	+ No - I will track manually
