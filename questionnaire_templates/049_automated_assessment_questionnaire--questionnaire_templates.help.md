# Automated Assessment Questionnaire - Help Guide
## Purpose

The Automated Assessment Questionnaire is a tool used to evaluate an individual's performance and skills in a professional setting. It assesses various competencies such as technical proficiency, communication skills, problem-solving ability, and teamwork. The form provides a standardized and systematic way to evaluate an individual's strengths and areas for improvement.

## How To Complete This Form

1. Fill out the form with the required information for the subject being assessed.
2. Select the relevant options for each section, providing a numerical value for technical proficiency, communication skills, problem-solving ability, and teamwork.
3. Provide a brief explanation for the areas for development and key strengths observed (if applicable).
4. Select the overall meeting expectations and automated scoring fairness.
5. Indicate whether the individual is ready for promotion or certification.

## Field-by-Field Explanation

* **Subject Name**: Enter the name of the person being assessed. This is a required field.
* **Employee or Trainee ID**: Enter the internal identifier for the person being assessed. This is a required field.
* **Assessment Date**: Select the date of the assessment. This is a required field.
* **Technical Proficiency**: Rate the individual's technical proficiency on a scale of 1 to 5. This is a required field with options:
	+ 1 - Needs Improvement
	+ 2
	+ 3 - Proficient
	+ 4
	+ 5 - Expert
* **Communication Skills**: Rate the individual's communication skills on a scale of 1 to 5. This is a required field with options:
	+ 1 - Poor
	+ 2
	+ 3 - Satisfactory
	+ 4
	+ 5 - Excellent
* **Problem Solving Ability**: Rate the individual's problem-solving ability on a scale of 1 to 5. This is a required field with options:
	+ 1 - Poor
	+ 2
	+ 3 - Average
	+ 4
	+ 5 - Exceptional
* **Teamwork and Collaboration**: Rate the individual's teamwork and collaboration on a scale of 1 to 5. This is a required field with options:
	+ 1 - Lone Worker
	+ 2
	+ 3 - Cooperative
	+ 4
	+ 5 - Natural Leader
* **Areas for Development**: If applicable, provide a brief description of specific skills or behaviors that the individual should improve on. This is an optional field.
* **Key Strengths Observed**: If applicable, provide a brief description of notable positive contributions or skills observed. This is an optional field.
* **Overall Meeting Expectations**: Select the overall meeting expectations for the assessment. This is a required field with options:
	+ Exceeds Expectations
	+ Meets Expectations
	+ Below Expectations
* **Automated Scoring Fairness**: Indicate how fair you find the automated components of the assessment process. This is a required field with options:
	+ Strongly Agree
	+ Agree
	+ Neutral
	+ Disagree
* **Feedback on Assessment Process**: If you have any suggestions for improving the assessment process, provide them here. This is an optional field.
* **Ready for Promotion or Certification**: Indicate whether the individual is ready for promotion or certification. This is a required field with options:
	+ True
	+ False
	+ Pending further review
