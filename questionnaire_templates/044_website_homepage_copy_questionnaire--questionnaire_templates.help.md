# Website Homepage Copy Questionnaire - Help Guide
## Purpose
This form is used to collect information for creating a compelling hero section on a website. 

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the required fields marked as such.
2. Enter the text for the `Homepage Header Copy`.
3. Enter the URL of the `Hero Image` to be used.
4. Enter the `Alt Text` for the Hero Image.
5. Enter the text for the `Hero CTA Button`.
6. Enter the URL of the `Hero CTA Button`.
7. Select the color of the `Hero CTA Button` from the options provided.
8. Select the background color of the `Hero CTA Button`.
9. Select the text color of the `Hero CTA Button`.
10. Choose the padding for the `Hero CTA Button`.
11. Select the width for the `Hero CTA Button`.
12. Select the height for the `Hero CTA Button`.
13. Select the position of the `Hero CTA Button`.
14. Select the alignment of the `Hero CTA Button`.
15. Select the color for the `Hero CTA Button Icon` from the options provided.
16. (Optional) Enter the `Hero CTA Button Icon Width`.
17. (Optional) Enter the `Hero CTA Button Icon Height`.
18. (Optional) Select the position of the `Hero CTA Button` relative to the parent element.
19. (Optional) Select the alignment of the `Hero CTA Button` relative to the parent element.
20. (Optional) Enter the margin top for the `Hero CTA Button`.
21. (Optional) Enter the margin bottom for the `Hero CTA Button`.
22. (Optional) Enter the padding for the `Hero CTA Button`.
23. (Optional) Enter the border radius for the `Hero CTA Button`.
24. (Optional) Enter the shadow for the `Hero CTA Button`.

## Field-by-Field Explanation
* **Homepage Header Copy** (`homepage_header_copy`, `text`, required): Enter the text to be displayed on the header of the website. This text will be displayed at the top of the page.
* **Hero Image URL** (`hero_image_url`, `text`, required): Enter the URL of the image to be used as the hero image. This image will be displayed prominently on the website.
* **Hero Image Alt Text** (`hero_image_alt`, `text`, optional): Enter the alternative text for the hero image. This text will be displayed if the image cannot be loaded.
* **Hero CTA Button Text** (`hero_cta_button_text`, `text`, optional): Enter the text to be displayed on the CTA button. This text will be displayed on the CTA button.
* **Hero CTA Button URL** (`hero_cta_button_url`, `text`, required): Enter the URL to be linked to the CTA button.
* **Hero CTA Button Color** (`hero_cta_button_color`, `select_one`, required): Select the color of the CTA button from the provided options.
* **Hero CTA Button Background** (`hero_cta_button_background`, `select_one`, required): Select the background color of the CTA button from the provided options.
* **Hero CTA Button Text Color** (`hero_cta_button_text_color`, `select_multiple`, optional): Select the text color of the CTA button from the provided options.
* **Hero CTA Button Padding** (`hero_cta_button_padding`, `text`, optional): Enter the padding for the CTA button.
* **Hero CTA Button Width** (`hero_cta_button_width`, `select_one`, required): Select the width for the CTA button from the provided options.
* **Hero CTA Button Height** (`hero_cta_button_height`, `select_one`, required): Select the height for the CTA button from the provided options.
* **Hero CTA Position** (`hero_cta_position`, `select_multiple`, required): Select the position of the CTA button from the provided options.
* **Hero CTA Alignment** (`hero_cta_alignment`, `select_multiple`, required): Select the alignment of the CTA button from the provided options.
* **Hero CTA Button Icon** (`hero_cta_button_icon`, `text`, optional): Enter the icon to be displayed on the CTA button.
* **Hero CTA Button Icon Color** (`hero_cta_button_icon_color`, `select_one`, required): Select the color of the CTA button icon from the provided options.
* **Hero CTA Button Icon Width** (`hero_cta_button_icon_width`, `text`, optional): Enter the width of the CTA button icon.
* **Hero CTA Button Icon Height** (`hero_cta_button_icon_height`, `text`, optional): Enter the height of the CTA button icon.
* **Hero CTA Position Relative** (`hero_cta_position_relative`, `select_one`, optional): Select the position of the CTA button relative to the parent element.
* **Hero CTA Alignment Relative** (`hero_cta_alignment_relative`, `select_multiple`, optional): Select the alignment of the CTA button relative to the parent element.
* **Hero CTA Margin Top** (`hero_cta_margin_top`, `text`, optional): Enter the top margin for the CTA button.
* **Hero CTA Margin Bottom** (`hero_cta_margin_bottom`, `text`, optional): Enter the bottom margin for the CTA button.
* **Hero CTA Padding** (`hero_cta_padding`, `text`, optional): Enter the padding for the CTA button.
* **Hero CTA Border Radius** (`hero_cta_border_radius`, `text`, optional): Enter the border radius for the CTA button.
* **Hero CTA Shadow** (`hero_cta_shadow`, `text`, optional): Enter the shadow for the CTA button.

## Tips

* Make sure to enter the correct URL for the hero image to avoid any errors.
* If you want to display an icon on the CTA button, enter the icon name in the `Hero CTA Button Icon` field.
* If you want to change the color of the CTA button text, select the desired color in the `Hero CTA Button Text Color` field.
* Enter the correct width and height for the CTA button for proper display.
* Enter the correct margin top and bottom for the CTA button for proper display.
