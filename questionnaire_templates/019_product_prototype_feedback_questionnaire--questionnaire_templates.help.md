# Product Prototype Feedback Questionnaire - Help Guide
## Purpose
This form is designed to gather feedback from users about a product prototype. It asks for information about the product's category, description, name, and image, as well as any feedback or comments users may have.

## How To Complete This Form
To complete this form, simply follow these steps:
* Fill in each of the required fields with as much detail as possible.
* You can add any additional comments or feedback in the "feedback" field.
* Click "Submit" to save your responses.

## Field-by-Field Explanation

* **product_prototype (id: 1)**: A text input field for providing a brief description of the product prototype.
* **category (id: 2)**: A text input field for specifying the category of the product.
* **description (id: 3)**: A text input field for adding any additional details about the product.
* **product_name (id: 4)**: A text input field for specifying the name of the product.
* **feedback (id: 5)**: A text area where you can type any comments or feedback about the product.
* **product_image (id: 6)**: A text input field for providing a URL or link to an image of the product prototype.
* **product_design (id: 7)**: A text input field for describing the product's design.

## Tips
* Please provide as much detail as possible in each field.
* You can use the "feedback" field to provide any additional comments or suggestions.
* If you have any questions or need help, contact us at form@gic.mx.
