# Deadlock Understanding Survey - Help Guide
## Purpose
This form collects information about deadlocks that have occurred, including date, time, and circumstances.

## How To Complete This Form

1. Fill out the form in the following order:
	1. Page 1: First question
	2. Second question
	3. First answer
	4. First choice
	5. Second answer
	6. Third answer
	7. Date of occurrence
	8. Time of occurrence
	9. Email
	10. Phone
	11. First note
## Field-by-Field Explanation

* **First_question** (`first_question`, text, required/optional): This is the first question of the form. Please provide a brief description of the circumstances surrounding the deadlock.
* **Second_question** (`second_question`, text, required/optional): This is the second question of the form. Please provide a brief description of the circumstances surrounding the deadlock.
* **First_answer** (`first_answer`, select_one, required/optional): This question is asking you to select the most likely cause of the deadlock. Please choose one of the options provided.
* **First_choice** (`first_choice`, select_multiple, required/optional): This question is asking you to select all applicable options that contributed to the deadlock. Please select all relevant options.
* **Second_answer** (`second_answer`, select_one, required/optional): This question is asking you to select the most likely cause of the deadlock. Please choose one of the options provided.
* **Third_answer** (`third_answer`, select_one, required/optional): This question is asking you to select the most likely cause of the deadlock. Please choose one of the options provided.
* **Date_of_occurrence** (`date_of_occurrence`, date, required/optional): This is the date the deadlock occurred. Please enter the date in the format YYYY-MM-DD.
* **Time_of_occurrence** (`time_of_occurrence`, time, required/optional): This is the time the deadlock occurred. Please enter the time in the format HH:MM:SS.
* **Email** (`email`, email, required/optional): This is the email address of the user who experienced the deadlock. Please enter a valid email address.
* **Phone** (`phone`, text, required/optional): This is an optional field for users to provide their phone number.
* **First_note** (`first_note`, note, required/optional): This is an optional field for users to provide additional notes about the deadlock.

Note: The fields marked as required/optional will only be required if the field is actually marked as "required" in the form schema. The rest of the guide provides general guidance on how to complete the form, regardless of field requirement.
