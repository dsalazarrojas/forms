# Resource Development Assessment - Help Guide
## Purpose
The Resource Development Assessment form is a tool used to evaluate the development of a resource within an organization, gathering feedback and insights from various stakeholders.

## How To Complete This Form
To complete this form, please select all applicable answers for each section and fill in any necessary details.

## Field-by-Field Explanation

* **Feedback From Team Members** (`internal_feedback`, select_multiple): Select all the team members who have provided feedback on this resource.
	+ Please choose 'Yes' if team members have provided feedback on this resource.
* **Resource Adequacy** (`resource_adequacy`, number): Enter a numerical value to indicate the adequacy of the resource, with higher values indicating greater adequacy.
	+ A higher value indicates that the resource is more adequate in meeting the team's needs.
* **Challenges** (`resource_challenges`, select_one): Select the challenges that the resource is facing.
	+ Choose 'Yes' if the resource is facing any challenges.
* **Priority Areas** (`priority_areas`, select_multiple): Select all the priority areas that need attention.
	+ Choose 'Yes' for areas that are a priority.
* **Internal Communication** (`internal_communication`, select_one): Select the level of internal communication for this resource.
	+ Choose 'Yes' if internal communication is good.
* **Manager Responses** (`manager_responses`, select_one): Select the manager's responses to this resource.
	+ Choose 'Yes' if the manager has provided responses to this resource.
* **HR Responses** (`hr_responses`, select_one): Select the HR department's responses to this resource.
	+ Choose 'Yes' if HR has provided responses to this resource.
* **External Feedback** (`external_feedback`, select_one): Select the level of external feedback received for this resource.
	+ Choose 'Yes' if external feedback has been received.

## Tips
- Make sure to fill out all required fields.
- Select all applicable answers for each section.
- If you are unsure about any of the fields, please contact the resource development team for guidance.
