# Pre Market Listing Questionnaire - Help Guide
## Purpose
The Pre Market Listing Questionnaire is a form designed to collect necessary information from sellers to facilitate the listing process for their properties. Please ensure that all required fields are filled accurately to provide a complete and clear representation of the property.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, marked as "true" under the "required" field.
2. Review each field carefully and ensure the information is correct.
3. For properties with multiple features, you can add them in the "Property Features" field.

## Field-by-Field Explanation
### Seller Name (1)
* **Seller Name**: Enter the name of the property seller.
### Contact Number (2)
* **Contact Number**: Enter the contact number of the property seller, which will be used for communication and inquiries.
### Property Address (3)
* **Property Address**: Enter the physical address of the property to be listed.
### Property Type (4)
* **Property Type**: Select the type of property being listed, such as Apartment, Condo, House, or Townhouse.
### Property Status (5)
* **Property Status**: Select the current status of the property, such as Active, Bank Owned, Pre-Approval, Short Sale, or Sold. (Optional)
### Listing Price (6)
* **Listing Price**: Enter the price at which the property is to be listed.
### Asking Price (7)
* **Asking Price**: Select the price range the property is being sold at, such as $200,000 - $300,000.
### Property Features (8)
* **Property Features**: Add any additional features of the property, such as "Pool" or "Gym".
### Additional Notes (9)
* **Additional Notes**: Enter any extra information about the property that may be useful for potential buyers.
### Seller Agent (10)
* **Seller Agent**: Select the agent handling the listing, such as Agent A or Agent B. 
### Buyer Agency (11)
* **Buyer Agency**: Select the agency representing the buyer, such as Agency A or Agency C. (Optional)

## Tips
* Please ensure that all fields are filled accurately and completely.
* If unsure about any field, contact the relevant agent or contact person.
* Please review the form before submitting it to avoid any mistakes.
* If you need to add more features, use the "Property Features" field.
* If you need to add more notes, use the "Additional Notes" field.
