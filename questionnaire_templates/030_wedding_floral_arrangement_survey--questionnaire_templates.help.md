# Wedding Floral Arrangement Survey - Help Guide
## Purpose
The Wedding Floral Arrangement Survey is a form used to collect information about the couple's preferences for their wedding floral arrangement. The form is designed to help the planner understand the couple's style and needs, making it easier to create a beautiful and meaningful wedding arrangement.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each question carefully and answer according to your preferences.
2. Make sure to select all relevant options for each field.
3. Fill in any additional notes or contact information as needed.

## Field-by-Field Explanation
* **What are the couple's floral style preferences?** (`wedding_floral_styles`, `select_multiple`, required: false): 
Please select all the floral styles that best describe the couple's preferences. For example, if they prefer classic and elegant arrangements, select "Yes" for Classic.

* **What is the wedding color palette?** (`wedding_color_palette`, `select_one`, required: false): 
Choose the color palette that best matches the couple's style and preferences.

* **What are the couple's wedding arrangement needs?** (`wedding_arrangement_needs`, `select_multiple`, required: false): 
Select all the arrangement needs that apply to the couple's preferences. For example, if they want a mix of fresh and artificial flowers, select "Yes" for both.

* **What is the couple's preferred color palette?** (`couple_color_pallette_preferred`, `select_one`, required: false): 
Choose the color palette that the couple likes best.

* **Number of guests attending the wedding reception?** (`number_of_guests_attending`, `number`, required: false): 
Enter the estimated number of guests attending the wedding reception.

* **What is the wedding budget?** (`wedding_budget`, `number`, required: false): 
Enter the estimated budget for the wedding floral arrangement.

* **What type of venue is this going to be held in?** (`venue_type`, `select_multiple`, required: false): 
Select all the venue types that apply. For example, if the wedding is going to be in a garden, select "Outdoor".

* **What is the date of the wedding?** (`wedding_date`, `date`, required: false): 
Enter the date of the wedding in the format YYYY-MM-DD.

* **How do you prefer to contact the venue?** (`contact_method_venue`, `select_multiple`, required: false): 
Select all the contact methods that the couple prefers. For example, if they want to be contacted via email, select "Yes" for Email.

* **How do you prefer to contact the florist?** (`contact_method_florist`, `select_multiple`, required: false): 
Select all the contact methods that the couple prefers. For example, if they want to be contacted via phone, select "Yes" for Phone.

* **Any additional notes to the planner?** (`note_to_planner`, `note`, required: false): 
Add any additional comments or notes that the couple wants to share with the planner.

* **Email address** (`email`, `email`, required: false): 
Enter the email address of the couple.

* **Phone number** (`phone`, `text`, required: false): 
Enter the phone number of the couple.

* **Address** (`address`, `text`, required: false): 
Enter the address of the couple.

Please make sure to review each question carefully and answer according to your preferences. If you have any questions or need further clarification, feel free to ask.
