# Media Impact On Academic Performance Survey - Help Guide
## Purpose
This form is designed to collect information about the impact of media on academic performance. It asks respondents to report their media consumption habits and how they affect their grades.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by providing some basic information:
	* `student_name`: Enter your name as it appears on your academic records.
	* `student_id`: Enter your student ID number (if applicable).
2. Report your media consumption habits:
	* `media_type`: Select the type of media you consume most often (e.g., TV, Movies, Books, Games, or Online media).
	* `media_frequency`: Report how often you consume media (e.g., daily, weekly, monthly).
	* `media_hours`: Report the average number of hours you spend on media each day.
	* `media_minutes`: Report the average number of minutes you spend on media each day.
	* `media_days`: Report the average number of days you spend on media each week.
3. Report your grades:
	* `grade1` to `grade17`: Report your grades for different subjects or classes (e.g., math, science, history).

## Field-by-Field Explanation

* **Media Type** (`media_type`, select_one): Select the type of media you consume most often (e.g., TV, Movies, Books, Games, Online media).
* **Media Consumption Frequency** (`media_frequency`, number): Report how often you consume media (e.g., daily, weekly, monthly).
* **Media Consumption Time** (`media_hours`, number): Report the average number of hours you spend on media each day.
* **Media Consumption Time per Session** (`media_minutes`, number): Report the average number of minutes you spend on media each day.
* **Average Media Consumption Days Per Week** (`media_days`, number): Report the average number of days you spend on media each week.
* `grade1`: Report your grade for the first subject or class (e.g., math).
* `grade2`: Report your grade for the second subject or class (e.g., science).
* ...
* `grade17`: Report your grade for the 17th subject or class (e.g., history).
* **Student Name** (`student_name`, text): Enter your name as it appears on your academic records (optional).
* **Student ID** (`student_id`, number): Enter your student ID number (if applicable).

Note: All fields are optional unless marked as required in the form.
