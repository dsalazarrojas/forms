# Question Import Form - Help Guide

## Purpose
The Question Import Form is used to import new questions into the system. Please complete this form to add a new question, along with its associated metadata and file.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the Form ID field (if you're updating an existing form, make sure it's the correct ID).
2. Select a Category from the list to assign the question to the correct category.
3. Enter a Description of the question.
4. Optionally, upload a File associated with the question (if required for the question).

## Field-by-Field Explanation
* **Form ID (Number)** (Required/Optional): Enter a unique identifier for this question. If you're updating an existing question, ensure this ID matches the original form's ID.
* **Category (Text)** (Optional): Choose a category for this question from the list. This helps organize questions in the system.
* **Description (Text)** (Optional): Provide a brief description of the question.
* **File Upload (Text)** (Optional): Upload a file associated with this question, if applicable.

## Tips
* Ensure the Form ID is unique to prevent accidental overwriting of existing questions.
* If a form with the same ID already exists, you will be notified and cannot proceed.
* Use the Category field to group questions logically in the system.
* Use the Description field to provide context to the question.
* Use the File Upload field to attach relevant files to the question.
