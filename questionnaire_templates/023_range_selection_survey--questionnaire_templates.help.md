# Range Selection Survey - Help Guide
## Purpose
The Range Selection Survey is a form designed to collect user feedback on meeting times, temperature, productivity, range selection, and other related metrics. This form is intended to be used by a specific group of users and is not intended for general public use. It is used to collect data for internal purposes only.

## How To Complete This Form
To complete the Range Selection Survey, follow these steps:

1. Select all applicable meeting times from the list provided.
2. Choose whether you are affected by temperature.
3. Indicate whether you consider yourself productive or not.
4. If applicable, select a range for selection time.
5. Enter a numerical value for range selection temperature.
6. If applicable, enter a numerical value for range selection range.
7. Select the start and end times of a specific event.

## Field-by-Field Explanation
* **Meeting Times** (`meeting_times`, select_multiple, required: false): This field asks you to select all meeting times that apply to you. Please choose all meeting times that you are available to attend.
* **Temperature** (`temperature`, select_one, required: false): This field asks whether you are affected by temperature. Please choose 'Yes' or 'No' to indicate your response.
* **Productivity** (`productivity`, select_multiple, required: false): This field asks you to indicate whether you consider yourself productive or not. Please select all options that apply.
* **Range Selection Time** (`range_selection_time`, time, required: false): This field asks you to select a specific time for range selection. Please choose a valid time in 24-hour format.
* **Range Selection Temperature** (`range_selection_temp`, number, required: false): This field asks you to enter a numerical value for range selection temperature. Please enter a whole number.
* **Range Selection Range** (`range_selection_range`, number, required: false): This field asks you to enter a numerical value for range selection range. Please enter a whole number.
* **Start Time** (`start_time`, time, required: false): This field asks you to select the start time of a specific event. Please choose a valid time in 24-hour format.
* **End Time** (`end_time`, time, required: false): This field asks you to select the end time of a specific event. Please choose a valid time in 24-hour format.

## Tips
* Please answer all questions truthfully and completely.
* If you are unsure about any question, please ask for clarification.
* You can skip fields that do not apply to you.
* Please note that this form is for internal use only and will not be shared publicly.
