# Foundation Assessment Survey - Help Guide
## Purpose
The Foundation Assessment Survey is a tool designed to gather information about a building's foundation. This form helps assess the condition, type, and other relevant details of a building's foundation.

## How To Complete This Form
- To complete this form, please answer each question honestly and accurately.
- Make sure to fill out all required fields.
- If a field is not applicable, please select "N/A" or "Not Applicable" or leave it blank.
- If you are unsure about any of the questions or answers, please ask for clarification before proceeding.

## Field-by-Field Explanation

* **Foundation Assessment** (`foundation_assessment`, Text, Optional): This is the main description of the building's foundation. Please provide a brief description of the foundation's condition.
* **Building Type** (`building_type`, Select One, Optional): This field asks for the type of building (Commercial, Residential, Industrial).
* **Address** (`address`, Text, Optional): Enter the address of the building for which you are assessing the foundation.
* **Location Map URL** (`location_map_url`, Text, Optional): If you have a URL for a location map that can help identify the building's location, please enter it here.
* **Foundation Type** (`foundation_type`, Select Multiple, Optional): This field asks for the type of foundation (Slab-on-grade, Full Basement, Crawlspace).
* **Height** (`foundation_height`, Number, Optional): Enter the height of the foundation in feet.
* **Width** (`foundation_width`, Number, Optional): Enter the width of the foundation in feet.
* **Length** (`length`, Number, Optional): Enter the length of the foundation in feet.
* **Foundation Condition** (`foundation_condition`, Select One, Optional): Assess the condition of the foundation as Good, Fair, or Poor.
* **Foundation Condition Comment** (`foundation_condition_comment`, Text, Optional): If you want to provide more details about the foundation's condition, please add them here.
* **Comments** (`foundation_comments`, Text, Optional): Add any other comments that might be helpful for the assessment.
* **Building Age** (`building_age`, Select Multiple, Optional): Assess the age of the building as 0-5 Years, 5-10 Years, 10-20 Years, 20-30 Years, or more.
* **Inspector Name** (`inspector_name`, Text, Optional): Enter the name of the person who performed the assessment.
* **Inspector Phone** (`inspector_phone`, Text, Optional): Enter the phone number of the inspector who performed the assessment.
* **Inspector Email** (`inspector_email`, Text, Optional): Enter the email of the inspector who performed the assessment.
* **Inspector License** (`inspector_license`, Text, Optional): Enter the license number of the inspector who performed the assessment.
* **Inspector Company** (`inspector_company`, Text, Optional): Enter the name of the company that employed the inspector who performed the assessment.
* **Comments** (`inspector_comments`, Text, Optional): Add any comments that might be helpful for the assessment.
* **Submit** (`submit`, Text, Optional): This button will save the assessment when clicked.

Note: This form is designed to gather information for internal use. Please do not attempt to submit this form with false or inaccurate information.
