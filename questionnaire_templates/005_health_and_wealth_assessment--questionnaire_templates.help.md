# Health And Wealth Assessment - Help Guide
## Purpose
The Health and Wealth Assessment form is a comprehensive evaluation tool designed to assess a person's wellbeing, finances, goals, and time management. It is intended to be used by professionals in various fields, such as healthcare, finance, or counseling, to gain a better understanding of an individual's current situation and provide guidance or support.

## How To Complete This Form
To complete this form, follow these steps:

1. Read each question carefully and answer according to your current situation.
2. Select the most accurate response for each multiple-choice question.
3. Enter numerical values for questions that require time inputs.
4. Add any additional comments or information as needed in the "Follow-up" section.

## Field-by-Field Explanation
### 1. **Wellbeing** (`Wellbeing`, `select_multiple`, optional):
	* This question assesses your overall wellbeing status. Select all applicable options that describe your current wellbeing situation.
	* Options: 'Yes', 'No'

### 2. **Finances** (`Finances`, `select_multiple`, optional):
	* This question evaluates your current financial status. Select all applicable options that describe your financial situation.
	* Options: 'Yes', 'No'

### 3. **Goals** (`Goals`, `text`, optional):
	* This question is intended to understand your current goals and objectives. Provide a brief description of your goals.

### 4. **Income** (`Income`, `number`, optional):
	* This question asks for your current monthly income.

### 5. **Expenses** (`Expenses`, `number`, optional):
	* This question asks for your monthly expenses.

### 6. **Assets** (`Assets`, `number`, optional):
	* This question asks for your current assets.

### 7. **Wellbeing Goals** (`Wellbeing Goals`, `select_one`, optional):
	* This question evaluates whether you have wellbeing goals. Select 'Yes' if you have wellbeing goals.

### 8. **Financial Goals** (`Financial Goals`, `select_one`, optional):
	* This question evaluates whether you have financial goals. Select 'Yes' if you have financial goals.

### 9. **Financial Status** (`Financial Status`, `select_one`, optional):
	* This question asks for your current financial status. Select 'Active' if you are currently active and managing your finances well, or 'Inactive' if you are not.

### 10. **Follow-up** (`Follow-up`, `note`, optional):
	* This section is intended for any additional comments or information that you would like to provide.

### 11-24. **Wellbeing Scale** (`Wellbeing Scale 1-15`, `time`, optional):
	* These questions ask for the amount of time spent on various wellbeing-related activities. Select the number of hours spent on each activity per week.
	* Examples: exercise, meditation, reading, etc.

### 25. **Wellbeing Scale 16** (`Wellbeing Scale 16`, `time`, optional):
	* This question asks for the amount of time spent on other wellbeing-related activities. Select the number of hours spent per week.
	* This is a catch-all question for any other wellbeing-related activities not listed previously.
