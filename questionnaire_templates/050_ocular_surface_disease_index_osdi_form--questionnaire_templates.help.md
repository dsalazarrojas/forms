# Ocular Surface Disease Index (OSDI) Form - Help Guide

## Purpose

The Ocular Surface Disease Index (OSDI) Form is designed to collect clinical data for patients suffering from ocular surface disease. This form helps healthcare professionals gather detailed information about the patient's symptoms, medical history, and treatment progress.

## How To Complete This Form

1. Please select the "Patient Name" field and enter the patient's name as it appears in the medical records.
2. In the "Age" field, enter the patient's age in years.
3. For "Sex", select the patient's sex from the options provided (Male, Female, Other).
4. If applicable, select the duration of the patient's symptoms in the "Symptoms Duration" field.
5. For "Eye Opening Pain", "Redness", "Stringiness", "Tear Distribution", "Tearing", "Fluctuation with Puffing", and "Fluctuation with Puffing Duration" fields, select the level of severity from the provided options (None, Some, A little, A moderate amount, A lot).
6. Select the "Photophobia" and "Photobobia" fields as per the patient's symptoms.
7. For "Pain with Puffing", "Tearing with Puffing", "Photophobia Duration", and "Pain with Photophobia" fields, select the level of severity from the provided options (None, Some, A lot).
8. In "Photophobia Description" and "Photobia Description" fields, enter a brief description of the patient's symptoms.
9. Ensure to fill out all required fields to complete the form.

## Field-by-Field Explanation

* **Patient Name** (patient_name, text, required): Enter the patient's name as it appears in the medical records.
* **Age** (age, number, required): Enter the patient's age in years.
* **Sex** (sex, select_one, required): Select the patient's sex from the options provided (Male, Female, Other).
* **Symptoms Duration** (symptoms_duration, time, optional): If applicable, select the duration of the patient's symptoms.
* **Eye Opening Pain** (eye_opening_pain, number, optional): Select the level of eye opening pain from the provided options (None, Some, A lot).
* **Redness** (redness, number, optional): Select the level of redness from the provided options (None, Some, A lot).
* **Stringiness** (stringiness, select_multiple, optional): Select the level of stringiness from the provided options (None, Some, A lot).
* **Tear Distribution** (tear_distribution, select_multiple, optional): Select the tear distribution from the provided options (Central, Peripheral, Both).
* **Tearing** (tearing, select_one, optional): Select the level of tearing from the provided options (None, Some, A lot).
* **Fluctuation with Puffing** (fluctuation, select_multiple, optional): Select the level of fluctuation with puffing from the provided options (None, Some, A little, A moderate amount, A lot).
* **Fluctuation with Puffing Duration** (fluctuation_with_puffing_duration, time, optional): Select the duration of fluctuation with puffing.
* **Photophobia** (photophobia, select_multiple, optional): Select the level of photophobia from the provided options (None, Some, A lot).
* **Photobia Description** (photobia_description, note, optional): Enter a brief description of the patient's photophobia symptoms.
* **Pain with Puffing** (pain_with_puffing, select_one, optional): Select the level of pain with puffing from the provided options (None, Some, A lot).
* **Tearing with Puffing** (tearing_with_puffing, select_one, optional): Select the level of tearing with puffing from the provided options (None, Some, A lot).
* **Tearing with Puffing Duration** (tearing_with_puffing_duration, time, optional): Select the duration of tearing with puffing.
* **Photobobia** (photobobia, select_multiple, optional): Select the level of photobia from the provided options (None, Some, A lot).
* **Tearing** (tearing, select_one, optional): Select the level of tearing from the provided options (None, Some, A lot).
* **Fluctuation with Puffing** (fluctuation_with_puffing, select_multiple, optional): Select the level of fluctuation with puffing from the provided options (None, Some, A little, A moderate amount, A lot).
* **Fluctuation with Puffing Duration** (fluctuation_with_puffing_duration, time, optional): Select the duration of fluctuation with puffing.
* **Redness** (redness, number, optional): Select the level of redness from the provided options (None, Some, A lot).
* **Tearing with Fluctuation** (tearing_with_fluctuation, select_multiple, optional): Select the level of tearing with fluctuation from the provided options (None, Some, A lot).
* **Pain with Photophobia** (pain_with_photophobia, select_one, optional): Select the level of pain with photophobia from the provided options (None, Some, A lot).
* **Photophobia Duration** (photophobia_duration, time, optional): Select the duration of photophobia.
* **Photophobia Description** (photophobia_description, note, optional): Enter a brief description of the patient's photophobia symptoms.
