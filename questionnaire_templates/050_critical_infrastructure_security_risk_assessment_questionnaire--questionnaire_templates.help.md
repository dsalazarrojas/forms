# Critical Infrastructure Security Risk Assessment Questionnaire - Help Guide
## Purpose
The purpose of this form is to assess and document potential risks to critical infrastructure sites.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the general information section with the facility's location, name, and other relevant details.
2. Evaluate the site's risk level and identify any security concerns.
3. Document the risk assessment date, frequency, and status.
4. Provide comments and suggestions for improvement.

## Field-by-Field Explanation

* **Facility Location** (`facility_location`, text, optional): Enter the location of the facility.
* **Facility Name** (`facility_name`, text, optional): Enter the name of the facility.
* **Facility ID** (`facility_id`, number, optional): Enter the facility's ID number.
* **Site ID** (`site_id`, number, optional): Enter the site ID number.
* **Risk Assessment Date** (`risk_assessment_date`, date, optional): Enter the date of the risk assessment.
* **Risk Assessment Frequency** (`risk_assessment_frequency`, text, optional): Evaluate how often the site's risks are assessed.
* **Risk Assessment Status** (`risk_assessment_status`, select_one, optional): Select the current risk assessment status (New, Existing, or Not Assessed).
* **Risk Assessment Comments** (`risk_assessment_comments`, text, optional): Provide any comments or suggestions for improvement.
* **Site Contacts** (`site_contacts`, text, optional): Enter contact information for the site.
* **Contact Names** (`contact_names`, text, optional): Enter contact names.
* **Security Concerns** (`security_concerns`, text, optional): Identify any security concerns.
* **Risk Level** (`risk_level`, select_multiple, optional): Select the level of risk (Critical, High, Medium, Low, None).
* **Report ID** (`report_id`, number, optional): Enter the report ID number.
* **Critical Infrastructure Security Risks** (`critical_infrastructure_security_risks`, text, optional): Identify potential security risks to the site.
* **Safeguards** (`safeguards`, text, optional): Evaluate the safeguards in place to mitigate risks.
* **Site Safeguards** (`site_safeguards`, text, optional): Enter site-specific safeguards.
* **Site Safeguard** (`site_safeguard`, select_multiple, optional): Select the type of safeguard (Physical, Operational, Cyber, None).
* **Site Risks** (`site_risks`, text, optional): Identify potential site-specific risks.
* **Security Measures** (`security_measures`, text, optional): Evaluate the security measures in place.
* **Control Measures** (`control_measures`, text, optional): Evaluate the control measures in place.
* **Security Controls** (`security_controls`, text, optional): Enter security controls.
* **Control Frequency** (`control_frequency`, text, optional): Evaluate the control frequency.
* **Control Status** (`control_status`, select_one, optional): Select the status of controls (New, Existing, Not Controlled).
* **Controls** (`controls`, text, optional): Enter control information.
* **Comments** (`comments`, text, optional): Provide any additional comments.
