# Lighting Control Preferences - Help Guide
## Purpose
This form is designed to collect information about lighting control preferences.

## How To Complete This Form
1. Please select the "Lighting Control Needs" option that best describes your needs:
	* If you need to control lighting in a residential setting, select "Residential".
	* If you need to control lighting in a commercial setting, select "Commercial".
	* If you need to control lighting in an industrial setting, select "Industrial".
2. Choose the level of automation you require:
	* If you need high automation, select "High".
	* If you need medium automation, select "Medium".
	* If you need low automation, select "Low".
3. Select the lighting control methods you need:
	* If you need to control lighting based on motion detection, select "Motion".
	* If you need to control lighting based on dimming, select "Dimming".
	* If you need to control lighting based on brightness, select "Brightness".
4. Enter the type of control system you plan to use:
	* Please provide the name of the control system you plan to use.
5. Add any additional notes about your lighting control preferences:
	* Please provide any additional information about your needs or requirements.

## Field-by-Field Explanation
* **Lighting Control Needs**: This field is used to specify the level of lighting control you need.
* **Facility**: This field is used to select the type of facility where lighting control is needed.
* **Automation Level**: This field is used to select the level of automation required for lighting control.
* **Lighting Control**: This field is used to select the types of lighting control methods needed.
* **Control System**: This field is used to enter the type of control system you plan to use.
* **Notes**: This field is used to provide any additional information about your lighting control preferences.

## Tips
* Please be as specific as possible when filling out this form.
* If you need help or have questions, contact us at form@gic.mx.
