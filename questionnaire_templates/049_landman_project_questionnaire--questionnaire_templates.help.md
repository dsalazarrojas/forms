# Landman Project Questionnaire - Help Guide

## Purpose
The Landman Project Questionnaire is used to collect information about a landman project, including project details, personnel involved, and contact information. This form is designed to provide a structured and organized way to gather essential data for project management and coordination.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the project name in the field provided.
2. Provide a brief description of the project.
3. Select the project category (Oil, Gas, or Mineral).
4. Enter the location of the project.
5. Enter your Landman name (if applicable).
6. Choose your role in the project (Manager, Crew, or Staff).
7. Enter your phone number.
8. Enter your email address.
9. Select your date of birth.
10. Enter the start date of the project.
11. Enter the end date of the project (if known).
12. Add any additional notes about the project.
13. Enter the name of the manager (if applicable).
14. Enter the manager's email address (if applicable).
15. Enter the manager's phone number (if applicable).
16. List the team members involved in the project (if applicable).

## Field-by-Field Explanation
### 1. Project Name
* **Project Name** (`landman_project_questionnaire`, text, optional): Enter the name of the project.

### 2. Project Description
* **Project Description** (`project_description`, text, optional): Provide a brief description of the project.

### 3. Project Category
* **Project Category** (`project_category`, select_one, optional): Select the project category from the options (Oil, Gas, Mineral).

### 4. Location
* **Location** (`location`, text, optional): Enter the location of the project.

### 5. Landman Name
* **Landman Name** (`landman_name`, text, optional): Enter your Landman name if applicable.

### 6. Role
* **Role** (`role`, select_multiple, optional): Choose your role in the project from the options (Manager, Crew, Staff).

### 7. Phone Number
* **Phone Number** (`phone_number`, text, optional): Enter your phone number.

### 8. Email
* **Email** (`email`, email, optional): Enter your email address.

### 9. Date of Birth
* **Date of Birth** (`date_of_birth`, date, optional): Select your date of birth.

### 10. Start Date
* **Start Date** (`start_date`, date, optional): Enter the start date of the project.

### 11. End Date
* **End Date** (`end_date`, date, optional): Enter the end date of the project (if known).

### 12. Notes
* **Notes** (`notes`, note, optional): Add any additional notes about the project.

### 13. Manager Name
* **Manager Name** (`manager_name`, text, optional): Enter the name of the manager (if applicable).

### 14. Manager Email
* **Manager Email** (`manager_email`, email, optional): Enter the manager's email address (if applicable).

### 15. Manager Phone Number
* **Manager Phone Number** (`manager_phone_number`, text, optional): Enter the manager's phone number (if applicable).

### 16. Team Members
* **Team Members** (`team_members`, text, optional): List the team members involved in the project (if applicable).

**Tips**

* Make sure to fill out all required fields (if any) and provide accurate information to ensure the project details are up-to-date and correct.
* If you are unsure about any field, feel free to ask for assistance or clarification.
