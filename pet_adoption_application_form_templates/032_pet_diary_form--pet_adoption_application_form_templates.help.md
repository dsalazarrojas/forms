# Pet Diary Form - Help Guide
## Purpose
The Pet Diary Form is a tool for collecting and recording essential information about pets in our shelter.

## How To Complete This Form
- Please fill out this form with the most up-to-date and accurate information about the pet.
- If you're unsure about any field, please contact your supervisor or colleague for guidance.
- If you have filled out this form for a pet before, please ensure you're not duplicating any previous entry.

## Field-by-Field Explanation
* **Pet Name** (`pet_name`, text, required): Enter the pet's name, if known. If not, please leave this field blank.
* **Pet Breed** (`pet_breed`, select_one, required): Select the pet's breed from the options provided.
* **Pet Type** (`pet_type`, select_one, required): Choose the type of pet (Dog, Cat, or Other).
* **Pet Color** (`pet_color`, text, required): Enter the pet's color or description (e.g., brown, black, or calico).
* **Pet Weight** (`pet_weight`, number, required): Enter the pet's weight in pounds or kilograms.
* **Pet Health** (`pet_health`, select_multiple, required): Select the pet's current health status (Healthy, Slightly Ill, or Very Ill).
* **Pet Medication** (`pet_medication`, text, required): Enter any medication the pet is currently taking, if applicable.
* **Additional Notes** (`pet_diary_form`, text, required): Please add any additional information about the pet, such as their personality, behavioral notes, or any special instructions.
