# Fundraising Event Details Form - Help Guide
## Purpose
The Fundraising Event Details Form is used to create a new fundraising event. Please fill out the form with the requested information to help us track and promote your event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the **Event Details** section with a brief description of the event.
2. Enter the **Fundraising Goal** amount, which is the target amount to be raised for the event.
3. Enter the **Target Amount**, which is the total amount to be raised from the event.
4. Provide a **Goal Description** that outlines the purpose and goals of the event.
5. Enter the **Start Date** and **End Date** of the event.
6. Enter the **Event Time** of the event.
7. Enter the **Event Location**, where the event will take place.
8. Enter the **Event Link** if the event has a website or social media page.
9. Add any additional **Event Notes** that will help us understand the event.
10. Enter the **Contact Name** and **Contact Email** for the event organizer.
11. Enter the **Contact Phone** number for the event organizer.
12. Enter the **Contact Website** for the event organizer.

## Field-by-Field Explanation

* **Event Details**: A brief description of the event. Please provide a short paragraph explaining what the event is about.
* **Fundraising Goal**: The target amount to be raised for the event.
* **Target Amount**: The total amount to be raised from the event.
* **Goal Description**: A brief description of the event's purpose and goals.
* **Start Date**: The date when the event will start.
* **End Date**: The date when the event will end.
* **Event Time**: The time when the event will take place.
* **Event Location**: The location where the event will occur.
* **Event Link**: A link to the event's website or social media page.
* **Event Notes**: Additional information about the event.
* **Contact Name**: The name of the event organizer.
* **Contact Email**: The email address of the event organizer.
* **Contact Phone**: The phone number of the event organizer.
* **Contact Website**: The website of the event organizer.

## Tips
- Please make sure to fill out all required fields to ensure that your event is properly registered.
- If you are unsure about any field, please contact us for clarification.
- This form is intended to be completed by the event organizer, not by event participants or supporters.
- Please review your submission before submitting to ensure that all information is accurate.
