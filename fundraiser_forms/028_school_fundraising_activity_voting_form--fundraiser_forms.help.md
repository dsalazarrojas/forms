# School Fundraising Activity Voting Form - Help Guide
## Purpose
This form is used to create and manage fundraising activities for your school. Please use it to collect data for internal purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the fundraising activity in the **School Fundraising Activity Voting Form** field.
2. Provide a description of the activity in the **Description** field.
3. Select a category for the activity from the **Category** options: **Fundraiser Forms** or **Other**.
4. If you selected **Fundraiser Forms** as the category, enter a subcategory in the **Fundraiser Forms** field.
5. Enter your email address in the **Email** field.
6. Input your phone number in the **Phone** field.
7. Select a date for the event in the **Date** field.
8. Select a time for the event in the **Time** field.
9. Enter any additional notes about the activity in the **Additional Note** field.

## Field-by-Field Explanation

* **School Fundraising Activity Voting Form** (`form_title`, text, not required): This is the title of the fundraising activity. Enter a brief and descriptive title for the activity.
* **Description** (`form_description`, text, not required): This field is used to provide a detailed description of the activity.
* **Category** (`form_category`, select one, not required): Select a category for the activity. You can choose between **Fundraiser Forms** or **Other**.
* **Fundraiser Forms** (`form_category_value`, text, not required): If you selected **Fundraiser Forms** as the category, enter a subcategory in this field.
* **Email** (`form_email`, email, not required): Enter your email address where you can be reached.
* **Phone** (`form_phone`, text, not required): Input your phone number where you can be reached.
* **Date** (`form_date`, date, not required): Select a date for the event.
* **Time** (`form_time`, time, not required): Select a time for the event.
* **Note** (`form_note`, note, not required): Enter any additional notes about the activity.
* **Additional Note** (`form_note_2`, note, not required): Enter any additional notes about the activity.
* **Submit** (`form_submit`, text, not required): This is a submit button, click it to complete the form.
* **Cancel** (`form_cancel`, text, not required): This is a cancel button, click it to discard your input and start over.

Note: Some fields are not required, but it's recommended to fill in as much information as possible to make it easier for school administrators to track and manage your fundraising activities.
