# Fundraiser Information Form - Help Guide
## Purpose
This form is used to collect information about fundraising events, such as event name, date, location, and contact person. It is intended for event organizers to submit details about their event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Name field with a brief description of the event.
2. Enter the Event Date in the format `MM/DD/YYYY` (e.g., 01/15/2024).
3. Enter the Event Time in the format `HH:MM AM/PM` (e.g., 02:00 PM).
4. Enter the Event Location, which should be a short description of the venue or site where the event will take place.
5. If the event has a contact person, enter their name and title (if applicable) in the Contact Person field.
6. Select the type of event from the options provided (Fundraiser, Charity, or Sponsorship).
7. Optionally, you can enter the Event Goal, which should be a number representing the financial goal for the event.

## Field-by-Field Explanation

* **Event Name** (`event_name`, `text`, required: false): A short description of the event.
* **Event Date** (`event_date`, `date`, required: false): Enter the date of the event in the format `MM/DD/YYYY`.
* **Event Time** (`event_time`, `time`, required: false): Enter the time of the event in the format `HH:MM AM/PM`.
* **Event Location** (`event_location`, `text`, required: false): A short description of the venue or site where the event will take place.
* **Contact Person** (`contact_person`, `text`, required: false): If there is a contact person associated with the event, enter their name and title (if applicable).
* **Event Type** (`event_type`, `select_multiple`, required: false): Select the type of event from the options provided (Fundraiser, Charity, or Sponsorship).
* **Fundraiser Name** (`fundraiser_name`, `text`, required: false): Optionally, enter the name of the fundraiser.
* **Event Goal** (`event_goal`, `number`, required: false): Enter a financial goal for the event, if applicable.

## Tips
* Make sure to fill in all relevant fields to provide a complete picture of the event.
* If you're unsure about any field, leave it blank and someone will follow up with you for clarification.
* If you're filling out this form for an event that has already been submitted, please do not resubmit the form.
