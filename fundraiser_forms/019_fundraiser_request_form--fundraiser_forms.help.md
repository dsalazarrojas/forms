# Fundraiser Request Form - Help Guide
## Purpose
The Fundraiser Request Form is used to determine if a project requires a fundraiser event. This form helps the team assess whether a project needs to be funded and gather information to make an informed decision.

## How To Complete This Form
To complete this form, follow these steps:

1. Select all the projects that you think require a fundraiser event.
2. Choose a category for your fundraiser request from the options provided.
3. Provide a brief description of the project and its purpose.
4. Enter the contact person's name and details.

## Field-by-Field Explanation

* **Fundraiser Request Form**: This section is a multiple-choice field where you can select one or more projects that require a fundraiser event. Choose all the projects that apply.
* **Category**: Select the category for your fundraiser request from the options provided. This will help us understand the type of fundraiser event needed.
* **Description**: Provide a brief description of the project and its purpose. Try to be as clear and concise as possible.
* **Contact Person**: Enter the name and details of the person we should contact for more information about the project. This will help us get in touch with the right person if we need more information.

## Tips
* Make sure to select only the projects that require a fundraiser event.
* If you are unsure about the category, choose "Fundraiser Forms" as it is the most suitable option.
* Keep the description brief and focused on the project's purpose.
* Ensure that the contact person is reachable and able to provide more information about the project.
