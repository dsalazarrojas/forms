# Fundraising Event Time Off Form - Help Guide

## Purpose
The Fundraising Event Time Off Form is used to create or modify a fundraising event, including defining the event details, specifying the time off period, and designating the approver and their contact information.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the event title and description.
2. Select the start and end dates of the time off period.
3. Choose the time off time.
4. Specify the reason for the time off.
5. Choose the approval status.
6. Select the event category (Charity or Donation).
7. Select the approver (HR or Manager).
8. Enter the approver's email and phone number.
9. Add any additional approver notes.
10. Enter the employee's ID.
11. Enter the event ID.
12. Add any additional approver comments.

## Field-by-Field Explanation

* **Fundraising Event Time Off Form** (`title`, `text`, required: false): Enter the title of the fundraising event.
* **Event Description** (`event_description`, `text`, required: false): Briefly describe the event and its purpose.
* **Time Off Start Date** (`time_off_start_date`, `date`, required: false): Select the start date of the time off period.
* **Time Off End Date** (`time_off_end_date`, `date`, required: false): Select the end date of the time off period.
* **Time Off Time** (`time_off_time`, `time`, required: false): Choose the time off time.
* **Reason** (`reason`, `text`, required: false): Specify the reason for the time off.
* **Approval Status** (`approval_status`, `select_one`, required: false): Choose the approval status (Approved, Denied, Pending).
* **Event Category** (`event_category`, `select_one`, required: false): Select the event category (Charity or Donation).
* **Approver** (`approver`, `select_one`, required: false): Choose the approver (HR or Manager).
* **Approver Email** (`approver_email`, `email`, required: false): Enter the approver's email address.
* **Approver Phone** (`approver_phone`, `text`, required: false): Enter the approver's phone number.
* **Approver Notes** (`approver_notes`, `note`, required: false): Add any additional approver notes.
* **Employee ID** (`employee_id`, `text`, required: false): Enter the employee's ID.
* **Event ID** (`event_id`, `text`, required: false): Enter the event ID.
* **Approver Comments** (`approver_comments`, `text`, required: false): Add any additional approver comments.

Note: All fields are optional, but are required for the form to be submitted and reviewed by the approver.
