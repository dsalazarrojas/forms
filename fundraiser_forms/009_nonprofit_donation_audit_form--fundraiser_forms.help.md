# Nonprofit Donation Audit Form - Help Guide
## Purpose
This form is a collection of questions to gather information from donors about their nonprofit donation. It is intended to be completed by donors and will help the nonprofit organization track and manage their donations.

## How To Complete This Form
- To complete this form, please follow these steps:
  1. Fill in the required information, marked with an asterisk (\*).
  2. Select the relevant options for each field.
  3. Make sure to review your submission before submitting the form.

## Field-by-Field Explanation
- **Donor Info** (`donor_info`, Text, Optional): Enter any additional information about the donor, such as their name, address, or any other relevant details.
- **Donation Amount** (`donation_amount`, Number, Optional): Enter the amount of the donation, if applicable.
- **Donation Date** (`donation_date`, Date, Optional): Enter the date of the donation.
- **Gift Frequency** (`gift_frequency`, Select One, Required): Choose whether the donation is a one-time gift or recurring.
  - Select "One-Time" if the donation is a single payment.
  - Select "Recurring" if the donation will be ongoing.
- **Gift Type** (`gift_type`, Select Multiple, Required): Choose the type of gift:
  - Select "Donation" for a monetary donation.
  - Select "Other (Specify)" for any other type of gift, and enter a description in the "Notes" field.
- **Donor Email** (`donor_email`, Email, Optional): Enter the donor's email address, if applicable.
- **Donor Phone** (`donor_phone`, Text, Optional): Enter the donor's phone number, if applicable.
- **Donation Frequency** (`donation_frequency`, Select One, Required): Choose whether the donation is one-time or recurring.
  - Select "One-Time" if the donation is a single payment.
  - Select "Recurring" if the donation will be ongoing.
- **Notes** (`notes`, Note, Optional): Enter any additional information or notes about the donation.
- **Assigned Tool** (`assigned_tool`, Text, Optional): Enter the tool or resource assigned to the donation, if applicable.

## Tips
- Make sure to fill in all required fields.
- Double-check your information before submitting the form.
- If you are unsure about any field, contact the nonprofit organization for clarification.
