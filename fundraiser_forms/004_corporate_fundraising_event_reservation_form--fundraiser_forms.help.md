# corporate_fundraising_event_reservation_form - Help Guide
## Purpose
The corporate fundraising event reservation form is used to collect information from individuals reserving a spot for a corporate fundraising event within an organization.

## How To Complete This Form

1. To start, select the "Category" field and choose one of the available categories.
2. Fill in your First Name, Last Name, and Email address.
3. If you have an organization, please provide it in the field.
4. Select any meal preferences you have (Breakfast, Lunch, or Dinner).
5. If you have any special requests, you can provide them in this field.
6. Finally, provide your contact Phone number.

## Field-by-Field Explanation

* **Category** (`category`, select_one, required): Choose one of the available categories for the event.
* **First Name** (`first_name`, text, optional): Your first name as it should be displayed on event materials.
* **Last Name** (`last_name`, text, optional): Your last name as it should be displayed on event materials.
* **Email** (`email`, email, optional): Your contact email address for event follow-up and updates.
* **Organization** (`organization`, text, optional): Your organization name if applicable.
* **Meal Preferences** (`meal_preferences`, select_multiple, optional): Select any meal preferences you have for the event (Breakfast, Lunch, or Dinner).
* **Special Requests** (`special_requests`, text, optional): If you have any special requests or requirements, please let us know here.
* **Phone** (`phone`, text, optional): Your contact phone number for event follow-up and updates.

## Tips
* Please ensure that you select the correct category for the event to ensure accurate event organization and follow-up.
* If you have any special requests, please provide them in the "Special Requests" field for us to note.
