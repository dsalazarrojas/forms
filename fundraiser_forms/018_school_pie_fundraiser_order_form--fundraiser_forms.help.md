# School Pie Fundraiser Order Form - Help Guide
## Purpose
The School Pie Fundraiser Order Form is designed to gather information from customers interested in participating in the school pie fundraiser. This form collects details such as the orderer's name, contact information, and preferences for the fundraiser.

## How To Complete This Form

1. **Order Details**: This is the main section where you can fill in the orderer's details such as their name, contact information and the date of the order. Make sure to enter the correct information in these fields.
2. **Orderer's Name**: Enter the name of the person placing the order.
3. **Contact Information**: Enter the contact information of the person placing the order, such as their email address.
4. **Order Date**: Enter the date the order is being placed on.
5. **Order Pies**: Select "Yes" if you'd like to place an order for pies.
6. **Pie Quantity**: If you've selected "Yes" for Order Pies, enter the number of pies you'd like to order.
7. **Favors**: Select "Yes" if you'd like to add any additional favors to your order.
8. **Payment Details**: This is the space where you can include any additional information regarding the payment for your order.
9. **Payment Method**: Select "Yes" if you'd like to pay for the order immediately. If you'd like to be contacted about the payment, select "No".
10. **Payment Amount**: This field is not currently applicable for this form as the payment method is not set up, but it will be used if a payment method is selected.

## Field-by-Field Explanation
* **Order Details**: Enter the orderer's name, contact information and the date of the order.
* **Orderer's Name**: A field to enter the name of the person placing the order.
* **Contact Information**: A field to enter the contact information of the person placing the order, such as their email address.
* **Contact Email**: Enter the email address of the person placing the order.
* **Order Date**: The date on which the order is placed.
* **Order Pies**: Select "Yes" to place an order for pies.
* **Pie Quantity**: If "Yes" is selected for "Order Pies", enter the number of pies to order.
* **Favors**: Select "Yes" to add any additional favors to the order.
* **Payment Details**: A field for any additional information regarding the payment for the order.
* **Payment Method**: Select "Yes" to pay for the order immediately. If "No" is selected, you will be contacted about the payment.
* **Payment Amount**: This field is not currently applicable as the payment method is not set up.

## Tips
* Make sure to fill out each field carefully as it will help us process your order correctly.
* If you have any questions or concerns, feel free to contact us.
* Please make sure to select "Yes" for "Order Pies" and "Favors" if you actually want to order these.
* We will contact you about the payment if you select "No" for "Payment Method".
