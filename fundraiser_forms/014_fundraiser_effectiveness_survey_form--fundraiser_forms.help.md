# Fundraiser Effectiveness Survey Form - Help Guide
## Purpose

The Fundraiser Effectiveness Survey Form is a tool to evaluate the success and impact of a fundraising event. It helps to gather information about the event's effectiveness in achieving its goals, identify areas for improvement, and inform future fundraising strategies.

## How To Complete This Form

1. Please answer the questions based on your direct involvement or observation of the event.
2. For questions with multiple options, select all that apply.
3. Answer each question as accurately as possible, based on the data and information you have.

## Field-by-Field Explanation

* **Intro** (1): This is a brief introduction to the form. You can read it, but no action is required.
* **Event Participation** (2): How many participants attended the event?
	+ Select "Yes" if the event had a high number of attendees.
	+ Select "No" if the event did not have many attendees.
* **Event Participation Scale** (3): How would you rate the number of participants in the event?
	+ Rate from 1 to 5, where 1 is "low" and 5 is "high".
* **Fundraising Effort** (4): What effort is your organization making to raise money for the event?
	+ Select one of the options: Fundraising Basics, Social Media Campaigns, Fundraising Events, Online Campaigns, or Other.
* **Fundraising Success** (5): How successful was the fundraising event?
	+ Select all that apply from the options: 1-20% successful, 21-40% successful, 41-60% successful, 61-80% successful, 81-100% successful.
* **Feedback** (6): What suggestions do you have for improving the fundraising event?
	+ Provide any comments or recommendations to enhance future events.
* **Suggestions** (7): What suggestions do you have for improving the fundraising event?
	+ Provide any comments or recommendations to enhance future events.
* **Event Type** (8): What type of event was held? 
	+ Select one of the options: Fundraising Walk/Run, Fundraising Gala, Fundraising Dinner, Other.
* **Event Size** (9): How many attendees were at the event? 
	+ Provide the number of attendees.
* **Event Date** (10): Date of the event 
	+ Enter the date of the event.
* **Total Donated** (11): Total amount donated
	+ Enter the total amount donated.
* **Donation Method** (12): How did donors fund the event? 
	+ Select all that apply from the options: Online, In-person, Mail-in, Other.
* **Donation Frequency** (13): How often do donors give to your organization? 
	+ Select all that apply from the options: Monthly, Quarterly, Annually, Rarely.
* **Fundraising Budget** (14): What is the allocated budget for the event? 
	+ Enter the budget for the event.
* **Actual Spent** (15): What was the total actual spent on the event? 
	+ Enter the actual expenses.
* **Actual Donated** (16): What was the total actual donated for the event? 
	+ Enter the actual amount donated.
* **Budget Variance** (17): How did the actual expenses differ from the allocated budget? 
	+ Provide the difference between the actual expenses and the allocated budget.
* **Fundraising Goal** (18): What is the goal for the fundraising event? 
	+ Select one of the options: Less than 10k, 10-20k, 20-30k, More than 30k.
* **Fundraising Achievement** (19): How close were you to reaching the goal? 
	+ Select all that apply from the options: Not at all close, Somewhat close, Moderately close, Very close, Extremely close.
* **Overall Impact** (20): How impactful was the event for your organization? 
	+ Select all that apply from the options: Not impactful, Slightly impactful, Moderately impactful, Highly impactful, Extremely impactful.
* **Evaluation** (21): Would you recommend this event for future fundraising campaigns? 
	+ Select one of the options: Not at all, Somewhat, Moderately, Highly, Extremely.
