## Fundraising Campaign Records Release Form - Help Guide

### Purpose
The purpose of this form is to release fundraising campaign records, allowing you to track and manage your fundraising campaigns efficiently.

### How to Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields as accurately as possible.
2. Review each field carefully to ensure all necessary information is included.
3. Submit the form when completed.

### Field-by-Field Explanation

* **Participant Name** (`participant_name`, text, **not required**): Enter the name of the participant in this field. This field is optional, but entering a name can help identify the participant's involvement in the campaign.
* **Organization Name** (`organization_name`, text, **not required**): Enter the name of the organization or group associated with this campaign. Similar to the participant name, this is an optional field that can help with identification.
* **Campaign ID** (`campaign_id`, number, **not required**): Enter the unique ID of the fundraising campaign. This field is optional but can be helpful for tracking and referencing the campaign.
* **Campaign Type** (`campaign_type`, select multiple, **not required**): Select the type of campaign (Fundraising, Awareness, or Other). This field is optional but can help categorize the campaign's purpose.
* **Campaign Date** (`campaign_date`, date, **not required**): Enter the date of the campaign, if applicable. This field is optional and can be used for historical reference.
* **Campaign Start Date** (`campaign_start_date`, date, **not required**): Enter the start date of the campaign, if applicable. This field is optional and can be useful for tracking the campaign's timeline.
* **Campaign End Date** (`campaign_end_date`, date, **not required**): Enter the end date of the campaign, if applicable. This field is optional but can help track the campaign's duration.
* **Fundraising Goal** (`fundraising_goal`, number, **not required**): Enter the target fundraising amount for the campaign, if applicable. This field is optional and can aid in tracking fundraising progress.
* **Campaign Budget** (`campaign_budget`, number, **not required**): Enter the budget allocated for the campaign, if applicable. This field is optional and can help with financial planning.
* **Participant Email** (`participant_email`, email, **not required**): Enter the contact email of the participant, if applicable. This field is optional and can facilitate communication.
* **Participant Phone** (`participant_phone`, text, **not required**): Enter the phone number of the participant, if applicable. This field is optional and can be useful for further contact.
* **Participant Note** (`participant_note`, note, **not required**): Add any additional notes about the participant, if applicable. This field is optional and can provide context.
* **Organization Email** (`organization_email`, email, **not required**): Enter the contact email of the organization or group associated with this campaign, if applicable. This field is optional and can aid in communication.
* **Organization Phone** (`organization_phone`, text, **not required**): Enter the phone number of the organization or group, if applicable. This field is optional and can be useful for further contact.
* **Organization Note** (`organization_note`, note, **not required**): Add any additional notes about the organization or group, if applicable. This field is optional and can provide context.
* **Campaign Status** (`campaign_status`, select one, **not required**): Select the status of the campaign (Active or Inactive). This field is optional but can help track the campaign's status.
* **Participant Status** (`participant_status`, select one, **not required**): Select the status of the participant (Active or Inactive). This field is optional but can aid in tracking participant involvement.

### Tips
* Ensure that all fields are filled in as accurately as possible to maintain the integrity of the data.
* Review each field carefully to avoid missing any necessary information.
* Double-check the campaign and participant status fields to ensure they reflect the current state of the campaign and participant.
* Use the form to track and manage fundraising campaigns efficiently, and make use of the optional fields to gather more information about each campaign and participant.
