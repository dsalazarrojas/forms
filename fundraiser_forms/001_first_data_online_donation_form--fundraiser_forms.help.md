# first-data-online-donation-form - Help Guide
## Purpose

The "first-data-online-donation-form" is a tool for collecting information about online donation forms. It helps users specify the category, description, assigned tool, and output file name for these forms, facilitating efficient data management and customization.

## How To Complete This Form

1. Enter a brief title for the form in the "Form Name" field.
2. Select the category of the form from the options "Fundraiser Forms" or "Other".
3. Provide a brief description of the form in the "Description" field.
4. Choose the assigned tool for the form from the options "chatjimmy" or "Other".
5. Specify the output file name in the "Output File" field.

## Field-by-Field Explanation

* **Form Name**: (`form_name`, text, optional): Enter the name of the form in a brief title.
* **Category**: (`category`, select_one, optional): Choose the category of the form from "Fundraiser Forms" or "Other".
* **Description**: (`description`, text, optional): Provide a brief description of the form, describing its purpose and content.
* **Assigned Tool**: (`assigned_tool`, select_one, optional): Select the assigned tool for the form from "chatjimmy" or "Other".
* **Output File**: (`output_file`, text, optional): Specify the output file name for the form.

## Tips

* Ensure that the form name and description accurately reflect the form's content.
* Select the correct category and assigned tool according to the form's purpose.
* Be concise in the output file name to facilitate easy identification.
* Use this form to efficiently collect and manage information about online donation forms.
