# Fundraiser Ticket Form - Help Guide

## Purpose
This form is designed to collect essential information for fundraising events, including event details and ticket management data. It's ideal for promoting and managing ticketed events, ensuring attendees receive the necessary information.

## How To Complete This Form

To fill out the form correctly, follow these steps:

1. Enter the **Event Name** in the `Event Name` field. This field is used to label the event, so make sure to include the event's name in plain text.
2. Select the **Event Date** using the date input field. This field is required, so please make sure to choose a date in the correct format (`YYYY-MM-DD` is the expected format).
3. Choose the **Event Time** using the time input field. Like the event date, this field is also required, indicating the time of the event.
4. Enter the **Ticket Price** for the event, which should be a number representing the cost of a ticket.
5. Fill in the **Address** field, providing the location of the event in text format. This will help attendees know where to find the event.
6. Write a brief **Description** of the event, which will appear on promotional materials and provide context for attendees.
7. If your event has a **URL**, you can optionally provide it for additional information or event details.
8. For events with unique identifiers (e.g., for tracking or internal management), enter a **Unique ID**.
9. If you're using a series of tickets with a specific **Prefix**, enter it here.
10. If you're using a specific **Number Padding** for ticket numbers, enter it here.
11. Finally, enter the current **Index** of the ticket series.

## Field-by-Field Explanation

* **Event Name (Event Name)** (`event_name`, text, required): Enter the event name to label the event clearly.
* **Event Date (event_date)** (`event_date`, date, required): Select the date of the event in the expected format (YYYY-MM-DD).
* **Event Time (event_time)** (`event_time`, time, required): Choose the time of the event in the 24-hour format (HH:MM).
* **Ticket Price (ticket_price)** (`ticket_price`, number, required): Enter the price of a ticket for the event.
* **Address (event_address)** (`event_address`, text, required): Provide the location of the event in text format.
* **Description (event_description)** (`event_description`, text, required): Write a short description of the event.
* **Event URL (event_url)** (`event_url`, text, optional): Enter the URL for additional event information.
* **Unique ID (unique_id)** (`unique_id`, number, required): Enter a unique identifier for the event.
* **Current Index (current_index)** (`current_index`, number, optional): Enter the current index of the ticket series.
* **Prefix (prefix)** (`prefix`, text, optional): Enter a prefix for the ticket series.
* **Number Padding (number_padding)** (`number_padding`, text, optional): Enter the number padding for the ticket series.

## Tips

* Double-check the event date and time format to ensure they're correct.
* Make sure the ticket price is a valid number.
* For addresses, use a clear and concise format to help attendees understand the location.
* If you're unsure about any field, refer to the event's original plan or consult with the event organizer.
* Use this form for events that require ticket management and promotion.
