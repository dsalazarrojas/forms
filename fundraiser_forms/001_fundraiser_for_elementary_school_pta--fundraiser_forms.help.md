# Fundraiser For Elementary School PTA - Help Guide
## Purpose

The Fundraiser Form is used to create and manage fundraising campaigns for Elementary School PTA events. This form helps gather essential information about the event, including the event name, date, location, goal amount, and contact details.

## How To Complete This Form

1. Fill in the event details: Enter the event name, date, and time in the corresponding fields.
2. Set the goal amount: Enter the total amount you want to raise for the event.
3. Select the target donors: Choose the primary, secondary, and tertiary targets for the donations.
4. Set the event location: Enter the location where the event will take place.
5. Add event description: Provide a brief description of the event.
6. Select the fundraiser category and status: Choose the category and status of the fundraiser.
7. Select the event organizer: Choose the person or organization responsible for the event.
8. Add contact details: Enter the contact name, email, phone number, and website.

## Tips

* Make sure to fill in all required fields.
* Double-check the event details before submitting the form.
* Use proper formatting for dates and times.
* Enter accurate and up-to-date contact information.
