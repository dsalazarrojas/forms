# Summer School Application Form - Help Guide
## Purpose
This form is designed to help applicants gather information for a Summer School program. The form aims to collect basic data from students to process their applications efficiently.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your name in the "Category" field.
2. Provide a brief description of yourself in the "Description" field.
3. Specify the tool you are interested in being assigned in the "Assigned Tool" field.
4. Upload the required output file in the "Output File" field.

## Field-by-Field Explanation

* **Category** (`Category`, text, required: false): Enter a brief category or label that describes you. This can be your school year, grade level, or other relevant information.
* **Description** (`Description`, text, required: false): Write a concise description of yourself, including any relevant interests, skills, or experiences that make you a good fit for the Summer School program.
* **Assigned Tool** (`Assigned Tool`, text, required: false): Specify the tool you would like to be assigned during the program. Please select only one tool that aligns with your interests and skills.
* **Output File** (`Output File`, text, required: false): Upload the required output file, usually a document that showcases your work or project. Make sure it's in a suitable format and meets the program's requirements.
