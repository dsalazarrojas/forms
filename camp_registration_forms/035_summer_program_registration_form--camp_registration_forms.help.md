# Summer Program Registration Form - Help Guide
## Purpose
This form is used to collect participant information for the Summer Program. It will help us understand your preferences, availability, and other essential details, which will aid in planning and organizing the program.

## How To Complete This Form
- Please read through this guide carefully before starting to fill out the form.
- Ensure you answer each field accurately and completely.
- If you are unsure about any field, do not hesitate to reach out to us for clarification.

## Field-by-Field Explanation
- **Participant Information** (`participant_info`, `text`, required):
    - This is the main section to collect your name, contact information, and any other relevant details about you as a participant.
- **Program Preference** (`program_picking`, `select_multiple`, required):
    - Choose the programs you are interested in participating in. Please select all that apply.
    - Options: Program 1, Program 2, Program 3
- **Availability** (`availability`, `date`, required):
    - Enter your availability for the program duration. Please note that this is a date field, so ensure to follow the correct date format (MM/DD/YYYY).
- **Contact Information** (`contact_info`, `text`, required):
    - Provide your contact information, including your name, email, and phone number.
- **Additional Comments** (`additional_comments`, `text`, optional):
    - If you have any additional information you'd like to share with us, this is the section to do so.
- **Program Interest** (`program_interest`, `number`, required):
    - Indicate how much you are interested in the program (1-5).
- **Preferred Format** (`preferred_format`, `select_one`, required):
    - Select your preferred format for the program (Online, In-person, Hybrid).
- **Dietary Restriction** (`dietary_restrictions`, `select_one`, optional):
    - If you have any dietary restrictions, please select them from the options provided (No restriction, Vegetarian, Vegan, Gluten-free).
- **Emergency Contact** (`emergency_contact`, `select_one`, optional):
    - Indicate if you have an emergency contact, and if so, provide their name and information.
- **Program Commitment** (`program_commitment`, `number`, required):
    - Indicate how many programs you are committed to participating in.
- **Preferred Schedule** (`preferred_schedule`, `select_one`, required):
    - Select your preferred schedule for the program (Weekdays, Weekends, Flexibility).
- **Special Accommodations** (`special_accommodations`, `select_one`, optional):
    - If you need any special accommodations, please select them from the options provided (No special accommodations needed, Hearing assistance, Visual assistance, Physical assistance, Other (please specify)).
