# School Employee Attendance - Help Guide
## Purpose
The School Employee Attendance form is used to track and manage employee attendance, including capturing basic employee details, attendance status, and any assigned tools or users.

## How To Complete This Form
1. Fill in the required fields with accurate information about the employee.
2. Select the correct options for the "Location", "QR Code", "Tool ID", "Assigned Tool", "Assigned User", and "Goals" fields as applicable.
3. Review and submit the form for processing.

## Field-by-Field Explanation
* **Employee ID (1)**: Enter the employee's ID number.
* **Date (2)**: Select the date of the attendance event.
* **Time (3)**: Select the time of the attendance event.
* **Check In (4)**: Briefly note the time and date of check-in, if applicable.
* **Check Out (5)**: Briefly note the time and date of check-out, if applicable.
* **Location (6)**: Select all locations where the employee was present.
* **QR Code (7)**: Indicate whether a QR code was used for attendance tracking.
* **Tool ID (8)**: Enter the ID number of any tools assigned to the employee.
* **Assigned Tool (9)**: Select all tools assigned to the employee.
* **Assigned User (10)**: Select all users assigned to the employee.
* **Assigned User (11)**: This field is a duplicate of field 12, please ignore.
* **Assigned User (12)**: Select all users assigned to the employee.
* **Goals (11)**: Select all goals achieved by the employee.
