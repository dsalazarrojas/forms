# High School Tutoring Attendance Form - Help Guide
## Purpose
This form is designed to track student attendance in high school tutoring sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the student's name in the "Student Name" field.
2. Enter the date of the tutoring session in the "Attendance Date" field.
3. Enter the time of the tutoring session in the "Attendance Time" field.
4. Enter the start and end times of the session in the "Session Start Time" and "Session End Time" fields.
5. If applicable, select the sessions the student attended from the "Sessions Attended" field.
6. Enter any additional comments or notes about the session in the "Comments" field.
7. Select the status of the form completion from the "Form Completion Status" field.
8. Leave the "Student Attendance Form ID" and "Form Version Number" fields blank, as they are not editable by users.

## Field-by-Field Explanation
- **Student Name** (student_name, text, required): Enter the name of the student being tutored.
- **Attendance Date** (attendance_date, date, required): Enter the date of the tutoring session in the format YYYY-MM-DD.
- **Attendance Time** (attendance_time, time, required): Enter the time of the tutoring session in the format HH:MM AM/PM.
- **Session Start Time** (session_start_time, time, required): Enter the start time of the session.
- **Session End Time** (session_end_time, time, required): Enter the end time of the session.
- **Tutor Name** (tutor_name, text, required): Enter the name of the tutor.
- **Student Grade** (student_grade, text, required): Enter the student's grade level (e.g., 9th, 10th, 11th, 12th).
- **Sessions Attended** (attended_sessions, select_multiple, optional): Select the sessions the student attended (e.g., "Yes", "No").
- **Comments** (comments, note, optional): Enter any additional comments or notes about the session.
- **Form Completion Status** (form_completion_status, select_one, optional): Select the status of the form completion (e.g., "Completed", "Incomplete", "Pending").
- **Student Attendance Form ID** (student_attendance_form_id, text, read-only): This field is not editable by users and serves as a unique identifier for the form.
- **Form Version Number** (form_version_number, text, read-only): This field is not editable by users and indicates the version number of the form.

## Tips
* Please fill out only the necessary fields for each situation.
* Use the "Sessions Attended" field to track which sessions the student attended.
* Use the "Form Completion Status" field to indicate whether the form is completed, incomplete, or pending.
* Leave the "Student Attendance Form ID" and "Form Version Number" fields blank, as they are not editable by users.
