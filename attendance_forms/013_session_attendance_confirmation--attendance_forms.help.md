# Session Attendance Confirmation - Help Guide

## Purpose
The "Session Attendance Confirmation" form is used to record and confirm attendance for sessions.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the "Session id" in the first field to identify the session you are confirming attendance for. **Note: This field is currently not required but may be necessary for session identification.**
2. Enter the attendee's name in the "Attendee name" field.
3. Select the correct attendance status in the "Attendance" field. **Note: The options for this field correspond to unclear labels 1, 2, 3, 4, 5. Please select the correct option based on the session's attendance status.**
4. Enter the attendee's email in the "Email" field, if applicable.
5. Enter the attendee's phone number in the "Phone number" field, if applicable.
6. Enter the attendance date in the "Attendance date" field.
7. Enter the attendance time in the "Attendance time" field.
8. Add any additional comments or remarks in the "Notes" field. **Note: This field is for additional comments or remarks, and is not mandatory.**
9. Confirm the session attendance by providing a number in the "Session attendance confirmation" field.
10. Enter the assigned tool in the "Assigned tool" field, if applicable.

## Field-by-Field Explanation
* **Session id (1)**: Enter the session ID to identify the session being attended.
* **Attendee name (2)**: Enter the name of the attendee.
* **Attendance (3)**: Select the correct attendance status from the options 1, 2, 3, 4, 5. **Note: This field corresponds to unclear labels 1, 2, 3, 4, 5. Please select the correct option based on the session's attendance status.**
* **Email (4)**: Enter the attendee's email, if applicable.
* **Phone number (5)**: Enter the attendee's phone number, if applicable.
* **Attendance date (6)**: Enter the date the attendee attended the session.
* **Attendance time (7)**: Enter the time the attendee attended the session.
* **Notes (8)**: Add any additional comments or remarks about the session attendance.
* **Assigned tool (9)**: Enter the assigned tool, if applicable.
* **Session attendance confirmation (10)**: Confirm the session attendance by providing a number.

Note: Please review the form carefully and fill in the required fields. If you have any questions or concerns, please contact the relevant support team.
