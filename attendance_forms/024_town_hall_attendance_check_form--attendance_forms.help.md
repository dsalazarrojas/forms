# Town Hall Attendance Check Form - Help Guide
## Purpose
This form is used to check if a user is attending a town hall event and to collect some basic information about the event and the user.

## How To Complete This Form
To complete this form, follow these steps:

1. Check the "are-you-sure-to-attend" field to indicate if you are attending the event.
2. Enter the number of attendees in the "number-of-attendees" field.
3. If you have any additional notes, you can add them in the "notes" field.
4. If you need to, you can also enter your email address and phone number in the respective fields.
5. Finally, enter the town hall ID, event ID, and event name if required.

## Field-by-Field Explanation
* **are-you-sure-to-attend** (Yes/No): This field is used to confirm if you are attending the event. Please select 'Yes' if you are attending, 'No' otherwise.
* **number-of-attendees**: Enter the number of people attending the event with you.
* **notes** (optional): If you need to add any additional information about your attendance or the event, you can enter it here.
* **email** (optional): Enter your email address if you need to provide it.
* **phone** (optional): Enter your phone number if you need to provide it.
* **town-hall-id** (optional): Enter the ID of the town hall event.
* **town-hall-name** (optional): Enter the name of the town hall event.
* **event-id** (optional): Enter the ID of the event.
* **event-name** (optional): Enter the name of the event. 

## Tips
* Make sure to fill out all required fields accurately.
* If you are unsure about any field, please contact your administrator for assistance.
* If you need to add multiple attendees, please enter each attendee separately in the form. 

Note: This guide assumes that the user is authorized to fill out the form. If you are not authorized, please contact your administrator for further instructions.
