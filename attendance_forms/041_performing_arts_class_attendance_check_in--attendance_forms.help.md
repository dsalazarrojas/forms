# performing-arts-class-attendance-check-in - Help Guide
## Purpose
This form is designed to track the attendance of students in performing arts classes, providing a way to record session details, student information, and instructor feedback.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the title of the performing arts class.
2. Select the session date.
3. Choose the session time.
4. Enter the student's name.
5. Input the student's email (if available).
6. Select whether the student attended the session.
7. Enter any notes for the student.
8. Enter the instructor's name.
9. Input the instructor's email (if available).
10. Select whether the instructor is active or inactive.
11. Choose the type of session (Music, Dance, or Theater).
12. Select the specific session type (Piano, Vocal, Jazz, Ballet, Jazz, Tap, Play, or Musical).
13. Select whether the student is active or inactive.
14. Select whether the student attended (yes/no) and the session status (Active/Inactive).
15. Select whether the student attended (yes/no) and the session status (Active/Inactive).
16. Enter any session notes.
17. Enter the parent's name (if applicable).
18. Input the parent's email (if applicable).
19. Enter the parent's phone number (if applicable).
20. Select whether the session is attended or not.
21. Select the status of the session (Active/Inactive).
22. Select the status of the student (Active/Inactive).
23. Select the type of music session (Piano, Vocal, or Jazz).
24. Select the type of dance session (Ballet, Jazz, or Tap).
25. Select the type of theater session (Play or Musical).

## Field-by-Field Explanation
- **Performing arts class**: Enter the title of the performing arts class.
- **Session date**: Select the date of the session.
- **Session time**: Choose the time of the session.
- **Student name**: Enter the student's name.
- **Student email**: Input the student's email (if available).
- **Student attended**: Select whether the student attended the session.
- **Student note**: Enter any notes for the student.
- **Instructor name**: Enter the instructor's name.
- **Instructor email**: Input the instructor's email (if available).
- **Instructor note**: Enter any notes for the instructor.
- **Session notes**: Enter any notes for the session.
- **Parent name**: Enter the parent's name (if applicable).
- **Parent email**: Input the parent's email (if applicable).
- **Parent phone**: Enter the parent's phone number (if applicable).
- **Session attended**: Select whether the session is attended or not.
- **Session status**: Select the status of the session (Active/Inactive).
- **Student status**: Select the status of the student (Active/Inactive).
- **Music session**: Select the type of music session (Piano, Vocal, or Jazz).
- **Dance session**: Select the type of dance session (Ballet, Jazz, or Tap).
- **Theater session**: Select the type of theater session (Play or Musical).
- **Submitted by**: Select who submitted the form (Student or Instructor).

Note: Ensure that all fields are filled out as required, and that you are submitting the form on behalf of either the student or the instructor.
