# Surgeon Attendance Log - Help Guide
## Purpose
The Surgeon Attendance Log is a tool for tracking the presence and activity of surgeons in hospitals. It helps with scheduling, staffing, and administrative purposes.

## How To Complete This Form
To complete this form, follow the instructions for each field below.

## Field-by-Field Explanation

* **Surgeon Presence** (`Surgeon Presence`, `select_one`, required: false): Please select one of the options to indicate the surgeon's current presence status: Surgeon, On Site, On Leave, On Vacation, or On Other.
* **Coverage Type** (`Coverage Type`, `select_one`, required: false): Choose the type of coverage the surgeon has, if applicable: On Call, On Service, Off Duty, or Other.
* **Start Time** (`Start Time`, `time`, required: false): Enter the start time of the surgeon's shift, if applicable.
* **End Time** (`End Time`, `time`, required: false): Enter the end time of the surgeon's shift, if applicable.
* **Notes** (`Notes`, `note`, required: false): Add any additional comments or details about the surgeon's presence or activity.
* **Surgeon Name** (`Surgeon Name`, `text`, required: false): Enter the name of the surgeon, if applicable.
* **Surgeon ID** (`Surgeon ID`, `text`, required: false): Enter the ID of the surgeon, if applicable.
* **Hospital Location** (`Hospital Location`, `text`, required: false): Enter the location of the hospital, if applicable.
* **Date** (`Date`, `date`, required: false): Enter the date of the surgeon's presence or activity, if applicable.
* **Physician ID** (`Physician ID`, `text`, required: false): Enter the ID of the physician, if applicable.
* **Surgeon Type** (`Surgeon Type`, `text`, required: false): Enter the type of surgeon, if applicable.
* **Department** (`Department`, `text`, required: false): Enter the department where the surgeon is working, if applicable.
* **Room Number** (`Room Number`, `text`, required: false): Enter the room number where the surgeon is working, if applicable.
* **Shift** (`Shift`, `text`, required: false): Enter the shift or schedule of the surgeon, if applicable.
* **Time In** (`Time In`, `time`, required: false): Enter the time the surgeon clocked in, if applicable.
* **Time Out** (`Time Out`, `time`, required: false): Enter the time the surgeon clocked out, if applicable.
* **Duration** (`Duration`, `number`, required: false): Enter the duration of the surgeon's presence or activity, if applicable.
* **Comments** (`Comments`, `text`, required: false): Add any additional comments or details about the surgeon's presence or activity.
* **Hospital Name** (`Hospital Name`, `text`, required: false): Enter the name of the hospital, if applicable.
* **Shift Start** (`Shift Start`, `time`, required: false): Enter the start time of the shift or schedule, if applicable.
* **Shift End** (`Shift End`, `time`, required: false): Enter the end time of the shift or schedule, if applicable.
* **Surgeon Name 2** (`Surgeon Name 2`, `text`, required: false): Enter the name of the second surgeon, if applicable.
* **Surgeon ID 2** (`Surgeon ID 2`, `text`, required: false): Enter the ID of the second surgeon, if applicable.
* **Surgeon Type 2** (`Surgeon Type 2`, `text`, required: false): Enter the type of the second surgeon, if applicable.
