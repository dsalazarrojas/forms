# Startup Project Attendance Form - Help Guide
## Purpose
The Startup Project Attendance Form is designed to gather information from participants attending a startup project event. Please fill out the form accurately and completely to ensure we receive the information we need.

## How To Complete This Form
1.  Fill in the following sections:
	* Event Details: Provide a brief description of the event you are attending.
	* Participant Details: Enter your name, email, and any other relevant details.
	* Project Details: Provide information about the project you are interested in, or are working on.
	* Consent: Check the box to indicate that you have read and agree to the terms of the project.
	* Additional Info: Add any other information you think might be helpful.
2.  Be accurate and thorough in your responses to ensure we receive the information we need.

## Field-by-Field Explanation
* **Event Details** (`event_details`): Provide a brief description of the event you are attending (e.g., "Attendee of Project Demo Day").
* **Participant Details** (`participant_details`): Enter your name and email address. Please ensure to enter the correct details for accurate contact and participant tracking.
* **Project Details** (`project_details`): Provide information about the project you are interested in, or are working on (e.g., project name, status, and team members).
* **Consent** (`consent`): Check this box to indicate that you have read and agree to the terms of the project. This is a required field.
* **Additional Info** (`additional_info`): Add any other information you think might be helpful to the project team.
