# Weekly Service Attendance Record - Help Guide
## Purpose

The Weekly Service Attendance Record is a form used to record details about attendance to services, such as date, time, type of service, location, number of attendees, and any notes or follow-up actions.

## How To Complete This Form

To fill out this form, follow these steps:

1. Select the correct date for the attendance record you want to create.
2. Enter the time of the service.
3. Choose the type of service that was held.
4. Select the location where the service took place.
5. Enter the number of attendees who participated in the service.
6. If required, add a list of attendees.
7. Enter any notes about the service, such as any notable events or actions taken.
8. If necessary, add notes for the service leaders, such as any important decisions or reminders.
9. Choose any follow-up action that needs to be taken.
10. Add any notes about the follow-up action, if necessary.

## Field-by-Field Explanation

* **Attendance Details** (`weekly_service_attendance_record_form`, text, optional): 
  This field is used to provide a brief overview of the attendance record. It should be a concise description of the service event.
* **Date** (`date`, date, optional): 
  This field is used to select the date when the service took place. Please choose the correct date from the calendar provided.
* **Time** (`time`, time, optional): 
  This field is used to select the time when the service started. Please choose the correct time from the available options.
* **Service Type** (`service_type`, select_one, optional): 
  This field is used to select the type of service that was held. Choose the option that best describes the type of service, such as a "worship service," "youth service," "children's service," etc.
* **Location** (`location`, select_multiple, optional): 
  This field is used to select the location where the service took place. Choose all locations that apply, such as "main auditorium," "side auditorium," "outside service," etc.
* **Attendees Count** (`attendees_count`, number, optional): 
  This field is used to enter the number of attendees who participated in the service. Please enter a whole number.
* **Attendees List** (`attendees_list`, note, optional): 
  This field is used to add a list of attendees. You can add as many attendees as necessary, separated by commas.
* **Notes** (`notes`, note, optional): 
  This field is used to add any additional notes about the service, such as any notable events or actions taken.
* **Service Leaders** (`service_leaders`, select_multiple, optional): 
  This field is used to select the service leaders who were present during the service. Choose all leaders that apply.
* **Service Leaders Notes** (`service_leaders_notes`, note, optional): 
  This field is used to add any notes about the service leaders, such as any important decisions or reminders.
* **Follow Up** (`follow_up`, select_one, optional): 
  This field is used to select any follow-up action that needs to be taken. Choose the option that best describes the follow-up action.
* **Follow Up Notes** (`follow_up_notes`, note, optional): 
  This field is used to add any notes about the follow-up action, if necessary.
