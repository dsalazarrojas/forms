# Attendance Certificate Template - Help Guide
## Purpose
This form is used to create attendance certificates for participants who attended an event. It will help event organizers to create customized certificates with relevant information.

## How To Complete This Form
- Read through the form carefully and fill in the required fields.
- Select the correct certificate type from the options provided.
- Fill in the participant's information, including their name, title/position, and address.
- Enter the event details, such as name, date, location, and description.
- Select the design template for the certificate.
- Fill in any additional details if required.
- Review the certificate content before signing.

## Field-by-Field Explanation

* **Certificate Type** (`Certificate Type`, **Select One**, required): This field allows you to select the type of certificate, such as Participation, Attendance, Completion, Achievement, Recognition, or Appreciation.
* **Certificate Number** (`Certificate Number`, **Text**, optional): This field is used for tracking purposes and is not required. You can leave it blank if not needed.
* **Issue Date** (`Issue Date`, **Date**, required): This field is the date when the certificate is being issued.
* **Recipient Name** (`Recipient Name`, **Text**, required): This field is for the full name of the participant.
* **Recipient Title/Position** (`Recipient Title/Position`, **Text**, optional): This field is for the participant's professional title or position.
* **Recipient Organization** (`Recipient Organization`, **Text**, optional): This field is for the participant's organization or company name.
* **Recipient Address** (`Recipient Address`, **Text**, optional): This field is for the participant's mailing address.
* **Event Name** (`Event Name`, **Text**, required): This field is for the name of the event attended.
* **Event Date** (`Event Date`, **Date**, required): This field is for the date of the event.
* **Event Location** (`Event Location`, **Text**, required): This field is for where the event took place.
* **Event Description** (`Event Description`, **Text**, optional): This field is for a brief description of the event.
* **Hours of Attendance** (`Hours of Attendance`, **Number**, optional): This field is for the total hours attended or course duration.
* **Organizing Body/Institution** (`Organizing Body/Institution`, **Text**, required): This field is for the organization that held the event.
* **Signatory Name** (`Signatory Name`, **Text**, required): This field is for the name of the person signing the certificate.
* **Signatory Title** (`Signatory Title`, **Text**, required): This field is for the title/position of the signer.
* **Signatory Contact** (`Signatory Contact`, **Text**, optional): This field is for the email or phone number of the signer.
* **Certificate Statement/Message** (`Certificate Statement/Message`, **Text**, required): This field is for the main text of the certificate.
* **Special Achievements or Honors** (`Special Achievements or Honors`, **Text**, optional): This field is for any special recognition or awards received.
* **Design Template Selection** (`Design Template Selection`, **Select One**, required): This field is for choosing the certificate design style.
* **Additional Details** (`Additional Details`, **Text**, optional): This field is for any other information to include on the certificate.
