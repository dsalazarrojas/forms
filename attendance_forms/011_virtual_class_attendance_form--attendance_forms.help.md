# Virtual Class Attendance Form - Help Guide
## Purpose
The Virtual Class Attendance Form is designed to track student attendance for virtual classes. Instructors use this form to record student participation and engagement in online classes. It's essential to fill out the form accurately and submit it for each virtual class.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the attendance status for the virtual class.
2. Enter the student's ID number.
3. Choose the date of the virtual class.
4. Select the time the virtual class took place.
5. Choose the attendance status for the student (e.g., Present, Absent, or Late).
6. Add any additional notes about the student's attendance.

## Field-by-Field Explanation
- **Virtual Class** (`virtual_class_attendance_form`, select_one, required): Select the virtual class for which you're reporting attendance. This field will display a list of available virtual classes.
  * Choose the correct virtual class from the list.
- **Student ID** (`student_id`, number, optional): Enter the student's unique identifier.
  * Enter the student's ID number (e.g., 123456).
- **Date** (`attendance_date`, date, optional): Select the date of the virtual class.
  * Choose the correct date from the calendar.
- **Time** (`attendance_time`, time, optional): Select the time the virtual class took place.
  * Choose the correct time (e.g., 9:00 AM).
- **Status** (`attendance_status`, select_one, optional): Choose the attendance status for the student (e.g., Present, Absent, or Late).
  * Select the correct attendance status.
- **Notes** (`notes`, note, optional): Add any additional comments or notes about the student's attendance.
  * Enter any relevant notes or comments.

## Tips
* Make sure to fill out the form for each virtual class accurately and submit it for record-keeping purposes.
* Avoid submitting multiple attendance reports for the same virtual class; instead, submit one report per class.
* If a student's attendance status changes, update the attendance report accordingly.
