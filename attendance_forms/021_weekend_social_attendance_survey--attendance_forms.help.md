# Weekend Social Attendance Survey - Help Guide
## Purpose
The Weekend Social Attendance Survey form is designed to collect information from attendees about their weekend social events. This includes their attendance status, event details, and feedback.

## How To Complete This Form
1. Start by selecting the event you attended from the "weekend_event_attendance" dropdown menu.
2. If you attended the event, please provide the "weekend_event_name" and "weekend_event_description" fields.
3. Specify the start and end times of the event in the respective "start_time" and "end_time" fields.
4. Indicate whether you attended the event on your preferred day in the "preferred_day" field.
5. If you attended the event with others, select the corresponding option in the "attendees" field.
6. If you have any comments or feedback, provide them in the "comments" field.
7. Input your email address in the "email" field.
8. Finally, input your phone number in the "phone_number" field.

## Field-by-Field Explanation
* **Weekend Event Attendance** (`weekend_event_attendance`): Select "Yes" if you attended the weekend event, "No" otherwise.
* **Weekend Event Name** (`weekend_event_name`): Enter the name of the event you attended.
* **Weekend Event Description** (`weekend_event_description`): Provide a brief description of the event.
* **Preferred Day** (`preferred_day`): Choose the day you would prefer to attend events, but note that this information is not directly related to this event.
* **Start Time** (`start_time`): Enter the start time of the event.
* **End Time** (`end_time`): Enter the end time of the event.
* **Duration** (`duration`): Select "Yes" if the event had a significant duration, "No" otherwise.
* **Attendees** (`attendees`): Select "Yes" if you attended with others, "No" otherwise.
* **Comments** (`comments`): Provide any additional comments or feedback about the event.
* **Email** (`email`): Input your email address.
* **Phone Number** (`phone_number`): Input your phone number.

## Tips
* Please be honest and accurate when selecting the event attendance and providing event details.
* If you have any issues or concerns, feel free to provide comments for further clarification.
* If you have any questions or need help, contact the event organizers directly.
