# Format Attendance Sheet (Public Program) - Help Guide
## Purpose
The Format Attendance Sheet (Public Program) form is used to format an attendance sheet for a public program. This form collects information about the program's category, description, assigned tool, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you have all the necessary information and details about the program.
2. Fill out the form accurately and precisely, paying attention to all the required fields.
3. Check if the attendance sheet has already been formatted before initiating the process.

## Field-by-Field Explanation
* **Category** (Required, Select One): Select the category of the public program from the options provided. This will help in categorizing and organizing the program's details.
* **Description** (Optional, Text): Provide a brief description of the public program. This field is not required but will help in providing more context about the program.
* **Assigned Tool** (Required, Select One): Indicate whether the program has an assigned tool. This will help in tracking and managing the program's resources.
* **Format Attendance Sheet Public Program 1-20** (Optional, Text): These fields are used to enter additional details about the program. Please fill out each field as required.

  * **Format Attendance Sheet Public Program 2**
  * ...
  * **Format Attendance Sheet Public Program 20**

Note: The fields with labels like "Format Attendance Sheet Public Program 1" are used to enter specific details about the public program. Please refer to the actual labels for each field for accurate information.
