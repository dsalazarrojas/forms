# Construction Site Worker Attendance Form - Help Guide
## Purpose

The purpose of this form is to gather information about a worker's attendance on a construction site. This includes their attendance date, project details, supervisor contact information, and work-related activities.

## How To Complete This Form

1. Fill out all required fields marked as "required".
2. Ensure you enter accurate and truthful information for each field.
3. If you're unsure about any field, ask your supervisor for guidance.

## Field-by-Field Explanation

* **Attendance Date** (`attendance_date`, date, required): Enter the date of this attendance record.
* **Project Name** (`project_name`, text, required): Type the name of the project you are working on.
* **Project Address** (`project_address`, text, required): Enter the site location.
* **Supervisor Name** (`supervisor_name`, text, required): Enter the name of your supervisor.
* **Worker Full Name** (`worker_name`, text, required): Type your full name as the worker.
* **Employee ID** (`employee_id`, text, not required): If you have an employee ID, enter it here. If not, leave this field blank.
* **Company Name** (`company_name`, text, required): Enter the name of your employer or subcontractor.
* **Job Title** (`job_title`, select_one, required): Choose the job title that best describes your role on the site.
* **Check-In Time** (`check_in_time`, time, required): Enter the time you arrived on the site.
* **Check-Out Time** (`check_out_time`, time, not required): If you leave the site, enter the time you departed. If not, leave this field blank.
* **Total Hours** (`total_hours`, number, not required): If you worked beyond your regular schedule, enter the extra hours here.
* **Break Start Time** (`break_start`, time, not required): If you took a break, enter the time it began.
* **Break End Time** (`break_end`, time, not required): If you took a break, enter the time it ended.
* **Break Duration** (`break_duration`, number, not required): If you took a break, enter the length in minutes.
* **Work Area Assigned** (`work_area`, text, required): Type the location on site where you worked.
* **Work Description** (`work_description`, text, required): Describe the tasks you performed today.
* **Safety Equipment Issued** (`safety_equipment_issued`, select_multiple, not required): If you used any safety equipment, select all that apply.
* **Safety Meeting Attended** (`safety_meeting_attended`, select_one, required): If a safety meeting was held, indicate if you attended.
* **Incidents Reported** (`incidents_reported`, select_one, required): If an incident occurred, select "True".
* **Incident Description** (`incident_description`, text, not required): If an incident occurred, describe it here.
* **Equipment Used Today** (`equipment_used`, text, not required): If you operated machinery or tools, list them here.
* **Overtime Hours** (`overtime_hours`, number, not required): If you worked beyond your regular schedule, enter the extra hours here.
* **Per Diem Eligible** (`per_diem_eligible`, select_one, not required): If you are eligible for per diem, select "True".
* **Meal Break Taken** (`meal_break_taken`, select_one, not required): If you took a meal break, select "True".
* **Worker Signature** (`worker_signature`, text, required): Type your full name as the worker.
* **Supervisor Signature** (`supervisor_signature`, text, required): Type the supervisor's full name.
* **Additional Notes** (`notes`, text, not required): Add any other relevant information here.

## Tips

* Always ask your supervisor if you're unsure about any field.
* Double-check the form for accuracy before submitting.
* Complete the form honestly and thoroughly.
