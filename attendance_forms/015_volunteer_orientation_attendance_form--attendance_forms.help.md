# Volunteer Orientation Attendance Form - Help Guide
## Purpose
This form is used to track the attendance of participants during volunteer orientation sessions. It captures key information about each participant, including session details and personal contact information. The form also collects the participant's attendance status, which is useful for tracking and reporting purposes.

## How To Complete This Form
1. Select the correct session date for the orientation.
2. Enter the session time for the orientation session.
3. Choose the location of the session.
4. Enter the participant's name.
5. Enter the participant's email address (if applicable).
6. Enter the participant's phone number (if applicable).
7. Add any additional notes about the participant (if necessary).
8. Select the attendance status of the participant (e.g., "Attended", "No Show", "Late Arrival").
9. Add any notes about the session (if necessary).

## Field-by-Field Explanation

* **Session Date** (`session_date`, date, required/optional): Enter the date of the orientation session.
* **Session Time** (`session_time`, time, required/optional): Enter the time of the orientation session.
* **Session Location** (`session_location`, text, required/optional): Enter the location of the orientation session.
* **Participant Name** (`participant_name`, text, required/optional): Enter the name of the participant.
* **Participant Email** (`participant_email`, email, required/optional): Enter the email address of the participant (if applicable).
* **Participant Phone** (`participant_phone`, text, required/optional): Enter the phone number of the participant (if applicable).
* **Participant Note** (`participant_note`, note, required/optional): Add any additional notes about the participant (if necessary).
* **Attendance Status** (`attendance_status`, select_one, required/optional): Select the attendance status of the participant (e.g., "Attended", "No Show", "Late Arrival").
* **Session Note** (`session_note`, note, required/optional): Add any additional notes about the session (if necessary).
* **Submitted At** (`submitted_at`, date, required/optional): The timestamp when the form was submitted (auto-generated).

Note: The required/optional status of each field is indicated in the field explanation above.
