# Online Class Attendance - Help Guide

## Purpose
This form is for recording the attendance of students in an online class.

## How To Complete This Form

### Step 1: Gather the necessary information
Before starting, make sure you have the required information ready, such as the student's name, class code, date, time, and email.

### Step 2: Fill out the form
- Fill in the student's name in the **Student Name** field.
- Enter the class code in the **Class Code** field.
- Choose the date of the attendance record in the **Date** field.
- Select the time of the attendance record in the **Time** field.
- Select the attendance status (Present, Absent, or Late) in the **Attendance Status** field.
- Provide any additional comments about the student's attendance in the **Comments** field.
- Enter the student's email in the **Email** field.
- If necessary, enter the student's phone number in the **Phone** field.

## Field-by-Field Explanation
* **Student Name**: Enter the name of the student as it appears on their record.
* **Class Code**: Enter the code of the class the student is enrolled in.
* **Date**: Enter the date of the attendance record using the format MM/DD/YYYY.
* **Time**: Enter the time of the attendance record using the format HH:MM AM/PM.
* **Attendance Status**: Choose from the options Present, Absent, or Late to indicate the student's attendance status.
* **Comments**: Provide any additional comments about the student's attendance.
* **Email**: Enter the student's email address for contact purposes.
* **Phone**: If necessary, enter the student's phone number for further contact.

## Tips
- Make sure to double-check the entered information for accuracy before submitting the form.
- If you're unsure about a particular field, please contact the relevant authorities for clarification.
- This form should only be used for new attendance records, and not for editing or updating existing ones.
