# Event Feedback Form - Help Guide
## Purpose
The Event Feedback Form is designed to collect participant feedback about their experience at an event. Your feedback is valuable in helping us understand what we did well and what we can improve for future events.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Answer all the questions to the best of your knowledge.
2. Be honest and thorough in your feedback.
3. Make sure to submit your form once you have answered all the questions.

## Field-by-Field Explanation
### 1. **What was your experience?**
	* Label: what_was_your_experience
	* Type: text
	* This is the main question to capture your overall impression of the event.
### 2. **What were your feelings about the presentation?**
	* Label: presenters
	* Type: select_one (select from not_satisfied, somewhat_satisfied, very_satisfied)
	* Please choose your feelings about the presentation.
### 3. **What was your impression of the venue?** (Optional)
	* Label: venue
	* Type: text
	* If you have any comments about the venue, please provide them here.
### 4. **Do you have any suggestions?** (Optional)
	* Label: suggestions
	* Type: text
	* If you have any suggestions for future events, please provide them here.
### 5. **Do you have any comments?** (Optional)
	* Label: comments
	* Type: note
	* This is a free text field where you can provide any additional comments.
### 6. **Email**
	* Label: email
	* Type: email
	* Please provide your email address so we can follow up with you if necessary.
### 7. **Phone Number** (Optional)
	* Label: phone
	* Type: text
	* If you would like to be contacted for any reason, please provide your phone number.
### 8. **Which services were satisfactory or unsatisfactory?**
	* Label: services
	* Type: select_multiple (select from venue, presentation, speakers, catering, overall, logistics)
	* Please select all the services that were satisfactory or unsatisfactory.
### 9. **Do you agree with the following statement?**
	* Label: agree
	* Type: select_one (select from agree, not_agree, neutral)
	* Please select your agreement with the following statements.
### 10. **Do you have any other comments or suggestions?** (Optional)
	* Label: dont_know
	* Type: select_multiple (select from agree, not_agree, neutral)
	* If you have any other comments or suggestions, please provide them here.
### 11. **Other (please specify)** (Optional)
	* Label: dont_know_other
	* Type: text
	* If you have any other comments or suggestions, please provide them here.
### 12. **Do you agree or disagree with the other comments?** (Optional)
	* Label: agree_other
	* Type: text
	* If you have any other comments or suggestions, please provide them here.
### 13. **Was the venue satisfactory or not?** (Optional)
	* Label: dont_know_venue
	* Type: select_one (select from venue, not_venue, neutral)
	* If you have any comments or suggestions about the venue, please provide them here.
