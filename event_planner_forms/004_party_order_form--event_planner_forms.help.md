# Party Order Form - Help Guide
## Purpose
The Party Order Form is used to collect party details and contact information from event planners and organizers for events such as parties, conferences, or corporate events.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select whether or not the event will have a party from the "party_details" page.
2. Choose whether or not the party will have contact information from the "contact_info" page.
3. Select the party packages that will be needed for the event from the "party_packages" page.

## Field-by-Field Explanation
* **party_details** (`Yes/No`, Select Multiple, Not Required): Select whether or not the event will have a party.
* **contact_info** (`Yes/No`, Select Multiple, Not Required): Choose whether or not the party will have contact information. If yes, please provide your contact details.
* **party_packages** (`Yes/No`, Select Multiple, Not Required): Select the party packages that will be needed for the event. Please choose from the options provided.

## Tips
* Please select only the party packages that are actually needed for your event.
* If you have any other specific requirements or needs for the party, please describe them in the comments section (not provided in this form).
