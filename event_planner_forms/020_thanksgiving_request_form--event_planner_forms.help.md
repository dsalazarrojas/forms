# Thanksgiving Request Form - Help Guide
## Purpose
The Thanksgiving Request Form is a tool for users to submit requests for events or activities to be held during the Thanksgiving holiday season. This form helps the event planner gather necessary information to process and manage these requests effectively.

## How To Complete This Form
1. Fill in your user information, which includes any details that are relevant to your request.
2. Provide event details, including any specific events or activities you would like to request.
3. Select a date and time for the event.
4. Choose the type of request you are making (e.g., Option 1, Option 2, or Option 3).
5. Add any additional information that may be helpful for the event planner.
6. Enter your contact email and phone number so that the event planner can reach out to you.
7. Select who the event should be assigned to (if applicable).
8. Indicate whether the event is a part of the "Yes" or "No" event category.
9. Finally, submit your request for processing.

## Field-by-Field Explanation
- **User Info**: This field is used to capture any personal details that are relevant to your request. Enter your name, role, or any other identifying information that may be necessary for the event planner.
* **Event Details**: Enter a brief description of the event or activity you are requesting.
* **Date And Time**: Select a date and time for the event. Please ensure that the date and time chosen are reasonable and feasible for the event planner.
* **Request Type**: Select the type of request you are making, which will help the event planner understand your needs. Please choose one of the options provided (Option 1, Option 2, or Option 3).
* **Additional Info**: If there is any additional information that you would like to provide to support your request, enter it in this field.
* **Contact E-mail**: Enter your email address so that the event planner can contact you for further information or clarification.
* **Contact Phone**: Enter your phone number so that the event planner can reach out to you if needed.
* **Assigned To**: If you are requesting something that is specific to a particular person or team, select the name from the provided options.
* **Event Category**: Check the box if the event is part of the "Yes" event category or "No" event category. This will help the event planner understand the scope and purpose of the event.
* **Submit**: Once you have completed all the fields, click the "Submit" button to send your request to the event planner for processing.
