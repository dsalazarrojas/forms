# Event Debrief Form - Help Guide

## Purpose
The Event Debrief Form is used to gather detailed information about an event, ensuring that all relevant data is captured and stored for future reference.

## How To Complete This Form
1. Fill out the form completely, paying attention to the required fields marked as "required".
2. Select the correct options for the "Event Organization" field.
3. Enter the event's name in the "Event Name" field.
4. Select the event's dates using the date picker provided.
5. Enter the event's start and end times using the time picker provided.
6. Enter the event's venue and location in the provided text fields.
7. Provide any additional details about the event in the "Event Details" field.
8. Indicate if attendees were present at the event by selecting "Yes" or "No" in the "Event Attendees" field.
9. Add any additional notes or comments about the event in the "Event Notes" field.

## Field-by-Field Explanation

* **Event Organization**: 
  - Type: Select One (`<name>`): 
  - This field asks whether the event was organized as part of a larger organization or not. Select "Yes" if the event was organized by a company or group, "No" otherwise.
* **Event Name**: 
  - Type: Text (`<name>`): 
  - Enter the name of the event.
* **Event Dates**: 
  - Type: Date (`<name>`): 
  - Select the start and end dates of the event.
* **Event Time**: 
  - Type: Time (`<name>`): 
  - Choose the start and end times of the event.
* **Event Venue**: 
  - Type: Text (`<name>`): 
  - Enter the location where the event took place.
* **Event Location**: 
  - Type: Text (`<name>`): 
  - Enter the address or location of the event.
* **Event Details**: 
  - Type: Note (`<name>`): 
  - Provide any additional details about the event that are not captured elsewhere on the form.
* **Event Attendees**: 
  - Type: Select Multiple (`<name>`): 
  - Indicate whether attendees were present at the event by selecting "Yes" or "No".
* **Event Notes**: 
  - Type: Note (`<name>`): 
  - Add any additional notes or comments about the event.

## Tips
- Ensure that all required fields are completed accurately and thoroughly.
- Review the form before submitting to ensure all information is correct.
- Use the form for post-event evaluation and planning purposes only.
