# Festival Vendor Dispute Incident Report Form - Help Guide
## Purpose
The purpose of this form is to report incidents involving festival vendors that may occur during the festival. These incidents may include disputes between vendors, vendor complaints, or other issues that affect the festival experience.

## How To Complete This Form
To complete this form, simply fill in the required fields with the requested information. You can access the form through [link to form].

## Field-by-Field Explanation
### Vendor Name (1)
* **Vendor Name** (`vendor_name`, text, optional): Please enter the name of the vendor involved in the incident.

### Incident Date (2)
* **Incident Date** (`incident_date`, date, optional): Enter the date on which the incident occurred.

### Incident Time (3)
* **Incident Time** (`incident_time`, time, optional): Enter the time of day when the incident occurred.

### Incident Location (4)
* **Incident Location** (`incident_location`, text, optional): Describe the location where the incident took place.

### Incident Description (5)
* **Incident Description** (`incident_description`, text, optional): Provide a detailed description of what happened.

### Evidence (6)
* **Evidence** (`evidence`, note, optional): If you have any supporting documents or photos that can help us understand the incident, please attach them to this field.

### Follow-up (7)
* **Follow-up** (`follow_up`, select_one, optional): Please indicate if you would like to be contacted for further discussion regarding this incident.

### Assigned To (8)
* **Assigned To** (`assigned_to`, text, optional): If this incident needs to be assigned to a specific person or team, please enter their name or ID.

### Follow-up Date (9)
* **Follow-up Date** (`follow_up_date`, date, optional): If you would like to be contacted for follow-up on this incident, please enter a date.
