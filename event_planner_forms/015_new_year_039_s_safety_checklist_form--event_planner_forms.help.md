# New Year's Safety Checklist Form - Help Guide
## Purpose
This form is designed for event planners to ensure that all necessary safety measures and protocols are in place for New Year's events, such as parties or gatherings. It helps to identify potential hazards and ensure that attendees are aware of emergency contact information and procedures.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page of the form to understand the questions and options presented.
2. Answer all questions truthfully, marking "Yes" or "No" as applicable.
3. For questions that require multiple selections, choose all relevant options.

## Field-by-Field Explanation

* **Emergency Contacts** (`emergency_contacts`, select_multiple, optional): This field is used to list the names and contact information of emergency contacts, such as first aid staff or medical professionals. Please select "Yes" if these contacts are available, and "No" if not.
* **Emergency Numbers** (`emergency_numbers`, select_one, optional): This field is used to confirm whether emergency numbers, such as 911 or a local emergency number, are available and accessible during the event.
* **Fire Exits** (`fire_exits`, select_multiple, optional): This field is used to identify if all emergency exits are clearly marked and accessible. Please select "Yes" if fire exits are clearly marked and accessible, and "No" if not.
* **Fire Drills** (`fire_drills`, select_one, optional): This field is used to confirm if fire drills are conducted before the event, as a safety measure.
* **Fire Supervision** (`fire_supervision`, select_multiple, optional): This field is used to identify if fire supervision is in place, including fire watch or fire wardens. Please select "Yes" if fire supervision is present, and "No" if not.
* **Electrical Hazards** (`electrical_hazards`, select_one, optional): This field is used to confirm if electrical hazards, such as exposed wiring or faulty electrical equipment, are mitigated. Please select "Yes" if all hazards are mitigated, and "No" if not.
* **Fire Extinguishers** (`fire_extinguishers`, select_multiple, optional): This field is used to identify if fire extinguishers are available and accessible. Please select "Yes" if fire extinguishers are available, and "No" if not.
* **Fire Supervising Officers** (`fire_supervising_officers`, select_one, optional): This field is used to confirm if fire supervising officers are on site and present. Please select "Yes" if fire supervising officers are present, and "No" if not.
