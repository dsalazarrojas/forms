# Gift Basket Order Form Template - Help Guide

## Purpose
The Gift Basket Order Form Template is a tool for customers to place an order for a gift basket. This form collects information about the gift basket products, any personal message, gift card details, and payment and shipping information. It's designed to help customers create a thoughtful and personalized gift for their loved ones.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the products you'd like to include in the gift basket from the list of options.
2.  Add a personal message to include with the gift basket, if desired.
3.  Choose the gift card details, including type, number, expiration date, and expiration year.
4.  Select the payment method you'd like to use.
5.  Enter the price of the gift basket.
6.  Select the shipping method and enter any additional shipping information, if necessary.

## Field-by-Field Explanation
- **Gift Basket Order Form** (`gift_basket_form`, Text): This is the title of the form.
- **Select Gift Basket Products** (`gift_basket_products`, Select Multiple): Select the products you'd like to include in the gift basket.
  - Choose one or more from the list of options (Apple, Banana, Cherry, Date).
- **Message to Include** (`gift_message`, Text): Enter a personal message to include with the gift basket, if desired.
- **Gift Card Details** (`gift_card_details`, Select One): Choose the gift card details.
  - Select one from the options (Card Type, Card Number, Card Expiration Date, Card Security Code).
- **Payment Method** (`gift_payment_method`, Select One): Choose the payment method.
  - Select one from the options (PayPal, Credit Card, Bank Transfer).
- **Gift Basket Price** (`gift_basket_price`, Number): Enter the price of the gift basket.
- **Gift Basket Total** (`gift_basket_total`, Number): This field is likely for internal use and not for customer input.
- **Shipping Method** (`gift_shipping`, Select One): Choose the shipping method.
  - Select one from the options (Shipping Option 1, Shipping Option 2, Shipping Option 3).
- **Gift Option** (`gift_option`, Select Multiple): Select additional gift options, if desired.
  - Choose one or more from the list of options (Gift Option 1, Gift Option 2, Gift Option 3).
- **Recipient** (`gift_recipient`, Text): Enter the recipient's name.
- **Message to Recipient** (`gift_message_to_recipient`, Text): Enter a message to be delivered to the recipient, if desired.
- **Gift Card Details 2** (`gift_card_details_2`, Text): Enter additional gift card details, if desired.
- **Gift Card Number** (`gift_card_number`, Text): Enter the gift card number.
- **Gift Card Expiration Date** (`gift_card_expiration_date`, Date): Enter the gift card expiration date.
- **Gift Card Expiration Month** (`gift_card_expiration_month`, Select One): Choose the gift card expiration month.
  - Select one from the options (January, February, March, April, May, June, July, August, September, October, November, December).
- **Gift Card Expiration Year** (`gift_card_expiration_year`, Select One): Choose the gift card expiration year.
  - Select 'Yes' if the card is active, 'No' if inactive, or Other for custom expiration year.
- **Gift Card Type** (`gift_card_type`, Text): Enter the gift card type, if desired.
- **Gift Basket Price Range** (`gift_basket_price_range`, Select Multiple): Select the gift basket price range.
  - Choose one or more from the list of options (10-20, 21-30, 31-40).
- **Gift Basket Price 2** (`gift_basket_price_2`, Number): This field is likely for internal use and not for customer input.
- **Shipping** (`gift_shipping_2`, Text): Enter the shipping details.
- **Shipping Address** (`gift_shipping_address`, Text): Enter the shipping address.

**Tips**
* Make sure to double-check your selections and input to ensure accuracy.
* Enter a personal message and gift card details to make the gift extra special.
* If you have any questions or issues, contact our customer support team for assistance.
