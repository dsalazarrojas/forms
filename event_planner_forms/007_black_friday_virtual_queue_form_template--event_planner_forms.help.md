# Black Friday Virtual Queue Form Template - Help Guide
## Purpose
This form is used for customers to register for the Black Friday virtual queue to receive an entry position in the queue.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information:
	* **Attendee Name**: Enter the full name of the attendee, as it will appear on their queue entry.
	* **Contact Email**: Provide a valid email address to receive updates on their queue position.
	* **Preferred Notification Channel**: Select how you would like to receive updates (Email, SMS, or Push Notification).
	* **Terms Acknowledgement**: Confirm that you agree to the queue policies.
2. Fill in optional fields with relevant information:
	* **Attendee Name** (if you are bringing guests, add their names here).
	* **Device Type**: Specify the type of device you will be using to access the queue (Desktop, Mobile, or Tablet).
	* **Expected Arrival Time**: Optional time you expect to join the queue.
	* **Additional Guests**: If you are bringing guests, specify the number of people joining with you.
	* **Comments**: Any accessibility needs or notes.
3. Click the submit button to complete the registration process.

## Field-by-Field Explanation
### 1. **Attendee Name** (`attendee_name`, `text`, required)
Enter the full name of the attendee.

### 2. **Contact Email** (`contact_email`, `email`, required)
Enter a valid email address to receive updates on their queue position.

### 3. **Device Type** (`device_type`, `select_one`, optional)
Select the type of device you will be using to access the queue (Desktop, Mobile, or Tablet).

### 4. **Expected Arrival Time** (`expected_arrival_time`, `time`, optional)
Optional time you expect to join the queue.

### 5. **Preferred Notification Channel** (`preferred_channel`, `select_one`, required)
Select how you would like to receive updates (Email, SMS, or Push Notification).

### 6. **Additional Guests** (`additional_guests`, `number`, optional)
Specify the number of guests joining with you.

### 7. **Comments** (`comments`, `text`, optional)
Enter any accessibility needs or notes.

### 8. **Terms Acknowledgement** (`terms_acknowledgement`, `select_one`, required)
Confirm that you agree to the queue policies.

## Tips

* Make sure to fill in all required fields to complete the registration process.
* Select the correct device type and preferred notification channel to receive updates effectively.
* If you are bringing guests, specify their names and number in the "Attendee Name" and "Additional Guests" fields.
