> # Packing List Form - Help Guide
## Purpose
This form is used to gather contact information and camper details for an event planner application. It is intended for use cases where multiple campers may be involved, and the form allows for the selection of multiple campers and additional camper information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the contact information section with the relevant details.
2. Select the correct options for the camper attributes such as diet, allergies, and medical conditions.
3. Choose whether to select multiple campers or add additional camper information.
4. Review and submit the form.

## Field-by-Field Explanation
- **Contact Info (1)** (`contact_info`, text, required/optional): Enter your contact information for this event planning application.
- **Title (2)** (`contact_title`, text, required/optional): Enter your title or position related to the contact information.
- **First Name (3)** (`contact_first_name`, text, required/optional): Enter the first name of the contact person.
- **Last Name (4)** (`contact_last_name`, text, required/optional): Enter the last name of the contact person.
- **Phone (5)** (`contact_phone`, text, required/optional): Enter the phone number of the contact person.
- **Email (6)** (`contact_email`, text, required/optional): Enter the email address of the contact person.
- **Notes (7)** (`contact_notes`, text, required/optional): Enter any additional notes related to the contact information.
- **Supplies (8)** (`campers_supplies`, select_multiple, required/optional): Select whether the campers bring their own supplies or not.
- **Select All (9)** (`select_all`, select_one, required/optional): Select whether to select all campers for this event.
- **Camper Info (10)** (`camper_info`, text, required/optional): Enter additional camper information.
- **First Name (11)** (`camper_first_name`, text, required/optional): Enter the first name of the camper.
- **Last Name (12)** (`camper_last_name`, text, required/optional): Enter the last name of the camper.
- **Age (13)** (`camper_age`, number, required/optional): Enter the age of the camper.
- **Diet (14)** (`camper_diet`, select_one, required/optional): Select the diet preference of the camper.
- **Allergy (15)** (`camper_allergy`, text, required/optional): Enter any allergies of the camper.
- **Medication (16)** (`camper_medication`, text, required/optional): Enter any medications the camper is currently taking.
- **Medical Condition (17)** (`camper_medical_condition`, text, required/optional): Enter any medical conditions of the camper.
- **Select Multiple Campers (18)** (`select_multiple_campers`, select_multiple, required/optional): Select whether multiple campers are involved.
- **Add Camper (19)** (`add_campers`, select_multiple, required/optional): Choose whether to add additional camper information.
- **Submit (20)** (`submit`, select_one, required/optional): Select whether to submit the form.
- **Notes (21)** (`notes`, text, required/optional): Enter additional notes related to the camers.
- **Camper Info2 (22)** (`camper_info2`, text, required/optional): Enter additional camper information.
- **First Name2 (23)** (`camper_first_name2`, text, required/optional): Enter the first name of the additional camper.
- **Last Name2 (24)** (`camper_last_name2`, text, required/optional): Enter the last name of the additional camper.
- **Age2 (25)** (`camper_age2`, number, required/optional): Enter the age of the additional camper.
- **Submit (21)** (`submit`, select_one, required/optional): Select whether to submit the form for the additional camper.
