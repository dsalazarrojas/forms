# Webinar Materials Submission Form - Help Guide
## Purpose
This form is designed to collect information from participants or organizers about a webinar, including session participants, materials, and other essential details.

## How To Complete This Form
To fill out this form correctly, follow these steps:

1. **Enter your name**: In the `Participant Name` field, please enter your name as it appears on your ID or business card.
2. **Indicate session participants**: Choose whether or not you are a session participant by selecting "Yes" or "No" in the `Session Participants` field.
3. **Select webinar start time**: Choose the start time of the webinar from the available options using the `Webinar Start Time` field.
4. **Choose webinar start date**: Select the start date of the webinar using the `Webinar Start Date` field.
5. **Enter your email**: In the `Participant Email` field, enter your email address.
6. **Specify whether a URL is available**: Indicate whether a URL is available for the webinar materials by selecting "Yes" or "No" in the `Webinar URL` field.
7. **Enter materials title**: Enter the title of the materials related to the session in the `Materials Title` field.
8. **Describe the materials**: Provide a brief description of the materials in the `Materials Description` field.
9. **Enter the materials link**: Enter the link to access the webinar materials in the `Materials Link` field.
10. **Enter participant phone number**: Enter your phone number, if applicable, in the `Participant Phone` field.
11. **Add any participant notes**: Provide any additional notes about the participant in the `Participant Note` field.
12. **Add session notes**: Provide any additional notes about the session in the `Session Note` field.
13. **List session hosts**: Indicate whether the current session has hosts by selecting "Yes" or "No" in the `Webinar Hosts` field.
14. **List session materials**: Indicate whether the session materials are available by selecting "Yes" or "No" in the `Session Materials` field.
15. **Enter materials addition date**: Enter the date when the materials were added in the `Materials Added` field.
16. **Enter materials last updated date**: Enter the date when the materials were last updated in the `Materials Last Updated` field.
17. **Specify start time for session 1**: Enter the start time for the first session in the `Session Start Time 1` field.
18. **Specify end time for session 1**: Enter the end time for the first session in the `Session End Time 1` field.
19. **Specify start time for session 2**: Enter the start time for the second session in the `Session Start Time 2` field.
20. **Specify end time for session 2**: Enter the end time for the second session in the `Session End Time 2` field.
21. **List session materials for session 1**: Indicate whether materials are available for session 1 by selecting "Yes" or "No" in the `Session Materials 1` field.
22. **List session materials for session 2**: Indicate whether materials are available for session 2 by selecting "Yes" or "No" in the `Session Materials 2` field.
23. **Specify session host**: Indicate whether the current session has a host by selecting "Yes" or "No" in the `Session Host` field.
