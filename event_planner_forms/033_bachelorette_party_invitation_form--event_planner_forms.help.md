# Bachelorette Party Invitation Form - Help Guide

## Purpose
This Bachelorette Party Invitation Form is designed to collect essential information about the upcoming bachelorette party. It's a crucial tool for the host and the bride-to-be's friends and family to gather the necessary details.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill out the host name field, which is the name of the person or organization hosting the party.
2. Enter the bride-to-be's full name in the bride name field.
3. Select the date for the party in the event date field.
4. Fill out the venue and address field with the location details.
5. Set the RSVP by date for responses in the RSVP by date field.
6. Choose whether you will attend the party in the attending status field.
7. If applicable, list any dietary restrictions in the dietary restrictions field.
8. Indicate whether you will bring a plus one in the plus one field.
9. If you'd like to contribute to a group gift, enter the amount or a note in the contribution to gift field.
10. Write a short congratulatory message for the bride in the message for the bride field.

## Field-by-Field Explanation
- **Host name**: This is the name of the person or organization hosting the party. Enter the correct name for the host.
  - Type: text
  - Required: false
  - Hint: Organizer of the event
- **Bride to be name**: This is the full name of the bride-to-be. Enter her correct name.
  - Type: text
  - Required: true
  - Hint: Full name
- **Event date**: This is the date of the party. Choose the correct date from the calendar or enter the date manually.
  - Type: date
  - Required: true
  - Hint: Date of party
- **Venue and address**: This is the location details of the party. Enter the correct venue and address.
  - Type: text
  - Required: true
  - Hint: Location details
- **RSVP by date**: This is the deadline for responses. Set the correct date for RSVPs.
  - Type: date
  - Required: true
  - Hint: Deadline for responses
- **Attending status**: Choose whether you will attend the party. Select 'True' if you will attend, 'False' if you will not, or 'Maybe' if you're unsure.
  - Type: select_one
  - Required: true
  - Hint: Will you attend
- **Dietary restrictions**: If you have any dietary restrictions, list them here. This is optional.
  - Type: text
  - Required: false
  - Hint: List any allergies
- **Bringing a plus one**: Indicate whether you will bring a plus one. Select 'True' if yes, 'False' if no.
  - Type: select_one
  - Required: false
  - Hint: Indicate yes or no
- **Contribution to gift**: If you'd like to contribute to a group gift, enter the amount or a note here. This is optional.
  - Type: text
  - Required: false
  - Hint: If applicable amount or note
- **Message for the bride**: Write a short congratulatory message for the bride. This is optional.
  - Type: text
  - Required: false
  - Hint: Short congratulatory note
