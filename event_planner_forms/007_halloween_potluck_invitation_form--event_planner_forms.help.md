# Halloween Potluck Invitation Form - Help Guide
## Purpose
The Halloween Potluck Invitation Form is designed to gather information from attendees regarding a Halloween-themed potluck event. Please use this form to RSVP and share what dish you plan to bring.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your contact information on the "Contact Information" page.
2. On the "RSVP" page, select "Yes" if you plan to attend the event.
3. On the "Event Info" page, describe the dish you plan to bring.
4. On the "Date and Time" page, select the date you can attend the event.
5. On the "Time" page, select the time slot you can attend.

## Field-by-Field Explanation
* **Contact Information (Contact Information, text, required/optional)**: This is where you enter your name, email, and any other relevant contact information. Please make sure to include a valid phone number and email address.
* **RSVP (RSVP, select_multiple, required/optional)**: Select "Yes" if you are attending the event, or "No" if you are not. If you are attending but do not know what dish to bring, just select "Yes" and add a comment in "Event Info".
* **Event Info (Event Info, text, required/optional)**: Describe the dish you plan to bring. Please include any necessary ingredients, allergy considerations, or special instructions.
* **Date and Time (Date and Time, select_one, required/optional)**: Select the date you can attend the event from the available options.
* **Time (Time, select_one, required/optional)**: Select the time slot you can attend the event from the available options.

## Tips
* Please make sure to include a valid dish name and description in "Event Info".
* If you are unsure about the event time, select "Yes" on the "RSVP" page and add a comment about your availability.
* If you are bringing a dish that requires special handling or storage, please include those instructions in "Event Info".
* If you have any dietary restrictions or preferences, please mention those in "Event Info" so others can plan accordingly.
