# Event Survey - Help Guide
## Purpose
The Event Survey form is used to gather details about an event, including its title, dates, organizer's contact information, attendees, and ratings.

## How To Complete This Form
To complete this form, please follow these steps:

1. Provide the event title and description in the respective text fields.
2. Enter the start and end dates and times of the event.
3. Enter the organizer's contact information, including email and phone number.
4. Select the attendees who will be attending the event from the options provided.
5. Rate the event using the provided rating scale.
6. Add any additional information about the event in the "Additional Info" field.
7. Enter any comments or suggestions about the event.

## Field-by-Field Explanation

* **Event Title**: Enter the title of the event that you are surveying. This will be the heading for the event in the survey.
* **Event Description**: Enter a brief description of the event to provide context.
* **Start Date**: Enter the date when the event started.
* **Start Time**: Enter the time when the event started.
* **End Date**: Enter the date when the event ended.
* **End Time**: Enter the time when the event ended.
* **Organizer**: Enter the name of the person or organization responsible for the event.
* **Organizer Email**: Enter the email address of the person or organization responsible for the event.
* **Organizer Phone**: Enter the phone number of the person or organization responsible for the event.
* **Attendees**: Select the attendees who will be attending the event from the provided options.
* **Additional Info**: Enter any additional information about the event that you want to provide.
* **Rating**: Rate the event on a scale of 1-5, where 1 is the lowest and 5 is the highest.
* **Comments**: Enter any comments or feedback about the event.
* **Suggestions**: Enter any suggestions for future events.
* **Rating Scale**: Select the rating scale to use for the event, with options for "Scale 1", "Scale 2", "Scale 3", "Scale 4", or "Scale 5".
