# Father's Day Stall Form - Help Guide

## Purpose
The Father's Day Stall Form is a tool used to collect information from event planners to create a Father's Day stall.

## How To Complete This Form
To complete the form, please follow these steps:

1. Ensure you have all the necessary information ready to submit.
2. Fill in the `Name` field with the event planner's name.
3. Enter your `Phone` number in the `phone` field.
4. Enter your `Email` in the `email` field.
5. Choose a date for the `Event Date`.
6. Choose a time for the `Event Time`.
7. Enter the `Event Address` where the stall will be located.
8. Enter the `Event Location` where the stall will be situated.
9. Type a brief `Event Description` of the stall's details.

## Field-by-Field Explanation

* **Name** (`name`, text, required): Enter the event planner's name.
* **Phone** (`phone`, text, required): Enter the event planner's phone number.
* **Email** (`email`, email, required): Enter the event planner's email address.
* **Event Date** (`event_date`, date, required): Choose the date for the Father's Day event.
* **Event Time** (`event_time`, time, required): Choose the time for the Father's Day event.
* **Event Address** (`event_address`, text, required): Enter the address where the event will be held.
* **Event Location** (`event_location`, text, required): Enter the location within the address where the stall will be situated.
* **Event Description** (`event_description`, text, required): Type a brief description of the stall's details.
