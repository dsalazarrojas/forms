# Event Layout Upload Form - Help Guide

## Purpose
The Event Layout Upload Form is a tool for event planners to upload event layouts for various events. It helps in organizing and processing event layouts in a structured and efficient manner.

## How To Complete This Form

1.  **Upload Event Layout**: Select the "Upload Event Layout" page from the form navigation.
2.  **Select Event Type**: Select the type of event from the provided options.
3.  **Upload Event Layout File**: Upload the event layout file as per the specified format.
4.  Enter **Event Details**: Enter the necessary details about the event in the provided text field.
5.  **Event File Type**: Select the type of event file from the options.
6.  **Uploaded By**: Enter your name as the person who uploaded the event layout.
7.  **Uploaded On**: Select the date on which you uploaded the event layout.
8.  **Uploaded By Email**: Enter your email address.
9.  **Uploaded By Phone**: Enter your phone number.
10.  **Comments**: Enter any additional comments about the event layout.
11.  **Uploaded By Phone Country**: Select the country of your phone number.
12.  **Uploaded By Phone Area**: Enter your phone area code.
13.  **Uploaded By Phone Extension**: Enter your phone extension (if applicable).
14.  **Uploaded By Phone Number**: Enter your phone number again.
15.  **Event Planner Email**: Enter the email of the event planner.
16.  **Event Planner Phone**: Enter the phone number of the event planner.
17.  **Event Planner Name**: Enter the name of the event planner.
18.  **Event Planner Company**: Enter the name of the event planner company.
19.  **Event Planner Notes**: Enter any additional notes about the event planner.
20.  **Uploaded By**: Re-enter your name as the person who uploaded the event layout.
21.  **Uploaded On**: Re-enter the date on which you uploaded the event layout.

## Field-by-Field Explanation

* **Title**: This is not a field in the actual form, but a heading for the form title.
* **File**: Select a file to upload event layout for the selected event type.
* **Event Type**: Select the type of event you are uploading the layout for. For example, "Event Type 1" or "Event Type 2".
* **Event Date**: Select the date of the event. For example, "YYYY-MM-DD".
* **Event Time**: Select the time of the event. For example, "HH:MM".
* **Venue**: Select the venue where the event is held.
* **Event Details**: Enter any additional details about the event.
* **Event Layout File**: Upload the event layout file in the specified format.
* **Event File Type**: Select the type of event file you are uploading, for example, "File Type 1" or "File Type 2".
* **Uploaded By**: Enter your name as the person who uploaded the event layout.
* **Uploaded On**: Select the date when you uploaded the event layout.
* **Uploaded By Email**: Enter your email address.
* **Uploaded By Phone**: Enter your phone number.
* **Comments**: Enter any additional comments about the uploaded event layout.
* **Uploaded By Phone Country**: Select the country of your phone number.
* **Uploaded By Phone Area**: Enter your phone area code.
* **Uploaded By Phone Extension**: Enter your phone extension (if applicable).
* **Uploaded By Phone Number**: Enter your phone number again.
* **Event Planner Email**: Enter the email of the event planner.
* **Event Planner Phone**: Enter the phone number of the event planner.
* **Event Planner Name**: Enter the name of the event planner.
* **Event Planner Company**: Enter the name of the event planner company.
* **Event Planner Notes**: Enter any additional notes about the event planner.
* **Uploaded By**: Re-enter your name as the person who uploaded the event layout.
