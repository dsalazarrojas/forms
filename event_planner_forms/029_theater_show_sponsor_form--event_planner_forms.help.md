# Theater Show Sponsor Form - Help Guide
## Purpose
The form is used to collect information from potential sponsors for a theater show event.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide a brief description of the show, including its title, date, and time.
2. Enter the sponsor's details, such as their name and company/organization.
3. Enter the sponsor's contact information, including their email address.
4. Add a message to the sponsor.
5. Review the terms and conditions of the sponsorship.
6. Enter any additional event details if necessary.

## Field-by-Field Explanation

* **Show Details (1)**:
	+ Type: text
	+ Required: No
	+ Description: Enter a brief description of the show, including its title, date, and time.
* **Sponsor Details (2)**:
	+ Type: text
	+ Required: No
	+ Description: Enter the sponsor's name and company/organization.
* **Contact Details (3)**:
	+ Type: text
	+ Required: No
	+ Description: Enter the sponsor's contact information, including their name and email address.
* **Message to Sponsor (4)**:
	+ Type: text
	+ Required: No
	+ Description: Add a personal message to the sponsor.
* **Terms and Conditions (5)**:
	+ Type: text
	+ Required: No
	+ Description: Review the terms and conditions of the sponsorship.
* **Event Details (6)**:
	+ Type: text
	+ Required: No
	+ Description: Enter any additional event details if necessary.
* **Email (7)**:
	+ Type: email
	+ Required: No
	+ Description: Enter the sponsor's email address. 

## Tips
* Make sure to provide accurate and clear information about the show and the sponsor.
* Review the terms and conditions before submitting the form.
* If you have any questions or concerns, contact us at form@gic.mx.
