# Event Crew Rest Area Booking Form - Help Guide
## Purpose

The "Event Crew Rest Area Booking Form" is used to book a rest area for events or conferences. It is designed to collect essential information from the event crew to provide support and services during the event.

## How To Complete This Form

To complete this form, follow these steps:

1.  Determine if the event crew will be present ('Yes' or 'No') and select the corresponding option.
2.  Specify the location where the event crew will be present ('Yes', 'No', or multiple locations).
3.  Choose a valid time slot for the event crew's presence, following the format: `HH:MM - MM/DD/YY` (e.g., 09:00 - 12/12/23).

## Field-by-Field Explanation

*  **team** (Yes/No): Select 'Yes' if you need a rest area for the event crew, 'No' otherwise.
    *   Required
*  **location** (Select Multiple): Choose the location where the event crew will be present.
    *   Required
*  **time_slot**: Choose a valid time slot for the event crew's presence in the format HH:MM - MM/DD/YY.
    *   Required

## Tips

- Please ensure you provide accurate information to avoid any misunderstandings.
- If you need to make changes or cancel your booking, refer to your booking reference number for assistance.
- For more information about rest areas or booking, contact your event coordinator.
