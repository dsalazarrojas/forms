# Movie Night Scheduling Form - Help Guide
## Purpose
This form is designed to help event planners schedule movie nights by collecting relevant details about the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the movie night date in the "Movie Night Date" field.
2. Enter the start time for the movie night in the "Start Time" field.
3. Enter the name of the event in the "Event Name" field.
4. Enter the location for the movie night in the "Location" field.
5. Enter the duration of the event in the "Movie Length" field.
6. Enter the number of attendees for the event in the "Number of Attendees" field.
7. Enter the title of the movie in the "Movie Title" field.
8. Enter a brief description of the movie night in the "Description" field.
9. Choose whether the event is family-friendly or not in the "Is Family Friendly" field.
10. Enter the contact information for the event in the "Contact Name", "Contact Email", and "Contact Phone" fields.
11. If the event is recurring, select the recurrence frequency and enter the recurrence date and time in the corresponding fields.
12. Enter any additional notes about the event in the "Note" field.

## Field-by-Field Explanation

* **Movie Night Date** (1, date, required/optional): Enter the date of the movie night.
* **Start Time** (2, time, required/optional): Enter the start time of the movie night.
* **Event Name** (3, text, required/optional): Enter the name of the event, e.g., "Movie Night: The Avengers".
* **Location** (4, text, required/optional): Enter the location where the movie night will take place.
* **Event Time** (5, time, required/optional): Enter the time the event will occur. 
* **Event End Time** (6, time, required/optional): Enter the time the event will end. 
* **Movie Length** (7, number, required/optional): Enter the length of the movie in minutes.
* **Number of Attendees** (8, number, required/optional): Enter the number of people attending the event.
* **Movie Title** (9, text, required/optional): Enter the title of the movie being shown.
* **Description** (10, text, required/optional): Enter a brief description of the movie night.
* **Is Family Friendly** (12, select_one, required/optional): Select "Yes" if the event is family-friendly, "No" otherwise.
* **Contact Name** (14, text, required/optional): Enter the name of the person responsible for the event.
* **Contact Email** (15, email, required/optional): Enter the email address of the person responsible for the event.
* **Contact Phone** (16, text, required/optional): Enter the phone number of the person responsible for the event.
* **Note** (17, note, required/optional): Enter any additional notes about the event.
* **Is Recurring** (17, select_one, required/optional): Select "Recurring" if the event is recurring, "Non Recurring" otherwise.
* **Recurring Events** (22, select_multiple, required/optional): Select "Yes" if this event is a recurring event, "No" otherwise.
* **Recurrence Frequency** (18, select_multiple, required/optional): Select the frequency of the recurring event, e.g., "Daily", "Weekly", "Monthly".
* **Recurrence Time** (19, time, required/optional): Enter the time the event recurs.
* **Recurrence Date** (20, date, required/optional): Enter the date the event recurs.
* **Recurrence End Date** (21, date, required/optional): Enter the date the event ends.
* **Event ID** (23, text, required/optional): Enter a unique identifier for the event.
* **Form ID** (24, text, required/optional): Enter a unique identifier for the form.
* **Assigned User** (25, text, required/optional): Enter the name of the user responsible for the form.
