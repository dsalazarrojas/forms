# event_interest_form - Help Guide
## Purpose
The "event_interest_form" is used to capture user's interests and preferences for events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select your preferred event type from the options provided.
2. Choose how often you would like to attend a similar event.
3. If you have a specific date and time in mind, provide it in the format "MM/DD/YYYY hh:mm".
4. If you prefer a specific start and end time, enter it in the format "hh:mm AM/PM" or "hh:mm 24h".
5. Enter your preferred location for events.
6. Provide any additional description about your events of interest.
7. Enter your email address, if you would like to be contacted about future events.
8. Enter your phone number, if you would like to be contacted by phone about future events.
9. If you have any other information you would like to share, please enter it in the text box.

## Field-by-Field Explanation

* **Event Type** (`event_type`, select_one): Select the type of event that interests you, such as music, sports, or comedy.
* **How often would you like to attend a similar event?** (`frequency`, select_multiple): Choose how often you would like to attend a similar event, such as daily, weekly, or monthly.
* **Date of Event** (`date_of_event`, date): If you have a specific date in mind, enter it in the format "MM/DD/YYYY".
* **Start Time** (`start_time`, time): If you prefer an early start time, enter it in the format "hh:mm AM/PM" or "hh:mm 24h".
* **End Time** (`end_time`, time): If you prefer a late end time, enter it in the format "hh:mm AM/PM" or "hh:mm 24h".
* **Location** (`location`, text): Enter the location you prefer for events.
* **Description** (`description`, text): Provide any additional description about your events of interest.
* **Email** (`email`, email): If you would like to be contacted by email about future events.
* **Phone** (`phone`, text): If you would like to be contacted by phone about future events.
* **Note** (`note`, note): If you have any other information to share about your events of interest.
* **Event Date** (`event_date`, date): Enter the date you prefer for the event.
* **Event Time** (`event_time`, time): Enter the start and end time you prefer for the event.
* **Event Frequency** (`event_frequency`, select_multiple): Choose how often you would like to attend events with the community.
* **Preferred Time** (`preferred_time`, select_one): Select your preferred time slot for events.
* **Preferred Day** (`preferred_day`, select_one): Select your preferred day of the week for events.
* **Preferred Time 2** (`preferred_time_2`, select_one): Select your second preferred time slot.
* **Preferred Day 2** (`preferred_day_2`, select_one): Select your second preferred day of the week.
