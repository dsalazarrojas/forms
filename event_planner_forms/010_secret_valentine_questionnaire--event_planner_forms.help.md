# Secret Valentine Questionnaire - Help Guide

## Purpose
The Secret Valentine Questionnaire is designed to gather information about your partner's preferences and interests to help you plan the perfect Valentine's Day surprise. This guide will walk you through each section of the form and explain what you need to fill out.

## How To Complete This Form
To complete this form, simply click on the link and fill out each field with your thoughts and feelings. Make sure to answer all the questions that apply to you, and don't worry if you need some time to think about your answers. You can review and edit your answers as many times as you need before submitting the form.

## Field-by-Field Explanation

* **Participant Name** (`participant_name`, text, optional): Enter the name of the person you want to create a Secret Valentine surprise for.
* **Participant Email** (`participant_email`, email, optional): Enter the email address of the participant (if applicable).
* **Message to Participant** (`message_to_participant`, text, optional): Write a personal message for the participant.
* **Gift Idea** (`gift_idea`, text, optional): Share your gift idea for the participant.
* **Message to Valentine** (`message_to_valentine`, text, optional): Write a message for the person you want to surprise.
* **Valentine Message** (`valentine_message`, text, optional): Enter a message to be delivered to the participant on Valentine's Day.
* **Participant Phone** (`participant_phone`, text, optional): Enter the phone number of the participant (if applicable).
* **Valentine Name** (`valentine_name`, text, optional): Enter the name of the person you're planning the surprise for.
* **Valentine Participant Name** (`valentine_participant_name`, text, optional): Enter any additional information about the participant.
* **Gift Message** (`gift_message`, text, optional): Enter a gift message for the participant.
* **Question** (`question_id`, select_one, optional): Answer the question "Do you have a gift idea?" with either "Yes", "Yes, but it's a surprise", "No", or "Not sure".
* **Gift Type** (`gift_type`, select_multiple, optional): Select one or more gift types from the list (Chocolate, Candy, Card, Other).
* **Gift Value** (`gift_value`, number, optional): Enter a gift value (if applicable).
* **Message Type** (`message_type`, select_one, optional): Answer the question "What kind of message do you want to send?" with either "Anonymous", "Signed", "Both", or "Neither".
* **Message Content** (`message_content`, select_multiple, optional): Select one or more message content types from the list (Love Poem, Love Letter, Song, Story).
* **Valentine Type** (`valentine_type`, select_one, optional): Answer the question "What kind of Valentine are you?" with either "Friend", "Family", "Romance", or "Not Sure".
* **Message Timing** (`message_timing`, select_one, optional): Answer the question "When do you want to send the message?" with either "Valentine's Day", "Before Valentine's Day", or "After Valentine's Day".
* **Question 2** (`question_id_2`, select_one, optional): Answer the question "Do you like to receive gifts?" with either "Yes, love them", "No", or "Not sure".
* **Participant Interests** (`participant_interests`, select_multiple, optional): Select the participant's interests from the list (Music, Dance, Sports, Travel).
* **Valentine Interests** (`valentine_interests`, select_multiple, optional): Select the Valentine's interests from the list (Music, Dance, Sports, Travel).
* **Participant Idea** (`participant_idea`, text, optional): Enter any additional ideas for the participant.
* **Valentine Idea** (`valentine_idea`, text, optional): Enter any additional ideas for the Valentine.
* **Participant Note** (`participant_note`, text, optional): Enter any additional notes about the participant.
* **Valentine Note** (`valentine_note`, text, optional): Enter any additional notes about the Valentine.

## Tips
- Make sure to answer all questions that apply to you.
- If you're unsure about a question, don't worry! Just answer with "Not sure" and we'll take care of it.
- If you have any additional thoughts or ideas, feel free to add them in the "Participant Idea" and "Valentine Idea" fields.
- If you have any additional notes, add them in the "Participant Note" and "Valentine Note" fields.
- Review your answers before submitting the form to make sure everything is correct.
