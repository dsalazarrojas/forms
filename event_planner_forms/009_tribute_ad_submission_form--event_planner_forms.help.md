# Tribute Ad Submission Form - Help Guide
## Purpose
The Tribute Ad Submission Form is a tool designed for event planners and organizers to collect information for a tribute or honorarium ad submission. It is meant to be used to gather data from honorees or their representatives and display it in a tribute ad.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the **Tribute Ad Submission** field with a brief description of the tribute or honorarium ad.
2. Provide details about the **Honoree Details** by entering the relevant information for the honoree, this is a required field.
3. If you'd like to share an image of the **Artwork**, you can do so by uploading or linking it here.
4. If you'd like to leave a **Submission Message**, please use this field for any additional comments or information.
5. The **Honorarium** field is for any honorarium information, if applicable.
6. If you've uploaded an **Artwork Image**, please provide a **Description** of the image.
7. Enter the **Honoree Name** as it appears on the tribute ad.
8. Finally, select a **Submission Date** for the tribute ad submission.

## Field-by-Field Explanation
* **Tribute Ad Submission**: A brief description of the tribute or honorarium ad.
	+ This field is used to describe the tribute or honorarium ad. Please keep it concise and clear.
* **Honoree Details**: Required field for honoree information.
	+ This field is required and should contain any relevant information for the honoree.
* **Artwork**: Upload or link an image of the artwork.
	+ This field is optional and should be used to share an image of the artwork.
* **Submission Message**: An optional field for any additional comments or information.
	+ This field is optional and can be used for any additional information about the submission.
* **Honorarium**: An optional field for any honorarium information.
	+ This field is optional and should be used if applicable.
* **Artwork Image**: If you've uploaded an image, please provide a **Description** of it.
	+ This field is optional and should be used if an image has been uploaded.
* **Honoree Name**: Enter the honoree's name as it appears on the tribute ad.
	+ This field is optional and should be entered as per the honoree's name on the tribute ad.
* **Submission Date**: Select the date of submission for the tribute ad.
	+ This field is optional and should be selected as the date of submission for the tribute ad.

## Tips
* Make sure to fill in all required fields.
* Keep the **Tribute Ad Submission** field concise and clear.
* If you've uploaded an **Artwork Image**, make sure to provide a **Description** of it.
