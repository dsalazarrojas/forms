# Upload Form Upload Entry Poster - Help Guide

## Purpose
The purpose of this form is to collect information for uploading an entry poster, which is used for showcasing artwork or talents submitted by users. This form helps to categorize and describe the submitted work, ensuring that it is correctly attributed to the creator.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the category of the artwork or talent you are uploading:
	* If the artwork is a traditional art piece, select "Art".
	* If the artwork is digital, such as a graphic or illustration, select "Digital Art".
	* If the artwork is created by a talent, select "Talent".
	* If the artwork is created by a digital talent, select "Digital Talent".
2. Provide a brief description of the artwork or talent.
3. Upload the artwork or talent file (this field accepts text for description, not actual file upload).
4. Enter your submission title and provide a brief description of why it should be submitted (this field is for text-based submission, not actual file upload).
5. Click the "Submit" button to submit your entry poster.

## Field-by-Field Explanation

* **Art Category** (`art_category`, select_one, required): Select the category of the artwork or talent you are uploading.
* **Talent Category** (`talent_category`, select_one, required): Select the category of the talent that created the artwork.
* **Description** (`description`, text, optional): Provide a brief description of the artwork or talent.
* **Upload Artwork** (`upload_artwork`, text, optional): Enter your submission title and a brief description of why it should be submitted.
* **Submit Entry** (`submit_entry`, text, optional): This field is not used and does not affect the form's functionality.
