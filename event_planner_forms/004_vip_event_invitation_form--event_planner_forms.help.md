# vip_event_invitation_form - Help Guide
## Purpose
The `vip_event_invitation_form` is a form designed to gather information about a VIP event, including event details, contact information, and VIP guest preferences.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event name in the `Event Name` field.
2. Provide a brief description of the event in the `event_description` field.
3. Enter the date of the event in the `Event Date` field.
4. Enter the time of the event in the `Event Time` field.
5. Enter your contact information, including first name, last name, email, and phone number, in the respective fields.
6. Enter the event address, city, state, and zip code in the respective fields.
7. Specify whether the event is a guest list, and if so, enter the list of guests.
8. Indicate if there are VIP guests attending the event, and if so, select 'Yes' in the `VIP Guests` field.
9. Enter the count of VIP guests.
10. Enter a message for VIP guests.
11. Indicate if the event is hosted by a VIP, and if so, select 'Yes' in the `VIP Event Host` field.
12. Enter a message for the VIP event host.
13. Optionally, enter the email of the VIP event host.
14. Optionally, enter a message for VIP guests.

## Field-by-Field Explanation
- **Event Name** (1, text, required): Enter the name of the event.
- **Event Description** (2, text, required): Provide a brief description of the event.
- **Event Date** (3, date, required): Enter the date of the event.
- **Event Time** (4, time, required): Enter the time of the event.
- **Contact First Name** (5, text, required): Enter your first name.
- **Contact Last Name** (6, text, required): Enter your last name.
- **Contact Email** (7, email, required): Enter your email address.
- **Contact Phone** (8, text, required): Enter your phone number.
- **Event Address** (9, text, required): Enter the address of the event.
- **Event City** (10, text, required): Enter the city of the event.
- **Event State** (11, text, required): Enter the state of the event.
- **Event Zip** (12, text, required): Enter the zip code of the event.
- **Guest List** (13, text, required): Enter the list of guests (optional).
- **VIP Guests** (14, select_multiple, required): Indicate if there are VIP guests attending the event.
- **VIP Guests Count** (15, select_one, required): Select the count of VIP guests.
- **VIP Guests Message** (16, text, required): Enter a message for VIP guests.
- **VIP Event Host** (17, select_one, required): Indicate if the event is hosted by a VIP.
- **VIP Event Host Message** (18, text, optional): Enter a message for the VIP event host.
- **VIP Event Host Email** (19, email, optional): Enter the email of the VIP event host.
- **VIP Guest Message** (20, text, optional): Enter an optional message for VIP guests.
