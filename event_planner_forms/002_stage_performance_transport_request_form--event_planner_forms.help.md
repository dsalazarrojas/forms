# Stage Performance Transport Request Form - Help Guide
## Purpose
This form is used to request transportation services for stage performances. Event planners and coordinators use this form to provide information about the event, crew, and transportation requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* `Event Name`: Enter the name of the event you are planning.
	* `Crew Number`: Enter the number of crew members that will be attending the event.
2. Provide information about the transportation:
	* `Transport Date`: Enter the date when you need the transportation services.
	* `Pickup Location`: Enter the location where you need the crew to be picked up.
	* `Dropoff Location`: Enter the location where you need the crew to be dropped off.
3. Estimate the travel time:
	* `Estimated Travel Time`: Enter the estimated time it will take to transport the crew.
4. Choose transportation options:
	* `Transport Type`: Select whether you need transportation (Yes) or not (No).
	* `Transport Details`: If you need any special transportation arrangements, enter them here.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required/optional): Enter the name of the event you are planning.
* **Performer Name** (`performer_name`, text, required/optional): Enter the name of the performer or artist performing at the event.
* **Crew Number** (`crew_number`, number, required/optional): Enter the number of crew members that will be attending the event.
* **Equipment Count** (`equipment_count`, number, required/optional): Enter the number of equipment pieces that need to be transported.
* **Transport Date** (`transport_date`, date, required/optional): Enter the date when you need the transportation services.
* **Pickup Location** (`pickup_location`, text, required/optional): Enter the location where you need the crew to be picked up.
* **Dropoff Location** (`dropoff_location`, text, required/optional): Enter the location where you need the crew to be dropped off.
* **Estimated Travel Time** (`estimated_travel_time`, time, required/optional): Enter the estimated time it will take to transport the crew.
* **Transport Type** (`transport_type`, select_multiple, required/optional): Select whether you need transportation (Yes) or not (No).
* **Transport Details** (`transport_details`, text, required/optional): If you need any special transportation arrangements, enter them here.
* **Event Date** (`event_date`, date, required/optional): Enter the date of the event you are planning.

## Tips
* Ensure that you have checked the event date and crew details carefully before submitting this form.
* If you have already submitted this form for the same event, do not submit again as this may cause unnecessary duplication of effort and affect the transportation planning process.
