# Event Sponsorship Form - Help Guide
## Purpose
This form is used to capture information about potential event sponsors. Sponsors will be listed on event promotional materials and may have exclusive recognition at the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your name and any other relevant details in the "Sponsor Details" field.
2. Indicate the amount of money you are willing to sponsor the event in the "Sponsorship Amount" field.
3. Select the type of sponsor you would like to be recognized as (Company, Individual, or Organization) in the "Sponsor Type" field.
4. If you have any additional message or message you would like to convey to the event organizers, you can type it in the "Sponsor Message" field.
5. Provide your contact information in the "Sponsor Contact Info" field so we can get in touch with you if needed.

## Field-by-Field Explanation

* **Sponsor Details** (`id: 2`, text, required: false): Enter your name and any other relevant details about yourself or your organization.
* **Sponsorship Amount** (`id: 3`, number, required: false): Indicate the amount of money you are willing to sponsor the event. Please enter a number value.
* **Sponsor Type** (`id: 4`, select_one, required: false): Choose the type of sponsor you would like to be recognized as (Company, Individual, or Organization).
* **Sponsor Message** (`id: 5`, text, required: false): Type any additional message or message you would like to convey to the event organizers.
* **Sponsor Contact Info** (`id: 6`, text, required: false): Enter your contact information so we can get in touch with you if needed.

Note: All fields are optional, but please note that providing some information will help us better recognize and appreciate your sponsorship.
