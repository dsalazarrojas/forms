# Drive In Halloween Registration Form - Help Guide
## Purpose
The Drive In Halloween Registration Form is designed to collect essential information from event organizers and participants for a successful and enjoyable experience. It's essential to fill out the form accurately and without duplication to avoid any confusion or miscommunication.

## How To Complete This Form

1. Fill out the form completely and accurately.
2. Make sure to review each field carefully to ensure you're providing the correct information.
3. If you're unsure about any field, refer to the field-by-field explanation below.

## Field-by-Field Explanation

* **Drive In Halloween Event** (`drive_in_halloween_event`): Enter a brief description of the event (e.g., "Costume Contest").
* **Name** (`name`): Enter your full name (first name, last name, and any titles, e.g., Mr., Ms., Dr.).
* **Email** (`email`): Enter your email address for communication.
* **Phone** (`phone`): Enter your phone number for communication.
* **Participant Count** (`participant_count`): Enter the number of participants expected.
* **Event Date** (`event_date`): Enter the date of the event in the format MM/DD/YYYY.
* **Event Time** (`event_time`): Enter the time of the event in the format HH:MM AM/PM or 24-hour format.
* **Event Time Note** (`event_time_note`): Enter any notes or comments about the event time (optional).
* **Event Location** (`event_location`): Choose where the event will take place, Home, Away, or Office.
* **Drive In Halloween Event Note** (`drive_in_halloween_event_note`): Enter any notes or comments about the event (optional).
* **Participant Age** (`participant_age`): Enter the age of the participant (optional).
* **Participant Age Range** (`participant_age_range`): Select the age range of the participant (10-13, 14-17, 18-21, 22-25).
* **Drive In Halloween Event Details** (`drive_in_halloween_event_details`): Enter the details of the event.
* **Drive In Halloween Event Details Note** (`drive_in_halloween_event_details_note`): Enter any notes or comments about the event details (optional).
* **Drive In Halloween Event Organizer** (`drive_in_halloween_event_organizer`): Enter the name of the event organizer or contact person.
* **Drive In Halloween Event Organizer Phone** (`drive_in_halloween_event_organizer_phone`): Enter the phone number of the event organizer or contact person.
* **Drive In Halloween Event Organizer Email** (`drive_in_halloween_event_organizer_email`): Enter the email address of the event organizer or contact person.
* **Drive In Halloween Event Organizer Location** (`drive_in_halloween_event_organizer_location`): Choose where the event will take place, Home, Away, or Office.
* **Drive In Halloween Event Organizer Note** (`drive_in_halloween_event_organizer_note`): Enter any notes or comments about the event organizer (optional).
* **Drive In Halloween Event Attendees** (`drive_in_halloween_event_attendees`): Select who will be attending the event (Friend, Family, Colleagues, Coworkers).
* **Drive In Halloween Event Dress Code** (`drive_in_halloween_event_dress_code`): Select the dress code for the event (Formal, Casual, Business).
* **Drive In Halloween Event Food** (`drive_in_halloween_event_food`): Select the type of food that will be served at the event (Food, Snacks, Drinks).
* **Drive In Halloween Event Favors** (`drive_in_halloween_event_favors`): Select if favors will be given at the event (Favors, No Favors).
* **Drive In Halloween Event Parking** (`drive_in_halloween_event_parking`): Select if there will be parking available at the event (Parking, No Parking).
* **Drive In Halloween Event Notes** (`drive_in_halloween_event_notes`): Enter any notes or comments about the event (optional).

## Tips

* Make sure to double-check your email address and phone number for accuracy.
* If you're unsure about any field, refer to the field-by-field explanation above.
* If you have any questions or concerns, contact the event organizer or contact person listed in the form.
