# Mother's Day Raffle Form - Help Guide
## Purpose
This form is designed to collect participant and event information for the Mother's Day raffle event.

## How To Complete This Form
- Fill out all required fields marked as required.
- For optional fields, provide as much detail as you can.
- Review your entries before submitting to ensure accuracy and completeness.

## Field-by-Field Explanation
- **Raffle Name** (`raffle_name`, text, optional): Enter the name of the raffle event.
- **Participant Name** (`participant_name`, text, optional): Enter the name of the participant.
- **Email** (`email`, email, optional): Enter the participant's email address.
- **Phone** (`phone`, text, optional): Enter the participant's phone number.
- **Participant Type** (`participant_type`, select_multiple, optional): Select the type of participant (Mother, Child, Family, Friend).
- **Participant Age Range** (`participant_age_range`, select_one, required): Select the participant's age range (0-5, 6-15, 16-30, 31+).
- **Participant Gender** (`participant_gender`, select_multiple, optional): Select the participant's gender (Male, Female, Other).
- **Number of Tickets** (`raffle_number_of_tickets`, number, optional): Enter the number of tickets to be purchased.
- **Ticket Price** (`ticket_price`, number, optional): Enter the price of each ticket.
- **Draw Date** (`draw_date`, date, optional): Enter the date of the draw.
- **Draw Time** (`draw_time`, time, optional): Enter the time of the draw.
- **Prize Description** (`prize_description`, text, optional): Enter a description of the prize.
- **Raffle Organizer Name** (`raffle_organizer_name`, text, optional): Enter the name of the raffle organizer.
- **Raffle Organizer Email** (`raffle_organizer_email`, text, optional): Enter the email of the raffle organizer.
- **Raffle Organizer Phone** (`raffle_organizer_phone`, text, optional): Enter the phone number of the raffle organizer.
- **Event Date** (`event_date`, date, optional): Enter the date of the event.
- **Event Time** (`event_time`, time, optional): Enter the time of the event.
- **Event Location** (`event_location`, text, optional): Enter the location of the event.
- **Event Description** (`event_description`, text, optional): Enter a description of the event.
- **Event Poster** (`event_poster`, text, optional): Enter the name of the event poster.
- **Raffle Rules** (`raffle_rules`, text, optional): Enter the rules of the raffle.
- **Participant Comments** (`participant_comments`, text, optional): Enter any comments about the participant.
- **Raffle Status** (`raffle_status`, select_one, optional): Select the status of the raffle (Open, Closed, Started, Ended).
- **Participant Comments** (`participant_comments`, text, optional): Enter any comments about the participant.
