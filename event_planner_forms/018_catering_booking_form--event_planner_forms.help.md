# Catering Booking Form - Help Guide
## Purpose
This form is for event planners to book catering services for their events. It is a comprehensive form that captures essential information about the event and the client's preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your personal details (Client Full Name, Email Address, Phone Number) and event details (Event Name, Event Date, Event Start and End Time).
2. Select the type of event and venue.
3. Choose your preferred menu and beverage package.
4. Provide any special requests or additional comments.
5. Confirm that you have paid the deposit and signed the contract.
6. Fill in the booking date and any additional comments.

## Field-by-Field Explanation

* **Client Full Name** (Required): Your full name.
* **Email Address** (Required): Your email address.
* **Phone Number** (Required): Your contact phone number.
* **Company or Organization** (Optional): Your organization name.
* **Event Name** (Required): Name or title of your event.
* **Event Type** (Required): Select one of the following options:
	+ Wedding
	+ Corporate Event
	+ Birthday Party
	+ Anniversary
	+ Graduation
	+ Conference
	+ Private Party
	+ Holiday Party
	+ Other
* **Event Date** (Required): Date of your event.
* **Event Start Time** (Required): When does the event start?
* **Event End Time** (Required): When does the event end?
* **Venue Name** (Required): Name of the venue.
* **Venue Address** (Required): Complete address of the venue.
* **Number of Guests** (Required): Expected guest count.
* **Menu Selection** (Required): Select one of the following options:
	+ Breakfast Package
	+ Lunch Package
	+ Dinner Package
	+ Cocktail Reception
	+ Buffet Style
	+ Plated Service
	+ Custom Menu
* **Beverage Package** (Required): Select one of the following options:
	+ Non-Alcoholic Only
	+ Beer and Wine
	+ Full Bar
	+ Coffee and Tea Service
	+ No Beverage Service
* **Dietary Requirements** (Required): List all dietary restrictions.
* **Vegetarian Meals Needed** (Optional): Number of vegetarian meals.
* **Vegan Meals Needed** (Optional): Number of vegan meals.
* **Gluten-Free Meals Needed** (Optional): Number of gluten-free meals.
* **Additional Services** (Optional): Select any of the following:
	+ Tables and Chairs
	+ Linens
	+ China and Silverware
	+ Glassware
	+ Serving Staff
	+ Bartenders
	+ Setup and Cleanup
	+ Decorations
* **Special Requests** (Optional): Any special requirements.
* **Deposit Paid** (Required): Confirm if you have paid the deposit.
* **Contract Signed** (Required): Confirm if you have signed the contract.
* **Booking Date** (Required): Date of this booking.
* **Additional Comments** (Optional): Any other information.

Please note that all fields are marked as required for a specific reason, and they must be filled before submitting the form.
