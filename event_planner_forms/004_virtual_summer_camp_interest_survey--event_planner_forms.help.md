# Virtual Summer Camp Interest Survey - Help Guide
## Purpose

This guide will walk you through the purpose and requirements of the Virtual Summer Camp Interest Survey form.

## How To Complete This Form

1.  Review the form carefully and make sure you are completing it for the right purpose.
2.  Fill in the required fields (indicated by an asterisk \*).

## Field-by-Field Explanation

* **Virtual Summer Camp Interest Survey** (`virtual_summer_camp_interest_survey`, Text, Optional): This is the title of the form and should not be filled in.
* **Camper Name** (`camper_name`, Text, Optional): This is where you should input your or your child's name.
* **Camper Age** (`camper_age`, Number, Optional): This is where you should input your or your child's age.
* **Email** (`email`, Email, Optional): This is where you should input a valid email address.
* **Camper Phone** (`camper_phone`, Text, Optional): This is where you should input a valid phone number.
* **Session Time** (`session_time`, Time, Optional): This is where you should input the time you would prefer your session to be.
* **Camper Attendance** (`camper_attendance`, Select One, Optional): This is where you should select which session you would prefer to attend (if any). Please select one of the options provided.
* **Session Length** (`session_length`, Number, Optional): This is where you should input the duration of the session you would prefer.
* **Additional Info** (`additional_info`, Note, Optional): This is where you can add any additional information you think would be useful.
* **Session Date** (`session_date`, Date, Optional): This is where you should input the date you would prefer your session to be.
* **Camper Interest** (`camper_interest`, Select Multiple, Optional): This is where you should select which activities you or your child are interested in (Art, Music, Games).
* **Session Frequency** (`session_frequency`, Select Multiple, Optional): This is where you should select how often you or your child would like to attend a session (Yes, No).
* **Camper Interest Other** (`camper_interest_other`, Text, Optional): This is where you can add any other activities you or your child are interested in.
* **Camper Phone Number** (`camper_phone_number`, Text, Optional): This is where you should input a valid phone number.
* **Camper Interest Other 2** (`camper_interest_other_2`, Text, Optional): This is where you can add any other activities you or your child are interested in.
* **Session Time 2** (`session_time_2`, Time, Optional): This is where you should input the time you would prefer your session 2 to be.
* **Camper Phone Number 2** (`camper_phone_number_2`, Text, Optional): This is where you should input a valid phone number.
* **Camper Attendance 2** (`camper_attendance_2`, Select One, Optional): This is where you should select which session 2 you would prefer to attend (if any). Please select one of the options provided.
* **Session Frequency 2** (`session_frequency_2`, Select Multiple, Optional): This is where you should select how often you or your child would like to attend session 2 (Yes, No).
* **Session Date 2** (`session_date_2`, Date, Optional): This is where you should input the date you would prefer session 2 to be.
* **Camper Interest 2** (`camper_interest_2`, Select Multiple, Optional): This is where you should select which activities you or your child are interested in (Art, Music, Games).
* **Camper Phone Number 3** (`camper_phone_number_3`, Text, Optional): This is where you should input a valid phone number.
* **Session Frequency 3** (`session_frequency_3`, Select Multiple, Optional): This is where you should select how often you or your child would like to attend session 3 (Yes, No).
* **Camper Interest 3** (`camper_interest_3`, Select Multiple, Optional): This is where you should select which activities you or your child are interested in (Art, Music, Games).

## Tips

- Please make sure to fill in all the required fields correctly.
- Make sure to select all the relevant options for your or your child's preferences.
- If you have any other activities or preferences that are not listed, you can add them in the "Additional Info" field.
- If you have any questions or concerns, please contact the summer camp staff.
