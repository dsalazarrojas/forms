# Event Sound Amplifier Booking Form - Help Guide
## Purpose

This form is designed to help event planners book a sound amplifier system for their events. It collects information about the event details, sound system requirements, and payment methods.

## How To Complete This Form

To complete this form, follow these steps:

* Select the event details and sound system requirements
* Fill in the event details, including date, start and end times, and location
* Choose the sound system packages that meet your needs
* Indicate your payment details, including payment method and cost

## Field-by-Field Explanation

* **Event Sound System** (`event_soundsystem`, select_multiple, required: false)
Select whether you need a sound system for your event
* **Event Details** (`event_details`, text, required: false)
Fill in the event details, including date, start and end times, and location
* **Location** (`location`, text, required: false)
Enter the location of the event
* **Event Date** (`event_date`, date, required: false)
Select the date of the event
* **Start Time** (`start_time`, time, required: false)
Select the start time of the event
* **End Time** (`end_time`, time, required: false)
Select the end time of the event
* **Sound System Packages** (`sound_system_packages`, select_multiple, required: false)
Choose the sound system packages that meet your needs
* **Package Cost** (`package_cost`, number, required: false)
Fill in the package cost
* **Total Cost** (`total_cost`, number, required: false)
Fill in the total cost
* **Payment Details** (`payment_details`, note, required: false)
Fill in any additional payment details
* **Payment Method** (`payment_method`, select_multiple, required: false)
Select the payment method
* **Email** (`email`, email, required: false)
Enter your email address
* **Phone** (`phone`, text, required: false)
Enter your phone number
* **Comments** (`comments`, text, required: false)
Fill in any additional comments
* **Assigned** (`assigned_tool`, text, required: false)
Select the tool assigned to the event
* **User** (`assigned_user`, text, required: false)
Select the user assigned to the event
* **Form Comments** (`form_comments`, text, required: false)
Fill in any comments about the form
* **Status** (`status`, text, required: false)
Fill in the status of the event
* **Event Status** (`event_status`, select_multiple, required: false)
Select the status of the event
* **Event Category** (`event_category`, select_multiple, required: false)
Select the category of the event
* **Package Status** (`package_status`, select_multiple, required: false)
Select the status of the package
* **Event Planner** (`event_planner`, text, required: false)
Fill in the event planner
* **Event Venues** (`event_venues`, text, required: false)
Fill in the event venues
* **Event Locations** (`event_locations`, text, required: false)
Fill in the event locations

Note: Some fields are not required, but it's best to fill them out for accuracy and to ensure that your event is properly booked.
