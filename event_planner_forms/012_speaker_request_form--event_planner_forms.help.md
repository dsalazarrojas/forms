# Speaker Request Form - Help Guide

## Purpose
This form is designed to collect information about speakers who would like to present at your event. It will help us understand your needs, preferences, and goals, so we can best tailor our response to fit your needs.

## How To Complete This Form
1. Fill out the form with the requested information:
	* Speaker Information (page 1): Provide a brief description of the type of speaker you are interested in.
	* Speaker Information (page 2):
		+ Speaker Name: Enter the speaker's name.
		+ Speaker Email: Enter the speaker's email address.
		+ Speaker Phone: Enter the speaker's phone number.
2. Add event details:
	* Event Title (page 2): Enter the title of the event you are interested in.
	* Event Date and Time (page 2): Select the date and time of the event.
	* Event Location (page 2): Enter the location of the event.
3. Leave a message for the speaker:
	* Speaker Request Message (page 2): Provide any additional information or requests you have for the speaker.

## Field-by-Field Explanation

* **Speaker Information**: A brief description of the type of speaker you are interested in (optional).
* **Speaker Name** (`speaker_name`, `text`, required/optional): Enter the speaker's name.
* **Speaker Email** (`speaker_email`, `email`, required/optional): Enter the speaker's email address. Please ensure you enter a valid email address.
* **Speaker Phone** (`speaker_phone`, `text`, required/optional): Enter the speaker's phone number.
* **Event Title** (`event_title`, `text`, required/optional): Enter the title of the event you are interested in.
* **Event Date** (`event_date`, `date`, required/optional): Select the date of the event.
* **Event Time** (`event_time`, `time`, required/optional): Select the time of the event.
* **Event Location** (`event_location`, `text`, required/optional): Enter the location of the event.
* **Speaker Request Message** (`speaker_request_message`, `note`, required/optional): Provide any additional information or requests you have for the speaker.
