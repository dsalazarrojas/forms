# Cancellation Or Postponement Voting Form - Help Guide

## Purpose
This form is used to gather opinions on whether the event should be cancelled or postponed due to unforeseen circumstances.

## How To Complete This Form

1.  **Select a single option for "How should we proceed with this event?"**
    * This field allows you to vote on whether the event should be cancelled, postponed, or proceed as scheduled. You can select only one option from the provided choices.
2.  **Provide a reason for cancellation (if applicable)**
    * If you selected "Cancel the event completely" in the previous field, please provide your primary reason for cancellation from the list of options provided.
3.  **Suggest a postponement date (if applicable)**
    * If you selected "Postpone to a later date" in the previous field, please suggest a date for the postponed event.
4.  **List any primary concerns**
    * Please select all that apply from the list of options, as they relate to your concerns about the event.
5.  **Assess the impact**
    * Indicate how the cancellation or postponement would affect you, whether positively or negatively.
6.  **Virtual attendance**
    * Select how you would feel about attending a virtual version of this event.
7.  **Additional comments**
    * Share any other thoughts or suggestions you may have regarding the event.
8.  **Contact for updates**
    * Let us know if you wish to be contacted for updates regarding this decision.
9.  **Confirm your vote**
    * Please confirm that your vote reflects your honest opinion.

    *   This field is only visible if you selected "Cancel the event completely" in the previous field.

    *   This field is only visible if you selected "Postpone to a later date" in the previous field.

    *   This field is only visible if you selected "Postpone to a later date" in the previous field.
