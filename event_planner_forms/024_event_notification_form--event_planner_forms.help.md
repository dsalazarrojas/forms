# Event Notification Form - Help Guide
## Purpose
The Event Notification Form is a tool used to notify various stakeholders about events that require attention or action. This form helps ensure that the right people are informed and can respond promptly to events such as meetings, concerts, weddings, and other activities that may impact the community or require special handling.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the required fields: **Event Date** and **Event Time** to provide a specific date and time for the event.
2. Provide a brief description of the event in the **Event Description** field.
3. Check the relevant boxes in the **Notify Authorities** field to select who should be notified about the event.
4. Select the type of event this is in the **Event Type** field.
5. Enter a contact number and email address for further information in the **Contact Number** and **Contact Email** fields, respectively.
6. Choose the tool and user that will be assigned to handle the event in the **Assigned Tool** and **Assigned User** fields, respectively.
7. Add any additional notes or information about the event in the **Additional Notes** field.
8. Finally, select the submission status of the event in the **Submission Status** field.

## Field-by-Field Explanation
* **Event Details** (`event_notification_form`): Briefly describe the event and its purpose.
* **Event Date** (`event_date`): Provide the date of the event in the format `YYYY-MM-DD`.
* **Event Time** (`event_time`): Provide the time of the event in the format `HH:MM AM/PM` or `HH:MM 24H` (e.g., 8:00 AM or 14:00 24H).
* **Event Location** (`event_location`): Provide the location of the event.
* **Event Description** (`event_description`): Briefly describe the event and its significance.
* **Event Status** (`event_status`): Select the current status of the event from the options: Active, Inactive, Cancelled, or Reopened.
* **Notify Authorities** (`notify_authorities`): Check the boxes for Police, Mayor, Fire Department, or other relevant authorities that should be notified.
* **Event Type** (`event_type`): Select the type of event from the options: Meeting, Concert, Wedding, or other types of events.
* **Contact Number** (`contact_number`): Enter a contact number for further information about the event.
* **Contact Email** (`contact_email`): Enter a contact email address for further information about the event.
* **Assigned Tool** (`assigned_tool`): Choose the tool assigned to handle the event.
* **Assigned User** (`assigned_user`): Choose the user that will handle the event.
* **Additional Notes** (`additional_notes`): Add any additional information or comments about the event.
* **Submission Status** (`submission_status`): Select the status of the submission from the options: Approved, In Progress, Reopened, Closed, or Rejected.
