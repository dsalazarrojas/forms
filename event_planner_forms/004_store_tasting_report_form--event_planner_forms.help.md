# Store Tasting Report Form - Help Guide

## Purpose
This guide will walk you through completing the Store Tasting Report Form. Please follow the instructions below to ensure that you fill out the form correctly.

## How To Complete This Form
1. Fill out the Store Tasting Form with the following information:
	* Store Name: Enter the name of the store that hosted the tasting event.
	* Event Name: Enter the name of the event that took place at the store.
2. Enter the dates for both the Event Date and Date of Tasting, making sure to follow the date format specified.
3. If a store manager was present, enter their name and contact phone number.

## Field-by-Field Explanation
* **Store Name**: Enter the name of the store that hosted the tasting event. For example: "Fine Wine & Co."
* **Event Name**: Enter the name of the event that took place at the store. This could be a wine-tasting event, a sale, or any other store event. For example: "Wine Tasting Night"
* **Date of Tasting**: Enter the date on which the event took place. Please format the date according to your system's date format (e.g., YYYY-MM-DD).
* **Event Date**: Enter the date when the event was scheduled to take place. This should match the date of the actual event.
* **Store Manager**: If a store manager was present during the event, enter their name here.
* **Store Manager Phone**: If a store manager's contact phone number is available, enter it here.
