# Show Day Of The Week Form - Help Guide
## Purpose
The Show Day Of The Week Form is used to gather feedback about whether the event planner should display the day of the week for each event date.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose whether to show the day of the week for each event date.
2. Select the date you want to associate with the feedback.
3. Select whether to show the day of the week for the chosen date.

## Field-by-Field Explanation
* **Show Day of the Week** (`show_day_of_week_form`, `select_one`, not required): Choose whether to show the day of the week for each event date. This field is not required.
* **Date** (`date`, `date`, not required): Select the date you want to associate with the feedback. This field is not required.
* **Day of the Week** (`show_day_of_week`, `select_one`, not required): This field is actually asking whether the day of the week is available for the selected date. Select "Yes" if it is, "No" otherwise.
* **Day of the Week** (`show_day_of_week`, `select_one`, not required): This field is asking the same question as the previous one, but it seems there are multiple fields with the same label. To ensure accurate data collection, choose "Yes" if you want to show the day of the week for events on this date, and "No" if it should not be shown.
* **Day of the Week** (`show_day_of_week`, `select_one`, not required): This field is also asking the same question as the previous ones. Choose "Yes" if you want to show the day of the week for events on this date, and "No" if it should not be shown.

## Tips
* Make sure to fill in the correct field for each question.
* Be accurate when selecting the date and choosing whether to show the day of the week.
