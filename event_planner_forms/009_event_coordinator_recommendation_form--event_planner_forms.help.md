# event_coordinator_recommendation_form - Help Guide
## Purpose
This form is used for event planners to recommend events to the organization's management for approval. It gathers information about upcoming events, including date, time, and location, to facilitate informed decisions about event planning.

## How To Complete This Form
1. Fill out the form with the requested information about the event.
2. Make sure to provide all required fields (marked as "required").
3. Check the organization's event calendar to ensure that you are not duplicating an already scheduled event.

## Field-by-Field Explanation
* **event_coordinator** (Text, required): Provide the name and title of the event coordinator responsible for this event.
* **event_date** (Date, not required): Enter the date of the event. Use the MM/DD/YYYY format (e.g., 05/01/2023 for May 1st, 2023).
* **event_time** (Time, not required): Enter the start and end time of the event. Use the HH:MM format (e.g., 08:00 for 8:00 AM).
* **event_location** (Text, not required): Provide the location of the event (e.g., conference room, park, or city).
* **event_notes** (Note, not required): Add any additional notes about the event. This can be a brief description of the event, its purpose, or any other relevant information.
