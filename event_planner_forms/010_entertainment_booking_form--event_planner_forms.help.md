# Entertainment Booking Form - Help Guide
## Purpose
The Entertainment Booking Form is used to collect information about an upcoming event or performance in the entertainment industry. This form helps event planners or bookers gather necessary details about the event, including dates, performer availability, event duration, contact information, and other relevant details.

## How To Complete This Form
1. Fill out the form with the required information.
2. Make sure to double-check for any errors or inconsistencies before submission.

## Field-by-Field Explanation
* **Booking Date**: The date of the event or performance.
* **Performer Details**: Select whether the performer is available or not.
* **Performance Duration**: The length of the performance, in hours or minutes.
* **Event Information**: A brief description of the event or performance.
* **Client Name**: The name of the client or organization booking the event.
* **Contact Number**: The phone number of the client or contact person.
* **Email**: The email address of the client or contact person.
* **Event Time**: The time of the event or performance.
* **Event Location**: The location of the event or performance.
* **Event Description**: A brief description of the event or performance.

## Tips
* Make sure to fill out all required fields before submission.
* Double-check for any errors or inconsistencies before submission.
* If you have any questions or concerns, contact your event planner or contact person for assistance.
