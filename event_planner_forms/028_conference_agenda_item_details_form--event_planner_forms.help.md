# Conference Agenda Item Details Form - Help Guide
## Purpose
This form is used to submit detailed information about items to be included in a conference agenda.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Enter the conference name in the `Conference Name` field.
2. Select the date of the item from the calendar in the `Conference Date` field.
3. Enter your name and email in the `Submitter Name` and `Submitter Email` fields, respectively.
4. Select your role within the conference in the `Submitter Role` field.
5. Enter the title of the item in the `Item Title` field.
6. Select the type of the item from the options in the `Item Type` field.
7. Enter a brief description of the item in the `Item Description` field.
8. Enter the scheduled date and time of the item in the `Scheduled Date` and `Start Time` fields, respectively.
9. Select the audio visual needs of the item in the `Audio Visual Needs` field.
10. If applicable, select the catering needs of the item in the `Catering Needs` field.
11. Select the current status of the item in the `Item Status` field.
12. Enter any additional notes about the item in the `Additional Notes` field.

## Field-by-Field Explanation
* **Agenda Item Details** (`agenda_header`, note, optional): This is a note field where you can enter any additional details about the item.
* **Conference Name** (`conference_name`, text, required): Enter the name of the conference.
* **Conference Date** (`conference_date`, date, required): Select the date of the conference from the calendar.
* **Submitter Name** (`submitter_name`, text, required): Enter your name as the submitter of the item.
* **Submitter Email** (`submitter_email`, email, required): Enter your email address as the contact information for the submitter.
* **Submitter Role** (`submitter_role`, select_one, required): Select your role within the conference (Organizer, Speaker, Session Chair, Committee Member, Staff, Other).
* **Item Title** (`item_title`, text, required): Enter the title of the item.
* **Item Type** (`item_type`, select_one, required): Select the type of item (Keynote Speech, Panel Discussion, Workshop, Breakout Session, Networking Event, Meal Break, Coffee Break, Opening Ceremony, Closing Ceremony, Other).
* **Item Description** (`item_description`, text, required): Enter a brief description of the item.
* **Scheduled Date** (`scheduled_date`, date, required): Select the date when the item occurs.
* **Start Time** (`start_time`, time, required): Select the start time of the item.
* **End Time** (`end_time`, time, required): Select the end time of the item.
* **Location Details** (`location_details`, note, optional): Enter any additional details about the location of the item.
* **Venue Room** (`venue_room`, text, optional): Enter the room number or name where the item takes place.
* **Building** (`building`, text, optional): Enter the building name where the item takes place.
* **Floor** (`floor`, text, optional): Enter the floor level where the item takes place.
* **Expected Capacity** (`capacity`, number, optional): Enter the expected number of attendees for the item.
* **Participants** (`participants`, note, optional): Enter any participants involved in the item.
* **Speaker Names** (`speaker_names`, text, optional): Enter the names of the speakers for the item.
* **Speaker Bios** (`speaker_bios`, text, optional): Enter brief biographies of the speakers for the item.
* **Moderator Name** (`moderator_name`, text, optional): Enter the name of the moderator for the item.
* **Technical Requirements** (`technical_requirements`, note, optional): Enter any technical requirements for the item.
* **Audio Visual Needs** (`av_needs`, select_multiple, optional): Select the audio visual needs of the item (Projector, Microphone, Speakers, Laptop, Whiteboard, Video Conferencing, Recording Equipment, Lighting).
* **Special Requirements** (`special_requirements`, text, optional): Enter any special requirements for the item.
* **Catering Needs** (`catering_needs`, select_one, optional): Select the catering needs of the item (None, Coffee and Tea, Light Refreshments, Full Meal Service).
* **Item Status** (`status`, select_one, required): Select the current status of the item (Proposed, Confirmed, Cancelled, Completed).
* **Additional Notes** (`additional_notes`, text, optional): Enter any additional notes about the item.

## Tips
* Make sure to select the correct conference date and time for the item.
* Be sure to enter accurate and complete information for all required fields.
* If you are unsure about any field, you can refer back to this help guide.
