# Marketing Event Checklist Form - Help Guide
## Purpose
This form is designed to help marketing event planners organize their tasks, resources, and schedule to ensure a successful event.

## How To Complete This Form

To complete this form, follow these steps:

1. Start with the **Event Planning Checklist** section (Page 1). This section includes a text field where you can list all the necessary tasks to be completed before and after the event.
2. Move on to the **Marketing Tasks** section (Page 2). This section is a multiple-choice list of marketing tasks that are relevant to the event. Select all the tasks that apply to your event.
3. In the **Event Resources** section (Page 3), select the resources you will need for the event from the provided options.
4. The **Event Responsibilities** section (Page 4) is another multiple-choice list of responsibilities related to the event. Again, select all the applicable tasks.
5. For the **Event Schedule** section (Page 5), enter the date of the event.
6. If you have a budget for the event, enter it in the **Event Budget** section (Page 6). This is an optional field, and if you leave it blank, you can focus on other important aspects of the event.
7. In the **Event Notes** section (Page 7), add any additional notes or comments about the event.
8. Finally, in the **Event Status** section (Page 8), select the current status of the event from the options provided.
9. If you need to contact the event organizer or team, enter their email address in the **Event Email** field (Page 9).
10. For the **Event Phone** field (Page 10), enter the phone number of the event contact person.
11. Enter the **Event Address** (Page 11), **Event City** (Page 12), **Event Postal Code** (Page 13), **Event State** (Page 14), and **Event Country** (Page 15) to provide the location details of the event.

## Field-by-Field Explanation

* **Event Planning Checklist**: This field is where you can list all the necessary tasks to be completed before and after the event.
* **Marketing Tasks**: This is a multiple-choice list of marketing tasks that are relevant to the event. Select all the tasks that apply to your event.
* **Event Resources**: This field allows you to select the resources you will need for the event from the provided options.
* **Event Responsibilities**: This is another multiple-choice list of responsibilities related to the event. Select all the applicable tasks.
* **Event Schedule**: Enter the date of the event.
* **Event Budget**: If you have a budget for the event, enter it here.
* **Event Notes**: Add any additional notes or comments about the event.
* **Event Status**: Select the current status of the event from the options provided.
* **Event Email**: Enter the email address of the event contact person.
* **Event Phone**: Enter the phone number of the event contact person.
* **Event Address**: Enter the physical address of the event location.
* **Event City**: Enter the city of the event location.
* **Event Postal Code**: Enter the postal code (zip code) of the event location.
* **Event State**: Enter the state of the event location.
* **Event Country**: Enter the country of the event location.
