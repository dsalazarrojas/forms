# Judging Panel Information Form - Help Guide
## Purpose
The Judging Panel Information Form is used to collect and store information about a specific event. The form is intended for internal use.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the title of the event in the "Event Title" field.
2. Enter the start and end dates of the event in the "Event Start Date" and "Event End Date" fields, respectively.
3. Enter the start time of the event in the "Event Start Time" field.
4. Specify the location of the event in the "Event Location" field.
5. Select the chairperson of the judging panel from the "Panel Chairperson" dropdown menu.
6. Choose the members of the panel from the "Panel Members" dropdown menu.
7. Choose the type of event (competition, audition, or contest) from the "Event Type" dropdown menu.
8. Select the status of the event (upcoming, past, or in progress) from the "Event Status" dropdown menu.
9. Enter a brief description of the event in the "Event Description" field.

## Field-by-Field Explanation
* **Event Title**: Enter the title of the event, e.g., "The Annual Art Competition."
* **Event Start Date**: Enter the date the event started, e.g., "2022-01-01".
* **Event End Date**: Enter the date the event ended, e.g., "2022-01-15".
* **Event Start Time**: Enter the time the event started, e.g., "09:00".
* **Event Location**: Enter the location of the event, e.g., "New York City, USA".
* **Panel Chairperson**: Choose the person leading the judging panel, e.g., "John Doe".
* **Panel Members**: Select the members of the judging panel, e.g., "Jane Smith", "Bob Johnson", and "Alice Brown".
* **Event Type**: Choose the type of event, e.g., "Competition".
* **Event Status**: Choose the status of the event, e.g., "Upcoming".
* **Event Description**: Enter a brief description of the event, e.g., "An annual art competition for local artists."
