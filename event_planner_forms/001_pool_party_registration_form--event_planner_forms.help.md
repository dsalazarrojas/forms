# Pool Party Registration Form - Help Guide
## Purpose
This form is used by event planners to collect information about pool parties.
## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the date of the party (field: pool_date).
2. Select the type of party (field: party_type).
3. (Optional) Enter the number of guests attending the party (field: party_guests).
4. (Optional) Enter the number of dogs attending the party (field: party_dogs).
5. Add any notes or comments about the party (field: party_notes).
6. Enter the name of the party host (field: party_host).
7. Enter the location of the party (field: party_location).

## Field-by-Field Explanation
* **pool_date**: Enter the date of the party in YYYY-MM-DD format.
* **party_type**: Select the type of party you are planning (e.g., Pool Party 1, Pool Party 2, or Pool Party 3).
* **party_guests**: (Optional) Enter the number of guests attending the party.
* **party_dogs**: (Optional) Enter the number of dogs attending the party.
* **party_notes**: Add any notes or comments about the party.
* **party_host**: Enter the name of the party host.
* **party_location**: Enter the location of the party.

## Tips
* Make sure to double-check the date and type of party to ensure they are correct.
* If you are unsure about any of the fields, feel free to ask the event planner for assistance.
* This form is used solely for planning and executing pool parties; do not use it for any other type of event.
