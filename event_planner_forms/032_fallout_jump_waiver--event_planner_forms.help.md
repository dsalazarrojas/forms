# Fallout Jump Waiver - Help Guide
## Purpose
The Fallout Jump Waiver form is used to document and manage jump-related events and activities. It's crucial for participants to acknowledge and accept the risks involved.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form title.
2. Select the category of the event (e.g., Event Planner Forms).
3. Enter a brief description of the event.
4. Fill in the description of the form.
5. Enter the name of the person who submitted the form.
6. Select the date the form was submitted (note: this field is not visible in the current version).
7. Fill in the name of the person who signed the waiver.
8. Select the date the waiver was signed (note: this field is not visible in the current version).
9. Enter the name of any witnesses to the event.
10. Enter the signatures of any witnesses.

## Field-by-Field Explanation

* **Form Title** (`form_title`, required/optional): Enter a brief title for the waiver, e.g., "Event Name: Jump Fest 2023".
* **Category** (`category`, required/optional): Select the category for the event, e.g., "Event Planner Forms".
* **Description** (`description`, required/optional): Enter a brief description of the event or activity.
* **Form Description** (`form_description`, required/optional): Enter a detailed description of the form's purpose and content.
* **Submitted By** (`submitted_by`, required/optional): Enter the name of the person who submitted the form.
* **Date Submitted** (`date_submitted`, required/optional): Select the date the form was submitted (note: this field is not visible in the current version).
* **Signed By** (`signed_by`, required/optional): Enter the name of the person who signed the waiver.
* **Date Signed** (`date_signed`, required/optional): Select the date the waiver was signed (note: this field is not visible in the current version).
* **Witness 1** (`witness_1`, required/optional): Enter the name of any witnesses to the event.
* **Witness 1 Signature** (`witness_1_signature`, required/optional): Enter the signature of Witness 1, if applicable.
* **Witness 2** (`witness_2`, required/optional): Enter the name of any additional witnesses to the event (if applicable).
* **Witness 2 Signature** (`witness_2_signature`, required/optional): Enter the signature of Witness 2, if applicable.

## Tips

* Make sure to fill out the form carefully and accurately.
* Ensure the form is complete before submission.
* If you're unsure about any field, refer to the form's internal documentation or seek assistance from the event planner.
