# Thanksgiving Pie Order Form - Help Guide

## Purpose
The Thanksgiving Pie Order Form is a user-facing form used to collect order information for customers ordering pies for Thanksgiving. This form ensures accurate and efficient pie orders, allowing customers to easily provide their preferences.

## How To Complete This Form
1. Enter your contact information (name, email, and phone number).
2. Select the type of pie you would like to order (e.g., Apple, Pumpkin, Pecan, or Cherry).
3. Enter the quantity of pies you would like to order.
4. Provide any special address or message if necessary.
5. Optionally, assign a specific tool for delivery.
6. Enter your desired Form ID for internal reference.
7. Provide any additional category or description if applicable.

## Field-by-Field Explanation

* **Customer Name** (`customer_name`, Text, Optional): Enter your name for accurate order recognition.
* **Customer Email** (`customer_email`, Email, Optional): Enter your email address for easy contact.
* **Phone Number** (`phone_number`, Number, Optional): Enter your phone number for efficient communication.
* **Pie Order** (`pie_orders`, Select Multiple, Optional): Choose from the available pie types (Apple, Pumpkin, Pecan, or Cherry).
* **Quantity** (`quantity`, Number, Optional): Enter the number of pies you would like to order.
* **Address** (`address`, Note, Optional): Provide any special address or message if necessary.
* **Customer Message** (`customer_message`, Note, Optional): Enter any additional information or message for the order.
* **Assigned Tool** (`assigned_tool`, Text, Optional): Optionally, assign a specific tool for delivery.
* **Form ID** (`form_ids`, Text, Optional): Enter your desired Form ID for internal reference.
* **Category** (`category`, Text, Optional): Provide any category information if applicable.
* **Description** (`description`, Text, Optional): Enter any additional description if necessary.
 
## Tips
- Make sure to enter your correct contact information for efficient order processing.
- Choose the correct pie type and quantity for accurate ordering.
- If you have any special requests, please provide them in the address or message field.
