# Golf Tournament Registration & Sponsor Form - Help Guide
## Purpose
The Golf Tournament Registration & Sponsor Form is a tool for collecting contact and demographic information from participants and sponsors of a golf tournament event. This form is essential for event organizers to gather the necessary details to manage the event efficiently.

## How To Complete This Form

To complete this form, follow these steps:

1. Click on the "Submit" button to begin the form.
2. On the first page, "Prophets Registration Form", enter the participant's information in the required fields.
3. On the second page, "Sponsor Registration Form", select the sponsor's registration status ("Yes" or "No") and provide any additional sponsor information if applicable.
4. Review and submit the form to ensure all required fields are completed accurately.

## Field-by-Field Explanation

* **Prophets Registration Form**
	+ **Prophets Registration Form** (`participant_registration`, `number`, **Required**): This is the first page of the form, where you will enter the participant's information. Please fill in the required fields accurately.
* **Sponsor Registration Form**
	+ **Sponsor Registration Form** (`sponsor_registration`, `select_multiple`, **Optional**): On this page, select "Yes" if the sponsor is registered, or "No" if not. If you select "Yes", you will be able to provide additional sponsor information on the next page.
* **Sponsor Info**
	+ **Sponsor Info** (`sponsor_info`, `text`, **Optional**): If you selected "Yes" on the previous page, fill in this field to provide additional sponsor information. This is an optional field, so feel free to leave it blank if not applicable.
* **Participant Info**
	+ **Participant Info** (`participant_info`, `text`, **Optional**): This is an optional field for participants to provide additional information. You can leave it blank if not applicable.
* **Sponsor Email**
	+ **Sponsor Email** (`sponsor_email`, `email`, **Optional**): If you selected "Yes" on the previous page, enter the sponsor's email address. This is an optional field, so feel free to leave it blank if not applicable.
* **Participant Email**
	+ **Participant Email** (`participant_email`, `email`, **Optional**): Enter the participant's email address in this field. This is an optional field, so feel free to leave it blank if not applicable.
* **Participant Phone Number**
	+ **Participant Phone Number** (`participant_phone`, `text`, **Optional**): Enter the participant's phone number in this field. This is an optional field, so feel free to leave it blank if not applicable.
* **Sponsor Phone Number**
	+ **Sponsor Phone Number** (`sponsor_phone`, `text`, **Optional**): If you selected "Yes" on the previous page, enter the sponsor's phone number. This is an optional field, so feel free to leave it blank if not applicable.

## Tips

* Make sure to review the form carefully before submitting to avoid any errors.
* Use the correct format for email addresses and phone numbers (e.g., `example@example.com` for email).
* If you have any issues or questions while completing the form, contact the event organizers for assistance.
