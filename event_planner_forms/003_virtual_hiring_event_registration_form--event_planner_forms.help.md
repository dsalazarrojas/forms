# Virtual Hiring Event Registration Form - Help Guide
## Purpose
This form is designed for registrants to provide information about themselves and their participation in a virtual hiring event. It's essential to complete this form accurately to ensure a smooth and successful event.

## How To Complete This Form
- Please ensure that you have all necessary information about the event before starting the form.
- Review each field carefully and enter the requested information accurately.
- If you need assistance with any field, don't hesitate to contact the event organizers.

## Field-by-Field Explanation
* **Event Planner** (`event_planner`, text, optional): This field is not required but is an optional way to provide additional context about the event planner or coordinator.
* **Event Name** (`event_name`, text, optional): Enter the name of the event, which will help in identifying the event for future reference.
* **Job Fair** (`job_fair`, select_one, optional): Select 'Yes' if this is a job fair event, 'No' otherwise.
* **Recruiter** (`recruiter`, text, optional): Enter the name of the recruiter or representative of the company involved in the event.
* **Event Date** (`event_date`, date, optional): Enter the date of the event in the format 'YYYY-MM-DD'.
* **Event Time** (`event_time`, time, optional): Enter the time of the event in the format 'HH:MM' 24-hour clock.
* **Event Location** (`event_location`, text, optional): Provide the location or venue of the event.
* **Job Description** (`job_description`, text, optional): Enter a brief description of the job or opportunity being offered.
* **Job Title** (`job_title`, text, optional): Enter the title of the job or position being offered.
* **Job Type** (`job_type`, text, optional): Enter the type of job or category it falls into.

## Tips
- Be as accurate and precise as possible when filling out the form.
- If you are unsure about any information, consult with the event organizers or contact them for help.
- Review your form carefully before submitting it to avoid errors or mistakes.
