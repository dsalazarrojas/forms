# Scheduled Event Details Form - Help Guide

## Purpose
The Scheduled Event Details Form is designed to collect information about an event. It is used to gather relevant details that will help the event organizer or planner create a well-planned and executed event. This form is a helpful tool for event planners, organizers, and coordinators to capture the necessary information to make the event a success.

## How To Complete This Form
To complete the Scheduled Event Details Form, follow these steps:

1. Review the form's pages: The form has three pages: "Event Details", "Guest Lists", and "Schedule". Make sure you have access to all the necessary information before starting.
2. Start with the "Event Details" page: This page is used to input information about the event, such as the event name, date, and time.
3. Fill in the required and optional fields: Each page has required and optional fields. Make sure to fill in the required fields before proceeding.
4. Review and edit as needed: Once you have filled out the form, review it for any mistakes or inconsistencies.
5. Submit the form: Finally, submit the form to complete it.

## Field-by-Field Explanation

- **Event Details**: (`event_details_page`, `text`, not required) This is the first page of the form used to input the basic information about the event, including event name, date, and time.
  On this page, you will enter details about the event, such as its title, date, and start and end times. Make sure to fill in these required fields to ensure the form is complete.

- **Guest Lists**: (`guest_lists_page`, `text`, not required) This page is used to input a list of guests that will be attending the event. You can add as many guests as you need, but make sure to include their names and other relevant details.
  On this page, you will enter the list of guests that will be attending the event. You can add as many guests as you need by typing their names and other relevant details.

- **Schedule**: (`schedule_page`, `text`, not required) This page is used to input the schedule for the event, including start and end times for different sessions or activities.
  On this page, you will enter the schedule for the event, including start and end times for different sessions or activities. Make sure to include all the necessary details, such as time slots and activity names.

## Tips
- Make sure to fill in all required fields to avoid incomplete submissions.
- Review your form answers for accuracy and completeness.
- Use the "Event Details" page to get a general overview of the event.
- Use the "Guest Lists" page to manage the guests' details and RSVPs.
- Use the "Schedule" page to plan and organize the event activities.
- This form is best used for events with a fixed date and time, such as conferences, workshops, or seminars.
- If you have any issues or questions, contact form@gic.mx.
