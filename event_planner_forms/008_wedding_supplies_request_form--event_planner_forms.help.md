# wedding_supplies_request_form - Help Guide
## Purpose
This form is for event planners to request supplies for a wedding event. It's used to gather essential details about the wedding, including the number of guests, wedding date and time, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields with accurate information about the wedding.
* Choose the correct supply type(s) you need for the wedding.
* Provide any additional information about your special request.
* Select the correct person assigned to handle the request.

## Field-by-Field Explanation

* **wedding supplies**: A text input field for the couple's wedding supplies request.
	+ Type: Text input field
	+ Required: No
* **name**: A text input field for the couple's name.
	+ Type: Text input field
	+ Required: No
* **contact email**: A field for entering the couple's contact email address.
	+ Type: Email input field
	+ Required: No
* **contact phone**: A field for entering the couple's contact phone number.
	+ Type: Text input field
	+ Required: No
* **wedding date**: A field for entering the wedding date.
	+ Type: Date input field
	+ Required: No
* **wedding time**: A field for entering the wedding time.
	+ Type: Time input field
	+ Required: No
* **number of guests**: A field for entering the number of guests attending the wedding.
	+ Type: Number input field
	+ Required: No
* **supply type**: A select multiple input field with options for choosing the supply type (chair, table, napkin, etc.).
	+ Type: Select multiple input field
	+ Required: No
* **special request**: A text area field for any additional information about the wedding supplies request.
	+ Type: Text area field
	+ Required: No
* **assigned**: A select one input field with options for choosing who will handle the request.
	+ Type: Select one input field
	+ Required: No
