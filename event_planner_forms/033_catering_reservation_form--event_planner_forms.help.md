# Catering Reservation Form - Help Guide
## Purpose
This form is used to reserve catering services for events. It captures essential information such as contact details, event specifics, and menu preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill in your contact information, including your name, email address, and phone number.
2.  Provide the event date, event type, and the date of the event.
3.  Specify the number of attendees (party size) and the preferred catering package.
4.  Choose the type of menu and beverage service you would like.
5.  If applicable, provide the name and address of the venue.
6.  Confirm that a deposit has been paid.
7.  If necessary, specify any dietary restrictions or special requests.
8.  Add any additional comments or information.

## Field-by-Field Explanation

*   **Contact Name** (`contact_name`, `text`, required): This is the contact person's name.
    Please fill in your full name.

*   **Email Address** (`email`, `email`, required): This is your email address.
    Please enter your email address where you can be reached.

*   **Phone Number** (`phone`, `text`, required): This is your contact phone number.
    Enter your contact phone number.

*   **Company Name** (`company_name`, `text`, optional): If you're representing a company, please provide the company name.
    If you're representing a company, enter the name here.

*   **Reservation Date** (`reservation_date`, `date`, required): This is the date you are reserving for.
    Please select the date for your event.

*   **Event Type** (`event_type`, `select_one`, required): Choose the type of event you are having.
    Select the type of event (e.g., Wedding, Corporate Event, Birthday Party).

*   **Event Date** (`event_date`, `date`, required): This is the date of the event.
    Select the date for your event.

*   **Event Time** (`event_time`, `time`, required): This is the start time of the event.
    Enter the start time of the event.

*   **Party Size** (`party_size`, `number`, required): This is the estimated number of attendees.
    Enter the estimated number of people attending.

*   **Venue Name** (`venue_name`, `text`, optional): If you're not holding this event at our location, please provide the venue name.
    Enter the name of the venue if you're not with us.

*   **Venue Address** (`venue_address`, `text`, optional): If you're not holding this event at our location, please enter the venue address.
    Enter the address of the venue if you're not with us.

*   **Package Selection** (`package_selection`, `select_one`, required): Choose a preferred catering package.
    Select the preferred package from the options provided.

*   **Menu Type** (`menu_type`, `select_one`, required): Choose the type of menu.
    Select the menu type (e.g., Breakfast, Brunch, Lunch).

*   **Cuisine Preference** (`cuisine_preference`, `select_one`, optional): If you have a preferred cuisine, please select it.
    Select a preferred cuisine if you have a preference.

*   **Dietary Requirements** (`dietary_requirements`, `text`, optional): If you have any dietary restrictions, please specify them.
    Enter any dietary restrictions you may have.

*   **Beverage Package** (`beverage_package`, `select_one`, optional): Choose the beverage service.
    Select the beverage service type (e.g., Non-Alcoholic, Beer and Wine).

*   **Setup Style** (`setup_style`, `select_one`, optional): Choose the preferred setup style.
    Select the preferred setup style (e.g., Buffet, Plated).

*   **Deposit Amount** (`deposit_amount`, `number`, optional): Enter the deposit amount.
    If applicable, enter the deposit amount.

*   **Deposit Paid** (`deposit_paid`, `select_one`, required): Confirm if a deposit has been paid.
    Select if a deposit has been paid.

*   **Special Requests** (`special_requests`, `text`, optional): If you have any special requirements, please describe them.
    Enter any special requirements you may have.

*   **Additional Comments** (`additional_comments`, `text`, optional): If you have any additional information, please add it here.
    Add any other relevant information.
