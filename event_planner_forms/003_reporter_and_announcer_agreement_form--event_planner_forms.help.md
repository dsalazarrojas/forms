# Reporter And Announcer Agreement Form - Help Guide
## Purpose

The "Reporter and Announcer Agreement Form" is used for event planners to collect information about the events they plan, the media contacts they need to work with, and other relevant details. The form is designed to be used by event planners to ensure that all necessary information is collected and that there is mutual understanding between the event planner and the media contacts.

## How To Complete This Form

1. Complete the "Assignment Details" field by providing a brief description of the event assignment.
2. In the "Event Details" field, provide any additional information about the event that is relevant to the planner.
3. Select one of the options in the "Consent" field to indicate whether or not event coverage is desired.
4. If "Other Event Details" is selected, provide any additional information in the text field.
5. If "School" is selected in the "School Media Contact" field, provide the name of the school media contact in the "School Media Contact Name" field.
6. If "School Media Team" is selected in the "School Media Contact" field, provide the name of the school media contact in the "School Media Contact Name" field.
7. If "Not Applicable" is selected in the "School Media Contact" field, do not complete the "School Media Contact" fields.
8. In the "Other School Info" field, provide any other school-specific information that is relevant to the event.

## Field-by-Field Explanation

* **Assignment Details**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): A brief description of the event assignment.
* **Event Details**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): Any additional information about the event that is relevant to the planner.
* **Consent**
	+ (Required/Optional): Not Required
	+ (Type): Select One
	+ (Purpose): Indicate whether or not event coverage is desired. Select "Event Coverage" to indicate that coverage is desired, "No Event Coverage" to indicate that it is not, or "Other (please specify)" to indicate that coverage is not desired, but you have additional information.
* **Other Event Details**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): Provide any additional information about the event that is not included in the "Event Details" field.
* **Media Contact Name**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): The name of the media contact.
* **Media Contact Phone**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): The phone number of the media contact.
* **School Media Contact**
	+ (Required/Optional): Not Required
	+ (Type): Select One
	+ (Purpose): Indicate who is the school media contact. Select "School" for a school media contact, "School Media Team" for a school media team, or "Not Applicable" if there is no school media contact.
* **School Media Contact Name**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): The name of the school media contact.
* **School Media Contact Phone**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): The phone number of the school media contact.
* **Other School Info**
	+ (Required/Optional): Not Required
	+ (Type): Text
	+ (Purpose): Any other school-specific information that is relevant to the event.
