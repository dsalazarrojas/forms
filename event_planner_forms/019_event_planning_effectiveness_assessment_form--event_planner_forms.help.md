# Event Planning Effectiveness Assessment Form - Help Guide
## Purpose
This form is used to gauge the effectiveness of the event planning process and gather feedback on various aspects of event planning. It helps event planners understand areas for improvement and areas of strength in their planning process.

## How To Complete This Form
1. Please answer the questions based on your experience with the event planning process.
2. Select the options that best describe your experience.
3. Provide any additional comments or suggestions in the text fields.

## Field-by-Field Explanation
* **Overall** (id: 2): Rate your overall experience with the event planning process. Select "Strongly Agree" if you were satisfied, "Neutral" if you were neither satisfied nor dissatisfied, or "Disagree" if you were not satisfied.
* **Event Planning Process** (id: 3): Describe your experience with the event planning process.
* **Team Compliance** (id: 4): Select the level of compliance among team members. Choose "Event Team" if team members worked well together, "Other" if they did not, or "Both" if it was a mix of both.
* **Event Team Effectiveness** (id: 5): Rate the effectiveness of the event team. Select "Event Team" if they were effective, "Other" if they were not, or "Both" if it was a mix of both.
* **Communication** (id: 6): Rate your communication with the event team. Select "Strongly Agree" if you felt well-communicated, "Neutral" if communication was average, or "Disagree" if you felt under-communicated.
* **Communication with Sponsors** (id: 7): Rate your communication with sponsors. Select "Strongly Agree" if you felt well-communicated, "Neutral" if communication was average, or "Disagree" if you felt under-communicated.
* **Communication with Vendors** (id: 8): Rate your communication with vendors. Select "Strongly Agree" if you felt well-communicated, "Neutral" if communication was average, or "Disagree" if you felt under-communicated.
* **Overall Event Effectiveness Score** (id: 9): Enter a numerical value between 1-10 to rate the overall effectiveness of the event planning process.
* **Event Improvement Plan** (id: 10): Describe any areas for improvement or suggestions for future event planning processes.
* **Communication with Speakers** (id: 11): Rate your communication with speakers. Select "Strongly Agree" if you felt well-communicated, "Neutral" if communication was average, or "Disagree" if you felt under-communicated.
* **Communication with Vendors** (id: 12): Rate your communication with vendors. Select "Strongly Agree" if you felt well-communicated, "Neutral" if communication was average, or "Disagree" if you felt under-communicated.
* **Event Planning Effectiveness Score** (id: 13): Enter a numerical value between 1-10 to rate the event planning process.
* **Overall Event Experience Score** (id: 14): Enter a numerical value between 1-10 to rate your overall event experience.
* **Overall Event Planning Effectiveness** (id: 15): Rate your overall event planning process. Select "Strongly Agree" if you were satisfied, "Neutral" if you were neither satisfied nor dissatisfied, or "Disagree" if you were not satisfied.
* **Event Satisfaction** (id: 16): Rate your overall satisfaction with the event. Select "Strongly Agree" if you were satisfied, "Neutral" if you were neither satisfied nor dissatisfied, or "Disagree" if you were not satisfied.

## Tips
* Please answer honestly and accurately.
* Provide specific examples or anecdotes to support your answers.
* This form is designed to gather feedback and help improve the event planning process.
