# Event Setup And Teardown Checklist - Help Guide
## Purpose
This form is designed to assist users in collecting essential information for event setup and teardown activities. It serves as a checklist to ensure that all necessary details are captured, making it easier to manage and track events.

## How To Complete This Form

1. Select "Event Setup" from the form's dropdown menu and fill out the fields provided on that page.
2. Once you've completed the "Event Setup" page, move on to the "Event Teardown" page, which is also accessible via a dropdown menu.
3. Fill out the required fields for event details such as date, time, location, planner, and event name.
4. On the "Event Planner" page, select the assigned tool from the dropdown menu.
5. Finally, take note of any additional comments or information in the "Notes" field.

## Field-by-Field Explanation
* **Event Setup** (`event_setup`, text, optional): This field is used to enter the event setup details.
* **Event Teardown** (`event_teardown`, text, optional): This field is used to enter the event teardown details.
* **Event Date** (`event_date`, date, optional): Enter the date of the event.
* **Event Time** (`event_time`, time, optional): Enter the time of the event.
* **Event Location** (`event_location`, text, optional): Enter the location of the event.
* **Event Planner** (`event_planner`, text, optional): Enter the event planner's name or contact details.
* **Event Name** (`event_name`, text, optional): Enter the name of the event.
* **Assigned Tool** (`assigned_tool`, select_one, optional): Select the tool assigned for the event.
* **Notes** (`notes`, note, optional): Enter any additional comments or information about the event.

## Tips
- Make sure to provide accurate and relevant information for each field to ensure proper event management.
- Use the select_one field to assign the correct tool for the event.
- Take advantage of the "Notes" field to capture any additional context or comments about the event.
- Review and update the form as needed to reflect changes in event details or requirements.
