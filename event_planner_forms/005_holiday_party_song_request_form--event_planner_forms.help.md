# Holiday Party Song Request Form - Help Guide
## Purpose
This form is used to collect information about songs for a holiday party playlist. You can submit requests for multiple songs, each with various attributes such as mood, energy, and popularity.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and ensure you have all necessary information about the songs you'd like to request.
2. Fill in the required fields for each song, starting from the first page.
3. Select the attributes for each song, such as mood, energy, and popularity.
4. Add any additional comments for each song.
5. Repeat the process for each song you'd like to submit.

## Field-by-Field Explanation

* **Song Name 1** (`song_name_1`, text, not required): Enter the name of the first song you'd like to request.
* **Artist Name 1** (`artist_name_1`, text, not required): Enter the artist name for the first song.
* **Favorite Instruments 1** (`favorite_instruments_1`, select multiple, not required): Select your favorite instruments for the first song.
* **Favorite Genres 1** (`favorite_genres_1`, select multiple, not required): Select your favorite genres for the first song.
* **Song Mood 1** (`song_mood_1`, select one, not required): Choose the mood of the first song (e.g., happy, sad, upbeat).
* **Song Energy 1** (`song_energy_1`, select one, not required): Select the energy level of the first song (e.g., low, high).
* **Song Danceability 1** (`song_danceability_1`, select one, not required): Choose how danceable the first song is (e.g., not very, somewhat, very).
* **Song Tempo 1** (`song_tempo_1`, select one, not required): Select the tempo of the first song (e.g., fast, slow).
* **Song Popularity 1** (`song_popularity_1`, select one, not required): Choose the popularity of the first song (e.g., low, high).
* **Additional Comments 1** (`additional_comments_1`, text, not required): Add any additional comments for the first song.
* **Favorite Songs 1** (`favorite_songs_1`, select multiple, not required): Select your favorite songs for the first song.
* **Favorite Artists 1** (`favorite_artists_1`, select multiple, not required): Select your favorite artists for the first song.

Note that each field has a counterpart for the second song (e.g., Song Name 2, Artist Name 2, etc.), with the same labels and explanations as above.

## Tips

* Be as specific as possible when choosing attributes for each song.
* If you have multiple favorite artists or songs, select them all in the respective fields.
* You can repeat the process for each song you'd like to request.
* If you have any questions or need clarification, please contact [support email/phone number].
* Please submit all required information for each song before submitting the form.
