# Event Planner Offboarding Form - Help Guide
## Purpose
The Event Planner Offboarding Form is a tool for event planners to collect information from event attendees, project managers, and other stakeholders during the offboarding process. This form helps event planners track progress, gather feedback, and document the offboarding process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by providing your name and email address for contact purposes.
2. Enter the name of the project you are offboarding from.
3. Identify the project manager responsible for the project.
4. Provide feedback on the project, if any.
5. Select the current status of the task or project (Active, Completed, Not Started, or On Hold).
6. If applicable, enter the date and time when the task was completed.
7. Optionally, add any additional comments about the task or project.

## Field-by-Field Explanation
* **name** (text): Please enter your name for contact purposes.
* **email** (email): Enter your email address for communication and follow-up.
* **project name** (text): Enter the name of the project you are offboarding from.
* **project manager** (text): Identify the project manager responsible for the project.
* **feedback** (text): Provide any feedback you have about the project.
* **task status** (select_one): Select the current status of the task or project (Active, Completed, Not Started, or On Hold).
* **task completion date** (date): If the task has been completed, enter the date it was completed.
* **task completion date and time** (time): If the task completion date and time are known, enter them here.
* **comments** (text): Add any additional comments about the task or project.
* **task status** (select_one): Please note that "task status" is a repeated field and should be ignored.

Note: The "task status" field appears twice in the original YAML. It should be removed or merged into a single field in the actual form implementation.
