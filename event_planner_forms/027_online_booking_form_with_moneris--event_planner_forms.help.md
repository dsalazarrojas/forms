# Online Booking Form With Moneris - Help Guide
## Purpose
This form is designed to create a customizable online booking form that can be used for various purposes such as event planning, calendar management, and other related tasks.

## How To Complete This Form
To complete this form, follow these steps:

* Select a category for this form from the options provided.
* Enter your unique 4-digit form ID.
* Choose a name for your saved output file.
* Select a tool or platform this form is integrated with (optional).
* Select multiple categories for this form (optional).
* Describe how this form will help users manage events (optional).
* Explain how this form integrates with calendars, CRMs, and spreadsheets (optional).
* Add any additional notes about this form (optional).

## Field-by-Field Explanation

* **Event Planner Forms** (`category`, `select_one`, required):
	+ Select a category for this form from the available options.
* **Description** (`description`, `text`, optional):
	+ Enter a description of this form and its purpose.
* **Form ID** (`form_id`, `number`, required):
	+ Enter a unique 4-digit ID for this form.
* **Output File** (`output_file`, `text`, optional):
	+ Name your saved output file.
* **Assigned Tool** (`assigned_tool`, `select_one`, optional):
	+ Select a tool or platform this form is integrated with.
* **Categories** (`categories`, `select_multiple`, optional):
	+ Select multiple categories for this form from the available options.
* **Form Description** (`description_2`, `text`, optional):
	+ Describe how this form will help users manage events.
* **Integration Description** (`integration_description`, `text`, optional):
	+ Explain how this form integrates with calendars, CRMs, and spreadsheets.
* **Notes** (`notes`, `text`, optional):
	+ Add any additional notes about this form.
