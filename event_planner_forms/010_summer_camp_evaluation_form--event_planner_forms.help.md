# Summer Camp Evaluation Form - Help Guide
## Purpose
This form is used to gather feedback on the quality of the summer camp program.

## How To Complete This Form
To complete this form, please follow these steps:

1. Answer the questions in the text field on Page 1.
2. On Page 2, select your assessment of the staff's performance using the dropdown options.
3. Provide a detailed description of your experience in the text field on Page 3.

## Field-by-Field Explanation

* **Summer Camp Evaluation Form (Page 1, <name>):** 
	+ Type: Text area where you can provide a brief description of your feedback.
* **Staff (Page 2, <name>):** 
	+ Type: Select one option from the dropdown menu to rate the staff's performance.
	+ Options: Very Good, Not Very Good, Not at All
* **Experience (Page 3, <name>):** 
	+ Type: Text area where you can provide a detailed description of your experience.
* **Tips:**
	+ Be specific and concrete in your feedback.
	+ Focus on your personal experience with the summer camp program.
	+ If you have suggestions for improvement, please include them in your feedback.
