# Special Event Request Form - Help Guide
## Purpose
The Special Event Request Form is a document that allows you to request special event details for internal events such as events, parties, photo shoots, and more. It is used to collect essential information for planning and coordination.

## How To Complete This Form
To complete the form correctly:
1.  Enter the event's title, ensuring it accurately reflects the event's purpose.
2.  Select the type of event (Event, Party, Photo Shoot, etc.).
3.  Specify the event's venue, which can be a Restaurant, Park, Gym, or Venue.
4.  Enter the start and end dates for the event.
5.  Choose the start and end times for the event.
6.  Select the location where the event will be hosted.
7.  Enter the contact person's name.
8.  Provide a valid email address for the contact person.
9.  Enter the contact person's phone number.
10.  Add any additional information or notes about the event.
11.  (Optional) Upload any supporting attachments for the event.
12.  (Optional) Enter any special requests or additional details.
