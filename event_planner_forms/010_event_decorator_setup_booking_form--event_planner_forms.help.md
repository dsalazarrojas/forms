# Event Decorator Setup Booking Form - Help Guide
## Purpose
This form is used to set up booking information for events. Please fill out the form with accurate and relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with your details, ensuring all required fields are completed.
2. Review each field carefully, and provide accurate information.

## Field-by-Field Explanation

* **First Name (1)**: Enter your first name as it is written on your identification documents.
* **Last Name (2)**: Enter your last name as it is written on your identification documents.
* **Email (3)**: Enter a valid email address to be contacted for event-related matters.
* **Phone (4)**: Enter your phone number where you can be reached.
* **Event Type (5)**: Select 'Yes' if this event requires special handling or setup, and 'No' otherwise.
* **Event Date (6)**: Enter the date of the event in the standard date format (DD/MM/YYYY).
* **Event Time (7)**: Enter the time of the event in the standard time format (HH:MM).
* **Event Location (8)**: Enter the location where the event will take place.
* **Special Requests (9)**: Select 'Yes' if you have any special requests for the event, and 'No' otherwise.
* **Notes (10)**: Enter any additional notes or comments about the event.

## Tips
- Ensure that all required fields are completed.
- Double-check the information provided for accuracy.
- If you have any doubts or questions, contact the event organizer.
