# Care Package Giveaway Event Registration Form - Help Guide
## Purpose
This form is designed to collect information from potential volunteers for a care package giveaway event.

## How To Complete This Form

1. Read each section carefully and answer the questions as prompted.
2. Fill out the form completely and accurately.
3. Review your answers for completeness and correctness before submitting.

## Field-by-Field Explanation

* **Full Name**: Enter your full name as it appears on your official documents.
	+ Type: text
	+ Required: true
* **Email Address**: Enter a valid email address where you can be reached for event confirmation and updates.
	+ Type: email
	+ Required: true
* **Phone Number**: Enter your phone number where you can be reached for event-related matters.
	+ Type: text
	+ Required: true
* **Organization Affiliation**: If you are representing an organization, enter its name here.
	+ Type: text
	+ Required: false
* **Organization Type**: Select the type of organization you represent.
	+ Type: select_one
	+ Options: Individual volunteer, Non-profit organization, School or university, Religious organization, Corporate group, Community group, Government agency, Other
	+ Required: true
* **Number of Volunteers Registering**: Enter the number of people registering as volunteers, including yourself.
	+ Type: number
	+ Required: true
* **Volunteer Names**: List the names of all volunteers registering for the event.
	+ Type: text
	+ Required: true
* **Preferred Event Date**: Select the date you are most available to volunteer.
	+ Type: select_one
	+ Options: Saturday, March 15, 2026, Saturday, March 22, 2026, Saturday, April 5, 2026, Any date - flexible
	+ Required: true
* **Preferred Volunteer Role**: Select the role you are most interested in volunteering for.
	+ Type: select_one
	+ Options: Care package assembly, Distribution and handout, Registration and check-in, Setup and teardown, Photography and social media, Transportation assistance, No preference
	+ Required: true
* **Preferred Time Slot**: Select the time slot you are most available to volunteer.
	+ Type: select_one
	+ Options: Morning shift (8 AM - 12 PM), Afternoon shift (12 PM - 4 PM), Full day (8 AM - 4 PM), Flexible
	+ Required: true
* **Previous Volunteer Experience**: Select your level of volunteer experience.
	+ Type: select_one
	+ Options: Yes - extensive experience, Yes - some experience, No - first time volunteering
	+ Required: true
* **Skills and Interests**: Select all skills and interests you have that would be valuable for the event.
	+ Type: select_multiple
	+ Options: Event planning, Team leadership, Customer service, Physical labor, Creative design, Social media, Photography, Driving, Bilingual skills, None specific
	+ Required: false
* **Care Package Types Interest**: Select all care package types you are interested in.
	+ Type: select_multiple
	+ Options: Homeless care packages, Senior care packages, Student care packages, Military care packages, Healthcare worker appreciation, New parent packages, Holiday gift packages, Emergency relief packages, Any type needed
	+ Required: true
* **Items to Contribute**: Select all items you can contribute to the event.
	+ Type: select_multiple
	+ Options: Toiletries, Snacks and non-perishable food, Socks and underwear, Blankets or clothing, School supplies, Hygiene products, Gift cards, Monetary donation, Nothing to contribute, Other items
	+ Required: true
* **T-Shirt Size**: Select the size of the volunteer shirt you would like.
	+ Type: select_one
	+ Options: XS, S, M, L, XL, 2XL, 3XL, No shirt needed
	+ Required: true
* **Dietary Restrictions**: Select any dietary restrictions you have.
	+ Type: select_one
	+ Options: None, Vegetarian, Vegan, Gluten-free, Nut allergy, Other allergies
	+ Required: false
* **Accessibility Needs**: If you have any accessibility needs, please specify here.
	+ Type: text
	+ Required: false
* **Transportation Needed**: If you need transportation assistance, select this option.
	+ Type: select_one
	+ Options: 'True', 'False'
	+ Required: true
* **Background Check Status**: If a background check is required for your role, select this option.
	+ Type: select_one
	+ Options: Already completed, Willing to complete, Not applicable
	+ Required: true
* **Emergency Contact Name**: Enter the name of the person you would like us to contact in case of an emergency.
	+ Type: text
	+ Required: true
* **Emergency Contact Phone**: Enter the phone number of the person you listed above.
	+ Type: text
	+ Required: true
* **Liability Waiver**: Confirm that you understand and agree to the event's liability waiver.
	+ Type: select_one
	+ Options: 'True', 'False'
	+ Required: true
* **Photo Release Authorization**: Confirm that you allow photos to be used for promotional purposes.
	+ Type: select_one
	+ Options: 'True', 'False'
	+ Required: true
* **Referral Source**: Select how you heard about this event.
	+ Type: select_one
	+ Options: Social media, Email newsletter, Friend or family, Organization referral, Website, Community bulletin, Other
	+ Required: true
* **Motivation for Volunteering**: If you have a reason for volunteering that motivates you, please share it here. (Optional)
	+ Type: text
	+ Required: false
* **Additional Comments or Questions**: If you have any additional comments or questions, please share them here. (Optional)
	+ Type: text
	+ Required: false
