# Corporate Event RSVP Form - Help Guide
## Purpose
The Corporate Event RSVP Form is designed to help you provide your RSVP status and details for corporate events hosted by our company. This form will help us ensure accurate headcounts for the event and make necessary arrangements accordingly.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the event details section (page 1) and enter the event title and date if you know them.
2. On the RSVP status page (page 2), select your RSVP status from the options provided (Attending, Declining, Unable to Attend).
3. If you're attending, you can specify the number of attendees you'll be bringing (in the "Attendees" field on page 1).
4. Review and complete the form carefully, ensuring that all fields are accurate and complete.
5. Click submit to send your RSVP status to us.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, optional): Please enter the event title and date if you know them. This will help us associate your RSVP with the correct event.
* **RSVP Status** (`rsvp_status`, select_one, optional): Please select your RSVP status from the options provided:
	+ Attending: I will be attending the event.
	+ Declining: I will not be able to attend the event.
	+ Unable to Attend: I will not be able to attend, but I'd like to be kept informed about future events.
* **Event Date** (`event_date`, date, optional): Please enter the event date if you know it.
* **Event Time** (`event_time`, time, optional): Please enter the event time if you know it.
* **Attendees** (`attendees`, number, optional): If attending, please specify the number of attendees you'll be bringing with you.

## Tips
* Be accurate and complete when filling out this form.
* If you're unsure about any of the fields, ask your event planner for clarification.
* Make sure to review your form carefully before submitting it to ensure all fields are accurate and complete.
