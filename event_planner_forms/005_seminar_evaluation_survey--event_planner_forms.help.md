# Seminar Evaluation Survey - Help Guide

## Purpose
This form is designed to evaluate the seminar's content, participants, and overall satisfaction. The feedback collected will help us improve future seminars.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully to understand what information is being asked.
2. Fill out all sections thoroughly and accurately.
3. If you have any suggestions for improvement, please provide them in the "Suggestions for improvement" section.

## Field-by-Field Explanation

* **Introduction (Page 1)** (`title`, required: false): This is a brief introduction to the form. Please ignore this page and proceed to the next section.
* **Seminar Participants (Page 2)** (`seminar_participants`, required: false): Please select all the seminar participants that you met during the seminar.
* **Seminar Content (Page 3)** (`seminar_content`, required: false): Please select all the seminar content that you found helpful or interesting.
* **Seminar Leader (Page 4)** (`seminar_leader`, required: false): Please select the seminar leader's performance.
* **Seminar Location (Page 5)** (`seminar_location`, required: false): Please select the seminar location's suitability.
* **Overall Satisfaction (Page 6)** (`overall_satisfaction`, required: false): Please select your overall satisfaction with the seminar.
* **Suggestions for improvement (Page 7)** (`suggestions_for_improvement`, required: false): Please provide any suggestions you have for improving future seminars.
* **Seminar Evaluation (Page 8)** (`seminar_evaluation`, required: false): Please select your final evaluation of the seminar.

Note: All fields are not required, so you can skip them if you don't have any opinions or experiences to share.
