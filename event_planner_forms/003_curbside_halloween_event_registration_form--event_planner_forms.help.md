# Curbside Halloween Event Registration Form - Help Guide

## Purpose
The Curbside Halloween Event Registration Form is designed to collect information from customers or event coordinators for a specific Halloween event. The data collected will help in organizing and executing the event smoothly.

## How To Complete This Form
To fill out the Curbside Halloween Event Registration Form, follow these steps:

1. Enter the **Event Name** in the first field. This is the title of the event you're registering for. Ensure it accurately represents the event's name.
2. Provide your **Email** in the second field. This will help the event coordinators contact you with further instructions or event updates.
3. Enter your **Phone** number in the third field. This is an optional but recommended field for quick contact.
4. Enter your **Address** in the fourth field. This is where you can provide the physical address associated with the event.
5. Enter the **City** name in the fifth field. This is the city where the event will take place.

## Field-by-Field Explanation
* **Event Name**: Enter the actual name of the event you're registering for. Make sure it's clear and concise.
* **Email**: This field requires a valid email address where you can be contacted. Use the format 'email@example.com' if you have one.
* **Phone**: If you'd like to be contacted via phone, enter your number here. If not needed, leave this field blank.
* **Address**: Provide the physical location associated with the event.
* **City**: Enter the city where the event will take place.
