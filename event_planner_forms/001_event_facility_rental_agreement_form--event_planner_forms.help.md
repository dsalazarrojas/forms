# Event Facility Rental Agreement Form - Help Guide
## Purpose
The Event Facility Rental Agreement Form is a crucial document that outlines the terms and conditions for renting a facility for an event. It ensures that both the event planner and facility manager have a clear understanding of the event details, reducing misunderstandings and errors.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide the facility address where the event will take place.
2. Enter the contact information of the facility.
3. Specify the event date and start time.
4. Select the number of guests attending the event.
5. Describe the event in detail.
6. Select any additional equipment, amenities, and services required for the event.
7. Confirm the event's audio, visual, and other services needs.
8. Select any additional services required for the event.
9. Specify the event's security and staffing needs.
10. Confirm the event's setup and teardown requirements.
11. Specify the facility access requirements.
12. Add any additional event notes.
13. Review and accept the agreement terms.
14. Finalize the agreement by specifying the agreement date and start time.
