# virtual_game_night_registration_form - Help Guide

## Purpose
This form is used to register for a virtual game night event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your participant details:
	* **Participant name**: Enter your name as it appears on your identification.
	* **Participant email**: Enter a valid email address that we can use to contact you.
	* **Participant phone**: Enter a valid phone number that we can use to contact you.
2. Fill in event details:
	* **Event name**: Enter the name of the event you are registering for.
	* **Game name**: Enter the name of the game you will be playing.
	* **Game type**: Enter the type of game you will be playing.
	* **Game date**: Enter the date of the game.
	* **Game time**: Enter the time of the game.
3. Fill in host details:
	* **Host name**: Enter the name of the host.
	* **Host email**: Enter a valid email address that we can use to contact the host.
	* **Host phone**: Enter a valid phone number that we can use to contact the host.
4. Confirm your participation:
	* **Participant agreement**: Confirm that you agree to the rules and regulations of the game.
	* **Participant confirmation**: Confirm that you can participate in the game.
5. Enter game-specific details:
	* **Game password**: If required, enter the game password. If not required, leave this field blank.
	* **Game password hint**: Enter a hint for the game password.
	* **Player count**: Enter the number of players in the game.
	* **Max player count**: Enter the maximum number of players in the game.
6. Confirm game details:
	* **Rules**: Enter any additional rules for the game.
	* **Rules URL**: Enter the URL for the game rules.
	* **Rules password**: If required, enter the password for the rules.
