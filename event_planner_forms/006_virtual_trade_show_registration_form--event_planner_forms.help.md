# Virtual Trade Show Registration Form - Help Guide
## Purpose
This form is designed for users to register for a virtual trade show. Please fill out the form with your information and event-specific details to help us prepare for the event.

## How To Complete This Form
1. Fill out the form with your First Name and Last Name.
2. Enter your Email address to be contacted about event details and updates.
3. If you are registering as an employee of a company, please provide the Company name.
4. Indicate the Event Name you are registering for.
5. Select the Start Date and End Date of the event.
6. Choose whether you are a 'Yes' or 'No' for Event Type.

## Field-by-Field Explanation
* **First Name** (`event_planner_forms_first_name`, text, required/optional): This is the first name of the attendee.
* **Last Name** (`event_planner_forms_last_name`, text, required/optional): This is the last name of the attendee.
* **Email** (`event_planner_forms_email`, email, required/optional): Enter your email address to be contacted about event details and updates.
* **Company** (`event_planner_forms_company`, text, required/optional): If you are registering as an employee of a company, please provide the company name.
* **Event Name** (`event_planner_forms_event_name`, text, required): This is the name of the event you are registering for.
* **Start Date** (`event_planner_forms_start_date`, date, required): Select the start date of the event.
* **End Date** (`event_planner_forms_end_date`, date, required): Select the end date of the event.
* **Event Type** (`event_planner_forms_event_type`, select_one, required): Indicate whether you are a 'Yes' or 'No' for the event type.
