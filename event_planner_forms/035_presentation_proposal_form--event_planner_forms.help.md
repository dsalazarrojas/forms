# Presentation Proposal Form - Help Guide
## Purpose
The Presentation Proposal Form is designed to collect all necessary information for a presentation, including speaker details, presentation details, event information, and submission status. This form is used to ensure that all relevant information is provided for the presentation.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information for the presentation.
2. Provide accurate and clear details about the speaker, presentation, and event.
3. Select the correct options from the dropdown menus as needed.
4. Make sure to check your submission before clicking the submit button.

## Field-by-Field Explanation

* **Speaker Information (Speaker Name)** (`speaker_info`, text, optional): Please enter the name of the speaker.
* **Presentation Information (Presentation Name)** (`presentation_info`, text, optional): Please enter the name of the presentation.
* **Event Information (Event Title)** (`event_info`, text, optional): Please enter the title of the event.
* **Presentation Details (Presentation Title)** (`presentation_details`, text, optional): Please enter a brief description of the presentation.
* **Submission Date** (`submission_date`, date, optional): Please enter the date you plan to submit the presentation.
* **Presentation Title** (`presentation_title`, text, optional): Please enter the title of the presentation.
* **Speaker Abstract** (`speaker_abstract`, text, optional): Please enter a brief abstract about the speaker.
* **Presenter Information (Presenter Name)** (`presenter_info`, text, optional): Please enter the name of the presenter.
* **Presenter Experience** (`presenter_experience`, select multiple, optional): Please select the presenter's relevant experience.
* **Presentation Length** (`presentation_length`, number, required): Please enter the length of the presentation.
* **File Upload (Submission File)** (`submission_file`, text, optional): Please upload a supporting file for the presentation.
* **Presentation Topics** (`presentation_topics`, text, optional): Please enter a brief description of the presentation topics.
* **Event Date** (`event_date`, date, optional): Please enter the date of the event.
* **Event Time** (`event_time`, time, optional): Please enter the time of the event.
* **Event Location** (`event_location`, text, optional): Please enter the location of the event.
* **Speaker Email** (`speaker_email`, email, required): Please enter the speaker's email address.
* **Speaker Phone** (`speaker_phone`, text, required): Please enter the speaker's phone number.
* **Speaker Notes** (`speaker_notes`, note, required): Please enter notes about the speaker.
* **Event Notes** (`event_note`, note, required): Please enter notes about the event.
* **Submission Notes** (`submission_note`, note, required): Please enter notes about the submission.
* **Submission Status** (`submission_status`, select one, required): Please select the submission status.
* **Submission Date Range** (`submission_date_range`, date, required): Please enter the submission date range.
* **Submission Time Range** (`submission_time_range`, time, required): Please enter the submission time range.
* **Submission File** (`submission_file`, text, required): Please upload a submission file.
* **Submission Comment** (`submission_comment`, text, optional): Please enter any additional comments about the submission.
