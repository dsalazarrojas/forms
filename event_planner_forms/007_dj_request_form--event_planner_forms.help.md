# DJ Request Form - Help Guide
## Purpose
The DJ Request Form is used to request a specific type of event and to provide details about the event and the music preferences of the requesting user.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out each field accurately and completely to ensure that your event is processed efficiently.
2. Ensure that all required fields are filled out.

## Field-by-Field Explanation
* **Event Title** (`request_title`, text, required): Enter the title of the event.
* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Event Date** (`event_date`, date, required): Enter the date of the event in the correct format (YYYY-MM-DD).
* **Start Time** (`start_time`, time, required): Enter the start time of the event in the correct format (HH:MM AM/PM).
* **End Time** (`end_time`, time, required): Enter the end time of the event in the correct format (HH:MM AM/PM).
* **Song Request** (`song_request`, text, required): Enter the songs you would like to hear.
* **Artist Request** (`artist_request`, text, optional): Enter the artist you would like to request.
* **Genre Request** (`genre_request`, text, optional): Enter the genre of music you would like to hear.
* **Event Type** (`event_type`, select_one, required): Select the type of event (e.g. Dance, Party, Wedding, Other).
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Message** (`message`, text, optional): Add any comments or messages for the DJ.
* **Assigned Tool** (`assigned_tool`, text, required): Enter the assigned tool.
* **Form Comments** (`form_comments`, text, optional): Add any comments about the form or the event.
