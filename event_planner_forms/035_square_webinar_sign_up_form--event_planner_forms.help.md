# Square Webinar Sign Up Form - Help Guide
## Purpose
The Square Webinar Sign Up Form is designed to streamline the registration process for attendees and event organizers. By using this form, users can easily sign up for webinars, provide essential details, and track the registration status.

## How To Complete This Form

1. **Review each field carefully** to understand its purpose and requirements.
2. **Fill in the required fields**, indicated by the asterisk (∗) symbol.
3. **Submit the form** after filling in all required fields.

## Field-by-Field Explanation

* **User Details** (`user_input`, `text`, ∗): Provide your name and any other details you'd like to share with the event organizer.
* **Email** (`email`, `email`, ∗): Enter your valid email address to receive updates and notifications about the webinar.
* **First Name** (`first_name`, `text`, ∗): Enter your first name as you'd like it to be displayed for the event organizer.
* **Last Name** (`last_name`, `text`, ∗): Enter your last name as you'd like it to be displayed for the event organizer.
* **Phone** (`phone`, `text`, non-required): If you'd like to be contacted by phone, provide your phone number.
* **Date** (`date`, `date`, non-required): Choose the date you'd like to attend the event. If left blank, you'll be registered for the default event date.
* **Time** (`time`, `time`, non-required): Choose the time you'd like to attend the event. If left blank, you'll be registered for the default event time.
* **Note** (`note`, `note`, non-required): Share any notes or special requests with the event organizer.
* **Event Details** (`event_details`, `text`, ∗): Provide any additional details you'd like to share with the event organizer.
* **Event Time** (`event_time`, `time`, ∗): Choose the time of the event you'd like to attend.
* **Event Date** (`event_date`, `date`, ∗): Choose the date of the event you'd like to attend.
* **Registration Status** (`registration_status`, `select_multiple`, ∗): Select your registration status for the event from the provided options.

Note: The asterisk (∗) symbol indicates a required field.
