# Cotillion Application Form - Help Guide

## Purpose
The Cotillion Application Form is a tool for users to provide information about an event they are hosting or attending.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the required fields with the necessary information about the event.
2. Select the correct options for the "Event Type" field based on the type of event you are hosting or attending.
3. Provide a detailed "Event Description" of the event, including any additional information that might be relevant to the event planner or other attendees.
4. If you are the host or organizer of the event, fill in your "Event Host" information, including their phone number, email, and address.
5. Finally, review the form for accuracy and completeness before submitting it for review.

## Field-by-Field Explanation

* **Event Type** (`Event Type`, `select_one`): Select the type of event you are hosting or attending. Options include "Wedding", "Birthday", and "Other".
* **Event Date** (`Event Date`, `date`): Enter the date of the event.
* **Event Time** (`Event Time`, `time`): Enter the time of the event.
* **Event Location** (`Event Location`, `text`): Enter the location where the event will take place.
* **Number of Guests** (`Number of Guests`, `number`): Enter the number of guests attending the event.
* **Special Requests** (`Special Requests`, `note`): Enter any special requests or requirements for the event.
* **Dance Style** (`Dance Style`, `select_multiple`): Select the type of dance style for the event. Options include "Salsa", "Tango", "Rumba", and "Jive".
* **Experience Level** (`Experience Level`, `select_one`): Select the experience level of the event's attendees. Options include "Beginner", "Intermediate", and "Advanced".
* **Emergency Contact** (`Emergency Contact`, `text`): Enter the name and contact information of an emergency contact person.
* **Emergency Number** (`Emergency Number`, `text`): Enter the phone number of the emergency contact.
* **Event Host** (`Event Host`, `text`): Enter the name of the host or organizer of the event.
* **Event Host Phone** (`Event Host Phone`, `text`): Enter the phone number of the event host.
* **Event Host Email** (`Event Host Email`, `text`): Enter the email address of the event host.
* **Event Host Address** (`Event Host Address`, `text`): Enter the address of the event host.
* **Payment Method** (`Payment Method`, `select_one`): Select the payment method for the event. Options include "Cash", "Check", and "Credit".
* **Payment Details** (`Payment Details`, `text`): Enter any additional payment details, if necessary.
* **Confirmation Message** (`Confirmation Message`, `text`): Enter any confirmation or follow-up information for attendees.
