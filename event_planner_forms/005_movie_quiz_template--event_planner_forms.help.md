# Movie Quiz Template - Help Guide
## Purpose
This form is used to create a movie quiz template with various options for the type of quiz, answer format, and other settings.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of quiz you want to create (Multiple Choice, True/False, or Fill-in-the-blank).
2. Enter 10-20 questions in the "Questions" field.
3. Choose the format of the answers you want to receive (Multiple choice, True/False, or Fill-in-the-blank).
4. Enter the correct answers for each question.
5. Select a name for your quiz from the options.
6. Enter a brief description of the quiz.

## Field-by-Field Explanation

* **What type of quiz do you want to create?** (question_type): Choose the type of quiz you want to create (Multiple Choice, True/False, or Fill-in-the-blank).
* **Questions** (questions): Enter 10-20 questions for your quiz.
* **What type of answers do you want to get?** (answer_type): Choose the format of the answers you want to receive (Multiple choice, True/False, or Fill-in-the-blank).
* **Answer format** (answer_format): Choose the format of the answers (Multiple choice, True/False, or Fill-in-the-blank).
* **Correct answers** (correct_answer): Enter the correct answers for each question.
* **Answers** (answers): Enter the answers to each question.
* **Quiz name** (quiz_name): Select a name for your quiz from the options.
* **Quiz description** (quiz_description): Enter a brief description of the quiz.

## Tips
* Make sure to enter the correct answers for each question.
* Enter a brief description that will help users understand the purpose and context of the quiz.
* Use the correct format for the answers to ensure accuracy and consistency.
* Keep the quiz name and description clear and concise.
