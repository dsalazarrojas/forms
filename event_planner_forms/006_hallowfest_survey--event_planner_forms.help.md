# Hallowfest Survey - Help Guide

## Purpose
This form is designed to collect information related to events or surveys, likely for an event planning purpose such as collecting event details, dates, times, email, phone numbers, and notes. The form is designed to be a multiple-page form with 25 fields across various pages.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in all the required fields. The required fields are marked as "required" in the form.
2. Use the correct format for the date fields: `MM/DD/YYYY` or `DD-MM-YYYY`
3. Use the correct format for the time fields: `HH:MM AM/PM` or `HH:MM HH:MM AM/PM`
4. For select fields, choose one option from the dropdown menu.
