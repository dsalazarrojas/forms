# Women's Tea Event Registration Form - Help Guide
## Purpose
This form is designed to collect information from attendees for an event called "Women's Tea Event". The form is used to gather details from participants about their contact preferences, event schedule, and other relevant information.

## How To Complete This Form
- Start by providing your name and any other information that is requested on the "attendee_info" page.
- Select one of the contact preferences (Phone, Email, In Person) on the "contact_preference" page.
- Enter the date of the event in the format mm/dd/yyyy on the "date_of_event" page.
- Enter the time of the event in 24-hour format (HH:MM) on the "time_of_event" page.
- Add any brief description of the event on the "event_details" page.
- Select any dietary restrictions you have (Gluten-Free, Vegan, Vegetarian, None) on the "dietary_restrictions" page.
- Add any special requests on the "special_requests" page.
- Add any additional comments or notes on the "notes" page.
- Add any additional comments or notes from the attendee on the "attendee_comments" page.

## Field-by-Field Explanation
- **Attendee Information** (`attendee_info`): Enter your name and any other information that is requested.
- **Contact Preference** (`contact_preference`): Select one of the contact preferences (Phone, Email, In Person).
  - Phone: You will receive a call or text from the event organizer.
  - Email: You will receive an email from the event organizer.
  - In Person: You will be contacted directly at the event.
- **Date of Event** (`date_of_event`): Enter the date of the event in the format mm/dd/yyyy.
- **Time of Event** (`time_of_event`): Enter the time of the event in 24-hour format (HH:MM).
- **Event Details** (`event_details`): Add a brief description of the event.
- **Dietary Restrictions** (`dietary_restrictions`): Select any dietary restrictions you have (Gluten-Free, Vegan, Vegetarian, None).
  - Gluten-Free: You have a gluten allergy or intolerance.
  - Vegan: You do not consume any animal products.
  - Vegetarian: You consume dairy products but not meat.
  - None: You do not have any dietary restrictions.
- **Special Requests** (`special_requests`): Add any special requests.
- **Notes** (`notes`): Add any additional comments or notes.
- **Attendee Comments** (`attendee_comments`): Add any additional comments or notes from the attendee.
