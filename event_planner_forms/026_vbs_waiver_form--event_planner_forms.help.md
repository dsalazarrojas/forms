# vbs-waiver-form - Help Guide
## Purpose
The vbs-waiver-form is used to collect information from users for various waiver forms.

## How To Complete This Form
To complete this form, follow these steps:

*   Start by selecting the relevant waiver form type (VBS Waiver Form, VBS Waiver Form 1, or VBS Waiver Form 2) from the dropdown menu.
*   For each of the remaining sections, fill in the required information:
    *   If you need to select an option, choose from the list provided.
    *   If you need to provide a text input, type your answer.
    *   If you need to provide a date or time input, select the date or time from the provided calendar or clock.
    *   Be sure to review and submit the form when you have completed all the required fields.
