# Free Movie Ticket - Help Guide
## Purpose
This form is used to provide details about a movie event, including the date, time, movie title, theater, genre, description, director, and starring actor. The form helps event planners to plan and organize movie events accurately.

## How To Complete This Form
1. Fill in the "Movie Date" field with the date of the movie event.
2. Enter the "Movie Time" in 24h format (e.g., 14:00 for 2:00 PM).
3. Type in the "Movie Title" field with the title of the movie.
4. Enter the name of the movie theater in the "Movie Theater" field.
5. Select the "Movie Genre" option that best describes the movie genre.
6. Add a brief description of the movie in the "Movie Description" field.
7. Enter the name of the movie director in the "Movie Director" field.
8. Enter the name of the movie's starring actor in the "Movie Star" field.

## Field-by-Field Explanation
* **Free Movie Ticket**: A text field where you can enter any additional information about the movie.
* **Movie Date**: A date field where you can enter the date of the movie event. Make sure to format it in YYYY-MM-DD or other accepted date formats.
* **Movie Time**: A time field where you can enter the time of the movie event in 24h format (e.g., 14:00 for 2:00 PM).
* **Movie Theater**: A text field where you can enter the name of the movie theater.
* **Movie Genre**: A dropdown selection field where you can choose from a list of genres (Yes, No).
* **Movie Description**: A text field where you can enter a brief description of the movie.
* **Movie Director**: A text field where you can enter the name of the movie director.
* **Movie Star**: A text field where you can enter the name of the movie's starring actor.
