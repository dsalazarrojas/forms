# Marriage Application Form - Help Guide
## Purpose
This form is designed to gather information about a wedding event.

## How To Complete This Form
1. Please fill out the form with the required and optional information about the wedding event.
2. Ensure that you provide accurate and truthful information.
3. Review the form carefully before submitting it.

## Field-by-Field Explanation

* **User Input**: This field is for any additional information you want to share about the wedding event. (required: false)
* **Date Of Marriage**: Enter the date of the wedding event. (required: false)
* **Marriage Location**: Enter the location of the wedding ceremony. (required: false)
* **Marriage Date**: Enter the date of the marriage. This should match the date of the marriage ceremony. (required: false)
* **Time Of Marriage**: Enter the time of the marriage ceremony. (required: false)
* **Marriage Time**: Enter the time of the marriage. This should match the time of the marriage ceremony. (required: false)
* **Wedding Attire**: Select the attire worn by the wedding party. (options: Formal, Semi-Formal, Casual, Other)
* **Marriage License Number**: Check if the wedding is officially licensed. (options: True, False)
* **Marriage Certificate**: Check the marriage certificate status. (options: Certified Copy, Not Certified, Pending)
* **Marriage Certificate Number**: Check the marriage certificate number. (options: Certified, Not Certified, Pending)
* **Ceremony Attire**: Select the attire worn during the ceremony. (options: Formal, Semi-Formal, Casual)
* **Ceremony Time**: Select the time of the ceremony. (options: Morning, Afternoon, Evening)
* **Reception Attire**: Select the attire worn during the reception. (options: Formal, Semi-Formal, Casual)
* **Reception Location**: Select the location of the reception. (options: Restaurant, Hotel, Venue, Other)
* **Reception Time**: Select the time of the reception. (options: Morning, Afternoon, Evening)
* **Photo Permission**: Check if photos can be taken. (options: True, False)
* **Photo Release**: Check if photo release is allowed. (options: True, False)
* **Signature 1**: This is a note field for signatures. Please enter your signature here. (required: false)
* **Signature 2**: This is a note field for signatures. Please enter your signature here. (required: false)
* **Photo Signature**: This is a note field for signatures and photos. Please enter your signature and photo here. (required: false)
* **Photo Signature 1**: This is a note field for signatures and photos. Please enter your signature and photo here. (required: false)
* **Photo Signature 2**: This is a note field for signatures and photos. Please enter your signature and photo here. (required: false)
* **Wedding Song**: This is a field to input a wedding song. (required: false)
* **Reception Song**: This is a field to input a reception song. (required: false)
* **Special Requests**: This is a field to input any special requests. (required: false)

## Tips

- Review the form carefully before submitting it.
- Double-check that all required fields are filled out.
- Use clear and concise language when filling out the form.
- Ensure that you are filling out the form for a specific wedding event.
- Do not fill out this form for any other purpose.
