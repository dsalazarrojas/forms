# Glamorous Event Waiver Form - Help Guide
## Purpose
This form is used by event planners to collect participant information and waiver agreements for events. The form is intended to ensure that participants understand and agree to the terms of the event.

## How To Complete This Form
1. Please fill in your participant information, including:
	* Participant ID
	* Name
	* Email
	* Phone
	* Participant Waiver
	* Participant Waiver Date
	* Participant Waiver Time
	* Participant Waiver Signature
2. Select 'Yes' or 'No' for the Participant Waiver question to indicate whether you agree to the event terms.
3. Fill in the event details:
	* Event Name
	* Event Date
	* Event Location

## Field-by-Field Explanation

* **Participant ID**: This is a unique identifier assigned to each participant.
* **Name**: Please enter your name as it appears on your identification.
* **Email**: Enter your email address where you can be contacted.
* **Phone**: Enter your phone number where you can be reached.
* **Participant Waiver**: Select 'Yes' to indicate you agree to the event terms.
* **Participant Waiver Date**: The date you sign the waiver.
* **Participant Waiver Time**: The time you sign the waiver.
* **Participant Waiver Signature**: A handwritten or printed signature to indicate agreement to the waiver.
* **Event Name**: The name of the event you are participating in.
* **Event Date**: The date of the event.
* **Event Location**: The location of the event.
* **Event Planner ID**: This is a unique identifier assigned to each event planner.
* **Event Planner Name**: The name of the event planner.
* **Event Planner Email**: The email address of the event planner.
* **Event Planner Phone**: The phone number of the event planner.
* **Event Planner Waiver**: Select 'Yes' or 'No' to indicate whether the event planner has a waiver agreement.
* **Event Planner Waiver Date**: The date the event planner signed the waiver.
* **Event Planner Waiver Time**: The time the event planner signed the waiver.
* **Waiver Agreement**: This is a general waiver agreement for the participant, which they must sign.
* **Waiver Date**: This is the date the participant signed the waiver.
* **Waiver Time**: This is the time the participant signed the waiver.
* **Waiver Signature**: A handwritten or printed signature to indicate agreement to the waiver.
