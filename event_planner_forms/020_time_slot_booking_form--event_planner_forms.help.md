# Time Slot Booking Form - Help Guide
## Purpose
This form is designed to collect information about time slots, allowing users to book and manage events. The goal is to provide all necessary details for an event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the General Info section with your name, email, and any other relevant contact information.
2. In the Date Time section, enter the date and time of the event.
3. In the Contact Info section, add any additional contact information you'd like to share with the event organizer.
4. In the Event Details section, provide a brief description of the event.
5. Choose the type of event you're booking (e.g., Meeting, Consultation, Appointment, or Other).
6. If necessary, add a description of the event in the Description field.
7. Enter the location of the event in the Location field.
8. Set the time and duration of the event in the Time and Duration fields.
9. Choose how often the event will repeat (e.g., Once, Multiple, Daily, Weekly, or Monthly).
10. If the event repeats, select a frequency (e.g., every day, every other day, etc.).
11. Set a reminder for the event, if desired.
12. Enter a repeat time, if the event repeats (e.g., every 2 weeks).
13. Enter the repeat count for the event (e.g., 5 times, 10 times, etc.).
14. If needed, select a timezone for the event.
15. Add any additional notes about the event.

## Field-by-Field Explanation

* **General Info** (`General Info`, `text`, required: false): Enter your name and any other relevant contact information to be shared with the event organizer.
* **Date Time** (`Date Time`, `text`, required: false): Enter the date and time of the event.
* **Contact Info** (`Contact Info`, `text`, required: false): Add any additional contact information you'd like to share with the event organizer.
* **Event Details** (`Event Details`, `text`, required: false): Provide a brief description of the event.
* **Event Type** (`Event Type`, `select_multiple`, required: false): Choose the type of event you're booking (e.g., Meeting, Consultation, Appointment, or Other).
* **Description** (`Description`, `text`, required: false): If necessary, add a more detailed description of the event.
* **Location** (`Location`, `text`, required: false): Enter the location of the event.
* **Time** (`Time`, `time`, required: false): Set the time of the event.
* **Duration** (`Duration`, `number`, required: false): Set the duration of the event.
* **Start Time** (`Start Time`, `time`, required: false): Set the start time of the event.
* **End Time** (`End Time`, `time`, required: false): Set the end time of the event.
* **Repeat** (`Repeat`, `select_one`, required: false): Choose how often the event will repeat (e.g., Once, Multiple, Daily, Weekly, Monthly).
* **Frequency** (`Frequency`, `text`, required: false): If the event repeats, enter the frequency (e.g., every day, every other day, etc.).
* **Reminder** (`Reminder`, `text`, required: false): Set a reminder for the event, if desired.
* **Repeat Time** (`Repeat Time`, `time`, required: false): If the event repeats, enter the repeat time.
* **Repeat Count** (`Repeat Count`, `text`, required: false): Enter the repeat count for the event (e.g., 5 times, 10 times, etc.).
* **Timezone** (`Timezone`, `text`, required: false): Select a timezone for the event.
* **Notes** (`Notes`, `note`, required: false): Add any additional notes about the event.

## Tips

* Please ensure that you fill in all required fields and any other relevant information.
* You can choose to fill in only the necessary fields according to your needs.
* If the event repeats, make sure to fill in the repeat time and count fields.
* Remember to select a timezone if needed.
* Use the notes field for any additional event details that don't fit in other fields. 

Note: Fields without options are text fields.
