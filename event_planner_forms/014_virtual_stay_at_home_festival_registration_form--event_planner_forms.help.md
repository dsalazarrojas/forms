# Virtual Stay At Home Festival Registration Form - Help Guide
## Purpose
This form is used to register for the Virtual Stay At Home Festival. Please fill out the form accurately to ensure that you are registered for the event.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Review each field carefully before submitting the form.
3. Make sure to choose the correct payment method and ticket price.

## Field-by-Field Explanation

* **First Name** (Text): This is your first name. Please fill it out carefully.
* **Last Name** (Text): This is your last name. Please fill it out accurately.
* **Email** (Email): This is your email address. Please enter your email address in the correct format (e.g. example@example.com).
* **Phone** (Text): This is your phone number. Please enter your phone number accurately.
* **Event Date** (Date): This is the date of the virtual event. Please select the correct date from the calendar or enter it in the correct format (e.g. mm/dd/yyyy).
* **Event Time** (Time): This is the time of the virtual event. Please select the correct time from the clock or enter it in the correct format (e.g. HH:MM AM/PM).
* **Event Location** (Text): This is the virtual location of the event. Please fill it out accurately.
* **Event Description** (Text): This is a brief description of the event. Please fill it out accurately.
* **Number of Attendees** (Number): This is the number of people attending the event with you. Please enter the correct number.
* **List of Attendees** (Multiple Selection): This is a list of attendees. Please select "Yes" for each attendee that will be attending the event.
* **Additional Comments** (Note): This is an optional field for any additional comments or information you'd like to share.
* **Payment Method** (Select One): This is the method of payment you'd like to use. Please select one of the options (PayPal or Bank Transfer).
* **Ticket Price** (Number): This is the price of the ticket for the event. Please enter the correct price.
* **Total Cost** (Number): This is the total cost of the event. Please enter the correct price.
* **Payment Status** (Select One): This is the status of your payment. Please select one of the options (Paid or Unpaid).
* **Notes** (Note): This is an optional field for any additional comments or information you'd like to share.

## Tips
* Make sure to review each field carefully before submitting the form.
* Ensure that you have filled out all required fields accurately.
* If you have any questions or issues, please contact us for assistance.
