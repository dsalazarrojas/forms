# Live Experience Design Submission Application Form - Help Guide

## Purpose
The Live Experience Design Submission Application Form is used to submit events for live experience design projects. This form is essential for the project lead and their team to be contacted for further evaluation and follow-up.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the event type by choosing one of the three options: Live Event, Virtual Event, or Hybrid Event.
2. Fill in the project lead, project lead email, and project lead phone number fields, if applicable.
3. Provide a detailed description of the event.
4. Enter the dates and time of the event.
5. Specify the event location.
6. Enter the event capacity and cost (if applicable).

## Field-by-Field Explanation
* **Event Type** (`event_type`, required): Select one of the three event options: Live Event, Virtual Event, or Hybrid Event.
* **Project Lead** (`project_lead`, optional): Enter the name of the project lead.
* **Project Lead Email** (`project_lead_email`, optional): Enter the email address of the project lead.
* **Project Lead Phone** (`project_lead_phone`, optional): Enter the phone number of the project lead.
* **Event Description** (`event_description`, optional): Provide a detailed description of the event.
* **Event Dates** (`event_dates`, optional): Enter the dates of the event.
* **Event Time** (`event_time`, optional): Enter the time of the event.
* **Event Location** (`event_location`, optional): Specify the event location.
* **Event Capacity** (`event_capacity`, optional): Enter the number of attendees expected at the event.
* **Event Cost** (`event_cost`, optional): Enter the cost of the event (if applicable).

## Tips
* Ensure that the form is filled out completely and correctly before submission.
* Double-check the event type selection to ensure it accurately reflects the project requirements.
* Enter accurate and relevant information for the project lead and their team to follow up with the project lead.
