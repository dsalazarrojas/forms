**Virtual Experience Production Request Form - Help Guide**
## Purpose
The purpose of this form is to submit a request for the production of a virtual experience. This form is used by organizers and producers to create a virtual event, workshop, conference, meetup, or seminar.

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the type of event (e.g., event, workshop, conference, meetup, seminar) that you would like to produce.
2. Fill in the event details, including the date and time.
3. Specify the duration of the event in hours or minutes.
4. Choose the team that will be responsible for producing the event.
5. Add any additional notes or requirements for the event production.

## Field-by-Field Explanation

* **Production Request**: Enter a brief description of the event you are requesting.
* **Event Type**: Select the type of event you would like to produce (e.g., event, workshop, conference, meetup, seminar).
* **Date**: Enter the date of the event in the format of `MM/DD/YYYY` (e.g., 01/22/2024).
* **Venue**: Enter the name of the venue or location of the event.
* **Time**: Enter the time of the event in the format of `HH:MM AM/PM` (e.g., 02:00 PM).
* **Duration**: Enter the duration of the event in hours or minutes (e.g., 2 hours).
* **Team**: Select the team that will be responsible for producing the event (e.g., Team A, Team B, Team C, Team D).
* **Notes**: Add any additional notes or requirements for the event production.

## Tips

* Make sure to double-check your event details for accuracy before submitting the form.
* Ensure that you only submit one request per form.
* If you need to make changes to an existing request, please contact the production team directly.
* If you have any questions or concerns, please don't hesitate to reach out to us for assistance.
