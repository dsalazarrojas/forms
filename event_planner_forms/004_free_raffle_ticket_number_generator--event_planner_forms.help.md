# free_raffle_ticket_number_generator - Help Guide
## Purpose
The free raffle ticket generator form is designed to create free raffle tickets with customizable options for events or contests.

## How To Complete This Form
To complete this form, follow the steps below:

1. Select the type of raffle tickets you want to generate using the "Generate Raffle" field.
2. Enter a title for your raffle in the "Raffle Title" field.
3. Provide a description of your raffle in the "Raffle Description" field.
4. Enter the number of tickets to be generated in the "Ticket Quantity" field.
5. Set the starting number of the raffle tickets in the "Start Number" field.
6. Enter the ticket numbers to be generated in the "Ticket Numbers" field.
7. Finally, select the number of tickets to download as PDF from the "Download PDF" field.

## Field-by-Field Explanation
* **Generate Raffle** (`select_multiple`, required): This field allows you to select the type of raffle tickets you want to generate. Choose from the available options to create your raffle tickets.
* **Raffle Title** (`text`, optional): Enter a title for your raffle, which will be displayed on the generated tickets.
* **Raffle Description** (`text`, optional): Provide a description of your raffle, which will be displayed on the tickets.
* **Ticket Quantity** (`number`, optional): Enter the number of tickets to be generated.
* **Start Number** (`number`, optional): Set the starting number of the raffle tickets.
* **Ticket Numbers** (`text`, optional): Enter the ticket numbers to be generated.
* **Download PDF** (`select_one`, optional): Select the number of tickets to download as PDF from the available options.
