# Hospitality Event Management Audit Form - Help Guide
## Purpose
The Hospitality Event Management Audit Form is a collection of fields for auditing and managing events in the hospitality industry.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the necessary information for the following fields:
	* Event Location
	* Event Date
	* Event Time
	* Event Planner
	* Guests
	* Services
	* Notes
	* Event Score
	* Comments
2. Leave the other fields blank unless you need to add more details.

## Field-by-Field Explanation
### 1. **Event Location**
	* Label: Event Location
	* Description: Enter the location where the event took place.
### 2. **Event Date**
	* Label: Event Date
	* Description: Enter the date of the event (YYYY-MM-DD).
### 3. **Event Time**
	* Label: Event Time
	* Description: Enter the time of the event (HH:MM).
### 4. **Event Planner**
	* Label: Event Planner
	* Description: Enter the name of the person responsible for planning the event.
### 5. **Event Planner**
	* Label: Event Planner
	* Description: Note: This field is not used as it has the same name as event_planner (id: 4) which is not recommended.
### 6. **Guests**
	* Label: Guests
	* Description: Enter a list of attendees or guests who attended the event.
### 7. **Services**
	* Label: Services
	* Description: Enter the services provided at the event (e.g. food, entertainment, etc.).
### 8. **Notes**
	* Label: Notes
	* Description: Enter any additional comments or notes about the event.
### 9. **Event Score**
	* Label: Event Score
	* Description: Enter a score for the event (e.g. on a scale of 1-10).
### 10. **Comments**
	* Label: Comments
	* Description: Enter any comments about the event.

## Tips
* Make sure to enter accurate and complete information to ensure that the event is properly recorded.
* Use the "Notes" field for any additional comments or observations.
* The "Event Score" field is optional and can be used to assess the overall success of the event.
