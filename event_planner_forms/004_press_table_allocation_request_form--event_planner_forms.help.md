# Press Table Allocation Request Form - Help Guide
## Purpose
The Press Table Allocation Request Form is used to request allocation of press tables for various events. Fill out this form to request a press table for a specific event.

## How To Complete This Form

1. Start by selecting the "Press Table Request" page on the first page of the form.
2. Fill out the required fields on this page.
3. Proceed to the "Contact Information and Event Details" page.
4. Fill out the required fields on this page.
5. Submit the form.

## Field-by-Field Explanation

* **Press Table Request (press_table_allocation_request_form_page_1)**: A description of the press table request. Please provide a brief description of the event and the press table needs.
* **Contact Name (contact_name)**: The name of the contact person responsible for the press table allocation.
* **Email (email)**: The email address of the contact person.
* **Phone Number (phone_number)**: The phone number of the contact person. (Note: This is an optional field.)
* **Organization (organization)**: The name of the organization or company associated with the press table request.
* **Role (role)**: The role or position of the contact person.
* **Media Type (media_type)**: Check if the event requires media coverage. (Note: This is an optional field.)
* **Media Quantity (media_quantity)**: The number of media personnel that will attend the event.
* **Start Date (start_date)**: The date of the event start.
* **Start Time (start_time)**: The time of the event start. (Note: This is an optional field.)
* **End Date (end_date)**: The date of the event end.
* **End Time (end_time)**: The time of the event end.
* **Duration (duration)**: The duration of the event. Please provide a brief description of the event duration.
* **Press Table Size (press_table_size)**: Check if the press table size is required.
* **Table Layout (table_layout)**: Please provide a brief description of the press table layout.
* **Note**: All required fields must be completed before submitting the form.
