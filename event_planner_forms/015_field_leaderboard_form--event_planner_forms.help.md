# Field Leaderboard Form - Help Guide

## Purpose
The Field Leaderboard Form is used to create a report of fields within a specified area, typically for tracking and analyzing agricultural or farming data. This form helps to identify and compare key metrics such as field type, name, and size.

## How To Complete This Form

1. **Start by selecting the correct Field Information**. This section is optional but helps to provide context for your report.
2. **Choose the Type of Field** by selecting one of the provided options: Crop, Equipment, or Animal.
3. **Enter the Field Name**, if desired. This is a free-text field for any additional information about the field.
4. **Specify the Size** of the field in acres.

## Field-by-Field Explanation

* **Field Information (section_1)** (`text`, optional): Enter any relevant information about the field, such as its location or specific characteristics.
* **Type (field_type)** (`select_one`, required): Select one of the following options:
	+ Crop: For fields used for growing crops.
	+ Equipment: For fields used for equipment storage or other non-agricultural purposes.
	+ Animal: For fields used for animal grazing or other animal-related activities.
* **Field Name (field_name)** (`text`, optional): Enter a name for the field, which can be useful for identification or reference.
* **Size (size)** (`number`, optional): Enter the size of the field in acres.
