# Santa Photo Order Form - Help Guide
## Purpose
The Santa Photo Order Form is used by event planners to collect information about a holiday event, including photo sessions and orders.

## How To Complete This Form

To complete this form, follow these steps:

1. Determine if the event is for event planners or not. Select "Yes" or "No" from the "Event Planner Forms" page.
2. Enter the name of the event.
3. Select the date and time of the event.
4. Enter the location of the event, including the address, city, state, and zip code.
5. Enter any additional photo session details, such as the name and details of the photo session.
6. Enter any additional photo order details, such as the order and any other photo sessions.
7. Review and submit the form.
