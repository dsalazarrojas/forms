# University Fair Registration Form - Help Guide
## Purpose
The purpose of this form is to collect details about university fairs and events, including event title, dates, venue, and contact information, to provide accurate and consistent data collection.

## How To Complete This Form

1. Fill out the required fields with accurate and relevant information about the event.
2. Select the appropriate event type and category from the provided options.
3. Enter the event start and end dates and times in the correct format (date and time fields).
4. Provide the event venue and location details.
5. Enter the contact information, including name, email, and phone number.

## Field-by-Field Explanation

* **Registration Form**: A text field where you can enter your name and/or university affiliation.
* **Event Details**: A text field where you can enter a brief description of the event.
* **Event Dates**: A date field where you can enter the start and end dates of the event.
* **Event Organizer**: A text field where you can enter the name of the event organizer.
* **Event Title**: A text field where you can enter the title of the event.
* **Event Description**: A text field where you can enter a brief description of the event.
* **Event Venue**: A text field where you can enter the location of the event.
* **Event Type**: A dropdown field where you can select the type of event (Yes/No).
* **Event Category**: A dropdown field where you can select the category of the event (Yes/No).
* **Event Start Date**: A date field where you can enter the start date of the event.
* **Event Start Time**: A time field where you can enter the start time of the event.
* **Event End Date**: A date field where you can enter the end date of the event.
* **Event End Time**: A time field where you can enter the end time of the event.
* **Event Location**: A text field where you can enter the location of the event.
* **Contact Name**: A text field where you can enter the name of the contact person.
* **Contact Email**: A email field where you can enter the email of the contact person.
* **Contact Phone**: A text field where you can enter the phone number of the contact person.
* **Additional Comments**: A text field where you can enter any additional comments or information about the event.
