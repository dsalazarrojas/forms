# ribbon_cutting_event_booking_form - Help Guide
## Purpose
The "Ribbon Cutting" event booking form is a tool used to gather essential information for planning and hosting a successful event. It is designed to be completed by the event host or a designated representative to provide accurate and detailed information about the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the event before starting the form.
2. Select the "Event Details" page and fill in the relevant information about the event, including the event name, location, and a brief description of the event.
3. Proceed to the "Event Date" and "Event Time" fields and enter the dates and times of the event.
4. In the "Location" field, provide the venue or venue address where the event will take place.
5. Enter the number of guests expected to attend the event in the "Number of Guests" field.
6. In the "Guest Details" field, provide any additional information about the guests, such as their names, ages, or any special requests.
7. Enter the event host's name in the "Event Host" field.
8. Enter the event host's phone number in the "Event Host Phone" field.
9. Enter the event host's email in the "Event Host Email" field.

## Field-by-Field Explanation

* **Event Details** (`event_details`, text, required): A brief description of the event. Be as detailed as possible to ensure the event planner can effectively communicate with your team.
* **Event Date** (`event_date`, date, required): The date of the event. Enter the date in the format `mm/dd/yyyy`.
* **Event Time** (`event_time`, time, required): The time of the event. Enter the time in the format `hh:mm AM/PM`.
* **Location** (`location`, text, required): The venue or address where the event will take place. Ensure to include the exact address or a description that will help the event planner locate the venue.
* **Event Name** (`event_name`, text, required): The name of the event. This will be displayed on promotional materials and communication with the team.
* **Number of Guests** (`number_of_guests`, number, required): The number of guests expected to attend the event. Enter the expected number of guests to help plan and prepare for the event.
* **Guest Details** (`guest_details`, text, required): Any additional information about the guests, such as their names, ages, or special requests. This field is optional, but providing detailed information will help the event planner accommodate any special needs.
* **Event Host** (`event_host`, text, required): The name of the event host. This will be the contact person for the event.
* **Event Host Phone** (`event_host_phone`, text, required): The phone number of the event host. This will allow the event planner to contact the host with any updates or questions.
* **Event Host Email** (`event_host_email`, email, required): The email address of the event host. This will be the primary contact method for the event planner.
