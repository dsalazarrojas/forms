# Group Registration Form - Help Guide
## Purpose
This form is for registering events for groups or teams. Please fill out the form carefully to provide the required information for the event.

## How To Complete This Form
To complete this form, simply fill out the fields as instructed below.

## Field-by-Field Explanation
- **First Name** (First name, text, optional): Enter the first name of the person registering the event.
- **Last Name** (Last name, text, optional): Enter the last name of the person registering the event.
- **Email** (Email, email, optional): Enter the email address of the person registering the event or the group's official email.
- **Phone** (Phone, text, optional): Enter the phone number of the person registering the event or the group's contact number.
- **Event Name** (Event Name, text, optional): Enter the name of the event, e.g., "Team Meeting".
- **Event Start Date** (Event Start Date, date, optional): Enter the start date of the event in the format YYYY-MM-DD.
- **Event Start Time** (Event Start Time, time, optional): Enter the start time of the event in the format HH:MM:SS.
- **Event End Date** (Event End Date, date, optional): Enter the end date of the event in the format YYYY-MM-DD.
- **Event End Time** (Event End Time, time, optional): Enter the end time of the event in the format HH:MM:SS.
- **Attendees** (Attendees, select multiple, optional): Indicate if the event will have attendees or not.
  - Select 'Yes' if the event is open to attendees.
  - Select 'No' if the event is not open to attendees.
- **Notes** (Notes, note, optional): Enter any additional information about the event, e.g., location, venue, and other relevant details.

## Tips
* Please fill out each field carefully to ensure accurate event registration.
* If you are unsure about any field, refer to the provided event details or contact the event organizer.
* Make sure to review the form thoroughly before submitting to avoid errors.
