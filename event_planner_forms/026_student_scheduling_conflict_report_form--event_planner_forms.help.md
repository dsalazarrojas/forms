# Student Scheduling Conflict Report Form - Help Guide
## Purpose
The Student Scheduling Conflict Report Form is designed to help students report and resolve potential scheduling conflicts with instructors or other students. This form is used to document and address conflicts that may arise due to overlapping schedules, conflicting availability, or other scheduling issues.
## How To Complete This Form
To complete this form, follow these steps:

1.  Click on the "Submit" button to start the form.
2.  Fill out the form with the required information.
3.  Select the correct date for the start and end of the conflict.
4.  Provide detailed description of the conflict in the "Conflict Details" field.
5.  Choose the resolution method for the conflict from the options provided.
6.  Select the status of the conflict resolution (optional).
7.  Enter the date and comment for the conflict resolution (optional).
8.  If the conflict resolution method is not listed, provide a detailed description in the "Conflict Resolution Method Other" field.
## Field-by-Field Explanation
* **Conflict Start Date** (`conflict_start_date`, date, required: false): Enter the date when the conflict started.
* **Conflict End Date** (`conflict_end_date`, date, required: false): Enter the date when the conflict ended.
* **Conflict Details** (`conflict_details`, text, required: false): Provide a detailed description of the conflict, including any relevant dates, times, and locations.
* **Conflict Resolution Method** (`conflict_resolution_method`, select_one, required: false): Choose from the following options:
	+ Value 1: Select one of the provided options as the resolution method.
	+ Value 2: Select one of the provided options as the resolution method.
	+ Value 3: Select one of the provided options as the resolution method.
* **Conflict Resolution Status** (`conflict_resolution_status`, select_multiple, required: false): Choose from the following options (multiple selections allowed):
	+ Status 1: Select one of the provided status options.
	+ Status 2: Select one of the provided status options.
	+ Status 3: Select one of the provided status options.
* **Conflict Resolution Date** (`conflict_resolution_date`, date, required: false): Enter the date of the conflict resolution.
* **Conflict Resolution Comment** (`conflict_resolution_comment`, text, required: false): Enter a comment about the conflict resolution (optional).
* **Conflict Resolution Method Other** (`conflict_resolution_method_other`, text, required: false): If the conflict resolution method is not listed, provide a detailed description in this field.
Tips: 

This form is designed to help students and instructors resolve conflicts in a efficient and organized manner. By providing detailed information, students can better understand and address scheduling conflicts, reducing misunderstandings and miscommunications. Make sure to fill out the form accurately and thoroughly to help resolve the conflict effectively.
