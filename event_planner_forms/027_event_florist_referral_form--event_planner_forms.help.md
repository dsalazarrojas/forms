# Event Florist Referral Form - Help Guide
## Purpose
This form is designed to help event planners find suitable vendors for their events by gathering essential details.

## How To Complete This Form
To complete this form successfully:

1.  Fill out the form with as much information as possible, especially for fields marked as required.
2.  Make sure to select the correct options for event type and vendor type.
3.  If you have any additional notes or comments, use the "Submission Notes" field.

## Field-by-Field Explanation

* **Event Details** (`event_details_1`, text, optional): This field is for a brief description of the event. Provide as much information as possible.
* **Wedding Venue** (`wedding_vendor_1`, select_one, optional): Select "Yes" if the event is a wedding, "No" otherwise. 
* **Corporate Venue** (`corporate_vendor_1`, select_one, optional): Select "Good" if the event is corporate, "Fair" otherwise. 
* **Partnered Venue** (`partner_vendor_1`, select_one, optional): Select "Yes" if the event is partnered, "No" otherwise.
* **Event Type** (`event_type_1`, select_one, optional): Choose the type of event you are referring: Wedding, Corporate, or Other.
* **Event Type 2** (`event_type_2`, select_one, optional): This is a duplicate field of "Event Type" and will not affect the referral process.
* **Event Date 1** (`event_date_1`, date, optional): Enter the date of the event, if known. 
* **Event Date 2** (`event_date_2`, date, optional): This field is a duplicate of "Event Date 1" and will not affect the referral process.
* **Event Time** (`event_time_1`, time, optional): Enter the start time of the event, if known. 
* **Event Time 2** (`event_time_2`, time, optional): This field is a duplicate of "Event Time" and will not affect the referral process.
* **Vendor Name** (`vendor_name_1`, text, optional): This is the name of the vendor you are referring, if you have one. 
* **Vendor Contact** (`vendor_contact_1`, text, optional): Enter the contact person's name or name of the event planner.
* **Vendor Email** (`vendor_email_1`, email, optional): Enter the contact email, if known. 
* **Vendor Phone** (`vendor_phone_1`, text, optional): Enter the contact phone number, if known. 
* **Vendor Address** (`vendor_address_1`, text, optional): Enter the vendor's address, if known.
* **Vendor Description** (`vendor_description_1`, text, optional): Brief description of the vendor's services or features. 
* **Vendor Image** (`vendor_image_1`, text, optional): Upload or enter a URL to the vendor's image.
* **Event Location** (`event_location_1`, text, optional): Enter the event location or venue name. 
* **Event Location 2** (`event_location_2`, text, optional): This field is a duplicate of "Event Location" and will not affect the referral process.
* **Event URL** (`event_url_1`, text, optional): Enter the event's URL or website.
* **Event Url 2** (`event_url_2`, text, optional): This field is a duplicate of "Event URL" and will not affect the referral process.
* **Referral Fee** (`vendor_referral_fee_1`, number, optional): Enter the referral fee, if applicable. 
* **Vendor Referral Fee 2** (`vendor_referral_fee_2`, number, optional): This field is a duplicate of "Referral Fee" and will not affect the referral process.
* **Submission Notes** (`submission_notes_1`, note, optional): Add any additional notes or comments for the vendor referral.
