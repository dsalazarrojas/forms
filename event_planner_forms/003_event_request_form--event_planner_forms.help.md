# Event Request Form - Help Guide
## Purpose
The Event Request Form is designed to gather information for event planning and execution. This form helps the organizers or administrators to process event requests in a structured and organized manner.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Input the title of the event.
2. Select the date of the event using the date picker.
3. Select the time of the event using the time picker.
4. Provide the location of the event.
5. Enter the event organizer's name and contact information.

## Field-by-Field Explanation
* **Event Request Form** (1): Enter the title of the event, such as "Annual Company Meeting" or "Summer Festival".
* **Event Date (2)**: Select the date of the event. This field is used to determine the event schedule. Please use the date picker to select the correct date.
* **Event Time (3)**: Choose the time of the event. This field is used to schedule the event accordingly. Please use the time picker to select the correct time.
* **Event Location (4)**: Enter the address or venue of the event. This field is used to identify the location where the event will take place.
* **Event Organizer (5)**: Provide the name and contact information of the event organizer, including their name, email, and phone number. This field is crucial for communication and follow-up purposes.

## Tips
* Please make sure to provide accurate and relevant information for the event details.
* If you have any doubts or questions about the form, please don't hesitate to contact us.
* This form is for internal use only, and the information collected will be processed and reviewed by the event organizers or administrators.
