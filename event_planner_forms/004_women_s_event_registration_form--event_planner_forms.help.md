The "Women's Event Registration Form" is for users to provide information about themselves in order to be registered for an event organized for women. This form is not meant to be completed by men, so please ensure that you are a woman before proceeding. If you're not sure or have already registered for this event, please don't fill out this form.

# Women's Event Registration Form - Help Guide

## Purpose
This form is for women to register for an event.

## How To Complete This Form

1. Make sure you are a woman.
2. Fill out the form with the required information (marked as "required" in the form):
	* First Name
	* Last Name
	* Email
	* Phone (optional)
3. Provide the date you plan to attend the event.
4. Provide a time you plan to attend the event.
5. If you have any specific event details, such as a particular event name or assigned tool, you can provide that information.
6. If you would like to download the output file of your registration, provide a file path.

## Field-by-Field Explanation

* **First Name** (`first_name`, text, required): Please enter your first name as it appears on your official documents.
* **Last Name** (`last_name`, text, required): Please enter your last name as it appears on your official documents.
* **Email** (`email`, email, required): Enter your contact email address.
* **Phone** (`phone`, text, optional): If you have a phone number, you can provide it.
* **Date** (`date`, date, required): Select or enter the date you plan to attend the event (mm/dd/yyyy).
* **Time** (`time`, time, required): Select or enter the time you plan to attend the event (HH:MM).
* **Event** (`event`, text, optional): If you want to specify which event you are registering for, you can provide the name of the event.
* **Assigned Tool** (`assigned_tool`, text, optional): If you have been assigned a specific tool for the event, you can provide its name.
* **Output File** (`output_file`, text, optional): If you would like to download the output file of your registration, provide the file path.

## Tips

* Please make sure to double-check your information before submitting the form.
* If you encounter any issues or need assistance, contact the event organizers.
* If you are already registered for this event, you do not need to fill out this form again.
* If you are a man, you are not eligible to register for this event, so please do not attempt to fill out this form.
