# Boxed Lunch Order Form - Help Guide
## Purpose
This form is used to order a batch of lunches for an event. It captures necessary contact and event details, as well as menu preferences to fulfill the order.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the contact information: Please provide your name, email address, and phone number. This is necessary for order confirmation and any future communication.
2. Specify the event details: Choose the event date when lunches are needed.
3. Select delivery options: Pick a preferred delivery time and location.
4. Order the lunches: Enter the total number of lunches needed and select the lunch package type, sandwich preference, bread type preference, and beverage preference.
5. Add any special requests or notes: If there are any specific dietary restrictions or special requests, add them here.
6. Set a budget: Select the approximate budget per lunch.
7. Confirm the order: Check the "Confirmed" option to submit the order.

## Field-by-Field Explanation

* **Contact Name**: Enter the name of the person placing the order.
* **Email Address**: Enter the email address where you can be reached for order confirmation and updates.
* **Phone Number**: Enter your phone number for quick contact.
* **Company or Organization**: Enter the name of the entity ordering the lunches (optional).
* **Event Date**: Choose the date when lunches are needed for the event.
* **Preferred Delivery Time**: Select the time when lunches should be delivered.
* **Delivery Location**: Enter the address where lunches should be delivered.
* **Total Number of Lunches**: Enter the total number of lunches needed for the event.
* **Lunch Package Type**: Choose the type of lunch package to be ordered (e.g., Classic, Deluxe, Vegetarian).
* **Sandwich Preference**: Select the primary protein option for the sandwich (e.g., Turkey, Roast Beef, Chicken).
* **Bread Type Preference**: Choose the type of bread for the sandwich (e.g., White, Wheat, Rye).
* **Side Dish Options**: Select any side dishes to be included with the lunch (e.g., Chips, Fruit salad, Veggie platter).
* **Beverage Preference**: Choose the drink option for the lunch (e.g., Water, Iced tea, Lemonade).
* **Special Dietary Restrictions**: Select any special dietary restrictions (e.g., Gluten-free, Dairy-free, Vegan).
* **Special Requests or Notes**: Add any additional information or requests for the order.
* **Budget Per Lunch**: Select the approximate budget per lunch.
* **I confirm this lunch order**: Check the "Confirmed" option to submit the order and complete the form.
