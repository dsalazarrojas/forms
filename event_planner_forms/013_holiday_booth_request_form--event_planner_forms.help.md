# Holiday Booth Request Form - Help Guide
## Purpose
The Holiday Booth Request Form is a tool used to collect and track requests for holiday events. This form is designed to ensure that all necessary information is collected in a structured and efficient manner, helping to streamline the event planning process.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select the correct options for each field, as indicated in the Field-by-Field Explanation section.

## Field-by-Field Explanation

* **Event Title/Description** (`event_planner_form_1`, `text`, required: false): This field is where you can enter a brief title and description of the event. This information will be used to identify and categorize the event.
* **Event Type** (`event_planner_form_2`, `select_one`, required: false): Select one option to indicate the type of event. This helps ensure that the event is properly categorized and prioritized.
* **Event Space** (`event_planner_form_3`, `select_one`, required: false): Select one option to indicate the space requirements for the event. This information will help with venue selection and setup.
* **Event Contact** (`event_planner_form_4`, `text`, required: false): Enter the contact information for the event, such as a name and phone number.
* **Event Phone** (`event_planner_form_5`, `text`, required: false): Enter the phone number for the event contact.
* **Event Email** (`event_planner_form_6`, `email`, required: false): Enter the email address for the event contact.
* **Event Priority** (`event_planner_form_7`, `select_one`, required: false): Select one option to indicate the event priority. This information will help with scheduling and resource allocation.
* **Event Category** (`event_planner_form_8`, `select_one`, required: false): Select one option to indicate the category of the event. This information will help with categorization and reporting.
* **Event Status** (`event_planner_form_9`, `select_one`, required: false): Select one option to indicate the status of the event. This information will help with monitoring and reporting.
* **Event Location** (`event_planner_form_10`, `select_one`, required: false): Select one option to indicate the location of the event. This information will help with logistics and venue selection.
* **Event Team** (`event_planner_form_11`, `select_one`, required: false): Select one option to indicate if the event has a team. This information will help with team coordination and resource allocation.
* **Event Notes** (`event_planner_form_12`, `text`, required: false): Enter any additional notes or comments about the event.
* **Event Date** (`event_planner_form_13`, `date`, required: false): Select a date for the event.
* **Event Time** (`event_planner_form_14`, `time`, required: false): Select a time for the event.

## Tips
* Double-check all fields for accuracy before submitting the form.
* Make sure to select the correct options for each field to ensure proper event categorization and prioritization.
* Use clear and concise language when filling out the "Event Notes" field.
* If you have any questions or concerns, please contact the event planner for assistance.
