# Vote Exam Date Flat Color - Help Guide
## Purpose
This form is used to create a flat color scheme for exam dates. It allows you to select the exam date, color scheme, and other background settings for a visually appealing exam layout.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the exam date using the date field.
2. Choose the color scheme from the provided options.
3. Select the majority choice(s) by choosing the desired color.
4. Enter the majority percentage (optional).
5. Select the form background color from the provided options.
6. Upload a background image (optional).
7. Decide on the background repeat and position.
8. Choose the background size.

## Field-by-Field Explanation
* **Exam Date** (`vote_exam_date_flat_color_date`, `date`, required/optional): Select the exam date for which you want to configure the flat color scheme.
* **Color Scheme** (`vote_exam_date_flat_color_color_scheme`, `select_one`, required/optional): Choose the color scheme from the provided options:
	+ Red
	+ Blue
	+ Green
* **Majority Choice** (`vote_exam_date_flat_color_majority_choice`, `select_multiple`, required/optional): Select the majority choice by choosing one or more colors.
* **Majority Percentage** (`vote_exam_date_flat_color_majority_percentage`, `number`, required/optional): Enter the majority percentage (between 0 and 1).
* **Percentage** (`vote_exam_date_flat_color_majority_percentage_percentage`, `text`, required/optional): This field is for entering the percentage value.
* **Form Background Color** (`vote_exam_date_flat_color_form_background_color`, `select_one`, required/optional): Choose the background color from the provided options:
	+ Flat
	+ Colorful
* **Background Image** (`vote_exam_date_flat_color_background_image`, `text`, required/optional): Upload a background image.
* **Background Repeat** (`vote_exam_date_flat_color_background_repeat`, `select_multiple`, required/optional): Decide on the background repeat:
	+ 'True'
	+ 'False'
* **Background Position** (`vote_exam_date_flat_color_background_position`, `select_multiple`, required/optional): Choose the background position:
	+ Center
	+ Top Left
	+ Bottom Right
* **Background Size** (`vote_exam_date_flat_color_background_size`, `select_multiple`, required/optional): Choose the background size:
	+ 10%
	+ 50%
	+ 100%

## Tips

* Make sure to select the correct exam date.
* Choose a color scheme that suits your exam needs.
* Be cautious when entering the majority percentage value.
* Ensure you upload a suitable background image (if necessary).
* Be mindful of the background repeat and position settings.
* Choose the correct background size for your exam layout.
