# holiday_gift_sign_up_form - Help Guide
## Purpose
The holiday gift sign-up form is used to collect information from users to help manage holiday gift-giving processes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your first name in the "First Name" field.
2. Enter your last name in the "Last Name" field.
3. Provide your email address in the "Email" field.
4. Enter your phone number in the "Phone" field.
5. Select a gift choice from the options provided in the "Gift Choice" field.
6. Type or write a message in the "Message" field, if desired.
7. Enter the value of the gift in the "Gift Value" field.
8. Choose the date of the event from the calendar in the "Event Date" field.
9. Select the type of gift you would like to receive from the options provided in the "Gift Type" field.
10. If applicable, choose the tools that will be assigned to you from the options provided in the "Assigned Tool" field.
11. Select the categories that you would like to be associated with from the options provided in the "Category" fields.
12. Type any additional information or description about yourself in the "Description" field, if desired.

## Field-by-Field Explanation
* **First Name** (text): Enter your first name to help us get to know you better.
* **Last Name** (text): Enter your last name to help us get to know you better.
* **Email** (email): Enter your email address so we can contact you.
* **Phone** (text): Enter your phone number so we can reach you.
* **Gift Choice** (select_one): Choose a gift you would like to receive, such as a Gift Card.
* **Message** (note): Type any personal message or notes you'd like to include.
* **Gift Value** (number): Enter the value of the gift you would like to receive.
* **Event Date** (date): Choose the date of the event associated with this gift.
* **Gift Type** (select_one): Choose the type of gift you would like to receive, such as a Gift Card or Cash.
* **Assigned Tool** (text): If you have a specific tool assigned to you, enter its name here.
* **Category** (select_multiple): Select categories you would like to be associated with.
* **Category 2** (select_multiple): Select categories you would like to be associated with (note: this field is similar to "Category" and allows for additional selection).
* **Description** (note): Enter any additional information or description about yourself.

Note: This form is designed to be completed by individual users, and the fields are self-explanatory and easy to understand. If you have any questions or concerns, please don't hesitate to contact us.
