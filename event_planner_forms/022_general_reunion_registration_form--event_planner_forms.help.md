# General Reunion Registration Form - Help Guide
## Purpose
The General Reunion Registration Form is designed for event planners to collect information about upcoming reunions. This form helps to gather details about the event name, date, time, location, and attendees. Fill out this form to provide necessary information for planning and execution of a successful reunion.

## How To Complete This Form
1. **Fill out the form in sections**: Divide your response into the individual pages of the form.
2. **Enter the required information**: Make sure to complete all required fields, which are indicated by an asterisk (\*) in the label.
3. **Fill in the details**: Enter the event name, date, and description in the respective fields.
4. **Choose options for attendees**: Select all the attendees that will be attending the reunion from the provided options.
5. **Choose the reunion location**: Select the correct location for the reunion from the provided options.
6. **Add a note (optional)**: If you have any further information or notes about the event, you can add them in the text box.
7. **Enter contact information (optional)**: If you want to be contacted about the event, you can enter your email and phone number.

## Field-by-Field Explanation
* **Reunion Name** (1, text, required): Enter the name of the reunion.
* **Reunion Date** (2, date, optional): Enter the date of the reunion in the correct format (mm/dd/yyyy).
* **Reunion Time** (3, time, optional): Enter the time of the reunion in the correct format (hh:mm).
* **Reunion Description** (4, text, optional): Enter a brief description of the reunion.
* **Attendees Count** (5, number, optional): Enter the number of attendees expected.
* **Attendee Names** (6, select multiple, required): Select all the attendees that will be attending the reunion from the provided options.
* **Reunion Location** (7, select one, optional): Select the location of the reunion from the provided options.
* **Note** (8, note, optional): Enter any additional notes about the event.
* **Email** (9, email, optional): Enter your email address so that you can be contacted about the event.
* **Phone** (10, text, optional): Enter your phone number so that you can be contacted about the event.
