# Waiver Request Form - Help Guide
## Purpose

The Waiver Request Form is used to track and manage waiver requests for a construction project. This form is used to collect information about the project start date, department, employees involved, manager, and waiver status.

## How To Complete This Form

1. Select the "Waiver Request" option to indicate whether or not the waiver is requested.
2. Enter the "Project Start Date" of the construction project.
3. Enter the department involved in the waiver request.
4. Select the number of employees involved in the waiver request.
5. Select the manager involved in the waiver request.
6. Enter the name of the construction company.
7. Select the status of the waiver signed (yes or no).
8. Select the status of the waiver approved (yes or no).
9. Select the status of the waiver request (active or inactive).
10. Enter any additional comments about the waiver request.
11. Enter the status of the waiver request date.
12. Enter the name of the person who submitted the waiver request form.
13. Enter the date the waiver request form was submitted.
14. Enter the time the waiver request form was submitted.
15. Enter the IP address of the person who submitted the waiver request form.
16. Enter the country where the waiver request form was submitted.
17. Enter the city where the waiver request form was submitted.
18. Enter the state where the waiver request form was submitted.
19. Enter the browser used to submit the waiver request form.

## Field-by-Field Explanation

* **Waiver Request** (`waiver_request_form`): This field indicates whether or not a waiver is requested.
* **Project Start Date** (`project_start_date`): This field is used to enter the project start date.
* **Department** (`department`): This field is used to enter the department involved in the waiver request.
* **Employees** (`employees`): This field is used to select the number of employees involved in the waiver request.
* **Manager** (`manager`): This field is used to select the manager involved in the waiver request.
* **Construction Company** (`construction_company`): This field is used to enter the name of the construction company.
* **Waiver Signed** (`waiver_signed`): This field is used to select the status of the waiver signed (yes or no).
* **Waiver Signed Date** (`waiver_signed_date`): This field is used to enter the date the waiver was signed.
* **Waiver Signed By** (`waiver_signed_by`): This field is used to enter the name of the person who signed the waiver.
* **Waiver Signed Status** (`waiver_signed_status`): This field is used to select the status of the waiver signed (active or inactive).
* **Waiver Approved** (`waiver_approved`): This field is used to select the status of the waiver approved (yes or no).
* **Waiver Approved Date** (`waiver_approved_date`): This field is used to enter the date the waiver was approved.
* **Waiver Approved By** (`waiver_approved_by`): This field is used to enter the name of the person who approved the waiver.
* **Waiver Approved Status** (`waiver_approved_status`): This field is used to select the status of the waiver approved (active or inactive).
* **Waiver Request Status** (`waiver_request_status`): This field is used to select the status of the waiver request (active or inactive).
* **Notes** (`notes`): This field is used to enter any additional comments about the waiver request.
* **Waiver Request Form Comments** (`waiver_request_form_comments`): This field is used to enter any additional comments about the waiver request form.
* **Waiver Request Status Date** (`waiver_request_status_date`): This field is used to enter the status date of the waiver request.
* **Waiver Request Form Submitted By** (`waiver_request_form_submitted_by`): This field is used to enter the name of the person who submitted the waiver request form.
* **Waiver Request Form Submitted Date** (`waiver_request_form_submitted_date`): This field is used to enter the date the waiver request form was submitted.
* **Waiver Request Form Submitted Time** (`waiver_request_form_submitted_time`): This field is used to enter the time the waiver request form was submitted.
* **Waiver Request Form Submitted IP** (`waiver_request_form_submitted_ip`): This field is used to enter the IP address of the person who submitted the waiver request form.
* **Waiver Request Form Submitted Country** (`waiver_request_form_submitted_country`): This field is used to enter the country where the waiver request form was submitted.
* **Waiver Request Form Submitted City** (`waiver_request_form_submitted_city`): This field is used to enter the city where the waiver request form was submitted.
* **Waiver Request Form Submitted State** (`waiver_request_form_submitted_state`): This field is used to enter the state where the waiver request form was submitted.
* **Waiver Request Form Submitted Browser** (`waiver_request_form_submitted_browser`): This field is used to enter the browser used to submit the waiver request form.
