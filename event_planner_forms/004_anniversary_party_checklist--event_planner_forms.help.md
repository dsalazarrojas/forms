# Anniversary Party Checklist - Help Guide
## Purpose
This form is designed to help event planners and organizers gather and track essential information for a memorable anniversary celebration. It covers various aspects of event planning, including logistics, arrangements, and tasks.

## How To Complete This Form
To complete the form, follow these steps:

1. Provide the **Event Planner Name**, who is responsible for organizing the event.
2. Enter the **Email Address** of the event planner for contact purposes.
3. Enter the **Phone Number** of the event planner for easy contact.
4. Select the type of **Anniversary** being celebrated (e.g., Wedding Anniversary, Business/Corporate Anniversary).
5. Specify the **Anniversary Milestone**, if applicable (e.g., 1st anniversary, 10-year anniversary).
6. Choose a **Event Date**, when the celebration will take place.
7. Set the **Event Start Time**.
8. Enter the **Venue Name**, where the event will be held.
9. Confirm if the **Venue has been booked and confirmed**.
10. Check if the **Guest List is complete**.
11. Enter the **Estimated Guest Count**.
12. Confirm if **invitations have been sent**.
13. Choose if **catering has been arranged**.
14. Select if the **menu is finalized with the caterer**.
15. Confirm if **the anniversary cake has been ordered**.
16. Select the **decorations planned** (e.g., Balloons, Banners, Flowers).
17. Choose if **entertainment has been booked** (e.g., DJ, Live Band, Playlist).
18. Select if **photography and videography will be documented**.
19. Choose if **drinks have been arranged** (e.g., Full Bar, Beer and Wine Only, Non-Alcoholic Only).
20. Confirm if **transportation has been arranged**.
21. Select if **party favors have been prepared**.
22. Choose the **budget tracking status** (e.g., On Track, Slightly Over, Significantly Over, Under Budget).
23. Enter the **Day-of Coordinator's Name**, if assigned.
24. Confirm if a **contingency plan is ready**.
25. Add any **additional notes or reminders**.

## Field-by-Field Explanation

* **Event Planner Name (planner_name)**: Enter the name of the person organizing the event.
* **Email Address (email)**: Enter the email address of the event planner for contact purposes.
* **Phone Number (phone)**: Enter the phone number of the event planner for easy contact.
* **Anniversary Type (anniversary_type)**: Select the type of anniversary being celebrated (e.g., Wedding Anniversary, Business/Corporate Anniversary).
* **Anniversary Milestone (anniversary_milestone)**: Specify the anniversary milestone, if applicable (e.g., 1st anniversary, 10-year anniversary).
* **Event Date (event_date)**: Choose the date of the celebration.
* **Event Start Time (event_time)**: Set the start time of the event.
* **Venue Name (venue_name)**: Enter the name of the venue where the event will be held.
* **Venue Booked and Confirmed (venue_booked)**: Confirm if the venue has been booked and confirmed.
* **Guest List Complete (guest_list_complete)**: Check if the guest list is complete.
* **Estimated Guest Count (estimated_guest_count)**: Enter the estimated number of attendees.
* **Invitations Sent (invitations_sent)**: Confirm if invitations have been sent.
* **Catering Selected (catering_selected)**: Choose if catering has been arranged.
* **Menu Finalized (menu_finalized)**: Select if the menu is finalized with the caterer.
* **Anniversary Cake Ordered (cake_ordered)**: Confirm if the anniversary cake has been ordered.
* **Decorations Planned (decorations_planned)**: Select the type of decorations planned (e.g., Balloons, Banners, Flowers).
* **Entertainment Booked (entertainment_booked)**: Choose if entertainment has been booked.
* **Photography and Videography (photographer_videographer)**: Select if photography and videography will be documented.
* **Beverages Arranged (beverages_arranged)**: Choose if drinks have been arranged (e.g., Full Bar, Beer and Wine Only, Non-Alcoholic Only).
* **Transportation Arranged (transportation_arranged)**: Confirm if transportation has been arranged.
* **Party Favors Prepared (favors_prepared)**: Select if party favors have been prepared.
* **Budget Status (budget_tracking)**: Choose the budget tracking status (e.g., On Track, Slightly Over, Significantly Over, Under Budget).
* **Day-of Coordinator (day_of_coordinator)**: Enter the name of the day-of coordinator, if assigned.
* **Contingency Plan Ready (contingency_plan)**: Confirm if a contingency plan is ready.
* **Additional Notes (additional_notes)**: Enter any additional notes or reminders.
