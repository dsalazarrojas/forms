# Friendsgiving Potluck Invitation Form - Help Guide
## Purpose
This form is designed to collect information from guests who are invited to a Friendsgiving potluck event. Please fill out this form to help us better understand who is coming and what dishes to expect.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your **Name**, which is your full name as you'd like to be addressed.
2. Enter your **Email**, which will be used to contact you with event updates.
3. Enter your **Phone number**, which will only be used in case we need to reach you directly.
4. Select a date and time for the event. Please ensure this is accurate, as it will help us plan the potluck.
5. Enter the **Address** where the event will take place. This is not a required field, but it helps us understand where you will be bringing your dish.
6. Add a brief **Note** about yourself, which can help us get to know you better.
7. Choose what dish you will be bringing, in the **Food** field.
8. Select which options you are **Attending**. Please only choose options that apply to you.
9. If applicable, enter the category and/or assigned tool you have been assigned to bring, in the **Category** and **Assigned Tool** fields.
10. Finally, enter a file name for the output file, in the **Output File** field.
11. Enter a unique **Form ID**, which is used to identify your entry in the system.

## Field-by-Field Explanation

* **Name** (text, required): Enter your full name as you'd like to be addressed.
* **Email** (email, required): Enter your email address, which will be used to contact you with event updates.
* **Phone** (text, required): Enter your phone number, which will only be used in case we need to reach you directly.
* **Date** (date, required): Select a date for the event. This must be accurate, as it will help us plan the potluck.
* **Time** (time, required): Select a time for the event. This must be accurate, as it will help us plan the potluck.
* **Address** (text, optional): Enter the address where the event will take place. This is not a required field, but it helps us understand where you will be bringing your dish.
* **Note** (note, optional): Add a brief note about yourself, which can help us get to know you better.
* **Food** (text, required): Enter the dish you will be bringing. Please be as specific as possible, as this helps us plan the potluck.
* **Attending** (select_multiple, required): Select which options apply to you. Please only choose options that are true for you.
* **options_1**, **options_2**, **options_3** (text, optional): Enter any additional information for these optional fields.
* **Category** (text, required): Enter the category you have been assigned to bring. If you're unsure, please ask your host.
* **Assigned Tool** (text, required): Enter the tool you have been assigned to bring, if applicable.
* **Output File** (text, required): Enter a file name for the output file. This will be used to store your entry in the system.
* **Form ID** (text, required): Enter a unique ID for your entry. This is used to identify your entry in the system.
