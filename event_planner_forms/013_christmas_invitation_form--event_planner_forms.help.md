# Christmas Invitation Form - Help Guide
## Purpose
The Christmas Invitation Form is a tool for event planners to collect essential information about a Christmas celebration. This form helps hosts gather details about their event, including contact information, event specifics, and RSVP requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the host's contact information: 
	* Host Full Name: Enter your first and last name.
	* Email Address: Enter a valid email address for RSVP responses.
	* Phone Number: Enter your phone number for guest inquiries.
2. Event Details:
	* Event Title: Enter the name of your Christmas event.
	* Event Type: Select the type of celebration (e.g., Office Party, Family Gathering, etc.).
	* Event Date: Enter the date of the event.
	* Start Time: Enter the start time of the event.
3. Venue Information:
	* Venue Name: Enter the name of the venue.
	* Venue Address: Enter the full street address of the venue.
4. Event Settings:
	* Dress Code: Choose a dress code for guests (e.g., Casual, Smart Casual, etc.).
	* Meal Provided: Choose whether food will be served or not.
5. RSVP and Guest Information:
	* RSVP Deadline: Enter the date by which guests must respond.
	* Plus One Allowed: Choose if guests can bring someone.
	* Children Welcome: Choose if children are welcome.
6. Gift Expectations:
	* Gift Expectations: Choose if guests should bring gifts.
7. Special Requests:
	* Special Requests: Enter any dietary needs or accommodations.

## Field-by-Field Explanation
* **Host Full Name** (1, text, required): Enter your first and last name.
* **Email Address** (2, email, required): Enter a valid email address for RSVP responses.
* **Phone Number** (3, text, required): Enter your phone number for guest inquiries.
* **Organization or Company** (4, text, optional): If hosting on behalf of a group, enter the name of the organization or company.
* **Event Title** (6, text, required): Enter the name of your Christmas event.
* **Event Type** (7, select_one, required): Select the type of celebration (e.g., Office Party, Family Gathering, etc.).
* **Event Date** (8, date, required): Enter the date of the event.
* **Start Time** (9, time, required): Enter the start time of the event.
* **End Time** (10, time, optional): Enter the end time of the event (if applicable).
* **Venue Name** (12, text, required): Enter the name of the venue.
* **Venue Address** (13, text, required): Enter the full street address of the venue.
* **City** (14, text, required): Enter the city of the event.
* **Postal Code** (15, text, required): Enter the postal code or zip code of the venue.
* **Virtual Attendance Option** (16, select_one, required): Choose if there will be online access or not.
* **Dress Code** (18, select_one, required): Choose a dress code for guests (e.g., Casual, Smart Casual, etc.).
* **Meal Provided** (19, select_one, required): Choose if food will be served or not.
* **RSVP Deadline** (20, date, required): Enter the date by which guests must respond.
* **Plus One Allowed** (22, select_one, required): Choose if guests can bring someone.
* **Children Welcome** (23, select_one, required): Choose if children are welcome.
* **Gift Expectations** (24, select_one, required): Choose if guests should bring gifts.
* **Special Requests** (25, text, optional): Enter any dietary needs or accommodations.
* **Personal Message** (26, text, optional): Add a personal message to guests.
* **Parking Information** (27, text, optional): Enter instructions for guests.
* **Host Information** (5, note, optional): Enter additional host information (if necessary).
* **Event Details** (11, note, optional): Enter additional event details (if necessary).
* **RSVP Information** (21, note, optional): Enter additional RSVP information (if necessary).
* **Dress Code** (Note: this field is redundant, use the corresponding select_one field)
