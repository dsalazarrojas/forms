# Post Program Feedback Form - Help Guide

## Purpose
The Post Program Feedback Form is used to collect feedback from participants after a program has been completed. This form helps us understand the participant's experience and overall rating of the program. It also allows us to track follow-up activities and next steps for future engagement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the title of the program you are providing feedback on in the **Form Title** field.
2. Enter your name and email address in the **Participant Name** and **Participant Email** fields, respectively.
3. Enter the program ID number in the **Program ID** field.
4. In the **Overall Rating** field, select one of the following options:
	* Excellent
	* Good
	* Fair
	* Poor
5. For each option selected in the **Rating Reasons** field, select one or more reasons why you rated the program well.
6. Enter any additional comments or feedback in the **Additional Comments** field.
7. If you would like to receive follow-up on your feedback, select **Yes** in the **Follow-up** field and complete the following fields:
	* **Follow-up Method**: Select how you would like to be contacted for follow-up (Email or Phone).
	* **Follow-up Info**: Enter any necessary information for the follow-up.
	* **Follow-up Message**: Enter a message to be sent to you for follow-up.
	* **Follow-up Date**: Enter the date for the follow-up.
	* **Follow-up Time**: Enter the time for the follow-up.
	* **Follow-up Frequency**: Select how often you would like to be contacted for follow-up (Daily, Weekly, or Monthly).
	* **Follow-up Status**: Select the status of the follow-up (In progress or Complete).
	* **Follow-up Comments**: Enter any comments for the follow-up.
	* **Follow-up Details**: Enter any additional details for the follow-up.
	* **Follow-up Next Step**: Enter the next step for the follow-up.
	* **Follow-up Next Step Info**: Enter any additional information for the follow-up next step.
	* **Follow-up Next Step Date**: Enter the date for the follow-up next step.
	* **Follow-up Next Step Time**: Enter the time for the follow-up next step.
