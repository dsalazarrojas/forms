# easter balloons order form - Help Guide
## Purpose
This form is a tool for customers to place orders for Easter balloons. It helps customers to specify the type of balloons they want to order, the date for which they want to have the balloons, and provides an option for them to enter any additional comments or information.

## How To Complete This Form
1. Click on the "easter balloons order" field to select the type of balloon order you would like to place. You can choose from balloons, eggs, or baskets.
2. If you want to be more specific about the balloons, click on the "balloon type" field and select from latex, mylar, or foil.
3. In the "order date" field, enter the date you would like to have your balloons delivered.
4. If you would like to specify a pick up time, enter it in the "pick up time" field.
5. Enter your email address in the "customer email" field.
6. Enter your phone number in the "customer phone" field.
7. If you have any additional comments or information, enter them in the "comments" field.

## Field-by-Field Explanation
* **Easter Balloons Order** (`easter_balloons_order_form`): This is the main section of the form where you can select the type of balloon order you want to place.
* **Easter Balloons** (`easter_balloons_order`): Select the type of balloon order you want, which can be balloons, eggs, or baskets.
* **Balloon Type** (`balloon_type`): If you've selected balloons, you can be more specific about the type of balloon you want, which can be latex, mylar, or foil.
* **Order Date** (`order_date`): Enter the date you would like to have your balloons delivered.
* **Pick Up Time** (`pick_up_time`): Enter the time you would like to pick up your balloons.
* **Customer Email** (`customer_email`): Enter your email address.
* **Customer Phone** (`customer_phone`): Enter your phone number.
* **Comments** (`comments`): Enter any additional comments or information you have about your order. 
* **Form ID** (`form_id`), **Form Title** (`form_title`), **Form Description** (`form_description`), **Form Status** (`form_status`), **Form Published** (`form_published`), **Form Deleted At** (`form_deleted_at`), **Form Archived At** (`form_archived_at`), **Form Assigned To** (`form_assigned_to`), **Form Tags** (`form_tags`), **Form Comments** (`form_comments`), **Form Views** (`form_views`), **Form Submissions** (`form_submissions`), **Form Total Submissions** (`form_total_submissions`), **Form Created By** (`form_created_by`): These are internal metadata fields that are not intended for end-user input.
