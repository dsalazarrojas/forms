# thanksgiving_potluck_survey - Help Guide
## Purpose
This form is designed to collect information from attendees of a Thanksgiving potluck event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Main Info** field with a brief description of the event and the dish you are bringing.
2. Enter your **Name** in the corresponding field.
3. Enter the **Name of Host** in the corresponding field.
4. If you have an **Email** address, enter it in the corresponding field. This is an optional field.
5. If you have a **Phone** number, enter it in the corresponding field. This is an optional field.
6. Select the **Event Date** from the calendar or enter the date in the format MM/DD/YYYY.
7. Select the **Event Time** in the format HH:MM AM/PM.
8. Enter the **Event Location** where the event will take place.
9. Enter the number of **Guests** you are planning to bring for in the corresponding field.
10. In the **Dish to be Brought** field, enter a description of the dish you are bringing.
11. In the **Name of Dish Brought** field, enter the name of the dish you are bringing.
12. Select the type of **Main Course** from the options provided.
13. Select the type(s) of **Side Dish** from the options provided.
14. If you are bringing a **Dessert**, select the type from the options provided. If not, leave it blank.
15. In the **Comments** field, enter any additional comments or information about the dish you are bringing.

## Field-by-Field Explanation

* **Main Info** (Page 1): A description of the event and the dish.
* **Name**: The name of the person bringing the dish.
* **Name of Host**: The name of the person hosting the event.
* **Email**: An optional field for the person bringing the dish to enter their email address.
* **Phone**: An optional field for the person bringing the dish to enter their phone number.
* **Event Date**: The date of the event.
* **Event Time**: The time of the event.
* **Event Location**: The location of the event.
* **Number of Guests**: The number of guests the person bringing the dish is planning to bring for.
* **Dish to be Brought**: A description of the dish.
* **Name of Dish Brought**: The name of the dish.
* **Main Course**: A select-one field to select the type of main course.
* **Side Dish**: A select-multiple field to select the type(s) of side dish.
* **Dessert**: A select-one field to select the type of dessert.
* **Comments**: Any additional comments about the dish.
