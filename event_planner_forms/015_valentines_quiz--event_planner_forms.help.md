# Valentines Quiz - Help Guide
## Purpose
The Valentines Quiz form is designed to collect user input for a short quiz about Valentine's Day. This form is intended to be a lighthearted way to learn about the history and tradition of the holiday.

## How To Complete This Form
1. Read each question carefully and provide your response in the text field next to it.
2. If you are unsure of an answer, you can type your best guess.
3. Select the correct option from the select one field at the end of the form for the final question.
4. Click "Submit" to complete the quiz.

## Field-by-Field Explanation

* **Valentines Day Quiz Form** (`valentines_day_quiz_form`, text, required/optional): This is the main field where you can type your response to the first question.
* **Questions** (`questions`, text, required/optional): This field is where you can type your response to the second question.
* **Answers** (`answers`, text, required/optional): This is where you can type your response to the third question.
* **Correct** (`correct`, number, required/optional): This field is not currently used, but it is intended for future development.
* **Score** (`score`, number, required/optional): This field is not currently used, but it is intended for future development.
* **Result** (`result`, select_one, required/optional): Select the correct option from the dropdown menu to complete the quiz.
* **Valentines Day History** (`valentines_day_history`, text, required/optional): This field is where you can type your response to the fourth question.
* **Question 2** (`question_2`, text, required/optional): This field is where you can type your response to the fifth question.
* **Question 3** (`question_3`, text, required/optional): This is where you can type your response to the sixth question.
* **Question 4** (`question_4`, text, required/optional): This field is where you can type your response to the seventh question.
