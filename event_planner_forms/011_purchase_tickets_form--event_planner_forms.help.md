# Purchase Tickets Form - Help Guide
## Purpose
This form is designed to collect information from users who want to purchase tickets for an event. It captures essential details such as user name, ticket quantity, gift registries, event date and time, available tickets, and whether the user wants to purchase tickets.

## How To Complete This Form
1.  To start, fill out your user name in the **User Name** field.
2.  In the **Quantity** field, enter the number of tickets you wish to purchase.
3.  If you are affiliated with a gift registry, select the relevant registry under **Gift Registry**.
4.  Choose the **Event Date** and **Event Time** of the event for which you're purchasing tickets.
5.  Enter the number of **Available Tickets** for the event if you know it.
6.  Finally, indicate whether you'd like to **Purchase Tickets** by selecting the option in the last field.

## Field-by-Field Explanation

*   **User Name**: A text field that captures the name of the user who is purchasing the tickets. Please enter your name as it should be recorded in the records.
    *   **Type**: text
    *   **Required**: Yes
*   **Quantity**: Enter the number of tickets you want to buy.
    *   **Type**: number
    *   **Required**: No
*   **Gift Registry**: Select the gift registry associated with you if you are purchasing tickets for someone else.
    *   **Type**: select\_multiple
    *   **Required**: No
*   **Event Date**: Choose the date of the event for which you are buying tickets.
    *   **Type**: date
    *   **Required**: No
*   **Event Time**: Select the time of the event for which you're buying tickets.
    *   **Type**: time
    *   **Required**: No
*   **Available Tickets**: If you know the number of tickets available, enter that here.
    *   **Type**: number
    *   **Required**: No
*   **Tickets Purchased**: Enter the number of tickets you've actually purchased.
    *   **Type**: number
    *   **Required**: No
*   **Purchase Tickets**: Check this box to confirm you'd like to purchase tickets.
    *   **Type**: select\_one
    *   **Required**: No
