# Workshop Feedback Form - Help Guide
## Purpose
The purpose of this form is to collect feedback from workshop participants on how to improve the workshop and what they would recommend it to others.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Read each question carefully and answer it to the best of your ability.
2. Provide as much detail as possible in your answers.
3. Select only the options that apply to you.
4. Do not skip any fields that are marked as required.
5. If you have any additional comments or suggestions, please use the "Comments" field at the end of the form.

## Field-by-Field Explanation

* **Introduction** (`1`, `note`, required: false): This section is a brief introduction to the form. Please take a moment to read it before proceeding.
* **How can we improve this workshop?** (`2`, `text`, required: false): This field is for you to suggest ways to improve the workshop. Be as specific as possible with your suggestions.
* **Score** (`3`, `number`, required: false): Rate the workshop on a scale of 1 to 10, where 1 is the lowest and 10 is the highest.
* **Comments** (`4`, `text`, required: false): If you have any additional comments or suggestions that don't fit in the other fields, please write them here.
* **Would recommend** (`5`, `select_multiple`, required: false): Select all that apply:
	+ Yes: You would recommend this workshop to others.
	+ No: You would not recommend this workshop to others.
* **Reasons for recommendation 1, 2, 3** (`6`, `7`, `8`, `text`, required: false): If you have any reasons why you would recommend this workshop, please write them in these fields.
* **Improvement area 1, 2, 3, 4, 5, 6** (`9`, `10`, `11`, `12`, `13`, `14`, `text`, required: false): If you have any suggestions on how to improve this workshop, please write them in these fields.
* **Would recommend to colleagues** (`15`, `select_multiple`, required: false): Select all that apply:
	+ Yes: You would recommend this workshop to your colleagues.
	+ No: You would not recommend this workshop to your colleagues.
* **Would recommend to friends** (`16`, `select_multiple`, required: false): Select all that apply:
	+ Yes: You would recommend this workshop to your friends.
	+ No: You would not recommend this workshop to your friends.
* **Comments to facilitator** (`17`, `text`, required: false): If you have any comments or suggestions for the facilitator, please write them here.
