# Raffle Ticket Form - Help Guide
## Purpose
The Raffle Ticket Form is a tool used to collect information for a raffle event. This form will help manage the process of creating and running a raffle event, ensuring all necessary details are collected from participants and winners.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information before filling out the form.
2. Fill out your user email address in the `User Email` field.
3. Provide your phone number in the `User Phone` field.
4. Enter the quantity of tickets you would like to purchase in the `Ticket Quantity` field.
5. Select the correct winner from the list in the `Select Winner` field.
6. If applicable, enter the name of the winner in the `Winner Name` field.
7. Enter the price of the ticket in the `Ticket Price` field.
8. Select the type of raffle event you are participating in from the `Raffle Type` field.
9. Enter the email of the winner in the `Winner Email` field.
10. Select the payment method you would like to use in the `Payment Method` field.
11. Select the payment processor to be used in the `Payment Processor` field.
12. Enter the date of the raffle event in the `Raffle Date` field.
13. Enter the time of the raffle event in the `Raffle Time` field.

## Field-by-Field Explanation
* **User Email**: A field to input your email address for communication purposes. This will be used to send updates and notifications regarding the raffle event.
* **User Phone**: A field to input your phone number for further contact if needed.
* **Ticket Quantity**: The number of tickets you would like to purchase for the raffle event.
* **Select Winner**: Select the correct winner from the list of options provided.
* **Winner Name**: If applicable, enter the name of the winner.
* **Ticket Price**: The price of the ticket for the raffle event.
* **Raffle Type**: Select the type of raffle event you are participating in.
* **Winner Email**: A field to input the email of the winner.
* **Payment Method**: Select the payment method to be used for the raffle event.
* **Payment Processor**: Select the payment processor to be used for the raffle event.
* **Raffle Date**: The date of the raffle event.
* **Raffle Time**: The time of the raffle event.
