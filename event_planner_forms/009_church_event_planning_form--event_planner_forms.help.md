# Church Event Planning Form - Help Guide

## Purpose
This form is designed to collect and review event details for church events. Please ensure that all required fields are filled out accurately and thoroughly.

## How To Complete This Form
Follow the general guidelines provided in the introduction to ensure a smooth and accurate submission.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required): Enter the name of the event, for example, "Welcome Home Sunday Service".
* **Type of Event** (`event_type`, select_one, required): Choose from the list of event types (e.g., Worship Service, Bible Study, etc.) that best describes the event.
* **Event Organizer Name** (`event_organizer`, text, required): Provide the name of the primary person responsible for the event.
* **Organizer Email** (`organizer_email`, email, required): Enter the email address of the event organizer.
* **Organizer Phone** (`organizer_phone`, text, required): Enter the phone number of the event organizer.
* **Event Date** (`event_date`, date, required): Enter the date of the event in the MM/DD/YY format (e.g., 01/01/22).
* **Start Time** (`start_time`, time, required): Enter the start time of the event in 24-hour format (e.g., 09:00 AM).
* **End Time** (`end_time`, time, required): Enter the end time of the event in 24-hour format (e.g., 12:00 PM).
* **Expected Number of Attendees** (`expected_attendance`, number, required): Estimate the number of people attending the event.
* **Event Location** (`venue_location`, select_one, required): Choose from the list of location options where the event will be held (e.g., Main Sanctuary, Fellowship Hall).
* **Estimated Budget Needed** (`budget_required`, number, required): Enter the estimated budget for the event.
* **Volunteers Needed** (`volunteers_needed`, number, required): Enter the number of volunteers needed for the event.
* **Volunteer Roles** (`volunteer_roles`, select_multiple, required): Select all the volunteer roles needed for the event (e.g., setup, registration, ushers, etc.).
* **Equipment Needed** (`equipment_needed`, select_multiple, required): Select all the equipment required for the event (e.g., sound system, projector, etc.).
* **Food Service** (`catering_needed`, select_one, required): Choose if food will be served and what type (e.g., full meal, light refreshments, etc.).
* **Marketing Support** (`marketing_needed`, select_one, required): Choose the marketing support needed (e.g., bulletin announcement, social media posts, etc.).
* **Security Considerations** (`security_concerns`, text, optional): Enter any special security considerations for the event.
* **Leadership Approval Status** (`approval_status`, select_one, required): Choose the status of the event approval (e.g., Approved, Pending approval, Needs discussion).
* **Additional Notes** (`additional_notes`, text, optional): Enter any other important information regarding the event.

## Tips
* Double-check all information for accuracy before submitting the form.
* Ensure all required fields are filled out.
* Be clear and concise in all answers.
* Use proper formats for dates and times.
* Select all that apply for volunteer and equipment needs.
* Submit the form once complete and a representative from the leadership team will review and respond.
