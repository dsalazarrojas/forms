# Event Planning Approval Form - Help Guide
## Purpose
The Event Planning Approval Form is used to collect and track information about events, including their title, category, description, time, date, location, and other details. This form helps to keep track of event organizers, event budgets, and event status.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter the title of the event in the **Form Title** field.
2. Select the category of the event from the **Form Category** dropdown menu.
3. Provide a brief description of the event in the **Description** field.
4. Enter the date and time of the event in the **Event When** field.
5. Enter the location of the event in the **Event Location** field.
6. List the names of all event organizers in the **Organizers** field.
7. Enter the estimated event budget in the **Event Budget** field.
8. Enter the date of the event in the **Date** field.
9. Enter the time of the event in the **Time** field.
10. Enter the duration of the event in the **Duration** field.
11. Select the status of the event from the **Status** dropdown menu.
12. Select whether the event is a priority from the **Priority** dropdown menu.
13. Enter the date of approval in the **Approval Date** field.

## Field-by-Field Explanation
* **Form Title** (text): Enter a brief title for the event.
* **Form Category** (select_one): Select the category of the event (e.g. "Yes", "No").
* **Description** (text): Provide a brief description of the event.
* **Event When** (date): Enter the date and time of the event.
* **Event Location** (text): Enter the location of the event.
* **Venue** (text): Enter the venue of the event.
* **Organizers** (text): List the names of all event organizers.
* **Event Budget** (number): Enter the estimated event budget.
* **Date** (date): Enter the date of the event.
* **Time** (time): Enter the time of the event.
* **Duration** (number): Enter the duration of the event.
* **Status** (select_one): Select the status of the event (e.g. "Active", "Inactive").
* **Priority** (select_one): Select whether the event is a priority.
* **Approval Date** (date): Enter the date of approval for the event.
