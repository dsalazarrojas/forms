# drone_permission_form - Help Guide
## Purpose
The drone permission form is used by event planners to obtain permission to operate drones within their event. This form helps ensure that the event planner is aware of and approves drone operations, ensuring a safe and successful event.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form with accurate and truthful information about the event and drone operations.
2. Ensure that all required fields are filled out.
3. Review the form carefully before submitting it to the event planner for approval.

## Field-by-Field Explanation
* **Event Location** (`event_location`, text, required: false): This field allows you to specify the location of the event where drone operations will take place.
* **Drone Type** (`drone_type`, select_multiple, required: false): This field allows you to specify the type of drone(s) that will be used during the event. Please select all applicable options.
* **Start Date** (`start_date`, date, required: false): This field allows you to specify the start date of the event where drone operations will begin.
* **End Date** (`end_date`, date, required: false): This field allows you to specify the end date of the event where drone operations will end.
* **Purpose of Use** (`purpose_of_use`, text, required: false): This field allows you to specify the reason for using drones during the event.
* **Location Details** (`location_details`, text, required: false): This field allows you to provide additional information about the location where drone operations will take place.
* **Local Authority** (`local_authority`, select_one, required: false): This field allows you to specify if local authorities are aware of and approve of drone operations at the event location.
* **Federal Authority** (`federal_authority`, select_one, required: false): This field allows you to specify if federal authorities are aware of and approve of drone operations at the event location.

## Tips
* Please ensure that all fields are filled out accurately and truthfully.
* Review the form carefully before submitting it to the event planner for approval.
* This form does not replace any other regulatory or legal requirements that must be met for drone operations.
* It is the event planner's responsibility to ensure that all relevant laws and regulations are followed.
