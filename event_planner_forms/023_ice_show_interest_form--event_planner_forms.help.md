# Ice Show Interest Form - Help Guide
## Purpose
The Ice Show Interest Form is designed for event planners and organizers to collect information about upcoming ice shows. It includes fields for event title, date, time, type, event location, organizer, and other relevant details.

## How To Complete This Form
1. Fill out the required fields with accurate and relevant information.
2. Enter your name and email address for contact purposes.
3. Select the event type and roles involved in the event.
4. Choose the event location (indoor or outdoor).
5. Enter any additional event details, if necessary.
6. Review your submissions for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **Name** (`name`, `text`, required): Enter your name for contact purposes.
* **Email** (`email`, `email`, required): Enter your email address for contact purposes.
* **Phone** (`phone`, `text`, required): Enter your phone number for contact purposes.
* **Note** (`note`, `note`, optional): Enter any additional comments or notes about the event (if necessary).
* **Event Title** (`event_title`, `text`, required): Enter the title of the event (e.g., "Ice Skating Show").
* **Date** (`date`, `date`, optional): Enter the date of the event (if available).
* **Time** (`time`, `time`, optional): Enter the time of the event (if available).
* **Event Type** (`event_type`, `select_one`, required): Select the type of event (e.g., "Ice Show," "Ice Dance Show," or "Ice Skating Show").
* **Roles** (`roles`, `select_multiple`, required): Select the roles involved in the event (e.g., "Skating," "Coaching," "Instructing").
* **Rink** (`rink`, `select_one`, required): Select the event location type (e.g., "Outdoor" or "Indoor").
* **Event Location** (`event_location`, `text`, optional): Enter the specific event location (if different from the selected rink type).
* **Event Details** (`event_details`, `text`, optional): Enter any additional event details (if necessary).
* **Event Organizer** (`event_organizer`, `select_one`, required): Select the event organizer type (e.g., "Event Organizers," "Coaches," or "Instructors").
* **Comments** (`comments`, `text`, optional): Enter any additional comments about the event (if necessary).
* **Comments 2** (`comments2`, `text`, optional): This field is a duplicate of "Comments" (for redundancy purposes).
* **Submit** (`submit`, `text`, required): Confirm your submission and confirm the accuracy of the entered information.

Note: The duplicate fields at the end of the form are for redundancy and backup purposes.
