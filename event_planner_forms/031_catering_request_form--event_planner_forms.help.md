# Catering Request Form - Help Guide
## Purpose
This form is designed to collect information for catering requests from employees, meeting organizers, or other stakeholders. It will help us ensure that all necessary details are captured and communicated effectively for the smooth execution of events. Please fill out this form as accurately and thoroughly as possible to help us better understand your catering needs.

## How To Complete This Form
To complete this form, please fill in the required fields and choose from the provided options when applicable. Make sure to submit the form once you've finished entering all the necessary information.

## Field-by-Field Explanation
### 1. Requester Name (`requester_name`, **Text**, Required)
Your full name.

*   Enter your full name as it appears on official documents.

### 2. Email Address (`email`, **Email**, Required)
Your email address.

*   Enter your official email address that you use for work.

### 3. Phone Number (`phone`, **Text**, Required)
Your contact phone number.

*   Enter your work phone number or a number where you can be reached during working hours.

### 4. Company Name (`company_name`, **Text**, Optional)
Your company or organization name.

*   If you're representing a company or organization, enter your company name.

### 5. Department (`department`, **Text**, Optional)
Your department or team name.

*   If you're representing a department or team within your company, enter your department name.

### 6. Request Date (`request_date`, **Date**, Required)
Date of this request.

*   Enter the date when you would like to place your catering order.

### 7. Event Type (`event_type`, **Select One**, Required)
What type of event.

*   Select the type of event that you're planning (e.g. Meeting, Conference, Workshop, etc.).

### 8. Event Date (`event_date`, **Date**, Required)
Date of your event.

*   Enter the date when the event will take place.

### 9. Event Start Time (`event_start_time`, **Time**, Required)
Start time.
*   Enter the start time of your event.

### 10. Event End Time (`event_end_time`, **Time**, Required)
End time.
*   Enter the end time of your event.

### 11. Event Location (`location`, **Text**, Required)
Where will the event be held.

*   Enter the location where the event will take place.

### 12. Room Number (`room_number`, **Text**, Optional)
Specific room if applicable.
*   If your event is held in a specific room, enter the room number.

### 13. Expected Attendee Count (`attendee_count`, **Number**, Required)
Number of people expected.
*   Enter the expected number of attendees.

### 14. Service Type (`service_type`, **Select One**, Required)
Type of catering service.

*   Select the type of catering service you would like to have (e.g. Breakfast, Morning Break, etc.).

### 15. Menu Selection (`menu_selection`, **Text**, Required)
Your preferred menu.
*   Enter your preferred menu options.

### 16. Beverage Service (`beverage_service`, **Select Multiple**, Optional)
Beverages needed.
*   Select the beverages you would like to have available during your event.

### 17. Dietary Requirements (`dietary_requirements`, **Text**, Optional)
Any dietary restrictions.
*   If you or any attendees have dietary restrictions, enter them here.

### 18. Vegetarian Meals (`vegetarian_count`, **Number**, Optional)
Number of vegetarian meals.
*   Enter the number of vegetarian meals you would like to have.

### 19. Vegan Meals (`vegan_count`, **Number**, Optional)
Number of vegan meals.
*   Enter the number of vegan meals you would like to have.

### 20. Gluten-Free Meals (`gluten_free_count`, **Number**, Optional)
Number of gluten-free meals.
*   Enter the number of gluten-free meals you would like to have.

### 21. Setup Requirements (`setup_requirements`, **Text**, Optional)
Any special setup needs.
*   If you have any special setup needs, enter them here.

### 22. Budget Code (`budget_code`, **Text**, Optional)
Cost center or budget code.
*   If you have a specific budget code or cost center, enter it here.

### 23. Approval Status (`approval_status`, **Select One**, Optional)
Approval status.
*   If this request has been approved, select Approved. If it has been rejected, select Rejected.

### 24. Special Requests (`special_requests`, **Text**, Optional)
Any additional requirements.
*   If you have any additional requirements or requests, enter them here.

### 25. Additional Comments (`additional_comments`, **Text**, Optional)
Any other information.
*   If you have any other information to share, enter it here.

**Tips**

*   Please make sure to fill out all required fields.
*   If you're unsure about any field, please ask for clarification.
*   Double-check your entries for accuracy to avoid any issues with your order.
