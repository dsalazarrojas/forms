# Contact Form With Paper Theme - Help Guide
## Purpose
This form is used to collect event planning information from users, including contact details and event specifics.

## How To Complete This Form
1. Fill out the form with the required information.
2. Enter your name, email, and phone number in the corresponding fields.
3. Choose the type of event you are planning.
4. Select a preferred date for the event.
5. Specify the expected number of guests.
6. Choose the services you require for the event.
7. Select a budget range for the event.
8. Provide any additional details to help with event planning.

## Field-by-Field Explanation
* **Contact name** (`contact_name`, `text`, required): Enter your name as the primary contact.
* **Email address** (`email`, `email`, required): Enter your email address for event correspondence.
* **Phone number** (`phone`, `text`, optional): Enter your best phone number for the event planner to reach you.
* **Event type** (`event_type`, `select_one`, required): Choose the type of event you are planning (e.g., Conference, Wedding, Corporate meeting, etc.).
* **Event date** (`event_date`, `date`, optional): Select a preferred date for the event. 
* **Expected guests** (`expected_guests`, `number`, optional): Enter the approximate number of guests attending the event.
* **Services required** (`services_required`, `select_multiple`, optional): Select the services you need for the event (e.g., Venue booking, Catering, AV equipment, etc.).
* **Budget range** (`budget_range`, `select_one`, optional): Choose the estimated budget range for the event planning.
* **Additional details** (`additional_details`, `text`, optional): Provide any other information that can help with event planning.
