# Event Follow Up Survey - Help Guide
## Purpose
The Event Follow Up Survey is used to collect feedback, status updates, and other relevant information about events after they have occurred. This form is essential for event planners and coordinators to track progress, communicate with customers, and ensure that follow-ups are conducted efficiently.

## How To Complete This Form
To complete this form, follow these steps:
* Ensure you have all the required information and data points necessary for the event you are reporting on.
* Complete each field accurately and thoroughly, providing as much detail as possible.
* Review the form for any errors or inconsistencies before submitting.

## Field-by-Field Explanation
### **Event Follow Up Survey** (1)
* Type: Text
* Required: Yes
* This field is the title of the survey, which should be completed with the name of the event.

### **Event Date** (2)
* Type: Date
* Required: Yes
* Enter the date of the event.

### **Event Time** (3)
* Type: Time
* Required: Yes
* Enter the time of the event.

### **Customer Name** (4)
* Type: Text
* Required: Yes
* Enter the full name of the customer.

### **Event Attended** (5)
* Type: Select One
* Required: Yes
* Select one of the provided options to indicate if the customer attended the event.

### **Feedback Question** (6)
* Type: Select Multiple
* Required: Yes
* Select all applicable options to provide feedback about the event.

### **Email** (7)
* Type: Email
* Required: Yes
* Enter the email address of the customer.

### **Phone** (8)
* Type: Text
* Required: Yes
* Enter the phone number of the customer.

### **Additional Info** (9)
* Type: Note
* Required: Yes
* Enter any additional information about the event or customer.

### **Comments** (10)
* Type: Text
* Required: Yes
* Enter any comments or notes about the event or customer.

### **Prophet** (11)
* Type: Select One
* Required: Yes
* Select one of the provided options to assign the event to a team member or user.

### **Assigned Date** (12)
* Type: Date
* Required: Yes
* Enter the date the event was assigned to the team member or user.

### **Assigned Time** (13)
* Type: Time
* Required: Yes
* Enter the time the event was assigned to the team member or user.

### **Assignee Name** (14)
* Type: Text
* Required: Yes
* Enter the name of the team member or user assigned to the event.

### **Event Status** (15)
* Type: Select Multiple
* Required: Yes
* Select all applicable options to indicate the status of the event.

### **Follow-up Survey Sent** (16)
* Type: Select One
* Required: Yes
* Select one of the provided options to indicate if the follow-up survey was sent to the customer.

### **Event Status Date** (17)
* Type: Date
* Required: Yes
* Enter the date the event status was updated.

### **Event Status Time** (18)
* Type: Time
* Required: Yes
* Enter the time the event status was updated.

### **Event Status Notes** (19)
* Type: Note
* Required: Yes
* Enter any notes or comments about the event status.

### **Assigned Notes** (20)
* Type: Note
* Required: Yes
* Enter any notes or comments about the assigned team member or user.

### **Follow-up Survey Sent Date** (21)
* Type: Date
* Required: Yes
* Enter the date the follow-up survey was sent to the customer.

### **Follow-up Survey Sent Time** (22)
* Type: Time
* Required: Yes
* Enter the time the follow-up survey was sent to the customer.

### **Follow-up Survey Notes** (23)
* Type: Note
* Required: Yes
* Enter any notes or comments about the follow-up survey.

### **Customer Email Sent** (24)
* Type: Select Multiple
* Required: Yes
* Select all applicable options to indicate if the customer was sent an email.

### **Customer Email Sent Date** (25)
* Type: Date
* Required: Yes
* Enter the date the email was sent to the customer.

## Tips
* Ensure to review the form carefully before submission to avoid errors.
* Enter as much detail as possible in each field to provide comprehensive information.
* If you are unsure about any field or have questions, please reach out to the event planners or coordinators for assistance.
