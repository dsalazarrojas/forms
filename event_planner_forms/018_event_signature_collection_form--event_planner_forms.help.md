# Event Signature Collection Form - Help Guide
## Purpose
The Event Signature Collection Form is used to collect information about events that do not already exist in the system. This form is used by event planners to provide details about events that are currently being planned or are in need of planning.

## How To Complete This Form

1. To fill out this form, please select "Yes" if the event is being planned or needs planning, and "No" if it is already planned or ongoing.
2. Enter the name of the event.
3. Select the event location.
4. Enter the date of the event.
5. Enter the email and phone number of the person attending the event.
6. Provide a signature by signing the form.
7. If you have more information about the event, please add it in the "Event Details" field.

## Field-by-Field Explanation

* **Event Planning Form** (Select Multiple):
	+ This field asks if the event is being planned or needs planning. Select "Yes" if the event is in the planning stage, or "No" if it is already planned or ongoing.
* **Event Name**:
	+ Enter the name of the event.
* **Event Location**:
	+ Select the location of the event.
* **Date**:
	+ Enter the date of the event.
* **Email**:
	+ Enter the email address of the person attending the event.
* **Phone**:
	+ Enter the phone number of the person attending the event.
* **Signature**:
	+ Provide a signature by signing the form.
* **Event Details**:
	+ If you have any additional information about the event, please add it in this field.
* **Consent Form**:
	+ This field is not currently used in the form, but is intended for future use.
* **Assigned Tool**:
	+ This field is not currently used in the form, but is intended for future use.

## Tips

* Please only fill out this form for events that do not already exist in the system.
* Make sure to provide accurate and complete information about the event.
* If you are unsure about any of the fields, please contact the event planning team for clarification.
