# Reopening Attendance Confirmation Form - Help Guide

## Purpose
This form is for attendees to confirm their attendance and preferences for events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name and email address.
2. Confirm your attendance by selecting the correct option for how you plan to attend (in person, virtually, or other).
3. Provide a date for when you plan to attend (if applicable).
4. Enter a time for when you plan to start attending (if applicable).
5. Enter any reason for why you are confirming your attendance (if applicable).
6. Add any comments or additional information about your attendance (if applicable).
7. Confirm if you will be attending in person, virtually, or other (if applicable).

## Field-by-Field Explanation

* **User Name**: Enter your name to identify yourself as an attendee.
	+ Type: Text
	+ Required: Optional
* **User Email**: Enter your email address to allow us to contact you about event details.
	+ Type: Email
	+ Required: Optional
* **Confirm Attendance**: Select how you plan to attend the event (in person, virtually, or other).
	+ Type: Select One
	+ Required: Optional
* **Date**: Enter the date you plan to attend (if applicable).
	+ Type: Date
	+ Required: Optional
* **Time**: Enter the time you plan to start attending (if applicable).
	+ Type: Time
	+ Required: Optional
* **Reason**: Enter any reason for why you are confirming your attendance (if applicable).
	+ Type: Text
	+ Required: Optional
* **Comment**: Add any additional information about your attendance (if applicable).
	+ Type: Text
	+ Required: Optional
* **Confirm In Person**: Confirm if you will be attending in person.
	+ Type: Select One
	+ Required: Optional
* **Confirm In Video**: Confirm if you will be attending through video conferencing.
	+ Type: Select One
	+ Required: Optional
* **Confirm In Audio**: Confirm if you will be attending through audio conferencing.
	+ Type: Select One
	+ Required: Optional
* **Confirm In Phone**: Confirm if you will be attending through phone calls.
	+ Type: Select One
	+ Required: Optional
* **Confirm Outside Work**: Confirm if you will be attending outside of work hours.
	+ Type: Select One
	+ Required: Optional
* **Confirm Virtual**: Confirm if you will be attending virtually.
	+ Type: Select One
	+ Required: Optional
* **Confirm Absent**: Confirm if you will be absent.
	+ Type: Select One
	+ Required: Optional
* **Comments**: Add any additional information about your attendance.
	+ Type: Text
	+ Required: Optional
* **Confirm Outside Work Reason**: Enter any reason for why you are attending outside of work hours.
	+ Type: Text
	+ Required: Optional
* **Confirm Virtual Reason**: Enter any reason for why you are attending virtually.
	+ Type: Text
	+ Required: Optional
