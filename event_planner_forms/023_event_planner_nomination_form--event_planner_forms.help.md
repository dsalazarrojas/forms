# Event Planner Nomination Form - Help Guide
## Purpose
This form is designed to collect information for the nomination of an event planner. The goal is to identify and recognize exceptional individuals in the organization, acknowledging their efforts and contributions to the company.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the correct category that best describes the event planner's work.
2. Enter the name of the event planner you are nominating.
3. Select the source of the nomination (e.g., manager, colleague, or self-nomination).
4. Provide any additional comments or reasons for the nomination.

## Field-by-Field Explanation
### Category (id: 3)
* **Category** (`category1, category2, category3`, required): Select one of the categories to describe the event planner's role or department.

### Nominee (id: 4)
* **Nominee** (`event_planner_form_nominee`, required): Enter the full name of the event planner you are nominating.

### Nomination Source (id: 5)
* **Nomination Source** (`event_planner_form_nominator`, required): Select the source of the nomination (e.g., manager, colleague, or self-nomination).

### Comments (id: 6)
* **Comments** (`event_planner_form_comments`, optional): Provide any additional comments or reasons for the nomination, selecting one or more of the provided options or typing in your own comments.

## Tips
* Make sure to fill out the form completely and correctly to ensure accurate and fair nominations.
* Only nominate event planners once.
* If you are unsure of the correct category or nomination source, consult with a supervisor or HR representative.
