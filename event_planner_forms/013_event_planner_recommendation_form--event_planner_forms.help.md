# Event Planner Recommendation Form - Help Guide
## Purpose
This form is used to collect information from users about the type of event planner they need for their event. This information is used to ensure that the right person is assigned to handle the event planning process.

## How To Complete This Form
To complete this form, follow these steps:

* Select the type of event planner you are looking for from the "What type of event planner are you looking for" dropdown menu.
* Enter the name of the event planner in the "Event planner name" field.
* Enter the contact email of the event planner in the "Contact Email" field.
* Enter the phone number of the event planner in the "Phone number" field.

## Field-by-Field Explanation
* **What type of event planner are you looking for**: This is a dropdown menu where you select the type of event planner you need. Choose from the available options to ensure you get the right type of planner for your event.
* **Event planner name**: This is the name of the event planner you are looking for. Enter their full name as you would normally write it.
* **Contact Email**: This is the email address of the event planner. Enter their email address to help us contact them for further information.
* **Phone number**: This is the phone number of the event planner. Enter their phone number to help us contact them for further information.

## Tips
* Make sure to select the correct type of event planner for your event.
* Double-check the spelling of the event planner's name.
* Enter the correct contact email and phone number of the event planner.
* If you are unsure about any of the fields, please ask for help.
