# Promoter Application Form - Help Guide
## Purpose
The Promoter Application Form is a tool for event organizers to submit applications for events in the system, providing essential information about their events.

## How To Complete This Form
- Fill out the form with the required information for your event.
- Ensure that all fields are correctly filled and valid data is provided.
- Review your submission carefully before submitting it for review.

## Field-by-Field Explanation
### Event Name (Event Name, text, required: false)
Enter the name of your event in a clear and concise manner.

### Contact Information (Contact Information, text, required: false)
Provide your contact information so we can reach you about your event.

### Event Dates (Event Dates, date, required: false)
Enter the date(s) of your event in a standard date format (e.g., MM/DD/YYYY).

### Event Time (Event Time, time, required: false)
Enter the start and end time of your event in a 24-hour format (e.g., 13:30).

### Event Venue (Event Venue, text, required: false)
Enter the name and location of the event venue.

### Promotion Goals (Promotion Goals, text, required: false)
Explain the goals of your promotion, such as social media promotion or sponsorships.

### Promotion Media (Promotion Media, text, required: false)
List the types of media used for promotion, such as email, social media, or flyers.

### Promotion Budget (Promotion Budget, number, required: false)
Enter the budget allocated for promotion, if any.

### Promotion Terms (Promotion Terms, select_multiple, required: false)
Check 'Yes' for terms that apply to your promotion, such as 'Paid promotion', 'Free promotion'.

### Promoter Details (Promoter Details, select_multiple, required: false)
Check 'Yes' for details that apply to your event promotion, such as 'Sponsorships', 'Partnerships'.

### Event Description (Event Description, text, required: false)
Provide a brief description of your event.

### Event Organizer's Role (Event Organizer's Role, select_multiple, required: false)
Check 'Yes' for the role of the event organizer, such as 'Event Manager', 'Marketing Manager'.
