# event_cancellation_form - Help Guide
## Purpose
The event_cancellation_form is a form used to request cancellation of an event due to various reasons.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Fill out the form with the required information.
2. Choose a valid reason for the event cancellation from the dropdown options.
3. Optionally, provide any additional information in the text fields.

## Field-by-Field Explanation
* **User Info** (`user_info`, text, optional): Enter your name and contact information.
* **User Contact** (`user_contact`, text, optional): Enter your contact details so that we can communicate with you about your event cancellation.
* **Event Info** (`event_info`, text, optional): Provide a brief description of the event that you are canceling.
* **Cancellation Reason** (`cancellation_reason`, select_one, optional): Select the reason for the event cancellation from the dropdown options: COVID-19, Personal Reasons, or Other.
* **Cancellation Date** (`cancellation_date`, date, optional): Enter the date you want the event canceled.
* **Event Cancellation Form Terms** (`event_cancellation_form_terms`, note, optional): Read and agree to our event cancellation terms and conditions.
* **Refund Status** (`refund_status`, select_multiple, optional): Select the status of the refund for the event: Approved, Pending.
* **Payment Status** (`payment_status`, select_multiple, optional): Select the status of the payment for the event: Paid, Unpaid.
* **Reason Other** (`reason_other`, text, optional): If you've selected 'Other' as your reason for cancellation, provide a brief explanation.

## Tips
* If you're unsure about any of the information, please do not hesitate to contact your event planner for assistance.
* Make sure to fill out all the required fields to ensure your request is processed smoothly.
