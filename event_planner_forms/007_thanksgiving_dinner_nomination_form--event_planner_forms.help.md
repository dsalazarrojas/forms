# Thanksgiving Dinner Nomination Form - Help Guide
## Purpose
This form is used to submit nominations for a Thanksgiving dinner event. Please fill out the form completely and accurately to ensure your nomination is successfully received.

## How To Complete This Form
To fill out this form, follow these steps:

1. Fill in the required fields (Name, email, phone, event date, event time, nomination details, supporting families, community contributions, holiday promotions) completely and accurately.
2. If you wish to add any additional comments, you can fill in the Comments field.
3. Make sure to specify the tool assigned to the event in the Assigned Tool field, if applicable.

## Field-by-Field Explanation
* **Nomination Form**: This section is the main body of the form where you need to describe your nomination. Make sure to include all necessary details.
* **Name**: Enter your name as you would like to be recognized by the event organizers.
* **email**: Enter your email address so the event organizers can contact you with any questions or concerns.
* **Phone**: Enter your phone number so the event organizers can reach you if needed.
* **Date**: Enter the date of the event you are nominating.
* **Time**: Enter the time of the event you are nominating.
* **Nomination Details**: Enter a detailed description of your nomination, including any relevant details or information.
* **Supporting Families**: List any families or individuals you would like to see supported by the event.
* **Community Contributions**: Describe any community contributions you would like to highlight related to the event.
* **Holiday Promotions**: Share any holiday-related promotions or discounts you would like to promote.
* **Comments**: If you have any additional comments or suggestions, this is the place to add them.
* **Assigned Tool**: If the event is associated with a specific tool, enter the name of the tool here.
