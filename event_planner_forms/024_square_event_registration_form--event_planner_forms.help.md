# Square Event Registration Form - Help Guide
## Purpose
The Square Event Registration Form is a tool for event planners to register events with their details and collect attendee information. This form is specifically designed for events related to Square's payment services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate information:
	* Event Name
	* Event Venue
	* Event Address
	* Event City
	* Event Type
	* Event Category
	* Ticket Price
	* Ticket Total
	* Ticket Status
	* Payment Method
	* Payment Gateway
	* Ticket Venue
2. Provide the following optional fields as needed:
	* Event Date
	* Event Time
	* Attendee Name
	* Attendee Email
	* Attendee Phone
	* Order ID
	* Order Total
	* Notes
	* Event Tags
	* Event Tags 2
3. Select the correct options for:
	* Payment Method (Cash, Card, Online Payment)
	* Payment Status (Paid, Not Paid, Pending)
	* Order Status (Confirmed, Pending, Cancelled)
	* Ticket Status (Available, Sold Out, Pending)
	* Event Type (Online, Offline)
	* Event Category (Food, Drink, Event)
	* Event Tags (tags for the event)
	* Event Tags 2 (secondary tags for the event)
	* Payment Gateway (Stripe, PayPal, Square)
	* Ticket Status (status of the ticket)

## Field-by-Field Explanation

* **Event Name (id: 1)**: Enter the name of the event.
* **Event Date (id: 2)**: Enter the date of the event (if applicable). 
* **Event Time (id: 3)**: Enter the time of the event (if applicable). 
* **Event Venue (id: 4)**: Enter the venue where the event will take place.
* **Attendee Name (id: 5)**: Enter the name of the attendee.
* **Attendee Email (id: 6)**: Enter the email of the attendee.
* **Attendee Phone (id: 7)**: Enter the phone number of the attendee.
* **Order ID (id: 8)**: Enter the ID of the order.
* **Payment Method (id: 9)**: Select the payment method used for the event (Cash, Card, Online Payment).
* **Order Total (id: 10)**: Enter the total amount of the order.
* **Payment Status (id: 11)**: Select the payment status of the event (Paid, Not Paid, Pending).
* **Order Status (id: 12)**: Select the order status of the event (Confirmed, Pending, Cancelled).
* **Notes (id: 13)**: Enter any additional notes about the event.
* **Event Type (id: 14)**: Select the type of event (Online, Offline).
* **Event Category (id: 15)**: Select the category of the event (Food, Drink, Event).
* **Event Tags (id: 16)**: Enter any tags for the event.
* **Event Tags 2 (id: 17)**: Enter secondary tags for the event.
* **Ticket Quantity (id: 18)**: Enter the quantity of tickets for the event.
* **Ticket Price (id: 19)**: Enter the price of each ticket.
* **Ticket Total (id: 20)**: Calculate the total price of all tickets.
* **Ticket Status (id: 21)**: Select the status of the ticket (Available, Sold Out, Pending).
* **Payment Gateway (id: 22)**: Select the payment gateway used for the event (Stripe, PayPal, Square).
* **Ticket Venue (id: 23)**: Enter the venue where the tickets will be distributed.
* **Event Address (id: 24)**: Enter the address of the event.
* **Event City (id: 25)**: Enter the city of the event.
