# Reunion Registration Form - Help Guide
## Purpose
This form is designed to collect information from attendees for the reunion event. It includes fields for user contact information, event details, and payment methods.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and email address in the "User Information" page.
2. Provide your payment method and amount in the "Payment Info" page.
3. Select your preferred payment method and card type in the "Payment Method" and "Card Type" page.
4. Fill in any additional comments or questions you have in the "Comments" field.
5. Indicate if you are attending the event in the "Is Attending" field.
6. Enter the event ID, type, date, time, and location in the respective fields.
7. Provide the attendee count and event description in the "Event Details" page.
8. Finally, submit the form to complete your registration.

## Field-by-Field Explanation

### User Information
* **Name** (required): Enter your full name.
* **Email** (required): Enter your email address.
* **Phone** (optional): Enter your phone number if you'd like to be contacted.

### Reunion Details
* **Is Attending** (optional): Indicate if you are attending the event.
* **Event ID** (optional): Enter the event ID if you know it.
* **Event Type** (optional): Describe the type of event.
* **Event Date** (optional): Enter the event date.
* **Event Time** (optional): Enter the event time.
* **Event Venue** (optional): Describe the event venue.
* **Event Description** (optional): Enter a brief description of the event.
* **Event Start Time** (optional): Enter the start time of the event.
* **Event End Time** (optional): Enter the end time of the event.
* **Event Location** (optional): Describe the event location.
* **Event Organizer** (optional): Enter the event organizer's name.

### Payment Info
* **Payment Method** (optional): Select your preferred payment method (Cash, Card, Bank Transfer).
* **Card Type** (optional): Select your card type (Visa, MasterCard, American Express, Discover).
* **Payment Amount** (optional): Enter the amount you are paying.

### Contact Info
* **Comments** (optional): Enter any additional comments or questions you have.
* **Contact Info** (optional): Enter any additional contact information you'd like to provide. 

Please note that all fields are optional unless marked as required.
