# Camp Supplies Preparation Check Form - Help Guide
## Purpose
This form is used to collect information from campers and their parents/guardians to ensure that they are adequately prepared for a camp stay.

## How To Complete This Form
To complete this form, please follow these steps:

1. Start by filling out the Camper Information section, where you will provide the camper's name and age.
2. Move on to the Clothing Items section, where you will indicate the number of shorts, T-shirts, socks, and underwear packed.
3. In the Personal Care Items section, select whether you have packed toiletries, medications, sunscreen, and insect repellent.
4. In the Footwear section, choose whether you have packed hiking boots or shoes, water shoes or sandals, or neither.
5. In the Additional Items section, select whether you have packed a flashlight with extra batteries.

## Field-by-Field Explanation

*   **Camper Name (Camper Name)**:
    A field to input the name of the Camper.
*   **Age (Age)**: 
    An age field for the Camper to ensure they are an adult or a minor.
*   **Cabin Assignment (Cabin Assignment)**: This field is used for Camper to be assigned to a cabin and is not mandatory.
*   **Parent or Guardian Name (Parent or Guardian Name)**:
    A field to input the name of the Parent or Guardian.
*   **Parent Contact Number (Parent Contact Number)**: 
    A field for the Parent or Guardian contact number.
*   **Number of Shorts Packed (Number of Shorts Packed)**: 
    Number of Shorts to be packed.
*   **Number of T-Shirts Packed (Number of T-Shirts Packed)**: 
    Number of T-Shirts to be packed.
*   **Number of Socks Packed (Number of Socks Packed)**: 
    Number of Socks to be packed.
*   **Number of Underwear Packed (Number of Underwear Packed)**: 
    Number of Underwear to be packed.
*   **Pajamas (Pajamas)**: This field is used to select if Pajamas are packed or not.
*   **Light Jacket or Hoodie (Light Jacket or Hoodie)**: This field is used to select if a Light Jacket or Hoodie is packed or not.
*   **Rain Jacket or Poncho (Rain Jacket or Poncho)**: This field is used to select if a Rain Jacket or Poncho is packed or not.
*   **Swimsuit (Swimsuit)**: This field is used to select if a Swimsuit is packed or not.
*   **Toiletries (Toiletries)**: This field is used to select if Toiletries are packed or not.
*   **Medications and First Aid Items (Medications and First Aid Items)**: This field is used to select if Medications and First Aid Items are packed or not.
*   **Sunscreen (Sunscreen)**: This field is used to select if Sunscreen is packed or not.
*   **Insect Repellent (Insect Repellent)**: This field is used to select if Insect Repellent is packed or not.
*   **Hiking Boots or Shoes (Hiking Boots or Shoes)**: This field is used to select if Hiking Boots or Shoes are packed or not.
*   **Water Shoes or Sandals (Water Shoes or Sandals)**: This field is used to select if Water Shoes or Sandals are packed or not.
*   **Flashlight with Extra Batteries (Flashlight with Extra Batteries)**: This field is used to select if Flashlight with Extra Batteries is packed or not.

## Tips

*   Please ensure that you have packed all necessary items to avoid any issues during the camp stay.
*   Double-check the information provided before submitting the form to ensure accuracy.
*   If you have any questions or concerns, do not hesitate to reach out to the camp staff for assistance.
