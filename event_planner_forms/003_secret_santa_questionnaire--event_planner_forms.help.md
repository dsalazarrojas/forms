# Secret Santa Questionnaire - Help Guide
## Purpose
The Secret Santa Questionnaire is a form designed to collect information about an event where participants will exchange gifts. This form will help the event host gather the necessary details to plan and execute the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and gift limit on the "Name Request" and "Gift Limit" fields, respectively.
2. Enter the event details on the "Event Name", "Description", "Start Date", "End Date", "Start Time", and "End Time" fields.
3. Specify the event location on the "Location" field.
4. Indicate the participant limit on the "Participant Limit" field.

## Field-by-Field Explanation
* **Name Request** (`name_request`, text, required/optional): Enter your name, which will be used to identify you in the event.
* **Gift Limit** (`gift_limit`, number, required/optional): Set your gift budget limit for the event.
* **Event Name** (`event_name`, text, required/optional): Enter a name for the event, which will be displayed to participants.
* **Description** (`description`, text, required/optional): Briefly describe the event, including any relevant details or rules.
* **Start Date** (`start_date`, date, required/optional): Enter the start date of the event.
* **End Date** (`end_date`, date, required/optional): Enter the end date of the event.
* **Start Time** (`start_time`, time, required/optional): Set the start time of the event.
* **End Time** (`end_time`, time, required/optional): Set the end time of the event.
* **Location** (`location`, text, required/optional): Specify the event location.
* **Participant Limit** (`participant_limit`, number, required/optional): Set the maximum number of participants allowed in the event.
* **No other fields are currently part of the form.
