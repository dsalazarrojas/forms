# Custom Cookie Request Form - Help Guide
## Purpose

The Custom Cookie Request Form is designed to collect information about custom cookies requests from users. This form is intended to be used by users who have not made a cookie request in the past 30 days. A cookie is a small text file stored on the user's browser that stores information about the user's interactions with this website.

## How To Complete This Form

1. Fill out the required fields:
   - First Name
   - Last Name
   - Email
   - Cookie Types (select only one type)
   - Date (format: DD/MM/YY)
2. Select one or more Cookie Flavors (if not required, you may skip this field)
3. Fill out any optional fields: 
   - Phone (optional, only if you have a specific phone number you wish to use for this request)
   - Message (optional, only if you have a specific message you wish to include with your request)

## Field-by-Field Explanation
### First Name
*   `First Name (required)`: Please enter your first name as per your identification documents.

### Last Name
*   `Last Name (required)`: Please enter your last name as per your identification documents.

### Email
*   `Email (required)`: Please enter a valid email address that is accessible to you.

### Phone
*   `Phone (optional)`: If you have a specific phone number you wish to use for this request, please enter it here. 

### Cookie Types
*   `Cookie Types (required)`: Select one cookie type from the options provided. This will help us process your request correctly.

### Cookie Flavors
*   `Cookie Flavors (optional)`: Select multiple cookie flavors that you are interested in. This field is optional and will not affect your request if left empty.

### Date
*   `Date (required)`: Please enter the date in the format DD/MM/YY. For example, 12/07/2025.

### Time
*   `Time (optional)`: Please note that time is not required for this form.

### Note
*   `Note (optional)`: If you have any additional information you wish to include with your request, please enter it here.
