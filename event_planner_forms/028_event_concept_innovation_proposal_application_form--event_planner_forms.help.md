# event-concept-innovation-proposal-application-form - Help Guide
## Purpose
The Event Concept Innovation Proposal Application Form is designed to help users submit a new event concept proposal to your organization. This form collects information about the event, including its concept, category, title, description, and logistics.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter a brief description of the event concept in the **Event Concept** field.
2. Select the category of the innovation (e.g., Event, Workshop, Conference, Meeting, or Festival).
3. Enter a title for the proposal in the **Proposal Title** field.
4. Describe the proposal in more detail in the **Proposal Description** field.
5. Estimate the expected attendance for the event in the **Expected Attendance** field.
6. Set the expected duration of the event in the **Expected Duration** field.
7. Enter the date and time of the event in the **Event Date** and **Event Time** fields.
8. Specify the venue for the event in the **Venue** field.
9. Enter the location of the event in the **Location** field.
10. List the organizers of the event in the **Organizers** field.
11. Upload an image related to the proposal in the **Proposal Image** field.

## Field-by-Field Explanation
- **Event Concept** (`event_concept`, text, optional): Enter a brief description of the event concept.
- **Innovation Category** (`innovation_category`, select_one, optional): Select the category of the innovation (e.g., Event, Workshop, Conference, Meeting, or Festival).
- **Proposal Title** (`proposal_title`, text, optional): Enter a title for the proposal.
- **Proposal Description** (`proposal_description`, text, optional): Describe the proposal in more detail.
- **Expected Attendance** (`expected_attendance`, number, optional): Estimate the expected attendance for the event.
- **Expected Duration** (`expected_duration`, number, optional): Set the expected duration of the event.
- **Event Date** (`event_date`, date, optional): Enter the date of the event.
- **Event Time** (`event_time`, time, optional): Enter the time of the event.
- **Venue** (`venue`, text, optional): Specify the venue for the event.
- **Location** (`location`, text, optional): Enter the location of the event.
- **Organizers** (`organizers`, text, optional): List the organizers of the event.
- **Proposal Image** (`proposal_image`, text, optional): Upload an image related to the proposal.
