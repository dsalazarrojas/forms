# Funeral Place Guest Book Request Form - Help Guide

## Purpose

This form is designed to gather information from guests who attended a funeral service or viewing to help the family of the deceased stay in touch and keep them informed about upcoming events and updates.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter your name and relationship to the deceased.
2. Indicate if you attended the funeral service and/or viewing.
3. If you did not attend the funeral service, please indicate how you heard about the funeral.
4. If you would like to receive updates from the family, select the "True" option in the "Would you like to receive updates from the family?" field.
5. Provide any special message or memory of the deceased you would like to share with the family.
6. If you attended other events, select the "True" option and specify which events you attended in the "Other Events Attended" field.

## Field-by-Field Explanation

* **Name**: Please enter your name.
* **Relationship to Deceased**: Please select how you are related to the deceased (e.g., spouse, child, parent, etc.).
* **Attended Funeral Service**: Please indicate if you attended the funeral service.
* **Attended Viewing**: Please indicate if you attended the viewing.
* **Contact Information**: Please enter your contact information so the family can reach out to you.
* **Special Message or Memory of Deceased**: Please share a special message or memory of the deceased.
* **Attended Other Events**: Please indicate if you attended other events related to the funeral.
* **Other Events Attended**: If you selected "True" for "Attended Other Events", please specify which events you attended.
* **How did you hear about the funeral?**: Please specify how you heard about the funeral.
* **Would you like to receive updates from the family?**: Please indicate if you would like to receive updates from the family.

## Tips

* Please ensure you have permission from the family to fill out this form.
* If you are unsure about any of the fields, please ask the family for clarification.
* If you have any special requests or questions, you can reach out to the family directly.
