# Generic T Shirt Order Form - Help Guide
## Purpose
The Generic T Shirt Order Form is designed to collect order information for T shirts, including size, color, type, name, contact details, and order date.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the size of the T shirt you would like to order (e.g., Large, Medium, Small).
2. Choose the color of the T shirt (e.g., red, blue, green).
3. Decide if you would like to order any T shirt type (e.g., yes or no).
4. Enter your name.
5. Enter your email address.
6. Enter your phone number.
7. Write a brief description of your order, if desired.
8. Select the date you would like to order the T shirt.

## Field-by-Field Explanation
* **Shirt size**: Select the size of the T shirt you would like to order.
* **T-Shirt color**: Choose the color of the T shirt you would like to order.
* **T-Shirt type**: Decide if you would like to order any T shirt type (e.g., yes or no).
* **Name**: Enter your name to associate with your order.
* **Email**: Enter your email address so we can contact you about your order.
* **Phone**: Enter your phone number so we can contact you about your order.
* **Description**: Write a brief description of your order, if desired.
* **Order date**: Select the date you would like to order the T shirt.

## Tips
* Make sure to select the correct shirt size and color to ensure proper fit and delivery of the correct product.
* Check your email and phone number for accuracy to ensure proper contact from our team.
* If you have any special requests or comments, use the description field to let us know.
