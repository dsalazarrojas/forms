# Virtual Workshop Feedback Form - Help Guide
## Purpose
This form is designed to gather feedback and information about a virtual workshop.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your personal information: 
   - First Name
   - Email
   - Phone Number

2. Select the workshop you attended:
   - Select the workshop you attended from the dropdown list
   - Choose the date and time of the workshop from the dropdown list

3. Rate and provide feedback about the workshop:
   - Rate the workshop as Excellent, Good, Fair, or Bad
   - Write your comments about the workshop
   - Choose when you would like to attend the next workshop

4. Answer additional questions about the workshop:
   - Have you attended this workshop before?
   - Would you recommend this workshop?
   - Where was the workshop held?
   - What type of workshop was it?
   - How long was the workshop?
   - Have you attended any other workshops?
