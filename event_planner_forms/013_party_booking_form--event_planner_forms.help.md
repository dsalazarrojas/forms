# Party Booking Form - Help Guide
## Purpose
The Party Booking Form is a form used to book a party with the event planners. This form gathers essential information about the event to create a customized event plan.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired event date from the calendar.
2. Choose the event time that suits your needs.
3. Enter the location where the party will take place.
4. Provide a message or note about the event.
5. Specify the number of guests attending.
6. Choose the status of the guests (Confirmed, Not Confirmed, or Cancel).
7. Select the event planner company from the list (Event Planners Inc. or Jimmy's Event Planners).
8. Choose the type of event (Wedding, Birthday, or Graduation).
9. Enter the phone number and email address associated with the event.

## Field-by-Field Explanation
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Event Time** (`event_time`, time, required): Choose the start time of the event.
* **Event Location** (`event_location`, text, required): Enter the venue or location where the event will take place.
* **Event Message/Note** (`event_message`, text, required): Provide any additional information or notes about the event.
* **Guest Count** (`guest_count`, number, required): Enter the number of guests attending the event.
* **Guest Status** (`guest_status`, select_one, required): Choose the status of the guests (Confirmed, Not Confirmed, or Cancel).
* **Event Planner** (`event_planner`, select_one, required): Select the event planner company from the list (Event Planners Inc. or Jimmy's Event Planners).
* **Event Type** (`event_type`, select_multiple, required): Choose the type of event (Wedding, Birthday, or Graduation).
* **Event Phone Number** (`phone_number`, text, required): Enter the phone number associated with the event.
* **Email Address** (`email_address`, email, required): Enter the email address associated with the event.

## Tips
* Make sure to provide accurate and up-to-date information to ensure a successful party booking.
* If you have any specific requirements or requests, please include them in the event message/note field.
* If you need to make any changes to the event details, please contact the event planners directly.
