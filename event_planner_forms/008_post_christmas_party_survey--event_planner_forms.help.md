# Post Christmas Party Survey - Help Guide

## Purpose

This form is intended to collect feedback and ratings from employees who attended the post-Christmas party. The goal is to gather information on the overall experience of the event and identify areas for improvement for future events.

## How To Complete This Form

To complete this form, follow these steps:

1. **Select "Event Attendees"**: Choose whether you attended the event.
2. **Select "Attendees List"**: Indicate if you are willing to be listed as an attendee for future events.
3. **Rate the Event**: Choose how you rated the event (Option 1, Option 2, Option 3, or Option 4).
4. **Provide Feedback**: Share your thoughts and suggestions about the event.

## Field-by-Field Explanation

* **Event Attendees**: This question asks if you attended the event. Please select "Yes" if you attended and "No" if you did not.
* **Attendees List**: This question asks if you are willing to be listed as an attendee for future events. Please select "Yes" if you are willing, "No" if you are not, and you will not be contacted for future events. 
  If you select "Yes", you may be asked to participate in future events.
* **Event Rating**: This question asks you to rate your overall experience with the event. Please choose one of the four options: Option 1, Option 2, Option 3, or Option 4.
* **Feedback**: This is an optional text field for you to provide any thoughts, suggestions, or comments about the event. You can write as much or as little as you like.

## Tips

* Please be honest and thorough in your answers, as this information will help us improve future events.
* If you are unsure about any question, please ask a colleague for help or contact us directly.
* You can only submit this form once, so please complete it in one sitting.
