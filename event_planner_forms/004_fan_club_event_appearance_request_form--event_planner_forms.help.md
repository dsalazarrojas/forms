# Fan Club Event Appearance Request Form - Help Guide

## Purpose
This form is designed for event planners to request specific events or appearances from a fan club. It allows event planners to gather information about the event and send a request to the fan club.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully to ensure you are requesting the correct event or appearance details.
2. Fill in the required fields accurately, such as event details.
3. Select relevant options from the dropdown menus when applicable.
4. Double-check your answers before submitting the form.

## Field-by-Field Explanation

* **Event Planner Forms** (event_planner_forms): This field is intended for event planners to enter their name or ID for record-keeping purposes. Enter your name or ID in this text field.
* **Event Planner** (event_planner_forms_2): Similar to the previous field, enter your event planning credentials or name for record-keeping purposes.
* **Planner** (event_planner_forms_3): Enter your event planning information or name.
* **Forms** (event_planner_forms_4): Select "Yes" if you want the fan club to send you a form for each event. Select "No" if you do not want to receive a form for each event.
* **Event Planner Forms 5** (event_planner_forms_5): This field is intended to ask if you want the fan club to send you multiple forms for the event. Select "Yes" if you want multiple forms, "No" otherwise.
* **Event** (event_planner_forms_6): Select "Yes" if you want the fan club to consider your request for an event.
* **Event Planner Forms 7** (event_planner_forms_7): This field is intended to be a date field for event planning purposes. Enter the date of the event you're requesting.
* **Event Planner Forms 8** (event_planner_forms_8): This field is intended to be a time field for event planning purposes. Enter the time of the event you're requesting.
* **Request Form** (event_planner_forms_9): Enter the date you want to request the fan club to send you a form for.
* **Request** (event_planner_forms_10): This field is intended to be a time field for requesting a form from the fan club. Enter the time you want to request the form.
