# Event Recording Form - Help Guide
## Purpose
The Event Recording Form is used to record new events, providing a standardized way to document and track event details.

## How To Complete This Form
1. Fill out the form with the required and optional information for the event being recorded.
2. Enter the speaker's name and role in the respective fields.
3. Select the recording method (audio, video, or both) from the dropdown menu.
4. Enter any relevant notes or descriptions for the speaker and event.
5. If applicable, upload any associated files (video, audio, or image).

## Field-by-Field Explanation
* **form_1_label**: This is the title of the form, which will serve as the event title. (text, required)
* **speaker_name**: Enter the name of the speaker who delivered the event. (text, required)
* **speaker_role**: Specify the role or position of the speaker. (text, optional)
* **event_date**: Enter the date of the event in YYYY-MM-DD format. (date, optional)
* **event_start_time** and **event_end_time**: Enter the start and end times of the event in 24-hour format (HH:MM). (time, optional)
* **event_recording_method**: Select the method of recording (audio, video, or both). (select_one, optional)
* **speaker_notes**: Enter any additional notes or information about the speaker. (text, optional)
* **event_notes**: Enter any additional notes or descriptions for the event. (text, optional)
* **event_location**: Enter the location of the event. (text, optional)
* **event_status**: Select the status of the event (pending, completed, or cancelled). (select_one, optional)
* **event_recorder**: Enter the name of the person who recorded the event. (text, optional)
* **email**: Enter the email address of the person who recorded the event. (email, optional)
* **phone**: Enter the phone number of the person who recorded the event. (text, optional)
* **file**: Upload any associated files (video, audio, or image). (note, optional)
* **file_type**: Select the type of file (video, audio, or image). (select_multiple, optional)
* **file_url**: Enter the URL of the file. (text, optional)
* **file_size**: Enter the size of the file in bytes. (number, optional)
* **file_duration**: Enter the duration of the file in seconds. (number, optional)
* **file_description**: Enter a brief description of the file. (text, optional)
* **speaker_notes_2**: Enter any additional notes or information about the speaker. (text, optional)
* **event_id**: Enter the ID of the event. (text, optional)
* **event_name**: Enter the name of the event. (text, optional)
* **event_date_2**: Enter the date of the event in YYYY-MM-DD format. (date, optional)
* **event_time**: Enter the time of the event in 24-hour format (HH:MM). (time, optional)

**Tips**

* Make sure to fill out all required fields.
* Use descriptive text for file descriptions.
* Ensure that the form is completed accurately and thoroughly.
* If you're unsure about any field, refer to the form's purpose and the provided explanations above.
