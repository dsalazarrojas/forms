# Secret Santa Form - Help Guide
## Purpose
This form helps you plan and track your Secret Santa gifts. Fill it out to specify who you would like to gift, how much you'd like to spend, and if you'd like to include a card or a monetary value for your gift.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill in your desired gift recipient's name in the "Gift Recipient" field.
2. Enter the value you'd like to spend on the gift in the "Gift Value" field.
3. If you'd like to include a gift card, type in its value in the "Card Value" field.
4. You can add a personal message in the "Message" field, if you'd like.

## Field-by-Field Explanation
* **Gift Recipient** (`Gift Recipient`, `text`, optional): Enter the name of the person you'd like to gift.
* **Gift Value** (`gift_value`, `number`, optional): Specify the value you'd like to spend on the gift. This will help your gift-giver know how much to budget.
* **Gift Card** (`gift_card`, `text`, optional): If you'd like to give a gift card, type in its value here.
* **Card Value** (`card_value`, `number`, optional): If you've chosen to include a gift card, enter its value in this field.
* **Message** (`message`, `note`, optional): A personal message for your gift-giver to know how much you appreciate them.

## Tips
* Make sure to fill out all required fields or you won't be able to submit your form.
* If you're not sure about any field, just let your gift-giver know you're still deciding or provide an estimate.
* This form is meant for internal use, so please keep sensitive information private.
