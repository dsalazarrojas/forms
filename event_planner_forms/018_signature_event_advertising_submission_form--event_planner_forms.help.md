# Signature Event Advertising Submission Form - Help Guide
## Purpose
This guide is to assist users in filling out the Signature Event Advertising Submission Form. The form is designed to collect information for event advertising purposes.

## How To Complete This Form
1.  Scroll through the form and fill out each section accordingly.
2.  Ensure that all required fields are filled out completely.
3.  Review the form for accuracy before submitting.

## Field-by-Field Explanation
### Event Name
*   **Event Name** (`event_name`, text, required: false): Enter the name of the event.
    Please fill out the name of the event as it will be displayed for advertising purposes.

### Ad Type
*   **Ad Type** (`ad_type`, select_one, required: false): This is the type of advertisement you would like to promote. Please select one of the available options from the dropdown list.
    Please select the type of ad that best suits your event.

### Event Location
