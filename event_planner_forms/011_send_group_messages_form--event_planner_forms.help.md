# Send Group Messages Form - Help Guide
## Purpose
The Send Group Messages Form is used to send messages to a group of people, allowing you to communicate with a selected group of recipients.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the desired recipient from the "Select Recipient" dropdown menu.
2. Enter your message in the "Message" field.
3. Enter the detailed message body in the "Message Body" field.
4. Set the date when you want to send the message.
5. Click "Submit" to send the message.

## Field-by-Field Explanation
* **Select Recipient** (`recipient`, select_one, required: false): This field allows you to choose the recipient(s) you want to send the message to. Select the correct option that matches your intended recipient.
* **Message** (`message`, text, required: false): This field is for entering the main message you want to send to the recipient(s). Enter the content of the message you want to send.
* **Message Body** (`message_body`, text, required: false): This field is for entering the detailed content of the message. Enter any additional information you want to include with the message.
* **Send By Date** (`date`, date, required: false): This field is for setting the date when you want to send the message. Enter the date in the format MM/DD/YYYY. 

## Tips
* Make sure to select the correct recipient and enter the correct message details before submitting the form.
* Double-check the form for any errors before sending the message.
* You can adjust the "Send By Date" field to schedule the message to be sent on a specific date in the future.
* If you are not sending the message immediately, make sure to save the form so that you can return to it and complete it later.
