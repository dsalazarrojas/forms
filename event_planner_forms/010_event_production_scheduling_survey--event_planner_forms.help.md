# Event Production Scheduling Survey - Help Guide
## Purpose
This form is used to collect information from event planners on their production schedules and resource needs for upcoming events. It helps the event production team plan and prepare for the events.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each page carefully to ensure you have all the necessary information before proceeding to the next page.
2. Answer each question to the best of your ability.
3. If you're unsure about any question, refer to the instructions provided.

## Field-by-Field Explanation
### Main Page
* **Title (Page 1)**: Enter the title of the event you are planning.
* **Page 2 (Optional)**: Enter any additional information or notes about the event.
* **Event Details**: Enter details about the event, such as date and time.
* **Event Preferences**: Enter any specific preferences or requirements for the event.
* **Page 3 (Optional)**: Enter any additional information or notes about the event.

### Page 2
* **Page 2 (Page 2)**: This page is optional and provides space for you to enter any additional information about the event.

### Page 3
* **Page 3 (Page 3)**: This page is optional and provides space for you to enter any additional information about the event.

### Resources Needed (Page 4)
* **Resources Needed**: Choose all the resources you will need for the event from the list.
*   • Yes: You will need resources for this event.
*   • No: You will not need resources for this event.

### Page 4
* **Page 4 (Page 4)**: This page is optional and provides space for you to enter any additional information about the event.

### Event Planner (Page 5)
* **Event Planner**: Choose the event planner responsible for this event.
*   • Yes: You are the event planner for this event.
*   • No: Someone else is the event planner for this event.

### Resources Available (Page 6)
* **Resources Available**: Choose all the resources you have available for the event from the list.
*   • Yes: You have these resources available for the event.
*   • No: You do not have these resources available for the event.

### Page 5
* **Page 5 (Page 5)**: This page is optional and provides space for you to enter any additional information about the event.
