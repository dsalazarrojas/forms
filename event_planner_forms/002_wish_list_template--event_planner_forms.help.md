# Wish List Template - Help Guide
## Purpose
The Wish List Template is a general-purpose form used to gather information about an event from the end-user. It's designed to be completed by the person organizing or hosting the event.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill in the "What do you desire?" field with a brief description of what you're hoping to achieve or accomplish with the event.
2. Provide your contact information in the "Contact Info" and "Contact Phone" fields.
3. Choose an option from the "Event Details" field that best describes the type of event you're planning.
4. Select a date and time for the event in the "Event Date" and "Event Time" fields.
5. Choose the location for the event from the "Location" field.
6. Provide any additional information about the event in the "Additional Information" field.

## Field-by-Field Explanation
* **What do you desire?** (`user_preferences`, `text`, optional): This field is a free-text area where you can describe what you're hoping to achieve or accomplish with the event.
* **Contact Info** (`contact_info`, `email`, optional): Enter your email address so that we can contact you about the event.
* **Contact Phone** (`contact_phone`, `text`, optional): Provide your phone number so that we can reach you about the event.
* **Event Details** (`event_details`, `select_one`, required): Choose from the options to describe the type of event you're planning (e.g., Conference, Workshop, Meeting).
* **Event Date** (`event_date`, `date`, optional): Select the date for the event.
* **Event Time** (`event_time`, `time`, optional): Choose the time of the event.
* **Location** (`location`, `select_multiple`, optional): Select the location for the event from the available options.
* **Additional Information** (`additional_info`, `text`, optional): Provide any extra details about the event that may be helpful to know.

## Tips
* Make sure to fill out all required fields to ensure that we have enough information to plan your event.
* If you have any special requests or requirements for your event, include them in the "Additional Information" field.
* If you need help with anything, don't hesitate to reach out to us.
