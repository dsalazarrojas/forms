# RSVP Form - Help Guide
## Purpose
This RSVP Form is designed to help event planners and organizers collect RSVPs from attendees for upcoming events. It's a simple and straightforward form that gathers essential information to keep track of guest confirmations and provide a clear picture of event attendance.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the event in the **Event Name** field. This field is used to identify the event for which you're RSVPing.
2. Select **Yes** or **No** in the **Guest List** field to indicate whether you will be attending the event with guests.
3. Enter the **Date** of the event in the format MM/DD/YYYY. If the event spans multiple dates, enter the start date.
4. Select the **Time** of the event in the format HH:MM. If the event spans multiple time slots, choose the start time.
5. Choose your **RSVP Status** by selecting one of the four options provided. This helps the event planner know your availability and intentions.
6. Add any additional **Notes** you'd like to share with the event planner in the text area. This is a great place to mention any specific accommodations or requests you have.
7. Enter your **Email** address so that the event planner can contact you with updates and reminders.
8. If you'd like to provide your **Phone Number**, you can enter it here. This helps the event planner reach you with last-minute updates or changes.

## Field-by-Field Explanation
* **Event Name** (1, text, required/optional): Enter the name of the event, e.g., "Summer BBQ" or "Conference 2023".
* **Guest List** (2, select_multiple, required/optional): Choose **Yes** if you will be attending with guests, or **No** if you'll attend alone.
* **Date** (3, date, required/optional): Enter the date of the event in MM/DD/YYYY format, e.g., 06/17/2024.
* **Time** (4, time, required/optional): Select the start time of the event in HH:MM format, e.g., 14:00.
* **RSVP Status** (5, select_one, required/optional): Choose one of the four options to indicate your availability:
	+ Option 1: Attending
	+ Option 2: Maybe
	+ Option 3: Regretfully Declined
	+ Option 4: Unable to Attend
* **Notes** (6, note, required/optional): Add any additional comments or requests you'd like to share with the event planner.
* **Email** (7, email, required/optional): Enter your email address so the event planner can contact you with updates.
* **Phone Number** (8, text, required/optional): Provide your phone number if you'd like to receive phone updates or reminders.
