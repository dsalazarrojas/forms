# Wedding Appointment Request Form - Help Guide

## Purpose
The Wedding Appointment Request Form is a tool used to submit a wedding event request to our team of event planners. This form captures all necessary information to create an accurate record of the event and assign a tool to handle it.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields, indicated by <strong>Required</strong> in the field label.
2. Select the correct service provider option from the dropdown menu for Service Provider.
3. Enter accurate contact information to ensure we can reach out to you with any further questions or updates.
4. Double-check your submission for accuracy and completeness before submitting.

## Field-by-Field Explanation

* **Request Date** (`request_date`): Date of the wedding event.
	+ Use the date format MM/DD/YY (e.g., 02/15/2022 for February 15, 2022).
* **Start Time** (`start_time`): Start time of the wedding event.
	+ Use the time format HH:MM AM/PM (e.g., 2:00 PM for 2 o'clock in the afternoon).
* **End Time** (`end_time`): End time of the wedding event.
	+ Use the time format HH:MM AM/PM (e.g., 5:00 PM for 5 o'clock in the afternoon).
* **Service Provider** (`service_provider`): Select the service provider you would like to handle your wedding event.
* **Service Details** (`service_details`): Briefly describe the services you need from us for your wedding event.
* **Location** (`service_location`): Enter the location of the wedding event.
* **Contact Name** (`contact_name`): Enter the name of the contact person handling this request.
* **Contact Info** (`contact_info`): Enter any additional contact information, such as phone numbers or email addresses.
* **Request Reason** (`request_reason`): Briefly describe the reason for your wedding event request.
* **Wedding Date** (`wedding_date`): Date of the wedding event.
	+ Use the date format MM/DD/YY (e.g., 02/15/2022 for February 15, 2022).
* **Wedding Time** (`wedding_time`): Time of the wedding event.
	+ Use the time format HH:MM AM/PM (e.g., 2:00 PM for 2 o'clock in the afternoon).
* **Contact Email** (`contact_email`): Enter the email address of the contact person.
* **Contact Phone** (`contact_phone`): Enter the phone number of the contact person.
* **Assigned Tool** (`assigned_tool`): Select the tool you would like to be assigned to handle your wedding event.
* **Submitted By** (`submitted_by`): Select who is submitting this request (Couple or Service Provider).
* **Submitted Date** (`submitted_date`): Date the request was submitted.
	+ Use the date format MM/DD/YY (e.g., 02/15/2022 for February 15, 2022).
* **Submitted Time** (`submitted_time`): Time the request was submitted.
	+ Use the time format HH:MM AM/PM (e.g., 2:00 PM for 2 o'clock in the afternoon).

Please ensure you have filled out all required fields accurately and completely before submitting this form. If you have any questions or concerns, please don't hesitate to contact us.

## Tips

* Double-check all information before submitting the form.
* Enter dates in the format MM/DD/YY.
* Select the correct service provider from the dropdown menu.
* Enter correct contact information to ensure we can reach out to you with any further questions or updates.
* Review the form carefully before submitting to ensure accuracy and completeness.
* Contact us if you have any questions or concerns.
