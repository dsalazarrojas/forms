# Baby Shower Invitation Form - Help Guide
## Purpose
This form is used to collect information for a baby shower celebration, specifically for the host to plan and invite guests. Please ensure you have the necessary permissions and approvals before sharing this form with others.

## How To Complete This Form
1. Fill in your details in the first 5 fields: Host Name, Host Email, Host Phone, Honoree Name, and Partner Name (if applicable).
2. Choose the baby's gender and date of the celebration in the subsequent fields.
3. Enter the celebration time, location, and full address of the venue.
4. Set a reasonable RSVP deadline and select a suitable response method for guests.
5. Optionally, provide a gift registry link or mention the dress code and any special requests, such as dietary needs or accessibility requirements.
6. Decide on the invitation style preference and add a personal message if desired.
7. Finally, review all the fields carefully to ensure all information is accurate and complete.

## Field-by-Field Explanation
* **Host Name**: Enter the name of the host or person planning the celebration.
* **Host Email**: Provide the contact email where guests can RSVP.
* **Host Phone**: Enter the contact phone number for any questions or inquiries.
* **Honoree Name**: Name of the expectant parent.
* **Partner Name**: Name of the partner, if the honoree has one.
* **Baby Gender**: Select the known or desired baby gender.
* **Shower Date**: Enter the date of the celebration.
* **Shower Time**: Enter the start and end time of the celebration.
* **Location Name**: Enter the venue name or the host's home.
* **Full Address**: Provide the street address of the venue.
* **City and State**: Enter the city, state, and ZIP code of the venue.
* **RSVP Deadline**: Set a reasonable deadline for guests to respond.
* **RSVP Method**: Select the suitable response method for guests (e.g., phone call, text message, email, online form, or mail response card).
* **Gift Registry**: If the honorees are registered, provide the link.
* **Dress Code**: Select the dress code preference (e.g., casual, semi-formal, formal, themed).
* **Special Requests**: Describe any special requests, such as dietary needs or accessibility requirements.
* **Additional Guests Policy**: Decide on the policy for guests bringing plus ones (e.g., only invited guests, plus ones welcome, children welcome, adults only).
* **Parking Information**: Provide any parking instructions or information.
* **Personal Message**: Enter a special note or message to include with the invitation.
* **Invitation Style Preference**: Select the desired design theme for the invitation (e.g., classic and elegant, fun and playful, modern and minimal, rustic, floral, character theme).
