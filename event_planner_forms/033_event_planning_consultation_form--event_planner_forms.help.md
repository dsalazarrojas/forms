# event_planning_consultation_form - Help Guide
## Purpose
This form is designed to collect event planning details for consultation purposes. It's meant to gather information about an event, including its title, location, date and time, venue, description, type, and contact person and contact information. This form is used to facilitate communication and collaboration among event planners and stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event title in the "Event Details" field.
2. Provide the event location in the "Event Location" field.
3. Select the event date in the "Event Date" field using the date picker.
4. Choose the event time in the "Event Time" field using the time picker.
5. Enter the event venue in the "Event Venue" field.
6. Write a brief description of the event in the "Event Description" field.
7. Select the type of event from the options provided in the "Event Type" field.
8. Enter the contact person's name in the "Contact Person" field.
9. Enter the contact person's email address in the "Contact Email" field.
10. Enter the contact person's phone number in the "Contact Phone" field.

## Field-by-Field Explanation

* **Event Details** (`title`, text, false): Enter a brief title of the event to give a clear understanding of what it's about.
* **Event Location** (`event_location`, text, false): Provide the physical address or location where the event will take place.
* **Event Date** (`event_date`, date, false): Choose the date of the event using the calendar picker.
* **Event Time** (`event_time`, time, false): Select the time of the event using the time picker.
* **Event Venue** (`event_venue`, text, false): Enter the name of the venue or location where the event will take place.
* **Event Description** (`event_description`, text, false): Write a brief description of the event, including its purpose and main highlights.
* **Event Type** (`event_type`, select_one, false): Select the type of event from the options provided:
	+ Wedding
	+ Conference
	+ Party
* **Contact Person** (`contact_person`, text, false): Enter the name and surname of the person responsible for the event.
* **Contact Email** (`contact_email`, email, false): Enter the email address of the person responsible for the event.
* **Contact Phone** (`contact_phone`, text, false): Enter the phone number of the person responsible for the event.

Tips:
* Make sure to enter accurate and correct information for each field to ensure successful communication and coordination.
* Double-check the date and time fields for correct formatting and consistency.
* Use a descriptive event description to help others understand the event's purpose and scope.
* Select the correct event type to help others identify the event's nature.
