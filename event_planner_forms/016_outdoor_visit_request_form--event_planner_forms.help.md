# Outdoor Visit Request Form - Help Guide

## Purpose
This form is used to request a visit to a specific event. It captures visitor details, event information, and any additional notes or messages that need to be shared.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Review each field for any additional guidance or hints that can help you complete it correctly.
3. Submit the form once all fields have been filled out.

## Field-by-Field Explanation

* **Visitor Details** (visitor_details): This is the first step in filling out the form. Enter any additional details about the visitor.
* **Visitor Name** (visitor_name): Enter the visitor's name.
* **Visitor Phone** (visitor_phone): Enter the visitor's phone number.
* **Visitor E-mail** (visitor_email): Enter the visitor's email address.
* **Event Date** (event_date): Enter the date of the event the visitor is interested in visiting.
* **Visit Time** (visit_time): Enter the time of the event the visitor is interested in visiting.
* **Event Type** (event_type): Choose whether the event is a 'Yes' or 'No' by selecting one of the options provided in the dropdown menu.
* **Event Venue** (event_venue): Choose whether the event will take place at 'Yes' or 'No' by selecting one of the options provided in the dropdown menu.
* **Event Description** (event_description): Enter a brief description of the event.
* **Visitor Message** (visitor_message): Enter any additional notes or messages that need to be shared with the visitor.
* **Visitor Message Hint** (visitor_message_hint): This is a hint to help you fill out the visitor message.

## Tips
* Make sure to double-check the accuracy of all information provided before submitting the form.
* If any field is not applicable, simply leave it blank.
* If you have any further questions or need clarification on any of the fields, feel free to ask.
