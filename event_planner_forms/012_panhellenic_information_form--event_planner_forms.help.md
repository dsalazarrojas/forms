# Panhellenic Information Form - Help Guide

## Purpose

This form is designed to collect information about Panhellenic events. It is essential to provide accurate and up-to-date details about each event to ensure smooth planning and execution.

## How To Complete This Form

1. Fill out the form carefully, ensuring that all required fields are completed.
2. Use the "Event Type" field to select the type of event.
3. Enter the "Date" and "Time" fields with the correct dates and times for the event.
4. Provide the event location in the "Event Location" field.
5. Enter a brief description of the event in the "Event Description" field.
6. If relevant, select the themes or interests associated with the event in the "Event Theme" and "Interested in Theme" fields.
7. Confirm that the event has occurred by selecting the correct "Last Event Date" and "Last Event Time" fields.
8. Review and correct any errors before submitting the form.

## Field-by-Field Explanation

* **First Name (id: 1)**: Enter the first name of the event's primary contact person.
* **Last Name (id: 2)**: Enter the last name of the event's primary contact person.
* **Email (id: 3)**: Enter the email address of the event's primary contact person.
* **Phone (id: 4)**: Enter the phone number of the event's primary contact person.
* **Event Type (id: 5)**: Select the type of event (Yes/No).
* **Date (id: 6)**: Enter the date of the event (mm/dd/yyyy).
* **Time (id: 7)**: Enter the time of the event (hh:mm).
* **Event Location (id: 8)**: Enter the location of the event.
* **Event Description (id: 9)**: Enter a brief description of the event.
* **Event Details (id: 10)**: Enter additional details about the event in this notes field.
* **Last Event Date (id: 11)**: Enter the date of the last event.
* **Last Event Time (id: 12)**: Enter the time of the last event.
* **Interested In (id: 13)**: Select the interests associated with the event (Yes/No).
* **Event Theme (id: 14)**: Select the theme associated with the event (Yes/No).
* **Interested in Theme (id: 15)**: Select the themes associated with the event (Yes/No).
* **Form Data 16 (id: 16)**: Select the theme associated with the event (Yes/No).
* **Form Data 17 (id: 17)**: Select the theme associated with the event (Yes/No).
* **Form Data 18 (id: 18)**: Select the themes associated with the event (Yes/No).
* **Last Event Theme (id: 19)**: Select the theme associated with the last event (Yes/No).

Please review the form carefully and ensure that all fields are completed accurately. If you have any doubts or questions, please reach out to the event planner for assistance.
