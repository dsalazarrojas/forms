# Virtual Class Reunion Form - Help Guide

## Purpose
This form is designed to gather information from classmates for a virtual class reunion.

## How To Complete This Form
To complete this form, follow the steps outlined above.

## Field-by-Field Explanation
*   **First name** (Text, Optional): Enter your first name.
*   **Last name** (Text, Optional): Enter your last name.
*   **Email** (Email, Optional): Enter your email address.
*   **Phone** (Text, Optional): Enter your phone number.
*   **Event date** (Date, Optional): Enter the date of the virtual class reunion.
*   **Event time** (Time, Optional): Enter the time of the virtual class reunion.
*   **Event duration** (Number, Optional): Enter the duration of the virtual class reunion in minutes.
*   **Class year** (Number, Optional): Enter the year you graduated.
*   **School name** (Text, Optional): Enter the name of your school.
*   **School location** (Text, Optional): Enter the location of your school.
*   **Classmates invited** (Select Multiple, Optional): Indicate if you have invited any classmates to the virtual class reunion.
*   **Event details** (Note, Optional): Enter any additional details about the virtual class reunion.
*   **Additional comments** (Text, Optional): Enter any additional comments about the virtual class reunion.

## Tips
Complete the form accurately and thoroughly. If you have any questions or concerns, feel free to contact the event planner.
