# First Time Attendee Survey - Help Guide

## Purpose

This form is designed to gather information from first-time attendees of an event. The goal is to understand how they found out about the event, what motivated them to attend, and what they think could be improved. The collected data will help us better understand our audience's preferences and tailor future events accordingly. 

## How To Complete This Form

To complete this form, please follow these steps:

1. Select the answer that best describes how you heard about this event. 
2. Choose the reason that brought you to this event.
3. If you have any thoughts on what would improve this event, select all that apply.
4. Enter your email address.
5. If you want to share any additional comments, please enter or type them in the space provided.

## Field-by-Field Explanation

* **First Time Attending**: A numerical indicator of whether this is your first time attending this event. 
* **How did you hear about this event**: Select all the methods you heard about this event. This can include:
	+ Event Planner (e.g., through our website or social media)
	+ Social Media (e.g., through Facebook or Twitter)
	+ Word of Mouth (e.g., recommendations from friends or colleagues)
	+ Option 4 (Other)
* **What brought you to this event**: Select the reason that motivated you to attend this event. This can be:
	+ I wanted to see a specific presenter
	+ I wanted to meet specific people
	+ I wanted to attend a specific session
	+ Other
* **What will happen next?**: This field is optional, but if you have any thoughts on what you think will happen next at the event, please select one of the options provided or type something else in the space provided. This can be:
	+ Nothing
	+ Maybe a follow-up session
	+ I'll attend goals
	+ Other
* **What will improve this event?**: Select all the options that you think would improve this event. This can include:
	+ Better location
	+ Better food
	+ More variety of sessions
	+ Other
* **Email**: Enter your email address so we can contact you if needed.
* **Phone**: Enter your phone number so we can contact you if needed.
* **Comments**: If you have any thoughts or comments about this event, please enter them here.
* **Additional Comments**: If you have any additional comments or thoughts, please enter them here.
