# Event Planning Survey - Help Guide
## Purpose
This form is designed to gather information about an event, allowing you to collect details such as event name, guests, venue, dates, time, location, and description. The form is meant to be a simple and straightforward way to plan and organize events.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the Event Details page, which includes fields for event name, venue, and description.
2. Proceed to the Guests page, where you can select the guests you want to invite.
3. On the Dates page, choose the dates for your event from the available options.
4. Move on to the Time page, where you can select the time for your event.
5. Next, provide the location of your event.
6. Finally, review and submit your event details.

## Field-by-Field Explanation

* **Event Details** (event_planning_survey_1): Enter the name of the event and any additional details you'd like to include about the event.
* **Guests** (event_planning_survey_2): Select all the guests you want to invite to the event. You can choose as many or as few guests as needed.
* **Venue** (event_planning_survey_3): Enter the location where the event will take place.
* **Dates** (event_planning_survey_4): Choose one of the available options for the event dates.
* **Time** (event_planning_survey_5): Enter the start and end time of the event in 24-hour format (e.g., 14:00 for 2 PM).
* **Location** (event_planning_survey_6): Enter the full address of the event location.
* **Description** (event_planning_survey_7): Provide a brief description of the event, including any relevant details or instructions for the guests.
