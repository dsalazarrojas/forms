# League Event Credential Printing Order Form - Help Guide
## Purpose
This form is used to order League Event Credentials for printing and delivery. It is designed to collect information about an event, select the type of credential, and specify print details and delivery instructions.

## How To Complete This Form
1. To start, fill in the "Event Name" field with the name of the event you are ordering credentials for.
2. Select the type of event from the "Event Type" dropdown list that best describes the event.
3. If necessary, specify the quantity of credentials you need printed.
4. If applicable, enter the URL for an associated artwork or image.
5. Choose the method of delivery from the "Delivery Method" list.
6. Select the type of credential you need printed from the "Credential Type" dropdown list.
7. Enter any additional print instructions or information in the "Print Info" field.
8. Select a date and time for delivery.

## Field-by-Field Explanation
* **Event Name**: The name of the event for which you are ordering credentials.
* **Event Type**: The type of event (e.g. conference, meet-and-greet, etc.).
* **Quantity**: The number of credentials you need printed. 
* **Artwork URL**: The URL of an associated artwork or image. This field is optional.
* **Delivery Method**: The method of delivery for the credentials. Options include [Delivery Method 1, Delivery Method 2, Delivery Method 3].
* **Credential Type**: The type of credential you need printed (e.g. certificate, badge, etc.). 
* **Print Info**: Any additional information about the print that you would like to include.
* **Delivery Date**: The date you would like the credentials to be delivered.
* **Delivery Time**: The time you would like the credentials to be delivered.
