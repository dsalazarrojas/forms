# Event Completion Report Form - Help Guide
## Purpose

This guide will walk you through the Event Completion Report Form. The form is used to report the status of completed events, providing valuable insights for event planners to improve future event planning and management.

## How To Complete This Form

1. **Fill in the title**: Enter a brief title of the event that you are reporting on.
2. **Select start and end dates**: Enter the start and end dates of the event.
3. **Describe the event**: Provide a brief description of the event, including any notable details or outcomes.
4. **Leave feedback**: Share any feedback or comments about the event, including any areas that could be improved.
5. **Document future planning efforts**: Outline any plans or actions you will take to improve or build upon the event in the future.
6. **Mark event status**: Select the current status of the event from the options provided.

## Field-by-Field Explanation

* **Title** (Required): A brief title of the event.
* **Start Date** (Required): The date the event started.
* **End Date** (Required): The date the event ended.
* **Description** (Optional): A detailed description of the event, including any notable details or outcomes.
* **Feedback** (Optional): Share any feedback or comments about the event, including any areas that could be improved.
* **Areas for Improvement** (Optional): Outline any plans or actions you will take to improve or build upon the event in the future.
* **Future Planning Efforts** (Optional): Document any plans or actions you will take to improve or build upon the event in the future.
* **Event Completion Status** (Required): Select the current status of the event from the options provided:
	+ **Completed**: The event has been fully completed and concluded.
	+ **In Progress**: The event is still ongoing and not yet completed.
	+ **Cancelled**: The event was cancelled before completion.

## Tips

* Make sure to provide accurate information for the start and end dates.
* Be thorough when describing the event and providing feedback.
* Consider sharing lessons learned and areas for improvement to help inform future event planning and management decisions.
