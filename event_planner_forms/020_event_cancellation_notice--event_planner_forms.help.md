# event-cancellation-notice - Help Guide
## Purpose
The "event-cancellation-notice" form is designed to provide notice to attendees, stakeholders, and venues in the event of an event cancellation, postponement, or rescheduling.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the reason for the event cancellation from the list provided (Event Cancelled, Postponed, Rescheduled, or Other).
2. Provide a brief explanation for the event cancellation.
3. Select the stakeholders you want to notify (email, phone, or in-person) and the venue (True or False).
4. Add any additional documentation or notes related to the cancellation.
5. Click "Submit" to send the form.

## Field-by-Field Explanation

* **Event Notice** (`event_notice`, `text`, required/optional): This field is for you to enter a brief notice about the event cancellation.
* **reason** (`reason`, `select_one`, required): Select the reason for the event cancellation (Event Cancelled, Postponed, Rescheduled, or Other).
* **explanation** (`explanation`, `text`, required/optional): Provide a detailed explanation for the event cancellation.
* **Notify Stakeholders** (`stakeholders_notify`, `select_multiple`, required): Choose how you want to notify stakeholders (email, phone, or in-person).
* **Notify Venue** (`venue_notify`, `select_multiple`, required): Indicate whether you want to notify the venue or not (True or False).
* **Documentation** (`documentation`, `note`, required): Add any additional documentation or notes related to the cancellation.
* **Other Notes** (`other_notes`, `text`, required/optional): Add any other relevant notes or information about the event cancellation.
* **Submit** (`submit`, `text`, required/optional): Click this field to send the form.

## Tips
- Ensure you have the necessary information and approvals before completing this form.
- Double-check the selected options to ensure accuracy.
- Keep the explanation concise and clear to avoid confusion.
- Use this form as a template to adjust and customize according to your specific event needs.
