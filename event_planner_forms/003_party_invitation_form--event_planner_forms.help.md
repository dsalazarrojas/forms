# Party Invitation Form - Help Guide
## Purpose
This party invitation form is designed to collect information for a successful and enjoyable party event.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the event title in the "Host Information" field.
2. Provide general information about the event in the "General Information" field.
3. Enter the guest's contact information in the "Guest Information" field.
4. Add any additional contact information in the "Contact Information" field.
5. Specify the party details such as event type, number of guests, host, email, phone, address, and description.
6. Enter the event date and time in the "Event Date" and "Event Time" fields.
7. Enter the location of the event in the "Location" field.
8. Add any additional information or notes in the "Additional Information" field.
9. Click "Submit" to finalize the form and save the event information.

## Field-by-Field Explanation
* **Event Type** (`event_type`): Select the type of event (Dinner Party, Pool Party, Baby Shower, or Housewarming Party).
* **Date** (`event_date`): Enter the date of the event.
* **Time** (`event_time`): Enter the start and end time of the event.
* **Guest Count** (`guests`): Enter the number of guests expected.
* **Host** (`host`): Enter the host's name.
* **Contact Information** (`contact_info`): Enter any additional contact information such as phone number or address.
* **Address** (`address`): Enter the event location's address.
* **Description** (`description`): Enter a brief description of the event.
* **Location** (`location`): Enter the physical location of the event.
* **URL** (`url`): Enter any URL related to the event.
* **Note** (`note`): Add any additional notes or information about the event.
* **Event End Date** (`end_date`): Enter the end date of the event.
* **Event End Time** (`end_time`): Enter the end time of the event.
* **End Repeat** (`end_repeat`): Enter the repeat status of the event (if applicable).
* **General Information** (`form_group`): Enter any general information about the event.
* **Guest Information** (`guest_info`): Enter any guest-specific information.
* **Host Information** (`host_info`): Enter any host-specific information.
* **Additional Information** (`additional_info`): Enter any additional information.
* **Submit** (`submit`): Click to finalize and save the form.

## Tips
* Make sure to fill out all required fields to ensure the form is complete and accurate.
* Use the correct event type to ensure the event information is categorized correctly.
* Double-check the event date and time to ensure they are correct.
* Be sure to enter a valid phone number and email address for the contact information.
* Use a clear and concise description of the event to help guests understand what to expect.
* Proofread the form for any typos or errors before submitting.
