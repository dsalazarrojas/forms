# corporate_group_conference_registration_form - Help Guide

## Purpose
This form is designed to gather all the necessary information for planning and organizing a corporate group conference. It covers various aspects of the conference, including user information, conference details, and billing information.

## How To Complete This Form
To complete this form, please follow these steps:

* Review the form carefully and ensure you have all the necessary information before starting to fill it out.
* Fill out each section of the form, one page at a time.
* Make sure to review your answers carefully before submitting the form.

## Field-by-Field Explanation

* **User Info** (1, text, optional): This section is for providing basic user information such as name and contact details.
* **Conference Info** (2, text, optional): This section is for providing general conference information such as the conference title and description.
* **Registration Info** (3, text, optional): This section is for collecting registration information such as the number of attendees and their contact details.
* **Group Details** (4, text, optional): This section is for providing details about the group such as their interests and requirements.
* **Billing Info** (5, text, optional): This section is for collecting billing information such as the payment method and amount.
* **Contact Details** (6, text, optional): This section is for providing contact details for the conference organizers and attendees.
* **Payment Details** (7, text, optional): This section is for providing payment details such as the payment method and amount.
* **Conference Details** (8, text, optional): This section is for providing additional conference details such as the agenda and speakers.
* **Conference Program** (9, text, optional): This section is for providing information about the conference program such as the schedule and activities.
* **Group Size** (10, number, optional): This section is for selecting the size of the group attending the conference.
* **Conference Fee** (11, number, optional): This section is for selecting the conference fee per attendee.
* **Conference Type** (12, select one, optional): This section is for selecting the type of conference such as in-house or external.
* **Other Conference Type** (13, text, optional): This section is for providing additional conference type details.
* **Start Date** (14, date, optional): This section is for selecting the start date of the conference.
* **Start Time** (15, time, optional): This section is for selecting the start time of the conference.
* **End Date** (16, date, optional): This section is for selecting the end date of the conference.
* **End Time** (17, time, optional): This section is for selecting the end time of the conference.
* **Duration** (18, number, optional): This section is for selecting the duration of the conference.
* **Location** (19, text, optional): This section is for selecting the conference location.
* **Address** (20, text, optional): This section is for providing the conference address.
* **Capacity** (21, number, optional): This section is for selecting the conference capacity.
* **Status** (22, select multiple, optional): This section is for selecting the conference status such as open, pending, or closed.

Note: The required field for each section is marked with an asterisk (\*).
