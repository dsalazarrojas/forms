# Event Planning Checklist Form - Help Guide

## Purpose
The Event Planning Checklist Form is designed to gather essential information about an event. This form helps event planners collect and organize crucial details about the event, such as its date, time, location, and organizer. By using this form, event planners can ensure that all necessary information is documented and easily accessible.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the event's details and provide information in the required fields. Note that some fields may be optional.
2. Enter the event's name and a brief description in the **Event Details** field.
3. Select the **Start Date** and **Start Time** fields to specify when the event will begin.
4. Select the **End Date** and **End Time** fields to specify when the event will end.
5. Enter the event's **Event Location** to provide its address or venue information.
6. Provide the event's **Event Organizer** name and contact information for further contact.

## Field-by-Field Explanation

### Event Details (Text)
* **Event Details (Event Details)**: Enter a brief description of the event, including its name and any other relevant details that will help others understand the purpose and scope of the event.

* **Start Date (Start Date)**: Select the date on which the event will start. Use the format YYYY-MM-DD.

* **Start Time (Start Time)**: Select the start time of the event in HH:MM format (e.g., 09:00 or 03:30).

* **End Date (End Date)**: Select the end date of the event. Use the format YYYY-MM-DD.

* **End Time (End Time)**: Select the end time of the event in HH:MM format (e.g., 11:00 or 05:00).

* **Event Location (Event Location)**: Enter the event's location, including the address or venue name.

* **Event Organizer (Event Organizer)**: Enter the name and contact information of the event's organizer. This will help attendees contact the organizer for further information.
