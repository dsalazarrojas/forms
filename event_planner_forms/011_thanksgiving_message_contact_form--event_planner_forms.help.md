# thanksgiving_message_contact_form - Help Guide
## Purpose
The "thanksgiving_message_contact_form" is a form used for sending messages or contact information related to event planning.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your name, which is your personal contact information.
2. Enter your email address for contact purposes.
3. Write your message or description of the event or activity.
4. If necessary, enter your phone number for further communication.
5. Select the tool assigned to this event or activity.
6. Choose the category for this event or activity.
7. If required, select "Yes" or "No" for the assigned tool and category.
8. Enter the date and time of the event or activity (if necessary).
9. Enter any additional notes or comments about the event or activity.
10. Click the "Submit" button to send the message or contact information.

## Field-by-Field Explanation

* **Name**: Enter your name for contact purposes.
* **Email**: Enter your email address for further communication.
* **Message**: Write a brief description or message about the event or activity.
* **Phone**: Enter your phone number if necessary for further communication.
* **Tool**: Select the tool assigned to this event or activity.
* **Category**: Choose the category for this event or activity.
* **Date**: Enter the date of the event or activity (if necessary).
* **Time**: Enter the time of the event or activity (if necessary).
* **Note**: Enter any additional notes or comments about the event or activity.
* **Submit**: Click this button to send the message or contact information.
* **Form ID**: Enter the ID of the form (if necessary).
* **Description**: Enter a brief description of the event or activity (if necessary).
* **Category ID**: Enter the ID of the category (if necessary).
* **Tool ID**: Enter the ID of the tool (if necessary).
* **Category**: Select "Yes" or "No" for the assigned category.
* **Tool**: Select "Yes" or "No" for the assigned tool.

## Tips

* Make sure to enter accurate and complete information for each field.
* If you are unsure about the tool or category assigned to you, please contact your supervisor or event planner.
* Use the "Submit" button to send the message or contact information only when you have completed all necessary fields.
