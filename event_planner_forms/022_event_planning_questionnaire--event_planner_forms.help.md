# event_planning_questionnaire - Help Guide
## Purpose
The event_planning_questionnaire form is designed to collect information for event planning purposes.

## How To Complete This Form
To complete this form, simply answer the questions and select relevant options for each field. You can move from page to page to access each field, and the fields are organized into pages to make navigation easier.

- **event_planning_questionnaire-page-3-label** (3, text, Optional): Enter any further information about the event.
