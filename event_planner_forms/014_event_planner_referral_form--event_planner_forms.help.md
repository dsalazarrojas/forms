# Event Planner Referral Form - Help Guide
## Purpose

This form is designed to collect contact information from event planners for referral purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your event planner's name in the "name" field.
2. Enter the email address of the event planner in the "email" field.
3. Optionally, enter any additional information in the "event_planner_referral_form" field if needed.

## Field-by-Field Explanation

* **event_planner_referral_form** (`event_planner_referral_form`, text, optional):
	+ This field is for any additional information the event planner wants to share about their services or referral.
* **name** (name, text, optional):
	+ Enter the name of the event planner.
* **email** (email, email, required):
	+ Enter the email address of the event planner. This will be used to follow up with them.
