# Bounce House Request Form - Help Guide
## Purpose
The Bounce House Request Form is designed for event planners to submit requests for bounce house rentals. This form helps our team quickly gather the necessary information to determine if we can fulfill your request and create a quote for the services.

## How To Complete This Form
To complete this form, simply follow these steps:

1.  Enter your first and last name.
2.  Enter your phone number and email address.
3.  Fill in your address.
4.  Select the type of event you are planning.
5.  Fill in the event date and times.
6.  Enter the location of the event.
7.  Choose the type of venue.
8.  Select the type of bounce house you prefer.
9.  Choose any theme preferences.
10.  Select the age range of the users.
11.  Enter the number of children expected.
12.  Enter the approximate space needed for the bounce house.
13.  If there is a power outlet nearby, select true or false.
14.  If a generator is needed, select true or false.
15.  Choose the preferred delivery time.
16.  Enter your budget range.
17.  Enter any additional requests or questions.
18.  Tell us how you heard about us.
19.  If you are ready to book, select yes or no.

## Field-by-Field Explanation
* **First Name**: Enter your first name.
* **Last Name**: Enter your last name.
* **Phone Number**: Enter your primary contact number.
* **Email Address**: Enter your email address for quote and booking communications.
* **Address**: Enter the complete address of your event location.
* **Event Type**: Select the type of event you are planning.
* **Event Date**: Enter the date of your event.
* **Event Start Time**: Enter the time when your event starts.
* **Event End Time**: Enter the time when your event ends.
* **Event Location**: Enter the location of your event.
* **Location Type**: Select the type of venue for your event.
* **Bounce House Preference**: Select the type of bounce house you are interested in.
* **Preferred Themes**: Choose any theme preferences for the event.
* **Age Range of Users**: Select the age range of the children who will use the bounce house.
* **Expected Number of Children**: Enter the approximate count of children who will use the bounce house.
* **Space Available**: Enter the approximate dimensions in feet for the space needed for the bounce house.
* **Power Available**: Select true if there is a power outlet nearby, false if not.
* **Generator Needed**: If you need a generator rental, select true, otherwise select false.
* **Delivery Time Preference**: Select your preferred delivery time for the bounce house.
* **Budget Range**: Select your estimated budget for the bounce house rental.
* **Additional Requests**: Enter any special requests or questions you have.
* **How Did You Hear About Us**: Select the source that led you to use our services.
* **Ready to Book**: If you are ready to book, select yes, otherwise select no.

**Tips**

* Please be as specific as possible when filling out the form.
* If you are unsure about any of the options, you can ask for clarification.
* If you have any questions or need further assistance, please contact us directly.
