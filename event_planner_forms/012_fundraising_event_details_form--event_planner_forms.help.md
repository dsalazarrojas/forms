# Fundraising Event Details Form - Help Guide
## Purpose
This form is used to collect and store details about a fundraising event. It includes information such as address, date, time, event type, and target value. This information can be used to plan and track the progress of the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event.
2. Enter a brief description of the event.
3. Enter the date and time of the event.
4. Enter the name and contact information of the event organizer.
5. Enter the target value and currency for the event.
6. Select the type of event (e.g., Event, Fundraiser).
7. Select the category of the event (e.g., Event, Fundraiser, Charity).
8. Select the status of the event (e.g., Active, In Progress, Upcoming).
9. Enter the start and end dates of the event.
10. Save the form to submit the event details.
