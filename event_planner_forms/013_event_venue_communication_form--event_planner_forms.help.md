# Event Venue Communication Form - Help Guide
## Purpose
This form is used to collect and organize event details for communication purposes only. It is not intended for event booking or management.

## How To Complete This Form
To complete this form, simply fill out the fields as needed:

1. Select the event organizer from the list.
2. Enter the event details, including the event start date and time, type, description, capacity, and duration.
3. Specify the event status, event type, and event priority.
4. Enter the contact details, including the contact person's name, email, and phone number.
5. Enter the venue details, including the venue name, address, capacity, and status.

## Field-by-Field Explanation

* **Event Organizer** (`event_organizer`):
	+ This field allows you to select the organizer of the event.
	+ Choose the correct event organizer from the list.
* **Event Details** (`event_details`):
	+ This field collects the event start date and time, type, description, capacity, and duration.
	+ Enter the required details for the event.
* **Event Type** (`event_type`):
	+ This field specifies the type of event (e.g., Conference, Meeting, Event).
	+ Choose the correct event type from the list.
* **Event Description** (`event_description`):
	+ This field provides a brief description of the event.
	+ Enter a short description of the event.
* **Event Capacity** (`event_capacity`):
	+ This field specifies the maximum number of attendees for the event.
	+ Enter the maximum capacity for the event.
* **Event Duration** (`event_duration`):
	+ This field specifies the length of the event.
	+ Enter the duration of the event in hours or minutes.
* **Event Status** (`event_status`):
	+ This field specifies the status of the event (Active or Inactive).
	+ Choose the correct status from the list.
* **Event Priority** (`event_priority`):
	+ This field specifies the priority level of the event (High or Low).
	+ Choose the correct priority from the list.
* **Contact Details** (`contact_details`):
	+ This field collects the contact person's first and last name, email, and phone number.
	+ Enter the required details for the contact person.
* **Venue Details** (`venue_details`):
	+ This field collects the venue name, address, and status.
	+ Enter the required details for the venue.
* **Venue Capacity** (`venue_capacity`):
	+ This field specifies the maximum number of attendees for the venue.
	+ Enter the maximum capacity for the venue.
* **Venue Priority** (`venue_priority`):
	+ This field specifies the priority level of the venue (High or Low).
	+ Choose the correct priority from the list.

Note: This help guide is for the event venue communication form.
