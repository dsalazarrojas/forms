# Event Programming Form - Help Guide
## Purpose
This form is designed to collect data for event planning purposes, including event title, description, category, and possibly other details like assigned tools or output files.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the event title in the "event_planner_forms_title" field.
2. Provide a brief description of the event in the "event_planner_forms_description" field.
3. Select the category for the event from the "event_planner_forms_category" field.
4. Add any additional description or details in the "event_planner_forms_description_2" field if needed.
5. You may also select another category for the event from the "event_planner_forms_category_2" field.
6. If necessary, specify the assigned tool for the event in the "event_planner_forms_assigned_tool" field.
7. Finally, you may need to specify the output file for the event in the "event_planner_forms_output_file" field.

## Field-by-Field Explanation

* **event_planner_forms**: This field is the main section of the form, where you can input the overall category for the event.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_label**: This field is for adding a label or title for the event.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_description**: This field is for providing a brief description of the event.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_category**: This field is to select the category for the event.
	+ **Type: Select One**
	+ **Required: False**
	+ **Hint: Select the category for the event (Event Planner Forms, Forms and Questionnaires, Surveys and Polls)**
* **event_planner_forms_description_value**: This field is for adding any additional description or details.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_title**: This field is for specifying the title of the event.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_output_file**: This field is for specifying the output file for the event.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_assigned_tool**: This field is for specifying the assigned tool for the event.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_description_2**: This field is for adding any additional description or details.
	+ **Type: Text**
	+ **Required: False**
	+ **Hint: None**
* **event_planner_forms_category_2**: This field is to select another category for the event.
	+ **Type: Select One**
	+ **Required: False**
	+ **Hint: Select the category for the event (Event Planner Forms, Forms and Questionnaires, Surveys and Polls)**

## Tips
* Make sure to fill in all required fields to ensure accurate event planning data collection.
* Double-check the category and assigned tool selections to ensure they match the event's actual needs.
* Use the output file field to specify any necessary output files for the event.
