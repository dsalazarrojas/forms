# Event Attendee Interest Survey - Help Guide
## Purpose
The Event Attendee Interest Survey is designed to gather information from event attendees about their preferences for various events. This will help event planners to better understand their interests and offer tailored services.

## How To Complete This Form

1.  Select the type of event you are interested in from the options provided.
2.  Choose your preferred date and time for the event (if applicable).
3.  Enter the location you are interested in attending the event at.
4.  Select all the attendees you would like to attend the event with (if applicable).
5.  Share any interests or comments about the event.
6.  Provide your email address so we can get in touch with you.
7.  Enter your phone number for further contact.
8.  If you have any comments or additional details to share, please use the comments field.
9.  If you have any specific tool requirements, please mention them in the comments field.
10. Review and submit the form.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `text`, not required): This is an optional field where you can briefly introduce yourself and share any relevant information about your interest in the event.
* **Event Type** (`event_type`, `select_one`, required): Choose the type of event that interests you the most.
* **Date** (`date`, `date`, not required): Enter your preferred date for the event (if applicable).
* **Time** (`time`, `time`, not required): If applicable, select your preferred time for the event.
* **Location** (`location`, `text`, not required): Enter the location you would like to attend the event at.
* **Attendees** (`attendees`, `select_multiple`, not required): Select all the attendees you would like to have at the event (if applicable).
* **Interests** (`interests`, `text`, not required): Share any specific interests or comments about the event.
* **Comments** (`comments`, `note`, not required): Leave any additional comments or details about the event.
* **Email** (`email`, `email`, not required): Enter your email address for further contact.
* **Phone** (`phone`, `text`, not required): Enter your phone number for further contact.
* **Assigned To** (`assigned_user`, `text`, not required): If you have any specific requirements, please mention them.
* **Assigned Date** (`assigned_date`, `date`, not required): If applicable, select a specific date for the event.
* **Assigned Time** (`assigned_time`, `time`, not required): If applicable, select a specific time for the event.
* **Assigned Location** (`assigned_location`, `text`, not required): If applicable, enter the location for the event.
* **Assigned Attendees** (`assigned_attendees`, `select_multiple`, not required): Select all the attendees you would like to have at the event (if applicable).
* **Assigned Comments** (`assigned_comments`, `note`, not required): Leave any additional comments about the event.
* **Output File** (`output_file`, `text`, not required): If you have any requirements for the output file, please mention them.
* **Assigned Tool** (`assigned_tool`, `text`, not required): If you have any specific tool requirements, please mention them.
