# Weekend Activity Sign Up Form - Help Guide
## Purpose
This form is designed to collect information about weekend activities, including the type of event, details about the event, and contact information for the event organizer and attendees. This form helps the event planner to efficiently collect and manage sign-ups for weekend events.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of event (Weekend Activity or Other).
2. Enter the name of the event.
3. Choose the date and time of the event.
4. Provide the venue information.
5. Enter the number of attendees.
6. List the names of all attendees.
7. Add any additional notes or comments about the event.
8. Enter the contact information for the event organizer, including email and phone number.

## Field-by-Field Explanation
- **Event Type** (`Weekend Activity`, `Other`, required): Select the type of event to indicate the nature of the activity.
- **Event Name** (`event name`, text, required): Enter a brief name for the event.
- **Event Date** (`event date`, date, required): Choose the date of the event.
- **Event Time** (`event time`, time, required): Choose the time of the event.
- **Venue** (`venue`, text, required): Enter the location where the event will take place.
- **Number of Attendees** (`number of attendees`, number, required): Enter the number of people attending the event.
- **Names of Attendees** (`attendee_names`, text, required): List the names of all attendees.
- **Notes** (`notes`, note, optional): Add any additional notes or comments about the event.
- **Email** (`email`, email, required): Enter the email address of the event organizer.
- **Phone** (`phone`, text, required): Enter the phone number of the event organizer.
- **Comments** (`comments`, text, optional): Add any additional comments about the event.
- **Event Organizer** (`event organizer`, select_one, required): Select the name of the event organizer from the provided list.
- **Event Organizer Email** (`event organizer email`, email, required): Enter the email address of the event organizer.
- **Event Organizer Phone** (`event organizer phone`, text, required): Enter the phone number of the event organizer.
- **Event Organizer Notes** (`event organizer notes`, note, optional): Add any additional notes or comments about the event organizer.
- **Assigned Tool** (`assigned tool`, select_one, required): Select the tool assigned to the event organizer from the provided list.
