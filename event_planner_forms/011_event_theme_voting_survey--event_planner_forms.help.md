# Event Theme Voting Survey - Help Guide
## Purpose
This form is designed to gather opinions and votes on event themes. It allows users to select one or multiple themes for an event or gathering.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **Survey Form** section with your thoughts and suggestions for the event theme.
2. In the **Theme 1** section, select a single theme from the dropdown list that best represents your idea for the event theme. You can choose one of the five options: Theme 1, Theme 2, Theme 3, Theme 4, or Theme 5.
3. In the **Theme 2** section, select multiple themes from the dropdown list that best represent your idea for the event theme. You can choose one or more of the five options: Theme 1, Theme 2, Theme 3, Theme 4, or Theme 5.
4. In the **Theme 3** section, select a single theme from the dropdown list. This field is only available for events where you can answer "Yes" or "No".
5. In the **Event Name** section, enter a brief name for the event.
6. In the **Event Date** section, select the date for the event.

## Field-by-Field Explanation

* **Survey Form** (text): Enter a brief description of your event theme suggestion.
* **Theme 1** (select_one):
	+ Select a single theme from the dropdown list that best represents your idea for the event theme.
* **Theme 2** (select_multiple):
	+ Select multiple themes from the dropdown list that best represent your idea for the event theme.
* **Theme 3** (select_one):
	+ Select a single theme from the dropdown list. This field is only available for events where you can answer "Yes" or "No".
* **Event Name** (text): Enter a brief name for the event.
* **Event Date** (date): Select the date for the event.

## Tips
* Make sure to provide clear and concise answers in the **Survey Form** section.
* If you're unsure about which themes to select for **Theme 1** or **Theme 2**, you can choose one or multiple themes that best represent your idea.
* If you answer "Yes" for **Theme 3**, make sure you have a clear justification for your selection.
* Enter a brief and descriptive event name that accurately reflects the event's purpose and topic.
* Ensure that the selected event date is accurate and feasible for the event.
