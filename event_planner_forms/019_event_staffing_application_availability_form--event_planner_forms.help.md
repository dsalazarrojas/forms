# Event Staffing Application & Availability Form - Help Guide
## Purpose
The Event Staffing Application & Availability Form is designed to collect information from event staff members to assign them to events based on their availability and preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Fill in the required fields, marked with an asterisk (\*).
2.  Choose your role preferences from the options provided.
3.  Select the date and time you are available.
4.  Provide event details, including event location and contact information.
5.  Enter the event time and staff quantity.
6.  Enter the contact number and email of the staff member.
7.  Add any additional notes about the event.
8.  Finally, click the submit button to send the form.

## Field-by-Field Explanation

* **Event Staffing Application Form** (`event_staffing_application_form`, text, required): This field is the main event staffing application form where you can enter your availability and preferences.
* **Role Preferences** (`role_preferences`, select_one, required): Please select your role preferences from the options provided. 
* **Availability** (`availability`, date, required): This field allows you to select the date(s) and time you are available.
* **Event Details** (`event_details`, text, required): Enter details about the event, including event location.
* **Event Organizer** (`event_organizer`, text, required): Enter the name of the event organizer.
* **Venue** (`venue`, text, optional): This field is optional and can be used to provide additional details about the event venue.
* **Staff Coordinator** (`staff_coordinator`, text, optional): This field is optional and can be used to provide details about the staff coordinator.
* **Event Date** (`event_date`, date, optional): This field is optional and can be used to select the date of the event.
* **Event Time** (`event_time`, time, required): Enter the time of the event.
* **Staff Quantity** (`staff_quantity`, text, optional): This field is optional and can be used to provide details about the staff quantity required.
* **Staff Shift** (`staff_shift`, text, optional): This field is optional and can be used to provide details about the staff shift.
* **Staff Rate** (`staff_rate`, text, optional): This field is optional and can be used to provide details about the staff rate.
* **Staff Availability** (`staff_availability`, time, optional): This field is optional and can be used to select the staff availability.
* **Event Location** (`event_location`, text, optional): This field is optional and can be used to provide details about the event location.
* **Contact Number** (`contact_number`, text, required): Enter the contact number of the staff member.
* **Contact Email** (`contact_email`, email, required): Enter the email of the staff member.
* **Notes** (`notes`, note, optional): This field is optional and can be used to provide additional notes about the event.
* **Event Planner 1**-8 (`event_planner_1`, text, optional): These fields are optional and can be used to provide details about the event planners.
* **Staff Rate** and **Staff Shift** fields can be ignored as they are not clearly defined in the provided YAML fields and are likely meant to be used in a different context.
