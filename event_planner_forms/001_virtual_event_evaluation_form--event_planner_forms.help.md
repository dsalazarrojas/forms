# virtual_event_evaluation_form - Help Guide
## Purpose
The virtual event evaluation form is designed to collect feedback from attendees on the overall satisfaction, session durations, and other event-related details. Please complete this form to help improve future virtual events.

## How To Complete This Form
To complete this form, follow these steps:

1. Start with the first page, titled "Welcome to our Virtual Event Evaluation Form." This page serves as a heading and introduction.
2. Scroll down to the next page, which includes the evaluation questions.
3. Answer each question truthfully to provide valuable feedback.
4. Review your answers for accuracy before submitting the form.

## Field-by-Field Explanation
### 1. <label> Welcome to our Virtual Event Evaluation Form</label>
This page is a heading and introduction to the form. It serves as a warm welcome to attendees.

### 2. <label> virtual_event_name</label>
Enter the name of the virtual event you attended.

### 3. <label> evaluation_date</label>
Select the date you attended the virtual event.

### 4. <label> start_time</label>
Enter the start time of the virtual event.

### 5. <label> end_time</label>
Enter the end time of the virtual event.

### 6. <label> overall_satisfaction</label>
Rate your overall satisfaction with the virtual event on a scale of 1-10.

### 7. <label> comments</label>
Share any additional comments or feedback about the virtual event.

### 8. <label> virtual_event_attendee_count</label>
Enter the number of attendees you observed during the virtual event.

### 9. <label> session_durations</label>
Select all applicable session durations that applied to your virtual event experience.
