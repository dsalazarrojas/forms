# Costume Contest Judging Form - Help Guide
## Purpose
This form is used to collect scores and feedback from judges for a costume contest. It's likely part of a larger system for managing events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the first and second costume from the provided options.
2. Assign a score to each costume, using numbers for your evaluation.
3. Optionally, provide comments for each costume.
4. Enter the name of the event and the assigned judge.
5. Enter the date of the event.
6. Optionally, enter a name for the costume and the contestant.

## Field-by-Field Explanation

* **First Costume** (first_costume): Select the first costume to be judged.
* **Second Costume** (second_costume): Select the second costume to be judged. You can select multiple options.
* **Score for First Costume** (score_first_costume): Enter a number to evaluate the first costume.
* **Score for Second Costume** (score_second_costume): Enter a number to evaluate the second costume.
* **Overall Score** (overall_score): Enter a final score for both costumes.
* **Costume Name** (costume_name): Enter a name for the first costume (optional).
* **Contestant Name** (contestant_name): Enter the name of the contestant (optional).
* **Comments** (comments): Provide any additional comments or feedback for the contest (optional).
* **Event Name** (event_name): Enter the name of the event.
* **Assigned Judge** (assigned_judge): Enter the name of the assigned judge.
* **Event Date** (event_date): Enter the date of the event.
* **Form ID** (form_id): This field is likely for internal use and not intended for user input.

## Tips
* Make sure to select the correct costumes and provide scores and comments for each.
* If you're unsure about any of the fields, you can refer to the event organizers for clarification.
* This form is designed to be used for one-time events, but it's also possible to be used for multiple events.
