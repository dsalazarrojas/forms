# T Shirt Pre Order Form Template - Help Guide
## Purpose
This form is a pre-order form for t-shirts. It is intended to be filled out by customers to specify their desired t-shirt order details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with your desired t-shirt information.
2. Submit the form to the sales team.

## Field-by-Field Explanation
* **T Shirt Name** (`t_shirt_name`, text, optional): Enter the name of the t-shirt you would like to order.
* **T Shirt Size** (`size`, select_one, optional): Select the size of the t-shirt you would like to order. Options include:
	+ Small
	+ Medium
	+ Large
* **Quantity** (`quantity`, number, optional): Enter the quantity of t-shirts you would like to order.
* **Color** (`color`, select_multiple, optional): Select one or more colors for the t-shirt you would like to order. Options include:
	+ Red
	+ Blue
	+ Green
* **Order Date** (`order_date`, date, optional): Enter the date you would like to order the t-shirt. This will help the sales team prepare for production.
* **Order Time** (`order_time`, time, optional): Enter the time you would like to receive the order. This will help the sales team schedule production.
* **Additional Information** (`note`, note, optional): This field is not currently being used.
