# Game T Shirt Order Form - Help Guide
## Purpose
The Game T Shirt Order Form is designed to collect information about T shirt orders from customers. It's used to gather details such as size, color, and quantity of T shirts ordered.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the size of the T shirt you wish to order from the options provided.
2. Choose the color of the T shirt you wish to order from the available options.
3. Enter the quantity of T shirts you wish to order using the number input field.

## Field-by-Field Explanation

* **T shirt size**: Select the size of the T shirt you want to order. Choose from the available options: small, medium, large.
* **T shirt color**: Choose the color of the T shirt you want to order. Select from the available options: red, blue, green.
* **T shirt quantity**: Enter the number of T shirts you wish to order. This is a numerical input field.
