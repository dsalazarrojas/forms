# Authorization To Use The AAPG LACR Certificate Template For Chapter Events - Help Guide
## Purpose
This form is for requesting authorization to use the AAPG LACR Certificate Template for Chapter Events. The template is designed to provide official certification for chapter events, and this form helps ensure that all necessary information is collected to maintain quality and integrity.

## How To Complete This Form
To fill out this form, please make sure to provide detailed information for each field as follows:

## Field-by-Field Explanation

* **Authorization Date** (`authorization_date`, required): The date of this authorization request.
* **Chapter Name** (`chapter_name`, required): The name of the AAPG chapter.
* **Chapter Location** (`chapter_location`, required): The geographic location of the chapter.
* **Chapter President Name** (`chapter_president_name`, required): The name of the chapter president.
* **Chapter President Email** (`chapter_president_email`, required): The email contact of the chapter president.
* **Chapter President Phone** (`chapter_president_phone`, optional): The contact phone number of the chapter president.
* **Event Title** (`event_title`, required): The name of the chapter event.
* **Event Date** (`event_date`, required): The date of the scheduled event.
* **Event Location** (`event_location`, required): The location of the event.
* **Event Type** (`event_type`, required): The type of chapter event (e.g., Educational Seminar, Technical Workshop, etc.).
* **Expected Attendance** (`expected_attendance`, required): The approximate number of attendees.
* **Purpose of Certificate Use** (`certificate_use_purpose`, required): How the certificates will be used (e.g., Participant Recognition, CEU Documentation, etc.).
* **Certificate Design Customization** (`certificate_design`, required): The level of customization desired for the certificate template (e.g., Use Standard Template Only, Minor Customization, etc.).
* **Continuing Education Unit Credits** (`ceu_credits`, optional): The number of CEU credits offered.
* **Who Will Receive Certificates** (`certificate_recipients`, required): The categories of recipients (e.g., All Attendees, Paid Participants Only, etc.).
* **Certificate Distribution Method** (`distribution_method`, required): How the certificates will be delivered (e.g., Printed at Event, Digital - Email, etc.).
* **Digital Verification Needed** (`digital_verification`, optional): Whether digital verification is needed for the certificates.
* **AAPG Branding Requirements** (`aapg_branding`, required): The AAPG elements that must appear on the certificates (e.g., AAPG Logo, AAPG Name, etc.).
* **Agree to AAPG Template Compliance** (`compliance_agreement`, required): Whether you agree to follow AAPG guidelines.
* **Quality Assurance Needed** (`quality_assurance`, optional): Whether AAPG will review certificates before use.
* **Certificate Records Storage** (`document_storage`, required): Where the certificate records will be kept (e.g., Chapter Maintains Records, AAPG Central Database, etc.).
* **Record Retention Period** (`record_retention`, optional): The duration for which records must be kept.
* **Authorization to Use Certificate Template** (`authorization_confirmation`, required): Do you authorize the use of the template?
* **Additional Notes or Requirements** (`additional_notes`, optional): Any special requests or conditions.

Please provide accurate and detailed information to ensure that the certificate template is correctly customized and meets the requirements for your chapter event.
