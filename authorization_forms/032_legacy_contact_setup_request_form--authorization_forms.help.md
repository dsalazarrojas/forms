# Legacy Contact Setup Request Form - Help Guide
## Purpose
The Legacy Contact Setup Request Form is used to request access to a user's account when they are unable to manage their account themselves. This form helps administrators identify a trusted contact who can be reached in case of emergencies or important account-related issues.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Make sure to provide a valid email address for the contact.
3. Fill in any additional details in the description field if necessary.

## Field-by-Field Explanation

* **First name** (<code>first_name</code>, <code>text</code>, required: false): Enter the first name of the trusted contact.
* **Last name** (<code>last_name</code>, <code>text</code>, required: true): Enter the last name of the trusted contact.
* **Trusted name** (<code>trusted_name</code>, <code>text</code>, required: true): Enter the name that will be used to identify the trusted contact in the account.
* **Account name** (<code>account_name</code>, <code>text</code>, required: true): Enter the name of the account that the trusted contact is related to.
* **Email** (<code>email</code>, <code>email</code>, required: true): Enter a valid email address for the trusted contact.
* **Phone** (<code>phone</code>, <code>text</code>, required: false): Enter the phone number of the trusted contact (optional).
* **Address** (<code>address</code>, <code>text</code>, required: false): Enter the address of the trusted contact (optional).
* **Description** (<code>description</code>, <code>text</code>, required: false): Provide any additional details or context for the request.

## Tips
* Make sure to only request access for legitimate reasons.
* If you have previously requested access, you do not need to re-fill out this form.
* If you are unsure about any of the fields, please contact an administrator for assistance.
