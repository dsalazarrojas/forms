# Smart Key Integration Consent Form - Help Guide

## Purpose
The Smart Key Integration Consent Form is designed to obtain necessary permissions and information for integrating Smart Lock systems with the Smart Key system.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a title for the integration in the **Smart Key Integration Consent Form** field.
2. Select the category under which this integration falls.
3. Provide a description of the integration.
4. Choose whether access to your Smart Lock system will be granted (**Yes** or **No**).
5. Choose whether integration details will be shared (**Yes** or **No**).
6. (Optional) Enter a note on the key details (for example, a key number or key ID).
7. Enter the date of authorization for the integration.
8. Choose the type of access to be granted to your Smart Lock system (**Yes** or **No**).
9. Choose the Smart Lock model to be integrated (**Yes** or **No**).
10. Enter the Smart Lock serial number (if applicable).
11. Enter the integration key for the Smart Lock system.
12. Enter the Smart Lock password (if applicable).
13. Enter the Smart Lock key for the integration.

## Field-by-Field Explanation
* **Smart Key Integration Consent Form** (`form_title`, text, required): Enter a short title for the integration, e.g., "John's Smart Lock System Integration".
* **Category** (`category`, text, required): Select the category that this integration belongs to (e.g., "Office", "Home", etc.).
* **Description** (`description`, text, required): Provide a detailed description of the integration, explaining its purpose and requirements.
* **Smart Lock Access** (`smartlock_access`, select_multiple, required): Decide whether access to your Smart Lock system will be granted (**Yes** or **No**).
* **Integration Details** (`integration_details`, select_multiple, required): Choose whether integration details will be shared (**Yes** or **No**).
* **Key Details** (`key_details`, note, optional): Enter any key details, such as a key number or ID.
* **Authorization Date** (`authorization_date`, date, required): Enter the date on which authorization for the integration was given.
* **Smart Lock Access Type** (`smart_lock_access_type`, select_one, required): Choose the type of access to be granted to your Smart Lock system (**Yes** or **No**).
* **Smart Lock Model** (`smart_lock_model`, select_one, required): Choose the Smart Lock model to be integrated (**Yes** or **No**).
* **Smart Lock Serial Number** (`smart_lock_serial_number`, text, optional): Enter the Smart Lock serial number.
* **Integration Key** (`integration_key`, text, optional): Enter the integration key for the Smart Lock system.
* **Smart Lock Password** (`smart_lock_password`, text, optional): Enter the Smart Lock password.
* **Smart Lock Key** (`smart_lock_key`, text, optional): Enter the Smart Lock key.

## Tips
* Ensure that you have the necessary authority to grant access to your Smart Lock system before completing this form.
* Enter accurate and relevant information to ensure a smooth integration process.
* If you are unsure about any field, contact your IT or administrative team for guidance.
