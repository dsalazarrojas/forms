# Supersedeas Bond Motion Form - Help Guide

## Purpose
This form is used for requesting a supersedeas bond in a specific case. A supersedeas bond is a court-ordered financial bond that is used to ensure that a party in a case appears at court proceedings. The purpose of this form is to document the request for a supersedeas bond and collect relevant information for the court.

## How To Complete This Form

To complete this form, please follow these steps:

1. Review the form carefully to ensure you have all the necessary information.
2. Fill in the requested fields with the required information. Fields with a red asterisk (\*) are required.
3. Ensure that you have selected the correct options for each field.
4. Once you have completed the form, review it carefully for errors before submitting.

## Field-by-Field Explanation

* **Supersedeas Bond Motion Request** (`supersedeas_bond_motion_request`, note, not required): This field is used to provide a brief description of the request for the supersedeas bond.
* **party_name** (`party_name`, text, not required): Please enter the name of the party requesting the supersedeas bond.
* **bond_amount** (`bond_amount`, number, not required): This field is used to specify the amount of the supersedeas bond.
* **filing_party** (`filing_party`, select one, not required): Please select "Yes" if the party requesting the bond is the filing party.
* **motion_number** (`motion_number`, text, not required): Please enter the motion number related to this supersedeas bond request.
* **judge_name** (`judge_name`, text, not required): Enter the name of the judge presiding over the case.
* **motion_date** (`motion_date`, date, not required): Enter the date of the motion related to this supersedeas bond request.
* **bond_date** (`bond_date`, date, not required): Enter the date when the supersedeas bond is to be filed.
* **bond_type** (`bond_type`, select one, not required): Please select "Yes" if this is a supersedeas bond.
* **motion_type** (`motion_type`, select multiple, not required): This field is not clearly defined, but it appears to be related to the type of motion. Please select all applicable types of motion that apply to this supersedeas bond request.
* **supersedeas_bond_motions** (`supersedeas_bond_motions`, select multiple, not required): Please select all applicable supersedeas bond motions that apply to this request.
* **case_type** (`case_type`, select one, not required): Please select "Yes" if this is a supersedeas bond case type.
* **case_number** (`case_number`, number, not required): Enter the case number related to this supersedeas bond request.

## Tips

* Please ensure that all required fields are filled in accurately and completely.
* If you are unsure about any field, please contact the court for clarification.
* This form is for informational purposes only and should not be used for any other purpose.
