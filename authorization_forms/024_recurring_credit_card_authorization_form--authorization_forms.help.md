# Recurring Credit Card Authorization Form - Help Guide
## Purpose
This form is used to obtain authorization from a card holder for recurring payments from a credit card.

## How To Complete This Form
To fill out this form, follow the steps below:

1. Enter the Card Number in the "Card Number" field. This is the 16-digit credit card number.
2. Enter the Expiration Date in the "Expiration Date" field. This date should be in the format MM/YY (e.g., 12/21).
3. Select the Month for the expiration in the "Month" field. This should match the month of the expiration date.
4. Select the Year for the expiration in the "Year" field. This should match the year of the expiration date.
5. Enter the CVV (Card Verification Value) code for the credit card in the "CVV" field. This is the 3-digit security code found on the back of the card.
6. Enter the Start Date for the recurring payment in the "Start Date" field. This date should be in the format MM/YY (e.g., 01/22).
7. Select the Start Month for the recurring payment in the "Start Month" field. This should match the month of the start date.
8. Select the Start Year for the recurring payment in the "Start Year" field. This should match the year of the start date.
9. Enter the CVV (Card Verification Value) code for the credit card in the "CVV" field (again).
10. Enter the Card Holder Name in the "Card Holder Name" field.
11. Enter the Authorization Amount in the "Authorization Amount" field. This is the amount to be charged for the recurring payment.
12. Select the frequency of the recurring payment in the "Frequency" field. This can be monthly, quarterly, or annually.
13. Select the type of payment in the "Authorization Type" field. This can be a recurring or one-time payment.
14. Enter the Payment Type in the "Payment Type" field. This should be a yes or no answer.
15. Enter the Stripe Publishable Key in the "Stripe Publishable Key" field. This is a unique identifier for the stripe publishable key.
16. Enter the Payment Method in the "Payment Method" field. This can be a yes or no answer.
17. Enter the CVC (Card Verification Code) in the "CVC" field. This is the 3-digit security code found on the back of the card.
18. Select the Expiration Month for the credit card in the "Expiration Month" field. This should match the month of the expiration date.
19. Select the Expiration Year for the credit card in the "Expiration Year" field. This should match the year of the expiration date.
20. Enter the Card Holder Address in the "Address" field.
21. Enter the Zip Code in the "Zip Code" field.
22. Enter the Card Holder State in the "State" field.
23. Enter the Card Holder City in the "City" field.
24. Enter the Card Holder Country in the "Country" field.
25. Select if the card holder is authorized to make payments in the "Payment Method" field. This can be a yes or no answer.

## Field-by-Field Explanation
* **Card Number** (1, text, required): Enter the 16-digit credit card number.
* **Expiration Date** (2, date, required): Enter the expiration date of the credit card in the format MM/YY.
* **Month** (3, select_one, required): Select the month of the expiration date.
* **Year** (4, select_one, required): Select the year of the expiration date.
* **CVV** (5, text, required): Enter the 3-digit card verification value code.
* **Start Date** (6, date, required): Enter the start date of the recurring payment in the format MM/YY.
* **Start Month** (8, select_one, required): Select the start month of the recurring payment.
* **Start Year** (9, select_one, required): Select the start year of the recurring payment.
* **CVV** (10, text, required): Enter the 3-digit card verification value code again.
* **Card Holder Name** (11, text, required): Enter the name of the card holder.
* **Authorization Amount** (12, number, required): Enter the authorization amount.
* **Frequency** (13, select_multiple, required): Select the frequency of the recurring payment.
* **Authorization Type** (14, select_multiple, required): Select the type of payment.
* **Payment Type** (15, select_multiple, required): Select if the card holder is authorized to make payments.
* **Stripe Publishable Key** (16, text, required): Enter the stripe publishable key.
* **Payment Method** (17, select_multiple, required): Select if the card holder is authorized to make payments.
* **CVC** (18, text, required): Enter the 3-digit card verification code.
* **Expiration Month** (19, select_one, required): Select the month of the expiration date.
* **Expiration Year** (20, select_one, required): Select the year of the expiration date.
* **Address** (21, text, required): Enter the address of the card holder.
* **Zip Code** (22, text, required): Enter the zip code of the card holder.
* **State** (23, text, required): Enter the state of the card holder.
* **City** (24, text, required): Enter the city of the card holder.
* **Country** (25, text, required): Enter the country of the card holder.
