# Role Assignment Authorization Form - Help Guide
## Purpose
The Role Assignment Authorization Form is a formal request for authorization to perform a role assignment within the organization. It is used to gather information from the manager or team members about the role assignment and gather their approval.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information, which includes:
	* Manager Name
	* Manager Email
	* Team Members (select either "Yes" or "No")
	* Role Change Reason
	* Role Change Request Date
	* Role Change Request Time
	* Manager Approval (select either "Approve", "Reject", or "Pending")
	* Role Effective Date
	* Role Change Requester

2. Submit the form for review and approval from the manager.

## Field-by-Field Explanation

* **Role Assignment Information** (Page 1): This page contains a brief introduction to the form and a list of fields to be filled out.
* **Manager Name** (Page 2):
	+ This field is used to enter the name of the manager who will be approving the role assignment.
	+ Please enter the manager's name in the format "Last Name, First Name".
* **Manager Email** (Page 2):
	+ This field is used to enter the manager's email address.
	+ Please enter the manager's email address in the correct format (e.g. "john.doe@example.com").
* **Team Members** (Page 2):
	+ This field is used to indicate whether the team members are involved in the role assignment.
	+ Select "Yes" if the team members are involved, "No" if they are not.
* **Role Change Reason** (Page 3):
	+ This field is used to enter a brief explanation for the role change.
	+ Please enter a clear and concise description of the reason for the role change.
* **Role Change Request Date** (Page 3):
	+ This field is used to select the date of the role change request.
	+ Please select the date using the calendar icon and choose the desired date.
* **Role Change Request Time** (Page 3):
	+ This field is used to select the time of the role change request.
	+ Please select the time using the clock icon and choose the desired time.
* **Manager Approval** (Page 4):
	+ This field is used to select the manager's approval status.
	+ Please select either "Approve", "Reject", or "Pending" to indicate the manager's decision.
* **Role Effective Date** (Page 4):
	+ This field is used to select the effective date of the role change.
	+ Please select the date using the calendar icon and choose the desired date.
* **Role Change Requester** (Page 4):
	+ This field is used to enter the name of the person requesting the role change.
	+ Please enter the name in the format "Last Name, First Name".
* **Manager Approval** (Page 4):
	+ This field is used to select the manager's approval status.
	+ Please select either "Approve", "Reject", or "Pending" to indicate the manager's decision.

## Tips

* Please fill out the form in a clear and concise manner to ensure that the manager has all necessary information to make an informed decision.
* If you are unsure about any of the fields, please consult with your manager or team lead.
* Make sure to review the form carefully before submitting it to ensure that all required fields are filled out.
