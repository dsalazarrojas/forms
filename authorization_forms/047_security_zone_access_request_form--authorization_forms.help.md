# Security Zone Access Request Form - Help Guide

## Purpose
The Security Zone Access Request Form is used to request access to a specific Security Zone. This form collects necessary information to ensure that the access request is processed correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Click the "Submit" button to initiate the request process.
2. Provide your individual name and ensure that it matches the identity information on file with us.
3. Select the appropriate organization from the drop-down list that corresponds to your affiliation.
4. If applicable, provide the name of the contact person who should be notified about the access request.
5. If applicable, provide their contact phone number and contact email.
6. Describe the purpose and details of your access request.

## Field-by-Field Explanation
* **Submit** (`submit_button`, text, required):
	+ Click this button to send your access request.
* **Request Date** (`request_date`, date, optional):
	+ Enter the date of your access request.
* **Individual Name** (`individual_name`, text, optional):
	+ Enter your name, as it appears on our records.
* **Organization** (`organization`, select_one, optional):
	+ Select your organization from the provided options to indicate your affiliation.
* **Contact Person** (`contact_person`, text, optional):
	+ If applicable, enter the name of the contact person who should be notified about the access request.
* **Contact Phone** (`contact_phone`, text, optional):
	+ If applicable, enter the phone number of the contact person.
* **Contact Email** (`contact_email`, email, optional):
	+ If applicable, enter the email address of the contact person.
* **Request Details** (`request_details`, text, optional):
	+ Describe the specific reason and details of your access request.

## Tips
* Ensure that all fields are filled accurately and completely before submitting the form.
* Review the submitted form for any errors or inconsistencies before clicking the "Submit" button.
* If you are unsure about any field, contact us for guidance.
