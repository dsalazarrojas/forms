# reference_check_authorization - Help Guide
## Purpose
The Reference Check Authorization form is used to gather background information about an individual to be verified for employment, promotion, or other purposes.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select the response to the question "Reference Check Authorization" from the options "Yes" or "No".
2.  If "Yes", provide your signature as confirmation of your authorization.
3.  Enter the "Reason for Request" if you have a specific reason for the reference check.
4.  Enter "Contact Information" so that the individual being checked can get in touch with you.
5.  Choose the "Authorized Person" who will be conducting or has conducted the reference check. Select from the following options: HR Manager, Line Manager, Team Lead, or CEO.

## Field-by-Field Explanation
- **Reference Check Authorization** (Yes, No): This field asks if you are authorizing a reference check for the individual.
- **Signature** (Note): This field is used to add your handwritten or typed signature, confirming that you are authorizing the reference check.
- **Reason for Request** (Text): If there is a specific reason why a reference check is being conducted, please enter a brief description here.
- **Contact Information** (Text): Enter your contact information so that the individual being checked can reach out to you.
- **Authorized Person** (Select One): This field allows you to choose who will be conducting the reference check or has conducted it. Choose from HR Manager, Line Manager, Team Lead, or CEO.
