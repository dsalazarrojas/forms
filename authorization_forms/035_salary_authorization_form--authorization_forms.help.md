# Salary Authorization Form - Help Guide
## Purpose
This form is used for requesting a salary authorization for an employee. It gathers necessary information about the employee, authorized person, salary amount, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Employee ID of the individual for whom you are requesting the salary authorization.
2. Enter the proposed salary amount for the employee.
3. Select the authorized person from the list (Manager, Director, or Supervisor).
4. Enter the date for which the salary authorization is being requested.
5. Enter the time for which the salary authorization is being requested.
6. Add any additional comments or notes about the authorization request.

## Field-by-Field Explanation
### 1. **Employee ID**
* **Employee ID** (required: false, type: number)
Enter the Employee ID of the individual for whom you are requesting the salary authorization.

### 2. **Salary Amount**
* **Salary Amount** (required: false, type: number)
Enter the proposed salary amount for the employee.

### 3. **Authorized By**
* **Authorized By** (required: false, type: select_one)
Select one of the following options:
	+ Manager
	+ Director
	+ Supervisor

### 4. **Date**
* **Date** (required: false, type: date)
Enter the date for which the salary authorization is being requested.

### 5. **Time**
* **Time** (required: false, type: time)
Enter the time for which the salary authorization is being requested.

### 6. **Comment**
* **Comment** (required: false, type: text)
Add any additional comments or notes about the authorization request.

## Tips
* Please make sure to enter accurate and correct information in each field.
* Double-check the selected authorized person to ensure it is correct.
* Use the comment field to provide any additional context or details about the authorization request.
