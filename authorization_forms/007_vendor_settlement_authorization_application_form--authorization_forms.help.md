# Vendor Settlement Authorization Application Form - Help Guide
## Purpose
This form is designed to facilitate the vendor settlement process by collecting necessary information from vendors.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you have all the required information ready.
2. Complete all fields accurately and thoroughly.
3. Double-check the form for any errors or missing information before submitting it.

## Field-by-Field Explanation

* **Vendor Details (Page 1)**: Enter the vendor's details, including their name and any other relevant information.
* **Settlement Details (Page 1)**: Provide a clear and detailed description of the settlement you are requesting.
* **Bank Details (Page 1)**: Enter the bank account details, including account number and branch number.
* **Bank Routing Info (Page 1)**: Enter the bank routing information, including ABA routing number and bank branch number.
* **Bank Account Info (Page 1)**: Enter the bank account information, including account type and account status.
* **Tax ID Number (Page 2)**: Enter the vendor's tax ID number, if applicable.
* **Tax ID Type (Page 2)**: Select the type of tax ID (e.g., "Active", "Inactive", etc.).
* **Tax ID Date Of Issue (Page 2)**: Enter the date the tax ID was issued.
* **Tax ID Place Of Issue (Page 2)**: Select "Yes" or "No" to indicate whether the tax ID was issued in the vendor's country of residence.
* **Tax ID Status (Page 2)**: Select the status of the tax ID (e.g., "Active", "Inactive", etc.).
* **Tax ID Expire Date (Page 2)**: Enter the date the tax ID expires.

## Tips
* Double-check all fields for accuracy and completeness before submitting the form.
* Ensure all fields are filled out in full before submitting the form.
* Only submit the form once all required fields are complete.
