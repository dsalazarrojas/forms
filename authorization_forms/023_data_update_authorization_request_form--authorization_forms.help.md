# Data Update Authorization Request Form - Help Guide
## Purpose
This form is used to request authorization for data updates from an organization or user. 

## How To Complete This Form

1. Choose the organization that is involved in the data update by selecting "Yes" or "No" from the "Choose Organization" dropdown menu.
2. Choose the user that will be performing the data update by selecting "Yes" or "No" from the "Choose User" dropdown menu.
3. Select the type of data update by choosing one of the options from the "Update Type" dropdown menu.
4. Select the specific data fields to be updated by choosing multiple options from the "Select Data Fields" dropdown menu.
5. If necessary, select the specific data values to be updated by choosing multiple options from the "Select Data Values" dropdown menu.
6. Enter the date of consent for the data update.
7. Select the reviewers who will review the data update by choosing multiple options from the "Reviewers" dropdown menu.
8. Select the approvers who will approve the data update by choosing multiple options from the "Approvers" dropdown menu.
9. Provide a reason for rejection if the update is not approved.
10. Leave comments for the data update.
11. Enter the date of approval for the data update.
12. Choose the status of the data update from the "Status" dropdown menu.
13. Leave comments for the data update.
14. Enter your signature.
15. Enter the name of the approver.
16. Enter the email of the approver.
17. Enter the phone number of the approver.
18. Enter the name of the reviewer.
19. Enter the email of the reviewer.
20. Enter the phone number of the reviewer.

## Field-by-Field Explanation

* **Choose Organization**: This field allows you to select the organization that is involved in the data update. You must choose "Yes" or "No" from the dropdown menu.
* **Choose User**: This field allows you to select the user that will be performing the data update. You must choose "Yes" or "No" from the dropdown menu.
* **Update Type**: This field allows you to select the type of data update. Choose one of the options from the dropdown menu.
* **Select Data Fields**: This field allows you to select the specific data fields to be updated. Choose multiple options from the dropdown menu.
* **Select Data Values**: This field allows you to select the specific data values to be updated. Choose multiple options from the dropdown menu.
* **Consent Date**: This field is for entering the date of consent for the data update.
* **Reviewers**: This field allows you to select the reviewers who will review the data update. Choose multiple options from the dropdown menu.
* **Approvers**: This field allows you to select the approvers who will approve the data update. Choose multiple options from the dropdown menu.
* **Reason for Rejection**: This field is for providing a reason for rejection if the update is not approved.
* **Comments**: This field is for leaving comments for the data update.
* **Approval Date**: This field is for entering the date of approval for the data update.
* **Status**: This field is for choosing the status of the data update. Choose one of the options from the dropdown menu.
* **Comments**: This field is for leaving comments for the data update.
* **Signature**: This field is for entering your signature.
* **Approver Name**: This field is for entering the name of the approver.
* **Approver Email**: This field is for entering the email of the approver.
* **Approver Phone**: This field is for entering the phone number of the approver.
* **Reviewer Name**: This field is for entering the name of the reviewer.
* **Reviewer Email**: This field is for entering the email of the reviewer.
* **Reviewer Phone**: This field is for entering the phone number of the reviewer.
