> # Port Access Authorization Form - Help Guide

## Purpose

The Port Access Authorization Form is a standardized document used to request and record access to a specific port or facility within an organization. Its primary purpose is to verify and manage access permissions for individuals and organizations.

## How To Complete This Form

To complete this form, follow these steps:

1. Choose the grantee type from the options provided.
2. Select the grantee title from the available options.
3. Enter the grantee's name, email, phone number, and address.
4. Enter the facility ID number.
5. Select the access type (Access Granted or Access Denied).
6. Choose the start and end dates for the access period.

## Field-by-Field Explanation

* **Grantee Type** (`grantee_type`, select_one): Select the type of grantee (Authorized Person, Authorized Organization, Authorized Government Agency, or Other).
* **Grantee Title** (`grantee_title`, select_one): Choose the title of the grantee (Mr., Mrs., Ms., or Other).
* **Grantee Name** (`grantee_name`, text): Enter the first and last name of the grantee.
* **Grantee Email** (`grantee_email`, email): Enter the email address of the grantee.
* **Grantee Phone** (`grantee_phone`, text): Enter the phone number of the grantee.
* **Grantee Address** (`grantee_address`, text): Enter the address of the grantee (first and last name).
* **Facility ID** (`facility_id`, number): Enter the facility ID number (if required).
* **Access Type** (`access_type`, select_one): Choose the access type (Access Granted or Access Denied).
* **Access Start Date** (`access_start_date`, date): Select the start date of the access period.
* **Access End Date** (`access_end_date`, date): Select the end date of the access period.

## Tips

* Ensure that you have all the necessary clearance and permissions to complete this form.
* Double-check your entries for accuracy and completeness.
* If you have any questions or concerns, contact the relevant authorities within your organization.
