# Agent Linking Guide Form - Help Guide
## Purpose
The Agent Linking Guide Form is designed to collect information for linking and access authorization between agent profiles and systems.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and agency name in the corresponding fields.
2. Choose the system or database you are requesting access to.
3. Select the access level you need (Read-only, Edit, Admin, or Financial Auditor).
4. Provide a reason for your request.
5. Choose the duration of access you require (Permanent or Temporary).
6. If your access is temporary, select the expiry date.
7. Confirm that your request has been approved by a manager.
8. Enter the name of the authorizing official who approved your request.

## Field-by-Field Explanation
* **Requested by - Name**: Enter your name as the agent requesting access.
* **Agency Name**: Enter the name of the agency you are representing.
* **Request Date**: Enter the date you are requesting access.
* **Agent ID to be linked**: Enter your unique system identifier.
* **System or Database Name**: Select the system or database you are requesting access to.
* **Access Level Requested**: Choose the level of access you need, such as Read-only, Edit, Admin, or Financial Auditor.
* **Reason for linking request**: Provide a clear explanation for your request.
* **Duration of access**: Choose whether your access is Permanent or Temporary.
* **Access Expiry Date**: If your access is temporary, select the date when your access will expire.
* **Has this request been approved by a manager?**: Confirm that your request has been approved by a manager. 
* **Name of Authorizing Official**: Enter the name of the person who approved your request.
* **Permanent**: Choose this option if you require permanent access.
* **Temporary (Fixed Term)**: Choose this option if you require temporary access.
* **Read-only Access**: Select this option for read-only access.
* **Standard Edit Access**: Select this option for standard edit access.
* **Administrator Privileges**: Select this option for admin privileges.
* **Financial Auditor Access**: Select this option for financial auditor access.

## Tips
* Make sure to fill in all required fields accurately and completely.
* Double-check your selection for "Has this request been approved by a manager?" to ensure your request is valid.
* If your access is temporary, select the correct expiry date to avoid any issues.
