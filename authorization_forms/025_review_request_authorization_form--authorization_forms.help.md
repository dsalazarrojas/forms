# Review Request Authorization Form - Help Guide
## Purpose

The Review Request Authorization Form is a tool used for requesting and reviewing authorization to process a review request. This form ensures that all necessary information is gathered for a smooth review process.

## How To Complete This Form

1. Fill out the form completely and accurately with the required information.
2. Review the form carefully to ensure that all fields are filled in correctly.
3. Submit the form for review.

## Field-by-Field Explanation

* **Review Request Form** (1): A text field where you can type in a brief description of the review request.
* **Review Requester Info** (2): Enter the contact information of the person making the review request.
* **Review Requester Name** (3): Enter the name of the person making the review request.
* **Review Request Date** (4): Select the date of the review request.
* **Review Request Deadline** (5): Select the deadline for the review request.
* **Review Request Description** (6): Enter a detailed description of the review request.
* **Reviewer Info** (7): Enter the contact information of the person reviewing the request.
* **Reviewer Name** (8): Enter the name of the person reviewing the request.
* **Reviewer Decision** (9): Select the decision for the review request (Approve, Reject, or Incomplete).
* **Review Request Status** (10): Select the status of the review request (Active, Pending, or Inactive).
* **Submitter** (11): Enter the email address of the person submitting the form.
* **Review Request ID** (12): Enter a unique ID for the review request.
* **Review Request Note** (13): Enter a note for the review request.
* **Reviewer Note** (14): Enter a note for the reviewer.
* **Reviewer Comment** (15): Enter a comment for the reviewer.
* **Review Request Attachment** (16): Attach a file for the review request.
* **Review Requester Email** (17): Enter the email address of the person making the review request.
* **Review Requester Phone** (18): Enter the phone number of the person making the review request.
* **Reviewer Phone** (19): Enter the phone number of the person reviewing the request.
* **Review Request Note Attachment** (20): Attach a file for the review request note.
* **Submitter Note** (21): Enter a note for the submitter.
* **Reviewer Note Attachment** (22): Attach a file for the reviewer note.
* **Form Status** (23): Select the status of the form (Active, Pending, or Inactive).
* **Submitter Email** (24): Enter the email address of the person submitting the form.
* **Submitted** (25): Enter the date and time the form was submitted.
