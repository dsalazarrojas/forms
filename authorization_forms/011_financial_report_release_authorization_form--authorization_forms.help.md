# Financial Report Release Authorization Form - Help Guide
## Purpose
The Financial Report Release Authorization Form is used to request access to financial reports for the purpose of releasing confidential information. This form ensures that only authorized personnel can access these reports and that the authorization is properly documented.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your user information, if required.
2. Select the type of report you need to access using the dropdown menu.
3. Choose the type of authorization you need, either General Consent, Specific Consent, or Revocation.
4. Enter the date of authorization and, if applicable, the date of revocation.
5. Enter your contact information, including email and phone number.
6. Add any additional comments or notes.

## Field-by-Field Explanation
* **User Information**: Enter your name, if required, to identify yourself as the user requesting access.
* **Form ID**: Enter a unique ID for this authorization, if required.
* **Report Type**: Select the type of financial report you need to access, such as Balance Sheets, Cash Flow, or Income Statements.
* **Authorization Type**: Choose the type of authorization you need, either General Consent, Specific Consent, or Revocation.
* **Effective Date**: Enter the date when this authorization becomes effective.
* **Authorization Date**: Enter the date when this authorization was granted.
* **Expiration Date**: Enter the date when this authorization will expire.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Notes**: Add any additional comments or notes about your request.
