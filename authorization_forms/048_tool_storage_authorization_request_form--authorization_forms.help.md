# Tool Storage Authorization Request Form - Help Guide
## Purpose
This form is used to request authorization to store a tool within the tool storage system.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the required fields, including tool-id, name, and request-date.
2.  Select the required access type (Admin, User, or Group).
3.  Choose the approver for your tool storage request (Jimmy, John, or Jane).
4.  Provide a note for the approver to review (optional).
5.  Enter the duration of tool storage in months.
6.  Enter the size of tool storage in units.
7.  Select the location for tool storage.

## Field-by-Field Explanation
*   **tool-id (text)**: Enter the ID of the tool you want to store.
*   **name (text)**: Enter a name for the tool that will be displayed in the storage system.
*   **request-date (date)**: Enter the date you are requesting tool storage for.
*   **request-time (time)**: Enter the time you are requesting tool storage for.
*   **tool-description (text)**: Enter a description for the tool you want to store.
*   **access-type (select multiple)**: Select the types of users who will have access to the tool (Admin, User, or Group).
*   **approver (select one)**: Select the person who will approve your tool storage request (Jimmy, John, or Jane).
*   **approver-note (note)**: Enter a note for the approver to review (optional).
*   **storage-duration (number)**: Enter the duration of tool storage in months.
*   **storage-size (number)**: Enter the size of tool storage in units.
*   **storage-location (text)**: Select the location where the tool will be stored.
