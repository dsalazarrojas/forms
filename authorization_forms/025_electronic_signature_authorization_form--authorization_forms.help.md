# electronic_signature_authorization_form - Help Guide
## Purpose
The electronic signature authorization form is a document that requires a user's electronic signature to authorize a specific action or process. This form is used to ensure that the user understands and agrees to the terms and conditions of the electronic signature.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form title with a brief description of the document.
2. Select the category of the form from the provided options.
3. Provide a description of the form's purpose or content.
4. Select the user assigned to this form.
5. Add a file related to the form (if necessary).
6. Specify the date and time the form was submitted.
7. Select the type of signature required (Electronic, Paper, or Both).
8. Upload a file with the electronic signature (if required).
9. Add any additional notes or comments (if necessary).
10. Enter the email and phone number of the person who submitted the form.
11. Specify the number of required pages for the form.
12. Finally, click on the "Submit" button to save your form.

## Field-by-Field Explanation

* **Form Title** (`form_title`, `text`, required/optional): Enter a brief description of the document.
* **Category** (`category`, `select_one`, required/optional): Select the category of the form from the provided options.
* **Description** (`description`, `text`, required/optional): Provide a description of the form's purpose or content.
* **Assigned User** (`assigned_user`, `select_multiple`, required/optional): Select the user assigned to this form.
* **Form File** (`form_file`, `text`, required/optional): Add a file related to the form (if necessary).
* **Submitted At** (`submitted_at`, `date`, required/optional): Specify the date and time the form was submitted.
* **Submitted By** (`submitted_by`, `time`, required/optional): Specify the time the form was submitted.
* **Signature Type** (`signature_type`, `select_one`, required/optional): Select the type of signature required (Electronic, Paper, or Both).
* **Signature File** (`signature_file`, `text`, required/optional): Upload a file with the electronic signature (if required).
* **Note** (`note`, `note`, required/optional): Add any additional notes or comments (if necessary).
* **Email** (`email`, `email`, required/optional): Enter the email of the person who submitted the form.
* **Phone** (`phone`, `text`, required/optional): Enter the phone number of the person who submitted the form.
* **Required Pages** (`required_pages`, `number`, required/optional): Specify the number of required pages for the form.
* **Submit** (`submit_button`, `text`, required/optional): Click on the "Submit" button to save your form.
