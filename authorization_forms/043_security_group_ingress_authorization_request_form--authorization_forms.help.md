# security_group_ingress_authorization_request_form - Help Guide
## Purpose

The "security_group_ingress_authorization_request_form" is used to request access to a specific security group. This form provides the necessary information for the approval process, ensuring that requests are properly reviewed and approved before granting access.

## How To Complete This Form

1. **Request Form** (`1`, `text`, optional)
	* Enter a brief description of your request in the "Request Form" field. This is the main content of your request.
2. **Security Group** (`2`, `text`, optional)
	* Enter the name of the security group you are requesting access to.
3. **Ingress Point** (`3`, `text`, optional)
	* Enter the ingress point you want to access (e.g., network port, system service).
4. **Access Level** (`4`, `select_one`, optional)
	* Select the level of access you require:
		+ Low: Read-only access
		+ Medium: Read and write access
		+ High: Full access
5. **Justification** (`5`, `text`, optional)
	* Provide a detailed explanation for your request, including the purpose and benefits of granting access.
6. **Approved By** (`6`, `select_multiple`, optional)
	* Select the team members or roles that you would like to approve your request:
		+ IT
		+ Security
		+ Management
7. **Comments** (`7`, `text`, optional)
	* Add any additional comments or notes about your request.
8. **Submit** (`8`, `text`, optional)
	* Click the "Submit" button to complete and submit your request.

## Tips

* Please ensure that your request is complete and accurate before submitting it.
* If you have already submitted a request for the same security group, do not re-submit it.
