# leaseTerminationAuthorizationForm - Help Guide

## Purpose
The leaseTerminationAuthorizationForm is used to document the details of a lease termination, which is an essential step when a tenant's lease is being ended or modified.

## How To Complete This Form
To complete this form, follow these steps:
- Ensure you have all the necessary information and documents required for lease termination.
- Select the correct page (form1, form2, etc.) and fill out the corresponding fields.
