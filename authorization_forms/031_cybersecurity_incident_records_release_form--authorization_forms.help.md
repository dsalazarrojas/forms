# cybersecurity_incident_records_release_form - Help Guide
## Purpose
This form is for reporting and releasing cybersecurity incident records. It captures critical information about the incident, including the organization's details, incident category, and contact information for the person responsible.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter your organization's name in the **Organization** field.
2. Type or paste the incident ID, which is a unique identifier for the incident.
3. If available, enter the date and time of the incident using the date and time fields. These fields are not required but help in tracking the incident timeline.
4. In the **Incident Details** field, provide a detailed description of the incident, including what happened, how it affected your organization, and any relevant details.
5. Select the category of the incident from the **Category** field, which could be **Financial**, **IT**, **Legal**, or **Other**. You can select multiple categories if applicable.
6. Select a subcategory for the incident from the **Subcategory** field, which provides more specific details within the selected category.
7. Enter the name and email of the contact person responsible for the incident.
8. If necessary, enter the contact person's phone number.

## Field-by-Field Explanation
* **Organization** (organization, text, required): Enter the name of the organization that experienced the incident.
* **Incident ID** (incident_id, number, required): Enter the unique identifier for the incident.
* **Incident Date** (incident_date, date, optional): If known, enter the date of the incident.
* **Incident Time** (incident_time, time, optional): If known, enter the time of the incident.
* **Incident Details** (incident_details, text, required): Provide a detailed description of the incident.
* **Category** (incident_category, select multiple, required): Select the category of the incident from **Financial**, **IT**, **Legal**, or **Other**.
* **Subcategory** (incident_subcategory, select one, required): Select a more specific subcategory within the selected category.
* **Contact Person** (contact_person, text, required): Enter the name of the contact person responsible for the incident.
* **Contact Email** (contact_email, email, required): Enter the email of the contact person responsible for the incident.
* **Contact Phone** (contact_phone, text, optional): If necessary, enter the contact person's phone number.

## Tips
* Ensure that you provide a detailed and accurate description of the incident in the **Incident Details** field.
* If you are unsure of the incident category or subcategory, select the closest match or contact your organization's incident response team for guidance.
* Double-check that you have entered the correct contact information for the person responsible for the incident.
* If you need to report multiple incidents, complete a separate form for each incident.
