# Event Access Authorization Form - Help Guide
## Purpose
The Event Access Authorization Form is used to grant access to events for specific users or groups.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form completely and accurately.
* Ensure that the information provided is up-to-date and correct.
* Review the form before submission to ensure you have filled out all necessary fields.

## Field-by-Field Explanation
* **Event Info** (1, text, required/optional): This field is used to enter a brief description of the event.
* **Access Level** (2, select_one, required/optional): Select the level of access you want to grant to the user. Options include:
	+ admin: Administrator access
	+ staff: Staff access
	+ attendee: Attendee access
	+ vendor: Vendor access
* **Access Level Options** (3, select_multiple, required/optional): Select multiple access levels for the user. This field is optional and allows you to grant multiple access levels.
* **Access Dates** (4, date, required/optional): Enter the dates you want the user to have access to the event.
* **Access Duration** (5, time, required/optional): Enter the duration of access you want to grant to the user. This field is typically used for time-sensitive events.
* **Access Notes** (6, note, required/optional): Add any additional notes or comments about the access request.
* **Contact Info** (7, number, required/optional): Enter the contact information for the user, such as their phone number.
* **Email** (8, email, required/optional): Enter the email address of the user.
* **Phone** (9, text, required/optional): Enter the phone number of the user.

Note: This form is not meant to be filled out by the user requesting access. It is intended for the event organizer to grant access to the event for the specified user or group.
