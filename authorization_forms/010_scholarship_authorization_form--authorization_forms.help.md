# Scholarship Authorization Form - Help Guide
## Purpose
The Scholarship Authorization Form is used to verify and manage student scholarship applications. This form is intended for authorized personnel to review and approve or deny applications.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the form for each student with their corresponding application.
2. Ensure all required fields are filled out correctly.
3. Review the student's status and select the appropriate option from the dropdown menu.
4. Select all relevant scholarship programs the student is eligible for.
5. Enter the scholarship amount and authorize the application.

## Field-by-Field Explanation
* **Student Application**: Enter the student's application details in this field.
* **Student ID**: Enter the student's unique ID number.
* **Institution Name**: Enter the name of the institution the student is associated with.
* **Student Name**: Enter the student's name.
* **Student Contact**: Enter the student's contact information.
* **Student Status**: Select the student's current status from the dropdown menu:
	+ `active`: The student is currently active.
	+ `inactive`: The student is currently inactive.
	+ `pending`: The student's status is pending.
* **Scholarship Program**: Select all relevant scholarship programs the student is eligible for.
* **Scholarship Amount**: Enter the amount of the scholarship being offered to the student.
* **Authorization**: Select the authorization status from the dropdown menu:
	+ `approved`: The application has been approved.
	+ `denied`: The application has been denied.
	+ `pending`: The application is still pending.
* **Reason Denied (optional)**: If the application has been denied, enter the reason for denial.
* **Notes (optional)**: Enter any additional notes or comments about the application.
