# Work Authorization Renewal Form - Help Guide
## Purpose
The Work Authorization Renewal Form is used by employees to renew their work authorization, ensuring they can continue working on specific projects or tasks.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the employee's ID number.
2. Enter the current job title and a detailed job description.
3. Select the correct supervisor's name.
4. Choose the date of the work authorization.
5. Specify the work hours for the authorization period.
6. Select the department and location where the work will be performed.
7. Choose the status of the work authorization.
8. Optionally, add any comments.
9. Select the names of the people assigned to and by this work authorization.

## Field-by-Field Explanation
* **Employee ID (`employee_id`, number, required)**: Enter the employee's ID number.
* **Job Title (`job_title`, text, required)**: Enter the current job title of the employee.
* **Supervisor Name (`supervisor_name`, text, required)**: Enter the name of the supervisor responsible for the employee.
* **Job Description (`job_description`, text, optional)**: Provide a detailed job description for the work authorization.
* **Work Authorization Date (`work_authorization_date`, date, required)**: Choose the date the work authorization should start.
* **Work Hours (`work_hours`, number, required)**: Enter the number of work hours for the authorization period.
* **Department (`department`, select multiple, optional)**: Select the department(s) responsible for the work authorization.
* **Location (`location`, select multiple, optional)**: Choose the location(s) where the work will be performed.
* **Work Authorization Status (`work_authorization_status`, select one, optional)**: Choose the status of the work authorization (Approved, Rejected, or Pending).
* **Comments (`comments`, note, optional)**: Add any additional comments for the work authorization.
* **Assigned To (`assigned_to`, select multiple, optional)**: Select the names of people assigned to this work authorization.
* **Assigned By (`assigned_by`, select multiple, optional)**: Select the name(s) of the person(s) assigning this work authorization.
