# Source Code Waiver Request Form - Help Guide
## Purpose
The Source Code Waiver Request Form is used to request access to sensitive or proprietary source code. This form must be completed by the requestor to ensure proper evaluation of their request.
## How To Complete This Form
Before completing this form, please ensure that you have the necessary clearance to access the source code you are requesting. If you are unsure, consult with your manager or supervisor.

To complete this form, follow these steps:

1. Enter your First Name, Last Name, and Email address. Your Email address will be used to contact you if any additional information is required.
2. Enter your Phone number, which will be used to contact you if necessary.
3. Choose the date you wish to request access to the source code, as it must be approved prior to that date.
4. Enter a brief Reason for your request, explaining why you need access to the source code.
5. If you have a manager, select whether or not they have reviewed or will review your request.
6. If you have a manager, enter their name in the Manager Name field.
7. Enter your Name in the Requestor field.
8. Select which teams you have access to, as some teams may be restricted from accessing certain code.
9. Enter any additional Comments regarding your request.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Enter your first name.
* **Last Name** (`last_name`, text, required): Enter your last name.
* **Email** (`email`, email, required): Enter your email address, which will be used to contact you if any additional information is required.
* **Phone** (`phone`, text, required): Enter your phone number, which will be used to contact you if necessary.
* **Request Date** (`request_date`, date, required): Choose the date by which you wish to request access to the source code.
* **Reason** (`reason`, text, optional): Enter a brief reason why you need access to the source code. This will help us understand your request.
* **Manager** (`manager`, select_one, required): Select whether or not your manager has reviewed or will review your request.
* **Manager Name** (`manager_name`, text, required if manager is selected): If your manager has reviewed or will review your request, enter their name here.
* **Requestor** (`requestor`, text, required): Enter your full name in the Requestor field.
* **Team** (`team`, select_multiple, required): Select which teams you have access to, as some teams may be restricted from accessing certain code.
* **Comments** (`comments`, note, optional): Enter any additional comments regarding your request.
