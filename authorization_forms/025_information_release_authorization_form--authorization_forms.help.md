# information_release_authorization_form - Help Guide
## Purpose
This form is used to collect information for the authorization of data release. It is meant to be filled out by individuals or organizations requesting access to data, ensuring that their identity, purpose, and other relevant details are verified.

## How To Complete This Form
1. Fill out the form accurately and thoroughly, providing all required information.
2. Ensure that all fields are filled out with correct and up-to-date information.
3. Review the form carefully before submitting to ensure that all details are correct.

## Field-by-Field Explanation
* **Organization**: The organization making the request.
	+ Type: Text
	+ A brief description of the organization requesting access to the data.
* **Contact Person**: The person making the request on behalf of the organization.
	+ Type: Text
	+ The name of the person making the request.
* **Contact Email**: The email address of the contact person.
	+ Type: Email
	+ The email address of the person making the request.
* **Purpose of Request**: A brief description of the purpose of the request.
	+ Type: Text
	+ A short description of why the data is being requested.
* **Authorized By**: The person or authority that has authorized the request.
	+ Type: Text
	+ The name of the person authorizing the request.
* **Authorized Date**: The date the request was authorized.
	+ Type: Date
	+ The date on which the request was approved.
* **Authorized Time**: The time the request was authorized.
	+ Type: Time
	+ The time on which the request was approved.
* **Release Type**: Whether the data is a release or not.
	+ Type: Select one
	+ Options: Yes, No
	+ Select 'Yes' if the data is to be released.
* **Data Subjects**: The subjects related to the data being requested.
	+ Type: Select multiple
	+ Options: Yes, No
	+ Select all relevant data subjects.
* **Notes**: Any additional comments or remarks.
	+ Type: Note
	+ A field for any additional information.
* **Submitter**: The person submitting the request.
	+ Type: Text
	+ The name of the person submitting the request.
* **Submitter Email**: The email address of the submitter.
	+ Type: Email
	+ The email address of the person submitting the request.
* **Submitter Contact**: Additional contact information for the submitter.
	+ Type: Text
	+ Any additional contact information.
* **Submitter Organization**: The organization of the submitter.
	+ Type: Text
	+ The name of the organization of the submitter.
* **Submitter Title**: The title of the submitter.
	+ Type: Text
	+ The job title or position of the submitter.
* **Submitter Phone**: The phone number of the submitter.
	+ Type: Text
	+ The phone number of the submitter.
* **Submitter Fax**: The fax number of the submitter.
	+ Type: Text
	+ The fax number of the submitter.
