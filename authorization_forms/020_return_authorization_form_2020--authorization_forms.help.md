# return-authorization-form-2020 - Help Guide
## Purpose
The Return Authorization Form 2020 is designed for employees to request returns from company property, including equipment, tools, or other materials. This form is used by both employees and managers to track and manage return requests in an organized and transparent way.

## How To Complete This Form

1.  Fill in the required fields marked as required (indicated by an asterisk *), such as "Return Status".
2.  Ensure that you have filled out all the fields correctly before submitting the form.
3.  If you are unsure about any field, refer to the field-by-field explanation section below.

## Field-by-Field Explanation

* **Company** (`company`, text, optional): This field is for entering the name of the company.
* **Employee** (`employee`, text, optional): This field is for entering the name of the employee requesting the return.
* **Manager** (`manager`, text, optional): This field is for entering the name of the manager handling the return request.
* **Reason** (`reason`, text, optional): This field is for entering the reason for the return request.
* **Date** (`date`, date, required): This field is for selecting the date when the return is due.
* **Signature** (`signature`, note, optional): This field is for the employee to sign and date the form.
* **Return Date** (`return_date`, date, optional): This field is for selecting the date the return is expected.
* **Employee Phone** (`employee_phone`, text, optional): This field is for entering the employee's contact phone number.
* **Manager Phone** (`manager_phone`, text, optional): This field is for entering the manager's contact phone number.
* **Company Email** (`company_email`, email, optional): This field is for entering the company's email address.
* **Manager Email** (`manager_email`, email, optional): This field is for entering the manager's email address.
* **Manager Title** (`manager_title`, select_multiple, optional): This field is for selecting the manager's title from the available options (CFO, CMO, COO).
* **Employee Title** (`employee_title`, select_multiple, optional): This field is for selecting the employee's title from the available options (Intern, Team Leader, Manager).
* **Company Address** (`company_address`, text, optional): This field is for entering the company's address.
* **Manager Address** (`manager_address`, text, optional): This field is for entering the manager's address.
* **Return Reason** (`return_reason`, text, optional): This field is for entering a detailed reason for the return.
* **Return Comment** (`return_comment`, text, optional): This field is for providing additional comments about the return request.
* **Return Status** (`return_status`, select_one, required): This field is for selecting the status of the return request (Approved, Denied).
* **Approval Date** (`approval_date`, date, optional): This field is for selecting the date when the return request was approved.
* **Approval Time** (`approval_time`, time, optional): This field is for selecting the time when the return request was approved.
* **Approved By** (`approved_by`, select_one, optional): This field is for selecting who approved the return request (Chatbot, Manager).
* **Return Date** (`return_date`, date, optional): This field is for selecting a date for the return, but it seems it may not be used.
* **Approval Note** (`approval_note`, note, optional): This field is for adding notes about the approval.
* **Return Status 2** (`return_status2`, select_one, optional): This field is for selecting another status of the return request (Approved, Denied).
* **Return Status 3** (`return_status3`, select_one, optional): This field is for selecting another status of the return request (Approved, Denied).

## Tips
- Make sure to fill out all required fields before submitting the form.
- Review the form carefully before submitting it for accuracy and completeness.
- If you have any doubts or questions about the form, contact your supervisor or the help desk for assistance.
