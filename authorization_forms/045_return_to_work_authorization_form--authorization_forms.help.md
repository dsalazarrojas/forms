# Return To Work Authorization Form - Help Guide
## Purpose
The Return To Work Authorization Form is used to notify the supervisor and HR department that an employee is returning to work after an absence. It requires the employee's information, including their name, work status, and authorization date, as well as supervisor comments and a doctor's note.

## How To Complete This Form

1. Fill in the Employee Name field with the employee's full name.
2. Select the Date Of Return field using the provided date picker or input format (YYYY-MM-DD).
3. Choose the Work Status field from the options: On-site, Remote, or Leave.
4. If required, sign the form with your supervisor's signature in the Supervisor Signature field.
5. If required, sign the form with your employee's signature in the Employee Signature field.
6. Enter your comments for the supervisor's review in the Supervisor Comments fields.
7. Fill in the Doctor's Note field with the relevant information, if required.
8. If applicable, enter the Job Code in the Job Code field.
9. If applicable, provide a Reason For Return in the Reason For Return field.
10. Enter your expected Work Hours in the Work Hours field, if required.
11. Enter your expected Work Days in the Work Days field, if required.
12. Enter your expected Work Hours Start and End times in the Work Hours Start and Work Hours End fields, if required.
13. Select the Work Days you plan to work in the Work Days field, if required.

## Field-by-Field Explanation

* **Employee Name** (Text, Required): Enter the employee's full name.
* **Date Of Return** (Date, Required): Select the date the employee will return to work.
* **Work Status** (Select One, Required): Choose the work status: On-site, Remote, or Leave.
* **Supervisor Signature** (Text, Required): Sign with your supervisor's signature if required.
* **Employee Signature** (Text, Optional): Sign with your employee's signature if required.
* **Doctor's Note** (Text, Required): Enter the relevant information from the doctor's note.
* **Job Code** (Text, Optional): Enter the job code, if applicable.
* **Reason For Return** (Text, Optional): Provide a reason for returning to work.
* **Work Hours** (Number, Optional): Enter the expected work hours.
* **Work Days** (Select Multiple, Required): Select the days you plan to work.
* **Work Hours Start** and **Work Hours End** (Time, Optional): Enter your expected work hours start and end times.
* **Supervisor Comments** (Text, Optional): Enter comments for the supervisor's review.
*   **Supervisor Comments 2** and **Supervisor Comments 3** and **Supervisor Comments 4** (Text, Optional): Enter comments for the supervisor's review, if necessary.
*   **Supervisor Comments 1** and **Supervisor Comments 5**, not listed
