# Contractor Access Authorization Form - Help Guide
## Purpose
The purpose of this form is to request authorization for a contractor to access various areas of the organization. This form ensures that all necessary information is collected to assess the contractor's access level, locations, and systems access requirements.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the contractor's personal details:
   - Enter the contractor's full name as it appears on their ID.
   - Enter the contractor's email address.
   - Enter the contractor's phone number.
2. Enter the contracting company's details:
   - Enter the name of the contracting company or agency.
3. Select the access type required for the contractor:
   - Choose the level of access needed (e.g., Building Access Only, Network Access Only, etc.).
4. Select the locations requiring access:
   - Choose all applicable locations where the contractor will need access.
5. Enter the access start and end dates:
   - Set the date when the contractor's access should begin and expire.
6. Select the authorized access hours:
   - Choose the time periods when access is allowed (e.g., 24 Hours, Business Hours Only, etc.).
7. Confirm system access requirements:
   - Select all systems the contractor needs to access (e.g., Email System, Project Management Tool, etc.).
8. Enter the data classification level:
   - Choose the highest level of data access needed.
9. Enter the requesting manager's details:
   - Enter the name and email of the manager requesting access.
10. Select the department the contractor will work with:
    - Choose the department the contractor will be working with.
11. Enter the business justification:
    - Explain the reason for access authorization.
12. Enter the project name (optional):
    - If applicable, enter the name of the project the contractor is working on.
13. Confirm security requirements:
    - Check if a background check has been completed, if a non-disclosure agreement has been signed, and if required security training has been completed.
14. Add any additional comments or special requirements:
    - Enter any other relevant information or special requirements.

## Field-by-Field Explanation

* **Contractor Full Name** (`contractor_name`, text, required): Enter the contractor's full name as it appears on their ID.
* **Contractor Email** (`contractor_email`, email, required): Enter the contractor's primary email address.
* **Contractor Phone** (`contractor_phone`, text, required): Enter the best contact number for the contractor.
* **Contracting Company Name** (`company_name`, text, required): Enter the name of the contracting company or agency.
* **Access Type** (`access_type`, select_one, required): Choose the level of access needed (e.g., Building Access Only, Network Access Only, etc.).
* **Locations Requiring Access** (`access_locations`, select_multiple, required): Choose all locations where the contractor will need access.
* **Access Start Date** (`access_start_date`, date, required): Set the date when the contractor's access should begin.
* **Access End Date** (`access_end_date`, date, required): Set the date when the contractor's access should expire.
* **Authorized Access Hours** (`access_hours`, select_one, required): Choose the time periods when access is allowed (e.g., 24 Hours, Business Hours Only, etc.).
* **Network Access Required** (`network_access_required`, select_one, required): Check if the contractor needs network access.
* **Systems to Access** (`systems_list`, select_multiple, optional): Choose all systems the contractor needs to access.
* **Data Classification Level** (`data_classification_level`, select_one, required): Choose the highest level of data access needed.
* **Requesting Manager Name** (`requesting_manager`, text, required): Enter the name of the manager requesting access.
* **Requesting Manager Email** (`manager_email`, email, required): Enter the email of the requesting manager.
* **Department** (`department`, select_one, required): Choose the department the contractor will work with.
* **Business Justification** (`business_justification`, text, required): Explain the reason for access authorization.
* **Project Name** (`project_name`, text, optional): If applicable, enter the name of the project the contractor is working on.
* **Background Check Status** (`background_check_status`, select_one, required): Check if a background check has been completed.
* **NDA Signed** (`nda_signed`, select_one, required): Check if a non-disclosure agreement has been signed.
* **Security Training Completed** (`security_training_completed`, select_one, required): Check if required security training has been completed.
* **Emergency Contact Name** (`emergency_contact_name`, text, optional): Enter the name of the emergency contact.
* **Emergency Contact Phone** (`emergency_contact_phone`, text, optional): Enter the phone number for the emergency contact.
* **Special Requirements or Restrictions** (`special_requirements`, text, optional): Enter any special conditions or limitations.
* **Additional Comments** (`additional_comments`, text, optional): Enter any other relevant information.

## Tips

* Please ensure all required fields are filled before submitting the form.
* Double-check your selections to ensure accuracy and completeness.
* If you are unsure about any field, please reach out to the relevant team for guidance.
