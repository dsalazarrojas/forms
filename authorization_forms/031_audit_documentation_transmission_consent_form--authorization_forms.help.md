# Audit Documentation Transmission Consent Form - Help Guide

## Purpose
The Audit Documentation Transmission Consent Form is a document that requires the requestor to provide information about the audit documentation they are requesting to be transmitted to a recipient. This form is necessary to ensure that the recipient has the necessary permissions to receive and handle sensitive audit documentation.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the required fields with the correct information:
	* **Requestor Full Name**: Enter the legal name of the person requesting the transmission.
	* **Email Address**: Enter the email address of the person requesting the transmission.
	* **Phone Number**: Enter the phone number of the person requesting the transmission.
	* **Organization Name**: Enter the name of the organization or firm requesting the transmission.
	* **Consent Date**: Enter the date of the consent request.
	* **Audit Period**: Enter the period covered by the audit documentation.
	* **Audit Type**: Select the type of audit conducted (e.g. Financial Audit, Internal Audit, etc.).
	* **Documentation Description**: Describe the documentation to be transmitted.
	* **Transmission Purpose**: Select the purpose of the transmission (e.g. Regulatory filing, Client request, etc.).
	* **Recipient Name**: Enter the name of the person receiving the documentation.
	* **Recipient Organization**: Enter the organization of the person receiving the documentation.
	* **Recipient Email**: Enter the email address of the person receiving the documentation.
	* **Recipient Relationship**: Select the recipient's relationship to the audit (e.g. Client representative, Regulatory body, etc.).
	* **Transmission Method**: Select the method of transmission (e.g. Secure email, Encrypted file transfer, etc.).
	* **Data Sensitivity**: Classify the data being transmitted (e.g. Public, Internal use only, etc.).
	* **Confidentiality Agreement**: Select whether the recipient has agreed to confidentiality terms.
	* **Retention Period**: Select the period for which the recipient should retain the documentation (e.g. 1 year, 3 years, etc.).
	* **Destruction Requirements**: Select whether there are specific destruction requirements.
	* **Authorization Confirmed**: Confirm that you are authorized to approve this transmission.
	* **Requestor Signature**: Type your full name as an electronic signature.
	* **Signature Date**: Enter the date of consent.
