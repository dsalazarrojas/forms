# Thanksgiving Turkey Pre Order Form - Help Guide
## Purpose
The purpose of this form is to gather information from customers or employees to place an order for a turkey to be purchased or delivered for the holiday.

## How To Complete This Form
1. Enter the relevant information in each field as prompted, starting from the top of the form.
2. Fill in the "Thanksgiving Turkey Pre Order" field with any details you have regarding the order.
3. Indicate if you will be having a "Thanksgiving" by selecting "Yes" in the "Thanksgiving Date" field. This will help the form recipient know when to fulfill the order.
4. For the "Turkey Breed" field, select the breed of turkey you would like to purchase. This field is optional.
5. If you would like to purchase multiple turkeys, select the number of "Turkeys" in the "Turkey Number" field. This field is optional.
6. Select the size of the turkey you would like to purchase from the options in the "Turkey Size" field. This field is optional.
7. Enter your name in the "Customer Name" field.
8. Enter a valid email address in the "Customer Email" field. This will help the form recipient contact you about the order.
9. Enter your phone number in the "Customer Phone" field.
10. If you have any additional comments or requests regarding your order, enter them in the "Notes" field.
11. Enter your shipping address in the "Customer Address" field.

## Field-by-Field Explanation
- **Thanksgiving Turkey Pre Order**: Enter any details you have about the order. (text)
  This field allows you to enter any information you would like to provide about the order.
  
- **Thanksgiving Date**: Select "Yes" if you are having a Thanksgiving celebration. (Select One)
  This field helps the form recipient know when to fulfill the order.
  
- **Turkey Breed**: Select the breed of turkey you would like to purchase (Select One)
  This field allows you to specify which type of turkey you would like to purchase. This field is optional.
  
- **Turkey Number**: Select the number of turkeys you would like to purchase (Select Multiple)
  This field allows you to specify if you would like to purchase more than one turkey. This field is optional.
  
- **Turkey Size**: Select the size of turkey you would like to purchase (Select Multiple)
  This field allows you to specify the size of the turkey you would like to purchase. This field is optional.
  
- **Customer Name**: Enter your name. (Text)
  This field allows you to enter your name so the form recipient can contact you about the order.
  
- **Customer Email**: Enter a valid email address. (Email)
  This field allows you to enter a valid email address so the form recipient can contact you about the order.
  
- **Customer Phone**: Enter your phone number. (Text)
  This field allows you to enter your phone number so the form recipient can contact you about the order.
  
- **Notes**: Enter any additional comments or requests. (Note)
  This field is for any additional comments or requests you would like to make regarding the order.
  
- **Customer Address**: Enter your shipping address. (Text)
  This field is for your shipping address so the order can be delivered to you.
