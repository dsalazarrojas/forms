# Grazing Project Approval Survey - Help Guide
## Purpose
The Grazing Project Approval Survey is a form used to collect information on grazing projects, which are initiatives aimed at managing and protecting grazing lands. This form is designed to gather project details, environmental impact, and contact information to facilitate approval and coordination among relevant parties.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **Project Location** in the text field. This is the location where the grazing project will take place.
2. Select the **Project Start Date** and **Project End Date** using the date picker. Make sure to select dates that accurately represent the project's duration.
3. Enter the **Project Duration** in days. This is the number of days the project will last.
4. Choose the **Animal Type** related to the project from the dropdown options: Cattle, Sheep, Horses, or Other.
5. Describe the **Grazing Area** in the text field. This is the area where the grazing project will occur.
6. Provide a brief description of the **Environmental Impact**, if any, in the text field. This may include any potential effects on the environment due to the project.
7. Enter the name and title of the **Project Leader** in the text field. This person is responsible for overseeing the project.
8. Enter the name of the **Organization** involved in the project in the text field.
9. Enter the name of the **Agency** responsible for the project in the text field.
10. Enter the **Contact Number** of the project leader or contact person in the text field.
11. Enter the **Email** address of the project leader or contact person in the email format.
12. Enter the **Contact Address** of the project leader or contact person in the text field.
13. Add a brief **Project Description** in the text field. This should outline the project's objectives, scope, and goals.
14. Add any additional **Project Notes** in the text field. This is an optional field for any further information or comments.

## Field-by-Field Explanation
* **Project Location**: Enter the location where the grazing project will take place.
* **Project Start Date**: Select the date when the project will begin.
* **Project End Date**: Select the date when the project will end.
* **Project Duration**: Enter the number of days the project will last.
* **Animal Type**: Choose the type of animals related to the project (Cattle, Sheep, Horses, or Other).
* **Grazing Area**: Describe the area where the project will occur.
* **Environmental Impact**: Describe any potential effects on the environment due to the project (if any).
* **Project Leader**: Enter the name and title of the person overseeing the project.
* **Organization**: Enter the name of the organization involved in the project.
* **Agency**: Enter the name of the agency responsible for the project.
* **Contact Number**: Enter the contact number of the project leader or contact person.
* **Email**: Enter the email address of the project leader or contact person.
* **Contact Address**: Enter the contact address of the project leader or contact person.
* **Project Description**: Add a brief description of the project's objectives, scope, and goals.
* **Project Notes**: Add any additional notes or comments about the project (optional).
