# Pesticide Application Record - Help Guide
## Purpose
The "Pesticide Application Record" form is used to store and document information related to pesticide applications. This form is meant to record the details of each application for future reference, reporting, or auditing purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Application Date" field with the date of the pesticide application.
2. Enter the name of the person who applied the pesticide in the "Applicator Name" field.
3. Provide the location where the pesticide was applied in the "Location" field.
4. Enter the name of the pesticide product used in the "Product" field.
5. Select the type of application made (Yes/No) in the "Application Type" field.
6. Describe the area treated in the "Treated Area" field.
7. Note any conditions related to the application in the "Conditions" field.
8. Add any additional comments or notes about the application in the "Notes" field.

## Field-by-Field Explanation
- **Application Date** (`Date`, Required): The date on which the pesticide application was made.
- **Applicator Name** (`Text`, Required): The name of the person who applied the pesticide.
- **Location** (`Text`, Required): The location where the pesticide was applied.
- **Product** (`Text`, Required): The name of the pesticide product used.
- **Application Type** (`Select One`, Optional): Select "Yes" if the application was made, "No" otherwise.
- **Treated Area** (`Text`, Optional): A description of the area treated with the pesticide.
- **Conditions** (`Text`, Optional): Any conditions or notes about the application.
- **Notes** (`Note`, Optional): Additional comments or notes about the application.

## Tips
* Make sure to fill out the form accurately and consistently to ensure that your records are reliable.
* If you need to report or reference an application in the future, this form will help you retrieve the information quickly and easily.
* If you have any concerns or questions about the form, contact your supervisor or department head for assistance.
