# Farmland Transition Feedback Form - Help Guide
## Purpose
This form is designed to collect feedback from farmers and landowners about their transition experience, satisfaction levels, support needs, and other related details.

## How To Complete This Form
1. To complete this form, start by filling out each section in order, from top to bottom.
2. For text and note fields, type or write your answers in the space provided.
3. For select fields, choose one or multiple options from the list provided.
4. Make sure to fill out all required fields, as indicated by the required label next to the field.
5. You can save your progress and come back later to continue filling out the form.

## Field-by-Field Explanation

* **Land Transfer Experience**: This field is a text input where you can describe your experience with land transfer.
* **Satisfaction Prophets**: This is a number input field where you can rate your level of satisfaction.
* **Support Needs**: This field allows you to select multiple needs for support, such as Farming equipment, Market access, Land tenure, Business training, or Other.
* **Feedback**: This field is a text note where you can provide additional feedback.
* **Goals**: This field is a select field where you can choose one or multiple goals, such as Land development, Land consolidation, Land acquisition, Farmland management, or Farm equipment.
* **Farm Equipment**: This field is a select field where you can choose whether or not you have farm equipment.
* **Email**: This field is a text input where you can enter your email address.
* **Phone**: This field is a text input where you can enter your phone number.
* **Land Use**: This field is a select field where you can choose the use of your land, such as Residential, Commercial, Agricultural, Recreational, or Other.
* **Farmland**: This field is a text note where you can describe your farmland.
* **Notes**: This field is a text note where you can add additional information.
* **Submission Date**: This field is a date input where you can enter the date of your submission.
* **Submission Time**: This field is a time input where you can enter the time of your submission.
* **Submission User**: This field is a text input where you can enter the username responsible for this submission.
* **Submission Device**: This field is a text input where you can enter the device used for this submission.
* **Prophets**: This field is a select field where you can select multiple prophets, such as Farming or Other.
* **Land Size**: This field is a number input where you can enter the size of your land.
* **Farm Equipment 2**: This field is a select field where you can choose whether or not you have farm equipment 2.
* **Notes 2**: This field is a text note where you can add additional information 2.
* **Submission Date 2**: This field is a date input where you can enter the date of your submission 2.
* **Submission Time 2**: This field is a time input where you can enter the time of your submission 2.
* **Land Use 2**: This field is a select field where you can choose whether or not your land use 2 is Yes.
* **Prophets 2**: This field is a select field where you can select whether or not you have prophets 2.
* **Submission User 2**: This field is a select field where you can choose the submission user 2 as Yes.
* **Submission Device 2**: This field is a select field where you can select the submission device 2 as Yes.
* **Land Use 2**: This field is a select field where you can choose the use of your land 2, such as Yes.

Please note that this form is for general guidance only and may require some modifications to fit the actual needs of your organization or agency. Also, please check your organization's or agency's specific policies for field-by-field requirements.
