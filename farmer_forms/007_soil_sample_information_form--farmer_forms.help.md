# soil_sample_information_form - Help Guide
## Purpose
The purpose of this form is to collect soil sample information for lab testing.

## How To Complete This Form
1. Fill out the form with the required information for the soil sample you are submitting to the lab.
2. Double-check your entries for accuracy before submitting the form.
3. Ensure that you have not already submitted this form for the same sample.

## Field-by-Field Explanation

* **soil_sample_info** (`soil_sample_info`, text, required/optional): Enter a brief description of the soil sample.
* **Sample Collection Date** (`sample_collection_date`, date, optional): Record the date the soil sample was collected.
* **Sample Location** (`sample_location`, text, optional): Describe the location where the soil sample was collected.
* **sample_comments** (`sample_comments`, text, optional): Enter any comments about the soil sample.
* **Lab Test Info** (`lab_test_info`, select_multiple, optional): Select which lab tests were performed on the sample (Yes/No).
* **Lab Test Results** (`lab_test_results`, select_one, optional): Specify the results of lab tests (Yes/No).
* **Soil Characteristics** (`soil_characteristics`, text, optional): Describe the characteristics of the soil sample.
* **Lab Test Request** (`lab_test_request`, select_one, optional): Was a lab test requested (Yes/No).
* **Lab Test Frequency** (`lab_test_frequency`, text, optional): Enter the frequency of lab tests.
* **Lab Test Request Reason** (`lab_test_request_reason`, text, optional): Enter the reason for lab test request.
* **Lab Test Result Comments** (`lab_test_result_comments`, text, optional): Enter comments about lab test results.
* **Lab Sample Received** (`lab_sample_received`, date, optional): Record the date the lab sample was received.
* **Lab Sample Sent** (`lab_sample_sent`, date, optional): Record the date the lab sample was sent.
* **Lab Test Cost** (`lab_test_cost`, text, optional): Enter the cost of the lab test.
* **Lab Test Status** (`lab_test_status`, select_one, optional): Specify the status of the lab test (Active/Inactive).
* **Farmer Comments** (`farmer_comments`, text, optional): Enter comments from the farmer about the soil sample.
* **Soil Type** (`soil_type`, select_one, optional): Was the soil type determined (Yes/No).
* **Sample Weight** (`sample_weight`, select_one, optional): Was the sample weight measured (Yes/No).
* **Sample Weight Unit** (`sample_weight_unit`, select_one, optional): Specify the unit of measurement for the sample weight (Yes/No).
* **Sample Container** (`sample_container`, select_one, optional): Was the sample in a container (Yes/No).
* **Sample Container ID** (`sample_container_id`, text, optional): Enter the ID of the sample container.
* **Lab Contact** (`lab_contact`, text, optional): Enter contact information for the lab.
* **Lab Test Requesting Physician** (`lab_test_requesting_physician`, text, optional): Enter the name of the physician requesting the lab test.
* **Lab Test Requesting Physician E-mail** (`lab_test_requesting_physician_email`, text, optional): Enter the email of the physician requesting the lab test.
* **Lab Test Requesting Physician Phone** (`lab_test_requesting_physician_phone`, text, optional): Enter the phone number of the physician requesting the lab test.
