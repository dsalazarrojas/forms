# Agricultural Land Use Survey - Help Guide

## Purpose

This form is used to collect information about a farm or agricultural land's usage and characteristics.

## How To Complete This Form

To complete this form, please answer each field according to your knowledge about your agricultural land. If you're unsure about any field, refer to the field-by-field explanation below for clarification.

## Field-by-Field Explanation

* **Landowner Name** (Landowner Name, text, required): This is the full name of the landowner.
* **Property Address** (Property Address, text, required): This is the physical address of the property, including the street address, city, state, and zip code.
* **Parcel Number** (Parcel Number, text, optional): This is the tax parcel or legal identifier of the property, if applicable.
* **Total Acreage** (Total Acreage, number, required): This is the total size of the property in acres.
* **Primary Land Use** (Primary Land Use, select_one, required): Choose the main use of the agricultural land (e.g., Cropland, Pasture, Rangeland, etc.).
* **Cropland Acres** (Cropland Acres, number, optional): If the primary land use is Cropland, enter the acres used for crop production.
* **Pasture Acres** (Pasture Acres, number, optional): If the primary land use is Pasture, enter the acres used for grazing.
* **Fallow Acres** (Fallow Acres, number, optional): If the primary land use is Fallow, enter the acres currently not in production.
* **Irrigation Type** (Irrigation Type, select_one, required): Choose the primary irrigation method used (e.g., None, Flood, Sprinkler, etc.).
* **Water Source** (Water Source, select_multiple, optional): Choose the primary source of irrigation water (e.g., Well, River/Stream, Lake/Pond, etc.).
* **Crops Grown (Current Season)** (Crops Grown, select_multiple, required): Select all crops currently grown on the property.
* **Livestock Present** (Livestock Present, select_one, required): Mark if any livestock is kept on the property.
* **Livestock Types** (Livestock Types, select_multiple, optional): If livestock is present, select all types of livestock.
* **Conservation Practices** (Conservation Practices, select_multiple, required): Select all conservation practices implemented on the property.
* **Primary Soil Type** (Primary Soil Type, select_one, optional): Choose the main soil type on the property (e.g., Clay, Loam, Sandy, etc.).
* **Land Slope** (Land Slope, select_one, required): Choose the general slope of the property (e.g., Flat, Gently sloping, Moderately sloping, etc.).
* **Organic Certified** (Organic Certified, select_one, required): Mark if any portion of the land is organically certified.
* **Years in Agricultural Operation** (Years in Agricultural Operation, select_one, required): Choose how long this has been a farm.
* **Future Land Use Plans** (Future Land Use Plans, text, optional): Enter any planned changes in land use within the next 5 years.
* **Survey Date** (Survey Date, date, required): Enter the date of survey completion.
