# Shipping Service Drop Off Check In Form - Help Guide
## Purpose
The Shipping Service Drop Off Check In Form is a tool used by package senders to provide necessary information about their packages when dropping them off for shipping services.

## How To Complete This Form

To complete this form, follow these steps:

1.  Enter the necessary information about the package you are dropping off.
2.  Ensure that all required fields are filled in.
3.  Review and submit the form for processing.

## Field-by-Field Explanation

* **Package ID** (shipping_service_drop_off_check_in_form_package_id): Unique numeric ID for the package
* **Service Name** (shipping_service_drop_off_check_in_form_service_name): Name of the shipping service
* **Service Provider** (shipping_service_drop_off_check_in_form_service_provider): Name of the shipping service provider
* **Date** (shipping_service_drop_off_check_in_form_date): Date of the package drop off
* **Time** (shipping_service_drop_off_check_in_form_time): Time of the package drop off
* **Weight** (shipping_service_drop_off_check_in_form_weight): Package weight in lbs
* **Length** (shipping_service_drop_off_check_in_form_length): Package length
* **Width** (shipping_service_drop_off_check_in_form_width): Package width
* **Height** (shipping_service_drop_off_check_in_form_height): Package height
* **Status** (shipping_service_drop_off_check_in_form_status): Package status (Normal, Delayed, On Hold, or Unknown)
* **Notes** (shipping_service_drop_off_check_in_form_notes): Any additional information about the package
* **Email Address** (shipping_service_drop_off_check_in_form_email_address): Contact email for the package sender
* **Phone Number** (shipping_service_drop_off_check_in_form_phone_number): Contact phone number for the package sender
* **Address** (shipping_service_drop_off_check_in_form_address): Package sender's address
* **City** (shipping_service_drop_off_check_in_form_city): Package sender's city
* **State** (shipping_service_drop_off_check_in_form_state): Package sender's state
* **Zip** (shipping_service_drop_off_check_in_form_zip): Package sender's zip

## Tips

*   Please ensure that all required fields are filled in.
*   Review the form for accuracy before submission.
*   Contact the shipping service provider with any questions or concerns.
