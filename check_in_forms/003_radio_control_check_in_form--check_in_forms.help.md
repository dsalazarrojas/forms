# radio_control_check_in_form - Help Guide
## Purpose

The purpose of this form is to collect information about participants for an event, ensuring that all necessary details are recorded and up-to-date.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the participant's information, including name, email, phone number, and additional notes.
2. Select the participant's status and the event status.
3. Enter the participant's name again (Participant Name 2) and phone number (Participant Phone 2).
4. Enter any additional notes about the participant.
5. Select the participant's status again (Participant Status 2).
6. Finally, enter the participant's date and the event's start and end times.

## Field-by-Field Explanation

* **Participant Information** (`participant_info`): Enter the participant's name, email, phone number, and additional notes.
* **Email Address** (`participant_email`): Enter the participant's email address.
* **Phone Number** (`participant_phone`): Enter the participant's phone number.
* **Additional Notes** (`participant_notes`): Enter any additional notes about the participant.
* **Participant Start Time** (`participant_time`): Enter the participant's start time.
* **Participant Date** (`participant_date`): Enter the participant's date.
* **Event Status** (`event_radio`): Select the status of the event.
* **Participant Status** (`participant_radio`): Select the participant's status.
* **Participant Name** (`participant_name`): Enter the participant's name.
* **Event Start Time** (`event_start_time`): Enter the event start time.
* **Event End Time** (`event_end_time`): Enter the event end time.
* **Participant Radio** (`participant_radio_2`): Select the participant's status.
* **Participant Info 2** (`participant_info_2`): Enter any additional information about the participant.
* **Participant Phone** (`participant_phone_2`): Enter the participant's phone number.
* **Participant Notes** (`participant_notes_2`): Enter any additional notes about the participant.
* **Participant Date 2** (`participant_date_2`): Enter the participant's date.
* **Tips**

* Make sure to double-check your inputs for accuracy.
* If you're unsure about any information, ask the participant for clarification.
* This form is designed to guide you through the process of checking in participants, so follow the form carefully to ensure completeness and accuracy.
