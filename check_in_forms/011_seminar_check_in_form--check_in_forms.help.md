# seminar_check_in_form - Help Guide
## Purpose
The seminar check-in form is designed to record attendee information for seminars and events. It is used to capture essential details about the event, attendee, and their role in the event.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the event ID to associate the check-in with the relevant event.
2. Enter the attendee's name.
3. Choose their role in the event (Attendee, Team, or Speaker).
4. Enter the start and end times of the event.

## Field-by-Field Explanation
### Event ID
* **event id** (Number, Required: False): Enter the ID of the event you are checking in to. This helps to identify the event and associate it with your check-in details.

### Attendee Name
* **attendee name** (Text, Required: False): Enter the name of the person checking in. This will be used to identify you for event-related communications and records.

### Role
* **role** (Select One, Required: False): Select your role in the event from the options provided:
	+ Attendee: If you are participating in the event as a regular attendee.
	+ Team: If you are part of a team or have a supporting role in the event.
	+ Speaker: If you are presenting or giving a talk during the event.

### Start Time
* **start time** (Time, Required: False): Enter the start time of the event. This helps the organizers know when the event begins. Use the 24-hour clock format (HH:MM).

### End Time
* **end time** (Time, Required: False): Enter the end time of the event. This helps the organizers know when the event concludes. Use the 24-hour clock format (HH:MM).
