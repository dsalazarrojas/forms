# Yoga Student Pre Session Readiness Check In - Help Guide
## Purpose
This form is used by yoga instructors to assess the readiness of students before each session. It helps to gather information about the student's physical and mental state, allowing the instructor to make informed decisions about their participation in the session.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill out the Student Name field with the student's name.
2. Enter the student's email address in the Email field, if applicable.
3. If the student has a phone number, enter it in the Phone field.
4. Add any relevant notes about the student in the Student Notes field.
5. Enter any relevant notes about the instructor in the Instructor Notes field.
6. Describe the session details in the Session Details field.
7. Select the Check In Status to indicate whether the student is active or inactive.
8. Indicate the student's readiness for the session by selecting "Yes" or "No" in the Student Readiness field.
9. Enter the Check In Time and Check In Date for the student.
10. Enter the Session Start Time and Session End Time for the session.
11. Select the Class Topic to indicate whether the student has been taught a class topic relevant to this session.
12. If applicable, enter the Studio Id and Assigned Tool fields.

## Field-by-Field Explanation
* **Student Name** (text, required): Enter the student's name.
* **Email** (email, optional): Enter the student's email address, if applicable.
* **Phone** (text, optional): Enter the student's phone number, if applicable.
* **Student Notes** (text, optional): Add any relevant notes about the student.
* **Instructor Notes** (text, optional): Add any relevant notes about the instructor.
* **Session Details** (text, optional): Describe the session details.
* **Check In Status** (select_one, required): Select "Active" or "Inactive" to indicate the student's status.
* **Student Readiness** (select_multiple, required): Select "Yes" or "No" to indicate the student's readiness.
* **Check In Time** (date, required): Enter the time the student checked in.
* **Check In Date** (date, required): Enter the date the student checked in.
* **Session Start Time** (time, required): Enter the start time of the session.
* **Session End Time** (time, required): Enter the end time of the session.
* **Class Topic** (select_one, required): Select "Yes" or "No" to indicate whether the student has been taught a class topic relevant to this session.
* **Studio Id** (number, optional): Enter the studio's ID number, if applicable.
* **Assigned Tool** (text, optional): Enter the assigned tool, if applicable.
* **Session Id** (text, optional): Enter the session's ID number, if applicable.
