# university_library_resource_access_check_in - Help Guide
## Purpose

This form is used to record details about the access and availability of library resources. It is intended to help library staff manage resource allocation, track visitor activity, and optimize library operations.

## How To Complete This Form

1. Review the form carefully to ensure you have all the necessary information to complete it accurately.
2. Enter your contact information as the "Visitor Info" section, providing your name and any relevant contact details.
3. Enter the name of the resource you wish to access in the "resource name" field.
4. Specify the location of the resource in the "resource location" field.
5. Select the start time of your resource access in the "start time" field.
6. Select the end time of your resource access in the "end time" field.
7. Enter any additional comments or notes about your resource access in the "notes" field.
8. If applicable, select a date for check-out in the "check out date" field.
9. Select the time of check-out in the "check out time" field.
10. Confirm whether you have any user details that need to be recorded ("user details").
11. Indicate the availability of the resource you are accessing, selecting all that apply from the list of options in the "resource availability" field.

## Field-by-Field Explanation

* **Visitor Info (1)**:
  - A text field for entering your name and contact information.
* **resource name (2)**:
  - Enter the name of the resource you wish to access.
* **resource location (3)**:
  - Specify the location of the resource.
* **start time (4)**:
  - Select the time you wish to begin accessing the resource.
* **end time (5)**:
  - Select the time you wish to end accessing the resource.
* **notes (6)**:
  - Enter any additional comments or notes about your resource access.
* **check out date (7)**:
  - If applicable, select a date for check-out.
* **check out time (8)**:
  - Select the time of check-out.
* **user details (9)**:
  - Confirm whether you have any user details that need to be recorded.
* **resource availability (10)**:
  - Select all applicable options from the list to indicate the availability of the resource.
