# Theater Audience Check In Form - Help Guide
## Purpose
The Theater Audience Check In Form is used to gather information about attendees at a performance, including whether they have arrived, if they require accessibility accommodations, and their contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. **Select the performance**: Choose the performance that the attendee is attending from the "Performance" dropdown list.
2. **Indicate your arrival**: Answer whether you have arrived at the performance or not. Note that this is not a required field, but it's still useful for the event organizers.
3. **Accessibility needs**: If you have specific accessibility needs, select the options that apply to you. This will help the event staff provide better accommodations.
4. **Enter your email**: Enter your email address so that the event staff can contact you if necessary.
5. **Enter your phone number**: Enter your phone number so that the event staff can contact you if needed.

## Field-by-Field Explanation

* **Performance**: This dropdown list asks you to select the performance you are attending. This helps the event staff identify which event you are checking in for.
* **Arrivals**: This field is used to indicate whether you have arrived at the performance or not. Answer "Yes" if you have arrived, and "No" otherwise.
* **Accessibility**: This is a multiple-choice field where you can select the accessibility accommodations you require. Select all that apply to you.
* **Email**: Enter your email address so that the event staff can contact you if needed. This is a required field, so please make sure to enter a valid email address.
* **Phone**: Enter your phone number so that the event staff can contact you if needed.

## Tips
* Make sure to enter your contact information accurately to ensure that the event staff can get in touch with you if needed.
* If you have specific accessibility needs, please select them from the list to help the event staff provide better accommodations.
* This form is designed to be completed by one person at a time, so please do not try to submit multiple entries for the same performance.
