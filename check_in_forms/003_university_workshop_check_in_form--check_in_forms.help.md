# university_workshop_check_in_form - Help Guide
## Purpose
This form is used for checking in to a university workshop. It is used to record the attendance and checkout times of attendees.

## How To Complete This Form
To complete this form, follow the steps below:
1. Enter your name in the "Name" field.
2. Select the event you are attending in the "Event" field.
3. Select the time you checked in using the "Time in" field.
4. Select the time you plan to check out using the "Time out" field.
5. Choose your current check-in status from the options in the "Check-in Status" field.

## Field-by-Field Explanation
* **Name** (Name, text, required): Enter your name as it appears on your ID or badge.
* **Event** (Event, text, required): Select the event you are attending from the available options.
* **Time In** (Time in, time, required): Select the time you arrived at the workshop using the date and time picker.
* **Time Out** (Time out, time, required): Select the time you plan to leave the workshop using the date and time picker.
* **Check-in Status** (Check-in Status, select_one, required): Choose your current check-in status as Active or Inactive.
