# Performing Arts Class Attendance Check In - Help Guide
## Purpose
This form is intended to record attendance for the Performing Arts Class. Please use it to check in your students for the class you are teaching or attending.

## How To Complete This Form
To use this form, simply follow these steps:

1. Select the Class ID to associate with your attendance record.
2. Enter the student's name and email address (if available).
3. Add the student's phone number (if available).
4. Enter the name of the class you are attending or teaching.

## Field-by-Field Explanation
* **Class ID** (`Class ID`, `number`, required/optional: no): Select the ID of the class you are attending. This field is used to link your attendance record with the relevant class.
* **Student Name** (`student name`, `text`, required/optional: no): Enter the name of the student you are checking in.
* **Student Email** (`Student Email`, `email`, required/optional: no): Enter the student's email address (if available).
* **Student Phone** (`Student Phone`, `text`, required/optional: no): Enter the student's phone number (if available).
* **Class Name** (`Class Name`, `text`, required/optional: no): Enter the name of the class you are teaching or attending. This field is used to provide a description of the class, but is not mandatory.

## Tips
* Make sure to select the correct Class ID to ensure accurate attendance records.
* If you have any issues or concerns, contact the Performing Arts Department for assistance.
