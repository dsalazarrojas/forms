# NGO Seminar Check In Form - Help Guide

## Purpose
This form is designed to gather information about attendees for an NGO seminar. It will help us track attendance, participation, and other relevant details for each session.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your first name and last name in the respective text fields.
2. Enter your email address and phone number for contact purposes.
3. Choose your arrival method and session participation status for each session.
4. Provide any additional comments or notes.
5. Select the session you attended from the available options.
6. Choose your attendee type and status.
7. Fill in any additional attendance status for each session.

## Field-by-Field Explanation
* **First name** (First name, Text, Optional): Enter your first name.
* **Last name** (Last name, Text, Optional): Enter your last name.
* **Email** (Email, Email, Optional): Enter your email address.
* **Phone number** (Phone number, Text, Optional): Enter your phone number.
* **Check in time** (Check in time, Time, Optional): Enter the time you arrived.
* **Session participation** (Session participation, Select Multiple, Optional): Choose all sessions you participated in.
* **Arrival method** (Arrival method, Select One, Optional): Choose how you arrived (Session 1, Session 2, Session 3, Session 4).
* **Attendee comments** (Attendee comments, Note, Optional): Provide any additional comments or notes.
* **Staff comments** (Staff comments, Note, Optional): Provide any comments or notes for the staff.
* **Session 1 participation** (Session 1 participation, Select Multiple, Optional): Choose if you participated in Session 1.
* **Session 2 participation** (Session 2 participation, Select Multiple, Optional): Choose if you participated in Session 2.
* **Session 3 participation** (Session 3 participation, Select Multiple, Optional): Choose if you participated in Session 3.
* **Session 4 participation** (Session 4 participation, Select Multiple, Optional): Choose if you participated in Session 4.
* **Attendee type** (Attendee type, Select One, Optional): Choose your attendee type (NGO, Community, Staff, Others, Guest, Volunteer).
* **Attendee status** (Attendee status, Select One, Optional): Choose your attendee status (Confirmed, Confirmed but did not attend, No show, Unable to attend, Not yet confirmed).
* **Session attended** (Session attended, Select One, Optional): Choose the session you attended.
* **Session 1 session attended** (Session 1 session attended, Select One, Optional): Choose if you attended Session 1.
* **Session 2 session attended** (Session 2 session attended, Select One, Optional): Choose if you attended Session 2.
* **Session 3 session attended** (Session 3 session attended, Select One, Optional): Choose if you attended Session 3.
* **Session 4 session attended** (Session 4 session attended, Select One, Optional): Choose if you attended Session 4.
* **Notes** (Notes, Note, Optional): Provide any additional notes.
* **Session 1 attendance status** (Session 1 attendance status, Select One, Optional): Choose your attendance status for Session 1 (Attended, Did not attend, Unable to attend, Not yet attended).
* **Session 2 attendance status** (Session 2 attendance status, Select One, Optional): Choose your attendance status for Session 2 (Attended, Did not attend, Unable to attend, Not yet attended).
* **Session 3 attendance status** (Session 3 attendance status, Select One, Optional): Choose your attendance status for Session 3 (Attended, Did not attend, Unable to attend, Not yet attended).
* **Session 4 attendance status** (Session 4 attendance status, Select One, Optional): Choose your attendance status for Session 4 (Attended, Did not attend, Unable to attend, Not yet attended).
