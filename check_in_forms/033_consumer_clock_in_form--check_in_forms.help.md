# Consumer Clock In Form - Help Guide
## Purpose
The Consumer Clock In Form is designed to gather information from employees for clocking in, ensuring accurate attendance records and work schedule management.

## How To Complete This Form

1. Ensure you have all necessary information before starting the form.
2. Fill out each field according to your work status and circumstances.
3. Double-check the accuracy of your input.

## Field-by-Field Explanation
### Employee First Name
* **First Name (employee_first_name)**: Enter your first name.

### Employee Last Name
* **Last Name (employee_last_name)**: Enter your last name.

### Employee ID
* **Employee ID (employee_id)**: Enter your identification number.

### Email Address
* **Email Address (email_address)**: Enter your work email address.

### Phone Number
* **Phone Number (phone_number)**: Enter your contact number (optional).

### Department
* **Department (department)**: Select your department.

### Supervisor Name
* **Supervisor Name (supervisor_name)**: Enter your supervisor's name.

### Work Location
* **Work Location (work_location)**: Select where you are working (e.g., Main Office, Remote, Client Site, Branch Office, Field Location, Other).

### Specific Location
* **Specific Location (specific_location)**: If you selected "Other" in the previous field, provide the specific location.

### Clock In Date
* **Clock In Date (clock_in_date)**: Select today's date.

### Clock In Time
* **Clock In Time (clock_in_time)**: Enter the time you are starting work.

### Shift Type
* **Shift Type (shift_type)**: Select your shift type (e.g., Morning Shift, Afternoon Shift, Evening Shift, Night Shift, Flexible, Overtime).

### Scheduled Start Time
* **Scheduled Start Time (scheduled_start_time)**: If you have a scheduled start time, enter it.

### Type of Work
* **Type of Work (work_type)**: Select the type of work you will be doing (e.g., Regular Hours, Overtime, Weekend, Holiday, Training, Meeting, Travel).

### Project Code
* **Project Code (project_code)**: If you are working on a project, enter the applicable project code.

### Primary Task or Assignment
* **Primary Task or Assignment (task_description)**: Describe the primary task or assignment you will be working on.

### Equipment or Tools Used
* **Equipment or Tools Used (equipment_used)**: List any equipment or tools you will be using.

### Safety Checklist Completed
* **Safety Checklist Completed (safety_checklist)**: Indicate if you have completed the safety checklist.

### Uniform or Dress Code
* **Uniform or Dress Code (uniform_compliance)**: Indicate if you are in compliance with the uniform or dress code policy.

### Expected Breaks
* **Expected Breaks (breaks_expected)**: Enter the number of breaks expected.

### Meal Break Required
* **Meal Break Required (meal_break_required)**: Indicate if you will take a meal break.

### Additional Notes
* **Additional Notes (notes)**: Provide any additional information for your supervisor.

### Verification
* **Verification (verification)**: Confirm that the information provided is accurate.
