# Virtual Event Check In - Help Guide
## Purpose
The Virtual Event Check In form is used to create a check-in record for a virtual event. This record tracks attendee information and event details for future reference and analysis.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Virtual Event Check In" page.
2. Fill in the required fields, marked as required.
3. Review the form for accuracy before submitting.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required/optional): Enter the name of the event for which you are checking in attendees.
* **Email** (`email`, email, required/optional): Enter the email address of the attendee.
* **Phone** (`phone`, text, required/optional): Enter the phone number of the attendee.
* **Registration Date** (`registration_date`, date, required/optional): Enter the date the attendee registered for the event.

## Tips
* Please ensure you have the necessary permissions to access this form and that the event is relevant to the data you are collecting.
* Double-check the form for accuracy before submitting.
* This form is intended for use in a variety of scenarios, such as post-event follow-up, survey distribution, or data collection for reporting purposes.
