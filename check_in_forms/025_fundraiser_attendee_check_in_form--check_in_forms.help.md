# Fundraiser Attendee Check In Form - Help Guide
## Purpose
This form is designed to collect check-in information from fundraiser attendees. It helps event organizers track and manage attendees in a efficient and organized manner.

## How To Complete This Form
To complete this form, please follow these steps:
1. Select the Check In Information page.
2. Fill out the First Name field with the attendee's first name.
3. Fill out the Last Name field with the attendee's last name.
4. Enter the attendee's Email address.

## Field-by-Field Explanation
- **First Name** (`attendee_first_name`, text, required): Please fill out the attendee's first name.
  - Example: John
- **Last Name** (`attendee_last_name`, text, required): Please fill out the attendee's last name.
  - Example: Smith
- **Email** (`attendee_email`, email, optional): Please enter the attendee's email address.
  - Example: [john.smith@example.com](mailto:john.smith@example.com)
