# HCV Elimination Plan Check In - Help Guide
## Purpose
The HCV Elimination Plan Check In form is used to track and report progress on HCV elimination efforts. This form collects information on project sites, regions, districts, team size, and testing statistics to help monitor and evaluate the success of the project.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have the necessary permissions and access to submit this form.
2. Fill out the required fields, marked as such on the form.
3. Provide accurate information for each field, as it will be used for tracking and reporting purposes.

## Field-by-Field Explanation
* **Project Site** (`project_site`): This field is required and asks for the name of the project site where you are working.
* **Region** (`region`): This field is required and asks for the name of the region where you are working.
* **Date Submitted** (`date_submitted`): This field is required and asks for the date on which you are submitting this form.
* **Team Size** (`team_size`): This field is required and asks for the number of people on your team.
* **Total Cases Tested** (`total_cases_tested`): This field is optional and asks for the total number of cases tested.
* **New Cases Reported** (`new_cases_reported`): This field is optional and asks for the number of new cases reported.
* **Total Cases Confirmed** (`total_cases_confirmed`): This field is optional and asks for the total number of cases confirmed.
* **Total Cases Treated** (`total_cases_treated`): This field is optional and asks for the total number of cases treated.
* **Total Cases Cured** (`total_cases_cured`): This field is optional and asks for the total number of cases cured.
* **Total Cases Died** (`total_cases_died`): This field is optional and asks for the total number of cases died.
* **Total Cases Referred** (`total_cases_referred`): This field is optional and asks for the total number of cases referred.
* **Total Cases Transferred** (`total_cases_transferred`): This field is optional and asks for the total number of cases transferred.
* **Total Cases Discharged** (`total_cases_discharged`): This field is optional and asks for the total number of cases discharged.
* **Cases Confirmed in Last Week** (`cases_confirmed_in_last_week`): This field is optional and asks for the number of cases confirmed last week.
* **Cases Confirmed Last Month** (`cases_confirmed_last_month`): This field is optional and asks for the number of cases confirmed last month.
* **Total Tests Conducted Last Week** (`total_tests_conducted_last_week`): This field is optional and asks for the total number of tests conducted last week.
* **Tests Positive Last Week** (`tests_positive_last_week`): This field is optional and asks for the number of positive tests last week.
* **Cases Confirmed Last Month** (`cases_confirmed_last_month`): This field is optional and asks for the number of cases confirmed last month.
* **Total Tests Conducted Last Month** (`total_tests_conducted_last_month`): This field is optional and asks for the total number of tests conducted last month.
* **Total Positive Last Month** (`total_positive_last_month`): This field is optional and asks for the total number of positive tests last month.
* **Total Positive Last Week** (`total_positive_last_week`): This field is optional and asks for the total number of positive tests last week.
* **Total Tests Conducted** (`total_tests_conducted`): This field is optional and asks for the total number of tests conducted.

## Tips
* Ensure you have accurate and up-to-date information before submitting this form.
* If you are unsure about any field, please ask your supervisor or consult the project documentation.
* Double-check your submissions for errors before clicking the submit button.
