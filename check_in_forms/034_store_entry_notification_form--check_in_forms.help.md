# Store Entry Notification Form - Help Guide

## Purpose
The Store Entry Notification Form is designed to notify users of new store entries, allowing them to provide entry details, select the correct time zone, and add additional comments. This form is used by team members to create and update entry notifications.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the entry details in the "Entry Details" field.
2. Select the entry date and time using the respective fields.
3. Choose the entry time zone from the dropdown list.
4. If necessary, add a note in the "Entry Details Note" field for additional information.
5. Select the team member responsible for the entry in the "Team Member" field.

## Field-by-Field Explanation

* **Entry Details** (`entry_details`, text, required): Enter a brief description of the store entry, such as a product name or a specific detail.
* **Entry Date** (`entry_date`, date, optional): Select the date of the store entry.
* **Entry Time** (`entry_time`, time, optional): Select the time of the store entry.
* **Entry Time Zone** (`entry_time_zone`, select_multiple, optional): Choose the time zone of the store entry from the dropdown list.
* **Team Member** (`team_member`, text, optional): Select the team member responsible for the store entry.
* **Entry Details Note** (`entry_details_note`, note, optional): Add any additional comments or information about the store entry.
