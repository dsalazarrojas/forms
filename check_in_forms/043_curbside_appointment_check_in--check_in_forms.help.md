# curbside_appointment_check_in - Help Guide
## Purpose
This form is used to check in patients for their scheduled appointments. It collects the patient's name, contact information, appointment date and time, and any additional notes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the patient's first name in the "First Name" field.
2. Enter the patient's last name in the "Last Name" field.
3. Enter the patient's email address in the "Email" field.
4. Enter the patient's phone number in the "Phone" field.
5. Select the date of the appointment using the calendar icon.
6. Select the time of the appointment using the time picker.
7. Enter any additional notes about the patient's appointment in the "Note" field (optional).
8. If applicable, select the category of the appointment from the dropdown list.
9. Confirm the patient's phone number in the "Confirm Phone" field.

## Field-by-Field Explanation
* **First Name** (Required): Enter the patient's first name.
* **Last Name** (Required): Enter the patient's last name.
* **Email** (Required): Enter the patient's email address.
* **Phone** (Required): Enter the patient's phone number.
* **Appointment Date**: Select the date of the appointment using the calendar icon.
* **Appointment Time**: Select the time of the appointment using the time picker.
* **Note** (Optional): Enter any additional notes about the patient's appointment.
* **Category** (Optional): If applicable, select the category of the appointment from the dropdown list.
* **Confirm Phone** (Required): Confirm the patient's phone number.

## Tips
* Ensure that you enter accurate and complete information for the patient.
* Double-check the appointment date and time to ensure it matches the scheduled appointment.
* Use the "Confirm Phone" field to verify the patient's phone number.
* If you are unsure about any field, please contact the healthcare staff or system administrator for assistance.
