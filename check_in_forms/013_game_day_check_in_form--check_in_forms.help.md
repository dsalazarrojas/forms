# Game Day Check In Form - Help Guide
## Purpose
The Game Day Check In Form is a tool used to record information about an event, including the date and time of the event, the name of the event, and details about the players participating. This form helps to ensure that all relevant information is captured accurately and consistently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the event date from the calendar.
2. Enter the event time.
3. Enter the event name.
4. If the player is attending the event, select "Yes" from the "Team" field.
5. Enter the player's name.
6. For players who are not attending, select "No" from the "Team" field.
7. If applicable, select any relevant shirt sizes from the "Shirt Size" field.
8. Enter the player's phone number.
9. Enter the player's email.
10. If applicable, select the player's status as "Active" or "Inactive" from the "Player Status" field.
11. If applicable, select the player's category from the options in the "Player Category" field.
12. If applicable, select the player's position from the options in the "Player Position" field.
13. Enter the player's number.
14. Enter the team's score.
15. Enter the player's score.
16. In the "Notes" field, enter any additional comments or information about the player.
17. Enter the event location.
18. Enter the event venue.
19. If applicable, select the team's category from the options in the "Team Category" field.
20. If applicable, select the player's category from the options in the "Player Category" field.
21. If applicable, select the notes category from the options in the "Notes Category" field.
22. In the "Notes Text" field, enter any additional information about the notes.
23. Enter the team's venue.
24. If applicable, select the player's status category from the options in the "Player Status Category" field.
25. If applicable, select the player's position category from the options in the "Player Position Category" field.

## Field-by-Field Explanation

• **Event Date** (`event_date`, `date`, required: false) - The date of the event.

• **Event Time** (`event_time`, `time`, required: false) - The time of the event.

• **Event Name** (`event_name`, `text`, required: false) - The name of the event.
