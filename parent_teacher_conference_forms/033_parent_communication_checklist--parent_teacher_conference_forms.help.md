# Parent Communication Checklist - Help Guide
## Purpose
This form is designed for parent-teacher communication in a school setting to facilitate regular information sharing and collaboration between parents and teachers.

## How To Complete This Form
To complete this form effectively, follow these steps:

1.  Fill out your information, including your name, email, and student's name.
2.  Select the event type (e.g., Meeting, Phone Call, Email, etc.) to indicate the type of communication you are undertaking.
3.  Optionally, select the school event type that this communication is related to (e.g., Field Trip, Holiday, etc.).
4.  Enter any relevant notes or comments for the teacher and parent to refer to.
5.  Choose the date and time of the communication event.
6.  Once you have filled out all the necessary fields, click submit to complete and share the form.

## Field-by-Field Explanation

* **Parent Name (`parent_name`, text, optional):** Enter the name of the parent or guardian associated with the communication event.
* **Parent Email (`parent_email`, email, optional):** Enter the email address of the parent or guardian, if applicable.
* **Teacher Name (`teacher_name`, text, optional):** Enter the name of the teacher associated with the event.
* **Student Name (`student_name`, text, optional):** Enter the name of the student associated with the event.
* **Event Type (`event_type`, select multiple, optional):** Choose the type of event or communication (e.g., Meeting, Phone Call, Email, etc.).
* **Notes (`notes`, note, optional):** Enter any additional comments or information for the teacher and parent to refer to.
* **Date (`date`, date, optional):** Enter the date of the communication event.
* **Time (`time`, time, optional):** Enter the time of the communication event.
* **School Events (`school_events`, select one, optional):** Choose the school event type related to this communication (e.g., Field Trip, Holiday, etc.).
* **Teacher Comments (`teacher_comments`, text, optional):** Enter any comments or feedback from the teacher related to the event.
