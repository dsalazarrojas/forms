# Tax File Declaration Form - Help Guide
## Purpose
The Tax File Declaration Form is a tool used to declare and track tax files. This form is designed to help users accurately and efficiently report their tax information. By completing this form, users can ensure that their tax records are up-to-date and compliant with relevant regulations.
## How To Complete This Form
To complete the Tax File Declaration Form, follow these steps:
1. Select the relevant category from the dropdown menu.
2. Provide a brief description of the form.
3. Enter a unique file number.

## Field-by-Field Explanation
* **Category** (`tax_forms`, select_one, required/optional): Select the type of tax form you are declaring. This will help us understand the context of your declaration.
* **Description** (`description`, text, optional): Briefly describe the tax form you are declaring. This will help us understand the details of your declaration.
* **File Number** (`file_number`, number, optional): Enter a unique number for the tax file you are declaring. This will help us track your tax files easily.

## Tips
* Make sure to select a valid category for accurate tracking.
* Use a descriptive title for your tax file declaration.
* If you have any questions or concerns about this form, contact your administrator.
