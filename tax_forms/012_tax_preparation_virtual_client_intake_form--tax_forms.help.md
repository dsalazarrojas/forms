# Tax Preparation Virtual Client Intake Form - Help Guide
## Purpose
This form is designed to gather information from clients for tax preparation services. It collects client data, tax year, return type, return location, tax preparer, documents, tax return status, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. **Enter Client Information**: Fill in the client's name and contact information in the "Client Information" field.
2. **Select Tax Year**: Choose the tax year for which the client needs tax preparation services.
3. **Choose Tax Return Type**: Select the type of tax return the client needs (Individual, Business, Partnership, or Corporate).
4. **Select Tax Return Location**: Choose where the client would like to receive their tax return (Online, Mail, or In-Person).
5. **Select Tax Preparer**: Choose the tax preparer assigned to the client (Joe, Jane, John, or Sarah).
6. **Upload Documents**: Upload any relevant documents related to the client's tax preparation.
7. **Update Tax Return Status**: Select the current status of the tax return (Pending, In-Progress, Complete, or Cancelled).
8. **Add Tax Return Notes**: Add any additional notes or comments about the client's tax return.
9. **Enter Review Date and Time**: Enter the date and time when the tax return is to be reviewed.
10. **Enter Submission Date and Time**: Enter the date and time when the tax return was submitted.

## Field-by-Field Explanation
* **Client Information**: Enter the client's name and contact information to ensure accurate communication and efficient service.
* **Tax Year**: Select the tax year for which the client needs tax preparation services.
* **Tax Return Type**: Choose the type of tax return the client needs (Individual, Business, Partnership, or Corporate).
* **Tax Return Location**: Choose where the client would like to receive their tax return (Online, Mail, or In-Person).
* **Tax Preparer**: Select the tax preparer assigned to the client (Joe, Jane, John, or Sarah).
* **Documents**: Upload any relevant documents related to the client's tax preparation.
* **Tax Return Status**: Select the current status of the tax return (Pending, In-Progress, Complete, or Cancelled).
* **Tax Return Notes**: Add any additional notes or comments about the client's tax return.
* **Review Date and Time**: Enter the date and time when the tax return is to be reviewed.
* **Submission Date and Time**: Enter the date and time when the tax return was submitted.
* **Submitted By**: Choose who submitted the tax return (Client, Preparer, or Other).
