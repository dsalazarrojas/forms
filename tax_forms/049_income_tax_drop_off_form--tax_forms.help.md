# Income Tax Drop Off Form - Help Guide
## Purpose
The "Income Tax Drop Off Form" is designed to collect information about income tax returns, including the return itself, associated documents, client details, and tax professional involvement. This form is likely used for tax-related administrative purposes.

## How To Complete This Form
To complete this form, follow these steps:

*   Enter the required information in each field, including the income tax return and associated documents.
*   Ensure that all required fields are filled out.
*   If a field is optional, provide any additional information that might be relevant to the tax return.

## Field-by-Field Explanation

*   **Income Tax Return** (`income_tax_return`, `text`, required): Enter the income tax return in this field. This field is required to provide the main information about the tax return.
*   **Tax Documents** (`tax_documents`, `text`, required): Enter any associated tax documents in this field. This field is required to provide relevant documents for the tax return.
*   **Client Info** (`client`, `text`, required): Enter client information in this field. This field is required to provide client details.
*   **Tax Professional Info** (`tax_professional`, `select_multiple`, optional): If applicable, select "Yes" to indicate that the tax professional is involved in the return. This field is optional and not required.
*   **Income Tax Return Year** (`income_tax_return_year`, `number`, optional): Enter the income tax return year in this field. This field is optional and not required.
*   **Tax Drop Off Form Notes** (`tax_drop_off_form_notes`, `note`, optional): Enter any additional notes about the tax return in this field. This field is optional and not required.
*   **Client Phone Number** (`client_phone_number`, `text`, optional): Enter the client's phone number in this field. This field is optional and not required.
*   **Income Tax Return Date** (`income_tax_return_date`, `date`, optional): Enter the income tax return date in this field. This field is optional and not required.
*   **Drop Off Location** (`drop_off_location`, `select_multiple`, optional): If applicable, select "Yes" to indicate that the tax return will be dropped off. This field is optional and not required.
*   **Email** (`tax_drop_off_form_email`, `email`, optional): Enter the email address of the client or tax professional in this field. This field is optional and not required.
*   **Income Tax Return Year Range** (`income_tax_return_year_range`, `number`, optional): Enter the income tax return year range in this field. This field is optional and not required.
*   **Is Signed** (`is_signed`, `select_one`, optional): If the tax return is signed, select "Yes" in this field. This field is optional and not required.
*   **Drop Off Date** (`drop_off_date`, `date`, optional): Enter the drop off date of the tax return in this field. This field is optional and not required.
*   **Tax Professional** (`tax_professional`, `select_one`, optional): If the tax professional is involved, select "Yes" in this field. This field is optional and not required.
*   **Tax Profesional Info 2** (`tax_profesional_info_2`, `select_one`, optional): If the tax professional is involved, select "Yes" in this field. This field is optional and not required.
