# W 8BEN - Help Guide
## Purpose
The W 8BEN form is designed to collect information about tax forms. It seems to be used for categorizing and organizing tax forms within a specific category.

## How To Complete This Form
To complete the W 8BEN form, follow these steps:

1. Enter a clear and concise title for the tax form in the **What is the W 8BEN title?** field.
2. Select the correct category for the tax form from the **What category does this tax form belong to?** dropdown menu. The options seem to be tax-related categories.
3. Provide a brief description of the tax form in the **Provide a brief description of the tax form.** field.
4. If applicable, select a tool that is assigned to this tax form in the **What tool is assigned to this tax form?** field.
5. Enter the output file name for this tax form in the **What is the output file name for this tax form?** field.
6. Add any additional notes about the tax form in the **What are the notes about this tax form?** field.
7. Optional: Enter the form ID for this tax form if you have one in the **What is the form ID for this tax form?** field.
8. Optional: Select the category ID for this tax form from the dropdown menu in the **What is the category ID for this tax form?** field.
9. Optional: If applicable, enter the assigned tool ID for this tax form in the **What is the assigned tool ID for this tax form?** field.
10. Optional: Add any additional notes in the **What are the notes for this tax form?** field.

## Field-by-Field Explanation
- **What is the W 8BEN title?** (text, required): This field should contain the title of the tax form you're creating or editing.
- **What category does this tax form belong to?** (select_one, required): Select the correct category for the tax form from the options provided.
- **Provide a brief description of the tax form.** (text, required): Describe the purpose and content of the tax form.
- **What tool is assigned to this tax form?** (text, optional): If a tool is assigned to this tax form, enter its name.
- **What is the output file name for this tax form?** (text, required): Enter the name of the output file for the tax form.
- **What are the notes about this tax form?** (note, required): Add any additional notes or comments about the tax form.
- **What is the form ID for this tax form?** (number, optional): This field is optional and seems to be related to internal tracking or referencing the form.
- **What is the category ID for this tax form?** (select_one, optional): Select the category ID for the tax form from the dropdown menu.
- **What is the assigned tool ID for this tax form?** (number, optional): This field is optional and seems to be related to the assigned tool.
- **What are the notes for this tax form?** (note, optional): Add any additional notes or comments about the tax form.
