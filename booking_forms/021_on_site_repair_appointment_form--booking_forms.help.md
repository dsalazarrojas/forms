# On Site Repair Appointment Form - Help Guide
## Purpose
The On Site Repair Appointment Form is used to schedule and manage on-site repair appointments. It captures essential information to ensure that the technician and customer are informed and prepared for the visit.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields:
	* Customer Name
	* Visit Date
	* Visit Time
2. Select the relevant options for:
	* Visit Type
	* Services Offered
	* Appointment Status
	* Payment Method
	* Equipment Used
	* Technician Skills
3. Add any Additional Comments or Service Details as necessary
4. Review and submit the form for review and approval

## Field-by-Field Explanation
* **Customer Name** (`on_site_repair_appointment_form_customer_name`, Text, Required): Enter the name of the customer being visited.
* **Visit Date** (`on_site_repair_appointment_form_visit_date`, Date, Required): Select the date of the visit.
* **Visit Time** (`on_site_repair_appointment_form_visit_time`, Time, Required): Select the time of the visit.
* **Customer Phone** (`on_site_repair_appointment_form_customer_phone`, Text, Optional): Enter the customer's phone number for contact purposes.
* **Visit Type** (`on_site_repair_appointment_form_visit_type`, Select One, Optional): Select the type of visit (Service, Emergency, or Other).
* **Customer ID** (`on_site_repair_appointment_form_customer_id`, Number, Optional): Enter the customer's ID (if applicable).
* **Customer Email** (`on_site_repair_appointment_form_customer_email`, Email, Optional): Enter the customer's email address for communication purposes.
* **Services Offered** (`on_site_repair_appointment_form_services_offered`, Select Multiple, Optional): Select the services to be offered during the visit.
* **Additional Comments** (`on_site_repair_appointment_form_additional_comments`, Text, Optional): Add any additional comments or instructions for the technician.
* **Appointment Status** (`on_site_repair_appointment_form_appointment_status`, Select One, Optional): Select the appointment status (Scheduled, Unscheduled, or Confirmed).
* **Technician Name** (`on_site_repair_appointment_form_technician_name`, Text, Optional): Enter the name of the technician assigned to the visit.
* **Visit Location** (`on_site_repair_appointment_form_visit_location`, Text, Optional): Enter the location of the visit.
* **Service Address** (`on_site_repair_appointment_form_service_address`, Text, Optional): Enter the address of the service location.
* **Visit Start Date** (`on_site_repair_appointment_form_visit_start_date`, Date, Optional): Select the start date of the visit.
* **Visit End Date** (`on_site_repair_appointment_form_visit_end_date`, Date, Optional): Select the end date of the visit.
* **Payment Method** (`on_site_repair_appointment_form_payment_method`, Select One, Optional): Select the payment method (Cash, Credit Card, or Other).
* **Payment Amount** (`on_site_repair_appointment_form_payment_amount`, Text, Optional): Enter the payment amount.
* **Payment Notes** (`on_site_repair_appointment_form_payment_notes`, Text, Optional): Add any payment notes or instructions.
* **Equipment Used** (`on_site_repair_appointment_form_equipment_used`, Select Multiple, Optional): Select the equipment used during the visit.
* **Technician Skills** (`on_site_repair_appointment_form_technician_skills`, Select Multiple, Optional): Select the skills of the technician assigned to the visit.
* **Technician Notes** (`on_site_repair_appointment_form_technician_notes`, Text, Optional): Add any notes from the technician.
* **Customer Notes** (`on_site_repair_appointment_form_customer_notes`, Text, Optional): Add any notes from the customer.
* **Service Details** (`on_site_repair_appointment_form_service_details`, Text, Optional): Add any service details.
* **Service Notes** (`on_site_repair_appointment_form_service_notes`, Text, Optional): Add any service notes.
* **Visit Notes** (`on_site_repair_appointment_form_visit_notes`, Text, Optional): Add any visit notes or instructions.

## Tips
* Ensure all required fields are filled in accurately.
* Double-check the selected options for Visit Type, Services Offered, and Payment Method.
* Review the form carefully before submission to avoid errors.
* Keep the form up-to-date and accurate for efficient processing and communication.
