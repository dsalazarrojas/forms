# Film Pitch Presentation Booking Form - Help Guide
## Purpose
This form is used to book film pitch presentations for film projects. The form helps gather essential information from the production team, including project details, event and presenter information, and production status. This information is crucial for organizing and scheduling presentations at film festivals, markets, or pitch events.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the project details, including the project title, production company, and project status.
* Select the event and presenter for the presentation booking.
* Choose the presentation date, start date, end date, and budget for the project.
* Enter the presentation time and select the presenter and production company for the project.
* Review and confirm the information before submitting the form.

## Field-by-Field Explanation

* **Project Details**: Enter the title of the film project, including the title and a brief description.
* **Production Company**: Select the production company responsible for the project.
* **Event Details**: Enter the event details, including event type and location.
* **Presenter Details**: Enter the presenter's name and contact information.
* **Contact**: Enter the contact person's name and email address.
* **Presenter Booking**: Select the presentation time for the booking.
* **Event Booking**: Select the date for the event.
* **Project Status**: Select the status of the project (Active, Closed, or In Progress).
* **Production Status**: Select the status of the production (Active, Closed, or In Progress).
* **Presenter**: Select the presenter for the booking.
* **Production Company 2**: Select the production company 2 responsible for the project.
* **Event**: Select the type of event (Film Festival, Film Market, or Film Pitch).
* **Project Type**: Select the type of project (Animation, Live Action, or Documentary).
* **Project Length**: Enter the length of the project.
* **Presentation Date**: Enter the date of the presentation.
* **Production Start Date**: Enter the start date of the production.
* **Production End Date**: Enter the end date of the production.
* **Project Budget**: Enter the budget for the project.
* **Presentation Time**: Enter the time of the presentation.
* **Project Status 2**: Select the status of the project 2 (Active, Closed, or In Progress).
* **Production Status 2**: Select the status of the production 2 (Active, Closed, or In Progress).
* **Presenter 2**: Select the presenter 2 responsible for the booking.
* **Production Company 3**: Select the production company 3 responsible for the project.
* **Event 2**: Select the type of event 2 (Film Festival, Film Market, or Film Pitch).
* **Project Type 2**: Select the type of project 2 (Animation, Live Action, or Documentary).
