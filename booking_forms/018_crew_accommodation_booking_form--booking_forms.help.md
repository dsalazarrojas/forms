# crew-accommodation-booking-form - Help Guide
## Purpose
The crew-accommodation-booking-form is a form used to book accommodations for a crew.

## How To Complete This Form
1. Fill out all the required fields to provide information about the crew's booking.
2. Review all the fields for accuracy before submission.

## Field-by-Field Explanation
* **booking-form-info** (Text, Optional): Enter any additional information about the booking.
* **start-date** (Date, Optional): Enter the start date of the booking.
* **end-date** (Date, Optional): Enter the end date of the booking.
* **number-of-crew-members** (Number, Optional): Enter the number of crew members that will be booking accommodations.
* **crew-name** (Text, Optional): Enter the name of the crew.
* **accommodation-type** (Select One, Optional): Select the type of accommodation needed.
* **accommodation-name** (Select Multiple, Optional): Select the specific accommodations needed.
* **accommodation-availability** (Time, Optional): Enter the time when the accommodations are available.
* **accommodation-address** (Text, Optional): Enter the address of the accommodations.
* **accommodation-phone** (Text, Optional): Enter the phone number of the accommodations.
* **accommodation-email** (Email, Optional): Enter the email of the accommodations.
* **accommodation-website** (Text, Optional): Enter the website of the accommodations.
* **crew-requirements** (Text, Optional): Enter any special requirements for the crew.
* **special-requirements** (Text, Optional): Enter any additional special requirements.
* **additional-info** (Text, Optional): Enter any additional information.
* **submit-btn** (Note, Required): This button is used to submit the form.
* **book-appointment** (Select One, Optional): Select to book the appointment.
* **cancel-btn** (Select One, Optional): Select to cancel the appointment.
* **back-btn** (Select One, Optional): Select to go back to the previous page.
* **save-btn** (Select One, Optional): Select to save the form.
* **reset-btn** (Select One, Optional): Select to reset the form.
* **submit-previous-page-btn** (Select One, Optional): Select to submit the previous page.
* **submit-current-page-btn** (Select One, Optional): Select to submit the current page.
* **submit-last-page-btn** (Select One, Optional): Select to submit the last page.

Note: Some fields may not be required due to the 'required' property set to false in the form's schema.
