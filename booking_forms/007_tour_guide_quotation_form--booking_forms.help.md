# Tour Guide Quotation Form - Help Guide
## Purpose
The Tour Guide Quotation Form is used to collect information for a tour guide quotation. Please fill out this form to provide all necessary details about your tour.

## How To Complete This Form
- Read each field carefully to ensure you understand what information is being asked.
- Fill out all required fields (marked with *) before submitting the form.
- Use the options provided for select_one and select_multiple fields to select the appropriate options.
- Use the currency_id field to select the currency of the tour cost.
- Use the tour_type and guide_languages fields to select multiple options.
- For date fields, use the format MM/DD/YY (e.g., 01/01/2022).
- Double-check your email address in the email field for correct formatting.

## Field-by-Field Explanation

* **tour_guide_id** (2, number, optional): Enter the ID of the tour guide if available.
* **tour_duration** (3, text, optional): Describe the duration of the tour in hours or days.
* **departure_date** (4, date, optional): Enter the departure date of the tour in MM/DD/YY format (e.g., 01/01/2022).
* **travel_date** (5, date, optional): Enter the travel date of the tour in MM/DD/YY format (e.g., 01/01/2022).
* **tour_cost** (6, number, optional): Enter the cost of the tour in the selected currency.
* **currency_id** (7, select_one, optional): Select the currency of the tour cost from the options.
* **tour_type** (8, select_multiple, optional): Select the type(s) of tour (e.g., Walking, Hiking, Biking, Kayaking).
* **guide_languages** (9, select_multiple, optional): Select the languages of the tour guide (e.g., English, Spanish, Chinese, French, German).
* **travel_agency** (10, text, optional): Enter the name of the travel agency.
* **agency_address** (11, text, optional): Enter the address of the travel agency.
* **contact_person** (12, text, optional): Enter the name of the contact person.
* **email** (13, email, optional): Enter the email address of the contact person.
* **phone** (14, text, optional): Enter the phone number of the contact person.
* **notes** (15, note, optional): Add any additional notes about the tour.
* **customer_id** (16, number, optional): Enter the ID of the customer (not required for internal use).
