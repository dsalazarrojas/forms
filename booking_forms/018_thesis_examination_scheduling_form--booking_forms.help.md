# Thesis Examination Scheduling Form - Help Guide

## Purpose
This form is used to schedule a thesis examination for a student.

## How To Complete This Form
To complete this form, fill out the fields in the following order:

1. Enter the defense date and time.
2. Select the thesis supervisor.
3. Select multiple graduate programs.
4. Enter the defense location.
5. Enter the student's name.
6. Select supervisor approval.
7. Select student approval.
8. Select department chair.
9. Select coordinator approval.

## Field-by-Field Explanation
* **Defense Date**:
	+ This field is used to select the date of the thesis examination.
* **Defense Time**:
	+ This field is used to select the time of the thesis examination.
* **Thesis Supervisor**:
	+ This field is used to select a supervisor from the list.
* **Graduate Program**:
	+ This field is used to select multiple graduate programs.
* **Defense Location**:
	+ This field is used to enter the defense location.
* **Student Name**:
	+ This field is used to enter the student's name.
* **Supervisor Approval**:
	+ This field is used to select supervisor approval.
* **Student Approval**:
	+ This field is used to select student approval.
* **Department Chair**:
	+ This field is used to select department chair.
* **Coordinating Approval**:
	+ This field is used to select coordinator approval.
