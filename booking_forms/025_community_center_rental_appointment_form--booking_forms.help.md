# Community Center Rental Appointment Form - Help Guide
## Purpose
This form is designed for individuals or organizations interested in renting a space at the community center. By submitting this form, you will be able to request a rental appointment for your event or activity. Please fill out all required fields to ensure that your request is processed efficiently.

## How To Complete This Form
To complete this form, simply fill out the following sections and fields. If you need help or have questions, please don't hesitate to contact us.

## Field-by-Field Explanation
* **Full Name of Renter or Organization**: Please enter the full name of the person or organization requesting the rental. This is a required field.
* **Email Address**: Enter a valid email address to receive confirmation and rental agreement information. This is a required field.
* **Primary Contact Phone Number**: Enter the primary phone number of the person responsible for the rental. This is a required field.
* **Mailing Address**: Enter the street, city, state, and zip code of the mailing address. This is a required field.
* **Type of Event or Activity**: Select the type of event or activity you are planning (e.g., Meeting, Birthday Party, Wedding Reception, etc.). This is a required field.
* **Which space are you interested in renting**: Select one of the available spaces (e.g., Main Hall, Meeting Room A, etc.). This is a required field.
* **Estimated Number of Attendees**: Enter the estimated number of people attending the event. This is a required field.
* **Date Requested for the Event**: Enter the date you are requesting for the event. This is a required field.
* **Requested Event Start Time**: Enter the start time for the event. This is a required field.
* **Requested Event End Time**: Enter the end time for the event. This is a required field.
* **Preferred Date for Appointment**: Select a preferred date for the initial rental consultation. This is a required field.
* **Preferred Time for Appointment**: Select a preferred time for the appointment (e.g., Morning, Afternoon, etc.). This is a required field.
* **Preferred Appointment Format**: Select the format for the appointment (e.g., In-Person Site Visit, Virtual, etc.). This is a required field.
* **I acknowledge and agree**: Confirm that this is a request only and does not guarantee a rental booking. This is a required field.
* **Date of Submission**: Enter the date of the submission. This is a required field.
* **Digital Signature**: Enter your full name as a digital signature. This is a required field.
* **Any Additional Comments or Requests**: Enter any additional comments or requests you may have. This is an optional field.
