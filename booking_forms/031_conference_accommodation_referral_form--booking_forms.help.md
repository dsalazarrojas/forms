# Conference Accommodation Referral Form - Help Guide

## Purpose
The Conference Accommodation Referral Form is used to refer attendees to an accommodation partner for a specific conference. This form helps the accommodation partner to provide suitable accommodation options for the attendee. Please fill out this form to provide accurate information about the attendee and their accommodation needs.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill in the required fields marked as "Required".
2. Select the "Preferred room type", "Distance to venue preference" and "Budget per night" options from the drop-down menus.
3. Enter any additional information in the "Special requests" field.
4. Enter the "Loyalty program membership" number if the attendee has one.
5. Enter the "Contact phone" number for booking confirmation.
6. Enter any additional "Referral notes" about the attendee.

## Field-by-Field Explanation

* **Requester name (Requester name)** (`requester_name`, text, **Required**): Please enter the name of the person requesting the referral.
* **Attendee name (Attendee name)** (`attendee_name`, text, **Required**): Please enter the name of the person needing accommodation.
* **Conference dates (Conference dates)** (`conference_dates`, date, **Required**): Please enter the dates of the conference the attendee will attend.
* **Preferred room type (Preferred room type)** (`room_type`, select_one, **Required**): Please select the preferred room type for the attendee. Options include Single, Double, Suite, and Accessible.
* **Budget per night (Budget per night)** (`budget_per_night`, number, **Optional**): Please enter the maximum preferred rate per night for the accommodation.
* **Distance to venue preference (Distance to venue preference)** (`distance_to_venue`, select_one, **Optional**): Please select the preferred distance to the venue. Options include Walking distance, Short drive, and Shuttle required.
* **Special requests (Special requests)** (`special_requests`, text, **Optional**): Please enter any special requests, such as accessibility or dietary needs, for the attendee.
* **Loyalty program membership (Loyalty program membership)** (`loyalty_program`, text, **Optional**): Please enter the hotel loyalty number if the attendee has one.
* **Contact phone (Contact phone)** (`contact_phone`, text, **Optional**): Please enter the phone number for booking confirmation.
* **Referral notes (Referral notes)** (`referral_notes`, text, **Optional**): Please enter any additional information for the accommodation partner.

## Tips
* Please make sure to fill out all required fields to ensure the accommodation partner has enough information to provide suitable accommodation options.
* If you are unsure about any field, please enter the best information you can provide.
* The form will be reviewed by the accommodation partner to provide the best possible accommodation options for the attendee.
