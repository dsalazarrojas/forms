## Voice Actor Recording Time Booking Form - Help Guide

## Purpose
This form is used to book and schedule voice actor recording sessions with producers.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the project details section (project_details) with a brief description of the project.
2. Provide details about the recording session (recording_details).
3. Enter the desired schedule date and time for the session (schedule).
4. Indicate if you need to work on an Emacs script during the session (script).
5. Add any additional notes about the session (notes).
6. Select the producer you would like to work with (producer).

## Field-by-Field Explanation

* **Project Details (project_details)** (`project_details`, text, required: false): Enter a brief description of the project.
* **Recording Details (recording_details)** (`recording_details`, text, required: false): Provide details about the recording session.
* **Session Details (session_details)** (`session_details`, text, required: false): Enter details about the session.
* **Schedule (schedule)** (`schedule`, date, required: false): Enter the desired date and time for the session.
* **Emacs (script)** (`script`, select_multiple, required: false): Indicate if you need to work on an Emacs script during the session.
* **Notes (notes)** (`notes`, note, required: false): Add any additional notes about the session.
* **Producer (producer)** (`producer`, select_one, required: false): Select the producer you would like to work with.
