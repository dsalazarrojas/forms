# drone-light-show-booking-form - Help Guide
## Purpose
The drone light show booking form is used to book a drone light show for a specific date and time. It gathers essential information from the customer, such as show details and contact information, to ensure a smooth and efficient booking process.

## How To Complete This Form
To complete the form, follow these steps:

1. Provide a title for the booking, which will appear in the booking summary.
2. Enter the desired show date using the date picker.
3. Select the start and end times of the show using the time picker.
4. Enter your booking date for reference.
5. Enter your name and email address so we can contact you with booking updates.
6. Enter your phone number so we can contact you for any last-minute details or changes.
7. Enter the ID of the drone you would like to book.
8. Enter any comments or requests you may have for the booking.

## Field-by-Field Explanation

* **Drone Light Show Booking** (`drone_light_show_booking_form`, text, optional)
	+ Enter a title for the booking that will appear in the booking summary.
* **Show Date** (`show_date`, date, optional)
	+ Select the date you would like to book the drone light show.
* **Start Time** (`start_time`, time, optional)
	+ Choose the start time of the drone light show.
* **End Time** (`end_time`, time, optional)
	+ Choose the end time of the drone light show.
* **Booking Date** (`booking_date`, date, optional)
	+ Enter the date you are booking the drone light show for reference.
* **Customer Name** (`customer_name`, text, optional)
	+ Enter your name so we can contact you with booking updates.
* **Customer Email** (`customer_email`, email, optional)
	+ Enter your email address so we can contact you with booking updates.
* **Customer Phone** (`customer_phone`, text, optional)
	+ Enter your phone number so we can contact you with last-minute details or changes.
* **Drone ID** (`drone_id`, number, optional)
	+ Enter the ID of the drone you would like to book.
* **Booking Comment** (`booking_comment`, note, optional)
	+ Enter any comments or requests you may have for the booking.
