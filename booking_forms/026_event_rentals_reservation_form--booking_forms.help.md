# Event Rentals Reservation Form - Help Guide
## Purpose
This form is intended to collect information for event rentals reservations. It is designed to be completed by individuals interested in renting a specific event space or facility.

## How To Complete This Form
To complete this form, please follow the steps below:

1. Fill in the form fields as required and optional information is requested.
2. Ensure you have all necessary details before submitting the form.

## Field-by-Field Explanation

* **event_rentals_reservation_form** (`event_rentals_reservation_form`, text, required: false): 
    Enter the name of the event or rental request. This field is intended to help the event organizers understand the purpose of your reservation inquiry.
* **event_details** (`event_details`, text, required: false): 
    Provide a brief description or any additional details about the event or rental request. This field is optional but can be helpful for event organizers to better understand your needs.
* **confirm_and_complete** (`confirm_and_complete`, text, required: false): 
    Please confirm that you are providing accurate and complete information for your reservation inquiry. This field is optional but helps ensure that you are committed to providing the necessary details for the event organizers.

## Tips
- Please ensure all required fields are filled out before submitting the form.
- Double-check your entries for accuracy before submitting to avoid any issues with your reservation.
- If you have any questions or concerns, feel free to contact the event organizers for clarification.
