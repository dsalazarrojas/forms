# indoor_party_booking_form - Help Guide
## Purpose
This form is designed to collect information for booking an in-door party event. It provides a structured way to input details about the event, making it easier for event organizers to manage and respond to bookings.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the event details in the "Event Details" section.
2. Provide your contact information in the "Contact Info" section.
3. Select the event date and time in the "Event Date and Time" section.
4. Enter the event organizer's name in the "Event Organizer" section.

## Field-by-Field Explanation
### Event Details (text)
* **Event Details** (`event_details`, `text`, required: false): Enter a brief description of the event.

### Contact Info (text)
* **Contact Info** (`contact_info`, `text`, required: false): Enter your name, email, and phone number to ensure we can reach you for further communication.

### Event Date and Time (date)
* **Event Date and Time** (`event_date_time`, `date`, required: false): Select the date and time you would like to hold the event.

### Event Organizer (text)
* **Event Organizer** (`event_organizer`, `text`, required: false): Enter the name of the person or organization organizing the event.
