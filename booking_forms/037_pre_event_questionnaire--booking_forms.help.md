# pre_event_questionnaire - Help Guide
## Purpose
The pre_event_questionnaire is a form used to collect essential details about an event to share with attendees and other stakeholders.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the first page, **event_details**.
2. In **event_details**, provide a brief description of the event.
3. Move to the **attendee_details** page, and provide a count of the expected number of attendees.
4. Continue to the **event_details** page to fill out the expected **event_duration**, **event_format**, and **event_content**.
5. Move to the **speaker_details** page, and enter the name and brief bio of the speaker(s).
6. Proceed to the **event_location** page, and enter the location of the event.
7. Fill out the **event_start_time** and **event_end_time** on the respective pages.
8. Finally, enter a brief description of the event in the **event_description** field.

## Field-by-Field Explanation
- **Event Details** (`event_details`, text, required/optional): Describe the event in a few words.
  - Enter a brief description of the event.
- **Attendees Details** (`attendee_details`, text, required/optional): Enter the expected number of attendees.
  - Enter the number of attendees expected.
- **Event Details** (`event_details`, text, required/optional): Describe the event format and duration.
  - Enter the expected duration and format of the event.
- **Speaker Details** (`speaker_details`, text, required/optional): Enter the speaker's name and bio.
  - Enter the name and brief bio of the speaker.
- **Location** (`event_location`, text, required/optional): Enter the location of the event.
  - Enter the physical location of the event.
- **Event Start Time** (`event_start_time`, time, required/optional): Enter the start time of the event.
  - Enter the start time of the event.
- **Event End Time** (`event_end_time`, time, required/optional): Enter the end time of the event.
  - Enter the end time of the event.
- **Event Duration** (`event_duration`, text, required/optional): Describe the expected event duration.
  - Enter the expected duration of the event.
- **Event Description** (`event_description`, text, required/optional): Enter a brief description of the event.
  - Enter a brief description of the event.

Note: The fields marked as optional may not be required to be filled out, but they are recommended for a more detailed and informative pre-event questionnaire.
