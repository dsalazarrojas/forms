# RV Site Reservation Form - Help Guide
## Purpose
The RV Site Reservation Form is designed to collect information for the purpose of facilitating the reservation of a recreational vehicle site.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the required fields, which are indicated as 'required' in the form.
2. Ensure that you provide accurate and truthful information for all fields.
3. Double-check your submission before submitting it for processing.

## Field-by-Field Explanation
* **Guest Name** (`guest_name`, **text**, required): Enter the name of the person booking the RV site.
* **Guest Phone** (`guest_phone`, **text**, optional): Enter the phone number of the person booking the RV site.
* **Check in Date** (`check_in_date`, **date**, optional): Enter the date you plan to check in to the RV site.
* **Check out Date** (`check_out_date`, **date**, optional): Enter the date you plan to check out of the RV site.
* **Rv Site Size** (`rv_site_size`, **select_one**, optional): Select 'Yes' if the RV site is large, 'No' if it is small.
* **Rv Site Type** (`rv_site_type`, **select_one**, optional): Select 'Yes' if the RV site is available, 'No' if it is not.
* **Site Number** (`site_number`, **text**, optional): Enter the number of the RV site you are booking.
* **Arrival Time** (`arrival_time`, **time**, optional): Enter the time you plan to arrive at the RV site.
* **Reservation Status** (`reservation_status`, **select_one**, optional): Select 'Active' if the reservation is active, 'Inactive' if it is not.
* **Payment Method** (`payment_method`, **select_one**, optional): Select 'Yes' if you have paid for the reservation, 'No' if you have not.
* **Payment Status** (`payment_status`, **select_one**, optional): Select 'Active' if the payment is active, 'Inactive' if it is not.
* **Site Availability** (`site_availability`, **select_multiple**, optional): Select 'Yes' if the site is available, 'No' if it is not.

## Tips
* Please ensure that you provide accurate and truthful information for all fields.
* Double-check your submission before submitting it for processing.
* If you have any questions or concerns, please contact our customer service team.
