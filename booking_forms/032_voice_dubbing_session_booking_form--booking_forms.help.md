# Report Form - Help Guide
## Purpose
This form is used to collect information about a session, allowing for accurate and efficient reporting.

## How To Complete This Form
1. Fill out the following fields with the relevant information:
	* Session Details: Enter a brief description of the session.
	* Client Name: Enter the name of the client.
	* Date: Enter the date of the session.
	* Time: Enter the time of the session.
	* Duration: Enter the duration of the session.
	* Voice Type: Select the type of voice actor involved in the session.
	* Project Details: Enter any additional information about the project.
	* Email: Enter the client's email.
	* Phone: Enter the client's phone number.
	* Session Status: Select the status of the session (Pending, Confirmed, Cancelled).
	* Booking Details: Enter any additional information about the booking.
	* Additional Information: Enter any additional details about the session.

## Field-by-Field Explanation
* **Session Details** (`session_details`, text, optional): Enter a brief description of the session.
* **Client Name** (`name`, text, optional): Enter the name of the client.
* **Date** (`date`, date, optional): Enter the date of the session.
* **Time** (`time`, time, optional): Enter the time of the session.
* **Duration** (`duration`, number, optional): Enter the duration of the session.
* **Voice Type** (`voice_type`, select_one, optional): Select the type of voice actor involved in the session.
* **Project Details** (`project_details`, text, optional): Enter any additional information about the project.
* **Email** (`email`, email, optional): Enter the client's email address.
* **Phone** (`phone`, text, optional): Enter the client's phone number.
* **Session Status** (`session_status`, select_one, optional): Select the status of the session (Pending, Confirmed, Cancelled).
* **Booking Details** (`booking_details`, text, optional): Enter any additional information about the booking.
* **Additional Information** (`additional_info`, text, optional): Enter any additional details about the session.

## Tips
* Double-check that all required fields are filled out before submitting the form.
* Make sure to enter accurate and up-to-date information.
* If you have any doubts or concerns, please contact the relevant department or support team.
