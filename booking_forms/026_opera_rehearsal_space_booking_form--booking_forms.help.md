# Opera Rehearsal Space Booking Form - Help Guide
## Purpose
This form is used to book and manage rehearsal spaces for performances. Please fill out the form with accurate information to ensure a smooth and efficient booking process.

## How To Complete This Form
To complete this form, simply fill out the fields below with the required information.

## Field-by-Field Explanation
* **Production Name** (`production_name`, text, optional): Enter the name of the production or event being rehearsed.
* **Performance Date** (`performance_date`, date, optional): Select the date of the performance.
* **Start Time** (`start_time`, time, optional): Enter the start time of the performance.
* **End Time** (`end_time`, time, optional): Enter the end time of the performance.
* **Event Organizers** (`event_organizers`, text, optional): List the names of the people organizing the event.
* **Event Coordinators** (`event_coordinators`, text, optional): List the names of the event coordinators.
* **Event Producers** (`event_producers`, text, optional): List the names of the event producers.

## Tips
- Make sure to double-check the performance date and times to avoid scheduling conflicts.
- Include all necessary contact information for event organizers, coordinators, and producers.
- If you are unsure about any field, please contact [form@gic.mx](mailto:form@gic.mx) for assistance.
