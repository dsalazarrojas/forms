# Pickup Time Slot Selection - Help Guide
## Purpose
This form is used to select a pickup time slot for a pickup or delivery operation. It's a simple way to gather information from the user for scheduling purposes.

## How To Complete This Form

To complete this form, follow these steps:

1. Select one or more time slots from the dropdown menu that you would like to schedule for the pickup or delivery operation.
2. If you want to add any additional contact information, fill in the Contact Name, Phone, and Email fields.
3. Click submit to send your selection and contact information.

## Field-by-Field Explanation

* **Time Slot Selection** (`time_slot_selection`, `select_multiple`, required: false): This is the main field where you select one or more time slots for the pickup or delivery operation. Each time slot is a 30-minute increment from 09:00 to 15:00. Select one or more time slots that work for you.
* **Contact Name** (`contact_name`, `text`, required: false): If you would like to provide any contact information, fill in your name here.
* **Contact Phone** (`contact_phone`, `text`, required: false): If you would like to provide any phone number information, fill in the contact phone number here.
* **Contact Email** (`contact_email`, `email`, required: false): If you would like to provide any email information, fill in the contact email here.

## Tips

* You can select multiple time slots if you have multiple options that work for you.
* You can leave the contact information fields blank if you do not want to provide any contact information.
* Make sure to select at least one time slot to complete the form successfully.
