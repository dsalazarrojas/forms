# Entrepreneurship Workshop Booking Form - Help Guide
## Purpose
This form is used to book an entrepreneurship workshop with a specified duration, time, and date. Please fill out the form with your details and preferences to ensure a smooth booking process.

## How To Complete This Form
1. Please fill out the form with accurate and complete information for each field.
2. Make sure to review your submission before confirming.

## Field-by-Field Explanation

* **Workshop Details** (`workshop_details`, `text`, required: false):
	+ This field is a free text area where you can provide any information about the workshop you'd like to book.
* **Participant Information** (`participant_info`, `text`, required: false):
	+ This field is meant for any additional details about the participant.
* *Participant Name* (`participant_name`, `text`, required: false):
	+ Enter your name as you'd like to be referred to during the workshop.
* *Participant Email* (`participant_email`, `email`, required: false):
	+ Enter a valid email address to reach out to you for updates or confirmations.
* *Participant Phone* (`participant_phone`, `text`, required: false):
	+ If you'd like to be contacted by phone, please enter your phone number.
* *Workshop Date* (`workshop_date`, `date`, required: false):
	+ Please enter the date of the workshop you're interested in, in the `yyyy-mm-dd` format.
* *Workshop Time* (`workshop_time`, `time`, required: false):
	+ Select the time of the workshop you'd like to attend.
* *Workshop Duration* (`workshop_duration`, `number`, required: false):
	+ Specify the number of hours or minutes you'd like the workshop to last.
* *Participant Message* (`participant_message`, `text`, required: false):
	+ If you have any special requests or need to convey any information to the workshop organizers, this is the place to do so.
