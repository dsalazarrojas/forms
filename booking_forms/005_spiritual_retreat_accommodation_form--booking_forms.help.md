# Spiritual Retreaet Accommodation Form - Help Guide
## Purpose

This form is used for booking spiritual retreat accommodations for participants. It collects necessary information for the accommodation process, including participant details, accommodation type, and payment information. Before completing this form, please ensure that you are eligible to book spiritual retreat accommodations.

## How To Complete This Form

1. **Retreat Location**: Enter the location of the spiritual retreat. This is the physical address where the retreat will take place.
2. **Participants List**: Select 'Yes' if you are booking accommodations for multiple participants. This will allow us to better prepare for their needs.
3. **Dates**: If you are booking for a specific date range, enter the start and end dates in the format 'mm/dd/yyyy' or 'mm/dd/yyyy', respectively. Leave empty if not applicable.
4. **Start Date**: Enter the start date of the retreat, if applicable.
5. **End Date**: Enter the end date of the retreat, if applicable.
6. **Participant Name**: Enter the name of the participant you are booking for.
7. **Participant Email**: Enter the email address of the participant.
8. **Participant Phone**: Enter the phone number of the participant.
9. **Participant Information**: Enter any additional information about the participant.
10. **Participant Type**: Select 'Yes' if this participant requires special attention or accommodations.
11. **Participant Special Requirements**: Enter any special requests or requirements for this participant.
12. **Accommodation Type**: Select 'Yes' if you require accommodations for this participant.
13. **Accommodation Details**: Enter any additional details about the required accommodations.
14. **Accommodation Price Range**: Select the price range of the accommodations required.
15. **Other Accommodation**: Select 'Yes' if other accommodations are required.
16. **Accommodation Information**: Enter any additional information about the accommodations.
17. **Special Requests**: Enter any special requests or requirements for this accommodation.
18. **Payment Method**: Select 'Yes' if you are paying by a specific method.
19. **Billing Address**: Enter the billing address for this booking.
20. **Billing City**: Enter the city for the billing address.
21. **Billing State**: Enter the state for the billing address.
22. **Billing Postal Code**: Enter the postal code for the billing address.
23. **Billing Country**: Enter the country for the billing address.
24. **Billing Information**: Enter any additional information about the billing address.
25. **Notes**: Enter any additional notes or comments about this booking.
