# event-rehearsal-scheduling-form - Help Guide
## Purpose
The event-rehearsal-scheduling-form is designed to collect information about an event's date, time, duration, participants, and description. This form helps ensure that all necessary details are recorded accurately and reduces the chance of scheduling conflicts.

## How To Complete This Form

To complete this form, follow these steps:

1.  Select the date of the event in the "Event Date" field.
2.  Choose the start time for the event in the "Event Start Time" field.
3.  Enter the duration of the event in the "Event Duration" field.
4.  Indicate if the event will have participants and choose "Yes" or "No" in the "Participants" field.
5.  Enter a description of the event in the "Description" field.

## Field-by-Field Explanation
*  **Event Date** (`event_date`, date, required/optional): Select the date of the event from the calendar.
*  **Event Start Time** (`event_start_time`, time, optional): Select the start time of the event.
*  **Event End Time** (`event_end_time`, time, optional): Select the end time of the event.
*  **Event Duration** (`event_duration`, number, optional): Enter the duration of the event in hours or minutes.
*  **Start Date** (`event_start_date`, date, optional): Select the start date for the event's registration or planning.
*  **End Date** (`event_end_date`, date, optional): Select the end date for the event's registration or planning.
*  **Participants** (`event_participants`, select multiple, optional): Check "Yes" if the event will have participants and "No" otherwise.
*  **Venue** (`event_venue`, text, optional): Enter a brief description of the event venue.
*  **Description** (`event_description`, text, optional): Enter a brief description of the event.
