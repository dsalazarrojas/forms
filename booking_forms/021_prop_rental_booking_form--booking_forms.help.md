# Prop Rental Booking Form - Help Guide
## Purpose
The Prop Rental Booking Form is used to book a prop for an event. Fill out the form to provide details about the event and the prop.

## How To Complete This Form
1. Select a date range for the event by entering the start and end dates.
2. Provide the event location.
3. Enter the type of event (e.g., concert, conference, etc.).
4. Enter the name and contact information of the event organizer.
5. Add any additional notes about the event.
6. Select the type of prop you want to book (e.g., chair, table, etc.).
7. Enter the quantity of props needed.
8. Describe the condition of the props.
9. Enter the price of the props.
10. Upload an image of the prop.
11. Add any additional notes about the prop.
12. Enter the size of the prop.
13. Describe the prop in detail.
14. Upload an image of the prop.
15. Add any additional notes about the prop.

## Field-by-Field Explanation
* **event_start_date (Date)**: Enter the start date of the event.
* **event_end_date (Date)**: Enter the end date of the event.
* **event_location (Text)**: Provide the address or location of the event.
* **event_type (Text)**: Select the type of event (e.g., concert, conference, etc.).
* **event_organizer (Text)**: Enter the name and contact information of the event organizer.
* **event_notes (Note)**: Add any additional notes about the event.
* **equipment_type (Text)**: Select the type of prop you want to book (e.g., chair, table, etc.).
* **equipment_quantity (Number)**: Enter the quantity of props needed.
* **equipment_condition (Text)**: Describe the condition of the props.
* **equipment_price (Number)**: Enter the price of the props.
* **equipment_description (Text)**: Describe the prop in detail.
* **equipment_image (Text)**: Upload an image of the prop.
* **equipment_additional_notes (Note)**: Add any additional notes about the prop.
* **prop_type (Text)**: Select the type of prop (e.g., chair, table, etc.).
* **prop_size (Text)**: Enter the size of the prop.
* **prop_description (Text)**: Describe the prop in detail.
* **prop_image (Text)**: Upload an image of the prop.
* **prop_additional_notes (Note)**: Add any additional notes about the prop.
* **first_name (Text)**: Enter your first name.
* **email (Email)**: Enter your email address.
* **phone (Text)**: Enter your phone number.
