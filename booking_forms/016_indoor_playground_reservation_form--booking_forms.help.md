# indoor_playground_reservation_form - Help Guide
## Purpose
This form is for booking a time slot for your child(ren) to play at our indoor playground.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in the required information:
   - **User**: Enter your name and contact details.
   - **Start Date**: Select the date you'd like to book.
   - **End Date**: Select the date you'd like the booking to end.
   - **Start Time**: (Optional) Select the start time for the booking. If left blank, the system will default to the standard start time for the selected date.
   - **End Time**: Select the end time for the booking.
   - **Number of Children**: Choose the number of children you'd like to book.
   - **Age Range**: Select the age range of the children you'd like to book.
   - **Reservation Date**: This is the date we will use to confirm the booking.
   - **Email**: Enter your email address.
   - **Phone**: Enter your phone number.
   - **Submit**: Select "Save" to complete the booking.

## Field-by-Field Explanation

*   **User** (`text`, required/optional): Enter your name and contact details.
*   **Start Date** (`date`, required): Select the date you'd like to book.
*   **End Date** (`date`, required): Select the date you'd like the booking to end.
*   **Start Time** (`time`, optional): Select the start time for the booking.
*   **End Time** (`time`, required): Select the end time for the booking.
*   **Number of Children** (`number`, required): Choose the number of children you'd like to book.
*   **Age Range** (`select_one`, required): Select the age range of the children you'd like to book.
*   **Reservation Date** (`date`, required): This is the date we will use to confirm the booking.
*   **Email** (`email`, required): Enter your email address.
*   **Phone** (`text`, required): Enter your phone number.
*   **Submit** (`select_multiple`, required): Select "Save" to complete the booking.
