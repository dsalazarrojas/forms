# Concert Information Form - Help Guide
## Purpose
This form is used to collect information about concerts and events. You can use it to provide essential details about the event, including the event basics, venue information, performer details, and technical requirements.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the basic event details, such as the event name, date, start time, and venue name.
2. Select the genre of music that best fits the event.
3. Enter the name of the headlining artist or band.
4. Provide details about supporting acts, if applicable.
5. Enter the estimated number of attendees, if available.
6. Fill in the ticket price range, including the minimum and maximum prices.
7. Choose the current ticket availability status.
8. Select the age restriction for the event.
9. Enter the contact information for the event organizer, including their name, email, and phone number.

## Field-by-Field Explanation

* **Event Name** (`event_name`, required): Enter the official name of the concert or event.
* **Event Date** (`event_date`, required): Select the primary concert date.
* **Event Start Time** (`event_time`, required): Enter the time when the event starts.
* **Venue Name** (`venue_name`, required): Enter the name of the concert hall or venue.
* **Venue Address** (`venue_address`, required): Enter the complete street address of the venue.
* **Venue Capacity** (`venue_capacity`, required): Enter the maximum audience capacity of the venue.
* **Headlining Artist or Band** (`headlining_artist`, required): Enter the name of the main performer or band.
* **Supporting Acts** (`supporting_acts`, optional): Enter the names of the supporting performers, if applicable.
* **Music Genre** (`artist_genre`, required): Select the primary genre of music that best fits the event.
* **Expected Attendance** (`expected_attendance`, optional): Enter the estimated number of attendees, if available.
* **Ticket Information** (`ticket_information`, optional): Enter pricing and availability details for the event tickets.
* **Minimum Ticket Price** (`ticket_price_min`, required): Enter the lowest price point for event tickets in dollars.
* **Maximum Ticket Price** (`ticket_price_max`, required): Enter the highest price point for event tickets in dollars.
* **Ticket Availability Status** (`ticket_availability`, required): Select the current ticket availability status.
* **Age Restriction** (`age_restriction`, required): Select the age restriction for the event.
* **Organizer Name** (`organizer_name`, required): Enter the name of the event organizer.
* **Organizer Email** (`organizer_email`, required): Enter the contact email address of the event organizer.
* **Organizer Phone** (`organizer_phone`, required): Enter the contact phone number of the event organizer.
