# Travel Package Extension Form - Help Guide
## Purpose
This form is used to request an extension for a travel package. It is designed to gather information from customers or travel agents about the reason for the extension and the package details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a short description of the reason for the extension in the `reason_for_extension` field.
2. If you are a travel agent, check the `travel_agent` field to indicate whether the agency is handling the package.
3. Enter the ID of the travel package in the `travel_package_id` field.
4. If you are a customer, select "Yes" or "No" in the `customer` field to indicate whether you are the customer or not.
5. Review and submit the form once all fields are filled in.

## Field-by-Field Explanation

* **reason_for_extension**: A short description of the reason for the extension (text field).
* **travel_agent**: If you are a travel agent, check "Yes" to indicate that you are handling the package (select multiple field).
* **travel_package_id**: Enter the ID of the travel package (number field).
* **customer**: If you are a customer, select "Yes" to indicate that you are the customer (select multiple field).

## Tips
* Make sure to fill in all required fields to ensure that your request is processed correctly.
* If you are unsure about any field, please don't hesitate to ask for assistance.
* Review the form carefully before submitting to ensure that all information is accurate.
