# Stage Rigging Crew Booking Form - Help Guide
## Purpose
This form is designed for booking a stage rigging crew for an event. It collects necessary details about the event, crew requirements, and contact information to ensure a smooth and efficient booking process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the name of the event in the "Event Name" field.
2. Select the date of the event in the "Event Date" field.
3. Choose the time of the event in the "Event Time" field.
4. Select the type of crew required for the event from the "Crew Type" dropdown menu.
5. List the equipment needed for the event in the "Equipment List" field.
6. Provide details about the equipment in the "Equipment Details" field.
7. Enter the name and contact information of the person booking the crew in the "Contact Name", "Contact Email", and "Contact Phone" fields.
8. Enter the location of the event in the "Event Venue", "Event Venue Location", "Event Venue City", "Event Venue State", "Event Venue Postal Code", and "Event Venue Country" fields.
9. Enter any additional details about the event in the "Event Details" field.
10. Enter the setup and teardown times for the event in the "Event Setup" and "Event Teardown" fields, respectively.
11. Enter the load in and load out times for the event in the "Event Load In" and "Event Load Out" fields, respectively.
12. Enter the dimensions of the stage in the "Stage Height" and "Stage Width" fields.
13. Enter the rigging height in the "Rigging Height" field.
14. Add any comments or special requests in the "Comments" field.

## Field-by-Field Explanation
* **Event Name** (`event_name`, text, required): Enter the name of the event.
* **Event Date** (`event_date`, date, required): Select the date of the event.
* **Event Time** (`event_time`, time, required): Choose the time of the event.
* **Crew Type** (`crew_type`, select_one, required): Select the type of crew required for the event (e.g., Rigger, Stagehand, Roustabout).
* **Equipment List** (`equipment_list`, text, required): List the equipment needed for the event.
* **Equipment Details** (`equipment_details`, text, required): Provide details about the equipment.
* **Contact Name** (`contact_name`, text, required): Enter the name of the person booking the crew.
* **Contact Email** (`contact_email`, email, required): Enter the email address of the person booking the crew.
* **Contact Phone** (`contact_phone`, text, required): Enter the phone number of the person booking the crew.
* **Event Venue** (`event_venue`, text, required): Enter the location of the event.
* **Event Venue Location** (`event_venue_location`, text, required): Enter the location of the event venue.
* **Event Venue City** (`event_venue_city`, text, required): Enter the city of the event venue.
* **Event Venue State** (`event_venue_state`, text, required): Enter the state of the event venue.
* **Event Venue Postal Code** (`event_venue_postal_code`, text, required): Enter the postal code of the event venue.
* **Event Venue Country** (`event_venue_country`, text, required): Enter the country of the event venue.
* **Event Details** (`event_details`, text, required): Enter any additional details about the event.
* **Event Setup** (`event_setup`, number, required): Enter the setup time for the event.
* **Event Teardown** (`event_teardown`, number, required): Enter the teardown time for the event.
* **Event Load In** (`event_load_in`, time, required): Enter the load in time for the event.
* **Event Load Out** (`event_load_out`, time, required): Enter the load out time for the event.
* **Stage Height** (`stage_height`, number, required): Enter the height of the stage.
* **Stage Width** (`stage_width`, number, required): Enter the width of the stage.
* **Rigging Height** (`rigging_height`, number, required): Enter the rigging height.
* **Comments** (`comments`, text, required): Enter any comments or special requests.
