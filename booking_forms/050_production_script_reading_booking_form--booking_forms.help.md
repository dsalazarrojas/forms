# Production Script Reading Booking Form - Help Guide
## Purpose

The Production Script Reading Booking Form is a tool to manage script readings for production purposes. It is used to collect and store information about the script, the reading date and time, and the contact information of the person making the booking.

## How To Complete This Form

1. Fill in the project name.
2. Select the type of script you are looking to read (e.g. screenplay, screenplays).
3. Choose a date for the reading.
4. Select a time for the reading.
5. Choose the status of the script (e.g. pending, approved, rejected).
6. Add any additional comments or notes about the script.
7. Provide the name of the contact person.
8. Enter their email address.
9. Enter their phone number.
10. Update the status of the booking (e.g. pending, approved, rejected).
11. Add any additional comments or notes about the booking.

## Field-by-Field Explanation

* **project_name** (text, required): This field is used to enter the name of the project.
* **script_type** (select multiple, not required): Select the type of script you are looking to read (e.g. screenplay, screenplays).
* **reading_date** (date, required): This field is used to choose a date for the reading.
* **reading_time** (time, required): This field is used to select a time for the reading.
* **script_status** (select one, required): Choose the status of the script (e.g. pending, approved, rejected).
* **script_note** (note, not required): Add any additional comments or notes about the script.
* **contact_name** (text, required): This field is used to enter the name of the contact person.
* **contact_email** (email, required): Enter the email address of the contact person.
* **contact_phone** (text, required): This field is used to enter the phone number of the contact person.
* **booking_status** (select one, required): Update the status of the booking (e.g. pending, approved, rejected).
* **booking_note** (note, required): Add any additional comments or notes about the booking.

## Tips

* Make sure to fill in all required fields.
* Double-check the information you enter before submitting the form.
* Use the select multiple feature to choose multiple script types if necessary.
