# Accommodation Variation Request Form - Help Guide
## Purpose
This form is used to submit requests for changes to existing bookings.

## How To Complete This Form

1. **Guest Information**: 
- **Guest Full Name (As it appears on your booking confirmation)**: Please enter the name of the guest as it appears on your booking confirmation email.
- **Email Address (Email)**: Enter the email address associated with the booking.
- **Phone Number (Text)**: Enter the phone number associated with the booking.
- **Booking Reference Number (Text)**: Enter the booking reference number found in your confirmation email.

2. **Current Booking Details**:
- **Current Check-In Date (Date)**: Enter the original check-in date of the booking.
- **Current Check-Out Date (Date)**: Enter the original check-out date of the booking.
- **Current Room Type (Text)**: Enter the original room type of the booking.

3. **Requested Changes**:
- **Type of Change Requested (Select Multiple)**: Select all the changes you are requesting, such as changing the check-in date, check-out date, room type, or adding services.
- **New Check-In Date (if changing) (Date)**: If you are requesting to change the check-in date, enter the new date.
- **New Check-Out Date (if changing) (Date)**: If you are requesting to change the check-out date, enter the new date.
- **New Room Type Requested (if changing) (Select One)**: If you are requesting to change the room type, select the new type from the options provided.
- **Updated Number of Guests (Number)**: If you are requesting to add or remove guests, enter the new number of guests.

4. **Reason for the Requested Change**:
- **Reason for the Requested Change (Text)**: Provide a clear and specific reason for the requested changes.

5. **Additional Services and Requests**:
- **Additional Services Needed (Select Multiple)**: Select any additional services you need, such as airport transfers, extra beds, meals, or late check-out.
- **Additional Special Requests (Text)**: If you have any further requests, specify them here.

## Tips
- Make sure to fill out all required fields.
- Provide clear and specific information for each field.
- If you have any questions or concerns, contact our support team for assistance.
