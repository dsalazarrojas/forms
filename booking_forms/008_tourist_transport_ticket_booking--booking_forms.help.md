# tourist_transport_ticket_booking - Help Guide
## Purpose
The "tourist_transport_ticket_booking" form is designed to collect comprehensive details for tourist transportation bookings, allowing users to input information about customers, transportation types, dates, times, contact details, and more. This form aims to provide a complete overview of the booking process.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the **Customer Name**, which is a text field where you can type in the customer's name.
2. Select the **Departure Location** from the provided options (e.g., "Yes" or "No").
3. Select the **Arrival Location** from the provided options (e.g., "Yes" or "No").
4. Input the **Departure Date** in the date format (MM/dd/yyyy).
5. Input the **Transportation Type**, a multiple-choice field where you can select one or more options (e.g., "Yes" or "No").
6. Enter the **Number of Travelers**, which is a numeric field.
7. Enter the **Contact Number**, a text field for the customer's contact information.
8. Enter the **Email**, a text field for the customer's email address.
9. Select the **Booking Date**, which is a date field.
10. Select the **Booking Time**, which is a time field.
11. Input any additional **Note** for the booking.
12. Input the **Payment Gateway ID**, a numeric field.
13. Enter the **Transport Cost**, a numeric field.
14. Enter the **Customer Email**, which is a text field for the customer's email address.
15. Enter the **Customer Phone**, a text field for the customer's contact number.
16. Enter the **Customer Name** again, as a duplicate field (please note: this field is likely a redundancy and can be removed or renamed for better clarity).
17. Enter the **Customer Note**, a text field for any additional customer notes.
18. Enter the **Transport Provider**, a text field for the transportation provider's information.
19. Enter the **Transport Type Name**, a text field for the transportation type's name.
20. Select the **Departure Time**, which is a time field.
21. Select the **Booking Status**, which is a text field for the booking status.
22. Select the **Transport Status**, which is a text field for the transportation status.
23. Enter the **Customer Type**, a text field for the customer type.
24. Enter the **Vehicle Number**, a numeric field.
25. Enter the **Fare**, a numeric field.
