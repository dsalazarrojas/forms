# Taxi Online Booking - Help Guide
## Purpose
The "Taxi Online Booking" form is designed to let users book taxi services for a specific journey. The form allows users to input details such as pickup and dropoff locations, journey type (one-way, return, one day, or multiple), taxi type, and other relevant information to schedule their taxi ride.

## How To Complete This Form
To use this form, follow these steps:

1. Fill in the pickup location where you would like to be picked up.
2. Enter the dropoff location where you would like to be dropped off.
3. Select the type of journey you require (one-way, return, one day, or multiple).
4. Choose the type of taxi you prefer (Sedan, Minivan, or Luxury).
5. If you need to input any special instructions or notes for the driver, you can add them in the "Instructions" field.
6. If you want to input a specific route, you can do so in the "Insert Route" field.
7. Select the date and time for your taxi booking.
8. Finally, enter your phone number so that we can contact you to confirm your booking.

## Field-by-Field Explanation

* **Pickup Location (id: 1)**: Enter the address where you would like to be picked up.
* **Dropoff Location (id: 2)**: Enter the address where you would like to be dropped off.
* **Instructions (id: 3)**: Add any special instructions or notes for the driver.
* **Select Journey Type (id: 4)**: Choose the type of journey you require (one-way, return, one day, or multiple).
* **Select Taxi Type (id: 5)**: Choose the type of taxi you prefer (Sedan, Minivan, or Luxury).
* **Insert Route (id: 6)**: If you need to input a specific route, enter it here.
* **Date (id: 7)**: Select the date for your taxi booking.
* **Time (id: 8)**: Select the time for your taxi booking.
* **Phone Number (id: 9)**: Enter your contact number so that we can contact you to confirm your booking.
