# Cue Operator Booking Form - Help Guide
## Purpose
The Cue Operator Booking Form is designed to collect booking information for a specific event with an operator. This form is used to gather essential details such as event date, time, location, and operator contact information, as well as confirm the booking status and assign additional tools.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide event details, including date and time.
2. Enter the location of the event.
3. Enter operator details, including name and contact email.
4. Confirm the booking status.
5. Select any additional tools to be assigned.
6. Leave a comment (if necessary).

## Field-by-Field Explanation
### Event Details
* **Event Date**: Enter the date of the event, in `date` format (e.g., 2023-02-16).
* **Event Time**: Enter the time of the event, in `time` format (e.g., 14:00).
* **Event Location**: Enter the location of the event.

### Operator Details
* **Operator Name**: Enter the name of the operator.
* **Operator Email**: Enter the email address of the operator.
* **Operator Phone**: Enter the phone number of the operator.

### Booking Information
* **Booking Date**: Enter the date of the booking, in `date` format (e.g., 2023-02-16).
* **Booking Time**: Enter the time of the booking, in `time` format (e.g., 14:00).
* **Booking Status**: Select the current booking status, which is either "Active", "Pending", or "Inactive".
* **Assigned Tool**: Select the tool to be assigned for the booking.

### Confirmations and Notes
* **Confirmation**: Confirm that the form has been completed correctly and select if additional tools are to be assigned.
* **Notes**: Enter any additional comments or notes related to the booking.

### Form Submission
* **Submit Form**: Select "Yes" to submit the form and complete the booking process.
