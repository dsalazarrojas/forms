# Online Photo Shoot Booking Form - Help Guide
## Purpose
This form is for customers to provide necessary information to book a photo shoot session with our organization.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in your Customer Details.
2.  Choose your preferred Session Type (Morning or Afternoon).
3.  Optionally, provide any additional Session Purpose details if necessary.
4.  If you have any questions or comments, please use the Questions or Comments field.

## Field-by-Field Explanation
* **Customer Details** (`customer_details`, text, required): This is the first field to be filled. Please enter your name and any other relevant details about yourself.
* **Session Type** (`session_type`, select_one, required): Please select the time of your photo shoot session. This can be either Morning or Afternoon.
* **Session Purpose** (`session_purpose`, text, optional): This is an optional field to provide more details about your session purpose. If you don't have anything specific, you can leave this field blank.
* **Questions or Comments** (`questions_comments`, text, optional): If you have any questions or need to make any comments, please use this field. This will help us to serve you better.

## Tips
* Please ensure that all required fields are filled before submitting the form.
* If you have any doubts or questions, please don't hesitate to contact [support email/number].
