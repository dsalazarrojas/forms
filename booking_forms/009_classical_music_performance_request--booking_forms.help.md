# Classical Music Performance Request - Help Guide
## Purpose
The Classical Music Performance Request form is designed to gather all necessary information about your event and your musical preferences. Please fill out this form to ensure that we can tailor our performance to your specific needs.

## How To Complete This Form
1. Start by selecting the correct event type.
2. Fill in all required fields (marked with an asterisk *).
3. Provide as much detail as possible in the text fields.
4. Select only one option for each select_one field.
5. If you have any special requests or additional notes, use the special requests field.

## Field-by-Field Explanation
* **Event Type** (`Event Type`, required): Select the type of event for which you are requesting a performance (e.g., Wedding, Corporate Event, etc.).
* **Name** (`Name`, required): Enter the full name of the person requesting the performance.
* **Email Address** (`Email Address`, required): Provide a valid email address for communication purposes.
* **Phone Number** (`Phone Number`, required): Enter your contact number.
* **Organization or Event Name** (`Organization or Event Name`, required): Enter the name of the organization or event.
* **Event Description** (`Event Description`, required): Describe the event and atmosphere you desire.
* **Event Date** (`Event Date`, required): Select the preferred date for the performance.
* **Event Time** (`Event Time`, required): Choose the time the performance should take place.
* **Duration Needed** (`Duration Needed`, required): Select the length of the performance.
* **Event Location** (`Event Location`, required): Enter the street address and venue name.
* **Venue Type** (`Venue Type`, required): Choose the type of venue (e.g., Concert Hall, Church, etc.).
* **Expected Audience Size** (`Expected Audience Size`, optional): Estimate the number of attendees.
* **Music Style or Composer Preferences** (`Music Style or Composer Preferences`, optional): Indicate any specific pieces, composers, or styles you desire.
* **Ensemble Type Preferred** (`Ensemble Type Preferred`, required): Choose the type of musicians you need (e.g., Solo Pianist, String Quartet, etc.).
* **Custom Arrangements** (`Custom Arrangements`, optional): If you need custom arrangements or special pieces, select 'True' (default is 'False').
* **Piano or Sound System Available at Venue** (`Piano or Sound System Available at Venue`, required): Select how you will provide a piano or sound system.
* **Parking Available for Performers** (`Parking Available for Performers`, optional): Indicate if parking is free, paid, or limited.
* **Accommodation Needed** (`Accommodation Needed`, optional): If performers need lodging, select 'True'.
* **Performance Budget Range** (`Performance Budget Range`, required): Choose your budget range for the performance.
* **Special Requests or Additional Notes** (`Special Requests or Additional Notes`, optional): Provide any other relevant information we should know.
