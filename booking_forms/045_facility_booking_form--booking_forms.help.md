# Facility Booking Form - Help Guide
## Purpose
This form is designed for booking facilities for events or rentals. It gathers information about the facility and the customer, including the start and end dates, time, and other relevant details.

## How To Complete This Form

*   Fill out the form with the required information:
    *   Enter the facility name and address for the event or rental.
    *   Enter your customer name and email address.
    *   Provide the start and end dates for the event or rental.
    *   Select a time for the event or rental.
    *   Choose the duration of the booking.
    *   Select the type of booking (one-off event or ongoing use).
    *   Add any comments you'd like to share with the facility.
    *   If required, select the facility status (available or not available).
    *   If required, select the facility availability (available or not available).
    *   If required, enter the facility capacity and limit.
    *   If required, select the method of payment (online or offline).
    *   If required, confirm the facility booking status (available or not available).
*   Review the form carefully and ensure that all required fields are completed accurately.

## Field-by-Field Explanation

*   **Facility Name (1)**: Enter the name of the facility you are booking.
*   **Facility Email (4)**: Enter the facility email address associated with the facility.
*   **Customer Name (6)**: Enter your name as the customer making the booking.
*   **Customer Email (7)**: Enter your email address associated with your customer account.
*   **Facility Address (3)**: Enter the address of the facility you are booking.
*   **Facility Phone (5)**: Enter the phone number of the facility if applicable.
*   **Customer Phone (8)**: Enter your phone number if you'd like the facility to contact you.
*   **Start Date (9)**: Select the start date for the event or rental.
*   **End Date (10)**: Select the end date for the event or rental.
*   **Time (11)**: Select the time for the event or rental.
*   **Facility Booking Duration (12)**: Enter the duration of the facility booking.
*   **Customer Booking Duration (13)**: Enter the duration of the customer's booking.
*   **Facility Booking Type (14)**: Select the type of facility booking (one-off event or ongoing use).
*   **Customer Comments (15)**: Add any comments you'd like to share with the facility.
*   **Facility Comments (16)**: Add any comments you'd like to share with the customer.
*   **Facility Status (17)**: If the facility is not available, select "Not Available."
*   **Facility Availability (18)**: Select the availability of the facility for the booking period.
*   **Facility Capacity (19)**: Enter the capacity of the facility if required.
*   **Facility Booking Limit (20)**: Enter the booking limit of the facility if required.
*   **Facility Booking Price (21)**: Enter the booking price of the facility if required.
*   **Facility Status (22)**: If the facility is not available, select "Not Available."
*   **Customer Payment (23)**: Select the method of payment (online or offline).
*   **Payment Method (24)**: Select the method of payment (credit card, bank transfer, or cheque).
*   **Facility Booking Confirmation (25)**: If the booking is confirmed, select "Available."
