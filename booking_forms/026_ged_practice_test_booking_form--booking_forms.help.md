# GED Practice Test Booking Form - Help Guide
## Purpose
The GED Practice Test Booking Form is used to collect information from students and teachers about a practice test, including the schedule date, select time, practice test name, student name, student phone number, student email, and other relevant details.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Select a date for the practice test from the calendar.
3. Choose the time for the practice test from the list of options.
4. Enter the name of the practice test.
5. Enter the student's name.
6. Enter the student's phone number.
7. Enter the student's email address.
8. If applicable, enter the teacher's name.

## Field-by-Field Explanation

* **Schedule Date** (`schedule_date`, date, required: false): Select the date for the practice test from the calendar. This is the date when the practice test will take place.
* **Select Time** (`select_time`, select_multiple, required: false): Choose the time for the practice test from the list of options. This is the time slot available for the practice test.
* **Practice Test Name** (`practice_test_name`, text, required: false): Enter the name of the practice test, e.g., "Math Practice Test".
* **Student Name** (`student_name`, text, required: false): Enter the student's name, e.g., "John Doe".
* **Student Phone** (`student_phone`, text, required: false): Enter the student's phone number, e.g., "123-456-7890".
* **Student Email** (`student_email`, email, required: false): Enter the student's email address. This is where the student can be reached for more information.
* **Teacher** (`teacher`, text, required: false): If applicable, enter the teacher's name, e.g., "Mrs. Smith".
* **Student Info** (`student_info`, note, required: false): This is an optional field where you can add any additional information about the student.

## Tips
* Make sure to double-check your information before submitting the form.
* If you are unsure about any of the fields, contact your supervisor or the form creator for clarification.
* If you have any questions or need help with the form, reach out to the form creator or your team for assistance.
