# Faculty Recording Session Booking Form - Help Guide

## Purpose
The Faculty Recording Session Booking Form is a tool for faculty members to book and manage their recording sessions. It is essential to provide accurate information about the session, including type, date, time, and duration, to ensure smooth and efficient recording processes.

## How To Complete This Form

1.  Select the "Booking Details" page and enter the necessary information.
2.  On the "Session Details" page, choose the type of session (Faculty Development, Faculty Presentation, or Other).
3.  On the "Session Details" page, select a date for the session.
4.  On the "Session Details" page, select the time for the session.
5.  On the "Session Details" page, select the duration of the session.
6.  On the "Participant List" page, enter the names of participants attending the session.
7.  Select the "Available" or "Not Available" status for the booking.
8.  Review your entries and submit the form.

## Field-by-Field Explanation

*   **Booking Details** (Faculty Recording Session Booking Form Page 1):
    *   **Faculty Recording Session Booking Form Page 1** (text): Enter a brief description of the booking.
*   **Session Details** (Faculty Recording Session Booking Form Page 2):
    *   **Session Type** (`Faculty Recording Session Booking Form Session Details`):
        *   Select the type of session (Faculty Development, Faculty Presentation, or Other).
        *   Choose the correct type that best describes the purpose of the recording session.
    *   **Session Date** (`Faculty Recording Session Booking Form Session Date`):
        *   Enter the date for the session (format: YYYY-MM-DD).
        *   Choose a date that the session will take place.
    *   **Session Time** (`Faculty Recording Session Booking Form Session Time`):
        *   Enter the time for the session (format: 24-hour clock, e.g., 08:00, 12:00, 18:00).
        *   Choose the correct time for the session to take place.
    *   **Session Duration** (`Faculty Recording Session Booking Form Session Duration`):
        *   Enter the duration of the session in minutes.
        *   Choose the correct duration for the session.
*   **Participant List**:
    *   **Participant List** (`Faculty Recording Session Booking Form Participant List`):
        *   Enter the names of participants attending the session.
        *   Separate multiple participants with commas.
*   **Session Details**:
    *   **Session Status** (`Faculty Recording Session Booking Form Booking Status`):
        *   Select "Available" if the session is available for booking.
        *   Select "Not Available" if the session is already booked or in progress.
