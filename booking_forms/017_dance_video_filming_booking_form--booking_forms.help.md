# Dance Video Filming Booking Form - Help Guide

## Purpose
This form is designed to collect all the necessary information for a successful video filming project. It covers various aspects, including event/project details, client contact information, project specifics, and project status.

## How To Complete This Form

1.  Start by choosing a title for the form (Form Title).
2.  Provide the Client Name and their phone number in the Client Name and Phone field.
3.  Enter the Client Email to ensure smooth communication.
4.  Enter the project details in the Project Details field, which will help us understand your requirements.
5.  Choose the Event Type from the list provided.
6.  Select the Event Date, Event Time, Event Start Date, and Event End Date accurately.
7.  Specify the Equipment Needed for the event.
8.  Enter the Project Amount in the desired currency (USD, EUR, or JPY).
9.  Select the Project Status (Active or Pending) and provide the Project Start Time and Project End Time.
10.  Enter the Project Duration.
11.  If you have any additional comments or instructions, enter them in the Project Description field.
12.  Finally, submit the form with the date you submit it.

## Field-by-Field Explanation

*   **Form Title** (1, text, optional): This field is for you to give a title to the project. It will be used for reference and organization.
*   **Client Name** (2, text, optional): Enter the name of the person or organization you are working with.
*   **Client Name and Phone** (8, text, required): Include both the client's name and their phone number for easy contact.
*   **Event Type** (3, select_one, required): Choose the type of event or project you are booking for.
*   **Event Date** (4, date, required): Enter the date of the event.
*   **Event Time** (5, time, required): Select the time of the event.
*   **Event Start Date** (6, date, required): Enter the date the event is expected to start.
*   **Event End Date** (7, date, required): Enter the date the event is expected to end.
*   **Client Email** (10, email, required): Enter the email address of the client for easy communication.
*   **Project Details** (9, text, required): Describe your project requirements here.
*   **Equipment Needed** (15, text, required): Specify the equipment you need for the event.
*   **Project Amount** (18, number, required): Enter the amount you are expecting for the project. Please select the currency from the options provided.
*   **Project Status** (19, select_multiple, required): Choose the current status of the project (Active or Pending).
*   **Project Start Time** (20, time, required): Enter the start time of the project.
*   **Project End Time** (21, time, required): Enter the end time of the project.
*   **Project Duration** (22, number, required): Enter the duration of the project.
*   **Project Amount Currency** (23, select_one, required): Select the currency for the project amount.
*   **Project Description** (24, text, optional): Provide any additional comments or instructions for the project.
*   **Form Submitted** (25, date, required): Enter the date this form was submitted.

Note: The fields marked as required are mandatory and must be filled out to complete the form accurately.
