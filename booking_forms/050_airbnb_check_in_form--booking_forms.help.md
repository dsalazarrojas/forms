# Airbnb Check In Form - Help Guide

## Purpose
The AirBnB Check In Form is a tool for guests to provide information about their arrival and stay. This form helps hosts to track and manage guest's check-in details, including reservation information, check-in process, property condition, and feedback.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the required fields, indicated by a red asterisk (\*) symbol.
2. Enter your Reservation Code, which can be found in your booking confirmation.
3. Enter the name of the property/ID you are staying at.
4. Enter the name of the guest checking in.
5. Choose the actual check-in time.
6. Select the method of key handover (e.g. Smart Lock Code, Lockbox, In-Person Host, Front Desk).
7. Enter the last 4 digits of your ID (Passport or Driver's License).
8. Indicate if you received a welcome guide for the property.
9. Choose the condition of the property on arrival.
10. If necessary, report any damage or issues with the property.
11. If you need the WiFi code, select "True" and enter the code.

## Field-by-Field Explanation
### Reservation Code
* **Reservation Code**: Enter your booking confirmation code to confirm your reservation.
* (Required)

### Property Name / ID
* **Property Name / ID**: Enter the name or ID of the property you are staying at.
* (Required)

### Guest Name
* **Guest Name**: Enter the name of the primary guest checking in.
* (Required)

### Actual Check-In Time
* **Actual Check-In Time**: Select the time you actually arrived at the property.
* (Required)

### Key Handover Method
* **Key Handover Method**: Choose how you received the keys for the property (e.g. Smart Lock Code, Lockbox, In-Person Host, Front Desk).
* (Required)

### ID Verification Number
* **ID Verification Number**: Enter the last 4 digits of your ID (Passport or Driver's License).
* (Required)

### Welcome Guide Received?
* **Welcome Guide Received?**: Indicate if you received a welcome guide for the property.
* (Required)

### Condition on Arrival
* **Condition on Arrival**: Choose the condition of the property on arrival (Perfectly Clean, Satisfactory, Needs Cleaning, Damaged Items Found).
* (Required)

### Report Damage / Issues
* **Report Damage / Issues**: Describe any problems or issues with the property if applicable.
* (Optional)

### Need WiFi Code?
* **Need WiFi Code?**: If you need the WiFi code, select "True" and enter the code.
* (Optional)

### Initial Feedback
* **Initial Feedback**: Share your first impressions of the property.
* (Optional)

Note: The form is divided into two sections: "Reservation Information" and "Check-In Process" and "Property Condition". Please fill in the required fields and provide feedback as needed.
