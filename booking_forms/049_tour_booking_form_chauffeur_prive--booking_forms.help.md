# Tour Booking Form Chauffeur Prive - Help Guide
## Purpose

The Tour Booking Form Chauffeur Prive is used to collect customer information for booking a private tour. It helps the tour company to get the customer's contact details, tour preferences, and payment status.

## How To Complete This Form

1. Fill out each field as prompted, and make sure to complete all required fields.
2. Enter a valid date and time for the booking, taking into account the available tour options.
3. Enter the customer's personal details including name, email, phone number, address, and other relevant information.
4. Select the tour guide and tour price accordingly.
5. Choose a payment status from the available options.
6. Provide any additional customer notes if necessary.

## Field-by-Field Explanation

* **Booking Date** (`booking_date`, date, required): Enter the date when you'd like to book the tour.
* **Start Time** (`start_time`, time, required): Select the start time of the tour.
* **Customer Name** (`customer_name`, text, required): Enter the customer's name.
* **Customer Email** (`customer_email`, email, required): Enter the customer's email address.
* **Customer Phone** (`customer_phone`, text, optional): Enter the customer's phone number.
* **Tour Name** (`tour_name`, text, optional): Enter the tour name (if applicable).
* **Duration** (`duration`, number, required): Select the duration of the tour.
* **Start Date** (`start_date`, date, required): Enter the start date of the tour.
* **End Time** (`start_time_2`, time, optional): Select the end time of the tour (if applicable).
* **Customer Message** (`customer_message`, text, optional): Enter any additional customer message.
* **Tour Guide** (`tour_guide`, text, required): Select the tour guide.
* **Tour Price** (`tour_price`, number, required): Enter the tour price.
* **Booking Fee** (`booking_fee`, number, required): Enter the booking fee.
* **Payment Status** (`payment_status`, select multiple, required):
  Select one or more of:
  • Paid
  • Pending
  • Cancelled
* **Customer Address** (`customer_address`, text, optional): Enter the customer's address.
* **Customer City** (`customer_city`, text, optional): Enter the customer's city.
* **Customer State** (`customer_state`, text, optional): Enter the customer's state.
* **Customer Zip** (`customer_zip`, text, optional): Enter the customer's zip code.
* **Customer Country** (`customer_country`, text, optional): Enter the customer's country.
* **Tour Description** (`tour_description`, text, required): Enter a brief description of the tour.
* **Customer Gender** (`customer_gender`, text, optional): Enter the customer's gender.
* **Customer Birthdate** (`customer_birthdate`, date, optional): Enter the customer's birthdate.
* **Customer Age** (`customer_age`, number, optional): Enter the customer's age.
* **Customer Document** (`customer_document`, text, optional): Enter any customer document.
* **Customer Note** (`customer_note`, note, optional): Enter any additional customer note.
