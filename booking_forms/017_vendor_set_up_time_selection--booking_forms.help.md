# Vendor Set Up Time Selection - Help Guide
## Purpose
This form is designed to collect vendor setup information for event management, conferences, or trade shows.

## How To Complete This Form
Please follow the steps below to fill out the form accurately:
1. Select one or multiple options for "Vendor Set Up Time Selection" (Field 10).
2. Enter the Move-In Start Time and Move-in End Time of the vendor (Fields 2 & 3) for the selected time slot.
3. Check the boxes for "Move-in Details" (Field 6) and provide a brief description in the text box.
4. Select the vendor's "Move-in Details" status (Field 6).
5. Choose the "Estimated Arrival Time" (Field 7) for the selected time slot.
6. Select the "Vendor Set-Up Requirements" and "Additional Vendor Set-Up Requirements" (Fields 8 & 9) for the selected time slot.
7. Enter any "Vendor Contact Info" (Field 11) if necessary.
8. Enter the Event ID and Vendor ID (Fields 12 & 13) if necessary.

## Field-by-Field Explanation
* **Vendor Set Up Time Selection** (Field 10, Select One): Select whether the vendor will have a setup time.
* **Move-In Start Time** (Field 2, Time): Enter the start time of the vendor's move-in.
* **Move-In End Time** (Field 3, Time): Enter the end time of the vendor's move-in.
* **Vendor Setup Details** (Field 4, Select Multiple): Choose additional details to be considered for the vendor's setup (e.g., yes or no).
* **Vendor Setup Location** (Field 5, Select Multiple): Select whether the vendor will set up at the event location (yes or no).
* **Move-in Details** (Field 6, Text): Enter any specific details about the move-in (e.g., parking information).
* **Estimated Arrival Time** (Field 7, Time): Enter the estimated time of the vendor's arrival.
* **Vendor Set-Up Requirements** (Field 8, Select Multiple): Select any requirements that need to be considered for the vendor's setup (e.g., special equipment).
* **Additional Vendor Set-Up Requirements** (Field 9, Select Multiple): Select any additional requirements for the vendor's setup (e.g., power supply).
* **Vendor Contact Info** (Field 11, Text): Enter any contact information for the vendor (e.g., phone number).
* **Event ID** (Field 12, Number): Enter the ID of the event.
* **Vendor ID** (Field 13, Number): Enter the ID of the vendor.
