# escape_room_group_booking_form - Help Guide
## Purpose
The purpose of this form is to collect information for group bookings in an escape room.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the **Group Details** for the booking. This is a free-form text field where you can provide any relevant information about the group.
2. Select a **Preferred Date** for the booking. This is a date field where you can choose a specific date for the escape room experience.
3. If the group has any **Special Requests**, please describe them in the **Group Booking Request** field. This is a text field where you can provide any additional information or requests for the group.
4. Choose the **Group Details** options that apply to the group. This is a selection field where you can choose one or more options.
5. Enter the **Email** of the person making the booking, as well as any additional email addresses for the group members.
6. Provide the **Phone** number of the person making the booking, and any additional phone numbers for the group members.
7. Select a **Preferred Date 2** for the booking. This is a date field where you can choose an alternate date for the escape room experience.

## Field-by-Field Explanation
* **Group Details**: Enter a brief description of the group that is making the booking. This could include their name, purpose of the visit, or any special requests.
* **Preferred Date**: Choose the date that the group would like to book the escape room experience. This is a date field, so you can select a date in the format MM/DD/YYYY.
* **Special Requests 2**: If the group has any special requests, such as "no gluten-free options" or "no smoking", please describe them here.
* **Group Booking Request**: Enter any additional information or requests for the group that are not covered in the previous fields.
* **Group Details 2**: Choose one or more options that apply to the group. These options are not described in the provided YAML, so their purpose and meaning are unknown.
* **Email**: Enter the email address of the person making the booking, as well as any additional email addresses for the group members. This is a required field.
* **Phone**: Enter the phone number of the person making the booking, as well as any additional phone numbers for the group members. This is a text field.
* **Preferred Date 2**: Choose an alternate date for the escape room experience. This is a date field, so you can select a date in the format MM/DD/YYYY.
