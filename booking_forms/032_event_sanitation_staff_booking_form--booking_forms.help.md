# event_sanitation_staff_booking_form - Help Guide
## Purpose
The event_sanitation_staff_booking_form is a form used to book events that require the presence of sanitation staff. This form ensures that staff have all necessary resources and equipment for the event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the event sanitation staff booking form.
2. Fill in the necessary fields with the required information.
3. Ensure all required fields are filled in before submitting the form.
4. Review the form carefully before submitting it to ensure accuracy.

## Field-by-Field Explanation

* **event_sanitation_staff_booking_form**: This is the title of the form. It is not a field that requires completion.
* **dates**: Enter the date(s) of the event. This is a date field where you can enter one or multiple dates.
* **locations**: Enter the location(s) where the event will take place. This is a text field for entering addresses or other relevant details.
* **staff_needed**: Specify the number of staff members needed for the event. This is a numerical field for entering the amount of staff required.
* **service_details**: Provide any additional information about the services required for the event. This is a text field for entering specific details about the services needed.
* **notes**: Add any additional notes or comments about the event. This is a text field for entering any extra information that might be relevant.
* **event_name**: Enter a name for the event, if applicable. This is a text field for entering a specific name of the event.
* **event_date**: Enter the date of the event. This is a date field for entering a single date.
* **event_time**: Enter the time of the event. This is a time field for entering a specific time.
* **event_venue**: Enter the venue or location of the event. This is a text field for entering the specific location where the event will take place.

## Tips

* Ensure that you are booking the correct type of form for your event.
* Double-check the fields for accuracy before submitting the form.
* Be as detailed as possible when filling in the fields to ensure the staff are properly prepared for the event.
