# Sound Mixing Masterclass Booking Form - Help Guide
## Purpose
The Sound Mixing Masterclass Booking Form is a tool for users to book a spot for a Sound Mixing Masterclass event.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired attendee type (Student, Teacher, or Both)
2. Enter your name as you would like to be listed for the event
3. Provide a valid email address
4. Enter your phone number
5. Enter your address
6. Select the event date (if available)
7. Select the event time (if available)
8. Enter the event duration (if required)

## Field-by-Field Explanation
* **Attendee Type** (`attendee_type`, select_multiple, required): Choose the type of attendee you are booking for (Student, Teacher, or Both).
* **Attendee Name** (`attendee_name`, text, required): Enter your name as you would like to be listed for the event.
* **Email** (`email`, email, required): Enter a valid email address.
* **Phone Number** (`phone_number`, text, required): Enter your phone number.
* **Address** (`address`, text, required): Enter your physical address.
* **Event Date** (`event_date`, date, required): Select the date of the event (if available).
* **Event Time** (`event_time`, time, required): Select the event time (if available).
* **Event Duration** (`event_duration`, number, required): Enter the expected duration of the event.

## Tips
* Ensure you've checked the event schedule to confirm the correct event date and time.
* If you're unsure about any of the fields, please contact the event organizer for assistance.
* If you've already submitted a booking for this event, please do not resubmit.
