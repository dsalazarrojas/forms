# Amusement Park Event Space Rental Application - Help Guide
## Purpose
The Amusement Park Event Space Rental Application form is used to request event space rental at the park. This form collects information necessary for event planning, including event details, client contact information, payment and deposit policies, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Event Information section with the requested details.
2. Provide contact information in the Client Information section.
3. Select the preferred event type and date in the Event Details section.
4. Choose the preferred event venue and backup venue in the Venue Selection section.
5. Determine if catering services are needed and select the preferred meal type in the Catering Services section.
6. Select any additional services required in the Additional Services section.
7. Provide budget and deposit information in the Budget and Payment Information sections.
8. Review and acknowledge the park's policies and agreements in the Policies and Agreements section.
9. Add any additional comments or special requests in the Additional Information section.
10. Sign and date the form to complete the application.

## Field-by-Field Explanation
* **Event Name**: Enter the name of the event.
* **Event Type**: Select the type of event (e.g., Corporate event, Private party, Birthday celebration, etc.).
* **First Name**: Enter the first name of the contact person.
* **Last Name**: Enter the last name of the contact person.
* **Company/Organization Name**: Enter the name of the company or organization (if applicable).
* **Email Address**: Enter the email address of the contact person.
* **Phone Number**: Enter the phone number of the contact person.
* **Address**: Enter the full address of the contact person (if different from the billing address).
* **Requested Event Date**: Select the date of the event.
* **Alternative Dates**: Enter any alternative dates if the first choice is unavailable.
* **Event Start Time**: Enter the start time of the event.
* **Event End Time**: Enter the end time of the event.
* **Setup Time Needed**: Select the amount of setup time needed before the event.
* **Expected Guests**: Enter the expected number of guests.
* **Preferred Venue**: Select the preferred event venue (e.g., Indoor pavilion, Outdoor garden, etc.).
* **Backup Venue**: Select the backup event venue (in case of weather, etc.).
* **Catering Needed**: Select if catering services are needed.
* **Meal Type**: Select all the types of meal that are needed (e.g., Breakfast, Lunch, Dinner, etc.).
* **Menu Preferences**: Enter any specific menu preferences.
* **Dietary Requirements**: Enter any dietary requirements (e.g., vegetarian, allergies, etc.).
* **Park Access for Guests**: Select if park access is included for guests.
* **Entertainment Requests**: Select any entertainment requests (e.g., live music, DJ, etc.).
* **AV Equipment Needed**: Select any audio-visual equipment needed (e.g., microphone, speakers, etc.).
* **Decoration Package**: Select the decoration package (e.g., Basic, Standard, etc.).
* **Theme**: Enter any event theme (if applicable).
* **Color Scheme**: Enter any color scheme preferences.
* **Additional Services**: Select any additional services required (e.g., security, valet parking, etc.).
* **Budget Range**: Select the budget range for the event.
* **Deposit Ready**: Select if ready to pay a deposit.
* **Preferred Payment Method**: Select the preferred payment method.
* **Billing Address**: Enter the billing address (if different from the contact address).
* **Cancellation Policy Acknowledgment**: Acknowledge the cancellation policy.
* **Deposit Policy Acknowledgment**: Acknowledge the deposit policy.
* **Weather Policy Acknowledgment**: Acknowledge the weather policy (if applicable).
* **Special Requests**: Enter any special requests.
* **Additional Comments**: Enter any additional comments.
* **How Did You Hear About Us**: Select how you heard about the park.
* **Authorization**: Leave this field blank.
* **Applicant Signature**: Sign your name as the applicant.
* **Date of Signature**: Enter the date of signature.
* **Application Status**: This field will be filled out by park staff.
* **Assigned Event Coordinator**: This field will be filled out by park staff.
