# Pottery Session Reservation Form - Help Guide
## Purpose
This form is designed to collect information for booking pottery sessions. It allows users to enter details such as student names, contact information, and session preferences. This form is required for booking purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the start and end times for your session in the "Start Time" and "End Time" fields, respectively.
2. Enter the student's name in the "Student Name" field.
3. Enter the student's contact email in the "Email" field.
4. Check the "Student Classes" options to indicate if the student is attending or not. This field is optional.
5. Select the preferred "Pottery Session" and "Session Type" options from the drop-down menus.
6. If the student is not attending, enter 0 as the "Student Quantity" field.
7. Leave any additional notes for the session in the "Notes" field.
8. Click the "Submit" button to complete and submit the form.

## Field-by-Field Explanation
* **Start Time** (`start-time`, time, required/optional): Enter the start time of your session.
* **End Time** (`end-time`, time, required/optional): Enter the end time of your session.
* **Student Name** (`Student Name`, text, required/optional): Enter the student's name.
* **Student Name** (`Student Name`, text, required/optional): This is a duplicate field. Please provide a different name for this field.
* **Email** (`Email`, email, required/optional): Enter the student's contact email.
* **Phone** (`Phone`, text, required/optional): Enter the student's contact phone number.
* **Student Classes** (`Student Classes`, select_multiple, required/optional): Check the options to indicate if the student is attending or not.
* **Pottery Session** (`Pottery Session`, select_one, required): Select the preferred "Pottery Session" option.
* **Instructor** (`Instructor`, text, required/optional): Leave this field blank if not applicable.
* **Date** (`Date`, date, required/optional): Enter the date of your session.
* **Session Type** (`Session Type`, select_one, required): Select the preferred "Session Type" option.
* **Student Quantity** (`Student Quantity`, number, required/optional): Enter the number of students attending the session, if any.
* **Notes** (`Notes`, note, required/optional): Add any additional notes for the session.
* **Student Quantity** (`Student Quantity`, number, required/optional): Another duplicate field. Please provide a different quantity for the session.
