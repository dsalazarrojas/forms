# Property Reservation Request Form - Help Guide
## Purpose
This form is designed to collect information from users to request a property reservation. The form is intended for users to provide their property details, address, and other relevant information for the reservation.

## How To Complete This Form
1. Review the form carefully before submitting to ensure you are providing all required and optional information.
2. Fill in each field with the requested information:
	* Property Details: A description of the property you are interested in.
	* Address: The address of the property.
	* Property Type: Select the type of property you are interested in.
	* Number of Guests: Enter the number of guests who will be staying.
	* Stay Start Date: Enter the start date of your stay.
	* Stay End Date: Enter the end date of your stay.
	* Property Manager Email: Enter the email address of the property manager.
	* Property Manager Phone: Enter the phone number of the property manager.
	* Property Manager Name: Enter the name of the property manager.
	* Property Reservation Request Message: Enter any special requests or messages for the property manager.
	* Stay Duration: Enter the duration of your stay.
	* Reservation Start Date: Enter the start date of your reservation.
	* Reservation End Date: Enter the end date of your reservation.
	* Property Status: Select the status of the property.
	* Payment Method: Select the payment method you will use.
	* Goals: Enter any goals or purposes for your stay.
	* Stay Duration: Enter the duration of your stay.

## Field-by-Field Explanation
- **Property Details**: A brief description of the property you are interested in.
- **Address**: The address of the property.
- **Property Type**: Select the type of property (e.g., apartment, house, etc.).
- **Number of Guests**: The number of guests who will be staying.
- **Stay Start Date**: The start date of your stay.
- **Stay End Date**: The end date of your stay.
- **Property Manager Email**: The email address of the property manager.
- **Property Manager Phone**: The phone number of the property manager.
- **Property Manager Name**: The name of the property manager.
- **Property Reservation Request Message**: A special message for the property manager.
- **Stay Duration**: The duration of your stay.
- **Reservation Start Date**: The start date of your reservation.
- **Reservation End Date**: The end date of your reservation.
- **Property Status**: Select the status of the property (e.g., Active, Inactive).
- **Payment Method**: Select the payment method you will use.
- **Goals**: Enter any goals or purposes for your stay.
- **Stay Duration**: The duration of your stay.
