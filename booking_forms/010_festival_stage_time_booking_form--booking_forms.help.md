# Festival Stage Time Booking Form - Help Guide
## Purpose
The Festival Stage Time Booking Form is designed to collect and manage bookings for festival stages.

## How To Complete This Form
### Steps for Completing the Form

1. Select a date for the booking.
2. Enter the start and end times for the event.
3. Choose the stage to be booked from the available options.
4. Enter the event name and description.
5. Provide any additional event details if necessary.

## Field-by-Field Explanation

*   **booking_date**: Select a date for the booking.
*   **start_time**: Enter the start time for the event.
*   **end_time**: Enter the end time for the event.
*   **stage_id**: Choose the stage to be booked from the available options.
*   **event_name**: Enter a brief name for the event.
*   **event_description**: Enter a brief description of the event.
*   **event_details**: Provide any additional event details if necessary.

## Tips
*   Please ensure that the date and time are accurate to avoid conflicts with other bookings.
*   Choose a stage that is available and suitable for the event.
*   Enter a clear and concise event name and description.
*   Add any relevant details to provide a complete event summary.
