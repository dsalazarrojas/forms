# LED Screen Setup Booking Form - Help Guide
## Purpose
This form is used to book a LED screen installation for an event. It guides the user through the necessary details required to complete the booking process.

## How To Complete This Form
To complete this form, please fill out the required fields with the relevant information. Ensure that you have all the necessary information before submitting the form.

## Field-by-Field Explanation
- **Event Details** (`event_details`): Enter a brief description of the event, including the event name, date, and any other relevant details.
- **Event Date** (`event_date`): Enter the date of the event.
- **Event Time** (`event_time`): Enter the time of the event.
- **Event Location** (`event_location`): Enter the location of the event.
- **Client Name** (`client_name`): Enter the name of the client or organization booking the event.
- **Event Duration** (`event_duration`): Enter the duration of the event.
- **Number of Screens** (`number_of_screen`): Enter the number of screens required for the installation.
- **Screen Size** (`screen_size`): Enter the size of each screen.
- **Installation Date** (`installation_date`): Enter the date of the installation.
- **Installation Time** (`installation_time`): Enter the time of the installation.
- **Installation Location** (`installation_location`): Enter the location of the installation.
- **Notes** (`notes`): Add any additional notes or comments about the installation.
- **Email** (`email`): Enter your email address for contact purposes.
- **Phone** (`phone`): Enter your phone number for contact purposes.
- **Contact** (`contact`): Select the type of contact person responsible for the event.
- **Client** (`client`): Confirm if the client is confirmed for the event.
- **Screen Layout** (`screen_layout`): Select the screen layout for the installation (Horizontal, Vertical, Split, or Double Screen).
- **Screen Type** (`screen_type`): Select the screen type for the installation (2K, 4K, LED Wall, or LED Curtain).
- **Installation Details** (`installation_details`): Add any additional details about the installation.
- **Client Requirements** (`client_requirements`): Enter any requirements or requests from the client.
- **Installation Instructions** (`installation_instructions`): Add any specific instructions for the installation.
- **Screen Technical Requirements** (`screen_technical_requirements`): Enter any technical requirements for the screens.
- **Payment Method** (`payment_method`): Select the method of payment for the installation (Cheque, Bank Transfer, or Credit Card).
- **Payment Details** (`payment_details`): Enter any additional payment details.
- **Cancellation Policy** (`cancellation_policy`): Select the policy for cancellations (Flexible, Strict, or None).
- **Screen Setup Booking Form** (`screen_booking_form`): Enter any additional details about the installation.
