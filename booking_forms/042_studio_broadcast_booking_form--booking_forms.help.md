## Studio Broadcast Booking Form - Help Guide
## Purpose
The Studio Broadcast Booking Form is a tool used for booking and scheduling studio time slots for events. Please ensure that you have the correct information and approvals in place before submitting this form. To avoid delays, please review this form carefully before submitting.

## How To Complete This Form
- Fill out the form completely and accurately with all the required fields.
- Review your submission for errors before submitting.
- Make sure to submit your form before the requested broadcast date.

## Field-by-Field Explanation
- **Booking Form** (`1`, `text`, required: `false`): Enter the name of the event or project you're booking studio time for.
  - This field is for a general description of the event or project.
  - Enter a brief and concise title that summarizes the event or project.
- **Booking Dates** (`2`, `number`, required: `false`): Select a date for the event or project.
  - This field is for selecting a date for the event or project.
  - You can select one or multiple dates, but please ensure they are accurate and within the requested broadcast date range.
- **Start Time** (`3`, `time`, required: `false`): Enter the start time of the event or project.
  - This field is for entering the start time of the event or project.
  - Format is HH:MM, 24-hour time format.
- **End Time** (`4`, `time`, required: `false`): Enter the end time of the event or project.
  - This field is for entering the end time of the event or project.
  - Format is HH:MM, 24-hour time format.
- **Broadcast Date** (`5`, `date`, required: `false`): Select a date for the event or project.
  - This field is for selecting a date for the event or project.
  - You can select one or multiple dates, but please ensure they are accurate and within the requested broadcast date range.
- **Broadcast Time** (`6`, `time`, required: `false`): Enter the time for the event or project.
  - This field is for entering the time of the event or project.
  - Format is 24-hour time format.
- **Broadcast Duration** (`7`, `number`, required: `false`): Enter the duration of the event or project in minutes.
  - This field is for entering the duration of the event or project.
  - Please ensure that it's within the allowed time slots.
- **Broadcast Type** (`8`, `select_one`, required: `false`): Select the type of broadcast.
  - This field is for selecting the type of broadcast.
  - Options are: Broadcasting, Live, Pre-recorded.
- **Broadcast Details** (`9`, `text`, required: `false`): Enter any additional details about the event or project.
  - This field is for entering any additional details about the event or project.
  - Enter as much information as necessary for our team to prepare for the event. 

## Tips
- Please ensure that all fields are completed accurately and correctly before submitting.
- If you have any questions or concerns, please contact our team directly.
- Review this guide before submitting your form to ensure you have all the necessary information. 

Note: The fields are numbered based on the "id" field in the input schema.
