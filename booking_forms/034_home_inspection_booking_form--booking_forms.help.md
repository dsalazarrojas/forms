# Home Inspection Booking Form - Help Guide
## Purpose
The Home Inspection Booking Form is used to collect information from the user for a home inspection. This form is meant to be filled out by individuals or entities requesting an inspection of a specific property.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the "User Details" field with your name and contact information.
2. Select a preferred date for the inspection in the "Preferred Date" field.
3. Provide your "Contact Info" in the "Contact Info" field.
4. Enter the "Inspection Details" in the "Inspection Details" field.
5. (Optional) Select "Yes" or "No" in the "Select Option" field.
6. (Optional) Select "Yes" or "No" in the "Another Select Option" field.
7. Enter your email address in the "Email" field.
8. Enter your phone number in the "Phone" field.
9. (Optional) Enter a note in the "Note" field.
10. Enter the "Home Address" of the property to be inspected.

## Field-by-Field Explanation
### User Details
* **User Details (text)**: Please enter your name and any additional contact information you'd like to provide.
### Preferred Date
* **Preferred Date (date)**: Select the date on which you would like the inspection to be conducted. Please note that the inspection will be scheduled on the selected date if possible.
### Contact Info
* **Contact Info (text)**: Provide your contact information so we can get in touch with you.
### Inspection Details
* **Inspection Details (text)**: Enter any additional information about the property you would like the inspector to be aware of.
### Notes
* **Notes (text)**: (Optional) Enter any additional notes or comments for the inspector.
### Select Option
* **Select Option (select_multiple)**: Select "Yes" if you have specific requirements or requests for the inspection, or "No" if you don't have any specific requirements.
### Another Select Option
* **Another Select Option (select_multiple)**: Select "Yes" if you have specific requirements or requests for the inspection, or "No" if you don't have any specific requirements.
### Email
* **Email (email)**: Enter your email address so we can get in touch with you.
### Phone
* **Phone (text)**: Enter your phone number so we can contact you.
### Note
* **Note (note)**: This is a space to enter any additional information or comments.
### Home Address
* **Home Address (text)**: Enter the address of the property you would like to be inspected.
### Select Option
* **Select Option (select_multiple)**: Select "Yes" if you have specific requirements or requests for the inspection, or "No" if you don't have any specific requirements.
