# dj_service_renewal_form - Help Guide
## Purpose
This form is used to renew a service contract or agreement. It captures relevant information to update the existing contract and ensures that the renewal process is completed accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer all questions truthfully and accurately.
2. Select the correct options for each field as instructed.
3. Make sure to fill out all required fields marked as "required".

## Field-by-Field Explanation
- **Contact Info** (select_multiple, required: false): This field is used to select whether the contact information for the service should be updated or not. You can choose 'Yes' if you need to update the contact information or 'No' if it remains the same.
- **Client Info** (text, required: true): In this field, please provide the updated client information. This could include changes to the client's name, address, or any other relevant details.
- **Services Offered** (select_one, required: true): This field allows you to select whether services will be offered or not. Please choose 'Yes' if services will be provided and 'No' if they will not.
- **Contract Info** (note, required: false): If there are any changes to the contract terms or conditions, please include them in this field for reference.
- **Additional Comments** (text, required: false): You can add any additional comments or notes about the service renewal here. This could include any specific details or instructions related to the renewal process.
- **Payment Terms** (number, required: true): This field is used to capture the payment terms of the service renewal, including any updates or changes.
- **Cancellation Policies** (text, required: true): Please provide any cancellation policies or procedures that apply to the service renewal.
- **Contract Start Date** (date, required: true): Enter the date when the service contract will start again.
- **Contract End Date** (date, required: true): Enter the date when the service contract will end.
- **Assigned Tool** (select_one, required: true): In this field, select the tool assigned to the service. You can choose between 'chatjim' and 'chatbot'.
- **Form ID** (number, required: false): This field is used for internal purposes and can be filled out for reference only.

Note: Make sure to review the form carefully and complete all required fields for a smooth and accurate service renewal process.
