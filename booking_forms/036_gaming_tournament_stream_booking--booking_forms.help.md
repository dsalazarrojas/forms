# Gaming Tournaments Stream Booking - Help Guide
## Purpose
The purpose of this form is to collect and manage booking information for gaming tournaments streams. It is used by administrators to record and track event and stream details, as well as the status and history of bookings.

## How To Complete This Form

To complete this form, follow these steps:

1. Start by providing an introduction to the event, if necessary.
2. Fill in the event information, including the title, description, date, and start time.
3. Choose the stream type (e.g., Gaming PC, Console, etc.).
4. Enter the stream title, description, and URL.
5. Select the stream slot (e.g., Slot 1, Slot 2, etc.).
6. Choose the booking status (e.g., Pending, Confirmed).
7. Enter the contact information for the stream requestor and booker.
8. Set the booking date.
9. Optionally, enter any additional notes about the booking.

## Field-by-Field Explanation

* **Introduction (Note)**: A brief introduction to the event, if desired.
* **Event Information (Text)**: A required field for event details, including the title and description.
* **Event Title (Text)**: The title of the event.
* **Event Description (Text)**: A description of the event.
* **Event Date (Date)**: The date of the event.
* **Event Start Time (Time)**: The start time of the event.
* **Event Duration (Number)**: The duration of the event.
* **Stream Title (Text)**: The title of the stream.
* **Stream Description (Text)**: A description of the stream.
* **Stream Type (Select Multiple)**: Choose the type of stream (e.g., Gaming PC, Console, etc.).
* **Stream URL (Text)**: The URL of the stream.
* **Stream Tags (Text)**: Any relevant tags for the stream.
* **Team Name (Text)**: The name of the team.
* **Team Logo (Text)**: The logo of the team.
* **Team Website (Text)**: The website of the team.
* **Contact Email (Email)**: The email of the contact person.
* **Contact Phone (Text)**: The phone number of the contact person.
* **Contact Note (Text)**: Any additional notes about the contact person.
* **Stream Slot (Select Multiple)**: Choose the time slot for the stream.
* **Booking Status (Select Multiple)**: Choose the status of the booking (e.g., Pending, Confirmed).
* **Stream Requester (Text)**: The name of the person requesting the stream.
* **Stream Booker (Text)**: The name of the person booking the stream.
* **Booking Date (Date)**: The date the stream was booked.
* **Booked By (Text)**: The person who booked the stream.
* **Notes (Text)**: Any additional notes about the booking.
