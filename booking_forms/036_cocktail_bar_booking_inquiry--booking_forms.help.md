# Cocktail Bar Booking Inquiry - Help Guide
## Purpose
This form is designed to help us understand your event needs so we can provide the best possible service.

## How To Complete This Form
1. Fill out your contact information: Enter your name, email address, and phone number so we can get in touch with you.
2. Provide event details: Select the type of event (e.g., corporate event, wedding, etc.), date, start time, and end time.
3. Specify event location: Enter the location or venue where the event will take place.
4. Share guest information: Tell us about the expected number of guests.
5. Choose services: Select the type of service you're interested in (e.g., full bar service, limited bar service, etc.).
6. Make special requests: If you have any specific requests (e.g., special drinks, themes, etc.).
7. Share dietary restrictions: If there are any dietary restrictions or considerations for your guests.
8. Choose setup and equipment: Select how you'll need our setup and equipment services.
9. Share budget information: If you're able to share your budget range, it will help us better plan and prepare.
