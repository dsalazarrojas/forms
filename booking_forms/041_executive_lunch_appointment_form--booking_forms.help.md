# Executive Lunch Appointment Form - Help Guide
## Purpose
The Executive Lunch Appointment Form is used for executives to request lunch meetings with other executives.

## How To Complete This Form
To complete the form, follow these steps:

1.  Fill in your executive lunch request details, including the venue and schedule.
2.  Select the attendees for the lunch meeting.
3.  Enter any additional comments or notes regarding the meeting.

## Field-by-Field Explanation

*   **Executive Lunch Request** (id: 1, name: executive_lunch_request, type: text, required: false): 
    This field is used to enter the reason for the executive lunch request.
*   **Venue** (id: 2, name: venue, label: Venue, type: select_one, options: office, restaurant, hotel, required: false): 
    Select the location for the executive lunch meeting. Options are office, restaurant, or hotel.
*   **Schedule** (id: 3, name: schedule, label: Schedule, type: date, required: false): 
    This field is used to select the date for the lunch meeting. Please use the standard date format.
*   **Executive Lunch Details** (id: 4, name: executive_lunch_details, label: Executive Lunch Details, type: text, required: false):
