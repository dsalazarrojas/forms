# Time Slot Booking Form - Help Guide
## Purpose

This form is used for booking or scheduling time slots for events or meetings. You can select from multiple time slots, specify the number of guests, and provide contact information.

## How To Complete This Form

1. Select the time slot for your event or meeting by choosing from the options in the "Select Time Slot" field.
2. Enter the number of guests that will be attending the event or meeting.
3. Enter your contact email address.
4. Optionally, add a note or message about the event or meeting.
5. Select the start and end dates and times for your event or meeting.
6. Enter the duration of the event or meeting.
7. Choose whether you want to book additional time slots.
8. Select any specific options or settings for your booking, such as booking type, start and end hour, repeat, and time zone.

## Field-by-Field Explanation
- **Select Time Slot** (`select_time_slot`, select_one, required): Select the time slot for your event or meeting from the available options.
- **Number of Guests** (`number_of_guests`, number, required): Enter the number of guests that will be attending the event or meeting.
- **Contact Email** (`contact_email`, email, required): Enter your contact email address.
- **Note** (`note`, note, required): Add a note or message about the event or meeting (optional).
- **Start Date** (`start_date`, date, required): Select the start date for your event or meeting.
- **Start Time** (`start_time`, time, required): Select the start time for your event or meeting.
- **End Date** (`end_date`, date, required): Select the end date for your event or meeting.
- **End Time** (`end_time`, time, required): Select the end time for your event or meeting.

- **Start Hour** (`start_hour`, select_one, required): Choose whether you want to start the event or meeting on the hour.
- **End Hour** (`end_hour`, select_one, required): Choose whether you want to end the event or meeting on the hour.

## Tips

- Make sure to select the correct time slot for your event or meeting.
- Enter the correct number of guests and contact information.
