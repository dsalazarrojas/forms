# Animation Editing Workstation Booking Form - Help Guide
## Purpose
This form is used to book a workstation for animation editing purposes. It gathers information about the user, their project, and the workstation requirements to ensure efficient resource allocation.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your Full Name, Email Address, and Phone Number in the corresponding fields.
2. Select the Workstation you need from the available options.
3. Choose the Required Workstation Specifications (if any) you need for your project.
4. Select the Booking Date and Start and End Time for your project.
5. Specify the Purpose of your booking (e.g., Color Correction, Visual Effects Work, etc.).
6. Briefly describe your project in the Project Description field.
7. If necessary, select any Specific Software Required and File Format Requirements for your project.
8. Mention any Additional Equipment Needed for your project.
9. Indicate the Number of People Using the Workstation and the Required Access Level.
10. Specify if this is a Recurring Booking (e.g., weekly, bi-weekly, etc.).
11. Add any Special Notes or Comments about your project.

## Field-by-Field Explanation

* **Full Name**: Your full name as it appears on your ID or business card.
* **Email Address**: Your email address for booking confirmation and updates.
* **Phone Number**: Your contact number for any additional information or questions.
* **Employee ID or Department**: Your ID or department name (if applicable).
* **Select Workstation**: Choose the workstation you need from the available options (e.g., Color Suite, VFX Station, etc.).
* **Required Workstation Specifications**: Select any specific technical requirements for your project (e.g., High-Resolution Monitor, Color-Calibrated Display, etc.).
* **Booking Date**: Select the date you need the workstation for your project.
* **Start Time**: Specify the time you need to begin your project.
* **End Time**: Specify the time you expect to finish your project.
* **Purpose of Booking**: Choose the purpose of your booking (e.g., Color Correction, Visual Effects Work, etc.).
* **Project Description**: Briefly describe your project in this field.
* **Specific Software Required**: Select any specific software needed for your project (e.g., Adobe Premiere, Avid Media Composer, etc.).
* **File Format Requirements**: Select the file formats you will be working with (e.g., ProRes, DNxHD, H.264, etc.).
* **Additional Equipment Needed**: Mention any special equipment or peripherals needed for your project.
* **Number of People Using Workstation**: Indicate how many people will be using the workstation for your project.
* **Required Access Level**: Choose the required access level for your project (e.g., Full Access, Read-Only Access, etc.).
* **Recurring Booking**: Specify if this is a recurring booking (e.g., weekly, bi-weekly, etc.).
* **Special Notes or Comments**: Add any additional information or comments about your project.

By following this guide, you should be able to complete the form accurately and effectively book the necessary workstation for your animation editing project.
