# speed_meeting_booking_form - Help Guide
## Purpose
The speed_meeting_booking_form is a form designed to collect details about a speed meeting event, including the type of event, date, start and end times, event location, and contact information for attendees.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the event type from the options provided in the "event_type" field.
2. Enter the date of the event (in YYYY-MM-DD format) in the "event_date" field.
3. Choose the start time of the event in the "start_time" field.
4. Choose the end time of the event in the "end_time" field.
5. Enter the duration of the event in the "event_duration" field.
6. Enter the location of the event in the "event_location" field.
7. Select whether attendees will be present ("Yes") or not ("No") in the "attendees" field.
8. Enter the email of the attendee(s) in the "attendee_email" field.
9. Enter the phone number of the attendee(s) in the "attendee_phone" field.
10. (Optional) Add any additional notes about the event or attendee in the "event_notes" field.

## Field-by-Field Explanation

* **speed_meeting_booking_form**: (Page 1, Speed Meeting Booking Form) The main form title.
* **event_type**: (Page 1, Select one of the provided options) Choose the type of event you are booking.
* **event_date**: (Page 1, Event Date, YYYY-MM-DD) Enter the date of the event.
* **start_time**: (Page 1, Start Time) Choose the start time of the event.
* **end_time**: (Page 1, End Time) Choose the end time of the event.
* **event_duration**: (Page 1, Event Duration) Enter the duration of the event.
* **event_location**: (Page 1, Event Location) Enter the location of the event.
* **attendees**: (Page 1, Select Yes or No) Select whether attendees will be present at the event.
* **attendee_email**: (Page 1, Attendee Email) Enter the email of the attendee(s).
* **attendee_phone**: (Page 1, Attendee Phone) Enter the phone number of the attendee(s).
* **attendee_notes**: (Page 1, Optional, Attendee Notes) Add any additional notes about the attendee. 
* **event_notes**: (Page 1, Optional, Event Notes) Add any additional notes about the event.
