# media_interview_segment_booking_form - Help Guide
## Purpose
This form is designed for users to book a media interview segment with a guest. Please ensure that you only use this form when you have been explicitly invited to book a media interview segment.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in the Guest name field with the name of the guest you would like to book a media interview segment with.
2. Enter the contact email of the guest in the Contact Email field.
3. Enter the contact phone number of the guest in the Contact Phone field.
4. Specify the topic you would like to discuss with the guest in the Topic field.
5. Select a preferred time slot for the interview in the Preferred Time Slot field.
6. Provide any additional host details in the Host Details field.
7. Select the tool that has been assigned to you from the Assigned Tool dropdown menu.
8. Indicate whether you have selected a tool for the interview by selecting "Yes" or "No" in the Selected Tool field.

## Field-by-Field Explanation
- **Guest Name** (`guest_name`, text, optional): Enter the name of the guest you would like to book a media interview segment with.
- **Contact Email** (`contact_email`, email, optional): Enter the email address of the guest you would like to book a media interview segment with.
- **Contact Phone** (`contact_phone`, text, optional): Enter the contact phone number of the guest you would like to book a media interview segment with.
- **Topic** (`topic`, text, optional): Specify the topic you would like to discuss with the guest.
- **Preferred Time Slot** (`preferred_time_slot`, date, optional): Select a preferred time slot for the interview.
- **Host Details** (`host_details`, text, optional): Provide any additional details about the host or the interview.
- **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool that has been assigned to you from the dropdown menu.
- **Selected Tool** (`selected_tool`, select_one, required): Indicate whether you have selected a tool for the interview by selecting "Yes" or "No".
