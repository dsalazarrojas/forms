# nick_baldwin_booking_form - Help Guide
## Purpose
This form is for booking artists or performers for events. It collects information about the artist's availability and preferences to schedule an event or meeting.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Artist Information section with your name, email, and any other relevant details.
2. In the Request section, provide a clear and concise description of your event or meeting request.
3. Select the type of event you are requesting (e.g., guest speaker, musical performance, or panel discussion).
4. Enter the desired date and time for the event.
5. Provide any additional notes or information about your event or meeting.
6. Select the contact method(s) you prefer (e.g., phone, email, or text).
7. Review and submit the form once you have filled in all required fields.

## Field-by-Field Explanation
- **Artist Information (1)**: Enter your name and any other relevant details about yourself.
  - Type: text
  - Required: false
- **Request (2)**: Provide a clear and concise description of your event or meeting request.
  - Type: text
  - Required: true
- **Event Type (3)**: Select the type of event you are requesting (e.g., guest speaker, musical performance, or panel discussion).
  - Type: select_one
  - Required: true
- **Date (4)**: Enter the desired date for the event.
  - Type: date
  - Required: true
- **Time (5)**: Enter the desired time for the event.
  - Type: time
  - Required: true
- **Note (6)**: Provide any additional information about your event or meeting.
  - Type: text
  - Required: false
- **Contact Method (7)**: Select the contact method(s) you prefer (e.g., phone, email, or text).
  - Type: select_multiple
  - Required: true
- **Submit (8)**: Once you have filled in all required fields, review and submit the form to finalize your booking request.
  - Type: text
  - Required: true
