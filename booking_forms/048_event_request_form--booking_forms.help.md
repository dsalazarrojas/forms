# event_request_form - Help Guide
## Purpose
The event request form is used to create a new event request, which is a crucial process for the organization's event management system. It allows users to input details about the event, including event type, date, time, venue, and other relevant information. This form is designed to guide users through the process of submitting a complete and accurate event request.

## How To Complete This Form
To complete this form, follow these steps:

1. Start by filling out the event request form, which is divided into multiple pages.
2. On the first page, fill out the event request details, including the event title, type, description, date, time, and venue.
3. On subsequent pages, provide additional information as required.
4. Review all fields carefully before submitting the form to ensure accuracy and completeness.
5. Click the "Submit" button to send the form to the event management system.

## Field-by-Field Explanation
### event_request_form_1 (Page 1)
* **event_request**: This field is used to enter a brief title summarizing the event request. (text, required/optional)

### event_type (Page 1)
* **Event Type**: Select "Yes" to indicate that this is an event request. (select_one, required/optional)

### event_description (Page 1)
* **Event Description**: Provide a detailed description of the event, including its purpose and objectives. (text, required/optional)

### date (Page 1)
* **Date**: Enter the date of the event. (date, required/optional)

### time (Page 1)
* **Time**: Enter the time of the event. (time, required/optional)

### venue (Page 2)
* **Venue**: Enter the location of the event. (text, required/optional)

### event_status (Page 2)
* **Event Status**: Select "Active" to indicate that this is an active event request. (select_one, required/optional)

### event_organizer (Page 2)
* **Event Organizer**: Enter the name of the person or organization responsible for organizing the event. (text, required/optional)

### event_location (Page 2)
* **Event Location**: Enter the location of the event. (text, required/optional)

Note: Ensure that you've read and understood the form's purpose and instructions before proceeding. If you have any questions or need further clarification, please contact the event management team.
