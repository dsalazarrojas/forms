# Warehouse Space Booking Form - Help Guide
## Purpose
This form is designed to help authorized users book a specific warehouse space for a specific period.

## Field-by-Field Explanation

* **Date**: Select the date you want to book the space for. This is a required field.
* **Start Time**: Enter the time you want to start using the space. This is a required field.
* **End Time**: Enter the time you want to end using the space. This is a required field.
* **Space ID**: Choose the ID of the space you want to book. This is a required field.
* **Room ID**: Select the ID of the room where the space is located. This is a required field.
* **Room Number**: Enter the room number where the space is located. This is a required field.
* **Floor**: Choose the floor of the room where the space is located. This is a required field.
* **Space Name**: Select the name of the space you want to book. This is a required field.
* **Description**: Enter a brief description of your booking reason. This is a required field.
* **Capacity**: Enter the number of people or units the space can accommodate. This is a required field.
* **Space Type**: Choose the type of space (Warehouse, Office, or Storage). This is a required field.
* **Space Status**: Choose the status of the space (Available, Reserved, or Booked). This is a required field.
* **Booked By**: Enter the name of the person booking the space. This is a required field.
* **Booking Start Date**: Select the start date of the booking. This is a required field.
* **Booking End Date**: Select the end date of the booking. This is a required field.
* **Booking Start Time**: Enter the start time of the booking. This is a required field.
* **Booking End Time**: Enter the end time of the booking. This is a required field.
* **User ID**: Enter the ID of the user booking the space. This is a required field.
* **User Name**: Enter the name of the user booking the space. This is a required field.
* **User Email**: Enter the email of the user booking the space. This is a required field.
