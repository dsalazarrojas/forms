# Entertainment Booking Form - Help Guide
## Purpose
This guide is to help users understand the purpose and process of filling out the Entertainment Booking Form.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the **artist_name** field with the name of the performing artist or band.
2. Enter the **event_date** in the format YYYY-MM-DD.
3. Select a suitable time slot for the **start_time** and **end_time** fields.
4. Enter the **venue** where the event will take place.
5. Specify the **booking_manager** who is responsible for handling the booking.
6. Choose the **event_type** from the options provided (e.g., Event Type 1, Event Type 2, Event Type 3).
7. Enter the **artist_fee** as a numerical value.
8. Fill in the **booking_date** and **booking_start_time** and **booking_end_time** fields with the date and time of the booking.
9. Enter the **booking_venue** where the event will be held.
10. Provide the name of the **contact_person** responsible for the event.
11. Enter the **phone** and **email** of the contact person (optional).
12. If necessary, provide additional terms for the **artist_fee** in the **artist_fee_terms** field (optional).
13. Add any **event_details**, such as the event description or requirements (optional).
14. Specify any **special_requirements** for the event (optional).
15. Provide any **event_type_terms** specific to the event type (optional).
16. Enter the **event_location** where the event will take place (optional).
17. Specify the **performance_length** of the event in minutes.
18. Choose the **artist_fee_currency** from the options provided (e.g., Dollar, Pound, Yen).
19. Enter the **artist_fee_currency_code** to indicate the specific currency used for the artist's fee.
20. Add any additional **notes** about the booking or event.

## Field-by-Field Explanation

* **artist_name**: Enter the name of the performing artist or band.
* **event_date**: Date of the event in YYYY-MM-DD format.
* **start_time**: Start time of the event.
* **end_time**: End time of the event.
* **venue**: Location of the event.
* **booking_manager**: Name of the person responsible for handling the booking.
* **event_type**: Type of event (e.g., Event Type 1, Event Type 2, Event Type 3).
* **artist_fee**: Monetary value for the artist's fee.
* **booking_date**: Date of the booking in YYYY-MM-DD format.
* **booking_start_time**: Start time of the booking.
* **booking_end_time**: End time of the booking.
* **booking_venue**: Location of the booking.
* **contact_person**: Name of the person in charge of the event.
* **phone**: Optional contact phone number of the contact person.
* **email**: Optional contact email of the contact person.
* **artist_fee_terms**: Additional terms for the artist's fee (if necessary).
* **event_details**: Event description or requirements (if any).
* **special_requirements**: Any special requirements for the event.
* **event_type_terms**: Event type-specific terms (if necessary).
* **event_location**: Location of the event.
* **performance_length**: Length of the event in minutes.
* **artist_fee_currency**: Currency used for the artist's fee (e.g., Dollar, Pound, Yen).
* **artist_fee_currency_code**: Code of the currency used for the artist's fee.
* **notes**: Additional notes about the booking or event.
