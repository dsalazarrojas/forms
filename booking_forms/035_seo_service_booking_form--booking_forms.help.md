# seo_service_booking_form - Help Guide
## Purpose
The seo_service_booking_form is a form used to collect information from clients for SEO services.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the Client Information section with the client's details.
2. Choose the type of service the client is interested in by selecting an option in the Service Preferences field.
3. Select a date for the service using the Date field.
4. Enter the time for the service using the Time field.
5. Provide any additional notes or instructions in the Notes field.
6. Enter the client's email address in the Email field.
7. Enter the client's phone number in the Phone field.
8. Assign a tool or resource to the client's case in the Assigned Tool field.
9. Assign a person to the client's case in the Assigned to field.
10. Enter any additional information about the output file in the Output File field.

## Field-by-Field Explanation

* **Client Information (Client Information, text, required)**: Enter the client's name and other identifying information.
* **Service Preferences (Service Preferences, select_one, required)**: Choose the type of SEO service the client is interested in. Options are: seo analysis, seo audit, seo strategy.
* **Date (Date, date, required)**: Select a date for the service.
* **Time (Time, time, required)**: Enter the time for the service.
* **Notes (Notes, note, required)**: Provide any additional notes or instructions for the service.
* **Email (Email, email, required)**: Enter the client's email address.
* **Phone (Phone, text, required)**: Enter the client's phone number.
* **Assigned Tool (Assigned Tool, text, required)**: Assign a tool or resource to the client's case.
* **Assigned to (Assigned to, text, required)**: Assign a person to the client's case.
* **Output File (Output File, text, required)**: Enter any additional information about the output file.

Note: Some fields in this form are marked as required, but they do not have any validation or input masking for sensitive data like phone numbers or email addresses. Please be cautious when filling out this form.
