# Venue Rental Intake Form - Help Guide
## Purpose
The Venue Rental Intice Form is designed to gather event information from event organizers, allowing venue management to review and approve event bookings.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the event details, including event title, date, and time.
2. Provide information about the event planner, including name and contact information.
3. Specify the number of attendees expected at the event.
4. Fill in the requested fields as accurately and thoroughly as possible.

## Field-by-Field Explanation

* **Event Details**: <label> (Event Details, text, required: false): Please fill in a brief description of the event, including the event title.
* **Rental Agreement**: <label> (Rental Agreement, text, required: false): This field should be left blank unless you have any specific requests or requirements for the event.
* **Event Planner**: <label> (Event Planner, text, required: false): Enter the name and contact information of the person responsible for the event, including email and phone number.
* **Venue**: <label> (Venue, text, required: false): Specify the venue where the event will take place.
* **Date**: <label> (Date, date, required: false): Enter the date of the event in YYYY-MM-DD format.
* **Time**: <label> (Time, time, required: false): Enter the start and end time of the event in HH:MM 24hr format.
* **Attendees**: <label> (Attendees, text, required: false): Please specify the number of attendees expected at the event.

## Tips

* Make sure to fill in all required and optional fields accurately and thoroughly.
* Proofread your submission before submitting the form to ensure everything is correct.
* If you have any questions or concerns, contact the form administrators at form@gic.mx.
