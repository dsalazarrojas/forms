# film restoration workroom booking form - Help Guide
## Purpose
The film restoration workroom booking form is a tool used for booking and managing film restoration services. This form collects necessary information for accurate and efficient scheduling. It is used for customers to request workroom services, such as booking time slots and providing details about the restoration services needed.

## How To Complete This Form
To complete the film restoration workroom booking form, follow these steps:

1. Ensure you have all necessary information ready, including the customer's details, the desired restoration service, and the dates and times for the service.
2. Fill out the form with the required information, making sure to provide accurate details about the customer and their requirements.
3. Select the desired restoration service from the options provided.
4. Choose the start and end dates and times for the service.
5. Specify the duration of the service.
6. Add any additional notes about the booking.
7. Review the form for accuracy before submitting it.

## Field-by-Field Explanation
- **Booking Form** (`booking_form`, text, optional): This field is for customers to describe the purpose of their booking or any other information about their service.
- **Customer info** (`customer_info`, text, optional): This field is for customers to provide a brief description of themselves and their company or organization.
- **Customer name** (`customer_name`, text, optional): This field is for customers to provide their name.
- **Email** (`email`, email, optional): This field is for customers to enter their email address.
- **Phone** (`phone`, text, optional): This field is for customers to enter their phone number.
- **Workroom details** (`workroom_details`, text, optional): This field is for customers to provide details about the equipment or workroom they need for the restoration service.
- **Restoration service** (`restoration_service`, select_one, optional): This field allows customers to select the type of restoration service they need. Options include 1, 2, 3, 4, and 5.
- **Start date** (`start_date`, date, optional): This field is for customers to select the start date for the service.
- **End date** (`end_date`, date, optional): This field is for customers to select the end date for the service.
- **Start time** (`start_time`, time, optional): This field is for customers to select the start time for the service.
- **End time** (`end_time`, time, optional): This field is for customers to select the end time for the service.
- **Duration** (`duration`, number, optional): This field is for customers to specify the duration of the service in hours.
- **Notes** (`notes`, note, optional): This field is for customers to add any additional notes about the booking.
- **Form submit** (`form_submit`, select_one, optional): This field is used to confirm the submission of the form.
