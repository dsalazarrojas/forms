# Cruise Itinerary Extension Form - Help Guide
## Purpose
This form is intended to aid travel agencies in handling passenger itinerary extension requests. It's used to gather necessary information to manage these extensions efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide passenger information in the first field.
2. Enter relevant cruise details in the second field.
3. Select your travel agency from the third field.
4. Choose your travel agent from the fourth field.
5. Enter your contact method in the fifth field (e.g., email or phone).
6. Add any additional details that might be useful (optional).
7. If you're extending an existing itinerary, provide the date of extension.

## Field-by-Field Explanation
* **Passenger Information (passenger_info)**:
	+ This is the first field where you enter the passenger's personal details (name, contact, etc.).
* **Cruise Details (cruise_details)**:
	+ This field is for any information related to the original cruise booking or changes required for the extension.
* **Travel Agency (travel_agency)**:
	+ Select the agency responsible for handling this extension request (e.g., Air France, Airline, Other).
* **Travel Agent (travel_agent)**:
	+ Choose the specific travel agent handling this extension request (e.g., John, Jane, Jim).
* **Contact Method (contact_method)**:
	+ Choose how you'd like to be contacted about this request (e.g., Email, Phone).
* **Additional Details (additional_details)**:
	+ If there's any extra information you'd like to add about the extension request, enter it here.
* **Date of Extension (date_of_extension)**:
	+ If you're extending an existing itinerary, provide the date of the extension.

## Tips
* Ensure all required fields are filled out to facilitate efficient processing.
* Use the contact method to receive updates or notifications about your extension request.
* If you have any further questions or concerns, feel free to reach out to us at form@gic.mx.
