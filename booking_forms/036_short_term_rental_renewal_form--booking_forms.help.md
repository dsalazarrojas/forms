# short_term_rental_renewal_form - Help Guide

## Purpose
This form is used to manage the renewal process of short-term rentals. It collects necessary information from the tenant to determine the eligibility for renewal and the terms of the rental agreement.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the rental details page and select the relevant options for your situation. If you are unsure, please refer to the instructions below.
* On the tenant information page, select whether the tenant has provided the necessary documents for the renewal process.
* On the renewal terms page, select the renewal terms that apply to your situation.

## Field-by-Field Explanation

* **Rental Details** (`Rental Details`, `select_multiple`, required): This field allows you to select the relevant details of the rental agreement. Please select 'Yes' if you have the necessary information about the rental, otherwise select 'No'.
* **Tenant Information** (`Tenant Information`, `select_one`, required): This field indicates whether the tenant has provided the necessary documents for the renewal process. Select 'Yes' if the documents have been provided, otherwise select 'No'.
* **Renewal Terms** (`Renewal Terms`, `select_one`, required): This field determines the renewal terms of the rental agreement. Please select the terms that apply to your situation.
* **Tenant Documents** (`Tenant Documents`, `text`, required): In this field, please describe the documents provided by the tenant that are necessary for the renewal process.

Tips:
* Please make sure to select the correct options for the rental details and renewal terms to ensure accurate processing of the form.
* If you are unsure about any field, refer to the instructions above for guidance.
* Remember to provide clear and concise descriptions of the tenant's documents in the "Tenant Documents" field.
