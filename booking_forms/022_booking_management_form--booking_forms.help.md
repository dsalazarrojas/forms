# Booking Management Form - Help Guide
## Purpose
The Booking Management Form is used for managing bookings for guests, including viewing details, modifying, cancelling, and making other actions as needed.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the booking reference number to identify the specific booking.
2. Fill in the guest's name and email address.
3. Enter the guest's phone number.
4. Select the management action needed from the options provided (e.g., view, modify, cancel, etc.).
5. If modifying, enter the new check-in and check-out dates.
6. If modifying, select the new room type if different from the current one.
7. If reporting an issue, enter a brief description of the problem.
8. Select the priority level of the issue (e.g., low, medium, high, urgent).
9. Enter any additional notes or information as needed.

## Field-by-Field Explanation

* **Booking Reference Number** (`booking_reference`): Enter the booking reference number to identify the specific booking.
* **Guest Name** (`guest_name`): Enter the full name of the guest.
* **Guest Email Address** (`guest_email`): Enter the guest's email address.
* **Guest Phone Number** (`guest_phone`): Enter the guest's phone number.
* **Management Action Needed** (`management_action`): Select the action needed from the options provided (e.g., view, modify, cancel, etc.).
* **Current Check-in Date** (`current_check_in`): Enter the date of the current check-in if modifying.
* **Current Check-out Date** (`current_check_out`): Enter the date of the current check-out if modifying.
* **New Check-in Date** (`new_check_in`): Enter the new check-in date if modifying.
* **New Check-out Date** (`new_check_out`): Enter the new check-out date if modifying.
* **Current Room Type** (`room_type`): Select the type of room booked.
* **Requested Changes** (`requested_changes`): Select any changes needed (e.g., room upgrade, room downgrade, etc.).
* **Issue or Concern Description** (`issue_description`): Enter a brief description of the issue if reporting.
* **Priority Level** (`priority_level`): Select the priority level of the issue (e.g., low, medium, high, urgent).
* **Preferred Resolution** (`preferred_resolution`): Enter any additional information for resolution.
* **Additional Notes** (`additional_notes`): Enter any other information or notes about the booking.

Note: All fields are required to be filled unless noted otherwise.
