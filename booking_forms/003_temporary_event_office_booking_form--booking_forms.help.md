# Temporary Event Office Booking Form - Help Guide
## Purpose
This form is used to book temporary events, such as meetings, conferences, and workshops, for office space. It collects essential details about the event, including the date, time, type, and contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the event type from the options provided.
2. Choose a date for the event.
3. Choose a time slot for the event booking.
4. Enter the number of attendees.
5. Enter the contact email and phone number for the event organizer.
6. Provide any additional comments about the event.
7. Click the "Submit" button to submit the form.

## Field-by-Field Explanation

* **Event Details**: Enter a brief description of the event.
	+ Type: text
	+ Required: false
* **Event Date**: Enter the date of the event (mm/dd/yyyy).
	+ Type: date
	+ Required: false
* **Event Time**: Enter the time of the event (HH:MM AM/PM).
	+ Type: time
	+ Required: false
* **Event Type**: Select the type of event (e.g. Meeting, Conference, Seminar, etc.).
	+ Type: select_one
	+ Required: true
* **Office Booking**: Select one or more time slots for the event booking.
	+ Type: select_multiple
	+ Required: false
* **Attendees**: Enter the number of attendees expected.
	+ Type: number
	+ Required: false
* **Contact E-mail**: Enter the email address of the event contact.
	+ Type: email
	+ Required: false
* **Contact Phone**: Enter the phone number of the event contact.
	+ Type: text
	+ Required: false
* **Comments**: Provide any additional comments about the event.
	+ Type: note
	+ Required: false
* **Event Comments**: Provide any additional comments about the event.
	+ Type: note
	+ Required: false
* **Event Comments 2**: Provide any additional comments about the event.
	+ Type: note
	+ Required: false
* **Submit**: Click to submit the form and book the event.
	+ Type: text
	+ Required: false
