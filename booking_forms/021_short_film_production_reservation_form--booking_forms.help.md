# Short Film Production Reservation Form - Help Guide

## Purpose
The Short Film Production Reservation Form is designed to collect necessary information for the production of short films. This form helps the production team understand project details, logistical requirements, and contact information. 

## How To Complete This Form
1. Fill out each field with the required information.
2. Ensure that all required fields are completed before submission.

## Field-by-Field Explanation

* **Project Name**: This field is for the title or name of the short film project. Enter the name of the project that you are reserving.
* **Project Description**: This field is for a brief description of the project. Provide a concise and clear description of what your project is about.
* **Location**: This field is to confirm whether the production will take place in a specific location. Select 'Yes' if the project requires a particular location, or 'No' if not.
* **Equipment**: This field is to confirm what equipment will be needed for the production. Select multiple options if necessary (e.g., lights, camera, etc.).
* **Start Date**: This field is for the expected start date of the project. Enter the date when production is set to begin.
* **End Date**: This field is for the expected end date of the project. Enter the date when production is set to conclude.
* **Start Time**: This field is for the expected start time of the project. Enter the time when production is set to begin.
* **End Time**: This field is for the expected end time of the project. Enter the time when production is set to conclude.
* **Contact Name**: This field is for the name of the contact person for the project. Enter the name of the person in charge.
* **Contact E-Mail**: This field is for the email address of the contact person. Enter the email address of the person in charge.
* **Contact Phone**: This field is for the phone number of the contact person. Enter the phone number of the person in charge.
* **Contact Note**: This field is for any additional contact information or notes. Enter any specific details about the contact person.
* **Assigned User**: This field is for the person assigned to the project. Enter the name of the person or team member assigned.
* **Project Notes**: This field is for any additional project-related notes. Enter any specific details about the project.
* **Location Notes**: This field is for any specific details about the location where the production will take place. Enter any relevant information.

## Tips
- Ensure all required fields are filled out correctly.
- Use the provided fields to the best of your abilities to provide accurate and complete information.
- If any field does not apply, simply leave it blank.
