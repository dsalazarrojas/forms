# Audio Postproduction Editing Booking Form - Help Guide
## Purpose
This form is designed to gather essential information for booking audio postproduction editing services.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your full name and contact email address.
2. Provide the project title and type (e.g., Feature Film, Short Film, etc.).
3. Specify the total duration of the audio files in minutes.
4. Choose the services you require for postproduction editing (select all that apply).
5. Select the source file format (e.g., Pro Tools Session, OMF/AAF, etc.).
6. Enter the expected start and finish dates for the project delivery.
7. Provide a link to the project files in cloud storage.
8. If necessary, add any specific creative instructions for the project.
9. Enter a valid phone number for contact.

## Field-by-Field Explanation

* **Full Name** (requestor_name): Your full name and contact details are required for us to get back to you.
* **Project or Production Title** (production_title): Enter the title of the project you are working on.
* **Type of Production** (production_type): Select the type of project you are working on (e.g., Feature Film, Short Film, etc.).
* **Total Duration of Audio (Minutes)** (total_duration_minutes): Enter the total duration of the audio files in minutes.
* **Services Requested** (services_requested): Select all the services you need for postproduction editing (e.g., Dialogue Cleaning and Editing, Noise Reduction, etc.).
* **Source File Format** (source_format): Choose the format of the source files (e.g., Pro Tools Session, OMF/AAF, etc.).
* **Expected Start Date** (expected_start_date): Enter the expected start date for the project.
* **Deadline for Final Delivery** (expected_finish_date): Enter the deadline for the final project delivery.
* **Link to Project Files** (files_location_link): Provide a URL to access the project files in cloud storage.
* **Specific Creative Instructions** (special_instructions): If you have any specific instructions or preferences for the project, add them here.
* **Contact Email** (contact_email): Enter a valid email address for contact purposes.
* **Phone Number** (contact_phone): Enter a valid phone number for contact purposes.

## Tips

* Make sure to fill in all required fields accurately to ensure efficient processing of your request.
* If you have any special requests or instructions, please add them in the "Specific Creative Instructions" field.
* Ensure that the link to project files is valid and accessible.
