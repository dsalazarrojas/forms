# Event Logistics Vehicle Booking Form - Help Guide
## Purpose
This form is designed to collect information about vehicle bookings for events, which can be used to manage logistics and ensure that vehicles are picked up and dropped off correctly.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the required fields with accurate and up-to-date information about the event and vehicle booking.
* Ensure that you provide all necessary information to prevent delays or misunderstandings in the booking process.
* If you are unsure about any field or require clarification, please contact the event team directly.

## Field-by-Field Explanation

* **Vehicle**: This field is for the vehicle make and model that will be used for the event.
	+ Please enter the make and model of the vehicle, e.g., Toyota Camry or Honda Civic.
* **Event Details**: This field is for providing additional information about the event, such as event name, date, and location.
	+ Please enter any relevant event details, e.g., "Company Conference" or "Wedding Reception".
* **Start Date**: This field is for entering the start date of the event.
	+ Please enter the date in a standard date format, e.g., 2022-02-15.
* **End Date**: This field is for entering the end date of the event.
	+ Please enter the date in a standard date format, e.g., 2022-02-15.
* **Pickup Time**: This field is for entering the time of pickup for the vehicle.
	+ Please enter the time in a standard time format, e.g., 10:00 AM.
* **Dropoff Time**: This field is for entering the time of dropoff for the vehicle.
	+ Please enter the time in a standard time format, e.g., 10:00 PM.
* **Event Location**: This field is for entering the location of the event.
	+ Please enter the address or name of the event location.
* **Vehicle Details**: This field is for providing additional information about the vehicle, such as make, model, color, and any other relevant details.
	+ Please enter any additional vehicle details, e.g., "Toyota Camry, red, 2009".
* **Vehicle Make**: This field is for entering the make of the vehicle.
	+ Please enter the make of the vehicle, e.g., Toyota.
* **Vehicle Model**: This field is for entering the model of the vehicle.
	+ Please enter the model of the vehicle, e.g., Camry.
* **Vehicle Color**: This field is for entering the color of the vehicle.
	+ Please enter the color of the vehicle, e.g., red.
* **Pickup Address**: This field is for entering the address of the pickup location.
	+ Please enter the address of the pickup location, e.g., 123 Main St.
* **Dropoff Address**: This field is for entering the address of the dropoff location.
	+ Please enter the address of the dropoff location, e.g., 123 Main St.
* **Notes**: This field is for entering any additional comments or notes about the vehicle booking.
	+ Please enter any additional information about the event or vehicle, e.g., "Parking details: please park at back entrance".
* **Notes 1-6**: These fields are for entering any additional comments or notes about the vehicle booking (1-6).
	+ Please enter any additional information about the event or vehicle, e.g., "Additional details about the event: please wear formal attire."
