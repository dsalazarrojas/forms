# Game Studio Demo Slot Booking Form - Help Guide
## Purpose
The Game Studio Demo Slot Booking Form is used to book time slots for demo purposes, such as presentations, game testing, or meetups.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your First Name and Last Name in the respective fields.
2. Enter your Email address in the Email field.
3. Enter your Phone number in the Phone field.
4. Select a preferred Date for the demo.
5. Choose a Time Slot for the demo from the available options.
6. Specify the length of the demo in the Demo Length field.
7. Select the Media Type for the demo (e.g., game trailer, gameplay footage, etc.).
8. Choose the booking status (Confirmed, Pending, or Canceled).
9. Leave any additional Notes for the demo organizers.
10. Click the "Submit" button to complete the form.

## Field-by-Field Explanation
- **First Name** (`first_name`, text, optional): Enter your first name.
- **Last Name** (`last_name`, text, optional): Enter your last name.
- **Email** (`email`, email, optional): Enter your email address.
- **Phone** (`phone`, text, optional): Enter your phone number.
- **Date** (`date`, date, optional): Select a date for the demo.
- **Time Slot** (`time_slot`, select_one, optional): Choose a time slot for the demo from the available options.
- **Demo Length** (`demo_length`, number, optional): Specify the length of the demo.
- **Media Type** (`media_type`, select_multiple, optional): Select the media type for the demo (e.g., game trailer, gameplay footage, etc.).
- **Booking Status** (`booking_status`, select_one, optional): Choose the booking status (Confirmed, Pending, or Canceled).
- **Notes** (`notes`, note, optional): Leave any additional notes for the demo organizers.
- **Form ID** (`form_id`, text, optional): This field is likely intended for internal use by the game studio team to keep track of the form submissions.

## Tips
- Double-check your email address for correctness before submitting the form.
- Make sure to choose a specific media type for the demo to help the game studio prepare accordingly.
- If your booking status is Pending or Canceled, be prepared to discuss with the game studio team to confirm the demo details.
- Use the Notes field to leave any additional information that might be helpful for the demo organizers.
