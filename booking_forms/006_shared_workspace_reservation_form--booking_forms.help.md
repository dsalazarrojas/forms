# shared_workspace_reservation_form - Help Guide
## Purpose
The shared_workspace_reservation_form is used to reserve a shared workspace. This form is used to provide details such as start and end dates, start and end times, and other relevant information for booking a shared workspace.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of workspace you want to reserve (e.g., "Yes" or "No").
2. Enter the start date of the reservation.
3. Enter the end date of the reservation.
4. Enter the start time of the reservation.
5. Enter the end time of the reservation.
6. Select the ID of the room you want to reserve (e.g., "Yes" or "No").
7. Enter a description of the reservation.
8. Enter the maximum capacity of the reservation.
9. Enter the number of guests you are expecting.
10. Enter the contact email of the person or group booking the reservation.
11. Enter any comments or notes about the reservation.
12. Select the ID of the user booking the reservation (e.g., "Yes" or "No").

## Field-by-Field Explanation

* **Workspace Type** (workspace_type, select_one): Choose "Yes" if you want to reserve a shared workspace, "No" if you do not.
* **Start Date** (start_date, date): Enter the date you want to start the reservation.
* **End Date** (end_date, date): Enter the date you want to end the reservation.
* **Start Time** (start_time, time): Enter the time you want to start the reservation.
* **End Time** (end_time, time): Enter the time you want to end the reservation.
* **Room ID** (room_id, select_one): Choose the ID of the room you want to reserve (e.g., "Yes" or "No").
* **Description** (description, text): Enter a description of the reservation (e.g., purpose of the booking).
* **Capacity** (capacity, number): Enter the maximum number of people that can be in the reserved workspace.
* **Guests** (guests, number): Enter the number of guests you are expecting.
* **Contact** (contact, email): Enter the email of the person or group booking the reservation.
* **Comments** (comments, text): Enter any comments or notes about the reservation.
* **Booking User ID** (booking_user_id, select_one): Choose "Yes" if you are the booking user, "No" if you are not.
