# Holiday Decoration Service Booking - Help Guide
## Purpose
This form is used to book a holiday decoration service for various types of holidays.
## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of holiday for which you want to book the decoration service.
2. Choose the date and time for the decoration.
3. Select the location(s) where you want the decoration to take place.
4. Enter your contact information so we can get in touch with you.

## Field-by-Field Explanation
* **Holiday Type (Select)**: Select the type of holiday for which you want to book the decoration service.
* **Date**: Enter the date for the decoration.
* **Time**: Enter the time for the decoration.
* **Location**: Select the location(s) where you want the decoration to take place. You can choose one or multiple locations.
* **Preferences**: If you have any specific preferences for the decoration, enter them here. (Note: this is an optional field)
* **Notes**: If you have any additional comments or requests, enter them here. (Note: this is an optional field)
* **Contact Name**: Enter your name or the name of the person we should contact.
* **Contact Phone**: Enter your phone number or the phone number of the person we should contact.
* **Contact Email**: Enter your email address or the email address of the person we should contact.
## Tips
* Please make sure to fill out all required fields accurately and completely.
* If you're unsure about any field, you can contact our customer support team for assistance.
* Please note that we will need at least 24 hours' notice before the event to prepare for the decoration.
