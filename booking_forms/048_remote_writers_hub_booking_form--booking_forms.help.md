# Remote Writers’ Hub Booking Form - Help Guide

## Purpose
The Remote Writers’ Hub Booking Form is used to book a remote writer for a project. This form allows users to select one or multiple projects, enter their name and contact information, and provide details about the project.

## How To Complete This Form
To complete this form, follow these steps:
1. Select one or multiple projects to book by choosing the desired options in the "Booking Form" section.
2. Enter your name and contact information in the corresponding fields.
3. Select the project brief and remote writer from the dropdown menus.
4. Enter any additional project details in the "Project Details" field.
5. Add any notes about the project deadline in the "Project Deadline Note" field.
6. Complete any additional fields as needed.
7. Click submit to submit the form.

## Field-by-Field Explanation
* **Booking Form (Select one or multiple options)**: This is where you select the project(s) you want to book.
* **Name**: Enter your name as you would like it to appear on the booking.
* **Deadline**: Select a deadline for the project, if applicable.
* **Project Brief**: This is where you select the project brief. Choose the correct brief for your project.
* **Remote Writer**: This is where you select the remote writer. Choose the correct writer for your project.
* **Email**: Enter your email address where you can be reached.
* **Phone**: Enter your phone number where you can be reached.
* **Project Details**: This is where you provide any additional information about your project.
* **Project Deadline Note**: If you have any special instructions or notes about the project deadline, enter them here.
* **Form Submitted By**: This field is not currently used, but it's there in case it's needed in the future.
