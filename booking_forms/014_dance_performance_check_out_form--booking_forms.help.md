# Dance Performance Check Out Form - Help Guide
## Purpose
The Dance Performance Check Out Form is designed to gather information from participants in a dance performance event. This form helps event organizers with participant details, preferences, and requirements, ensuring a smooth and organized event.

## How To Complete This Form
1. Start by selecting the relevant options from the Participant Info page.
2. Fill in the participant's name, email, phone number, and any special requests on the Participant Info page.
3. On the Check Out page, select the date and time of the event.
4. If necessary, add any notes about the participant's needs or expectations.
5. Finally, select the assigned tool from the options provided.

## Field-by-Field Explanation

* **Participant Info (Select One)**: Choose the relevant option for the participant's information.
  * Option 1: Participant is a regular performer.
  * Option 2: Participant is a VIP performer.
  * Option 3: Participant is a special guest.
* **Participant Name**: Enter the participant's full name.
* **Email**: Enter the participant's email address.
* **Phone**: Enter the participant's phone number.
* **Date**: Select the date of the event.
* **Time**: Select the time of the event.
* **Special Requests**: Enter any additional requests or needs the participant has.
* **Note**: If the participant has any specific notes or comments, add them here.
* **Assigned Tool**: Select the tool assigned to the participant from the options provided. 
  * ChatJimmy: This is a tool or software used for communication.
  * Other: Select this option if the participant has a different tool assigned to them.
