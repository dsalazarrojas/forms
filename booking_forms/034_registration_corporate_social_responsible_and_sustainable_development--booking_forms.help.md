# Registration Corporate Social Responsible And Sustainable Development - Help Guide
## Purpose
This form is used to create a new booking form for corporate social responsible and sustainable development events.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the title of the event in the "Title" field.
2. Select the category of the event from the "Category" field. This field is required.
3. Enter a description of the event in the "Description" field. This field is required.
4. Select the categories that apply to the event from the "Categories" field. This field is optional.
5. Select the booking forms that apply to the event from the "Booking Forms" field. This field is required.
6. Enter the date of the event in the "Date" field. This field is required.
7. Enter the time of the event in the "Time" field. This field is optional.
8. Enter any additional file information in the "File" field. This field is optional.
9. Enter the email of the event contact in the "Email" field. This field is optional.
10. Enter the phone number of the event contact in the "Phone" field. This field is optional.
11. Enter any additional notes about the event in the "Note" field. This field is optional.

## Field-by-Field Explanation
* **Title** (`form_title`, text, required): Enter the title of the event.
* **Category** (`category`, select_one, required): Select the category of the event.
* **Description** (`form_description`, text, required): Enter a description of the event.
* **Categories** (`form_categories`, select_multiple, optional): Select the categories that apply to the event.
* **Booking Forms** (`form_categories_1`, select_one, required): Select the booking forms that apply to the event.
* **Date** (`form_date`, date, required): Enter the date of the event.
* **Time** (`form_time`, time, optional): Enter the time of the event.
* **File** (`form_file`, text, optional): Enter any additional file information.
* **Email** (`form_email`, email, optional): Enter the email of the event contact.
* **Phone** (`form_phone`, text, optional): Enter the phone number of the event contact.
* **Note** (`form_note`, note, optional): Enter any additional notes about the event.
