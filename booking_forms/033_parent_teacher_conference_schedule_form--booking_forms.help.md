# Parent Teacher Conference Schedule Form - Help Guide

## Purpose

The Parent Teacher Conference Schedule Form is designed to collect information necessary to schedule a parent-teacher conference, which allows for a meeting between a parent/guardian and a teacher to discuss a student's progress or other matters.

## How To Complete This Form

1. Fill in the parent's name.
2. Fill in the teacher's name.
3. Provide the student's name.
4. Choose a conference date and time.
5. Select the type of conference.
6. Enter conference details.
7. Specify the conference location.
8. Select start and end times for the conference.
9. Choose the attendance of the parent, teacher, and student.
10. Enter any additional notes about the conference.
11. Provide a contact email and phone number.

## Field-by-Field Explanation

* **Parent Name**: Please enter the name of the parent or guardian.
	+ Type: Text.
	+ Required: Optional.
* **Teacher Name**: Please enter the name of the teacher.
	+ Type: Text.
	+ Required: Optional.
* **Student Name**: Please enter the name of the student.
	+ Type: Text.
	+ Required: Optional.
* **Date**: Please select a date for the conference.
	+ Type: Date.
	+ Required: Optional.
* **Time**: Please select the time for the conference.
	+ Type: Time.
	+ Required: Optional.
* **Conference Type**: Please select the type of conference (e.g. meeting, discussion, etc.).
	+ Type: Select One.
	+ Required: Optional.
* **Conference Details**: Please enter any additional details about the conference.
	+ Type: Text.
	+ Required: Optional.
* **Conference Location**: Please enter the location of the conference.
	+ Type: Text.
	+ Required: Optional.
* **Conference Start Time**: Please select the start time of the conference.
	+ Type: Time.
	+ Required: Optional.
* **Conference End Time**: Please select the end time of the conference.
	+ Type: Time.
	+ Required: Optional.
* **Parent Attendance**: Please select the attendance of the parent.
	+ Type: Select One.
	+ Required: Optional.
* **Teacher Attendance**: Please select the attendance of the teacher.
	+ Type: Select One.
	+ Required: Optional.
* **Student Attendance**: Please select the attendance of the student.
	+ Type: Select One.
	+ Required: Optional.
* **Note**: Please enter any additional notes about the conference.
	+ Type: Text.
	+ Required: Optional.
* **Email**: Please enter the contact email.
	+ Type: Email.
	+ Required: Optional.
* **Phone**: Please enter the contact phone number.
	+ Type: Text.
	+ Required: Optional.

## Tips

* Make sure to double-check the conference details and schedule.
* Be clear about the conference type and purpose.
* If any of the fields are not applicable, please make sure to select "N/A" or leave a note explaining why.
* If there are any conflicts with the conference schedule, please notify the relevant parties.
