# Corporate Event Catering Quotation Form - Help Guide
## Purpose
The purpose of this form is to gather event details to generate a catering quotation for corporate events such as conferences, meetings, weddings, and parties.

## How To Complete This Form
To complete this form, please follow these steps:

* Enter event details in the "Event Details" field.
* Select the event date and start date from the calendar.
* Select the event start time and end time.
* Enter the event location.
* Provide any additional details about the event.
* Choose the event type (e.g. Conference, Meeting, Wedding, etc.).
* Estimate the number of attendees.
* Estimate the budget for the event.

## Field-by-Field Explanation

* **Event Details** (id: 1):
  * A brief description of the event (text).
  * Please describe the event in 1-2 sentences.
* **Event Date** (id: 2):
  * The date of the event (date).
  * Select the date of the event from the calendar.
* **Event Time** (id: 3):
  * The time of the event (time).
  * Select the start time of the event from the clock.
* **Event Start Date** (id: 4):
  * The start date of the event (date).
  * Select the start date of the event from the calendar.
* **Event Start Time** (id: 5):
  * The start time of the event (time).
  * Select the start time of the event from the clock.
* **Event End Date** (id: 6):
  * The end date of the event (date).
  * Select the end date of the event from the calendar.
* **Event End Time** (id: 7):
  * The end time of the event (time).
  * Select the end time of the event from the clock.
* **Event Location** (id: 8):
  * The location of the event (text).
  * Enter the address or venue of the event.
* **Event Details** (id: 9):
  * A brief description of the event (text).
  * Please provide any additional details about the event.
* **Event Type** (id: 10):
  * The type of event (select one).
  * Choose from: Corporate Event, Conference, Wedding, Meeting, Party, Birthday.
* **Event Attendance** (id: 11):
  * Estimated number of attendees (number).
  * Enter the estimated number of people attending the event.
* **Guests Count** (id: 12):
  * Estimated number of guests (number).
  * Enter the estimated number of guests.
* **Budget** (id: 13):
  * Estimated budget for the event (number).
  * Enter the estimated budget for the event.
