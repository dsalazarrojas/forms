# Limousine Service Inquiry Form - Help Guide
## Purpose
The Limousine Service Inquiry Form is designed to collect information about your limousine requirements for a smooth and efficient service experience.

## How To Complete This Form

1. Enter your desired **pickup location** where you would like to be picked up. This is the address or city where you would like to be collected from.
2. Select your desired **pickup date** for the limousine service. Ensure you choose a date in the correct format (dd/mm/yyyy).
3. Choose your desired **pickup time** for the limousine service. Select a time in the format 24-hour clock (HH:MM).
4. If you have any **special requests**, such as additional equipment or services required, please specify them in this field.
5. Please enter the **number of guests** you will be traveling with.
6. Select the type of **limousine** you prefer:
	* **Luxury**: Ideal for special occasions or business events.
	* **Standard**: Suitable for everyday transportation needs.
	* **Economy**: Basic, budget-friendly option.
7. Add any **pickup location note** if you have specific requirements for the driver to be aware of.
8. Enter a name for the **output file**, which will contain your limousine details. (This is only necessary for internal use.)
9. Finally, provide details on the **assigned tool**, which is not used for your limousine booking.

## Field-by-Field Explanation

* **Pickup Location (1)**: Enter the address or city where you would like to be collected from.
* **Pickup Date (2)**: Select the date you would like to be picked up.
* **Pickup Time (3)**: Choose the time you would like to be picked up.
* **Special Requests (4)**: If you have any special requirements or services needed, please specify them here.
* **Number of Guests (5)**: Enter the number of people you will be traveling with.
* **Limousine Type (6)**: Select the type of limousine that suits your needs:
	+ **Luxury**: Ideal for special events or business meetings.
	+ **Standard**: Suitable for everyday transportation needs.
	+ **Economy**: Basic, budget-friendly option.
* **Pickup Location Note (7)**: Add any specific requirements or instructions for the driver to be aware of.
* **Output File Name (8)**: Enter a name for the file containing your limousine details (this is for internal use).
* **Assigned Tool (9)**: This field is not used for limousine booking purposes; please leave it blank.

## Tips
* Please ensure that all fields are completed accurately and thoroughly.
* If you have any questions or concerns, feel free to contact us directly.
* We appreciate your cooperation in providing detailed and clear information to ensure the best possible service experience.
