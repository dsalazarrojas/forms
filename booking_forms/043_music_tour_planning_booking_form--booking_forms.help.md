# Music Tour Planning Booking Form - Help Guide
## Purpose
This form is used to collect information for music tour planning and booking.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant tour dates for the booking.
2. Choose the locations where the tour will take place.
3. Enter any specific requirements for the tour.
4. Enter the tour budget.
5. Provide the name of the tour manager.
6. Enter the manager's contact information (email and phone number).
7. Enter the name of the band or artist.
8. Choose whether a booking agency will be involved in the booking process.
9. Enter any additional tour dates if necessary.
10. Add any notes or comments about the tour.
11. Enter any other relevant information about the submission.

## Field-by-Field Explanation

* **Tour Dates**: This field allows you to select the dates that the tour will take place. You can choose multiple dates if the tour will have a series of events.
	+ Type: `select_multiple`
* **Locations**: This field is used to choose the locations where the tour will take place.
	+ Type: `select_one`
* **Tour Requirements**: This field is used to enter any specific requirements for the tour.
	+ Type: `date`
* **Tour Budget**: This field is used to enter the budget for the tour.
	+ Type: `number`
* **Manager Name**: This field is used to enter the name of the tour manager.
	+ Type: `text`
* **Manager Email**: This field is used to enter the email address of the tour manager.
	+ Type: `email`
* **Manager Phone**: This field is used to enter the phone number of the tour manager.
	+ Type: `text`
* **Band Name**: This field is used to enter the name of the band or artist.
	+ Type: `text`
* **Booking Agency**: This field is used to choose whether a booking agency will be involved in the booking process.
	+ Type: `select_one`
* **Tour Dates 2**: This field is used to enter any additional tour dates if necessary.
	+ Type: `date`
* **Manager Notes**: This field is used to add any additional notes or comments about the tour.
	+ Type: `note`
* **Form Submission**: This field is used to enter any other relevant information about the submission.
	+ Type: `text`
* **Tour Dates 3**: This field is used to enter any further tour dates if necessary.
	+ Type: `date`
* **Tour Budget 2**: This field is used to enter the budget for the second part of the tour.
	+ Type: `number`

## Tips
* When entering dates, please use the format `YYYY-MM-DD`.
* When entering budget, please enter the amount in the local currency.
* When adding notes, please use plain text without any formatting.
* If you are unsure about any field, please ask your tour manager for guidance.
* Remember to submit the form only once to avoid duplicate submissions.
