# Face Painting Booking Form - Help Guide
## Purpose
The Face Painting Booking Form is used to book a face painting event or service. Fill in the required information to ensure a smooth and successful booking process.

## How To Complete This Form
1. Select a date for the booking.
2. Indicate whether the event details are Yes or No.
3. Enter your contact details (name, email, and phone number).
4. Enter any additional customer notes.
5. Select the start time for the event.

## Field-by-Field Explanation
* **Booking Date** (`booking_date`, date, required: false): Select the date you'd like to book the face painting event. If you need help with dates, you can refer to [Your Company's Date Calendar].
* **Event Details** (`event_details`, select_multiple, required: false): Choose Yes to indicate that the event is happening or No to show that it's not.
* **Contact Details** (`contact_details`, text, required: false): Provide your name as the primary point of contact.
* **Contact E-mail** (`contact_email`, email, required: false): Enter your email address for communication.
* **Contact Phone** (`contact_phone`, text, required: false): Enter your phone number for communication.
* **Customer Name** (`customer_name`, text, required: false): Enter the customer's name if different from the contact person.
* **Customer Note** (`customer_note`, note, required: false): Add any additional information or notes for the customer.
* **Event Start Time** (`event_start_time`, time, required: false): Select the start time for the event.
