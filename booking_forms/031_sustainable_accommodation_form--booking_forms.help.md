# Sustainable Accommodation Form - Help Guide
## Purpose
The Sustainable Accommodation Form is designed to collect information about sustainable accommodations. It helps manage bookings, payments, and ratings, ensuring accurate and up-to-date data.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections and fields carefully.
2. Fill in the required fields (marked as required).
3. Enter accurate and relevant information for each field.
4. Double-check your entries before submission.

## Field-by-Field Explanation
* **Booking Details** (1, text, required/optional): Enter a brief description of the booking.
* **Host Name** (2, text, required/optional): Enter the host's name.
* **Start Date** (3, date, required/optional): Enter the start date of the booking in the format YYYY-MM-DD.
* **End Date** (4, date, required/optional): Enter the end date of the booking in the format YYYY-MM-DD.
* **Accommodation Address** (5, text, required/optional): Enter the address of the accommodation.
* **Start Time** (6, time, required/optional): Enter the start time of the booking in 24-hour format (e.g., 14:00).
* **End Time** (7, time, required/optional): Enter the end time of the booking in 24-hour format (e.g., 16:00).
* **Accommodation Name** (8, text, required/optional): Enter the name of the accommodation.
* **Host Message** (9, text, required/optional): Enter a message for the host.
* **Booking Status** (10, select_one, required/optional): Select the booking status (Pending, Confirmed, Cancelled).
* **Accommodation Type** (11, select_multiple, required/optional): Select the type of accommodation (Eco-Lodges, Green Hotels, Sustainable Villas).
* **Guest Message** (12, note, required/optional): Enter a note for the guest.
* **Host Phone** (13, text, required/optional): Enter the host's phone number.
* **Host Email** (14, email, required/optional): Enter the host's email address.
* **Accommodation URL** (15, text, required/optional): Enter the URL of the accommodation.
* **Host Website** (16, text, required/optional): Enter the host's website.
* **Accommodation Phone** (17, text, required/optional): Enter the accommodation's phone number.
* **Accommodation URL** (18, text, required/optional): This field appears to be a duplicate of the previous one (Accommodation Phone). Please disregard this field.
* **Payment Status** (19, select_one, required/optional): Select the payment status (Paid, Pending, Cancelled).
* **Payment Method** (20, select_multiple, required/optional): Select the payment method (Stripe, PayPal, Bank Transfer).
* **Payment Note** (21, text, required/optional): Enter a note for the payment.
* **Booking Notes** (22, text, required/optional): Enter notes for the booking.
* **Accommodation Image** (23, text, required/optional): Enter an image URL or description for the accommodation.
* **Accommodation Rating** (24, select_one, required/optional): Select the rating of the accommodation (1/5, 2/5, 3/5, 4/5, 5/5).
* **Host Note** (25, text, required/optional): Enter a note for the host.

## Tips
* Be accurate and complete in your entries.
* Double-check your information before submission.
* Avoid duplication of fields with similar labels.
