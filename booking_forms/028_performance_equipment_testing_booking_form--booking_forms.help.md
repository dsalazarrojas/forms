# Performance Equipment Testing Booking Form - Help Guide
## Purpose
The Performance Equipment Testing Booking Form is used to request and manage performance equipment testing sessions. This form helps users to provide necessary information for the test request, including equipment type, test location, and test status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Test Request Details field with a brief description of the test request.
2. Select the Test Date for when the test is scheduled to take place.
3. Choose the Start Time and End Time for the test session.
4. Enter the Test Duration in the required number format.
5. Select the Equipment Type from the provided options (Testing Equipment, Calibration Equipment, or Inspection Equipment).
6. Choose the Test Location from the options provided (Test Room 1, Test Room 2, Test Room 3).
7. Select the Test Equipment required for the test session.
8. Choose the Test Status as In Progress, Completed, or Cancelled.
9. Enter any Test Notes and Booking Notes if necessary.
10. If applicable, fill in the Requestor's Name, Contact Number, Email, and Department.
11. If applicable, select the Assignee's Name, Contact Number, Email, and fill in the Assigned Date.
12. Set the Priority as High, Low, or Medium.
13. Set the Status as Open, In Progress, or Closed.
14. Fill in the Submitted By, Submitted Date, and Submitted Time if applicable.

## Field-by-Field Explanation

* **Test Request Details**: A brief description of the test request.
* **Test Date**: The date on which the test is scheduled to take place.
* **Start Time**: The start time of the test session.
* **End Time**: The end time of the test session.
* **Test Duration**: The duration of the test session in number format.
* **Equipment Type**: The type of equipment required for the test session.
	+ Testing Equipment
	+ Calibration Equipment
	+ Inspection Equipment
* **Test Location**: The location where the test will take place.
	+ Test Room 1
	+ Test Room 2
	+ Test Room 3
* **Test Equipment**: The equipment required for the test session.
* **Test Status**: The status of the test session.
	+ In Progress
	+ Completed
	+ Cancelled
* **Test Notes**: Additional information or notes for the test session.
* **Booking Notes**: Additional information or notes for the test request.
* **Requestor Name**: The name of the person requesting the test session.
* **Requestor Contact Number**: The contact number of the person requesting the test session.
* **Requestor Email**: The email of the person requesting the test session.
* **Requestor Department**: The department of the person requesting the test session.
* **Assignee Name**: The name of the staff member assigned to the test session.
* **Assignee Contact Number**: The contact number of the staff member assigned to the test session.
* **Assignee Email**: The email of the staff member assigned to the test session.
* **Assigned Date**: The date on which the test was assigned to the staff member.
* **Due Date**: The date by which the test session is due to be completed.
* **Priority**: The level of priority for the test session.
	+ High
	+ Low
	+ Medium
* **Status**: The status of the test session.
	+ Open
	+ In Progress
	+ Closed
* **Submitted By**: The name of the person who submitted the test request.
* **Submitted Date**: The date on which the test request was submitted.
* **Submitted Time**: The time at which the test request was submitted.

## Tips
* Ensure that all required fields are filled in accurately to avoid delays.
* Review each field carefully to ensure that you are entering the correct information.
* If you have any questions or concerns, contact the relevant personnel.
