# Recreational Facility Check Out Form - Help Guide
## Purpose
The Recreational Facility Check Out Form is designed to help facility staff manage and track the usage of recreational facilities such as pool tables, game tables, and other equipment.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User ID number to identify yourself
2. Select the Facility ID of the facility where the equipment is located
3. Choose the equipment being checked out (if applicable)
4. Enter the start and end dates of the reservation
5. Select the start and end times of the reservation
6. Enter the duration of the reservation (if not using specific start and end times)
7. Add any comments or notes about the reservation

## Field-by-Field Explanation

* **User ID**: Enter your personal identification number to associate with this booking.
* **Facility ID**: Choose the unique identifier for the facility where the equipment is located.
* **Equipment ID** (if applicable): Select the specific equipment you would like to book.
* **Start Date**: Enter the date you would like to start using the facility.
* **End Date**: Enter the date you would like to end using the facility.
* **Reservation Start Time**: Enter the time you would like to start using the facility.
* **Reservation End Time**: Enter the time you would like to end using the facility.
* **Reservation Duration**: If you're using specific start and end times, you can skip this field. Otherwise, enter the duration of your reservation.
* **Comments**: Add any additional notes or comments about your reservation.
