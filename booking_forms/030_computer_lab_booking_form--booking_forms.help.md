# Computer Lab Booking Form - Help Guide
## Purpose
The Computer Lab Booking Form is designed to reserve computer lab space and resources for users. This form is used to gather essential information to ensure proper allocation of lab space and resources during the requested time slot.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter your name as the requester.
2.  Specify the name of the organization or course you are representing.
3.  Choose a date for the booking.
4.  Select the start and end times for the booking.
5.  Indicate the number of computers required.
6.  If required, specify any special equipment needed for the booking.
7.  Enter a contact phone number for the day of the booking.

## Field-by-Field Explanation

* **Requester Name** (id: 2, required: True): Enter the name of the person booking the computer lab space.
* **Organization or Course** (id: 3, required: False): Enter the name of the organization or course you are representing. If not applicable, leave this field blank.
* **Date of Booking** (id: 4, required: True): Choose a date for the booking from the available dates.
* **Start Time** (id: 5, required: True): Select the start time for the booking.
* **End Time** (id: 6, required: True): Select the end time for the booking.
* **Number of Computers Needed** (id: 7, required: True): Specify the quantity of computers required for the booking.
* **Special Equipment** (id: 8, required: False): If any special equipment is needed (e.g. projectors, adapters, etc.), enter the details here. Leave this field blank if no special equipment is required.
* **Contact Phone** (id: 9, required: False): Enter a contact phone number for the day of the booking. This is for the purpose of contacting the requester in case of any last-minute adjustments. Leave this field blank if not applicable.
