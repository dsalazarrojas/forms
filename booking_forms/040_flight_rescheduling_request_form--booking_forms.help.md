# Flight Rescheduling Request Form - Help Guide
## Purpose
This form is used to submit flight rescheduling requests. Please fill out this form with the necessary details for your request to be processed.

## How To Complete This Form
* Read the form carefully before submitting it.
* Make sure you have all the required information before starting.
* Fill out all the required fields (indicated by *).

## Field-by-Field Explanation

* **Flight Info** (Flight Info, text, required/optional): This field is used to enter the flight number or code for which you are requesting a reschedule.
* **Passenger Information** (Passenger Information, text, required/optional): Enter the passenger(s) name(s) and contact details here.
* **Contact Info** (Contact Info, text, *): This field is required to provide your or your representative's contact information so we can get in touch with you.
* **Airline** (Airline, text, *): Please enter the name of the airline operating the flight for which you are requesting a reschedule.
* **Flight Details** (Flight Details, select_multiple, *): Choose between 'Domestic' or 'International' flight type to help us understand the type of flight you are dealing with.
* **Travel Dates** (Travel Dates, date, *): Enter the original and new travel dates for which you are requesting a reschedule.
* **Travel Time** (Travel Time, time, *): Enter the original and new travel time for which you are requesting a reschedule.
* **Reason For Reschedule** (Reason For Reschedule, text, *): Provide a brief explanation for your reschedule request.
* **Flight Number** (Flight Number, text, *): Enter the unique flight number for which you are requesting a reschedule.
* **Flight Status** (Flight Status, text, optional): If you have any information about the current flight status, please provide it here. (Note: This field is not required but helps us understand the context of your request.)
* **Airline Phone** (Airline Phone, text, optional): If you have any contact number of the airline, please provide it here. (Note: This field is not required but helps us contact the airline.)
* **Airline Email** (Airline Email, email, optional): If you have any email contact of the airline, please provide it here. (Note: This field is not required but helps us contact the airline.)
* **Airline URL** (Airline URL, text, optional): If you have any website URL of the airline, please provide it here. (Note: This field is not required but helps us find more information about the airline.)
* **Airline Fax** (Airline Fax, text, optional): If you have any fax number of the airline, please provide it here. (Note: This field is not required but helps us contact the airline.)
* **Airline Address** (Airline Address, text, optional): If you have any physical address of the airline, please provide it here. (Note: This field is not required but helps us contact the airline.)

Note: This help guide provides an overview of the form's purpose and instructions on how to complete it. The field-by-field explanations are provided to ensure that the user understands each required field and its relevance to the form's purpose. The fields marked as optional are intended to provide additional information but are not mandatory for the rescheduling request to be processed.
