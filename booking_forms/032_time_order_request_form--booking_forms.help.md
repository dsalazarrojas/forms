# time_order_request_form - Help Guide

## Purpose
The Time Order Request Form is designed to help staff request time orders to track and manage their time and work.

## How To Complete This Form

1. Fill out the form by typing in the required and optional fields, making sure to select the correct Category and Form ID if applicable.
2. Review each field to ensure that it is filled out correctly and accurately represents your request.

## Field-by-Field Explanation

* **Time Order Request Form**: This field is for the title of the time order request form. Please enter a descriptive title that will help identify the request. (text, required: false)
* **Category**: Please select the Category for your time order request from the dropdown list. This will help to determine which forms are relevant to your request. (select_one, required: true)
* **Description**: Enter a brief description of your time order request here. This will help the approver understand the reason for the request. (text, required: false)
* **Assigned Tool**: Enter the tool that you are requesting time on. (text, required: false)
* **Form IDs**: Enter the IDs of any additional forms that you are requesting, separated by commas. This field is only visible when Category is set to "Booking Forms". (number, required: false)

## Tips

* Make sure to review the form carefully before submitting it to ensure that all information is accurate and complete.
* If you are unsure about any of the fields, please consult with your team or supervisor for clarification.
* If you need to request multiple forms, please separate the Form IDs with commas in the Form IDs field.
