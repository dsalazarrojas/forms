# Fitness Centre Booking Form - Help Guide

## Purpose
This form is for booking a fitness class at a fitness centre. To use this form, please fill out the required fields to complete the booking process.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the required fields with accurate information.
* If you are booking on behalf of another person, fill out their information as well.
* Select the available payment method and add any additional information if required.
* Add any necessary notes or comments for the staff.

## Field-by-Field Explanation

* **Class Booking Date** (class_booking_date, date, required: false): Please select the date you would like to book the class for.
* **Class Booking Time** (class_booking_time, time, required: false): Please select the time slot you would like to book the class for.
* **Customer Name** (customer_name, text, required: false): Please enter the customer's name.
* **Customer Email** (customer_email, email, required: false): Please enter the customer's email address.
* **Customer Phone** (customer_phone, text, required: false): Please enter the customer's phone number.
* **Class Booking Time Slots** (class_booking_time_slots, text, required: false): Please select the time slots available for the class.
* **Session Length** (session_length, number, required: false): Please select the length of the class session.
* **Number of Sessions** (number_of_sessions, number, required: false): Please select the number of sessions you would like to book.
* **Class Booking Status** (class_booking_status, select_one, required: false): Please select the status of the class booking (Available, Booked, Cancelled).
* **Payment Method** (payment_method, select_one, required: false): Please select the payment method (Cash, Credit Card, Bank Transfer).
* **Payment Method Additional Info** (payment_method_additional_info, note, required: false): Please add any additional information for the payment method if required.
* **Class Booking Notes** (class_booking_notes, note, required: false): Please add any notes for the class booking.
* **Customer Notes** (customer_notes, note, required: false): Please add any notes for the customer.
* **Class Booking Comments** (class_booking_comments, note, required: false): Please add any comments for the class booking.
