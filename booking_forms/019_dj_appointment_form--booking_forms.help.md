# DJ Appointment Form - Help Guide
## Purpose
This form is designed to collect information for a DJ event, including its date, time, duration, details, client information, and other relevant details. The form is likely used by DJs or event organizers to gather necessary information for events they are hosting or have been hired to perform at.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Event Date and Time in the correct format (YYYY-MM-DD for date and HH:MM for time).
2. Enter the Event Duration (number of hours or minutes the event will last).
3. Provide a detailed description of the event in the Event Details field.
4. Enter the Client's Name and contact information in the Client Name and Client Contact fields.
5. Enter the Event Location where the event will take place.
6. Add any additional notes about the event in the Event Notes field.
7. Enter the DJ's Name and contact information in the DJ Name and DJ Contact fields.
8. Finally, enter the Event Start and End Dates in the correct format (YYYY-MM-DD for date).

## Field-by-Field Explanation
* **Event Date** (event_date): Enter the date of the event. This field should be in the format (YYYY-MM-DD).
* **Event Time** (event_time): Enter the start time of the event. This field should be in the format HH:MM.
* **Event Duration** (event_duration): Enter the number of hours or minutes the event will last.
* **Event Details** (event_details): Provide a detailed description of the event.
* **Client Name** (client_name): Enter the client's name.
* **Client Contact** (client_contact): Enter the client's contact information.
* **Event Location** (event_location): Enter the location where the event will take place.
* **Event Notes** (event_notes): Add any additional notes about the event.
* **DJ Name** (dj_name): Enter the DJ's name.
* **DJ Contact** (dj_contact): Enter the DJ's contact information.
* **Event Start Date** (event_start): Enter the start date of the event. This field should be in the format (YYYY-MM-DD).
* **Event End Date** (event_end): Enter the end date of the event. This field should be in the format (YYYY-MM-DD).
