# Event Venue Pre-Inspection Form - Help Guide
## Purpose
This form is designed to collect information about an event venue's general information, safety procedures, accessibility features, venue equipment, and event planning. The collected information will be used by venue managers to prepare for events and ensure a safe and accessible environment for guests.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form sections carefully and answer all required questions.
2. For each field, provide clear and concise answers.
3. Be sure to answer all questions truthfully and accurately.

## Field-by-Field Explanation
### General Information
* **Venue Name** (`name`, text, required): Enter the name of the venue.
* **Address** (`address`, text, required): Enter the address of the venue.
* **Contact Information** (`contact_information`, text, required): Enter the contact information of the venue.

### Safety Procedures
* **Emergency Exit Route** (`emergency_exit_route`, text, required): Describe the emergency exit route in the venue.
* **Fire Safety Procedures** (`fire_safety_procedures`, text, required): Describe the fire safety procedures in the venue.
* **First Aid Facilities** (`first_aid_facilities`, text, required): Describe the first aid facilities available in the venue.

### Accessibility Features
* **Accessibility Entrances** (`accessibility_entrances`, text, required): Describe the accessibility entrances in the venue.
* **Wheelchair Accessible Areas** (`wheelchair_accessible_areas`, text, required): Describe the wheelchair accessible areas in the venue.
* **Accessible Restrooms** (`accessible_restrooms`, text, required): Describe the accessible restrooms in the venue.

### Venue Equipment
* **Sound and Audio Equipment** (`sound_and_audio_equipment`, text, required): Describe the sound and audio equipment available in the venue.
* **Stage and Lighting Equipment** (`stage_and_lighting_equipment`, text, required): Describe the stage and lighting equipment available in the venue.

### Event Planning
* **Event Schedule** (`event_schedule`, text, required): Describe the event schedule.
* **Event Layout** (`event_layout`, text, required): Describe the event layout.
* **Technical Requirements** (`technical_requirements`, text, required): Describe the technical requirements for the event.

## Tips
* Be sure to answer all questions truthfully and accurately.
* Review the form carefully before submitting.
* If you are unsure about any question, contact the venue manager for clarification.
