# Club Event Tent And Flag Order Form - Help Guide
## Purpose
The Club Event Tent And Flag Order Form is used to collect information for booking events at the club, including dates, locations, event organizers, and rental requests for tents and flags.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the order date for the event.
2. Enter the name of the club or organization hosting the event.
3. Enter the name of the event organizer, including their name and email address.
4. Enter the name of the event, including a brief description.
5. Specify the date and time of the event.
6. Enter the setup and teardown times for the event.
7. Provide the full address or campus location of the event.
8. Specify the number of tents needed for the event.
9. Choose the preferred tent size for the event.
10. Enter the number of flags needed for the event.
11. Choose the type of flags needed for the event.
12. If custom flags are required, select the type of customization needed.
13. Specify the weather contingency plan in case of bad weather.
14. Enter the total rental cost for the event.
15. Choose the payment method for the event.

## Field-by-Field Explanation

* **Order Date** (`order_date`, date, required): Enter the date you would like to book the event on.
* **Club Name** (`club_name`, text, required): Enter the name of the club or organization hosting the event.
* **Event Organizer Name** (`organizer_name`, text, required): Enter the name of the person organizing the event.
* **Event Organizer Email** (`organizer_email`, email, required): Enter the email address of the event organizer.
* **Organizer Phone** (`organizer_phone`, text, required): Enter the phone number of the event organizer.
* **Event Name** (`event_name`, text, required): Enter a brief description of the event.
* **Event Date** (`event_date`, date, required): Enter the date of the event.
* **Setup Start Time** (`event_start_time`, time, required): Enter the start time for setting up the event.
* **Teardown End Time** (`event_end_time`, time, required): Enter the end time for tearing down the event.
* **Event Location** (`event_location`, text, required): Enter the full address or campus location of the event.
* **Number of Tents Needed** (`tent_quantity`, number, required): Enter the number of tents needed for the event.
* **Tent Size Preference** (`tent_size`, select_one, required): Choose the preferred size for the tents.
* **Number of Flags Needed** (`flag_quantity`, number, required): Enter the number of flags needed for the event.
* **Flag Type** (`flag_type`, select_one, required): Choose the type of flags needed for the event.
* **Flag Customization or Printing** (`flag_customization`, select_one, required): Select if custom flags are needed.
* **Weather Contingency Plan** (`weather_backup`, select_one, required): Specify the plan in case of bad weather.
* **Total Rental Cost** (`total_rental_cost`, number, required): Enter the total rental cost for the event.
* **Payment Method** (`payment_method`, select_one, required): Choose the method of payment for the event.
