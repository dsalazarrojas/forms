# studio_access_reschedule_request_form - Help Guide
## Purpose
The studio_access_reschedule_request_form is used to request rescheduling of a studio access.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the User Details section with your personal information.
2. In the New Booking Details section, provide the new booking details after rescheduling.
3. In the Why Reschedule? section, briefly explain the reason for rescheduling.

## Field-by-Field Explanation
### User Details
* **User Details**: This is a text field where you should enter your name and any other personal information that we need to know about you.

### New Booking Details
* **New Booking Details**: This is a text field where you should enter the new booking details after rescheduling, such as the new date, time, or any other relevant information.

### Why Reschedule?
* **Why Reschedule?**: This is a text field where you should explain the reason for rescheduling. This will help us understand the circumstances and process your request efficiently.

## Tips
* Make sure to fill out all required fields.
* If you have any questions or issues, please contact us at form@gic.mx.
* We will review your request and get back to you as soon as possible.
