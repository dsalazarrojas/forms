# housing_cart_reservation_form - Help Guide

## Purpose
The housing_cart_reservation_form is used to collect information from guests who are making a reservation for a housing cart.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the guest's name in the "Guest Name" field. This is a required field.
2. Enter the guest's email address in the "Guest Email" field.
3. Select the start date of the reservation in the "Start Date" field.
4. Select the end date of the reservation in the "End Date" field.
5. Select the start time of the reservation in the "Start Time" field.
6. Select the end time of the reservation in the "End Time" field.
7. Enter the duration of the reservation in the "Duration" field.
8. Select the facility required for the reservation from the "Facility" dropdown menu.
9. Select the equipment required for the reservation from the "Equipment" dropdown menu. Note that this field allows for multiple selections.
10. Enter any additional message or comment in the "Message" field.

## Field-by-Field Explanation

* **Guest Name**: Enter the guest's name.
* **Guest Email**: Enter the guest's email address.
* **Start Date**: Select the start date of the reservation.
* **End Date**: Select the end date of the reservation.
* **Start Time**: Select the start time of the reservation.
* **End Time**: Select the end time of the reservation.
* **Duration**: Enter the duration of the reservation.
* **Facility**: Select the facility required for the reservation from the options provided.
* **Equipment**: Select the equipment required for the reservation from the options provided. Note that multiple selections are allowed.
* **Message**: Enter any additional message or comment about the reservation.
