# wildlife_photographer_accommodation_form - Help Guide
## Purpose
This form is for booking a photographer's accommodation for your specific photography-related needs. Please fill out this form carefully to ensure that your requirements are met.

## How To Complete This Form
To fill out this form, please go through each page carefully and provide the required information.

## Field-by-Field Explanation
* **Arrival Date** (`arrival_date`, date, required: false): Please select the date you plan to arrive at the accommodation.
* **Arrival Time** (`arrival_time`, time, required: false): Select the time you plan to arrive at the accommodation.
* **Accommodation Type** (`accommodation_type`, select_one, required: false): Choose whether you prefer a 'Yes' or 'No' accommodation type.
* **Other Accommodation Type** (`accommodation_type_other`, text, required: false): If you have a specific accommodation type that is not listed, please enter it here.
* **Accommodation Preferences** (`accommodation_preferences`, select_multiple, required: false): Please select your accommodation preferences. You can select multiple options.
	+ **Private room** (`accommodation_preferences_1`, select_one, required: false): Select whether you prefer a private room.
	+ **Shared room** (`accommodation_preferences_2`, select_one, required: false): Select whether you prefer a shared room.
	+ **Accommodation Preferences 3** (`accommodation_preferences_3`, select_one, required: false): Select your preference for this option.
	+ **Smoking allowed** (`accommodation_preferences_4`, select_one, required: false): Select whether smoking is allowed in the accommodation.
	+ **Accommodation Preferences 5** (`accommodation_preferences_5`, select_one, required: false): Select your preference for this option.
	+ **Pet allowed** (`accommodation_preferences_6`, select_one, required: false): Select whether pets are allowed in the accommodation.
	+ **Accommodation Preferences 7** (`accommodation_preferences_7`, select_one, required: false): Select your preference for this option.
	+ **Accommodation Preferences 8** (`accommodation_preferences_8`, select_one, required: false): Select your preference for this option.
	+ **Accommodation Preferences 9** (`accommodation_preferences_9`, select_one, required: false): Select your preference for this option.
	+ **Accommodation Preferences 10** (`accommodation_preferences_10`, select_one, required: false): Select your preference for this option.
* **Special Requests** (`special_requests`, text, required: false): If you have any special requests, please enter them here.
* **Special Requests Input** (`special_requests_input`, text, required: false): If you have any additional information about your special requests, please enter it here.
* **Special Requests 1** (`special_requests_1`, select_one, required: false): Select whether this is a yes or no for this request.
* **Special Requests 2** (`special_requests_2`, select_one, required: false): Select whether this is a yes or no for this request.
