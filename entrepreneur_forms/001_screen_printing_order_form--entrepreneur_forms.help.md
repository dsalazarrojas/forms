# Screen Printing Order Form - Help Guide
## Purpose
The Screen Printing Order Form is a comprehensive form used to capture all the necessary details for a screen printing order.

## How To Complete This Form
To complete the form, please follow these steps:

1.  Fill in the customer information section with the customer's details.
2.  Select the order summary options that apply to your order.
3.  Enter the customer's address in the customer address section.
4.  Enter the shipping address in the shipping address section.
5.  Choose the payment method from the payment information section.
6.  Add any additional order notes in the order notes section.
7.  Enter the total cost of the order.
8.  Set the payment status of the order.

## Field-by-Field Explanation

*  **Customer Information (id: 1)**: A text field where the customer's name, contact, and other relevant information will be entered.
    \- Type: Text
    \- Required: No
*  **Order Summary (id: 2)**: A multiple-select field where the order summary options will be selected.
    \- Type: Select Multiple
    \- Required: No
*  **Customer Address (id: 3)**: A text field where the customer's address will be entered.
    \- Type: Text
    \- Required: No
*  **Shipping Address (id: 4)**: A text field where the shipping address will be entered.
    \- Type: Text
    \- Required: No
*  **Payment Information (id: 5)**: A single-select field where the payment method will be chosen.
    \- Type: Select One
    \- Required: No
*  **Order Notes (id: 6)**: A note field where additional order information can be added.
    \- Type: Note
    \- Required: No
*  **Order Total (id: 7)**: A number field where the total cost of the order will be entered.
    \- Type: Number
    \- Required: No
*  **Payment Status (id: 8)**: A single-select field where the payment status will be set.
    \- Type: Select One
    \- Required: No

## Tips

*   Use this form for any screen printing order to ensure all necessary details are captured.
*   Make sure to select all applicable order summary options.
*   Enter accurate customer and shipping addresses.
*   Choose the correct payment method.
*   Set the correct payment status after the order is processed.
