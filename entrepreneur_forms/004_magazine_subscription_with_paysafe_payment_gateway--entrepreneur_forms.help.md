# Magazine Subscription With Paysafe Payment Gateway - Help Guide
## Purpose
This form is used for managing magazine subscriptions with the Paysafe payment gateway.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the required fields (indicated by *) with the necessary information.
2. Review each field carefully to ensure accuracy and completeness.
3. Submit the form once you have filled out all the necessary fields.

## Field-by-Field Explanation

* **First Name** (1, text, *): Enter the customer's first name.
* **Last Name** (2, text, *): Enter the customer's last name.
* **Email** (3, email, *): Enter the customer's email address.
* **Phone** (4, text, *): Enter the customer's phone number.
* **Payment Method** (5, select_one): Select the payment method for the subscription (e.g., Visa, Mastercard, Discover, American Express, or Paysafe).
* **Other** (6, text, ): This field is for selecting an alternative payment method that is not listed in the previous field. This should only be used if none of the listed payment methods are applicable.
* **Order ID** (7, number, ): Enter the order ID for the subscription (this field is not required for creating a new subscription but might be necessary for updates).
* **Subscription Term** (8, select_multiple): Select the subscription term (e.g., 1, 2, 3, or 4).
* **Billing Cycle** (9, select_one): Select the billing cycle (e.g., Monthly, Quarterly, or Yearly).
* **Billing Frequency** (10, select_one): Select how often the subscription will be billed (e.g., Monthly, Quarterly, or Yearly).
* **Start Date** (11, date, *): Enter the start date of the subscription.
* **Start Time** (12, time, ): Enter the start time of the subscription (if applicable).
* **End Date** (13, date, ): Enter the end date of the subscription (if applicable).
* **End Time** (14, time, ): Enter the end time of the subscription (if applicable).
* **Subscription Status** (15, select_one): Select the subscription status (e.g., Active, Inactive, or Canceled).
* **Notes** (16, note, ): Add any additional notes about the subscription.
* **Form Submission Date** (17, date, ): This field is not editable and displays the date when the form was submitted.
* **Total Amount** (18, number, ): Enter the total amount of the subscription (if applicable).
* **Billing Address** (19, select_multiple): Select whether the billing address is a Billing, Shipping, or Residential address.
* **Billing Postal Code** (20, number, ): Enter the billing postal code (zip code).
* **Order Number** (21, number, ): Enter the order number.
* **Subscription Start Date** (22, date, ): Enter the start date of the subscription.
* **Subscription End Date** (23, date, ): Enter the end date of the subscription.
* **Subscription Cycle** (24, select_one): Select the subscription cycle (e.g., Month, Quarter, or Year).
* **Assigned Tool** (25, text, ): Enter the assigned tool name.

Note: This guide assumes that the fields without a * are not required.
