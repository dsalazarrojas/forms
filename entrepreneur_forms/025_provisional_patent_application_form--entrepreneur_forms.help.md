# Provisional Patent Application Form - Help Guide
## Purpose
The Provisional Patent Application Form is designed to collect essential information from applicants interested in filing a provisional patent application. This form helps to streamline the patent application process by gathering details about the invention, the applicant, and the application type.

## How To Complete This Form
- Read each section carefully and answer all questions truthfully.
- Ensure all required fields are filled out.
- For fields with options, select the most accurate choice.
- If you are unsure about any field, ask for clarification or seek advice from a qualified professional.
- Double-check your answers for accuracy before submitting.

## Field-by-Field Explanation

### Application Type
- **Application Type** (`application_type`, select_one, required: false): 
  Indicate whether this is a new invention or an updated application. Choose 'Yes' for a new application or 'No' for an updated application.

### Invention Name
- **Invention Name** (`invention_name`, text, required: false): 
  Enter a brief description of the invention, including its name and any relevant details.

### Applicant Name
- **Applicant Name** (`applicant_name`, text, required: false): 
  Enter your full name as the applicant.

### Applicant Address
- **Applicant Address** (`applicant_address`, text, required: false): 
  Enter your full address as the applicant.

### Invention Description
- **Invention Description** (`invention_description`, text, required: false): 
  Provide a detailed description of the invention, including its purpose, function, and any relevant technical details.

### Invention Image
- **Invention Image** (`invention_image`, text, required: false): 
  You can upload images or provide a link to an image of the invention if it's relevant for the application.

## Tips
- Double-check all fields for accuracy and completeness before submitting.
- If you need help or have questions, don't hesitate to ask.
- This form is not a substitute for legal advice, and you should seek advice from a qualified professional before proceeding with the patent application.
