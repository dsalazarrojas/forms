# Free Project Proposal - Help Guide
## Purpose
This guide will walk you through the process of completing the "Free Project Proposal" form. The form is designed to gather essential details about a project that requires funding or resources without a specific budget allocated.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter a unique title for your project in the "Project Name" field.
2. Provide a brief description of the project in the "Project Description" field.
3. Enter the start and end dates of the project in the "Start Date" and "End Date" fields, respectively.
4. Specify the project lead in the "Project Lead" field.
5. Indicate whether you have a team for the project in the "Team Members" field.
6. Enter a total budget for the project in the "Budget" field.
7. Select the current project status in the "Project Status" field.
8. Add any project notes in the "Project Notes" field.
9. Enter your email address in the "Email" field.

## Field-by-Field Explanation
* **Project Name** (`project_name`, text, required: false): Enter a unique and descriptive name for your project.
* **Project Description** (`project_description`, text, required: false): Briefly describe the project, including its objectives, goals, and any relevant details.
* **Start Date** (`start_date`, date, required: false): Enter the date when the project is expected to start.
* **End Date** (`end_date`, date, required: false): Enter the date when the project is expected to end.
* **Project Lead** (`project_lead`, text, required: false): Specify the person responsible for leading the project.
* **Team Members** (`team_members`, select_multiple, required: false): Check the box if you have a team for the project.
* **Budget** (`budget`, number, required: false): Provide a total budget for the project, including any expenses or resources required.
* **Project Status** (`project_status`, select_one, required: false): Select the current status of the project, either "Active" or "Inactive".
* **Project Notes** (`project_notes`, note, required: false): Add any additional information or comments about the project.
* **Email** (`email`, email, required: false): Enter your email address for contact purposes.
