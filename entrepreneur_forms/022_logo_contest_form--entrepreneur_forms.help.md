# Logo Contest Form - Help Guide
## Purpose
The Logo Contest Form is designed to gather information about a logo upload, including the type, date, and size of the logo, as well as its upload result and file size. This form helps in organizing and categorizing logos uploaded to the system.

## How To Complete This Form
To complete the Logo Contest Form, follow these steps:

1.  **Upload a logo file**: Select a file from your computer and upload it to the system.
2.  Choose the type of logo: Select the type of logo you are uploading from the provided options (Iconic, Logotype, or Badge).
3.  Specify the upload date: Enter the date you uploaded the logo.
4.  Select the upload result: Choose how the upload went (Success, Error, or Warning).
5.  Enter logo URL (optional): If you want to provide a URL for the uploaded logo, enter it here.
6.  Specify the logo size: Choose the size of the uploaded logo from the provided options (Small, Medium, or Large).
7.  Select logo color: Choose the color of the logo from the provided options (Black, White, or Grey).
8.  Enter logo width and height: Enter the width and height of the logo in pixels.
9.  Enter logo file size: Enter the size of the uploaded logo file.

## Field-by-Field Explanation
* **Upload Logo**: Upload a logo file from your computer to the system.
* **Logo Type**: Select the type of logo you are uploading from the options:
	+ **Iconic**: A small, simplified representation of a symbol or logo.
	+ **Logotype**: A text-based logo.
	+ **Badge**: An emblem or icon that represents a brand or organization.
* **Contest Date**: Enter the date you uploaded the logo.
* **Upload Result**: Choose how the upload went from the options:
	+ **Success**: The upload was successful.
	+ **Error**: There was an error during the upload.
	+ **Warning**: A warning message was displayed during the upload.
* **Logo URL**: Enter the URL of the uploaded logo, if applicable.
* **Logo Size**: Choose the size of the uploaded logo from the options:
	+ **Small**: A small-sized logo.
	+ **Medium**: A medium-sized logo.
	+ **Large**: A large-sized logo.
* **Logo Color**: Choose the color of the logo from the options:
	+ **Black**: A black-colored logo.
	+ **White**: A white-colored logo.
	+ **Grey**: A grey-colored logo.
* **Logo Width**: Enter the width of the logo in pixels.
* **Logo Height**: Enter the height of the logo in pixels.
* **Logo File Size**: Enter the size of the uploaded logo file in bytes.
