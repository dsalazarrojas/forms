# owner-operator-lease-contract-application-form - Help Guide
## Purpose
The owner-operator lease contract application form is a tool for business owners to submit a lease contract for a vehicle. This form is used to collect personal and vehicle information, as well as lease specifics, for administrative or operational purposes within a business context.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and relevant information.
2. Select the correct vehicle make and year from the options provided.
3. Enter the vehicle model and license state.
4. Provide the driver's name, license number, and vehicle ID number.
5. Enter the lease start and end dates, rental period, and lease status.
6. Select the lease type and term from the options provided.
7. Enter any additional notes or comments about the lease.

## Field-by-Field Explanation
* **Lease A Truck** (1, number, required): This field is where you enter the number of trucks to be leased.
* **Name** (2, text, required): Enter the name of the business or individual submitting the lease contract.
* **Address** (3, text, required): Enter the address of the business or individual submitting the lease contract.
* **Phone** (4, text, required): Enter the phone number of the business or individual submitting the lease contract.
* **Email** (5, email, required): Enter a valid email address associated with the business or individual submitting the lease contract.
* **Start Date** (6, date, required): Enter the start date of the lease.
* **End Date** (7, date, required): Enter the end date of the lease.
* **Note** (8, text, optional): Add any additional comments or notes about the lease.
* **Vehicle Make** (9, select_one, required): Select the make of the vehicle to be leased from the options provided (e.g., Ford, Dodge, Chevrolet).
* **Vehicle Year** (10, select_multiple, required): Select the year of the vehicle to be leased from the options provided (e.g., 2018, 2019, 2020).
* **Vehicle Model** (11, text, required): Enter the model of the vehicle to be leased.
* **License State** (12, select_one, required): Select the state where the vehicle will be licensed from the options provided (e.g., California, New York, Florida).
* **Driver Name** (13, text, required): Enter the name of the driver or owner of the vehicle.
* **Driver License Number** (14, text, required): Enter the driver's license number.
* **Vehicle Id Number** (15, text, required): Enter the vehicle's ID number.
* **Vehicle Insurance** (16, text, required): Enter the vehicle's insurance information.
* **Lease Start Date** (17, date, required): Enter the start date of the lease.
* **Lease End Date** (18, date, required): Enter the end date of the lease.
* **Rental Period** (19, text, required): Enter the rental period of the vehicle.
* **Rental Start Date** (20, date, required): Enter the start date of the rental.
* **Rental End Date** (21, date, required): Enter the end date of the rental.
* **Lease Type** (22, select_one, required): Select the type of lease from the options provided (e.g., Month, Month to Month, Week, Weekend, Weekday).
* **Lease Term** (23, select_multiple, required): Select the lease term from the options provided (e.g., 1 month, 3 months, 6 months).
* **Lease Status** (24, select_one, required): Select the current status of the lease from the options provided (e.g., Active, Expired, Cancelled).
* **Assigned Tool** (25, text, optional): Add any additional comments or notes about the lease or assigned tool.

## Tips

* Make sure to fill out all required fields accurately and completely.
* Double-check the vehicle make, year, and model to ensure accuracy.
* Verify the driver's license number and vehicle ID number.
* Ensure that the lease start and end dates are correctly entered.
* Review and select the correct lease type and term to avoid confusion.
* Check the lease status to ensure it accurately reflects the current state of the lease.
