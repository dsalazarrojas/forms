# Business Logo Submission Form - Help Guide
## Purpose
This form is designed to collect business logo information for design and approval processes.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully to ensure you are providing accurate and relevant information.
2. Enter your company name in the "Company name" field.
3. Enter the name of the person submitting the logo in the "Contact name" field.
4. Enter a valid email address for contact and communication in the "Contact email" field.
5. If you have specific file instructions for the logo submission, please enter them in the "Logo file instructions" field.
6. Describe the required color variants for the logo in the "Color variants" field.
7. Select where the logo will be used (Print, Web, Social media, Merchandise) in the "Usage contexts" field.
8. Decide if a tagline is to be included with the logo in the "Tagline included" field.
9. Provide any additional notes or design instructions in the "Additional notes" field.

## Field-by-Field Explanation
* **Company name** (`company_name`, text, required): Enter the name of your company to appear with the logo.
* **Contact name** (`contact_name`, text, required): Enter the name of the person submitting the logo.
* **Contact email** (`contact_email`, email, required): Enter a valid email address for contact and communication.
* **Logo file instructions** (`logo_file_instructions`, note, required): Provide any specific file instructions for the logo submission.
* **Color variants** (`color_variants`, text, optional): Describe the required color variants for the logo.
* **Usage contexts** (`usage_contexts`, select multiple, optional): Select where the logo will be used (Print, Web, Social media, Merchandise).
* **Tagline included** (`tagline_included`, select one, optional): Decide if a tagline is to be included with the logo.
* **Additional notes** (`additional_notes`, text, optional): Provide any additional notes or design instructions for the logo.
