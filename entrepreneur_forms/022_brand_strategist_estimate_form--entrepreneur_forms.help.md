# Brand Strategist Estimate Form - Help Guide
## Purpose
This form is designed to collect essential information for estimating the cost and timeline of a project, as well as ensuring the client's acceptance of the estimate.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the client's name and project scope.
2. Enter the estimated total hours and hourly rate for the project.
3. Provide a brief description of the key deliverables to be provided.
4. Estimate the project timeline.
5. Enter the email address used to send the acceptance email to the client.
6. Review the form for accuracy and completeness before submission.

## Field-by-Field Explanation

* **Client name**: This is the name of the client or company you will be working with. This is a required field, so please fill it out as accurately as possible. (id: 1)
* **Project scope**: Briefly describe the scope of the project. This will help us understand the extent of the work involved. (id: 2)
* **Estimated hours**: This is the total number of hours you estimate will be spent on the project. If this is not a required field, please fill it out if you have an estimate. (id: 3)
* **Hourly rate**: This is your consultant's hourly rate in the local currency. This is a required field, so please fill it out accurately. (id: 4)
* **Total estimate**: If you have estimated the total cost of the project, please enter it here. If not, leave this field blank. (id: 5)
* **Deliverables**: Describe the key deliverables of the project, such as reports, presentations, or other items that will be provided to the client. This is an optional field, so feel free to fill it out if it applies. (id: 6)
* **Timeline**: Estimate the timeline for the project, including any key milestones or deadlines. This is an optional field, so fill it out if it's relevant to the project. (id: 7)
* **Acceptance email**: Enter the email address to which you will send the acceptance email to the client. This is a required field, so please make sure to enter it accurately. (id: 8)
