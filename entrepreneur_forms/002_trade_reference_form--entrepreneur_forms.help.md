# Trade Reference Form - Help Guide
## Purpose
The Trade Reference Form is a crucial document used to collect and store information about a trade. This form is used to create a comprehensive overview of the trade, including details such as contact information, address, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the trade before starting.
2. Enter the trade name in the "Trade Name" field if applicable.
3. Enter the trade address in the "Trade Address" field.
4. Enter the trade contact information, including phone number and email, in their respective fields.
5. Select the reference status (Active or Inactive) in the "Reference Status" field.
6. Enter the reference name and title in their respective fields.
7. Enter the reference description (if applicable).
8. Select the reference date and time in the "Reference Date" and "Reference Time" fields.
9. Enter the reference URL (if applicable).
10. Select the reference type (Yes or No) in the "Reference Type" field.
11. Enter the reference contact information, including phone number and email, in their respective fields.
12. Enter any additional reference notes (if applicable).
13. Click the "Submit" button to complete the form.

## Field-by-Field Explanation
* **Trade Reference Form** (`trade_reference_form`, text, required/optional): This field is the title of the form.
* **First Name** (`first_name`, text, required): Enter the first name of the trade contact person.
* **Last Name** (`last_name`, text, required): Enter the last name of the trade contact person.
* **Address** (`address`, text, optional): Enter the trade address.
* **City** (`city`, text, optional): Enter the trade city.
* **Region** (`region`, select multiple, required): Select multiple regions associated with the trade.
* **Country** (`country`, select one, required): Select the trade's country.
* **Reference Name** (`reference_name`, text, required): Enter the name of the reference.
* **Reference Title** (`reference_title`, text, required): Enter the title of the reference.
* **Reference Description** (`reference_description`, text, optional): Enter a brief description of the reference (if applicable).
* **Reference Date** (`reference_date`, date, required): Select the date of the reference.
* **Reference Time** (`reference_time`, time, required): Select the time of the reference.
* **Reference Phone** (`reference_phone`, text, optional): Enter the reference contact phone number.
* **Reference Email** (`reference_email`, email, optional): Enter the reference contact email.
* **Reference Address** (`reference_address`, text, required): Enter the reference address.
* **Reference URL** (`reference_url`, text, optional): Enter the reference URL.
* **Reference Type** (`reference_type`, select one, required): Select the type of reference (Yes or No).
* **Reference Status** (`reference_status`, select one, required): Select the status of the reference (Active or Inactive).
* **Reference Notes** (`reference_notes`, text, optional): Enter any additional reference notes.
* **Trade Name** (`trade_name`, text, optional): Enter the trade name (if applicable).
* **Trade Address** (`trade_address`, text, optional): Enter the trade address (if applicable).
* **Trade Phone** (`trade_phone`, text, optional): Enter the trade contact phone number (if applicable).
* **Trade Email** (`trade_email`, email, optional): Enter the trade contact email (if applicable).
* **Trade URL** (`trade_url`, text, optional): Enter the trade URL (if applicable).

## Tips
* Ensure all fields are filled out accurately and completely.
* Double-check the information before submitting the form.
* If you are unsure about any field, please consult with the relevant team or supervisor.
