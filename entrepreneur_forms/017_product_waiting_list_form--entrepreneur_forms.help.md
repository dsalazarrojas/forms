# Product Waiting List Form - Help Guide

## Purpose
This form is used to create and manage waiting lists for products, customers, and form-related information. It is intended to be filled out by authorized personnel to track and update product waiting lists.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "product_waiting_list" field and enter the product code or name you want to add to the waiting list.
2. Choose whether the product is on the waiting list for customers or not.
3. Enter the customer(s) who are waiting for the product, selecting multiple customers if needed.
4. Enter the quantity of the product being waited for.
5. Select the date and time when the product is expected to be available.
6. Add any additional comments or notes regarding the waiting list.
7. Optionally, select the user assigned to manage the waiting list.
8. Choose the status of the waiting list (Active or Inactive).
9. Select the priority level of the waiting list (Yes or No).
10. If applicable, select the tool assigned to the waiting list.
11. Enter the date the waiting list was created.
12. Enter the date the waiting list was last updated.
13. Enter the date the waiting list was deleted.
14. Select whether the waiting list was created by authorized personnel.
15. Select whether the waiting list was last updated by authorized personnel.
16. Select whether the waiting list was deleted by authorized personnel.
17. Enter the unique identifier of the waiting list.
18. Select the version of the waiting list form used to create this record.
19. Select the status of the waiting list form (Active or Inactive).
20. Enter the date the waiting list form was last updated.
21. Enter the date the waiting list form was created.
22. Select whether the waiting list form was created by authorized personnel.

## Field-by-Field Explanation

* **product_waiting_list**: Enter the product code or name you want to add to the waiting list.
* **customers_waiting_list**: Choose whether the product is on the waiting list for customers or not.
* **product**: Enter the product ID number.
* **customer**: Enter the customer ID number.
* **quantity**: Enter the quantity of the product being waited for.
* **date_waiting**: Select the date when the product is expected to be available.
* **time_waiting**: Select the time when the product is expected to be available.
* **note**: Add any additional comments or notes regarding the waiting list.
* **email**: Enter the email address of the customer or contact person.
* **phone**: Enter the phone number of the customer or contact person.
* **assigned_user**: Optionally, select the user assigned to manage the waiting list.
* **status**: Choose the status of the waiting list (Active or Inactive).
* **priority**: Select the priority level of the waiting list (Yes or No).
* **assigned_tool**: If applicable, select the tool assigned to the waiting list.
* **created_at**: Enter the date the waiting list was created.
* **updated_at**: Enter the date the waiting list was last updated.
* **deleted_at**: Enter the date the waiting list was deleted.
* **created_by**: Select whether the waiting list was created by authorized personnel.
* **updated_by**: Select whether the waiting list was last updated by authorized personnel.
* **deleted_by**: Select whether the waiting list was deleted by authorized personnel.
* **form_id**: Enter the unique identifier of the waiting list.
* **form_version**: Select the version of the waiting list form used to create this record.
* **form_status**: Select the status of the waiting list form (Active or Inactive).
* **form_updated_at**: Enter the date the waiting list form was last updated.
* **form_created_at**: Enter the date the waiting list form was created.
* **form_created_by**: Select whether the waiting list form was created by authorized personnel.
