# Embroidery Upload Form - Help Guide

## Purpose
The Embroidery Upload Form is designed to collect information and metadata for uploaded embroidery files. This form helps you provide details about the uploaded file, including its title, type, description, tags, categories, and status.

## How To Complete This Form
1. To start, ensure you have an embroidery file ready to upload.
2. Select the type of embroidery file you are uploading (e.g. Embroidery, Monogram, Logo).
3. Enter the title and description of the file.
4. Add relevant tags and categories to help identify the file.
5. Select the status of the file (e.g. New, In Progress, Completed, Waiting).
6. Optionally, provide additional notes and metadata for the file.

## Field-by-Field Explanation

* **Upload File** (`upload_file`, text, required): Enter the name of the file you are uploading.
* **What Type** (`upload_type`, select_one, required): Select the type of embroidery file you are uploading (e.g. Embroidery, Monogram, Logo).
* **Description** (`upload_description`, text, optional): Enter a brief description of the file.
* **Tags** (`upload_tags`, text, optional): Add relevant tags to help identify the file.
* **Categories** (`upload_categories`, text, optional): Select categories for the file.
* **Status** (`upload_status`, select_multiple, optional): Select the status of the file (e.g. New, In Progress, Completed, Waiting).
* **Date** (`upload_date`, date, optional): Enter the date of the file.
* **Time** (`upload_time`, time, optional): Enter the time of the file.
* **Email** (`upload_email`, email, optional): Enter a contact email.
* **Phone** (`upload_phone`, text, optional): Enter a contact phone number.
* **Notes** (`upload_notes`, note, optional): Enter additional notes for the file.

## Tips

* Ensure you have the correct file format and size for upload.
* Be as detailed as possible when adding tags and categories.
* Use the status field to track the progress of your embroidery file.
* Use the email and phone fields to provide contact information for the file.
