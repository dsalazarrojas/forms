# summer_camp_return_transportation_signup_form - Help Guide
## Purpose
This form is designed to help parents or guardians sign up for return transportation services for their child's summer camp. It is used to plan and coordinate the return transportation of the camper.

## How To Complete This Form
To complete this form, follow these steps:

1. Please select whether you would like to sign up for return transportation services.
2. Enter the camper's name.
3. Enter the pickup date and time.
4. Indicate if you would like to have a vehicle for pick up.
5. Enter your phone number for emergency contact purposes.
6. Enter the camper's email for updates and notifications.
7. Enter the camper's address (optional).
8. Add any additional notes or comments.

## Field-by-Field Explanation
- **Return Transportation Services** (`return_transportation`, select_one, required): Select 'Yes' to sign up for return transportation services. This is a required field.
- **Camper's Name** (`name`, text, required): Please enter the name of the camper.
- **Pickup Date** (`pickup_date`, date, required): Enter the date of the desired pickup.
- **Pickup Time** (`pickup_time`, time, required): Enter the time of the desired pickup.
- **Vehicle** (`vehicle`, select_one, required): Select 'Yes' to indicate that you would like to have a vehicle for pick up.
- **Phone** (`phone`, text, required): Please enter your 10-digit phone number for emergency contact purposes.
- **Email** (`email`, email, required): Enter the camper's email address for updates and notifications.
- **Address** (`address`, text, optional): This field is not required, but please enter the camper's address if you have one.
- **Notes** (`notes`, text, optional): Add any additional notes or comments about your camper's return transportation.
