# Sample Summer Camp Registration Form - Help Guide
## Purpose
The purpose of this form is to collect information about the camper and their guardian for a smooth and enjoyable experience during the summer camp.

## How To Complete This Form
1. Select the summer camp option that best suits your needs.
2. Fill out the camper's name, email, and contact information.
3. Provide the guardian's name, email, and contact information.
4. Choose up to two cabin mates for the camper.
5. Select the camper's age group and other relevant information such as medical conditions, height, and weight.
6. Select the guardian's relationship with the camper and their English ability.
7. Choose up to two activities that the camper would like to participate in.

## Field-by-Field Explanation

* **Registration (id: 1)**:
	+ A dropdown menu to select the summer camp option that best suits your needs.
* **Camper Name (id: 2)**:
	+ Enter the camper's full name.
* **Email (id: 3)**:
	+ Enter the camper's email address.
* **Guardian Name (id: 4)**:
	+ Enter the guardian's name.
* **Guardian Email (id: 5)**:
	+ Enter the guardian's email address.
* **Contact Number (id: 6)**:
	+ Enter the guardian's contact number.
* **Consent Form (id: 7)**:
	+ Review and sign the consent form.
* **Camper Address (id: 8)**:
	+ Enter the camper's address.
* **Medical Conditions (id: 9)**:
	+ List any medical conditions that affect the camper.
* **Cabin Mates (id: 10)**:
	+ Select up to two friends for the camper to share a cabin with.
* **Camper Age (id: 11)**:
	+ Select the camper's age group.
* **Guardian Relationship (id: 12)**:
	+ Select the guardian's relationship with the camper.
* **Guardian Phone (id: 13)**:
	+ Enter the guardian's contact number.
* **Camper Medication (id: 14)**:
	+ List any medication the camper is taking.
* **Camper Height (id: 15)**:
	+ Enter the camper's height.
* **Camper Weight (id: 16)**:
	+ Enter the camper's weight.
* **Camper Birthdate (id: 17)**:
	+ Enter the camper's birthdate.
* **Camper Identification (id: 18)**:
	+ Select any of the available options.
* **Camper Special Needs (id: 19)**:
	+ Select any special needs the camper may have.
* **Camper English Ability (id: 20)**:
	+ Select the camper's English ability.
* **Guardian English Ability (id: 21)**:
	+ Select the guardian's English ability.
* **Camper Physical Abilities (id: 22)**:
	+ Select all that apply for the camper's physical abilities.
* **Does Camper have a Camera (id: 23)**:
	+ Select yes or no.
* **Camper Social Media (id: 24)**:
	+ Select all that apply for the camper's social media presence.
* **Campers Vehicle Arrangement (id: 25)**:
	+ Select all that apply for the camper's vehicle arrangement.

## Tips
- Make sure to review the form carefully before submitting.
- If you have any questions or concerns, please contact the summer camp administration.
- Please fill out the form accurately and honestly.
