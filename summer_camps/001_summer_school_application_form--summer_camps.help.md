# Summer School Application Form - Help Guide

## Purpose
This form is designed to gather information from students applying for summer school programs. It collects personal details, program preferences, and payment information to facilitate a smooth application process.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your first and last name in the respective fields.
2. Enter your email address and contact number.
3. Select the date of birth.
4. Choose the summer camp(s) you would like to attend.
5. Select the payment method and enter the amount to be paid.
6. Answer the essay questions.
7. Select the program(s) and date for the selected camp(s).
8. Repeat steps 5-7 for the second set of questions.

## Field-by-Field Explanation
### First Name (`first_name`, text, required)
Enter your first name as it appears on your identification documents.

### Last Name (`last_name`, text, required)
Enter your last name as it appears on your identification documents.

### Email (`email`, email, required)
Enter your valid email address.

### Contact Number (`phone_number`, text, required)
Enter your contact number where you can be reached for further communication.

### Date Of Birth (`date_of_birth`, date, required)
Enter your date of birth in the format `mm/dd/yyyy`.

### Which camp would you like to attend? (`select_one_camp`, select_one, required)
Select one summer camp from the options provided.

### Which camps do you want to attend? (`select_multiple_camps`, select_multiple, required)
Select multiple summer camps from the options provided.

### Payment Method (`tuition_fees`, select_one, required)
Choose your preferred payment method.

### Amount (`tuition_amount`, number, required)
Enter the amount to be paid for the selected camp(s).

### Note (`note`, note, required)
Provide any additional comments or notes about your application.

### Essay question (`select_one_essay`, select_one, required)
Answer the essay question as per the option selected.

### Multi choice question (`select_multiple_essay`, select_multiple, required)
Select multiple options for the multi-choice question.

### Time (`time`, time, required)
Enter the time for the selected camp.

### Payment Method 2 (`tuition_fees_2`, select_one, required)
Choose your preferred payment method for the second set of questions.

### Amount 2 (`tuition_amount_2`, number, required)
Enter the amount to be paid for the second set of questions.

### Note 2 (`note_2`, note, required)
Provide any additional comments or notes about your application.

### Essay question 2 (`select_one_essay_2`, select_one, required)
Answer the essay question as per the option selected.

### Multi choice question 2 (`select_multiple_essay_2`, select_multiple, required)
Select multiple options for the multi-choice question 2.

### Time 2 (`time_2`, time, required)
Enter the time for the second set of questions.

### Program (`program`, text, optional)
Enter any additional program information if not already selected.

### Select multiple programs (`select_multiple_programs`, select_multiple, required)
Select multiple programs from the options provided.

### Select multiple programs 2 (`select_multiple_programs_2`, select_multiple, required)
Select multiple programs from the options provided.

### Date 2 (`date_2`, date, required)
Enter the date for the second set of questions.

### Select one program 2 (`select_one_program_2`, select_one, required)
Select one program from the options provided.

### Select multiple programs 2 (`select_multiple_programs_2`, select_multiple, required)
Select multiple programs from the options provided.
