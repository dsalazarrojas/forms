# Summer Camp Waitlist Form - Help Guide
## Purpose
This form is used for individuals to sign up for summer camps, including programs A and B. It collects personal and sponsorship information for both attendees and their sponsors.

## How To Complete This Form

### Step 1: Provide Personal Information

* Fill out the following fields:
	+ First Name
	+ Last Name
	+ Address
	+ Email
	+ Phone

### Step 2: Select Programs

* Select one or multiple programs that you would like to sign up for:
	+ Select One Camp Program
	+ Select Multiple Camp Programs

### Step 3: Provide Sponsor Information (if applicable)

* If you are a sponsor, fill out the following fields:
	+ First Name of Sponsor
	+ Last Name of Sponsor
	+ Address of Sponsor
	+ Email of Sponsor
	+ Phone of Sponsor
	+ Select One Camp Program of Sponsor

### Step 4: Optional Information

* Date and Time (if applicable)
* Note (if you have any other information not listed above)
