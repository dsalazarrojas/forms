# Summer Camp Registration Template - Help Guide
## Purpose
This form is used to register a camper for the summer camp program. It collects essential details such as name, birth date, camp dates, and medical information.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the camper's **name** in the "camper_name" field.
2. Provide the camper's **birth date** in the "birth_date" field.
3. Enter the dates of the **camp** in the "start_date" and "end_date" fields.
4. Fill in the camper's **email address** and **phone number** in the "email" and "phone" fields, respectively.
5. Indicate if the camper has any **medical conditions** in the "medical_conditions" field.
6. Specify if the camper has any **allergies** in the "allergies" field.
7. Check if the camper has any **special needs** in the "special_needs" field.
8. Mark if the camper has any **food restrictions** in the "food_restrictions" field.
9. Provide any additional **medical notes** in the "medical_notes_1" to "medical_notes_4" fields.
10. Fill in any additional information about the camper in the "camper_info_1" to "camper_info_3" fields.

## Field-by-Field Explanation
* **Summer Camp Registration**: This is the main registration page for the camper.
* **camper_name**: Enter the name of the camper to be registered.
* **birth_date**: The birth date of the camper. This is required to verify the camper's age.
* **camp_days**: This field is not used in this form. Please ignore it.
* **start_date**: Enter the start date of the camp.
* **end_date**: Enter the end date of the camp.
* **camper_info**: This field is not used in this form. Please ignore it.
* **first_name**: Enter the first name of the camper.
* **last_name**: Enter the last name of the camper.
* **email**: Enter the email address of the camper.
* **phone**: Enter the phone number of the camper.
* **address**: Enter the address of the camper.
* **camper_info_2**: This field is not used in this form. Please ignore it.
* **medical_conditions**: Check if the camper has any medical conditions.
* **allergies**: Check if the camper has any allergies.
* **special_needs**: Check if the camper has any special needs.
* **food_restrictions**: Check if the camper has any food restrictions.
* **medical_notes_1**: Enter any additional medical notes about the camper.
* **medical_notes_2**: Enter any additional medical notes about the camper.
* **medical_notes_3**: Enter any additional medical notes about the camper.
* **medical_notes_4**: Enter any additional medical notes about the camper.
* **camper_info_3**: This field is not used in this form. Please ignore it.
* **medical_notes_2**: This field is not used in this form. Please ignore it.
