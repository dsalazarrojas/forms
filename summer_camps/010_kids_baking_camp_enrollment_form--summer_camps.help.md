# Kids Baking Camp Enrollment Form - Help Guide

## Purpose
This form is designed to help us collect information about the summer camps your kids are enrolled in. Please fill out the form with the required information and submit it when you are finished.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Start by filling in the title of the form, which should be a brief description of the summer camps your kids are enrolled in.
2. If your kids are in any summer camps, please select "Yes" next to the "category" field. Otherwise, select "No".
3. Please enter a brief description of the summer camps your kids are enrolled in in the "description" field.
4. Enter a unique form ID for each camp.
5. Please provide the tool assigned to the summer camps in the "assigned_tool" field.
6. You can optionally select the file output for the summer camps in the "output_file" field.
7. If you want to provide more details about the category of the summer camps, please select "Yes" next to the "category_name" field.
8. Please enter the name of the category of the summer camps in the "category_name" field.
9. Select the category for the summer camps in the "form_category" field.
10. Please enter a brief description of the form in the "form_description" field.
11. Select the sessions that your kids are enrolled in in the "session_selection" field.
12. Optionally, enable or disable submission tracking for the form by selecting "Yes" or "No" next to the "submission_tracking" field.

## Field-by-Field Explanation

* **Form Title**: form_title (required): Enter a brief description of the summer camps your kids are enrolled in.
* **Category**: category (optional): If your kids are in any summer camps, select "Yes" next to this field. Otherwise, select "No".
* **Description**: description (optional): Please enter a brief description of the summer camps your kids are enrolled in.
* **Form ID**: form_id (required): Enter a unique form ID for each camp.
* **Assigned Tool**: assigned_tool (optional): Please provide the tool assigned to the summer camps.
* **Output File**: output_file (optional): Optionally, select the file output for the summer camps.
* **Category Name**: category_name (optional): If you want to provide more details about the category of the summer camps, please select "Yes" next to the "category_name" field.
* **Form Category**: form_category (required): Select the category for the summer camps.
* **Form Description**: form_description (optional): Please enter a brief description of the form.
* **Session Selection**: session_selection (optional): Select the sessions that your kids are enrolled in.
* **Submission Tracking**: submission_tracking (optional): Optionally, enable or disable submission tracking for the form by selecting "Yes" or "No".
