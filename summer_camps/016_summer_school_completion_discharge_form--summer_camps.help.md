# Summer School Completion Discharge Form - Help Guide
## Purpose
This form is used to document and track a student's completion of a summer school program. It includes fields for student name, program completion dates, hours completed, and student progress. Please use this form to accurately report a student's progress and completion status.

## How To Complete This Form
1. Fill out the form with the student's information, including their name, completion dates, and academic program details.
2. Select the relevant academic program from the dropdown menu.
3. Enter the start and end dates of the academic program.
4. Record the number of hours completed and enrolled in the program.
5. Write a note about the student's progress.
6. Choose the student's signature from the dropdown menu.

## Field-by-Field Explanation

* **summer_school_completion_discharge_form_data** (text): Please provide a brief description of the student's completion status.
* **student_name** (text): Enter the student's name.
* **date_of_completion** (date): Enter the date the student completed the program.
* **academic_program_completed** (select_one): Select the academic program the student completed.
* **academic_program_start_date** (date): Enter the start date of the academic program.
* **academic_program_end_date** (date): Enter the end date of the academic program.
* **academic_program_hours_completed** (number): Record the number of hours completed in the program.
* **academic_program_hours_enrolled** (number): Record the number of hours enrolled in the program.
* **student_progress** (note): Write a note about the student's progress.
* **student_signature** (select_one): Select the student's signature.
