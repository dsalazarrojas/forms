# Camp Activity Attendance Form - Help Guide
## Purpose
This form is used to record and document the details of a camp activity, including the name of the camp, activity date, time, location, and attendance of campers. It also captures any incidents that may have occurred during the activity.

## How To Complete This Form

1.  Fill in the **Camp Name** field with the name of the camp program.
2.  Enter the **Activity Name** of the specific activity.
3.  Select the **Activity Date** on which the activity took place.
4.  Enter the **Counselor Name** who supervised the activity.
5.  Choose the **Session Time** of the activity from the available options (e.g., morning, afternoon, evening).
6.  Select the **Activity Type** from the given options (e.g., Sports, Arts and Crafts, etc.).
7.  Enter the **Activity Location** where the activity took place.
8.  For each camper, fill in their full name in the corresponding **Camper X Name** fields.
9.  Record the attendance status of each camper by selecting the relevant option from **Camper X Attendance Status**.
10.  Enter the **Total Number Present** count of campers who attended the activity.
11.  If applicable, select the **Weather Conditions** during the activity.
12.  Check if any **Incidents Occurred** during the activity and describe them in the **Incident Details** field if needed.
13.  Enter any additional **Activity Notes**.

## Field-by-Field Explanation

*   **Camp Name**: Name of the camp program.
    *   This field is required to identify the camp program.
*   **Activity Name**: Name of the specific activity.
    *   This field is required to document the type of activity.
*   **Activity Date**: Date of the activity.
    *   This field is required to record the date of the activity.
*   **Counselor Name**: Name of the supervising counselor.
    *   This field is required to track the staff member responsible for the activity.
*   **Session Time**: Time of the activity session.
    *   This field is required to schedule the activity.
*   **Activity Type**: Select the type of activity.
    *   This field is required to categorize the activity type.
*   **Activity Location**: Where the activity took place.
    *   This field is required to track the activity location.
*   **Camper X Name**: Full name of the camper.
    *   These fields are optional but required for campers attending the activity.
*   **Camper X Attendance Status**: Select the attendance status of the camper.
    *   These fields are required for tracking camper attendance.
*   **Total Number Present**: Count of campers who attended the activity.
    *   This field is required for overall attendance tracking.
*   **Weather Conditions**: Select the weather condition.
    *   This field is optional, as it may not be applicable to all activities.
*   **Incidents Occurred**: Check if any incidents occurred.
    *   This field is required for incident reporting and safety.
*   **Incident Details**: Describe any incidents that occurred.
    *   This field is optional and used to provide more information about incidents.
*   **Activity Notes**: Add any additional notes about the activity.
    *   This field is optional for extra comments and observations.
