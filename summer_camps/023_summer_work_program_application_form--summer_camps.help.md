# Summer Work Program Application Form - Help Guide

## Purpose
This form is designed to collect information from potential summer camp staff members. The purpose of this form is to gather details about the staff's availability and preferences for the summer program.

## How To Complete This Form

- **Step 1: Enter the program name**, type in the name of the program you are interested in.
- **Step 2: Select the start date**, choose the first day of the program you are applying for.
- **Step 3: Select the end date**, choose the last day of the program you are applying for.
- **Step 4: Enter job title**, type in a brief description of the position you are applying for (e.g., Counselor-in-Charge, Chef, etc.).
- **Step 5: Work experience**, describe any previous work experience you have that is relevant to the position you are applying for.
- **Step 6: Select availability**, choose all the days of the week you are available to work during the program.
- **Step 7: Select summer months of availability**, choose all the months you are available to work during the summer (June, July, August).
- **Step 8: Add any additional notes**, provide any additional information you think would be helpful for the program staff to know.

## Field-by-Field Explanation

* **Program Name** (`program_name`, text, optional): Enter the name of the program you are interested in.
* **Start Date** (`start_date`, date, required): Select the first day of the program you are applying for. This is the date you would start working for the program.
* **End Date** (`end_date`, date, required): Select the last day of the program you are applying for. This is the date you would finish working for the program.
* **Job Title** (`job_title`, text, optional): Type in a brief description of the position you are applying for (e.g., Counselor-in-Charge, Chef, etc.).
* **Work Experience** (`work_experience`, text, optional): Describe any previous work experience you have that is relevant to the position you are applying for.
* **Availability** (`availability`, select multiple, required): Choose all the days of the week you are available to work during the program.
* **Availability 2** (`availability2`, select multiple, required): Choose all the months you are available to work during the summer (June, July, August).

## Tips

* Be honest and accurate when filling out this form.
* Double-check your selections before submitting the form.
* If you have any questions or concerns, contact the program staff.

This form will help us get to know you better and ensure that you are a good fit for the program. Thank you for taking the time to fill it out!
