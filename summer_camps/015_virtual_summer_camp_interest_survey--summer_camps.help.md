# Virtual Summer Camp Interest Survey - Help Guide
## Purpose
This form is used to collect information from campers and their parents about their interests, availability, and other relevant details to help us tailor our virtual summer camps to their needs and interests.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your camper's name and parents' phone number.
2. Choose your camper's grade level.
3. Select your camper's interests (art, music, science, sports, etc.).
4. Choose your camper's age range.
5. Indicate your camper's availability for the virtual summer camps.
6. Select the time of day you are available.
7. Add any additional comments you would like to share.
8. Confirm if this form was submitted by you or a parent.

## Field-by-Field Explanation
- **Camper Name** (`camper_name`, text): Please fill in your camper's name.
- **Parents Phone** (`parents_phone`, text): Please enter your parents' phone number.
- **Parents Email** (`parents_email`, email): Please enter your parents' email address.
- **Camper Grade** (`camper_grade`, text): Please select your camper's grade level.
- **Interests** (`camper_interests`, select_multiple): Please select your camper's interests (e.g., art, music, science, sports, etc.).
- **Art** (`camper_interests_option_1`, text): If your camper is interested in art, please select this option.
- **Music** (`camper_interests_option_2`, text): If your camper is interested in music, please select this option.
- **Science** (`camper_interests_option_3`, text): If your camper is interested in science, please select this option.
- **Sports** (`camper_interests_option_4`, text): If your camper is interested in sports, please select this option.
- **Camper Ages** (`camper_ages`, select_multiple): Please select your camper's age range.
- **8-12** (`camper_ages_option_1`, text): If your camper is between 8-12 years old, please select this option.
- **13-15** (`camper_ages_option_2`, text): If your camper is between 13-15 years old, please select this option.
- **16-18** (`camper_ages_option_3`, text): If your camper is between 16-18 years old, please select this option.
- **19-21** (`camper_ages_option_4`, text): If your camper is between 19-21 years old, please select this option.
- **22-24** (`camper_ages_option_5`, text): If your camper is between 22-24 years old, please select this option.
- **25+** (`camper_ages_option_6`, text): If your camper is 25 years old or more, please select this option.
- **Availability** (`camper_availability`, date): Please select the date you are available.
- **Weekday** (`camper_availability_2`, time): Please select the time of day you are available.
- **Comments** (`camper_comments`, note): Please add any additional comments or information you would like to share.
- **Submitted by** (`form_submitted_by`, select_one): Please confirm if this form was submitted by you or a parent.
- **Form 1** (`form_submitted_by_option_1`, text): If this form was submitted by a parent, select this option.
- **Form 2** (`form_submitted_by_option_2`, text): If this form was submitted by someone other than a parent, select this option.
- **Form 3** (`form_submitted_by_option_3`, text): If this form was submitted by a teacher, select this option.
- **Form 4** (`form_submitted_by_option_4`, text): If this form was submitted by a camp counselor, select this option.
- **Form 5** (`form_submitted_by_option_5`, text): If this form was submitted by a different form, select this option.
