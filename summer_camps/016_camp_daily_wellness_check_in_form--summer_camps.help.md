# Camp Daily Wellness Check In Form - Help Guide
## Purpose
The Camp Daily Wellness Check In Form is used to track the daily well-being of summer campers. It ensures that each camper's health and safety are monitored, and any potential issues are addressed promptly.

## How To Complete This Form
To complete this form, please follow these steps:
1. Enter the full name of the camper, as it will appear on all records and attendance logs.
2. Select the date of the wellness check.
3. Enter the camper's measured body temperature in Celsius.
4. Select any symptoms the camper is experiencing from the provided options.
5. Assess the camper's overall well-being by selecting the rating that best describes their condition.
6. If necessary, document any medications administered to the camper.
7. Check if the camper requires isolation for safety reasons.
8. Record any staff observations or follow-up instructions.
9. Indicate if a parent or guardian has been notified.
10. Describe any follow-up actions required after the check.

## Field-by-Field Explanation
*   **Camper Name** (`camper_name`, text, required): Enter the full name of the camper for attendance and records purposes.
*   **Date** (`date`, date, required): Select the date of the wellness check.
*   **Temperature Celsius** (`temperature_celsius`, number, required): Record the camper's body temperature in Celsius.
*   **Symptoms Present** (`symptoms_present`, select_multiple, required): Select any symptoms the camper is experiencing.
*   **Overall Wellness Rating** (`overall_wellness_rating`, select_one, required): Assess the camper's overall well-being by selecting the rating that best describes their condition.
*   **Medication Administered** (`medication_administered`, text, optional): Document any medications given to the camper, if necessary.
*   **Isolation Required** (`isolation_required`, select_one, required): Check if the camper needs isolation for safety reasons.
*   **Staff Notes** (`staff_notes`, text, optional): Record any staff observations or follow-up instructions.
*   **Parent Contacted** (`parent_contacted`, select_one, optional): Indicate if a parent or guardian has been notified.
*   **Follow Up Actions** (`follow_up_actions`, text, optional): Describe any follow-up actions required after the wellness check.

## Tips
- Make sure to report any symptoms or concerns promptly to ensure timely intervention.
- Always check if a parent or guardian has been notified when they have been contacted.
- Use clear and concise language in the 'Staff Notes' field for easy reference.
