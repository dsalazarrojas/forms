# Store Entrance Decal Order Form - Help Guide
## Purpose
This form is used to create a new order for entrance decals for stores. Please fill out the form accurately to ensure that the order is processed correctly.

## How To Complete This Form
To complete this form, follow these steps:

* Click on the "Submit" button to begin filling out the form.
* Select the order type from the dropdown menu. If you need to place a new order, select "Yes". If you need to cancel an order, select "No".
* Enter the date of the order in the format of mm/dd/yyyy.
* Enter the name of the store that needs the entrance decal.
* Enter a description of the order details.
* Enter the quantity of entrance decals needed.
* Enter the total cost of the order.
* Enter the customer's name.
* Enter the customer's email address.
* Enter the customer's phone number.
* Select the type of decal from the dropdown menu.
* Select the status of the order from the dropdown menu.

## Field-by-Field Explanation
* **Order Type (`order_type`, select_one, required):** Select the type of order you are placing. If you need to place a new order, select "Yes". If you need to cancel an order, select "No".
* **Date of Order (`order_date`, date, optional):** Enter the date of the order in the format of mm/dd/yyyy. This field is not required but it will help to keep track of order history.
* **Store Name (`store_name`, text, optional):** Enter the name of the store that needs the entrance decal.
* **Order Details (`order_details`, text, optional):** Enter a description of the order details.
* **Quantity (`quantity`, number, optional):** Enter the number of entrance decals needed.
* **Total (`order_total`, number, optional):** Enter the total cost of the order.
* **Customer Name (`customer_name`, text, optional):** Enter the name of the customer.
* **Customer Email (`customer_email`, email, required):** Enter the customer's email address.
* **Customer Phone (`customer_phone`, text, required):** Enter the customer's phone number.
* **Type of Decal (`store_entrance_type`, select_one, optional):** Select the type of decal from the dropdown menu.
* **Status of Order (`order_status`, select_one, optional):** Select the status of the order from the dropdown menu.
