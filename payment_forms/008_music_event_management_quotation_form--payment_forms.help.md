# Music Event Management Quotation Form - Help Guide

## Purpose
The Music Event Management Quotation Form is designed to collect essential information for event planning and quotation.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the type of event (Live Event, Recording Session, Festival, or Other)
2. Enter the date of the event
3. Provide the location of the event
4. Specify the duration of the event
5. Indicate the event capacity
6. Add any additional event details
7. Enter the email address of the client
8. Enter the phone number of the client

## Field-by-Field Explanation

* **Event Type** (Select One, Event Type):
  This field is used to determine the type of event (Live Event, Recording Session, Festival, or Other).
  
* **Event Date** (Date, Event Date):
  Enter the date of the event in the correct format (mm/dd/yyyy).
  
* **Event Location** (Text, Event Location):
  This field is used to enter the location of the event (e.g., venue name, address).
  
* **Event Duration** (Time, Event Duration):
  Enter the duration of the event in the format (hh:mm).
  
* **Event Capacity** (Number, Event Capacity):
  Specify the maximum number of attendees allowed at the event.
  
* **Event Details** (Note, Event Details):
  Add any additional information about the event that is not covered in the other fields.
  
* **Email** (Email, Email):
  Enter the email address of the client for communication purposes.
  
* **Phone** (Text, Phone):
  Enter the phone number of the client for communication purposes.

## Tips

* Double-check the information provided in the form before submission.
* Ensure all required fields are filled out accurately.
* Avoid duplicating the form for different events.
