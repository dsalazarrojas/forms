# e_payment_terminal_exchange_form - Help Guide
## Purpose
The e_payment_terminal_exchange_form is used to record details about payment terminal exchange process for administrative purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of payment terminal from the options provided.
2. If required, enter the date and time of the transfer.
3. Enter any operational notes related to the exchange process.
4. If necessary, enter the amount transferred.
5. If required, provide a valid email address and/or phone number for contact purposes.

## Field-by-Field Explanation

* **payment_terminal_type** (`payment terminal type`, `select_one`, required): Select the type of payment terminal that was used in the exchange process.
* **date_of_transfer** (`date`, `date_of_transfer`, required): Enter the date of the transfer, if required.
* **time_of_transfer** (`time`, `time_of_transfer`, required): Enter the time of the transfer, if required.
* **operational_notes** (`operational notes`, `note`, optional): Enter any notes about the operational activities related to the exchange process.
* **transfer_amount** (`transfer_amount`, `number`, optional): Enter the amount transferred, if necessary.
* **email** (`email`, `email`, optional): Enter a valid email address for contact purposes, if required.
* **phone** (`phone`, `text`, optional): Enter a valid phone number for contact purposes, if required.

## Tips
- Make sure to select the correct payment terminal type to ensure accurate recording of the exchange process.
- If entering the time of transfer, use the 24-hour clock format (HH:MM).
- For the transfer amount, enter the amount in the currency used for the transaction.
- If providing an email or phone number, ensure it is a valid and active contact information.
