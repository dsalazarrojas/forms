# Magazine Order With Eway Payment Gateway - Help Guide

## Purpose
This form is used to collect information for the magazine order process using Eway payment gateway.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the magazine order.
2. Enter a brief description of the order.
3. Upload the background image of the magazine.
4. Enter the logo of the magazine.
5. Select the issue of the magazine (if any).
6. Select the month of publication (if any).
7. Select the year of publication (if any).
8. Set up the Eway fee for the magazine (if any).
9. Confirm the Eway fee hint.
10. Select Eway fees (if any).
11. Confirm Eway gateway availability.
12. Enter the publisher of the magazine.
13. Enter the form builder of the magazine.
14. Enter the form customization of the magazine.
15. Set up the Eway gateway fee (if any).
16. Select Eway gateway fees (if any).
17. Enter the price of the issue.
18. Enter the hint for the issue price.
19. Enter the total amount of the order.
20. Enter the hint for the total amount.
21. Select the payment method (Bank Transfer, Credit Card, or PayPal).
21. Review and submit the form.

## Field-by-Field Explanation

### 1. Category (Category, select_one)
Select the category of the magazine order.
