# real_estate_agent_payment_portal - Help Guide
## Purpose
This form is designed to collect payment information for real estate transactions.

## How To Complete This Form
1. Start by reviewing the payment details and selecting the relevant information.
2. Choose the correct payment method from the provided options.
3. Enter the transaction date in the correct format.
4. Provide the property address associated with the payment.
5. Enter the payment amount.
6. Indicate the payment status.
7. If applicable, provide agent, broker, or client information for reference purposes.

## Field-by-Field Explanation

* **Payment Info** (1, text, required): Enter a brief description of the payment, including the purpose and any additional relevant details.
* **Payment Method** (2, select_one, required): Select one of the following payment methods:
	+ Cash
	+ Check
	+ Credit Card
	+ Bank Transfer
* **Transaction Date** (3, date, required): Enter the date of the transaction in the correct format (MM/DD/YYYY).
* **Property Address** (4, text, required): Enter the address associated with the payment.
* **Payment Amount** (5, number, required): Enter the exact amount paid.
* **Payment Status** (6, select_one, required): Select one of the following payment statuses:
	+ Paid
	+ Unpaid
* **Agent Info** (7, text, optional): Provide any relevant information about the real estate agent involved.
* **Broker Info** (8, text, optional): Provide any relevant information about the broker involved.
* **Client Info** (9, text, optional): Provide any relevant information about the client or payor.
