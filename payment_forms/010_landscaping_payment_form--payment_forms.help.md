# Landscaping Payment Form - Help Guide
## Purpose
This form is used to collect information from clients for landscaping services provided.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the client's name in the "Client Name" field.
2. Select the type of service provided from the "Service" dropdown menu.
3. Enter the start and end dates of the project in the "Start Date" and "End Date" fields, respectively.
4. Enter the amount to be paid in the "Amount" field.
5. Select the payment method from the "Payment Method" dropdown menu.
6. If desired, enter any additional notes in the "Client Note" field.

## Field-by-Field Explanation
* **Client Name**: Enter the name of the client, including their first and last name. This field is required.
* **Service**: Select the type of service provided from the list:
	+ Lawn Care: This includes services such as mowing, pruning, and fertilizing.
	+ Gardening: This includes services such as planting, weeding, and pruning.
	+ Landscaping: This includes services such as designing, installing, and maintaining landscaping features.
	+ Irrigation: This includes services related to installing and maintaining irrigation systems.
	+ Other: Select this option if the service is not listed above.
* **Start Date**: Enter the start date of the project. This field is required.
* **End Date**: Enter the end date of the project. This field is required.
* **Amount**: Enter the amount to be paid for the project. This field is required.
* **Payment Method**: Select the method of payment from the list:
	+ Cash
	+ Credit Card
	+ PayPal
	+ Bank Draft
* **Client Note**: Enter any additional notes or comments you want to provide to the landscaping team. This field is optional.
