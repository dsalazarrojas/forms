# Custom Gate And Fence Order Form - Help Guide
## Purpose
This form is designed to guide customers through the process of ordering custom gates and fences. The form collects various details about the order, including project details, payment information, gate type, material type, fence type, order status, and additional notes.

## How To Complete This Form
1. Select the appropriate project details from the options provided.
2. Enter payment information (if applicable).
3. Choose the type of gate and fence that best suits your needs.
4. Select the desired material type for the gate and fence.
5. Choose the type of fence you would like to order.
6. Specify the order status.
7. Provide any additional notes or comments about the order.
8. Enter the length of the gate (if applicable).
9. Enter any additional notes or comments about the order status.

## Field-by-Field Explanation
- **Project Details (project_details)**: Select the project details that correspond to your specific order.
- **Payment Info (payment_info)**: Enter your payment information (if applicable). This field is not required.
- **Gate Type (gate_type)**: Choose the type of gate that you would like to order (e.g., Gate Type 1, Gate Type 2, etc.).
- **Material Type (material_type)**: Select the material type that you would like to use for the gate and fence (e.g., Material Type 1, Material Type 2, etc.).
- **Fence Type (fence_type)**: Choose the type of fence that you would like to order (e.g., Fence Type 1, Fence Type 2, etc.).
- **Order Status (order_status)**: Specify the current status of your order (e.g., Order Status 1, Order Status 2, etc.).
- **Order Notes (order_notes)**: Provide any additional notes or comments about your order. This field is not required, but it helps us understand your needs better.
- **Gate Length (gate_length)**: Enter the length of the gate (if applicable).
- **Order Status Notes (order_status_notes)**: Enter any additional notes or comments about the order status (if applicable). This field is not required.
