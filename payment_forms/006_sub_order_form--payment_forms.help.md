# Sub Order Form - Help Guide
## Purpose
The Sub Order Form is used to create and manage new sub orders. This form allows staff to track the status of sub orders, including details about the customer and order specifics.

## How To Complete This Form
To complete this form, please follow these steps:

*   Fill in the following information:
    *   **Name** (`name`): Enter the customer's name.
    *   **Email** (`email`): Enter the customer's email address.
    *   **Phone** (`phone`): Enter the customer's phone number.
    *   **Address** (`address`): Enter the customer's address.
*   Choose the correct order type:
    *   **Sandwich Type** (`sub_type`): Select the type of sandwich ordered (Grilled, Cold, Hot).
*   Record the order details:
    *   **Order** (`sub_order`): Enter a brief description or notes about the order.
*   Calculate and record the subtotal:
    *   **Sub Total** (`sub_total`): The total cost of the order.
*   Choose the payment method:
    *   **Payment Gateway** (`payment_gateway`): Select the payment gateway used for the order.
*   Update the order status:
    *   **Status** (`sub_status`): Select the status of the order (Processing, Ready to pick up, Delivered).
*   Schedule pickup or delivery:
    *   **Date** (`date`): Enter the date for pickup or delivery.
    *   **Time** (`time`): Enter the time for pickup or delivery.
*   Add any additional notes:
    *   **Note** (`note`): Add any additional comments or instructions for the staff.
*   Update the order status:
    *   **Sub Order Status** (`sub_order_status`): Select the current status of the order (New, In progress, Ready to pick up, Delivered, Cancelled).

## Field-by-Field Explanation

*   **Name** (`name`): This field is used to record the customer's name.

*   **Phone** (`phone`): This field is used to record the customer's phone number.

*   **Sandwich Type** (`sub_type`): This field allows you to select the type of sandwich ordered (Grilled, Cold, Hot).
*   **Order** (`sub_order`): This field is used to record a brief description or notes about the order.
*   **Sub Total** (`sub_total`): This field is used to record the total cost of the order.
*   **Payment Gateway** (`payment_gateway`): This field is used to select the payment gateway used for the order.
*   **Status** (`sub_status`): This field is used to select the status of the order (Processing, Ready to pick up, Delivered).
*   **Date** (`date`): This field is used to record the date for pickup or delivery.
*   **Time** (`time`): This field is used to record the time for pickup or delivery.
*   **Note** (`note`): This field is used to add any additional comments or instructions for the staff.
*   **Sub Order Status** (`sub_order_status`): This field is used to select the current status of the order (New, In progress, Ready to pick up, Delivered, Cancelled).

**Tips:**

*   Make sure to fill in all required fields to avoid any issues with order processing.
*   Double-check the order details before submitting to ensure accuracy.
*   Update the order status regularly to reflect any changes.
*   Use the note field to add any important comments or instructions for the staff.
