# Event Program Printing Order Form - Help Guide
## Purpose
The Event Program Printing Order Form is a digital form designed to collect order information for printed event programs. It's meant for event organizers or administrators to gather details about an event's program printing needs.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the event name in the `event_name` field.
2. Select the event program type from the `program_type` options.
3. Choose the order type(s) from the `order_type` select multiple field.
4. Specify the quantity of programs needed.
5. Provide a valid email address in the `email` field.
6. Enter your phone number in the `phone` field (optional).
7. Select a payment method from the `payment_method` options.
8. Finally, click the `Submit` button to complete the order.

## Field-by-Field Explanation
* **Event Name (event_name)**: Enter the name of the event for which you need a printed program.
* **Program Type (program_type)**: Select the type of program you want to print.
* **Order Type (order_type)**: Choose one or more types of orders (e.g., Order 1, Order 2, Order 3).
* **Quantity (quantity)**: Enter the number of programs you need.
* **Email (email)**: Enter a valid email address where you can be contacted about your order.
* **Phone (phone)**: Enter your phone number for any additional information or contact (optional).
* **Payment Method (payment_method)**: Select the payment method you'd like to use (e.g., Credit/Debit Card, PayPal, Bank Transfer).
* **Submit (submit)**: Click this button to complete and submit your order.
