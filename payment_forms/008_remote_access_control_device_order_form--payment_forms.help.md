# remote_access_control_device_order_form - Help Guide
## Purpose
The purpose of this form is to facilitate the ordering of remote access control devices for various purposes.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of remote access control device from the options provided.
2. Choose the location where the device will be ordered.
3. Select the customer details.
4. Add any additional comments or notes regarding the order.
5. Enter the email address of the customer.
6. Enter the phone number of the customer.
7. Provide the date and time for the order.

## Field-by-Field Explanation

* **Remote Access Control Device Order** (`remote_access_control_device_order`, select_one):
	+ Select the type of remote access control device you would like to order.
* **Access Control Device Type** (`access_control_device_type`, select_one):
	+ Choose the type of remote access control device you need.
* **Ordering Location** (`remote_access_control_device_ordering_location`, text):
	+ Enter the location where the device will be ordered.
* **Customer Details** (`customer_details`, select_multiple):
	+ Select the customer details you need to provide.
* **Order Comments** (`remote_access_control_device_order_comments`, note):
	+ Enter any additional comments or notes regarding the order.
* **Customer Email** (`remote_access_control_device_email`, email):
	+ Enter the email address of the customer.
* **Customer Phone** (`remote_access_control_device_phone`, text):
	+ Enter the phone number of the customer.
* **Order Date** (`remote_access_control_device_order_date`, date):
	+ Select the date for the order.
* **Order Time** (`remote_access_control_device_order_time`, time):
	+ Select the time for the order.
* **Order Comments** (`remote_access_control_device_order_comments`, note):
	+ Enter any additional comments or notes regarding the order.
