# Personalized E Commerce Order Form - Help Guide
## Purpose
This form is used to create personalized e-commerce orders, allowing users to input customer and order information, as well as payment details.

## How To Complete This Form

To complete this form, follow these steps:

1.  Enter the First Name of the customer.
2.  Enter the Last Name of the customer.
3.  Select the Order Date for the purchase.
4.  Select the Order Time for the purchase.
5.  Enter the Order Details, a brief description of the order.
6.  Provide the Customer Email address.
7.  Enter the Customer Phone number.
8.  Enter the Shipping Address.
9.  Enter the Shipping City.
10. Enter the Shipping State (either 'Yes' or 'No').
11. Enter the Shipping Zip code.
12. List the items Ordered.
13. Enter the Order Value.
14. Select the Payment Method (either 'Yes' or 'No').
15. Select the Payment Gateway (either 'Yes' or 'No').
16. Enter any Customer Note.
17. Select the Order Status (multiple options: Active, Inactive).
18. Enter the Payment Success URL.
19. Enter the Payment Failure URL.
20. Enter the Payment Gateway ID.
21. Enter the Customer ID.
22. Enter the Order ID.
23. Enter the Form ID.
24. Enter the Assigned Tool.
25. Enter User Defined Field 1.
26. Enter User Defined Field 2.

## Field-by-Field Explanation
*   **First Name** (`first_name`, `text`, required): Enter the First Name of the customer.
*   **Last Name** (`last_name`, `text`, required): Enter the Last Name of the customer.
*   **Order Date** (`order_date`, `date`, required): Select the date of the order.
*   **Order Time** (`order_time`, `time`, required): Select the time of the order.
*   **Order Details** (`order_details`, `text`, required): Enter a brief description of the order.
*   **Customer Email** (`customer_email`, `email`, required): Enter the customer's email address.
*   **Customer Phone** (`customer_phone`, `text`, required): Enter the customer's phone number.
*   **Shipping Address** (`shipping_address`, `text`, required): Enter the shipping address.
*   **Shipping City** (`shipping_city`, `text`, required): Enter the shipping city.
*   **Shipping State** (`shipping_state`, `select_one`, required): Select the shipping state (either 'Yes' or 'No').
*   **Shipping Zip** (`shipping_zip`, `text`, required): Enter the shipping zip code.
*   **Items Ordered** (`items_ordered`, `text`, required): List the items ordered.
*   **Order Value** (`order_value`, `number`, required): Enter the order value.
*   **Payment Method** (`payment_method`, `select_one`, required): Select the payment method (either 'Yes' or 'No').
*   **Payment Gateway** (`payment_gateway`, `select_one`, required): Select the payment gateway (either 'Yes' or 'No').
*   **Customer Note** (`customer_note`, `text`, required): Enter any customer notes.
*   **Order Status** (`order_status`, `select_multiple`, required): Select the order status (multiple options: Active, Inactive).
*   **Payment Success URL** (`payment_success_url`, `text`, required): Enter the payment success URL.
*   **Payment Failure URL** (`payment_failure_url`, `text`, required): Enter the payment failure URL.
*   **Payment Gateway ID** (`payment_gateway_id`, `text`, required): Enter the payment gateway ID.
*   **Customer ID** (`customer_id`, `text`, required): Enter the customer ID.
*   **Order ID** (`order_id`, `text`, required): Enter the order ID.
*   **Form ID** (`form_id`, `text`, required): Enter the form ID.
*   **Assigned Tool** (`assigned_tool`, `text`, required): Enter the assigned tool.
*   **User Defined Field 1** (`user_defined_field_1`, `text`, required): Enter User Defined Field 1.
*   **User Defined Field 2** (`user_defined_field_2`, `text`, required): Enter User Defined Field 2.

## Tips
*   Please ensure all required fields are completed before submitting the form.
*   Use a consistent format for dates and times to avoid confusion.
*   Be cautious when selecting the payment method and gateway options.
*   Review the order details carefully to ensure accuracy.
*   Enter accurate information for the customer email and phone number.
*   Double-check the shipping address and zip code for accuracy.
*   List the items ordered in a clear and concise manner.
*   Enter the correct order value.
*   Select the correct payment gateway ID.
*   Enter the correct customer ID and order ID.
*   Enter the correct form ID and assigned tool.
*   Enter User Defined Field 1 and 2 accurately.
