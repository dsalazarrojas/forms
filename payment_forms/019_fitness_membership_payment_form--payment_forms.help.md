# Fitness Membership Payment Form - Help Guide
## Purpose
This form is used to collect and update information related to a user's fitness membership.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the member's name and email address in the respective fields.
2. Select the membership type (yes/no) to indicate whether the member is enrolled or not.
3. Enter the payment details, including the payment method (yes/no), payment date, payment term, and payment amount.
4. Choose the payment status (active/inactive) to indicate the member's current status.
5. Set the membership start and end dates.
6. Select the membership status (active/inactive) to indicate the member's current status.
7. Enter any additional membership notes.

## Field-by-Field Explanation

* **Enrollment Details (id: 1)** (`Enrollment Details`, text, optional)
	+ This field is used to collect any additional enrollment details. You can enter any relevant information about the member's enrollment process.
* **Member Name (id: 2)** (`Member Name`, text, optional)
	+ Enter the member's name in this field.
* **Member Email (id: 3)** (`Member Email`, email, optional)
	+ Enter the member's email address in this field.
* **Membership Type (id: 4)** (`Membership Type`, select_one, optional)
	+ Select 'Yes' to indicate that the member is currently enrolled, or 'No' to indicate they are not.
* **Payment Details (id: 5)** (`Payment Details`, text, optional)
	+ Enter any additional payment details or information.
* **Payment Method (id: 6)** (`Payment Method`, select_one, optional)
	+ Select 'Yes' to indicate the payment method is active, or 'No' to indicate it is not.
* **Payment Date (id: 7)** (`Payment Date`, date, optional)
	+ Enter the date of the payment.
* **Payment Term (id: 8)** (`Payment Term`, number, optional)
	+ Enter the payment term or cycle number.
* **Payment Amount (id: 9)** (`Payment Amount`, number, optional)
	+ Enter the payment amount.
* **Payment Status (id: 10)** (`Payment Status`, select_one, optional)
	+ Select 'Active' to indicate the payment is active, or 'Inactive' to indicate it is not.
* **Membership Start Date (id: 11)** (`Membership Start Date`, date, optional)
	+ Enter the start date of the membership.
* **Membership End Date (id: 12)** (`Membership End Date`, date, optional)
	+ Enter the end date of the membership.
* **Membership Status (id: 13)** (`Membership Status`, select_one, optional)
	+ Select 'Active' to indicate the membership is active, or 'Inactive' to indicate it is not.
* **Membership Notes (id: 14)** (`Membership Notes`, text, optional)
	+ Enter any additional membership notes or comments.
