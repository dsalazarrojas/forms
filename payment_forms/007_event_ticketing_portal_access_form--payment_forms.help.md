# Event Ticketing Portal Access Form - Help Guide
## Purpose
The Event Ticketing Portal Access Form is a comprehensive form for event management, attendee tracking, and ticketing. It collects attendee information, event details, and ticket data to facilitate event organization and administration.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the Event Tier that best describes the event you're accessing.
2. Fill in your First Name and Last Name accurately.
3. Enter your Email for communication purposes.
4. Provide your Phone number for contact.
5. Enter the Attendee Name, if you're accessing an existing attendee's information.
6. Select the correct Event Date for the event you're accessing.
7. Choose the correct Event Time for the event you're accessing.
8. Specify the Event Duration of the event.
9. (Optional) Select the Event Type to further describe the event.
10. (Optional) Choose the Ticket Type for the event.
11. Enter the Ticket Price for the attendee's ticket.
12. Specify the Ticket Quantity.
13. Enter any relevant Notes for the attendee or event.
14. (Optional) Select the Payment Method for the attendee.
15. (Optional) Select the Event Status for the event.
16. (Optional) Select the Attendee Status for the attendee.
17. (Optional) Select the Assigned Tool for the event.
18. Enter the Ticket ID for the attendee's ticket.
19. Enter the Event ID for the event.
20. Enter the Attendee ID for the attendee.
21. Enter the Event Status ID for the event.
22. Enter the Attendee Status ID for the attendee.
23. Enter the Assigned Tool ID for the event.
24. Enter any relevant Note for the attendee or event.

## Field-by-Field Explanation

* **Event Tier** (`event_tier`, select_one, not required): Choose the Event Tier to describe the event you're accessing. This helps categorize the event for better management.
* **First Name** (`first_name`, text, required): Enter your first name for identification purposes.
* **Last Name** (`last_name`, text, required): Enter your last name for identification purposes.
* **Email** (`email`, email, required): Enter your Email for communication purposes. This will be used for further updates and notifications.
* **Phone** (`phone`, text, required): Enter your Phone number for contact and communication purposes.
* **Attendee Name** (`attendee_name`, text, required): Enter the name of the attendee you're accessing the information for.
* **Event Date** (`event_date`, date, required): Choose the correct Event Date for the event you're accessing. This is crucial for scheduling and organization.
* **Event Time** (`event_time`, time, required): Choose the correct Event Time for the event you're accessing.
* **Event Duration** (`event_duration`, number, required): Specify the duration of the event in minutes or hours.
* **Event Type** (`event_type`, select_one, not required): (Optional) Select the type of event for further description and categorization.
* **Ticket Type** (`ticket_type`, select_one, not required): (Optional) Choose the type of ticket for the event.
* **Ticket Price** (`ticket_price`, number, required): Enter the price of the ticket for the attendee.
* **Ticket Quantity** (`ticket_quantity`, number, required): Specify the number of tickets purchased by the attendee.
* **Note** (`note`, text, required): Enter any relevant Notes for the attendee or event for further reference.
* **Payment Method** (`payment_method`, select_one, not required): (Optional) Select the Payment Method for the attendee.
* **Event Status** (`event_status`, select_one, not required): (Optional) Select the Event Status for the event you're accessing.
* **Attendee Status** (`attendee_status`, select_one, not required): (Optional) Select the Attendee Status for the attendee.
* **Assigned Tool** (`assigned_tool`, select_one, not required): (Optional) Select the Assigned Tool for the event.
* **Ticket ID** (`ticket_id`, text, required): Enter the unique ID for the attendee's ticket.
* **Event ID** (`event_id`, text, required): Enter the unique ID for the event.
* **Attendee ID** (`attendee_id`, text, required): Enter the unique ID for the attendee.
* **Event Status ID** (`event_status_id`, text, required): Enter the unique ID for the event status.
* **Attendee Status ID** (`attendee_status_id`, text, required): Enter the unique ID for the attendee status.
* **Assigned Tool ID** (`assigned_tool_id`, text, required): Enter the unique ID for the assigned tool.

## Tips
Please fill in the form accurately and thoroughly to ensure that your information is updated correctly in the system.
