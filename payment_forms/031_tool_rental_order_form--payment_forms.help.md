# Tool Rental Order Form - Help Guide
## Purpose
The Tool Rental Order Form is used to collect information for tool rental orders. Fill out the form with the relevant details to ensure a smooth and efficient rental process.

## How To Complete This Form
1. Fill out all required fields marked with an asterisk (\*). If a field is optional, you can leave it blank.
2. Enter your customer name, contact number, email, and address in the corresponding fields.
3. Select the tool type from the available options.
4. Enter the rental start and end dates for the tool.
5. Specify the rental duration, quantity, and any special requirements.
6. Type a brief description of the tool you want to rent.
7. Review your information carefully before submitting the form.

## Field-by-Field Explanation
* **Customer Name (1)**: Enter your name as it appears on your identification.
* **Tool Type (2)**: Select the type of tool you wish to rent from the available options.
* **Rental Start Date (3)**: Enter the date you wish to start renting the tool.
* **Rental End Date (4)**: Enter the date you wish to end renting the tool.
* **Rental Duration (5)**: Enter the number of days or weeks you wish to rent the tool.
* **Quantity (6)**: Specify how many tools you need.
* **Contact Number (7)**: Enter your contact number for communication purposes.
* **Email (8)**: Enter your email address for communication and updates.
* **Address (9)**: Provide your address for delivery or pickup purposes.
* **Tool Description (10)**: Type a brief description of the tool you want to rent.
* **Special Requirements (11)**: Enter any specific requirements or instructions for the tool rental.

## Tips
* Make sure to review your information carefully before submitting the form.
* If you have any doubts or questions, contact the relevant department for assistance.
