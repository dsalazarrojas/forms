# Extension Application Fee Payment Form - Help Guide

## Purpose
This form is designed to facilitate payment processing for extension requests. Complete this form to submit payment information for an extension request.

## How To Complete This Form
1. Fill in the required fields:
	* **Extension Request ID**: Enter the unique ID of the extension request.
	* **Payment Method**: Select the method of payment (e.g., credit card, bank transfer).
	* **Payment Amount**: Enter the total amount to be paid.
	* **Extension Requestor Contact**: Choose the contact method (e.g., phone, email).
2. Fill in the optional fields:
	* **Extension Requestor Name**: Enter the name of the extension requestor.
	* **Application Type**: Select the type of application (e.g., renewal, new application).
	* **Payment Status**: Select the status of the payment (e.g., pending, completed).
	* **Payment Date**: Enter the date of payment.
	* **Payment Time**: Enter the time of payment.
	* **Email**: Enter the email address of the extension requestor.
	* **Phone**: Enter the phone number of the extension requestor.
	* **Additional Information**: Provide any additional information about the payment.
	* **Additional Information 2**: Provide any additional information about the payment (e.g., payment terms).
	* **Payment Details**: Select the payment details (e.g., payment terms, payment conditions).
	* **Payment Method 2**: Select an alternative payment method.
	* **Payment Status 2**: Select the status of the second payment (e.g., pending, completed).
	* **Additional Information 3**: Provide any additional information about the payment.
	* **Payment Amount 2**: Enter the second payment amount.
	* **Extension Requestor Info**: Select the type of extension requestor information (e.g., business, individual).
	* **Additional Information 4**: Provide any additional information about the payment.
	* **Application Fee 2**: Enter the second application fee.
	* **Extension Requestor Contact**: Choose the contact method (e.g., phone, email).
	* **Additional Information 5**: Provide any additional information about the payment.
	* **Additional Information 6**: Provide any additional information about the payment.
