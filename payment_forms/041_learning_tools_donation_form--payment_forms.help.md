# Learning Tools Donation Form - Help Guide
## Purpose
The purpose of this form is to collect donations for learning tools. Donations are crucial for supporting the development and maintenance of these tools, which benefit learners worldwide. This form helps us understand the type and frequency of donations, ensuring that we can better serve the community with the tools they need.

## How To Complete This Form

1. To complete this form, please follow the instructions below step-by-step:

## Field-by-Field Explanation

* **Donation Amount** (`donation_amount`, number, required: false):
	+ Enter the amount you wish to donate for learning tools.
	+ This field is optional; you can donate any amount that feels comfortable to you.
* **Donation Type** (`donation_type`, select one, required: true):
	+ Select the type of donation you would like to make:
		- One-Time: A one-time donation is a single contribution towards the learning tools.
		- Recurring: A recurring donation is a regular contribution towards the learning tools, which helps us plan and budget for the future.
		- In-Kind: An in-kind donation is a non-monetary contribution, such as materials or services, that support the development and maintenance of learning tools.
* **Recurring Donation Frequency** (`recurring_donation_frequency`, select multiple, required: false):
	+ Indicate whether you would like to make a recurring donation:
		- Yes: You will make regular donations at the frequency you select below.
		- No: You will not make recurring donations.
* **Donor Name** (`donor_name`, text, required: false):
	+ Provide your name as the donor.
	+ This field is optional, but it helps us recognize and acknowledge your support.
* **Donor Email** (`donor_email`, email, required: false):
	+ Enter your email address as the contact information for the donation.
	+ This field is optional, but it helps us communicate with you about your donation and any progress or updates.
* **Donor Phone** (`donor_phone`, text, required: false):
	+ Provide your phone number as the contact information for the donation.
	+ This field is optional, but it helps us reach out to you if we need to discuss anything related to your donation.
* **Donation Comments** (`donation_comments`, note, required: false):
	+ Share any additional comments or notes about your donation, such as the purpose of the donation or any specific learning tool you'd like to support.
	+ This field is optional, but it helps us understand your thoughts and preferences.
* **Form ID** (`form_id`, text, required: false):
	+ This field is automatically populated with a unique identifier for the form.
	+ You do not need to fill this in.
* **Form Version** (`form_version`, number, required: false):
	+ This field indicates the version of the form you are using.
	+ You do not need to fill this in.
* **Assigned Tool** (`assigned_tool`, text, required: false):
	+ Indicate the specific learning tool you are donating towards, if any.
	+ This field is optional.
* **Output File** (`output_file`, text, required: false):
	+ If you would like to receive the output file of your completed form, select this option.
	+ This field is optional.
* **Form Category** (`form_category`, text, required: false):
	+ This field is automatically populated with the category of the form.
	+ You do not need to fill this in.
* **Custom JotForm ID** (`custom_jotform_id`, text, required: false):
	+ This field is used for internal purposes and you do not need to fill this in.
* **Custom JotForm API Key** (`custom_jotform_api_key`, text, required: false):
	+ This field is used for internal purposes and you do not need to fill this in.
* **Form Description** (`form_description`, text, required: false):
	+ This field is automatically populated with the description of the form.
	+ You do not need to fill this in.
* **Form Description (English)** (`form_description_en`, text, required: false):
	+ This field is automatically populated with the English description of the form.
	+ You do not need to fill this in.

By following these steps, you should be able to complete the form with ease. If you have any questions or need further assistance, please do not hesitate to contact us.
