# paperless_billing_request_form - Help Guide

## Purpose
The "Paperless Billing Request Form" is used to collect and process paperless billing requests from customers. This form is designed to gather essential information from customers to facilitate efficient and accurate paperless billing.

## How To Complete This Form

1. Select the relevant Category for the paperless billing request.
2. Provide a detailed Description of the request.
3. Enter the Customer Name.
4. Enter the Customer Address.
5. Enter the Customer Email.
6. Enter the Customer Phone Number (optional).
7. Optionally, add any relevant Customer Note.

## Field-by-Field Explanation
* **Category** (`category`, select_multiple): Select the type of payment form this request is related to (e.g., Payment Forms, Other).
* **Description** (`description`, text, required): Enter a clear and concise description of the paperless billing request.
* **Customer Name** (`customer_name`, text, required): Enter the name of the customer making the request.
* **Address** (`address`, text, required): Enter the customer's address.
* **Email** (`email`, email, required): Enter the customer's email address.
* **Phone** (`phone`, text, optional): Enter the customer's phone number (if applicable).
* **Customer Note** (`customer_note`, note, optional): Add any relevant notes or details regarding the customer's request. 

## Tips
- Make sure to select the correct Category to ensure accurate processing of the request.
- Keep the Description concise and clear to help us process the request efficiently.
- Verify the customer's contact information is accurate.
