# Fundraising Event Expense Claim Form - Help Guide
## Purpose
The Fundraising Event Expense Claim Form is used to submit a claim for reimbursement for expenses related to fundraising events. This form helps to gather all necessary information for processing and approval of expense claims.

## How To Complete This Form
1. Fill out the form with the required information, including event details, expense type, description, amount, and date claimed.
2. Attach any supporting documents or receipts as necessary.
3. Review and submit the form.

## Field-by-Field Explanation
* **Event Details** (`event_details`, text, required: false): Enter a brief description of the event.
* **Expense Type** (`expense_type`, select_one, required: false): Select the type of expense (e.g., Cash, In-Kind).
* **Description** (`description`, text, required: false): Briefly describe your expense.
* **Amount** (`amount`, number, required: false): Enter the amount of the expense.
* **Date Claimed** (`date_claimed`, date, required: false): Enter the date you claimed reimbursement for.
* **Date Expensed** (`date_expensed`, date, required: false): Enter the date of the event.
* **Total Claimed** (`total_claimed`, number, required: false): Enter the total amount claimed.
* **Event Total** (`event_total`, number, required: false): Enter the total amount of the event.
* **Reimbursed Amount** (`reimbursed_amount`, number, required: false): Enter the amount already reimbursed.
* **Status** (`status`, select_one, required: false): Select the status of the claim (e.g., Pending, Approved, Rejected).
* **Reason for Rejection** (`reason_for_rejection`, text, required: false): Enter the reason for rejection (if applicable).
* **Attachments** (`attachments`, text, required: false): Upload any supporting documents or receipts.
* **Event Details Attachments** (`event_details_attachments`, text, required: false): Attach any event details documents.
* **Expense Type Attachments** (`expense_type_attachments`, text, required: false): Attach any expense type documents.
* **Description Attachments** (`description_attachments`, text, required: false): Attach any description documents.
* **Date Claimed Attachments** (`date_claimed_attachments`, text, required: false): Attach any date claimed documents.
* **Date Expensed Attachments** (`date_expensed_attachments`, text, required: false): Attach any date expensed documents.
* **Total Claimed Attachments** (`total_claimed_attachments`, text, required: false): Attach any total claimed documents.
* **Event Total Attachments** (`event_total_attachments`, text, required: false): Attach any event total documents.
* **Reimbursed Amount Attachments** (`reimbursed_amount_attachments`, text, required: false): Attach any reimbursed amount documents.
* **Status Attachments** (`status_attachments`, text, required: false): Attach any status documents.
* **Reason for Rejection Attachments** (`reason_for_rejection_attachments`, text, required: false): Attach any reason for rejection documents.
* **Notes** (`notes`, text, required: false): Enter any additional comments.
* **Attachments** (`attachments`, text, required: false): Upload any additional supporting documents.
* **Form Submit** (`form_submit`, text, required: false): Click to submit the form.
* **Attachments** (`form_submit_attachments`, text, required: false): Attach any additional documents with the form submission.
* **Event Date** (`event_date`, date, required: false): Enter the date of the event.
* **Total Expenses** (`total_expenses`, number, required: false): Enter the total amount of expenses.

Tips:
* Make sure to fill out all required fields before submitting the form.
* Attach supporting documents as necessary to support your claim.
* Review and submit the form carefully to ensure accuracy.
* If rejected, review and address the reason for rejection before resubmitting.
