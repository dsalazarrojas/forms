# exhibition_booth_payment_form - Help Guide

## Purpose
This form is used to collect and process payment information for exhibitors at an event or exhibition.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the exhibitor's name and ID, if applicable.
2. Enter the exhibitor's address (up to 3 lines).
3. Select the payment method (Credit Card or Other).
4. Enter any additional details about the payment.
5. Enter the price of the booth.
6. Fill in the exhibitor's email address.
7. Provide the exhibitor's phone number.
8. Add any comments about the payment or booth.

## Field-by-Field Explanation

* **Form ID** (1): A unique identifier for this form.
	+ Type: number
	+ Required: no
* **Exhibitor's Name** (2): The name of the exhibitor.
	+ Type: text
	+ Required: no
* **Exhibitor ID** (3): The ID of the exhibitor, if applicable.
	+ Type: number
	+ Required: no
* **Price** (4): The price of the booth.
	+ Type: number
	+ Required: no
* **Payment Method** (5): The method used for payment (Credit Card or Other).
	+ Type: select_one
	+ Required: no
* **Additional Details** (6): Any additional information about the payment.
	+ Type: note
	+ Required: no
* **Exhibitor Address** (7): The address of the exhibitor (up to 3 lines).
	+ Type: select_multiple
	+ Required: no
* **Email** (8): The email address of the exhibitor.
	+ Type: email
	+ Required: no
* **Phone** (9): The phone number of the exhibitor.
	+ Type: text
	+ Required: no
* **Comments** (10): Any comments about the payment or booth.
	+ Type: text
	+ Required: no
