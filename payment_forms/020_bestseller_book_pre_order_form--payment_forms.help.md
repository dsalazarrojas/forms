# Bestseller Book Pre Order Form - Help Guide

## Purpose
This form is designed to collect pre-order information from customers for the book "Bestseller". The form will be used to gather customer details, shipping preferences, and payment information to facilitate the pre-order and delivery process.

## How To Complete This Form

1. Fill out the form completely and accurately to ensure a smooth pre-order experience.
2. Ensure that all required fields are filled in before submitting the form.
3. Double-check your information for errors before submitting.

## Field-by-Field Explanation

* **Full Name** (`customer_name`, text, required): Enter your full name as you would like to be addressed.
* **Email Address** (`customer_email`, email, required): We will use this to send order confirmation and any other relevant information.
* **Phone Number** (`customer_phone`, text, optional): If you would like to be contacted for order updates, enter your phone number here.
* **Shipping Address** (`shipping_address`, text, required): Enter your complete shipping address where the book should be delivered.
* **City** (`city`, text, required): Enter your city for delivery purposes.
* **State or Province** (`state`, text, required): Enter your state or province for delivery purposes.
* **Postal or ZIP Code** (`postal_code`, text, required): Enter your postal or ZIP code for delivery purposes.
* **Country** (`country`, select_one, required): Select your country of residence for delivery purposes.
* **Book Format** (`book_format`, select_one, required): Choose the format in which you would like to receive the book (e.g., Hardcover, Paperback, Kindle or E-book, Audiobook, etc.).
* **Quantity** (`quantity`, number, required): Enter the number of copies you would like to pre-order.
* **Unit Price** (`unit_price`, number, required): Enter the price per copy.
* **Would You Like Personalization** (`personalization`, select_one, required): If you would like to have the book personalized, select this option.
* **Name for Personalization** (`personalization_name`, text, optional): If you selected personalization, enter the name to be included in the inscription.
* **Would You Like Gift Wrapping** (`gift_wrap`, select_one, optional): Select this option if you would like to have the book gift wrapped.
* **Shipping Method** (`shipping_method`, select_one, required): Choose how you would like your order shipped (e.g., Standard Shipping, Express Shipping, Overnight Shipping, International Shipping).
* **Payment Method** (`payment_method`, select_one, required): Select the payment method you would like to use (e.g., Credit Card, Debit Card, PayPal, Apple Pay, Google Pay, Bank Transfer).
* **Card Number** (`card_number`, text, optional): If you selected a credit or debit card payment method, enter your card number here.
* **Expiry Date** (`expiry_date`, text, optional): If you selected a credit or debit card payment method, enter your expiry date in MM/YY format.
* **CVV** (`cvv`, text, optional): If you selected a credit or debit card payment method, enter your 3-digit security code here.
* **Promotional Code** (`promo_code`, text, optional): If you have a promotional code, enter it here.
* **Special Instructions** (`special_instructions`, text, optional): Enter any special instructions or notes for your order.
* **Would You Like to Join Our Newsletter** (`newsletter_signup`, select_one, optional): Select this option if you would like to join our newsletter to receive updates about new releases and promotions.
* **How Did You Hear About This Book** (`how_heard_about`, select_one, optional): Tell us how you heard about this pre-order (e.g., Social Media, Author Website, Bookstore, Friend or Family, Email Newsletter, Online Advertisement, Book Review, Other).
* **Additional Comments** (`additional_comments`, text, optional): Enter any additional comments or information about your order.
