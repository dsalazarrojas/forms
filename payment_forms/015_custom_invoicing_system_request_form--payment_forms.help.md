# Custom Invoicing System Request Form - Help Guide
## Purpose
The Custom Invoicing System Request Form is designed to gather information about a custom invoicing system requested by your company. This form will help us understand your business needs and provide an accurate quote for the requested system.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with your company information.
2. Select the type of invoicing system you need.
3. Provide the due date and start date for the project.
4. Enter any additional notes or comments.
5. Submit the form once you have completed all the fields.

## Field-by-Field Explanation
* **Company Name** (`company_name`, text, required): Enter your company name as it should appear on the invoice.
* **Contact Person** (`contact_person`, text, required): Please provide the name and title of the person responsible for the project.
* **System Type** (`system_type`, select_one, required): Select the type of invoicing system you are requesting (Yes or No).
* **Invoice Frequency** (`invoice_frequency`, select_one, required): Select the frequency of the invoicing cycle (Yes or No).
* **Due Date** (`due_date`, date, required): Enter the date by which the project must be completed.
* **Start Date** (`start_date`, date, required): Enter the start date of the project.
* **Company Address** (`company_address`, text, required): Enter your company address for contact and payment purposes.
* **Company Phone** (`company_phone`, text, required): Enter your company phone number for contact purposes.
* **Company Email** (`company_email`, email, required): Enter your company email address for contact purposes.
* **Billing Cycle** (`billing_cycle`, select_one, required): Select whether the system has a billing cycle (Yes or No).
* **Payment Terms** (`payment_terms`, select_multiple, required): Select the payment terms for the project (Yes or No).
* **Notes** (`notes`, note, required): Add any additional notes or comments about the project.
* **Additional Notes** (`additional_notes`, note, required): Add any additional notes or comments about the project.
* **System Description** (`system_description`, text, required): Describe the custom invoicing system you are requesting.
* **System Requirements** (`system_requirements`, text, required): List the system requirements for the project.
* **System Limitations** (`system_limitations`, text, required): List any limitations of the system.
* **System Features** (`system_features`, text, required): List any features of the system.
* **System Goals** (`system_goals`, text, required): Describe the system goals.
* **System Purpose** (`system_purpose`, text, required): Describe the system purpose.
* **System Uses** (`system_uses`, text, required): Describe how the system will be used.
* **System Implementation** (`system_implementation`, text, required): Describe the system implementation plan.
* **System Maintenance** (`system_maintenance`, text, required): Describe the system maintenance plan.
* **System Deprecation** (`system_deprecation`, text, required): Describe the system deprecation plan.
* **System Upgrade** (`system_upgrade`, text, required): Describe the system upgrade process.
* **System Downgrade** (`system_downgrade`, text, required): Describe the system downgrade process.
* **Additional Notes** (`additional_notes`, note, required): Add any additional notes or comments about the project.
* **System Uses** (`system_uses`, text, required): Describe how the system will be used. 

Note: Please ensure that you have filled all fields before submitting the form.
