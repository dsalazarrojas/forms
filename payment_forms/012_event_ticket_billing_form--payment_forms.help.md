# Event Ticket Billing Form - Help Guide
## Purpose
The Event Ticket Billing Form is used to collect payment information for events.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the billing address for the event.
2. Provide a valid email address for the billing contact.
3. Enter the phone number of the billing contact.
4. Enter the name of the billing contact.
5. Add any additional notes about the billing details.

## Field-by-Field Explanation
* **Billing Address** (`billing_address`, text, optional): Enter the address where the bill will be sent.
* **Billing Email** (`billing_email`, email, optional): Enter a valid email address for the billing contact.
* **Billing Phone** (`billing_phone`, text, optional): Enter the phone number of the billing contact.
* **Billing Name** (`billing_name`, text, optional): Enter the name of the billing contact.
* **Billing Notes** (`billing_notes`, note, optional): Enter any additional notes or comments about the billing details.
