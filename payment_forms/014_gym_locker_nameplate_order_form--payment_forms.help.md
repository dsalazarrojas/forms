# Gym Locker Nameplate Order Form - Help Guide
## Purpose
This form is used to collect information for ordering a gym locker nameplate. Fill out the form with the required and optional fields to ensure a successful order.

## How To Complete This Form
- Start by selecting the nameplate type that you want to order.
- Fill in the member's details, including name, email address, and phone number.
- Select the payment method and payment amount you would like to use for the order.
- Choose the date and time you would like to receive the nameplate.
- If necessary, select the order details to confirm or decline.

## Field-by-Field Explanation
- **Nameplate Type** (`Nameplate Type`, required): Select the type of nameplate you would like to order.
- **Member Details** (`Member Details`, required): Enter the member's name, ensuring that it matches the information on their membership card.
- **E-mail** (`E-mail`, required): Enter the member's email address, which will be used for communication regarding the order.
- **Phone** (`Phone`, optional): Enter the member's phone number for any additional communication.
- **Payment Method** (`Payment Method`, required): Select the payment method you would like to use for the order.
- **Payment** (`Payment`, required): Enter the payment amount for the order.
- **Date** (`Date`, required): Select the date you would like to receive the nameplate.
- **Time** (`Time`, required): Select the time you would like to receive the nameplate.
- **Order Details** (`Order Details`, optional): If required, select whether the nameplate is to be delivered with order details.

## Tips
- Please ensure all required fields are filled out correctly.
- Double-check the accuracy of the information you have filled out before submitting the form.
