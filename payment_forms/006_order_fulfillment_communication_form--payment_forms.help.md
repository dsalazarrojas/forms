# Order Fulfillment Communication Form - Help Guide
## Purpose

This form is used for customers to communicate with the fulfillment team about their orders. Please use this form to update the order status, or to notify us of any issues that have arisen during the fulfillment process.

## How To Complete This Form

- First, fill out the form completely and accurately.
- Ensure that you are not duplicating a previous communication with the customer.
- If you are communicating with the customer via phone or chat, please provide the order ID so we can easily locate the order.

## Field-by-Field Explanation

* **Customer Name (customer_name, text, required)**: Please enter your name as it appears on your order receipt.
* **Order ID (order_id, number, required)**: Please enter the exact order ID of your order, found on your order receipt.
* **Communication Method (communication_method, select multiple, required)**: Please select one or more preferred methods to communicate with you:
	+ **Email**: We will email you regarding the status updates.
	+ **Phone**: We will contact you via phone to discuss the order status.
	+ **Chat**: We will communicate with you via chat for any updates or concerns.
* **Order Status (order_status, select one, required)**: Please select the current status of your order:
	+ **Placed**: Order has been placed, waiting for fulfillment.
	+ **Processing**: Order is being processed.
	+ **Fulfilled**: Order has been fulfilled and ready for pickup or delivery.
	+ **Cancelled**: Order has been cancelled.
* **Customer Message (customer_message, text, optional)**: If you have any comments or messages regarding your order, please enter here.
* **Customer Signature (customer_signature, note, optional)**: If you have a signature for any reason, please attach it here.
* **Fulfillment Message (fulfillment_message, text, optional)**: If you have any messages for the fulfillment team, please enter here.
* **Fulfillment Status (fulfillment_status, select one, required)**: Please select the status of your order:
	+ **Pending**: Order is pending fulfillment.
	+ **Fulfilled**: Order has been fulfilled.
	+ **Not Fulfilled**: Order has not been fulfilled.
* **Reason for Non-Fulfillment (reason_for_non_fulfillment, select one, optional)**: If your order was not fulfilled due to a reason, please select one of the following:
	+ **Not Found**: Order was not found.
	+ **Out of Stock**: Item(s) were not in stock.
	+ **Customer Refused**: Customer declined to receive the order.
* **Date Ordered (date_ordered, date, required)**: Please enter the date you ordered the item. 

Note to the reader: The date and time should match your local time and date format.
