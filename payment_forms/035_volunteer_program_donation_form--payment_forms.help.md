# volunteer_program_donation_form - Help Guide
## Purpose
The volunteer program donation form is used to capture information about a donor's donation for a volunteer program.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the donation amount and frequency from the respective dropdown menus.
2. Choose the volunteer program you are donating to.
3. Select the payment method you prefer.
4. Enter your email and phone number.
5. Add any additional note (optional).
6. Assign a tool for the donation (optional).
7. Select the category for the donation (optional).
8. Provide a description of the donation (optional).
9. Enter the form ID for the donation.
10. Select the output file format for the form.

## Field-by-Field Explanation

* **donation_amount** (`donation_amount`): The amount you are willing to donate.
* **frequency_of_donations** (`donation_frequency`): Select the frequency of your donation (monthly, one time, or recurring).
* **volunteer_program** (`volunteer_program`): Choose the volunteer program you are donating to.
* **payment_method** (`payment_method`): Select your preferred payment method (credit card, PayPal, or bank transfer).
* **email** (`email`): Enter your email address.
* **phone** (`phone`): Enter your phone number.
* **note** (`note`): Add any additional note about the donation (optional).
* **assigned_tool** (`assigned_tool`): Assign a tool for the donation (optional).
* **category** (`category`): Select the category for the donation (payment forms or Other).
* **description** (`description`): Provide a description of the donation (optional).
* **form_id** (`form_id`): Enter the form ID for the donation.
* **output_file** (`output_file`): Select the output file format for the form.

## Tips
* Make sure to fill out all required fields.
* Ensure you select the correct output file format for your donation information.
