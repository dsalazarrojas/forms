# Single Product W Single Choice Orders - Help Guide
## Purpose
This form is designed to collect information for single-product orders with single-choice options for payment processing and customer information.

## How To Complete This Form

To complete this form, follow the instructions below:

1. Select the Category for the product.
2. Select the Product from the dropdown menu.
3. Enter the Quantity of the product ordered.
4. Select a Single Choice from the dropdown menu.
5. Select Single Choice Orders from the dropdown menu.
6. Enter the Total Value of the order.
7. Select the Order Date and Time.
8. Enter the customer's Email and/or Phone number.
9. Add any additional Customer information in the Customer field.
10. Add any additional Order Notes in the Order Notes field.
11. Select the Payment Method from the dropdown menu.
12. Select any additional Payment Method Orders.
13. Enter the Payment Method Total.
14. Select the Payment Method Date and Time.
15. Add any additional Customer Name information in the Customer Name field.
16. Add any additional Customer Name Notes in the Customer Name Notes field.
17. Enter the Customer Name Value.
17. Add any assigned Tool information in the Assigned Tool field.

## Field-by-Field Explanation

* **Category** (`category`, select): Select the category for the product.
* **Product** (`product`, select): Select the product from the dropdown menu.
* **Quantity** (`quantity`, number): Enter the quantity of the product ordered.
* **Single Choice** (`single_choice`, select): Select a single option from the dropdown menu.
* **Single Choice Orders** (`single_choice_orders`, select): Select a single option from the dropdown menu.
* **Total Value** (`total_value`, number): Enter the total value of the order.
* **Order Date** (`order_date`, date): Select the order date.
* **Order Time** (`order_time`, time): Select the order time.
* **Email** (`email`, email): Enter the customer's email address.
* **Phone** (`phone`, text): Enter the customer's phone number.
* **Customer** (`customer`, note): Add any additional customer information.
* **Customer Orders** (`customer_orders`, note): Add any additional customer orders information.
* **Order Notes** (`order_notes`, note): Add any additional order notes.
* **Payment Method** (`payment_method`, select): Select the payment method.
* **Payment Method Orders** (`payment_method_orders`, select): Select any additional payment method orders.
* **Payment Method Total** (`payment_method_total`, number): Enter the payment method total.
* **Payment Method Date** (`payment_method_date`, date): Select the payment method date.
* **Payment Method Time** (`payment_method_time`, time): Select the payment method time.
* **Customer Name** (`customer_name`, note): Add any additional customer name information.
* **Customer Name Orders** (`customer_name_orders`, note): Add any additional customer name orders information.
* **Customer Name Notes** (`customer_name_notes`, note): Add any additional customer name notes.
* **Customer Name Value** (`customer_name_value`, number): Enter the customer name value.
* **Assigned Tool** (`assigned_tool`, note): Add any assigned tool information.
