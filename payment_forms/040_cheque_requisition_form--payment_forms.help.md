# Cheque Requisition Form - Help Guide
## Purpose
The purpose of this form is to request a cheque payment for a specific amount to a payee for a particular purpose.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you have all necessary supporting documents attached.
2. Fill in your contact information (name, ID number, department, email address, phone number, and request date).
3. Choose the payment urgency level (Routine, Standard, Urgent, or Emergency).
4. Provide details about the payee, including their name, type, and address.
5. Enter the payment amount and currency.
6. Specify the payment purpose and description.
7. Indicate if you have previously paid this payee before.
8. Check the tax implications for this payment (1099 required, other tax forms, no tax implications, or unsure).
9. Select the cheque pickup method (pick up in person, mail to payee, internal mail, or courier).
10. If necessary, provide additional comments or instructions for finance to consider.

## Field-by-Field Explanation

* **Requester Name** (1, text, required): Please enter your full name.
* **Requester ID** (2, text, required): Enter your employee ID number.
* **Department** (3, text, required): Select your department name.
* **Email Address** (4, email, required): Enter your email address.
* **Phone Number** (5, text, required): Enter your contact number.
* **Request Date** (6, date, required): Enter the date of this request.
* **Payment Urgency** (7, select_one, required): Choose the urgency level of this payment:
	+ Routine: Non-urgent payment.
	+ Standard: Standard payment.
	+ Urgent: High-priority payment.
	+ Emergency: Payment with immediate urgency.
* **Required By Date** (8, date, required): Enter the date by which you need the cheque.
* **Payee Name** (9, text, required): Enter the name of the person or entity to be paid.
* **Payee Type** (10, select_one, required): Select the type of payee:
	+ Individual
	+ Company
	+ Government agency
	+ Non-profit organization
	+ Vendor
	+ Contractor
	+ Employee
* **Payee Address** (11, text, required): Enter the full address of the payee.
* **Payment Amount** (12, number, required): Enter the amount to be paid.
* **Currency** (13, select_one, required): Select the currency of the payment:
	+ USD - US Dollar
	+ CAD - Canadian Dollar
	+ EUR - Euro
	+ GBP - British Pound
	+ AUD - Australian Dollar
	+ Other
* **Payment Purpose** (14, select_one, required): Choose the purpose of this payment:
	+ Vendor payment
	+ Contractor payment
	+ Refund
	+ Reimbursement
	+ Service fee
	+ Purchase payment
	+ Loan payment
	+ Other
* **Payment Description** (15, text, required): Enter a detailed description of the payment purpose.
* **Invoice Number** (16, text, optional): If applicable, enter the related invoice number.
* **Invoice Date** (17, date, optional): If applicable, enter the date of the invoice.
* **Purchase Order Number** (18, text, optional): If applicable, enter the PO number.
* **Account to Charge** (19, text, required): Select the budget account or cost center to charge.
* **Budget Code** (20, text, required): Enter the budget code for this expense.
* **Supporting Documents Attached** (21, select_one, required): Check if you have attached all necessary supporting documents:
	+ Yes, all attached
	+ Some attached
	+ Will provide later
	+ Not applicable
* **Types of Documents** (22, select_multiple, optional): Select all documents attached:
	+ Invoice
	+ Purchase order
	+ Contract
	+ Receipt
	+ Approval email
	+ Quote
	+ Other
* **Previous Payments to This Payee** (23, select_one, required): Indicate if you have previously paid this payee before:
	+ Yes, multiple times
	+ Yes, once
	+ No, first time
* **Tax Implications** (24, select_one, required): Check the tax implications for this payment:
	+ Yes, 1099 required
	+ Yes, other tax forms
	+ No tax implications
	+ Not sure
* **Special Instructions** (25, text, optional): If necessary, provide additional comments or instructions for finance to consider.
* **Supervisor Approval** (26, select_one, required): Check if your supervisor has approved this request:
	+ Yes, approved
	+ Pending approval
	+ Not yet requested
* **Supervisor Name** (27, text, optional): Enter the name of your approving supervisor.
* **Supervisor Signature Date** (28, date, optional): Enter the date of supervisor approval.
* **Finance Approval** (29, select_one, required): Check if finance has approved this request:
	+ Yes, approved
	+ Pending approval
	+ Not yet submitted
* **Requester Signature** (30, select_one, required): Certify that this request is accurate:
	+ Yes, I certify
	+ False
* **Cheque Pickup Method** (31, select_one, required): Select how you would like to receive the cheque:
	+ Pick up in person
	+ Mail to payee
	+ Internal mail
	+ Courier
* **Tracking Notes** (32, text, optional): Enter any additional notes for finance use only.
