# Tabletop Gaming Event Payment Form - Help Guide
## Purpose
The Tabletop Gaming Event Payment Form is used to collect information from participants for a tabletop gaming event, including event name, participant details, payment method, and other relevant data. This form helps event organizers gather necessary details for payment processing and event management.

To complete this form, follow these steps:

1. Enter the **Event Name** in the first field. This is a required field and should match the name of the event you are registering for.
2. Enter your **Participant Name** in the second field. This is also a required field and should match your name.
3. Enter the **Price** you are paying for the event in the third field. This is a required field and is used for payment processing.
4. Select the **Event Date** of the event from the calendar picker in the fourth field. This is a required field and should match the date of the event.
5. If applicable, select the **Payment Method** from the dropdown menu in the fifth field.
6. If applicable, select the **Event Organizer** from the dropdown menu in the sixth field.
7. Enter the number of **Participant Count** in the seventh field. This is a required field and is used to determine the number of participants in the event.
8. If applicable, enter the **Registration Date** of the event in the eighth field.
9. Select the **Event Type** from the dropdown menu in the ninth field. This includes options like Board Game, Card Game, and Role Playing Game.
10. If applicable, enter any additional **Notes** about the event or participant in the tenth field.
11. Enter your **Email** address in the eleventh field. This is a required field and is used for communication purposes.
12. Enter your **Phone** number in the twelfth field. This is a required field and is used for contact purposes.
13. If applicable, select the **Event Time** from the time picker in the thirteenth field.
14. Select the **Price Range** from the dropdown menu in the fourteenth field. This includes options like Low, Medium, and High.
15. Enter any additional **Participant Details** in the fifteenth field. This is an optional field and is used for additional information.
16. Enter any additional **Participant Info** in the sixteenth field. This is an optional field and is used for additional information.
17. Select the **Participant Type** from the dropdown menu in the seventeenth field. This includes options like Type 1, Type 2, and Type 3.
