# Courier Service Order Form - Help Guide

## Purpose
The Courier Service Order Form is designed to collect information for a courier service order. To use this form, please ensure that you are in a valid business context and that you have not completed this form previously. The form is used to capture customer details and order specifics, which will be used to process the order and deliver the requested goods or services.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the order date, ensuring it is a valid date in the format `YYYY-MM-DD`.
2. Enter the customer's name in the text box provided.
3. Enter the order time in 24-hour format (HH:MM).
4. Provide the customer's address in the text box.
5. Enter the customer's email address in the format `example@example.com`.
6. Enter the customer's phone number in the text box.
7. Add any additional order details in the text box provided.

## Field-by-Field Explanation
* **Order Date** (`order_date`, date, not required): This field is used to capture the date of the order. Please ensure it is in the format `YYYY-MM-DD`.
* **Customer Name** (`customer_name`, text, not required): This field is used to capture the name of the customer.
* **Order Time** (`order_time`, time, not required): This field is used to capture the time of the order in 24-hour format (HH:MM).
* **Order Address** (`order_address`, text, not required): This field is used to capture the address of the order location.
* **Customer Email** (`customer_email`, email, not required): This field is used to capture the email address of the customer. Please note that this should be in the format `example@example.com`.
* **Customer Phone** (`customer_phone`, text, not required): This field is used to capture the phone number of the customer.
* **Order Details** (`order_details`, text, not required): This field is used to capture any additional information about the order.
