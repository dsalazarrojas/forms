# Digital Payment Integration Request Form - Help Guide
## Purpose
This form is used to request integration of digital payments with our system. It helps us understand the type of integration you need and ensures a smooth and secure setup process.

## How To Complete This Form
To complete this form, simply select the type of integration you require, choose your payment method, and provide any additional details as requested. Fill in the required fields carefully, and don't hesitate to ask if you have any questions or concerns.

## Field-by-Field Explanation
* **What is the type of integration you are requesting?** (`payment_method`, select_one): This field allows you to choose the type of digital payment integration you need. Please select from the options provided.
* **What is the payment method you are using?** (`payment_method`, select_multiple): Here, you select the payment method you want to use (e.g., Stripe, PayPal, Bank Transfer).
* **Describe your payment method in more detail.** (`payment_method_description`, note): If you need to provide more information about your chosen payment method, please type it in this field.
* **Describe your payment gateway in more detail.** (`payment_gateway_description`, note): If you need to provide more information about your payment gateway, please type it in this field.
* **What is the merchant ID?** (`merchant_id`, number): Enter your merchant ID if applicable.
* **What is the merchant key?** (`merchant_key`, text): Enter your merchant key if applicable.
* **What is the API key?** (`api_key`, text): Enter your API key if you're using API integration.
* **What is the API secret?** (`api_secret`, text): Enter your API secret if you're using API integration.
* **Do you confirm your payment method selection?** (`confirm`, select_one): Confirm your payment method selection to ensure everything is correct.
* **Payment Gateway Details** (`payment_gateway_details`, note): If you have any additional information about your payment gateway, type it in this field.
* **Payment Method Details** (`payment_method_details`, note): If you have any additional information about your payment method, type it in this field.
* **Is the merchant account already set up?** (`payment_method_details_2`, checkbox): If you have a merchant account set up already, select the correct option.
* **If set up, provide more details about the merchant account.** (`payment_gateway_details_2`, note): If you have a merchant account set up, provide more details about it in this field.
* **Are you sure about your payment method selection?** (`payment_method_details_3`, note): Double-check your payment method selection before submitting the form.
* **Is everything correct?** (`payment_gateway_details_3`, note): Double-check your payment gateway selection before submitting the form.
* **Do you have any further questions or concerns?** (`payment_method_details_4`, note): If you have any questions or concerns, type them in this field.
* **Describe the payment gateway you selected.** (`payment_gateway_details_4`, note): If you need to provide more information about your selected payment gateway, type it in this field.
* **Payment Gateway Details 5** (`payment_gateway_details_5`, note): This field is not currently used, please ignore.
* **Payment Gateway Details 6** (`payment_gateway_details_6`, note): This field is not currently used, please ignore.

Please fill out this form carefully and let us know if you have any questions or concerns. We'll be happy to help with any issues you may encounter.
