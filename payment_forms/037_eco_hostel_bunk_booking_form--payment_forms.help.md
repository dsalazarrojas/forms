# Eco Hostel Bunk Booking Form - Help Guide

## Purpose
The Eco Hostel Bunk Booking Form is designed for hostels and small lodging operators to collect reservations, payments, and guest details efficiently.

## How To Complete This Form
To complete the form, follow these steps:

1. Enter the title of the form and any description you'd like to provide. This form is meant to collect eco-hostel bunk reservations.
2. Select the category of the form from the options provided.
3. You can leave the category as "Payment Forms" if you are using it for payment purposes.
4. The description field should be filled with a brief description of the form.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, optional): Enter the title of the form, e.g., "Eco Hostel Bunk Booking Form".
* **Category** (`category`, select_one, optional): Choose a category for the form from the options provided (Payment Forms, Other Forms, Special Use Forms, Forms for Travel Agency).
* **Description** (`description`, text, optional): Enter a brief description of the form, e.g., "Collect eco hostel bunk reservations, payments, and guest details in one place."
* **Form ID** (`form_id`, text, optional): Enter a unique ID for the form, e.g., "EHB-001".
* **Form Category** (`form_category`, text, optional): Enter the category of the form, e.g., "Payment Forms".
* **Form Description** (`form_description`, text, optional): Enter a brief description of the form, e.g., "Collect eco-hostel bunk reservations and payments."
* **Output File** (`form_output_file`, text, optional): Enter the file name to save the form output, e.g., "eco_hostel_bunk_reservations.csv".
* **Assigned Tool** (`assigned_tool`, text, optional): Enter the tool assigned to this form, e.g., "Google Sheets".

## Tips
* Make sure to enter the correct category and description to help you and others understand the purpose of the form.
* Use the form ID, category, and description fields for organization and identification.
* The form output file can be used for reporting or data analysis purposes.
