# Main Course Selection Form - Help Guide
## Purpose

The Main Course Selection Form is used to gather information from users regarding their course selections and preferences for events.

## How To Complete This Form

1. Fill out the form with the required and optional information.
2. Select the "Select a Course" option to choose from multiple courses.
3. In the "Additional Courses" field, select multiple courses if you want to.
4. Enter the event date in the "Event Date" field.
5. Select the start time in the "Start Time" field.
6. Select the end time in the "End Time" field.
7. Choose your meal preferences in the "Meal Preferences" field.
8. Enter the number of guests in the "Number of Guests" field.
9. Select the contact method in the "Contact Method" field.
10. Enter your contact information in the "Contact Information" field.

## Field-by-Field Explanation

* **Select a Course** (`main_course_selection_form_1`, select_multiple, required: false): This field is used to select multiple courses. Choose from the provided options.
* **Additional Courses** (`main_course_selection_form_2`, select_multiple, required: false): Select multiple courses if you want to. This field is used to select additional courses.
* **Event Date** (`event_date`, date, required: false): Enter the date of the event.
* **Start Time** (`start_time`, time, required: false): Select the start time of the event.
* **End Time** (`end_time`, time, required: false): Select the end time of the event.
* **Meal Preferences** (`meal_preferences`, select_one, required: false): Choose your meal preferences from the provided options.
* **Number of Guests** (`number_of_guests`, number, required: false): Enter the number of guests.
* **Contact Method** (`contact_method`, select_one, required: false): Select the method of contact from the provided options.
* **Contact Information** (`contact_info`, text, required: false): Enter your contact information.

## Tips

* Make sure to fill out all required fields.
* Choose only one option for "Meal Preferences" and "Contact Method".
* Enter a valid date and time for "Event Date", "Start Time", and "End Time".
* Enter a valid number for "Number of Guests".
