### Field-by-Field Explanation

* **Billing Info**:
	+ Type: text
	+ Required: false
	+ Description: Enter the billing information of the guest or customer, including their name, address, etc.
* **Guest Charge**:
	+ Type: number
	+ Required: false
	+ Description: Enter the guest's charge as a numerical value.
* **Room Rate**:
	+ Type: number
	+ Required: false
	+ Description: Enter the room rate as a numerical value.
* **Service Charge**:
	+ Type: number
	+ Required: false
	+ Description: Enter the service charge as a numerical value.
* **Total Amount**:
	+ Type: number
	+ Required: false
	+ Description: Enter the total amount as a numerical value.
* **Payment Terms**:
	+ Type: select_one
	+ Required: false
	+ Description: Select the payment terms from the drop-down menu.
* **Service Type**:
	+ Type: select_multiple
	+ Required: false
	+ Description: Choose the service type from the multi-select option.
* **Date**:
	+ Type: date
	+ Required: false
	+ Description: Enter the date of the billing.
* **Time**:
	+ Type: time
	+ Required: false
	+ Description: Enter the time of the billing.
* **Email**:
	+ Type: email
	+ Required: false
	+ Description: Enter the email address of the guest or customer.
* **Phone**:
	+ Type: text
	+ Required: false
	+ Description: Enter the phone number of the guest or customer.
