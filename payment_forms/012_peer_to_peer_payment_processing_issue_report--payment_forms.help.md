# Peer To Peer Payment Processing Issue Report - Help Guide
## Purpose
The Peer To Peer Payment Processing Issue Report is a structured form used to report any issues related to peer-to-peer payment processing. This form helps the support team to efficiently track and resolve payment issues.

## How To Complete This Form
To complete this form, please follow these steps:

1. Please select the type of payment issue you're experiencing from the options provided.
2. Enter the amount involved in the issue.
3. Provide the date when the issue occurred.
4. Describe the issue in detail, including any relevant screenshots or descriptions.
5. If necessary, provide additional user information such as phone number.
6. Choose the status of the issue (e.g., new, reopened, etc.).
7. Indicate the priority level of the issue (e.g., high, low, etc.).
8. Select the support team member assigned to handle your issue.
9. If necessary, provide additional support information.
10. Provide the date when the issue was assigned to the support team.
11. If necessary, provide the date when the issue was closed.
12. Include any resolution information, if applicable.
13. Provide any payment information, if applicable.
14. Enter any additional notes or comments about the issue.
15. Enter your email address, if you have one.

## Field-by-Field Explanation

* **Payment Issue Information** (`payment_issue_info`, text, required/optional): This is the main section where you describe the payment issue you're experiencing.
* **Payment Type** (`payment_type`, select_one, required/optional): Select the type of payment issue you're experiencing from the options provided.
* **Amount Involved** (`amount_involled`, number, required/optional): Enter the amount involved in the issue.
* **Issue Date** (`issue_date`, date, required/optional): Enter the date when the issue occurred.
* **Description** (`description`, text, required/optional): Describe the issue in detail, including any relevant screenshots or descriptions.
* **Screenshot** (`screenshot`, text, required/optional): Attach any relevant screenshots that may help the support team understand the issue.
* **Screenshot Description** (`screenshot_description`, text, required/optional): Describe any attached screenshots.
* **User Information** (`user_info`, text, required/optional): Enter any user information you'd like to share with the support team.
* **User Phone** (`user_phone`, text, required/optional): Enter your phone number, if you'd like to be contacted.
* **Issue Status** (`issue_status`, select_one, required/optional): Choose the status of the issue from the options provided (e.g., new, reopened, etc.).
* **Issue Priority** (`issue_priority`, select_one, required/optional): Indicate the priority level of the issue from the options provided (e.g., high, low, etc.).
* **Support Information** (`support_info`, text, required/optional): Enter any additional support information, if necessary.
* **Support Team** (`support_team`, select_one, required/optional): Select the support team member assigned to handle your issue.
* **Support Team Description** (`support_team_description`, text, required/optional): Describe the support team member's role, if necessary.
* **Assigned Date** (`assigned_date`, date, required/optional): Enter the date when the issue was assigned to the support team.
* **Closed Date** (`closed_date`, date, required/optional): Enter the date when the issue was closed, if applicable.
* **Resolution Information** (`resolution_info`, text, required/optional): Enter any resolution information, if applicable.
* **Payment Information** (`payment_info`, text, required/optional): Enter any payment information, if applicable.
* **Notes** (`notes`, note, required/optional): Enter any additional notes or comments about the issue.
* **Email** (`email`, email, required/optional): Enter your email address, if you have one.
* **Payment Provider** (`payment_provider`, text, required/optional): Enter the payment provider involved in the issue.
* **Payment Provider Information** (`payment_provider_info`, text, required/optional): Enter any additional information about the payment provider involved.
* **Bank Name** (`bank_name`, text, required/optional): Enter the bank involved in the issue.
* **Bank Branch** (`bank_branch`, text, required/optional): Enter the bank branch involved in the issue.
