# event_ticking_subscription_form - Help Guide
## Purpose
This form is used to create and manage ticket subscriptions for events. It allows you to set up ticket pricing, payment methods, and track attendee information.

## How To Complete This Form
1. Select a "Ticket Type" from the drop-down menu to choose the type of ticket you are selling.
2. Enter the "Attendee Count" to determine how many tickets you are purchasing.
3. Enter the "Start Date" and "End Date" for the event.
4. Enter the "Event Name" to identify the event.
5. Enter the "Ticket Price" for each ticket.
6. Select a "Payment Method" from the drop-down menu to choose how you will be paying (e.g., "Pay Now" or "Pay Later").
7. Enter the "Attendee Email" and "Attendee Phone" for each attendee if necessary.
8. Enter a "Event Description" to provide more information about the event.
9. Choose the "Ticket Status" as either "Available" or "Sold Out" depending on the status of the tickets.
10. Add any additional "Payment Note" if necessary.
11. Enter the "Ticket Number" if required.
12. Set up the "Subscription Start Date" and "Subscription End Date" if necessary.

## Field-by-Field Explanation
* **Ticket Type**: Select the type of ticket you are selling (e.g., Single or Multiple).
* **Attendee Count**: Enter the number of tickets you are purchasing.
* **Start Date**: Enter the start date of the event.
* **End Date**: Enter the end date of the event.
* **Event Name**: Enter the name of the event.
* **Ticket Price**: Enter the price for each ticket.
* **Payment Method**: Select a payment method from the drop-down menu (e.g., "Pay Now" or "Pay Later").
* **Attendee Email**: Enter the email address for each attendee if required.
* **Attendee Phone**: Enter the phone number for each attendee if required.
* **Event Description**: Enter a description of the event.
* **Ticket Status**: Choose the status of the ticket as either "Available" or "Sold Out."
* **Payment Note**: Add any additional payment-related information if necessary.
* **Ticket Number**: Enter the ticket number if required.
* **Subscription Start Date**: Enter the start date of the subscription if necessary.
* **Subscription End Date**: Enter the end date of the subscription if necessary.
* **Payment Method Note**: Add any additional notes about the payment method if necessary.
