**event_planning_payment_form - Help Guide**

## Purpose
This form is used to collect essential information about event planning and payment details.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the "Event Organizer" field with the name of the event organizer.
2. Select the "Payment Method" from the dropdown list.
3. Enter the "Amount" paid for the event.
4. Fill in any additional comments or notes in the "Note" field.
5. Select the "Event Date" and "Event Time" for the event.
6. Select the "Payment Status" from the dropdown list.
7. Select the "Assigned Tool" from the dropdown list.
8. Enter the "Form ID" (optional).
9. Select the "Category" from the dropdown list.
10. Enter any additional "Description" of the form.
11. Enter the "Title" of the form.

## Field-by-Field Explanation

* **Event Organizer** (`event_organizer`, text, required): Enter the name of the event organizer.
* **Payment Method** (`payment_method`, select_one, required): Select the payment method used for the event (e.g., Visa, Mastercard, American Express).
* **Amount** (`amount`, number, required): Enter the amount paid for the event.
* **Note** (`note`, note, optional): Enter any additional comments or notes about the event.
* **Email** (`email`, email, optional): Enter the email of the event organizer (optional).
* **Phone** (`phone`, text, optional): Enter the phone number of the event organizer (optional).
* **Event Date** (`event_date`, date, required): Select the date of the event.
* **Event Time** (`event_time`, time, required): Select the time of the event.
* **Payment Status** (`payment_status`, select_one, required): Select the status of the payment (e.g., Pending, Received, Failed).
* **Assigned Tool** (`assigned_tool`, select_one, required): Select the tool assigned to the event (e.g., chatjimmy, chatjenny, other).
* **Form ID** (`form_id`, number, optional): Enter a unique form ID (optional).
* **Category** (`category`, select_one, required): Select the category of the form (e.g., Payment Forms, Other).
* **Output File** (`output_file`, text, optional): Enter any output file associated with the form (optional).
* **Description** (`description`, text, optional): Enter a brief description of the form (optional).
* **Title** (`title`, text, optional): Enter the title of the form (optional).
