# Invoice Transparency Feedback Form - Help Guide
## Purpose
The purpose of this form is to gather feedback about the transparency of our invoicing process. If you have received an invoice from us and have thoughts or suggestions on how we can improve, this is the right place to share them.

## How To Complete This Form
1. Select the rating of our invoicing process by choosing one of the options from the dropdown menu.
2. Choose the type of invoice you received by selecting one or more options from the list. This will help us understand what type of invoice was received.
3. If you have any comments or suggestions on how we can improve, please type them in the text field.
4. If you would like to be contacted about your feedback, please enter your contact email address.
5. Please enter your name for our records.
6. Select the tool that this form is assigned to, if applicable.
7. Choose the category that this form is assigned to, if applicable.
8. Select the form ID to ensure that your feedback is linked to the correct invoice.
9. If you have any additional comments or feedback, please enter them in the text field.

## Field-by-Field Explanation
* **Rate our invoicing process** (`Rating`, `select_one`, required: false): Please select one of the options to rate our invoicing process. This will help us understand your opinion about our transparency.
* **What type of invoice did you receive?** (`Invoice type`, `select_multiple`, required: false): Please select one or more options that apply to the type of invoice you received.
* **What can we improve?** (`Comments`, `text`, required: false): If you have any comments or suggestions on how we can improve our transparency, please type them in this field.
* **Contact email** (`Contact email`, `email`, required: false): If you would like to be contacted about your feedback, please enter your contact email address.
* **Name** (`Name`, `text`, required: false): Please enter your name for our records.
* **Which tool is this form assigned to?** (`Tool`, `select_multiple`, required: false): If this form is assigned to a specific tool, please select the tool from the list.
* **Category** (`Category`, `select_multiple`, required: false): If this form is assigned to a specific category, please select the category from the list.
* **Form ID** (`Form ID`, `select_one`, required: false): Please select the form ID to ensure that your feedback is linked to the correct invoice.
* **Form Id 2** (`Form Id 2`, `select_one`, required: false): Please select the form ID 2 to ensure that your feedback is linked to the correct invoice.
* **Form propeirts** (`Form propeirts`, `text`, required: false): Please enter any additional comments or feedback in this field.
* **Form prophets** (`Form prophets`, `text`, required: false): Please enter any additional comments or feedback in this field.
