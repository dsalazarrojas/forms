# Desktop Calendar Order Form - Help Guide
## Purpose
The Desktop Calendar Order Form is a form used to collect customer information and order specifics for desktop calendar purchases.

## How To Complete This Form

1. Fill in the required fields with your accurate and complete information. This includes:
	* `first_name` (Your first name)
	* `last_name` (Your last name)
	* `email` (Your email address)
	* `phone` (Your phone number)
	* `date` (Order date)
	* `time` (Order time)
2. For the optional fields, select the options that best match your situation:
	* `select_one` (Select one of the options: Option 1, Option 2, or Option 3)
	* `select_multiple` (Select multiple of the options: Option 1, Option 2)
	* `payment_method` (Select one of the options: credit, cash, paypal)
	* `payment_amount` (Enter the total order amount)
	* `order_type` (Enter a brief description of the order)
	* `ship_address` (Enter your shipping address)
	* `ship_city` (Enter the city for the shipping address)
	* `ship_state` (Enter the state for the shipping address)
	* `ship_zip` (Enter the zip code for the shipping address)
	* `ship_country` (Enter the country for the shipping address)
	* `ship_phone` (Enter the phone number for the shipping address)
	* `ship_email` (Enter the email address for the shipping address)
	* `ship_note` (Enter any additional notes for the shipping address)
	* `ship_date` (Ship date)
	* `ship_time` (Ship time)

## Field-by-Field Explanation
* **first_name** (First Name, Text, Required): Enter your first name.
* **last_name** (Last Name, Text, Required): Enter your last name.
* **email** (Email, Email, Required): Enter your email address.
* **phone** (Phone, Text, Optional): Enter your phone number.
* **select_one** (Select One, Select One, Optional): Select one of the options: Option 1, Option 2, or Option 3.
* **select_multiple** (Select Multiple, Select Multiple, Optional): Select multiple of the options: Option 1, Option 2.
* **date** (Date, Date, Optional): Enter the order date.
* **time** (Time, Time, Optional): Enter the order time.
* **payment_method** (Payment Method, Select One, Optional): Select one of the options: credit, cash, paypal.
* **payment_amount** (Payment Amount, Number, Optional): Enter the total order amount.
* **order_type** (Order Type, Text, Optional): Enter a brief description of the order.
* **order_details** (Order Details, Text, Optional): Enter any additional details about the order.
* **ship_address** (Ship Address, Text, Optional): Enter your shipping address.
* **ship_city** (Ship City, Text, Optional): Enter the city for the shipping address.
* **ship_state** (Ship State, Text, Optional): Enter the state for the shipping address.
* **ship_zip** (Ship Zip, Text, Optional): Enter the zip code for the shipping address.
* **ship_country** (Ship Country, Text, Optional): Enter the country for the shipping address.
* **ship_phone** (Ship Phone, Text, Optional): Enter the phone number for the shipping address.
* **ship_email** (Ship Email, Text, Optional): Enter the email address for the shipping address.
* **ship_note** (Ship Note, Text, Optional): Enter any additional notes for the shipping address.
* **ship_date** (Ship Date, Date, Optional): Enter the ship date.
* **ship_time** (Ship Time, Time, Optional): Enter the ship time.
* **confirm** (Confirm, Note, Optional): Enter any confirmation notes.
* **confirm_payment_method** (Confirm Payment Method, Select One, Optional): Select one of the options: confirm credit, confirm cash, confirm paypal.
