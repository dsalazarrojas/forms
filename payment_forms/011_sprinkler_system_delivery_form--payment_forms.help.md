# Sprinkler System Delivery Form - Help Guide
## Purpose
The Sprinkler System Delivery Form is used to record the details of a customer's sprinkler system delivery. This form captures key information such as customer name, delivery date and time, order number, sprinkler system type, delivery status, delivery address, and customer phone number.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Make sure to select the correct Sprinkler System option from the dropdown list.
3. For the Delivery Status field, select all applicable statuses (e.g., Delivered, Pending, Canceled).
4. Enter the customer's delivery address in the provided text area.
5. Enter the customer's phone number in the provided text field.

## Field-by-Field Explanation
* **Customer Name** (`customer_name`, text, optional): Enter the name of the customer who received the delivery.
* **Delivery Date** (`delivery_date`, date, optional): Select the date of the delivery from the calendar picker or enter manually in the format `YYYY-MM-DD`.
* **Delivery Time** (`delivery_time`, time, optional): Select the time of the delivery in the format `HH:MM`.
* **Order Number** (`order_number`, text, optional): Enter the order number associated with the delivery.
* **Sprinkler System** (`sprinkler_system`, select one, optional): Select the type of sprinkler system delivered.
* **Delivery Status** (`delivery_status`, multiple select, optional): Select all applicable statuses that apply to the delivery (e.g., Delivered, Pending, Canceled).
* **Delivery Address** (`delivery_address`, note, optional): Enter the delivery address in the provided text area.
* **Customer Phone** (`customer_phone`, text, optional): Enter the customer's phone number.

## Tips
- Make sure to fill out all required fields before submitting the form.
- If unsure about any field, please ask for assistance.
- Ensure that the information entered is accurate and up-to-date.
- Submit the form only when all fields are complete and accurate.
