# fitness_challenge_medal_design_order_form - Help Guide
## Purpose
The fitness challenge medal design order form is a form for ordering medals for a fitness challenge event or program.

## How To Complete This Form
1. **Participant Information**: Start by filling out the Participant Information section, which includes fields for participant name, email, phone number, and order date.
2. **Design Preferences**: In the Design Preferences section, select the desired medal type, color, size, and design ribbon options.
3. **Custom Message**: If you would like to add a custom message to your medal, you can do so in the Custom Message section.
4. **Payment Details**: In the Payment Details section, select the desired payment method and provide any additional payment details.
5. **Order Total**: Finally, enter the order total to complete your order.

## Field-by-Field Explanation
- **Participant Name**: Enter the participant's name as it should appear on the medal.
- **Participant Email**: Enter the participant's email address.
- **Participant Phone**: Enter the participant's phone number.
- **Participant Name Hints**: Enter any hints or notes about the participant's name.
- **Participant Email Hints**: Enter any hints or notes about the participant's email.
- **Participant Phone Hints**: Enter any hints or notes about the participant's phone number.
- **Order Date**: Enter the date the order is being placed.
- **Order Time**: Enter the time the order is being placed.
- **Medal Type**: Select the type of medal you would like to order.
- **Color**: Select the color of the medal you would like to order.
- **Size**: Select the size of the medal you would like to order.
- **Ribbon Options**: Select the ribbon option(s) you would like to include on your medal.
- **Custom Message**: Enter any custom message you would like to appear on the medal.
- **Custom Message Hints**: Enter any hints or notes about the custom message.
- **Custom Message Hints Options**: Select the option(s) you would like to include in your custom message.
- **Payment Method**: Select the payment method you would like to use (e.g. credit card, PayPal, etc.).
- **Payment Details**: Enter any additional payment details or instructions.
- **Order Total**: Enter the total amount of your order.
- **Order Notes**: Enter any notes or comments about your order.
