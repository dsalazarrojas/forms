# Quick Release Adapter Order Form - Help Guide
## Purpose
The Quick Release Adapter Order Form is used to collect necessary information for placing an order for a quick release adapter from a supplier. It's recommended to fill out this form only once for each new order.

## How To Complete This Form
To complete this form, start by providing the supplier's name and address. You will also need to enter the contact person's name, email, phone number, and any customer message you may have. 

Next, enter the order quantity, unit price, and subtotal for the adapter order. Select the preferred payment method from the given options and choose a shipping date and time if necessary. Decide on the delivery method, which can be pickup, delivery, or shipping. 

Finally, update the payment status, shipping status, and order status fields as per the order's current state.

## Field-by-Field Explanation
### Supplier Name (1)
* **Supplier Name**: Enter the name of the supplier from whom you are placing the order.

### Address (2)
* **Address**: Enter the supplier's address for delivery purposes.

### Contact Name (3)
* **Contact Name**: Enter the name of the contact person associated with the supplier.

### Email (4)
* **Email**: Enter the contact person's email address.

### Phone (5)
* **Phone**: Enter the contact person's phone number.

### Quantity Ordered (6)
* **Quantity**: Enter the quantity of the quick release adapter ordered.

### Unit Price (7)
* **Unit Price**: Enter the unit price of the quick release adapter.

### Subtotal (8)
* **Subtotal**: This will be calculated automatically, but you can enter it if you prefer.

### Payment Method (9)
* **Payment Method**: Select the preferred payment method, which can be Stripe, PayPal, or Bank Transfer.

### Shipping Date (10)
* **Shipping Date**: Enter the date on which the shipping should take place.

### Shipping Time (11)
* **Shipping Time**: Enter the time at which the shipping should take place.

### Delivery Method (12)
* **Delivery Method**: Select the delivery method, which can be Pickup, Delivery, or Shipping.

### Comments (13)
* **Comments**: Enter any comments or additional information you may have about the order.

### Assigned Tool (14)
* **Assigned Tool**: Enter the tool assigned to the order if applicable.

### Assigned Tool ID (15)
* **Assigned Tool ID**: Enter the ID of the assigned tool if applicable.

### Customer Name (16)
* **Customer Name**: Enter the name of the customer associated with the order.

### Customer Address (17)
* **Customer Address**: Enter the customer's address for delivery purposes.

### Customer Email (18)
* **Customer Email**: Enter the customer's email address.

### Customer Phone (19)
* **Customer Phone**: Enter the customer's phone number.

### Customer Message (20)
* **Customer Message**: Enter any message or note to the customer.

### Payment Status (21)
* **Payment Status**: Update the payment status as per the order's current state, which can be Paid, Unpaid, or Partially Paid.

### Shipping Status (22)
* **Shipping Status**: Update the shipping status as per the order's current state, which can be Confirmed, Pending, or Cancelled.

### Order Status (23)
* **Order Status**: Update the order status as per the order's current state, which can be Completed, Open, or Cancelled.

### Form ID (24)
* **Form ID**: This field is not editable, it's an internal tracking number.

### Form Version (25)
* **Form Version**: This field is not editable, it's the version number of the form.

Note: This help guide is a simplified version, and actual field labels and options might vary based on the actual form implementation.
