# Home Security System Bundle Order Form - Help Guide
## Purpose
The Home Security System Bundle Order Form is used to collect information from customers or end-users about their home security system bundle orders.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the customer's information in the fields provided, including name, address, phone number, and email.
2. Provide the phone number and installation date/time if applicable.
3. Select the system bundles for the order.
4. Enter any additional comments about the order if necessary.
5. Specify the payment method and provide any relevant payment details.
6. Optionally, provide information about the assigned tool and user if applicable.

## Field-by-Field Explanation
* **Customer Information (Customer Information, text, required)**: Enter the customer's name and any other relevant contact information.
* **Address (Address, text, required)**: Enter the customer's address for delivery or installation.
* **Phone Number (Phone Number, text, required)**: Enter the customer's phone number.
* **Email (Email, email, required)**: Enter the customer's email address.
* **System Details (System Details, text, required)**: Describe the type and quantity of the home security system bundle being ordered.
* **Installation Date (Installation Date, date, required)**: Enter the date of the installation.
* **Installation Time (Installation Time, time, required)**: Enter the time of the installation.
* **System Bundles (System Bundles, select multiple, required)**: Select all the system bundles that the customer has ordered.
* **Total System Cost (Total System Cost, number, required)**: Enter the total cost of the system bundle.
* **Payment Method (Payment Method, select one, required)**: Select the payment method (e.g. credit card, bank transfer).
* **Payment Details (Payment Details, text, required)**: Enter any additional payment details.
* **Comments (Comments, note, optional)**: Provide any additional comments about the order.
* **Assigned Tool (Assigned Tool, text, optional)**: If applicable, enter the tool assigned to the customer.
* **Assigned User (Assigned User, text, optional)**: If applicable, enter the user assigned to the customer.
