# Healthy Shake Request Form - Help Guide
## Purpose
The Healthy Shake Request Form is designed to collect user information for a healthy shake request. This form is used to gather details necessary for fulfilling a user's request for a healthy shake, such as user contact information, shake details, payment information, and delivery preferences.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the **User Info** section with your name, email address, and phone number.
2. Provide details about the **Shake Details** you are requesting, such as the type of shake and any specific ingredients or allergies you have.
3. Select your preferred **Payment Method** from the available options (Cash, PayPal, Visa, Mastercard, or American Express).
4. Choose your preferred **Delivery Method** by selecting one or more options (Pickup or Delivery).

## Field-by-Field Explanation
* **user_info**:
	+ Type: Text Input
	+ Description: This field is for your name, email address, and phone number.
* **shake_details**:
	+ Type: Text Input
	+ Description: Please provide details about the shake you are requesting, such as the type of shake and any specific ingredients or allergies you have.
* **payment_info**:
	+ Type: Text Input
	+ Description: This field is for your payment method information. Please enter the required details for the payment method you selected.
* **other_info**:
	+ Type: Select One
	+ Description: Please select your preferred payment method from the available options (Cash, PayPal, Visa, Mastercard, or American Express).
* **delivery_method**:
	+ Type: Select Multiple
	+ Description: Please choose one or more delivery options (Pickup or Delivery).
