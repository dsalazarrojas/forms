# same-day-delivery-form - Help Guide
## Purpose
This form is used to collect information for same-day delivery services. It's essential to fill out the form accurately to ensure a smooth delivery experience.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the customer information section with the relevant details.
2. Specify the delivery time and date for the order.
3. Select the payment method for the order.
4. Enter the phone number of the customer.
5. Add any additional customer notes.
6. Update the delivery status as needed.
7. Add more customer notes if necessary.
8. Specify the delivery time again, if required.

## Field-by-Field Explanation
* **Customer Info**: Enter the customer's name and any other relevant information.
* **Delivery Time**: Choose the time of day for the delivery.
* **Delivery Date**: Choose the date for the delivery.
* **Payment Method**: Select the payment method for the order. (Cash, Credit Card, PayPal)
* **Phone Number**: Enter the customer's phone number.
* **Customer Notes**: Add any additional notes about the customer.
* **Delivery Status**: Update the delivery status as needed (Pending, Confirmed, Cancelled).
* **More Customer Notes**: Add any additional customer notes.
* **Delivery Time 2**: Choose the time of day for the delivery, if required.
* **Phone Number**: Enter the customer's phone number again, for confirmation or further details.
* **Customer Notes**: Add any additional notes about the customer, if necessary.
* **Delivery Status**: Update the delivery status as needed.
* **More Customer Notes**: Add any additional customer notes, if necessary.
* **Payment Method**: Select the payment method for the order, if not already selected.
