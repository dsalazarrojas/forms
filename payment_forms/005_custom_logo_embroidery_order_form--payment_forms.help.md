# Custom Logo Embroidery Order Form - Help Guide
## Purpose
This form is used to collect information for custom logo embroidery orders. Please use this guide to ensure accurate and complete submission of the required information.

## How To Complete This Form

1. **Upload logo**: Upload your logo file by clicking on the "Upload logo" field. Ensure the file is in a supported format and of sufficient quality for embroidery.
2. **Product name**: Enter the name of the product that the custom logo will be applied to (e.g., t-shirt, mug, etc.).
3. **Quantity**: Enter the number of items you would like to order.
4. **Color**: Enter the color of the logo you would like to use (if different from the product's default color).
5. **Size**: Enter the size of the logo to be embroidered (e.g., small, medium, large).
6. **Thread color**: Enter the thread color to be used for the embroidery (if different from the product's default thread color).
7. **Font style**: Choose whether to use a font for the custom logo (Yes/No).
8. **Font size**: Choose the font size for the custom logo (if font style is "Yes") (Yes/No).
9. **Logo type**: Choose the type of logo to be used (e.g., vector, raster) (Yes/No).
10. **Product type**: Choose the type of product the custom logo will be applied to (e.g., apparel, promotional product) (Yes/No).
11. **Quantity per design**: Enter the number of items per design.
12. **Order date**: Enter the desired date for the order to be fulfilled.
13. **Order time**: Enter the desired time for the order to be fulfilled.
14. **Payment method**: Choose the payment method to be used for the order (Yes/No).
15. **Notes**: Add any additional information or comments for the order (optional).
16. **Email**: Enter your email address (for order confirmation and updates).
17. **Phone**: Enter your phone number (for communication and updates).
18. **Billing address**: Enter your billing address.
19. **Shipping address**: Enter the shipping address (if different from the billing address).
20. **Payment gateway**: Choose the payment gateway to be used (Yes/No).
21. **Order details**: Add any additional information or comments for the order (optional).
22. **Order notes**: Add any additional information or comments for the order (optional).
23. **Total cost**: This field will be populated automatically after submitting the order.
24. **Payment status**: This field will be populated automatically after submitting the order.
25. **Payment date**: This field will be populated automatically after submitting the order.
