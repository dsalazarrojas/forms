# Employee Merchandise Order Form - Help Guide

## Purpose
## How to Complete This Form
To complete this form, simply follow these steps:

1. Fill out the fields as instructed below.
2. Review and submit your order.

## Field-by-Field Explanation

### Employee Order Form
* **Employee Order Form (employee_order_form)**: This is where you will enter your order request. Please type out your request clearly and concisely.

### Payment Details
* **Payment Details (payment_details)**: This is where you will enter any relevant payment information, such as any additional payment instructions or details.

### Payment Method
* **Payment Method (payment_method)**: Select all the payment methods you wish to use for this order. You can choose between "Card Number" and "Check" as options.

### Order Item List
* **Order Item List (order_item_list)**: Select all the items you would like to order from the options provided. You can choose multiple items for this order.

### Item Type
* **Item Type (order_item_type)**: Select the type of item you are ordering. You can choose between "Swag", "Gift", or "Other" as options.

### Item Description
* **Item Description (item_description)**: This is where you will enter a brief description of the item you are ordering. Please keep it concise and clear.

### Item Price
* **Item Price (item_price)**: Enter the price of the item you are ordering. This field is for reference only and will not affect the order total.

### Total Cost
* **Total Cost (total_cost)**: This field will automatically calculate the total cost of your order based on the items you select.

### Delivery Address
* **Delivery Address (delivery_address)**: Enter the delivery address where you would like the order to be sent to. Please make sure to include a valid address for accurate delivery.

### Employee ID
* **Employee ID (employee_id)**: Enter your Employee ID as required by your company.

### Department
* **Department (department)**: Enter the name of your department as required by your company.

## Tips
* Please only request merchandise that is approved by your department.
* Double-check that you have not already submitted a request for this order before submitting a new one.
* Make sure to include all necessary information for accurate delivery.
* If you have any questions or concerns, please contact your department administrator.
