# receipt_submission_for_projects - Help Guide
## Purpose
The receipt submission form is used to submit receipts related to projects.

## How To Complete This Form
1. Fill out the form with the required information, starting with the project ID.
2. Enter the project name.
3. Select the date the receipt was submitted.
4. Enter the amount submitted for the project.
5. Add a description of the submission.
6. Attach the receipt file related to the project.

## Field-by-Field Explanation
* **Project ID**: A unique identifier for the project. This is usually a number.
* **Project Name**: The name of the project being submitted.
* **Date Submitted**: The date the receipt was submitted.
* **Amount Submitted**: The amount submitted for the project. This is usually a numerical value.
* **Description**: A brief description of the submission.
* **Receipt File**: A file containing the receipt related to the project.
