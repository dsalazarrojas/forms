# In Store Tablet Mount Order Form - Help Guide
## Purpose
This form is used to collect information from retailers for in-store tablet mount orders. It includes fields for order details, payment methods, and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the necessary information in each field.
2. Fill out the form according to your specific needs.

## Field-by-Field Explanation

* **Retailer**: Enter the name or business name of the retailer.
	+ Type: text
	+ Required: false
* **Tablet Mount Quantity**: Enter the number of tablet mounts ordered.
	+ Type: number
	+ Required: false
* **Order Date**: Select the date of the order.
	+ Type: date
	+ Required: false
* **Order Total**: Enter the total value of the order.
	+ Type: number
	+ Required: false
* **Payment Type**: Select the payment method (Cash, Credit, or Other).
	+ Type: select_one
	+ Required: false
* **Payment Method**: Select the payment method (Cash, Credit, Debit, or Other).
	+ Type: select_multiple
	+ Required: false
* **Tablet Mount Type**: Select the type of tablet mount (Wall mount, Floor stand, or Table top).
	+ Type: select_one
	+ Required: false
* **Tablet Mount Color**: Select the color of the tablet mount (Black, White, Gray, or Other).
	+ Type: select_multiple
	+ Required: false
* **Note**: Enter any additional comments or notes for the order.
	+ Type: note
	+ Required: false
* **Email**: Enter the email address of the retailer.
	+ Type: email
	+ Required: false
* **Phone**: Enter the phone number of the retailer.
	+ Type: text
	+ Required: false
* **Retailer Email**: Enter the email address of the retailer.
	+ Type: email
	+ Required: false
* **Retailer Phone**: Enter the phone number of the retailer.
	+ Type: text
	+ Required: false

## Tips
* Please ensure that all required fields are filled out correctly.
* Double-check the accuracy of the information provided.
* If you have any questions or issues, contact your sales representative.
