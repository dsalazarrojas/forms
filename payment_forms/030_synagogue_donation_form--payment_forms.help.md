# Synagogue Donation Form - Help Guide
## Purpose
The Synagogue Donation Form is a tool designed to help individuals contribute financially to the synagogue's activities and events.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of donation you would like to make from the options provided.
2. Choose whether you would like to make a one-time donation or a recurring donation (e.g., weekly, monthly, or yearly).
3. Indicate your preferred payment frequency (if applicable).
4. If you are making a recurring donation, select how frequently you would like to receive payments.
5. If you have any additional comments or details to share, type them in the Notes field.
6. Enter your contact information to ensure we can get back to you with any questions or updates.

## Field-by-Field Explanation
* **General Donation** (`general_donation`, text, optional): This field allows you to enter a one-time or initial donation amount for the synagogue.
* **Event Donation** (`event_donation`, select_one, optional): Select this option if you would like to make a donation specifically for an event, program, or fund.
* **Recurring Donation** (`recurring_donation`, select_multiple, optional): Select from the options provided to indicate how frequently you would like to make recurring donations (e.g., weekly, monthly, or yearly).
* **Amount** (`amount`, number, optional): Enter the amount you would like to donate.
* **Payment Frequency** (`payment_frequency`, select_one, optional): If you selected a recurring donation, select how you would like to receive payments (e.g., one time, weekly, monthly, etc.).
* **Frequency** (`frequency`, select_multiple, optional): If you selected a recurring donation, select how frequently you would like to receive donations (e.g., every week, every 2 weeks, etc.).
* **End Frequency** (`end_frequency`, select_one, optional): If you selected a recurring donation, you can choose to have it end on a specific date or not have it end at all.
* **Notes** (`notes`, note, optional): Enter any additional comments or details you have about your donation.
* **Email** (`email`, email, optional): Enter your email address so we can get back to you with any questions or updates.
* **Phone** (`phone`, text, optional): Enter your phone number so we can get back to you with any questions or updates.
