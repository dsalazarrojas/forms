# Conference Registration Payment Form - Help Guide
## Purpose
The Conference Registration Payment Form is used to collect payment information from individuals registering for a conference or events. This form helps the organizers to efficiently process payments and ensures accurate and up-to-date records.

## How To Complete This Form

1. **Payer Full Name**: Enter the name of the person making the payment.
2. **Email Address**: Enter a valid email address for payment confirmation and communication purposes.
3. **Phone Number**: Enter the contact number of the person making the payment.
4. **Organization**: Enter the name of the company or institution associated with the payment.
5. **Registration ID**: If you have already registered for the conference, enter your Registration ID.
6. **Attendee Name**: Enter the name of the person attending the conference.
7. **Payment Type**: Select the type of payment you are making (e.g., Full Conference Registration, Partial Payment, etc.).
8. **Payment Amount**: Enter the amount to be paid for the selected payment type.
9. **Currency**: Select the currency of the payment.
10. **Payment Method**: Choose the method of payment (e.g., Credit Card, Debit Card, etc.).
11. **Card Type**: If using a credit or debit card, select the type of card.
12. **Card Number**: Enter the card number (only required if using a card for payment).
13. **Cardholder Name**: Enter the name on the card (only required if using a card for payment).
14. **Expiration Month** and **Expiration Year**: Enter the expiration month and year of the card (only required if using a card for payment).
15. **Security Code CVV**: Enter the 3 or 4 digit security code (only required if using a card for payment).
16. **Billing Address**: Enter the billing address of the card (only required if using a card for payment).
17. **Billing City**: Enter the billing city of the card (only required if using a card for payment).
18. **Billing State**: Enter the billing state or province of the card (only required if using a card for payment).
19. **Billing ZIP Code**: Enter the billing postal code of the card (only required if using a card for payment).
20. **Billing Country**: Enter the country of the card billing address (only required if using a card for payment).
21. **Payment Notes**: Enter any special instructions or comments related to the payment.
22. **Receipt Preference**: Select how you would like to receive the payment receipt (e.g., Email, Mail, Both).
23. **I Authorize This Payment**: Confirm that you authorize this payment.

## Tips

* Ensure that you have a valid email address to receive payment confirmations and updates.
