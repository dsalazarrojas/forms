# Web Development Payment Form - Help Guide
## Purpose
The Web Development Payment Form is a form used to collect payment information and project details for web development projects.

## How To Complete This Form
1. Select the relevant options for each field as required.
2. Enter the client's name and email address in the respective fields.
3. Provide a detailed description of the project in the "Project Description" field.
4. Select the payment method and payment status as required.
5. Enter the payment amount and tax rate as required.
6. Enter the project status and request status as required.
7. Enter any additional notes as required.

## Field-by-Field Explanation

* **Web Development Payment Form** (`web_development_payment_form`, select_one, required/optional): This field is a select-one field that allows you to choose whether the project is for web development or not.
* **Client** (`client`, text, required): Enter the client's name in this field.
* **Project Description** (`project_description`, text, required): Enter a detailed description of the project.
* **Payment Method** (`payment_method`, select_one, required/optional): Select the payment method used for the project.
* **Payment Amount** (`payment_amount`, number, required): Enter the payment amount in this field.
* **Email** (`email`, email, required): Enter the client's email address in this field.
* **Phone** (`phone`, text, required/optional): Enter the client's phone number in this field.
* **Due Date** (`due_date`, date, required/optional): Enter the due date for the project.
* **Payment Status** (`payment_status`, select_one, required/optional): Select the payment status of the project.
* **Payment Details** (`payment_details`, text, required/optional): Enter any additional payment details.
* **Notes** (`notes`, note, required/optional): Enter any additional notes about the project.
* **Project Status** (`project_status`, select_one, required/optional): Select the project status.
* **Project Request Type** (`project_request_type`, select_one, required/optional): Select the project request type.
* **Request Status** (`request_status`, select_one, required/optional): Select the request status.
* **Project Type** (`project_type`, text, required): Enter the project type.
* **Payment Terms** (`payment_terms`, text, required): Enter the payment terms.
* **Tax Rate** (`tax_rate`, number, required): Enter the tax rate.
* **Project Status Label** (`project_status_label`, text, required/optional): Enter the project status label.
* **Payment Method Label** (`payment_method_label`, text, required/optional): Enter the payment method label.
* **Project Request Label** (`project_request_label`, text, required/optional): Enter the project request label.
* **Request Status Label** (`request_status_label`, text, required/optional): Enter the request status label.
* **Project Type Label** (`project_type_label`, text, required/optional): Enter the project type label.
* **Notes Label** (`notes_label`, text, required/optional): Enter the notes label.
* **Payment Terms Label** (`payment_terms_label`, text, required/optional): Enter the payment terms label.
* **Additional Notes** (`notes`, note, required): Enter any additional notes about the project.

Note: Some fields are not required, but they are optional and can be filled out if needed.
