# New Particle Submission Form - Help Guide
## Purpose
The New Particle Submission Form is a tool used to gather information about new particles submitted for review. This guide will walk you through each field to ensure a smooth and accurate submission process.

## How To Complete This Form
- Read this guide carefully before starting the form.
- Fill out the form with accurate and clear information.
- Ensure all required fields are filled out.
- Review the options for each field carefully.
- Use the submission date and time field to mark the actual submission date and time.

## Field-by-Field Explanation
* **Particle Description (particle_description)**: Briefly describe the new particle, including any notable features or characteristics. This field is required to provide a clear understanding of the particle.
* **Particle Image (particle_image)**: Select a numerical value to represent the particle image, as this field is currently not accepting file uploads. Please note that this field may be used for future developments.
* **Particle Type (particle_type)**: Choose one of the provided types: Aerodynamic or Gravitational. This selection will help categorize and process the particle submission.
* **Researcher Name (researcher_name)**: Enter the researcher's name associated with the particle submission. This field is required to attribute the submission correctly.
* **Researcher Institution (researcher_institution)**: Enter the institution affiliated with the researcher. This information helps track the submission's origin.
* **Researcher Email (researcher_email)**: Enter the researcher's email address. This field ensures that the researcher can be contacted regarding the submission.
* **Researcher Phone (researcher_phone)**: Enter the researcher's phone number. This field allows for additional contact information.
* **Submission Date (submission_date)**: Mark the actual submission date and time accurately. This field is required for tracking and review purposes.
* **Submission Time (submission_time)**: Record the submission time in the correct format. This field is also required for accurate tracking.
* **Researcher Comments (researcher_comments)**: Provide any additional comments or notes from the researcher. This field is optional and can be used to provide further context.
* **Particle Coordinates (particle_coordinates)**: Select one or more coordinates that apply to the particle. Currently, the options are '1', '2', and '3'. This field is not required, but selecting the correct coordinates will aid in the review and processing of the particle submission.
