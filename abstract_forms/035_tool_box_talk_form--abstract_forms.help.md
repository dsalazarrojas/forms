# Tool Box Talk Form - Help Guide
## Purpose
The Tool Box Talk Form is used to report availability and comments on a tool box talk meeting.

## How To Complete This Form
To complete this form, follow these steps:

1.  Select your response to the tool box talk meeting by choosing an option from the "Tool Box Talk Form" dropdown menu.
2.  If necessary, input the tool or equipment assigned to you in the "Assigned Tool" text field.
3.  Add any additional comments or feedback in the "Comments" text field.
4.  Confirm your submission by selecting an option from the "Submit" dropdown menu.

## Field-by-Field Explanation

### Tool Box Talk Form
*   **Tool Box Talk Form** (`tool_box_talk_form`, select_multiple, required: false): Select your response to the tool box talk meeting from the dropdown menu.
    *   Options: Yes, No

### Assigned Tool
*   **Assigned Tool** (`assigned_tool`, text, required: false): Input the tool or equipment assigned to you if necessary.
*   **Type:** text field

### Comments
*   **Comments** (`tool_box_talk_form_comments`, note, required: false): Add any additional comments or feedback.
*   **Type:** text field

### Submit
*   **Submit** (`tool_box_talk_form_submit`, select_one, required: false): Confirm your submission by selecting an option from the dropdown menu.
*   Options: Yes, No
