# the_isis_vortex - Help Guide
## Purpose
This form is designed to help game administrators or managers create and manage game events, including game concepts, player roles, and game-related activities such as start and end times.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully and enter the required information.
2. Enter the game concept, a brief description of the game.
3. Select the player role for the game (Yes or No).
4. Enter the game location.
5. Provide a mission briefing for the game (optional).
6. Enter the date and time for the game.
7. Enter the time of day for the game (optional).
8. Provide any additional notes about the game.
9. Enter the player's email address.
10. Enter the player's phone number.
11. Enter the game master's name.
12. Enter the game master's email address.
13. Enter the game master's phone number.
14. Enter the start time of the game (optional).
15. Enter the end time of the game (optional).
16. Select the player's status (Active or Inactive).
17. If necessary, provide additional information about the player's status.
18. Select the game master's status (Active or Inactive).
19. If necessary, provide additional information about the game master's status.
20. Select the player's previous status (Active or Inactive).
21. If necessary, provide additional information about the player's previous status.
22. Select the game master's previous status (Active or Inactive).
23. If necessary, provide additional information about the game master's previous status.
24. Enter the starting point of the game.
25. Enter the ending point of the game.
26. Select whether the game has specific weather conditions (Yes or No).

## Field-by-Field Explanation
* **Game Concept** (`game_concept`, `text`, required): A brief description of the game.
* **Player Role** (`player_role`, `select_one`, required): Select Yes or No to indicate the player's role in the game.
* **Game Location** (`game_location`, `text`, required): Enter the location where the game will take place.
* **Mission Briefing** (`mission_briefing`, `text`, optional): Provide a detailed description of the game's objectives and goals.
* **Date and Time** (`date_time`, `date`, required): Enter the date and time for the game.
* **Time of Day** (`time_of_day`, `time`, optional): Enter the time of day for the game.
* **Notes** (`notes`, `note`, required): Enter any additional comments or notes about the game.
* **Player Email** (`player_email`, `email`, required): Enter the player's email address.
* **Player Phone** (`player_phone`, `text`, required): Enter the player's phone number.
* **Game Master Name** (`game_master_name`, `text`, required): Enter the game master's name.
* **Game Master Email** (`game_master_email`, `email`, required): Enter the game master's email address.
* **Game Master Phone** (`game_master_phone`, `text`, required): Enter the game master's phone number.
* **Game Start Time** (`game_start_time`, `time`, optional): Enter the start time of the game.
* **Game End Time** (`game_end_time`, `time`, optional): Enter the end time of the game.
* **Player Status** (`player_status`, `select_multiple`, required): Select the player's status (Active or Inactive).
* **Player Previous Status** (`player_previous_status`, `select_multiple`, required): Select the player's previous status (Active or Inactive).
* **Game Master Status** (`game_master_status`, `select_multiple`, required): Select the game master's status (Active or Inactive).
* **Game Master Previous Status** (`game_master_previous_status`, `select_multiple`, required): Select the game master's previous status (Active or Inactive).
* **Game Starting Point** (`game_starting_point`, `text`, optional): Enter the starting point of the game.
* **Game Ending Point** (`game_ending_point`, `text`, optional): Enter the ending point of the game.
* **Game Weather** (`game_weather`, `select_one`, required): Select whether the game has specific weather conditions (Yes or No).
