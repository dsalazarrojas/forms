# CCTV IP System Audit - Help Guide
## Purpose
The CCTV IP system audit is a comprehensive assessment of the CCTV system's hardware, network, and security settings to ensure it meets the required standards and best practices for video surveillance.

## How To Complete This Form

1. Fill in the required information in the fields marked as "required" in the form.
2. Select the most accurate options for each field based on your observations.
3. Provide detailed descriptions for text fields, such as "Auditor Name" and "Audit Findings and Recommendations".
4. Ensure that all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Audit Date** (`audit_date`, date, required): Enter the date of the audit in the format `YYYY-MM-DD`.
* **Audit Time** (`audit_time`, time, required): Enter the time of the audit in 24-hour format (`HH:MM`).
* **Auditor Name** (`auditor_name`, text, required): Enter the name of the person conducting the audit.
* **Facility Name** (`facility_name`, text, required): Enter the name of the building or location being audited.
* **VMS (Video Management System) Type** (`vms_type`, text, required): Enter the software and version used for the system.
* **Total Number of IP Cameras** (`total_cameras`, number, required): Enter the total number of IP cameras installed.
* **Number of Active Cameras** (`active_cameras`, number, required): Enter the number of IP cameras currently in operation.
* **Number of Inactive Cameras** (`inactive_cameras`, number, optional): Enter the number of IP cameras not currently recording.
* **Camera Condition Assessment** (`camera_condition`, select_one, required): Assess the overall state of the cameras and select the corresponding option:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ Needs Replacement
* **Lens Cleanliness** (`lens_cleanliness`, select_one, required): Assess the cleanliness of the camera lenses and select the corresponding option:
	+ Clean
	+ Minor Dust
	+ Moderate Dust
	+ Heavy Dirt or Condensation
* **Cable Integrity** (`cable_integrity`, select_one, required): Assess the condition of the camera cables and select the corresponding option:
	+ Good
	+ Minor Wear
	+ Moderate Damage
	+ Severe Damage
* **Connector Condition** (`connector_condition`, select_one, required): Assess the condition of the camera connectors and select the corresponding option:
	+ Good
	+ Minor Corrosion
	+ Moderate Corrosion
	+ Severe Corrosion
* **Network Connectivity Status** (`network_connectivity`, select_one, required): Assess the network connectivity of the cameras and select the corresponding option:
	+ All Connected
	+ Most Connected
	+ Some Disconnected
	+ Multiple Issues
* **Bandwidth Performance** (`bandwidth_performance`, select_one, required): Assess the bandwidth performance of the system and select the corresponding option:
	+ Excellent
	+ Good
	+ Fair
	+ Inadequate
* **IP Addressing Scheme** (`ip_addressing`, select_one, required): Assess the IP addressing scheme and select the corresponding option:
	+ Properly Configured
	+ Minor Issues
	+ Moderate Issues
	+ Significant Problems
* **Storage Capacity Status** (`storage_capacity`, select_one, required): Assess the storage capacity and select the corresponding option:
	+ Adequate for Future Use
	+ At Acceptable Levels
	+ Getting Full
	+ Critical - Upgrade Needed
* **Recording Retention Period** (`retention_period`, text, required): Enter the number of days or weeks of footage retained.
* **Security Compliance Status** (`security_compliance`, select_one, required): Assess the security compliance of the system and select the corresponding option:
	+ Fully Compliant
	+ Mostly Compliant
	+ Partially Compliant
	+ Non-Compliant
* **Audit Findings and Recommendations** (`audit_notes`, text, required): Enter detailed descriptions of any issues identified and recommended actions for improvement.

## Tips

* Be thorough in your assessment and provide detailed descriptions for each field.
* Ensure that all required fields are completed.
* If unsure about any field, refer to the provided options for guidance.
* This form is designed to help identify potential issues and provide recommendations for improvement.
