# virtual-event-abstract-submission-form - Help Guide

## Purpose
This form is designed to collect information about virtual events. It is an original adaptation of a public survey topic metadata and is not affiliated with, endorsed by, or derived from any form platform. You are free to use, modify, and even sell forms derived from it - just give credit.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the Event Name field with the name of the virtual event you are submitting.
2. Select the Event Category that best describes your event from the drop-down list.
3. Choose the Event Type that best describes your event from the drop-down list.
4. Fill in the Event Start Date and Event End Date fields with the start and end dates of your virtual event, respectively.
5. Enter the Event Location where the event will take place.
6. Provide a brief Event Description of your virtual event.
7. Fill in the Submitter Name field with your name.
8. Enter your Submitter Email address.
9. Enter your Submitter Organization, if applicable.

## Field-by-Field Explanation

* **Event Name** (`event_name`, text, required: false): This field is where you enter the name of the virtual event you are submitting. Please fill in the name of your event.
* **Event Category** (`event_category`, select_one, required: false): Select the category that best describes your event from the drop-down list. Choose the one that best fits your event's type or topic.
* **Event Type** (`event_type`, select_multiple, required: false): Choose the event types that best describe your event from the drop-down list. You can select multiple types.
* **Event Start Date** (`event_start_date`, date, required: false): Fill in the start date of your virtual event.
* **Event End Date** (`event_end_date`, date, required: false): Fill in the end date of your virtual event.
* **Event Location** (`event_location`, text, required: false): This field is where you enter the location where the event will take place.
* **Event Description** (`event_description`, text, required: false): This field is where you provide a brief description of your virtual event.
* **Submitter Name** (`submitter_name`, text, required: false): Fill in your name as the submitter of this virtual event.
* **Submitter Email** (`submitter_email`, email, required: false): Enter your email address as the submitter of this virtual event.
* **Submitter Organization** (`submitter_organization`, text, required: false): If you are submitting on behalf of an organization, enter the name of the organization here.
