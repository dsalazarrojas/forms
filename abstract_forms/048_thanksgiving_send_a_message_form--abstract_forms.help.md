# thanksgiving_send_a_message_form - Help Guide
## Purpose
This form is designed to help users send messages to their family and friends during Thanksgiving, allowing them to express gratitude and appreciation. The form includes fields for the recipient's name, a message to send, the sender's email and phone number, and options for the category and type of contact.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the type of contact you want to send the message to, choosing from "family" or "friends" options.
2. Choose the category of the message you want to send, selecting from "Thank-you", "Greetings", "Love", "Kindness", or "Friendship".
3. Enter the recipient's name, email, or phone number, depending on your preference.
4. Type the message you want to send to the recipient.
5. Optionally, enter a note about the sender to provide more context.
6. Enter your email and phone number to send the message.
7. Confirm your choice of category and contact type.

## Field-by-Field Explanation
- **give_thanks**:
  - Type: Select Multiple
  - Optional
  This field is used to determine the purpose of the message, whether it's a thank you or otherwise.
- **recipient_name**:
  - Type: Text
  - Optional
  Enter the recipient's name to ensure the message reaches them.
- **message_to_send**:
  - Type: Text
  - Optional
  Enter the message you want to send to the recipient.
- **sender_email**:
  - Type: Email
  - Optional
  Enter your email address to send the message from.
- **sender_phone**:
  - Type: Text
  - Optional
  Enter your phone number to send a message via SMS.
- **sender_note**:
  - Type: Note
  - Optional
  Add a note about yourself to provide context.
- **send_message**:
  - Type: Date
  - Optional
  Set a specific date to send the message.
- **category**:
  - Type: Select One
  - Optional
  Select the category of the message, such as "Thank-you", "Greetings", "Love", "Kindness", or "Friendship".
- **send_to**:
  - Type: Select Multiple
  - Optional
  Choose the type of contact you want to send the message to, selecting from "family" or "friends" options.
- **send_to_other**:
  - Type: Text
  - Optional
  Enter any additional contact information if not listed in the "send to" options.
- **send_to_note**:
  - Type: Note
  - Optional
  Add a note about the recipient to provide additional context.
- **send_to_email**:
  - Type: Email
  - Optional
  Enter the recipient's email address to send a message via email.
- **send_to_phone**:
  - Type: Text
  - Optional
  Enter the recipient's phone number to send a message via SMS.
- **send_to_note**:
  - Type: Note
  - Optional
  Add a note about the recipient to provide additional context.
