# 3d Text Effect - Help Guide
## Purpose
The 3D Text Effect form is used to collect feedback and ratings from users about their experience with the 3D Text Effect plugin. By providing your input, you help us understand how the plugin works for you and what we can do to improve it.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your full name in the "Full name" field.
2. Provide your email address in the "Email address" field, which will be used for follow-up and release notes.
3. Select the date you submitted the feedback in the "Date submitted" field.
4. If you have used a product or plugin version, enter it in the "Product or plugin version" field (optional).
5. Rate your overall satisfaction with 3D Text Effect in the "How satisfied are you with 3D Text Effect?" field using the select_one option.
6. Rate your overall rating (1-10) of 3D Text Effect in the "Overall rating" field.
7. Select all the aspects that applied to your experience in the "Which aspects applied to your experience?" field.
8. Choose the primary usage context of 3D Text Effect in the "Primary usage context" field.
9. Indicate if you applied custom CSS to achieve the effect in the "Did you apply custom CSS to achieve the effect?" field.
10. If you applied custom CSS, provide a CSS snippet or describe the main properties used in the "CSS snippet or key properties used" field (optional).
11. Select the observed performance impact of 3D Text Effect in the "Observed performance impact" field.
12. Select all the accessibility issues you noticed with 3D Text Effect in the "Accessibility issues noticed" field (if any).
13. Select your preferred visual presets in the "Preferred visual presets" field (if any).
14. Provide suggestions or changes you would like to see in 3D Text Effect in the "What would you improve or change about 3D Text Effect?" field (optional).
15. Add any additional comments or notes about your experience with 3D Text Effect in the "Additional comments or notes" field (optional).

## Field-by-Field Explanation
* **Full name** (`full_name`, text, required): Enter your full name for identification purposes.
* **Email address** (`email_address`, email, required): Enter the email address associated with your feedback.
* **Date submitted** (`date_submitted`, date, required): Select the date you submitted this feedback.
* **Product or plugin version** (`product_version`, text, optional): If you used a specific product or plugin version, enter it here.
* **How satisfied are you with 3D Text Effect?** (`satisfaction`, select_one, required): Rate your overall satisfaction with 3D Text Effect using the provided options.
* **Overall rating** (`overall_rating`, integer, required): Rate 3D Text Effect from 1 to 10, where 1 is the worst and 10 is the best.
* **Which aspects applied to your experience?** (`experience_aspects`, select_multiple, required): Select all the aspects that applied to your experience with 3D Text Effect.
* **Primary usage context** (`usage_context`, select_one, required): Choose the primary usage context of 3D Text Effect.
* **Did you apply custom CSS to achieve the effect?** (`custom_css_applied`, select_one, required): Indicate if you applied custom CSS to achieve the 3D Text Effect.
* **CSS snippet or key properties used** (`css_snippet`, text, optional): If you applied custom CSS, provide a CSS snippet or describe the main properties used.
* **Observed performance impact** (`performance_impact`, select_one, optional): Select the observed performance impact of 3D Text Effect.
* **Accessibility issues noticed** (`accessibility_issues`, select_multiple, optional): Select all the accessibility issues you noticed with 3D Text Effect (if any).
* **Preferred visual presets** (`preferred_presets`, select_multiple, optional): Select your preferred visual presets for 3D Text Effect.
* **What would you improve or change about 3D Text Effect?** (`open_feedback`, text, optional): Provide suggestions or changes you would like to see in 3D Text Effect.
* **Additional comments or notes** (`additional_comments`, text, optional): Add any other comments or notes about your experience with 3D Text Effect.
