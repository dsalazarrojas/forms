# University Senate Petition Form - Help Guide

## Purpose
This form is intended to collect and document student requests, appeals, or concerns to be presented to the University Senate for review and consideration.

## How To Complete This Form
1. Enter a **university_senate_petition_form** (`text`, Required: no) - A brief title for the form, such as "Request for Course Changes" or "Appeal for University Policies".
2. Select **petition_forms** (`select_one`, Required: no) - Choose from the options "Petition Forms" or "Other" to categorize your request.
3. Describe your **description** (`note`, Required: no) - Provide a clear and concise description of your request or appeal.
4. Optionally, provide a more detailed **description** (`text`, Required: no) - This field is for additional context or information supporting your request.
5. Enter a **form_id** (`number`, Required: no) - This field is for internal use and should be automatically generated.
6. Enter the **assigned_tool** (`text`, Required: no) - This field is for the tool assigned to handle the petition process. This field is not intended for user input.
7. Enter the **output_file** (`text`, Required: no) - This field is for the output file of the petition process. This field is not intended for user input.
8. Enter the **assigned_tool** (`text`, Required: no) - This field is a duplicate of the field at id: 6. This field is not intended for user input.

## Field-by-Field Explanation
* **university_senate_petition_form** (text, Required: false): A clear and concise title for the petition.
* **petition_forms** (select_one, Required: false): Categorize your request as "Petition Forms" or "Other".
* **description** (note, Required: false): A clear and concise description of your request or appeal.
* **university_senate_petition_form_description** (text, Required: false): A more detailed description of the petition, providing additional context or information.
* **form_id** (number, Required: false): An internal identifier for the petition process. This field is automatically generated and not intended for user input.
* **assigned_tool** (text, Required: false): The tool assigned to handle the petition process. This field is not intended for user input.
* **output_file** (text, Required: false): The output file of the petition process. This field is not intended for user input.
* **assigned_tool** (text, Required: false): A duplicate field of the "assigned_tool" field. This field is not intended for user input.

## Tips
- Please ensure that your request or appeal is clear and concise.
- Review the form carefully before submission to avoid errors.
- If you have any questions or concerns, contact the University Senate for support.
