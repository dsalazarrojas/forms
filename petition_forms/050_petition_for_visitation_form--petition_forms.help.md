# Petition For Visitation Form - Help Guide

## Purpose
The Petition For Visitation Form is used for the purpose of requesting a court-ordered visitation arrangement between a child and a non-custodial parent. This form is typically used when a party is seeking to establish a regular visitation schedule for their child, such as weekend visitation or holiday visitation.

## How To Complete This Form

To complete this form, follow these steps:

* Review the form carefully and ensure you understand what each field is asking for.
* Answer all required fields (indicated by an asterisk \*).
* Use the provided options for select fields (such as "Yes" or "No").
* Enter any additional information in the text fields as relevant to your situation.
* Sign and date the form to confirm that you have read and understood the information.

## Field-by-Field Explanation

* **Petitioner Info** (Petitioner Info, Number, Required): This field is used to collect information about the person requesting visitation. Please enter your name and any other relevant information as requested.
* **Other Parent Info** (Other Parent Info, Note, Optional): If you are requesting visitation with a parent who is not the other parent, please enter their information here.
* **Visitation Requests** (Visitation Requests, Select Multiple, Required): You may select multiple options for the type of visitation you are requesting. Please choose all that apply.
* **Court Orders** (Court Orders, Text, Required): If you have any court orders related to the visitation, please enter them here.
* **Other Documents** (Other Documents, Select One, Optional): If you have any other documents related to the visitation, please select "Yes" to indicate that you are including them.
* **Child Info** (Child Info, Select Multiple, Required): You may select multiple options for the child's needs and information. Please choose all that apply.
* **Additional Info** (Additional Info, Text, Optional): If there is any other information you would like to share about the visitation, please enter it here.
* **Signature** (Signature, Text, Required): Please sign and date the form to confirm that you have read and understood the information.
* **Date** (Date, Date, Required): Enter the date you are signing the form.
* **Time** (Time, Time, Required): Enter the time you are signing the form.
* **Relationship** (Relationship, Select One, Required): You may select one of the options to indicate your relationship to the child.
* **Other Relationship** (Other Relationship, Select One, Required): If you have an existing relationship with the child, please select "Yes".
* **Signature 2** (Signature 2, Text, Required): Please sign and date the form to confirm that you have read and understood the information.
* **Name of Other Parent** (Name of Other Parent, Text, Required): Enter the name of the other parent.
* **Name of Other Parent 2** (Name of Other Parent 2, Text, Optional): If you are requesting visitation with a second parent, please enter their name here.
* **Phone** (Phone, Text, Optional): If you would like to provide a contact phone number, please enter it here.
* **Email** (Email, Email, Optional): If you would like to provide a contact email, please enter it here.
* **Fax** (Fax, Text, Optional): If you would like to provide a fax number, please enter it here.
* **Other Phone** (Other Phone, Text, Optional): If you would like to provide an additional contact phone number, please enter it here.
* **Other Email** (Other Email, Email, Optional): If you would like to provide an additional contact email, please enter it here.
* **Other Fax** (Other Fax, Text, Optional): If you would like to provide an additional fax number, please enter it here.
* **Address** (Address, Text, Optional): If you would like to provide an address, please enter it here.
* **Other Address** (Other Address, Text, Optional): If you would like to provide an additional address, please enter it here.
* **Other Signature** (Other Signature, Text, Optional): If you would like to provide an additional signature, please enter it here.
