# Class Council Petition Template - Help Guide

## Purpose
This form is a template for students to submit petitions to the Class Council, which is a student-led governing body that represents the interests and concerns of the student body. The Class Council helps to promote student welfare, address school policies, and facilitate student engagement.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully and ensure you understand the purpose and requirements.
2. Fill in the required information, making sure to provide accurate and detailed answers.
3. Save and submit your completed form.

## Field-by-Field Explanation

### 1. **Petitioner Full Name** (`petitioner_name`)
    * A text field where you can input your name.
    * Required: true

### 2. **Student ID Number** (`student_id`)
    * A text field where you can input your student ID number.
    * Required: true

### 3. **Email Address** (`email_address`)
    * A field for your school email address.
    * Required: true

### 4. **Phone Number** (`phone_number`)
    * A text field for your contact phone number.
    * Required: false

### 5. **Grade Level** (`grade_level`)
    * A select-one field with options: Grade 9, Grade 10, Grade 11, Grade 12.
    * Required: true

### 6. **Petition Title** (`petition_title`)
    * A text field for a brief title of your petition.
    * Required: true

### 7. **Petition Category** (`petition_category`)
    * A select-one field with options: Academic Policy, School Facilities, Student Life, Extracurricular Activities, Dress Code, Cafeteria Services, Transportation, Safety and Security, Environmental Issues, Other.
    * Required: true

### 8. **Describe the Issue or Concern** (`issue_description`)
    * A text field where you can elaborate on the issue or concern.
    * Required: true

### 9. **What Solution Do You Propose?** (`proposed_solution`)
    * A text field for your suggested solution.
    * Required: true

### 10. **How Many Students Are Affected?** (`affected_students`)
    * A select-one field with options: Just my class, Multiple classes, Entire grade, Whole school.
    * Required: true

### 11. **How Urgent Is This Matter?** (`urgency_level`)
    * A select-one field with options: Very urgent - needs immediate attention, Somewhat urgent - within this semester, Moderate - can wait this year, Low priority - long-term goal.
    * Required: true

### 12. **Have You Discussed This With Anyone?** (`previous_discussions`)
    * A select-one field with options: Yes, with teacher, Yes, with counselor, Yes, with administrator, Yes, with student council, No, this is first step.
    * Required: true

### 13. **What Was the Outcome?** (`discussion_outcome`)
    * A text field for the outcome of previous discussions.
    * Required: false

### 14. **Do You Have Supporting Evidence?** (`supporting_evidence`)
    * A select-one field with options: Yes, will attach, Yes, have but not attaching, No, based on student feedback.
    * Required: true

### 15. **What Benefits Will This Change Bring?** (`expected_benefits`)
    * A text field for the positive outcomes of the proposed change.
    * Required: true

### 16. **Are There Potential Concerns or Objections?** (`potential_concerns`)
    * A text field for anticipated challenges or objections.
    * Required: false

### 17. **When Should This Be Implemented?** (`implementation_timeline`)
    * A select-one field with options: Immediately, Next semester, Next school year, Gradual implementation, No preference.
    * Required: true

### 18. **How Many Students Support This Petition?** (`student_support`)
    * A number field for the current signature count.
    * Required: true

### 19. **Would You Like to Present to Council?** (`presentation_request`)
    * A select-one field with options: Yes, I want to present, Yes, but someone else can present, No, written petition is enough.
    * Required: true

### 20. **Do You Have a Faculty Advisor?** (`faculty_advisor`)
    * A select-one field with options: True, False, Looking for one.
    * Required: true

### 21. **Faculty Advisor Name** (`advisor_name`)
    * A text field for the name of your faculty advisor.
    * Required: false

### 22. **Additional Comments or Information** (`additional_comments`)
    * A text field for any extra information or comments.
    * Required: false
