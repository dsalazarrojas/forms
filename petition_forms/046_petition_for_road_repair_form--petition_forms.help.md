# Petition For Road Repair Form - Help Guide
## Purpose
The Petition For Road Repair Form is a tool for citizens to report road conditions and request repairs. By filling out this form, you can help the city identify areas that need attention and prioritize repairs based on the urgency of the issues reported.

## How To Complete This Form
To complete this form, follow these steps:
1. Describe the condition of the road and include any relevant details.
2. Provide the location of the road and its address if possible.
3. Specify what you want us to fix, from common issues like potholes and cracks to more serious problems like flooding and traffic signal malfunctions.
4. If applicable, select the priority level of the issue (High, Medium, or Low).
5. Enter your name and contact information so we can follow up with you if needed.

## Field-by-Field Explanation
* **Condition of the Road** (id: 2, type: text, required: false): Describe the condition of the road, including any hazards or obstacles you've encountered.
* **Location of the Road** (id: 3, type: text, required: false): Provide the exact address or nearest intersection to help us locate the issue.
* **Description of the Issue** (id: 4, type: text, required: false): Give us as much detail as possible about the problem, including what you think needs to be fixed.
* **What Do You Want Us to Fix?** (id: 5, type: select_one, required: false): Select the specific issue you want us to address, such as potholes, cracks, or flooding.
* **Priority** (id: 6, type: select_multiple, required: false): If you think the issue is urgent, select High for priority, Medium for average, or Low for non-urgent.
* **Your Name** (id: 7, type: text, required: false): Please enter your name so we can follow up with you if needed.
* **Email** (id: 8, type: email, required: false): Enter your email address so we can contact you if we need more information or to keep you updated on the repair status.
* **Phone** (id: 9, type: text, required: false): Enter your phone number in case we need to call you for more information or to schedule a follow-up.

## Tips
* Please submit one form per road condition issue.
* If you have multiple issues with the same road, please combine them into one submission.
* If you're reporting an issue that's already known to us, please include the reference number or ticket number so we can look it up easily.
