## Mayor Meeting Petition Form - Help Guide
## Purpose
The "Mayor Meeting Petition Form" is used to collect petitions from citizens in relation to a meeting with the mayor, during the designated meeting period. This form allows citizens to submit feedback, suggestions, and concerns before the meeting.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill out the "Title" field with a brief description of the petition.
2.  In the "Description" field, provide a detailed description of the petition.
3.  Select a "Category" that best describes the type of petition.
4.  Enter a valid phone number in the "Submitted by" field.
5.  Provide a date for the petition in the "Date" field in MM/DD/YYYY format.
6.  If applicable, provide a time for the petition in the "Time" field.
7.  Enter a valid email address in the "Email" field.
8.  Add any additional comments or notes in the "Note" field.

## Field-by-Field Explanation
* **Form Title** (`form_title`, text, required: false): A brief description of the petition.
* **Description** (`form_description`, text, required: true): A detailed description of the petition.
* **Category** (`form_category`, select_one, required: false): Select the category that best describes the type of petition.
	+ Option 1: Select this option for Petition 1.
	+ Option 2: Select this option for Petition 2.
* **Submitted by** (`form_submitted_by`, text, required: false): Enter a valid phone number.
* **Date** (`form_date`, date, required: false): Enter a date in MM/DD/YYYY format.
* **Time** (`form_time`, time, required: false): If applicable, provide a time for the petition.
* **Email** (`form_email`, email, required: false): Enter a valid email address.
* **Note** (`form_note`, note, required: false): Add any additional comments or notes.

## Tips

* Please ensure that you submit the form during the designated meeting period.
* Ensure that you enter valid phone numbers and email addresses.
* If you have any additional comments or notes, please add them in the "Note" field.
