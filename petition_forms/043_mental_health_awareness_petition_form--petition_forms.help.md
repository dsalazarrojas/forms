# Mental Health Awareness Petition Form - Help Guide

## Purpose
This form is designed to gather information for the purpose of raising awareness about mental health issues. It helps to collect and process petition data for further analysis and action.

## How To Complete This Form
1.  Ensure you have filled out all required fields.
2.  Please select the correct category ("Yes" or "No") for the purpose of the petition.
3.  Fill out your name and email address as prompted.
4.  You can optionally provide your phone number if you wish to be contacted.
5.  You can write a message if you have any comments or suggestions.
6.  Select the assigned tool categories as prompted.
7.  Enter the assigned tool 2 as prompted.
8.  Enter the form ID(s) as prompted.
9.  Enter the output file name(s) as prompted.

## Field-by-Field Explanation

* **category** (`category`, select_one, required): Select "Yes" if the petition is for mental health awareness, and "No" otherwise.
* **description** (`description`, text, optional): You can optionally provide a description of the petition.
* **name** (`name`, text, required): Enter your name as it appears on your identification or business card.
* **email** (`email`, email, required): Enter your email address.
* **phone** (`phone`, text, optional): Enter your phone number if you wish to be contacted.
* **message** (`message`, text, optional): You can write a message if you have any comments or suggestions.
* **assigned_tool** (`assigned_tool`, text, optional): Enter the assigned tool as prompted.
* **Category Options** (`category_options`, select_one, required): Select "Petition Forms" as the category for this petition.
* **Assigned Tool 2** (`assigned_tool_2`, text, optional): Enter the assigned tool 2 as prompted.
* **form_ids** (`form_ids`, text, required): Enter the form ID(s) as prompted.
* **output_file** (`output_file`, text, required): Enter the output file name as prompted.
* **Assigned Tool 3** (`assigned_tool_3`, text, optional): Enter the assigned tool 3 as prompted.
* **Output File 2** (`output_file_2`, text, optional): Enter the output file 2 name as prompted.
