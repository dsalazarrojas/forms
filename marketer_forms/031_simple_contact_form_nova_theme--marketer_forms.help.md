# Simple Contact Form Nova Theme - Help Guide
## Purpose
This form is a basic contact form designed to collect information from users. It is intended for general use and can be used in various contexts such as customer support, feedback, or sales inquiries.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **First Name** in the text field labeled "first name".
2. Enter your **Email** in the text field labeled "email".
3. Enter your **Message** in the text field labeled "message".
4. Select a **Date and Time** (optional) by using the date picker or typing it manually.
5. Enter your **Phone Number** (if applicable) in the text field labeled "phone number".
6. Select one or multiple options from the dropdown menu labeled "select one".
7. Select one or multiple options from the dropdown menu labeled "select multiple".
8. Enter your **Time** (if applicable) in the 24-hour format.
9. If necessary, enter a **Note** in the text field labeled "note".
10. Optionally, enter an alternate **Email** (not recommended to be used for primary contact).

## Field-by-Field Explanation
### First Name (`first_name`, text, required: false)
Enter your first name in this field.

### Email (`email`, email, required: false)
Enter your email address.

### Message (`message`, text, required: false)
Enter a message for the support team.

### Date and Time (`date_time`, date, required: false)
Enter the date and time of your inquiry, or select it using the date picker.

### Phone Number (`phone_number`, text, required: false)
Enter your phone number if you have one.

### Select One (`select_one`, select_one, required: false)
Select one option from the list.

### Select Multiple (`select_multiple`, select_multiple, required: false)
Select multiple options from the list.

### Time (`time`, time, required: false)
Enter the time in 24-hour format (e.g., 14:30).

### Note (`note`, note, required: false)
If you have any additional comments, enter them here.

### Email (Duplicate Field, email, required: false)
This is a duplicate field of the first email field, not recommended for use.

**Tips**

* Make sure to fill out all the required fields to ensure your message is sent successfully.
* Use the date picker for more accurate date and time input.
* Select multiple options for the select multiple field to provide more information.
* Enter your phone number in the format of international phone number (e.g., +1-123-456-7890).
