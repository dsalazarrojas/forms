# Link Submission Form - Help Guide
## Purpose
The purpose of this form is to allow users to submit links they think would be relevant to our community, such as articles, blog posts, or social media posts.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the Submission field with a brief description of the link you want to submit.
2. Enter your Name and Email address to help us contact you if we have any questions or need more information.
3. Add your Phone number if you want to be contacted by phone for more information.
4. Enter the URL of the link you want to submit.
5. Click the submit button to submit your link for review.

## Field-by-Field Explanation
* **Submission** (`submit_link`, text, required): Briefly describe the link you want to submit, e.g., "Check out this interesting article on [topic]".
* **Name** (`name`, text, optional): Enter your name so we can contact you if we need more information.
* **Email** (`email`, email, optional): Enter your email address so we can contact you if we need more information or have any questions.
* **Phone** (`phone`, text, optional): Enter your phone number if you want to be contacted by phone for more information.
* **URL** (`url`, text, required): Enter the URL of the link you want to submit. Make sure it's a direct link, and not a link to a page that requires login or registration.
