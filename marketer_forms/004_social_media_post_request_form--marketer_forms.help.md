# Social Media Post Request Form - Help Guide
## Purpose
The purpose of this form is to request a social media post on a specific social media channel.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the required fields (indicated by a * in the form).
2. Select the type of post you want to request (e.g. "Yes" for a promotional post, "No" for an event post).
3. Choose the social media channel where you want the post to be published.
4. Enter the date you want the post to be published.
5. Select the time you want the post to be published.
6. If the post is requested by someone else, select "Yes" for "Requesting User" and enter their email address.
7. Enter the requesting user's email address.
8. Provide a brief title for the post.
9. Enter the message for the post.

## Field-by-Field Explanation

* **Social Media Post Request** (social_media_post_request_form_1):
	+ This is the main description of the social media post request.
* **Post Type** (social_media_post_request_form_2):
	+ Select "Yes" to request a promotional post, "No" for an event post, or other types of posts as necessary.
* **Social Media Channel** (social_media_post_request_form_3):
	+ Choose the social media platform where you want the post to be published (e.g. Facebook, Twitter, LinkedIn).
* **Post Date** (social_media_post_request_form_4):
	+ Enter the date you want the post to be published in MM/DD/YYYY format.
* **Post Time** (social_media_post_request_form_5):
	+ Enter the time you want the post to be published in 12-hour format (e.g. 02:30 PM).
* **Requesting User** (social_media_post_request_form_6):
	+ If the post is requested by someone else, select "Yes" and enter their email address.
* **Requesting User Email** (social_media_post_request_form_7):
	+ Enter the email address of the requesting user.
* **Requesting User Phone** (social_media_post_request_form_8):
	+ Enter the phone number of the requesting user.
* **Post Title** (social_media_post_request_form_9):
	+ Enter a brief title for the post.
* **Post Message** (social_media_post_request_form_10, social_media_post_request_form_11):
	+ Enter the main content of the post. 

## Tips
* Please make sure to fill out all required fields before submitting the form.
* If you are requesting a post for someone else, make sure to enter their email address and phone number accurately.
* Double-check the date and time you select for the post to ensure it is correct.
