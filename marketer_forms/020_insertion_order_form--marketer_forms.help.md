# Insertion Order Form - Help Guide
## Purpose
The Insertion Order Form is used to collect and track information about insertion orders for marketing materials. This form helps ensure accurate and efficient processing of orders.

## How To Complete This Form
1. Fill out the form with the required information, indicated by an asterisk (\*) in the field label.
2. For fields with options, select the relevant option from the dropdown list.
3. Enter the details in the text fields.
4. Review your answers to ensure they are accurate and complete.

## Field-by-Field Explanation
* **Order Details** (`order_details`, text, optional): Enter a brief description of the order.
* **Order Type** (`order_type`, select_one, optional): Choose the type of order, such as Print, Digital, or Online.
* **Ad Size** (`ad_size`, number, optional): Enter the size of the ad, if applicable.
* **Ad Color** (`ad_color`, select_multiple, optional): Select the color of the ad, if applicable. Options are Full Color and Black & White.
* **Ad Type** (`ad_type`, select_one, optional): Choose the type of ad, such as Billboard, Online, TV, or Print.
* **Ad Media** (`ad_media`, select_one, optional): Select the media type, such as Print, Digital, or Online.
* **Ad Frequency** (`ad_frequency`, number, optional): Enter the frequency of the ad, if applicable.
* **Order Status** (`order_status`, select_one, optional): Select the status of the order, such as New, Reorder, or Pending.
* **Reorder Reason** (`reorder_reason`, text, optional): Enter a brief reason for reordering, if applicable.
* **Ad Size Unit** (`ad_size_unit`, select_one, optional): Select the unit of measurement for the ad size, such as Square Foot, Page Count, or Column Inch.

## Tips
* Double-check the options selected for order type, ad type, ad media, and order status to ensure accuracy.
* If the ad size is not applicable, you can leave this field blank.
* If you have trouble selecting an option for a field, refer back to the help text in the field label for guidance.
