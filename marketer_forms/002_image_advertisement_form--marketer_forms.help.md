# image_advertisement_form - Help Guide
## Purpose
The image_advertisement_form is used to upload and manage images used for advertisements. This form allows users to select the type of image, upload the image, and provide a description for the image.

## How To Complete This Form
To complete this form, follow these steps:

1. Click on the "image_advertisement_form_page" field to begin.
2. Select the type of image you want to upload by choosing from the "image_type" field. You can choose between "image", "video", or "3D model".
3. If you selected "image" or "video", you can upload the image by filling in the "upload_image" field.
4. Add a description of the image in the "description" field, if desired.

## Field-by-Field Explanation
* **image_advertisement_form_page**: This field is the initial page of the form that begins the process of uploading and managing images for advertisements.
* **image_url**: This field is not actually used in the form, but it's included as a field; we'll ignore it for the sake of this explanation.
* **image_type**: This field allows you to select the type of image you want to upload. Choose from "image", "video", or "3D model".
* **upload_image**: This field is used to upload the image or video you selected in the "image_type" field.
* **description**: This field is optional and allows you to add a description of the image or video you uploaded.
