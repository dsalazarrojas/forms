# Opt In Form - Help Guide
## Purpose
This form is used to collect information from users about their opt-in preferences.

## How To Complete This Form
To fill out this form, follow these steps:

1. Enter your First Name in the First Name field.
2. Enter your Last Name in the Last Name field.
3. Enter your Email in the Email field, following the format of an actual email address.
4. If you wish to include a phone number, enter it in the Phone field.
5. Select your preferred method of updates using the Update Method field.
6. Choose how often you would like to receive updates using the Update Frequency field.
7. If you have any additional notes or comments, you can add them in the Notes field.
8. If you have a preferred tool for this form, you can select it in the Assigned Tool field.
9. If you're filling this out for someone else, select the correct user who created it in the Created By field.
10. Select the users who this form should be assigned to in the Assigned To field.
11. Enter the date you created this form in the Created Date field, in the format YYYY-MM-DD.
12. Finally, enter the date this form was last updated in the Updated Date field, in the format YYYY-MM-DD.

## Field-by-Field Explanation

* **First Name (text)**: Enter your first name.
* **Last Name (text)**: Enter your last name.
* **Email (email)**: Enter your email address. This is required for us to contact you.
* **Phone (text)**: If you have a phone number, enter it here. This is optional.
* **Opt In (select_one)**: Select Yes or No to indicate your preference for communication.
* **Update Frequency (select_multiple)**: Choose how often you'd like to receive updates (Every Day, Every Week, Every Month).
* **Update Method (select_one)**: Select your preferred method of updates (Email, Text Message, Phone Call).
* **Notes (note)**: Add any additional comments or notes about your preferences.
* **Assigned Tool (text)**: Select a tool for this form (optional).
* **Created By (select_one)**: Select the user who created this form (optional).
* **Assigned To (select_multiple)**: Select the users this form is assigned to (optional).
* **Created Date (date)**: Enter the date you created this form in the format YYYY-MM-DD.
* **Updated Date (date)**: Enter the date this form was last updated in the format YYYY-MM-DD.
