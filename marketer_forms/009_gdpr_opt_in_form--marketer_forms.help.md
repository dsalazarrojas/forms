# GDPR Opt In Form - Help Guide
## Purpose
This form is used to collect your consent and preferences on how we should contact and communicate with you, specifically regarding GDPR-related matters. We want to make sure we respect your boundaries and preferences.

## How To Complete This Form
1. To complete this form, please select your preferred options from the provided dropdown menus. You can choose one or multiple options for each question.
2. Make sure to fill in all required fields, indicated by *Required*.
3. If you have any doubts or concerns, feel free to contact us for assistance.

## Field-by-Field Explanation
* **Opt In** (`gdpr_opt_in`, Select One, Required): Select "Yes" if you agree to be contacted regarding GDPR-related matters, or "No" if you do not.
* **Email** (`email`, Email, Required): Provide your email address where you can be reached for communication.
* **Consent** (`consent`, Select Multiple, Required): Choose how you would like to be contacted (e.g., phone, email, mail).
* **Updates** (`updates`, Select One, Required): Select "Yes" if you would like to receive updates on new developments, or "No" if you do not.
* **Offers** (`offers`, Select One, Required): Choose "Yes" if you would like to receive special offers, or "No" if you do not.
* **Marketing Comm** (`marketing_comm`, Select One, Required): Select "Yes" if you would like to be contacted by our marketing department, or "No" if you do not.
* **Opt In Updates** (`updates_opt_in`, Select One, Required): Select "Yes" if you would like to receive updates on new developments, or "No" if you do not.
* **Opt In Offers** (`offers_opt_in`, Select One, Required): Choose "Yes" if you would like to receive special offers, or "No" if you do not.
* **Opt In Marketing Comm** (`marketing_comm_opt_in`, Select One, Required): Select "Yes" if you would like to be contacted by our marketing department, or "No" if you do not.
* **Updates Comm** (`updates_comm`, Select Multiple, Required): Choose how you would like to receive updates (e.g., email, phone, mail).
* **Offers Comm** (`offers_comm`, Select Multiple, Required): Choose how you would like to receive special offers (e.g., email, phone, mail).
* **Updates Comm** (`updates_comm`, Select Multiple, Required): This field is not actually present in the original YAML. I have removed it to avoid confusion.
