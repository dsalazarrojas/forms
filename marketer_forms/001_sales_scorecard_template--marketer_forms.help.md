# Sales Scorecard Template - Help Guide
## Purpose
The Sales Scorecard Template is a tool used to capture and manage sales scorecard data. It provides a structured format for storing and tracking essential information about each scorecard.

## How To Complete This Form
To complete this form, follow the steps below:
1. Start by filling out the required fields: Scorecard ID, Name, Owner, Frequency, Last Updated By, and Target Score Range.
2. Provide details about the scorecard, such as its version and status.
3. Enter the last updated date and time for the scorecard.
4. Enter any additional notes or comments for the scorecard.

## Field-by-Field Explanation
### Scorecard ID (`scorecard_id`)
* A unique identifier for the scorecard.
* Enter a unique number that identifies this scorecard.

### Name (`scorecard_name`)
* The name of the scorecard.
* Enter the scorecard's name in text format.

### Owner (`scorecard_owner`)
* The person or department responsible for the scorecard.
* Enter the name or department in text format.

### Status (`scorecard_status`)
* The status of the scorecard.
* Select one of the following options:
	+ Active
	+ Inactive
	+ Archived

### Frequency (`scorecard_frequency`)
* How often the scorecard is updated.
* Select one of the following options:
	+ Monthly
	+ Quarterly
	+ Yearly

### Last Updated By (`scorecard_last_updated_by`)
* The person or department that last updated the scorecard.
* Select one of the following options:
	+ Admin
	+ User

### Frequency Notes (`scorecard_frequency_notes`)
* Additional notes for the scorecard's frequency.
* Enter any comments or explanations for the frequency selection.

### Target Score Range (`scorecard_target_score_range`)
* The target score range for the scorecard.
* Select one of the following options:
	+ High
	+ Medium
	+ Low

### Last Updated Date (`scorecard_date`)
* The date and time the scorecard was last updated.
* Enter the date and time in date format.

### Last Updated By (`scorecard_last_updated_by`)
* The person or department that last updated the scorecard.
* Select one of the following options:
	+ Admin
	+ User

### Last Updated Notes (`scorecard_last_updated_notes`)
* Additional notes for the scorecard's last update.
* Enter any comments or explanations for the last update.

### Target Score Range Min (`scorecard_target_score_range_min`)
* The minimum target score for the scorecard.
* Enter a number that represents the minimum target score.

### Target Score Range Max (`scorecard_target_score_range_max`)
* The maximum target score for the scorecard.
* Enter a number that represents the maximum target score.

### Target Score Range Notes 1-4 (`scorecard_target_score_range_notes_1`, `scorecard_target_score_range_notes_2`, `scorecard_target_score_range_notes_3`, `scorecard_target_score_range_notes_4`)
* Additional notes for the target score range.
* Enter any comments or explanations for the target score range.

### Target Score (`scorecard_score`)
* The target score for the scorecard.
* Enter a number that represents the target score.

### Target Score Notes (`scorecard_score_notes`)
* Additional notes for the target score.
* Enter any comments or explanations for the target score.

### Score (`scorecard_score`)
* The scorecard's actual score.
* Enter a number that represents the scorecard's score.

* Additional notes for the target score range.
