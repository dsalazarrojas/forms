# Copy Request Form - Help Guide
## Purpose
The "Copy Request Form" is used to collect and track information about copy requests, which involves documents, reports, and other materials. This form is used to gather details from users about their requests, including who is requesting the copy, what type of copy is being requested, and other relevant information.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the required fields for "Files", "Documents", "Reports", "Staff", "Requestor", and "Status" using the provided options.
2. Enter the "Date Submitted" and "Submit Date" using the date picker input.
3. Enter your "Staff ID" and "Form ID" numbers.
4. Select the "Tool" used for the request.
5. Enter your "Submitter Email" and "Submitter Phone" if applicable.
6. Enter your "Comments" if required or if you need to provide additional information.
7. Review and submit the form once all required fields are filled.

## Field-by-Field Explanation

* **Files**: Select whether the copy request involves files or not.
* **Documents**: Select whether the copy request involves documents or not.
* **Reports**: Select whether the copy request involves reports or not.
* **Staff**: Select the staff member making the request.
* **Requestor**: Select the requestor of the copy request.
* **Department**: Enter the department involved in the copy request (optional).
* **Date Submitted**: Enter the date the copy request was submitted.
* **Comments**: Enter any additional comments or information about the copy request (optional).
* **Submit Date**: Enter the date the form is being submitted.
* **Staff ID**: Enter your staff ID number.
* **Tool**: Enter the tool used for the copy request (optional).
* **Status**: Select the status of the copy request (Active or Inactive).
* **Assigned Tool**: Select whether the tool is assigned to the copy request or not.
* **Form ID**: Enter your form ID number.
* **Created By**: Enter the person who created the copy request (optional).
* **Date Created**: Enter the date the copy request was created.
* **Updated By**: Enter the person who updated the copy request (optional).
* **Date Updated**: Enter the date the copy request was updated.
* **Submitter**: Enter your name.
* **Submitter Email**: Enter your email address.
* **Submitter Phone**: Enter your phone number.
* **Comments 1**, **Comments 2**, **Comments 3**, and **Comments 4**: Enter any additional comments or information about the copy request (optional).

## Tips
* Please ensure all required fields are filled before submitting the form.
* Use the correct format for entering dates (DD/MM/YYYY).
* If you have any questions or concerns, please contact the form administrators.
