# Newsletter Registration Form - Help Guide

## Purpose
This form is designed for registering users to a newsletter, allowing them to receive periodic updates and news on specific topics. Please note that registration is not intended for internal use, so only external users will be able to register.

## How To Complete This Form
To register for the newsletter, please follow these steps:

1. Enter your first name in the "First name" field.
2. Enter your last name in the "Last name" field.
3. Type a valid email address in the "Email" field, following the format: `user@example.com`.
4. Enter your phone number in the "Phone number" field.

## Field-by-Field Explanation
* **First name**: Enter your first name for identification purposes.
	+ Type: `text`
	+ Required: No
* **Last name**: Enter your last name for identification purposes.
	+ Type: `text`
	+ Required: No
* **Email**: Enter a valid email address for contact purposes.
	+ Type: `email`
	+ Required: No
	+ Hint: Enter a valid email address in the format: `user@example.com`
* **Phone number**: Enter your phone number for potential contact.
	+ Type: `text`
	+ Required: No

## Tips
* Make sure to enter a valid email address to receive newsletter updates.
* If you have any issues with the form, contact our support team.
