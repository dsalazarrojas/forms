# Sosyal Medya İçerik Talep Formu - Help Guide
## Purpose
This form is used to create a content request for social media content creation. It collects information about the user, content details, tags, and other relevant data to help the content creators understand what type of content is needed.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the **User Information** section with your details.
2. Provide information about the content you need, such as its type, schedule, and time.
3. Select the target audience and social media platforms for the content.
4. Add any additional tags or notes about the content.
5. Choose the user assigned to create the content and its status.
6. Select the priority level of the content.
7. Add any additional files or tags required for the content.

## Field-by-Field Explanation

* **User Information** (id: 1, name: user_info, type: text)
	+ Enter your name and other relevant contact information.
* **Content Information** (id: 2, name: content_info, type: text)
	+ Enter a brief description of the content you need.
* **Content Details** (id: 3, name: content_details, type: text)
	+ Enter more details about the content, such as its schedule and time.
* **Content Type 2** (id: 4, name: content_type_2, type: select_one)
	+ Select the type of content you need (Video, Photo, or Post).
* **Content File 1** (id: 5, name: content_file_1, type: text)
	+ Select the file required for the content.
* **Content File 2** (id: 6, name: content_file_2, type: text)
	+ Select the file required for the content.
* **Content Tags** (id: 7, name: content_tags, type: text)
	+ Enter tags for the content.
* **Target Audience** (id: 8, name: target_audience, type: select_one)
	+ Select the target audience (Everyone, Friends, or Family).
* **Content Schedule** (id: 9, name: content_schedule, type: date)
	+ Select the schedule for the content.
* **Content Time** (id: 10, name: content_time, type: time)
	+ Select the time for the content.
* **Social Media Platforms** (id: 11, name: social_media_platforms, type: select_multiple)
	+ Select the social media platforms for the content.
* **Content Note** (id: 12, name: content_note, type: text)
	+ Enter notes about the content.
* **Content Requester** (id: 13, name: content_requester, type: select_one)
	+ Select the person requesting the content (John Doe or Jane Doe).
* **Content Status** (id: 14, name: content_status, type: select_one)
	+ Select the status of the content (Approved or Declined).
* **Assigned User** (id: 15, name: assigned_user, type: select_one)
	+ Select the user assigned to create the content (John or Jane).
* **Content Priority** (id: 16, name: content_priority, type: number)
	+ Select the priority level of the content (e.g., High, Medium, Low).
* **Content File 2 2** (id: 17, name: content_file_2_2, type: text)
	+ Select the file required for the content.
* **Assigned User 2** (id: 18, name: assigned_user_2, type: select_one)
	+ Select the user assigned to create the content (John or Jane).
* **Social Media Channels** (id: 19, name: social_media_channels, type: select_multiple)
	+ Select the social media channels for the content (Private or Public).
* **Target Location** (id: 20, name: target_location, type: select_multiple)
	+ Select the target location (Location 1 or Location 2).
* **Target Language** (id: 21, name: target_language, type: select_multiple)
	+ Select the target language (English or French).
* **Content Language** (id: 22, name: content_language, type: select_multiple)
	+ Select the content language (English or French).
* **Tags** (id: 23, name: tags, type: select_multiple)
	+ Select the tags for the content (Tag 1 or Tag 2).
* **Content Category** (id: 24, name: content_category, type: select_one)
	+ Select the content category (Category 1 or Category 2).
* **Content Tags 2** (id: 25, name: content_tags_2, type: select_multiple)
	+ Select the tags for the content (Tag 1 or Tag 2).
