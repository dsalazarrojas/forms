# visual_preference_survey - Help Guide
## Purpose
The visual_preference_survey form is a tool for collecting information on the visual preferences of a building or design project. It is designed to help designers, architects, or project managers understand the client's visual preferences and make informed decisions about the building's design.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the building type from the options provided.
2. Choose the building orientation that best describes the project.
3. Select the building size that aligns with the project's scale.
4. Determine the building height from the provided options.
5. Choose the dominant building color.
6. Select the primary building material.
7. Provide a brief description of the building site characteristics.
8. Choose the building view angle from the options.
9. Indicate the building's location on the compass.
10. Select the building's environment as described.

## Field-by-Field Explanation
- **Building Type** (`Building`, `select_one` , required): Select the type of building you are considering, such as a residential, commercial, or industrial building.
- **Building Orientation** (`Landscape`, `Linear`, `Angular`, `select_one` , required): Choose the orientation of the building, such as landscape, linear, or angular.
- **Building Size** (`Small`, `Medium`, `Large`, `select_one` , required): Select the size of the building, such as small, medium, or large.
- **Building Height** (`Low`, `Medium`, `High`, `select_one` , required): Determine the building height from the provided options.
- **Building Color** (`Warm`, `Cool`, `select_one` , required): Choose the dominant building color.
- **Building Material** (`Brick`, `Glass`, `Stone`, `select_one` , required): Select the primary building material.
- **Building Site Characteristics** (``, `text` , required): Provide a brief description of the building site characteristics, such as its topography, accessibility, or unique features.
- **Building View Angle** (`0-90`, `90-180`, `180-270`, `select_one` , required): Choose the building view angle, such as 0-90, 90-180, or 180-270 degrees.
- **Building Location** (`North`, `South`, `East`, `select_one` , required): Indicate the building's location on the compass, such as north, south, or east.
- **Building Environment** (`Open`, `Partially Open`, `Closed`, `select_one` , required): Select the building's environment, such as open, partially open, or closed.

## Tips
- Make sure to select the options that best describe the building or design project.
- If you are unsure about an option, choose the one that is most similar to your project.
- Provide a clear and concise description of the building site characteristics.
- If you have any further questions, please contact form@gic.mx.
