# Target Audience Grouping Form - Help Guide
## Purpose
The Target Audience Grouping Form is designed for marketers to create and manage groups of target audiences for various marketing campaigns. This form helps in segmenting audiences based on demographic values, target audience preferences, and other relevant factors to tailor marketing strategies.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the demographic value for the target audience group using the drop-down menu.
2. Select multiple target audience options using the check-boxes.
3. Add a description for the target audience group.
4. Assign a tool to the target audience group.
5. Choose the user who created the target audience group.
6. Optionally, select an option for the created by user field.
7. Optionally, select an update option for the updated by field.

## Field-by-Field Explanation
### Demographic Value (Page 1)
* **Demographic Value** (`demographic_value`, select_one, required: false): Select the demographic value for the target audience group. This field allows you to specify the demographic characteristics of the target audience, such as age, gender, or location.

### Target Audience Grouping (Page 1)
* **Target Audience Grouping** (`target_audience_grouping`, select_multiple, required: false): Select multiple target audience options using the check-boxes. This field allows you to choose the various demographics or interests that make up the target audience group.

### Description (Page 2)
* **Description** (`description`, text, required: false): Add a brief description of the target audience group. This field is optional but helps in providing context for the group.

### Assigned Tool (Page 2)
* **Assigned Tool** (`assigned_tool`, select_one, required: false): Select a tool to be assigned to the target audience group. This field helps in specifying which tool will be used to manage the group.

### Created By (Page 3)
* **Created By** (`created_by`, text, required: false): Choose the user who created the target audience group. This field is automatically filled with the current user's ID.

### Created On (Page 3)
* **Created On** (`created_on`, date, required: false): Select the date when the target audience group was created.

### Updated On (Page 4)
* **Updated On** (`updated_on`, date, required: false): Select the date when the target audience group was last updated.

### Created By User (Page 4)
* **Created By User** (`created_by_user`, select_one, required: false): Select an option for the created by user field. This field is used to override the current user's ID.

### Updated By (Page 5)
* **Updated By** (`updated_by`, select_one, required: false): Select an option for the updated by user field. This field is used to override the current user's ID.
