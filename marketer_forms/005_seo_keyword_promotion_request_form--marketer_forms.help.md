# SEO Keyword Promotion Request Form - Help Guide
## Purpose
This form is used to request the promotion of search engine optimization (SEO) keywords for a marketing campaign.

## How To Complete This Form
1. Fill out the required fields with accurate information.
2. Make sure to select the correct options for each field.
3. Provide a brief description of the campaign.
4. Select the keyword list and other relevant options.

## Field-by-Field Explanation

* **Keyword**: Enter the keyword(s) you want to promote.
* **Keyword List**: Select all the keywords you want to promote. You can select multiple keywords.
* **Description**: Provide a brief description of the campaign.
* **URL**: Enter the URL of the campaign.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Promotion Start Date**: Select the start date of the promotion.
* **Promotion End Date**: Select the end date of the promotion.
* **Promotion Status**: Select the status of the promotion. (Active/Inactive)
* **Assigned Tool**: Select whether this campaign is assigned to a tool.
* **Category**: Select whether this campaign is a category.
* **Tags**: Enter any additional tags for the campaign.
* **Notes**: Enter any additional notes for the campaign.
* **Keyword Group**: Select all the keyword groups for the campaign. You can select multiple keyword groups.
* **Target Audience**: Select whether this campaign targets a specific audience.
* **Search Engine**: Select all the search engines for the campaign. You can select multiple search engines.
* **Keywords**: Enter any additional keywords for the campaign.
* **Keyword Groups**: Select all the keyword groups for the campaign. You can select multiple keyword groups.
* **Campaign Status**: Select the status of the campaign. (Active/Inactive)
* **Campaign Budget**: Enter the budget for the campaign.
* **Campaign Budget Currency**: Select the currency of the campaign budget.
* **Target Location**: Select whether this campaign targets a specific location.
* **Target Country**: Select the country targeted by the campaign. (Selecting 'Yes' will open up options for this field.)
* **Target City**: Enter the city targeted by the campaign.
* **Campaign Budget Currency**: Enter the currency of the campaign budget.
