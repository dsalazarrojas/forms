# software_product_demo_request_form - Help Guide
## Purpose
This form is designed to collect information from users for a software product demonstration.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Fill out the required fields:
	* Company Name (page 1)
	* Software (page 2)
	* Name (page 3)
	* Email (page 4)
	* Phone (page 5)
	* Time (page 6)
	* Date (page 7)
	* Product (page 8)
	* Demo Time (page 10)
	* Demo Date (page 11)
2. Optional fields:
	* Message (page 9)
	* Demo Agendas (page 13)
	* Assigned Agent (page 14)
	* Output File (page 16)
	* Form ID (page 17)
	* Assigned Tool (page 18)
	* Category (page 19)
	* Description (page 20)
	* Category Title (page 21)
	* Assigned Category (page 22)
	* Description Title (page 23)
	* Demo Title (page 24)
	* Demo Category (page 25)

## Field-by-Field Explanation
### Page 1: Company
* **Company Name** (`Company Name`, text, required): This is the name of your company or organization.
### Page 2: Software
* **Software** (`software`, select_one, required): This field allows you to select whether the software is being used or not.
### Page 3: Name
* **Name** (`Name`, text, required): This is your name or the name of the person requesting the demo.
### Page 4: Email
* **Email** (`Email`, email, required): This is your email address.
### Page 5: Phone
* **Phone** (`Phone`, text, required): This is your phone number.
### Page 6: Time
* **Time** (`Time`, time, required): This is the time of the demo.
### Page 7: Date
* **Date** (`Date`, date, required): This is the date of the demo.
### Page 8: Product
* **Software Product** (`software_product`, select_one, required): This field allows you to select whether the software product is being used or not.
### Page 9: Message
* **Message** (`Message`, text, optional): This is an optional field for any additional message or comment.
### Page 10: Demo Time
* **Demo Time** (`demo_time`, time, optional): This is the time of the demo.
### Page 11: Demo Date
* **Demo Date** (`demo_date`, date, optional): This is the date of the demo.
### Page 12: Demo Note
* **Demo Note** (`demo_note`, note, optional): This is a note for the demo.
### Page 13: Demo Agendas
* **Demo Agendas** (`demo_agendas`, select_multiple, optional): This field allows you to select multiple agendas for the demo.
### Page 14: Assigned Agent
* **Assigned Agent** (`assigned_agent`, select_one, optional): This field allows you to select whether an assigned agent is required or not.
### Page 16: Output File
* **Output File** (`output_file`, text, optional): This is the output file.
### Page 17: Form ID
* **Form ID** (`form_ids`, text, optional): This is the form ID.
### Page 18: Assigned Tool
* **Assigned Tool** (`assigned_tool`, text, optional): This is the assigned tool.
### Page 19: Category
* **Category** (`category`, text, optional): This is the category.
### Page 20: Description
* **Description** (`description`, text, optional): This is the description.
### Page 21: Category Title
* **Category Title** (`category_title`, text, optional): This is the category title.
### Page 22: Assigned Category
* **Assigned Category** (`assigned_category`, text, optional): This is the assigned category.
### Page 23: Description Title
* **Description Title** (`description_title`, text, optional): This is the description title.
### Page 24: Demo Title
* **Demo Title** (`demo_title`, text, optional): This is the demo title.
### Page 25: Demo Category
* **Demo Category** (`demo_category`, text, optional): This is the demo category.
