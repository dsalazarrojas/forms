# Creative Design Request Form - Help Guide
## Purpose
The Creative Design Request Form is designed to collect information and preferences from the user for a creative design request. This includes general information such as form title and description, categorization, assigned tool, and output file.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the form title and description to provide a brief overview of the project.
2. Select the category for the project from the options provided.
3. Choose the assigned tool from the available options.
4. Specify the output file for the project.
5. Select the custom options that apply to the project.
6. Decide how the project should be shared with or via other users.
7. Fill in the synced with count, synced via count, synced at, and synced via fields with the relevant information.
8. Finally, fill in the custom fields with any additional information required.

## Field-by-Field Explanation
* **Form title** (1, text, required): Enter a brief title for the project.
* **Description** (2, text, required): Provide a detailed description of the project.
* **Category** (3, select_one, required): Select the category for the project from the options provided (Marketer Forms, Designer Forms, Manager Forms).
* **Assigned Tool** (4, select_one, required): Choose the tool assigned to the project from the options provided (chatjimmy, tool1, tool2).
* **Output File** (5, text, required): Specify the output file for the project.
* **Custom Options** (6, select_multiple, required): Select the custom options that apply to the project.
* **Embedded Code** (7, text, required): Enter any embedded code required for the project.
* **Shared with** (8, select_multiple, required): Decide how the project should be shared with other users (Yes, No).
* **Shared via** (9, select_multiple, required): Decide how the project should be shared via other users (Yes, No).
* **Shared with count** (10, text, required): Enter the number of users shared with.
* **Shared via count** (11, text, required): Enter the number of users shared via.
* **Synced with count** (12, text, required): Enter the number of users synced with.
* **Synced via count** (13, text, required): Enter the number of users synced via.
