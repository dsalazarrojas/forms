# New Blog Post Entry Form - Help Guide

## Purpose
The form is used to create a new blog post entry. It is essential to fill out the form accurately to ensure that the blog post is created correctly.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the required information in the form.
2. Select the correct options for the blog post.
3. Review the form carefully before submitting to ensure that all fields are accurate.

## Field-by-Field Explanation

* **Entry Form** (`title`, `text`, optional):
	+ Enter your blog post entry information here.
* **Headline** (`headline`, `text`, optional):
	+ Enter the headline of the blog post.
* **Content** (`content`, `text`, optional):
	+ Enter the content of the blog post.
* **Published** (`published_at`, `date`, optional):
	+ Select the published status of the blog post.
* **Author** (`author`, `text`, optional):
	+ Select the author of the blog post.
* **Tags** (`tags`, `select_multiple`, optional):
	+ Select the tags of the blog post.
* **Category** (`category`, `select_multiple`, optional):
	+ Select the category of the blog post.
* **Blog Post ID** (`blog_post_id`, `number`, optional):
	+ Enter a unique blog post ID.
* **Blog Post** (`blog_post`, `select_one`, optional):
	+ Select the blog post from the options.
* **Blog Category** (`blog_category`, `select_multiple`, optional):
	+ Select the category of the blog post.
* **Status** (`blog_status`, `select_one`, optional):
	+ Select the status of the blog post.
* **Created At** (`created_at`, `date`, optional):
	+ Select the created at date of the blog post.
* **Updated At** (`updated_at`, `date`, optional):
	+ Select the updated at date of the blog post.
* **Created By** (`created_by`, `text`, optional):
	+ Enter the author name.
* **Updated By** (`updated_by`, `text`, optional):
	+ Enter the author name.
* **Tags Tags** (`tags_tags`, `select_multiple`, optional):
	+ Select the tags of the blog post.
* **Category Tags** (`category_tags`, `select_multiple`, optional):
	+ Select the category tags of the blog post.
* **Blog Post Tags** (`blog_post_tags`, `select_multiple`, optional):
	+ Select the blog post tags.
* **Blog Post Status Tags** (`blog_post_status_tags`, `select_multiple`, optional):
	+ Select the blog post status tags.
* **Published At Date** (`published_at_date`, `date`, optional):
	+ Select the published at date of the blog post.
* **Created At Date** (`created_at_date`, `date`, optional):
	+ Select the created at date of the blog post.
* **Updated At Date** (`updated_at_date`, `date`, optional):
	+ Select the updated at date of the blog post.
* **Entry Form Tags** (`entry_form_tags`, `select_multiple`, optional):
	+ Select the tags of the blog post.

## Tips

* Make sure to fill out all the required fields accurately.
* Select the correct options for the blog post.
* Review the form carefully before submitting to ensure that all fields are accurate.
