# Black Friday Subscription Box Order Form Template - Help Guide
## Purpose
This form is used to collect order information from customers for Black Friday subscription boxes. It's essential to complete this form accurately to ensure that customers receive their correct subscription boxes and that customer data is collected correctly.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the customer's name, shipping address, and email address in the respective fields.
2. Choose the subscription plan that suits the customer's needs.
3. Select the box variant that the customer wants to order.
4. Enter the number of boxes to order.
5. Choose the billing method that the customer prefers (credit card, PayPal, or invoice).
6. Enter any promotional code available to the customer (optional).
7. Add any special requests or preferences for the box items (optional).

## Field-by-Field Explanation
- **Customer name** (`Customer name`, text, required): Enter the customer's full name for shipping purposes.
- **Shipping address** (`Shipping address`, text, required): Enter the customer's street address, city, and postal code for shipping purposes.
- **Email address** (`Email address`, email, required): Enter the customer's email address for order confirmation.
- **Subscription plan** (`Subscription plan`, select_one, required): Choose the subscription duration (monthly, quarterly, or annually).
- **Box variant** (`Box variant`, select_one, required): Select the box theme or size that the customer wants to order.
- **Quantity** (`Quantity`, number, required): Enter the number of boxes to order.
- **Billing method** (`Billing method`, select_one, required): Choose the billing method (credit card, PayPal, or invoice).
- **Promo code** (`Promo code`, text, optional): Enter any promotional code available to the customer.
- **Special requests** (`Special requests`, text, optional): Enter any special requests or preferences for the box items.
