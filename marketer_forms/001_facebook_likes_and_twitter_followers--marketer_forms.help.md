# Facebook Likes And Twitter Followers - Help Guide
## Purpose
This form is designed to collect information about Facebook and Twitter page metrics for social media monitoring or analytics purposes.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields with the necessary information. All fields are optional, but some may be required depending on the context.
* For Facebook fields:
	+ Enter the Facebook page ID or URL to target a specific page.
	+ Enter the date and time range (if applicable) to track historical data.
* For Twitter fields:
	+ Enter the Twitter page ID or URL to target a specific page.
	+ Enter the date and time range (if applicable) to track historical data.

## Field-by-Field Explanation
* **get_facebook_likes (1)**: Enter the number of Facebook likes for the target page.
* **get_twitter_followers (2)**: Enter the number of Twitter followers for the target page.
* **get_facebook_followers (3)**: Enter the number of Facebook followers for the target page.
* **get_twitter_likes (4)**: Enter the number of Twitter likes for the target page.
* **get_twitter_followers_count (5)**: Enter the number of Twitter followers for the target page. (This field is a count, not a count of counts.)
* **get_facebook_likers (7)**: Enter the number of people who like the target Facebook page.
* **get_twitter_likers (8)**: Enter the number of people who like the target Twitter page.
* **target_facebook_page_id (9)**: Enter the ID of the target Facebook page.
* **target_twitter_page_id (10)**: Enter the ID of the target Twitter page.
* **target_account_id (11)**: Enter the ID of the target account.
* **target_facebook_page_url (12)**: Enter the URL of the target Facebook page.
* **target_facebook_page_name (13)**: Enter the name of the target Facebook page.
* **target_twitter_account_url (14)**: Enter the URL of the target Twitter page.
* **target_twitter_page_name (15)**: Enter the name of the target Twitter page.
* **start_date (16)**: Enter the start date for tracking historical data.
* **end_date (17)**: Enter the end date for tracking historical data.
* **start_time (18)**: Enter the start time for tracking historical data.
* **end_time (19)**: Enter the end time for tracking historical data.
* **target_facebook_page_likes (20)**: Enter the number of likes for the target Facebook page.
* **target_twitter_followers (21)**: Enter the number of followers for the target Twitter page.
* **target_facebook_followers (22)**: Enter the number of followers for the target Facebook page.
* **target_twitter_likers (23)**: Enter the number of likers for the target Twitter page.
* **target_facebook_likers (24)**: Enter the number of likers for the target Facebook page.
* **notes (25)**: Enter any additional comments or remarks.

## Tips
* Ensure you have the necessary permissions to access the target pages' metrics.
* Be careful when entering dates and times, as they should be in the correct format.
* If you're unsure about any field, refer to the form's structure and labeling for guidance.
