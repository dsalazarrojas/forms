# Graphic Design Request - Help Guide
## Purpose
This form is designed for clients and internal teams to request graphic design services for various projects, such as logo, brochure, print, and web design. The purpose of this form is to gather essential information about the client's needs and to ensure that requests are properly routed to the design team for efficient processing and delivery.

## How To Complete This Form
To submit a graphic design request, please follow these steps:

1. Enter your client's name in the "Client Name" field.
2. Select the services needed for your project from the "Services Needed" dropdown menu.
3. Provide the project deadline, if applicable, in the "Project Deadline" field.
4. Describe the project requirements and details in the "Description" field.
5. Choose how you will contact the client regarding the project status (e.g., phone, email, or in person) in the "Contact Method" field.
6. Enter the client's email address in the "Email" field, if required (e.g., for communication purposes).
7. Upload any additional files related to the project in the "Upload File" field.

## Field-by-Field Explanation

* **Graphic Design Request**: This is the title of the form, and you can leave it blank if not required.
* **Client Name**: Please enter the name of your client.
* **Services Needed**: Select one or more services needed from the dropdown menu: Logo Design, Brochure Design, Print Design, Web Design, or Branding.
* **Project Deadline**: If you have a specific deadline for the project, enter the date (mm/dd/yyyy) to help us schedule the design work.
* **Description**: Provide a brief description of the project, including any relevant details or requirements.
* **Contact Method**: Select how you will contact the client regarding project status: Phone, Email, or In person.
* **Email**: Enter the client's email address for communication purposes.
* **Upload File**: If you need to attach additional files related to the project, you can upload them here.

## Tips

* Make sure to fill out all required fields to ensure proper processing and delivery of the request.
* If you are unsure about any field, please ask a team member for clarification or guidance.
* Attach any relevant files or documents to ensure that the designer has all the necessary information for a successful project outcome.
