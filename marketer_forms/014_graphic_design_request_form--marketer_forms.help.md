# graphic_design_request_form - Help Guide
## Purpose
The graphic design request form is used to collect information from graphic designers about projects they would like to take on.

## How To Complete This Form
To fill out this form, follow these steps:

1. Click on the form and start filling out the sections below.
2. Enter your project details in the "Project Details" section.
3. Provide the client's name in the "Client Name" section.
4. Give a brief description of the project in the "Project Description" section.
5. Indicate if the project is of a specific type in the "Project Type" section.
6. Choose the file formats you are comfortable working with in the "File Format" section.
7. Set a deadline for the project in the "Deadline" section.
8. Enter your contact information in the "Contact Info" section.
9. Enter your email address in the "Email" section.

## Field-by-Field Explanation

* **Project Details** (Project Details, text, required: false): This is the first section of the form where you will provide a brief summary of your project.
* **Client Name** (Client Name, text, required: false): Enter the name of the client associated with this project.
* **Project Description** (Project Description, text, required: false): Provide a brief description of the project, including any relevant details.
* **Project Type** (Project Type, select_one, required: false): Select 'Yes' if the project is of a specific type, or 'No' if it is not.
* **File Format** (File Format, select_multiple, required: false): Choose the file formats you are comfortable working with for this project. Select 'Yes' for each format you are comfortable with.
* **Deadline** (Deadline, date, required: false): Enter a deadline for the project, if applicable.
* **Contact Info** (Contact Info, text, required: false): Enter your contact information, including any other relevant details.
* **Email** (Email, email, required: false): Enter your email address, which will be used for communication about this project.

## Tips
* Please be thorough when providing information in each section, as it will help us better understand your project and match it with the right designer.
* If you have any questions or concerns, feel free to reach out to us.
* Make sure to review your submission before submitting it to ensure you have provided all necessary information.
