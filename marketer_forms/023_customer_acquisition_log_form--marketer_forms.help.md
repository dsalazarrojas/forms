# Customer Acquisition Log Form - Help Guide
## Purpose
This form is used to record information about how customers were acquired. This helps us track the effectiveness of our marketing efforts and identify areas for improvement.

## How To Complete This Form
- Start by selecting the source of the customer acquisition, such as Email or Social Media.
- Enter the date and time of the customer acquisition in the format mm/dd/yyyy and 12:00 PM for a 12:00 PM time.
- Provide a brief note about the customer acquisition in the text field.
- If the customer was acquired through a specific email, enter their email address.
- If the customer was acquired through a referral, enter the referral source ID.
- If the customer was acquired through a social media source, enter the source URL.
- If the customer was acquired through a specific source, select the source type from the dropdown menu.
- If the customer was acquired through a source with a button, enter the button text, URL, and select the button type and size.
- If the customer was acquired through a source with a button image, enter the image URL.
- If the customer was acquired through a source with a button target, enter the target URL.
- Select the button color and icon from the dropdown menus.
- Finally, select the button position from the dropdown menu.

## Field-by-Field Explanation

* **customer_acquisition_source** (Select One, Required): Select the source of the customer acquisition, such as Email or Social Media.
* **customer_acquisition_date** (Date, Required): Enter the date of the customer acquisition in the format mm/dd/yyyy.
* **customer_acquisition_time** (Time, Required): Enter the time of the customer acquisition in the format 12:00 PM.
* **customer_acquisition_note** (Text, Optional): Enter a brief note about the customer acquisition.
* **customer_acquisition_email** (Email, Required): If the customer was acquired through a specific email, enter their email address.
* **customer_acquisition_phone** (Text, Optional): Enter the phone number of the customer.
* **customer_acquisition_source_id** (Text, Optional): Enter the source ID of the customer acquisition.
* **customer_acquisition_source_url** (Text, Optional): Enter the URL of the source of the customer acquisition.
* **customer_acquisition_source_type** (Select One, Required): Select the type of source from the dropdown menu.
* **customer_acquisition_source_name** (Text, Optional): Enter the name of the source.
* **customer_acquisition_source_description** (Text, Optional): Enter a description of the source.
* **customer_acquisition_source_image_url** (Text, Optional): Enter the URL of the source image.
* **customer_acquisition_source_button_text** (Text, Optional): Enter the text of the button.
* **customer_acquisition_source_button_url** (Text, Optional): Enter the URL of the button.
* **customer_acquisition_source_button_target** (Text, Optional): Enter the target URL of the button.
* **customer_acquisition_source_button_type** (Select One, Required): Select the type of button from the dropdown menu.
* **customer_acquisition_source_button_color** (Select One, Optional): Select the color of the button from the dropdown menu.
* **customer_acquisition_source_button_icon** (Select One, Optional): Select the icon type of the button from the dropdown menu.
* **customer_acquisition_source_button_position** (Select One, Optional): Select the position of the button from the dropdown menu.
* **customer_acquisition_source_button_position_top** (Select One, Optional): Select the position of the button top from the dropdown menu.
* **customer_acquisition_source_button_position_right** (Select One, Optional): Select the position of the button right from the dropdown menu.
* **customer_acquisition_source_button_position_left** (Select One, Optional): Select the position of the button left from the dropdown menu.
* **customer_acquisition_source_button_position_bottom** (Select One, Optional): Select the position of the button bottom from the dropdown menu.
