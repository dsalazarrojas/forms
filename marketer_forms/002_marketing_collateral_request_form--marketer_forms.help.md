# marketing_collateral_request_form - Help Guide
## Purpose
This form is used for requesting marketing collateral materials such as brochures, flyers, and postcards.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **Business Entity** from the list of options.
2. Enter the **Contact Person** who is making the request.
3. Select the **Marketing Material Request** that you need (e.g., brochures, flyers, postcards).
4. Enter the **Marketing Material Count** if applicable.
5. Select the type of **Material Type** you need (e.g., brochures, flyers, postcards).
6. Choose the **Material Format** (e.g., PDF, JPEG, PNG).
7. Enter a **File Name** for the requested material.
8. Enter a **File Description** to provide additional information about the material.
9. Select the **File Type** (e.g., image, document).
10. Choose the **File Location** where the material will be stored (e.g., cloud drive, local).
11. Select the **Marketing Materials** you need (e.g., brochures, flyers, postcards).
12. Enter the **Marketing Material Request Date** when the request is made.
13. Enter the **Marketing Material Request Time** if applicable.
14. Select whether the **Marketing Collateral Request** is requested or not.
15. Select the type of **Marketing Collateral Type** (e.g., in-house, external).
16. Enter the **Marketing Collateral Request Date** when the request is made.
17. Enter the **Marketing Collateral Request Time** if applicable.
18. Select the status of the **Marketing Collateral Material Request** (e.g., requested, in progress, done).
19. Enter any **Marketing Collateral Material Request Comments** if necessary.
20. Enter the **Submitted By** person or user making the request.
21. Confirm that the **Submitted By User** is correct.
22. Mark the request as **Submitted**.

## Field-by-Field Explanation

- **Business Entity (required)**: Select the company or business entity from the list of options. This field ensures that the request is associated with the correct business.
  * Select: Acme Inc.
  * Select: Bmc
  * Select: DigiBank
  * Select: Test Inc.

- **Contact Person (required)**: Enter the name of the person making the request.

- **Marketing Material Request (required)**: Select the type of marketing material you need (e.g., brochures, flyers, postcards).

- **Marketing Material Count (optional)**: Enter the number of materials you need.

- **Material Type (required)**: Select the type of material you need (e.g., brochures, flyers, postcards).

- **Material Format (required)**: Choose the format of the material (e.g., PDF, JPEG, PNG).

- **File Name (required)**: Enter a name for the file.

- **File Description (optional)**: Enter a description of the file.

- **File Type (required)**: Select the type of file (e.g., image, document).

- **File Location (required)**: Choose where the file will be stored (e.g., cloud drive, local).

- **Marketing Materials (required)**: Select the type of marketing materials you need (e.g., brochures, flyers, postcards).

- **Marketing Material Request Date (required)**: Enter the date when the request is made.

- **Marketing Material Request Time (optional)**: Enter the time when the request is made.

- **Marketing Collateral Request (required)**: Select whether the collateral is requested or not.

- **Marketing Collateral Type (required)**: Select the type of collateral (e.g., in-house, external).

- **Marketing Collateral Request Date (required)**: Enter the date when the request is made.

- **Marketing Collateral Request Time (optional)**: Enter the time when the request is made.

- **Marketing Collateral Material Request Status (required)**: Select the status of the request (e.g., requested, in progress, done).

- **Marketing Collateral Material Request Comments (optional)**: Enter any comments about the request.

- **Submitted By (required)**: Enter the person or user making the request.

- **Submitted By User (required)**: Confirm the person or user making the request.

- **Submitted (required)**: Mark the request as submitted.

## Tips

* Ensure that you have all necessary information before completing the form.
* Review the form carefully to ensure that all required fields are filled out.
* If you have any doubts or concerns, contact the authorized personnel for assistance.
* Make sure to keep the form up to date and accurate.
