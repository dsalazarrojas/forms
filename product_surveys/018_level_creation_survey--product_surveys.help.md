# level_creation_survey - Help Guide
## Purpose
This form is used to collect feedback and suggestions from users who have recently created a level. The purpose is to identify areas of improvement for the level creation process.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Choose all that apply for "What did you like best" to provide feedback on what you liked most about the level creation process.
2. Provide detailed feedback on what you liked best in the "What did you like best about it" field.
3. Offer suggestions on how to improve the level creation process in the "How would you improve the level creation process" field.
4. Indicate what you liked least about the level creation process by selecting all that apply for "What did you like least".
5. Provide any additional suggestions or comments in the "Do you have any suggestions for improvement" field.
6. If you want to be contacted regarding your feedback, provide your contact information (phone number and email) in the "Contact" and "Email" fields respectively.
7. If you want to provide more specific feedback or details, you can provide the date of when you went through the level creation process in the "Date" field.

## Field-by-Field Explanation

* **What did you like best**: This is a select-one field that allows you to choose what you liked most about the level creation process. Please select all that apply from the options provided.
* **What did you like best about it**: This is a text field where you can provide detailed feedback on what you liked best about the level creation process.
* **How would you improve the level creation process**: This is a text field where you can provide suggestions on how to improve the level creation process.
* **What did you like least**: This is a select-multiple field that allows you to choose what you liked least about the level creation process. Please select all that apply from the options provided.
* **Do you have any suggestions for improvement**: This is a text field where you can provide any additional feedback or suggestions.
* **Contact**: This is a text field where you can provide your phone number if you want to be contacted regarding your feedback.
* **Email**: This is a text field where you can provide your email address if you want to be contacted regarding your feedback.
* **Date**: This is a date field where you can provide the date of when you went through the level creation process.
* **Level Creation Process**: This field is not currently used in this form but is likely a field for providing feedback on the level creation process.
