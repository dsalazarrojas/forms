# Game Feature Specification Survey - Help Guide
## Purpose
This form is designed to gather feedback and information about game features from users, which will help improve the game development process.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Select the game teams you are most familiar with from the list provided.
2. For the "Game feature" field, briefly describe the game feature you are referring to.
3. Choose your experience with the game feature from the options provided.
4. Select the priority of the game feature from the options provided.
5. If you have any additional comments, type them in the "Comments" field.
6. If you have any submit comments, select the options that apply from the "Submit comments" field.
7. Enter your contact email address so we can reach out to you for further clarification or questions.
8. Enter your contact phone number so we can reach out to you for further clarification or questions.
9. If you have any further comments, type them in the "Additional comments" field.
10. For the "Feature status" field, select the status of the game feature from the options provided.
11. For the "Player status" field, select the status of the player with the game feature from the options provided.
12. For the "Game feature" field, select whether the game feature is implemented or not.
13. For the "Game version" field, select whether the game version is implemented or not.
14. For the "Feature teams" field, select whether the team is working on the game feature or not.
15. Review your answers carefully before submitting the form.

## Field-by-Field Explanation

### Game teams
* Game teams (`game_teams`, `select_one`): This field allows you to select the game teams you are most familiar with. Please choose one or more teams from the list provided.

### Game feature
* Game feature (`game_feature`, `text`): This field is used to briefly describe the game feature you are referring to. Please type a brief description of the game feature.

### Player experience
* Player experience (`player_experience`, `select_multiple`): This field asks for your experience with the game feature. Please choose the options that best describe your experience.

### Feature priority
* Feature priority (`feature_priority`, `select_multiple`): This field asks for the priority of the game feature. Please select the options that best describe the priority.

### Update planning
* Update planning (`update_planning`, `number`): This field is not currently being used in this form, but you can leave it blank if you are unsure.

### Product decisions
* Product decisions (`product_decisions`, `select_multiple`): This field asks for your input on product decisions related to the game feature. Please select the options that best describe your opinions.

### Player satisfaction
* Player satisfaction (`player_satisfaction`, `select_one`): This field asks for your satisfaction level with the game feature. Please choose the option that best describes your experience.

### Feature description
* Feature description (`feature_description`, `note`): This field allows you to provide a brief description of the game feature. Please type a brief description.

### Contact email
* Contact email (`contact_email`, `email`): This field asks for your email address so we can reach out to you for further clarification or questions.

### Contact phone
* Contact phone (`contact_phone`, `text`): This field asks for your phone number so we can reach out to you for further clarification or questions.

### Comments
* Comments (`comments`, `note`): This field is for additional comments or thoughts you want to share about the game feature.

### Submit comments
* Submit comments (`submit_comments`, `select_multiple`): This field asks for your input on submit comments. Please select the options that best describe your agreement or disagreement with the comments.

### Feature status
* Feature status (`feature_status`, `select_multiple`): This field asks for the status of the game feature. Please select the options that best describe the status.

### Player status
* Player status (`player_status`, `select_multiple`): This field asks for the status of the player with the game feature. Please select the options that best describe the status.

### Game feature
* Game feature (`game_feature`, `select_multiple`): This field asks whether the game feature is implemented or not. Please select the options that best describe the status.

### Game version
* Game version (`game_version`, `select_multiple`): This field asks whether the game version is implemented or not. Please select the options that best describe the status.

### Feature teams
* Feature teams (`feature_teams`, `select_multiple`): This field asks whether the team is working on the game feature or not. Please select the options that best describe the status.
