# Manga Reading Platform Feedback - Help Guide
## Purpose
The purpose of this form is to collect feedback from users about their experience with our manga reading platform. We want to know about your platform usage, what issues you've encountered, and any suggestions you have on how we can improve the platform.


## How To Complete This Form
To complete this form, simply select one of the options for the "Platform Use" question, fill in any number for the "Manga Experience" question, provide any relevant information in the "Technical Issues" text field, select all that apply for the "What Can We Improve" question, enter your email address in the "Contact Info" field, select a number for the "Average Time Spent" question, and type in any additional comments in the "Additional Comments" text field. Finally, enter the date you last visited the platform in the "Last Visit Date" field and submit the form.


## Field-by-Field Explanation

* **Platform Use (Select One)**: This question asks how often you use our manga reading platform. Please choose the option that best describes your behavior.
	+ Option 1: I have only ever used this platform once.
	+ Option 2: I use this platform occasionally, but less than a month ago.
	+ Option 3: I use this platform regularly, usually within a week.
* **Manga Experience (Number)**: This question asks about your overall experience with the platform. Please enter a number from 1 to 5, where 1 is a very poor experience and 5 is an excellent experience.
* **Technical Issues (Text Field)**: If you have encountered any technical issues while using the platform, please describe them in this text field.
* **What Can We Improve (Select Multiple)**: This question asks about areas where we can improve the platform. Please select all that apply to you.
	+ Option 4: Navigation and search
	+ Option 5: Filtering and sorting
	+ Option 6: Performance and loading times
* **Contact Info (Email)**: This question is for your contact information. Please enter your email address so we can get in touch with you for further questions or to follow up on your feedback.
* **Average Time Spent (Number)**: This question asks about how much time you spent using the platform. Please enter an approximate number in hours and minutes.
* **Additional Comments (Text Field)**: If you have any additional comments, concerns, or ideas, please type them in this text field.
* **Last Visit Date (Date)**: This question asks when you last visited our platform. Please enter the date in the format DD/MM/YYYY.
* **Technical Issues (Text Field)**: This question is a duplicate of "Additional Comments" and is used to gather more specific technical issues you've encountered. Please use this field to report any technical issues you've experienced.
