# Vehicle Lighting Control Survey - Help Guide
## Purpose
The Vehicle Lighting Control Survey is designed to collect your feedback and satisfaction level with the vehicle's lighting control system. Your input will help us improve the system and provide better driving experiences for all users.

## How To Complete This Form
To complete this form, simply select your answers for each question and submit. You can select one or multiple options for select_multiple fields. For select_one fields, choose only one option that best describes your experience.

## Field-by-Field Explanation
* **Satisfaction Level**: This question asks about your level of satisfaction with the vehicle's lighting control system. Please select one of the options: Very Satisfied, Somewhat Satisfied, Neutral, Somewhat Dissatisfied, or Very Dissatisfied.
* **Feature Priorities**: This question asks which features of the vehicle's lighting control system are important to you. Please select all the features that are important or relevant to you. Note that this field is not required.
* **Safety Perceptions**: This question asks if you feel safe while using the vehicle's lighting control system. Please select one of the options: Yes or No.
* **Issues Encountered**: This question is for any issues or problems you may have encountered while using the vehicle's lighting control system. Please enter your answers in the text field.
* **Suggestions**: This question is for any suggestions you may have to improve the vehicle's lighting control system. Please enter your answers in the text field.
