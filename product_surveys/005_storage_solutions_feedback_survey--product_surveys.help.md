# Storage Solutions Feedback Survey - Help Guide

## Purpose
This form is designed to collect feedback from customers about their experience with your storage solutions. We want to hear about your thoughts, likes, and dislikes so we can improve our services for future customers.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in your **Customer Name** in the text field provided.
2. Enter your **Email** address in the format `example@email.com` or a similar valid email address.
3. Choose all the storage **Storage Product Used** that apply to your experience.
4. Select your **Satisfaction Level** with the storage solutions.
5. Enter your **Rating** for the storage solutions, using a number between 1 and 10.
6. If you'd like to add a specific **Time Spent** on the storage solutions, please use the format `HH:MM` or `MM:SS`.
7. If you'd like to add a **Date Of Last Use**, enter the date you last used the storage solutions.
8. If you'd like to add a **Date Of First Use**, enter the date you first used the storage solutions.
9. In the **Additional Comments** field, write any further thoughts or suggestions you may have about the storage solutions.
10. Choose your preferred **Contact Method** (Phone, Email, In-Person).
11. Select your preferred **Preferred Contact Time** (Morning, Afternoon, Late Afternoon, Evenings).
12. If you have any further thoughts or suggestions, please add them in the **Additional Comments 2** field.

## Field-by-Field Explanation

* **Customer Name**: This is your name as the customer. Please enter your full name as it appears on your records.
* **Email**: This is your valid email address. Please enter it in the format `example@email.com`.
* **Storage Product Used**: Choose all the storage products you used for this experience.
*   *Product A*: Select this option if you used Product A.
*   *Product B*: Select this option if you used Product B.
*   *Product C*: Select this option if you used Product C.
* **Satisfaction Level**: This is how satisfied you are with the storage solutions. Please select one of the options:
	+ **Very Satisfied**
	+ **Somewhat Satisfied**
	+ **Not Satisfied**
* **Rating**: This is how would rate the storage solutions, using a number between 1 and 10.
* **Time Spent**: If you'd like to add a specific time spent on the storage solutions, please use the format `HH:MM` or `MM:SS`.
* **Date Of Last Use**: If you'd like to add a date you last used the storage solutions, please enter the date in the format `MM/DD/YYYY`.
* **Date Of First Use**: If you'd like to add a date you first used the storage solutions, please enter the date in the format `MM/DD/YYYY`.
* **Additional Comments**: This is a free-text field for you to add any further thoughts or suggestions you may have about the storage solutions.
* **Contact Method**: This is how you'd like to be contacted:
	+ **Phone**: Please call us to contact you.
	+ **Email**: Please email us to contact you.
	+ **In-Person**: Please contact us in person.
* **Preferred Contact Time**: This is when you'd prefer to be contacted:
	+ **Morning**: Between 8am and 12pm.
	+ **Afternoon**: Between 12pm and 4pm.
	+ **Late Afternoon**: Between 4pm and 6pm.
	+ **Evenings**: After 6pm.
* **Additional Comments 2**: This is another free-text field for you to add any further thoughts or suggestions you may have.
