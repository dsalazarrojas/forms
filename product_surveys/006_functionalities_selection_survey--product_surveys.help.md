# Functionalities Selection Survey - Help Guide
## Purpose
This form is designed to collect information on functionalities that users want to select or have selected. It's used to gather preferences or input from users on various options related to reports and exports.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the desired functionalities in each list (Functionalities List 1, Functionalities List 2, Functionalities List 3, Functionalities List 4) by choosing the corresponding options.
2. Choose the format in which to save the selections (PDF, CSV, Excel).
3. Select whether to send an email notification (True or False).
4. Enter a subject line for the email notification.
5. Write a brief description of the email notification.
6. Enter the title of the report.
7. Enter a description for the report.
8. Choose the type of report (Option 1, Option 2, Option 3).
9. Enter a file name for the report.
10. Enter the path for the report file.
11. Confirm that the email was sent (True or False).
12. Enter the email address to which the report was sent.
13. Enter the email content sent to the recipient.
14. Choose the type of report file (PDF, CSV, Excel).
15. Enter a description for the report (optional).
16. Enter a description for the report (optional).
17. Enter a description for the report (optional).
18. Enter a description for the report (optional).
19. Click the "Submit" button to complete the form.
