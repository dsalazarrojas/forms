# Mobile Network Connectivity Survey - Help Guide
## Purpose
This survey aims to collect feedback on mobile network connectivity to better understand individual experiences. Please answer the questions honestly to help us improve the service.

## How To Complete This Form
1. Please answer each question based on your actual usage and experience with your mobile network.
2. If you're unsure about a question, please choose the answer that best represents your experience.
3. If you have any additional comments or feedback, please use the "Comments" section at the end.

## Field-by-Field Explanation

* **Introduction** (`Introduction`, note, not required): This is a brief introduction to the survey, explaining its purpose and instructions.
* **How would you rate your current mobile network coverage?** (`mobile_network_coverage`, select_one, not required): Rate your current mobile network coverage as:
	+ Excellent
	+ Good
	+ Fair
	+ Poor
	+ No Coverage
* **How would you rate the reliability of your mobile network?** (`mobile_network_reliability`, select_one, required): Rate the reliability of your mobile network as:
	+ Always On
	+ Most of the time
	+ Sometimes
	+ Rarely
	+ Never
* **How satisfied are you with your mobile network?** (`mobile_network_satisfaction`, select_one, required): Rate your satisfaction with your mobile network as:
	+ Very Satisfied
	+ Satisfied
	+ Neutral
	+ Dissatisfied
	+ Very Dissatisfied
* **What location is your current mobile network usage?** (`location`, select_multiple, not required): Select all that apply:
	+ Rural Area
	+ Urban Area
	+ Suburban Area
	+ Other
* **On how many devices do you use this mobile network?** (`mobile_network_usage`, number, required): Please enter the number of devices you use this mobile network on.
* **What are the mobile devices you use this network on?** (`mobile_network_usage_devices`, select_multiple, not required): Select all that apply:
	+ Mobile Phone
	+ Tablet
	+ Laptop
	+ Desktop
	+ Other
* **Comments** (`mobile_network_comments`, note, not required): If you have any additional comments or feedback, please use this section.
* **Rating** (`mobile_network_rating`, select_one, required): Rate your experience with your mobile network as:
	+ 5
	+ 4
	+ 3
	+ 2
	+ 1
