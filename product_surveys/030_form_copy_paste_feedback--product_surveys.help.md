# Form Copy Paste Feedback - Help Guide
## Purpose
The purpose of this form is to collect feedback from users on the copy-paste functionality of a product or application.

## How To Complete This Form
To complete this form, follow these steps:

* Fill out the form completely, answering all the questions and selecting all the required fields.
* If you have encountered an issue with the copy-paste functionality, describe it in the "Issue Description" field.
* If you have attached a screenshot or file to help explain the issue, upload it in the "Issue Description Attachment" field.
* If you have attached a file that is not a screenshot, upload it in the "Attachment" field.
* If you have feedback or additional information about your experience, provide it in the "Feedback" field.
* If you would like to report your satisfaction with the copy-paste functionality, rate it using the "Satisfaction" field.
* If you have encountered any issues with your operating system, browser type, or browser version, select the relevant options in the "Devices", "Browser Type", and "Browser Version" fields.
* If you would like to report if the issue was relevant to you, select the relevant option in the "Issue Relevant" field.

## Field-by-Field Explanation

* **Copy Paste Feedback** (`copy_paste_title`, text, required)
	+ This is the title of the form.
* **Category** (`category`, select_one, optional)
	+ Please select whether the issue you are experiencing is related to the copy-paste functionality.
* **Description** (`description`, text, required)
	+ Please describe the issue you are experiencing with the copy-paste functionality.
* **Devices** (`devices`, select_multiple, required)
	+ Please select the devices you are using to access the product or application.
* **Browsers** (`browsers`, select_multiple, required)
	+ Please select the browsers you are using to access the product or application.
* **Satisfaction** (`satisfaction`, number, optional)
	+ Please rate your satisfaction with the copy-paste functionality on a scale of 1-10.
* **Issue Found** (`issue_found`, select_multiple, required)
	+ Please select whether you have encountered any issues with the copy-paste functionality.
* **Issue Description** (`issue_description`, text, optional)
	+ Please describe the issue you are experiencing with the copy-paste functionality.
* **Screenshot URL** (`screenshot_url`, text, optional)
	+ If you have a screenshot that can help us understand the issue, please provide the URL of the screenshot.
* **Screenshot File URL** (`screenshot_file_url`, text, optional)
	+ If you have a file that can help us understand the issue, please provide the URL of the file.
* **Feedback** (`feedback`, text, optional)
	+ Please provide any additional feedback or information about your experience.
* **Additional Info** (`additional_info`, text, optional)
	+ Please provide any additional information about your experience.
* **Attachment** (`attachment`, text, optional)
	+ If you have attached a file that can help us understand the issue, please provide the URL of the file.
* **Email** (`email`, email, optional)
	+ Please provide your email address so we can contact you for further clarification.
* **Phone** (`phone`, text, optional)
	+ Please provide your phone number so we can contact you for further clarification.
* **Date Submitted** (`date_submitted`, date, optional)
	+ Please provide the date you submitted this form.
* **Time Submitted** (`time_submitted`, time, optional)
	+ Please provide the time you submitted this form.
* **User Agent** (`user_agent`, text, optional)
	+ Please provide the User Agent string from your browser.
* **Operating System** (`operating_system`, select_one, optional)
	+ Please select the operating system you are using.
* **Browser Type** (`browser_type`, select_one, optional)
	+ Please select the browser type you are using.
* **Browser Version** (`browser_version`, text, optional)
	+ Please provide the version of your browser.
* **Screenshot** (`screenshot`, text, optional)
	+ If you have a screenshot that can help us understand the issue, please provide the URL of the screenshot.
* **Issue Relevant** (`issue_relevant`, select_multiple, optional)
	+ Please select whether the issue was relevant to you.
