# Skincare Product Shelf Life Awareness Survey - Help Guide
## Purpose
This survey is designed to collect data from users about the shelf life awareness of skincare products. The information collected will help us improve the quality of our products and services.

## How To Complete This Form
1. Please answer the questions honestly and thoroughly.
2. If you are unsure about any question, please choose the option that best matches your situation.
3. Take your time to answer each question carefully.

## Field-by-Field Explanation

* **Introduction** (`introduction`, `text`, optional): This is a brief introduction to the survey. Please write a short paragraph describing your experience with the skincare products.
* **Product Type** (`product_type`, `select_one`, optional): Please select the type of skincare product you are referring to (e.g., face cream, serum, lotion, etc.).
* **Product Use** (`product_use`, `select_multiple`, optional): Please select all the ways you use the skincare product (e.g., face, body, hands, etc.).
* **Purchase Date** (`purchase_date`, `date`, optional): If possible, please provide the date you purchased the product.
* **Storage Conditions** (`storage_conditions`, `select_one`, optional): Please describe the storage conditions of the product (e.g., opened, sealed, exposed to light, etc.).
* **Shelf Life Status** (`shelf_life_status`, `select_one`, optional): Please select the current shelf life status of the product (e.g., Active, Inactive, etc.).
* **Packaging** (`packaging`, `text`, optional): Describe the packaging of the product (e.g., sealed, tamper-evident, etc.).
* **Product Condition** (`product_condition`, `select_one`, optional): Please select the current condition of the product (e.g., good, expired, etc.).
* **Purchase Location** (`purchase_location`, `text`, optional): If possible, please provide the location where you purchased the product (e.g., store name, online platform, etc.).
* **Storage Location** (`storage_location`, `text`, optional): If possible, please provide the storage location of the product (e.g., cupboard, drawer, etc.).
* **Packaging Opening** (`packaging_opening`, `select_one`, optional): Please select whether the packaging has been opened (e.g., Yes, No, etc.).
* **Shelf Life** (`shelf_life`, `select_one`, optional): Please select whether the shelf life of the product is still valid (e.g., Yes, No, etc.).
* **Purchase Method** (`purchase_method`, `select_one`, optional): Please select the method of purchase (e.g., online, in-store, etc.).
* **Purchase Price** (`purchase_price`, `number`, optional): If possible, please provide the price you paid for the product.
* **Expiration Date** (`expiration_date`, `date`, optional): If possible, please provide the expiration date of the product.
* **Product Age** (`product_age`, `select_one`, optional): Please select the age of the product (e.g., new, used, etc.).
* **Storage Condition** (`storage_condition`, `select_one`, optional): Please select the storage condition of the product (e.g., dry, damp, etc.).
* **Packaging Quality** (`packaging_quality`, `text`, optional): Describe the quality of the packaging (e.g., good, bad, etc.).
* **Product Pourness** (`product_pourness`, `select_one`, optional): Please select the condition of the product pourness (e.g., Yes, No, etc.).
* **Packaging Opening Condition** (`packaging_opening_condition`, `select_one`, optional): Please select the condition of the packaging opening (e.g., Yes, No, etc.).
* **Packaging Opening Quality** (`packaging_opening_quality`, `text`, optional): Describe the quality of the packaging opening (e.g., good, bad, etc.).
* **Storage Condition** (`storage_condition`, `select_one`, optional): Please select the storage condition of the product (e.g., Yes, No, etc.).
* **Packaging Condition** (`packaging_condition`, `select_one`, optional): Please select the condition of the packaging (e.g., Yes, No, etc.).
* **Pourness Condition** (`pourness_condition`, `select_one`, optional): Please select the condition of the pourness (e.g., Yes, No, etc.).
* **Submission** (`submission`, `note`, optional): Please provide any additional comments or observations about the product and its packaging.
