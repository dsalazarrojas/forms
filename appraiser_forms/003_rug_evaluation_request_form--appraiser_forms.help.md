# Rug Evaluation Request Form - Help Guide
## Purpose
The Rug Evaluation Request Form is a tool used to request an evaluation or appraisal of a rug from experts or assessors. This form helps to gather essential information about the rug, allowing the assessor to provide an accurate and informed evaluation.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the unique **Rug ID** field with the specific ID of the rug you would like to be evaluated.
2. Provide a brief description of the **Rug Name** in the text field.
3. Enter the **Rug Photo URL** with a direct link to a high-quality image of the rug.
4. Select the type of evaluation or appraisal you require in the **Appraisal Type** field from the available options:
	* Appraisal: to determine the value or worth of the rug
	* Restoration: to assess the need for repairs or conservation
	* Resale: to evaluate the rug for resale or market value
	* Inspection: for a general assessment of the rug's condition
5. Finally, provide any additional **Rug Description** in the text field to help the assessor understand the rug's unique features or characteristics.

## Field-by-Field Explanation
### Rug ID (`rug_id`, Number, Required)
* A unique identifier for the rug, used to track and identify the rug in the assessment process.

### Rug Name (`rug_name`, Text, Not Required)
* A brief description of the rug, including its name or any notable features.

### Rug Photo URL (`rug_photo_url`, Text, Not Required)
* A direct link to a high-quality image of the rug, allowing the assessor to examine its condition and features.

### Appraisal Type (`appraisal_type`, Select One, Not Required)
* Select from the available options to indicate the type of evaluation or appraisal required:
	+ Appraisal: to determine the value or worth of the rug
	+ Restoration: to assess the need for repairs or conservation
	+ Resale: to evaluate the rug for resale or market value
	+ Inspection: for a general assessment of the rug's condition

### Rug Description (`rug_description`, Text, Not Required)
* Any additional information about the rug, including its unique features, history, or context.
