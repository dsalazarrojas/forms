# Vintage Item Condition Checklist - Help Guide
## Purpose
The Vintage Item Condition Checklist is a form used to collect detailed information about a vintage item. It helps sellers accurately describe and price their items, ensuring a smooth and efficient buying and selling experience.

## How To Complete This Form
1. Fill in the required fields:
	* Item Number: A unique identifier for the item, if required.
	* Item Description: A brief description of the item.
	* Condition: The overall condition of the item (Excellent, Very Good, Fair, Poor, or Needs Repair).
	* Material: The material the item is made of (Metal, Wood, Plastic, or Other).
	* Item Weight: The weight of the item.
	* Item Value: The value of the item.
2. Fill in the optional fields:
	* Dimensions: If the item has specific dimensions, provide them.
	* Date Purchased: The date the item was purchased (if known).
	* Condition Note: Additional notes about the item's condition.
	* Item History: A brief description of the item's history.
	* Serial Number: The serial number of the item (if applicable).
	* Warranty: Whether the item comes with a warranty (True, False, or Not Applicable).
	* Item Image: A link to an image of the item.
	* Item Video: A link to a video of the item.
	* Item Document: A document related to the item.
	* Other Document: Additional documents related to the item.
	* Item Note: Additional notes about the item.
	* Seller Note: Notes for the seller.
	* Buyer Note: Notes for the buyer.
	* Contact Email: The contact email for the seller.
	* Contact Phone: The contact phone number for the seller.
	* Condition 1, 2, 3, 4: Additional condition descriptions.
3. Review and confirm all fields before submitting the form.

## Field-by-Field Explanation
- **Item Number**: A unique identifier for the item. If required, please fill in the correct identifier. (Required)
- **Item Description**: A brief description of the item. This will help the buyer understand the item's characteristics. (Required)
- **Condition**: The overall condition of the item (Excellent, Very Good, Fair, Poor, or Needs Repair). This will give the buyer an idea of the item's wear and tear. (Required)
- **Material**: The material the item is made of (Metal, Wood, Plastic, or Other). This will help the buyer understand the item's durability and potential flaws. (Required)
- **Item Weight**: The weight of the item. This will give the buyer an idea of the item's size and bulk. (Required)
- **Item Value**: The value of the item. This will give the buyer an idea of the item's monetary worth. (Required)
- **Dimensions**: If the item has specific dimensions, please provide them in the format "Height x Width x Depth" or "Length x Width". (Optional)
- **Date Purchased**: The date the item was purchased (if known). This will give the buyer an idea of the item's age and history. (Optional)
- **Condition Note**: Additional notes about the item's condition. This can be used to provide more details about the item's condition. (Optional)
- **Item History**: A brief description of the item's history. This can be used to provide more context about the item. (Optional)
- **Serial Number**: The serial number of the item (if applicable). This can be used to verify the item's authenticity. (Optional)
- **Warranty**: Whether the item comes with a warranty (True, False, or Not Applicable). This will give the buyer an idea of the item's reliability and support. (Optional)
- **Item Image**: A link to an image of the item. This can be used to provide a visual representation of the item. (Optional)
- **Item Video**: A link to a video of the item. This can be used to provide a more in-depth look at the item. (Optional)
- **Item Document**: A document related to the item. This can be used to provide more information about the item. (Optional)
- **Other Document**: Additional documents related to the item. This can be used to provide more context about the item. (Optional)
- **Item Note**: Additional notes about the item. This can be used to provide more information about the item. (Optional)
- **Seller Note**: Notes for the seller. This can be used to provide more information about the seller. (Optional)
- **Buyer Note**: Notes for the buyer. This can be used to provide more information about the buyer. (Optional)
- **Contact Email**: The contact email for the seller. This can be used to contact the seller for more information. (Optional)
- **Contact Phone**: The contact phone number for the seller. This can be used to contact the seller for more information. (Optional)
- **Condition 1, 2, 3, 4**: Additional condition descriptions. These can be used to provide more details about the item's condition. (Optional)
