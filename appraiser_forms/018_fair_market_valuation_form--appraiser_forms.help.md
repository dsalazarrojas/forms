# fair-market-valuation-form - Help Guide
## Purpose
The fair market valuation form is designed to collect data for fair market valuation of properties. It helps gather information about the property in question, including its type, sale type, address, and other relevant details.

## How To Complete This Form

To complete this form, please follow these steps:

1.  Start by filling out the property type field. This will help us understand the type of property you are dealing with (e.g., residential, commercial, industrial).
2.  Next, select the sale type from the options provided (e.g., As-Is, Where-Is, Commission Sale).
3.  Enter the property address in the property address field.
4.  If applicable, select the fair market value amount and other relevant fields.
5.  Continue filling out the remaining fields as they apply to your situation.
6.  Review your answers carefully before submission.

## Field-by-Field Explanation

*  **Property Type**: This field asks for the type of property you are valuing (e.g., residential, commercial, industrial).
*  **Sale Type**: This field helps us understand how the property is being sold (e.g., As-Is, Where-Is, Commission Sale).
*  **Sale Conditions**: This field allows you to specify any special conditions of the sale (e.g., sale as-is, subject to inspection).
*  **Property Description**: Please provide a brief description of the property.
*  **Property Address**: Enter the complete address of the property.
*  **Fair Market Value Amount**: Enter the estimated fair market value of the property (in dollars).
*  **Comparable Sales**: Provide a list of comparable sales used for valuation.
*  **Property Age**: Select the age of the property from the provided options (e.g., 0-5, 6-15, 16-25).
*  **Property Land Size**: Select the size of the property from the provided options (e.g., Small, Medium, Large).
*  **Market Trends**: Select the current market trend from the provided options (e.g., Increasing, Decreasing, Stable).
*  **Comparable Sales Count**: Enter the number of comparable sales used for valuation.
*  **Average Sale Price**: Enter the average sale price of comparable sales (in dollars).
*  **Sale Date**: Enter the date of the sale (in mm/dd/yyyy format).
*  **Property Type 2**: This field asks for an additional type of property (e.g., residential, commercial, industrial).
*  **Property Use**: Select the intended use of the property from the provided options (e.g., residential, commercial, industrial).
*  **Property Land Use**: Select the land use of the property from the provided options (e.g., residential, commercial, industrial).
*  **Property Use Status**: Select the status of the property use from the provided options (e.g., active, inactive, vacant).
*  **Property Zoning**: Select the zoning of the property from the provided options (e.g., residential, commercial, industrial).
*  **Neighborhood**: Select whether the property is in a neighborhood with desired features (Yes/No).
*  **Property Viewing Area**: Enter any relevant property viewing area information.
*  **Sale Commission**: Select whether commission is included in the sale (Yes/No).
*  **Property Features**: Provide any additional property features.
*  **Neighborhood Features**: Select whether the neighborhood has desired features (Yes/No).
*  **Property Condition**: Select the condition of the property from the provided options (e.g., good, fair, poor).
*  **Property Land Use Status**: Select the status of the property land use from the provided options (e.g., active, inactive, vacant).
*  **Sale Condition**: Select the condition of the sale from the provided options (e.g., as-is, with repair, other).
*  **Similar Properties**: Provide information about similar properties.
*  **Notes**: Leave any additional comments or notes about the property.
*  **Appraiser Note**: Enter any additional comments or notes from the appraiser.
