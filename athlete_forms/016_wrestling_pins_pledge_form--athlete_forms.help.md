# Wrestling Pins Pledge Form - Help Guide
## Purpose
This form is used to gather information on wrestlers who intend to support a particular wrestler in a tournament or competition.

## How To Complete This Form
To complete this form, please follow these steps:

1. Review the form and ensure you have all the necessary information before submitting.
2. Select the correct response for each question, using the options provided.
3. Enter numerical values in the numerical fields as required.
4. Submit the form once you have completed all the fields.

## Field-by-Field Explanation
* **Wrestler** (`wrestler`, select_one, required: false): Select "Yes" if you plan to support this wrestler, or "No" if not.
* **Pledge** (`pledge`, number, required: false): If you selected "Yes" for the previous question, enter the amount you are willing to pledge.
* **Pledge Type** (`pledge_type`, select_one, required: false): If you are pledging support, select "Yes" to indicate you are offering monetary support, and "No" otherwise.
* **Amount** (`amount`, number, required: false): Enter the numerical value of the pledge.
* **Pin Total** (`pin_total`, number, required: false): Enter the total number of pins or points for this wrestler.
* **Pin Value** (`pin_value`, number, required: false): Enter the value for the first pin.
* **Pin Value 2** (`pin_value_2`, number, required: false): Enter the value for the second pin.
* **Pin Value 3** (`pin_value_3`, number, required: false): Enter the value for the third pin.
* **Pin Value 4** (`pin_value_4`, number, required: false): Enter the value for the fourth pin.
* **Pin Value 5** (`pin_value_5`, number, required: false): Enter the value for the fifth pin.
* **Pin Value 6** (`pin_value_6`, number, required: false): Enter the value for the sixth pin.
* **Pin Value 7** (`pin_value_7`, number, required: false): Enter the value for the seventh pin.
* **Pin Value 8** (`pin_value_8`, number, required: false): Enter the value for the eighth pin.
* **Pin Value 9** (`pin_value_9`, number, required: false): Enter the value for the ninth pin.
* **Pin Value 10** (`pin_value_10`, number, required: false): Enter the value for the tenth pin.

## Tips
* Ensure you have all the necessary information before submitting the form.
* Review your responses carefully to ensure accuracy.
* If you are unsure about any question, ask for clarification before submitting.
