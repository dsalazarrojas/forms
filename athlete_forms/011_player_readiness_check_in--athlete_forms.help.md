# Player Readiness Check In - Help Guide

## Purpose
This form is used to report an athlete's availability for each leg of an event. It helps the event organizers to track the athlete's readiness and make informed decisions about their participation.

## How To Complete This Form
1. Select "Player Readiness Check In" from the form options.
2. Enter the player's name and email address, if available.
3. Enter the player's phone number, if available.
4. For each leg of the event, select "Yes" or "No" to indicate the player's availability.
5. Enter any additional notes or comments in the "Notes" section.
6. Select the category of the event from the options provided.

## Field-by-Field Explanation

* **Name** (Text): Enter the player's name.
* **Email** (Email): Enter the player's email address, if available.
* **Phone** (Text): Enter the player's phone number, if available.
* **Availability 1**, **Availability 2**, **Availability 3**, **Availability 4**, **Availability 5**, **Availability 6** (Select one): Select "Yes" or "No" for each leg of the event to indicate the player's availability.
* **Notes** (Note): Enter any additional comments or information about the player's situation.
* **Category** (Select multiple): Select all the categories that apply to the event.
