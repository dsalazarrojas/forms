# sports_team_mid_season_health_check_in_form - Help Guide
## Purpose

This form is used to gather information about a player's health and status during the mid-season period. It helps the team's medical staff to provide timely and accurate support to the player.

## How to Complete This Form

1.  Fill out each field accurately and completely.
2.  If a field is marked as optional, you can leave it blank, but providing the information will help the team's medical staff to better understand the player's situation.
3.  Reach out to the team's medical staff if you're unsure about any field or feel that some information is not relevant.

## Field-by-Field Explanation

- **Player Health**: This is a free-form field where you can describe the player's health in general.
  * Required: No
  * Type: Text

- **Player Symptoms**: This field is used to list the player's symptoms.
  * Required: No
  * Type: Text

- **Medical Condition**: This field is used to describe any existing medical conditions that the player may have.
  * Required: No
  * Type: Text

- **Health Check Date**: This field is used to record the date of the health check.
  * Required: No
  * Type: Date

- **Team Doctor's Notes**: This field is for the medical staff to add any additional notes.
  * Required: No
  * Type: Text

- **Player Status**: Please select all that apply:
    * Active
    * Injured
    * Sick
  * Required: No
  * Type: Select Multiple

- **Player Status Note**: This field is for any additional notes about the player's status.
  * Required: No
  * Type: Text

- **Return Date**: This field is for recording the expected return date of the player.
  * Required: No
  * Type: Date

- **Return Note**: This field is for any additional notes about the player's return.
  * Required: No
  * Type: Text

- **Other Notes**: This field is for any additional information.
  * Required: No
  * Type: Note

- **Contact**: This field is for contact information.
  * Required: No
  * Type: Text

- **Email**: This field is for the player's email address.
  * Required: No
  * Type: Email

- **Team Name**: This field is for the team's name.
  * Required: No
  * Type: Text

- **Team Name Other**: This field is for any additional team name information.
  * Required: No
  * Type: Text

- **School Club League**: This field is for the school club league.
  * Required: No
  * Type: Text

- **School Club League Other**: This field is for any additional school club league information.
  * Required: No
  * Type: Text

- **Player ID**: This field is for the player's ID number.
  * Required: No
  * Type: Number

- **Player ID Other**: This field is for any additional player ID information.
  * Required: No
  * Type: Text

- **Sport**: This field is for the sport played.
  * Required: No
  * Type: Text

- **Sport Other**: This field is for any additional sport information.
  * Required: No
  * Type: Text

- **Season**: This field is for the season.
  * Required: No
  * Type: Text

- **Season Other**: This field is for any additional season information.
  * Required: No
  * Type: Text

- **Coach Name**: This field is for the coach's name.
  * Required: No
  * Type: Text

- **Coach Name Other**: This field is for any additional coach name information.
  * Required: No
  * Type: Text

- **Submitted By**: This field is for the person submitting the form.
  * Required: No
  * Type: Text
