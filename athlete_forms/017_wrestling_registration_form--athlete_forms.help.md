# Wrestling Registration Form - Help Guide
## Purpose
This form collects information from wrestlers, referees, and other stakeholders involved in a wrestling match. The goal is to gather essential details for official record-keeping and future reference.

## How To Complete This Form
- Start by filling out the first page (page 1) with your basic information, including your name (wrestler_info), your athlete info (athlete_info), and any additional info (info_form).
- Proceed to page 2 to enter details about your team (team_info), match (match_info), and match details (match_details).
- Fill out the referee information (referee_info) and match result (match_result) on page 3.
- Finally, review and confirm all your entries on the last page (page 4).

## Field-by-Field Explanation
- **wrestler_info** (wrestler_info): A basic text input field for your name.
	* Label: Wrestler Info
	* Type: text
	* Required: No
- **athlete_info** (athlete_info): A text box for additional information about the athlete.
	* Label: Athlete Info
	* Type: text
	* Required: No
- **team_info** (team_info): A text input field for team information.
	* Label: Team Info
	* Type: text
	* Required: No
- **match_info** (match_info): A basic text input field for the match.
	* Label: Match Info
	* Type: text
	* Required: No
- **match_details** (match_details): A text box for match details, such as rules or unique aspects.
	* Label: Match Details
	* Type: text
	* Required: No
- **referee_info** (referee_info): A text input field for the referee's information.
	* Label: Referee Info
	* Type: text
	* Required: No
- **match_result** (match_result): A text box for recording the match result.
	* Label: Match Result
	* Type: text
	* Required: No
- **athlete_info** (athlete_info): A basic text input field for athlete info.
	* Label: Athlete Info
	* Type: text
	* Required: No
- **wrestler** (wrestler): A basic text input field for wrestler's name.
	* Label: Athlete (Wrestler)
	* Type: text
	* Required: No
- **matches** (matches): A basic text input field for recorded matches.
	* Label: Matches
	* Type: text
	* Required: No
