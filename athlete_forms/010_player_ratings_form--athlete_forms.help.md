# player_ratings_form - Help Guide
## Purpose
The "player_ratings_form" is used for collecting ratings and feedback on player performance.

## How To Complete This Form
1. Select "Player One" and "Player Two" fields from the given options.
2. Provide a numerical value for "Rating" field.
3. Add comments in the "Comments" field, if necessary.
4. Select the rating system and rating date and time for the player.
5. Choose the "Player Rated By" field from the given options.
6. Provide contact information in "Email" and "Phone" fields.
7. Add additional notes in the "Notes" field, if necessary.
8. Provide more specific player ratings in "Player Rating 1", "Player Rating 2", "Player Rating 3", "Player Rating 4", "Player Rating 5" fields.
9. Add additional comments or feedback in "Created By", "Modified By", "Created At" fields, if necessary.

## Field-by-Field Explanation
* **Player One**: Select one of the given options for Player One.
* **Player Two**: Select one of the given options for Player Two.
* **Rating**: Provide a numerical value for the player's rating.
* **Comments**: Add any additional comments or feedback for the player.
* **Rating System**: Select one of the given options for the rating system.
* **Player Rating Date**: Select a date for the player's rating.
* **Player Rating Time**: Select a time for the player's rating.
* **Player Rated By**: Select one of the given options for Player Rated By.
* **EMail**: Enter the player's email address.
* **Phone**: Enter the player's phone number.
* **Notes**: Add any additional notes about the player.
* **Player Rating 1, Player Rating 2, Player Rating 3, Player Rating 4, Player Rating 5**: Provide more specific player ratings.
* **Created By**: Enter the name of the person who created the form.
* **Modified By**: Enter the name of the person who modified the form.
* **Created At**: Select a date for when the form was created.

Please ensure that all required fields are filled out, and provide accurate information for each field. If you have any doubts or concerns, please contact the relevant authorities.
