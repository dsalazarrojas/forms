# Athlete Absence Notification - Help Guide
## Purpose
The Athlete Absence Notification form is used to inform the athletic department of an athlete's absence and provide relevant details for planning and coordination purposes.

## How To Complete This Form

To complete this form, please follow these steps:

1. Enter the athlete's full name and ID number in the "Athlete Full Name" and "Athlete ID Number" fields.
2. Select the team the athlete belongs to from the "Team Name" dropdown menu.
3. Select the sport the athlete participates in from the "Sport" dropdown menu.
4. Choose the type of absence from the "Type of Absence" dropdown menu.
5. Select the date of absence and the expected return date in the respective fields.
6. Choose a reason category from the "Reason Category" dropdown menu.
7. Enter a brief description of the reason for absence in the "Reason Details" field.
8. Select "Yes" or "No" in the "Is This Absence Injury Related" field if the absence is due to an injury.
9. Enter the name, email, and phone number of the parent or guardian submitting this form in the "Parent or Guardian Name", "Parent or Guardian Email", and "Parent or Guardian Phone" fields.
10. Select the primary coach to notify from the "Coach to Notify" dropdown menu.
11. Enter any additional comments or information in the "Additional Comments" field.

## Field-by-Field Explanation

* **Athlete Full Name** (Text, Required): Enter the first and last name of the athlete.
* **Athlete ID Number** (Text, Optional): Enter the student or team ID number if applicable.
* **Team Name** (Select One, Required): Select the team the athlete belongs to.
* **Sport** (Select One, Required): Select the sport the athlete participates in.
* **Type of Absence** (Select One, Required): Choose the type of absence from the dropdown menu.
* **Date of Absence** (Date, Required): Select the date the athlete will be absent.
* **Expected Return Date** (Date, Optional): Enter the expected return date, if known.
* **Reason Category** (Select One, Required): Choose a reason category for the absence.
* **Reason Details** (Text, Required): Enter a brief description of the reason for absence.
* **Is This Absence Injury Related** (Select One, Required): Select "Yes" if the absence is due to an injury.
* **Medical Note Required** (Select One, Optional): Select "Yes" if a medical note is required upon return.
* **Parent or Guardian Name** (Text, Required): Enter the name of the parent or guardian submitting this form.
* **Parent or Guardian Email** (Email, Required): Enter the contact email for follow-up.
* **Parent or Guardian Phone** (Text, Required): Enter the contact phone number.
* **Coach to Notify** (Select One, Required): Select the primary coach to notify.
* **Additional Comments** (Text, Optional): Enter any other information the coaching staff should know.
