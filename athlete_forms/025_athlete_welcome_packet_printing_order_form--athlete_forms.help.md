# Athlete Welcome Packet Printing Order Form - Help Guide

## Purpose

This form is designed to gather information for printing welcome packets for athletes. Please fill out the form below to place your order.

## How To Complete This Form

1. Fill out the required fields (marked as "required" in the form)
2. Make sure to select the correct options for each field to ensure the correct processing of your order
3. Review the form carefully before submitting to ensure all necessary information is included

## Field-by-Field Explanation

* **Organization Name (1)**: Name of the team or organization
* **Department (2)**: Select the department that is ordering the welcome packets
* **Contact Person Name (3)**: Primary contact for the order
* **Contact Email (4)**: Email for order communications
* **Contact Phone (5)**: Phone number for order questions
* **Order Date (6)**: Date of the order
* **Needed By Date (7)**: When do you need the packets
* **Packet Type (8)**: Type of welcome packet (e.g. New Athlete Welcome Packet, Season Welcome Packet, etc.)
* **Quantity Needed (9)**: Number of packets to print
* **Packet Size (10)**: Preferred size of the packet
* **Paper Type (11)**: Preferred paper quality
* **Color Options (12)**: Print color preference
* **Binding Type (13)**: How the packets should be bound
* **Folder Type (14)**: If using folders, select the type of folder
* **Contents Included (15)**: Select all documents to include in the packet
* **Custom Content Description (16)**: Describe any custom documents included
* **Personalization Needed (17)**: Do the packets need individual names or info
* **Athlete List Provided (18)**: Will you provide a list for personalization
* **Logo Needed (19)**: Is logo printing needed
* **Logo File (20)**: Upload logo file or describe
* **Delivery Method (21)**: How should the order be delivered
* **Delivery Address (22)**: Where should the order be delivered
* **Budget or Account Code (23)**: For billing purposes
* **Special Instructions (24)**: Any special requests or notes
* **Rush Order (25)**: Is this a rush order

## Tips

* Make sure to review the form carefully before submitting
* Double-check the required fields are filled out correctly
* If you are unsure about any field, please contact the print shop for guidance
