# Gym Cross Training Tournament Entry Form - Help Guide
## Purpose
The purpose of this form is to register an athlete to participate in a Gym Cross Training Tournament.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the appropriate division level for the athlete.
2. Choose the weight class for the athlete.
3. Select a date for the tournament.
4. Confirm if the event is a check-in event.
5. Enter the name of the event.
6. Enter the Gym ID.
7. Enter the Tournament ID.
8. Set the event check-in time.
9. Set the event check-in date.
10. Set the registration date.
11. Confirm if this is a check-in event 2.
12. Select additional information for event checkin 2.

## Field-by-Field Explanation
* **Athlete Information** (`title`, `text`, `required`): This is the title of the form, it's not editable.
* **Division** (`division`, `select_one`, `required`): Choose the division level for the athlete. This field is required.
* **Weight Class** (`weight_class`, `select_multiple`, `required`): Select one or multiple weight classes for the athlete.
* **Tournament Date** (`tournament_date`, `date`, `required`): Enter the date of the tournament. This field is required.
* **Event Checkin** (`event_checkin`, `select_one`, `required`): Confirm if the event is a check-in event. This field is required.
* **Event Name** (`event_name`, `text`, `required`): Enter the name of the event. This field is required.
* **Gym ID** (`gym_id`, `text`, `required`): Enter the Gym ID. This field is required.
* **Tournament ID** (`tournament_id`, `text`, `required`): Enter the Tournament ID. This field is required.
* **Event Checkin Time** (`event_checkin_time`, `time`, `required`): Set the event check-in time. This field is required.
* **Event Checkin Date** (`event_checkin_date`, `date`, `required`): Set the event checkin date. This field is required.
* **Registration Date** (`registration_form`, `date`, `required`): Set the registration date. This field is required.
* **Event Checkin Form 2** (`event_checkin_form_2`, `select_multiple`, `required`): Confirm if this is a checkin event 2. This field is required.
* **Athlete Info Form 2** (`athlete_info_form_2`, `select_one`, `required`: Confirm if this is athlete info 2. This field is not required.

Note: This form has 12 fields, each with its own purpose and explanation. The form is designed to gather relevant information from athletes and ensure they are properly registered and prepared for the tournament.
