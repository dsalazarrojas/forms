# Peer Based Curriculum Evaluation Registration Form - Help Guide
## Purpose
This form is used for registering a peer-based curriculum evaluation. It gathers information about the curriculum being evaluated and the evaluator conducting the evaluation.

## How To Complete This Form
1.  Click on the "Registration Form" page to begin the evaluation registration process.
2.  Fill out the fields on the "Registration Form" page with the required information.
3.  Move on to the next page for more fields.
4.  Repeat steps 2-3 until you have completed all the pages.
5.  Once you have filled out all the fields, click the "Submit" button to complete the evaluation registration process.

## Field-by-Field Explanation

* **Registration Form** (1, text, required):
	+ This is the first page of the evaluation registration form. Enter the required information about the evaluated curriculum.
* **Evaluated Curriculum** (2, text, required):
	+ Enter the title of the curriculum being evaluated.
* **Evaluator Name** (3, text, required):
	+ Enter your name as the evaluator.
* **Institution** (4, text, required):
	+ Enter the name of the institution associated with the curriculum.
* **Evaluation Type** (5, select_one, required):
	+ Select the type of evaluation that applies to your situation, such as "Peer Review", "Peer Review (Internal)", or "Peer Review (Internal) - Institutional".
* **Start Date** (6, date, optional):
	+ Enter the start date of the evaluation if it is relevant to your situation.
* **End Date** (7, date, optional):
	+ Enter the end date of the evaluation if it is relevant to your situation.
* **Evaluation Period** (8, text, optional):
	+ Enter any additional information about the evaluation period if it is relevant to your situation.
* **Comments** (9, text, optional):
	+ Enter any additional comments about the evaluation if it is relevant to your situation.
* **Evaluation Completed** (10, select_multiple, required):
	+ Select whether the evaluation is completed, with options "Yes" or "No".
* **Evaluation Completed Date** (11, date, optional):
	+ Enter the date of when the evaluation was completed if it is relevant to your situation.
* **Evaluations Completed** (12, select_multiple, required):
	+ Select whether you have completed evaluations, with options "Yes" or "No".
* **Evaluator Notes** (13, text, optional):
	+ Enter any additional notes from the evaluator.
* **Evaluation Status** (14, select_multiple, required):
	+ Select the status of the evaluation, with options "Active" or "Completed".
* **Evaluator E-mail** (15, email, optional):
	+ Enter the email address of the evaluator.
* **Phone** (16, text, optional):
	+ Enter the phone number of the evaluator.
* **Institutional Reviewer Name** (17, text, optional):
	+ Enter the name of the institutional reviewer.
* **Department** (18, text, optional):
	+ Enter the department name associated with the institutional reviewer.
* **Evaluator Position** (19, text, optional):
	+ Enter the position of the evaluator.
* **Reviewer Notes** (20, text, optional):
	+ Enter any notes from the reviewer.
* **Reviewer E-mail** (21, email, optional):
	+ Enter the email address of the reviewer.
* **Phone1** (22, text, optional):
	+ Enter the phone number of the reviewer.
* **Reviewer Position1** (23, text, optional):
	+ Enter the position of the reviewer.
* **Institutional Reviewer Phone** (24, text, optional):
	+ Enter the phone number of the institutional reviewer.
* **Institutional Reviewer Position** (25, text, optional):
	+ Enter the position of the institutional reviewer.
* **Evaluator** (26, text, optional):
	+ Enter any additional information about the evaluator, if necessary.

## Tips
* Make sure to fill out all the required fields.
* Enter accurate and complete information to ensure that the evaluation process runs smoothly.
* If you are unsure about any field, refer back to this help guide for more information.
