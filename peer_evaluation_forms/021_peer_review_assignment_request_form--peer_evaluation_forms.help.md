# Peer Review Assignment Request Form - Help Guide
## Purpose
This form is used to request a peer review assignment from a reviewer. It helps to identify and document the necessary steps and requirements for the review process.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form completely and accurately.
2. Make sure to select a valid peer reviewer.
3. Select the correct evaluation criteria for the review.
4. Choose a due date for the review.
5. Select a review deadline if necessary.
6. Fill out the submission details, if applicable.
7. Select if the review form is required and if any attachments are needed.

## Field-by-Field Explanation
* **Request Form**: This field is for the purpose of the request.
* **Peer Reviewer**: Select the reviewer who will review the assignment. This field is required.
* **Evaluation Criteria**: Choose the criteria that the reviewer will use to evaluate the assignment. This field is optional, but selecting the correct criteria is crucial for a thorough review.
* **Due Date**: Enter the date by which the review needs to be completed. This field is optional.
* **Review Deadline**: Enter the date by which the submission should be received from the reviewer. This field is optional.
* **Submission**: Enter any additional submission details if necessary. This field is optional.
* **Review Form**: Indicate if a review form is required for this review. This field is optional.
* **Review Form Attachment**: Indicate if any attachments are required to be submitted with the review form. This field is optional.
