# Mixed Use Property Development Application Form - Help Guide
## Purpose
This form is designed to collect information for mixed-use property development applications.

## How To Complete This Form
1. Select the type of property development you are applying for.
2. Choose the size of the property.
3. Select the primary use of the land.
4. Enter the address of the property.
5. Enter the name of the contact person or organization.
6. Enter the contact person or organization email address.
7. Enter the contact person or organization phone number.
8. Confirm the property's address.
9. Enter the name of the property owner.
10. Describe the property's current status.
11. Enter the date of submission.
12. Enter the time of submission.
13. Describe your development project.
14. Confirm the type of property development.

## Field-by-Field Explanation

* **1. Property Development Type** (Residential/Commercial/Industrial): This field is used to select the type of property development you are applying for. Please choose the correct option that best describes your project.
* **2. Property Size** (Small/Medium/Large): This field is used to select the size of the property. Please choose the correct option that best describes your project.
* **3. Land Use** (Residential/Commercial/Industrial): This field is used to select the primary use of the land. Please choose the correct option that best describes your project.
* **4. Address** (text): This field is used to enter the address of the property. Please enter the correct address in the format of "Street address, City, State, Zip".
* **5. Contact Name** (text): This field is used to enter the name of the contact person or organization. Please enter the name of the person or organization responsible for the application.
* **6. Contact Email** (email): This field is used to enter the contact person or organization email address. Please enter a valid email address in the format of "name@example.com".
* **7. Contact Phone** (text): This field is used to enter the contact person or organization phone number. Please enter a valid phone number in the format of "123-456-7890" or "123-456-7890 ext 123".
* **8. Property Address** (text): This field is used to confirm the property's address. Please enter the correct address in the format of "Street address, City, State, Zip".
* **9. Property Owner** (text): This field is used to enter the name of the property owner. Please enter the name of the person or organization that owns the property.
* **10. Property Status** (text): This field is used to describe the property's current status. Please enter a brief description of the property's status.
* **11. Submission Date** (date): This field is used to enter the date of submission. Please enter a valid date in the format of "YYYY-MM-DD".
* **12. Submission Time** (time): This field is used to enter the time of submission. Please enter a valid time in the format of "HH:MM AM/PM".
* **13. Description** (text): This field is used to describe your development project. Please enter a brief description of your project.
* **14. Property Type (Confirmation)** (Residential/Commercial/Industrial): This field is used to confirm the type of property development. Please select the correct option that best describes your project.

Note: Please make sure to review each field carefully and enter accurate information to avoid errors and delays in the development process.
