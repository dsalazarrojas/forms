# Special Levy Reminder Form - Help Guide
## Purpose

The Special Levy Reminder Form is a tool used by property managers to keep track of special levies for various properties. It helps identify which properties have special levies, who the manager is, and the current payment status of the levy.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the properties with special levies using the "Special Levy Reminder Form" field on page 1.
2. Enter the property manager's information using the "Property Manager Info" field on page 2.
3. Provide the resident's information using the "Resident Info" field on page 2.
4. Specify whether to send a levy notice using the "Send Levy Notice" field on page 3.
5. Indicate whether to collect acknowledgement from the resident using the "Collect Acknowledgement" field on page 3.
6. Update the payment status of the levy using the "Payment Status" field on page 4.
7. Record the resident's response, if any, in the "Resident Response" field on page 4.
8. Enter any special instructions for the levy using the "Special Instructions" field on page 4.

## Field-by-Field Explanation

* **Special Levy Reminder Form** (`special_levy_reminder_form`, select_multiple, required: false): Select all properties with special levies.
* **Property Manager Info** (`property_manager_info`, text, required: false): Enter the property manager's name and contact information.
* **Resident Info** (`resident_info`, text, required: false): Enter the resident's name and contact information.
* **Send Levy Notice** (`send_levy_notice`, select_one, required: false): Choose whether to send a notice to the resident.
* **Collect Acknowledgement** (`collect_acknowledgement`, select_multiple, required: false): Choose whether to collect acknowledgement from the resident.
* **Payment Status** (`payment_status`, select_one, required: false): Indicate the current payment status of the levy (Paid, Unpaid, or Partial).
* **Resident Response** (`resident_response`, text, required: false): Record any response from the resident.
* **Special Instructions** (`special_instructions`, text, required: false): Enter any special instructions for the levy.
