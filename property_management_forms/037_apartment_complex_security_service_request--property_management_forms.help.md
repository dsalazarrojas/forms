# Apartment Complex Security Service Request - Help Guide
## Purpose
This form is used to submit a security service request to the apartment complex security team. Please fill out this form to provide information about the incident or issue you are reporting.

## How To Complete This Form
- Read each question carefully and answer all questions relevant to your request.
- Provide accurate and relevant information to help the security team respond and resolve your issue.
- If you are unsure about any questions, you can contact the security team for assistance.
- Once you have filled out the form, submit it for processing.

## Field-by-Field Explanation
* **Request ID** (`request_id`, text, required): A unique identifier for your request. Please enter a number that the security team can use to track your issue.
* **Request Date** (`request_date`, date, required): The date you are submitting this request.
* **Request Time** (`request_time`, time, required): The time you are submitting this request.
* **Resident Name** (`resident_name`, text, required): Your full name as a resident of the apartment complex.
* **Resident Email** (`resident_email`, email, required): Your contact email address.
* **Phone Number** (`resident_phone`, text, required): Your contact phone number.
* **Apartment Number** (`apartment_number`, text, required): The number of your apartment unit.
* **Building Number** (`building_number`, text, optional): The building identifier (if applicable).
* **Type of Security Request** (`request_type`, select_one, required): Select one of the following options: Emergency, Urgent, Routine, or Information only.
* **Incident Category** (`incident_category`, select_one, required): Select one of the following options: Suspicious activity, Noise complaint, Unauthorized access, Property damage, Theft or vandalism, Harassment, Parking issue, Lighting issue, Gate or access problem, or Other.
* **Incident Description** (`incident_description`, text, required): Describe the incident or issue you are reporting.
* **Incident Location** (`incident_location`, text, required): Where did the incident or issue occur?
* **Incident Date** (`incident_date`, date, required): When did the incident or issue occur?
* **Incident Time** (`incident_time`, time, required): What time did the incident or issue occur?
* **Is this an Ongoing Issue** (`ongoing_issue`, select_one, required): Select one of the following options: Yes, multiple times, Yes, once before, or No, first occurrence.
* **Have you Reported this Before** (`previous_reports`, select_one, required): Select one of the following options: True or False.
* **Number of Persons Involved** (`persons_involved`, number, optional): If applicable, enter the number of people involved.
* **Suspect Description** (`suspect_description`, text, optional): If applicable, describe the suspect.
* **Vehicle Description** (`vehicle_description`, text, optional): If applicable, describe the vehicle.
* **Evidence Available** (`evidence_available`, select_one, required): Select one of the following options: Yes, photos, Yes, video, Yes, audio, Yes, witness statements, or No evidence.
* **Were there Witnesses** (`witnesses_present`, select_one, required): Select one of the following options: True, False, or Not sure.
* **Witness Contact Information** (`witness_contact`, text, optional): If applicable, enter the contact information for witnesses.
* **Has a Police Report been Filed** (`police_report_filed`, select_one, required): Select one of the following options: True, False, or Planning to file.
* **Police Report Number** (`police_report_number`, text, optional): If applicable, enter the police report number.
* **Is Immediate Action Needed** (`immediate_action_needed`, select_one, required): Select one of the following options: Yes, immediate response, Yes, within 24 hours, Yes, within 48 hours, or No, routine response.
* **Do you Feel Safe** (`safety_concern`, select_one, required): Select one of the following options: Yes, I feel safe, Somewhat concerned, Very concerned, or I do not feel safe.
* **Requested Action** (`requested_action`, text, required): What would you like the security team to do?
* **Preferred Contact Method** (`preferred_contact_method`, select_one, required): Select one of the following options: Phone call, Text message, Email, or In-person visit.
* **Best Time to Contact** (`best_contact_time`, select_one, required): Select one of the following options: Morning, Afternoon, Evening, or Anytime.
* **Additional Information** (`additional_information`, text, optional): If applicable, enter any additional information.
* **Resident Signature** (`resident_signature`, text, required): Digital signature of the resident.
* **For Security Use Only** (`assignment_section`, note, optional): This field is for internal security use only.
* **Assigned To** (`assigned_to`, text, optional): This field will be filled out by the security team.
* **Priority Level** (`priority_level`, select_one, optional): The assigned priority level of your request.
* **Status** (`status`, select_one, optional): The current status of your request.
* **Response Date** (`response_date`, date, optional): The date and time the security team responded to your request.
* **Actions Taken** (`actions_taken`, text, optional): Describe the actions taken by the security team.
* **Resolution Notes** (`resolution_notes`, text, optional): The final outcome of the security request.
* **Follow-up Required** (`follow_up_required`, select_one, optional): Select one of the following options: True or False.
* **Follow-up Date** (`follow_up_date`, date, optional): If applicable, enter the date for follow-up.
* **Security Supervisor** (`security_supervisor`, text, optional): The name of the security supervisor.
* **Completion Date** (`completion_date`, date, optional): The date the request was completed.

## Tips
- If you have any questions or concerns, please contact the security team for assistance.
- Please be as detailed as possible when filling out the form to ensure the security team can respond and resolve your issue promptly.
- Once you have filled out the form, submit it for processing, and the security team will review and address your request.
