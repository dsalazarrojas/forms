# Property Information Collection Form - Help Guide
## Purpose
The Property Information Collection Form is designed to collect and store property information for various purposes such as property listings, management, or other related activities. This form ensures that all relevant details about a property are captured accurately and efficiently.

## How To Complete This Form
1. Navigate through the form's pages to gather information about the property.
2. Fill out each field as prompted, ensuring all required fields are filled out.
3. If a field is marked as optional, you can choose whether to fill it out or not.
4. Ensure that you enter accurate and complete information for each field.

## Field-by-Field Explanation

### Page 1: Address
* **Address** (`address`, `text`, required): Enter the property's physical address.

### Page 2: Contact Information
* **Street Number** (`street_number`, `text`, optional): If applicable, enter the street number of the property.
* **Unit Number** (`unit_number`, `text`, optional): If applicable, enter the unit number of the property.
* **Street Name** (`street_name`, `text`, optional): Enter the name of the street where the property is located.
* **Postal Code** (`postal_code`, `text`, optional): Enter the postal code of the property.
* **Country** (`country`, `text`, optional): Enter the country where the property is located.
* **City** (`city`, `text`, optional): Enter the city where the property is located.
* **State/Province** (`state_province`, `text`, optional): Enter the state or province where the property is located.
* **Postal Code (2)** (`postal_code_2`, `text`, optional): Enter the secondary postal code of the property.
* **Phone Number** (`phone_number`, `text`, optional): Enter the phone number associated with the property.
* **Email** (`email`, `text`, optional): Enter the email address associated with the property.

### Page 3: Additional Information
* **Listing Agency** (`listing_agency`, `select_one`, optional): Select the listing agency responsible for the property listing.
* **Property Type** (`property_type`, `select_one`, optional): Select the type of property.
* **Property Status** (`property_status`, `select_multiple`, optional): Select one or more property status options.

Please note that all fields are optional unless marked as required, and each field's explanation above is based on the provided YAML fields. If any field's label seems unclear or weak, the explanation has been provided to the best effort without introducing unsupported business logic.
