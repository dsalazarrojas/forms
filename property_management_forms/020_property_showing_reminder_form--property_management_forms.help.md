# Property Showing Reminder Form - Help Guide
## Purpose
The Property Showing Reminder Form is designed to help real estate agents or property managers manage properties showings, schedule reminders, and track follow-up activities.

## How To Complete This Form
1. Navigate to the form and select the "Scheduled Showing" page.
2. Choose the properties that will be shown using the "Select Multiple" options.
3. Enter any showing details in the "Showing Details" text field.
4. Set reminder preferences, send reminders, and select reminder frequencies as needed.
5. Set the reminder time and select who to send reminders to.
6. Enter confirmation and showing confirmation details.
7. Track property status and update property notes.
8. Track showing status and enter reasons for late or no-showings.
9. Enter follow-up questions, send follow-up messages, and track follow-up status and frequency.
10. Enter property type, location, address, and track showings.

## Field-by-Field Explanation

* **Scheduled Showing** (Select Multiple, Required: False): Select the properties that will be shown.
* **Showing Details** (Text, Required: False): Enter any showing details.
* **Reminder Preferences** (Select Multiple, Required: False): Options for setting reminder frequencies.
* **Send Reminders** (Text, Required: False): Options for sending reminders.
* **Reminder Frequency** (Select One, Required: False): Options for setting reminder frequencies.
* **Reminder Time** (Time, Required: False): Set the reminder time.
* **Send Reminders To** (Select Multiple, Required: False): Select who to send reminders to.
* **Confirmation** (Text, Required: False): Enter confirmation details.
* **Showing Confirmed** (Text, Required: False): Enter showing confirmation details.
* **Send Notification** (Text, Required: False): Send notifications.
* **Property Status** (Select One, Required: False): Options for tracking property status.
* **Property Notes** (Text, Required: False): Enter property notes.
* **Showing Status** (Select One, Required: False): Options for tracking showing status.
* **Reason for Late/No-Show** (Text, Required: False): Enter reasons for late or no-showings.
* **Follow-up Question** (Text, Required: False): Enter follow-up questions.
* **Send Follow-up** (Text, Required: False): Send follow-up messages.
* **Follow-up Time** (Time, Required: False): Set follow-up times.
* **Follow-up Details** (Text, Required: False): Enter follow-up details.
* **Follow-up Status** (Select One, Required: False): Options for tracking follow-up status.
* **Follow-up Frequency** (Select One, Required: False): Options for tracking follow-up frequencies.
* **Property Type** (Text, Required: False): Enter property type.
* **Property Location** (Text, Required: False): Enter property location.
* **Property Address** (Text, Required: False): Enter property address.
* **Showings** (Select One, Required: False): Options for tracking showings.
