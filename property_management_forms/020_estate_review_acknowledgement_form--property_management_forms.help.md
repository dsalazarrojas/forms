# Estate Review Acknowledgement Form - Help Guide
## Purpose
This form is used to acknowledge and record the status of an estate review, including the user's details, review details, and confirmed status.

## How To Complete This Form

1. Fill in your user name as the person completing this form.
2. Enter your details as the person reviewing the estate.
3. Select the date of the review.
4. Record the time of the review.
5. Enter the name of the estate being reviewed.
6. Enter the address of the estate being reviewed.
7. Select the name of the contact person.
8. Select the date of confirmation.
9. Record the time of confirmation.
10. Enter the number to confirm by phone.
11. Record any additional notes from the reviewer.
12. Record any additional notes from the reviewee.
13. Record any confirmed notes.
14. Enter the email of the reviewer.
15. Enter the email of the contact person.
16. Select if the reviewer has reviewed the estate.
17. Select if the reviewer has confirmed the review.
18. Select if the reviewee has reviewed the estate.
19. Select if the reviewee has confirmed the review.
20. Select if contact has been made.
21. Select if the reviewer is available.
22. Select if the reviewee is available.

## Field-by-Field Explanation

* **User Name** (1, text, required): Enter your user name as the person completing this form.
* **Reviewer Name** (2, text, required): Enter your details as the person reviewing the estate.
* **Review Date** (3, date, required): Select the date of the review.
* **Review Time** (4, time, required): Record the time of the review.
* **Estate Name** (5, text, required): Enter the name of the estate being reviewed.
* **Estate Address** (6, text, required): Enter the address of the estate being reviewed.
* **Contact Name** (7, text, required): Enter the name of the contact person.
* **Confirmed By** (8, text, required): Enter the number to confirm by phone.
* **Confirmation Date** (9, date, required): Select the date of confirmation.
* **Confirmed At** (10, time, required): Record the time of confirmation.
* **Confirmed By Phone** (11, text, required): Enter the number to confirm by phone.
* **Reviewer Note** (12, note, required): Record any additional notes from the reviewer.
* **Reviewee Note** (13, note, required): Record any additional notes from the reviewee.
* **Confirmed Note** (14, note, required): Record any confirmed notes.
* **Reviewer Email** (15, email, required): Enter the email of the reviewer.
* **Contact Email** (16, email, required): Enter the email of the contact person.
* **Reviewed By** (17, select_one, required): Select if the reviewer has reviewed the estate.
* **Confirmed By Phone** (18, select_multiple, required): Select if the reviewer has confirmed the review.
* **Reviewee Name** (19, select_one, required): Select if the reviewee has reviewed the estate.
* **Confirmed Note** (20, select_multiple, required): Select if the reviewee has confirmed the review.
* **Contact** (21, select_multiple, required): Select if contact has been made.
* **Reviewer** (22, select_multiple, required): Select if the reviewer is available.
* **Reviewee** (23, select_multiple, required): Select if the reviewee is available.
* **Estate** (24, select_multiple, required): Select if the estate is available.
