# Estate Maintenance Request Form - Help Guide
## Purpose
The Estate Maintenance Request Form is a tool for property owners or their representatives to request maintenance, repairs, or upgrades for a property. This form helps to communicate specific needs and ensure that all required information is captured for processing.

## How To Complete This Form
To complete this form, follow these steps:

* Select "Request Details" as the form type.
* Enter the property name and address.
* Choose the issue type (e.g., Maintenance, Repairs, Upgrades).
* Provide the date the issue was reported.
* Describe the issue in detail.
* Add any contact details (name, email, and phone number).
* Choose the priority level (High, Low, Medium).
* Assign the request to a specific person (chatjimmy or Other).
* Select the current status of the request (Open, In Progress, Done).
* Add any comments about the request.
* If necessary, schedule access to the property.

## Field-by-Field Explanation

* **Request Details**: A brief description of the maintenance request.
* **Property Name**: Enter the name of the property where the maintenance request is needed.
* **Address**: Enter the address of the property where the maintenance request is needed.
* **Issue Type**: Choose the type of issue that needs to be addressed (e.g., Maintenance, Repairs, Upgrades).
* **Date Reported**: Enter the date the issue was reported.
* **Description**: Provide a detailed description of the issue.
* **Contact Details**: Enter your name, email, and phone number to contact you regarding the request.
* **Email**: Enter your email address.
* **Phone**: Enter your phone number.
* **Priority**: Choose the level of priority for the request (High, Low, Medium).
* **Assigned To**: Choose the person assigned to handle the request (chatjimmy or Other).
* **Status**: Select the current status of the request (Open, In Progress, Done).
* **Comments**: Add any additional comments about the request.
* **Schedule Access**: If necessary, schedule access to the property for the maintenance team.
* **Schedule Access**: Schedule a date and time for the maintenance team to access the property. 

Note: The "Schedule Access" field is only necessary if the maintenance team needs to access the property for the work.
