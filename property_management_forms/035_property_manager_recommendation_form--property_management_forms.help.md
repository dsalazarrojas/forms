# Property Manager Recommendation Form - Help Guide
## Purpose
The Property Manager Recommendation Form is used to recommend a property manager to a property owner, allowing them to select the desired type of property manager and provide relevant details for the recommendation.

## How To Complete This Form

1.  Select the type of property manager you wish to recommend from the list of options. This could be a Property Manager, Facility Manager, or Maintenance Worker.
2.  Enter the name of the property you are recommending the property manager for.
3.  Enter the address of the property you are recommending the property manager for.
4.  Provide a brief reason for your recommendation in the "Reason For Recommendation" field.
5.  Enter any additional notes or comments about the recommendation.
6.  Select the "Submit" button to send the form for review and consideration.

## Field-by-Field Explanation

*   **Property Manager** (`Property Manager`, `select_one`): This field allows you to select the type of property manager you wish to recommend. Choose from Property Manager, Facility Manager, or Maintenance Worker.
*   **Property Name** (`property_name`, `text`): Enter the name of the property you are recommending the property manager for. This should match the property name as it appears on our system.
*   **Property Address** (`property_address`, `text`): Enter the address of the property you are recommending the property manager for. This should match the property address as it appears on our system.
*   **Recommendation** (`recommendation`, `note`): Provide a brief reason for recommending this property manager. Explain why you think they would be a good fit.
*   **Reason For Recommendation** (`reason_for_recommendation`, `text`): Enter a detailed reason for your recommendation.
*   **Additional Notes** (`additional_notes`, `note`): Enter any additional comments or notes that you think would be helpful for the review process.
*   **Submit** (`submit`, `select_one`): Select this button to send the form for review and consideration. You can also select the "Cancel" button to discard your changes.
*   **Form ID** (`form_id`, `number`): This field is not currently used and can be ignored.
*   **Assigned Tool** (`assigned_tool`, `select_one`): Select the tool that is currently assigned to the property from the list of options.
*   **Custom Data 1-15** (`custom_data_1`, `text`): These fields can be used to enter custom data specific to your organization.
*   **Submit 2** (`submit2`, `select_one`): This field is used to confirm that you are ready to submit the form for review and consideration.
