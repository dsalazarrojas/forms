# Property Rental Extension Form - Help Guide
## Purpose
This form is used to gather information for a property rental extension request. The tenant submits a request, which is then reviewed and approved or denied by the landlord or manager.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the reason for the lease extension request from the "Lease Extension Request" dropdown menu.
2. Enter the start and end dates of the current lease in the "Lease Start Date" and "Lease End Date" fields.
3. Enter the name of the tenant and their email address in the "Tenant Name" and "Tenant Email" fields.
4. Enter the tenant's phone number in the "Tenant Phone" field.
5. Enter the length of the original lease term and the requested extension duration in the "Lease Term Length" and "Extension Duration" fields.
6. Enter the address of the property in the "Property Address" field.

## Field-by-Field Explanation
* **Lease Extension Request** (Lease Extension Request, Select One, Required/Optional): Select the reason for the lease extension request from the dropdown menu.
* **Lease Start Date** (Lease Start Date, Date, Required/Optional): Enter the start date of the original lease agreement.
* **Lease End Date** (Lease End Date, Date, Required/Optional): Enter the end date of the original lease agreement.
* **Tenant Name** (Tenant Name, Text, Required/Optional): Enter the name of the tenant requesting the lease extension.
* **Tenant Email** (Tenant Email, Email, Required/Optional): Enter the email address of the tenant requesting the lease extension.
* **Tenant Phone** (Tenant Phone, Text, Required/Optional): Enter the phone number of the tenant requesting the lease extension.
* **Lease Term Length** (Lease Term Length, Number, Required/Optional): Enter the length of the original lease term.
* **Extension Duration** (Extension Duration, Number, Required/Optional): Enter the duration of the requested lease extension.
* **Property Address** (Property Address, Text, Required/Optional): Enter the address of the property being leased.
