# Property Financing Assistance Application - Help Guide
## Purpose
This form is used to capture property financing assistance application information for a financial institution. It will be reviewed by loan officers, financial analysts, or other authorized personnel to assess a property's financing feasibility.

## How To Complete This Form
1. Select the correct **property Type** from the provided options. This helps to categorize the property for proper assessment.
2. Choose the **Property Status** to indicate whether the property is active or inactive.
3. Enter the **Loan Amount**, which is a numerical value representing the loan amount requested.
4. Select the **Collateral Type**, which might involve multiple options.
5. Choose whether the **Loan Term** is applicable or not.
6. Input the **Interest Rate**, which is a numerical value representing the interest rate percentage.
7. Provide the **Loan Date**, which should be in the proper date format (YYYY-MM-DD).
8. Indicate if a **Payment Plan** is applicable.
9. Enter the **Loan Amount 1** and **Loan Amount 2** values, which might be part of a split loan application.
10. Choose whether the **Loan Term 1** and **Loan Term 2** are applicable.
11. Select the **Collateral 1** and **Collateral 2** options, which might involve multiple selections.
12. Indicate if a **Payment Plan 1** and **Payment Plan 2** are applicable.
13. Choose the **Payment Frequency** option.
14. Select the **Payment Type** option.
15. Input the **Payment Date**, which should be in the proper date format (YYYY-MM-DD).
16. Choose the **Payment Status**, which might indicate active or inactive status.
17. Select the **Collateral** options, which might involve multiple selections.
18. Select the **Collateral Type** options, which might involve multiple selections.
19. Enter the **Contact Number**, which is the contact number for property inquiries.
20. Input the **Property Address**, which is the address of the property.
21. Add any additional **Property Notes** for further information.

* **Collateral 1** (Select-Multiple): Select multiple types of collateral 1.

* **Payment Frequency** (Select-One): Choose the payment frequency.

* **Payment Date** (Date): Enter the payment date in the proper format (YYYY-MM-DD).
* **Payment Status** (Select-One): Choose the payment status.
