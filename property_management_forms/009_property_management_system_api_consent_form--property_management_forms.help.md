# Property Management System API Consent Form - Help Guide
## Purpose
The Property Management System API Consent Form is used to collect information from users on the API connection details for the Property Management System. This form is meant to ensure that users are aware of and consent to the terms and conditions of using the API.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the form carefully and ensure that you understand the purpose and the fields included.
2. Fill out the form with the requested information.
3. Make sure to select the relevant options for the "Client Authorization", "Connection Permissions", "Security Settings", and "Phone Number" fields according to your needs.
4. Leave any other fields blank if they are not relevant.

## Field-by-Field Explanation

* **Client Authorization** (`api_connection_details_1`, select_one, false): This field asks you to specify the type of client authorization you have. Please select the option that best describes your situation.
* **Connection Permissions** (`api_connection_details_2`, select_multiple, false): This field asks you to specify the permissions you need for the API connection. Select all the options that apply to your situation.
* **Security Settings** (`api_connection_details_3`, select_one, false): This field asks you to specify the security settings for the API connection. Select the option that best describes your security needs.
* **Additional Comments** (`notes`, note, false): This field is for any additional comments or information you want to provide about the API connection.
* **Email** (`email`, email, false): This field asks for your email address.
* **Phone Number** (`api_connection_details_4`, text, false): This field asks for your phone number.
* **Connection Date** (`date`, date, false): This field asks for the date you connected to the API.
* **Connection Time** (`time`, time, false): This field asks for the time you connected to the API.

## Tips

* If you are unsure about any of the fields, refer back to this guide for clarification.
* Double-check your selections before submitting the form to ensure everything is accurate.
* If you need to make changes to your API connection, you can always update this form accordingly.
