# property_supplement_form - Help Guide
## Purpose
The property supplement form is used to gather information about a property supplement, a financial benefit provided to property owners.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the property owners by choosing "Yes" or "No" from the "property_owners" field.
2. Enter the property address in the "property_address" field.
3. Enter the property phone number in the "property_phone" field.
4. Enter the property email in the "property_email" field.
5. Select "Yes" or "No" for the benefit details in the "benefit_details" field.
6. Select "Yes" or "No" for the benefits available to the property owner in the "benefits" field.
7. Select "Yes" or "No" for the income verification method in the "income_verification_method" field.
8. Enter the income verification date in the "income_verification_date" field.
9. Select "Yes" or "No" for the income verification reference in the "income_verification_reference" field.
10. Enter the income verification amount in the "income_verification_amount" field.
11. Select "Yes" or "No" for the benefit issuer in the "benefit_issuer" field.
12. Enter the benefit name in the "benefit_name" field.
13. Select "Yes" or "No" for the benefit type in the "benefit_type" field.
14. Select "Yes" or "No" for the relationship to the primary property owner in the "relationship_to_primary" field.
15. Select "Yes" or "No" for the household members in the "household_members" field.
16. Enter the household member names in the "household_member_names" field.
17. Enter the household income in the "household_income" field.
18. Select the benefit start date in the "benefit_start_date" field.
19. Select the benefit end date in the "benefit_end_date" field.
20. Select the benefit status in the "benefit_status" field.

## Field-by-Field Explanation
* **property_owners**: Select "Yes" or "No" to indicate if the property owner is eligible for the benefit.
* **property_address**: Enter the address of the property.
* **property_phone**: Enter the phone number of the property.
* **property_email**: Enter the email of the property.
* **benefit_details**: Select "Yes" or "No" to indicate if the benefit details are available.
* **benefits**: Select "Yes" or "No" to indicate if the benefits are available to the property owner.
* **income_verification_method**: Select "Yes" or "No" to indicate if income verification is required.
* **income_verification_date**: Enter the date of the income verification.
* **income_verification_reference**: Select "Yes" or "No" to indicate if income verification reference is required.
* **income_verification_amount**: Enter the income verification amount.
* **benefit_issuer**: Select "Yes" or "No" to indicate if the benefit issuer is available.
* **benefit_name**: Enter the name of the benefit.
* **benefit_type**: Select "Yes" or "No" to indicate if the benefit type is available.
* **relationship_to_primary**: Select "Yes" or "No" to indicate the relationship to the primary property owner.
* **household_members**: Select "Yes" or "No" to indicate if the household members are eligible for the benefit.
* **household_member_names**: Enter the names of the household members.
* **household_income**: Enter the household income.
* **benefit_start_date**: Select the benefit start date.
* **benefit_end_date**: Select the benefit end date.
* **benefit_status**: Select the benefit status.

## Tips
* Please ensure that all required fields are completed accurately and truthfully.
* If you are unsure about any field, please ask for help or clarification.
* This form is used to determine the eligibility of the property owners for the property supplement benefit.
