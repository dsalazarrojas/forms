# Tenant Move Out Checklist - Help Guide
## Purpose
This form is designed to gather information about a tenant's move-out situation.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the current property status from the "Current Property Status" dropdown menu.
2. Choose the condition of the property during move-out from the "Condition Of Move Out" dropdown menu.
3. Fill in the "Move In Date" and "Move Out Date" fields with the dates of the move-in and move-out.
4. Enter the notice period in the "Notice Period" field, if applicable.
5. Enter the notice period in days in the "Notice Period (Days)" field, if applicable.
6. Fill in the "Rent" field with the total rent amount.
7. Enter the security deposit amount in the "Security Deposit" field.
8. Select the utilities that have been paid in the "Utilities Paid" dropdown menu.
9. Select the utilities that are still to be billed in the "Utilities Billed" dropdown menu.
10. Choose the lease status from the "Lease Status" dropdown menu.
11. Select the type of property from the "Property Type" dropdown menu.
12. Fill in the "Move In Date 2" and "Move Out Date 2" fields with the dates of the move-in and move-out for the second property.
13. Enter the notice period in the "Notice Period 2" field, if applicable.
14. Fill in the "Rent 2" field with the total rent amount for the second property.
15. Enter the security deposit amount for the second property in the "Security Deposit 2" field.
16. Select the utilities that have been paid for the second property in the "Utilities 2" dropdown menu.
17. Select the utilities that are still to be billed for the second property in the "Utilities Billed 2" dropdown menu.
18. Enter the total number of notice period days in the "Notice Period Days 2" field.

## Field-by-Field Explanation

* **Current Property Status** (`property_status`, select_one, required): Select the current status of the property.
* **Condition Of Move Out** (`condition_of_move_out`, select_multiple, required): Choose the condition of the property during move-out.
* **Move In Date** (`move_in_date`, date, required): Fill in the date of the move-in.
* **Move Out Date** (`move_out_date`, date, required): Fill in the date of the move-out.
* **Notice Period** (`notice_period`, text, optional): Enter the notice period, if applicable.
* **Notice Period (Days)** (`notice_period_days`, number, optional): Enter the number of notice period days, if applicable.
* **Rent** (`rent`, number, required): Fill in the total rent amount.
* **Security Deposit** (`security_deposit`, number, required): Enter the security deposit amount.
* **Utilities Paid** (`utilities_paid`, select_one, optional): Select the utilities that have been paid.
* **Utilities Billed** (`utilities_billed`, select_multiple, optional): Select the utilities that are still to be billed.
* **Lease Status** (`lease_status`, select_multiple, optional): Choose the lease status.
* **Property Type** (`property_type`, select_one, optional): Select the type of property.
* **Move In Date 2** (`move_in_date_2`, date, required): Fill in the date of the move-in for the second property.
* **Move Out Date 2** (`move_out_date_2`, date, required): Fill in the date of the move-out for the second property.
* **Notice Period 2** (`notice_period_2`, text, optional): Enter the notice period for the second property, if applicable.
* **Utilities** (`utilities`, select_one, required): Select the utilities that have been paid for the second property.
* **Utilities Billed 2** (`utilities_billed_2`, select_multiple, required): Select the utilities that are still to be billed for the second property.
* **Rent 2** (`rent_2`, number, required): Fill in the total rent amount for the second property.
* **Security Deposit 2** (`security_deposit_2`, number, required): Enter the security deposit amount for the second property.
* **Notice Period Days 2** (`notice_period_days_2`, number, required): Enter the number of notice period days for the second property.
