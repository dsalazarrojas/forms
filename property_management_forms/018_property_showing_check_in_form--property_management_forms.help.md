# Property Showing Check In Form - Help Guide
## Purpose
The Property Showing Check In Form is used to record and document property showings. This form helps property managers to keep track of appointments, verify contact information, and store notes about each showing.

## How To Complete This Form
To complete this form, simply fill out the required fields with the relevant information for each showing. You can access this form through a web interface or mobile app.

## Field-by-Field Explanation
- **Show Date** (show_date, date, required/optional): Enter the date of the showing appointment.
  This field is required to record the date of the showing.
- **Show Agent** (agent_name, text, required/optional): Enter the name of the show agent or realtor.
  This field can be left blank if no agent was present.
- **Contact Name** (contact_name, text, required/optional): Enter the name of the contact person.
  This field can be left blank if no contact person was present.
- **Contact Number** (contact_number, text, required/optional): Enter the contact person's phone number.
  This field can be left blank if no contact number was provided.
- **Visitor Name** (visitor_name, text, required/optional): Enter the name of the visitor or potential buyer.
  This field can be left blank if no visitor was present.
- **Email** (email, email, required/optional): Enter the contact person's email address.
  This field can be left blank if no email address was provided.
- **Property ID** (property_id, select_one, required/optional): Select the property ID from the options provided.
  This field is required to verify property information.
- **Note** (note, note, required/optional): Enter any relevant notes about the showing.
  This field can be left blank if there are no notes to record.

## Tips
- Make sure to fill out all required fields to ensure accurate records.
- Use the Property ID field to verify that you are recording information for the correct property.
- If there are no show agents or contacts present, leave the corresponding fields blank.
