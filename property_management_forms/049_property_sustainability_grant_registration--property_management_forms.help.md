# Property Sustainability Grant Registration - Help Guide

## Purpose
The Property Sustainability Grant Registration form is a tool for property owners and project managers to register their property's sustainability efforts. This form is used to gather information about a property's category, type, and status, as well as its owner's contact information.

## How To Complete This Form
To complete this form, follow these steps:

1.  Fill in the property's category from the drop-down menu. Select one of the options: "Green Property Upgrades", "Green Community Programs", "Green Economic Development", or "Other".
2.  Choose the type of property by selecting one of the options: "Single Family Homes", "Multi Family Residences", "Commercial", or "Other".
3.  Indicate if the property is located within a municipality or not.
4.  Indicate if the property has a funding program associated with it or not.
5.  Select the current status of the project: "Active", "Proposed", "Completed", or "Cancelled".
6.  Briefly describe the project or upgrade in the "Project Description" field.
7.  Enter the property's address.
8.  Enter the property owner's name.
9.  Enter the name of the person to contact for more information.

## Field-by-Field Explanation

*   **Property Sustainability Grant Registration** (1, Text, Required): This is the form title.
*   **Category** (2, Select One, Required): Choose the category of the property's sustainability project.
    *   Select from: Green Property Upgrades, Green Community Programs, Green Economic Development, Other
*   **Property Type** (3, Select One, Required): Choose the type of property.
    *   Select from: Single Family Homes, Multi Family Residences, Commercial, Other
*   **Municipality** (4, Select Multiple, Required): Indicate if the property is located within a municipality or not.
    *   Select from: Yes, No
*   **Funding Program** (5, Select Multiple, Required): Indicate if the property has a funding program associated with it or not.
    *   Select from: Yes, No
*   **Project Status** (6, Select One, Required): Choose the current status of the project.
    *   Select from: Active, Proposed, Completed, Cancelled
*   **Project Description** (7, Text, Required): Briefly describe the project or upgrade.
*   **Property Address** (8, Text, Required): Enter the address of the property.
*   **Property Owner** (9, Text, Required): Enter the name of the property owner.
*   **Contact Name** (10, Text, Required): Enter the name of the person to contact for more information.

## Tips
*   Please ensure that you fill out only one property per form submission.
*   Double-check your answers for accuracy to avoid processing delays or errors.
