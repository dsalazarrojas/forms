# Rental Property Maintenance Log - Help Guide
## Purpose
The Rental Property Maintenance Log form is a tool for property managers to document and track maintenance activities for rental properties. It helps to keep a record of ongoing and past maintenance tasks, ensuring that potential issues are addressed promptly.

## How To Complete This Form
To complete the form, follow these steps:

1. Select the maintenance item description in the "Item description" field.
2. Choose the status of the maintenance item from the "Status" field.
3. Set the priority level of the maintenance item from the "Priority Level" field.
4. Determine if the maintenance item has been assigned to anyone from the "Assigned to" field.
5. Enter the due date for the maintenance item in the "Due Date" field.
6. Record the date the maintenance item was created in the "Created At" field.
7. Update the date the maintenance item was last updated in the "Updated At" field.

## Field-by-Field Explanation
* **Item description** (`maintenance_item`, text, required): This field is used to briefly describe the maintenance item to be addressed.
* **Status** (`item_status`, select_one, required): This field indicates the current status of the maintenance item, which can be either "Active" or "Inactive".
* **Priority Level** (`priority_level`, select_one, required): This field indicates the level of urgency or priority for the maintenance item, which can be either "High" or "Low".
* **Assigned to** (`assigned_to`, select_one, required): This field is used to determine if the maintenance item has been assigned to anyone, which can be either "Yes" or "No".
* **Due Date** (`due_date`, date, required): This field is used to record the date the maintenance item is expected to be completed by.
* **Created At** (`created_at`, date, required): This field is used to record the date the maintenance item was created.
* **Updated At** (`updated_at`, date, required): This field is used to record the date the maintenance item was last updated.
