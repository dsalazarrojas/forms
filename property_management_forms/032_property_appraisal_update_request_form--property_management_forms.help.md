# Property Appraisal Update Request Form - Help Guide

## Purpose
This form is used to update property information, including address, type, and appraiser details.

## How To Complete This Form
To complete this form, follow these steps:
1. Review the form carefully to ensure you have all the necessary information.
2. Fill out the property details section (Page 1) with the current property information.
3. Select the correct property type from the dropdown menu.
4. Enter the appraiser's name, phone number, and email in the corresponding fields.
5. Enter the date and time of the inspection.
6. If necessary, enter a new property value.
7. Select the reason for the update from the dropdown menu.
8. Provide any additional comments.

## Field-by-Field Explanation
* **Property Details**: Please enter the current property details, including the address.
* **Property Address**: Enter the complete address of the property, including the street, city, state, and zip code.
* **Property Type**: Select the type of property from the dropdown menu.
* **Appraiser Name**: Enter the name of the appraiser who performed the inspection.
* **Appraiser Phone**: Enter the phone number of the appraiser.
* **Appraiser Email**: Enter the email of the appraiser.
* **Date of Inspection**: Enter the date of the inspection in the format MM/DD/YY.
* **Time of Inspection**: Enter the time of the inspection.
* **Property Value**: Enter the new value of the property, if necessary.
* **Reason for Update**: Select the reason for the update from the dropdown menu.
* **Market Conditions**: Select this option if the market conditions have changed.
* **Property Value**: Select this option if the property value has changed.
* **Other**: Select this option if the reason for the update is not listed above.
* **Comments**: Provide any additional comments or information about the update.
* **Additional Comments**: Enter any additional information about the update.
