# Owner Input Item Checklist - Help Guide
## Purpose
The Owner Input Item Checklist form is a tool for property managers to collect detailed information from property owners regarding various aspects of their properties.

## How To Complete This Form
To complete this form, follow these steps:

1.  Review each field carefully and provide the necessary information.
2.  Fill in the "Rental Period" field with the rental period of the property.
3.  Enter the rent price of the property in the "Rent Price" field.
4.  Select the condition of the property from the "Item Condition" dropdown menu.
5.  Type any additional notes about the property in the "Item Notes" field.
6.  Confirm if the owner is willing to sell or transfer the property in the "Owner Confirmation" field.
7.  Check the "Turnover" field to confirm if the owner will be able to turn over the property on time.
8.  Select if the owner is willing to hand over the property on time in the "Handoff" field.
9.  Input the start date of the property's rent in the "Rent Start Date" field.
10. Enter the end date of the property's rent in the "Rent End Date" field.
11. Finally, input the monetary value of the property in the "Item Value" field.

## Field-by-Field Explanation
*   **Rental Period**: This is a date field to input the rental period of the property. Please use the date format MM/DD/YY.
*   **Rent Price**: Enter the rent price of the property here.
*   **Item Condition**: Select the condition of the item from the dropdown menu: Good, Used, or New.
*   **Item Notes**: This is a text field to input any additional notes or comments about the property.
*   **Owner Confirmation**: Select 'Yes' or 'No' to confirm if the owner is willing to sell or transfer the property.
*   **Turnover**: Check 'Yes' if the owner will be able to turn over the property on time, or 'No' otherwise.
*   **Handoff**: Select 'Yes' if the owner is willing to hand over the property on time, or 'No' otherwise.
*   **Rent Start Date**: Input the start date of the property's rent here. Please use the date format MM/DD/YY.
*   **Rent End Date**: Input the end date of the property's rent here. Please use the date format MM/DD/YY.
*   **Item Value**: Enter the monetary value of the property here.
