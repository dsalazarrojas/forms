# Lease Data Transfer Request Form - Help Guide

## Purpose

Fill out this form to request a lease data transfer.

## How To Complete This Form

1.  Fill in all the required fields to ensure accurate lease data transfer request submission.
2.  Ensure that each field is accurately filled out with the correct information for the lease data transfer request.

## Field-by-Field Explanation

*   **Form Data** (`1`, `text`, required/optional: false): This field is used for any additional information regarding the lease data transfer request.
*   **Property Details** (`2`, `text`, required/optional: false): Enter the details of the property you are requesting to transfer lease data for.
*   **Tenant Info** (`3`, `text`, required/optional: false): Provide information about the tenant or occupants of the property.
*   **Lease Terms** (`4`, `text`, required/optional: false): Enter the lease terms and conditions that you wish to transfer.
*   **Rental Agreement** (`5`, `text`, required/optional: false): Include any relevant details about the rental agreement.
*   **Lease Duration** (`6`, `date`, required/optional: false): Select the start and end date of the lease.
*   **Lease Start Date** (`7`, `date`, required/optional: false): Select the start date of the lease.
*   **Lease End Date** (`8`, `date`, required/optional: false): Select the end date of the lease.
*   **Lease Signed Date** (`9`, `date`, required/optional: false): Select the date the lease was signed.
*   **Lease Terms Signed** (`10`, `text`, required/optional: false): Enter the date and terms when the lease was signed.
*   **Lease Status** (`11`, `text`, required/optional: false): Enter the current status of the lease.
*   **Lease Type** (`12`, `text`, required/optional: false): Enter the type of lease.
*   **Lease Status Change** (`13`, `text`, required/optional: false): Enter the reason for lease status change.
*   **Lease Renewal Term** (`14`, `text`, required/optional: false): Enter the renewal term of the lease.
*   **Lease Cancellation Reason** (`15`, `text`, required/optional: false): Enter the reason for lease cancellation.
*   **Lease Extension Request** (`16`, `text`, required/optional: false): Enter any lease extension request.
*   **Lease Transfer Request** (`17`, `text`, required/optional: false): Enter lease transfer request.
*   **Property Address** (`18`, `text`, required/optional: false): Enter the property address.
*   **Contact Name** (`19`, `text`, required/optional: false): Enter the name of the contact person.
*   **Contact Phone** (`20`, `text`, required/optional: false): Enter the contact phone number of the contact person.
*   **Contact Email** (`21`, `email`, required/optional: false): Enter the email address of the contact person.
*   **Property Manager** (`22`, `text`, required/optional: false): Enter the name of the property manager.
*   **Property Manager Phone** (`23`, `text`, required/optional: false): Enter the phone number of the property manager.
*   **Property Manager Email** (`24`, `email`, required/optional: false): Enter the email address of the property manager.
*   **Additional Comments** (`25`, `note`, required/optional: false): Enter any additional comments regarding the lease data transfer request.
