# Tree Audit Form - Help Guide
## Purpose
The Tree Audit Form is a systematic tool designed to gather information about tree properties, facilitating quick and efficient audits of tree health, condition, and other important metrics.

## How To Complete This Form
To complete the form, simply follow these steps:

1. Fill out each field according to the instructions below.
2. Ensure you're filling out the form for the correct tree, or group of trees, as specified in the form's purpose.
3. Take care to fill out all required fields (denoted by "Required" in the field explanation).

## Field-by-Field Explanation
- **Property** (tree_audit_form_properties, text, Required/Optional): Enter a brief description of the tree property being audited, such as "Trunk diameter" or "Leaf condition".
- **Tree Type** (tree_audit_form_tree_type, select_one, Required/Optional): Select the type of tree (e.g., Spruce, Pine, Oak).
- **Tree Age** (tree_audit_form_tree_age, number, Required/Optional): Record the age of the tree, if known.
- **Note** (tree_audit_form_note, note, Required/Optional): Add any additional notes or observations about the tree property.

## Tips
- Be sure to fill out all required fields for the specific tree or group of trees being audited.
- Use the provided options for the "Tree Type" field to select the most accurate tree type.
- The "Note" field is a good place to add any additional comments or observations that might not fit into the other fields.
