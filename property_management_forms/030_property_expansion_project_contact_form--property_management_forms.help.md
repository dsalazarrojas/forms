# Property Expansion Project Contact Form - Help Guide

## Purpose
The Property Expansion Project Contact Form is a tool for stakeholders to communicate their interest in participating in a property expansion project. This form helps the project team understand your needs and provide more accurate information about the project's progress.

## How To Complete This Form
To complete this form, please follow the instructions below:

1. Read the form carefully and ensure you understand the purpose and context.
2. Answer each question accurately and thoroughly.
3. Provide as much detail as possible for the expansion inquiry sections.

## Field-by-Field Explanation

* **Contact Form**: This is where you select the status of your contact with the project: 
	+ 'Yes' - You are already in contact with the project team.
	+ 'No' - You are not in contact with the project team.
* **Expansion Inquiry**: Please enter any expansion inquiry or questions you have about the project.
* **Project Goal**: Describe the project goals or what you are hoping to achieve through this project.
* **Location**: Provide the location where the project expansion will take place.
* **Timing**: Enter the expected start and end dates for the project expansion.
* **Project Status**: This is where you select the status of your project:
	+ Active - The project is currently active and ongoing.
	+ Inactive - The project is currently inactive and not ongoing.
* **Expansion Inquiry Goals**: Describe the expansion inquiry goals or what you are hoping to achieve through this project.
* **Expansion Inquiry Location**: Provide the location where the expansion inquiry will take place.
* **Expansion Inquiry Timing**: Enter the expected start and end dates for the expansion inquiry.
* **Expansion Inquiry Project Status**: This is where you select the status of your expansion inquiry:
	+ Active - The expansion inquiry is currently active and ongoing.
	+ Inactive - The expansion inquiry is currently inactive and not ongoing.
* **Lead Type**: This is where you select whether you are a lead or not:
	+ 'Yes' - You are a lead.
	+ 'No' - You are not a lead.
* **Lead Source**: This is where you select where you heard about the project:
	+ 'Yes' - You heard about the project through a specific channel (e.g. social media, website).
	+ 'No' - You did not hear about the project through a specific channel.

## Tips
- Please ensure you answer each question accurately and thoroughly.
- If you are unsure about any question, please feel free to contact the project team.
- If you have any additional questions or concerns, please do not hesitate to reach out to us.
