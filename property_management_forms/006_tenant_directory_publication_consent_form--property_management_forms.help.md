# Tenant Directory Publication Consent Form - Help Guide
## Purpose
This form is used to collect the tenant's consent to be listed in the Tenant Directory. It is a crucial step to ensure that only tenants who have given their consent will be included in the directory.

## How To Complete This Form

To complete this form, please follow these steps:

1. Fill in your Tenant ID to identify you as a tenant.
2. Provide your name so that we can address you correctly.
3. Provide your contact details, including email and phone number so that we can contact you.
4. Choose whether you want to be published in the Tenant Directory (yes/no).
5. If yes, you can select additional options for your publication (e.g. you can choose to be published on a specific date and time).
6. Add any additional notes if you have any specific requirements or conditions.
7. Finally, click submit to send us your form.

## Field-by-Field Explanation

* **Tenant ID** (`tenant_id`, text, required): Please enter your tenant ID to identify you as a tenant.
* **Name** (`name`, text, required): Please enter your name as it should be displayed in the Tenant Directory.
* **Contact Details** (`contact_details`, text, required): Please enter your email and phone number so that we can contact you.
* **Publication Consent** (`tenant_directory_publication_consent_form_2`, select one, required): Please choose whether you want to be published in the Tenant Directory. Choose option 1 if you want to be published and option 2 if you do not.
* **Additional Consent** (`tenant_directory_publication_consent_form_3`, select multiple, required): If you choose to be published, you can select additional options for your publication. Please choose the options that apply to you.
* **Notes** (`notes`, text, optional): Please add any additional notes if you have any specific requirements or conditions.
* **Email** (`tenant_directory_publication_consents_form_6`, email, required): Please enter your email address so that we can contact you.
* **Phone** (`tenant_directory_publication_consent_form_7`, text, required): Please enter your phone number so that we can contact you.
* **Date** (`tenant_directory_publication_consent_form_8`, date, required): Please choose the date when you want to be published.
* **Time** (`tenant_directory_publication_consent_form_9`, time, required): Please choose the time when you want to be published.

## Tips

* Please ensure that you provide accurate and up-to-date information.
* If you have any questions or need help, please don't hesitate to contact us.
