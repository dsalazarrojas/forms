# Homeowners Association Estoppel Request - Help Guide
## Purpose
The Homeowners Association Estoppel Request form is used to request an estoppel certificate from a Homeowners Association (HOA). This certificate is an official document that proves the existence or non-existence of certain restrictions or conditions on a property.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **Home Address** in the first field. This is the address where you live, and the form will be used to verify your association with the property.
2. Enter the **HOA Name**, which is the name of the Homeowners Association responsible for managing your property.
3. Enter the **HOA Phone** number, so we can contact you with any questions or updates.
4. Provide the **HOA Email** address, if available.
5. Enter the **Property ID** number, if applicable.
6. Select the **Property Type** from the options provided:
	* Condo
	* Co-op
	* Other (please specify)
7. Select who has **Signed** the estoppel request:
	* Homeowner
	* Buyer
	* Property Manager
8. Choose the **Delivery Option** for the estoppel certificate:
	* Email
	* Mail
	* Fax (if applicable)
9. If you have any additional information or requests, enter it in the **Delivery Note** field.
10. Finally, indicate if the **Estoppel Signed** is true or false, depending on your situation.

## Field-by-Field Explanation

* **Home Address**: Enter the address where you live.
* **Home Address** (2): This field is optional and can be used to enter a secondary address if applicable.
* **HOA Name**: Enter the name of the Homeowners Association responsible for managing your property.
* **HOA Phone**: Enter the contact phone number for the HOA.
* **HOA Email**: Enter the email address for the HOA, if available.
* **Property ID**: Enter the property ID number, if applicable.
* **Property Type**: Select the type of property you own:
	+ Condo
	+ Co-op
	+ Other (please specify)
* **Signed By**: Select who has signed the estoppel request:
	+ Homeowner
	+ Buyer
	+ Property Manager
* **Signed Date**: Enter the date when the estoppel request was signed.
* **Delivery Option**: Choose how you would like to receive the estoppel certificate:
	+ Email
	+ Mail
	+ Fax (if applicable)
* **Delivery Note**: Enter any additional information or requests for the delivery of the estoppel certificate.
* **Estoppel Signed**: Indicate if the estoppel request is true or false.
* **Estoppel Signed**: Confirm if the estoppel request is true or false.

Tips:
* Make sure to enter accurate and up-to-date information to ensure the estoppel request is processed correctly.
* If you are unsure about any field, please contact your HOA for clarification.
* Please note that the form is not a substitute for official documentation or communication with your HOA.
