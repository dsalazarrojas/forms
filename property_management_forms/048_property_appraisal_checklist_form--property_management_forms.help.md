# Property Appraisal Checklist Form - Help Guide
## Purpose
The Property Appraisal Checklist Form is designed to collect detailed information about a property's condition, allowing users to assess its state and identify areas that require attention.

## How To Complete This Form
To complete the form, follow these steps:

1. Review the property's address and select the correct property type from the options provided.
2. Enter the property's size in the relevant field.
3. Select the property's status from the options provided.
4. Provide any additional status notes, if applicable.
5. Evaluate the condition of various structures and grounds, selecting the best description from the options provided for each.
6. Enter any additional comments or notes about the property.

## Field-by-Field Explanation
* **property_address** (1, text, required): Enter the property's address in the format "123 Main St, Anytown, USA 12345".
* **property_type** (2, select_one, required): Select the type of property, such as "single family", "single condo", "single condo unit", "townhouse", or "apartment".
* **property_size** (3, number, required): Enter the property's size in square feet.
* **property_status** (4, select_one, required): Select the property's status, such as "vacant", "occupied", "under contract", or "hold".
* **property_status_notes** (5, text, optional): Enter any additional status notes, if applicable.
* **condition_of_structures** (6, select_multiple, optional): Select the condition of various structures, such as "excellent", "good", "fair", or "poor", from the options provided.
