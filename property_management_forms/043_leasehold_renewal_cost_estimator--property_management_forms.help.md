# Leasehold Renewal Cost Estimator - Help Guide
## Purpose
This form is used to estimate the cost of leasehold renewal, which is the process of renewing a property lease.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the property type from the options provided (Land, House, Flat/Apartment, or Other).
2. Choose the property size from the options provided (Less than 50 sqm, 50-100 sqm, 100-200 sqm, or Greater than 200 sqm).
3. Select the property condition from the options provided (Poor, Fair, Good, Very Good, or Excellent).
4. Choose the lease length from the options provided (1 Year, 2 Years, 5 Years, or 10 Years).
5. Enter the lease start date in the date format (e.g., mm/dd/yyyy).
6. Enter the lease end date in the date format (e.g., mm/dd/yyyy).
7. Provide the property address.
8. Enter the contact name.
9. Enter the contact email address.
10. Enter the contact phone number.
11. Enter the name of the property professional handling the leasehold renewal process.
12. Add any additional notes or comments about the property or lease.
13. Select whether a follow-up is required (True or False).
14. Enter the follow-up date in the date format (e.g., mm/dd/yyyy) if a follow-up is required.
15. Add any follow-up notes or comments.

## Field-by-Field Explanation

* **Property Type (2)**: Select the type of property you are estimating the leasehold renewal cost for.
* **Property Size (3)**: Choose the size of the property in square meters.
* **Property Condition (4)**: Select the current condition of the property.
* **Lease Length (5)**: Choose the length of the lease.
* **Lease Start Date (6)**: Enter the start date of the lease in the date format (e.g., mm/dd/yyyy).
* **Lease End Date (7)**: Enter the end date of the lease in the date format (e.g., mm/dd/yyyy).
* **Property Address (8)**: Enter the address of the property.
* **Contact Name (9)**: Enter the name of the contact person.
* **Contact Email (10)**: Enter the email address of the contact person.
* **Contact Phone (11)**: Enter the phone number of the contact person.
* **Property Professional Name (12)**: Enter the name of the property professional handling the leasehold renewal process.
* **Notes (13)**: Add any additional notes or comments about the property or lease.
* **Follow Up Required (14)**: Select whether a follow-up is required to discuss the estimate.
* **Follow Up Date (15)**: Enter the date for the follow-up in the date format (e.g., mm/dd/yyyy) if a follow-up is required.
* **Follow Up Notes (16)**: Add any follow-up notes or comments.
* **Renewal Cost (17)**: Enter the estimated cost of leasehold renewal.

Note: The more information you provide, the more accurate the estimate will be. If you are unsure about any of the fields, please contact the property professional handling the leasehold renewal process for guidance.
