# Property Unit Setup Form - Help Guide
## Purpose
The Property Unit Setup Form is used to collect and manage property unit information in the property management system.

## How To Complete This Form
1. Select the relevant property unit info page and enter the required information in the corresponding fields.
2. Fill out the onboarding info page with any relevant details about the property unit.
3. Enter the portfolio info page with information about the property unit's investment or ownership status.
4. Provide property manager info, including name, email, and phone number.
5. Enter the property address and location.
6. Select the property type, size, and status.
7. Enter the property price and date available.
8. Enter the date the property was leased.
9. Review and submit the form to save changes.

## Field-by-Field Explanation
* **Property Unit Info**: This field is used to enter general information about the property unit, such as its name or ID.
* **Onboarding Info**: Enter any details about the onboarding process, such as the property unit's status or condition.
* **Portfolio Info**: This field is used to enter information about the property unit's investment or ownership status.
* **Property Manager Info**: Enter the name, email, and phone number of the property manager or administrator.
* **Property Address**: Enter the address of the property unit.
* **Property Location**: Enter the location of the property unit.
* **Property Manager Name**: Enter the name of the property manager or administrator.
* **Property Manager Email**: Enter the email of the property manager or administrator.
* **Property Manager Phone**: Enter the phone number of the property manager or administrator.
* **Property Type**: Select the type of property unit (e.g. "Yes" or "No").
* **Property Size**: Select the size of the property unit (e.g. "Yes" or "No").
* **Property Status**: Select the status of the property unit (e.g. "Active" or "Inactive").
* **Property Price**: Enter the price of the property unit.
* **Date Available**: Enter the date the property unit is available.
* **Date Leased**: Enter the date the property unit was leased.
