# Property Performance Analytics Registration Form - Help Guide
## Purpose

The Property Performance Analytics Registration Form is a critical input for the property performance analytics system. It is used to track and analyze the performance of properties, ensuring that data is accurate and reliable.

## How To Complete This Form

1.  Review the form instructions and fields to ensure you understand each section.
2.  Enter the required fields, including "Property Performance Analytics Data", "Property Performance Analytics Start Date", and "Property Performance Analytics Type".
3.  Optionally, enter additional details such as "Property Performance Analytics Email" and "Property Performance Analytics Phone".
4.  Fill in the "Property Performance Analytics Notes" field with relevant comments or observations.
5.  Review your answers before submitting the form to ensure accuracy and completeness.

*   **Property Performance Analytics Data** (`property_performance_analytics_data`):

    *   Type: Select multiple options

*   **Property Performance Analytics Phone** (`property_performance_analytics_phone`):
