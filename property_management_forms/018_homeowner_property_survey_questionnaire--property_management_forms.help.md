# Homeowner Property Survey Questionnaire - Help Guide
## Purpose

The Homeowner Property Survey Questionnaire is a collection of questions designed to gather information from homeowners about their properties. This form is intended to provide a comprehensive snapshot of property details, status, and other relevant data. Completing this form will help us better understand homeowners' needs and preferences, which will aid in improving our services.

## How To Complete This Form

1. Please answer each question to the best of your ability. If you're unsure about a question or have additional information to provide, you can use the "Notes" fields.
2. Select the correct options for each question using the provided dropdown menus.
3. Make sure to fill out all required fields, as indicated by the "required" label.
4. If you need to add extra information, use the "Notes" fields provided.

## Field-by-Field Explanation

* **property_details** (text): This field is for any additional information about your property. Please provide a brief description of your property, including its features, amenities, and any unique aspects.
* **property_status** (select_one):
	+ Option 1: Select this if you're currently renting your property.
	+ Option 2: Select this if you're currently selling your property.
	+ Option 3: Select this if you're currently owning your property.
* **property_type** (select_one):
	+ Option 1: Select this if your property is a single-family home.
	+ Option 2: Select this if your property is a condo or apartment.
	+ Option 3: Select this if your property is a commercial building.
* **property_address** (text): Enter the address of your property. This is a required field.
* **property_manager_name** (text): This field is for the name of the property manager or maintenance contact.
* **property_manager_phone** (text): This field is for the phone number of the property manager or maintenance contact.
* **property_details_1**, **property_details_2**, **property_details_3**, **property_details_4** (notes): These fields are for additional information about your property. Please use them to provide any relevant details or comments that didn't fit in the other fields.

## Tips

* Make sure to fill out all required fields and provide accurate information about your property.
* Use the "Notes" fields to add any extra details or comments about your property.
* If you're unsure about a question or have additional information, don't hesitate to ask for clarification.
