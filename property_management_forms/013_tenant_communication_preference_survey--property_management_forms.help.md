# tenant_communication_preference_survey - Help Guide
## Purpose
The tenant communication preference survey is a form used to gather information from tenants about their preferred contact methods, language, and timing.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the survey details page for any additional information or instructions.
2. On the "Contact Methods" page, select one or more of the following options:
	* Email
	* Phone
	* Message
3. On the "Preferred Language" page, select your preferred language:
	* English
	* Spanish
	* French
4. If you have a preferred email address, enter it in the "Email" field.
5. If you have a phone number, enter it in the "Phone" field.
6. If you have a message or comment, enter it in the "Message" field.
7. On the "Preferred Timing" page, select your preferred time for communication.

## Field-by-Field Explanation

* **Survey Details**: This page provides additional information about the survey, if any.
* **Contact Methods**: Select one or more contact methods that you prefer:
	+ Email: Select this option if you prefer to communicate via email.
	+ Phone: Select this option if you prefer to communicate via phone.
	+ Message: Select this option if you prefer to communicate via message.
* **Preferred Language**: Select your preferred language:
	+ English: Select this option if you prefer to communicate in English.
	+ Spanish: Select this option if you prefer to communicate in Spanish.
	+ French: Select this option if you prefer to communicate in French.
* **Email**: Enter your preferred email address.
* **Phone**: Enter your phone number.
* **Message**: Enter any additional comments or messages you have.
* **Preferred Timing**: Select your preferred time for communication.

## Tips

* Ensure you have selected the correct contact methods and preferred language for effective communication.
* Enter a valid email address and phone number if applicable.
* If you have a preferred language, select it for accurate communication.
* Review your answers before submitting the form to ensure they are accurate.
