# property_inquiry_form - Help Guide
## Purpose
This form is used to gather information about a property inquiry. It is designed to assist in understanding the details of the inquiry, including property type, address, status, contact information, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:
1. On the first page, type a brief description of the property inquiry.
2. On the second page, select whether the property type is "Yes" or "No".
3. On the third page, enter the address of the property.
4. On the fourth page, select the current status of the property from "Active" or "Inactive".
5. On the fifth page, enter the name of the contact person.
6. On the sixth page, enter the email of the contact person.
7. On the seventh page, enter the phone number of the contact person.
8. On the eighth page, enter any additional contact note.
9. On the ninth page, select which property features are applicable (e.g., "Yes" or "No").
10. On the tenth page, enter the number of property inquiries.
11. On the eleventh page, select whether the property is available for viewing ("Yes" or "No").

## Field-by-Field Explanation
* **Property Inquiry**: A brief description of the property inquiry.
* **Property Type**: Select "Yes" if you are inquiring about a specific property type, otherwise select "No".
* **Property Address**: Enter the address of the property.
* **Property Status**: Select "Active" if the property is currently available, otherwise select "Inactive".
* **Contact Name**: Enter the name of the contact person.
* **Contact Email**: Enter the email of the contact person.
* **Contact Phone**: Enter the phone number of the contact person.
* **Contact Note**: Enter any additional information about the contact.
* **Property Features**: Select which property features apply (e.g., "Yes" or "No").
* **Property Inquiries**: Enter the total number of property inquiries.
* **Property Viewing**: Select "Yes" if the property is available for viewing, otherwise select "No".
