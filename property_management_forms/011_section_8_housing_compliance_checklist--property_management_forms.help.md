# Section 8 Housing Compliance Checklist - Help Guide
## Purpose
This form is used to record the results of a rental unit inspection, ensuring compliance with Section 8 housing regulations.

## How To Complete This Form
1. Choose the correct program name (Option 1, Option 2, or Option 3) from the drop-down list for the Section 8 Program Name.
2. Enter the Building Name of the inspected rental unit.
3. Enter the Unit Number of the inspected rental unit.
4. Select the Inspection Date using the date input field.
5. Enter the name of the Inspector performing the inspection.
6. Enter the name of the Landlord.
7. Identify any Violations by selecting all applicable options.
8. Describe any corrective Actions Taken to address the identified violations.
9. Optionally, add any additional Comments related to the inspection.
10. Select the status of the form as completed or not.
11. Enter the Date the form was completed.
12. Enter the Time the form was completed.
13. Select the name of the user assigned to the form from the drop-down list.
14. Sign the form with your official signature.
15. Enter your Inspector ID.
16. Sign the form with the Landlord's official signature.
17. Enter the Landlord's ID.
18. Sign the form with the Building Manager's official signature.
19. Enter the Building Manager's ID.
20. Sign the form with the Property Manager's official signature.
21. Enter the Property Manager's ID.
22. Sign the form with the Other Party's official signature.
23. Enter the Other Party's ID.
24. Choose the assigned user for the form from the drop-down list.

## Field-by-Field Explanation
* **Rental Unit Inspection Results**: Enter the results of the inspection in this field, taking into account the conditions of the rental unit. (Page 1)
* **Section 8 Program Name**: Select the name of the Section 8 program the unit belongs to. This will help ensure accuracy in reporting. (Page 2)
* **Building Name**: Enter the name of the building or complex where the inspected unit is located. This will help identify the property. (Page 2)
* **Unit Number**: Enter the specific unit number of the inspected unit. This will help identify the unit's location within the building. (Page 3)
* **Inspection Date**: Enter the date of the inspection, using the calendar input field. This is crucial for tracking compliance timeline. (Page 4)
* **Inspector Name**: Enter your name as the inspector performing the inspection. This is a requirement for official record keeping. (Page 5)
* **Landlord Name**: Enter the name of the landlord or property manager of the inspected unit. This is a requirement for official record keeping. (Page 5)
* **Violations Identified**: Identify any violations observed during the inspection by selecting the applicable options. This is a critical field for tracking compliance issues. (Page 6)
* **Corrective Actions Taken**: Describe any corrective actions taken to address the identified violations. This field is essential for demonstrating compliance efforts. (Page 7)
* **Comments**: Optionally, add any additional comments related to the inspection. This can provide context for future reference. (Page 8)
* **Section 8 Housing Compliance Checklist Form Completed**: Select this option to confirm that the form is complete and accurate. (Page 9)
* **Date Completed**: Enter the date the form was completed. This is a requirement for tracking completion time. (Page 10)
* **Time Completed**: Enter the time the form was completed. This is a requirement for tracking completion time. (Page 11)
* **Section 8 Housing Compliance Checklist Form Signed By**: Sign the form with your official signature. This is a requirement for official record keeping. (Page 12)
* **Inspector Signature**: Sign the form with your official signature as the inspector. This is a requirement for official record keeping. (Page 13)
* **Inspector ID**: Enter your inspector ID, if applicable. This is a requirement for official record keeping. (Page 14)
* **Landlord Signature**: Sign the form with the landlord's official signature. This is a requirement for official record keeping. (Page 15)
* **Landlord ID**: Enter the landlord's ID, if applicable. This is a requirement for official record keeping. (Page 16)
* **Building Manager Signature**: Sign the form with the building manager's official signature. This is a requirement for official record keeping. (Page 17)
* **Building Manager ID**: Enter the building manager's ID, if applicable. This is a requirement for official record keeping. (Page 18)
* **Property Manager Signature**: Sign the form with the property manager's official signature. This is a requirement for official record keeping. (Page 19)
* **Property Manager ID**: Enter the property manager's ID, if applicable. This is a requirement for official record keeping. (Page 20)
* **Other Party Signature**: Sign the form with the other party's official signature. This is a requirement for official record keeping. (Page 21)
* **Other Party ID**: Enter the other party's ID, if applicable. This is a requirement for official record keeping. (Page 22)
* **Assigned User**: Choose the assigned user for the form from the drop-down list. This is a requirement for official record keeping. (Page 23)

Note: The fields marked as required are essential for official record keeping and must be completed accurately.
