# Home Matching Request Form - Help Guide
## Purpose
This form is designed to collect specific information from users regarding their home matching preferences. The collected information will be used to match homes according to the provided criteria.

## How To Complete This Form
1. Please provide accurate and honest information regarding your preferences.
2. Ensure that all required fields are filled out completely.
3. Double-check your submission to prevent errors.
4. If you have any questions or concerns, please contact the property management team.

## Field-by-Field Explanation
* **User Input** (`user_input`, text, required): This field is intended for users to provide any additional information they feel is necessary to help with the home matching process.
* **Owner's Preferences** (`owner_preferences`, select_multiple, optional): This field allows users to select multiple options regarding their preferences. Please select all options that apply.
* **Contact Method** (`contact_method`, select_one, optional): This field is intended to determine the method by which you would like to be contacted.
* **Date of Birth** (`date_of_birth`, date, optional): This field is to collect the user's date of birth for the home matching purposes.
* **Time of Day** (`time_of_day`, time, optional): This field is intended to collect the user's time of day for the home matching purposes.
* **Note** (`note`, note, optional): This field is for users to add any additional notes regarding their preferences.
* **Email** (`email`, email, optional): This field is to collect the user's email address.
* **Phone** (`phone`, text, optional): This field is for users to provide their phone number.
* **User Comments** (`user_comments`, text, required): This field is intended for users to provide any additional comments regarding their preferences.
* **User Agent** (`user_agent`, text, required): This field is for users to provide the name of the user agent.
* **Property Manager** (`property_manager`, text, required): This field is intended to collect the name of the property manager.
* **Relocation Team** (`relocation_team`, text, optional): This field is for users to provide the name of the relocation team.
* **User Input 2** (`user_input_2`, text, optional): This field is for users to provide any additional information.
* **User Input 3** (`user_input_3`, text, optional): This field is for users to provide any additional information. 

## Tips
- Please ensure that all required fields are filled out completely.
- Use the correct format for date and time fields (mm/dd/yy and 12:00 PM/AM).
- Use a valid email address and phone number format. 
- Provide honest and accurate information to ensure the best possible home match.
- If you have any questions or concerns, please contact the property management team.
