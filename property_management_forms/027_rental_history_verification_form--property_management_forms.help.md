# rental_history_verification_form - Help Guide
## Purpose
This form is used to verify the rental history of a property. It is used by property managers to gather information about a rental property's past and current status.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the rental history by choosing "Yes" or "No" from the dropdown menu.
2. Enter the name of the property manager.
3. Enter the name of the tenant who rented the property.
4. Enter the address of the rental property.
5. Select the start date of the rental period.
6. Select the end date of the rental period.
7. Enter the name of the property owner.

## Field-by-Field Explanation
* **rental_history** (`select_multiple`): Select "Yes" if the rental history is verified, "No" otherwise.
* **property_manager** (`text`): Enter the name of the property manager.
* **tenant_name** (`text`): Enter the name of the tenant who rented the property.
* **property_address** (`text`): Enter the address of the rental property.
* **start_date** (`date`): Select the start date of the rental period.
* **end_date** (`date`): Select the end date of the rental period.
* **property_owner** (`text`): Enter the name of the property owner.

## Tips
* Make sure to select the correct rental history status to ensure accurate information is recorded.
* Double-check the property address for accuracy.
* Enter the start and end dates correctly to ensure the rental period is recorded accurately.
