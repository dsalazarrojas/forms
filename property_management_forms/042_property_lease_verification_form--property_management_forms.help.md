# Property Leverage Verification Form - Help Guide
## Purpose
This form is used to collect and verify information about a property tenant or occupant. The form collects data on tenant identification, lease terms, and other relevant details.

## How To Complete This Form
1. Select the "Tenant Information" section at the top of the form.
2. Enter the "Unit Number" of the property.
3. Provide the "Street Address" of the property.
4. Select the "Minimalist Properties" options that apply to the tenant's property.
5. Enter the "Lease Start Date" and "Lease End Date" for the lease agreement.
6. Enter the "Rent" for the property.
7. Choose the "Rent Frequency" for the rent payments.
8. Enter the "Rent Amount" for the property.
9. Select the "Property Status" of the property.
10. Choose the "Lease Term" for the lease agreement.
11. Enter the "Photo ID" number for the tenant.
12. Enter the "ID Number" for the tenant.
13. Enter the "Passport Number" for the tenant (if applicable).
14. Enter the "Driver License Number" for the tenant (if applicable).
15. Enter the "Birthdate" of the tenant (if applicable).

## Field-by-Field Explanation

* **Tenant Information (1)**: Select this section to begin filling out the form.
	+ Type: Text
	+ Required: Required
* **Unit Number (2)**: Enter the number of the property unit.
	+ Type: Number
	+ Required: False
* **Street Address (3)**: Enter the street address of the property.
	+ Type: Text
	+ Required: False
* **Minimalist Properties (4)**: Select the properties that apply to this property. Options: 1, 2, 3.
	+ Type: Select Multiple
	+ Required: False
* **Lease Start Date (5)**: Enter the start date of the lease agreement.
	+ Type: Date
	+ Required: False
* **Lease End Date (6)**: Enter the end date of the lease agreement.
	+ Type: Date
	+ Required: False
* **Rent (7)**: Enter the monthly rent amount for the property.
	+ Type: Number
	+ Required: False
* **Rent Frequency (8)**: Choose how often the rent is paid. Options: 1, 2, 3.
	+ Type: Select One
	+ Required: False
* **Rent Amount (9)**: Enter the total rent amount for the property.
	+ Type: Number
	+ Required: False
* **Property Status (10)**: Select the status of the property. Options: Active, Inactive, Pending.
	+ Type: Select One
	+ Required: False
* **Lease Term (11)**: Choose the lease term. Options: 6, 12, 24.
	+ Type: Select Multiple
	+ Required: False
* **Photo ID (12)**: Enter the ID number for the tenant's photo.
	+ Type: Text
	+ Required: False
* **ID Number (13)**: Enter the ID number for the tenant.
	+ Type: Text
	+ Required: False
* **Passport Number (14)**: Enter the passport number for the tenant (if applicable).
	+ Type: Text
	+ Required: False
* **Driver License Number (15)**: Enter the driver's license number for the tenant (if applicable).
	+ Type: Text
	+ Required: False
* **Birthdate (16)**: Enter the birthdate of the tenant (if applicable).
	+ Type: Date
	+ Required: False
