# Commercial Property Conversion Application Form - Help Guide
## Purpose
This form is used to submit a request to convert a commercial property for a new or different use. Please fill out this form with accurate and up-to-date information about the property and the proposed conversion.

## How To Complete This Form
1. Fill out the required fields with your information.
2. Ensure that you have attached all required documents and supporting information.
3. Review your application carefully before submitting to ensure that it is accurate and complete.

## Field-by-Field Explanation
* **Primary Applicant Name** (`applicant_name`, text, required): Please enter the name of the primary applicant who will be responsible for the conversion project.
* **Business Name (if applicable)** (`business_name`, text, optional): If the property is owned by a business, please enter the business name.
* **Contact Email** (`applicant_contact_email`, email, required): Enter the email address of the primary applicant or contact person.
* **Contact Phone** (`applicant_contact_phone`, text, required): Enter the phone number of the primary applicant or contact person.
* **Property Address for Conversion** (`property_address_to_convert`, text, required): Enter the address of the property to be converted.
* **Current Zoning Classification** (`current_zoning_classification`, text, required): Enter the current zoning classification of the property.
* **Current Primary Use of Property** (`current_primary_use`, text, required): Enter the current primary use of the property (e.g., Warehouse, Retail, Office).
* **Proposed New Primary Use** (`proposed_new_use`, text, required): Enter the proposed new primary use of the property (e.g., Mixed-Use, Residential Lofts, Hospitality).
* **Total Square Footage to be Converted** (`square_footage_impacted`, number, required): Enter the total square footage of the property to be converted.
* **Will structural changes be required?** (`structural_changes_required`, select_one, required): Select one of the following options:
	+ Yes - Minor
	+ Yes - Major Structural
	+ No - Interior Finish Only
* **Estimated Conversion Project Cost** (`estimated_project_cost`, number, optional): Enter the estimated project cost.
* **Projected Construction Start Date** (`projected_start_date`, date, required): Enter the projected start date of the construction project.
* **Estimated Project Completion Date** (`estimated_completion_date`, date, required): Enter the estimated completion date of the construction project.
* **I certify that the information provided is accurate and I am authorized to submit this request** (`applicant_declaration`, select_one, required): Select I Certify.
