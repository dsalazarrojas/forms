# property_tour_request_form - Help Guide
## Purpose
This form is used to request a property tour with a property owner/agent. It helps gather information about the property and the client's preferences and interests in order to schedule a suitable tour experience.

## How To Complete This Form

1. Fill out the search form with the property's name or address to find the property you're interested in.
2. Select the type of property you're interested in touring (e.g. property type, rental, resale).
3. Choose how you want to be contacted (e.g. phone, email, in person).
4. Provide your contact details (e.g. name, email, phone).
5. Select the type of tour you're interested in (e.g. open house, private).
6. Choose a preferred time for the tour (e.g. now, today, tomorrow).
7. Check if you want to be followed up with after the tour.
8. Choose the method for follow up (e.g. phone, email).
9. Provide any additional details about the tour.
10. Confirm the property's status (e.g. active, inactive).
11. (Optional) Enter the property ID, agent's name, tour date and time, and location.

## Field-by-Field Explanation

* **Search Form** (`search_form`, text, required): Enter the property's name or address to find the property you're interested in.
* **Property Type** (`property_type`, select_one, required): Select the type of property you're interested in (e.g. property, rental, resale).
* **Contact Method** (`contact_method`, select_one, required): Choose how you want to be contacted (e.g. phone, email, in person).
* **Client Details** (`client_details`, select_multiple, required): Enter your first name, last name, email, phone, and address.
* **Tour Type** (`tour_type`, select_one, required): Select the type of tour you're interested in (e.g. open house, open house and private, private).
* **Preferred Time** (`preferred_time`, select_one, required): Choose a preferred time for the tour (e.g. now, today, tomorrow).
* **Follow Up** (`follow_up`, text, optional): Check if you want to be followed up with after the tour.
* **Follow Up Method** (`follow_up_method`, select_one, required): Choose the method for follow up (e.g. phone, email).
* **Follow Up Details** (`follow_up_details`, text, optional): Provide any additional details about the tour.
* **Property Status** (`property_status`, select_one, required): Confirm the property's status (e.g. active, inactive).
* **Property ID** (`property_id`, text, optional): Enter the property ID (if known).
* **Agent** (`agent`, text, optional): Enter the agent's name.
* **Date** (`date`, date, optional): Enter the tour date.
* **Time** (`time`, time, optional): Enter the tour time.
* **Comments** (`comments`, text, optional): Provide any additional comments about the tour.
* **Email** (`email`, email, optional): Enter your email address.
* **Phone** (`phone`, text, optional): Enter your phone number.
* **Address** (`address`, text, optional): Enter the property's address.
* **Zip** (`zip`, text, optional): Enter the property's zip code.
* **City** (`city`, text, optional): Enter the property's city.
* **State** (`state`, text, optional): Enter the property's state.
* **Agent Details** (`agent_details`, text, optional): Enter the agent's details.
* **Client Agent Details** (`client_agent_details`, text, optional): Enter the client's agent details.

## Tips
* Make sure to fill out the form accurately and completely to ensure that the property owner/agent has all the necessary information to schedule a suitable tour experience.
* If you're unsure about any field, feel free to ask the property owner/agent for clarification.
* If you're filling out this form for a client, make sure to provide your contact information so that they can be reached for the tour.
