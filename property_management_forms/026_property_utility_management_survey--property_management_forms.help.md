# property_utility_management_survey - Help Guide
## Purpose
This form is designed to collect information about a property's utility management needs to help property managers or administrators understand the property's usage and billing requirements.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of property you are surveying (Building Type).
2. Choose the types of utilities available at the property (Types of Utilities).
3. Indicate how often the property's utilities are used (Usage Frequency).
4. Specify the amount of each utility used (Usage Amount).
5. Determine the frequency of billing for each utility (Billing Cycle).
6. Specify the amount of each bill (Billing Amount).
7. Choose the methods of payment used for each utility (Payment Methods).

## Field-by-Field Explanation
* **Building Type** (Building Type, Select One, Required): This field is used to determine the type of property (e.g., residential, commercial, etc.).
* **Types of Utilities** (Types of Utilities, Select Multiple, Required): This field is used to select multiple types of utilities available at the property (e.g., water, electricity, gas, etc.).
* **How Often** (Usage Frequency, Select Multiple, Required): This field is used to determine how often the property's utilities are used (e.g., daily, weekly, monthly, etc.).
* **Usage Amount** (Usage Amount, Number, Required): This field is used to specify the amount of each utility used.
* **Usage Frequency** (Usage Frequency, Select One, Required): This field is used to determine the frequency of usage for each utility.
* **Usage Units** (Usage Units, Select One, Required): This field is used to specify the unit of measurement for each utility usage (e.g., m3, m2, kWh, etc.).
* **Billing Cycle** (Billing Cycle, Number, Required): This field is used to determine the frequency of billing for each utility.
* **Billing Frequency** (Billing Frequency, Select One, Required): This field is used to determine when the billing for each utility takes place.
* **Billing Amount** (Billing Amount, Number, Required): This field is used to specify the amount of each bill.
* **Payment Methods** (Payment Methods, Select Multiple, Required): This field is used to choose the methods of payment used for each utility (e.g., online, offline, bank transfer, etc.).
