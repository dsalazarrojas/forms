# Property Lease Renewal Form - Help Guide
## Purpose
The Property Lease Renewal Form is a form used to collect and update information for existing property leases. This form helps property managers to keep accurate and up-to-date records of lease details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the lease start date, which is the start date of the original lease.
2. Enter the lease end date, which is the end date of the original lease.
3. Enter the tenant's name and email address.
4. Enter the address of the property being leased.
5. Select the type of property (residential or commercial).
6. Enter the current rent amount of the property.
7. Review and submit the form for review and approval.

## Field-by-Field Explanation

* **Lease Start Date (1)** (`lease_start_date`, date, required): Enter the start date of the original lease. This date is used to determine the lease term and renewal eligibility.
* **Lease End Date (2)** (`lease_end_date`, date, required): Enter the end date of the original lease. This date is used to determine the lease term and renewal eligibility.
* **Tenant Name (3)** (`tenant_name`, text, required): Enter the name of the tenant who is renewing the lease.
* **Tenant Email (4)** (`tenant_email`, email, required): Enter the email address of the tenant who is renewing the lease. This is used for communication and notification purposes.
* **Property Address (5)** (`property_address`, text, required): Enter the address of the property being leased.
* **Property Type (6)** (`property_type`, select_one, required): Select the type of property (residential or commercial).
* **Property Rent (7)** (`property_rent`, number, required): Enter the current rent amount of the property.

## Tips
* Make sure to enter accurate and up-to-date information to ensure correct lease renewal processing.
* If you are unsure about any field, please contact the property management team for assistance.
* This form should only be used for existing leases, not for new lease requests.
