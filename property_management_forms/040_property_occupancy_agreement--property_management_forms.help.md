# Property Occupancy Agreement - Help Guide
## Purpose
This form is designed to document the terms and conditions of a property rental agreement between a landlord and a tenant.

## How To Complete This Form
1. Ensure that all required fields are filled out completely and accurately.
2. Enter the Landlord Name, Property Address, and Rent Start Date for the rental property.
3. Determine the Rent Frequency (e.g., monthly, weekly, bi-monthly) and enter the corresponding value from the options provided.
4. Enter the Lease Start and End Dates, if applicable.
5. Specify whether Utility Bills are Included or Excluded for the tenant.
6. Enter any parking details and parking fees, if applicable.
7. Enter any utility costs and other charges that apply to the rental property.
8. Add any additional comments or notes about the rental agreement.

## Field-by-Field Explanation
* **Landlord Details (1)** (`Landlord Details`, `text`, required/optional): Enter a brief description of the landlord's details, if applicable.
* **Landlord Name (2)** (`Landlord Name`, `text`, required/optional): Enter the name of the landlord.
* **Property Address (3)** (`Property Address`, `text`, required/optional): Enter the address of the rental property.
* **Rent Start Date (4)** (`Rent Start Date`, `date`, required/optional): Enter the date when the rent starts.
* **Move In Date (5)** (`Move In Date`, `date`, required/optional): Enter the date when the tenant is expected to move in.
* **Move Out Date (6)** (`Move Out Date`, `date`, required/optional): Enter the date when the tenant is expected to move out.
* **Tenant Details (7)** (`Tenant Details`, `text`, required/optional): Enter a brief description of the tenant's details, if applicable.
* **Tenant Name (8)** (`Tenant Name`, `text`, required/optional): Enter the name of the tenant.
* **Tenant Address (9)** (`Tenant Address`, `text`, required/optional): Enter the address of the tenant.
* **Rent Amount (10)** (`Rent Amount`, `number`, required/optional): Enter the rent amount.
* **Rent Frequency (11)** (`Rent Frequency`, `select_one`, required): Select how frequently the rent is paid: Monthly, Weekly, or Bi-Monthly.
* **Lease Start Date (12)** (`Lease Start Date`, `date`, required/optional): Enter the date when the lease starts, if applicable.
* **Lease End Date (13)** (`Lease End Date`, `date`, required/optional): Enter the date when the lease ends, if applicable.
* **Notice Period (14)** (`Notice Period`, `number`, required/optional): Enter the number of days or weeks for the notice period.
* **Deposit Amount (15)** (`Deposit Amount`, `number`, required/optional): Enter the deposit amount.
* **Security Deposit (16)** (`Security Deposit`, `number`, required/optional): Enter the security deposit amount.
* **Late Fee (17)** (`Late Fee`, `number`, required/optional): Enter the late fee amount.
* **Utility Bills (18)** (`Utility Bills`, `select_one`, required): Select whether Utility Bills are Included or Excluded.
* **Parking Details (19)** (`Parking Details`, `text`, required/optional): Enter a brief description of the parking details, if applicable.
* **Parking Fees (20)** (`Parking Fees`, `number`, required/optional): Enter any parking fees.
* **Utilities (21)** (`Utilities`, `text`, required/optional): Enter a brief description of the utilities included or excluded in the rental agreement.
* **Utilities Cost (22)** (`Utilities Cost`, `number`, required/optional): Enter the cost of the utilities.
* **Other Charges (23)** (`Other Charges`, `text`, required/optional): Enter a brief description of any other charges, if applicable.
* **Other Charges Cost (24)** (`Other Charges Cost`, `number`, required/optional): Enter the cost of other charges.
* **Additional Comments (25)** (`Additional Comments`, `note`, required/optional): Add any additional comments or notes about the rental agreement.
