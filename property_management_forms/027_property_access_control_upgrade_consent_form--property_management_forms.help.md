# property_access_control_upgrade_consent_form - Help Guide
## Purpose
The property_access_control_upgrade_consent_form is used to gather consent from property owners and residents for security system upgrades.

## How To Complete This Form
To complete this form, follow the instructions below:

1. Read the form carefully and understand the purpose of each field.
2. Answer each field accurately and truthfully.
3. If you are unsure about any field, contact your supervisor for guidance.

## Field-by-Field Explanation
• **Form Title** (`form_title`, text, optional): Please enter a brief title for the form, if desired.
• **Security System Upgrade** (`security_system_upgrade`, select_one, optional): Choose "Yes" if you are requesting an upgrade to the security system, or "No" if you are not.
• **Why do you want to upgrade your security system?** (`security_system_upgrade_reason`, text, required): Enter a brief explanation for the upgrade request.
• **Do you have the owner's approval?** (`owner_approval`, select_multiple, optional): Choose "Yes" if you have the owner's approval, or "No" if you do not. If "No", enter a brief description of your approval process.
• **Owner Approval (if other, please describe)** (`owner_approval_other`, text, optional): If you have not received the owner's approval, please enter a description of your approval process.
• **Have you received resident approval?** (`resident_approval`, select_multiple, optional): Choose "Yes" if you have received resident approval, or "No" if you have not. If "No", enter a description of your approval process.
• **Resident Approval (if other, please describe)** (`resident_approval_other`, text, optional): If you have not received resident approval, please enter a description of your approval process.
• **Has your manager approved the upgrade?** (`manager_approval`, select_multiple, optional): Choose "Yes" if your manager has approved the upgrade, or "No" if they have not. If "No", enter a brief description of your approval process.
• **Manager Approval (if other, please describe)** (`manager_approval_other`, text, optional): If your manager has not approved the upgrade, please enter a description of your approval process.
• **Resident/Owner Signature** (`signature`, date, required): Please enter the resident/owner signature date.

This form must be completed accurately and submitted for review. If you have any questions or concerns, please contact your supervisor for guidance.
