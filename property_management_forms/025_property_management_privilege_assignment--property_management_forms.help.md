### Property Management Privilege Assignment Form
#### How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Property Owner Name** in the "Property Owner Name" field. This is the person or organization that owns the property.
2. Select the **Start Date** of the privilege period using the date picker tool.
3. Choose the **Privilege Type** by selecting one of the options provided (Property Access, Document Access, Payment Access, Maintenance Access, or Repair Access).
4. If applicable, enter the **End Date** of the privilege period using the time picker tool.
5. Select the **Authorized Contacts** by choosing one or more of the options provided (Owner, Property Manager, Property Manager 2).
6. Provide any additional **Notes** regarding the privilege assignment.

## Field-by-Field Explanation
* **Property Owner Name** (`property_owner_name`, `text`, required/optional): The name of the property owner.
* **Start Date** (`start_date`, `date`, required/optional): The start date of the privilege period.
* **Privilege Type** (`privilege_type`, `select_one`, required/optional): The type of access being granted (Property Access, Document Access, Payment Access, Maintenance Access, or Repair Access).
* **End Date** (`end_date`, `time`, required/optional): The end date of the privilege period.
* **Authorized Contacts** (`authorized_contacts`, `select_multiple`, required/optional): The individuals or groups authorized to access the property.
* **Notes** (`notes`, `note`, required/optional): Additional information regarding the privilege assignment.

## Tips
* Make sure to fill out all required fields to accurately track and manage privileges.
* Use the date picker tool to select the start and end dates of the privilege period.
* Be specific when choosing the privilege type to ensure accurate tracking and management.
* Select all applicable authorized contacts to ensure all relevant parties are informed of the privilege assignment.
* Use the notes field to provide any additional context or information regarding the privilege assignment.
