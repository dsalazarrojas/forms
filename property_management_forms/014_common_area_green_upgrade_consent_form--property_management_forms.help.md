# Common Area Green Upgrade Consent Form - Help Guide
## Purpose
This form is used to gather consent from property owners or managers for green upgrades in common areas of their properties.

## How To Complete This Form

1. Fill out the form carefully, ensuring all required fields are accurate.
2. Provide the name and address of the property.
3. Enter the name, email, and phone number of the consenting resident.
4. Select the type of upgrade and location where it will be installed.
5. Choose the expected start date and project duration.
6. Enter the total cost of the project and resident's share.
7. Select the method of payment for the resident's share.
8. Estimate the annual savings from the upgrade.
9. Declare your consent to the upgrade.
10. Sign and date the form.

## Field-by-Field Explanation

* **Consent Information** (id: 1):
	+ Details about the green upgrade project.
* **Property Name** (id: 2):
	+ Full name of the property or complex.
* **Property Address** (id: 3):
	+ Full address of the property.
* **Resident Information** (id: 4):
	+ Details about the consenting resident.
* **Resident Name** (id: 5):
	+ Full name of the resident.
* **Unit Number** (id: 6):
	+ Apartment or unit number.
* **Resident Email** (id: 7):
	+ Contact email address.
* **Resident Phone** (id: 8):
	+ Contact phone number.
* **Upgrade Details** (id: 9):
	+ Information about the proposed upgrades.
* **Upgrade Type** (id: 10):
	+ Select the type of upgrade (e.g., LED lighting, solar panel, etc.).
* **Upgrade Location** (id: 11):
	+ Choose where the upgrade will be installed (e.g., lobby, hallway, etc.).
* **Project Timeline** (id: 12):
	+ Select the expected duration of the project.
* **Expected Start Date** (id: 13):
	+ Enter the date work is expected to begin.
* **Financial Information** (id: 14):
	+ Details about the cost and funding of the project.
* **Total Project Cost** (id: 15):
	+ Enter the total cost of the upgrade project in USD.
* **Resident Cost Share** (id: 16):
	+ Select if residents will share any costs.
* **Cost Amount** (id: 17):
	+ Enter the resident's share amount in USD.
* **Payment Method** (id: 18):
	+ Choose how costs will be collected (e.g., one-time assessment, monthly fee increase, etc.).
* **Expected Savings** (id: 19):
	+ Estimate the annual savings from the upgrade.
* **Consent Declaration** (id: 20):
	+ Declare your consent to the upgrade (yes, no, abstain).
* **Concerns** (id: 21):
	+ Enter any concerns about the project.
* **Suggestions** (id: 22):
	+ Enter any suggestions for the project.
* **Signature Date** (id: 23):
	+ Date of consent signature.
* **Witness Name** (id: 24):
	+ Name of witness if applicable.
