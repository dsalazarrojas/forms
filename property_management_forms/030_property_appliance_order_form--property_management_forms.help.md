# Property Appliance Order Form - Help Guide

## Purpose
This form is intended to collect order details for properties. It is ideal for property management companies, real estate agents, and property owners.

## How To Complete This Form
To complete this form, follow these steps:

- Click on the "Order Details" page to fill out the order details.
- Proceed to the "Appliance Details" page to provide appliance specifications.
- Move on to the "Property Details" page to enter property information.
- Continue to the "Contact Details" page to enter contact information.
- Fill out the "Order Summary" page to summarize the order.
- Optionally, enter the "Order Status" and "Order Notes" on the "Order Summary" page.
- Finally, confirm the order on the "Order Confirmation" page.

## Field-by-Field Explanation

- **Order Details (1)**: Enter order ID, date, or any other relevant order information here.
  (Type: text)

- **Appliance Details (2)**: Describe the appliance(s) you're ordering, including type and model numbers.
  (Type: text)

- **Property Details (3)**: Enter property information such as address, unit number, or property ID.
  (Type: text)

- **Contact Details (4)**: Provide contact details of the person placing the order, including name and phone number.
  (Type: text)

- **Order Summary (5)**: Summarize the order in a few sentences, including order ID, appliance type, and property address.
  (Type: text)

- **Order Status (6)**: Select the order status from the options available (e.g., "Ordered", "Delivered", "Cancelled").
  (Type: text)

- **Order Notes (7)**: Enter any additional notes about the order, such as installation instructions or special requests.
  (Type: text)

- **Order Confirmation (8)**: Confirm the order by checking the box or entering a confirmation code.
  (Type: text)

## Tips
- Please fill out each field accurately to ensure that the order is processed correctly.
- If you have any questions or need assistance, contact the relevant authorities or support team.
