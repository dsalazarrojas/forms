# Property Document Upload Form - Help Guide
## Purpose
This form allows users to upload and store property documents in a standardized way.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of document you are uploading (e.g. Building plans, Floor plans, Photos, etc.).
2. Choose whether the document is authorized or not.
3. If applicable, enter the name of the file you are uploading.
4. Enter the size of the file.
5. Enter the name of the person or organization that uploaded the document.
6. Choose a date for the uploaded date.
7. Optionally, add any additional notes about the document.
8. Enter your email address for contact purposes.
9. Enter your phone number for contact purposes.

## Field-by-Field Explanation

* **Upload Property Documents** (`property_document_upload_form`, Select One, Required): Select the type of document you are uploading (e.g. Building plans, Floor plans, Photos, etc.). 
* **Property Type** (`property_type`, Select Multiple, Optional): Choose the type of property (e.g. House, Commercial, Land, etc.). 
* **Authorization** (`authorization`, Select One, Optional): Choose whether the document is authorized or not. 
* **File** (`file`, Text, Optional): Enter the name of the file you are uploading. 
* **File Name** (`file_name`, Text, Optional): Enter the name of the file you are uploading. 
* **File Size** (`file_size`, Number, Optional): Enter the size of the file. 
* **Uploaded By** (`uploaded_by`, Text, Optional): Enter the name of the person or organization that uploaded the document. 
* **Uploaded Date** (`uploaded_date`, Date, Optional): Choose a date for the uploaded date. 
* **Notes** (`notes`, Note, Optional): Optionally, add any additional notes about the document. 
* **Email** (`email`, Email, Optional): Enter your email address for contact purposes. 
* **Phone** (`phone`, Text, Optional): Enter your phone number for contact purposes.
