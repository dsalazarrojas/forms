# furnishing_task_entry_checklist - Help Guide
## Purpose
The furnishing_task_entry_checklist form is a comprehensive tool for property management teams to create, manage, and track furnishing tasks for properties. This form helps ensure that tasks are properly assigned, prioritized, and completed.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the **room** where the task is located.
2. Choose the **status** of the task (New, In Progress, Completed, or Cancelled).
3. Assign the task to a specific **user** (Designer, Project Manager, Property Manager, or Project Team).
4. Set a **due date** and **start date** for the task.
5. Provide a brief **task description** and any relevant **comments**.
6. Select the **priority** level (Low, Medium, or High).
7. Add any additional **task notes** and **room notes**.
8. Select the **assigned tool** to be used for the task (chatjimmy, Google Docs, MS Project, or Trello).
9. Add any **task tags** for easy identification.
10. Finally, select the **created by** user who initiated the task.

## Field-by-Field Explanation
* **Room**: Select the room where the task is located.
* **Room**: Enter any additional notes about the room.
* **Task Description**: Provide a brief description of the task.
* **Task Status**: Select the current status of the task (New, In Progress, Completed, or Cancelled).
* **Task Status Comment**: Add any comments about the task status.
* **Assigned to**: Select the user assigned to complete the task (Designer, Project Manager, Property Manager, or Project Team).
* **Task Due Date**: Set a due date for the task.
* **Task Start Date**: Set a start date for the task.
* **Task Priority**: Select the priority level of the task (Low, Medium, or High).
* **Task Tags**: Add any tags to help identify the task.
* **Task Notes**: Add any additional notes about the task.
* **Project Team Notes**: Add any notes for the project team.
* **Task Category**: Enter any category for the task.
* **Assigned Tool**: Select the tool to be used for the task (chatjimmy, Google Docs, MS Project, or Trello).
* **Created By**: Select the user who initiated the task (Designer, Project Manager, Property Manager, or Project Team).
