# Property Utility Referral Form - Help Guide
## Purpose
This form is used to refer a property's utility services, such as electricity, gas, water, internet, and cable, for the purpose of setting up or managing services.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the name of the property.
2. Fill in the street number and name of the property.
3. Enter the city and state where the property is located.
4. Enter the zip code of the property.
5. Select the type of utility service being referred (e.g., electricity, gas, etc.).
6. Select the start date for the referred service (if applicable).
7. Submit the form.

## Field-by-Field Explanation

* **Property Name** (`property_name`, text, required): Enter the name of the property.
* **Street Number** (`street_number`, text, required): Enter the street number where the property is located.
* **Street Name** (`street_name`, text, required): Enter the name of the street where the property is located.
* **City** (`city`, text, required): Enter the city where the property is located.
* **State** (`state`, text, required): Enter the state where the property is located.
* **Zip Code** (`zip`, text, required): Enter the zip code of the property.
* **Utility Type** (`utility_type`, select_one, required): Select the type of utility service being referred (e.g., electricity, gas, etc.).
* **Start Date** (`start_date`, date, optional): If applicable, select the start date for the referred service.
* **Note** (`property_utility_referral_form`, note, required): This is a general note field for any additional information.

Note: This form is designed to collect information for setting up or managing utility services for properties. If you are unsure about any of the information, please contact the property owner or manager for clarification.
