# Residential Property Conversion Application Form - Help Guide
## Purpose
The purpose of this form is to collect information about residential properties being converted or re-purposed for new uses. This includes details about the property's status, type, and use, as well as contact information for the person submitting the application.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the correct "Property Status" and "Property Type" for the property being converted or re-purposed.
2. Enter the "Contact Name" and "Contact Number" of the person submitting the application.
3. Provide the "Property Address" and "Property Use" for the property being converted or re-purposed.
4. Enter the "Contact Email" and "Contact Phone" of the person submitting the application.
5. Add any additional "Application Details" as necessary.
6. Select the "Submitted By" person or entity submitting the application.
7. Select the "Submitted Date" and "Submitted Time" when the application was submitted.

## Field-by-Field Explanation

* **Property Manager (id: 1)**: Enter the name of the person responsible for managing the property.
* **Contact Name (id: 2)**: Enter the name of the person submitting the application.
* **Property Address (id: 3)**: Enter the address of the property being converted or re-purposed.
* **Contact Number (id: 4)**: Enter the phone number of the person submitting the application.
* **Property Status (id: 5)**: Select the current status of the property (e.g., Application, Vacant, Under construction).
* **Property Type (id: 6)**: Select the type of property (e.g., House, Apartment, Commercial).
* **Contact Email (id: 7)**: Enter the email address of the person submitting the application.
* **Contact Phone (id: 8)**: Enter the phone number of the person submitting the application.
* **Property Use (id: 9)**: Select the intended use of the property after conversion or re-purposing (e.g., Residential, Commercial, Industrial).
* **Application Details (id: 10)**: Add any additional details about the application.
* **Submitted By (id: 11)**: Select the person or entity submitting the application (e.g., Property Manager, Developer, Client).
* **Submitted Date (id: 12)**: Enter the date the application was submitted.
* **Submitted Time (id: 13)**: Enter the time the application was submitted.
