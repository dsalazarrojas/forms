# Tenant Complaint Escalation Request Form - Help Guide
## Purpose
The Tenant Complaint Escalation Request Form is used to document and manage complaints from tenants. It helps track and resolve issues raised by tenants, ensuring efficient and timely resolution.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill out the required fields:
    *   **name**: Enter the name of the tenant submitting the complaint.
    *   **contact_number**: Provide the contact number of the tenant for follow-up communication.
    *   **resolution_request**: Describe the resolution requested for the complaint.
    *   **escalation_level**: Select the level of escalation (High, Medium, or Low) to indicate the severity of the issue.
    *   **resolution_timeframe**: Enter the expected resolution time for the complaint.
*   Fill out any optional fields:
    *   **email**: Enter the email address of the tenant for further communication.
    *   **complaint_details**: Provide any additional information about the complaint.
    *   **supporting_info**: Add any supporting documents or information related to the complaint.
    *   **property_manager**: Identify the property manager handling the complaint.
    *   **resolution_status**: Note the current resolution status.
    *   **comments**: Add any comments or feedback about the complaint.
    *   **followup_comments**: Add any follow-up comments or updates.
*   Attach any relevant files or documents to the **attachment** field.

## Field-by-Field Explanation

*   **name (2)**: Enter the name of the tenant submitting the complaint.
*   **contact_number (3)**: Provide the contact number of the tenant for follow-up communication.
*   **email (4)**: Enter the email address of the tenant for further communication.
*   **complaint_details (5)**: Provide any additional information about the complaint.
*   **supporting_info (6)**: Add any supporting documents or information related to the complaint.
*   **resolution_request (7)**: Describe the resolution requested for the complaint.
*   **escalation_level (8)**: Select the level of escalation (High, Medium, or Low) to indicate the severity of the issue.
*   **resolution_timeframe (9)**: Enter the expected resolution time for the complaint.
*   **attachment (10)**: Attach any relevant files or documents to the complaint.
*   **comments (11)**: Add any comments or feedback about the complaint.
*   **tenant_status (12)**: Select the status of the tenant (Active, Inactive, or Pending).
*   **property_manager (13)**: Identify the property manager handling the complaint.
*   **resolution_status (14)**: Note the current resolution status.
*   **comments (15)**: Add any comments or feedback about the complaint.
*   **followup_comments (16)**: Add any follow-up comments or updates.

## Tips

*   Make sure to fill out all required fields to ensure accurate and effective complaint tracking.
*   Attach any supporting documents or files to provide context to the complaint.
*   Keep the **resolution_request** field concise and clear to help the property manager understand the issue.
*   Use the **escalation_level** field to indicate the severity of the issue.
*   Set realistic **resolution_timeframe** expectations to help manage expectations.
*   Use the **tenant_status** field to track the tenant's status.
*   Update the **resolution_status** field to reflect the current resolution status.
*   Keep the **comments** and **followup_comments** fields for any additional feedback or updates.
