# Rental Unit Management Form - Help Guide
## Purpose
This form is designed to collect and manage information about rental units in a building. It is intended for internal use by property managers or building administrators to keep track of rental unit details and other relevant information.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant page(s) that correspond to the type of information you want to collect.
2. Fill in the corresponding fields as prompted.
3. Make sure to include all required fields (marked with an asterisk \*).
4. Provide additional information as needed in the "Additional Information" page.

## Field-by-Field Explanation
### First Page \* (Required)
* **Rental Unit Number** (`rental_unit_management_form_first_page`): Enter the unique identifier for the rental unit.
* **Rental Unit Name** (`rental_unit_management_form_first_page`): Enter the name of the rental unit.
* **Rental Unit Type** (`rental_unit_management_form_first_page`): Select the type of rental unit (e.g. apartment, house, etc.).
* **Rental Unit Status** (`rental_unit_management_form_first_page`): Select the status of the rental unit (e.g. occupied, vacant, etc.).

### Second Page \* (Required)
* **Tenant Information** (`rental_unit_management_form_second_page`): Enter the name, contact information, and any other relevant details about the tenant.
* **Lease Start Date** (`rental_unit_management_form_second_page`): Enter the start date of the lease.
* **Lease End Date** (`rental_unit_management_form_second_page`): Enter the end date of the lease.
* **Rent Amount** (`rental_unit_management_form_second_page`): Enter the rent amount for the rental unit.

### Third Page \* (Required)
* **Additional Details** (`rental_unit_management_form_third_page`): Provide any additional details about the rental unit (e.g. amenities, features, etc.).

### Additional Information (Required)
* **Additional Comments** (`rental_unit_management_form_additional_information`): Enter any additional comments or notes about the rental unit.

### Additional Page (Required)
* **Notes and Comments** (`rental_unit_management_form_additional_page`): Enter any additional notes or comments about the rental unit.

## Tips
- Make sure to complete all required fields.
- Use the "Additional Information" page to provide any additional details that may not fit in other fields.
- Review and revise as needed before submission.
