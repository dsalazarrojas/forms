# Strata Records Search Request - Help Guide
## Purpose
The "Strata Records Search Request" form is used to search for specific records related to strata properties. This form is designed to collect information about a property, its strata scheme, and the manager's details.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the "Manager Details" option from the "Manager Details" dropdown menu.
2. Enter the manager's email address in the "Manager Email" field.
3. Enter the property's address in the "Property Address" field.
4. Enter the building number of the property in the "Building Number" field.
5. Select the type of property (house, unit, or other) in the "Property Type" field.
6. Select the status of the property (active, inactive, or other) in the "Property Status" field.
7. Enter the name of the strata scheme in the "Strata Scheme" field.
8. Enter the number of the strata scheme in the "Strata Scheme Number" field.
9. Select the type of document (strata rollup, strata certificate, or other) in the "Document Type" field.
10. Enter the date of the document in the "Document Date" field.
11. Enter the time of the document in the "Document Time" field.
12. Enter any additional notes in the "Document Note" field.

## Field-by-Field Explanation

* **Strata Records Search Request**:
	+ This is the title of the form.
* **Manager Details** (Select One):
	+ Select the type of manager you are searching for (strata manager or property manager).
* **Manager Title** (Text):
	+ Enter the manager's title (optional).
* **Manager Email** (Email):
	+ Enter the manager's email address.
* **Manager Phone** (Text):
	+ Enter the manager's phone number (optional).
* **Property Address** (Text):
	+ Enter the property's address.
* **Building Number** (Number):
	+ Enter the building number of the property.
* **Street Number** (Text):
	+ Enter the street number of the property (optional).
* **Unit Number** (Text):
	+ Enter the unit number of the property (optional).
* **Property Number** (Text):
	+ Enter the property number of the property.
* **Property Type** (Select Multiple):
	+ Select the type of property (house, unit, or other).
* **Property Status** (Select Multiple):
	+ Select the status of the property (active, inactive, or other).
* **Property Status Other** (Text):
	+ Enter the status of the property if not active or inactive.
* **Property Status Note** (Text):
	+ Enter any additional notes about the property status.
* **Strata Scheme** (Text):
	+ Enter the name of the strata scheme.
* **Strata Scheme Number** (Text):
	+ Enter the number of the strata scheme.
* **Manager Scheme** (Text):
	+ Enter the name of the manager's scheme.
* **Manager Scheme Number** (Text):
	+ Enter the number of the manager's scheme.
* **Document Type** (Select Multiple):
	+ Select the type of document (strata rollup, strata certificate, or other).
* **Document Type Other** (Text):
	+ Enter the type of document if not strata rollup or strata certificate.
* **Document Date** (Date):
	+ Enter the date of the document.
* **Strata Date** (Date):
	+ Enter the date of the strata scheme.
* **Document Time** (Time):
	+ Enter the time of the document.
* **Manager Time** (Time):
	+ Enter the time of the manager's scheme (optional).
* **Document Note** (Note):
	+ Enter any additional notes about the document.
