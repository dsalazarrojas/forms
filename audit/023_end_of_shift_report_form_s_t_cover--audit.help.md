# End Of Shift Report Form S&T Cover - Help Guide
## Purpose
The End Of Shift Report Form S&T Cover is used to record details of a shift conducted by S&T personnel.
## How To Complete This Form
To complete this form, follow the instructions below:
1. Enter the employee's ID in the Employee Id field.
2. Enter the employee's name in the employee_name field.
3. Enter the start time of the shift in the Shift Start Time field.
4. Enter the end time of the shift in the Shift End Time field.
5. Enter any additional notes or comments in the Employee Notes field.
6. Enter the supervisor's ID in the Supervisor Id field.
7. Enter the shift ID in the Shift Id field.
8. Enter the department ID in the Department Id field.
9. Enter the section ID in the Section Id field.
10. Enter the work period in the Work Period field.
11. Enter the report date in the Report Date field.
12. Enter the report time in the Report Time field.
13. Enter any assigned tools in the Assigned Tool field.
14. Enter the employee's name (if applicable) in the Employee Name 2 field.
15. Enter any additional notes in the Notes field.
16. Enter any comments in the Comments 2 field.
17. Enter the supervisor's name in the Supervisor Name field.
18. Enter the shift ID 2 in the Shift Id 2 field.
19. Enter the department ID 2 in the Department Id 2 field.
20. Enter the section ID 2 in the Section Id 2 field.
21. Enter the employee ID 2 in the Employee Id 2 field.
22. Enter any additional notes in the Notes 2 field.

## Field-by-Field Explanation

* **Employee Id** (`employee_id`, number, required): Enter the employee's ID number.
* **Employee Name** (`employee_name`, text, required): Enter the employee's name.
* **Shift Start Time** (`shift_start_time`, time, required): Enter the start time of the shift.
* **Shift End Time** (`shift_end_time`, time, required): Enter the end time of the shift.
* **Employee Notes** (`employee_notes`, note, required): Enter any additional notes or comments about the shift.
* **Supervisor Id** (`supervisor_id`, number, required): Enter the supervisor's ID number.
* **Comments** (`comments`, text, required): Enter any comments or notes about the shift.
* **Shift Id** (`shift_id`, number, required): Enter the shift ID number.
* **Department Id** (`department_id`, number, required): Enter the department ID number.
* **Section Id** (`section_id`, number, required): Enter the section ID number.
* **Work Period** (`work_period`, text, required): Enter the work period.
* **Report Date** (`report_date`, date, required): Enter the report date.
* **Report Time** (`report_time`, time, required): Enter the report time.
* **Assigned Tool** (`assigned_tool`, text, required): Enter any assigned tools for the shift.
* **Employee Name 2** (`employee_name_2`, text, required): Enter the name of the employee (if applicable).
* **Notes** (`notes`, note, required): Enter any additional notes.
* **Comments 2** (`comments_2`, text, required): Enter any comments or notes.
* **Supervisor Name** (`supervisor_name`, text, required): Enter the name of the supervisor.
* **Shift Id 2** (`shift_id_2`, number, required): Enter the shift ID 2 number.
* **Department Id 2** (`department_id_2`, number, required): Enter the department ID 2 number.
* **Section Id 2** (`section_id_2`, number, required): Enter the section ID 2 number.
* **Employee Id 2** (`employee_id_2`, number, required): Enter the employee ID 2 number.
* **Notes 2** (`notes_2`, note, required): Enter any additional notes.
* **Comments 3** (`comments_3`, text, required): Enter any comments or notes.
* **Notes 3** (`notes_3`, note, required): Enter any additional notes.

## Tips

* Make sure to enter accurate information for all fields.
* Use clear and concise language when entering notes or comments.
* Review the form carefully before submitting it to ensure all fields are filled out correctly.
