# Job Safety Observation Form - Help Guide
## Purpose
The Job Safety Observation Form is used to document and record observations about safety hazards and control measures on a job site. This form helps to identify potential hazards and control measures to mitigate risks and ensure a safe working environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer the questions in each field to provide a clear and concise report of your observation.
2. Select all applicable hazard control measures that are in place on the job site.
3. If a particular hazard control measure is not listed, select "No" and provide a brief explanation.
4. Indicate the risk level of each identified hazard.
5. List all hazards present on the job site.
6. If a particular hazard is not listed, select "No" and provide a brief explanation.
7. Describe the control measures in place to mitigate each hazard.
8. Record the date and time of your observation.
9. Provide any additional comments or notes about your observation.

## Field-by-Field Explanation
* **General Information** (text, optional): Enter a brief description of your observation.
* **What is the hazard control measure in place?** (select_multiple, optional): 
  - Select all applicable hazard control measures that are in place on the job site.
  - If a particular hazard control measure is not listed, select "No" and provide a brief explanation.
* **Please specify if you have any other hazard control measures** (select_multiple, optional): 
  - Select "Yes" if you have another hazard control measure not listed.
  - If yes, provide a brief description of the measure.
* **What is the risk level of the hazard?** (select_one, optional): 
  - Select the risk level of each identified hazard.
* **Please specify if other** (select_one, optional): 
  - Select "Yes" if the risk level is not listed.
  - If yes, provide a brief description of the risk level.
* **What hazards are present on the job?** (select_multiple, optional): 
  - List all hazards present on the job site.
* **Please specify if you have any other hazards** (select_multiple, optional): 
  - Select "Yes" if you have another hazard not listed.
  - If yes, provide a brief description of the hazard.
* **Describe the control measures** (text, optional): Enter a brief description of the control measures.
* **Observation Date** (date, optional): Record the date of your observation.
* **Observation Time** (time, optional): Record the time of your observation.
* **Observation Notes** (text, optional): Provide any additional comments or notes about your observation.
