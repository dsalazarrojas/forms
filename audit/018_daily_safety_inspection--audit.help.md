# Daily Safety Inspection - Help Guide
## Purpose
The Daily Safety Inspection form is used to gather information about a project's safety status and perform a daily safety evaluation. This form helps inspectors identify and document any safety concerns, issues, and actions taken to mitigate risks.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the project name and project number, if applicable.
2. Select the current project status (Active, Inactive, or Closed).
3. Enter the start and end dates of the inspection period.
4. Enter the site name and contact information for the site manager.
5. Enter the safety manager's name and contact information.
6. Enter the inspector's name and contact information.
7. Sign and date the form as the inspector.
8. Add any additional notes or comments about the inspection.
9. Review and update the project status as necessary.

* **First_page** (`first_page`, date, required/optional): Enter the date of the first day of the inspection period.

* **Project Name** (`project_name`, text, required/optional): Enter the name of the project being inspected.

* **Project Status** (`project_status`, select_one, required/optional): Select the current status of the project (Active, Inactive, or Closed).

* **First_page_note** (`first_page_note`, note, required/optional): Add any notes or comments about the first day of the inspection period.
