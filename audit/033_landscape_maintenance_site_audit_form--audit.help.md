# Landscape Maintenance Site Audit Form - Help Guide
## Purpose
This form is used to collect information about the condition and maintenance needs of a site's landscape. It helps to identify potential issues and record the status of maintenance actions taken.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the information in each field as prompted.
* For the "photos" field, select one of the options (Yes or No) to indicate whether photos are taken of the site.
* For the "site issues" field, select all issues that apply to the site.
* For the "action items" field, select one of the options (Yes or No) to indicate whether action items are present.
* For the "action items status" field, select one of the options (Active or Inactive) to indicate the status of action items.

## Field-by-Field Explanation
* **Site Survey** (`site_survey`, Text, Optional): A brief description of the site's current condition.
* **Photos** (`photos`, Select One, Optional): Whether photos are taken of the site.
* **Notes** (`notes`, Note, Optional): A text field for any additional comments or notes about the site.
* **Site Issues** (`site_issues`, Select Multiple, Optional): A list of issues or problems with the site. Select all issues that apply.
* **Site Issues Description** (`site_issues_description`, Text, Optional): A brief description of any site issues.
* **Action Items** (`action_items`, Select One, Optional): Whether action items are present on the site.
* **Action Items Description** (`action_items_description`, Text, Optional): A brief description of any action items.
* **Action Items Status** (`action_items_status`, Select One, Optional): The status of action items (Active or Inactive).

## Tips
* Make sure to provide accurate and detailed information about the site's condition and issues.
* Use the "site issues" field to select all relevant issues that apply to the site.
* Update the "action items status" field as necessary to reflect any changes to action items.
