# Custom Laptop Sleeve Order Form - Help Guide
## Purpose
The Custom Laptop Sleeve Order Form is used to collect information for a custom laptop sleeve order. Please fill in the required fields to ensure that your order is processed correctly.

## How To Complete This Form
1. Fill in the required fields:
	* **order_info**: Briefly describe the order, including any special requests or instructions.
	* **customer**: Enter the customer's name.
2. For customizations, you can select from the available options or enter a custom value. If you need to add a note, you can use the **custom_note** field.
3. Review your information carefully before submitting the form.

## Field-by-Field Explanation
### Order Info
* **order_info**: A short description of the order, including any special requests or instructions.

### Customer
* **customer**: Please enter the customer's name.

### Laptop
* **laptop**: Select the type of laptop to be customized (if applicable).

### Custom Text Fields
* **custom_text**: These fields are for custom text inputs. You can enter any information or instructions you need to communicate with the customer.

### Custom Integer/Decimal Fields
* **custom_integer**: Enter an integer value (e.g., quantity).
* **custom_decimal**: Enter a decimal value (e.g., price).

### Custom Email and Phone Fields
* **custom_email**: Enter the customer's email address.
* **custom_phone**: Enter the customer's phone number.

### Custom Date and Time Fields
* **custom_date**: Select a date in the format YYYY-MM-DD.
* **custom_time**: Select a time in the format HH:MM.

### Select One and Multiple Fields
* **custom_select_one**: Select one option from the dropdown list (e.g., "Yes" or "No").
* **custom_select_multiple**: Select one or more options from the dropdown list (e.g., "Yes" and "No").

### Custom Laptop Sleeve Fields
* **custom_laptop_sleeve_type**: Enter a custom value (e.g., type of material).
* **custom_laptop_sleeve_color**: Enter a custom color value.
* **custom_laptop_sleeve_size**: Enter a custom size value.
* **custom_laptop_sleeve_material**: Enter a custom material value.
* **custom_laptop_sleeve_quantity**: Enter a quantity value.
* **custom_laptop_sleeve_price**: Enter a price value.
* **custom_laptop_sleeve_status**: Select the status of the laptop sleeve (e.g., "available" or "unavailable").

### Status
* **custom_laptop_sleeve_status**: This field is a select-one field that indicates the status of the laptop sleeve (e.g., "available" or "unavailable").
