## Customized Apron Order Form - Help Guide
### Purpose

This form is used to place a customized order for an apron. The form allows you to select from various options such as apron type, color, size, and style to create a tailored product that suits your business needs.

### How To Complete This Form

1. Fill out the form with the required information.
2. Select the desired Apron Type from the dropdown menu.
3. Select multiple Apron Colors from the list.
4. Choose the Apron Style if applicable.
5. Select the desired Size for the apron.
6. Optionally, provide a Special Request or Custom Text for the order.
7. Enter your Email and Phone number for communication.
8. Add any additional Order Notes.

### Field-by-Field Explanation

* **Apron Type** (`id: 4`): Choose the type of apron you want to order. Currently, there are three options: Apron A, Apron B, and Apron C.
* **Apron Color** (`id: 5`): Select one or more colors for the apron. You can choose from White, Black, and Blue.
* **Apron Style** (`id: 6`): Select a style for the apron if applicable. Currently, there are two options: Style A and Style B.
* **Size** (`id: 7`): Choose the size of the apron. Select one or more from Small, Medium, and Large.
* **Quantity** (`id: 8`): Enter the quantity of aprons you want to order.
* **Special Request** (`id: 9`): Provide any special requests or instructions for the order.
* **Custom Text** (`id: 10`): Add any custom text for the order.
* **Email** (`id: 11`): Enter your email address for communication.
* **Phone** (`id: 12`): Enter your phone number for communication.
* **Note** (`id: 13`): Add any additional notes for the order.
* **Order Notes** (`id: 14`): Add any additional notes for the order.
* **Order Notes 2** (`id: 15`): Add another additional note for the order.
* **Custom Dropdown** (`id: 16`): Select 'Yes' or 'No' for a custom feature.
* **Time** (`id: 17`): Select a time for the order.
* **Date** (`id: 18`): Select a date for the order.
* **Time 2** (`id: 19`): Select another time for the order.
* **Date 2** (`id: 20`): Select another date for the order.
* **Time 3** (`id: 21`): Select another time for the order.
* **Date 3** (`id: 22`): Select another date for the order.
* **Date 4** (`id: 23`): Select another date for the order.
* **Custom Text 2** (`id: 24`): Add another custom text for the order.
* **Custom Text 3** (`id: 25`): Add another custom text for the order.
