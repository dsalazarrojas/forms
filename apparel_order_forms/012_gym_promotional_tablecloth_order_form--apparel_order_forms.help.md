# Gym Promotional Tablecloth Order Form - Help Guide
## Purpose
The Gym Promotional Tablecloth Order Form is used to collect information about promotional tablecloths for a gym. This form helps in collecting details such as tablecloth specifications, artwork, and order information to process the order efficiently.

## How To Complete This Form
To complete the form, please follow these steps:

1.  Enter tablecloth details such as "Tablecloth Details" (field **1**).
2.  Enter "Tablecloth Spec" details (field **2**).
3.  Specify if you want to include artwork on the tablecloths (field **3**).
4.  Enter order details such as "Order Details" (field **4**).
5.  Specify the quantity ordered (field **5**).
6.  Specify if the total is ordered (field **6**).
7.  Enter the delivery address (field **7**).
8.  Choose a delivery date (field **8**).
9.  Choose a delivery time (field **9**).
10. Enter the phone number for delivery (field **10**).
11. Enter the email address for delivery (field **11**).
12. Enter any additional notes (field **12**).
13. Enter artwork details if applicable (field **13**).
14. Enter tablecloth size (field **14**).
15. Enter tablecloth color (field **15**).
16. Enter tablecloth material (field **16**).
17. Enter tablecloth style (field **17**).
18. Specify the quantity ordered for the second tablecloth (field **18**), if applicable.
19. Enter artwork details for the second tablecloth, if applicable (field **19**).
20. Enter tablecloth size for the second tablecloth, if applicable (field **20**).
21. Enter tablecloth color for the second tablecloth, if applicable (field **21**).
22. Enter tablecloth material for the second tablecloth, if applicable (field **22**).
23. Enter tablecloth style for the second tablecloth, if applicable (field **23**).

## Field-by-Field Explanation
* **Tablecloth Details**: This field is for entering details about the tablecloth for the gym, such as size, color, etc.
* **Tablecloth Spec**: This field is for entering specifications about the tablecloth, such as material, style, etc.
* **Artwork**: This field is for specifying if you want to include artwork on the tablecloths.
* **Order Details**: This field is for entering order details, such as order type, etc.
* **Quantity Ordered**: This field is for specifying the quantity of tablecloths ordered.
* **Total**: This field is for specifying if the total is ordered.
* **Delivery Address**: This field is for entering the address where the tablecloths will be delivered.
* **Delivery Date**: This field is for choosing a delivery date.
* **Delivery Time**: This field is for choosing a delivery time.
* **Phone**: This field is for entering the phone number of the delivery address.
* **Email**: This field is for entering the email address of the delivery address.
* **Note**: This field is for entering any additional notes or comments.
* **Artwork Details**: This field is for entering details about the artwork, if applicable.
* **Tablecloth Size**: This field is for entering the size of the tablecloth.
* **Tablecloth Color**: This field is for entering the color of the tablecloth.
* **Tablecloth Material**: This field is for entering the material of the tablecloth.
* **Tablecloth Style**: This field is for entering the style of the tablecloth.
* **Quantity Ordered 2**: This field is for specifying the quantity of the second tablecloth ordered.
* **Artwork Details 2**: This field is for entering details about the artwork for the second tablecloth, if applicable.
* **Tablecloth Size 2**: This field is for entering the size of the second tablecloth.
* **Tablecloth Color 2**: This field is for entering the color of the second tablecloth.
* **Tablecloth Material 2**: This field is for entering the material of the second tablecloth.
* **Tablecloth Style 2**: This field is for entering the style of the second tablecloth.

The last field **Quantity Ordered 2** is likely used to ask for the quantity of the second tablecloth ordered. If the quantity is 0 then the field for the second tablecloth details should not be filled. 

Please note that the fields with "2" suffix are for the second tablecloth. If you are ordering only one tablecloth, please skip those fields. 

Also, please ensure that you fill all the required fields to submit the form successfully.
