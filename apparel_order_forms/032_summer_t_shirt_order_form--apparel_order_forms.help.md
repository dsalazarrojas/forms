# Summer T Shirt Order Form - Help Guide
## Purpose
This form is used to place an order for a summer T-shirt. It collects customer information, order details, and shipping address for the order to be fulfilled.

## How To Complete This Form
To complete this form, follow these steps:

* Fill in the required fields:
	+ Order Form
	+ Shipping Address (Line 1, Line 2, City, Province/State, ZIP/Postal Code, Country)
	+ Credit Card Info (Number, Expiration, Security Code)
	+ Order Total
	+ Payment Method
	+ Email (Billing and Shipping)
	+ Phone (Shipping)
	+ Name
	+ Order Comments
* Select the desired T-shirt option:
	+ Select T Shirt
* Provide additional details:
	+ Quantity
	+ Size
	+ Order Notes
* Leave the optional fields:
	+ Shipping Address (optional)
	+ Billing Email and Phone (optional)

## Field-by-Field Explanation

* **Order Form**: This section is required to be filled in. It's a general section to capture the order details.
* **Select T Shirt**: This is a drop-down menu to select the desired T-shirt option. Please choose 'Yes' if you want to order a T-shirt.
* **Quantity**: Enter the number of T-shirts you would like to order. Please be accurate as it will affect the order total.
* **Size**: Select the size of the T-shirt you would like. Please choose 'Yes' for the size you prefer.
* **Shipping Address**: Enter your shipping address, including street (Line 1), apartment or suite (Line 2), city, province or state, ZIP or postal code, and country.
* **Shipping Email and Phone**: Enter your shipping address's email and phone number for updates and contact.
* **Credit Card Info**: This section is optional but required for order completion. Enter your credit card number, type (not used in this form, so 'Yes' or 'No' is not relevant), expiration, and security code for payment.
* **Order Total**: This is calculated based on the quantity and order details. Please ensure accuracy for proper fulfillment.
* **Payment Method**: Select 'Yes' if you would like to use a credit card as the payment method.
* **Order Notes**: Add any additional comments or notes about the order, if needed.
* **Billing Email and Phone**: Enter your email and phone number for billing and updates.
* **Shipping Name**: Enter your name to associate with the order.
* **Order Comments**: Add any other comments about the order, if needed.
* **Billing Address** (optional): Enter your billing address if you prefer to use a different address than the shipping address.
* **Shipping and Billing Email** (optional): Enter the email of your shipping and billing address, if different. 
* **Phone** (optional): Enter your phone number for billing and updates, if different.
* **Phone Number for Shipping** (required): Enter your shipping address's phone number for contact.
* **Billing and Shipping Email** (optional): Enter the email of your billing and shipping address, if different.

Note: This guide is written in a simple and concise manner to help end-users understand the form's purpose and how to complete it accurately. If any field's label is weak or unclear, the explanation has been provided in best-effort intent.
