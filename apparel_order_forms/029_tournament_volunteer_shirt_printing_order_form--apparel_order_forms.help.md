# Tournament Volunteer Shirt Printing Order Form - Help Guide
## Purpose
This form is intended to collect information from volunteers for a tournament event. The form will be used to gather details about the volunteer, the shirt order, and event information. It is divided into three sections, each focusing on a specific aspect of the volunteer's experience.

## How To Complete This Form
1. Start by reviewing the form sections below.
2. Begin on the first page, "Volunteer Information".
3. Answer the questions as instructed.
4. Proceed to the next page, "Shirt Order Information".
5. Provide details about the shirt order.
6. Move to the final page, "Event Information".
7. Add any necessary event details.

## Field-by-Field Explanation

### Volunteer Information
* **Volunteer Name** (text, required): Enter the name of the person who will be volunteering.
* **Volunteer Email** (text, required): Provide the volunteer's email address for communication purposes.
* **Volunteer Phone** (text, required): Enter the volunteer's phone number for contact.

### Shirt Order Information
* **Shirt Size** (text, required): Select the volunteer's preferred shirt size.
* **Shirt Color** (text, required): Select the preferred shirt color from the options provided.
* **Additional Instructions** (text, optional): If there are any special requests or comments about the shirt order, please include them here.

### Event Information
* **Event Name** (text, required): Enter the name of the event where the volunteer will be working.
* **Event Date** (text, required): Provide the date of the event.
* **Event Location** (text, required): Enter the location of the event.
* **Event Description** (text, optional): Add any additional information about the event if necessary.

## Tips
* Please fill out the form accurately and thoroughly.
* Ensure all required fields are completed.
* If you have any questions or concerns, contact the event organizers.
* Review the form before submission to avoid errors.
