# Shirt Orders - Help Guide

## Purpose
The Shirt Orders form is designed for customers to place orders for shirts. It collects necessary information to process the order correctly and efficiently. Please ensure you have all required information before submitting the form. If you have any questions or issues, contact our support team.

## How To Complete This Form
To complete the Shirt Orders form, follow these steps:

1. Click on the "Submit" button to start the form.
2. Fill in the required fields, including:
	* Order Details: A brief description of the order.
	* Customer Info: Customer's name, address, and contact information.
	* Shipping Address: Customer's shipping address.
	* Order Date: The date when the order is scheduled to be fulfilled.
	* Customer Phone: Customer's phone number.
	* Customer Email: Customer's email address.
	* Order Notes: Any additional information about the order.
	* Customer Notes: Notes from the customer for our reference.
3. Select a date for the "Order Date" field using the calendar icon.
4. Ensure all fields are filled in correctly before submitting the form.

## Field-by-Field Explanation

* **Order Details**: (<label>Order Details, text, required)
	+ A brief description of the order, including any specific details or requests.
* **Customer Info**: (<label>Customer Info, text, required)
	+ Customer's name, address, and contact information, such as name, address, and phone number.
* **Shipping Address**: (<label>Shipping Address, text, required)
	+ Customer's shipping address, including address line 1, address line 2, city, state, and zip.
* **Order Date**: (<label>Order Date, date, required)
	+ The date when the order is scheduled to be fulfilled.
* **Customer Phone**: (<label>Customer Phone, text, required)
	+ Customer's phone number.
* **Customer Email**: (<label>Customer Email, email, required)
	+ Customer's email address.
* **Order Notes**: (<label>Order Notes, text, required)
	+ Any additional information about the order.
* **Customer Notes**: (<label>Customer Notes, text, required)
	+ Notes from the customer for our reference.

## Tips
* Please ensure all fields are filled in correctly before submitting the form.
* If you have any questions or issues, contact our support team.
* Double-check your email address and phone number to ensure they are accurate.
