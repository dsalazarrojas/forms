# Football Equipment Issue Form - Help Guide
## Purpose
The Football Equipment Issue Form is used to report any problems or malfunctions with team equipment. This form helps the maintenance team to quickly identify and resolve issues, reducing downtime and ensuring the team's performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in your name and any other relevant details if required.
2. Specify the date of the issue occurred.
3. Select the type of equipment involved in the issue (e.g., ball, jersey, etc.).
4. Enter the equipment's ID number.
5. Provide a brief description of the problem.
6. If applicable, select the assigned tool or person responsible for fixing the issue.
7. Enter the player's number and team name (if available).
8. Choose the status of the issue (Active, Inactive, or Closed).
9. Provide any additional details about the issue.
10. Enter the time and date of the issue, if known.

## Field-by-Field Explanation
* **Player Name** (Player Name, text, optional): Enter your name if you are reporting the issue.
* **Issue Date** (Issue Date, date, optional): Specify the date the issue occurred.
* **Equipment Type** (Equipment Type, text, optional): Select the type of equipment involved (e.g., ball, jersey, etc.).
* **Equipment ID** (Equipment ID, text, optional): Enter the equipment's ID number.
* **Issue Reason** (Issue Reason, text, optional): Provide a brief description of the problem.
* **Assigned Tool** (Assigned Tool, select_one, optional): Select the tool or person responsible for fixing the issue (e.g., Jimmy, John, Jane).
* **Player Number** (Player Number, number, optional): Enter the player's number.
* **Team Name** (Team Name, text, optional): Enter the team's name.
* **Issue Status** (Issue Status, select_multiple, optional): Choose the status of the issue (Active, Inactive, or Closed).
* **Description** (Description, text, optional): Provide any additional details about the issue.
* **Issue Date/Time** (Issue Date/Time, time, optional): Enter the time the issue occurred, if known.
* **Issue Date/Time 2** (Issue Date/Time 2, date, optional): Enter the date the issue occurred, if known.
