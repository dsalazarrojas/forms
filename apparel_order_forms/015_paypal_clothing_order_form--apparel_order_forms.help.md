# paypal_clothing_order_form - Help Guide
## Purpose
The paypal_clothing_order_form is used to collect customer information and order details for processing apparel orders via PayPal.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter your customer information in the "customer info" section.
2. Select the product you would like to order (Sweater or Jeans).
3. Enter the quantity of the product you would like to order.
4. Enter the price of your order (optional, default will be calculated automatically).
5. If you need to specify shipping details, enter them in the "shipping" section (optional).

## Field-by-Field Explanation
* **Customer Info (customer info)** (`Text`, required):
This field is used to collect the customer's name and contact information for processing the order.
* **Product (product)** (`Select One`, required):
Select the type of clothing item you would like to order (Sweater or Jeans).
* **Quantity (quantity)** (`Number`, required):
Enter the number of clothing items you would like to order.
* **Price (price)** (`Number`, optional):
Enter the price of your order (if left blank, the system will calculate it automatically).
* **Shipping (shipping)** (`Text`, optional):
If you need to specify any special shipping instructions or details, enter them here (e.g., expedited shipping, special handling).
