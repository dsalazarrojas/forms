# valentines_day_order_form - Help Guide
## Purpose
The "valentines_day_order_form" is a form used to collect information for Valentine's Day orders. It is essential to fill out this form accurately and completely to ensure timely and correct delivery of the order.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the customer's name in the **Customer Name** field. This field is required to ensure that the order is delivered to the correct person.
2. Enter the customer's email address in the **Customer Email** field. This field is required to ensure that the order is delivered to the correct email address.
3. Select a delivery date in the **Delivery Date** field. This field is required to schedule the delivery of the order.
4. Select a delivery method from the **Delivery Method** field. This field is required to ensure that the order is delivered correctly.
5. Select one or more types of flowers or gifts from the **Order Type** field. This field is required to ensure that the correct type of order is placed.
6. Select a time for delivery from the **Delivery Time** field. This field is required to schedule the delivery of the order.
7. Enter any special instructions for the delivery in the **Order Notes** field. This field is optional.
8. Select the tool assigned to this order from the **Assigned Tool** field. This field is required.
9. Enter the order ID in the **Order ID** field. This field is required.
10. Enter the form ID in the **Form ID** field. This field is required.
11. Select the category for this order from the **Category** field. This field is required.
12. Enter the output file name in the **Output File** field. This field is required.

## Field-by-Field Explanation
* **Customer Name** (`customer_name`, `text`, required): Enter the customer's name.
* **Customer Email** (`customer_email`, `email`, required): Enter the customer's email address.
* **Delivery Date** (`delivery_date`, `date`, required): Select a date for delivery.
* **Delivery Method** (`delivery_method`, `select_one`, required): Select a delivery method.
* **Order Type** (`order_type`, `select_multiple`, required): Select one or more types of flowers or gifts.
* **Delivery Time** (`delivery_time`, `time`, required): Select a time for delivery.
* **Order Notes** (`order_notes`, `text`, optional): Enter any special instructions for the delivery.
* **Assigned Tool** (`assigned_tool`, `select_one`, required): Select the tool assigned to this order.
* **Order ID** (`order_id`, `text`, required): Enter the order ID.
* **Form ID** (`form_id`, `text`, required): Enter the form ID.
* **Category** (`category`, `text`, required): Select the category for this order.
* **Output File** (`output_file`, `text`, required): Enter the output file name.
