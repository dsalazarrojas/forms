# Sound Test Window Booking Form - Help Guide
## Purpose
This form is designed to be used for booking sound tests for clients who need to test their windows for sound quality. It allows users to select the type of sound test they require, choose a suitable time slot, and provide additional contact information for the booking.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the type of sound test you require by clicking on the "Sound tests" dropdown menu.
2. Choose your preferred time slot for the test by selecting one or more from the "Time slots" dropdown menu. You can select multiple time slots by holding down the Ctrl key (or Command key on Mac) while clicking on each slot.
3. If you have any specific date requirements, you can select a date for the test.
4. Please enter the duration of the booking in hours.
5. If you are booking multiple tests, please enter the total number of tests you would like to book.
6. Please provide any additional requirements or notes for the test in the "Requirements" field.
7. Finally, provide your contact information for us to get back to you.

## Field-by-Field Explanation
### Form Information
* **Form Info (id: 1)**: A brief description of your test requirement.

### Sound Tests
* **Sound tests (id: 2)**: Select the type of sound test you require. Currently, the options are A, B, C, and D.

### Time Slots
* **Time slots (id: 3)**: Choose the time slots you prefer for the test. You can select multiple slots by holding down the Ctrl key (or Command key on Mac) while clicking on each slot. Options are 9:00-12:00, 13:00-16:00, and 17:00-20:00.

### Date
* **Date (id: 4)**: If you have any specific date requirements, please enter the date for the test.

### Booking Duration
* **Booking duration (id: 5)**: Enter the duration of the booking in hours.

### Number of Bookings
* **Number of bookings (id: 6)**: If you are booking multiple tests, please enter the total number of tests you would like to book.

### Requirements
* **Requirements (id: 7)**: Please provide any additional requirements or notes for the test.

### Contact Information
* **Contact info (id: 8)**: Please provide your contact information so we can get back to you.

## Tips
* Make sure to double-check your selections before submitting the form to avoid any errors.
* If you have any issues or concerns, please don't hesitate to contact us.
