# DJ Appointment Form - Help Guide
## Purpose
The DJ Appointment Form is designed to collect information about upcoming DJ events, including event type, event name, start time, venue, DJ name, contact number, email, and client name. This form is intended for event organizers or individuals responsible for booking DJs.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the type of event you are booking a DJ for from the "Event Type" dropdown menu. Choose from: DJ Set, Club Nights, Corporate Event, Festival, Party, Wedding, Concert, or Other.
2. Enter the name of the event in the "Event Name" field.
3. Enter the start time of the event in the "Start Time" field in the format MM/DD/YY HH:MM.
4. Enter the address or location of the event in the "Venue" field.
5. Enter the name of the DJ in the "DJ Name" field.
6. Enter the contact number of the event organizer or responsible party in the "Contact Number" field.
7. Enter the email address of the event organizer or responsible party in the "Email" field.
8. Enter the name of the client or event host in the "Client Name" field.
9. Finally, select the date of the event in the "Event Date" field in the format MM/DD/YY.

## Field-by-Field Explanation
* **Event Type**: Select the type of event you are booking a DJ for.
* **Event Name**: Enter the name of the event.
* **Start Time**: Enter the start time of the event in the format MM/DD/YY HH:MM.
* **Venue**: Enter the address or location of the event.
* **DJ Name**: Enter the name of the DJ.
* **Contact Number**: Enter the contact number of the event organizer or responsible party.
* **Email**: Enter the email address of the event organizer or responsible party.
* **Client Name**: Enter the name of the client or event host.
* **Event Date**: Select the date of the event in the format MM/DD/YY.

## Tips
* Make sure to fill out all required fields to ensure the form is complete and accurate.
* Double-check the event type and event date to ensure they match the event details.
* If you have any questions or concerns, contact the event organizer or responsible party listed in the "Contact Number" field.
