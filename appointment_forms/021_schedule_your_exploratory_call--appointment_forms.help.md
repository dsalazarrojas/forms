# Schedule Your Exploratory Call - Help Guide
## Purpose
The "Schedule Your Exploratory Call" form is designed to collect information for planning and scheduling exploratory calls with leads. This form helps in gathering all the necessary details in one place, making it easier to coordinate and execute the calls.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Select the date you want to schedule the exploratory call.
2. Choose the correct time zone for the call.
3. Enter the desired time for the call.
4. Specify the duration of the call.
5. Fill in the lead's first name.
6. Add the lead's last name.
7. Enter the lead's email address.
8. Add the lead's phone number.
9. Provide any additional notes for the exploratory call.
10. If applicable, select the lead's company.
11. Indicate the lead's title.
12. Enter any scheduling link if available.
13. Choose the assigned user responsible for the call.
14. Select the status of the exploratory call scheduling (e.g., new, in progress, or done).
15. Add any additional notes for the scheduling process.

## Field-by-Field Explanation
* **Exploratory Call Schedule Date**: Choose the date for the exploratory call by selecting a date from the available options.
* **Time Zone**: Select the correct time zone for the call.
* **Exploratory Call Schedule Time**: Enter the desired time for the call.
* **Exploratory Call Schedule Duration**: Specify the duration of the call in text format.
* **Lead First Name**: Enter the lead's first name.
* **Lead Last Name**: Enter the lead's last name.
* **Lead Email**: Enter the lead's email address.
* **Lead Phone**: Enter the lead's phone number.
* **Exploratory Call Notes**: Add any additional notes for the exploratory call.
* **Lead Company**: If available, select the lead's company.
* **Lead Title**: Enter the lead's title.
* **Exploratory Call Scheduling Link**: Enter any scheduling link if available.
* **Assigned User**: Select the user responsible for the exploratory call.
* **Exploratory Call Scheduling Status**: Choose the status of the exploratory call scheduling (e.g., new, in progress, or done).
* **Exploratory Call Scheduling Notes**: Add any additional notes for the scheduling process.
