# virtual_event_invitation_form - Help Guide
## Purpose
This form is used to collect information for a virtual event.

## How To Complete This Form
1. **Event Title**: Enter a brief title for the event.
2. **Start Date**: Select the date of the event.
3. **Start Time**: Select the start time of the event.
4. **End Date**: Select the date of the end of the event.
5. **End Time**: Select the end time of the event.
6. **Event Location**: Enter the location of the event.
7. **Event Address**: Enter the address of the event location.
8. **Start Time (AM/PM)**: Choose if the start time is AM or PM.
9. **Attendees**: Choose if attendees are invited to the event.
10. **Attendees**: Enter the names of attendees if invited.
11. **Attendee Email**: Enter the email of each attendee.
12. **Attendee Phone**: Enter the phone number of each attendee.
13. **Event Details**: Enter any additional details about the event.
14. **Notes**: Enter any notes about the event.
15. **Appointment Date**: Select the date of the appointment.
16. **Appointment Time**: Select the time of the appointment.
17. **Attendee Message**: Enter a message for the attendee.
18. **Event Date**: Select the date of the event (note: duplicate of start_date).
19. **Event Time**: Select the time of the event (note: duplicate of start_time).
20. **Repeat**: Choose if the event is recurring.
21. **Repeat At**: Select the date of the recurring event.
22. **Repeat Time**: Select the time of the recurring event.
23. **Repeat Frequency**: Choose if the event will repeat.
24. **Repeat Note**: Enter any notes about the recurrence.
25. **Form Submission**: This is for internal use, do not fill in.

## Field-by-Field Explanation
* **Event Title**: A brief title of the event.
* **Start Date**: The date of the event.

* **Appointment Time**: The time of the appointment (note: same as start_time).
* **Attendee Message**: A message for the attendee.
* **Event Date**: Duplicate of start_date (no explanation needed).
