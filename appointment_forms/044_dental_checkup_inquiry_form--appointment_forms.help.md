# Dental Checkup Inquiry Form - Help Guide

## Purpose
This form is used to collect information from patients for their dental checkup inquiries.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in the following fields:
   - Schedule an appointment on [appointment_date] (`appointment_date`): Select the date you'd like to schedule your dental checkup.
   - Time (`appointment_time`): Select the time slot for your appointment.
   - Dentist's name (`dentist_name`): If you have a specific dentist in mind, please let us know their name. If not, we'll assign one for you.
   - Reason for visit (`reason_for_visit`): If you have any specific reason for your visit, please let us know.

2. If you're a dentist or assistant, please fill in your availability:
   - Available days (`available_days`): Select the days you're available to work.
   - Available time (`available_time`): Select the time slot you're available to work.
   - Selected date (`selected_date`): If you've selected a specific date for your patient's visit, please enter it here.
   - Select if you're a (`dentist`, `doctor`, `assistant`): Indicate if you're a dentist, doctor, or assistant.
   - Selected time (`selected_time`): If you've selected a specific time for your patient's visit, please enter it here.

3. If you're a patient, please fill in your details:
   - Full name (`name`): Please enter your full name.
   - Email (`email`): Enter your email address for communication purposes.
   - Patient's name (`patient_name`): If you'd like to specify a different name for your record, please enter it here.
   - Patient's email (`patient_email`): If you'd like to add a different email for your record, please enter it here.
