# Internal Audit Appointment Form - Help Guide
## Purpose
This form is used to schedule and track internal audits within your organization. It provides a structured way to capture information about the audit assignment, including the audit type, start and end dates, assigned user, and notes.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter your name and email address in the "User Input" field.
2. Select the date for the audit using the calendar picker.
3. Enter the time for the audit.
4. Enter the location for the audit.
5. Select the assigned user from the dropdown list.
6. Enter the assigned user's email address.
7. Enter the assigned user's phone number.
8. Enter any additional notes for the assigned user.
9. Select the audit type from the dropdown list.
10. Enter the start and end dates for the audit.
11. Enter the tool or resource assigned to the audit.
12. Enter any additional notes for the audit.
13. Select the submitted status.

## Field-by-Field Explanation

* **User Input** (User Input): Enter your name and email address.
* **Date** (Date): Select the date for the audit.
* **Time** (Time): Enter the time for the audit.
* **Location** (Location): Enter the location for the audit.
* **User Name** (User Name): Enter your name.
* **User Email** (User Email): Enter your email address.
* **User Phone** (User Phone): Enter your phone number.
* **User Notes** (User Notes): Enter any notes for the audit.
* **Assigned User** (Assigned User): Select the assigned user from the dropdown list.
* **Assigned User Label** (Assigned User Label): Enter the label for the assigned user.
* **Assigned User Email** (Assigned User Email): Enter the assigned user's email address.
* **Assigned User Phone** (Assigned User Phone): Enter the assigned user's phone number.
* **Assigned User Notes** (Assigned User Notes): Enter any additional notes for the assigned user.
* **Organization** (Organization): Enter the organization's name.
* **Auditor** (Auditor): Enter the auditor's name.
* **Auditor Label** (Auditor Label): Enter the label for the auditor.
* **Auditor Email** (Auditor Email): Enter the auditor's email address.
* **Auditor Phone** (Auditor Phone): Enter the auditor's phone number.
* **Auditor Notes** (Auditor Notes): Enter any notes for the auditor.
* **Audit Type** (Audit Type): Select the audit type from the dropdown list.
* **Audit Start** (Audit Start): Enter the start date for the audit.
* **Audit End** (Audit End): Enter the end date for the audit.
* **Assigned Tool** (Assigned Tool): Enter the tool or resource assigned to the audit.
* **Notes** (Notes): Enter any additional notes for the audit.
* **Submitted** (Submitted): Select the submitted status.
