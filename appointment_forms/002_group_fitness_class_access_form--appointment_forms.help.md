# Group Fitness Class Access Form - Help Guide
## Purpose
This form is used to select and access group fitness classes. Complete this form to express your interest or availability for a specific class.

## How To Complete This Form
1. Follow the on-screen instructions for each page to complete your answers.
2. Answer each question accurately and thoroughly.
3. Review your answers for accuracy before submitting.

## Field-by-Field Explanation
* **Class Selection**: Select one or more classes from this list. This will help us understand which classes you are interested in joining.
* **Participant Details**: Answer "Yes" for questions where you are able to participate, and "No" for questions where you are not. This will help us understand your individual needs and preferences.
* **Class Dates**: Select a date for a class that you are available to attend.
