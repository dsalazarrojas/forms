# Professional Development Workshop Appointment Form - Help Guide
## Purpose
This form is designed to help you schedule a Professional Development Workshop, which is a structured learning experience focused on enhancing professional skills and knowledge. The form captures essential details to facilitate the planning and coordination of the workshop, ensuring a smooth and successful event.

## How To Complete This Form
To complete this form, follow these steps:

1.  Determine if the workshop is a one-time event or a recurring opportunity. Choose "Yes" or "No" from the "Workshop Type" dropdown list.
2.  Select a date for the workshop using the date field. This will be the day of the event.
3.  Choose a time slot for the workshop using the "Time" field. This will be the start time of the workshop.
4.  Specify the start time of the workshop using the "Start Time" field. This can be further refined from the selected time slot.
5.  Choose the duration of the workshop using the "Duration" field. This is the length of the workshop in hours.
6.  Indicate the number of participants expected to attend the workshop using the "Participants" field.
7.  Enter the room number where the workshop will take place using the "Room Number" field. This is a free-text field for you to input the specific room name or number.
8.  Specify the capacity of the room, i.e., the maximum number of participants it can accommodate, using the "Room Capacity" field.

## Field-by-Field Explanation

* **workshop_type** (Select One):
	+ "Yes": A one-time event, not a series of workshops.
	+ "No": A recurring or series of workshops.
* **Date** (Date):
	+ Enter a date in the format of YYYY-MM-DD.
* **Time** (Time):
	+ Choose a time slot for the workshop in 24-hour format (e.g., 08:00 for 8 am).
* **Start Time** (Time):
	+ Enter the exact start time for the workshop.
* **End Time** (Time):
	+ Enter the exact end time for the workshop.
* **Duration** (Number):
	+ Enter the length of the workshop in hours.
* **Participants** (Number):
	+ Indicate the expected number of participants for the workshop.
* **Room Number** (Text):
	+ Enter the name or number of the room where the workshop will take place.
* **Room Capacity** (Number):
	+ Enter the maximum number of participants the room can accommodate.

Note: If you need help with any of these fields or have questions, please reach out to your workshop coordinator or event planner for assistance.
