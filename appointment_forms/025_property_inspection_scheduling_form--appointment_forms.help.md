# Property Inspection Scheduling Form - Help Guide
## Purpose
The Property Inspection Scheduling Form is used to collect information necessary for scheduling and conducting property inspections. It is a crucial tool for property managers, tenants, or inspection teams to plan and execute inspections efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the **Inspection Request** field to describe the reason for the inspection.
2. Provide the **Tenant Name** if applicable.
3. Enter the **Property Address** where the inspection will take place.
4. Select the date for the **Inspection Date**.
5. Choose the **Inspection Time** for the scheduled inspection.
6. Provide the **Inspector Name** responsible for the inspection, if applicable.
7. Select the **Inspection Type** from the options provided, if necessary.
8. Enter any **Inspection Notes** to provide additional context.
9. Specify the **Preferred Location** for the inspection (e.g., Front Door, Back Door, Side, or Other).
10. Add **Additional Inspection Comments** if needed.
11. Enter the **Property Manager Name**, **Property Manager Phone**, and **Property Manager Email** if applicable.
12. Select the **Inspection Team** responsible for the inspection.
13. Choose the **Inspection Status** from the options provided (e.g., Scheduled, Completed, Rescheduled).
14. Enter the **Inspection Schedule** and **Inspection Start Time**, **Inspection End Time**, and **Scheduled Inspection Start Time**, **Scheduled Inspection End Time** for the scheduled inspection.
15. Specify the **Inspection Duration** and **Total Inspection Time** if necessary.
16. Enter the **Inspection Cost** and **Inspection Cost Currency** if applicable.
17. Finally, enter the **Submission Status** of the form submission.

## Field-by-Field Explanation

* **Inspection Request**: A brief description of the reason for the inspection.
* **Tenant Name**: The name of the tenant or property owner.
* **Property Address**: The address where the inspection will take place.
* **Inspection Date**: The date of the scheduled inspection.
* **Inspection Time**: The time of the scheduled inspection.
* **Inspector Name**: The name of the inspector responsible for the inspection.
* **Inspection Type**: The type of inspection (e.g., routine, emergency, etc.).
* **Inspection Notes**: Additional comments or notes for the inspection.
* **Preferred Location**: The preferred location for the inspection (e.g., Front Door, Back Door, Side, or Other).
* **Additional Inspection Comments**: Any additional comments or information about the inspection.
* **Property Manager Name**: The name of the property manager.
* **Property Manager Phone**: The phone number of the property manager.
* **Property Manager Email**: The email address of the property manager.
* **Inspection Team**: The team responsible for the inspection.
* **Inspection Status**: The status of the inspection (e.g., Scheduled, Completed, Rescheduled).
* **Inspection Schedule**: The schedule for the inspection.
* **Inspection Start Time**: The start time of the inspection.
* **Inspection End Time**: The end time of the inspection.
* **Scheduled Inspection Start Time**: The scheduled start time of the inspection.
* **Scheduled Inspection End Time**: The scheduled end time of the inspection.
* **Inspection Duration**: The duration of the inspection.
* **Total Inspection Time**: The total time of the inspection.
* **Inspection Cost**: The cost of the inspection.
* **Inspection Cost Currency**: The currency of the inspection cost.
* **Submission Status**: The status of the form submission.
