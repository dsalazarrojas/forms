# Real Estate Virtual Tour Appointment Form - Help Guide
## Purpose
This form is designed to help real estate businesses manage virtual tour appointments with potential clients. It collects relevant information from clients, allowing businesses to better understand their needs and preferences.

## How To Complete This Form
1. Select the option for "Potential Clients" to indicate if this form is for a current or future client.
2. Enter the name of your Real Estate Business.
3. Choose a virtual tour time that suits you best.
4. Select a date for the virtual tour.
5. Provide the appointment time.
6. Enter the client's name.
7. Enter the client's email address.
8. Provide the client's contact number.
9. Add any additional notes about the meeting.
10. If you are ready to publish the form, select "Published Form".

## Field-by-Field Explanation
* **Potential Clients**: Select 'Yes' if this form is for a current client, 'No' if for a future client.
* **Real Estate Business**: Enter the name of your real estate business.
* **Virtual Tour Details**: Choose a time for the virtual tour, and make sure it fits your schedule.
* **Virtual Tour Date**: Select a date for the virtual tour. 
* **Appointment Time**: Choose the time slot for the appointment.
* **Client Name**: Enter the name of the client.
* **Client Email**: Enter a valid email address for communication with the client.
* **Contact Number**: Provide the client's contact number for further contact.
* **Notes**: Add any additional notes about the meeting with the client.
* **Published Form**: Select 'Published Form' to make the form visible for clients to fill out. 

**Tips**: Make sure to double-check the virtual tour details, as this information will be visible to the client.
