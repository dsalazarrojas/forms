# Health Screening Appointment Form - Help Guide
## Purpose
This form is used to collect patient information and appointment details for health screenings.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the patient's information (Patient Information page).
2. Select a schedule time for the appointment (Schedule Appointment page).
3. Provide any relevant medical history (Medical History page).
4. Choose the appointment details (Appointment Details page).
5. Select the medical screening to be conducted (Medical Screening page).

## Field-by-Field Explanation

* **Patient Information** (`patient_info`, `text`, required/optional): Provide basic patient information, such as name, address, phone number, and email.
* **Schedule Appointment** (`schedule_appointment`, `select_one`, required/true): Select a time for the appointment from the list (9:00 am, 10:00 am, 11:00 am).
* **Medical History** (`medical_history`, `text`, required/optional): Describe any relevant medical history or allergies.
* **Contact Info** (`contact_info`, `text`, required/optional): Provide any contact information for the patient.
* **Appointment Details** (`appointment_details`, `select_multiple`, required/true): Select all that apply from the list (Option 1, Option 2, Option 3).
* **Medical Screening** (`medical_screening`, `select_one`, required/true): Select a medical screening to be conducted (Option 1, Option 2, Option 3).
* **Appointment Notes** (`appointment_notes`, `note`, required/optional): Any notes or comments regarding the appointment.
* **Next Steps** (`next_steps`, `select_multiple`, required/false): Select all that apply from the list (Option 1, Option 2, Option 3).
* **Follow Up** (`follow_up`, `select_multiple`, required/false): Select all that apply from the list (Option 1, Option 2, Option 3).
* **Medical History Notes** (`medical_history_notes`, `text`, required/optional): Any notes about the patient's medical history.
* **Patient Comments** (`patient_comments`, `text`, required/optional): Any comments from the patient.
* **Provider Notes** (`provider_notes`, `text`, required/optional): Any notes from the healthcare provider.
* **Follow Up Comments** (`follow_up_comments`, `text`, required/optional): Any follow-up comments.
* **Screening Results** (`screening_results`, `text`, required/optional): Any results from the medical screening.
* **Additional Info** (`additional_info`, `text`, required/optional): Any additional information about the patient.
* **Signature** (`signature`, `text`, required/false): Provide a digital signature.
* **Signature Date** (`signature_date`, `date`, required/false): Date of the signature.
* **Signature Time** (`signature_time`, `time`, required/false): Time of the signature.
* **Signature Provider** (`signature_provider`, `text`, required/false): Name of the signature provider.
* **Signature Title** (`signature_title`, `text`, required/false): Title of the signature.
* **Follow Up Time** (`follow_up_time`, `time`, required/false): Time for follow-up.
* **Next Steps Details** (`next_steps_details`, `text`, required/false): Details about next steps.
* **Follow Up Provider** (`follow_up_provider`, `text`, required/false): Name of the follow-up provider.
* **Screening Provider** (`screening_provider`, `text`, required/false): Name of the screening provider.
* **Screening Date** (`screening_date`, `date`, required/false): Date of the screening.

## Tips

* Ensure that all fields are filled out accurately and thoroughly.
* Use clear and concise language when filling out the form.
* Review the form carefully before submitting.
