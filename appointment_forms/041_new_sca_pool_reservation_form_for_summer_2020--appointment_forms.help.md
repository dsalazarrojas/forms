# NEW SCA Pool Reservation Form For Summer 2020 - Help Guide
## Purpose
This form is used to reserve a pool for a specific time period during the summer of 2020. Fill out the form to request a pool reservation for a specified date and time.

## How To Complete This Form
1. Fill out the form with accurate information for each field.
2. Review the "Reservation Status" field before submitting the form.

## Field-by-Field Explanation

* **Pool Reservation Form** (`pool_reservation_form`, text, required/optional): This field should be filled out with any relevant information about the reservation.
* **Pool Name** (`pool_name`, text, required/optional): Enter the name of the pool you would like to reserve.
* **Start Date** (`start_date`, date, required/optional): Select the start date of the reservation period.
* **End Date** (`end_date`, date, required/optional): Select the end date of the reservation period.
* **Capacity** (`capacity`, text, required/optional): Enter the total capacity of the pool during the reservation period.
* **Number of People** (`number_of_people`, number, required/optional): Enter the number of people attending the reservation.
* **Time** (`time`, time, required/optional): Select the time of day for the reservation.
* **Reservation Status** (`reservation_status`, text, required/optional): Select the status of the reservation (e.g. "Reserved", "Cancelled", etc.).
* **Reserved By** (`reserved_by`, text, required/optional): Enter the name of the person reserving the pool.
* **Comments** (`comments`, text, required/optional): Enter any additional comments or notes about the reservation.
