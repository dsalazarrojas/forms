# Gravesite Maintenance Scheduling Request - Help Guide
## Purpose
This form is used to request maintenance for gravesites. Maintenance can include tasks such as grave maintenance, headstone repair, and memorial stone replacement.

## How To Complete This Form
To complete this form, follow these steps:
- Fill out the form completely and accurately.
- Ensure that you have filled out all required fields, indicated by an asterisk (\*) in the label.
- If you're unsure about any field, you can refer to the field-by-field explanation below.

## Field-by-Field Explanation
- **Gravesite Maintenance Scheduling Request** (`gravesite_details`, text, optional): This field is the main description of the maintenance request. Please provide a brief description of the maintenance task you need to be performed.
- **Date Requested** (`date_requested`, date, optional): Select the date you're requesting the maintenance task to be performed. This is not a specific date for the maintenance job to be performed, but rather the date you're submitting the request.
- **Time Requested** (`time_requested`, time, optional): If you have a specific time in mind for the maintenance task, select it here.
- **Service Required** (`service_required`, select_one, optional): Please select the service you're requesting for the gravesite maintenance. Options are:
	+ Maintenance
	+ Decoration
	+ Data Collection
- **Gravesite ID** (`gravesite_id`, number, optional): If you know the gravesite's ID, please provide it to help us locate the gravesite more efficiently.
- **Maintenance Type** (`maintenance_type`, select_multiple, optional): Select all maintenance types that apply to your request. Options are:
	+ Grave Maintenance
	+ Headstone Repair
	+ Memorial Stone Replacement
- **Grave Status** (`grave_status`, select_one, optional): Please select the current status of the gravesite. Options are:
	+ Open
	+ Closed
	+ In Progress
- **Grave Type** (`grave_type`, select_multiple, optional): If the gravesite is for an Adult, Child, or Infant, select the corresponding option(s).
- **Notes** (`notes`, note, optional): Add any additional notes or comments about the maintenance request.
- **Email** (`email`, email, optional): Enter your contact email address if you'd like us to reach out to you about the status of the maintenance task.
- **Phone** (`phone`, text, optional): Enter your phone number if you'd like to be contacted about the status of the maintenance task.
- **Submitter Name** (`submitter_name`, text, optional): Enter your name for your records and ours.
- **Submitter Email** (`submitter_email`, email, optional): Enter your email address for your records and ours.
- **Submitter Phone** (`submitter_phone`, text, optional): Enter your phone number for your records and ours.
- **Submitter Notes** (`submitter_notes`, note, optional): Add any additional comments or information about your request.

## Tips
- Please fill out the form completely and accurately.
- If you have any questions or concerns, contact the gravesite management team or relevant personnel.
- If you need to submit additional requests, please make sure to submit them separately to avoid confusion.
