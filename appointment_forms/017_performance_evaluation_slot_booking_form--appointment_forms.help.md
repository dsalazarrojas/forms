# Performance Evaluation Slot Booking Form - Help Guide
## Purpose
This form is used for booking a performance evaluation slot, which is a specific time slot for a performance evaluation. This form helps to collect information from the user regarding the performance status, slot booking details, reviewer information, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the performance status of the task or project from the dropdown menu on Form Page 1.
2. Provide the slot booking details, including any necessary comments, on Form Page 2.
3. Confirm or deny the booking request for the reviewer on Form Page 3.
4. Select the relevant reviewers for the evaluation on Form Page 4.
5. Choose the method of contact for the reviewer on Form Page 5.
6. Add any additional comments on Form Page 6.
7. Enter the reviewer's email address on Form Page 7.
8. Enter the reviewer's contact method on Form Page 8.
9. Add any additional comments on Form Page 9.
10. Specify the slot duration and set the start and end times on Form Pages 10, 11, and 12.
