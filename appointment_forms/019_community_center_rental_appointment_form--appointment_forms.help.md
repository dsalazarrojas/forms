# Community Center Rental Appointment Form - Help Guide

## Purpose
This form is used to schedule appointments for community center facilities. It is essential to provide accurate and complete information to ensure that the event is properly scheduled and coordinated.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the Requester name field with the name of the person requesting the rental.
2. If the event is for an organization, fill in the Organization name field. Otherwise, leave it blank.
3. Select the date of the event using the calendar picker or type in the date manually.
4. Choose the start and end times for the event.
5. Estimate the approximate number of attendees for the event.
6. Select the facility needed for the event by choosing from the options provided.
7. If any special equipment is required, type it in the Special equipment field.
8. Enter a contact phone number for the day of the event.

## Field-by-Field Explanation

* **Requester name (1)**: The name of the person requesting the rental. This is a required field.
* **Organization name if applicable (2)**: If the event is for an organization, enter the name here. Otherwise, leave it blank.
* **Event date (3)**: The date of the event. Choose from the calendar or type it in manually.
* **Start time (4)**: The start time of the event.
* **End time (5)**: The end time of the event.
* **Expected attendance (6)**: Estimate the approximate number of attendees for the event.
* **Facility required (7)**: Choose the facility needed for the event.
	+ Main hall
	+ Meeting room A
	+ Meeting room B
	+ Outdoor space
* **Special equipment needed (8)**: If any special equipment is required for the event, type it in here.
* **Contact phone number (9)**: Enter a contact phone number for the day of the event.

## Tips

* Please be accurate and complete when filling out this form to ensure that the event is properly scheduled and coordinated.
* If you are unsure about any field, double-check with staff before proceeding.
* Make sure to select the correct facility and equipment needed for the event to avoid any potential issues.
* Enter a contact phone number that can be reached on the day of the event.
