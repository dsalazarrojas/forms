# drama_class_appointment_form - Help Guide
## Purpose
This form is used to schedule a new drama class session.

## How To Complete This Form
To complete this form, please follow the steps below:

- Fill in the required fields: Class Date, Class Start Time, Class End Time, Class Duration, Instructor, and Whether the class is a Workshop or not.

- Optionally, provide the Maximum Enrollments and Maximum Students fields.

- If the class is a workshop, you can optionally provide the Workshop Description and Workshop Location.

## Field-by-Field Explanation
### 1. **Class Date** (`class_date`, Date, Required)
Enter the date of the class.

### 2. **Class Start Time** (`class_start_time`, Time, Required)
Enter the start time of the class.

### 3. **Class End Time** (`class_end_time`, Time, Required)
Enter the end time of the class.

### 4. **Class Duration** (`class_duration`, Text, Required)
Enter the duration of the class.

### 5. **Maximum Enrollments** (`class_max_enroll`, Text, Optional)
Optional field to specify the maximum number of enrollments allowed for the class.

### 6. **Maximum Students** (`class_max_students`, Text, Optional)
Optional field to specify the maximum number of students allowed for the class.

### 7. **Instructor** (`instructor`, Text, Required)
Enter the name of the instructor for the class.

### 8. **Workshop Type** (`workshop_type`, Select One, Required)
Select 'Yes' if the class is a workshop, 'No' otherwise.

### 9. **Workshop Description** (`workshop_description`, Text, Optional)
Optional field to provide a brief description of the workshop.

### 10. **Workshop Location** (`workshop_location`, Text, Optional)
Optional field to specify the location of the workshop.

### 11. **Form Footer** (`form_footer`, Note, Optional)
This is an informational section to be filled by the admin or the instructor.
 
 ## Tips
- Ensure that all required fields are filled before submitting the form.
- Please be as detailed as possible in the optional fields.
