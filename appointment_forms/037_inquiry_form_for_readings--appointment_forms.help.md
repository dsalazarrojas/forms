# Inquiry Form For Readings - Help Guide

## Purpose
This form is used to schedule a reading or inquire about scheduling a reading. Please fill out this form to provide your contact information and preferences for scheduling.

## How To Complete This Form
To complete this form, simply fill out the following fields with your information and preferences.

## Field-by-Field Explanation
* **First Name** (`first_name`, `text`, required: false): Please enter your first name.
* **Last Name** (`last_name`, `text`, required: false): Please enter your last name.
* **Email** (`email`, `email`, required: false): Please enter your email address.
* **Phone** (`phone`, `text`, required: false): Please enter your phone number.
* **Date** (`date`, `date`, required: false): Please select a date for your reading.
* **Time** (`time`, `time`, required: false): Please select a time for your reading.
* **Preferred Time** (`preferred_time`, `time`, required: false): Please select a preferred time for your reading.
* **Message** (`message`, `note`, required: false): Please enter any additional message or comments.
* **Schedule Call Back** (`schedule_call_back`, `select_one`, required: false): Please select whether you would like to schedule a call back.
* **Schedule Call Back Other** (`schedule_call_back_other`, `text`, required: false): If scheduling a call back, please enter the reason why you want to schedule a call back.
* **Schedule Call Back Time** (`schedule_call_back_time`, `time`, required: false): If scheduling a call back, please select a time for the call back.
* **Schedule Call Back Date** (`schedule_call_back_date`, `date`, required: false): If scheduling a call back, please select a date for the call back.
* **Schedule Call Back Email** (`schedule_call_back_email`, `email`, required: false): If scheduling a call back, please enter your email for the call back.
* **Schedule Call Back Phone** (`schedule_call_back_phone`, `text`, required: false): If scheduling a call back, please enter your phone number for the call back.
* **Schedule Call Back Message** (`schedule_call_back_message`, `note`, required: false): If scheduling a call back, please enter any additional message or comments.
* **Available Days** (`available_days`, `select_multiple`, required: false): Please select which days you are available for your reading.
* **Available Time** (`available_time`, `select_multiple`, required: false): Please select which times you are available for your reading.
* **Available Time Range** (`available_time_range`, `select_multiple`, required: false): Please select a time range for your reading.
* **Schedule Call Back 2** (`schedule_call_back_2`, `select_one`, required: false): If scheduling a call back, please select whether you would like to schedule a call back.
* **Schedule Call Back Other 2** (`schedule_call_back_other_2`, `text`, required: false): If scheduling a call back, please enter the reason why you want to schedule a call back.
* **Schedule Call Back Date 2** (`schedule_call_back_date_2`, `date`, required: false): If scheduling a call back, please select a date for the call back.
* **Schedule Call Back Time 2** (`schedule_call_back_time_2`, `time`, required: false): If scheduling a call back, please select a time for the call back.

Note: Some fields are optional, but please fill out as much information as you can to ensure we can better assist you with scheduling your reading.
