# Massage Booking Form - Help Guide
## Purpose
This form is used to book a massage appointment with a therapist. It collects information about the client, massage preferences, and appointment scheduling details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the client's information on the first page.
2. Select the massage type and duration for each appointment on subsequent pages.
3. Choose the therapist for each appointment.
4. Select the appointment date and time for each appointment.
5. Enter any additional notes or comments for each appointment.
6. Enter the client's phone number and email address.

## Field-by-Field Explanation
- **Client Information** (`client_info`, `text`, required: false): Enter the client's name and any other relevant information.
- **Massage Type** (`massage_type`, `select_multiple`, required: false): Select one or more massage types for the appointment (e.g., Massage Oil, Aromatherapy, Deep Tissue, Swedish).
- **Massage Duration** (`massage_duration`, `number`, required: false): Enter the duration of the massage in minutes.
- **Booking Date** (`booking_date`, `date`, required: false): Select the date of the appointment.
- **Booking Time** (`booking_time`, `time`, required: false): Select the time of the appointment.
- **Therapist** (`therapist`, `select_one`, required: false): Choose the therapist for the appointment.
- **Notes** (`notes`, `note`, required: false): Enter any additional comments or notes for the appointment.
- **Phone Number** (`phone`, `text`, required: false): Enter the client's phone number.
- **Email** (`email`, `email`, required: false): Enter the client's email address.
- **Appointment Time** (`appointment_time`, `time`, required: false): Select the time of the appointment.
- **Appointment Date** (`appointment_date`, `date`, required: false): Select the date of the appointment.
- **Massage Duration 2** (`massage_duration_2`, `number`, required: false): Enter the duration of the second massage in minutes.
- **Massage Type 2** (`massage_type_2`, `select_one`, required: false): Select the massage type for the second appointment.
- **Booking Date 2** (`booking_date_2`, `date`, required: false): Select the date of the second appointment.
- **Appointment Time 2** (`appointment_time_2`, `time`, required: false): Select the time of the second appointment.
- **Massage Type 3** (`massage_type_3`, `select_one`, required: false): Select the massage type for the third appointment.
- **Massage Duration 3** (`massage_duration_3`, `number`, required: false): Enter the duration of the third massage in minutes.
- **Booking Time 2** (`booking_time_2`, `time`, required: false): Select the time of the second appointment.
- **Notes 2** (`notes_2`, `note`, required: false): Enter any additional comments or notes for the second appointment.
- **Appointment Date 2** (`appointment_date_2`, `date`, required: false): Select the date of the second appointment.
- **Email 2** (`email_2`, `email`, required: false): Enter the client's email address.
- **Phone 2** (`phone_2`, `text`, required: false): Enter the client's phone number.
- **Appointment Time 3** (`appointment_time_3`, `time`, required: false): Select the time of the third appointment.
- **Appointment Date 3** (`appointment_date_3`, `date`, required: false): Select the date of the third appointment.
- **Therapist 2** (`therapist_2`, `select_one`, required: false): Choose the therapist for the second appointment.
