# Retail Merchandising Appointment Form - Help Guide
## Purpose
This form is used to schedule appointments with merchandising managers for retail store visits.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the time slot for the appointment from the options provided.
2. Choose the merchandising manager(s) you would like to be present during the appointment.
3. Add any notes for the merchandising manager if necessary.
4. Select the retail store to be visited.
5. Choose the sales representative(s) you would like to be present during the appointment.
6. Add any notes for the sales representative if necessary.
7. Enter the email address of the merchandising manager.
8. Enter the phone number of the merchandising manager.

## Field-by-Field Explanation
* **Appointment Time** (`Appointment Time`, select_one): Select the time slot for the appointment from the available options.
* **Merchandising Manager ID** (`Merchandising Manager ID`, select_multiple): Choose the merchandising manager(s) to be present during the appointment.
* **Merchandising Manager Notes** (`Merchandising Manager Notes`, note): Add any notes for the merchandising manager if necessary.
* **Retail Store** (`Retail Store`, select_one): Select the retail store to be visited.
* **Sales Rep ID** (`Sales Rep ID`, select_multiple): Choose the sales representative(s) to be present during the appointment.
* **Sales Rep Notes** (`Sales Rep Notes`, note): Add any notes for the sales representative if necessary.
* **Merchandising Manager Email** (`Merchandising Manager Email`, email): Enter the email address of the merchandising manager.
* **Merchandising Manager Phone** (`Merchandising Manager Phone`, text): Enter the phone number of the merchandising manager.
