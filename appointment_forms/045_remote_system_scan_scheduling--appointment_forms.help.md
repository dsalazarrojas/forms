# Remote System Scan Scheduling - Help Guide
## Purpose
This form collects information for remote system scans to assist with troubleshooting, maintenance, or optimization of systems. It's essential to fill out the form accurately to ensure efficient processing of your request.

## How To Complete This Form
To complete this form, follow these steps:

1. Provide your contact information, including your name and preferred contact method.
2. Describe the scan request details, such as the purpose of the scan and any specific areas of concern.
3. Enter system information, such as the system name, type, and version.
4. If necessary, provide additional information to help with the scan.
5. Double-check your answers and submit the form to schedule the remote system scan.

## Field-by-Field Explanation
* **Contact Information** (Required):
	+ Type: Text input field
	+ Description: Enter your name and preferred contact method (email, phone, or chat) so we can get in touch with you to discuss your scan request.
* **Scan Request Details** (Required):
	+ Type: Text input field
	+ Description: Describe the purpose of the scan and any specific areas of concern you'd like us to focus on during the remote system scan.
* **System Information** (Required):
	+ Type: Text input field
	+ Description: Enter the system name, type, and version to help us identify the system correctly.
* **Additional Information** (Optional):
	+ Type: Text input field
	+ Description: If you have any further details or context about the scan, such as system logs or error messages, please provide them here to help with the process.
* **Scan Results** (Required):
	+ Type: Text input field
	+ Description: After the scan is completed, you'll receive an email with the results. Please check your email for the scan results.
* **Submit** (Required):
	+ Type: Button
	+ Description: Click the submit button to schedule the remote system scan and we'll get in touch with you to discuss further details.
