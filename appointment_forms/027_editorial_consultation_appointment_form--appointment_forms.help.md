# editorial_consultation_appointment_form - Help Guide
## Purpose
This form is used to schedule editorial consultations for a project. It collects information about the project's details, editor involvement, schedule, and status.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the project details:
	* Enter a brief description of the project.
	* Select the relevant editors involved in the project.
2. Schedule the consultation:
	* Choose a date and time for the consultation.
	* Select the duration of the consultation (in minutes or hours).
	* Specify the location of the consultation.
3. Confirm the project status:
	* Select the current status of the project.

## Field-by-Field Explanation
* **Project Title** (`project-title`, text, required): Enter a brief description of the project.
* **Project Description** (`project-description`, text, not required): Enter a more detailed description of the project.
* **Editors Details** (`Editors Details`, select_multiple, required): Select all editors involved in the project.
* **Editor 1** (`editor1`, select_one, not required): Select the first editor involved in the project.
* **Editor 2** (`editor2`, select_one, not required): Select the second editor involved in the project.
* **Editor 3** (`editor3`, select_one, not required): Select the third editor involved in the project.
* **Editor 4** (`editor4`, select_one, not required): Select the fourth editor involved in the project.
* **Schedule Date** (`Schedule Date`, date, required): Choose the date for the consultation.
* **Schedule Time** (`Schedule Time`, time, required): Choose the time for the consultation.
* **Schedule Duration** (`Schedule Duration`, number, required): Specify the duration of the consultation.
* **Schedule Location** (`Schedule Location`, text, required): Specify the location of the consultation.
* **Project Notes** (`Project Notes`, text, not required): Enter any additional notes about the project.
* **Project Status** (`Project Status`, select_one, not required): Select the current status of the project.
* **Submit** (`Submit`, select_one, not required): Confirm submission of the form.
* **Cancel** (`Cancel`, select_one, not required): Cancel the form submission.
* **Schedule Time Hints** (`schedule-time-hints`, text, not required): Enter any hints or additional information about the schedule time.
* **Schedule Duration Hints** (`schedule-duration-hints`, text, not required): Enter any hints or additional information about the schedule duration.
* **Schedule Location Hints** (`schedule-location-hints`, text, not required): Enter any hints or additional information about the schedule location.
* **Project Status Hints** (`project-status-hints`, text, not required): Enter any hints or additional information about the project status.
* **Editors Details Hints** (`editors-details-hints`, text, not required): Enter any hints or additional information about the editors involved.
* **Schedule Date Hints** (`schedule-date-hints`, text, not required): Enter any hints or additional information about the schedule date.
* **Schedule Time Hints** (`schedule-time-hints`, text, not required): Enter any hints or additional information about the schedule time.
