# Equipment Calibration Appointment Request - Help Guide
## Purpose
This form is used to request a calibration appointment for your equipment. Please fill out the form below to submit your request.

## How To Complete This Form
To complete this form, simply select the relevant fields and provide the required information. Please ensure that you have already checked the equipment's calibration schedule to avoid duplicate requests.

## Field-by-Field Explanation
* **Equipment Details (Equipment Details, text, required/optional):** Enter a brief description of the equipment to be calibrated, such as the model number or a short description.
* **Equipment Model (Equipment Model, text, required/optional):** Enter the model number or a brief description of the equipment to be calibrated.
* **Preferred Location (Preferred Location, select_one, required/optional):** Select your preferred location for the calibration appointment from the available options.
* **Date (Date, date, required/optional):** Enter the date you would like to schedule the calibration appointment. Please use the standard date format (DD/MM/YY).
* **Time (Time, time, required/optional):** Enter the time you would like to schedule the calibration appointment. Please use the 24-hour format (HH:MM).
