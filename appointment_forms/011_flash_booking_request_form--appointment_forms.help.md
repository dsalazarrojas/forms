# Flash Booking Request Form - Help Guide
## Purpose
The Flash Booking Request Form is for users to submit a request for an appointment booking for a flash service.

## How To Complete This Form
1. **Fill out the form carefully**: Make sure to enter accurate and complete information to help us process your request efficiently.
2. **Submit the form**: Click the submit button to send your request for review.
3. **Wait for our response**: We will review your request and respond to you within a reasonable time frame.

## Field-by-Field Explanation

* **Service Request (text)**: This is the description of the service you are interested in booking. Please provide a brief description of the service you would like to book.
* **Preferred Booking Time (select_one)**: Please select 'Yes' if you would like to book a specific time for the service, or 'No' if you are flexible with the time.
* **Contact Number (text)**: This is your contact number where we can reach out to you for further information or to confirm your booking details. Please enter a valid contact number.

## Tips

* Please note that this form is optional, but if you would like to book a service, filling out this form will help us process your request faster.
* Make sure to provide accurate and complete information to ensure that your request is processed efficiently.
