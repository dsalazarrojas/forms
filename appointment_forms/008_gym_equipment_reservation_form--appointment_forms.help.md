# gym_equipment_reservation_form - Help Guide
## Purpose
The gym equipment reservation form is used to collect information for reserving gym equipment, allowing users to reserve equipment and schedule time slots.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the reservation date for the equipment you wish to reserve.
2. Choose the equipment you would like to reserve from the provided options.
3. Select the time slot you would like to reserve the equipment for.
4. Add any additional notes if necessary.
5. Select the user who will be using the reserved equipment.
6. Select the tool(s) assigned to the user (if any).
7. Submit the form to complete the reservation.

## Field-by-Field Explanation
* **Reservation Date** (Reservation Date, date, required/optional): This field is used to select the date of the reservation. Please choose a date in the format of YYYY-MM-DD.
* **Equipment ID** (equipment_id, select_one, required/optional): Choose the equipment you would like to reserve from the options provided.
* **Time Slot** (time_slot, select_multiple, required/optional): Select the time slot you would like to reserve the equipment for. You can choose multiple time slots if necessary.
* **Notes** (notes, note, required/optional): This field is used for adding any additional comments or notes about the reservation.
* **Assigned User** (assigned_user, select_one, required/optional): Select the user who will be using the reserved equipment.
* **Assigned Tool** (assigned_tool, select_one, required/optional): If any tools are assigned to the selected user, choose them from the options provided.
