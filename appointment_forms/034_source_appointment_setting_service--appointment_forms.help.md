# Source Appointment Setting Service - Help Guide

## Purpose
This form is used to set up appointments for service providers, it allows you to choose from different options for each page, making it easy to customize the appointment settings according to your needs.

## How To Complete This Form
To complete the form, go through each page carefully and fill out the required fields. Start from the first page and navigate through the pages as indicated by the navigation buttons.


## Field-by-Field Explanation

* **Choose a Campaign** (`campaign_name`, select_one, required: false): On this page, select the campaign you are interested in from the options provided.
* **Select a Service** (`service_option`, select_multiple, required: false): Choose one or more services you need for the appointment.
* **Select a Service Date** (`service_option_date`, date, required: false): Select the date for the service you have chosen.
* **Select a Service Time** (`service_option_time`, time, required: false): Choose the time for the service.
* **Note** (`note`, note, required: false): Add any additional notes or information about the appointment.
* **Email** (`email`, email, required: false): Enter the email address of the person scheduling the appointment.
* **Phone** (`phone`, text, required: false): Enter the phone number of the person scheduling the appointment.
* **Additional Information** (`note_1`, note, required: false): Add any additional information about the appointment.
* **Contact Person's Email** (`email_1`, email, required: false): Enter the email address of the contact person.
* **Contact Person's Phone** (`phone_1`, text, required: false): Enter the phone number of the contact person.
* **Campaign** (`campaign_name`, select_one, required: false): This field is identical to the first page, choose from the provided options.
