# credit_strategy_session_registration - Help Guide
## Purpose
The credit strategy session registration form is designed to collect essential information for scheduling a credit strategy session. This form is used to provide details necessary for a credit strategist to schedule a session with the user.

## How To Complete This Form
1.  To complete this form, start by selecting a date for the session using the "Schedule Session" field.
2.  Next, choose the type of session you require using the "Select Session Type" field.
3.  Then, choose the date and time for the session using the "Select Session Date" and "Select Session Time" fields.
4.  After that, select the professional you wish to schedule the session with using the "Select Professional" field.
5.  Select the location for the session using the "Select Location" field.
6.  Enter your email address using the "Email" field.
7.  Enter your phone number using the "Phone" field.
8.  Finally, confirm your email and phone number using the "Confirm Email" and "Confirm Phone" fields.

## Field-by-Field Explanation
* **Schedule Session** (1, date, required: false): This field is used to select a date for the session. Please choose a date from the calendar provided or enter a date in the format MM/DD/YYYY.
* **Select Session Type** (2, select_one, required: false): This field is used to choose the type of session you require. Please select one of the available options.
* **Select Session Date** (3, select_multiple, required: false): This field is used to choose the date and time for the session. Please select one or more dates and times from the provided options.
* **Select Session Time** (4, select_one, required: false): This field is used to choose the time for the session. Please select one of the available options.
* **Session Details** (5, note, required: false): This field is a free-text area for you to provide any additional information about the session.
* **Select Professional** (6, select_one, required: false): This field is used to choose the professional who will be leading the session. Please select one of the available options.
* **Select Location** (7, select_one, required: false): This field is used to select the location for the session. Please select one of the available options.
* **Email** (8, email, required: false): This field is used to enter your email address. Please enter your email address in the format you@yourcompany.com.
* **Phone** (9, text, required: false): This field is used to enter your phone number. Please enter your phone number in the format XXX-XXX-XXXX.
* **Confirm Email** (10, email, required: false): This field is used to confirm your email address. Please enter the same email address as in the "Email" field.
* **Confirm Phone** (11, text, required: false): This field is used to confirm your phone number. Please enter the same phone number as in the "Phone" field.
