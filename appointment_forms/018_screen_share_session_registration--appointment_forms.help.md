# Screen Share Session Registration - Help Guide
## Purpose
The "Screen Share Session Registration" form is used to register a new screen share session. This form captures essential details about the session, including session topic, start time, duration, and other relevant information. It's essential to complete this form accurately to ensure a successful screen share session.

## How To Complete This Form
To complete this form, follow these steps:

1.  Enter the Session Topic in the text field provided. This field is required to help the session participants identify the topic of the session.
2.  Choose the Session Topic Type (video, meeting, or presentation) from the dropdown menu. This field is optional and helps the session organizer categorize the session type.
3.  Select the Session Topic Category (IT, Saas, or Education) from the dropdown menu. This field is also optional and helps the session organizer categorize the session category.
4.  Choose the Session Topic Subcategory (consulting, support, or tutorial) from the dropdown menu. This field is optional and helps the session organizer further categorize the session type.
5.  If you're assigning the session to a specific person, select their name (ChatJimmy, or Other) from the dropdown menu. This field is optional and helps the session organizer know who the session is assigned to.
6.  Enter the Start Time for the session using the time field. This field is required to schedule the session.
7.  Enter the duration of the session using the number field. This field is required to ensure the session duration.
8.  Enter the End Time for the session using the time field. This field is required to determine the session end time.
9.  Enter the Screen URL for the session. This field is required to share the screen URL.
10. Add any Session Notes you want to include in the session registration.
11. Enter the Screen Share URL for the session. This field is optional but required if the session requires screen sharing.
12. Enter the Screen Share Password for the session. This field is optional but required if the session requires screen sharing.
13. Indicate if Session Participants are present using the select multiple field. This field is optional but helps the session organizer know if participants are present.
14. If you want to send reminders, indicate if you want to send reminders at specific times.
15. If you want to schedule the session for a specific time, select the Scheduled Time using the time field.
16. Select the Session Status (pending, accepted, or completed) using the dropdown menu. This field is optional but helps the session organizer track the session status.
17. Add any Session Comments you want to include in the session registration.
18. Select if the session Agreed Terms are accepted.
19. Enter the Terms Version number if applicable.
20. Enter the Screen Share Token for the session. This field is optional but required if the session requires screen sharing.

## Field-by-Field Explanation

* **Session Details**: Enter a brief description of the session.
* **Session Topic**: Enter a brief description of the session topic.
* **Start Time**: Enter the start time of the session.
* **Duration**: Enter the duration of the session.
* **End Time**: Enter the end time of the session.
* **Screen URL**: Enter the URL of the screen share session.
* **Session Notes**: Add any additional notes for the session.
* **Screen Share URL**: Enter the URL of the screen share session.
* **Screen Share Password**: Enter the password for the screen share session.
* **Session Participants**: Indicate if session participants are present.
* **Session Topic Type**: Select the type of session topic (video, meeting, or presentation).
* **Session Topic Category**: Select the category of the session topic (IT, Saas, or Education).
* **Session Topic Subcategory**: Select the subcategory of the session topic (consulting, support, or tutorial).
* **Assigned to**: Select the person assigned to the session.
* **Scheduled For**: Select the date and time for the session.
* **Reminder**: Indicate if you want to send reminders.
* **Reminders At**: Select the specific time for reminders.
* **Reminders Time**: Enter the time for reminders.
* **Session Status**: Select the status of the session (pending, accepted, or completed).
* **Session Comments**: Add any additional comments for the session.
* **Agreed Terms**: Select if the session agreed terms are accepted.
* **Terms Version**: Enter the terms version number.
* **Screen Share Token**: Enter the screen share token for the session.
