# Real Estate Project Appointment Request - Help Guide
## Purpose
This form is for requesting an appointment for a real estate project. It is designed to gather essential information from the user to schedule an appointment with a real estate agent. The form is typically used by potential clients to schedule meetings with agents to discuss project details.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out the form with the required information.
2. Select the real estate agent from the list.
3. Choose the appointment details (if applicable).
4. Select the time slot for the appointment.
5. Enter the start and end dates for the appointment.
6. Choose the location(s) for the appointment (if applicable).
7. Enter any additional notes about the appointment.
8. Confirm that you want to send a contact request to the real estate agent.

## Field-by-Field Explanation
* **Contact Info** (`contact_info`, text, required): Enter your name, email, and phone number to ensure the real estate agent can contact you.
* **Real Estate Agent** (`real_estate_agent`, select_one, optional): Select the real estate agent you would like to schedule an appointment with. If left blank, a default agent will be assigned.
* **Appointment Details** (`appointment_details`, select_multiple, optional): Select any additional details about the appointment, such as specific rooms or features to be discussed.
* **Time Slot** (`time_slot`, date, required): Select the date and time for the appointment.
* **Start Date** (`start_date`, date, required): Enter the start date of the appointment.
* **End Date** (`end_date`, date, required): Enter the end date of the appointment.
* **Time Slot** (`time_slot`, time, required): Select the time of day for the appointment.
* **Location** (`location`, select_multiple, optional): Choose the location(s) where the appointment will take place (if applicable).
* **Appointment Notes** (`appointment_notes`, note, optional): Enter any additional notes about the appointment.
* **Contact Request** (`contact_request`, text, required): Confirm that you want to send a contact request to the real estate agent.
* **Message** (`message`, text, required): Enter a brief message to the real estate agent.
