# shipping_documentation_appointment_form - Help Guide

## Purpose
This form is used to create or manage shipping documentation appointments.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form to ensure you have all the necessary information before starting.
2. Fill in the required fields:
	* **Shipper Name**: Enter the name of the shipper.
	* **Contact Person**: Enter the name of the contact person associated with the shipper.
	* **Contact Number**: Enter the contact number of the contact person.
	* **Email Address**: Enter the email address of the contact person.
	* **Shipper Type**: Select the type of shipper (e.g., shipper 1, shipper 2, or shipper 3).
	* **Documentation Date**: Enter the date for the shipping documentation.
	* **Start Time**: Enter the start time of the appointment.
	* **End Time**: Enter the end time of the appointment.
3. The **Notes** field is optional and can be used to capture any additional information about the appointment.
4. Enter the **Assigned User** who will be handling the shipping documentation appointment.

## Field-by-Field Explanation

* **Shipper Name (shipper_name)** (`text`, required): Enter the name of the shipper.
* **Contact Person (contact_person)** (`text`, required): Enter the name of the contact person associated with the shipper.
* **Contact Number (contact_number)** (`number`, required): Enter the contact number of the contact person.
* **Email Address (email_address)** (`email`, required): Enter the email address of the contact person.
* **Shipper Type (shipper_type)** (`select_one`, required): Select the type of shipper (e.g., shipper 1, shipper 2, or shipper 3).
* **Documentation Date (documentation_date)** (`date`, required): Enter the date for the shipping documentation.
* **Start Time (start_time)** (`time`, required): Enter the start time of the appointment.
* **End Time (end_time)** (`time`, required): Enter the end time of the appointment.
* **Notes (notes)** (`note`, optional): Enter any additional information about the appointment.
* **Assigned User (assigned_user)** (`text`, required): Enter the user who will be handling the shipping documentation appointment.

## Tips

* Ensure all required fields are completed before submitting the form.
* Double-check the information entered, especially for dates and times.
* Use the **Notes** field to capture any additional relevant information.
* Review the form carefully before submitting it to ensure all necessary information is included.
