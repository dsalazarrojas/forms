# executive_lunch_appointment_form - Help Guide
## Purpose
This form is used to request an executive lunch meeting. It helps to provide necessary information for the meeting, which will be sent to the executive team for review and scheduling.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the meeting request section with a brief description of the meeting purpose.
2. Select a specific date for the meeting.
3. Choose a specific time for the meeting.
4. Choose a meeting venue, if applicable.
5. Indicate if the meeting will have attendees.
6. Specify the meeting subject.

## Field-by-Field Explanation
* **Meeting Request** (`meeting_request`, text, optional): Enter a brief description of the meeting purpose. Please provide enough information so that the executive team can properly review and schedule the meeting.
* **Meeting Date** (`meeting_date`, date, optional): Select the date for which you would like to schedule the meeting.
* **Meeting Time** (`meeting_time`, time, optional): Choose the time for the meeting. Please be aware that meeting schedules can be busy, so be flexible with time options.
* **Meeting Venue** (`meeting_venue`, text, optional): If the meeting will take place in a specific location, enter the venue name.
* **Attendees** (`attendees`, select_multiple, optional): Check if the meeting will have attendees. If yes, please list the attendees.
* **Meeting Subject** (`meeting_subject`, text, optional): Enter a brief description of the meeting subject. Please make sure it's not already on the calendar before submitting this form.

## Tips
* Be concise and clear in filling out this form to ensure that the meeting request is properly documented and reviewed by the executive team.
* Make sure to review the form before submitting it to catch any errors or missing information.
* If you are unsure about any field, you can contact the executive assistant for assistance.
