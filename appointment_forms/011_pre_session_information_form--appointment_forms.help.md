# Pre Session Information Form - Help Guide
## Purpose
This form collects essential information from participants before a session, providing the session facilitator with valuable insights into their preferences, interests, and details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your **Participant Name** in the "Participant Name" field. This is a required field.
2. Provide your **Email** address in the "Email" field. This is a required field.
3. Enter your **Phone** number in the "Phone" field. This is a required field.
4. Select your **Preferred Language** from the dropdown menu. This is a required field.
5. If you have any additional **Participant Details**, you can provide them in the "Participant Details" field (note-taking area). This field is optional.
6. Select your **Participant Interests** from the list of options provided. You can select multiple interests. This field is optional.
7. If you have any additional notes or information about yourself, you can type them in the "Participant Notes" field (note-taking area). This field is optional.

## Field-by-Field Explanation
* **Participant Name** (id: 1, text, required): Enter the name of the participant.
* **Email** (id: 2, email, required): Enter the participant's email address.
* **Phone** (id: 3, text, required): Enter the participant's phone number.
* **Preferred Language** (id: 4, select_one, required): Select the participant's preferred language from the list of options.
* **Participant Details** (id: 5, note, optional): Provide any additional details about the participant.
* **Participant Interests** (id: 6, select_multiple, optional): Select the participant's interests from the list of options.
* **Participant Notes** (id: 7, note, optional): Type any additional notes or information about the participant.

## Tips
* Please ensure that the information provided is accurate and up-to-date.
* If you have any questions or concerns, do not hesitate to contact us.
* If you need to make any changes or updates to your information, please let us know so we can assist you.
