# Workplace Hazard Assessment Appointment Form - Help Guide
## Purpose
The Workplace Hazard Assessment Appointment Form is a tool used to identify and assess potential hazards and risks that employees may be exposed to on the job. The form is designed to gather essential information about the job, employee, and assessment methods to help create a safe working environment.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant information for the selected job type.
2. Choose the correct date for the assessment.
3. Choose the correct time for the assessment.
4. Enter the employee's job title.
5. Enter the employee's name and ID number.
6. Select whether the job requires a specific type of assessment (yes or no).
7. Select the work location (yes or no).

## Field-by-Field Explanation
* **Appointment Form**: This field is where you input any relevant information for the selected job type.
* **Date**: Enter the date on which the assessment will take place. Please format the date as MM/DD/YYYY (month/day/year).
* **Time**: Enter the time on which the assessment will take place. Please format the time as HH:MM (hour/minute).
* **Job Title**: Enter the title of the employee's job.
* **Employee Name**: Enter the name of the employee being assessed.
* **Employee ID**: Enter the ID number of the employee being assessed.
* **Job Type**: Select "yes" if the job requires a specific type of assessment, otherwise select "no".
* **Work Location**: Select "yes" if the job involves work at a different location, otherwise select "no".
* **Assessment Method**: Select all the assessment methods that apply to the job. Please select "yes" for each method that is applicable to the job. 

## Tips
* Ensure you are filling out the form for every job type to get a comprehensive assessment.
* Double-check your answers to ensure accuracy and completeness.
* If the job requires a specific type of assessment, make sure to select that option.
* If the job involves work at a different location, select the "Yes" option for Work Location.
