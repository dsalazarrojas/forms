# Vastu Consultation Request - Help Guide
## Purpose
The Vastu Consultation Request form is used by Vastu agents to request a consultation with a client regarding a property. This form helps agents to schedule and coordinate meetings with clients, allowing for more efficient communication and better service.

## How To Complete This Form
1. Fill out the form with the relevant property details.
2. Specify the concerns or issues with the property that you would like to discuss during the consultation.
3. Select the preferred time for the consultation (morning, afternoon, or evening).
4. Choose the type of property that the consultation is regarding (house, apartment, townhouse, or duplex).
5. Select the method of contact for the consultation (phone, email, or video call).
6. Enter the name and contact information of the person to be contacted.
7. Enter the phone number of the person to be contacted.

## Field-by-Field Explanation
* **Property Details**: This field is used to enter the details of the property that you would like to discuss during the consultation. Please be as specific as possible about the property's location, size, and any other relevant features.
* **Concerns**: This field is used to specify any issues or concerns that you have about the property. Please list these concerns clearly and concisely.
* **Appointment Time**: This field is used to select the preferred time for the consultation. Please choose from the options morning, afternoon, or evening.
* **Preferred Time**: This field is used to select a more specific time for the consultation. Please choose from the options morning, afternoon, or evening. Note that this field is not a requirement.
* **Property Type**: This field is used to specify the type of property that the consultation is regarding. Please choose from the options house, apartment, townhouse, or duplex.
* **Contact Method**: This field is used to select the method of contact for the consultation. Please choose from the options phone, email, or video call.
* **Contact Person**: This field is used to enter the name of the person to be contacted.
* **Contact Phone**: This field is used to enter the phone number of the person to be contacted.

## Tips
* Make sure to fill out the form as accurately and completely as possible.
* Double-check that you are not duplicating a request for the same property.
* If you are unsure about any of the fields, please reach out to your supervisor or team lead for clarification.
* The form is designed to be completed in a few minutes, so please take your time and fill it out carefully.
