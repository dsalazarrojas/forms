# Event Promotion Consultation Booking Form - Help Guide
## Purpose

This form is used for booking and planning promotional events. It collects information about the event's details, dates, times, and organizers to ensure smooth event promotion.

## How To Complete This Form

1. Review the form carefully before filling it out.
2. Fill out each field with accurate information about the event.
3. Ensure all required fields are completed before submitting the form.

## Field-by-Field Explanation

* **Event Details** (`event_promotion_consultation_booking_form_event_details`):
  * A brief description of the event.
* **Event Date** (`event_promotion_consultation_booking_form_event_date`):
  * The date of the event.
* **Event Start Time** (`event_promotion_consultation_booking_form_event_start_time`):
  * The start time of the event.
* **Event End Time** (`event_promotion_consultation_booking_form_event_end_time`):
  * The end time of the event.
* **Event Location** (`event_promotion_consultation_booking_form_event_location`):
  * The location of the event.
* **Event Organizer** (`event_promotion_consultation_booking_form_event_organizer`):
  * The person or organization responsible for organizing the event.
* **Event Agency** (`event_promotion_consultation_booking_form_event_agency`):
  * The agency or company associated with the event.
* **Booking Details** (`event_promotion_consultation_booking_form_booking_details`):
  * Any additional details about the event booking process.
* **Consultation Date** (`event_promotion_consultation_booking_form_consultation_date`):
  * The date of the consultation or discussion about the event.
* **Consultation Start Time** (`event_promotion_consultation_booking_form_consultation_start_time`):
  * The start time of the consultation or discussion.
* **Consultation End Time** (`event_promotion_consultation_booking_form_consultation_end_time`):
  * The end time of the consultation or discussion.
* **Agency Details** (`event_promotion_consultation_booking_form_agency_details`):
  * Additional details about the agency or company associated with the event.
* **Contact Person** (`event_promotion_consultation_booking_form_contact_person`):
  * The person to contact for more information about the event.
* **Phone** (`event_promotion_consultation_booking_form_phone`):
  * The phone number of the contact person.
* **Email** (`event_promotion_consultation_booking_form_email`):
  * The email address of the contact person.
* **Message** (`event_promotion_consultation_booking_form_message`):
  * Any further information or messages about the event.

## Tips

* Double-check the accuracy of all input fields before submitting the form.
* Make sure all required fields are completed before submitting the form.
* If you need help with any field, don't hesitate to reach out to the event organizer or contact person.
