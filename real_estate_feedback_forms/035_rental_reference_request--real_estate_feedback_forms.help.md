# Rental Reference Request - Help Guide
## Purpose
The Rental Reference Request form is designed to collect information from real estate professionals and property owners to provide details about a rental property that a potential tenant or renter is inquiring about.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill in your name and phone number in the "Applicant Name" and "Applicant Phone" fields.
2. Provide the name of the property owner or landlord company.
3. Enter the phone number of the property owner or landlord.
4. Provide the physical address of the rental property.
5. If you are affiliated with a rental agency, please enter their name in the "Rental Agency" field.
6. If applicable, provide the name and contact information for the property manager.
7. Enter the date you started renting the property.

## Field-by-Field Explanation
* **Rental Reference Request Form**: This is a text field where you can enter any additional information about the rental property.
* **Applicant Name**: This is your name, as the person submitting the request.
* **Applicant Phone**: This is your phone number, for follow-up communication.
* **Landlord Company**: This is the name of the company or person managing the rental property.
* **Landlord Phone**: This is the phone number of the landlord or property manager.
* **Landlord Address**: This is the physical address of the rental property.
* **Rental Agency**: If you are a representative of a rental agency, please enter their name.
* **Property Manager**: If you are the property manager, enter your name and contact information.
* **Property Address**: This is the physical address of the rental property.
* **Rent Start Date**: This is the date you started renting the property.

## Tips
* Be as specific as possible when providing information about the rental property.
* If you have any further questions or need assistance, please contact us.
