# Property Renovation Quality Survey - Help Guide
## Purpose
The Property Renovation Quality Survey is a form designed to collect feedback from users about the quality of a property renovation. The data collected will help the property management team make data-driven decisions to improve the customer experience.

## How To Complete This Form
1. Review each page carefully and answer the questions to the best of your ability.
2. Select the correct options for each question.
3. Complete all required fields (indicated by a red asterisk \*).
4. Submit the form once you have finished.

## Field-by-Field Explanation

### Page 1: Home Page
* **Home Page** (`property_renovation_quality_survey_page_1`, `note`, not required): This page serves as an introduction to the survey.
* **Page 2** (`property_renovation_quality_survey_page_2`, `select_multiple`, not required): Select all that apply to describe your experience with the property's renovation process.
	+ Option 1: The renovation process was well-organized.
	+ Option 2: The renovation process was not well-organized.
* **Page 3** (`property_renovation_quality_survey_page_3`, `select_one`, not required): Select the best description of your experience with the property's renovation process.
	+ Option 1: The renovation was completed ahead of schedule.
	+ Option 2: The renovation was completed on schedule.
	+ Option 3: The renovation was completed behind schedule.
* ...
* **Page 25** (`property_renovation_quality_survey_page_25`, `select_multiple`, not required): Select all that apply to describe your experience with the property's renovation process.
	+ Option 1: The property's renovation met my expectations.
	+ Option 2: The property's renovation did not meet my expectations.
