# Training Records Access Form - Help Guide
## Purpose
The purpose of this form is to provide access to training records for employees.

## How To Complete This Form

To complete this form, follow these steps:

*   Enter your Employee Id number, which is unique identifier for you as an employee.
*   Select whether the employee is currently enrolled in a training program.
*   If the employee is enrolled, select the Start Date of the training program.
*   Choose the current status of the training program (Active or Inactive).
*   Add any comments from your manager about the training program (optional).

## Field-by-Field Explanation

*   **Employee Id**: Enter your Employee Id number, which is a unique identifier for you as an employee.
    *   Type: number
*   **Training Program**: Select whether the employee is currently enrolled in a training program.
    *   Type: select_one
*   **Start Date**: If the employee is enrolled, enter the Start Date of the training program.
    *   Type: date
*   **Training Status**: Choose the current status of the training program (Active or Inactive).
    *   Type: select_multiple
*   **Manager Comments**: Add any comments from your manager about the training program (optional).
    *   Type: text

## Tips
*   Ensure that you have the necessary permissions to access training records before completing this form.
*   If you are unsure about any information, please consult with the HR administrator.
