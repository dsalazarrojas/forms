# Scouting Recruitment Form - Help Guide
## Purpose
The Scouting Recruitment Form is designed to help units gather and organize necessary information for the scouting recruitment process.

## How To Complete This Form
1. Fill in the unit's ID and name in the respective fields. These are required fields.
2. Provide a brief description of the unit's scouting recruitment plan.
3. If applicable, fill in the contact information and contact email for the unit.
4. Choose the unit's type from the select one options.
5. Select the unit's level from the select multiple options.
6. If the unit has a specific recruitment goal, describe it in the recruitment goal field.
7. Specify the target start and end dates for the recruitment campaign.
8. Provide dates for any events related to the recruitment campaign.
9. Add any additional notes about the recruitment campaign.
10. Select the scouting recruiters for the unit from the select one options.
11. If other recruiters are needed, provide their names in the other recruiters field.
12. If the unit has an officer, select the corresponding option.
13. If a flyer is needed, select the appropriate option from the select multiple options.

## Field-by-Field Explanation
- **What is the unit's scouting recruitment plan?** (1) - This field is used to describe the unit's scouting recruitment plan. Please provide a brief description of the plan.
- **Unit ID** (2) - This is a required field that must be filled in with the unit's ID.
- **Unit name** (3) - This is a required field that must be filled in with the unit's name.
- **Unit contact information** (4) - This field is used to provide contact information for the unit.
- **Unit contact email** (5) - This field is used to provide the unit's contact email.
- **Unit type** (6) - This field is used to select the unit's type. Please choose from the select one options.
- **Unit level** (7) - This field is used to select the unit's level. Please choose from the select multiple options.
- **Recruitment goal** (8) - This field is used to describe the unit's recruitment goal if applicable.
- **Target start date** (9) - This field is used to specify the target start date for the recruitment campaign.
- **Target end date** (10) - This field is used to specify the target end date for the recruitment campaign.
- **Dates for events** (11) - This field is used to provide dates for events related to the recruitment campaign.
- **Notes** (12) - This field is used to add any additional notes about the recruitment campaign.
- **Scouting recruiters for the unit** (13) - This field is used to select the scouting recruiters for the unit. Please choose from the select one options.
- **Other scouting recruiters** (14) - This field is used to provide other scouting recruiters' names if needed.
- **Unit officer** (15) - This field is used to indicate if the unit has an officer. Please select from the select one options.
- **Do you need a flyer?** (16) - This field is used to ask if a flyer is needed for the recruitment campaign. Please select from the select multiple options.
