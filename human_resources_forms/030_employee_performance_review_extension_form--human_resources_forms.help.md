# Employee Performance Review Extension Form - Help Guide

## Purpose
The purpose of this form is to facilitate the performance review process by allowing reviewers to provide an updated evaluation of an employee's performance, extend the review timeline if necessary, and document feedback.

## Field-by-Field Explanation

*   *Job Title* (`Job Title`, text, optional): Enter the employee's current job title.
*   *Employee Rating* (`Employee Rating`, select_one, optional): Select the employee's performance rating using one of the following options: 1 - Excellent, 2 - Good, 3 - Fair, 4 - Poor, 5 - Unsatisfactory.
*   *Date Last Review* (`Date Last Review`, date, optional): Enter the date of the last performance review.
*   *Next Review Date* (`Next Review Date`, date, optional): If necessary, enter the expected date of the next performance review.
*   *Employee Name* (`Employee Name`, text, optional): Enter the employee's name.
*   *Reviewer Name* (`Reviewer Name`, text, optional): Enter your name and title.
*   *Feedback* (`Feedback`, note, optional): Provide any additional feedback or comments about the employee's performance.
 
## Tips
- Ensure that the form is completed accurately and thoroughly.
