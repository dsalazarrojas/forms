# performance_review_audit_form - Help Guide
## Purpose
The performance Review Audit Form is used to conduct a thorough performance review of an employee's work, ensuring fair and consistent feedback and guidance from managers.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form and ensure you have all necessary information and attachments required.
2. Fill out the form with accurate and honest feedback as an employee.
3. Review and sign the form as a manager, ensuring all necessary sections are completed.
4. Attach any supporting documents or attachments as required.
5. Submit the form to your manager or HR representative for review and approval.

## Field-by-Field Explanation

* **Performance Review** (`performance_review`, `text`, not required): This section is for the manager to describe the employee's performance over the review period. Please provide a thorough and honest evaluation of the employee's work.
* **Employee Name** (`employee_name`, `text`, not required): This section is for the employee to enter their name.
* **Manager Name** (`manager_name`, `text`, not required): This section is for the manager to enter their name.
* **Review Period** (`review_period`, `select_one`, not required): Select the review period covered by this performance review (e.g., Q1, Q2, Q3, Q4).
* **Employee ID** (`employee_id`, `text`, not required): This section is for the employee to enter their ID number.
* **Evaluation Date** (`evaluation_date`, `date`, not required): This section is for the manager to enter the date of the evaluation.
* **Performance Score** (`performance_score`, `number`, not required): This section is for the manager to enter the employee's performance score out of a maximum of 100.
* **Development Areas** (`development_areas`, `text`, not required): This section is for the manager to list areas where the employee needs development or improvement.
* **Feedback** (`feedback`, `text`, not required): This section is for the manager to provide feedback to the employee.
* **Action Plan** (`action_plan`, `text`, not required): This section is for the manager to outline actions the employee can take to improve their performance.
* **Signed By** (`signed_by`, `text`, not required): This section is for the manager to enter their name as the person signing the performance review.
* **Signature Date** (`signature_date`, `date`, not required): This section is for the manager to enter the date they signed the performance review.
* **Signed By Title** (`signed_by_title`, `text`, not required): This section is for the manager to enter their title.
* **Signature** (`signature`, `note`, not required): This section is for the manager to sign the performance review.
* **Review Status** (`review_status`, `select_multiple`, not required): Select the status of the review (Active or Inactive).
* **Comments** (`comments`, `text`, not required): This section is for the manager to add any additional comments about the performance review.
* **Attachments** (`attachments`, `text`, not required): This section is for the manager to attach any supporting documents or files.
