# Job Interview Portfolio Checklist - Help Guide
## Purpose
The purpose of this form is to collect and record information about a job interview, including details about the candidate, the job, and the interview process.

## How To Complete This Form
To complete this form, simply follow the instructions below:

1. Start by entering the candidate's information, including any relevant background details.
2. Provide information about the interview, including the location, date, and time.
3. Select the job type and enter any required details about the job.
4. Evaluate the candidate's performance using the evaluation scale provided.
5. Add any comments or recommendations about the candidate.
6. Enter any additional notes about the candidate.

## Field-by-Field Explanation
* **Candidate Info** (`candidate_info`, optional): Enter the candidate's name, email, and any other relevant contact information.
* **Interview Info** (`interview_info`, optional): Enter a brief description of the interview.
* **Job Info** (`job_info`, optional): Enter any details about the job, including the job title and description.
* **Evaluation** (`evaluation`, optional): Evaluate the candidate's performance using the scale provided.
* **Recommendations** (`recommendations`, optional): Add any recommendations for the candidate.
* **Comments** (`comments`, optional): Enter any additional comments about the candidate.
* **Candidate Notes** (`candidate_notes`, optional): Enter any additional notes about the candidate.
* **Evaluation Scale** (`evaluation_scale`, optional): Select the evaluation scale for the candidate's performance.
* **Evaluation Scale 2** (`evaluation_scale_2`, optional): Select a secondary evaluation scale (if necessary).
* **Job ID** (`job_id`, optional): Enter the job ID number for the job being interviewed for.
* **Job Title** (`job_title`, optional): Enter the title of the job.
* **Job Description** (`job_description`, optional): Enter a brief description of the job.
* **Job Type** (`job_type`, required): Select the type of job (e.g. Full Time, Part Time, Contract, or Intern).
* **Interview Location** (`interview_location`, optional): Enter the location of the interview.
* **Interview Date** (`interview_date`, optional): Enter the date of the interview.
* **Interview Time** (`interview_time`, optional): Enter the time of the interview.
* **Interview Duration** (`interview_duration`, optional): Enter the duration of the interview.
* **Interviewers** (`interviewers`, optional): Enter the names of the interviewers.
* **Job Evaluation Scale** (`evaluation_scale`, optional): Select the evaluation scale for the job.
* **Job Evaluation Scale 2** (`evaluation_scale_2`, optional): Select a secondary evaluation scale for the job.
