# s.t.a.r.t template - Help Guide
## Purpose
The S.T.A.R.T template is a tool used to document and track important information related to tasks and projects. It helps to ensure that relevant details are captured and recorded accurately, providing a clear understanding of project progress and completion status.

## How To Complete This Form
To complete the S.T.A.R.T template, follow these steps:

1. Start by filling in the required fields:
	* **task**: Enter a brief description of the task or project.
	* **result**: Describe the outcome or outcome of the task or project.
	* **resources**: Specify whether resources were used for the task or project. Choose 'Yes' or 'No'.
	* **submitted_by**: Indicate who submitted the report, 'Yes' or 'No'.
	* **submitted_on**: Enter the date the report was submitted.
2. If applicable, fill in the remaining fields:
	* **action**: Provide additional information about any actions taken during the task or project.
	* **time**: Enter the date the task or project was completed, if applicable.
	* **location**: Specify the location where the task or project was completed.
3. Review and edit your entries as necessary to ensure accuracy and completeness.

## Field-by-Field Explanation
- **task** (task, text, required): Enter a brief description of the task or project.
- **Action** (action, text, optional): Provide additional information about any actions taken during the task or project.
- **Time** (time, date, optional): Enter the date the task or project was completed, if applicable.
- **Location** (location, text, optional): Specify the location where the task or project was completed.
- **Resources** (resources, select_multiple, required): Specify whether resources were used for the task or project. Choose 'Yes' or 'No'.
- **Assigned Tool** (assigned_tool, select_one, required): Indicate whether a tool was assigned for the task or project. Choose 'Yes' or 'No'.
- **Submitted By** (submitted_by, select_one, required): Indicate who submitted the report, 'Yes' or 'No'.
- **Submitted On** (submitted_on, date, required): Enter the date the report was submitted.

## Tips
- Be as concise as possible when filling out the form.
- Double-check the accuracy of your entries before submitting.
- Use the provided options for fields with select options types.
- Ensure all required fields are filled out before submitting the form.
