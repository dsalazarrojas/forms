# workforce_capability_evaluation_request_form - Help Guide
## Purpose
The workforce capability evaluation request form helps to assess the capability of a team or individual to complete a task or achieve an objective.

## How To Complete This Form
1. Select the objective of the task you want to evaluate.
2. Choose the timeframe within which the task needs to be completed.
3. Indicate the priority level of the task.
4. Add any relevant details about the objective.
5. Add any relevant details about the timeframe.
6. Add any relevant details about the priority.
7. Select the strategic or tactical nature of the task.
8. Add any additional details about the objectives.
9. Select the priority level of the task.
10. Add any additional details about the priority.
11. Enter any notes about the task.

## Field-by-Field Explanation
* **Objective** (`objective`, text, optional):
	+ This field asks for a brief description of the task or objective.
	+ Please be as specific as possible about what needs to be accomplished.
* **Timeframe** (`timeframe`, select_one, optional):
	+ This field asks for the timeframe within which the task needs to be completed.
	+ Please select one of the options: 1, 2, or 3.
* **Priority** (`priority`, select_multiple, optional):
	+ This field asks for the priority level of the task.
	+ Please select one or more of the options: High, Medium, or Low.
* **Objective Details** (`objective_details`, text, optional):
	+ This field is for any additional details about the objective.
	+ Please provide any relevant information that may help in the evaluation.
* **Timeframe Details** (`timeframe_details`, text, optional):
	+ This field is for any additional details about the timeframe.
	+ Please provide any relevant information that may help in the evaluation.
* **Priority Details** (`priority_details`, text, optional):
	+ This field is for any additional details about the priority.
	+ Please provide any relevant information that may help in the evaluation.
* **Objectives** (`objectives`, select_one, optional):
	+ This field asks for the strategic or tactical nature of the task.
	+ Please select one of the options: Strategic or Tactical.
* **Objectives Details** (`objectives_details`, text, optional):
	+ This field is for any additional details about the objectives.
	+ Please provide any relevant information that may help in the evaluation.
* **Priorities** (`priorities`, select_multiple, optional):
	+ This field asks for the priority level of the task.
	+ Please select one or more of the options: High, Medium, or Low.
* **Priorities Details** (`priorities_details`, text, optional):
	+ This field is for any additional details about the priority.
	+ Please provide any relevant information that may help in the evaluation.
* **Notes** (`notes`, note, optional):
	+ This field is for any additional comments or notes about the task.
	+ Please provide any relevant information that may help in the evaluation.
