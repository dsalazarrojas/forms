# Roleplay Scenario Assessment - Help Guide
## Purpose
The Roleplay Scenario Assessment form is a tool to collect information about roleplay scenarios, allowing you to record and analyze details about each scenario.

## How To Complete This Form
1. Start by addressing each scenario one by one, using the tabs provided for each roleplay scenario.
2. For each scenario, fill in the title, description, objective, and outcome fields.
3. Indicate whether there is risk involved in each scenario.
4. Repeat the process for each of the four scenarios provided.
