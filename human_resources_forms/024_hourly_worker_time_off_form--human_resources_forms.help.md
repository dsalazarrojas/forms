# Hourly Worker Time Off Form - Help Guide
## Purpose
The Hourly Worker Time Off Form is a document used to request time off from work. It's a crucial tool for hourly workers to communicate their availability and schedule changes to the HR department.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of your time off request in the "Time off reason" field.
2. Provide the start and end dates of your time off in the "Time off start date" and "Time off end date" fields, respectively.
3. Specify the number of hours you will be absent from work in the "Time off hours" field.
4. Add any additional comments or details about your time off request in the "Time off comment" field (optional).

## Field-by-Field Explanation
### Time off Request (Time off Request, Text, Required)
Enter a brief description of your time off request. This field is essential for the HR department to understand your reason for requesting time off.

### Time off Reason (Time off reason, Text, Required)
Provide a clear and concise explanation of your time off reason. This will help the HR department process your request efficiently.

### Time off Start Date (Time off start date, Date, Required)
Enter the start date of your time off. This date should be in the format MM/DD/YYYY.

### Time off End Date (Time off end date, Date, Required)
Enter the end date of your time off. This date should be in the format MM/DD/YYYY.

### Time off Hours (Time off hours, Number, Required)
Specify the number of hours you will be absent from work. This includes any partial hours, such as half a day or a few hours.

### Time off Comment (Time off comment, Text, Optional)
Add any additional comments or details about your time off request. This field is optional, but it can help clarify any specific requirements or concerns.
