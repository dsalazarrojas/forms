# Value Assessment Form - Help Guide

## Purpose
The Value Assessment Form is used to determine the value of a property. This form helps assessors evaluate properties by gathering relevant information about the property, including its type, address, rent, square footage, and value determination.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the Property Manager's name in the **Property Manager** field.
2. Enter the property's address in the **Property Address** field.
3. Select the type of property (Apartment, Single Family, or Townhouse) in the **Property Type** field.
4. Enter the property's rent in the numerical value in the **Rent** field.
5. Enter the property's square footage in the **Square Footage** field.
6. Check the **Value Determination** box if the value of the property is determinate. Otherwise, uncheck it.
7. Enter the value of the property in the **Value** field.
8. Enter the date the property was assessed in the **Date Assessed** field.

## Field-by-Field Explanation

* **Property Manager**: Enter the name of the person responsible for managing the property.
* **Property Address**: Enter the address of the property, including street number and city.
* **Property Type**: Select the type of property from the options provided (Apartment, Single Family, or Townhouse).
* **Rent**: Enter the current rent of the property in numerical value.
* **Square Footage**: Enter the total square footage of the property.
* **Value Determination**: Check this box if the value of the property is determinate. Otherwise, uncheck it.
* **Value**: Enter the determined value of the property in numerical value.
* **Date Assessed**: Enter the date the property was last assessed.
