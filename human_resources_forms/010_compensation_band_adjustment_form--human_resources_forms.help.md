# Compensation Band Adjustment Form - Help Guide

## Purpose
The purpose of this form is to request changes to an employee's current compensation band due to exceptional performance, promotions, or other reasons.

## How To Complete This Form
To complete this form, please follow these steps:

1.  Provide employee information.
2.  Select the current and requested compensation bands.
3.  Specify the effective date for the adjustment.
4.  Provide a justification for the adjustment and any supporting evidence.
5.  Select the approving manager's name.
6.  Select the manager's approval status.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, text, required): Enter the full legal name of the employee requesting the compensation band adjustment.
* **Employee ID** (`employee_id`, text, required): Enter the employee's internal identifier.
* **Current Compensation Band** (`current_band`, select_one, required): Select the current compensation band of the employee.
* **Requested Compensation Band** (`requested_band`, select_one, required): Select the requested compensation band.
* **Effective Date** (`effective_date`, date, optional): If a date change is requested, enter the date when the adjustment should take effect.
* **Justification for Adjustment** (`justification`, text, required): Explain the reasons and provide any supporting evidence for the requested adjustment.
* **Manager Name** (`manager_name`, text, required): Enter the name of the approving manager.
* **Manager Approval Status** (`manager_approval`, select_one, required): Select the manager's approval status (Approved, Denied, or Pending).
