# Conflict Resolution Checklist - Help Guide
## Purpose

This form is used to document and track the conflict resolution process in the workplace.

## How To Complete This Form

1. Fill out this form accurately and thoroughly, providing all necessary information about the conflict.
2. Make sure to complete all required fields.
3. If any field is not applicable, select "Not Applicable" or "None" as the answer.
4. Use the "Select One" options when multiple options are available.
5. Use the "Select Multiple" options when multiple options are available and multiple selections are required.
6. If you are unsure about any part of the form, refer to the relevant policies and procedures in the employee handbook or consult with an HR representative.

## Field-by-Field Explanation

* **Case Number** (`case_number`, `text`, Required): Unique identifier for this case.
* **Checklist Date** (`checklist_date`, `date`, Required): Date and time when this form is being completed.
* **HR Representative** (`hr_representative`, `text`, Required): Name of HR personnel handling this case.
* **Manager Name** (`manager_name`, `text`, Required): Name of the employee's manager.
* **Department** (`department`, `text`, Required): Department where the conflict occurred.
* **Type of Conflict** (`conflict_type`, `select_one`, Required): Select the primary category of conflict.
*   - Interpersonal Dispute
*   - Team Conflict
*   - Manager Employee Dispute
*   - Harassment Complaint
*   - Discrimination Complaint
*   - Performance Related
*   - Resource Dispute
*   - Other
* **Parties Involved** (`parties_involved`, `text`, Required): Names of all employees involved in the conflict.
* **Date Conflict Was Reported** (`date_conflict_reported`, `date`, Required): Date when this issue was first raised.
* **Initial Complaint Received** (`initial_complaint_received`, `select_one`, Required): Has a formal complaint been submitted?
*   - True
*   - False
* **Complaint Documented** (`complaint_documented`, `select_one`, Required): Is the complaint properly documented?
*   - True
*   - False
*   - Not Applicable
* **Initial Assessment Completed** (`initial_assessment_completed`, `select_one`, Required): Has the initial risk assessment been done?
*   - True
*   - False
* **Severity Level** (`severity_level`, `select_one`, Required): Assessment of conflict severity.
*   - Low - Informal Resolution
*   - Medium - Formal Process
*   - High - Immediate Action Required
*   - Critical - Escalate to Leadership
* **All Parties Interviewed** (`parties_interviewed`, `select_one`, Required): Have all parties been interviewed?
*   - True
*   - False
*   - In Progress
* **Interview Dates** (`interview_dates`, `text`, Optional): Dates when interviews were conducted.
* **Witnesses Identified** (`witnesses_identified`, `select_one`, Required): Are there witnesses to interview?
*   - True
*   - False
* **Witnesses Interviewed** (`witnesses_interviewed`, `select_one`, Required): Have all witnesses been interviewed?
*   - True
*   - False
*   - Not Applicable
* **Evidence Collected** (`evidence_collected`, `select_one`, Required): Has relevant evidence been gathered?
*   - True
*   - False
*   - Not Applicable
* **Types of Evidence** (`evidence_types`, `select_multiple`, Optional): List types of evidence collected.
*   - Email Communications
*   - Written Documents
*   - Performance Records
*   - Witness Statements
*   - Video or Audio
*   - Physical Evidence
*   - None
* **Mediation Offered** (`mediation_offered`, `select_one`, Required): Was mediation offered to parties?
*   - Yes - Accepted
*   - Yes - Declined
*   - No - Not Appropriate
* **Mediation Scheduled** (`mediation_scheduled`, `date`, Optional): Date of mediation session if applicable.
* **Interim Measures Implemented** (`interim_measures`, `select_multiple`, Required): Temporary measures during investigation.
*   - None Required
*   - Schedule Adjustment
*   - Reporting Structure Change
*   - Remote Work Arrangement
*   - Leave of Absence
*   - No Contact Order
*   - Other
* **Investigation Complete** (`investigation_complete`, `select_one`, Required): Has the full investigation concluded?
*   - True
*   - False
*   - In Progress
* **Findings Documented** (`findings_documented`, `select_one`, Required): Are investigation findings documented?
*   - True
*   - False
* **Resolution Action** (`resolution_action`, `select_one`, Required): Action taken to resolve conflict.
*   - Informal Resolution
*   - Mediation Successful
*   - Formal Warning Issued
*   - Training Required
*   - Transfer or Reassignment
*   - Termination
*   - No Action Required
*   - Other
* **Follow-Up Required** (`follow_up_required`, `select_one`, Required): Is follow-up monitoring needed?
*   - True
*   - False
* **Follow-Up Date** (`follow_up_date`, `date`, Optional): When follow-up is scheduled.
* **Case Closed** (`case_closed`, `select_one`, Required): Has this case been formally closed?
*   - True
*   - False
* **Case Close Date** (`case_close_date`, `date`, Optional): Date when case was closed.
* **HR Representative Signature** (`hr_signature`, `text`, Required): Name of HR representative.
