# Employee Retention Assessment Form - Help Guide
## Purpose
The employee retention assessment form is a tool for measuring employee satisfaction and perception of their work experience. It is designed to provide insights into the company's performance and employee retention.

## How To Complete This Form
To complete this form, follow these steps:

1. Answer all the questions honestly and to the best of your knowledge.
2. Select the correct options for each question from the provided choices.
3. Do not leave any question blank, as this may affect the accuracy of the results.
4. If you are unsure about any question, select the option that best describes your experience or perception.

## Field-by-Field Explanation

* **Company Location**: Please enter the name of the company or office location where you are currently or were last employed.
	+ Type: text
	+ Required: Optional
* **Department Name**: Please enter the name of the department where you are currently or were last employed.
	+ Type: text
	+ Required: Optional
* **Job Title**: Please enter your current or last job title.
	+ Type: text
	+ Required: Optional
* **Job Satisfaction**: Please select how satisfied you are with your job:
	+ Type: select_one
	+ Options: Satisfied, Very Satisfied, Not Satisfied, Very Not Satisfied
	+ Required: Optional
* **Workplace Environment**: Please select the description of the current or last workplace environment:
	+ Type: select_multiple
	+ Options: Positive, Neutral, Negative
	+ Required: Optional
* **Manager Relationship**: Please select the description of your relationship with your manager:
	+ Type: select_one
	+ Options: Good, Fair, Poor
	+ Required: Optional
* **Job Security**: Please select how secure you feel about your job:
	+ Type: select_multiple
	+ Options: Secure, Somewhat Secure, Not Secure
	+ Required: Optional
* **Benefits Provided**: Please select the description of the benefits provided by the company:
	+ Type: select_multiple
	+ Options: Good, Fair, Poor
	+ Required: Optional

## Tips

* Please answer all questions truthfully and to the best of your knowledge.
* If you are unsure about any question, select the option that best describes your experience or perception.
* If you need help or have any questions, feel free to contact us.
