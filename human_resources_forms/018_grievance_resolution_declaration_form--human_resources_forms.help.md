# grievance_resolution_declaration_form - Help Guide
## Purpose
The grievance resolution declaration form is used to document and track the resolution status of grievances submitted by employees.

## How To Complete This Form
1. Ensure you have not already submitted a grievance resolution declaration for the same issue.
2. Select the "resolution_status" field and choose whether the grievance has been resolved or not.
3. Enter the "resolution_date" in the correct format (YYYY-MM-DD).
4. Provide a brief explanation of the resolution in the "resolution_details" field.

## Field-by-Field Explanation
* **grievance_resolution**: This field is a note field where you can enter a brief description of the grievance.
* **resolution_date**: Enter the date when the grievance was resolved. Please use the YYYY-MM-DD format.
* **resolution_status**: Select "Active" if the grievance is still being addressed, and "Inactive" if it has been resolved.
* **resolution_details**: Provide a brief explanation of what was done to resolve the grievance.
