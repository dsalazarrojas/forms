# Timesheet Submission Verification Form - Help Guide
## Purpose
This form is used to verify the accuracy and completeness of employee timesheet submissions. Use this form when an employee's timesheet has not been verified previously.

## How To Complete This Form
1. Fill out the form completely and accurately.
2. Ensure that all required fields are filled out.
3. Review the employee's submitted timesheet for completeness and accuracy.
4. Sign and date the form to confirm verification.

## Field-by-Field Explanation

### Employee Details
* **Employee Details** (`employee_details`, text, optional): Enter the employee's name and ID number for reference.

### Date
* **Date** (`date`, date, optional): Enter the date when the timesheet was submitted or verified.

### Manager Signature
* **Manager Signature** (`manager_signature`, note, optional): This field is used to store any comments or notes from the manager.

### Employee Signature
* **Employee Signature** (`employee_signature`, note, optional): This field is used to store the employee's signature or comments.

### Verification Status
* **Verification Status** (`verification_status`, select_one, optional): Select one of the following:
	+ Active: The timesheet has been verified and is active.
	+ Inactive: The timesheet has been verified but is inactive.

### Notes
* **Notes** (`notes`, text, optional): Enter any additional comments or notes about the timesheet submission.

### Manager Name
* **Manager Name** (`manager_name`, text, optional): Enter the name of the manager who verified the timesheet.

### Verified By
* **Verified By** (`verified_by`, text, optional): Enter the name of the person who verified the timesheet.

## Tips
* Make sure to review the employee's submitted timesheet carefully before verifying it.
* Ensure that all required fields are filled out before submitting the form.
* If the verification status is Inactive, explain the reason for inactivity in the Notes field.
