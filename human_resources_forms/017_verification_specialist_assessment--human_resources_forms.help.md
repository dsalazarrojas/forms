# Verification Specialist Assessment - Help Guide
## Purpose
This form is designed to assess the verification specialist's skills and experience in verifying candidate information. The form is used to gather and verify candidate information in a structured and efficient way.

## How To Complete This Form
To complete this form, please follow these steps:
1. Review the candidate's information carefully before starting the form.
2. Fill in the candidate's information in the required fields, which are marked as "required".
3. If you need to add any additional information or comments, you can use the "submission_notes" field.
4. Make sure to attach any supporting documents or evidence as necessary.

## Field-by-Field Explanation
* **Candidate Information (Text, Not Required)**: This field is used to record the candidate's basic information.
* **Scenario-Based Screening (Text, Not Required)**: This field is used to describe a scenario-based screening exercise that the verification specialist performed on the candidate.
* **Evaluation (Number, Not Required)**: This field is used to evaluate the candidate's performance in the scenario-based screening exercise.
* **Submission Date (Date, Not Required)**: This field is used to record the date of submission of the verification specialist's evaluation.
* **Submission Time (Time, Not Required)**: This field is used to record the time of submission of the verification specialist's evaluation.
* **Email (Email, Not Required)**: This field is used to record the candidate's email address.
* **Phone (Text, Not Required)**: This field is used to record the candidate's phone number.
* **Submission Notes (Note, Not Required)**: This field is used to add any additional comments or notes about the candidate's submission.

# Tips
* Please make sure to review the candidate's information carefully before proceeding with the form.
* If you are unsure about any field, please consult with the relevant authorities or seek clarification before submitting the form.
* Make sure to attach any supporting documents or evidence as necessary.
* Complete the form thoroughly and accurately to ensure accurate decision-making.
