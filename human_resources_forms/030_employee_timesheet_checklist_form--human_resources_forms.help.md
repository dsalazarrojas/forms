# Employee Timesheet Checklist Form - Help Guide
## Purpose
This form is used to record employee work hours, attendance, overtime, manager comments, and employee comments. It is a checklist form designed to gather information about an employee's work schedule and performance.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure that you have all necessary information and authorization to access and fill out this form.
2. Select all relevant options for the employee work hours field, choosing from the available options.
3. Enter the attendance details, using the time format specified.
4. Record any overtime hours worked, if applicable.
5. Add any comments or remarks from the manager, if necessary.
6. Enter any comments or remarks from the employee, if necessary.

## Field-by-Field Explanation
* **Employee Work Hours** (select multiple): Select all relevant work hours options for the employee.
* **Attendance** (time): Enter the employee's attendance details in the specified time format.
* **Overtime** (number): Record any overtime hours worked by the employee.
* **Manager Comments** (note): Add any comments or remarks from the manager, if necessary.
* **Employee Comments** (note): Enter any comments or remarks from the employee, if necessary.
