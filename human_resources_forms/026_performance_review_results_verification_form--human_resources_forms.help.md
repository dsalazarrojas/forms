# Performance Review Results Verification Form - Help Guide
## Purpose
The Performance Review Results Verification Form is used to confirm the completion status of employee performance reviews. This is a crucial step in the review process to ensure accuracy and completeness.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the Employee ID to associate the review with the correct employee.
2. Select the Reviewer ID to confirm who performed the review.
3. Enter the Performance Score to confirm the review's score.
4. Enter the Evaluation Date to confirm when the review was completed.
5. Select the Review Status to confirm the status of the review.
6. Enter any additional Notes if necessary.
7. Select the Employee Evaluation to confirm the employee's evaluation.
8. Enter the Review Comments and Evaluation Comments if necessary.
9. Enter the Approval Date and Approval Status to confirm approval.
10. Select the Review Cycle to confirm the review cycle.

## Field-by-Field Explanation

* **Employee Id**: Enter the unique ID number of the employee that this review is for. This will help us track the review to the correct employee.
* **Reviewer Id**: Select the ID number of the reviewer who completed this review. This ensures that we have the correct person reviewing the employee.
* **Performance Score**: Enter the score given to the employee based on their performance. This is an important part of the review process.
* **Evaluation Date**: Enter the date this review was completed. This is when the review took place.
* **Review Status**: Select the status of the review: Approved, Rejected, or Pending. This confirms whether the review is complete and ready for next steps.
* **Notes**: Add any additional comments or information related to the review. This can help explain any reasons for the review status.
* **Employee Evaluation**: Select the employee's evaluation: Excellent, Average, or Below Average. This is an important part of the review process.
* **Review Comments**: Add any comments related to the review. This can help clarify any issues or concerns.
* **Evaluation Comments**: Add any comments related to the evaluation. This can help provide additional context.
* **Approval Date**: Enter the date this review was approved. This confirms that the review is complete and final.
* **Approval Status**: Select the status of the approval: Approved, Rejected, or Pending. This confirms whether the review is approved or not.
* **Review Cycle**: Select the review cycle: First Cycle, Second Cycle, or Third Cycle. This helps track the review cycle.
* **Review Comments 2** and **Evaluation Comments 2**: These are additional comments related to the review. You can add any relevant information here.
* **Review Cycle 2**: Select the review cycle for this review. This helps track the review cycle.

Please fill out the form accurately and completely to ensure that the review is marked as complete and the employee's status is updated correctly.
