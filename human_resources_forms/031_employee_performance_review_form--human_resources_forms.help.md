# Employee Performance Review Form - Help Guide

## Purpose
This form is designed to provide a structured approach to evaluating employee performance, setting goals, and making recommendations for growth and development. It helps managers assess employee performance, identify areas for improvement, and document progress over time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's first name in the "First Name" field.
2. Enter the employee's last name in the "Last Name" field.
3. Enter the employee's job title in the "Job Title" field.
4. Select the employee's department from the options provided.
5. Choose the performance level of the employee (A, B, or C).
6. Select the date of the last performance review from the calendar.
7. Enter the name of the person who conducted the last review.
8. Enter comments from the employee (optional).
9. Enter comments from the manager (optional).
10. Select the rating of the employee's performance (1-5).
11. Enter evaluation comments.
12. Select a recommendation for the employee (promotion, raise, or no recommendation).
13. Enter the employee's signature.
14. Enter the manager's signature.
15. Select the date of the signature.
16. Enter the manager's name.
17. Enter the employee's name.
18. Select the date of the last evaluation.
19. Select the date of the next evaluation (if applicable).
20. Enter any employee notes (if applicable).

## Field-by-Field Explanation

* **First Name** (text, required): Enter the employee's first name.
* **Last Name** (text, required): Enter the employee's last name.
* **Job Title** (text, required): Enter the employee's job title.
* **Department** (text, optional): Enter the employee's department (if applicable).
* **Performance Level** (select_one, required): Select the performance level of the employee (A, B, or C).
* **Date of Last Review** (date, required): Select the date of the last performance review.
* **Last Reviewed By** (text, required): Enter the name of the person who conducted the last review.
* **Employee Comments** (text, optional): Enter comments from the employee (if applicable).
* **Manager Comments** (text, optional): Enter comments from the manager (if applicable).
* **Rating** (select_one, required): Select the rating of the employee's performance (1-5).
* **Evaluation Comments** (text, required): Enter comments about the employee's performance.
* **Recommendation** (select_one, required): Select a recommendation for the employee (promotion, raise, or no recommendation).
* **Employee Signature** (text, required): Enter the employee's signature.
* **Manager Signature** (text, required): Enter the manager's signature.
* **Date Signed** (date, required): Select the date of the signature.
* **Manager Name** (text, required): Enter the manager's name.
* **Employee Name** (text, required): Enter the employee's name.
* **Date Reviewed** (date, required): Select the date of the last evaluation.
* **Date Evaluated** (date, optional): Select the date of the next evaluation (if applicable).
* **Employee Notes** (text, optional): Enter any employee notes (if applicable).
* **Performance Improvement Areas** (select_multiple, optional): Select areas for improvement.
* **Evaluation Frequency** (select_one, optional): Select the evaluation frequency (Quarterly, Semi-Annual, or Annual).
* **Last Evaluation Date** (date, optional): Select the date of the last evaluation.
* **Next Evaluation Date** (date, optional): Select the date of the next evaluation.
* **Notes** (text, optional): Enter any notes about the employee's performance.
