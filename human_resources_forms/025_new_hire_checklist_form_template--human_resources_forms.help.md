# new_hire_checklist_form_template - Help Guide
## Purpose
This form is used to collect essential information for new hires, including contact details, personal details, employment status, job title, and other relevant job-related information.

## How To Complete This Form
To complete this form, follow the instructions for each field carefully. Make sure to fill out every required field (marked as "required" in the explanations) and provide accurate and relevant information.

## Field-by-Field Explanation
* **New Hire Form** (Required): Enter a brief description of the new hire, including their name and job title.
* **Contact Information** (Required): Enter the new hire's contact information, including email and any other relevant contact details.
* **Personal Details** (Required): Enter the new hire's date of birth and hire date. This information is crucial for employment records and compliance.
* **Supervisor** (Required): Indicate whether the new hire has a supervisor. This will help in assigning tasks and responsibilities.
* **Date of Birth** (Required): Enter the new hire's date of birth. This information helps in tracking employee age and other benefits-related details.
* **Hire Date** (Required): Enter the date the new hire joined the company.
* **Email** (Optional): Enter the new hire's email address. This will help in communicating with them and keeping them informed about company news and policies.
* **Phone** (Optional): Enter the new hire's phone number. This will help in reaching them during work hours or emergencies.
* **Job Code** (Optional): Indicate whether the new hire is part of a job code system. This helps in categorizing and tracking job roles within the company.
* **Job Title Code** (Required): Select relevant job title codes for the new hire. This helps in tracking job titles and responsibilities within the company.
* **Employment Type** (Required): Indicate whether the new hire is full-time or part-time. This helps in tracking employment status and benefits.
* **Job Type** (Optional): Enter a brief description of the new hire's job type, if applicable.
* **Job Status** (Optional): Enter a brief description of the new hire's job status, if applicable.
* **Employment Status** (Optional): Enter a brief description of the new hire's employment status, if applicable.
* **Employment Type Code** (Optional): Enter a brief description of the new hire's employment type code, if applicable.
* **Job Group** (Optional): Enter a brief description of the new hire's job group, if applicable.
* **Reporting Manager** (Optional): Enter the new hire's reporting manager's name and contact information, if applicable.
* **Team** (Optional): Enter the new hire's team name or department, if applicable.
* **Location** (Optional): Enter the new hire's work location, if applicable.
* **Job Code System** (Optional): Enter a brief description of the new hire's job code system, if applicable.
* **Job Category** (Optional): Enter a brief description of the new hire's job category, if applicable.
