# Workplace Safety Complaint Form - Help Guide
## Purpose
This form is for reporting incidents or near-miss events that occurred in the workplace. It helps our safety team to understand what happened, where it happened, and how we can prevent similar incidents in the future.

## How To Complete This Form
To complete this form, simply follow these steps:

1. Fill in all the required fields (marked as **required**). If a field is not required, you can leave it blank.
2. Be as detailed as possible in your description of the incident.
3. Choose the correct incident type from the list.
4. Submit the form when you're finished.

## Field-by-Field Explanation
* **Workplace Safety Form 1**: This is the header for this form.
* **incident description**: Please describe the incident or near-miss event that occurred. Be as detailed as possible.
* **date of incident**: Enter the date the incident occurred.
* **time of incident**: Enter the time the incident occurred.
* **incident location**: Enter the location where the incident occurred.
* **incident type**: Choose the type of incident from the list. If the incident type is not listed, select "Other" and provide a description in the "incident description" field.
* **incident type (Other)**: If you selected "Other" for incident type, please describe the incident type in this field.
