# Payroll System Access Form - Help Guide
## Purpose
The Payroll System Access Form is used to grant or deny access to the payroll system for employees based on various criteria.
## How To Complete This Form
To complete this form, please follow the instructions below:

1. Fill out the employee id field with the numerical identifier for the employee.
2. Select the department(s) that the employee has access to from the department field.
3. Enter the employee's job title in the job title field.
4. Choose the access level for the employee from the access level field.
5. Enter the start date and end date for the employee's access to the payroll system in the start date and end date fields.
6. Select the start and end times for the employee's access to the payroll system in the start time and end time fields.

## Field-by-Field Explanation
* **employee id** (`employee_id`, `number`, required): A numerical identifier for the employee.
* **department** (`department_id`, `select_one`, not required): Selects if the employee has access to the payroll system for a specific department.
* **job title** (`job_title`, `text`, not required): The job title of the employee.
* **access level** (`access_level`, `select_multiple`, not required): Selects the level of access the employee has to the payroll system.
* **start date** (`start_date`, `date`, not required): The date when the employee's access to the payroll system starts.
* **end date** (`end_date`, `date`, not required): The date when the employee's access to the payroll system ends.
* **start time** (`start_time`, `time`, not required): The time when the employee's access to the payroll system starts.
* **end time** (`end_time`, `time`, not required): The time when the employee's access to the payroll system ends.

## Tips
* Make sure to complete all required fields accurately and correctly.
* If you are unsure about any field, please contact the HR department for assistance.
* This form is used to grant or deny access to the payroll system, so be careful when completing it.
* If you have any issues or concerns, please contact the HR department for help.
