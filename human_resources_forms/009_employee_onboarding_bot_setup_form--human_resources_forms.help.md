# Employee Onboarding Bot Setup Form - Help Guide
## Purpose
The Employee Onboarding Bot Setup Form is designed to collect details about new hires and their onboarding status. It helps to streamline the onboarding process and ensures that new employees have all the necessary information and resources to perform their tasks effectively.

## How To Complete This Form
1. Fill out the Onboarding Details page with the new hire's information, such as their name, title, and job role.
2. Provide the new hire's new hire details on the New Hire Details page.
3. List the onboarding tasks and messages on the respective pages.
4. Select the assigned tool and onboarding status for the new hire.
5. Enter the Form ID and Company ID for tracking purposes.
6. Select the manager's name and email address for communication.
7. Choose the team members who will be working with the new hire.
8. Review and confirm the onboarding status of the new hire.

## Field-by-Field Explanation

* **Onboarding Details**
	+ (id: 1, name: onboarding_details, label: Onboarding Details, type: text, required: false)
	+ This field is for providing a brief description of the onboarding process for the new hire.
* **New Hire Details**
	+ (id: 2, name: new_hire_details, label: New Hire Details, type: text, required: false)
	+ This field is for recording the details about the new hire, such as their name, job role, and department.
* **Onboarding Tasks**
	+ (id: 3, name: onboarding_tasks, label: Onboarding Tasks, type: text, required: false)
	+ List the tasks assigned to the new hire as part of the onboarding process.
* **Onboarding Messages**
	+ (id: 4, name: onboarding_messages, label: Onboarding Messages, type: text, required: false)
	+ Provide any important messages or instructions to the new hire as part of the onboarding process.
* **Onboarding Documents**
	+ (id: 5, name: onboarding_documents, label: Onboarding Documents, type: text, required: false)
	+ Attach any relevant documents or handbooks to the onboarding process.
* **Assigned Tool**
	+ (id: 6, name: assigned_tool, label: Assigned Tool, type: select_one, required: false)
	+ Select the tool assigned to the new hire for use during their onboarding process.
* **Onboarding Status**
	+ (id: 7, name: onboarding_status, label: Onboarding Status, type: select_multiple, required: false)
	+ Select the onboarding status of the new hire, such as active or inactive.
* **Form ID**
	+ (id: 8, name: form_id, label: Form ID, type: text, required: false)
	+ Enter a unique identifier for the form, used for tracking purposes.
* **Company ID**
	+ (id: 9, name: company_id, label: Company ID, type: text, required: false)
	+ Enter the company ID for tracking and administrative purposes.
* **Manager**
	+ (id: 10, name: manager, label: manager, type: select_one, required: false)
	+ Select the manager's name who will be responsible for the new hire's onboarding process.
* **Manager Email**
	+ (id: 11, name: manager_email, label: manager_email, type: email, required: false)
	+ Enter the manager's email address for communication purposes.
* **Team Members**
	+ (id: 12, name: team_members, label: team_members, type: select_multiple, required: false)
	+ Select the team members who will be working with the new hire.
* **Onboarding Status**
	+ (id: 13, name: onboarding_status, label: Onboarding Status, type: select_one, required: false)
	+ Select the onboarding status of the new hire, such as active or inactive.
* **Assigned Tool**
	+ (id: 14, name: assigned_tool, label: Assigned Tool, type: select_one, required: false)
	+ Select the tool assigned to the new hire for use during their onboarding process.

## Tips

* Make sure to fill out the form accurately and completely to ensure a smooth onboarding process for the new hire.
* Review the form carefully before submitting it to ensure all necessary information is provided.
* Use the form to track and monitor the onboarding progress of new hires.
* Update the form regularly to reflect any changes in the new hire's status or assigned tasks.
