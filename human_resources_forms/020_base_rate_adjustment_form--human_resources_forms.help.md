# Base Rate Adjustment Form - Help Guide

## Purpose
The purpose of this form is to request a base rate adjustment for an employee. It is used to collect information about the employee and their request for a base rate adjustment.

## How To Complete This Form

1. **Employee Full Name**: Enter the employee's full name as it appears on their ID.
2. **Employee ID Number**: Enter the employee's ID number as issued by the company.
3. **Department**: Select the department of the employee.
4. **Current Job Title**: Enter the employee's current job title.
5. **Request Date**: Enter the date the request is being made.
6. **Requesting Manager Name**: Enter your name as the manager submitting the request.
7. **Manager Email**: Enter your email address for communication purposes.
8. **Current Base Rate**: Enter the current base rate of the employee.
9. **Proposed Base Rate**: Enter the proposed new base rate.
10. **Rate Type**: Select whether the proposed base rate is hourly or annual.
11. **Percentage Increase**: Enter the percentage increase from the current rate.
12. **Effective Date**: Enter the date when the new base rate should take effect.
13. **Reason for Adjustment**: Select the reason for the base rate adjustment.
14. **Justification for Increase**: Enter a detailed explanation for the requested increase.
15. **Current Performance Rating**: Select the current performance rating of the employee.
16. **Last Performance Review Date**: Enter the date of the most recent performance review.
17. **Time in Current Position**: Select how long the employee has been in their current position.
18. **Date of Last Rate Increase**: Enter the date of the last base rate increase, if applicable.
19. **Budget Approval Status**: Select the status of the budget approval.
20. **Market Data Supporting Request**: Enter any market data supporting the request, if applicable.
21. **Internal Equity Considered**: Select whether internal equity was considered in the request.
22. **Retention Risk Level**: Select the retention risk level of the employee.
23. **HR Approval**: Select the status of HR approval.
24. **Finance Approval**: Select the status of finance approval.
25. **Additional Comments**: Enter any additional comments or relevant information.
26. **Manager Signature**: Type your full name as the manager submitting the request.
27. **HR Approval Signature**: If HR approval is pending or not yet submitted, you will need to sign as HR representative.
