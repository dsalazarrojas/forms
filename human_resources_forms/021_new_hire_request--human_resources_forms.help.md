# New Hire Request - Help Guide
## Purpose
The New Hire Request form is used by the HR department to request a new employee to be hired. It is used to gather information about the new hire, including their name, start date, department, and employment period. The form is also used to request additional resources such as computers, software, and peripherals for the new hire.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the new hire's name in the "Name" field.
2. Select the start date of the new hire in the "Start Date" field.
3. Select the department that the new hire will be working in from the "Department" field.
4. Specify the employment period for the new hire.
5. If the new hire requires any additional requests, select "Yes" or "No" in the "Additional Requests" field.
6. If the new hire requires any specific computers, software, or peripherals, select "Yes" or "No" from the corresponding fields.
7. Select the tool that will be assigned to the new hire from the "Assigned Tool" field.
8. Select the user who will be assigned to the new hire from the "Assigned User" field.
9. Specify any additional information in the "Notes" fields.

## Field-by-Field Explanation

* **Name** (`Name`, Text, Required): Enter the name of the new hire.
* **Start Date** (`Start Date`, Date, Required): Select the start date of the new hire.
* **Department** (`Department`, Text, Required): Select the department that the new hire will be working in.
* **Employment Period** (`Employment Period`, Text, Required): Specify the employment period for the new hire.
* **Additional Requests** (`Additional Requests`, Checkbox, Optional): Select "Yes" if the new hire requires any additional requests.
* **Computers** (`Computers`, Checkbox, Optional): Select "Yes" if the new hire requires any computers.
* **Software** (`Software`, Checkbox, Optional): Select "Yes" if the new hire requires any software.
* **Peripherals** (`Peripherals`, Checkbox, Optional): Select "Yes" if the new hire requires any peripherals.
* **Additional Requests Details** (`Additional Requests Details`, Text, Optional): Specify any additional requests that the new hire requires.
* **Assigned Tool** (`Assigned Tool`, Select, Optional): Select the tool that will be assigned to the new hire.
* **Assigned User** (`Assigned User`, Text, Optional): Select the user who will be assigned to the new hire.
* **Category** (`Category`, Text, Optional): Specify any additional information about the new hire.
* **Category Options** (`Category Options`, Select, Optional): Select any additional category options for the new hire.
* **Notes** (`Notes`, Text, Optional): Specify any additional information about the new hire in the "Notes" field.

Tips:

* Please ensure that you have all necessary approvals and information before filling out this form.
* Double-check the fields for accuracy before submitting the form.
* If you are unsure about any of the fields, contact the HR department for assistance.
* This form is for internal use only and not for public viewing.
