# License Renewal Time Off Form - Help Guide
## Purpose
The License Renewal Time Off Form is used to request a license renewal for an employee. It is intended to collect relevant information to process the license renewal request.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the employee's ID number in the "Employee ID" field.
2. Select the type of license to be renewed from the "License Type" field.
3. Enter the start date and end date of the license in the "Start Date" and "End Date" fields, respectively.
4. Provide a valid reason for the license renewal in the "Reason for Renewal" field.
5. Select the submitted by option from the "Submitted By" field (User, Manager, or HR Representative).
6. Choose the department(s) related to the license renewal from the "Department" field.
7. Provide a note with the manager's signature in the "Manager Signature" field.

## Field-by-Field Explanation
* **Employee ID** (1, Employee Id, Required): Enter the employee's unique ID number.
* **License Type** (2, License Type, Optional): Select the type of license to be renewed (Security Clearance, Professional License, or Other).
* **Start Date** (3, Start Date, Optional): Enter the start date of the license.
* **End Date** (4, End Date, Optional): Enter the end date of the license.
* **Reason for Renewal** (5, Reason For Renewal, Optional): Provide a valid reason for the license renewal.
* **Submitted By** (6, Submitted By, Optional): Select who submitted the form (User, Manager, or HR Representative).
* **Department** (7, Department, Optional): Choose the department(s) related to the license renewal (HR, Accounting, or IT).
* **Manager Signature** (8, Manager Signature, Optional): Provide a note with the manager's signature for the license renewal request.

## Tips
* Ensure that the submitted reason for renewal is valid and relevant.
* Confirm with the employee that they have informed of the license renewal need.
* Review the submitted form for completeness and accuracy before processing.
