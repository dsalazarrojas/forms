# program-coordinator-offer-letter - Help Guide

## Purpose
This form is used to create and manage offer letters for program coordinators. It helps track the details of job offers, including job titles, salary ranges, start and end dates, locations, and more. The form is essential for HR and program management teams to maintain accurate and up-to-date information on program coordinator positions.

## How To Complete This Form

1.  Click on the "Offer Letter" form to start creating a new offer letter.
2.  Fill in the required fields, such as Program Coordinator Name, Job Title, Salary Range, Start Date, End Date, Location, Job Description, Contact Number, and Contact Email.
3.  Optionally, select the Offer Type, Offer Start Time, and Program Status as required.
4.  Add any additional notes or details in the Program Notes field.
5.  Finally, review and submit the form to create the offer letter.
