# offer_letter_submission_form - Help Guide
## Purpose
This form is used for offering letters from one organization to their employees.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter the name of the organization that is offering the letter.
2. Enter the name of the employee receiving the offer.
3. Enter the job title of the employee.
4. Select the offer date, which is the date the offer was made.
5. Select the hire date, which is the date the employee will start working.

## Field-by-Field Explanation

* **organization** (`organization`, text, required: false): Enter the name of the organization that is offering the letter.
* **employee name** (`employee_name`, text, required: false): Enter the name of the employee receiving the offer.
* **job title** (`job_title`, text, required: false): Enter the job title of the employee.
* **offer date** (`offer_date`, date, required: false): Select the date the offer was made.
* **hire date** (`hire_date`, date, required: false): Select the date the employee will start working.
