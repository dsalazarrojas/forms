# Paralegal Information Form - Help Guide
## Purpose
The Paralegal Information Form is a collection of questions and fields meant to gather relevant information about a paralegal. This form is used to collect data that helps in managing and understanding paralegal's employment status, job details, and personal contact information.

## How To Complete This Form
To complete this form, follow these steps:

1. Review each field carefully to understand its intended use.
2. Answer each question accurately and truthfully.
3. Ensure that you have all necessary permissions to complete this form.
4. Submit the form once you have completed all required fields.

## Field-by-Field Explanation
### 1. Paralegal Name
* **Paralegal Name** (`paralegal_name`, Text, Optional): Enter the paralegal's name.

### 2. Job Title
* **Job Title** (`job_title`, Text, Optional): Enter the paralegal's job title or role.

### 3. Work Status
* **Work Status** (`work_status`, Select Multiple, Optional):
	+ Select all applicable statuses (Active, Non-active, Onboarding) to indicate the paralegal's current work status.

### 4. Work Location
* **Work Location** (`work_location`, Select One, Optional):
	+ Choose from Remote, Office, or Hybrid to indicate where the paralegal works.

### 5. Work Type
* **Work Type** (`work_type`, Select Multiple, Optional):
	+ Select from Contract, Full-time, or Part-time to indicate the paralegal's employment type.

### 6. Start Date
* **Start Date** (`start_date`, Date, Optional): Enter the date the paralegal started working.

### 7. End Date
* **End Date** (`end_date`, Date, Optional): Enter the date the paralegal ended working (if applicable).

### 8. Work Hours
* **Work Hours** (`work_hours`, Number, Optional): Enter the number of hours the paralegal works.

### 9. Hourly Rate
* **Hourly Rate** (`hourly_rate`, Number, Optional): Enter the paralegal's hourly rate.

### 10. Annual Salary
* **Annual Salary** (`annual_salary`, Number, Optional): Enter the paralegal's annual salary.

### 11. Email
* **Email** (`email`, Email, Optional): Enter the paralegal's work email.

### 12. Phone Number
* **Phone Number** (`phone_number`, Text, Optional): Enter the paralegal's work phone number.

### 13. Emergency Contact Name
* **Emergency Contact Name** (`emergency_contact_name`, Text, Optional): Enter the name of the paralegal's emergency contact.

### 14. Emergency Contact Phone
* **Emergency Contact Phone** (`emergency_contact_phone`, Text, Optional): Enter the emergency contact's phone number.

### 15. Emergency Contact Email
* **Emergency Contact Email** (`emergency_contact_email`, Email, Optional): Enter the emergency contact's email.

### 16. Emergency Contact Relation
* **Emergency Contact Relation** (`emergency_contact_relation`, Text, Optional): Enter the relation between the paralegal and the emergency contact.

### 17. Emergency Contact Relationship
* **Emergency Contact Relationship** (`emergency_contact_relationship`, Text, Optional): Enter any additional details about the emergency contact relationship.

### 18. Work Experience
* **Work Experience** (`work_experience`, Text, Optional): Enter a brief description of the paralegal's work experience.

### 19. Availability
* **Availability** (`availability`, Text, Optional): Enter the paralegal's availability information.

### 20. Work Status 2
* **Work Status 2** (`work_status_2`, Text, Optional): Enter additional details about the paralegal's work status, if applicable.

### 21. Work Status 3
* **Work Status 3** (`work_status_3`, Text, Optional): Enter additional details about the paralegal's work status, if applicable.

### 22. Work Status 4
* **Work Status 4** (`work_status_4`, Text, Optional): Enter additional details about the paralegal's work status, if applicable.

### 23. Work Status 5
* **Work Status 5** (`work_status_5`, Text, Optional): Enter additional details about the paralegal's work status, if applicable.

### 24. Notes
* **Notes** (`notes`, Note, Optional): Enter any additional comments or notes about the paralegal.

### 25. Assigned To
* **Assigned To** (`assigned_to`, Select One, Optional):
	+ Choose from 'Yes' or 'No' to indicate if the paralegal is assigned to anyone.
