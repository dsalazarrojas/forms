# Program Termination Acknowledgment - Help Guide
## Purpose
The "Program Termination Acknowledgment" form is a formal document used to acknowledge the termination of a program. This form ensures that all necessary parties are informed and in agreement with the termination, which is essential for administrative and compliance purposes.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the **Program Name** field: This field is used to identify the program that has been terminated.
2. Enter the **Termination Date** field: This is the date on which the program was terminated.
3. Select a **Reason for Termination** from the provided options (Termination for cause, Termination for convenience, or Termination other). If "Termination other" is selected, please enter a description in the **Other Termination Reason** field to provide further explanation.
4. Confirm that the participant has acknowledged the program termination in the **Participant Confirmation** field. If the participant has acknowledged, select "Yes", otherwise select "No" or "Unknown".
5. Confirm that the program has terminated the participant in the **Program Confirmation** field. If the program has terminated the participant, select "Yes", otherwise select "No" or "Unknown".
6. Confirm that the training provider has acknowledged the program termination in the **Training Provider Confirmation** field. If the training provider has acknowledged, select "Yes", otherwise select "No".
7. Confirm that the school has terminated the participant in the **School Confirmation** field. If the school has terminated the participant, select "Yes", otherwise select "No".

## Field-by-Field Explanation
* **Program Name**: Enter the name of the program that has been terminated.
* **Termination Date**: Enter the date on which the program was terminated.
* **Reason for Termination**: Select one of the provided options (Termination for cause, Termination for convenience, or Termination other). If "Termination other" is selected, provide a description in the **Other Termination Reason** field.
* **Participant Confirmation**: Confirm that the participant has acknowledged the program termination. Select "Yes" if the participant has acknowledged, otherwise select "No" or "Unknown".
* **Program Confirmation**: Confirm that the program has terminated the participant. Select "Yes" if the program has terminated the participant, otherwise select "No" or "Unknown".
* **Training Provider Confirmation**: Confirm that the training provider has acknowledged the program termination. Select "Yes" if the training provider has acknowledged, otherwise select "No".
* **School Confirmation**: Confirm that the school has terminated the participant. Select "Yes" if the school has terminated the participant, otherwise select "No".
