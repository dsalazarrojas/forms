# Social Media Policy Acknowledgment Form - Help Guide
## Purpose
The Social Media Policy Acknowledgment Form is a document used to ensure that employees understand and agree to the company's social media policy. This form is a requirement for employees to acknowledge their awareness and understanding of the social media guidelines, which are essential for maintaining a positive and professional image of the company.

## How to Complete This Form
- Please select all the social media policy sign-offs that apply to you, as shown on page 1 of the form. 
- Fill in your name in the text box on page 2, which is required to be filled. 
- Select your department from the drop-down options on page 2, which is mandatory for the form to be completed. 
- You do not need to fill in any date or signature fields as they are not required for submission. 
- On page 4, please provide a detailed acknowledgement in the text box, which is a mandatory requirement for the form.

## Field-by-Field Explanation
* **Social Media Policy Sign-Offs (Select Multiple)**: This field allows you to select all the social media policy sign-offs that apply to you. Please carefully read through each option and choose the ones that apply to your work situation.
* **Name**: This field is a text box where you can input your name, which is a required field to be filled in.
* **Department**: This field is a drop-down menu with options for different departments. You must select your department from the provided options.
* **Date**: This field is a date field where you can input any date, though it is not a required field for submission.
* **Manager Name**: This field is a text box where you can input your manager's name, although it is not a required field.
* **Manager Email**: This is an email input field for your manager's email, which is also not required to be filled.
* **Acknowledgement**: This is a text box where you provide your detailed acknowledgement of the social media policy. This field is a mandatory requirement for submission.
* **Signed By**: This field is a date field where you can input the date you signed the form, though it is not required for submission.
* **Signature**: This field is a time field, though its purpose is unclear, and it is not a required field for submission.
