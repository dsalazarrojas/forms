# Speaking Interview Recording Form - Help Guide
## Purpose
The Speaking Interview Recording Form is designed to record and store information about speaking interviews, including details about the interviewee, recording device, time, date, and location.

## How To Complete This Form
1. Fill out the form fields with the relevant information about the interview.
2. Select the recording device used from the options provided.
3. Choose the recording time format (24-hour or 12-hour).
4. If you are recording audio, select the desired file extension (WAV, MP3, or FLAC).
5. Choose how you want to record the audio (as a file or transcribed).
6. If recording video, select the desired option.
7. Enter the file size and type after uploading the file.
8. Optionally, you can save the form as a draft or save and close it once completed.
9. Finally, cancel the form if you need to stop the recording.

## Field-by-Field Explanation
* **Introduction** (`id: 1`, text, optional): Briefly describe the context and purpose of the interview.
* **Interviewee Name** (`id: 2`, text, optional): Enter the name of the person being interviewed.
* **Question** (`id: 3`, text, optional): Type in the question asked to the interviewee.
* **Answer** (`id: 4`, text, optional): Record the response given by the interviewee.
* **Recording Device** (`id: 5`, select_multiple, optional): Select the device used to record the interview (Camera, Recorder, Smart Phone).
* **Recording Time** (`id: 6`, time, optional): Enter the time of the recording in 24-hour format.
* **Recording Date** (`id: 7`, date, optional): Select the date of the recording.
* **Interviewer Name** (`id: 8`, text, optional): Enter your name as the interviewer.
* **Notes** (`id: 9`, text, optional): Add any additional comments or notes about the interview.
* **Recording Location** (`id: 10`, text, optional): Enter the location where the recording took place.
* **File Path** (`id: 11`, text, optional): Enter the path where the file will be saved.
* **Recording Time Format** (`id: 12`, select_one, optional): Choose the time format for the recording (24-hour or 12-hour).
* **Recording File Name** (`id: 13`, text, optional): Enter the name of the file to be saved.
* **File Upload** (`id: 14`, text, optional): Upload the file to be saved.
* **File Extension** (`id: 15`, select_one, optional): Choose the file extension for the recording (WAV, MP3, FLAC).
* **Record Audio** (`id: 16`, select_multiple, optional): Choose how to record audio (as a file or transcribed).
* **Record Video** (`id: 17`, select_multiple, optional): Choose how to record video (as a file or transcribed).
* **File Size** (`id: 18`, text, optional): Enter the size of the file after uploading.
* **File Type** (`id: 19`, text, optional): Enter the type of file.
* **File Name** (`id: 20`, text, optional): Enter the name of the file.
* **Save and Close** (`id: 21`, text, optional): Save and close the form once completed.
* **Save as Draft** (`id: 22`, select_one, optional): Save the form as a draft.
* **Save** (`id: 23`, select_one, optional): Save the form.
* **Cancel** (`id: 24`, select_one, optional): Cancel the form.
