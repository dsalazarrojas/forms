# Scheduled Event Details Form - Help Guide
## Purpose
This form is used to collect details of a scheduled event for internal administrative purposes.

## How To Complete This Form
To complete this form, follow the steps outlined in the "How to Complete This Form" section above.

## Field-by-Field Explanation

*   **Schedule Date** (`schedule_date`, date, required: false): This field allows you to select the date of the event.
*   **Schedule Time** (`schedule_time`, time, required: false): This field allows you to select the time of the day the event will take place.
*   **Guest List** (`guest_list`, select_multiple, required: true): Select all the guests that will be attending the event.
*   **Guest List Hints** (`guest_list_hints`, text, required: false): Provide any additional information about the guests, such as their roles or contact details.
*   **Event Budget** (`event_budget`, number, required: false): If applicable, enter the event budget.
*   **Event Notes** (`event_notes`, note, required: false): Provide any additional notes about the event.
