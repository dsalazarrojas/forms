# Employee Relocation Package Accommodation Form - Help Guide
## Purpose
This form is designed to help employees gather necessary information about their relocation package. Please fill it out to ensure that all relevant details are covered.

## How To Complete This Form
1. Answer all questions carefully and honestly.
2. Provide accurate and up-to-date information.

## Field-by-Field Explanation
* **Employee Name** (`employee_name`, text, required): This field should be filled with the employee's full name, including their last name and first name.
* **Company Name** (`company_name`, text, required): This field should be filled with the name of the company the employee is relocating to or from.
* **Job Title** (`job_title`, text, required): This field should be filled with the employee's current job title.
* **Reporting Manager** (`reporting_manager`, text, required): This field should be filled with the name of the employee's reporting manager.
* **Relocation Location** (`relocation_location`, text, required): This field should be filled with the city or location where the employee will be working.
* **Travel Dates** (`travel_dates`, date, required): This field should be filled with the employee's expected travel dates to the new location.
* **Accommodation Cost** (`accommodation_cost`, number, required): This field should be filled with an estimate of the accommodation cost for the employee's stay.
* **Accommodation Type** (`accommodation_type`, select_one, required): This field should be filled with the type of accommodation the employee will need, which can be "Option 1", "Option 2", or "Option 3".
  - Select one of the options to choose the type of accommodation.

## Tips
* Please review the form carefully before submitting it.
* Double-check that all required fields are filled out.
* If you're unsure about any field, ask your HR representative for clarification.
* Make sure to submit the form accurately and completely.
