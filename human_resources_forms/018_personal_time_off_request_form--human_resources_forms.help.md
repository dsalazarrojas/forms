# Personal Time Off Request Form - Help Guide
## Purpose
This form is used to request time off from work for personal reasons such as vacations, illnesses, or other personal matters.

## How To Complete This Form
To complete this form, follow the steps below:

1. Fill in the **Reason for Time Off** field with the reason why you are requesting time off. You can select from the options provided or type in a different reason.
2. Enter the **Time Off Duration** field with the number of days you are requesting off.
3. Select the **Start Date** and **End Date** fields with the dates you plan to be off.
4. Choose the **Time Off Type** field with the type of time off you are requesting (e.g. vacation, illness, etc.).
5. Select the **Assigned To** field to indicate who is responsible for managing your time off request.
6. Choose the **Status** field to indicate the status of your time off request (Active or Inactive).
7. Enter any additional notes in the **Notes** field if needed.

## Field-by-Field Explanation

* **Personal Time Off Request**: This field is the title of the form.
* **Reason for Time Off**: This field asks for the reason why you are requesting time off. You can select from the options provided or type in a different reason.
* **Time Off Duration**: This field is used to enter the number of days you are requesting off.
* **Start Date**: This field is used to select the start date of your time off.
* **End Date**: This field is used to select the end date of your time off.
* **Time Off Type**: This field is used to choose the type of time off you are requesting (e.g. vacation, illness, etc.).
* **Assigned To**: This field is used to indicate who is responsible for managing your time off request.
* **Status**: This field is used to indicate the status of your time off request (Active or Inactive).
* **Notes**: This field is used to enter any additional notes or comments about your time off request.

## Tips

* Make sure to fill in all required fields to ensure your time off request is processed correctly.
* Check the options provided for the **Reason for Time Off**, **Time Off Type**, and **Status** fields to ensure you select the correct option.
* If you have any special requests or considerations, include them in the **Notes** field.
* Review the form carefully before submitting it to ensure all fields are filled in correctly.
