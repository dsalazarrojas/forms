# Employee Assistance Program Log - Help Guide
## Purpose
The purpose of this form is to track employee assistance sessions and ensure consistent and efficient support.

## How To Complete This Form
To complete this form:

1. Enter the employee's ID number.
2. Select the session date.
3. Choose the session topic.
4. Provide session notes.
5. Indicate referral source.
6. Select follow-up status.
7. Enter next follow-up date.
8. Provide follow-up notes.
9. Select follow-up frequency and method.
10. Indicate employee status.
11. Select next follow-up status.
12. Enter next follow-up date, if applicable.
13. Leave any additional comments or notes.

## Field-by-Field Explanation

* **Employee ID** (1, number, required): Enter the employee's ID number to identify the employee being assisted.
* **Session Date** (2, date, required): Select the date of the assistance session.
* **Session Topic** (3, text, required): Choose the topic of the session, e.g., "Employee Well-being" or "Performance Coaching".
* **Session Notes** (4, text, optional): Provide a brief description of the session, including any notable discussions or outcomes.
* **Referral Source** (5, select_one, optional): Indicate whether the session was referred by an internal or external source, e.g., "Manager" or "External Agency".
* **Follow-up Status** (6, select_one, optional): Select the current follow-up status of the session, e.g., "Active" or "Inactive".
* **Follow-up Date** (7, date, required): Enter the date for the next follow-up action.
* **Follow-up Notes** (8, text, optional): Provide any additional information or notes regarding the next steps.
* **Follow-up Frequency** (9, select_one, optional): Select the follow-up frequency, e.g., "Weekly" or "Monthly".
* **Follow-up Method** (10, select_one, optional): Indicate the follow-up method, e.g., "Phone" or "Email".
* **Employee Status** (11, select_one, optional): Indicate the employee's status, e.g., "Active" or "Inactive".
* **Follow-up Status 2** (12, select_one, optional): Select the next follow-up status, e.g., "Active" or "Inactive".
* **Next Follow-up Date** (13, date, optional): Enter the date for the next follow-up action, if applicable.
* **Notes** (14, text, optional): Leave any additional comments or notes.
* **Completed Status** (10, select_one, optional): Select whether the session is complete or not.
* **Referral Source** (5, select_one, optional): Select whether the session was referred by an internal or external source.
* **Next Steps** (9, text, optional): Provide any additional information or notes regarding the next steps.
* **Follow-up Location** (14, select_one, optional): Indicate the location of the follow-up action, e.g., "On-site" or "Remote".
* **Follow-up Frequency** (9, select_one, optional): Select the follow-up frequency, e.g., "Weekly" or "Monthly".
