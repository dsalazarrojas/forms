# New Facility Setup Absence Form - Help Guide

## Purpose
This form is intended to provide an overview of the new facility setup absence, including the start and end dates, reason for absence, absence location, and other details. It is a key part of the absence reporting process and helps ensure that all necessary information is captured and recorded.

## How To Complete This Form
To complete this form, please follow these steps:

1. Enter the Facility Name in the text field.
2. Select the Start Date and End Date using the calendar picker.
3. Provide a clear Reason for Absence, which will help in the absence approval process.
4. Choose the Type of Absence from the dropdown menu.
5. Enter the Absence Location in the text field.
6. Provide additional Absence Details if necessary.
7. Select the Assigned Tool from the dropdown menu.
8. Add any Comments regarding the absence.
9. Enter the Contact Person's name and phone number.
10. Enter the Email address of the Contact Person.
11. Choose the Category from the dropdown menu to categorize the absence.

## Field-by-Field Explanation

* **Facility Name** (`facility_name`, text, required/optional): Enter the name of the facility where the absence will occur.
* **Start Date** (`start_date`, date, required/optional): Select the start date of the absence.
* **End Date** (`end_date`, date, required/optional): Select the end date of the absence.
* **Reason for Absence** (`reason_for_absence`, text, required/optional): Provide a clear reason for the absence.
* **Type of Absence** (`type_of_absence`, select_one, required/optional): Choose the type of absence from the dropdown menu.
* **Absence Location** (`absence_location`, text, required/optional): Enter the location where the absence will occur.
* **Absence Details** (`absence_details`, text, required/optional): Provide any additional details regarding the absence.
* **Assigned Tool** (`assigned_tool`, select_multiple, required/optional): Select the tool(s) assigned to the employee during the absence.
* **Comments** (`comments`, note, required/optional): Add any comments regarding the absence.
* **Contact Person** (`contact_person`, text, required/optional): Enter the name and phone number of the contact person.
* **Email** (`email`, email, required/optional): Enter the email address of the contact person.
* **Category** (`category`, select_one, required/true): Choose the category from the dropdown menu to categorize the absence.
* **Form ID** (`form_id`, number, required/optional): This field is automatically generated and not intended to be filled by users.
