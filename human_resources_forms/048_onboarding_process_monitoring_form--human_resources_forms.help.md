# Onboarding Process Monitoring Form - Help Guide
## Purpose
The Onboarding Process Monitoring Form is used to track and monitor the progress of new employees through the onboarding process. This form helps to ensure a smooth transition into the company and identifies potential issues or areas for improvement.

## How To Complete This Form
To complete this form, please follow these steps:

1. Fill out the form for each new employee.
2. Enter the date of onboarding, which is the date the new employee joined the company.
3. Enter the ID of the new employee.
4. Select the onboarding status of the new employee (Active or Inactive).
5. Select the onboarding status options that apply to the new employee (Active, Inactive).
6. Select the new employee status (Active or Inactive).
7. Indicate whether there are any onboarding issues (Yes or No).
8. Enter any feedback or comments regarding the new employee's onboarding process.
9. Enter any additional comments or notes from the manager.
10. Select the action items that need to be addressed (Yes or No).

## Field-by-Field Explanation

* **Title** (text): Enter a brief title for the form.
* **Date of Onboarding** (date): Enter the date the new employee joined the company.
* **New Employee ID** (number): Enter the unique ID of the new employee.
* **Manager ID** (number): Enter the ID of the manager responsible for the new employee.
* **Date of Monitoring** (date): Enter the date this form is being completed.
* **Feedback** (text): Enter any feedback or comments regarding the new employee's onboarding process.
* **Comments** (text): Enter any additional comments or notes from the manager.
* **Onboarding Status** (select_one): Select the onboarding status of the new employee (Active or Inactive).
* **Onboarding Status Options** (select_multiple): Select all options that apply to the new employee's onboarding status (Active, Inactive).
* **New Employee Status** (select_multiple): Select the new employee status (Active or Inactive).
* **Onboarding Issues** (select_multiple): Select whether there are any onboarding issues (Yes or No).
* **Manager Notes** (text): Enter any additional notes from the manager.
* **Action Items** (select_multiple): Select the action items that need to be addressed (Yes or No).
