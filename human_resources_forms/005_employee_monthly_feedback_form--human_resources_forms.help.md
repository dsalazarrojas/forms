# Employee Monthly Feedback Form - Help Guide
## Purpose
The purpose of this form is to gather feedback from employees on their work experience, allowing HR or management to identify areas of improvement and track trends over time.

## How To Complete This Form
To complete this form, simply select or enter your answers to each question. You can choose from the provided options or enter a numerical value for fields that require it. If you're unsure about any question, please ask your supervisor or HR representative for guidance.

## Field-by-Field Explanation
* **Job Satisfaction** (`Job Satisfaction`, select_multiple, required/optional): Please select all that apply to describe your current job satisfaction. You can choose from High, Medium, and Low options.
* **Work Life Balance** (`Work Life Balance`, select_one, required/optional): Please select one option that best describes your current work-life balance. You can choose from High, Medium, and Low options.
* **Communication Effectiveness** (`Communication Effectiveness`, text, required/optional): Please enter a brief description of your experience with communication effectiveness in the workplace.
* **Job Security** (`Job Security`, select_multiple, required/optional): Please select all that apply to describe your current job security. You can choose from High, Medium, and Low options.
* **Management Support** (`Management Support`, select_one, required/optional): Please select one option that best describes your experience with management support. You can choose from High, Medium, and Low options.
* **Team Collaboration** (`Team Collaboration`, select_multiple, required/optional): Please select all that apply to describe your current team collaboration. You can choose from High, Medium, and Low options.
* **Work Life Balance Goal** (`Work Life Balance Goal`, number, required/optional): Please enter a numerical value that represents your goal for work-life balance for the next month. This is a percentage value between 0 and 100.
* **Job Security Goal** (`Job Security Goal`, number, required/optional): Please enter a numerical value that represents your goal for job security for the next month. This is a percentage value between 0 and 100.
* **Management Support Goal** (`Management Support Goal`, number, required/optional): Please enter a numerical value that represents your goal for management support for the next month. This is a percentage value between 0 and 100.
* **Team Collaboration Goal** (`Team Collaboration Goal`, number, required/optional): Please enter a numerical value that represents your goal for team collaboration for the next month. This is a percentage value between 0 and 100.

Note: Please keep in mind that these questions are meant to be completed on a monthly basis, so please answer based on your current experience and goals for the next month.
