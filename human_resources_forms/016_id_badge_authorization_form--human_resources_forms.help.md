# id_badge_authorization_form - Help Guide

## Purpose
The id_badge_authorization_form is used to request an ID badge for visitors or employees who need to access certain areas or facilities. This form helps to ensure that the individual's identity and purpose of visit are accurately recorded and approved before allowing them access.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the correct **user** who is requesting the ID badge.
2. Enter the **date of visit**, if required.
3. Choose the **purpose of visit** from the available options.
4. Enter the **company name** of the individual, if required.
5. Select the **department** of the individual, if required.
6. Choose the **badge type** (Regular, Temporary, or Special) that the individual needs.
7. Enter the individual's **name on badge**.
8. Select **employee ID** to indicate if the individual is an employee ('Yes' or 'No').

## Field-by-Field Explanation

* **user** (`John, Jane, Joe`, select_one): Select the user who is requesting the ID badge.
* **date_of_visit**: Enter the date the individual plans to visit. Note: this field is optional, but required in certain cases.
* **purpose_of_visit** (Business Meeting, Tour, Interview, select_one): Choose the purpose of visit from the available options.
* **company_name** (text): Enter the company name if the individual's company needs to be recorded.
* **department** (HR, Finance, IT, select_one): Select the department of the individual, if required.
* **badge_type** (Regular, Temporary, Special, select_multiple): Choose the badge type that the individual needs.
* **name_on_badge** (text): Enter the name to be displayed on the ID badge.
* **employee_id** (Yes, No, select_one): Select 'Yes' to indicate that the individual is an employee, otherwise choose 'No'.

## Tips

* Please ensure that all fields are completed accurately and thoroughly.
* If the individual is an employee, please select 'Yes' for **employee ID**.
* If the individual's department is not specified, please select 'N/A' or leave the field blank.
* If the individual's badge type is not specified, please select 'Regular' as default.
* If you are unsure about any field, please contact the HR department or the individual's manager for clarification.
