# employment_progress_report - Help Guide
## Purpose

The employment_progress_report form is used to document and track employee performance progress over time.

## How To Complete This Form

1. Fill in the employee's name in the **employee_name** field.
2. Select the **reporting_period** to indicate when the progress report was made.
3. Add any **performance_comments** about the employee's performance.
4. Specify the employee's **job_title** and **department**.
5. Enter the **manager_name** who is responsible for the report.
6. Enter the **employee_id** of the employee being reported on.
7. Choose a **reporting_date** for when the report was made.
8. Rate the employee's **performance_rating** on a scale (e.g. 1-5).
9. Set the next **follow_up_date** and any associated **follow_up_notes**.
10. Set the next **next_follow_up_date** and any associated **next_follow_up_notes**.
11. Specify the employee's **employee_status**.
12. Select the **follow_up_frequency** (e.g. weekly, bi-weekly, monthly).
13. Choose the method for follow-up (e.g. email, phone call).
14. Add any **manager_comment** or **employee_comment** regarding the report.
15. Predict the next **performance_rating**.
16. Update the form last updated by **last_updated_by**, **last_updated_date**, **last_updated_time**, **last_updated_by_ip**, **last_updated_by_browser**, and **last_updated_by_os**.

* **employee_name**: Enter the name of the employee being reported on.

* **employee_id**: Enter the employee ID number.

* **performance_rating**: Rate the employee's performance on a scale (e.g. 1-5).
* **follow_up_date**: Set the next date for follow-up.
* **follow_up_notes**: Add any notes for the next follow-up.

* **next_follow_up_notes**: Add any notes for the next follow-up.
* **employee_status**: Enter the current status of the employee (e.g. active, inactive).
* **follow_up_frequency**: Select the frequency for follow-up (e.g. weekly, bi-weekly, monthly).
* **follow_up_method**: Choose the method for follow-up (e.g. email, phone call).
* **manager_comment**: Add any comments from the manager.
