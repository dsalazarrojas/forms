# Disciplinary Action Communication Form - Help Guide
## Purpose
The Disciplinary Action Communication Form is a document used to inform employees of disciplinary actions taken against them.

## How To Complete This Form

To complete this form, follow these steps:

1. Enter a brief description of the reason for the disciplinary action in the "Reason for Disciplinary Action" field.
2. Select the date on which the action was taken.
3. Choose the type of action taken from the "Type of Action" dropdown.
4. Enter the employee's name and ID (if applicable).
5. Enter the manager's name.
6. Enter the date of birth of the employee (if applicable).
7. Provide a description of the disciplinary action taken (if required).
8. Enter any additional notes relevant to the action.
9. Check the "Email Sent" box if an email was sent to the employee.
10. Enter the phone number of the employee (if applicable).

## Field-by-Field Explanation
- **Reason for Disciplinary Action** (`action_taken`, text, optional): A description of the reason for the action.
- **Date of Action** (`date_of_action`, date, optional): Select the date on which the disciplinary action was taken.
- **Type of Action** (`action_type`, select_one, optional): Choose the type of action taken from the available options (Verbal Warning, Written Warning, Termination).
- **Employee Name** (`employee_name`, text, optional): Enter the employee's name.
- **Employee ID** (`employee_id`, number, optional): Enter the employee's ID.
- **Manager Name** (`manager_name`, text, optional): Enter the manager's name.
- **Date of Birth** (`date_of_birth`, date, optional): Enter the employee's date of birth.
- **Disciplinary Action Taken** (`disciplinary_action_taken`, text, optional): Provide a description of the disciplinary action taken.
- **Notes** (`notes`, note, optional): Enter any additional notes relevant to the action.
- **Email Sent** (`email_sent`, email, optional): Check this box if an email was sent to the employee.
- **Phone Number** (`phone_number`, text, optional): Enter the employee's phone number.

## Tips
- Always ensure that the form is completed accurately and truthfully.
- Use the available fields only for actual instances of disciplinary actions.
- Keep all fields filled in to ensure that the form is complete and accurate.
