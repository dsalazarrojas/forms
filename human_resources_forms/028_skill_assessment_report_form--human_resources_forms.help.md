# Skill Assessment Report Form - Help Guide
## Purpose
This form is used to provide feedback and guidance on an employee's skills and performance.

## How To Complete This Form
To complete this form, please follow these steps:

1. Select the relevant option for each field to provide a clear and accurate assessment of the employee's skills.
2. Enter a specific date for the assessment, if the assessment has already taken place.
3. Provide any comments or feedback from the manager, if applicable.
4. Enter any comments or feedback from the employee, if applicable.
5. Select the skills to be assessed for the employee, using the options provided.

## Field-by-Field Explanation

* **Skill Assessment Form 1**: This is the first section of the form where you will select the status of the employee's skills. Please choose 'Yes' if the employee has demonstrated the required skill, and 'No' otherwise.
* **Employee Rating**: This field is used to rate the employee's overall performance. Please enter a numerical value between 1 and 5, where 1 is the lowest and 5 is the highest.
* **Date of Assessment**: If the assessment has already taken place, please enter the date of the assessment. If not, leave this field blank.
* **Manager Comments**: Provide any comments or feedback from the manager, if applicable. This can include suggestions for improvement or areas where the employee excels.
* **Employee Comments**: Provide any comments or feedback from the employee, if applicable. This can include their own assessment of their skills and performance.
* **Skills to Assess**: This section is used to select the skills that need to be assessed. Please choose one option from the list provided.
* **Skills to Assess 1**: This field is similar to the previous one, where you select one skill to be assessed.
* **Skills to Assess 2**: This field is another option to select one skill to be assessed.

## Tips
* Make sure to complete this form thoroughly and accurately to provide the best possible feedback and guidance for the employee.
* If you are unsure about any field, please ask for clarification or guidance from your supervisor or HR representative.
* This form is an important part of the performance evaluation process, so please take the time to complete it thoughtfully and thoroughly.
