# Pay Grade Evaluation Request Form - Help Guide

## Purpose
The Pay Grade Evaluation Request Form is used to request a pay grade evaluation for an employee, allowing managers and HR personnel to assess and update the employee's compensation grade based on their performance and job responsibilities.

## How To Complete This Form

1. **Employee Section**
	* Enter the employee's name and ID in the text field. This is where you can search for the employee by their name or ID to find their record in the system.
2. **Pay Grade Selection**
	* Choose the correct pay grade level for the employee from the dropdown menu. The pay grade levels are:
		+ Level 1
		+ Level 2
		+ Level 3
3. **Reason for Request**
	* Briefly explain the reason for the pay grade request in the text field. Be specific about the employee's performance and any changes that justify the request.
4. **Evaluation Date**
	* Select the date you are requesting the pay grade evaluation for the employee. This date should reflect the current performance period.

## Field-by-Field Explanation

* **Employee** (employee, text, optional)
	+ This field is used to search for the employee's name or ID in the system.
* **Pay Grade** (pay_grade, select_one, optional)
	+ Choose the correct pay grade level for the employee based on their performance and job responsibilities.
	+ Please select the highest level that accurately reflects the employee's current position and performance.
* **Reason for Request** (reason, text, optional)
	+ This field is used to provide a brief explanation for the pay grade request.
	+ Please provide specific details about the employee's performance and any changes that justify the request.
* **Evaluation Date** (date, date, optional)
	+ This field is used to select the date you are requesting the pay grade evaluation for the employee.
	+ Please choose the current performance period to ensure accurate evaluation.

## Tips
* Make sure to fill out all required fields for accurate evaluation.
* Please use specific examples and details to justify the pay grade request.
* If you are unsure about any field, please contact HR or your supervisor for guidance.
