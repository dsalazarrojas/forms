# Worker Attendance Data Request Form - Help Guide
## Purpose
The Worker Attendance Data Request Form is used to gather attendance information from workers. This form is designed to be used when you need to know if a worker is present or absent on a specific date and time.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Worker ID number in the field provided.
2. Enter the Worker Name in the field provided.
3. Select the Department where the worker is located.
4. Enter the Date for which you need to know the worker's attendance.
5. Select the Shift during which the worker was on duty.
6. Enter the Check-in time.
7. Enter the Check-out time.
8. Select the Absence Reason for the worker's absence.
9. Enter any additional information in the Drag and Drop field.

## Field-by-Field Explanation
* **Worker ID** (1, number, required): Enter the unique identifier for the worker.
* **Worker Name** (2, text, required): Enter the name of the worker.
* **Department** (3, select_one, required): Select the department where the worker is located.
* **Date** (4, date, required): Enter the date for which you need to know the worker's attendance.
* **Shift** (5, select_multiple, required): Select the shift during which the worker was on duty.
* **Check-in** (6, time, required): Enter the time the worker checked in.
* **Check-out** (7, time, required): Enter the time the worker checked out.
* **Absence Reason** (8, select_multiple, required): Select the reason for the worker's absence.
* **Drag and Drop** (9, note, required): Enter any additional information you want to provide.
