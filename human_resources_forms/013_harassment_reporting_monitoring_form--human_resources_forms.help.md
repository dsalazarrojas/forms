# Harassment Reporting Monitoring Form - Help Guide
## Purpose
This form is used to report and track incidents of harassment in the workplace. It is essential to fill out this form accurately and completely to ensure that incidents are documented and addressed promptly.

## How To Complete This Form
To complete this form, follow these steps:
1. Fill out the **report_incident** field with a detailed description of the incident.
2. Answer the **incident_details** field by selecting all that apply. If the incident was not severe, select "No."
3. Enter your **reporting_person** details in the text field.
4. Provide a **report_date** for the incident.

## Field-by-Field Explanation

* **report_incident (Text)**: Enter a detailed description of the harassment incident, including the date, time, location, and any other relevant information.
* **incident_details (Select Multiple)**: Select all that apply regarding the incident severity and type:
	+ Select "Yes" if the incident was severe.
	+ Select "Yes" if the incident involved physical or emotional harm.
	+ Select "Yes" if the incident involved retaliation or bullying.
	+ Select "No" if the incident was not severe.
* **reporting_person (Text)**: Enter your name and contact information (e.g., email, phone number) so that we can follow up with you for more information or clarification.
* **report_date (Date)**: Enter the date the incident occurred.
