# Recruitment Process Checklist - Help Guide
## Purpose
The Recruitment Process Checklist is a document that guides the hiring team through the recruitment process, ensuring that all necessary steps are taken and documented for each candidate.

## How To Complete This Form
1. Review the form and select the relevant stages of the recruitment process that apply to the current candidate.
2. Answer each question truthfully, providing the current status of the candidate at each stage.
3. Use the select_one fields to indicate the current status of the candidate, i.e., "Yes" or "No".
4. Use the select_multiple fields to select all applicable stages for the candidate, i.e., multiple "Yes" options.
5. Enter any additional comments or notes in the text fields.

## Field-by-Field Explanation
* **Initial Application**: This field is used to document the candidate's initial application, including any relevant information submitted with their application.
* **Resume Screening**: Indicate whether the candidate's resume has been reviewed and screened for qualification.
* **Interview Scheduling**: Select all the interview stages that have been scheduled for the candidate.
* **Candidate Selection**: Select all the stages that the candidate has been selected for.
* **Background Check**: Enter the current status of the background check, if applicable.
* **Reference Check**: Select "Yes" if a reference check has been conducted.
* **Offer Creation**: Select "Yes" if an offer has been created for the candidate.
* **Candidate Feedback**: Enter any additional comments or feedback provided to the candidate.
* **Hiring Decision**: Select "Yes" if the hiring decision has been made.
* **Final Notes**: Enter any final notes or comments about the candidate.
* **Candidate Status**: Select the current status of the candidate, either "Active" or "Inactive".
* **Candidate Contact**: Select "Yes" if you have contact information for the candidate.
* **Follow Up**: Select all the follow-up stages that have been completed for the candidate.

## Tips
- Ensure that all stages of the form are filled out for each candidate.
- Review the form regularly to track progress and make decisions.
- Use the form to communicate with the candidate and stakeholders, providing clear status updates.
