# Temporary Assignment Absence Form - Help Guide
## Purpose

The Temporary Assignment Absence Form is a tool for tracking and managing temporary assignments of employees. This form helps ensure that all relevant information is captured and communicated effectively, allowing for smoother transitions and better resource allocation.

## How To Complete This Form

Before starting, make sure to have all necessary information ready, including:

* Employee's name
* Start and end dates of the assignment
* Description of the assignment
* Status of the assignment (Approved, Rejected, or Pending)

## Field-by-Field Explanation

* **Temporary Assignment Absence Form** (`temporary_assignment_absence_form`, text, optional): This field is for any additional comments or notes about the temporary assignment. It's not a required field, so feel free to skip it if not necessary.
* **Name** (`name`, text, optional): This field is for the name of the employee who is assigned to the temporary project or role.
* **Start Date** (`start_date`, date, optional): Enter the start date of the temporary assignment. Please use the format 'mm/dd/yyyy' or 'mm/dd/yy' (e.g., 01/01/2024 or 01/01/24).
* **End Date** (`end_date`, date, optional): Enter the end date of the temporary assignment. Please use the format 'mm/dd/yyyy' or 'mm/dd/yy' (e.g., 01/01/2024 or 01/01/24).
* **Assigned Tool** (`assigned_tool`, text, optional): This field is for any specific tool or resource assigned to the employee during the temporary assignment.
* **Description** (`description`, text, optional): This field is for a brief description of the temporary assignment, explaining its purpose and scope.
* **Status** (`status`, select_one, required): This field is for tracking the status of the temporary assignment. Please select from the options:
	+ Approved
	+ Rejected
	+ Pending

## Tips

* Before submitting the form, ensure that you have discussed and agreed upon the temporary assignment with all affected parties.
* This form is for tracking and managing temporary assignments, not for requesting permanent changes to an employee's role.
* If you need to make changes to a temporary assignment, please update the form accordingly and re-submit it for review and approval.
