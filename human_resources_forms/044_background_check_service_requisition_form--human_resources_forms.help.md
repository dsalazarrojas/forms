# Background Check Service Requisition Form - Help Guide
## Purpose
The Background Check Service Requisition Form is a tool for HR departments to request background check services for new or existing employees.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the name of the HR representative or requester.
2. Select the hiring department that is making the request.
3. Enter the budget code or account code associated with the requisition.
4. Enter the full name of the candidate or employee.
5. Select the type of hire or transaction (e.g., new external hire, internal promotion).
6. Select the authorized screening package (e.g., Basic, Standard, Comprehensive).
7. Indicate whether a drug screen is included in this requisition.
8. If necessary, enter any custom search requirements (e.g., international checks, professional licenses).
9. Select "Authorized" to confirm HR management authorization.
10. Enter the date of authorization.
11. Enter any internal HR notes.

## Field-by-Field Explanation
* **HR Representative/Requester Name**: Enter the name of the HR representative or requester who is submitting this form.
* **Hiring Department**: Select the department that is making the request for the background check.
* **Budget/Account Code**: Enter the budget code or account code associated with this requisition.
* **Candidate Full Name**: Enter the full name of the candidate or employee.
* **Type of Hire/Transaction**: Select the type of hire or transaction (e.g., new external hire, internal promotion).
* **Authorized Screening Package**: Select the authorized screening package (e.g., Basic, Standard, Comprehensive).
* **Is a drug screen included in this requisition?**: Indicate whether a drug screen is included in this requisition.
* **Specific Custom Search Requirements**: If necessary, enter any custom search requirements (e.g., international checks, professional licenses).
* **HR Management Authorization**: Select "Authorized" to confirm HR management authorization.
* **Date of Authorization**: Enter the date of authorization.
* **Internal HR Notes**: Enter any internal HR notes or comments.

## Tips
* Ensure that all required fields are completed before submitting the form.
* Use the correct budget code or account code to ensure proper accounting and tracking.
* Be specific when entering custom search requirements, as this will affect the scope of the background check.
* Enter the correct date and time of authorization to ensure accurate record-keeping.
* Review and verify all information before submitting the form to ensure accuracy and completeness.
