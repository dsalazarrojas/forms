# Worker Language Delegation Form - Help Guide
## Purpose

The Worker Language Delegation Form is used to delegate tasks or projects to workers, ensuring clear communication and productivity within the team.

## How To Complete This Form

1. Fill out the form completely and accurately, providing all the required information for each field.
2. Enter the supervisor's name and ID in the first two fields.
3. Select the languages for which the worker is available to work on the task.
4. Enter the task description, start and end dates, start and end times, and expected duration.
5. Select the task status and frequency.
6. Choose the assigned tool for the task.
7. Enter any additional supervisor notes or worker notes (if applicable).

## Field-by-Field Explanation

* **Supervisor Name**: Enter the supervisor's name who is delegating the task to you.
* **Supervisor ID**: Enter the supervisor's ID for reference and tracking purposes.
* **Worker Name**: Enter your own name as the worker assigned to the task.
* **Languages**: Select the languages you are proficient in or available to work on. You can select multiple languages.
* **Task Description**: Describe the task or project that needs to be completed.
* **Task Frequency**: Select the frequency of the task, which can be Daily, Weekly, or Monthly.
* **Task Duration**: Select the expected duration of the task, which can be Short (less than 1 hour), Medium (1-4 hours), or Long (more than 4 hours).
* **Start Date**: Enter the start date of the task in mm/dd/yyyy format.
* **End Date**: Enter the end date of the task in mm/dd/yyyy format.
* **Start Time**: Enter the start time of the task in hh:mm a format.
* **End Time**: Enter the end time of the task in hh:mm a format.
* **Assigned Tool**: Enter the tool assigned for the task.
* **Task Status**: Select the status of the task, which can be New, In Progress, Completed, or On Hold.
* **Supervisor Notes**: Enter any additional notes or instructions from the supervisor.
* **Worker Notes**: Enter any additional notes or comments as the worker.
