# Editable Mentor Application - Help Guide
## Purpose
The Editable Mentor Application form is used to create, edit, and manage mentorship applications.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields: First Name, Last Name, Email, Role, Mentor Name, and Application Status.
2. Select the relevant options for the Role and Mentor Name fields.
3. Enter the start and end dates for the mentorship.
4. You can add notes to the form if necessary.
5. Click "Submit" to save the changes.

## Field-by-Field Explanation
* **First Name** (`first_name`, text, required): Enter the mentor's first name.
* **Last Name** (`last_name`, text, required): Enter the mentor's last name.
* **Email** (`email`, email, required): Enter the mentor's email address.
* **Phone** (`phone`, text, optional): Enter the mentor's phone number (if applicable).
* **Role** (`role`, select_one, required): Select the role the mentor will play (Mentor, Assistant, Coordinator).
* **Start Date** (`start_date`, date, optional): Enter the start date of the mentorship.
* **End Date** (`end_date`, date, optional): Enter the end date of the mentorship.
* **Mentor Name** (`mentor_name`, select_multiple, required): Select the mentor's name from the dropdown list.
* **Application Status** (`application_status`, select_one, required): Select the current status of the mentorship (Active, Inactive, Removed).
* **Notes** (`notes`, note, optional): Add any additional notes about the mentorship.
* **Created By** (`created_by`, text, optional): Enter the person who created the mentorship record (optional).
* **Created Date** (`created_date`, date, optional): Enter the date the mentorship record was created (automatically populated).
