# Internal Salary Audit Request Form - Help Guide
## Purpose
The Internal Salary Audit Request Form is used to request an internal salary audit for an employee. This form is intended to gather necessary information to accurately process the audit request.

## How To Complete This Form
To complete this form:

1.  Select the employee whose salary you would like to audit.
2.  Enter the employee's current salary.
3.  Choose the type of salary discrepancy (e.g., Overtime, Bonus, Commission, etc.).
4.  Select the frequency of the discrepancy (e.g., Monthly, Quarterly, etc.).
5.  Enter the discrepancy amount.
6.  Provide a reason for the discrepancy.
7.  Attach any supporting documentation (if necessary).
8.  Add any comments from the employee.

## Field-by-Field Explanation
- **Employee Information** (`employee`, `text`, required): Please enter the employee's name and ID number for accurate processing.
- **Salary Details** (`salary_details`, `number`, required): Enter the employee's current salary to ensure accurate calculations.
- **Salary Discrepancy Type** (`discrepancy_type`, `select_one`, optional): Choose the type of salary discrepancy (e.g., Overtime, Bonus, Commission, etc.).
- **Discrepancy Frequency** (`discrepancy_frequency`, `select_multiple`, optional): Select the frequency of the discrepancy (e.g., Monthly, Quarterly, etc.).
- **Discrepancy Amount** (`discrepancy_amount`, `number`, required): Enter the exact discrepancy amount.
- **Reason for Discrepancy** (`reason_for_discrepancy`, `text`, required): Explain the reason for the discrepancy to ensure accurate processing.
- **Supporting Document** (`supporting_document`, `text`, optional): Attach any supporting documentation required for the audit.
- **Employee Comments** (`employee_comments`, `text`, optional): Add any additional comments from the employee.
- **Approver Comments** (`approver_comments`, `text`, optional): Add any comments from the approver.
- **Reviewer Comments** (`reviewer_comments`, `text`, optional): Add any comments from the reviewer.
- **Approver** (`approver`, `select_multiple`, optional): Select the approver's name (Manager, HR, Director, etc.).
