# Workplace Mentorship Expense Claim Form - Help Guide
## Purpose
The Workplace Mentorship Expense Claim Form is used to report and claim workplace mentorship expenses. This form is used by HR department to verify and process expense claims.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the amount of the expense.
2. Briefly describe the expense.
3. Select the date the expense was incurred.
4. Choose the type of expense.
5. Select the category and subcategory of the expense.
6. Select any additional subcategories.
7. Fill in the claimed amount.

## Field-by-Field Explanation
- **Amount**: Enter the total amount of the expense.
- **Description**: Briefly describe the expense you are claiming. 
  (e.g., "Mentorship meeting with John Doe at 123 Main St.")
- **Date of Expense**: Enter the date of the expense in the format (mm/dd/yyyy). (e.g., 12/05/2023)
- **Type of Expense**: Select the type of expense you are claiming (e.g., "Mentorship Event", "Travel", etc.).
- **Category of Expense**: Select one or more categories that apply to the expense (e.g., "Mentorship", "Travel", "Food and Beverage", etc.).
- **Subcategory of Expense**: Select one or more subcategories that apply to the expense (e.g., "Meeting", "Food", etc.). 
  - **Subcategory of Expense 2**: Select one or more subcategories that apply to the expense (e.g., "Breakfast", "Lunch", etc.).
  - **Subcategory of Expense 3**: Select one or more subcategories that apply to the expense (e.g., "Hotel", "Transportation", etc.).
  - **Subcategory of Expense 4**: Select one or more subcategories that apply to the expense (e.g., "Parking", "Gas", etc.). 
- **Claimed Amount**: Enter the amount you are claiming for the expense.
