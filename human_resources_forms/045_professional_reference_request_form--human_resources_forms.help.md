# Professional Reference Request Form - Help Guide
## Purpose
The Professional Reference Request Form is used to request a professional reference from an employee's previous work experience. This form helps you gather information about an employee's job responsibilities, reasons for leaving, and other relevant details.

## How To Complete This Form

1.  Review the form carefully and ensure you have all the necessary information before proceeding.
2.  Fill out the form accurately and completely, providing as much detail as possible.
3.  Select the correct options for the "Employer" and "Reference Relationship" fields.
4.  Ensure that the "Review Date" and "Review By" fields are filled out correctly.

## Field-by-Field Explanation

*   **Reference Name** (`reference_name`, Text, Optional): Enter the name of the employee whose reference is being requested.
*   **Job Title** (`job_title`, Text, Optional): Enter the job title of the employee at the time of their previous employment.
*   **Previous Job Title** (`previous_job_title`, Text, Optional): Enter the job title of the employee's previous role.
*   **Employer** (`employer`, Select Multiple, Optional): Select the company where the employee was previously employed.
*   **Work Phone** (`work_phone`, Text, Optional): Enter the employee's work phone number.
*   **Work Email** (`work_email`, Email, Optional): Enter the employee's work email address.
*   **Start Date** (`start_date`, Date, Optional): Enter the start date of the employee's previous employment.
*   **End Date** (`end_date`, Date, Optional): Enter the end date of the employee's previous employment.
*   **Reason for Leaving** (`reason_for_leaving`, Text, Optional): Enter the reason for the employee's departure from their previous role.
*   **Job Duration** (`job_duration`, Number, Optional): Enter the duration of the employee's previous employment.
*   **Job Status** (`job_status`, Select One, Optional): Select the job status of the employee at the time of leaving (Active or Inactive).
*   **Reference Relationship** (`reference_relationship`, Select Multiple, Optional): Select the relationship between the reference and the employee (Current Manager, Previous Manager, Coworker, Supervisor).
*   **Reference Type** (`reference_type`, Select One, Optional): Select the type of reference (Professional Reference, Personal Reference).
*   **Reference Comments** (`reference_comments`, Text, Optional): Enter any additional comments about the reference.
*   **Submitted By** (`submitted_by`, Select Multiple, Optional): Select who submitted the reference request (HR Department, Employee).
*   **Review Date** (`review_date`, Date, Optional): Enter the date for reviewing the reference.
*   **Review By** (`review_by`, Select One, Optional): Select who reviews the reference (Manager, HR Department, Employee).
*   **Submitted To** (`submitted_to`, Select One, Optional): Select who the reference is submitted to (Manager, HR Department).
*   **Submitted Date** (`submitted_date`, Date, Optional): Enter the date the reference was submitted.
*   **Submitter** (`submitted_by`, Text, Optional): Enter the name of the person who submitted the reference.
*   **Reference Source** (`reference_source`, Select One, Optional): Select the source of the reference (Previous Employer, Colleague, Other).
*   **Reference Note** (`reference_note`, Text, Optional): Enter any additional notes about the reference.

This guide will help you understand how to complete the Professional Reference Request Form accurately and effectively.
