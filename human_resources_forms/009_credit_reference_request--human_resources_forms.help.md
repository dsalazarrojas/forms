# credit_reference_request - Help Guide
## Purpose
This form collects information about an employee's professional reference for employment or certification purposes.

## How To Complete This Form

1. Enter your First Name in the field marked "First Name".
2. Enter your Last Name in the field marked "Last Name".
3. Enter your Email in the field marked "Email".
4. Enter your Phone number in the field marked "Phone".
5. Enter the Reference Name in the field marked "Reference Name".
6. Enter the Reference Organization in the field marked "Reference Organization".
7. Enter a description of your reference relationship with the Reference Name in the field marked "Reference Relationship".
8. Enter the number of years you have known the reference in the field marked "Years Known".
9. Enter the reference's Phone number in the field marked "Reference Phone".
10. Enter the reference's Email in the field marked "Reference Email".
11. Enter a brief reason for the reference in the field marked "Reason".
12. (Optional) Add any additional comments about the reference in the field marked "Comments".

## Field-by-Field Explanation
- **First Name** (`1`, `text`, required): Enter your first name as it is written on your identification documents.
- **Last Name** (`2`, `text`, required): Enter your last name as it is written on your identification documents.
- **Email** (`3`, `email`, required): Enter your work email address or any other email address you would like to provide.
- **Phone** (`4`, `text`, required): Enter your phone number where you can be reached.
- **Reference Name** (`5`, `text`, required): Enter the name of the reference you are providing.
- **Reference Organization** (`6`, `text`, required): Enter the name of the organization or company where the reference works or has worked.
- **Reference Relationship** (`7`, `text`, required): Briefly describe your relationship with the reference.
- **Years Known** (`8`, `number`, required): Enter the number of years you have known the reference.
- **Reference Phone** (`9`, `text`, required): Enter the reference's phone number.
- **Reference Email** (`10`, `email`, required): Enter the reference's email address.
- **Reason** (`11`, `text`, required): Briefly describe the reason for providing this reference.
- **Comments** (`12`, `text`, optional): Provide any additional comments about the reference.
- **Form ID** (`13`, `text`, optional): This field is not intended for user input.
- **Assigned Tool** (`14`, `text`, optional): This field is not intended for user input.
- **Category** (`15`, `select_one`, required): Select the category for this reference request (e.g. Human Resources Forms).
- **Category 2** (`16`, `select_multiple`, optional): Select any additional categories for this reference request (e.g. Other, Something Else).
- **Description** (`17`, `text`, optional): Provide a description of the reference request.
- **Output File** (`18`, `text`, optional): This field is not intended for user input.
- **Created By** (`19`, `text`, optional): This field is not intended for user input.
- **Created At** (`20`, `date`, optional): This field is populated automatically.
- **Updated At** (`21`, `date`, optional): This field is populated automatically.
- **Assigned Tool** (`22`, `text`, optional): This field is not intended for user input.
- **Description 2** (`23`, `text`, optional): Provide a description of this reference request.
- **Description 3** (`24`, `text`, optional): This field is not intended for user input.
- **Description 4** (`25`, `text`, optional): This field is not intended for user input.
