# Reception Supervisor Evaluation - Help Guide
## Purpose
The Reception Supervisor Evaluation form is used to assess the performance of a reception supervisor in a hospital setting.

## How To Complete This Form
1. Select the evaluation period from the options provided.
2. Choose the evaluation date from the date picker field.
3. If applicable, select the evaluation time from the time picker field.
4. Choose the evaluation length from the options provided.
5. Rate the reception supervisor's performance as either Good or Fair.
6. Select the performance criteria that were met or not met during the evaluation period.
7. Add any additional comments or feedback in the comments field.
8. Finally, evaluate the overall performance of the reception supervisor as either Yes or No.

## Field-by-Field Explanation
* **Evaluation Period**: Select the period during which the reception supervisor's performance was being evaluated. This can be either "Yes" or "No" to indicate whether the evaluation was conducted during this period.
* **Evaluation Date**: Enter the date on which the evaluation took place. This is a date field where you can select a date from the calendar.
* **Evaluation Time**: If applicable, select the time of day when the evaluation took place. This is a time field where you can select a time of day.
* **Evaluation Period Length**: Choose the length of time over which the reception supervisor's performance was being evaluated. This can be a number indicating the duration in days or weeks.
* **Evaluation Supervisor Rating**: Rate the reception supervisor's performance as either Good or Fair.
* **Performance Criteria**: Select the performance criteria that were met or not met during the evaluation period. This field allows you to choose multiple criteria from the options provided.
* **Comments**: Add any additional feedback or suggestions for the reception supervisor's performance.
* **Overall Performance**: Evaluate the overall performance of the reception supervisor as either Yes or No.
