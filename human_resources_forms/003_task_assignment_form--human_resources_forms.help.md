# Task Assignment Form - Help Guide

## Purpose
The purpose of this form is to assign tasks to employees and track their progress, availability, and deadline.

## How To Complete This Form
To complete this form, follow the steps below:

1. Review the task list carefully to avoid assigning tasks that are already assigned.
2. Fill out the required fields with accurate information:
	* Task details (select one or multiple)
	* Employee name (select one)
	* Deadline (date)
	* Hours (time)

## Field-by-Field Explanation

* **Task Assignment** (assign_task, text, optional): Enter a brief description of the task to be assigned.
* **Task Details** (task_details, select_multiple, optional): Select one or multiple from the dropdown menu to specify the task details.
	+ 'Yes' and 'No' options are provided for users to select from.
* **Employee Name** (employee_name, select_one, optional): Choose one employee from the dropdown list to assign the task to.
* **Deadline** (task_deadline, date, optional): Enter the deadline for the assigned task.
* **Hours** (task_hours, time, optional): Select the hours required for the task.

## Tips

* If you are unsure about the correct employee for a task, please ask the support team for clarification.
* Ensure that the deadline is reasonable and achievable given the task's complexity.
* If a task has specific requirements, please note these in the task description for clarity.
