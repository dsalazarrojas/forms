# Employee Retention Program Evaluation Form - Help Guide
## Purpose
The Employee Retention Program Evaluation Form is a tool used to gather feedback and evaluate the effectiveness of the Employee Retention Program in the organization. It helps to identify areas of improvement and provide insights to make data-driven decisions to enhance the program's efficiency.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill out all required fields with accurate and detailed information.
2. For the "Satisfaction" and "Retention Initiatives" fields, select the corresponding options from the dropdown lists.
3. For the "Zip Code" field, enter the employee's zip code.
4. For the "Submission Date" field, select the date you are submitting the form.

## Field-by-Field Explanation

* **Employee Name** (`employee_name`, `text`, required): Enter the name of the employee being evaluated.
* **Manager Name** (`manager_name`, `text`, required): Enter the name of the employee's manager.
* **Feedback** (`feedback`, `text`, required): Provide your feedback about the program's effectiveness.
* **Satisfaction** (`satisfaction`, `select_one`, required): Select how satisfied you are with the program.
	+ Options: Satisfied, Dissatisfied
* **Retention Initiatives** (`retention_initiatives`, `select_multiple`, required): Select which retention initiatives are being implemented.
	+ Options: Yes, No
* **Effectiveness** (`effectiveness`, `select_one`, required): Select whether the program is effective.
	+ Options: Yes, No
* **Satisfaction Scale** (`satisfaction_scale`, `number`, required): Enter a scale from 1 to 5 to rate your satisfaction with the program.
* **Action Plans** (`action_plans`, `text`, required): Describe any action plans you have implemented or plan to implement as a result of the feedback.
* **Comments** (`comments`, `text`, required): Enter any additional comments about the program.
* **Submission Date** (`submission_date`, `date`, required): Select the date you are submitting the form.
* **Submitter** (`submitter`, `text`, required): Enter your name and position.
* **Department** (`department`, `text`, required): Enter the department of the employee being evaluated.
* **Division** (`division`, `select_one`, required): Select whether the division is affected.
	+ Options: Yes, No
* **Location** (`location`, `select_one`, required): Select whether the location is affected.
	+ Options: Yes, No
* **Region** (`region`, `select_one`, required): Select whether the region is affected.
	+ Options: Yes, No
* **Country** (`country`, `select_one`, required): Select whether the country is affected.
	+ Options: Yes, No
* **City** (`city`, `select_one`, required): Select whether the city is affected.
	+ Options: Yes, No
* **Zip Code** (`zip_code`, `text`, required): Enter the zip code of the location.
* **Comments Other** (`comments_other`, `text`, required): Enter any additional comments not captured by the other fields.
* **Attachment** (`attachment`, `text`, required): Attach any supporting documents.
* **Attachment 2** (`attachment_2`, `text`, required): Attach any additional documents.
* **Attachment 3** (`attachment_3`, `text`, required): Attach any additional documents.
* **Attachment 4** (`attachment_4`, `text`, required): Attach any additional documents.
* **Attachment 5** (`attachment_5`, `text`, required): Attach any additional documents.

Note: Please ensure that you fill out all required fields accurately and thoroughly to provide valuable feedback.
