# Physician Release To Return To Work Form - Help Guide

## Purpose
This form is used to document a physician's opinion on an employee's fitness to return to work after an injury or illness. It is intended to provide a clear and concise medical opinion that can be used by HR or management to make informed decisions about the employee's return to work status.

## How To Complete This Form
To complete this form, follow these steps:

1. Read the form carefully and ensure you understand the questions and fields.
2. Select "Yes" or "No" to answer the question in section 1: "Has the employee been released to return to work".
3. If the employee has been released to return to work, enter the date of release in the field provided.
4. Enter the date of the injury or illness in the field provided.
5. If the employee has been released to return to work, select "Yes" or "No" to answer the question in section 4: "Is the employee fit to return to work".
6. If the employee has been released to return to work and is fit for duty, enter the date of expected return in the field provided.
7. Enter the date of your signature in the field "Physician signature date".
8. Enter your name and specialty in the fields "Physician name" and "Physician specialty", respectively.

## Field-by-Field Explanation

* **Has the employee been released to return to work** (`physician_release_to_return_to_work_form_1`, `select_one`): This field allows you to answer whether the employee has been cleared to return to work. Select "Yes" if the employee has been released, "No" otherwise.
* **Date of release** (`physician_release_to_return_to_work_form_2`, `date`): Enter the date on which the employee was released to return to work.
* **Date of injury or illness** (`physician_release_to_return_to_work_form_3`, `date`): Enter the date of the injury or illness that prevented the employee from working.
* **Is the employee fit to return to work** (`physician_release_to_return_to_work_form_4`, `select_one`): This field allows you to assess the employee's fitness to return to work. Select "Yes" if the employee is fit, "No" otherwise.
* **Date of expected return** (`physician_release_to_return_to_work_form_5`, `date`): Enter the date on which the employee is expected to return to work, if the employee has been released and is fit for duty.
* **Physician signature date** (`physician_release_to_return_to_work_form_6`, `date`): Enter the date on which you signed this form.
* **Physician name** (`physician_release_to_return_to_work_form_7`, `text`): Enter your name and credentials as a medical professional.
* **Physician specialty** (`physician_release_to_return_to_work_form_8`, `select_multiple`): Select your medical specialty from the options provided: "Primary care physician", "Surgeon", "Orthopedic specialist".
