# Employer Sponsored Visa Application Form - Help Guide

## Purpose
This form is designed to gather necessary information for an Employer Sponsored Visa Application. Please fill out the form accurately and completely to ensure that your application is processed efficiently.

## How To Complete This Form

To complete this form, follow the steps below:

1. Review the form to understand what information is required.
2. Fill out the form accurately and completely.
3. Ensure that all required fields are filled out.

## Field-by-Field Explanation

* **Applicant Information** (page 1):
	+ <label>: This section is for the applicant to provide their personal details.
	+ <type>: Text input field.
	+ <required>: No, this field is optional.
* **Employer Information** (page 1):
	+ <label>: This section is for the employer to provide their details.
	+ <type>: Text input field.
	+ <required>: No, this field is optional.
* **Document Intake** (page 1):
	+ <label>: This section is for the applicant to provide information about the document required for the application.
	+ <type>: Text input field.
	+ <required>: No, this field is optional.
* **Signature** (page 1):
	+ <label>: This section is for the applicant to sign their name.
	+ <type>: Text input field.
	+ <required>: No, this field is optional.
* **Contact Email** (page 2):
	+ <label>: This field is for the contact email of the applicant.
	+ <type>: Email input field.
	+ <required>: Yes, this field is required.
* **Contact Phone** (page 2):
	+ <label>: This field is for the contact phone number of the applicant.
	+ <type>: Text input field.
	+ <required>: No, this field is optional.
* **Document Type** (page 3):
	+ <label>: This field is for selecting the type of document required.
	+ <type>: Select one option.
	+ <required>: Yes, this field is required.
* **Upload Document** (page 3):
	+ <label>: This field is for uploading the required document.
	+ <type>: Text input field.
	+ <required>: Yes, this field is required.
* **Signature** (page 3):
	+ <label>: This section is for the applicant to sign their name digitally.
	+ <type>: Text input field.
	+ <required>: No, this field is optional.

## Tips

- Please ensure that all required fields are filled out accurately and completely.
- If you are unsure about any section, please review the field explanations above.
- If you have any further questions or concerns, please contact form@gic.mx.
