# Worker_s Compensation Records Release Form - Help Guide
## Purpose

This form is used to release workers' compensation records, and it's essential to complete it accurately to ensure the information is collected correctly. 

## How To Complete This Form

1. **Enter the employee name and email**: In this section, provide the name and email address of the employee for whom you're releasing the records.
2. **Enter the employer name and address**: Fill in the name and address of the employer. This information helps ensure that records are released to the correct organization.
3. **Choose the consent date**: Choose the date you're giving consent to release the records.
4. **Choose the signature date**: Select the date you sign this form.
5. **Sign with your preferred method**: Choose how you'd like to sign the form, either handwritten, electronic, or other (if applicable).
6. **Choose how you'd like to sign the form**: Select how you'd like to sign the form, either in-person, by email, or by fax.
7. **Enter the document ID and file name**: Enter the ID of the document and its name.
8. **Enter the file size**: Enter the size of the file.
9. **Choose the file type**: Select the type of file you're releasing, such as a document, video, or audio.
10. **Additional information**: You may have other details to include that aren't listed above. If so, use this section to provide them.
11. **Employee and employer contact information**: Enter the contact information for both you and the employer.
12. **Employee relationship**: If applicable, choose the type of relationship the employee has with the organization.
13. **Consent message**: You may want to include a message explaining why you're releasing the records.
14. **Employee and employer notes**: You may have additional notes to include for employee or employer.
15. **Other agreements**: If there are any other agreements, include them here.

## Field-by-Field Explanation

* **Employee Name**: The name of the employee for whom you're releasing the records.
* **Employee Email**: The email address of the employee.
* **Employee Phone**: The phone number of the employee.
* **Employee Address**: The address of the employee (not required).
* **Employee Relationship**: The type of relationship the employee has with the organization (not required).
* **Consent Date**: The date when you're giving consent to release the records.
* **Signature Date**: The date when you sign this form.
* **Signature**: Your signature (required).
* **Employer Name**: The name of the employer (required).
* **Employer Phone**: The phone number of the employer.
* **Employer Address**: The address of the employer (not required).
* **Consent Type**: The type of consent you're giving (not required).
* **Consent Message**: A message explaining why you're releasing the records (not required).
* **Employee Notes**: Additional notes for the employee (not required).
* **Employer Notes**: Additional notes for the employer (not required).
* **Other Agreements**: Any other agreements (not required).
* **Document ID**: The ID of the document.
* **File Name**: The name of the file.
* **File Size**: The size of the file.
* **File Type**: The type of file (not required).
* **Other Contacts**: Additional contacts (not required).
* **Signature Type**: The method of your signature (not required).
* **Signature Method**: The method of signing the form (not required).
