# Writing Residency Leave Of Absence Form - Help Guide
## Purpose

This form is used to request a leave of absence, which includes details such as category, description of reason for absence, dates of absence, and approval status.

## How To Complete This Form

To complete this form, follow these steps:

1. Fill in the form title to provide a brief summary of the request.
2. Select the category of the leave request.
3. Provide a brief description of the reason for the absence.
4. Enter the start and end dates of the absence.
5. Select the approval status.
6. Enter any comments or remarks.
7. Optionally, select the assigned user to handle the request.

## Field-by-Field Explanation

* **Form Title** (`form_title`, text, optional): Enter a brief summary of the request.
* **Category** (`category`, select_one, required): Select the category of the leave request from the options provided.
* **Description** (`description`, text, optional): Provide a brief description of the reason for the absence.
* **Date Of Absence Begin** (`date_of_absence_begin`, date, required): Enter the start date of the absence.
* **Date Of Absence End** (`date_of_absence_end`, date, required): Enter the end date of the absence.
* **Reason For Absence** (`reason_for_absence`, text, optional): Provide a detailed description of the reason for the absence.
* **Approval Status** (`approval_status`, select_one, required): Select the approval status of the request from the options provided.
* **Remarks** (`remarks`, text, optional): Enter any additional comments or remarks about the request.
* **Comments** (`comments`, text, optional): Enter any additional comments or remarks about the request.
* **Assigned User** (`assigned_user`, text, optional): Select the user who is handling the request.
* **Created Date** (`created_date`, date, required): This field is automatically populated when the form is submitted.
* **Updated Date** (`updated_date`, date, optional): This field is automatically populated when the form is updated.
