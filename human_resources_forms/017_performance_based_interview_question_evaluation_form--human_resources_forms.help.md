# Performance Based Interview Question Evaluation Form - Help Guide
## Purpose
This form is used to record and evaluate the performance of an employee based on a performance-based interview. It captures essential information such as name, interview type, and scores for various questions.

## How To Complete This Form
To complete this form, follow these steps:

1. Ensure you have all the necessary information about the employee's performance.
2. Fill in the employee's first name and last name in the first and last name fields, respectively.
3. Select the correct interview type from the options provided.
4. Answer the questions based on the employee's performance, assigning scores for each question.
5. Fill in the employee's email address in the email field.
6. Provide any additional comments or notes about the interview.
7. If applicable, select the follow-up options to indicate if follow-up is required and the follow-up timeframe.

## Field-by-Field Explanation
* **First Name (1)** (`first_name`, `text`, required/optional): Enter the employee's first name.
* **Last Name (2)** (`last_name`, `text`, required/optional): Enter the employee's last name.
* **Interview Type (3)** (`interview_type`, `select_one`, required/optional): Select the type of interview (e.g., "Type A", "Type B", "Type C").
* **Score 1 (9)** (`score_1`, `number`, required/optional): Enter the score for question 1.
* **Score 2 (10)** (`score_2`, `number`, required/optional): Enter the score for question 2.
* **Score 3 (11)** (`score_3`, `number`, required/optional): Enter the score for question 3.
* **Score 4 (12)** (`score_4`, `number`, required/optional): Enter the score for question 4.
* **Note (13)** (`note`, `text`, required/optional): Enter any additional notes about the interview.
* **Email (14)** (`email`, `email`, required/optional): Enter the employee's email address.
* **Phone Number (15)** (`phone_number`, `text`, required/optional): Enter the employee's phone number.
* **Comments (16)** (`comments`, `text`, required/optional): Enter any additional comments about the interview.
* **Date (17)** (`date`, `date`, required/optional): Enter the date of the interview.
* **Time (18)** (`time`, `time`, required/optional): Enter the time of the interview.
* **Interview Notes (19)** (`interview_notes`, `text`, required/optional): Enter any additional notes about the interview.
* **Follow Up (20)** (`follow_up`, `select_one`, required/optional): Select whether follow-up is required.
* **Next Steps (21)** (`next_steps`, `text`, required/optional): Enter any next steps for the employee.
* **Follow Up Notes (22)** (`follow_up_notes`, `text`, required/optional): Enter any follow-up notes.
* **Next Steps - Follow Up (23)** (`next_steps_follow_up`, `select_multiple`, required/optional): Select whether next steps will be followed up on.
* **Follow Up Timeframe (24)** (`follow_up_timeframe`, `time`, required/optional): Enter the follow-up timeframe.

Note: Required fields are marked with a asterisk (*) symbol.
