# COVID 19 Public Survey Form - Help Guide
## Purpose
The COVID-19 Public Survey Form is designed to collect information about the public's demographic characteristics, attitudes, and behaviors regarding the COVID-19 pandemic. The form is intended to help understand the community's perceptions and preferences, which can inform public health policies and interventions.

## How To Complete This Form
1. Select the correct answers for each field based on your real-life experiences and perceptions.
2. For demographic information, fill in your age group and select your vaccination status.
3. If you are comfortable, describe your attitudes toward the COVID-19 vaccination in the "Attitudes toward vaccine" field.
4. Indicate your comfort level with returning to work in the "Willingness to return to work" field.
5. Select all sources from which you obtain COVID-19-related information.
6. Choose your preferred method of receiving updates and information.
7. If you have any additional comments, feel free to type them in the "Additional comments" field.
8. Fill in the date on which you completed this survey.
9. Finally, indicate your consent for anonymized data to be used for research purposes.

## Field-by-Field Explanation

* **Age group**: Select the range that best describes your age group.
	+ Select "Under 18" for ages under 18 years old.
	+ Select "18 to 34" for ages between 18 and 34 years old.
	+ Select "35 to 54" for ages between 35 and 54 years old.
	+ Select "55 and over" for ages 55 and above.
* **Vaccination status**: Select your current vaccination status.
	+ Select "Not vaccinated" if you have not received a COVID-19 vaccination.
	+ Select "Partially vaccinated" if you have received some but not all recommended doses.
	+ Select "Fully vaccinated" if you have completed all recommended doses.
* **Attitudes toward vaccine**: Describe your views or concerns regarding the COVID-19 vaccine.
* **Willingness to return to work**: Indicate your comfort level with returning to your workplace.
	+ Select "Very comfortable" if you are very confident and eager to return.
	+ Select "Somewhat comfortable" if you are somewhat hesitant but willing.
	+ Select "Not comfortable" if you are not comfortable returning.
* **Sources of information**: Select all sources from which you obtain COVID-19-related information.
	+ Select "News media" for news articles, TV, or radio.
	+ Select "Social media" for social media platforms.
	+ Select "Healthcare providers" for medical professionals.
	+ Select "Government websites" for official government websites.
* **Preferred communication channel**: Choose how you prefer to receive updates and information.
	+ Select "Email" for email updates.
	+ Select "SMS" for text messages.
	+ Select "Website" for updates on a specific website.
	+ Select "Social media" for updates on social media platforms.
* **Additional comments**: Type any other feedback or comments you may have.
* **Consent for research**: Indicate your consent for anonymized data to be used for research purposes.
	+ Select "True" to allow data to be used.
	+ Select "False" to decline data use.
* **Survey date**: Fill in the date on which you completed this survey.
* **Survey date**: The date on which you completed this survey.

Note: The fields marked with an asterisk (\*) are required to be completed for the form to be valid.
