# Overtime Waiver Form - Help Guide
## Purpose
The Overtime Waiver Form is used to request and approve overtime work. It captures essential information for the employee and manager, including the employee's details, request details, and signatures.

## How To Complete This Form
1. Fill out your employee information in the "Employee Name", "Employee ID", and "Employee Signature" sections.
2. Enter the request details in the "Period Start Date", "Period End Date", "Period Start Time", "Period End Time", and "Period Type" sections.
3. Choose the correct period type from the options provided in the "Period Type" section.
4. Specify the period duration in the "Period Duration" section.
5. If you're a manager, enter your name and title in the "Manager Name" and "Manager Title" sections, and sign in the "Manager Signature" section.
6. If you're an employee, enter your manager's name and title in the "Alternate Manager Name" and "Alternate Manager Title" sections, and sign in the "Alternate Manager Signature" section.

## Field-by-Field Explanation
* **Manager Name** (`manager_name`): Enter your direct manager's name.
* **Employee Name** (`employee_name`): Enter your name.
* **Manager Title** (`manager_title`): Enter your direct manager's title.
* **Employee ID** (`employee_id`): Enter your employee ID number.
* **Period Start Date** (`period_start_date`): Enter the start date of the overtime period.
* **Period End Date** (`period_end_date`): Enter the end date of the overtime period.
* **Period Start Time** (`period_start_time`): Enter the start time of the overtime period.
* **Period End Time** (`period_end_time`): Enter the end time of the overtime period.
* **Period Type** (`period_type`): Choose the type of period (e.g., Overtime, Holiday, Vacation, etc.).
* **Period Duration** (`period_duration`): Specify the duration of the overtime period.
* **Manager Signature** (`manager_signature`): Sign and date the approval or denial of the overtime request.
* **Employee Signature** (`employee_signature`): Sign the overtime request.
* **Date Submitted** (`date_submitted`): The date the request was submitted.
* **Time Submitted** (`time_submitted`): The time the request was submitted.
* **Overtime Waiver** (`overtime_waiver`): Indicate whether or not you're approving the overtime request.
* **Overtime Waiver Note** (`overtime_waiver_note`): Provide any additional comments or explanations about the waiver.
* **Alternate Manager Name** (`manager_name_2`): If you're an employee, enter your manager's name if you're submitting the request on their behalf.
* **Alternate Period Start Time** (`period_start_time_2`): If you're an employee, enter the alternate start time of the period.
* **Alternate Period End Time** (`period_end_time_2`): If you're an employee, enter the alternate end time of the period.
* **Alternate Period Start Date** (`period_start_date_2`): If you're an employee, enter the alternate start date of the period.
* **Alternate Period End Date** (`period_end_date_2`): If you're an employee, enter the alternate end date of the period.
* **Alternate Manager Title** (`manager_title_2`): If you're an employee, enter your manager's title.
* **Alternate Employee ID** (`employee_id_2`): If you're an employee, enter your employee ID number.
* **Alternate Employee Name** (`employee_name_2`): If you're an employee, enter your name.
* **Alternate Manager Signature** (`manager_signature_2`): If you're an employee, sign and date the approval or denial of the overtime request on behalf of your manager.
* **Alternate Period Duration** (`period_duration_2`): If you're an employee, specify the duration of the overtime period.
