# Manufacturing Line Supervisor Interview Form - Help Guide
## Purpose
This form is designed to capture information for manufacturing line supervision interviews, which are typically conducted when a supervisor needs to evaluate a candidate's performance in a specific production line. The form ensures that necessary details are recorded consistently and accurately for future reference.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the relevant production line from the dropdown menu.
2. Enter the date of the interview.
3. Choose the start time of the interview.
4. Provide the name of the supervisor.
5. Specify the interview location.
6. Score the candidate's performance using the provided scale.
7. Enumerate the skills demonstrated by the candidate.
8. Add any notes related to the interview.
9. (Optional) Provide the assigned tool.
10. (Optional) Enter any production line-specific notes.
11. (Optional) Add any additional comments.
12. (Optional) Indicate whether the candidate is recommended for promotion.

## Field-by-Field Explanation
* **Manufacturing Line Supervisor Interview Form** (`manufacturing_line_supervisor_interview_form`): This field is a placeholder title and should not be edited.
* **Production Line** (`production_line_name`): Select the correct production line from the dropdown menu to ensure accuracy.
* **Interview Date** (`interview_date`): Enter the date of the interview, using the standard date format (e.g., 2022-07-25).
* **Start Time** (`start_time`): Choose the start time of the interview, using the 24-hour format (e.g., 08:00 for 8:00 AM).
* **Supervisor Name** (`supervisor_name`): Enter the name of the supervisor conducting the interview.
* **Interview Location** (`interview_location`): Specify the location where the interview took place.
* **Candidate Performance Score** (`candidate_performance_score`): Score the candidate's performance using the provided scale (e.g., 1-10).
* **Candidate Skills** (`candidate_skills`): Enumerate the skills demonstrated by the candidate during the interview.
* **Notes** (`notes`): Add any notes about the candidate's performance or any other relevant information.
* **Assigned Tool** (`assigned_tool`): (Optional) Enter the tool assigned to the candidate for this interview.
* **Production Line Notes** (`production_line_notes`): (Optional) Add any production line-specific notes.
* **Additional Comments** (`additional_comments`): (Optional) Add any additional comments about the candidate.
* **Recommended For Promotion** (`recommended_for_promotion`): (Optional) Indicate whether the candidate is recommended for promotion.
