# employee_performance_evaluation_form - Help Guide
## Purpose
The employee performance evaluation form is used to document and provide feedback on an employee's performance. It is intended to be filled out periodically to ensure that performance evaluations are up to date and accurate.

## How To Complete This Form
To complete this form, follow these steps:

1. Choose the type of performance evaluations that apply to the employee from the provided options. This may include "Evaluations" or "Other".
2. Add any detailed comments or feedback in the "performance_comments" section.
3. Rate the employee's performance as "High", "Medium", or "Low" using the provided options.
4. Select a date for the performance evaluation.

## Field-by-Field Explanation

* **performance_evaluations** (Select Multiple, employee_performance_evaluation_form_page_1):
	+ Select all applicable performance evaluations from the provided options.
* **performance_comments** (Note, employee_performance_evaluation_form_page_2):
	+ Add any detailed feedback or comments for the employee's performance.
* **employee_rating** (Select One, employee_performance_evaluation_form_page_3):
	+ Choose a rating for the employee's performance (High, Medium, or Low).
* **performance_date** (Date, employee_performance_evaluation_form_page_4):
	+ Select a date for the performance evaluation.
