# Landman Project Questionnaire - Help Guide
## Purpose
The Landman Project Questionnaire is a form designed to collect information about ongoing and upcoming projects within the organization. This form helps to track projects' details, such as project descriptions, leaders, start and end dates, categories, locations, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter a brief description of the project in the **Project Description** field.
2. Provide the name of the person leading the project in the **Project Leader** field.
3. Enter the start and end dates of the project in the **Project Start Date** and **Project End Date** fields, respectively.
4. Select the project category from the options provided in the **Project Category** field.
5. Indicate if the project location is relevant to you in the **Project Location** field.
6. Enter the name of the contact person responsible for the project in the **Contact Person** field.
7. Enter the name of the company associated with the project in the **Company Name** field.
8. Select the job function(s) of the project leader in the **Job Function** field.
9. Enter the status of the project (Active or Inactive) in the **Project Status** field.
10. Enter any additional notes about the project in the **Project Notes** field.
11. Enter the project email address in the **Project Email** field.
12. Enter the project phone number in the **Project Phone** field.
13. Enter the company address in the **Company Address** field.
14. Enter the job location in the **Job Location** field.
15. Enter the job responsibilities in the **Job Responsibilities** field.
16. Enter the start date of the job in the **Job Start Date** field.
17. Enter the end date of the job in the **Job End Date** field.
18. Enter the number of employees associated with the project in the **Employee Count** field.
19. Enter the category of the job in the **Job Category** field.
20. Select the type of job (Yes or No) in the **Job Type** field.
21. Enter the department name associated with the project in the **Department Name** field.
22. Enter the company website in the **Company Website** field.
23. Enter the status of the job (Active or Inactive) in the **Job Status** field.
24. Enter the name of the person who created the project in the **Created By** field.

## Field-by-Field Explanation
- **Project Description** (`project_description`, text, required: false): A brief description of the project.
- **Project Leader** (`project_leader`, text, required: false): The name of the person leading the project.
- **Project Start Date** (`project_start_date`, date, required: false): The start date of the project.
- **Project End Date** (`project_end_date`, date, required: false): The end date of the project.
- **Project Category** (`project_category`, select_one, required: false): The category of the project (e.g. Yes or No).
- **Project Location** (`project_location`, select_multiple, required: false): The location of the project (e.g. Yes or No).
- **Contact Person** (`contact_person`, text, required: false): The name of the contact person responsible for the project.
- **Company Name** (`company_name`, text, required: false): The name of the company associated with the project.
- **Job Function** (`job_function`, select_multiple, required: false): The job function(s) of the project leader.
- **Project Status** (`project_status`, select_one, required: false): The status of the project (e.g. Active or Inactive).
- **Project Notes** (`project_notes`, note, required: false): Any additional notes about the project.
- **Project Email** (`project_email`, email, required: false): The email address of the project.
- **Project Phone** (`project_phone`, text, required: false): The phone number of the project.
- **Company Address** (`company_address`, text, required: false): The address of the company associated with the project.
- **Job Location** (`job_location`, text, required: false): The location of the job.
- **Job Responsibilities** (`job_responsibilities`, text, required: false): A description of the job responsibilities.
- **Job Start Date** (`job_start_date`, date, required: false): The start date of the job.
- **Job End Date** (`job_end_date`, date, required: false): The end date of the job.
- **Employee Count** (`employee_count`, number, required: false): The number of employees associated with the project.
- **Job Category** (`job_category`, text, required: false): The category of the job.
- **Job Type** (`job_type`, select_one, required: false): The type of job (e.g. Yes or No).
- **Department Name** (`department_name`, text, required: false): The name of the department associated with the project.
- **Company Website** (`company_website`, text, required: false): The website of the company associated with the project.
- **Job Status** (`job_status`, select_one, required: false): The status of the job (e.g. Active or Inactive).
- **Created By** (`created_by`, text, required: false): The name of the person who created the project.

## Tips
* Make sure to fill out each field as accurately and completely as possible to ensure that your project information is up-to-date and correct.
* If a field is not applicable to your project, you can leave it blank.
* If you need help or have questions, contact your project leader or contact person.
