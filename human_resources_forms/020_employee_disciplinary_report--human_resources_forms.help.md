# Employee Disciplinary Report - Help Guide
## Purpose
This form is used to document and report disciplinary actions taken against employees, providing a formal record of the incident and the actions taken. 

## How To Complete This Form

To complete this form, please follow the steps below:

1. Enter the Reporting Officer's name and title who conducted the disciplinary meeting.
2. Enter the employee's ID number and their corresponding name.
3. Describe the reason for the disciplinary action taken.
4. Enter the date and time of the disciplinary action taken.
5. Enter the location where the disciplinary action took place.
6. Provide a detailed description of the disciplinary action taken, including any details about the incident.
7. Select the type of disciplinary action taken (e.g., Verbal Warning, Written Warning, Suspension, or Termination).
8. (Optional) Enter the date when the employee is expected to return to work.

## Field-by-Field Explanation

* **Reporting Officer** (select_one): The officer who conducted the disciplinary meeting. Please select one of the listed officers.
* **Employee ID** (number): Enter the employee's ID number. This is usually a numeric identifier assigned to each employee.
* **Reason for Disciplinary Action** (text): A brief description of why the disciplinary action was taken. Be as detailed as possible.
* **Date of Disciplinary Action** (date): The date when the disciplinary action took place.
* **Time of Disciplinary Action** (time): The time when the disciplinary action took place.
* **Location** (text): The location where the disciplinary action took place.
* **Description of Disciplinary Action** (text): A detailed description of the disciplinary action taken, including any details about the incident.
* **Disciplinary Action Taken** (select_multiple): The type of disciplinary action taken (e.g., Verbal Warning, Written Warning, Suspension, or Termination). Select all applicable options.
* **Date of Return to Work** (date): (Optional) Enter the date when the employee is expected to return to work.

## Tips

- Be as detailed and accurate as possible when filling out the form.
- Make sure to keep a copy of the form for your records.
- If you're unsure about a particular field or have questions, please reach out to your supervisor or HR representative.
