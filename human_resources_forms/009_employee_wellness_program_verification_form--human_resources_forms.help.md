# Employee Wellness Program Verification Form - Help Guide

## Purpose
This form is used to verify employee participation in the employee wellness program. It is essential to ensure that the correct information is collected and that duplicates or non-relevant submissions are prevented.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the required fields with accurate and up-to-date information.
2. Select the correct participant status from the dropdown menu.
3. Enter the dates of program participation using the date picker.
4. Select the employees who are participating in the program from the dropdown menu.
5. Enter any additional comments or remarks about the participant(s).
6. Enter the assigned tool or equipment used by the participant.
7. Enter the name of the employee and their manager.
8. Enter the participant ID number.

## Field-by-Field Explanation

* **User Input**: Enter a brief description or comments about the participant.
* **Participant Status**: Select the correct status of the participant (active, inactive, pending, or other).
* **Program Participation Dates**: Select the start and end dates of the program participation using the date picker.
* **Employee Program Participation**: Select the employees who are participating in the program from the dropdown menu.
* **Comments**: Enter any additional comments or remarks about the participant(s).
* **Assigned Tool**: Enter the assigned tool or equipment used by the participant.
* **Employee Name**: Enter the name of the employee participating in the program.
* **Manager Name**: Enter the name of the participant's manager.
* **Participant ID**: Enter the participant ID number.
