# Criminal History Authorization Form - Help Guide

## Purpose
The Criminal History Authorization Form is a document used to authorize access to certain employee information, specifically their criminal history. This form helps to provide employers with a clear understanding of an individual's background, which can be required for various purposes such as background checks, investigations, or security clearances.

## How To Complete This Form
To complete this form, follow these steps:

1. **Page 1**: This is the first page of the form, where you can provide any additional comments or information about the form.
2. **Employee Information**: This is a text box where you can enter any relevant details about the employee, such as their name, job title, or department.
3. **Criminal History**: This is a text box where you can provide any information about the employee's criminal history, including any relevant charges, convictions, or court cases.
4. **Authorization**: Select 'yes' or 'no' to indicate whether the employer has authorized access to the employee's criminal history.
5. **Signed Date**: This is a date field where you can enter the date the authorization was signed.
6. **Signature**: This is a text box where the person signing the form can provide their signature.
7-8 **Page 2-3**: These are additional text boxes for any additional comments or information.

## Field-by-Field Explanation

* **Employee Information**: This field is used to provide any relevant details about the employee.
* **Criminal History**: This field is used to provide any information about the employee's criminal history.
* **Authorization**: This field is used to indicate whether the employer has authorized access to the employee's criminal history. Select 'yes' to authorize access or 'no' to deny access.
* **Signed Date**: This field is used to record the date the authorization was signed.
* **Signature**: This field is used for the person signing the form to provide their signature.
* **Page 2-3**: These fields are used for any additional comments or information about the employee's criminal history.
