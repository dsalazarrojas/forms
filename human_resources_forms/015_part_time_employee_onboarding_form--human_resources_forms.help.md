# part_time_employee_onboarding_form - Help Guide
## Purpose
The "part_time_employee_onboarding_form" is a comprehensive form used by HR personnel to onboard new part-time employees and update their records. This form collects essential information about the employee's contact details, emergency contact information, job title, department, and other relevant details.

## How To Complete This Form
To complete this form, follow these steps:

1. Review the form carefully before starting.
2. Fill in the required fields marked as required.
3. Use the options provided for select fields to select the correct options.
4. Use the date fields to select the start and end dates for the employee's part-time position.
5. Make sure to provide accurate information about the employee's contact details and emergency contact information.
6. Enter any additional notes or comments if necessary.
7. Submit the form once you've completed all the required fields.

## Field-by-Field Explanation
* **New Employee Information** (`new_employee_info`): Enter the new employee's basic information, such as their name, email, and other relevant details.
* **Contact Information** (`contact_info`): Provide the new employee's contact information, including their address, phone number, and other relevant details.
* **Emergency Contact Information** (`emergency_contact_info`): Check if the emergency contact is available and select the relationship (e.g., family member) if applicable.
* **Emergency Contact Relationship** (`emergency_contact_relationship`): Select the relationship with the emergency contact (e.g., family member).
* **Emergency Contact Phone** (`emergency_contact_phone`): Enter the emergency contact's phone number.
* **Emergency Contact Note** (`emergency_contact_note`): Add any additional notes about the emergency contact.
* **Manager's Note** (`manager_note`): Add any additional notes for the manager.
* **Job Title** (`job_title`): Enter the new employee's job title.
* **Department** (`department`): Select the new employee's department.
* **Manager's Name** (`manager_name`): Enter the manager's name.
* **Manager's Job Title** (`manager_title`): Enter the manager's job title.
* **Start Date** (`start_date`): Select the start date for the new employee's part-time position.
* **End Date** (`end_date`): Select the end date for the new employee's part-time position.
* **Pay Rate** (`pay_rate`): Enter the new employee's pay rate.
* **Employee Status** (`employee_status`): Select the new employee's status (e.g., active, inactive, etc.).
* **Benefits** (`benefits`): Check if the new employee is eligible for benefits.
* **Benefits (Employers)** (`benefits_employer`): Check if the new employee's employer is eligible for benefits.
* **Benefits (Self)** (`benefits_self`): Check if the new employee is eligible for benefits as a self-employed individual.
* **Notes** (`notes`): Add any additional notes about the new employee.
* **Emergency Contact Name** (`emergency_contact_name`): Enter the emergency contact's name.
* **Emergency Contact Phone** (`emergency_contact_phone`): Enter the emergency contact's phone number.
* **Date** (`date`): Enter the current date.
* **Is emergency contact a family member?** (`emergency_contact_relationship_other`): Check if the emergency contact is a family member.
* **List Emergency Contacts** (`emergency_contacts`): List any additional emergency contacts.
* **Employee Information** (`employee_info`): Enter any additional employee information.
