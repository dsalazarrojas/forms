# jcg_step_one_review_goal_builder - Help Guide
## Purpose

The "jcg_step_one_review_goal_builder" form is used for reviewing and evaluating goals and objectives within an organization. It provides a structured way to capture and reference goal information.

## How To Complete This Form

1.  To complete this form, start by selecting the "Category" option from the dropdown menu. This is a required field as it helps classify the goal or objective into the correct category.
2.  Fill in the "Review Goal" field with a brief description of the goal or objective.
3.  If necessary, select the "Subcategory" options that apply to the goal or objective.
4.  Fill in the "Description" field with a detailed description of the goal or objective.
5.  Enter the "Start Date" and "End Date" of the goal or objective, if applicable.
6.  Select the "Status" of the goal or objective from the dropdown menu. This is a required field.
7.  Add any "Comments" you have about the goal or objective.
8.  If applicable, fill in the "Reviewer" field with their name or ID.
9.  Enter a "Rating" for the goal or objective, if applicable.
10. Add any "Notes" you have about the goal or objective.
11. Enter the "Email" and "Phone" contact information, if applicable.
12. If necessary, attach any relevant documents or files to the "Attachment" field.

## Field-by-Field Explanation

*   **Category** (`Category`, `select_one`, required): Select the category that best describes the goal or objective. This will help classify the goal or objective into the correct category.
*   **Review Goal** (`Review Goal`, `text`, optional): A brief description of the goal or objective.
*   **Subcategory** (`Subcategory`, `select_multiple`, optional): Select any subcategories that apply to the goal or objective.
*   **Description** (`Description`, `text`, optional): A detailed description of the goal or objective.
*   **Start Date** (`Start Date`, `date`, optional): Enter the start date of the goal or objective.
*   **End Date** (`End Date`, `date`, optional): Enter the end date of the goal or objective.
*   **Status** (`Status`, `select_one`, required): Select the status of the goal or objective from the dropdown menu.
*   **Comments** (`Comments`, `text`, optional): Add any comments or feedback about the goal or objective.
*   **Reviewer** (`Reviewer`, `text`, optional): Enter the name or ID of the reviewer.
*   **Rating** (`Rating`, `number`, optional): Enter a rating for the goal or objective, if applicable.
*   **Notes** (`Notes`, `note`, optional): Add any additional notes about the goal or objective.
*   **Email** (`Email`, `email`, optional): Enter the email contact information.
*   **Phone** (`Phone`, `text`, optional): Enter the phone contact information.
*   **Attachment** (`Attachment`, `text`, optional): Attach any relevant documents or files to the goal or objective.
