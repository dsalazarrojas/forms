# Manager Onboarding Form - Help Guide
## Purpose
This form is used to capture information for the onboarding process of new managers within the organization.

## How To Complete This Form
1. Fill out this form for each new manager onboarding process.
2. Ensure you fill out all required fields, indicated by an asterisk (*) in the label.
3. Select relevant information from the provided options for select fields.
4. Enter any additional notes or descriptions in the text fields.

## Field-by-Field Explanation
* **New Manager Name**: (`new_manager_name`, text, optional): Please enter the name of the new manager.
* **Role**: (`role`, select_one, optional): Choose the type of role the new manager will be filling. Options include:
	+ role type a
	+ role type b
	+ role type c
* **Reporting Manager's Name**: (`reporting_manager_name`, text, optional): Enter the name of the manager who will be reporting to.
* **Reporting Manager's Email**: (`reporting_manager_email`, email, optional): Enter the email address of the manager who will be reporting to.
* **Team Members**: (`team_members`, select_multiple, optional): Select the team members the new manager will be working with. Options include:
	+ team member1
	+ team member2
	+ team member3
* **Onboarding Date**: (`onboarding_date`, date, optional): Enter the date the new manager will start their onboarding process.
* **Start Date**: (`start_date`, date, optional): Enter the date the new manager will start their tenure.
* **End Date**: (`end_date`, date, optional): Enter the date the new manager's tenure will end.
* **New Manager Note**: (`new_manager_note`, note, optional): Enter any additional notes or comments about the new manager.
* **Role Description**: (`role_description`, text, optional): Enter a brief description of the new manager's role.
* **Reporting Manager Note**: (`reporting_manager_note`, note, optional): Enter any additional notes or comments about the reporting manager.
* **Team Description**: (`team_description`, text, optional): Enter a brief description of the team the new manager will be working with.
