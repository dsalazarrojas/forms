# Healthcare Staff Employment Review Form - Help Guide

## Purpose
This guide is to help you complete the Healthcare Staff Employment Review Form, a tool for evaluating and reviewing the performance of healthcare staff.

## How To Complete This Form
1. Fill out the form in sections, following the instructions for each field.
2. Ensure all required fields are completed before submitting the form.
3. Provide accurate and honest feedback for each field.

## Field-by-Field Explanation

### Employee Name (1)
* **Employee Name (1)**: Text input field
	+ Fill in the name of the employee being reviewed.
	+ This field is required.

### Job Title (2)
* **Job Title (2)**: Text input field
	+ Enter the job title of the employee being reviewed.
	+ This field is required.

### Performance Period (3)
* **Performance Period (3)**: Date input field
	+ Select the date range for which you are providing feedback on the employee's performance.
	+ This field is required.

### Performance Summary (4)
* **Performance Summary (4)**: Text input field
	+ Write a concise summary of the employee's performance during the selected date range.
	+ This field is required.

### Areas For Improvement (5)
* **Areas For Improvement (5)**: Text input field (optional)
	+ Provide specific areas for the employee to improve, if applicable.
	+ This field is optional.

### Strengths And (6)
* **Strengths And (6)**: Text input field (optional)
	+ List specific strengths or skills of the employee.
	+ This field is optional.

### Areas Of (7)
* **Areas Of (7)**: Text input field (optional)
	+ List specific areas where the employee needs improvement.
	+ This field is optional.

### Recommendations (8)
* **Recommendations (8)**: Text input field (optional)
	+ Provide any recommendations for the employee's growth or development.
	+ This field is optional.

### Overall Evaluation (9)
* **Overall Evaluation (9)**: Select one of the following:
	+ Excellent
	+ Satisfactory
	+ Unsatisfactory
	+ Choose the overall evaluation of the employee's performance.
	+ This field is required.

### Date (10)
* **Date (10)**: Date input field
	+ Select the date you are providing feedback on.
	+ This field is required.

### Time (11)
* **Time (11)**: Time input field (optional)
	+ Provide the time of the feedback or evaluation.
	+ This field is optional.

### Email (12)
* **Email (12)**: Email input field (optional)
	+ Enter the employee's email address, if applicable.
	+ This field is optional.

### Phone (13)
* **Phone (13)**: Text input field (optional)
	+ Enter the employee's phone number, if applicable.
	+ This field is optional.

### Note (14)
* **Note (14)**: Note input field (optional)
	+ Enter any additional comments or notes for the employee.
	+ This field is optional.

## Tips
* Ensure to complete all required fields before submitting the form.
* Be specific and constructive with your feedback.
* Keep the form concise and easy to read.

Note: This guide is based on the provided YAML fields and is subject to change if the form's purpose or structure changes.
