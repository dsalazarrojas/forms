# Incident Monitoring Form - Help Guide
## Purpose
The "Incident Monitoring Form" is a tool designed to capture and track incidents or events that have occurred within an organization.

## How To Complete This Form

1.  To start filling out this form, select the "Incident Monitoring Form" page.
2.  Fill out the required fields as instructed below. Note that some fields are optional and can be skipped if not applicable.

## Field-by-Field Explanation

*   **Incident Date** (`incident_date`, `date`, required: false): This field is used to record the date of the incident. Select the date of the incident using the date picker provided in the field.
*   **Incident Time** (`incident_time`, `time`, required: false): This field is used to record the time of the incident. Select the time of the incident using the time picker provided in the field.
*   **Incident Location** (`incident_location`, `text`, required: false): Enter the location where the incident occurred.
*   **Incident Description** (`incident_description`, `text`, required: false): Provide a detailed description of the incident.
*   **Incident Type** (`incident_type`, `select_one`, required: false): Choose the type of incident from the provided options: Incident Type 1, Incident Type 2, or Incident Type 3.
*   **Incident Priority** (`incident_priority`, `select_one`, required: false): Choose the priority level of the incident from the provided options: High, Medium, or Low.
*   **Incident Status** (`incident_status`, `select_multiple`, required: false): Choose the status of the incident from the provided options: Open, Resolved, or Pending.
*   **Incident Responder** (`incident_responder`, `text`, required: false): Enter the name of the person responding to the incident.
*   **Incident Resolution** (`incident_resolution`, `text`, required: false): Enter a description of the resolution or outcome of the incident.
*   **Incident Comments** (`incident_comments`, `text`, required: false): Enter any additional comments or feedback regarding the incident.
*   **Incident Attachments** (`incident_attachments`, `note`, required: false): Attach any relevant files or images related to the incident.
*   **Incident Notes** (`incident_notes`, `note`, required: false): Enter any additional notes about the incident.

## Tips

*   Be honest and accurate when filling out this form to ensure accurate tracking and monitoring of incidents.
*   If unsure about any of the fields, refer to the provided options or contact the form administrator for clarification.
*   Use the "Attachments" field to add any relevant files or images related to the incident.
*   Use the "Comments" field to enter any additional feedback or comments regarding the incident.
