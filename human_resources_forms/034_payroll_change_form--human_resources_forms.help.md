# Payroll Change Form - Help Guide
## Purpose

The Payroll Change Form is used to document changes to an employee's pay details, such as salary, pay rate, and pay period.

## How To Complete This Form

To complete this form, follow these steps:

1. Select the pay period for which you want to make the changes.
2. Enter the employee's ID number.
3. Enter the reason for the change (optional).
4. Enter the old salary for the employee (if applicable).
5. Enter the new salary for the employee (if applicable).
6. Select the new pay rate type (e.g., Hourly, Daily).
7. Select the pay rate frequency (e.g., Weekly, Biweekly).
8. Add any notes or comments about the change.
9. Enter the employee's email (optional).
10. Enter the employee's phone number (optional).
11. Set the effective date for the change.

## Field-by-Field Explanation

* **Employee ID** (Employee ID, Number, Optional): Enter the ID number of the employee who is having their payroll information changed.
* **Pay Period** (Pay Period, Select One, Optional): Select the pay period for which you want to make the changes (e.g., Monthly, Biweekly).
* **Change Reason** (Change Reason, Text, Optional): Enter a brief explanation for the change (if applicable).
* **Old Salary** (Old Salary, Number, Optional): Enter the old salary of the employee (if applicable).
* **New Salary** (New Salary, Number, Optional): Enter the new salary of the employee (if applicable).
* **New Pay Rate** (New Pay Rate, Select One, Optional): Select the new pay rate type (e.g., Hourly, Daily).
* **Pay Rate Type** (Pay Rate Type, Select Multiple, Optional): Select the pay rate frequency (e.g., Weekly, Biweekly).
* **Notes** (Notes, Note, Optional): Add any additional comments or notes about the change.
* **Email** (Email, Email, Optional): Enter the employee's email address (if applicable).
* **Phone** (Phone, Text, Optional): Enter the employee's phone number (if applicable).
* **Date** (Date, Date, Optional): Set the effective date for the change.
