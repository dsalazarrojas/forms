# Supervisor Evaluation Form - Help Guide
## Purpose
The Supervisor Evaluation Form is a tool for supervisors to evaluate and provide feedback on the performance of employees or staff members under their supervision.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the employee's name in the "Employee Name" field.
2. Select the date of evaluation in the "Evaluation Date" field.
3. Enter the start date of the evaluation period in the "Start Date" field.
4. Enter the end date of the evaluation period in the "End Date" field.
5. In the "Supervisor Comments" field, provide any comments or feedback regarding the employee's performance.
6. Choose the "Evaluation Outcome" from the dropdown list, indicating the outcome of the evaluation.
7. In the "Recommended Actions" field, suggest any actions or steps for the employee to improve.
8. Select the "Assigned Tool" that was used during the evaluation period.
9. Choose the "Category" for the evaluation, typically "Human Resources Forms".
10. Enter the "Form ID" to identify the form for future reference.
11. Provide a name for the output file in the "Output File Name" field.
12. Enter a brief description of the evaluation in the "Description" field.
13. Repeat the process for the second set of evaluation criteria.

## Field-by-Field Explanation

* **Employee Name** (text, required): Enter the name of the employee being evaluated.
* **Evaluation Date** (date, required): Select the date of the evaluation.
* **Start Date** (date, required): Enter the start date of the evaluation period.
* **End Date** (date, required): Enter the end date of the evaluation period.
* **Supervisor Comments** (text, required): Provide any comments or feedback on the employee's performance.
* **Evaluation Outcome** (select_one, required): Choose from the list, e.g., "Outstanding", "Needs Improvement", etc.
* **Recommended Actions** (text, required): Suggest any actions or steps for the employee to improve.
* **Assigned Tool** (select_one, required): Select the tool used during the evaluation period.
* **Category** (select_one, required): Typically "Human Resources Forms".
* **Form ID** (number, required): Enter the form ID for future reference.
* **Output File Name** (text, required): Provide a name for the output file.
* **Description** (text, required): Enter a brief description of the evaluation.
* **Assigned Tool 2** (select_one, required): Select the tool used for the second evaluation.
* **Category 2** (select_one, required): Typically "Human Resources Forms".
* **Form Id 2** (number, required): Enter the form ID for the second evaluation.
* **Output File Name 2** (text, required): Provide a name for the output file.
* **Title** (text, required): Enter a title for the evaluation.
* **Output File** (text, required): Provide a name for the output file.
