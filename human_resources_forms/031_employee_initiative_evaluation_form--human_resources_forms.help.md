# Employee Initiative Evaluation Form - Help Guide
## Purpose
The Employee Initiative Evaluation Form is a tool to assess and evaluate employee-led projects and initiatives within a company. This form helps project leaders and evaluators assess the progress, outcomes, and impact of a project, providing a structured framework for documentation and improvement.

## How To Complete This Form

To complete this form, follow these steps:

*   Fill in the project name, project leader's name, and project description on pages 1-3.
*   Enter the project start and end dates in the format `yyyy-mm-dd` on pages 4-5.
*   On page 6, provide a clear and concise summary of the project's scope.
*   On pages 7-8, describe the project's outcomes and impact.
*   Enter the name and email of the project evaluator on pages 9-10.

## Field-by-Field Explanation

*   **Project Name** (page 1, text): Enter the name of the project being evaluated.
*   **Project Leader** (page 2, text): Enter the name of the project leader responsible for the project.
*   **Project Description** (page 3, text): Provide a brief description of the project.
*   **Project Start Date** (page 4, date): Enter the start date of the project in the format `yyyy-mm-dd`.
*   **Project End Date** (page 5, date): Enter the end date of the project in the format `yyyy-mm-dd`.
*   **Project Scope** (page 6, text): Describe the project's scope, focusing on its objectives, goals, and deliverables.
*   **Project Outcomes** (page 7, text): Outline the project's outcomes, including any successes, challenges, and lessons learned.
*   **Project Impact** (page 8, text): Assess the project's impact, including its effects on the organization, employees, and customers.
*   **Project Evaluator** (page 9, text): Enter the name of the person evaluating the project.
*   **Project Evaluator Email** (page 10, email): Enter the email address of the project evaluator.

## Tips

*   Be as specific as possible when filling out the form.
*   Use clear and concise language when describing project details.
*   Proofread the form carefully before submitting it.
*   Make sure to save a copy of the form for future reference.
*   If you're unsure about any field, contact the project leader or evaluator for clarification.
