# phased_return_to_work_form - Help Guide
## Purpose
The Phased Return to Work Form is used to track and manage employee return to work activities, ensuring that employees can safely and efficiently return to work after an extended leave.

## How To Complete This Form
To complete this form, follow these steps:
1. Enter the employee's name in the first field.
2. Select the manager's name who authorized the leave.
3. Input the return date and start time of the employee's return.
4. Enter the end time of the work period.
5. Select the number of days worked during the leave.
6. Select the work days the employee will work during their phased return.
7. Enter the number of work hours the employee will work per day.
8. Select the location where the employee will be working during their phased return.
9. Enter the supervisor's name who authorized the return to work.
10. Enter the supervisor's signature to confirm the return to work.
11. Enter the manager's signature to confirm the return to work.
12. Optionally, enter a note about the return to work.
13. Enter the employee's email.
14. Enter the employee's phone number.
15. Select the department the employee belongs to.
16. Select the reason for the leave.
17. Enter the date of return to work.
18. Enter the work status of the employee.
19. Enter the job title of the employee.
20. Enter the employee ID.
21. Enter the start date of the leave.
22. Enter the end date of the leave.
23. Enter the total number of days off.
24. Select the type of leave (full time, part time, or other).

## Field-by-Field Explanation
* **Employee Name** (`Employee Name`, text, required): Enter the name of the employee returning to work.
* **Manager's Name** (`Manager's Name`, text, required): Select the name of the manager who authorized the leave.
* **Return Date** (`Return Date`, date, required): Enter the date the employee is expected to return to work.
* **Start Time** (`Start Time`, time, required): Enter the time the employee will start working after the return.
* **End Time** (`End Time`, time, required): Enter the time the employee will end working on the last day of the phased return.
* **Days Worked** (`Days Worked`, number, required): Select the number of days the employee will work during the phased return.
* **Work Days** (`Work Days`, select_one, required): Select the days the employee will work during the phased return.
* **Work Hours** (`Work Hours`, number, required): Enter the number of hours the employee will work per day during the phased return.
* **Location** (`Location`, text, required): Select the location where the employee will be working during the phased return.
* **Supervisor Name** (`Supervisor Name`, text, required): Select the supervisor's name who authorized the return to work.
* **Supervisor Signature** (`Supervisor Signature`, text, required): Enter the supervisor's signature to confirm the return to work.
* **Manager Signature** (`Manager Signature`, text, required): Enter the manager's signature to confirm the return to work.
* **Return to Work Note** (`Return to Work Note`, note, optional): Optionally, enter a note about the return to work.
* **Email** (`Email`, email, required): Enter the employee's email.
* **Phone** (`Phone`, text, required): Enter the employee's phone number.
* **Department** (`Department`, select_multiple, required): Select the department the employee belongs to.
* **Reason for Leave** (`Reason for Leave`, select_multiple, required): Select the reason for the leave.
* **Date of Return** (`Date of Return`, date, required): Enter the date of return to work.
* **Work Status** (`Work Status`, number, required): Enter the work status of the employee during the phased return.
* **Job Title** (`Job Title`, text, required): Enter the job title of the employee.
* **Employee ID** (`Employee ID`, text, required): Enter the employee ID.
* **Leave Start Date** (`Leave Start Date`, date, required): Enter the start date of the leave.
* **Leave End Date** (`Leave End Date`, date, required): Enter the end date of the leave.
* **Total Days Off** (`Total Days Off`, number, required): Enter the total number of days off.
* **Leave Type** (`Leave Type`, select_multiple, required): Select the type of leave (full time, part time, or other).
