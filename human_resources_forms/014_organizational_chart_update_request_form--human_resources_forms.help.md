# Organizational Chart Update Request Form - Help Guide
## Purpose
The Organizational Chart Update Request Form is used to request updates to the company's organizational chart. This form is used to track and manage changes to the organizational structure of the company.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter your User Name in the field provided.
2. Enter your Manager's Name in the field provided.
3. Check the "Reporting Line" field to indicate if you are reporting to someone.
4. In the "Reporting Line Options" field, select all applicable options.
5. Select the reason for the change in the "Reason" field.
6. Choose the type of change in the "Change Type" field.
7. Select the level of change in the "Change Level" field.
8. Enter the effective date of the change in the "Effective Date" field.
9. Enter a brief justification for the change in the "Change Justification" field.
10. Check the "Comments" field to provide any additional comments or context for the change.

## Field-by-Field Explanation
* **User Name**: Enter your employee ID or login credentials to identify yourself as the user requesting the change.
* **Manager Name**: Enter the name of your manager or supervisor.
* **Reporting Line**: Check "Yes" if you have a reporting line (e.g., you report to someone), check "No" if you do not.
* **Reporting Line Options**: Select all applicable options for reporting line relationships (e.g., direct report, indirect report).
* **Reason**: Select the reason for the change (e.g., promotion, transfer, separation).
* **Change Type**: Select the type of change (e.g., addition, deletion, modification).
* **Change Level**: Select the level of change (e.g., high, low).
* **Effective Date**: Enter the date the change is effective.
* **Change Justification**: Enter a brief explanation for the change.
* **Comments**: Enter any additional comments or context about the change.
* **Comments**: Select "Yes" if you have comments, select "No" if you do not.
