# Housing Project Manager Exit Offboarding Form - Help Guide
## Purpose
The Housing Project Manager Exit Offboarding Form is designed to collect information and facilitate a smooth transition for Project Managers who are exiting the organization. This form helps to document the reason for offboarding, identify next steps, and ensure a smooth handover of assigned tools and responsibilities.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Project Manager's ID in the **Project Manager ID** field.
2. Select the date of offboarding in the **Offboarding Date** field (if applicable).
3. Provide a brief explanation for the reason of offboarding in the **Reason For Offboarding** field.
4. Select the next steps that will be taken in the **Next Steps** field (multiple selections allowed).
5. Choose the assigned tool that will be returned to the organization in the **Assigned Tool** field.
6. Add any additional notes or comments in the **Notes** field (if applicable).

## Field-by-Field Explanation

* **Project Manager ID (Project Manager ID)**: Enter the unique ID of the Project Manager who is offboarding.
* **Offboarding Date (Offboarding Date)**: Select the date when the Project Manager will be offboarding.
* **Reason For Offboarding (Reason For Offboarding)**: Provide a brief explanation for the reason of offboarding.
* **Next Steps (Next Steps)**: Select one or multiple next steps that will be taken after the Project Manager offboards.
	+ **Next Steps 1**: Select the next steps to be taken for the Project Manager.
	+ **Next Steps 2**: Select the next steps to be taken for the Project Manager.
	+ **Next Steps 3**: Select the next steps to be taken for the Project Manager.
* **Assigned Tool (Assigned Tool)**: Choose the assigned tool that will be returned to the organization.
* **Notes (Notes)**: Add any additional notes or comments regarding the offboarding process.
