# HR System Migration Application Form - Help Guide

## Purpose
The HR System Migration Application Form is a necessary step in the HR system migration process. It gathers information required for the migration team to assess and fulfill your system migration request.

## How To Complete This Form
- Ensure you have a valid reason for filling out this form. Check with your HR representative if you have already submitted a migration application form in the past.
- Carefully read and follow the instructions on this help guide to avoid confusion.
- Complete the form in a new tab or window to prevent data loss in case of navigation away from this page.
- Fill out the form completely, but do not submit the form until you have read and agreed to the "Terms and Conditions" page.

## Field-by-Field Explanation

### User Input
**User Input** (`user_input`, `text`, optional): Enter a brief description of your system migration request.

### Objective
**Objective** (`objective`, `text`, optional): Provide a clear explanation of the objective of your system migration request.

### Timeline
**Timeline** (`timeline`, `number`, optional): Enter a timeline for your system migration request in years/months.

### IT Support
**IT Support** (`it_support`, `select_multiple`, optional): Select all necessary IT support options for your system migration request:

• Option 1
• Option 2
• Option 3

### HR Approval
**HR Approval** (`hr_approval`, `select_one`, optional): Select the HR approval type for your system migration request:

• Option 1
• Option 2
• Option 3

### Migration Request
**Migration Request** (`migration_request`, `date`, optional): Enter the date you require the system migration to be completed by.

### Status Update
**Status Update** (`status_update`, `note`, optional): Add any additional comments or status updates about your system migration request.

Please review the form carefully and submit it once you have finished filling it out. If you have any questions, contact your HR representative for assistance.
