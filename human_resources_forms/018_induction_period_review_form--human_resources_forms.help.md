# Induction Period Review Form - Help Guide
## Purpose
This form is designed to collect information for the Induction Period Review of new employees. It is used to evaluate the progress and performance of new hires during their induction period.

## How To Complete This Form
To complete this form, please follow these steps:

1. Ensure you are filling out the form for the correct employee.
2. Enter the new employment details, if applicable.
3. Select the relevant review period from the options provided.
4. Rate the employee's job performance using the provided options.
5. Provide feedback and recommendations for improvement.
6. Select the review status.

## Field-by-Field Explanation
- **New Employment Details** (`new_employment_details`): Enter any additional information related to the new employment details, if applicable.
  * Type: Text field
  * Required: No
  * Hint: null
- **Job Title** (`job_title`): Enter the job title of the employee.
  * Type: Text field
  * Required: No
  * Hint: null
- **Start Date** (`start_date`): Enter the start date of the employee's employment.
  * Type: Date field
  * Required: No
  * Hint: null
- **Probation Start Date** (`probation_start_date`): Enter the start date of the employee's probation period.
  * Type: Date field
  * Required: No
  * Hint: null
- **Review Period** (`review_period`): Select the relevant review period for the employee's induction.
  * Type: Select One field
  * Required: Yes
  * Hint: null
  * Options: New Hire, Probation, Induction
- **New Employee Name** (`new_employee_name`): Enter the name of the new employee.
  * Type: Text field
  * Required: No
  * Hint: null
- **Reporting Manager Name** (`reporting_manager_name`): Enter the name of the reporting manager.
  * Type: Text field
  * Required: No
  * Hint: null
- **Job Performance Rating** (`job_performance_rating`): Rate the employee's job performance.
  * Type: Select Multiple field
  * Required: Yes
  * Hint: null
  * Options: Satisfactory, Unsatisfactory, Needs Improvement
- **Skills Acquired** (`skills_acquired`): Enter any skills or knowledge acquired by the employee.
  * Type: Text field
  * Required: No
  * Hint: null
- **Areas for Improvement** (`areas_for_improvement`): Provide feedback on areas that need improvement.
  * Type: Text field
  * Required: No
  * Hint: null
- **Overall Feedback** (`overall_feedback`): Enter your overall feedback on the employee's performance.
  * Type: Text field
  * Required: No
  * Hint: null
- **Recommendations** (`recommendations`): Enter any recommendations for the employee's growth and development.
  * Type: Text field
  * Required: No
  * Hint: null
- **Next Review Date** (`next_review_date`): Enter the date for the next review.
  * Type: Date field
  * Required: No
  * Hint: null
- **Review Status** (`review_status`): Select the review status.
  * Type: Select One field
  * Required: Yes
  * Hint: null
  * Options: On Time, Overdue, Not Applicable
