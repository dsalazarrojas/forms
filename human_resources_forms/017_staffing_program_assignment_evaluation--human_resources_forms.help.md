# Staffing Program Assignment Evaluation - Help Guide
## Purpose
The Staffing Program Assignment Evaluation form is designed to assess the effectiveness of a staffing program by collecting information on performance, assignments, and other relevant details. This form helps HR or management teams evaluate the success of program assignments, identify areas for improvement, and make data-driven decisions.

To complete this form, follow these steps:

1. Review the form questions and ensure you have all the necessary information before starting.
2. Select all relevant answers for each question.
3. Fill in any text fields (e.g., manager name, comments).
4. Select dates for the date assigned field.

## Field-by-Field Explanation
* **assignment_performance** (`assignment_performance`, select_multiple, required: false): Answer this question by selecting all that apply. For example, "Yes" for "Yes, the assignment was completed successfully" and "No" for "No, the assignment was not completed successfully".
* **manager_name** (`manager_name`, text, required: false): Enter the name of the manager responsible for the assignment.
* **assigned_to** (`assigned_to`, select_one, required: false): Select "Yes" if you were assigned to the program, "No" if you were not.
* **performance_rating** (`performance_rating`, number, required: false): Enter a numerical rating (e.g., 1-5) to assess your performance on the assignment.
* **comments** (`comments`, text, required: false): Provide any additional comments or feedback about your experience with the assignment.
* **date_assigned** (`date_assigned`, date, required: false): Select the date the assignment was assigned to you.
