# Local Leave Election Form - Help Guide
## Purpose
This form is used to elect a leave option for an employee. It is used to record the employee's choice of leave type (e.g., vacation, sick, personal) and other relevant details such as category and assigned tool.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of leave you are requesting. You can choose from "Human Resources Forms" or "Other".
2. Enter a brief description of your leave request.
3. Choose the assigned tool used for this leave.
4. Enter the name of the output file that will contain the result of this form.

## Field-by-Field Explanation
* **Category** (`Category`, `select_one`, required: false): Select the category of leave you are requesting. This will help the system to process your leave request correctly.
* **Description** (`Description`, `text`, required: false): Enter a brief description of your leave request.
* **Assigned Tool** (`Assigned Tool`, `select_one`, required: false): Choose the tool assigned for this leave.
* **Output File** (`Output File`, `text`, required: false): Enter the name of the output file that will contain the result of this form.
* **Form ID** (`Form ID`, `number`, required: false): This is a unique identifier for this form. Please do not fill this field unless required by the system.

## Tips
* Make sure to fill in all required fields to ensure that your leave request is processed correctly.
* If you are unsure about any field, please ask your HR representative for assistance.
