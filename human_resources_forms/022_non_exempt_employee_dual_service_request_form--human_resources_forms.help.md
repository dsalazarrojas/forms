# Non Exempt Employee Dual Service Request Form - Help Guide
## Purpose
This form is used to request assistance from another employee for tasks that are not typically part of your main job responsibilities. This ensures that tasks are properly assigned and prevents non-duplication of requests.

## How To Complete This Form
1. Select the category for which you are requesting dual service (Human-Resources Forms or Other).
2. Provide a brief description of the task or project you need assistance with.
3. Select the employee(s) to whom you are requesting assistance from (John, Jane, or Other).
4. Enter the date you need assistance with the task.
5. Enter the time you need assistance with the task in 24h format.
6. Select the employee who will be submitting the request (John, Jane, or Other).
7. Add any additional comments or notes about the request.
8. Enter your email address.
9. Enter your phone number.
10. Select the current status of the request (Pending, Approved, or Rejected).
11. Select the output file format for the request (022 non exempt employee dual service request form--human resources forms.yaml or 022 non exempt employee dual service request form--hrforms.yaml).
12. Select the tool(s) assigned to assist with the task (chatjimmy or Other).

## Field-by-Field Explanation

* **Category** (1): Select the category that best fits the task you are requesting assistance with. This will help ensure that the correct department receives your request.
* **Description** (2): Provide a brief description of the task or project you need assistance with. This will help the assigned employee understand the task requirements.
* **Assigned to** (3): Select the employee(s) who you are requesting assistance from. Please ensure that the employee has enough capacity to assist you with the task.
* **Date** (4): Enter the date you need assistance with the task in YYYY-MM-DD format.
* **Time** (5): Enter the time you need assistance with the task in 24h format.
* **Submitted by** (6): Select the employee who will be submitting the request. This should be the employee requesting assistance.
* **Note** (7): Add any additional comments or notes about the request.
* **Email** (8): Enter your email address so that the assigned employee can contact you with updates or questions.
* **Phone** (9): Enter your phone number so that the assigned employee can contact you with updates or questions.
* **Status** (10): Select the current status of the request (Pending, Approved, or Rejected).
* **Output File** (11): Select the output file format for the request. This will determine the file that is generated for your request.
* **Assigned Tool** (12): Select the tool(s) assigned to assist with the task (chatjimmy or Other).
