# Payroll Overpayment Resolution Request Form - Help Guide
## Purpose
The Payroll Overpayment Resolution Request Form is used to request resolution of overpaid amounts on an employee's paycheck. It helps ensure accurate pay and prevents future discrepancies by providing a process for employees to request and address overpaid amounts within a specified time frame.

## How To Complete This Form
1. **Base Form Data**: Enter the base information for the overpayment resolution request. This field is not mandatory.
2. **Overpayment Amount**: Enter the overpaid amount that requires resolution. This field is not mandatory.
3. **Reason for Overpayment**: Enter the reason for the overpaid amount. This field is not mandatory.
4. **Employee Identification**: Enter the employee's identification number or name. This field is not mandatory.
5. **Overpayment Resolution Request Date**: Enter the date the overpayment resolution request is being made. This field is not mandatory.
6. **Payroll Department**: Select the department responsible for processing the overpayment resolution. Options include: Accounting, Payroll, and Finance. This field is not mandatory.
7. **Overpayment Type**: Select the type of overpayment being requested. Options include: Back Pay, Holiday Pay, Other Pay. This field is not mandatory.
8. **Overpayment Reason**: Select the reason for the overpayment. Options include: Bonus, Commissions, Holiday Pay, Overtime, Terminaiton Pay, Vacation Pay. This field is not mandatory.
9. **Overpayment Resolution**: Enter any additional information or comments regarding the overpayment resolution. This field is not mandatory.

## Field-by-Field Explanation
* **Overpayment Amount**: Enter the amount that was overpaid. For example, if the original paycheck was for $100 and the employee received $150, enter $50 as the overpaid amount.
* **Employee Identification**: Enter the employee's identification number or name to help the payroll department locate the employee's record.
* **Overpayment Resolution Request Date**: Enter the date the overpayment resolution request is being made, usually the date of the original overpayment.
* **Payroll Department**: Select the department responsible for processing the overpayment resolution, which could be Accounting, Payroll, or Finance.
* **Overpayment Type**: Select the type of overpayment being requested, which could be Back Pay, Holiday Pay, or Other Pay.
* **Overpayment Reason**: Select the reason for the overpayment, which could be Bonus, Commissions, Holiday Pay, Overtime, Terminaiton Pay, or Vacation Pay.
* **Overpayment Resolution**: Enter any additional information or comments regarding the overpayment resolution. This could include the reason for the overpayment, how it was resolved, or any other relevant details.
