# Analyst Quarterly Evaluation Form - Help Guide
## Purpose
The Analyst Quarterly Evaluation Form is designed to evaluate an analyst's performance over the past quarter. The purpose of this form is to assess key areas of an analyst's performance, including data accuracy and integrity, report timeliness, technical proficiency, core competencies, key achievements, areas for development, overall performance score, strategic goals for the next quarter, and evaluation date.

## How To Complete This Form
To complete this form, follow these steps:

1. Enter the Employee Name in the first field. This is the name of the analyst being evaluated.
2. Enter the Manager Name in the second field. This is the name of the manager who will review the evaluation.
3. Enter the Department in the third field. This is the department the analyst belongs to.
4. Select the Data Accuracy and Integrity Rating for the analyst's performance in the Data Accuracy and Integrity Rating field. This rating is used to assess the analyst's ability to provide accurate and reliable data.
5. Select the Report Timeliness and Deadlines field. This rating is used to evaluate the analyst's ability to meet report deadlines.
6. Select the Technical Proficiency with Tools field. This rating is used to assess the analyst's proficiency with technical tools such as SQL, Excel, and BI tools.
7. Enter Key Achievements This Quarter in the Key Achievements This Quarter field. This is a field for the analyst to describe their key achievements over the past quarter.
8. Enter Areas for Development / Growth in the Areas for Development / Growth field. This is a field for the analyst to suggest areas for personal and professional growth.
9. Select the Overall Performance Score for the analyst. This score ranges from 1 to 5, with 5 being the highest.
10. Enter the Strategic Goals for Next Quarter in the Strategic Goals for Next Quarter field. This is a field for the analyst to outline their goals for the next quarter.
11. Select the Evaluation Date for the evaluation. This date is the date the evaluation was completed.
12. Optionally, enter Employee Comments in the Employee Comments field. This is a field for the analyst to provide feedback on their performance evaluation.

## Field-by-Field Explanation
* **Employee Name** (Text, Required): Enter the name of the analyst being evaluated.
* **Manager Name** (Text, Required): Enter the name of the manager who will review the evaluation.
* **Department** (Text, Required): Enter the department the analyst belongs to.
* **Data Accuracy and Integrity Rating** (Select One, Required): Select the rating for the analyst's data accuracy and integrity. Options are Exceptional, Proficient, Developing, and Needs Improvement.
* **Report Timeliness and Deadlines** (Select One, Required): Select the rating for the analyst's report timeliness and deadlines. Options are Always on Time, Usually on Time, Occasionally Late, and Frequently Late.
* **Technical Proficiency with Tools** (Select One, Required): Select the rating for the analyst's technical proficiency with tools. Options are Advanced, Intermediate, and Beginner.
* **Key Achievements This Quarter** (Text, Required): Enter the analyst's key achievements over the past quarter.
* **Areas for Development / Growth** (Text, Required): Suggest areas for personal and professional growth.
* **Overall Performance Score** (Select One, Required): Select the overall performance score for the analyst. Options are 1, 2, 3, 4, and 5.
* **Strategic Goals for Next Quarter** (Text, Required): Outline the analyst's goals for the next quarter.
* **Evaluation Date** (Date, Required): Select the date the evaluation was completed.
* **Employee Comments** (Text, Optional): Provide feedback on the performance evaluation.
* **Section  -- Analyst Quarterly Evaluation --** (Note, Required): This is a section header for the evaluation.
* **Section  -- Performance Metrics --** (Note, Required): This is a section header for the evaluation.
* **Section  -- Core Competencies --** (Note, Required): This is a section header for the evaluation.
* **Section  -- Sign-off --** (Note, Required): This is a section header for the evaluation.

## Tips
* Make sure to fill out all required fields.
* Select the correct ratings and scores for each field.
* Be specific and provide concrete examples when entering text fields.
* Proofread your work before submitting the evaluation.
