# performance_review_appointment_form - Help Guide
## Purpose
This form is used to schedule and manage performance reviews.

## How To Complete This Form
To complete this form, follow these steps:
1. Select the type of review that should be conducted from the dropdown menu on page 1.
2. Select the manager who will be involved in the review from the dropdown menu on page 2.
3. Select the employee who will be reviewed from the dropdown menu on page 3.
4. Select the date(s) of the review from the dropdown menu on page 4.
5. Select the time(s) of the review from the dropdown menu on page 5.
6. Add any additional notes about the review on page 6.
7. Select the review status from the dropdown menu on page 7.

## Field-by-Field Explanation

* **Select Review Type** (`Select the type of review`): Select the type of review to be conducted.
* **Select Manager** (`Select the manager`): Choose the manager who will be involved in the review.
* **Select Employee** (`Select the employee`): Choose the employee to be reviewed.
* **Select Date** (`Select the date`): Choose the date(s) of the review.
* **Select Time** (`Select the time`): Choose the time(s) of the review.
* **Add Notes** (`Add notes`): Add any additional information about the review.
* **Review Status** (`Review status`): Select the status of the review (Not Started, In Progress, Done).

## Tips
* Make sure to select the correct review type, manager, and employee for accurate information.
* Select the correct date and time for the review.
* Add any necessary notes to the review.
* Check the review status regularly to ensure everything is up-to-date.
