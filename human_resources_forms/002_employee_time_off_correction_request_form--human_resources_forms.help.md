# Employee Time Off Correction Request Form - Help Guide
## Purpose
This form is used to request corrections to previously submitted time off requests. It helps ensure accuracy and fairness in the time off management process.

## How To Complete This Form
1. Fill in the required fields, marked with an asterisk (\*).
2. Provide accurate information about the correction, including the date, start and end times, and reason for the correction.
3. Choose the correct status for the correction request (Approved, Pending, or Rejected).
4. Add any supporting comments or attachments as necessary.

## Field-by-Field Explanation
* **Employee Name**: <employee_name> - Enter the name of the employee requesting the correction.
* **Employee ID**: <employee_id> - Enter the employee's ID number (optional, but recommended for accurate tracking).
* **Correction Date**: <correction_date> - Enter the date on which the correction is being made.
* **Start Time**: <start_time> - Enter the corrected start time for the time off request.
* **End Time**: <end_time> - Enter the corrected end time for the time off request.
* **Reason**: <reason> - Enter the reason for the correction (optional).
* **Status**: <status> - Choose the status for the correction request: Approved, Pending, or Rejected.
* **Form Comments**: <form_comments> - Enter any comments about the correction request.
* **Attachment**: <attachment> - Upload any supporting documentation or attachments as necessary.
* **Attachment Description**: <attachment_description> - Briefly describe the attachment. 
* **Approved By**: <approved_by> - Select whether the correction request has been approved by a manager.
* **Corrected By**: <corrected_by> - Select whether the correction request was made by the original employee.
* **Employee Comment**: <employee_comment> - Enter any comments from the employee about the correction request.
