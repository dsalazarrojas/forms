# Media Public Relations Manager Interview Form - Help Guide
## Purpose
The Media Public Relations Manager Interview Form is designed to collect information about Media Public Relations Manager candidates. This form is used for internal evaluation and assessment purposes, and it's essential to complete it accurately and thoroughly for new hires.

## How To Complete This Form
To complete this form, follow these steps:

1. Fill in the "Candidate Details" section with the applicant's basic information.
2. In the "PR Manager Details" section, select the correct PR role from the dropdown menu.
3. Answer the written interview questions in the "Written Interview Responses" section, selecting multiple responses as necessary.
4. Add any additional notes or comments in the "Notes" section.
5. If applicable, provide Media Contact Details in the "Media Contact Details" section.

## Field-by-Field Explanation
* **Candidate Details** (Page 1):
	+ (id: 1, type: text, required: false): This field is for the candidate's basic information, such as their name, job title, and other relevant details.
* **Written Interview Questions** (Page 1):
	+ (id: 2, type: text, required: false): This field is for the candidate's written responses to the interview questions. Please answer each question accurately and thoroughly.
* **PR Manager Details** (Page 2):
	+ (id: 3, type: select_one, required: false): Select the correct PR role from the dropdown menu. This will help us understand the candidate's experience and qualifications.
* **Written Interview Responses** (Page 3):
	+ (id: 4, type: select_multiple, required: true): Select the responses that best answer the written interview questions. Make sure to choose all relevant responses.
* **Notes** (Page 4):
	+ (id: 5, type: note, required: false): This field is for any additional comments or notes about the candidate. Keep it brief and to the point.
* **Media Contact Details** (Page 5):
	+ (id: 6, type: text, required: false): If the candidate has any media contact details, such as email or phone numbers, please provide them here.

## Tips
* Make sure to complete all required fields accurately and thoroughly.
* Double-check your responses for spelling and grammar errors.
* If you're unsure about any field, please ask your supervisor or HR representative for guidance.
* This form is for new hires only. If you're evaluating an existing employee, please use the correct form for that purpose.
