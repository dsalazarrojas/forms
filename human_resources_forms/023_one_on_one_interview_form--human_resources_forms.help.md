# One On One Interview Form - Help Guide
## Purpose
This form is used to collect details about one-on-one interviews between employees and their managers or supervisors.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the one-on-one interview (e.g., performance evaluation, goal setting).
2. Provide a brief description of the meeting, including the main topics discussed and outcomes.
3. If applicable, specify the tool or document used during the meeting (e.g., performance evaluation form, project plan).

## Field-by-Field Explanation

* **Category** (`category`, select_one, required: false): Select the relevant category of the one-on-one interview (e.g., Human Resources Forms, Other).
* **Description** (`description`, note, required: false): Briefly describe the main topics discussed and outcomes of the meeting.
* **Output File** (`output_file`, text, required: false): If relevant, specify the file or document used during the meeting (e.g., performance evaluation form, project plan).
* **Assigned Tool** (`assigned_tool`, text, required: false): If applicable, specify the tool or document used during the meeting (e.g., performance evaluation form, project plan).
