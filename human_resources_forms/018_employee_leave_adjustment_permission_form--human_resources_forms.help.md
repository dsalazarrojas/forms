# Employee Leave Adjustment Permission Form - Help Guide
## Purpose
The Employee Leave Adjustment Permission Form is used to request an adjustment to an existing leave schedule or to make new leave requests.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the leave adjustment request (Human Resources Forms or Other Forms).
2. Briefly describe the reason for the leave adjustment in the description field.
3. Choose the date and time of the leave adjustment (if applicable).
4. Enter the employee's ID number.
5. Enter the name and email of the employee's manager.

## Field-by-Field Explanation

* **employee_leave_adjustment_permission** (text, optional): Enter a brief description of the leave adjustment request.
* **category** (select_one, optional): Select the category of the leave adjustment request. This will help human resources understand the type of request being made. Options include Human Resources Forms and Other Forms.
* **description** (text, optional): Briefly describe the reason for the leave adjustment.
* **date** (date, optional): Select the date of the leave adjustment (if applicable).
* **time** (time, optional): Select the time of the leave adjustment (if applicable).
* **employee id** (number, optional): Enter the employee's ID number.
* **manager name** (text, optional): Enter the name of the employee's manager.
* **manager email** (email, optional): Enter the email of the employee's manager.

## Tips
* Make sure to enter accurate and clear information in all fields.
* Check with the employee before submitting the form to ensure that the request is legitimate and not a duplicate.
* Review the employee's leave schedule and adjust accordingly.
* Save and submit the form when complete.
* Note: This form is not intended for use in emergency situations or urgent matters. If an urgent leave adjustment is needed, contact human resources directly.
