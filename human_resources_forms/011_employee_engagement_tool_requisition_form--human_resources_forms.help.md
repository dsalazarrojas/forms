# Employee Engagement Tool Requisition Form - Help Guide
## Purpose
This form is used to request the creation or modification of a new engagement tool. It is essential to fill in all required fields to ensure the request is processed accurately and efficiently.

## How To Complete This Form
To complete this form, follow these steps:

1. Select the category of the tool you are requesting (e.g., Human Resources Forms, Financial Management, etc.).
2. Provide a detailed description of the tool you need.
3. Enter the desired output file format (if applicable).
4. Add any additional information or requirements related to the tool.

## Field-by-Field Explanation
* **form_title** (Text, Required): Enter a brief title for the tool you are requesting.
* **category** (Select One, Optional): Choose the category of the tool you need (e.g., Human Resources Forms, Financial Management, etc.).
* **description** (Text, Required): Provide a detailed description of the tool you need.
* **form_ids** (Number, Optional): Enter your 5-digit form ID (if you have one).
* **assigned_tool** (Select One, Optional): Select the tool you would like to be assigned to (e.g., chatjimmy, chatjane).
* **output_file** (Text, Required): Specify the desired output file format (if applicable).
* **note** (Note, Optional): Add any additional comments or notes related to the tool you are requesting.
* **email** (Email, Optional): Enter your work email address.
* **phone** (Text, Optional): Enter your phone number (if applicable).
* **date** (Date, Optional): Select the date you need the tool by.
* **time** (Time, Optional): Choose the time you need the tool by.
* **description_2** (Text, Required): Provide any additional information about the tool you need.
* **description_3** (Text, Optional): Add any further comments or details about the tool.
* **description_4** (Text, Optional): Enter any specific requirements or constraints for the tool.
